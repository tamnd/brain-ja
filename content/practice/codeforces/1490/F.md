 ## 問題の理解

 整数の配列が与えられ、要素を削除できます。 削除後、残りの要素は強い規則性条件を満たす必要があります。値が存在する必要があります。$C$最終的な配列に現れるすべての数値が正確に現れるようにする$C$何度か、あるいはまったくそうではありません。 

したがって、最終的な配列はいくつかの異なる値で構成され、それらの値のそれぞれが同じ周波数に寄与します。 値の出現をすべて保持する必要はありません。頻度を選択した値と一致させるために一部を破棄できます。$C$、または完全に破棄します。 

目標は、保持する要素の数を最大化することです。これは、削除を最小限に抑えることと同じです。 

重要な問題は、どの値を保持するか、および共通の周波数を選択する必要があることです。$C$そうあるべきだ。 すべての値には独自の元の周波数があり、それを正確に「トリミング」できる場合にのみ使用できます。$C$。 

制約により、最大で$2 \cdot 10^5$すべてのテスト ケースにわたる要素。 これにより、値のすべてのサブセットを試行したり、ネストされた値ごとのスキャンですべての可能なターゲット周波数を試行したりするソリューションは即座に除外されます。 おおよその解決策は$O(n \log n)$または$O(n)$テストケースごとに必要です。 

素朴なアプローチでは、あらゆる可能性を試みるでしょう$C$から$1$に$n$、それぞれについて$C$、合計して保持できる要素の数を計算します。$\lfloor f_i / C \rfloor \cdot C$。 これでは遅すぎます。$C$すべての周波数をスキャンすると、$O(n^2)$最悪の場合。 

2 番目の微妙な落とし穴は、周波数が大きくても不均一な場合に発生します。 たとえば、1 つの値が 1000 回表示され、他の多くの値が 1 回表示される場合、$C = 1$または$C = 2$非常に異なる動作をします。 周波数を固定せずに貪欲に並べ替えることを前提としたアプローチ$C$明示的に失敗します。 

## アプローチ

 まず、配列をそれぞれの個別の値の周波数に圧縮します。 周波数があると仮定します$f_1, f_2, \dots, f_k$。 

数字を選びたい$C$およびこれらの周波数のサブセット。 選択されたそれぞれの周波数$f_i$貢献する$C$要素、$f_i \ge C$。 もし$f_i < C$、全く使えません。 

したがって、固定の場合$C$、最良の戦略は決定論的です。少なくともすべての周波数を取得します。$C$、そしてそれぞれが正確に貢献します$C$。 保持される合計サイズは次のようになります。$$C \cdot (\text{number of } f_i \ge C)$$したがって、問題は次のことを見つけることになります。$$\max_C \; C \cdot \#(f_i \ge C)$$ブルートフォースオーバー$C$から$1$に$n$この式をチェックインします$O(nk)$。 これでは遅すぎる$n$大きいです。 

重要な観察は次のとおりです$C$周波数リストに表示される値、または適格な周波数の数が変化するしきい値でのみ問題となります。 周波数を並べ替えて、個別の周波数値ごとにカウントするアプローチを使用できます。$f$、候補として扱います$C$、少なくとも周波数がいくつあるかを計算します。$f$。 これは、並べ替えとスキャンによって効率的に行うことができます。 

周波数がソートされたら、二分探索または 2 ポインター スイープを使用できます。 ポジションごとに$i$、私たちが選択するなら$C = f[i]$、次に、からのすべての周波数$i$以降は使用可能であり、次のようになります。$$f[i] \cdot (k - i)$$すべてにおいて最大限のものを採用します$i$。 

これが機能するのは、最適なソリューションは一致する必要があるためです。$C$既存の周波数値を使用します。 もし$C$は厳密に 2 つの周波数値の間にあり、わずかに増加しても対象となる要素の数は変わりませんが、有効な周波数に達した場合にのみ乗数が増加するため、最適化は離散点で発生します。

 ## アルゴリズムのチュートリアル

 1. 配列内のすべての値の頻度を数えます。 これにより、問題が出現数のリストに変換され、無関係な順序情報が削除されます。 
2. すべての周波数を配列に保存する$f$。 元の値の構造はもはや重要ではなく、それぞれが何回出現するかだけが問題になります。 
3. 周波数配列を降順でない順に並べ替えます。 並べ替えにより、特定のターゲット周波数をサポートできる値の数を効率的に推論できるようになります。 
4. 各インデックスについて$i$、 扱う$f[i]$共通周波数の候補として$C$。 これは有効です。なぜなら、最適な$C$周波数しきい値にマッピングできます。 
5. これをサポートできる値の数を計算します。$C$、つまり$k - i$、すべての周波数が$i$それ以降は少なくとも$f[i]$。 
6. 保持された要素を次のように計算します。$f[i] \cdot (k - i)$。 すべての最大値を追跡する$i$。 
7. 答えは、合計要素からこの最大保持値を引いたものです。 

### なぜ効果があるのか

 このアルゴリズムは、固定しきい値に対する不変式に基づいています。$C$、少なくとも周波数のみ$C$貢献し、それぞれが正確に貢献します$C$。 以下の頻度で値を使用しようとする試み$C$不可能、および上記の余分な出来事$C$破棄されるため無関係です。 これにより、最適化はしきい値の選択と、しきい値の中で生き残る値の数のカウントに集約され、並べ替えられた構造により、そのようなすべてのしきい値が正しい境界点で評価されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = Counter(a)
        f = sorted(freq.values())
        
        k = len(f)
        best_keep = 0
        
        for i, c in enumerate(f):
            best_keep = max(best_keep, c * (k - i))
        
        print(n - best_keep)

if __name__ == "__main__":
    solve()
```コードは、配列を周波数マップに変換することから始まります。これがコア削減ステップです。 周波数をソートすることで、しきい値に基づく評価が可能になります。 各反復では、頻度を潜在的な共通カウントとして扱い、そのレベルで参加できる値の数を評価します。 

からの引き算$n$最後に、保持された要素の最大化が、必要な削除の最小化に変換されます。 

よくある間違いは、各周波数を何倍で除算できるかで乗算しようとすることです。$C$ですが、これでは、選択されたすべての値が正確に同じ周波数を共有する必要があるという条件が破られます。

## テストケース```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output

    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = Counter(a)
        f = sorted(freq.values())
        k = len(f)
        best = 0
        for i, c in enumerate(f):
            best = max(best, c * (k - i))
        out.append(str(n - best))
    return "\n".join(out)

 ## 特殊なケース

 特殊なケースの 1 つは、すべての要素が一意である場合です。 のような入力の場合`[1,2,3,4,5]`、すべての周波数は 1 です。アルゴリズムでは次のことのみが考慮されます。$C=1$完全な保持と削除なしの結果が得られ、要件に一致します。 

もう 1 つの特殊なケースは、多くのまれな要素の中で頻度の高い 1 つの要素です。 のために`[1,1,1,1,2,3,4]`、周波数は`[4,1,1,1]`。 最適な選択は、$C=1$、すべての要素を保持します。 ソートされた周波数をスイープすると、両方が正しく評価されます。$C=1$そして$C=4$、最大値が確実に捕捉されます。 

最後のエッジケースは、複数の中周波値が存在する場合です。 のために`[1,1,2,2,3,3]`、すべての周波数が等しいため、すべての候補が同じ結果を生成します。 アルゴリズムは各しきい値を一貫して評価し、並べ替えられた構造が等価グループを自然に処理するため、特別なケースは必要ありません。
