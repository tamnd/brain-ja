 ## 問題の理解

 整数の間隔が与えられます$[l, r]$。 この間隔から、すべての整数を 1 回だけ含むリストを作成します。 このリストのコピーの 1 つは配列として固定されています$b$。 もう一方のコピー、配列$a$、最初は同一ですが、任意に並べ替えることができます。 

ポジションごとに$i$、ペアリングします$a_i$固定値で$b_i$、そしてビットごとの OR を取ることによってペアをスコア付けします。 目標は、次の順列を選択することです。$a$これらの OR 値の合計を最大化します。 

重要な問題は、値の寄与がそれ自体のビットだけでなく、その値の組み合わせにも依存することです。 ペアの両方の数値のビットが 0 に設定されていない限り、ビットは OR に寄与します。 これにより、ペアリング構造が重要となるグローバルなマッチングの問題が発生します。 

制約$r < 2^{30}$は、各数値が 30 ビットに収まることを意味します。 テスト ケース全体の間隔サイズは最大でも$2 \cdot 10^5$、つまり、大まかに言うよりも悪い解決策はありますか$O(n \log n)$またはビットごとの線形は許容されますが、二次ペアリング戦略は許容されません。 

単純な間違いは、最大値と最大値の組み合わせが最適であると想定することです。 たとえば、次のような短い間隔で$[0,3]$の場合、OR の動作が合計や XOR とは異なるため、両方の配列を同じように並べ替えると、一方を逆に並べ替える場合と比べて次善の結果が得られます。 

別の失敗例は、貪欲なローカル決定から生じます。 それぞれを合わせてみると$b_i$利用可能な最高のものを使って$a_j$独立して、より優れたグローバル ペアリングをブロックできます。 各数値は多くのビットに同時に影響を与えるため、局所的な最適性は全体的な最適性を意味しません。 

## アプローチ

これにより、問題は補数一致のアイデアに変換されます。つまり、数値をペアにして、いつでも$b_i$いくつかのビットが欠落しているため、それらのビットを次の方法で提供しようとします。$a_i$。 これは、数値と相補的なビット パターンの組み合わせを示唆しています。 

重要な観察は、どんな数値であっても$x$、数字と組み合わせる$y$最大化する$x \,|\, y$いつ$y$外部に同じ数のビットが含まれています$x$できるだけ。 ～にとってのベストパートナー$x$したがって、 は固定ビット範囲内のビット単位の補数になります。 30 ビット以内で作業しているため、これは、関連するすべてのビットが 1 である「完全なマスク」を中心に値をペアにすることを示唆しています。 

しましょう$M = (2^{30}-1)$。 次のように数字を組み合わせると、$a_i \approx M - b_i$の場合、各ペアはすべてのビットをアクティブにして、OR 合計を局所的に最大化する傾向があります。 ただし、区間内で任意の補数を構築することはできないため、範囲のビット構造に対して分割統治を使用してこのアイデアを近似します。 

間隔$[l,r]$間の最も異なるビットによって整列されたセグメントに再帰的に分解できます。$l$そして$r$。 各セグメント内で、下半分と上半分をペアにして、ペアの要素間で上位ビットを反転し、すべてのペアが OR でそのビットをアクティブにするようにします。 

この再帰的なペアリングは、最初に最も異なるビットの寄与を最大化し、その後、より小さいサブ範囲で独立して継続します。

 ## アルゴリズムのチュートリアル

 間隔を指定して再帰的に順列を構築します。 

1. フルセグメントから始めます$[l, r]$。 セグメントに要素が 1 つしかない場合は、それを直接返します。 単一の要素にはペアリングの選択肢がないため、局所的にはすでに最適化されています。 
2. 最上位ビットを見つけます。$l$そして$r$異なる。 This bit defines the most significant structural split in the interval. Everything in the interval shares higher bits, and only this bit separates values into two meaningful groups.
 3. このビットに基づいて間隔を 2 つの部分に分割します。ビットが設定されていない数値が左側のグループを形成し、ビットが設定されている数値が右側のグループを形成します。 This partition is contiguous due to binary ordering of integers.
 4. Recurse on both halves to build two ordered lists.
 5. Pair elements from the left recursive result with elements from the right recursive result in order. このペアリングにより、一方の側にはビットが設定され、もう一方の側にはビットが設定されていないため、選択されたビット位置ですべてのペアが OR で 1 となることが保証されます。 
6. 結果の配置を再帰構造と一致する方法で連結し、上位レベルのペアが下位レベルのペアよ​​りも優先されるようにします。 

### なぜ効果があるのか

 At each recursion level, we isolate the highest bit that can differ inside the segment. 最適なソリューションでは、このビットができるだけ多く寄与することを保証する必要があります。これは、セグメント サイズ内で結合されたすべての下位ビットよりも重みが優先されるためです。 

By pairing across the split induced by that bit, every pair forces that bit to appear in the OR exactly once. After fixing this bit’s contribution, the subproblems on both sides become independent because all numbers in each side share that bit value. The remaining optimization is identical on a reduced bit range, so the recursion preserves optimality inductively.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(l, r):
    if l == r:
        return [l]
    
    # find highest differing bit
    x = l ^ r
    bit = x.bit_length() - 1
    
    mid_mask = 1 << bit
    
    left = []
    right = []
    
    for i in range(l, r + 1):
        if i & mid_mask:
            right.append(i)
        else:
            left.append(i)
    
    left_res = solve(left[0], left[-1]) if left else []
    right_res = solve(right[0], right[-1]) if right else []
    
    # pair interleaving
    res = []
    for i in range(len(left_res)):
        res.append(left_res[i])
        res.append(right_res[i])
    
    return res

t = int(input())
out = []
for _ in range(t):
    l, r = map(int, input().split())
    arr = solve(l, r)
    
    # compute answer
    b = list(range(l, r + 1))
    total = 0
    for i in range(len(arr)):
        total += arr[i] | b[i]
    
    out.append(str(total))
    out.append(" ".join(map(str, arr)))

print("\n".join(out))
```The implementation follows the recursive splitting idea. 最初の重要な操作は、エンドポイント間の最大の相違ビットを識別することです。これにより、区間の最も重要な構造的パーティションが決定されます。 This ensures that we always prioritize maximizing the most valuable bit contributions first.

 へのパーティション`left`そして`right`groups is done explicitly by scanning the interval. これは再帰レベルごとに線形ですが、各レベルが互いに素なセグメントを分割するため、合計作業量は管理可能なままです。 

次に、再帰はそれぞれの半分を独立して解決しようとし、最終的に反対側の半分の対応する要素がペアになるようにそれらをインターリーブし、各 OR 計算で上位ビットが常にアクティブになることを保証します。 

微妙な点は、再構成では両方の半分が同じサイズであると仮定していることです。これは、ビットによる分割により連続する区間が正確に一致する 2 のべき乗の整列セグメントに分割されるため当てはまります。 This structural property is what makes the interleaving valid.

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def solve(l, r):
        if l == r:
            return [l]
        x = l ^ r
        bit = x.bit_length() - 1
        mid = 1 << bit
        left = []
        right = []
        for i in range(l, r + 1):
            if i & mid:
                right.append(i)
            else:
                left.append(i)
        L = solve(left[0], left[-1]) if left else []
        R = solve(right[0], right[-1]) if right else []
        res = []
        for i in range(len(L)):
            res.append(L[i])
            res.append(R[i])
        return res

    t = int(input())
    out = []
    for _ in range(t):
        l, r = map(int, input().split())
        a = solve(l, r)
        b = list(range(l, r + 1))
        total = sum(x | y for x, y in zip(a, b))
        out.append(str(total))
        out.append(" ".join(map(str, a)))
    return "\n".join(out)

 ## 特殊なケース

 次のような単一要素間隔の場合$[x,x]$、再帰はすぐに停止し、戻ります$[x]$。 ペアの選択はなく、両方の配列に同じ単一の値が含まれるため、OR の合計はゼロになります。 

次のような 2 のべき乗で整列された範囲の場合$[0,7]$、すべての再帰レベルは完全にバランスの取れた半分に分割されます。 最上位ビットは、各ペアがそのビットに 1 回寄与することを保証し、下位レベルは同じ構造を繰り返し、完全に一貫したインターリーブを生成して、OR ビットの可能な最大の飽和を達成します。
