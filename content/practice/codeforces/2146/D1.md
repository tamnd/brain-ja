 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。`l`そして`r`、 どこ`l`この簡単なバージョンでは常にゼロであり、`r`20万未満です。 これらから、配列を定義します`b`からのすべての整数が含まれます`l`に`r`、包括的。 この配列のコピーを並べ替えることができます。これを`a`。 タスクは並べ替えることです`a`したがって、対応する要素のビットごとの OR の合計は、`a`そして`b`が最大化され、最大合計と 1 つの有効な順序の両方を報告します。`a`。 

以来`l=0`、 配列`b`単純に`[0, 1, 2, ..., r]`。 配列の長さ、`n`、 は`r - l + 1`、それはまさに`r + 1`。 制約により許可されるのは、`n`すべてのテスト ケース全体で約 200,000 もの規模になります。 これにより、総当りの置換が除外されます。`n!`は天文学的に大きく、すべてのテスト ケースを合計すると O(n²) 個のペアごとの比較でも遅すぎます。 O(n log n) または O(n) の解が必要です。 

難しいのは、ビットごとの OR の合計を最大化する方法を理解することです。 それぞれをペアにするような無頓着なアプローチ`b[i]`それ自体を使用したり、単に配列を反転したりしても、常に最大の合計が得られるわけではありません。 たとえば、次の場合`b = [0,1,2,3]`、降順でペアリングします`[3,2,1,0]`合計を与える`3+3+3+3 = 12`、これは確かに最大値です。 洞察としては、高ビットが`b[i]`の数字と一致する必要があります`a`OR を最大化するために相補ビットを設定します。 

## アプローチ

 素朴なアプローチは、次のすべての順列を試してみることです。`a`、それぞれの OR の合計を計算し、最大値を選択します。 これは原理的には正しいですが、順列の数が階乗的に増加するため、まったく実行不可能です。 すべてのペアを生成する場合でも`(a[i], b[i])`ブルートフォース方式では O(n²) となり、制限時間を超えます。`n`200,000まで。 

重要な点は、ビットごとの OR 演算が設定されたビットに関して単調であるということです。 これは、より高いビットが設定されている大きな数値が、OR 合計で小さな数値よりも優勢であることを意味します。 それぞれ欲しいです`b[i]`とペアリングする`a[j]`これにより、できるだけ多くの上位ビットが OR に含まれるようになります。 これは当然、貪欲なアプローチにつながります。つまり、上位ビットが現在ゼロを持つ位置に揃うように数値を照合するというものです。`b[i]`。 実際には、これを達成する簡単な方法は、配列を逆にして、最小の位置に対して最大の数値を配置することです。 以来`l=0`そして`b`増加している、逆転している`a`すべてのテスト ケースの合計を最大化するには十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 貪欲な逆転 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`r`（以来`l=0`）。 
3. 構築する`b`として`[0, 1, 2, ..., r]`。 
4. 構築する`a`として`[0, 1, 2, ..., r]`最初にそれを逆にします`[r, r-1, ..., 0]`。 
5. 次の合計を計算します。`a[i] | b[i]`みんなのために`i`0から`r`。 
6. 和と反転配列を出力する`a`。 

なぜ機能するのか: 反転`a`最大の数値が最小の数値と一致することを保証します。`b`。 これにより、OR 演算により各位置にできるだけ多くの上位ビットが追加されるようになります。 以来`b`厳密に増加しており、`l=0`、他の順列ではこれより高い合計を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    l, r = map(int, input().split())
    n = r - l + 1
    a = list(range(l, r + 1))[::-1]  # reversed array
    total = sum(a[i] | i for i in range(n))
    print(total)
    print(' '.join(map(str, a)))
```コードは最初にテスト ケースの数を読み取ります。 テストケースごとに、`a`からの逆の順序として`l`に`r`。 OR 合計は、インデックスを反復処理し、それぞれを OR 演算することによって計算されます。`a[i]`と`b[i]`（それはただのことです`i`以来`l=0`）。 配列を反転することが不可欠です。 逆にするのを忘れた場合は、数値を単純に合計すると、厳密に小さい合計が得られます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        l, r = map(int, input().split())
        n = r - l + 1
        a = list(range(l, r + 1))[::-1]
        total = sum(a[i] | i for i in range(n))
        out.append(str(total))
        out.append(' '.join(map(str, a)))
    return '\n'.join(out)
