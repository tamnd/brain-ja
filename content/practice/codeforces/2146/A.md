 ## 解決策
 ## 問題の理解

 減少しない整数の配列が与えられ、すべての要素が同じ回数出現するサブシーケンスを見つけたいとします。 サブシーケンスは要素をスキップできますが、その順序を変更することはできません。 たとえば、から`[1, 1, 4, 4, 4]`、その続き`[1, 1, 4, 4]`バランスが取れているので、`1`そして`4`それぞれ正確に 2 回表示されます。 タスクは、そのようなバランスの取れたサブシーケンスの最長のものの長さを決定することです。 

制約は中程度です。各配列には最大 100 個の要素があり、最大 500 個のテスト ケースがあります。 これは、テスト ケースごとにおよそ O(n²) の操作を含むアルゴリズムが制限時間内で快適に実行されることを示唆しています。 また、サイズが小さいため、複雑さの高い最適化を心配することなく、計数頻度に基づいてソリューションを検討することができます。 

すべての要素が同じである場合、微妙な特殊なケースが発生します。 のために`[3, 3, 3, 3, 3]`、アレイ全体はすでにバランスが取れています。 もう 1 つは、すべての要素が個別である場合です。`[1, 2, 3]`; ここでのバランスの取れたサブシーケンスは、任意の単一要素、またはそれぞれが 1 回出現する場合はすべての要素です。これは、各要素が 1 回だけ出現するため機能します。 頻度を調べずにサブシーケンスを形成しようとする単純なアプローチでは、これらのシナリオでは誤った結果が生じる可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを生成し、それらのバランスが取れているかどうかを確認します。 サブシーケンスごとに、各要素の出現数を数えて比較します。 あらゆる可能性を徹底的に考慮しているため、これは正しいです。 ただし、部分列の数は指数関数的に (2ⁿ) 増加するため、このアプローチは n=20 の場合でも実行不可能になります。 

より良いアプローチは、要素がソートされ、頻度カウントが使用されるという事実を利用します。 まず、それぞれの異なる数字が何回出現するかを数えます。 次に、すべての要素がサポートできる出現回数 k を選択することにより、最も長いバランスの取れたサブシーケンスが取得されます。 たとえば、周波数が次の場合、`[3, 5, 2]`、すべての数値が少なくとも 2 回出現し、長さの部分列を形成するため、k=2 を選択できます。`2 * 3 = 6`。 1 から任意の要素の最大周波数まで、考えられるすべての k を反復処理することで、最大のバランスの取れたサブシーケンスを効率的に見つけることができます。 

重要な洞察は、バランスの取れたサブシーケンスの長さは、選択された出現数と、少なくともその数の出現を提供できる個別の数値の数を掛けたものであるということです。 頻度カウントをソートすると、配列内に存在する頻度を確認するだけで済むため、最大長を見つけることが簡単になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2ⁿ * n) | O(n) | 遅すぎる |
 | 最適 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケース t の数を読み取ります。 各テスト ケースについて、n と配列 a を読み取ります。 
2. それぞれの異なる数値の出現数を数えます。 配列はソートされているため、これを 1 回のパスで実行できます。 カウントをリストに保存する`freq`。 
3.初期化`max_len`これにより、最も長いバランスのとれたサブシーケンスの長さが保持されます。 
4. 1 から最大周波数までの考えられるカウント k ごとに、次のようになります。 

ａ． 要素の数を数えます`freq`k 以上です。 これに電話してください`num_elements`。 

b. 候補となる部分列の長さは次のとおりです。`k * num_elements`。 アップデート`max_len`これが現在より大きい場合`max_len`。 
5. After iterating through all k, output`max_len`このテストケースでは。 

不変条件は、各ステップで、少なくとも 1 つの要素によって提供できるカウント k のみを考慮するということです。 可能なすべての k を反復処理することで、最適なサブシーケンス長を見逃さないようにします。 計算するから`num_elements`各 k について、そのサイズのバランスの取れたサブシーケンスに参加できる要素のみを正しく考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    freq = []
    count = 1
    for i in range(1, n):
        if a[i] == a[i-1]:
            count += 1
        else:
            freq.append(count)
            count = 1
    freq.append(count)
    
    max_len = 0
    max_freq = max(freq)
    
    for k in range(1, max_freq + 1):
        num_elements = sum(1 for f in freq if f >= k)
        max_len = max(max_len, k * num_elements)
    
    print(max_len)
```最初のセクションでは、入力を効率的に読み取り、単純なリニア スキャンを使用して周波数をカウントします。 の`freq`リストには、それぞれの一意の番号が何回出現するかが含まれます。 可能な k 値を反復することで、各数値が同じ回数出現するすべてのサブシーケンスを考慮することが保証されます。 少なくとも k 回出現する要素をカウントすることで、サブシーケンスのバランスが保たれることが保証されます。

 両方の数値が 1 回出現するため、配列全体のバランスが取れ、最大長は 2 になります。
