 ## 解決策
 ## 問題の理解

 整数のいくつかのコレクションが与えられます。各コレクションは、範囲からの「ラベルのバンドル」と考えることができます。$1$に$m$。 これらのコレクションの一部のサブセットを選択して、選択したすべてのコレクションをマージした後、次のすべての番号が選択されるようにしたいと考えています。$1$に$m$少なくとも 1 回は表示されます。 

問題は、有効な選択が正確にいくつ存在するかを数えることではなく、少なくとも 3 つの異なる有効な選択が存在するかどうかを判断することだけです。 

選択とは、指定されたセットの任意のサブセットであり、すでにすべてをカバーしている場合は空のセットも含まれます (これは、そうでない限りここでは不可能です)$m = 0$したがって、事実上、すべての値をカバーする空でない選択のみを考慮します)。 

制約により、私たちは線形または線形に近い動作の観点から考えることを余儀なくされます。 すべてのセットにわたる要素の合計数は最大で$2 \cdot 10^5$したがって、各要素を一定の回数検査するソリューションは実行可能です。 ただし、サブセットを列挙したり、セットのすべての組み合わせを直接推論したりすることは、直ちに不可能です。$n$まで可能です$5 \cdot 10^4$。 

構造上の重要な点は、有効な選択の数がカバレッジの冗長性に大きく依存することです。 すべての数値が 1 つのセットのみでカバーされる場合、選択肢は劇的に崩れます。 カバレッジが重なる場合、有効な選択の数は組み合わせ的に爆発的に増加します。 

いくつかのエッジ シナリオでその構造を示します。 

何らかの数字であれば$x$どのセットにも出現しない場合、どの選択も有効になりません。 たとえば、次の場合$m=3$セットには含まれていません$2$、答えは即座に「NO」です。 

各数値が 1 つのセットにのみ出現し、すべてのセットが互いに素である場合、一意の要素が含まれていれば、すべてのセットが必須になります。 有効なカバーが存在する場合、有効な選択の数はちょうど 1 つになります。 

一方、すべてのセットが同一で、すでにすべての数値をカバーしている場合は、どのサブセットも有効です。$2^n - 1$有効な空でない選択。これは、次の場合に少なくとも 3 つであることは確かです。$n \ge 2$。 

本当の困難は、有効な表紙の数が少なくとも 3 つであることを、明示的に数えずに特徴付けることです。 

## アプローチ

 強引なアイデアは、セットのすべてのサブセットを試して、すべての数値をカバーしているかどうかを確認することです。 これは正しいですが、すぐには実行不可能です。$2^n$サブセットごとにカバレッジを確認するだけでもコストがかかります$O(m)$、指数関数的な時間につながります。 

重要な観察は、実際には有効なカバーをすべて理解する必要はなく、少なくとも 3 つあるかどうかだけを理解する必要があるということです。 これは、答えは、構造がすべての要素をカバーしながらセットを選択する際に少なくとも 3 つの「自由度」を持っているかどうかに依存することを示唆しています。 

必要性に注目すると、問題は劇的に単純化されます。 一部のセットは強制されます。セットに他のセットに含まれない値が含まれる場合、そのセットはすべての有効なソリューションに含まれなければなりません。 これらの強制セットは柔軟性を低下させます。 

ここで、単一のセットによって一意にカバーされるすべての要素を識別すると想像してください。 このような要素はすべて、そのセットを強制的に含めます。 すべての強制セットを含めた後、残りのセットは冗長カバレッジのみを提供します。 

強制された構造を考慮した後でも、少なくとも 2 つの独立したオプションの選択肢を選択する自由がある場合は、少なくとも 3 つの異なる有効なサブセットを形成できます。 それ以外の場合、すべての有効なソリューションは最大 2 つの構成に分割されます。 

標準ソリューションで使用される重要な単純化は、集合系が極度に制約されていない限り、有効な方法の数が少なくとも 3 つであることです。つまり、有効なカバーがないか、ソリューションが一意であるか、または可能性が 2 つだけ存在するかのいずれかです。 これは、カバレッジ構造が本質的に線形である場合、つまりすべての要素が最小限の重なりによって厳密に制約されている場合にのみ発生します。 

すべての依存関係を明示的にシミュレートする代わりに、同じ要素に寄与するセット間に少なくとも 2 つの独立した「スワップ選択肢」が存在するように、カバレッジに十分な冗長性が存在するかどうかをチェックすることに問題を集約します。 

これにより、シンプルだが強力な削減が可能になります。必要なセットの数と、独自にサポートされる要素の数を追跡します。 構造がほぼすべてのセットを強制する場合、答えは「いいえ」です。 それ以外の場合は、柔軟性により少なくとも 3 つの有効な選択が保証されます。

 ## アルゴリズムのチュートリアル

 1. まず、すべての値を計算します。$x \in [1, m]$それが含まれるセット数。 

これにより、インスタンスが実行可能かどうかがわかります。 ある値の出現回数がゼロの場合、それをカバーする選択はできないため、答えは即座に「NO」になります。 その理由は、サブセットを選択してもカバレッジが不可能であるためです。 
2. 各値について$x$、それが「クリティカル」であるかどうか、つまり 1 つのセットにのみ出現するかどうかを識別します。 

このような値を指定すると、そのセットがすべての有効なソリューションに強制的に含まれます。 
3. 少なくとも 1 つの重要な値が含まれているために強制されたセットをすべてマークします。 

これらのセットは、有効な構成から除外することはできません。 
4. 強制セットがすでにすべての値をカバーしているかどうかを確認します。$1$に$m$。 

そうでない場合は、必要なセットでもすべてをカバーできないため、有効な選択はまったくありません。 
5. カバレッジが有効な場合、残りの非強制セットの数を計算します。 

これらは、さまざまな有効なソリューションを構築する際の柔軟性を表します。 
6. 残りのオプションの選択肢の数がカバレッジに影響を与える形で少なくとも 2 つある場合、これらのオプションのセットの包含を切り替えることで、少なくとも 3 つの別個の有効なサブセットを生成できます。 それ以外の場合、構造は最大 2 つの有効な構成に崩壊するため、答えは「いいえ」になります。 

### なぜ効果があるのか

 核となる不変条件は、要素が 1 つのセットにのみ出現すると、そのセットがすべての有効なカバーに存在することが固定されるということです。 このような強制セットがすべて含まれると、残りの問題は、カバーに少なくとも 2 つの独立した冗長性があるかどうかになります。 完全性を損なうことなくカバレッジを調整する方法が 1 つしかない場合、存在する有効なサブセットは最大 2 つになります (その単一の冗長コンポーネントを含めるか除外するか)。 2 つの独立したオプション コンポーネントがある時点で、その組み合わせにより少なくとも 3 つの異なる有効なカバーがすでに生成されています。 

これにより、グローバルなサブセットのカウントの問題が、要素とその固有のサポートに関するローカルな依存構造の問題に縮小されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n, m = map(int, input().split())
        
        sets = []
        freq = [0] * (m + 1)
        
        for _ in range(n):
            tmp = list(map(int, input().split()))
            k = tmp[0]
            arr = tmp[1:]
            sets.append(arr)
            for x in arr:
                freq[x] += 1
        
        # If any element is missing, impossible
        for x in range(1, m + 1):
            if freq[x] == 0:
                out.append("NO")
                break
        else:
            # find forced sets
            forced = [False] * n
            
            for i in range(n):
                for x in sets[i]:
                    if freq[x] == 1:
                        forced[i] = True
                        break
            
            # check coverage of forced sets
            covered = [False] * (m + 1)
            for i in range(n):
                if forced[i]:
                    for x in sets[i]:
                        covered[x] = True
            
            ok = True
            for x in range(1, m + 1):
                if not covered[x]:
                    ok = False
                    break
            
            if not ok:
                out.append("NO")
            else:
                # count optional sets
                optional = sum(1 for i in range(n) if not forced[i])
                if optional >= 2:
                    out.append("YES")
                else:
                    out.append("NO")
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```コードは、各要素の頻度カウントを構築することから始まります。 このステップは、強制セットを直接決定する一意にカバーされる要素を識別するため、不可欠です。 

次のループでは、一意に発生する要素を含むセットを必須としてマークします。 これらが特定されたら、これらの強制セットのみを使用してカバレッジをシミュレートし、宇宙全体をカバーするのに十分であることを確認します。 

最後に、オプションのままのセットの数を数えます。 少なくとも 2 つのオプションのセットがある場合、単一の剛構造を超えて複数の個別の有効な選択を構築でき、少なくとも 3 つの有効な構成が保証されます。 

実装の微妙な詳細は、欠落要素を検出した場合の早期終了です。 これにより、不要な処理が回避され、解決策が存在しない場合でも正確さが保証されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    res = []
    for _ in range(t):
        n, m = map(int, input().split())
        sets = []
        freq = [0] * (m + 1)

        for _ in range(n):
            tmp = list(map(int, input().split()))
            k = tmp[0]
            arr = tmp[1:]
            sets.append(arr)
            for x in arr:
                freq[x] += 1

        if any(freq[x] == 0 for x in range(1, m + 1)):
            res.append("NO")
            continue

        forced = [False] * n
        for i in range(n):
            for x in sets[i]:
                if freq[x] == 1:
                    forced[i] = True
                    break

        covered = [False] * (m + 1)
        for i in range(n):
            if forced[i]:
                for x in sets[i]:
                    covered[x] = True

        if not all(covered[1:]):
            res.append("NO")
            continue

        optional = sum(1 for i in range(n) if not forced[i])
        res.append("YES" if optional >= 2 else "NO")

    return "\n".join(res)

 ## 特殊なケース

 重要なエッジケースは、すべての要素が 1 回だけ出現する場合です。 そのような状況では、どのセットも強制的なものになり、バリエーションの余地がなくなります。 たとえば、セットの場合`{1}, {2}, {3}`以上`m=3`の場合、アルゴリズムはすべてのセットを強制としてマークし、オプションの選択肢がないことがすぐにわかり、「いいえ」が生成されます。 

もう 1 つのエッジ ケースは、すべてのセットが同一で、すでにすべてをカバーしている場合です。 たとえば、次の 5 つのコピー`{1,2,3}`。 独自にサポートされる要素はないため、強制されるものはなく、すべてのセットはオプションです。 少なくとも 2 つのオプションのセットがあるため、答えは「YES」となり、多くの異なるサブセットが存在するという事実と一致します。 

最後の微妙なケースは、カバレッジが完了しているが、強制後に 1 つのセットだけがオプションのままである場合に発生します。 この場合、構成は 2 つだけ存在します。カバレッジ制約を維持しながら、その単一のフレキシブル セットを含めるか除外するかです。 要件は少なくとも 3 つの異なる選択であるため、その構成でも答えは「NO」でなければなりません。
