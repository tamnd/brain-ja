 ## 解決策
 ## 問題の理解

 数直線上で卵が配置される一連の位置が与えられます。 また、固定数の加熱ランプを整数座標に配置することもできます。 すべての卵は最も近いランプによって「提供」され、構成の品質は卵から最も近いランプまでの最大距離によって測定されます。 

タスクは、最大でも$k$この最大距離ができるだけ短くなるようにランプを調整します。 

これについて考えると便利な方法は、各ランプがその近傍の卵を覆っており、すべての卵は少なくとも 1 つのランプから一定の半径内に収まる必要があるということです。 すべての卵をカバーできる最小半径を最小化しようとしています。$k$センター。 

制約は大きく、最大で$5 \cdot 10^5$これにより、すべての配置を評価したり、すべての構成の距離をシミュレートしようとするソリューションは除外されます。 二次関数または偶数関数$O(nk)$機能しません。 少なくとも必要です$O(n \log n)$、 通常$O(n \log \max a_i)$または$O(n \log n)$。 

単純なアプローチでは、エッグ間またはエッグ間にランプを配置できるすべての配置を試してカバレッジを計算しますが、候補となる構成の数が組み合わせで増加するため、それはすぐに失敗します。 

貪欲な直感が微妙に失敗するケースは、卵の間隔が不均等な場合に現れます。 たとえば、ほとんどの卵がクラスター化されているが、1 つが遠くにある場合、単純な均等分割ではランプの配置が適切に行われない可能性があります。 

次のように入力します。```
5 2
0 1 2 100 101
```単純な「カウントで均等に分割する」アプローチでは、ランプがインデックス 2 と 101 のクラスター境界の近くに誤って配置され、最適なグループ化が失われる可能性があります。 正しい解決策は、数ではなく距離に依存します。 

## アプローチ

 強引な解釈では、半径を考慮します。$R$最大でも配置できるかどうかを尋ねます$k$すべての卵が距離内にあるようにランプを付ける$R$あるランプの。 これを効率的にテストできれば、二分探索を行うことができます。$R$。 

固定の場合$R$、各ランプが一定の長さの間隔をカバーする位置に配置されていると想像できます。$2R$。 すべての卵が入っているので、$R$ランプの 1 つがそのような間隔内にある必要があり、各ランプはソートされた卵の位置の連続セグメントを効果的にカバーします。 

これは貪欲なチェックにつながります。最も左の覆われていない卵から始めて、距離内でできるだけ多くの卵を覆うようにランプを最適に配置します。$R$と繰り返します。 許可されたカバレッジ ウィンドウ内のできるだけ右にランプを配置すると、常に以前の配置が優先されるため、これは最適です。 

配置ポイントのサブセットの数が指数関数的であるため、すべての配置を試行する総当りバージョンは実行不可能です。 重要な洞察は、固定半径の場合、構造は並べ替えられた線上の区間をカバーし、線形時間で貪欲に解決できるということです。 

したがって、最適化問題を決定問題に変換し、その答えを二分探索します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース配置 | 指数 | O(n) | 遅すぎる |
 | 二分探索 + 貪欲チェック | O(n log V) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 卵の位置を並べ替える

 並び替えが必要になるのは、報道がラインに沿った順序でのみ意味を成すからです。 並べ替えがなければ、連続するセグメントについて推論することはできません。 

### ステップ 2: 関数を定義する`can(R)`半径かどうかをテストします$R$せいぜい使用すれば十分です$k$ランプ。 

### ステップ 3: 貪欲なカバーリングプロセス

 まだ覆われていない左端の卵から始めます。 

その卵を所定の位置に取ります$x$。 カバーをしたまま、ランプをできるだけ右に配置します。$x$、つまり、次の場所に配置することを意味します。$x + R$。 このランプはすべての卵を最大までカバーします。$x + 2R$。 

この選択は最適です。$x$に横たわらなければなりません$[x - R, x + R]$、右にシフトすると、カバレッジを失うことなく、右側のカバレッジが増加するだけです。$x$。 

### ステップ 4: 覆われた卵を飛び越える

 ランプを配置した後、ポインターを最初の卵に進めます。$x + 2R$。 これは、1 回の操作でセグメント全体を消費することをシミュレートします。 

### ステップ 5: 使用したランプの数を数える

 必要なランプの数を超える場合$k$、 それから$R$小さすぎます。 

### ステップ 6: 二分探索の答え

 最低限のものを探す$R$0 から卵間の最大可能距離まで。 各チェックは直線的な時間で実行されます。 

### なぜ効果があるのか

 このアルゴリズムは単調な特性に依存しています。$R$機能するだけでなく、より大きな半径も機能します。 これにより二分探索が可能になります。 貪欲なカバーにより、あらゆる固定に対して確実に$R$、各ステップで常に可能な限り右側をカバーすることで、必要なランプの数を最小限に抑えます。 これにより、最適ではない部分的なカバレッジでのランプの無駄遣いが防止され、貪欲な戦略が必要以上のものを必要とする場合に保証されます。$k$ランプの代わりにこれ以上の効果を発揮するものはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(a, k, r):
    n = len(a)
    i = 0
    used = 0

    while i < n:
        used += 1
        if used > k:
            return False

        start = a[i]
        cover_end = start + 2 * r

        while i < n and a[i] <= cover_end:
            i += 1

    return True

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    lo, hi = 0, a[-1] - a[0]

    while lo < hi:
        mid = (lo + hi) // 2
        if can(a, k, mid):
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```ソートステップにより、すべての貪欲な間隔が連続していることが保証されます。 の`can`関数は中核となる決定手順であり、卵をサイズの間隔の最小数に貪欲にグループ化します。$2R$。 次に、二分探索により、実行可能な最小の半径が見つかります。 

微妙な点は、ランプの位置を明示的に保存する必要がないことです。 必要なのは、一番左の覆われていない卵に対して最適に配置することによって引き起こされるカバレッジ間隔だけです。 

もう 1 つのよくある間違いは、$R$代わりに間隔の長さとして直接$2R$。 位置にあるランプ$x+R$カバー$[x, x+2R]$、 ない$[x, x+R]$。 

## 実用的な例

 ### 例 1

 入力:```
3 20
0 5 7
```ソートされた配列はすでに`[0, 5, 7]`。 

半径の実現可能性をテストします。 

| ステップ | 私 | 位置 | 中古ランプ | 取材終了 |
 | --- | --- | --- | --- | --- |
 | 開始 | 0 | 0 | 1 | 0+2R |
 | 移動 | 1 | 5 | 1 | 0+2R |
 | 移動 | 2 | 7 | 1 | 0+2R |
 | 終わり | 3 | - | 1 | - |

 十分な大きさの場合$R$、ランプは1つで十分です。 もし$R = 1$、カバレッジは 2 であるため、最初のランプは 0 のみをカバーし、5 と 7 には別のランプが必要となり、ランプが 2 つになります。 二分探索により最小値が見つかります$R$ランプを制限内に保ちます。 

### 例 2

 入力:```
5 2
-2 -1 0 1 4
```並べ替え:`[-2, -1, 0, 1, 4]`たとえば、半径を小さくしてみてください$R = 1$。 

| ステップ | 私 | 開始 | カバーエンド | 中古 |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | -2 | 0 | 1 |
 | 2 | 3 | 1 | 3 | 2 |
 | 3 | 4 | 4 | - | 3 (失敗) |

 ランプが3つ必要なので、$R = 1$実現不可能です。 

のために$R = 2$:

 | ステップ | 私 | 開始 | カバーエンド | 中古 |
 | --- | --- | --- | --- | --- |
 | 1 | 0 | -2 | 2 | 1 |
 | 2 | 4 | 4 | 6 | 2 |

 2 つのランプで動作するようになりました。$k$。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |$O(n \log V)$| ソートと範囲にわたる二分検索。 各実現可能性チェックは線形です。 
| スペース |$O(n)$| ソートされた位置のストレージ |

 値の範囲$V$までです$2 \cdot 10^9$ただし、二分探索には約 31 回の反復しか必要ありません。 と$n = 5 \cdot 10^5$、これは制限内に快適に収まります。

 ## 特殊なケース

 単一の卵の入力は次のようになります`n = 1`距離が存在しないため、常に 0 を返します。 二分探索範囲が崩れてしまうため、アルゴリズムがこれを処理します。`can(0)`1 つのランプですぐに true を返します。 

すべての卵が等間隔に配置されている場合、たとえば`[1,2,3,4,5]`は、グループ化がカウントではなく距離に基づいて厳密に行われることをアルゴリズムに強制します。 のために`k = 2`、貪欲な手順は 2 つの連続したセグメントを形成し、離れた要素を決して混合しようとせず、最適な分割を生成します。 

大きく離れた外れ値、たとえば、`[0,1,2,3,100000]`、貪欲な戦略が密集領域でランプを無駄にしないことをテストします。 最初のランプカバー`[0..3]`、2 番目のランプは外れ値のみをカバーし、最初のランプを右に移動しようとすると左側のカバレッジが減少しますが、これは不変式で禁止されています。
