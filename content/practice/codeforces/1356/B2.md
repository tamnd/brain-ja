 奇数素数を法として計算します$p$と因数$$x^8 + 1.$$因数分解の構造は完全に方法に依存します。$-1$そして$2$で行動する$\mathbb{F}_p$、自然な試みは書き換えることであるため、$x^8+1$これらの要素の平方根から得られる二次式の積として。 

アイデンティティから始める$$x^8 + 1 = (x^4)^2 + 1^2,$$したがって、最初の自然なステップは、以下を含む拡張に対する二次因数分解です。$\sqrt{-1}$:$$x^8 + 1 = (x^4 - i)(x^4 + i),$$どこ$i^2 = -1$適切な拡張フィールドに。 以上$\mathbb{F}_p$、これはベースフィールドで正確に分割されます$\sqrt{-1} \in \mathbb{F}_p$、つまり、いつ$p \equiv 1 \pmod{4}$。 

次に、同じアイデアを適用して各 4 次項をさらに因数分解します。$x^4 \pm i$。 

の有無に応じてケースを区別するようになりました。$\sqrt{-1}$、$\sqrt{2}$、 そして$\sqrt{-2}$で$\mathbb{F}_p$。 

### ケース 1:$\sqrt{-1} \in \mathbb{F}_p$書く$i = \sqrt{-1}$。 それから$$x^8 + 1 = (x^4 - i)(x^4 + i).$$導入後の各 4 次は 2 乗の差です。$\sqrt{2}$そして$\sqrt{-2}$。 

最初に書き換えます:$$x^4 - i = (x^2)^2 - i.$$もし$\sqrt{i}$が存在すると、これは直接分割されますが、$\sqrt{i}$まさにそのときに存在します$\sqrt{-1}$平方根がある場合、つまり$-1$は第4の力です。 これは必要以上に強力なので、代わりに二次補完を使用して対称的に因数分解します。$$x^4 - i = (x^2 + a x + b)(x^2 - a x + b)$$係数を一致させると、$$b^2 = -i,\quad a^2 = 2b.$$したがって、因数分解は次の存在に帰着します。$\sqrt{-i}$そして$\sqrt{2}$。 

以来$-i = \sqrt{-1}\cdot (-1)$、必要な量はすべて次のように表すことができます。$\sqrt{-1}$そして$\sqrt{2}$。 

両方のとき$\sqrt{-1}$そして$\sqrt{2}$存在すると、4 つの二次因子が得られます。$$x^8+1 = \prod_{\varepsilon_1,\varepsilon_2 \in \{\pm 1\}} \left(x^2 + \varepsilon_1 \sqrt{2}\, x + \varepsilon_2 \sqrt{-1}\right).$$### ケース 2:$\sqrt{-1} \notin \mathbb{F}_p$、 しかし$\sqrt{-2} \in \mathbb{F}_p$させて$j = \sqrt{-2}$。 それから$j^2 = -2$、 それで$-1 = j^2/2$。 キー因数分解は、次の根をペアにすることによって得られます。$x^8+1$形で$$x^8 + 1 = (x^4 + j x^2 + 1)(x^4 - j x^2 + 1).$$各 4 次関数は 2 次関数代入によって削減されるようになりました。$y = x^2$:$$y^2 \pm j y + 1.$$これらは分裂していきます$\mathbb{F}_p$まさにいつ$\sqrt{j^2 - 4} = \sqrt{-2 - 4} = \sqrt{-6}$存在します。 許可されるラジカルに関しては、$\sqrt{-2}$すでに障害物がエンコードされており、最終的な因数分解は 2 次式になります。$$x^8 + 1 = \prod_{\varepsilon \in \{\pm 1\}} \left(x^2 + \varepsilon \sqrt{-2}\, x + 1\right)\left(x^2 - \varepsilon \sqrt{-2}\, x + 1\right)$$各四次関数内の正方形を完成させた後。 

したがって、すべての因子は次のようにパラメータ化された二次式になります。$\sqrt{-2}$。 

### ケース 3:$\sqrt{-1} \notin \mathbb{F}_p$、$\sqrt{2} \notin \mathbb{F}_p$、 しかし$\sqrt{-2} \in \mathbb{F}_p$これは一般的な奇数素数の状況です。$x^8+1$は、次の場合を除き、連続する 2 次拡張に対して既約です。$-2$構造。 

私たちはアイデンティティを利用します$$x^8+1 = (x^4 + 1)^2 - 2x^4.$$セット$y = x^2$、与える$$y^4 + 1 = (y^2 + \sqrt{-2}\, y + 1)(y^2 - \sqrt{-2}\, y + 1).$$それぞれの二次方程式$y$の 4 次因数を生成します$x$:$$x^4 \pm \sqrt{-2}\, x^2 + 1.$$これらは依然として還元不可能です$\mathbb{F}_p$ない限り$\sqrt{2}$または$\sqrt{-1}$存在します。 したがって、最終的な因数分解は次のようになります。$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1).$$### ケース 4: どれも$\sqrt{-1}, \sqrt{2}, \sqrt{-2}$存在する

 この状況では、二次改良は行われません。 多項式は、上記の 2 つの四次関数の積として既約です。$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1),$$そして各四次関数はいつまでも既約のままです$\mathbb{F}_p$。 

## 最終的な明示的な因子の説明

 すべての奇数素数は上記のいずれかのケースに当てはまり、因数は常に次のように表現できます。$\sqrt{-1}$、$\sqrt{2}$、 そして$\sqrt{-2}$それらが存在するとき。 

統一的な説明は次のとおりです。$$x^8 + 1 = (x^4 + \sqrt{-2}\, x^2 + 1)(x^4 - \sqrt{-2}\, x^2 + 1),$$そしていつでも$\sqrt{-1}$そして$\sqrt{2}$が存在し、各四次関数はさらに次のように分割されます。$$x^8+1 = \prod_{\varepsilon_1,\varepsilon_2 \in \{\pm 1\}} \left(x^2 + \varepsilon_1 \sqrt{2}\, x + \varepsilon_2 \sqrt{-1}\right).$$これで、指定された根号に関する明示的な因数分解が完了します。 ∎
