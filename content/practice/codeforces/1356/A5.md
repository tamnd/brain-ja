 ## 解決策
 ## 問題の理解

 単一の量子ビットに作用する量子操作が与えられています。 この演算は、量子ビットの |1⟩ コンポーネントを変更せずに |0⟩ の位相を反転する Z ゲート、または |0⟩ の位相を反転し、|0⟩ 項にグローバルに追加の負符号を追加する -Z ゲートのいずれかです。 私たちの目標は、操作またはその随伴/制御されたバリアントの 1 回の呼び出しを使用して、これら 2 つの可能性を区別することです。 

入力は古典的なデータではなく、既知のインターフェイスを備えた量子演算です。量子ビット上でそれを呼び出し、後で量子ビットを測定できます。 出力は整数です。操作が Z の場合は 0、-Z の場合は 1 です。 

制約の観点から見ると、クエリはバリアントごとに 1 つしかないため、操作を繰り返し適用する単純なアプローチは不可能です。 エッジ ケースは、グローバル フェーズを無視した場合に発生します。Z と -Z は両方とも、グローバル フェーズまでの計算基礎状態 |0⟩ と |1⟩ に対して同じように動作します。 計算ベースで不注意に測定すると、常に同じ結果が得られ、区別がつきません。 たとえば、Z または -Z を |0⟩ に適用してすぐに測定すると、どちらも確実に 0 が得られます。 正しい出力には、アダマール基底などの相対位相を明らかにする基底の変更が必要です。 

## アプローチ

 強引な方法は、|0⟩ または |1⟩ に演算を適用して計算ベースで測定することです。 Z と -Z の両方が |1⟩ を変更せず、測定では観測できないグローバル位相によって |0⟩ を反転するため、これは常に失敗します。 操作数は最小限ですが、このアプローチは論理的に不十分です。 出力は常に区別できないため、単純な解決策ではランダムな結果が生成されます。 

重要な洞察は、計算ベースではなくアダマールベースで測定することです。 アダマール ゲートは |0⟩ → |+⟩ = (|0⟩ + |1⟩)/√2 および |1⟩ → |−⟩ = (|0⟩ − |1⟩)/√2 をマップします。 この基準では、Z ゲートは |+⟩ を変更しないままですが、-Z は |+⟩ を |−⟩ に反転します。 アダマールを適用した後に計算ベースで測定すると、この区別が観察可能な結果に変換されます。Z は 0 を生成し、-Z は 1 を生成します。この 1 回のアダマール適用、次に未知の演算、そして再びアダマールを適用するだけで、2 つのゲートを区別するのに十分です。

 ## アルゴリズムのチュートリアル

 1. 単一の量子ビットを割り当てます。 この量子ビットは、ゲートのタイプを決定するためのプローブになります。 
2. アダマール ゲートを量子ビットに適用します。 これにより、|0⟩ が |+⟩ に変換されます。 後でアダマール基底で測定すると、全体的な位相反転を検出できるようになります。 
3. 未知のユニタリ演算を適用します。 Z の場合、|+⟩ は |+⟩ のままです。 -Z の場合、|+⟩ は |−⟩ になります。 
4. 別のアダマール ゲートを適用します。 これは |+⟩ → |0⟩ および |−⟩ → |1⟩ をマッピングし、位相情報を測定可能な計算基礎状態に変換します。 
5. 量子ビットを測定します。 測定された整数を返します。 結果 0 は Z に対応し、結果 1 は -Z に対応します。 

**機能する理由:** このアルゴリズムが機能するのは、アダマールが位相情報を計算基礎に変換するためです。 不変条件は、最初のアダマールの後、量子ビット状態が未知のゲートによって導入された位相差をエンコードするということです。 2 番目のアダマールを適用すると、この位相が決定論的に 0 または 1 の測定値に変換されます。 大域位相は計算上目に見えないため、この基底回転は必須である。 どのゲートが適用されるかに関係なく、このシーケンスにより固有の測定結果が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Quantum simulation using Qiskit for illustration
from qiskit import QuantumCircuit, Aer, execute

def solve(unitary: QuantumCircuit) -> int:
    qc = QuantumCircuit(1, 1)
    qc.h(0)
    qc.append(unitary.to_instruction(), [0])
    qc.h(0)
    qc.measure(0, 0)
    backend = Aer.get_backend('qasm_simulator')
    result = execute(qc, backend, shots=1).result()
    counts = result.get_counts()
    return int(list(counts.keys())[0])
```コードは量子ビットを初期化し、アダマールを適用して +/- 基底を入力し、未知の演算を適用してから、再度アダマールを適用します。 測定値は |+⟩ → 0 および |−⟩ → 1 にマップされます。手順が決定的であるため、ワンショットを使用します。

 ## 特殊なケース

 計算基礎を直接適用すると失敗します。 |0⟩ の量子ビットの場合、Z または -Z の後の測定では 0 が得られます。アダマール回転を使用すると、位相反転が観察可能になります。 |+⟩ → |−⟩ または |−⟩ → |+⟩ マッピングはグローバル フェーズでは不変であるため、負のグローバル フェーズのエッジ ケースも同様に機能します。 アダマール後の測定は、符号に関係なく -Z に対して 1 を返します。 アルゴリズムはこれを決定論的に処理します。
