 ## アルゴリズムのチュートリアル

 標準の対話型制約は最大 12 クエリであると仮定します。 

### ステップ

 1. 1 から n までのすべてのインデックスをクエリして、グローバル最大値を取得します$M$。 

これにより、すべての答えの上限が得られ、すべての比較が固定されます。 
2. インデックスに対して二分検索を実行して、1 つの位置を特定します。$p$そのような$A[p] = M$。

3. インデックスを取得したら$p$、2番目の最大値を見つけることができます$M_2$を除くすべてのインデックスをクエリすることにより、$p$。 

これは、最大値の 1 つの出現を削除しても、それが唯一の出現でない限り結果に影響を与えないため機能します。 
4. サブセットごとに$S_i$を削除すると、すべての最大位置が削除されるかどうかを判断したいと考えています。 

の補数をクエリします$S_i$。 結果が次の場合$M$の場合、少なくとも 1 つの最大インデックスが外側に残ります。$S_i$。 それ以外の場合は、すべての最大位置が内側になります。$S_i$。 
5. 補数クエリが返された場合$M$、 セット$P_i = M$。 それ以外の場合は設定$P_i = M_2$。 
6. 配列全体を出力する$P$。 

### なぜ効果があるのか

 構造全体は単一の不変式に依存します。すべてのクエリ結果は、少なくとも 1 つのインデックスに値があるかどうかによってのみ決まります。$M$クエリされたセットに含まれています。 このようなインデックスを含むセットは次の値を返します。$M$; そのようなインデックスをすべて除いた任意のセットが返されます$M_2$。 すべての決定は完全な最大セットの有無を検出することに帰着するため、1 つの代表的な最大位置を超えて個々の値を再構成する必要はありません。 これにより、最大値が複数回発生した場合でも正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def query(indices):
    print("?", len(indices), *indices)
    sys.stdout.flush()
    res = int(input())
    if res == -1:
        sys.exit(0)
    return res

def solve():
    n, k = map(int, input().split())
    S = []
    for _ in range(k):
        tmp = list(map(int, input().split()))
        S.append(tmp[1:])

    # Step 1: global maximum
    all_idx = list(range(1, n + 1))
    M = query(all_idx)

    # Step 2: find one position of maximum via binary search
    lo, hi = 1, n
    pos = 1
    while lo <= hi:
        mid = (lo + hi) // 2
        res = query(list(range(lo, mid + 1)))
        if res == M:
            pos = lo
            hi = mid - 1
        else:
            lo = mid + 1

    # Step 3: second maximum
    rest = [i for i in range(1, n + 1) if i != pos]
    M2 = query(rest)

    # Step 4: answer each S_i
    ans = []
    for si in S:
        comp = [i for i in range(1, n + 1) if i not in set(si)]
        res = query(comp)
        if res == M:
            ans.append(M)
        else:
            ans.append(M2)

    print("!", *ans)
    sys.stdout.flush()

    verdict = input().strip()
    if verdict != "Correct":
        sys.exit(0)

if __name__ == "__main__":
    solve()
```サブセット定義はテスト全体で固定されているため、実装はすべてのサブセット定義を読み取ることから始まります。 次に、全範囲クエリを 1 つ発行して、グローバル最大値を決定します。 二分探索フェーズでは、最大値が半分の間隔内にまだ現れるかどうかを繰り返しチェックすることで、この最大値を達成する単一のインデックスを絞り込みます。 

1 つの最大位置を特定した後、コードはそのインデックスを除外して 2 番目の最大位置を計算します。 これが機能するのは、最大値を 1 つ削除しても、その最大値が 1 つだけである場合を除き、すべての最大値を削除できないためです。 

最後に、コードはサブセットごとにその補数を構築し、それをクエリします。 結果がグローバル最大値と一致する場合、サブセットはすべての最大値位置を完全にはカバーしていません。 それ以外の場合は実際にそうなり、答えは 2 番目の最大値まで下がります。 

主な微妙な点は、ループ内のセット メンバーシップ チェックが高価であるため、実際の対話型設定で厳密な効率を実現するには、サブセットをセットに変換するか、ブール マスクを事前計算する必要があることです。

## 特殊なケース

 主なエッジケースは、最大値が複数回出現する場合です。 一意性を誤って仮定した場合、バイナリ検索では出現箇所が 1 つ見つかりますが、最大位置を 1 つ削除してもクエリ結果は減らないため、サブセットの評価が正しくなくなります。 

もう 1 つのエッジ ケースは、サブセットに 1 つの最大インデックスを除くすべてが含まれる場合です。 この場合、補数は依然として同じ最大値を返し、すべての最大位置を完全にカバーする場合にのみ結果が変わります。 このアルゴリズムは、「最大インデックスが含まれているか」を決してチェックせず、補数が依然としてグローバル最大値を返すかどうかのみをチェックするため、これを正しく処理します。
