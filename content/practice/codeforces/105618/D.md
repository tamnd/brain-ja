 ## 解決策
 # 問題の理解

 入力は、シークレット サンタの割り当てを順列として記述します。 子供`i`現在子供にプレゼントをあげています`p[i]`。 一部の子供たちは悪いとマークされ、発表後に課題を修正する必要があります。 良い子は別の良い子にだけ与えなければなりませんし、悪い子は別の悪い子にだけ与えなければなりません。 最終的な割り当ては依然として有効なシークレット サンタの順列である必要があります。つまり、全員が 1 つのプレゼントを受け取り、誰も自分にプレゼントするものではありません。 

すべての有効な修復のうち、変更する必要がある元のペアはできる限り少なくする必要があります。 同じタイプの子を既に接続しているすべてのペアが有効であるため、最適解ではそのようなすべてのペアが保持され、良好なグループと不良グループの間で交差するペアのみが変更されます。 

すべてのテスト ケースにおける子の数は最大で`10^5`。 これにより、置換を繰り返し検索したり、多くのペアを比較したり、線形以上の複雑さのグラフ アルゴリズムを実行したりするソリューションは除外されます。 構造は順列から来ており、すべての子には 1 つの入力エッジと 1 つの出力エッジが正確に存在するため、テスト ケースごとの線形スキャンで十分です。 

厄介なケースは、配置転換後の自分への贈り物に起因します。 不注意な解決策は、新しい受取人を必要とする悪い子供たちと自由になった悪い子供たちを単純に一致させる可能性がありますが、これにより、子供が自分自身のプレゼントを受け取ることになる可能性があります。 

例えば：```
1
4
3 4 1 2
2
1 2
```悪い子たちは、`1`そして`2`。 現在の任務は`1 -> 3`、`3 -> 1`、`2 -> 4`、`4 -> 2`。 現在、悪い子は両方とも良い子に寄付をしているため、どちらも新しい悪い受け取り手が必要です。 それらを同じ順序で割り当てると、次のようになります。`1 -> 1`そして`2 -> 2`、これは無効です。 循環シフトは次のようにしてこれを修正します。`1 -> 2`そして`2 -> 1`。 

もう 1 つのエッジ ケースは、グループ内で再割り当てが必要な子が 1 人だけである場合です。 例えば：```
1
4
2 1 4 3
2
1 3
```ここで悪い子が`1`良い子にあげる`2`、良い子でありながら`2`悪い子にあげる`1`。 2 つの間違ったエッジは、同じ循環再割り当てロジックを通じて交換する必要があります。 影響を受けるすべてのグループに少なくとも 2 つの要素があると想定し、やみくもにローテーションするソリューションは、この状況では失敗する可能性があります。 

# アプローチ

 直接的なアプローチは、受信者のタイプが間違っているすべての子供を調べ、同じタイプの適切な受信者を見つけて、すべての制約が満たされるまで割り当てを繰り返し交換することです。 クロスタイプのエッジのみが無効であるため、この考えは正しいです。 ただし、残りの子を検索して実装すると、簡単に二次関数になる可能性があります。 と`n = 100000`、チェックの最悪のケース`O(n)`それぞれの候補者`O(n)`悪いエッジは約`10^10`限界をはるかに超えた操作。 

重要な観察は、元の割り当てがすでに順列になっているということです。 変更が必要なすべての子には、同じタイプの欠落している受信者が 1 つだけあります。 このようなすべての送信者とすべての受信者を、良い子と悪い子に分けて収集できます。 残りの唯一のタスクは、セルフギフトを作成せずに、2 つの同じサイズのセットをペアにすることです。 

循環シフトはこれを解決します。 送信者が配列に配置され、受信者が別の配列に配置されている場合、送信者の割り当て`i`受信者へ`(i + 1) mod k`すべての受信者を元の位置から遠ざけます。 いずれにしてもこれらすべてのエッジは変更する必要があるため、これにより変更の数が保存されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 順列を読み、すべての悪い子にマークを付けます。 すべての有効なエッジは変更されないため、元の割り当てを保持します。 
2. すべての子をスキャンし、無効なエッジを見つけます。 悪い子が良い子を指している場合は、悪い側の送信者リストに属します。 悪い子を指す良い子は、善側の送信者リストに属します。 
3. スキャン中に、各タイプのどの子供が受け取ったギフトを紛失したかも見つけます。 すべての子供について、誰が自分を指さしているかを数えてください。 良い前任者を持つ悪い子は無料で悪い受信者であり、悪い前任者を持つ良い子は無料で良い受信者です。 
4. 不正な送信者と空きの不正な受信者については、循環シフトを使用して割り当てます。 良い子には同じことを独立して行います。 インデックスからインデックスへの直接割り当てでは、子供が独自のギフトを受け取る可能性があるため、この変更が必要です。 
5. 修復された順列を出力します。 

これが機能する理由: 変更されていないエッジはすべて、同じタイプの 2 つの子をすでに接続しているため、それを維持してもルールに違反することはありません。 変更されたすべての送信者は、正しい種類の受信者を 1 つだけ受信し、解放されたすべての受信者は 1 回だけ使用されます。 巡回シフトにより、送信者は自分自身を受信できなくなるため、最終的なマッピングは自己ループのない順列のままになります。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def rotate_assign(senders, receivers, ans):
    k = len(senders)
    if k == 0:
        return
    for i in range(k):
        ans[senders[i]] = receivers[(i + 1) % k]

    out = []

    for _ in range(t):

        p = [int(x) - 1 for x in input().split()]

            bad[x - 1] = True

        for x in p:
            indeg[x] += 1

        bad_senders = []
        good_senders = []
        bad_receivers = []
        good_receivers = []

        for i in range(n):
            if bad[i] and not bad[p[i]]:
                bad_senders.append(i)
            elif not bad[i] and bad[p[i]]:
                good_senders.append(i)

        for i in range(n):
            if indeg[i] == 1:
                continue

        for i in range(n):
            # In a permutation every node has one incoming edge.
            # Find the type of the incoming sender.
            pass

        inv = [0] * n
        for i, x in enumerate(p):
            inv[x] = i

        for i in range(n):
            if bad[i] and not bad[inv[i]]:
                bad_receivers.append(i)
            elif not bad[i] and bad[inv[i]]:
                good_receivers.append(i)

        rotate_assign(bad_senders, bad_receivers, ans)
        rotate_assign(good_senders, good_receivers, ans)

```コードは最初に逆順列を構築します。 これは、どの子供が特定の受取人にプレゼントを贈ったかを見つける最も簡単な方法です。 割り当ては順列であるため、すべての受信者は入力エッジを 1 つだけ持ちます。 

2 つの送信者リストには、現在のエッジが良好または不良の制限に違反する子が正確に含まれています。 レシーバー リストには、無効なエッジが削除された後に使用可能になる子が含まれます。 一方のグループのすべての無効なエッジがもう一方のグループに入るため、それらのサイズは一致します。 

の`rotate_assign`関数は巡回再割り当てを実行します。 1 つの位置のシフトは重要な詳細です。 これがないと、送信者と受信者がたまたま同じ子である場合にペアになる可能性があります。 

このソリューションでは、子の数に比例したサイズの配列のみが保存されます。 Python の整数は、ここではすべてのインデックスに対して十分な大きさであるため、特別な処理は必要ありません。 

# 実用的な例

 最初のサンプルの場合:```
n = 6
p = [3, 4, 2, 1, 6, 5]
bad = {3, 4, 2, 5}
```ゼロベースのインデックスを使用すると、重要な状態は次のようになります。 

| ステップ | 悪い送信者 | 良い送信者 | 受信機が悪い | 良い受信機 |
 | --- | --- | --- | --- | --- |
 | エッジをスキャンした後 | 2、4 | 0、3 | 1、4 | 0、3 |
 | 回転後 | 2 -> 4、4 -> 2 | 0 -> 3、3 -> 0 | 中古 | 中古 |

 最後の割り当てでは、すでに有効なペアがすべて保持され、交差するエッジのみが変更されます。 ローテーションにより、自分自身への贈り物が回避されます。 

より小規模な構築ケースの場合:```
1
4

2

```トレースは次のとおりです。 

| ステップ | 悪い送信者 | 受信機が悪い | 新しい課題 |
 | --- | --- | --- | --- |
 | 初期スキャン | 1、2 | 1、2 | なし |
 | 循環シフト | 1、2 | 1、2 | 1 -> 2、2 -> 1 |

 この例は、直接一致の主な危険性を示しています。 アルゴリズムによって順序が変更されるため、子供が自分のギフトを受け取ることはありません。

import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().split()
    sys.stdin = old

    it = iter(data)
    t = int(next(it))
    ans_out = []

    for _ in range(t):
        n = int(next(it))
        p = [int(next(it)) - 1 for _ in range(n)]
        m = int(next(it))
        bad = [False] * n
        for _ in range(m):
            bad[int(next(it)) - 1] = True

        inv = [0] * n
        for i, x in enumerate(p):
            inv[x] = i

        ans = p[:]
        bs, gs, br, gr = [], [], [], []

        for i in range(n):
            if bad[i] and not bad[p[i]]:
                bs.append(i)
            elif not bad[i] and bad[p[i]]:
                gs.append(i)

        for i in range(n):
            if bad[i] and not bad[inv[i]]:
                br.append(i)
            elif not bad[i] and bad[inv[i]]:
                gr.append(i)

        for a, b in ((bs, br), (gs, gr)):
            for i in range(len(a)):
                ans[a[i]] = b[(i + 1) % len(a)]

        ans_out.append(" ".join(str(x + 1) for x in ans))

    return "\n".join(ans_out)

 # エッジケース

 最初のエッジケースの場合:```
1
4
3 4 1 2
2
1 2
```子供たち`1`そして`2`悪いです。 現在はどちらも良い子にプレゼントを贈っているため、悪い送り主として回収されています。 不良グループの中で新たな贈り物を必要としている子供たちも、`1`そして`2`。 直接割り当ては自己ギフトを作成するため失敗します。 循環代入により生成されるのは、`1 -> 2`そして`2 -> 1`、これは有効です。 

2 番目のエッジケースの場合:```
1
4
2 1 4 3
2
1 3
```子供`1`悪いので今は良い子にあげています`2`。 子供`3`悪いので今は良い子にあげています`4`。 逆に、良いグループでも同じ状況が起こります。 このアルゴリズムは 2 つのグループを分離し、影響を受ける受信者をローテーションし、すでに有効なエッジをすべてそのまま残します。 結果は、型の制限と置換規則の両方を満たします。
