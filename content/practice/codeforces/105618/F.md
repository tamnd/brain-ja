 ## 解決策
 ## 問題の理解

 次の重み付き無向グラフが与えられます。$n$部屋と$m$双方向トンネル。 各トンネルには交通費がかかります。 私たちはいつも部屋からスタートします$1$、そしてすべての部屋に$v$それを達成するためには最小限のコストが必要です。 

ツイストは各部屋に関連付けられた単一の特殊能力です$a$: 現在部屋にいる場合$a$、から新しいトンネルを即座に作成できます。$a$他の部屋へ$v$費用がかかる$c_a$。 この人工トンネルはどのルートでも1回のみ使用できます。 これは「テレポート エッジ」のように動作し、そのコストはアクティブ化される部屋にのみ依存します。 

重要なのは、この能力はグローバルではないということです。 目的地ごとに$v$、私たちはこのテレポートを、からのパスに沿ったどこかで一度だけ使用することを想像することができます。$1$に$v$ただし、目的地が異なると、異なるテレポートのアクティブ化が選択される場合があります。 

したがって、固定ターゲットの場合$v$、有効なルートは、元のグラフ内の通常の最短パス、またはある時点でノードを訪れるパスのいずれかです。$a$、次に直接ジャンプします$v$費用の支払い$c_a$。 

制約により、最大で$2 \cdot 10^5$すべてのテスト ケースにわたる頂点とエッジの合計。$O((n+m)\log n)$または線形解法。 すべてのノードの最短パスを最初から再計算しようとするアイデアは、ノードごとに 1 つのダイクストラでも爆発的に増加してしまうため、遅すぎます。$O(nm \log n)$。 

グラフが切断されている場合、微妙なエッジケースが現れます。 テレポートがないと、一部のノードに到達できません。 テレポートを使用すると、到達可能なノードがある場合でも到達可能になる可能性があります。$a$有限を提供します$c_a$から直接ジャンプできるため、$a$任意の頂点に。 

もう 1 つのケースは、テレポートがどこでも通常のパスよりも悪い場合です。 その場合、それは完全に無視されなければならず、答えは標準的な最短経路に帰着します。 

## アプローチ

 この問題を直接考える方法は、以下から最短経路を計算することです。$1$ダイクストラのアルゴリズムを使用して、考えられるテレポートの使用法をすべて個別に試してみます。 固定ペアの場合$(a, v)$、から行くパスを考えることができます。$1$に$a$、支払います$c_a$、で終了します$v$。 これは、中間の選択肢をすべてチェックすることを示唆しています$a$あらゆる人にとって$v$、それは次のことにつながります$O(n^2)$最短経路の計算に基づく組み合わせ。 グラフの端を無視しても、これは大きくなりすぎます。 

重要な簡素化は、テレポートの構造を分離することです。 どこかのノードに到着したら$a$、テレポートは目的地に依存しなくなりました。 これにより、常に最終ノードに直接ジャンプできます。 これは、「テレポート フェーズ」全体が単一のグローバル候補値に集約されることを意味します。$$\min_a (\text{dist}[a] + c_a)$$どこ$\text{dist}[a]$～からの最短距離です$1$に$a$元のグラフでは。 

この値は、1 つのテレポートを使用して任意のノードに到達するための最も安価な方法を表します。 テレポートは目的地に直接着陸するため、この候補はすべてのノードに均一に適用されます。 

したがって、問題はノードからの単一ソースの最短パスを計算することに帰着します。$1$次に、すべてのノードにわたる 1 つのグローバル最小値を計算し、最後にその値を各ノードと比較します。$\text{dist}[v]$。 

ブルートフォースはテレポートの宛先を個別に推論しようとするため失敗します。 正しい観察は、テレポートの選択はターゲットではなくアクティベーション ノードにのみ依存するため、その効果は 1 つのスカラーに要約できるということです。

 ## アルゴリズムのチュートリアル

 ソリューションは 2 つの独立したフェーズで構築されます。 

1. ノードからダイクストラを実行する$1$元のグラフに基づいて計算します$\text{dist}[v]$すべての頂点に対して。 これにより、テレポートをまったく使用せずに最高のコストが得られます。 これが有効な理由は、元のすべてのトンネルが標準の重み付きエッジであるため、ダイクストラは特別な操作の前に最適な動きを完全に捕捉するためです。 
2. ダイクストラ中またはダイクストラ後のノードの処理中に、値を計算します。$\text{dist}[a] + c_a$すべてのノードに対して$a$。 すべてのノードにわたってこの式の最小値を維持します。 これは、可能な限り最高の「テレポート起動コスト」を表します。 
3. すべてのノードについて$v$、最終的な答えは次のように計算されます。$$\min(\text{dist}[v], \text{bestTeleport})$$なぜなら、テレポートを一度も使用しないか、一度使用するとすぐに旅が終了してしまうかのどちらかだからです。$v$。 
4. すべてのノードに対してこれらの値を出力します。 

構造上の重要な点は、テレポートは新しい層状グラフの走査を作成しないことです。 単一のグローバル ショートカット オプションのみが導入されます。 

### なぜ効果があるのか

 からの有効なパス$1$に$v$テレポートを使用する場合は、まず通常のエッジに従う必要があります。$1$どこかのノードに$a$、テレポートを適用して停止します。 このようなパスのコストは正確に$\text{dist}[a] + c_a$。 すべての場所に到達するための最短の方法はすでに計算されているので、$a$、プレフィックスをそれより悪いものに置き換えても、結果は改善されません。 したがって、すべてのテレポートベースのパスは、いずれかの値によって表されます。$\text{dist}[a] + c_a$、そして全体の最小値を取る$a$あらゆる可能性を捉えます。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

INF = 10**30

def dijkstra(n, adj):
    dist = [INF] * (n + 1)
    dist[1] = 0
    pq = [(0, 1)]

    while pq:
        d, u = heapq.heappop(pq)
        if d != dist[u]:
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    c = [0] + list(map(int, input().split()))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))

    dist = dijkstra(n, adj)

    best_teleport = INF
    for i in range(1, n + 1):
        if dist[i] < INF:
            best_teleport = min(best_teleport, dist[i] + c[i])

    res = []
    for v in range(1, n + 1):
        if v == 1:
            res.append("0")
        else:
            ans = min(dist[v], best_teleport)
            res.append(str(ans))

    print(" ".join(res))
```コードは最初にグラフを構築し、ノードからの最短パスを計算します。$1$。 ヒープベースのダイクストラにより、最大で大きなエッジの重みを正しく処理できるようになります。$10^9$。 

2 番目のパスでは、すべてのノードを 1 回スキャンして、最適なテレポート アンカーを計算します。 よくある間違いは、ディクストラ緩和中にテレポートを適用しようとすることです。 テレポートは宛先の状態に依存しないため、これは不要です。 

最後に、それぞれの答えは、直接の最短パスとグローバル テレポート ショートカットの単純な比較です。

import sys, io
import heapq

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    INF = 10**30

    def dijkstra(n, adj):
        dist = [INF] * (n + 1)
        dist[1] = 0
        pq = [(0, 1)]
        while pq:
            d, u = heapq.heappop(pq)
            if d != dist[u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        return dist

    t = int(input())
    out_lines = []
    for _ in range(t):
        n, m = map(int, input().split())
        c = [0] + list(map(int, input().split()))
        adj = [[] for _ in range(n + 1)]
        for _ in range(m):
            u, v, w = map(int, input().split())
            adj[u].append((v, w))
            adj[v].append((u, w))

        dist = dijkstra(n, adj)

        best = INF
        for i in range(1, n + 1):
            if dist[i] < INF:
                best = min(best, dist[i] + c[i])

            if v == 1:
                res.append("0")
            else:
                res.append(str(min(dist[v], best)))
        out_lines.append(" ".join(res))

    return "\n".join(out_lines)

## 特殊なケース

 切断されたグラフは、テレポートの主な役割を強調しています。テレポートは、到達不可能な距離を有限のグローバル最小値に置き換えます。 このような場合、ダイクストラは多くのノードに対して無限大を生成しますが、テレポート集約は到達可能なノードのみに依存するため、依然として使用可能な値を生成します。$a$。 

いつすべて$c_a$が非常に大きい場合、アルゴリズムは自然に標準の最短パスに戻ります。$\min(\text{dist}[v], \text{bestTeleport})$テレポート用語を選択することはありません。 

単一ノードのグラフは簡単ですが、実装が正確であるために重要です: ノード$1$常に出力する必要があります$0$たとえテレポート計算がゼロ以外の値を示唆したとしてもです。
