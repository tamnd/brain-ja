 しましょう$a_1 \ge \cdots \ge a_n \ge 0$そして$a'_1 \ge \cdots \ge a'_n \ge 0$のパーティションになる$n$、長さに合わせてゼロが埋め込まれます$n$。 それらの共役は次のように定義されます。$$b_k = |\{ i \mid a_i \ge k \}|, \qquad b'_k = |\{ i \mid a'_i \ge k \}|.$$目的は、辞書編集上の順序を比較することです。$b_1 b_2 \cdots b_n$そして$b'_1 b'_2 \cdots b'_n$辞書編集上の順序を逆にしたもの$a_n \cdots a_1$そして$a'_n \cdots a'_1$。 

させて$r_i = a_{n-i+1}$そして$r'_i = a'_{n-i+1}$逆の順序になります。 の辞書編集的比較$r$そして$r'$最小のインデックスによって決定されます$i$そのような$r_i \ne r'_i$、同等に最大のインデックス$j = n-i+1$そのような$a_j \ne a'_j$。 

させて$j$で最大のインデックスになる$a_j \ne a'_j$。 それから$a_{j+1} = a'_{j+1}, \ldots, a_n = a'_n = 0$、そして反転されたシーケンスは最初に位置が異なります。$i = n-j+1$。 

仮定する$a_j < a'_j$; 逆の場合は対称です。 それでは皆さんに$k > a'_j$、 両方$a_j$そして$a'_j$は$< k$、つまり行は$1,\ldots,j$に貢献しない$b_k$または$b'_k$。 のために$k \le a_j$、両方の行$j$貢献との違い$b_k$そして$b'_k$完全に指数によって決まります$1,\ldots,j-1$、 どこ$a$そして$a'$一致する。 したがって、$b_k = b'_k$みんなのために$k \le a_j$。 

で$k = a_j + 1$、 行$j$に貢献する$b'_k$しかしそうではありません$b_k$、 以来$a_j < a'_j$。 したがって$b'_{a_j+1} = b_{a_j+1} + 1$、 それで$b < b'$辞書順に。 

これを逆のシーケンスに関連付けます。 以来$j$は差のある最大のインデックスであり、最初の差です。$r$そして$r'$位置で発生します$n-j+1$、 どこ$r_{n-j+1} = a_j$そして$r'_{n-j+1} = a'_j$。 したがって、$r < r'$辞書順に。 

これは、次のことを示しています。$a_n \cdots a_1 < a'_n \cdots a'_1$、 それから$b_1 \cdots b_n < b'_1 \cdots b'_n$。 

逆に、次のように仮定します。$b < b'$そしてさせてください$k$最小のインデックスになる$b_k \ne b'_k$。 それから$b_1 = b'_1, \ldots, b_{k-1} = b'_{k-1}$ですので、皆さんにとって$i$と$a_i \ge k-1$、そのようなインデックスのカウントは一致します。$a$そして$a'$。 行構造における最初の不一致は、最も高い行インデックスで発生する必要があります。$j$のいずれかが$a_j, a'_j$閾値を越える$k$。 これはつまり、$a_j < a'_j$そして、上位のインデックス付き行はすべて等しいことを確認します。 

したがって$j$はまさに最大のインデックスです。$a_j \ne a'_j$、逆のシーケンスの最初の違いは位置で発生します。$n-j+1$と$a_j < a'_j$。 したがって、$a_n \cdots a_1 < a'_n \cdots a'_1$。 

どちらの意味も成り立つため、2 つの辞書編集上の比較は同等です。
