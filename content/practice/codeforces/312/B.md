 ## 解決策
 ## 問題の理解

 2 人の射手が交互に標的を撃ちます。 SmallR が先に撃ち、確率で命中する$a/b$各ショットで。 ザノスが確率で命中する$c/d$各ショットで。 誰かが試合の最初のヒットを打つとすぐにゲームは終了し、そのプレイヤーが勝ちます。 

入力は 4 つの整数で構成されます$a, b, c, d$、次の 2 つのヒット確率を定義します。$$p=\frac{a}{b}, \qquad q=\frac{c}{d}$$SmallR が最終的に勝つ確率を計算する必要があります。 

制約はわずかです。 入力には 4 つの整数のみが含まれており、答えは 1 つの確率です。 大規模なデータ構造、グラフ、繰り返されるクエリはありません。 この課題は完全に数学的なものです。 閉じた形式の式を導出するソリューションはすべて定数時間で実行されます。 

主な困難は、ゲームが原則として永遠に継続できることを認識することです。 単純なシミュレーションでは、無限に多くのラウンドがあるため、考えられるすべてのシーケンスを列挙することはできません。 代わりに、確率は無限級数として表現されるか、漸化式によって解決される必要があります。 

よくある間違いは、最初のラウンドだけを考慮することです。 例えば：```
1 2 1 2
```SmallR が確率で即ヒット$1/2$、しかし、彼もミスする可能性があり、Zanoes もミスする可能性があり、その後、SmallR には別のチャンスが与えられます。 正しい答えは、$2/3$、 ない$1/2$。 

もう 1 つの微妙なケースは、両方のプレイヤーのヒット確率が非常に小さい場合に発生します。```
1 1000 1 1000
```試合は何ラウンドも続くかもしれませんが、合計の勝率は依然として明確に定義されています。 固定ラウンド数の後にプロセスを切り捨てるアプローチは、顕著な確率量を失う危険があります。 

エラーの 3 番目の原因は、SmallR が最初に射撃することを忘れていることです。 考慮する：```
1 1 1 1
```両選手ともミスはしない。 SmallR は Zanoes より先にシュートを放つので、確率で彼が勝ちます$1$、 ない$1/2$。 

## アプローチ

 最も直接的なアプローチは、SmallR が勝つことができるすべての方法を列挙することです。 

彼は最初のショットですぐに勝つことができます。 両方のプレイヤーが 1 回失敗し、2 回目の試技でヒットした後に勝つこともできます。 両方のプレイヤーが 2 回失敗した後、3 回目の試行でヒットするなどして勝つことができます。 

これにより、無限和が生成されます。$$p + (1-p)(1-q)p + ((1-p)(1-q))^2 p + \cdots$$すべての用語は、SmallR が最終的に最初のヒットに到達するまでの、完全に失敗した特定のラウンド数に対応します。 

ブルートフォース バージョンでは、文字通りこのシリーズの多くの用語が評価されます。 各項は独立した勝利シナリオを表すため、これは数学的に正しいです。 問題は、系列が無限であることです。 後を切り捨てる$k$項によって近似誤差が生じるため、十分に大きな値を選択する$k$は不要です。 

重要な観察は、この系列が幾何学的であるということです。 

させて$$r=(1-p)(1-q).$$すると確率は次のようになります$$p + rp + r^2p + r^3p + \cdots.$$まさに幾何級数ですね$$p \sum_{i=0}^{\infty} r^i.$$以来$0 \le r < 1$、その合計は$$\frac{p}{1-r}.$$元に戻す:$$\boxed{ \frac{p}{1-(1-p)(1-q)} }$$この閉じた形式の式では、定数時間で答えが得られます。

 ## アルゴリズムのチュートリアル

 1. 4 つの整数を読み取ります$a, b, c, d$。 
2. SmallR のヒット確率を計算します。$$p=\frac{a}{b}.$$3. ザノエスの命中確率を計算します。$$q=\frac{c}{d}.$$4. ラウンド全体が失敗する確率、つまり両方のプレイヤーが失敗する確率を計算します。$$r=(1-p)(1-q).$$このようなラウンドの後、ゲームは最初とまったく同じ状態に戻ります。 
5. 等比級数の式を使用します。$$\text{answer} = \frac{p}{1-r}.$$6. 結果を十分な精度で印刷します。 

### なぜ効果があるのか

 しましょう$W$SmallR がラウンドの開始から勝つ確率を示します。 

SmallR は確率ですぐに勝つことができます$p$。 

SmallR がミスし、Zanoes もミスした場合、これは確率で起こります$(1-p)(1-q)$、ゲームは元の状態に戻ります。 その時点から、SmalleR が最終的に勝つ確率は再び$W$。 

したがって$$W=p+(1-p)(1-q)W.$$を解決する$W$:$$W\bigl(1-(1-p)(1-q)\bigr)=p,$$

$$W= \frac{p}{1-(1-p)(1-q)}.$$アルゴリズムはこの数量を正確に計算するため、正しい当選確率を返す必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, c, d = map(int, input().split())

p = a / b
q = c / d

ans = p / (1.0 - (1.0 - p) * (1.0 - q))

print(f"{ans:.12f}")
```プログラムはまず、分数を浮動小数点の確率に変換します。 次に、両方のプレーヤーがラウンド全体でミスする確率を計算します。 

式$$\frac{p}{1-(1-p)(1-q)}$$直接適用されます。 Python の倍精度浮動小数点は、必要な機能には十分です。$10^{-6}$正確さ。 

小数点以下 12 桁を印刷すると、エラー許容範囲を十分に満たすことができます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    a, b, c, d = map(int, input().split())
    p = a / b
    q = c / d
    ans = p / (1.0 - (1.0 - p) * (1.0 - q))

    return f"{ans:.12f}"

# provided sample
assert run("1 2 1 2\n") == "0.666666666667"

# SmallR always hits
assert run("1 1 1 2\n") == "1.000000000000"

# Zanoes always hits if he gets a turn
assert run("1 2 1 1\n") == "0.500000000000"

# Equal small probabilities
out = float(run("1 1000 1 1000\n"))
expected = (1 / 1000) / (1 - (999 / 1000) * (999 / 1000))
assert abs(out - expected) < 1e-12

# Both always hit
assert run("1 1 1 1\n") == "1.000000000000"

 ## 特殊なケース

 ### SmallR は常にヒットします

 入力:```
1 1 1 2
```我々は持っています$p=1$そして$q=1/2$。 

アルゴリズムは計算します$$r=(1-1)\left(1-\frac12\right)=0,$$

$$\text{answer}=\frac{1}{1-0}=1.$$ザノエスが撃たれる前に小さな小屋があるので、確率は$1$は正しいです。 

### 両方のプレイヤーのヒット確率はわずかです

 入力:```
1 1000 1 1000
```ラウンドが失敗する確率は、$$r=\frac{999}{1000}\cdot\frac{999}{1000}=0.998001.$$ゲームは多くのラウンドに及ぶことがよくありますが、公式はすべての可能性を一度に合計します。$$\text{answer} = \frac{0.001}{1-0.998001} \approx 0.500250125.$$切り捨ては必要ないため、確率質量が失われることはありません。 

### どちらも必ずヒットします

 入力:```
1 1 1 1
```アルゴリズムが与えるのは、$$r=0, \qquad \text{answer}=1.$$不用意な解決策は対称性を前提として、次のような結果を招く可能性があります。$1/2$。 この公式には、SmallR が最初に射撃し、すぐに勝つという事実が正しく組み込まれています。
