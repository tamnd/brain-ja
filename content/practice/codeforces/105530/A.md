 ## アルゴリズムのチュートリアル

 現在の順列配列と、各値の位置を追跡する逆位置配列の 2 つの構造を維持します。 これにより、一定時間内に任意の値を見つけることができます。 

値がどこにあるかも追跡します$1$すべての操作がそこを通過する必要があるため、現在は座っています。 

### ステップ

3. もし$i$すでに所定の位置にいます$i$、何もせずに次の値に進みます。 

これにより、不必要なスワップが回避され、すでに正しい配置が維持されます。 
4. それ以外の場合は、値の場所を見つけます$i$現在は、たとえば の位置にあります$p$。 これからそれを所定の位置に配置したいと思います$i$, ただし、直接交換することはできません。

6. 次に、位置の値を交換します。$1$現在の位置の値で$i$。

7. 各交換後に、影響を受けるすべての値の位置を更新します。 すべての位置が固定されるまで続けます。 

重要なアイデアは、置き忘れられた値はすべて位置を介してルーティングできるということです。$1$、そのような修正ごとに最大 2 つのスワップが必要です。 

### なぜ効果があるのか

 このアルゴリズムは、これまでに処理されたすべての値が正しいインデックスで固定されているという不変条件を維持します。$1$は常に現在の場所で正しく追跡されます。 各操作は一定数の位置にのみ影響し、位置を一時的に通過する場合を除いて、すでに固定された値を乱すことはありません。$1$、すぐに修正されます。 間違った要素はすべて一定時間内にターゲット位置に直接移動されるため、正しく配置された後に要素が再訪されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))

    pos = [0] * (n + 1)
    for i in range(n):
        pos[a[i]] = i

    ops = []

    def swap(i, j):
        a[i], a[j] = a[j], a[i]
        pos[a[i]] = i
        pos[a[j]] = j
        ops.append((i + 1, j + 1))

    for i in range(1, n + 1):
        if a[i - 1] == i:
            continue

        p = pos[i]

        if p != pos[1]:
            swap(p, pos[1])

        swap(i - 1, pos[1])

    print(len(ops))
    for x, y in ops:
        print(x, y)

if __name__ == "__main__":
    solve()
```この実装では、値からインデックスへの直接マッピングが維持されるため、配置中のスキャンが回避されます。 各スワップはログに記録され、配列と逆位置配列の両方に即座に反映され、将来の操作の正確性が保証されます。 

微妙な点は、常に位置を再計算することです。`pos`、そのため、古いインデックスに依存することはありません。 これは重要な要素です。$1$頻繁に移動し、動的バッファとして機能します。
