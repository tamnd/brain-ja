 ## 解決策
 ## 問題の理解

 数値を固定することによって生成されるすべての剰余を調べます$n$そしてそれをすべての整数で割ります$i$から$1$に$n$。 これにより、次の形式の値のセットが得られます。$n \bmod i$。 除数を選択するたびに、以下の剰余が生成されます。$0$そして$i - 1$したがって、すべての約数にわたって、構造化されているが任意ではない整数のセットを収集します。 

タスクは、これらの剰余の中で決して出現しない最小の非負の整数を決定することです。 言い換えれば、セットの MEX を計算しています。$\{ n \bmod i \mid 1 \le i \le n \}$。 

制約構造は非常に厳密です。 入力は単一の整数であるため、次の値までの任意の解が得られます。$O(n)$あるいは$O(\sqrt{n})$は自明のことながら十分に高速であり、本当の課題は計算ではなく、剰余のセット内のパターンを認識することです。 

単純なアプローチでは、すべての値を明示的に計算します。$n \bmod i$、それらをセットに挿入し、最初の欠落している整数が見つかるまでゼロから上方向にスキャンします。 これは機械的に機能しますが、構造が隠蔽され、実際に到達可能な値についての直感を誤解させる可能性があります。 

大きな値が剰余として発生する可能性があるかどうかを推論するときに、微妙な落とし穴が発生します。 たとえば、値が次の値に近いと誤って仮定する可能性があります。$n$弾性率が変化するため表示されることがあります。$i$、しかし実際には、すべての剰余は厳密にその除数よりも小さいため、グローバルな意味で可能な最大値が制限されます。 

たとえば、次のようなとき$n = 5$、セットは次のとおりです。$5 \bmod 1 = 0$、$5 \bmod 2 = 1$、$5 \bmod 3 = 2$、$5 \bmod 4 = 1$、$5 \bmod 5 = 0$、

 それでメキシコは$3$。 

正しい答えは、すべての剰余の正確な分布ではなく、出現が保証されている小さな整数の数にのみ依存することがわかります。 

## アプローチ

 直接的な総当たり戦略により、すべての剰余が計算されます。$n \bmod i$のために$i$から$1$に$n$。 これにより、$n$値を取得し、それらをブール配列に挿入するか、欠落している最小の整数を設定して線形に検索します。 これは、ターゲット セットを徹底的に構築するため、正しいです。 

このアプローチのコストは次のように線形です。$n$、剰余の生成とスキャンの両方に使用されます。 せいぜいそれくらいです$2n$これは一般的な制約には適していますが、構造的な洞察は得られません。 

重要な観察は、剰余のセットの周囲に鋭いしきい値があることです。$\lceil n/2 \rceil$。 このしきい値より小さいすべての整数は、何らかの除数の剰余として現れることができますが、しきい値自体が存在することは決して保証されません。 これにより、ゼロから始まる達成可能な値の連続したプレフィックスが作成され、MEX はまさにこのプレフィックスの外側の最初の値になります。 

このブルートフォースはすべての残基を直接列挙するため機能しますが、到達可能な値が連続区間を形成していることが認識されると、その必要はなくなります。 問題は、この間隔を明示的に構築するのではなく、この間隔の長さを特定することに帰着します。

 ## アルゴリズムのチュートリアル

 最適な解決策は、到達可能な剰余の構造を認識することに基づいています。 

1. コンピューティング$k = \lceil n/2 \rceil$。 この値は、保証された剰余と不可能な剰余を分ける境界として機能します。 
2. 戻る$k$答えとして。 これは、次のように表すことができない最初の整数です。$n \bmod i$誰にとっても$i \le n$。 

このステップが有効である理由は、モジュラー リダクションの動作に由来します。小さい値は、必要な剰余よりわずかに大きい約数を選択することで形成できますが、しきい値以上の値は制約に耐えることができません。$n \bmod i < i$みんなのために$i$。 

### なぜ効果があるのか

 任意の整数の場合$m < \lceil n/2 \rceil$、約数を構築できます$i = n - m$。 この選択により、次のことが保証されます。$n \bmod i = m$、 以来$n = 1 \cdot (n - m) + m$。 条件$i \le n$自動的に保持されるため、$m > 0$暗示する$i < n$、そしてのために$m = 0$、私たちは取ることができます$i = n$。 

これは、以下のすべての値が$\lceil n/2 \rceil$達成可能です。 一方、任意の値$m \ge \lceil n/2 \rceil$除数が必要になります$i \le n - m \le n/2$、しかし、そのような構造では、剰余が等しいことは保証されなくなります。$m$、実際、算術構造により、すべてのより大きな値を連続してカバーすることはできません。 到達可能なセットはプレフィックスを正確に形成します$[0, \lceil n/2 \rceil - 1]$つまり、MEX は$\lceil n/2 \rceil$。

```ソリューション全体は、半分の上限を計算することに帰着します。$n$。 表現$(n + 1) // 2$偶数と奇数の両方のケースをきれいに処理します。 到達可能な構造は列挙ではなく算術推論によって完全に決定されるため、追加のデータ構造やループは必要ありません。 

ここでよくある間違いは、剰余をシミュレートしたり、セットを構築しようとしたりすることですが、これは不必要であり、境界に関する混乱を招く危険があります。 解決策は整数の除算の動作のみに依存します。
