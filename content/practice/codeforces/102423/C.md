 ## 問題の理解

 この問題は、動物ごとに 1 つずつ、一連の石の山を記述します。 動物はいくつかの石から始まります。 その後、各ラウンドで数字が`k`と発表される。 現在のサイズが次の値で割り切れるすべてのパイル`k`得点が得られるため、エマはすぐにそのようなすべての山に石を 1 つ追加します。 追加された石はそこに残ります。つまり、同じ動物を後のラウンドで再度変更することができます。 

課題は、エマが投げなければならない石の合計数を計算することです。 電流で割り切れるすべての山は`k`を増やす必要がある場合、最適な戦略には選択の余地がありません。 強制的な変更をシミュレートするだけで済みますが、すべてを調べずにシミュレートする必要があります。`n`すべてのラウンドに動物がいます。 

入力には最大で次のものが含まれます`10^5`動物と`10^5`ラウンドします。 初期パイル サイズは最大でも`3 * 10^5`、発表されたすべての約数も最大で`3 * 10^5`。 直接`n * m`シミュレーションには必要な場合があります`10^10`これは、5 秒の制限時間でサポートできる範囲をはるかに超えています。 可能な最大のパイル サイズは最大です。`3 * 10^5 + 10^5 = 4 * 10^5`というのは、個々の山はラウンドごとに最大 1 回しか増加できないからです。 この比較的小さな値の範囲が、私たちが利用する構造的特性です。 

微妙なケースは、複数の動物のパイル サイズが同じである場合です。 例えば、```
3 3
2
2
2
2
3
4
```正しい答えは、`9`。 3 つの山はすべて次のようになります。`3`最初のラウンドで、その後全員が`4`2番目では、すべてになります`5`3番目に。 すべての動物を個別に保存するシミュレーションは、ここで 9 つの個別の更新を実行しますが、3 匹の動物は 1 つの頻度で表すことができます。`3`。 

もう 1 つの重要なケースは、山が先に増分されたという理由だけで、後の約数で割り切れる場合です。 例えば、```
1 2
2
2
3
```最初`2`からパイルを変更します`2`に`3`、そしてその後`3`から変更します`3`に`4`。 答えは、`2`。 初期値のみから影響を受けるすべての動物を決定するソリューションでは、2 番目の操作が失敗します。 

3 番目の境界ケースは、発表された値では決して割り切れない山です。 例えば、```
1 2
1
2
3
```答えは、`0`。 値`1`発表された除数が存在するという理由だけで変更されるわけではありません。`2`そして`1`で割り切れない`2`。 「倍数ではない」と「除数未満」を混同すると、間違った更新が行われる可能性があります。

### なぜ効果があるのか

 中心的な不変条件は次のとおりです`cnt[x]`現在のパイルサイズが正確に一致する動物の数です`x`、およびクエリされたすべての約数について`k`、そのセットには占有された値が正確に含まれます`x`満足のいく`x % k == 0`。 

最初は、すべての初期占有値がその約数のセットに挿入されるため、不変式が成り立ちます。 ラウンド中のセットは、`k`動物を変更する必要がある値が正確に含まれています。 移動`cnt[x]`から`x`に`x + 1`これらすべての動物に必要な操作と正確に一致します。 削除中`x`古い除数セットからの挿入`x + 1`新しい除数セットに代入すると、次のラウンドの不変式が復元されます。 したがって、強制石の追加はすべて 1 回だけカウントされ、不必要な追加はカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXV = 400000

def solve():
    n, m = map(int, input().split())

    initial = [int(input()) for _ in range(n)]
    queries = [int(input()) for _ in range(m)]

    queried = [False] * (MAXV + 1)
    for k in queries:
        queried[k] = True

    # divisors[x] contains all divisors >= 2 of x.
    divisors = [[] for _ in range(MAXV + 1)]

    for d in range(2, MAXV + 1):
        for x in range(d, MAXV + 1, d):
            divisors[x].append(d)

    # cnt[x] = number of animals currently having x stones.
    cnt = [0] * (MAXV + 2)

    # Only queried divisors need sets.
    buckets = {}
    for k in set(queries):
        buckets[k] = set()

    for x in initial:
        cnt[x] += 1

    # Build the initial membership structure.
    for x in set(initial):
        if cnt[x] == 0:
            continue
        for d in divisors[x]:
            if queried[d]:
                buckets[d].add(x)

    answer = 0

    for k in queries:
        current = buckets[k]

        # The current k cannot receive new elements while it is being
        # processed, because x % k == 0 implies (x + 1) % k != 0.
        for x in list(current):
            c = cnt[x]
            if c == 0:
                continue

            answer += c

            cnt[x] = 0
            cnt[x + 1] += c

            # x is no longer occupied.
            for d in divisors[x]:
                if d != k and queried[d]:
                    buckets[d].discard(x)

            # x + 1 is now occupied.
            for d in divisors[x + 1]:
                if queried[d]:
                    buckets[d].add(x + 1)

        current.clear()

    print(answer)

if __name__ == "__main__":
    solve()
```周波数配列は、アルゴリズムの値グループ化のアイデアを直接実装したものです。 いつ`cnt[x]`がゼロ以外の場合、これらの動物はすべて現在のラウンドで同じ動作をするため、1 つの遷移がすべての動物を表します。 

の`divisors`sieve は、バケットを維持するために必要な関係を構築します。 たとえば、次の場合`x = 12`、関連するセットには、`2`、`3`、`4`、`6`、 そして`12`。 の約数`x`は、まさに、杭が次の状態にあるときに杭を選択できるクエリ値です。`x`。 

辞書`buckets`までのすべての整数にセットを割り当てる代わりに使用されます。`400000`。 実際にクエリとして表示される値のみを検索可能にする必要があります。 これにより、Python オブジェクトのオーバーヘッドが大幅に節約されます。 

の`list(current)`変換は意図的に行われます。 セットを処理しながら、同時に他のセットのメンバーシップを変更することを推論するのは困難です。 より具体的には、現在のバケットはこのラウンド中に新しい値を取得できません。`x`で割り切れます`k`、 それから`x + 1`で割り切れない`k`。 スナップショットを取得すると、別の値の処理によって生じる突然変異から反復を独立させることもできます。 

答えは Python の整数型で保存されるため、オーバーフローの心配はありません。 理論的な答えは到達できる`n * m`、つまり`10^10`、すでに符号付き 32 ビット整数を超えています。 

上限`MAXV = 400000`最大初期値から得られます`300000`それぞれに最大 1 つの増分を加えます。`100000`ラウンドします。 トランジションで使用されるため、配列には 2 つの余分な位置があります。`x + 1`。
