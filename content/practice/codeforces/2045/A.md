 **タグ:** ブルートフォース、貪欲
 **解決時間:** 1 分 7 秒
 **確認済み:** はい

 ## 解決策
 ## 問題の理解

 私たちは、音節と文字という非常に特殊な概念に基づいて、与えられた大文字の文字列から可能な限り長い単語を構築するように求められます。 アルファベットは、母音 (A、E、I、O、U)、子音 (Y を除くその他すべて)、およびそのいずれかとして機能する特殊文字 Y に分割されます。 また、「NG」という文字列も 1 つの子音としてカウントされます。 音節は子音-母音-子音として厳密に定義されており、単語は 1 つ以上の音節の連続です。 文字を並べ替えたり、好きな文字を削除したりすることはできますが、まだ存在しない文字を追加することはできません。 

入力は最大 5000 文字の単一の文字列です。 文字を削除できるため、文字の順序は問題になりません。問題は、「NG」を 1 つの子音として数えるなど、使用可能な子音と母音の数を数えるということになります。 出力は最長の単語の長さ、または音節を形成できない場合は 0 です。 

素朴なアプローチでは、有効な単語を形成するために文字列の考えられるすべての順列またはサブセットを生成しようとするかもしれませんが、5000 文字ではサブセットの数は天文学的な数になります。 代わりに、音節の構造を利用して最大編成を数える必要があります。 

エッジケースには、母音のみまたは子音のみを含む文字列が含まれます。 たとえば、「AEIOU」には母音が含まれていますが、子音が含まれていないため、音節を形成できず、正しい出力は 0 になります。もう 1 つの注意が必要なケースは、「NG」シーケンスが存在することです。 文字列が「NGNGNGA」の場合、「NG」の子音が 3 つと母音が 1 つあり、長さ 3 の音節は 1 つだけ許可されます。「NG」を 2 つの別々の文字として数え間違えると、結果が過大評価されてしまいます。 Y は音節数を最大化するものに応じて母音または子音のいずれかになる可能性があるため、Y を含む文字列は慎重に扱う必要があります。 

## アプローチ

 ブルートフォースアプローチは、文字列のすべての再配置を試み、長さ 3 のすべての部分文字列が有効な音節であるかどうかを確認することです。 これは理論的には正しいですが、文字の階乗順列があるため、n = 5000 ではまったく実行不可能です。 操作回数は 5000 回を超えます。 実用的な制限をはるかに超えています。 

重要な洞察は、必要なのは母音と子音の数だけであるということです。 各音節はちょうど 1 つの母音と 2 つの子音を消費します。 Y は柔軟性があるため、音節数が最大になるように数えるべきです。 「NG」シーケンスは単一の子音として機能するため、使用される文字 N と G をデクリメントしながら、「NG」のすべての出現を単一の子音カウントに変換する前処理ステップが必要です。 母音と子音の有効な数がわかったら、音節の最大数は単純に母音の数と子音の数の半分の最小値を切り捨てたものになります。 最大単語長は音節数の 3 倍になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | カウントベースの貪欲 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 母音、子音、Y の数を初期化します。 また、「NG」シーケンスも別の子音単位としてカウントします。 文字列を左から右にスキャンします。 「NG」が見つかるたびに、子音カウントを 1 つ増やし、次の文字をスキップします。 それ以外の場合は、文字をチェックします。母音の場合は、母音の数を増やします。 Y の場合は、Y カウントをインクリメントします。 それ以外の場合は、子音の数を増やします。 

2. 最初のパスの後、Y をどのように割り当てるかを決定する必要があります。 Y は母音または子音として機能します。 音節を最大化するには、現在制限要因となっているカテゴリに Y を割り当てます。 総母音を次のようにします`v + y_used_as_vowel`そして子音の合計は`c + y_used_as_consonant`。 音節の数が次のように Y を割り当てます。`min(v_total, c_total // 2)`、最大化されます。 これは、現在比率が小さい方（母音または子音）に Y のバランスを取ることになります。 

3. 音節の数を計算します。 させて`syllables = min(total_vowels, total_consonants // 2)`。 各音節はちょうど 3 文字で構成されているため、単語の最大長は次のようになります。`3 * syllables`。 音節がゼロの場合は 0 を出力します。 

4. 結果を出力します。 

中心的な考え方は、音節の制約は母音と子音の数にのみ依存するため、置換を試みる必要がないということです。 

機能する理由: 各音節は 1 つの母音と 2 つの子音を正確に消費する必要があります。 すべての子音 (「NG」および子音として割り当てられた Y を含む) と母音 (母音として割り当てられた Y を含む) を数えることにより、音節を構築するためのすべてのリソースが得られます。 再配置によってこれらのカウントで許可されている以上の音節を作成することはできないため、最大単語長を決定するにはカウントだけで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    s = input().strip()
    vowels = set("AEIOU")
    n = len(s)
    consonant_count = 0
    vowel_count = 0
    y_count = 0
    i = 0
    while i < n:
        if i + 1 < n and s[i] == 'N' and s[i+1] == 'G':
            consonant_count += 1
            i += 2
            continue
        if s[i] in vowels:
            vowel_count += 1
        elif s[i] == 'Y':
            y_count += 1
        else:
            consonant_count += 1
        i += 1

    # distribute Y to maximize syllables
    max_syllables = 0
    for y_as_vowel in range(y_count + 1):
        v_total = vowel_count + y_as_vowel
        c_total = consonant_count + (y_count - y_as_vowel)
        syllables = min(v_total, c_total // 2)
        if syllables > max_syllables:
            max_syllables = syllables

    print(3 * max_syllables)

if __name__ == "__main__":
    main()
```コードはまず文字列を処理して子音、母音、および Y をカウントし、「NG」シーケンスを単一の子音として処理します。 次に、音節の数を最大化するために、可能な限り Y の割り当てを試みます。 最後に、単語の長さを音節数の 3 倍として計算します。 

「NG」の扱いには微妙な点があります。子音カウントを 1 つ増やして次の文字をスキップすることで、二重カウントを防ぐことができます。 もう 1 つは Y です。0 から 1 までを繰り返します。`y_count`最大音節に対して可能なすべての割り当てを確実に考慮します。
