 ## 問題の理解

 私たちに与えられたデッキは、$N$カードには、以下の整数値がラベル付けされています。$1$そして$N$。 ゲームには、$N$ラウンドします。 で$i$- 第 ラウンドでは、各デッキの値の最大公約数が正確に一致するように、デッキ 1 とデッキ 2 と呼ばれる、空ではない 2 つの素のカードのサブセットを選択する必要があります。$i$。 どちらのデッキにも入っていないカードは無視されます。 ラウンドのクリエイティビティポイント$i$は$i$これら 2 つのデッキを選択する方法の数を掛け合わせます。 タスクは、すべてのラウンドのモジュロで創造性ポイントを合計することです。$998\,244\,353$。 

入力は次のもので構成されます$N$に続く$N$整数$A_1$に$A_N$。 出力は単一の整数、つまり創造性ポイントの合計です。 

最初の重要な観察は、$N$最大 200,000 になる可能性があり、サブセットの数は指数関数的であるため、サブセットを列挙する総当り的な試みは不可能になります。$N$。 同様に、サブセットのすべてのペアをチェックすると、次のようになります。$O(3^N)$最悪の場合の運用。 制限時間 1 秒は、おおよそのアルゴリズムが必要であることを意味します。$O(N \log N)$または$O(N \sqrt{N})$。 

単純なソリューションを壊す可能性のあるエッジケースには、すべてのカードがいくつかのカードと等しい場合が含まれます。$i$。 たとえば、$N = 3$そして$A = [3, 3, 3]$に対応するラウンドのみ$i = 3$創造性ポイントがゼロではありません。 ソリューションがサブセットごとに GCD を単純に計算しようとすると、GCD は乗算的であり、列挙ではなくカウント方法を使用した方が効率的に処理できるため、タイムアウトになったり、正しいカウントが失敗したりします。 

## アプローチ

 素朴なアプローチは、すべてのラウンドを試すことです$i$、カードのすべてのサブセットを生成し、GCD を計算し、有効なペアをカウントします。 これは原理的には正しいですが、列挙する必要があります。$2^N$サブセット、次にペアを比較し、$O(4^N)$複雑。 たとえ$N = 20$、これは不可能です。 

重要な洞察は、の倍数で割り切れるカードを数えるということです。$i$サブセット列挙の代わりに組み合わせ推論を使用します。 ラウンド用$i$、値が次の値で割り切れるカードのみ$i$GCD は正確に一致する必要があるため、使用できます。$i$。 させて$c_i$そのようなカードの数になります。 それぞれについて$i$、これらを分割する方法の数が必要です$c_i$カードを空ではない 2 つの素のサブセットに分割し、各サブセットの GCD が残ります。$i$。 

包含-排他原則を次の倍数にわたって使用できます。$i$。 まず、以下で割り切れるカードのサブセットをすべて数えます。$i$。 次に、GCD が次の倍数より大きいサブセットを減算します。$i$、再帰的に。 最後に各ラウンドごとに$i$、空ではない 2 つのデッキを割り当てる方法の数$f[i]$GCD を正確に備えたカード$i$は$f[i] \times f[i] - f[i]$なぜなら、デッキ 1 には空でない任意のサブセットを選択し、デッキ 2 には空でない互いに素なサブセットを選択して、無効な構成を除外できるからです。 

これにより、問題は約数と倍数の反復に帰着します。$O(N \log N)$ふるいのようなアプローチを使用します。 2 の累乗を数え、モジュラー演算を適用することで、制限内に確実に収まります。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`count`サイズの$N+1$ゼロに。 カードの値を反復処理する$A_1$に$A_N$そして増加します`count[val]`カードの価値ごとに。 これは、それぞれの値を持つカードの枚数を数えます。 
2. 各整数について$i$から$1$に$N$、計算する`mult[i]`で割り切れるカードの総数として$i$。 の倍数にわたって繰り返します$i$そして合計します`count`価値観。 これにより、GCD でデッキを形成できる候補カードの総数が得られます。$i$。 
3. 配列を初期化する`f`サイズの$N+1$ゼロに。 から反復します$N$まで$1$。 させて`total`なれ$2^{mult[i]} - 1$モジュロ$998244353$、次で割り切れるカードの空でないすべてのサブセットを表します。$i$。 次に引きます`f[j]`すべての倍数に対して$j = 2*i, 3*i, ..., N$GCD が次の倍数に等しいサブセットを削除するには$i$。 結果を割り当てる`f[i]`。 今`f[i]`GCD が正確に一致するカードの空でないサブセットの数を表します。$i$。 
4. ラウンドごとに$i$、空ではない 2 つの互いに素なサブセットを選択する方法の数。`f[i]`カードは$f[i] \times f[i] - f[i]$。 これは、1 つのサブセットが空である場合を除いた、すべての順序付きペアをカウントします。 乗算する$i$このラウンドの創造性ポイントを取得し、それを合計モジュロに加算します。$998244353$。 
5. 創造性ポイントの合計を出力します。 

なぜ効果があるのか​​: あらゆる段階で、`f[i]`GCD が正確に一致するサブセットを正しくカウントします。$i$で割り切れるすべての部分集合が含まれるため、$i$そして、より高い倍数についてカウントされたサブセットを減算します。 2 のべき乗を使用すると、考えられるすべてのサブセットが効率的に計算されます。 順序付けられたペアをカウントすることで、すべての有効なデッキ割り当てを正確に取得できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    N = int(input())
    A = list(map(int, input().split()))
    
    count = [0] * (N + 1)
    for a in A:
        count[a] += 1
    
    mult = [0] * (N + 1)
    for i in range(1, N + 1):
        for j in range(i, N + 1, i):
            mult[i] += count[j]
    
    f = [0] * (N + 1)
    pow2 = [1] * (N + 2)
    for i in range(1, N + 2):
        pow2[i] = (pow2[i-1] * 2) % MOD
    
    for i in range(N, 0, -1):
        total = (pow2[mult[i]] - 1) % MOD
        j = 2 * i
        while j <= N:
            total = (total - f[j]) % MOD
            j += i
        f[i] = total
    
    result = 0
    for i in range(1, N + 1):
        ways = (f[i] * f[i] - f[i]) % MOD
        result = (result + ways * i) % MOD
    
    print(result)

solve()
```コードは計算します`mult[i]`どのカードがラウンドに登場できるかを決定する`i`。 2 の累乗は、サブセットのカウントを効率的に処理します。 引き算`f[j]`倍数の場合は、正確な GCD 要件を確実に遵守します。 最後に、順序付きペアの式により、ラウンドの有効なデッキ割り当てがカウントされます。
