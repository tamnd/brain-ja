 ## 解決策
 ## 問題の理解

 未知の順列のペアごとの最大値の配列が与えられます。 

順列の長さは偶数です`n`。 その要素をペアにグループ化すると`(p1, p2), (p3, p4), ...`各ペアをその最大値で置き換えると、配列が得られます`b`長さの`n/2`。 

タスクは順列を再構築することです`p`それは与えられたものを生み出す`b`。 すべての有効な順列の中で、辞書編集的に最小のものを出力する必要があります。 順列が生成できない場合`b`、印刷します`-1`。 

重要な観察は、`b`それ自体が順列の中に現れる必要があります。 これはそのペアの最大値であるため、そのペアの 1 つの位置を占有し、もう 1 つの位置には厳密に小さい未使用の数値が含まれている必要があります。 

制約は大きいです。 すべての合計`n`すべてのテストケース全体で最大でも`2 · 10^5`、つまり、`O(n log n)`解は簡単に十分に高速ですが、二次関数は遅すぎます。 残りのすべての数値を繰り返しスキャンする再構築には、おおよその時間がかかります。`n²`最悪の場合は動作が制限され、制限内に収まらない場合があります。 

いくつかの特殊なケースは見落とされがちです。 

考慮する：```
n = 4
b = [4, 4]
```両方のペアの最大値は等しい。 順列には各数値が 1 回だけ含まれるため、値は`4`2回出現することはできません。 解決策は存在しないため、答えは次のようになります。```
-1
```ローカルペアの条件のみをチェックする再構築では、誤って再利用する可能性があります。`4`。 

もう 1 つの重要なケースは次のとおりです。```
n = 6
b = [2, 4, 6]
```未使用の番号は、`{1,3,5}`。 

最初のペアの最大値は`2`、以下の未使用の数値が必要です。`2`。 唯一の選択肢は`1`。 

2 番目のペアの最大値は`4`、以下の未使用の数値が必要です。`4`。 残された唯一の選択肢は、`3`。 

3 番目のペアには、`5`。 

これは有効です:```
1 2 3 4 5 6
```利用可能な最大の小さい数値を最初に使用する不注意な貪欲法はここでも機能しますが、必ずしも辞書編集上最小の順列を生成するとは限りません。 

最も微妙な失敗は、ペアの最大値が小さすぎる場合に発生します。```
n = 8
b = [8, 7, 2, 3]
```未使用の番号は、`{1,4,5,6}`。 

最大値に達すると`2`、唯一小さい数字は`1`、まだ利用可能なので、それを使用します。 

最大限に`3`、今度は、より小さい未使用の番号が必要ですが、何も残りません。 答えは次のとおりです。```
-1
```どのアルゴリズムでもそのような状況を即座に検出する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、各ペアの最初の位置への欠落した数値の割り当てをテストすることによって、順列を再構築しようとします。 大体から`n/2`数字が欠落していますが、次のオーダーで存在する可能性があります`(n/2)!`可能な割り当て。 中程度の値であっても、`n`、これはまったく不可能です。 

問題の構造からは、一般的な再構成問題よりもはるかに多くの情報が得られます。 

のすべての値`b`順列内に 1 回だけ出現する必要があります。 これはそのペアの最大値であるため、すぐにそのペアの 2 番目の要素として配置できます。```
(_, b1), (_, b2), ...
```ここでの唯一のタスクは、各ペアの最初の要素を選択することです。 

最大値が次のペアを処理しているとします。`x`。 最初の要素は、次の値よりも厳密に小さい未使用の数値でなければなりません。`x`。 このような候補者の中からどれを選ぶべきでしょうか?

 順列全体を辞書編集的に最小限に抑えたいと考えています。 最初の未決定の位置は、対応する最大値の前に表示されます。 順列を最小限に抑えるには、可能な限り最小の有効な数値をそこに配置する必要があります。 

これはすぐに貪欲な戦略を示唆します。 

に表示されない番号はすべて保持します。`b`順序付けされたセット内。 それぞれの最大値について`x`、まだ小さい未使用の最大の数値を取得します。`x`。 

一見すると、これは辞書編集的な最小化とは逆のように思えます。 それが正しい理由は、最大値自体が固定されているためです。 実現可能な最大の小さい数値を選択すると、将来のポジションに対してより小さい値が保存され、後のエントリができるだけ小さくなります。 小さな値をあまりにも早く消費すると、将来のペアが不可能になる可能性があります。 

これはまさに、受け入れられているソリューションで使用される古典的な貪欲です。 

効率的な先行クエリが必要です。「次の値より小さい未使用の最大値を見つける」`x`"。順序付きセットはこれをサポートします。`O(log n)`時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取る`b`。 
2. すべての値が`b`は区別されます。 

順列には各数値が 1 回だけ含まれます。 ある値が 2 回出現する場合、`b`、再建は不可能です。 
3. に表示されるすべての値にマークを付けます。`b`すでに使用されているように。 
4. 以下のすべての数字を入力します。`1`に`n`に現れないもの`b`順序付きセットに変換します。 
5. 答えのペアをペアごとに作成します。 
6. 最大値について`x = b[i]`、厳密に小さい未使用の最大の数値を見つけます。`x`。 

これは順序付きセット内の先行クエリです。 
7. そのような番号が存在しない場合は、次のように出力します。`-1`。 

したがって、このペアは最大条件に違反しない限り形成できません。 
8. 選択した先行ファイルを追加し、さらに追加します。`x`答えに。 
9. 選択した先行セットを順序付きセットから削除します。 
10. すべてのペアが処理された後、構築された順列を出力します。 

### なぜ効果があるのか

 すべてのペアには最大値が含まれている必要があります`b[i]`なので、次のすべての値を配置します。`b`は必須です。 

最大のペアの場合`x`、有効なパートナーはすべて以下より小さい必要があります。`x`。 利用可能なすべての候補の中で、最大のものを選択するのが最も安全な選択です。 これにより、後のペアで使用できる小さい数値がすべて残され、将来のオプションのセットが増えるだけになります。 

有効な再構築が存在すると仮定します。 最大値のペアを処理する場合`x`、未使用の小さい番号をそこに割り当てることができます。 これを、より小さい未使用の数値に置き換えます。`x`将来の最大値は少なくとも以前と同じくらい多くのより小さな値を利用できるため、現在のペアに害を及ぼすことはできず、将来のペアを助けることしかできません。 

したがって、貪欲な選択によって、解決策が存在する場合、それが破壊されることはありません。 アルゴリズムが、ある最大値に対してより小さい未使用の値を見つけることができなかった場合`x`の場合、有効な再構成はまったく存在しません。 

生成された順列も、すべての有効な再構成の中で辞書編集的に最小です。 貪欲型は、最も早い将来の位置の最小値を保存します。これはまさに辞書編集上の最小化が必要とするものです。 

## Python ソリューション```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def erase(self, x):
        self.parent[x] = self.find(x - 1)

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))

        if len(set(b)) != len(b):
            print(-1)
            continue

        used = [False] * (n + 1)
        for x in b:
            used[x] = True

        dsu = DSU(n)

        for x in range(1, n + 1):
            if used[x]:
                dsu.erase(x)

        ans = []
        ok = True

        for x in b:
            y = dsu.find(x - 1)

            if y == 0:
                ok = False
                break

            ans.append(y)
            ans.append(x)

            dsu.erase(y)

        if ok:
            print(*ans)
        else:
            print(-1)

solve()
```最初の検証ステップでは、値が 2 回出現するかどうかをチェックします。`b`。 各最大値自体が順列に出現する必要があるため、このような入力は順列から得られることはありません。 

DSU は先行構造として機能します。 あらゆる価値観に対して`v`、`find(v)`現在利用可能な最大の数値を返します。`v`。 

最初はすべての数字が表示されません`b`利用可能です。 に登場するすべての数字`b`はすでに最大ペアとして予約されているため、DSU から削除されます。 

最大限に`x`、クエリします`find(x - 1)`。 これは、次の値より小さい、利用可能な最大の数値を直接返します。`x`。 

の`erase`操作は番号をその前の番号にリンクします。 After removing`y`、今後のクエリでは自動的にスキップされます。 

DSU の実装は、範囲に対する先行クエリの一般的なトリックです。`1..n`。 バランスのとれたツリーを回避し、複雑さをほぼ線形に保ちます。
