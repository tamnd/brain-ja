 ## 問題の理解

 バイナリグリッドが与えられます。 黒の部分長方形は、全体が以下のもので構成される軸に整列した長方形です。`1`s.

 すべての黒い四角形の中で、その四角形を含む大きな黒い四角形に拡張できない場合、その四角形は「ナイス」と呼ばれます。 言い換えれば、封じ込めに関しては最大限です。 

2 つの美しい四角形がセルを共有しない場合、グリッドはエレガントと呼ばれます。 

この定義は、考えられるすべてのことについて述べているため、一見すると複雑に思えます。`1`長方形とその包含関係。 課題は、このような重なり合う最大の長方形が存在できるかどうかを判断することです。 

グリッドの寸法は最大でも`100 × 100`、テスト ケース全体のすべての行数と列数の合計は次のように制限されます。`777`。 これは非常に小さな入力サイズです。 たとえ`O(nm(n+m))`解決策は容易に受け入れられます。 受け入れられないのは、考えられるすべての長方形を列挙することです。`100 × 100`グリッドには大まかに含まれる`25 million`長方形なので、それぞれをチェックするのは非常にコストがかかりすぎます。 

主な困難は、エレガントの定義が実際に何を意味するのかを認識することです。`1`s.

4 つのセルすべてが単一の最大の黒い長方形を形成します。 隣接しているかどうかだけをチェックする単純なアプローチ`1`sが存在すると、それが誤って拒否されてしまいます。

3人`1`L字型になります。 1 つの最大の長方形は上の行で、別の最大の長方形は左の列です。 左上のセルで重なっているため、グリッドはエレガントではありません。 

接続コンポーネントのみをカウントする不注意な実装では、このケースが誤って受け入れられます。`1`は単一のコンポーネントに属します。

The hole in the center prevents the entire shape from being a rectangle. Multiple maximal black rectangles overlap around the corners, creating intersecting nice rectangles.

 The solution comes from understanding exactly which shapes of`1`は許可されます。 

## アプローチ

 ブルートフォース解釈は定義に直接に従います。 

軸に揃えられたすべての長方形を列挙し、それが完全に次のもので構成されているかどうかを確認できます。`1`s、それが最大であるかどうかを判断し、すべての適切な四角形を収集し、すべてのペアの交差をテストします。 

サイズのグリッド`100 × 100`およそ含まれています$$\frac{100\cdot101}{2}\cdot\frac{100\cdot101}{2} \approx 25\,000\,000$$長方形。 

内容を確認する前から、すでに制限時間内に処理できる範囲をはるかに超えています。 

重要な観察は、実際の定義が非常に単純な幾何学的特性に崩壊するということです。 

の接続されたコンポーネントを取得します`1`■ 4 方向の隣接関係を使用します。 

そのコンポーネント自体が塗りつぶされた長方形を形成する場合、その中にはちょうど 1 つの最大の黒い長方形、つまりコンポーネント全体が存在します。 重複の問題は存在しません。 

コンポーネントが塗りつぶされた四角形を形成していない場合は、その境界ボックス内に少なくとも 1 つの欠落セルが存在する必要があります。 このような形状には必然的に L ターン、つまり水平方向に延びるコーナーが含まれます。`1`s と垂直方向の実行`1`会います。 これら 2 つの実行により、コーナー セルを共有する異なる最大の黒い四角形が生成されます。 したがって、2 つの美しい長方形が交差します。 

これは次のことを意味します:

 グリッドは、すべての接続コンポーネントが存在する場合にのみエレガントになります。`1`s は完全な長方形を形成します。 

この特性を発見すると、問題は非常に小さくなります。 すべての連結コンポーネントについて、その境界ボックスを計算します。 コンポーネントにその境界ボックスのすべてのセルが正確に含まれている場合、コンポーネントは長方形になります。 それ以外の場合はすぐに答えが得られます`NO`。

 ## アルゴリズムのチュートリアル

 1. グリッドのすべてのセルを繰り返します。 
2. 未訪問のセルに次の内容が含まれるたびに、`1`が見つかった場合は、BFS または DFS を開始して、接続されているコンポーネント全体を検出します。 
3. コンポーネントを移動しながら、次のことを記録します。 

- 最小行インデックス。 
- 最大行インデックス。 
- 最小の列インデックス。 
- 最大列インデックス。 
- コンポーネント内のセルの数。 
4. トラバースが終了したら、コンポーネントの外接する四角形の面積を計算します。```
area = (max_row - min_row + 1) × (max_col - min_col + 1)
```5. コンポーネントのサイズと外接する四角形の領域を比較します。 

それらが異なる場合は、外接する四角形内の一部のセルが欠落しています。 コンポーネントは塗りつぶされた長方形ではないため、グリッドをエレガントにすることはできません。 出力`NO`。 
6. すべてのコンポーネントの処理を続行します。 
7. すべてのコンポーネントがチェックに合格した場合、出力`YES`。 

なぜ面積を比較するだけで十分なのでしょうか? コンポーネントのすべてのセルが境界ボックスの内側にあるためです。 コンポーネントのセルの数がボックスの面積と等しい場合、ボックス内のすべての位置がコンポーネントに属している必要があります。 コンポーネントはまさに長方形です。 

### なぜ効果があるのか

 重要な特性は、接続されたコンポーネントが`1`s は、塗りつぶされた長方形の場合には正確に安全です。 

コンポーネントが塗りつぶされた長方形の場合、コンポーネント全体は 1 つの最大の黒い長方形になります。 小さな黒い長方形がその中に含まれていると、好ましくありません。 きれいな長方形のペアは交差できません。 

コンポーネントが塗りつぶされた四角形ではない場合、その境界ボックスには少なくとも 1 つの欠落セルが含まれています。 このような形状は、単一の最大の長方形では表現できません。 少なくとも 2 つの最大の黒い長方形が必要で、それらはコンポーネント内のどこかで重なっています。 これらの重なり合う最大の長方形は、優雅さを侵害する素晴らしい長方形です。 

したがって、すべての接続コンポーネントは長方形である必要があり、その条件を確認することは必要かつ十分です。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())
    g = [input().strip() for _ in range(n)]

    vis = [[False] * m for _ in range(n)]
    ok = True

    for r in range(n):
        for c in range(m):
            if g[r][c] != '1' or vis[r][c]:
                continue

            q = deque([(r, c)])
            vis[r][c] = True

            min_r = max_r = r
            min_c = max_c = c
            cnt = 0

            while q:
                x, y = q.popleft()
                cnt += 1

                min_r = min(min_r, x)
                max_r = max(max_r, x)
                min_c = min(min_c, y)
                max_c = max(max_c, y)

                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx = x + dx
                    ny = y + dy

                    if (
                        0 <= nx < n
                        and 0 <= ny < m
                        and not vis[nx][ny]
                        and g[nx][ny] == '1'
                    ):
                        vis[nx][ny] = True
                        q.append((nx, ny))

            area = (max_r - min_r + 1) * (max_c - min_c + 1)

            if area != cnt:
                ok = False
                break

        if not ok:
            break

    print("YES" if ok else "NO")
```外側のループは未訪問のものを検索します`1`細胞。 このような各セルは、新しい接続コンポーネントを開始します。 

BFS は 2 つの目的を同時に果たします。 コンポーネントに属するすべてのセルをマークし、コンポーネントの境界ボックスを計算します。 行インデックスと列インデックスの最小値と最大値を追跡すると、グリッド上での余分なパスが回避されます。 

変数`cnt`コンポーネント内のセルの数を格納します。 BFS が終了すると、バウンディング ボックスによって決定される長方形がわかります。 コンポーネントが完全な長方形の場合、そのサイズは長方形の面積と等しくなければなりません。 穴、くぼみ、または L 字型があると、境界ボックスは変更されないままコンポーネントのサイズが小さくなり、比較が失敗します。 

この実装では 4 方向の隣接関係が使用されます。これは、これがグリッド コンポーネントの接続の自然な概念であるためです。 斜めの隣は意図的に無視されます。 

単一のセル、単一の行、または単一の列については、特別な処理は必要ありません。 面積の公式は、これらすべての場合において正しく機能します。
