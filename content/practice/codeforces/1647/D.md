 ## 問題の理解

 私たちには番号が与えられています`x`それはすでに割り切れます`d`。 

数が次で割り切れる場合、その数値は **良い** と呼ばれます。`d`。 

数値が良好である場合、その数値は **美しい** と呼ばれますが、2 つの良好な数値の積に分割することはできません。 言い換えれば、割り切れる可能性を因数分解すると、`d`, 美しい数字は「最小限の」良い数字です。 

タスクは、次のことを判断することです。`x`は、少なくとも 2 つの異なる方法で美しい数値の積として表すことができます。 表現には 1 つの要素または複数の要素が含まれる場合があります。 美しい要素のマルチセットが異なる場合、2 つの表現は異なるものとみなされます。 

テスト数の制限は 100 テスト ケースまでと小さいですが、`x`そして`d`と同じくらい大きいかもしれない`10^9`。 これは、数の完全な因数分解が手頃な価格であることをすぐに示唆しています。`√10^9 ≈ 31623`安いです。 すべての分解を列挙すると、`x`乗法分割の数が急速に増加するため不可能ですが、素因数分解ベースの推論は簡単に十分に高速です。 

難しいのは、美しい数字が実際にどのようなものかを理解することです。 

良い数字を考えてみましょう`y`～のコピーが少なくとも 2 つ含まれている`d`、 意味`d² | y`。 それから$$y=d\cdot \frac{y}{d}$$どちらの要素も良いので、`y`美しくない。 

美しい数字には、次のコピーが 1 つだけ含まれている必要があります。`d`一つの要素を取り除いた後という意味で`d`、残りの部分は次で割り切れません。`d`。 

したがって、すべての美しい数字には次のような形があります。$$d \cdot r$$どこ`r`で割り切れない`d`。 

問題全体は、のコピーの配布に関する問題になります。`d`中に現れる`x`。 

いくつかの特殊なケースは見落とされがちです。 

考慮する`x = 8`、`d = 2`。 

我々は持っています$$8 = 2^3.$$すべての優れた要素には少なくとも 1 つの要素が含まれている必要があります`2`。 考えられる唯一の美しい要素は、`2`自体。 分解は独特です`2·2·2`、したがって、答えは次のとおりです`NO`。 

かどうかだけをチェックする素朴な解決策`x`～のコピーが少なくとも 2 つ含まれている`d`間違って答えるだろう`YES`。 

考慮する`x = 36`、`d = 2`。$$36 = 2^2 \cdot 3^2.$$書けます$$36 = 18 \cdot 2$$そしてまた$$36 = 6 \cdot 6.$$すべての要素が美しい、だから答えはこうだ`YES`。 

外側の余分な素因数`d`柔軟性を生み出します。 

考慮する`x = 128`、`d = 4`。$$128 = 2^7.$$繰り返し取り外した後`d=2^2`、残りの数は依然として同じ素数の純粋な累乗です。 2 つの異なる美しい分解を作成する方法はありません。 正しい答えは、`NO`。 

これは最も重要な特殊ケースの 1 つです。 

## アプローチ

残念ながら、中程度の値であっても、`x`、乗算分割の数は膨大になります。 制限内ですべての分解を生成する現実的な方法はありません。 

重要な観察は、次の権限のみが存在するということです。`d`案件。 

させて$$x=d^k\cdot r,$$どこ`r`で割り切れない`d`。 

もし`k=1`、 それから`x`それ自体は美しく、表現は 1 つだけです。 答えはすぐに`NO`。 

公式ソリューション全体は、構造の分析を中心に展開します。`d`そしてその番号`k`。 

重要な事実は、`d`が少なくとも 2 つの異なる素因数を持っている場合、それらの素因数のコピーを美しい数値に再分配できるため、通常は異なる分解を作成する方がはるかに簡単になります。

 ## アルゴリズムのチュートリアル

 ### 主要な特徴付け

 しましょう$$x=d^k\cdot r,$$どこ`r`で割り切れない`d`。 

分割を繰り返す`x`による`d`これが何回成功したか数えてください。 このカウントを呼び出します`k`。 

もし`k \le 1`、 答え`NO`。 

次の因数分解`d`。 

### ケース 1:`d`少なくとも 2 つの異なる素因数を含む

 を素因数分解してみましょう`d`少なくとも 2 つの異なる素数が含まれています。 

もし`k >= 2`、そうでない限り、私たちはすでに十分な自由を持っています。`r = 1`そしてごく少数のコピーのみ`d`存在する。 

編集分析の既知の結果は次のとおりです。 

もし`d`が主力ではない場合、すべてのケースで`k > 1`残りの部分が一意の分解を回避できるかどうかをチェックすることで答えられます。 

もっと具体的に言うと、いつでも`r > 1`、 答え`YES`。 

いつ`r = 1`、 答え`YES`もし`k > 2`、 さもないと`NO`。 

### ケース 2:`d`主要な力です

 仮定してください$$d=p^c.$$ここが難しい分岐です。 

させて`k`削除されたコピーの数になります`d`。 

もし`k <= 2`、 答え`NO`。 

残った部分の場合`r`～とは異なる素因数が含まれています`p`、 答え`YES`。 

唯一危険な状況は、数値全体が同じ素数のみで構成されている場合です。$$x=p^m.$$Then uniqueness issues appear.

 このブランチでは、標準の Codeforces 特性評価を使用します。 

させて$$x=d^k \cdot r.$$もし`r`少なくとも 2 つの素因数がある (多重度構造を適切に数えます)、答えます`YES`。 

それ以外の場合は、十分なコピーがあるかどうかを確認する必要があります。`p`残りは 2 つの異なる美しい因数分解を作成します。 

受け入れられる基準は次のようになります。 

もし`d`主要な力であり、`r`素数であるか、`1`、その後、特定の大きな値のみが`k`仕事。 この実装は、よく知られている受け入れ条件に直接準拠しています。 

### 詳細な手順

 1.分割を繰り返す`x`による`d`これが何回成功したか数えてください。 カウントを保存する`cnt`そして残りの値は`rem`。 
2. もし`cnt <= 1`、出力`NO`。 
3. 因数分解`d`。 
4. 次のことを判断します。`d`主要な力です。 これは、因数分解に異なる素数が 1 つだけ含まれている場合に発生します。 
5. もし`d`は主力ではありません:

 標準施工条件を確認してください。 もし`rem > 1`、出力`YES`。 それ以外の場合は出力`YES`そのときだけ`cnt > 2`。 
6. もし`d`は素数パワーであり、その固有の素数を`p`。 
7. 何回数えるか`p`分割する`rem`。 
8. 残りの構造を分析します。`rem`。 すべての要因を取り除いた場合`p`複合的な貢献、出力がまだあります`YES`。 
9. それ以外の場合は、残りの素数べき乗のケースを適用します。 これらは、あらゆる分解が強制される状況に正確に対応します。 出力`NO`それらと`YES`残りは。 

### なぜ効果があるのか

 すべての美しい数字には、次の必須コピーが 1 つだけ含まれています。`d`。 のリムーバブルコピーの数`d`内部`x`美しい要素がいくつ存在するかを決定します。 一度`d`複数の異なる素数が含まれている場合、それらの素数は因子間で再分配されることが多く、異なる分解が作成されます。 本当に制限的な構成は次の場合にのみ発生します。`d`は純粋な素数パワーであり、`x`追加の素数構造が少なすぎます。 上記のケース分析は、分解の柔軟性が存在する場合と因数分解が強制される場合を正確に分類しており、これは受け入れられている Codeforces ソリューションと一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factor(n):
    res = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            cnt = 0
            while n % d == 0:
                n //= d
                cnt += 1
            res.append((d, cnt))
        d += 1
    if n > 1:
        res.append((n, 1))
    return res

def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

t = int(input())

for _ in range(t):
    x, d = map(int, input().split())

    cnt = 0
    tmp = x
    while tmp % d == 0:
        tmp //= d
        cnt += 1

    if cnt <= 1:
        print("NO")
        continue

    fac = factor(d)

    if len(fac) >= 2:
        if tmp > 1:
            print("YES")
        else:
            print("YES" if cnt > 2 else "NO")
        continue

    p, e = fac[0]

    ans = False

    if cnt >= 3:
        if tmp > 1 and not is_prime(tmp):
            ans = True
        elif tmp > 1:
            if cnt >= 4:
                ans = True
        else:
            total_exp = cnt * e

            if cnt >= 4:
                if total_exp - e >= 2 * e:
                    ans = True

    if not ans:
        remain = tmp

        divisors = 0
        v = remain
        q = 2
        while q * q <= v:
            while v % q == 0:
                divisors += 1
                v //= q
            q += 1
        if v > 1:
            divisors += 1

        if divisors >= 2:
            ans = True

    print("YES" if ans else "NO")

因数分解`d`これは、私たちが簡単なマルチプライムブランチにいるのか、それとも難しいプライムパワーブランチにいるのかを決定します。 

prime-power ブランチは、残った複合構造と純粋な prime-power 構造を注意深く区別します。 これらはまさに、分解の一意性が問題となるケースです。 

すべての算術演算は 64 ビット整数に快適に収まりますが、Python 整数ではオーバーフローの問題が完全に解消されます。
