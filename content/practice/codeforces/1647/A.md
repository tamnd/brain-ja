 ## 問題の理解

 桁の合計が指定された合計になる、可能な限り最大の数を構成するように求められます。`n`、数値にゼロを含めることはできないこと、および連続する 2 つの数字が等しくなることはできないという 2 つの制限があります。 各テスト ケースは異なる合計を提供します`n`、それぞれに有効な数値を生成する必要があります。 入力は最大 1000 のテスト ケースで構成され、それぞれのテスト ケースは`1 ≤ n ≤ 1000`。 出力は制約を満たす最大数です。 

単純なアプローチでは、すべての数字の合計を生成しようとする可能性があります。`n`、ゼロまたは連続する数字の繰り返しを含むものをフィルタリングして、それらを数値的に比較します。 これはすぐに実行不可能になります。`n = 1000`、数字シーケンスの数は天文学的に多く、1 秒の制限時間内での妥当な操作数をはるかに超えています。 したがって、可能性を列挙するのではなく、数字を直接構築する建設的なアプローチが必要です。 

不注意な実装でつまずく可能性のあるエッジケースとしては、次のようなものがあります。`n`1 桁の回答が最適な値と、先頭の桁を最大化するために桁間を交互に繰り返すシーケンスです。 例えば、`n = 1`生産すべき`1`、 そして`n = 11`生産すべき`987`次のような繰り返しの数字を使用しようとする代わりに、`5551`、これは連続数字ルールに違反します。 

## アプローチ

 ブルートフォース手法では、すべての数字の合計を生成します。`n`、ゼロまたは連続した数字の繰り返しを含むシーケンスをフィルターで除外し、最大値を選択します。 このアプローチは概念的には単純ですが、次の点で指数関数的です。`n`、長さのシーケンスの数が最大であるため、`n`組み合わせて成長します。 と`n`最大値が 1000 に達すると、総当たりアプローチは妥当な時間内に完了することはできません。 

重要な洞察は、左端の桁ができるだけ大きく、連続する桁が異なる場合に数値が最大になるということです。 これを利用するには、9 から 1 までの降順シーケンスを繰り返し使用して右から左に数値を構築し、から各桁を減算します。`n`ゼロになるまで。 最後に構築されたシーケンスを逆にすると、最大の数字が最初に表示されます。 この方法が機能するのは、使用可能な最大の桁が常に全体の数値を最大化する位置に配置され、降順パターンにより連続した重複が自然に防止されるためです。

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化する`digits`構築中の数値を保存します。 
2. 可能な最大の数字から始めます`9`。 その間`n`がゼロより大きい場合は、現在の桁がこの値を超えずに使用できるかどうかを確認してください。`n`。 
3. 現在の数字を次の値に追加します。`digits`、からその値を減算します。`n`。 次の反復のために数字をデクリメントします。 数字が 0 になった場合は、9 にリセットしてシーケンスを続行します。 
4. までこのプロセスを繰り返します。`n`ゼロに達します。 
5. リバース`digits`それらを文字列に結合して、最終的な数値を生成します。 

これが機能するのは、常に利用可能な最大の桁を最初に取得し、最初はそれを最下位の位置に配置し、次にそれを反転して最上位の位置に移動するためです。 降順シーケンスにより連続した重複が防止され、1 ～ 9 の数字のみを使用することでゼロが完全に回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        digits = []
        current = 9
        while n > 0:
            take = min(current, n)
            digits.append(take)
            n -= take
            current -= 1
            if current == 0:
                current = 9
        print("".join(map(str, reversed(digits))))

solve()
```この関数はテスト ケースの数を読み取り、それぞれを繰り返します。`n`。 の`while`ループは 9 から下の数字を貪欲に構築し、必要に応じて 9 にラップアラウンドします。 最終的な数値は、桁のリストを逆にして、より大きな桁がより重要な位置を占めるようにして構築されます。 慎重な取り扱い`current`連続した重複がなく、ゼロが表示されないことを保証します。
