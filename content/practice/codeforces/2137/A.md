 ## 解決策
 ## 問題の理解

 Collatz 演算を正確に実行した結果が得られます。`k`回と最終値`x`。 多くの異なる開始値が同じ結果をもたらす可能性があるため、タスクは元の値を一意に見つけることではありません。 必要なのは、正確な後に指定された最終値を生成する開始整数を構築することだけです。`k`操作。 

操作は簡単です。 現在の数値が偶数の場合、次の数値は`x / 2`。 現在の数値が奇数の場合、次の数値は次のようになります。`3x + 1`。 

制約は非常に小さいです。 両方`k`そして`x`せいぜい`20`、多くても`400`テストケース。 指数関数的な構造でも簡単に適合します。 これは、意図したソリューションが最適化ではなく、プロセスを元に戻す方法を理解することであることを示唆しています。 

主な問題は、コラッツ操作が常に反転できるわけではないことです。 たとえば、現在の値が次のようになっていることがわかっているとします。`4`、以前の値は次のようになっている可能性があります`8`なぜなら`8 → 4`偶数ルールを介して、あるいはそうであった可能性があります`1`なぜなら`1 → 4`奇妙なルールによって。 

不用意に逆構築すると、可能な限り奇妙な先行部分を使用しようとする可能性があります。 考慮する：```
k = 1, x = 5
```方程式`(5 - 1) / 3`は整数ではないため、奇数の前任者は存在しません。 正しい答えは、`10`、 以来`10 → 5`。 

もう 1 つの罠は、有効な答えが 1 つだけ必要であるということを忘れていることです。 のために```
k = 1, x = 4
```両方`1`そして`8`は有効な先行者です。 あらゆる可能性を探る必要はありません。 

3 番目の微妙なケースは、多くの手順を繰り返し逆に実行するときに発生します。 のために```
k = 5, x = 4
```有効な再構成の 1 つは、```
4 ← 8 ← 16 ← 32 ← 64 ← 21
```それが答えを与えます`21`。 逆戦略では、すべての後退ステップが有効な前方コラッツの動きに対応することを保証する必要があります。 

## アプローチ

 最も直接的なアイデアはブルートフォースです。 考えられるすべての開始番号を試してシミュレーションすることもできます`k`最終値が指定された値と等しいものが見つかるまでコラッツ演算を行います。`x`。 

これは制約が小さいため機能しますが、正しい開始値がどの程度の大きさであるかについて明確な上限はありません。 小さいものでも`k`、多くの候補者がテストを受ける必要があるでしょう。 このアプローチには明確な保証はありません。 

重要な観察は、プロセスを逆転できるということです。 

現在の値が`y`。 

前の値が偶数の場合、前方への移動によりそれが 2 で除算されます。```
previous = 2y
```この前任者は常に存在します。 

前の値が奇数の場合は、次のようになります。```
3 · previous + 1 = y
```それは与える```
previous = (y - 1) / 3
```ただし、これは次の場合にのみ有効です`(y - 1)`で割り切れます`3`そして結果は奇妙です。 

重要な事実は、すべての前任者が必要なわけではないということです。 各ステップで必要な有効な先行タスクは 1 つだけです。 2 倍化すると常に有効な先行データが生成されるため、繰り返し適用できます。```
y ← 2y
```その通り`k`回。 

反転後`k`このようにステップを進めると、取得される数値は次のようになります。```
x · 2^k
```この番号から先に Collat​​z プロセスを実行すると、`k`連続して 2 で除算し、正確に戻ります`x`。 

これにより、即座に建設的な解決策が得られます。

 ## アルゴリズムのチュートリアル

 1.読む`k`そして`x`。 
2. 与えられた値を処理する`x`すべての操作がすでに実行された後の状態として。 
3. 保証された先行ステップを選択して、Collat​​z ステップを 1 つ取り消します。`2x`。 

すべての偶数は順方向プロセスでその値の半分にマップされるため、これは常に有効です。 
4. 前の手順を正確に繰り返します`k`回。 

1 回逆のステップを実行すると、値は次のようになります。`2x`、2つのステップの後、次のようになります`4x`、その後`k`になるステップ`x · 2^k`。 
5. 結果の数値を出力します。 

### なぜ効果があるのか

 すべてのリバース ステップは、コラッツの前進移動が 2 で除算される数値を構築します。 から始めると`x · 2^k`、最初の操作で生成されるのは`x · 2^(k-1)`、2番目は生成します`x · 2^(k-2)`、 等々。 まさにその後`k`私たちがたどり着いた操作`x`。 

すべての中間値は偶数であるため、コラッツ プロセスはすべてのステップで 2 による除算規則に従い、再構成が有効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    k, x = map(int, input().split())
    print(x * (1 << k))
```このソリューションは、逆の構造を直接実装します。 

各テスト ケースには、次のテスト ケースの番号が必要です。`k`コラッツ演算はすべて 2 による除算です。 乗算`2^k`まさにそのような数値を作成します。 

表現`1 << k`計算する`2^k`ビットシフトを効率的に使用します。 以来`k ≤ 20`、結果は非常に小さく、Python の整数内に簡単に収まります。 

シミュレーションは必要ありません。 すぐに答えを作成し、印刷します。

 次のことを考慮してください。```
