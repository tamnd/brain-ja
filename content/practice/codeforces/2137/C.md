 ## 問題の理解

 2 つの整数が与えられます。$a$そして$b$、正の整数を選択できます$k$そのような$b$で割り切れます$k$。 それから交換します$a$と$a \cdot k$そして$b$と$b / k$。 目標は合計を作ることです$a + b$均一であることを確認しながら、できるだけ大きくします。 選択肢がない場合$k$偶数の和を生成すると、戻ります$-1$。 

入力は最大で構成されます$10^4$テストケース。 それぞれ$a$そして$b$と同じ大きさにすることができます$10^{18}$、つまり、すべての約数に対する単純な反復が行われることを意味します。$b$特に次の場合は高価になる可能性があります$b$大きな素因数を持っています。 したがって、私たちのソリューションは、広い範囲にわたる明示的な列挙を避け、すべての可能な乗数ではなく数値のパリティに関する推論に焦点を当てる必要があります。 

エッジケースが発生するのは次の場合です$a$そして$b$異なるパリティパターンを持っています。 たとえば、両方の場合、$a$そして$b$奇妙であり、$b$プライムです、いいえ$k > 1$分割する$b$、 そして$a + b$奇数のままです。 もう 1 つの微妙なケースは、一方の数が偶数で、もう一方の数が奇数であるが、偶数が最小である場合です。 偶数成分をあまり減らさずに、より大きな偶数和を生成することは不可能な場合があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての約数を反復処理することです。$b$。 各約数について$k$、計算します$a \cdot k + b / k$最大値を追跡して、それが偶数であるかどうかを確認します。 これは原理的には機能します。なぜなら、すべての有効な乗数が$k$はの約数です$b$、ただし大きい場合は$b$、特に近くの人$10^{18}$に近づくことができる約数の数$10^6$またはそれ以上であり、大きな数値を繰り返し乗算すると非効率になる可能性があります。 これは正しいですが、遅すぎる可能性があります。$10^4$極端なテストケース$b$。 

重要な洞察は、すべての約数が必要なわけではないということです。 この問題はパリティのみを必要とします: 我々はパリティを必要とします$a \cdot k + b / k$均等になるように。 いくつかのシナリオしかありません。 

1. 両方の場合$a$そして$b$偶数、任意$k$合計を均等に保ち、より大きくします$k$増加する傾向にある$a \cdot k + b / k$。 
2. もし$a$奇妙であり、$b$偶数です、必要です$b/k$偶数と奇数を組み合わせる$a \cdot k$そして偶数の合計を生成します。 から 2 の係数を 1 つ取り除くと、$b$多くの場合、最適な偶数和が得られます。 
3. 両方の場合$a$そして$b$奇妙です、$a + b$奇数であり有効ではありません$k$、与える$-1$。 

これにより、問題はパリティを調べて 2 のべき乗を因数分解することになります。$b$、すべての約数を考慮するのではなく。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数を読み取ります。$a$そして$b$。 
2. 合計の場合$a + b$何も操作しなくてもすぐに録音$a + b$最大候補として。 これは最も単純なケースを処理します。 
3. 両方の場合$a$そして$b$が奇数、合計が奇数で乗算している$a$奇数の除数または除算による$b$奇数の除数によってパリティを変更することはできません。 この場合、出力$-1$。 
4. もし$b$が偶数である場合、2 の最大のべき乗を因数分解し、それを呼び出します$x = \text{largest power of 2 dividing } b$。 させて$b' = b / x$。 合計$a \cdot k + b / k$私たちが選んだとしても$k$どちらかの$a \cdot k$または$b/k$は均等です。 
5. 均等であることを保証しながら合計を最大化するために、2 つの乗数の候補を検討します。 1つは$k = x$、与える$a \cdot x + b / x$。 もう一つは、$k = x / 2$もし$x > 1$、与える$a \cdot (x/2) + 2 * b / x$。 これら 2 つの候補の最大値を取得します。 
6. これらの演算を通じて有効な偶数和が得られない場合、出力$-1$。 

機能する理由: 2 のべき乗を因数分解すると、合計が均等になる可能性があるすべての可能性をテストできることが保証されます。$a \cdot k + b/k$は完全に 2 のべき乗によって制御されます$a$そして$b$。 合計を最大化することは、より大きな数値に有効な最大値を乗算することに関して単調であるため、$k$、このアプローチでは、すべての約数を列挙することなく最適解を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_even_sum(a, b):
    if (a + b) % 2 == 0:
        return a + b
    if a % 2 == 1 and b % 2 == 1:
        return -1

    # Ensure b is even for factoring
    if b % 2 == 1:
        a, b = b, a

    # factor out largest power of 2 from b
    x = b
    while x % 2 == 0:
        x //= 2

    # candidate k values
    candidate1 = a * (b // x) + x
    if x > 1:
        candidate2 = a * (b // (2*x)) + 2*x
        return max(candidate1, candidate2)
    return candidate1

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(max_even_sum(a, b))
```このソリューションでは、最初に自明なパリティをチェックします。 次に、それを保証します$b$は偶数因数分解であり、2 の最大のべき乗を抽出し、偶数の和を最大化するために最大 2 つの候補を考慮します。 すべての約数を反復処理することを回避します。これは、大きな入力の場合に重要です。
