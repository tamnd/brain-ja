 ## 問題の理解

 数値のシーケンスが与えられ、そのシーケンス内の各数値を、構築する必要がある未知の配列の周波数要件として解釈したいとします。 具体的には、配列を構築する必要があります`a`すべての位置が`i`値が含まれています`a[i]`、に書かれた値`b[i]`回数と等しくなければなりません`a[i]`配列全体に表示されます。 

これにより、自己参照条件が作成されます。 各位置は、それ自身の値を直接記述するのではなく、その値をグローバルに繰り返す回数を記述します。 値を代入すると`x`ある位置に移動し、その後、以下を含むすべての位置に`x`同じ合計数について合意する必要があります`x`最終的な配列で。 

出力は次のような配列です`a`、または一貫した割り当てが存在しないというステートメント。 

この制約により、テスト ケース全体で合計 2 · 10^5 までの要素が許可されます。 これにより、テスト ケースごとに二次関数が即座に除外されます。 おそらくグループ化または頻度のカウントに基づいて、線形または線形に近い構造が必要です。 

値が次の場合、微妙な故障モードが表示されます。`b`内部的に矛盾しています。 たとえば、ある位置が周波数 2 を要求し、別の位置が周波数 3 を要求しているが、両方を同時に満たすのに十分な位置がない場合、構築は存在しません。 カウントが構造的に矛盾する場合、別の問題が発生します。 例えば、`b = [2, 2, 3]`2 回出現する値は 3 回の出現を要求する位置を満たすことができないため、これは不可能ですが、すべての位置は何らかの値クラスに属している必要があります。 

小さな矛盾の例としては、`b = [1, 2, 3]`。 頻度 3 を必要とする位置に値を割り当てる場合、その値は 3 回出現する必要がありますが、要件 3 を持つ位置は 1 つだけであり、サイズ 3 のグループを形成する余地はありません。 

## アプローチ

 ブルートフォースの試みでは、位置に値を割り当て、誘発された頻度カウントの一貫性をチェックしようとします。 各位置について、値を推測し、実行中の配列を維持し、周波数を再計算し、すべての位置が必要な周波数と一致するかどうかを検証できます。 値を次のように制限したとしても、`1..n`、これは組み合わせになります:`n`ポジションは最大です`n`選択肢が増え、割り当ての数が指数関数的に増加し、割り当てごとの検証も線形になります。 これは実現可能な限界をはるかに超えています。 

重要な観察は、この条件が、同じ値が割り当てられたグループ化インデックスのみに依存するということです。 価値を決めたら`x`使用されています`k`割り当てられたすべてのインデックスの回数`x`持っている必要があります`b[i] = k`。 これは、同じ値が割り当てられたすべての位置が同一である必要があることを意味します`b[i]`、そのような位置の数はその値と等しくなければなりません。 

So the problem reduces to grouping indices by their required frequency, and ensuring that each group size is consistent with the value defining it. 周波数の場合`k`表示されます`c`回`b`、それからそれら`c`位置はグループに分割する必要があり、各グループは正確に表示される 1 つの個別の値を表す必要があります。`k`回。 したがって、各グループは正確に消費します`k`インデックスなので、`c`で割り切れる必要があります`k`。 

実現可能性が確認されると、各値の構築は簡単になります。`k`、すべてのインデックスを取得します`b[i] = k`、それらをサイズの塊に分割します`k`、各チャンクに新しいラベルを割り当てます。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 各値が何回あるかを数えます`k`に登場する`b`。 

これは、ある値が正確に表示される必要があるポジションがどれだけあるかを示します。`k`回。 
2. 個別の値ごとに`k`、カウントされているかどうかを確認します`cnt[k]`で割り切れます`k`。 

そうでない場合は、有効なグループ化は不可能であると直ちに結論付けます。 

その理由は、要件を持つポジションにそれぞれの有効な値が割り当てられているためです。`k`正確に占めなければなりません`k`ポジションを保持し、残りは許可されません。 
3. 有効なすべての場合`k`、インデックスのリストを取得します。`b[i] = k`。 
4. このリストを同じサイズの連続したブロックに分割します。`k`。 各ブロックは、最終的な配列内の 1 つの個別の値に対応します。`a`。 
5. 新しい一意の整数ラベルを各ブロックに割り当て、そのラベルをブロックのすべてのインデックスに書き込みます。`a`。 
6. 構築された配列を出力します。 

### なぜ効果があるのか

 同じ値が割り当てられたすべての位置は、同一のインデックスの同じグループに属します。`b[i]`。 各グループのサイズは正確です`k`したがって、そのグループ内のすべての位置で周波数が正しく認識されます。`k`最終的な配列で。 グループは互いに素であり、各頻度クラスのすべてのインデックスをカバーするため、異なる頻度値の間で競合は発生しません。 割り算条件により、周波数クラス内でペアになっていないインデックスが残らないことが保証され、部分的なグループが定義に違反することが防止されます。`f(x)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        
        pos = [[] for _ in range(n + 1)]
        for i, x in enumerate(b):
            pos[x].append(i)
        
        a = [-1] * n
        ok = True
        label = 1
        
        for k in range(1, n + 1):
            if not pos[k]:
                continue
            if len(pos[k]) % k != 0:
                ok = False
                break
            
            for i in range(0, len(pos[k]), k):
                for j in range(i, i + k):
                    a[pos[k][j]] = label
                label += 1
        
        if not ok:
            print(-1)
        else:
            print(*a)

if __name__ == "__main__":
    solve()
```実装では、必要な頻度によってインデックスをグループ化します。`b[i]`。 の`pos`構造体はこれらのグループを効率的に格納します。 周波数ごとに`k`、ラベルを割り当てる前に割り切れることを確認します。 

微妙な点は、ラベルがサイズのグループごとに導入されていることです。`k`、値ごとではありません`k`。 これが必要なのは、複数の個別の値があるためです。`a`同じ周波数要件を共有することもできますが、グループの一意性を満たすために区別可能な状態を維持する必要があります。 

ネストされたループは各ブロックに新しい識別子を割り当て、すべてのグループが確実に個別の値になるようにします。`a`。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての値が同一である場合に発生します。`b = [n, n, n, ..., n]`。 アルゴリズムはすべてのインデックスを単一のバケットに配置し、`n % n == 0`が成り立ち、単一のグループが生成されます。 すべてのインデックスは同じラベルを受け取り、すべての値が正確に表示されるため、結果の配列は条件を満たします。`n`回。 

もう 1 つのエッジ ケースは、値がほとんど小さいにもかかわらず、1 つの大きな要件が現れる場合です。たとえば、`b = [1, 1, 1, 4]`。 のバケツ`4`サイズは 1 で、4 で割り切れないため、アルゴリズムはすぐに拒否します。 その位置に値を割り当てようとすると、4 回の出現が必要になりますが、そのクラス内の候補位置が 1 つしかない場合、これは不可能です。 

最後の構造的なエッジケースは、次のような有効なグループをインターリーブすることです。`b = [2, 2, 1, 1, 1, 1]`。 ここでは、両方のバケットが可分性を満たしています: の 2 つの位置`2`、4つの場合`1`。 アルゴリズムはそれらをサイズ 2 の 1 つのグループとサイズ 4 の 1 つのグループに正しく分割し、個別に異なるラベルを割り当てます。 これにより、異なる値をリンクする制約がないため、周波数クラス間の独立性が十分であることが確認されます。`k`最終施工中。
