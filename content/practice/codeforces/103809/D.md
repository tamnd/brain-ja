 ## 解決策
 ## 問題の理解

 各セルが 1 つの対角線セグメントを含むか、ブロックされているグリッドが与えられます。 対角線はセルの対向する 2 つの角を接続するため、ブロックされていないすべてのセルは 2 つのグリッド頂点間の 1 つのエッジに寄与します。 そのエッジの方向はセルの値に依存し、セルを反転して対角線を他の方向に切り替えることができます。 ブロックされた細胞は何も寄与しません。 

重要な頂点は対角線の端点だけです。 これらの「アクティブな」頂点のうち、対角エッジに沿ってトラバースするときに、誘導されたグラフが接続されるようにしたいと考えています。 各反転は、単一セル内のエッジ方向を 1 つだけ変更します。結果のグラフが接続されるように、そのような反転の数は最小限にする必要があります。 どの反転シーケンスもすべてのアクティブな頂点を 1 つの連結コンポーネント内に配置できない場合は、マイナス 1 を出力する必要があります。 

グリッド サイズはテスト ケースごとに最大 500 x 500 で、テスト全体の合計次元は数千に制限されます。 これは、セル数にほぼ線形または線形演算の動作が必要であることを強く示唆しています。$O(nm \log(nm))$または$O(nm)$テストごとの解は許容されますが、頂点またはエッジの数が 2 次であるものは許容されません。 

アクティブな構造がすでに接続されているが反転する必要がない場合、微妙なエッジ ケースが発生します。 もう 1 つは、グラフが 2 部構成になっており、反転に関係なく接続が妨げられる場合です。たとえば、すべてのアクティブなコンポーネントが対角線の選択ではなく構造によって分離されている場合です。 3 番目は、アクティブなグラフに単一の対角セルなどのエッジが非常に少ない場合です。接続性は簡単に満たされますが、シングルトン頂点を無視する単純なコンポーネント構築ロジックでは、誤って接続されていないものとして扱われる可能性があります。 

## アプローチ

 各セルは、2D グリッド グラフの 2 つの頂点間の対角エッジに寄与します。 重要な観察は、各セルが 2 つの可能なエッジの間の二者択一であるということです。 頂点の観点から考える代わりに、二重構造の観点から考える方がはるかに自然です。各対角線はグリッド コーナーの 2 つの「パリティ クラス」を接続し、どのコーナーのペアが接続されているかを反転して交換します。 

強引なアイデアは、すべてを試すことです$2^{k}$構成$k$ブロックされていないセルの数です。 構成ごとにグラフを作成し、DFS または DSU を使用して接続をテストします。 これは正しいですが、一度ではすぐには不可能です$k$20くらいを超えるので、$2^{20}$すでに100万の州に到達しており、ここでは$k$は250,000までです。 

指数関数的な選択を、反転がどのように相互作用するかを捉える構造に置き換える必要があります。 重要な洞察は、各セルが単独で新しい接続の「選択肢」を導入するわけではないということです。 代わりに、各セルは 2 つの固定頂点を接続し、反転すると接続されている頂点のペアが交換されるだけです。 これは、すべてのセルが固定の基礎となるグラフ内の 2 つのノード間のエッジであり、2 つのエッジ タイプのいずれかを選択することと同じです。 

ここで問題は、セルごとに 1 つのエッジを選択して、頂点上の結果のグラフが接続され、参照構成から逸脱する回数を最小限に抑えることです。 これは、各変数が 2 つの状態を持ち、接続性にグローバルに影響を与える、グラフ上の最小コスト制約満足問題です。 

エッジ選択の下で接続を強制する標準的な方法は、問題を補助グラフ内の最小スパニング構造を見つけることに減らすことです。 各セルは 2 つの候補エッジ、つまりコスト 0 (方向維持) とコスト 1 (反転) の 1 つを提供します。 次に、各セルが選択された 1 つのエッジに正確に寄与することを考慮しながら、最小の総コストですべての頂点を接続するエッジのサブセットを選択します。 これはマトロイド交差/制約付き MST 構造の変形になりますが、ここでは各セルが独立しており、使用可能なエッジを 1 つだけ提供するため、単純化されています。 

代わりに、別の方法で再定式化します。各セルは 2 つの頂点を接続しますが、それらの頂点は座標のパリティのみに依存します。 グリッドは自然にコーナーが 4 方向に隣接するグラフに分割されますが、対角線は常に反対側のパリティ コーナーを接続します。 重要な単純化は、すべてのアクティブな頂点が少なくとも 1 つの選択されたエッジのコーナーであるため、接続性は、選択された対角線の端点によって形成されるグラフ内の接続性と同等であるということです。 

各セルを 2 つの固定グラフ ノード間のエッジとして扱います。 次に、セルごとに 1 つのエッジを正確に使用して、反転を最小限に抑えるスパニング ツリーがノード上に必要です。 これはまさに最小スパニング ツリー問題であり、各セルに 2 つの重み付きエッジが与えられ、セルごとに 1 つだけ選択します。 これは、両方の方向に対して Kruskal を使用した DSU によって解決できます。「反転されていない」エッジをコスト 0 として扱い、反転されたエッジをコスト 1 として扱いますが、セルごとに 2 つのエッジのうち 1 つだけを選択できるという制約があります。 これは、各セルをペアとして処理し、接続構造に違反しない、より安価で許容可能なオプションを選択することによって強制できます。 サイクルが形成されるときは、コストゼロのエッジが優先されます。 

より正確で実装可能な定式化は、ノードがグリッドの頂点であり、エッジがすべて可能な対角線であるグラフを構築することです。 エッジがセルごとにグループ化されている DSU Kruskal を実行します。セルごとに 2 つのエッジがあり、コストを増加させて処理しますが、セルがスパニング フォレストですでに使用されているかどうかを追跡することで、セルあたり最大 1 つを選択するようにします。 その結果、制約された MST が得られます。

 | 制約付き MST (DSU + セルあたり 2 エッジ) | O(nm α(nm)) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 各グリッドの角をグラフ内のノードとしてモデル化します。 各セルは、対角方向の向きに応じて、4 つの角の間にある可能性のある 2 つのエッジを正確に定義します。 1 つの向きは無料とみなされ、もう 1 つの向きには 1 回の反転がかかります。 

次に、総反転コストを最小限に抑えながら、選択した少なくとも 1 つのエッジに付随するすべての頂点が単一の連結コンポーネントに属するようにエッジを選択します。

1. すべてのグリッドの頂点 (コーナー) に ID を割り当てます。 これにより、幾何学的グリッドが標準のグラフ ノード セットに変わります。 コーナーを使用する理由は、対角線が自然にコーナーを接続するため、端点の一貫した表現が必要になるためです。 
2. ブロックされていない各セルについて、考えられる 2 つの対角エッジを構築します。 1 つのエッジは現在の方向に対応し、コスト 0 を持ち、もう 1 つのエッジは反転した方向に対応し、コスト 1 を持ちます。これにより、操作コストがエッジの重みに直接エンコードされます。 
3. これらすべてのエッジをリストに収集します。 各セルは正確に 2 つの候補エッジを提供しますが、最終的な構造では最大でも 1 つが選択されるようにします。 
4. すべてのゼロコストの選択肢が反転コストの選択肢の前に考慮されるように、エッジをコストでソートします。 これにより、可能な限り既存の対角線を維持することを積極的に好むようになります。 
5. すべての頂点に対して素の集合和集合構造を初期化します。 この構造は、ソリューションを構築するときに接続されたコンポーネントを維持します。 
6. コストの高い順にエッジを処理します。 各エッジについて、そのエンドポイントがすでに DSU に接続されているかどうかを確認します。 そうでない場合は、このエッジを追加し、その端点を結合します。 対応するセルを使用済みとしてマークし、後でその代替方向を選択できないようにします。 この制約の理由は、各セルが正確に 1 つの対角線に寄与する必要があるためです。 
7. 処理後、選択したエッジに属するすべての頂点が単一の DSU コンポーネント内に存在することを確認します。 そうでない場合は、有効な構成が存在しません。 
8. 答えは、コスト 1 で選択されたエッジの数、つまり適用された反転の数です。 

### なぜ効果があるのか

 各セルは、2 つの重み付けされたエッジの間の選択にきれいにマップされるバイナリ決定を強制します。 有効な最終構成は、セルごとに 1 つのエッジを選択することに正確に対応します。 すべてのアクティブな頂点を接続するすべての選択の中で、最小コストの選択が必要です。 DSU ベースの Kruskal プロセスでは、新しいコンポーネントを接続するエッジを常に受け​​入れることが保証されます。コストは 0 または 1 のみであるため、コスト 1 のエッジを遅らせても結果が改善されることはありません。 セルごとに 1 つのエッジという制約は、2 つのエッジのいずれかが選択されるとセルを使用済みとしてマークすることによって強制され、選択の競合を防ぎます。 

結果として得られる構造は、可能であれば単一のツリーに強制的に組み込まれたスパニング フォレストであり、反転の最小数は、選択されたコスト 1 のエッジの数に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1
        return True

def solve():
    T = int(input())
    out = []

    for _ in range(T):
        n, m = map(int, input().split())

        # map grid corners to ids
        def vid(i, j):
            return i * (m + 1) + j

        edges = []

        grid = [list(map(int, input().split())) for _ in range(n)]

        # Each cell connects 4 corners:
        # (i,j), (i,j+1), (i+1,j), (i+1,j+1)
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 2:
                    continue

                a = vid(i, j)
                b = vid(i, j + 1)
                c = vid(i + 1, j)
                d = vid(i + 1, j + 1)

                if grid[i][j] == 0:
                    # current: (a, d), flip: (b, c)
                    edges.append((0, a, d, i, j))
                    edges.append((1, b, c, i, j))
                else:
                    # current: (b, c), flip: (a, d)
                    edges.append((0, b, c, i, j))
                    edges.append((1, a, d, i, j))

        edges.sort(key=lambda x: x[0])

        dsu = DSU((n + 1) * (m + 1))
        used = set()
        cost = 0

        for w, u, v, i, j in edges:
            if (i, j) in used:
                continue
            if dsu.union(u, v):
                used.add((i, j))
                cost += w

        # check connectivity of all vertices that appear
        rep = None
        ok = True

        for i in range(n + 1):
            for j in range(m + 1):
                r = dsu.find(vid(i, j))
                if rep is None:
                    rep = r
                elif r != rep:
                    ok = False
                    break
            if not ok:
                break

        out.append(str(cost if ok else -1))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```DSU は、対角線を選択するときにグリッドの角をコンポーネントに圧縮します。 各セルは慎重に 2 つの可能なエッジに拡張され、ソートにより非反転構成が優先されることが保証されます。 の`used`set は、各セルが最終構造で選択された 1 つの対角線のみに寄与するという制約を強制します。 

孤立したコーナーは、選択したエッジによって形成される単一の接続コンポーネントに属している場合にのみ許可されるため、最終的な接続性チェックではすべての頂点がスキャンされます。 

## 実用的な例

 すべてのセルが最初にタイプ 0 に設定されている、2 × 2 の小さなグリッドを考えます。4 つのセルのそれぞれが、現在の対角線と反転された対角線という 2 つの候補エッジに寄与します。 DSU は隅々まで切断された状態から始まります。 最初にコスト 0 のエッジを処理するため、反転せずにできるだけ多くのコンポーネントを接続します。 サイクルが形成される場合は、そのエッジをスキップし、場合によっては後で反転エッジを取得します。

ここで、すべてのゼロコストの選択肢が、フリップによってのみ結合できる 2 つの切断されたクラスターを形成する場合を考えてみましょう。 このアルゴリズムは、最初にすべてのゼロコスト結合を使い果たし、次にフリップコストエッジの使用を開始します。そのような各エッジは、コンポーネント間の必要な構造的接続に直接対応します。

 ## 特殊なケース

 隣接セルのない単一のアクティブ セルは、接続性が空虚に真実である縮退グラフを形成します。 DSU は結合を一切実行せず、すべての頂点がアクティブな頂点を基準とした単一の暗黙的なコンポーネント内に留まるため、アルゴリズムはこれを処理します。 

対角線が交互に現れる市松模様のパターンでは、グラフが切り離されたコンポーネントに分割される可能性があります。 このような場合、コンポーネントを接続できるのはフリップ エッジのみであり、アルゴリズムは必要な最小限のフリップをカウントして、コスト 1 のエッジを必要になるまで正しく遅延させます。 

すべてのセルがブロックされているグリッドではエッジが生成されません。 DSU は重要なままであり、最終チェックに合格し、接続するものが何もないため、ゼロが返されます。
