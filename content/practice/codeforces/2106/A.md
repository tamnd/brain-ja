 ## 解決策
 ## 問題の理解

 バイナリ文字列が与えられます`s`長さの`n`、そして私たちは創造することを想像します`n`ちょうど 1 ビットを反転して新しい文字列を作成します`s`それぞれの立場で。 結果の文字列は、`n × n`ボード。 私たちの目標は、`1`この板にあります。 

たとえば、次の場合`s = 101`(長さ 3) の場合、行は次のように生成されます。最初の行は最初のビットを反転し、次のようになります。`001`; 2 行目は 2 番目のビットを反転して、`111`; 3 行目は 3 番目のビットを反転して、`100`。 すべてを数える`1`これらの行の s の合計は 5 になります。 

制約は小さいです。`n`最大 10 個、最大 1000 個のテスト ケースを含めることができます。 ボード上のセルの総数は`n^2`、最悪の場合のセル数は 100 です。これは、直接シミュレーションでも実行可能であることを示唆しています。 ただし、パターンを理解すると、すぐに数式を作成できるようになり、ネストされたループの必要性が回避されます。 

明らかではないエッジケースには、次のような状況が含まれます。`s`全てです`0`またはすべて`1`s. のために`s = 0000`、任意のビットを反転すると、正確に 1 つが作成されます。`1`その行には、`1`に等しい`n`。 のために`s = 1111`、1 ビットを反転すると、`1`の中へ`0`, したがって、の合計数は`1`に等しい`n*(n-1)`。 単純に合計する単純な実装`1`にいる`s`反転されたビットを考慮せずにすべての行を実行すると、これらの極端な場合には誤った結果が生成されます。 

## アプローチ

 最も簡単な解決策は総当たりです。各行を反復処理し、反転されたビットで文字列を構築し、その文字列をカウントします。`1`s. これは文字通りボードをシミュレートするため正しいですが、その複雑さは次のとおりです。`O(n^2)`テストケースごとに。 と`n`10 まではまだ実行可能です。`n^2`は最大 100 で、1,000 のテスト ケースにわたって 100,000 の操作が行われますが、これは許容範囲です。 

より洗練された解決策は、最終的なカウントに対する各ビットの寄与に注目することから生まれます。 少し入っていたら`s`は`1`、反転した行を除くすべての行に表示されます。 少し入っていたら`s`は`0`、反転された行にのみ寄与します。 させて`ones`の数になります`1`にいる`s`。 次に、の合計数は、`1`ボード上の は`ones * (n - 1) + (n - ones) * 1 = ones * (n - 1) + (n - ones) = ones * (n - 2) + n`。 この式は次のように答えを直接与えます。`O(n)`を数える時間`1`s、ボード全体を構築するよりも高速です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 計算を繰り返します`t`回。 
2. 各テスト ケースについて、整数を読み取ります。`n`そして文字列`s`。 
3. の数を数えます`1`にいる`s`そしてそれを変数に保存します`ones`。 
4. の合計数を計算します。`1`数式を使用してボード上で s を計算します。`total_ones = ones * (n - 2) + n`。 
5. 印刷`total_ones`。 

なぜ機能するのか: それぞれのビット`s`予測可能な方法で合計に寄与します。 あ`1`反転された行を除くすべての行に残りますが、`0`反転された行でのみ貢献します。 すべてのポジションにわたるこれらの寄与を合計すると、ボードを構築しなくても正しい合計が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    ones = s.count('1')
    total_ones = ones * (n - 2) + n
    print(total_ones)
```コードは最初にテスト ケースの数を読み取ります。 各テスト ケースについて、次のようになります。`n`そしてバイナリ文字列`s`。 の数を数える`1`と一緒です`s.count('1')`元の文字列の寄与を示します。 導出された式を適用すると、次の合計数が得られます。`1`ボード上にあります。 の`strip()`呼び出しにより、改行がカウントに干渉しないことが保証されます。

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

        ones = s.count('1')

## 特殊なケース

 のために`s = 0`(単一の文字)、ボードには次のセルが 1 つだけあります。`1`裏返した後、合計は 1 になります。`s = 1`、唯一の行が反転します`1`に`0`、合計は 0 になります。`total_ones = ones*(n-2)+n`これらを自動的に処理します:`n=1`そして`ones=0`、合計 = 0*(1-2)+1=1; のために`ones=1`、合計 = 1*(1-2)+1=0。 

すべての文字列の場合`1`さん、`s = 1111`、 我々は持っています`ones=4`そして`n=4`、与える`total_ones = 4*(4-2)+4=12`。 それぞれのオリジナル`1`は 4 行中 3 行に存在し、ボードを構築せずにボードの合計を確認します。 これは、極端な入力でも特別なケースを使用せずに正しいカウントを生成することを示しています。
