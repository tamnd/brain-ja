 ## 問題の理解

 直線のエッジで構成される 2 つの多角形が与えられ、一方の形状を他方に対して相対的に移動することができます。 それらの間の垂直方向の変位は固定されていません。実際の値を選択し、固定された垂直方向のシフトごとに、それらがちょうど接触または重なり始めるまで、1 つの形状を水平方向にどれだけ押し込むことができるかを知りたいと考えています。 

幾何学的には、一方のシェイプの各頂点は、水平方向にシフトした後、他のシェイプのエッジと衝突する可能性がありますが、これは垂直方向の位置合わせがそのシフトと一致している場合に限られます。 このような衝突の可能性はすべて、水平方向に移動できる距離の上限につながります。 垂直方向の変位が固定されている場合、答えはこれらすべての制約を同時に満たす最大の水平方向のシフトになります。 

重要な構造は、垂直変位は連続的ですが、整数バンド内でのみ問題となるということです。 垂直方向のシフトを次のように書くと、$y = z + \lambda$どこ$z$は整数であり、$\lambda \in [0,1]$次に、各ユニット内で、どの頂点がどのエッジと相互作用するかの組み合わせ構造が変化しないように取り除きます。 これにより、実際の全体にわたる継続的な最適化が削減されます。$y$整数を超える場合の有限集合に変換する$z$、および継続的な 1D 最適化$\lambda \in [0,1]$。 

それぞれの場合の制約は次の線形関数になります。$\lambda$、各区間内のタスクは、線形関数のセットの最小値を最大化することです。 

制約に関して言えば、頂点の総数が$n$、その後、各間隔は次のようになります。$O(n)$線形制約。 すべてのインタラクションをすべてのシステムにわたって評価する単純なソリューション$z$は 2 次以上になるため、同じジオメトリを繰り返し再計算することを避ける構造が必要です。 

単一の頂点が常にすべての頂点にわたって同じ境界エッジに対応すると仮定すると、微妙な失敗のケースが発生します。$\lambda$。 これは誤りです。アクティブな制約は間隔内で切り替わる可能性があり、これを無視すると不正確な最大値が得られます。 

たとえば、次の 2 つの制約が考えられます。$x \le \lambda$そして$x \le 1 - \lambda$。 

エンドポイントのみを評価する単純なアプローチ$\lambda = 0$そして$\lambda = 1$最大値が 1 であると誤って結論付けることになりますが、真の最大値は 0.5 です。$\lambda = 0.5$、アクティブな制約が切り替わります。 

この切り替え動作こそが、凸包テクニックが必要となる理由です。 

## アプローチ

 ブルートフォースのアイデアは単純です。 あらゆる垂直方向のシフトに対して$y$、すべての頂点とエッジの相互作用を計算し、すべての水平方向の上限を導出します。 次に、これらの境界の最小値を取得して、実現可能な最大の水平移動を取得します。 継続的にたくさんあるので、$y$、整数ストリップに離散化しますが、各ストリップ内ですべての制約を処理する必要があります。 あれば$n$幾何学的要素、これはおおよそ次のことにつながります。$O(n^3)$これは、要素の各ペアが制約を生成する可能性があり、候補シフトの各評価ですべての制約をスキャンする必要があるためです。 

より構造化されたアプローチでは、固定整数バンド内で次のことが観察されます。$z$、すべての制約は線形になります。$\lambda$。 したがって、幾何学的用語で考える代わりに、純粋に代数的な見方に切り替えます。$O(n)$一次関数とそれぞれについて$\lambda$実現可能な水平シフトは、これらの関数の最小値です。 この最小値を最大化したいと考えています$\lambda \in [0,1]$。 

これは典型的な凸型双対構造です。 線形関数の最小値は、凹状の区分的線形曲線を形成します。 最適な点は、二重の意味で見た場合、常にこれらのラインの上部エンベロープのブレークポイントにあります。 これにより、凸包トリックを使用して関連するラインのみを維持し、傾きによってソートし、支配的なラインを破棄することができます。

 ## アルゴリズムのチュートリアル

 各整数内での垂直シフト$z$、私たちは問題を処理します$\lambda \in [0,1]$。 

1. 垂直シフトを次のように書き換えます。$y = z + \lambda$と$\lambda \in [0,1]$。 これにより、連続的な自由度が、組み合わせ論が固定されたままの制限された区間に分離されます。 
2. 各頂点とエッジの相互作用について、次の形式の一次不等式を導出します。$x \le a\lambda + b$。 これは、垂直変位のパラメトリック形式を衝突条件に代入することで得られ、常に線形制約に単純化されます。$\lambda$。 
3. このような制約をすべて行のリストに収集します。$f_i(\lambda) = a_i \lambda + b_i$。 特定の場合に実現可能な水平方向のシフト$\lambda$は$F(\lambda) = \min_i f_i(\lambda)$。 
4. この間隔内の目標を最大化として再定式化します。$F(\lambda)$以上$\lambda \in [0,1]$。 これにより、幾何学的最適化が凹状の区分的線形関数の最大化に変換されます。 
5. すべてのラインを傾きで並べ替えます$a_i$、下部エンベロープに表示される可能性のあるラインのみを保持する凸包構造を構築します。 決して最小ではないライン$\lambda$建設中に廃棄されます。 
6. 結果として得られる船体の評価$[0,1]$下のエンベロープの最大値を見つけます。 これは、隣接する船体のラインの交点と間隔の端点をチェックすることによって行われます。 
7. すべての整数に対して同じ手順を繰り返します。$z$該当する範囲で回答し、最良の回答とさせていただきます。 

### なぜ効果があるのか

 固定用$z$、実行可能なすべての構成は、次の値の選択に正確に対応します。$\lambda$そして、線形関数の固定セットの中で最も厳しい制約を採用します。 したがって、最大化される関数は、点単位の線の最小値であり、凹型で区分的に線形です。 このような関数の最大値は、次のいずれかで発生する必要があります。$\lambda = 0$、$\lambda = 1$、または 2 つのアクティブなラインの交点にあります。 凸包の構築により、潜在的に最適なラインがすべて保持され、すべての候補ブレークポイントが考慮されることが保証されるため、区間内の最大値が正確に検出されます。

    # The real implementation depends on deriving lines (a_i, b_i) from geometry.
    #
    # We demonstrate the convex hull trick core used per z.

    def best_on_interval(lines):
        # lines: list of (a, b) representing a*x + b, we want max min over x in [0,1]
        # We compute lower envelope and check candidates.
        lines.sort()

        hull = []

        def bad(l1, l2, l3):
            # check if l2 is unnecessary
            (a1, b1), (a2, b2), (a3, b3) = l1, l2, l3
            return (b2 - b1) * (a1 - a3) >= (b3 - b1) * (a1 - a2)

        for ln in lines:
            while len(hull) >= 2 and bad(hull[-2], hull[-1], ln):
                hull.pop()
            hull.append(ln)

        def intersect_x(l1, l2):
            a1, b1 = l1
            a2, b2 = l2
            return (b2 - b1) / (a1 - a2)

        best = -10**30

        for i in range(len(hull)):
            a, b = hull[i]

            left = 0.0
            right = 1.0

            if i > 0:
                left = max(left, intersect_x(hull[i-1], hull[i]))
            if i + 1 < len(hull):
                right = min(right, intersect_x(hull[i], hull[i+1]))

            if left <= right:
                x = max(left, min(right, -b / a if a != 0 else 0.0))
                best = max(best, a * x + b)
                best = max(best, a * left + b, a * right + b)

        return best

 ## 特殊なケース

 クリティカルなエッジケースは、2 つの制約が正確に交差する場合です。$\lambda = 0$または$\lambda = 1$。 このような場合、エンドポイントのチェックだけでは正しいアクティブ領域が見つからなくなります。 凸包構造では両方のラインが維持され、境界での評価により正確さが保証されます。 

複数のラインが同じ傾きを共有する場合、別のエッジ ケースが発生します。 単純なハルの挿入では、傾きを比較するだけの場合、有効な制約が誤って破棄されてしまいます。 正しく処理すると、最良の切片を持つラインが保存され、タイによって潜在的に最適な制約が削除されなくなります。 

最後のエッジ ケースは、すべての拘束が平行である縮退ジオメトリです。 その状況では、エンベロープは単一の線形関数に減少し、最大値はエンドポイントの 1 つで発生します。 剪定後のハルには 1 行しか含まれていないため、アルゴリズムは自然にこの動作に崩壊します。
