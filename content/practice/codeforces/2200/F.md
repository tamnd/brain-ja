 ## 解決策
 ## 問題の理解

 私たちには粒子の集合が与えられており、それぞれにエネルギー値と反応性の限界があります。 粒子の反応性によって、リアクター内で粒子と共存できる他の粒子の最大数が決まります。 目標は、各粒子の反応性の制限を尊重しながら、総エネルギーを最大化する粒子のサブセットを選択することです。 さらに、追加の粒子を備えたショップがあり、各ショップの粒子について、その粒子を正確に購入できる場合に達成可能な最大総エネルギーを計算する必要があります。 重要なのは、エネルギーを最大化するのに役立たない場合、購入した粒子を最終サブセットに含めないことを選択することもあります。 

入力サイズでは、すべてのテスト ケースで最大 200,000 個のパーティクル、最大 10,000 個のテスト ケースが許可されます。 それぞれの粒子のエネルギーが到達できるのは、$10^9$。 サブセット空間は指数関数的であるため、これにより、すべてのサブセットを反復する単純なアプローチは即座に排除されます。 代わりに、粒子の数に応じて線形またはほぼ線形にスケールする戦略が必要です。 

複数の高エネルギー粒子の反応性が非常に低い場合、微妙なエッジ ケースが 1 つ発生します。 たとえば、(10,0)、(5,2)、(1,1) という 3 つの粒子について考えてみましょう。 エネルギー順に粒子を選択する素朴な貪欲なアプローチでは、エネルギー 10 の粒子とエネルギー 5 の粒子を含めようとするかもしれませんが、エネルギー 10 の粒子は他の粒子と共存できません。 正しいサブセットは、10 ユニットを生成する単一の 10 エネルギー粒子です。 

別のエッジケースは、ショップ粒子のエネルギーが非常に高いが反応性が低い場合に発生します。 これを含めると、Bessie の元の粒子からのより高い累積エネルギーの組み合わせを含めることができなくなる可能性があります。 アルゴリズムは、購入した粒子が全体の合計に役立つかどうかを慎重に検討する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各ショップ粒子について、ベッシー粒子とショップ粒子のすべての有効なサブセットを列挙し、それらの合計エネルギーを計算し、最大値を選択できます。 これはあらゆる組み合わせを考慮するため正確性を保証しますが、すぐに失敗します。$n = 10^5$粒子の場合、サブセットの数は$2^{10^5}$、これは実現不可能です。 

重要な観察は、粒子が反応性を持っているということです。$y$最大でも共存できる$y$他の粒子。 これは、上部のみが$y+1$最高エネルギー粒子は、この粒子が含まれる場合、最大エネルギーに寄与します。 エネルギー別に粒子を並べ替え、プレフィックスの合計を維持することで、上位の合計を効率的に計算できます。$k$粒子。 貪欲な洞察は、特定の粒子の最適なサブセットには常にその粒子自体と最大の粒子が含まれるということです。$y$他の粒子（可能であれば）。反応性の制限に違反することなく、より小さなエネルギーの粒子をより高いエネルギーの粒子に置き換えることができるためです。 

また、ショップのパーティクルを効率的に処理する必要もあります。 毎回すべてのベッシー粒子を考慮して各ショップ粒子の最大エネルギーを再計算する代わりに、上位のエネルギーとプレフィックスの合計を事前計算し、次にショップ粒子ごとに上位のベッシー粒子がいくつ共存できるかを決定し、有利な場合はそれをショップ粒子のエネルギーと組み合わせます。

 | ブルートフォース | O(m * 2^n) | O(n+m) | 遅すぎる |
 | 最適 | O(n log n + m log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、ベッシー粒子の数を読み取ります。$n$そしてショップパーティクル$m$。 ベッシーの粒子とショップの粒子のエネルギーと反応性を読み取ります。 
2. ベッシー粒子をエネルギーの降順に並べ替えます。 これらのエネルギーのプレフィックスの合計を計算して、上位の合計が$k$エネルギーは一定時間でクエリできます。 
3. 各ショップ パーティクルに対して、ショップ パーティクル自体を考慮して候補セットを初期化します。 共存できる追加粒子の最大数、つまり反応性を決定します。$y$。 
4. 上部を選択します$y$Bessie 粒子からのエネルギー。ショップ粒子が Bessie 粒子にすでに含まれている場合はスキップします。 効率的に計算するには、プレフィックスの合計を使用します。 
5. ショップ粒子エネルギーの合計と選択した上位ベッシー粒子エネルギーの合計として合計エネルギーを計算します。 ショップパーティクルを含めた場合と含めない場合で得られる最大エネルギーを追跡します。 
6. テスト ケース内のすべてのショップ パーティクルに対してこの手順を繰り返し、結果を出力します。 

これが機能する理由は、特定の粒子の最大エネルギーを持つサブセットには常に粒子自体 (考慮した場合) とその反応性と互換性のある最高エネルギー粒子が含まれるためです。 エネルギー別に並べ替えることで、より高い合計の組み合わせを見逃すことがなくなり、プレフィックス合計により効率的な累積が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        bessie = []
        for _ in range(n):
            x, y = map(int, input().split())
            bessie.append((x, y))
        shop = []
        for _ in range(m):
            x, y = map(int, input().split())
            shop.append((x, y))

        bessie.sort(reverse=True)  # sort by energy descending
        energies = [x for x, _ in bessie]
        prefix = [0]
        for e in energies:
            prefix.append(prefix[-1] + e)

        # compute max energy ignoring shop particles
        max_energy_no_shop = 0
        for x, y in bessie:
            take = min(y+1, n)
            max_energy_no_shop = max(max_energy_no_shop, prefix[take])

        res = []
        for sx, sy in shop:
            # maximum number of other particles we can take with shop particle
            take = min(sy, n)
            # candidate energies: top take Bessie energies, possibly excluding a Bessie particle identical to shop
            total = sx + prefix[take]
            # if shop particle is stronger than any Bessie particle, we may have double-counted
            for bx, by in bessie:
                if bx == sx:
                    total = max(total, sx + prefix[min(sy, n-1)])
                    break
            total = max(total, max_energy_no_shop)
            res.append(str(total))
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```この解決策は、最もエネルギーの高い粒子が常に最初に考慮されるように、Bessie の粒子を分類することから始まります。 プレフィックス合計を使用すると、上位の合計を定数時間で計算できます。$k$エネルギー。 ショップ粒子ごとに、ショップ粒子と共存できる最高エネルギーのベッシー粒子を含むエネルギーを考慮し、潜在的な重複を処理します。 最後に、これをショップ粒子を含まずに達成可能な最大エネルギーと比較し、世界最大値を保証します。
