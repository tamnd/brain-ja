 ## 問題の理解

 有効な長さの数を数えています`n`非常に特殊な隣接ルールに基づいて形成できます。 連続する数字のすべてのペアが素数である 2 桁の数字を形成する場合、その数字は有効であるとみなされます。 桁自体は 10 進数からのものですが、制約は個々の桁に関するものではなく、サイズ 2 のスライディング ウィンドウに関するものです。 

したがって、番号が`d1 d2 d3 ... dn`、次に各ペア`(d1d2), (d2d3), ..., (d(n-1)dn)`2 桁の素数でなければなりません。 これにより、問題は、2 つの数字の連結が 10 から 99 までの素数を形成するかどうかによって遷移が左右される、制約された数字上のウォークに変わります。 

入力は単一の整数です`n`、非常に大きくなる可能性があり、最大`10^15`。 出力は、有効な長さの桁のシーケンスの数です。`n`、モジュロ`1e9 + 7`。 

のサイズ`n`長さを超える動的プログラミングは直ちに除外されます。 平`O(n)`それは不可能です、なぜなら`n`天文学的に大きくなる可能性があります。 唯一実現可能な方向は、遷移を圧縮し、固定状態空間上で行列のべき乗または反復二乗を使用することです。 

先頭の数字について考えると、微妙な特殊なケースが現れます。 この問題では最初の桁が制限されていないため、シーケンスは任意の桁で始まる可能性があります。`0-9`ただし、通常、数値の先頭にゼロを付けることはできません。 ここでは標準的な整数を構築しているのではなく、数字列を構築しているので、`0`は開始数字として有効です。 

もう 1 つの重要な観察は、数字は数値ではなく状態であるということです。 隣接規則は、前の数字にのみ依存します。 これにより、構造は最大 10 個のノードを持つグラフになります。 

## アプローチ

 ブルート フォース ソリューションでは、有効な長さのすべての数字列を構築しようとします。`n`。 各位置について、すべての桁を試します`0-9`前の数字とのペアが素数を形成するかどうかを確認します。 これはおおよそ次のことにつながります`10^n`ほとんどの遷移は多くの桁で許可されるため、最悪の場合は可能性があります。 たとえ`n = 20`、これはすでに実行不可能であり、`n = 10^15`それは全く不可能です。 

重要な構造上の観察は、数値の有効性は使用される最後の桁のみに依存するということです。 最後の数字がわかっていれば、その後の選択は、どの数字がその数字と 2 桁の素数を形成するかによってのみ決まります。 これにより、長さの歩行を数えるという問題が軽減されます`n-1`10 個のノードを持つ有向グラフで、エッジは有効な素数遷移に対応します。

行列のサイズは一定であるため、べき乗には次の時間がかかります。`O(10^3 log n)`これは、`n = 10^15`。

 ## アルゴリズムのチュートリアル

 数字をグラフ内のノードとして再解釈します。 有効な 2 桁の素数はそれぞれ、10 の位から 1 の位までの有向辺を定義します。 

まず、すべての 2 桁の素数を事前計算します。 これらは 10 から 99 までの素数です。 そのような素数ごとに`p`、抽出します`u = p // 10`そして`v = p % 10`、からの移行をマークします`u`に`v`。 

次に、10 × 10 の隣接行列を構築します。`T`、 どこ`T[u][v] = 1`移行が許可される場合。 

第三に、ベクトルを構築します。`dp0`サイズは 10 で、すべてのエントリは 1 です。これは、任意の桁が長さ 1 の有効なシーケンスの開始桁になり得ることを表します。 

4番目に、計算します`T^(n-1)`高速累乗を使用します。 これは、複数のステップにわたってトランジションがどのように構成されるかを表します。 

五番目に、掛け算をします`dp0`このマトリックスパワーによって。 結果のベクトル`dp`数字ごとに、有効な長さのシーケンスの数を返します。`n`その数字で終わります。 

6 番目に、次のすべてのエントリを合計します。`dp`有効なシーケンスの総数を取得します。 

これが機能する理由は単純な不変条件に関係しています: 処理後`k`ステップ、`dp[d]`有効な長さのシーケンスの数に等しい`k+1`数字で終わるもの`d`。 各行列の乗算は、すべてのシーケンスを 1 つの有効な桁遷移だけ拡張し、すべてのステップで正確さを維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def is_prime(x):
    if x < 2:
        return False
    for i in range(2, int(x**0.5) + 1):
        if x % i == 0:
            return False
    return True

def mul(A, B):
    n = 10
    C = [[0] * n for _ in range(n)]
    for i in range(n):
        Ai = A[i]
        Ci = C[i]
        for k in range(n):
            if Ai[k] == 0:
                continue
            aik = Ai[k]
            Bk = B[k]
            for j in range(n):
                Ci[j] = (Ci[j] + aik * Bk[j]) % MOD
    return C

def mpow(M, e):
    n = 10
    R = [[0] * n for _ in range(n)]
    for i in range(n):
        R[i][i] = 1
    while e > 0:
        if e & 1:
            R = mul(R, M)
        M = mul(M, M)
        e >>= 1
    return R

def main():
    n = int(input().strip())

    primes = [x for x in range(10, 100) if is_prime(x)]

    T = [[0] * 10 for _ in range(10)]
    for p in primes:
        u = p // 10
        v = p % 10
        T[u][v] = 1

    if n == 1:
        print(10)
        return

    P = mpow(T, n - 1)

    ans = 0
    for i in range(10):
        for j in range(10):
            ans = (ans + P[i][j]) % MOD

    print(ans)

if __name__ == "__main__":
    main()

機能`mul`モジュロ演算で 10 × 10 の行列乗算を実行します。 行列のサイズが固定されており小さいため、トリプル ループは安全であり、内側のループは定数因数を減らすためにゼロ エントリをスキップします。 

機能`mpow`行列に対して 2 進累乗を実行し、必要に応じて繰り返し 2 乗して適用します。 これにより、非常に大きなサイズの処理が可能になります`n`。 

最終的な答えは、結果の行列のすべてのエントリを合計することによって計算されます。これは、すべての可能な開始桁とすべての可能な終了桁に正確に対応します。`n-1`トランジション。 

## 実用的な例

 小さなケースを考えてみましょう。`n = 2`。 有効な 2 桁の数値を数えていますが、数値自体は 2 桁の素数でなければなりません。 マトリックスは有効なペアを直接エンコードします。 

| ステップ | アクション | 状態 |
 | --- | --- | --- |
 | 1 | 素数を構築する | {11、13、17、19、23、...} |
 | 2 | ビルドトランジション | 1→1、1→3、1→7、1→9 などのエッジ |
 | 3 | 計算結果 | すべてのエッジを数える |

| ステップ | アクション | 状態 |

これは、DP がパス数を自然に蓄積する仕組みを示しています。

import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    input = _sys.stdin.readline

    MOD = 10**9 + 7

    def is_prime(x):
        if x < 2:
            return False
        for i in range(2, int(x**0.5) + 1):
            if x % i == 0:
                return False
        return True

    def mul(A, B):
        n = 10
        C = [[0] * n for _ in range(n)]
        for i in range(n):
            for k in range(n):
                if A[i][k]:
                    for j in range(n):
                        C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD
        return C

    def mpow(M, e):
        n = 10
        R = [[0]*n for _ in range(n)]
        for i in range(n):
            R[i][i] = 1
        while e:
            if e & 1:
                R = mul(R, M)
            M = mul(M, M)
            e >>= 1
        return R

    n = int(input().strip())
    primes = [x for x in range(10, 100) if is_prime(x)]

    T = [[0]*10 for _ in range(10)]
    for p in primes:
        T[p//10][p%10] = 1

    if n == 1:
        return "10"

    P = mpow(T, n-1)
    ans = 0
    for i in range(10):
        for j in range(10):
            ans = (ans + P[i][j]) % MOD

    return str(ans)
