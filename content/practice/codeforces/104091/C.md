 ## 問題の理解

## アプローチ

 最も直接的な解決策は、すべての`n`桁数を指定し、隣接するすべてのペアをテストし、有効なものを数えます。 すべての候補者が独立して検査されるため、これは明らかに正しいです。 残念ながら、実行時間は次のように比例します。`9 × 10^(n-1)`、おおよそ次のようになります`10^27`最悪の場合の運用。 

この条件は、隣接する数字のみを関連付けます。 前の桁が固定されると、前の桁は重要ではなくなります。 これはまさに、最後の桁に対する動的計画法が効果的な状況です。 

重要な観察は、次のように割り切れることです。`3`は、隣接する 2 桁の剰余のみに依存します。 最後の桁だけを覚えていれば、左から右に数字を組み立てることができます。 数字で終わる有効なプレフィックスの数がすでにわかっている場合`d`、次にすべての数字`x`満足のいく`(10d + x) % 3 == 0`これらのプレフィックスを拡張できます。 

可能な最後の桁は 10 個だけであるため、動的プログラムの各層には 10 個の状態のみが含まれます。 各状態は最大 10 回の遷移を試行し、1 桁あたり約 100 回の操作のみが行われます。

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`dp`サイズの`10`、 どこ`dp[d]`数字で終わる有効なプレフィックスの数を格納します`d`。 
2. 最初の桁を初期化します。 数字`1`を通して`9`それぞれが 1 つの有効な長さのプレフィックスを形成します`1`ので、設定します`dp[1]`を通して`dp[9]`に`1`。 離れる`dp[0]`に等しい`0`先頭のゼロは禁止されているためです。 
3. 繰り返します`n - 1`残りのポジションごとに 1 回。 
4. 新しいアレイを作成する`next_dp`ゼロで埋められています。 
5. 前の可能なすべての数字について`a`そして次の可能なすべての数字`b`、どうかを確認してください`(10 * a + b) % 3 == 0`。 そうであれば、で終わるすべての有効なプレフィックスが`a`によって延長できます`b`ので、追加します`dp[a]`に`next_dp[b]`。 
6. 交換する`dp`と`next_dp`。 
7. すべての位置を処理した後、次のすべての値を合計します。`dp`。 各状態は異なる最終桁で終わる有効な数値を表すため、それらの合計が必要な答えとなります。 

### なぜ効果があるのか

 動的計画法の不変条件は、処理後の`k`数字、`dp[d]`有効な数と同じです`k`最後の数字が次の数字の接頭辞`d`。 

ゼロ以外のすべての数字が長さ 1 の有効なプレフィックスを 1 つだけ形成するため、初期化は正しく行われます。 

移行中、すべての拡張機能は 1 回だけ考慮されます。 新しく作成された隣接ペアが次の値で割り切れる場合にのみ、遷移が許可されます。`3`。 無効な拡張子が追加されたり、有効な拡張子が省略されたりすることはありません。 

処理された長さの帰納法により、不変式は反復ごとに真のままになります。 結局`n`数字は処理されており、すべてが美しい`n`桁番号は最後の桁に応じて 1 つの状態に属するため、すべての状態を合計すると正しい答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

dp = [0] * 10
for d in range(1, 10):
    dp[d] = 1

for _ in range(n - 1):
    ndp = [0] * 10
    for a in range(10):
        if dp[a] == 0:
            continue
        for b in range(10):
            if (10 * a + b) % 3 == 0:
                ndp[b] += dp[a]
    dp = ndp

print(sum(dp))
```初期化は、考えられるすべての 1 桁のプレフィックスを表します。 最終的な数値には正確な値が含まれている必要があるため、数字のゼロは除外されます。`n`数字。 

反復ごとにプレフィックスが 1 桁拡張されます。 現在の位置の遷移が同じレイヤー内の他の遷移に影響を与えてはいけないため、新しい配列が使用されます。 

カウントが 0 である状態をスキップすることは正確性のために必要ありませんが、不必要な作業を避けることができます。 

Python の整数は自動的に任意のサイズに拡張されるため、32 ビット整数の範囲を超える場合でも、答えは適合します。
