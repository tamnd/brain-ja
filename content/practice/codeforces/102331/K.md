 ## 解決策
 ## 問題の理解

 35 文字のアルファベット、つまり数字にわたる長さ (n) の文字列を数える必要があります。`1`を通して`9`そして小文字。 文字列は、長さが (n-k) 以上のタンデムリピートを含まない場合に有効です。 

タンデム リピートは、2 つの同一の連続する半分から構成される偶数長の部分文字列です。 例えば、`abab`は、その 2 つの半分が両方とも同じであるため、タンデムリピートです。`ab`、 その間`abca`そうではありません。 出力は、このような十分に長いタンデム反復をすべて回避する長さ (n) 文字列の数のモジュロ (998244353) です。 

制約の有用な部分は、(k) の値が小さいことです。 (n) は 100 にできますが、すべての禁止された繰り返しの長さは少なくとも (n-k) であるため、禁止できる間隔は少数しかありません。 実際、タンデム反復候補の数は (O(k^2)) であり、指定された範囲では最大でも数十です。 これにより、はるかに強力な枝刈り観察の後に、候補リピートに対する包含/除外検索が実行可能になります。 

すべての文字列を単純に列挙することは完全に不可能です。 (n=100) の場合、(35^{100})、約 (2.5\cdot10^{154}) 個の文字列があります。 1 つの文字列のチェックに (O(n^2)) しかかからなかったとしても、合計はすでに (10^{158}) 回ほどの操作になります。 すべての候補部分文字列とすべての文字比較を直接チェックすることは、(O(35^n n^3)) に近くなります。 

実装が不正な禁止間隔のセットを黙って使用する可能性がある境界ケースがいくつかあります。 のために`1 16`、すべてのタンデムリピートは正の偶数の長さを持ち、文字列には 1 文字しかないため、タンデムリピートは存在しません。 正しい答えは、`35`。 

のために`4 0`、長さ 4 のタンデム リピートのみが対象となります。 禁止条件は (s_0=s_2) と (s_1=s_3) だけなので、答えは (35^4-35^2=1499400) になります。 ここで長さ 2 の繰り返しも禁止する解決策は間違っています。 

のために`2 16`、しきい値は (2-16=-14) であるため、すべてのタンデム リピートが対象となります。 唯一可能なタンデム繰り返しは文字列全体です。これは、2 つの文字が等しくてはならないことを意味します。 答えは (35\cdot34=1190) です。 しきい値を 2 に固定したり、(k<n) と仮定したりする不注意な実装は、このケースを誤って処理する可能性があります。 

のために`3 0`、しきい値は 3 ですが、タンデムリピートは偶数の長さである必要があります。 したがって、禁止された部分文字列はまったくなく、すべての文字列が有効です。 答えは (35^3=42875) です。 これにより、パリティをチェックせずに、しきい値自体を可能な繰り返しの長さとして扱うコードが捕捉されます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 (35^n) 個の文字列をすべて生成し、禁止されたタンデムリピートが含まれているかどうかを確認します。 少なくとも (n-k) の長さの偶数区間ごとに、その前半と後半を比較します。 K-POP 文字列の定義はまさにこれらの間隔が存在しないことであるため、このテストは正しいです。 問題は文字列の数です。(n=100) では、検索スペースはおよそ (2.5\cdot10^{154}) であるため、非現実的に安価なテストであっても、このアプローチを有用にすることはできません。 

主な変更点は、文字列の列挙を停止し、代わりに禁止されたパターンを列挙することです。 特定のタンデムリピートでは、キャラクター自体を知る必要はありません。 ポジション間に平等制約を課すだけです。 たとえば、次のようなイベントが`abab`(0\ldots3) の位置で発生すると、(s_0=s_2) および (s_1=s_3) が課されます。 

いくつかのタンデムリピート イベントを選択し、それらすべてが同時に発生するように要求するとします。 すべての等価制約は 2 つの文字列位置を接続します。 制約は素集合の和集合構造で表すことができます。 結果の等式グラフに (c) 個の連結成分がある場合、すべての成分は 35 文字のうちの 1 つを独立して選択できるため、正確に (35^c) 個の文字列が選択されたすべてのイベントを満たします。 

これにより、包含と排除が行われます。 禁止イベントが (E_1,E_2,\ldots,E_m) の場合、有効な文字列の数は

 [
 35^n-\sum_i |E_i|+\sum_{i<j}|E_i\cap E_j|-\cdots。 
】

 明らかな問題は、イベントが約 80 個存在する可能性があるため、(2^m) 個のサブセットが多すぎることです。 重要な観察は、この包含と除外の多くの分岐が完全に冗長であるということです。 すでに選択されているイベントによって、現在のイベント (E_i) に必要なすべての等価性が強制されるとします。 この場合、(E_i) を追加しても連結成分はまったく変わりません。 (E_i) を含むすべての交差は、(E_i) を含まない対応する交差と同一ですが、反対の包含/除外符号を持ちます。 これら 2 つの貢献は、後のイベントのすべての可能な選択肢を含めてキャンセルされます。 ブランチ全体をすぐに破棄できます。 

ロールバック DSU を使用して接続されたコンポーネントを維持します。 イベントが追加されると、成功した結合をすべて記録し、再帰して、それらの結合を正確に元に戻します。 最初に長いタンデムリピートを処理します。 この順序により、強い制約が早期に出現し、後のイベントが冗長になることが多くなります。 公式社説では、同様の包含・除外および構成要素の取り消しの考え方を説明し、効果的な命令の 1 つとしてリピートの長さを短くすることを推奨しています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(35^nn^3)) | (O(n)) | 遅すぎる |
 | ロールバック DSU による包含/除外 | (O(Bn\log n)) | (O(nk^2)) | 承認済み |

 ここで (B) は、冗長枝刈り後に生き残る再帰ノードの数です。 理論上の最悪のケースでも検索は指数関数的ですが、この構築の要点は、(k\le16)、イベントは (O(k^2)) 個しかなく、ほとんどの包含-除外分岐は現在のイベントがすでに暗示されるとすぐに終了するということです。 

## アルゴリズムのチュートリアル

1. 可能な限りの禁止されたタンデム リピートを生成します。 (L\ge n-k) の偶数の長さ (L) の場合、(0) から (n-L) までの開始位置 (l) を選択します。 (h=L/2) の場合、イベントは (0\le j<h) ごとに (s_{l+j}=s_{l+h+j}) を必要とします。 部分文字列自体ではなく、それらの位置ペアを保存します。 
2. イベントを長さの降順に並べ替えます。 繰り返しが長くなると、より多くの等価性制約が課されるため、後のイベントが冗長になる傾向があります。 正確な順序付けは正当性証明の一部ではありませんが、検索ツリーの実際のサイズに大きな影響を与えます。 
3. 文字列位置ごとに 1 つのコンポーネントを使用してロールバック DSU を初期化します。 最初は (35^n) 個の完全に制限のない文字列に対応する (n) 個のコンポーネントがあります。 
4. イベントを再帰的に処理します。 まず、現在のイベントが包含/除外の対象として選択されていない分岐を選択します。 次に、現在のイベントのすべての等価制約を一時的に DSU に追加し、パーティションを実際に変更したユニオンの数をカウントします。 
5. イベントを追加しても結合が成功しない場合、そのイベントは選択したイベントによってすでに暗示されています。 その包含分岐と除外分岐は正確にキャンセルされるため、後のイベントを検査せずに、この再帰状態からゼロを返します。 
6. イベントが少なくとも 1 つの新しい等価性を導入する場合は、イベントを含めて再帰します。 その包含-除外符号は、除外されたブランチに対して負であるため、除外されたブランチから含まれたブランチの結果を減算します。 
7. すべてのイベントが処理されると、現在の DSU には、選択したイベントのサブセットに必要な等価性が正確に含まれます。 (c) 個の連結コンポーネントがある場合、(35^c) 個の互換性のある文字列が存在します。 その値を返します。 
8. すべてのブランチを含めた後、DSU を保存されたスナップショットにロールバックします。 これにより、現在のイベントが考慮される前に存在していたパーティションが正確に復元されるため、兄弟再帰ブランチが互いに影響を与えることはありません。 

機能する理由: すべての再帰状態で、DSU は現在の包含/除外パスで選択されたイベントによって課される等価性を正確に表します。 連結コンポーネントは、同じ文字を強制的に保持する位置の 1 セットであり、異なるコンポーネントは独立しており、リーフで (35^c) の割り当てが与えられます。 現在のイベントが新しいコンポーネント マージを作成しない場合、その制約は選択したイベントによってすでに暗黙的に指定されています。 その後のイベントのすべてのサブセットについて、現在のイベントとの交差はイベントなしの交差と同一になりますが、2 つの包含と除外の記号は反対になります。 それらの寄与はキャンセルされるため、ゼロを返すことは数学的に正確です。 すべての非冗長イベントは、可能な包含と除外の両方の選択肢で考慮されます。これは、すべてのサブセットが正しい符号で表されることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
ALPHABET = 35

def count_kpop(n, k):
    threshold = n - k

    events = []

    # An event is a forbidden tandem repeat.
    # For length L = 2*h starting at l, impose
    # s[l+j] == s[l+h+j] for 0 <= j < h.
    for L in range(max(2, threshold), n + 1):
        if L & 1:
            continue

        h = L // 2
        for l in range(n - L + 1):
            pairs = [(l + j, l + h + j) for j in range(h)]
            events.append((L, l, pairs))

    # Longer repeats first give much better pruning.
    events.sort(key=lambda x: (-x[0], x[1]))

    m = len(events)

    # powers[c] = 35^c mod MOD
    powers = [1] * (n + 1)
    for i in range(1, n + 1):
        powers[i] = powers[i - 1] * ALPHABET % MOD

    parent = list(range(n))
    size = [1] * n
    history = []
    components = n

    def find(x):
        while parent[x] != x:
            x = parent[x]
        return x

    def unite(a, b):
        nonlocal components

        a = find(a)
        b = find(b)

        if a == b:
            return False

        if size[a] < size[b]:
            a, b = b, a

        # Store enough information to undo this union.
        history.append((b, a, size[a]))

        parent[b] = a
        size[a] += size[b]
        components -= 1
        return True

    def rollback(snapshot):
        nonlocal components

        while len(history) > snapshot:
            b, a, old_size_a = history.pop()
            parent[b] = b
            size[a] = old_size_a
            components += 1

    sys.setrecursionlimit(1000000)

    def dfs(idx):
        # All selected events have now been fixed.
        if idx == m:
            return powers[components]

        # If all positions are already equal, every remaining event
        # is implied, so all inclusion-exclusion contributions cancel.
        if components == 1:
            return 0

        # Exclude the current event.
        result = dfs(idx + 1)

        # Include the current event.
        snapshot = len(history)
        changed = False

        for a, b in events[idx][2]:
            if unite(a, b):
                changed = True

        # The event was already implied by the current constraints.
        # Including or excluding it gives identical intersections,
        # so their contributions cancel completely.
        if not changed:
            rollback(snapshot)
            return 0

        result -= dfs(idx + 1)
        result %= MOD

        rollback(snapshot)
        return result

    return dfs(0)

def main():
    n, k = map(int, input().split())
    print(count_kpop(n, k))

if __name__ == "__main__":
    main()
```の最初の部分`count_kpop`重要なイベントを正確に構築します。 下限は`max(2, threshold)`タンデムリピートは正の偶数の長さを持つためです。 奇数の間隔はタンデムリピートにできないため、パリティを個別にテストします。 

各イベントは、等しい位置のペアを直接保存します。 これにより、再帰中の文字列操作が回避されます。 長さ (2h) の繰り返しの場合、正確に (h) 個の等価制約があります。 

再帰のリーフには現在の数の DSU コンポーネントのみが必要なため、累乗配列は事前に計算されます。 ルックアップ (35^c) は、リーフごとにべき乗剰余演算を実行するのではなく、定数時間になります。 

DSU は意図的にパス圧縮を使用しません。 パス圧縮によりロールバックが複雑になります。`find`この操作により、多くの親ポインターが変更される可能性があります。 ここでは、位置が (n\le100) しかなく、すべての検索操作が対数に保たれるため、サイズによる結合で十分です。 

の`history`stack には、成功した結合を元に戻すために必要な正確な情報が含まれています。 ユニオンが失敗しても DSU は変更されないため、記録する必要はありません。 

最も微妙な部分は、`changed`テスト。 イベントに等価対があるかどうかを尋ねるだけでは十分ではありません。 どのイベントもそうです。 重要なのは、少なくとも 1 つの等式が 2 つの現在異なるコンポーネントを接続しているかどうかです。 何も行われない場合、イベントは新しい情報を追加せず、その包含/除外サブツリー全体がキャンセルされます。 

の減算`result -= dfs(idx + 1)`は包含と除外の記号です。 イベントのないブランチは現在の状態に対してプラスに寄与しますが、イベントのあるブランチはマイナスに寄与します。 最後のモジュロ演算では、結果が必要な範囲内に保たれます。 

Python の整数はオーバーフローしないため、すべての算術演算は安全です。 包含除外により負の中間値と非常に大きな正の値が生成される可能性があるため、モジュロが再帰的結果に適用されます。 

## 実用的な例

 サンプル 1 の入力は次のとおりです。`1 16`。 長さ 1 の文字列内には偶数間隔が収まらないため、イベント リストは空になります。 

| イベントインデックス | コンポーネント | アクション | 貢献 |
 | --- | --- | --- | --- |
 | 0 | 1 | イベントが存在しません | (35^1=35) |

 再帰はすぐにリーフに到達し、(35) を返します。 これは、(k) の値に関係なく、非常に小さな文字列にタンデム反復を含めることができない境界ケースを示しています。 

サンプル 2 の入力は次のとおりです。`4 0`。 しきい値は 4 なので、禁止されるイベントは文字列全体だけです。 その 2 つの半分の長さは 2 で、等価制約 (s_0=s_2) および (s_1=s_3) が与えられます。 

| イベントインデックス | コンポーネント | アクション | 貢献 |
 | --- | --- | --- | --- |
 | 0 | 4 | イベントを除外する | (35^4=1500625) |
 | 0 | 2 | イベントを含める | (-35^2=-1225) |
 | 1 | 2 | 葉 | (35^2=1225) |

 最終的な値は (1500625-1225=1499400) です。 位置 0 と 2 が結合され、位置 1 と 3 が結合されるため、イベントが組み込まれた後、DSU には 2 つのコンポーネントがあります。 これは、長さ 4 のタンデムリピートを含む (35^2) 文字列と正確に一致します。 

サンプル 3 の入力は次のとおりです。`15 5`。 しきい値は 10 なので、偶数の長さ 10、12、および 14 のみが考慮されます。 可能な開始位置ごとに 1 つのイベントが作成され、長い等価パターンの小さなコレクションが得られます。 長さが減少する順序により、DSU は短いイベントがテストされる前に強力な制約を蓄積できます。 

| 繰り返しの長さ | 可能な開始 | イベントごとの等価ペア |
 | --- | --- | --- |
 | 14 | 0、1 | 7 |
 | 12 | 0、1、2、3 | 6 |
 | 10 | 0、1、2、3、4、5 | 5 |

 包含-除外再帰では、すべての非冗長交差について互換性のある割り当てが評価され、すべての冗長分岐がキャンセルされます。 結果の値は次のとおりです。`911125634`、サンプル出力と一致します。

| スペース | (O(nk^2)) | (O(k^2)) 個のイベントがあり、それぞれに (O(n)) 個の等価ペアとロールバック DSU が含まれています。

 ## 特殊なケース

 のために`1 16`の場合、イベント生成ループは長さ 2 で始まり、すでに (n) より大きくなります。 イベント リストは空であるため、DSU は 1 つのコンポーネントから開始され、再帰は (35^1=35) を返します。 長さ 1 の人為的な繰り返しは導入されません。 

のために`4 0`、しきい値は正確に 4 です。生成された唯一のイベントは、長さが 4 で、2 つの等価ペアを持ちます。 include ブランチにより DSU のコンポーネントが 4 つから 2 つに減り、(35^2) 個の不正な文字列が発生します。 包含-排他は、すべての (35^4) 文字列からそれらを減算し、次のようになります。`1499400`。 

のために`2 16`、しきい値は負ですが、実装によって長さが 0 または 1 の間隔が誤って生成されることはありません。 長さ 2 から開始するため、イベントが 1 つだけ検索され、2 つの位置が等しい必要があります。 含まれるイベントは 1 つの DSU コンポーネントを残すため、その寄与は (35) となり、結果は (35^2-35=1190) になります。 

のために`3 0`、しきい値は 3 です。ループは 3 から 3 までの長さを考慮しますが、3 は奇数であるため拒否されます。 イベントは残っていないため、すべての (35^3=42875) 文字列がカウントされます。 このため、イベントの構築中にパリティをチェックすることが不可欠です。 

最大サイズの場合`100 0`、しきい値は 100 です。禁止されたタンデム リピートにできるのは完全な文字列のみです。 その 2 つの半分の長さは 50 であるため、等価制約により、ちょうど 50 個の独立した文字の選択肢が残ります。 結果は (35^{100}-35^{50}) モジュロ (998244353) であり、再帰にはイベントが 1 つだけ含まれるため、このケースは文字列の最大長にもかかわらず、基本的に最も単純な包含/除外インスタンスになります。
