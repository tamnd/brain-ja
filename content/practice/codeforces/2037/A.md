 ## 解決策
 ## 問題の理解

 小さな整数の配列が与えられます。 Kinich は、各インデックスを最大 1 回使用できるという制限付きで、等しい値を含む 2 つの異なるインデックスを繰り返し選択することでポイントを獲得できます。 タスクは、各テスト ケースのそのようなペアの最大数を決定することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、配列の長さと配列要素自体を指定します。 出力は、Kinich がそのテスト ケースで達成できる最大スコアです。 各操作は同じ値の 2 つの要素を正確に消費するため、スコアは完全に同じ数値のペアが何組存在するかによって決まります。 

配列の長さという制約は非常に厳しいです。$n$は最大 20 で、各要素は 1 ～$n$。 これは、チェックできる組み合わせの総数が$n \choose 2$繰り返しますが、これは非常に小さいです$n \le 20$。 

明らかではないエッジ ケースは、すべての要素が異なる場合、またはすべての要素が同一である場合に発生します。 たとえば、配列が [1,2,3,4] の場合、操作は不可能であるため、スコアは 0 になるはずです。逆に、配列が [2,2,2,2] の場合、作成できる素なペアが 2 つあり、スコアは 2 になります。一意の数値のみをカウントする不注意な実装やインデックスの再利用の防止を忘れると、これらのシナリオでは誤った結果が生じる可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべての等しい数値のペアを試し、それらを使用済みとしてマークし、再帰的にスコアを最大化します。 これは、考えられるすべての組み合わせシーケンスを調査するため、正しいです。 ただし、$n=20$、この再帰的手法には階乗増加があり、この問題には不必要です。 

重要な観察は、数字の位置を考慮する必要はなく、その頻度だけを考慮する必要があるということです。 それぞれの数字が貢献できるのは最大でも$\lfloor \text{frequency} / 2 \rfloor$すべてのペアには 2 つの出現が必要であるため、 はスコアを指します。 合計する$\lfloor \text{frequency} / 2 \rfloor$すべての個別の数値に対して直接最大スコアを与えます。 これにより、問題は発生回数をカウントすることになり、指定された制約の場合は簡単になります。 

ブルート フォースは有効なペアをすべて明示的に列挙するため機能しますが、次の場合には失敗します。$n$組み合わせの数が爆発的に増えるため、大きくなります。 周波数のカウントに関する観察により、問題が単純な算術に変換され、組み合わせ爆発が回避されます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. テスト ケースごとに、配列の長さを読み取ります。$n$そして配列要素。 
3. サイズの周波数配列を初期化します。$n+1$ゼロに。 これにより、1 から 2 までの各整数の出現数が保存されます。$n$。 
4. 配列を走査し、各数値の頻度を増加させます。 
5. スコアを 0 に初期化します。 
6. 周波数配列内の各数値について、周波数を 2 で整数で割ることによって形成できるペアの数を計算します。これをスコアに加算します。 
7. テストケースのスコアを出力します。 

これは、任意の数値に対する重複しないペアの最大数がその出現のちょうど半分であるため機能します。 すべての数値を合計すると、個々のインデックスを追跡する必要がなく、達成可能な最大スコアが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    
    freq = [0] * (n + 1)
    for x in a:
        freq[x] += 1
    
    score = 0
    for count in freq:
        score += count // 2
    
    print(score)
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、各数値の出現をカウントし、重複しないペアの最大数を計算します。 周波数配列のサイズが決まります`n+1`1 から始まるインデックス作成の便宜のため、整数除算により完全なペアのみがカウントされるようになります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()

        n = int(input())

        freq = [0] * (n + 1)

            freq[x] += 1
        score = sum(count // 2 for count in freq)

 ## 特殊なケース

 次のような単一要素配列の場合`[1]`、アルゴリズムは周波数配列を初期化し、カウントします。`1`1 回、2 で除算して 0 ペアを取得し、0 を出力します。次のようなすべての要素が等しい配列の場合`[2,2,2,2]`、頻度は 4 で、整数を 2 で割ると 2 つのペアが得られ、これがまさに最大スコアになります。 次のような混合ケース`[1,1,2,2,2,2]`歩留まり頻度カウント`[0,2,4,...]`、1+2=3 ポイントが生成され、アルゴリズムがさまざまな数値にわたるさまざまな周波数を正しく処理していることがわかります。
