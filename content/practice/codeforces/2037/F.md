 ## 問題の理解

 敵の列が与えられ、それぞれの体力と位置が固定されています。 ザイロネンは選択した 1 つの位置から攻撃できる`p`、そして各攻撃は敵の体力を次のように減らします。`m - |p - x|`その差が負でない場合。 目標は選択することです`p`少なくともそうなるように`k`最小限の攻撃回数で敵を倒すことができます。 出力は、攻撃の最小数、または`-1`殺害を許可する立場がない場合`k`敵。 

最初の重要な観察は、各攻撃によるダメージが距離に応じて直線的に減少するということです。 つまり、敵が遠ざかるほど、`p`、それを倒すにはより多くの攻撃が必要です。 私たちもそれに気づいています`p`敵の位置に制限されず、任意の整数にすることができ、敵の位置は厳密に増加します。 

制約が意味するのは、`n`最大 100,000 に達する可能性があり、`m`そして`h_i`最大 10^9。 これは、すべての可能な位置をシミュレートする O(n^2) 総当りアプローチを行う余裕がないことを意味します。`p`。 また、合計で最大 10^4 のテスト ケースを処理する必要があります。`n`すべてのケースで最大 10^5。 したがって、私たちのアルゴリズムは、最悪でもテスト ケースごとにおよそ O(n log n)、理想的には高速である必要があります。 

エッジケースには、敵の間隔が通常よりも離れている場合が含まれます。`m`、一度に複数に影響を与えること、またはすべての敵が距離内にある場合は不可能になります`m`, 1 つの位置で複数のターゲットを攻撃できるようになります。 たとえば、次の場合`n=2`、`m=1`、`k=2`、および位置は`[1, 3]`、シングルではありません`p`両方の敵に到達できるので、答えは次のとおりです。`-1`。 最初にヒットできると常に想定する素朴なアプローチ`k`敵はここで失敗するでしょう。 

## アプローチ

 ブルートフォース手法では、考えられるすべての整数の位置を反復処理します。`p`そして各敵を倒すのに必要な攻撃回数を計算します。 次に、これらの数を並べ替えて、`k`どれだけの攻撃が十分であるかを確認するには最小値を使用します。 これは正しいですが、あまりにも遅すぎるため、`p`最大 10^9 の範囲に及ぶ可能性があり、潜在的に巨大な検索スペースが発生します。 

重要な洞察は、攻撃パターンが区分的に線形であるということです。 各敵は、ダメージを受けることができる位置の間隔を定義します。 具体的には、敵`x_i`健康とともに`h_i`まで生き残ることができます`ceil(h_i / (m - |p - x_i|))`攻撃は次のように減少します`|p - x_i|`減少します。 したがって、いかなる攻撃に対しても、`t`、敵が最大で倒される位置の間隔を計算できます。`t`攻撃します。 これは問題を区間カバレッジの問題に変換します。位置が必要です。`p`それは少なくとも次の間隔にあります`k`敵。 

これを攻撃数の二分探索と組み合わせることができます。 候補者にとって`t`、で倒されるすべての敵の間隔を生成します。`t`攻撃します。 次に、いずれかのポジションが少なくとも次の条件でカバーされているかどうかを確認します。`k`掃引線アプローチを使用してこれらの間隔を計算し、間隔のエンドポイントをソートすることで重複を効率的にカウントします。 二分探索により最小値が確実に見つかります`t`効率的に。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、`m`、`k`、健康配列`h`、および位置配列`x`。 
2. ヘルパー関数を定義する`possible(t)`少なくとも次の場合に True を返します`k`敵は倒せる`t`攻撃します。 
3. で`possible(t)`、すべての敵を繰り返します。 敵ごとに最大距離を計算します`d`そのような`m - d`回`t`少なくとも`h_i`。 もし`d >= m`、敵をスキップします。 それは負けられない`t`攻撃します。 それ以外の場合は、間隔を追加します`[x_i - d, x_i + d]`リストに。 
4. 間隔のエンドポイントを並べ替え、スイープ ラインを実行します。 各ポイントで重複する間隔の数を追跡します。 どこかの時点で少なくとも`k`重複する間隔の場合は、True を返します。 
5. 二分探索を使用します。`t`。 セット`low = 1`、`high = max(h)`、または 10^9 などの安全な上限。 それぞれの中間値について、次を呼び出します。`possible(mid)`。 True の場合、減らす`high`; False の場合は増加します`low`。 
6. 二分探索後、有効なものがない場合`t`見つかった、出力`-1`。 それ以外の場合は、最小値を出力します`t`見つかった。 

機能する理由: 二分探索では、最初の検索が保証されます。`t`誰のために`possible(t)`True を返します。 間隔ベースのスイープにより、実際に敵を倒すことができる位置のみを考慮することが保証されます。`t`攻撃を検出し、重複を数えることで、確実に`p`それは少なくとも負ける`k`敵。 このアプローチにより、すべての整数位置の反復処理が回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        h = list(map(int, input().split()))
        x = list(map(int, input().split()))
        
        def possible(t_attacks):
            events = []
            for hi, xi in zip(h, x):
                d = m - math.ceil(hi / t_attacks)
                if d < 0:
                    continue
                left = xi - d
                right = xi + d
                events.append((left, 1))
                events.append((right + 1, -1))
            events.sort()
            count = 0
            for pos, delta in events:
                count += delta
                if count >= k:
                    return True
            return False
        
        low, high = 1, max(h)
        answer = -1
        while low <= high:
            mid = (low + high) // 2
            if possible(mid):
                answer = mid
                high = mid - 1
            else:
                low = mid + 1
        print(answer)
        
solve()
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`複数のテストケースを処理します。 の`possible`関数は、候補数の攻撃内で敵を倒すことができる各敵の間隔を計算し、ソートされた間隔のエンドポイントで掃引線アプローチを使用して、少なくともカバーされる位置が存在するかどうかを確認します。`k`間隔。 二分探索は攻撃の数を最小限に抑えるために使用されます。 

微妙な点としては、天井の扱いが挙げられます。`hi / t`正しく、間隔に両端が含まれていることを確認し、追加します。`+1`スイープラインを正確にするために、右の終点に設定します。 間隔エンドポイントでのオフバイワンエラーにより、重複する間隔のカウントが中断されます。
