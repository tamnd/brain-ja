 ## 問題の理解

 長さの文字列が与えられます$n$。 位置の文字を交換するスワップ操作を繰り返し適用できます。$i$そして$i+k$両方のインデックスが有効である限り。 これらのスワップは、任意の順序で何度でも実行できます。 

タスクは、これらの交換のシーケンスを適用することによって、元の文字列からいくつの異なる文字列を生成できるかを決定することです。 少なくとも 1 つの位置が異なる場合、2 つの文字列は異なるものとみなされます。 

重要な構造は、スワップがグローバルに機能しないことです。 各スワップは、インデックスが正確に異なるポジションのみを接続します。$k$。 これは、インデックスが剰余モジュロに基づいて独立したグループに分割されていることを直ちに示唆しています。$k$。 

制約$n \le 10^6$あらゆる解が本質的に線形であるか、または$O(n \log n)$。 状態空間は階乗であるため、順列の列挙や状態に対する BFS を伴うものは不可能です。$n$。 私たちは、変換をシミュレートするのではなく、スワップの効果を組み合わせ計数問題に圧縮することを余儀なくされています。 

単純な推論による微妙な失敗のケースは、十分なスワップが存在する場合、文字列の任意の並べ替えが可能であると仮定することです。 たとえば、$n=4, k=2$、文字列「aabb」では 4 つすべてを生成することはできません。 順列。 位置 (1,3) と (2,4) のみが接続されているため、文字はそれらのペア内でのみ再配置できます。 単純なグローバル順列モデルは大幅にオーバーカウントします。 

もう 1 つのエッジケースは次のような場合です$k=1$。 この場合、隣接するすべての交換が許可されます。つまり、文字列全体を任意に並べ替えることができるため、答えは次のようになります。$n!$文字の多さで分けられます。 

反対の極端な場合、$k=n$、スワップはできないため、構成は 1 つだけ存在します。 

## アプローチ

 ブルートフォースアプローチでは、各インデックスをノードとしてモデル化し、インデックス間にエッジを追加します。$i$そして$i+k$。 次に、接続されたコンポーネントを構築し、各コンポーネント内の到達可能なすべての順列をシミュレートします。 サイズの各成分$m$貢献するだろう$m!$再配置できますが、文字が繰り返されているため重複を削除する必要があります。 これにより、コンポーネントごとに多項係数が得られます。 

ただし、コンポーネント内ですべての置換を明示的に生成すると指数関数的になるため、総当たり攻撃は失敗します。 各コンポーネントだけでもサイズがある可能性があるため、状態グラフを構築することすら不可能です。$O(n)$、階乗増加を与えます。 

重要な観察は、スワップでは、段階的に増加することによって形成される各連結コンポーネント内の任意の再配置のみが可能であるということです。$k$。 これらのコンポーネントは正確に剰余クラスの剰余です$\gcd(n,k)$グラフによって引き起こされる構造$i \leftrightarrow i+k$。 実際、インデックスは次のように分割されます。$k$独立したチェーン:$$i, i+k, i+2k, \dots$$範囲内で。 各チェーン内では、チェーンに沿った隣接するスワップによってそのコンポーネント上に完全な対称グループが生成されるため、あらゆる置換が実現可能です。 

したがって、問題は次のようになります。チェーンごとに、その文字のマルチセットの異なる順列がいくつ存在するかを数えます。 これらは多項カウントであり、チェーンは独立しているため、すべてのチェーンにわたって結果を乗算します。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: インデックスをチェーンに分割する

 位置を剰余モジュロでグループ化します$k$。 残りごとに$r$、インデックスを考慮する$r, r+k, r+2k, \dots$。 スワップによって異なるグループ間でキャラクターが移動されることはないため、このような各グループは独立しています。 これが問題の根本的な分離です。 

### ステップ 2: 各チェーン内の文字を数える

 各チェーンについて、それらの位置に出現する文字のマルチセットを収集します。 チェーン内の任意の順列に到達できるため、個別の配置の数は多重度のみに依存します。 

### ステップ 3: チェーンごとの多項寄与を計算する

 チェーンに長さがある場合$m$、文字数$c_1, c_2, \dots$の場合、個別の順列の数は次のようになります。$$\frac{m!}{\prod c_i!}$$これを効率的に評価するために階乗とモジュラー逆行列を計算します。 

これが有効である理由は、スワップによってチェーンに沿ってすべての隣接する転置が生成され、そのチェーン上に完全な対称グループが生成されるためです。 

### ステップ 4: 貢献度を増やす

 チェーンは独立しているため、到達可能な文字列の総数はすべてのチェーンにわたる積になります。 

### なぜ効果があるのか

 各スワップでは、剰余モジュロによるインデックスのパーティションが保存されます。$k$, したがって、どのキャラクターもそのチェーンから離れることはありません。 チェーン内では、スワップは接続されたパス グラフを形成し、隣接するスワップによってそのパスのすべての順列が生成されます。 したがって、各チェーンは、他のチェーンとは独立して、そのマルチセットの順列の数に正確に寄与します。 独立とは掛け算を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k = map(int, input().split())
    s = input().strip()

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = modinv(fact[n])
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    used = [False] * n
    ans = 1

    for r in range(k):
        freq = [0] * 26
        length = 0
        i = r
        while i < n:
            freq[ord(s[i]) - 97] += 1
            length += 1
            i += k

        ways = fact[length]
        for c in freq:
            ways = ways * invfact[c] % MOD

        ans = ans * ways % MOD

    print(ans)

if __name__ == "__main__":
    solve()
