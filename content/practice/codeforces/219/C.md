 ## 解決策
 ## 問題の理解

 の行として表されるストライプが与えられます。`n`セル。各セルは次のいずれかでペイントされます。`k`文字でラベル付けされた色`A`を通して`k`- 番目の手紙。 目標は、隣接する 2 つのセルが同じ色を共有しないように、できるだけ少ない数のセルを再描画することです。 出力には、再描画の最小数と、結果として得られる有効なストライプ構成の両方が含まれている必要があります。 

入力サイズは重要です。`n`最大 500,000 に達する可能性があり、`k`最大 26 まで可能です。これにより、二次関数となる解は除外されます。`n`、 なぜなら`n^2`最悪の場合、操作は約 2.5×10^11 に達し、制限時間 2 秒をはるかに超えます。 線形または線形に近いソリューションが必要です。 小さな上限は`k`各セルで利用可能なすべての色を一定時間内に考慮する余裕があることを示唆しています。 

次の場合、微妙なエッジケースが発生します。`k = 2`。 このシナリオでは 2 色しかないため、ストライプは 2 色間で完全に交互になる必要があります。 同じ色が 3 つ連続するシーケンスでは、必然的に中央の色を再ペイントする必要があります。 前のセルのみを参照する素朴な貪欲な選択は、次のセルを考慮していない場合に失敗し、次善の再描画数が発生する可能性があります。 

もう 1 つの潜在的な落とし穴は、ストライプにすでに色が交互になっている場合です。 不注意なアルゴリズムでは、シーケンスがすでに有効であることを考慮せずに「前と同じ場合は変更」を盲目的に強制すると、不必要に再描画が行われる可能性があります。 

## アプローチ

 ブルートフォース手法では、隣接条件を満たす各セルへの色の割り当てをすべて考慮し、再描画をカウントします。 各セルには、`k`オプション、および`n`この結果生じる細胞`k^n`可能性。 枝刈りをしても、これは絶望的に遅いです`n`500,000まで。 

重要な洞察は、前のセルに注意を払うことで問題を貪欲に解決できるということです。 目的は隣接する重複を避けることだけであるため、各セルの選択はそのすぐ隣のセルの色のみに依存します。 これにより線形スキャンが可能になります。セルごとに、前のセルと一致する場合は、異なる色を選択します。 代替色の選択は、すべてを繰り返すことで一定時間内に行うことができます。`k`前の色と異なる色が見つかるまで (オプションで次の色も見つかります)`k > 2`新たな競合が生じることは避けたいと考えています)。 

のために`k = 2`、有効なストライプは 2 つだけあり、最初の色または 2 番目の色から交互に始まります。 両方の再塗装コストを計算し、より安価なオプションを選択できます。 のために`k > 2`、左から右への貪欲なスキャンは、最小限の再描画で常に成功します。これは、当面の競合を回避する選択できる色が常に少なくとも 1 つあるためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^n) | O(n) | 遅すぎる |
 | 貪欲なリニアスキャン | O(n・k) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 所定の位置に再描画するため、入力文字列を変更可能な操作用のリストに変換します。 これにより、新しい文字列を繰り返し構築することが回避されます。 
2. もし`k = 2`、最初の色から開始する場合と 2 番目の色から開始する場合の両方の可能な交互シーケンスの再ペイント コストを計算します。 カウントを比較し、安価なシーケンスを選択します。 カウントとシーケンスを返します。 
3. もし`k > 2`、2 番目のセルから開始して、ストライプを左から右に繰り返します。 各セルについて、前のセルと一致するかどうかを確認します。 
4. 一致するものが見つかった場合は、再描画カウンターをインクリメントし、このセルの新しい色を選択します。 すべてを反復処理する`k`色を選択し、前のセルと次のセル (存在する場合) の両方と異なる最初のセルを選択します。 この色を現在のセルに割り当てます。 
5. 最後までスキャンを続けます。 終了するまでに、隣接するセルのすべてのペアが異なる色を持つことが保証されます。 
6. 総再描画回数とその結果のストライプを出力します。 

貪欲アルゴリズムが機能するのは、現在のインデックスの左側にあるすべてのセルが隣接する重複がなく正しく色付けされているという不変条件が維持されるためです。 各ステップで、必要な場合にのみ再ペイントし、常に不変条件を維持する色を選択します。 以来`k ≥ 2`、選択できる有効な色が常に少なくとも 1 つあり、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
s = list(input().strip())
colors = [chr(ord('A') + i) for i in range(k)]
repaints = 0

if k == 2:
    # only two valid sequences: ABAB... or BABA...
    alt1 = [colors[i % 2] for i in range(n)]
    alt2 = [colors[(i + 1) % 2] for i in range(n)]
    cost1 = sum(s[i] != alt1[i] for i in range(n))
    cost2 = sum(s[i] != alt2[i] for i in range(n))
    if cost1 <= cost2:
        print(cost1)
        print(''.join(alt1))
    else:
        print(cost2)
        print(''.join(alt2))
else:
    i = 1
    while i < n:
        if s[i] == s[i - 1]:
            repaints += 1
            for c in colors:
                if c != s[i - 1] and (i + 1 == n or c != s[i + 1]):
                    s[i] = c
                    break
        i += 1
    print(repaints)
    print(''.join(s))
```コードは、入力文字列を可変リストに変換することから始まります。 のために`k = 2`エッジケースでは、2 つの交互シーケンスを構築し、両方の再描画コストをカウントします。 のために`k > 2`、アルゴリズムは各セルをスキャンし、前のセルとの競合を検出し、有効な代替色を選択します。 次のセルに対するチェックにより、当面新たな競合が発生するのを防ぎます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n・k) | 各セルは 1 回ずつ訪問されます。 再描画するときは、最大 k 色まで繰り返します。 k ≤ 26 の場合、これは事実上一定です。 |
 | スペース | O(n) | ストライプを可変リストおよび長さ k の色の配列として保存します。 |

 n ≤ 5×10^5 および k ≤ 26 の場合、O(n・k) 演算は 2×10^7 をはるかに下回っており、2 秒の制限時間と 256 MB のメモリに十分に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        n, k = map(int, input().split())
        s = list(input().strip())
        colors = [chr(ord('A') + i) for i in range(k)]
        repaints = 0

        if k == 2:
            alt1 = [colors[i % 2] for i in range(n)]
            alt2 = [colors[(i + 1) % 2] for i in range(n)]
            cost1 = sum(s[i] != alt1[i] for i in range(n))
            cost2 = sum(s[i] != alt2[i] for i in range(n))
            if cost1 <= cost2:
                print(cost1)
                print(''.join(alt1))
            else:
                print(cost2)
                print(''.join(alt2))
        else:
            i = 1
            while i < n:
                if s[i] == s[i - 1]:
                    repaints += 1
                    for c in colors:
                        if c != s[i - 1] and (i + 1 == n or c != s[i + 1]):
                            s[i] = c
                            break
                i += 1
            print(repaints)
            print(''.join(s))
    return out.getvalue().strip()

# Provided sample
assert run("6 3\nABBACC\n") == "2\nABCACA", "sample 1"
# Minimum size
assert run("1 2\nA\n") == "0\nA", "single cell"
# All equal, k=2
assert run("5 2\nAAAAA\n")
```
