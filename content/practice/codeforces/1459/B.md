 ## 解決策
 ## 問題の理解

 ロボットは次から始まります`(0, 0)`そして正確に作ります`n`動きます。 すべての動きには長さがある`1`。 

最初の移動はどの基本的な方向でも可能です。 その後、ロボットは垂直方向と水平方向の動作を交互に繰り返すことになります。 北または南に移動しただけであれば、次は東または西に移動する必要があります。 東か西に移動しただけなら、次は北か南に移動する必要があります。 

パスを数えるように求められることはありません。 正確に到達した後に、異なる座標がいくつ到達できるかだけを気にします。`n`動きます。 

入力には単一の整数が含まれています`n`、出力は異なる最終位置の数です。 

制約が非常に小さいので、`n ≤ 1000`したがって、二次シミュレーションでも簡単に適合します。 本当の課題は、到達可能なポイントの背後にある数学的パターンを認識することです。 

よくある間違いは、最終的な座標ではなく、一連の動きをカウントしてしまうことです。 たとえば:

 入力:```
2
```ロボットには多くの有効な方向の選択肢がありますが、到達可能なすべての位置は次のとおりです。```
(1,1), (1,-1), (-1,1), (-1,-1)
```正しい答えは次のとおりです。```
4
```もう一つの微妙なケースは、`n = 3`。 

ロボットは 1 つの軸で 2 つの動作を実行し、もう 1 つの軸で 1 つの動作を実行します。 可能な座標は次のとおりです。```
(±2, ±1)
(±1, ±2)
```8 つの異なる位置があるため、答えは次のようになります。```
8
```ロボットが常に半径のダイヤモンドで終わると仮定した素朴な試み`n`間違った結果が生じます。 

最も重要な観察は、奇数の手数と偶数の手数でパリティの動作が異なるということであり、最終的な式は完全に次のとおりであるかどうかに依存します。`n`奇数か偶数です。 

## アプローチ

 最も直接的なアプローチはブルートフォースです。 有効なターンのシーケンスをすべて再帰的に生成し、ロボットの位置を追跡し、到達可能なすべてのエンドポイントをセットに保存できます。 

すべての有効な動作シーケンスは 1 回だけ探索されるため、これは正しいです。 残念ながら、最初の動きの後は常に左か右の 2 つの選択肢があります。 パスの数は次のように増加します`4 · 2^(n-1)`。 

のために`n = 1000`、これは天文学的に大きく、計算することは完全に不可能です。 

重要な観察は、ムーブメントの構造を見ることから得られます。 

最初の移動後、方向は水平と垂直の間で永久に切り替わります。 これは、x 座標と y 座標が独立して構築されることを意味します。 

仮定する`n`は均等です。 

それではまさに`n/2`動きは水平であり、`n/2`動きは垂直です。 各座標は次の合計です。`n/2`に等しい値`+1`または`-1`。 

合計`k`価値観`±1`取ることができます:```
k + 1
```異なる値:```
-k, -k+2, ..., k-2, k
```したがって、x と y は両方とも`k+1`可能性。 ただし、それらのパリティはリンクされているため、格子点の半分しか発生しません。 注意深く数えると次のようになります。```
(k + 1)^2 + k^2
```どこ`k = n/2`。 

さて、仮定してください`n`奇数です。 

1 軸が受信`(n+1)/2`もう一方が受信している間に移動します`(n-1)/2`動きます。 

させて：```
a = (n+1)/2
b = (n-1)/2
```最初の座標は`a+1`可能な値と 2 番目の値は`b+1`可能な値。 すべての組み合わせが到達可能であり、以下が生成されます。```
(a + 1)(b + 1)
```代入:```
(a + 1)(b + 1)
= ((n+1)/2 + 1)((n-1)/2 + 1)
= ((n+1)/2 + 1)^2
```なぜなら`b + 1 = (n+1)/2`。 

これにより、非常にコンパクトな式が得られます。

 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`。 
2. もし`n`偶数、設定`k = n / 2`。 
3. 答えを次のように計算します。```
k² + (k + 1)²
```これは、両方の軸が同じ数の移動を受け取ったときに、到達可能なすべての格子点をカウントします。 
4. もし`n`奇数である場合、次のように設定します。```
k = (n + 1) / 2
```5. 答えを次のように計算します。```
(k + 1)²
```1 つの軸が取得されます`k`移動すると、もう一方が取得されます`k-1`が移動し、サイズが等しい到達可能な座標値の長方形のセットが得られます。`(k+1)²`。 
6. 結果を印刷します。 

### なぜ効果があるのか

 ロボットは水平移動と垂直移動を交互に行います。 すべての動きが行われた後、各座標は単にいくつかの独立したものの合計になります。`+1`そして`-1`貢献。 

軸が受信した場合`m`移動すると、その座標は正確に取得できます`m+1`考えられる合計は次のとおりであるため、値は次のようになります。```
-m, -m+2, ..., m-2, m
```奇数の場合`n`、2 つの軸は異なる移動数を受け取り、到達可能な x 値と y 値のすべての組み合わせを独立して実現できます。 

偶数の場合`n`、両方の軸は同じ数の移動を受け取ります。 到達可能なポイントは、サイズが次の 2 つのパリティ クラスに分割されます。`k²`そして`(k+1)²`、最終的なカウントを与える`k² + (k+1)²`。 

これらのカウントは、到達可能なすべてのエンドポイントを 1 回だけ表すため、式は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 0:
    k = n // 2
    print(k * k + (k + 1) * (k + 1))
else:
    k = (n + 1) // 2
    print((k + 1) * (k + 1))
```実装では、閉じた形式の式が直接評価されます。 

偶数の場合`n`、両方の軸が同じ数の移動を受け取るため、次を使用します。`k² + (k+1)²`。 

奇数の場合`n`、一方の軸は他方よりも 1 つ多くの移動を受け取ります。 カウントを単純化すると、`(k+1)²`、 どこ`k = (n+1)/2`。 

すべての算術演算は Python 整数内に簡単に収まります。 最大入力でも`n = 1000`、答えは周りにしかありません`500000`。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())

def run(inp: str) -> str:

    sys.stdout = old_stdout
