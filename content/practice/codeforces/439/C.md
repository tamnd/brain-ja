 ## 解決策
 ## 問題の理解

 個別の整数の配列が与えられているので、それを正確に _k_ 個の空でないグループに分割する必要があります。 これらのグループのうち、正確に _p_ は偶数の合計を持たなければならず、残りの _k - p_ は奇数の合計を持たなければなりません。 グループは連続している必要はありません。 要素の任意の組み合わせを含めることができます。 出力には、そのようなパーティションが可能かどうかが示され、可能であれば、有効なグループが 1 つ提供されます。 

この制約により、配列には最大 10^5 個の要素を含めることができ、値自体は 10^9 まで大きくできることがわかります。 これは、配列を分割する方法の数が指数関数的に増加するため、考えられるすべてのパーティションを反復する解決策を試みることはできないことを意味します。 素朴なアプローチはすぐに実行不可能になります。 

いくつかの特殊なケースがすぐに目立ちます。 配列内の奇数よりも多くの奇数和グループを作成するように求められた場合、その作業は不可能です。 同様に、必要な奇数グループを割り当てた後、偶数和グループを形成するのに十分な数が残っていない場合、タスクは失敗します。 もう 1 つの微妙な点は、合計の制約で複数の奇数を組み合わせて偶数の合計を形成する必要がある場合に発生します。 これを無視すると、正しくないパーティションが作成される可能性があります。 たとえば、配列の場合`[1, 3, 5, 7]`、すべての数値が奇数であるため、2 つの偶数和グループと 1 つの奇数和グループを求めることは不可能であり、それらを組み合わせて正確に 2 つの偶数和グループを作成することは失敗します。 

## アプローチ

 ブルート フォース アプローチでは、配列のすべてのサブセットを列挙し、グループの組み合わせが奇数/偶数の合計要件を満たしているかどうかを確認します。 これにより正確性が保証されますが、サブセットの数は 2^n であり、n = 10^5 の場合はまったく実用的ではありません。 

重要な観察は、合計パリティが各グループ内の奇数要素の数によって決定されるということです。 具体的には、グループに奇数の奇数の要素が含まれている場合に限り、合計は奇数になります。 和は、偶数の奇数要素が含まれる場合、または偶数要素のみが含まれる場合、偶数となります。 この洞察により、配列を奇数と偶数に分類し、どの要素をどのグループに入れる必要があるかを推論できるようになります。 

そこから、戦略は奇数と偶数を数え、利用可能な奇数を使用して奇数和グループの数を満たすことが可能かどうかを確認し、残りの数字から偶数和グループを形成します。 要素が不十分であるかパリティが不可能であるために、いずれかの段階で必要なグループを満たすことができない場合、答えは「いいえ」です。

 ## アルゴリズムのチュートリアル

 1. 配列を 2 つのリストに分割します。`odds`奇数の場合と`evens`偶数の場合。 これにより、合計パリティについて簡単に推論できるようになります。 
2. 条件を満たすのに十分な奇数があるかどうかを確認します。`k - p`奇数和グループ。 各奇数和グループには少なくとも 1 つの奇数が必要です。 奇数の数が以下の場合`k - p`、「NO」を出力します。 
3. 奇数和グループごとに 1 つを予約した後、残りの奇数を計算します。 残りの偶数和グループについては、それらの数の合計が偶数であることを確認する必要があります。 各グループは、合計を偶数にするために 1 つの偶数または 2 つの奇数のいずれかを使用できます。 ステップ 2 の後に残った奇数が、偶数和グループの数から使用可能な偶数を引いた数の 2 倍未満である場合は、「NO」を出力します。 
4. 各奇数和グループに 1 つの奇数を割り当てます。 これにより、これらのグループの合計が奇数になることが保証されます。 
5. 十分な偶数がある限り、各偶数和グループに 1 つの偶数を割り当てます。 十分でない場合は、残った 2 つの奇数を組み合わせて 1 つの偶数和グループを形成します。 
6. 残りの数値 (奇数と偶数の両方) は、必要なパリティに影響を与えることなく、任意のグループに配置できます。 一般的なアプローチは、それらを最初の偶数合計グループまたは最後に作成されたグループに追加することです。 
7. 「YES」を出力し、必要な形式でグループを出力します。要素の数から始まり、その後に要素自体が続きます。 

機能する理由: 各奇数和グループが最初に常に正確に 1 つの奇数を受け取るという不変式を維持することで、その和が奇数であることが保証されます。 偶数合計グループは、偶数または奇数のペアから構築され、それらの合計が偶数であることが保証されます。 残った要素は、適切に追加された場合にはパリティに影響を与えません。 このロジックはすべての可能性をカバーし、事前チェックが成功した場合にパーティショニングが正しく行われます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k, p = map(int, input().split())
a = list(map(int, input().split()))

odds = [x for x in a if x % 2 == 1]
evens = [x for x in a if x % 2 == 0]

odd_needed = k - p
if len(odds) < odd_needed:
    print("NO")
    sys.exit()

remaining_odds = len(odds) - odd_needed
even_needed = p

if remaining_odds % 2 != 0:
    if even_needed == 0:
        print("NO")
        sys.exit()
    remaining_odds += 1
    even_needed -= 1

if remaining_odds // 2 + len(evens) < even_needed:
    print("NO")
    sys.exit()

groups = []

# Assign one odd to each odd-sum group
for _ in range(odd_needed):
    groups.append([odds.pop()])

# Assign one element to each even-sum group
for _ in range(even_needed):
    if evens:
        groups.append([evens.pop()])
    else:
        groups.append([odds.pop(), odds.pop()])

# Append all remaining numbers to the last group
remaining_numbers = odds + evens
if remaining_numbers:
    groups[-1].extend(remaining_numbers)

print("YES")
for g in groups:
    print(len(g), *g)
```最初のセクションでは、パリティによって数値が区切られます。 次の 3 つの条件ブロックは、それぞれ問題の論理制約に対応する実現可能性チェックを実行します。 奇数と偶数を割り当てると、それぞれの合計要件が確実に満たされます。 残りの数値を最後に追加すると、パリティ制約を変更せずに完全なパーティションが保証されます。
