 ## 解決策
 ## 問題の理解

 合計で配布しております`n`同じお菓子を`f`それぞれの友達に少なくとも 1 つのお菓子を贈らなければならないというルールがあります。 したがって、分布の結果は順序付けられた配列として見ることができます。`a1, a2, ..., af`合計が次のような正の整数の`n`。 

このような有効な順序付けされたパーティションすべての中で、すべての最大公約数が一致するものだけを数えるように求められます。`ai`は正確に 1 です。言い換えると、すべてのパイル サイズが 1 より大きい公約数を共有する分布は拒否されます。 

順序が重要なので、`[1, 2]`そして`[2, 1]`結果は異なります。 

制約は大きく、最大 100,000 クエリであり、各クエリには`n`100,000まで。 これにより、合成または除数に対するクエリごとの列挙が直ちに除外されます。 平`O(n)`クエリごとに実行すると、合計 10^10 の操作に達するため、遅すぎます。 

隠れた主な難点は、gcd の制限です。 単純なアプローチでは、次のすべての構成が生成される可能性があります。`n`の中へ`f`正の部分を抽出して gcd でフィルタリングしますが、組成の数は`C(n-1, f-1)`、概念的に中程度のものを列挙することすらできないほど大きすぎます。`n`。 

すべての組成をカウントし、包含除外を注意深く行わずに gcd が 1 より大きい組成を減算しようとすると、より微妙な失敗のケースが発生します。 たとえば、すべての部分が 2、3 などの倍数である場合、割り算条件間の重複を正しく処理する必要があります。 除数ごとの単純な減算では、交差部分が 2 重にカウントされます。 

## アプローチ

 まず、gcd 条件を無視します。 順序付けされた分布を数える`n`の中へ`f`肯定的な部分は典型的な星と棒の結果です。 

設定により変数を変換します`bi = ai - 1`、これですべてが実現します`bi ≥ 0`それらの合計は次のようになります`n - f`。 このような順序付けされた解の数は次のとおりです。`C(n - 1, f - 1)`。 

したがって、制約がなければ、答えは単純な二項係数になります。 

次に、gcd 条件を組み込みます。 重要な観察は、もしすべてが`ai`公約数を共有する`d > 1`、そして、次のように書くことができます`ai = d * bi`。 これは次のことを意味します`d`分けなければなりません`n`、および縮小されたベクトル`b`を満たす:`b1 + b2 + ... + bf = n / d`。 

したがって、すべての不正な分布 (gcd ≥ 2) は、より小さい合計の有効な分布に正確に対応します。`n/d`。 

この構造は、除数に対する包含/除外に最適です。 させて`F(n, f)`gcd がちょうど 1 である有効な組成の数になります。`G(n, f)`総構成は次のようになります。`G(n, f) = C(n - 1, f - 1)`。 

それから：`G(n, f) = sum over d dividing gcd of parts (actually sum over d | n) of F(n/d, f)`。 

メビウス反転による書き換え:`F(n, f) = sum over d | n of mu(d) * C(n/d - 1, f - 1)`。 

これにより、gcd 制約がメビウス関数で重み付けされた除数の合計に変換されます。 以来`n ≤ 10^5`、メビウスの値と約数を効率的に事前計算し、二項係数の階乗を事前計算できます。 

また、すべての答えを事前計算します`(n, f)`除数を反復処理することで事前に実行します。

 ## アルゴリズムのチュートリアル

 私たちは、組み合わせ論、数論、事前計算という 3 つの概念レイヤーでソリューションを構築します。 

1. 階乗および逆階乗を最大で事前計算します。`MAX = 100000`。 これにより、二項係数の定数時間計算が可能になります。`C(n, k)`モジュロ`1e9+7`。 
2. メビウス関数を計算する`mu[1..MAX]`直線ふるいを使用します。 メビウス値は、数値に素因数が繰り返されているかどうか (繰り返している場合は 0)、および素因数の数に基づいた符号をエンコードします。 
3. それぞれについて`n`、すべての約数を反復処理します`d`の`n`。 各約数について、以下を寄与します。`mu[d] * C(n/d - 1, f - 1)`有効なすべての答えに`f`。 

この反転ステップが解決策の核心です。 これは、gcd が何らかの素因数で割り切れる分布からの寄与をキャンセルすることで、gcd が正確に 1 である分布をカウントすることを保証します。 

1. すべての結果を 2D テーブルに保存する`ans[n][f]`。 
2. クエリごとに直接出力`ans[n][f]`。 

### なぜ効果があるのか

 すべての有効なディストリビューションには、明確に定義された gcd があります。`g`。 因数分解すると`g`、gcd 1 で原始分布が得られます。合計の各原始分布`n/g`の約数構造ごとに 1 回だけ複製されます。`g`。 Möbius 関数は、これらの多重度全体にわたるキャンセル メカニズムとして機能し、gcd-1 構成のみが確実に存続するようにします。 これにより、重複する可分性条件の二重カウントが自動的に回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAX = 100000

# factorials
fact = [1] * (MAX + 1)
invfact = [1] * (MAX + 1)

for i in range(1, MAX + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAX] = pow(fact[MAX], MOD - 2, MOD)
for i in range(MAX, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if n < 0 or r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# Möbius function
mu = [1] * (MAX + 1)
is_prime = [True] * (MAX + 1)
primes = []

mu[0] = 0
for i in range(2, MAX + 1):
    if is_prime[i]:
        primes.append(i)
        mu[i] = -1
    j = 0
    while j < len(primes) and i * primes[j] <= MAX:
        is_prime[i * primes[j]] = False
        if i % primes[j] == 0:
            mu[i * primes[j]] = 0
            break
        else:
            mu[i * primes[j]] = -mu[i]
        j += 1

# precompute divisors
divs = [[] for _ in range(MAX + 1)]
for d in range(1, MAX + 1):
    for m in range(d, MAX + 1, d):
        divs[m].append(d)

# precompute answers
ans = [[0] * (MAX + 1) for _ in range(MAX + 1)]

for n in range(1, MAX + 1):
    for f in range(1, n + 1):
        res = 0
        for d in divs[n]:
            if n // d - 1 >= f - 1:
                res += mu[d] * C(n // d - 1, f - 1)
        ans[n][f] = res % MOD

q = int(input())
for _ in range(q):
    n, f = map(int, input().split())
    print(ans[n][f] % MOD)
```階乗配列は標準であり、二項係数が O(1) で計算されることを保証します。 メビウスの篩は、包含除外重みを効率的に構築します。 

除数リスト`divs[n]`除数を繰り返し再計算することを回避し、事前計算を管理しやすくします。 

ファイナルテーブル`ans[n][f]`密度は高いですが実現可能です。`n ≤ 10^5`、クエリは O(1) で応答されます。

 ## 特殊なケース

 微妙なケースの 1 つが次のような場合です。`f = n`。 この状況では、すべての友達にちょうど 1 つのお菓子が与えられるため、配布されるのは次のとおりです。`[1, 1, ..., 1]`。 gcd は 1 なので、答えは常に 1 でなければなりません。アルゴリズムでは、これは次の理由で捕捉されます。`C(n-1, n-1) = 1`そして他のすべての用語は消滅します`n/d - 1 < f - 1`みんなのために`d > 1`。 

もう一つのケースは、`f = 1`。 配列は 1 つだけです`[n]`。 その gcd は`n`、したがって、次の場合にのみ貢献します。`n = 1`。 この式は正しく減少します。`n > 1`, メビウスのキャンセルはゼロになります。 

3 番目のケースは次の場合です。`n`プライムです。 すると、約数は`1`そして`n`。 の用語`d = n`は常に無効な full-gcd 寄与をキャンセルし、均一にスケーリングされていない構成だけを残します。これは、自明な gcd-1 構成を除いて自明でないスケーリング構造が存在しないという事実と一致します。
