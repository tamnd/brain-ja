 ## 解決策
 ## 問題の理解

 長さの 2 つの整数シーケンスが与えられます。$n$。 1 つのシーケンス$b$固定の「キー」として機能し、他のシーケンスは$c$観察された未知のシーケンスの暗号化された出力です$a$そのキーの下にあります。 暗号化ルールは直接的には明らかにしません$a$; 代わりに、次の循環シフトごとに計算します。$b$、からどれくらい離れていますか$a$ユークリッドの二乗距離でそれらを保存します$n$距離を暗号文として使用します。 

具体的にはシフトごとに$t$、比較します$a_i$に対して$b_{(i+t)\bmod n}$、差を二乗し、すべての位置を合計します。 これにより値が生成されます$c_t$。 したがって、出力全体は、循環畳み込みのような二次変換になります。$a$のすべての回転に対して$b$。 

課題は逆転します。私たちには与えられたものがあります。$b$そして$c$、すべての可能なシーケンスを再構築する必要があります$a$それは生み出すことができたかもしれない$c$。 さらに、有効なすべてを出力する必要があります。$a$辞書順に。 

重要な構造的保証は、すべての循環シフトが$b$は線形独立です。 これは、反転を可能にし、結果として得られる線形システムが非縮退であることを保証する重要な代数的特性です。 

制約の観点から見ると、$n$大きい (この問題クラスでは典型的な 2e5 スケールまで)。 それは直ちにあらゆることを排除します$O(n^2)$再構築または単純なシフトごとの再計算。 変換にはすべての循環シフトが含まれるため、直接シミュレーションにはすでにコストがかかります$O(n^2)$、そして全体にわたるブルートフォース検索$a$指数関数的に不可能です。 

システムをインデックスごとに独立したものとして誤って扱うと、微妙なエッジ ケースが発生します。 たとえば、次の各位置を解決しようとすると、$a$から独立して$c$それぞれの理由で失敗します$c_t$のすべての座標を混合します$a$ローテーションされたペアリングを介して$b$。 もう 1 つの落とし穴は、巡回シフトがフルランク基底を形成することを無視していることです。これがないと、逆問題の解が無限に多くなるか、まったく解が存在しない可能性がありますが、ここではシフト基底での表現の一意性が保証されます。 

## アプローチ

 ブルートフォースアプローチでは、シーケンスを推測しようとします。$a$、すべてを計算します$n$循環シフト距離から$b$、と比較します$c$。 それぞれのチェックがあったとしても、$O(n^2)$、可能なスペース$a$は整数に制限がないため、このアプローチは基本的に不可能です。 

重要な観察点は、次の式を定義していることです。$c_t$は循環シフト上の二次形式です。$b$。 正方形を拡張すると次のようになります。$$c_t = \sum_i a_i^2 + \sum_i b_i^2 - 2\sum_i a_i b_{i+t}$$最初の 2 つの項は独立しています$t$、つまり、すべてのバリエーション$c$は相互相関項から来ています。$$\sum_i a_i b_{i+t}$$これは、次の間の循環相互相関です。$a$そして$b$。 次のように示すとします。$$S_t = \sum_i a_i b_{i+t}$$それから：$$c_t = A + B - 2S_t$$それで回復中$a$とのすべての循環相関からそれを回復することになります。$b$。 

ここで重要な構造的事実: の循環シフト$b$は線形独立です。 これは、$n$シフトによって形成されるベクトル$b$～の基礎を形成する$\mathbb{R}^n$。 したがって、マッピングは次のようになります。$$a \mapsto ( \langle a, \text{shift}_t(b) \rangle )_{t=0}^{n-1}$$は可逆線形変換です。 

つまり再構築できるということです$a$循環行列によって定義される線形システムを解くことによって。 循環システムは離散フーリエ変換によって対角化されます。 したがって、問題は、周波数空間に移動し、点ごとに分割し、反転することになります。 

一度$a$が回復されると、問題はすべての有効な解決策を要求します。 システムがフルランクなので解法も独特なので、$k$一貫性に応じて 0 または 1 のいずれかになります。

 ## アルゴリズムのチュートリアル

 システムを畳み込み形式に書き直し、FFT を使用して解きます。 

1. 距離の式の定数部分を計算します。$$C = \sum_i b_i^2$$これにより、次の部分が分離されます。$c_t$それはに依存します$a$。 
2. 変身$c_t$相互相関値への変換:$$S_t = \frac{A + C - c_t}{2}$$どこ$A = \sum_i a_i^2$、当初は不明でした。 

このステップでは、二次制約を次の観点から線形システムに書き換えます。$S_t$FFT は線形畳み込み構造にのみ適用されるため、これは不可欠です。 
3. 次のことを認識する$S_t$は循環相互相関です$a$そして$b$。 これを畳み込みとして書き直します。 

1 つのシーケンスを逆にして、次のようにします。$$S = a * b_{\text{rev}}$$これにより、巡回シフト構造が標準の畳み込みに変換され、FFT の使用が可能になります。 
4. FFT を使用して、周波数空間での畳み込みを計算します。 フーリエ変換を計算します。$$\mathcal{F}(S) = \mathcal{F}(a) \cdot \overline{\mathcal{F}(b)}$$以来$b$は既知であり、そのシフトは線形独立しています。$\mathcal{F}(b)$にはゼロ周波数成分がないため、除算が可能です。 
5. を解く$a$周波数空間では:$$\mathcal{F}(a) = \frac{\mathcal{F}(S)}{\overline{\mathcal{F}(b)}}$$次に、逆FFTを適用して回復します$a$時間領域で。 
6. 再構築されたことを確認します。$a$与えられたものを生成します$c$。 数値精度の問題が発生した場合は、無効な解を破棄してください。 
7. システムはフルランクであるため、単一の回復されたシーケンスを出力するか、矛盾している場合は 0 を出力します。 

### なぜ効果があるのか

 からの変革$a$すべての循環シフトとの相関ベクトルに$b$は、循環行列によって表される線形マップです。 すべてのシフトが$b$線形独立であることは、この行列が可逆であることを保証します。 循環行列は離散フーリエ基底によって対角化されるため、システムは周波数空間で対角になります。 各周波数成分は独立したスカラー方程式になり、点ごとの除算によって解くことで固有の有効なプリイメージが得られることが保証されます。$c$存在する場合。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import numpy as np

def fft_convolve(a, b):
    n = 1
    while n < len(a) + len(b) - 1:
        n <<= 1
    fa = np.fft.fft(a, n)
    fb = np.fft.fft(b, n)
    fc = fa * fb
    c = np.fft.ifft(fc).real
    return c

def solve():
    n = int(input())
    b = list(map(float, input().split()))
    c = list(map(float, input().split()))

    # reverse b for correlation handling
    br = b[::-1]

    # We treat system as circular convolution approximation
    # Compute FFT size
    sz = 1
    while sz < 2 * n:
        sz <<= 1

    fb = np.fft.fft(br, sz)

    # unknown S is derived from c up to constant; we reconstruct via linear system
    # build target vector in a consistent normalization
    fc = np.fft.fft(c, sz)

    # Solve in frequency domain assuming S = a * br
    # We effectively invert circulant system
    eps = 1e-9
    fa = np.zeros(sz, dtype=complex)

    for i in range(sz):
        if abs(fb[i]) > eps:
            fa[i] = fc[i] / fb[i]

    a = np.fft.ifft(fa).real

    res = [int(round(x)) for x in a[:n]]

    # verify
    def calc(a):
        s = sum(x * x for x in b)
        res = []
        for t in range(n):
            cur = 0
            for i in range(n):
                diff = a[i] - b[(i + t) % n]
                cur += diff * diff
            res.append(cur)
        return res

    if calc(res) != c:
        print(0)
        return

    print(1)
    print(*res)

if __name__ == "__main__":
    solve()
```実装は周波数空間への縮小に続きますが、重要な構造は FFT を使用した循環システムの反転です。 の逆転$b$循環シフトを標準の畳み込みカーネルに変換するものです。 浮動小数点 FFT 反転により、正確な等価性が崩れる小さなドリフトが発生する可能性があるため、最終検証が必要です。 

実装上の微妙な問題は丸めです。代数が正しい場合でも、逆 FFT は浮動小数点近似を返します。 丸めは再構築後にのみ実行する必要があり、検証は元の整数定義に対して実行する必要があります。

 ## 特殊なケース

 繊細なエッジケースが現れるのは、$b$交互または周期的なパターンなど、強い対称性を持っています。 問題保証によりシフトは線形独立のままですが、数値 FFT 逆変換によりゼロに近い周波数成分が生成され、浮動小数点誤差が増幅される可能性があります。 アルゴリズムは、再構成されたシーケンスを次の定義に対して直接検証することでこれを処理します。$c$、完全一致のみが受け入れられるようにします。 

もう一つのエッジケースは、$n=1$ここで、畳み込みは単一のスカラー方程式に縮退します。 FFT 機構は依然として動作しますが、単純な逆変換にまで減少し、検証ステップで曖昧さのない正確さが確認されます。
