 ## 解決策
 ## 問題の理解

 英大文字と小文字を含む単一の文字列を受け取ります。 タスクは、この文字列を 3 つのルールに従って変換することです。 

まず、すべての母音を削除する必要があります。 この問題の母音は、`A, O, Y, E, U, I`大文字と小文字の両方の形式で。 

次に、残りの文字はすべて子音なので、小文字に変換する必要があります。 

第三に、各子音の前にドットを挿入します。`.`。 

たとえば、次の文字列`Codeforces`になる`.c.d.f.r.c.s`なぜなら母音は`o`、`e`、 そして`o`は削除され、残りの子音は小文字になり、先頭にドットが付けられます。 

入力長は最大 100 文字です。 これは非常に小さいため、ここではパフォーマンスは問題になりません。 非効率なソリューションであっても、即座に実行されます。 それでも、最もクリーンなアプローチは、文字列に対する 1 回の線形スキャンです。 

難しいのは複雑さではなく、正確さです。 いくつかの小さな詳細は、不注意に扱われると簡単に間違った答えを生み出す可能性があります。 

よくある間違いの 1 つは、大文字の母音を忘れることです。 考慮する：```
Input:
aBAcAba
```正しい出力は次のとおりです。```
.b.c.b
```小文字の母音のみをチェックすると、大文字の母音も`A`文字が誤って答えに残ってしまう可能性があります。 

もう 1 つの簡単な間違いは、母音かどうかを確認する前に、すべての文字の前にドットを追加することです。 例えば：```
Input:
tour
```正しい出力は次のとおりです。```
.t.r
```不用意に実装すると、次のような結果が生じる可能性があります。```
.t.o.u.r
```母音を完全にスキップするのではなく、母音の前にドットを挿入するためです。 

3 番目の微妙なケースは、大文字の子音を正しく処理することです。 例えば：```
Input:
QWERTY
```正しい出力は次のとおりです。```
.q.w.r.t
```文字`E`そして`Y`この問題では母音なので消える必要があり、残りの子音は小文字になる必要があります。 

## アプローチ

 最も直接的なアプローチは、文字列を 1 文字ずつ処理することです。 文字ごとに、それが母音であるかどうかを確認します。 そうでない場合は、ドットとその文字の小文字バージョンを答えに追加します。 

すべての文字が 1 回検査されるため、これはすでに線形時間で実行されます。 

より単純なバージョンでは、次のような連結を使用して文字列を繰り返し再構築できます。```
ans = ans + "." + ch.lower()
```Python 文字列は不変であるため、連結するたびに新しい文字列が作成されます。 最悪の場合、これは二次的な動作につながります。 わずか 100 文字であれば、それでも問題なく通過できますが、これは理想的な練習ではありません。 

より良いアプローチは、部分のリストを作成し、最後にそれらを 1 回結合することです。 リストへの追加は効率的であり、最後の`"".join(...)`線形時間で答えを作成します。 

重要な観察は、すべての文字が独立して処理されるということです。 1 つの文字が生き残るかどうかは、その特定の文字が母音であるかどうかによってのみ決まります。 ポジション間の相互作用がないため、パスは 1 つで十分です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 承認済み |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力文字列を読み取ります。 
2. すべての母音を小文字で含むセットを作成します。`{'a', 'o', 'y', 'e', 'u', 'i'}`。 

小文字の母音を使用すると、文字をチェックする前に正規化できます。 
3. 最終的な回答の一部を保存する空のリストを作成します。 
4. 文字列内の各文字を繰り返し処理します。 
5. 現在の文字を小文字に変換します。 

これにより、大文字と小文字が均一に処理されます。 
6. 小文字が母音かどうかを確認します。 

母音の場合は完全にスキップします。 
7. 子音の場合は追加します`"." + character`回答リストへ。 
8. すべての文字を処理した後、リストを 1 つの文字列に結合して出力します。 

### なぜ効果があるのか

 すべてのステップで、アルゴリズムは、処理されたすべての文字の正しく変換されたバージョンが回答リストに含まれるという不変条件を維持します。 

母音に遭遇すると、問題はそれを消す必要があるため、母音をスキップすることで正確さを保ちます。 

子音に遭遇した場合、問題には 2 つの操作が必要です。それを小文字に変換し、その前にドットを配置します。 追加中`"." + lowercase_character`まさにそれらの操作を実行します。 

すべての文字が問題のルールに従って 1 回処理されるため、最終的に結合された文字列がまさに必要な出力となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()

vowels = set("aoyeui")
result = []

for ch in s:
    ch = ch.lower()

    if ch not in vowels:
        result.append("." + ch)

print("".join(result))
```プログラムは、入力文字列を読み取り、末尾の改行を次のように削除することから始まります。`strip()`。 

母音セットには小文字のみが含まれます。 このコードでは、大文字と小文字の両方を個別にチェックするのではなく、比較する前にすべての文字を小文字に変換します。 これによりロジックが単純になり、重複が避けられます。 

の`result`list には変換された子音が格納されます。 Python 文字列は不変であるため、文字列の連結を繰り返すよりもリストを使用することをお勧めします。 リストへの追加は効率的であり、最後に一度結合することで不必要なコピーを避けることができます。 

ループ内で、各文字は次のように正規化されます。`lower()`。 文字が母音ではない場合、コードはドットの後に小文字の子音を追加します。 

最終出力は次のように生成されます。`"".join(result)`。 

微妙な点の 1 つは操作の順序です。 母音セットのメンバーシップを確認する前に、文字を小文字にする必要があります。 それ以外の場合は大文字の母音`E`または`Y`間違って生き残ってしまうだろう。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    s = input().strip()

    vowels = set("aoyeui")
    result = []

    for ch in s:
        ch = ch.lower()

        if ch not in vowels:
            result.append("." + ch)

    print("".join(result))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run("tour\n") == ".t.r", "sample 1"

# custom cases
assert run("a\n") == "", "single vowel should disappear"
assert run("b\n") == ".b", "single consonant"
assert run("Codeforces\n") == ".c.d.f.r.c.s", "mixed uppercase and lowercase"
assert run("QWERTY\n") == ".q.w.r.t", "uppercase vowels removed correctly"
assert run("abcdefghijklmnopqrstuvwxyz\n") == ".b.c.d.f.g.h.j.k.l.m.n.p.q.r.s.t.v.w.x.z", "full alphabet case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`a`| 空の文字列 | 単母音の除去 |
 |`b`|`.b`| 単一の子音の書式設定 |
 |`Codeforces`|`.c.d.f.r.c.s`| 混合大文字と複数の母音 |

 ## 特殊なケース

 次の入力を考えてみましょう。```
A
```アルゴリズムは変換します`A`小文字にする`a`。 以来`a`は母音なのでスキップされます。 結果リストは空のままであるため、出力は空の文字列になります。 これにより、大文字の母音が正しく処理されることが確認されます。 

次の入力を考えてみましょう。```
BCDF
```処理手順は次のとおりです。`B -> b -> append ".b"`

`C -> c -> append ".c"`

`D -> d -> append ".d"`

`F -> f -> append ".f"`最終的な出力は次のようになります。```
.b.c.d.f
```これにより、すべての子音が先頭のドットを 1 つだけ受け取ることが確認されます。 

次の入力を考えてみましょう。```
Yy
```どちらの文字も小文字になります`y`。 以来`y`この問題では は母音として扱われるため、両方ともスキップされます。 出力は空です。 

よくある間違いはそれを忘れることです`Y`他の多くの問題では別の方法で分類されていますが、ここでは母音としてカウントされます。 

最後に、次のことを考慮してください。```
Input:
aBAcAba
```処理シーケンスは次のとおりです。`a -> vowel -> skip`

`B -> b -> append ".b"`

`A -> a -> skip`

`c -> c -> append ".c"`

`A -> a -> skip`

`b -> b -> append ".b"`

`a -> a -> skip`最終的な出力は次のとおりです。```
.b.c.b
```この例では、子音の書式設定が行われる前に大文字の母音が削除されることを確認します。
