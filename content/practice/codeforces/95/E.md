 ## 解決策
 ## 問題の理解

 双方向の道路で接続された一連の島が与えられています。 アイランドはリージョンを形成します。各リージョンは接続されたコンポーネントであり、異なるリージョンのアイランド間にはパスがありません。 その地域内の島の数が幸運な数字、つまり数字 4 と 7 だけで構成される数字である場合、その地域はラッキーと呼ばれます。Petya は、異なる地域の島の間に道路を追加する可能性があるため、少なくとも 1 つの幸運な地域を作成したいと考えています。 目標は、このような幸運な地域を形成するために必要な道路の最小数を決定すること、またはそれが不可能な場合は -1 を報告することです。 

入力により島の数が得られます。$n$既存道路の数$m$、 に続く$m$道路を表す整数のペア。 出力は単一の整数、つまり幸運な地域を構築するための道路の最小数、または -1 です。 

制約$n, m \le 10^5$を超える解決策があることを意味します。$O(n \log n)$または$O(m \log n)$制限時間内に操作が実行される可能性は低いです。 グラフには自己ループまたは複数のエッジが含まれる場合があるため、エッジを不用意にカウントすると接続性が誤って表示される可能性があります。 リージョンはすでに幸運である場合もあれば、複数のリージョンを組み合わせる必要がある場合もあります。 すべての領域が小さく、どの組み合わせでも幸運な数字が得られない場合、答えは -1 になります。 

考慮すべきエッジ ケースとしては、すべての島が孤立している国、すでに幸運に恵まれている地域、すべての島の合計が幸運な数字を形成している、すべての地域の組み合わせを単純に探索するのでは遅すぎる非常に大きなグラフなどがあります。 

## アプローチ

 素朴なアプローチは、地域のすべてのサブセットを列挙し、各サブセット内の島の総数を計算し、それが幸運かどうかを確認することです。 のサブセットごとに、$k$地域では必要になります$k-1$それらを合流させるための道路。 これは問題を正しくモデル化しているため、理論的には機能しますが、サブセットの数は$2^R$どこ$R$は領域の数であり、最大で$n$。 たとえ$n = 30$、これには実現可能をはるかに超える 10 億回以上の操作が必要になります。$n = 10^5$。 

重要な洞察は、これを古典的なサブセット合計問題の変形として考慮することです。この問題では、幸運な数字に到達するために領域サイズを組み合わせます。 各領域のサイズは次の整数です。$n$、領域の数は最大です。$n$。 動的プログラミングを使用してこれをモデル化できます。`dp[s]`合計を達成するために必要な領域の最小数として`s`。 最初は、各地域が個別に貢献します。 次に、すべての領域サイズを反復処理して更新します。`dp[s + size]`を使用して`dp[s] + 1`。 

微妙な点は、リージョンの追加は、使用されるリージョンの数よりも 1 本少ない道路を追加することに相当するということです。 合計の場合`s`組み合わせて形成されます`k`地域が必要です`k - 1`追加の道路。 これは、問題を、使用される要素の数を数えることによって制限されたサブセットの合計に変換します。これは、サイズの配列を使用した動的プログラミングを使用して効率的に実行できます。$n + 1$。

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、隣接リストを使用してグラフを構築します。 これにより、接続されたコンポーネントを効率的に走査できます。 
2. DFS または BFS を使用して、接続されているすべてのコンポーネントを検索します。 各コンポーネントのサイズをリストに記録します`components`。 
3. 最大の幸運な数字のセットを生成します。`n`。 これは、数字 4 と 7 を使用して数値を生成することで再帰的に実行できます。 
4. DP 配列を初期化する`dp`サイズの`n+1`無限を表すセンチネル値を使用します。 セット`dp[0] = 0`合計 0 に使用されるゼロ領域を表します。 
5. 各領域サイズを反復処理します。`c`で`components`。 考えられるそれぞれの合計について`s`から`n`まで`c`、 アップデート`dp[s] = min(dp[s], dp[s-c] + 1)`。 これにより、各コンポーネントを 1 回だけ使用することが保証されます。 
6. すべての領域を処理した後、すべてのラッキーナンバーを反復処理します。 ラッキーナンバーごとに`l`、どうかを確認してください`dp[l]`有限です。 「はい」の場合、必要な道路の最小数は次のとおりです。`dp[l] - 1`、合併するので`dp[l]`リージョンに必要な道路はリージョンの数より 1 つ少なくなります。 
7. ラッキーナンバーの合計に到達できない場合は、-1 を返します。 それ以外の場合は、計算された道路の最小数を返します。 

なぜ機能するのか: DP の不変条件は次のとおりです。`dp[s]`合計に達するために必要な最小数の領域を常に保持します`s`。 領域を反復処理し、合計を降順に更新することで、領域の二重カウントを回避します。 地域の数から道路への変換は正しいです。`k`リージョンを 1 つに分割する必要がある`k-1`エッジ。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

def generate_lucky_numbers(limit):
    lucky = []
    def dfs(num):
        if num > limit:
            return
        if num > 0:
            lucky.append(num)
        dfs(num * 10 + 4)
        dfs(num * 10 + 7)
    dfs(0)
    return set(lucky)

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    visited = [False] * n
    components = []

    def dfs(u):
        visited[u] = True
        size = 1
        for v in adj[u]:
            if not visited[v]:
                size += dfs(v)
        return size

    for i in range(n):
        if not visited[i]:
            components.append(dfs(i))

    lucky_numbers = generate_lucky_numbers(n)
    INF = n + 1
    dp = [INF] * (n + 1)
    dp[0] = 0

    for c in components:
        for s in range(n, c - 1, -1):
            if dp[s - c] + 1 < dp[s]:
                dp[s] = dp[s - c] + 1

    answer = INF
    for l in lucky_numbers:
        if dp[l] < INF:
            answer = min(answer, dp[l] - 1)
    print(-1 if answer == INF else answer)

if __name__ == "__main__":
    main()
```コードは最初にグラフを構築し、すべての接続コンポーネントのサイズを見つけます。 機能`generate_lucky_numbers`までのすべてのラッキーナンバーを列挙します`n`。 DP アレイ`dp`最小の領域カウントを追跡して合計を形成し、降順で反復することで領域を 2 回カウントすることを回避します。 最後に、地域の数を道路の数に合わせて調整します。 

## 実用的な例

 ### Sample Input 1```
4 3
1 2
2 3
1 3
```| 変数 | 状態 |
 | --- | --- |
 | コンポーネント | [3,1] |
 | ラッキーナンバー | {4,7} |
 | 処理後の dp 3 | dp[3]=1、dp[0]=0 |

 | 答え | dp[4]-1 = 2-1 = 1 |

 結果は、サイズ 3 と 1 の 2 つの領域を 1 本の道路と結合すると、サイズ 4 の幸運な領域が得られることを示しています。

```すべての島は孤立しています。 コンポーネント = [1,1,1,1,1]、ラッキーナンバー = {4,7}。 DP は、任意の 4 つの島を組み合わせることで到達可能な合計 4 を見つけます。`dp[4] = 4`、答え = 3。
