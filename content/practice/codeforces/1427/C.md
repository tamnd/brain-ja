 ## 解決策
 ## 問題の理解

 課題は、パパラッチが都市で撮影できる有名人の数を最大化することです。\(r \times r\)街路の格子。 各有名人は特定の時刻に特定の交差点 \((x_i, y_i)\) に出現します\(t_i\)、パパラッチは \((1, 1)\) から始まります。 ある交差点から別の交差点への移動にはマンハッタン距離分かかるため、\((x, y)\) から \((x', y')\) への移動には時間がかかります\(|x-x'| + |y-y'|\)分。 パパラッチが予定時間通りにセレブに到着した場合にのみ、写真を撮ることができます。 出力は、撮影できる有名人の最大数です。 

この制約により、強引なアプローチが実行不可能であることが明らかです。 まで\(n = 100,000\)有名人と時代\(t_i\)と同じくらい大きい\(10^6\)、 \(O(n^2)\) の解を買う余裕はありません。 各有名人は以前の到達可能な状態をチェックする必要があり、以前のすべての有名人を単純に繰り返すと遅すぎます。 小さいグリッドサイズ\(r \le 500\)空間内の局所性を最適化に利用できることを示唆しています。 

明らかではないエッジケースは、有名人があまりにも早く現れて、パパラッチがオフィスから連絡を取ることができない場合に発生します。 たとえば、有名人が \((6,8)\) にいるとします。\(t = 11\)、マンハッタンの距離は\(12\)。 常に次に予定されている有名人に移動する素朴な貪欲な実装では、一部の有名人をスキップすると合計数が大きくなるケースを見逃す可能性があります。 

## アプローチ

 ブルートフォース手法は、有名人ごとに動的プログラミング配列を維持することです。\(i\)、パパラッチが有名人で終わった場合に撮影できる写真の最大数を保存します。\(i\)。 有名人ごとに\(i\)、以前のすべての有名人について繰り返します\(j < i\)から移動しているかどうかを確認します\(j\)に\(i\)実現可能です。 これは問題の制約を直接モデル化するので正しいですが、実行には \(O(n^2)\) 時間かかります。\(n = 10^5\)。 

より高速なアプローチのための重要な観察点は、グリッド サイズが次のとおりであることです。\(r\)は小さく、2 つの位置間の移動は時間差によって制限される可能性があります。 連続する 2 人の有名人の時間差が少なくとも 1 秒である場合\(2r\)そうすると、常にグリッド上の任意の位置に到達することが可能になります。 これにより、最後のデータを追跡するだけで最適化できます。\(2r\)詳細な DP 更新にはイベントを使用し、古いイベントにはグローバル最大値を使用します。 これにより、演算数が \(O(n \cdot r^2)\) に減りますが、これは許容範囲内です。\(r^2 \le 250,000\)。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | タイムウィンドウを使用して最適化された DP | O(n * r^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 街路数の入力値を読み取ります。\(r\)そして有名人\(n\)。 各有名人の時間と位置をタプルのリストとして保存します。 
2. 動的プログラミング配列を初期化する\(dp[i]\)有名人で終わる写真の最大数を保存します\(i\)。 セット\(dp[0] = 0\)\((1,1)\) の初期位置の時間経過\(t_0 = 0\)。 
3. 変数を維持する\(best\_so\_far\)の世界最大値を追跡する\(dp\)過去が遠すぎて短期間で到達できない有名人の価値観\(2r\)分。 
4. 各有名人を反復処理する\(i\)から\(1\)に\(n\):
 1.セット\(dp[i] = 0\)。 
2. 過去の有名人ごとに\(j\)どこ\(i - j \le 2r\):
 1.次のことを確認します\(|x_i - x_j| + |y_i - y_j| \le t_i - t_j\)。 
2. 到達可能な場合は、\(dp[i] = \max(dp[i], dp[j] + 1)\) を更新します。 
3. もし\(i > 2r\)、グローバル最大値を使用すると古いイベントに到達できるため、 \(dp[i] = \max(dp[i], best\_so\_far + 1)\) も更新します。 
4. \(best\_so\_far = \max(best\_so\_far, dp[i])\) を更新します。 
5. 印刷\(best\_so\_far\)最終的な答えとして。 

維持される不変条件は次のとおりです\(dp[i]\)パパラッチが有名人で終わった場合に達成可能な写真の最大数を常に表します\(i\)。 最近のイベントのローカル チェックと古いイベントのグローバル最大値を組み合わせることで、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

r, n = map(int, input().split())
events = [(0, 1, 1)]  # add initial position at time 0
for _ in range(n):
    t, x, y = map(int, input().split())
    events.append((t, x, y))

dp = [-float('inf')] * (n + 1)
dp[0] = 0
best_so_far = 0

for i in range(1, n + 1):
    t_i, x_i, y_i = events[i]
    dp[i] = -float('inf')
    for j in range(max(0, i - 2 * r), i):
        t_j, x_j, y_j = events[j]
        if abs(x_i - x_j) + abs(y_i - y_j) <= t_i - t_j:
            dp[i] = max(dp[i], dp[j] + 1)
    if i > 2 * r:
        dp[i] = max(dp[i], best_so_far + 1)
    best_so_far = max(best_so_far, dp[i])

print(best_so_far)
```このコードはアルゴリズムのステップを直接実装します。 最初のダミー イベントは、時刻 \((1,1)\) のオフィスを表します。\(0\)。 各有名人について、最後のものをチェックします\(2r\)到達可能性のためのイベント。 の`best_so_far`古いイベントの写真の達成可能な最大数を追跡します。 使用する`max(0, i - 2*r)`負のインデックスには決してアクセスしないようにします。 最後の print ステートメントはグローバル最大値を出力します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 |---|---|---|
 | 時間 | O(n * r) | 各有名人がチェックするのはせいぜい\(2r\)以前のイベント |
 | スペース | O(n) | 各有名人の dp を保存します |
