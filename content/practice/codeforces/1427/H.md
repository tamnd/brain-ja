 ## 解決策
 ## 問題の理解

 最低速度を計算するように求められます$v$凸型の多角形の刑務所から囚人が脱出するのを二人の看守が阻止できる。 囚人は主境界線の外側、左端の固定点から開始します。 彼は、周囲の「登れる」部分に沿った任意の点に向かって速度 1 で自由に移動できます。この部分は、からの多角形セグメントで構成されます。$P_1$に$P_{n+1}$。 警備員はから始まります$P_1$周囲に沿ってのみ移動しますが、完全に調整して同じ速度で移動できます。$v$。 囚人は、看守が占拠している境界点に到達すると即座に殺され、看守が占拠していない登攀可能な地点に到達すると即座に逃走する。 

入力は頂点の座標で構成されます$P_1$に$P_{n+1}$登れるポリゴン エッジの。 多角形自体は凸面であり、追加の 3 つの頂点があります。$P_{n+2}$そして$P_{n+3}$反対側からの脱出を防ぐために、巨大な負の X 座標を持つ長方形を形成します。 出力は最小値を表す実数です。$v$看守は囚人が決して逃亡しないことを保証できるようにするためです。 答えは正確でなければなりません$10^{-6}$。 

制約は小さいです。$n \le 50$。 各座標の境界は次のとおりです。$10^3$。 囚人の速度は常に 1 で、看守の速度は任意に速くすることができますが、最小限に抑える必要があります。 なぜなら$n$小さいですが、アルゴリズムはおおよそ次のとおりです$O(n^2)$または$O(n \log n)$許容されます。 エッジケースには、囚人が最初に端点または角に到達する場合や、看守が両端の間で最適に分割して周囲全体をカバーする場合が含まれます。 ガードが常に 1 つの点で一緒にいることを前提とする不用意なアプローチは、非対称ポリゴンでは失敗します。 

## アプローチ

 素朴なアプローチは、囚人が登ることができる境界に沿ってあらゆる地点に移動する一方で、看守が囚人を捕らえるために最適に移動することをシミュレートすることです。 多角形の各セグメントを小さなステップに離散化し、各ステップで囚人がそこに到達するまでの時間と各看守がそこに到達するまでの時間を計算できます。 最小ガード速度$v$そうすると、看守の移動距離と囚人の移動距離の比のすべての点での最大値になります。 これは概念的には正しいですが、離散化にはセグメントごとに多くのステップが必要となり、ガードの最適な動きは離散的ではなく連続的であるため、非効率的です。 

重要な観察は、周囲が 1 次元で凸状であることです。 問題は、からの線分をカバーすることに帰着します。$P_1$に$P_{n+1}$から始まる2人のガードと$P_1$そして高速で動く$v$外から近づいてくる捕虜を迎え撃つ。 囚人は速度 1 で直線移動するため、最悪の場合の逃走は、囚人がカバーする必要がある距離に対する看守がカバーする必要がある距離の比率が最大になる周囲に沿った点で発生します。 各ガードは周囲に沿ってどちらの方向にも移動できます。 したがって、固定ガード速度の場合、$v$、次の形式の関数をチェックすることで、看守が周囲のあらゆる場所で囚人を捕らえられるかどうかを判断できます。$$\text{guard distance along perimeter} \le v \times \text{time prisoner needs to reach point}$$周囲が凸状であるため、この関数は各セグメントに沿って単峰性になります。 これにより、各セグメントに沿って 3 値検索を実行して、最大のガード速度が必要な臨界点を見つけることができます。 最小値を計算したら$v$各セグメントに必要な、すべてのセグメントの最大値が最小値になります。$v$世界的に。

 ## アルゴリズムのチュートリアル

 1. 登頂可能な周囲に沿った各ポリゴン セグメントの合計長を事前計算します。 これにより、各点を線形の「周囲に沿った距離」パラメータに変換できます。$s$。 
2. ポリゴンセグメントごとに$P_i P_{i+1}$、そのセグメントに沿った点を、そこで捕虜を迎撃するために必要な最小限の警備速度にマッピングする連続関数を定義します。 ポイントとしては$Q$遠くで$d$囚人スタートから囚人は時間がかかる$t_p = d$。 警備員が境界に沿って移動する場合、到達するまでの最小時間$Q$周囲に沿った距離を次の値で割った値です。$v$。 必要です$t_g \le t_p$したがって、$v \ge \frac{guard\_distance}{t_p}$。 
3. 囚人は直線的に移動し、凸面の周囲に沿った警備距離は単調に変化するため、セグメントに沿った各関数は単峰性です。 したがって、各セグメントに対して三項検索を実行して、必要なガード速度が得られるポイントを見つけることができます。$v$最大化されます。 
4. 各セグメントに必要な最大ガード速度を計算し、すべてのセグメントにわたる全体の最大値を取得します。 これにより、最小限の結果が得られます$v$警備員が迎撃を保証できる。 
5. この最大値を出力します$v$十分な精度で。 

不変条件は、各セグメントについて、三分探索によって看守の移動距離と囚人の移動時間の比が最大となる点を見つけるということです。 ガードは常に周囲に沿って最適に移動できるため、登れる壁の両端を覆うことで脱出が不可能になります。 すべてのセグメントの最大値を取ることで、最悪のシナリオが処理されることが保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def dist(a, b):
    return math.hypot(a[0]-b[0], a[1]-b[1])

def solve():
    n = int(input())
    P = [tuple(map(int, input().split())) for _ in range(n+1)]

    # Precompute perimeter positions
    perim = [0]
    for i in range(n):
        perim.append(perim[-1] + dist(P[i], P[i+1]))
    total_length = perim[-1]

    prisoner_start = (-1e17, P[-1][1]/2)

    # Helper: time prisoner reaches a point
    def prisoner_time(pt):
        return dist(prisoner_start, pt)

    # Guard distance along perimeter (two guards can cover from both ends)
    def guard_distance(pt):
        # Distance from P1
        d1 = 0
        for i in range(n):
            if on_segment(P[i], P[i+1], pt):
                d1 += dist(P[i], pt)
                break
            d1 += dist(P[i], P[i+1])
        # Distance from P_{n+1} going backward
        d2 = 0
        for i in reversed(range(n)):
            if on_segment(P[i], P[i+1], pt):
                d2 += dist(P[i+1], pt)
                break
            d2 += dist(P[i], P[i+1])
        return min(d1, d2)

    def on_segment(a, b, p):
        return abs(dist(a, p) + dist(p, b) - dist(a, b)) < 1e-8

    ans = 0
    for i in range(n):
        a, b = P[i], P[i+1]

        left = 0.0
        right = 1.0
        for _ in range(100):
            t1 = left + (right-left)/3
            t2 = right - (right-left)/3
            pt1 = (a[0] + (b[0]-a[0])*t1, a[1] + (b[1]-a[1])*t1)
            pt2 = (a[0] + (b[0]-a[0])*t2, a[1] + (b[1]-a[1])*t2)
            v1 = guard_distance(pt1)/prisoner_time(pt1)
            v2 = guard_distance(pt2)/prisoner_time(pt2)
            if v1 < v2:
                left = t1
            else:
                right = t2
        t = (left+right)/2
        pt = (a[0] + (b[0]-a[0])*t, a[1] + (b[1]-a[1])*t)
        ans = max(ans, guard_distance(pt)/prisoner_time(pt))

    print("{0:.10f}".format(ans))

solve()
```コードは最初に周囲に沿った距離を計算して、2D 問題を 1D 線形パラメータ化に変換します。 各セグメントの三分探索により、最高のガード速度が必要な臨界点が見つかります。 の`guard_distance`関数は、登れる境界線の両端からの最小距離を計算し、反対側の端から始まる 2 つのガードをシミュレートします。 の比率`guard_distance / prisoner_time`は必要な速度であり、すべてのセグメントの最大値を取ることで最終的な答えが得られます。
