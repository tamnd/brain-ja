 ## 解決策
 ## 問題の理解

 小さな長方形のグリッドが与えられ、各セルは空かロボットが含まれています。 ロボットは 4 つの基本的な方向のいずれかに同時に移動でき、ロボットがグリッドから離れようとすると爆発します。 私たちの目標は、爆発を起こさずに少なくとも 1 つが左上隅に到達するようにロボットを移動できるかどうかを判断することです。 各テスト ケースはグリッドの寸法とレイアウトを提供し、出力は単純に YES または NO です。 

制約は厳しく、グリッドは最大 5×5 で、最大 5000 のテスト ケースを含めることができます。 グリッドが小さいため、各セルを個別に推論する余裕があります。 ただし、グリッドが小さい場合でも、すべてのロボットをやみくもに動かそうとすると、不注意なアプローチで失敗する可能性があります。 ロボットがすでに上端または左端にいる場合、重要な微妙な点が生じます。その方向への移動を命令すると爆発が発生します。 たとえば、2×2 グリッドの場合:```
ER
RE
```すぐに左または上に移動すると、最初の行または列のロボットが爆発します。 正しい答えは「いいえ」ですが、単純なアルゴリズムでは、どのロボットでも最終的には左上隅に移動できると想定され、誤った「はい」が生成される可能性があります。 

ロボットがすでに左上隅にいる場合、別のエッジ ケースが発生します。 何も動かす必要はなく、答えはすぐに「YES」です。 

## アプローチ

 ブルートフォース手法では、ロボットが左上に到達するか爆発が発生するまで、考えられるすべての動作シーケンスをシミュレートします。 各移動は上、下、左、右のいずれかであるため、分岐係数は 4 です。 5×5 グリッドの場合でも、シーケンスの数は指数関数的に増加し、5000 個のテスト ケースでシーケンスのすべてを反復処理するのは過剰になりますが、グリッド サイズが小さいため技術的には実現可能です。 ブルートフォースはロボットの状態空間を完全に探索するため機能しますが、時間がかかり、不必要です。 

最適なアプローチは、重要な唯一のロボットは左上隅に最も近いロボットであるという観察を活用します。 上または左への移動は、すでに最上行または最左列にい​​る他のロボットを爆発させる危険性があります。 したがって、最も上で最も左にあるロボットがすべてのロボットの中で一番左上の位置にあるかどうかを確認するだけで済みます。 そのようなロボットが存在する場合、それを行と列に沿って左上に向かって移動させることができ、他のロボットが範囲外に移動することを強制されることはありません。 

これにより、問題は最小の行インデックスと最小列インデックスを持つロボットを見つけて、それが左上端のロボットと一致するかどうかを確認することになります。 そうであれば、答えはイエスです。 それ以外の場合は「NO」です。 この洞察は、潜在的に指数関数的な問題をグリッドの単純な線形スキャンに変換します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^(n*m)) | O(n*m) | 遅すぎる |
 | 最適 | O(n*m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数の初期化`min_row`そして`min_col`すべてのロボットの中で最小の行インデックスと列インデックスを表す大きな数値にします。 
2. グリッドを行ごと、列ごとにスキャンします。 
3. ロボットを含むすべてのセルについて、更新します。`min_row`そして`min_col`現在の値とロボットの行インデックスと列インデックスの最小値になります。 
4. スキャン後、ロボットが位置 (`min_row`、`min_col`) は左上隅、つまり行 0 と列 0 にあります。 
5. そうである場合は、YES と出力します。 それ以外の場合は、NO を出力します。 

なぜ効果があるのか​​:`min_row`そして`min_col`すでに左上隅に最も近いロボットを特定します。 これより小さい行または列のロボットは存在しないため、このロボットを上または左に移動しても、他のロボットはすべて爆発しません。これは、他のすべてのロボットが左上の端から離れているためです。 したがって、左上のロボットが (`min_row`、`min_col`)、制約に違反することなく安全に左上隅に移動できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    min_row, min_col = n, m
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'R':
                if i < min_row:
                    min_row = i
                if j < min_col:
                    min_col = j
    if min_row == 0 and min_col == 0:
        print("YES")
    else:
        print("NO")
```コードはすべてのテスト ケースを読み取り、グリッドごとにすべてのセルをスキャンしてロボットを見つけます。 の`min_row`そして`min_col`左上に最も近いロボットを追跡します。 スキャン後、このロボットが左上隅にあるかどうかを確認すると、正解が得られます。 初期化するかの選択`min_row`そして`min_col`に`n`そして`m`実際のロボットの位置が正しく更新されることを保証します。 インデックスはゼロから始まるため、境界処理は暗黙的です。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [input().strip() for _ in range(n)]
        min_row, min_col = n, m
        for i in range(n):
            for j in range(m):
                if grid[i][j] == 'R':
                    if i < min_row:
                        min_row = i
                    if j < min_col:
                        min_col = j
        if min_row == 0 and min_col == 0:
            print("YES")
        else:
            print("NO")
    return output.getvalue().strip()
