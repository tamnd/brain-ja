 ## 問題の理解

 ホワイトボード上の整数のコレクションと、それを変更するための 2 つの操作が与えられています。 最初の操作である消去では、最大で削除できます。$k$数字。 2 番目の操作である Split では、任意の数値を分割できます。$x \ge 3$3つの整数に$x_1, x_2, x_3$合計すると$x$しかし、ただ保持するだけ$x_1$そして$x_3$、破棄$x_2$。 タスクは、これらの操作を実行した後にホワイトボードに残っているすべての数値の最大公約数 (GCD) を最大化することです。 

入力は複数のテスト ケースを提供します。 各テスト ケースは次のように指定します$n$、整数の数、$k$、許可される消去の最大数、および配列$a$整数の。 各整数は次の条件を満たします$1 \le a_i \le n$。 制約は重要です。$n$最大 200,000 およびすべての合計$n$テストケース全体の数も 200,000 です。 これにより、演算が指数関数的に行われるため、考えられるすべての分割またはサブセットを反復する総当りアプローチが排除されます。$n$実現不可能でしょう。 

明らかではないエッジケースには、次のような状況が含まれます。$k = 0$そして、数値には 1 のような単一の外れ値が含まれています。たとえば、配列が$[1, 2, 2, 2]$そして$k = 0$1 を消すことはできないので、最大 GCD は 1 になります。数値がすべて等しいか、素数が 2 より大きい場合には、別の厄介なシナリオが発生します。 分割では数字を減らすか並べ替えることしかできないため、どの要素を消去するかを特定することが重要です。 

## アプローチ

 ブルートフォースアプローチは、消去と分割のあらゆる組み合わせを試すことです。 ホワイトボード上の各数値について、すべての分割構成を試行し、結果の配列の GCD を計算できます。 これは理論的には正しいです。操作の任意の組み合わせを検討できるためですが、計算的には実行不可能です。 各数値はさまざまな方法で分割できます。$n$最大 200,000 まで、可能性の数は爆発的に増えます。 

重要な観察は、最終的な GCD のみを考慮しており、Split 操作を使用して任意の数値のペアを生成できることです。$x_1, x_3$に限って$x_1 + x_2 + x_3 = x$そして$x_2 \ge 1$。 これにより、任意の数を減らすことができます$a_i$候補 GCD の任意の倍数$d$それ以下である$a_i$。 したがって、特定の候補者について、問題を再構成できます。$d$、の倍数に変換できない数値はいくつありますか?$d$スプリットを使っても？ これらの数値は消去する必要があり、その数値が以下の場合は、$k$、$d$達成可能です。 

これを効率的に実装するために、可能な約数を反復処理します。$d$1から$n$。 それぞれについて$d$、配列内で割り切れない数値がいくつあるかを数えます。$d$そのカウントが ≤ であるかどうかを確認します$k$。 最大の$d$このチェックに合格することが答えです。 候補ごとに線形スキャンのみが必要なため、これは高速です$d$、最大のものから開始して最適化できます。$d$そして最初の有効なもので停止します。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、$k$、および配列$a$。 各整数の頻度を追跡すると、候補で割り切れる数値の数をすばやく計算できます。$d$。 
2. 候補 GCD を反復する$d$1 から最大数まで$a$、または同等の最大$n$。 それぞれについて$d$, で割り切れる数の数を求めます。$d$モジュラー演算を使用して。 
3. の倍数に変換できない数値の数を計算します。$d$even with splits. Split を使用すると、任意の 2 つの数値を加算し続けることができるため、$x$真ん中の値を破棄し、それ以上の任意の数$d$の倍数を生成するように調整できます。$d$。 より小さい数値のみ$d$消去しなければなりません。 
4. 消去する必要がある数字の数が ≤ の場合$k$、 記録$d$正当な美しさとして。 有効な最大値を追跡する$d$反復中に。 
5. 最大値を出力する$d$テストケース用。 すべてのテスト ケースに対して繰り返します。 

このアルゴリズムが機能するのは、分割操作により数値を分解する際に完全な柔軟性が得られるためです。つまり、候補 GCD よりも小さい数値のみが選択を制約します。 消去操作は、これらの小さな数値を削除するための安全弁を提供します。 候補を降順にチェックすることで、最初に実現可能な候補が確実に得られます。$d$可能な限り最大です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_beauty(n, k, a):
    freq = [0] * (n + 2)
    for x in a:
        freq[x] += 1
    
    count = [0] * (n + 2)
    for d in range(1, n + 1):
        cnt = 0
        for mult in range(d, n + 1, d):
            cnt += freq[mult]
        count[d] = cnt
    
    for d in range(n, 0, -1):
        if n - count[d] <= k:
            return d
    return 1

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_beauty(n, k, a))
```の`freq`配列は各数値の出現をカウントします。 の`count`次に、配列は各候補 GCD の倍数がいくつあるかを集計します。 これを引くと$n$すべての数値をその候補で割り切れるようにするために必要な最小消去数を示します。 下降反復により、可能な限り最大の美しさが確実に見つかります。
