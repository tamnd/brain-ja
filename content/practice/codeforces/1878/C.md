 ## 問題の理解

 問題は正確に選択できるかどうかを尋ねます`k`セットからの個別の整数`{1, 2, ..., n}`それらの合計が等しくなるように`x`。 各テスト ケースでは、次の 3 つの整数が提供されます。`n`、選択できる数値の上限。`k`、選択する必要がある要素の数。 そして`x`、目標金額。 出力は、そのような選択が可能な場合は「YES」、そうでない場合は「NO」になります。 

制約が示すのは、`n`最大 200,000 までの可能性があり、`x`最大 400 億、最大 10,000 のテスト ケースを含めることができます。 k 要素のサブセットの数は組み合わせによって増加するため、すべての組み合わせを列挙する強引な試みは実行不可能です。`n`そして`k`。 したがって、テスト ケースごとに一定時間または線形時間で機能するソリューションが必要です。 

見落とされやすいエッジケースには、合計が最小値よりも小さい状況が含まれます。`k`要素、または可能な最大合計よりも大きい。 たとえば、次の場合`n = 5`、`k = 3`、 そして`x = 3`、3 つの異なる数値の最小合計は次のようになります。`1 + 2 + 3 = 6`、したがって、答えは「NO」でなければなりません。 同様に、`x`の合計を超えます`k`の最大数`{1..n}`、それは不可能です。 

## アプローチ

 ブルートフォースアプローチは、次のすべての組み合わせを生成することです。`k`間の数字`1`そして`n`それらの合計が次になるかどうかを確認します`x`。 これは正しいですが、非常に遅いです。組み合わせの数は次のとおりです。`C(n, k)`、最大値の場合、`n`そして`k`10^150 を超える可能性があり、実行可能な計算をはるかに超えています。 

重要な洞察は、次のことを認識することです。`k`個別の数値は常に最初の数値の合計になります`k`自然数、`1 + 2 + ... + k = k*(k+1)/2`。 同様に、最大合計は最大の合計です。`k`数字、`n + (n-1) + ... + (n-k+1) = k*(2n - k + 1)/2`。 もし`x`が最小合計より小さいか最大合計より大きい場合、答えは即座に「NO」になります。 それ以外の場合は、正確に到達するために真ん中の数字を選択することが可能です`x`。 これにより、各テスト ケースに対して一定時間のチェックが行われます。

 | ブルートフォース | O(C(n,k)) | O(k) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、`k`、 そして`x`。 
2. 可能な最小合計を計算します。`k`明確な数字として`min_sum = k*(k+1)//2`。 この合計は最初の値を使用します`k`正の整数。 
3. 可能な最大合計を次のように計算します。`max_sum = k*(2*n - k + 1)//2`。 この合計は最大のものを使用します`k`からの整数`1`に`n`。 
4. 比較する`x`と`min_sum`そして`max_sum`。 もし`x`間隔の外にあります`[min_sum, max_sum]`、「NO」を出力します。 
5. それ以外の場合は、「YES」を出力します。 

機能する理由: 外部の任意の合計`[min_sum, max_sum]`要素は個別であり、1 と 1 で区切られているため、取得できません。`n`。 最初の値から開始することで、間隔内の任意の合計に到達できます。`k`アプローチする数値と段階的に増加する要素`x`を超えずに`n`。 このアルゴリズムは、シーケンスを明示的に構築せずに、このプロパティを利用します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n, k, x = map(int, input().split())
        min_sum = k * (k + 1) // 2
        max_sum = k * (2 * n - k + 1) // 2
        if x < min_sum or x > max_sum:
            print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    main()
```コードはテスト ケースの数を読み取り、テスト ケースの最小合計と最大合計を計算してそれぞれを処理します。`k`要素。 比較チェックは整数で行われ、Python の任意精度の算術演算を使用してオーバーフローを回避します。 これにより、大きな問題による落とし穴が回避されます。`x`最大 4*10^10 の値。 エッジケース`k = 1`または`k = n`数式によって正しい最小値と最大値が生成されるため、これらは自動的に処理されます。
