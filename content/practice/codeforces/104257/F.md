 ## 問題の理解

 私たちは辺の長さが整数である三角形を扱っています。次のように書かれます。$a \le b \le c$。 この三角形から、辺上に 2 つの特別な点が構築されます。$AB$そして$AC$。 各点は幾何学的条件によって定義されます。点は側面上にあり、反対側の頂点角を形成する 2 本の線からも等距離にあります (必要に応じて三角形の延長線を使用します)。 これにより、各点が角の二等分上に配置されるため、構築される両方の点は純粋に辺の長さによって決まります。 

これら 2 つの点は頂点とともに小さな三角形を形成します$A$。 この問題では、整数のトリプルがいくつあるかを数えるように求められます。$(a,b,c)$、 と$1 \le a \le b \le c \le N$、元の三角形と内側の三角形の間の面積の特定の比率が整数になる構成を生成します。 

入力により複数の値が与えられます。$N$、それぞれがその範囲内にある有効なトリプルの数を求めます。$N$。 以来$N$まで上がります$10^6$まであります$10^5$クエリの場合、理想的には前処理後にほぼ線形または線形に近い時間で、ソリューションを大幅に事前計算する必要があります。 

すべてのトリプルを単純に列挙することは不可能です。 有効な三角形をすべてチェックしても、$N$おおよそです$O(N^2)$、すでにそうなっています$10^{12}$限界での操作。 

微妙な問題は、スケーリング下での幾何学的構造の動作に現れます。 多くの素朴な試みは三角不等式のみが重要であると想定していますが、構成された比率は辺に沿った内部比例除算に依存するため、次の割り算特性に敏感です。$a,b,c$。 もう 1 つのよくある落とし穴は、実際には辺の長さの代数である条件を純粋に計量として扱うことです。 

## アプローチ

 直接的な総当たりアプローチでは、すべてのトリプルに対して反復処理が行われます。$1 \le a \le b \le c \le N$、幾何学的構造を計算し、標準的な三角形の面積公式を使用して面積比を導き出し、それが整数であるかどうかを確認します。 定数時間の式であっても、これには約$N^3/6$完全に不可能な構成です。 

重要な単純化は、幾何学的構造が角の二等分線によって作成される辺に沿った比率のみに依存することです。 角の二等分定理を使用して、各特別な点は、隣接する辺によって決定される比率で辺を分割します。 これにより、幾何学が完全に排除され、すべてが代数に還元されます。$a,b,c$。 

面積式を導出した後、比率は$\frac{[ABC]}{[APQ]}$の対称有理関数に単純化されます。$a,b,c$。 重要な構造上の観察は、式が均一であるため、係数によってすべての辺をスケーリングすることです。$k$分子と分母を予測可能な方法で乗算します。 これにより、トリプルをプリミティブ コアに分離できます。$(a,b,c)$と$\gcd(a,b,c)=1$、およびスケーリング係数。 

最低項で書き直すと、整数条件は次の対称多項式の割り算制約になります。$a,b,c$。 これにより、問題は、プリミティブ形式が固定算術条件を満たすトリプルを数え、すべての可能なスケーリングを合計して、$N$。 

最後の変換では、全体にわたる除数和スタイルの事前計算が行われます。$N$、通常は複数にわたるふるいのような累積を使用します。

 ## アルゴリズムのチュートリアル

 このソリューションは、幾何学的条件を純粋な算術制約に変換することを中心に構築されています。$(a,b,c)$、構造化されたトリプルを効率的に数えます。 

### 1. 角の二等分線を使用して内分割点を表現します

 角の二等分定理を使用すると、次の点が得られます。$AB$によって決定されます$$\frac{AP}{PB} = \frac{b}{a},$$そしてその点は$AC$によって決定されます$$\frac{AQ}{QC} = \frac{c}{a}.$$これにより、すべての幾何学的座標が次の線形式に変換されます。$a,b,c$。 

### 2. 面積比を代数関数として書き直す

 分割比を座標またはベクトルの面積式に代入すると、比は対称有理式に簡略化されます。$$\frac{[ABC]}{[APQ]} = F(a,b,c),$$どこ$F$は次数 0 の同次であり、次の対称多項式の分数として書き直すことができます。$a,b,c$。 

重要な単純化は、三角形の面積からのすべての平方根項が比率で相殺されることです。 

### 3. 整数性を割り切れる条件に還元する

 「比率が整数である」という条件は次のようになります。$$\text{denominator}(a,b,c) \mid \text{numerator}(a,b,c).$$簡略化すると、これは次の形式で表現できます。$$abc \mid (a+b+c)^2.$$このステップは主要な代数的崩壊です。すべての幾何学的構造が消失し、対称な可分性制約だけが残ります。 

### 4. gcd を使用した個別のスケーリング

 しましょう$g = \gcd(a,b,c)$、そして次のように書きます。$$a = gx,\quad b = gy,\quad c = gz,\quad \gcd(x,y,z)=1.$$条件に代入すると次のようになります。$$g^3 xyz \mid g^2(x+y+z)^2.$$これは次のように単純化されます。$$g \cdot xyz \mid (x+y+z)^2.$$したがって、固定プリミティブトリプルの場合$(x,y,z)$、特定のスケーリングのみ$g$有効です。 

### 5. すべての貢献度を事前計算する$N$有効なプリミティブ トリプルごとに、有効なすべてのプリミティブ トリプルを決定します。$g$そのような$g \le N/\max(x,y,z)$そして割り切れる条件が成り立ちます。 このような各トリプルは、そのスケーリング範囲のすべての倍数に寄与します。 

これは、ふるいのような周波数配列を使用して累積されます。$N$。 

### なぜ効果があるのか

 正しさは 2 つの不変条件から得られます。 まず、幾何学的構造は辺の比率によって完全に決定されるため、角の二等分線の除算によって幾何学的な曖昧さがすべて取り除かれ、問題が辺の長さに関する代数に還元されます。 第 2 に、結果として得られる条件は均一であるため、スケーリングが予測可能な方法で分子と分母に影響を与えることが保証され、プリミティブ構造とスケーリング係数への分離が可能になります。 これにより、二重カウントが防止され、すべての有効な三角形がそのプリミティブ形式を通じて正確に 1 回表現されることが保証されます。

 ## 特殊なケース

 のために$N = 1$、縮退三角形のみ$(1,1,1)$が存在し、アルゴリズムはプリミティブ列挙の基本ケースを通じてそれを正しく処理し、スケーリングによる寄与の欠落がないことを保証します。 

次のような非常にアンバランスなトリプルの場合$(1,1,N)$の場合でも、この構成では依然として有効な二等分点が生成されますが、分割条件は三角形の形状とは無関係に純粋に代数的にチェックされるため、これらは正しく処理されます。 スケーリング ロジックにより、これらが有効な場合は 1 回だけ含まれ、そうでない場合は除外されることが保証されます。
