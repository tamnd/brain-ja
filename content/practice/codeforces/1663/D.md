 ## 解決策
 ## 問題の理解

 問題は文字列を与えます`S`長さ 3 で、次の文字で構成されます。`+`そして`-`、および負でない整数`X`。 この文字列は、整数に対する一連の演算を表します。`+`1ずつ増加することを意味します。`-`は 1 ずつ減少することを意味します。`X`、シーケンスを繰り返し適用します`S`無限に。 タスクは、この無限の変換シーケンスで、負ではない別の整数がいくつ出現できるかを決定することです。 

なぜなら`S`長さは 3 なので、サイクルごとの演算数は非常に少なくなります。`X`最大 10 億まで可能で、これは大きいですが、固定サイズは小さいです。`S`数サイクルにわたるシミュレーションで十分である可能性があることを示唆しています。 明らかではない点は、シーケンスが永久に繰り返され、負の値が破棄されることです。同じ値が複数回再利用される可能性があるため、注意してカウントする必要があります。 までのすべてのステップをシミュレートする単純なアプローチ`10^9`は実行不可能であり、新しい値が出現しないサイクルまたは境界を検出する必要があります。 

エッジケースには、直ちに減少するシーケンスが含まれます。`X`ゼロまで増加するシーケンス、常に増加するシーケンス、および繰り返しの適用により 2 つの値の間で変動が生じるシーケンス。 たとえば、次の場合`S = "+-+"`そして`X = 1`、シーケンスは次のように展開します。`1 → 2 → 1 → 2 → …`。 ここでの個別の値は次のとおりです`{1, 2}`。 単純なシミュレーションでは、誤ってこれらの繰り返しを超えてカウントを続ける可能性があります。 

## アプローチ

 ブルートフォース手法では、次から始まるシーケンスをシミュレートします。`X`そして、繰り返しが表示されるか、値が負になるまで、セット内の負でないすべての値を追跡します。 擬似コードでは、これは次のようになります。```
values = {X}
current = X
while True:
    for op in S:
        current += 1 if op == '+' else -1
        if current < 0:
            break
        values.add(current)
    if no new values were added:
        break
```これは正しいですが、もし`X`または値が大きくなると、反復回数が多すぎる可能性があります。`X`まで可能です`10^9`。 ただし、`S`長さが 3 の場合、サイクルごとの正味の変化は小さい (-3 から +3 の間)。 これは、負の数値に到達するか、繰り返しパターンに到達するまでに表示される個別の値の数が最大でも`3 * 2 + 1 = 7`最悪の場合の発振シナリオでは、ブルートフォースが実際にここで実行可能です。 

重要な洞察は、シーケンスがゼロに達するか繰り返されるまで、最大数サイクルをシミュレートするだけでよいということです。 訪問した値を追跡することで、負でない各整数を正確に 1 回カウントすることが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O( | S | * (#個別の値)) |
 | サイクル検出による最適化 | O( | S | * 小さな定数) |

 最適なアプローチは本質的に同じシミュレーションですが、新しい値が検出されない場合、または負の数が生成される場合に形式的に停止します。 のサイズなので、`S`が固定されている場合、これは一定時間で実行されることが保証されます。 

## アルゴリズムのチュートリアル

 1. セットを初期化する`visited`開始値で`X`。 これにより、シーケンス内に出現するすべての非負の整数が追跡されます。 
2.セット`current = X`。 
3. 全サイクルで新しい値が追加されなくなるまで、次の手順を繰り返します。 

1. 文字列を反復処理する`S`:

 1. キャラクターが`+`、増分`current`1までに。 
2. キャラクターが`-`、デクリメント`current`1までに。 
3. もし`current`マイナスになった場合は破棄してこのサイクルを停止します。 
4. それ以外の場合は追加します`current`に`visited`。 
2.次のサイズの場合`visited`このサイクル中に変化しなかった場合は、ループを終了します。 
4. サイズを出力します。`visited`。 

機能する理由: 反復ごとに、もう 1 回のアプリケーションで到達可能なすべての新しい非負の整数が追加されます。`S`。 なぜなら`S`長さは 3 で、値が負になることはありません。到達可能な数値のセットは単調に増加しますが、制限されています。 新しい数値が出現できなくなるとアルゴリズムは停止し、到達可能なすべての個別の非負の整数を正確に 1 回カウントすることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

S = input().strip()
X = int(input())

visited = set()
visited.add(X)
current = X

while True:
    new_values = set()
    temp = current
    for op in S:
        if op == '+':
            temp += 1
        else:
            temp -= 1
        if temp >= 0:
            new_values.add(temp)
    if not new_values - visited:
        break
    visited.update(new_values)
    current = max(new_values)

print(len(visited))
```このコードは、訪問した値のセットを次のように初期化します。`X`。 各サイクルごとに、`S`、それは許可せずに新しい到達可能な値を計算します。`current`ネガティブになる。 サイクルで新しい値が生成されなくなると停止し、それぞれの個別の値が 1 回カウントされるようになります。 の選択`current = max(new_values)`これにより、到達可能な最大値からシミュレーションを継続できるため、可能なすべての増分が効率的に取得されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    S = input().strip()
    X = int(input())
    visited = set([X])
    current = X
    while True:
        new_values = set()
        temp = current
        for op in S:
            if op == '+':
                temp += 1
            else:
                temp -= 1
            if temp >= 0:
                new_values.add(temp)
        if not new_values - visited:
            break
        visited.update(new_values)
        current = max(new_values)
    return str(len(visited))

# Provided samples
assert run("+-+\n1\n") == "4", "sample 1"
assert run("---\n2\n") == "3", "sample 2"

# Custom cases
assert run("+++\n0\n") == "4", "increasing from 0"
assert run("++-\n1\n") == "3", "mixed operations"
assert run("--+\n1\n") == "3", "decreasing then increasing"
assert run("---\n0\n") == "1", "all negative from 0"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`+++\n0`| 4 | シーケンスは常にゼロから始まり増加します。 
|`++-\n1`| 3 | 混合操作による振動の発生 |
 |`--+\n1`| 3 | 減少してから増加、ゼロを処理します。 
|`---\n0`| 1 | 負の値はすぐに破棄されます。 

## 特殊なケース

 いつ`X = 0`そして`S`のみが含まれます`-`、アルゴリズムはそれを生成するだけで正しく処理します。`{0}`。 入力用`S = "---"`そして`X = 0`の場合、最初のステップの後、一時値はすぐに負になるため、新しい値は追加されません。 出力は`1`、予想と一致します。 同様に、次のようなシーケンス`"+-+"`小さなことから始める`X`正しく発振し、新しい値が表示されなくなるとループは終了します。 このアルゴリズムでは、到達可能なすべての個別の非負の整数が正確に 1 回カウントされることが保証されます。
