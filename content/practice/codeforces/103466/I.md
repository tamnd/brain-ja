 ## 問題の理解

 0 から n までのインデックスが付けられた宇宙ステーションのコレクションが与えられます。 各ステーションには整数のエネルギー値があり、ステーション 0 が開始点になります。 初めに、私たちはステーション 0 の値に等しいエネルギーをすでに所有しており、ステーションを訪問するたびに、そのエネルギーを永続的に獲得します。 

移動は制限されています。現在の位置から、現在保持しているエネルギーを超えないエネルギーを持つステーションまでしか移動できません。 エネルギーはステーションを訪問するときにのみ増加するため、これは、いかなる移動も時間の経過とともに決して減少しない動的しきい値を遵守する必要があることを意味します。 

タスクは、ステーション 0 から開始して、このルールの下ですべてのステーションを 1 回だけ訪問する個別の順序が何回可能であるかを数えることです。答えは 1e9 + 7 を法とする必要があります。 

主要な構造上の制約は、n が 100000 まで大きくなり得るのに対し、エネルギーは 0 ～ 50 で区切られた非常に小さな整数であるということです。この不一致は、解が二次または三次の方法でステーションの数に直接依存することはできず、代わりにエネルギーの小さな値範囲を使用して状態を圧縮する必要があることを直ちに示します。 

考えられるすべての置換をシミュレートしようとする素朴なアプローチは、n = 20 であってもすでに 20 を生成するため、明らかに失敗します。 実現不可能な可能性。 サブセットにわたる DP であっても、2^n を超えると爆発的に増加します。 

多くのステーションが同じエネルギー値を共有する場合、微妙なエッジケースが発生します。 たとえば、すべてのステーションのエネルギーが等しい場合、制約が移動を妨げないため、すべての順列が有効になります。 その場合の答えは (n+1) になるはずです。 法 M。等エネルギー遷移を制限されたものとして誤って扱うアプローチは、大幅に過小評価されます。 

もう 1 つの特殊なケースは、ステーション 0 が最大のエネルギーを持つ場合です。 この場合、他のすべてのステーションはエネルギー ≤ a0 でなければならないため、やはり任意の順序が有効になります。 これは、初期しきい値にすべての適格な n がすでに含まれているという事実をアルゴリズムが正しく処理するかどうかをテストします。
