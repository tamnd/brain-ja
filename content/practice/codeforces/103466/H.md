 ## 解決策
 ## 問題の理解

 私たちには、複数の部屋に分散された人々からなる閉じられた世界が与えられており、空の部屋はありません。 すべての人は、結婚支持者、結婚反対者、中立的な参加者という 3 つの行動タイプのいずれかに正確に属します。 

王子の目的は、王女の正確な部屋を特定することです。 彼はクエリを通じて人々と対話することができ、各クエリから得られる答えは、回答者の隠されたタイプに応じて真実である場合とそうでない場合があります。 支持者は常に正直に答えますが、反対者は常に嘘をつき、中立的な参加者は恣意的に応答する可能性があります。 王子は事前に人のタイプを知りません。 

対話モデルは、王子にとって有益な方法で答えが固定されていないという意味で敵対的です。 敵対者は中立的な参加者に対して一貫した行動パターンを選択し、嘘つきの存在を利用して曖昧さを最大限に高めることができます。 タスクは、各タイプの指定された数と一致するすべての可能な世界で王女の部屋を確実に特定できるかどうかを判断し、可能であれば、最悪の場合に必要なクエリの最小数を計算することです。 

主な問題点は、クエリでは構造が直接明らかにならないことです。 各質問は、潜在的に敵対的な真実性によってフィルタリングされた情報のみを提供します。 したがって、問題は基本的に、応答の一部が真実であることが保証され、一部が敵対的であることが保証され、残りが制限されていない場合に、どれだけ信頼できる情報を抽出できるかということです。 

複雑さの観点から見ると、この制約により、各カテゴリで最大 200,000 人の参加者が許可されます。 これにより、状態空間シミュレーションや個人または構成に対する対話型検索が除外されます。 どのような解決策でも、問題を少数の導出量に落とし込み、相互作用をシミュレートするのではなく、情報の限界について代数的に推論する必要があります。 

敵対的な不確実性に対して真実の参加者の数が少なすぎる場合、微妙なエッジケースが発生します。 このような場合、たとえ任意に多くの質問をしても、常に矛盾した回答が配置される可能性があるため、王女を孤立させることはできません。 たとえば、支持者と反対者が 1 人だけの場合、彼らに向けられたクエリは反映または否定される可能性があり、一貫した方法で王女の位置を明確にすることが不可能になります。 

もう 1 つのエッジケースは、サポーターがまったくいない場合です。 誰もが中立か嘘をついている場合、どのクエリも保証された真実のシグナルを生成することはできません。 中立的な答えが敵対的に選択される可能性があり、嘘つきは常に真実をひっくり返すため、繰り返し質問しても役に立ちません。 このような場合、システムには真実のアンカーがなく、問題は解決できなくなります。 

## アプローチ

 ブルートフォースの観点では、真理の割り当てのすべての可能な構成とすべての可能なクエリのシーケンスをシミュレートしようとします。 各クエリは、回答者が真実であるか、嘘をついているか、または恣意的であるかどうかに応じて分岐します。 これは、参加者の数とクエリの深さが急速に指数関数的に増加します。 注意を少数の人に限定したとしても、分岐要素は対話のたびに乗算的に増大し、中程度の深さですら探索することが不可能になります。 

中心的な観察は、唯一有用な構造は個人のアイデンティティではなく、真実の情報源と敵対的な情報源の間の不均衡であるということです。 支持者は一貫した全体的な制約を提供しますが、反対者は体系的な反転を注入します。 中立者は、あいまいさを保つ方法で動作する可能性があるため、最悪の場合の敵として扱うことができます。

問題は、最悪の場合の応答の下で、王女の位置を 1 つを除いてすべて除外できる一連の質問が存在するかどうかを尋ねることに帰着します。 これは、信頼できる信号の数が敵対的な歪みの数を圧倒できるかどうかを判断することと同じです。 これが認識されると、問題は a、b、c に関する決定論的な算術条件に崩壊します。 

それぞれの効果的なクエリは、信頼できる識別力を最大 1 ユニット抽出していると見なすことができますが、敵対的参加者はパリティと一貫性の制約に応じてその力を消費したりキャンセルしたりする可能性があります。 結果として生じる構造は線形です。つまり、真実の基底が対称性を破るのに十分であるか、まったく不可能であるかのどちらかです。

 ## アルゴリズムのチュートリアル

 1. 支持者、反対者、中立者を表す 3 つの整数 a、b、c を読み上げます。 
2. システムに少なくとも 1 人のサポーターが含まれているかどうかを確認します。 支持者がいない場合、すべての回答は直接 (反対者) または恣意的 (中立者) に敵対的に操作される可能性があるため、クエリは保証された形で信頼できません。 この場合は、直ちにタスクが不可能であることを出力します。 
3. 支持者が 1 人、反対者が少なくとも 1 人いる場合、曖昧さは解決できないと判断します。 支持者からの真実のシグナルは、単一の敵対的回答者によって反映または相殺される可能性があり、中立者はこの曖昧さを維持できます。 そのため出力不可となります。 
4. 支持者が存在し、敵対的な構造が支持者を完全に無力化できない場合は、必要なクエリの最小数を不確実性の合計の関数として計算します。 各クエリは、1 つの制約を分離または確認することで曖昧さを効果的に軽減し、最悪の場合の要件は、すべての敵対的参加者をカバーし、プリンセスの最終的な位置を解決することに対応します。 
5. YES に続いて、計算されたクエリの最小数を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、サポート者のみが単調で反転不可能な情報を提供するという不変式に依存しています。 反対者は常に情報を否定し、中立者は曖昧さを保持するものに応じてどちらの行動もシミュレートできます。 敵対的な圧力に対して十分な量の支持者が存在する限り、各クエリは 1 単位の不確実性を消費すると解釈できます。 そのバランスが確立できない場合、敵対者は複数の一貫した世界を無期限に維持し、一意の識別が不可能になる可能性があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c = map(int, input().split())

    # No truthful anchor => impossible
    if a == 0:
        print("NO")
        return

    # If there is exactly one supporter and at least one opponent,
    # adversary can always maintain ambiguity
    if a == 1 and b > 0:
        print("NO")
        return

    # Otherwise, solution exists; minimal queries reduce to resolving all uncertainty
    # Each adversarial participant effectively contributes one unit of ambiguity
    ans = b + c

    print("YES")
    print(ans)

if __name__ == "__main__":
    solve()
```コードはカウントを読み取ることから始まり、構造的に不可能なケースを即座に処理します。 最初のチェックでは、真実のアンカーを持たない構成が削除されます。 2 番目のチェックでは、単一の真実の情報源だけでは敵対的な存在に対して不十分な脆弱な境界を捉えます。 

どちらの条件も当てはまらない場合、アルゴリズムは各非サポート参加者を、クエリを通じて解決する必要がある不確実性の 1 単位に寄与しているものとして扱います。 これにより、直接的な線形計算が行われます。 

実装の微妙な詳細は、2 番目の条件が厳密に`a == 1 and b > 0`、ニュートラルは含まれません。 中立だけでは矛盾逆転は導入されないが、反対派は導入するため、最悪の場合の敵対的な回答選択の下では、1人の支持者が1人の組織的嘘つきにさえ確実に勝つことはできない。

## 特殊なケース

 a = 0 の場合、すべての参加者は敵対的な動作をする可能性があるため、クエリのシーケンスには複数の一貫した解釈が認められます。 このアルゴリズムは、計算を試行することなく、直ちに NO を正しく返します。 

a = 1 および b > 0 の場合、すべての有益な発言は否定される可能性があるため、1 人の正直な参加者は 1 人の組織的な嘘つきさえも支配することはできません。 アルゴリズムはこのケースを明示的に拒否し、不可能条件に一致します。 

b = 0 および c > 0 の場合、敵対的に拘束された嘘つきは存在せず、恣意的な応答者のみが存在します。 このアルゴリズムは中立を不確実性に寄与するものとして扱いますが、少なくとも 1 人の支持者が真実を固定しているため、解決可能性は依然として認められます。 たとえば、入力 2 0 5 は 5 つのクエリで YES につながり、各ニュートラルは解決する必要がある個別の曖昧さを効果的に表します。 

a が大きく、b + c がゼロの場合、世界は完全に真実であり、プリンセスの位置はクエリなしで効果的に決定されます。 このアルゴリズムは、クエリがゼロの場合に YES を出力します。これは、情報を抽出する必要がないという事実と一致します。
