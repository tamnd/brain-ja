 ## 解決策
 ## 問題の理解

 1 から n までの整数のセットが与えられます。 タスクは、この範囲からサイズ k のサブセットをどのように選択しても、そのサブセット内で一方が他方を除算する 2 つの異なる数値 u と v が必ず見つかるように、最小の数値 k を決定することです。 

言い換えれば、セットに約数の関係にある数値のペアが含まれることが避けられなくなる前に、そのセットがどのくらいの大きさでなければならないかを理解しようとしているのです。 出力は、指定された各 n に対する最小強制サイズ k です。 

この制約により、n は最大 10^9 および最大 10^5 のテスト ケースが許可されるため、前処理または直接式の後に、テスト ケースごとに解が O(1) になる必要があります。 テスト ケースあたりの O(n) さえも天文学的に大きいため、n までの範囲で反復したり、サブセットを構築したりするアプローチは、直ちに実行不可能になります。 

n が小さい場合、微妙なエッジケースが現れます。 たとえば、n = 2 の場合、セットは {1, 2} になります。 サイズ 2 のサブセットにはすでに (1, 2) が含まれており、1 で 2 を割るので、答えは 2 になります。n = 3 の場合、セットは {1, 2, 3} になります。 サイズ 2 のサブセット (たとえば、{2, 3}) は割り切れる可能性を回避できますが、サイズ 3 のサブセットには 1 が含まれている必要があるため、割り切れるペアが強制されます。 これは、答えの構造が、数字を慎重に選択することで割り切れないようにできるかどうかに関係していることをすでに示唆しています。 

素朴な直感は、鎖や素構造を探すことを示唆するかもしれませんが、実際の障害はもっと単純です。一方が他方を分割するペアを含まない、{1, ..., n} の最大の部分集合が必要です。 したがって、答えは、このようなサブセットの最大サイズより 1 つ大きくなります。 

## アプローチ

 この問題を考える強引な方法は、サブセットを列挙し、サイズ k の各サブセットに常に割り切れるペアが含まれているかどうかを確認することです。 これは概念的には簡単です。固定 k の場合、サイズ k のすべてのサブセットをチェックし、プロパティを検証します。 サブセットの数は二項(n, k)であり、nで指数関数的であるため、これはすぐに不可能になります。 単一のサブセットをチェックするだけでも O(k^2) 回の割り算チェックが必要なため、このアプローチは n が大きくなるずっと前に失敗します。 

重要な洞察は視点を変えることです。 割り算を強制する代わりに、割り算関係をまったく持たない可能な限り最大のサブセットを構築しようとします。 このような「除数のない」セットの最大サイズを見つけることができれば、それより大きなセットは条件に違反するはずであるため、答えはそのサイズに 1 を加えたものになります。 

ここで、可分性の構造が重要になります。 最大の奇数因数でグループ化された数値を考慮する場合、またはより直接的に、数値が奇数になるまで繰り返し 2 で除算すると、すべての数値が一意の奇数の代表にマッピングされます。 それぞれの奇数 x について、x、2x、4x、8x などの数字はすべて n までの範囲内にあり、それぞれが次の数字を分割するチェーンを形成します。 

このような各チェーン内では、可分性のペアを作成せずに複数の要素を選択することはできません。 したがって、各チェーンから最大 1 つの数字を選択できます。 したがって、除数のない最大サブセットは、範囲内の個別の奇数成分の正確な数になります。これは、2 のべき乗をすべて因数分解した後の、2 で割り切れない 1 から n までの整数の数です。 これは単に [1, n] 内の奇数の整数の数、つまり ceil(n / 2) です。 

したがって、割り切れないペアを持たない最大のサブセットのサイズは ceil(n / 2) であり、不正なペアを強制する最小 k は ceil(n / 2) + 1 です。 

しかし、より注意深く観察すると、より強力な構造が示されます。実際の極値構造は、(n/2, n] 内のすべての数値を選択することです。n/2 より大きい数値の約数は最大でも n/2 でなければならず、集合の外にあるため、これらはいずれも他の数値を除算できません。この集合のサイズは n - Floor(n/2) = ceil(n/2) であり、最適性が確認されています。

 したがって、最終的な答えは単純に ceil(n / 2) + 1 になります。

 ## アルゴリズムのチュートリアル

 1. サイズ k のすべてのサブセットに割り切れるペアが含まれるように、最小の k が必要であることに注目してください。 これを、割り切れないペアのない最大のサブセットを見つけて、1 を追加するという形で再定式化します。 
2. 範囲 (n/2, n] から数値のみを選択して、割り算を回避するサブセットを構築します。この範囲では、任意の 2 つの数値は厳密に n/2 より大きいため、除数は n/2 以下である必要があり、除外されるため、他の数値を割り切ることはできません。
 3. (n/2, n] に含まれる数値の数を数えます。この数は n - Floor(n/2) であり、ceil(n/2) と等しくなります。
 4. これより大きいサブセットには、v を分割する u のペアが少なくとも 1 つ含まれている必要があると結論付けます。これは、分割可能関係の単一の重複しない最大アンチチェーン内に完全に留まることができないためです。 
5. ceil(n/2) + 1 を答えとして返します。 

### なぜ効果があるのか

 n までの整数の割り算関係は、チェーンが 2 の繰り返しの乗算に対応する半順序を形成します。 区間 (n/2, n] は、この半順序で最大のアンチチェーンを形成します。これは、割り算の下で比較できる 2 つの要素が存在しないことを意味します。そのサイズが最大となるのは、任意の数値 ≤ n/2 を範囲内の数値に 2 倍することで上に拡張できるためです。そのため、すでに上半分にある要素よりも多くの独立した要素に寄与することはできません。したがって、最大の除数のないサブセットのサイズは ceil(n/2) であり、これより大きいサブセットには必ず比較可能なペアが含まれている必要があり、これを完成させます。 議論。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        ans = (n // 2) + 1
        print(ans)

if __name__ == "__main__":
    solve()
```実装では、派生した式を直接エンコードします。 式 n // 2 は Floor(n/2) を計算し、1 を加算すると必要な k が得られます。 ceil(n/2) + 1 は、floor(n/2) + 1 に単純化されるため、ceil の浮動小数点演算は必要ありません。 

このソリューションは、各テスト ケースを一定時間で独立して処理します。これは、T の値が大きい場合に必要です。

 ## 特殊なケース

 n = 2 の場合、セットは {1, 2} です。 アルゴリズムは (2 // 2) + 1 = 2 を計算します。サイズ 2 の唯一のサブセットは、条件を満たす (1, 2) を含む完全なセットです。 

n = 3 の場合、結果は (3 // 2) + 1 = 2 になります。これは、サイズ 2 のサブセットは割り切れないことを回避できますが、サイズ 3 のサブセットには 1 が含まれている必要があるため、別の要素と割り切れるペアが作成されるという事実と一致します。 

n = 1 の場合、制約の一部ではありませんが、考慮すると式は 1 を与えます。サイズ 1 のサブセットにはペアをまったく含めることができないため、これは一貫しています。
