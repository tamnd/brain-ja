 ## 解決策
 ## 問題の理解

 文字「X」、「V」、「I」、および「?」で構成される文字列が与えられます。 各文字には数値が含まれます。「X」は 10 の価値があり、「V」は 5 の価値があり、「I」は通常 1 の価値がありますが、直後に「X」または「V」が続く場合は -1 としてカウントされます。 文字列値は、そのすべての文字の値の合計です。 疑問符は、文字「X」、「V」、または「I」の任意の組み合わせで置き換えることができますが、置き換えには所定の可用性の制約が考慮される必要があります。 各クエリについて、クエリで許可されている文字のみを使用してすべての疑問符を置き換えた後、可能な最小の文字列値を見つけるように求められます。 

入力は複数のテスト ケースを提供し、それぞれに文字列と複数のクエリが含まれます。 各クエリでは、疑問符の置換に使用できる各タイプの文字の数を指定します。 制約では、長さ 3×10^5 までの文字列と、すべてのテスト ケースにわたるクエリの合計数も最大 3×10^5 まで許可されます。 これは、最悪の場合の疑問符の数が 3×10^5 に近づく可能性があるため、置換のすべての順列を考慮した解決策は非常に遅すぎることを示唆しています。 

問題の微妙な部分は、「私」の定義です。 その値は次の文字によって異なります。つまり、「I」をどこに配置するかについて貪欲に決定すると、明らかではない形で合計値に影響を与える可能性があります。 たとえば、置換可能な「X」が 1 つだけある文字列「I?X」について考えてみましょう。 「?」を置き換えます 「X」を使用すると、最初の「I」が -1 としてカウントされ、合計値が減りますが、「I」に置き換えると +1 になります。 すべての疑問符を最小の絶対文字値 (「I」) に置き換える単純なアプローチでは、可能な最小の合計が得られない可能性があります。 

エッジケースには、すべて疑問符である文字列、「I」で終わる文字列、文字のサブセットのみが使用可能であり、特定の配置が不可能であるクエリが含まれます。 たとえば、文字列「??」 使用可能な文字 1 個の「X」と 1 個の「V」では、「X」または「V」の前の「I」が合計から減算されることを考慮して、どの組み合わせが最小の合計を生成するかを検討する必要があります。 

## アプローチ

 ブルートフォース手法では、クエリごとに疑問符の可能なすべての置換を試し、それぞれの文字列値を計算し、最小値を選択します。 任意の文字列の値を決定論的に計算できるため、これは理論的には機能しますが、置換の数は疑問符の数で指数関数的に増加します。 文字列に疑問符が 10 個ある場合、可能性は 3^10 ≈ 59,000 になります。 3×10^5 個の疑問符がある場合、ブルート フォースはまったく実行不可能です。 ブルートフォースの解決策は正しいですが、遅すぎます。 

重要な観察は、最小値は貪欲な配置戦略によって達成できるということです。 「X」は +10 に貢献し、「V」は +5 に貢献し、「I」は後継に応じて -1 または +1 になる可能性があるため、可能な限り「I」が -1 になる配置を優先する必要があります。 つまり、「I」が「X」または「V」の前にある場合は、合計から減算されます。 したがって、使用可能な最大の文字の前に「I」を配置し、その後に「X」または「V」がない場合にのみ「I」を最後に配置することを目指しています。 同時に、-1 としてカウントされる先行する 'I' の数を最大化するために、'X' と 'V' を末尾の方に配置したいと考えています。 

文字列の固定文字の位置と疑問符の相対位置を事前に計算できます。 次に、クエリごとに、左から右に疑問符を埋めることをシミュレートし、最後に「X」と「V」を選択して、先行する多くの「I」を -1 の寄与に変換します。 残りの文字は「I」として入力されます。 これにより、問題はクエリごとの線形スキャンに縮小され、O(n + q) のソリューションが生成されます。

 ## アルゴリズムのチュートリアル

 1. 疑問符を無視して文字列の基本値を事前計算します。 左から右に繰り返します。「X」の場合は 10、「V」の場合は 5 を加算し、次の文字がわかっている場合はそれに基づいて「I」の値を決定します。 
2. 疑問符の位置を配列に記録します。 左から右の順序で処理していきます。 
3. クエリごとに、文字の可用性を可変カウンタ c_X、c_V、c_I にコピーします。 
4. 文字列を左から右にトラバースします。 「？」が表示されるたびに、 が見つかったら、どの文字を配置するかを決定します。 

- 固定の「X」または「V」の前、または未来の「?」の前に「I」を配置する場合 「X」または「V」に置き換えられると、-1 としてカウントされます。 c_I > 0 の場合、そのような位置に「I」を配置します。 
- それ以外の場合は、-1 としてカウントされる前の 'I' を最大化するために、'X' または 'V' をできるだけ遅く配置します。 それに応じて c_X または c_V を減らします。 
5. 置換後、再度スキャンしてローマ字形式の評価を使用して文字列の合計値を計算します。左から右に繰り返し、「I」の後に「X」または「V」が続く場合は常に -1 としてカウントします。 それ以外の場合は +1。 「X」と「V」の固定寄与分を追加します。 
6. このクエリの合計値を出力します。 

このアルゴリズムが機能するのは、貪欲な選択により、-1 に変換できるすべての「I」が確実に -1 になり、「X」/「V」がこの効果を最大化するように配置されるためです。 利用可能な制限内でのみ文字を割り当てるため、クエリの制約の下で正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def compute_min_value(s, counts):
    n = len(s)
    s = list(s)
    c_X, c_V, c_I = counts
    q_positions = [i for i, ch in enumerate(s) if ch == '?']

    # Greedy assignment
    for i in q_positions:
        # Check if we can force this I to be -1
        # Lookahead to next known character
        if c_I > 0:
            next_char = None
            for j in range(i+1, n):
                if s[j] != '?':
                    next_char = s[j]
                    break
            if next_char in ('X', 'V'):
                s[i] = 'I'
                c_I -= 1
                continue
        # Otherwise assign smallest effect: assign I if available
        if c_I > 0:
            s[i] = 'I'
            c_I -= 1
        elif c_V > 0:
            s[i] = 'V'
            c_V -= 1
        elif c_X > 0:
            s[i] = 'X'
            c_X -= 1

    # Compute string value
    total = 0
    for i in range(n):
        if s[i] == 'X':
            total += 10
        elif s[i] == 'V':
            total += 5
        elif s[i] == 'I':
            if i + 1 < n and s[i+1] in ('X', 'V'):
                total -= 1
            else:
                total += 1
    return total

def main():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())
        s = input().strip()
        queries = [tuple(map(int, input().split())) for _ in range(q)]
        for counts in queries:
            print(compute_min_value(s, counts))

if __name__ == "__main__":
    main()
```この解決策では、まずすべての疑問符の位置を特定します。 各クエリに対して、文字列値を最小限に抑えるために文字を貪欲に割り当てます。-1 ルールを利用するために、「X」または「V」の前に「I」を配置し、空き状況に応じて残りの疑問符を文字で埋めます。 最終的な値の計算では、「I」のローマ式評価ルールが使用されます。
