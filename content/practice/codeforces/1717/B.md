 ## 解決策
 ## 問題の理解

 を構築する必要があります`n × n`のみを含むグリッド`'.'`そして`'X'`。 

グリッドは 2 つの条件を満たす必要があります。 まず、水平方向の長さのすべてのセグメント`k`少なくとも 1 つを含める必要があります`'X'`。 第二に、長さのすべての垂直セグメント`k`少なくとも 1 つを含める必要があります`'X'`。 このようなすべてのグリッドの中で、可能な限り最小数のグリッドが必要です。`'X'`細胞。 さらに、特定の細胞`(r, c)`を含むことが必要です`'X'`。 

入力により、いくつかのテスト ケースが得られます。 テストケースごとに、`n`で割り切れます`k`、これは非常に強力な構造上のヒントです。 私たちはグリッドを検証することを求められているのではなく、グリッドを構築することだけを求められています。 

すべての合計`n`値は最大でも`500`。 たとえ`O(n²)`出力自体には次のものが含まれるため、構築は完全に安全です。`n²`文字。 グリッドを記述するソリューションでは、すでにそれだけの作業が費やされています。 

主な困難はパフォーマンスではなく、有効性と最小数の両方を達成するパターンを発見することです。`'X'`細胞。 

よくある間違いは、`'X'`毎`k`セルは各行に独立して配置されます。 例えば：```
n = 6, k = 3

X..X..
X..X..
X..X..
X..X..
X..X..
X..X..
```すべての行の条件は満たされていますが、列 2 と列 3 には何も含まれていません。`'X'`、非常に多くの垂直セグメントが失敗します。 

もう 1 つの簡単な間違いは、有効な周期パターンを構築したが、必要なセルを忘れてしまうことです。 考慮する：```
n = 3, k = 3, r = 3, c = 2
```斜めのパターン```
X..
.X.
..X
```最小限の数が含まれています`'X'`、しかしセル`(3,2)`はマークされていません。 必要なセルが選択したパターンに属するように、答えをシフトする必要があります。 

エッジケース`k = 1`も重要です。 長さのすべてのセグメント`1`が含まれている必要があります`'X'`、つまり、すべてのセルが次のようになっている必要があります。`'X'`。 マーク間の間隔を想定した構築は、ここでは失敗します。 

## アプローチ

 ブルートフォース的な考え方は、問題を制約を満たすタスクとして扱うことから始まります。 置いてみるのもいいかもしれません`'X'`セルを繰り返し、すべての水平方向と垂直方向の長さを確認します。`k`セグメントをカバーし、最小限の解決策を模索します。 

これは原理的には正しいですが、検索スペースは膨大です。 アン`n × n`グリッドには`2^(n²)`可能な構成。 たとえ`n = 20`、これはまったく不可能です。 

重要な観察は、最小限のソリューションがどのようなものでなければならないかを理解することから得られます。 

すべてのグループからちょうど 1 つのセルを選択するとします。`k`列に沿った位置。 これらの選択された位置が行全体で一貫して並んでいる場合、長さのすべての水平ブロックが`k`自動的に 1 つが含まれます`'X'`。 

非常に自然なパターンは、座標が次の条件を満たすすべてのセルにマークを付けることです。```
(row + column) mod k = constant
```固定行の場合、すべての行のうち 1 列だけ`k`連続する列はこの条件を満たします。 同様に、固定列の場合、すべての列のうち 1 行だけが含まれます。`k`連続する行はそれを満たします。 

これにより、すべての水平方向と垂直方向の長さが即座に保証されます。`k`セグメントには、マークされたセルが 1 つだけ含まれています。 

なぜこれが最小値なのでしょうか? 以来`n`で割り切れます`k`、各行には正確に含まれます`n / k`マークされたセル。 すべての行の合計数は、`'X'`細胞はなる```
n × (n / k) = n² / k
```有効なグリッドには少なくともこの数のマークが必要であり、この構造はその境界を達成します。 

残りのタスクは、次のことが行われるように正しい残基クラスを選択することです。`(r, c)`パターンに属します。 0 から始まるインデックスを使用する場合、必要な剰余は次のようになります。```
(r + c) mod k
```そして、同じ残基を持つすべてのセルにマークを付けます。

 ## アルゴリズムのチュートリアル

 1. 必要な位置を変換します`(r, c)`0 から始まる座標に変換します。 
2. ターゲットの残基を計算します。```
target = (r + c) mod k
```同じ剰余クラスを持つセルは、選択した対角パターンに属します。 
3.`n × n`グリッドは最初に塗りつぶされています`'.'`。 
4. すべてのセルについて`(i, j)`、どうかを確認してください```
(i + j) mod k = target
```true の場合、配置します`'X'`。 
5. 結果のグリッドを出力します。 

これが機能する理由は、マークされたすべてのセルが単一の剰余クラスのモジュロに属しているためです。`k`。 必要なセルはその残基クラスを選択するために使用されたため、マークされることが保証されます。 

### なぜ効果があるのか

 任意の行を考えてみましょう。 列インデックスが 1 つ増えると、`(row + column) mod k`すべての残基を循環します。 すべての中で`k`連続する列の場合、ちょうど 1 つが選択された残基を持ちます。 したがって、長さのすべての水平セグメント`k`正確に 1 つ含まれています`'X'`。 

同じ議論が列にも適用されます。 行インデックスが増加すると、剰余はすべての値を循環するため、長さのすべての垂直セグメントが`k`ちょうど 1 つも含まれています`'X'`。 

各行には正確に次の内容が含まれます`n / k`マークされたセル`n`で割り切れます`k`。 したがって、マークの合計数は次のようになります。`n² / k`、これは達成可能な最小数です。 選ばれた残基は`(r + c) mod k`、必要なセルは常に含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, k, r, c = map(int, input().split())

    r -= 1
    c -= 1

    target = (r + c) % k

    grid = []

    for i in range(n):
        row = []
        for j in range(n):
            if (i + j) % k == target:
                row.append('X')
            else:
                row.append('.')
        grid.append(''.join(row))

    print('\n'.join(grid))
```最初のステップでは、指定された座標を 0 から始まるインデックスに変換します。 Python のインデックスは自然にゼロから始まるため、これによりモジュラー演算がよりクリーンになります。 

値`target`どの対角剰余クラスにすべてが含まれるかを決定します`'X'`細胞。 あらゆる細胞が満足`(i + j) % k == target`マークが付いています。 

ネストされたループはすべてのセルを 1 回だけ訪問し、出力グリッドを構築します。 答え自体に含まれているため、`n²`文字の場合、漸近的に高速に構築することはできません。 

最も一般的な実装上の間違いは、変換を忘れることです。`(r, c)`剰余を計算する前に 0 ベースの座標に変換します。 1 から始まる座標を使用すると、パターン全体がシフトされ、必要なセルがマークされないままになる場合があります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n, k, r, c = map(int, input().split())

        r -= 1
        c -= 1
        target = (r + c) % k

        for i in range(n):
            row = ''.join(
                'X' if (i + j) % k == target else '.'
                for j in range(n)
            )
            out.append(row)

    return "\n".join(out)

# sample 2 from statement
assert run("1\n2 1 1 2\n") == "XX\nXX"

# minimum size
assert run("1\n1 1 1 1\n") == "X"

# k = n
assert run("1\n3 3 3 2\n") == "X..\n..X\n.X."

# off-by-one check near border
assert run("1\n4 2 4 4\n") == ".X.X\nX.X.\n.X.X\nX.X."

# larger periodic pattern
assert run("1\n6 3 4 2\n") == ".X..X.\nX..X..\n..X..X\n.X..X.\nX..X..\n..X..X"
