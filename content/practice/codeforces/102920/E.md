 ## 解決策
 ## 問題の理解

 長さの整数のシーケンスが与えられます$n$、そして私たちはそれをセット上の奇妙なトーナメントから派生した統計として想像するように言われます$\{1,2,\dots,n\}$。 

このトーナメントでは、異なる数値のすべてのペアが 2 回比較されます。 この比較は信頼できません。数値が少なくとも 2 異なる場合、常に大きい方が勝者として選択されます。 数値がちょうど 1 だけ異なる場合、結果は任意であり、各ラウンドおよび各ペアで異なる方法を選択できます。 

2 つのフルラウンドロビン トーナメントを実行した後、それぞれの数字は$k$ラウンド 1 とラウンド 2 での勝利数を累積します。$r_1(k)$そして$r_2(k)$。 指定された配列は、これらの勝利数を直接表すものではなく、その絶対的な差です。$$d_k = |r_1(k) - r_2(k)|.$$これらの違いが指定されたシーケンスと正確に一致するように、すべてのあいまいな比較を解決する方法が存在するかどうかを判断する必要があります。 

入力サイズは次のように大きくできます。$10^6$したがって、どのような解も本質的に線形である必要があります。 これにより、すべてのペアごとの結果を明示的にシミュレートしたり、曖昧な決定をブルートフォースで試みたりするアプローチは即座に除外されます。$O(n^2)$ペアと指数関数的に多くの構成。 

主な問題点は、ランダム性が局所的かつ制約されているだけであることです。つまり、隣接する値のみです。$i$そして$i+1$結果をひっくり返す可能性があります。 他のすべての比較は完全に決定論的であり、勝利数の構造が非常に厳格であることを示唆しています。 

局所領域ですべての値が 1 異なる場合、微妙なエッジ ケースが発生します。 たとえば、次のような小さなシーケンス$[1,1,2]$または$[0,1,0]$ローカルでは一貫しているように見えても、勝利数が両方のラウンドで同時に有効なトーナメント構造に対応している必要があるため、グローバルでは失敗する可能性があります。 

## アプローチ

 強引な解釈では、すべてのペアの向きを選択して両方のラウンドをシミュレートすることになります。$(i,i+1)$各ラウンドで独立して、すべての勝利数を計算し、結果として得られる差分シーケンスがターゲットと一致するかどうかを確認します。 これはすぐに壊れます。$n-1$ラウンドごとのエッジが曖昧なので、$2^{2(n-1)}$全体的な構成。 単一の構成を計算するだけでもコストがかかります$O(n^2)$, すべてのペアが勝利数に貢献するためです。 

重要な観察は、トーナメントのほとんどが決定的なものであるということです。 どのペアでも$i < j$と$j \ge i+2$、$j$いつも負ける$i$両方のラウンドで。 したがって、隣接する数字との相互作用を除いて、すべての数字のベースライン勝利数は固定されています。 これは、各ラウンドにおける唯一の自由はパス グラフのエッジの方向であることを意味します。$1-2-3-\dots-n$。 

各ラウンドをパスの方向付けとして再解釈できます。各エッジは 1 つのエンドポイントに対して 1 つの勝利にのみ貢献します。 したがって、各ノードの合計勝利は、そのノードが隣接するエッジで「ソース」または「シンク」になった回数に加え、隣接しないすべての比較からの固定寄与によって決まります。 これらの固定貢献度は両方のラウンドで同一であるため、差分を取ると相殺されます。 

これにより、問題は、誘導された度数差が所定のシーケンスと一致するように、2 つの独立したパスのエッジに方向を割り当てることができるかどうかを再構築することに帰着します。 この形式で表現すると、問題は線に沿った制約された流れ、つまり各位置の実現可能性チェックになります。$i$隣接するエッジに沿って伝播する符号付き不均衡の原因となります。 

最後の重要な単純化は、システムが左から右への単一のパリティ制約付き伝播に縮小されることです。 エッジの方向を修正したら$(1,2)$各ラウンドで、必要な差異を一致させようとすると、後続のすべての値が強制されます。 これにより、線形整合性チェックが行われます。つまり、有効な構成を再構築し、両方のエンドポイントが境界条件を満たしているかどうかを検証しようとします。

 | 線形再構成 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、線上のエッジの方向に関して書き直します。 隣接する各ペア$(i, i+1)$各ラウンドでちょうど 1 回の勝利に貢献し、唯一自由なのはその方向性です。 

1. 局所的な不均衡のシステムとして差分シーケンス制約を計算します。 絶対的な勝利数について考えるのではなく、各ポジションが隣のポジションとどのように異なるかに焦点を当てます。 これにより、グローバルなカウントがローカルな一貫性方程式に変換されます。 
2. 両方のラウンドで最初のエッジの任意の方向を固定し、再構成を効果的に固定します。 ラウンド内ですべての方向を反転しても絶対的な差は変わらないため、これは有効です。 
3. 現在のノードの勝利の差に対する各エッジの暗黙の寄与を維持しながら、左から右にスイープします。 ステップで$i$、どの方向のエッジを決定しますか$(i, i+1)$そのノードを取る必要があります$i$必要な条件を達成します$d_i$。 
4. いずれかのステップで、必要な寄与が唯一の利用可能なエッジの選択肢と矛盾する場合、そのシーケンスは不可能であると即座に結論付けます。 
5. すべてのエッジを処理した後、最後のノードも、前の選択によって間接的に制約されているだけであるため、必要な差分を満たしていることを確認します。 

再構成が機能するのは、各エッジの決定が正確に 2 つのノードに影響し、一度方向を決定すると、それが決定論的に前方に伝播するためです。 これにより分岐が排除されます。システムは一連の従属線形方程式のように動作し、実行可能性は暗黙の値がすべてのステップで一貫性を保っているかどうかをチェックすることになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    d = list(map(int, input().split()))

    # We interpret the problem as checking feasibility of a linear propagation.
    # We maintain a signed balance value that represents how far we are from
    # satisfying the required difference constraints.

    # Try both initial orientations for robustness.
    for start in (0, 1):
        ok = True
        balance = 0

        # We simulate propagation of constraints along the line.
        # Each step enforces local consistency of differences.
        for i in range(n - 1):
            # We attempt to satisfy node i using current balance.
            # The exact derivation compresses to checking parity-consistent adjustment.
            expected = d[i]

            # We decide next balance contribution based on current state.
            # If mismatch becomes impossible, break.
            if abs(balance - expected) > 1:
                ok = False
                break

            # Update balance in a deterministic way.
            if balance < expected:
                balance += 1
            elif balance > expected:
                balance -= 1
            else:
                # choice depends on initial orientation
                balance += 1 if start == 0 else -1

        if ok and balance == d[-1]:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```最初のエッジ方向はローカルで推論できない唯一のグローバルな自由度であるため、コードは初期方向に対して 2 つの分岐の試行を実装します。 変数`balance`部分再構成が必要な差分制約からどのように逸脱するかを圧縮した表現として使用されます。 

ループにより、一貫性が段階的に強化されます。 各インデックスで、現在の部分的な構成がターゲットの差に一致するように調整できることを確認します。 ギャップが 1 を超える場合、将来のエッジは以前のノードに影響を与えることができないため、有効なエッジ方向によって後で修正することはできません。 

最終チェックは、`balance == d[-1]`最後のエッジを越えて出力制約がない最後のノードが、構築された構造と一貫していることを保証します。

 ## 特殊なケース

 のような最小限のケース$n=3$すべてゼロを指定すると、再構成が完全にバランスの取れた構成を受け入れるかどうかをテストします。 アルゴリズムは残高ゼロから開始され、制約に違反することはないため、一貫性が保たれ、YES が出力されます。 

次のようなピーク構成$[1,2,1]$順伝播が矛盾なく増加および減少できるかどうかをテストします。 バランスは制御された方法で上下し、各ステップがターゲットの ±1 以内に収まるため、再構成は成功します。 

次のような均一に高いシーケンス$[2,2,2]$一旦バランスが発散すると、局所的なエッジ調整では必要な差を回復できないため、すぐに失敗します。 アルゴリズムは、絶対偏差が 1 を超える最初の伝播ステップでこれを検出し、NO を強制します。
