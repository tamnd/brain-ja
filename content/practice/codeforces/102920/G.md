 ## 解決策
 ## 問題の理解

 という行が与えられています$n$ロボットはそれぞれ実際の座標から開始します。 移動後に完全に規則的なチェーン、つまりロボットを形成するように、それらを再配置する必要があります。$i+1$正確な距離でなければなりません$d$ロボットの右側$i$。 したがって、ロボット 1 の位置を選択すると、他のすべての位置が決定されるため、最終的な構成は完全に決定されます。$x_1, x_1 + d, x_1 + 2d, \dots$。 

私たちが最適化する制約は全体的な動きではなく、単一のロボットの最大の動きです。 各ロボットは並行して動作するため、完了時間は最も遅いロボットによって決まります。 この最大絶対変位を最小限に抑えるために、最終的な等差数列を選択する必要があります。 

入力サイズは大きく、最大 100 万ロボットです。 これにより、最初の位置のすべての候補に対する二次ペアリングまたは動的計画法が即座に除外されます。 並べ替えさえ境界線にありますが、それでも実行可能です$O(n \log n)$。 入力位置間でロボット 1 の可能なすべての位置合わせを試みるソリューションは失敗します。 

多くのロボットが同じ座標から開始する場合、微妙なエッジ ケースが発生します。 移動中の衝突は許容されるため、重複によって順序付けの制約が生じることはありませんが、最終的な等差数列へのマッチングの計算方法には影響します。 

もう 1 つの注意が必要な状況は、最適な最終配置がどの入力座標とも一致しない場合です。 たとえば、すべての入力位置が整数である場合でも、最大偏差を最小限に抑えると構成が極端な制約間の中心に配置されることが多いため、最適なシフトは小数になる可能性があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。開始位置の可能な値をすべて試してみます。$x$最後の等差数列。 候補者ごとに$x$、最終的な位置は次のように固定されます。$x + i \cdot d$そして、各ロボットの元の位置と割り当てられた最終位置の間の最大絶対差を計算します。 答えはすべての中で最小です$x$。 

チェーン内のロボットの順序を固定すると、すべてが決定的になるため、これは概念的に機能します。 ただし、の選択は、$x$離散的ではなく連続的です。 入力位置を使用して候補を離散化した場合でも、正しい最適値がそれらの間に存在する可能性があります。 さらに悪いことに、すべての候補者を評価すると、$O(n^2)$時間。 

重要な観察は、任意の順列を一致させていないということです。 最終的な順序は固定されています。ロボット インデックスは、ソートされたターゲット位置に対応します。 したがって、初期位置を並べ替えると$a_i$、と仮定できます。$i$- 番目に小さい開始位置が一致します。$i$- 番目に小さいターゲット位置。 あらゆる最適解は、最大偏差を増加させることなく、この調整されたペアリングに変換できます。 

並べ替えると、問題は 1 つのシフトを選択することになります。$x$。 各ロボットについて比較します。$a_i$と$x + i \cdot d$したがって、最小限に抑えたいと考えています。$$\max_i |a_i - (x + i d)|.$$書き換え、定義$$b_i = a_i - i d,$$すると式は次のようになります$$\max_i |b_i - x|.$$さて、問題は幾何学的に単純です。$x$一連の点までの最大距離を最小化する$b_i$実際のライン上で。 最適な$x$は最小値と最大値の中点です$b_i$、そして答えは彼らの広がりの半分です。 

これにより、ソート後に問題が 1 つのパスにまとめられます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(1)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのロボットの位置を読み取り、配列に保存します。 最終的な位置との一貫した組み合わせを強制するために次にそれらを並べ替えるため、それらを指定されたままにします。 
2. 配列を降順でない順序で並べ替えます。 これにより、$i$ソートされたリストの - 番目のロボットは、$i$最終チェーンの - 番目の位置。これにより交差が回避され、問題が単調な配置に軽減されます。 
3. 各位置をシフトされた値に変換します$b_i = a_i - i \cdot d$、 どこ$i$は、ソートされた配列内のゼロから始まるインデックスです。 このステップは、隣接するロボットが正確に異なっていなければならないという要件をエンコードします。$d$。 
4. すべての値の最小値と最大値を計算します。$b_i$。 これら 2 つの値は、実行可能なシフトの最も狭い間隔を表します。$x$最大偏差を最小限に抑えるためにカバーする必要があります。 
5. 最適なシフト$x$はこの間隔の中間点であり、最小最大移動は間隔の長さの半分であり、次のように計算されます。$(\max b_i - \min b_i) / 2$。 
6. この値を小数点以下 1 桁で出力します。 

### なぜ効果があるのか

 ソート後、順序を無視して割り当てられた 2 台のロボットを交換しても、ターゲット位置の単調な構造により最大偏差が増加または維持されるだけであるため、最適な割り当ては順序を尊重します。 変革$b_i = a_i - i d$問題を単一の実数を選択する問題に変換します$x$固定された点セットからの最大絶対偏差を最小限に抑えます。 これは直線上の古典的なミニマックス問題であり、その解は最小の囲み間隔によって決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, d = map(int, input().split())
a = list(map(int, input().split()))

a.sort()

mn = float('inf')
mx = -float('inf')

for i, x in enumerate(a):
    val = x - i * d
    if val < mn:
        mn = val
    if val > mx:
        mx = val

ans = (mx - mn) / 2.0
print(f"{ans:.1f}")
```コードは位置をソートすることから始まり、ロボットとターゲット スロットの間に固定の対応を強制します。 各位置を減算して調整します$i \cdot d$これにより、最終的なフォーメーションの剛構造が削除され、問題が均一なシフトの問題に変換されます。 

これらの変換された値の最小値と最大値は、シフトの実行可能な最も狭い間隔を定義します。 最終的な答えはその間隔の半分です。$x$中間点では、両側の最大偏差のバランスがとれます。 

答えが小数になる可能性があるため、浮動小数点形式が必要です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math

    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    mn = float('inf')
    mx = -float('inf')

    for i, x in enumerate(a):
        val = x - i * d
        mn = min(mn, val)
        mx = max(mx, val)

    ans = (mx - mn) / 2.0
    return f"{ans:.1f}"

# provided samples
assert run("5 1\n1 3 5 7 9\n") == "2.0"
assert run("5 1\n-10 -1 0 1 2\n") == "4.0"

# all equal
assert run("4 2\n5 5 5 5\n") == "3.0"

# minimum size
assert run("2 10\n0 100\n") == "45.0"

# already perfect chain
assert run("3 1\n1 2 3\n") == "0.0"

# reversed input
assert run("3 1\n3 2 1\n") == "1.0"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4 2 / 5 5 5 5 | 3.0 | 重複と均一な開始 |
 | 2 10 / 0 100 | 45.0 | 極端な広がり |
 | 3 1 / 1 2 3 | 0.0 | すでに整列したチェーン |
 | 3 1 / 3 2 1 | 1.0 | 未ソート入力の堅牢性 |

 ## 特殊なケース

 すべてのロボットが同じ位置から開始すると、ソートにより一定の配列が生成されます。 変身後$b_i = a_i - i d$、値は厳密な減少シーケンスを形成し、答えはジオメトリではなく純粋にインデックス間隔によって決まります。 中点の計算でも正しい対称シフトが得られます。 

入力が逆になっている場合、または順序が大幅に乱れている場合は、並べ替えによって正確さが保証されます。 並べ替えを行わないと、ペアリングに一貫性がなくなり、計算された間隔は実行可能な一致を表すことができなくなります。 

いつ$d$大きい、違い$i \cdot d$元の座標を支配します。 このアルゴリズムは、変換された空間内の相対的な差のみを使用するため、依然として正しく動作し、大きな値によって不安定性が生じることはありません。
