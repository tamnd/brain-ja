 ## 問題の理解

 無向グラフがあります。`n`場所。 ヒーローたちはその場所から始まる`1`、避難所はその場所にあります`n`そしてアリオスはすでに占領している`k`場所。 

アリオットは単一のキャラクターのように動きません。 それは広がります。 時間内に場所が占有された場合`t`、永遠に占領されたままになり、さらに広がり始めます。 グラフの用語では、Alioth の頂点への到着時間は、単に最初に占有されていた頂点からの最短距離になります。 

拠点間に追加のトンネルを構築することが許可されています。 目標は、ヒーローたちがアリオスよりも厳密に早くシェルターに到着できるようにしながら、できるだけ多くのトンネルを追加することです。 ある場所に両方が同時に到着した場合、ヒーローは負けます。 

入力により、初期グラフと感染場所のセットが得られます。 出力は、構築できる新しいトンネルの最大数です。 どうやっても生き残れないなら印刷しなければならない`-1`。 

グラフには以下が含まれます`10^5`頂点と`2·10^5`エッジ。 考えられるすべての追加エッジを個別に推論しようとする解決策は、遅すぎるでしょう。なぜなら、完全なグラフには大まかな内容が含まれるからです。`n²/2`エッジ。 線形または線形に近い時間でチェックできる特性評価が必要です。

 ブルートフォースアプローチでは、どの欠落エッジを追加してもよいか、どのエッジを欠落のままにしておく必要があるかを推論しようとします。 まであります$$\frac{n(n-1)}2$$可能なエッジ、つまり約`5·10^9`いつ`n = 10^5`。 すべての潜在的なエッジを反復処理することさえ不可能です。 

重要な観察は、ヒーローに必要な安全なルートは 1 つだけであるということです。 トンネルは自由に追加できるため、最適なルートは明らかです。接続します。`1`直接に`n`そのエッジがまだ存在しない場合は、1 回の移動で移動します。 

ヒーローたちは時間とともにスタートする`0`頂点内`1`そして時間通りに避難所に到着`1`。 

この計画が機能するには、アリオスが頂点に到達する必要があります`n`厳密には時間が経ってから`1`。 Alioth は最短経路で拡散するため、これは感染したすべての頂点から頂点までの距離を意味します。`n`少なくとも`2`。 

アリオスを到達させることができるもの`n`ワンステップで？ まさに、感染した頂点と頂点の間のエッジです。`n`。 

これにより、最適なグラフの全体構造が即座に得られます。 

感染した頂点がすでに接続されている場合`n`最初のグラフでは、後で何を追加しても、Alioth は 1 ステップで避難所に到着します。 生き残るのは不可能だから答えは`-1`。 

それ以外の場合は、感染した頂点を直接接続するエッジを除くすべての欠落エッジを追加できます。`n`。 

これらの禁断のエッジは、アリオスの避難所への到着時間を少なくとも 1 時間から短縮できる唯一のものです。`2`まさに`1`。 

させて`k`感染した頂点の数になります。 完全なグラフには次のものがあります。$$\frac{n(n-1)}2$$エッジ。 正確に除外する必要があります`k`エッジ、つまり`(infected, n)`。

 ## アルゴリズムのチュートリアル

 1. 感染した頂点を読み取り、ブール配列でマークします。 
2. 既存のエッジをすべて読み取ります。 
3. エッジの読み取り中に、1 つのエンドポイントがシェルターであるかどうかを確認します`n`もう一方のエンドポイントは感染しています。 
4. そのようなエッジが存在する場合は、印刷します。`-1`。 

アリオスはすでにシェルターに一歩で到達できます。 英雄たちは厳密にはそれより早く到着することはできません。 
5. それ以外の場合は計算します$$\text{complete} = \frac{n(n-1)}2.$$6. 最終的なグラフには、エッジを除くすべてのエッジが含まれる場合があります。`k`感染した頂点とシェルターの間のエッジ。 
7. 新しいトンネルの最大数は次のとおりです。$$\text{complete} - k - m.$$8. その値を出力します。 

### なぜ効果があるのか

 感染した頂点がシェルターに隣接している場合、アリオスは時間どおりにシェルターに到着します。`1`。 ヒーローの開始場所からのルートはいずれも少なくとも 1 回の移動が必要となるため、ヒーローの最善の到着時間も次のようになります。`1`。 条件が厳しいので生存は不可能です。 

感染した頂点がシェルターに隣接していないと仮定します。 を除くすべての可能なエッジを含むグラフを構築します。`k`禁断の縁`(infected, n)`。 

The heroes travel directly from`1`に`n`ワンステップで。 

アリオスは届かない`n`感染した頂点から頂点までのすべてのエッジを 1 つのステップで処理できるため、`n`は不在です。 したがって、アリオスは到達します`n`時間より早くないでください`2`。 

英雄たちは時間通りに到着する`1`、厳密にはそれより前です。 

形状以外の追加エッジ`(infected, n)`アリオスの下の避難所への到着時間は短縮されません`2`したがって、そのようなエッジはすべて安全に追加できます。 このグラフは最大値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
infected = list(map(int, input().split()))

bad = [False] * (n + 1)
for v in infected:
    bad[v] = True

impossible = False

for _ in range(m):
    u, v = map(int, input().split())

    if u == n and bad[v]:
        impossible = True
    if v == n and bad[u]:
        impossible = True

if impossible:
    print(-1)
else:
    total_edges = n * (n - 1) // 2
    answer = total_edges - k - m
    print(answer)
```最初の部分では、感染したすべての頂点をブール配列に格納するため、メンバーシップ チェックは一定時間で行われます。 

エッジを読み取る際に気にするのは 1 つの条件だけです。それは、シェルターがすでに感染した頂点に隣接しているかどうかです。 グラフの走査は必要ありません。 

そんな縁があれば答えはすぐに`-1`。 

それ以外の場合は、グラフ全体のサイズを計算し、`k`感染した頂点をシェルターに接続する永久に禁止されたエッジ。 グラフにはすでに含まれています`m`したがって、残りの数は正確にまだ構築できるトンネルの数です。 

すべての算術演算では 64 ビット サイズの値が使用されます。 Python では、整数には制限がないため、オーバーフローのリスクはありません。 の最大値`n(n-1)/2`についてです`5·10^9`、とにかく快適にフィットします。
