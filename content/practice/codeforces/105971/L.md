 ## 解決策
 ## 問題の理解

 この問題は、次の点を頂点とする直角二等辺三角形内を移動する点を記述します。`(0,0)`、`(0,n)`、 そして`(n,0)`。 ポイントは次から始まります`(x,y)`そして速度を持って動きます`(vx,vy)`。 三角形の辺に触れると、光線のように反射します。 星系を離れる唯一の方法は、三角形の角に正確に到着することです。 これが実際に起こるかどうかを判断する必要があります。起こった場合は、コーナーに到達するまでに側面衝突が何回発生するかをカウントする必要があります。 

の値`n`、座標、および速度は次のように大きくできます。`10^9`、最大で`10^4`テストケース。 反射の数が膨大になる可能性があるため、衝突から衝突への移動に基づいたシミュレーションは不可能です。 すべての単位時間またはすべての訪問位置を通過しようとするアプローチでさえ、利用可能な操作をはるかに超えています。 幾何学を、各テスト ケースが対数時間で処理される数論の問題に変換する必要があります。 

難しいケースは、コーナーに到達することと側面に接触することは異なるという事実から生じます。 たとえば、パスが次の範囲に達した場合、`(n,0)`まさに、それは逃避であり、反省ではありません。 越えた境界線をすべてカウントするアプローチでは、このイベントが過大にカウントされてしまいます。 

入力用```
6 2 2 5 2
```答えは`2`。 展開されたパスは、2 つの辺を横切った後、三角形の頂点に達します。 単純な衝突カウンターでは最終コーナーを 3 回目の衝突としてカウントする可能性がありますが、これは正しくありません。 

入力用```
4 1 1 2 1
```答えは`-1`。 軌道は頂点に揃うことなく繰り返し続けます。 開始オフセットも重要であるため、移動方向だけをチェックするだけでは十分ではありません。 

入力用```
6 2 3 2 3
```答えは`5`。 ポイントは最終的に頂点に到達しますが、速度方向だけでは反射の数はわかりません。 展開平面内のパス全体の長さが必要です。 

## アプローチ

 簡単な解決策は、動きをシミュレートすることです。 ポイントが到達する次の面を計算し、速度を反映して続行できます。 シミュレーションは物理規則に正確に従っているため、これは正しいです。 問題は、反射の数が非常に多くなる可能性があることです。 周囲の座標と速度`10^9`、コーナーに到達するまでのイベントの数も膨大になる可能性があるため、このアプローチを完了することはできません。 

重要な観察は、三角形を展開することで反射を除去できるということです。 移動点が側面にぶつかったときにそれを反射するのではなく、その側面を横切る三角形を反射します。 移動点は永遠に直線を続けることができます。 これにより、バウンス パスが、ミラー化された三角形でタイル化された平面を通過する法線に変換されます。 

この無限タイリングでは、元の三角形の頂点はすべて、両方の座標が の倍数となる点になります。`n`。 問題は初めての発見です`t`次のような:```
x + vx * t = multiple of n
y + vy * t = multiple of n
```2 つの合同式は一緒に解かれます。 共通の時間が存在しない場合、答えは次のようになります。`-1`。 

最終的な展開位置を見つけた後`(X,Y)`、反射の数は、タイル境界に到達する前に横切ったタイル境界の数です。 交差した境界線は、反射によって作成された垂直線、水平線、および 2 つの対角線ファミリーです。 最終点は頂点であるため、境界ヒットとしてカウントされるべきではないため、厳密に終点より前の行のみをカウントします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルートフォース | O(反射回数) | お(1) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. 分割`vx`そして`vy`それらの最大公約数によって。 これにより、速度から無駄なスケーリングが削除され、同じパスが維持されます。 頂点に到達する瞬間は、速度ではなく方向比のみに依存します。 
2. 2 つの合同式を解きます。```
vx * t = -x (mod n)
vy * t = -y (mod n)
```using the Chinese Remainder Theorem. 最初の合同式は、X 座標がグリッド線と整列する可能性のある時間を示し、2 番目の合同式は Y 座標に対しても同じことを行います。 

1. 2 つの合同式に互換性がない場合、出力`-1`。 展開平面には、この光線上の三角形の頂点に対応する点はありません。 
2. 展開された目的地の座標を計算します。```
X = x + vx * t
Y = y + vy * t
```これらは次の倍数であることが保証されています`n`。 

1. 交差するタイル境界の数を数えます。 垂直境界と水平境界は、内部倍数の数に寄与します。`n`交差した。 対角境界は、展開されたグリッドの変換された対角座標を使用してカウントされます。 
2. 合計数を返します。 このステートメントではエスケープ前の境界へのタッチのみがカウントされるため、最後の頂点自体は除外されます。 

この方法が正しい理由は、展開によって距離と角度が維持されるためです。 元の三角形のすべての反射は、鏡映されたコピーに直接入り続けることと同じです。 元の三角形の頂点に到達することは、展開された平面で繰り返される頂点の 1 つに到達することとまったく同じです。 したがって、モジュラー方程式は可能な脱出の瞬間を正確に見つけ、ラインカウントは反射の数を正確に示します。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

def inv(a, mod):
    return egcd(a, mod)[1] % mod

def solve_one(n, x, y, vx, vy):
    g = gcd(vx, vy)
    vx //= g
    vy //= g

    def get_solution(v, pos):
        d = gcd(v, n)
        if pos % d:
            return None
        v //= d
        n2 = n // d
        pos //= d
        return (-pos * inv(v % n2, n2)) % n2, n2

    a = get_solution(vx, x)
    b = get_solution(vy, y)

    if a is None or b is None:
        return -1

    r1, m1 = a
    r2, m2 = b

    g = gcd(m1, m2)
    if (r2 - r1) % g:
        return -1

    lcm = m1 // g * m2
    p = m1 // g
    q = m2 // g

    _, s, t = egcd(p, q)
    k = ((r2 - r1) // g * s) % q
    time = (r1 + m1 * k) % lcm

    X = x + vx * time
    Y = y + vy * time

    ans = X // n - 1
    ans += Y // n - 1

    ans += (X + Y) // (2 * n)
    ans += abs(X - Y) // (2 * n)

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n, x, y, vx, vy = map(int, input().split())
        out.append(str(solve_one(n, x, y, vx, vy)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```機能`get_solution`1 つの座標条件をモジュラー方程式に変換します。 可分性チェックは、速度がその座標を次の倍数と決して一致させることができない場合を処理します。`n`。 

中国剰余定理の部分は、2 つの可能な時間セットをマージします。 の`egcd`関数は、合同式を結合するために必要な逆モジュールを提供します。 Python の整数は任意の精度であるため、大きな中間積は安全です。 

最終的な数式は展開平面上で機能します。`X // n - 1`垂直境界は端点よりも前で厳密にカウントされ、同じ考え方が水平境界にも使用されます。 2 つの対角ファミリは次のように表されます。`X + Y`そして`X - Y`。 

## 実用的な例

 のために```
6 2 2 5 2
```計算は次のようになります。 

| ステップ | 時間 | X | や | 反射 |
 | --- | --- | --- | --- | --- |
 | 開始 | 0 | 2 | 2 | 0 |
 | 展開される動き | 2 | 12 | 6 | 2 |

 最後の点は両方の座標を次の値で割り切れます。`6`, したがって、三角形の頂点に相当します。 2 つの交差した境界はカウントされますが、エンドポイントは無視されます。 

のために```
6 2 3 2 3
```得られるもの:

 | ステップ | 時間 | X | や | 反射 |
 | --- | --- | --- | --- | --- |
 | 開始 | 0 | 2 | 3 | 0 |
 | 展開される動き | 2 | 6 | 9 | 5 |

 終点は、展開されたタイリングの繰り返される頂点です。 この道はそこに到着するまでに 5 つの国境以外の国境を越えます。

 ## 特殊なケース

 のために```
4 1 2 1 1
```x 座標と y 座標の合同を同時に満たすことはできません。 展開された光線は繰り返される頂点に決して到達しないため、アルゴリズムは境界を数える前にそれを拒否します。 

のために```
6 2 2 5 2
```展開された平面の目的地は`(12,6)`。 どちらの座標も の倍数であるため、`n`、それは有効な脱出ポイントです。 この点より前の垂直方向と水平方向の交差がカウントされ、`2`。 

端点が頂点である場合、最後の線の交差を含めてはなりません。 最後の頂点はこれらのグリッド ライン上にあり、衝突イベントではないため、カウント式では、垂直線と水平線の単純な倍数カウントから 1 が減算されます。
