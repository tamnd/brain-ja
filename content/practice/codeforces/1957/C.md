 ## 解決策
 ## 問題の理解

 私たちは 2 人用ゲームをプレイしています。$n \times n$チェス盤。 あなたが手番で白いルークを配置すると、コンピューターはその直後に黒いルークを配置し、メインの対角線を横切るあなたの動きを反映します。つまり、ルークは$(r, c)$にミラーリングされます$(c, r)$。 あなたの動きが対角線上にある場合$(r = c)$、コンピュータは順番をスキップします。 ルークは互いに攻撃できないため、新しいルークは既存のルークと行または列を共有できません。 

入力では複数のテスト ケースを指定します。 各テスト ケースはボード サイズを提供します$n$、すでに行われた移動の数$k$、およびそれらの動きの座標。 動きは有効です。つまり、攻撃禁止ルールとコンピュータのミラー ルールを満たしています。 目標は、現在のボード状態からゲームを続行することで取得できる個別の最終構成の総数を計算することです。 

制約を考慮すると、$n$到達できる$3 \cdot 10^5$、まであるかもしれません$10^4$テストケース。 すべての正方形を明示的に調べるか、可能な配置をすべて再帰的に列挙するアプローチでは、時間がかかりすぎます。$O(n^2)$テストケースごとの操作は実行不可能になります。 代わりに、すべてのボード状態を明示的に生成することを避けるために、問題を組み合わせ計算に落とし込む必要があります。 

明らかではないエッジ ケースには、残りの空の行と列の多くに重複するミラーリング制約がある場合、または移動が対角線上にあり、ミラーリングされた応答が妨げられる場合が含まれます。 単純な実装では、ミラーリングによって課せられる対称性を考慮しないため、構成が二重にカウントされる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、各動きをターンごとにシミュレートし、他のルークを攻撃しない白ルークの可能な配置をすべて試してから、ミラーリングされた黒ルークを配置することです。 これは概念的には正しいですが、再帰的分岐の数は空の行と列の数に応じて指数関数的に増加するため、大規模な環境では実行不可能になります。$n$そして$k$。 たとえば、$n = 10^3$、のオーダーがあります。$10^6$これは制限時間 2 秒の操作限界をはるかに超えています。 

重要な洞察は、問題は基本的に、ミラーリング ルールによって制約される空き行と空き列の間の一致をカウントすることにあるということです。 イニシャルの後$k$移動すると、空いている行と列はそれぞれ空いているか、既存のルークによってブロックされます。 列の場合$r$そしてコラム$c$どちらも無料で、白いルークを配置できます。$(r, c)$場合のみ$(c, r)$ただし、$r = c$。 配置ごとに、空き行と空き列のセットが 1 つまたは 2 つずつ減ります。$r = c$。 これにより、問題は、空き行と空き列のセットからの選択シーケンスをカウントするという問題に軽減され、組み合わせて実行できます。 

具体的には、$R$空き行のセットであり、$C$最初の移動後の空き列のセット。 させて$x$まだルークが配置されていない行の数であり、$y$ルークのない列の数になります。 各移動は、行と列のペアとして考えることができます。 行と列が異なる場合、2 つの位置が占有されます (ミラーリングされたペア)。 行が列と等しい場合、1 つの位置のみが占有されます。 構成の総数は、ミラーリング用に調整された階乗に似た選択の積として計算できます。

 | ブルートフォース | O(2^n) | O(n^2) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最初のセットに基づいて、どの行と列がすでにルークによって占有されているかを追跡するためにセットを初期化します。$k$移動とそのミラーリングされた配置。 それぞれの初動ごとに$(r_i, c_i)$、マーク行$r_i$そしてコラム$c_i$占領されているように。 もし$r_i \neq c_i$、行もマークします$c_i$そしてコラム$r_i$ミラードブラックルークが占有しているように。 
2. 残りの空き行と空き列を数えます。 させて`free_rows`ルークのない行の数になり、`free_cols`ルークのない列の数。 
3. 変数を初期化する`result`1 に設定します。これは、可能な構成の数を法的に保存します。$10^9 + 7$。 
4. 残りの空き行を繰り返し処理します。 空き行ごとに、有効な移動を形成するためにペアになる列の数を数えます。 列の場合$r$そしてコラム$c$どちらも無料ですし、$r \neq c$にルークを置きます$(r, c)$両方を占めます$(r, c)$そして$(c, r)$、空き行と列の数が 2 つ減ります。 もし$r = c$、1つだけ減らす。 
5. モジュラー演算を使用して、各ステップでの選択の積を計算します。 配置順序は対称性までにのみ重要であるため、使用可能な行と列のペアの減少の積により、すべての個別の最終構成が正しくカウントされます。 
6. 戻る`result`モジュロ $10^9 + 7`。 

正確さを保証する不変条件は、各ステップでアルゴリズムが行や列が再利用されていない有効な配置のみをカウントし、ミラーリング ルールが尊重されることです。 選択肢の増加により、すべての一連の移動が考慮されます。また、占有されている行や列を再検討することはないため、どの構成も 2 回カウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        row_occupied = set()
        col_occupied = set()
        for _ in range(k):
            r, c = map(int, input().split())
            row_occupied.add(r)
            col_occupied.add(c)
            if r != c:
                row_occupied.add(c)
                col_occupied.add(r)
        free_rows = n - len(row_occupied)
        free_cols = n - len(col_occupied)
        # Number of ways is product of choices for remaining rooks
        min_free = min(free_rows, free_cols)
        res = 1
        for i in range(min_free):
            res = res * (i + 1) % MOD
        print(res)

if __name__ == "__main__":
    solve()
```このソリューションでは、最初に、最初の移動とミラー配置によってすでに占有されているすべての行と列にマークを付けます。 次に、残りの空き行と列の数を計算し、追加で配置できるルークの数を決定するために最小値を取得し、その数の剰余の階乗を計算します。$10^9+7$。 各配置により使用可能な行と列のセットが 1 つずつ減少するため、階乗はすべての可能な配置シーケンスを考慮します。
