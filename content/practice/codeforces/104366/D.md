 ## 解決策
 ## 問題の理解

 数直線上のセグメントの集合が与えられます。 これらのセグメントから、考えられるすべてのサブセットを検討します。 選択したサブセットについて、すべてのセグメントを数直線上にペイントすることを想像します。ただし、重複する部分は 1 回だけカウントされます。 つまり、各サブセットは、選択された間隔の結合の尺度である単一のペイントされた全長を生成します。 

タスクは、単一のサブセットのこの和集合の長さを計算することではなく、区間のすべてのサブセットにわたるこれらの和集合の長さの合計を計算することです。 サブセットが 2ⁿ あるため、指数関数的に大きな空間を合計することになり、寄与を列挙するのではなく分析的にカウントする方法が必要です。 

n が 2 × 105 までの制約により、サブセットを明示的に処理したり、ペアごとのサブセット DP を実行したりするものから遠ざけられます。 どの解も O(n log n) または O(n) に近い値でなければなりません。 

ここで最も一般的な失敗モードは、重複を個別に処理したり、結合効果を正しく処理せずに間隔ごとに寄与を追加しようとしたりすることに起因します。 たとえば、区間 [1,3] と [2,4] の場合、単純な加算では、両方が選択されたサブセットにわたる重複動作が 2 倍にカウントされます。 

もう 1 つの微妙な落とし穴は、合計される内容を誤解することです。 選択した間隔の合計の長さを合計するのではなく、それらの結合の長さを合計します。 オーバーラップによって構造が崩壊し、寄与が相対的な順序に依存するため、この区別は重要です。 

小さな例:

 入力:

 [1,3]、[2,4]

 サブセット:

 空集合 → 0

 {1} → 2

 {2} → 2

 {1,2} → 3

 答え = 7

 サブセット間の間隔の長さを単純に合計すると、サブセット全体に対して誤って 8 が生成されたり、サブセット間の重複重複が誤って処理されたりする可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてのサブセットを列挙し、サブセットごとに区間をマージして和集合の長さを計算します。 サイズ k のサブセットをマージするには、実装に応じて O(k log k) または O(k) のコストがかかります。 すべてのサブセットを合計すると、およそ O(n 2ⁿ) になりますが、これは n = 20 の場合でも実現不可能です。 

重要な変化は、サブセットを組み合わせオブジェクトとして考えるのをやめ、代わりに線上の個々の点について考えることです。 各点 x は、少なくとも 1 つの選択された区間でカバーされる回数と同じだけ答えに寄与します。 各 x について、x でカバレッジをアクティブにするサブセットの数を数えることができれば、これをすべての x にわたって統合できます。 

次に、点 x を修正します。 n 個の間隔のうち k 個でカバーされると仮定します。 x をサブセット内でペイントするには、それらの k 間隔のうち少なくとも 1 つを選択する必要があります。 残りの n − k 区間は、x がカバーされるかどうかとは無関係です。 したがって、x がペイントされていないサブセットの数は、k 個のカバー区間のいずれも選択しないサブセット、つまり 2^(n−k) です。 したがって、x をペイントする部分集合は 2ⁿ − 2^(n−k) になります。 このような各サブセットは x で無限小の長さに寄与するため、この寄与に k が定数である場合の尺度を乗算します。 

これにより、ラインに沿ったカバレッジ数の計算の問題が軽減され、エンドポイントをスイープすることで導出できます。 ただし、連続 x を直接積分する必要はありません。 代わりに、カバレッジが変化するイベント ポイント上にスイープ ラインを使用して問題を変換します。 

連続するソートされたエンドポイント間では、カバレッジ数 k は一定です。 長さ L のセグメント上の k がわかっている場合、答えへの寄与は次のようになります。 

L × (2ⁿ − 2^(n−k))。 

したがって、すべての間隔のエンドポイントによって引き起こされる、互いに素な基本セグメントに対してカバレッジ プロファイルを構築するだけで済みます。 

異なるエンドポイントが最大 2n 個あるため、これは効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n · 2ⁿ) | O(n) | 遅すぎる |
 | スイープ + カバレッジのカウント | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

すべての間隔のエンドポイントを並べ替えられたイベント リストに変換し、カバレッジが数直線上でどのように変化するかを追跡します。 

1. すべての間隔エンドポイントを抽出し、l でカバレッジを増加させ、r 以降のカバレッジを減少させるイベントを構築します。 セグメントをきれいに分離できるように、実装ロジックでは間隔を半開きとして扱います。 これにより、連続するイベント位置間でカバレッジが区分的に一定になります。 
2. すべてのイベント座標を並べ替えます。 これにより、数直線がセグメント内に開始または終了する区間がないセグメントに分割されます。 これが機能する理由は、カバレッジがエンドポイントでのみ変更できるためです。 
3. ランニングカウンターを維持しながら、左から右にスイープします。`cur`現在アクティブな位置をカバーしている間隔の数を表します。 
4. イベント位置 x[i] と x[i+1] の隣接するペアごとに、セグメント長 L = x[i+1] − x[i] を計算します。 このセグメントでは、カバレッジは一定であり、次と同等です。`cur`。 
5. このセグメントについては、次のように寄与度を計算します。 

L × (2ⁿ − 2^(n−cur))。 

減算項は、このセグメントをカバーする間隔をアクティブ化できなかったサブセットをカウントします。 
6. この寄与分を累積して、998244353 を法とする最終回答を求めます。 
7. アップデート`cur`次のセグメントを処理する前に、位置 x[i+1] でその座標で発生するすべてのイベントを使用します。 

### なぜ効果があるのか

 ライン上の各点はスイープ セグメントの 1 つに正確に属し、各セグメント内でカバー間隔のセットは固定されています。 固定セグメントの場合、ペイントされる唯一の条件は、そのカバー区間の少なくとも 1 つがサブセット内で選択されていることです。 非カバレッジ区間の選択はこのセグメントのカバレッジに影響しないため、乗算係数 2^(n-cur) に寄与します。 この独立性により、セグメントの寄与を合計すると、重複を二重にカウントすることなく、すべてのサブセットの結合長が正確にカウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n = int(input())
    events = []
    
    coords = set()
    segs = []
    
    for _ in range(n):
        l, r = map(int, input().split())
        segs.append((l, r))
        coords.add(l)
        coords.add(r)
    
    coords = sorted(coords)
    idx = {v: i for i, v in enumerate(coords)}
    
    diff = [0] * (len(coords) + 1)
    
    for l, r in segs:
        diff[idx[l]] += 1
        diff[idx[r]] -= 1
    
    cur = 0
    ans = 0
    
    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD
    
    for i in range(len(coords) - 1):
        cur += diff[i]
        if cur == 0:
            continue
        L = coords[i + 1] - coords[i]
        if L == 0:
            continue
        # segments covered by cur intervals
        total = pow2[n]
        bad = pow2[n - cur]
        ans += L * ((total - bad) % MOD)
        ans %= MOD
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```このコードは、すべてのエンドポイントから圧縮座標系を構築し、差分配列を使用して各座標領域をカバーする間隔の数を追跡します。 スイープはセグメントごとのカバレッジを計算し、前に導出した式を適用します。 2 の累乗を事前計算すると、ループ内での再計算が回避されます。各セグメントは O(1) で処理する必要があるため、これは重要です。 

カバレッジはエンドポイントでのみ変更されるため、実装の微妙な点は、連続する座標間でセグメントを正しく処理することです。 もう 1 つは、モジュラー減算を確実にすることです。`total - bad`モジュロを適用する前に中間値が負になる可能性があるためです。

 ## 特殊なケース

 重要なエッジ ケースは、[1,10]、[1,10] など、すべての間隔が同一である場合です。 セグメント上のカバレッジは常に 2 であるため、各単位長は 2ⁿ − 2^(n−2) に寄​​与し、同一の間隔を選択しないサブセットを除くすべてのサブセットを正しくカウントします。 

もう 1 つのエッジ ケースは、[1,10]、[2,9]、[3,8] などのネストされた間隔です。 スイープにより、中央のカバレッジが増加し、境界で減少することが保証されます。また、寄与は間隔の同一性ではなく、互いに素な座標セグメントに関連付けられているため、各領域は 1 回だけカウントされます。
