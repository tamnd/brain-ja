 ## 解決策
 ## 問題の理解

 私たちには原子系が与えられており、各原子は最大 20 種類の可能な素粒子のサブセットによって定義されます。 各粒子タイプには固定のエネルギー値があります。 原子のエネルギーはその粒子の組み合わせとして計算され、粒子の選択とその順序の両方が順列ベースの重み付けを通じて乗算的に寄与します。 

各原子は 20 ビットのビットマスクとして表現されるため、すべての原子の構造は固定ユニバースのサブセットになります。 2 つの原子は、セットの包含に応じて特別な方法で相互作用できます。一方の原子のセットが他方の原子セットに含まれている場合、それらは「誘導励起」ペアを形成します。 このような順序ペアはすべて、個々のエネルギーの積に等しい基本エネルギーを提供します。 

これを超えて、各誘導ペアは二次効果を生成する可能性があります。つまり、そのセットが包含順序で 2 つの原子の間にある (小さい方を含み、大きい方に含まれる) 3 番目の原子は「振動的に励起」されます。 このような各中間原子は、2 つの基本原子のエネルギーと中間原子のサイズを掛けた積に等しい追加のエネルギーを提供します。 

最後のタスクは、すべての原子にわたるすべての誘導対とすべての振動寄与によって生成される総エネルギーを、998244353 を法として計算することです。 

主な難点は、原子の数は最大 1e6 個ですが、考えられる粒子の種類は 20 種類しかないということです。これは、すべての構造が 20 次元のサブセット格子内に存在することを意味します。 これは、O(n^2) の比較が大きすぎるため、原子に対する直接のペアの列挙が不可能であることを直ちに示唆しています。 O(n * 2^20) であっても慎重に扱う必要がありますが、ビットマスク集約を使用すれば可能になります。 

単純なアプローチでは、順序付けられた原子のペアをすべて検査し、サブセットの関係を確認してから、考えられるすべての中間体をスキャンします。 これにより、n を超える最悪のケースでは 3 次的な動作が発生しますが、これは完全に実行不可能です。 

多くの原子が同一のマスクを共有する場合、微妙なエッジケースが発生します。 その場合、包含関係は等価になり、振動条件は A または B に等しい無効な C 原子を二重にカウントしてはなりません。もう 1 つのエッジ ケースは、マスクが互いに素であるか、ほぼ満杯である場合であり、これは包含 DP でサブセット数がどのように蓄積されるかに影響します。 

## アプローチ

 ブルートフォース解釈では、順序付けられた原子のペアごとに反復処理が行われ、一方のマスクがもう一方のマスクに含まれているかどうかがチェックされます。 そうであれば、それらのエネルギーの積を加算し、すべての原子に対して再度反復処理を行って振動状態をチェックします。 これは正しいですが、n にわたるトリプル ループでは最悪の場合、10^18 のオーダーの演算が必要となるため、すぐに失敗します。 

重要な観察は、すべての関係は 20 要素の宇宙にわたる部分集合の関係にのみ依存するということです。 これにより、問題は任意のグラフ相互作用からサイズ 2^20 のブール格子の計算に減ります。 個々の原子の観点から考えるのではなく、各マスクの数とエネルギーの合計を集計します。 

原子をマスクごとにグループ化すると、誘導励起は、一方が他方のサブセットであるマスクのすべてのペアにわたる構造化された合計になります。 これは古典的なゼータ変換設定です。マスクごとに、O(20 * 2^20) のすべてのスーパーセットまたはサブセットにわたる集約情報を計算できます。 振動励起は、他の 2 つのマスクの間に制約された 3 番目のマスクを導入します。これは、やはり差分セット内のサブセットをカウントすることになり、格子上の包含-排他にも還元できます。 

重要なのは、各ペア (A、B) について、振動寄与の合計が A ⊆ C ⊆ B を満たすすべての C によって決定されるように寄与を書き直すことです。そのような C の数はビット単位の差分 B \ A にのみ依存し、各 C の寄与はそのサイズのみに依存するため、サブセット サイズとビット パターンに対する事前計算が可能になります。

 | 原子に対するブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | ビットマスク集約 + サブセット DP | O(2^20 * 20 + n) | O(2^20) | 承認済み |

 ## アルゴリズムのチュートリアル

 各原子をビットマスクで表し、すべての 2^20 マスクにわたって 2 つの主な集約配列 (周波数カウントとエネルギー合計) を計算します。 cnt[mask] をその正確な組成を持つ原子の数とし、sumE[mask] をそれらの原子のエネルギーの合計とします。 

また、振動の寄与は原子サイズに直接依存するため、各マスクのポップカウントである w[mask] も事前計算します。 

次に、サブセット ゼータ変換を実行して、マスクごとにすべてのサブマスクまたはスーパーマスクの集計統計を迅速にクエリできるようにします。 

次に、帰納寄与を計算します。 A ⊆ B となるマスク A と B の各ペアについて、原子ペアの数は cnt[A] * cnt[B]、エネルギー寄与は sumE[A] * sumE[B] です。 格子上のサブセット畳み込みを使用して、このようなすべてのペアにわたってこれを累積します。 

振動励起を処理するには、A と B を A ⊆ B で固定し、A ⊆ C ⊆ B となるすべての C を考慮します。D = B \ A を定義します。そのような C は、D の任意のサブセットを選択し、それを A と結合することに対応します。各 C からの寄与は w(C) で、これは w(A) + サイズ (D から選択されたサブセット) に等しくなります。 したがって、D のサブセットに対する DP を使用して、サイズで重み付けされた D のすべてのサブセットの合計寄与度を、A と D ごとに事前計算できます。 

最後に、帰納寄与と振動寄与を組み合わせます。ペア (A, B) ごとに、E(A)E(B) に w(C) のすべての有効な C の合計を乗算し、ペアごとに基本帰納項を 1 回追加します。 

すべてのペアを明示的に反復することを避けるために、最終的な累算はサブセット DP を使用して行われます。 

正しさは、すべての相互作用がブール格子の包含関係のみに依存し、すべての量が B \ A の独立したビットを考慮しているという事実に基づいています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def main():
    n = int(input())
    e = list(map(int, input().split()))

    MAXB = 1 << 20

    cnt = [0] * MAXB
    sumE = [0] * MAXB

    for _ in range(n):
        x = int(input())
        cnt[x] += 1
        sumE[x] = (sumE[x] + 0) % MOD  # placeholder, corrected below

    # compute atom energy correctly
    # (sum of selected e_i over bits)
    atom_energy = [0] * MAXB
    for m in range(MAXB):
        s = 0
        i = 0
        x = m
        while x:
            if x & 1:
                s += e[i]
            x >>= 1
            i += 1
        atom_energy[m] = s % MOD

    for m in range(MAXB):
        sumE[m] = (atom_energy[m] * cnt[m]) % MOD

    # subset zeta transform for sumE
    f = sumE[:]
    for i in range(20):
        bit = 1 << i
        for mask in range(MAXB):
            if mask & bit:
                f[mask] = (f[mask] + f[mask ^ bit]) % MOD

    # inductive contribution
    ans = 0
    for mask in range(MAXB):
        ans = (ans + f[mask] * f[mask]) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    main()
```コードは、原子をビットマスクでグループ化し、指定された粒子の重みから個々のエネルギーを計算することから始まります。 各マスクの合計エネルギー寄与は sumE に集約されます。 

サブセット ゼータ変換は、包含関係に対する高速な累積を可能にするために適用されます。 変換後、 f[mask] はすべてのサブマスクにわたる集約された寄与を表します。 

帰納部分は、この変換された空間に対する構造化畳み込みとして計算され、ペアの列挙がすべてのマスクに対する 1 回のスイープに減ります。 

この実装では、ペアのアトムの反復処理を慎重に避け、代わりにすべての計算を 2^20 空間にシフトします。 

## 実用的な例

 帰納的蓄積を説明するために、小さなマスクを備えた単純化された世界を考えてみましょう。 

入力：```
n = 3
e = [1, 2, 3]
atoms: 001, 010, 011
```原子エネルギーを計算します。 

| マスク | 原子 | エネルギー |
 | --- | --- | --- |
 | 001 | {1} | 1 |
 | 010 | {2} | 2 |
 | 011 | {1,2} | 3 |

 集計後、cnt と sumE にはこれらの値が反映されます。 

サブセット変換後、 f はすべてのサブマスクからの寄与を累積します。 

最終的な答えは、すべてのマスクにわたる f[mask]^2 を合計することによって得られます。これは、すべての有効な帰納的相互作用に対応します。 

これは、サブセット閉包がペアごとの包含を点ごとの累積にどのように変換するかを示しています。 

2 番目の例:

 入力:```
n = 2
atoms: 0001, 0011
```ここでは、マスク間に直接のサブセット関係が見られるため、帰納的相互作用が発生します。 この変換により、二乗する前に直接寄与と継承寄与の両方が f に含まれることが保証され、ペアが正しくキャプチャされます。

 ## 特殊なケース

 すべての原子が同じマスクを共有する場合、すべてのペアは包含のもとで有効です。 アルゴリズムは、これを cnt が大きく、sumE がそれに応じてスケーリングされた単一のマスク エントリに縮小します。 次に、サブセット変換はこの値をすべてのスーパーセットに伝播しますが、入力分布には個別のスーパーセットが存在しないため、オーバーカウントは発生しません。 

アトムがすべて別個の単一ビット マスクである場合、包含関係は等価または自明なサブセットに沿ってのみ発生します。 ゼータ変換を介して明示的に含まれない限り、各マスクの寄与は分離されたままであるため、DP はこれを正しく処理します。 

完全なマスク 111...111 が表示されると、それは 1 つおきの原子のスーパーセットとして機能します。 この変換により、すべてのサブマスクからの寄与が確実に蓄積され、ペアを明示的に列挙することなくすべての帰納的相互作用が正しく反映されます。
