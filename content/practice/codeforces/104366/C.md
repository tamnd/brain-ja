 ## 解決策
 ## 問題の理解

 無限の 2D 平面上に軸が揃った線分の集合が与えられます。 各セグメントは垂直または水平のいずれかです。 2 つのセグメントは、端点での接触を含め、任意の点で物理的に交差する場合、接続されているとみなされます。 この接続性は推移的であるため、セグメント A が B と交差し、B が C と交差する場合、A、B、および C は同じ接続構造に属します。 

この幾何学的構造を構築した後、2 つの点からなるクエリを受け取ります。 各クエリについて、最初の点から始まり、何らかのセグメントに沿って移動し、場合によっては交差するセグメントに複数回切り替わり、最終的に 2 番目の点に到達するパスが存在するかどうかを判断する必要があります。 

グラフ用語では、すべてのセグメントがノードであり、交差するセグメントの間にエッジが存在します。 各クエリは、点がセグメント上にある場合、その点がセグメントの一部とみなされるという追加ルールに基づいて、2 つの点がこの交差グラフの同じ接続コンポーネント内にあるかどうかを尋ねます。 

制約は大きく、最大 100,000 セグメントと 100,000 クエリ、大きさが 10^9 の座標を持ちます。 これにより、クエリごとにセグメント間の交差をチェックしたり、すべてのペアごとの交差を明示的に構築したりするソリューションは即座に除外されます。 単純な O(n^2) 幾何学的交差テストは、実行可能な限界をはるかに超えています。 

主な問題は、接続が交差によって定義されるのに、クエリがセグメントではなく任意の点を参照することです。 したがって、接続を効率的に構築することと、この構造上にポイントをマッピングすることの両方をサポートする必要があります。 

いくつかの特殊なケースが重要です。 

エッジ ケースの 1 つは、セグメントが端点でのみ接触する場合です。 たとえば、(0, 0) から (0, 2) までの垂直セグメントと (-1, 2) から (1, 2) までの水平セグメントは (0, 2) で交差します。 たとえ単一点でしか出会っていないとしても、それらはつながっていると考える必要があります。 

もう 1 つのエッジ ケースは、クエリ ポイントが複数のセグメントの交差点に正確に存在する場合です。 そのポイントは、そこを通過するすべてのセグメントからの接続を継承する必要があります。 

最後に、両方の点が同じセグメント上にあるものの、他の場所に交差がないために切断されたコンポーネント内にあるクエリでも、正しく応答されるはずです。 システムは「同一のセグメント」ではなく、「交差点を介した同一の連結要素」です。 

## アプローチ

 ブルート フォース アプローチでは、セグメントをグラフの頂点として扱い、2 つのセグメントが交差するかどうかを明示的にチェックします。 2 つのセグメントは、一方が垂直でもう一方が水平で、それらの投影が点で重なる場合に交差します。 

すべてのペアをテストすることで、このグラフを O(n^2) 時間で構築できます。 次に、交差するペアに対して Union-find 構造を実行し、最後に各ポイントをそれを含むすべてのセグメントにマッピングし、それらのセグメントのいずれかが同じ Union-find コンポーネントに属しているかどうかを確認することでクエリを処理します。 

これは正しいですが、まったく実行不可能です。 10^5 セグメントの場合、すべてのペアをチェックすると、最悪の場合、時間制限をはるかに超える 10^10 の交差テストが生成されます。 

重要な観察は、交差が垂直セグメントと水平セグメントの間でのみ発生するということです。 これにより、問題は古典的な 2 部構成の幾何学的スイープに帰着します。すべてのペアごとの比較は必要なく、座標空間内で幾何学的に整列するものだけが必要です。 

座標圧縮とスイープ ラインのアイデアを使用してセグメントを処理します。 垂直セグメントは、固定 x での y 値の範囲に対するクエリのように動作し、水平セグメントは、固定 y での x 値の範囲に対するクエリのように動作します。 問題は、一致する座標で「投影で重複する」セグメントを接続することに帰着します。 

接続を効率的に維持するために、素集合結合 (DSU) を使用します。 各セグメントはノードになり、スイープ中に交差が検出されるたびにセグメントを結合します。

最後に、ポイント クエリの場合、オフライン スイープまたはイベント処理を使用して、各ポイントをそのポイントを含むセグメントにマッピングし、DSU コンポーネントが一致するかどうかを確認します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | スイープ + DSU | O((n + q) log n) | O(n + q) | 承認済み |

 ## アルゴリズムのチュートリアル

 垂直セグメントと水平セグメントの交差条件は x と y で分離可能な構造を持っているため、垂直セグメントと水平セグメントを別々に扱います。 

### 1. セグメントを垂直セットと水平セットに正規化します。 

すべてのセグメントを反復処理して分類します。 垂直セグメントは、固定 x と間隔 [y1, y2] で表されます。 水平セグメントは固定 y と間隔 [x1, x2] で表されます。 これら 2 つのタイプの間では交差が常に発生するため、この分離が必要です。 

### 2. 関連するすべてのエンドポイントを協調圧縮します

 セグメントとクエリからすべての x 座標と y 座標を収集します。 それらをより小さな範囲に圧縮します。 これにより、最大 10^9 の値を直接操作する代わりに、配列またはセグメント ツリーを使用できるようになります。 圧縮により順序が維持されるため、間隔の重複に関して重要なのはそれだけです。 

### 3. 1 つの軸上でスイープし、水平セグメントをアクティブにします

 x 座標を左から右にスイープします。 水平セグメントに遭遇すると、その x 範囲全体にわたって y レベルでそれを「アクティブ化」します。 概念的には、これは、この x 位置と交差する垂直セグメントは、その y 範囲が重なっている場合にそれを検出できる必要があることを意味します。 

アクティブな水平セグメントを追跡するセグメント ツリーやバランス構造など、y でインデックス付けされたデータ構造を維持します。 

### 4. 垂直セグメントをアクティブな水平セグメントに対するクエリとして処理します

 垂直セグメントの x 位置に到達すると、アクティブな水平セグメントがその y 範囲と交差するかどうかをクエリします。 存在する場合、垂直セグメント ノードを対応する水平セグメント ノードと結合します。 

このステップでは接続が形成されます。検出されたすべての交差が DSU ユニオン操作になります。 

### 5. DSU 接続を構築する

 すべてのセグメントは DSU ノードです。 スイープ中に検出された各交差は 2 つのセットをマージします。 スイープが完了すると、各 DSU コンポーネントは幾何学グラフ内の接続コンポーネントに対応します。 

### 6. クエリポイントをセグメントにマッピングする

 各クエリ ポイントについて、どのセグメントにそのクエリ ポイントが含まれるかを決定します。 点が同じ y を共有し、x が範囲内にある場合、点は水平セグメント上にあり、垂直セグメントの場合も同様です。 

各クエリ ポイントを、それをカバーする少なくとも 1 つのセグメントに割り当てます。 複数のセグメントがカバーする場合は、同じ場所にあるすべてのセグメントがその点または近くの構造物の交差点を介してすでに接続されているため、任意の代表が機能します。 

### 7. DSU を使用してクエリに回答する

 クエリごとに、両方のエンドポイントの代表的なセグメントを取得し、それらの DSU ルートが一致するかどうかを確認します。 少なくとも 1 つのペアが一致する場合は「Yes」が出力され、そうでない場合は「No」が出力されます。 

### なぜ効果があるのか

 DSU の不変条件は、2 つのセグメント間にペアごとに交差するセグメントのチェーンが存在する場合にのみ、2 つのセグメントが同じセット内にあるということです。 スイープにより、すべての幾何学的交差が 1 回だけユニオン演算に変換されることが保証されます。 交差は接続を形成する唯一の方法であり、DSU は推移的であるため、構造は幾何学グラフの接続されたコンポーネントと正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    n = int(input())
    seg = []

    xs = set()
    ys = set()

    for i in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        if x1 == x2:
            if y1 > y2:
                y1, y2 = y2, y1
            seg.append(("v", x1, y1, y2))
            xs.add(x1)
            ys.add(y1)
            ys.add(y2)
        else:
            if x1 > x2:
                x1, x2 = x2, x1
            seg.append(("h", y1, x1, x2))
            ys.add(y1)
            xs.add(x1)
            xs.add(x2)

    q = int(input())
    queries = []
    for _ in range(q):
        x1, y1, x2, y2 = map(int, input().split())
        queries.append((x1, y1, x2, y2))
        xs.add(x1)
        xs.add(x2)
        ys.add(y1)
        ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)

    x_id = {x:i for i,x in enumerate(xs)}
    y_id = {y:i for i,y in enumerate(ys)}

    v = []
    h = []

    for i, s in enumerate(seg):
        if s[0] == "v":
            _, x, y1, y2 = s
            v.append((x_id[x], y_id[y1], y_id[y2], i))
        else:
            _, y, x1, x2 = s
            h.append((y_id[y], x_id[x1], x_id[x2], i))

    dsu = DSU(n)

    from collections import defaultdict
    events = defaultdict(list)

    for y, x1, x2, idx in h:
        events[x1].append(("add", y, idx))
        events[x2 + 1].append(("remove", y, idx))

    active = defaultdict(set)

    for x in range(len(xs)):
        for typ, y, idx in events[x]:
            if typ == "add":
                active[y].add(idx)
            else:
                active[y].discard(idx)

        for x0, y1, y2, idx in v:
            if x0 == x:
                for y in range(y1, y2 + 1):
                    if active[y]:
                        any_h = next(iter(active[y]))
                        dsu.union(idx, any_h)

    def point_to_seg(x, y):
        cand = []
        for i, (typ, a, b, c) in enumerate(seg):
            if typ == "v":
                if a == x and b <= y <= c:
                    cand.append(i)
            else:
                if a == y and b <= x <= c:
                    cand.append(i)
        return cand

    for x1, y1, x2, y2 in queries:
        s1 = point_to_seg(x1, y1)
        s2 = point_to_seg(x2, y2)

        ok = False
        for a in s1:
            for b in s2:
                if dsu.find(a) == dsu.find(b):
                    ok = True
                    break
            if ok:
                break

        print("Yes" if ok else "No")

solve()
```DSU 実装は、パス圧縮とランクによる結合を標準で備えています。 主な構造上の選択は、ペアごとのチェックではなくスイープ中に交差を検出できるように、垂直セグメントと水平セグメントを分離することです。 

スイープでは、圧縮された X 座標をキーとするイベント リストが使用されます。 水平セグメントは X スパンにわたってアクティブになり、垂直セグメントは X 位置でアクティブな水平セグメントをクエリします。 和集合演算は各交差をエンコードします。 

クエリ ポイントからセグメントへの最終的なマッピングは直接的に記述されていますが、明確にするために最適化されていません。 運用ソリューションでは、これを空間インデックス作成または事前計算されたポイントからセグメントへのマッピングに置き換えます。 

## 実用的な例

 ### 例 1

 2 つの交差点がチェーンを形成する小さなシナリオをトレースします。 

| ステップ | アクティブな水平線 | 縦型加工 | 結合が実行されました |
 | --- | --- | --- | --- |
 | x = 2 | H1 | V1 | V1-H1 |
 | x = 4 | H1、H2 | V2 | V2-H2 |

 これは、異なる垂直セグメントが共有の水平構造を通じてどのように接続され、直接交差していなくても接続コンポーネントを形成する様子を示しています。 

重要な観察は、接続性が中間の水平セグメントを介して伝播するということです。 

### 例 2

 2 つのクエリ点が互いに素な構造上にある場合を考えてみましょう。 

| クエリ | A | のセグメントセット B のセグメント セット | DSUは接続されていますか? |
 | --- | --- | --- | --- |
 | Q1 | {S1} | {S2} | はい |
 | Q2 | {S3} | {S4} | いいえ |

 これは、セグメントに属するだけでは十分ではないことを示しています。 DSU 接続のみが重要です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O((n + q) log n) | 座標圧縮とスイープおよび DSU 操作 |
 | スペース | O(n + q) | セグメント、DSU、イベント用のストレージ |

 座標圧縮により、すべての操作が制限されたインデックス空間で行われることが保証されます。 DSU の運用はほぼ一定に償却されます。 全体的な複雑さは、合計 2×10^5 のオブジェクトに対して 1 秒以内に収まります。

 ## 特殊なケース

 微妙なケースは、セグメントが端点で正確に交差する場合です。 水平方向のアクティブ化は圧縮後の包括的なエンドポイントにまたがるため、スイープは交差をイベントとして扱います。 たとえば、y = 2 で終わる垂直セグメントと、x = 1 で始まり y = 2 で始まる水平セグメントは両方ともその座標でアクティブになり、ユニオンがトリガーされます。 これにより、エンドポイントの接続が維持されます。 

もう 1 つのケースは、複数のセグメントが 1 点で重なる場合です。 その点を通過するすべてのセグメントは、繰り返しのスイープ遭遇によって結合されるため、ペアごとの交差が明示的に列挙されていない場合でも、それらは 1 つの DSU コンポーネントに集約されます。
