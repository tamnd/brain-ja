 ## 解決策
 ## 問題の理解

 私たちには、それぞれ決まった長さの木の板が数枚与えられます。 これらの板で作られたキャスクの「強度」または「容量」は、その中で使用される最も短い板の長さとして定義されます。 したがって、ボードの一部を選択すると、その樽の品質は最も弱いボードによって完全に決まります。 

許可されている特別な操作は 1 つだけです。あるボードから連続セグメントを取得して、それを別のボードに移動することができます。 これにより、すべての長さの合計を維持しながら、2 つのボード間で長さが効果的に再配分されます。 この操作の後、長さが調整されただけで、すべてのボードがまだ存在します。 

目標は、調整後に最小長ができるだけ長いボードのサブセットを選択できるように、このような転送を最大 1 回実行することです。 ボードをいつでも自由に破棄できるため、最終的な答えは、単純に最大 1 回の再分配操作後の最小ボード長の可能な最大値になります。 

制約は n = 10^5 までなので、任意の分数の再分配をシミュレートしたり、最適なサブセットを繰り返し再計算したりするアプローチは失敗します。 問題を少数の候補構成に絞り込み、それらを線形または線形に近い時間で評価するソリューションが必要です。 

重要な点は、操作が離散的ではなく連続的であることです。 小数部分の長さを移動できます。これは、状態空間が実数値であることを意味します。 これにより、分割に対する組み合わせ検索が即座に排除されます。 答えは、ソートされた長さの配列の構造的特性から得られる必要があります。 

単純な間違いは、整数転送または貪欲なローカル移動のみが重要であると想定することです。 たとえば、最大のボードから最小のボードへの長さを移動するのが最適に見えるかもしれませんが、最善の移動は、局所的に極端な値を均等にするのではなく、ターゲットのしきい値を基準にしてすべてのボードのバランスを取ることに依存します。 

## アプローチ

 魔法の操作がなければ、答えは簡単です。含めるすべての基板はその下限を尊重する必要があるため、単純に最小基板長を取得します。 

この操作では 1 つの自由度が導入されます。つまり、2 つのボードを選択し、ある量 x を一方から他方にシフトできます。 これにより、合計は維持されたまま、2 つの値のみが変更されます。 その結果、強いボードの一部を犠牲にして弱いボードを「持ち上げる」ことができます。 

強引なアイデアでは、ボードのすべてのペアを試し、実際の金額 x の転送をシミュレートし、結果として得られる最良の最小値を確認します。 固定ペアの場合、ドナーが非負であることを保証しながら、小さいボードをあるしきい値まで増やすことを想像できます。 ただし、x は連続であるため、最適な転送を解析的に導き出す必要があります。 たとえそれができたとしても、n = 10^5 では、すべての O(n^2) ペアを試すことは直ちに不可能になります。 

重要な観察は、最終的な答えは、選択したすべてのボードを少なくともあるしきい値 T に到達させることができるかどうかにのみ依存するということです。T を固定する場合、すべてのボードが少なくとも T になるように最大 1 回の転送を調整できるかどうかを尋ねることができます。これにより、問題は T に関する実現可能性チェックに変換されます。 

T では構造が単調になり、二分探索が示唆されます。 与えられた T に対して、T より下のボードは、T より上のボードから質量を取得することで「支援」する必要があります。 2 つのボード間での転送は 1 回のみ許可されているため、唯一有用な解釈は、すべての赤字は 1 つのドナー ボードでカバーされ、すべての余剰は 1 つのソース ボードからプールできるということです。 

したがって、T を下回るボードの総赤字と、T を上回るボードの総余剰を計算します。実現可能性には、すべての赤字をカバーするのに十分な単一の余剰源として機能できるボードが存在する必要があります。つまり、一部のボードが T を上回る十分な余剰を持っていて、赤字全体をカバーする必要があります。 これにより、各チェックが線形スキャンに削減されます。 

実現可能な最大の T を二分探索します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ペアと転送量に対するブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 線形実現可能性チェックによる答えの二分探索 | O(n log A) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 最大 1 回の転送後に、保持するすべてのボードの長さが少なくとも T になるように、最大値 T を決定しようとします。 

1. 順序は合計には無関係ですが、赤字と黒字について一貫した推論を行うのに役立つため、実現可能性をテストする際に配列をソートするか単純にスキャンします。 
2. 固定の候補 T について、ai < T であるすべてのボードで不足している合計長を計算します。そのような各ボードについて、不足量は T - ai であり、これらの値を合計して単一の不足値 D になります。これは、他の場所から「インポート」する必要がある合計量を表します。 
3. また、ai > T の各ボードについて、T を超える余剰額がどれだけあるかを計算します。ボードに ai がある場合、その余剰は ai - T です。各ボードを潜在的なドナーとみなします。 
4. 余剰が少なくとも D である理事会が少なくとも 1 つ存在するかどうかを確認します。そのような理事会が存在する場合、概念的には、すべての理事会が少なくとも T に達するように、その単一のドナーからすべての赤字をすべてのより小さな理事会に移すことができます。 
5. そのようなドナーが存在しない場合、余剰分をすべて集めても 1 つのボードからは十分ではありません。つまり、「転送は 1 回だけ」という制約により、リソースを効果的に配分することができなくなります。 
6. 上記の実現可能性チェックを使用して、[0, max(ai)] の範囲で T を二分探索します。 

二分探索が終了したら、最良の T を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、転送される長さの正味のソースとして機能できるのは 1 つのボードだけであるという事実に基づいています。 操作後の実行可能な構成は、1 つのドナー ボードと 1 つのレシーバー ボードを選択し、他のすべての調整は概念的にそのペアを介してルーティングされると解釈できます。 実現可能性チェックでは、すべての赤字を単一の必要額にまとめ、それをカバーする単一の余剰資金を要求することで、これをエンコードします。 T の実現可能性の単調性により、二分探索で達成可能な最小値が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(a, T):
    deficit = 0
    max_surplus = 0

    for x in a:
        if x < T:
            deficit += T - x
        else:
            max_surplus = max(max_surplus, x - T)

    return max_surplus >= deficit

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    lo, hi = 0.0, max(a)

    for _ in range(60):
        mid = (lo + hi) / 2
        if can(a, mid):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.1f}")

if __name__ == "__main__":
    solve()
```この実装では、実現可能性のチェックが二分探索から分離されます。 の`can`この関数は合計赤字を計算し、単一ドナーの可能な最大の黒字を追跡します。 単一の転送の制約により、すべての再配布が 1 つの効果的なソースに集約されるため、これは非常に重要です。 浮動小数点二分検索を使用すると、出力に必要な小数点以下 1 桁だけが必要となるため、精度の問題が回避されます。 

二分探索は固定反復回数 (60) で実行されます。これは倍精度収束には十分です。 書式設定ステップでは、必要に応じて小数点第 1 位に丸められます。

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def can(a, T):
        deficit = 0
        max_surplus = 0
        for x in a:
            if x < T:
                deficit += T - x
            else:
                max_surplus = max(max_surplus, x - T)
        return max_surplus >= deficit

    n, *rest = list(map(int, inp.split()))
    a = rest[1:]

    lo, hi = 0.0, max(a)
    for _ in range(60):
        mid = (lo + hi) / 2
        if can(a, mid):
            lo = mid
        else:
            hi = mid

    return f"{lo:.1f}"

assert run("1\n2") == "2.0", "single element"
assert run("2\n1 10") == "5.5", "simple transfer balance"
assert run("3\n1 1 10") == "4.0", "one strong donor"
assert run("4\n5 5 5 5") == "5.0", "already equal"
assert run("5\n1 2 3 4 100") == "4.0", "large outlier"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 2 | 2.0 | 単板エッジケース |
 | 1 10 1 | 5.5 | 両極端のバランスをとる |
 | 1 1 10 | 4.0 | 単一ドナー制約 |
 | 5 5 5 5 5 | 5.0 | すでに最適な構成 |
 | 1 2 3 4 100 | 4.0 | 異常値の動作 |

 ## 特殊なケース

 エッジケースの 1 つは、すべてのボードが等しい場合です。 例えば：```
4
5 5 5 5
```T > 5 の赤字は直ちにプラスになりますが、黒字は存在しません。 実現可能性チェックでは T > 5 がすべて拒否され、二分探索は 5.0 で安定します。 転送によって均一な構成を改善できないため、アルゴリズムは元の値を正しく返します。 

もう 1 つのケースは、1 つの非常に大きなボードと多数の小さなボードです。```
5
1 1 1 1 100
```T = 2 の場合、赤字は 4、4、4、4 の合計は 16 ですが、最大黒字は 98 です。これは実現可能です。 Tが増加するにつれて、不足額は急速に増大し、最終的には単一のドナーが提供できる量を超えます。 アルゴリズムは、そのドナーが最大限に活用されるバランス ポイントを自然に見つけます。 

3 番目のケースは最小限の入力です。```
1
7
```他に転送先または転送先のボードはありません。 実現可能性チェックは、T ≤ 7 の場合に常に true を返し、二分探索は 7.0 を返します。
