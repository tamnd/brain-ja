 ## 解決策
 ## 問題の理解

 1 次元の長さのセグメントに沿って街灯を配置しています。$n$。 まで選択できます$k$これらのライトの位置を決めます。 各ライトはセグメント上のすべての点に明るさを与えますが、その寄与は距離に応じて二次関数的に減衰します。点が距離にある場合$r$光から、その光が貢献する$d \cdot r^2$その時の明るさ。 

ただし、ジオメトリを形成するには 2 つの重要な制約があります。 まず、明るさは加算されるため、各ポイントはすべてのライトからの寄与の合計を受け取ります。 第 2 に、ライトには特別なルールがあります。つまり、ライトはそれ自体の位置で無限の明るさを提供します。これは事実上、セグメント全体の最小輝度がライトの位置で正確に発生することは決してないことを意味します。 

街路灯が互いに遮るという障害ルールもあります。 ライトがソース ライトと点の間にある場合、ソース ライトの影響はそこを通過しません。 これにより、セグメントがライトによって分離された独立した領域に効果的に分割されます。 

目標は、最大でも$k$セグメント内のすべての点の最小輝度が可能な限り大きくなるように、セグメント上で点灯します。 言い換えれば、カバレッジ内の深い谷を排除するようにライトを配置することで、最も弱い部分を「平滑化」しようとしているのです。 

入力サイズが大きい: 最大$10^5$テストケース、$n$そして$k$と同じくらい大きい$10^9$。 位置をシミュレートしたり、明るさをポイントごとに評価したりするソリューションは、直ちに不可能です。 ライトの構成を保存することすら不可能です。 解決策は、明示的な構築ではなく、最適な配置の構造特性のみに依存する必要があります。 

次の場合、微妙なエッジケースが発生します。$k = 1$。 単一のライトは中間点に最適に配置する必要があります。 もう 1 つのエッジケースは次のような場合です$k = n$なぜなら、ライトは覆われていない大きなギャップを効果的に排除でき、構造が完全に飽和するからです。 素朴な直感は、貪欲な配置または等間隔シミュレーションを示唆するかもしれませんが、明るさが距離に二次的に依存し、追加の寄与により非局所的であるため、どちらも失敗します。 

## アプローチ

 ブルートフォース戦略では、あらゆる方法で上位に到達することを試みます。$k$セグメントに沿ってライトを点灯し、各構成の間隔全体にわたる最小輝度を評価します。 位置を整数座標に離散化したとしても、選び方は無数にあります。$k$間の位置$n$は組み合わせ的なものであり、各構成を評価するには、少なくともセグメントの線形スキャンまたは連続最小化問題の解決が必要です。 これはすぐに指数関数的になるか、少なくとも$O(n^k)$、これは小さな入力であっても完全に実行不可能です。 

重要な構造的観察は、どのような最適な構成でも、ボトルネック ポイント、つまり最小の明るさを持つポイントが、2 つの隣接するライトの間のギャップの中央、または境界とライトの間の位置にあるということです。 各ライトは距離の凸二次関数に寄与するため、最適なレイアウトでは、隣接するライト間の任意の間隔の合計輝度も凸対称になります。 これにより、最適な配置がセグメントの均一な分割に向けて推進されます。 

問題が最悪のギャップを均等化することによって制御されることが認識されると、ライトの正確な位置は、誘発される分割サイズほど重要ではなくなります。 セグメントは効果的に次のように分割されます。$k+1$独立した間隔であり、最小の明るさはそのような最大の間隔によって決まります。 これらの間隔が可能な限り等しい場合、最適な構成が達成されます。 

これにより、問題は単一の長さの区間の分析に縮小されます。$L = \frac{n}{k+1}$、および光の境界の対称的な配置によって引き起こされる最小の明るさを計算します。 寄与の二次構造により、そのような区間内の最悪の点に対する閉形式の式が得られます。

 ## アルゴリズムのチュートリアル

 ### 最適な推論手順

 1. 最適な配置では、ライトがセグメントをブロック ポイントで区切られた独立した領域に分割することを観察します。 これにより、遠く離れた領域間の相互作用が減少し、各領域を個別に分析できるようになります。 
2. 最小輝度を最大化しているため、ボトルネックは連続するライト間の最大ギャップ、または境界とライトの間の最大ギャップにあるはずです。 ギャップ サイズの不均衡は、ライトを移動することで改善できます。 
3. 最適な配置によりセグメントが次のように分散されると結論付けます。$k+1$等しい長さの間隔、それぞれの長さ$L = \frac{n}{k+1}$。 これにより、不釣り合いに弱い領域が存在しないことが保証されます。 
4. 単一の長さの区間に焦点を当てる$L$。 二次距離コストの対称性により、その区間の最悪の点はその中間点になります。 
5. 中間点の明るさを、最も近い 2 つの境界ライトからの寄与の合計として計算します。 各投稿はフォームに従います$d \cdot r^2$、 どこ$r = L/2$、つまり各側が貢献します$d \cdot (L/2)^2$。 
6. 両側からの寄与を加算して、合計の最小輝度を取得します。$$2 \cdot d \cdot (L/2)^2 = d \cdot \frac{L^2}{2}$$1. 代役$L = \frac{n}{k+1}$最終的な式を取得するには:$$\text{answer} = d \cdot \frac{n^2}{2 (k+1)^2}$$### なぜ効果があるのか

 重要な不変条件は、2 つの隣接するライト間のセグメントのすべての内部点が凸状の二次輝度プロファイルを経験し、凸性により最大間隔の中点で最小値が発生することです。 等間隔からの逸脱により、より大きな間隔が作成され、その中点の明るさはより小さな間隔の中点よりも厳密に小さくなります。 輝度は加法的であり、区間全体で対称であるため、最悪の区間を改善すると全体的な最小値が改善されます。 したがって、問題は区間の長さの平衡化に帰着し、平衡化されると、二次評価は決定的になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n, k, d = map(int, input().split())
        L = n / (k + 1)
        ans = d * (L * L) / 2.0
        out.append(f"{ans:.10f}")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```コードは、派生した閉じた形式の式を直接実装します。 唯一の微妙な点は浮動小数点の精度です。$n$、$k$、 そして$d$大きい値になる可能性があるため、中間値は倍精度で計算する必要があります。 必要なエラー許容度は次のとおりであるため、Python float を使用すれば十分です。$10^{-4}$。 

による除算$k+1$道路を等しい最大のセグメントに分割することに対応します。 二乗ステップは、距離に応じた影響の二次減衰を反映します。 の要因$1/2$両方のバウンディング ライトの寄与を対称的に組み合わせることで得られます。

 ## 特殊なケース

 いつ$k = 1$、アルゴリズムはセグメント全体を 2 つの等しい長さに縮小します。$n/2$。 中間点が最小輝度の唯一の候補です。 入力用`1 1 1`、計算結果は次のようになります$L = 0.5$そして最終的な値$0.125$、両側からの対称二次寄与と一致します。 

いつ$k = n$、間隔の長さは次のようになります$n/(n+1)$これは、すべての領域が非常に小さく、二次ペナルティが急速に縮小することを意味します。 導出では次のことを前提としていないため、この式は変更せずにそのまま適用されます。$k \ll n$、間隔が等しいだけです。 

いつ$n$など大きいです$10^9$、浮動小数点の安定性が重要です。 計算では double の乗算と除算のみが使用され、中間の大きさが範囲内に収まるため、安定したままになります。$10^{18}$、IEEE 754 の精度損失しきい値を大幅に下回り、必要な精度レベルで 2 倍になります。
