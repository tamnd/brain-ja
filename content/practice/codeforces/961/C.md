 ## 解決策
 ## 問題の理解

 チェス盤の 4 つの別々の正方形の断片が与えられます。各断片は$n \times n$すべてのセルがすでに黒または白に色付けされているグリッド。 値$n$これは奇妙であり、目標はこれら 4 つの部分をより大きなものに組み立てることです。$2n \times 2n$チェス盤。 

4 つのピースを任意の順序で配置できますが、回転したり反転したりすることはできません。 それらを配置した後、$2 \times 2$ブロックのレイアウトに応じて、個々のセルの色を変更する場合があります。 コストは、色を変更するセルの数です。 最終的な目標は、その結果、$2n \times 2n$Grid は有効なチェス盤であり、すべてのセルの色が隣のセルと異なることを意味します。 

課題は、4 つのピースの最適な配置を選択した後、必要な再着色の回数を最小限に抑えることです。 

制約$n \le 100$これは、各ピースのセルが最大 10,000 個であることを意味するため、完全な入力は十分に小さいため、ピース間のコストを直接計算することができます。 すべての配置を試すソリューションは実行可能です。$4!$順列。 

微妙な点は、最終ボードの隣接性が駒の境界を越えていることです。 したがって、隣り合って配置された 2 つのピースは、接触するエッジ全体に制約を課します。 ここで、単純な独立した処理が失敗します。 

典型的な間違いは、各ピースを独立してチェス盤のパターンに作成し、単純に組み合わせることができると考えることです。 これは、色のパリティが境界を越えて一致する必要があることを無視しています。 たとえば、2 つの隣接するピースがどちらも左上のセルが黒であると想定しているが、それらの相対オフセットが一致しない場合、境界の競合が発生し、コストが予期せず増加します。 

もう 1 つの微妙な問題は、$n$が奇数の場合、各ピース内の座標のパリティは一貫して動作します。これは、各ピースが最終グリッドに配置されたときに固定の「チェッカー パリティ アライメント」を持つことを意味します。 この位置合わせは、その作品が 4 つの象限のどれに割り当てられているかによって異なります。 

## アプローチ

 ブルート フォース ビューは、各ピースが最終的な 4 つの象限のいずれかに配置できることに気づくことから始まります。$2n \times 2n$ボード。 がある$4!$すべての順列を試すことができるように、ピースを象限に割り当てる方法。 

固定割り当ての場合、最終的なボードが正しく交互になるように反転する必要があるセルの数を計算する必要があります。 最終的なチェス盤自体には有効な色が 2 つだけあります。左上のセルが黒か白です。 開始選択が決定されると、他のすべてのセルは座標のパリティによって決定されます。 

したがって、各順列と 2 つの開始色のそれぞれについて、全体にわたる不一致コストを計算します。$4n^2$細胞。 正しさとしてはすでに十分です。 

重要な点は、段階的に再カラーをシミュレートする必要がないということです。 各セルは独立して貢献します。必要なのは、その現在の色が最終位置で予想されるチェス盤の色と一致するかどうかを確認することだけです。 

これにより、問題は一定数の構成を評価することになります。$4!$順列に 2 つのグローバル カラーリングを掛け、それぞれをチェックインします$O(n^2)$。 

より微妙な構造上の洞察は、各ピースが常に固定象限に配置されるため、その座標はシフトされますが、変換されないということです。 これにより、予想される色の公式が均一になり、計算が容易になります。

## アルゴリズムのチュートリアル

 4 つの部分に次のラベルを付けます$P_0, P_1, P_2, P_3$。 それらを 4 つの象限 (左上、右上、左下、右下) に割り当てるあらゆる方法を検討します。 

1. 4 つの部分のすべての順列を生成します。 各順列は、象限への 1 つの固定配置を表します。 象限が明確であり、回転による対称性の低下がないため、これで十分です。 
2. 各順列について、2 つの可能な最終的なチェス盤の色を考慮します。 その細胞を仮定すると、$(0,0)$は白であり、もう一方は黒であると見なされます。 すべてのチェス盤は開始セルによって決定されるため、有効なグローバル パターンはこれらのみです。 
3. 各セルについて$(i, j)$ピースの内部で、その最終座標を計算します。$2n \times 2n$ボードは、割り当てられた象限に応じて異なります。 これは単純なオフセットです。左上に追加します。$(0,0)$、右上に追加$(0,n)$、左下に追加$(n,0)$、右下に追加$(n,n)$。 
4. パリティを使用して、その最終位置で期待される色を決定します。 開始色を 0 として定義すると、期待される色は次のようになります。$(i + j) \bmod 2$。 開始色が 1 の場合、これを反転します。 
5. 予想される色と指定されたセルの色を比較し、不一致数を蓄積します。 この数は、この構成に必要な再カラー操作の数を表します。 
6. すべての順列および両方の開始色の選択にわたる最小の不一致を追跡します。 

結果は、各構成コストがグリッド上で線形時間で計算される有限の構成空間における最小値になります。 

### なぜ効果があるのか

 すべての有効な最終ボードは、象限への駒の配置とグローバル パリティ オフセットという 2 つの選択肢によって一意に決定されます。 これらが修正されると、各セルの正しい色はパリティによって強制され、他のすべてのセルから独立します。 したがって、コスト関数はセルごとの独立した不一致の合計に分解され、小さな構成空間にわたる徹底的な検索により、全体的な最適値がチェックされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def read_piece(n):
    g = []
    for _ in range(n):
        line = input().strip()
        g.append([int(c) for c in line])
    return g

def solve():
    n = int(input().strip())
    input()  # consume empty line after n

    pieces = []
    for _ in range(4):
        pieces.append(read_piece(n))
        input()  # empty line between pieces

    # quadrant offsets
    offsets = [(0, 0), (0, n), (n, 0), (n, n)]

    import itertools

    ans = 10**18

    for perm in itertools.permutations(range(4)):
        for start in (0, 1):
            cost = 0

            for qi in range(4):
                pi = perm[qi]
                ox, oy = offsets[qi]
                piece = pieces[pi]

                for i in range(n):
                    for j in range(n):
                        final_parity = (ox + i + oy + j) & 1
                        expected = final_parity ^ start
                        cost += (piece[i][j] != expected)

            ans = min(ans, cost)

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、まず 4 つのグリッドを慎重に解析し、ブロック間の空行に注意します。 これは、セパレータをスキップしたり読み間違えたりすると、後続のすべての部分が誤ってシフトされるため、この問題の一般的なバグの原因です。 

各順列は、ピースを固定順序で象限に割り当てます。 オフセット配列は、最終的なボードの各象限の配置をエンコードします。 各セルについて、座標加算を使用して最終的なパリティを計算し、選択したグローバル開始色と XOR を計算します。 XOR が使用されるのは、開始色を反転すると、期待されるすべての値が単純に反転されるためです。 

ネストされたループオーバー$4n^2$セルは許容されるため、$n \le 100$、したがって、合計の操作は次のとおりです$4 \cdot 4! \cdot 2 \cdot 10^4$, これは簡単に制限内に収まります。
