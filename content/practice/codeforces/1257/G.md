 ## 解決策
 ## 問題の理解

 入力によって数値が直接与えられるわけではありません。 代わりに、等しい素数が何度も現れる可能性がある素因数のリストとして素因数分解を行います。 

素数を仮定します$q$表示されます$c$回。 次に、すべての約数は次の間の指数を選択します。$0$そして$c$そのプライムのために。 個別の素数に多重性がある場合$$c_1,c_2,\dots,c_k,$$すべての約数はベクトルに対応します$$(e_1,e_2,\dots,e_k), \qquad 0 \le e_i \le c_i.$$割り切れる関係は非常に単純になります。$$(e_1,\dots,e_k)\mid(f_1,\dots,f_k)$$もし、そしてその場合に限り$$e_i \le f_i$$あらゆるコーディネートに。 

割り算の下で 2 つの異なる約数が比較できないように、可能な限り最大の約数の集合を見つけなければなりません。 ポセットの用語では、アンチチェーンの最大サイズを探しています。 

入力要素の数は最大で$2\cdot10^5$。 約数を列挙することは不可能です。 すべての因数が異なる場合、約数の数は次のようになります。$2^n$、それは天文学的な大きさです。 どのような解法も、等しい素数の多重度を直接処理する必要があります。 

微妙な点は、答えは約数の数ではないということです。 例えば：```
n = 3
primes = [2,3,5]
```除数は、3 次元のブール格子を形成します。 最大のアンチチェーンにはサイズがあります$3$、 ない$8$。 

もう 1 つの簡単な間違いは、証明することなく、同じ数の素因数を持つすべての約数が常に最適であると仮定することです。 考慮する：```
x = 2^3
```約数は次のとおりです。$1,2,4,8$。 すべてのペアは同等であるため、最大の良好なセットにはサイズがあります$1$。 除数格子の構造が重要です。 

3 番目のトラップは、階乗公式を使用して、特定のランクで約数を数えようとすることです。 多重度は次のように大きくなります。$2\cdot10^5$、指数は素数ごとに独立して制限されます。 正しい計数オブジェクトは生成関数であり、多項係数ではありません。 

## アプローチ

 ブルート フォース ビューは、基礎となる組み合わせ構造を明らかにするため便利です。 

すべての約数は指数のベクトルに対応します。 優れたセットは、連鎖積ポーズセットのアンチチェーンです。$$[0,c_1]\times[0,c_2]\times\cdots\times[0,c_k].$$ブルート フォース ソリューションでは、すべての約数を生成し、可算関係を構築し、最大のアンチチェーンを検索します。 約数の数が指数関数的に増加する可能性があるため、これは絶望的です。$n$。 

重要な観察は、このポーズが次の基準でランク付けされていることです。$$r(e_1,\dots,e_k)=e_1+\cdots+e_k.$$同じランクの 2 つの異なる要素を比較することはできません。 もし$$e_i\le f_i$$すべての座標でランクの合計が等しい場合は、すべての座標が等しくなければなりません。 

したがって、すべてのランクは自動的にアンチチェーンになります。 

ここで、深い定理が登場します。 連鎖の積はランク対称およびランク単峰性であり、シュペルナー特性を満たします。 このようなポセットの場合、最大アンチチェーンのサイズは最大ランクのサイズと等しくなります。 

合計ランクの範囲は次のとおりです。$0$に$$c_1+\cdots+c_k=n.$$ランク サイズは対称的かつ単峰性であるため、最大のランクは中央のランクになります。$$\left\lfloor \frac n2 \right\rfloor .$$したがって、問題全体は、次を満たす指数ベクトルを数えることに帰着します。$$0\le e_i\le c_i, \qquad e_1+\cdots+e_k=\left\lfloor\frac n2\right\rfloor.$$これはまさに次の係数です$$\prod_{i=1}^{k}(1+x+x^2+\cdots+x^{c_i})$$程度で$\lfloor n/2\rfloor$。 

残りのタスクは多項式の乗算です。 

各因子は次の形式の多項式です。$$1+x+\cdots+x^{c_i}.$$すべての度数の合計は、$$c_1+\cdots+c_k=n\le 2\cdot10^5.$$すべての多項式を分割統治戦略で乗算すると、NTT は受け入れられる解決策を提供します。

 ## アルゴリズムのチュートリアル

 1. 因数分解で各素数が何回出現するかを数えます。 

素数が出たら$c$多項式に寄与することが多い$$1+x+\cdots+x^c.$$2. 多重度ごとに 1 つの多項式を作成します。 

からのすべての指数があるため、係数はすべて 1 です。$0$を通して$c$は 1 回だけ許可されます。 
3. 2 つの最小の多項式を繰り返し乗算します。 

これは、最適なマージ パターンに似ています。 これにより、中間多項式のサイズが小さく保たれ、NTT の総作業量が削減されます。 
4. 係数の下で数論的変換を使用する$998244353$すべての乗算に対して。 

この係数は、特に効率的な NTT をサポートするために選択されました。 
5. すべての多項式が結合された後、最終的な母関数を取得します。$$F(x)=\prod_i(1+x+\cdots+x^{c_i}).$$6.次数係数を出力する$$\left\lfloor \frac n2 \right\rfloor.$$連鎖積のスペルナー特性により、この係数は適切なサブセットの最大サイズに等しくなります。 

### なぜ効果があるのか

 除数格子は連鎖の産物です。 そのランク関数は指数の合計です。 同じランクを持つ同等の要素は同一でなければならないため、すべてのランクがアンチチェーンを形成します。 

チェーンの積はシュペルナー ポセットであるため、最大のアンチチェーンがまさに最大のランクになります。 ランクサイズは生成関数によってカウントされます。$$\prod_i(1+x+\cdots+x^{c_i}),$$対称性と単峰性により、最大ランクが次数に配置されます。$\lfloor n/2\rfloor$。 アルゴリズムはその係数を正確に計算するため、返される値は最大の良好なサブセットのサイズになります。 

## Python ソリューション```python
import sys
from collections import Counter
from heapq import heapify, heappop, heappush

input = sys.stdin.readline

MOD = 998244353
G = 3

def ntt(a, invert):
    n = len(a)

    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(G, (MOD - 1) // length, MOD)
        if invert:
            wlen = pow(wlen, MOD - 2, MOD)

        for i in range(0, n, length):
            w = 1
            half = length // 2
            for j in range(i, i + half):
                u = a[j]
                v = a[j + half] * w % MOD

                a[j] = (u + v) % MOD
                a[j + half] = (u - v) % MOD

                w = w * wlen % MOD

        length <<= 1

    if invert:
        inv_n = pow(n, MOD - 2, MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % MOD

def multiply(a, b):
    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1

    fa = a[:] + [0] * (n - len(a))
    fb = b[:] + [0] * (n - len(b))

    ntt(fa, False)
    ntt(fb, False)

    for i in range(n):
        fa[i] = fa[i] * fb[i] % MOD

    ntt(fa, True)
    return fa[:need]

def solve():
    n = int(input())
    primes = list(map(int, input().split()))

    freq = Counter(primes)

    heap = []
    uid = 0

    for c in freq.values():
        poly = [1] * (c + 1)
        heap.append((len(poly), uid, poly))
        uid += 1

    heapify(heap)

    while len(heap) > 1:
        _, _, a = heappop(heap)
        _, _, b = heappop(heap)

        c = multiply(a, b)

        heappush(heap, (len(c), uid, c))
        uid += 1

    result = heap[0][2]
    print(result[n // 2] % MOD)

if __name__ == "__main__":
    solve()
```頻度をカウントするステップでは、素因数分解を多重度に変換します。$c_i$。 各多重度はすぐに多項式になります$1+x+\dots+x^{c_i}$。 

プライオリティ キューは正確性のために必要ありませんが、パフォーマンスが大幅に向上します。 最初に小さな多項式を乗算することで、NTT の作業の総量が最適近くに保たれます。 

NTT 実装は、モジュラスに基づいて標準の反復変換を実行します。$998244353$。 両方のオペランドを変換した後、係数は点ごとに乗算され、逆変換されます。 

最終的な多項式は次数を正確に持ちます$n$。 程度$d$座標の合計が以下に等しい指数ベクトルをカウントします。$d$。 最大のアンチチェーンはランクにあるため$\lfloor n/2\rfloor$、その係数が答えです。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from collections import Counter

def run(inp: str) -> str:
    MOD = 998244353

    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    p = list(map(int, input().split()))

    freq = Counter(p)

    dp = [1]
    for c in freq.values():
        ndp = [0] * (len(dp) + c)
        for i, v in enumerate(dp):
            for e in range(c + 1):
                ndp[i + e] += v
        dp = ndp

    return str(dp[n // 2] % MOD) + "\n"
