 ## 解決策
 ## 問題の理解

 平面内に一連の点が与えられ、それぞれが別個の座標に配置された塔を表します。 タスクは、これらの塔のいくつかを選択し、それらをサイクルで接続して単純な多角形を形成することです。この多角形は、すべての内角が少なくとも 90 度でなければならないという幾何学的制約を満たす必要があります。 塔の任意のサブセットを使用できますが、必要な有効なポリゴンは 1 つだけです。 そのような多角形を形成できない場合は、不可能であることを報告する必要があります。 

出力は、時計回りまたは反時計回りの循環順序で選択されたタワーのインデックスです。 選択したタワーが多角形の直線エッジ上にある場合、それを出力に含めるかどうかはオプションですが、この自由度によって実現可能性が変わることはありません。 

角度の制約が重要な構造上の制約です。 すべての内角が少なくとも 90 度である多角形は、任意のものであってはなりません。 急旋回はできず、凸包の頂点の角度が厳密に 90 度未満である構成は即座に除外されます。 凸包はすでに可能な限り最小の外側境界を与えているため、有効な解は本質的に、鋭角な回転を避ける慎重に選択された凸形状のように動作する必要があります。 

入力サイズは最大 3000 ポイントです。 これにより、O(n^2) または O(n^2 log n) のアプローチが可能になりますが、3 次またはすべてのサブセットを列挙することは不可能です。 

いくつかの特殊なケースは見落とされがちです。 

すべての点が単一線上にある場合、非縮退内角を持つ閉じた形状を形成できないため、いかなる多角形も不可能になります。 たとえば:

 入力:```
3
0 0
1 0
2 0
```出力：```
impossible
```サブセットを選択しようとすると、常に縮退した多角形または線分が生成され、面積を持つ有効なサイクルの定義を満たしません。 

もう 1 つの微妙なケースは、点が凸多角形を形成しているが、鋭角が含まれている場合です。 たとえば、薄い三角形は、その角がすべて鋭角であるか、1 つは鈍角だが他の角は鋭角であるため、常に失敗し、要件に違反します。 

隠れた主な困難は、凸多角形を要求されていないことですが、角度制約により形状が強く制限され、解決策は最終的に制御された回転で単調なチェーンのような構造を形成できる点の選択に基づいて行われることです。 

## アプローチ

 ブルートフォース戦略は、サイズが少なくとも 3 の点のすべてのサブセットを試し、各サブセットについて、単純な多角形に順序付けできるかどうか、およびすべての内角が少なくとも 90 度であるかどうかを確認することです。 順序を修正したとしても、妥当性をチェックするには、多角形の単純さとすべての角度を計算する必要があり、これは線形です。 サブセットの数は指数関数的なので、これは直ちに実行不可能です。 

サイズ k のサブセットに限定したとしても、順列の数は k! であり、k についてはすでに 10 または 15 あたりで爆発的に増加しています。ジオメトリ条件はエッジのみに局所的ではないため、単純な枝刈りはできません。 

重要な点は、角度条件が非常に制限されているということです。すべての頂点で、回転は絶対値で最大 90 度でなければなりません (内角 ≥ 90 は外回転 ≤ 90 を意味するため)。 これは、基本的に、方向の変化が厳密に制限され、ジグザグの動作を防止する多角形のチェーンを構築していることを意味します。 

この制約は、すべての有効なポリゴンが回転後に少なくとも 1 つの方向で単調でなければならないことを強く示唆しています。 点を方向に投影し、あまり急激に曲がりすぎないチェーンを構築しようとする場合、「階段」構造を形成する点を選択することで実現可能性を高めることができます。 これを強制する自然な方法は、ポイントを並べ替えて 2 つの単調チェーンを構築することです。これは凸包構築に似ていますが、より厳密なターン制約を伴います。 

問題は、各ステップが前の方向から大きく逸脱しない、単純な閉じたチェーンを構築することに帰着します。 これは、ソートされた順序で極点を選択し、鋭角が現れないように慎重に上部と下部の構造を形成することで実現できます。

 ## アルゴリズムのチュートリアル

 この解決策は、凸包のような多角形を構築し、鋭角にならないことを検証して保証することに基づいています。これは、凸性と慎重な選択戦略によって保証されます。 

## アルゴリズムのチュートリアル

 1. すべての点を X 座標で並べ替え、Y 座標で結合を解除します。 これにより、モノトーン チェーンを構築するために使用できる、一貫した左から右への構造が得られます。 
2. 凸包に似た下部チェーンを構築します。 ソートされたポイントを反復処理し、スタックを維持します。 新しいポイントごとにそれを追加し、最後の 3 つのポイントが急すぎる右折を形成している間、中間のポイントを削除します。 ここでの削除条件は、厳密に鋭角な回転に相当する 90 度未満の角度を作成しないようにすることに基づいています。 
3. 同様に上のチェーンを構築しますが、ポイントの逆の順序で繰り返します。 これにより、対称性が確保され、実現可能な多角形の上部境界が構築されます。 
4. 2 つのチェーンをマージし、重複するエンドポイントを削除します。 結果として得られるシーケンスは、単純なポリゴン候補を形成します。 
5. 結果の多角形に少なくとも 3 つの異なる頂点があることを確認します。 そうでない場合は出力できません。 
6. オプションで、連続する頂点の各トリプルをチェックし、隣接するエッジの内積を計算することにより、角度制約を検証します。 いずれかのドット積が正の場合 (鋭角を示す)、拒否されます。 
7. 結果のサイクルを順番に出力します。 

### なぜ効果があるのか

重要な不変条件は、構築された両方のチェーンが、連続する点のローカル トリプルが鋭角を形成しないように、制御された回転方向を維持することです。 スタックベースの削除により、潜在的な急性ターンが現れるたびに中間点が削除され、違反の伝播が防止されます。 この構築は凸包の単調性を反映していますが、より厳密な角度制約があるため、結果として得られる多角形は単純であり、境界に沿ったあらゆる場所で内角の要件を満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dot(a, b, c):
    # dot product of BA and BC
    return (a[0]-b[0])*(c[0]-b[0]) + (a[1]-b[1])*(c[1]-b[1])

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]

if n < 3:
    print("impossible")
    sys.exit()

pts.sort()

# Build lower hull with stricter convexity-like constraint
lower = []
for p in pts:
    lower.append(p)
    while len(lower) >= 3:
        if cross(lower[-3], lower[-2], lower[-1]) <= 0:
            lower.pop(-2)
        else:
            break

# Build upper hull
upper = []
for p in reversed(pts):
    upper.append(p)
    while len(upper) >= 3:
        if cross(upper[-3], upper[-2], upper[-1]) <= 0:
            upper.pop(-2)
        else:
            break

upper.reverse()

# merge
poly = lower[:-1] + upper[:-1]

# remove duplicates while preserving order
seen = set()
final = []
for p in poly:
    if p not in seen:
        seen.add(p)
        final.append(p)

if len(final) < 3:
    print("impossible")
    sys.exit()

# check angle condition
ok = True
m = len(final)
for i in range(m):
    a = final[i-1]
    b = final[i]
    c = final[(i+1) % m]
    if dot(a, b, c) > 0:
        ok = False
        break

if not ok:
    print("impossible")
    sys.exit()

# output indices
idx = {p: i+1 for i, p in enumerate(pts)}
res = [idx[p] for p in final]

print(len(res), *res)
```コードは最初に点を並べ替えて、決定的な構造を課します。 下部と上部の構造は、モノトーン チェーン凸包アルゴリズムを直接適用したものですが、重要なフィルタリング条件では非正の外積を使用して非左折を排除します。 内向きの鋭角を防ぐ機構です。 

結合ステップにより、閉じた多角形の境界が形成されます。 船体の構造では極端な点が繰り返されるため、重複する端点は削除されます。 最後に、角度チェックではドット積テストが使用されます。頂点の連続するエッジ間のドット積が正であれば、条件に違反する鋭角を示します。 

インデックス マッピングは、問題ステートメントによって保証される座標の一意性に依存します。

 ## 特殊なケース

 完全に共線的な入力により、船体の崩壊動作が明らかになります。 外積チェックによってすべての中間点が削除されるため、このアルゴリズムでは、上位チェーンと下位チェーンの両方が 2 つのエンドポイントのみに減ります。 最終的なサイズは 3 未満になり、ポリゴンを形成できないという幾何学的事実と一致し、不可能になります。 

ほぼ同一線上にある凸状チェーンは、除去条件が弱いターンを正しく処理するかどうかをテストします。 ほぼ線上にある点は依然として外積ゼロを満たしているため、それらは一貫して削除され、最終的な多角形に平面角が現れるのを防ぎます。 

正方形などの小さな凸多角形は、マージ ステップで有効なサイクルが維持されるかどうかをテストします。 下部チェーンと上部チェーンは境界を正確に再構成し、内積チェックによりすべての角度が直角であることが確認され、少なくとも 90 度であるという要件が満たされます。
