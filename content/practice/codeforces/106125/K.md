 ## 解決策
 ## 問題の理解

 2 人のプレーヤーが、封印された入札に基づいて単一の交換を実行しようとしています。 プレイヤーの 1 人、マクドナルドじいさんはすでにカップの中に何枚かのコインを隠しています。あなたはそれが何枚のコインであるかを正確に知っています。$c$。 あなたも持っています$n$利用可能なコイン。 番号を選択する必要があります$x$、入札を表します。 

両方の入札が明らかになった後、コインが交換され、マクドナルドを受け取ります。$c$コインを受け取ると、彼はあなたのものを受け取ります$x$コイン。 その後、より多くのコインを入札した人に牛が与えられます。 入札額が同じ場合、牛の手を変えることはありません。 

あなたの目標は 2 層の辞書編集です。 まず、この 1 回のやり取りの後に最終的に得られる牛の数を最大化したいと考えます。 複数の選択肢がある場合のみ、$x$同じ牛の結果を出した場合、交換後により多くのコインが残る方が好きですか。 取引所は常に入札を交換するため、取引後の最終的なコイン数は次のようになります。$n - x + c$したがって、同じ牛の結果の中で、より小さいものを好むことになります。$x$。 

出力は単一の整数です$x$、選択した入札額。 

制約により許可されるのは、$c, n \le 10^9$これは、すべての解はテスト ケースごとに一定時間である必要があることを意味します。 可能な入札範囲をシミュレーションする余地はありませんが、ゲームの構造は十分に単純であるため、最適な決定を分析的に導き出すことができます。 

いくつかのエッジの状況が重要です。 

正確に入札した場合$c$、結果は引き分けとなり、牛は交換されません。 単純な戦略では、これを中立または勝ち負けと同等のものとして誤って扱う可能性がありますが、これは別個の結果クラスです。 

以上入札した場合$n$、持っていないコインを使うことができないため、その動きは無効です。 これにより、決定境界が次のようになります。$x \le n$重要な。 

もし$c = 0$, マクドナルドは何も貢献せず、積極的な入札があればすぐに牛が勝ちますが、入札を最小限に抑えることが第二の目標になります。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能な入札が試行される$x$から$0$に$n$。 各候補者について、結果をシミュレートします。比較します。$x$と$c$、牛を獲得するか失うかを決定し、最終的なコインを計算します。$n - x + c$。 次に、2 つのレベルの目標に従って最適なものを選択します。 

問題は次のとおりであるため、これは正しく機能します。$n+1$可能性があり、各評価は定数時間です。 ただし、$n$まで$10^9$、すべての値を反復処理するには、テストごとに 10 億回のオーダーの操作が必要となり、これは 1 秒の制限をはるかに超えています。 

重要な観察は、結果は次の比較のみに依存するということです。$x$そして$c$、そのしきい値を超える大きさではありません。 有効な入札はすべて、次の 3 つのカテゴリのいずれかに正確に当てはまります。$x < c$、$x = c$、 または$x > c$。 各カテゴリ内で牛の結果は固定されているため、唯一の意味のある最適化は、二次コイン目標の下で最良の代表を選択することです。 

もし$x > c$、牛に勝ちます。 このようなすべての選択肢の中で、最終的なコインは次のように減少します。$x$が増加するため、最高落札価格は、厳密に よりも大きい可能な最小値となります。$c$、つまり$c+1$を超えない限り、$n$。 

もし$x = c$、牛は得られませんが、コインは保持します$n$。 これは常に、勝つよりも牛の数が厳密に悪いため、勝つことが不可能な場合にのみ問題になります。 

もし$x < c$、牛を失います。 このうち、選んだコインを最大化するには$x = 0$, ただし、これは勝つことが不可能な場合にのみ問題になります。 

したがって、解決策は落札価格が存在するかどうかによって決まります。$c+1 \le n$。

 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 比較する$c + 1$と$n$。 これにより、手頃な価格でありながら厳密にマクドナルドを上回る入札が存在するかどうかが決まります。 
2. もし$c + 1 \le n$、 選ぶ$x = c + 1$。 これは可能な最小の落札価格であり、消費されるコインを最小限に抑えながら牛の勝利を保証します。 
3. それ以外の場合、入札は厳密に次の値を超えることはできません。$c$予算内なので勝つのは不可能です。 
4. その場合は、$x = 0$。 これにより、牛が負けたり結ばれたりする状況は避けられないことを受け入れながら、コインを完全に失うことを回避できます。 

### なぜ効果があるのか

 ゲームの構造により、すべての結果が単調なしきい値に引き下げられます。$c$。 上記以上の入札$c$牛を落札する場合と同じカテゴリ的な結果が得られますが、コストは厳密に入札額に応じて増加します。 したがって、最適な勝利戦略は、しきい値を超える実現可能な最小値です。 そのような値が存在しない場合、すべての勝ちの状態に到達することはできず、入札を最小限に抑えることによって達成される、可能な限り最善の負けまたは同点の構成に戻ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    c, n = map(int, input().split())
    if c + 1 <= n:
        print(c + 1)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```このコードは、以前に導出したしきい値ロジックを直接実装します。 条件`c + 1 <= n`最小落札価格の実現可能性をチェックします。 true の場合、その値を出力します。 それ以外の場合は、ポジティブな入札ではマクドナルドを上回ることができず、最終的なコインが減少するだけであるため、デフォルトはゼロになります。 

微妙な点は、入札を正確に考慮する必要がないということです。$c$。 この場合、負けたり勝ったりした場合に比べて牛の結果が改善されることはなく、コインの残高も改善されません。$x=0$負けた政権の中で。

 ## 特殊なケース

 いつ$c = n$、条件$c+1 \le n$失敗したので出力します$0$。 入力用`25 25`、アルゴリズムが選択します$x = 0$。 1 から 25 までの入札は、牛の結果において同点か負けのいずれかになり、それ以上の入札は不可能です。 この決定により、不必要なコインの損失が回避されます。 

いつ$c = 0$、 例えば`0 10`、条件が成立し、選択します$x = 1$。 これは最小のプラス入札であり、牛の勝利が保証されます。 選択する$x = 0$この場合は引き分けになるだけで、牛の頭数では厳密に言うとさらに悪くなります。 

いつ$n = 0$、積極的な入札はできません。 入力用`5 0`、条件は失敗し、出力します。$0$、これが唯一の有効な動きです。 たとえ牛を失ったとしても、制約の中で代替手段は存在しません。
