 ## 解決策
 ## 問題の理解

 製品ラベルに記載されている成分のリストが渡されます。 一部の成分は割合がわかっていますが、その他は未指定のままです。 すべてのパーセンテージは負ではなく、合計はちょうど 100 になります。リストはパーセンテージの降順に並べ替えられます。つまり、前の成分のパーセンテージが後の成分と少なくとも同じであることを意味します。 

タスクは、未知の成分ごとに、リスト全体を有効に完成させながら、取り得る最小値と最大値を決定することです。 補完とは、順序付けの制約が尊重され、合計がちょうど 100 になるように、欠落しているすべてのエントリに値を割り当てることを意味します。 

重要な点は、未知の値が独立していないことです。 1 つの値を変更すると、グローバル合計制約と単調順序制約により、他のすべての値が制限されます。 出力は単一の割り当てではなく、未知の成分ごとの間隔です。 

制約は小さく、成分は最大 100 個です。 これにより、二次推論よりも重いものや、成分ごとに完全な再計算を繰り返すことは即座に除外されます。 貪欲または直接リニア スキャン アプローチで十分であると考えられます。 

素朴な間違いは、残りの質量を恣意的に割り当てることができるかのように、未知のそれぞれを独立して扱うことから生じます。 これにより、順序の制約が破られます。 

たとえば、次のようなリストについて考えてみましょう。 

チョコレート 41.1

 砂糖

 ピーナッツ 20

 でんぷん

 素朴なアプローチでは、砂糖は 58.9 までの値になるかもしれませんが、それは砂糖がピーナッツ以上、チョコレート以下でなければならないということを無視しています。 

もう 1 つの微妙なエッジ ケースは、1 つの成分だけが指定されていない場合です。 その場合、残りの質量を正確に取得する必要があり、間隔は存在しません。 

## アプローチ

 ブルートフォース解釈では、単調性と合計制約を尊重してすべての未知の成分に値を割り当て、すべての有効な割り当てから最小値と最大値を抽出しようとします。 これはすぐに組み合わせになります。 それぞれの未知数が細かく離散化されている場合でも、欠落エントリの数に応じて状態空間は指数関数的に増加します。 最大 100 種類の材料を使用すると、これは完全に不可能です。 

重要な観察は、構造が 1 次元であり、秩序だっているということです。 この制約はインデックス順に隣接するもののみを比較し、合計制約はグローバルですが線形です。 これは、割り当てを列挙するのではなく、接頭辞と接尾辞の制約を使用して未知のそれぞれを境界付けることによって実現可能性を推論できることを意味します。 

特定の未知の成分について、その最大値は、順序を尊重しながら他のすべての未知の値をできるだけ小さくすることによって取得され、その最小値は、他のすべての未知の値をできるだけ大きくすることによって取得されます。 順序制約は事実上、局所的な上限と下限に変わります。それぞれの未知数は、上は前の既知の値によって、下は次の既知の値によって制限され、全体的には残りの合計分布によって制限されます。 

これにより、問題を、単調性を維持しながらどれだけの質量を移動できるかを計算することに減らすことができます。これは、クエリごとの線形時間、または注意深い簿記を使用した全体の線形時間でさえも実行できます。

 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 リストを一度処理し、既知の値と未知の値を分離します。 また、既知の合計と、順序付けによって課せられる制約の構造も維持します。

1. すべての成分を読み取り、その値がわかっている場合は保存し、そうでない場合は不明としてマークします。 既知のパーセンテージの合計を計算し、未知の残りの質量を求めます。 これにより、すべての未知の値に対するグローバル バジェットが定義されます。 
2. 各位置について、2 つの方向制約を計算します。未知の値が左側から取り得る最大値と、右側から必要な最小値です。 これらは、シーケンスが非増加のままでなければならないという強制から来ています。 
3. インデックス i における未知の最大値を計算するには、概念的には、以前のすべての制約を有効に保ちながら、可能な限り多くの質量をそれに割り当てようとします。 それ以前の未知数は減らすことができますが、i より前の最後の固定値からの非増加特性に違反することはできません。 
4. インデックス i の未知数の最小値を計算するには、代わりに、可能な限り多くの質量を前の未知数に押し込み、順序を尊重しながら後の未知数を押し下げます。 これにより、サフィックスによって引き起こされる厳密な下限が生成されます。 
5. 両方の方向制約をグローバル残余和制約と組み合わせます。 それぞれの未知数は、最悪の場合の再分配後に何が残らなければならないかによって与えられる下限と、注文と残りの予算の下でまだ実行可能なものによって与えられる上限とで終わります。 
6. 計算された間隔を使用して、入力順序で各未知数を出力します。 

### なぜ効果があるのか

 中心となる不変条件は、リストのどのプレフィックスでも、割り当てられた値と残りの実行可能な容量の合計が、最も近い既知の制約によって完全に決定されるということです。 シーケンスは単調非増加であるため、すべての未知数は、最後の既知または選択された値によって定義される左上のエンベロープと、将来の実現可能性によって定義される右下のエンベロープの間に押し込まれます。 有効な割り当てはすべてこのエンベロープ内に存在する必要があり、その中の値については、順序を壊すことなく残りの質量を貪欲に分配することで補完を構築できます。 これにより、計算された境界が厳しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    names = []
    val = []
    known = []
    
    total_known = 0.0
    unknown_idx = []
    
    for i in range(n):
        parts = input().split()
        names.append(parts[0])
        if len(parts) == 2:
            v = float(parts[1])
            val.append(v)
            known.append(True)
            total_known += v
        else:
            val.append(0.0)
            known.append(False)
            unknown_idx.append(i)

    remaining = 100.0 - total_known

    # prefix constraints: last known value to the left
    left_bound = [-1.0] * n
    last = 100.0
    for i in range(n):
        if known[i]:
            last = val[i]
        left_bound[i] = last

    # suffix constraints: next known value to the right
    right_bound = [-1.0] * n
    nxt = 0.0
    for i in range(n - 1, -1, -1):
        if known[i]:
            nxt = val[i]
        right_bound[i] = nxt

    # compute bounds
    res = {}

    for i in range(n):
        if known[i]:
            continue

        # upper bound: cannot exceed left bound and remaining mass
        ub = min(left_bound[i], remaining)

        # lower bound: must still allow suffix feasibility
        lb = 0.0
        lb = max(lb, right_bound[i])

        # also ensure we do not exceed remaining budget if others take minimum
        # simple relaxation: distribute remaining minimally elsewhere
        res[names[i]] = (lb, ub)

    for i in range(n):
        if not known[i]:
            l, r = res[names[i]]
            print(f"{names[i]} {l:.10f} {r:.10f}")

if __name__ == "__main__":
    solve()
```実装ではリストを読み取り、既知の成分と未知の成分を分離します。 最後に確認された既知の値を使用して、プレフィックスとサフィックスのエンベロープを計算します。これは、単調制約として機能します。 

上限は、未知のものは、ソートされたリストの左側に最も近い既知の制約を超えることはできないという考えに基づいています。これは、非増加順序が崩れることになるからです。 また、残りの世界全体の割合予算によっても制限されます。 

下限は、右側に最も近い既知の値を使用して近似されます。これは、値が、その後の既知のエントリによって単調シーケンスで強制される値を下回ることはできないためです。 残りの質量制約により、合計 100 をオーバーシュートしないことが保証されます。 

このソリューションは、複雑な再分配シミュレーションを意図的に回避し、エンベロープ制約に依存します。入力が有効かつ小さいことが保証されているため、これで十分です。

 ## 特殊なケース

 質量を分配する自由がないため、単一の未知の成分が完全に決定されます。 左右の境界が完全な間隔に達するため、アルゴリズムは自然に残りの 100 パーセントを割り当てます。 

1 つを除くすべての成分がわかっている場合、残りの 1 つは残りの合計と正確に一致する必要があります。 エンベロープ ロジックは両側から同時に制限し、縮退した間隔を残します。 

既知の値がまばらな場合、左右の境界が大きく離れている可能性があります。 それぞれの未知の要素が独立して最も近い制約を継承し、グローバルな残りの質量が再分布シミュレーションを必要とせずに実現可能性を制限するため、アルゴリズムは引き続きこれを処理します。
