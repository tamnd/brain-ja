 ## 問題の理解

 グリッドは (n \times n) 個の正方形のボードです。 一部の細胞には金が含まれており、`X`、他のすべてのセルは空であり、 でマークされています。`.`。 どのセルからでも移動は水平方向または垂直方向にのみ許可されるため、隣接するセルへの移動にはちょうど 1 ステップのコストがかかります。 斜め方向への移動は禁止です。 

すべての空のセルについて、最も近い金のセルまでのマンハッタンの距離が必要です。 その距離が 1 ～ 9 の場合、セルはその数字に置き換えられます。 最も近いゴールドが 10 以上の距離にある場合、セルはそのままになります。`.`。 金細胞自体は残る`X`。 公開された Codeforces ステートメントでは、(n) の上限は明示的に指定されていませんが、時間制限は 1 秒、メモリ制限は 256 MB であるため、作業量がセル数に応じて二次関数的に増加するアルゴリズムが自然なターゲットになります。 

主なエッジ ケースは、距離 10 でのカットオフです。たとえば、次のようになります。```
2
X.
..
```出力があります```
X1
21
```なぜなら、金以外のすべてのセルは金から最大でも 2 歩離れているからです。 を使用する不注意な実装`distance <= 10`間違って印刷されてしまう`10`セルがちょうど 10 歩離れたとき。 このステートメントでは、セルが少なくとも 10 歩離れた場所に留まる必要があります`.`。 

もう 1 つの簡単な間違いは、斜めの動きを 1 つのステップとして扱うことです。 例えば、```
2
X.
..
```パスには水平移動と垂直移動が 1 つずつ含まれている必要があるため、右下のセルの距離は 1 ではなく 2 になります。 

3 番目のエッジ ケースは、多くの金セルがある場合に発生します。 例えば、```
3
X..
...
..X
```中央のセルはいずれかの金のセルから距離 2 にあります。 特定の 1 つの金セルから独立して距離を計算すると、別の金セルに近いセルに対して誤った結果が得られます。 

## アプローチ

 直接的なアプローチでは、すべてのセルから検索を開始し、最初のゴールド ブロックに到達したときに停止します。 1 つのセルからの幅優先検索には最悪の場合 (O(n^2)) 時間がかかり、すべての (n^2) 個の開始セルに対してそれを繰り返すと (O(n^4)) の作業量がかかります。 (n=1000) の場合、これは (10^{12}) 個のセルの訪問数に相当し、1 秒の制限をはるかに超えています。 BFS は開始セルからの最短パスを見つけますが、隣接する開始セルに対してほぼすべての同じ作業を繰り返すので、この方法は正しいです。 

有益な観察は、すべてのゴールド セルが同等の宛先であるということです。 「このセルは最も近い金からどのくらい離れていますか?」と尋ねるのではなく、 セルごとに個別に、質問を逆にして、すべてのゴールド セルから同時に BFS を開始できます。 BFS は距離が減少しない順序で状態を処理するため、BFS が初めてセルに到達するときは、最も近い金ソースからそのセルに到達したことになります。 

これは標準のマルチソース BFS パターンです。 私たちはすべてを置きます`X`距離ゼロのキューに入れます。 それらの隣接層は距離 1 を受け取り、次に次の層は距離 2 を受け取ります。 出力では 10 未満の距離と他のすべての距離のみが区別されるため、距離 9 を超えて検索を拡張する理由はありません。この境界付き BFS によって到達されたすべてのセルは直接書き込むことができますが、到達されていないすべてのセルは直接書き込むことができます。`.`は変わらないままです。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、すべての金色のセルの座標を収集します。 これらの座標をすべてキューに入れ、距離をゼロにします。 すべての金セルから開始すると、1 つの BFS が任意の 1 つの金セルまでの距離ではなく、最も近い金セルまでの距離を表すようになります。 
2. 未訪問の値に初期化された距離配列を維持します。 すべての金色のセルに距離ゼロのマークを付けます。 別の距離配列により、未訪問のセルと距離がゼロのセルを誤って混同することがなくなります。 
3. キューから次のセルを繰り返し削除します。 4 つの有効な近隣のそれぞれについて、その近隣がすでに訪問されているかどうかを確認します。 そうでない場合は、現在の距離に 1 を加えた値を割り当ててキューに入れます。 
4. 新しい距離が 10 になるセルをキューに入れないでください。出力には 10 以上の距離が必要ないため、そこで停止すると、必要な文字を変更せずに不要な作業が削減されます。 
5. BFS が完了したら、元のグリッドをスキャンします。 すべてを維持する`X`変わらない。 距離が 1 ～ 9 の空のセルの場合、その距離を文字として出力します。 セルに到達しなかった場合は、出力`.`。 

これが機能する理由: BFS の不変条件は、セルがキューから削除されるたびに、保存される距離がそのセルからゴールド ソースまでの可能な最小距離になるということです。 すべての金セルの距離がゼロであるため、最初はこれが当てはまります。 距離 (d) のセルが未訪問の隣接セルを発見した場合、その隣接セルはゴールド セルから (d+1) ステップで到達可能です。 より早く到達する代替ルートは、以前に処理された BFS 層からのものである必要があるため、近隣を未訪問にすることはできません。 したがって、記録されたすべての距離が真の最近接ゴールド距離となります。 距離 9 を超えたセルは意図的に無視され、これらのセルはまさに残すべきセルです。`.`。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n = int(input())
    grid = [input().strip() for _ in range(n)]

    # -1 means that the cell has not been reached.
    dist = [[-1] * n for _ in range(n)]
    q = deque()

    # Multi-source BFS: every gold cell is a source at distance 0.
    for r in range(n):
        row = grid[r]
        for c in range(n):
            if row[c] == 'X':
                dist[r][c] = 0
                q.append((r, c))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while q:
        r, c = q.popleft()
        nd = dist[r][c] + 1

        if nd >= 10:
            continue

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if 0 <= nr < n and 0 <= nc < n and dist[nr][nc] == -1:
                dist[nr][nc] = nd
                q.append((nr, nc))

    answer = []

    for r in range(n):
        out = []
        for c in range(n):
            if grid[r][c] == 'X':
                out.append('X')
            elif 1 <= dist[r][c] < 10:
                out.append(str(dist[r][c]))
            else:
                out.append('.')
        answer.append(''.join(out))

    sys.stdout.write('\n'.join(answer))

if __name__ == "__main__":
    solve()
```最初のスキャンでは、すべてのゴールド セルが識別され、BFS キューに配置されます。 これらのセルはすべて、検索開始前に距離ゼロを受け取ります。これが、通常の単一ソース BFS との主な違いです。 

BFS ストア`-1`未訪問のセルの場合。 ゴールドセルの距離はゼロであるため、このセンチネルを正当な距離と混同することはできません。 4 つの方向のペアは、許可される水平方向と垂直方向の移動を正確に表します。 

の`nd >= 10`チェックは近隣を拡張する前に意図的に実行されます。 距離 9 のセルは距離 10 のセルを検出する可能性がありますが、それらのセルは出力には必要ないため、検索は距離 9 のレイヤーで停止します。 厳密なカットオフは、ステートメントの「10 歳未満」と「10 歳以上」の区別と一致します。 

最終スキャンでは、距離ゼロを一般的な出力値として扱うのではなく、元のグリッドが使用されます。 ゴールドセルは残しておかなければなりません`X`, 一方、10 未満の正の距離のみが数字になります。 

Python の整数はオーバーフローせず、保存される最大距離はわずか 9 です。キューには座標ペアが含まれるため、そのサイズは、ゴールド セルの 9 ステップ以内に到達するセルの数に比例します。
