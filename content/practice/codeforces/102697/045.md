 ## 解決策
 ## 問題の理解

 この問題では、惑星オミクロン ペルセイ VIII に落下する物体を記述する 3 つの物理量が与えられます。 最初の値は人に作用する重力 (F_g)、2 番目はその人の質量 (M)、3 番目は物体が落下する距離 (D) です。 オブジェクトは静止状態から開始するため、初速度はゼロです。 立ち下がり時間 (T) を計算し、それを距離とともに出力する必要があります。両方の数値は小数点第 1 位まで表示されます。 元の問題では、1 秒の時間制限と 256 MB のメモリ制限が指定されています。 

最初の方程式は重力加速度を直接与えます。 

[
 F_g = MG
 】

 それで

 [
 G = \frac{F_g}{M}。 
】

 2 番目の方程式はオブジェクトの変位を表します。 

[
 D = V_iT + \frac12GT^2。 
】

 オブジェクトは静止状態から解放されるため (V_i=0)。 方程式は次のようになります

 [
 D = \frac12GT^2。 
】

 正の時間で解くと、

 [
 T = \sqrt{\frac{2D}{G}}。 
】

 (G=F_g/M) を代入すると、実装に最も便利な形式が得られます。 

[
 T = \sqrt{\frac{2DM}{F_g}}。 
】

 公開されたステートメントには、(F_g)、(M)、または (D) の明示的な数値制限はありません。 つまり、ここには意味のある入力サイズの複雑さの問題はありません。 このアルゴリズムは、固定数の算術演算と 1 平方根を実行するため、1 秒の制限に簡単に適合します。 

微妙なエッジ ケースは、初速度をゼロとして扱う必要があることです。 たとえば、入力の場合```
500
70
10
```正しい出力は```
It will take the object 1.7 seconds to fall 10.0 meters
```なぜならオブジェクトは静止状態から始まるからです。 未指定 (V_i) をゼロ以外の値として保持する不用意な実装は、別の物理的状況を解決することになります。 これは、問題によって提供されるサンプルでもあります。 

もう 1 つのよくある間違いは、計算された時間のみをフォーマットすることです。 入力用```
100
50
5
```(G=2) と (T=\sqrt{5}\about2.236) があるため、必要な出力は次のようになります。```
It will take the object 2.2 seconds to fall 5.0 meters
```距離自体も小数点以下 1 桁で印刷する必要があります。 印刷`5`の代わりに`5.0`必要な形式と一致しません。 

3 番目のエッジ ケースは、すでに非常に小さい距離です。 例えば、```
10
2
0.1
```(G=5) と (T=\sqrt{0.04}=0.2) が得られるため、出力は次のようになります。```
It will take the object 0.2 seconds to fall 0.1 meters
```四捨五入ではなく切り捨てを行う不用意な実装は、10 分の 1 の間にある値で失敗する可能性があります。 

## アプローチ

 この問題を考える強引な方法は、考えられる時間を 10 分の 1 秒単位でシミュレートすることです。 各候補 (t) について、距離を計算できます。 

[
 D(t)=\frac12Gt^2
 】

 候補者が必要な距離に到達すると停止します。 候補が昇順にチェックされ、結果が適切に丸められている場合、これは正しいです。 ただし、真の答えが (T) の場合、およそ (10T) 回のチェックが必要になります。 より正確には、(0.0,0.1,\ldots,\lceil10T\rceil/10) をチェックするには、(\lceil10T\rceil+1) 個の候補評価が必要です。 このステートメントでは (T) の上限が指定されていないため、このシミュレーションには有限の最悪ケースの操作数はありません。 たとえ限界が存在したとしても、方程式を正確に解くことができる問題には数値探索は不要です。 

この総当たりアプローチは、距離が時間の単調関数であるため機能しますが、未知数が代数的に分離できる方程式を繰り返し評価するため、失敗します。 重要な観察は、物体が静止状態から始まるため、速度項が完全に消滅するということです。 一度 (V_i=0) になると、残りの方程式には (T^2) のみが含まれるため、(T) を直接解くことができます。 

まず力と質量から重力加速度を計算します。 次に、その加速度を落下距離の方程式に代入し、正の平方根を分離します。 これにより、問題全体が定数時間の演算に還元されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(T))候補チェック | (O(1)) | 原理的に遅すぎる |
 | 最適 | (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (F_g)、(M)、(D) を読み取ります。 これらは、重力、惑星の重力加速度を決定するために使用される質量、および落下距離です。 
2. 重力加速度を次のように計算します。 

[
 G=\frac{F_g}{M}。 
】

 これは (F_g=MG) から直接得られるため、惑星の重力を事前に知る必要はありません。 
3. 物体が静止状態から解放されるため、初速度をゼロに設定します。 したがって、一般方程式 (D=V_iT+\frac12GT^2) は次のようになります。 

[
 D=\frac12GT^2。 
】
 4. 式を並べ替えて次の値を取得します。 

[
 T^2=\frac{2D}{G}。 
】

 時間を負にすることはできないので、正の平方根をとります。 
5. (G)に式を代入して計算します。 

[
 T=\sqrt{\frac{2DM}{F_g}}。 
】

 これにより、不要な中間変数が回避され、実装が短縮されます。 
6. (T) と (D) の両方に小数点以下 1 桁を使用して必要な文を出力します。 Python の浮動小数点書式設定`.1f`必要な小数点以下の四捨五入を実行します。 

重要な不変条件は、(T) の計算値はすべて、条件 (V_i=0) を適用した後の正確な物理方程式から取得されるということです。 計算された加速度は (F_g=MG) を満たし、結果の時間は (D=\frac12GT^2) を満たします。 物理時間は負ではないため、正の平方根を選択すると、固有の有効な解が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    fg = float(input())
    mass = float(input())
    distance = float(input())

    time = math.sqrt(2.0 * distance * mass / fg)

    print(
        f"It will take the object {time:.1f} seconds "
        f"to fall {distance:.1f} meters"
    )

if __name__ == "__main__":
    solve()
```最初の 3 つの読み取りは、入力内の 3 つの物理量に直接対応します。 ステートメントでは値が整数に制限されていないため、これらは浮動小数点数として解析されます。 

表現`2.0 * distance * mass / fg`はまさに式 (2DM/F_g) を整理したものです。 使用する`math.sqrt`次に、(T) の正の解を生成します。 

出力は次を使用します`{time:.1f}`そして`{distance:.1f}`。 最初のフォーマット操作では、計算された立ち下がり時間を小数点第 1 位に四捨五入しますが、2 番目の操作では、入力が次のような整数であった場合でも、指定された距離が必要なフォーマットで表示されることを保証します。`10`。 

ループ、再帰、配列、その他のデータ構造はありません。 計算には定数メモリが使用され、固定量の作業のみが実行されます。

 重力加速度は約 (7.1429\text{ m/s}^2) です。 これを落下距離の式に代入すると、時間は約 (1.6733) 秒となり、四捨五入すると (1.7) になります。 距離は次のように出力されます。`10.0`。 

結果の出力は次のとおりです。```
It will take the object 1.7 seconds to fall 10.0 meters
```この例では、主な式を実行し、両方の数値フィールドに小数点以下 1 桁が必要であることも確認します。 

2 番目の例として、次のことを考えてみましょう。```
100

5
```計算は

 | (F_g) | (男) | (D) | (G=F_g/M) | (2DM/F_g) | (た) | プリント(T) |

 | 100 | 50 | 5 | 2 | 5 | 2.236067... | 2.2 |

 ここで、重力加速度は正確に (2\text{ m/s}^2) です。 結果の時間は (\sqrt5)、約 (2.2361) 秒であるため、10 進数 1 桁の形式では次のようになります。`2.2`。

It will take the object 2.2 seconds to fall 5.0 meters
```このトレースは、プログラムが数学的結果を整数に切り捨てるのではなく四捨五入する必要があることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(1)) | 固定数の算術演算と 1 つの平方根が実行されます。 |
 | スペース | (O(1)) | 3 つの入力値といくつかのスカラー中間値のみが保存されます。 |

 公開されている制限は 1 秒と 256 MB ですが、問題には入力値が 3 つしか含まれておらず、一定サイズの計算が必要です。 解決策は両方の限界をはるかに下回っています。 

## テストケース```python
import sys
import io
import math

def solve():
    input = sys.stdin.readline

    fg = float(input())
    mass = float(input())
    distance = float(input())

    time = math.sqrt(2.0 * distance * mass / fg)

    print(
        f"It will take the object {time:.1f} seconds "
        f"to fall {distance:.1f} meters"
    )

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample
assert run("500\n70\n10\n") == (
    "It will take the object 1.7 seconds to fall 10.0 meters\n"
), "sample 1"

# Minimum-style positive values
assert run("1\n1\n1\n") == (
    "It will take the object 1.4 seconds to fall 1.0 meters\n"
), "basic positive values"

# All quantities chosen so that the time is exactly 0.2
assert run("10\n2\n0.1\n") == (
    "It will take the object 0.2 seconds to fall 0.1 meters\n"
), "small distance"

# Exact integer time
assert run("100\n50\n8\n") == (
    "It will take the object 2.8 seconds to fall 8.0 meters\n"
), "non-integer rounded time"

# Large values, useful for checking floating-point arithmetic
assert run("1000000000000\n1000000000000\n1000000000000\n") == (

), "large values"

 | --- | --- | --- |
 |`500 / 70 / 10`|`1.7 seconds`、`10.0 meters`| 提供されたサンプルと必要なフォーマット |

 |`10 / 2 / 0.1`|`0.2 seconds`、`0.1 meters`| 短い距離と小数入力 |
 |`100 / 50 / 8`|`2.8 seconds`、`8.0 meters`| 正しい平方根計算と丸め |

## 特殊なケース

 最初のエッジケースは初速度です。 と```
500
70
10
```オブジェクトは明示的に静止状態から解放されるため、(V_i=0)。 このアルゴリズムは、方程式を解く前に (V_iT) 項全体を削除します。 この項をゼロ以外の任意の速度に保つと、物理的に異なる答えが生成されます。 

2 番目のエッジ ケースは、出力フォーマットに関するものです。 のために```
100
50
5
```計算時間はおよそ (2.2360679) です。 必要な結果は次のとおりです`2.2`、 ない`2`そしてそうではありません`2.3`。 の`:.1f`書式指定子は、小数点以下 1 桁を保証しながら丸めを実行します。 距離は個別にフォーマットされ、`5.0`。 

3 番目のエッジ ケースは小数距離です。```
10
2
0.1
```ここ

 [
 T=\sqrt{\frac{2(0.1)(2)}{10}}
 =\sqrt{0.04}
 =0.2。 
】

 プログラムは印刷します```
It will take the object 0.2 seconds to fall 0.1 meters
```これにより、距離が整数であると想定する実装が捕捉されます。 

最後に、大きな数値によってアルゴリズムは変更されません。 のために```
1000000000000
1000000000000
1000000000000
```式では質量と重力が相殺され、(T=\sqrt{2\cdot10^{12}})、およそ (1414213.562) が残ります。 プログラムは印刷します`1414213.6`。 計算では、入力値の大きさに関係なく、定数メモリと定数時間のみが使用されます。
