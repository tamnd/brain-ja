 ## 問題の理解

 このタスクは、Morbit 暗号を使用して小文字の平文を暗号化することです。 暗号化には、中間にモールス信号と 2 文字のモールス ブロックという 2 つの表現があります。 

すべての文字は標準のモールス表現に置き換えられます。 連続する文字の間に 1 文字を置きます`x`、連続する単語の間には 2 つの単語を置きます。`x`文字。 したがって`ab`になる`.-x-...`、 なぜなら`a`は`.-`、文字は次のように区切られています。`x`、 そして`b`は`-...`。 次に、完全なモールス信号列が左から右へペアに分割されます。 長さが奇数の場合は、最後に 1 つ`x`が追加されています。 

各位置には以下を含めることができるため、可能なペアはちょうど 9 つあります。`.`、`-`、 または`x`。 9 つの主要な行は、これら 9 つのペアの順列を示します。 The first line is the pair represented by digit`1`、2 番目は数字で表されるペアです`2`、など、数字による`9`。 必要な出力は、構築されたモールス文字列内のすべての連続するペアに対応する数字です。 公式声明では、1 秒の時間制限と 256 MB のメモリ制限が指定されています。 

このステートメントでは、平文の最大長が明示的に提供されていません。 つまり、安全な設計は、作業が二次的に増加するものではなく、テキスト上の単一の線形パスであることを意味します。 キーには 9 つのエントリしか含まれていないため、9 つのエントリすべてを単純に検索しても非常に小さな定数に制限されますが、辞書を使用するとより明確な結果が得られます。`O(1)`すべてのモールス信号ペアを検索します。

2 番目のエッジ ケースは単語境界です。 同じキーを使用すると、平文`ab`生成する`.-x-...`。 そのペアは`.-`、`x-`、`-.`、 そして`..`、与える`2936`。 よくある間違いは、`x`スペースの場合、スペースには 2 つ必要です`x`文字。 境界以降はペアごとに区別が変わります。 この問題は明示的に定義します`x`文字の間と単語の間の 2 つです。

## アプローチ

 直接的なアプローチでは、最初に完全なモールス文字列を構築し、次にそれを一度に 2 文字ずつ処理します。 すべてのペアについて、一致するペアが見つかるまで 9 つのキー エントリをスキャンできます。 これは正しいです。キーによって、考えられるすべての 2 文字ブロックを表す桁が正確に定義されるからです。 モールス信号に次の内容が含まれている場合、`P`キャラクター、あります`P / 2`のペアであり、各ルックアップは最大 9 つのエントリを検査でき、最大で`9P / 2`ペアの比較。 この問題には最大値が明記されていません`P`, そのため、定数が小さいにもかかわらず、キーを繰り返しスキャンするのは不必要な作業です。 

よりクリーンな解決策が即座に得られる観察結果は、キーが固定されており、考えられるペアの値が 9 つだけ含まれているということです。 保存することでキーを一度反転できます`pair -> digit`。 次に、各モールス信号ペアは 1 回の辞書検索でその数字に変換されます。 高価な部分はキーの検索ではなくなり、暗号化全体が生成されるモールス信号のサイズに線形になります。 

モールス変換自体も当然ながら線形です。 各平文文字を固定の 26 エントリのテーブルにマッピングします。`x`文字の後に別の文字が続く場合に挿入します`xx`次の文字が別の単語を始めるとき。 モールス表現を構築した後、パディングとペアの処理はそれぞれ別の線形パスを実行します。

| 最適 | O(P) | O(P) | 承認済み |

 ここ`P`は、セパレータと可能なパディングを含む、生成されたモールス文字列の長さを示します。 すべてのモールス符号化は最大 4 つの一定の長さを持ち、各文字は一定量の区切り情報のみを提供するため、`P`平文の長さは線形です。 

## アルゴリズムのチュートリアル

 1. スペースを破棄せずに、完全な平文行を読み取ります。 スペースは、2 つのスペースがどこに配置されるかを決定するため、意味があります。`x`文字を挿入する必要があります。 
2. 9 つのキー ペアを読み取り、キーが 2 文字のブロック、値がその数字である辞書を作成します。`1`を通して`9`。 これにより、キーが与えられる方向が逆転し、暗号化に必要な内容が正確に一致します。 
3. 平文をモールス信号に変換します。 すべての単語について、標準の A から Z のモールス表を使用して文字を変換し、1 つの文字を入力します。`x`連続する文字の間。 2つ入れて`x`連続した単語の間にある文字。 
4. 結果のモールス信号の長さが奇数の場合は、モールス信号を追加します。`x`。 これにより、すべての文字が 1 つの 2 文字ブロックに属します。 
5. モールス線を 2 つのステップで通過させます。 各ペアを抽出し、キー辞書で検索します。 対応する数字を答えに追加します。 
6. 累積された数字を 1 つの文字列として出力します。 各ペアは正確に 1 桁を構成するため、出力には区切り文字は含まれません。 

**機能する理由** モールス変換後、文字はモールス符号を使用し、単語と文字の境界は指定された文字列を使用するため、構築された文字列は暗号に必要な中間表現とまったく同じになります。`x`区切り文字。 パディングは、必要な最終的な不一致位置のみを変更し、長さが奇数の場合に正確に実行されます。 次に、文字列は、暗号によって定義された同じ連続する 2 文字のブロックに分割されます。 逆キー辞書は、そのようなすべてのブロックを、それに割り当てられた数字に正確にマッピングするため、すべての出力数字は正しく、すべてのブロックは 1 回だけ処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MORSE = [
    ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..",
    ".---", "-.-", ".-..", "--", "-.", "---", ".--.", "--.-", ".-.",
    "...", "-", "..-", "...-", ".--", "-..-", "-.--", "--.."
]

def solve():
    text = input().rstrip("\n")

    key = {}
    for digit in range(1, 10):
        pair = input().strip()
        key[pair] = str(digit)

    words = text.split()
    morse_parts = []

    for word_index, word in enumerate(words):
        for i, ch in enumerate(word):
            morse_parts.append(MORSE[ord(ch) - ord("a")])
            if i + 1 < len(word):
                morse_parts.append("x")

        if word_index + 1 < len(words):
            morse_parts.append("xx")

    morse = "".join(morse_parts)

    if len(morse) % 2:
        morse += "x"

    answer = []
    for i in range(0, len(morse), 2):
        answer.append(key[morse[i:i + 2]])

    print("".join(answer))

if __name__ == "__main__":
    solve()
```の`MORSE`配列にはインデックスが付けられています`ord(ch) - ord("a")`、 それで`a`インデックスを選択します`0`、`b`インデックスを選択します`1`、など。 これにより、一連の条件文が回避され、定数時間の文字変換が行われます。 

平文は単語に分割され、単語の境界を正確に表すことができます。`xx`。 各単語内に、コードは明示的に 1 つの単語を挿入します。`x`2つの文字の間のみ。 これにより、単語の最後の文字の後に誤って区切り文字を追加することがなくなります。 

キー辞書は入力とは逆方向に構築されます。 5 番目のキー行が次の場合`.x`、 それから`key[".x"]`になる`"5"`。 これは、暗号化中に必要な検索方向です。 

パディングは、モールス文字列全体が構築された後にのみ行われます。 順序は重要です。`x`はパディングであり、単語の区切り文字ではありません。 単語境界で終わる平文は、追加の人為的な区切り文字を取得すべきではありません。 

ペア ループは 2 文字ずつ進むため、1 つの検索キーの形成に使用される 2 文字が次のペアと重複することはありません。 このループの前の奇数長チェックにより、最終スライスに常に正確に 2 文字が含まれることが保証されます。 

ここでは、Python の整数ではオーバーフローの問題が発生しません。また、暗号文は数値ではなく一連の数字であるため、出力は文字列として蓄積されます。

import sys
import io

MORSE = [
    ".-", "-...", "-.-.", "-..", ".", "..-.", "--.", "....", "..",

def solve():
    input = sys.stdin.readline
    text = input().rstrip("\n")

    key = {}
    for digit in range(1, 10):
        key[input().strip()] = str(digit)

    words = text.split()
    parts = []

    for wi, word in enumerate(words):
        for i, ch in enumerate(word):
            parts.append(MORSE[ord(ch) - ord("a")])
            if i + 1 < len(word):
                parts.append("x")
        if wi + 1 < len(words):
            parts.append("xx")

    morse = "".join(parts)

    if len(morse) % 2:
        morse += "x"

    ans = []
    for i in range(0, len(morse), 2):
        ans.append(key[morse[i:i + 2]])

    print("".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
