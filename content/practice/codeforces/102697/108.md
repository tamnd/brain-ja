 グリッドは、空のタイルと斜めの鏡を含む長方形のホールです。 レーザーはコラムの下から入射します`x`そして最初は上向きに移動します。 空のタイルに到達するたびに、レーザーが通過する方向に従ってそのタイルにマークを付ける必要があります。 縦の通路になります`|`、水平通路になります。`-`、両方の方法で走査されたタイルは次のようになります。`+`。 ミラータイルは変更されません。 

鏡は新しい方向を決定します。 のために`/`、上向きのビームは右に向きを変え、右向きのビームは上に向きを変え、下向きのビームは左に向きを変え、左向きのビームは下向きに曲がります。 のために`\`、上向きのビームは左に曲がり、左向きのビームは上向きに、下向きのビームは右に曲がり、右向きのビームは下に曲がります。

## アプローチ

 最も直接的な総当たりシミュレーションは、現在の位置と方向を保持し、次のミラーが見つかるまでその行または列に沿って検索することです。 ミラーが見つかったら、現在の位置とミラーの間のすべての空のタイルにマークを付け、対応する反射を適用します。 ビームが空のタイルを通過している間は何もビームの方向を変えることができないため、これは正しいです。 

問題は、スキャンによって次のミラーを見つけると、大量の作業が繰り返される可能性があることです。 させて`L = max(n, m)`。 多くてもあります`4nm`明確な位置と方向の状態を検出し、次の障害物をスキャンすることで、最大で次の障害物を検査できます。`L`細胞。 したがって、セル検査の最悪の場合の量は次のように制限されます。`4nmL`、つまり`O(nm max(n,m))`。 大きなグリッドでは、そのような余分な要素は不要です。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、出力用の変更可能なコピーを作成します。 元のミラー文字は変更されずに存続する必要がありますが、空のセルは無効になる可能性があります。`|`、`-`、 または`+`。 
2. から開始します`(n - 1, x)`方向性あり`up`。 開始タイルはグリッド内にあるため、他のすべてのタイルと同様に処理する必要があります。 
3. 状態を処理する前に、次のことを確認します。`(row, column, direction)`はすでに訪問されています。 そうなっている場合は、停止してください。 動作ルールは決定的であるため、同じ状態に再び到達するということは、将来の状態のまったく同じシーケンスが繰り返されることを意味します。 
4. 現在のセルが空の場合はマークを付けます。 垂直方向が貢献`|`、水平方向が寄与します`-`、セルにすでに他のパス文字が含まれている場合は、それを次のように変更します。`+`。 ミラーセルはそのまま残されます。 
5. 現在のセルに次の内容が含まれている場合`/`を使用して方向を変更します。`/`反省ルール。 含まれている場合`\`、対応するものを使用してください`\`ルール。 それ以外の場合は、同じ方向に進み続けます。 
6. 下の境界を特別に処理します。 ビームが一番下の列にあり、下向きに移動している場合は、グリッドから離れるのではなく、左に回転させます。 これは、問題の幾何学によって表される入口側の反射です。 
7. 1 つおきに、次の行と列を計算します。 次の位置がグリッドの外側にある場合、ビームはホールから出ており、シミュレーションは終了します。 それ以外の場合は、そこに移動してステップ 3 から続行します。 

### なぜ効果があるのか

 不変条件は、各反復の直前に、`(row, column, direction)`は、実際のレーザー ビームの位置と方向を正確に記述しており、これまでに通過したすべての空のタイルには、ビームが通過したすべての方向がすでにマークされています。 

空のタイルの場合、ビームの方向は変わらないため、1 つのセルを移動することは、次のイベントに直接移動することとまったく同じです。 ミラーの場合、実装では対応する反射ルールが適用されるため、次の状態も正確になります。 底部の境界は特別な入口動作に従って処理され、他のすべての出口はビームを終了します。 

状態が繰り返される場合、決定論とは、ビームがその時点以降同じ遷移をたどることを意味します。 このようなサイクルでは新しいセルやパス方向を追加できないため、そこで停止すると完全な出力が保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x = map(int, input().split())
    grid = [list(input().rstrip("\n")) for _ in range(n)]

    # Directions: 0 = up, 1 = right, 2 = down, 3 = left.
    dr = (-1, 0, 1, 0)
    dc = (0, 1, 0, -1)

    # Reflection tables.
    # '/'  : up->right, right->up, down->left, left->down
    # '\'  : up->left, left->up, down->right, right->down
    slash = (1, 0, 3, 2)
    backslash = (3, 2, 1, 0)

    seen = [[[False] * 4 for _ in range(m)] for _ in range(n)]

    r, c, d = n - 1, x, 0

    while True:
        if seen[r][c][d]:
            break
        seen[r][c][d] = True

        # Mark the empty cell according to the current direction.
        if grid[r][c] == '.':
            if d == 0 or d == 2:
                if grid[r][c] == '.':
                    grid[r][c] = '|'
            else:
                grid[r][c] = '-'
        elif grid[r][c] == '|':
            if d == 1 or d == 3:
                grid[r][c] = '+'
        elif grid[r][c] == '-':
            if d == 0 or d == 2:
                grid[r][c] = '+'

        # Mirrors change the direction.
        if grid[r][c] == '/':
            d = slash[d]
        elif grid[r][c] == '\\':
            d = backslash[d]

        # The bottom edge is the entrance edge. A downward beam
        # reaching it turns left instead of leaving the hall.
        if r == n - 1 and d == 2:
            d = 3
            continue

        nr = r + dr[d]
        nc = c + dc[d]

        # The other three boundaries are exits.
        if not (0 <= nr < n and 0 <= nc < m):
            break

        r, c = nr, nc

    sys.stdout.write("\n".join("".join(row) for row in grid))

if __name__ == "__main__":
    solve()
```方向配列は、時計回りの固定順序で 4 つの可能な動きをエンコードします。 これにより、ミラー遷移がネストされた条件のコレクションではなく、小さなルックアップになります。 

の`seen`配列には、セル方向のペアごとに 1 つのブール値が含まれます。 異なる方向から同じセルに入ると、将来のパスが異なる可能性があるため、セルだけではサイクルを検出するのに十分ではありません。 

マーキング コードは 3 つのケースを区別します。 以前にタッチされていなかったセルは、`|`または`-`。 反対のパス文字がすでに含まれているセルは次のようになります。`+`。 ミラー文字は決して変更されません。 明示的なチェックは、`|`そして`-`これにより、後の垂直パスで交差点を正しく変換できるようになります。 

下端のチェックは鏡面反射後に行われます。 境界ルールが関係する前に、一番下の行のミラー自体が下向きのビームの方向を変える可能性があるため、この順序は重要です。 最下行で方向が下向きであることがわかったら、それを左に変更して同じセルから続行すると、入口エッジの動作が再現されます。 

Python には整数オーバーフローの問題はありません。 最大の補助構造物は、`seen`配列。グリッド セルごとに 4 つの状態に比例します。
