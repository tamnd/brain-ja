 ## 問題の理解

 同位体には、この問題に関連する 2 種類の粒子、陽子と中性子が含まれています。 その質量数は両方をカウントするので、

 [
 m = p + n、
 】

 ここで、(p) は陽子の数、(n) は中性子の数、(m) は質量数です。 

入力は (p \le m) とともに (p) と (m) を与えます。 必要な出力は中性子の数です。 定義を再整理するとすぐに次のようになります

 [
 n = m - p。 
】

 公開されたステートメントでは、1 秒の時間制限と 256 MB のメモリが指定されていますが、(p \le m) を超える 2 つの整数に制限的な上限は与えられていません。 計算自体は一定の時間と一定の追加スペースであるため、実際に考慮すべき点は整数のサイズだけです。 Python の整数は任意の精度をサポートしているため、実装では固定幅のオーバーフローの問題は発生しません。 

主なエッジケースは平等です。 たとえば、入力の場合`5 5`、質量数は 5 つの陽子で構成され、中性子は含まれないため、正しい出力は次のようになります。`0`。 ステートメントで結果が正の整数として記述されているため、答えが正でなければならないと仮定する不注意な解決策は、指定された条件によって等価性が許可されている場合、この境界で失敗します。 

もう 1 つの境界ケースは、中性子が 1 つだけ存在する場合です。 入力あり`92 93`、正しい出力は次のとおりです。`1`。 減算は正しい順序で実行する必要があります。`p - m`生み出すだろう`-1`中性子の数がプラスであっても。 

## アプローチ

 強引な解釈では、何らかの方法で可能な中性子の数を検索し、その結果の合計が質量数と一致するかどうかを確認することになります。 たとえば、(p+n=m) まで (n=0,1,2,\ldots) を試すことができます。 これは正しいです。質量数の定義によって、候補の中性子数がいつ有効であるかが正確にわかるからです。 ただし、最悪の場合、(m-p+1) 回の反復を実行する可能性がありますが、これは不必要な作業であり、ステートメントが小さな数値制限を課していないため、任意に大きくなってしまいます。 

問題の構造により、その検索は不要になります。 質量数を定義する式には、すでに目的の値が直接含まれています。 (m=p+n) であるため、既知の総陽子数から既知の陽子の数を引くと、正確な中性子の数が得られます。 ブルート フォースは、方程式を満たす値を検索するため機能しますが、方程式が 1 回の操作で代数的に解けることを無視するため失敗します。 量が単純な合計を形成することが観察されると、問題全体が 1 つの減算に減ります。

 ## アルゴリズムのチュートリアル

 1. 陽子の数 (p) と質量数 (m) を読み取ります。 これらは、同位体の中性子数を再構築するために必要な 2 つの量です。 
2. (m-p) を計算します。 質量数にはすべての陽子とすべての中性子が含まれるため、すべての (p) 陽子を除去すると、正確に中性子が残ります。 
3. 結果を印刷します。 追加の処理、検索、データ構造は必要ありません。 

重要な不変条件は定義 (m=p+n) です。 (m-p) を計算する時点では、総質量数から既知の陽子の寄与を代数的に削除しています。 したがって、残りの値は正確に (n) であるため、印刷された答えは必要な中性子数以外のものを表すことはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

p, m = map(int, input().split())
print(m - p)
```最初の行は、唯一の入力行から 2 つの整数を読み取ります。`map(int, ...)`それらを Python 整数に変換します。これにより、固定幅整数のオーバーフローに関する懸念も回避されます。 

減算はアルゴリズムの 2 番目のステップから直接続きます。 意図的に次のように書かれています`m - p`、 ない`p - m`、質量数は合計であり、陽子の数は除去される部分であるためです。 

ループや補助データ構造はありません。 プログラムは、1 つの入力操作、1 つの算術操作、および 1 つの出力操作を実行します。 

## 実用的な例

 サンプル 1 の同位体には 92 個の陽子と 238 の質量数があります。 

| (p) | (男) | (m-p) | 出力 |
 | --- | --- | --- | --- |
 | 92 | 238 | 146 | 146 |

 方程式は(238=92+n)なので、(n=146)となります。 減算により中性子数が直接回復されます。 

サンプル 2 の場合、同位体には 36 個の陽子と 85 の質量数があります。 

| (p) | (男) | (m-p) | 出力 |
 | --- | --- | --- | --- |
 | 36 | 85 | 49 | 49 |

 再度、(85=36+n) となり、(n=49) となります。 同じ不変式が特別な処理を行わずに適用されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    p, m = map(int, input().split())
    print(m - p)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

# provided samples
assert run("92 238\n") == "146\n", "sample 1"
assert run("36 85\n") == "49\n", "sample 2"

# minimum-size style case
assert run("1 1\n") == "0\n", "zero neutrons"

# all protons except one particle is a neutron
assert run("92 93\n") == "1\n", "exactly one neutron"

# large values, checking arithmetic without iteration
assert run("1000000000000000000 1000000000000000000\n") == "0\n", "large equal values"

# large gap between proton count and mass number
assert run("123456789 1000000000\n") == "876543211\n", "large neutron count"

## 特殊なケース

5 5
```アルゴリズムは (p=5) と (m=5) を読み取り、(5-5=0) を計算して出力します。```

```これは、答えが厳密に肯定的でなければならないという誤った仮定を捉えています。 算術定義では、常に (p=m) ゼロの中性子が許可されます。

0
