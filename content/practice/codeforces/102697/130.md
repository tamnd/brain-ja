 ## 解決策
 ## 問題の理解

 世界は 20 x 20 の固定グリッドの Minecraft チャンクです。 すべての細胞は既知のタイガ (`T`）、 砂漠 （`D`）、 森 （`F`)、または未踏の (`.`）。 少なくとも 1 つの Taiga セルがすでに知られており、実際の世界には 1 つの Taiga バイオームが正確に含まれています。 

バイオームの関連する定義は、側面に隣接するセルを介した接続性です。 2 つの Taiga セルは、それらの間に Taiga セルのみを使用して上下左右に移動するパスがある場合、同じバイオームに属します。 

私たちは、すべての未探索のセルについて、タイガ バイオームが 1 つだけ存在するという世界の一貫性を保ちながら、それがタイガである可能性があるかどうかを判断したいと考えています。 出力は、そのようなすべてのセルが次から変更された元のマップです。`.`に`T`。 

重要な制限は、既知の砂漠または森林セルは決してタイガになることができないことです。 未探索のセルは、他の未探索のセルを介して既知のタイガ セルに接続できるとき、まさにタイガになることができます。 既知の砂漠や森林を通過せずに既知のタイガ セルに到達できない場合、それをタイガに割り当てると別のタイガ コンポーネントが作成され、世界には 1 つのタイガ バイオームが存在するという事実に矛盾します。 これは、ステートメント内の接続定義から直接得られます。 

グリッド サイズは常に 20 x 20 なので、セルは 400 個のみです。 セルごとに数百回の演算を行うアルゴリズムであっても、1 秒の制限内では十分に高速になります。 高度な漸近最適化は必要ありませんが、自然なグラフ走査は、すべてのセルを個別に繰り返し検索するよりも簡単で効率的です。 

最初のエッジケースは、孤立した既知の Taiga セルです。 たとえば、左上隅に次のような地図があるとします。`T`、 と`D`そのすぐ右とその下にあります。 これら 2 つの Desert セルは Taiga セルからの動きを完全にブロックするため、正しい出力では他のすべてのセルは変更されません。 すべての未探索のセルをタイガの可能性があるものとして扱う不用意な実装は、ボード全体を誤って`T`。 

2 番目のエッジ ケースは、2 つの分離された既知のタイガ地域を接続する未踏の地域です。 知っていたら`T`にあります`(0,0)`、別の場所にあります`(0,2)`、 そして`(0,1)`は`.`、 それから`(0,1)`タイガの可能性があると考えなければなりません。 最終的なバイオームは次のようになります。`T T T`, したがって、2 つの既知の部分は同じバイオームの一部になります。 ドットが既存のドットに直接隣接しているかどうかのみをチェックする実装`T`接続パスに沿ってさらに遠くのセルを見逃す可能性があります。 

3 番目のエッジ ケースは境界で発生します。 最初の行のセルからはその上に隣接するセルはなく、最後の列のセルからは右に隣接するセルはありません。 たとえば、唯一既知の Taiga セルが次の場所にある場合、`(0,0)`、トラバースは行にアクセスしてはなりません`-1`または列`-1`。 Python では、負のインデックスは有効な構文であり、配列の反対側を暗黙的に参照するため、境界チェックを忘れると、例外ではなく完全に間違ったマップが生成される可能性があります。 

## アプローチ

 直接的な総当たりアプローチは、すべての未探索のセルを個別に検討し、砂漠や森林を通らずにそのセルから既知のタイガ セルに至る経路があるかどうかを尋ねることです。 1 つのセルの DFS または BFS は、最大 400 個のセルすべてにアクセスできます。 400 個のセルすべてに対してその検索を繰り返すと、最大でも`400 * 400 = 160,000`セルの訪問数は、この問題としてはすでに小さいため、実際には快適に通過できるでしょう。 

より自然なアプローチは、質問を逆にすることです。 すべてのドットがタイガに到達できるかどうかを個別に尋ねる代わりに、既知のタイガ セルから開始して、タイガが到達できるすべてのセルを見つけます。 両方を治療する`T`そして`.`処理しながら横断可能として`D`そして`F`ブロックされたように。 次に、単一のマルチソース BFS または DFS が、固有の Taiga コンポーネントに属する可能性のあるすべてのセルを訪問します。 

個々の到達可能性クエリは小さいため、ブルート フォースが機能しますが、基本的に同じ探索が何度も繰り返されます。 すべての有効なセルが既知のタイガ領域から到達可能なセルであるという観察により、代わりに 1 回の走査を実行できます。 すべてのセルは最大 1 回処理されるため、アルゴリズムはグリッド セルの数に応じて線形時間で実行されます。

 ## アルゴリズムのチュートリアル

 1. 世界地図の 20 行を可変グリッドに読み取ります。 既存のすべての`T`ユニークなタイガバイオームの開始点となる可能性があります。 
2. 既知のものをすべて入力します`T`セルを DFS スタックに追加し、訪問済みとしてマークします。 すべての既知の Taiga セルから一度に開始することは、それらがすでに同じ最終バイオームに属している必要があるため便利です。 
3. スタックが空ではない間に、1 つのセルを削除し、その隣り合う 4 つのセルを検査します。 隣接するオブジェクトが 20 × 20 グリッド内にあり、その元の文字が次のいずれかである場合、その隣接オブジェクトは通過可能であるとみなされます。`T`または`.`。 

砂漠と森林のセルは、その生物群系がすでに知られており変更できないため、決して通過することはできません。 
4. 未訪問の通過可能なネイバーが見つかったら、それを訪問済みとしてマークし、スタックにプッシュします。 もしあの隣人がそうだったら`.`に変更します`T`すぐに。 

このようなすべてのセルをタイガに割り当てることができるのは、合法的にタイガになることができるセルのみを使用して、トラバースによって既知のタイガ セルからそのセルへのパスが明示的に見つかっているためです。 
5. トラバースが終了したら、変更したグリッドを印刷します。 訪問したすべてのドットは次のようになります`T`、到達できないドット、砂漠、森林、および元のタイガ セルはすべて、必要な値を保持します。 

### なぜ効果があるのか

 不変条件は、訪問されたすべてのセルが、元のセルのみを使用して少なくとも 1 つの既知の Taiga セルから到達可能であることです。`T`細胞と未踏の細胞。 したがって、訪問したすべてのドットを Taiga に安全に割り当てることができ、トラバースによって到達したすべての既知の Taiga セルは 1 つの接続されたコンポーネントに属します。 

逆に、未探索のセルが、有効な最終世界のタイガである可能性があると仮定します。 Taiga バイオームは 1 つだけ存在し、既知の Taiga セルが少なくとも 1 つ存在するため、そのセルは既に存在するセルを介して既知の Taiga セルに接続されている必要があります。`T`あるいは元々未開拓だったもの。 このようなパスには何も含まれていません`D`または`F`, したがって、トラバースはパス全体をたどり、セルを訪問します。 したがって、アルゴリズムは、ユニークな Taiga バイオームに属する可能性のある細胞を正確にマークします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    grid = [list(input().strip()) for _ in range(20)]

    visited = [[False] * 20 for _ in range(20)]
    stack = []

    for r in range(20):
        for c in range(20):
            if grid[r][c] == 'T':
                visited[r][c] = True
                stack.append((r, c))

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    while stack:
        r, c = stack.pop()

        for dr, dc in directions:
            nr = r + dr
            nc = c + dc

            if not (0 <= nr < 20 and 0 <= nc < 20):
                continue

            if visited[nr][nc]:
                continue

            if grid[nr][nc] == 'D' or grid[nr][nc] == 'F':
                continue

            visited[nr][nc] = True
            grid[nr][nc] = 'T'
            stack.append((nr, nc))

    sys.stdout.write('\n'.join(''.join(row) for row in grid))

if __name__ == "__main__":
    solve()

DFS は、許容されるグリッドの動きに正確に対応する 4 つの方向ベクトルを使用します。 近隣セルがグリッドから離れる場合、すでに訪問されている場合、または既知の砂漠または森林セルである場合、近隣セルは拒否されます。 

ドットは次のように変換されます`T`発見された瞬間に。 これは安全です。発見とは、既知のタイガ セルから合法的にタイガになれるセルを通ってそのドットに至る経路がすでに存在することを意味するからです。 

アクセスする前に境界チェックを行う必要があります`grid[nr][nc]`。 次のような式があるため、これは Python に特に関連します。`grid[-1]`は合法であり、最後の行を指します。これは、境界外の動きを誤ったラップアラウンドの動きにサイレントに変換します。 

整数演算は関与しないため、整数のオーバーフローは無関係です。 グリッド全体に含まれるセルは 400 個のみで、各セルは最大 1 回だけスタックにプッシュされます。

既知のタイガが 1 つある完全なオープンワールドの場合、すべてのセルがそのタイガに接続されます。 走査は最終的に 400 個のセルすべてを訪問し、399 個の未知のセルすべてを`T`。 これは可能な最大のタイガ バイオームであり、既知のタイガの周囲に 1 つのレイヤーだけを拡張した後でもアルゴリズムが停止しないことも確認されています。 

既知の森林セルと砂漠セルについては、`F`または`D`タイガと広大な未踏の地域を隔てる細胞。 これらのセルはスタックにプッシュされないため、トラバースはその壁で停止します。 たとえ未開の地がタイガ地域に比べて広大であっても、壁の周りに別の道がなければ、そのすべてをタイガに割り当てることはできません。 このアルゴリズムは、通常の 4 方向の到達可能性を通じてその区別を正確に発見します。
