 ## 問題の理解

 このタスクは、アフィン暗号を使用して小文字の文字列をエンコードすることです。 2 つの整数`a`そして`b`暗号を定義します。 すべての文字について、まず変換します。`a`に`z`数字に落とし込む`0`を通して`25`、適用する

入力には、1 行目に 2 つの暗号パラメータが含まれ、2 行目に平文が含まれます。 出力は、元のすべてのスペースを含む完全なエンコードされた文字列です。

## アプローチ

 最も直接的な総当たり手法では、各文字を処理し、アフィン公式を満たす数値を持つ文字が見つかるまで、26 個の出力可能な文字をすべて試します。 これは正しいです。すべての候補出力には 0 から 25 までの既知の値があるため、26 個の可能性をすべてテストすると、最終的に必要な値が見つかるはずです。 ある長さの文字列の場合`n`ただし、これは次までのパフォーマンスを発揮します`26n`最悪の場合の候補者チェック。 26 は定数であるため、この作業は技術的には線形ですが、不必要であり、問​​題の単純な算術構造がわかりにくくなります。 

アルファベットが小さいため総当り攻撃は機能しますが、暗号自体がすでに答えの正確な数値を与えています。 文字が変換されると、`x`、実行する検索はありません。 計算できます`(a * x + b) % 26`直接、その数値を文字に変換し直します。 

重要な観察は、変換がすべてのキャラクターに対して独立しているということです。 1 つの文字の暗号化された値は、前の文字、次の文字、または文字列内の文字の位置には依存しません。 つまり、入力を 1 回スキャンして文字をすぐに変換し、スペースを変更せずにコピーできるということです。 

したがって、最適なソリューションは、入力文字ごとに一定の作業を実行します。 その実行時間は、`O(n)`、 どこ`n`は入力文字列の長さであり、次の値が必要です`O(n)`出力を新しい文字列として構築する場合はスペース。

 ## アルゴリズムのチュートリアル

 1.読む`a`そして`b`最初の行から読み取ってから、2 行目全体を平文として読み取ります。 スペースはデータの一部であるため、行全体を読む必要があります。 
2. 出力バッファを作成します。 文字列を 1 文字ずつ処理すると、小文字のみを置換しながらスペースを正確に保持できます。 
3. 各文字について、それがスペースであるかどうかを確認します。 その場合、暗号は文字にのみ適用されるため、変更せずにスペースを追加します。 
4. 小文字の場合は、次のコマンドを使用して数値に変換します。`ord(c) - ord('a')`。 このマップは`a`に`0`、`b`に`1`、 そして`z`に`25`。 
5. 計算する`(a * x + b) % 26`。 モジュロ演算により、結果が有効なアルファベットの範囲に戻されます。`0`を通して`25`、算術演算がラップアラウンドする場合を含む`z`に戻る`a`。 
6. 結果の数値を次のように小文字に変換します。`chr(value + ord('a'))`、それを出力バッファに追加します。 
7. 完成した出力文字列を出力します。 文字は入力とまったく同じ順序で表示され、小文字のみが暗号化された値に置き換えられます。 

### なぜ効果があるのか

 すべての入力文字に対して、アルゴリズムはまず規定の文字コードを正確に取得します。`x`。 次に、暗号の定義式を適用します。`(a * x + b) % 26`, したがって、生成される数値は、必要な暗号化された文字コードとまったく同じです。 スペースは暗号から除外されるというルールに従って、変更されずにコピーされます。 アルゴリズムはこの正しい変換を文字ごとに独立して実行し、順序を変更しないため、結果として得られる文字列はまさに必要な暗号化となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b = map(int, input().split())
    s = input().rstrip('\n')

    result = []

    for c in s:
        if c == ' ':
            result.append(c)
        else:
            x = ord(c) - ord('a')
            y = (a * x + b) % 26
            result.append(chr(y + ord('a')))

    print(''.join(result))

if __name__ == "__main__":
    solve()
```最初の 2 つの値は、アフィン公式に直接関与するため、整数として読み取られます。 2行目は次のように読み取られます`input()`スペースはプレーンテキストの一部のままでなければならないため、トークンベースの入力ではありません。 

への呼び出し`rstrip('\n')`行を読み取って追加された改行のみを削除します。 スペースは削除されないため、先頭、末尾、または連続するスペースはそのまま残ります。 これは、`strip()`これにより、平文から意味のあるスペースも削除されます。 

文字テストは数値変換の前に行われます。 電話をかける`ord()`スペースに対してはアルファベットのインデックスは生成されないため、スペースを個別に処理することで無効な変換を防ぐことができます。 

手紙の場合は、`ord(c) - ord('a')`は 0 ～ 25 の値を返します。Python の整数はオーバーフローしないため、異常に大きな値であってもオーバーフローしません。`a`そして`b`整数オーバーフローの問題は発生しません。 モジュロ 26 演算は、完全なアフィン式の後に指定どおりに適用されます。 

出力はリストに蓄積され、最後に一度結合されます。 これにより、より大きな中間文字列を繰り返し構築することが回避され、総構築時間が線形になります。
