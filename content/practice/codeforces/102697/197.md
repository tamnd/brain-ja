 ## 解決策
 ## 問題の理解

 座標平面内に 3 本の非平行な線が与えられています。 各行は次のように書かれます`y = mx + b`したがって、すべての線はその傾きによって完全に記述されます。`m`と y 切片`b`。 すべての線のペアはちょうど 1 点で交差します。 これら 3 つのペアごとの交点は三角形を形成し、その面積を 10 進数として出力する必要があります。 

入力にはちょうど 3 つの方程式が含まれているため、入力とともに増加するパラメーターはありません。 制限時間は 1 秒、メモリ制限は 256 MB ですが、この問題はすでに定数です。方程式の数値に関係なく、3 つの直線の交点と 1 つの三角形領域の計算のみを実行します。 

ステートメント内の数値には明示的な制限がないため、実装では整数演算ではなく浮動小数点演算を使用する必要があります。 パイソンの`float`裁判官は小さな数値許容範囲内で回答を受け入れるため、これで十分です。 

微妙なケースは、3 つの線すべてが同じ点を通過する場合です。 例えば、```
y = x + 5
y = 2x + 5
y = 3x + 5
```3つの交差点はすべて、`(0, 5)`したがって、正しい領域は次のとおりです。`0.0`。 不注意な実装では、3 本の非平行線が常に非縮退三角形を形成し、ゼロ領域を処理できないと想定する可能性があります。 

もう 1 つのエッジ ケースは、負の傾きと負の切片です。 例えば、```
y = -2x - 3
y = x + 1
y = 4x - 8
```符号は方程式の一部であり、解析中に失われてはなりません。 ステートメントは固定のトークン形式ではなく数式を記述しているため、スペースを中心に入力を分割することは脆弱です。 スペースを削除すると、最初に両方が作成されます`y = -2x - 3`そして`y=-2x-3`同等。 

3 番目のケースは、座標が分数である交差点です。 例えば、```
y = 2x + 3
y = -2x + 9
y = x - 2
```非整数の交差座標と次の領域が生成されます。`28.166666666666664`。 整数除算を使用すると、暗黙のうちに計算が破損します。 

## アプローチ

 最も直接的なアプローチは、3 つの頂点を明示的に構築することです。 線のペアごとに 2 つの線形方程式を解き、交点を取得します。 次に、三角形の面積に対する標準の行列式を適用します。 

このアプローチはすでに定数時間です。 ちょうど 3 つの線のペアがあります。`(1, 2)`、`(1, 3)`、 そして`(2, 3)`。 各交差には、固定数の算術演算が必要であり、その後に固定サイズの靴紐の計算が必要です。 数学的に言えば、最悪のケースはちょうど 3 つの交差計算と 1 つの面積計算であり、最終的な行列式演算を数える前に 3 つの座標ペアに対しておよそ 21 回の基本算術演算が必要になります。 遅くなる可能性のある入力依存のループはありません。 

したがって、この問題では、遅い総当たり法と漸近的に高速な解決策との間の通常の区別は実際には存在しません。 有用な最適化は、漸近的ではなく代数的です。 可能な点を検索したり、幾何学的構造を使用したりする代わりに、すべての線がすでに次の形式を持っているという事実を利用します。`y = mx + b`、別の線との交点がすぐに得られます。 

ライン用`y = m1 x + b1`そして`y = m2 x + b2`、

 それらの交差は満たされます`m1 x + b1 = m2 x + b2`。 

並べ替えると`x = (b2 - b1) / (m1 - m2)`。 

一度`x`がわかっている場合は、それをいずれかの行に代入して取得します`y`。 このステートメントは、2 本の線が平行ではないことを保証します。`m1 - m2`決してゼロではありません。 

次に、3 つの交点を使用できます。`(x1, y1)`、`(x2, y2)`、 そして`(x3, y3)`行列式では`area = |x1(y2-y3) + x2(y3-y1) + x3(y1-y2)| / 2`。 

その結果、一定の時間と一定の追加スペースが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 明示的な交差 + 靴紐 | お(1) | お(1) | 承認済み |
 | 直接代数幾何学 | お(1) | お(1) | 承認済み |

 入力には常に正確に 3 行が含まれるため、2 つのアプローチの漸近的な複雑さは同じになります。 2 番目のプレゼンテーションは、数学的構造を直接公開し、不必要な幾何学的機構を回避するため、推奨されます。 

## アルゴリズムのチュートリアル

 1. 3 つの方程式を読み、それぞれをペアに変換します。`(m, b)`。 まずスペースを削除すると、入力の周囲にスペースが含まれているかどうかにパーサーが依存しなくなります。`=`、`x`、そして標識。 
2. ラインのペアごとに`(i, j)`を使用してそれらの交差を計算します。`x = (bj - bi) / (mi - mj)`。 

この問題では 2 本の直線が平行ではないことが保証されているため、分母はゼロではありません。 
3. 対応する y 座標を次のように計算します。`y = mi * x + bi`。 

ポイントは両方のライン上にあるため、ペアの最初のラインを使用するだけで十分です。 
4. 3 つの交点を保存します。 ペア`(0, 1)`最初の頂点を与える、`(0, 2)`2番目を与え、そして`(1, 2)`3番目を与えます。 
5. 靴紐の公式をこれら 3 つの点に適用し、絶対値を 2 で割ります。 絶対値を取得すると、頂点の時計回りまたは反時計回りの順序が処理されます。 
6. 結果の浮動小数点値を出力します。 裁判官は小さな数値誤差を受け入れるため、特定の小数表現を強制する必要はありません。 

機能する理由: 交差公式は、1 対の直線の 2 つの方程式から直接取得されるため、生成されたすべての点は、まさに必要なペアごとの交差となります。 このアルゴリズムは、3 つのペアごとの交差をすべて生成します。これらは、まさに問題によって定義された頂点です。 靴紐の公式は、これら 3 つの点によって決定される三角形の正確な面積を示します。これには、3 本の線が同時にある場合はゼロも含まれます。 したがって、最終的な値は必要な三角形の面積になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def parse_line(line):
    s = line.replace(" ", "")
    left, right = s.split("x")
    m = float(left.split("=")[1])
    b = float(right)
    return m, b

def intersection(a, b):
    m1, b1 = a
    m2, b2 = b

    x = (b2 - b1) / (m1 - m2)
    y = m1 * x + b1
    return x, y

def solve():
    lines = [parse_line(input().strip()) for _ in range(3)]

    p1 = intersection(lines[0], lines[1])
    p2 = intersection(lines[0], lines[2])
    p3 = intersection(lines[1], lines[2])

    x1, y1 = p1
    x2, y2 = p2
    x3, y3 = p3

    area = abs(
        x1 * (y2 - y3)
        + x2 * (y3 - y1)
        + x3 * (y1 - y2)
    ) / 2.0

    print(area)

if __name__ == "__main__":
    solve()
```パーサーはまず、方程式からすべてのスペースを削除します。 その後、次のような方程式が成り立ちます。`y = -2x + 9`になる`y=-2x+9`。 で分割します`x`傾斜部分を切片部分から分離し、`float`正の値と負の値、および小数値を処理します。 

の`intersection`関数は、アルゴリズムのウォークスルーで導出された方程式を実装します。 分母は使用します`m1 - m2`したがって、ゼロ除算の唯一の可能性は 2 つの等しい傾きになりますが、この問題では明示的に除外されます。 

3 つの呼び出しでは、考えられる各ペアが 1 回だけ使用されます。 靴紐の表現は次のように包まれているため、この領域では順序は関係ありません。`abs`。 

Python の整数ではオーバーフローの問題は発生しませんが、ここでの計算では`float`交差点の座標と最終的な面積は小数になる可能性があるためです。 問題の浮動小数点出力要件に合わせて、印刷前に丸めは実行されません。

 ### サンプル 1

 入力は```

## 特殊なケース

 同時回線の場合は、次の点を考慮してください。```
y = x + 5
y = 2x + 5
y = 3x + 5
```1 番目と 2 番目の線は次の点で交差します。`(0, 5)`。 1 番目と 3 番目の線も次の点で交差します。`(0, 5)`、2行目と3行目も同様です。 保存された 3 つの点は同一であるため、靴紐の行列式のすべての項がキャンセルされ、アルゴリズムは次のように出力します。`0.0`。 特別なブランチは必要ありません。 

負の係数については、次のことを考慮してください。```
y = -2x - 3
y = x + 1
y = 4x - 8
```最初の 2 つの線は次の位置で交差します。`(-4/3, 5/3)`、最初と 3 番目は次の点で交差します。`(-1/2, -2)`、2 番目と 3 番目は次の点で交差します。`(9/5, 14/5)`。 結果として得られる面積は、`6.25`。 傾きと切片を抽出する前に方程式全体がコンパクトな形式に変換されるため、パーサーは両方のマイナス符号を保持します。 

分数交差については、最初のサンプルで関連するケースがすでに提供されています。 2本目と3本目の線の交点は、`(11/3, 5/3)`。 浮動小数点の実装では、これらの分数が裁判官の許容範囲内で十分に保存されますが、整数の除算ではそれらの分数が不正な整数になってしまいます。 

傾きがゼロの場合、次のことを考慮します。```
y = 1000x + 1
y = -1000x + 1
y = 0x - 1000000
```3 行目は水平線ですが、並列ペアのみが禁止されているため、これは完全に有効です。 最初の 2 行は次の位置で交わります。`(0, 1)`、他の 2 つの交点には x 座標があります。`-1000.001`そして`1000.001`。 結果として得られる面積は、`1000002000.001`, これは、線の 1 つが水平で、三角形が非常に大きい場合にもこの式が機能することを示しています。
