 ## 問題の理解

 問題は、Codeforces Gym 101775、問題 L のゲーム **SOS** です。ボードは (N) 個の空のセルの行です。 パンダが最初に動き、プレイヤーは交互に空のセルを選択して次のいずれかを書き込みます。`S`または`O`そこに。 移動によって 3 つの連続するセルのスペルが作成される瞬間`SOS`、その動きをしたプレイヤーが勝ちます。 すべてのセルが生成されずに満たされた場合`SOS`、結果は引き分け。 

入力には最大 (1000) の独立したゲームが含まれ、(N) は最大で (1000) です。 答えは実際の一連の動きではなく (N) のみに依存するため、意図した解はテスト ケースごとに基本的に一定時間である必要があります。 ゲームツリーを探索するシミュレーションは絶望的です。 完全な移動シーケンスだけを数えたとしても、すべての移動が残りのセルの 1 つと 2 つの文字の 1 つを選択するため、それらは (2^N N!) 個存在する可能性があります。 2 秒という制限により、ゲームの構造を理解すれば多項式シミュレーションさえも不要になります。 

重要なエッジケースは、非常に小さな基板です。 (N=3) の場合、パンダは最初の動きしか取れず、羊は常に最後の 3 つのセルが移動するのを防ぐことができるため、パンダは勝利を強制することはできません。`SOS`。 正しい結果は`Draw`。 たとえば、入力```

## アプローチ

 直接的な解決策は、ゲーム全体をモデル化することになります。 すべての位置で、すべての空のセルと考えられる両方の文字を試し、現在のプレーヤーが勝利を強制できるかどうかを再帰的に判断し、勝利した時点で停止します。`SOS`が表示されます。 これは正しいです。すべての正当な手が考慮されるため、ミニマックスは勝ち、負け、引き分けの局面を区別できます。 問題は木の大きさです。 枝刈りをしないと、完全な再生シーケンスの数は (2^N N!) になります。 すべてのセルが空になる可能性があるため、ボードのメモ化された表現でも最大 (3^N) 個の状態があります。`S`、 または`O`。 (N=1000) の場合、どちらのアプローチも遠隔的には実行可能ではありません。 

有益な観察は、このゲームには局所的な勝ちパターンがあるということです。 フォーム内の 4 つの連続するセルを考慮します。`S__S`、中央の 2 つのセルは空です。 このポジションで手を打った人はすぐに負けます。 そのプレイヤーが書いたら`O`どちらかの空のセルに、相手は書き込みます`S`他のセルで取得します`SOS`。 そのプレイヤーが書いたら`S`空いている 1 つのマスに相手が書きます。`O`もう一方で、再び取得します`SOS`。 したがって`S__S`それは、そのターンのプレイヤーにとっての罠です。 

次の問題は、このトラップをどのように強制するかです。 連続する 7 つの空のセルで十分です。 置く`S`4番目のセルにあります。 対戦相手がこれら 7 つのセル内で移動するたびに、反対側のエンドポイントを選択し、別のエンドポイントを配置します。`S`そこには。 2 つの間の 2 つのセル`S`文字は空のままになり、`S__S`。 対戦相手が 7 セル領域の外でプレイする場合、どちらのエンドポイントも選択できるため、同じ構築がさらに簡単になります。 

この 7 セル構成により、奇数ボードの結果が説明されます。 長さが少なくとも 7 の奇数ボードでは、パンダは最初にそのような領域を作成し、残りの動きの同等性を使用して羊をトラップに直面させることができます。 したがって、すべての奇数 (N\ge7) がパンダの勝ちになります。

(N=16) では、パンダはボードを 7 より短い 2 つの領域に分割できなくなりました。 最初はどこでも構いません`O`が配置され、片面には少なくとも 7 つのセルが含まれます。 羊は同じ 7 つのセル構造を使用してその側面を利用できます。 同じ引数がより大きな偶数 (N) ごとに適用されるため、すべての偶数 (N\ge16) に対して羊が勝ちます。 これにより完全な分類が得られます

 ## アルゴリズムのチュートリアル

 1. (N) を読み取ります。 勝者はボードの長さだけで決まるため、実際のボードを構築する必要はありません。 
2. (N) が奇数で (N\ge7) の場合、出力`Panda`。 7 つのセル領域により、最初のプレーヤーは`S__S`奇数パリティにより、トラップは作成したプレイヤーに有利になります。 
3. それ以外の場合、(N) が偶数で (N\ge16) の場合、出力`Sheep`。 パンダの初防衛`O`このサイズのボードを 7 より短い 2 つの領域に分割することはできないため、Sheep は 7 セルの領域を取得し、同じ構造を逆にすることができます。 
4. (N) の残りの値ごとに、出力`Draw`。 これは、勝ちの構造が適合しないすべての (N\le6) と、パンダがいずれかのプレイヤーが十分に大きな領域を取得するのを妨げる可能性がある (8) から (14) までのすべての偶数 (N) をカバーします。 

この分類が機能する理由は、`S__S`不変。 プレイヤーが屋内への移動を強制されると`S__S`、可能なすべての文字は、相手の次の動きですぐに失われます。 7 つの連続した空のセルは、対戦相手が 1 回移動したにもかかわらず、この構造を作成するには正確に十分であり、しきい値は 7 になります。 次に、ボードの同等性によって、どのプレイヤーが対戦相手にトラップ内で移動するように強制できるかが決まります。 偶数の場合は、パンダの最初の防御動作の両側に十分なスペースが必要で、16 で 2 番目のしきい値が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for case in range(1, t + 1):
        n = int(input())

        if n >= 7 and n % 2 == 1:
            result = "Panda"
        elif n >= 16 and n % 2 == 0:
            result = "Sheep"
        else:
            result = "Draw"

        print(f"Case #{case}: {result}")

if __name__ == "__main__":
    solve()
```このソリューションは、まずゲーム数を読み取り、次に各ボードを個別に処理します。 最初の条件は、奇数の勝利範囲 (7,9,11,\ldots) をチェックします。 2 番目の条件は、均等な勝ちの範囲 (16,18,20,\ldots) をチェックします。 どちらの条件にも当てはまらない値はすべて引き分けとなります。 

2 つの範囲が互いに素であるため、条件の順序は技術的に危険ではありませんが、数学的分類から直接記述することで実装の検証が容易になります。 配列、再帰、ボード シミュレーションがないため、境界インデックスを管理する必要がなく、整数オーバーフローの心配もありません。 Python の整数型は入力範囲としては十分です。 

出力では必要な`Case #x: result`元の問題で指定されたとおりに、1 から始まるケース番号が付けられた形式。

```羊が左側のどこかでプレイすると、パンダがプレイします`S`右の終点にあります。 代わりに羊が右側のどこかでプレイすると、パンダがプレイします`S`左側の終点にあります。 結果として得られる 4 つのセル セグメントは次の形式になります。`S__S`, そのため、羊は 2 つの空のセルで安全に遊ぶことができません。 7 セル領域が同等であるため、正しいプレイヤーが移動するトラップが残り、パンダに勝利が与えられます。 これはまさに解答例の背後にある構造です。
