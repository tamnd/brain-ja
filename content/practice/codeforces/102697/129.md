 ## 問題の理解

ノンバリアセルかどうか`*`または`.`、になります`.`隣接する 8 つの位置のうち少なくとも 1 つが配置されるとすぐに、`.`。 8 つの近傍には、水平、垂直、斜めの位置が含まれます。 バリアの動作は異なります。`X`になる`.`それが厳密にボードの内側にあり、その隣接するすべてのポジションも同様である場合にのみ、`X`。 アン`X`外側のエッジは決して消えることはありません。

## アプローチ

 直接的なアプローチは、ボードを一度に 1 ターンずつシミュレートすることです。 すべてのセルについて、その 8 つの隣接セルを検査し、そのセルが死滅するかどうかを判断します。 すべてのアップデートは同時に行われるため、次世代には 2 番目のボードが必要です。 すべての遷移は前の世代によってのみ決定されるため、これは正しいです。 

問題は世代数です。 死んだセルが存在すると、死滅は世代ごとに 1 チェビシェフ ステップずつ伝播する可能性があるため、次元 n および m の基板では、死滅する可能性のあるすべてのセルが死滅するまでに O(max(n,m)) 世代を必要とする可能性があります。 したがって、完全なシミュレーションでは O(nmmax(n,m)) セルの更新が実行され、更新ごとに最大 8 つの隣接検査が行われます。 最悪の場合、これは、各新しいボードを構築するオーバーヘッドを考慮する前に、約 8nmmax(n,m) の近隣チェックになります。 

ブルートフォース シミュレーションは、死は不可逆であるため機能しますが、グラフ トラバーサルが 1 回のパスで検出できるのと同じ伝播を繰り返し検出するため、失敗します。 

重要な観察は、細胞が死んだ後は二度と変化しないということです。 このプロセスは実際には塗りつぶしです。 イニシャル`.`細胞はすでにこの洪水の原因となっています。 さらにもう 1 種類のソースがあります。それはインテリアです。`X`その 8 セル近傍全体は、`X`細胞。 そんな`X`最初のターンがなかったとしても、最初のターンで死亡します。`.`細胞。 

これらの発生源が特定された後、最終的に死滅する可能性のあるすべてのセルは、それら自体が死滅する可能性のある位置を介してそれらの 1 つから到達可能なセルとなります。 インテリア`X`細胞は、波が到達すると死ぬ可能性があるため、通過可能です。 非バリアセルも通過可能です。 境界`X`セルは通過できない唯一のセルです。`X`永遠に。 

これにより、無限シミュレーションがマルチソース BFS に変わります。 BFS はすべての世代を複製する必要はありません。 拡張するデッド領域が最終的に到達するすべてのセルを直接検索します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nmmax(n,m)) | O(nm) | 遅すぎる |
 | マルチソース BFS | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ボードを読み、元の内容を保存します。 自然に死滅した細胞を特定するときは、元の状態が必要です。その状態は、新たに作成された死んだ細胞が存在する前に評価されるためです。 
2. キューを作成し、最初に配置されたすべてのセルを追加します。`.`。 これらの細胞は時間ゼロでは死んでいるため、死が伝播する最初の発生源となります。 
3. 内部をすべて検査する`X`。 隣接する 8 つのセルすべても同様である場合、`X`、このセルを別のソースとしてキューに追加します。 バリア ルールでは最初のターンで死亡するため、最終状態を計算する際には距離 0 のソースとして扱うだけで十分です。 
4. すべてのソースを同時に使用して BFS を実行します。 デキューされたすべてのセルについて、その 8 つの隣接する位置を検査します。 隣接ノードがボード内にあり、境界ではない場合は、隣接ノードに到達できます。`X`。 まだ到達していない場合は、デッドとしてマークし、エンキューします。 
5. 到達したすべてのセルを次のように置き換えます。`.`。 到達しなかったセルは、元のシンボルを保持します。 残ることができる唯一の細胞`X`は伝播をブロックする境界障壁であり、`*`到達した領域の外側のセルは、隣接する死んだセルがなければルールによってセルを殺すことができないため、永久に生き続けます。 

BFS の不変条件は、すでに到達済みとしてマークされているすべてのセルは、最終的には死滅するセルであるということです。 逆に、未到達セルに到達した隣接セルがあり、永続的な境界ではない場合`X`、ルールにより最終的にそのセルは無効になるため、BFS はそのセルに到達する必要があります。 永続的な障壁は境界だけなので`X`セルを横断すると、最終的に死ぬセルに正確に到達します。

Pythonimport sysfrom collections import deque
input = sys.stdin.readline
def solve():    n, m = map(int, input().split())    board = [list(input().strip()) for _ in range(n)]
    q = deque()    dead = [[False] * m for _ in range(n)]
    # Initial dead cells are sources.    for r in range(n):        for c in range(m):            if board[r][c] == '.':                dead[r][c] = True                q.append((r, c))
    # Interior X cells surrounded entirely by X are also sources.    for r in range(1, n - 1):        for c in range(1, m - 1):            if board[r][c] != 'X':                continue
            all_barriers = True            for dr in (-1, 0, 1):                for dc in (-1, 0, 1):                    if dr == 0 and dc == 0:                        continue                    if board[r + dr][c + dc] != 'X':                        all_barriers = False                        break                if not all_barriers:                    break
            if all_barriers and not dead[r][c]:                dead[r][c] = True                q.append((r, c))
    # Multi-source BFS.    while q:        r, c = q.popleft()
        for dr in (-1, 0, 1):            for dc in (-1, 0, 1):                if dr == 0 and dc == 0:                    continue
                nr = r + dr                nc = c + dc
                if not (0 <= nr < n and 0 <= nc < m):                    continue
                # Boundary X cells never become dead.                if board[nr][nc] == 'X':                    if nr == 0 or nr == n - 1 or nc == 0 or nc == m - 1:                        continue
                if dead[nr][nc]:                    continue
                dead[nr][nc] = True                q.append((nr, nc))
    for r in range(n):        for c in range(m):            if dead[r][c]:                board[r][c] = '.'
    sys.stdout.write('\n'.join(''.join(row) for row in board))
