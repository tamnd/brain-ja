 ## 解決策
 ## 問題の理解

 1 つの小文字文字列が与えられます。 ほとんどの文字はそのままで構いませんが、3 つの文字には特別な多重度があります。 毎`c`出力内に 2 回出現する必要があります。`h`は 5 回出現する必要があり、毎回`z`12回出現しなければなりません。 他のキャラクターは 1 回ずつ登場します。 文字の順序は変更されないため、各入力文字は個別に変換され、そのコピーは一緒に残ります。 

たとえば、`c`で`schizophrenia`になる`cc`、`h`になる`hhhhh`、そして`z`12連続になる`z`文字。 必要な出力は、単純に変換された文字列です。 

元の問題では、入力長の明示的な上限が公開されていません。 制限時間は 1 秒、メモリ制限は 256 MB です。 出力は入力の 12 倍長くなる可能性があるため、受け入れられたソリューションは必然的に、生成される出力のサイズに少なくとも線形時間を費やします。 各入力文字を 1 回処理し、その結果をバッファーに構築するアルゴリズムが自然なターゲットであり、長さ n の入力に対して O(n) 時間、出力に対して O(n) 個の追加スペースが必要になります。 

不注意な実装が露呈する可能性のある小さなケースがいくつかあります。 入力に次のような特殊文字が含まれていない場合、`abc`、出力も次のようにする必要があります`abc`。 すべての文字に置換カウントがあると仮定したソリューションでは、通常の文字が誤って変更される可能性があります。 

入力が`c`、正しい出力は次のとおりです。`cc`。 指定された数をコピーの総数ではなく追加のコピーの数として扱うと、`ccc`。 

入力が`h`、正しい出力は次のとおりです。`hhhhh`、そして入力が`z`、正しい出力は 12 です。`z`文字。 よくある境界の間違いは、乗数自体で終わる範囲を使用して、コピーが 1 つ少なくなってしまうことです。 

特殊文字は連続して使用することもできます。 入力用`chz`、出力は`cchhhhhzzzzzzzzzzzz`。 各文字は、順序を変更せずに個別に展開する必要があります。 

## アプローチ

 単純な実装では、文字列をスキャンして、一度に 1 文字ずつ答えを構築します。 入力文字ごとに乗数が決定され、その文字が必要な回数だけ追加されます。 ある位置の変換は他の位置に依存しないため、このロジックは直接的には正しいです。 

不変の文字列を使用して答えが繰り返し拡張されると、微妙なパフォーマンスの問題が発生します。 現在の結果の長さが k の場合、別の文字を追加するには、既存の k 文字のコピーが必要になる場合があります。 n 個の入力文字がある場合、連結を繰り返すと、最悪の場合、約 1 + 2 + 3 + ... + n 文字 (O(n²)) がコピーされる可能性があります。 正確な定数は Python の実装と特殊文字の分布によって異なりますが、二次関数の増加が問題になります。 

重要な観察は、キャラクター間に相互作用がないことです。 変換された部分をリストに収集し、最後に一度結合することができます。 各入力文字は固定数のコピーに寄与し、最大乗数はわずか 12 です。生成される合計の長さは最大でも 12n であるため、すべての部分を構築して結合するには O(n) 時間がかかります。 

各文字には独立した置換ルールがあるため、ブルート フォースは機能しますが、文字列の連結によって既に構築されたプレフィックスが繰り返しコピーされる場合は失敗する可能性があります。 最後の文字列が独立した変換された部分のシーケンスにすぎないという観察により、最初にそれらの部分を保存し、最後の結合を 1 回実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 文字列連結を繰り返すブルートフォース | O(n²) 最悪の場合 | O(n) | 十分に大きな文字列に対して遅すぎる |
 | 最適リストプラス`join`| O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 単一の入力文字列を読み取り、末尾の改行を削除します。 テスト ケースは 1 つだけであるため、テスト ケース カウンタは必要ありません。 
2. すべての入力文字の変換されたバージョンを保持する空のリストを作成します。 リストを追加しても結果全体が繰り返しコピーされないため、リストが使用されます。 
3. 入力を左から右に処理します。 現在のキャラクターが`c`、追加`c * 2`。 もしそうなら`h`、追加`h * 5`。 もしそうなら`z`、追加`z * 12`。 小文字を 1 つおきに、その文字自体を追加します。 
4. 保存されているすべての部分を 1 つの文字列に結合し、印刷します。 これらの部分は、対応する入力文字とまったく同じ順序ですでに表示されているため、それらを結合すると必要な順序が維持されます。 

### なぜ効果があるのか

 最初の i 個の入力文字を処理した後、リストにはそれらの i 文字に必要な出力が元の順序で正確に含まれます。 これはスキャン全体を通じて維持される不変条件です。 次の文字が処理されるとき、アルゴリズムはその文字に規定されたコピー数を正確に追加するため、不変条件は true のままになります。 最後の文字以降、リストは完全に変換された文字列を表し、その要素を結合しても順序や内容を変更することはできません。 したがって、出力された文字列はまさに必要な出力です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()

result = []

for ch in s:
    if ch == 'c':
        result.append(ch * 2)
    elif ch == 'h':
        result.append(ch * 5)
    elif ch == 'z':
        result.append(ch * 12)
    else:
        result.append(ch)

print(''.join(result))
```入力は次のように読み取られます`input()`そして`strip()`標準入力によって追加された改行を削除します。 文字列自体には小文字のみが含まれるため、3 つの特殊なケースを確認するだけで十分です。 

ループはアルゴリズムの左から右の処理に従います。 Python の文字列の繰り返し。たとえば、`ch * 12`では、正確に 12 個のコピーが作成されるため、手動でループする必要がなく、繰り返し回数が 1 つずれてエラーが発生するリスクもありません。 

変換された部分は次の場所に保存されます。`result`。 決勝戦`''.join(result)`意図的に一度だけ実行されます。 繰り返し書いている`answer += piece`既存の回答を繰り返しコピーできますが、`join`既知の部分のコレクションを使用して最終文字列を割り当てます。 

入力サイズに依存する数値がないため、ここでは Python 整数はオーバーフローしません。 乗数は 2、5、12 のみです。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline
    s = input().strip()

    result = []
    for ch in s:
        if ch == 'c':
            result.append(ch * 2)
        elif ch == 'h':
            result.append(ch * 5)
        elif ch == 'z':
            result.append(ch * 12)
        else:
            result.append(ch)

    return ''.join(result)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    try:
        return solve() + "\n"
    finally:
        sys.stdin = old_stdin

# provided sample
assert run("schizophrenia\n") == "scchhhhhizzzzzzzzzzzzophhhhhrenia\n", "sample 1"

# custom: minimum-size input
assert run("a\n") == "a\n", "ordinary single character"

# custom: each special character exactly once
assert run("chz\n") == "cchhhhhzzzzzzzzzzzz\n", "all special characters"

# custom: consecutive special characters
assert run("ccchhhzzz\n") == (
    "cccccc"
    "hhhhhhhhhhhhhhh"
    "zzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzzz"
    "\n"
), "repeated special characters"

# custom: only ordinary characters
assert run("abcdefg\n") == "abcdefg\n", "no special characters"

 | --- | --- | --- |
 |`a`|`a`| 最小サイズの入力と通常の文字の処理 |
 |`chz`|`cchhhhhzzzzzzzzzzzz`| 3 つの特別な乗数すべて |
 |`ccchhhzzz`|`cccccc...`各グループを展開した状態 | 連続する特殊文字と繰り返しの変換 |
 |`abcdefg`|`abcdefg`| 特別な規則がない文字は変更されません。 

## 特殊なケース

 通常の文字のみを含む入力の場合、たとえば、`a`、ループは最終に到達します`else`分岐して 1 つだけ追加します`a`。 出力は`a`。 1 以外のデフォルトの乗数を使用するソリューションは、このケースでは失敗します。 

入力用`c`、アルゴリズムは乗数 2 を選択し、追加します。`c * 2`、生産`cc`。 これら 2 文字を超える追加のコピーはないため、乗数は出現の合計数として解釈されます。 

入力用`h`、アルゴリズムは追加します`h * 5`、与える`hhhhh`。 Python の繰り返し演算子は、正確なカウントを直接処理し、次のようなループ境界を回避します。`range(5)`誤って次のように書かれている`range(4)`。 

入力用`z`、アルゴリズムは追加します`z * 12`、与える`zzzzzzzzzzzz`。 これは問題における最大の拡張係数であるため、固定入力長に対する出力の最大増加も表します。 

連続する特殊文字の場合、入力`chz`3 つの独立した位置として処理されます。 最初に生成されるのは`cc`、2番目は生成します`hhhhh`、3番目は12を生成します`z`文字。 リストにはこれら 3 つの部分が正確な順序で含まれており、最後の結合により次の結果が得られます。`cchhhhhzzzzzzzzzzzz`。 どのキャラクターも別のキャラクターの乗数や配置に影響を与えることはできません。 

特殊文字を含まない入力の場合、次のようになります。`abc`、すべての反復では通常の文字分岐が使用されます。 結果リストは次のようになります`["a", "b", "c"]`を結合すると、`abc`、変換によって指定された 3 つの文字のみが変更されることが確認されます。
