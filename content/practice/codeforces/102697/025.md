 ## 問題の理解

 スペルを間違えた単語が与えられました`s`そして候補単語の辞書。 スペル ミスには特定の構造があります。つまり、文字が他の文字に置き換えられている可能性がありますが、文字の挿入または削除は行われていません。 つまり、意図する単語は以下とまったく同じ長さでなければなりません。`s`。 その長さのすべての候補の中で、次の単語と異なる単語が必要です。`s`最も少ないポジションで。 複数の候補の不一致の最小数が同じである場合、入力辞書内で最も早く出現した候補が勝ちとなります。 公式声明では、少なくとも 1 人の候補者が必要な長さを備えていることが保証されています。 

同じ長さの 2 つの単語の場合、それらの距離は単に文字が異なるインデックスの数になります。 たとえば、比較すると、`deat`と`beat`、最初の文字のみが異なるため、距離は次のようになります。`1`。 比較する`deat`と`deer`、3番目と4番目の文字が異なり、距離が与えられます`2`。

## アプローチ

 自然な最初の試みは、スペルミスの単語を辞書のすべての単語と比較し、異なる位置の数を数えることです。 これはすでに正しい基本戦略です。 各候補者について、その文字を次の文字と並べてスキャンします。`s`、不一致をカウントし、カウントが最小の候補を保持します。 長さが異なる候補は直ちに無視できます。 

スペルを間違えた単語に長さがある場合`L`そしてそこにあります`n`辞書エントリ、最悪のケースを調べる`nL`キャラクターペア。 より正確には、すべての候補の長さが同じで、早期に終了できる比較がない場合、アルゴリズムは正確に実行されます。`nL`キャラクターの比較。 このステートメントでは明示的な上限が示されていないため、これは問題に対する適切な最悪の場合の表現です。 

魅力的な代替手段は、レーベンシュタイン距離などの一般的な文字列編集距離を計算することです。 これにより、挿入と削除が可能になりますが、それらの操作は入力モデルによって明示的に禁止されています。 一般的な動的プログラミングの編集距離には、`O(L^2)`候補者あたりの所要時間`O(nL^2)`全体として、これは必要以上に厳密に一般的な問題を解決します。 

重要な点は、許容されるエラーは置換だけであるということです。 2 つの単語の長さが同じになると、アラインメントを決定する必要はありません。 位置`i`一言で言うと位置に直接対応する必要があります`i`つまり。 したがって、それらの距離はハミング距離にすぎず、1 回の線形スキャンで計算できます。 

すべての候補を個別にチェックできるため、総当たりのアイデアは機能しますが、一般的な編集距離の実装では、発生し得ない挿入や削除が考慮されるため、不必要な作業が行われます。 位置が固定されているという観察により、すべての比較を文字ごとの直接スキャンに減らすことができます。

 ## アルゴリズムのチュートリアル

 1. スペルミスの単語を読みます`s`そしてその長さ`L`。 正確に一致する候補のみが含まれるため、この長さは役に立ちます。`L`文字が有効になる可能性があります。 
2. 辞書の各単語を指定された順序で読みます。 長さがそうでない場合は、`L`、スキップしてください。 そんな言葉は得られない`s`置換のみを使用します。 
3.長さの候補の場合`L`、からすべての位置をスキャンします`0`を通して`L - 1`と異なる文字が何文字あるか数えます`s`。 各位置は対応する位置と強制的に一致するため、このカウントは正確に必要な距離です。 
4. これまでに確認された最小距離の最初の候補を維持します。 比較は厳密に行う必要があります`<`、 ない`<=`。 新しい距離が現在の最適距離と等しい場合、以前の辞書エントリが答えのままでなければなりません。 
5. すべての候補が処理された後、保存されている最良の単語を出力します。 少なくとも 1 つの辞書単語が同じ長さであることが保証されるということは、答えが常に存在することを意味します。 

### なぜ効果があるのか

 不変条件は、最初の処理後の`k`辞書の項目、`best_word`からの最小置換距離を持つエントリの中で最も古い単語です。`s`。 すべての有効な候補は次と同じ長さになります。`s`したがって、その距離は、スキャンによって計算された不一致位置の数と正確に一致します。 候補の距離が厳密に小さい場合、現在の答えを置き換えると不変式が保持されます。 距離が等しい場合、現在の答えを変更しないままにすると、最も早い出現要件が維持されます。 すべての辞書エントリが処理されると、不変式が辞書全体をカバーするため、保存された単語はまさに必要な答えとなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    n = int(input())

    length = len(s)
    best_word = None
    best_dist = length + 1

    for _ in range(n):
        word = input().strip()

        if len(word) != length:
            continue

        dist = 0
        for a, b in zip(s, word):
            if a != b:
                dist += 1

        if dist < best_dist:
            best_dist = dist
            best_word = word

    print(best_word)

if __name__ == "__main__":
    solve()
```最初の 2 つの読み取りにより、スペルが間違っている単語と辞書エントリの数が取得されます。 すべての候補が正確にその長さを持つ必要があるため、その長さを一度保存​​します。 

長さのチェックは文字の比較の前に行われます。 これは論理的に必要であり、互換性のない単語を比較するよりもわずかにコストがかかります。 置換によって長さを変更することはできないため、そのような候補が答えになることはありません。 

不一致カウンタは、すべての候補について 0 から始まります。`zip(s, word)`これは、まさに置換のみのエラー モデルによって課される対応関係です。 動的プログラミングやその他の調整機構は必要ありません。`best_dist`から始まります`length + 1`、すべての有効な距離よりも大きな値。 これにより、最初の有効な候補に特別なケースを適用する必要がなくなります。 候補の距離が小さくなると、それが現在の答えになります。 

アップデートで使用されるのは、`dist < best_dist`。 使用する`<=`前の候補を同じ品質の後の候補で置き換えることにより、辞書の順序の同順位ルールが破られます。 

Python の整数はオーバーフローせず、可能な最大距離は語長のみです。 このアルゴリズムは、現在読み取られている文字列とは別に、一定の補助スペースのみを使用します。
