 ## 解決策
 ## 問題の理解

 二等辺三角形の頂点を表す、平面内に正確に 3 つの点が与えられます。 3 つの入力行は任意の順序で表示できます。 課題は、三角形が指す方向、つまり、等しい底辺の中点から反対側の頂点に向かう対称軸の方向を決定することです。 

例えばポイントの場合`(-1, 0)`、`(0, 1)`、 そして`(-2, 2)`、等しい辺は次の位置で交わります。`(-2, 2)`。 他の 2 点の中点は、`(-0.5, 0.5)`、したがって、対称軸は次の方向を指します。`( -1.5, 1.5 )`、方向性があります`135`正の X 軸からの度。 したがって、必要な答えは、`135.0`。 

座標は浮動小数点値であり、このステートメントでは意味のある大きな値は得られません。`n`または繰り返しのテストケースパラメータ。 常に正確に 3 つの点が存在するため、考えられる頂点のすべての選択を調べるアプローチでも、一定数の算術演算のみが実行されます。 の可能性はありません`O(n^2)`または同様の漸近問題がここにあります。 主な困難は、頂点の幾何学的識別と、によって返される角度の正しい処理です。`atan2`。 

最初のエッジ ケースは、対称軸が正の x 軸に正確に沿っている三角形です。 例えば、```
0 02 01 1
```頂点は`(1, 1)`、基本中点は`(1, 0)`、方向は`(0, 1)`したがって、正しい出力は次のようになります。`90.0`。 頂点から底辺に向かうベクトルの角度を測定する不用意な実装では、次のような出力が出力されます。`270.0`、必要な方向を反転します。 

2 番目のエッジ ケースは、方向に負の y 成分がある場合に発生します。 例えば、```
0 02 01 -1
```方向は下向きなので、数学的な角度は次のようになります。`-90`によって直接返されたときの度`atan2`。 必要な表現は次のとおりです`0`そして`360`したがって、正しい出力は次のようになります。`270.0`。 負の角度を正規化することを忘れると、間違った結果が生じます。 

3 番目のエッジ ケースは、入力ポイントが任意の順序で提示される場合です。 例えば、```
-2 2-1 00 1
```答えはまだです`135.0`。 最初の点が頂点であると想定する実装では、誤って間違った対称軸が使用されてしまいます。 

退化したケースには別途注意が必要です。 正三角形には、3 つの辺がすべて等しいため、頂点として 3 つの選択肢があり、固有の指す方向がありません。 問題の意図した二等辺三角形の入力は、結果的に一意の頂点を提供する必要があります。 以下のアルゴリズムはそのプロパティに依存しています。 

## アプローチ

 直接的なアプローチは、3 つのポイントのそれぞれを頂点として試してみることです。 選んだポイントに対して`A`、残りの2点`B`そして`C`～から等距離でなければなりません`A`もし`A`二等辺三角形の頂点です。 二乗距離を比較できます`AB²`そして`AC²`、平方根を完全に避けます。 正しい頂点が見つかると、その中点が`BC`対称軸上の点と、その中点から に向かうベクトルを与えます。`A`要求された方向を示します。 

この総当たりアプローチは、可能な頂点が 3 つしかないため、すでに定数時間です。 最悪のケースでは、3 つの候補すべてを検査し、最大 6 回の距離比較と一定量のジオメトリに対して、それぞれについて 2 つの二乗距離計算を実行します。 実用的な性能上の問題はありません。 

有益な幾何学的観察は、頂点が他の 2 つの頂点までの距離が等しいことによって完全に特徴づけられるということです。 三角形の角度を計算したり、どちらの辺が最初に底辺であるかを決定したりする必要はありません。 等しい側の端点がわかれば、その端点と反対側の中点を通る線がまさに三角形の対称軸になります。 

もう少しすっきりした定式化は、3 つの平方辺の長さをすべて計算することです。 非正辺二等辺三角形では、そのうちの 2 つは等しく、残りの辺が底辺になります。 もし`AB = AC`、 それから`A`頂点です。 もし`AB = BC`、 それから`B`頂点です。 さもないと`C`頂点です。 浮動小数点入力の場合、比較では正確な 2 値の等価性を要求するのではなく、小さな相対許容誤差を使用する必要があります。 

ブルートフォース手法と幾何学手法では、入力自体に 3 つの点しか含まれていないため、漸近的な複雑さは同じになります。 2 番目の定式化は、幾何学的不変量を明示的にし、置換に対する不必要な検索を回避するため、推奨されます。

 ## アルゴリズムのチュートリアル

 1. 3つのポイントを読む`A`、`B`、 そして`C`。 それらの順序には幾何学的な意味はないので、頂点を自分で決定する必要があります。 
2. 3 つの平方辺の長さを計算します。`AB²`、`AC²`、 そして`BC²`。 正の距離が等しいことは距離の 2 乗が等しいことと等価であり、平方根を避けるとより単純で安定した演算が得られるため、距離の 2 乗で十分です。 
3. どの点が頂点であるかを決定します。 もし`AB²`そして`AC²`等しい場合、`A`他の 2 点から等距離にあり、頂点です。 それ以外の場合は、`AB²`そして`BC²`等しい、`B`頂点です。 残りのケースは`C`頂点。 
4. しましょう`A`識別された頂点となり、`B`、`C`がベースエンドポイントになります。 底の中点を次のように計算します。`M = ((Bx + Cx) / 2, (By + Cy) / 2)`。 

二等辺三角形は底辺の垂直二等分線の周りで対称であるため、対称軸は頂点とこの中点を通過します。 
5. ベースの中点から頂点に向かう方向ベクトルを構築します。`v = A - M`。 

この問題では三角形がどちらの方向を指しているのかが問われるため、方向は頂点から離れるのではなく、頂点に向かう必要があります。 
6. 使用する`atan2(vy, vx)`正の X 軸からの符号付き角度を取得します。 ラジアンから度に変換します。 
7. 角度が負の場合は、`360`。 結果の値は必要な値に含まれます。`[0, 360)`範囲。 

### なぜ効果があるのか

 二等辺三角形の頂点は、等しい長さの辺によって他の 2 つの頂点に接続されている頂点です。 したがって、3 つの正方形の辺の長さを比較すると、すべての有効な非等辺入力の頂点を一意に識別できます。 頂点と底辺がわかれば、底辺の中点は底辺の垂直二等分線上にあり、これは三角形の対称軸でもあります。 したがって、その中点から頂点までのベクトルは、要求された方向を正確に持ちます。 ついに、`atan2`正の x 軸を基準にしてそのベクトルを測定し、追加します`360`負の結果の場合は、方向を変更せずに、符号付き表現を必要な正の表現に変換します。 

## Python ソリューション```python
Pythonimport sysimport math
input = sys.stdin.readline

def equal(a, b):    return math.isclose(a, b, rel_tol=1e-9, abs_tol=1e-9)

def solve():    points = [tuple(map(float, input().split())) for _ in range(3)]    A, B, C = points
    def dist2(P, Q):        dx = P[0] - Q[0]        dy = P[1] - Q[1]        return dx * dx + dy * dy
    ab = dist2(A, B)    ac = dist2(A, C)    bc = dist2(B, C)
    if equal(ab, ac):        apex = A        base1 = B        base2 = C    elif equal(ab, bc):        apex = B        base1 = A        base2 = C    else:        apex = C        base1 = A        base2 = B
    mid_x = (base1[0] + base2[0]) / 2.0    mid_y = (base1[1] + base2[1]) / 2.0
    vx = apex[0] - mid_x    vy = apex[1] - mid_y
    angle = math.degrees(math.atan2(vy, vx))
    if angle < 0:        angle += 360.0
    print(angle)

if __name__ == "__main__":    solve()
```の`dist2`関数は二乗ユークリッド距離を計算します。 等しい辺を特定する場合は等しいことのみが重要であるため、平方根を求めると情報を追加せずに作業が追加されます。 

の`equal`ヘルパーが使用する`math.isclose`座標は浮動小数点値として読み取られるためです。 次のような直接比較`ab == ac`数学的に等しい量がわずかに異なる浮動小数点表現を取得すると、失敗する可能性があります。 

3 つの比較により、考えられる 3 つの頂点がエンコードされます。 もし`AB = AC`、に起こる両側`A`等しいです。 もし`AB = BC`、2 つの等しい辺が次の位置で交わります。`B`。 どちらの条件も当てはまらない場合、等しい辺は次の点で一致する必要があります。`C`。 

中点は、方向ベクトルを構築する前に計算されます。 減算の順序は意図的に行われます。`apex - midpoint`底辺の中心から三角形の先端に向かって指します。 減算を逆にすると、答えは正確に回転します`180`度。`atan2`通常の垂直ベクトルを含む 4 つの象限すべてを処理します。`atan(y / x)`ゼロで割ることになります。 結果はラジアンと間隔で表されます`[-180, 180]`度に変換後。 追加`360`値が負の場合のみ、必要な正の範囲にマップされます。 

Python の整数はオーバーフローしませんが、いずれにしても座標は浮動小数点値であるため、すべての幾何学的計算では当然 Python の浮動小数点表現が使用されます。

 ## 特殊なケース

 水平方向が 0 度の場合、```
0 00 21 1
```等しい辺が次の位置で交わる`(1, 1)`。 基本の中点は`(0, 1)`したがって、方向ベクトルは次のようになります。`(1, 0)`。`atan2(0, 1)`返品`0`、そしてアルゴリズムは出力します`0.0`。 正規化では負の角度のみが変更されるため、ゼロ自体には特別なケースは必要ありません。 

下向きの場合は、```
0 02 01 -1
```等しい辺が次の位置で交わる`(1, -1)`。 基本の中点は`(1, 0)`、生産`(0, -1)`。`atan2(-1, 0)`与える`-90`度。 アルゴリズムは追加します`360`、生産`270.0`。 これは、必要な正の角度範囲を忘れた実装が公開される可能性が最も高い境界ケースです。 

任意発注の場合は、```
-1 0-2 20 1
```等しい側は依然として次の時点で一致します`(-2, 2)`たとえその点が入力の途中であっても。 からの二乗距離`(-2, 2)`他の 2 点は両方とも`5`, したがって、2 番目の比較により、それが頂点であることが特定されます。 結果のベクトルは次のようになります。`(-1.5, 1.5)`、与える`135.0`。
