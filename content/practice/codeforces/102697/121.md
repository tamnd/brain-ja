 ## 解決策
 ## 問題の理解

 このタスクは、直接的な 3 次元幾何学計算です。 宇宙船には 1 つの固定位置があります`(X, Y, Z)`、そしてレーダーレポート`n`外国人の立場。 すべてのエイリアンについて、宇宙船からのユークリッド距離を計算し、エイリアンに指定されたのと同じ順序で距離を出力する必要があります。 

ある宇宙人にとって、`(x, y, z)`、3 つの座標の違いは次のとおりです。`x - X`、`y - Y`、 そして`z - Z`。 それらを二乗すると符号が削除され、3 つの二乗の差を加算すると二乗距離が得られ、平方根を取ると実際の距離が得られます。`distance = sqrt((x-X)^2 + (y-Y)^2 + (z-Z)^2)`。 

公式声明では、制限時間は 1 秒、メモリは 256 MB と規定されています。 座標や`n`したがって、最も安全な解釈は、エイリアンの数に比例してスケールするようにソリューションを設計することです。 出力自体にはエイリアンごとに 1 つの値が含まれるため、エイリアンごとに一定の作業を費やすアルゴリズムが漸近的に最適になります。 二次アルゴリズムは次のように使用できなくなります。`n`成長しながら、`O(n)`ソリューションは、入力ポイントごとに 1 つの固定サイズの計算のみを実行します。 Python の整数は中間二乗差分でのオーバーフローも回避しますが、十分に広い整数型を持つ言語では通常の座標境界によりオーバーフローは問題になりません。 

実装が静かに失敗する可能性がある小さなケースがいくつかあります。 エイリアンがまさに宇宙船にいるとき、答えはゼロでなければなりません。 例えば、```
1 2 3
1
1 2 3
```生成する```
0.0
```平方根を忘れた不注意な実装では、次のように出力されます。`0`これは数値的には同じですが、必要な 10 進数の出力形式に従っていません。 

負の座標の差も正しく二乗する必要があります。 例えば、```
2 4 6
1
-2 -4 -6
```生成する```
14.966629547095765
```二乗する前に絶対値を取得すると同じ結果が得られますが、差分の生の合計のみを使用すると、正と負の座標が誤ってキャンセルされてしまいます。 

エイリアンの順序は重要です。 例えば、```
0 0 0
2
3 0 0
0 4 0
```生成する```
3.0
4.0
```エイリアンを処理する前にソートする実装では、必要な出力順序が変更されます。 

## アプローチ

 最も直接的なアプローチはすでに最適なものです。 すべてのエイリアンについて、3 つの座標の差を計算し、それらを 2 乗し、3 つの値を加算し、平方根をとり、結果を出力します。 これは正しいです。なぜなら、この式は 3 次元におけるユークリッド距離の定義とまったく同じであるため、各エイリアンは他のエイリアンとは独立して処理できるからです。 

あれば`n`エイリアンの場合、各エイリアンは 3 回の減算、3 回の乗算、2 回の加算、および 1 回の平方根演算を必要とします。 入力コストと出力コスト、つまりエイリアンごとに 9 回の固定算術演算を無視するか、`9n`入力全体に対するこのような操作。 平方根の正確なマシンレベルのコストは実装によって異なりますが、それでも一定です。`n`。 

より精巧なブルートフォース解釈では、すべてのエイリアンを他のすべての点と比較したり、幾何学的関係を検索したり、距離を繰り返し再計算したりすることが考えられます。 要求された距離は宇宙船と現在のエイリアンのみに依存するため、ここではどれも役に立ちません。 発見する必要のあるエイリアン間の相互作用はありません。 

重要な観察は、問題が完全に分離可能であるということです。 宇宙船の座標がわかれば、エイリアンの答えもわかる`i`宇宙人について何も知らなくても計算できる`j`。 つまり、動的プログラミングの状態、グラフの走査、並べ替え、または幾何学的データ構造を維持する必要がありません。 エイリアンごとに定数の式を 1 回実行するだけです。 

出力要件には下限も与えられます。`Omega(n)`、プログラムは生成する必要があるため、`n`別々の回答。 その結果、`O(n)`時間は漸近的に最適になります。 したがって、最適な解決策は、総当たりベースラインと同じ単純な計算ですが、不必要なペアワイズ作業が導入されないという決定的な違いがあります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) は、エイリアンごとに 1 つの距離計算として実装される | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.宇宙船の座標を読み取る`X`、`Y`、 そして`Z`。 これらの座標は、距離を計算するたびに変更されません。 
2.読む`n`、検出された宇宙人の数。 これらのそれぞれに対して正確に 1 つの出力値が必要です。`n`ポジション。 
3. 各エイリアンについて、その座標を読み取ります`(x, y, z)`。 コンピューティング`dx = x - X`、`dy = y - Y`、 そして`dz = z - Z`。 次の操作で差が 2 乗されるため、差を符号付きのままにしても問題ありません。 
4. コンピューティング`dx * dx + dy * dy + dz * dz`。 これはユークリッド距離の 2 乗であるため、最終平方根の前の幾何学的近似を回避します。 
5. その合計の平方根を求め、すぐに出力します。 すべての答えは独立しているため、以前のエイリアンやその距離を保存する必要はありません。 
6. すべての計算を繰り返します`n`エイリアンは、入力順序を出力内で保持します。 

### なぜ効果があるのか

 すべてのエイリアンについて、アルゴリズムはエイリアンと宇宙船の間の 3 つの座標の違いを正確に計算します。 これらの差を 2 乗して加算すると、ユークリッド距離の 2 乗が求められ、平方根を取るとユークリッド距離そのものが求められます。 計算はエイリアンごとに独立して実行され、エイリアンは入力順に処理されるため、出力されるすべての値は、必要な位置での必要な距離になります。 他のエイリアンからの情報は結果に影響を与えることができないため、ポイントを個別に処理しても条件を見逃したり、別の有効な解釈を生成したりすることはありません。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    X, Y, Z = map(int, input().split())
    n = int(input())

    out = []

    for _ in range(n):
        x, y, z = map(int, input().split())

        dx = x - X
        dy = y - Y
        dz = z - Z

        distance = math.sqrt(dx * dx + dy * dy + dz * dz)
        out.append(str(distance))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```宇宙船は決して移動しないため、最初の入力行は一度保存されます。 次の行は、必要な反復回数を示します。 

コードはエイリアンごとに 3 つの差異を個別に計算します。 これにより、式の検証が容易になり、宇宙船の座標と宇宙人の座標を誤って混合することを回避できます。 

内側の表現`math.sqrt`は整数の二乗距離です。 Python の任意精度の整数により、座標が固定幅 C++ の範囲より大きい場合でも中間計算が安全になります。`int`。`math.sqrt`次に、非負の値を浮動小数点距離に変換します。 

答えは以下に蓄積されます`out`そして一緒に書きました。 これにより、エイリアンごとに個別のシステム呼び出しを行う必要がなくなります。`n`大きいです。 計算自体は、出力文字列とは別に、一定量の作業メモリのみを使用します。 

ステートメントでは丸めが不要であることが明示されているため、丸めコードはありません。 Python の浮動小数点変換は、裁判官が期待する通常の 10 進表現を生成します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | どのエイリアンも一定数の算術演算と 1 平方根を必要とします。 |
 | スペース | O(n) | 実装では、`n`文字列を書き込む前に出力してください。 |

 このアルゴリズムは、検出されたエイリアンごとに固定サイズの計算を 1 回だけ実行するため、実行時間は入力サイズに比例して増加します。 出力自体は`n`直線では、線形時間は漸近的に最適になります。 数学的な動作状態は次のとおりです。`O(1)`、実装では使用します`O(n)`出力をバッチ処理するため、メモリのみが使用されます。 メモリが極度に制限されている場合は、代わりに各回答をすぐに印刷して、補助メモリを削減することもできます。`O(1)`。 

## テストケース```python
import sys
import io
import math

def solve():
    input = sys.stdin.readline

    X, Y, Z = map(int, input().split())
    n = int(input())

    out = []

    for _ in range(n):
        x, y, z = map(int, input().split())

        dx = x - X
        dy = y - Y
        dz = z - Z

        out.append(str(math.sqrt(dx * dx + dy * dy + dz * dz)))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

), "sample 1"

## 特殊なケース

 エイリアンと宇宙船が同じ点を占める場合、入力```
1 2 3
1
1 2 3
```与える`dx = 0`、`dy = 0`、 そして`dz = 0`。 二乗距離は`0`、 それで`math.sqrt(0)`生成する`0.0`。 特別な分岐は必要なく、出力は正確に```
0.0
```負の座標は減算と二乗によって直接処理されます。 のために```
2 4 6
1
-2 -4 -6
```違いは`-4`、`-8`、 そして`-12`。 彼らの正方形は、`16`、`64`、 そして`144`、二乗距離は次のようになります。`224`。 平方根は`14.966629547095765`、したがってアルゴリズムは次のように生成します```
14.966629547095765
```1次元や2次元の差分ゼロも当然扱います。 のために```
10 20 30
1
-5 20 30
```違いは`-15`、`0`、 そして`0`。 二乗距離は`225`、与える```
15.0
```これにより、誤って座標を省略したり、ゼロの差を誤って処理したりする実装が捕捉されます。

0 4 0
