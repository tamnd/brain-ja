 ## 解決策
 ## 問題の理解

 平面内の整数座標に固定されたピンは最大 7 本あります。 これらのピンのいくつかを選択し、選択したセットの周囲にゴムバンドを引き伸ばします。 点の集合の周りのピンと張ったゴムバンドは、凸包の境界に従います。 選択したピンはすべてバンドに触れている必要があり、厳密にはバンドの内側に他のピンがあってはなりません。 バンドの上に直接置かれているピンは、バンドに触れているため無害です。 

タスクは、これら 2 つの幾何学的条件を満たす選択されたピンの数を最大化することです。 公式の入力制限は (n \le 7) のみで、制限時間は 1 秒、メモリは 256 MB です。 これは非常に小さいため、サブセットに対する指数アルゴリズムは完全に合理的です。 サブセットは最大で (2^7=128) 個あり、すべてのサブセットに対して数回 (O(n^2)) の幾何学的チェックを実行することさえ無視できます。 

主なエッジ ケースは、同一線上にある点、または厳密に凸包の内側にある点から発生します。 例えば、```
3
0 0
1 0
2 0
```答えがあります`3`。 3 つのピンはすべて、縮退した凸包の境界上にあるため、バンドはすべてのピンに触れることができます。 

より危険なケースは、内部ポイントです。```
5
0 0
4 0
2 2
2 -2
2 0
```それ以外の4つのポイント`(2, 0)`外側のダイヤモンドを形成し、`(2, 0)`厳密にその中にあります。 内側のピンがバンドに触れないため、5 つのピンすべてを選択することは不可能です。 正しい答えは、`4`。 

船体のエッジ上の点を内部の点と混同しないでください。 例えば、```
6
0 0
2 0
4 0
2 2
2 -2
3 -1
```答えがあります`5`。 ポイント`(3, -1)`～の端にある`(4, 0)`に`(2, -2)`, なので輪ゴムが接触します。 標準の凸包実装の頂点以外のすべてを内部点として扱うと、この構成が誤って拒否されます。 

## アプローチ

 入力が小さいため、直接総当たりはすでに正しいアプローチです。 ピンのすべてのサブセットを列挙し、これがラバー バンドを伸ばすセットであるとみなして、その凸包を計算し、そのサブセットが有効かどうかを確認できます。 

サブセットが機能するには、選択されたすべての点がその凸包の境界上になければなりません。 そうしないと、選択した点は厳密にラバー バンドの内側にあり、タッチされなくなります。 選択されなかったすべてのピンも検査します。 このようなピンが厳密に凸包の内側にある場合、ラバーバンドはピンに触れずにピンを囲むため、サブセットは無効になります。 明示的に選択していない場合でも、境界上のピンは許可されます。 

ブルート フォース検索では、(2^n) 個のサブセットが考慮されます。 各サブセットについて、ハルは (O(n\log n)) で構築でき、(n\le7) であるため、より単純な (O(n^2)) 幾何学的チェックでも十分に高速です。 最悪の場合でも、プリミティブ方向テストは数千回しか実行されません。 

有益な観察は、輪ゴムの無限に多くの可能な形状を探索する必要がないということです。 選択したピンが固定されると、ピンと張ったバンドは凸包によって完全に特徴付けられます。 ジオメトリは、元の物理的記述を 2 つの有限チェックに減らします。選択された点はハルの境界上にある必要があり、選択されていない点は厳密にハルの内側にあってはなりません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース | (O(2^n n^2)) | (O(n)) | 承認済み |
 | 凸包チェックによる最適なサブセット列挙 | (O(2^n n^2)) | (O(n)) | 承認済み |

 この問題に関しては、2 行目が事実上意図された解決策となります。 (n) は最大 7 であるため、より複雑な漸近手法は必要ありません。 

## アルゴリズムのチュートリアル

 1. すべてのピンの座標を読み取り、各ピンをそのインデックスとその座標のペアで表します。 2 つの異なるピンが同じ座標を占有する可能性があるため、インデックスを維持することが重要です。 
2. (n) 個のピンの空ではないサブセットをすべて列挙します。 (n\le7) なので、検査するサブセットは最大 127 個です。 
3. 現在のサブセットに属する点を抽出し、それらの凸包を計算します。 モノトーン チェーン ハルを使用しますが、ハルのエッジ上の同一線上の点を破棄せずに保持します。 エッジ上の点は物理的にラバーバンドに触れているため、境界点としてカウントする必要があります。 
4. 選択したすべての点を船体の境界に対してチェックします。 選択した点が 1 つでも厳密にハルの内側にある場合、このサブセットは拒否されます。 1 点のサブセットの場合、点自体が境界になります。 2 つ以上の同一線上にある点の場合、ハルはセグメントとなり、そのセグメント上のすべての点は境界上にあります。 
5. 選択されていないピンをすべてチェックします。 厳密に凸包の内側にある場合は、サブセットを拒否します。 外側にある場合、または船体の境界上にある場合は条件に違反しません。 
6. 両方のチェックに合格した場合は、サブセットのサイズで回答を更新します。 サブセットは独立しているため、有効な最大サイズを維持すると、必要な最大値が直接得られます。 

### なぜ効果があるのか

 固定の選択セット (S) の場合、ピンと張ったラバーバンドが (\operatorname{conv}(S)) の境界になります。 選択した点は、その境界上にあるときに正確にタッチされます。 選択されていないピンは、厳密に凸包の内側にある場合、バンドが接触せずにピンを取り囲むため、条件に違反します。 アルゴリズムは、選択されたすべての可能なセットに対して、これら 2 つの必要かつ十分なプロパティを正確にチェックします。 すべての候補サブセットが検査されるため、受け入れられた最大のサブセットが最適な答えになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    """Return the hull boundary as an ordered list.

    Collinear points on an edge are kept.
    Duplicate coordinates are removed for geometric construction.
    """
    points = sorted(set(points))

    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) < 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) < 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def on_segment(a, b, p):
    return (
        cross(a, b, p) == 0
        and min(a[0], b[0]) <= p[0] <= max(a[0], b[0])
        and min(a[1], b[1]) <= p[1] <= max(a[1], b[1])
    )

def on_boundary(hull, p):
    if len(hull) == 0:
        return False

    if len(hull) == 1:
        return p == hull[0]

    for i in range(len(hull)):
        if on_segment(hull[i], hull[(i + 1) % len(hull)], p):
            return True

    return False

def strictly_inside(hull, p):
    """Whether p lies strictly inside the polygonal hull."""
    if len(hull) < 3:
        return False

    if on_boundary(hull, p):
        return False

    sign = 0
    m = len(hull)

    for i in range(m):
        c = cross(hull[i], hull[(i + 1) % m], p)

        if c == 0:
            return False

        if sign == 0:
            sign = 1 if c > 0 else -1
        elif (c > 0 and sign < 0) or (c < 0 and sign > 0):
            return False

    return True

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    answer = 1

    for mask in range(1, 1 << n):
        chosen = [points[i] for i in range(n) if mask & (1 << i)]

        if len(chosen) <= answer:
            continue

        hull = convex_hull(chosen)

        # Every selected pin must be on the rubber band's boundary.
        valid = True
        for p in chosen:
            if not on_boundary(hull, p):
                valid = False
                break

        if not valid:
            continue

        # An unselected pin may be outside or on the band,
        # but never strictly inside it.
        for i, p in enumerate(points):
            if mask & (1 << i):
                continue

            if strictly_inside(hull, p):
                valid = False
                break

        if valid:
            answer = len(chosen)

    print(answer)

if __name__ == "__main__":
    solve()
```の`cross`関数は、3 つの点で形成される三角形の符号付き面積を計算します。 その符号は、3 番目の点が有向エッジの左側にあるか右側にあるかを示し、ゼロは 3 つの点が同一線上にあることを意味します。 

船体構築では座標をソートし、下部チェーンと上部チェーンを構築します。 通常のモノトーンチェーンの実装では、多くの場合、`<= 0`ポイントを削除する場合、同一線上にあるポイントは破棄されます。 ここでは、ゴムバンドの直線部分にあるピンがまだ触れているため、これは間違っています。 したがって、実装ではターンが厳密に時計回りの場合にのみポイントが削除されます。 

の`on_boundary`この関数は、点がハル頂点の 1 つであるかどうかを尋ねるのではなく、実際のハル セグメントを意図的にチェックします。 これにより、同一線上にあるピンが正しく処理され、縮退した 1 点および 2 点のケースも処理されます。 

の`strictly_inside`関数は 2 次元のハルに対してのみ意味を持ちます。 セグメントまたは単一点の場合、正の領域の内部がないため、false を返します。 ポリゴンの場合、点がすべての有向ハル エッジの厳密に同じ側にある場合、その点は厳密に内側になります。 境界点は内部テストから明示的に拒否されます。 

サブセット ループは、現在の答え以下のサブセットをスキップします。 このようなサブセットでは結果が改善されないため、幾何学的チェックを実行する理由はありません。 すべての算術演算では Python 整数が使用されるため、座標の大きさに関係なくオーバーフローの問題は発生しません。
