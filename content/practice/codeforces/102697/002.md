 ## 解決策
 ## 問題の理解

 このタスクは、指定された 2 つの正の整数を取得してそれらを乗算し、その結果を 3 で乗算することによって生成される値を計算することです。 入力には 2 つの因子が個別に含まれており、出力はこの 3 つの積を表す 1 つの整数です。 

2 つの数値の値は小さく、それぞれ最大 2000 です。これは、直接の算術演算でも十分すぎることを意味します。 計算全体が定数時間で行われるため、高度なデータ構造やアルゴリズムは必要ありません。 主な関心事は、単純に乗算を正しく実行し、結果を出力することです。 

いくつかの特殊なケースでは、不注意な実装で間違いが発生する可能性があります。 両方の数値が可能な限り最小の値である場合でも、プログラムは乗算を通常どおり処理する必要があります。 

例えば：```
Input:
1
1

Output:
3
```最後の 3 の乗算を忘れたソリューションでは、誤って出力されます。`1`。 

もう 1 つのよくある間違いは、操作の順序を誤って変更することです。 表現は次のようにする必要があります`a * b * 3`、これは以下と同等です`(a * b) * 3`。```
Input:
2000
2000

Output:
12000000
```一部の言語では、答えは小さな整数型に収まらないため、実装では積を保持できる整数型を使用する必要があります。 Python の整数はこれを自動的に処理します。 

## アプローチ

 この問題を強引に解釈すると、数値間のより複雑な関係を探すことになりますが、発見できる隠された構造はありません。 必要な値は算術式によって直接定義されます。 さまざまな組み合わせを試したり、乗算をシミュレートしたりする強引なアプローチでは、同じ結果が得られながらも、不必要な作業が追加されるだけです。 

重要な観察は、この問題では 1 つの決定論的な計算が必要であるということです。 2 つの入力値が読み取られると、答えは完全に決定されます。 ソリューション全体は、2 つの整数を読み取り、それらを乗算し、3 を乗算して、結果を出力するだけです。 

総当り的なアプローチは不要ですが、直接算術解は一定時間内に完了します。

 ## アルゴリズムのチュートリアル

 1. 入力から 2 つの整数を読み取ります。 各値は製品の 1 つの要素を表します。 
2. 2 つの値を掛け合わせます。 これにより、2 つの数値の正規積が求められます。 
3. 結果を 3 で乗算し、出力します。 追加の乗算が問題の要件全体です。 

なぜ効果があるのか:

 このアルゴリズムは、必要な出力の数学的定義に正確に従います。 入力値の各ペアに対して考えられる答えは 1 つだけであるため、式を直接評価してもケースを見逃すことはありません。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    print(a * b * 3)

if __name__ == "__main__":
    solve()
```プログラムは 2 行を整数として読み取り、それらを`a`そして`b`。 乗算は問題の式と同じ順序で実行されるため、誤って 3 の因数を省略することがなくなります。 

Python の整数実装は任意の精度をサポートしているため、入力が最大値であってもオーバーフローの心配はありません。 

入力には 2 つの数値しか含まれていないため、このソリューションには配列、ループ、または追加のメモリは必要ありません。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    a = int(sys.stdin.readline())
    b = int(sys.stdin.readline())
    print(a * b * 3)

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

# provided sample
assert run("3\n5\n") == "45\n", "sample 1"
