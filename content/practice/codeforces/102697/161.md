 ## 解決策
 ## 問題の理解

 この問題では、散髪に来た数人の顧客について説明しています。 お客様ごとに現在の髪の長さとカット後の希望の長さを把握しています。 現在の長さを要求された長さに変更するには、何インチの髪を除去する必要があるかを計算する必要があります。 

現在の長さのクライアントの場合`a`そして希望の長さ`b`、切断`x`インチの葉`a - x`インチ。 私たちが欲しいのは`a - x = b`。 

を解決する`x`与える`x = a - b`。 

したがって、各テスト ケースは完全に独立しており、クライアント間の対話はありません。 公式入力には次のものが含まれます`n`テスト ケースの後に、クライアントごとに 1 組の整数が続きます。 公式声明では整数値の明示的な上限は示されていませんが、すべてのテスト ケースで必要な減算は 1 回だけであるため、値のサイズはアルゴリズムの複雑さに影響しません。 Python の整数は固定幅のオーバーフローも回避します。 

主なエッジケースは、クライアントがすでに要求された長さを正確に持っている場合です。 例えば、```
1
10 10
```出力が必要です```
0
```すべての顧客がプラスの削減額を必要としていると想定する不用意な解決策は、誤った生産を引き起こす可能性があります。`1`そうでない場合は、ゼロの場合の処理​​に失敗します。 

もう 1 つの境界ケースは、テスト ケースが 1 つだけ存在する場合です。 例えば、```
1
1 0
```出力が必要です```
1
```複数の場合に特別な初期化は必要ないため、同じ減算でこれを正しく処理できます。 

このステートメントでは、要求された長さが現在の長さよりも大きい場合に何が起こるかについては明示的に述べられていません。 このような状況は、髪を切ることによっては達成できません。なぜなら、髪を切ることは長さを短くすることしかできないからです。 数学的な量`current - desired`その場合はマイナスになります。 意図した問題のコンテキストは、要求された最終長さが切断によって達成可能であるため、ソリューションでは必要な差を直接計算します。 

元の問題には 1 秒の時間制限と 256 MB のメモリ制限があります。 各テスト ケースは一定の作業のみを必要とするため、非常に多数のテスト ケースであっても、入力ペアの数に対して線形時間で処理されます。 並べ替え、動的プログラミング、グラフ アルゴリズム、またはその他のデータ構造を使用する理由はありません。 

## アプローチ

 ブルートフォース手法では、ヘアカットを一度に 1 インチずつシミュレートしようとする場合があります。 たとえば、クライアントの髪の長さが 1,000,000 インチで、希望の長さが 1 インチの場合、そのようなシミュレーションでは 999,999 回の個別のカット操作が実行されることになります。 より一般的には、削除する量が`d`、シミュレーションが実行されます`d`したがって、実行時間はテスト ケースの数ではなく数値に依存します。 入力値が大きいと、不必要に遅くなる可能性があります。 

希望の長さに達するまで、シミュレートされたカットごとに現在の長さが正確に 1 だけ減少するため、ブルート フォースが機能します。 ただし、この問題では、実際にはこれらの中間状態をシミュレートする必要はありません。 合計量を削除するだけで済みます。 

重要な観察は、除去された量が最初の長さと最終の長さの差に正確であるということです。 初期の長さが`a`そして最終的な長さは`b`、その後削除します`a - b`インチは長さを直接変更します`a`に`b`。 したがって、プロセス全体を 1 つの減算で置き換えることができます。 

ブルート フォースは最終的に同じ差を計算するため機能しますが、差が大きい場合は失敗します。 最初と最後の長さのみが重要であるという観察により、各テスト ケースを定数時間の演算に減らすことができます。

 | 最適 | ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 番号を読み取ります`n`クライアントの。 あるクライアントのヘアカットは他のクライアントには影響を与えないため、私たちは各クライアントを個別に処理します。 
2. すべてのクライアントについて、現在の長さを読み取ります。`a`要求された最終長さ`b`。 答えを決定するために必要な値はこれら 2 つだけです。 
3. コンピューティング`a - b`。 これは、方程式が次のとおりであるため、削除する必要がある量です。`a - removed = b`独自のソリューションを持っています`removed = a - b`。 
4. 計算された差をすぐに出力します。 以前のテスト ケースを保存したり、グローバル状態を維持したりする必要はありません。 

### なぜ効果があるのか

 すべてのクライアントに対して、`x`髪のカット量になります。 カット後の髪の長さは、`a - x`、必要な最終的な長さは次のとおりです。`b`。 したがって、有効なヘアカットは次の条件を満たす必要があります。`a - x = b`。 並べ替えると`x = a - b`したがって、アルゴリズムはすべてのテスト ケースに必要な量を正確に出力します。 ケースは独立しているため、それらを 1 つずつ処理すると、必要なすべての答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ans = []

    for _ in range(n):
        current, desired = map(int, input().split())
        ans.append(str(current - desired))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初の行は独立したクライアントの数として読み取られます。 その後、ループは入力ペアごとに 1 回だけ実行されます。 

ループ内では、`current - desired`アルゴリズムのウォークスルーで導出された方程式を直接実装します。 回答は文字列に変換されて収集されるため、プログラムはそれらをすべて一度に書き込むことができます。 

この問題では、訪問した中間の長さの数ではなく、脱毛する毛の量が求められるため、オフバイ 1 の問題はありません。 たとえば、14 から 8 に変更するには、正確に次のものが必要です。`14 - 8 = 6`5インチや7インチではありません。 

Python の整数表現は、整数オーバーフローの懸念がないことも意味します。 プログラムは一度に少数の変数のみを使用するため、出力リストを除いて補助メモリは一定のままです。

        return sys.stdout.getvalue()
    finally:

        sys.stdout = old_stdout
