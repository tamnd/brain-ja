 ## 問題の理解

 施設は次のように表されます。`n × m`グリッド。 を含むセル`X`は壁ですが、`.`歩いて行ける空きスペースであり、`P`航空機を含む歩行可能なセルです。 移動は水平または垂直に隣接するセル間でのみ許可されるため、斜めの移動は禁止されます。 部屋はまさに、壁ではなく細胞がつながった領域です。 チームが選択できる部屋は 1 つだけなので、答えは部屋の最大数になります。`P`歩行可能なセルの任意の単一の接続コンポーネントに属するセル。 公開された声明では、航空機のセル自体が通過できることが確認されており、これが重要な点です。`P`のように振る舞う`.`接続目的のため。 

この声明では、明示的な境界を公開していません。`n`そして`m`、しかしグリッドは正確に`n × m`セル、制限時間は 256 MB のメモリで 1 秒です。 したがって、ソリューションでは、グリッド全体を繰り返しスキャンすることを回避する必要があります。 セル上の直線または直線に近いパスが自然なターゲットです。 アン`O((nm)^2)`グリッドに多くの歩行可能なセルが含まれるとすぐにソリューションが高価になる可能性があります。`O(nm)`トラバーサルは各セルを一定の回数だけ処理します。 

最初のエッジケースは単一の航空機です。 入力用```

最後に、境界上のセルは内部のセルとまったく同じ処理が必要です。 のために```

## アプローチ

 直接的ではあるが非効率な解決策は、航空機のすべてのセルからグラフ検索を開始することです。 それぞれについて`P`、到達可能なすべての歩行可能なセルを通じて BFS または DFS を実行し、遭遇した航空機の数をカウントできます。 これは正しいです。その開始航空機から到達可能なすべての部屋はまさにその接続コンポーネントであるため、検索によりその部屋にある航空機の数が得られます。 

問題は、多くの開始航空機が同じ大きな部屋に所属できることです。 グリッドに`N = nm`セルであり、そのほとんどすべてが歩行可能な航空機を含むセルまたは空のセルであり、1 回の検索でタッチできる可能性があります。`Θ(N)`細胞が存在する可能性があります`Θ(N)`出発する飛行機。 結果として最悪のケースは、`Θ(N²) = Θ((nm)²)`携帯電話の訪問。 10,000 個のセルを含むグリッドでは、隣接チェックを考慮する前に、すでに約 1 億回のセル アクセスが発生する可能性があります。 

総当たりアプローチは、トラバースによって 1 つの部屋が正しく識別されるため機能しますが、同じ接続されたコンポーネントの問題を繰り返し解決します。 重要な観察は、接続されたコンポーネントがすべての歩行可能なセルを分割していることです。 1 回の検索で部屋を完全に探索すると、その部屋内のすべてのセルがすでに分類されているため、再度探索する必要はありません。 

グリッドを 1 回スキャンすることで、これを利用できます。 未訪問の非壁セルに遭遇するたびに、そこから BFS または DFS を開始します。 その走査中に、次のすべてをカウントします。`P`遭遇した。 トラバースが終了すると、その部屋にある航空機の正確な数が分かるので、グローバル最大値を更新します。 各歩行可能なセルは 1 回だけ訪問され、グリッド セルの数に線形時間が与えられます。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、セルごとに 1 つのエントリを持つ訪問済み構造を作成します。 壁を通過する必要はありませんが、訪問する構造物を長方形にしておくと、隣接する構造物の処理が簡単になります。 
2. すべてのセルを上から下、左から右にスキャンします。 セルが壁であるか、すでに訪問されている場合は、新しい部屋を開始できないため、スキップしてください。 
3. 未訪問の歩行可能セルが見つかったら、そのセルから BFS を開始し、すぐに訪問済みとしてマークします。 開始セルは次のいずれかになります`.`または`P`両方とも歩行可能であり、同じ接続グラフに属しているためです。 
4. 現在のルームのカウンターを維持します。 BFS が`P`キューからのセル、または同等のセルが最初に検出されたとき。 
5. 訪問したセルごとに、その 4 つの直交する隣接セルを検査します。 近隣がグリッドの外側にある場合、壁である場合、またはすでに訪問されている場合は無視します。 残りのすべてのネイバーは同じ部屋に属しているため、訪問済みとしてマークし、BFS キューに追加します。 
6. BFS キューが空になると、接続されているコンポーネント全体が探索されています。 航空機数をこれまでに見つかった最大値と比較し、大きい方の値を維持します。 
7. すべてのグリッド セルが考慮されるまで外側のスキャンを続けます。 保存されている最大値は、単一の部屋に含まれる航空機の最大数であるため、出力します。 

### なぜ効果があるのか

 不変条件は、BFS が開始されるたびに、その開始セルがこれまでに探索されていない接続コンポーネントに属し、BFS がそのコンポーネント内のすべての歩行可能なセルを正確に訪問するということです。 セルは検出されたときに訪問済みとしてマークされるため、セルを 2 回処理することはできません。 毎`P`したがって、コンポーネント内の は 1 回だけカウントされますが、すべての`P`コンポーネントの外側は除外されます。 外側のスキャンでは、これまでに調査されていないすべてのコンポーネントに対して BFS が開始されるため、すべての部屋が 1 回だけ考慮されます。 したがって、これらのコンポーネントの最大数を取得すると、ツアーに最適なスペースが正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]
    best = 0

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    for r in range(n):
        for c in range(m):
            if grid[r][c] == 'X' or visited[r][c]:
                continue

            queue = [(r, c)]
            visited[r][c] = True
            head = 0
            aircraft = 0

            while head < len(queue):
                cr, cc = queue[head]
                head += 1

                if grid[cr][cc] == 'P':
                    aircraft += 1

                for dr, dc in directions:
                    nr = cr + dr
                    nc = cc + dc

                    if not (0 <= nr < n and 0 <= nc < m):
                        continue
                    if visited[nr][nc] or grid[nr][nc] == 'X':
                        continue

                    visited[nr][nc] = True
                    queue.append((nr, nc))

            best = max(best, aircraft)

    print(best)

if __name__ == "__main__":
    solve()
```外側の二重ループは、手順 2 と 7 で説明したコンポーネント検出を実装します。セルが壁である場合、または以前に探索された部屋にすでに割り当てられている場合、セルは無視されます。 

キューには、現在の BFS に属するセルが格納されます。 整数`head`処理する次のセルを指すため、実装では Python リストの先頭から繰り返し削除することが回避されます。 で削除する`pop(0)`残りのすべての要素が移動され、走査のコストが不必要に高くなる可能性があります。 

セルは、削除されたときではなく、キューに追加されたときに訪問済みとしてマークされます。 これにより、同じセルが異なる隣接セルを介して何度も挿入されることが防止されます。 

4 つの方向のペアは、許可される動きを正確に表します。 境界チェックはインデックス作成前に実行されます。`grid[nr][nc]`、境界セルを安全に処理します。 特別なケースはありません`P`航空機セルは歩行可能であるため、空のセルと同じ BFS に参加するためです。 

Python の整数には任意の精度があるため、航空機を数えるときに整数オーバーフローの心配はありません。 最大数は次のとおりです`n × m`。
