 ## 解決策
 ## 問題の理解

 この問題では、重力車両がテストされている惑星の重力値を特定するように求められます。 入力は惑星 (地球または火星のいずれか) を表す 1 つの単語であり、出力は対応する重力定数です。 地球は 9.807 m/s² の重力値を使用しますが、火星は 3.711 m/s² を使用します。 

2 つの可能な値のうちの 1 つを持つ文字列は 1 つだけであるため、入力サイズは一定です。 これにより、高度なアルゴリズムやデータ構造の必要性が即座に排除されます。 タスク全体が直接検索であるため、時間計算量が一定のソリューションでも十分です。 

主なエッジケースは、正確な入力値を正しく処理することで発生します。 間違ったスペルを比較したり、桁が欠けている値を出力したりするプログラムは失敗します。 

たとえば、入力が次の場合:```
EARTH
```正しい出力は次のとおりです。```
9.807
```と出力する不用意な実装`9.8`必要な精度が失われ、間違った答えが得られます。 

別のケースは次のとおりです。```
MARS
```正しい出力:```
3.711
```入力をチェックせずにデフォルトの答えとして地球を想定するソリューションは、このケースでは暗黙のうちに失敗します。 

## アプローチ

 強引なアプローチは、ある種の重力計算をシミュレートするか、物理式から値を導き出そうとすることです。 この問題ではすでに 2 つの可能な定数が示されているため、これは不要です。 このような方法では、追加情報を使用せずに追加の作業が実行され、正確な操作数は選択した不必要なシミュレーションによって異なります。 

重要な観察点は、入力は単なるラベルであり、測定値ではないということです。 考えられるラベルは 2 つあり、それぞれに固定の答えがあるため、問題は 2 つの保存された値のどちらかを選択することになります。 単純な条件チェックで十分です。 

最終的に惑星を特定する方法ならどれでも答えを導き出せるため、総当り攻撃は機能しますが、必要以上に難しいバージョンの問題を解決するため失敗します。 惑星名から重力値へのマッピングが固定されているという観察により、すべての計算を定数時間の検索に置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k) ここで、k は不必要なシミュレーションに依存します。 お(1) | 原理的に遅すぎて不要 |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力から惑星名を読み取ります。 必要な情報は、車両が地球でテストされているのか、それとも火星でテストされているのかということだけです。 
2. 名前を比較します。`"EARTH"`。 一致する場合は出力`9.807`それは地球の固定重力定数だからです。 
3. それ以外の場合、唯一残っている有効な可能性は次のとおりです。`"MARS"`ので、出力します`3.711`。 

これが機能する理由: 入力ドメインには有効な状態が 2 つだけ含まれており、各状態には必要な出力が 1 つだけあります。 アルゴリズムはこれらの状態を直接チェックするため、有効な入力に対して誤った値が選択される可能性はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    planet = input().strip()

    if planet == "EARTH":
        print("9.807")
    else:
        print("3.711")

if __name__ == "__main__":
    solve()
```プログラムは単一の入力文字列を読み取り、次を使用して末尾の改行を削除します。`strip()`。 この問題では大文字の惑星名が使用されているため、比較は正確です。 

条件分岐は Earth を明示的に処理します。 他に有効な入力は火星だけなので、`else`ブランチは Mars 値を安全に出力できます。 出力は浮動小数点数ではなく文字列として保存されるため、小数点以下 3 桁が正確に保持されます。

## テストケース```python
import sys
import io

def solve():
    import sys
    input = sys.stdin.readline
    planet = input().strip()

    if planet == "EARTH":
        print("9.807")
    else:
        print("3.711")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return result

assert run("EARTH\n") == "9.807\n", "sample 1"
assert run("MARS\n") == "3.711\n", "sample 2"

assert run("EARTH\n") == "9.807\n", "earth constant"
assert run("MARS\n") == "3.711\n", "mars constant"
assert run("EARTH") == "9.807\n", "input without trailing newline"
assert run("MARS") == "3.711\n", "input without trailing newline"
```| テスト入力 | 期待される出力 | 検証内容 |
