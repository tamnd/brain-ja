 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、そこから 4 つの標準統計 (算術平均、中央値、最頻値、および範囲) を計算する必要があります。 必要な出力は、これら 4 つの値がその順序で 1 行に 1 つずつ含まれています。 元の問題ステートメントでは、配列のサイズが示され、次の行にすべての配列の値が示されています。 

平均は、すべての値の合計を値の数で割ったものです。 中央値では、値が並べ替えられた順序で考慮される必要があります。 配列の長さが奇数の場合、中央値は単一の中央値になります。 長さが偶数の場合、中央の 2 つの値の平均になります。 最頻値は最も頻繁に発生する値であり、範囲は最大値と最小値の差です。 

公開されたステートメントでは (n) の数値の上限が指定されていないため、小さな入力サイズに依存すべきではありません。 制限時間は 1 秒、メモリ制限は 256 MB です。 すべての要素に対して配列全体を繰り返しスキャンするソリューションは (O(n^2)) 時間がかかり、(n) が大きくなるにつれて不適切になります。 並べ替えにより (O(n \log n)) の中央値と極値が得られ、頻度辞書からは期待される (O(n)) の最頻値が得られます。 これにより、主要な作業は (O(n \log n)) に快適に残ります。 

不注意な実装によって誤った結果が生じる可能性がある小さなケースがいくつかあります。 1 つの値を含む配列の場合、次のようになります。`1`に続く`7`、正しい出力は次のとおりです。`7.0`、`7.0`、`7`、`0`。 2 つの異なる中間位置があると想定した実装では、中央値が誤って処理される可能性があります。 

偶数サイズの配列も、一般的な境界ケースです。 のために`4`に続く`1 2 3 4`、正しい出力は次のとおりです。`2.5`、`2.5`、`1`、`3`。 ここでは中央値は配列要素の 1 つではないため、次のように使用します。`a[n // 2]`無条件に与えるだろう`3`の代わりに`2.5`。 

意味のあるモードには値の繰り返しが必要です。 のために`5`に続く`2 2 8 1 5`、正しいモードは次のとおりです。`2`他のすべての値が 1 回表示されるのに対し、この値は 2 回表示されるためです。 こちらも付属のサンプルです。 

負の値も正しく処理する必要があります。 のために`3`に続く`-5 -5 -2`、正しい出力は次のとおりです。`-4.0`、`-5.0`、`-5`、`3`。 範囲を次のように計算します`max - min`負の数は自然に処理されますが、個々の要素の絶対値を取得することは正しくありません。 

このステートメントは単一モードを要求していますが、複数の同じ頻度の値に対するタイブレーク ルールは定義していません。 以下の実装では、結合モード間で最初に検出された値が保持されます。 サンプルには固有のモードがあり、これは周波数スキャンの自然な動作であり、厳密に大きい周波数が見つかった場合にのみ現在のモードを置き換えます。 

## アプローチ

 直接的な総当たりソリューションでは、1 回のスキャンで平均と範囲を計算し、配列を並べ替えて中央値を取得し、すべての値を他のすべての値と比較して最頻値を見つけることができます。 (n) 個の配列要素のそれぞれについて、すべて (n) 個の位置をスキャンし、等しい値をカウントします。 最悪の場合、モード計算のみで正確に (n^2) 個の等価性チェックが実行されます。 このアプローチは正しいです。考えられるすべての値が検査され、その完全な頻度がカウントされるため、最大の頻度を見つける必要があります。 その弱点は二次関数の実行時間です。 

すべての統計には単純な定義があるため、総当たり攻撃は機能しますが、周波数スキャンの繰り返しにより不必要な作業が行われます。 同じ値が何度も発生する場合、アルゴリズムはその値を何度もカウントします。 頻度辞書は、配列をスキャンするときにそれぞれの個別の値に関連付けられたカウントを保存することでこれを修正します。 各発生は 1 つのカウンタにのみ寄与するため、モード計算全体が期待されるようになります (O(n))。 

中央値により、残りの非線形部分が作成されます。 配列がソートされると、中央値と範囲の両方が直接インデックス付け操作になります。 並べ替えると、最小値と最大値もすぐに得られます。 したがって、1 回のソートで必要な順序情報がすべて得られ、頻度辞書は繰り返しを独立して処理します。 

合計は順序に依存しないため、ソートする前に合計を計算できます。 同じ初期スキャン中に周波数辞書を構築することもできます。 その後は、並べ替えが唯一の (O(n \log n)) 操作になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | n が大きいと遅すぎます |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (n) と (n) の整数を読み取ります。 中央値では要素がソートされた順序で配置されている必要があるため、配列を保持します。 
2. 値を読み取りながら合計を計算し、頻度辞書を作成します。 合計は平均を直接示しますが、辞書を使用すると、配列を繰り返しスキャンすることなくモードを決定できます。 
3. 配列を非降順で並べ替えます。 ソート後、最小値がインデックスにあります`0`、最大のものはインデックスにあります`n - 1`、中間の位置がわかっています。 
4. 平均を次のように計算します。`sum / n`。 パイソンの`/`演算子は浮動小数点の結果を生成します。これにより、整数の平均を含む奇数サイズの配列などの場合に必要な形式も得られます。 
5. 中央位置から中央値を計算します。`n`奇数です。 いつ`n`偶数、インデックスの 2 つの中心要素の平均`n // 2 - 1`そして`n // 2`。 偶数の観測値には 2 つの中心値があるため、区別する必要があります。 
6. 周波数辞書を調べて、最大周波数の値を保持することによってモードを見つけます。 頻度が同点の場合は、同じ頻度で現在の回答を置き換えるのではなく、最初に見つかった値を保持します。 
7. 範囲を次のように計算します。`a[-1] - a[0]`。 並べ替えにより、配列の両端に最小値と最大値がすでに配置されているため、追加のスキャンは必要ありません。 
8. 平均値、中央値、最頻値、および範囲を必要な順序で別の行に出力します。 

### なぜ効果があるのか

 並べ替え後の配列は、中央値の定義で使用される順序とまったく同じになるため、選択された中間値または中間値のペアは正しいものになります。 頻度ディクショナリには、すべての個別の値の正確な出現数が含まれているため、モードとして保持される値は最大頻度を持ちます。 最初と最後に並べ替えられた要素はそれぞれ最小値と最大値であり、それらの差が範囲となります。 合計にはすべての入力値が 1 回だけ含まれるため、それを (n) で割ることで平均値が得られます。 したがって、各統計は、その統計の定義プロパティから計算されます。 

## Python ソリューション```python
import sys
from collections import Counter

input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    total = sum(a)
    freq = Counter(a)

    a.sort()

    mean = total / n

    if n % 2 == 1:
        median = float(a[n // 2])
    else:
        median = (a[n // 2 - 1] + a[n // 2]) / 2.0

    mode = a[0]
    best_count = 0

    for value, count in freq.items():
        if count > best_count:
            best_count = count
            mode = value

    value_range = a[-1] - a[0]

    print(mean)
    print(median)
    print(mode)
    print(value_range)

if __name__ == "__main__":
    solve()
```最初のスキャンのビルド`total`そして`freq`。 並べ替える前にこれらの値を保持しておくと、後で並べ替えられた配列から周波数を回復する必要がなくなります。 

への呼び出し`a.sort()`メインの (O(n \log n)) 操作です。 Python は整数を昇順にソートするので、`a[0]`そして`a[-1]`範囲に直接使用できます。 

奇数サイズの中央値は次のように使用されます。`a[n // 2]`。 たとえば、次のようなとき`n = 5`、これはインデックスです`2`、3番目の要素。 均一なサイズの場合、`n = 6`、中間の位置はインデックスです`2`そして`3`、まさに`n // 2 - 1`そして`n // 2`。 

明示的な`float`奇数の中央値で変換すると、その型が偶数の場合と一致します。 したがって、中央値が整数である入力でも、次のような出力を生成できます。`2.0`、サンプルの表現と一致します。 

モードスキャンで使用されるのは、`>`それよりも`>=`。 これは、固定された周波数が現在のモードを上書きしないことを意味します。 Python 辞書は挿入順序を保持するため、選択した結合モードは、スキャン中に頻度が最大に達する最初のモードになります。 

Python の整数には任意の精度があるため、エンドポイント間の合計や差を計算するときに整数のオーバーフローの問題は発生しません。 

## 実用的な例

 ### サンプル 1

 付属のサンプルは次のとおりです。```
5
2 2 8 1 5
```当初の合計額は、`18`、周波数辞書は次のようになります。`{2: 2, 8: 1, 1: 1, 5: 1}`。 農産物の仕分け`[1, 2, 2, 5, 8]`。 

| ステップ | ソートされた配列 | 合計 | 中間値 | モード | 範囲 |
 | --- | --- | --- | --- | --- | --- |
 | 読み取り値 |`[2, 2, 8, 1, 5]`| 18 | 計算されていません | 計算されていません | 計算されていません |
 | 並べ替え |`[1, 2, 2, 5, 8]`| 18 |`2`|`2`|`7`|
 | 統計を計算する |`[1, 2, 2, 5, 8]`| 18 |`2`|`2`|`7`|

 平均は`18 / 5 = 3.6`。 長さが奇数なのでインデックス`5 // 2 = 2`中央値を与える`2`。 値`2`周波数が最も高く、範囲は`8 - 1 = 7`。 結果の出力は、提供されたサンプル出力とまったく同じです。 

### サンプル 2

 偶数サイズの例:```
4
1 2 3 4
```すべての値の頻度は 1 であるため、上記の結合動作では最初の値がモードのままになります。 並べ替えても配列は変更されません。 

| ステップ | ソートされた配列 | 合計 | 中間値 | モード | 範囲 |
 | --- | --- | --- | --- | --- | --- |
 | 読み取り値 |`[1, 2, 3, 4]`| 10 | 計算されていません | 計算されていません | 計算されていません |
 | 並べ替え |`[1, 2, 3, 4]`| 10 |`2, 3`|`1`|`3`|
 | 統計を計算する |`[1, 2, 3, 4]`| 10 |`2.5`|`1`|`3`|

 平均は`10 / 4 = 2.5`。 要素が 4 つあるため、中央値は次のようになります。`(2 + 3) / 2 = 2.5`。 すべての値は 1 回出現するため、最初に見つかった値は、`1`、選択されたモードが維持されます。 範囲は`4 - 1 = 3`。
