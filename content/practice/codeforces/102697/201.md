 ## 解決策
 ## 問題の理解

 ここの Ken Ken ボードは常に 5 × 5 のグリッドです。 すべてのセルには 1 から 5 までの整数が含まれている必要がありますが、行内または列内で数値が繰り返されないという追加のラテン方格条件が必要です。 

ボードはケージに分割されています。 ケージは接続されたセルのグループであり、読み取り順序で最初のセルにはターゲットと操作が含まれます。 1 セルのケージはそのターゲットに単純に固定されます。 より大きなケージの場合、加算と乗算はケージ内のすべてのセルに適用されますが、減算と除算はちょうど 2 つのセルにのみ使用されます。 減算の場合、差の絶対値がターゲットと等しい限り、どちらの順序でも有効です。 除算の場合、大きい値を小さい値で割った値がターゲットと等しい限り、どちらの順序でも有効です。 

ケージ構造が ASCII 図面としてエンコードされているため、入力は少し特殊です。 すべてのセルは、その図面内で 2 行 2 列の位置を占めます。 垂直`|`2 つのセルの間にある場合はセルが分離されていることを意味し、垂直の壁がない場合はそれらが同じケージに属していることを意味します。 同じ考え方が水平方向にも適用されます。`-`。 操作テキストは、各ケージの一番上、次に一番左のセル内に表示されます。 

出力は完成した 5 × 5 グリッドです。 すべての値は 1 ～ 5 であるため、各行を 5 桁として直接印刷できます。 

固定サイズ`n = 5`アルゴリズムのトレードオフを大幅に変更します。 25 個のセルに対する一般的なラテン方陣検索では、最大で`5^25`割り当て、つまり大まかに言うと`3 × 10^17`したがって、ボードをやみくもに列挙することは不可能です。 同時に、各セルのドメインには 5 つの値のみが含まれ、ケージには最大 25 個のセルが含まれます。 これにより、特に十分な情報が入手可能になるとすぐにケージ演算がチェックされる場合に、制約ベースのバックトラッキングが実用的になります。 

いくつかの詳細により、単純な実装が静かに不正確になる可能性があります。 減算ケージには順序がありません。 たとえば、次のように記述されるケージです。`2-`含むことができる`1,3`または`3,1`ので、チェックのみ`a - b == 2`有効な解決策を拒否することになります。 同様に、`2/`ケージは受け入れます`1,2`、`2,1`、`2,4`、 そして`4,2`; 最初のセルを 2 番目のセルで割った値のみをチェックするのは間違っています。 

ケージには繰り返し値が含まれる場合もあります。 たとえば、3 セル`6+`ケージには合法的に収容できる`1,2,3`または`2,2,2`。 Latin 制約は、ケージではなく行と列に適用されます。 ケージ内のすべてのセルを強制的に区別する実装では、有効なソリューションが拒否される可能性があります。 

最後に、ケージは複数の行または列にまたがることができ、長方形である必要はありません。 連結されたL型ケージが有効です。 たとえば、最初のサンプルには、単に連続した間隔でセルが連続しているのではなく、欠落した壁を介してセルが接続されているケージが含まれています。 視覚的に長方形の各領域をケージとして扱うと、間違った制約が構築されてしまいます。 

## アプローチ

 最も直接的なブルート フォース ソリューションは、すべての空のセルに 5 つの値のうち 1 つを割り当て、完全なボードを構築した後にラテン平方とケージの条件をチェックします。 これは正しいです。最終的には考えられるすべてのボードが検討され、最初の有効なボードが解決策となります。 問題は検索スペースです。25 個のセルにそれぞれ 5 つの選択肢が与えられます。`5^25 = 298,023,223,876,953,125`制約が使用される前に可能な割り当て。 

自然な改善は、問題を制約検索に変えることです。 値が割り当てられるとすぐに、行と列によって他のセルが使用できる値が制限されます。 さらに重要なのは、ケージの操作により、ケージが完了するずっと前に部分的な割り当てが拒否される可能性がある別の制約が与えられることです。 

追加ケージの場合、部分的な合計を、まだ達成可能な最小および最大の合計と比較できます。 乗算ケージの場合、同じ考え方が積にも当てはまります。 仮に`12+`ケージには 5 つのセルがあり、最初の 3 つの合計は現在 10 になります。残りの 2 つのセルの合計は正確に 2 になる必要がありますが、すべてのセルが少なくとも 1 であるため、これは不可能です。そのブランチの探索はすぐに中止できます。 

減算と除算のケージの場合、セルはちょうど 2 つあるため、両方の値が割り当てられたときの動作を確認するだけで十分です。 シングルトン ケージは、検索が開始される前に値が固定されるため、さらに単純です。 

結果として得られる検索は技術的には依然として指数関数的ですが、強力なプルーニングが行われた小さなドメインでは指数関数的になります。 すべてのボードをチェックするだけで論理的に十分であるため、総当り攻撃は機能しますが、ほとんどすべてのボードが多数の無関係な割り当ての後でのみ拒否されるため、失敗します。 行、列、ケージが部分的な割り当てを拒否する可能性があるという観察により、それらの分岐が不可能になった瞬間にそれらの分岐を切断することができます。

## アルゴリズムのチュートリアル

 1. ASCII ボードを読み取り、どのグリッド セルが同じケージに属しているかを判断します。 水平方向に隣接するセルの各ペアについて、対応する描画線上でそれらの間の文字を検査します。 ない場合`|`、2 つのセルを結合します。 垂直方向に隣接するセルについては、水平方向の境界線でそれらの間の文字を検査します。 ない場合`-`、それらをマージします。 素集合共用体構造は、これらのマージを実行する便利な方法です。 
2. すべてのマージが完了したら、DSU ルートごとにセルをグループ化します。 各グループは 1 つのケージです。 セルを行優先の順序で並べ替えて、最初のセルがパズルで操作が記述されていることが正確に指定されるセルになるようにします。 
3. 各ケージの最初のセルから演算を読み取ります。 シングルトン ケージには、次のような固定整数が含まれます。`2`。 マルチセルケージには、数字の後に続きます。`+`、`x`、`-`、 または`/`。 ターゲットと操作をケージに保管します。 
4. 現在のボードと行と列ごとに 2 つのセットを維持します。 値を代入するときは、`(r, c)`、その値がすでに行に表示されている場合はすぐに拒否します`r`または列`c`。 これにより、ボード全体が推測された後ではなく、ラテン方格条件が段階的に適用されます。 
5. 各ケージに割り当てられた値、合計、および積を追跡します。 追加ケージの場合は、現在の合計を計算し、それを未割り当てのセルで可能な最小および最大の合計と比較します。 ターゲットがその間隔の外にある場合、ブランチは機能しない可能性があります。 乗算ケージの場合は、同等の積結合を実行します。 
6. 減算または除算ケージが完成したら、その動作を直接評価します。 減算には絶対差を使用します。 割り算では、まず大きい方の値を小さい方の値で割ります。正確な割り算とターゲットの商が必要です。 
7. ケージが完成したら、その動作を正確に確認します。 これにより、単純な部分和や積限界では表現できない制約が捕捉されます。 
8. 次の未割り当てのセルを選択し、1 から 5 までの値を試します。この固定された 5 x 5 の問題には、行優先のトラバーサルで十分です。これは、試行される各値が安価で、ケージ枝刈りが強力であるためです。 値を割り当て、影響を受けるすべての状態を更新し、再帰的に行い、分岐が失敗した場合は割り当てを元に戻します。 
9. 25 個のセルすべてが割り当てられたらすぐに停止します。 その時点で、すべての行と列は区別され、すべてのケージはすでにその算術制約を通過しているため、ボードは有効な Ken Ken ソリューションになります。 

### なぜ効果があるのか

 バックトラッキング中の不変条件は、割り当てられたすべてのセルが行と列の制約を満たし、部分的に割り当てられたすべてのケージがターゲットに到達できる状態を維持することです。 分岐が拒否されると、行または列にすでに重複が含まれているか、ケージが算術ターゲットに到達できなくなっているか、完了したケージがその操作に違反しています。 いずれの場合も、そのブランチには有効な完了がないため、枝刈りによってソリューションを破棄することはできません。 検索が完全に割り当てられたボードに到達すると、不変条件により有効な行と列が得られ、すべてのケージが必要な操作に対してチェックされます。 したがって、返品されたボードは有効な解決策となります。 

## Python ソリューション```python
import sys
import re

input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]

def solve():
    n = int(input())
    lines = [input().rstrip("\n") for _ in range(2 * n + 1)]

    dsu = DSU(n * n)

    def cell_id(r, c):
        return r * n + c

    # Missing vertical wall means two horizontal neighbours
    # are in the same cage.
    for r in range(n):
        line = lines[2 * r + 1]
        for c in range(n - 1):
            wall = line[2 * c + 2]
            if wall != '|':
                dsu.union(cell_id(r, c), cell_id(r, c + 1))

    # Missing horizontal wall means two vertical neighbours
    # are in the same cage.
    for r in range(n - 1):
        line = lines[2 * r + 2]
        for c in range(n):
            wall = line[2 * c + 1]
            if wall != '-':
                dsu.union(cell_id(r, c), cell_id(r + 1, c))

    cages = {}
    for r in range(n):
        for c in range(n):
            root = dsu.find(cell_id(r, c))
            cages.setdefault(root, []).append((r, c))

    cage_list = []
    cage_of = [[None] * n for _ in range(n)]

        cells.sort()
        r, c = cells[0]
