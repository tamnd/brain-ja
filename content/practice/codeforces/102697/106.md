 ## 問題の理解

 私たちは、`n × m`迷路。 各セルには次の 1 つの数字が含まれます。`0`に`9`、その細胞の放射線レベルを表します。 左上のセルから開始して、一番下の行に到達する必要があります。 辺を共有するセル間では移動が許可されているため、上下左右に移動できます。 

経路のコストは放射線レベルの合計ではありません。 代わりに、それはそのパス上の任意の場所で検出される最大値です。 最大セル値ができるだけ小さいパスが必要であり、その最小値を可能な限り最大値として出力します。 

制約により、グラフの解釈が便利になります。 両方`n`そして`m`以下にあります`100`, したがって、次の数よりも少なくなります。`10,000`細胞。 迷路全体を 1 秒の制限内で簡単に横断できます。 実現不可能なのは、指数関数的な数の可能なパスを調べることです。 迷路にはサイクルがあり、セルを再訪問する必要がないことがわかった後でも、単純なパスの数はセルの数に応じて指数関数的に増加する可能性があります。 

不注意な実装が失敗する可能性がある境界ケースがいくつかあります。 迷路が 1 つのセルで構成されている場合、次のようになります。```

```可能な唯一のパスはそこから始まりそこで終わります。したがって、答えは次のとおりです。`7`。 に対する答えを初期化する実装`0`隣接するセルのみを検査し、誤って返される可能性があります`0`。 

開始セル自体もパスの放射に寄与します。 例えば、```

```可能なパスは 1 つだけなので、答えは次のようになります。`8`。 開始後に入力されたセルのみをチェックする実装では、誤って返される可能性があります。`2`。

## アプローチ

これは正しいです。すべての有効なルートが最終的に生成され、各ルートはそのルートに沿った最大セル値を正確に使用して評価されるからです。 問題は路線数です。 迷路があれば`V = n*m`セルでは、単純な上限は、最初の移動で最大 4 つの方向を選択し、その後の各移動で最大 3 つの新しい方向を選択することによって決まります。`O(4 * 3^(V-1))`単純なパスの制限が考慮される前に、可能な歩行が可能になります。 したがって、最悪の場合の作業は指数関数的に増加します。`V`。 生成された各パスを一度処理する DFS は、`Θ(P)`現在の最大値が段階的に維持される場合、パス拡張は機能します。`P`単純なパスの数です。 ほぼ`10,000`セル、これは完全に非現実的です。 

重要な観察は、目標は最小限で可能な限り最大であるということです。 最適な経路を直接尋ねる代わりに、許容できる最大放射線量を推測することができます。 

しきい値を選択するとします`x`。 次に、放射が次の値を超えるすべてのセルを禁止します。`x`。 質問は非常に単純になります。許可されたセルのみを使用して、開始セルから最後の行まで移動できるでしょうか?

すべてのセルには次の数字が含まれているため、可能なしきい値は 10 個のみです。`0`を通して`9`。 単純にしきい値を昇順にテストし、一番下の行に到達できる最初のしきい値で停止するだけです。 これにより、二分探索の必要さえなくなり、実装が非常に小さく保たれます。

 ## アルゴリズムのチュートリアル

 1. 迷路を読み取り、すべての数字を整数として保存します。 候補となる放射線閾値との整数比較が必要です。 
2. 以下のしきい値を試します。`0`を通して`9`昇順で。 しきい値`t`放射線を持った細胞が最大でも`t`を入力することはできますが、`t`ブロックされたものとして扱われます。 
3. しきい値に対して BFS を実行する前に、開始セルの放射線が次の値を超えているかどうかを確認します。`t`。 そうなると、すべてのパスに開始セルが含まれるため、どのパスも機能しなくなる可能性があります。 
4.BFS を実行します。`(0, 0)`。 各セルについて、その 4 つの直交する隣接セルを検査し、それが迷路内にあり、最大でも放射線がある場合に正確に隣接セルをキューに入れます。`t`、まだ訪問されていません。 
5. BFS が最後の行のいずれかのセルに到達するとすぐに、現在のしきい値が実現可能になります。 しきい値は最小から最大までテストされるため、これは可能な最小の最大放射量であるため、すぐに出力します。 
6. しきい値が一番下の行に到達できない場合は、そのしきい値を破棄し、次のしきい値に進みます。 最大のセル値は最大であるため、`9`、あるしきい値は常に成功します。`9`。 

### なぜ効果があるのか

 固定閾値の場合`t`, BFS は、放射線量が 2 を超えるすべてのセルの後で、開始セルの接続コンポーネントに属するセルを正確に訪問します。`t`は削除されています。 したがって、BFS は、すべてのセルに放射線が最大でも存在するパスが存在する場合にのみ、最下行に到達します。`t`。 

最適な答えを次のようにします`k`。 以下のすべてのしきい値`k`このようなしきい値は、最適値よりも小さい最大放射を持つパスの存在を意味するため、不可能です。 しきい値`k`最適なパスを定義することで可能になります。 アルゴリズムはしきい値を昇順にチェックし、最初の実行可能なしきい値を返すため、正確に返されます。`k`。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().strip())) for _ in range(n)]

    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

    for limit in range(10):
        if grid[0][0] > limit:
            continue

        visited = [[False] * m for _ in range(n)]
        visited[0][0] = True

        q = deque([(0, 0)])

        while q:
            r, c = q.popleft()

            if r == n - 1:
                print(limit)
                return

            for dr, dc in directions:
                nr = r + dr
                nc = c + dc

                if not (0 <= nr < n and 0 <= nc < m):
                    continue
                if visited[nr][nc]:
                    continue
                if grid[nr][nc] > limit:
                    continue

                visited[nr][nc] = True
                q.append((nr, nc))

if __name__ == "__main__":
    solve()
```グリッドは整数として保存されるため、`grid[r][c] > limit`セルが現在の BFS に対して禁止されているかどうかを直接表します。 

外側のループでは、考えられるすべての回答がソートされた順序で考慮されます。 外部の値を検索する必要はありません`0`を通して`9`というのは、迷路内に現れる放射線レベルはこれらだけだからです。 

しきい値ごとに、`visited`すでに到達したセルを記録します。 セルは、削除されるときではなく、キューに挿入されるときにマークされます。 これにより、同じセルが異なる隣接セルを介して何度もキューに入れられることがなくなります。 

小切手`r == n - 1`最後の行のいずれかのセルに到達すると、必要な目的地に到達したことを意味するため、成功を検出するにはこれで十分です。 それ以降は検索を続ける必要はありません。 

境界条件は、グリッドにアクセスする前に行と列の両方の範囲をチェックします。 これにより、Python での負のインデックスの動作が回避されます。これは、次のような式により特に見落とされやすいものです。`grid[-1][c]`は有効な Python ですが、拒否されずに最後の行を参照します。 

すべての値は数字であり、Python の整数はとにかく任意の精度を持っているため、整数オーバーフローの懸念はありません。 キューには最大でも次のものが含まれます`n*m`1 つの BFS のセル。
