 ## アルゴリズムのチュートリアル

 1.読む`m`そしてプライムシーブとバイト配列を割り当てます`omega`多重度で数えられる素因数の数。 
2. エラトステネスのふるいを最大までかける`m`。 ふるいにかけた後に素数としてマークされたままの数値は、後の数値に因数を与えることができるまさに素数です。 
3. 素数ごとに`p`、の倍数をすべて訪問します。`p`そして因子数に 1 を加えます。 次に、複数の場所を訪問します`p^2`、`p^3`、そして最大でもより高い権限`m`、各パワーでさらに 1 つ追加します。 これは、次のすべての発生をカウントします。`p`単純に異なる素約数を数えるのではなく、因数分解を行うことができます。 
4. 開始時間`n = m`まで下に移動します。`omega[n] == 2`。 これは上から最初に現れる半素数であるため、必然的に許容される最大値となります。`n`。 
5.選択します`e`このセミプライムの構造から。 もし`n`奇数です、使用してください`e = 2`。 もし`n`は偶数であり、次で割り切れます`3`とすると、この状況で考えられる唯一の準プライムは次のとおりです。`n = 6`ので、使用します`e = 5`。 それ以外の場合は使用します`e = 3`。 
6. 印刷`n`そして`e`。 選択された指数は次の値より小さいです`n`、少なくとも`2`、と互いに素です`n`。 

なぜ効果があるのか​​:`omega[x]`はまさに次の素因数の数です`x`、繰り返される要素をカウントします。 したがって、`omega[x] == 2`もし、そしてその場合に限り`x`問題の定義では準素数です。 その結果、下方向のスキャンにより最大の有効な係数が返されます。 奇数のセミプライムの場合、`2`素因数を共有することはできません。 偶数のセミプライムの場合、`n = 2p`; もし`p != 3`、 それから`3`と互いに素である`n`、 その間`n = 6`必要`5`。 これらはあらゆる場合において可能な最小の有効な指数であるため、結果のペアは両方の最適化基準を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m = int(input())

    # Sieve of Eratosthenes.
    is_prime = bytearray(b'\x01') * (m + 1)
    if m >= 0:
        is_prime[0] = 0
    if m >= 1:
        is_prime[1] = 0

    p = 2
    while p * p <= m:
        if is_prime[p]:
            start = p * p
            count = (m - start) // p + 1
            is_prime[start:m + 1:p] = b'\x00' * count
        p += 1

    # omega[x] = total number of prime factors of x,
    # counting multiplicity.
    omega = bytearray(m + 1)

    for p in range(2, m + 1):
        if not is_prime[p]:
            continue

        power = p
        while power <= m:
            for x in range(power, m + 1, power):
                omega[x] += 1

            if power > m // p:
                break
            power *= p

    # Find the largest semiprime.
    n = m
    while n >= 4 and omega[n] != 2:
        n -= 1

    # Find the smallest valid e.
    if n & 1:
        e = 2
    elif n % 3 == 0:
        # The only even semiprime divisible by 3 is 6.
        e = 5
    else:
        e = 3

    print(n, e)

if __name__ == "__main__":
    solve()

の`omega`配列の用途`bytearray`100 万未満の数には多くの素因数を含めることはできないためです。 可能な最大値は、次の値を繰り返し乗算することで得られます。`2`, ということで以下になります。`20`。 1 バイトで十分すぎるため、メモリの使用量は非常に少なく抑えられます。 

素数ごとに`p`、ループオーバー`power = p, p^2, p^3, ...`これが、個別の素因数の数を調べるふるいからこれを区別するものです。 たとえば、次のようなとき`p = 2`、番号`12`に訪問されています`2`、`4`、ではありません`8`, したがって、プライムから 2 つの貢献を受け取ります。`2`。 プライム`3`一度寄付して寄付する`omega[12] = 3`。

指数の選択により、汎用の GCD ループが回避されます。 奇数の場合`n`、`e = 2`は常に有効です。 偶数の場合`n`、セミプライムの形式は次のとおりです。`2p`。 で割り切れるなら`3`、 それから`p = 3`そして`n = 6`、作る`5`最初の有効な指数。 さもないと`3`と互いに素である`n`。 あらゆる場合に選ばれたのは、`e`より厳密に小さいです`n`。
