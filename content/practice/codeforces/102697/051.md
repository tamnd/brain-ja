 ## 解決策
 ## 問題の理解

 軸が揃った 2 つの長方形が与えられます。 各長方形は向かい合う 2 つの角で記述されるため、1 行には 4 つの整数が含まれます。`x1 y1 x2 y2`最初の四角形の情報が含まれており、次の行には 2 番目の四角形の同じ情報が含まれています。 座標はどちらの順序でも指定できるため、ソリューションで最初に行う必要があるのは、すべての四角形をその左、右、下、上の境界に変換することです。 

必要な答えは、`YES`2 つの長方形の外周に少なくとも 1 つの共通点がある場合、および`NO`さもないと。 この解釈は、2 つの同一の四角形が交差するという問題の特殊な条件に従いますが、厳密に別の四角形の内側にある四角形は、その周囲が互いに素である場合には交差しません。 

公式声明では、制限時間は 1 秒、メモリは 256 MB とされています。 明示的な座標境界を公開しないため、有用な大きな座標値はありません。`n`さらに最適化します。 入力自体には常に 2 つの四角形のみが含まれます。これは、意図した解が定数時間であり、8 つの座標のみに依存する必要があることを意味します。 

主なエッジケースは厳格な封じ込めです。 考慮する```
0 0 10 10
2 2 8 8
```正しい出力は次のとおりです```
NO
```2 番目の長方形は完全に最初の長方形の内側にあり、それらの周囲は決して接触しません。 2 つの長方形の x と y の間隔が重なっているかどうかだけをチェックする不注意な解決策では、次のように出力されます。`YES`両方の投影が完全に重なっているためです。 

逆の状況は、接触境界による封じ込めです。```
0 0 10 10
0 2 8 8
```正しい出力は次のとおりです```
YES
```2 番目の長方形は、左側に沿って最初の長方形に接しています。 2 つの長方形は境界点を共有しているため、包含は厳密ではありません。 封じ込めを検出するときに厳密な不等式を使用すると、このケースが正しく処理されます。 

もう 1 つの重要なケースは、2 つの同一の長方形です。```
0 0 5 5
0 0 5 5
```正しい出力は次のとおりです```
YES
```厳密な包含テストでは、対応するすべての境界点が両方の四角形に属するため、同一の四角形を包含として分類してはなりません。 このステートメントでは、重複する同一の長方形は交差しているものとしてカウントされると明示的に述べています。 

最後に、長方形はちょうど 1 つの角で交差できます。```
0 0 2 2
2 2 5 5
```正しい出力は次のとおりです```
YES
```間隔の比較は包括的である必要があります。 交換中`<=`による`<`このケースは誤って拒否されてしまいます。 

## アプローチ

 直接的な総当たりのアイデアは、2 つの長方形を結合した境界ボックス内のすべての整数点を検査し、その点が両方の境界線上にあるかどうかを確認することです。 すべての入力座標は整数であり、長方形は軸に沿って配置されているため、境界間の交差部分は整数座標になります。 を含む境界ボックスの場合`W + 1`可能な整数の x 座標と`H + 1`可能な整数の y 座標。最悪のケースでも正確に検査されます。`(W + 1)(H + 1)`ポイント。 座標範囲が大きい場合、これは任意にコストが高くなる可能性があり、この問題では、そのような列挙を合理的にする座標境界が与えられません。 

より幾何学的なブルートフォース手法では、境界セグメントのすべてのペアをチェックできます。 長方形ごとに 4 つの辺があり、正確に 16 個のセグメントのペアが与えられます。 この方法はすでに定数時間であるため受け入れられますが、必要以上に多くのジオメトリ コードが必要になります。 

重要な観察は、軸に揃えられた長方形が 2 つの 1 次元間隔によって完全に記述されるということです。 長方形は、x 範囲が重複し、y 範囲が重複する場合にのみ、交差する周囲を持つことができます。 ただし、厳密な封じ込めによって境界が分離されたままの場合でも投影が重複するため、間隔のオーバーラップだけでは十分ではありません。 

有効な削減方法は、2 つのテストを実行することです。 まず、長方形の x 間隔と y 間隔が重なっていること (接触している端点も含む) を確認します。 次に、どちらの四角形も厳密にもう一方の四角形の内側にないことを確認します。 両方の条件が当てはまる場合、境界はどこかで交わる必要があります。 いずれかの間隔が互いに素である場合、長方形は分離されます。 一方の長方形が厳密に他方の長方形の内側にある場合、2 つの周囲は互いに素です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 整数小数点の列挙 | O(W・H) | お(1) | 座標が大きいと遅すぎる |
 | ペアごとのエッジ交差 | お(1) | お(1) | 承認済み |
 | 間隔のオーバーラップ + 包含 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各長方形の向かい合う 2 つの角を読み取り、それらを正規化します。 角のある長方形の場合`(x1, y1)`そして`(x2, y2)`、 定義する`left = min(x1, x2)`、`right = max(x1, x2)`、`bottom = min(y1, y2)`、 そして`top = max(y1, y2)`。 これにより、反対側のどのコーナーが最初にリストされたかという依存関係がなくなります。 
2. 次のコマンドを使用して、X 投影が重なっているかどうかを確認します。`max(left1, left2) <= min(right1, right2)`。 垂直境界または単一の X 座標の共有は依然として交差と互換性があるため、不等式は包括的です。 
3. 次のコマンドを使用して、y 投影が同じように重なっているかどうかを確認します。`max(bottom1, bottom2) <= min(top1, top2)`。 いずれかの投影が互いに素である場合、長方形は共通の境界点を持つことができません。 
4. 最初の長方形が厳密に 2 番目の長方形の内側にあるかどうかを確認します。 これはまさに次のようなときに起こります。`left2 < left1`、`right1 < right2`、`bottom2 < bottom1`、 そして`top1 < top2`。 
5. 2 番目の長方形が最初の長方形の内側に厳密に存在するかどうかの対称条件を確認します。 
6. 印刷`YES`まさに、投影が重なり合い、厳密な封じ込め条件がどちらも真ではないときです。 厳密な不等式は、真の包含を、エッジまたはコーナーに沿って単に接触しているだけの長方形と区別するものです。 

**Why it works.** Suppose the algorithm prints`YES`。 x 投影と y 投影は重なるため、2 つの長方形は平面の共通領域を占めるか、境界で接触します。 どちらの長方形も厳密には他方の長方形の中に含まれていないため、それらの境界を完全に分離することはできません。 したがって、それらの周囲は少なくとも 1 つの点を共有する必要があります。 

逆に、長方形の外周が交差しているとします。 共通の境界点は両方の長方形で同じ x 座標と y 座標を持つため、それらの x 投影と y 投影は必然的に重なり合います。 また、厳密に包含すると内周が外周から完全に離れて配置されるため、どちらの長方形も厳密に他方の内側に存在することはできません。 したがって、すべての本物の交差は両方のテストに合格し、アルゴリズムは次のように出力します。`YES`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(rect):
    x1, y1, x2, y2 = rect
    left = min(x1, x2)
    right = max(x1, x2)
    bottom = min(y1, y2)
    top = max(y1, y2)
    return left, right, bottom, top

def solve():
    r1 = normalize(list(map(int, input().split())))
    r2 = normalize(list(map(int, input().split())))

    left1, right1, bottom1, top1 = r1
    left2, right2, bottom2, top2 = r2

    x_overlap = max(left1, left2) <= min(right1, right2)
    y_overlap = max(bottom1, bottom2) <= min(top1, top2)

    first_inside = (
        left2 < left1 and
        right1 < right2 and
        bottom2 < bottom1 and
        top1 < top2
    )

    second_inside = (
        left1 < left2 and
        right2 < right1 and
        bottom1 < bottom2 and
        top2 < top1
    )

    if x_overlap and y_overlap and not first_inside and not second_inside:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```の`normalize`関数は、向かい合う角の各ペアを正規表現に変換します。`(left, right, bottom, top)`。 この手順を行わないと、比較では各入力四角形の 4 つの可能な方向を処理する必要があります。 

の`x_overlap`そして`y_overlap`式では包括的な比較が使用されます。 これは、エッジまたはコーナーでの接触が交差点としてカウントされるため必要です。 例えば、`[0, 2]`そして`[2, 5]`終点で重なる`2`。 

封じ込めチェックでは厳密な不等式が使用されます。 境界座標が等しい場合、長方形は接触しており、包含は厳密ではありません。 これはまさに、外側の長方形の左端を共有する 1 つの長方形のような場合に必要なものです。 

Python の整数はオーバーフローしないため、32 ビット整数の範囲よりはるかに大きな座標であっても、解は安全なままです。 ループや補助データ構造は必要ありません。

import sys
import io

def solve():
    def normalize(rect):
        x1, y1, x2, y2 = rect
        return min(x1, x2), max(x1, x2), min(y1, y2), max(y1, y2)

    r1 = normalize(list(map(int, input().split())))
    r2 = normalize(list(map(int, input().split())))

    left1, right1, bottom1, top1 = r1
    left2, right2, bottom2, top2 = r2

    x_overlap = max(left1, left2) <= min(right1, right2)
    y_overlap = max(bottom1, bottom2) <= min(top1, top2)

    first_inside = (
        left2 < left1 and right1 < right2 and
        bottom2 < bottom1 and top1 < top2
    )

    second_inside = (
        left1 < left2 and right2 < right1 and
        bottom1 < bottom2 and top2 < top1
    )

    print("YES" if x_overlap and y_overlap
          and not first_inside and not second_inside else "NO")

def run(inp: str) -> str:
    global input

    old_stdin = sys.stdin
    old_input = input

    try:
        sys.stdin = io.StringIO(inp)
        input = sys.stdin.readline

        old_stdout = sys.stdout
        sys.stdout = io.StringIO()
        try:
            solve()
            return sys.stdout.getvalue()
        finally:
            sys.stdout = old_stdout
    finally:
        sys.stdin = old_stdin
        input = old_input

# Custom case 4: boundary touch with very large coordinates

 ## 特殊なケース

 厳重な封じ込めのため、```
0 0 10 10
2 2 8 8
```正規化では、両方の四角形が変更されないままになります。 X 範囲`[0,10]`そして`[2,8]`y 範囲と同様に、オーバーラップします。 2 番目の長方形は次の条件を満たします`0 < 2`、`8 < 10`、`0 < 2`、 そして`8 < 10`, したがって、厳密には最初の内側にあります。 アルゴリズムはペアを拒否し、出力します`NO`。 

境界接触については、```
0 0 10 10
0 2 8 8
```X 範囲は複数の点で重なり、Y 範囲は重なり合います。 2 番目の長方形は、その左境界が最初の長方形の左境界と等しいため、厳密には最初の長方形の内側にありません。 したがって、アルゴリズムは次のように出力します。`YES`、共有垂直エッジを交差点として正しく処理します。 

同一の長方形の場合、```
0 0 5 5
0 0 5 5
```対応するすべての境界が厳密にネストされているのではなく等しいため、両方の包含テストは false になります。 投影が重なるため、アルゴリズムは次のように出力します。`YES`。 

一つ角の交差点の場合、```
0 0 2 2
2 2 5 5
```X 範囲は次の位置で交差します。`x = 2`、y 範囲は次の点で交差します。`y = 2`。 どちらの比較でも使用します`<=`、つまり、シェアポイント`(2, 2)`受け入れられます。 どちらの四角形も厳密にはもう一方の四角形に含まれず、正しい出力が得られます。`YES`。 

コーナーの順序を逆にすると、```
5 5 0 0
8 8 4 4
```正規化により、長方形が次のように変換されます。`[0,5] × [0,5]`そして`[4,8] × [4,8]`。 アルゴリズムの残りの部分は通常の方向と同じであり、`YES`。 このため、考えられるすべての入力方向を個別に処理しようとするよりも、最初に座標を正規化する方が望ましいのです。
