 ## 解決策
 ## 問題の理解

 このタスクは、スタインハート・ハート方程式を中心に構築された小さな数値代数問題です。 3 つの校正測定があります。 各測定値は抵抗 (R_i) と温度 (T_i) を組み合わせており、モデルでは次のようになります。 

[
 \frac{1}{T}=A+B\ln R+C(\ln R)^3。 
】

 3 つの測定により、3 つの未知の定数 (A)、(B)、および (C) が決定されます。 (A) を印刷するだけです。 入力には (T_1,T_2,T_3,R_1,R_2,R_3) が含まれており、それぞれが独自のライン上の浮動小数点値として含まれます。 公式声明では定数を計算するための一連の中間式を明示的に示しているため、プログラミング作業は主にそれらの式を正しい順序で評価することになります。 

ここには、大きな (n)、配列、グラフ、または繰り返されるテスト ケースはありません。 入力サイズは常に 6 つの浮動小数点数で、制限時間は 256 MB のメモリで 1 秒です。 したがって、漸近的な最適化は問題になりません。 固定数の算術演算を実行するソリューションは事実上瞬時に実行されます。 本当の懸念は、自然対数を使用すること、浮動小数点精度を維持すること、および意図した順序で除算を評価することです。 

キャリブレーション ポイントは、提供された式に適している必要があります。 特に、対数には正の抵抗が必要であり、式を定義するには分母 (L_2-L_1)、(L_3-L_1)、(L_3-L_2)、および (L_1+L_2+L_3) が消えてはいけません。 

有用な境界ケースは、正確に (1) の抵抗です。 例えば、```
1
1
1
1
2
4
```(L_1=\ln 1=0) があります。 3 つの温度がすべて (1) の場合、すべての (Y_i) が (1) になるため、両方の傾きがゼロになり、(C=0)、(B=0)、そして最後に (A=1) になります。 正しい出力は (1) です。 対数が常に非ゼロであると仮定する不注意な実装は、これを誤って特殊なケースとして扱ったり、(L_1) による不必要な除算を導入したりする可能性があります。 

もう 1 つの特殊なケースは、3 つの温度がすべて等しいが抵抗が異なる場合です。 のために```
1
1
1
1
2
4
```同じ計算で (A=1)、(B=0)、(C=0) が得られます。 異なる温度が必要であると仮定する方法は、完全に有効な数学的ケースを拒否することになります。 

さらに危険なケースは、繰り返し抵抗することです。 例えば、```
1
1
1
2
2
4
```(L_2-L_1=0) となるため、(\gamma_2) は未定義になります。 提供された式では、そのようなデータから校正定数を決定することはできません。 不用意に実装すると、除算が試行され、例外または無効な浮動小数点の結果が生成される可能性があります。 有効なテスト データでは、この特異な状況を回避する必要があります。 

## アプローチ

 この問題を考える一般的な方法は、3 つの測定値を 3 つの未知数 (A、B、C) の 3 つの方程式として扱うことです。 書いた後

 [
 Y_i=\frac1{T_i},\qquad L_i=\ln R_i,
 】

 各測定値は次のようになります

 [
 Y_i=A+B L_i+C L_i^3。 
】

 素朴な代数実装では、これを (3\times3) 線形システムとして構築し、ガウス消去法を実行できます。 行列には常に 3 行 3 列が含まれるため、このアプローチは完全に実現可能です。 一定数の算術演算のみを実行するため、通常の大入力総当たりとは異なり、漸近的に遅くなりすぎる入力サイズはありません。 最悪のケースは依然として、数百の算術演算をはるかに下回る、単なる固定サイズの消去です。 

より自然な解決策は、問題がこの正確なシステムに特化した消去シーケンスをすでに提供していることを観察することによって得られます。 方程式間の差異を取ると (A) が削除されます。 これらの差を (L) の対応する差で割ると、2 つの割線の傾き (\gamma_2) と (\gamma_3) が得られます。 それらの差により 3 次係数 (C) が分離され、その後に (B) がすぐに続きます。 最後に、最初の校正点を代入すると (A) が回復します。 

代数では基底関数 (1,L,L^3) の特別な構造が既に利用されているため、これは一般的なガウス消去法よりも好ましいです。 マトリックスの構築、ピボット、または汎用の削除を実装する必要はありません。 計算全体は、対数、加算、乗算、除算の固定シーケンスです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 一般的な 3x3 ガウス消去法 | (O(1)) | (O(1)) | 承認済み |
 | 直接の Steinhart-Hart 式 | (O(1)) | (O(1)) | 受け入れられ、よりシンプル |

 ## アルゴリズムのチュートリアル

 1. 6 つの浮動小数点値を入力順序で読み取ります。 このステートメントでは順序が (T_1,T_2,T_3,R_1,R_2,R_3) であるため、最初の 3 つの値は抵抗ではなく温度として解釈する必要があります。 
2. (L_1=\ln R_1)、(L_2=\ln R_2)、および (L_3=\ln R_3) を計算します。 これらは、Steinhart-Hart 方程式で使用される独立変数の値です。 
3. (Y_1=1/T_1)、(Y_2=1/T_2)、(Y_3=1/T_3) を計算します。 元の方程式は (1/T) で表されるため、これらの値は測定値を代数に必要な形式に変換します。 
4. コンピューティング

 [
 \gamma_2=\frac{Y_2-Y_1}{L_2-L_1}
 】

 そして

 [
 \gamma_3=\frac{Y_3-Y_1}{L_3-L_1}。 
】

 これらの量は、データ変換後の最初のキャリブレーション ポイントと他の 2 つのポイントの間の傾きを表します。 

1. コンピューティング

 [
 C=
 \frac{\gamma_3-\gamma_2}{L_3-L_2}
 \cdot
 \frac{1}{L_1+L_2+L_3}。 
】

 2 つの傾きの差により、(L) で線形に動作する寄与が除去され、3 次係数を決定するのに十分な情報が残ります。 

1. コンピューティング

 [
 B=\gamma_2-C(L_1^2+L_1L_2+L_2^2)。 
】

 これにより、最初の割線の傾きから 3 次寄与が減算され、(L) の係数が残ります。 

1. 最初のキャリブレーションポイントを使用して (A) を回復します。 

[
 A=Y_1-L_1(B+L_1^2C)。 
】

 これは、(A) を分離するために元の方程式を再構成したものにすぎません。 

1. (A) を浮動小数点値として出力します。 裁判官は公差を使用するため、正確な小数点の再現は必要ありません。 公式声明では、正確な四捨五入について心配する必要はないと明示的に述べられています。

計算全体を通じて不変なのは、(L_i) と (Y_i) が常に元の校正測定値の変換された座標を表す一方で、(C)、次に (B)、最後に (A) が、新しく計算されたすべての係数が既知の値のみに依存する順序で復元されることです。 式は 3 つの元の方程式から代数的に導出されているため、結果として得られる (A) は、キャリブレーション データを生成したのと同じモデルに属する係数です。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve(values):
    T1, T2, T3, R1, R2, R3 = values

    L1 = math.log(R1)
    L2 = math.log(R2)
    L3 = math.log(R3)

    Y1 = 1.0 / T1
    Y2 = 1.0 / T2
    Y3 = 1.0 / T3

    gamma2 = (Y2 - Y1) / (L2 - L1)
    gamma3 = (Y3 - Y1) / (L3 - L1)

    C = ((gamma3 - gamma2) / (L3 - L2)) / (L1 + L2 + L3)

    B = gamma2 - C * (L1 * L1 + L1 * L2 + L2 * L2)

    A = Y1 - L1 * (B + L1 * L1 * C)

    return A

def main():
    values = [float(input()) for _ in range(6)]
    print(solve(values))

if __name__ == "__main__":
    main()
```の`solve`関数は数学的導出を直接反映します。 (L_i) と (Y_i) を別個の変数として保持すると、依存関係の順序が明示的になり、温度とその逆数が誤って混合されるのを防ぎます。`math.log`Steinhart-Hart 方程式で必要な自然対数を計算します。 パイソンの`float`裁判官は数値許容範囲内で回答を受け入れるため、これで十分です。 

(C) の式は、明示的な負の指数を使用するのではなく、2 つの除算として記述されます。 どちらの形式も数学的に同等であり、選択したバージョンにより分母の構造を検査しやすくなります。 (B) の式では、導出によって得られたとおりに (L_1^2)、(L_1L_2)、および (L_2^2) が使用されます。 

すべての計算では Python 浮動小数点値が使用されるため、整数オーバーフローの問題はありません。 また、小数点以下の桁数を固定するなどの特別な書式設定も必要ありません。 完全な Python 浮動小数点表現を出力すると、指定された許容値に対して十分な精度が得られます。
