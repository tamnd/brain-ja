 ## 解決策
 ## 問題の理解

 このタスクは、単一行のテキストとして書かれた多項式を記号的に微分することです。 多項式は次のような項で構成されます。`5x^5`、`x`、`8x^2`、 または`10`、隣接する用語は次のいずれかで区切られます。`+`または`-`。 最初の項は定数ではないことが保証されています。 

期間について`kx^n`と`n >= 2`、微分すると次のように変わります。`knx^(n-1)`。 のような用語`7x`派生語があります`7`一方、定数には導関数ゼロがあり、結果の多項式から消えます。 必要な出力は導関数であり、同じ形式のスペースと文字を使用して記述されます。`+`または`-`区切り文字。 

このステートメントでは多項式の最大長が明示的に指定されていないため、自然な目標は入力の長さの線形時間になります。 ソリューションでは、式を 1 回読み取り、各符号付き項を識別し、その係数と指数を解析し、微分して、答えを構築する必要があります。 式全体を繰り返し再スキャンするアプローチは、長さが 2 次になる可能性があるため、不要です。 

主なエッジケースは、用語が取り得るさまざまなテキスト形式に由来します。 係数は次のように省略できます。`x^5`、つまり係数は`1`。 次のように指数は省略できます。`9x`、つまり指数は`1`。 次のような定数`10`はありません`x`まったく、消えなければなりません。 たとえば、入力`x + 10`出力があります`1`、の派生であるため、`x`は`1`そして定数は消えます。 すべての用語に次のものが含まれると想定する不用意な実装`x`処理中に失敗する`10`。 

標識も正しい用語に関連付けられている必要があります。 例えば、`5x^2 - 3x`になる`10x - 3`、 ない`10x + 3`。 減算区切り文字はそれに続く用語に属しているため、符号なしの用語のみを抽出するパーサーは警告なしに符号を失う可能性があります。 

2 番目の境界ケースは省略された係数です。 例えば、`x^3 + 2x`になる`3x^2 + 2`。 欠落している係数をゼロとして扱うと、テキストを処理しながら最初の項が誤って削除されてしまいます。`x`数値として指定すると、解析が失敗する可能性があります。 

最後に、定数項は非定数項の間に現れることがあります。 入力`x + 10 + 3x`になる`1 + 3`。 真ん中の定数は余分なものを残さずに削除する必要があります。`+`、出力は、元の文字列をその場で変更するのではなく、残っている導関数項から再構築する必要があります。 

## アプローチ

 簡単なブルートフォース実装では、残りの式全体を繰り返しスキャンして次の区切り文字を見つけ、対応する用語を抽出し、次の用語に対して別のスキャンを開始できます。 すべての項は最終的にべき乗則に従って分離および微分されるため、これは正しいです。 問題は、同じ文字が何度も検査されることです。 式に長さがある場合`L`短い用語が多く、スキャンではおおよその内容を調べることができます。`1 + 2 + 3 + ... + L = L(L+1)/2`最悪の場合の文字、つまり Θ(L²) です。 

解決策をより単純にする観察は、区切り記号がすでに正確な用語の境界を与えているということです。 すべての区切り文字は次のいずれかであるため、`+`または`-`、式をトークンに分割することで、各用語を 1 回だけ処理できるようになります。 まだその符号が必要ですが、それはスペースで分割することで処理できます。つまり、次のような多項式です。`5x^5 + 3x^4 - 2x`トークンシーケンスになります`5x^5`、`+`、`3x^4`、`-`、`2x`。 次に、各用語の記号を持ったこれらのトークンを左から右に見ていきます。 

各用語について、2 つのケースを区別するだけで済みます。 含まれていない場合`x`、これは定数であり、何も寄与しません。 それ以外の場合は、その前の部分`x`は係数で、デフォルトは`1`空の場合とその後の部分`x`指数を決定します。デフォルトは`1`空のとき。 導関数ルールを適用すると、1 つの出力項が生成されます。 定数は単純にスキップされます。 

結果は、当然のことながら、書式設定された派生用語のリストとして構築されます。 そのリストに加わるのは、`" + "`負の項は正しく保存されないため、最もクリーンな実装では、各微分係数を符号付きで保存し、最終的な式を左から右にフォーマットします。

## アルゴリズムのチュートリアル

 1. 完全な多項式を 1 行として読み取り、末尾の改行のみを削除します。 式内のスペースは、用語とその用語を区切るために意味があります。`+`または`-`オペレーター。 
2. 式をスペースで分割します。 入力ではすべての語句の両側にスペースが保証されるため、これにより交互の用語トークンと演算子トークンが生成されます。`+`または`-`。 
3. 最初の項を正符号で個別に処理します。 このステートメントは、この項が定数ではないことを保証しているため、その導関数は間違いなく答えに寄与します。 
4. 以下の演算子と用語のペアごとに、次のように解釈します。`+`記号として`+1`そして`-`記号として`-1`。 用語を区別する前に、その記号を用語に付けてください。 
5. 用語に「no」が含まれている場合`x`、スキップしてください。 このような項は定数であり、その導関数はゼロです。 
6. 用語に次の内容が含まれる場合`x`で概念的に分割します。`x`。 係数は前のテキストです`x`、空の係数は次のように解釈されます。`1`。 指数はその後のテキストです`x`、空の指数は次のように解釈されます。`1`。 
7. 係数に指数を乗算して新しい係数を取得し、指数を 1 減算します。 指数の場合`1`、結果の項は定数であるため、その係数のみを出力します。 
8. 係数が 0 である導関数項は無視します。 与えられた入力保証の下では、最初の項は定数にすることができず、入力係数は通常の多項式係数であるため、これは主に一般的な解析ロジックに関連します。 
9. 符号を維持しながら、残っているすべての微分項を結果に追加します。 最初に残った用語は先頭なしで出力されます。`+`。 
10. フォーマットされた部分をスペースで結合し、結果を出力します。 最初の元の項は非定数であるため、導関数には少なくとも 1 つの非ゼロ項が含まれるため、特別な関数は必要ありません。`0`指定された入力形式には出力が必要です。 

### なぜ効果があるのか

 不変条件は、入力の接頭辞を処理した後、結果リストにはその接頭辞からのすべての非定数項の導関数が、元の順序と元の符号で正確に含まれることです。 定数はゼロを与えるため、正しく省略されます。 すべての非定数項はその係数と指数に解析され、べき乗則によってその数学的導関数が正確に生成されます。 多項式の項は独立して微分するため、すべての項を 1 回処理すると、完全な多項式の導関数が正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def differentiate_term(term):
    if 'x' not in term:
        return None

    x_pos = term.index('x')

    coefficient_text = term[:x_pos]
    exponent_text = term[x_pos + 1:]

    coefficient = int(coefficient_text) if coefficient_text else 1
    exponent = int(exponent_text[1:]) if exponent_text.startswith('^') else 1

    new_coefficient = coefficient * exponent
    new_exponent = exponent - 1

    if new_exponent == 0:
        return str(new_coefficient)

    if new_exponent == 1:
        if new_coefficient == 1:
            return 'x'
        return f'{new_coefficient}x'

    if new_coefficient == 1:
        return f'x^{new_exponent}'

    return f'{new_coefficient}x^{new_exponent}'

def solve():
    expression = input().strip()
    tokens = expression.split()

    result = []

    # The first term is guaranteed to be non-constant.
    first = differentiate_term(tokens[0])
    if first is not None:
        result.append((1, first))

    i = 1
    while i < len(tokens):
        sign = 1 if tokens[i] == '+' else -1
        term = tokens[i + 1]

        derivative = differentiate_term(term)

        if derivative is not None:
            result.append((sign, derivative))

        i += 2

    output = []

    for index, (sign, term) in enumerate(result):
        if index == 0:
            if sign == -1:
                output.append('-')
            output.append(term)
        else:
            output.append('+' if sign == 1 else '-')
            output.append(term)

    print(' '.join(output))

if __name__ == "__main__":
    solve()

微分後の指数が 0 は結果が定数であることを意味するため、係数のみが出力されます。 1 の指数は、`^1`表記は不要なので、結果は次のように出力されます。`kx`。 より大きな指数の場合は通常`kx^n`という形式が使われます。 を含む項からも係数 1 が省略されます。`x`、 それで`1x^4`になる`x^4`。 

主な機能は以下を使用します`split()`見つけようとするのではなく`" + "`そして`" - "`手動で。 入力ではすべての演算子の周囲にスペースが保証されているため、結果のシーケンスは、項、演算子、項、演算子、項という予測可能な形式になります。 各反復で 2 つのトークンずつ進むことで、演算子が誤って用語として解釈されるのを防ぎます。 

結果には、記号が用語テキストとは別に保存されます。 これにより、定数が消失した場合の不正な式が回避されます。 例えば、`x + 10 - 3x`派生作品を生み出す`1`そして`-3`、そして破棄された定数によって不要な区切り文字が作成されることはありません。 

Python の整数には任意の精度があるため、高次項の導関数係数などの係数がオーバーフローすることはありません。 このアルゴリズムは、文字またはトークンごとに一定量の作業のみを実行し、入力長に対して線形時間を与えます。

            output.append(term)

    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return output

 ## 特殊なケース

 最初のエッジ ケースは、単一の変数項です。 正確な入力のために`x`、ソースでは係数が省略されているため、パーサーが係数を割り当てます。`1`。 指数も省略されているため、指数を割り当てます`1`。 導関数は定数になります`1`、そしてアルゴリズムは出力します`1`。 

2 番目のエッジ ケースは、2 つの変数項の間の定数です。 のために`7x + 100 + 3x`、最初の項は生成します`7`、定数`100`はスキップされ、最後の項が生成されます。`3`。 結果は`7 + 3`。 出力用語は書式設定前に独立して保存されるため、定数を削除しても余分な区切り文字を残すことはできません。 

3 番目のエッジケースは減算です。 のために`5x^2 - 3x - 10`、最初の項は になります。`10x`、第2期は`-3`、最後の定数は消えます。 フォーマットされた結果は、`10x - 3`。 符号は項の前の演算子トークンから読み取られるため、項が変数式から定数に変化しても減算は保持されます。 

4 番目のエッジ ケースは、高次項の係数 1 です。 のために`x^5`、解析された係数は`1`そして指数は`5`、生産`5x^4`。 フォーマッタは意図的に係数を省略します`1`微分後にのみ出力されるため、出力は次のようになります。`5x^4`無効に見えるのではなく`5*1x^4`。 

5 番目のエッジ ケースは、非常に大きな指数です。 のために`300x^200`、計算は単純です`300 * 200 = 60000`そして新しい指数は`199`、生産`60000x^199`。 Python の任意精度の整数は、オーバーフローの問題なく係数を処理します。 

最後のエッジ ケースは、多くの項を含む長い多項式です。 このアルゴリズムは、前の文字を再スキャンして次の区切り文字を検索することはありません。`split()`トークンを 1 回識別し、各トークンが 1 回消費されるため、実行時間は入力の長さに比例して増加します。
