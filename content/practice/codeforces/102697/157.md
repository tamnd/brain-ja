## アプローチ

 直接的なアプローチは文字通り式に従います。 すべての項について、奇数の指数を計算します`2k+1`、計算します`x^(2k+1)`、計算します`(2k+1)!`、交互の符号を適用し、結果を加算します。 

これは、要求されたテイラー近似を定義する数式を正確に評価するため、正しいです。 問題は繰り返し作業です。 次の項の階乗には前の項の階乗のほぼすべてが含まれ、次のべき乗には前のべき乗のほぼすべてが含まれます。 

もし`k`-th 階乗は最初から再構築され、そのコストは次のように比例します。`k`。 横切って`n`およその条件を与える

 1+2+⋯+n= 2 n(n+1) 、

 それはΘ(`n²`) 算術演算。 能力を最初から再計算すると、追加の作業も発生します。 大型用`n`、この二次関数の動作は不要です。 

重要な観察は、2 つの連続するテイラー項が相互から直接取得できることです。 しましょう

 ## アルゴリズムのチュートリアル

 1. テイラー項の数を読み取る`n`そしてラジアン値`x`。 シリーズの第一期はいつも`x`ので、両方を初期化します`term = x`そして`answer = x`。 
2. 残りの期間ごとに、次を使用して現在の期間を更新します。 

T k+1 ＝−T k (2k+2)(2k+3) x 2 。 

今期がインデックスに該当する場合`k`、その分母は`(2k+1)!`。 次の奇数乗に移動すると、分子に次の値が乗算されます。`x²`そして階乗は`(2k+2)(2k+3)`。 マイナス符号は、正弦系列の交互の符号を表します。 
3. 新しく計算された項を`answer`。 この時点で`answer`正確に最初のものが含まれています`k+2`テイラー用語。 
4.その後`n-1`更新、印刷`answer`。 Python の組み込みへの呼び出しはありません`sin`この問題では実際の正弦値ではなくテイラー近似が特に求められるため、この関数が必要になります。 

### なぜ効果があるのか

 不変条件は、各反復の開始時に、`term`まさに最新のテイラーシリーズ用語です

 (−1) k (2k+1)! × 2k+1 .

 それを掛けると

 − (2k+2)(2k+3) × 2

 生成する

 (−1) k+1 (2k+3)! × 2k+3 、

 それはまさに次の学期です。 アルゴリズムは正しい最初の項から始まり、正しい次の項を繰り返し生成するため、累積合計は、通常の浮動小数点丸めまでの、要求された有限テイラー近似とまったく同じになります。 

## Python ソリューション```python
Pythonimport sysinput = sys.stdin.readline

def solve():    n = int(input())    x = float(input())
    term = x    ans = x    x2 = x * x
    for k in range(n - 1):        term *= -x2 / ((2 * k + 2) * (2 * k + 3))        ans += term
    print(ans)
