 ## 問題の理解

 タスクは最初のファイルを印刷することです`n`パスカルの三角形の行。 行`i`正確に含まれています`i`整数。 各行の最初と最後の値は次のとおりです。`1`, 一方、すべての内部値は、前の行のすぐ上の 2 つの値を加算することによって取得されます。 たとえば、最初の 4 行が構築された後、次の行は次のようになります。`1 4 6 4 1`。 

入力は 1 つの正の整数で構成されます`n`、出力には正確に含まれている必要があります`n`行、行あり`i`を含む`i`三角形のその行に属する値。 これは問題によって与えられる完全な仕様です。 公式声明では上限は定められていない`n`したがって、自然な制約は出力自体から生じます。`n`行は印刷が必要です`1 + 2 + ... + n = n(n+1)/2`整数。 受け入れられた解決策は、これらの整数を生成するだけで少なくとも Ω(n²) 時間を費やす必要があります。 

その出力下限により、作業が 3 次または指数関数的なアルゴリズムが即座に除外されます。`n`一度`n`適度に大きくなります。 二次アルゴリズムは、印刷する必要があるデータ量に一致するため、適切なターゲットです。 三角形全体を格納するのではなく、行を一度に 1 つずつ生成すると、メモリを線形に保つこともできます。

## アプローチ

 単純な総当たりソリューションでは、すべての値を二項係数として独立して計算できます。 行の値`r`は、ゼロベースのインデックスを使用すると、`C(r, k)`。 事前に計算された三角形に依存せずにそれを計算する 1 つの方法は、すべての係数の乗算式を個別に評価することです。 たとえ対称性が使用されているとしても、`k <= r/2`が計算されると、位置の係数が`k`Θ(k) の算術ステップが必要です。 すべての行にわたって、これは次のようになります`Σ(r=0..n-1) Σ(k=1..floor(r/2)) Θ(k) = Θ(n³)`、

 そのため、必要な出力には Θ(n²) 値のみが含まれる一方で、演算量は 3 次的に増加します。 このアプローチは数学的には正しいですが、隣接する係数が共有する可能性のある作業を繰り返します。 

有用な構造は、パスカルの三角形が局所再帰によってすでに定義されていることです。 1行`r - 1`行のすべての内部値が既知である`r`は、前の行の 2 つの隣接する値から取得されます。 これらの値を最初から再計算する必要はありません。 

現在の行を配列に保持できます。 次の行は次で始まり、次で終わります。`1`、それらの間のすべての位置は、現在の行の隣接する 2 つの要素の合計になります。 新しい行を印刷した後、それが次の反復の現在の行になります。 各行はその長さに比例した作業を必要とするため、すべての行の構築には Θ(n²) がかかり、出力する必要がある値の数と正確に一致します。 

各位置が実際には二項係数であるため、総当り攻撃は機能しますが、同じ情報が繰り返し再発見されるため失敗します。 隣接する行が単純な 2 値の反復によって接続されていることが観察されると、作業が避けられない出力サイズまで削減されます。

 ## アルゴリズムのチュートリアル

 1.読む`n`、印刷する必要がある行数。 反復ごとに正確に 1 行を生成するため、ループは必然的に必要な出力行に対応します。 
2. 前の空の行から開始します。 最初の行を生成する前は、その行の上に値はありません。 
3. 行の長さについて`length`から`1`を通して`n`、最初と最後の値が次のような新しい行を作成します。`1`。 これらは、すでに構築されている行の数に関係なく、常にパスカルの三角形の境界値です。 
4. すべての内部位置について、前の行の 2 つの隣接する値を加算します。 前の行が`[1, 3, 3, 1]`たとえば、次の行の内部は次のようになります。`1 + 3`、`3 + 3`、 そして`3 + 1`、与える`[1, 4, 6, 4, 1]`。 
5. 新しく作成された行を印刷し、前の行をその行で置き換えます。 次の行を構築するには直前の行のみが必要なため、古い行を保持するとメモリが無駄になります。 

### なぜ効果があるのか

 不変条件は、行を構築する直前の条件です。`i`、`previous`正確に行が含まれています`i - 1`パスカルの三角形の。 新しい行の場所`1`両方の境界で、三角形の定義と一致します。 すべての内部位置はそのすぐ上の 2 つの値の合計として計算されるため、各内部値も定義と一致します。 したがって、新しく構築された行は正確に行です`i`、そしてそれをに割り当てます`previous`次の反復のために不変式を復元します。 アルゴリズムは最初の行から始まり、行全体にわたってこの引数を繰り返すため`n`、印刷されたすべての行は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    previous = []

    for length in range(1, n + 1):
        if length == 1:
            current = [1]
        else:
            current = [1] * length

            for j in range(1, length - 1):
                current[j] = previous[j - 1] + previous[j]

        sys.stdout.write(" ".join(map(str, current)) + "\n")
        previous = current

if __name__ == "__main__":
    solve()
```の`previous`配列には、完成した行を 1 つだけ格納します。 最初の行については、特殊なケース`length == 1`作成します`[1]`。 以降の行ごとに、配列全体を次のように初期化します。`1`両方の境界を即座に処理します。 

ループオーバー`j`から始まります`1`そしてその前に止まります`length - 1`なぜなら、これらはまさに内部の位置だからです。 ポジションについて`j`、その上の 2 つの値は次のとおりです。`previous[j - 1]`そして`previous[j]`。 このインデックス付けは、実装における off-by-one の中心的な詳細です。 

印刷後、`previous = current`新しい行を次の反復で使用できるようにします。 前の行は必要ないため、アルゴリズムは 2 次元の三角形を構築しません。 

Python の整数は固定マシン幅ではオーバーフローしないため、固定幅の整数型を使用する言語で発生する整数オーバーフローの問題が回避されます。 値自体が大きくなる`n`は大きくなり、そのサイズは当然、印刷に必要な作業量に反映されます。 

使用する`sys.stdout.write`オーバーヘッドの高いメソッドを繰り返し呼び出すことを回避します`print`行ごとに関数を実行します。 入力には整数が 1 つだけ含まれているため、入力処理がボトルネックではない場合でも、標準の高速入力パターンで十分です。 

## 実用的な例

 ## 特殊なケース

 のために`n = 1`、アルゴリズムは次に入ります。`length == 1`ブランチとコンストラクト`[1]`。 すぐにその行を印刷して終了します。 アクセスしようとする試みはありません`previous[j]`したがって、空の前の行によってインデックス付けエラーが発生することはありません。 正確な出力は次のとおりです`1`。 

のために`n = 2`、最初の反復で生成されるのは`[1]`。 2 回目の反復で初期化します`[1, 1]`また、内部位置がないため、内部ループには反復がありません。 したがって、出力は次のようになります```
1
1 1
```これは、行にちょうど 2 つの要素が含まれる境界を処理します。 

のために`n = 3`、3行目は次のように始まります`[1, 1, 1]`。 唯一の内部位置はインデックスです`1`、これは次のように置き換えられます`previous[0] + previous[1] = 1 + 1 = 2`。 最後の行は次のようになります`[1, 2, 1]`、内部ループの境界にすべての内部要素が 1 回だけ含まれていることを確認します。 

サンプルについて`n = 5`、5 回目の反復で受信します。`[1, 3, 3, 1]`として`previous`。 3 つの内部値を次のように計算します。`1 + 3 = 4`、`3 + 3 = 6`、 そして`3 + 1 = 4`、2 つの境界値は残ったままになります。`1`。 結果はまさに`1 4 6 4 1`。 

次のような大きな入力の場合`n = 1000`の場合でも、アルゴリズムは前の行と現在の行のみを保存します。 生成される値の数は Θ(n²) ですが、すべてを出力する必要があるためこれは避けられません。 この実装は係数を再帰的に再計算したり三角形全体を保持したりしないため、その作業と補助メモリは意図した二次境界と線形境界に従います。
