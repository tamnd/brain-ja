 ## 解決策
 ## 問題の理解

 入力には 2 つの線形方程式が含まれており、それぞれがすでに傾き切片形式で記述されています。`y=mx+b`。 係数`m`は線の傾きであり、`b`線が y 軸と交差する場所のみを決定します。 タスクは、2 つの線が平行かどうかを判断して印刷することです。`PARALLEL`そうであれば、または`NOT PARALLEL`さもないと。 公式声明は、次のことを明示的に保証しています。`x`の前に表示されます`x`係数が次の場合を含む項`1`。 

2 本の非垂直線は、その傾きが等しい場合に正確に平行になります。 したがって、方程式については、`y=m1x+b1`そして`y=m2x+b2`、比較する必要がある唯一の値は`m1`対`m2`。 インターセプト`b1`そして`b2`線の方向には影響しません。 

この問題には大きな配列やグラフは隠されていません。 入力は正確に 2 つの方程式で構成されているため、係数がどれだけ大きいかに関係なく、計算量は一定です。 したがって、O(1) アルゴリズムには 1 秒の時間制限で十分です。 Python の整数は、係数が大きい場合にもオーバーフローを回避します。 

主な解析エッジ ケースは負の傾きです。 例えば：```
y=-8x+3
y=-8x+1
```正しい出力は次のとおりです。```
PARALLEL
```係数が正の数字のみで構成されていると想定する不注意なパーサーは、読み取りに失敗する可能性があります。`-8`正しく。 部分文字列を抽出する場合は、前にマイナス記号を含める必要があります。`x`。 

もう 1 つのエッジ ケースは、`1`:```
y=1x+5
y=1x-20
```正しい出力は次のとおりです。```
PARALLEL
```このステートメントでは特に許可されています`m=1`明示的に次のように書く`1x`したがって、パーサーは係数が省略されることを予期してはなりません。 

切片は、答えに影響を与えずに負の値になることもあります。```
y=7x-100
y=7x+200
```正しい出力は次のとおりです。```
PARALLEL
```方程式の傾きではなく完全な方程式を比較する解決策では、このケースは誤って拒否されてしまいます。 切片が異なるということは、単に 2 つの平行線が異なる位置にあることを意味します。 

最後に、方程式には非常に大きな係数が含まれる場合があります。 例えば：```
y=1000000000000000000x+7
y=1000000000000000000x-9
```答えはまだです`PARALLEL`。 浮動小数点演算の必要がないため、精度の問題はありません。 

## アプローチ

 文字通りの総当たり的なアプローチでは、2 つの直線上の点を調べることによって、2 つの直線が同じ方向を向いているかどうかを判断しようとします。 たとえば、次の多くの値を選択できます。`x`、対応するを計算します`y`両方の線の値を調べて、2 つのグラフが一定の垂直距離にあるかどうかを推測してみます。 問題は、ラインに無限に多くの点が含まれるため、リテラル検索では最悪の場合の演算数が有限であることです。 たとえ一定数の x 値の後で任意に停止したとしても、それは線が平行であるという数学的な証明にはなりません。 

この強引なアイデアは、傾斜そのものではなく傾斜の影響を調べているため失敗します。 方程式はすでに正確な傾きを直接示しています。 で`y=mx+b`、`m`は線の方向であり、平行線はまったく同じ方向を持ちます。 この観察により、問題全体が直前の係数の抽出に帰着します。`x`各式からこれら 2 つの整数を比較します。 

入力文字列が 2 つだけであるため、解析作業はそれらの文字列の長さに比例します。 入力文字列に長さがある場合`L`の場合、実行時間は O(L) であり、この問題では事実上一定です。 このアルゴリズムは、2 つの入力文字列とは別に O(1) 個の追加スペースを使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 無制限 | お(1) | 遅すぎる / 有限アルゴリズムではない |
 | 最適 | O(L)、L は入力の長さ | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの方程式を文字列として読み取ります。 入力は次のような方程式としてフォーマットされているため、文字列として保持します。`y=-8x+3`、空白で区切られた一連の整数としてではありません。 
2. キャラクターの位置を見つける`x`それぞれの式で。 最初の間のすべて`y=`そして`x`斜面です。 
3. 抽出された部分文字列を整数に変換します。 パイソンの`int`は正と負の係数の両方を正しく処理するため、次のような文字列`17`そして`-8`は対応する整数の傾きになります。 
4. 2 つの傾きを比較します。 それらが等しい場合、2 つの方程式は同じ方向の直線を表すため、次のように出力します。`PARALLEL`。 それ以外の場合は、印刷します`NOT PARALLEL`。 

### なぜ効果があるのか

 次のように書かれた行の場合`y=mx+b`、係数`m`その傾きです。 この形の 2 本の線は、傾きが等しい場合に正確に平行になります。 このアルゴリズムは、両方の方程式からこの係数を正確に抽出し、変更したり近似したりすることなく比較します。 切片は変更されるため意図的に無視されます。`b`線を垂直方向に移動しますが、方向は変更しません。 したがって、アルゴリズムは次のように出力します`PARALLEL`問題が必要とするケースに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def slope(equation):
    x_pos = equation.index('x')
    return int(equation[2:x_pos])

def main():
    line1 = input().strip()
    line2 = input().strip()

    m1 = slope(line1)
    m2 = slope(line2)

    if m1 == m2:
        print("PARALLEL")
    else:
        print("NOT PARALLEL")

if __name__ == "__main__":
    main()
```の`slope`関数で検索する`x`, このステートメントは、次の係数が保証されていることを保証しているため、`x`その文字の前に表示されます。 接頭語`y=`地位を占める`0`そして`1`、 それで`equation[2:x_pos]`正確に傾きが含まれています。 

使用する`int`浮動小数点変換ではなく、意図的に変換されます。 指定された形式の傾きは整数係数として表され、整数比較は正確です。 2 つの正確な係数が等しいかどうかだけを問う問題に浮動小数点の丸めを導入する理由はありません。 

比較は両方の勾配が抽出された後に行われます。 切片は並列処理に影響を与えることができないため、解析されません。 の`.strip()`呼び出しでは、標準入力から読み取られた改行が削除されますが、改行は後に表示されるため、部分文字列の抽出はそれなしでも機能します。`x`したがって、勾配には入りません。 

## 実用的な例

 ### サンプル 1

 入力は次のとおりです。```
y=17x+12

```実行は次のように要約できます。 

| 方程式 | の位置`x`| 抽出された傾き | 現在の比較 |
 | --- | --- | --- | --- |
 |`y=17x+12`| 5 | 17 | 最初の傾き = 17 |
 |`y=2x+21`| 4 | 2 | 17 != 2 |

 傾きが異なるため、線の方向が異なり、平行ではなく交差します。 プログラムは印刷します`NOT PARALLEL`。 

### サンプル 2

 入力は次のとおりです。```
y=-8x+3

```実行は次のとおりです。 

| 方程式 | の位置`x`| 抽出された傾き | 現在の比較 |
 | --- | --- | --- | --- |
 |`y=-8x+3`| 5 | -8 | 最初の傾き = -8 |
 |`y=-8x+1`| 5 | -8 | -8 == -8 |

 切片は異なりますが、両方の直線に傾きがあります`-8`。 それらの方向は同一であるため、プログラムは次のように出力します。`PARALLEL`。

## テストケース```python
import sys
import io

def solve(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        line1 = sys.stdin.readline().strip()
        line2 = sys.stdin.readline().strip()

        def slope(equation):
            x_pos = equation.index('x')
            return int(equation[2:x_pos])

        m1 = slope(line1)
        m2 = slope(line2)

        if m1 == m2:
            print("PARALLEL")
        else:
            print("NOT PARALLEL")

        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample 1
assert solve(
    "y=17x+12\n"
    "y=2x+21\n"
) == "NOT PARALLEL\n", "sample 1"

# Provided sample 2
assert solve(
    "y=-8x+3\n"
    "y=-8x+1\n"
) == "PARALLEL\n", "sample 2"

# Minimum-size input with the smallest useful slope values
assert solve(
    "y=1x+0\n"
    "y=1x+1\n"
) == "PARALLEL\n", "slope 1"

# Different slopes with negative values
assert solve(
    "y=-1x+100\n"
    "y=1x-100\n"
) == "NOT PARALLEL\n", "opposite slopes"

# Very large coefficients
assert solve(
    "y=1000000000000000000x+7\n"
    "y=1000000000000000000x-9\n"
) == "PARALLEL\n", "large integer coefficients"

# Negative slope and different intercept
assert solve(
    "y=-123456789x-999\n"
    "y=-123456789x+888\n"
) == "PARALLEL\n", "negative slope with negative intercept"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`y=1x+0`、`y=1x+1`|`PARALLEL`| 最小サイズの入力と明示的な傾き`1`|
 |`y=-1x+100`、`y=1x-100`|`NOT PARALLEL`| 負の傾きと反対方向 |
 |`y=1000000000000000000x+7`、`y=1000000000000000000x-9`|`PARALLEL`| オーバーフローのない大きな整数の係数 |
 |`y=-123456789x-999`、`y=-123456789x+888`|`PARALLEL`| 負の傾き、負の切片、および等しい傾き |

 ## 特殊なケース

 負の傾きの場合は、次のことを考慮してください。```
y=-8x+3
y=-8x+1
```最初`x`後に発生します`y=-8`、したがって、抽出された部分文字列は次のようになります`-8`。 2 番目の方程式は同じ整数を生成します。 比較は成功し、出力は次のようになります。`PARALLEL`。 これにより、誤ってマイナス記号を破棄するパーサーが捕捉されます。 

明示的な傾きの場合、`1`、 考慮する：```
y=1x+5
y=1x-20
```前の部分文字列`x`は`1`両方の方程式で。 このアルゴリズムは係数を特殊化しないため、自然に次のように生成されます。`PARALLEL`。 これは入力形式に従い、明示的に保持されます。`1`前に`x`。 

さまざまな切片については、次のことを考慮してください。```
y=7x-100
y=7x+200
```抽出された傾きは両方とも`7`。 アルゴリズムは切片を決して読み取らないため、次のように出力します。`PARALLEL`。 幾何学的には、2 つの線は同じ方向を持ち、互いにずれています。 

係数が非常に大きい場合は、次のことを考慮してください。```
y=1000000000000000000x+7
y=1000000000000000000x-9
```両方の傾斜部分文字列は同じ Python 整数に変換されます。 Python の整数には任意の精度があるため、比較は正確なままであり、出力は次のようになります。`PARALLEL`。 このアルゴリズムは乗算や除算を実行しないため、数値のオーバーフローを考慮するよりも実装が簡単になります。 

それ以外は同様の方程式を持つ異なる傾きについては、以下を考慮してください。```
y=-1x+100
y=1x-100
```抽出された値は、`-1`そして`1`。 それらが異なるため、出力は次のようになります。`NOT PARALLEL`。 これは、アルゴリズムが符号付き傾きの絶対値を単に比較するのではなく、符号付き傾きを比較していることを確認します。
