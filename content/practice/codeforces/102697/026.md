 ## 解決策
 ## 問題の理解

 これは入門的な入出力問題です。 プログラムは競技規則を含む 1 行を受け取ります。その唯一の仕事は、固定見出しとその後にまったく同じ規則行を出力することです。 見出しは次のようにする必要があります`Competition Rules:`元の入力は次の行に変更されずに表示される必要があります。 公式声明では、意図した解決策は単純に行を読み取り、見出しと入力を別の行に出力することであることが確認されています。 

アルゴリズムの選択を変更する数値的な制約はありません。 入力行に (L) 文字が含まれている場合、すべての入力文字を少なくとも 1 回処理または出力する必要があるため、読み取りと書き込みには (O(L)) 時間がかかります。 行が Python 文字列として保存されている場合、メモリ使用量は (O(L)) です。 大きな数値パラメータや入れ子構造がないため、ここでは並べ替え、動的プログラミング、グラフ走査、総当たり検索などのアルゴリズムは役に立ちません。 

主なエッジケースは空のルール行です。 例えば、```

```競技規則として空の文字列が含まれています。 正しい出力は次のとおりです```
Competition Rules:
```を呼び出す不用意な実装`strip()`そして、表示されるテキストが存在する必要があると想定し、誤って入力を変更したり、2 行目を省略したりする可能性があります。 最も安全な方法は、行全体を読み取り、その内容を変更せずに印刷することです。 

もう 1 つの簡単な間違いは、ルール内の空白を変更することです。 たとえば、```
Use 2 spaces here.
```正しい出力は```
Competition Rules:
Use 2 spaces here.
```入力を単語に分割し、それらを再度結合するソリューションは、複数のスペースを静かに 1 つに変えることができます。 ルールを解析する理由はないため、行全体を不透明なテキストとして扱うことで、この問題を回避できます。 

## アプローチ

 最も直接的なアプローチは、1 つの入力行を読み取り、必要な見出しを出力し、その後にその行を出力することです。 出力は入力によって完全に決定されるため、この問題に対して意味のある組み合わせ総当たりアルゴリズムはありません。 

これを意図的に非効率的な実装と対比したい場合は、連結を繰り返して、入力を一度に 1 文字ずつ成長する Python 文字列にコピーしたとします。 長さ (L) の行の場合、蓄積された文字列は追加のたびにコピーされ、おおよその結果が得られます。 

[
 1 + 2 + 3 + \dots + L = \frac{L(L+1)}{2}
 】

 最悪の場合、文字コピー操作。 タスクでは (L) 文字の再現のみが必要ですが、つまり (O(L^2)) です。 

出力する必要のあるテキストが入力にすでに正確に含まれていることがわかり、すべての変換作業が不要になります。 行全体を 1 つの文字列として保持し、直接出力できます。 したがって、最適解は線形作業のみを実行します。これは、出力自体に (L) 個の入力文字が含まれるため、自然な下限でもあります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 繰り返しの文字列構築 | O(L²) | O(L) | 不必要に遅い |
 | 直接読み取りと印刷 | O(L) | O(L) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 競技規則を含む 1 行を読みます。 スペースを含むすべての文字が必要な出力に属しているため、行を分割せずにテキストとして保持します。 
2. 固定文字列を出力する`Competition Rules:`。 これは入力とは独立しており、常に最初の出力行を占有します。 
3. 入力行を読み取られたとおりに正確に出力します。 改行はすでに消費されています`readline()`印刷前に削除されるため、`print()`余分な空白行は作成されません。 

### なぜ効果があるのか

 入力は 1 つのルール行で構成され、必要な出力は固定見出しと同じルール行の 2 行で構成されます。 このアルゴリズムは、固定の最初の行を印刷し、保存されている入力テキストを 2 行目として正確に印刷します。 ルールには変換が適用されないため、保持する必要があるすべての文字は変更されず、生成される出力は必要な形式と一致します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    rules = input().rstrip('\n')
    print("Competition Rules:")
    print(rules)

def run(inp: str) -> str:
    global input

    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()
    input = sys.stdin.readline

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

# Provided sample
assert run("This is a competition rule\n") == (
    "Competition Rules:\n"
    "This is a competition rule\n"
), "sample 1"

# Empty rules line
assert run("\n") == (
    "Competition Rules:\n"
    "\n"
), "empty rules"

# Repeated spaces
assert run("Rules  contain   extra spaces\n") == (
    "Competition Rules:\n"
    "Rules  contain   extra spaces\n"
), "preserve spaces"

# Leading and trailing spaces
assert run("  padded rules  \n") == (
    "Competition Rules:\n"
    "  padded rules  \n"
), "preserve boundary spaces"

long_rules = "A" * 100000
assert run(long_rules + "\n") == (

), "large input line"
