 ## 解決策
 ## 問題の理解

 3 つの整数辺の長さが与えられています。`a`、`b`、 そして`c`。 タスクは、これら 3 つのセグメントが非縮退三角形の辺になり得るかどうかを決定することです。 必要な出力は次のとおりです`VALID`このような三角形を形成できたとき、`INVALID`さもないと。 公式問題では 1 つのテスト ケースが使用され、テスト ケースの数はありません。 

3 つの正の辺の長さの場合、三角形不等式は、すべての辺が他の 2 つの辺の合計よりも厳密に短くなければならないことを示します。`a + b > c`、`a + c > b`、 そして`b + c > a`。 

入力はわずかです。数値がちょうど 3 つあるため、一定数の算術演算でも十分です。 大きいものは無い`n`これにより、二次アルゴリズムまたは三次アルゴリズムが適切になります。 したがって、1 秒の時間制限と 256 MB のメモリ制限は必要以上に寛大です。 

不用意に実装すると、平等に失敗する可能性があります。 たとえば、```
1 2 3
```答えは```
INVALID
```なぜなら`1 + 2 = 3`。 これら 3 つのセグメントは直線のみを形成でき、非縮退三角形は形成できません。 使用する`>=`の代わりに`>`間違った方向に進むと、誤ってこのケースを受け入れる可能性があります。 

もう 1 つのエッジケースは、明らかに支配的な側です。```
1 5 1
```答えは```
INVALID
```なぜなら`1 + 1 < 5`。 2 つの短い辺は、形状を閉じるのに十分な距離まで到達できません。 これは最初の公式サンプルです。 

等しい辺は、その長さが正の場合には完全に有効です。 例えば、```
5 5 5
```生成する```
VALID
```すべてのペアの合計は`10`、残りの辺より厳密に大きくなります。 3 つの長さがすべて異なるはずだと仮定する解決策は正しくありません。 

## アプローチ

 最も直接的なアプローチは、定義を文字通りに確認することです。 3 つの三角形不等式をすべて評価します。`a + b > c`、`a + c > b`、 そして`b + c > a`、 3 つすべてが true の場合は正確に受け入れます。 これは正しいです。非縮退三角形を形成するには、3 つの正の長さに対して三角形不等式が必要かつ十分であるためです。 最悪のケースでは、正確に 3 回の加算と 3 回の比較が実行され、その後に一定量のブール ロジックが実行されます。 

最大の側のみをチェックする必要があることに注目すると、同じ推論をさらに単純化できます。 3 つの長さが次のようにソートされているとします。`x <= y <= z`。 以来`z`が最大の辺である場合、潜在的に困難な不等式は`x + y > z`。 他の 2 つの不等式は自動的に真になります。`z >= y`そして`z >= x`、すべての辺の長さは正です。 したがって、問題は、最大の辺を見つけて、他の 2 つの辺の和が厳密にそれよりも大きいかどうかをチェックすることになります。 

値が 3 つしかないため、並べ替えにも一定の時間がかかります。 Python では、3 つの整数のソートは実質的に一定の作業であり、結果として得られるコードはコンパクトで、順序付けミスが起こりにくいものになります。 

ブルートフォースアプローチと最適アプローチには次のようなコストがかかります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(1) | お(1) | 承認済み |
 | 最適 | お(1) | お(1) | 承認済み |

 ここでの区別は、漸近的な複雑さに関するものではありません。 どちらのアプローチも簡単に十分に高速です。 最適化された公式は、三角不等式の数学的構造を明らかにし、3 つの別々の条件を 1 つに減らすため、推奨されます。 

## アルゴリズムのチュートリアル

 1. 3辺の長さを読み取ります。`a`、`b`、 そして`c`。 テスト ケースは 1 つだけであるため、外部のテスト ケース ループは必要ありません。 
2. 3 つの長さのうち最大のものを見つけて、それを呼び出します`z`。 残りの2つの長さは、`x`そして`y`。 
3. かどうかを確認します。`x + y > z`。 これは、辺が順序付けされると失敗する可能性がある唯一の三角不等式です。`z`満足させるのが最も難しい側面です。 
4. 印刷`VALID`不等式が真の場合。 それ以外の場合は印刷します`INVALID`。 等価では三角形ではなく縮退した直線が作成されるため、比較は厳密でなければなりません。 

### なぜ効果があるのか

 側面を注文した後、`x <= y <= z`、小さい辺を含む 2 つの不等式を考えます。 以来`x`そして`y`ポジティブです、`y + z > x`は自動的に真になります。`z >= x`そしてポジティブなことを追加します`y`左側を厳密に大きくします。 同様に、`x + z > y`は自動的に真になります。`z >= y`そして`x`はポジティブです。 右辺に最大の辺を含む唯一の不等式は、`x + y > z`。 したがって、この 1 つの条件をチェックすることは、3 つの三角形不等式をすべてチェックすることと同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, b, c = map(int, input().split())

x, y, z = sorted((a, b, c))

if x + y > z:
    print("VALID")
else:
    print("INVALID")
```入力行は次のように読み取られます`input`、入力が 3 つの整数のみであっても、必要な高速 I/O パターンに従います。`map(int, ...)`3 つのトークンを直接整数に変換します。 

農産物の仕分け`x <= y <= z`、それは`z`一番大きな面。 したがって、自明でない唯一の条件は次のとおりです。`x + y > z`。 

厳格な`>`比較することが不可欠です。 と`1 2 3`、式は次のようになります`1 + 2 > 3`これは false であり、正しく生成されます。`INVALID`。 使用する`>=`縮退三角形を誤って受け入れてしまいます。 

Python の整数はオーバーフローしないため、加算は`x + y`非常に大きな整数入力でも安全です。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    a, b, c = map(int, sys.stdin.readline().split())
    x, y, z = sorted((a, b, c))

    if x + y > z:
        print("VALID")
    else:
        print("INVALID")

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return result

## 特殊なケース

 平等の場合`1 2 3`値をソートすることで処理されます。`1, 2, 3`そしてテスト`1 + 2 > 3`。 2 つの辺が 3 番目の辺と等しいだけであるため、この比較は誤りです。 プログラムは印刷します`INVALID`、縮退した形状を正しく拒否します。 

ドミナントサイドの場合`1 5 1`になる`1, 1, 5`。 アルゴリズムは計算します`1 + 1 = 2`、 それで`2 > 5`は false であり、出力されます`INVALID`。 最大の辺がすでにわかっているため、他の 2 つの不等式について個別にチェックする必要はありません。 

すべてが等しい場合`5 5 5`、並べ替えても何も変わりません。 アルゴリズムチェック`5 + 5 > 5`、それは正しいので、答えは次のようになります。`VALID`。 長さが等しいことは特別な障害状態ではありません。 

入力`4 5 6`は有効なケースを示しています。 並べ替えた後、`4 + 5 = 9`、 そして`9 > 6`が成立する。 アルゴリズムは出力します`VALID`、残りの不平等は次の事実によって保証されます。`6`が最大のプラス面です。 

最後に、側面のある大きな入力`10^18`、`10^18`、 そして`1999999999999999999`有用な境界チェックを提供します。 小さい辺の合計は正確に`2000000000000000000`、これは最大の隣り合うものより大きい`1`したがって、出力は次のようになります`VALID`。 Python の任意精度の整数により、特別なオーバーフロー処理を行わずに計算が安全になります。
