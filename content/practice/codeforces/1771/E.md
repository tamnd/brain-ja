 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、`n × m`ホッサムの地面を表すグリッド。 各セルには品質があります: 完璧 (`.`）、 中くらい （`m`)、または悪い (`#`）。 ホッサムは、いくつかのセルに壁を配置して文字「H」を描きたいと考えています。 文字は2本の縦線と、それを結ぶ1本の横線で構成されています。 垂直線は同じ列または隣接する列にあってはなりません。 これらは同じ行で開始および終了する必要があり、水平線は垂直線の最上行と最下行の間に厳密に存在する必要があります。 不良セルには壁を配置できません。使用できるのは最大でも 1 つの中セルです。 

課題は、文字「H」を形成するように配置できる壁の最大数を見つけることです。 手紙を描くことが不可能な場合、私たちは戻らなければなりません`0`。 

制約`n, m ≤ 400`総演算数は約 2.5 × 10^7 であり、2 秒の制限時間内では許容できるため、O(n^2 m^2) アルゴリズムが妥当であると示唆しています。 ただし、O(n^3 m^3) では遅すぎます。 

明らかではないエッジ ケースには、間に少なくとも 1 つの列がある 2 本の垂直線を収めることができないグリッドが含まれます。 たとえば、完全なセルで完全に埋められた 2×2 グリッドは、垂直線が隣接する列になければならないため、有効な「H」を保持できません。 もう 1 つの微妙なケースは、中セルが 1 つだけ存在する場合に発生します。 壁の数を最大化しながら、培地セルの割り当てを決して超過しないようにする必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 考えられるすべての列のペアを反復処理します。`(c1, c2)`縦のラインに。 各ペアについて、垂直線のすべての可能な開始行と終了行を繰り返します。 次に、それらの間にある考えられる各行について、それを水平線の位置とみなします。 中セルの制約を尊重しながら、選択した長方形内の壁の数を数えます。 このアプローチは有効な構成をすべて列挙するので正しいですが、最悪の場合でも O(n^3 m^2) であり、n = m = 400 にとっては遅すぎます。 

最適化するための重要な洞察は、中/不良の制約に違反することなく、各列に構築できる最大垂直線の長さを事前計算できることです。 また、培地細胞の位置も追跡します。 垂直線の長さがわかったら、列のすべてのペアを反復し、2 つのポインターを使用して水平線を配置できる最大の垂直セグメントを見つけ、水平線が禁止された方法で中/不良セルを横切っていないかどうかを確認します。 列ごとのプレフィックスの合計を事前に計算すると、任意のセグメントの O(1) 内の中間/​​不良セルをクエリできるようになります。 これにより、複雑さが O(n m^2) に軽減され、指定された範囲では許容可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3 m^2) | O(nm) | 遅すぎる |
 | 最適化されたプレフィックス + 列のペア | O(n m^2) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各列について 2 つの配列を事前計算します: プレフィックスの合計を使用して、各行までの完全セルと中間セルの数。 これにより、任意の垂直セグメントに対して O(1) クエリを実行して、中程度のセルまたは不良セルがいくつ存在するかを確認できます。 
2. 各列について、不良セルを含まず、最大で 1 つの中程度のセルを含むすべての可能な行から始まる連続する垂直線の最大長を決定します。 これを列長の配列として保存します。 
3. 列のすべてのペアを反復処理します。`(c1, c2)`どこ`c2 - c1 ≥ 2`垂直線が隣接していないことを確認します。 
4. 特定のペアについて、2 つのポインターを使用して行上をスライドさせ、最大の垂直セグメントを見つけます。`[r1, r2]`これは、中セル制限の下では両方の列で有効です。 
5. 垂直セグメントの候補ごとに、可能性のある水平線の位置を厳密に反復します。`r1`そして`r2`。 壁の総数を数えます:`length_vertical1 + length_vertical2 + length_horizontal`。 「H」全体で使用される培地セルが 1 つだけであることを確認してください。 
6. すべての柱ペアと垂直セグメントにわたって見つかった壁の最大合計を記録します。 

**機能する理由:** このアルゴリズムでは、考えられるすべての列のペアと実行可能なすべての垂直セグメントが考慮されますが、プレフィックスの合計により、メディア セルの制約が正しく尊重されることが保証されます。 垂直セグメント内の水平線のみをスキャンすることにより、「H」の幾何学的制約が尊重されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
grid = [input().strip() for _ in range(n)]

# Precompute prefix sums of medium and bad cells for each column
medium = [[0]*m for _ in range(n+1)]
bad = [[0]*m for _ in range(n+1)]

for r in range(1, n+1):
    for c in range(m):
        medium[r][c] = medium[r-1][c] + (grid[r-1][c] == 'm')
        bad[r][c] = bad[r-1][c] + (grid[r-1][c] == '#')

def get_counts(col, r1, r2):
    mids = medium[r2+1][col] - medium[r1][col]
    bads = bad[r2+1][col] - bad[r1][col]
    return mids, bads

max_walls = 0

for c1 in range(m):
    for c2 in range(c1+2, m):
        r1 = 0
        r2 = 0
        while r1 < n:
            # extend r2 as far as possible
            while r2 < n:
                mids1, bads1 = get_counts(c1, r1, r2)
                mids2, bads2 = get_counts(c2, r1, r2)
                if bads1 > 0 or bads2 > 0 or mids1 + mids2 > 1:
                    break
                r2 += 1
            # consider horizontal line positions between r1+1 and r2-2
            if r2 - r1 >= 3:
                # total vertical walls
                vertical_walls = (r2 - r1) * 2
                # horizontal line
                for hr in range(r1+1, r2-1):
                    h_meds = 0
                    h_bads = 0
                    for hc in range(c1+1, c2):
                        if grid[hr][hc] == '#':
                            h_bads = 1
                            break
                        if grid[hr][hc] == 'm':
                            h_meds += 1
                    if h_bads or mids1 + mids2 + h_meds > 1:
                        continue
                    total = vertical_walls + (c2 - c1 - 1)
                    max_walls = max(max_walls, total)
            r1 += 1
            if r2 < r1:
                r2 = r1

print(max_walls)
```このソリューションでは、まずプレフィックスの合計を計算して、中程度のセルと不良セルに対する定時間クエリを可能にします。 次に、行に対して 2 ポインター アプローチを使用して列のペアを反復処理し、制約に違反することなく最大の垂直セグメントを見つけます。 実行可能な垂直セグメントごとに、すべての有効な水平線がチェックされ、中セルの総数が 1 を超えないことが保証されます。 水平線の位置を慎重に処理することで、無効な位置にある壁をカウントすることを回避できます。
