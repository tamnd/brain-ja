 ## 解決策
 ## 問題の理解

 非降順でソートされた整数の配列が与えられているので、前のすべての要素の合計と等しくなる要素が存在しないように要素を再配置する必要があります。 そのような再配置が不可能な場合は、それを報告する必要があります。 入力は複数のテスト ケースで構成され、それぞれに配列の長さとその要素が含まれます。 出力は「NO」または「YES」のいずれかで、その後に美しいアレンジが続きます。 

制約は小さく、配列の長さです。$n$は最大 50、要素値は 1 ～ 100 です。$t \le 2000$、たとえ$O(n^2)$ソリューションは効率的に実行されるため、$n^2 \cdot t \le 5 \cdot 10^6$操作。 

すべての要素が等しい場合、特に次の場合に重要なエッジ ケースが発生します。$n = 2$2 番目の要素は常に、前のすべての要素の合計と等しいためです。 たとえば、$a = [10, 10]$、どのような順列でも 2 番目の要素が最初の要素と同じになるため、美しくすることは不可能になります。 もう 1 つのエッジ ケースは、小さい要素の合計が最大の要素に等しい場合です。これは、次のような配列で発生する可能性があります。$[1, 2, 3]$素朴に並べ替えると。 単に配列をソートしたままにする不注意な実装は、醜い配列を作成する危険があります。 

## アプローチ

 ブルートフォースアプローチは、配列のすべての順列を試して、それが美しいかどうかを確認することです。 長さの配列をチェックする$n$かかります$O(n)$、しかし、あります$n!$順列。 のために$n = 50$、入力制限が小さい場合でも、これは実行不可能です。$50!$天文学的に大きいです。 

重要な観察は、ソートされた配列内の以前のすべての要素の合計と一致する可能性があるのは、最大の要素のみであるということです。 最大の要素を最後に配置し、残りの要素をその前に配置すると、それまでのすべての要素の合計が最大化され、最大の要素と等しくなる可能性が高くなります。 これを回避するには、最大の要素を最初に配置して、以前の合計がそれに一致しないようにするか、配列を非昇順に並べ替えることができます。 降順で並べ替えると、すべての要素が等しい配列の場合を除き、任意の位置の前のすべての要素の合計が現在の要素よりも厳密に大きくなることが保証されます。 すべての要素が等しい場合、$n > 1$の場合、次の場合に限り、2 番目の要素は常に前の要素の合計と等しくなります。$n = 2$そしてその値が繰り返されます。 これにより、降順でソートし、最初の 2 つの要素をチェックするという、シンプルで安全な再配置戦略が得られます。 それらが等しく、配列に要素が 2 つしかない場合は、NO を出力します。 それ以外の場合は、再配置された配列を出力します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n) | O(n) | 遅すぎる |
 | 降順ソート | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして配列$a$。 
3. 配列をソートする$a$降順で。 これにより、右に行くにつれて合計が増加するため、各要素がその前のすべての要素の合計と等しくないことが保証されます。 
4. 次のことを確認します。$n = 2$そして 2 つの要素は等しいです。 そうであれば、「NO」と出力してください。 これは、2 番目の要素が常に最初の要素と等しいという、不可能な特殊なケースを処理します。 
5. それ以外の場合は、YES に続いてソートされた配列を出力します。 配列が降順でソートされている場合、プレフィックスの合計が現在の要素と等しくなることはないため、これにより美しい配列が保証されます。 

機能する理由: より大きな要素を最初に配置すると、些細な不可能な場合を除いて、接頭辞の合計は常に次の要素より小さくなります。 降順により、要素がその前の要素の合計と等しくなるリスクが排除され、唯一の例外 (2 つの等しい数値) が明示的に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def make_beautiful():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort(reverse=True)
        if n == 2 and a[0] == a[1]:
            print("NO")
        else:
            print("YES")
            print(" ".join(map(str, a)))

if __name__ == "__main__":
    make_beautiful()
```コードは最初にテスト ケースの数を読み取ります。 構成が醜くなるのを防ぐために、各配列は降順にソートされます。 2 つの等しい数値という特殊なケースは明示的に処理されます。 配列を文字列として出力すると、出力形式が問題の要件に一致することが保証されます。 所定の位置で並べ替えると、メモリのオーバーヘッドが軽減されます。

 ## 特殊なケース

 このアルゴリズムは、2 つの等しい要素を持つ配列を明示的に処理しますが、これを美しくすることは不可能です。 降順でソートするとプレフィックスの合計が等しくなることが回避されるため、等しい要素が 2 つ以上ある配列は安全です。 単一要素の配列は制約により許可されません。 最大の要素が小さな要素の合計と等しい配列は、降順で自動的に固定されます。 例えば、`[1, 2, 3]`になる`[3, 2, 1]`, 真ん中の醜い合計を避けます。 それぞれのエッジ ケースは、並べ替えと 2 要素のチェックによって考慮されます。
