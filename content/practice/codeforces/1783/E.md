## アプローチ

 最も直接的なアプローチは、考えられるすべてのことをテストすることです`k`。

ボスにパラメータがあるとします。`(a,b)`。

興味深いケースは、`b < a`。 

させて```
ceil(a / k)
```試行に到達するために必要な Monocarp ブロックの数になります`a`、同様に```
ceil(b / k)
```ポリカープ用。 

これら 2 つの値が異なる場合は、より少ないブロックを必要とする方が最初に強制終了の試行に達します。 

以来`b < a`、私たちはいつも持っています```
ceil(b/k) ≤ ceil(a/k)
```Monocarp が勝つことができる唯一の方法は、両方の数量が等しい場合です。 その後、同じブロックのペアの間に殺害の試みに達し、Monocarp のブロックが最初になります。 

したがって、上司の場合、`b < a`、Monocarp が正確に勝つのは$$\left\lceil \frac{a}{k} \right\rceil = \left\lceil \frac{b}{k} \right\rceil.$$ここからは重要な単純化です。 

整数の場合`x`、値`ceil(x/k)`変更されるのは次の場合のみです`k`特定の約数を超えます。 すべての良い点を明示的に見つけるのではなく、`k`、すべての悪い間隔をマークします。 

それを観察してください$$\left\lceil \frac{a}{k} \right\rceil > \left\lceil \frac{b}{k} \right\rceil$$まさに次の倍数が存在するとき`k`狭間に横たわっている`[b, a-1]`。 

確かに、いくつかの複数の場合`m = t·k`満足する$$b \le m < a,$$それから`b`そして`a`異なる天井ブロックに属し、異なる天井値を生成します。 

同様に、`k`の倍数の場合は不良です`k`にある`[b,a-1]`。 

繰り返す代わりに`k`、すべての不良間隔を処理します`[b,a)`差分配列を使用します。 これにより非常にコンパクトになります`O(n log n)`スタイル ソリューション。次のように実装されます。`O(n log n)`倍数による高調波加算。 公式のソリューションでは、間隔のカウントによってさらにエレガントに表現されています。

 ## アルゴリズムのチュートリアル

 ### 条件の導出

 上司の場合`b < a`, の倍数が存在する場合、Monocarp は負けます。`k`内部：$$[b,\;a)$$なぜならその時は$$\left\lceil \frac{a}{k}\right\rceil > \left\lceil \frac{b}{k}\right\rceil.$$したがって、そのような上司はそれぞれ、次のすべての価値観を禁止します。`k`その間隔内に少なくとも 1 つの倍数があること。 

### 差分配列の再定式化

 しましょう`dx[x]`間隔を何回数えるか`[b,a)`ポイントが含まれている`x`。 

すべての上司に対して`b < a`:```
dx[b] += 1
dx[a] -= 1
```プレフィックスの合計を計算した後、```
dx[x]
```整数点をカバーする不良間隔の数に等しい`x`。 

### k の値を確認する

 値`k`禁止された間隔に次の倍数が含まれていない場合に有効です。`k`。 

の倍数`k`は：```
k, 2k, 3k, ...
```複数あれば`mk`禁止された範囲内にある場合、`dx[mk] > 0`。 

したがって、次のようになります。```
k is valid
⇔ dx[mk] = 0 for every multiple mk of k
```### アルゴリズム

 1. 差分配列を作成する`dx`サイズの`n+1`。 
2. すべての上司に対して:

 もし`b[i] < a[i]`、間隔を追加します`[b[i], a[i])`差分配列に入れます。 
3. 次のようにプレフィックスの合計を計算します。`dx[x]`カバーする間隔の数になります`x`。 
4. あらゆる人にとって`k`から`1`に`n`:

 次の倍数をすべてチェックしてください`k`。 

すべての倍数が満たされる場合`dx[multiple] = 0`、 それから`k`は有効な答えです。 
5. 有効な値をすべて出力します。 

### なぜ効果があるのか

 すべての上司に対して`b < a`、間隔`[b,a)`の倍数が存在する位置を正確に表します`k`別れるだろう`b`そして`a`さまざまな天井ブロックに分割します。 そのような複数が存在するときはいつでも、ポリカルプはより早く殺害の試みに到達し、モノカルプはそのボスを失います。 

prefix-sum 配列には、整数点ごとに、その整数点に含まれる損失間隔の数が格納されます。 の倍数`k`負け区間内にあることは、Monocarp を倒すボスと同等です。 

すべての倍数をチェックする`k`損失間隔に次の倍数が含まれないことを保証します。`k`。 したがって、すべてのボスは Monocarp によって勝利されます。 逆に、いくつかの倍数が負け区間にある場合、そのボスは負けます。 特性評価は正確であるため、アルゴリズムはすべての有効な値を正確に返します。`k`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))

        dx = [0] * (n + 2)

        for ai, bi in zip(a, b):
            if bi < ai:
                dx[bi] += 1
                dx[ai] -= 1

        for i in range(1, n + 1):
            dx[i] += dx[i - 1]

        ans = []

        for k in range(1, n + 1):
            ok = True

            m = k
            while m <= n:
                if dx[m] != 0:
                    ok = False
                    break
                m += k

            if ok:
                ans.append(k)

        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
