 ## 解決策
 ## 問題の理解

 この問題では、改造されたナイトが特定のキングとクイーンの両方を攻撃できる無限のチェス盤上のすべての位置を見つけるように求められます。 ナイトの動きは 2 つの正の整数で定義されます。$a$そして$b$、ジャンプできるので$a$一方向に正方形になり、$b$通常の騎士のスケール版のような、垂直方向の正方形。 チェス盤の座標は、マイナスを含む任意の整数のペアにすることができ、キングとクイーンは特定の個別のセルに配置されます。 

入力により、複数のテスト ケースにおけるナイトの移動サイズとキングとクイーンの座標が得られます。 各テスト ケースの出力は単一の数値、つまりナイトが両方の駒を同時に脅かす位置の数です。 ボードは無限であるため、エッジの制限はありません。 キングとクイーンを基準とした配置の組み合わせの可能性のみを考慮します。 

制約は次のことを示唆しています$a$そして$b$まで可能です$10^8$最大 1000 のテスト ケースを作成できます。 これにより、考えられるすべてのボード セルをチェックしたり、広い範囲にわたって反復したりする強引なアプローチが排除されます。$O(a \cdot b)$または$O(x_{\text{max}} \cdot y_{\text{max}})$アルゴリズムが遅すぎるでしょう。 このソリューションは、絶対的な基板スキャンではなく、相対座標を直接操作する必要があります。 

キングとクイーンが単一の位置から両方に届くナイトの動きが不可能な方法で並んでいる場合、微妙なエッジケースが発生します。 たとえば、それらが同じ水平線上にあるが、その水平距離が正確に一致していない場合、$2a$または$2b$、騎士はそれらをフォークすることはできません。 不注意な解決策では、すべてのセルのペアに少なくとも 1 つのフォーク位置があると想定され、誤った結果が生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチは概念的には単純です。キングとクイーンを含む十分に大きな長方形上の潜在的なナイトの位置ごとに、ナイトが両方を攻撃するかどうかを確認します。 これが機能するのは、ナイトがどこを攻撃できるかを正確に知っているためです。位置は次のようにオフセットされます。$(\pm a, \pm b)$または$(\pm b, \pm a)$騎士の位置から。 ただし、必要な長方形は次のとおりです。$10^8$幅または高さで。 これらすべての位置を反復処理すると、最悪の場合の操作数が 1 桁になります。$10^{16}$、それは不可能です。 

重要な洞察は、ナイトの攻撃パターンが対称的であるということです。 すべてのボード セルを列挙する代わりに、1 つの駒 (キングなど) に対するナイトの考えられるすべての相対位置を列挙し、同じ位置が他の駒 (クイーン) も攻撃するかどうかを確認できます。 各ナイトには、正確に 8 つの可能な攻撃位置があります。 したがって、問題は、王に対するこれら 8 つの位置のそれぞれについて、女王から騎士が 1 つ離れたところに着地するかどうかをチェックすることになります。 

これにより、巨大な検索空間の問題が、テスト ケースごとに一定の制限された検索空間の問題に変換されます。 ブルート フォースは原理的には機能しますが、サイズが原因で失敗します。一方、8 つの「キング相対」候補位置を調べるだけでよいという観察により、各テスト ケースを一定時間で解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(大きな長方形) | お(1) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. キングとクイーンの間の相対座標の差を計算します。$dx = x_Q - x_K$そして$dy = y_Q - y_K$。 ボードは無限であり、相対的な位置のみが重要であるため、これらの違いのみを考慮する必要があります。 
2. 王に対する 8 つの可能なナイトの位置をすべて生成します。 彼らです$(\pm a, \pm b)$そして$(\pm b, \pm a)$。 これらは、騎士が王を攻撃するために必要な場所を表しています。 
3. これらの候補位置のそれぞれについて、騎士の仮想座標を計算します。$x_N = x_K + \delta_x$、$y_N = y_K + \delta_y$。 
4. 同じナイトのポジションがクイーンも攻撃しているかどうかを確認します。 これには、女王の座標との絶対的な差が次のいずれかに一致する必要があります。$(a, b)$または$(b, a)$。 数学的には、$(|x_N - x_Q|, |y_N - y_Q|)$等しいはずです$(a, b)$または$(b, a)$。 
5. 両方の攻撃を満たす各候補を数えます。 このカウントをテスト ケースに対して出力します。 

機能する理由: ナイトの各ポジションは、有効なフォークかどうかのどちらかです。 キングに対するすべてのポジションを体系的にチェックすることで、候補者が見逃されることがないことを保証します。 ナイトの動きの対称性により、8 つの可能性がすべて考慮され、絶対差チェックによってナイトがクイーンも攻撃することが確認されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_forks(a, b, kx, ky, qx, qy):
    candidates = [(a, b), (a, -b), (-a, b), (-a, -b),
                  (b, a), (b, -a), (-b, a), (-b, -a)]
    count = 0
    for dx, dy in candidates:
        nx, ny = kx + dx, ky + dy
        dxq, dyq = abs(nx - qx), abs(ny - qy)
        if (dxq, dyq) == (a, b) or (dxq, dyq) == (b, a):
            count += 1
    return count

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    kx, ky = map(int, input().split())
    qx, qy = map(int, input().split())
    print(count_forks(a, b, kx, ky, qx, qy))
```8 つの相対的な動きを生成し、各ナイトの絶対位置を計算し、絶対的な差を使用してクイーンまでの距離を比較します。 使用する`abs`負のオフセットを正しく処理できるようにします。 各候補は 1 回だけチェックされます。
