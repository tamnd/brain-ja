 ## 解決策
 ## 問題の理解

 いくつかのテスト ケースが与えられ、各テスト ケースは素数で始まります。$n$。 そういったものごとに$n$、別の素数を選択する必要があります$m$合計が$n + m$プライムではありません。 有効な素数$m$許容範囲内の値は許容され、異なるテスト ケースは独立しています。 

中心となるタスクは、素数性を複雑な方法で繰り返し計算することではなく、各入力素数に対して有効なパートナー素数を構築することです。 出力制約は寛大です。$m$までの任意の素数を指定できます$10^5$であり、有効性を超えて最小化または最適化する必要はありません。 

制約$n \le 10^5$そして$t \le 10^4$は、いくつかの前処理の後、解はテスト ケースごとに基本的に一定時間でなければならないことを示唆しています。 テスト ケースごとに素数チェックを繰り返すものは、チェックが次の場合にのみ問題ありません。$O(1)$ただし、クエリごとに素数の検索を繰り返すと、最悪の場合、速度が非常に遅くなります。 

次の場合、微妙なエッジケースが発生します。$n$小さいです。 もし$n = 2$、次に次のような小さな素数を選択します$m = 2$または$m = 3$すぐに合計を計算します$4$または$5$、そのうちの1つだけが非プライムです。 すべての合計が同様に動作すると仮定すると、リスト内の最初の素数を常に選択する単純なアプローチは失敗する可能性があります。 もう 1 つの例外的なケースは次のような場合です。$n$大きくて近いです$10^5$、不注意な建設戦略が限界を超える可能性がある場合$n + m$ただし、和の素数だけが問題であり、その大きさではありません。 

## アプローチ

 ブルートフォースアプローチでは、すべての素数を試します$m$かどうかを確認してください$n + m$プライムです。 各テスト ケースについて、これにより、以下のすべての素数がスキャンされます。$10^5$、各候補について素数を計算します。$n + m$。 素数性が篩で事前に計算されている場合でも、テスト ケースごとに最大約 9,500 個の素数をチェックすることになり、おおよその結果が得られます。$10^8$すべてのテストで最悪のケースをチェックしますが、これは不要です。 

重要な点は、検索する必要がないということです。 少なくとも 1 つの単純な選択が機能することを保証する必要があるだけです。 素数の構造はすぐに近道を与えます: 小さな固定素数を選択すると$m$かどうかを確認するだけです。$n + m$複合です。 以来$n$は常に素数であるため、パリティを利用できます。 を除いて$n = 2$、すべての素数は奇数です。 2 つの奇数の合計は偶数で 2 より大きいため、合成されます。 これは、すべての奇数素数に対して、$n$、選択する$m = 3$常に合成和が生成されます。 

唯一問題となるケースは、$n = 2$。 ここ$n$は偶数なので、$2 + 3 = 5$は素数ですが、失敗します。 別の固定された小さな素数が必要です。 選択する$m = 2$与える$2 + 2 = 4$、これは複合です。 これにより、唯一の例外的なケースが解決されます。 

したがって、解決策は一定時間の条件付き選択に帰着します。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、素数を読み取ります。$n$。 これを純粋に整数として扱います。 因数分解は必要ありません。 
2. かどうかを確認します。$n = 2$。 これは唯一の偶数素数であり、奇数プラス奇数の構造を壊すため、他の素数とは異なる動作をします。 
3. もし$n = 2$、出力$m = 2$。 これにより、$n + m = 4$、これは素数ではありません。 
4. それ以外の場合は出力$m = 3$。 2 を除くすべての素数は奇数であるため、これにより次のことが保証されます。$n + 3$は偶数で 2 より大きいため、複合です。 

### なぜ効果があるのか

 正確さは素数の構造的特性に依存します。 2 より大きいすべての素数は奇数です。 2 つの奇数を加算すると、結果は偶数になります。 2 より大きい偶数は、約数が 2 であるため、素数になることはできません。 したがって、奇数の素数に対して$n$、選択する$m = 3$力$n + m$複合的であること。 唯一の例外は、$n = 2$、ここでパリティが壊れ、別の素数和の生成を避ける別の素数を明示的に選択します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 2:
            print(2)
        else:
            print(3)

if __name__ == "__main__":
    solve()
```コードは構造の後に直接続きます。 唯一の決定点は、2 に対する等価性チェックです。それ以外はすべて定数出力です。 

よくある間違いは、有効な情報を「検索」しようとすることです。$m$これは不必要であり、タイムアウトの危険性があります。 もう一つの間違いはそれを忘れることです$2 + 3 = 5$は素数なので、$m = 3$には無効です$n = 2$。 明示的なブランチがこれを処理します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        if n == 2:
            out.append("2")
        else:
            out.append("3")
    return "\n".join(out) + "\n"
