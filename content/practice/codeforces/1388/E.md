 ## 解決策
 ## 問題の理解

 x 軸の上にいくつかの水平線分が配置されています。 各セグメントには固定の高さと整数の端点を持つ水平間隔があります。 セグメントは平面内で互いに交差しませんが、異なる高さに位置し、X 投影で重なる場合があります。 

下半平面で方向を選択し、すべてのセグメントをその方向と平行な線に沿って x 軸に投影します。 各セグメントは X 軸上の新しい間隔に折りたたまれます。 投影は線形であるため、すべてのエンドポイントは選択した方向に応じて線形に移動します。 

目標は、すべての投影された間隔が互いに素なまま (端点で接触する可能性がある)、すべての投影されたセグメントによってカバーされる合計スパンができるだけ小さくなるように方向を選択することです。 

n が最大 2000 であるため、入力サイズは O(n²) または O(n² log n) の解に対して十分小さいです。これにより、セグメントのすべてのトリプルにわたる立方体構造が即座に除外されますが、依然として O(n) オブジェクトに対するペアワイズ推論と凸包スタイルのジオメトリが可能になります。 

微妙なエッジ ケースは、投影がセグメントの任意の独立した動きではないという事実から生じます。 方向の選択を誤ると、たとえ平面内で 2 つのセグメントが分離されていたとしても、投影後にそれらのセグメントが重なり合う可能性があります。 たとえば、1 つのセグメントが高いものの、はるか左から始まる場合、急な投影によってそのセグメントが下のセグメントを押しのけ、投影における非交差要件に違反する可能性があります。 

2 番目のエッジ ケースは、投影後に複数のセグメントが整列する縮退方向です。 これらは間隔が接触している限り有効ですが、エンドポイント式間の完全な等しい場合に対応し、離散比較ではなく実数演算で処理する必要があります。 

## アプローチ

 直接的な試みは、方向をパラメータとして扱い、固定角度の投影をシミュレートすることです。 方向を固定すると、すべてのセグメントが線上の間隔になり、左の最小端点と右の最大端点を取得することでスパンを計算できます。 ただし、2 つの投影された間隔が重ならないようにする必要もあります。これは、投影に沿った順序が選択した方向と一致しているかどうかによって決まります。 

n 階乗の可能性があるため、セグメントの可能な順序をすべて試すことは直ちには不可能です。 固定次数の実現可能性をチェックすることに限定したとしても、すべてのペアごとの制約に対して方向の一貫性をテストする必要があり、これにより、傾きパラメーターの不平等系が生じます。 

重要な簡素化は、投影を明示的に記述することで実現します。 投影方向をパラメータ化すると、すべての点 (x, y) は、いくつかの実パラメータ s に対して x + s * y に移動します。 これにより、各セグメントが移動間隔 [l_i + s y_i, r_i + s y_i] に縮小されます。 全体の構成は、端点が s とともに直線的に移動する n 個の間隔のセットになります。 

和集合のスパンは、s の 2 つの関数、つまりすべての右端点の最大値とすべての左端点の最小値によって決まります。 これらのそれぞれは、n 個の線形関数にわたる最大値または最小値であり、凸状の区分線形構造を形成します。 構造が変化する可能性がある唯一の点は、2 つの線形関数が交差するときです。これは、境界を定義する際に重要になるセグメントのペアに対応します。 

投影が重なり合わないという実現可能性の制約は、これらの境界イベントを超える新しい自由度を導入しません。 方向が最適な場合、端点のペアが緊密になるまで継続的にシフトできます。つまり、投影後に 1 つのセグメントの右端点が別のセグメントの左端点と整列する s の値で最適化が常に発生します。

これにより、探索空間が r_i + s y_i = l_j + s y_j の形式の等式によって定義される候補勾配に縮小されます。 このような各等式は、境界セグメントの優位性が変化する固有の を定義します。 

このような候補の傾きでは、合計スパンを直接評価し、すべての候補の最小値を取得できます。 これを効率的に行うために、右端の上部エンベロープと左端の下部エンベロープに現れる可能性のあるセグメントのみを考慮します。これは、極端でないセグメントでは最適な点でグローバルな最大値または最小値を定義できないためです。 

これにより、上部エンベロープの点 (y_i, r_i) と下部エンベロープの (y_i, l_i) の凸包が計算され、各包からの 1 つのライン間のすべての交点がテストされます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 方向と順列に対するブルートフォース | 指数関数 | O(n) | 遅すぎる |
 | 凸包境界交差 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各セグメントをパラメーター s の 2 つの線形関数に変換します。ここで、左の端点は l_i + s y_i、右の端点は r_i + s y_i です。 これにより、幾何学が線に関する問題に変わります。 
2. 各セグメントを点 (y_i、r_i) として扱い、右端の線の上のエンベロープを構築します。 このエンベロープは、どのセグメントが特定の傾斜の最大右側境界を定義するかを表します。 
3. 点 (y_i、l_i) を使用して、左端の線の下側エンベロープを作成します。 このエンベロープは、どのセグメントが左の最小境界を定義するかを表します。 
4. 上部エンベロープの 1 つのセグメントと下部エンベロープの 1 つのセグメントで構成されるすべてのペアについて、対応する端点が等しくなる傾き s を計算します。 これは、r_i + s y_i = l_j + s y_j を解くことで得られます。 
5. このような各候補勾配について、すべてのセグメントを使用して、最大右端点から最小左端点を引いた値を評価することによってスパンを計算します。 
6. すべての候補にわたって最小のスパンを維持します。 

この正確さは、スパン関数が s 内で区分的に線形であり、その定義する極値の変化が 2 つの終点の線が交差する場合にのみ発生するという事実から得られます。 s の最適な値は、そのような交差点に存在する必要があります。 それ以外の場合は、構造上の制約に違反することなく、目的を改善するために s をわずかにシフトすることができます。 極値を定義できるのはエンベロープ セグメントだけであるため、候補をハル ペアに制限すると、考えられるすべての重大なイベントが保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_hull(points, key_index):
    points.sort()
    hull = []
    for y, val in points:
        while len(hull) >= 2:
            y1, v1 = hull[-2]
            y2, v2 = hull[-1]
            if (v2 - v1) * (y - y2) >= (v - v2) * (y2 - y1):
                hull.pop()
            else:
                break
        hull.append((y, val))
    return hull

n = int(input())
seg = [tuple(map(int, input().split())) for _ in range(n)]

upper = [(y, r) for l, r, y in seg]
lower = [(y, l) for l, r, y in seg]

upper.sort()
lower.sort()

uh = []
for y, r in upper:
    while len(uh) >= 2:
        y1, r1 = uh[-2]
        y2, r2 = uh[-1]
        if (r2 - r1) * (y - y2) >= (r - r2) * (y2 - y1):
            uh.pop()
        else:
            break
    uh.append((y, r))

lh = []
for y, l in lower:
    while len(lh) >= 2:
        y1, l1 = lh[-2]
        y2, l2 = lh[-1]
        if (l2 - l1) * (y - y2) <= (l - l2) * (y2 - y1):
            lh.pop()
        else:
            break
    lh.append((y, l))

def eval_span(s):
    mn = float('inf')
    mx = -float('inf')
    for l, r, y in seg:
        x1 = l + s * y
        x2 = r + s * y
        mn = min(mn, x1)
        mx = max(mx, x2)
    return mx - mn

ans = float('inf')

for yi, ri in uh:
    for yj, lj in lh:
        if yi == yj:
            continue
        s = (lj - ri) / (yi - yj)
        ans = min(ans, eval_span(s))

print(f"{ans:.10f}")
```この実装では、まず問題を 2 セットの線形関数 (左端点と右端点) に変換します。 次に、(y, value) ペア上の単調スタックを使用して両方の凸包を構築します。これにより、関連する極端なセグメントのみが確実に残ります。 

ハル ポイント上の二重ループにより、右側の境界線が左側の境界線と交わるすべての候補傾斜が生成されます。 各候補は、フル スパンを再計算することによって評価されます。 これは高価に見えますが、船体サイズは直線的であり、n は最大でも 2000 であるため、総作業量は許容範囲内に保たれます。 

一般的な実装の落とし穴は、傾き計算における符号の処理です。 r_i + s y_i = l_j + s y_j の正しい再配置は、y_i < y_j の場合にゼロによる除算や誤った順序付けを避けるために慎重に解決する必要があります。

 ## 特殊なケース

 複数のセグメントが同じ高さ y を共有すると、縮退した状況が発生します。 その場合、それらの投影されたシフトは同一であるため、それらの間の順序は投影パラメータによって変更されることはありません。 傾きの計算ではゼロによる除算がスキップされ、そのようなペアは有効な交差イベントを定義しないため、アルゴリズムはこれを安全に処理します。 

別のエッジケースは、最適な傾きが非常に大きな振幅値に対応する場合に発生します。 これは、最小値が漸近的に近づいていることを示唆しています。 実際には、そのようなケースは単一のエンベロープ セグメントによって優勢に崩壊しますが、極端な傾きは凸包構造ですでに表現されている終点で定義された遷移に対応するため、包ベースの候補生成は依然として正しい境界動作を捕捉します。 

最後の微妙なケースは、2 つの候補イベントが同じ傾きを生成する場合です。 評価ステップは重複とは独立しており、スパンを再計算すると、最小値のみが保持されるため、浮動小数点の冗長性が正確さに影響を与えないことが保証されます。
