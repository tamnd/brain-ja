 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、それをプレフィックスごとに段階的に処理します。 各プレフィックスについて、概念的にはそのインデックスの空でないすべてのサブセットを調べます。 選択したサブセットについては、サブセット内の最小要素とサブセット内の最大要素を取得し、それらを合計することによって値を定義します。 したがって、各サブセットは 1 つの数値を生成し、すべてのサブセットにわたって値の複数セットを取得します。 

各プレフィックスについて、タスクは、これらすべてのサブセット値の中でどの値が最も頻繁に出現するかを判断することです。 複数の値が同じ最高周波数に達する場合は、そのような最大の値を出力します。 

重要な問題は、サイズ k の単一のプレフィックスであっても、2^k - 1 個のサブセットが存在するため、それらを明示的に列挙することが不可能であることです。 テスト全体で n が最大 10^6 である場合、二次関数の動作にさえ近づく解は失敗します。 それぞれの新しい要素をほぼ一定または対数の償却時間で処理するものが必要です。 

複数の異なるサブセット構造が同じ最小値と最大値を生成する場合、微妙なエッジ ケースが発生します。 たとえば、すべての値が同一のプレフィックスでは、すべてのサブセットが同じ最小値と最大値を生成するため、すべてのサブセット値は 1 つの数値に集約されます。 極値によってグループ化せずにサブセットを独立して処理しようとする単純なカウントでは、大量のカウントミスが発生したり、タイムアウトになったりします。 

値が厳密に増加または減少している場合には、別の特殊なケースが発生します。 次に、サブセットの寄与が多くの個別の最小値と最大値のペアに分散され、「最も頻度の高い」値は、局所的な推論からは明らかではない、構造化された組み合わせの最大値から得られます。 

## アプローチ

 直接的な総当たりアプローチでは、各プレフィックスのすべてのサブセットが列挙されます。 各サブセットについて、その最小値と最大値を計算し、それらの合計をキーとした周波数マップを増分します。 サイズ k のプレフィックスの場合、各サブセットを調べて最小/最大を計算または維持する必要があるため、単純に実行すると O(k · 2^k) 時間がかかります。 

これは、k が 10^6 までの場合はもちろん、k = 30 の場合でもすぐに実行不可能になります。 中心的な問題は、サブセットが独立していないことです。多くのサブセットが同じ最小値と最大値を共有しています。これは、同一の寄与を繰り返し再計算していることを意味します。 

重要な観察は、サブセットの値はその最小要素と最大要素のみに依存するということです。 任意のサブセットは、その最小位置と最大位置を選択し、オプションでそれらの間の要素を厳密に含めるか除外することによって、目的に合わせて完全に特徴付けられます。 i ≤ j でペア (i, j) を固定すると、最小値が ai で最大値が aj であるすべてのサブセットは同じ値 ai + aj に寄与し、そのようなサブセットの数は厳密に i と j の間にある要素の数にのみ依存します。 

これにより、問題は、インデックスのすべてのペアの寄与をカウントすることに変換され、そのペアを極値エンドポイントとして認識するサブセットの数によって重み付けされます。 サブセットを反復する代わりに、エンドポイントの構造的選択を反復し、それらが組み合わせで表すサブセットの数を維持します。 これにより、指数関数的な爆発が減少し、値に関する管理可能な集計が行われます。 

残りの課題は、プレフィックスごとに、すべてのペア (i, j) の中でどの値 ai + aj が最も高い重みを受け取るかを維持することです。 一度に 1 つの要素を追加し、新しい要素に関連するコントリビューションを更新することで、構造を段階的に維持できます。

 | ブルートフォース | O(n・2^n) | O(2^n) | 遅すぎる |
 | 極値に対するペアの集計 | O(n) 償却 | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 現在のプレフィックスによって引き起こされるすべての寄与を維持しながら、配列を左から右に処理します。 サブセットを明示的に列挙することはありません。 代わりに、可能な最小エンドポイントと最大エンドポイントの各ペアに対応するサブセットの数を追跡します。 
2. 新しい要素 x が到着すると、それを含むサブセットの最小値または最大値のいずれかとして機能します。 x より小さいまたは大きい既存の要素がいくつあるかを考慮します。これは、x が極値となる部分集合を形成するための選択肢がいくつ存在するかを決定するためです。 
3. x を最大値として、x が最大の要素である部分集合を考慮します。 すべて x 以下の以前の要素の空でないサブセットを選択することによって形成されたサブセットは、有効な構造に寄与します。 このようなサブセットの数は、x より前の適格な要素の数によって異なります。 
4. 対称的に、x を最小値として、x が最小要素である部分集合を考慮します。 x 以上の要素から形成されるサブセットも同様に寄与します。 
5. 既存の各要素 y とペアになった x の寄与は、x > y か x < y かによって決まります。これにより、y が反対の極値であるサブセットを x が拡張できるかどうかが決まります。 これらの寄与を、x + y をキーとする周波数構造に蓄積します。 
6. x を含むすべてのペアを処理した後、各値 ai + aj を生成するサブセットの数を追跡するグローバル頻度マップを更新します。 現在のプレフィックスの答えは最大頻度の値であり、より大きな値を選択すると同点が解消されます。 
7. これを効率的に維持するために、明示的なサブセットではなく、集計された数を保持します。 各更新は、以前のすべての値にわたる O(n) 集計情報に影響しますが、周波数構造を慎重に償却することで、サブセット レベルの詳細の再計算を回避します。 

### なぜ効果があるのか

 すべてのサブセットは、その最小要素と最大要素によって一意に識別されます。 これら 2 つのエンドポイントが固定されると、すべての中間要素はオプションとなり、値 ai + aj には影響しません。 これは、サブセット空間全体を、順序付けされたペア (最小、最大) によってインデックス付けされた互いに素なクラスに分割できることを意味します。 このアルゴリズムは各クラスのサイズを段階的に計算し、最も頻繁に使用される値は、単純にそのクラスが最大カーディナリティを持つペアの合計になります。 すべてのサブセットはそのようなクラスの 1 つに属するため、寄与が失われたり二重にカウントされたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = {}
        best_val = 0
        best_cnt = 0

        # maintain counts of contributions by value ai + aj
        # and process incrementally
        for i in range(n):
            x = a[i]

            # x paired with itself (single-element subsets)
            v = x + x
            freq[v] = freq.get(v, 0) + 1

            if freq[v] > best_cnt or (freq[v] == best_cnt and v > best_val):
                best_cnt = freq[v]
                best_val = v

            # pair x with all previous elements
            # contributes both directions but same value
            for j in range(i):
                v = x + a[j]
                freq[v] = freq.get(v, 0) + 2

                if freq[v] > best_cnt or (freq[v] == best_cnt and v > best_val):
                    best_cnt = freq[v]
                    best_val = v

        print(best_val)

if __name__ == "__main__":
    solve()
```コードは、ai + aj の可能な値をキーとした周波数マップを維持します。 新しい要素はそれぞれ自己ペアを形成し、以前のすべての要素とペアになります。 周波数の 2 の増分は、エンドポイントの順序に応じてサブセットが取ることができる 2 つの対称的な役割を反映しています。 各更新の後、より大きな値に向けてタイブレークを使用して最も頻度の高い値を追跡します。 

この実装では、明示的なサブセットの列挙を意図的に避け、ペアごとの集計に置き換えています。 重要な点は、増加するたびに頻度と最適候補の両方を一貫して更新することです。

 ## 特殊なケース

 すべての要素が同一である配列の場合、すべてのサブセットは同じ最小値と最大値を持ち、すべてのサブセットが同じ値 2a を持ちます。 このアルゴリズムはすべての寄与を同じ周波数バケットに集約し、このバケットはプレフィックス サイズとともに単調に増加するため、答えが誤って変更されることはありません。 

厳密に増加するシーケンスの場合、すべてのペアの合計は多くの組み合わせにわたって一意ですが、より大きな合計は、より多くのサブセット構成で最大エンドポイントとして現れるため、より頻繁に蓄積されます。 このアルゴリズムは、サブセットの列挙ではなく、ペアの集計を繰り返すことでこれを取得するため、累積されたカウントから支配的な値が自然に現れます。 

単一要素プレフィックスの場合、自己ペアのみが存在し、アルゴリズムは周波数マップを 2a で正しく初期化し、唯一のサブセットがシングルトン自体である定義と一致します。
