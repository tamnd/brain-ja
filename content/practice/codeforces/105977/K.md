 ## 解決策
 ## 問題の理解

 すべてのノードに 1 つの重みが付加されたツリーが与えられますが、それらのノードの重みは隠されています。 ノードの重みの代わりに、すべてのエッジはすでに端点の合計を示しています。u と v を接続するエッジの場合、この値は u と v に割り当てられた未知の正の整数の合計に等しいことがわかります。 

タスクは、すべてのエッジ合計に正確に一致するノードへの正の整数の割り当てが存在するかどうかを判断し、存在する場合は、すべての値が許容範囲内に収まる有効な割り当てを構築することです。 

構造は重要です。グラフはツリーなので、2 つのノード間には単純なパスが 1 つだけ存在します。 各エッジは bu + bv = wuv という形式の線形制約を作成し、すべての制約が同時に満たされる必要があります。 

n ≤ 2 × 10^5 という制約により、代入に対する指数関数または二次関数の推論が即座に除外されます。 有効な解決策は、ノード数が線形またはほぼ線形である必要があります。これは、O(n log n) であっても許容されますが、すべての代入を試したり、一般システムを直接解いたりするようなものは許容されないためです。 

微妙な問題は、一方のエンドポイントが既知になると各エッジがローカルに一方のエンドポイントを決定しますが、明らかなグローバルな開始点がないことです。 値を恣意的に選択すると、暗黙の値が負になったり、制限を超えたりした場合に、矛盾が発生しやすくなります。 

失敗の小さな例としては、長さ 3 の単純なパスがあります。 

b1 + b2 = 5、b2 + b3 = 9、および b3 + b4 = 4 の場合、すべてを b2 で表現すると矛盾する不等式が生じ、b2 が同時に 5 より大きく、かつ 5 より小さくなることが強制されますが、これは不可能です。 これは、ツリーにサイクルがないにもかかわらず、実現可能性が自動的に得られるわけではないことを示しています。 

もう 1 つの微妙なエッジ ケースは、1 つの中心値によりすべてのリーフが大きすぎるか小さすぎることを強制し、正数または上限 10^9 の違反を引き起こす星型ツリーです。 

## アプローチ

 直接的なアプローチは、問題を n 個の未知数に対する n 個の線形方程式として扱うことです。 ガウス消去法を試みることもできますが、それは不必要に重く、グラフの構造を無視します。 スパース性があっても、最大 2 × 10^5 の制約の下で実装するのは複雑になります。 

重要な観察は、各エッジ方程式により、1 つのノードの重みをその隣接ノードに関して直接表現できるということです。 ルート値を選択すると、他のすべての値をツリー全体に一意に伝播できます。 唯一残っている問題は、この伝播によって自由パラメータが導入され、すべてのノードがそのパラメータの線形関数になることです。 

すべてのエッジはエンドポイント間の符号関係を反転するため、各ノードの値は、ツリー内の深さのパリティのみに応じて、+X または -X に定数を加えたものとして書き込むことができます。 これにより、システム全体が単一変数の実現可能性問題に変わります。つまり、すべての派生ノード値が有効になるような整数 X を見つけます。 

各ノードは、正の値と上限 10^9 に基づいて X に間隔制約を与えます。 最終的な答えは、これらすべての間隔が交差するときに正確に存在します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 直接線形代数 | O(n^3) または O(n^2) | O(n^2) | 遅すぎる |
 | パラメータ | を使用したツリーの伝播 O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 任意のノード (通常はノード 1) でツリーをルートし、すべてのノード値をルート値を表す単一の変数 X の線形関数として表します。

1. ルート r を固定し、その値を br = X に設定します。X はまだ選択していません。 これを記号パラメータとしてのみ扱います。 
2. DFS または BFS を使用してツリーを走査します。 既知の重み wuv を持つすべてのエッジ u から v について、bv = wuv − bu を導出します。 これにより、u が分かるとすぐに v の線形関係が得られます。 
3. 各ノード v について、bv = av · X + cv の形式の式を維持します。ここで、av は +1 または -1 です。 これは、値がルート パラメーターにどのように依存するかをキャプチャします。 
4. エッジ u から v に移動するときは、符号を反転して定数を調整します。 bu = au · X + cu の場合、bv = wuv − bu は av = −au および cv = wuv − cu になります。 このステップでは、既知の式をエッジ制約に直接代入するため、正確さが保たれます。 
5. 走査後、すべてのノードは X の線形制約に変換されます。各ノードに対して、正の値と上限 10^9 を適用します。これにより、av と cv に応じて L ≤ X ≤ R の形式の不等式が生成されます。 
6. すべてのノード上でこれらすべての間隔を交差させます。 交差部分が空の場合、有効な割り当ては存在しません。 
7. 交差部分が空でない場合は、その中の任意の整数 X を選択し、bv = av · X + cv を使用してすべてのノード値を計算します。 

これが機能する理由は、ツリー構造により、各ノードがルートからの定義パスを 1 つだけ持つことが保証されるため、線形式に不一致が発生しないためです。 唯一の自由度は初期ルート値 X であり、すべての制約はこの 1 つのパラメーターを制限することになります。 有効な代入が存在する場合、それは最終的な交差内の X の選択に対応する必要があり、逆に、交差内の X は一貫した正の範囲の割り当てを生成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    if n == 1:
        print("YES")
        print(1)
        return

    g = [[] for _ in range(n)]
    for _ in range(n - 1):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, w))
        g[v].append((u, w))

    a = [0] * n
    c = [0] * n
    vis = [False] * n

    from collections import deque
    dq = deque([0])
    vis[0] = True
    a[0] = 1
    c[0] = 0

    while dq:
        u = dq.popleft()
        for v, w in g[u]:
            if vis[v]:
                continue
            vis[v] = True
            a[v] = -a[u]
            c[v] = w - c[u]
            dq.append(v)

    L, R = 1, 10**9

    for i in range(n):
        if a[i] == 1:
            L = max(L, 1 - c[i])
            R = min(R, 10**9 - c[i])
        else:
            L = max(L, c[i] - 10**9)
            R = min(R, c[i] - 1)

    if L > R:
        print("NO")
        return

    X = L
    res = [0] * n
    for i in range(n):
        res[i] = a[i] * X + c[i]
        if res[i] <= 0 or res[i] > 10**9:
            print("NO")
            return

    print("YES")
    print(*res)

if __name__ == "__main__":
    solve()
```実装はシンボリック伝播に正確に従います。 BFS は、各ノードにルート変数に関連する符号と定数を割り当てます。 その後、区間交差ステップにより、すべての制約が X の単一の実行可能な範囲に集約されます。 

微妙な点は、整数の境界を正しく処理することです。 不等式は厳密な正と上限であるため、直接比較するのではなく、1 − cv や 10^9 − cv のようなシフトされた境界に変換されます。 このシフトは、off-by-one エラーが発生しやすい主な場所です。 

最後に、X を選択した後でも、すべての値を再計算して検証することで、算術ミスやオーバーフローのような推論エラーを防ぐことができます。 

## 実用的な例

 チェーンの例を考えてみましょう。 

制約のあるノード 1-2-3-4:

 b1 + b2 = 5、b2 + b3 = 9、b3 + b4 = 4。 

b1 = X で 1 をルートとした後、伝播は次のようになります。 

| ノード | av | CV | 式 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | X |
 | 2 | -1 | 5 | 5 − X |
 | 3 | 1 | 4 | X + 4 |
 | 4 | -1 | 0 | −X |

 次に制約を適用します。 

ノード 1 の場合: 1 ≤ X ≤ 10^9

 ノード 2 の場合: 1 ≤ 5 − X ≤ 10^9 は X ≤ 4 および X ≥ −10^9 + 5 を与えます。 

ノード 3 の場合: 1 ≤ X + 4 ≤ 10^9 により、X ≥ −3 が得られます。 

ノード 4 の場合: 1 ≤ −X ≤ 10^9 は X ≤ −1 を与えますが、これはすでに X ≥ 1 と競合します。 

間隔が崩壊するため、解決策は存在しません。 これは、交互の制約が最終的に矛盾する境界を強制するという直観と一致します。 

次に、一貫した短いツリーを考えてみましょう。 

エッジ:

 1-2 = 5、1-3 = 4。 

伝播により次のことが得られます。 

| ノード | av | CV | 式 |
 | --- | --- | --- | --- |
 | 1 | 1 | 0 | X |
 | 2 | -1 | 5 | 5 − X |
 | 3 | -1 | 4 | 4 − X |

 制約により次のことが可能になります。 

X ≥ 1、X ≤ 4、X ≤ 4、X ≥ 3。 

したがって、X ∈ [3, 4] となります。 X = 3 を選択すると、b1 = 3、b2 = 2、b3 = 1 となり、両方のエッジが満たされます。 

このトレースは、実現可能性が単一パラメータ上の線形制約の交差に完全に帰着することを示しています。 

## 複雑さの分析

| スペース | O(n) | 隣接リストと符号と定数の配列 |

                if vis[v]:

 ## 特殊なケース

 単一ノードはエッジ制約が存在しない唯一の状況であるため、範囲内の値はすべて有効です。 アルゴリズムは 1 を返すことでこれを直接処理し、区間の交差は必要ありません。 

2 ノード ツリーでは b1 + b2 = w の関係がすぐに修正されますが、1 つの自由度が残ります。 BFS は b2 = w − X を割り当て、区間の交差により両方の値が範囲内に留まることが保証されます。 w が大きすぎる場合、交差点は空になり、正しく NO が生成されます。 

長いチェーンではステップごとに符号が交互に切り替わり、ルート変数に交互の上限と下限が作成されます。 これはまさに、エッジの重みが一致しない場合に矛盾が現れる場所であり、区間交差ステップは L と R を折りたたむことによってその失敗を正確に捕捉します。
