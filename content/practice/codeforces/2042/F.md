 ## 解決策
 ## 問題の理解

 2 つの配列があります。`a`そして`b`。 

任意のサブ配列に対して`[l, r]`、その値は単なる要素の合計ではありません。`a`その中に。 また追加します`b_l`そして`b_r`、2 つのエンドポイントに関連付けられた値。 

部分配列が単一の位置で構成されている場合、両方の端点が同じであるため、その値は次のようになります。$$a_l + 2b_l$$クエリは次のいずれかを更新します`a[p]`または`b[p]`。 興味深いクエリは、完全に範囲内に含まれる **2 つの空でない互いに素な部分配列** の値の最大合計を求めます。`[l,r]`。 

選択した 2 つのサブ配列の長さは任意ですが、重複することはできません。 

最初に注意すべきことは、答えは単純に「最良のサブ配列 + 2 番目に最良のサブ配列」ではないということです。 エンドポイント ボーナスにより、通常の最大サブアレイ機構では不十分な相互作用が生じます。 

制約こそが本当の課題なのです。 両方`n`クエリの数は最大です`2·10^5`。 1 つのクエリで、配列全体とほぼ同じ長さの間隔について尋ねることがあります。 クエリ中に間隔をスキャンするソリューションは、すぐに遅すぎます。 平`O(√n)`操作ごとに不快になるでしょう。 目安は大まかに`O(log n)`更新ごとおよびクエリごとに。 

いくつかのエッジケースでは、単純な状態定義が失敗します。 

考慮する：```
a = [0,0]
b = [100,100]
```でのベストアンサーは`[1,2]`は、2 つのシングルトン部分配列を取得することによって取得されます。```
[1] = 200
[2] = 200
answer = 400
```通常の部分配列の合計のみを追跡する定式化では、2 倍のエンドポイントの寄与が見逃されます。 

もう 1 つの微妙なケースは、すべての値が負の場合です。```
a = [-5,-5]
b = [0,0]
```答えは次のとおりです。```
(-5) + (-5) = -10
```空ではないサブ配列を 2 つ選択する必要があります。 何も選択しないことを黙って許可する状態は、誤って返されます。`0`。 

3 番目のトラップは、最適解が 1 つの長い間隔と 1 つのシングルトンを使用する場合です。```
a = [10,-100,10]
b = [0,100,0]
```最良の選択は次のとおりです。```
[1,1] = 10
[2,2] = 100
```大きな連続した構造ではなく。 セグメント ツリーは、さまざまな形状の間隔を混合するのに十分な情報を保存する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、まずクエリ範囲内のすべてのサブ配列の値を計算します。 

さまざまな長さの場合`m`、 がある`O(m²)`サブアレイ。 次に、重複しない部分配列のすべてのペアを試してみると、次のようになります。`O(m⁴)`可能性。 サブ配列値を事前に計算した後でも、すべてのペアをチェックするには依然としてコストがかかります`O(m⁴)`。 

と`m ≈ 2·10^5`、これはまったく不可能です。 

さらに洗練された観察は、部分配列の値は次のように書き換えることができるということです。$$(a_l+\cdots+a_r)+b_l+b_r$$中央は通常のプレフィックスサム構造のみを提供します。 唯一の特別な部分は、2 つのエンドポイントの処理です。 

これは、どのエンドポイントがすでに選択されているかを追跡する間隔 DP を強く示唆しています。 

重要なアイデアは、左エンドポイント ボーナスの収集から始まり、セグメントを横断して累積するパスとしてサブ配列をモデル化することです。`a`、右エンドポイントボーナスを収集して終了します。 

このように記述すると、結合間隔は、最大部分配列合計を求める古典的なセグメント ツリー DP と非常によく似たものになります。 違いは、2 つの互いに素な部分配列の構築による部分的な進行を記述するのに十分な状態が必要であることです。 

洗練された解決策は、すべてのセグメント ツリー ノードに小さな max-plus 行列を保存することです。 マトリックスの乗算は、2 つの隣接するセグメントがマージされるときに DP トランジションを自動的に実行します。 

この行列には、2 つのサブ配列の構築による進行状況を表す 5 つの状態があります。 2 つのセグメントを結合すると、max-plus 行列の乗算になり、これは結合的になります。 そのため、ポイント更新と範囲クエリを含むセグメント ツリーに最適です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(n⁴) | お(1) | 遅すぎる |
 | セグメント ツリー + Max-Plus 行列 | 更新/クエリごとに O(log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ソリューション全体は、すべての位置を遷移行列で表すことに基づいています。 

5 つの DP ステージを使用します。 

州`0`何も始まって​​いないことを意味します。 

州`1`最初のサブ配列の左側のエンドポイント ボーナスが選択されたことを意味します。 

州`2`最初のサブアレイがすでに完成していることを意味します。 

州`3`は、2 番目のサブ配列の左側のエンドポイント ボーナスが選択されたことを意味します。 

州`4`両方のサブアレイが完了したことを意味します。 

状態数が減少することはありません。 すべての遷移は前に進むか、同じ状態に留まります。 

### 行列の解釈

 単一ポジションの場合`i`、 定義する：$$A=a_i,\qquad B=b_i$$許可される遷移は次のとおりです。$$0\to1 : +B$$最初のサブ配列を開始します。$$1\to1 : +A$$この位置を介して最初のサブアレイを拡張します。$$1\to2 : +A+B$$ここで最初の部分配列を終了します。$$2\to3 : +B$$2 番目のサブ配列を開始します。$$3\to3 : +A$$2 番目のサブアレイを拡張します。$$3\to4 : +A+B$$2 番目の部分配列を終了します。 

また、すべての状態が値のまま変更されないようにします。`0`。 

これらの遷移は、`5×5`マックスプラス行列。 

### セグメント表現

 セグメントの場合、その行列はセグメント全体を左から右にスキャンするときに取得できる最良の値を表します。 

エントリ`(i,j)`状態のセグメントに入るときに得られる最大ゲインを保存します。`i`そしてその状態で去る`j`。 

### セグメントの結合

 セグメントを想定`X`マトリックスあり`M1`とセグメント`Y`マトリックスあり`M2`。 

走査`X`に続く`Y`max-plus 乗算に正確に対応します。$$M = M_1 \otimes M_2$$どこ$$M[i][j] = \max_k (M_1[i][k]+M_2[k][j])$$これは、状態の左セグメントを終了した後であるため、機能します。`k`、同じ状態から右側のセグメントを続行します。 

結合性は、max-plus 行列乗算の結合性から得られます。 

### セグメントツリーの構築

 各リーフには、1 つの配列位置に対応する行列が格納されます。 

内部ノードは、その子の最大プラス積を保存します。 

### 更新を処理しています

 いつ`a[p]`または`b[p]`変更:

 1. 葉のマトリックスを再構築する`p`。 
2. ルートへのパス上の行列を再計算します。 

のみ`O(log n)`ノードが変化します。 

### クエリの処理

 範囲用`[l,r]`:

 1. その区間をカバーするセグメントツリー行列を収集します。 
2. それらを左から右の順序で乗算します。 
3. 結果の行列を次のようにします。`M`。 
4. 答えは次のとおりです。`M[0][4]`。 

州`0`は、間隔に入る前に何も選択されていないことを意味します。 

州`4`2 つの完全な重複しないサブアレイが構築されたことを意味します。 

その遷移に保存されている最大値は、まさに必要な答えです。 

### なぜ効果があるのか

 5 つの状態は、位置を左から右にスキャンしながら 2 つの互いに素なサブ配列を構築する可能なすべての段階を表します。 

状態からの移行`1`述べます`1`は、現在位置が最初の部分配列の内部に属していることを意味します。 からの移行`1`に`2`は、現在位置が右端点であることを意味します。 同じ解釈が州にも当てはまります`3`そして`4`2 番目のサブ配列の場合。 

状態は前方にのみ進むため、最初の部分配列が終了する前に 2 番目の部分配列を開始することはできません。 これにより、非重複が自動的に強制されます。 

各位置は、サブ配列値の定義で必要な数量に正確に寄与します。エンドポイント ボーナスは、サブ配列に入るときまたは出るときに追加され、含まれるすべての位置がその値に寄与します。`a`拡張トランジションを通じて価値を高めます。 

セグメントのマトリックスには、可能な開始状態と終了状態のすべてのペアの最適値が格納されます。 Max-plus multiplication correctly concatenates neighboring segments, so the matrix of a queried interval describes all valid ways to build two subarrays inside that interval. 状態からの移行`0`述べます`4`これは、2 つの完全な重複しない部分配列を構築することに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

NEG = -(10 ** 30)
SZ = 5

class Node:
    __slots__ = ("m",)

    def __init__(self):
        self.m = [[NEG] * SZ for _ in range(SZ)]

def leaf(a, b):
    x = Node()

    for i in range(SZ):
        x.m[i][i] = 0

    x.m[0][1] = max(x.m[0][1], b)

    x.m[1][1] = max(x.m[1][1], a)
    x.m[1][2] = max(x.m[1][2], a + b)

    x.m[2][3] = max(x.m[2][3], b)

    x.m[3][3] = max(x.m[3][3], a)
    x.m[3][4] = max(x.m[3][4], a + b)

    return x

def merge(left, right):
    res = Node()

    A = left.m
    B = right.m
    C = res.m

    for i in range(SZ):
        Ai = A[i]
        Ci = C[i]

        for k in range(SZ):
            if Ai[k] == NEG:
                continue

            v = Ai[k]
            Bk = B[k]

            for j in range(SZ):
                cand = v + Bk[j]
                if cand > Ci[j]:
                    Ci[j] = cand

    return res

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

size = 1
while size < n:
    size <<= 1

seg = [Node() for _ in range(2 * size)]

for i in range(size):
    if i < n:
        seg[size + i] = leaf(a[i], b[i])
    else:
        idm = Node()
        for j in range(SZ):
            idm.m[j][j] = 0
        seg[size + i] = idm

for i in range(size - 1, 0, -1):
    seg[i] = merge(seg[i << 1], seg[i << 1 | 1])

def update(pos):
    p = pos + size
    seg[p] = leaf(a[pos], b[pos])

    p >>= 1
    while p:
        seg[p] = merge(seg[p << 1], seg[p << 1 | 1])
        p >>= 1

def identity():
    x = Node()
    for i in range(SZ):
        x.m[i][i] = 0
    return x

def query(l, r):
    left_res = identity()
    right_res = identity()

    l += size
    r += size

    while l <= r:
        if l & 1:
            left_res = merge(left_res, seg[l])
            l += 1

        if not (r & 1):
            right_res = merge(seg[r], right_res)
            r -= 1

        l >>= 1
        r >>= 1

    res = merge(left_res, right_res)
    return res.m[0][4]

q = int(input())

ans = []

for _ in range(q):
    t, p, x = map(int, input().split())

    if t == 1:
        a[p - 1] = x
        update(p - 1)
    elif t == 2:
        b[p - 1] = x
        update(p - 1)
    else:
        l = p - 1
        r = x - 1
        ans.append(str(query(l, r)))

print("\n".join(ans))
```リーフ行列は、単一の位置で発生する可能性のあるすべてのアクションをエンコードします。 同じ状態に留まると値が 0 になり、位置をスキップできます。 

マージ関数は、max-plus 行列の乗算を実行します。 マトリックスのサイズは 5 に固定されているため、各マージのコストはわずかです。`5³ = 125`操作。 

範囲クエリでは、標準の反復セグメントツリー手法が使用されます。 セグメントツリーのフラグメントが左側と右側から異なる順序で収集されるため、2 つのアキュムレータが維持されます。 左から右への乗算順序を維持することが重要です。 これを逆にすると、DP セマンティクスが壊れます。 

すべての値は 64 ビット スケールの整数として保存されます。 最大の答えは次のとおりです`4·10^14`したがって、Python の整数で十分です。
