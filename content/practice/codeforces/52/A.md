 ## 解決策
 ## 問題の理解

 すべての数値が 1、2、または 3 のいずれかである整数のリストが与えられます。目標は、すべての数値が同じになるようにシーケンスを変換することであり、可能な限り最小の置換数を使用してこれを行う必要があります。 各置換は、数値を他の 2 つの値のいずれかに変更することで構成されます。 入力は整数で始まります`n`シーケンスの長さを指定し、その後に`n`整数。 出力は、必要な変更の最小数を表す単一の整数です。 

制約を見てみると、`n`最大100万まで可能です。 これにより、計算量が爆発的に増加するため、考えられるすべての置換シーケンスを反復したり、変換のあらゆる組み合わせを試行したりするアルゴリズムは即座に除外されます。 ここでは線形時間アプローチが受け入れられます。`n`は最大 10^6 であり、10^6 から 10^7 程度の操作は 2 秒の制限時間内で快適に実行されます。 

考慮すべきエッジケースには、すべての数値がすでに同じであるシーケンス、各数値がまったく同じ回数出現するシーケンス、および要素が 1 つだけあるシーケンスが含まれます。 たとえば、シーケンスが次の場合、`[2]`、代替品は必要ありません。答えは次のとおりです。`0`。 シーケンスが`[1, 2, 3]`の場合、最良の選択は、すべての数値を 1、2、または 3 にすることであり、2 つの変更が必要になります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 すべての数値を 1 に、次にすべて 2 に、最後にすべてを 3 にして、それぞれの場合に必要な変更の数を数え、最小値を取得します。 これら 3 つのターゲット値のいずれかによって必ず最小数の置換が生成されるため、この方法は正しいです。 この方法のコストは次のように比例します。`3 * n`ターゲット番号ごとに、配列全体をスキャンして不一致をカウントする必要があるためです。 この問題ではこれは許容されます。`3 * 10^6`操作は管理可能ですが、より厳密な時間設定や数値範囲が大きい場合、このアプローチは非効率的になります。 

問題をさらに最適化するための重要な洞察は、シーケンスの変更をシミュレートする必要がまったくないことを認識することです。 重要なのは、各数字が何回出現するかです。 1、2、および 3 の数がわかっている場合、置換の最小数は全長から最大数を引いたものになります。 これは、すべての要素をすでに最も頻繁に出現する数値に変換することが最適な選択であるためです。 これにより、問題は単純な計数問題に縮小され、配列の 1 回のパスで解決できます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(3 * n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 数値ごとに 1 つずつ、3 つのカウンターを初期化します。`count1`、`count2`、 そして`count3`。 それぞれがシーケンス内で 1、2、3 が何回出現したかを記録します。 これは、最適な交換戦略を決定するために必要な最小限の情報です。 
2. シーケンス内の各数値を繰り返します。 数値が 1 の場合は増加します`count1`。 2の場合はインクリメントします`count2`。 それ以外の場合はインクリメントします`count3`。 このようにカウントすると、1 回の線形パスで完全な周波数マップが得られます。 
3. 3 つのカウントの最大周波数を決定します。 これは、シーケンスの残りの部分を変換する必要がある数値を表します。 させて`max_count`の中で最大になる`count1`、`count2`、 そして`count3`。 
4. 必要な最小置換数は、シーケンスの全長からこの最大数を引いたものです。`n - max_count`。 これが機能するのは、最大カウント要素がすでに正しいため、残りの要素は一致するように変更する必要があるからです。 

機能する理由: 各時点で、考えられる各値の出現数を維持します。 任意の数値を他の数値に変更できるため、最適な戦略は常に、最も頻繁に発生する値を選択し、残りを変換することです。 最も頻度の高い数値から逸脱すると必然的により多くの要素の変更が必要となるため、他の戦略では必要な変更を少なくすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

count1 = count2 = count3 = 0
for num in a:
    if num == 1:
        count1 += 1
    elif num == 2:
        count2 += 1
    else:
        count3 += 1

max_count = max(count1, count2, count3)
print(n - max_count)
```コードは、次を使用して入力を効率的に読み取ることから始まります。`sys.stdin.readline`大きな入力サイズの場合。 次に、シーケンス内の可能な値ごとにカウンターを初期化します。 反復中に、各数値が適切なカウンターをインクリメントし、off-by-one エラーが発生しないようにします。 カウント後、最大カウントを計算し、それを次から引きます。`n`最小限の置換数を得るために。 このアルゴリズムは不必要なデータ構造を回避し、O(1) スペースを確保します。

## 複雑さの分析

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    count1 = count2 = count3 = 0
    for num in a:
        if num == 1:
            count1 += 1
        elif num == 2:
            count2 += 1
        else:
            count3 += 1
    return str(n - max(count1, count2, count3))

# Provided sample
assert run("9\n1 3 2 2 2 1 1 2 3\n") == "5", "sample 1"

# Custom cases
assert run("1\n1\n") == "0", "single element"
assert run("5\n2 2 2 2 2\n") == "0", "all equal"
assert run("3\n1 2 3\n") == "2", "all different"
assert run("6\n1 1 2 2 3 3\n") == "4", "equal counts"
assert run("10\n3 3 3 3 3 3 3 3 3 3\n") == "0", "all 3s"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1\n1 | 0 | 単一要素シーケンス |
 | 5\n2 2 2 2 2 | 0 | すでに均一なシーケンス |
 | 3\n1 2 3 | 2 | すべての個別の値を持つシーケンス |
 | 6\n1 1 2 2 3 3 | 4 | カウントが等しいシーケンス |
 | 10\n3 3 3 3 3 3 3 3 3 3 | 0 | すべての最大長の繰り返し値を含むシーケンス |
