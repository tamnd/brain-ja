 ## 解決策
 ## 問題の理解

 各セルが空かマークが付いている長方形のグリッドが与えられます。`*`。 毎`*`cell は、そのセルの中心に位置する点を表します。 次のように直角三角形がいくつ形成できるかを数える必要があります。 

- 3 つの頂点はすべて`*`細胞、
 - the right angle is formed by one horizontal side and one vertical side,
 - the legs of the triangle are parallel to the grid axes.

 A triangle is fully determined once we choose the vertex containing the right angle. もし`*`セルには別のものがあります`*`同じ列のどこかと別の列`*`somewhere in the same column, then those two choices form a valid right triangle.

 グリッドの寸法は最大でも`1000 × 1000`, したがって、セルの総数は 100 万に達する可能性があります。 すべてのトリプルをチェックするソリューション`*`セルは完全に不可能です。 すべてのセルをその行および列内のすべてのセルに対して単純にチェックしても、繰り返し実行すると速度が非常に遅くなる可能性があります。 

有益な観察は、固定直角頂点の場合、水平方向と垂直方向の選択が独立しているということです。 細胞が持っている場合`r`同じ列にある他の星と`c`その列の他のスターが貢献する場合`r * c`三角形。 

いくつかのエッジケースでは、不正な実装が静かに破壊される可能性があります。 

行が 1 つだけあるグリッドを考えてみましょう。```
1 5
*****
```正しい答えは、`0`。 水平方向に多くのペアが存在しても、垂直方向の脚は形成されません。 

直角の頂点自体が誤って選択肢の 1 つとしてカウントされるグリッドを考えてみましょう。```
2 2
**
**
```正しい答えは、`4`。 

各コーナーはちょうど 1 つの三角形に寄与します。 

- 左上は右上と左下を使用します。 
- 右上は左上と右下を使用します。 
- 左下は左上と右下を使用します。 
- 右下は右上と左下を使用します。 

を使用した不用意な数式`row_count * col_count`の代わりに`(row_count - 1) * (col_count - 1)`頂点がそれ自体とペアになることを許可することでオーバーカウントします。 

行または列に星が 1 つだけ含まれている場合には、別の微妙なケースが発生します。```
3 3
*..
.*.
..*
```答えは`0`。 すべての星は行と列の両方で孤立しているため、合計 3 つの星があっても直角三角形は存在しません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 次のトリプルをすべて列挙します`*`セルを作成し、軸が揃った有効な直角三角形を形成しているかどうかをテストします。 

グリッドが完全に埋まっていると仮定します。 それから、`10^6`星。 すべてのトリプルをチェックするには、大まかに次のことが必要になります。$$\binom{10^6}{3}$$天文学的に不可能な操作です。 

もう少し優れた総当りアプローチでは、最初に直角の頂点を修正します。 あらゆる人にとって`*`セルの場合、行全体をスキャンして水平方向のパートナーを見つけ、列全体をスキャンして垂直方向のパートナーを見つけます。 細胞が持っている場合`r`水平方向の選択肢と`c`垂直方向の選択が貢献する`r * c`。 

このアプローチは正しいです。すべての有効な三角形には直角の頂点が 1 つだけあり、その頂点が固定されると、水平および垂直の端点を独立して選択できるからです。 

問題はパフォーマンスです。 すべてのセルに対して行と列を繰り返しスキャンすると、複雑さは次のようになります。$$O(n \cdot m \cdot (n + m))$$と`n = m = 1000`、最悪の場合、これは約 20 億の操作になります。 

重要な点は、行と列の情報が決して変更されないことです。 カウントを繰り返し再計算する代わりに、以下を前処理できます。 

- 各列に星がいくつあるか、
 - 各列に星の数が存在するか。 

それからそれぞれ`*`セルは一定時間内にその寄与を計算できます。 

セルの場合`(i, j)`星が含まれています:

 -`row[i] - 1`同じ列にある他の星の数を与えます。 
-`col[j] - 1`同じ列内の他の星の数を示します。 

彼らの積は、次の式を使用して正確に直角三角形の数になります。`(i, j)`直角の頂点として。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n · m · (n + m)) | お(1) | 遅すぎる |
 | 最適 | O(n・m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、保存します。 
2. 配列を作成する`row`どこ`row[i]`の数を保存します`*`並んだセル`i`。 
3. 配列を作成する`col`どこ`col[j]`の数を保存します`*`列内のセル`j`。 
4. グリッドを 1 回横断して、これらの配列を埋めます。 

毎回、`*`で見つかります`(i, j)`、増分:

 -`row[i]`-`col[j]`5. グリッドを再度横断します。 
6. あらゆる人にとって`*`細胞`(i, j)`、次を計算します。$$(row[i] - 1) \times (col[j] - 1)$$減算により、現在のセル自体が両方のカウントから削除されます。 

1. すべての投稿を最終回答に追加します。 
2. 答えを印刷します。 

### なぜ効果があるのか

 すべての有効な三角形には、固有の直角の頂点があります。 頂点が固定されると、1 つの頂点が同じ行に存在し、別の頂点が同じ列に存在する必要があります。 

スターの場合`(i, j)`:

 - まさにあります`row[i] - 1`有効な水平方向の選択、
 - まさにあります`col[j] - 1`有効な垂直方向の選択。 

このような選択肢のすべてのペアは 1 つの固有の直角三角形を形成し、すべての有効な三角形はその直角の頂点から 1 回だけ数えられます。 どの三角形も 2 つの直角を持つことができないため、重複は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())

grid = [input().strip() for _ in range(n)]

row = [0] * n
col = [0] * m

for i in range(n):
    for j in range(m):
        if grid[i][j] == '*':
            row[i] += 1
            col[j] += 1

ans = 0

for i in range(n):
    for j in range(m):
        if grid[i][j] == '*':
            ans += (row[i] - 1) * (col[j] - 1)

print(ans)
```最初の走査では、各行と列に表示される星の数を計算します。 この前処理が全体の最適化です。 これがなければ、すべてのセルの行と列を繰り返しスキャンすることになります。 

2 番目の走査では、それぞれを評価します。`*`セルは独立しています。 式:```
(row[i] - 1) * (col[j] - 1)
```以下の可能なすべての組み合わせをカウントします。 

- 同じ列の別の星、
 - 同じ列の別の星。 

引き算`1`現在のセルは両方のカウントに属しているため、これは必須です。 これを忘れると、1 つの端点が直角の頂点自体に等しい無効な三角形が作成されます。 

答えは大きくなる可能性がありますが、Python の整数は任意のサイズを自動的に処理します。 固定幅整数を使用する言語では、64 ビット型が必要です。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n, m = map(int, input().split())

    grid = [input().strip() for _ in range(n)]

    row = [0] * n
    col = [0] * m

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                row[i] += 1
                col[j] += 1

    ans = 0

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                ans += (row[i] - 1) * (col[j] - 1)

    print(ans)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()

    backup_stdout = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup_stdout
    return out.getvalue().strip()

 ## 特殊なケース

 単一行の場合を考えてみましょう。```
1 5
*****
```唯一の行の行数は次のとおりです。`5`ただし、すべての列数は`1`。 

各星について:

 -`row[i] - 1 = 4`-`col[j] - 1 = 0`すべての貢献は次のようになります。$$4 \times 0 = 0$$最終的な答えは、`0`垂直脚は存在できないため、これは正しいです。 

次に、完全に満たされたものを考えてみましょう`2x2`グリッド：```
2 2
**
**
```すべての行数と列数が等しい`2`。 

4 つのセルのそれぞれについて:

 -`row[i] - 1 = 1`-`col[j] - 1 = 1`それぞれが 1 つの三角形に寄与します。 

合計：$$4 \times 1 = 4$$これは、減算する理由を裏付けています`1`重要です。 減算がないと、各セルはそれ自体をパートナーとして誤ってカウントしてしまいます。 

最後に、対角線上に孤立した星を考えます。```
3 3
*..
.*.
..*
```すべての行数と列数が等しい`1`。 

すべての星について:

 -`row[i] - 1 = 0`-`col[j] - 1 = 0`すべての寄与はゼロであるため、アルゴリズムは有効な直角三角形が存在しないことを正しく報告します。
