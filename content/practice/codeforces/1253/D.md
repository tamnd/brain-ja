 ## 解決策
 ## 問題の理解

 1 から n までのラベルが付けられた頂点上の無向グラフが与えられ、エッジを追加することができます。 目標は、頂点の自然な順序に依存する非常に具体的な到達可能性の制約をグラフが満たすようにすることです。 

この条件は、既存のエッジを使用して頂点 l が頂点 r に到達できる場合は常に、ラベルが厳密に l と r の間にあるすべての頂点も l から到達可能でなければならないことを示しています。 言い換えれば、l から r への接続は中間ラベルを「スキップ」できません。 l が r に到達できる場合、数値区間 [l, r] 内のすべての頂点が l の接続領域内に存在する必要があります。 

到達可能性はノードの順序と相互作用するため、これは標準的な接続要件ではありません。 連結成分は許可されますが、数直線上への投影は連続した区間のように動作する必要があります。そうでない場合は、「穴」を修正するためにエッジを追加する必要があります。 

n、m が最大 200,000 という制約により、ノードのペアやクエリごとの単純な BFS に対する二次推論から遠ざけられます。 どのような解も線形または線形演算に近いものでなければなりません。 順序付けされた軸上の接続間隔について繰り返し推論しているため、素のセット構造やソートされたエッジに対する貪欲なスイープが自然になります。 

コンポーネントの数値範囲が広いにもかかわらず内部ノードが欠落している場合、微妙なエッジ ケースが発生します。 たとえば、1 が 5 に接続されているが、1 から 3 に到達できない場合、通常の意味で接続が存在していても、グラフは無効であるため修復する必要があります。 もう 1 つのエッジ ケースは、複数のコンポーネントが数値範囲内で重複しているが、実際には接続されていない場合です。これにより、到達可能性を注意深く追跡しないと違反が隠れてしまう可能性があります。 

## アプローチ

 ブルートフォースのアイデアは、頂点 l と r のすべてのペアの条件を明示的にチェックすることです。 各 l について、DFS または BFS を実行して、到達可能なすべてのノードを検索し、到達可能なすべての r について、すべての中間ノードも到達可能であることを確認できます。 これではすぐに高価になってしまいます。 ノードあたりの 1 つの DFS は O(n + m) ですが、これをすべてのノードに対して実行すると O(n(n + m)) となり、制限をはるかに超えます。 

重要な観察は、この条件は基本的に個々のパスではなく、接続されたコンポーネントに関するものであるということです。 接続コンポーネントに注目すると、その最小ラベルが l で最大ラベルが r の場合、l と r の間のすべてのノードが同じコンポーネントに属している必要があるというルールが必要です。 そうしないと、条件に違反するギャップが存在します。 

これにより、問題は、各連結成分が数直線上で「区間完全」になるように強制されます。 コンポーネントが l から r に及ぶ場合、その範囲内のすべてのノードがその中になければなりません。 [l, r] 内のノードが外側にある場合は、それを内側に接続する必要があります。 

これは、ノードを昇順にスイープしながらエッジをソートするか、DSU を使用することを示唆しています。 私たちはコンポーネントを維持し、コンポーネントの範囲内にギャップが見つかった場合は常に、エッジを追加してそれをマージまたは「埋める」ようにします。 標準的な解決策は、各コンポーネントの到達可能な最も遠い境界を維持しながら、ノードを昇順に処理することです。 ノードが以前に確認したコンポーネントのスパン内にあるが接続されていないことを検出した場合は、必ず接続して、応答を増やし、それに応じてコンポーネントをマージする必要があります。 

DSU 構造はコンポーネントを効率的に維持する一方で、これまでに検出されたコンポーネントの最大の正しいエンドポイントを追跡します。 左から右にスキャンするときに、ノードがアクティブな間隔内にあるが接続されていない場合、効果的にノードをブリッジします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (マルチ BFS/DFS チェック) | O(n(n + m)) | O(n + m) | 遅すぎる |
 | DSU + ソートされた構造に対する貪欲なスイープ | O((n + m) α(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

ノードを昇順に処理し、素セット結合構造を使用して接続されたコンポーネントを維持します。 

1. n 個のノードすべてで DSU を初期化します。 これは、指定されたエッジからの現在の接続を表します。 
2. ノード 1 から n までを繰り返し、各ノードをコンポーネントの潜在的な左境界として扱います。 現在のコンポーネントから到達可能な最大インデックスを追跡するポインターまたは境界を維持します。 最初は、これは単なるノードそのものです。 
3. 各ノード i について、DSU を使用して、その現在の接続コンポーネントの右端のエンドポイントを計算します。 これにより、このコンポーネントがすでに数値的にどれだけ伸びているかがわかります。 
4. i から右端のエンドポイントまでのすべてのノードをスキャンします。 この間隔内で別の DSU コンポーネントに属するノード j を見つけた場合は、それを接続する必要があります。 現在のコンポーネントの代表と j の間にエッジを追加し、答えをインクリメントして、DSU でそれらを結合します。 

これが機能する理由は、間隔内の欠落しているノードが「到達可能性のギャップなし」ルールの違反を表すためです。 
5. コンポーネントを結合するたびに、結合によって間隔が拡大する可能性があるため、最も右の境界を再計算します。 
6. スキャンが安定するまで続行します。つまり、間隔内のすべてのノードが同じ DSU コンポーネントに属します。 

### なぜ効果があるのか

 不変条件は、ノードのプレフィックスを処理した後、このプレフィックスと交差するすべての連結コンポーネントがノード ラベルに関して連続した間隔を形成するということです。 現在の間隔内でまだ接続されていないノードを検出すると、それを明示的にマージし、ギャップを排除します。 ギャップが見つかった場合にのみエッジを追加するため、すべての不連続性を除去するために必要な最小限の数のエッジを追加します。 DSU は、ノードがマージされると、それらが一貫して単一の間隔として扱われることを保証し、冗長または競合するマージを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return False
        if self.size[a] < self.size[b]:
            a, b = b, a
        self.parent[b] = a
        self.size[a] += self.size[b]
        return True

def solve():
    n, m = map(int, input().split())
    dsu = DSU(n)

    for _ in range(m):
        u, v = map(int, input().split())
        dsu.union(u, v)

    ans = 0

    i = 1
    while i <= n:
        root = dsu.find(i)
        r = i

        # expand interval of this component
        for j in range(i, n + 1):
            if dsu.find(j) == root:
                r = j

        # fill gaps inside [i, r]
        j = i
        while j <= r:
            if dsu.find(j) != root:
                ans += 1
                dsu.union(root, j)
                root = dsu.find(root)
                r = max(r, j)
            j += 1

        i += 1

    print(ans)

if __name__ == "__main__":
    solve()
```DSU は、元のエッジからの接続を維持するために使用されます。 外側のループは開始点 i を選択し、前方にスキャンして現在のコンポーネントのスパンを特定します。 内側のループは、そのスパン内の欠落しているノードをチェックし、ギャップが見つかるたびに結合を強制します。 各和集合は 1 つのエッジの追加に対応し、これが答えに直接寄与します。 

重要な実装の詳細は、結合のたびに代表者が変わる可能性があるため、ルートを再計算し、場合によっては間隔を延長することです。 ルートを正しく更新できないと、到達可能性が過小評価され、必要なエッジが欠落することにつながります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n α(n)) | DSU 運用が大半を占め、各ほぼ一定の償却が行われます。 
| スペース | O(n) | DSU の親とサイズの配列 |

 ## 特殊なケース

 重要なエッジ ケースは、接続が大きな数値間隔にまたがるが、内部ノードをスキップする場合です。 たとえば、エッジがパスを介して 1 から 10 に接続しているが、ノード 5 が分離されている場合、アルゴリズムは 5 が区間 [1, 10] 内にあることを検出し、結合を強制します。 これにより、到達可能性はあるが間隔の連続性が壊れている場合のサイレント違反が防止されます。 

もう 1 つのエッジ ケースは、完全に接続されていないグラフです。 その場合、すべてのノードが独自のコンポーネントを形成し、スキャンによって欠落しているカバレッジが繰り返し検出され、エッジが追加されて単一の間隔のような構造にマージされます。 このアルゴリズムは、条件の要求に応じて単一の連結区間コンポーネントを自然に構築します。
