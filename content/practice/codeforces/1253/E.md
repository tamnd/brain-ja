 ## 解決策
 ## 問題の理解

 数直線上に配置された信号塔のセットが与えられています。 各タワーには固定位置と対称的なカバレッジ半径があります。 所定の位置にある塔$x_i$半径あり$s_i$からのすべての整数点をカバーします$x_i - s_i$に$x_i + s_i$。 各タワーの半径は固定されていません。それを増やすことができ、各ユニットの増加には 1 コインのコストがかかります。 

目標は、すべての整数が 1 ～$m$半径の一部を拡張すると、少なくとも 1 つの塔で覆われます。 

重要な観察は、カバレッジが線上で連続しており、半径を増加させると間隔が対称的に拡大するということです。 重複を避ける必要がないため、複数のタワーがペナルティなしで同じ領域をカバーできます。 唯一の要件は、すべての拡張された間隔の和集合が完全にカバーすることです。$[1, m]$。 

アンテナの数という点では制約は小さく、最大 80 ですが、座標範囲は最大 100,000 までと広いです。 これは、アンテナを反復するのは問題ないが、カバレッジをポイントごとにシミュレートしようとしたり、回線全体にわたる強引な間隔拡張を試みたりするソリューションでは遅すぎることがすぐにわかります。 アンテナのすべてのサブセットにわたる単純な動的プログラミングには、以下が含まれます。$2^{80}$状態、それは実行不可能です。 

単一のアンテナがすでに間隔の一部をカバーしているものの、有効な方向ではない場合、微妙なエッジ ケースが発生します。 たとえば、右端のアンテナはすでに、より広い位置をカバーしている可能性があります。$m$ただし、覆われていない左側に到達するには拡張が必要です。 同様に、重なりが大きいアンテナは、現在のカバレッジに基づいて貪欲な選択を試みる可能性がありますが、拡張コストは重なり構造ではなく、覆われていない境界までの距離に依存するため、これは失敗します。 

## アプローチ

 強引なアイデアは、回線のどのセグメントをどの程度カバーするためにどのアンテナを拡張するかを選択することを考えることです。 責任の割り当てが固定されている場合、各アンテナは、必要なセグメントのエンドポイントに到達できるように間隔を延長するのに十分なコストを支払います。 これにより、間隔を分割するあらゆる方法を検討することになります。$[1, m]$アンテナに割り当てられた断片に分割され、組み合わせ爆発性があります。 

重要な構造上の洞察は、アンテナを位置ごとに分類した後、最適なソリューションが左から右へ順番にラインをカバーするように動作するということです。 特定のアンテナがセグメントを担当すると判断した場合、そのアンテナの最善の役割は、その位置を中心とする連続した間隔をカバーすることです。 セグメントをカバーするためにアンテナを延長するコスト$[L, R]$両方のエンドポイントを含めるために、その自然な間隔がどの程度まで拡大する必要があるかを単純に表します。 

これにより、問題は 1 次元のカバレッジ DP に変換されます。つまり、すでにどこまでカバーしているかを考慮し、どのアンテナが最小限の増分コストでカバレッジをさらに拡張できるかを決定します。 なぜなら$n \le 80$、アンテナとカバレッジ境界間の遷移を考慮した DP を用意できます。 

アンテナを位置ごとに分類し、処理したアンテナの数と右側のどの範囲までカバーできたかに基づいて状態を定義します。 各アンテナについて、拡張された間隔を使用して、現在の境界からカバレッジを拡張しようとします。 コストは、左側の境界が現在のカバーされていない位置に到達するために半径をどれだけ増加させる必要があるかによって決まります。 

重要な単純化は、カバレッジを拡張するためにアンテナが選択されると、その拡張は、現在のカバーされていないポイントに接触し、場合によってはさらに右に拡張するという要件によって完全に決定されることです。 追加の拡張は将来のカバー範囲に役立つだけであるため、アンテナを部分的に拡張する理由はありません。

 ## アルゴリズムのチュートリアル

 まず、各アンテナをその位置を中心とする間隔に変換します。 アンテナ用$i$、現在の対象範囲は$[x_i - s_i, x_i + s_i]$。 

1. アンテナを位置ごとに分類します。 これにより、左から右へのカバレッジ戦略を一貫した順序で表現できるようになります。 
2. DP 状態を定義する$dp[i]$インデックスまでのアンテナを使用して、ある境界までの回線のプレフィックスを完全にカバーするために必要な最小コストとして$i$。 遷移を意味のあるものにするために、アンテナを使用して現在の境界から新しい境界にカバレッジを拡張するものとして DP 遷移を解釈します。$i$。 
3. 各アンテナについて$i$、次のセグメント拡張子として考慮してください。 現在のカバーされていないポイントが の位置にある場合$L$、次にアンテナ$i$左端が最大で到達するまで半径を拡張する必要があります。$L$。 これにより、必要な新しい半径が次のように決定されます。$r = x_i - L$。 
4. 半径が左側の境界を満たすように固定されると、アンテナは最大でカバーします。$x_i + r$。 これにより、新しい覆われた境界が得られます$R = x_i + r$。 
5. コスト寄与分は、初期半径と比較した半径の増加です。$s_i$、だから私たちが支払います$\max(0, r - s_i)$。 
6. 到達可能なすべての境界状態からすべてのアンテナを次のエクステンダとして試行することで、DP 遷移を緩和します。 
7. 答えは、少なくとも最大の補償範囲を達成するための最小コストです。$m$。 

### なぜ効果があるのか

 どの時点でも、カバーされていない領域は常に左端の 1 つの点から始まります。$L$。 次に貢献するアンテナはこの点をカバーする必要があります。そうでない場合は意味がありません。 アンテナを強制的にかぶせたら$L$、最適な使用方法は、到達するのに十分なだけ拡張することです。$L$なぜなら、小規模な拡張ではカバレッジが適用されず、大規模な拡張ではコストが不必要に増加するか、後でより安価に実現できる冗長なカバレッジが提供されるだけだからです。 これにより、次に露出する境界をどのアンテナが担当するかを選択するという決定が軽減され、後戻りや重複の競合なしに、最適なソリューションをそのような選択のシーケンスに分解できることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    ants = []
    for _ in range(n):
        x, s = map(int, input().split())
        ants.append((x, s))
    
    ants.sort()
    
    INF = 10**18
    
    # dp[i][j] = min cost using first i antennas to reach coverage up to position j
    # we compress states dynamically using only reachable boundaries
    dp = {0: 0}  # coverage -> cost
    
    for x, s in ants:
        new_dp = dp.copy()
        
        for covered, cost in dp.items():
            if covered >= m:
                continue
            
            # we want this antenna to cover position (covered + 1)
            L = covered + 1
            
            # minimal radius needed so left end reaches L
            r = x - L
            
            if r < 0:
                continue
            
            add_cost = max(0, r - s)
            new_covered = x + r
            
            if new_covered > m:
                new_covered = m
            
            new_cost = cost + add_cost
            
            if new_covered not in new_dp or new_dp[new_covered] > new_cost:
                new_dp[new_covered] = new_cost
        
        dp = new_dp
    
    ans = dp.get(m, INF)
    print(ans)

if __name__ == "__main__":
    solve()
```実装では、すでにカバーしている範囲から、それを達成するために必要な最小コストまでのマッピングが維持されます。 各アンテナについて、それを無視するか、現在の境界からカバレッジを拡張する責任をアンテナに割り当てます。 この移行では、次のカバーされていない位置に到達するためにアンテナをどの程度拡張する必要があるかを正確に計算し、それをコストに換算します。 

微妙な点は、アンテナが常に、前の任意の点ではなく、次のカバーされていない位置から正確に開始するように強制することです。 これにより、二重カウントが回避され、左から右への単調な構造が保証されます。 もう 1 つの重要な詳細は、適用範囲の上限を次のとおりに設定することです。$m$, since anything beyond is irrelevant for the objective.

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import inf

    n, m = map(int, sys.stdin.readline().split())
    ants = [tuple(map(int, sys.stdin.readline().split())) for _ in range(n)]
    ants.sort()

    INF = 10**18
    dp = {0: 0}

    for x, s in ants:
        new_dp = dp.copy()
        for covered, cost in dp.items():
            if covered >= m:
                continue
            L = covered + 1
            r = x - L
            if r < 0:
                continue
            add = max(0, r - s)
            nc = min(m, x + r)
            new_cost = cost + add
            if nc not in new_dp or new_dp[nc] > new_cost:
                new_dp[nc] = new_cost
        dp = new_dp

    return str(dp.get(m, INF))

 ## 特殊なケース

 主なエッジ ケースは、アンテナが現在のカバーされていない位置の右側にあるにもかかわらず、依然として左側に拡張する必要がある場合です。 たとえば、現在のカバレッジが 10 で終了し、アンテナが半径 0 の位置 15 にある場合、10 に戻るには少なくとも 5 ユニットに拡張する必要があります。アルゴリズムはこれを処理します。$r = x_i - L$、アンテナが遠くにある場合でも、必要な半径を正確に計算します。 

もう 1 つのケースは、アンテナが拡張せずに必要な境界をすでにカバーしている場合です。 もし$s_i \ge x_i - L$、 それから$r - s_i \le 0$となり、追加コストはゼロになります。 これにより、すでに十分なアンテナに対して過剰な支払いをすることがなくなります。 

最後に、複数のアンテナが重なり合うケースは、正確さに影響しません。これは、各 DP 遷移がアンテナを独立して扱い、現在の境界を拡張することのみを考慮し、切り離された責任を維持しないためです。
