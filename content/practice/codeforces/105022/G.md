 ## 解決策
 ## 問題の理解

 長さ N の 2 つのシーケンスが与えられ、それらを使用して N × N 行列を定義します。ここで、すべてのエントリは、最初のシーケンスの行の重みと 2 番目のシーケンスの列の重みを乗算することによって形成されます。 具体的には、エントリ (i, j) は a_i と b_j を乗算したものであるため、すべての行は同じベクトルのスケーリングされたコピーであり、すべての列も同じ乗算方法で構造化されています。 

この行列 A から、標準的な行列乗算で A の K 乗を計算するように求められます。 A^K を取得した後は、完全な行列は必要ありません。 対象となる唯一の数量は、すべてのエントリの合計です。 

この制約により、N は最大 100000 まで許可され、完全な N x N 構造での直接の行列乗算や累乗は即座に除外されます。 単一の行列の乗算には、単純な形式ですでに N^3 の演算が必要ですが、これは 100000 どころか、N = 1000 の場合でも制限をはるかに超えています。行列が密であるため、最適化された乗算でも依然として大きすぎます。 

指数 K は 998244352 まで大きくなる可能性があり、これも反復乗算を除外します。 有効な解決策では、問題を O(N) または O(1) の集合体の演算に落とし込み、べき乗を対数時間以上で処理する必要があります。 

K = 0 の場合、微妙なエッジ ケースが現れます。その場合、a_i と b_i に関係なく、A^0 が単位行列になります。 対角要素のみが 1 であるため、その要素の合計は正確に N になります。正の累乗について導出された式は、個別に処理しない限り、通常、K = 0 で壊れます。 

もう 1 つの特殊なケースは K = 1 です。この場合、答えは A 自体のすべてのエントリの合計に減らされる必要があります。 その値は、(sum a_i) と (sum b_i) の積です。 派生した式はすべて、これに完全に崩壊する必要があります。 

最後に、ドット積や累乗などの中間積は 998244353 を法として取得する必要があるため、a_i または b_i の負の値が重要になります。モジュラー リダクションを遅らせる不用意な実装は、オーバーフローしたり、不正な動作を引き起こす可能性があります。 

## アプローチ

 この問題にアプローチする単純な方法は、2 つのシーケンスから行列 A を明示的に構築し、標準的な行列の乗算を使用してそれ自体を K 回乗算することです。 2 つの N × N 行列の各乗算には O(N^3) の演算が必要で、それを K 回繰り返すと、たとえ小さな N であっても複雑さが法外なものになります。N = 100000 での 1 回の乗算ですら、時間とメモリの両方の理由から不可能です。 

重要な構造的観察は、A が一般行列ではないということです。 すべてのエントリは行依存項と列依存項の積です。これは、A が 2 つのベクトルの外積であることを意味します。 これにより、A はランク 1 の行列になります。 ランク 1 行列は乗算時に非常に強力な閉包特性を持ちます。2 つのランク 1 行列の積はランク 1 のままであり、構造は予測可能なスカラー方式で進化します。 

A = a * b^T と書くと、A を単独で乗算すると、外積構造を維持しながら、内積 b^T a を含むスカラー因数に分解されます。 これは、乗算を繰り返しても構造の複雑さは増加せず、単一のスカラー指数のみが増加することを意味します。 

これにより、問題は行列のべき乗から、いくつかのベクトル和とドット積を組み合わせたスカラーべき乗へと軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース行列乗算 | O(K・N^3) | O(N^2) | 遅すぎる |
 | ランク 1 の減算 + 累乗 | O(N + log K) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 最初のシーケンスをベクトル a として表し、2 番目のシーケンスを b として表します。 

### 1. 3 つのコア集計を計算する

 a のすべての要素の合計、b のすべての要素の合計、およびそれらの内積を計算します。 

合計は、すべてのエントリが集計されたときに外積がどのように動作するかをキャプチャします。 ドット積は、外積行列を乗算するときに表示される重要なスカラーです。

### 2. 指数ゼロの場合を処理する

 K = 0 の場合、結果は単位行列であり、そのエントリの合計はちょうど N になります。正の累乗の代数式は適用されないため、これをすぐに返します。 

### 3. スカラー遷移係数を計算する

 s を内積 sum_i a_i * b_i とします。 A を単独で乗算するたびに、行列の構造に s の因数が導入されます。 K - 1 回の乗算の後、この係数は s^(K-1) になります。 

これが機能するのは、すべての中間乗算が (a b^T)(a b^T) = a (b^T a) b^T によって折りたたまれるためです。 

### 4. 外の和と組み合わせる

 ランク 1 行列 a b^T のすべてのエントリの合計は、(sum a_i) * (sum b_i) です。 K 回の乗算の後、これは s^(K-1) によってスケーリングされます。 

したがって、最終的な答えは次のようになります。 

(a_i の合計) * (b_i の合計) * (dot(a, b))^(K-1)

 ### なぜ効果があるのか

 行列 A は、ランク 1 の線形変換である外積として開始されます。 このような 2 つの行列の乗算では、外積形式を維持しながら、定義ベクトルの内積である新しいスカラー項が 1 つだけ導入されます。 これは、A の累乗によって生成される可能な行列の空間がスケーリングまで 1 次元であることを意味します。 すべてのべき乗 A^k は、同じランク 1 構造に適用されるスカラー係数によってのみ異なります。 この構造ではエントリの合計は線形であるため、最終的な答えは 3 つのスカラー量と 1 つのべき乗のみに依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(x, e):
    res = 1
    while e > 0:
        if e & 1:
            res = res * x % MOD
        x = x * x % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    sum_a = 0
    sum_b = 0
    dot = 0

    for i in range(n):
        ai = a[i] % MOD
        bi = b[i] % MOD
        sum_a = (sum_a + ai) % MOD
        sum_b = (sum_b + bi) % MOD
        dot = (dot + ai * bi) % MOD

    if k == 0:
        print(n % MOD)
        return

    factor = mod_pow(dot, k - 1)
    ans = sum_a * sum_b % MOD
    ans = ans * factor % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```実装は、配列に対する単一の線形パスで 3 つの必要な集計を計算することから始まります。 各値は、オーバーフローを回避し、モジュラー演算における内積の一貫性を維持するために、指定されたモジュラスを法として即座に減算されます。 

特殊なケース K = 0 は、べき乗の前に明示的に処理されます。 これにより、無効な指数ロジックが回避され、単位行列の合計が直接返されます。 

べき乗剰余演算は、スカラー遷移係数を対数時間で効率的に計算します。これは、K が 998244352 まで大きくなる可能性があるため必要です。 

最後に、結果は 2 つの合計と累乗されたドット積の積として組み立てられ、正確性を維持するために各ステップでモジュラー乗算が適用されます。 

## 実用的な例

 a = [1, 2]、b = [3, 4]、K = 2 の小さなインスタンスを考えてみましょう。 

次のように計算します。 

合計a = 3

 合計b = 7

 ドット = 1・3 + 2・4 = 11

 | ステップ | 合計 | 合計_b | ドット | パワー (ドット^(K-1)) | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 3 | 7 | 11 | - | - |
 | K=2 | 3 | 7 | 11 | 11 | 3 * 7 * 11 = 231 |

 これは、行列構造を明示的に形成する必要がないことを示しています。 すべてはスカラー演算に集約されます。 

次に、同じ配列で K = 1 を考えます。 

| ステップ | 合計 | 合計_b | ドット | パワー (dot^0) | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 3 | 7 | 11 | 1 | 21 |

 行列は元の外積にすぎないため、これは A のすべてのエントリの直接和と一致します。

 ## 特殊なケース

 K = 0 の場合、アルゴリズムはすべてのベクトル構造をバイパスし、N を直接返します。これにより、内積を負の指数に引き上げようとするランク 1 の累乗公式の誤った適用が回避されます。 

N = 1 の場合、行列は単一の値 a_1 * b_1 になります。 この場合、式は (a_1 b_1)^K となり、アルゴリズムは sum_a = a_1、sum_b = b_1、dot = a_1 b_1 を生成するため、結果は a_1 b_1 * (a_1 b_1)^(K-1) となり、正しく単純化すると (a_1 b_1)^K になります。 

値が負または大きい場合、乗算ごとにモジュラー リダクションによって正確さが保証されます。 即時モジュロを使用しないと、ドット積がオーバーフローして累乗基数が静かに破損し、完全に不正確な結果が生じる可能性があります。
