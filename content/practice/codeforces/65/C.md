 ## 解決策
 ## 問題の理解

 スニッチは 3D 空間内の固定ポリラインに沿って移動します。 最初の頂点から開始し、一定の速度でセグメントごとに移動します`vs`。 ハリーは別の地点からスタートし、一定の速度で任意の方向に移動できます`vp`、 どこ`vp >= vs`。 

ハリーと密告者がまったく同じ地点を占有することができる最も早い時間が必要です。 スニッチがポリラインのトラバースを終了する前にそれが起こらない場合は、次のように出力します。`"NO"`。 

ジオメトリは連続的です。 スニッチは頂点間を飛び越えるのではなく、各セグメントに沿ってスムーズに移動します。 ハリーは空間内を自由に継続的に移動することもできます。 課題は、スニッチの軌道上で最初に到達可能なポイントを見つけることです。 

パスには最大でも次の内容が含まれます`10000`これにより、非常にきめの細かいシミュレーションが即座に除外されます。 小さな増分を伴う単純なタイムステップ手法では、浮動小数点の精度のために答えが見つからないか、十分な精度を達成するために何十億回もの反復が必要になります。 

各座標は最大で`10^4`, そのため、距離は数値で管理できます。 倍精度浮動小数点演算で十分です。 

厄介な点は、スニッチの軌跡が区分的に線形であることです。 最も早いキャッチ ポイントは、頂点ではなく、厳密にセグメント内で発生する可能性があります。 頂点だけをチェックする解決策は間違っています。 

次の例を考えてみましょう。```
1
0 0 0
10 0 0
2 1
5 0 0
```スニッチはから移動します`(0,0,0)`に`(10,0,0)`スピードを持って`1`。 ハリーはから始めます`(5,0,0)`スピードを持って`2`。 

ハリーは間に合うように密告者を捕まえる`5/3`、時点で`(5/3,0,0)`。 エンドポイントのみをチェックすると、これは完全に見逃されます。 

もう 1 つの簡単な間違いは、ハリーがいつでも密告者を捕まえられると思い込んでいることです。`vp >= vs`。 

例：```
1
0 0 0
10 0 0
1 1
100 0 0
```スニッチは時間どおりに終了します`10`。 ハリーには必要なもの`90`エンドポイントに到達するまでの秒数。 スニッチが動いている間は捕まえることは不可能なので、正解は`"NO"`。 

セグメント境界付近にも精度の落とし穴があります。 スニッチが頂点に到達した瞬間にキャッチの瞬間が起こると仮定します。 慎重な間隔処理を行わずにセグメント内で個別にバイナリ検索を行うと、誤って正確なエンドポイントをスキップする可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 スニッチの位置を時間でパラメータ化し、時間通りにグローバルに二分探索を行って、ハリーがスニッチの位置に到達できる最初の瞬間を見つけます。 

一定の時間`t`、ポリラインに沿ってスニッチの位置を計算できます。 もしそうなら、ハリーはその地点に到達できるだろう$$\text{distance}(P, S(t)) \le vp \cdot t$$どこ`P`はハリーの開始位置であり、`S(t)`時のスニッチ位置です`t`。 

この条件は単調です。 ハリーがスニッチに到達できるようになると、彼はただ待つだけで済むため、その後ずっとその能力を維持します。 

したがって、時間をかけてグローバルな二分探索が機能します。 

難しいのは評価です`S(t)`。 スニッチは上まで移動します`10000`セグメント。 二分探索反復ごとにすべてのセグメントをスキャンすると、複雑さはおおよそ次のようになります。$$O(n \cdot \log(\text{precision}))$$ここではすでに受け入れられていますが、各セグメントの構造を利用することで推論をさらに単純化できます。 

単一セグメント内では、スニッチ位置は時間とともに直線的に変化します。 実現可能条件もその区間内では単調です。 つまり、セグメントを 1 つずつ処理し、キャッチが可能になる最初のセグメント内でのみ二分探索を行うことができます。 

重要な観察結果は次のとおりです。 

ハリーがセグメントの終わりに達するまでにスニッチを捕まえることができなかった場合、最も早く捕まえる時間はもっと遅くなるはずです。 

セグメント用`i`、 させて：

-`t0`スニッチがセグメントに入る時刻であること
 -`t1`セグメントを離れる時刻になります

 ハリーが時間までにセグメントのエンドポイントに到達できない場合`t1`の場合、将来のセグメントの以前の部分はまだ重要ではありません。 

時間内にエンドポイントに到達できる最初のセグメントが見つかったら、最も早いキャッチの瞬間はそのセグメント内のどこかにあるはずです。 次に、内部で時間通りに二分探索を行います`[t0, t1]`正確な答えが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | セグメント スキャンによるブルート フォース グローバル バイナリ検索 | O(n 対数精度) | O(n) | 承認済み |
 | セグメントごとの二分探索 | O(n + 対数精度) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのポリラインの頂点を読み取り、すべてのセグメントの長さを事前計算します。 

スニッチは一定の速度で移動するため、セグメントの移動時間は次のようになります。$$\frac{\text{segment length}}{vs}$$2.現在の累積時間を維持する`cur_t`。 

これは、スニッチが現在のセグメントの開始点にいつ到達するかを表します。 
3. セグメントを順番に処理します。 

現在のセグメントが次のものであると仮定します。`A`に`B`。 
4. セグメントの走査時間を計算します。 

セグメント長が`d`、 それから：$$\Delta t = \frac{d}{vs}$$スニッチが届く`B`時間:$$t_1 = cur_t + \Delta t$$5. ハリーがエンドポイントに到達できるかどうかを確認する`B`時間までに`t1`。 

ハリーに必要なのは:$$\frac{\text{distance}(P, B)}{vp}$$そこに着くまで数秒。 

これを超えると`t1`、その後、ハリーはこのエンドポイントまでのどこでもスニッチを捕まえることができないため、次のセグメントに進みます。 
6. 時間内にエンドポイントに到達できるようになると、最も早いキャッチはこのセグメント内にあります。 

セグメント開始時点ではキャッチは不可能でした。 セグメントエンドでは可能です。 条件は単調に変化するため、遷移点は 1 つだけです。 
7. 現在のセグメント間隔内の時間での二分探索。 

検索範囲を`[cur_t, t1]`。 
8. 候補時間について`mid`、セグメント上のスニッチ位置を計算します。 

セグメントパラメータが次の場合:$$r = \frac{mid - cur_t}{\Delta t}$$その場合、位置は線形補間になります。$$S(mid) = A + r(B - A)$$9. 実現可能性を確認します。 

ハリーは間に合うように密告者を捕まえることができる`mid`もし：$$\text{distance}(P, S(mid)) \le vp \cdot mid$$可能であれば、二分探索を左に移動します。 それ以外の場合は右に移動します。 
10. 十分な反復の後、最終的な時刻と位置を出力します。 

### なぜ効果があるのか

 重要な特性は単調性です。 

定義する：$$f(t) = \text{distance}(P, S(t)) - vp \cdot t$$ハリーはいつでも密告者を捕まえることができる`f(t) <= 0`。 

時間が経過するにつれて、ハリーの到達可能な半径は直線的に増加します。 スニッチはハリーの速度と同じ速度で連続的に動きます。 スニッチは一度ハリーの手の届く範囲に入ると、永久にそこから逃げることはできません。 

つまり、実現可能性は不可能から可能に一度だけ変化します。 二分探索は有効です。 

セグメントを順番に処理すると、有効な時刻を含む最も早いセグメントが確実に見つかり、そのセグメント内の二分探索により実行可能な最も早い瞬間が復元されます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def dist(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    dz = a[2] - b[2]
    return math.sqrt(dx * dx + dy * dy + dz * dz)

def solve():
    n = int(input())

    pts = [tuple(map(float, input().split())) for _ in range(n + 1)]

    vp, vs = map(float, input().split())
    P = tuple(map(float, input().split()))

    cur_t = 0.0

    for i in range(n):
        A = pts[i]
        B = pts[i + 1]

        seg_len = dist(A, B)
        seg_time = seg_len / vs

        end_t = cur_t + seg_time

        if dist(P, B) > vp * end_t + 1e-12:
            cur_t = end_t
            continue

        lo = cur_t
        hi = end_t

        for _ in range(100):
            mid = (lo + hi) / 2.0

            ratio = (mid - cur_t) / seg_time

            x = A[0] + (B[0] - A[0]) * ratio
            y = A[1] + (B[1] - A[1]) * ratio
            z = A[2] + (B[2] - A[2]) * ratio

            snitch = (x, y, z)

            if dist(P, snitch) <= vp * mid:
                hi = mid
            else:
                lo = mid

        t = hi
        ratio = (t - cur_t) / seg_time

        x = A[0] + (B[0] - A[0]) * ratio
        y = A[1] + (B[1] - A[1]) * ratio
        z = A[2] + (B[2] - A[2]) * ratio

        print("YES")
        print(f"{t:.10f}")
        print(f"{x:.10f} {y:.10f} {z:.10f}")
        return

    print("NO")

solve()
```最初のヘルパー関数は、3D 空間のユークリッド距離を計算します。 問題内のすべてが幾何学的であるため、この操作は繰り返し表示されます。 

メインループは一度に 1 つのセグメントを処理します。`cur_t`スニッチがセグメントの先頭に到着したときに格納されます。 セグメントの長さとスニッチ速度から、トラバースにかかる時間を計算します。 

エンドポイントの到達可能性チェックは、重要な枝刈りステップです。 スニッチが到着するまでにハリーがまだセグメントの終点に到達できない場合は、そのセグメントのそれより前のポイントも機能しません。 これにより、セグメント全体をスキップできます。 

実現可能なエンドポイントが見つかったら、答えはそのセグメント内にあるはずです。 二分探索では、時間を検索変数として使用します。 時間をセグメント上の点に変換するには、パラメータを使用した線形補間が必要です`ratio`。 

二分探索が実行されるのは、`100`繰り返し。 それは十分すぎるほどです`1e-6`各反復で間隔が半分になるため、精度が高くなります。 

小さなイプシロン:```
dist(P, B) > vp * end_t + 1e-12
```値が非常に近い場合の浮動小数点の不安定性を回避します。 

微妙なディテールが使用されています`hi`二分探索後の最終答えとして。`hi`常に実行可能な時間を保存しますが、`lo`実行不可能なものを保存します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + 対数精度) | 各セグメントは 1 回処理され、バイナリ検索が 1 回だけ実行されます。 
| スペース | O(n) | すべてのポリラインの頂点を保存します。 

と`n <= 10000`、これは簡単に制限内に収まります。 二分探索は一定回数の反復を実行するため、実行時間はセグメント全体の線形スキャンによって支配されます。

 ## 特殊なケース

 キャッチがまさに頂点で発生する場合を考えてみましょう。 

入力：```
1

10 0 0
2 1
20 0 0
```スニッチが届く`(10,0,0)`時に`10`。 ハリーもまさに必要です`10`その点に到達するまでの秒数。 

アルゴリズムはセグメントを処理し、エンドポイントの実現可能性をチェックします。$$\text{distance} = 10,\quad vp \cdot t = 20$$したがって、セグメントは実行可能です。 

二分探索はエンドポイント自体に収束します。 で実現可能性を確認しているので、`<=`, the exact equality case is accepted correctly.

| 時間 | スニッチ位置 | ハリーの到達可能な半径 | 実現可能 |
