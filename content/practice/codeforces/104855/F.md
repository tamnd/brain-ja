 ## 問題の理解

 平面上の一連の点と、固定数の辺を持つ正多角形が与えられます。$m$。 ポリゴンは常に原点を中心に配置されますが、自由に回転できます。 変更できるのはサイズだけです。つまり、原点から頂点までの距離であり、これによって形状全体が固定されます。 

目標は、回転後にすべての点が多角形の内側または境界上に位置するように、可能な限り小さいサイズを選択することです。 

常連の$m$原点を中心とする -gon は、次の交点として説明できます。$m$半面。 各辺は方向に対応し、多角形は、すべての外向き法線方向への投影がサイズに比例する値によって制限される点の集合です。 

制約は全体として大きくなります。すべてのテスト ケースにわたるポイントの総数は最大です。$2 \cdot 10^5$、 その間$m$これにより、回転ごとに多角形を明示的にシミュレートしたり、多くの候補サイズに対して素朴な方法で各点をすべての面に対してチェックしようとしたりするソリューションは即座に除外されます。 点ごとの検証と組み合わせた回転に対する単純な幾何学的検索では、簡単に次の値を超えるでしょう。$10^9$最悪の場合の手術。 

主な問題点は、回転によってすべての点が結合されることです。 1 つの回転はすべての点の制約を同時に満たす必要があるため、各点は角度と原点からの距離に応じて有効な回転範囲を制限します。 

点がポリゴンの境界方向に非常に近い位置にある場合、微妙なエッジ ケースが発生します。 このような場合、回転のわずかな変化により、ポイントが有効から無効に切り替わる可能性があります。 これにより、回転空間全体にわたって実現可能性が不連続になり、強引な角度サンプリングの信頼性が低くなります。 

## アプローチ

 直接的なアプローチは、候補のサイズを固定することです$R$ポリゴンのすべての回転を試します。 回転ごとに、すべての点が多角形の内側にあるかどうかを確認できます。 1 回転のチェックにかかる時間$O(nm)$点ごとにすべての半平面をテストすると、回転数は無限に増えます。 回転を細かいステップに離散化しても、依然として遅すぎるため、最適な位置合わせを逃す危険性もあります。 

重要な構造観察は視点を逆転させることです。 固定点上で回転する多角形を考える代わりに、多角形の構造を固定し、各点が回転角度に制約を課すものとして見ます。 固定サイズの場合$R$、各ポイントは、ポリゴン内に配置する一連の回転を制限します。 

常連の$m$-gon には等間隔の側面方向があり、角度周期があります。$L = \frac{2\pi}{m}$。 ポリゴンをある角度だけ回転すると$\theta$、各点はこの周期的なグリッドに対して事実上シフトされます。 点がポリゴン内に存在するための条件は、その角度位置が最も近いグリッド境界にどれだけ近いかという制約になります。 

指定された半径に対して$R$、距離のある点$r$原点からの角度は、最も近いポリゴン軸からの一定の角度偏差を許容できます。 境界方向に近すぎる場合は、より大きな値が必要になります。$R$セクター内で適切に中央に配置されていれば、より簡単に適合できます。 これにより、各点が回転モジュロの円領域上の許容される間隔に変換されます。$L$。 

すべての点が回転の間隔制約に変換されると、問題はこれらすべての間隔が回転に対して交差するかどうかを確認することになります。 これは、実現可能性チェックごとに直線的な時間で実行できます。 

これにより、問題は次の単調な決定問題に変換されます。$R$、答えの二分探索が可能になります。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: ジオメトリを極形式に変換する

 各点について、その極角を計算します。$\phi_i$と半径$r_i$。 半径は固定です。 角度のみが回転と相互作用します。 この分離により、ポリゴン制約を角度の実現可能性問題に変えることができます。 

### ステップ 2: 候補のポリゴン サイズを修正する

 最小限の二分探索を行います$R$。 固定の場合$R$、すべての点をカバーする多角形の回転が存在するかどうかをテストします。 

与えられたものの実現可能性$R$単調です: サイズが次のポリゴンの場合$R$機能するだけでなく、より大きなポリゴンも機能します。 

### ステップ 3: ポリゴン制約を角度許容値に変換する

 常連の$m$-gon の定義$m$等間隔の境界方向。 隣接する境界間の角度間隔は次のとおりです。$$L = \frac{2\pi}{m}.$$半径上の点の場合$r_i$、最も近い境界方向までの距離は、回転されたグリッドに対する角度のみに依存します。 

幾何学的には、最も近い側の法線への投影が多角形の頂点を超えない場合、その点は有効です。 これは、最大許容角度偏差に変換されます。$\alpha_i$、 どこ$\alpha_i$は以下から導出されます:$$\cos(\alpha_i) = \frac{R \cos(\pi/m)}{r_i}.$$この値が 1 を超える場合、そのポイントはどのような回転でも自明に実行可能になります。 

### ステップ 4: 各点を回転間隔に変換します。 

回転を修正する$\theta$。 定義する$$x_i = (\phi_i - \theta) \bmod L.$$ポイントは、セクターのどちらの境界にも近づきすぎない場合に有効です。これは次のことを意味します。$$x_i \in [\alpha_i, L - \alpha_i].$$この間隔は長さの円上にあります$L$。 したがって、各点はセクター境界の周囲の禁止された近傍、またはシフトされた角度の許容間隔を定義します。 

各点を間隔制約に変換します。$\theta$、すべての間隔を共通の座標系モジュロにシフトします。$L$。 

### ステップ 5: 区間の交差を確認する

 すべてのポイントを変換した後、$\theta$それはすべての許可された間隔内にあります。 これは、循環間隔を交差させることになります。これは、ラップアラウンド間隔を分割し、エンドポイントをスイープすることで実行できます。 

交差点が空でない場合、候補は$R$実現可能です。 

### ステップ 6: 最小半径の二分探索

 二分探索をします$R$十分な数値範囲を超えています。 それぞれのチェックは、$O(n \log n)$ソート間隔エンドポイントのため、全体的な複雑さは許容範囲内です。 

### なぜ効果があるのか

 正確さは、幾何学的被覆問題を 1 次元の円形の実現可能性問題に還元することで得られます。 各ポイントは、ポリゴンの境界付近に配置される角度を除外することによって、回転を個別に制限します。 これらの制約は角度の違いのみに依存し、多角形の規則的な構造により周期性が保証されます。$2\pi/m$。 すべての点が同じ円領域上の独立した間隔制約に寄与するため、実現可能性はグローバル交差条件と同等です。 このような回転が存在する場合、多角形を定義するすべての半平面制約を同時に満たすため、区間モデルの外側で幾何学的違反が発生することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def can(R, pts, m):
    L = 2 * math.pi / m
    eps = 1e-12

    intervals = []

    for x, y in pts:
        r = math.hypot(x, y)
        if r == 0:
            continue

        # apothem condition
        val = (R * math.cos(math.pi / m)) / r
        if val >= 1:
            # full freedom in angle
            continue
        if val <= -1:
            return False

        alpha = math.acos(val)

        # we work modulo L
        # allowed: distance to nearest boundary >= alpha
        # x = (angle - theta) mod L in [alpha, L-alpha]
        # translate to theta interval modulo L

        # angle of point
        ang = math.atan2(y, x) % L

        left = (ang - (L - alpha)) % L
        right = (ang - alpha) % L

        if left <= right:
            intervals.append((left, right))
        else:
            intervals.append((0.0, right))
            intervals.append((left, L))

    if not intervals:
        return True

    intervals.sort()

    # sweep on circle unwrapping
    cur_l, cur_r = intervals[0]
    if cur_l > 0:
        cur_l -= L
    cur_r = cur_r

    for l, r in intervals[1:]:
        if l < cur_l:
            l += L
            r += L
        if l > cur_r:
            return False
        cur_l = max(cur_l, l)
        cur_r = min(cur_r, r)

    return True

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        lo, hi = 0.0, 50000.0

        for _ in range(50):
            mid = (lo + hi) / 2
            if can(mid, pts, m):
                hi = mid
            else:
                lo = mid

        print(f"{hi:.12f}")

if __name__ == "__main__":
    solve()
```このコードはまず、固定半径の実現可能性チェッカーを定義します。 各点を、正多角形のアポセム条件から導出される角度制約に変換します。 各制約は、長さの円形領域にわたる間隔にマッピングされます。$2\pi/m$、ポリゴン方向の周期構造をキャプチャします。 

区間交差ロジックは、円の境界を越える区間を分割することでラップアラウンドを処理します。 ソート後、実行中の交差点が維持され、オーバーラップが空になると早期に失敗します。 

次に、二分探索により最小半径が絞り込まれます。 必要な精度は次の条件によって決まるため、固定反復回数を選択すれば十分です。$10^{-9}$許容範囲。
