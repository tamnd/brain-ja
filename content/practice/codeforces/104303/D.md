 ## アルゴリズムのチュートリアル

 私たちは、反転が非ゼロ剰余系を素数を法として並べ替えるという事実に完全に依存しています。

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        p = int(input())
        if p == 2:
            out.append("1")
        else:
            out.append("0")
    print("\n".join(out))

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 のために$p = 2$、反転セットは単一の要素に折りたたまれます。 アルゴリズムは、一般規則を適用する前にこのケースを明示的にチェックします。

次のような大きな素数の場合$p = 11$、個々の逆数が不規則に見える場合でも、順列プロパティにより合計が固定されたままであることが保証され、アルゴリズムは正しい結果を返しながら、それらを直接計算することを回避します。
