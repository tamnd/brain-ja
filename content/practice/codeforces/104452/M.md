 ## 解決策
 ## 問題の理解

 各ホッケーの試合は次のように構成されています。$n$独立した期間。 どのピリオドでも、スコアボードには 4 つの可能な結果のうちの 1 つが表示されます。どちらのチームも得点しない、最初のチームが 1 回得点する、2 番目のチームが 1 回得点する、または両方のチームが 1 回得点する。 したがって、完全なゲームは単なる長さのシーケンスです$n$、各ポジションはこれら 4 つの期間結果の 1 つを選択します。 

最終的な勝者は、全期間の合計ゴール数によってのみ決定されます。 私たちは、すべての期間を合計した後、最初のチームが 2 番目のチームよりも厳密に多くのゴールを獲得しているシーケンスにのみ関心があります。 タスクは、そのようなシーケンスがいくつ存在するかを数え、結果のモジュロを出力することです。$10^9+7$。 

制約$n \le 50000$シーケンスを明示的に列挙したり、考えられるスコア差の全範囲にわたって動的プログラミングを実行したりするソリューションは除外されます。 スコア差に対する直接的な DP は、次の値に比例する範囲に拡大します。$n$、大まかに生産$O(n^2)$が遅すぎる状態です。 

「有効なシーケンスをすべて数えて、同点のシーケンスを差し引くだけ」として問題を処理しようとすると、微妙な失敗例が発生します。 多くのアプローチは、ゼロ差分期間の重み付けされた性質を処理せずに、独立性を誤って仮定しています。 特に、結果は、$(0:0)$そして$(1:1)$どちらも差がゼロですが、多重度が同等ではなく、これを無視すると、小さい値であっても誤ったカウントが発生します。$n$。 たとえば、次のようなとき$n=1$、正確に 4 つのシーケンスがありますが、「最初のチームの勝利は偽」構造を満たすのは 1 つだけです。 ゼロ差分の処理が間違っていると、ここで不注意な対称性の推論が簡単に崩れてしまう可能性があります。 

## アプローチ

 各ピリオドはスコアの差に値をもたらします$d = A - B$。 この違いに関して 4 つの結果を書き直すと、次のようになります。 

-$(1:0)$貢献する$+1$-$(0:1)$貢献する$-1$-$(0:0)$貢献する$0$-$(1:1)$貢献する$0$つまり、どのゲームも長さがあります -$n$の一連のステップ$\{-1, 0, +1\}$ただし、工夫が必要です。ゼロ ステップの多重度は 2 ですが、その他のステップの多重度は 1 です。 

合計が厳密に正であるシーケンスの数が必要です。 

ブルートフォースアプローチでは、すべてが列挙されます。$4^n$シーケンスを作成し、それらの合計を計算します。 これは正しいですが、指数関数的に増加し、すでに実行不可能になります。$n=25$。 

重要な観察は対称性です。 シーケンスごとに 2 つのチームの役割を交換すると、すべてのシーケンスが変化します。$+1$踏み込む$-1$ゼロステップは変更しないまま、その逆も同様です。 これは、合計が正のシーケンスと合計が負のシーケンス間の全単射です。 したがって、正の和シーケンスの数は負の和シーケンスの数に等しくなります。 残りのシーケンスはすべて、合計がちょうどゼロになるシーケンスです。 

これにより、次のような削減が行われます。$$\text{answer} = \frac{4^n - \text{ways(sum = 0)}}{2}$$残っている唯一のタスクは、合計がゼロになるシーケンスの数を計算することです。 

和がゼロになるには、次の数が必要です。$+1$ステップは次の数と等しくなければなりません$-1$ステップ。 選択するとします$i$前向きな一歩と$i$ネガティブなステップ。 残り$n - 2i$位置はゼロ差分期間である必要があり、それぞれに 2 つの選択肢があります。 これにより、次の結果が得られます。$$\text{ways}(0) = \sum_{i=0}^{\lfloor n/2 \rfloor} \frac{n!}{i!\,i!\,(n-2i)!} \cdot 2^{n-2i}$$これは以下で計算可能です$O(n)$階乗事前計算を使用します。

 | 最適な組み合わせ論 + 対称性 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 3 つの概念的な段階で答えを計算します。 

1. 階乗および逆階乗を最大で事前計算します。$n$。 これにより、定数時間の二項係数クエリが可能になります。 これがなければ、ゼロスコア構成の合計の各項に直線的な時間がかかり、ソリューションが中断されてしまいます。 
2. コンピューティング$4^n$モジュロ$10^9+7$。 これは、制限のないすべての可能なゲームを表します。 
3. 合計スコアが 0 のシーケンスの数を計算します。 考えられるそれぞれの数字について$i$の$+1$ステップで、ポジションを選択します$+1$、のポジション$-1$、残りをゼロステップとして割り当てます。 組み合わせ構造は、これらのカテゴリの独立した配置を直接反映します。 
4. 合計からゼロサムのカウントを減算し、2 の逆モジュラを使用して 2 で割ります。対称性によって正の結果と負の結果の正確な組み合わせが保証されるため、除算は有効です。 

### なぜ効果があるのか

 2 つのチームを交換する変換は、すべての有効なシーケンスを、合計スコアが否定された別のシーケンスに全単射的にマッピングします。 これにより、ポジティブな結果とネガティブな結果の間の完璧な組み合わせが保証されます。 ゼロサム シーケンスのみがペアになっていない状態で残るため、合計からゼロサム シーケンスを削除すると偶数が残り、半分にすると最初のチームの勝利シーケンスの数が正確に得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n = int(input().strip())

fact = [1] * (n + 1)
invfact = [1] * (n + 1)

for i in range(1, n + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact[n] = modpow(fact[n], MOD - 2)
for i in range(n, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(a, b):
    if b < 0 or b > a:
        return 0
    return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

pow2 = [1] * (n + 1)
for i in range(1, n + 1):
    pow2[i] = pow2[i - 1] * 2 % MOD

zero = 0
for i in range(n // 2 + 1):
    zero += C(n, i) * C(n - i, i) % MOD * pow2[n - 2 * i]
    zero %= MOD

total = modpow(4, n)
ans = (total - zero) % MOD
ans = ans * modpow(2, MOD - 2) % MOD

print(ans)
```階乗表は、多項係数を効率的に評価するために必要です。 機能$C(n, i)C(n-i, i)$の配置を構築します$+1$そして$-1$ポジションは個別に行われますが、残りのポジションは$2^{n-2i}$2 つのゼロ差の結果の係数。 

べき乗剰余演算は両方に使用されます$4^n$および 2 の逆モジュラであり、モジュラスの下で正確さを保証します。

import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input().strip())
    MOD = 10**9 + 7

    def modpow(a, e):
        r = 1
        while e:
            if e & 1:
                r = r * a % MOD
            a = a * a % MOD
            e >>= 1
        return r

    fact = [1] * (n + 1)
    invfact = [1] * (n + 1)

    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[n] = modpow(fact[n], MOD - 2)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = pow2[i - 1] * 2 % MOD

    zero = 0
    for i in range(n // 2 + 1):
        zero = (zero + C(n, i) * C(n - i, i) % MOD * pow2[n - 2 * i]) % MOD

    total = modpow(4, n)
    ans = (total - zero) % MOD
    ans = ans * modpow(2, MOD - 2) % MOD

    return str(ans)

 ## 特殊なケース

 のために$n=1$、ゼロ和項には両方が含まれます$(0:0)$そして$(1:1)$、合計 2 つの中立的な結果が得られます。 アルゴリズムはこれらを 4 つの完全なセットから正しく減算し、2 で割って、正確に 1 つの勝利構成を残します。 

大型の場合$n$、主な微妙な点は、多数のゼロ差分結果が正しく処理されるようにすることです。 両方$(0:0)$そして$(1:1)$ゼロステップに独立して貢献し、$2^{n-2i}$これは要因によって明確に説明されます。 この要素がなければ、対称性の議論は構造的には機能しますが、中立シーケンスのカウントが不正確になり、最終的な答えに伝播します。
