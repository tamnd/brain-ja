 ## 解決策
 ## 問題の理解

 正の整数の複数のセットが与えられます。 このセットから整数がいくつあるかを数えたいとします。$x$次のプロパティがあります:$x$指定されたセットの任意の 2 つの数値と組み合わせると、これら 3 つの値は常に非縮退三角形を形成できます。 

2 つの小さい辺の合計が最大の辺より厳密に大きい場合、長さの 3 倍は有効な三角形を形成します。 したがって、選択したペアについては、$a_i, a_j$、値$x$可能なすべての順序で三角形不等式を満たさなければなりません。 

要件は強力です:$x$少なくとも 1 つのペアだけでなく、配列内のすべてのペアで機能する必要があります。 つまり、$x$は、配列内の最悪のペア、つまり三角形不等式を満たすのが最も困難なペアによって制約されます。 

入力サイズは以下に達します$5 \cdot 10^5$したがって、すべてのペアをチェックすることを含む解決策は直ちに実行不可能になります。 二次関数のアプローチには約$10^{11}$制限時間をはるかに超えた最悪の場合の作戦。 

微妙なエッジ ケースは、多くの値が等しいか非常に小さいという縮退構成から発生します。 たとえば、配列に次のものが含まれている場合、$[1, 1]$、その後は陽性ではありません$x$働けるので$1, 1, x$必要$x < 2$そして$x > 0$、与える$x = 1$、しかし、これはより大きな配列内のすべてのペアにも当てはまらなければならないため、より大きな要素が存在する場合、実現可能性はすぐに崩壊します。 

もう 1 つの重要なケースは、アレイのバランスが非常に悪い場合です。$[1, 1000000000]$。 ここでは、中程度の値でも、$x$大きな要素とのペアが三角形制約を支配するため、失敗する可能性があります。 

## アプローチ

 直接的な解釈から始めます。 固定の場合$x$すべてのペアをチェックする必要があります$(a_i, a_j)$。 各ペアについて、次のことをテストします。$(x, a_i, a_j)$三角不等式を満たします。 あるので$O(n^2)$ペアと潜在的に多くの候補者$x$、これは爆発につながります。 

ペアを反復する代わりに、視点を反転します。 私たちは、どのような制約が課せられているかを尋ねます。$x$一組で$(a_i, a_j)$?

 仮定する$a_i \le a_j$。 の三角形の条件は、$(x, a_i, a_j)$以下のように減少します:$$x + a_i > a_j$$他の不等式は次の場合に正の値に対して自動的に満たされるため、$a_j$3 つの要素の中で最大または 2 番目に大きい要素です。 これにより、次のようになります。$$x > a_j - a_i$$したがって、各ペアは次の下限を生成します。$x$。 すべてのペアが同時に動作するには、$x$すべての値の最大値を超える必要があります$a_j - a_i$すべてのペアにわたって。 

次に、最悪のペアを特定します。 最大の差$a_j - a_i$配列のグローバル最大値とグローバル最小値によって達成されます。 したがって、最も強い制約は次のとおりです。$$x > \max(a) - \min(a)$$これはすべての整数を意味します$x$厳密にそれより大きい$\max(a) - \min(a)$有効です。 

ただし、この問題には暗黙の限界も存在します。$x$セット自体によって。 意図された解釈は次のとおりです$x$明示的な上限のない正の整数から選択されますが、条件はすべてのペアに当てはまります。$a$。 上限がないため、しきい値より大きいすべての整数が有効であり、これは無限になります。そのため、唯一の一貫した解釈は、セットの任意の 2 つの要素と組み合わせたときにすべての三角形を有効にする可能な整数値を数えているということですが、事実上、これは、すべてのペアの三角形不等式によって決定される、制限された実行可能な区間内の整数値を数えることになります。 

より正確な再定式化は、固定の場合に次のことを観察することです。$x$、三角形条件には次のものも必要です。$$a_i + a_j > x$$すべてのペアに$(i, j)$、そうでないから$x$が最大の辺となり、不等式に違反します。 これにより、上限が導入されます。$$x < a_i + a_j$$すべてのペアの場合、次のようになります。$$x < \min(a_i + a_j)$$ペアの最小合計は、配列の最小の 2 つの要素から取得されます。 させて$m_1 \le m_2$最小の 2 つの値になります。 それから：$$x < m_1 + m_2$$両方の制約を組み合わせると有効です$x$以下を満たす必要があります:$$\max(a) - \min(a) < x < m_1 + m_2$$したがって、答えは単にこの間隔内の整数の数です。 

最小の 2 つの要素と最大の 2 つの要素を線形時間で計算し、間隔の長さを評価します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ペアに対するブルートフォース |$O(n^2)$|$O(1)$| 遅すぎる |
 | 最適 (最小/最大削減) |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 最小値と 2 番目に小さい値を維持しながら、配列を 1 回スキャンします。 これが必要なのは、最も厳しい上限制約は最小化から得られるためです。$a_i + a_j$。 
2. 同じスキャンで、最大値と 2 番目に大きい値を維持します。これは、最も厳しい下位制約は要素間の差異を最大化することから得られるためです。 
3. 下限を計算します$L = \max(a) - \min(a) + 1$。 厳密な不等式が開始整数境界になります。 
4. 上限を計算する$R = m_1 + m_2 - 1$、 以来$x$最小のペアの合計より厳密に小さくなければなりません。 
5. もし$L > R$両方の制約を同時に満たす整数はないため、0 を返します。 
6.そうでない場合は戻る$R - L + 1$。 

これら 2 つの境界が十分である理由は、次のようなすべての三角不等式が成り立つためです。$x$2 つの配列要素は、差を含む制約または和を含む制約のいずれかに折りたたまれ、両方の極値は配列の極値要素によって完全に決定されます。 

### なぜ効果があるのか

 任意のペア$(a_i, a_j)$次の 2 つの制約に影響します。$x > |a_i - a_j|$そして$x < a_i + a_j$。 1 つ目はグローバル極値差によって最大化され、2 つ目は最小のペアの合計によって最小化されます。 どちらの制約ファミリーもペア全体で単調であるため、中間のペアは両端よりも厳密な境界を生成できません。 これにより、二次制約システムが、実現可能性を完全に特徴付ける 2 つのスカラー境界に縮小されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # smallest and second smallest
    m1 = m2 = 10**18
    # largest and second largest
    M1 = M2 = -10**18
    
    for x in a:
        if x < m1:
            m2 = m1
            m1 = x
        elif x < m2:
            m2 = x
        
        if x > M1:
            M2 = M1
            M1 = x
        elif x > M2:
            M2 = x
    
    L = M1 - m1 + 1
    R = m1 + m2 - 1
    
    if L > R:
        print(0)
    else:
        print(R - L + 1)

if __name__ == "__main__":
    solve()
```コードは単一パスを実行して、すべての制約を定義する 4 つの極値を抽出します。 下限は 2 つの配列要素間の最大の差から導出され、上限は 2 つの要素の最小可能な合計から導出されます。 最終的なカウントは、結果として得られる間隔内の整数の数です。 

厳密な不平等には注意が必要です。 コードは変換されます$x > M1 - m1$の中へ$M1 - m1 + 1$そして$x < m1 + m2$の中へ$m1 + m2 - 1$、オフバイワンエラーなしで正しい整数カウントを保証します。

| ステップ | 値 | m1 | 平方メートル | M1 | M2 |

 | 1 | 3 | 3 | インフ | 3 | -inf |
 | 2 | 3 | 3 | 3 | 3 | -inf |

 今：$L = 5 - 3 + 1 = 3$

$R = 3 + 3 - 1 = 5$有効$x$は$3, 4, 5$, したがって、答えは 3 です。 

これは、両方の極端な値がどのように重要であるかを示しています。最大値は下限を狭め、複製された最小値は上限を狭めます。

 ## 特殊なケース

 次のような完全に均一な配列$[k, k, k]$生成する$L = 0 + 1$そして$R = 2k - 1$、したがって、実行可能な間隔は、次の値までのすべての正の整数になります。$2k - 1$。 両方の極値が同一の最小値と最大値に正しく折りたたまれ、厳密だが有効な境界が生成されるため、アルゴリズムはこれを処理します。 

次のような非常に偏った配列$[1, 1000000000, 1000000000]$収量$L = 999999999 + 1$そして$R = 1 + 1000000000 - 1$、空になります。 このアルゴリズムは、中間ペアについて推論する必要なく、純粋に極端な追跡を通じてこれを検出します。 

次のようなほぼソートされた配列$[2, 3, 4, 5]$小さいですが空ではない間隔が生成されます。 最小ペアの合計は最初の 2 つの要素から取得され、最大差はエンドポイントから取得され、アルゴリズムは内部構造の影響を受けることなくこれらを正しく分離します。
