 ## 解決策
 ## 問題の理解

 無限の六角形グリッド上に選択されたセルのセットが与えられます。 各セルは整数の座標を持ち、完全なエッジを共有することによって隣接関係が定義されます。 グリッドには、すべてのグリッドの頂点が正確に 3 つのセルに属するという追加の幾何学的特性があります。 

禁止された構成はエッジに直接関係するものではありません。 代わりに、単一のグリッド点で交わる 3 つのセルに注目します。 このようなトリプルは、同じ頂点の周囲にある 3 つの異なるセルがすべて選択されたセットに存在する場合に正確に発生します。 タスクは、入力セットからの 3 つの入射セルすべてに囲まれたグリッド頂点が存在しないように、指定されたセルをできるだけ少なく削除することです。 

出力は、単に削除された入力セルのサブセットです。 それらを削除した後、すべての頂点には最大 2 つのインシデント選択セルが残っている必要があるため、「完全に占有された頂点トリプル」はもう存在しません。 

入力サイズは最大 100000 セルです。 隣接するセルのすべてのトリプルを調べたり、セル間の隣接関係を明示的に列挙しようとするソリューションは、いずれも困難を伴います。各セルは複数の頂点構成に参加することができ、ローカル近傍はすべての禁止されたトリプルの単純な列挙を可能にする方法で制限されていないためです。 n における線形時間に近い解決策が必要です。 

微妙な点は、制約が幾何学的なものであり、エッジの隣接性に基づく純粋なグラフではないことです。 頂点のみを共有しエッジを共有しない 2 つのセルは、依然として同じ禁止構造の一部です。 エッジ隣接性のみを使用する単純なグラフ モデルでは、これらの制約を完全に無視して、不正確な答えが生成されます。 

## アプローチ

 ブルートフォースアプローチでは、頂点で交わるセルのトリプルをすべて明示的に再構築します。 入力セルによって誘導された各グリッド頂点について、セット内に 3 つの入射セルがすべて存在するかどうかを確認し、存在する場合は少なくとも 1 つを削除する必要があります。 これは当然、重複するトリプルに関するグローバル ヒッティング セットの問題につながります。 

問題は、各セルがそのような複数の頂点トリプルに属しており、それらのトリプルが重なり合っていることです。 構造のない貪欲な戦略またはローカルな戦略は、セルを 1 つ削除すると予測できない方法で複数の制約が同時に解決されるため、セルの削除が多すぎると簡単に行き詰まってしまう可能性があります。 

重要な観察は、六角形のグリッドが任意のものではないということです。 すべてのグリッド頂点が各色の 1 つのセルに正確に属するように、セルのグローバル 3 色分けが許可されます。 この構造が認識されると、すべての禁止されたトリプルは非常に単純になります。常に、頂点で交わる各色のちょうど 1 つのセルで構成されます。 

したがって、すべての頂点で条件に違反する唯一の方法は、各カラー クラスから少なくとも 1 つのセルを同時に保持することです。 同様に、その頂点に 3 色すべてが存在したままにすると、違反が発生します。 

さて、問題はそのようなトリプルをすべて破ることに帰着します。 すべてのトリプルは正確に 1 つの赤、1 つの緑、1 つの青のセルであるため、単一の色クラスのすべてのセルを削除すると、考えられるすべてのトリプルが即座に破棄されます。これは、頂点に 3 色すべてを含めることができなくなるためです。 

これはすでに有効な解決策を提供しています。 3 つのカラー クラスのうち、最も小さいものを選択し、その中のすべてのセルを削除します。 すべての有効なソリューションはすべての不良トリプルから少なくとも 1 つのセルを削除する必要があり、1 つのフルカラー クラスを削除することは、すべての制約を同時に満たす統一的な方法であるため、より優れたソリューションであっても、このパーティション内の最小カラー クラス サイズよりも少ないセルを削除することはできません。

 ## アルゴリズムのチュートリアル

 まず、すべての 16 進セルに 3 つの色のいずれかを割り当てる一貫した方法が必要です。 16 進グリッドの軸座標では、3 を法とする座標の一次関数が有効な 3 色を与える標準構造が存在します。 正確な式は座標の規則によって異なりますが、重要な特性は、すべての頂点について、周囲の 3 つのセルが 3 つの異なる残基を受け取るということです。 

1. x および y のモジュロ 3 の固定線形式を使用して、各セルに {0, 1, 2} のカラー値を割り当てます。これが機能するのは、16 進グリッド構造により頂点近傍の並進一貫性が保証されるためです。 
2. 3 つの色のそれぞれに該当する入力セルの数を数えます。 これにより、入力セット全体をカバーする 3 つの素グループが得られます。 
3. 最小サイズのカラー クラスを選択します。 直観的には、削除するセルの数が少ない方が常に良いため、フルカラー クラスを削除すると、禁止されたトリプルがすべて削除されることが保証されます。 
4. 選択したカラークラスに属するすべてのセルを除去セットとして出力します。 

明らかではない部分ですが、カラー クラス全体を削除するだけで十分である理由がわかります。 すべての禁止された構成は 1 つのグリッド頂点に結び付けられ、各頂点の周囲の構造は厳格です。そこでは、色ごとに 1 つずつ、正確に 3 つのセルが集まります。 したがって、違反がある場合は、そのローカル構造内に 3 色すべてが存在するようにする必要があります。 1 つの色全体をグローバルに削除すると、どの頂点もこの条件を満たすことができなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def color(x, y):
    # A standard 3-coloring for hex/triangular lattice in axial coordinates.
    # This works under the common CF convention used in such problems.
    return (x - y) % 3

def main():
    n, cost, gamma = input().split()
    n = int(n)

    groups = [[], [], []]

    cells = []

    for _ in range(n):
        x, y = map(int, input().split())
        c = color(x, y)
        groups[c].append((x, y))

    # choose smallest group
    best = min(range(3), key=lambda i: len(groups[i]))

    res = groups[best]

    print(len(res))
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    main()
```実装は、カラーリング関数の正確さに完全に依存しています。 解決策の残りの部分は簿記です。つまり、ポイントを 3 つのバケットに分配し、最小のものを選択します。 三角形や隣接関係を明示的に検出する必要はありません。 

よくある間違いは、16 進数セルの 6 つの隣接する方向のみに基づいて隣接グラフを構築しようとすることです。 このアプローチは、禁止されたトリプルがエッジベースではなく頂点ベースであるという事実を見逃しています。 もう 1 つの間違いは、ローカル トライアングル数に基づいて貪欲な削除を試みることです。これは、グローバル パーティション構造を利用しないため、過剰な削除を行う可能性があります。

 ## 特殊なケース

 単一のセルを含む最小のケースには、禁止されたトリプルが含まれていないことは明らかであり、アルゴリズムはそれに色を割り当て、それが最小のクラスである場合はそれを削除する可能性がありますが、有効性が保たれている限り余分なセルの削除が許可されるため、これは依然として有効です。 

座標の縮退によりすべてのセルが 1 つまたは 2 つのカラー クラスに分類される構成では、アルゴリズムは依然として最小のクラスを削除します。これはセルの大部分を削除することを意味する可能性がありますが、必要な 3 つのカラーすべてを同時に保持できる頂点はないため、すべての頂点トリプルを分割するにはこれでも十分です。
