 ## 解決策
 ## 問題の理解

 1 から 2 までの番号が付けられたスイレンの列で行われる 2 人用ゲームを分析するように求められました。$n$。 アリスはリリーパッドから始まります$a$そしてリリーパッドのボブ$b$、そして彼らは交代で左または右に一歩ジャンプします。 カエルは、有効な空いているスイレンの葉にジャンプできなかった場合に負けます。 アリスが最初に動きますが、問題は、両方が最適にプレイした場合に勝利を保証できるかどうかです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$、スイレンの数、開始位置$a$そして$b$。 アリスが常に勝つことができる場合、出力は「YES」、そうでない場合は「NO」です。 

なぜなら$n$が最大 100 であれば、位置ごとに少数の操作を実行するアルゴリズムであればどれでも実行可能です。 下限は、ポジションを順番に考えても許容できることを示しています。 エッジケースは、カエルがエッジ近く (位置 1 または$n$）またはカエルが隣接している場合。 たとえば、アリスが 1 でボブが 2 の場合、アリスは左に移動できず、右に移動するとボブの隣に着地し、潜在的に負けのポジションが作成されます。 アリスがどこにもジャンプできなかった場合、彼女は即座に負けます。 

単純なアプローチでは、考えられるすべてのジャンプ シーケンスを再帰的にシミュレートしようとする可能性があります。 これは小規模でも機能する可能性があります$n$, しかし、ゲームは対称的であり、端までの距離から最適な手を導き出すことができるため、その必要はありません。 

## アプローチ

 ブルートフォースアプローチは、ゲームを再帰的にシミュレートすることです。カエルのターンごとに、有効な動きをすべて試してから、次のターンに再帰します。 アリスとボブの位置によって定義されるゲーム状態ごとに、現在のプレイヤーが勝利につながる手を持っているかどうかを確認します。 これはすべての法的順序を調査するため正しいですが、州の数は次のとおりです。$O(n^2)$(ポジションのペアごと)、各再帰は最大 2 つの動きに分岐します。 これにより、テスト ケースごとに何百もの再帰呼び出しが発生する可能性があり、500 のテスト ケースでは過剰になります。 

重要な洞察は、ゲームはつまるところ、アリスがボブを最初に端に押し込むことができるかどうかであるということです。 アリスから最も近いエッジまでのスイレンの数がボブからの数よりも少ない場合、アリスはより速くエッジに到達し、ボブを移動のない位置に強制することができます。 正式には、アリスは、自分の位置から列の最も近い端までの最小距離が、ボブの最も近い端までの最小距離よりも厳密に小さい場合に勝つことができます。 両方の距離が等しい場合、ボブはアリスの動きを反映して、代わりに勝つことができます。

 | --- | --- | --- | --- |

 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アリスから最も近いエッジまでの距離を計算します。$\text{dA} = \min(a-1, n-a)$。 これは、アリスがボブがブロックできないスイレンの葉にどれだけ早く到達できるかを表します。 
2. ボブから最も近いエッジまでの距離を計算します。$\text{dB} = \min(b-1, n-b)$。 これはボブの類似距離です。 
3. 2 つの距離を比較します。 もし$\text{dA} < \text{dB}$, アリスは最初に端に到達し、勝利を保証できます。 「はい」と印刷します。 
4. そうしないと、ボブが先にエッジに到達するか、ボブの動きをミラーリングしてブロックするかのいずれかになるため、アリスは勝利を保証できません。 「いいえ」を印刷します。 

不変条件は、エッジに近いプレイヤーがゲームをコントロールできるということです。 常にその端に向かって移動することで、アリスはボブが罠にはまるまでボブの選択肢を減らすことができます。 彼女がボブよりもエッジに近づかない限り、他の一連の動きで彼女の位置を改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    # compute distance to nearest edge
    dA = min(a - 1, n - a)
    dB = min(b - 1, n - b)
    if dA < dB:
        print("YES")
    else:
        print("NO")
```まず、テスト ケースの数を読み取ります。 テストケースごとに、ユリの葉の数とカエルの位置を読み取ります。 エッジまでの距離が直接計算され、比較されます。 境界条件は正しく処理されるため、`min(a-1, n-a)`常に最も近い端までのステップを表す非負の整数を生成します。 以来$a \neq b$どちらも範囲内にあるため、追加のチェックは必要ありません。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        dA = min(a - 1, n - a)
        dB = min(b - 1, n - b)
        print("YES" if dA < dB else "NO")
    return out.getvalue().strip()

 ## 特殊なケース

 2 つのリリーパッド ゲームでアリスが 1 位から開始し、ボブが 2 位から開始した場合、アリスは左にジャンプできず、右に移動するとボブの隣に着地します。 アルゴリズムは計算します`dA = min(1-1, 2-1) = 0`そして`dB = min(2-1, 2-2) = 0`。 以来`dA < dB`が false の場合、出力は NO となり、アリスが即座に負けることが正しく識別されます。 同様に、アリスとボブがそれぞれのエッジまで等しい距離にある中央から開始する場合、アルゴリズムは NO を出力し、対称ミラーリング シナリオをキャプチャします。 距離比較では、分岐ロジックを追加することなく、エッジの隣接性、中間位置、最小基板サイズを完全に処理します。
