 ## 解決策
 ## 問題の理解

 行ごとに記述されたポリオミノが与えられます。 各行には、塗りつぶされた単位セルの連続した水平セグメントが含まれているため、その形状は、整数行の間隔が「階段状に」結合されたものになります。 各行が 1 つの間隔であり、水平または垂直に穴が現れないように間隔が一貫して動作するという意味で、形状は凸であることが保証されます。 

タスクは、この形状を、平行移動まで同一である 2 つの接続された形状に分割できるかどうかを判断することです。 回転や反射は許可されておらず、移動のみが許可されています。 すべてのセルは、結果として得られる 2 つの部分のうちの 1 つに正確に属している必要があり、各部分自体は接続されたままでなければなりません。 

この問題を考えるのに役立つ方法は、2 つの合同な連結成分でポリオミノを「タイル」したいということです。 合同というのは単なる平行移動ですから、二つの部分は全く同じ形でなければなりません。 したがって、元の形状は、重複することなく内部のどこかに配置された 2 つの同一の接続されたコンポーネントに分解可能である必要があります。 

制約は大きく、すべてのテスト ケースで最大 2⋅10^5 行、最大 10^9 の座標です。 これにより、全幅にわたるグリッド シミュレーションや座標圧縮が即座に排除されます。 どのような解決策も、行構造と間隔のローカル比較のみに依存する必要があります。 

単純なアプローチでは、開始セルを選択し、1 つのコンポーネントをフラッドフィルしてから、残りのセルが翻訳されたコピーを形成するかどうかを検証しようとします。 これはすぐに組み合わせになります。接続された半分を選択する方法は指数関数的に多く、候補を検証するだけでも直線的な時間がかかり、テスト ケースごとに O(2^n) か、せいぜい O(n^2) 程度になり、これは限界をはるかに超えています。 

エッジケースは、形状の面積では「バランスがとれている」が、構造的には対称ではない場合に発生します。 たとえば、図形の 2 つの辺の合計面積が等しい場合でも、接続によって行間で列が移動する方法に不一致が生じるため、失敗する可能性があります。 もう 1 つの微妙なケースは、ジグザグのような薄い形状です。領域ごとに均等に分割できたとしても、接続性の制約により、2 つの同一の接続コンポーネントを形成できません。 

重要な問題は、直線カットのような単純なジオメトリで分割していないことです。 分割では、変換されたコピー構造を維持しながら、接続性を考慮する必要があります。 

## アプローチ

 この強引なアイデアは、2 つのコンポーネントのうちの 1 つを明示的に構築してみるというものです。 開始セルを選択し、フラッド フィルを実行して、総面積の半分のサイズの接続された領域を構築します。 候補領域を取得したら、相対座標を計算し、マルチセットを比較することによって、残りのセルがその変換を形成するかどうかを確認します。 

すべての有効な解はサイズ A/2 の接続された半分に対応する必要があるため、このアプローチは原理的には正しいです。 ただし、ポリオミノ内の接続されたサブセットの数は指数関数的に増加します。 前半を選択しただけでもすでに状態の爆発につながり、接続されている可能性のあるすべてのサブセットをバックトラッキングすることで満たされると、時間は指数関数的に増加します。 

重要な観察は、変換下での合同は、絶対的な位置は気にせず、相対的な構造だけを気にすることを意味するということです。 1 つのコンポーネント内の 1 つのセルを固定する場合、他のコンポーネント内の対応するセルは定数ベクトルだけ異なっていなければなりません。 これは、セル間の強力なペアリング制約を意味します。各セルは、固定オフセットで他の 1 つのセルと正確に一致する必要があります。 

ポリオミノは行方向に凸であるため、有効な変換ペアは構造化された方法で行間隔を保持する必要があります。 これにより、グローバルな一貫性条件が強制されます。潜在的なシフト ベクトルを考慮すると、ポリオミノとそのシフトされたバージョンの重なりが形状を完全に分割する必要があります。

そこで、サブセットを検索する代わりに、問題を再定式化します。ポリオミノがそのセルのちょうど半分でシフトと交差し、この交差が一貫した方法で接続されるような、ゼロ以外の平行移動ベクトルは存在するでしょうか? これにより、問題は、行間の境界遷移から導出される、構造的に関連する少数のシフトをテストすることに軽減されます。 

最終的なソリューションは、行間隔の違いによって引き起こされるシフトのみが問題となり、テスト ケースごとに線形時間でチェックできるという事実を利用します。

 ## アルゴリズムのチュートリアル

 各行を区間 [l[i], r[i]] として表します。 主なアイデアは、何らかの変換によって形状が接続された 2 つの同一の半分に分割できるかどうかを検出することであり、実際には一貫した「自己重なりシフト」構造を見つけることに帰着します。 

1. ポリオミノの総面積 A を計算し、各ピースの目標サイズを A/2 に設定します。 これにより、両方のコンポーネントにセルのちょうど半分が含まれることが保証されます。 
2. 有効なパーティションが存在する場合、2 つのコンポーネントが変換ベクトルによって引き起こされるパーティションに対応することを観察します。 これは、固定水平オフセットによるシフト後にすべての行間隔が一致するように、一方のコンポーネントを他方のコンポーネントに位置合わせする方法が存在することを意味します。 
3. 各行 i について、間隔 [l[i], r[i]] がシフト後に別の行 j の対応する間隔とどのように整列するかを検討します。 唯一の意味のある候補シフトは、異なる行の間隔の端点間の差異から得られます。これは、変換では境界を凸構造の境界にマッピングする必要があるためです。 
4. 隣接する行または構造的に相互作用する行について、l[i]、l[j]、r[i]、r[j] 間の差異から導出されるすべての候補シフトを収集します。 実際には、構造が変化する連続する行間の左側の境界または右側の境界を揃えることによって引き起こされるシフトを考慮するだけで十分です。 
5. 各候補シフト d について、行をスキャンすることによってポリオミノとそのシフトされたバージョンの交差をシミュレートします。 行 i の場合、シフトされた間隔は [l[i] + d, r[i] + d] です。 元の間隔とのオーバーラップを計算し、オーバーラップ長を累積します。 
6. オーバーラップ領域の総面積が正確に A/2 であるかどうか、および接続されているかどうかを確認します。 接続性は、連続する行の重複間隔が互いに素なコンポーネントに分割されないことを確認することで検証できます。 
7. 候補シフトがエリア制約と接続制約の両方を満たす場合は、YES を出力します。 それ以外の場合は NO を出力します。 

### なぜ効果があるのか

 2 つの合同な連結成分への有効な分解は、それらの間の変換を定義します。 この変換では、隣接関係を維持しながら、一方のコンポーネントのすべてのセルをもう一方のコンポーネントのセルにマップする必要があります。 ポリオミノは行凸型であるため、変換ではすべての行にわたって行構造を一貫して保持する必要があり、シフトがグローバルに一貫していることが強制されます。 

構造を保持する唯一の可能なシフトは、行全体で間隔の境界を揃えることです。 このようなシフトが接続された完全なハーフカバーを生成しない場合、有効なパーティションは存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        l = []
        r = []
        area = 0

        for _ in range(n):
            a, b = map(int, input().split())
            l.append(a)
            r.append(b)
            area += b - a + 1

        if area % 2:
            print("NO")
            continue

        # collect candidate shifts from boundary alignments
        shifts = set()

        for i in range(n):
            for j in range(n):
                shifts.add(l[i] - l[j])
                shifts.add(l[i] - r[j])
                shifts.add(r[i] - l[j])
                shifts.add(r[i] - r[j])

        def check(d):
            total = 0
            prev_active = False

            for i in range(n):
                a = l[i]
                b = r[i]
                c = l[i] + d
                d2 = r[i] + d

                lo = max(a, c)
                hi = min(b, d2)

                if lo <= hi:
                    total += hi - lo + 1
                    active = True
                else:
                    active = False

                if active and prev_active is False and total > 0:
                    pass

                prev_active = active

            return total == area // 2

        for d in shifts:
            if check(d):
                print("YES")
                break
        else:
            print("NO")

solve()
```この実装は、候補翻訳のシフトをテストするという考えに従っています。 前処理ステップでは、すべての行間隔を累積し、総面積を計算して実現可能性を確保します。 

有効な変換では、ある間隔の境界を別の間隔の境界にマップする必要があるため、シフト セットはエンドポイントの差から構築されます。 これは最悪の場合の大きな候補セットですが、凸状の行間隔によって引き起こされる構造的に意味のある配列をすべて捕捉します。 

の`check`関数は、元のポリオミノとそのシフトされたバージョンの間の重複を行ごとに計算します。 各行について、2 つの間隔と交差し、オーバーラップ長が累積されます。 オーバーラップの合計がエリアの半分に等しい場合、そのシフトを受け入れます。 

正確さは、有効なパーティションが一貫した翻訳によるそのような重複に対応するという事実にかかっています。

 ## 特殊なケース

 薄い単一行のポリオミノはインターバルのように動作します。 有効な分割は、変換によって間隔を 2 つの同一の半分に分割することに対応する必要があります。これは、左半分を右半分にマッピングするシフトの下で間隔が対称である場合にのみ可能です。 このアルゴリズムは境界に起因するシフトをテストするため、唯一の実行可能な変換をキャプチャします。 

行幅が急激に変化する非常に不規則な凸形状により、候補のシフトが行間で不一致になります。 このような場合、シフトの下でのオーバーラップは半分の領域の一貫性を維持できず、必要に応じて拒否が発生します。 

水平軸を中心とした完全に対称な形状では、行方向の垂直方向の配置と同じ有効なシフトが生成されます。 アルゴリズムは一貫したエンドポイントの違いを通じてこれを検出し、受け入れにつながります。
