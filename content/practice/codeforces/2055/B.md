 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 それぞれで、次のコレクションから始めます。$n$材料の種類。 それぞれのタイプ$i$初期金額があります$a_i$、そして少なくとも達成したいのは$b_i$タイプごとの単位。 

すべてのリソースを緊密に結合する単一の操作があります。 素材を選ぶなら$i$、増やします$a_i$1 ずつ増えますが、他のすべてのマテリアルは 1 単位を失います。 したがって、この操作は、他のすべてのリソースを犠牲にして、リソースを 1 つの座標に向けてシフトします。この操作は、他のマテリアルがゼロを下回らない場合にのみ有効です。 

タスクは、すべての最終値が必要な目標を満たすか超えるように、そのような操作のシーケンス (おそらくゼロ) を実行できるかどうかを判断することです。 

重要な制約は、すべての操作が同時に 1 つのユニットを消費することです。$n-1$材料。 これにより、システムの相互依存性が高くなります。1 つの座標を改善すると、他のすべての座標が積極的に損なわれます。 

制約から、次の合計は$n$テストケース全体で最大$2 \cdot 10^5$したがって、すべての解はテスト ケースごとに線形または線形に近いものでなければなりません。 二次関数の何か$n$すぐに失敗してしまうだろう。 

単純なアプローチでは、操作をシミュレートしたり、各座標を個別に貪欲に調整しようとしたりする可能性がありますが、すべての操作ですべての値がグローバルに変更されるため、どちらも失敗します。 

いくつかの微妙な障害状況を強調する価値があります。 

1 つの材料が目標を大幅に下回っているが、他の材料はかろうじて十分である場合を考えてみましょう。 単純な貪欲な人は、不足している座標を繰り返し「修正」しようとするかもしれませんが、各操作により他のすべての座標が消耗され、連鎖的な障害が発生します。 

もう 1 つの注意が必要な状況は、すべての値が目標に近いにもかかわらず、質量を再配分するには全体的に不十分な合計が存在する場合です。 例えば：```
n = 3
a = [0, 0, 10]
b = [5, 5, 5]
```局所的にはマテリアル 3 を他のリソースに変換することが可能のように見えるかもしれませんが、それぞれの変換は他のリソースも破壊するため、実現可能性は局所的な動きではなくグローバルなバランス条件に依存します。 

問題は基本的に、対称的なコスト構造の下で繰り返し再分配をサポートするのに十分な全体的な「余裕」がシステムにあるかどうかにあります。 

## アプローチ

 ブルートフォース解釈では、各操作を状態遷移として扱います。$n$-次元空間。 州から$a$、すべての選択肢を試します$i$、変換を適用し、すべての制約が満たされるか、移動が不可能になるまで続行します。 

これは完全な状態空間を探索するため、原理的には正しいです。 ただし、各州は次のように分岐します。$n$新しい状態、そして価値観が最大まで成長する可能性があります$O(10^9)$、状態空間が天文学的に大きくなります。 小さなインスタンスでも組み合わせによって爆発します。 

重要な観察は、この作戦が非常に厳格な世界的な影響を及ぼしているということです。 すべての要素を合計すると、1 回の操作で合計が次のように変化します。$$(+1) + (-(n-1)) = 2 - n$$したがって、すべての操作で合計が減少します。$n \ge 3$、次の場合にのみ保存します。$n = 2$。 これは、実現可能性が一連の選択ではなく、グローバルな不変条件によって制御されることを直ちに示唆しています。 

のために$n \ge 3$、各操作は効果的に質量を再配分しますが、総可用性は確実に減少するため、初期構成に十分な「空き容量」が既に含まれているかどうかを注意深く確認する必要があります。$b$。 

これをより正確に確認する方法は、赤字を定義することです。$$d_i = b_i - a_i$$リソースを繰り返しシフトすることでプラスの赤字をすべて解消する必要がありますが、すべてのシフトには次のことが必要です。$n-1$他の指数からのサポート単位。 これにより、実現可能性はシステム全体に分配された総余剰によって最大赤字を補うことができるかどうかに依存するという状況が生じます。 

これにより、問題は、操作制約の下で必要な増分に対する総余剰のバランスから導出される単純な線形チェックに帰着します。 

最終的な簡略化は次のようになります。 

総剰余金を計算します$S = \sum (a_i - b_i)$。 もし$S < 0$、すでに総質量が不足しているため、すぐに失敗します。 それ以外の場合は、各操作の消費量を考慮して、最大の赤字をサポートできるかどうかを確認します。$n-2$システム全体の柔軟性の正味単位。 これは、単一の座標がシステムが再分配できる以上の補正を必要としないことを保証するのと同等のチェックにつながります。 

より明確な導出により、最終条件が得られます。 

仕分けします$b_i - a_i$最大赤字を追跡することで暗黙的に、総黒字が少なくともその赤字に対して必要な構造的補償であることを検証します。 

これにより、$O(n)$テストケースごとのソリューション。

 ## アルゴリズムのチュートリアル

 私たちは問題を赤字と黒字という観点から再定式化して、単一のグローバルな実現可能性条件を検証します。 

1. 差を計算する$d_i = b_i - a_i$あらゆる素材に。 正の値は必要な増加を表し、負の値は過剰な供給を表します。 
2. 総剰余金の計算$S = \sum (a_i - b_i)$。 これは、再分配後の需要を満たすのに十分な総リソースがあるかどうかさえ把握します。 もし$S < 0$、作戦を行っても目標を達成することはできません。 
3. 最大赤字を特定する$D = \max(d_i)$。 これは、すべての操作が他のすべての操作に同時に害を及ぼすため、満足させるのが最も難しい座標を表します。 
4. システムに最悪の損失をカバーするのに十分な柔軟性があるかどうかを確認します。 1 つの座標で単位が増加するたびに、実質的に犠牲が必要になります$n-1$したがって、世界の余剰は、この再分配構造に「資金を供給」するのに十分でなければなりません。 これにより、比較する実現可能条件が得られます。$D$利用可能な余剰に対して。 
5. 条件が成立する場合は「YES」を返し、そうでない場合は「NO」を返します。 

### なぜ効果があるのか

 不変量は、座標間の固定線形関係を維持する操作の下での総質量の分布です。 すべての操作により、1 つの成分が増加し、他のすべての成分が均等に減少する方向にベクトルが移動します。 これは、到達可能な状態が総和発展と座標間の対称性によって制約された格子を形成することを意味します。 

有効な最終構成は、これらの操作によって到達可能な凸領域内に存在する必要があり、その領域は総和と極値座標の制約によって完全に特徴付けられます。 このチェックにより、中間ステップ中に非負性制約に違反することなく、グローバル システムが再配分できる以上の補正を必要とする座標がないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        sa = sum(a)
        sb = sum(b)
        
        if sa < sb:
            print("NO")
            continue
        
        # compute maximum deficit
        max_def = 0
        for i in range(n):
            if b[i] > a[i]:
                max_def = max(max_def, b[i] - a[i])
        
        # key condition derived from redistribution constraint
        if max_def <= sa - sb:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```### コードの説明

 まず、初期リソースと必要なリソースの合計を計算します。 必要な合計が手持ちの合計を超える場合、操作は再分配または総質量の削減のみを行うため、一連の操作ではそれを修正できません。$n \ge 3$。 

次に、個別の最大不足額を計算します。 これにより、修正が最も困難な座標がキャプチャされます。これは、座標を改善するすべての操作が他のすべての座標を同時に消費するためです。 

最後に、この最大の赤字を世界の利用可能な黒字と比較します。 余剰が最悪の座標の修正に「支払う」のに十分な大きさであれば、操作の均一な性質により、他のすべての座標を同時に処理できます。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての配列がすでに等しい場合です。 アルゴリズムは計算します$sa = sb$そして最大赤字$0$, そのため、再配布を試行せずにすぐに YES を返します。 

もう 1 つの特殊なケースは、合計は正確に一致するが、分布が不均一である場合です。 そのような状況では、$sa - sb = 0$、したがって、プラスの赤字があるとNOになります。 これは、スラックが不足しているため、あらゆる操作が別の座標を破壊するという事実と一致します。 

最後のエッジケースは、1 つの座標が非常に大きな赤字であるにもかかわらず、全体としては黒字が存在する場合です。 このチェックにより、総余剰がプラスであっても、最悪の座標をカバーするのに十分であることが保証されます。 そうしないと、一連の操作で中間の違反を回避できなくなります。
