 ## 問題の理解

 直線のファミリーが 2 つあります。 最初のファミリーには (y=x+p) という形式の行が含まれており、2 番目のファミリーには (y=-x+q) という形式の行が含まれています。 値 (p) は、値 (q) と同様に別個の整数です。 

最初のファミリーのすべてのラインは、傾きが (1) と (-1) であるため、2 番目のファミリーのすべてのラインと交差します。 このようなペアごとに、それらの交点の座標が整数であるかどうかを判断する必要があります。 答えは、この条件を満たすペアの数です。 

線 (y=x+p) と線 (y=-x+q) の場合、2 つの式を等価すると次のようになります。 

[
 x+p=-x+q、
 】

 それで

 [
 x=\frac{q-p}{2}。 
】

 これをどちらかの行に代入すると、

 [
 y=\frac{p+q}{2}。 
】

 したがって、(q-p) が偶数の場合、両方の座標は正確に整数になります。 整数が同じパリティを持つ場合、2 つの整数の差は正確に均等になります。 したがって、幾何学的な問題全体は、(p) と (q) が両方とも偶数であるか、両方とも奇数であるペアを数えることに帰着します。 

重要な制約は、各ファミリーに最大 (100,000) 行を含めることができるということです。 すべてのペアを検査するメソッドでは、最大 (100000\cdot100000=10^{10}) 個のチェックが実行されます。 これは、競技プログラミングの制限である 2 秒がサポートできる範囲をはるかに超えています。 仕事が本質的に入力値の数に比例するソリューションが必要です。 

誤って処理されやすい境界ケースがいくつかあります。 両方の値が奇数の場合でも、その差は偶数のままです。 たとえば、```
1
1
1
3
```2 つの線は (y=x+1) と (y=-x+3) です。 それらの交点は ((1,2)) であるため、正解は次のようになります。`1`。 両方の数値が偶数であるかどうかのみをチェックするソリューションでは、誤ってゼロが返されます。 

値ゼロも偶数なので、通常どおりに扱う必要があります。 例えば、```
1
0
1
1
```(x=\frac{1-0}{2}) は整数ではないため、正しい出力は次のようになります。`0`。 ゼロを他の偶数と区別して扱う不注意な実装では、この問題が発生する可能性があります。 

(p) と (q) が等しいことは特別な問題ではありません。 例えば、```
1
5
1
5
```交差 ((0,5)) が生成されるため、答えは次のようになります。`1`。 2 つの直線は、パラメータが等しいにもかかわらず、傾きが異なるため異なります。 

最後に、最大の答えは非常に大きくなる可能性があります。 両方のファミリーのすべての (100000) 値が同じパリティを持つ場合、すべてのペアが機能し、(10^{10}) 個の有効なペアが得られます。 したがって、答えは少なくとも (10^{10}) を保持できる整数型に格納する必要があります。 ここでは、Python の整数にはオーバーフローの問題はありません。 

## アプローチ

 直接的なアプローチは、すべてのライン (y=x+p_i) を取得し、それをすべてのライン (y=-x+q_j) と組み合わせ、(q_j-p_i) を計算し、結果が偶数であるかどうかを確認することです。 これは正しいです。なぜなら、考えられるすべてのペアが 1 回だけ検査され、導出された交差式によって整数座標の正確な基準が得られるからです。 

問題はペアの数です。 (n=m=100000) の場合、ブルート フォースは (10^{10}) 個のパリティ チェックを実行します。 各チェックは数学的に単純ですが、100 億回の反復は制限時間に対して多すぎます。 

重要な観察は、実際には差の値が必要ないということです。 必要なのはそれらの同等性だけです。 可能なパリティは偶数と奇数の 2 つだけです。 ペアは、その 2 つのパラメータが同じパリティ クラスに属している場合にのみ寄与します。 

最初のファミリーのパラメータの中に (E_p) の偶数値と (O_p) の奇数値があると仮定します。 同様に、(E_q) と (O_q) を 2 番目のファミリーの対応するカウントとします。 すべての偶数 (p) はすべての偶数 (q) とペアにすることができ、(E_pE_q) 個の有効なペアが生成されます。 同様に、すべての奇数 (p) をすべての奇数 (q) とペアにすることができ、(O_pO_q) 個の有効なペアが生成されます。 

したがって、答えは次のとおりです

 [
 E_pE_q+O_pO_q。 
】

 各入力配列を 1 回スキャンして、その偶数要素と奇数要素をカウントするだけで済みます。 パラメータの実際の位置と大きさは、パリティがわかった後は無関係になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(nm)) | (O(1)) | 遅すぎる |
 | 最適 | (O(n+m)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 形式 (y=x+p) の行数 (n) を読み取り、すべて (p) の値を読み取ります。 偶数が何個か、奇数が何個か数えてください。 交差基準はパリティのみに依存するため、これら 2 つのカウントのみが重要です。 
2. 形式 (y=-x+q) の行数 (m) を読み取り、すべての値 (q) を読み取ります。 もう一度、偶数と奇数の値を数えます。 
3. 偶数 (p) の数と偶数 (q) の数を掛けます。 このようなペアはすべて (q-p) が偶数であるため、それらのすべてが答えに寄与します。 
4. 奇数 (p) の数と奇数 (q) の数を掛けます。 それらの差も均等であるため、これらのペアも同様に寄与します。 
5. 2 つの積を加算し、結果を出力します。 逆パリティのペアは、その差が奇数であるため除外され、両方の交差座標が半整数になります。 

### なぜ効果があるのか

 線のペアの場合、その交点は次のようになります。 

[
 \left(\frac{q-p}{2},\frac{p+q}{2}\right)。 
】

 (p) と (q) が同じパリティを持つ場合、(q-p) と (p+q) は両方とも偶数であるため、両方の座標は整数になります。 パリティが異なる場合、両方の式は奇数となるため、両方の座標は非整数になります。 したがって、有効なペアはまったく同じパリティのペアです。 偶数-偶数および奇数-奇数のペアをカウントすると、すべての有効なペアが 1 回だけカウントされ、すべての無効なペアが除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    p = list(map(int, input().split()))

    m = int(input())
    q = list(map(int, input().split()))

    even_p = sum(x % 2 == 0 for x in p)
    odd_p = n - even_p

    even_q = sum(x % 2 == 0 for x in q)
    odd_q = m - even_q

    answer = even_p * even_q + odd_p * odd_q
    print(answer)

if __name__ == "__main__":
    solve()
```最初の 2 つの入力読み取りにより、2 つのパラメーター ファミリが取得されます。 この問題では、各ファミリーが 1 行で指定されることが保証されているため、行全体をリストに変換するだけで十分です。 

最初のファミリーの 2 つのパリティ カウンタは、偶数値をカウントし、(n) から減算して奇数値の数を取得することによって取得されます。 2 番目のファミリーについても同じことが行われます。 

最後の式は、数学的結果 (E_pE_q+O_pO_q) を直接実装します。 配列を並べ替えたり、線を作成したり、明示的に交差を計算したりする必要はありません。 

モジュロ演算`% 2`許可されているすべての非負のパラメーター値に対して安全です。 Python の任意精度の整数は、特別な処理を行わずに、可能な最大の答え (10^{10}) も処理します。

## 特殊なケース

 最初のパリティ エッジ ケースは 2 つの奇数パラメータです。 考慮する```
1
1
1
3
