 ## 問題の理解

 部屋の隅に長方形のキャビネットが立っています。 壁に沿った 2 つの次元は次のとおりです。`a`そして`b`。 長さのあるドア`d`離れたところに取り付けられている`l`角から。 ドアが開いたときに、キャビネットに触れずに 2 つの部屋の壁のいずれかに到達できるかどうかを判断する必要があります。 

ジオメトリは上から見て考えられます。 キャビネットはコーナーに隣接する長方形を占め、ドアはヒンジを中心に回転します。 ドアは、最終的に壁に当たって停止し、どの時点でもキャビネットに触れない場合にのみ成功します。 キャビネットの角に正確に触れた場合も失敗とみなされます。 入力は 4 つの正の整数で構成されます`a`、`b`、`d`、 そして`l`、すべての値が最大で`30000`そして`a <= l`。 必要な出力は次のとおりです`Yes`壁に到達する安全な方法が少なくとも 1 つ存在する場合、および`No`さもないと。

## アプローチ

 文字通りの幾何学的シミュレーションでは、ドアを回転させて、ドアが壁またはキャビネットに最初に接触するタイミングを判断しようとします。 ドアの角度は連続的であるため、これは有用な計算モデルではありません。 特にキャビネットに触れただけで答えが変わる場合、サンプリング角度によって正確な接線位置が失われる可能性があります。 サンプリング密度を増加しても、近似を正確な解に変えることはなく、プログラムが遅くなるだけです。 

より直接的な強引な解釈は、考えられる 2 つの壁を別々に考慮することです。 ドアがキャビネットを避ける場合、ドアが最初に成功するのは、ドアに近い壁か、反対側の壁のいずれかである必要があります。 幾何学的可能性は 2 つだけであるため、列挙するための大きな検索スペースはありません。 本当の最適化はケースの数を減らすことではなく、ケースごとに正確な不等式を導出し、浮動小数点計算を回避することです。 

近い壁のジオメトリは特にシンプルです。 ドアには長さがある`d`、キャビネットが占有されている間、`a`ドアとコーナーの間のユニットを関連する方向に沿って配置します。 キャビネットを通過し、壁に触れずに近くの壁に到達するために使用できる距離`l`それらを組み合わせた長さよりも厳密に大きくなければなりません。 したがって、条件は次のとおりです`a + d < l`。 

厳密な不等式は衝突ルールから直接導き出されます。 等しいとは、ドアの終点がキャビネットの境界に正確に到達することを意味します。 

遠い壁では重要な幾何学的な観察が必要です。 させて`x = l - a`。 

制限構成では、ドアはキャビネットの奥の隅を通過する必要があります。 ドアの開始点からキャビネットの角までの水平変位は次のとおりです。`x`そして垂直変位は`b`。 ピタゴラスの定理によれば、そのセグメントには長さがあります`sqrt(x² + b²)`。 

同じラインが反対側の壁に到達するまで続きます。 その水平成分はから成長するため、`x`に`l`、ドアのヒンジからその壁までのセグメント全体の長さ`l * sqrt(x² + b²) / x`。 

ドアの長さが厳密にこの値よりも大きい場合にのみ、ドアは遠くの壁に安全に到達できます。 厳密な不等号が再び重要になります。なぜなら、等しいということは、ドアがキャビネットの角に正確に到達し、したがってドアに傷が付くということを意味するからです。 これは、公式コンテスト分析で使用される幾何学的な導出です。 

浮動小数点平方根を使用してこの条件を評価することもできますが、正確な整数の問題に数値精度を導入する理由はありません。 から始まる`d > l * sqrt(x² + b²) / x`そして使用して`x > 0`、正の辺を 2 乗して乗算することができます。`x²`。 条件はこうなります`d² * x² > l² * (x² + b²)`。 

すべての量は負ではないため、二乗しても不等式の真実は変わりません。 Python の整数にも任意の精度があるため、オーバーフローは問題になりません。 

2 つのケースは独立しています。 壁に近い条件または壁より遠い条件のいずれかが成功した場合、答えは次のようになります。`Yes`。 それ以外の場合の答えは、`No`。

 ## アルゴリズムのチュートリアル

 1. 4 つの次元を読み取る`a`、`b`、`d`、 そして`l`。 これらは、キャビネット、ドア、ドアから部屋の隅までの距離を表します。 
2. かどうかを確認します。`a + d < l`。 これが本当であれば、ドアの終点がキャビネットに到達する前に、ドアは近くの壁に到達する可能性があるため、答えはすぐに得られます。`Yes`。 キャビネットに触れると衝突とみなされるため、平等は意図的に拒否されます。 
3. コンピューティング`x = l - a`。 これは、ドアのヒンジからキャビネットの隅までの水平距離です。 
4. もし`x = 0`の場合、限界線の水平成分がゼロであるため、遠い壁の構造を評価することは不可能です。 壁に近い条件はすでに失敗しているため、答えは次のようになります。`No`。 
5. 比較する`d² * x² > l² * (x² + b²)`。 

これは、ドアがヒンジからキャビネットの角を通過する向こう側の壁までの線よりも厳密に長いという条件の正方形バージョンです。 
6. 比較が真の場合、出力します。`Yes`。 それ以外の場合は印刷します`No`。 

機能する理由: キャビネットにぶつからずにドアが開き終わる唯一の安全な方法は、近い壁に到達するか、遠い壁に到達することです。 最初の可能性はまさに次のような特徴を持ちます。`a + d < l`。 2 番目の可能性の場合、キャビネットの安全側に留まりながら奥の壁に到達できる最短のドアの長さは、キャビネットの奥の角を通る線であり、その長さは`l * sqrt((l-a)²+b²)/(l-a)`。 厳密に長いドアはその角に触れることなく壁に到達しますが、同等以下のドアは安全に到達できません。 両方の幾何学的可能性が正確にチェックされるため、アルゴリズムは次の結果を返します。`Yes`まさに安全な開口部が存在するときです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())
    d = int(input())
    l = int(input())

    # The door can pass to the nearer wall.
    if a + d < l:
        print("Yes")
        return

    x = l - a

    # No room remains for the far-wall trajectory.
    if x == 0:
        print("No")
        return

    # Compare:
    # d > l * sqrt(x^2 + b^2) / x
    #
    # All quantities are positive, so we can square safely:
    # d^2 * x^2 > l^2 * (x^2 + b^2)
    left = d * d * x * x
    right = l * l * (x * x + b * b)

    print("Yes" if left > right else "No")

if __name__ == "__main__":
    solve()
```最初の比較では、壁に近いケースを直接実装します。 平方根は関係せず、厳密には`<`等しいということはドアがキャビネットに接触することを意味するため、これは不可欠です。 

変数`x`を表します`l - a`、ドアのヒンジから遠くのキャビネットの角までの水平距離。 いつ`x`がゼロである場合、それによる除算は無効になります。 さらに重要なのは、この構成では有効な壁の向こう側への脱出が存在しないため、`No`は正しい幾何学的動作です。 

最後の比較は、整数の乗算のみを使用して意図的に記述されています。 元の幾何学的条件には平方根と除算が含まれていますが、関係するすべての量は負ではないため、両方とも削除できます。 厳格な`>`厳格であり続けなければなりません。 それを次のものに置き換えると、`>=`キャビネットの角にぴったり届くドアを誤って受け入れてしまう可能性があります。 

最大の製品は次のとおりです`30000^4`、 その周り`8.1 * 10^17`、これは符号付き 64 ビット整数に収まります。 いずれにせよ、Python の整数には制限がないため、マシンのオーバーフローについて手動で推論しなくても実装は安全です。
