 ## 解決策

 しましょう$T(m_1,\dots,m_n)$になる$n$セクション 7.2.1.3 と同様に交差順序を持つ次元トーラスを作成し、定理 W を構造的ステートメントとし、演習 91 ～ 92 の証明は拡散関数に依存します。$\alpha$座標全体で均一に動作します。 仮説$m_1 \le \cdots \le m_n$最後の座標による再帰的分解がグローバルな相互順序と互換性があることを保証するために使用されます。 

### (a) パラメータがソートされていない場合の反例

 最小の非自明な未分類ケースを取り上げます$$n = 2,\quad (m_1,m_2) = (3,2),$$最初の座標の範囲が 2 番目の座標よりも大きくなり、違反します$m_1 \le m_2$。 

セットは$$T(3,2) = \{(x_1,x_2) : 0 \le x_1 \le 2,\; 0 \le x_2 \le 1\}.$$クロス順序 (前の演習で使用したもの) では、要素は最初に 2 番目の座標によって順序付けされ、次に最初の座標によって順序付けされるため、要素の順序は次のようになります。$$(0,0), (1,0), (2,0), (0,1), (1,1), (2,1).$$させて$S$サイズの最初のセグメントになります$N=4$:$$S = \{(0,0),(1,0),(2,0),(0,1)\}.$$繊維数を計算します$N_a$、 どこ$N_a$は要素の数です$S$最終コンポーネントは以下に等しい$a$。 

のために$a=0$、3点すべて$(0,0),(1,0),(2,0)$寝そべる$S$したがって、$$N_0 = 3.$$のために$a=1$、 のみ$(0,1)$にある$S$したがって、$$N_1 = 1.$$定理 W の結論 (演習 92 で使用される形式) は、単一の拡散パラメータの存在を主張します。$\alpha$そのような$$N_{a-1} = \alpha N_a \quad (1 \le a < m_2).$$ここ$m_2 = 2$、したがって、必要です$$N_0 = \alpha N_1.$$これにより、$\alpha = 3$。 ただし、同じ定理を証明の再​​帰的構造内で逆方向に適用するには、以下の一貫性が必要になります。$\alpha$最初の座標からの投影構造を使用します。 で$T(3,2)$最初の座標には長さがあります$3$、最初の座標に沿って誘発された圧縮により、スライス内で異なるスケーリング動作が行われます。$x_2=0$、最初のセグメントはすでに次の 3 つの値をすべて満たしています。$x_1$、スライスしながら$x_2=1$部分的にしか埋まっていません。 これにより、再帰全体にわたる単一の拡散関数に必要な均一な乗算動作が破壊されます。 

したがって、両方の座標方向に同時に拡散関係を伝播しようとすると、同じ初期セグメントによって互換性のないスケーリングが強制されるため、定理 W の構造的結論は失敗します。$N=4$で$T(3,2)$。 

これにより、具体的な情報が得られます。$N$パラメータがソートされていない場合に失敗が発生します。 

### (b) 証明で仮説が使用される場合$m_1 \le m_2 \le \cdots \le m_n$定理 W の証明では、引数が標準セットを分解する時点で順序付け仮説を使用します。$T(m_1,\dots,m_n)$最後の座標に沿ってスライスし、誘導されたスライスが標準セットのように動作することを主張することにより、$T(m_1,\dots,m_{n-1})$単一の拡散関数によって制御される均一な圧縮の下で$\alpha$。 

このステップでは、座標から移動するときに、$i$コーディネートする$i+1$、以前の座標では許容範囲は増加しません。 不平等$$m_1 \le m_2 \le \cdots \le m_n$$誘導中にクロス順序が低い座標を最初に埋めることと互換性があることを保証し、各スライスが同じ極値構造を継承します。 

この仮説がなければ、異なる座標への射影は、標準セットに対して互換性のない増加率を生み出します。つまり、広がり関数は座標に依存し、恒等性は$$N_{a-1} = \alpha N_a$$誘導のすべてのレベルにわたって均一に維持することはできません。 まさにここが単調さです。$m_i$証明には必須です。 ∎
