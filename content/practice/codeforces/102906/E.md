 ## 解決策
 ## 問題の理解

 一連の数値が与えられますが、それらを個別の値として扱うのではなく、非常に特殊な変換を繰り返し実行できるマルチセットとして考える必要があります。 タスクは、これらの変換のみを使用して、ある数値を別の数値に変換できるかどうかを判断することです。 

操作は簡単です。固定ベクトル C を何度でも追加でき、現在のベクトルを時計回りに何度でも 90 度回転することもできます。 ベクトル A から開始して、ベクトル B に到達できるかどうかを知りたいのです。 

幾何学的には、これは、A から始まる平面内を歩いていることを意味します。各ステップで、C または C の回転バージョンのいずれかによってシフトし、追加する前に C を回転し続けることができます。 問題は、これらの一連の動きによって到達可能なすべての点のセットに B が存在するかどうかです。 

入力は 3 つの 2D ベクトル A、B、および C で構成されます。出力は、B が A に、C の回転と加算によって生成される有限の演算シーケンスを加えたものとして表現できるかどうかという 1 つの決定です。 

この制約により、絶対値で 10^8 までの座標が許可されるため、一連の操作の強引なシミュレーションを避ける必要があることがすぐにわかります。 シーケンスを列挙したり状態を段階的に探索したりする方法は、各ステップが複数の可能性 (回転するかしないか、追加するかしないか) に分岐するため、指数関数的に爆発的に増加します。 O(1) または最大でも O(log 値) の代数的特徴付けが必要です。 

C がゼロ ベクトルの場合、微妙なエッジ ケースが発生します。 この場合、回転は何も行わず、すべての操作は同一であるため、到達可能な唯一のポイントは A 自体です。 たとえば、A = (1, 2)、B = (1, 2)、C = (0, 0) の場合、答えは YES ですが、B が異なる場合は、NO になります。 代数的アプローチでは、この縮退を明示的に処理する必要があります。そうしないと、ゼロで割ったり、可逆性を仮定したりする危険があります。 

別の特殊なケースは、C が軸上にある場合、または同一線上に回転している場合に発生します。 たとえば、C = (1, 0) の場合、その回転により (0, 1)、(-1, 0)、(0, -1) が生成され、整数グリッド全体に広がります。 対照的に、C = (0, 0) の場合、回転は完全に崩壊します。 これら 2 つの極端な動作は根本的に異なるため、ソリューションでは、到達可能性について推論する前に C を分類する必要があります。 

## アプローチ

 素朴なアイデアは、A から始まるすべての可能な操作シーケンスをシミュレートすることです。各ステップでは、C を追加するか、そのローテーションされたバージョンの 1 つを追加できます。 k ステップの後、回転と加算の選択肢が複合するため、およそ 4^k 個の可能性を探索することになります。 繰り返される状態を枝刈りしたとしても、到達可能なセットは構造なしで増大します。 最悪の場合は、半径が増加する内のすべての整数格子点に達し、k が 50 に達するずっと前に、このアプローチは実行不可能になります。 

重要な点は、順序は重要ではないということです。 すべての演算は、C の 4 つの回転のうちの 1 つであるベクトルを加算するだけです。したがって、プロセス全体は、有限のベクトルのセット、C、R(C)、R²(C)、および R³(C) の整数線形結合を構築することに帰着します。ここで、R は 90 度の回転です。 

これにより、問題は、ベクトル B − A がこれら 4 つのベクトルの整数範囲内にあるかどうかを確認するように変換されます。 しかし、これらのベクトルは独立していません。 実際、2D では、ベクトルの 4 つの回転バージョンが最大でも 2D 格子を生成し、そのスパンは 2 つの基底ベクトルで記述できる構造に崩壊します。 

これをより明確に確認する方法は、C = (x, y) を扱うことです。 その場合、その回転は (x, y)、(−y, x)、(−x, −y)、(y, −x) となります。 到達可能なベクトルは、負でない係数を含むこれらの合計ですが、演算は任意の順序で適用できるため、任意に並べ替えることができます。 これにより、問題は整数の線形システムに解があるかどうかを確認するようになります。

重要な単純化は、到達可能なセットが 2 つのベクトル (x, y) と (−y, x) によって生成されるグリッドを形成することです。 B − A をこれら 2 つの線形結合として表現できる場合、答えは YES です。 

これにより、問題は 2×2 整数系を解くことに帰着します。これは、行列式の一貫性をチェックし、整数解が存在することを確認することで実行できます。

 ## アルゴリズムのチュートリアル

 1. 変位ベクトル D = B − A を計算します。すべての演算は平行移動によって A に作用するため、相対的な動きのみを考慮します。 
2. C = (0, 0) という特殊なケースを処理します。 この場合、移動はまったく不可能であるため、答えは D = (0, 0) の場合にのみ YES となり、それ以外の場合は NO となります。 
3. C = (x, y) とします。 2 つの基底ベクトル v1 = (x, y) および v2 = (−y, x) を構築します。 これらは、平面内の 2 つの独立した回転方向に対応します。 
4. 次のような整数 a および b が存在するかどうかを確認します。 

D = a * v1 + b * v2。 

座標を展開すると、次のようなシステムが得られます。 

Dx = a x − b y

 Dy = a y + b x
 5. 行列式推論を使用してこの系を解きます。 det = x² + y² を計算します。 det が 0 の場合、C は 0 であり、すでに処理されていることを意味します。 それ以外の場合は、次のように計算します。 

a = (Dx x + Dy y) / det

 b = (Dy x − Dx y) / det
 6. a と b が両方とも整数であることを確認します。 どちらかが整数でない場合、変換は不可能です。 両方が整数の場合、答えは「YES」です。 

機能する理由: 許可されるすべての操作は、C の 4 つの回転コピーの 1 つを追加することに相当し、これら 4 つのベクトルは、C とその 90 度回転を基底とする格子を生成します。 一連の操作はこれらの基底ベクトルの整数の組み合わせにまとめられるため、到達可能性はまさにその格子のメンバーシップになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    ax, ay = map(int, input().split())
    bx, by = map(int, input().split())
    cx, cy = map(int, input().split())

    dx = bx - ax
    dy = by - ay

    if cx == 0 and cy == 0:
        print("YES" if dx == 0 and dy == 0 else "NO")
        return

    det = cx * cx + cy * cy

    a_num = dx * cx + dy * cy
    b_num = dy * cx - dx * cy

    if a_num % det != 0 or b_num % det != 0:
        print("NO")
        return

    print("YES")

solve()
```このコードはまず問題を純粋な変位チェックに落とし込み、開始点への依存を取り除きます。 縮退したゼロベクトルの場合は、無効な除算を回避するために直ちに処理されます。 

決定要因`cx*cx + cy*cy`が表示されるのは、これがベクトル C の 2 乗の長さであり、回転基底に投影するときに正規化係数として機能するためです。 の表現`a_num`そして`b_num`は、C とその垂直ベクトルによって形成される回転行列の逆行列を使用して 2×2 線形システムを解くことから得られます。 

実装でよくある落とし穴は、実際には浮動小数点値を計算する必要がないことを忘れていることです。 すべてが整数のままである必要があり、可算性のチェックが実現可能性を検証する唯一の信頼できる方法です。 

## 実用的な例

 ### 例 1

 入力:

 A = (0, 0)、B = (1, 1)、C = (0, 1)

 D = (1, 1) を計算します。 C はゼロではないため、det = 1 になります。 

今:

 a_num = 1・0 + 1・1 = 1

 b_num = 1・0 − 1・1 = −1

 どちらも det = 1 で均等に除算すると、a = 1、b = −1 となるため、答えは YES です。 

これは、係数の解釈が負である場合でも、システムがさまざまな一連の操作を通じてキャンセルできることを裏付けています。 

### 例 2

 入力:

 A = (0, 0)、B = (2, 2)、C = (1, 1)

 D = (2, 2)、det = 2 を計算します。 

a_num = 2・1 + 2・1 = 4

 b_num = 2・1 − 2・1 = 0

 a = 2、b = 0 となるため、YES となります。 

これは、一方向のみが必要な場合を示しています。 C のみを繰り返し添加するだけで十分です。

 ## 特殊なケース

 C が (0, 0) の場合、すべての回転は同じ点に集約されるため、到達可能なセットには A のみが含まれます。アルゴリズムは代数の前にこれを明示的にチェックし、無効な除算が発生しないことを保証し、すべてのゼロ移動シナリオの正しさを保証します。 

C が非常に大きいか座標が大きい場合、cx * cx や dx * cx などの中間積が 32 ビットの制限を超える可能性があります。 Python を使用するとオーバーフローが完全に回避されますが、C++ では 64 ビット整数が必要です。 行列式に基づく可分性を使用した定式化は、正確な算術のみに依存するため、大きさに関係なく有効です。
