 ## 解決策
 ## 問題の理解

 個別の整数の配列が与えられます。 タスクは、1 つの連続セグメントを反転した後、配列全体を昇順にソートできるかどうかを判断することです。 

可能であれば印刷しなければなりません`"yes"`および 1 つの有効なセグメント`[l, r]`その反転により配列がソートされます。 無理な場合は印刷いたします`"no"`。 

配列のサイズは次のように大きくできます。$10^5$。 この規模では、配列の大部分を繰り返しコピーまたは並べ替えるアルゴリズムは高価になります。 考えられるすべてのセグメントを試して結果を確認するなど、二次的な動作を伴うソリューションでは、大まかに次のことが必要になります。$10^{10}$制限時間を大幅に超えた最悪の場合の作戦。 リニアまたは$O(n \log n)$ソリューションは簡単に十分に高速です。 

いくつかの特殊なケースは注目に値します。 

すでにソート済みの配列を考えてみましょう。```
5
1 2 3 4 5
```正しい答えは次のとおりです。```
yes
1 1
```長さ 1 のセグメントを反転しても何も変わらないため、要件は満たされます。 不注意に実装すると、誤って印刷される可能性があります`"no"`減少する部分が存在しないからです。 

完全に逆の配列を考えてみましょう。```
3
3 2 1
```正しい答えは次のとおりです。```
yes
1 3
```配列全体が単一の減少セグメントを形成し、それを反転すると配列がソートされます。 

複数の分離された反転を考えてみましょう。```
5
3 1 2 5 4
```正しい答えは次のとおりです。```
no
```両方の障害の位置を修正する単一の連続した逆転はありません。 最初の反転のみを調べる実装では、このケースを誤って受け入れる可能性があります。 

終点に接する減少セグメントを考えてみましょう。```
5
1 5 4 3 6
```正しい答えは次のとおりです。```
yes
2 4
```片側が存在しない可能性があるため、反転されたセグメントの周囲の境界チェックは慎重に処理する必要があります。 

## アプローチ

 単純な総当たりソリューションでは、考えられるすべてのセグメントが試行されます。$[l,r]$。 選択ごとに、そのセグメントを反転し、結果の配列がソートされているかどうかを確認し、有効なセグメントが見つかった場合は停止します。 

このアプローチは、許可されているすべての操作を明示的に検査するため、正しいです。 問題は走行時間です。 がある$O(n^2)$可能なセグメント。 結果の配列がソートされているかどうかを確認するコスト$O(n)$。 全体の複雑さは次のようになります。$O(n^3)$、これは完全に不可能です$n=10^5$。 

重要な観察は、1 回の反転で配列をソートできる場合、すべての無秩序は 1 つの連続した減少ブロックに集中するはずであるということです。 

これを確認する便利な方法は、配列をソートされたバージョンと比較することです。 すべての値は個別であるため、すべての要素は固有の正しい位置を持ちます。 1 つのセグメントを反転することで配列が修正される場合、元の配列がソートされた配列と異なる位置は、1 つの連続した間隔を形成する必要があります。 

すべての反転をテストする代わりに、配列のソートされたバージョンを構築できます。 次に、配列が異なる最初の位置と、配列が異なる最後の位置を見つけます。 これらの位置は、反転する価値のある唯一の候補セグメントを定義します。 

そのセグメントを反転するとソートされた配列が生成される場合、答えは次のようになります。`"yes"`。 それ以外の場合は、有効なセグメントが存在しません。 

これにより、問題は 1 つの分類と 1 つの検証に減ります。

 | ブルートフォース |$O(n^3)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取り、ソートされたコピーを作成します。 
2. 元の配列がソートされた配列と異なるすべての位置を見つけます。 
3. 異なる位置がない場合、配列はすでにソートされています。 出力`"yes"`そしてセグメント`1 1`。 
4. それ以外の場合は、`l`最初の異なる位置であり、`r`最後の異なる位置になります。 
5. セグメントを反転します。`l`に`r`元の配列のコピーにあります。 
6. 変更された配列とソートされた配列を比較します。 
7. 同一の場合は出力`"yes"`そしてインデックス`l+1`そして`r+1`この問題では 1 から始まるインデックスが使用されているためです。 
8. それ以外の場合は出力`"no"`。 

### なぜ効果があるのか

 しましょう$b$配列のソートされたバージョンになります。 

何らかの逆転によって配列がソートされたとします。 反転されたセグメントの外側では要素は決して移動しないため、それらの位置はすでに一致している必要があります$b$。 したがって、元の配列と配列の間の不一致はすべて、$b$1 つの連続した間隔内になければなりません。 

最初の不一致と最後の不一致により、すべての不一致を含む最小間隔が一意に決定されます。 有効な反転は、その間隔を正確にカバーする必要があります。 より小さい間隔を反転すると、少なくとも 1 つの不一致はそのまま残り、より大きな間隔を反転すると、すでに一致している位置が変更されます。 

アルゴリズムは、この唯一の可能な候補間隔を逆にして、結果がソートされた配列と等しいかどうかを直接チェックします。 そうであれば、有効な反転が存在します。 そうでない場合、単一の反転では配列をソートできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    b = sorted(a)

    diff = [i for i in range(n) if a[i] != b[i]]

    if not diff:
        print("yes")
        print(1, 1)
        return

    l = diff[0]
    r = diff[-1]

    c = a[:]
    c[l:r + 1] = reversed(c[l:r + 1])

    if c == b:
        print("yes")
        print(l + 1, r + 1)
    else:
        print("no")

solve()
```この解決策は、完全にソートされたターゲット配列を作成することから始まります。 成功した結果はすべてこのソートされたバージョンと一致する必要があるため、アルゴリズム全体で参照として機能します。 

リスト`diff`現在の配列がソートされた配列と一致しないすべての位置を保存します。 このリストが空の場合、配列はすでにソートされています。 1 セグメントの長さの反転が許可されているため、答えはすぐに得られます。`"yes"`インデックス付き`1 1`。 

不一致が存在する場合、最初と最後の不一致が唯一の候補セグメントを定義します。 その範囲を反転すると、すでに正しい位置はそのままにしたまま、間違って配置された可能性のあるすべての要素が移動します。 

最終的な比較`c == b`完全な正確性チェックとして機能します。 これにより、境界や隣接する値に関する難しいケース分析が回避されます。 反転された配列がソートされた配列と正確に一致する場合、セグメントは機能します。 それ以外の場合は、有効なセグメントが存在しません。 

最も一般的な実装上の間違いは、問題で 1 から始まるインデックスが使用されていることを忘れることです。 内部的には Python の 0 から始まるインデックスを使用し、答えを出力するときにのみ変換します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def solve():
        n = int(input())
        a = list(map(int, input().split()))

        b = sorted(a)

        diff = [i for i in range(n) if a[i] != b[i]]

        out = []

        if not diff:
            out.append("yes")
            out.append("1 1")
            return "\n".join(out)

        l = diff[0]
        r = diff[-1]

        c = a[:]
        c[l:r + 1] = reversed(c[l:r + 1])

        if c == b:
            out.append("yes")
            out.append(f"{l + 1} {r + 1}")
        else:
            out.append("no")

        return "\n".join(out)

    global input
    input = sys.stdin.readline
    return solve()

# provided sample
assert run("3\n3 2 1\n") == "yes\n1 3", "sample"

# already sorted
assert run("5\n1 2 3 4 5\n") == "yes\n1 1", "already sorted"

# middle segment reversal
assert run("5\n1 5 4 3 6\n") == "yes\n2 4", "middle decreasing block"

# impossible case
assert run("5\n3 1 2 5 4\n") == "no", "multiple disorder regions"

# minimum size
assert run("1\n42\n") == "yes\n1 1", "single element"
```| テスト入力 | 期待される出力 | 検証内容 |

 |`1 / 42`|`yes 1 1`| 最小配列サイズ |
