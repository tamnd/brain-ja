 ## 解決策
 ## 問題の理解

 私たちは持っています`n`フラワーボックス。 箱から`i`、その間に任意の数の花を撮ることができます。`0`そして`f[i]`、包括的。 色はそれぞれ異なるため、各ボックスからどれだけの花を取り出したかによって、セレクションが完全に表現されます。 

タスクは整数ベクトルの数をカウントすることです$$x_1+x_2+\cdots+x_n=s$$そのような$$0 \le x_i \le f_i$$箱ごとに。 答えはモジュロで報告する必要があります$10^9+7$。 

まず目につくのは数字の大きさです。 ボックスの数は最大です$20$、非常に小さいです。 一方で、どちらも$s$ボックスの容量は膨大になる可能性があり、$10^{14}$そして$10^{12}$それぞれ。 

これらの制約により、合計に対する動的プログラミングは即座に排除されます。 複雑さが依存するあらゆるソリューション$s$絶望的だ。 平$O(ns)$までの処理が必要になります$10^{14}$州。 

の小さな値$n$が本当の手がかりです。 いつでも$n \le 20$、サブセットを含む手法は多くの場合実行可能になります。$2^{20}\approx 10^6$、管理可能です。 

見落としやすいエッジケースがいくつかあります。 

考慮する```
1 0
0
```唯一の有効な選択は、花をまったく受け取らないことです。 答えは`1`。 誤ってゼロを特別な無効なケースとして扱う数式は、ここで失敗します。 

考慮する```
1 5
3
```ボックスには花が 3 つしか入っていないため、有効な選択は存在しません。 答えは`0`。 制限のないカウント式では、誤って 1 つのソリューションがカウントされてしまいます。 

考慮する```
2 1
0 0
```繰り返しになりますが、答えは`0`。 上限により、すべての候補解が完全に排除されます。 

包含と排除の際には、別の微妙なケースが現れます。 一部のサブセット寄与は、次の計数解に対応します。$$x_1+\cdots+x_n = T$$と$T<0$。 このような項の寄与はゼロでなければなりません。 このチェックを忘れると、無効な二項係数が計算に入力されることになります。 

## アプローチ

 強引な解決策では、すべての箱から可能な限りすべての花を選択することになります。 

各ボックスごとに$i$、 がある$f_i+1$可能性。 総検索スペースは次のとおりです。$$\prod_{i=1}^{n}(f_i+1).$$以来$f_i$届くかもしれない$10^{12}$、これは天文学的な大きさです。 次のような小さな値であっても、$f_i=100$、検索空間は次のようになります。$101^{20}$、それはすでに不可能です。 

この問題の自然な制限のないバージョンははるかに簡単です。 上限を無視して必要なだけを指定すると、$$x_1+\cdots+x_n=s,\qquad x_i\ge 0,$$次に、古典的な星と棒の公式は次のようになります。$$\binom{s+n-1}{n-1}.$$唯一の障害は上限です$x_i\le f_i$。 

単純な下限と上限があれば、包含/除外が有力な候補になります。 無制限のカウントは簡単です。 1 つ以上の上限に違反する解は体系的にカウントできます。 

特定のボックスを想定します$i$その制限を破っています。 それから$$x_i\ge f_i+1.$$させて$$y_i=x_i-(f_i+1).$$このシフトの後、$y_i\ge 0$、合計は によって減少します$f_i+1$。 

サブセットの場合$S$のボックスがその制限に違反することを強制され、すべての変数をシフトした後、$S$、$$\sum x_i=s$$になる$$\sum y_i=s-\sum_{i\in S}(f_i+1).$$非負の解の数も星と棒の数です。 

以来$n\le 20$、すべてのサブセットを列挙できます$S$。 あるのは$2^n$彼らのうち。 

残りの課題は、最高値が以下の値になる可能性がある二項係数を計算することです。$10^{14}$。 幸いなことに、底値は常に最大で$$n-1\le 19.$$この小さな値により、モジュロを直接乗算する計算が可能になります。$10^9+7$。

 | --- | --- | --- | --- |
 | ブルートフォース |$O\!\left(\prod (f_i+1)\right)$|$O(n)$| 遅すぎる |
 | 最適な包含-除外 |$O(n2^n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`、`s`、および容量`f[i]`。 
2. 次のビットマスクを使用してボックスのすべてのサブセットを列挙します。`0`に`(1<<n)-1`。 
3. 現在のサブセットの場合`mask`、計算する$$T=s-\sum_{i\in S}(f_i+1),$$どこ$S$は選択されたビットのセットです。 

これは、すべてのボックスを強制的に挿入することに相当します。$S$その限界を超えること。 

1. もし$T<0$、シフト後に非負の解はないため、このサブセットはゼロに寄与します。 
2. それ以外の場合は、次の無制限の解を数えます。$$y_1+\cdots+y_n=T.$$星とバーが与えるもの$$\binom{T+n-1}{n-1}.$$1. サブセットのサイズが偶数の場合、この量を答えに追加します。 
2. サブセットのサイズが奇数の場合は、答えからこの数量を減算します。 

これはまさに包含排他原理です。 
3. すべてのサブセットを処理した後、答えのモジュロを正規化します。$10^9+7$。 

### なぜ効果があるのか

 すべてのサブセットについて$S$、包含-除外は、すべての変数が含まれる解をカウントします。$S$上限に違反します。 違反している各変数を次のように置き換えます。$$y_i=x_i-(f_i+1)$$は、そのような解と縮小和方程式の非負の解との間に全単射を作成します。 スターアンドバーは、これらのソリューションを正確にカウントします。 

包含-除外により、すべての有効なソリューションが 1 回カウントされ、すべての無効なソリューションがキャンセルされることが保証されます。 すべてのサブセットが処理されるため、最終的な合計は、すべての上限を同時に満たす解の数に等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def modinv(x):
    return pow(x, MOD - 2, MOD)

def comb_large_n_small_k(n, k):
    if n < 0 or k < 0 or k > n:
        return 0

    res = 1
    for i in range(1, k + 1):
        res = res * ((n - k + i) % MOD) % MOD
        res = res * modinv(i) % MOD
    return res

def solve():
    n, s = map(int, input().split())
    f = list(map(int, input().split()))

    ans = 0

    for mask in range(1 << n):
        t = s
        bits = 0

        for i in range(n):
            if mask & (1 << i):
                t -= f[i] + 1
                bits += 1

        if t < 0:
            continue

        ways = comb_large_n_small_k(t + n - 1, n - 1)

        if bits & 1:
            ans -= ways
        else:
            ans += ways

    print(ans % MOD)

solve()
```中心となるルーチンは、`comb_large_n_small_k`。 上の引数は次のように大きくなります。$10^{14}$、ただし、下位の引数は最大でも$19$。 私たちは計算します$$\binom{N}{K} = \prod_{i=1}^{K} \frac{N-K+i}{i} \pmod{MOD}$$直接。 

なぜなら$K<MOD$、すべての分母には逆モジュラーがあります。 

サブセット ループは包含と除外を正確に実装します。 選択したボックスごとに減算します`f[i] + 1`これは、そのボックスを強制的に制限を超えるようにすることに相当します。 結果の合計が負になる場合、解は存在せず、サブセットは何も寄与しません。 

サブセット サイズのパリティによって、寄与が加算されるか減算されるかが決まります。

 ## 特殊なケース

 検討してください```
1 0
0
```空のサブセットは次のようになります。$$\binom{0}{0}=1.$$違反しているサブセットは負の縮小合計を生成し、寄与する値はゼロです。 最終的な答えは、`1`、花を撮らないというユニークな選択を表しています。 

考慮する```
1 5
3
```空のサブセットが貢献します$$\binom{5}{0}=1.$$違反するサブセットが寄与する$$\binom{1}{0}=1.$$包含排除利回り$$1-1=0.$$すべての無制限の解は上限に違反するため、キャンセルが完了します。 

考慮する```
2 1
0 0
```空のサブセットが貢献します$$\binom{2}{1}=2.$$各シングルボックス違反サブセットの影響$1$、ダブルボックスのサブセットが寄与します。$0$。 結果は$$2-1-1=0.$$どちらのボックスにも花が含まれていないため、有効な選択は存在しません。 

マイナスサムの場合は自動的に処理されます。 いつでも$$s-\sum_{i\in S}(f_i+1)<0,$$変数シフト後に非負の解は存在しないため、寄与はゼロになります。 これにより、無効な二項評価が防止され、包含と除外が数学的に正確に保たれます。
