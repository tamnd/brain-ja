 ## 解決策
 ## 問題の理解

 私たちは 8 × 8 のチェス盤でインタラクティブ ゲームをプレイしています。 私たちが管理する女王と、裁判官が管理する王がいます。 キングは、クイーンの開始セルとは異なる未知のセルから開始します。 最初のクイーンの位置を選択し、キングが最初に動くことからゲームが始まります。 キングが移動するたびに、その移動方向のみが示され、目的地は示されません。 次に女王を移動します。 

キングはチェスのキングのように 8 方向のいずれかに 1 ステップ移動しますが、追加の制限があります。現在のクイーンと同じ行、列、または対角線上にあるマス目に足を踏み入れることは許可されていません。 これは、女王が王の行動力を制限する禁断の境界線を定めることを意味します。 

私たちの目標は、最大 130 回のクイーン手以内でキングを正当な手がない位置に追い込むことです。 各動きは完全にインタラクティブであり、キングの動きの後に、指示された方向のみに基づいてクイーンの動きを決定する必要があります。 

重要な問題は、私たちが王の正確な位置を決して観察できないことです。 私たちは彼がいる可能性のあるセルのセットのみを維持し、このセットは両方のプレイヤーの動きからの制約をシミュレートするにつれて進化します。 

このボードは小さく、わずか 64 セルですが、相互作用の制約と移動の制限により、これは最短パスの問題ではなく、動的な状態追跡の問題になります。 

素朴な誤解は、決定論的な作品のように王を「追いかけ」ようとすることでしょう。 正確な位置がわからないため、これはすぐに失敗します。 正しい見方は、私たちが信念セットを縮小しているということです。 

エッジ ケースは、信念セットが切断された場合、または信念セットがすべて禁止されたクイーン ライン上にあるセルに崩壊した場合に発生します。 クイーンの攻撃ラインを尊重せずに境界ボックスのみを追跡する不注意なアプローチは、幾何学的にはもっともらしいが、キングにとって実際には違法な状態を生成します。 

## アプローチ

 ブルート フォースの観点では、考えられるすべてのキングの位置を明示的に追跡します。 最初は、女王の開始セルを除くすべてのセルが可能です。 各キングが方向を移動した後、すべての候補ポジションはその方向に 1 ステップ移動しますが、これは結果のポジションがボード内に留まり、現在のクイーンによって攻撃されない場合に限られます。 これにより、可能なキングの位置の更新されたセットが得られます。 

ボードには 64 セルしかないため、このブルート シミュレーションはすでに小さくなり、セットの維持費が安くなります。 本当の課題は、クイーンの動きを選択することです。 考えられるすべてのクイーンの目的地を試し、セットへの影響をシミュレートすると、移動後に可能なキングの位置がどれだけ残っているかを測定できます。 新しいクイーンと同じ行、列、または対角線上にあるセルはキングにとって不可能になるため、クイーンの移動によりキングはさらに制限されます。 

これは自然な貪欲なアイデアにつながります。 有効なクイーンの動きごとに、次の状態をシミュレートし、残りの可能なキング セットのサイズを最小化する動きを選択します。 直感的には、状態空間が非常に小さいため、各ステップで不確実性を積極的に縮小すれば、移動制限内で強制的に収束させるのに十分であると考えられます。 

すべてのクイーンの動きを明示的に試し、すべてのポジションをシミュレートする総当たりバージョンは、総作業量がおよそ 130 x 64 x 64 の操作に制限されるため、十分に高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての状態の残酷なシミュレーション + 貪欲な女王の選択 | O(130 × 64²) | お(64) | 承認済み |
 | 完全な状態追跡を行わない任意の幾何学的ヒューリスティック | O(130×1) | お(1) | 失敗 |

 重要な移行は、必要な唯一の情報は実行可能なキングの位置のセットであり、このセットは完全に総当り攻撃を実行できるほど小さいままであることに気づくことです。 

## アルゴリズムのチュートリアル

現在キングがいる可能性のあるすべてのセルの集合 S を維持します。 クイーンの位置 Q も追跡します。 

1. S を Q を除くすべての 64 セルとして初期化します。これは、考えられるすべての隠れたキングの配置を表します。 
2. キングの移動方向を受け取ると、S 内のすべての位置をその方向に 1 ステップずらすことによって新しい候補セット S' を計算します。 ボードから外れたシフトされた位置はすべて破棄されます。 
3. S' から、現在のクイーン Q によって攻撃されているすべてのポジションを削除します。キングはクイーンが制御するラインに入ることができないため、これらのポジションは不可能です。 
4. 次に、次のクイーン位置 Q' を選択します。 Q からの正当なクイーン移動によって到達可能なすべてのセルを列挙します。これは、同じ行、列、または対角にあるが Q に等しくないセルを意味します。 
5. 各候補 Q' について、クイーンをそこに移動した場合に S がどうなるかをシミュレーションします。 クイーンが移動すると、それらのマスはキングにとって違法になるため、S' から Q' によって攻撃されるすべてのポジションを削除します。 
6. すべての候補 Q' の中から、結果として得られるセットのサイズを最小にするものを選択します。 Q をその位置に更新し、S をシミュレーション結果に置き換えます。 
7. いずれかの時点で S が空になった場合、キングはトラップされ、インタラクションは終了します。 

重要な不変条件は、S が常に、観察されたすべてのキング方向とすべてのクイーン制約と一致する位置のセットを正確に表すことです。 すべての更新ステップで真の遷移ルール​​が逆に適用されるため、キングの位置が誤って追加または削除されることはありません。 

S は実際の到達可能な位置を決して過大評価したり過小評価したりすることはなく、各クイーンの動きはそのサイズを貪欲に最小化するため、キングの正当な手がなくなるまで不確実性は着実に崩壊します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

DIRS = {
    "Right": (0, 1),
    "Left": (0, -1),
    "Up": (-1, 0),
    "Down": (1, 0),
    "Up-Right": (-1, 1),
    "Up-Left": (-1, -1),
    "Down-Right": (1, 1),
    "Down-Left": (1, -1),
}

def inside(x, y):
    return 1 <= x <= 8 and 1 <= y <= 8

def attacked(x, y, qx, qy):
    return x == qx or y == qy or abs(x - qx) == abs(y - qy)

def apply_shift(S, dx, dy, qx, qy):
    ns = []
    for x, y in S:
        nx, ny = x + dx, y + dy
        if inside(nx, ny) and not attacked(nx, ny, qx, qy):
            ns.append((nx, ny))
    return ns

def queen_moves(qx, qy):
    res = []
    for i in range(1, 9):
        for j in range(1, 9):
            if (i, j) == (qx, qy):
                continue
            if i == qx or j == qy or abs(i - qx) == abs(j - qy):
                res.append((i, j))
    return res

def main():
    t = int(input())
    for _ in range(t):
        # initial placement
        qx, qy = 1, 1
        print(qx, qy, flush=True)

        # initial S (unknown king position)
        S = [(i, j) for i in range(1, 9) for j in range(1, 9) if (i, j) != (qx, qy)]

        for _ in range(130):
            s = input().strip()
            if s == "Done":
                break

            dx, dy = DIRS[s]

            # king moves
            S = apply_shift(S, dx, dy, qx, qy)

            # try all queen moves
            best = None
            bestS = None

            for nq in queen_moves(qx, qy):
                nx, ny = nq
                cand = []
                for x, y in S:
                    if not attacked(x, y, nx, ny):
                        cand.append((x, y))
                if bestS is None or len(cand) < len(bestS):
                    bestS = cand
                    best = nq

            qx, qy = best
            S = bestS

            print(qx, qy, flush=True)

            if not S:
                break

if __name__ == "__main__":
    main()
```このソリューションは、不確実性セットを明示的に維持することを中心に構築されています。 の`apply_shift`関数は、ボードの境界とクイーンの現在の攻撃ラインの両方を尊重しながらキングの動きを実装します。 の`queen_moves`関数は、ルークとビショップの移動ルールを直接チェックすることにより、すべての合法的なクイーンの宛先を列挙します。 

メインループは最初にキングの方向を処理し、信念セットを更新し、次に枝刈り効果をシミュレートすることによって考えられるすべてのクイーンの動きを評価します。 選択された手は、残りのキング候補の位置を最小にするものであり、これは情報利得を最大化することに直接対応します。 

微妙な点は、複数の状態を段階的に維持しようとするのではなく、クイーンが移動するたびにキングの位置の合法性を再計算していることです。 ボードが小さいため、再計算が簡単になり、エラーが発生しにくくなります。

 ## 特殊なケース

 重大なエッジケースは、残りのキングポジションがすべて、現在のクイーンによって攻撃されたライン上にあるときに発生します。 その状況では、クイーンの制限を適用すると、セットはすぐに空になります。 各クイーンの移動後のフィルタリング ステップで攻撃されたすべてのマスが削除され、空のセットはキングが歴史と一致する法的な場所を持たないことを示す有効な最終条件であるため、アルゴリズムはこれを正しく処理します。 

別のケースは、最上列からの連続した「上」移動など、キングがボードの境界に繰り返しヒットする場合に発生します。 シフト ステップは無効な位置を自然に破棄し、信念セットが誤ってラップしたり停滞したりするのを防ぎます。 縮小は純粋に幾何学的なものであり、一貫性が保たれます。 

最後に、キングが既に単一セルに強制的に配置されている場合、女王候補が移動するたびに、そのシングルトンが保存されるか、削除されます。 貪欲な選択は常に、可能であれば空のセットにつながる手を選択し、対話を即座に終了します。
