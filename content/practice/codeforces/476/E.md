 ## 解決策
 ## 問題の理解

 文字列から始めます`s`。 正確に削除する場合があります`x`文字、残りの文字は元の順序を維持します。 結果の文字列は次のサブシーケンスです。`s`。 

結果の文字列内で、**重複しない** パターンができるだけ多く出現するものを探します。`p`できるだけ。 削除数ごとに`x`から`0`に`|s|`、達成可能な最大出現数を出力する必要があります。 

主な難点は、削除後に出現回数がカウントされることです。 のコピー`p`元の文字列の部分文字列として現れる必要はありません。 間の文字を削除して、離れた文字を隣接させることもできます。 

長さ`s`最大でも 2000 ですが、`p`長さは最大 500 です。三次解はすでに危険であり、すべての部分列を列挙することに近いことは完全に不可能です。 解決策`O(n²)`または`O(n² + nm)`は正しいターゲットです。 

間違いやすい状況がいくつかあります。 

考慮する：```
s = "aa"
p = "aa"
```削除がゼロの場合、出現は 1 つです。 1 つの削除でできるのは、`"a"`, したがって、答えはゼロになります。 よくある間違いは、1 つの出現に必要な最小限の削除のみを計算し、それより大きな削除数もすべて可能であると結論付けることです。 ここではそれは誤りです。 

別の微妙なケースは次のとおりです。```
s = "abca"
p = "aa"
```パターンは次の部分文字列ではありません`s`、ただし、削除することで形成できます。`"bc"`。 元の文字列の部分文字列のみを検索するソリューションでは、有効な答えが見つかりません。 

3 番目の落とし穴は、オカレンスが元の文字列内の文字を共有する場合に発生します。```
s = "aaaaa"
p = "aa"
```最後の文字列内の出現箇所は重複してはなりません。 ポジションの選択`(1,2)`そして`(2,3)`同じキャラクターが両方のコピーに参加しているため、これは不正です。 動的プログラミングでは、互いに素な間隔を強制する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブシーケンスが試行されます。`s`、重複しないコピーが何枚あるか数えます。`p`が表示され、対応する削除数の回答が更新されます。 長さ 2000 の文字列があるため、`2^2000`その後、これは絶望的です。 

次の観察は、次のことが 1 回発生することです。`p`最後の文字列内の位置の選択に対応します。`s`その呪文`p`続編として。 最初に選択された位置が`l`最後に選択した位置は`r`。 間隔の中で`[l, r]`、オカレンスで使用されていないすべての文字を削除する必要があります。 強制削除の数は$$(r-l+1)-|p|.$$1 つの発生を表す最も安価な間隔がわかっている場合、問題は間隔スケジュールのように見え始めます。 

すべての開始位置について`i`、可能な限り最も早い終了位置を計算します。`end[i]`そのような`p`で始まるサブシーケンスとして照合できます`i`。 そのような間隔が存在する場合、それを選択すると 1 つの発生が発生し、強制されます。$$(end[i]-i+1)-|p|$$削除。 

ここで問題は次のようになります。 

重複しない発生間隔をいくつか選択します。 正確に取得するために必要な必須の削除の数を最小限に抑える`k`出来事。 

その最小値がわかれば、最終的な答えは簡単になります。 選択したすべての間隔外の文字は無関係です。 これらは自由に保存または削除できます。 これにより、最小削除 DP がすべての正確な削除数の回答に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(2^n)`|`O(n)`| 遅すぎる |
 | インターバル遷移による最適な DP |`O(n² + nm)`|`O(n²)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次の出現テーブルを事前計算します。`s`。 

すべての位置およびすべての文字について、その文字の最初の出現をその位置またはその後に保存します。 これにより、文字ごとに一定時間で部分シーケンスのマッチングが可能になります。`p`。 
2. ポジションごとに`i`で`s`、次の 1 回の発生を表す最も早い間隔を計算します。`p`。 

もし`s[i]`に等しくありません`p[0]`、そこから何かが始まることはありません。 

それ以外の場合は、残りの文字と貪欲に一致します。`p`次の出現テーブルを使用します。 マッチングが成功し、その位置で終了した場合`r`、 店：```
end[i] = r
cost[i] = (r - i + 1) - m
```どこ`m = |p|`。 
3. しましょう`dp[pos][k]`前で終わるプレフィックスを処理した後に必要な必須の削除の最小数です。`pos`、正確に作成しながら`k`出来事。 

初期化:```
dp[0][0] = 0
```4. 位置を左から右に処理します。 

位置で`i`、選択肢は2つあります。 

位置をスキップします:```
dp[i+1][k] = min(dp[i+1][k], dp[i][k])
```から始まる発生間隔を取得します。`i`:```
dp[end[i]+1][k+1]
    = min(dp[end[i]+1][k+1],
          dp[i][k] + cost[i])
```直接ジャンプ`end[i]+1`選択されたオカレンスが互いに素であることを保証します。 
5. すべての移行後、`dp[n][k]`正確に必要な最小限の必須削除に等しい`k`出来事。 
6. これらの最小値をすべての削除数の答えに変換します。 

もし`dp[n][k] = d`、 それから：```
mandatory deletions = d
maximum deletions preserving k copies = n - k*m
```間隔内のすべての削除数```
[d, n - k*m]
```達成可能です。 

このような削除数ごとに、次のように回答を更新します。`k`。 

### なぜ効果があるのか

 選択された各出現箇所は、一致で使用されていないすべての文字を内部から除去する必要がある間隔に対応します。 DP はこれらの必須の削除を明示的に蓄積し、間隔の終わりを飛び越えることによる重複を禁止します。 

選択した出現間隔外の文字は、出現が存在するかどうかに影響しません。 このような文字は、個別に保持または削除できます。 そのため、DP は強制的な削除を最小限に抑えるだけで済みます。 これらが修正されると、より大きな削除ごとにカウントアップされます。`n - km`追加の外字を削除することで実現できます。 

DP は、重複しない発生間隔の有効なセットをすべて調査し、発生回数ごとに最小の必須削除コストを記録します。 それはまさに、すべての答えを導き出すために必要な量です。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    s = input().strip()
    p = input().strip()

    n = len(s)
    m = len(p)

    # next occurrence table
    nxt = [[n] * 26 for _ in range(n + 2)]

    for c in range(26):
        nxt[n][c] = n

    for i in range(n - 1, -1, -1):
        nxt[i] = nxt[i + 1][:]
        nxt[i][ord(s[i]) - 97] = i

    end = [-1] * n
    cost = [0] * n

    for i in range(n):
        if s[i] != p[0]:
            continue

        pos = i
        ok = True

        for j in range(1, m):
            pos = nxt[pos + 1][ord(p[j]) - 97]
            if pos == n:
                ok = False
                break

        if ok:
            end[i] = pos
            cost[i] = (pos - i + 1) - m

    INF = 30000

    dp = [array('H', [INF]) * (n + 1) for _ in range(n + 1)]
    dp[0][0] = 0

    for i in range(n):
        cur = dp[i]
        nxt_row = dp[i + 1]

        for k in range(n + 1):
            val = cur[k]
            if val == INF:
                continue

            if val < nxt_row[k]:
                nxt_row[k] = val

            if end[i] != -1:
                r = end[i] + 1
                nv = val + cost[i]
                if nv < dp[r][k + 1]:
                    dp[r][k + 1] = nv

    min_del = dp[n]

    ans = [0] * (n + 1)

    for k in range(n + 1):
        d = min_del[k]
        if d == INF:
            continue

        max_del = n - k * m
        if max_del < d:
            continue

        for x in range(d, max_del + 1):
            if k > ans[x]:
                ans[x] = k

    print(*ans)

solve()
```次の出現テーブルを使用すると、部分シーケンスの一致の最も早い終了位置を見つけることができます。`O(m)`各スタートポジションの時間。 最大でも 2000 回の起動があるため、`m ≤ 500`、この前処理にはコストがかかります`O(nm)`。 

DP には、最小限の必須の削除が保存されます。 から飛び出すトランジション`i`直接に`end[i] + 1`重複を防ぐ仕組みです。 最初の間隔が終了した後に 2 番目のオカレンスが強制的に開始されるため、2 つのオカレンスで文字を共有することはできません。 

最後の変換ステップでは、多くの誤ったソリューションが失敗します。 最小限の削除を知る`k`発生だけでは十分ではありません。 上限も尊重する必要があります`n - km`、それぞれの発生には必要があるため、`m`生き残ったキャラクター。 

## 実用的な例

 ### サンプル 1

 入力:```
s = "aaaaa"
p = "aa"
```発生間隔は次のとおりです。 

| 開始 | 終わり | コスト |
 | --- | --- | --- |
 | 0 | 1 | 0 |
 | 1 | 2 | 0 |
 | 2 | 3 | 0 |
 | 3 | 4 | 0 |

 DP の主要なステートメントは次のとおりです。 

| ポジション | 出来事 | 最小必須削除数 |
 | --- | --- | --- |
 | 0 | 0 | 0 |
 | 2 | 1 | 0 |
 | 4 | 2 | 0 |
 | 5 | 2 | 0 |

 DP は次のことを発見しました。 

| k | minDel[k] |
 | --- | --- |
 | 0 | 0 |
 | 1 | 0 |
 | 2 | 0 |

 のために`k = 2`、達成可能な削除範囲は次のとおりです。```
[0, 5 - 2*2] = [0, 1]
```したがって、削除は重要です`0`そして`1`2 つのオカレンスを保持できます。 

最終出力:```
2 2 1 1 0 0
```この例は、発生間隔外の追加の削除が許可されることを示しています。 

### 例 2

 入力:```
s = "abca"
p = "aa"
```発生間隔:

 | 開始 | 終わり | コスト |
 | --- | --- | --- |
 | 0 | 3 | 2 |

 間隔の長さは 4 ですが、パターンの長さは 2 であるため、2 つの削除が必須です。 

DP の結果:

 | k | minDel[k] |
 | --- | --- |
 | 0 | 0 |
 | 1 | 2 |

 1 つの出来事について:```
deletion range = [2, 4 - 2] = [2, 2]
```正確に 2 つの削除だけが 1 つのコピーを保持できます`"aa"`。 

答えは次のようになります。```
0 0 1 0 0
```これは、単に次のことを確認するだけの理由を示しています。`minDel[k] ≤ x`では不十分です。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 |`O(n² + nm)`| DPは`O(n²)`、インターバル構築は`O(nm)`|
 | スペース |`O(n²)`| DPサイズ表`(n+1) × (n+1)`|

 と`n ≤ 2000`、DP は約 400 万回の状態更新を実行しますが、これは制限内に問題なく収まります。 メモリ使用量も 256 MB の制限内に収まります。 

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from array import array

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    s = input().strip()
    p = input().strip()

    n = len(s)
    m = len(p)

    nxt = [[n] * 26 for _ in range(n + 2)]
    for i in range(n - 1, -1, -1):
        nxt[i] = nxt[i + 1][:]
        nxt[i][ord(s[i]) - 97] = i

    end = [-1] * n
    cost = [0] * n

    for i in range(n):
        if s[i] != p[0]:
            continue

        pos = i
        ok = True

        for j in range(1, m):
            pos = nxt[pos + 1][ord(p[j]) - 97]
            if pos == n:
                ok = False
                break

        if ok:
            end[i] = pos
            cost[i] = (pos - i + 1) - m

    INF = 30000
    dp = [array('H', [INF]) * (n + 1) for _ in range(n + 1)]
    dp[0][0] = 0

    for i in range(n):
        for k in range(n + 1):
            v = dp[i][k]
            if v == INF:
                continue

            if v < dp[i + 1][k]:
                dp[i + 1][k] = v

            if end[i] != -1:
                r = end[i] + 1
                nv = v + cost[i]
                if nv < dp[r][k + 1]:
                    dp[r][k + 1] = nv

    ans = [0] * (n + 1)

    for k in range(n + 1):
        d = dp[n][k]
        if d == INF:
            continue

        mx = n - k * m
        if mx < d:
            continue

        for x in range(d, mx + 1):
            ans[x] = max(ans[x], k)

    return " ".join(map(str, ans))

# provided sample
assert run("aaaaa\naa\n") == "2 2 1 1 0 0"

# minimum size
assert run("a\na\n") == "1 0"

# pattern impossible
assert run("abc\nd\n") == "0 0 0 0"

# exact deletion bound
assert run("aa\naa\n") == "1 0 0"

# subsequence but not substring
assert run("abca\naa\n") == "0 0 1 0 0"

 | --- | --- | --- |
 |`a / a`|`1 0`| 最小の有効な入力 |

 ## 特殊なケース

 次のことを考慮してください。```
aa
aa
```DP は、必須の削除コストが発生した 1 件を見つけました。`0`。 その発生を維持する最大削除数も`0`両方の文字が必要なためです。 実現可能な範囲は、`[0, 0]`。 削除数については`1`、正解は次のようになります`0`。 

ここで次のことを考えてみましょう。```
abca
aa
```最も早い発生間隔は、`[0, 3]`。 その長さは`4`、パターンの長さは`2`, したがって、2つの削除は避けられません。 DPレコード`minDel[1] = 2`。 以来`n - km = 2`、1 回の出現で達成できる唯一の削除数は正確に`2`。 

ついに：```
aaaaa
aa
```オカレンスを選択するには、重複する方法が多数あります。 間隔を選択するとその終了後の位置に直接ジャンプするため、DP では重複は許可されません。 選択された 2 つの出現は常に素であり、最終的な文字列で重複しないコピーという問題の要件と一致します。
