 ## 問題の理解

 すべての整数の合計を計算するように求められます$x$指定された 2 つの整数に関してモジュラー条件のペアを満たす$a$そして$b$。 具体的には、正の整数$x$いくつか存在する場合は良いと考えられます$k$1との間$a$そのように分割する$x$による$k$の残りが得られます$b$。 言い換えると、$x$モジュロ$k$等しい必要があります$b$。 目標は、そのような整数をすべて合計し、その結果を剰余として返すことです。$10^9 + 7$。 

入力は 2 つの数値で構成されます。$a$そして$b$、それぞれ最大で$10^7$。 以来$a$と同じ大きさにすることができます$10^7$、次の値までのすべての数値を調べる総当り的なアプローチです。$a \cdot b$それ以上の場合は、数兆回の操作が必要になる可能性があり、これは 2 秒の制限時間に収まる量をはるかに超えています。 したがって、ソリューションでは、すべての候補を反復処理することを回避する必要があります。$x$個別に。 

微妙なエッジケースが発生する場合$b$よりも大きいです$a$。 小型用$a$そして大きな$b$の場合、剰余は常に除数より小さくなければならないため、条件を満たす整数はありません。 たとえば、次の場合$a = 1$そして$b = 2$、整数はありません$x$そのような$x \mod 1 = 2$、正しい出力は 0 です。単純な実装では不可能な除算を試みる可能性があるため、これを正しく処理することが重要です。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのことを繰り返すことになります。$k$1から$a$、それぞれについて$k$すべてを反復処理する$x$から始まる$b$十分な大きさの境界まで、増分します$k$そしてチェック$x \mod k = b$。 これは論理的には正しいですが、反復回数は爆発的に増加します。$a = 10^7$、大まかに生産$O(a \cdot (b/k))$実行不可能な操作。 

重要な洞察は、モジュラー演算からパターンを認識することです。$x$満足するもの$x \mod k = b$から始まる等差数列を形成する$b$そして増加します$k$。 このような数列を合計すると、$O(1)$制約を満たす最初と最後の要素を決定したら、等差級数の公式を使用して時間を計算します。 なお、最大値は$x$と考えられるのは$a \cdot (b+1)$、整数の除算プロパティを利用して、次の範囲をグループ化できます。$x/k$は一定のままなので、それぞれを繰り返す必要がなくなります。$x$個別に。 これにより、潜在的に$O(a^2)$問題を$O(\sqrt{a+b})$の間隔で反復して問題を解決する$x$効率的に。

 ## アルゴリズムのチュートリアル

 1. まず、次のことを確認します。$b$を超える$a$。 そうなった場合、剰余は除数より大きくなることはできないため、適切な整数は存在せず、すぐに 0 を返すことができます。 
2. 可能なすべての整数値を反復処理します。$q = \lfloor x / k \rfloor$。 の各値$q$の連続した間隔を定義します$k$を満たす価値観$x = k \cdot q + b$。 以来$k \le a$そして$k > b$（さもないと$x \mod k = b$は不可能です)、対応する最小値と最大値を計算します$x$それぞれに$q$間隔の境界を乗算することにより、$q$そして追加$b$。 
3. 間隔ごとに$x$同じ商を共有する値$q$、連続する整数の合計の公式を使用して等差数列を直接合計します。$sum = n \cdot (first + last)/2$。 モジュロの適用に注意してください$10^9 + 7$オーバーフローを避けるために各ステップで。 
4. すべてのインターバルまで継続します。$k \le a$疲れ果てています。 このアルゴリズムは、異なる商の数が次のとおりであるという観察に基づいています。$q$のために$x/k$によって制限されています$O(\sqrt{a+b})$なぜなら、各商は可能な値の減少系列を生成するからです。$k$価値観。 
5. 総和モジュロを出力します。$10^9 + 7$。 

機能する理由: すべての整数$x$それは満足する$x \mod k = b$一部の人にとっては$1 \le k \le a$商によって定義される 1 つの等差数列に属します$q = x // k$。 考えられる商を反復処理し、各間隔の合計を効率的に計算することで、すべての有効な商を取得します。$x$正確に 1 回だけ実行し、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    a, b = map(int, input().split())
    if b > a:
        print(0)
        return

    result = 0
    k = b + 1
    while k <= a:
        q = (a - b) // k
        max_k = (a - b) // q if q > 0 else a
        count = max_k - k + 1
        total = ((k + max_k) * count // 2) % MOD
        result = (result + total * q + count * b) % MOD
        k = max_k + 1

    print(result)

if __name__ == "__main__":
    main()
```このソリューションはまず、次のようなエッジケースを処理します。$b > a$、すぐに 0 を返します。 メインループは、以下の範囲の合計を効率的に計算します。$k$同じ商を生み出すもの$q$, 等差数列の公式を使用します。 オーバーフローを防ぐためにモジュラー演算が適用されます。 変数`k`各反復の後、次の未処理の範囲に進みます。 

## 実用的な例

 入力用`1 1`、`b`等しい`a`したがって、アルゴリズムは 0 を出力します。適切な整数は存在しません。$x \mod k = 1$不可能なとき$k = 1$。 

入力用`5 2`、イニシャル`k`商は間隔ごとに計算され、次のようなシーケンスが生成されます。`x = 3*1 + 2 = 5`、`x = 4*1 + 2 = 6`、など。各等差数列の合計が結果のモジュロに加算されます。$10^9 + 7$。 最終的な合計は 14 となり、予想される答えと一致します。

 このトレースは、間隔の等差数列の計算を示し、各間隔が次のことを確認します。`x`は 1 回カウントされ、合計は正しいです。
