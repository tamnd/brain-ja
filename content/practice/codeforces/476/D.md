 ## 問題の理解

 任務は構築することです`n`4 つの異なる正の整数のセット。各セットには特定の「ランク」があります。`k`。 ランク条件では、セット内の任意の 2 つの数値の最大公約数 (GCD) が正確に等しいことが必要です。`k`。 1 から上限までの整数を使用できます。`m`、整数は複数のセットに出現できません。 私たちの目標は、可能な限り最小限のものを決定することです`m`これにより、そのような構築が可能になり、セットの 1 つの有効な配置が生成されます。 

入力により得られるのは、`n`そして`k`。`n`最大 10,000 までの値になる可能性があります。これはかなりの量ですが、最大 10,000 までのすべての整数に対するネストされたループを回避すれば管理可能です。`m`。`k`は最大でも 100 であるため、GCD 係数は相対的に小さくなります。`m`。 これは、次のことを示唆しています。`k`小さな互いに素な数のシーケンスによって、候補セットを生成できます。 

エッジケースには以下が含まれます`k = 1`、数値自体はペアごとに互いに素でなければなりません、そして`n = 1`これは簡単ですが、単一のセットを正しく生成できるかどうかを確認します。 もう 1 つの微妙なシナリオは次のような場合です。`k > 1`数値は次の倍数である必要があります`k`しかし、別個であり、除算後の共素でもあります。`k`。 例えば、`n = 2, k = 2`すべての要素を 2 で割ると異なる互いに素な数が得られるセットが必要です。 で割った後の共素性を無視した不注意なアプローチ`k`失敗します。 

## アプローチ

 素朴なアプローチは、1 から 2 までの整数のすべての組み合わせを試してみることです。`m`、すべての 4 要素サブセットの GCD 条件を確認し、それが完了するまで繰り返します。`n`セットが見つかりました。 この強引な方法は正しいですが、4 要素のサブセットの数が O(m^4) になるほど増加するため、法外に遅くなり、`m`不明ですが、生成するには少なくとも 4n が必要と思われます`n`再利用せずにセットします。 のために`n = 10^4`、これはまったく不可能です。 

重要な洞察は、その乗算を観察することです。`k`ペアごとに互いに素である 4 つの数値によって、一連のランクが生成されます`k`。 これにより、問題は 4 つの互いに素な数のグループを見つけることになります。 最も単純な選択は、シーケンス 1、2、3、5 です。これらの数値はペアごとに互いに素であり、次のようにスケールできます。`k`GCD条件を満たすために。 衝突を避けるために異なるシーケンスを掛け合わせながら、セットごとにこのスケーリングされたシーケンスを繰り返すと、次のようになります。`n`効率的にセットします。 具体的には、各セットに割り当てることができます`k`、`2k`、`3k`、`4k`、次のセットでは 4 ずつ増加します。`(k*4i+1, k*4i+2, k*4i+3, k*4i+5)`。 これにより、すべての数値がセット間で異なることが保証され、ランク条件が尊重されます。

 ## アルゴリズムのチュートリアル

 1. 4 つの整数のセットにランクがあることを観察します。`k`各数値を次の値で割る場合`k`ペアごとに互いに素である 4 つの数値を返します。 したがって、4 つの互いに素な数のセットを生成し、次の値を乗算するだけで済みます。`k`。 
2. 最も単純な小さな互いに素の 4 倍を選択します: 1、2、3、5。これらの数値はペアごとに互いに素です。 乗算`k`1 つの有効なセットが生成されます。 
3. 重複せずに複数のセットを生成するには、4 の倍数を加算して基本 4 倍をシフトします。i 番目のセットの数値は次のとおりです。`(k*(1 + 4*(i-1)), k*(2 + 4*(i-1)), k*(3 + 4*(i-1)), k*(5 + 4*(i-1)))`。 これにより、すべての数値がセット間で区別され、GCD 条件が満たされることが保証されます。 
4. コンピューティング`m`任意のセットで使用される最大の数値として、`k*(4*(n-1) + 5)`。 
5. 出力`m`そしてすべて`n`セット。 

なぜ機能するのか: ペアごとの互いに素な数の 4 倍をスケーリングする`k`すべてのペアの GCD が等しいという特性を保持します。`k`。 各 4 倍数を 4 ずつインクリメントすると、ランク条件を維持しながら、異なるセット内の数値が重複しないことが保証されます。 帰納法により、このメソッドは最大で任意の数のセットを構築できます。`n = 10,000`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

sets = []
for i in range(n):
    a = k * (1 + 4*i)
    b = k * (2 + 4*i)
    c = k * (3 + 4*i)
    d = k * (5 + 4*i)
    sets.append((a, b, c, d))

m = k * (4*(n-1) + 5)
print(m)
for s in sets:
    print(*s)
```コードは最初に読み取られます`n`そして`k`。 それから構築します`n`上の式に従って設定します。 各セットは、小さな互いに素数を乗算します。`k`重複を避けるためにそれらを移動します。 最後に、最大数を計算します。`m`そしてすべてのセットを印刷します。 微妙な部分は、1、2、3、4 ではなく 1、2、3、5 を選択することです。 gcd(2, 4) = 2 であるため、k = 1 の場合、4 は共素性を破ります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    sets = []
    for i in range(n):
        a = k * (1 + 4*i)
        b = k * (2 + 4*i)
        c = k * (3 + 4*i)
        d = k * (5 + 4*i)
        sets.append((a, b, c, d))
    m = k * (4*(n-1) + 5)
    out = [str(m)] + [" ".join(map(str, s)) for s in sets]
    return "\n".join(out)
