 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`そして、異なるペアが何個あるかを数えるように求められます。`(x, y)`そのように存在する`x`の部分文字列です`s`、`y`の続きです`t`、 そして`x`そして`y`文字列として等しいです。 重要な違いは、「区別」がどのように定義されるかにあります。 の 2 つの部分文字列`s`内容が同一であっても、位置が異なる場合は区別されます。 同様に、次の 2 つの部分列は、`t`たとえ同じ文字列を生成したとしても、異なるインデックスから形成されている場合は区別されます。 

長さ`s`そして`t`は 5000 に達する可能性があります。これは、単純なアプローチでは次のすべての部分文字列を生成することを意味します。`s`およびそのすべてのサブシーケンス`t`実行不可能です。 の部分文字列の数`s`おおよそです`|s|*(|s|+1)/2`、および部分列の数`t`は`2^|t|`、それは天文学的な大きさです。 したがって、明示的に列挙せずに、一致するペアを効率的にカウントするアプローチが必要です。 

両方の文字列が繰り返しの文字で構成されている場合、特殊なケースが発生します。 たとえば、次の場合`s = "aa"`そして`t = "aa"`、すべての単一文字の部分文字列と部分シーケンスは互いに結合されます。 別の微妙な問題が発生する場合`s`または`t`単一の文字です。 長いシーケンスを想定したアルゴリズムは、カウントを間違えたり、範囲外のインデックスにアクセスしたりする可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、すべての部分文字列を反復処理します。`x`の`s`それぞれについて、すべてのサブシーケンスを数えてみます。`y`の`t`その一致`x`。 これはすべての可能性を列挙しているため、原理的には正しいですが、`t`は`2^|t|`、これは |t| には大きすぎます。 ≤ 5000。次の部分文字列に限定しても`s`各部分文字列が指数関数的な数の部分列と照合される可能性があるため、複雑さは十分に軽減されません。 

重要な洞察は、この問題が 2 つの文字列に対する動的プログラミングに適合するということです。 のサブシーケンスがいくつあるかを数えることを検討してください。`t`指定された部分文字列と等しい`x`の`s`。 これはまさに古典的な部分列カウント DP 問題です。`dp[i][j]`は部分列の数です`t[0..j]`に等しい`s[0..i]`。 この DP テーブルを取得したら、次のすべての部分文字列を反復処理できます。`s`あらゆるポジションから始めることで効率的に`i`そして右側に拡張して、からの貢献を追加します`dp[i][j]`各ステップで。 

次のように定義することで、再計算を回避するために DP をさらに最適化できます。`dp[i][j]`最初のものと一致する方法の数として`i`の部分文字列の文字`s`位置で終わる`i`最初のものと`j`の登場人物`t`。 トランジションによって文字が一致するかどうかが考慮され、ソリューションを段階的に構築できるようになります。 モジュロ 10^9+7 は、大きなカウントを処理するために適用されます。

 ## アルゴリズムのチュートリアル

 1. 2D DP テーブルを初期化する`dp`サイズの`(len_s + 1) x (len_t + 1)`すべてゼロで。`dp[i][j]`のサブシーケンスの数を保存します`t[0..j-1]`部分文字列と等しい`s[i-1]..s[end]`。 
2. 基本ケースを設定します: の空の部分文字列`s`一致する 1 つの方法に対応するため、`dp[0][j] = 1`みんなのために`j`。 
3. 反復処理`i`1から`len_s`そして`j`1から`len_t`。 それぞれのポジションについて、`s[i-1] == t[j-1]`、前の文字で終わるシーケンスの数を追加します。`dp[i-1][j-1]`に`dp[i][j]`。 
4. 常に引き継ぐ`dp[i][j-1]`～の部分系列を説明するため`t`スキップする`t[j-1]`。 
5. すべてを合計します`dp[i][j]`のすべての部分文字列に対して`s`最終的な答えを計算します。 具体的には、すべての位置で部分文字列を開始します`i`で`s`、DP を増分的に構築し、一致が見つかるたびにコントリビューションを追加します。 
6. 10^9+7 を法とした結果を返します。 

これが機能する理由は、すべてのステップで、`dp[i][j]`部分文字列をすべての方法で正しくカウントします`s[start..i]`の部分列と一致します`t[0..j]`、再計算を避けるために以前の計算を使用します。 不変条件は、有効な部分列のペアが省略されず、個別の部分文字列と部分列のペアがそれぞれ 1 回だけカウントされるということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

s = input().strip()
t = input().strip()

len_s = len(s)
len_t = len(t)

dp = [0] * (len_t + 1)
result = 0

for i in range(len_s):
    new_dp = [0] * (len_t + 1)
    for j in range(len_t):
        if s[i] == t[j]:
            new_dp[j + 1] = (dp[j] + 1) % MOD
        new_dp[j + 1] = (new_dp[j + 1] + new_dp[j]) % MOD
    dp = new_dp
    result = (result + sum(dp[1:])) % MOD

print(result)
```このソリューションは、スペースを最適化するために 1D DP 配列を初期化します。 の各キャラクターごとに、`s`の文字との一致を考慮して新しい DP 行を計算します。`t`。 の`+1`新しい部分文字列一致の開始を考慮し、累積合計は前の部分列を引き継ぎます。 総括`dp`各文字を処理した後、`s`すべての有効なペアを累積します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 10**9 + 7
    s = input().strip()
    t = input().strip()
    len_s = len(s)
    len_t = len(t)
    dp = [0] * (len_t + 1)
    result = 0
    for i in range(len_s):
        new_dp = [0] * (len_t + 1)
        for j in range(len_t):
            if s[i] == t[j]:
                new_dp[j + 1] = (dp[j] + 1) % MOD
            new_dp[j + 1] = (new_dp[j + 1] + new_dp[j]) % MOD
        dp = new_dp
        result = (result + sum(dp[1:])) % MOD
    return str(result)

assert run("aa\naa\n") == "5", "sample 1"

assert run("ab\nabc\n") == "4", "different letters"
assert run("abcd\ndcba\n") == "4", "reversed strings"
