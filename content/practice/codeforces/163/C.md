 ## 解決策
 ## 問題の理解

 アントンが移動するベルトコンベアからチョコレートを拾う確率を計算するように求められました。 ベルトはまっすぐに見える部分の長さがあります`l`床の下でループバックし、ベルトの全長になります。`2*l`。 ベルトは一定の速度で動きます`v1`アントンはその上を猛スピードで走ります`v2`したがって、床に対する彼の絶対速度は次のようになります。`v1 + v2`。 チョコレートはベルトに沿って特定の位置に配置されています。`0`に`2*l`。 アントンが走り始めると、ベルトは任意の回転をする可能性があります。つまり、アントンに対する各チョコレートの位置は一様にランダムになります。 

出力には、それぞれに必要な`i`から`0`に`n`、アントンが正確に収集する確率`i`チョコレート。 アントンが走り始めたときの位置に応じて、ベルトの上部にある各チョコレートに手が届く可能性があります。 ベルトの下半分のチョコレートは、アントンの走行内で上に回転しない限り到達できません。これは、上半分の長さと、ベルトに対するアントンの速度によってのみ決まります。 

制約を考慮すると、`n`最大 100,000 まで可能で、`l`、`v1`、 そして`v2`10^9 に達する可能性があります。 これにより、アントンの動きをシミュレートしたり、可能なすべてのベルト回転を微増分で反復したりするアプローチは除外されます。 線形または線形算術による解が必要です。`n`。 

明らかではないエッジケースには、所定の位置にチョコレートが含まれます`0`または正確に`l`。 たとえば、チョコレートが次の場所にある場合、`0`, アントンはすぐに始めれば必ず拾ってくれます。 チョコレートがあれば`l`、アントンの開始が遅すぎると到達できなくなります。 チョコレートが上半分にあるか下半分にあるかを無視する単純な解決策では、不正確な確率が生成されます。 

## アプローチ

 強引なアプローチでは、ベルトの可能な開始位置をそれぞれ考慮し、アントンのランニングをシミュレートし、アントンが拾ったチョコレートの数を数えます。 これは正しいですが、非効率的です。 のために`n = 10^5`連続的なベルト位置では、動作回数が管理できなくなります。`O(n * l)`離散化された場合のステップ。 

重要な洞察は、アントンの相対速度が上部を覆う一定の時間を決定し、ベルトの初期回転が一様にランダムであるため、各チョコレートを選択できる確率は、それが長さのセグメント内にあるかどうかのみに依存するということです。`v2*l / (v1 + v2)`上半分に。 チョコレートを分類し、長さのスライディング ウィンドウを適用することにより、`v2*l / (v1 + v2)`効率的に確率を計算できます。 これにより、ソートされた配列に沿って移動するウィンドウ内のチョコレートを数えるという問題が軽減されます。`O(n)`並べ替え後。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*l) | O(n) | 遅すぎる |
 | 最適 (2 つのポインタ) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値の読み取り: チョコレートの数`n`、トップの長さ`l`、ベルト速度`v1`、アントンのスピード`v2`、および位置`a`チョコレートの。 
2. すべてのチョコレートを上半分にマッピングします: チョコレートが下半分にある場合 (`a_i >= l`)、その位置を剰余として減らします。`l`回転中の上部の外観を表現します。 これにより、すべてのチョコレートが均一に処理されます。 
3. マッピングされたチョコレートの位置を並べ替えて、スライディング ウィンドウの計算を可能にします。 
4. 有効到達距離を計算する`d = l * v2 / (v1 + v2)`。 これは、アントンがコンベヤーの上にあるときにベルトに対して移動する距離です。 
5. 2 ポインタ ウィンドウを初期化します。左ポインタは最初のチョコレートに位置し、左と右のチョコレート間の距離が以下である限り右ポインタは拡大します。`d`。 
6. 左ポインタごとに、ウィンドウ内のチョコレートの数を数え、対応する確率バケットをその分数だけ増分します。`window_length / l`。 
7. 左ポインタを右に移動し、それに応じて右ポインタを調整します。 これにより、冗長な計算を行わずに、すべてのウィンドウが効率的にカウントされます。 
8. 上部の長さの合計で確率を正規化します。`l`それらの合計が 1 になるようにします。 

機能する理由: スライディング ウィンドウにより、到達可能な長さのすべての連続セグメントが 1 回だけカウントされ、並べ替えによりウィンドウがすべてのチョコレートを順番にカバーすることが保証されます。 下半分のチョコレートを上半分の位置にマッピングすることで、ベルトのすべての回転を正確にシミュレートします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, l, v1, v2 = map(int, input().split())
a = list(map(int, input().split()))

top_chocs = []
for x in a:
    if x < l:
        top_chocs.append(x)
    else:
        top_chocs.append(x - l)

top_chocs.sort()
probabilities = [0.0] * (n + 1)
d = l * v2 / (v1 + v2)

j = 0
for i in range(n):
    while j < n and top_chocs[j] - top_chocs[i] < d:
        j += 1
    count = j - i
    probabilities[count] += (top_chocs[i+1] - top_chocs[i]) / l if i+1 < n else (l - top_chocs[i]) / l

probabilities[0] = 1.0 - sum(probabilities[1:])
for p in probabilities:
    print(f"{p:.20f}")
```このソリューションは、すべてのチョコレートの位置をコンベアの上半分にマッピングします。 ソートにより、連続して到達可能なチョコレートを効率的に数えることができます。 2 ポインタのアプローチでは、到達可能なチョコレート上にスライディング ウィンドウが維持されます。 境界条件は、最後のチョコレート セグメントをチェックすることで慎重に処理されます。

 ## 特殊なケース

 位置 0、d = l/2 のチョコレートの場合、ベルトの回転に応じて部分的に到達可能です。 スライディング ウィンドウでは最初のウィンドウにそれが含まれ、セグメントの長さに比例して確率が追加されます。 すべてのチョコレートが下半分にある場合、それらを上にマッピングし直すことで、回転中にチョコレートが正しくカウントされるようになります。 チョコレートがまさに手の届く端にある場合は、不等式が使用されるため処理されます。`< d`そしてそうではありません`<= d`。
