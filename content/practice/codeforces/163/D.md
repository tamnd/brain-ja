 ## 解決策
 ## 問題の理解

 辺の長さが整数の長方形のボックスを構築する必要があります`a`、`b`、 そして`c`。 その体積は指定された数値と等しくなければなりません`V`そして、そのようなすべての整数のトリプルの中で、最小の表面積を持つものが必要です。 

箱の表面積は、$S = 2(ab + bc + ca)$ボリューム制約がある間、$abc = V$入力は与えません`V`直接。 代わりに、次の素因数分解が行われます。`V`。 たとえば、入力に次のものが含まれている場合、`(2,3)`そして`(5,1)`、 それから$V = 2^3 \cdot 5 = 40$タスクは、1 つの最適なトリプルとともに可能な最小の表面積を出力することです。`(a,b,c)`。 

可能な最大のボリュームは、`10^18`したがって、すべての約数を単純に反復処理することはすでに繊細です。 近い数字`10^18`まだそれ以上のものを持っていることができます`10^5`特別に構築されたケース内の約数。 すべてのトリプルを試す`(a,b,c)`と`abc=V`これは、最大 500 のテスト ケースで 5 秒に収まる範囲をはるかに超えています。 

式の構造が重要です。 表現`ab + bc + ca`寸法のバランスがとれると小さくなります。 実数を超えると、最小値は立方体で発生します。 整数と割り算の制約がある場合、最適解では 3 つの値を可能な限り近づける必要があります。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

もし`V`が素数の場合、可能なボックスは 1 つだけです。 

入力：```
1
1
17 1
```唯一有効なトリプルは、`(1,1,17)`、したがって、答えは次のようになります。```
70 1 1 17
```すべての次元に自明ではない約数があると仮定する不注意な検索は、ここでは失敗します。 

完璧な立方体も重要なケースです。 

入力：```
1
1
2 6
```これはつまり`V = 64`。 最適な箱は、`(4,4,4)`表面積あり`96`。 厳密に増加する約数のみを検索するアルゴリズムでは、等しい次元を見逃す可能性があります。 

単一素数の累乗が大きいと、オーバーフローの間違いも明らかになります。 例えば：```
1
1
2 60
```ここ`V = 2^60`よりも大きい`10^18`。 中間製品のような`ab`そして`2(ab+bc+ca)`64 ビット範囲内に収まる必要があります。 Python はこれを自然に処理しますが、固定幅言語では注意が必要です。 

## アプローチ

 最も直接的なアプローチは、次のすべての約数を生成することです。`V`次に、すべてのペアを試してください`(a,b)`そのような`a*b`分割する`V`、計算する`c = V/(ab)`、表面積を評価します。 

これは、すべての有効な冷蔵庫が 1 つの約数の 3 倍に正確に対応するため機能します。 すべての約数のペアを列挙すると、最終的には最適なものが検討されます。 

問題は組み合わせの数です。 させて`d(V)`約数の数になります。 たとえ除数の生成自体は管理可能であっても、すべてのペアを大まかにチェックするのはコストがかかります`O(d(V)^2)`。 その周り`10^5`約数、これは約になります`10^10`組み合わせ、完全に不可能です。 

重要な点は、寸法をオーダーできることです。 

常に維持しているとします$a \le b \le c$それから：```
a^3 ≤ abc = V
```それで：```
a ≤ cbrt(V)
```固定後も同様に`a`:```
b^2 ≤ bc = V/a
```それで：```
b ≤ sqrt(V/a)
```これにより、検索スペースが大幅に縮小されます。 

すべての約数の 3 倍を反復処理する代わりに、約数のみを列挙します。`a`の立方根まで`V`。 そういったものごとに`a`、約数を列挙します`b`の`V/a`平方根まで。 それから`c`強制されます。 

残りの課題は除数の生成です。 入力はすでに素因数分解を提供しているため、因数分解の作業を行わずに再帰的に約数を生成できます。 

チェックされた状態の総数は、完全な除数立方体よりもはるかに小さくなります。 実際には、これは制限内に簡単に収まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 除数ペアに対するブルート フォース | O(d(V)^2) | O(d(V)) | 遅すぎる |
 | 順序付き除数の列挙 | O(d(V) · V^(1/3) 実際にはもっと小さくなります) | O(d(V)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. の素因数分解を再構築します。`V`入力から。 

実際に計算する必要はありません`V`繰り返し乗算することによって。 因数分解は便利な構造です。 
2. すべての約数を生成します。`V`再帰的に。 

素数ごとに`p^e`のコピー数を選択してください`p`除数に属し、から`0`に`e`。 
3. 約数を並べ替えます。 

これにより、約数が許容範囲を超えた場合に早期に停止できます。 
4. すべての約数を反復処理します。`a`。 

以下を満たす約数のみを考慮します。```
a^3 ≤ V
```なぜなら、順序付けられたトリプルでは`(a,b,c)`、最小の次元は立方根を超えることはできません。 
5. 有効なそれぞれについて`a`、次を計算します。```
rem = V / a
```ここで 2 つの整数が必要になります`b`そして`c`次のような:```
bc = rem
```6. 除数を反復処理する`b`の`rem`。 

当社は以下を実施するため、```
b ≤ c
```必要なのは以下だけです:```
b^2 ≤ rem
```7. いつでも`b`分割する`rem`、次を計算します。```
c = rem / b
```8. 表面積を計算します。```
S = 2(ab + bc + ca)
```9. 最小表面積を追跡し、対応するトリプルを記憶します。 
10. 最適な表面積と寸法を出力します。 

### なぜ効果があるのか

 すべての有効な冷蔵庫は、ある整数のトリプルに対応します。`(a,b,c)`と`abc=V`。 命令を強制することで`a≤b≤c`、順序のない解はすべて 1 回だけ表示されます。 

不平等`a^3≤V`そして`b^2≤V/a`これらは順序付けの結果であり、ヒューリスティックな枝刈りではありません。 最適なソリューションはこれらに違反することはできません。 このアルゴリズムは、実行可能な順序付きトリプルをすべて 1 回正確に列挙し、その正確な表面積を計算し、最小値を維持します。 候補がスキップされないため、最終的な答えは最適になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def gen_divisors(factors, idx, cur, divisors):
    if idx == len(factors):
        divisors.append(cur)
        return

    p, e = factors[idx]
    val = 1

    for _ in range(e + 1):
        gen_divisors(factors, idx + 1, cur * val, divisors)
        val *= p

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        k = int(input())

        factors = []
        V = 1

        for _ in range(k):
            p, e = map(int, input().split())
            factors.append((p, e))
            V *= pow(p, e)

        divisors = []
        gen_divisors(factors, 0, 1, divisors)
        divisors.sort()

        best_s = None
        best_triplet = None

        divisor_set = set(divisors)

        for a in divisors:
            if a * a * a > V:
                break

            rem = V // a

            for b in divisors:
                if b * b > rem:
                    break

                if rem % b != 0:
                    continue

                c = rem // b

                if b > c:
                    continue

                s = 2 * (a * b + b * c + c * a)

                if best_s is None or s < best_s:
                    best_s = s
                    best_triplet = (a, b, c)

        a, b, c = best_triplet
        out.append(f"{best_s} {a} {b} {c}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```再帰的除数ジェネレータは、素因数分解から直接すべての除数を構築します。 これは、次の数までの試行除算よりもはるかに高速で信頼性が高くなります。`10^18`。 

外側のループは候補の最小次元を反復します。`a`。 条件`a * a * a > V`は、前に説明した順序付きトリプル枝刈りです。 約数はソートされているため、境界に失敗した場合はすぐに停止できます。 

内側のループは以下を検索します`b`。 再び注文制限を使用します`b ≤ c`となり、`b² ≤ rem`。 

微妙な点の 1 つは、すべての約数を再度反復処理することです。`b`の約数ではありません`rem`具体的には。 割り算チェック:```
if rem % b != 0:
    continue
```無効な候補をフィルタリングします。 

もう 1 つの微妙な点は、浮動小数点の立方根と平方根を避けることです。 浮動小数点の丸めの近く`10^18`危険です。 次のような整数比較:```
a * a * a > V
```Python では正確かつ安全です。

 ## 特殊なケース

 プライム ボリュームは、可能なボックスを 1 つだけ強制します。
