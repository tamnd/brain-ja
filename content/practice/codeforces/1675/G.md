 ## 解決策
 ## 問題の理解

 配列は、皿の列に配置されたパンケーキのスタックを表します。 1 つのパンケーキを繰り返し選択し、隣接する皿に 1 ステップ移動することができます。移動ごとに 1 のコストを支払います。 十分な操作を行った後、結果として得られる構成が左から右に増加しないようにします。つまり、各皿には少なくともそのすぐ右の皿と同じ数のパンケーキが含まれることになります。 

パンケーキの総数は固定されていますが、移動ごとに 1 つのパンケーキが隣接する位置に移動するだけである限り、その配分は任意に変更できます。 目標は、特定のターゲット配置に到達することではなく、隣接する移動の総数を最小限に抑えながら単調性条件を満たす任意の配置に到達することです。 

制約は十分に小さいため、二次または三次動的計画法ソリューションが受け入れられます。 n と m が最大 250 の場合、O(n・m²) または O(n・m³) のアプローチは 2 秒の制限内で実現可能ですが、分布の状態空間が指数関数的に増大するため、動きを直接シミュレートしたり、すべての構成を列挙しようとすることは不可能です。 

素朴な直感は、違反が現れるたびに貪欲にパンケーキを左から右に押し出すことを示唆するかもしれません。 局所的な修正により将来のコストが増加する可能性があるため、これは失敗します。 たとえば、[0, 0, 10, 0, 0] のような構成は、貪欲に平滑化するのが簡単に見えるかもしれませんが、移動するたびに距離が蓄積されるため、パンケーキをどこに広げるかに関する早期の決定は、後の移動コストに全体的に影響します。 

隣接する値を貪欲に等化するときに、別の微妙な失敗ケースが発生します。 [3, 0, 3] を取得した場合、貪欲な修正によりパンケーキが 3 番目の皿から 2 番目の皿にすぐに移動する可能性がありますが、後の構造によっては、代わりに左側から再分配する方が良い場合があります。 重要な問題は、コストが最終的なカウントだけではなく、移動距離によって決まることです。 

これは、最終配列の形状制約の下での全体的なトランスポート最適化問題です。 

## アプローチ

 単調性制約を無視すると、問題はライン上の古典的な最小コスト フローになります。つまり、供給 a[i] を需要 b[i] に一致させ、コストはパンケーキの総移動距離になります。 これは、エッジを越えてパンケーキを移動するたびにプレフィックスの合計が変化するため、絶対的なプレフィックスの不均衡を合計することと同等です。 

この難しさは完全に、最終的な配列が非増加でなければならないという要件から生じています。 この制約はすべての位置を結合します。b[i] を選択すると、以降のすべての b[i+1]、b[i+2] などが制限されます。 

ブルートフォース手法では、増加しないシーケンス b を合計 m で列挙し、a から b への輸送コストを計算し、最小値を取得します。 このようなシーケンスの数は、長さが制限されたパーティションの数であり、m = 250 の場合でも膨大な数になるため、これは実行不可能になります。 

重要な観察は、b はグローバルに増加しない必要があるが、その構築は逐次的であるということです。 b[i] を修正するときは、それが b[i−1] を超えないことを確認するだけで済みます。 これにより、問題は左から右への DP に変わり、州は 2 つの情報、つまり現在の位置に割り当てたパンケーキの数と、これまでに生じた需要と供給の間の不均衡を記憶する必要があります。 

不均衡は、プレフィックス合計の差として追跡できます。 S[i] が i までの元の配列とターゲット配列間の累積差である場合、不均衡の各単位は、それが持続するステップごとにコスト 1 を寄与します。 これにより、移動コストがプレフィックスの絶対合計の合計に変換されます。 

したがって、動きをシミュレートする代わりに、有効なターゲット シーケンスを選択し、その構築中にプレフィックスがどの程度「不安定」になるかを測定します。 位置、最後に選択された高さ、電流の不均衡に関する動的プログラミングにより、実現可能性とコストの両方が得られます。

 ## アルゴリズムのチュートリアル

 ターゲット配列を左から右に構築する DP を定義します。 

1. 最終的な配列をシーケンス b として解釈します。ここで、b[i] は料理 i に割り当てられたパンケーキの数です。 制約は b[i] ≥ b[i+1] であるため、右に移動してもシーケンスが増加することはありません。 
2. プレフィックスの不均衡 S を定義します。これは、割り当てたものと比較して「動いている」パンケーキがどれだけ多いかを追跡します。 形式的には、i 個の位置を処理した後、S は合計 a[1..i] から合計 b[1..i] を引いたものと等しくなります。 この不均衡がコストを決定します。これは、不均衡の各単位がステップごとに 1 単位のコストに寄与し、したがって |S| に寄与するためです。 各プレフィックスの答えに。 
3. DP 状態 dp[i][x][s] を定義します。これは、最初の i 皿の処理後、最後に選択された値が x で、現在の不均衡が s であることを意味します。 シーケンスが増加しないようにする必要があるため、最後の値が必要です。そのため、次の値は最大でも x に制限されます。 
4. 各位置 i で、0 から前の値 x まで、b[i] の可能なすべての選択を試みます。 これにより、単調性が確実に維持されます。 
5. b[i] の選択ごとに、不均衡を s + a[i] − b[i] として更新します。 新しい不均衡の絶対値によってコストが増加します。これは、それがこのプレフィックスで累積されたコストであるためです。 
6. すべての位置を処理した後、すべての可能な最後の値 x の最小値 dp[n][x][0] を取得します。これは、総パンケーキ数を維持するには、最終的な不均衡が 0 でなければならないためです。 

### なぜ効果があるのか

 重要な不変条件は、i 位置を処理した後、すべての有効な動きのシーケンスが 1 つの状態 (i、最後に選択された値、プレフィックスの不均衡) に正確に対応するということです。 不均衡は、将来の決定とは無関係に、その時点までのすべての移動コストを完全に把握しますが、最後に選択された値は、今後の実現可能性に影響を与える唯一の制約をエンコードします。 有効な非増加シーケンスは、この制約を超えて先を読むことなく段階的に構築できるため、DP は重複や省略なしに実現可能な空間全体を探索します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = list(map(int, input().split()))

    OFFSET = m
    INF = 10**18

    dp = [[[INF] * (2 * m + 1) for _ in range(m + 1)] for _ in range(2)]
    
    for v in range(m + 1):
        dp[0][v][OFFSET] = 0

    cur, nxt = 0, 1

    for i in range(n):
        for v in range(m + 1):
            for s in range(2 * m + 1):
                dp[nxt][v][s] = INF

        for last in range(m + 1):
            for s in range(2 * m + 1):
                if dp[cur][last][s] == INF:
                    continue
                cur_cost = dp[cur][last][s]

                for b in range(last + 1):
                    ns = s + a[i] - b
                    if 0 <= ns <= 2 * m:
                        val = cur_cost + abs(ns - OFFSET)
                        if val < dp[nxt][b][ns]:
                            dp[nxt][b][ns] = val

        cur, nxt = nxt, cur

    ans = INF
    for last in range(m + 1):
        ans = min(ans, min(dp[cur][last][OFFSET]))

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、メモリの安定性を維持するために、ローリング DP を位置に使用します。 最後に選択された高さは外側の状態で反復され、不均衡はオフセットによってシフトされるため、配列に格納できます。 すべての遷移では、次の高さを最大でも前の高さに制限することにより、増加しない制約が適用されます。 

コストの更新では、プレフィックスの不均衡の絶対値が使用されます。これは、そのプレフィックス境界で実際に「場違い」になっているパンケーキの数に相当します。

 ## 特殊なケース

 すべてのパンケーキが 1 つの位置に集中している場合は、例外的なケースが発生します。 DP は、一時的に大きな不均衡を許容しますが、最後には強制的にゼロに戻すことでこれに対処します。 累積されたコストは、パンケーキが移動しなければならない合計距離に等しくなります。これは、まさにプレフィックスの絶対合計で得られるものです。 

もう 1 つの微妙なケースは、最適解を得るには、局所的な不均衡を後で減少させる前に、一時的に増加させる必要がある場合です。 DP はコストを介する場合を除いて中間の不均衡を制限しないため、当然そのような動作が許容され、その長期的なコストへの影響が正しく評価されます。 

最後のケースは、最適な b シーケンスに同じ値が長く続く場合です。 DP はこれを正しく処理します。これは、遷移によって b[i] が b[i−1] に等しくなるためです。これにより、不必要な再配分を強制することなく平坦な領域が作成されます。
