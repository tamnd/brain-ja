 ## 解決策
 ## 問題の理解

 長さが増加するシーケンスを構築する必要があります$n$, where every value lies between 1 and 100. The sequence must satisfy a special condition involving remainders.

 ポジションごとに$i$、値を考慮してください$a_i \bmod i$。 要件は、これらの剰余がすべて異なることです。 つまり、計算してみると、$$a_1 \bmod 1,\ a_2 \bmod 2,\ a_3 \bmod 3,\ \ldots,\ a_n \bmod n,$$その場合、それらのうちの 2 つが等しくなることはありません。 

入力には複数のテスト ケースが含まれています。 各テスト ケースに対して、次のことだけが与えられます。$n$有効な増加シーケンスを出力する必要があります。 

制約は非常に小さいです。 可能な最大値は次のとおりです。$n=50$このステートメントでは、解決策が常に存在することが保証されているため、実際のタスクは、パターンを検索するのではなく、単純な構築的なパターンを発見することです。 

よくある間違いは、残りではなく値そのものに注目してしまうことです。 たとえば、増加するシーケンス```
1 2 3
```自然に見えますが、$$1 \bmod 1 = 0,\quad 2 \bmod 2 = 0,\quad 3 \bmod 3 = 0$$したがって、残りはすべて同一となり、条件に違反します。 

もう 1 つの簡単な罠は、個別の剰余を構築しているにもかかわらず、シーケンスが厳密に増加している必要があることを忘れていることです。 たとえば、$n=4$、```
4 3 2 1
```異なる剰余が生成されます$$0,1,2,1$$これはすでに剰余条件を満たしておらず、増加もしていません。 

この問題の興味深い部分は、両方のプロパティを同時に自動的に保証するパターンを見つけることです。 

## アプローチ

 強引な考え方では、増加するシーケンスを生成し、残りがすべて異なるかどうかをテストします。 候補シーケンスをチェックするのは簡単です: 計算します$a_i \bmod i$すべてのインデックスについて、一意性を検証します。 

難点は探索スペースです。 値が 100 に制限されている場合でも、長さ 50 の増加シーケンスの数は膨大になります。 徹底的な検索はまったく非現実的です。 

重要な観察は、可能な剰余の範囲を調べることから得られます。 

インデックス用$i$、残り$a_i \bmod i$に属さなければなりません$$0,1,\ldots,i-1.$$それを手配できれば$$a_i \bmod i = i-1,$$その場合、すべてのインデックスは異なる剰余を取得します。$$0,1,2,\ldots,n-1.$$タスクははるかに簡単になりました。 必要なのは増加するシーケンスだけです。$i$-番目の要素は余りを残します$i-1$で割ると$i$。 

非常に便利な選択肢は、$$a_i = 2i-1.$$残りを確認してみましょう:$$(2i-1)\bmod i = i-1.$$確かに、$$2i-1 = i + (i-1),$$それで割る$i$残りを残す$i-1$。 

シーケンス$$1,3,5,7,\ldots$$は厳密に増加しており、残りはすべて異なります。$n \le 50$最大の値は$$2\cdot 50 - 1 = 99,$$これは 100 の制限を満たします。

 ## アルゴリズムのチュートリアル

 1.読む$n$。 
2. シーケンスを構築する$$a_i = 2i-1$$あらゆる人にとって$i$1から$n$。 
3. 生成された値を出力します。 

この選択が機能する理由:$$a_i = 2i-1 = i + (i-1),$$それで$$a_i \bmod i = i-1.$$残りは$$0,1,2,\ldots,n-1,$$これらはすべて異なるものです。 

各項が前の項よりちょうど 2 大きいため、シーケンスも厳密に増加しています。 

### なぜ効果があるのか

 不変条件は、位置の剰余です。$i$正確に等しい$i-1$。 

インデックスが異なれば値も異なるため、$i-1$、2 つのポジションが同じ余りを共有することはできません。 したがって、必要なペアごとの区別条件が自動的に満たされます。 

同時に、$$a_{i+1}-a_i=(2(i+1)-1)-(2i-1)=2>0,$$したがって、シーケンスは厳密に増加しています。 最後に、最大の要素は 99 になります。$n=50$、許容範囲内に残ります。 問題のすべての要件が同時に満たされます。 

## Python ソリューション```python
import sys

for _ in range(t):
    n = int(input())
    ans = [str(2 * i - 1) for i in range(1, n + 1)]
    print(" ".join(ans))

テストケースごとに奇数を生成します$$1,3,5,\ldots,2n-1.$$リスト内包表記を使用すると、コードが簡潔に保たれ、直線的な時間で実行されます。 

微妙な点は、上限を確認することです。 以来$n\le 50$、生成される最大値は$99$したがって、追加のチェックは必要ありません。 

数学的証明のインデックスは 1 から始まり、コードは反復することでそれを反映します。`i`1から`n`。 これにより、数式を関連付ける際の 1 つ違いの間違いを回避できます。$a_i=2i-1$実装まで。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        out.append(" ".join(str(2 * i - 1) for i in range(1, n + 1)))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

### 最大サイズ

 入力:```

```シーケンスは次のようになります$$1,3,5,\ldots,99.$$最大値はちょうど 99 で、制限の 100 を下回っています。残りは次のとおりです。$$0,1,2,\ldots,49.$$どれも個性的です。 

### ゼロ剰余の繰り返しを避ける

 素朴な考えは、使用することです```
1 2 3 4 5
```このシーケンスの場合、$$a_i \bmod i = 0$$どのポジションでも、すぐに失敗します。 

私たちの建設が生み出すのは、```
1 3 5 7 9
```余りあり$$0,1,2,3,4,$$したがって、衝突は完全に消えます。 

### 数式内の 1 つずつの間違い

 誰かが間違って選択したとします$$a_i = 2i.$$のために$n=3$、余りは次のようになります$$2\bmod1=0,\quad 4\bmod2=0,\quad 6\bmod3=0.$$残りはすべて衝突します。 

使用する$$a_i=2i-1$$すべての剰余を正確にシフトします$i-1$、必要な個別のシーケンスを生成します。
