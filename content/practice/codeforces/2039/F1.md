 ## 解決策
 ## 問題の理解

 1 から 1 までの要素を持つ配列を数えるように求められます。$m$非常に特殊な特性を満たすもの: 計算すると$f(k)$あらゆる長さに対して$k$部分配列の値、2 つの値はありません$f(i)$そして$f(j)$等しいです。 ここ、$f(k)$長さのすべての部分配列の最大値の最大公約数です$k$。 たとえば、配列を考えてみましょう。$[2, 1, 4]$。 長さ 1 の部分配列の最大数は次のとおりです。$[2,1,4]$GCD 1 では、長さ 2 に対して最大値が得られます。$[2,4]$GCD 2 の場合、長さ 3 の最大値は GCD 4 の 4 です。1、2、4 はすべて異なるため、配列は「良好」です。 

入力により得られるのは、$t$それぞれ単一の整数を含むテスト ケース$m$。 1 から 1 までの要素を持つ空ではない「良好な」配列の数を出力します。$m$、モジュロ 998244353。それぞれ$m$まで行くことができます$10^5$、すべてのテスト ケースの合計は次のように制限されます。$10^5$したがって、ソリューションは各テスト ケースを効率的に、理想的には線形または線形に近い時間で処理する必要があります。$m$。 

明白ではないエッジケースには、非常に小さなケースが含まれます$m$1 か 2 のように。$m = 1$、唯一の配列は$[1]$、これは些細なことです。 のために$m = 2$、 両方$[1,2]$そして$[2,1]$単一要素配列と同様に優れています$[1]$そして$[2]$。 配列の単純な総当たり列挙は、組み合わせ的に爆発してしまいます。 平$m = 5$生み出すだろう$5^n$長さの配列$n$それぞれに$n \le m$、合理的な期限をすぐに超えます。 

## アプローチ

 ブルートフォースアプローチは、各配列のすべての配列を列挙することです。$m$、計算する$f(k)$それぞれの長さについて、区別性をチェックします。 これは原理的には正しいですが、実行不可能です。$m = 10$、 がある$10^1 + 10^2 + \dots + 10^{10}$配列。 コンピューティング$f(k)$各配列に対して、すべてのサブ配列の反復処理が含まれます。$O(n^2)$アレイごとに、許容限界をはるかに超える時間の複雑さが生じます。 

重要な洞察は、次のように現れる可能性のある値を考慮することです。$f(k)$。 指定された長さの配列の場合$n$、シーケンス$f(1), f(2), ..., f(n)$最大値の GCD は特定の配列構成の下では単調に動作するため、要素を賢く配置すると厳密に増加します。 すべての適切な配列は、ある整数から始まる一連の約数としてエンコードできます。$m$、次の各要素は、特定の降順で前の要素で割り切れます。 これにより、問題は、各数値が次の数値を除算する一連の整数をカウントするという問題に縮小されます。この問題は、動的プログラミングと除数プロパティを使用した包含/除外によって対処可能です。 

具体的には、$dp[g]$value で終わるシーケンスの数として$g$前のすべての要素が次の倍数になるようにする$g$。 最大から最小まで繰り返すことによって$g$、簡単な式を使用してカウントを伝播できます。$dp[g] = (m // g)^1 - sum(dp[multiples\ of\ g\ larger\ than\ g])$。 これにより、「良好な」特性に違反する配列を過剰にカウントすることなく、シーケンスがカウントされるようになります。

 ## アルゴリズムのチュートリアル

 1. 1 から 1 までのすべての約数を事前計算します。$m$。 それぞれの番号について$i$、の倍数であるすべての数値を格納します。$i$まで$m$。 これにより、除数チェーンに沿ったカウントの迅速な伝播が可能になります。 
2. 配列を初期化する$dp$長さの$m+1$ゼロに。 それぞれ$dp[g]$value で終わるシーケンスの数を保存します$g$それは「良い」配列にまで拡張される可能性があります。 
3. 反復する$g$から$m$1 まで。それぞれについて$g$、の倍数を使用した可能な最大配列長$g$は$(m // g)$。 から始める$count = pow(2, m // g, MOD) - 1$で割り切れるポジションの空でないサブセットをすべて数えます。$g$。 
4. すでにカウントされているシーケンスの寄与を減算します。$g$より大きい$g$二重カウントを避けるため。 正式には、$dp[g] = count - sum(dp[k * g])$のために$k > 1$そして$k * g \le m$。 
5. 最終的な答えは次の合計です。$dp[1..m]$これは、明示的に列挙せずに「良好な配列」条件を満たすすべてのシーケンスをカウントします。 

機能する理由: シーケンスはトップダウンで構築され、すべての長さが DP 伝播における厳密に減少する約数に対応するため、サブ配列最大値の GCD が明確になるようにします。 減算ステップではオーバーカウントがないことが保証され、一意性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve_case(m):
    dp = [0] * (m + 2)
    for g in range(m, 0, -1):
        total = pow(2, m // g, MOD) - 1
        k = 2
        while k * g <= m:
            total -= dp[k * g]
            if total < 0:
                total += MOD
            k += 1
        dp[g] = total
    return dp[1]

t = int(input())
for _ in range(t):
    m = int(input())
    print(solve_case(m))
```この解決策は高速累乗を使用します$pow(2, m//g, MOD)$空ではないサブセットを効率的にカウントします。 からの反復$m$down は、より高い倍数がより低い除数よりも前に処理されるようにするため、オーバーカウントされたシーケンスの減算が有効になります。 負の値を避けるためにモジュロ演算を維持するように注意が必要です。
