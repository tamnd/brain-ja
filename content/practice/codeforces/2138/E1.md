 ## アプローチ

 行列式は、ライプニッツの公式を使用して書くことができます。$$\det(M)=\sum_{\sigma} \operatorname{sgn}(\sigma)\prod_i M_{i,\sigma(i)}.$$ブルートフォースの観点は、各順列をすべての行から 1 つの出力エッジとすべての列への 1 つの入力エッジを選択するものと考えることです。 グラフ言語では、これはサイクル カバーに相当します。 行列式は、すべてのサイクル カバーの符号付き合計です。 

多くの異なるカバーが相互作用して互いに打ち消し合う可能性があるため、サイクル カバーを直接設計しようとすることは困難です。 候補行列の行列式を検証する場合でも、3 次時間消去が必要であり、行列の探索空間は天文学的なものになります。 

重要な観察は、行列が重み付き有向グラフの隣接行列として見なせるということです。 その後、行列式項は加重サイクル カバーになります。 DAG に近いグラフを作成すると、サイクル カバーが非常にシンプルになります。 

一意のソースを持つ DAG を検討してください$s$そして沈む$t$。 ウェイトの自己ループを追加する$1$あらゆる頂点に。 最後にエッジを 1 つ追加します。$t$に戻る$s$。 

現在、すべてのサイクル カバーには 2 つの可能性しかありません。 

最初の可能性は、すべての自己ループを取得して、1 つの簡単なカバーを生成することです。 

2 番目の可能性は、次のパスを選択することです。$s$に$t$、エッジと一緒に$t \to s$。 残りの頂点はすべて自己ループを使用します。 このようなカバーは全単射的に対応します。$s$-に-$t$パス。 

エッジに適切な標識があるため、すべてのパスが正確に貢献します$+1$決定要因に。 行列式は正確に次の数になります。$s$-に-$t$DAG 内のパス。 

問題は、パス数が以下に等しいスパース DAG を構築することに帰着します。$x$。

操作$m \rightarrow 2m$は 2 つの新しい頂点を使用して実装されます。$$p\to a,\quad p\to b,\quad a\to b.$$新しい終端頂点は次のようになります。$b$。 到達する方法は正確に 2 つあります$b$から$p$, そのため、パス数は 2 倍になります。

### なぜ効果があるのか

 すべてのサイクル カバーでは、自己ループのみを使用するか、シンクからソースに戻る固有のエッジを使用する必要があります。 リターン エッジが選択されると、カバーの残りの重要な部分は、DAG 内のソースからシンクへの 1 つのパスになります。 これにより、サイクル カバーと DAG パスの間に 1 対 1 の対応関係が確立されます。 重みを割り当てることで$-1$すべての DAG エッジに対して、行列式によって寄与される符号が大きなサイクルのパリティ効果を打ち消し、すべての有効なパスが寄与するようになります。$+1$。 行列式は正確にソースからシンクへのパスの数になります。 

バイナリ ガジェットは、現在のエンドポイントに必要な数のソースからエンドポイントへのパスが正確に存在するという不変条件を維持します。 ビットを処理すると、次のバイナリ値が再構築されます。$x$したがって、最終的なパス数、つまり行列式は次のようになります。$x$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def construct(x):
    if x == 0:
        return [[0]]

    n = 2
    p = 2
    lst = 1

    a = [[0] * 81 for _ in range(81)]

    def add(u, v, w=-1):
        a[u][v] = w

    add(1, 2)

    def mul():
        nonlocal n, p
        add(p, n + 1)
        add(p, n + 2)
        add(n + 1, n + 2)
        p = n + 2
        n += 2

    def mul_add():
        nonlocal n, p, lst
        add(p, n + 1)
        add(p, n + 2)
        add(n + 1, n + 2)

        add(lst, n + 3)
        add(n + 3, n + 1)

        p = n + 2
        lst = n + 3
        n += 3

    highest = x.bit_length() - 1

    for b in range(highest - 1, -1, -1):
        if (x >> b) & 1:
            mul_add()
        else:
            mul()

    for i in range(2, n + 1):
        a[i][i] = 1

    add(p, n + 1)
    n += 1
    a[n][1] = 1

    res = []
    for i in range(1, n + 1):
        res.append(a[i][1:n + 1])

    return res

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        x = int(input())
        mat = construct(x)

        out.append(str(len(mat)))
        for row in mat:
            out.append(" ".join(map(str, row)))

    sys.stdout.write("\n".join(out))

solve()

最後のシンク頂点は、すべてのビットが処理された後にのみ追加されます。 エッジが頂点に戻る`1`重要なサイクル カバーを作成できる唯一のエッジです。
