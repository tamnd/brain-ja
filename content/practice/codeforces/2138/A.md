 ## 解決策
 ## 問題の理解

 ショコラとバニラという 2 人がいます。彼らはまったく同じ数のケーキから始めます。$2^k$それぞれ。 ケーキの総数は、$2^{k+1}$。 目標は、チョコラが正確に終わるようにケーキを再分配することです。$x$ケーキとバニラが残りを受け取ります。 再分配の各ステップには制約があります。つまり、ある人が自分のケーキの半分を他の人に与えることができますが、それは現在のケーキの数が偶数である場合に限られます。 タスクは、目標に到達するための最小ステップ数を見つけて、それを達成する一連の操作を提供することです。 

入力には複数のテスト ケースが含まれています。 各テスト ケースは次のように指定します$k$そして$x$、 と$k$最大 60 個。つまり、最初のケーキの数は最大 60 個まで可能です。$2^{61}$これにより、ケーキごとに反復するシミュレーション アプローチが除外されます。 許容される最大演算数 120 は、数値を半分にすることを繰り返すとすぐに収束するため、対数またはビットごとの戦略で十分であることを示す強力なヒントです。 

素朴なソリューションにつまずく可能性があるエッジケースとしては、次のようなものがあります。$x$ケーキの初期数に等しい (移動は必要ありません)、$x$1 または$2^{k+1}-1$(最大限に不均衡であり、正確な一連の操作が必要です)、および繰り返し半分にするとゼロになるか、目標をオーバーシュートする可能性がある状況です。 

## アプローチ

 ブルート フォース アプローチでは、考えられるすべての操作シーケンスを再帰的または BFS 経由でシミュレートします。 各ステップで、ケーキの半分をショコラからバニラに、またはその逆に与えることができます。 これにより正確性が保証されますが、状態空間はステップ数に応じて指数関数的に増加します。$2^{60}$ケーキをメモリ内で個別のオブジェクトとして表すことはできません。 ケーキ数を超える BFS は現実的ではありません。 

重要な観察は、半分にする操作がケーキ数のバイナリ表現を操作することに対応しているということです。 各演算では、一方の数値を 2 で除算し、その数値をもう一方の数値に加算します。 どちらもから始まるので、$2^k$、ターゲットを表すことができます$x$2 のべき乗の合計として、各ステップで半分にシフトするトラッキング。 基本的に、ターゲットをオーバーシュートすることなく一方の側からもう一方の側にシフトできる 2 の最大のべき乗を繰り返しチェックすることで、建設的なアルゴリズムを実行します。 これにより、問題は、$x$そして最初の金額。

 ## アルゴリズムのチュートリアル

 1. しましょう$c = 2^k$ショコラのイニシャルケーキと$v = 2^k$バニラのものになります。 空の操作リストを初期化します。 
2. その間$c \neq x$、 比較する$c$と$x$。 もし$c > x$, ショコラはバニラにケーキをあげる必要があります。 そうでなければ、バニラはショコラにケーキをあげなければなりません。 
3. 与えるステップで半分にできる 2 の最大のべき乗を特定します。 半分にできるのは偶数だけなので、最大値を見つけてください$2^i$贈り主が少なくとも$2^i$ケーキを転送してもターゲットをオーバーシュートしません。 
4. 選択した量を半分にして操作を実行します。 記録`1`ショコラがケーキをあげたら、`2`バニラがケーキをくれたら。 アップデート$c$そして$v$それに応じて。 
5. まで繰り返します。$c = x$。 各ステップで差分のバイナリ表現の 1 ビットが効果的に操作されるため、$|c - x|$、ループは最大で終了します$2k$ステップ数は 120 ステップ保証の範囲内です。 
6. 操作の回数と順序を出力します。 

不変条件は、各演算後にケーキの合計が残ることです。$2^{k+1}$、各操作は、可能な分布をスキップすることなく、2 のべき乗に沿ってケーキを移動するだけです。 常にターゲットに向けて許容可能な最大のシフトを選択するため、ステップ数は最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        k, x = map(int, input().split())
        c = 1 << k
        v = 1 << k
        ops = []
        while c != x:
            if c > x:
                # Chocola gives half to Vanilla
                give = c // 2
                while c - give < x:
                    give //= 2
                c -= give
                v += give
                ops.append(1)
            else:
                # Vanilla gives half to Chocola
                give = v // 2
                while c + give > x:
                    give //= 2
                c += give
                v -= give
                ops.append(2)
        print(len(ops))
        if ops:
            print(" ".join(map(str, ops)))

if __name__ == "__main__":
    solve()
```このソリューションは、上記で説明した貪欲なアルゴリズムを実装します。 転送可能なハーフケーキの最大量を繰り返し特定し、オーバーシュートすることなく目標に向かって移動できるようにします。 整数除算を使用すると、有効な演算のみが実行されることが保証されます。 while ループ構造により、各反復でターゲット差分のバイナリ表現内の少なくとも 1 ビットが確実に修正されます。 

## 実用的な例

 入力用`2 3`:

 | ステップ | ショコラ(c) | バニラ (v) | 操作 |
 | --- | --- | --- | --- |
 | 0 | 4 | 4 | - |
 | 1 | 6 | 2 | 2 |
 | 2 | 3 | 5 | 1 |

 ステップ2の後、$c = 3$、ターゲットと一致します。 

入力用`2 4`:

 | ステップ | ショコラ(c) | バニラ (v) | 操作 |

 | 0 | 4 | 4 | - |

 チョコラにはすでに目標数があるため、操作は必要ありません。 

これらのトレースは、貪欲なビット単位の半分化アプローチがターゲットに効率的に到達するために必要な 2 のべき乗のみを調整していることを示しています。

 ## 特殊なケース

 入力用`1 1`, ショコラはケーキ2個からスタート。 アルゴリズムが最初に見るのは`c > x`そして操作 1 を実行します。半分 (ケーキ 1 個) をバニラに与えます。 新しい状態は`c = 1, v = 3`、ターゲットに一致します。 これにより、最小限のターゲットが正しく処理されます。 

のために`1 3`, ショコラは2、バニラは2から始まります。`c < x`, バニラは半分（ケーキ1個）をショコラに渡します。 新しい状態`c = 3, v = 1`目標を達成しています。 アルゴリズムは、相対値と最大許容半分に基づいてギバーを正しく選択します。 

のために`2 4`, どちらも最初はケーキが4個あります。 while ループ条件はすぐに失敗し、0 個の操作が出力されます。 これは、「すでに目標を達成している」というエッジケースを処理します。
