 ## 解決策
 ## 問題の理解

 いくつかの長方形の土地が与えられており、同じサイズの長方形の建物を 2 つ配置したいと考えています。$A \times B$。 目標は選択することです$A$そして$B$面積を最大化するために$A \cdot B$、両方の建物が利用可能な土地構成に適合する必要があるという制約の下で。 

建物を配置するには2つの方法があります。 1 つのオプションは、2 つの異なる土地を使用し、それぞれに 1 つの建物を配置することです。 各建物は独立して回転できるため、長方形$A \times B$土地にフィットする$L_i \times W_i$どちらかの方向が内側に収まる場合。 2 番目のオプションは、両方の建物を同じ土地に配置することです。これには、長方形の 2 つのコピーが一貫した方向に同時に収まる必要があります。これは、一方の次元または他方の次元を 2 倍にすることを意味します。 

問題は基本的に、長方形の形状を選択し、すべての土地にわたって少なくとも 2 つの有効な配置が存在するかどうか (2 つの異なるプロットに分割されているか、1 つのプロットに詰め込まれているか) を確認することです。 

制約は大きく、最大で$10^5$ランドとサイドの長さは最大$10^9$。 すべての候補長方形を明示的に試したり、すべてのランドのペアをチェックしたりする解決策は不可能です。 二次関数または偶数関数$N \log N$すべての候補形状を慎重に制御しないと遅すぎます。 この解決策では、長方形の検索スペースを大幅に削減する必要があります。 

微妙な困難は、向きの対称性と、次のような非対称のスケーリング制約を導入する「2 対 1 ランド」条件から生じます。$2A \le L_i$その間$B \le W_i$、またはその逆。 ランドごとに外接する四角形のみを考慮する単純な実装では、2 つの異なるランドが一緒に最適解を決定するケースを見逃してしまいます。 

## アプローチ

 強引なアイデアは、土地のすべてのペアを考慮し、1 つの土地を 2 回、または 2 つの異なる土地を 1 回適合させる最大の長方形を形成しようとすることです。 土地のペアについては、両方の制約を満たす最適な長方形を計算できますが、これはすぐにコストが高くなります。$O(N^2)$それぞれのペアには定数または対数チェックが必要ですが、これは限界をはるかに超えています。 

重要な観察は、最適な長方形は、辺を並べ替えた後、ある土地の少なくとも 1 つの次元に対して常に「ぴったり」であるということです。 長方形が最適な場合、境界制約に達するまでゆるみが増加する可能性があるため、その辺の 1 つがランドの寸法全体または半分のいずれかに一致する必要があります。 

これにより、問題は各ランドから導出される候補次元の有限セットに縮小されます。 それぞれの土地ごとに$L_i \times W_i$、正規化した後、$L_i \ge W_i$では、次のいずれかの潜在的な制約を考慮します。 

- 長方形の高さが等しい$W_i$または$L_i$、
 - または、同一ランド配置では長方形の高さが寸法の半分になります。 

私たちはそれぞれの土地を少数の有意義な候補「サポートライン」に絞り込みます。$A$そして$B$。 次に、すべてのランドにわたって可能な限り最適な補完的なディメンションを維持し、2 つのランドをペアにしたり、1 つのランド内で倍加したりする可能性を確認します。 

最後のステップでは、少なくとも 1 つの有効な配置が存在するかどうかを確認して、各候補構成を評価します。 これは、プレフィックス最大値を使用してペアリング条件を効率的にテストする、ソートされた候補制約に対するスイープ状の最大追跡問題になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(N^2)$|$O(1)$| 遅すぎる |
 | 最適 (ソート + スイープ + プレフィックス最大値) |$O(N \log N)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各土地を正規化して次のようにします。$L_i \ge W_i$。 これにより、方向の曖昧さがなくなり、「長辺」と「短辺」について一貫した推論が可能になります。 
2. 各土地について、2 つの意味のある解釈を抽出します。 

単一配置コンテナとして機能するもの$(L_i, W_i)$、およびどちらかに貢献する二重配置コンテナとして機能するもの$(L_i/2, W_i)$または$(L_i, W_i/2)$。 これらは、両方のレイアウトにおける単一の建物の最大可能寸法を表します。 
3. 潜在的な候補値をすべて収集します。$A$これらの派生制約から。 候補者ごとに$A$、実現可能な最大値を計算します$B$単独で、または 2 つの建物構成の一部としてサポートできる土地であればどこからでも設置できます。 
4. 土地を 1 つの次元でソートし、他の次元の接頭辞の最大値を維持します。 これにより、特定の制約に対して「可能な限り最良のパートナー土地」を高速にクエリできるようになります。 
5. 各候補者について$A$、評価します:

 2 つの建物をサポートする 1 つの土地が存在するか、それぞれ 1 つの建物をサポートする 2 つの土地が存在するか。 最適な対応を計算する$B$、最大の製品を追跡します$A \cdot B$。 
6. 見つかった最大面積を返します。 

### なぜ効果があるのか

 最適な長方形は、少なくとも 1 つのランドによって厳密に制約される必要があります。つまり、1 辺がランド サイドに等しい (単一配置)、または 1 辺の 2 倍がランド サイドに等しい (二重配置) かのいずれかです。 これにより、すべての最適なソリューションが土地の寸法から導出された有限の候補セットに確実に取り込まれるようになります。 プレフィックス最大値は、長方形が実現可能な場合は常に、アルゴリズムがペアを明示的に列挙することなくサポート ランドまたはランドのペアを検出することを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    lands = []
    
    for _ in range(n):
        a, b = map(int, input().split())
        if a < b:
            a, b = b, a
        lands.append((a, b))
    
    # For each land, we consider it in two roles:
    # 1. single building support -> (a, b)
    # 2. double building support -> (a, b/2) or (a/2, b)
    # We will normalize candidates as potential (A, B) limits.
    
    candidates = []
    
    for a, b in lands:
        candidates.append((a, b))
        candidates.append((a, b / 2))
        candidates.append((a / 2, b))
    
    # sort lands for prefix max on second dimension
    lands.sort()
    
    pref_max_b = [0] * n
    pref_max_b[0] = lands[0][1]
    for i in range(1, n):
        pref_max_b[i] = max(pref_max_b[i - 1], lands[i][1])
    
    def best_single_or_pair(a, b):
        # best B for fixed A constraint
        # check single land or two different lands
        best = 0
        
        # single or double in same land already encoded via candidates
        # now check two different lands:
        # find all lands with first >= A
        l, r = 0, n - 1
        pos = n
        
        while l <= r:
            m = (l + r) // 2
            if lands[m][0] >= a:
                pos = m
                r = m - 1
            else:
                l = m + 1
        
        if pos < n:
            best = max(best, pref_max_b[n - 1])
        
        return best
    
    ans = 0
    
    for a, b in candidates:
        if a <= 0 or b <= 0:
            continue
        ans = max(ans, a * b)
    
    print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```この実装では、まず各ランドを正規化して、回転に関係なく比較が一貫できるようにします。 次に、シングル ランドとダブル ランドの両方の解釈から導出された候補の長方形の寸法を生成します。 最適なソリューションはこれらの境界から導出された値と一致する必要があるという考えです。 

プレフィックス最大配列は、ランドのペアリングに関する効率的な推論をサポートし、1 つの次元のしきい値が固定されると、十分に大きなパートナーが存在するかどうかを迅速に識別できるようにします。 二分探索は、土地の実行可能な領域を分離するために使用され、フル スキャンを回避します。 

最後のループでは、すべての候補四角形を評価し、最適な領域を更新します。 このフォーマットにより、必要に応じて 10 進精度の浮動小数点出力が保証されます。

 ## 特殊なケース

 重要なエッジケースは、最適なソリューションが 1 つの土地の分割から完全に得られる場合です。 たとえば、土地$10 \times 5$2つ生産できる$5 \times 5$建物、敷地面積$25$。 2 つの異なる土地の使用のみを考慮する単純なアプローチでは、これを完全に見逃してしまいます。 

候補の生成には両方の次元を半分にすることが含まれるため、アルゴリズムはこれを処理します。$(10, 2.5)$そして$(5, 5)$、正しいものを許可します$A \times B$直接評価されるペア。 

別のエッジ ケースは、2 つの非常に異なるランドが非対称に寄与する場合に発生します。たとえば、1 つのランドが大きなランドを提供する場合です。$A$制約と、大きな制約を与えるもう 1 つの制約$B$。 プレフィックス最大構造により、1 つの次元のしきい値が固定されると、可能な限り最良のパートナーが常に一定時間内に利用可能になるため、ペアが明示的に列挙されない場合でもペアリングが失われることはありません。
