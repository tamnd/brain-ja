 ## 解決策
 ## 問題の理解

 長方形の領域と、その中に配置されたいくつかの円形のセンサーが与えられます。 各センサーは、その円の内側にあるあらゆる点を検出します。 2 つの重要な幾何学的特性が保証されています。センサーは、検出円が重なったり接触したりしないように十分に分離されており、開始位置とターゲット位置の両方は、すべての検出円の外側にあるという意味ですでに安全です。 

アレンは開始点から目標点まで移動する必要がありますが、直線セグメントに沿ってのみ移動できます。 選択した中間点で方向を変える可能性があり、ポリライン パス全体が長方形の内側に留まり、センサーの開いたディスクに入らないように、最大​​ 1000 個のそのような転換点のシーケンスを構築するように求められます。 

出力は最短パスや最適パスではなく、制限された数の曲がりを含む有効なパスのみです。 これは、タスクが幾何学的に実現可能であることを直ちに示唆しています。つまり、禁止された円形の障害物がある平面で曲線を配線していることになります。 

重要な制約は、直線セグメントがディスクを完全に避けなければならないということです。つまり、すべてのセグメントが各中心から少なくともセンサー半径に等しい距離に留まらなければなりません。 

問題のサイズはセンサーの点では小さく、最大でも 50 個ですが、座標は連続的であり、任意の実数値のルーティングが許可されます。 これにより、グリッド スタイルの離散化アプローチが排除され、組み合わせ構造を備えた連続幾何学へと私たちは推進されます。 

微妙なエッジ条件として、センサーの境界に触れることは許可されますが、内部への侵入は許可されません。 これは、パスが円を「かすめる」ことができることを意味し、これは接線方向の迂回路を構築するときに重要になります。 

もう 1 つの重要な構造上の保証は、センサー ディスクが互いに交差したり接触したりしないことです。 これは、各障害物が独立して動作し、グローバルな迂回を強いるような重複する禁止領域の連鎖が存在しないことを意味します。 

## アプローチ

 単純なアプローチでは、円の境界と四角形の境界上の多くの点をサンプリングして、連続平面上の可視性グラフを構築し、最短パスまたは到達可能性の検索を実行しようとします。 問題は、関連する幾何学的構成の数が明確な離散的な方法で制限されていないことです。 センサー境界ごとに k 点をサンプリングすると、O(kN) 個の頂点と O((kN)^2) 個のエッジが得られ、正確さはすべての接線方向の迂回を捕捉するのに十分な大きさの k を選択するかどうかに依存します。 正確な接線構造を失うことなく、最悪の場合の連続ジオメトリの正確さを保証する有限で均一なサンプリングは存在しないため、このアプローチは信頼できなくなります。 

正しい洞察は、直線セグメントを実際にブロックしているものを理解することから得られます。 セグメントは、円の内部を横切る場合にのみ失敗します。 円は互いに独立しているため、1 つの円を迂回しても他の円には干渉しません。 これにより、問題は局所的な障害物の回避に限定されます。 

古典的な幾何学の事実として、2 つの外部点を接続しながら単一の円を迂回する最短の方法は、円の接線を使用することです。 外部の点から見て、円上にはちょうど 2 つの接点が存在します。 これは、直接セグメントが円と交差する場合、そのセグメントを接点の 1 つを通過する 2 つのセグメントの迂回で置き換え、障害物ごとに最大 1 つの中間頂点だけパスを増やすことができることを示唆しています。 

センサーの数は最大 50 個であるため、センサーごとの直線的な迂回数でも 1000 ポイントの制限内に快適に収まります。

主な困難は、迂回する障害物の全体的な順序を決定することです。 ただし、ディスクは互いに素であるため、交差点を貪欲に処理できます。セグメントが円と交差するたびに、違反している円を 1 つ修正し、そのセグメントをそれを回避する迂回路で置き換えます。 これにより新しいセグメントが導入される可能性がありますが、各変更によりその円との交点の数が厳密に減少し、接線によって外部クリアランスが保証されるため、循環を引き起こすような以前に固定された円との新しい交点が導入されることはありません。 

したがって、構築は、すべてのセグメントが有効になるまでポリラインを反復的に改良することになります。

 | 接線ベースの反復修復 | O(N^2) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 開始点とターゲット点の間の単一セグメントから始まるパスを構築し、無効なセグメントを繰り返し修復します。 

1. パスを開始点とターゲット点のみを含むリストとして初期化します。 これは、リファインする単一の直線セグメントを表します。 
2. パス内にセンサー ディスクと交差するセグメントが存在する場合、そのようなセグメントを 1 つと違反センサーを 1 つ選択します。 慎重に選択する必要はありません。分離したディスクによって独立性が保証されるため、違反しているペアがあれば十分です。 
3. 選択した線分 AB と半径 r の円の中心 C について、A から円への接線、および B から円への接線を計算します。 実際には、一貫した接線方向が 1 つだけ必要です。 セグメントの方向と同じ側にある円上の接点を選択し、有効な外部パスを生成します。 
4. セグメント AB を 2 つのセグメント A → T → B に置き換えます。ここで、T は円の境界上で選択した接点です。 これにより、新しいポリラインは円の境界には接触しますが、内部には入らないことが保証されます。 
5. 元のセグメントを削除し、新しい中間点をパスに挿入します。 
6. 円と交差するセグメントがなくなるまで繰り返します。 

各置換では選択した円との少なくとも 1 つの交点が削除され、ディスクが重なり合わないため、新しいセグメントが無限の競合サイクルを繰り返し再導入することができないため、プロセスは終了する必要があります。 

### なぜ効果があるのか

 重要な不変条件は、各変更の後、すべてのセグメントが変更されないままであるか、変更を引き起こした特定の円に関して厳密に改善されるということです。 接線の置換により、円の内部の完全に外側に留まるセグメントが生成されるため、その円がこれら 2 つのサブセグメントによって再び侵害されることはありません。 円の数は有限であり、挿入ごとに少なくとも 1 つの違反が解決されるため、プロセスは終了する必要があります。 ばらばらであることにより、1 つの円を修正することで、無限に何度も再訪することを強いられる病的なカスケードが作成されなくなります。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

EPS = 1e-12

def seg_circle_intersect(a, b, c, r):
    # check if segment AB intersects open disk of center C
    ax, ay = a
    bx, by = b
    cx, cy = c

    abx, aby = bx - ax, by - ay
    acx, acy = ax - cx, ay - cy

    A = abx * abx + aby * aby
    B = 2 * (abx * acx + aby * acy)
    Cq = acx * acx + acy * acy - r * r

    disc = B * B - 4 * A * Cq
    if disc < 0:
        return False

    sqrt_d = math.sqrt(max(0.0, disc))
    t1 = (-B - sqrt_d) / (2 * A)
    t2 = (-B + sqrt_d) / (2 * A)

    return (0 < t1 < 1) or (0 < t2 < 1)

def tangent_point(p, c, r, pick=0):
    # compute one tangent point from external point p to circle
    px, py = p
    cx, cy = c
    vx, vy = px - cx, py - cy
    d2 = vx * vx + vy * vy
    d = math.sqrt(d2)

    # angle between CP and tangent
    ang = math.acos(min(1.0, r / d))
    base = math.atan2(vy, vx)

    theta = base + ang if pick == 0 else base - ang
    return (cx + r * math.cos(theta), cy + r * math.sin(theta))

def solve():
    N, xL, yL, xR, yR = map(int, input().split())
    sx, sy = map(int, input().split())
    tx, ty = map(int, input().split())

    circles = []
    for _ in range(N):
        x, y, r = map(int, input().split())
        circles.append(((x, y), r))

    path = [(sx, sy), (tx, ty)]

    changed = True
    while changed:
        changed = False
        for i in range(len(path) - 1):
            a = path[i]
            b = path[i + 1]

            bad = None
            for c, r in circles:
                if seg_circle_intersect(a, b, c, r):
                    bad = (c, r)
                    break

            if bad is None:
                continue

            c, r = bad

            t1 = tangent_point(a, c, r, 0)
            t2 = tangent_point(b, c, r, 1)

            # choose one tangent replacement
            mid = t1

            path.insert(i + 1, mid)
            changed = True
            break

    print(len(path) - 2)
    for x, y in path[1:-1]:
        print(f"{x:.10f} {y:.10f}")

if __name__ == "__main__":
    solve()
```実装では、パスを点のシーケンスとして明示的に維持します。 各反復ではセグメントをスキャンし、二次投影テストを使用して円との交差をチェックします。 違反しているセグメントが見つかると、端点から計算された接点が違反している円に挿入されます。 

実装上の微妙な選択は、明瞭さと数値安定性のために幾何学的射影公式の代わりに二次積集合を使用することです。これは、判別テストがセグメントがディスク内部に入るかどうかを直接エンコードするためです。 

接線の計算は基本的なジオメトリに依存します。つまり、外部点から円まで、接線方向は半径が接線に垂直な直角三角形を形成し、円弧の関係が得られます。

| ステップ | パス | アクション |
 | --- | --- | --- |
 | 1 | (1,1) → (9,9) | 初期セグメント |
 | 2 | (1,1) → T → (9,9) | 接点を挿入 |

 接線を計算した後、(5,5) の周囲の円上の境界点を選択します。 新しいパスはディスクを完全に回避します。 

これは、単一の障害物が 1 回の挿入で解決されることを示しており、局所的な修復動作が確認されています。 

### 例 2

 入力:```
2
0 0 20 20
1 1
19 19
5 5 2
15 15 2
```直線のパスは両方の円と交差します。 

| ステップ | パス | アクション |
 | --- | --- | --- |
 | 1 | A → B | イニシャル |
 | 2 | A → T1 → B | 最初の円を修正 |
 | 3 | A → T1 → T2 → B | 2番目の円を修正 |

 挿入するたびに、結合されていないことによる前のディスクの違反が再導入されることなく、1 つのディスクが解決されます。 

これは、挿入されたポイントの総数が N において線形のままであることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N^2) | 各挿入は少なくとも 1 つのセグメントとサークルの競合を解決し、最大で O(N) 個の挿入があり、それぞれが O(N) 個のサークルをチェックします。 
| スペース | O(N) | パスは挿入ごとに最大 1 ポイントずつ増加します。 

この制約では最大 50 個のセンサーが許可されるため、二次幾何学的修復プロセスでも制限内で快適に実行できます。 各センサーが寄与する迂回の数は最大でも一定であるため、1000 ポイントの上限には達しません。

 ## 特殊なケース

 直線セグメントが円に正確に接する場合、デリケートなケースが発生します。 その状況では、判別式はゼロになり、パスが内部に入らないため、交差テストではそれを安全なものとして扱う必要があります。 実装では、(0,1) の t の厳密な不平等を要求することでこれを保証します。 

もう 1 つのエッジ ケースは、開始点または終了点が円の境界に非常に近い場合です。 この問題では距離が厳密に正であることが保証されているため、接線の計算は明確に定義されたままであり、ゼロによる除算が発生することはありません。 

3 番目のケースは反復挿入振動ですが、セグメントが円の周りの接線に置き換えられると、結果として得られる両方のサブセグメントが構造上その円のディスクの外側に留まり、無限ループを防ぐため、互いに素な円は再違反サイクルを防ぎます。
