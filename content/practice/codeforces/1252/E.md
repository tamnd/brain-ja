 ## 問題の理解

 メロディーを表すオリジナルの整数列が与えられます。 直接保管することはできません。 代わりに、元のシーケンスの「形状」のみを保持する、同じ長さの新しいシーケンスを構築する必要があります。上昇する、等しいまま、または下降するすべてのステップは、新しいシーケンスに正確に反映される必要があります。 さらに、新しいシーケンス内の連続する値は急激に変化することができず、それらの絶対差は指定された定数によって制限されます。$K$、すべての値は一定の間隔内に収まる必要があります$[L, R]$。 

タスクは、有効な変換されたメロディーを見つけるだけでなく、辞書編集的に最小のものを見つけることです。 つまり、最初のポジションをできるだけ小さくし、制約によって強制された場合にのみ後のポジションを増やしたいと考えています。 

入力サイズ$N \le 10^5$いかなる二次戦略も排除します。 考えられるすべての有効なシーケンスを試したり、位置ごとに繰り返し間隔の伝播を実行したりするアプローチは、遅すぎます。 各位置が 1 回または少数回決定される、線形または線形に近い構造が必要です。 

微妙な問題は、制約が自明な方法でローカルではないことです。 方向制約は情報を前方に伝播しますが、有界差分制約は隣接する要素を緊密に結合します。 「常に最小の許容値を選択する」などの単純な貪欲な選択は失敗する可能性があります。値が小さすぎると将来のポジションが不可能になる可能性があるためです。 

よくある失敗例の 1 つは、ローカルのグリーディ ディップです。 

私たちが選ぶなら$B_i$辞書編集上の順序を最小限に抑えるために非常に小さいですが、$A_{i} < A_{i+1}$力$B_{i+1} > B_i$そしてまだ内側にある$K$、範囲制限により、後で実行可能な値が不足する可能性があります。 

したがって、本当の課題は、現在の値を最小限に抑えながら、将来の実現可能性を維持することです。 

## アプローチ

 強引な解釈は、次のように構築してみることです。$B$左から右に、各位置で可能なすべての値を試します。$[L, R]$、残りのサフィックスをまだ完了できるかどうかを確認します。 これには、選択ごとに、残りのすべての位置に制約を前方に伝播させ、実現可能性の問題を効果的に解決する必要があります。$O(N)$ポジションあたりの回数。 それは次のことにつながります$O(N^2)$あるいはさらに悪いことに、これは限界をはるかに超えています。$N = 10^5$。 

重要な観察は、間隔伝播を使用してサフィックス制約の実現可能性を維持できるということです。 単一の値にコミットするのではなく、サフィックスを補完できる範囲の可能な値を位置ごとに維持します。 この範囲は、右から左に移動するにつれて小さくなります。 

ただし、接尾辞の実現可能性だけでは、辞書編集上の最小性には十分ではありません。 実際のシーケンスを構築する必要もあります。 重要なアイデアは、後方の実現可能範囲を前方の貪欲な構造と組み合わせることであり、各位置で、サフィックスを実現可能に保つ最小値を選択します。 

実現可能性を計算するには、間隔を逆方向に伝播します。 させて$S_i$以下のすべての値のセットになります。$B_i$そのような立場をとることができます$i..N$有効のままです。 ポジションについて$N$、$S_N = [L, R]$。 以前の位置では、範囲制限、傾斜制限という 3 つの制約を交差させます。$A$、および互換性のある値が存在するという要件$S_{i+1}$距離内にある$K$。 

これにより、問題はシフトされた間隔を持つ間隔交差に変換されます。 

かどうかに応じて$A_i < A_{i+1}$、$=$、 または$>$、制限されたステップ サイズと組み合わせて、厳密に増加、均等、または厳密に減少する動作を強制します。 

これらの間隔を逆方向に計算すると、再構築できます。$B$左から右に、次の状態を実行可能な間隔内に維持する最小の有効な値を常に選択します。 

これにより、正確性を維持しながら指数関数的な分岐が回避されます。

 ## アルゴリズムのチュートリアル

 各位置に間隔を格納する後方 DP を定義します。$[L_i, R_i]$の有効な値のうち、$B_i$。 

### 1. 最後に初期化します

 最後の位置を次のように設定します。$[L, R]$、範囲内の任意の値が最初は可能であるためです。 

これは、前方制約のない唯一のポジションです。 

### 2. 制約を逆方向に伝播する

 ポジションごとに$i$から$N-1$まで$1$、与えられた場合にどのような値が可能かを決定します。$S_{i+1}$。 

まず関係を次のように翻訳します。$A$：

- もし$A_i < A_{i+1}$、 それから$B_i < B_{i+1}$- 等しい場合、$B_i = B_{i+1}$- 大きい場合は、$B_i > B_{i+1}$また、$|B_i - B_{i+1}| \le K$、 意味$B_{i+1}$に横たわらなければなりません$[B_i-K, B_i+K]$。 

前向きに推論する代わりに、関係を逆転させます。$B_{i+1}$、許容範囲を導き出します。$B_i$。 

これにより、次の間隔が生成されます。$B_i$間隔に応じて$[L_{i+1}, R_{i+1}]$。 方向制約とステップ制限の下でその区間に遷移できるすべての可能な値を計算し、次の値と交差します。$[L, R]$。 

### 3. 実現可能性を確認する

 If at any point the interval becomes empty, no valid melody exists and we output -1.

 ### 4. Construct lexicographically smallest sequence

We start from position 1. At each step, we choose the smallest value in$[L, R]$ある値に遷移できるように$S_{i+1}$。 保存された間隔内に互換性のある次の値が存在するかどうかを確認することで、実現可能性を確保します。 

この貪欲な選択は、サフィックス間隔がすべての実現可能性制約をすでにエンコードしているため、機能します。 

### なぜ効果があるのか

 核となる不変条件は、逆方向伝播の後、$S_i$のすべての値を正確に表します$B_i$有効な接尾辞に拡張できます$B_{i+1..N}$。 このセットは完全に区間として特徴付けられているため、このセットの外側にある値はおそらく不可能であり、その内側にある値には少なくとも 1 つの有効な継続があります。 

したがって、位置で実行可能な最小値を選択すると、$i$、すべてのサフィックスについて実現可能性がすでに事前に計算されているため、将来の失敗の危険にさらされることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def intersect(a1, a2, b1, b2):
    return max(a1, b1), min(a2, b2)

def solve():
    N, L, R, K = map(int, input().split())
    A = list(map(int, input().split()))
    
    INF = 10**30
    
    lo = [0] * N
    hi = [0] * N
    
    lo[-1], hi[-1] = L, R
    
    for i in range(N - 2, -1, -1):
        low_next, high_next = lo[i + 1], hi[i + 1]

        if A[i] < A[i + 1]:
            # B[i] < B[i+1]
            # so B[i] in [L, R], and must have some b_{i+1} in next interval > b_i
            # feasible b_i must be < high_next
            lo_i = L
            hi_i = min(R, high_next - 1)

        elif A[i] > A[i + 1]:
            # B[i] > B[i+1]
            lo_i = max(L, low_next + 1)
            hi_i = R

        else:
            # equal
            lo_i = max(L, low_next)
            hi_i = min(R, high_next)

        if lo_i > hi_i:
            print(-1)
            return

        lo[i], hi[i] = lo_i, hi_i

    res = [0] * N
    res[0] = lo[0]

    for i in range(1, N):
        prev = res[i - 1]
        low_next, high_next = lo[i], hi[i]

        if A[i - 1] < A[i]:
            # must increase
            cand = max(low_next, prev + 1)
            if cand > high_next:
                print(-1)
                return
            res[i] = cand

        elif A[i - 1] > A[i]:
            # must decrease
            cand = min(high_next, prev - 1)
            if cand < low_next:
                print(-1)
                return
            res[i] = cand

        else:
            # equal
            if low_next <= prev <= high_next:
                res[i] = prev
            else:
                print(-1)
                return

        if abs(res[i] - res[i - 1]) > K:
            print(-1)
            return

    print(*res)

if __name__ == "__main__":
    solve()
```コードはまず実現可能区間を逆方向に計算します。 各位置には、有効なサフィックスを許可する最小値と最大値が格納されます。 遷移ロジックは、グローバル境界を尊重しながら、厳密な増加、減少、または均等が必要かどうかを直接エンコードします。 

第 2 フェーズでは、事前に計算された間隔と方向制約の両方に一致する最小の実現可能な値を貪欲に選択することで、辞書編集的に最小のシーケンスを構築します。 最終チェックにより、$|B_i - B_{i+1}| \le K$制約。 

実装によくある落とし穴は、実現可能期間だけでは強制力がないことを忘れていることです。$K$-difference 制約をグローバルに適用します。 ここでの間隔伝播は、選択された貪欲なパスの正確なステップ サイズの一貫性ではなく、存在を保証するだけであるため、再構築中にチェックする必要があります。

 ## 特殊なケース

 脆弱なケースは、後方間隔が大きいままであるにもかかわらず、前方への貪欲な選択により実現可能性が崩壊する場合です。 たとえば:

 入力:```
3 1 5 1
1 2 1
```逆方向の間隔では、位置 1 で複数の選択肢が可能ですが、1 を選択すると、有効な中間値まで増加する機能がブロックされる可能性があります。 再構成ステップでは、事前計算された間隔内で有効な後続を許可する最小値を常に選択することでこれを回避します。 

もう 1 つの特殊なケースは、等価性チェーンです。 等しい長いセグメントの場合$A_i$存在します、すべての$B_i$同一である必要があります。 逆方向 DP では、すべての間隔がサフィックス範囲の交差部分に折りたたまれ、再構成では単一の値が単純に伝播されるため、偶発的なドリフトが防止されます。 

最後のエッジケースが発生するのは次の場合です。$K$大きいですが$[L, R]$きついです。 ステップ制約が緩いとしても、レンジ制約だけでも初期ポジションを狭い間隔に押し込む可能性があります。 逆方向計算により、貪欲な決定が行われる前にこの制限が確実に適用され、最終段階での失敗が防止されます。
