 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. すべての問題を必須時間順に並べ替えます$t_i$。 これにより、増加するにつれて、$s$、必須の問題のセットは増えるばかりです。 この単調性が、プレフィックス処理を可能にする核となる構造です。 
2. プレフィックス数を構築します: 位置$i$、最初の中に簡単な問題と難しい問題が何問出現するかを保存します。$i$問題を並べ替えた順序で表示します。 
3. それぞれの候補時間を考慮する$s$どちらかとして$t_i$一部の人にとっては$i$、 または$T$。 固定プレフィックスの場合は、$i$, これらの問題はすべて必須です。 
4. 必須の時間コストを次のように計算します。$cost = easy_i \cdot a + hard_i \cdot b$。 これを超えると$s$、これはスキップしてください$i$なぜなら、Petya は必要な制約さえ満たせないからです。 
5. 可能であれば、残り時間を計算します$rem = s - cost$。 残りのオプションの数も計算します。プレフィックスの外側では簡単ですが困難です。 
6. 解決した問題を最大限に高めるには、1 つの問題あたりにかかる時間が短いため、常に簡単なオプションの問題を最初に取り上げます。 使いやすいものをできるだけ多く使用してください$rem$, 次に難しい問題を使います。 
7. 有効なすべての解決策の最大合計を追跡します。$s$。 

### なぜ効果があるのか

 期限ごとにソートされたスイープでは、すべての有効なソリューションがソートされた配列の何らかのプレフィックスに対応することが保証されます。 固定プレフィックス内では、実現可能性は順序ではなく、必要な合計処理時間のみに依存します。 特定のタイプのすべてのタスクのコストは同じであるため、残りの時間の最適な使用はコストを考慮して貪欲に行われます。解決される問題の数の点で、より簡単なタスクを最初に実行することは、常に困難なタスクとの交換よりも優先されます。 これにより、プレフィックスの実現可能性とローカルの貪欲な充填がすべての最適なスケジュールをカバーする、安定した最適な構造が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m = int(input())
    for _ in range(m):
        n, T, a, b = map(int, input().split())
        tp = list(map(int, input().split()))
        t = list(map(int, input().split()))

        arr = list(zip(t, tp))
        arr.sort()

        easy_pref = [0]
        hard_pref = [0]

        for ti, typ in arr:
            easy_pref.append(easy_pref[-1] + (typ == 0))
            hard_pref.append(hard_pref[-1] + (typ == 1))

        ans = 0

        def evaluate(limit_time, idx):
            easy_m = easy_pref[idx]
            hard_m = hard_pref[idx]

            cost = easy_m * a + hard_m * b
            if cost > limit_time:
                return 0

            rem = limit_time - cost

            easy_total = easy_pref[-1]
            hard_total = hard_pref[-1]

            easy_avail = easy_total - easy_m
            hard_avail = hard_total - hard_m

            take_easy = min(easy_avail, rem // a)
            rem -= take_easy * a

            take_hard = min(hard_avail, rem // b)

            return easy_m + hard_m + take_easy + take_hard

        n = len(arr)

        for i in range(n + 1):
            limit = T if i == n else arr[i-1][0]
            ans = max(ans, evaluate(limit, i))

        print(ans)

if __name__ == "__main__":
    solve()
