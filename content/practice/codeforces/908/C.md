 ## 解決策
 ## 問題の理解

 等しい半径の円盤のセットが与えられ、最初は非常に高い _y_ 座標で平面の上に配置されます。 各ディスクには固定の _x_ 座標があり、地面に接触する (_y = 0_) か、すでに配置されている別のディスクに接触するまで、垂直線に沿ってまっすぐ下にスライドさせます。 タスクは、すべてのディスクを配置した後、各ディスクの中心の最終的な _y_ 座標を計算することです。 

入力は、ディスクの数である _n_ と、ディスクの共通半径である _r_ で構成されます。 次に、各ディスクの _x_ 座標を指定する _n_ 個の整数のシーケンスが続きます。 出力は、_n_ 個の実数、つまりディスクの最終的な垂直位置のリストです。 

制約は中程度です: _n_ ≤ 1000 および _r_ ≤ 1000 であるため、_O(n²)_ 解も実現可能です。 主な困難はアルゴリズムの効率ではなく、幾何学的相互作用を正しくモデル化することにあります。 

明らかではないエッジ ケースには、複数のディスクが同じ _x_ 座標を共有する状況が含まれます。 たとえば、入力が次の場合:```
3 1
5 5 5
```最初の円盤は _y = 1_ で着地し (地面に接触)、2 番目の円盤は最初の円盤に触れて _y = 3_ で静止し、3 番目の円盤は _y = 5_ で静止します。 以前のディスクの位置を無視する不用意なアプローチでは、すべてのディスクが誤って _y = 1_ に配置されてしまいます。 もう 1 つの微妙な点は、ディスクが水平方向に近いものの完全に位置合わせされていない場合に発生するため、新しいディスクは円と円の距離の公式を使用して垂直方向のオフセットを計算する必要があります。 

## アプローチ

 最も単純なアプローチはブルート フォースです。ディスクごとに、_y = r_ (地上レベル) から開始して、以前に配置されたすべてのディスクをチェックします。 水平距離が 2*r 以下である以前の円盤について、ピタゴラスの定理を使用して、新しい円盤が重ならずに静止できる最大の高さを計算します。 これらの候補の高さと地面のレベルの最大値を取得します。 このアプローチは、以前のすべてのディスクに対して明示的に停止条件を強制するため正しいものですが、新しいディスクごとに以前のすべてのディスクを検査する必要があり、時間計算量は _O(n²)_ になります。 _n ≤ 1000_ の場合、最大 100 万回の操作が発生しますが、これは許容範囲内です。 

重要な観察は、どのディスクも潜在的に以前のすべてのディスクと相互作用する可能性があるため、一般にこれより高速な漸近解は存在しないということです。 空間インデックス (セグメント ツリーや座標圧縮など) を維持することによって最適化を行うこともできますが、_n = 1000_ の場合はその必要はありません。 ブルートフォース手法で十分ですが、浮動小数点精度を処理するには慎重な実装が必要です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 承認済み |
 | 最適 | O(n²) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化する`y_positions`各ディスクの最終的な _y_ 座標を保存します。 
2. 各ディスクを反復処理します。`i`指定された順序で。 候補となる垂直位置から開始します`y = r`、地面に触れることに対応します。 
3. 前のディスクごとに`j`(0 から i-1)、水平距離があるかどうかを確認します。`abs(x[i] - x[j])`は 2*r 以下です。 これにより、新しいディスクをディスクの上に置くことができるかどうかが決まります。`j`。 
4. 円板が接触できる場合は、ピタゴラスの定理を使用して垂直オフセットを計算します。新しい中心の _y_ は次のとおりです。`y[j] + sqrt(4*r*r - dx*dx)`どこ`dx = abs(x[i] - x[j])`。 これにより、ディスクが重ならずに接する最も高い位置が得られます。 
5.アップデート`y`現在の値とこの計算された高さの最大値になります。 
6. 以前のすべてのディスクを確認した後、`y`に`y_positions`。 
7. すべてのディスクが処理されるまで繰り返します。 すべての位置を十分な浮動小数点精度で出力します。 

不変条件は、各ステップで、`y_positions[i]`は、ディスク _i_ が以前に配置されたディスクと交差せず、地面の制約を満たす最小の有効な _y_ 座標です。 

## Python ソリューション```python
import sys, math
input = sys.stdin.readline

n, r = map(int, input().split())
x_coords = list(map(int, input().split()))

y_positions = []

for i in range(n):
    y = r  # minimal y if it touches the ground
    for j in range(i):
        dx = abs(x_coords[i] - x_coords[j])
        if dx <= 2*r:
            y = max(y, y_positions[j] + math.sqrt(4*r*r - dx*dx))
    y_positions.append(y)

print(" ".join(f"{y:.10f}" for y in y_positions))
```コードはアルゴリズムのステップを直接実装します。 各ディスクを高さ _r_ で初期化し、以前のすべてのディスクをループして、重複を避けるために許容される最大の高さを計算し、その結果を追加します。 使用する`math.sqrt`正しい幾何学的配置を保証します。 高精度で印刷すると、浮動小数点チェッカーの問題が回避されます。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, r = map(int, input().split())
    x_coords = list(map(int, input().split()))
    y_positions = []
    for i in range(n):
        y = r
        for j in range(i):
            dx = abs(x_coords[i] - x_coords[j])
            if dx <= 2*r:
                y = max(y, y_positions[j] + math.sqrt(4*r*r - dx*dx))
        y_positions.append(y)
    return " ".join(f"{y:.10f}" for y in y_positions)

# Provided sample
assert run("6 2\n5 5 6 8 3 12\n") == "2.0000000000 6.0000000000 9.8729833462 13.3370849613 12.5187346573 13.3370849613"

# Minimum input
assert run("1 1\n1\n") == "1.0000000000"

# All disks in same x
assert run("3 1\n5 5 5\n") == "1.0000000000 3.0000000000 5.0000000000"

# All disks far apart
assert run("3 1\n1 100 200\n") == "1.0000000000 1.0000000000 1.0000000000"

# Disks at maximum n=1000, r=1000, sparse x
x_vals = " ".join(str(i*2) for i in range(1, 1001))
inp = f"1000 1000\n{x_vals}\n"
output = run(inp)
ys = list(map(float, output.split()))
assert all(y == 1000.0 for y in ys), "All disks should sit on ground due to spacing"
