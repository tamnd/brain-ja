 ## 解決策
 ## 問題の理解

 アリスは、一定の長さの音符のシーケンスをすべて数えたいと考えています`n`1 から 1 までのピッチを使用する`k`ただし、同じように「移動」するシーケンスは同一とみなされます。 連続する音符の各ペアが同じ相対関係 (増加、減少、または等しい) を持っている場合、2 つのシーケンスは音楽的に同等であるとみなされます。 たとえば、最初の曲が上がって下がってその後平らになる場合、正確なピッチに関係なく、上がって下がってその後平らになる他の曲は同等です。 

入力には 2 つの整数が与えられます。`n`、曲の長さ、そして`k`、アリスが歌うことができる最大の音程。 出力は、音楽的等価性における個別の曲の数 (モジュロ 998244353) です。 

制約により許可されるのは、`n`100万までと`k`最大10億まで。 これにより、すべてのシーケンスの生成やシーケンスの明示的な比較が即座に除外されます。`k^n`可能性は天文学的に大きいです。 線形またはほぼ線形にスケールするソリューションが必要です。`n`そして、に関して対数または定数`k`。 

微妙なエッジケースが発生する場合`n`は 1 です。この場合、連続するペアは存在しないため、1 から 1 までのすべての音符が`k`独特の曲です。`k`シーケンス。 もう 1 つのエッジケースは次のような場合です`k`1: すべての音符が同じであるため、同値クラスは 1 つだけです。`n`。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての長さのシーケンスを生成することです。`n`1からまでのメモ付き`k`そして、それを増加、減少、または同等の「パターン」に正規化します。 次に、異なるパターンを数えます。 これは原理的には正しいですが、保存する必要があります。`k^n`シーケンスには完全に不可能です`n`20 という小さいとき`k`サイズが大きくて不可能です`n`最大 10^6。 

重要な洞察は、音符間の「動き」のシーケンスが同じである場合に限り、2 つのシーケンスが同等であるということです。 それぞれの動きは上、下、または同じになります。 したがって、同値クラスの数を数えるのは、長さのシーケンスの数を数えるのと同じです。`n-1`1 から 1 までの数字で「実現可能」な動き`k`。 

各セグメントについて、一連の増加または減少で考えられる開始値と終了値の数がわかっている場合は、組み合わせ論を使用してシーケンスの総数を計算できます。 同値クラスの総数は、1 から 2 までの整数のべき乗の合計という単純な式に従うことがわかります。`k`、等比級数またはべき乗剰余技法を使用して効率的に計算できます。 具体的に言うと、答えは、`(k*(k+1)//2)^(n-1)`移動をカウントするときは、制約に合わせて調整されたモジュロ 998244353。

 | ブルートフォース | O(k^n) | O(k^n) | 遅すぎる |
 | 最適 | O(n ログ MOD) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. もし`n`1の場合はすぐに戻ります`k`なぜなら、それぞれの音符が独自のシーケンスであり、考慮すべき動きがないからです。 
2. のために`n`1 より大きい場合は、連続するノート間の動きに焦点を当てます。 移動には、上、下、または均等の 3 種類があります。 各長さのシーケンス`n`のシーケンスに一意に対応します`n-1`動きます。 
3. 任意の音符から始まるシーケンスの総数を考えてみましょう。 長さのシーケンスの場合`n`、等価クラスの数は、各開始音の等差級数の合計の累乗として表すことができます。`n-1`。 
4. 最初の値の合計を計算します。`k`998244353 を法とする整数。この合計は、任意の開始ノートからすべてのより高いノートまでの可能な移動をカウントします。 させて`S = k * (k+1) // 2 % MOD`。 
5. 同値クラスの総数は次のとおりです。`S^(n-1) % MOD`、それぞれの`n-1`動きはシーケンス全体で独立して組み合わせることができます。 
6. 998244353 を法とする計算値を返します。 

それが機能する理由: 動きの各シーケンスは、音楽的等価性の下で曲のクラスを独自に定義します。 個別の移動シーケンスの数をカウントすることにより、すべての同値クラスをカウントします。 べき乗剰余演算を使用すると、非常に大規模な場合でも計算が効率的になります。`n`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mod_pow(a, b, mod):
    result = 1
    a %= mod
    while b > 0:
        if b & 1:
            result = result * a % mod
        a = a * a % mod
        b >>= 1
    return result

def solve():
    n, k = map(int, input().split())
    if n == 1:
        print(k % MOD)
        return
    
    S = k * (k + 1) // 2 % MOD
    ans = mod_pow(S, n - 1, MOD)
    print(ans)

if __name__ == "__main__":
    solve()
```このコードはまず、単音の曲のエッジ ケースを処理しますが、これは簡単です。 の`mod_pow`関数は、998244353 を法とするべき乗を効率的に計算します。`n > 1`、以下の整数の合計`k`計算されて累乗されます`n-1`。 オーバーフローを避けるために、すべての演算は 998244353 を法として実行されます。

 ## 特殊なケース

 いつ`n=1`、音符間の移動はありません。 入力用`1 5`の場合、アルゴリズムは 5 つの異なるノートを反映して 5 を直接返します。 いつ`k=1`、入力用`2 1`、すべてのシーケンスは`[1,1]`したがって、等価クラスは 1 つだけです。 べき乗剰余演算は非常に大きなべき乗を効率的に処理し、たとえ次のような場合でもアルゴリズムがオーバーフローしないようにします。`n=10^6`そして`k=10^9`。
