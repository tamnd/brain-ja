 ## 解決策
 ## 問題の理解

 私たちは巨大な$n \times n$グリッド、ここで$n$と同じ大きさにすることができます$10^9$。 一部のセルは、列内に垂直セグメントを描画することにより黒く塗られます。 少なくとも 1 つのセグメントで覆われたすべてのセルが黒になります。 

すべてのセグメントが描画された後、残りの白セルは 1 つの連結成分を形成することが保証されており、少なくとも 3 つの白セルが存在します。 

次の特性を持つ白セルがいくつあるかを数えなければなりません。 

その 1 つの白いセルも黒にペイントすると、残りの白いセルのセットが切断されます。 

グラフの問題として見ると、すべての白いセルが頂点になります。 2 つの白いセルがエッジを共有している場合、隣接しています。 白い領域は最初は接続されています。 このグラフの関節点である白セルの数を数えるよう求められます。 

最初の困難はグリッドのサイズです。 リテラルグリッドには最大で次のものが含まれます$10^{18}$したがって、白血球を保存することさえ不可能です。 

2 番目の問題は、描画されるセグメントの数が比較的少ないことです。 すべてのテスト ケースにわたって、セグメントの合計数は最大でも$10^5$。 これは、グリッド自体は巨大であるにもかかわらず、白い領域の幾何学形状が単純であることを強く示唆しています。 

重要な観察は、黒いセルが少数の垂直セグメントにのみ表示されるということです。 ほとんどの列は完全に空です。 依存するソリューション$n$すぐには無理です。 アルゴリズムは以下にのみ依存する必要があります。$q$。 

### 明らかではないエッジケース

 3 つの連続する空の列を考えてみましょう。```
column i     empty
column i+1   empty
column i+2   empty
```中央の列の白いセルはすべて、同一の局所構造で囲まれています。 より遠くにある空の列を削除しても、アーティキュレーションの動作を変更することはできません。 すべての空の列を保持するソリューションでは、サイズのグラフが作成されます。$O(n)$、それは不可能です。 

非常に長い垂直の白い廊下を考えてみましょう。```
#
.
.
.
.
.
#
```すべての内部セルには同じ近傍パターンがあります。 すべてのセルを個別に処理すると、再び巨大なグラフが生成されます。 このソリューションでは、同等のセルの長い実行を圧縮する必要があります。 

狭い通路によって生じる調音点を考慮してください。```
..#..
..#..
.....

..#..
```周囲のグリッドがほとんど空であっても、中央のセルは重要です。 圧縮スキームでは、カットされたすべての頂点とブリッジを保持する必要があります。 単純な面積のカウントだけでは十分ではありません。 

## アプローチ

 ブルートフォースソリューションは概念的には単純です。 

白セルのグラフを作成します。 すべての白いセルを一時的に削除し、残りのグラフが接続されたままかどうかをテストします。 この定義はアーティキュレーション ポイントと正確に一致するため、これは正しいです。 

問題はサイズです。 ささやかなものでも$1000 \times 1000$グリッドの場合、グラフにはすでに 100 万個の頂点が含まれています。 ここ$n$到達できる$10^9$, そのため、グラフを表現することさえできません。 

黒細胞の構造がすべてを変えます。 

のみ$q$垂直セグメントが存在します。 列ごとに並べ替えると、3 列を超えるギャップは 3 列のギャップとまったく同じように動作します。 すべての黒いセグメントおよびすべての境界線から少なくとも 2 の距離にある頂点は、関節点になることはできません。 長い空の領域の中央部分は、新しいトポロジーに寄与しません。 

これにより、水平方向の圧縮が可能になります。 2 つの人工的な完全に黒い境界列を所定の位置に挿入した後$0$そして$n+1$、すべての列ギャップは次のように置き換えることができます。$$\min(\text{gap}, 3).$$該当する列の数は次のようになります。$O(q)$。 

次のステップは垂直方向の圧縮です。 

1 つの列内では、ほとんどの白セルは長い間隔に属しており、そのローカルな間隔は$3 \times 3$近所も同じです。 このようなセルは、すべてが調音点であるか、すべてが非調音点であるかのいずれかです。 近傍パターンが変化する区間のエンドポイントを保持する必要があるだけです。 

この圧縮後、白い領域全体は、$O(q)$頂点。 

最後の単純化では、長く圧縮されたセグメント間のエッジが削除されます。 長い垂直チェーンは、エンドポイント間のコネクタとしてのみ機能します。 すべての圧縮されたセルを明示的に保存する代わりに、そのチェーンによって表される内部セルの数と等しい重みを持つ重み付きエッジを保存します。 

ここで問題は次のようになります。 

関節頂点を数え、ブリッジ エッジで表されるすべてのセルを数えます。 

Tarjan のアルゴリズムは、圧縮されたグラフ上で両方のタスクを線形時間で解決します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$頂点かそれ以上 |$O(n^2)$| 不可能 |
 | 最適 |$O(q \log q)$|$O(q)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 所定の位置に 2 本の人工的な黒い柱を追加します。$0$そして$n+1$。 

これらの列は左右の境界を表し、後の圧縮を均一にします。 
2. すべての黒いセグメントを列ごとに並べ替えます。 
3. 水平距離を圧縮します。 

連続する 2 つの関連する列がギャップで区切られている場合$d$、そのギャップを次のように置き換えます$\min(d,3)$。 

アーティキュレーション構造に影響を与えることができるのは、空の領域の最初の 3 つの列だけです。 
4. 圧縮された列ごとに、重複するまたは隣接する黒の間隔をマージします。 
5. 重要な行座標のセットを構築します。 

近傍パターンは、黒区間の終点付近でのみ変更できます。 フォームのすべての行を収集します$l-1$そして$r+1$現在の列とその 2 つの隣接する列から。 
6. 重要な行には白いセルのみを配置します。 

これらはグラフの頂点になります。 
7. 隣接する列の間で等しい行を接続します。 

これは、白いセルを通る水平方向の動きを表します。 
8. 同じ列内の連続する重要な行を接続します。 

それらの間のすべての間隔が白である場合は、エッジを作成します。 エッジの重みは、省略された内部セルの数に等しくなります。 
9. Tarjan アーティキュレーション ポイント DFS を実行します。 

すべての関節頂点が 1 つの答えに貢献します。 
10. Tarjan ブリッジ DFS を実行します。 

エッジがブリッジの場合、その重みによって表されるすべての圧縮されたセルが答えに寄与します。 
11. 合計を出力します。 

### なぜ効果があるのか

 圧縮により、すべてのローカル トポロジー変更が保存されます。 

すべての黒いセグメントから十分に離れたセルには、近くのセルとまったく同じ近傍が表示されます。 このような領域では新しいアーティキュレーション動作を作成できないため、折りたたんでも安全です。 

残りのグラフには、接続が変化する可能性のあるすべての場所が含まれています。 圧縮されたグラフの関節頂点は、削除されたときに白い領域を切断する白いセルに正確に対応します。 長いチェーンは重み付けされたブリッジ エッジとして表されます。 このようなエッジがブリッジの場合、省略されたすべての内部セルも元のグリッドのカット頂点になります。 

頂点カットとチェーン カットの両方が保持されるため、最終的なカウントは元のグリッドと一致します。 

## Python ソリューション```python
import sys
from bisect import bisect_left

input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    t = int(input())
    for _ in range(t):
        n, q = map(int, input().split())

        segs = []
        for _ in range(q):
            y, s, f = map(int, input().split())
            segs.append([y, s, f])

        segs.append([0, 1, n])
        segs.append([n + 1, 1, n])

        segs.sort()

        comp = []
        prev = 0
        curx = 0

        for y, l, r in segs:
            curx += min(3, y - prev)
            comp.append([curx, l, r])
            prev = y

        maxc = comp[-1][0]

        cols = [[] for _ in range(maxc + 2)]
        for x, l, r in comp:
            cols[x].append((l, r))

        for i in range(1, maxc):
            arr = sorted(cols[i])
            merged = []
            for l, r in arr:
                if merged and merged[-1][1] + 1 >= l:
                    merged[-1][1] = max(merged[-1][1], r)
                else:
                    merged.append([l, r])
            cols[i] = merged

        def white(col, row):
            arr = cols[col]
            p = bisect_left(arr, [row + 1, -1]) - 1
            return p < 0 or arr[p][1] < row

        node_id = 0
        mp = [{} for _ in range(maxc + 2)]
        g = []

        def new_node():
            nonlocal node_id
            node_id += 1
            g.append([])
            return node_id

        for c in range(1, maxc):
            pts = {1, n}

            for dc in (-1, 0, 1):
                nc = c + dc
                if 0 <= nc <= maxc:
                    for l, r in cols[nc]:
                        pts.add(l - 1)
                        pts.add(r + 1)

            pts = sorted(x for x in pts if 1 <= x <= n and white(c, x))

            for p in pts:
                mp[c][p] = new_node()

            for p in pts:
                if p in mp[c - 1]:
                    u = mp[c][p] - 1
                    v = mp[c - 1][p] - 1
                    g[u].append((v, 0))
                    g[v].append((u, 0))

            for i in range(len(pts) - 1):
                a, b = pts[i], pts[i + 1]

                ok = True
                for l, r in cols[c]:
                    if a < l < b or a < r < b:
                        ok = False
                        break

                if ok:
                    u = mp[c][a] - 1
                    v = mp[c][b] - 1
                    w = b - a - 1
                    g[u].append((v, w))
                    g[v].append((u, w))

        N = node_id

        dfn = [0] * N
        low = [0] * N
        is_cut = [False] * N
        timer = 0

        ans = 0

        def dfs_cut(u, pe):
            nonlocal timer, ans
            timer += 1
            dfn[u] = low[u] = timer
            child = 0

            for v, _ in g[u]:
                if not dfn[v]:
                    child += 1
                    dfs_cut(v, u)
                    low[u] = min(low[u], low[v])

                    if pe != -1 and low[v] >= dfn[u]:
                        is_cut[u] = True
                elif v != pe:
                    low[u] = min(low[u], dfn[v])

            if pe == -1 and child > 1:
                is_cut[u] = True

        dfs_cut(0, -1)

        for x in is_cut:
            if x:
                ans += 1

        dfn = [0] * N
        low = [0] * N
        timer = 0

        def dfs_bridge(u, pe):
            nonlocal timer, ans
            timer += 1
            dfn[u] = low[u] = timer

            for v, w in g[u]:
                if not dfn[v]:
                    dfs_bridge(v, u)
                    low[u] = min(low[u], low[v])

                    if low[v] > dfn[u]:
                        ans += w
                elif v != pe:
                    low[u] = min(low[u], dfn[v])

        dfs_bridge(0, -1)

        print(ans)

solve()
```圧縮後のグラフ サイズはセグメント構造のみに依存し、セグメント構造には依存しません。$n$。 実装の重要な詳細は、重み付けされたエッジが省略された内部セルの数を格納することです。 Tarjan のブリッジ テストでは、エッジがブリッジの場合にその重みが追加されます。 

もう 1 つの微妙な点は、人工的な境界柱の挿入です。 これらがなければ、境界付近の非常に大きな空の領域は正しく圧縮されません。 

グラフは、重要な行、つまりローカル近傍が変化する可能性のある行のみを使用します。 1 行おきの行は均一な間隔に属し、暗黙的に表されます。

 | 測定 | 複雑さ | 説明 |
