 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$2n$席。 各座席には最初にラベルの付いたアイテムがあり、すべてのラベルが偶数回表示されることが保証されて、ラベルが繰り返されます。 座席はそれぞれの位置に配置されています$i$ユニークな反対の立場を持っています$i+n$サークル上で。 

目標は、一連の交換を実行することです。各交換では、円上の 2 つの隣接する座席のアイテムが交換され、最終的な配置では、すべての向かい合う座席のペアが同一のラベルを保持します。 

タスクは、最終的な配置を明示的に構築することではなく、そのような構成を達成するために必要な隣接するスワップの最小数を計算することです。 

重要な制約は、$2n$すべてのテスト ケースの合計は最大でも$2 \cdot 10^5$、これは解決策を強く示唆しています$O(n \log n)$または$O(n)$テストケースごとに。 スワップを直接シミュレートしたり、順列を検索したりする戦略は、状態の数が階乗的に増加するため、直ちに実行できなくなります。$2n$、グリーディ スワップ シミュレーションでも次のように劣化する可能性があります。$O(n^2)$テストごとに。 

この問題の微妙な問題は、「ペアリングの実現可能性」は保証されていますが、一意性は保証されていないことです。 単純なアプローチでは、スワップがサークル全体でどのように干渉するかを考慮せずに、同一の値をペアにすることが簡単であると誤って仮定する可能性があります。 

反対側のペアを一度に 1 つずつ貪欲に修正すると、よくある失敗ケースが発生します。 たとえば、一致する要素をペアごとに独立してまとめようとすると、1 つの要素を移動すると他の要素の将来の距離に影響を与えるため、スワップを簡単にカウントしすぎてしまう可能性があります。 

もう 1 つの落とし穴は、円を線形として扱い、位置間のラップアラウンド相互作用を無視することです。$1$そして$2n$。 スワップはサイクル上で隣接しているため、構造は純粋に線形ではありませんが、反対のペア制約により、線形割り当て問題に還元できる固定分解が提供されます。 

## アプローチ

 ブルートフォース的な観点では、反対側の位置間の不一致を繰り返し選択し、隣接するスワップを使用して円に沿って 1 つの要素を移動することで修正しようとします。 隣接するスワップによってすべての順列が生成されるため、これは正しいですが、各修正に時間がかかるため、遅すぎます。$O(n)$、そして、あります$O(n)$不一致が発生し、$O(n^2)$テストケースごとに。 

重要な観察は、最終的な条件は、各対のペア内の正確な配置には依存せず、各ペアの両方の位置に同じラベルが含まれることだけに依存するということです。 これにより、各ラベルの出現を、反対側のペアの片側に割り当てるという観点から考えることができます。 

がある$n$反対のペア$(i, i+n)$、そして各ペアは最終的に 2 つの同一のラベルを保持する必要があります。 したがって、各ラベルの出現をこれらの中の「スロット」に効果的に割り当てます。$2n$各ペアが同じラベルを 2 回受け取るという制約の下で、位置を指定します。 

このような割り当てを修正すると、初期配置をターゲット配置に変換するために必要な隣接スワップの最小数は、まさに 2 つのシーケンス間の反転距離になります。 これにより、この反転距離を最小限に抑える最適なターゲット割り当てを構築するという問題が軽減されます。 

各ラベルを個別に見ると、構造はさらに単純化されます。 ラベルの出現はペアに分割する必要があるため、ラベルが出現した場合、$k$回、正確に占有されます$k/2$反対のペア。 最終的な割り当てでの交差を回避する最適な方法は、ソートされた順序でオカレンスを処理し、それらを順番にペアにしてから、それらを反対側のペアにも順番に割り当てることです。 この単調な構造により、反転コストを増加させるインターリーブが回避されます。 

したがって、解決策は、ソートされた出現位置とソートされたターゲット スロット ($n$左側と右側で複製されたペア インデックス)。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース隣接固定 |$O(n^2)$|$O(1)$-$O(n)$| 遅すぎる |
 | 並べ替え + スロットのペアへの出現の貪欲な割り当て |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 円を反対側の固定ペアの集合に変換し、各出現箇所をこれらのペアの 1 つの内側の位置に割り当てることで、ソリューションを構築します。 

1. 分割します。$2n$に位置する$n$反対のペア$(i, i+n)$。 これらのペアは、同一のラベルで「埋める」ことができる唯一の構造単位です。 
2. ラベルごとに、それが表示されるすべてのインデックスを収集します。 すべてのラベルは偶数回出現するため、位置でソートした後、その出現を連続するペアに分割できます。 
3. 位置に表示されるラベルの場合$p_1 < p_2 < \dots < p_k$、ペアリングします$p_1$と$p_2$、$p_3$と$p_4$、 等々。 このような各ペアは、最終的に、向かい合う 1 つの座席ペアの両側を占有することになります。 これにより、スワップ コストが増加するだけとなる、ラベル内の割り当ての交差が防止されます。 
4. ここで、各ペアのグループを、1 つの反対のペアのインデックスへの割り当てが必要であるものとして扱います。$i$(つまり、1 つのオカレンスがその位置に移動します$i$、もう一方はに行きます$i+n$）。 私たちは利用可能なすべてのペアインデックスのリストを維持しています$1 \dots n$。 
5. ラベルペアのリスト (最初に出現した順序で) と利用可能なペアインデックスの両方をソートし、それらを順番に照合します。 両方のシーケンスが独立したブロックの単調表現であるため、この位置合わせにより総変位コストが最小限に抑えられます。 
6. ペアの割り当てによって寄与されるコスト$(x, y)$反対側のペアに$i$は$|x - i| + |y - (i+n)|$。 これをすべての割り当てで合計すると、合計反転距離が得られ、これは隣接するスワップの最小数に等しくなります。 

### なぜ効果があるのか

 重要な不変条件は、異なるラベル間での交差を強制するような方法での代入のインターリーブを決して許可しないことです。 2 つのラベル ブロック間の交差割り当ては、実現可能性を侵害することなく交差を解除でき、総変位を厳密に削減または維持します。 これは、絶対コストを伴う最適割り当て問題をソートベースのマッチングに分離できるものと同じ構造的特性です。 すべてのラベル ブロックが交差しなくなると、問題はソートされた位置とソートされたペア インデックスの間の独立した 1 次元の割り当てに分解され、これは単調マッチングによって最適に解決されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    pos = {}
    for i, x in enumerate(a):
        pos.setdefault(x, []).append(i)
    
    pairs = []
    
    for x in pos:
        arr = pos[x]
        for i in range(0, len(arr), 2):
            pairs.append((arr[i], arr[i+1]))
    
    pairs.sort()
    
    # assign pair indices 1..n
    # matching in order minimizes displacement
    ans = 0
    for i, (u, v) in enumerate(pairs, start=1):
        # i is 1-based pair index
        # compute cost to map u->i, v->i+n
        ans += abs(u - (i - 1)) + abs(v - (i - 1 + n))
    
    print(ans)

これらのペアを形成した後、それらをソートすると、以前の出現が以前の反対側のスロットに一致することが保証され、スワップ距離が増加する交差が防止されます。 

最後のループは、変位コストを直接計算します。各要素は、元のインデックスから最終的な配置のターゲット スロットに移動し、隣接するスワップは、円のライン表現に沿った単位距離の移動に正確に対応します。 

微妙な実装ポイントは、循環インデックスを線形インデックスに変換することです。$0 \dots 2n-1$これにより、反対の位置を次のようにきれいに扱うことができます。$i$そして$i+n$。

 ## 特殊なケース

 重要なエッジ ケースは、すべての同一のラベルがすでにクラスタ化されているものの、反対のペアと位置合わせされていない場合です。 このような場合、単純で貪欲な「不一致を修正する」アプローチでは、ローカルでスワップを試行し、最小値をオーバーシュートしてしまう可能性があります。 ペアリングベースの定式化は、ローカルな修正ではなくグローバルな割り当ての観点から機能することにより、これを完全に回避します。 

もう 1 つの微妙なケースは、ラベルが大量にインターリーブされている場合です。たとえば、次のようなパターンが交互に配置されている場合です。$1,2,1,2,\dots$。 ここで、貪欲な隣接修正は要素を振動させる傾向がありますが、ソートされたペアリング戦略は、オカレンスを一貫してペアリングし、それらを反対側のスロットに単調に割り当てることにより、最適な構造を即座に明らかにします。
