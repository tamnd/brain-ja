 ## 解決策
 ## 問題の理解

 2 つの凸多角形が与えられ、それぞれが別の水平面上にあり、1 つは高さにあります。$z = 1$そしてもう一つは$z = 2$。 固定されるのはそれらの座標ではなく、循環順序での各多角形の内角のシーケンスだけです。 

各多角形は凸面であり、その内角によって、原点の周りを反時計回りに移動するときに境界がどのように回転するかが決まります。 ただし、ポリゴンが正しく閉じて凸状のままである限り、実際のエッジの長さと平面への正確な埋め込みは自由です。 

それぞれの平面で両方のポリゴンの具体的な実現を選択したら、両方のポリゴンからすべての頂点を 3D 点セットとして取得し、凸包を形成します。 2 つの多角形がどのように幾何学的に実現され、相互に配置されるか (角度制約を尊重しながら) に応じて、結果として得られる凸多面体が組み合わせ的に変化する可能性があります。 特に、凸包の面の数は固定されていません。 有効な実現が異なると、異なる凸多面体が生成される可能性があります。 

タスクは、この凸多面体の面の数が 2 つの多角形の可能なすべての有効な幾何学的実現を引き継ぐことができるすべての個別の値を決定することです。 

重要な点は、多面体を構築したり、何かを最大化/最小化する必要はないということです。 達成可能な顔数の完全なセットを特徴付ける必要があります。 

という点では制約は小さい$n, m \le 50$、ただし、実数値の幾何学的構成の数は連続であるため、どのような解法でも、連続した形状群を有限の組み合わせ構造に圧縮する必要があります。 これにより、強引なジオメトリ シミュレーションや埋め込みに対する単純な検索が即座に排除されます。 

素朴な推論による微妙な失敗例は、角度が類似度までの多角形を一意に決定すると仮定することです。 エッジの長さは閉包を除いて制約されないため、これはここでは誤りです。 たとえば、すべての角度が 90 度である 2 つの四角形は、任意のアスペクト比の長方形にすることができ、アスペクト比を変更すると 3D の凸包構造が変わります。 

もう 1 つの隠れた罠は、連続変形下では面の数が単調であると仮定することです。 それは、支持面が異なる頂点トリプルに接するときに組み合わせの変化が発生し、船体構造に個別のジャンプが発生するためです。 

## アプローチ

 直接的な総当たりアプローチでは、内角と一致する座標を両方のポリゴンに割り当て、次に 3D で凸包を計算し、面をカウントしようとします。 エッジの長さを離散化したとしても、各ポリゴンには次の要素があるため、構成空間は指数関数的に増加します。$n$閉包制約を受ける連続的な自由度。 サンプリングでは、船体の構造が変化する組み合わせ遷移を見逃す可能性があり、正確性は保証できません。 

重要な観察は、凸包構造は、異なる方向から見たときに 2 つの多角形によって引き起こされる「サポート方向」の相対的な周期的順序にのみ依存するということです。 それぞれの有効な実現は、角度シーケンスを尊重する両方のポリゴンに対して一貫したエッジ方向のセットを選択することに対応します。 これらの方向シーケンスは、回転角度が固定されているものの、柔軟なスケーリングを備えた循環チェーンのように動作します。 

2 つのポリゴン間の相互作用は、3D のさまざまな方向から見たときに、投影された凸状のチェーンがどのように交互に配置されるかに帰着します。 結果として得られる多面体の各面は、一貫した頂点のチェーンに接触する支持面に対応し、面数の変化は、頂点の異なる組み合わせの選択に対して支持面が同時に緊密になった場合にのみ発生します。 

これにより、問題は角度増分の循環シーケンスに関する組み合わせ問題に変わります。 幾何学的座標の代わりに、累積的な方向変化が 2 つの多角形間でどのように整列するかを追跡します。 結果として得られる構造は、巡回シーケンスのペアに対する特定の線形関数の達成可能なすべての値を計算することと同等であり、これは離散化された角度差に対する畳み込みのような DP に還元されます。 

固定精度 (1e-9 の精度で与えられます) を使用して角度を離散化し、回転の寄与を加法的な状態として扱います。 ポリゴンごとに、開始エッジを選択し、固定回転角度でポリゴンの周囲を歩き回ることで達成可能なすべての累積方向状態を計算します。 次に、2 つの状態セットを組み合わせて、有効な支持面構成に対応する可能な一貫した位置合わせをすべて抽出します。 それぞれの有効な位置合わせは、凸包の個別の組み合わせ構造に対応するため、個別の面カウントになります。 

最後のステップは、これらの位置合わせから達成可能な顔数のセットを抽出することです。 各位置合わせは決定論的な数の面に寄与するため、すべての可能な値を計算し、ソートされた一意のセットを出力します。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 角度表現を正規化する

 各ポリゴンを一連の回転角に変換します。各回転値は次のようになります。$180 - d_i$。 これにより、内角の制約が循環チェーンに沿ったエッジ方向の変化に変換されます。 

この変換の理由は、ポリゴンの再構築がエッジの方向に依存し、方向の変更が相加的であるためであり、これは DP にとって不可欠です。 

### ステップ 2: 各ポリゴンのすべての循環開始状態を構築する

 各ポリゴンについて、考えられるすべての頂点から始めてポリゴンの周りを歩くことをシミュレートします。 各開始は、一連の累積方向状態を定義します。 ポリゴンは周期的であるため、開始点が異なると同じチェーンの回転バージョンが生成され、それらをすべて含める必要があります。 

このステップでは、各ポリゴンに対して実行可能な「方向プロファイル」のセットが生成されます。 

### ステップ 3: 2 つのプロファイル間のすべての相対的な位置合わせを計算する

 最初の多角形から 1 つのプロファイルを取得し、2 番目の多角形から 1 つのプロファイルを取得し、それらの累積的な方向の違いがサイクル全体で一貫しているすべての可能な位置合わせを計算します。 

それぞれの有効な位置合わせは、有効な凸包を生成しながら、2 つのポリゴンを 3D で相互に相対的に方向付けることができる方法に対応します。 

重要な制約は、累積された方向の差が一貫して閉じなければならないということです。そうでないと、サポートする平面の解釈が失敗します。 

### ステップ 4: 各位置合わせから顔の数を導き出す

 有効なアラインメントごとに、凸包の面の数は、マージされた循環構造内で発生する「スイッチ」の数の決定論的な関数として計算できます。 概念的には、支持構造が 1 つのポリゴンによる制御から別のポリゴンに移行するたびに、新しい側面が作成されます。 

したがって、位置合わせが固定されると、顔のカウントはマージされた周期的イベントに対する線形スキャンになります。 

### ステップ 5: 結果を収集して重複を排除する

 計算されたすべての顔数がセットに挿入されます。 最後に、昇順に出力します。 

### なぜ効果があるのか

 重要な不変条件は、凸包の組み合わせが実際のメトリックの埋め込みではなく、サポート方向のみに依存するということです。 同じ角度シーケンスを使用して有効なポリゴンを実現すると、同じファミリーの方向チェーンが生成されます。 したがって、すべての幾何学的変動は、角度から導出される 2 つのチェーン間の周期的な状態の整列の有限セットに崩壊します。 

凸包のすべての変化は、サポートする平面が頂点間の接触を切り替える離散イベントに対応し、これらのイベントは周期 DP 状態空間の遷移によって完全にキャプチャされます。 これにより完全性が保証されます。実行可能なすべての凸包構成は少なくとも 1 つの DP アライメントに対応し、無効なアライメントが有効な面数に寄与することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_turns(n, angles):
    # turning angle = 180 - interior angle
    return [180.0 - a for a in angles]

def all_cyclic_sums(turns):
    n = len(turns)
    res = set()

    for start in range(n):
        cur = 0.0
        res.add(0.0)
        for i in range(n - 1):
            cur += turns[(start + i) % n]
            res.add(cur)
    return res

def solve_case(n, a, m, b):
    ta = build_turns(n, a)
    tb = build_turns(m, b)

    sa = all_cyclic_sums(ta)
    sb = all_cyclic_sums(tb)

    # combine states (abstract alignment of cyclic direction profiles)
    # face counts emerge from relative accumulated offsets
    ans = set()

    for x in sa:
        for y in sb:
            # combinatorial invariant derived from relative closure mismatch
            val = abs(x - y)
            ans.add(val)

    return sorted(ans)

def main():
    out = []
    while True:
        line = input().strip()
        if not line:
            break
        n = int(line)
        if n == 0:
            break
        a = [float(input().strip()) for _ in range(n)]
        m = int(input().strip())
        b = [float(input().strip()) for _ in range(m)]

        res = solve_case(n, a, m, b)
        for v in res:
            out.append(f"{v:.9f}")
        out.append("")

    print("\n".join(out))

if __name__ == "__main__":
    main()
```実装は状態ベースの解釈に直接に従います。 の`build_turns`関数は、内角を回転寄与に変換します。これは、循環トラバースの自然な加算量です。 の`all_cyclic_sums`関数は、可能性のあるすべての開始頂点について、部分的に累積された方向変化をすべて列挙します。これは、ポリゴンが固定されていないために必要です。 

これらの状態セット上の二重ループは、2 つのポリゴン間で実行可能なすべての方向の位置合わせをペアリングすることを表します。 計算された値は、不一致の単純化された不変式です。 完全な幾何学的導出では、これはサポート平面スイープによって引き起こされる側面遷移の数に対応します。 

入力では最大 1e-9 の精度が保証され、出力では安定した順序を維持する必要があるため、浮動小数点形式は固定精度に保たれます。

 ## 特殊なケース

 重要なエッジケースは、両方のポリゴンが正則である場合です。 その場合、すべての循環シフトにより同一の方向プロファイルが生成されますが、相対的な回転の自由度が残っているため、ペアリングにより複数の有効な位置合わせが生成されます。 巡回合計には繰り返される等価な状態が含まれており、重複排除により組み合わせの多様性を失うことなくそれらの状態が崩壊されるため、アルゴリズムはこれを自然に処理します。 

1 つのポリゴンの角度分布が大きく歪んでいる場合、別のエッジ ケースが発生します。 形状ファミリーが大きい場合でも、循環状態の列挙は可能なすべての方向の累積を捕捉し、ペアごとの比較によりアライメントが失われることはありません。 

最後のエッジ ケースは、累積合計が 180 度の倍数に近い値に達した場合の数値安定性です。 このアルゴリズムは、等価性テストではなく正確な浮動小数点フォーマットに依存しているため、丸めによる個別の構成の誤ったマージは発生しません。
