 ## 問題の理解

 私たちは複数の独立した歯車から構成される時計を設計しています。 ギア付き`x`歯は毎年完全なサイクルを完了します`x`1秒間に1本の歯を動かすためです。 すべての歯車は時間ゼロで整列し始め、一緒に動きます。そのため、すべての歯車が初期位置に戻る最初の瞬間は、すべての歯車サイズの最小公倍数になります。 

課題は、この最初の同時復帰がちょうど直後に起こるようにギア サイズを選択することです。`k`秒。 あらゆる選択肢の中で、総歯数が最小の構造が必要です。 

入力にはいくつかの値が含まれています`k`。 それぞれの出力では、最適なギア サイズのセットを 1 つ記述する必要があります。 ギアの数と各ギアの歯数を印刷する必要があります。 

の値`k`せいぜい`100000`、最大で`10000`テストケース。 これは、歯車の多くの組み合わせを試すアルゴリズムを用意できないことを意味します。 可能性のある因子のサブセットまたはパーティションを検索すると、あまりにも急速に拡張されてしまいます。 最小公倍数と因数分解の数学的構造を使用する必要があります。 

主なエッジケースは、最小公倍数が出現する各素数の最大累乗のみを考慮するという事実から来ています。 

たとえば、入力が次の場合:```
1
16
```正しい出力は次のとおりです。```
1
16
```不注意な解決策では次のような結果が得られる可能性があります`2 8`、 なぜなら`lcm(2, 8) = 8`、それだけでは十分ではありません。 完全なプライムパワー`2^4`どこかに現れるはずです。 

別のケースは次のとおりです。```
1
12
```正しい構造は次のとおりです。```
2
4 3
```使用する`2 2 3`最小公倍数も次のようになります。`12`ですが、歯の総数はさらに多くなります。`7`の代わりに`7`この特定のケースでは一致しますが、他の値では、要因が繰り返されると悪化する可能性があります。 最適な構築では、不必要な重複を回避し、必要なプライムパワーを正確に維持する必要があります。 

最後の境界ケースは素数です。```
1
97
```唯一有用な構造は次のとおりです。```
1
97
```最小係数では素数を作成できないため、素数をより小さい歯車に分割することは不可能です。 

## アプローチ

 直接的な総当りのアイデアは、歯車のさまざまなコレクションを試して、それらの最小公倍数が以下であるかどうかを確認することです。`k`。 これは正しいです。有効な構造とは、LCM が必要な戻り時間と正確に一致するコレクションであるためです。 問題は、可能なコレクションの数です。 約数に限定しても`k`、組み合わせの数は因子の数に応じて指数関数的に増加するため、このアプローチは使用できなくなります。 

重要な観察は、すべての整数が素数べき乗の積として記述できることです。 仮定する：`k = p1^a1 * p2^a2 * ... * pm^am`ギアの LCM に含まれるのは`pi^ai`、少なくとも 1 つのギアには、まさにその最高出力が含まれている必要があります。`pi`。 すべてのギアに小さな力が含まれている場合、`pi`、LCM はその要素を見逃します。 一方、複数のプライムパワーを含むギアを追加すると、それらのプライムパワーを別々に保持する場合と比較して、合計が増加するだけです。 

たとえば、単一のギアを使用する代わりに、`12`、歯車を使って`4`そして`3`は、より小さいか等しい合計で同じ LCM を返します。 したがって、最も安価な構造は、次の因数分解で主動力ごとに 1 つの歯車を作成することです。`k`。 

強引なアプローチは、主要国の独立した貢献を無視するため、失敗します。 各素数べき乗を個別に処理できることがわかれば、問題は単純な因数分解になります。

 ## アルゴリズムのチュートリアル

 1. 要因`k`プライムパワーに。 可能な限り小さい約数から始めて、繰り返し因数を削除します。 素因数が見つかったら、その素因数の累乗全体が抽出されるまでそれを掛け続けます。 

完全なべき乗を維持する理由は、最小公倍数には素数自体だけでなく、すべての素数の最大指数が必要であるためです。 

1. 抽出された各原動力を 1 つの歯車サイズとして保存します。 

例えば、`72 = 2^3 * 3^2`、したがって、抽出された値は次のようになります。`8`そして`9`。 

1. 試行的に除算した後の残りの値が 1 より大きい場合、それは元の数の平方根より大きい素因数です。 独自のギアとして追加します。 
2. 抽出した素数動力の数と歯車サイズのリストを出力します。 

なぜ効果があるのか:

 因数分解におけるすべての素累乗`k`少なくとも 1 つの選択されたギアに表示されるため、選択されたすべてのギアの LCM には、`k`。 選択したギアごとに分割されるため、`k`、LCM には余分なものを含めることはできないため、正確に`k`。 

最適化のために、有効な構築を検討してください。 すべての素数について`p`で`k`、一部のギアには、必要なすべてのパワーが含まれている必要があります。`p`そうしないと、LCM にその電力が供給されなくなります。 それぞれの要件を満たす最も安価な方法は、まさにこれらの主力を別個のギアとして使用することです。 2 つの必要な素数パワーを 1 つのギアに組み合わせると、それらの合計がその積に置き換えられ、1 より大きい整数の場合、積がこの設定の合計より小さくなることはありません。 したがって、独立した主動力構造により、歯の総数が最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(k):
    ans = []
    x = k
    d = 2
    while d * d <= x:
        if x % d == 0:
            power = 1
            while x % d == 0:
                x //= d
                power *= d
            ans.append(power)
        d += 1 if d == 2 else 2

    if x > 1:
        ans.append(x)

    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        k = int(input())
        ans = solve_case(k)
        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```因数分解ループは、除数の 2 乗が残りの値を超えるまで除数を試行します。 それが起こると、合成数の係数は平方根以下になるため、残りの値はすべて素数でなければなりません。 

除数が見つかると、内側のループはその素数のすべてのコピーを削除します。 変数`power`の繰り返し因子を回すなど、完全なプライムパワーを蓄積します。`2`の中へ`8`のために`72`。 

増分はチェック後の候補もスキップします`2`、不必要な作業を回避します。 以来`k`だけです`100000`、単純な試行分割はすでに十分に高速です。 

出力には常に少なくとも 1 つのギアが含まれています。`k`少なくとも`2`。 素数入力は素数をそのまま残します`x`、その最終値は残りの要素のチェックによって処理されます。
