 ## 解決策
 ## 問題の理解

 山の高さを一列に並べたシーケンスが与えられます。 パラメータ$k$2 つの隣接する山が「互換性がある」とみなされる場合を定義します。隣接する位置間の高さの差が 2 を超える場合です。$k$の場合、その隣接関係は壊れます。 休憩が起こるたびに、新しい山脈が始まります。 言い換えると、隣接するすべての高さの差が最大でも次のような各連続セグメントです。$k$一つの山脈を形成しています。 

For any fixed$k$、配列をスキャンして、出現するセグメントの数を数えることができます。 タスクは、次の値が存在するかどうかを判断することです。$k$結果として得られる山脈の数が正確に$m$、そうであれば、そのような最小のものを出力します$k$。 

入力構造は単一の高さのシーケンスです。 出力は単一の整数です$k$、またはそのようなことがない場合は不可能であるという声明$k$存在します。 

制約が意味するのは、$n$可能なすべての二次シミュレーションまたは反復シミュレーションを実行できる十分な大きさです。$k$不可能です。 二重ループ内で考えられるすべての違いを直接チェックしても、遅すぎます。 ソリューションでは、位置の数と高さの値の範囲の両方への依存を軽減する必要があります。 

セグメント数がどのように変化するかを追跡せずに、セグメントについて局所的にのみ推論すると、微妙な失敗例が発生します。$k$成長します。 たとえば、高さを考えてみましょう$[1, 10, 2]$。 もし$k = 1$、すべての隣接関係が壊れ、3 つの範囲が得られます。 もし$k = 9$、すべてが 1 つの範囲に接続されます。 範囲の数はインデックスごとに滑らかに変化するのではなく、次の場合にのみ変化します。$k$特定のしきい値、つまり隣接する差分を超えます。 「推測」を試みるソリューション$k$これらのしきい値を特定しないと、有効な移行ポイントを見逃す危険があります。 

## アプローチ

 直接的なアイデアは、次の値を固定することです。$k$出現する山脈の数を計算します。 これは簡単です。配列を走査し、いつでも新しいセグメントを開始します。$|h[i] - h[i-1]| > k$。 これにはかかります$O(n)$クエリごとに。 

難しいのは、$k$長い間隔で変化する可能性があるため、可能な限りセグメンテーションを再計算します。$k$につながる$O(n \cdot H)$行動、どこで$H$可能な高さの差の範囲です。 これは不可能です。 

重要な構造的観察は、何かが変化する可能性がある唯一の場所は、隣接する差異自体であるということです。 2 つの連続する異なる差分値の間では、セグメンテーション構造は同一です。 これは、セグメントの数がすべての整数にわたる滑らかな関数ではなく、セット内の値でのみ変化するステップ関数であることを意味します。$\{|h[i] - h[i+1]|\}$。 

これを理解すると、問題を次のように再定式化できます。$k$継続的に、すべての隣接する差異をソートし、それらのうちのいくつが「アクティブ」であるかを推論します（つまり、$k$）。 アクティブなエッジごとに、完全に接続された場合と比較してセグメントの数が 1 つ増加します。 

違いを並べ替えると、より大きいものがいくつあるかを直接判断できます。$k$、これはブレークの数、つまり範囲の数を示します。 

また、単調性も観察されます。$k$セグメントの数を減らすか維持することのみが可能であり、増やすことはできません。 これにより、バイナリ検索が可能になります$k$ただし、よりクリーンな解決策は、違いを一度並べ替えて、答えを直接マッピングすることによって得られます。

 ## アルゴリズムのチュートリアル

 範囲についての考え方から、範囲間の境界についての考え方に切り替えます。 すべての隣接するペアは、その差が次の値を超えるかどうかに応じて、接続を維持するか切断されるかのいずれかになります。$k$。 

1. 隣接するすべての絶対差を計算します。$d[i] = |h[i+1] - h[i]|$。 これらの値は、分割が発生する可能性がある場所を完全に決定するため、重要な値のみです。 これにより、問題は連続的なしきい値から離散的なイベントに軽減されます。 
2. 配列をソートする$d$降順ではない順に。 これにより、すべての「アクティベーションしきい値」のグローバルな順序付けが行われ、増加する$k$さらに 1 つの隣接が接続されます。 
3. 接続を追加する代わりに、プロセスを逆方向から解釈します。$k$増加する場合は、すべての接続がアクティブな状態から始めることを考えてください (大$k$）そして徐々にそれらを「壊して」いきます。$k$減少します。 差分値を渡すたびに、さらに 1 つの隣接関係が切断されます。 
4. 正確であるかどうかを観察します。$i$最大の差はより大きい$k$、それではまさに$i$ブレークが存在し、セグメントの数は$1 + i$。 これにより、問題は超過する要素の数を数えるという問題に変換されます。$k$。 
5. まさに欲しいもの$m$セグメントなので正確に必要です$m-1$休憩します。 それはまさに意味します$m-1$の値$d$より大きくなければなりません$k$。 
6. ソートされた順序で、この条件により正確な間隔が特定されます。$k$は、ソートされた差分配列内の 2 つの連続する値の間になければなりません。 正しい境界は次によって決定されます。$(n-m)$先頭から数えて - 番目の要素。 
7. 間隔が崩れるか存在しない場合、有効な間隔はありません。$k$正確に生成します$m$セグメント。 

### なぜ効果があるのか

 セグメンテーション構造は、隣接するエッジがどの条件を満たすかによって完全に決定されます。$|h[i] - h[i+1]| \le k$。 各エッジは独立して動作し、パス グラフ内のコンポーネントの数は、削除されるエッジの数にのみ依存します。 エッジの除去は正確に行われるため、$k$がしきい値を下回っている場合、関数「セグメント数の関数として」$k$これにより、セグメント数からしきい値間隔へのマッピングが明確に定義され、一意になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    h = list(map(int, input().split()))

    if n == 1:
        # only one segment always
        print(0 if m == 1 else -1)
        return

    d = [abs(h[i] - h[i - 1]) for i in range(n - 1)]
    d.sort()

    # number of segments = 1 + number of edges > k
    # we want exactly m segments => exactly m-1 edges > k

    if m < 1 or m > n:
        print(-1)
        return

    idx = n - m  # boundary index in sorted differences

    # k must be at least d[idx] to ensure exactly m-1 edges exceed it
    # but also must be strictly less than d[idx+1] if it exists
    lower = d[idx] if idx >= 0 else 0
    upper = d[idx + 1] if idx + 1 < n - 1 else 10**18

    if lower < upper:
        print(lower)
    else:
        print(-1)

if __name__ == "__main__":
    solve()
```コードは、問題を隣接する差分に変換することから始まります。これは、それらのみがセグメントの境界を決定するためです。 それらを並べ替えることで、それぞれのしきい値をシミュレートするのではなく、グローバルなしきい値について推論できるようになります。$k$。 

キーインデックス$n-m$正確に達成するには、最大の差異のうち何個を「接続の切断」として扱う必要があるかを特定します。$m$セグメント。 答えは、この分割によって引き起こされる間隔にあるはずです。 その間隔が縮退した場合、有効な間隔は存在しません。$k$存在します。 

境界の取り扱いには注意が必要です。$m = 1$、すべてのエッジが接続されている必要があります。これは次のようになります。$k$少なくともすべての違いと同じくらい大きい。 いつ$m = n$、すべてのエッジが壊れており、非常に小さいものに相当します。$k$。

 ## 特殊なケース

 重要なエッジケースは、隣接する差分がすべて等しい場合です。 例えば、$h = [1, 10, 1, 10]$。 すべての違いは、$9$。 のために$m = 2$、 どれでも$k < 9$3 つのセグメントと任意のセグメントを生成します。$k \ge 9$1 セグメントを生成します。 正確に 2 つのセグメントを取得する方法はありません。 ソート差分アプローチでは、必要な間隔が異なるため、これを正しく検出できます。$k$空になる。 

もう一つのケースは次のような場合です。$m = 1$。 のために$h = [5, 2, 8]$、違いは次のとおりです$[3,6]$。 必要な$k$アルゴリズムは上限を正しく選択し、単一の接続されたセグメントを確保します。 

最後に、いつ$m = n$、すべての隣接関係を解除する必要があります。 任意の配列の場合、これは次のようになります。$k$最小差よりも小さいこと。 間隔の構築は自然に「最小要素の下」まで崩壊し、アルゴリズムはそれに応じて最小の有効なしきい値を返します。
