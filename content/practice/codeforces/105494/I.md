 ## 解決策
 ## 問題の理解

 一連の講義が与えられ、各講義は整数値で表されるある程度の知識を提供します。 講義ごとに、講義に参加するかどうか、および講義に参加する直前に特別な「瞑想」効果を適用するかどうかの 2 つの層で決定します。 

瞑想の状態によって、現在の講義から得られる知識の量が変化しますが、連続して使用できる回数も制限されます。 普通に講義に参加すれば、その価値を十分に得ることができます。 瞑想をしながら参加すると、得られる価値は 2 倍になりますが、連続した講義で瞑想を 2 回続けて適用することはできません。 

課題は、この制約を尊重しながらすべての講義にわたる合計知識を最大化し、さらにこの最大値を達成する 1 つの最適な意思決定シーケンスを再構築することです。 

入力は講義値のリストです。 出力は、可能な限り最大限の総合的な知識と、それを達成するための有効な選択のシーケンスです。 

主な難しさは、各講義での決定が現在の値だけでなく、前の講義で瞑想を使用したかどうかにも依存することです。 これにより、局所的に最適な決定が将来のより良い構成を妨げる可能性があるため、貪欲な選択が正しくなることを妨げる依存関係が作成されます。 

制約の観点から見ると、意図したソリューションは講義数に比例します。 すべてのサブセットを探索したり、メモ化せずに選択肢をシミュレートしたりするアプローチは、各講義で状態依存性のある分岐決定が導入されるため、指数関数的に成長します。 この種の問題の一般的な制限では最大約 100,000 レクチャーが許容されるため、入力が大きい場合は、二次関数の動作でも遅すぎます。 

すべての講義値がゼロまたは負の場合、微妙なエッジ ケースが発生します。 そのような場合、瞑想への参加を避けたり、間違って瞑想を過剰に使用したりする誘惑に駆られます。 ただし、すべての講義は依然としてシーケンスの一部であり、状態に基づいて寄与するため、すべてのゲインが正でない場合でも、DP は遷移を正しく処理する必要があります。 もう 1 つのエッジ ケースは、高値と低値を交互に使用すると、瞑想が特定のインデックスでのみ有効になる場合に発生します。これにより、貪欲な交互処理ではなく慎重な状態追跡が必要になります。 

## アプローチ

 強引な解決策では、各講義に通常の出席、瞑想の出席、または瞑想効果のスキップのいずれかを割り当てるために、あらゆる方法が試行されます。 各レクチャーは前の状態に依存するため、これは事実上、前の選択に基づいて各ポジションが分岐する状態爆発になります。 最悪の場合、各講義は複数の有効な遷移につながり、可能なシーケンスの数が指数関数的に生成されます。 枝刈りを行ったとしても、依存関係構造により、同じプレフィックス状態を繰り返し再利用することになります。 

問題の構造から、講義 i での決定は、講義 i での最良の結果から 2 つの可能な状態の下で 1 を引いたもののみに依存することがわかります。 これは、小さな有限状態空間における動的プログラミングの古典的な特徴です。 完全な履歴を追跡する代わりに、すべての関連情報をインデックスごとに 2 つの値に圧縮します。前の講義が瞑想していなかった場合の最良の結果と、瞑想していた場合の最良の結果です。 

これにより、2 つの実行状態を維持するという問題が軽減されます。 各遷移は前のステップから一定時間で計算され、指数関数的な探索が配列全体の線形スイープに分割されます。

 ## アルゴリズムのチュートリアル

 講義位置 i でインデックス付けされた 2 つの DP 配列を定義します。 1 つは、i で瞑想しなかった場合に i までに達成可能な最高のスコアを表し、もう 1 つは、i で瞑想した場合に達成可能な最高のスコアを表します。

1. 講義が処理されておらず、知識も得られていないため、位置 0 の両方の状態をゼロとして初期化します。 これにより再発の基礎が確立されます。 
2. 1 から n までの各講義 i について、i から 1 を引いた時点での両方の前の状態を考慮して、非瞑想状態の最適値を計算します。 両方の最大値を取得し、現在の講義値を加算します。 これは、以前のアクションに関係なく通常どおり参加できることを反映しており、より良い累積結果につながる以前の状態を選択します。 
3. i での瞑想状態の場合、i マイナス 1 での非瞑想状態からのみ到達できます。 したがって、i から 1 を引いたものから最良の非瞑想結果を取得し、現在の講義値の 2 倍を加算します。 これにより、瞑想を連続して 2 回行うことができないという制約が課されます。 
4. 両方の状態を n まで満たした後、最後の講義では瞑想を使用する場合と使用しない場合があるため、答えは 2 つの最終状態の最大値になります。 
5. シーケンスを再構築するには、n で最適な答えを生成した状態から開始します。 私たちは逆方向に進み、各ステップで DP 値を比較し、唯一の有効な先行関係に従うことによって、その状態が瞑想による遷移か非瞑想による遷移によるものかを判断します。 

再構成ステップは、最適値を達成するためにどの遷移が使用されたかを追跡することに依存しており、DP プロセスを効果的に逆転させます。 

これが機能する理由は、各インデックス i で、両方の DP 状態が、それらの解が以前にどのように到達したかに関係なく、それぞれの制約に対する最適な解を表すという事実から来ています。 すべての遷移は i から 1 を引いたもののみに依存するため、これらの状態が正しい場合は、それらを拡張することで最適性が維持されます。 これにより、以前の決定を再検討する必要なく、すべてのプレフィックスが最適に解決される、一貫した最適な下部構造が作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    a = list(map(int, input().split()))

    if n == 0:
        print(0)
        return

    dpO = [0] * (n + 1)
    dpM = [0] * (n + 1)

    for i in range(1, n + 1):
        dpO[i] = max(dpO[i - 1], dpM[i - 1]) + a[i - 1]
        dpM[i] = dpO[i - 1] + 2 * a[i - 1]

    if dpO[n] >= dpM[n]:
        state = "O"
        best = dpO[n]
    else:
        state = "M"
        best = dpM[n]

    print(best)

    res = []
    i = n
    cur = state

    while i > 0:
        if cur == "M":
            res.append("M")
            cur = "O"
            i -= 1
        else:
            if dpO[i - 1] >= dpM[i - 1]:
                res.append("O")
                cur = "O"
            else:
                res.append("O")
                cur = "M"
            i -= 1

    print(" ".join(reversed(res)))

if __name__ == "__main__":
    solve()
```この実装では、すべてのプレフィックスで各状態の最良の値を格納する 2 つの配列が保持されます。 遷移ロジックは繰り返しを直接反映しています。非瞑想状態は以前の状態と現在の値の両方の最良の部分を利用するのに対し、瞑想状態は非瞑想状態からのみ強制的に遷移し、ゲインを 2 倍にします。 

再構成は、瞑想状態は非瞑想状態から生じたものであり、非瞑想状態は 2 つの可能な先行状態のうちより良い方を選択するという事実を利用して、逆方向に進みます。 最後に反転すると、時系列が復元されます。 

一般的な実装の落とし穴は、dpO 遷移が dpM から発生する可能性があることを忘れていることであり、これにより、解の空間が誤って削減されてしまいます。 もう 1 つの微妙な問題は、dpO[i - 1] が dpM[i - 1] と等しい場合のバックトラッキングが正しくないことです。この場合、どちらの選択も有効ですが、順方向 DP との一貫性を維持する必要があります。 

## 実用的な例

 3 つの講義 (3、1、2) がある単純なケースを考えてみましょう。 

前方DP:

 | 私 | dpO | dpM | 説明 |
 | --- | --- | --- | --- |
 | 1 | 3 | 6 | O = 0+3、M = 0+6 |
 | 2 | 7 | 8 | O = 最大(3,6)+1、M = 6+2 |
 | 3 | 10 | 14 | O = 最大(7,8)+2、M = 8+4 |

 最良の結果は、最終状態 M の 14 です。バックトラックすると、最後の動きは瞑想であったことが示され、i = 2 で前の状態 O が強制されるなどです。 

次に、2、5、1 を考えてみましょう。 

| 私 | dpO | dpM | 説明 |
 | --- | --- | --- | --- |
 | 1 | 2 | 4 | ベーストランジション |
 | 2 | 9 | 10 | O = 最大(2,4)+5、M = 4+10 |
 | 3 | 11 | 18 | O = 最大(9,10)+1、M = 10+2 |

 ここでの最適値は 18 で、最後のステップで瞑想を使用することで達成されます。これは制約を逆方向に伝播し、初期のゲインのバランスが取れていた場合でも、ローカル 2 倍化がいかに支配的であるかを示しています。 

これらのトレースは、各状態がその制約の下で最適なプレフィックス値を正しく取得していること、および最適な選択は貪欲な選択ではなく状態の伝播によってのみ検証できることを確認します。

 ## 特殊なケース

 値が 5 の単一の講義の場合、DP は dpO1 を 5 に、dpM1 を 10 に初期化します。アルゴリズムは 2 つのうち良い方を即座に選択し、結果として瞑想が使用されます。 バックトラッキングにより、この状態が存在しない前の状態 O0 から来たものであることが正しく識別され、これは初期化と一致します。 

0 0 0 のような場合、両方の遷移は常に 0 を生成しますが、DP は依然として有効な状態を伝播します。 dpO と dpM の間の最終的な選択は、値は任意ですが、構造は一貫しており、再構成により、制約に違反することなくオプションの M 状態につながる有効な O 状態の交互シーケンスが生成されます。 

1 100 1 のような交互の値の場合、2 番目の講義は瞑想を強く支持し、dpM2 が優位になります。 DP はこの選択を正しくロックし、後方再構成により最初の講義が O 状態でなければならないことが強制され、単一の高い値のピークが状態依存性を通じて以前の決定をどのように制御できるかを示しています。
