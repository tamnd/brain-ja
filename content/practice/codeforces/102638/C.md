 ## 解決策
 ## 問題の理解

 棚が並んでいるのは、`n`ポジション。 一部の位置にはアニメ ディスクが含まれており、残りの位置にはゴミが含まれています。 私たちは与えられています`k`ディスクの説明。各説明は、そのディスクの位置の可能な範囲を示すだけです。 タスクは、どの位置にゴミが含まれているかを正確に判断することです。 

位置は次のように表されます。`0`ディスクが含まれている場合は出力内で、`1`ゴミが入っている場合。 入力により、可能な範囲に関する情報がディスクの 1 つの固有の配置を決定するのに十分であることが保証されます。 

の値`n`少し上でもいい`100000`したがって、多くの割り当てを繰り返し試行するアプローチは機能しません。 1 秒程度の制限があるため、それに近いものが必要です。`O(n log n)`または`O(n)`。 可能なディスク配置に対する総当り検索は指数関数的に増加し、可能な間隔の多くの組み合わせをチェックするだけでも、許容される操作数をはるかに超えてしまいます。 

厄介な点は、各間隔からはディスクの正確な位置がわからないことです。 不注意な解決策では、間隔を満たす任意の位置が選択される可能性がありますが、選択された位置は一意の配置ではない可能性があります。 

例えば：```
3 1
1 2
```位置 1 または 2 のどこかに 1 つのディスクがあります。両方の配置が可能であるため、答えが一意ではないため、この入力は表示されません。 

もう 1 つの重要なケースは、間隔が重なり合う場合です。```
3 2
1 2
2 3
```最初の間隔を位置 1 に割り当て、2 番目の間隔を位置 2 に割り当てる貪欲な方法では有効な配置が生成されますが、それらを位置 2 と 3 に割り当てることも有効です。 一意性の保証は、そのような曖昧さは公式テストでは起こり得ないことを意味しますが、間隔割り当ての構造を尊重する方法が必要な理由を示しています。 

ディスクのないケースも特別です。```
5 0
```どのポジションもゴミでなければならないので、答えは次のとおりです。```
1 1 1 1 1
```間隔だけを処理し、残りの位置の初期化を忘れるソリューションは、ここでは失敗します。 

## アプローチ

 直接的なアプローチは、すべてのディスクを許容間隔内の特定の位置に配置してみることです。 可能な配置の数は膨大になる可能性があるため、これは間隔と位置の間のマッチングの問題になります。 すべての選択肢を総当りで検索すると、指数関数的に複雑になります。 利用可能なポジションを求めてすべての間隔を繰り返しスキャンする低速のマッチング実装でも、約`O(nk)`オペレーション、それは周りにあります`10^10`最悪の場合。 

有益な観察は、すべての制約が直線上の間隔であるということです。 間隔には順序付けのプロパティがあります。最も早く終了する間隔を処理するときは、現在利用可能な最も早い位置をその間隔に与える必要があります。 この間隔を遅らせた場合、右側の端点が大きい後の間隔では引き続き後の位置を使用できますが、最も早く終了する間隔には代替手段が少なくなります。 

これにより、問題は貪欲な間隔マッチングプロセスに変わります。 すべてのディスク間隔を右のエンドポイントで並べ替えます。 次に利用可能な棚の位置を維持します。 間隔ごとに、その内側にある最初の未使用の位置を割り当てます。 割り当てられた位置は、ディスクの位置とまったく同じです。 出力は単にこれらの位置の補数です。 

すべての有効な割り当てでは各ディスクをその間隔内のどこかに配置する必要があるため、ブルート フォースは機能しますが、可能な選択肢が多すぎるため失敗します。 最も早く終了する間隔が最も制限的であるという観察により、すべての選択を即座に行うことができ、検索を回避できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 貪欲な間隔の割り当て | O((n + k) log k) | O(n + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのディスク間隔を読み取り、正しいエンドポイントで並べ替えます。 2 つの間隔が同じ右端点を持つ場合、それらの順序は正確さに影響しません。 
2. どの棚の位置にディスクが入っているかをアレイにマークしておきます。 最初はすべてのポジションが空であると見なされます。 
3. ソートされた間隔を 1 つずつ処理します。 現在の間隔については`[l, r]`、少なくとも次の最小の位置を選択します。`l`そしてこれまでに使用されていません。 その位置をディスクが含まれているものとしてマークします。 

可能な限り最小のポジ​​ションを選択する理由は、右側により多くのポジションが残っている場合にのみ、将来のインターバルが容易になるためです。 後のポジションを早期に使用すると、より小さな終了点で将来の間隔がブロックされる可能性があります。 
4. すべての間隔が処理された後、棚をスキャンします。 出力`0`ディスクとしてマークされた位置については、`1`他のポジションごとに。 

なぜ効果があるのか:

 貪欲な選択により、残りのすべての割り当てを完了する可能性が維持されます。 まだ処理されていない間隔の中で、右の端点が最も小さい間隔を検討します。 必要以上に遅れて位置を受信した場合、残りのすべての間隔がこの間隔より早く終了することはないため、その位置を最も早い利用可能な有効な位置に置き換えることによって、他の間隔が損なわれることはありません。 この引数を間隔ごとに繰り返すと、貪欲な割り当てによって有効なマッチングが生成されることがわかります。 この問題により、有効な配置が一意であることが保証されるため、このマッチングによって検出された位置は実際のディスクの位置である必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    intervals = []
    for _ in range(k):
        l, r = map(int, input().split())
        intervals.append((r, l))

    intervals.sort()

    disc = [False] * (n + 1)

    parent = list(range(n + 2))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for r, l in intervals:
        pos = find(l)
        disc[pos] = True
        parent[pos] = pos + 1

    ans = []
    for i in range(1, n + 1):
        ans.append('0' if disc[i] else '1')

    print(' '.join(ans))

if __name__ == "__main__":
    solve()
```間隔は次のように保存されます。`(right, left)`ペアであるため、ソートすると自然に最も早い終了位置を持つ間隔が最初に配置されます。 これは貪欲な引数で必要な順序です。 

の`parent`配列は素のセット構造を実装します。 ここでの目的は、任意のセットをマージすることではなく、すでにディスクに割り当てられている位置をすばやくスキップすることです。 位置の場合`x`が使用されている場合、その親を次のように設定します`x + 1`、次の検索を意​​味します`x`次の空き位置に直接ジャンプします。 

の`find`この関数は、指定されたインデックス以降の最初の未使用の位置を返します。 パス圧縮により、繰り返し検索がほぼ一定時間になります。 これにより、すでに占有されている位置をスキャンすることが回避されます。そうしないと、重複する多くの間隔が遅くなります。 

ポジションは次から保存されます`1`に`n`、追加要素`n + 1`安全な番兵として機能します。 これにより、最後の位置が使用される場合の範囲外アクセスが防止されます。 

## 実用的な例

 サンプルの場合:```
5 0
```処理する間隔はありません。 

| ステップ | 間隔 | 選択された位置 | ディスクの位置 |
 | --- | --- | --- | --- |
 | イニシャル | なし | なし | 空 |

 最終スキャンでは、どの位置にもディスクが含まれていないことが確認されるため、すべての位置がゴミになります。 

出力：```
1 1 1 1 1
```構築された例の場合:```
5 2
1 1
2 5
```処理は次のとおりです。 

| ステップ | 間隔 | 開始位置 | 選択された位置 | ディスクの位置 |
 | --- | --- | --- | --- | --- |
 | 1 | [1, 1] | 1 | 1 | {1} |
 | 2 | [2、5] | 2 | 2 | {1、2} |

 最初の間隔には可能な位置が 1 つしかないため、貪欲なステップが強制されます。 2 番目の間隔は、残りの最も古い有効な位置を受け取ります。 

最終的な出力は次のとおりです。```
0 0 1 1 1
```トレースは、アルゴリズムが常に最も制限された利用可能な位置を最初に消費することによって、一意の配置を保存していることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k log k + k α(n) + n) | ソートは間隔処理の大半を占めますが、素集合演算はほぼ一定時間です。 
| スペース | O(n + k) | 間隔リスト、マーキング配列、および素セット構造は線形メモリを使用します。 

の最大値`n`についてです`100000`したがって、この複雑さはメモリと時間の制限内に簡単に収まります。 素のセット構造により、広範囲にわたる繰り返しスキャンが防止されます。

 ## 特殊なケース

 間隔がない場合、アルゴリズムは貪欲な割り当てループに入ることはありません。 の`disc`配列は完全に false のままであるため、最終的な変換ではすべての位置がゴミとしてマークされます。 これは以下を処理します:```
5 0
```正しく、少なくとも 1 つのディスクが存在するという想定を回避します。 

単一位置間隔の場合:```
1 1
1 1
```素セットは位置から始まります`1`利用可能。 この間隔は、次の時点で最初に利用可能な位置を要求します。`1`したがって、アルゴリズムはそれをディスクとしてマークし、ポインターをセンチネルの位置に移動します。`2`。 出力は次のようになります。```
0
```境界に接する間隔の場合:```
6 3
1 1
2 3
4 6
```割り当ては次のように行われます。 最初の間隔は位置を受け取ります`1`。 2番目がポジションを受け取ります`2`、内部で最も早いフリー ポジションであるため、`[2,3]`。 3番目がポジションを受け取ります`4`、内側の最も早いフリーポジション`[4,6]`。 最終的なディスクの位置は次のとおりです。`{1,2,4}`、与える:```
0 0 1 0 1 1
```これは、利用可能な位置の検索が間隔の開始と棚の終了の両方を考慮していることを確認します。
