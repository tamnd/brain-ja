 ## 解決策
 ## 問題の理解

 このタスクは、平方根、立方根、および 2 つの異なるべき乗を含む方程式内に 1 つの整数を隠します。 処理する入力値がありません。 プログラムは一意の整数を決定するだけで済みます`x`等式を満たして印刷します。 

この問題の珍しい点は、方程式が数値検索によって解くことを意図していないことです。 制限時間は事実上、一定時間の観察を要求します。 多くの整数を試す強引なプログラムでは、平方根と立方根を繰り返しチェックするのに時間がかかりますが、目的の解決策では代数を直接構築する必要があります。 

入力が空であるため、入力に依存する制約はありません。 唯一の意味のある制約は、答えを正確に見つけなければならないということです。 浮動小数点近似は、方程式に大きな累乗が含まれるため危険であり、わずかな丸め誤差によって正しい等価性が誤った比較に変わる可能性があります。 

不用意にアプローチすると、短い間隔しか検索されない可能性があります。 たとえば、次の値を試してみます。`0`に`100`正しい出力は次のとおりであるため、答えは決して見つかりません。`228`。 もう 1 つの間違いは、浮動小数点演算を使用して 2 つの辺を比較することです。 たとえ正しい整数に達したとしても、無理数値のべき乗などの式では、等価性チェックに失敗するほどの誤差が蓄積される可能性があります。 

## アプローチ

 簡単なアプローチは、可能な整数を反復処理することです。`x`、すべての根号が定義されていることを確認し、方程式の両辺を評価し、それらが一致したときに停止します。 このステートメントでは、整数が 1 つだけ機能することが保証されているため、これは論理的に正しいです。 ただし、自然な上限はありません。 広範囲を検索するには、未知の数の高価な根数評価が必要となり、浮動小数点値による等価性のチェックも信頼性が低くなります。 

重要な観察は権力から来ています。 2 つの実数が満たされる場合`a^7 = b^3`の場合、7 と 3 は互いに素であるため、両方の値は共通の基数を使用して表すことができます。 次のように書くことができます:```
a = t^3
b = t^7
```何らかの本当の価値のために`t`。 

これを右辺に適用すると、次のようになります。```
x - sqrt((x^2 - 1984) / 5) = t^7
```隠された値は非常に単純であることがわかります。 自然な小整数の候補を試す`t = 2`与える`t^7 = 128`。 これを 2 番目の式に代入すると、次のようになります。```
x - sqrt((x^2 - 1984) / 5) = 128
```平方根を分離すると、次のようになります。```
(x - 128)^2 = (x^2 - 1984) / 5
```この方程式を拡張すると次のようになります。```
x^2 - 320x + 20976 = 0
```判別式は`18496`、その平方根は`136`、考えられる根を与える：```
x = (320 ± 136) / 2
```候補者は２名です`228`そして`92`。 のみ`228`平方根は等しい必要があるため、元の非二乗方程式を満たします。`x - 128`、これは負ではありません。 反対側をチェックすると、隠された構造が確認されます。```
sqrt(228 - 3) - cbrt((3 * 228 + 2) / 2)
= sqrt(225) - cbrt(343)
= 15 - 7
= 8
= 2^3
```したがって、方程式全体は次のように満たされます。`t = 2`そして`x = 228`。

 ## アルゴリズムのチュートリアル

 1. 双方の勢力が 7 と 3 であることを認識し、共有基底を使用して双方を表します。 左側はこうなります`t^3`そして右側は次のようになります`t^7`。 
2. 式を揃える小さな整数の基数を見つけます。 取る`t = 2`右辺は次と等しくなります`128`。 
3. 方程式を解きます。```
x - sqrt((x^2 - 1984) / 5) = 128
```非ラジカル部分を反対側に移動して二乗することによって。 

1. 結果として得られる二次方程式を解きます。 2 つの可能な値が生成されます。`228`そして`92`。 
2. 元の平方根式から符号条件を確認します。 平方根の下の値は次のことを表します`x - 128`、したがって候補者は満足する必要があります`x >= 128`。 これにより削除されます`92`。 
3. 出力`228`。 

なぜ効果があるのか:

 変換は答えを直接推測しません。 べき乗により、方程式の両辺が同じ量のべき乗になります。 値`t = 2`正確な整数構造を作成します。右辺は次のようになります。`128`、左側は次のようになります。`8`、まさにその通りです`2^3`。 結果として得られる二次方程式を解くと、この変換によって作成されたすべての可能な候補が見つかり、元の符号条件をチェックすることで、二乗法によって導入された無関係な解が除去されます。

 ## 特殊なケース

 検索ベースのソリューションは、答えが推測された範囲内にあると想定しているため、失敗する可能性があります。 たとえば、次の値のみをテストする実装です。`1`に`100`入力は受け取りませんが、内部的に考えられる答えを試行します。 正しい出力は次のようになりますが、解決策がないと誤って結論付けてしまいます。`228`。 定数時間ソリューションでは、検索の代わりに値を導出することでこれを回避します。 

浮動小数点検証アプローチも失敗する可能性があります。 有効な答えは次のとおりです。```

```この値では、左基は正確に次のようになります。```
sqrt(225) - cbrt(343) = 15 - 7 = 8
```そして、正しいベースは正確に次のとおりです。```
228 - sqrt((228^2 - 1984) / 5) = 228 - 100 = 128
```等価性は次のとおりです。```
8^7 = 128^3
```根号演算と累乗演算を繰り返した後、数値近似では片側がわずかに異なって表される場合があります。 最終的な解決策は、証明された整数を直接出力することで、そのような比較をすべて回避します。
