 ## 解決策
 ## 問題の理解

 2 つの複素数が与えられ、それぞれが整数の実部と整数の虚数部で記述されます。 最初の数字はペアから形成されます$a, b$として$a + bi$、そして2番目は$c + di$。 タスクは、積を計算し、結果の実数部と虚数部を出力することです。 

乗算は標準的な複素演算です。 直接展開すると、$$(a + bi)(c + di) = ac + adi + bci + bdi^2$$そしてそれ以来$i^2 = -1$、これは次のようになります$$(ac - bd) + i(ad + bc).$$したがって、出力は常に 2 つの整数になります: 実部$ac - bd$そして虚数部$ad + bc$。 

制約は非常に小さく、すべての値が次の範囲内にあります。$-1000$そして$1000$。 これは、正しい算術実装があれば十分であることを意味します。 単純な数式評価であっても一定時間で実行されるため、アルゴリズムの最適化は必要ありません。 

このタイプの問題でよくある間違いは、関連する用語を組み合わせるときの記号の処理です。$i^2$。 もう 1 つのよくある問題は、2 つのクロスタームを混同することです。$ad$そして$bc$特に、精神的に拡張しようとしたり、固定公式なしで実装しようとしたりする場合はそうです。 

## アプローチ

 強引な解釈では、文字通り次のように扱われます。$i$シンボリック オブジェクトとして乗算を段階的に拡張し、実数成分と虚数成分を別々に追跡します。 これは依然として操作ごとに一定の作業ですが、不必要なオーバーヘッドです。 複素数の構造は、すでに閉じた形式の乗算規則をエンコードしています。 

重要な観察は、複素乗算は常に 4 つのスカラー乗算と 2 つの加算/減算に分解されるということです。 複数の入力または反復プロセス間に依存性はありません。 代数恒等式が書き出されると、すぐに計算が開始されます。 

これにより、問題は固定式の直接評価に帰着します。

 ## アルゴリズムのチュートリアル

 1. 4 つの整数を読み取ります$a, b, c, d$。 これらは 2 つの複素数を定義します$a + bi$そして$c + di$。 交差項は実数成分と虚数成分の正確な組み合わせに依存するため、順序は重要です。 
2.恒等式を使用して実部を計算します$ac - bd$。 これは、実数部の積を結合し、虚数部の積を減算することで得られます。$i^2 = -1$。 
3. 次を使用して虚数部を計算します。$ad + bc$。 これらは、実数成分と虚数成分が相互作用する交差項です。 
4. 両方の値を順番に出力します。最初に実数部、次に虚数部です。 

2 つの式に分離することで、実装中に中間の記号的推論が必要なくなります。 

### なぜ効果があるのか

 正確さは、加算に対する乗算の分配性と定義特性から直接導き出されます。$i^2 = -1$。 展開内のすべての積項は、実数-実数、実数-虚数、虚数-実数、お​​よび虚数-虚数の 4 つのカテゴリのいずれかに正確に分類されます。 最後のカテゴリでは符号の変更が導入され、実部の減算が行われます。 考えられるすべての組み合わせが 1 回だけ考慮されるため、結果の式は完全かつ正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c, d = map(int, input().split())
    real = a * c - b * d
    imag = a * d + b * c
    print(real, imag)

if __name__ == "__main__":
    solve()
```このソリューションは 4 つの整数を読み取り、必要な 2 つの式を直接計算して出力します。 境界が小さいため、乗算と加算の演算はすべて 32 ビット整数の範囲内で安全です。
