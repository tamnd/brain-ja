 ## 解決策
 ## 問題の理解

 平面内に一連の線が与えられ、それぞれは次の形式の方程式で記述されます。$y = A x + B$。 2 本の線は同じではないため、すべての線は平行か、または 1 回だけ交差します。 

タスクは、他の線との交差が最も少ない線を選択し、その最小数の交差を出力することです。 

より具体的に再構成すると、各線はセグメントのない無限の直線トラックとして考えられます。 2 つのトラックが平行でない場合は、必ず 1 点で交差します。 トラックごとに、それが交差する他のトラックの数をカウントし、すべてのトラックにわたってその数が最小になるようにします。 

入力サイズは最大です$N = 10^5$。 すべてのペアにわたる直接のペアごとの比較には、約$10^{10}$これは、数秒の制限時間内で実行可能な範囲をはるかに超えています。 これにより、二次アプローチは即座に除外されます。 

重要な構造上の観察は、交差点が斜面のみに依存していることです。 2行$A_1 x + B_1$そして$A_2 x + B_2$その場合にのみ交差する$A_1 \ne A_2$。 傾きが等しい場合、線は平行であり、交差することはありません。 

したがって、傾きのある線については、$A$、交差点の数は正確に$N - \text{count of lines with slope } A$。 

多くのラインが同じ傾きを共有する場合、エッジ ケースが発生します。 たとえば、すべての行が同じである場合、$A$の場合、交差は発生せず、答えはゼロになります。 傾きがすべて異なる場合、すべての線が他のすべての線と交差し、答えは次のようになります。$N - 1$。 多重度を無視する単純なアプローチでは、すべてのペアが交差すると誤って想定されてしまいます。 

## アプローチ

 ブルートフォース ソリューションでは、ラインのすべてのペアがチェックされ、傾きが異なるたびにカウンターが増加します。 これは、交差の定義を直接シミュレートするため、正しいです。 ただし、実行します$N(N-1)/2$比較すると、約 50 億の演算になります。$N = 10^5$、これは実行不可能です。 

重要な簡素化は、ジオメトリをカウントから分離することで実現します。 交差は切片にはまったく依存せず、傾きが一致するかどうかのみに依存します。 ペアを調べる代わりに、各傾斜が何回出現するかを知ることだけが必要です。 

傾きによって線をグループ化すると、各グループの交差数を一定時間で計算できます。グループの外側のすべての線は、グループ内のすべての線と交差します。 したがって、傾きの値については$A$、交差数は$N - f(A)$、 どこ$f(A)$はその周波数です。 

これにより、問題は整数に関する頻度をカウントするタスクに変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(N^2)$|$O(1)$| 遅すぎる |
 | 最適 (度数計数) |$O(N)$|$O(N)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適な戦略

 1. すべてのラインを読み取り、その傾きを抽出します。$A$。 インターセプト$B$2 つの線が交差するかどうかには影響しないため、無関係です。 
2. ハッシュ マップまたは辞書を使用して、各勾配が何回出現するかを数えます。 このステップでは、ジオメトリを周波数情報に圧縮します。 
3. 各傾斜グループについて、そのグループ内のラインの交差点の数を次のように計算します。$N - f(A)$。 これは、同じ傾きを持つ線だけが交差しないという事実に由来します。 
4. すべての勾配グループにわたってこれらの値の最小値を追跡します。 
5. この最小値を出力します。 

### なぜ効果があるのか

 各線は、同じ傾きの線と交差しないだけです。 他のすべての勾配では交差点が 1 つだけ保証されているため、勾配クラス内のすべてのラインの交差点数は同じになります。 したがって、オーバーラインを最小化することは、オーバースロープグループを最小化することと同等であり、次の式は$N - f(A)$すべての非並列インタラクションを正しくキャプチャします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    freq = {}

    for _ in range(n):
        a, b = map(int, input().split())
        freq[a] = freq.get(a, 0) + 1

    ans = n
    for cnt in freq.values():
        ans = min(ans, n - cnt)

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは各行を読み取り、交差部分では何の役割も果たさないため、切片をすぐに破棄します。 辞書`freq`各勾配を共有するラインの数を格納します。 

入力を処理した後、勾配グループを反復処理します。 各サイズのグループごとに`cnt`、計算します`n - cnt`、傾きが異なるためグループと交差する線の数を表します。 すべてのグループの最小値により、望ましい答えが得られます。 

微妙な点は、`ans`として`n`。 どの線でも交差できる最大数は次のとおりであるため、これは安全です。$n - 1$であり、それ以上の初期化は正確さに影響しません。 

## 実用的な例

 ### サンプル 1

 入力:```
3
1 2
1 3
2 3
```傾き周波数を計算します。 

| ステップ | 傾きの読み取り | 周波数マップ |
 | --- | --- | --- |
 | 1 | 1 | {1:1} |
 | 2 | 1 | {1:2} |
 | 3 | 2 | {1:2、2:1} |

 次に交差数を計算します。 

| 坂道 | 周波数 | 交差点 |
 | --- | --- | --- |
 | 1 | 2 | 3 - 2 = 1 |
 | 2 | 1 | 3 - 1 = 2 |

 最小値は 1 です。 

これは、平行線が交差しないため、同一の斜面をグループ化すると交差数が減少することを示しています。

 ## 特殊なケース

 すべての傾きが同一の場合、周波数マップには値を持つ単一のキーが含まれます。$N$。 次のような入力の場合:```
3
1 5
1 2
1 9
```アルゴリズムが計算します`n - cnt = 3 - 3 = 0`、交差が発生しないことを正しく反映しています。 

すべての傾きが異なる場合、各周波数は 1 になります。```
3
1 0
2 0
3 0
```各グループの収穫量`3 - 1 = 2`したがって、答えは 2 です。これは、すべての線が他のすべての線と交差するという事実と一致します。 

たとえば、支配的な傾斜グループがある場合:```
6
1 0
1 1
1 2
2 0
3 0
4 0
```最大のグループのサイズは 3 です。`6 - 3 = 3`。 このアルゴリズムは、最も密度の高い傾斜グループ内のラインが最も平行な競合を回避するため、交差を最小限に抑えることを正確に識別します。
