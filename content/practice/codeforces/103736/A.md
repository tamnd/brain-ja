 ## 問題の理解

 単一の小文字文字列が与えられ、固定パターンが何回出現するかを数えるように求められます。`"hznu"`内部の連続したブロックとして表示されます。 有効な出現はそれぞれ 4 文字すべてに順番に一致し、連続した位置を占める必要があるため、異なるインデックスで始まる限り重複が許可されます。 

入力長は最大 100,000 文字です。 このサイズでは、部分文字列を繰り返し構築したり、二次動作で位置ごとに重い処理を実行したりするアプローチは即座に除外されます。 考えられるすべての開始インデックスをチェックし、一定数の文字のみを検査するソリューションはすでに十分ですが、繰り返しの文字列スライスや完全な文字列に対するネストされたスキャンを伴うものは、慎重に実装された場合にのみ安全です。 

いくつかの特殊なケースが自然に現れます。 文字列は 4 文字未満にすることもできます。たとえば、`"hzn"`完全に一致するものは存在しないため、明らかに 0 を返す必要があります。 完全に繰り返される文字で構成される文字列。`"hhhhhhhh"`パターンには特定のシーケンスが必要なため、0 も返されます。 もう 1 つの微妙なケースは、パターンの重複です。たとえば、`"hzhznu"`位置 2 から始まる有効な出現が 1 つだけ含まれており、不適切にシフトされた不注意な部分文字列抽出は、実装が間違っていると境界を見逃したり、二重にカウントしたりする可能性があります。 

## アプローチ

 最も直接的なアイデアは、考えられるすべての開始インデックスを調べて、長さ 4 の部分文字列が以下に等しいかどうかを確認することです。`"hznu"`。 各位置 i について、文字 s[i]、s[i+1]、s[i+2]、および s[i+3] を比較します。 すべて一致する場合、答えをインクリメントします。 

この総当たりアプローチは正しいです。パターンのすべての出現はインデックス i で開始する必要があり、そのようなインデックスをすべてチェックすることで、有効な一致がスキップされないことが保証されます。 コストは、最大 n 個の位置をスキャンし、各位置で一定量の作業を実行することで発生し、直線的な時間が得られます。 すでに効​​率的ではありますが、s[i:i+4] のような部分文字列を繰り返し構築する単純なバリアントは、Python ではこの制約に対して依然として安全ですが、不必要なオーバーヘッドが生じます。 

パターンは非常に小さく固定されているため、KMP のような高度な文字列アルゴリズムは必要ありません。 重要な観察は、パターン マッチングが各インデックスでのローカル比較に帰着するということです。

 ## アルゴリズムのチュートリアル

 1. 入力文字列 s を読み取り、ターゲット パターンを次のように定義します。`"hznu"`。 パターンは固定されており、決して変更されないため、4 つの定数文字比較として扱うことができます。 
2. カウンタ変数をゼロに初期化します。 これにより、文字列全体で見つかった有効な一致の数が累積されます。 
3. 0 から len(s) - 4 までのすべてのインデックス i を反復します。 各インデックスは、完全な 4 文字一致の可能な開始位置を表します。 len(s) - 4 で停止します。これを超えるインデックスは 4 文字に収まらないためです。 
4. 各インデックス i について、部分文字列 s[i:i+4] を次と比較します。`"hznu"`。 それらが等しい場合、カウンタを 1 つインクリメントします。 この直接比較により、完全一致のみをカウントすることが保証されます。 
5. スキャン終了後、最終結果としてカウンタを出力します。 

### なぜ効果があるのか

 有効なすべての発生`"hznu"`は、文字列内の 1 つの開始インデックス i に正確に対応します。 アルゴリズムは、そのようなすべてのインデックスを正確に 1 回チェックし、必要なパターンに対して正確な同等性テストを実行します。 どの位置もスキップされず、無効な位置も等価性チェックを満たすことができないため、カウントは完全かつ正確です。 各開始インデックスは独立して評価されるため、重複は自然に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    s = input().strip()
    target = "hznu"
    n = len(s)
    ans = 0

    for i in range(n - 3):
        if s[i:i+4] == target:
            ans += 1

    print(ans)

if __name__ == "__main__":
    main()
```コードは文字列を読み取り、次の値までのみ繰り返します。`n - 3`これにより、範囲外のインデックスにアクセスしないことが保証されます。 スライス`s[i:i+4]`Python では境界近くであっても安全ですが、ループ境界により、有効な開始位置のみを考慮することが保証されます。 

比較は固定文字列に対して直接行われます。`"hznu"`これにより、余分な前処理が回避されます。 各反復では一定の作業が実行されるため、解は線形のままです。

 次のような短い文字列`"hzn"`ループ条件によって処理されます`range(n - 3)`となり、`range(-1)`反復回数がゼロになるため、出力は 0 のままになります。
