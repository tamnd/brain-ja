 ## 問題の理解

 抽象的に巨大な正の整数のセットが与えられます。最初は 1 から始まり、$10^{1000}$、これは計算目的では実質的に制限がありません。 毎日、ポジションのリスト$a_1, a_2, \dots, a_n$が提供され、現在ソートされた順序でそれらの位置を占めている要素をセットから削除するように求められます。 後$k$除去を適用してから何日か経った場合、セット内の残りの最小数を知りたいと考えます。 

主要な入力パラメータは次のとおりです。$n$、1 日あたりの削除リストの長さ、および$k$、両方とも到達する可能性がある日数$2 \cdot 10^5$。 さらに、削除リストの値は$a_i$と同じ大きさにすることができます$10^9$、およびテストケースの総数$t$までかもしれない$10^5$。 これらの制約により、セットを明示的に保存する単純なアプローチは除外されます。$S$または、インデックスによって反復処理します。$S$大きすぎるため、操作数が超過します$10^9$単一のテストケースで。 

エッジケースは、初日に削除された最初の要素が 1 である場合、または次の場合に発生します。$a_1$1の繰り返しです。 たとえば、次の場合$a = [1, 2, 3]$そして$k = 1$、セット$S$以前の削除を考慮せずに位置を値に静的にマッピングすると仮定する不用意なアプローチでは、不正確な答えが生成されます。 

もう一つの微妙なケースは次のような場合です。$a$1から始まる連続した数字が含まれており、$k$など非常に大きいです$a = [1, 2, 3]$そして$k = 10^5$。 残りの最小要素は次のように直線的に増加します。$k$によって生じたギャップの倍$a_n$そして、この成長要素が欠けていると、簡単にオフバイワンのミスにつながる可能性があります。 

## アプローチ

 ブルート フォース アプローチは概念的に単純です。次のことを表す動的配列を維持することによって、削除プロセスをシミュレートします。$S$で指定された位置にある要素を毎日削除します。$a$。 これは原理的には機能します。$a$厳密に増加しており、前日からの削除を反映するように調整できます。 ただし、これには、次のすべての要素を保存する必要があります。$S$、これは不可能です。または、仮想セットでインデックス演算を実行しますが、これには依然として関係があります。$O(n \cdot k)$操作。 最悪の場合、$n$そして$k$どちらも到達できる$2 \cdot 10^5$、与える$O(4 \cdot 10^{10})$テストケースごとの操作が遅すぎます。 

重要な洞察は、セット全体が必要ないということです。$S$明示的に。 数値を削除するときに最小の要素がどのように変化するかを追跡する必要があるだけです。 以来$a$は厳密に増加しており、残りの要素の位置は毎日、その前に発生した削除の数だけ事実上シフトされます。 これにより、最小要素の合計シフトを計算できます。$S$セット全体をシミュレートする必要はありません。 具体的には、その後$k$日の場合、残りの最小要素は、各削除をマッピングした場合に発生する個別の削除の合計数に 1 を加えたものになります。$a$一日中連続して。 これにより、問題は、連続する要素間のギャップの単純な線形累積に帰着します。$a$。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$、$k$、およびソートされたリスト$a$。 ソートは不要なので、$a$厳密に増加していることが保証されています。 
2. 変数を初期化する`shift`これにより、セットの開始から事実上「削除」されたポジションの数が累積されます。 
3. 各要素を反復処理します。$x$で$a$。 要素ごとに計算します`x - shift - 1`、より小さい数値の数を表します。$x$まだ削除されていないもの。 この値が 0 より大きい場合は、$x$は依然として変化に貢献しています。 
4. 数字が何個あるか数えます$a$毎日削除した後も残り、このプロセスを繰り返します$k$回、更新`shift`それに応じて。 概念的には、シフトは削除された一意の位置の数だけ増加します。これは、次の最後の要素に相当します。$a$加えて、以前の反復からの累積シフト。 
5.その後$k$日、残りの最小要素は`1 + total_shift`。 

このアルゴリズムが機能するのは、削除によって残りの要素の位置が常に予測可能な直線的な方法で移動されるためです。 の各要素$a$これはその後のすべての要素の位置に影響を与えます。$a$が厳密に増加している場合、これらの効果を直接合計することができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        shift = 0
        ans = 0
        for x in a:
            if x > shift:
                ans += 1
                shift += 1
        
        result = 1 + ans * k
        print(result)

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 の各要素によって引き起こされる実効シフトを計算します。`a`そして乗算します`k`すべての日を計算します。 微妙な部分は正しく計算されています`x - shift`そして増加する`shift`要素の削除が後続の位置にどのような影響を与えるかを反映します。
