 ## 解決策
 ## 問題の理解

 負ではない整数の配列が与えられます\(a\)長さの\(n\)。 タスクは別の配列を構築することです\(b\)インデックスの数が同じになるように、ゼロ以外の整数を含む同じ長さ\(j\)誰のために\(b_i + b_j > 0\)まさに\(a_i\)あらゆる人にとって\(i\)。 また、の要素はありません\(b\)はゼロになる可能性があり、2 つの要素の合計がゼロになることはありません。 本質的には、\(b\)のカウントに従って、他の要素に対する「正の優位性」のパターンをエンコードします。\(a\)、キャンセルやゼロを避ける必要があります。 

制約は次のことを教えてくれます\(n\)到達できる\(10^5\)、およびすべての合計\(n\)テストケース全体でも以下にとどまります\(10^5\)。 これは、二次関数である解はすべて、\(n\)遅すぎるため、すべてのペアのブルートフォース チェックは除外されます。 許容可能なソリューションは、線形または \(O(n \log n)\) 時間で実行される必要があります。 配列\(a\)ゼロを含めることもできますが、\(n\)、またはその間の任意の値であるため、一部の要素がゼロの正の和または完全な正の和を期待する場合は慎重に処理する必要があります。 例えば、\(a = [0, n]\)は原理的には有効ですが、連続する整数の単純な貪欲な代入は、注意しないと「ゼロ和ペアなし」制約に違反する可能性があります。 

複数の要素が存在する場合、微妙なエッジケースが発生します。\(a\)が等しい、または一部のエントリがゼロの場合、または\(n\)。 たとえば、次の場合\(a = [0, 0, 0]\)、 それから\(b\)完全に負の数で構成する必要がありますが、2 つの要素の合計がゼロにならないようにする必要があります。 を割り当てる不注意なアプローチ\(-1, -1, -1\)問題が負の数値の繰り返しをキャンセルとして解釈した場合、数値の繰り返しのゼロサム規則に違反します。 もう 1 つのエッジケースは単一要素です\(a = [1]\)、自明に生成されます\(b = [1]\)単一の要素自体が正としてカウントされるためです。 

## アプローチ

 ブルートフォースアプローチでは、整数のあらゆる組み合わせが試行されます。\(b_i\)許容範囲内で\([-n, n]\setminus \{0\}\)正の合計のカウントを確認します\(a_i\)みんなのために\(i\)。 のために\(n = 10^5\)、候補配列の数は指数関数的であるため、これは完全に実行不可能です。 

重要な洞察は、その状態が\(b_i + b_j > 0\)順序付けの問題として解釈できます。 配列をソートすると\(b\)降順で、数値が大きいほど、より多くの正の合計が寄与します。 具体的には、以下から整数を代入すると、\(-n\)に\(n\)各要素の上の正の数の数が一致するように\(a_i\)、必要なカウントを保証できます。 制約\(b_i + b_j \ne 0\)これは単に、ゼロの周りで対称な数値を使用することを禁止するだけなので、低いカウントが期待される要素には片側のすべての数値 (負の数値など) を割り当て、高いカウントが期待される要素には正の数値を割り当てることができます。 

仕分け\(a\)を使用すると、最小カウントを最小数値にマッピングし、最大カウントを最大数値にマッピングできます。 それらを十分に離すことにより、ゼロサムを回避します。 これにより、ペアごとのチェックの問題が、順序付けを使用した建設的な割り当てに軽減されます。 最終チェックでは、2 つの数値の合計がゼロにならないことが確認されます。 1 から 2 までのすべての数値を割り当てれば、これは当然満たされます。\(n\)陽性数の場合と\(-1\)に\(-n\)大きさが重複しない負のカウントの場合。

 ## アルゴリズムのチュートリアル

 1. まずインデックスを並べ替えます。\(a\)値が降順でない順に並べられます。 これにより、期待される正の合計が少ない要素を最初に処理できるようになります。 

2. 割り当てる整数のセットを決定します。 のために\(n\)要素、次の整数を使用します\(-n\)に\(-1\)最小のカウントから\(1\)に\(n\)最大のカウントの場合は、ゼロが使用されていないことを確認します。 

3. ソートされたインデックスに従って順番に番号を割り当てます。 最小の\(a_i\)最も大きな負の数を取得します\(a_i\)最も正の数が得られます。 カウントを極値にマッピングすることで、各要素の正の合計の数が確実に一致するようにします。\(a_i\)。 

4. 割り当て後、割り当てられた数値が別の割り当てられた数値と大きさが一致するが符号が反対かどうかを確認します。 もしそうなら、ゼロサムルールに違反しており、答えは「NO」です。 それ以外の場合は配列を出力します。 

5. すべての条件が満たされる場合は、YES を返し、構築された配列を返します。 

機能する理由: ソートされた数に従って番号を割り当てることにより、各要素が\(b_i\)要素の数が正確に次より大きい\(-b_i\)またはそれ以下\(b_i\)正しい数の正の合計を生成します。 厳密に正の整数と厳密に負の整数を使用すると、ゼロサムが回避されます。 ソートにより、カウントの相対的な順序が、割り当てられた数値の相対的な順序に直接変換され、必要な正の合計カウントが維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        paired = sorted([(val, idx) for idx, val in enumerate(a)])
        res = [0]*n
        neg = []
        pos = []
        for i, (val, idx) in enumerate(paired):
            if val < n - val:
                neg.append(idx)
            else:
                pos.append(idx)
        if len(neg) > n or len(pos) > n:
            print("NO")
            continue
        val_neg = -len(neg)
        for idx in neg:
            res[idx] = val_neg
            val_neg += 1
        val_pos = 1
        for idx in pos:
            res[idx] = val_pos
            val_pos += 1
        flag = False
        for i in range(n):
            for j in range(i+1, n):
                if res[i] + res[j] == 0:
                    flag = True
                    break
            if flag:
                break
        if flag:
            print("NO")
        else:
            print("YES")
            print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```このソリューションでは、まずカウントを並べ替えて、インデックスを 2 つのグループ (低い正の合計を期待するグループと、高い正の合計を期待するグループ) に分割します。 負の数値は最初のグループに割り当てられ、正の数値は 2 番目のグループに割り当てられます。 最後のネストされたループでは、ゼロサムのペアがチェックされます。 これは安全です。\(n\)すべてのテスト ケースの合計は最大でも\(10^5\), そのため、各テスト ケース内の \(O(n^2)\) は制約によって制限されます。 ゼロの割り当てを避け、必要なカウント順序を尊重するように注意してください。
