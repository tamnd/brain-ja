 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。`n`そして`k`。 長さのフィボナッチのような数列がいくつあるかを数えたい`k`値で終わる`n`。 

フィボナッチ類似数列は、最初の 2 つの値が任意の非負の整数であり、数列が非減少である必要がある点を除いて、フィボナッチ数列とまったく同じように構築されます。 あらゆるポジションについて`i > 2`、$$f_i = f_{i-1} + f_{i-2}.$$最後の要素は修正されています。$$f_k = n.$$私たちのタスクは、最初の 2 つの要素の選択肢の数が、すべての要件を満たす有効なシーケンスを生成する数を数えることです。 

制約が最初の手がかりです。 テスト ケースの数は次のように大きくなります。`2 · 10^5`、およびすべての合計`n`値も最大です`2 · 10^5`。 に比例した作業を実行するソリューション`n`テストケースごとは許容されますが、二次関数は何でも可能です`n`すぐには無理です。 

珍しい制約は、`k`と同じ大きさにすることができます`10^9`。 長さのシーケンスを明示的に構築するアルゴリズム`k`絶望的だ。 この解決策は、フィボナッチ数が非常に急速に増加するという事実を利用する必要があります。 

いくつかの特殊なケースは注目に値します。 

いつ`k`とても大きくて、`n`小さい場合は、まったく解決策がない可能性があります。 例えば：```
n = 3, k = 9
```関連する係数`f_k`最初の 2 つの要素は 9 位のかなり前に大きくなり、非負の開始値を使用して 3 を表すことができなくなります。 

いつ`k = 3`、再発により与えられる$$f_3 = f_1 + f_2.$$すべてのペア`(f1, f2)`合計付き`n`提供された作品`f1 ≤ f2`。 のために`n = 1`、 のみ`(0,1)`は有効なので、答えは`1`。 

もう 1 つの微妙なケースは、非減少条件を強制することです。 ペアは漸化式を満たし、次の結果を生成する可能性があります。`f_k = n`それでも失敗するのは、`f_1 > f_2`。 たとえば、導出された解が次の場合、`(3,1)`、後のすべての値が決定されたとしても、それは拒否されなければなりません。 

重要な観察は、一度、`f_1`そして`f_2`否定的ではなく、満足している`f_1 ≤ f_2`、以降の各期は自動的に非減少になります。 

## アプローチ

 最も直接的なアイデアは、考えられるすべてのペアを試してみることです`(f_1, f_2)`。 

すべての項は負ではないため、最終的な値は次のようになります。`n`、両方の開始値は最大でも`n`。 すべてのペアを列挙し、位置までのシーケンスを生成できます。`k`、最後の値が等しいかどうかを確認します`n`。 

これは正しいですが、遅すぎます。 がある`O(n²)`候補ペアがあり、それぞれに多くの反復ステップが必要になる場合があります。 と`n`まで`2 · 10^5`、このアプローチは完全に実行不可能です。 

次の観察は、すべてのフィボナッチ数列は最初の 2 つの値において線形であるということです。 

させて$$f_1=a,\qquad f_2=b.$$それから：$$f_3=a+b,$$

$$f_4=a+2b,$$

$$f_5=2a+3b,$$等々。 

係数自体はフィボナッチ数に従います。 一般的に、$$f_k = F_{k-2}a + F_{k-1}b,$$どこ$F_1=1, F_2=1$。 

問題全体は、次の非負の整数解を数えることになります。$$F_{k-2}a + F_{k-1}b = n,$$の対象となる$$a \le b.$$これは線形ディオファントス方程式になりました。 

もう 1 つの重要な観察は、次の制約から得られます。`n`。 フィボナッチ数を超えています`200000`わずか数十期の後に。 以来`n ≤ 200000`、いずれかの係数が より大きくなると、`n`、些細な可能性は最大でも 1 つありますが、通常はありません。 

実際、重要なのは最初の約 30 フィボナッチ数だけです。 大型の場合`k`、答えは自動的にゼロになります。 

各テスト ケースについて、関連する 2 つのフィボナッチ係数を計算し、すべての整数のペアをカウントできます。`(a,b)`方程式を満たし、`a ≤ b`。 

以来`n`小さいので、可能な限りすべてを反復します`b`値は十分に速いです。

 ## アルゴリズムのチュートリアル

 1. フィボナッチ数を超えるまで事前計算する`200000`。 

ずっと`n`値は最大でも`200000`、より大きなフィボナッチ数は有効な表現に参加することはできません。 
2. テストケースの場合`(n, k)`、係数を決定します。 

使用する$$f_k = F_{k-2}a + F_{k-1}b,$$係数が必要です`A = F_{k-2}`そして`B = F_{k-1}`。 
3. もし`k-1`事前に計算されたフィボナッチ数の範囲を超えた場合は、すぐに戻ります`0`。 

その時点で`B > 200000 > n`、自明でない表現は不可能になります。 
4. 可能なすべての値を列挙します。`b`。 

以来$$A a + B b = n,$$私たちはただ考慮する必要があるだけです$$0 \le b \le \left\lfloor \frac n B \right\rfloor .$$5. 各候補者について`b`、残りの値を計算します。$$rem = n - B b.$$もし`rem`で割り切れない`A`、整数なし`a`存在します。 
6. それ以外の場合は計算します$$a = \frac{rem}{A}.$$次の場合にのみ解決策を数えます`a ≤ b`。 
7. 合計カウントを出力します。 

### なぜ効果があるのか

 すべてのフィボナッチ数列は、最初の 2 つの要素によって一意に決定されます。 繰り返しを展開すると、`k`-番目の項はまさに$$F_{k-2}a + F_{k-1}b.$$したがって、すべての有効なシーケンスは 1 つの整数解に対応します。`(a,b)`その方程式の。 

逆に、負でないすべての整数解は、`a ≤ b`有効な非減少フィボナッチのようなシーケンスを生成します。 反復により非否定性が保たれるため、$$f_3=a+b \ge b,$$後続のすべての項は、少なくとも前の項と同じ大きさになります。 

アルゴリズムはこれらのペアを正確にカウントし、それ以外は何もカウントしないため、これは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Fibonacci numbers with F1 = 1, F2 = 1
fib = [0, 1, 1]
while fib[-1] <= 200000:
    fib.append(fib[-1] + fib[-2])

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())

    if k - 1 >= len(fib):
        print(0)
        continue

    A = fib[k - 2]
    B = fib[k - 1]

    ans = 0

    for b in range(n // B + 1):
        rem = n - B * b

        if rem % A != 0:
            continue

        a = rem // A

        if a <= b:
            ans += 1

    print(ans)
```最初のセクションでは、可能な最大値を超える点までのみフィボナッチ数を事前計算します。`n`。 係数が大きくなると有効な表現に寄与できないため、これで十分です。 

テストケースごとに係数を取得します。`A = F_{k-2}`そして`B = F_{k-1}`。 もし`k`が大きすぎてこれらの係数が事前に計算された範囲を超えている場合、答えはすぐにゼロになります。 

ループオーバー`b`ソリューション内に現れる可能性のあるすべての非負の値をチェックします。 一度`b`が固定されている場合、方程式によって決定されます`a`ユニークに。 割り算は、その値が整数であるかどうかをチェックします。 

条件`a <= b`まさに非減少要件です。 反復によりその後自動的に増加項が生成されるため、追加の配列検証は必要ありません。 

Python の整数は任意の精度であるため、オーバーフローが問題になることはありません。 最大の算術値はまだほんのわずかです`200000`ともかく。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    fib = [0, 1, 1]
    while fib[-1] <= 200000:
        fib.append(fib[-1] + fib[-2])

    t = int(input())
    ans = []

    for _ in range(t):
        n, k = map(int, input().split())

        if k - 1 >= len(fib):
            ans.append("0")
            continue

        A = fib[k - 2]
        B = fib[k - 1]

        cur = 0
        for b in range(n // B + 1):
            rem = n - B * b
            if rem % A == 0 and rem // A <= b:
                cur += 1

        ans.append(str(cur))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out

    solve()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.getvalue().strip()

 次のことを考慮してください。```
