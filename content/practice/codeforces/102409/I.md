 ## 問題の理解

 ディエゴポリスにはちょうど (N=5{,}000{,}000) 人がいます。 各人は確率 (1/2) でスナップから独立して生き残ります。 (X) を生存者の数とすると、(X) はパラメータ (N) と (1/2) の二項分布に従います。 

すべてのテスト ケースに対して、しきい値 (K) が与えられ、少なくとも (K) 人が生き残る確率が必要です。 

[
 P(X\ge K)。 
】

 答えは浮動小数点確率である必要はありません。 代わりに、剰余 (M=10^9+7) を実行し、除算を逆剰余による乗算として扱います。 元の問題では人口が 500 万人に固定され、最大 (10^5) 個のクエリが許可されます。 

(N) のサイズが重要な制約です。 考えられるすべての結果に対して少量の作業を実行する計算では、すでに約 500 万回の操作が実行されており、これは一度としては妥当ですが、(10^5) クエリに対して個別にそれを実行すると、およそ (5\times10^{11}) の作業となり、まったく実行不可能です。 各クエリに対して個別に二項合計を明示的に計算するアプローチは除外されます。 コストのかかる作業をすべてのクエリで共有する必要があります。 

不注意な実装が失敗する可能性がある境界ケースがいくつかあります。 (K=0) の場合、イベントは確実であるため、答えは正確に (1) になります。 例えば、```

反対の極端な場合、(K=N) は全員が生き残らなければならないことを意味します。 したがって、答えは単純です

## アプローチ

 直接的なアプローチは、二項分布から直接導き出されます。 正確に (k) 人の生存者がいる確率がある

 [
 P(X=k)=\binom Nk\frac1{2^N}。 
】

 したがって、少なくとも (K) 人の生存者を求めるクエリは、次の合計によって答えることができます。 

[
 \sum_{k=K}^{N}\binom Nk\frac1{2^N}。 
】

 考えられる生存者数は相互に排他的であり、あらゆる結果をカバーするため、これは正しいです。 問題は繰り返し作業の量です。 クエリが (K=1) を要求する場合、およそ 500 万の用語を処理することになります。 これを (10^5) クエリに対して実行すると、最大 (5\times10^{11}) 項が得られ、1 秒の制限をはるかに超えます。 

重要な観察は、二項確率が独立した値ではないということです。 連続した用語には単純な比率があります。 

# \frac{\binom Nk}{\binom N{k-1}}

 \frac{N-k+1}{k}。 
】

 したがって、生存者がゼロになる確率がわかれば、

 [
 P(X=0)=\frac1{2^N}、
 】

 1 つのモジュラー乗算と 1 つのモジュラー逆数を使用して、後続のすべての確率を生成できます。 

クエリに関しては、もう 1 つ有益な観察があります。 (K) のすべてのクエリ値を並べ替えると、末尾の確率を維持しながら、最小のしきい値から最大のしきい値まで移動できます。 現在わかっていると仮定します

 [
 S_k=P(X\ge k)。 
】

 それから

 [
 S_{k+1}=S_k-P(X=k)。 
】

 したがって、しきい値を 1 つ進めると、現在の確率質量のみがかかります。 すべてのクエリにわたって、要求された最大値 (K) まで、分布を複数回トラバースする必要はありません。 

残りの問題は、すべての逆モジュラー (1^{-1},2^{-1},\ldots,m^{-1}) を取得する方法です。ここで (m) は、クエリされた最大のしきい値です。 (m<10^9+7) であるため、すべての分母は (M) を法として可逆です。 次を使用して、線形時間で逆関数を生成できます。 

M-\左\l階\frac ミ\右\r階
 \operatorname{inv}[M\bmod i]\pmod M.
 】

 Python の場合、500 万個の通常の整数を保存するとメモリを大量に消費するため、実装では`array('I')`、各モジュール値を 4 バイトに格納します。 したがって、500 万のエントリには約 20 MB が必要になります。 

ブルートフォースアプローチと最適化アプローチは次のように要約できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |

 | 最適 | (O(N+T\log T)) | (O(N+T)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのクエリを読み、元の位置を覚えておいてください。 クエリを並べ替えると、(K) の昇順に回答できるため、各二項確率は 1 回だけ生成されます。 
2. (m) をクエリの最大値 (K) とします。 より大きなしきい値を求めるクエリはないため、(m) を超える確率を生成する理由はありません。 
3. (1) から (m) までの逆モジュラーを構築します。 (m<10^9+7) であるため、この範囲内のすべての整数は逆剰余を持ちます。 
4. コンピューティング

 [
 p_0=P(X=0)=2^{-N}\pmod M.
 】

 Python の 3 つの引数`pow`べき乗剰余を効率的に計算するため、(N) 回反復する必要はありません。 

1. テール確率を次のように初期化します。 

[
 S_0=P(X\ge0)=1。 
】

 も保管してください`cur = 0`そして`p = p_0`、 どこ`p`(P(X=\text{cur})) を表します。 

1. ソートされたクエリを処理します。 次のクエリで (K) が要求された場合は、次のクエリから繰り返し移動します。`cur`(K)へ。 移動するたびに、現在の末尾から (P(X=\text{cur})) を減算し、増分します。`cur`、そして次の方法で新しい確率を生成します

 P(X=\text{cur}-1)
 \frac{N-\text{cur}+1}{\text{cur}}。 
】

 インクリメントする前に減算する理由は、(X=cur) で確率質量を削除することによって (P(X\ge cur)) が正確に (P(X\ge cur+1)) になるためです。 

1. 1回`cur == K`、維持される尾は正確に (P(X\ge K)) です。 元のクエリ位置に保存します。 
2. Print the answers in input order rather than sorted order. Duplicate thresholds need no special handling because they are simply answered from the same maintained state.

 ### なぜ効果があるのか

 The invariant is that immediately before answering a query with threshold`cur`、`tail`(P(X\ge cur)) に等しい、一方`pmf`(P(X=cur)) に等しい。 (cur) から (cur+1) に移動すると、尾部から消える必要がある 1 つの確率質量が正確に減算されるため、不変式は true のままになります。 の再発`pmf`連続する二項係数には比 ((N-k+1)/k) があるため、正確な次の二項確率が生成されます。 不変式は (P(X\ge0)=1) および (P(X=0)=2^{-N}) で始まるため、要求されたすべてのテール確率は正しいことになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from array import array

MOD = 1_000_000_007
N = 5_000_000

def solve():
    t = int(input())
    queries = [int(input()) for _ in range(t)]

    indexed = sorted(enumerate(queries), key=lambda x: x[1])
    max_k = indexed[-1][1]

    # inv[i] = modular inverse of i modulo MOD.
    inv = array('I', [0]) * (max_k + 1)
    if max_k >= 1:
        inv[1] = 1
        for i in range(2, max_k + 1):
            inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # P(X = 0) = 1 / 2^N.
    pmf = pow(pow(2, N, MOD), MOD - 2, MOD)

    # tail = P(X >= cur)
    cur = 0
    tail = 1

    ans = [0] * t

    for idx, k in indexed:
        while cur < k:
            # Remove P(X = cur), so tail becomes P(X >= cur + 1).
            tail -= pmf
            if tail < 0:
                tail += MOD

            cur += 1

            # P(X = cur) =
            # P(X = cur - 1) * (N - cur + 1) / cur
            pmf = pmf * (N - cur + 1) % MOD
            pmf = pmf * inv[cur] % MOD

        ans[idx] = tail

    sys.stdout.write('\n'.join(map(str, ans)))

if __name__ == "__main__":
    solve()
