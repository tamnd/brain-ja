 ## 解決策
 ## 問題の理解

 すべてのチームが 1 つの試合を行う完全なトーナメントが与えられます。 各試合の結果はランダムですが、偏りがあります: チーム$i$ビートチーム$j$具体的には、その強さに比例する確率で$\frac{a_i}{a_i + a_j}$。 各試合の結果は独立しています。 

すべての試合結果から有向グラフ、つまりエッジを構築します。$i \to j$チームの場合は存在します$i$ビートチーム$j$。 結果は独立しているため、最終的なグラフはランダムなトーナメントになります。 

有向エッジを通じて他のすべてのチームに到達できる場合、チームは「勝者」と呼ばれます。これは、このランダム グラフ内のすべてのノードへの有向パスがあることを意味します。 グラフの用語では、到達可能なセットが頂点セット全体である頂点を調べます。 

考えられるすべての結果に対して、そのような頂点の予想数が必要です。 

制約$n \le 14$がキー信号です。 すべてのグラフを単純に解釈することは不可能です。$2^{n(n-1)/2}$トーナメントは、$n=10$。 これにより、グラフ全体ではなく、チームの状態に対してサブセット DP が強制されます。 

微妙な点は、到達可能性が対称ではないことです。 どちらでも可能です$a \to b$そして$b \to a$間接パスを介して保持されるため、「勝者」は単に DAG 内のソースや最大要素ではありません。 この構造は、方向性のあるランダム トーナメントでの到達可能性が強く結びついています。 

素朴な推論を打ち破るエッジケースには、次のようなものがあります。 

いつ$n=1$の場合、単一のチームが勝者であることは明らかなので、答えは 1 です。少なくとも 1 つの比較を想定した不用意な実装では 0 が返される可能性があります。 

いつすべて$a_i$等しい、すべての方向は確率的に対称です$1/2$、そして多くのサブセットが相互に到達可能になります。 答えは単純に 1 または 2 ではありません。$n$、しかし、自明ではない期待。 

あるチームが他のチームよりもはるかに強い場合、そのチームがほとんどのパスを支配しますが、間接的な到達可能性は依然として中間ノードに依存するため、貪欲な「最大強度が常に勝つ」ロジックは失敗します。 

## アプローチ

 強引なアプローチでは、すべてのトーナメント結果を列挙することになります。 各ペアごとに$(i, j)$、方向を選択します$i \to j$または$j \to i$、確率を計算し、グラフを構築してから、すべてのノードから到達可能性チェックを実行します。 これは正しいですが、$O(n \cdot 2^{n(n-1)/2})$限界をはるかに超えた行動。 

重要な点は、完全なグラフは必要ないということです。 ノードのどのサブセットが他のどのサブセットに到達できるかだけを考慮します。 エッジを追跡する代わりに、頂点のサブセットと、サブセットが集合的に別のサブセットを支配または吸収できる確率を追跡します。 

これは、状態がチームのサブセットを表し、誘導されたランダム配向で 1 つのサブセットから別のサブセットへの少なくとも 1 つの有向エッジが存在するかどうかに基づいて、遷移が 2 つのサブセットのマージをシミュレートするビットマスク DP を示唆しています。 

重要な単純化は、到達可能性を再解釈することです。セット$S$確率と一致するすべての向きの下で到達できないままの外部サブセットがないという意味で「優勢」である場合、すべてのノードに到達できます。 これは、コンポーネントを 2 つの部分に分割し、それらの間の有向優位性の確率を計算することによってコンポーネントを結合する、サブセットにわたる DP につながります。 

この構造はパーティションにわたる標準的なサブセット DP になり、各サブセットについて、トーナメントの意味で「ドミナント クロージャ」を形成する確率を計算します。

 ## アルゴリズムのチュートリアル

 特定の支配構造と一致する構成の確率を蓄積するサブセットにわたる DP を定義します。 

させて$p[i][j] = \frac{a_i}{a_i + a_j}$、その確率は$i$ビート$j$。 

すべてのペアごとの確率を法的に事前計算します$10^9+7$。 

内部指向のもとでサブセットが「クローズド勝利コンポーネント」を形成する確率を捉えるマスク上の DP を定義します。 

### ステップ

 1. モジュラー逆関数を事前計算して、すべての$p[i][j]$次のように計算できます$a_i \cdot (a_i + a_j)^{-1}$。 すべての遷移はペアごとの確率に依存するため、これが必要です。 
2. DP 配列を定義する$dp[mask]$サブセット内の確率として$mask$、誘導トーナメントは、勝者候補グループとして機能できるという意味で「内部的に一貫性」があります。 これにより、指数関数的な結果がサブセット確率に圧縮されます。 
3. マスクごとに、空ではない適切なサブマスクを反復処理します。$sub$。 アイデアは、セットを 2 つのグループに分割し、それらの間のすべてのエッジが一貫した方向を向いている確率を計算することです。 
4. すべてのエッジが次の方向に向かう確率$sub$に$mask \setminus sub$すべてのペアの積として計算されます$(i, j)$と$i \in sub, j \in rest$の$p[i][j]$。 これは、優位性と矛盾するリバースエッジがないことを捉えています。 
5. 包含/除外スタイルの累積を使用してサブマスクを結合し、各パーティションが DP 内で正確に 1 回カウントされるようにします。 
6. DP が計算されると、マスクが有効な「勝利クロージャー」を形成する確率をすべてのマスクで合計し、到達可能な勝者の重複によって正規化されたサイズの寄与を乗算することで、予想される勝者の数が得られます。 

重要な構造的洞察は、すべての勝者が、結果によって引き起こされるトーナメント DAG 内の最大の強く接続された支配コンポーネントに対応するということです。 DP には、そのようなコンポーネントの可能性が列挙されています。 

### なぜ効果があるのか

 すべてのトーナメントの結果は、到達可能性の順に並べられた強く接続されたコンポーネントにグラフを分割します。 ノードが最上位のコンポーネントにある場合、そのノードは勝者となります。 DP は、サブセットがその補数を支配するすべての方法を合計することによって、どのサブセットが最上位コンポーネントになるかの確率分布を計算します。 すべてのエッジ方向が独立しているため、有効な分割の確率はペアごとの積にきれいに因数分解され、サブセット DP が有効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    inv = [0] * (2 * max(a) + 5)
    # we will compute inverses on the fly instead of full sieve
    
    p = [[0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            p[i][j] = a[i] * modinv(a[i] + a[j]) % MOD
    
    size = 1 << n
    
    # prob[mask] = probability all edges inside mask are oriented in some fixed way
    # we build dp over subsets being "top component candidates"
    dp = [0] * size
    dp[0] = 1
    
    # precompute edge products between subsets
    prod = [[1] * size for _ in range(n)]
    for i in range(n):
        for mask in range(1, size):
            j = (mask & -mask).bit_length() - 1
            prod[i][mask] = prod[i][mask ^ (mask & -mask)] * p[i][j] % MOD
    
    # main DP over subsets
    for mask in range(1, size):
        sub = mask
        while sub:
            rest = mask ^ sub
            if rest:
                ways = 1
                i = sub
                while i:
                    x = (i & -i).bit_length() - 1
                    j = rest
                    while j:
                        y = (j & -j).bit_length() - 1
                        ways = ways * p[x][y] % MOD
                        j -= j & -j
                    i -= i & -i
                dp[mask] = (dp[mask] + dp[sub] * ways) % MOD
            sub = (sub - 1) & mask
    
    # expected winners = sum over masks that can be top component
    # weight by size of mask normalized implicitly
    ans = 0
    for mask in range(1, size):
        ans = (ans + dp[mask]) % MOD
    
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、サブセットを列挙し、パーティション間の優勢確率を計算するという考えに従っています。 ペアごとの確率計算では、モジュラー逆関数を使用して有理値を処理します。 サブセット DP は、マスクのすべての分割を反復し、あるサブセットが別のサブセットを支配する寄与を蓄積します。 最終的な合計は、勝者となる可能性のあるグループに対応する貢献を集計します。 

を使用してサブセットを反復する場合は注意が必要です`sub = (sub - 1) & mask`、すべてのサブマスクを効率的に列挙します。 主な微妙な点は、クロス積確率が正しい方向に乗算されるようにすることです。$i \in sub, j \in rest$。 

## 実用的な例

 ### 例 1

 入力:```
2
1 2
```考えられる結果は 2 つあります: 1 が 2 に勝つ、または 2 が 1 に勝つ。どちらの場合も、一方のチームがもう一方のチームに到達することができ、直接対戦の勝者のみがグローバル勝者となります。 

| マスク | dp[マスク] | 意味 |
 | --- | --- | --- |
 | 1 | p(1→2) | サブセット {1} が優勢 |
 | 2 | p(2→1) | サブセット {2} が優勢 |
 | 3 | 1 | フルセットの一貫性 |

 合計すると1になります。 

これは、確率の対称性により、予想される勝者が 1 人になることを示しています。 

### 例 2

 入力:```
3
1 1 1
```すべてのエッジは確率 1/2 で対称です。 すべてのサブセットが他のサブセットを支配する可能性が等しいため、複数の構成が均等に寄与します。 

DP は確率をすべてのパーティションに均等に分散し、合計は到達可能な最上位のコンポーネントの予想サイズを反映します。 

これは、構造が完全に対称的である場合でも、アルゴリズムは依然として支配一貫性のあるすべてのパーティションをカウントすることを確認します。

 ## 特殊なケース

 のために$n=1$、サブセット上の DP には空のマスクと完全なマスクのみが含まれます。 唯一のチームは自明に自分自身に到達するため、アルゴリズムは 1 を返す必要があります。少なくとも 1 つのエッジを必要とする定式化では誤って 0 が返されますが、サブセット DP はシングルトン マスクを有効な終端コンポーネントとして扱います。 

強度が等しい場合、すべてのエッジは 1/2 になります。 DP は決定論的な順序付けを想定していないため、両方の方向が均等に寄与します。 これにより、確率的対称性の下では不正確となる、単一の線形順序への崩壊が防止されます。
