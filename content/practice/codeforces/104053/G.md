 ## 問題の理解

 2 人のプレーヤーが、選択した整数を掛け合わせて数値を繰り返し増やします。 アリスコントロールセット$A$、ボブコントロールセット$B$。 どちらも値から始まります$\alpha = 1$そして$\beta = 1$。 アリスが動くたびに、彼女は要素を選択します。$A$そしてそれを乗算します$\alpha$。 ボブが動くたびに、彼は要素を選択します。$B$そしてそれを乗算します$\beta$。 このプロセスは、アリスから開始して永遠に交互に行われます。 

ボブの勝利条件はシンプルですが、時間の経過とともにグローバルになります。$\alpha$分割する$\beta$, ボブはすぐに勝ちます。 アリスには直接的な勝利条件はありません。 彼女の目標は、ボブがこの可分性条件を強制できる状態に決して到達しないようにすることだけです。 

要素のサブセットを削除することができます。$A$試合が始まる前に。 要素を削除した後、残りの数字でゲームがプレイされます。$A$。 サブセットを削除しても、アリスが最適なプレイの下で負けを回避できるという事実が変わらない場合、そのサブセットは有効であると呼ばれます。 有効なサブセットがいくつあるかを数えなければなりません。 

制約は十分に小さいため、因数分解と要素ごとの推論が実行可能です。 どちらのセットにも最大 500 個の数値が含まれており、各数値は最大 500 です。これは、乗算のすべての相互作用が素数を介してきれいに分解されるため、素因数分解が正しい言語であることを直ちに示唆します。 ゲームプレイは無限であり、選択肢の分岐は毎ターン指数関数的に行われるため、ゲームプレイを直接シミュレートしようとするソリューションは遅すぎます。 

微妙なエッジケースは、何も削除しなくてもアリスがすでに負けている場合です。 たとえば、ボブが保証できる場合$\alpha \mid \beta$戦略に関係なく最初からアリスを助けるサブセットはなく、答えはゼロでなければなりません。 もう 1 つの特殊なケースは、次の空のサブセットです。$A$。 すべてを取り除くと、$\alpha$永久に 1 のままなので、最初はボブが勝つのは自明です。$\beta$も 1 から始まるため、割り算は即時に行われます。 これは、空のサブセットは決して有効ではないことを意味します。 

## アプローチ

 ゲームの素朴な解釈は、最適なプレイをシミュレートしようとします。 アリスとボブはあらゆる段階で、自分たちの目的を最大化する動きを選択します。 ブルートフォース状態では、現在の値を追跡する必要があります。$\alpha$そして$\beta$、これは無制限に乗算的に増加し、両方のプレイヤーの将来のすべての選択も考慮されます。 値を圧縮しても分岐要素は残る$|A| \cdot |B|$動きごとに、ゲームには自然終了の制限はありません。 これにより、直接的なゲーム シミュレーションが不可能になります。 

重要な観察は、素指数の観点から割り算条件を書き直すことから得られます。 すべての数値を 500 までの素数の指数のベクトルとして書き込みます。$\alpha \mid \beta$は指数を持つすべての素数と等価です$\alpha$それを超えないこと$\beta$。 乗算では指数が加算されるため、移動するたびにこれらのベクトルの 1 つが加算されます。 

ここで、ゲームは複数の独立した座標をめぐる競争になります。 各ターンで、アリスは次のベクトルを 1 つ追加します。$A$、ボブはから 1 つを追加します$B$。 要素を再利用できるため、長期的な動作は、どのベクトルが各方向の成長を最大化するかによって決まります。 固定素数の場合$p$、最良の寄与者を繰り返し選択することが混合戦略を支配するため、要素によって寄与される最大指数のみが漸近的に重要になります。 

これにより、ゲームは素数ごとに比較するだけになります。$p$、アリスとボブが利用できる最大指数。 ボブの最大値が少なくともすべての素数に対するアリスの最大値である場合、ボブは最終的にすべての座標でアリスと一致または超えることができ、強制的に割り切れます。 それ以外の場合、アリスが厳密に大きい最大寄与者を持つ素数が存在する場合、アリスはその座標を永遠に先に保持し、ボブの勝利条件を妨げることができます。 

この特徴付けが利用可能になると、サブセットの問題は純粋に構造的なものになります。 からの要素の削除$A$素数あたりのアリスの最大指数を変更します。 サブセットが有効になるのは、削除後もアリスの残りの最大値がボブの固定最大値を超える素数が少なくとも 1 つ存在する場合です。 

これにより、問題はすべての「勝ち素数」の破壊を回避するサブセットをカウントすることに変わります。

 ## アルゴリズムのチュートリアル

 まず、最大 500 までのすべての数値の素因数分解を事前計算し、各数値を指数のベクトルとして表現できるようにします。 

1. すべての数値を因数分解する$B$、各素数を計算します$p$のすべての要素の中で現れる最大の指数$B$。 これに電話してください$maxB[p]$。 これは、各コーディネートにおけるボブの可能な限り最も強力な成長を捉えています。 
2. すべての数値を因数分解する$A$、同様に計算します$maxA[p]$、フルセットに存在する最大指数$A$。 これにより、削除前にアリスが各素数方向でグローバルに進んでいるかどうかがわかります。 
3. すべての素数の場合$p$、$maxA[p] \le maxB[p]$の場合、ボブはすでにすべての座標でアリスを支配しているか、アリスと一致しています。 この場合、アリスはフルセットであってもアドバンテージを維持できないため、すべてのサブセットが負けており、答えはゼロになります。 
4. それ以外の場合は、どの要素が$A$「安全」です。 すべての素数の場合、要素は安全です$p$、その指数は超えません$maxB[p]$。 これらの要素は、ボブの能力を超えて座標を個別にプッシュすることはできません。 
5. しましょう$k$安全な要素の数になります。 安全な要素のみで構成されるサブセットは、アリスがボブを超える素数を作成できないため、そのようなサブセットはすべてアリスの位置を失います。 
6. したがって、無効なサブセットは、安全な要素のすべてのサブセットです。$2^k$。 サブセットの総数は$2^{|A|}$、つまり有効なサブセットは等しい$2^{|A|} - 2^k$、剰余を取得$10^9+7$。 

これが機能する理由は、長期支配条件では素数ごとの最大指数のみが重要であるためです。 少なくとも 1 つの素数でボブの境界を超える要素は、その座標でアリスの優位性を潜在的に維持するのに十分であるため、そのような要素をすべて削除すると、彼女の唯一の勝利方向が破壊されます。 逆に、そのような要素を少なくとも 1 つ保持すると、アリスが無限に先に進むことができる少なくとも 1 つの座標が保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXV = 500

# sieve for smallest prime factor
spf = list(range(MAXV + 1))
for i in range(2, MAXV + 1):
    if spf[i] == i:
        for j in range(i * i, MAXV + 1, i):
            if spf[j] == j:
                spf[j] = i

def factor(x):
    res = {}
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        res[p] = cnt
    return res

n, m = map(int, input().split())
A = list(map(int, input().split()))
B = list(map(int, input().split()))

maxB = {}
for b in B:
    f = factor(b)
    for p, c in f.items():
        maxB[p] = max(maxB.get(p, 0), c)

maxA_full = {}
for a in A:
    f = factor(a)
    for p, c in f.items():
        maxA_full[p] = max(maxA_full.get(p, 0), c)

# check if Alice is already doomed
alice_wins_somewhere = False
for p, v in maxA_full.items():
    if v > maxB.get(p, 0):
        alice_wins_somewhere = True
        break

if not alice_wins_somewhere:
    print(0)
    sys.exit()

maxB_default = lambda p: maxB.get(p, 0)

safe = 0
for a in A:
    f = factor(a)
    ok = True
    for p, c in f.items():
        if c > maxB_default(p):
            ok = False
            break
    if ok:
        safe += 1

ans = (pow(2, n, MOD) - pow(2, safe, MOD)) % MOD
print(ans)
```この実装は、最小の素因数ふるいに依存して、すべての数値を迅速に因数分解します。 ここではトライアル分割を繰り返しても十分高速ですが、構造化が不十分で推論が難しくなるため、これが必要です。 

ボブの素数ごとの最大値を一度計算し、それらを固定しきい値として扱います。 次に、それぞれの要素$A$素指数をこれらのしきい値と比較することによって、安全か安全でないかが分類されます。 最後の組み合わせによる減算は、サブセットのカウントから直接行われます。 

微妙な実装の詳細は、フルセットでもアリスに勝ち素数がない場合の早期終了です。 この場合、サブセットは結果を変更できないため、問題ステートメントではゼロを返す必要があります。 

## 実用的な例

 ### 例 1

 入力:```
2 3
2 6
6 7 8
```ボブの最大値を計算します。$6 = 2 \cdot 3$、$7$、$8 = 2^3$。 それで$maxB[2]=3$、$maxB[3]=1$、$maxB[7]=1$。 

アリスにとっては、$2$与える$2^1$、$6$与える$2^1 \cdot 3^1$、 それで$maxA[2]=1$、$maxA[3]=1$。 アリスはどの全盛期でもボブを超えることはなく、すでに支配されています。 アルゴリズムは 0 を出力します。 

これは早期終了のケースを示しています。 

### 例 2

 次のことを考慮してください。```
2 2
4 9
2 3
```ボブは持っています$2^1$そして$3^1$、 それで$maxB[2]=1$、$maxB[3]=1$。 アリスは$4=2^2$、$9=3^2$、つまり、彼女は両方の座標に勝利素数を持っています。 

安全な要素とは、ボブの最大値を超えない要素です。 4も9も安全ではないので、$k=0$。 サブセットの合計は 4 で、無効なサブセットは 1 (空のセット) なので、答えは 3 です。 

これは、純粋に要素の分類を通じてサブセットがどのようにカウントされるかを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from math import prod

    MOD = 10**9 + 7
    MAXV = 500
    spf = list(range(MAXV + 1))
    for i in range(2, MAXV + 1):
        if spf[i] == i:
            for j in range(i * i, MAXV + 1, i):
                if spf[j] == j:
                    spf[j] = i

    def factor(x):
        res = {}
        while x > 1:
            p = spf[x]
            c = 0
            while x % p == 0:
                x //= p
                c += 1
            res[p] = c
        return res

    n, m = map(int, input().split())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))

    maxB = {}
    for b in B:
        f = factor(b)
        for p, c in f.items():
            maxB[p] = max(maxB.get(p, 0), c)

    maxA = {}
    for a in A:
        f = factor(a)
        for p, c in f.items():
            maxA[p] = max(maxA.get(p, 0), c)

    if all(maxA.get(p, 0) <= maxB.get(p, 0) for p in maxA):
        return "0"

    safe = 0
    for a in A:
        f = factor(a)
        ok = True
        for p, c in f.items():
            if c > maxB.get(p, 0):
                ok = False
                break
        if ok:
            safe += 1

    return str((pow(2, n, MOD) - pow(2, safe, MOD)) % MOD)

 ## 特殊なケース

 アリスが削除前であってもボブを超える素数を持たない場合、フルセットはすでに負けています。 のような入力の場合$A = [6]$、$B = [6]$、両方とも同一の指数プロファイルを持ちます。 アルゴリズムは計算します$maxA[p] \le maxB[p]$すべての素数に対して、すぐにゼロを返します。 これは、削除がなくても Bob が即座に勝利するという事実と一致します。 

のすべての要素が$A$安全です、答えは$2^{|A|} - 2^{|A|} = 0$。 たとえば、すべての場合$a_i$は小さく、すべての素数でボブによって支配されていますが、すべてのサブセットは依然として負けています。 すべての要素が安全性チェックに合格するため、安全カウント メカニズムはこれを正確に捕捉します。
