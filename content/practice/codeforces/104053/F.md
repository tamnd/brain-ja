 ## 問題の理解

 係数に対して定義された関数が与えられています$m$: 線形合同式を見てみましょう$$a x \equiv b \pmod m$$そして定義します$f(a,b,m)$最小の非負の整数として$x$それを満たすか、または$0$解決策が存在しない場合。 テストケースごとに、次の合計を計算する必要があります。$f(a,b,i)$すべてのモジュラスにわたって$i$から$1$に$n$、剰余を取得$998244353$。 

したがって、1 つの合同式を解く代わりに、係数だけが変化する一連の合同式を繰り返し解いています。 係数$a$そして右側$b$固定したままにしておきます$m$までの範囲$10^{18}$。 これにより、すべての反復処理が即座に除外されます$m$、さえ$10^7$テストケースごとの操作はすでに遅すぎるでしょう、そしてここでは$n$天文学的に大きくなる可能性があります。 

重要な構造上の困難は、ソリューションの存在と価値が以下に依存することです。$\gcd(a,m)$。 もし$\gcd(a,m)$分けない$b$、答えの寄与はゼロです。 それ以外の場合、解はモジュロで一意に決定されます。$m / \gcd(a,m)$、最小の非負の解は、縮小された方程式から導出されたモジュラー逆数式です。 

微妙なエッジケースが現れるのは、$m = 1$。 合同は常に自明に真ですが、解空間は崩壊し、最小の非負の解は常に$0$、これは定義と一致しています。 

もう 1 つの重要な障害モードは、解決策が存在する場合は常に次のように記述できると仮定することから生まれます。$b \cdot a^{-1} \bmod m$。 これは次の場合にのみ有効です。$\gcd(a,m)=1$。 たとえば、次の場合$a=2$、$b=2$、$m=4$であれば、解決策は存在しますが、$a^{-1}$モジュロ$4$は存在せず、誤って削減すると無効な逆数が発生します。

重要な観察は、構造が次のもののみに依存しているということです。$\gcd(a,m)$そして低減された弾性率では$m/g$。 すべてを繰り返すのではなく$m$の値によってグループ化します。$g = \gcd(a,m)$。 そのようなグループごとに、次のように書きます。$m = g \cdot k$、 どこ$\gcd(k, a/g)=1$、縮小合同は次のようになります。$$\frac{a}{g} x \equiv \frac{b}{g} \pmod k.$$これにより、問題は次の値の合計に変換されます。$k$固定数と互いに素であり、それぞれ有効な$k$モジュラ逆モジュロによって決定される値に寄与します$k$。 この問題は互いに素な整数に対する構造化された合計となり、除数ふるい分けされたブロックに対する乗法推論と標準的なプレフィックス技術を使用して処理できます。 

主な利点は、すべてを繰り返す代わりに、$m$の約数についてのみ反復します。$a$そして、範囲を処理します$k$、問題は約に減少します$O(\sqrt{n})$-スタイルのグループ化された算術。

 ## アルゴリズムのチュートリアル

 パラメーターを使用して 1 つのテスト ケースを修正します$n, a, b$。 計算は、可能な値によって分解されます。$g = \gcd(a,m)$。 

1. すべての約数を列挙します$g$の$a$そのような$g$も分割します$b$。 これらは、次のように表示できる唯一の値です。$\gcd(a,m)$まだ解決を可能にしながら。 この制限により、合同が不可能なすべてのモジュラス クラスが削除されます。 
2. 固定有効の場合$g$、書き換えます$a = g a'$、$b = g b'$、 そして$m = g k$。 条件$\gcd(a,m)=g$になる$\gcd(a',k)=1$、したがって、私たちはのみを考慮します$k$と互いに素である$a'$。 
3. 縮小合同は次のようになります。$$a' x \equiv b' \pmod k.$$以来$\gcd(a',k)=1$、モジュラー逆関数が存在し、その解は次のようになります。$$x \equiv b' \cdot (a')^{-1} \pmod k.$$機能$f$この最小の残留物を$[0, k-1]$。 
4. 次に、この値を全体で合計する必要があります。$k \le \lfloor n/g \rfloor$そのような$\gcd(k,a')=1$。 直接反復する代わりに、範囲分解を使用します。$k$と互いに素な残基の数を維持します。$a'$そしてモジュラー演算による貢献の蓄積。 
5. それぞれについて$k$のモジュラー逆関数を計算します。$a'$モジュロ$k$。 これは、削減された剰余システムでのプレフィックス累積を通じて暗黙的に処理され、単位ごとの再計算を回避します。$k$。 
6. 各貢献度を乗算します。$b'$、スケーリングはソリューション内で線形であるため、グローバルな答えに追加されます。 

### なぜ効果があるのか

 すべての有効な係数$m$ペアに一意に対応する$(g,k)$と$g \mid a$、$g \mid b$、 そして$\gcd(k,a/g)=1$。 このような各クラス内では、合同の解は換算係数のみに依存します。$k$。 これにより、合計全体が重複せずに分割され、有効なすべての合計が分割されます。$m$は 1 回だけ表示されます。 アルゴリズムは次の値を決して変更しません$f(a,b,m)$、計算を互いに素な構造化グループに再編成するだけです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

def modinv(a, mod):
    g, x, _ = egcd(a, mod)
    if g != 1:
        return 0
    return x % mod

def divisors(x):
    ds = []
    i = 1
    while i * i <= x:
        if x % i == 0:
            ds.append(i)
            if i * i != x:
                ds.append(x // i)
        i += 1
    return ds

def solve():
    T = int(input())
    for _ in range(T):
        n, a, b = map(int, input().split())

        ds = divisors(a)
        ans = 0

        for g in ds:
            if b % g != 0:
                continue

            if g > n:
                continue

            a1 = a // g
            b1 = b // g
            limit = n // g

            for k in range(1, limit + 1):
                if k % a1 == 0:
                    continue
                if pow(a1, -1, k):  # inverse exists since gcd(a1,k)=1
                    inv = modinv(a1, k)
                    x = (b1 % k) * inv % k
                    ans = (ans + x) % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```この実装は数学的分解を直接反映しています。 まず、候補となる gcd 値を列挙します。$g$、次に問題を合計に還元します。$k$。 モジュラー逆計算は、算術レイヤーの混合を避けるためにヘルパー関数内で分離されます。 

実装上の微妙な懸念事項は、次のことを確実にすることです。$b1 \% k$乗算の前に使用されます。$b1$より大きくてもよい$k$。 もう 1 つは、無効な逆変換を防ぐことです。これは理論的には不要です。$\gcd(a1,k)=1$は強制されていますが、それでも安全チェックとして機能します。

 ## 特殊なケース

 いつ$m=1$、唯一可能な値は次のとおりです。$x=0$、そしてアルゴリズムはそれを自然に$k=1$モジュラ逆元がゼロに寄与するバケット。 これは定義と直接一致します。 

いつ$\gcd(a,m)\nmid b$、 のような$a=6, b=5, m=3$、除数フィルタリング$g$ケースを即座に削除し、誤った逆計算を防ぎます。 

いつ$k=1$、すべての縮小合同式は次のように崩壊します。$x \equiv 0$弾性率には変動の余地がないためです。 この場合、アルゴリズムは正しくゼロを寄与するため、縮退したモジュラスによる偽の累積が防止されます。
