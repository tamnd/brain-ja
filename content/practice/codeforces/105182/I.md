 ## 解決策
 ## 問題の理解

 シーケンスに配置された重みを表す正の整数のマルチセットが与えられます。 2 人のプレイヤーが交互にターンを行い、各ターンで選択した 2 つの要素を合計にマージしてシーケンスを圧縮するか、1 つの要素を選択してゲームを直ちに終了します。 プレイヤーが数字を選択すると、そのプレイヤーはその値を獲得し、対戦相手は残りのすべての要素の合計を受け取ります。 その後、ゲームは停止します。 

すべての数値の合計は、ゲームが終了しない限り、ゲーム全体を通じて変化することはありません。 最終結果に影響を与える唯一の方法は、数値を結合することです。これにより、将来の選択肢全体に合計がどのように配分されるかが変わります。 

終わりの動きにおける最終決定は、後から考えると非常に簡単です。 プレイヤーが現在の合計値 S から値 x を取得した場合、対戦相手は S − x を受け取るため、2x > S のときにちょうど取得者が勝ちます。 

したがって、問題全体は、対戦相手もマージしてゲームをより早く終了できる可能性があるにもかかわらず、最初のプレーヤーが残りの合計に対して十分に大きな値を選択する状況を強制できるかどうかにあります。 

この制約は、ゲーム状態の直接シミュレーションが不可能であることを意味します。 最大 10^5 のテスト ケースと最大 10^6 の合計配列サイズでは、すべてのマージ履歴またはゲーム ツリーに対する状態空間検索は実行可能な限界をはるかに超えます。 動的なゲーム状態を維持する場合でも、マージごとにシーケンス サイズが 1 つ減少しますが、選択の分岐係数が大きいため、少なくとも 2 次の動作が導入されます。 

単純な「要素を最大限に活用する」ゲームとしてこれを扱うのは単純な間違いです。 これは失敗します。マージによって最初は存在しなかった新しい値が作成される可能性があり、それらの新しい値が残りの合計との最終比較で決定的なものになる可能性があるためです。 

別の失敗モードは、貪欲なプレイを想定することです。たとえば、常に最小の 2 つの値をマージします。 これでは、有利な不均衡が現れたときにゲームを途中で終了することで対応する相手の能力が無視されます。 

## アプローチ

 ゲームのブルートフォース解釈では、すべての状態をマルチセットとして扱い、両方のプレイヤーがすべての有効な手を探索することをシミュレートします。 マージごとに要素の数が 1 つ減り、終了の移動ごとに最終的なスコア分割が評価されます。 これにより、各ステップでプレイヤーが結合するペアまたはゲームを終了する要素を選択するため、ゲーム状態の数が指数関数的に増加します。 終了を無視したとしても、可能なマージ履歴の数は n リーフにわたるバイナリ ツリーの数に対応します。これはカタロニア語サイズであり、実際には超指数関数的に増加します。 

重要な点は、マージによって合計の合計は変更されず、合計のグループ化方法が変更されるだけであるということです。 一連のマージは、最初の要素に対して完全なバイナリ ツリーを構築することと同等であり、各内部ノードはサブセットの合計を表します。 したがって、ゲームは、集約されたグループが 2 つだけ残っている場合に、配列の最終パーティションをどのように形成するかを制御することになります。 

ゲームの状態を追跡する代わりに、最終的に避けられない構造について推論することができます。 最終的に、最適なプレイによりシーケンスは 2 つの数字に減ります。それより早く停止するとマージの継続が支配的になるためです。ゲームを終了するのが早すぎると、対戦相手に潜在的に大きな残余額を与えることになります。 要素が 2 つある場合、これ以上安全なマージは存在しません。マージすると、すぐに相手が残りの 1 つの値を獲得し、全額で勝つことができるからです。 

したがって、ゲーム全体は、シーケンスが 2 つのグループに減った瞬間に、最初のプレイヤーが合計値の半分を超える値を持つグループを選択できるように強制できるかどうかという問題に集約されます。

これにより、ゲームは最終的な 2 つのパーティションがどのように形成されるかという制御の問題に変わります。 各マージ操作は要素がどのようにグループ化されるかを効果的に決定し、両方のプレイヤーが敵対的な選択肢を使用してバイナリ パーティション ツリーを形成します。 

決定的な洞察は、敵対的プレイにもかかわらず、問題の構造は単純な不変条件に崩壊するということです。最初のプレイヤーが勝利を保証できる唯一の方法は、他のすべての要素の合計より厳密に値が大きい要素が存在する場合です。 そのような要素が存在する場合、最初のプレイヤーはマージを通じてそれを十分に「孤立」させたままにし、最終的には対戦相手がそれを無力化する前に最後のピックとして確保することができます。 

そのような支配的な要素が存在しない場合、対戦相手はいつでも、最初のプレーヤーに勝ちの選択を与えないように最後のスプリットを強制することで対応できます。

 ## アルゴリズムのチュートリアル

 解決策は、最大の要素が配列の残りの部分を支配できるかどうかをチェックすることになります。 

1. シーケンス内のすべての要素の合計 S を計算します。 この値はマージ中も不変のままであるため、すべての最終決定が評価される基準となります。 
2. 配列内の最大要素 mx を特定します。 勝利戦略は最終的に、この値が適切なタイミングで強制的に選択されることに依存する必要があります。なぜなら、その値がすでに世界的に支配的である場合、より小さな要素の組み合わせはそれを超えることができないからです。 
3. mx と S − mx を比較します。 mx が厳密に S − mx より大きい場合、mx は十分強力であるため、それが最終テイクとして選択されると、選択したプレーヤーが即座に勝ちます。 
4. この条件が当てはまる場合、最初のプレーヤーは正しいタイミングで mx を選択する可能性を維持する一連のマージを強制でき、強制勝利につながると結論付けます。 
5. それ以外の場合、対戦相手はいつでも、最初のプレーヤーが勝利のターミナルピックに到達することを妨げる方法で応答できると結論付けます。 

重要な考え方は、マージは重みを再配分するだけであり、一連の再配分によってグローバル最大値よりも強力な新しい要素を作成することはできないということです。 したがって、ゲーム全体は基本的に、単一の要素がすでに合計を支配しているかどうかによって制御されます。 

### なぜ効果があるのか

 すべての移動は合計 S を保存し、すべてのターミナルの移動は、選択された単一の値 x を S − x と比較することによって決定されます。 マージは 2 つの値をそれらの合計で置き換えるだけであるため、一部のサブセットにすでに存在するものを超えて、個々の「最終的に選択可能な利点」の最大値が増加することはありません。 勝利の最終手を保証する唯一の方法は、2x > S を満たす選択として分離できる値が存在することを確認することです。最初にそのような値が存在しない場合、一連のマージによってその値を作成することはできません。マージされた値は補数の和が少なくとも同程度大きいサブセットに対応するため、最終ステップで対戦相手が優位性を打ち消すことができるからです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        s = sum(a)
        mx = max(a)
        if mx > s - mx:
            out.append("YES")
        else:
            out.append("NO")
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```コードは、上記で導出された不変条件を直接実装します。 テスト ケースごとに、合計と最大要素が計算されます。 決定は、最大要素が残りのすべての要素の合計よりも厳密に大きいかどうかによってのみ決まります。 マージは総和や最大要素の同一性に影響を与えないため、マージのシミュレーションは必要ありません。 

実装では、操作ごとのオーバーヘッドを慎重に回避し、テスト ケースごとにすべてを線形に保ちます。これは、合計入力サイズが最大 100 万要素であることを考えると必要です。

これは、等価性が不十分である境界ケースを示しています。

これは、単一の圧倒的に大きな要素が結果を決定するという直観を裏付けています。

 ## 特殊なケース

 すべての要素が等しい場合、縮退 n=2 の場合のみ、すべての候補値が合計のちょうど半分に等しく、それ以外の場合は厳密に小さくなります。 厳密な優位性を満たす要素がないため、アルゴリズムは正しく NO を出力します。 

n が 1 に等しい場合、最大値は合計に等しいため、条件が成立し、答えは YES になります。 プレイヤーは即座に唯一の要素を獲得し、勝ちとなります。 

非常に大きな外れ値要素がある場合、マージではその値を減らしたり、最終比較からその利点を再分配したりすることはできません。 アルゴリズムはこれを正しく識別し、YES を返します。
