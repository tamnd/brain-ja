 ## 解決策
 ## 問題の理解

 k 次元の整数空間には偶数の点、合計でちょうど 2n 点が与えられます。 各点は座標ベクトルに寄与し、任意の 2 点間の距離は、すべての k 次元にわたるマンハッタン距離になります。 アリスとボブの 2 人のプレーヤーは、すべてのポイントが取得されるまで交互に未使用のポイントを選択し、アリスが最初に開始します。 アリスは S1 にポイントを集め、ボブは S2 にポイントを集めます。 

各プレイヤーのスコアは、個々のポイントではなく、内部の結束力に基づいています。集合 S について、S 内のすべてのポイントのペア間のマンハッタン距離のペアごとの合計を計算します。アリスは差 val(S1) − val(S2) を最大化しようとする一方、ボブはそれを最小化しようとし、両方とも最適にプレイします。 

問題の構造は、すべてのポイントが最終的に同じサイズの 2 つのセットのうちの 1 つに正確に割り当てられる必要があるということですが、割り当ては直接分割ではなく、敵対的な選択プロセスを通じて決定されます。 目的は順序ではなく最終的なパーティションのみに依存しますが、順序は最適なプレイの下でどのパーティションが達成可能であるかを制約します。 

制約 n、k ≤ 10^5 (n・k ≤ 10^5) は、周囲の次元 k が大きくても、読み取られる座標値の総数が 2n・k ≤ 2・10^5 に制限されることを意味します。 これは、O(nk) 前処理は許容されるが、n の二次関数は不可能であることを強く示唆しています。 すべての点のペア (O(n^2 k)) を明示的に考慮するアプローチは、直ちに除外されます。 

いくつかの次元で点が同一またはほぼ同一である場合、微妙なエッジ ケースが発生します。 たとえば、すべてのポイントが同一の場合、すべての距離はゼロになるため、再生順序に関係なく、答えはゼロになる必要があります。 座標の大きさによって点を分離することに依存する貪欲な戦略は、人為的な構造を誤って導入し、寄与ゼロを維持できない可能性があります。 

k = 1 の場合、別のエッジ ケースが発生します。この場合、問題は、マンハッタン距離が絶対差である 1 次元の配置に帰着します。 これは、最適な分割が純粋に軸に沿った順序によって決定される古典的な設定であり、多次元の独立性に関する誤った推論によって解決策が崩れる可能性があります。 

## アプローチ

 素朴な解釈では、ゲームをシミュレートするということになります。 各ステップで、アリスまたはボブは、将来の完璧なプレイを想定して最終的な結果を最適化する残りのポイントを選択します。 これは、最大 2n のサイズのすべてのサブセットにわたるミニマックス再帰を示唆しています。 状態空間はすべて点のサブセットであり、遷移によって一度に 1 つの要素が削除されます。 

このアプローチはゲームの定義を正確に反映しているため、原則として正しいです。 ただし、分岐係数は 2n から始まり直線的に減少し、おおよそ (2n) になります。 可能なシーケンス。 サブセットの状態だけで既に 2^(2n) を形成しており、n に対して最大 10^5 までの天文学的な大きさであるため、サブセットに対するメモ化による枝刈りも役に立ちません。 

重要な構造的観察は、目的関数がピックの順序ではなく、最終パーティションのみに依存するということです。 したがって、ゲームは、敵対的制約の下でサイズ n の 2 つのセットの 1 つに各ポイントを割り当てることと同等です。 これにより、問題は、等しいサイズ制約を持つパーティションに対する組み合わせ最適化に変換されます。 

マンハッタン距離は次元間で分離可能です。つまり、各座標の寄与を独立して考慮し、最後に合計することができます。 これは、k 次元問題を k 個の独立した 1 次元問題に還元し、その後、寄与を結合することを示唆しています。

固定次元の場合、val(S) への寄与はその軸に沿った順序のみに依存します。 1 次元点の古典的な特徴は、集合 S 内のペアごとの絶対差の合計が、ソートされた順序統計を使用して表現できることです。各要素は、その左右にある要素の数に基づいて寄与します。 これにより、ソート後に二次ペアワイズ合計が要素ごとの線形寄与に変換されます。 

ゲーム構造は、アリスが合計貢献度の差を最大化するように、アリスかボブにポイントを割り当てるかを選択することになります。 これは、S1 と S2 に配置されたときの限界寄与をキャプチャするポイントごとに 1 つの値を計算することになります。 各ポイントにスカラー重みが割り当てられると、最適化はこれらの重みをソートし、利点の降順で交互に割り当てることになります。これは、サイズ制約の下で貪欲に最適に分割することと同じです。

 ## アルゴリズムのチュートリアル

 多次元構造を、ボブのセットではなくアリスのセットに配置した場合に、そのポイントがペアごとのマンハッタン距離にどの程度寄与するかをキャプチャする、ポイントごとの単一のスカラー スコアに還元します。 

1. 次元ごとに独立して、すべての 2n 点をその次元の座標で並べ替えます。 

1 次元のマンハッタン距離は相対的なランクにのみ依存するため、この順序付けにより、各点がその軸に沿った絶対差にどの程度寄与するかが決まります。 
2. 固定次元の場合、プレフィックス累積を使用して、各点のペアごとの絶対差への寄与を計算します。 

点がソート順で位置 i にある場合、その点は線形化された形式で右側の点にプラスに寄与し、左側のポイントにマイナスに寄与します。 これにより、各ポイントにその次元の符号付き寄与値を割り当てることができます。 
3. 各点のすべての k 次元にわたる寄与を合計します。 

マンハッタン距離は座標全体で加算されるため、ポイントの合計寄与度は、その次元ごとの寄与度の合計になります。 これにより、各ポイントにそのグローバルな影響を表す単一のスカラー重みが与えられます。 
4. ゲームをアリスに n ポイント、ボブに n ポイントを選択すると解釈します。アリスは、選択したポイントからボブのポイントを引いた重みの合計を最大化します。 

これは、アリスが 2 つの同じサイズのグループ間の合計の重みの差を最大化することに相当します。 
5. すべてのポイントを、計算された重みに従って降順に並べ替えます。 

最適な戦略は、利用可能な最大のウェイトアドバンテージをアリスに割り当てることです。ボブの動きは、アリスが影響力の大きいポイントではなく、影響度の低いポイントを取得するのを防ぐことに対応するためです。 
6. 上位 n 点をアリスに割り当て、残りの n 点をボブに割り当て、最終的な差を sum(Alice) − sum(Bob) として計算します。 

これは交換の議論から導き出されます。最も重みの高い残りポイントを取ることから逸脱すると、最終的にアリスの優位性が低下するか、ボブのコントロールが増大するだけです。 

### なぜ効果があるのか

 重要な不変条件は、各点を目的への限界寄与を表すスカラー重みに削減した後、点間の相互作用が消えることです。 元のペアごとの構造は、各ポイントがどちらの側に割り当てられているかにのみ応じて独立して最終的な差に寄与する加算的なスコアリング システムに崩壊します。 両方のプレイヤーは割り当て順序のみを制御し、最終的なカーディナリティの実現可能性は制御しないため、最適なプレイでは、アリスが利用可能な限界寄与の最大値を効果的に確保し、ボブが残りを強制的に確保することが強制されます。 この順序の反転は、実現可能性に影響を与えることなくローカルで交換できますが、Alice の目的を厳密に改善するため、貪欲でない結果が最適になるのを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    m = 2 * n
    pts = [list(map(int, input().split())) for _ in range(m)]

    contrib = [0] * m

    for d in range(k):
        order = list(range(m))
        order.sort(key=lambda i: pts[i][d])

        prefix = 0
        for i in range(m):
            idx = order[i]
            contrib[idx] += pts[idx][d] * i - prefix
            prefix += pts[idx][d]

        suffix = 0
        for i in range(m - 1, -1, -1):
            idx = order[i]
            contrib[idx] += suffix - pts[idx][d] * (m - 1 - i)
            suffix += pts[idx][d]

    contrib.sort(reverse=True)

    ans = 0
    for i in range(n):
        ans += contrib[i]
    for i in range(n, 2 * n):
        ans -= contrib[i]

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、各次元を 2 回スイープすることによって、ポイントごとの寄与を構築します。 前方スイープでは、点が大きな要素にどの程度寄与するかを累積し、後方スイープでは小さな要素を考慮して、その次元における符号付きペアごとの差分の寄与の正確な合計を生成します。 

最後のソートステップでは、アリスが最も有益なポイントを獲得する選択問題への帰着を実装します。 問題は固定サイズのサブセットに対する線形目的の純粋な最大化になるため、ソート後の分割は正しいです。 

よくある実装の落とし穴は、次元ごとに貢献を両方向に蓄積する必要があることを忘れていることです。 プレフィックス合計のみを使用すると、絶対差分同一性の半分しか生成されず、符号エラーが発生します。

 ## 特殊なケース

 すべての点が同一である場合、すべての次元ですべてのペアごとの距離はゼロになります。 プレフィックスとサフィックスのキャンセルによりすべての項が削除されるため、アルゴリズムはすべてのポイントにゼロ寄与を割り当てます。 ゼロ値の寄与をソートすると任意の分割が行われますが、両方の合計はゼロのままであり、正しい出力が生成されます。 

k = 1 でポイントが厳密に増加している場合、接頭辞と接尾辞の分解により、位置に基づいて対称的な正と負の寄与が割り当てられます。 極値にある点は最大の大きさの重みを受け取り、貪欲な分割によりアリスとボブにそれらが正しく割り当てられ、1 次元の絶対差の予想される最大分離構造と一致します。
