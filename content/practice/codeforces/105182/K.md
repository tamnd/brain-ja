 ## 解決策
 ## 問題の理解

 一連の整数が与えられると、非常に特殊な種類の演算を繰り返し適用することができます。つまり、配列内の正確に k 個の位置を選択し、選択されたすべての要素に同じ非ゼロの整数を乗算します。 この操作は何度でも繰り返すことができます。 

目標は、すべての要素が等しくなるようにシーケンスを変換することであり、これが可能な k の最大値を見つけたいと考えています。 

演算を再解釈する便利な方法は、素指数がどのように進化するかという観点から考えることです。 選択した k 個の要素に同じ値を乗算するということは、一度に正確に k 個のインデックスに同一の係数変更を追加することを意味します。 これは、絶対値ではなく、要素間の「違い」が重要な実際の構造であることを意味します。 

n が 10^5 まで、合計が 10^6 までという制約は、テスト ケースごとに本質的に線形または線形に近い処理が必要であることを意味します。 操作をシミュレートしたり、すべての要素間の変換についてペアごとに推論しようとするアプローチは、すぐに失敗します。 

すべての数値がすでに等しい場合、微妙な特殊なケースが発生します。 その場合、演算は必要ないため、任意の k は n まで有効です。 もう 1 つの重要なケースは、数値が完全に無関係な素因数分解を持つ場合 (たとえば、すべてのペアごとに互いに素な値である場合) です。 そのような状況でも、常にそれらを等しくすることはできますが、最大 k は等価性自体ではなく、構造的な可分性の関係によって制限されます。 

## アプローチ

 この問題を考える直接的ではあるが非生産的な方法は、実際に操作を実行しているところを想像することです。 各操作はロックステップで k 要素を変更するため、すべての値を徐々に「同期」しようとします。 ただし、可能な操作シーケンスの数は膨大であり、固定 k が機能するかどうかを判断するだけでも、更新の指数関数的な組み合わせについて推論する必要があります。 

重要な変化は、値について考えるのをやめ、代わりに比率について考えることです。 最終的にすべての数値が等しくなった場合、任意の 2 つのインデックス i および j について、比率 a[i] / a[j] は、許可された演算を使用して削減可能でなければなりません。 各演算は k 個の要素にのみ均等に影響を与えることができるため、実際に重要なのは、各素因数の指数の不均衡を共有する要素がいくつあるかということです。 

固定 k の場合、サイズ k のグループ内ですべての指数の差を「中和」できるように調整を繰り返し配布できれば、プロセスは成功します。 これは、素数全体の不均衡の合計をサイズ k のグループに調整できる場合にのみ可能です。つまり、k は合計の「指数偏差の質量」を非常に特殊な方法で分割する必要があります。 

これを確認する最も簡単な方法は、目標の最終値を修正することです。 すべての要素は同じで終了するため、その値はインデックス全体に分散した寄与から構築する必要があります。 各素因数について、ターゲットに対する指数の増加と減少を必要とする要素の数を考慮します。 すべての操作は k インデックスを均一に調整するため、ステップごとに k 単位の調整を効果的に移動します。 実現可能性の条件は、割り算の制約にまとめられます。k は、すべての素数のすべてのインデックスにわたる総調整予算を分割する必要があり、最も厳しい制約は配列のグローバル gcd 構造から得られます。 

重要な観察は、すべての操作で要素間の比率の gcd が維持され、唯一の自由度が同期グループのスケーリングにあるということです。 これは、最大 k が正確に最大の約数であるという事実につながり、等しい「差分シグネチャ」によるインデックスのグループ化が可能になります。これは、グローバル gcd を分割することによってシーケンスを正規化した後の任意の値の最大周波数のサイズに単純化されます。

配列全体の gcd で割ることにより、すべての値を正規化します。 この後、問題は正規化されたシーケンス内の任意の値の最大頻度を見つけることになります。 その周波数は最大の k です。なぜなら、それらの同一の値はすでに相互に調整する必要がなく、さらに大きなグループ化では互換性のない指数シフトが強制されるからです。 

したがって、答えは、配列を gcd で割った後の任意の数値の最大周波数になります。

 ## アルゴリズムのチュートリアル

 1. 配列全体の gcd を計算します。 これにより、すべての要素を均等に乗算することは、すべての位置を含む演算によって常に達成できるため、等価性の実現可能性に影響を与えない共通のスケーリング係数が削除されます。 
2. すべての要素をこの gcd で除算します。 このステップの後、残りの構造はすべて純粋に相対的なものになります。つまり、達成される平等は、これらの削減された値のバランスをとることからもたらされる必要があります。 
3. 各正規化値の頻度をカウントします。 
4. 答えは、これらのカウントの最大の頻度です。 これは、すでに同一である要素の最大グループに対応し、同期操作ですべてを調整できる最大の k を直接決定します。 

### なぜ効果があるのか

 グローバル gcd を削除した後、残りの値は還元不可能な相対差を表します。 有効な一連の操作では、同一の正規化値を共有するグループ内の等価関係が維持されます。 各操作は正確に k 個のインデックスに均一に影響を与えるため、係数調整で競合を引き起こすことなく、等しい正規化された構造のグループのみをマージできます。 このような最大のグループは常に操作ブロック サイズとして選択でき、k が大きくなると別個の正規化された値を組み合わせる必要があり、単一の共通エンドポイントに解決できない矛盾した乗法履歴が強制されます。 

## Python ソリューション```python
import sys
import math
from collections import Counter

input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        g = 0
        for x in a:
            g = math.gcd(g, x)
        
        for i in range(n):
            a[i] //= g
        
        freq = Counter(a)
        ans = max(freq.values())
        out.append(str(ans))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、最初に gcd が増分的に計算され、オーバーフローしたり、大きな中間積が格納されたりしないようにします。 正規化後は、gcd がすべての要素を除算することが保証されているため、整数除算は安全です。 

頻度をカウントするステップでは、最大 10^9 までの大きな値の範囲に最適なハッシュ マップを使用します。 最後に、最大周波数を直接抽出します。 

微妙な点は、gcd をテスト ケースごとに個別に再計算する必要があり、制約はテスト全体で合計されますが、値は無関係であるため、ケース間でカウンターを再利用してはいけないことです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | gcd 計算と頻度カウントは両方とも配列を 1 回スキャンします。 
| スペース | O(n) | 周波数マップは最大 n 個の個別の値を保存します。 

すべてのテスト ケースにわたる合計入力サイズは 10^6 で制限されるため、線形時間ソリューションは時間制限内に問題なく収まります。 各テスト ケースには単一の周波数マップのみが保存されるため、メモリの使用も安全です。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math
    from collections import Counter

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n = int(input())
            a = list(map(int, input().split()))
            g = 0
            for x in a:
                g = math.gcd(g, x)
            for i in range(n):
                a[i] //= g
            out.append(str(max(Counter(a).values())))
        return "\n".join(out)

    return solve()

assert run("1\n1\n5\n") == "1", "single element"
assert run("1\n5\n2 2 2 2 2\n") == "5", "all equal"
assert run("1\n5\n1 2 3 4 5\n") == "1", "all distinct"
assert run("1\n6\n2 2 3 3 3 6\n") == "3", "mixed frequencies"
assert run("1\n4\n8 4 2 1\n") == "1", "decreasing chain"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 単一要素 | 1 | 最小 n エッジケース |
 | すべて等しい | n | 達成可能な最大 k |
 | すべて異なる | 1 | グループ化はできません |
 | 混合周波数 | 3 | 典型的なケース |

 ## 特殊なケース

 すべての要素が同一の場合、gcd は値そのものと等しく、正規化によりすべて 1 の配列が生成されます。 周波数マップは n を返します。これは、どの演算でも直ちに等価性が維持されるため、k が n になり得ることを正しく反映しています。 

すべての要素が個別であるが、共通の gcd を共有する場合、正規化によって重複が生成される可能性がありますが、それらの重複のみが答えに寄与します。 たとえば、[6,10,14] は gcd 2 を持ち、[3,5,7] となり、答え 1 が得られます。これは、非自明なグループ化は不可能であるという事実と一致します。 

配列に支配的な繰り返し値といくつかの外れ値が含まれている場合、gcd 正規化は等価クラスを乱さず、頻度カウントが実現可能な最大のグループ化サイズを直接取得するため、アルゴリズムは自然に最大の同一クラスターを分離します。
