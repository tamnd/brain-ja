 ## 解決策
 ## 問題の理解

 サイズのバイナリ行列がいくつあるかを数えるように求められます$n \times n$行と列にわたって非常に非対称な方法で課される 2 つのグローバル制約を満たします。 

各行には、そのすべてのエントリの AND に関する条件があります。 行の AND の場合$i$が 1 の場合、行全体が 1 で埋められます。 0 の場合は、行が 1 で完全に埋められていないことを意味するだけなので、その行のどこかに少なくとも 1 つのゼロが存在する必要があります。 

各列には、そのすべてのエントリの OR に関する条件があります。 列の OR の場合$j$が 0 の場合、列全体がすべてゼロでなければなりません。 1 の場合、列のどこかに少なくとも 1 つの 1 が含まれている必要があります。 

タスクは、両方の制約セットを同時に満たす行列の数を数えることです。 

単一のセルが 1 つの行 AND 制約と 1 つの列 OR 制約に同時に寄与するため、制約は行と列の間の緊密な相互作用を直ちに示唆します。 と$n$まで$10^5$、行列を明示的に考慮したり、すべてのセルに対して反復したりするアプローチは不可能です。 ソリューションでは、構造を行と列の集合体に圧縮する必要があります。 

重要なエッジ ケースは、行がすべて 1 を必要とする一方で、列がすべて 0 を必要とする場合に発生します。 たとえば、ある行の AND が 1 に等しく、ある列の OR が 0 である場合、交差するセルは強制的に 1 と 0 の両方になりますが、これは不可能です。 このような場合、答えは直ちにゼロでなければなりません。 

もう 1 つの微妙なケースは、一方が「完全な固定」を強制する場合、たとえば、すべて 1 でなければならない行やすべて 0 でなければならない列などです。 これらの強制線は行列の自由度全体を排除し、カウント構造を崩壊させる可能性があるため、すべての行または列を個別に扱うと、誤った過剰カウントが発生します。 

## アプローチ

 ブルートフォースアプローチでは、それぞれの$n^2$セルを 0 または 1 にしてから、すべての行 AND と列 OR が指定された文字列と一致するかどうかを確認します。 これにはチェックが必要になります$2^{n^2}$行列であっても完全に実行不可能です。$n = 20$。 行ごとの構成を生成しようとしても、$2^n$行ごとの選択肢はまだ限界をはるかに超えています。 

重要な点は、制約がセルごとにローカルではなく、行および列ごとにグローバルであり、各制約が行または列全体を極端な状態に強制することです。 AND が 1 に等しい行は完全に固定されます。 OR が 0 に等しい列も完全に固定されます。 これらの強制構造が特定されると、残りの自由度は、より小さいサブグリッド上で「行がすべて 1 でない」および「列がすべて 0 でない」タイプの制約の下でバイナリ行列をカウントすることに減ります。 

ブルート フォースはすべての割り当てを探索するため機能しますが、ほとんどの行または列が固定的になるという事実を利用していないため失敗します。 行と列が強制的なグループと柔軟なグループに分割されるという観察により、問題を構造化制約に対する包含/除外を伴う組み合わせカウントに帰着させることができます。

 ## アルゴリズムのチュートリアル

 まず、制約を行と列の構造ルールに変換します。 

### ステップ 1: 行と列の制約を強制パターンに変換する

 列の場合$i$もっている$a_i = 1$、その行のすべてのエントリは 1 でなければなりません。$j$もっている$b_j = 0$、その列のすべてのエントリは 0 でなければなりません。これらは絶対的な制約です。 

これにより、すぐに矛盾条件が作成されます。次のような行が存在する場合です。$a_i = 1$と任意の列$b_j = 0$の場合、交差セルは強制的に 1 と 0 の両方になるため、構築は不可能になります。 

### ステップ 2: 早期拒否

 このような競合するペアが存在する場合は、0 を返します。 

### ステップ 3: 強制的にすべて 1 行が存在するかどうかで分割する

 しましょう$k$のインデックスの数になります$a_i = 1$。 

我々は、以下に応じて 2 つの根本的に異なる体制を扱います。$k$ゼロまたは正です。 

### ステップ 4: 少なくとも 1 つの行が 1 に完全に固定されている場合

 もし$k \ge 1$の場合、すべての列には、これらの完全に 1 つの行からの 1 が少なくとも 1 つ自動的に含まれます。 これは、すでに除外した強制ゼロ列がない限り、すべての列 OR 制約がすでに満たされていることを意味します。 

今残っている唯一の自由は、$a_i = 0$。 このような各行はすべて 1 になることを避けなければなりませんが、それ以外の点では制限はありません。 

これらの各行には、すべて 1 の文字列を除く任意のバイナリ文字列を指定できます。$2^n - 1$行ごとの選択肢。 行は独立しているため、寄与は次のようになります。$$(2^n - 1)^{\#\{i : a_i = 0\}}$$### ステップ 5: すべての行がゼロ AND 行である場合

 もし$k = 0$、すべての行に少なくとも 1 つのゼロが含まれている必要があります。 すべての行が強制的に 1 になることはありません。 

この時点では、列の OR 制約のみが問題となり、列の OR 制約は重要になります。$b_j = 0$完全にゼロに固定されます。 それらを無視し、次の列に焦点を当てます。$b_j = 1$、あると言う。$m$そういったコラム。 

サイズの行列を数えます$n \times m$次のような:

 すべて 1 の行はなく、すべて 0 の列もありません。 

これは古典的な対称的な包含-排他構造です。 行のサブセットを強制的にすべて 1 にするか、列のサブセットを強制的にすべて 0 にすることを検討します。 強制行と強制ゼロ列の両方を含む構成は、それらの交差が矛盾を必要とするため不可能です。 

したがって、包含-排他は、行制約と列制約という 2 つの独立したファミリーにきれいに分割されます。 

各家族は次のことに貢献します。$$(2^m - 1)^n$$行ベースと列ベースの両方の包含が同じ式に寄与するため、次の結果が得られます。$$2(2^m - 1)^n - 2^{nm}$$### ステップ 6: ケースを結合する

 一貫性を検証した後、強制的に 1 行が存在するかどうかに応じて、適切な式を返します。 

### なぜ効果があるのか

 不変条件は、すべての制約が、行全体を固定するか、列全体を固定するか、独立した行または列に「すべてが等しくない」条件を強制するかのいずれかになるということです。 強制された構造が分離されると、残りの選択肢は行ごとに独立し、対称的な「すべて 1 の行」イベントと「すべて 0 の列」イベントの包含/除外が相互作用項なしできれいに考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()

        has_a1 = any(ch == '1' for ch in a)
        has_b0 = any(ch == '0' for ch in b)

        if has_a1 and has_b0:
            print(0)
            continue

        pow2n = modpow(2, n)
        base = (pow2n - 1) % MOD

        if has_a1:
            k0 = a.count('0')
            print(pow(base, k0, MOD))
        else:
            m = b.count('1')
            term = pow((modpow(2, m) - 1) % MOD, n, MOD)
            full = modpow(2, n * m % (MOD - 1))
            ans = (2 * term - full) % MOD
            print(ans)

if __name__ == "__main__":
    solve()
```コードはまず、強制 1 行と強制 0 列の間の矛盾をチェックします。 次に、完全に 1 行が少なくとも 1 つある場合と、完全に 1 行が存在しないという 2 つの構造領域に分かれます。 最初の体制では、残りのすべての行が、すべて 1 でないバイナリ文字列として独立して寄与します。$n$列。 2 番目の領域では、行列は次のようになります。$n \times m$行と列の両方の「非縮退」制約が対称であるシステム。$2^m$。 

実装の微妙な詳細は、モジュロ演算で 2 の累乗を慎重に処理することです。 表現$2^{nm}$の直接乗算であるため、指数リダクションを伴うモジュラべき乗を使用して計算する必要があります。$n \cdot m$標準の整数制限をオーバーフローする可能性があり、フェルマー換算も考慮する必要があります。

 ## 特殊なケース

 行がすべて 1 に強制され、列がすべて 0 に強制されると、矛盾はそれらの交差セルに直ちに現れます。 例えば、$a = 1$、$b = 0$、$n = 1$単一のセルは 1 と 0 の両方である必要があり、強制的にゼロの答えが生成されます。 アルゴリズムは、次のいずれかの 1 をチェックすることでこれを直接検出します。$a$および任意の 0$b$。 

すべての行が 0 の AND 行である場合、システムは純粋にすべて 1 の行を防止すると同時に列の OR 制約を満たします。 アクティブな列に減らすことで、ゼロに固定された列が有効な構成に誤って寄与することがなくなります。
