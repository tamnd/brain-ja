 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$未知の順列から生成されたグリッド$p$長さの$2n$。 

構築ルールは単純です: セル内の値$(i,j)$は$p_{i+j}$。 以来$i$そして$j$は 1 から始まり、同じ対角線上のすべてのセルは同じ合計を共有するため同じ値を持ちます。$i+j$。 

私たちの仕事は、順列全体を再構築することです$p_1,p_2,\dots,p_{2n}$。 

重要な観察点は、グリッドにはインデックスに関する情報のみが含まれていることです。$2$を通して$2n$。 値$p_1$可能な最小の合計は次のとおりであるため、決して表示されません。$1+1=2$。 

制約は非常に小さいです。 すべての合計$n$テストケース全体では最大でも$800$、そのため、インプットを読むだけでも作業が支配されます。 グリッドを 1 回スキャンするソリューションであれば、十分に高速です。 高度なデータ構造や最適化は必要ありません。 

明らかではないエッジケースは、$n=1$。 

入力：```
1
1
1
```グリッドには次のものだけが含まれます$p_2=1$。 順列には数字が含まれている必要があるため、$1$そして$2$、欠損値は$2$。 答えは次のとおりです。```
2 1
```不注意な解決策は、すべての順列位置がグリッド内のどこかにあると想定し、再構成することを忘れる可能性があります。$p_1$。 

もう 1 つの微妙なケースは、欠損値が最小値でも最大値でもない場合です。 

入力：```
1
2
2 3
3 4
```グリッドから私たちは回復します$p_2=2$、$p_3=3$、$p_4=4$。 からの唯一の番号$\{1,2,3,4\}$現れないのは$1$、 それで：```
1 2 3 4
```推測するアプローチ$p_1$順列プロパティを使用する代わりにグリッド構造から使用すると、ここでは失敗します。 

## アプローチ

 この問題を考えるための強引な方法は、すべての立場を再構築することです$p_k$インデックスが満たすすべてのセルを調べることにより、$i+j=k$。 グリッドは有効であることが保証されているため、そのようなすべてのセルには同じ値が含まれます。 回収後$p_2$を通して$p_{2n}$、残りの数を決定し、所定の位置に配置します$1$。 

これはすでに制約内で機能しています。 グリッドには次のものだけが含まれます$n^2$細胞、そして$n \le 800$。 

本当の洞察は、すべての対角線を個別に検査する必要はないということです。 

任意の金額に対して$s$間$2$そして$2n$、常に少なくとも 1 つの有効なセルが存在します。$i+j=s$。 その対角線上のすべてのセルには$p_s$、単一の代表セルで十分です。 

のために$s \le n+1$、セルを使用できます$(1,s-1)$。 

のために$s > n+1$、セルを使用できます$(s-n,n)$。 

これにより、すべての値がすぐに得られます$p_2,p_3,\dots,p_{2n}$。 以来$p$の順列です$1$を通して$2n$、復元された値からちょうど 1 つの数値が欠落しています。 その欠けている番号はきっと$p_1$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^2)$|$O(n)$| 承認済み |
 | 最適 |$O(n^2)$|$O(n)$| 承認済み |

 グリッドの読み取りにはすでにコストがかかるため、漸近的な複雑さは同じです$O(n^2)$ただし、最適なアプローチでは、各順列値を直接抽出します。 

## アルゴリズムのチュートリアル

 1. グリッドを読み取ります。 
2. 配列を作成する`p`長さの`2n + 1`1 から始まるインデックスを使用します。 
3. 合計ごとに`s`から`2`に`2n`、 回復する`p[s]`。 

もし`s <= n + 1`、 使用`grid[0][s - 2]`、セルに対応します`(1, s-1)`。 

それ以外の場合は、使用します`grid[s - n - 1][n - 1]`、セルに対応します`(s-n, n)`。 

両方のセルは和と対角線上にあります`s`、つまり、正確に含まれています`p[s]`。 
4. 回復されたすべての値にマークを付けます`p[2] ... p[2n]`。 
5. 数字の中には`1 ... 2n`、マークされていないものを見つけます。 
6. その番号を次のように設定します`p[1]`。 
7. 出力`p[1] ... p[2n]`。 

### なぜ効果があるのか

 すべての対角は、正確に 1 つの置換位置に対応します。 和を伴う対角線$s$値のみが含まれます$p_s$したがって、その反対角から任意のセルを取得すると、正しい順列要素が回復されます。 

グリッドは合計をカバーします$2$を通して$2n$、これは、を除くすべての順列位置を明らかにすることを意味します。$p_1$。 シーケンスは次の順列であることが保証されているため、$1$を通して$2n$、復元された値にはちょうど 1 つの数値がありません。 その欠けている番号はきっと$p_1$。 他に選択肢はありません。だからこそ、この再建はユニークなのです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    g = [list(map(int, input().split())) for _ in range(n)]

    p = [0] * (2 * n + 1)

    for s in range(2, 2 * n + 1):
        if s <= n + 1:
            p[s] = g[0][s - 2]
        else:
            p[s] = g[s - n - 1][n - 1]

    seen = [False] * (2 * n + 1)
    for i in range(2, 2 * n + 1):
        seen[p[i]] = True

    for x in range(1, 2 * n + 1):
        if not seen[x]:
            p[1] = x
            break

    print(*p[1:])
```最初の部分では、指定されたとおりにグリッドを読み取ります。 

ループオーバー`s`位置を再構築します`2`を通して`2n`。 インデックス作成だけが少し注意が必要な部分です。 入力グリッドは 0 から始まるインデックスで保存されるため、セル`(1, s-1)`になる`g[0][s-2]`、セル中`(s-n, n)`になる`g[s-n-1][n-1]`。 

表示されているすべての順列値を回復した後、コードはそれらを`seen`配列。 順列には以下のすべての数値が含まれるため、`1`に`2n`マークされていない番号を 1 回だけスキャンすると、すぐに次の結果が得られます。`p[1]`。 

すべての値が最大値であるため、整数オーバーフローの懸念はありません。`1600`。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        g = [list(map(int, input().split())) for _ in range(n)]

        p = [0] * (2 * n + 1)

        for s in range(2, 2 * n + 1):
            if s <= n + 1:
                p[s] = g[0][s - 2]
            else:
                p[s] = g[s - n - 1][n - 1]

        seen = [False] * (2 * n + 1)
        for i in range(2, 2 * n + 1):
            seen[p[i]] = True

        for x in range(1, 2 * n + 1):
            if not seen[x]:
                p[1] = x
                break

        out.append(" ".join(map(str, p[1:])))

    return "\n".join(out)

 ## 特殊なケース

 最小の有効な入力を考えてみましょう。```
1
1
1
```アルゴリズムは回復のみを行います`p2 = 1`。 順列には数字が含まれている必要があります`{1,2}`。 欠損値は`2`したがって、次のように出力されます。```
2 1
```グリッドが単一のセルで構成されている場合でも、再構成は有効なままです。 

ここで次のことを考えてみましょう。```
1
2
2 3
3 4
```回復すると次のことが得られます。```
p2 = 2
p3 = 3
p4 = 4
```からの欠落番号`{1,2,3,4}`は`1`、生産:```
1 2 3 4
```これは、アルゴリズムが欠損値の特別な位置に依存していないことを確認します。 

最後に、次のことを考慮してください。```
1
2
1 4
4 2
```回収率:```
p2 = 1
p3 = 4
p4 = 2
```唯一未使用の番号は、`3`、 それで：```
3 1 4 2
```これにより、非表示の最初の要素が単なるエンドポイントではなく、順列範囲内の任意の値になり得ることが検証されます。
