 ## 問題の理解

 整数のシーケンスが与えられ、シーケンス内の各要素について、その要素と他のすべての要素の間の XOR の合計を計算できます。 私たちの仕事は、どの要素がこの合計を最大化するかを見つけることです。 より具体的に言うと、シーケンスの場合`a = [a_1, a_2, ..., a_n]`、可能な限り最大の値が必要です$$S_k = \sum_{i=1}^{n} (a_k \oplus a_i)$$すべての指数にわたって`k`。 XOR 演算はビット単位で行われるため、オペランドが異なるビットを反転します。 

制約により、最大で次のことが許可されます。`2·10^5`テストケースごとの要素と合計`2·10^5`すべてのテスト ケースにわたる要素。 各数値は 30 ビットに収まります。 これは、すべてのペアを反復する解 (O(n²)) が遅すぎることを示しています。 線形またはほぼ線形にスケールするソリューションを見つける必要があります。`n`。 

エッジ ケースには、長さ 1 のシーケンス、すべての要素が等しいシーケンス、数値が 2 の累乗であるシーケンスが含まれます。 たとえば、すべての要素が`18`の場合、どの要素の XOR 合計もゼロになります。`x XOR x = 0`。 シーケンスが`[1, 2, 4, 8, 16]`、最大の要素を選択すると、XOR 結果により多くの上位ビットが設定されるため、合計が最大になります。 ビットレベルの構造を無視する単純なアプローチでは、これらを効率的に処理できません。 

## アプローチ

 ブルートフォースアプローチによる計算`S_k`あらゆる人にとって`k`他のすべての要素を反復処理します。 のために`n = 2·10^5`、これはおおよそ次のことにつながります`4·10^10`最悪のテスト ケースに基づいた操作は実行不可能です。 

重要な洞察は、XOR がビットに対して線形であるということです。つまり、XOR の合計はビット位置によって分解できます。 1ビットを考えてみましょう`b`。 もし`b`に設定されています`a_k`、そのビットが設定されていない**すべての要素との XOR 合計に寄与します。 同様に、`b`では設定されていません`a_k`、**そのビットが設定されている**すべての要素との XOR 合計に寄与します。 したがって、各ビットについて、そのビットが設定されている数値の数を数えることができます (`ones`) とそうでない人はいくつありますか (`zeros`）。 選択時の合計に対するそのビットの寄与度`a_k`かどうかのみに依存します`a_k`ビットが設定されているかどうか:

 - ビットが設定されている場合`a_k`、貢献 =`zeros * (1 << bit)`- ビットが設定されていない場合`a_k`、貢献 =`ones * (1 << bit)`各ビットを個別に選択して合計を最大化できるため、最適なビットを構築できます。`a_k`要素あたり O(30) 時間です。 各数値は最大 30 ビットなので、全体の計算はテスト ケースごとに O(n * 30) になります。

 ## アルゴリズムのチュートリアル

 1. 30 要素の配列を初期化する`bit_count`ゼロに。 各エントリは、配列内の特定のビットが設定されている数値の数を格納します。 
2. 配列内の各数値を反復処理して更新します。`bit_count`ビット位置ごとに。 
3. 数字ごとに`a_k`、各ビットを個別に考慮して、配列との XOR 合計の合計を計算します。 ビットが設定されている場合`a_k`、貢献します`zeros * (1 << bit)`合計すると、`zeros = n - bit_count[bit]`。 ビットが設定されていない場合、それが寄与します`ones * (1 << bit)`と`ones = bit_count[bit]`。 
4. 発生した最大合計を記録します。 
5. すべての数値を処理した後、最大合計を出力します。 

**機能する理由:** XOR 合計はビット間で加算され、各ビットの寄与は他のビットから独立しています。 セットのビットをカウントすると、各ビットが候補の合計にどのように寄与するかを正確に知ることができます。`a_k`。 これにより、合計を決して過小評価したり過大評価したりしないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Count how many numbers have each bit set
        bit_count = [0] * 30
        for num in a:
            for b in range(30):
                if num & (1 << b):
                    bit_count[b] += 1
        
        max_sum = 0
        for num in a:
            total = 0
            for b in range(30):
                ones = bit_count[b]
                zeros = n - ones
                if num & (1 << b):
                    total += zeros * (1 << b)
                else:
                    total += ones * (1 << b)
            max_sum = max(max_sum, total)
        print(max_sum)

if __name__ == "__main__":
    solve()
```この実装では、まず各ビットが設定されている数値の数を数えます。 次に、数値ごとに、ビット寄与を効率的に組み合わせて XOR 合計を計算します。 慎重な使用`n - ones`ゼロを指定すると、1 つずつずれたミスを防ぐことができます。

 ## 特殊なケース

 単一の要素の場合`[1]`、`bit_count`1ビットをカウントします。 合計の式は 0 になります。`zeros = 0`、単一要素のシナリオを正しく処理します。 

すべての要素が等しい場合、次のように`[31, 31, 31]`、すべてのビットが XOR 合計にゼロを寄与し、予想どおり合計 0 が生成されます。 

上位ビットがまばらなシーケンスの場合、次のようになります。`[1, 2, 4]`、アルゴリズムはビットごとにゼロを正確にカウントし、寄与を独立して計算するため、数値に重複しないビットがある場合でも正しい最大合計が保証されます。
