 ## 問題の理解

 配列が与えられています`a`長さの`n`と正の整数`k`。 から`a`、より大きな配列を構築します`b`繰り返すことで`a`その通り`k`回。 つまり、`b`長さがある`n * k`、そしてその最初の`n`要素は同じです`a`、残りの要素が繰り返されます`a`順番に。 タスクは、指定されたしきい値に対して、`x`、開始位置の数を数える`l`で`b`少なくとも 1 つのセグメントがある`[l, r]`合計が少なくとも`x`。 

なぜなら`n`そして`k`それぞれ最大で可能です`10^5`、`b`理論的には最大の長さを持つことができます`10^10`。 明らかに、建設`b`明示的に、またはすべてのセグメントを反復処理することは不可能です。 すべての合計`n`そしてすべて`k`テストケース全体の境界は次のとおりです`2*10^5`これは、解が線形であることを示唆しています。`n`テストケースごとは許容されますが、線形のものは何でも可能です`n * k`そうではありません。 

注意すべきエッジケースには次のような場合があります。`k`とても大きいですが、`x`巨大なため、どのセグメントも到達しません`x`。 たとえば、次の場合`a = [1]`、`k = 100000`、 そして`x = 1000000000`、答えは`0`。 別のエッジケースが発生するのは次の場合です。`x`に比べて非常に小さい`a`、 のような`x = 1`そして`a = [100]`、すべての位置`l`有効です。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる開始位置が考慮されます。`l`で`b`、合計がそれに達するかそれを超えるまで要素を追加していきます。`x`。 これは正しく動作しますが、複雑です`O(n*k)`テスト ケースごとに、次のような大きさにすることができます。`10^{10}`操作。 これは制限時間内では不可能です。 

重要な洞察は 2 つの観察から得られます。 まず、配列`b`周期的で周期的です`n`。 これは、最初のセグメントの後に始まるセグメントを意味します。`n`要素は、最初のセグメント内で始まるセグメントにマッピングし直すことができます。`n`要素 (おそらく追加の完全なコピーを含む)`a`添付。 2 番目に、合計が少なくとも次のような_任意のセグメント_を探しているためです。`x`、最初のコピーの各位置について知る必要があるだけです。`a`、到達する必要がある繰り返しブロックの数`x`。 

次のプレフィックスの合計を事前計算します。`a`現在の位置から到達するために必要な要素の最小数を迅速に決定します。`x`。 の合計額が`a`は`S`、次にポジションについては、`x`よりも大きいです`S`、を複数回完全に繰り返す必要があるかもしれません。`a`。 必要な繰り返し回数を超えた場合`k`、その位置からのセグメントは到達できません`x`。 それ以外の場合は、開始位置の数を数えることができます。`b`完全な繰り返しが何回適合するかに基づいて成功します。 これにより問題は次のように縮小されます`O(n)`テストケースごとの操作。

 ## アルゴリズムのチュートリアル

 1.読む`n`、`k`、`x`、および配列`a`。 
2. プレフィックス合計配列を計算します。`pref`のために`a`、 どこ`pref[i] = a[0] + ... + a[i]`。 これにより、次のセグメントの合計を計算できます。`a`一定時間内に。 
3. 合計を計算します`S = sum(a)`。 もし`S >= x`、その後、長さ ≤ のいくつかのセグメント`n`到達できる`x`。 それ以外の場合は、複数のコピーが必要です。 
4. 各開始位置について`i`で`a`(0 ベース)、最大繰り返し回数を計算します。`a`合計を維持したまま使用できる<`x`。 具体的には、それぞれについて、`i`、完全なコピーの最小数を見つけます`full_blocks`後に必要な`i`からの累積和が`i`到達する`x`。 
5. 必要な全部数を超える場合`k`、このポジションは貢献します`0`有効な開始位置。 それ以外の場合は、対応するすべての位置が`b`繰り返すことで生まれる`a`貢献します。 有効なポジションの数を次のように数えます。`valid_count = k - full_blocks`。 
6.合計`valid_count`すべてのポジションにわたって`i`テストケースの答えを取得します。 

それが機能する理由: 不変条件は、各位置で`i`最初のコピーで`a`、到達するために必要な完全なコピーの数`x`プレフィックスの合計と合計の合計によってのみ決定されます`S`。 繰り返しを超えて`k`有効なセグメントを作成できません。 以降のコピーのすべてのポジション`a`周期性により、最初のコピー内の位置にマップが戻されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k, x = map(int, input().split())
        a = list(map(int, input().split()))
        S = sum(a)
        pref = [0] * n
        pref[0] = a[0]
        for i in range(1, n):
            pref[i] = pref[i-1] + a[i]

        result = 0
        for i in range(n):
            needed = x - pref[i-1] if i > 0 else x
            if needed <= 0:
                # sum from i to i only (or less) already >= x
                result += k
            else:
                # full repetitions needed
                full_blocks = (needed + S - 1) // S
                if full_blocks <= k:
                    result += k - full_blocks + 1
        print(result)

if __name__ == "__main__":
    solve()
```このコードは、まずプレフィックス合計を計算して、定数時間のセグメント合計クエリを可能にします。 開始位置ごとに、その位置に到達するまでに必要な完全な繰り返しの回数を計算します。`x`。 の使用`(needed + S - 1) // S`ブロックの過少カウントを避けるために適切な天井分割を保証します。 次に、繰り返される配列内の有効な開始位置の数を計算します。 最初の要素だけで到達できる位置には特別な注意が必要です。`x`。
