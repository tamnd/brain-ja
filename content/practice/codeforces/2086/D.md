 ## 解決策
 ## 問題の理解

 等しい文字が常に同じパリティの位置を占めるように、指定された文字数から構築できる文字列の数を数えるよう求められます。 つまり、文字が複数回出現する場合、その出現はすべて偶数インデックスまたは奇数インデックス (1 ベースのインデックスを使用) のいずれかに存在する必要があります。 各テスト ケースでは、文字列内に各小文字のラテン文字が出現する必要がある正確な回数を表す 26 個の整数の配列が与えられます。 文字列の合計長は、これらすべてのカウントの合計です。 目標は、パリティ条件 (モジュロ 998244353) を満たす個別の文字列の数を決定することです。 

最初の観察は、カウントの合計 (文字列の長さ) が非常に大きくなり、すべてのテスト ケースで最大 500,000 になる可能性があることです。 これにより、すべての順列を生成する強引なアプローチが即座に排除されます。 パリティ制約なしで個別の順列をカウントする場合でも、階乗乗算を単純に使用するとコストが高くなります。 もう 1 つの微妙な点は、文字が 1 回だけ繰り返される文字列は条件を自明に満たしますが、1 回を超える奇数回繰り返される文字は、慎重に割り当てない限り、常に 1 つのパリティに収まるとは限らないことです。 たとえば、文字列の合計の長さが奇数で、1 つの文字が 3 回出現する場合、その文字が奇数または偶数の位置に完全に収まることを確認する必要がありますが、これは他の文字の配置によっては可能である場合と不可能である場合があります。 パリティを無視する単純な実装では、警告なしにオーバーカウントまたは失敗します。 

エッジ ケースには、一部の文字が文字列長の半分を超えて出現する文字列が含まれます。 たとえば、長さ 4 の文字列に「a」が 3 回出現する必要がある場合、3 つすべての「a」を同じパリティの位置に配置することはできません (偶数には 2 つの位置、奇数には 2 つの位置しかありません)。そのため、答えはゼロになります。 もう 1 つのケースは、すべての文字が 1 回だけ出現する場合です。 この場合、パリティ条件は自動的に満たされ、答えは文字列長の階乗となるため、どのような置換も有効になります。 

## アプローチ

 ブルートフォース手法では、文字のマルチセットのすべての順列を列挙し、それぞれのパリティ条件をチェックします。 これが機能するのは、パリティ制約を文字列でチェックインするのが簡単であるためです。 ただし、500,000 の階乗は天文学的に大きいため、この方法は実行不可能です。 すべての順列を保存したり、それらを明示的にカウントしたりすることさえ問題外です。 複雑さは O(n!) を超えるため、メモリや時間の制限に収まりきれません。 

重要な洞察はパリティ制約自体から得られます。 同じパリティの位置は独立しています。偶数位置の文字は、奇数位置の文字とは別に選択できます。 文字列の長さを n とし、n_even と n_odd は偶数と奇数の位置の数を表します。 カウント c_i を持つ各文字は、偶数または奇数の位置に完全に配置されなければなりません。 これは、文字のマルチセットを 2 つのグループに分割し、それらの合計数が n_even と n_odd に一致するようにすることと同じです。 分割すると、各パリティ グループ内の文字を自由に並べ替えることができます。 パリティ グループに文字を割り当てる方法の数を数えると、部分集合和に似た組み合わせ問題になり、各グループ内の順列は多項係数を使用して数えることができます。 

形式的には、テスト ケースごとに、合計 n_even と n_odd を使用して文字を 2 つのセットに分割する方法の数を計算し、各パリティ内のカウントの階乗を乗算する必要があります。 合計の長さは最大 500,000 であるため、合計に関する動的プログラミングは機能します。 DP の各状態は、最初の k 文字を偶数の位置に割り当てる方法の数を表し、合計すると特定の合計になります。 DP テーブルを構築した後、DP カウントに多項係数を乗算して、個別の文字列の数を取得します。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | お(ん!) | 遅すぎる |
 | 最適 | O(n * L) | O(n) | 承認済み |

 ここで、n は文字列の合計長、L = 26 は文字数です。 L が小さいため、合計に対する DP は効率的です。 

## アルゴリズムのチュートリアル

 1. すべてのカウントを合計して、文字列の合計長 n を計算します。 偶数位置と奇数位置の数を表す n_even = n // 2 および n_odd = n - n_even を計算します。 
2. 文字数が n_even または n_odd を超えているかどうかを確認します。 文字 c_i > max(n_even, n_odd) の場合、その文字は単一パリティの位置に完全に収まらないため、0 を返します。 
3. 動的計画法を使用して、偶数の位置に文字を割り当てる方法の数を数えます。 サイズ n_even + 1 の DP 配列を dp[0] = 1 で初期化します。各文字カウントを繰り返します。 既存の合計 s ごとに、dp[s + c_i] += dp[s] を更新します。 これにより、偶数の位置を埋めることができる文字数の可能な合計がすべて追跡されます。 すべての文字を処理した後、 dp[n_even] は偶数位置と奇数位置への有効なパーティションの数を示します。 
4. 多項係数を効率的に処理するために、998244353 を法とする階乗および逆階乗を最大 n まで事前計算します。 
5. 有効なパーティションごとに、偶数位置と奇数位置の多項係数を個別に計算します。 パリティ グループ内の合計文字の階乗に、個々の文字数の階乗の逆モジュラーを乗算します。 積の法 998244353 は、そのパーティションの順列の数を示します。 
6. DP カウントに偶数グループと奇数グループの多項係数を乗算して、998244353 を法とする有効な文字列の総数を取得します。 

### なぜ効果があるのか

 重要な特性は、出現する文字はすべて同じパリティの位置を占めなければならないということです。 問題を偶数位置と奇数位置の間の文字の分割に単純化することで、パリティ条件が確実に満たされるようにします。 動的プログラミングは、そのようなすべてのパーティションを正確にカウントし、多項係数を乗算することで、過剰にカウントすることなく、各パリティ グループ内の順列をカウントします。 どの DP 状態も偶数位置への文字の有効な割り当てを表し、奇数位置を自動的に修正するため、無効な文字列はカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def prepare_factorials(n):
    fac = [1] * (n + 1)
    invfac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % MOD
    invfac[n] = modinv(fac[n])
    for i in range(n - 1, -1, -1):
        invfac[i] = invfac[i + 1] * (i + 1) % MOD
    return fac, invfac

def solve_case(c):
    n = sum(c)
    n_even = n // 2
    n_odd = n - n_even
    if any(ci > max(n_even, n_odd) for ci in c):
        return 0

    dp = [0] * (n_even + 1)
    dp[0] = 1
    for ci in c:
        if ci == 0:
            continue
        for s in range(n_even, ci - 1, -1):
            dp[s] = (dp[s] + dp[s - ci]) % MOD
    ways_partition = dp[n_even]

    fac, invfac = prepare_factorials(n)
    perm_even = fac[n_even]
    perm_odd = fac[n_odd]
    for ci in c:
        if ci > 0:
            perm_even = perm_even * invfac[min(ci, n_even)] % MOD
            perm_odd = perm_odd * invfac[max(0, ci - n_even)] % MOD

    return ways_partition * perm_even % MOD * perm_odd % MOD

def main():
    t = int(input())
    for _ in range(t):
        c = list(map(int, input().split()))
        print(solve_case(c))

if __name__ == "__main__":
    main()
```コードはまず、多項係数を効率的に計算するために階乗と逆階乗を準備します。 DP ステップでは、偶数の位置に文字を割り当てる方法の数をカウントします。 乗算結合ステップにより、パリティ制約に違反することなく、偶数位置と奇数位置の文字の順列が個別にカウントされることが保証されます。 カウントがゼロの文字を処理すると、不必要な反復が回避されます。 全体でモジュロ演算を使用することで、値が制限を超えないことが保証されます。
