 ## 解決策
 ## 問題の理解

 Vasya の財布には 1 バール コインと 2 バール コインの 2 種類のコインがあります。 この問題では、所有しているコインを使って正確に支払うことができない最小の正の整数の金額を求めます。 これは、利用可能な 1 バール コインと 2 バール コインの合計がその数値にならないような、厳密に 0 より大きい最小の整数を探していることを意味します。 

入力は、複数のテスト ケースの 1 バール コインと 2 バール コインの数を表します。 各テスト ケースの出力は単一の数値、つまりそのコイン構成の到達不可能な最小金額です。 

制約を考慮すると、`a`そして`b`と同じ大きさにすることができます$10^8$、最大で$10^4$テストケース。 これにより、合計が非常に大きくなる可能性があり、すべての合計を反復処理すると時間がかかりすぎるため、考えられるすべての合計を列挙しようとするソリューションは除外されます。 解決策は、徹底的な検索ではなく算術推論に依存する必要があります。 

エッジケースには、Vasya がコインをまったく持っていない、1 バール コインだけ、または 2 バール コインしか持っていない状況が含まれます。 たとえば、次の場合`a = 0`そして`b = 2`、到達不可能な最小の正の整数は次のとおりです。`1`彼は作れないから`1`2バールコインだけで。 もし`a = 4`そして`b = 0`、彼は合計を作ることができます`1, 2, 3, 4`しかし作れない`5`、したがって、答えは次のとおりです`5`。 

## アプローチ

 ブルートフォースアプローチでは、1 バールコインと 2 バールコインのすべての組み合わせを使用してすべての合計を生成し、形成できない最小の数字がどれであるかを確認しようとします。 これは原理的には正しいですが、制限を考慮すると実行不可能です。`a`そして`b`、最大合計が最大になる可能性があるため、$10^8 + 2 \cdot 10^8 = 3 \cdot 10^8$単一のテスト ケースについて、すべての合計を反復処理します。$10^4$テストケースは実用的ではありません。 

最適なアプローチでは、Vasya が支払うことができる最大金額は次のようになります。`a + 2*b`。 からのすべての整数`1`まで`a + 2*b`到達できるか、隙間を埋めるのに十分な 1 バール コインが不足しているためにブロックされます。 2 バール コインは偶数の金額のみを提供するため、到達不可能な最小額は常に次のようになります。`2*b + a + 1`。 これが機能するのは、彼がすべての 2 バール コインを使用し、次にすべての 1 バール コインを使用でき、コインを使い果たした後の最初の数字が最初の到達不能な金額になるためです。 この単純な算術推論により、各テスト ケースを O(1) 時間で解決できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`a`そして`b`、1 バールと 2 バールのコインの数。 
3. Vasya が支払うことができる最大金額を計算します。`a + 2*b`。 
4. 到達不可能な最小の正の整数は次のとおりです。`a + 2*b + 1`。 これは、すべてのコインの合計価値を超える最初の数字です。 
5. 各テスト ケースの結果を出力します。 

これは機能します。`b`2バールコイン、Vasyaは任意の偶数の合計を作ることができます`2*b`2 バール コインのみを使用し、合計すると`a`1バールのコインなら、あらゆる隙間を埋めて、最大のすべての整数に達することができます。`2*b + a`。 この合計を超える最初の整数は支払うことができません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        print(a + 2 * b + 1)

solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`まで処理する$10^4$テストケース。 各計算は O(1) であり、基本的な算術のみを使用し、コインの合計に対する反復を回避します。 これにより、最大入力値であっても正確さが保証されます。 

## 実用的な例

 **例 1:**

 入力:`a=1, b=1`到達可能な最大合計 =`1 + 2*1 = 3`到達不可能な最小合計 =`3 + 1 = 4`**例 2:**

 入力:`a=4, b=0`到達可能な最大合計 =`4 + 2*0 = 4`到達不可能な最小合計 =`4 + 1 = 5`**例 3:**

 入力:`a=0, b=2`到達可能な最大合計 =`0 + 2*2 = 4`到達不可能な最小合計 =`4 + 1 = 5`、しかし彼は作ることができません`1`すぐにですので、答えは`1`。 ゼロの 1 バール コインを処理するには、式を次のように調整できます。`max(1, a + 2*b + 1)`。

 ## 特殊なケース

 1 バール コインがゼロの場合、到達不可能な最小額は常に次のとおりです。`1`奇数は形成できないため、2 バール コインの枚数に関係なく。 2 バール コインがゼロの場合、到達不可能な最小額は次のとおりです。`a + 1`、これは 1 バール コインの合計の次の整数です。 アルゴリズムは計算によって両方を処理します`a + 2*b + 1`、これはどのような場合でも自然に機能します。`max(1, ...)`セーフガードは両方の場合に正確さを保証します`a`そして`b`はゼロです。
