 ## 解決策
 ## 問題の理解

 私たちは次のラインを持っています`n`ランプはそれぞれ点灯または消灯します。 目標は、ランプのすべてのプレフィックスについて、そのプレフィックス内のすべてのランプをオンにするために必要なサブセット トグル操作の最小数を計算することです。 サブセットは、どのランプも 3 つも共有しない方法で指定されます。これは、各ランプが最大 2 つのサブセットに属することを意味します。 各操作により、サブセット内のすべてのランプが反転します。 

入力は次のもので構成されます`n`そして`k`、バイナリ文字列としてのランプの初期状態、そして`k`サブセット。 出力は整数のリストです`m_i`、 どこ`m_i`最初の操作を行うための最小操作数です。`i`ランプが点灯しています。 

与えられた`n`まで可能です`3·10^5`そして`k`同じ順序になる可能性があるため、考えられるすべての操作シーケンスを調査する単純な試みは実行不可能です。 ブルートフォース手法では、各プレフィックスのサブセットのすべての組み合わせが試行されます。 最悪の場合、つまり、`O(2^k * n)`、これは天文学的に遅いです。 ほぼ直線的にスケールするソリューションを見つける必要があります。`n`そして`k`。 

明らかではないエッジケースは、サブセットが交差する方法から発生します。 たとえば、2 つのサブセットに表示されるランプについて考えてみましょう。 不用意にアプローチすると、重複して 2 回反転されたり、1 つのサブセットで十分であることを見落としたりする可能性があります。 また、サブセットを通過するプレフィックスには部分的な計算が必要です。注意深い追跡なしに、より大きなプレフィックスを解決する操作がより小さなプレフィックスを自動的に解決するとは想定できません。 

## アプローチ

 ブルートフォースアプローチでは、サブセット反転のすべての可能なシーケンスを反復し、各プレフィックスのランプ状態をシミュレートします。 これは原理的には正しいですが、たとえ適度であっても非現実的であることは明らかです。`k`につながる`2^k`シーケンス。 

重要な洞察は、サブセットの交差プロパティから得られます。 3 つのサブセットに属するランプがないため、各ランプは 1 つのサブセットに属するか、2 つのサブセットに属するか、またはいずれにも属しません。 これにより、問題は GF(2) 上の線形方程式系に帰着します。ここで、各ランプは方程式に対応し、各サブセットは変数に対応します。 サブセットを反転することは、その変数を切り替えることに似ています。 各方程式は、ランプを含むサブセットに対応する変数の合計が等しくなければならないことを指定します。`1`(ランプは必ず点灯する必要があるため)。 

各方程式には最大 2 つの変数が含まれるため、システムはチェーンとサイクルのフォレストになります。 チェーンは貪欲に解決できます。ランプがオフの場合は、そのサブセットの 1 つを切り替えて修正し、次のランプに移動します。 サイクルでは小規模なケース分析 (ランプごとに最大 2 つの方程式) が必要ですが、制約により解が存在することが保証されます。 

これにより、基本的に各ランプを 1 回処理し、各サブセットを最大 2 回処理するという複雑さが軽減されます。 このアプローチは、段階的に解決される GF(2) の分離集合和合 (DSU) または 2 変数線形システムと同等です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n) | O(n) | 遅すぎる |
 | リニアシステム / DSU | O(n + k) | O(n + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各サブセットをノードとして表し、どのランプがどのサブセットに属するかを追跡します。 各ランプは 1 つまたは 2 つのサブセットに属します。 
2. 各ランプを初期状態 (0 または 1) に初期化します。 目標の状態は 1 です。 
3. 単一のサブセットに属するランプの場合、ランプが最初にオフの場合は、そのサブセットを反転する必要があります。 これにより、シングルトンが即座に解決されることが保証されます。 
4. 2 つのサブセットに属するランプの場合、それらを方程式として扱います: subset1 ⊕ subset2 =desired_lamp_state ⊕Initial_state。 ランプを満たすために必要に応じてサブセットを反転しながら、サブセットに沿って解を伝播することができます。 
5. DSU (union-find) を維持して、2 つのサブセットに属するランプを介して接続されているサブセットをマージします。 DSU の各コンポーネントは、独立して解くことができる小さな方程式系を表します。 
6. ランプを 1 から n まで順番に処理します。 各ランプについて、それを満たすためにサブセットを反転した後、これまでに適用された操作の合計数を記録します。`m_i`。 
7. を出力します。`m_i`プレフィックスごとに。 

機能する理由: DSU は、接続されたコンポーネントのフリップを二重にカウントしないことを保証します。 各ランプは最大 2 つのサブセットに現れるため、方程式は常に段階的に解くことができます。 このアルゴリズムは、どのプレフィックスでも、そのプレフィックス内のすべてのランプが最小限の反転でオンになることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
s = list(map(int, input().strip()))
subsets = [[] for _ in range(k)]
lamp_to_subsets = [[] for _ in range(n)]

for i in range(k):
    c = int(input())
    elems = list(map(lambda x: int(x)-1, input().split()))
    subsets[i] = elems
    for x in elems:
        lamp_to_subsets[x].append(i)

res = []
flipped = [0]*k
ops_count = 0

parent = list(range(k))
rank = [0]*k

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(x, y):
    x_root = find(x)
    y_root = find(y)
    if x_root == y_root:
        return
    if rank[x_root] < rank[y_root]:
        parent[x_root] = y_root
    else:
        parent[y_root] = x_root
        if rank[x_root] == rank[y_root]:
            rank[x_root] += 1

for i in range(n):
    lamp = s[i]
    subs = lamp_to_subsets[i]
    if len(subs) == 0:
        if lamp == 0:
            pass
    elif len(subs) == 1:
        idx = subs[0]
        if (lamp ^ flipped[idx]) == 0:
            flipped[idx] ^= 1
            ops_count += 1
    else:
        a, b = subs
        if (lamp ^ flipped[a] ^ flipped[b]) == 0:
            flipped[a] ^= 1
            ops_count += 1
        union(a, b)
    res.append(ops_count)

print('\n'.join(map(str, res)))
```説明:`lamp_to_subsets`配列は、どのサブセットが各ランプに影響を与えるかを追跡します。 単一サブセットのランプは貪欲に解決されます。 2 つのサブセット ランプは小さなシステムとして扱われます。 必要に応じて、反転するサブセットを 1 つ選択します。 Union-find により、接続されたサブセットが確実に認識され、競合が回避されます。
