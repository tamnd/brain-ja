 ## 解決策
 ## 問題の理解

 私たちには、軸に沿って並んだ一連の長方形のポスターが与えられ、それぞれが色で塗られ、巨大な壁に次々と貼られます。 新しいポスターが配置されると、その領域内のその下のすべてが完全に覆われます。 タスクは、最終的に表示される画像をピクセルごとに再構築することではなく、すべてのオーバーレイを適用した後に、最終的な壁のどこにでも何色の異なる色が表示されるかを判断することだけです。 

各長方形は 2 つの向かい合う角によって与えられます。ここでの座標は大きく、約$2^{28}$、最大 4000 個の長方形が存在します。 長方形は回転されず、方向が一貫していることが保証されているため、それぞれが標準の軸が揃ったボックスになります。 主な問題は、重複する領域が挿入順序を尊重する必要があることです。つまり、重複する領域では、後のポスターが前のポスターよりも優先されることになります。 

素朴な解釈では、グリッドを想像して絵画をシミュレートすることになりますが、座標は直接離散化するには大きすぎます。 座標を圧縮したとしても、圧縮されたセルの数は二次関数であるため、セルごとの完全なシミュレーションは依然として大きくなりすぎる可能性があります。$n$、各セルでは多くの四角形をスキャンする必要がある場合があります。 

素朴な「セルごとに最後の色をマークする」アプローチの微妙な失敗例は、座標間に大きな空きスペースがある重なり合う四角形から発生します。 たとえば、1 つの四角形がほぼすべてをカバーし、後の小さな四角形がその一部と重なる場合、領域の大部分は変化していなくても、表示されるカラー セットは変更されます。 最上位の順序を正しく尊重せずにオーバーラップ数だけを追跡するソリューションは失敗します。 

もう 1 つのよくある落とし穴は、グローバルに最上位の長方形のみが重要であると仮定することです。 これは誤りです。壁の領域ごとに最上部の長方形が異なる可能性があるため、複数の色が同時に表示される可能性があります。 

出力は、どの色が最上位レイヤーである領域を少なくとも 1 つ持つかによってのみ決まります。 

制約により許可されるのは、$n = 4000$、これは次のことを示唆しています$O(n^2)$または$O(n^2 \log n)$ソリューションは許容されますが、長方形を超える立方体は遅すぎます。 各四角形は他の多くの四角形と幾何学的に相互作用する可能性があるため、単位面積ごとのシミュレーションを避け、代わりに四角形の境界によって引き起こされる構造を推論する必要があります。 

## アプローチ

 直接的なブルートフォース手法により、すべての x 座標と y 座標が離散化され、最大で 1 つのグリッドが形成されます。$2n \times 2n$座標圧縮後のセル。 次に、各長方形がカバーするすべてのセル上にペイントされ、順番に処理されます。 これはオーバーレイ プロセスを正確にシミュレートするため、これは正しいです。 ただし、各長方形でカバーできる範囲は次のとおりです。$O(n^2)$最悪の場合、セルが破損する可能性があるため、これを行うと、$n$長方形は次につながります$O(n^3)$限界をはるかに超えた行動$n = 4000$。 

重要な観察は、各領域の完全なジオメトリは決して必要ではなく、各基本セルの最上部の長方形の識別のみが必要であるということです。 セルごとの四角形ごとに反復する代わりに、視点を反転できます。つまり、x 間隔をスイープしてアクティブな四角形を維持し、各 x ストリップ内で y 間隔をスイープして、現在どの四角形が一番上にあるかを判断します。 

これにより、2D 可視性の問題が、x に沿って移動するにつれて長方形が出入りする、y にわたる繰り返しの 1D の「最上位間隔」クエリに変換されます。 アクティブ セットが変更されるのは四角形の境界だけであるため、イベントの構造はまばらです。 

最終的には、挿入時間 (Z インデックス) 順に並べられたアクティブな四角形の動的なセットを維持し、連続する X 座標間の垂直スラブごとに、Y 間隔ごとにどの四角形が一番上にあるかをクエリします。 これは、挿入、削除、および最大の Z インデックスの取得をサポートするバランスの取れた構造で実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッドペインティング |$O(n^3)$|$O(n^2)$| 遅すぎる |
 | アクティブ セットを使用した 2D スイープ ライン |$O(n^2 \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各四角形を x 軸と y 軸の両方のイベントとして扱い、問題を圧縮された座標のスイープに落とし込みます。 

1. 長方形の左端と右端からすべての一意の X 座標を収集し、並べ替えて、垂直ストリップを定義するために使用します。 これにより、ジオメトリが一定であるすべての X 領域が 1 回処理されることが保証されます。 
2. 同様に、上端と下端からすべての一意の y 座標を収集し、並べ替えて、水平ストリップを定義するために使用します。 これにより、各 x ストリップ内で y 構造も区分的に一定になります。 
3. 各長方形について、それを 2 つのイベントに変換します。1 つは左側の境界でアクティブになり、もう 1 つは右側の境界で非アクティブになります。 これにより、現在垂直ストリップをカバーしている一連の動的四角形を維持することができます。 
4. x 間隔を左から右にスイープします。 各 x ストリップで、x のこのストリップを現在カバーしているすべての四角形を含む、z インデックス (挿入順序) をキーとするデータ構造を維持します。 重要な考え方は、固定された X ストリップ内で、潜在的に表示される四角形のセットが固定されるということです。 
5. 各 X ストリップについて、Y 間隔を下から上にスイープします。 各 y 間隔で、最も高い z インデックスを持つアクティブな四角形がこの y 範囲をカバーするかを決定します。 その四角形は、対応するセル ブロックの表示色です。 
6. X-Y ブロック内で可視の長方形を識別するたびに、その色をブール配列またはセットに記録します。 最後に、これまでに可視として記録された色の数を数えます。 

最も重要な問題は、「最上部のアクティブな四角形」を効率的に維持することです。 これは、遅延削除を備えたヒープや Z オーダーをキーとするバランスのとれたツリーなど、挿入、削除、および最大の Z インデックスの取得をサポートする構造によって処理されます。 

### なぜ効果があるのか

 このアルゴリズムは、連続する x 座標と連続する y 座標によって定義されるセル内では、そのセルを覆う四角形のセットが一定であるという不変条件に依存します。 長方形は境界座標でのみ開始または停止するため、これらの原子領域内では変化は起こりません。 したがって、これらの領域のみをチェックすることで正確性が保証されます。 各領域内の Z オーダーの最上部の長方形によって、そこでの可視色が一意に決まります。すべての可視色は、少なくとも 1 つの領域で最上部の長方形として表示される必要があるため、色が欠落することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import heapq
from collections import defaultdict

def solve():
    n = int(input())
    rects = []
    xs = set()
    ys = set()

    for i in range(n):
        x1, y1, x2, y2, c = map(int, input().split())
        rects.append((x1, y1, x2, y2, c, i))
        xs.add(x1)
        xs.add(x2)
        ys.add(y1)
        ys.add(y2)

    xs = sorted(xs)
    ys = sorted(ys)

    x_id = {x:i for i, x in enumerate(xs)}
    y_id = {y:i for i, y in enumerate(ys)}

    x_events = [[] for _ in range(len(xs))]
    for x1, y1, x2, y2, c, i in rects:
        x_events[x_id[x1]].append(("add", x1, y1, x2, y2, c, i))
        x_events[x_id[x2]].append(("remove", x1, y1, x2, y2, c, i))

    active = set()
    seen_color = set()

    for xi in range(len(xs) - 1):
        for ev in x_events[xi]:
            typ, x1, y1, x2, y2, c, i = ev
            if typ == "add":
                active.add((i, y1, y2, c))
            else:
                active.discard((i, y1, y2, c))

        if not active:
            continue

        active_list = list(active)

        for yi in range(len(ys) - 1):
            y_low = ys[yi]
            y_high = ys[yi + 1]

            best = -1
            best_color = None

            for idx, y1, y2, c in active_list:
                if y1 > y_low and y2 < y_high:
                    continue
                if not (y2 <= y_low or y1 >= y_high):
                    if idx > best:
                        best = idx
                        best_color = c

            if best_color is not None:
                seen_color.add(best_color)

    print(len(seen_color))

if __name__ == "__main__":
    solve()
```この実装では、関連するすべての境界が個別のインデックスになるように座標が圧縮されます。 X スライスをスイープすると、挿入イベントと削除イベントを使用してアクティブな四角形セットが更新されます。 

各 X ストリップ内で、Y 間隔をスキャンし、どの四角形がその領域をカバーしているかを確認し、最も高いインデックスを持つ四角形を表示レイヤーとして選択します。 これはここでは単純な方法で実装されていますが、概念モデルはスイープ ラインのアイデアと一致しています。つまり、各基本領域は最上部のアクティブな四角形について 1 回だけチェックされます。 

よくある微妙な点は、長方形のカバレッジ チェックでは、完全な包含だけでなく、オーバーラップも考慮する必要があるということです。 交差の条件では、長方形が現在の y セルにまたがることを確認する必要があります。そうでない場合は、無視する必要があります。

 ## 特殊なケース

 エッジ ケースの 1 つは、長方形が重なり合う領域がなく、境界でのみ接触する場合です。 たとえば、x = 3 で終わる長方形と、x = 3 で始まる別の長方形です。これらは面積がゼロであるため、干渉しません。 スイープ ラインはこれを自然に処理します。これは、個別の座標間に圧縮された間隔が定義されており、正確な境界の重なり部分にはセルが存在しないためです。 

もう 1 つのケースは、他のすべてを完全に覆う大きな長方形の後に、散在する小さな長方形が続く場合です。 各小さな四角形がその領域内の少なくとも 1 つの圧縮セルを支配するため、アルゴリズムは依然としてすべての色を記録します。 

最後の微妙なケースは、z インデックスの順序付け動作が同一であることです。 長方形は挿入順に処理されるため、同順位は発生せず、最高のインデックスは常に明確に定義されます。
