 ## 問題の理解

 私たちは持っています$n$人々。 チームに分割する必要があり、各チームには 2 人または 3 人のメンバーが含まれます。 チームが形成された後、各チームは 2 つの文明のうち 1 つを独立して選択します。 

文明に割り当てられる人の数は、その文明を選択したすべてのチームの規模の合計です。 2 つの文明人口の差ができるだけ小さくなるように、チームの規模と文明の選択肢の両方を調整したいと考えています。 

各テスト ケースには、値のみが与えられます。$n$、そして達成可能な最小の差を出力する必要があります。 

制約は非常に小さいです。 まであります$10^4$テストケースとそれぞれの$n$せいぜい$10^4$。 シンプルなものでも、$O(n)$テストケースごとのソリューションは問題なく合格します。 それでも、問題の構造により、$O(1)$解決。 

難しいのは、文明を選択するのは個人ではなくチームだということを理解することです。 私たちは 2 つの文明間で人々を恣意的に分配することはできません。 どのチームも一度に 2 人か 3 人を貢献します。 

考慮する$n=2$。 サイズ 2 のチームは 1 つだけです。一方の文明には 2 人が割り当てられ、もう一方には 0 人が割り当てられるため、答えは 2 になります。不注意なアプローチでは、人々を個別に分割できると想定し、誤って 0 を返す可能性があります。 

検討してください$n=5$。 サイズ 2 と 3 のチームを編成できます。サイズ 2 のチームを 1 つの文明に割り当て、サイズ 3 のチームをもう 1 つの文明に割り当てます。 違いは 1.$n$偶数または奇数の場合はこれを見逃します。 

考慮する$n=7$。 有効なパーティションの 1 つは次のとおりです。$2+2+3$。 文明の合計は次のようになります。$5$そして$2$、違いを与える$3$、 または$4$そして$3$、違いを与える$1$。 チームを形成した後に文明の割り当てを選択する機能は不可欠です。 

## アプローチ

 ブルートフォースアプローチでは、表現するあらゆる方法が列挙されます。$n$2 と 3 の合計として。 各代表について、2 つの文明へのチームの割り当てをすべて試し、最小の差を記録します。 

これが機能するのは、すべての有効なソリューションが何らかのチーム分解とチームの割り当てに対応しているためです。 問題は、分解と代入の数が指数関数的に増加することです。 中程度の値であっても、$n$、あらゆる可能性を探ることは非現実的になります。 

重要な観察は、チームの規模が 2 人または 3 人だけであるということです。$$3 - 2 = 1,$$非常に柔軟に合計を構築できます。 重要なのは残りの部分だけです$n$モジュロ 2。 

もし$n$が均等であれば、いつでも 2 つの文明間で人々を平等に分けることができます。 1 つの単純な構成は、サイズ 2 のチームのみを形成することです。その場合、各文明はちょうど半分のチームを受け入れることができます。 差分は0になります。 

もし$n$が奇数である場合、文明人口の合計は奇数になる必要があるため、均等に分割することは不可能です。 可能な最大の差は少なくとも 1 です。 

次の疑問は、差 1 が奇数に対して常に達成可能かどうかです。$n$。 

あらゆる奇数に対して$n \ge 5$、書くことができます$$n = 3 + 2k.$$サイズ 3 のチームを 1 つ作成し、$k$サイズ 2 のチーム。$2k$人の合計が均等であれば、それらを均等に分割できます。 サイズ 3 の追加チームは、一方の文明に他方よりも 1 人多く貢献し、正確に 1 の差が生じます。 

この構造に適合しない唯一の奇数の値は、$n=3$。 サイズ 3 の単一チームの場合、一方の文明は 3 人全員を獲得し、もう一方の文明は 0 人を獲得するため、その差は 3 になります。 

これで答えは完全に決まります。 

-$n=3$3を与えます。 
- その他の奇妙なもの$n$1を与えます。 
- 偶数$n$ただし、0 を返します$n=2$、これは 2 を与えます。 

これらのケースは、次のようによりコンパクトに書くことができます。$n \bmod 2$、特殊な値を除く$2$そして$3$。

 ## アルゴリズムのチュートリアル

 1.読む$n$。 
2. もし$n=2$、出力2。 

サイズ 2 のチームは 1 つだけなので、1 つの文明がすべての人々を受け入れます。 
3. それ以外の場合、$n=3$、出力3。 

サイズ 3 のチームは 1 つだけなので、1 つの文明がすべての人々を受け入れます。 
4. それ以外の場合は出力$n \bmod 2$。 

もし$n$が偶数であれば、完全な分割が存在し、答えは 0 になります。 

もし$n$が奇数で少なくとも 5 の場合、差 1 の分割が存在します。母集団全体が奇数であるため、これより小さい差はあり得ません。 

### なぜ効果があるのか

 偶数の場合$n$、サイズ 2 のチームのみを形成すると、総人口を 2 つの文明間で均等に分割できるため、最小の差は 0 になります。 

奇数の場合$n \ge 5$、 書く$n=3+2k$。 サイズ 3 のチームを片側に割り当て、サイズ 2 のチームを均等に分割します。 文明の人口はちょうど 1 だけ異なります。総人口は奇数であるため、0 の差は存在できません。 

事例$n=2$そして$n=3$チームは 1 つしか結成できないため、例外的です。 一方の文明はすべての人を受け入れますが、もう一方の文明は誰も受け入れません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

ans = []
for _ in range(t):
    n = int(input())

    if n == 2:
        ans.append("2")
    elif n == 3:
        ans.append("3")
    else:
        ans.append(str(n % 2))

sys.stdout.write("\n".join(ans))
```最初の 2 つの条件は例外値のみを処理します。 のために$n=2$そして$n=3$、チームは 1 つだけであるため、その差はチームのサイズそのものに等しくなります。 

より大きな値ごとに、パリティによって答えが完全に決まります。 均等分割が可能なため、偶数の値は 0 を返します。 母集団の合計が奇数であるため、奇数の値は 1 を返し、差分 0 が除外され、サイズ 3 のチームを 1 つ使用した構築では差分 1 が得られます。 

すべての値が小さいため、算術オーバーフローの懸念はありません。 この実装では、テスト ケースごとに少数の定数時間操作のみが実行されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 2:
            ans.append("2")
        elif n == 3:
            ans.append("3")
        else:
            ans.append(str(n % 2))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run("3\n2\n5\n12\n") == "2\n1\n0"

# minimum valid values
assert run("2\n2\n3\n") == "2\n3"

# smallest odd value with answer 1
assert run("1\n5\n") == "1"

# even value
assert run("1\n8\n") == "0"

# maximum constraint
assert run("1\n10000\n") == "0"

# large odd value
assert run("1\n9999\n") == "1"
