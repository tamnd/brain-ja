 ## 解決策
 ## 問題の理解

 We are given a permutation of length$n$、これは単なる整数の配列です。$1$に$n$繰り返しなしで一定の順序で。 タスクは、すべての整数をカウントすることです$k$から$1$に$n-1$、連続する要素の各ペアが少なくとも 2 つ以上異なる長さの部分配列の数$k$。 これらのサブ配列は次のように呼ばれます。$k$-絶妙です。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは順列の長さを提供します$n$そして配列自体。 アウトプットしなければなりません$n-1$テスト ケースごとの数値。それぞれが次の数を表します。$k$- 対応する絶妙な部分配列$k$。 

制約が示すのは、$n$まで行くことができます$10^5$と合計$n$すべてのテストケースで次を超えない$2 \cdot 10^5$。 これはナイーブという意味です$O(n^2)$テストケースごとにすべてのサブ配列を反復処理するため、テストケースごとのアプローチは実行不可能です。$k$前後が必要になります$O(n^3)$最悪の場合の運用。 テスト ケースごとに線形または線形演算の複雑さに近いものが必要です。 考慮すべきエッジケースには、厳密に増加または減少する順列、長さ 2 の小さな配列、および一部の要素間の差異が正確に一致する部分配列が含まれます。$k$。 

単純なアプローチは、次のような配列では失敗します。`[1,2,3,4]`いつ$k=3$差がしきい値を満たしていないことに気づかずに、1 と 2 から始まるサブ配列を誤ってカウントする可能性があるためです。 

## アプローチ

 ブルート フォース手法では、長さがそれぞれ少なくとも 2 つのすべてのサブ配列に対して反復されます。$k$。 各サブ配列について、すべての連続するペアをチェックして、差分条件が満たされていることを確認します。 正しいのですが、このアプローチには次のことが必要です$O(n^2)$あたりの小切手$k$、すぐに管理できなくなります。$k$までの範囲$n-1$。 合計の操作はおおよそ次のようになります$O(n^3)$最悪の場合、遅すぎる$n\sim 10^5$。 

重要な観察は、問題を繰り返すのではなく、逆転できるということです。$k$部分配列をチェックして、順列内の連続する要素のペアを反復処理し、それらの間の絶対的な差を計算します。 各ペアは効果的に範囲を制限します。$k$有効な部分配列に寄与できる値。 具体的には、次の違いがある場合、$p[i]$そして$p[i+1]$は$d$、その後、任意の$k \le d$、このペアでは、それを含むサブ配列が許可されます。 サブ配列は連続しているため、連続するペアをマージして、差分制約が適用される範囲を形成できます。 素集合結合 (DSU) 構造または長さ追跡アプローチを使用すると、各差異が寄与するサブ配列の数をカウントし、すべてのサブ配列の結果を集計できます。$k$効率的に。 

改善は、各ペアがすべてのペアに貢献していることを認識することによってもたらされます。$k \le \text{difference}$また、すべてのサブ配列を個別に列挙するのではなく、セグメント長を使用してサブ配列をカウントできることもわかります。 ペアを差分でソートし、連続する有効なセグメントを拡張すると、すべてのセグメントのカウントを計算できます。$k$で$O(n \log n)$Union-find を使用した時間。

 ## アルゴリズムのチュートリアル

 1. 長さの順列を読み取る$n$。 連続するペアごとに絶対差を計算し、保存します。$(\text{difference}, \text{index})$みんなのために$i$から$0$に$n-2$。 
2. 差異を降順に並べ替えます。 これにより、有効な最小値に対応する最大の差異が最初に処理されることが保証されます。$k$しきい値。 
3. 各インデックスが長さ 1 の別個のセグメントとして始まる DSU を初期化します。この DSU は、現在のインデックスに対して差分条件が成立する連続したサブ配列を追跡します。$k$。 
4. 配列を初期化する`ans`長さの$n$カウントを蓄積します。`ans[k]`有効なサブ配列の数を格納します。$k$。 
5. ソートされた差異を反復処理します。 違いのある各ペアについて$d$インデックスで$i$:

 - を含むセグメントを結合します。$i$そして$i+1$。 マージされた長さは、次の場合に有効になる新しいサブ配列の数を示します。$k$に減少します$d$。 
- 次の式を使用して、このマージによって形成された新しい部分配列の数を計算します。$\text{length} \cdot (\text{length} - 1)/2$、そのセグメント内の少なくとも 2 の長さのすべての連続したサブ配列をカウントします。 
- アップデート`ans[d]`新しい部分配列の数を追加することによって。 
6. すべての差分を処理した後、カウントを下方に伝播します。$k$、`ans[k]`より大きな配列に対して有効なすべてのサブ配列が含まれます$k$。 これにより、`ans[k]`すべてを正しく反映します$k$- 絶妙な部分配列。 
7. 出力`ans[1..n-1]`テストケース用。 

機能する理由: 各ステップで、アルゴリズムは、現在の差分しきい値を満たす要素の連続セグメントを維持します。 差異による並べ替えにより、差異を処理するときに次のことが保証されます。$d$、差がより大きいすべてのペア$d$すでに合併されています。 セグメント長によってサブ配列をカウントすると、有効な各サブ配列が正確に 1 回カウントされるようになります。 カウントを下方に伝播することで、すべてのカウントが正しく累積されるようになります。$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1]*n

    def find(self, x):
        while x != self.parent[x]:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, x, y):
        x_root, y_root = self.find(x), self.find(y)
        if x_root == y_root:
            return 0
        if self.size[x_root] < self.size[y_root]:
            x_root, y_root = y_root, x_root
        self.parent[y_root] = x_root
        combined = self.size[x_root] + self.size[y_root]
        delta = combined*(combined-1)//2 - self.size[x_root]*(self.size[x_root]-1)//2 - self.size[y_root]*(self.size[y_root]-1)//2
        self.size[x_root] = combined
        return delta

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        diffs = [(abs(p[i]-p[i+1]), i) for i in range(n-1)]
        diffs.sort(reverse=True)
        ans = [0]*(n)
        dsu = DSU(n)
        for d, i in diffs:
            new_subarrays = dsu.union(i, i+1)
            ans[d] += new_subarrays
        # propagate counts downward
        for k in range(n-2, 0, -1):
            ans[k] += ans[k+1]
        print(' '.join(map(str, ans[1:n])))

solve()
```DSU クラスはセグメント サイズを効率的に追跡し、`union`この関数は、2 つのセグメントをマージするときに作成される新しいサブ配列の数を返します。 差分を降順に並べ替えると、より大きなしきい値が最初に処理されるようになります。これは、正確な累積に不可欠です。 下方伝播ステップにより、より小さな値が保証されます。`k`値はすべての有効な部分配列をカウントします。
