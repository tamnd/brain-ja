 ## 解決策
 ## 問題の理解

 それぞれの葉にちょうど 1 つのサクランボが含まれる根の生えた木があります。 

頂点で実行されるシェイク`v`のサブツリー内のすべての葉からサクランボが落ちます。`v`。 さくらんぼは一度落ちたら、決して他の揺れの影響を受けてはなりません。 いずれかのリーフが 2 つの異なるシェイクに属している場合、プロセスは無効になります。 

目標は、すべてのチェリーを集め、3 で割り切れる数のシェイクを使用することです。 

ツリーには以下が含まれます`2·10^5`すべてのテスト ケースにわたる頂点。 サブツリーを繰り返しスキャンしたり、頂点の多くの組み合わせを試行したりするアルゴリズムは、直ちに除外されます。 この入力サイズでは、テスト ケースごとに線形に近い時間が必要になります。 

難しいのは、どの頂点のセットを同時に振ることができるかを理解することです。 

頂点を揺動し、その子孫の 1 つも揺動するとします。 次に、子孫のサブツリー内のすべてのリーフは、祖先によって 1 回、子孫によって 1 回の計 2 回影響を受けます。 それは禁止されています。 

結果として、選択された頂点は祖先関係に関してアンチチェーンを形成する必要があります。 すべてのリーフは、選択された 1 つのサブツリーに属している必要があります。 

いくつかの特殊なケースは誤解されやすいものです。 

葉が 2 枚だけある木を考えてみましょう。```
1
├─2
└─3
```すべての葉をカバーする唯一の有効な方法は次のとおりです。```
{1}      -> 1 shake
{2,3}    -> 2 shakes
```どちらの数も 3 で割り切れないので、答えは次のようになります。`NO`。 

もう 1 つの重要なケースは、単一リーフ サブツリーです。```
1
└─2
```何らかの方法で葉を覆う必要があります。 頂点を振るか`1`または頂点`2`。 すべてのリーフを個別にカバーする必要があるため、サブツリーをカバーしないままにし、兄弟の貢献を期待することはできません。 

3 番目の微妙なケースは、複数の子サブツリーのそれぞれに複数の有効なシェイク カウントがある場合です。 正確な数には興味がありません。 3 で割り切れるだけが重要なので、3 を法とする数を維持するだけで十分です。 この観察を見逃すと、州の数が爆発的に増加します。 

## アプローチ

 ブルートフォース手法では、頂点のすべてのサブセットを試し、選択した頂点がすべてのリーフの有効なカバーを形成しているかどうかを確認し、選択した頂点の数が 3 で割り切れるかどうかをテストします。 

これは正しいですが、まったく現実的ではありません。 ある木`n = 2·10^5`頂点には`2^n`サブセットは処理できるものをはるかに超えています。 

有効なソリューションの構造は、より良い方向性を与えます。 

単一のルートサブツリーに焦点を当てます。 

頂点の場合`v`、可能性は2つだけです。 

震えるか`v`自体。 すると、そのサブツリーのすべての葉が即座に覆われ、子孫が揺さぶられることはありません。 

それとも震えませんか`v`。 次に、すべての子サブツリーは、それ自体のリーフすべてを独立してカバーする必要があります。 

これにより、自然にツリー DP が作成されます。 

させて`D[v]`のサブツリー内のすべての葉をカバーできる、可能なシェイク カウントのモジュロ 3 のセットになります。`v`。 

葉の場合、唯一の可能性は葉自体を振ってカウントを与えることです`1`。 

内部頂点の場合:

 1. 震えるかもしれない`v`、貢献数`1`。 
2.スキップしてもよい`v`この場合、すべての子は有効な剰余を 1 つ選択し、剰余は 3 を法として加算されます。 

残基が 3 つしかないため、各状態には最大 3 つの値が含まれます。 子を結合すると、小さなモジュロ 3 畳み込みになります。 

ブルート フォース アプローチでは、頂点の正確なサブセットが追跡されます。 重要な観察は、3 を法とするカウントのみが重要であり、すべてのサブツリーはその剰余を通じてのみツリーの残りの部分と相互作用するということです。 これにより、指数関数的検索が線形ツリー DP に折りたたまれます。

 ## アルゴリズムのチュートリアル

 1. ツリーの頂点にルートを作成します`1`。 
2. すべての子がその親の前に計算されるように、頂点を事後順序で処理します。 
3. 葉の頂点の場合、次のように設定します。```
D[v] = {1}
```同じ DP 状態の祖先が選択されていない場合は、リーフを振る必要があります。 
4. 内部頂点の場合、まず次の場合を計算します。`v`揺れていない。 

残留物から始める`{0}`。 
5. すべての子について、現在の剰余セットを子の剰余セットと結合します。 

残留の場合`a`すでに達成可能であり、残存している`b`子供の中で達成可能であり、その後は残ります`(a + b) mod 3`その子を処理した後に達成可能になります。 
6. すべての子が処理された後、結果のセットは、次の場合に達成可能なすべての剰余を表します。`v`それ自体は揺るがない。 
7. 代替を追加します。`v`動揺している。 

揺れる`v`正確に 1 回のシェイクに寄与するため、残留物`1`常に達成可能です。 
8.ストア```
D[v] = D_not_choose ∪ {1}
```9. 根を計算した後、剰余があるかどうかを確認します。`0`に属します`D[1]`。 

そうであれば、一部の有効なカバーでは 3 で割り切れる数のシェイクが使用されるため、次のように出力します。`"YES"`。 それ以外の場合は印刷します`"NO"`。 

### なぜ効果があるのか

 すべてのサブツリーについて、`D[v]`の祖先を使用せずに、そのサブツリー内のすべての葉をカバーするすべての有効な方法の残余が正確に含まれています。`v`。 

The definition is complete because every valid solution for a subtree falls into exactly one of two categories: either`v`選ばれるか選ばれないか。 

もし`v`を選択すると、サブツリー全体が 1 回のシェイクでカバーされます。 もし`v`が選択されていない場合、各子サブツリーは同じ問題を独立して解決する必要があり、合計のシェイク カウントは子のカウントの合計になります。 

有効な解決策が省略されたり、無効な解決策が導入されたりすることはありません。 サブツリー サイズの帰納法により、計算されたすべての剰余が達成可能となり、すべての達成可能な剰余が計算されます。 したがって、残留物`0`ルートにあるということは、シェイク カウントが 3 の倍数である有効なグローバル ソリューションが存在することと同等です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        g = [[] for _ in range(n)]
        for _ in range(n - 1):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        parent = [-1] * n
        order = [0]
        parent[0] = 0

        for v in order:
            for to in g[v]:
                if parent[to] == -1:
                    parent[to] = v
                    order.append(to)

        dp = [0] * n

        for v in reversed(order):
            children = [to for to in g[v] if to != parent[v]]

            if not children:
                dp[v] = 1 << 1
                continue

            cur = 1 << 0

            for ch in children:
                nxt = 0
                child_mask = dp[ch]

                for r1 in range(3):
                    if not (cur & (1 << r1)):
                        continue

                    for r2 in range(3):
                        if child_mask & (1 << r2):
                            nxt |= 1 << ((r1 + r2) % 3)

                cur = nxt

            dp[v] = cur | (1 << 1)

        ans.append("YES" if (dp[0] & 1) else "NO")

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```DFS は、深いツリーでの Python 再帰制限を回避するために反復的に実装されます。 

各 DP 状態は 3 ビットのマスクとして保存されます。 少し`r`残余の場合に設定されます`r`モジュロ 3 は達成可能です。 

例えば：```
mask = 0b101
```残基を意味します`0`そして`2`可能です。 

子の結合ステップは、モジュロ 3 の畳み込みです。 残基が 3 つしかないため、子ごとの作業は一定です。 

The leaf case deserves attention. リーフには子がありませんが、そのサブツリーにはまだ 1 つのチェリーが含まれています。 唯一の有効なローカル アクションは葉を振ることなので、その状態は正確に`{1}`。 

ルートの答えは、残留物があるかどうかをチェックします。`0`が存在します。 これは、合計の揺れ回数が 3 で割り切れる数に相当します。
