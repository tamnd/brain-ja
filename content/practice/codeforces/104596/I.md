 ## 解決策
 ## 問題の理解

 遺跡を表す小さなグリッドが与えられます。 各セルは宝物、岩、または空きスペースのいずれかです。 この構造は正方形の部屋で構成されていることが知られており、各部屋は空のセルの最大軸に沿った正方形のブロックであり、そのような各部屋にはちょうど 1 つの宝物が含まれています。 岩は部屋の構造を壊す硬い障壁として機能します。 

タスクは、これらの正方形の部屋に有効なグリッドのタイリングを再構築し、各部屋に一意のラベルを割り当てるか、有効な分解が存在しないことを判断することです。 すべての空のセルは、正確に 1 つの正方形の部屋に属している必要があり、各部屋は完全な正方形である必要があり、各部屋には正確に 1 つの宝物が含まれている必要があります。 

グリッドのサイズは最大です$100 \times 100$, そのため、現地での実現可能性を確認して地域を拡大する構築で十分です。 徹底的な分割は不要です。 

単純な失敗ケースは、重複をチェックせずに各宝物から独立して貪欲に拡張しようとしたときに発生します。 2 つの部屋が同じ空のセルをめぐって競合する可能性があり、割り当てが矛盾する可能性があります。 

例：```
1 3
$.$
```単一の宝物から貪欲に拡張すると、正方形の制約によって強制されることを無視して、行全体が 1 つの部屋として誤って割り当てられる可能性があります。$1 \times 1$宝物の周りの部屋。 部屋の境界はグローバルに制限されているため、制御されていない成長戦略は失敗します。 

## アプローチ

 ブルートフォースアプローチでは、すべての宝物に正方形のサイズを割り当ててから、誘導されたタイリングが重なりや宝物を見逃すことなくグリッドをカバーしているかどうかを検証します。 宝物ごとに、可能なすべての正方形の辺の長さを試して、一貫性をチェックできます。 これにより、正方形のサイズと位置の指数関数的な組み合わせが発生し、それぞれの検証コストが発生します。$O(nm)$、さえも実行不可能になります。$100 \times 100$グリッド。 

重要な観察は、各宝物が、有効な解の中に存在し得る、その宝物を中心とする最大正方形を一意に決定するということです。 部屋は重なり合わず、すべての空のセルをカバーする必要があるため、各宝物を可能な限り最大の有効な正方形に拡張し、一貫性を検証するだけで十分になります。 最大正方形が決定されると、それはグローバル タイリングに一貫して適合するか、インスタンスが不可能になります。 

これにより、各宝物から岩、グリッド境界、または他の部屋によってブロックされるまで問題が拡大し、すべての空のセルが正確に 1 回要求されることが保証されます。

 ## アルゴリズムのチュートリアル

 各宝物の周りに正方形の領域を成長させて部屋を構築します。 

### ステップ

 1. グリッドを読み取り、すべての宝物の座標を収集します。 

有効な解法では、各宝物はちょうど 1 つの正方形の部屋の中心であると想定されます。 
2. 各宝物について、それを含む最大の有効な正方形を決定してみます。 

すべてのセルがグリッド内に留まり、岩を通過しないようにしながら、4 方向に外側に均一に拡張します。 

辺の長さは、4 方向すべての境界または障害物までの最小距離によって制限されます。 
3. 宝物の周囲の各候補正方形について、次のことを確認します。 

正方形内のすべてのセルは空であるか、すでに一貫して割り当てられています。 

そして、広場内には現在の宝物以外に宝物はありません。 

これにより、部屋が重なり合わなくなり、各部屋に宝物が 1 つだけ含まれるようになります。 
4. 最初に遭遇した行優先の順序で各有効な正方形に一意のラベルを割り当てます。 
5. 各正方形内のすべてのセルにそのラベルを付けます。 岩は変わらず残っています。 
6. すべての宝物を処理した後、すべての非岩セルが 1 つの部屋に正確に割り当てられていることを確認します。 
7. 代入時に矛盾が発生した場合や検証に失敗した場合は、レイアウトが不可能であることを出力します。 

### なぜ効果があるのか

 各宝物は正確に 1 つの正方形の部屋に属している必要があり、正方形が重複することはできません。 可能な最大の正方形まで貪欲に拡張することで、有効なタイリングが存在する場合、構築された正方形が一意に一致することが保証されます。 小さな選択をすると、正方形の構造に違反するか、追加の宝物を導入することなく埋めることができない、覆われていない空きスペースが残ることになります。 

したがって、最大拡張プロセスではカバレッジと一意性の両方の制約が維持され、有効なタイリングが存在しない場合にエラーが発生します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]

    treasures = []
    for i in range(n):
        for j in range(m):
            if g[i][j] == '$':
                treasures.append((i, j))

    used = [[False]*m for _ in range(n)]
    ans = [['']*m for _ in range(n)]

    def can_place(x1, y1, x2, y2, ti, tj):
        seen_t = False
        for i in range(x1, x2+1):
            for j in range(y1, y2+1):
                if g[i][j] == '#':
                    return False
                if g[i][j] == '$':
                    if (i, j) != (ti, tj):
                        return False
                    seen_t = True
                if used[i][j]:
                    return False
        return seen_t

    label = ord('A')

    for ti, tj in treasures:
        best = None

        for size in range(1, 101):
            x1, y1 = ti, tj
            x2, y2 = ti + size - 1, tj + size - 1
            if x2 >= n or y2 >= m:
                break
            if can_place(x1, y1, x2, y2, ti, tj):
                best = (x1, y1, x2, y2)
            else:
                break

        if best is None:
            print("elgnatcer")
            return

        x1, y1, x2, y2 = best

        for i in range(x1, x2+1):
            for j in range(y1, y2+1):
                used[i][j] = True
                ans[i][j] = chr(label)

        label += 1
        if label == ord('Z') + 1:
            label = ord('a')

    for i in range(n):
        for j in range(m):
            if g[i][j] == '#':
                ans[i][j] = '#'
            elif ans[i][j] == '':
                print("elgnatcer")
                return

    for row in ans:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```このソリューションは、宝物を中心に各部屋を独立して構築し、最初の無効な拡張部分まで拡張します。 ヘルパー関数は、構造上の制約と部屋ごとの宝物の固有性の両方を強制します。 最終的な検証により、完全にカバーされることが保証されます。 

微妙な点は、単調な拡張です。サイズが失敗すると、それ以上のサイズは決して有効になりません。セルを追加しても、岩、別の宝物、または以前に割り当てられたセルに遭遇する可能性が高まるだけだからです。

 ## 特殊なケース

 空のスペースに囲まれた 1 つの宝物は、アルゴリズムが境界条件まで正しく拡張されるかどうかをテストします。 拡大は、さらなる成長がグリッドの境界を超えると正確に停止します。 

2 つのトレジャーをその間に空きスペースを空けて対角に配置することで、独立した拡張が干渉しないようにし、割り当てステップで既に割り当てられたセルを上書きしないようにする必要があります。 

宝物の隣に岩がある構成は、拡張の早期終了をテストします。 岩を突き抜けて成長しようとすると、大きな正方形が即座に無効になり、正しい境界検出が保証されます。
