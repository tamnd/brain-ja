 ## 解決策
 ## 問題の理解

 寸法が記載された長方形の段ボールシートが渡されます。$a \times b$。 各シートから、四隅から等しい正方形を切り取り、側面を折り畳むことによって、オープントップボックスを形成します。 カットサイズは整数です$x$、ベースのあるボックスを決定します$(a - 2x) \times (b - 2x)$と高さ$x$。 それぞれ有効$x$は、その体積に等しい数の単位立方体の本を正確に収納できる箱を生成します。$$V(x) = x \cdot (a - 2x) \cdot (b - 2x).$$すべての有効な整数カット サイズのうち、最大 3 つのボックス容量のみが考慮されます。 これら 3 つのボックス タイプのそれぞれについて、未知の固定数の本を梱包しようとします。$N$。 規定の箱容量で梱包する場合$V$、できるだけ多くの完全なボックスを満たし、残りは次のようになります。$N \bmod V$。 これらの残りは、最大、2 番目、3 番目に大きいボックス容量に対してそれぞれ与えられます。 

さらに、本の総数は既知の範囲内にあります$[f, g]$、そして解決策は一意であることが保証されています。 

任務は再構築することだ$N$。 

ジオメトリの制約は小さいです ($a, b \le 100$これは、すべてのボックス構成の候補を列挙することが可能であることを直ちに示唆しています。 難しい部分はジオメトリではなく、複数のモジュラー制約を大きな数値範囲内で一貫して調整することです。$10^9$。 

素朴なアプローチでは、あらゆることを試してしまうでしょう。$N$で$[f, g]$そして、残りの条件がすべて満たされているかどうかを確認します。 それには最大で$10^9$最悪の場合はチェックしますが、それは不可能です。 

2 番目の単純な間違いは、同じ未知の条件に対してすべての合同式が同時に成り立つ必要があることを考慮せずに、3 つの合同式を独立して扱うことです。$N$。 各ボックス サイズは異なるモジュラスを定義するため、解は 3 つの個別のチェックではなく、3 つのモジュラー演算制約の交点に存在する必要があります。 

複数のカットサイズが同じボリュームを生成する場合、微妙なエッジケースが発生します。 その場合、「上位 3 つのボックス サイズ」とは、単なる個別のボックス サイズではなく、体積別に最も優れた 3 つの異なる構成を指す必要があります。$x$値を昇順に盲目的に取得します。 

## アプローチ

 幾何学的な部分は、正しい解釈が決まれば簡単です。 すべての整数に対して$x$そのような$1 \le x < \min(a, b)/2$、体積を計算できます$V(x)$。 これにより、候補となる容量の小さなリストが得られます。 これらを体積順に並べ替えると、使用可能なボックスの最大容量、2 番目、3 番目の容量が得られます。 

問題全体に対するブルートフォース戦略は、すべての整数に対して反復処理を行うことになります。$N$で$[f, g]$、それぞれについて$N$次のことを確認します。$$N \bmod V_1 = c,\quad N \bmod V_2 = d,\quad N \bmod V_3 = e.$$これは正しいですが、間隔が次の範囲に及ぶ可能性があるため遅すぎます。$10^9$。 

重要な観察は、各条件が制限しているということです。$N$対応する体積を法とした剰余クラスに変換します。 すべての数値をスキャンする代わりに、これらのモジュール式制約を段階的に交差させることができます。 まず 1 つの合同式を修正し、次に 2 番目を満たす候補をフィルタリングし、最後に 3 番目を満たす候補をフィルタリングします。 モジュライが小さいため（せいぜい約$100^3$)、等差数列をステップ実行するのが効率的です。 

これをより構造化した方法で見ると、非共素係数を使用した合同系を解いていますが、指定された範囲内で増分フィルタリングを使用することで完全な中国剰余定理機構を回避しています。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. 有効なカット サイズをすべて列挙します。$x$1から$\min(a, b)/2 - 1$、そして計算します$V(x) = x(a-2x)(b-2x)$。 

これが機能するのは、有効なボックスは整数のカット サイズから取得する必要があり、式によってその容量が完全に決定されるためです。 
2. すべて並べ替える$(V(x), x)$ペアをボリュームの降順に並べます。 

私たちは、ボリュームごとに最高の 3 つの異なる構成を追跡します。 
3. 上位 3 つのボリュームを抽出します$V_1, V_2, V_3$、および対応する剰余$c, d, e$。 

これらは 3 つのモジュール制約を定義します。$$N \equiv c \pmod{V_1}, \quad
N \equiv d \pmod{V_2}, \quad
N \equiv e \pmod{V_3}.$$4. すべての数値を生成する$N$で$[f, g]$次のように書くことで最初の合同を満たす。$$N = c + kV_1.$$そのような最小のものから始めてください$N \ge f$、次にステップバイ$V_1$。 
5. 各候補者について$N$、次の条件も満たしているかどうかを確認します。$$N \bmod V_2 = d \quad \text{and} \quad N \bmod V_3 = e.$$最初の一致は一意の答えです。 

### なぜ効果があるのか

 各箱のサイズは、未知の本の合計数に関する固定モジュール条件を定義します。 本当の数字$N$は 3 つの等差数列の交点になければならず、すべてはさらに有限区間に制限されます。 1 つのモジュラスの完全な数列を生成し、他のモジュラスをフィルタリングすることで、すべての解が最初の数列に表示され、両方のチェックを通過する必要があるため、有効な解が見逃されないことが保証されます。 一意性により、最初に生き残った候補が答えであることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c, d, e, f, g = map(int, input().split())

    vals = []

    limit = min(a, b) // 2
    for x in range(1, limit):
        v = x * (a - 2 * x) * (b - 2 * x)
        if v > 0:
            vals.append((v, x))

    vals.sort(reverse=True)

    # take top 3 volumes
    top = vals[:3]
    V1, V2, V3 = top[0][0], top[1][0], top[2][0]
    c1, c2, c3 = c, d, e

    # ensure correct association already given by order
    def check(n):
        return (n % V1 == c1 and n % V2 == c2 and n % V3 == c3)

    start = f
    r = (start - c1) % V1
    n = start + (V1 - r) % V1

    while n <= g:
        if check(n):
            print(n)
            return
        n += V1

solve()
```カットサイズの列挙は安全です。$a, b \le 100$したがって、最大 50 個の候補値がテストされます。 並べ替えは無視できます。 

検索フェーズでは、最初の係数と一致する数値間を直接ジャンプすることで、範囲全体の反復を回避します。 アライメントステップにより、最初の候補が範囲内にあることが確認されます。$[f, g]$、間隔未満での無駄な反復を防ぎます。 

よくある実装の落とし穴は、開始点を正しく調整することを忘れることです。 から直接始まる$c$必要な範囲の外側または前に検索を配置できます。$f$。

 ## 特殊なケース

 重要なエッジケースは、複数のカットサイズが非常に近いまたは同一のボリュームを生成する場合に発生します。 このような場合、トップ 3 の選択は、最大のボリュームを選択するのではなく、ボリューム ランキングに厳密に基づいて行う必要があります。$x$価値観。 

たとえば、2 つの異なるカット サイズが同じ容量を生成する場合、並べ替えステップではそれらを個別の候補として扱う必要がありますが、「上位 3 つ」とは、単に最大の 3 つの構成ではなく、最大の容量を持つ 3 つの構成を指すことに注意する必要があります。$x$。 

もう 1 つのエッジ ケースは、等差数列の最初の有効な候補がすぐ下にある場合です。$f$。 から踏み始めたら$c$直接的には、多くの反復を無駄にしたり、範囲との調整をミスしたりする可能性があります。 正しい初期化により、最初にチェックされた値が進行中の最小の数値であることが保証されます。$f$。
