 ## 解決策
 ## 問題の理解

 の配列が与えられます$n$それぞれ 1 ～ 5000 の整数であり、この配列を 1 ～ 5000 の数値の順列に変換するように求められます。$n$。 順列とは、1 から 2 までの各整数が配置されるシーケンスです。$n$は 1 回だけ表示されます。 許可される操作は、単一の要素を他の整数に変更することです。 目標は、そのような変更の数を最小限に抑えることです。 

入力はシーケンスの長さを与えます$n$そして配列自体。 出力は、必要な置換の最小数を表す単一の整数です。 

制約は控えめです。$n$最大 5000 まで可能です。$O(n^2)$このアプローチではアレイを繰り返しスキャンする必要があるため、次のような解決策を目指す必要があります。$O(n \log n)$または$O(n)$。 メモリ使用量も制限されていますが、サイズ 5000 の周波数配列の保存は許容されます。 

エッジ ケースには、すでに有効な順列を形成しているシーケンス、すべての要素が同じシーケンス、または多くの数値が 1 から 1 への範囲外であるシーケンスが含まれます。$n$範囲。 たとえば、次の場合$n = 3$そして配列は$[5, 5, 5]$の場合、3 つの数値すべてを 1、2、3 に変更する必要があるため、正しい出力は 3 です。不注意なアプローチでは、範囲をチェックせずに重複のみをカウントし、間違った答えが生成される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、1 から 2 までのすべての数値を反復処理することです。$n$それぞれが配列内に存在するかどうかを確認します。 欠落している場合は、配列をスキャンして要素を置き換えることができます。 これは原理的には機能しますが、繰り返しスキャンすると複雑になります。$O(n^2)$最悪の場合、遅すぎる$n = 5000$。 

最適なアプローチはカウントを活用します。 有効な順列の場合、各数値は 1 から 1 までであることがわかります。$n$は 1 回だけ出現する必要があります。 この範囲外の数値、または範囲内の重複する数値は変更する必要があります。 したがって、各数値の頻度を計算し、1 から 2 までの数値を反復処理できます。$n$。 欠落している各番号は、必要な 1 つの変更に対応します。 重複または範囲外の「余分な」数値もカウントします。 最小変更数は欠落している数値の合計数であり、常に置換するのに十分な追加の数値と一致します。 

その洞察は、問題は欠損数と過剰数を数えることに帰着するということです。 余分な要素は不足しているスロットを埋めるために再利用できるため、配列をソートしたり、複雑なスワップを試みたりする必要はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 周波数配列を初期化する`freq`サイズの$n+1$1 から 1 までの数字の出現を数える$n$。 今のところ、この範囲外の数値は無視してください。 
2. 入力配列を反復処理します。 要素ごとに$a_i$1～1以内の場合$n$、増分`freq[a_i]`。 それ以外の場合は、「過剰な」要素としてカウントされ、最終的には置換が必要になります。 
3. カウンタを初期化する`changes`ゼロに。 数値 1 から 1 までを繰り返します$n$。 もし`freq[i]`ゼロは数値を意味します$i$が欠けています。 インクリメント`changes`1つずつ。 頻度が 1 より大きい数値の場合、余分なコピーが余分な要素のプールに寄与します。 
4. 戻る`changes`。 欠落している各数値は、重複または範囲外の数値からの追加要素を使用して埋めることができるため、この値はまさに必要な置換の数です。 

不変条件は、頻度を数えた後、欠落している数値の合計が必要な最小置換に等しいということです。 他の欠損数に影響を与えることなく、過剰な数値を欠損数に変更できるため、どの要素を変更するかが曖昧になりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

freq = [0] * (n + 1)
excess = 0

for x in a:
    if 1 <= x <= n:
        freq[x] += 1
    else:
        excess += 1

changes = 0
for i in range(1, n + 1):
    if freq[i] == 0:
        changes += 1

print(changes)
```コードはまず、有効な順列範囲内の各数値が何回出現するかをカウントします。 1 ～ 以外の任意の数値$n$自動的に超過とみなされます。 次に、1 から 1 までの数字ごとに、$n$、不足しているかどうかを確認します。 欠落している各番号は、必要な 1 つの変更に直接対応します。 質問ではカウントのみが求められるため、どの超過数値が変更されるかを正確に追跡する必要はありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    a = list(map(int, input().split()))
    freq = [0] * (n + 1)
    excess = 0
    for x in a:
        if 1 <= x <= n:
            freq[x] += 1
        else:
            excess += 1
    changes = 0
    for i in range(1, n + 1):
        if freq[i] == 0:
            changes += 1
    return str(changes)

# Provided samples
assert run("3\n3 1 2\n") == "0", "sample 1"
assert run("4\n4 4 1 5\n") == "2", "sample 2"

# Custom cases
assert run("1\n1\n") == "0", "single element correct"
assert run("3\n5 5 5\n") == "3", "all out of range"
assert run("5\n1 2 2 4 5\n") == "1", "one missing in range"
assert run("5\n1 1 1 1 1\n") == "4", "all duplicates"
assert run("5\n2 3 4 6 7\n") == "2", "mix of duplicates and out-of-range"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1\n1 | 0 | 最小入力、すでに正しい |
 | 3\n5 5 5 | 3 | すべての数値が範囲外です。すべて変更する必要があります |
 | 5\n1 2 2 4 5 | 1 | 1 つの番号が欠落しており、いくつかの重複があります |
 | 5\n1 1 1 1 1 | 4 | すべて重複しているため、複数の変更が必要です |
 | 5\n2 3 4 6 7 | 2 | 1 と 5 がありません。余分な範囲外の数値です。 

## 特殊なケース

 シーケンスのすべての数値が順列範囲外の値に等しい場合、たとえば、`[6, 6, 6]`のために`n=3`の場合、アルゴリズムは 3 つすべてを超過としてカウントし、欠落している数値 1、2、3 を特定します。`changes`カウンターは欠番の数に合わせて 3 になります。 

シーケンスの範囲内に重複がある場合、次のようになります。`[1, 1, 2, 4]`のために`n=4`、アルゴリズムは周波数をカウントします`[0,2,1,0,1]`欠落している番号 3 を特定します
