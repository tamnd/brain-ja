 ## 解決策
 ## 問題の理解

 配列が与えられ、順序を維持しながら正確に k 個の要素を選択するすべての方法を考えるように求められます。ただし、順序制約はどの値が選択されるかには影響せず、どのサブセットが有効であるかのみに影響します。 選択された k 個の要素のグループごとに、その最大値と最小値のみを調べ、それらの差を取得します。 タスクは、サイズ k のすべての可能な部分列にわたってこの量の平均を計算することです。 

重要なオブジェクトは、サブシーケンス構造自体ではなく、インデックスのすべての k 要素サブセットにわたる均一な分布です。 サイズ k のインデックスのすべてのサブセットは同じ確率であるため、問題はサブセットに対する純粋な組み合わせの期待に帰着します。 

制約は大きく、テスト ケース全体で n は最大 5 · 10^5 です。 サブセットを列挙したり、すべてのペアを直接処理したりする解決策は、少なくとも二次関数になるため、直ちに実行不可能になります。 ペアごとに O(n log n) スタイルのアプローチでさえ遅すぎます。 これは、ソリューションでは期待値を、線形または線形に近い時間で事前計算できる個々の要素または少数の構造化寄与の合計に減らす必要があることを強く示唆しています。 

素朴な試みを打ち破る微妙な点は、隣接情報を保持しているかのようにサブシーケンスを扱うことです。 そうではありません。 組み合わせをカウントする際に重要となるのは、連続した構造ではなく、相対的なインデックス順序のみです。 もう 1 つのよくある落とし穴は、最大値と最小値を同時に直接推論しようとすることであり、二重カウントや複雑な依存関係につながります。 正しい方向は、期待値の最大値と最小値の寄与を分離し、依存関係を取り除くことです。 

具体的な故障モードとして、すべてのサブセットを列挙することで小さな n についてシミュレーションを試みることを検討してください。 n = 50 および k = 25 の場合、これはすでに天文学的な大きさです。 もう 1 つの間違った考え方は、ペア (i, j) を固定し、両方を極値要素として選択するサブセットの数を正しく考慮せずに、それらの間の要素が独立していると仮定しようとすることです。 依存関係は純粋に組み合わせ的なものであり、二項係数で表現する必要があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 サイズ k のすべてのサブセットを列挙し、その最小値と最大値を計算し、それらの差を累積します。 これは、一様分布に対する期待の定義に直接従うため、正しいです。 ただし、そのようなサブセットの数は C(n, k) であり、中規模の k に対して n が指数関数的に増加します。 n = 40 の場合でも、これは実行不可能になります。 

重要な観察は、違いに対する期待が期待の差にきれいに分かれているということです。 式 max(S) − min(S) は E[max(S)] − E[min(S)] となります。 これにより、最小値と最大値の間の相互作用が完全に削除され、問題は 2 つの独立した順序統計の期待値に縮小されます。 

今度は構造が古典的になります。 配列をソートした後、各要素 ai は、選択されたサブセットの最大値または最小値の候補と見なすことができます。 サイズ k のサブセットの数が ai を最大値として持つか、同様にいくつのサブセットが ai を最小値として持つかを計算するだけで済みます。 このような各カウントは、ソート順で左側または右側にある要素の数に基づいて、二項係数に直接変換されます。 

これにより、問題は、階乗事前計算を使用して計算された組み合わせ重みを使用して、ソートされた配列に対する線形スイープに変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 | O(C(n, k) · k) | O(k) | 遅すぎる |
 | 注文統計による期待値 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 ### 1. 配列をソートする

位置がランクに対応するように配列をソートします。 これにより、インデックスのみを使用して、特定の要素より小さい要素の数、または大きい要素の数を推論することができます。 

### 2. 階乗と逆階乗を事前計算する

 法の下で二項係数が必要なので、n までの階乗と剰余逆数を事前計算します。 これにより、すべての C(n, k) クエリが O(1) になります。 

### 3. 各要素の寄与を修正する

 期待値は、選択されたサブセットの最大値または最小値に基づいて各要素が寄与するすべての要素の合計として解釈されます。 

位置 i (0 からインデックス) にある要素について、2 つの確率を計算します。 

それが最大である確率は、その前の i 要素から残りの k − 1 要素を選択する方法の数をサブセットの総数で割ったものです。 

それが最小である確率は、その後の要素から k − 1 個の要素を選択する方法の数です。 

これらは二項係数を使用して直接表現されます。 

### 4. 貢献度の集計

 各要素 ai について、その値に最大値と最小値の確率の差を乗じた値を加算します。 これにより、最大値−最小値に対する正味の期待寄与が得られます。 

### 5. サブセットの総数で正規化する

 すべての確率は同じ分母 C(n, k) を共有するため、最後にその逆モジュラーを乗算します。 

### なぜ効果があるのか

 すべてのサブセットには一意の最大値と最小値があるため、すべての要素の寄与を合計すると、各サブセットの最大値は「最大」項で 1 回だけカウントされ、各サブセットの最小値は「最小」項で 1 回だけカウントされます。 期待値の線形性により、この分解によって構成が失われたり二重にカウントされたりしないことが保証されます。 組み合わせ公式により、各要素が極値の役割を果たすサブセットの数によって正確に重み付けされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

maxn = 5 * 10**5 + 5
fact = [1] * (maxn)
invfact = [1] * (maxn)

for i in range(1, maxn):
    fact[i] = fact[i - 1] * i % MOD

invfact[maxn - 1] = pow(fact[maxn - 1], MOD - 2, MOD)
for i in range(maxn - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    if k == 1:
        print(0)
        continue

    total = C(n, k)
    inv_total = modinv(total)

    ans = 0

    for i, val in enumerate(a):
        # as maximum: choose k-1 from left side
        max_cnt = C(i, k - 1)
        # as minimum: choose k-1 from right side
        min_cnt = C(n - i - 1, k - 1)

        ans += val * (max_cnt - min_cnt)
        ans %= MOD

    ans = ans * inv_total % MOD
    print(ans)
```実装では階乗を 1 回事前計算します。これは、複数のテスト ケースが同じ境界を共有するために必要です。 コア ループはソート順を使用して、インデックス i が正確に i 個の小さい要素と n − i − 1 個の大きい要素を持つものとして解釈します。これにより、直接二項カウントが可能になります。 

特殊なケース k = 1 は、最大値と最小値が一致し、答えがゼロになるため、個別に処理されます。 

微妙な実装の詳細は、係数を適用する前に中間値が負になる可能性があるため、max_cnt から min_cnt を減算するときにモジュラー演算を慎重に維持することです。 

## 実用的な例

 k = 2 の配列 [4, 1, 3, 1] を考えてみましょう。 

ソートすると、[1, 1, 3, 4] が得られます。 サブセットの合計は C(4, 2) = 6 です。 

要素ごとの寄与を計算します。 

| 私 | 値 | C(i,1) | C(n-i-1,1) | 純貢献 |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 0 | 3 | 1・(0−3) |
 | 1 | 1 | 1 | 2 | 1 · (1 − 2) |
 | 2 | 3 | 2 | 1 | 3・(2−1) |
 | 3 | 4 | 3 | 0 | 4・(3−0) |

 合計すると正規化前の分子が得られます。 6で割ると期待値が得られます。 

このトレースは、各要素が 2 要素のサブセットのエンドポイントとして機能できるかどうかに応じて、それぞれがどのように独立して寄与するかを示します。 

ここで、k = 1 の [1, 1, 1] を考えます。すべてのサブセットは単一の要素であるため、max − min は常に 0 になります。寄与がキャンセルされるため、アルゴリズムは直接 0 を返します。

## テストケース```python
import sys, io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    maxn = 100
    fact = [1] * (maxn)
    invfact = [1] * (maxn)
    for i in range(1, maxn):
        fact[i] = fact[i - 1] * i % MOD
    invfact[maxn - 1] = pow(fact[maxn - 1], MOD - 2, MOD)
    for i in range(maxn - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    def C(n, r):
        if r < 0 or r > n:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

    t = int(input())
    out = []
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        if k == 1:
            out.append("0")
            continue

        total = C(n, k)
        inv_total = pow(total, MOD - 2, MOD)

        ans = 0
        for i, val in enumerate(a):
            max_cnt = C(i, k - 1)
            min_cnt = C(n - i - 1, k - 1)
            ans += val * (max_cnt - min_cnt)
            ans %= MOD

        out.append(str(ans * inv_total % MOD))

    return "\n".join(out)

 ## 特殊なケース

 k が 1 に等しい場合、すべてのサブシーケンスには 1 つの要素が含まれるため、最大値と最小値は同一になります。 アルゴリズムは、すぐにゼロを返し、式内で発生する組み合わせのキャンセルに一致することでこれを処理します。 

k が n と等しい場合、サブシーケンスは 1 つだけ、つまり配列全体になります。 各要素の寄与は決定論的な最大値と最小値に分解され、完全な確率の重みでちょうど 1 つの要素が最大値としてカウントされ、もう 1 つが最小値としてカウントされるため、式は正しく max(a) − min(a) になります。 

すべての値が等しい場合、すべてのサブセットの範囲はゼロになります。 式では、ソート後にすべての項が同一の値の差を乗算するため、合計はシステムを法としてゼロになり、期待される結果と一致します。 

値が負の場合、すべての組み合わせ推論は大きさの符号に依存しないため、何も変わりません。 この式は期待値の線形性にのみ依存するため、負の寄与は特別なケースなしで自然に処理されます。
