 ## 解決策
 ## 問題の理解

 入力は、遺伝子マーカーの環状チェーンを記述します。 マーカーは 1 つの遺伝子タイプに属し、開始マーカーまたは終了マーカーのいずれかになります。 円をどこで切り取るかを選択できるため、円の順序が通常の順序に変わります。 すべての遺伝子タイプについて、その新しい順序で独自のマーカーのみを調べ、それらが有効なバランスの取れた括弧の配列を形成しているかどうかを調べます。開始部分は開き括弧のように機能し、終了部分は閉じ括弧のように機能します。 

課題は、最も多くの遺伝子タイプを有効にする切断位置を選択することです。 複数のカットが同じスコアを与える場合、元のインデックス付けで最も古いカットを選択する必要があります。 

配列の長さは 100 万個のマーカーに達することがあります。 そうなると、すべてのカットを個別にチェックすることは直ちに不可能になります。 考えられるすべてのカットに対してすべてのマーカーをスキャンするソリューションでは、最悪の場合でも約 10^12 の操作が必要になりますが、これは数秒で可能な作業をはるかに超えています。 アルゴリズムはシーケンス全体を一定の回数だけ処理する必要があり、O(n) の目標を与えます。 

微妙なケースは、円や修正不可能な遺伝子タイプによって引き起こされます。 たとえば、次のことを考えてみましょう。```
2
s1 s1
```開始点が 2 つあり、終了点がないため、有効なカットはありません。 カットが非負のプレフィックスを生成するかどうかだけをチェックする方法では、このタイプが誤ってカウントされます。 

もう 1 つのケースは、有効なカットが元の始まりではない場合です。```
4
e1 s1 e1 s1
```正しい答えは次のとおりです。```
2 1
```2 番目のマーカーが表示される前にカットする`s1 e1 s1 e1`、バランスが取れています。 入力順序をチェックするだけのメソッドでは、シーケンスが循環していることを見逃してしまいます。 

## アプローチ

 直接的なアプローチは、可能な限りあらゆるカットを試すことです。 カットごとに、すべての遺伝子タイプのマーカーを結果の順序で抽出し、括弧内の条件が当てはまるかどうかを検証します。 考えられるすべての答えが検討されるため、これは正しいです。 ただし、n 個の可能なカットと、それぞれを検査するための最大 n 個のマーカーがあり、カットだけで O(n^2) の作業が必要になります。 n が 10^6 である場合、これは不可能です。 

重要な観察は、単一の遺伝子タイプを独立して分析できることです。 すべての開始マーカーに +1 の値を割り当て、すべての終了マーカーに -1 の値を割り当てます。 シーケンスは、合計がゼロの場合にのみ有効であり、累計が負になることはありません。 

循環シーケンスの場合、シーケンスを回転すると、累計の開始位置が変わります。 カット前のプレフィックスの合計が x であるとします。 回転後、すべてのプレフィックス値は、元のプレフィックス値から x を引いた値になります。 回転されたシーケンスは、x が元のシーケンスの最小プレフィックス値である場合にのみ有効です。 これは、すべての遺伝子タイプが、その最小プレフィックス和がどの位置で発生するかを知るだけでよいことを意味します。 

カットごとにすべての遺伝子タイプを再計算するのではなく、カットを一度に 1 位置ずつ移動します。 カットが 1 つの遺伝子タイプのマーカーを通過すると、そのタイプの現在のプレフィックス値のみが変更されます。 現在のカットで最小プレフィックスを持つ遺伝子タイプの数を維持できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(遺伝子の種類の数) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 循環シーケンスを読み取り、すべての遺伝子タイプについて、元の入力順序をたどる間に到達した合計バランスと最小プレフィックス値を計算します。 

合計バランスがゼロではない遺伝子タイプは、回転後に有効なネストを形成できないため、破棄されます。 
2. 最初のマーカーの前のカットから始めます。 残りのすべての遺伝子タイプの現在のプレフィックス値は 0 です。 現在、この値が最小プレフィックスに等しい有効な遺伝子タイプがいくつあるかを数えます。 

このカウントが、最初に考えられるカットの答えになります。 
3. カットを一度に 1 マーカーずつ前方に移動します。 タイプ i のマーカーを渡すとき、タイプ i の現在のプレフィックス値を更新します。 開始マーカーはそれを 1 つ増加させ、終了マーカーはそれを 1 つ減少させます。 
4. タイプの現在値を変更した後、そのタイプが現在のスコアに寄与するかどうかを更新します。 以前は最小値に等しかったが、現在は最小値に等しくない場合は、スコアから 1 つ削除します。 最小値と等しくなった場合は1を加算します。 
5. 確認された最大スコアを追跡します。 2 つのカットのスコアが同じ場合は、最も古いカット インデックスを保持します。 

なぜ効果があるのか:

 ある遺伝子タイプの場合、カットは、そのカットの直前のバランスが円上のどこかで到達した最小バランスであるときに正確に有効になります。 アルゴリズムは、円の周りを移動しながら、あらゆるカットを実行する前に現在のバランスを維持します。 各マーカーはそれ自体の遺伝子タイプにのみ影響するため、更新のたびにすべてのタイプの正しい有効性ステータスが維持されます。 追跡されるスコアは常に現在のカットの有効な遺伝子タイプの数であるため、検出された最大値が必要な答えとなります。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    data = sys.stdin.buffer.read()
    if not data:
        return

    n = int(data.split()[0])
    tokens = data.split()[1:]

    size = 1000001
    total = array('i', [0]) * size
    pref = array('i', [0]) * size
    mn = array('i', [0]) * size

    types = set()

    for token in tokens:
        if token[0] == 115:
            x = int(token[1:])
            total[x] += 1
            pref[x] += 1
        else:
            x = int(token[1:])
            total[x] -= 1
            pref[x] -= 1
        if pref[x] < mn[x]:
            mn[x] = pref[x]
        types.add(x)

    valid = []
    for x in types:
        if total[x] == 0:
            valid.append(x)

    cur = array('i', [0]) * size
    good = 0
    for x in valid:
        if mn[x] == 0:
            good += 1

    best = good
    ans = 1

    for idx, token in enumerate(tokens, 1):
        if token[0] == 115:
            x = int(token[1:])
            before = cur[x]
            after = before - 1
        else:
            x = int(token[1:])
            before = cur[x]
            after = before + 1

        if total[x] == 0:
            if before == mn[x]:
                good -= 1
            cur[x] = after
            if after == mn[x]:
                good += 1
        else:
            cur[x] = after

        if idx < n + 1 and good > best:
            best = good
            ans = idx + 1

    print(ans, best)

if __name__ == "__main__":
    solve()
```最初のパスでは、すべての遺伝子タイプに必要な情報が計算されます。 全体のバランスによってタイプが可能かどうかが決まり、最小プレフィックス値によってどのカットがそのタイプを有効にするかが決まります。 

2 番目のフェーズでは、カットの移動をシミュレートします。 配列`cur`現在のカットの直前に、すべての有効なタイプの現在の残高を保存します。 マーカーがシーケンスの最初から最後まで移動すると、バランス基準はちょうど 1 ステップだけ変化するため、更新する必要があるエントリは 1 つだけです。 

インデックスは少し繊細です。 この問題ではカット後のマーカーの位置が求められますが、シミュレーションでは当然その位置より前で終わるプレフィックスが考慮されます。 マーカー加工後`idx`、次のカットはマーカーの前にあります`idx + 1`、これが、保存された回答が使用する理由です`idx + 1`。 

## 実用的な例

 最初のサンプルの場合:```
e1 e1 s1 e2 s1 s2 e42 e1 s1
```入力を通過する際のタイプ 1 のバランスは次のとおりです。 

| 前にカット | 現在の残高 | 最低残高 | 有効なタイプ |
 | --- | --- | --- | --- |
 | 1 | 0 | -2 | 0 |
 | 2 | 1 | -2 | 0 |
 | 3 | 2 | -2 | 1 |
 | 4 | 1 | -2 | 0 |

 最良のカットはマーカー 3 の前で、サンプル出力と一致します。 

2 番目のサンプルの場合:```
s1 s1 e3 e1 s3 e1 e3 s3
```有効な回転は、現在の残高が最小値のときに表示されます。 

| 前にカット | 有効な遺伝子タイプ |
 | --- | --- |
 | 1 | 0 |
 | 4 | 1 |
 | 8 | 2 |

 最大スコアは 2 で、そのスコアを持つ最も早いカットはポジション 8 です。

 ## 特殊なケース

 開始と終了の数が異なる遺伝子タイプは、その合計バランスがゼロではないため、アルゴリズムによって無視されます。 現在の合計はローテーション後に一時的に有効に見えるかもしれませんが、最終的な合計がゼロに戻ることはありません。 

次のようなシーケンスの場合:```
4
e1 s1 e1 s1
```最初のパスでは、タイプ 1 の合計残高が 0 で、最小プレフィックス値が -1 であることが記録されます。 第 2 フェーズでは、現在のバランスが -1 に等しいカットのみがカウントされます。 このような最も早いカットは位置 2 であり、正しい結果が得られます。 

複数のカットが同じ最大スコアを与える場合、アルゴリズムは厳密に大きいスコアに基づいてのみ答えを更新します。 位置は左から右に処理されるため、最初に保存された位置は、すべての最適な選択肢の中で自動的に最小の位置になります。
