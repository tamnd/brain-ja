 ## 解決策
 ## 問題の理解

 板の色の配列として表現された線形の橋が与えられています。 ヴィカは最初のプランよりも先にスタートし、最後まで到達したいと考えています。 彼女は、同じ色を共有する選択された一連の板の上のみを歩くことが許可されており、選択した板から次の板に進むたびに、選択されていない板の隙間を横切らなければならない場合があります。 ステップのサイズは、連続して選択された位置間でスキップされた板の数と正確に一致し、目標は、そのような最大のスキップを最小限に抑えることです。 

追加のひねりが 1 つあります。 歩く前に、Vika は最大でも 1 枚の板を任意の色に再ペイントすることができ、単一の位置で配列を効果的に変更できます。 彼女は何も再描画しないことを選択することもできます。 

タスクは、開始境界と終了境界を含む、連続して選択された位置間の最大ギャップが最小になるように、色とその色の位置のサブシーケンス (おそらく 1 回の変更後) を選択することです。 

答えは、選択した色の出現によって引き起こされるギャップに関するミニマックス問題です。 色を固定すると、その出現によって配列がセグメントに分割され、最悪のセグメントによって、その色が歩行経路としてどの程度「危険」であるかが決まります。 

この制約は、すべてのテスト ケースにわたって最大 2⋅10^5 の板を処理する必要があることを意味します。 テスト ケースごとに 2 次的な解はすぐに失敗します。 ケースごとにほぼ線形または線形算術的な方法が必要で、全体的には線形であることが理想的です。 

単純な試みでは、各色と可能な再ペイント位置を試し、ギャップを再計算し、最大ステップを評価します。 これにより配列が繰り返しスキャンされ、簡単に O(n^2) まで膨れ上がります。 

すべての板がすでに同じ色である場合、微妙な特殊なケースが発生します。 その場合、ギャップはまったく存在しないため、答えはゼロになります。 もう 1 つは、色が完全に交互になっている場合で、最適なサブシーケンスであっても、再ペイントでギャップを埋めない限り、避けられない大きなギャップが生じます。 

## アプローチ

 ブルートフォースの観点では、色を固定し、そのすべての位置を収集し、それらの位置のみを歩くことによって引き起こされる最大ギャップを計算します。 再ペイントせずに、これは簡単です。 問題は再描画操作です。選択した色の追加のオカレンスを任意の位置に 1 つ挿入し、1 つの大きなギャップを 2 つの小さなギャップに効率的に分割することができます。 

これをすべての色とすべての可能な挿入位置についてシミュレートすると、ギャップ構造を繰り返し再計算することになります。 各色について、すべてのギャップ値を維持し、考えられるすべての分割点をテストすると、ギャップ候補ごとに O(n) の作業が発生し、最悪の場合は O(n^2) になります。 

重要な観察は、固定色の場合、対象となる構造はそのギャップ配列、つまり配列の境界からのエッジを含む、連続する出現間の距離であるということです。 再塗装を行わない色の答えは、単純に最大ギャップです。 1 回の再ペイントで、ギャップを取得して 2 つの部分に分割し、そのギャップが固有のボトルネックである場合にのみ最大値を減らすことができます。 

これにより、問題は、色ごとに、余分なオカレンスを 1 つ最適に挿入することによって最大のギャップをどれだけ削減できるかを評価することになります。 挿入は最大のギャップ内に配置し、できるだけ均等に分割して、その寄与が天井(ギャップ/2)になるようにするのが最適です。 他のすべてのギャップは変更されません。 したがって、各色について必要なのは、そのギャップ マルチセットとその最大値と 2 番目の最大値だけです。 

1 回のパスで各色のすべての位置を計算し、O(occurrences) のギャップを計算し、最良の 2 つの最大値を維持できます。 全体的な答えは、すべての色の達成可能な最大ギャップの最小値です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 各色のインデックスをリストにグループ化します。 これは、ギャップ構造がアレイ全体の繰り返しの絶対スキャンではなく、相対位置のみに依存するため必要です。 
2. 各色について、仮想エンドポイント 0 および n+1 を追加して拡張位置リストを構築します。 これらは最初の板の前の開始と最後の板の後の終了を表すため、境界のギャップは均一に処理されます。 
3. 連続する位置間のすべてのギャップを計算します。 各ギャップは、ある色から次の色に移動するときにスキップされる板の数を表します。 
4. 最大のギャップ gmax と 2 番目に大きいギャップ g2 を求めます。 分割できるギャップは 1 つだけであるため、これら 2 つの値によって 1 回の再ペイント後の最良の結果が決まります。 
5. 再塗装しない場合、この色のコストは gmax です。 再ペイントする場合は、最大のギャップを 2 つの部分に分割し、ceil(gmax / 2) まで減らすことを選択します。 新しい最悪のギャップは max(g2, ceil(gmax / 2)) になります。 
6. すべての色についてこの最適値を計算し、すべての色にわたる最小値を取得します。 
7. すべての色の最小値を出力します。 

### なぜ効果があるのか

 固定色の場合、有効なウォーキング戦略は、その色のすべての出現を順番に選択することに対応し、再描画により人工的に挿入された 1 つの出現によって増加する可能性があります。 この挿入されたポイントは、連続する出現間の 1 つの間隔にのみ影響を与えることができるため、元のギャップは 1 つだけ分割できます。 より小さなギャップを削減しても最大値は改善されないため、最適な分割は常に最大のギャップをターゲットとします。 したがって、最適な解決策は 2 つの最大ギャップのみに依存し、構造が完全に圧縮可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        c = list(map(int, input().split()))

        pos = [[] for _ in range(k + 1)]
        for i, x in enumerate(c, start=1):
            pos[x].append(i)

        ans = n

        for color in range(1, k + 1):
            if not pos[color]:
                continue

            arr = [0] + pos[color] + [n + 1]

            gaps = []
            for i in range(1, len(arr)):
                gaps.append(arr[i] - arr[i - 1] - 1)

            if len(gaps) == 0:
                ans = 0
                continue

            gmax = max(gaps)
            g2 = 0
            for g in gaps:
                if g != gmax:
                    g2 = max(g2, g)

            best = max(g2, (gmax + 1) // 2)
            ans = min(ans, best)

        print(ans)

if __name__ == "__main__":
    solve()
```このコードは、単一パスで色ごとに位置をグループ化し、線形前処理を保証します。 色ごとに、境界を拡張した位置リストを構築して、エンドポイントのギャップが特別なケースなしで処理されるようにします。 次に、1 回の走査ですべてのギャップを計算し、ソートなしで最大と 2 番目に大きいギャップを抽出します。これにより、色ごとの処理が発生数において線形に保たれます。 

微妙な点は、0 回または 1 回出現する色の処理です。 出現回数がゼロの場合、色は無関係です。 1 回発生すると、ギャップにはプレフィックスとサフィックス全体が含まれます。単一のギャップ リストがブリッジの両側を正しく表すため、式は依然として正しく適用されます。

 ## 特殊なケース

 単色の橋のような`[1,1,1,...]`隙間が生じません。 アルゴリズムはポジションを構築します`[0,1,2,...,n,n+1]`ここで、すべての内部ギャップはゼロであるため、gmax と g2 は両方ともゼロとなり、答えはゼロになります。 

1 回出現する色には 2 つの境界ギャップが生じます。 例えば`[2,1,1,1,3]`カラー 2 の場合は位置が得られます`[0,1,5]`そしてギャップ`[0,3]`。 最大ギャップはセグメント全体の長さとして正しく処理されます。 

高度に交互の配列では、小さいながらも頻繁にギャップが発生します。 このアルゴリズムは依然として色ごとの最大ギャップのみを追跡するため、すべてのパスをシミュレートする必要がなく、正しい処理が保証されます。
