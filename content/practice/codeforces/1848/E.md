 ## 解決策
 ## 問題の理解

 私たちは、石を水上の特定の点に正確に着地させる、明確な正の整数の力の数を数えるように求められます。 石は等差数列でスキップします。最初のタッチは離れたところで起こります。$f$、次の時間$f + (f-1)$、 それから$f + (f-1) + (f-2)$、など、距離の増分が 1 に達するまで続きます。これにより三角形の系列が形成され、力を入れて投げた石の合計距離が計算されます。$f$は$f + (f-1) + \dots + 1 = f(f+1)/2$。 

初期座標が与えられると$x$、整数のリストを連続して乗算します。$x_1, x_2, \dots, x_q$取得するため$X_1, X_2, \dots, X_q$、そしてそれぞれについて計算する必要があります$X_i$異なる正の整数の数$f$そのような$f(f+1)/2$分割する$X_i$石が正確に着地するように$X_i$。 答えはモジュロで計算されます$M$、これは素数であることが保証されています。 

制約は困難です。$x$まで可能です$10^9$、$q$まで$10^5$、そしてそれぞれ$x_i$まで$10^6$。 これにより、可能性のあるブルートフォース反復が排除されます$f$それぞれの値$X_i$、三角数の和が二次関数的に増加するため、$X_i$到達できる$10^{15}$またはそれ以上。 不注意な実装は、次のようなエッジケースでも失敗する可能性があります。$x = 1$または乗算の繰り返し$X_i$急速に増大し、整数オーバーフローやモジュロ誤りが発生します。 

微妙なケースとしては、$X_i$小さい、みたいな$X_1 = 1$。 のみ$f = 1$三角和の公式が次の結果を与えるため、機能します。$1(1+1)/2 = 1$。 コードが単純にすべてを反復処理すると、$f \le X_i$非効率的になるか、適切なモジュロ動作が失われる可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべての正の整数が試行されます。$f$それぞれに$X_i$、コンピューティング$f(f+1)/2$そしてそれが等しいかどうかを確認する$X_i$。 これは少数の場合は機能しますが、次の場合は失敗します。$X_i$まで$10^{15}$反復回数は次のとおりであるため、それ以上にする必要があります。$O(\sqrt{X_i})$、これは受け入れられません。$q = 10^5$。 

重要な洞察は、三角和の公式を逆にすることです。 させたら$T(f) = f(f+1)/2$、それでは必要です$f$そのような$T(f) = X_i$。 解決中$f(f+1)/2 = X_i$二次方程式が導かれます$f^2 + f - 2 X_i = 0$。 二次公式を使用すると、$f = \frac{-1 + \sqrt{1 + 8 X_i}}{2}$。 のために$f$整数になるには、$1 + 8 X_i$たとえば、完全な正方形でなければなりません$k^2$、 その後$f = (k-1)/2$。 

これが分かれば、問題は整数解の数を数えるということになります。$f$方程式に$f(f+1)/2 = X_i$。 素数ごとに$M$、剰余の除算が必要な場合、フェルマーの小さな定理を適用して逆剰余を効率的に計算できます。$M$。 乗算する$X_i$連続して$x_i$効率を上げるにはモジュラー演算のみが必要ですが、完全二乗のチェックでは大きな整数を処理する必要があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(q * sqrt(X_i)) | お(1) | 遅すぎる |
 | 最適 | O(q * log X_i) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化$current = x$。 の答えを計算します$X_1 = x x_1$、$X_2 = X_1 x_2$、...、$X_q = X_{q-1} x_q$。 
2. それぞれについて$i$から$1$に$q$、乗算する$current$による$x_i$そしてそれを次のものとして保存します$X_i$。 
3. それぞれについて$X_i$、計算する$d = 1 + 8 * X_i$。 これは書き換えから来ています$f(f+1)/2 = X_i$として$f^2 + f - 2 X_i = 0$。 
4. の整数の平方根を計算します。$d$、呼んでください$k$。 もし$k*k \neq d$の場合、整数は存在しません$f$, したがって、答えは0です。 
5. それ以外の場合は計算します$f = (k - 1) // 2$。 もし$f > 0$、これは個別の力の数です。 それ以外の場合、答えは 0 です。結果を剰余として取得します。$M$。 
6. それぞれの答えを印刷します。$X_i$順番に。 

なぜ機能するのか: 導出により、最初の値の合計が保証されます。$f$正の整数が等しい$X_i$まさにいつ$1 + 8 X_i$は完全な正方形です。 前向きな解決策は 1 つだけです$f$そのようなものごとに$X_i$、連続した乗算による算術演算は正確さを維持します。 小切手$k*k = d$非整数の解をカウントしないようにします。 

## Python ソリューション```python
import sys, math
input = sys.stdin.readline

x, q, M = map(int, input().split())
xs = list(map(int, input().split()))

current = x
for xi in xs:
    current *= xi
    d = 1 + 8 * current
    k = int(math.isqrt(d))
    if k * k != d or (k - 1) % 2 != 0:
        print(0 % M)
    else:
        f = (k - 1) // 2
        print(f % M)
```このソリューションでは、現在の座標を徐々に乗算し、再計算を回避します。`math.isqrt`大きな整数の整数平方根を安全に計算するために使用されます。 モジュロは、素数モジュラスを処理するために最後に適用されます。$M$。 小切手`(k-1) % 2 != 0`それを保証します$f$は整数です。 解決策が存在しない場合も処理し、0 を出力します。

## テストケース```python
import sys, io, math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    x, q, M = map(int, input().split())
    xs = list(map(int, input().split()))
    res = []
    current = x
    for xi in xs:
        current *= xi
        d = 1 + 8 * current
        k = int(math.isqrt(d))
        if k * k != d or (k - 1) % 2 != 0:
            res.append(str(0 % M))
        else:
            f = (k - 1) // 2
            res.append(str(f % M))
    return "\n".join(res)

# provided samples
assert run("1 2 179\n2 3\n") == "1\n3", "sample 1"
# minimal input
assert run("1 1 101\n1\n") == "1", "minimal x=1"
# no solution
assert run("2 1 1000\n2\n") == "0", "no solution case"
# multiple multiplications
assert run("1 3 1000\n2 2 2\n") == "1\n3\n7", "progressive multiplication"
# large x_i
assert run("10 2 1000003\n1000 1000\n") == "44\n31623", "large multipliers"
