 ## 解決策
 ## 問題の理解

 紙を表す文字のグリッドが与えられます。各セルは空かマークが付いています。 タスクは、マークされたセルのパターンが、最初は空のグリッドに 1 回以上押された単一の長方形のスタンプによって生成されたかどうかを判断することです。 各スタンプ アプリケーションは、軸に沿った長方形内のすべてのセルをペイントします。複数のアプリケーションが重なる場合があります。 

重要な制約は、最終グリッド内のマークされたすべてのセルが、単一の固定スタンプ形状の長方形の結合として説明可能でなければならないということです。 ただし、スタンプの形状自体は指定されていないため、問題は、ペイントされたセルを削除したり部分的に彫り込んだりすることなく、何らかの長方形を繰り返し適用することによって、マークされたセルのセットが「一貫してカバーされる」かどうかをチェックすることに帰着します。 

グリッド サイズは十分小さいため、O(nm) または O((nm)^2) の解でも問題ありません。 重要なのは、生の最適化よりも幾何学的構造です。 これにより、考えられるすべての長方形を明示的に試行するアプローチは即座に除外されます。最悪の場合、O(n^2 m^2) 個の候補が存在し、それぞれの候補がグリッドのスキャンを必要とするからです。 

微妙な失敗例は、マークされたセルがほぼ長方形の形状を形成しているが、単一の長方形を繰り返しスタンプすることによっては得られない内部穴または連続していない領域がある場合に発生します。 

たとえば、次のことを考えてみましょう。```
###
#..
###
```有効なスタンプ プロセスを仮定すると、一貫した長方形のスタンプで上下の行が完全に埋められている場合、中央の行を部分的に空のままにすることはできません。 ローカル接続をチェックしたり、塗りつぶされたセルの合計をカウントしたりするだけの単純なアプローチでは、そのようなパターンが誤って受け入れられてしまいます。 

もう 1 つの重要なエッジ ケースは、マークされたセルが複数の切断されたコンポーネントを形成し、それぞれが長方形に見えるが、同じ長方形を繰り返しスタンプすることで説明できるように位置合わせされていない場合です。 

中心的な課題は、マークされたすべてのセルが任意の位置に配置されたその長方形の和集合によって生成できるような一貫した長方形が存在するかどうかを判断することです。 

## アプローチ

 強引なアイデアは、グリッド内の可能なすべての長方形をスタンプ形状の候補として試してみることです。 候補となる各長方形について、可能なすべての位置にスタンプすることをシミュレートし、ターゲット グリッドを正確に再構築できるかどうかを確認します。 

これが機能するのは、問題が、不一致を生じさせることなく、マークされたすべてのセルをカバーできる翻訳コピーを持つ四角形を見つけることであるためです。 ただし、長方形の数は O(n^2 m^2) であり、各長方形に対して O(nm) のシミュレーションが必要になる可能性があり、最悪の場合の複雑さは O(n^3 m^3) になり、これは中程度のグリッドであっても限界をはるかに超えています。 

重要な観察は、有効なスタンプ プロセスが存在する場合、マークされたすべてのセルの最小外接四角形自体がスタンプ形状の有効な候補である必要があるということです。 これは、スタンプ操作では境界長方形の外側にマークされたセルを作成できず、スタンプを繰り返しても最終形状の凸長方形の包の一部を除外するように境界を内側に「曲げ」ることができないためです。 

したがって、任意の四角形を検索する代わりに、マークされたすべてのセルを囲む最小の四角形に焦点を当てます。 次に、この外接する四角形内のすべてのセルがマークされているかどうかを確認します。 内部のセルが空の場合、向かい合う角を覆うスタンプは必ずそのセルを埋めることになるため、完全な長方形をスタンプしてパターンを生成することはできません。 

これにより、問題は単純な構造チェックに集約されます。マークされたすべてのセルの境界ボックスを計算し、それが完全に満たされていることを確認します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての四角形に対するブルート フォース | O(n^3 m^3) | お(1) | 遅すぎる |
 | 外接する四角形のチェック | O(nm) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 グリッド構造を直接分析していきます。 

1. グリッド全体をスキャンして、マークを含む行インデックスと列インデックスの最小値と最大値を追跡しながら、マークされたすべてのセルを見つけます。 これにより、マークされたすべてのセルを含む軸に沿った最小の長方形が得られます。 
2. マークされたセルが存在しない場合、スタンプは必要なく、空のグリッドは簡単に実現できるため、グリッドが有効であることを直ちに返します。 
3. 計算された外接する四角形内のすべてのセルを繰り返します。 
4. この長方形の内側にマークされていないセルが見つかった場合は、有効なスタンプ シーケンスが境界ボックス全体を連続的に埋めるため、長方形全体をスタンプして形状を形成することはできないと結論付けます。 
5. 外接する四角形内のすべてのセルがマークされている場合、構成が有効であることが返されます。 

これが機能する理由は、長方形をスタンプすると、完全な長方形の平行移動の結合である領域が常に生成されるためです。 したがって、有効な最終形状はその最小境界ボックス内で密でなければなりません。 そのボックス内の欠落したセルは、単一の一貫したスタンプ形状の存在と矛盾する方法で接続性に影響を与えることなく、同一の軸に揃えられた長方形の結合によって作成できない穴を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    min_r, min_c = n, m
    max_r, max_c = -1, -1

    has = False

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#':
                has = True
                if i < min_r: min_r = i
                if i > max_r: max_r = i
                if j < min_c: min_c = j
                if j > max_c: max_c = j

    if not has:
        print("YES")
        return

    for i in range(min_r, max_r + 1):
        for j in range(min_c, max_c + 1):
            if grid[i][j] != '#':
                print("NO")
                return

    print("YES")

if __name__ == "__main__":
    solve()
```実装では、最初にすべての境界ボックスを抽出します。`#`細胞。 変数`min_r`、`max_r`、`min_c`、 そして`max_c`極端な座標を追跡します。 ブール値`has`空のグリッドと空でないグリッドを区別します。 

2 番目のフェーズでは、境界ボックスが完全に塗りつぶされていることを検証します。 グリッド サイズが十分に小さいため、四角形のスキャンがセルの数において線形になるため、ネストされたループは安全です。 

境界の初期化には注意が必要です。 設定`min_r`そして`min_c`に`n`そして`m`それぞれ、最初に遭遇したことを保証します`#`それらを正しく更新します。 同様に、`max_r`そして`max_c`有効なセルが適切に展開されるように、-1 から開始します。

 ## 特殊なケース

 エッジ ケースの 1 つは、完全に空のグリッドです。 アルゴリズムは、`#`存在します。 何も見つからない場合は、すぐに YES が返されます。 空の結果を生成するためにスタンプ操作は必要ないため、これは正しいです。 

もう 1 つの特殊なケースは、マークされた単一のセルです。 境界四角形は 1x1 領域に縮退しますが、これは塗りつぶしチェックに簡単に合格します。 

より微妙なケースは、マークは存在するが、バウンディング ボックスが大きく、ほとんどが空であるように散在している場合です。 例えば：```
#..
..#
```外接する四角形はグリッド全体に広がりますが、内部セルは空です。 長方形をスキャンすると、最初の空のセルで違反が正しく検出され、確実に拒否されます。 

これらのケースは、正確さが完全に最小の囲み四角形内の密度の検出に依存することを裏付けています。これはアルゴリズムが強制する中核的な不変条件です。
