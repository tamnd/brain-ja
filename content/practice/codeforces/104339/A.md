 ## 解決策
 ## 問題の理解

 各王は同じ連隊に分かれた軍隊を指揮します。 大麦は$a$連隊、それぞれに含まれる$x$兵士なので、彼の軍隊の総規模は$a \cdot x$。 ホップとモルトは同じように記述されます。$b \cdot y$そして$c \cdot z$。 

課題は、3 つの軍隊すべてをランク付けすることではなく、それらの軍隊の合計最大規模を見つけて、軍隊がその最大規模と一致するすべての王をリストすることです。 出力には、そのようなすべての王の名前が含まれている必要があり、それらの名前は辞書順に印刷される必要があります。 

制約は十分小さいため、直接演算で十分です。 各値は最大で$10^3$、したがって、各軍隊の合計規模は最大でも$10^6$。 すべてを何度も再計算したとしても、コストは無視できます。 これにより、ソリューションはテスト ケースごとに一定時間内にしっかりと配置されます。 

唯一の微妙な点は、等しい場合に発生します。 単一のキングが厳密に大きい場合、誤って出力するのは簡単ですが、この問題では、最大値に合わせてすべてのキングを収集することが明示的に必要です。 もう 1 つの考えられる間違いは、名前の辞書編集上の順序を忘れることです。これは、複数の王が資格を得る場合にのみ問題になります。 

具体的なエッジケースは、次のような 3 つの軍がすべて同等である場合です。 

入力:```
2 2 2 3 3 3
```すべての合計は$6$したがって、正しい出力は次のようになります。```
Barley Hops Malt
```単純な「最大値を選択して 1 つの名前を出力する」アプローチは、ここでは失敗します。 

もう 1 つのエッジ ケースは、2 人のキングが最大値で同点の場合です。 

入力:```
2 3 3 6 3 4
```合計は大麦です$12$、ホップ$9$、モルト$12$したがって、大麦と麦芽の両方を印刷する必要があります。 

## アプローチ

 強引な解釈では、各軍隊の規模を個別に計算し、その結果を繰り返しスキャンしてどれが最大であるかを決定します。 値が 3 つしかないため、過度に複雑なアプローチであっても、複雑さの点では些細なままですが、スキャンの繰り返しが高価になる多くのキングにこのパターンを拡張することは想像できます。 

この問題では、構造が十分に単純であるため、反復的な改良は必要ありません。 3 つの積を 1 回計算し、それらを 1 回比較して、最大値に等しいすべてのエントリを選択します。 重要な観察は、「決定セット」が非常に小さく、サイズが固定されているため、ソートや複数のパスが不要であるということです。 

この強引なアイデアは、すべての候補者を直接評価するため機能します。 これは非効率のためではなく、利用できる組み合わせ構造がないため、データセットは固定サイズで完全に独立しているため不要になります。

 ## アルゴリズムのチュートリアル

 1. 各王の軍隊の総規模を次のように計算します。$A = a \cdot x$、$B = b \cdot y$、 そして$C = c \cdot z$。 これにより、連隊構造からの入力が同等のスカラー値に変換されます。 
2. 以下の最大値を決定します。$A$、$B$、 そして$C$。 これは最強の軍隊規模を表します。 
3. 勝者の空のリストを初期化します。 各キングについて、その合計が最大値と等しいかどうかを確認します。 その場合は、その人の名前も含めてください。 これにより、関係が確実に維持されます。 
4. 選択した名前を辞書順に出力します。 名前は固定文字列であるため、「大麦」、「ホップ」、「モルト」の順序になります。 

### なぜ効果があるのか

 各キングの強さは 1 回のスカラー倍算によって完全に把握されます。 軍隊の比較はこれらのスカラーの比較に帰着し、最大値に対する等価性によりすべての最強の軍隊が正確に識別されます。 すべてのキングは同じ基準値に対して個別にチェックされるため、勝者が省略されたり、誤って追加されたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a, b, c, x, y, z = map(int, input().split())

    barley = a * x
    hops = b * y
    malt = c * z

    mx = max(barley, hops, malt)

    ans = []
    if barley == mx:
        ans.append("Barley")
    if hops == mx:
        ans.append("Hops")
    if malt == mx:
        ans.append("Malt")

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```このソリューションでは、まず各王の連隊を合計数に変換します。 次に、3 つの計算値の最大値を見つけます。 各キングの名前は、計算された合計がこの最大値と一致する場合にのみ、条件付きで追加されます。 「大麦」が「ホップ」と「モルト」の前に来るため、小切手の順序はすでに辞書編集的に正しいため、追加の並べ替えは必要ありません。

 ## 特殊なケース

 3 つの軍がすべて等しい場合でも、各比較で同じ最大値に対して同等性がチェックされるため、アルゴリズムにはすべてのキングが正しく含まれます。 入力の場合:```
3 3 3 3 3 3
```計算された合計はすべて 9 であるため、最大値は 9 となり、3 つの条件チェックがすべて成功し、すべての名前が正しい順序で生成されます。 

次のように、ちょうど 2 つの軍隊が最大数で同点の場合:```
2 3 3 6 3 4
```大麦と麦芽は両方とも 12 と評価されますが、ホップは小さくなります。 最大は 12 であるため、これら 2 つだけが追加されます。 このアルゴリズムは、キング間の厳密な順序付けには依存せず、グローバル最大値に対する平等のみに依存し、同点がどのように分散されるかに関係なく正確さを保証します。
