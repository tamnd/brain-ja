 ## 問題の理解

 一辺の長さの大きな三角形を細分して形成された大きな正三角形グリッドが与えられます。$n$単位正三角形にします。 構造は標準的な三角格子です。大きな三角形の各辺には次の要素が含まれます。$n$内部は上向きと下向きの単位三角形が規則的に配列されて埋められています。 

課題は、この図に存在する個別の三角形がいくつあるかを数えるということです。 三角形は、そのサイズや方向に関係なく、グリッド内のどこかに表示されればカウントされます。 2 つの三角形は、幾何学的に合同であっても、位置やサイズが異なる場合、異なるものとみなされます。 

入力は単一の整数です$n$、三角形グリッドのサイズを制御します。 出力は、構造内のすべての可能なサイズと向きの三角形の合計数を表す単一の整数です。 

制約$n \le 10^4$三角形を直接列挙するアプローチは直ちに除外されます。 適度に注意しても$O(n^3)$または$O(n^2)$候補となる部分構造の数は、三角格子内のトリプルまたはサブ領域の数に応じてほぼ増加するため、幾何学的列挙は遅すぎます。$n^2$細胞。 

微妙なエッジケースは、$n = 1$、ここで、図はちょうど 1 つの単位三角形で構成されます。 三角形は 1 つだけであり、それより大きな構成は存在しないため、答えは自明のことですが 1 です。 

もう一つのコーナーケースは小さいです$n$、 のような$n = 2$、小さな単位三角形と 1 つの大きな単位三角形の両方が存在します。 ここでは手動で数えることは簡単ですが、三角形が両方の方向に表示され、より大きな三角形が複数の単位セルと重なっていることも強調されます。 

## アプローチ

 ブルートフォースアプローチでは、三角格子内の可能な点のトリプルをすべて列挙し、それらがグリッドに沿った有効な正三角形を形成しているかどうかをチェックしようとします。 各辺の長さと方向は、グリッド構造に対して検証する必要があります。 格子状に並んだ三角形に限定しても、候補頂点ペアの数はすでに$O(n^4)$最悪の場合、$O(n^2)$ラティス ポイントを作成し、3 つのポイントを選択すると、3 次またはそれ以上の爆発が発生します。 これは使用できません$n = 10^4$。 

より構造化された方法は、任意の幾何学に関して考えるのをやめ、代わりに三角形グリッドの組み合わせ構造を使用することです。 図内のすべての三角形は、解釈に応じて、上向き、下向き、または回転バージョンの 3 つの方向のいずれかで軸が揃えられています。 重要な点は、有効な三角形は上部の頂点と辺の長さを選択し、それが境界内に収まるかどうかをチェックすることによって完全に決定されるということです。 

これにより、問題は、考えられる各辺の長さの三角形がいくつ存在するかを数えるという問題に変換されます。 辺の長さが固定の場合$k$、上向き三角形が収まる位置の数は、次の二次関数です。$n-k$、水平方向と垂直方向の配置の両方が直線的に縮小するため、$k$。 同じことが下向き三角形にも当てはまりますが、下向き三角形はラティスの特定のサブレイヤーにのみ存在するため、有効な配置は若干異なります。 

重要な洞察は、三角形を個別に列挙するのではなく、可能なすべての辺の長さを合計するということです。$k$、それぞれについて$k$、三角形のレイヤー化から導出された算術式を使用して、有効な配置がいくつ存在するかを数えます。 これにより、問題は次の閉形式の合計に帰着します。$k$、結果は$O(n)$あるいは$O(1)$代数的単純化に依存する解決策。 

最終的な解決策は、既知の三角形グリッドの構造、つまり次のサイズの三角形グリッド内の三角形の総数を使用します。$n$は次の 3 次多項式です$n$、すべての方向とサイズの寄与の合計から導出されます。

 ## アルゴリズムのチュートリアル

 1. グリッドを、水平方向の容量が増加したり減少したりする行に配置された単位三角形で構成されているものとして扱います。 これにより、座標ではなくレイヤーの観点から推論できるようになります。 この構造により、すべての大きな三角形がこれらのレイヤーの連続した選択に対応するようになります。 
2. 三角形の辺の長さを固定する$k$。 このサイズの三角形がいくつ存在するかを数えます。 上向きの三角形の場合、上の頂点は少なくとも次の位置になければなりません。$k-1$その下の行。 利用可能な水平位置も、下に移動するにつれて直線的に縮小します。 
3. サイズの上向き三角形の数を導出する$k$二次関数として$n-k+1$。 各行で許容される開始位置が前の行よりも少ないため、有効な配置の数は三角形の数構造を形成します。 
4. 下向きの三角形についても同じ推論を繰り返します。 これらは事実上、格子内のギャップを占める反転バージョンであり、それらのカウントは同様の二次パターンに従いますが、インデックス付けでシフトされます。 
5. 可能なすべての辺の長さの合計$k$1から$n$。 各寄与は次の多項式です。$k$そして$n$、したがって、合計は次の閉形式の合計になります。$k$、$k^2$、および定数。 
6. 結果の式を次の 3 次多項式に簡略化します。$n$。 これにより、反復の必要性が完全になくなります。 

### なぜ効果があるのか

 グリッド内のすべての三角形は、その方向、辺の長さ、および最上部の頂点によって一意に決定されます。 ラティス構造により、実現可能性が 2 つの軸に沿った線形制約のみに依存することが保証され、これによりカウントが層ごとの独立した寄与に分離可能になります。 これらの制約は線形であるため、すべての有効な配置を合計すると多項式の増加が生じ、すでに閉じた形式でキャプチャされたエンドポイントの外側に不規則な境界効果が残ることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    if n == 1:
        print(1)
        return

    # Closed-form result for number of all triangles in triangular grid
    # derived from summing all orientations and sizes
    res = (n * (n + 2) * (2 * n + 1)) // 8
    print(res)

if __name__ == "__main__":
    solve()
```このコードは、三角形のサイズを反復する代わりに、閉じた形式の式を直接計算します。 の条件$n = 1$式が正確であるために厳密に必要というわけではありませんが、これにより境界の動作が明確になり、縮退した場合の代数キャンセルへの依存が回避されます。 

使用される式は、三角格子内の三角形を上向きと下向きの寄与に標準的に分解するものに対応し、それぞれの寄与は有効な配置に対する二次和になります。 最終的な式は、定数係数で除算された 3 次多項式に単純化されます。

 ## 特殊なケース

 のために$n = 1$、グリッドには単一の単位三角形のみが含まれます。 アルゴリズムは計算します$(1 \cdot 3 \cdot 3)/8 = 9/8$これは整数の結果として有効ではないため、明示的に 1 を返します。これは、代数的単純化を盲目的に信頼するのではなく、境界で閉じた形式を慎重に適用する必要がある理由を示しています。 

のために$n = 2$、構造には、ちょうど 1 つの大きな三角形と複数の単位三角形が含まれています。 式では 5 が得られ、分解に一致します。3 つの上向きの単位三角形、1 つの下向きの単位三角形、および形状全体にわたる 1 つの大きな三角形です。 これにより、両方の方向が多項式で考慮されることが確認されます。
