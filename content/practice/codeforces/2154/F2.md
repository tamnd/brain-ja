 ## アルゴリズムのチュートリアル

 1. 階乗とモジュラー逆数を最大まで事前計算する$n$すべてのテストケースで。 これにより、モジュロを組み合わせた定数時間の計算が可能になります。$998,244,353$。 
2. 各テスト ケースについて、既知の数値をすべて特定します。$p$そして自分の位置をマークします。 最も早い位置を決定する`first_large`2 番目のサブシーケンスと最新の位置の値が含まれる`last_small`最初のサブシーケンスの値が含まれています。 もし`first_large < last_small`、順列はリフルシャッフルになることはできず、答えはゼロです。 
3. の数を数えます`-1`前のエントリ`first_large`として`left_unknown`そしてその後`last_small`として`right_unknown`。 これらは、最初と 2 番目のサブシーケンスの番号に使用できるスロットを表します。 
4. しましょう`left_total`最初の部分列に入れる必要があるがまだ配置されていない数値の数、および`right_total`は 2 番目のサブシーケンスの類似の数になります。 
5. 未知のスロットへの有効な数字の配置数は、次の 2 つの組み合わせの積です: 割り当てる方法の数`left_total`数字を入力する`left_unknown`ポジションと`right_total`数字を入力する`right_unknown`ポジション。 数式を使用する`C(n, k) = factorial[n] * inverse_factorial[k] * inverse_factorial[n-k] % MOD`。 
6. これらの組み合わせを乗算し、結果の剰余を出力します。`998\,244\,353`。 

機能する理由: 既知の数値によって強制される最小値と最大値の境界を追跡することで、リフル シャッフルの特性が違反されないようにします。 これらの境界を尊重する任意の順序で未知数を残りの数値で埋めると、必要な部分列が保存されます。 階乗はすべての個別の割り当てを説明します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def precompute_factorials(max_n):
    fact = [1] * (max_n + 1)
    inv_fact = [1] * (max_n + 1)
    for i in range(2, max_n + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact[max_n] = pow(fact[max_n], MOD - 2, MOD)
    for i in range(max_n, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD
    return fact, inv_fact

def comb(n, k, fact, inv_fact):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD

fact, inv_fact = precompute_factorials(10**6)

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))
    unknown_positions = [i for i, x in enumerate(p) if x == -1]
    used = set(x for x in p if x != -1)
    
    left_total = 0
    right_total = 0
    left_unknown = 0
    right_unknown = 0
    
    first_large = 0
    while first_large < n and (p[first_large] == -1 or p[first_large] <= n // 2):
        first_large += 1
    last_small = n - 1
    while last_small >= 0 and (p[last_small] == -1 or p[last_small] > n // 2):
        last_small -= 1
    
    if first_large <= last_small:
        print(0)
        continue
    
    left_unknown = sum(1 for i in range(first_large) if p[i] == -1)
    right_unknown = sum(1 for i in range(last_small + 1, n) if p[i] == -1)
    
    left_total = n // 2 - sum(1 for x in p if x != -1 and x <= n // 2)
    right_total = n - n // 2 - sum(1 for x in p if x != -1 and x > n // 2)
    
    ans = comb(left_unknown, left_total, fact, inv_fact) * comb(right_unknown, right_total, fact, inv_fact) % MOD
    print(ans)
```コードでは、階乗と逆階乗を 1 回事前計算して、高速な組み合わせ計算を可能にします。 の`first_large`そして`last_small`強制スプリットを決定し、リフルシャッフル特性を確保します。 未知のスロットと残りの数を数えることで、組み合わせ公式を使用して有効な割り当てを計算できるようになります。 すべての位置がゼロインデックスであるため、Python で off-by-one インデックスを処理する場合は特別な注意が必要です。
