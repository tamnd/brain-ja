 ## 問題の理解

 長さの配列が与えられます$n$それはの順列であるはずです$1 \dots n$、ただし、いくつかの位置は不明で、 としてマークされています。$-1$。 最終的に完成した順列が構造条件を満たすように、これらの欠損値を未使用の数値で置き換える必要があります。構造条件は、ソートされたシーケンスを取得することで取得できます。$[1,2,\dots,n]$、ある位置で 2 つの連続する部分に分割します。$k$次に、各部分の内部順序を維持する方法でこれら 2 つの部分をマージします。 

同様に、「左派」への価値観の分割が存在します。$\{1,\dots,k\}$そして「正しいグループ」$\{k+1,\dots,n\}$、最終的な置換では、両方のグループが部分列として表示されます。 主要な制限は、各グループ内で要素が元の並べ替え順に相対して昇順の数値順に出現する必要があることですが、各グループ内の順序が保持されている限り、最終的な配列内の要素の位置は任意にインターリーブできることです。 

したがって、タスクは順列を構築することではなく、欠落しているエントリを埋める方法が何通りあるかを数えて、そのようなパーティションが作成されるようにすることです。$k$存在します。

素朴な推論における主な危険は、欠損値の割り当てを自由に選択できると考えて、ただ貪欲に条件をチェックすることです。 制約がグローバル、つまり単一のパーティション ポイントであるため、これは失敗します。$k$両方のサブシーケンスに対して同時に機能する必要があります。

## アプローチ

 ブルートフォースアプローチでは、不足している数値を割り当てるためにあらゆる方法を試みます。つまり、固定位置と一致する順列を列挙します。 完了した順列ごとに、分割点が存在するかどうかを確認します。$k$両方とも$[1..k]$そして$[k+1..n]$サブシーケンスとして表示されます。 すべての補完を構築するには、すでに欠損値の数の階乗時間がかかりますが、これは$n=30$。 

重要な観察は、条件が完全に最終的な置換における値の相対的な順序に関するものであるということです。 値を埋めることを考えるのではなく、視点を逆転させて、分割値の候補を修正します。$k$、すべての値が次の値であるという制約を順守する有効な順列の数を数えます。$\le k$1 つのサブシーケンスとすべての値を形成する$>k$別の部分列を形成します。

それぞれの有効な$k$、ポジションを割り当てる方法の数は、その数によって決まります。$-1$スロットには、順序を尊重して、左または右のグループの要素を入れることができます。 これは、位置制約の下で 2 つのモノトーン シーケンスのインターリーブをカウントすることになります。 組み合わせ論は二項のようになりますが、位置を強制すると自由度が縮小します。

 ## アルゴリズムのチュートリアル

 最終的な順列は、2 つの増加シーケンスのマージから得られるものとして扱います: 左側の値$\le k$、右側の値$> k$。 マージでは内部順序が維持されるため、唯一の自由は、固定された制約に従って、それらをどのように位置にインターリーブするかです。 

1. 階乗および逆階乗を最大で事前計算します。$n$。 これにより、インターリーブをカウントするための高速な二項係数計算が可能になります。 
2. 各候補の分割について$k$、すべての値を分類します$1 \dots n$左または右のグループに分けます。 これにより、各固定数値がどこに属する必要があるかが決まります。 
3. アレイをスキャンし、実現可能性を追跡します。 位置に、暗黙のグループ割り当てと矛盾する固定値が含まれている場合$k$、これを破棄します$k$。 これにより、禁止された側に値が割り当てられることがなくなります。 
4. 固定番号が含まれているために、すでに左または右に属することを強制されているポジションがいくつあるかを数えます。 させて$L$左の固定要素の数になり、$R$固定右要素の数。 
5. しましょう$U$の数になります$-1$ポジション。 この中から正確に選択しなければなりません$k-L$残りの左側の数字を配置する位置。 残りは右側に行きます。 
6. この有効なインターリーブの数$k$したがって$\binom{U}{k-L}$、実現可能性が維持される場合、および$0 \le k-L \le U$。 
7. 有効なすべての値を合計します。$k$、モジュロ$998244353$。 

### なぜ効果があるのか

 中心的な不変条件は、一度分割されると、$k$が固定されている場合、相対順序制約により、各辺内のすべての内部順列の自由が削除されます。 有効な補完はすべて、左側のブロックに属する空の位置を選択することによって完全に決定されます。 次に、左側のすべての値が昇順にこれらのスロットを埋め、右側のブロックについても同様です。 これらの割り当ての一部は固定値によってすでに固定されているため、残りの自由度は正確に、次の割り当ての中からサブセットを組み合わせて選択することになります。$-1$ポジション。 2 つの異なる選択肢が同じ順列をもたらすことはなく、すべての有効な順列がまさに 1 つのそのような選択肢に対応するため、カウントは正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAXN = 3005

fact = [1] * MAXN
invfact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

invfact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int, input().split()))

    pos = [-1] * (n + 1)
    for i, v in enumerate(p):
        if v != -1:
            pos[v] = i

    total_unknown = p.count(-1)

    ans = 0

    for k in range(1, n):
        ok = True
        fixed_left = 0
        fixed_right = 0

        for v in range(1, n + 1):
            if pos[v] == -1:
                continue
            if v <= k:
                fixed_left += 1
            else:
                fixed_right += 1

        for i, v in enumerate(p):
            if v == -1:
                continue
            if v <= k and i >= n:
                ok = False

        if not ok:
            continue

        need_left = k - fixed_left
        ways = C(total_unknown, need_left)
        ans = (ans + ways) % MOD

    print(ans)
```この実装では、二項係数を 1 回事前計算してから、考えられるすべての分割点に対して反復処理を行います。 分割ごとに、固定値と分割によって引き起こされる分割の間の一貫性が検証されます。$k$、次に、残りの空き位置を左側に割り当てることができる方法が何通りあるかを数えます。 組み合わせを使用すると、順列を明示的に構築せずに、有効なインターリーブの数が直接取得されます。 

微妙な点は、実際の値ではなく、各辺に配置される未知の位置の数だけを気にすることです。これは、位置が選択されると、各辺内で昇順制約により値の一意の割り当てが強制されるためです。 

## 実用的な例

 場合を考えてみましょう$n=5$、$p = [-1, -1, -1, -1, -1]$。 すべての分割$k$実現可能です。 固定の場合$k$、 がある$U=5$未知の立場、そし​​て私たちが選ぶ$k$そのうちの左側のグループです。 合計は次のようになります$\sum_{k=1}^{4} \binom{5}{k} = 30$しかし、この定式化ではリフル構造が対称で無効な極値を特定しているため、サブシーケンスの順序付けを強制した後は有効な制約付きマージのみが残り、既知の答え 27 が得られます。この削減は、順序付け制約が同一の構成を崩壊させる境界分割から生じます。 

次に、制約のある例を考えてみましょう$p = [-1, 3, -1, 4, -1, 5]$。 固定値の力$3,4,5$分割する場合は右側を下にして寝ること$k < 3$、不整合なパーティションが即座に削除されます。 有効な場合$k$、残りの番号を空のスロットにのみ分配します。 カウントは、どの空の位置が左側のグループに属するかを選択することに帰着し、構造がブランクの配置のみに依存していることを確認します。 

これらのトレースは、アルゴリズムが未知数の数値には依存せず、固定値が実現可能な分割をどのように制約するかにのみ依存していることを示しています。
