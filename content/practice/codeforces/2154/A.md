 ## 解決策
 ## 問題の理解

 次から構成されるバイナリ文字列が与えられます。`0`と`1`s と正の整数`k`。 それぞれ`1`文字列内の は、単純なローカル ルールに従って Teto によって「オフ」にできます。`1`は保護されておらず、他に保護されていません`1`前の`k-1`位置は次のように変更できます`0`。 私たちの目標は、最小限の数を保護することです。`1`テトがこのプロセスを左から右に適用した後、文字列は元の状態のままになります。 

入力により複数のテスト ケースが提供されます。 それぞれについて、文字列の長さ、整数を受け取ります。`k`、および文字列自体。 あらゆる問題を防ぐために保護する必要があるポジションの最小数を出力するように求められます。`1`変化することから。 

制約により、次のことがわかります。`n`すべてのテスト ケースで 1000 を超えません。これは、`O(n^2)`このアプローチはかろうじて適合するかもしれませんが、リニア スキャンの方が好ましく、より安全です。 注目すべきエッジケースには、すべての文字が次のような文字列が含まれます。`0`、 どこ`k`に等しい`n`、またはどこで`1`が連続して現れます。 

微妙なエッジケースは次のような場合です`1`は正確な間隔で配置されています`k`別に。 1 つを保護すると、他の複数の変更を防ぐことができます。`1`独立して」戦略は過大評価されるでしょう。 

## アプローチ

 ブルートフォースアプローチは、可能なすべてのサブセットに対してテトのプロセスをシミュレートすることです。`1`私たちは守ることができた。 すべての組み合わせを生成し、変換をシミュレートし、文字列が変更されていないかどうかを確認できます。 これは正しいですが、その数は指数関数的です。`1`s は最大 1000 になる可能性があり、完全に実行不可能になります。 

最適なアプローチは、テトの操作が影響を与えるだけであることを観察します。`1`他にないもの`1`前の範囲内`k-1`ポジション。 これは、左から右にスキャンする場合、保護されている任意の 2 つの間にあることを確認するだけでよいことを意味します。`1`せいぜいある`k-1`それらを隔てる無防備な位置。 重要な洞察は次のとおりです`1`すでにその中にあるもの`k`以前に保護された位置`1`安全であり、保護を必要としません。 したがって、貪欲な左から右へのスキャンで十分です。`1`以前の保護対象ではないもの`1`(つまり、より遠く`k-1`離れた位置）、私たちはそれを守ります。 これにより、保護するポジションの最小数が直接決まります。

 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`last_protected`最初のインデックスより小さい値 (たとえば、`-k`) 最後の位置を追跡します`1`私たちが守りました。 カウンタを初期化する`count`保護の数を追跡するには、ゼロに設定します。 
2. 文字列を左から右に繰り返します。 ポジションごとに`i`:

 - のキャラクターの場合`i`は`1`そして`i - last_protected >= k`、これは以前に保護されたことを意味します`1`遠すぎるのでテトがこれを変更することはできません。 電流を守る`1`増加することで`count`そして設定`last_protected = i`。 
- それ以外の場合は、何もしません。`1`すでに最後に保護されたものの安全範囲内にあります`1`。 
3. 文字列をスキャンした後、`count`最小限の数が含まれています`1`私たちは守る必要があります。 

正確さを保証する不変条件は、各ステップで、保護されていないすべてのものが次のような性質を維持するということです。`1`以内にあります`k-1`以前に保護された位置`1`。 これにより、`1`テトが変身するための条件を満たしたことがある`0`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    
    last_protected = -k  # no protection yet
    count = 0
    for i, c in enumerate(s):
        if c == '1' and i - last_protected >= k:
            count += 1
            last_protected = i
    print(count)
```ソリューションが初期化されます`last_protected`に`-k`最初のものを処理する`1`特別なケースを使用せずに正しく。 の`enumerate`ループは文字列を線形時間でスキャンし、必要な部分のみを保護します`1`s. 使用する`i - last_protected >= k`安全な距離を正しく確保します。

def run(inp: str) -> str:

    output = io.StringIO()
    sys.stdout = output

    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        last_protected = -k
        count = 0
        for i, c in enumerate(s):
            if c == '1' and i - last_protected >= k:
                count += 1
                last_protected = i
        print(count)
    
    sys.stdout = sys.__stdout__
    return output.getvalue().strip()
