 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。タスクは、すべての要素が正で、すべて奇数かすべて偶数の同じパリティを持つ、同じ長さの新しい配列を構築することです。 新しい配列の各要素について、元の配列から対応する要素をコピーするか、その要素と元の配列内の他の要素の差を取ることができます。 テスト ケースごとにそのような配列を構築できるかどうかを判断する必要があります。 

配列の長さは最大 200,000 まで可能で、すべてのテスト ケースの長さの合計も 200,000 を超えることはありません。 これは、要素ごとに考えられるすべての違いを試すなど、要素の各ペアを単純に処理するソリューションでは、次のオーダーが必要になることを意味します。$O(n^2)$動作が明らかに遅すぎます。 代わりに、理想的には、テスト ケースごとに線形または線形演算時間で機能するソリューションが必要です。$O(n)$。 

厄介なエッジ ケースは、配列に奇数と偶数が混在しているが、各タイプが 1 つだけ含まれている場合です。 たとえば、配列`[2, 3]`要素の違いによってパリティを整列できる数が生成されないため、美しい配列を形成できません。 もう 1 つの微妙な状況は、すべての要素がすでに同じパリティである場合です。 その場合、答えはすぐに「YES」になりますが、常に差異を計算しようとする不用意なアプローチは時間を無駄にしたり、差異を誤って分類したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての要素のペアを試して、考えられるすべての差を計算し、これらの数値から美しい配列を構築できるかどうかを確認します。 長さの配列の場合$n$、 がある$n^2$考慮すべき相違点。 すべての差異をセットに保存し、可能な均一パリティ配列をチェックすることができます。 これは、許可されているすべての操作をカバーしているため、原則的には正しいですが、$n$200,000 までの場合、最悪の場合は 400 億回の操作が必要となり、これでは遅すぎます。 

効率的な解決策を可能にする重要な洞察は、差分のパリティは元の数値のパリティによって完全に決定されるということです。 すべての数値がすでに同じパリティである場合、作業は完了です。 奇数と偶数が混在している場合、偶数から奇数を減算すると、常に奇数の結果が得られ、同じパリティの 2 つの数値を減算すると偶数の結果が得られます。 これは、唯一の障害は、すべての違いを揃えるのを妨げる混合物があることであることを意味します。 実際のチェックは、配列に 1 だけ異なる奇数と偶数の両方が含まれているかどうかを確認することになります。 

この観察により、単純に奇数と偶数の数を数えるだけで、各テスト ケースを線形時間で解くことができます。 少なくとも 1 つの奇数と 1 つの偶数がある場合、それらの最小の差をチェックして、美しい配列が実現可能かどうかを確認します。 それ以外の場合、配列はすでに非常に美しいものになっています。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n²) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列の長さを読み取ります。$n$そして配列$a$。 これにより、処理用のデータが設定されます。 
2. 配列内の奇数と偶数の数を数えます。 これにより、配列のパリティがすでに均一であるか、混合されているかがすぐにわかります。 
3. すべての数値が奇数であるか、すべての数値が偶数である場合は、「YES」を出力します。 配列はすでに美しいため、変更する必要はありません。 
4. 奇数と偶数の両方がある場合は、配列をソートします。 ソートにより、正確に 1 の差を持つ反対パリティの 2 つの数値が存在するかどうかを効率的にチェックできます。このようなペアは美しい配列内に共存できません。 
5. ソートされた配列を走査します。 連続する各ペアについて、一方が奇数でもう一方が偶数で、その差が 1 の場合、「NO」を出力して中断します。 これは、美しい配列を構築することが不可能な唯一のシナリオです。 
6. そのような隣接するペアが見つからない場合は、「YES」を出力します。 パリティを揃えるために常に相違点を選択できるため、複数の相違点または同じパリティのペアが存在しても、美しい配列の構築が妨げられることはありません。 

機能する理由: このアルゴリズムは、同じパリティの 2 つの数値を減算すると偶数が得られ、異なるパリティの 2 つの数値を減算すると奇数が得られるという事実に基づいています。 したがって、美しい配列を構築できない唯一の方法は、奇数と偶数が 1 だけ異なる場合です。これは、差を組み合わせてもゼロまたは負の数を生成せずに同じパリティに変換できないためです。 他のすべての構成では、元の数値または差分のいずれかを選択して、均一なパリティ配列を生成できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        odd_count = sum(1 for x in a if x % 2 == 1)
        even_count = n - odd_count
        if odd_count == 0 or even_count == 0:
            print("YES")
            continue
        a.sort()
        possible = True
        for i in range(1, n):
            if a[i] - a[i-1] == 1:
                possible = False
                break
        print("YES" if possible else "NO")
```このコードは、些細なケースを即座に処理するために、最初に奇数と偶数をカウントします。 ソートにより、1 の違いのチェックが効率的かつ直線的に行われます。 連続するペアに対するループは、美しい配列の構築を不可能にする唯一のシナリオを捉えます。
