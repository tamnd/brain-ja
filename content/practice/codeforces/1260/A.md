 ## 解決策
 ## 問題の理解

 私たちに与えられた家は、`n`部屋。 各部屋について、次の 2 つの数値がわかります。`c_i`、設置できるラジエーターの最大数、および`sum_i`、その部屋を適切に暖房するために必要なラジエーターセクションの総数。 各ラジエーターには任意の数のセクションを含めることができ、ラジエーターのコストは次のとおりです。`k`セクションは`k^2`。 私たちの目標は、部屋内のセクションの合計が少なくとも`sum_i`を超えません`c_i`ラジエーターを省き、トータルコストを最小限に抑えます。 

重要な制約は次のとおりです。`n`は最大 1,000 個まで可能で、各部屋には最大 10,000 個のラジエーターを備えた最大 10,000 個のセクションが必要になります。 これは許容できるほど小さいです`O(n)`部屋ごとの演算、ただし二次関数は何でも`sum_i`または`c_i`10^8 演算に達する可能性がありますが、これでは遅すぎます。 エッジケースが発生するのは次の場合です`c_i`よりもはるかに小さいです`sum_i`またはそれよりもはるかに大きい。 たとえば、部屋に 100 のセクションが必要だが、ラジエーターを 1 つしか配置できない場合は、100 のセクションすべてをその 1 つのラジエーターに配置する必要があります。 逆に、部屋に 1 セクションが必要で、10,000 個のラジエーターを配置できる場合は、1 つのラジエーターに 1 セクションを配置する必要があります。 

不注意な実装では、ラジエーター全体にわたるセクションの可能なすべての分布を反復しようとする可能性があります。 たとえば、`c_i = 2`そして`sum_i = 6`、列挙する`[6,0],[5,1],[4,2]…`少数の場合は機能しますが、`sum_i`そして`c_i`are 10,000, this approach would be hopelessly slow.

 ## アプローチ

 A naive brute-force approach would try every possible combination of`k`ラジエーターを配置し、あらゆる方法でセクションを割り当てます。 すべての有効な割り当てをカバーしているため、これは正しいですが、組み合わせの数は指数関数的に増加します。 のために`c_i = 10,000`そして`sum_i = 10,000`10,000 個のパーティションを 10,000 個の部分に列挙することさえ不可能です。 これは、ブルートフォースが実行不可能であることを示しています。 

重要な観察は、コスト関数が`k^2`凸です。 凸性とは、値が可能な限り等しい場合に二乗和が最小になることを意味します。 言い換えれば、指定された数のラジエーターの場合、セクションを均等に分散し、`floor(sum_i/c_i)`各ラジエーターに分配し、残りを分散します (`sum_i % c_i`) セクションを 1 つ追加することで、いくつかのラジエーターにまたがります。 これは凸関数の古典的なトリックです。固定和で平方和を最小化するには、数値のバランスを可能な限り保つ必要があります。 

使用するラジエーターの数がわかれば、コストの計算は簡単です。 計算します`x = sum_i // c_i`ラジエーターあたりのセクションの基本数として、`r = sum_i % c_i`残りのセクションとしてコストを計算します。`(c_i - r) * x^2 + r * (x + 1)^2`。 この式はラジエーターのバランスをとり、残ったセクションを考慮します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((sum_i は c_i を選択)) | O(c_i) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`、部屋の数。 
2. 各部屋について、以下をお読みください。`c_i`そして`sum_i`。 
3. 実際に使用するラジエーターの数を決定します。 これは`min(c_i, sum_i)`許可される最大セクション数またはセクションの総数を超えるラジエーターを使用できないためです (セクションが 0 のラジエーターは意味がありません)。 
4. ラジエーターあたりのセクションの基本数を次のように計算します。`x = sum_i // num_radiators`。 
5. 剰余を計算します`r = sum_i % num_radiators`。 これらは、均等に分散できない追加のセクションです。 
6. 総コストを計算します。`(num_radiators - r) * x^2 + r * (x + 1)^2`。 この式は次のように割り当てます。`x`セクションをほとんどのラジエーターに割り当て、残りをそれぞれ 1 つの追加セクションに分配します。`r`ラジエーター。 
7. 各部屋のコストを出力します。 

これが機能する理由: 不変条件は、割り当てられたセクションの合計が次の値に等しいということです。`sum_i`ラジエーターの数は以下を超えません`c_i`。 凸性により、セクションを可能な限り均等に分散することで平方和が最小化されることが保証されます。 一部のラジエーターが他のラジエーターよりも大幅に多くのセクションを取得する他の分布では、総コストが増加します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
for _ in range(n):
    c_i, sum_i = map(int, input().split())
    num_radiators = min(c_i, sum_i)
    x = sum_i // num_radiators
    r = sum_i % num_radiators
    cost = (num_radiators - r) * x * x + r * (x + 1) * (x + 1)
    print(cost)
```このソリューションでは、まず部屋の数を読み取ります。 部屋ごとに、使用するラジエーターの数を計算し、必要なセクションを均等に分割します。 残りはラジエーターごとに 1 つずつ分配され、すべてのラジエーターが整数セクションを持つようになります。 この順序で乗算と二乗を行うと、浮動小数点エラーが回避されます。 使用する`min(c_i, sum_i)`ラジエーターの数がセクションの数を超える特殊なケースに対処します。
