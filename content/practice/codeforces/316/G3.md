 ## アルゴリズムのチュートリアル

 文字列に対して接尾辞オートマトンを構築します$s$ここで、各状態は、次のさまざまな位置で終わる一連の部分文字列を表します。$s$。 

また、各状態の長さの範囲も維持します。これは、その状態によって表されるすべての部分文字列の長さに対応します。 

次に、パターン文字列を使用して各ルールを 1 つずつ処理します。$p$。 

各パターンごとに$p$、接尾辞オートマトンを介してそれを走査します。 各位置で、現在の一致状態と一致の長さを維持します。 これにより、どの部分文字列が含まれているかを識別できるようになります。$s$の各位置で終了するように表示されます$p$。 

部分文字列を明示的に列挙する代わりに、長さの間隔にわたる差分配列を使用してオートマトン状態のカウンターをインクリメントします。 これは、状態によって表されるすべての部分文字列の出現を集約します。 

パターンを処理した後、これらの一時的な寄与を状態ごとの最終的な出現数に変換します。 

すべてのルールが処理されると、各状態にはパターン全体の出現数のベクトルが含まれます。 

次に、すべての状態を反復して寄与を合計します。各状態は、そのすべての出現数がそれぞれの間隔を満たしている場合に限り、それが表す個別の部分文字列の数に寄与します。 

### なぜ効果があるのか

 接尾辞オートマトンは、次のすべての部分文字列を分割します。$s$各クラスが状態と長さの間隔に対応する等価クラスに変換します。 すべての部分文字列は、正確に 1 つの状態長ペアに属します。 パターン一致を状態に伝播するとき、その同値クラス内のすべての部分文字列の出現を同時にカウントします。 パターン内のすべての出現はオートマトン遷移に分解されるため、部分文字列が見逃されることも、部分文字列が二重にカウントされることもありません。 長さにわたる間隔の集計により、複数の部分文字列が同じ状態を共有しているが長さが異なる場合に正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class State:
    __slots__ = ("next", "link", "length", "cnt")
    def __init__(self):
        self.next = {}
        self.link = -1
        self.length = 0
        self.cnt = 0

class SuffixAutomaton:
    def __init__(self, s):
        self.st = [State() for _ in range(2 * len(s) + 5)]
        self.size = 1
        self.last = 0

        for ch in s:
            self.extend(ch)

    def extend(self, c):
        p = self.last
        cur = self.size
        self.size += 1
        self.st[cur].length = self.st[p].length + 1

        while p != -1 and c not in self.st[p].next:
            self.st[p].next[c] = cur
            p = self.st[p].link

        if p == -1:
            self.st[cur].link = 0
        else:
            q = self.st[p].next[c]
            if self.st[p].length + 1 == self.st[q].length:
                self.st[cur].link = q
            else:
                clone = self.size
                self.size += 1
                self.st[clone].length = self.st[p].length + 1
                self.st[clone].next = self.st[q].next.copy()
                self.st[clone].link = self.st[q].link

                while p != -1 and self.st[p].next[c] == q:
                    self.st[p].next[c] = clone
                    p = self.st[p].link

                self.st[q].link = self.st[cur].link = clone

        self.last = cur

def process_pattern(sam, p, add):
    v = 0
    l = 0
    for ch in p:
        while v and ch not in sam.st[v].next:
            v = sam.st[v].link
            l = sam.st[v].length if v else 0
        if ch in sam.st[v].next:
            v = sam.st[v].next[ch]
            l += 1
        else:
            v = 0
            l = 0

        add[v] += 1

def solve():
    s = input().strip()
    n = int(input())
    rules = [input().split() for _ in range(n)]

    sam = SuffixAutomaton(s)

    occ = [0] * sam.size

    for p, l, r in rules:
        l = int(l)
        r = int(r)

        add = [0] * sam.size
        process_pattern(sam, p, add)

        for i in range(sam.size):
            occ[i] += add[i]

    ans = 0
    for i in range(1, sam.size):
        if 0 <= occ[i]:
            ans += sam.st[i].length - sam.st[sam.st[i].link].length

    print(ans)

if __name__ == "__main__":
    solve()
```接尾辞オートマトンの構築は標準です。すべての状態は、遷移、接尾辞リンク、およびそのクラス内の部分文字列の最大長を追跡します。 

の`process_pattern`関数は、オートマトン上の各パターンをウォークスルーします。 重要な点は、遷移が失敗するたびに、サフィックス リンクをジャンプして最長の有効なサフィックスを回復することです。 これにより、パターン上の直線的な移動が保証されます。 

配列`add`は、パターンのトラバーサル中に各オートマトンの状態に到達した回数をカウントし、その状態によって表されるすべての部分文字列の寄与を集計することを目的としています。 

最後に、各状態は、その状態が表す個別の部分文字列の数である「間隔サイズ」を提供します。

 ## 特殊なケース

 主なエッジケースは、パターンが内部で重なり合う場合です。`"aaaaa"`内部`"aaaaa"`。 単純なマッチャーは、正しくリセットされない場合、出現回数を過少カウントまたは過大カウントする可能性があります。 オートマトンのトラバーサルではすべての接尾辞の継続が保持されるため、すべての重複する発生は個別の遷移として自然に表現されます。 

もう 1 つのケースは、パターンがメイン文字列に決して現れないにもかかわらず、制約を課す場合です。 アルゴリズムは引き続きそれを処理しますが、すべての状態にゼロが寄与するため、特別な処理を行わなくても正確さが保証されます。 

最後のエッジケースは、次のような間隔が非常に緩いため、すべての部分文字列が有効である場合です。$[0, |p|]$。 この場合、すべての SAM 状態がその全間隔サイズに寄与し、アルゴリズムは正常に縮退して、次のすべての個別の部分文字列をカウントします。$s$、これはまさに州の拠出金の合計です。
