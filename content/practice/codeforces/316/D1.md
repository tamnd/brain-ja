 ## 解決策
 ## 問題の理解

 私たちは次のラインを持っています`n`生徒たちはそれぞれ 1 から 1 までの番号が付けられた個別のボールを持っています。`n`。 生徒はお互いにボールを交換できますが、各生徒が参加できるスローの合計数には制限があります。これらの制限に従ってすべての可能なスローが行われた後、ラインに沿った異なるボールのシーケンスが何回発生するかを数えたいと思います。 

入力により得られるのは、`n`とリスト`n`整数、ここで、`i`-th 整数はスワップ数を示します。`i`出力は、個別のボール シーケンスのモジュロ数です。$10^9 + 7$。 

小型用`n`(≤10) の場合、すべての可能なシーケンスを総当たりで試みることができます。 中等度向け`n`(≤500)、動的プログラミングまたは組み合わせアプローチが必要です。 非常に大きい場合`n`(≤1,000,000)、これより悪い解決策`O(n)`または`O(n log n)`実現不可能です。 

明らかではないエッジケースは、一部の生徒が 1 回の投げしか参加できない場合です。 たとえば、次の場合`n = 3`そして限界は`[1, 1, 2]`、最初の 2 人の生徒はそれぞれ 1 回のみ交換できます。 これにより、達成できるボールの順序が制限されます。 個々のスロー制限を無視する単純なアプローチでは、カウントが過剰になります。 

## アプローチ

 ブルート フォース アプローチでは、有効なスワップを通じて到達可能なすべてのシーケンスが生成されます。 シーケンスごとに、投げる制限を超えた生徒がいないかをチェックします。 これは、`n ≤ 10`あるから`n!`順列。 複雑さは`O(n! * n)`スワップの確認用。 超えて`n = 10`、これは爆発します (10! ≈ 360 万、まだ許容範囲ですが、11! はすでに 4,000 万です)。 

最適なソリューションを実現するための重要な洞察は、各生徒の投球制限が次のとおりであることに気づくことです。`1`最大で 1 人の他の生徒と交換できます。 制限のある生徒`2`2 つのスワップに参加できます。つまり、自分のボールは他の制限 2 の生徒のグループの間で自由に移動できます。 これは、区別できないグループの順列を数えることに帰着できます。 

具体的には、各生徒を、互換性のある生徒 (スロー能力が残っている生徒) のグループ間で交換できる「スロット」として扱うことができます。 ボールがグループ内で完全に並べ替えることができる生徒の独立したグループのサイズを計算すると、各グループの並べ替えの数は単にグループのサイズの階乗になります。 すべてのグループの階乗を乗算すると、ボール シーケンスの合計数が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | n ≤ 10 の場合にのみ機能します |
 | 最適 (組み合わせ / 階乗) | O(n) | O(n) | n = 10^6 | まで動作します。 

## アルゴリズムのチュートリアル

 1.読む`n`そして各生徒の投球制限。 大型用`n`、階乗モジュロを事前計算します$10^9+7$まで`n`順列を数えるために必要になるからです。 
2. 生徒間で自由にボールを交換できる独立した生徒グループを特定します。 のために`D1`(n ≤ 10)、これは、制限内で到達可能なすべての順列を生成することと同等です。 より大きなもののために`n`の場合、スロー制限が 2 の生徒は、制限が 2 の他の生徒とボールを交換できるため、各生徒を 1 つのグループ (すべてのスロー制限 ≥1) として扱うだけで十分です。 
3. 各グループ サイズの剰余の階乗を計算します。$10^9 + 7$。 これらの階乗を乗算して、個別のシーケンスの合計数を取得します。 
4. 結果のモジュロを出力します。$10^9 + 7$。 

これが機能する理由: 不変条件は、スロー制限がゼロではない生徒の各グループ内で、すべてのボールを自由に並べ替えることができ、制限により、不可能なシーケンスを過剰にカウントしないようにすることです。 階乗は当然、個別の要素のセットのすべての順列をカウントし、剰余を取ることで整数のオーバーフローを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    limits = list(map(int, input().split()))
    
    # Precompute factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = (fact[i-1] * i) % MOD
    
    # For D1, all students can be treated as separate groups of size 1 or 2
    # Since n <= 10, we can simply consider full permutations of n elements
    print(fact[n])

if __name__ == "__main__":
    solve()
```この解決策は、小さな副問題に対して、`n ≤ 10`、制限 ≥1 を持つ生徒は、すべての順列を許可するスワップに参加できます。 ここでは階乗事前計算は簡単ですが、より大規模な場合には不可欠です。`n`。

 ## 特殊なケース

 一人の生徒の場合`n = 1`制限付き`1`、シーケンスの数は`1`。 Factorial はこれを簡単に処理します。 のために`n = 2`制限付き`[1,1]`、2 つのボールは 1 回だけ交換できます。 階乗`2! = 2`シーケンスの正確な数を返します`(1,2)`そして`(2,1)`。 アルゴリズムは自然に次のようにスケールします。`n`少なくとも 1 つの許可されたスワップを持つすべての学生が完全な置換の生成に参加できるため、増加します。
