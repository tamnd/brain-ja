 ## 解決策
 ## 問題の理解

 の列が与えられます`n`ビーバーにはそれぞれ 1 から 1 までの番号が付けられています。`n`。 各ビーバーは、次のように表されるように、誰が自分のすぐ前にいるべきかを知っています。`a[i]`(そのビーバーの番号)、またはわからない場合は、次のように表されます。`0`。 これらの依存関係には循環がありません。つまり、「フォロー」関係が連鎖の森を形成します。 目標は、特定のビーバーの可能な位置をすべて見つけることです。`x`、指定された情報と一致する最後のキューにあります。 

重要なのは、ビーバーの中には自分が誰をフォローしているのかわからない人もいるということです。 これにより不確実性が生じます。これらのビーバーは、ゼロ以外の依存関係を尊重する限り、シーケンス内の任意の空きスポットを占有する可能性があります。 既知の前任者を持つビーバーの位置は、互いに対して事実上固定されていますが、未知のものによって組み合わせの可能性が生じます。 

制約は管理可能です。`O(n^2)`アルゴリズムだから`n ≤ 1000`。 この問題は、2 つのスコアリング サブタスクを示唆しています。最大 20 個の未知数については、単純なシミュレーションが機能します。 任意の未知数については、より体系的なアプローチが必要です。 不用意に実装すると、入力の線形順序を仮定したり、未知数の伝播を無視したりする可能性があります。 たとえば、与えられた`n=3`、`x=1`そして`a=[2,0,0]`、単純な解決策では、ビーバー 1 は最初の位置で 2 にのみ従うことができると想定する可能性がありますが、位置 1 と 3 が他の未知数に対して空であり、ビーバー 1 に複数の有効な位置が存在する可能性もあります。 

## アプローチ

 ブルートフォースアプローチは、ゼロ以外の依存関係を尊重するビーバーのすべての順列を生成し、どこにあるかをチェックすることです。`x`それぞれに着陸します。 それぞれについて、`n!`順列、妥当性の検証`O(n)`。 これは明らかに遅すぎます`n=1000`未知数の上限が 20 である最初のサブタスクでも同様です。ブルート フォースは有効な命令をすべて明示的に列挙するため機能しますが、未知数の数が増えると失敗し、組み合わせ爆発が発生します。 

重要な洞察は、ビーバーが非ゼロに基づいて鎖を形成しているということです。`a[i]`価値観。 各チェーンには明確な相対順序があります。 ビーバーと`a[i]=0`チェーン間のどこにでも挿入できます。 したがって、完全な順列を生成する必要はありません。 代わりに、各チェーンを位置のシーケンスとしてモデル化し、各チェーンが占める可能性のある最も古い位置と最新の位置を見つけて、次に、`x`属するチェーンに基づいて占有することができます。 未知数を反復し、各チェーンの前に空のスポットがいくつ存在するかを考慮することで、一連の位置を効率的に計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n) | O(n) | n>20 では遅すぎる |
 | チェーンの伝播 + 位置追跡 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.`next_beaver`サイズの配列`n+1`、 どこ`next_beaver[i]`直後のビーバーです`i`。 で初期化します`0`。 これにより、チェーンを素早く通過できるようになります。 
2. すべてのチェーンヘッド、つまり他の誰にも追従されていないビーバーを特定します。 また、既知の前任者に続くビーバーも追跡します。 
3. チェーンごとに、その長さとキュー内で占めることができる位置の範囲を計算します。 最小位置はその前に来る必要があるチェーンの数によって決まりますが、最大位置は全長から残りのチェーンを引いたものによって決まります。 
4. もし`x`が既知の前任者を持つビーバーである場合、そのチェーンをたどって、そのチェーン内の相対位置を決定します。 最終的に可能な位置は、`x`チェーンの最小開始点とチェーンの相対位置の両方を考慮するキュー内のすべての位置です。 
5. もし`x`もっている`a[x]=0`の場合、その可能な位置は、ゼロ以外のチェーンによって占有されていないすべての空の位置に対応します。`a[i]`。 占有スポットをスキップしてすべての位置を反復処理し、次の位置を収集します。`x`挿入できた。 
6. 結果の位置を昇順に並べ替えて印刷します。 

**機能する理由**: このアルゴリズムは 2 つの不変条件を維持します。 まず、既知の先行者とのビーバーの相対的な順序は、チェーンを横断することによって保存されます。 第 2 に、未知のビーバーは既存のチェーンに違反しない位置にのみ挿入されます。 これらの不変条件により、生成されたすべての位置が`x`が有効であり、有効な位置が省略されていないことを確認します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, x = map(int, input().split())
a = list(map(int, input().split()))

next_beaver = [0] * (n + 1)
has_prev = [False] * (n + 1)

for i, val in enumerate(a, 1):
    if val != 0:
        next_beaver[val] = i
        has_prev[i] = True

# Identify chain heads
heads = [i for i in range(1, n + 1) if not has_prev[i]]

# Function to find positions in a chain
def get_chain(head):
    chain = []
    current = head
    while current:
        chain.append(current)
        current = next_beaver[current]
    return chain

occupied = set()
chains = []

for head in heads:
    chain = get_chain(head)
    chains.append(chain)
    occupied.update(chain)

possible_positions = set()

if a[x-1] != 0 or next_beaver[x] != 0:  # x in a chain
    for chain in chains:
        if x in chain:
            idx = chain.index(x)
            for pos in range(idx+1, n+1-len(chain)+idx+1):
                possible_positions.add(pos)
else:  # x is unknown, free to go to any unoccupied
    free_positions = [i for i in range(1, n+1) if i not in occupied]
    possible_positions.update(free_positions)

for pos in sorted(possible_positions):
    print(pos)
```このソリューションでは、まず次を使用して「フォロー」チェーンを構築します。`next_beaver`。 すべてのチェーン ヘッドを計算し、チェーンごとに走査してビーバーを収集します。 もし`x`がチェーンの一部である場合、チェーンの順序を尊重してすべての可能な位置を計算します。 もし`x`まったく不明な場合は、空いているスロットに単純に配置します。 微妙な点は、計算された位置がチェーンのオフセットを正確に反映していることを確認することです。
