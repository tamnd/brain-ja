 ## アルゴリズムのチュートリアル

3. コンピューティング`ways[d]`包含-除外を使用します。

```次に、より大きな約数の寄与を差し引きます。`g`。 

約数を最大から最小まで処理すると、gcd を使用して数値の正確なカウントが正確に得られます。`d`。 
4. しましょう`self = ways[g]`。

### なぜ効果があるのか

 重要な特性は、将来は現在の gcd にのみ依存するということです。 

現在の gcd が`g`。 につながる以前のシーケンス`g`次の gcd は常に次の gcd であるため、無関係になります。`gcd(g, x)`。 これによりプロセスがマルコフになります。 

州ごとに`g`、繰り返しでは、考えられるすべての次の描画が列挙されます。 用語`1`これから行う抽選の説明になります。 遷移確率は正確であるため、`ways[d]`gcd を生成する値を正確にカウントします。`d`。 

自己ループ確率を分離した後、再発が解決されます。 他のすべての遷移は適切な約数に進むため、期待値はトポロジカルな順序で計算されます。 したがって、式で使用されているすべての値はすでに正しいので、増加よりも帰納法が有効です。`g`正しさを証明します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    m = int(input())

    inv = [0] * (m + 1)
    for i in range(1, m + 1):
        inv[i] = pow(i, MOD - 2, MOD)

    divisors = [[] for _ in range(m + 1)]
    for d in range(1, m + 1):
        for multiple in range(d, m + 1, d):
            divisors[multiple].append(d)

    dp = [0] * (m + 1)

    for g in range(2, m + 1):
        divs = divisors[g]

        exact = {}
        for d in reversed(divs):
            cur = m // d
            for bigger in divs:
                if bigger > d and bigger % d == 0:
                    cur -= exact[bigger]
            exact[d] = cur

        num = m % MOD

        for d in divs:
            if d == g:
                continue
            num = (num + exact[d] * dp[d]) % MOD

        stay = exact[g]
        denom = m - stay

        dp[g] = num * inv[denom] % MOD

    ans = 1

    total = 0
    for i in range(1, m + 1):
        total += dp[i]

    ans = (ans + total % MOD * inv[m]) % MOD

    print(ans)

solve()
```最初の前処理ステップでは、次の値までのすべての整数の除数リストを作成します。`m`。 これにより、各州がそのすべての約数に効率的にアクセスできるようになります。 

固定 gcd 状態の場合`g`、各約数を生成する数値のカウントが必要です。 包含/除外の計算は、より大きな除数から開始され、すでに計算された正確なカウントが減算されます。 これは、「d の倍数」カウントを「gcd ちょうど d」カウントに変換する標準的な方法です。 

期待式には自己ループが含まれています。 このような反復を解くには、残りの確率質量で割る前に自己ループ項を左側に移動する必要があります。 この再配置を忘れることは、実装における最も一般的なバグです。
