 ## 問題の理解

 正方形のシートで同じ折りを繰り返します。 各操作で 4 つの角すべてが中央に折り畳まれ、回転された小さな正方形が生成されます。$45^\circ$。 これを行った後$N$times and unfolding the paper, every crease is either a mountain fold or a valley fold.

 させて$M$すべての山折り目の合計の長さとなります。$V$すべての谷折り目の合計の長さ。 数量$M/V$常に次のように書くことができます$$A + B\sqrt2,$$どこ$A$そして$B$合理的です。 必要なのは係数だけです$B$。 もし$$B=\frac pq$$最低の言葉で言えば、私たちはアウトプットしなければなりません$p \cdot q^{-1}\pmod{999999893}$。 

難しいのは、$N$と同じ大きさにすることができます$10^9$。 折り曲げプロセスのシミュレーションは不可能です。 レイヤーの数が操作ごとに 2 倍になるため、数十のステップを経た後で折り目パターンを保存することさえ不可能になります。 ソリューションでは、ジオメトリ全体を閉じた形式に変換し、それを高速累乗を使用して評価する必要があります。

## アプローチ

 強引なアプローチでは、折り目のパターン全体を追跡しようとします。 で$i$- 番目の折り目があります$2^{i-1}$紙を重ねていくと、折り目ごとにすべての紙に新しいしわが生まれます。 幾何学的オブジェクトの数は指数関数的に増加するため、$N=50$絶望的だ。 

重要な点は、折り目パターン自体は必要ないということです。 必要なのは山の全長と谷の長さの合計だけです。 

を考慮してください。$i$-回目の折り畳み操作。 

その折り目の前に、$2^{i-1}$層。 新しく作成された正方形は辺の長さがあります$$\left(\frac1{\sqrt2}\right)^{i-1}.$$正方形の角から中心までの折り目は、折り目の全長に寄与します。$2\sqrt2$現在のスケール係数を倍します。 したがって、ステップで作成された折り目の合計の長さは$i$は$$2^{i-1}\cdot 2\sqrt2\cdot \left(\frac1{\sqrt2}\right)^{i-1} = 2(\sqrt2)^i.$$残りの幾何学的な観察は、最初の折りの後、層のちょうど半分が元の面を上にし、半分が反対側を上にするということです。 新しく作成された折り目は、向きが逆のレイヤーに正確に山になります。 これはつまり：$$M=\sum_{i=2}^{N} (\sqrt2)^i,$$一方、最初の折り目とその後のすべての折り目は谷に寄与します。$$V=2\sqrt2+\sum_{i=2}^{N} (\sqrt2)^i.$$したがって$$\frac MV = \frac S{S+2\sqrt2}, \qquad S=\sum_{i=2}^{N}(\sqrt2)^i.$$この時点以降、問題は純粋な代数になります。 結果として得られる係数$B$のみに依存する$2^{\lfloor N/2\rfloor}$で計算できます。$O(\log N)$2進累乗を使用した時間。 この観察は、この問題の標準的な解決策に現れています。

 ## アルゴリズムのチュートリアル

 1.ハンドル$N=1$。 比率は$0$、したがって、の係数は$\sqrt2$は$0$。 
2.ハンドル$N=2$。 私たちはそれを直接知っています$$\frac MV=\sqrt2-1,$$それで$B=1$。 
3. しましょう$x=\sqrt2$。 
4. コンピューティング$$S=\sum_{i=2}^{N}x^i.$$5. 分析をパリティごとに分離します。 

のために$N=2m$、$$S=(2^{m+1}-2)+(2^m-2)x.$$書き込み$t=2^m$、$$S=(2t-2)+(t-2)x.$$6. に代入します$$\frac S{S+2x}$$そして分母を有理化します。 

簡略化した後、$$B= -\frac{2(t-1)}{(t-2)^2}.$$7. のために$N=2m+1$、$$S=(2t-2)+(2t-2)x, \qquad t=2^m.$$再び合理化すると、$$B= \frac{t-1}{t^2+2t-1}.$$8. コンピューティング$t=2^m \pmod P$、 どこ$$P=999999893.$$9. 対応する有理式モジュロを評価します。$P$モジュラーインバースを使用します。 

### なぜ効果があるのか

 すべての折り目は、既知の合計折り目長さに寄与します。$2(\sqrt2)^i$。 残る問題は、新たにできた折り目が山なのか谷なのかということです。 折り畳むと紙の層の向きが交互になり、最初のステップの後、ちょうど半分の層がそれぞれの向きになります。 ある方向で作成された折り目は山であり、他の方向で作成された折り目は谷です。 これにより、次の正確な式が得られます。$M$そして$V$、幾何学を代数量に還元する$$\frac S{S+2\sqrt2}.$$パリティベースの式は、$S$は正確な幾何級数です。 分母を有理化すると、次の係数が抽出されます。$\sqrt2$、上記の式が生成されます。 すべての変換は代数的に等価であるため、計算された係数は正確に必要な値となります。$B$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 999_999_893

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        if n == 1:
            ans.append("0")
            continue

        if n == 2:
            ans.append("1")
            continue

        m = n // 2
        p2 = pow(2, m, MOD)

        if n & 1:
            num = (p2 - 1) % MOD
            den = (p2 * p2 + 2 * p2 - 1) % MOD
        else:
            num = (-2 * (p2 - 1)) % MOD
            den = ((p2 - 2) * (p2 - 2)) % MOD

        ans.append(str(num * pow(den, MOD - 2, MOD) % MOD))

    sys.stdout.write("\n".join(ans))

solve()

すべてのより大きな値についてのみ、$2^m$が必要です。 以来$m$と同じくらい大きいかもしれない$5\cdot10^8$、2進累乗が必要です。 Pythonの組み込み`pow(base, exp, mod)`これを計算します$O(\log m)$。 

有理式は有限体モジュロで直接評価されます。$P$。 なぜなら$P$が素数の場合、モジュラー逆元はフェルマーの定理で計算されます。$$a^{-1}\equiv a^{P-2}\pmod P.$$モジュール値以外の大きな整数は格納されません。
