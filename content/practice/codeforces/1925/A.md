 ## 解決策
 ## 問題の理解

 最初の k 個の小文字で単一の文字列を構築し、それらの k 個の文字から形成される長さ n の可能なすべての文字列がその内部のどこかに部分列として現れるようにするように求められます。 サブシーケンスとは、残っている文字列を並べ替えることなく、構築された文字列から文字を削除しても、ターゲット文字列を取得できることを意味します。 

重要な要件は非常に強力です。単にいくつかのパターンを埋め込むのではなく、長さ n の考えられるすべての kⁿ シーケンスを埋め込むのです。 n と k は両方とも最大 26 であるため、最悪の場合、必要な文字列の総数はすでに天文学的に大きくなる可能性がありますが、サブシーケンスは柔軟な方法でオーバーラップできるため、構築された文字列は構造を大幅に再利用できます。 

出力もできるだけ短くする必要があります。 そのため、文字の不要な繰り返しは最適ではない可能性が高まるだけであるため、冗長な構造を避ける必要があります。 

素朴なアプローチでは、長さ n の各文字列がサブシーケンスとして現れることを明示的に確認しようとします。 すべての kⁿ 文字列を連結しようとしたり、不足している文字列を貪欲に追加したりすることもできます。 kⁿ が指数関数的に増加し、n = 10、k = 2 のような小さな入力でも必要な文字列が実行できなくなるため、これはすぐに失敗します。 

より微妙な失敗は、「abc...」を繰り返すようなパターンの貪欲な連結によって発生します。 これには多くのサブシーケンスが含まれる可能性がありますが、長さ n のすべての組み合わせをカバーすることは保証されません。 たとえば、k = 2、n = 2 の場合、文字列「abab」には部分列として「bb」が含まれていないため、すでに不十分です。 

問題の構造は、すべてのシーケンスを列挙せずに暗黙的にエンコードする普遍的な構造が必要であることを示唆しています。 

## アプローチ

 ブルートフォース戦略では、すべての kⁿ 文字列を列挙し、それらをサブシーケンス関係に基づいて最短のスーパーシーケンスにマージしようとします。 これは本質的に、指数集合上の最短の共通超列問題です。 長さ n の各文字列が制約に寄与し、それらをマージするには指数関数的な時間とメモリが必要になるため、状態空間を表現することさえ不可能になります。 

重要な洞察は、視点を逆転させることです。 長さ n のすべてのシーケンスを明示的にカバーすることを考える代わりに、位置を介して任意の選択肢のシーケンスを「ルーティング」できる文字列を構築します。 慎重に選択した構造を繰り返す場合、出現する文字を順番に選択することで、任意のシーケンスを確実に埋め込むことができます。 

最適な構成は驚くほど単純です。k 文字のアルファベットから順番に始めて、それを n 回繰り返します。 これにより、すべての文字がすべての「レイヤー」に出現する文字列が生成され、常に連続するレイヤーから出現を取得することで、長さ n の任意のシーケンスを選択できるようになります。 

これが機能する理由は、サブシーケンスの柔軟性に関係しています。 以降の繰り返しで出現する文字は、任意の文字列の次のステップを表すことができます。 すべての深さで k 個の選択肢が利用可能であることを保証することで、1 つの選択肢が別の選択肢をブロックする競合を回避します。 

この最小性は、必要な各文字列が順番に分散された少なくとも n 個の出現を必要とし、位置ごとに k 個の選択肢があるため、サブシーケンス位置を分離する機能を失うことなくレイヤーをさらに圧縮することができないという事実から導かれます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 | O(kⁿ・n) | O(kⁿ) | 遅すぎる |
 | 多層構造 | O(nk) | O(nk) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 最初の k 文字からなる基本アルファベット文字列を昇順に構築します。 これにより、使用可能なすべてのシンボルが単一の「レベル」で提供されます。 
2. この基本文字列を正確に n 回繰り返し、結果を連結します。 各繰り返しは、サブシーケンスが 1 ステップ先に進むことができる新しいレイヤーとして機能します。 
3. 結果の文字列を出力します。 

サブシーケンスはターゲット文字列の i 番目の文字を (i-1) 番目よりも厳密に後の位置から選択できなければならないため、各繰り返しが不可欠です。 レイヤーを繰り返しないと、順序付けの制約を保証できません。 

### なぜ効果があるのか

 長さ n の任意のターゲット文字列は、その i 番目の文字を、繰り返される階層構造内のその文字の i 番目の出現にマッピングすることによって埋め込むことができます。 各レイヤーには k 個の文字がすべて含まれているため、同じ出現を 2 回再利用する必要はなく、レイヤー間の順序付けによってサブシーケンス条件が保証されます。 これにより、ターゲット文字列内の位置から構築された文字列内の位置への単調マッピングが確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    base = ''.join(chr(ord('a') + i) for i in range(k))
    print(base * n)
```このソリューションでは、テスト ケースごとに 1 回アルファベットの接頭辞を作成し、それを n 回繰り返します。 唯一の微妙な点は、n と k の両方が変化するため、各テスト ケースを独立して処理することを保証することです。 

正確さは、繰り返される各ブロック内で完全なアルファベットが維持されるかどうかに完全に依存します。 アルファベットを並べ替えたり削減したりしようとすると、任意のシーケンスをマッピングする機能が無効になります。 

## 実用的な例

 ### 例 1

 入力: n = 2、k = 2

 ベース = "ab"、最終文字列 = "abab" を構築します。 

| ステップ | 対象キャラクター | 建設現場で選ばれた立場 |
 | --- | --- | --- |
 | 1 | | 最初のブロックの最初の 'a' |
 | 2 | b | 2 番目のブロックの最初の 'b' |

 これにより、各選択肢を後のブロックにルーティングできるため、{a, b} 上の長さ 2 の 4 つのシーケンスすべてを埋め込むことができることが確認されます。 

### 例 2

 入力: n = 3、k = 3

 構造: 「abcabcabc」

 | ステップ | 対象キャラクター | 選択された位置 |
 | --- | --- | --- |
 | 1 | b | ブロック1 |
 | 2 | c | ブロック2 |
 | 3 | | ブロック 3 |

 文字が辞書順に繰り返されるか減少する場合でも、後のブロックは常に有効な次の出現を提供します。 

これは、順序付けがブロック内の文字の順序ではなく、純粋にブロック インデックスによって処理されることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(nk) | k 長の基本文字列を構築し、それを n 回繰り返す |
 | スペース | O(nk) | 結果の出力文字列のサイズ |

 この制約により、テストごとに最大 26 文字と 26 回の繰り返しが許可されるため、出力サイズはテスト ケースごとに最大 676 文字となり、制限内で計算して印刷するのは簡単です。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    from io import StringIO
    _out = StringIO()
    _sys.stdin = io.StringIO(inp)

    t = int(input())
    res = []
    for _ in range(t):
        n, k = map(int, input().split())
        base = ''.join(chr(ord('a') + i) for i in range(k))
        res.append(base * n)
    return "\n".join(res)

# single alphabet repeated
assert run("1\n5 1\n") == "aaaaa", "k=1 repetition"

# maximal alphabet small n
assert run("1\n2 3\n") == "abcabc", "small layered case"

# boundary mix
assert run("2\n2 2\n3 1\n") == "baba\naaa", "mixed cases"

 ## 特殊なケース

 k = 1 の場合、この構造は 1 つの文字を n 回繰り返すことになります。 長さ n の文字列はすべて一意に決定されるため、可能な文字列は単一文字の繰り返しだけであるため、結果は自明に正しいものになります。 

n = 1 の場合、最初の k 個の文字のうちのすべての文字がサブシーケンスとして含まれることが要件となります。 構成はアルファベット文字列そのものとなるため、各文字が直接表示されます。 

k と n が大きい場合、各層が独立しており、アルファベットが完全に含まれているため、層状の繰り返しによってサブシーケンスが位置を競合しないことが保証されます。 これにより、異なるターゲット配列間の順序の競合が防止されます。
