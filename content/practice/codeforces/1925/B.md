 ## 解決策
 ## 問題の理解

 整数を分割するように求められます$x$正確に$n$合計が次のような正の整数$x$、これらの整数の最大公約数を最大化する方法で。 入力は複数のテスト ケースを与え、それぞれに次の値が含まれます。$x$そして$n$。 各テスト ケースの出力は、分割時に達成できる最大の GCD を表す単一の整数です。$x$の中へ$n$部品。 

境界は次のことを示します$x$と同じ大きさにすることができます$10^8$そして$n$まで可能です$x$。 最大 1000 のテスト ケースを使用して、考えられるすべての分割またはすべての約数にわたって線形に反復するソリューション。$x$ナイーブでは遅すぎます。 に近いアルゴリズムが必要です$O(\sqrt{x})$または各テストケースごとにそれ以上の結果が得られます。 

エッジケースは次の場合に発生します。$n = 1$または$n = x$。 もし$n = 1$、唯一の選択肢は$x$それ自体なので、GCD は$x$。 もし$n = x$、唯一の有効な分割は$1 + 1 + \dots + 1$、GCD は 1 になります。もう 1 つの微妙なシナリオは次のような場合です。$n$分けない$x$均等に。 割り当ての素朴なアプローチ$x / n$各部分に整数を生成できないため、約数について考える必要があります。$x$有効なパーティションを許可します。 

## アプローチ

 ブルートフォースアプローチでは、あらゆる可能な方法で分割を試みます。$x$の中へ$n$整数を取得し、各分割の GCD を計算します。 これは、長さのシーケンスをすべて列挙できるため、理論的には機能します。$n$合計すると$x$、ただし、シーケンスの数は組み合わせ的に増加します。 たとえば、次の場合$x = 10^8$そして$n = 2$、おおよそあります$10^8$可能なペアは大きすぎます。 したがって、ブルートフォースは非常に少数の場合にのみ実行可能です。 

重要な洞察は、GCD を最大化するには、すべての数値がその GCD の倍数である必要があるということです。$g$。 部品を次のように表すと、$g \cdot a_1, g \cdot a_2, \dots, g \cdot a_n$、その場合、合計は$g \cdot (a_1 + \dots + a_n) = x$。 これはつまり、$g$分けなければなりません$x$。 残りのタスクは、最大のものを選択することです$g$これにより、正確に分解できます$n$正の整数。 

わかったら$g$分割する$x$と定義します。$y = x / g$。 今必要なのは$n$正の整数の合計$y$。 の最小合計$n$正の整数は$n$、だから私たちは持っている必要があります$y \ge n$、これは制約を与えます$g \le x / n$。 これと次の事実を組み合わせると、$g$分けなければなりません$x$、問題は、の最大の約数を見つけることになります。$x$それはせいぜい$x / n$。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$x$そして$n$。 これらは、合計の難易度とサブ問題の数を表します。 
2. 変数を初期化する`best_gcd`1 に設定すると、有効な最大の除数が追跡されます。 
3. すべての整数を反復処理します。$d$1から$\sqrt{x}$。 それぞれについて$d$:

 - どうかを確認してください$d$分割する$x$。 そうでない場合は、続行してください。 
- もし$d$分割する$x$、補数を計算します$x / d$。 
4. 各約数について$d$とその補足$x / d$、以下であるかどうかを確認します。$x / n$。 その場合はアップデートしてください`best_gcd`現在の値とその除数の最大値になります。 
5. すべての約数を考慮した後、`best_gcd`の最大の約数が含まれます$x$を超えないもの$x / n$。 
6. 印刷`best_gcd`テストケース用。 

なぜ機能するのか: 除数を最大まで反復することにより、$\sqrt{x}$、補数を含むすべての約数が考慮されることを保証します。 不変条件というのは、`best_gcd`は常に次の約数です$x$パーティション制約を満たします。 これにより、最終的な値が問題セットのバランスを最大化することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    x, n = map(int, input().split())
    best_gcd = 1
    limit = x // n
    d = 1
    while d * d <= x:
        if x % d == 0:
            if d <= limit:
                best_gcd = max(best_gcd, d)
            if x // d <= limit:
                best_gcd = max(best_gcd, x // d)
        d += 1
    print(best_gcd)
```最初の行はテスト ケースの数を読み取ります。 ループは各テスト ケースを個別に処理します。`limit`有効な分割を可能にする約数のみを考慮するようにします。$n$正の整数。 while ループは、対称性を利用してすべての約数を効率的に見つけます。$x / d$それぞれに$d$。 これにより、ずっと反復する必要がなくなります。$x$が鈍くなるにもほどがあります。
