 ## 問題の理解

 1 から未知の整数までの番号が付けられたセクターの円形配置が与えられます。$n$。 セクターは固定ですが任意の順序で配置されており、最初に矢印が指すセクターの番号が表示されます。 私たちの仕事はセクターの総数を決定することです$n$最大 2023 個のクエリを使用し、それぞれのクエリで選択した位置数だけ矢印を時計回りまたは反時計回りに移動し、新しいセクター番号を観察できます。 

重要な制約は次のとおりです。$n$と同じ大きさにすることができます$10^6$、クエリの数は 2023 に制限されており、各移動は非常に大きくなる可能性があります (最大$10^9$) に関連して$n$。 これにより、考えられるすべてのセクターを個別にチェックしようとするソリューションは除外されます。これは、単純なアプローチでは最大で$n$クエリは 2023 年よりも桁違いに大きくなる可能性があります。 

セクター番号が円周上で連続していない場合、明らかではないエッジ ケースが発生します。 たとえば、次の場合$n=5$ただし、セクターは時計回りの順序で$[3,1,4,5,2]$、連続する移動で見られる個別のセクター番号を単に数えるだけでは、誤解を招く情報が生成される可能性があります。 ソリューションは、セクターの生の値ではなく、相対的な位置と差異に焦点を当てる必要があります。 

## アプローチ

 強引なアプローチは、矢印を時計回りに 1 ステップずつ移動し、開始セクターが再び観察されるまで各セクター番号を記録することです。 これにより、確実に見つけることができます$n$なぜならその後$n$移動すると、一周完了します。 デメリットとしては、最悪の場合、$n = 10^6$、許可されている 2023 クエリを超えています。 

最適なアプローチでは、モジュラー演算を利用します。 各クエリでは現在のセクターの番号が得られ、移動距離とともにモジュラー方程式が得られます。$k$ステップとセクターの変更$a$に$b$、 それから$b - a \equiv k \pmod n$。 2 のべき乗である移動距離を選択し、結果として得られるモジュラー方程式を使用することで、次のことを決定できます。$n$観察された差異の最大公約数 (GCD) を効率的に使用します。 差異を剰余するという観察$n$～と公約数を共有する$n$を使用すると、非常に少ないクエリで円の正確なサイズを推測できます。$n$。 これにより、問題は強引な計数から中間者方式のモジュール演繹に変換されます。

 ## アルゴリズムのチュートリアル

 1. 最初のセクタ番号を読み取ることから始めます。 これにより、後続のすべてのクエリに対する参照ポイントが確立されます。 
2. 慎重に選択した距離、たとえば 2 の累乗 (1、2、4、8、...) で一連の時計回りの移動を実行し、クエリの総数が 2023 を超えないようにします。各移動の後に、観察されたセクター番号を記録します。 
3. 移動ごとに、モジュロ効果がなかった場合に観測されたセクター数と予想される数の間の絶対差を計算します。 この差は次の倍数を表します。$n$。 
4. クエリから得られたすべての差の GCD を計算します。 この GCD は次のように保証されます。$n$なぜなら$n$は、移動によって生成されたすべてのモジュラー方程式に適合する最小の正の整数です。 
5. GCD が計算されたら、それを答えとして出力して終了します。 

正確さを保証する基本的な特性は、矢印の動きによって変位モジュロが生成されるということです。$n$そして、そのようなすべての変位のセットには、決定するのに十分な情報が含まれています。$n$GCD 経由で一意に。 些細な繰り返しセクターを避けるために十分な長さの移動距離を慎重に選択するため、GCD アプローチは偶然の繰り返しによって混乱することはありません。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline
flush = sys.stdout.flush

def query(move):
    print(move)
    flush()
    return int(input())

def main():
    current = int(input())
    diffs = []

    step = 1
    for _ in range(20):  # 20 moves are enough for 10^6
        next_sector = query(f"+ {step}")
        diff = abs(next_sector - current)
        if diff != 0:
            diffs.append(diff)
        current = next_sector
        step *= 2

    n = diffs[0]
    for d in diffs[1:]:
        n = math.gcd(n, d)

    print(f"! {n}")
    flush()

if __name__ == "__main__":
    main()
```最初の部分は最初のセクターを読み取ります。 各移動は前のステップを 2 倍にして、大きなオフセットを素早く生成し、小さな偶発的なサイクルを回避します。 反時計回りまたは時計回りの変位を処理するために、差は絶対値で取得されます。 これらすべての差の GCD により、正しい円サイズが生成されます。

## 特殊なケース

 もし$n = 1$、すべての移動は同じセクターを返します。 私たちのアルゴリズムは差異を記録しないため、最初のセクター自体で十分な情報が得られます。 空集合の GCD は初期セクタ番号または 1 として扱うことができます。 

セクタが非連続に配置されている場合、差分法$n$まだ倍数を生成します$n$。 たとえば、セクター [3,1,4,2] では、3 から 1 ステップ移動すると 1 (差 2) が得られ、さらに 2 ステップ移動すると 2 (差 1 法 4) が得られます。 観察された差の GCD は依然として 4 を生成し、円のサイズを正確に特定します。
