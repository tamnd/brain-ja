 ## 解決策
 ## 問題の理解

 この問題では、天候の制約を考慮して、ディマがスキー場で連続休暇を選択できる方法が何通りあるかを数えるよう求められます。 毎日の気温を表す整数の配列と、休暇の最小長という 2 つの数値が与えられます。$k$そして最高気温は$q$ディマは耐えられる。 有効な休暇期間は、すべての温度が最高以下の連続したサブアレイです。$q$そしてその長さは少なくとも$k$。 タスクは、テスト ケースごとに、有効な休暇期間の合計数を計算することです。 

入力制約は、すべてのテスト ケースの合計日数が次を超えないことを示します。$2 \cdot 10^5$。 大規模な配列のすべての部分配列を列挙するには、$O(n^2)$操作が遅すぎるため、$n$まで$2 \cdot 10^5$。 

考慮すべきエッジケースには、すべての温度が上記を超えるシナリオが含まれます$q$、したがって休暇は不可能です、またはどこで$k = 1$すべての温度が有効です。つまり、毎日および連続するすべてのサブ配列が影響します。 不注意なアプローチでは、ブルートフォースによってサブ配列をカウントしようとし、温度が超過したときに時間制限を超えたり、有効なサブ配列の境界を誤って処理したりする可能性があります。$q$。 

## アプローチ

 ブルートフォースアプローチは、すべての開始日とすべての終了日を繰り返し、それらの間の温度が決して超えないことを確認します。$q$そして長さは少なくとも$k$。 これは正しいですが、次のことが必要です$O(n^2)$テスト ケースごとの操作。これは最大の入力では受け入れられません。 

より迅速なアプローチを可能にする重要な観察は、気温が最高以下の連続する日が続くことです。$q$ブロックとして扱うことができます。 この長さのブロック内で$len$、少なくとも長さのすべての連続する部分配列$k$有効です。 このような部分配列の数は、次の単純な式を使用して直接計算できます。長さのブロックの場合$len \ge k$、 がある$(len - k + 1) + (len - k) + \dots + 1 = (len - k + 1)(len - k + 2)/2$有効な部分配列。 もし$len < k$、有効な部分配列がありません。 これにより、配列を 1 回スキャンして有効なブロックごとにカウントを合計するという問題が軽減されます。 

このアプローチは自然に次のような結果につながります。$O(n)$配列を 1 回走査するだけで、有効な温度のブロックごとに単純な算術式を計算するため、各テスト ケースのアルゴリズムが異なります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 有効な休暇期間の数を追跡するためにカウンターを初期化します。 変数を初期化する`length`気温が以下の連続日の現在のブロックを追跡する`q`。 
2. Iterate through each temperature in the array. 現在の気温が最高の場合`q`、増分`length`現在のブロックを拡張します。 
3.当日の​​気温が以上の場合`q`、現在のブロック内の有効な部分配列の数を計算します。 少なくとも一定の長さのブロックのみ`k`貢献する。 数式を使用する$(length - k + 1) + (length - k) + \dots + 1 = (length - k + 1) \cdot (length - k + 2) / 2$。 リセット`length`新しいブロックを開始するにはゼロにします。 
4. ループの後、配列が有効なシーケンスで終了する場合は、最後のブロックを処理します。 
5. 有効なサブ配列の合計数を返します。 

機能する理由: 最大温度制約を満たすすべての連続した温度ブロックを個別にカウントできます。 各ブロック内で、少なくとも長さの有効なサブ配列の数`k`列挙せずに正確に計算できます。 不変条件は、どの時点でも、`length`現在のインデックスで終了する連続有効日数を表します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_vacations(n, k, q, a):
    count = 0
    length = 0
    for temp in a:
        if temp <= q:
            length += 1
        else:
            if length >= k:
                count += (length - k + 1) * (length - k + 2) // 2
            length = 0
    if length >= k:
        count += (length - k + 1) * (length - k + 2) // 2
    return count

t = int(input())
for _ in range(t):
    n, k, q = map(int, input().split())
    a = list(map(int, input().split()))
    print(count_vacations(n, k, q, a))
```このソリューションは、高速 I/O を使用して入力を読み取り、最大$10^4$テストケースを効率的に実行します。 機能`count_vacations`有効な日数のブロックを追跡し、各ブロックの部分配列の数を計算します。 重要な実装の詳細は、ループ終了後の最後のブロックを処理することですが、これは忘れられがちです。

import sys, io

def run(inp: str) -> str:

    result = []
    t = int(input())

        a = list(map(int, input().split()))
        result.append(str(count_vacations(n, k, q, a)))
