 ## 解決策
 ## 問題の理解

 空港には複数の飛行機があり、それぞれに一定数の空席があります。 列に並んでいるすべての乗客は、航空券を購入する飛行機を選択でき、航空券の価格は、購入時のその飛行機の現在空席の数と同じになります。 乗客が合計を最大化するために貪欲に飛行機を選択した場合の最大総収益と、最小化するために乗客が貪欲に飛行機を選択した場合の最小総収益の 2 つの合計を計算するように求められます。 

入力により乗客数が得られます`n`そして飛行機の数`m`、その後に各飛行機の最初の空席を表す整数の配列が続きます。 最適な乗客の選択のもとで可能な最大収益と最小収益という 2 つの整数を出力する必要があります。 

境界は小さいです:`n`そして`m`は最大 1000、初期シートは最大 1000 です。`n`最大 1000 人であれば、乗客ごとにすべての飛行機をスキャンする単純なアプローチでも引き続き実行できる可能性があります。`O(n*m)`実際には許容できる時間です。 ただし、チケットが販売されるたびに座席が減少するため、適切なデータ構造を選択して、最大または最小の利用可能な座席を持つ飛行機を効率的に取得すると、ソリューションがよりクリーンかつ高速になります。 

明らかではない特殊なケースには、複数の飛行機が同じ数の座席を持っている状況が含まれます。 たとえば、2 つの飛行機の両方に空席が 1 つあり、乗客が 2 人だけの場合、選択する順序は総収益に影響しません。 もう 1 つの微妙なケースは、すべての飛行機に座席が 1 つだけあり、`n`座席の総数に等しい。 乗客は料金を増減できないため、最大収益と最小収益は同じです。 

## アプローチ

 ブルートフォースアプローチは各乗客に対して反復され、乗客ごとにすべての飛行機をスキャンして、最大の収益を得るために最大の座席を備えた飛行機、または最小の収益を得るために最小の座席を備えた飛行機のいずれかを見つけます。 飛行機を選択すると、その飛行機の座席数が 1 つ減ります。 これは、各ステップでの選択が局所的に最適であるため機能しますが、乗客ごとにすべての飛行機をスキャンすると、`O(n*m)`操作。 と`n`そして`m`1000 までは、最大 1,000,000 ステップが必要になる可能性があります。実現可能ですが、やや洗練されていません。 

重要な洞察は、各ステップで飛行機の座席の現在の最大または最小のみが必要になるように問題が構造化されていることです。 優先キューまたはヒープは、最大または最小のシート数を効率的に維持します。 収益を最大化するには最大ヒープを使用し、収益を最小化するには最小ヒープを使用します。 最大値または最小値をポップし、それを収益に追加し、1 ずつ減らし、それでもプラスの場合は押し戻します。 ヒープを使用すると、各操作に時間がかかります`O(log m)`、全体的に複雑になります`O(n log m)`- 境界が大きいほど、よりクリーンでスケーラブルになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n*m) | O(m) | 指定された範囲で許容可能 |
 | ヒープベースの最適 | O(n log m) | O(m) | 効率的かつ明確 |

 ## アルゴリズムのチュートリアル

 1. 入力の読み取り: 乗客数`n`、飛行機の数`m`、および各飛行機の初期の空席を配列として表示します。 
2. 収益を最大化するには、初期シート数から最大ヒープを構築します。 ヒープ内の各要素は、飛行機の現在の空席数を表します。 
3. 合計最大収益のカウンターを初期化します。 
4. 各乗客に対して反復処理を行います。 各ステップで、最大ヒープから最も多くの座席を備えた飛行機を抽出します。 現在の座席数を総収益に加算します。 シート数を 1 つ減らし、値が正のままの場合はヒープに戻します。 
5. 収益を最小限にするには、同様に最小ヒープを構築し、同じプロセスを繰り返しますが、各ステップで座席数が最も少ない飛行機を抽出します。 減少し、プラスの場合は押し戻されます。 
6. 最大収益と最小収益の 2 つの累積合計を出力します。 

機能する理由: このアルゴリズムは、ヒープがすべての飛行機の現在の空席数を常に反映するという不変条件を維持します。 最大値または最小値を選択すると、各乗客にとって局所的に最適な決定が保証されます。 各乗客は貪欲に選択し、座席は厳密に減少するため、一連の貪欲な選択により、世界的な最大または最小の収益が保証されます。 すべての収益単位は、シートが最大の場合は最大、最小の場合は最小のときに収集されるため、より良い合計を生み出す選択肢の組み合わせはありません。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

n, m = map(int, input().split())
seats = list(map(int, input().split()))

# Max revenue using a max-heap (negative values)
max_heap = [-s for s in seats]
heapq.heapify(max_heap)
max_revenue = 0
for _ in range(n):
    top = -heapq.heappop(max_heap)
    max_revenue += top
    if top - 1 > 0:
        heapq.heappush(max_heap, -(top - 1))

# Min revenue using a min-heap
min_heap = seats[:]
heapq.heapify(min_heap)
min_revenue = 0
for _ in range(n):
    top = heapq.heappop(min_heap)
    min_revenue += top
    if top - 1 > 0:
        heapq.heappush(min_heap, top - 1)

print(max_revenue, min_revenue)
```コードはまず、数値を否定することによってシート数を最大ヒープに変換します。`heapq`デフォルトでは最小ヒープです。 収益を最大化するために、最大の座席数を繰り返しポップし、それを収益に追加し、減少させ、プラスの場合は押し戻します。 収益を最小限に抑えるために、最小ヒープを使用し、対称操作を実行します。 同じ座席数の複数の飛行機などの特殊なケース`n`合計シートに等しいシートはヒープによって自動的に処理されます。

 | 1 | [1,1,1] | 2 | [1,1,2] | 2 |
 | 2 | [1,1,0] | 3 | [1,1] | 3 |
 | 3 | [1,0,0] | 4 | [1,0] | 4 |
 | 4 | [0,0,0] | 5 | [0,0] | 5 |

 両方の合計は 5 に等しく、総座席数が乗客数に等しく、最小収益と最大収益が同じになるというエッジ ケースを示しています。 

**サンプル 2**

 入力:`4 3\n3 1 2`| 乗客 | 最大ヒープ | 最大収益 | 最小ヒープ | 最小収益 |

 | 1 | [2,1,2] | 3 | [1,2,3] | 1 |

 これは、異なる最小合計と最大合計を生成する、貪欲な選択のさまざまなシーケンスを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log m) | 各乗客は、ヒープのポップとプッシュを 1 回ずつ実行します。`O(log m)`|
 | スペース | O(m) | すべての飛行機の現在の座席数をヒープに保存します。 

と`n`そして`m`1000まで、`n log m`操作数は約 10,000 で、2 秒の制限内に十分収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    seats = list(map(int, input().split()))

    max_heap = [-s for s in seats]
    heapq.heapify(max_heap)
    max_revenue = 0
    for _ in range(n):
        top = -heapq.heappop(max_heap)
        max_revenue += top
        if top - 1 > 0:
            heapq.heappush(max_heap, -(top - 1))

    min_heap = seats[:]
    heapq.heapify(min_heap)
    min_revenue = 0
    for _ in range(n):
        top = heapq.heappop(min_heap)
        min_revenue += top
        if top - 1 > 0:
            heapq.heappush(min_heap, top - 1)

    return f"{max_revenue} {min_revenue}"

# provided samples
assert run("4 3\n2 1 1\n") == "5 5", "sample 1"
assert run("4 3\n3 1 2\n") == "8 4", "sample 2"

# custom cases
assert run("1 1\n1\n") == "1 1", "single passenger, single seat"
assert run("3 3\n1 1 1\n") == "3 3", "all seats 1"
assert run("5 2\n3 5\n") == "16 11", "unequal seats, multiple passengers"
assert run("6 4\n1 2 3 4\n") == "18 10", "mixed seats"
assert run("1000 1\n1000\n") == "500
```
