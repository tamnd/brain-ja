 ## 解決策
 ## 問題の理解

 有向非巡回グラフ (DAG) を頂点 1 から頂点 n までナビゲートし、途中でカードと小道具を収集し、最後に合計の「パワー」を最大化することが求められます。 カードには HP とダメージの両方があり、カードのパワーはその 2 つの積です。 プロップは単一のパワー値を持ち、加算的に寄与します。 頂点での特別なイベントには、カードの獲得、カードの HP の増加、カードのダメージの増加、小道具の取得の 4 種類があります。 最後の頂点では、オプションで 1 枚のカードのダメージを次のように乗算することができます。$10^9$。 私たちの目標は、最終的にすべてのカードのパワーとすべてのプロップのパワーの合計を最大化することです。 

入力制約は中程度で、頂点数は最大 200、エッジ数は最大 2000 です。 グラフは DAG であり、エッジは常に低いインデックスから高いインデックスに向かうため、トポロジー順序は暗黙的に決まります。 これにより、DAG に沿った動的プログラミングが可能になります。 小規模な DAG でも指数関数的に多くのパスが存在する可能性があるため、適度なサイズでは、すべてのパスを明示的に反復するアルゴリズムは除外されます。 ただし、収集されるカードの数が多項式となる頂点ごとの操作は実行可能です。 

最後までにカードが 1 枚しかない場合、微妙なエッジケースが発生します。 途中で HP やダメージのブーストが発生した場合は、ブーストを適用する適切なカードを選択する必要があります。 もう 1 つの注意が必要な点は、ダメージを倍増させることです。$10^9$最後の頂点では、合計が完全に支配される可能性があります。 不注意な実装では、最終的な乗算を慎重に遅らせるかターゲットにすることが最適であるということを考慮できない可能性があります。 

たとえば、頂点 2 がカード (HP 2、ダメージ 3) を与え、頂点 4 がダメージを 10 増加させる場合、パス 1→2→4→n により、最終的にカード (HP 2、ダメージ 13) が得られます。 n でのダメージを乗算すると、$10^9$、マルチプライヤーを効果的に使用せずに複数の小さなカードを蓄積するパスよりもはるかに高い結果が得られます。 

## アプローチ

 ブルート フォース ソリューションでは、頂点 1 から頂点 n までのすべてのパスを列挙し、各パスに沿ってカードのすべてのセットを追跡します。 各頂点で、すべてのカードにイベントを適用し、合計パワーを計算します。 これは概念的には機能しますが、すぐに実行不可能になります。パスの数は n とともに指数関数的に増加する可能性があり、可能なカード状態の数も組み合わせ的に増加します。 n = 200 であっても、操作数は天文学的になります。 

重要な洞察は、問題が単調なエッジを持つ DAG であることを認識し、動的プログラミングを使用して各頂点で達成可能な最良の状態を計算できることです。 すべてのブーストは最大でも 1 枚のカードに影響し、ダメージ乗数は最後に 1 枚のカードに適用できるため、考えられるすべてのカードの組み合わせではなく、各頂点で達成可能な最大のカード パワーとプロップ サムを追跡するだけで済みます。 ダメージや HP ブーストを考慮するときは、より小さなカードをブーストすることは常に最適ではないため、最終的に最大のパワーを与えるカードにのみそれを適用します。 これにより、状態空間が大幅に減少します。 

ストーリーは次のとおりです。ブルート フォースは、すべてのパスに沿ってすべての可能なカード セットを追跡するため機能しますが、指数関数的な増加により失敗します。 グラフが DAG であり、ブーストは常に最も強い候補をターゲットにする必要があることを観察すると、状態ごとに 2 つの数値のみを保持する頂点上の DP が可能になります。それは、単一カードの最大パワーと、他のすべてのカードとプロップの合計です。 これにより、扱いやすい O(n・m) の解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n・n) | O(n^2) | 遅すぎる |
 | 最適 | O(n・m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化します。`dp1[i]`そして`dp2[i]`、各頂点 i について。`dp1[i]`1 枚のカードの最大パワーを追跡し、後で乗算する可能性があります$10^9$、 そして`dp2[i]`小道具を含む他のすべてのパワーの合計を追跡します。 頂点 1 では両方ともゼロです。 
2. トポロジ順 (1 から n) で頂点を処理します。 頂点ごとに`u`、その状態をすべての近隣に伝播します。`v`。 近隣ごとに、イベントのタイプを考慮します。`v`。 
3. 頂点の場合`v`(a, b) を持つ新しいカードを与え、そのパワーを計算します`a*b`。 アップデート`dp1[v]`現在の最大値まで`dp1[v]`そして`a*b`プラス`dp2[u]`。`dp2[v]`残っている`dp2[u]`まだ小道具が集まっていないからです。 
4. 頂点の場合`v`HP またはダメージをブーストし、現在追跡されているカードを特定します`dp1[u]`ブーストを適用します。 新しいカードパワーを計算して更新します`dp1[v]`それに応じて。 保つ`dp2[v] = dp2[u]`。 
5. 頂点の場合`v`べき乗 w のプロップを与えるので、単純に w を追加します`dp2[v]`そして去ります`dp1[v]`変わらない。 
6. 伝播のたびに、次のことを確認します。`dp1[v]`そして`dp2[v]`すべての入力エッジにわたって達成可能な最大値を取得します。 このようにして、私たちは常に全体的に最適なパスを追跡します。 
7. すべての頂点を処理すると、答えは次のようになります。`dp2[n] + dp1[n]*10^9`、最後の頂点で最高のカードに次の値を掛けることができるためです。$10^9$まさに一度。 

機能する理由: このアルゴリズムは 2 つの不変条件を維持します。 初め、`dp1[i]`最後に乗算する予定がある場合、常に頂点 i で到達可能な最高の 1 枚のカードのパワーを表します。 2番、`dp2[i]`パスに沿った他のすべての寄与を表します。 頂点をトポロジー順に処理するため、頂点にアクセスする前にすべての依存関係が解決され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
events = []
for _ in range(n):
    line = list(map(int, input().split()))
    events.append(line)

edges = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    edges[u-1].append(v-1)

dp1 = [0]*n  # max card to multiply
dp2 = [0]*n  # sum of other powers
dp1[0] = 0
dp2[0] = 0

for u in range(n):
    for v in edges[u]:
        e = events[v]
        c1, c2 = dp1[u], dp2[u]
        if e[0] == 0:
            dp1[v] = max(dp1[v], c1)
            dp2[v] = max(dp2[v], c2)
        elif e[0] == 1:
            a, b = e[1], e[2]
            new_card = a*b
            dp1[v] = max(dp1[v], max(c1, new_card))
            dp2[v] = max(dp2[v], c2 + min(c1, new_card) if c1 else c2)
        elif e[0] == 2:
            x = e[1]
            if c1:
                dp1[v] = max(dp1[v], (c1//max(1, c1//(10**9))) + x)
                dp2[v] = max(dp2[v], c2)
        elif e[0] == 3:
            y = e[1]
            if c1:
                dp1[v] = max(dp1[v], (c1//max(1, c1//(10**9))) * y)
                dp2[v] = max(dp2[v], c2)
        elif e[0] == 4:
            w = e[1]
            dp1[v] = max(dp1[v], c1)
            dp2[v] = max(dp2[v], c2 + w)

print(dp2[n-1] + dp1[n-1]*10**9)
