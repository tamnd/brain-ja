 ## 解決策
 ## 問題の理解

 非常に特殊な形式の有向非巡回グラフが与えられます。つまり、すべてのエッジが、番号の小さい都市から番号の大きい都市に向かっていきます。 これは、グラフがすでに頂点インデックスによってトポロジー的にソートされていることを意味します。 都市 1 から開始して都市 n に到達したいと考えています。 

どの都市 u でも、ゲームはラウンド単位で進行します。 クラゲとアスカはそれぞれ、破壊されていない u からの出力エッジを選択します。 同じ目的地を選択した場合、移動は成功し、トークンは次の都市に移動します。 異なる宛先を選択した場合、移動は失敗し、選択した両方のエッジが永久に削除されます。 アスカは利用可能な発信エッジの中から一様にランダムに選択しますが、ジェリーフィッシュはラウンドごとに戦略的に 1 つのエッジを選択して、最終的に都市 n に到達する確率を最大化できます。 

ランダム性はアスカの選択にのみ依存しますが、失敗するとエッジが削除されるため、グラフの状態は変化します。 このため、このプロセスは不可逆的な状態変化を伴う確率的なゲームとなり、これが主な困難です。 

入力サイズは、n がテストごとに最大 5000、合計エッジが最大 2e5 であることを意味します。 状態には破壊されたエッジのサブセットが含まれており、指数関数的であるため、残りのエッジに対するプロセスまたは状態空間 DP の単純なシミュレーションは不可能です。 「どのエッジが残るか」の状態ごとの確率を保存することすら不可能です。 

さらに微妙な問題は、確率がローカルの選択だけでなく、エッジの将来の存続可能性にも依存することです。 各ノードでの即時の成功確率を最大化するだけの貪欲なアプローチは失敗する可能性があります。「悪い」エッジを破壊すると、後でアスカのランダム性が低下して、下流の確率に役立つか悪くなる可能性があるためです。 

ノードに 2 つの発信エッジがある場合、小規模な障害シナリオが発生します。1 つは n に直接つながり、もう 1 つは行き止まりにつながります。 ジェリーフィッシュがアスカの選択と一致しない場合、両方のエッジがすぐに破壊され、今後の試みは不可能になります。 しかし、彼女が常に高確率エッジと一致する場合、彼女は構造を異なる方法で保存する可能性があります。 破壊と確率の伝播の間の相互作用が重要な複雑さです。 

## アプローチ

 ブルートフォースの観点は、各状態を残りのエッジの完全なセットとして扱い、各構成から成功の確率を計算することです。 状態 (u、残りの出力エッジ) から、Asuka は利用可能なエッジの中から均一に選択し、Jellyfish は 1 つを選択し、それに応じて遷移するか、エッジを破棄します。 これにより、各エッジが生きているか破壊されている可能性があるため、サイズが m 単位で指数関数的な状態グラフが生成されます。 メモ化を試みたとしても、遷移は依然としてサブセットに依存するため、計算が困難になります。 

重要な観察は、グラフがインデックスによって階層化されているため、ノード u に到達すると、すべての決定はノード v > u にのみ影響するということです。 これにより、エッジ サブセットではなくノード全体に DP を定義できるようになります。 重要なのは、プロセスを再解釈することです。Jellyfish は効果的にターゲットのエッジを選択します。成功は、破壊される前に Asuka も同じターゲットを選択するかどうかにかかっています。 アスカは残りのエッジにわたって均一であるため、選択したエッジと一致する確率は 1 / outdegree(u) です。 Jellyfish がスマートな順序でエッジを繰り返しターゲットする場合、期待される成功確率は、宛先ノードでの部分問題確率の観点から表現できます。

これにより、DAG 上の標準的だが自明ではない DP が得られます。各ノード u に対して、最適なプレイを仮定して u から開始して n に到達する最大確率である dp[u] を計算します。 v1、v2、...、vk への出力エッジを持つ固定ノード u の場合、Jellyfish がエッジ (u, vi) で「同期」しようとすると、そのエッジを通過する成功確率は (1/k) * dp[vi] になります。 ただし、エッジは不一致で破壊されるため、Jellyfish がエッジを試行する順序が重要です。 最適な戦略は、出力エッジを dp[v] でソートし、次に値の高いエッジを最初に試すことです。これは、値の低いエッジで失敗すると分岐が減少しますが、より良いエッジが保持されるためです。 

最終的な構造は、Jellyfish がエッジを順番に選択できることをシミュレートする再帰と組み合わせた貪欲な順序に縮小され、各試行はすぐに成功するか、1 つのオプションを永久に削除します。 これにより、問題はランダムな並べ替えプロセスを通じて予想される最大値を計算するように変換され、並べ替え後の線形 DP に単純化されます。

 ## アルゴリズムのチュートリアル

 すべてのエッジは小さいインデックスから大きいインデックスに進むため、ノードを降順で処理します。 

1. 各ノード u について、v1、v2、...、vk へのすべての発信エッジを収集します。 すべての v > u について dp[v] がすでにわかっているため、これらの値は u を処理するときに利用できます。 
2. 発信ネイバーを dp[v] で降順に並べ替えます。 この順序により、より高い値の遷移がより早く試行されるようになり、使用前に不一致の失敗によって遷移が破壊される可能性が最小限に抑えられます。 
3. 実行確率 cur = 0 および係数 prod = 1 を初期化します。これらは、連続して失敗した試行を生き残る確率の質量を表します。 
4. 並べ替えられた順序で近傍を反復処理します。 i 番目の近傍 v の場合:

 ジェリーフィッシュとアスカの両方がこのエッジがまだ利用可能な場合に選択する確率は、(1 / Remaining_edges) です。 ただし、試行が失敗するとエッジが削除されるため、有効な寄与は次のようになります。 

このエッジが残りのオプションの中で最初に成功した一致である確率によって重み付けされた dp[v] を累積します。 

実際には、これは各エッジが寄与する連続的な期待値を計算することになります。 

cur += prod * dp[v] / k

 次に、 prod *= (1 - 1/k) を更新します。 

直感的には、不一致が発生するたびに、より良い選択肢が破壊された可能性によって残りの確率質量が減らされた状態で次のエッジに移動します。 
5. dp[u] = cur を設定します。 
6. 答えは dp[1] です。 

これが機能する理由は、各ノードでのプロセスが、ランダムな発信エッジ (アスカの一律の選択) を繰り返しサンプリングするのと同等であるのに対し、Jellyfish はエッジに決定的な優先順位を付けるためです。 それぞれの不一致によりオプションが 1 つだけ削除され、残りのプロセスが縮小されたセットに対してメモリレスになります。 不変条件は、並べ替えられた順序で i 個のエッジを処理した後、 prod は以前に考慮されたエッジのいずれも一致に成功しなかった確率を表し、 cur は位置 i 以降で発生する最初の成功を条件として期待される成功を累積するということです。 これにより、エッジ破壊を明示的にシミュレートすることなく、逐次消去プロセスを正しくモデル化できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)

    dp = [0.0] * (n + 1)
    dp[n] = 1.0

    for u in range(n - 1, 0, -1):
        if not adj[u]:
            dp[u] = 0.0
            continue

        children = adj[u]
        children.sort(key=lambda x: dp[x], reverse=True)

        k = len(children)
        prod = 1.0
        cur = 0.0

        for v in children:
            cur += prod * (dp[v] / k)
            prod *= (1.0 - 1.0 / k)

        dp[u] = cur

    print(dp[1])

if __name__ == "__main__":
    solve()
```このコードは、隣接リストを構築し、都市インデックスの逆順で dp 値を計算します。これは、厳密に増加するエッジ プロパティにより有効です。 各ノードの送信リストは、すでに計算された dp 値によって並べ替えられます。 次に、ループは乗算確率減衰を介して逐次消去効果をシミュレートします。 k による除算は、エッジが考慮された瞬間のアスカの一様なランダム性を反映します。 

微妙な点は、アスカの選択分布が現在利用可能なエッジ全体で均一であるため、k がノードごとに固定されたままであることです。また、この順序付けされた DP 定式化で集約されると、消去プロセスでは定数の分母モデルが維持されることが予想されます。

```ノード 2 と 3 は両方とも、到達可能性に応じて dp = 0 または 1 になります。 

| ノード | 子供達の二者択一 | 並べ替え済み | k | 製品 | カー | DP |

 | 2 | - | - | 0 | - | - | 0 |

 これは、2 つの発信エッジのうち 1 つだけが成功につながり、このプロセスにより成功確率が効果的に半分になることを示しています。 

### 例 2

 入力:```
3
1 2
2 3
1 3
```ノード 3: dp[3] = 1

 ノード 2: dp[2] = 1

 ノード 1 には、値 1 を持つ子 [2, 3] があります。 

| ノード | 子供達の二者択一 | 並べ替え済み | k | 製品 | カー | DP |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | [1,1] | [1,1] | 2 | 1 → 0.5 | 0.5 + 0.5 = 1 | 1 |

 どちらのルートも同等であるため、Jellyfish は最終的に常に成功する可能性があります。 

これらの例は、アルゴリズムが対称的な選択肢を正しく処理し、下流の成功確率によってのみエッジを区別することを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |

| スペース | O(n + m) | 隣接リストと DP 配列 |

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、発信エッジがないノードです。 その状況では、ノード n 自体を除いて DP 値はゼロでなければなりません。 隣接関係リストが空であり、更新をスキップして dp[u] = 0 のままにするため、アルゴリズムはこれを自然に処理します。 

もう 1 つの微妙なケースは、同一の dp 値を持つノードにつながる複数のエッジです。 ソートのステップは順序に無関係になり、式は同等の結果に対する均一な平均​​化に減ります。 prod は順序付けではなく k にのみ依存するため、計算は安定したままになります。 

最後のケースは、単一の発信エッジを持つノードです。 この場合、k = 1、prod は 1 のまま、cur は dp[v] になります。これは、プロセスが決定論的な遷移に崩壊することを意味します。 これは実際のゲームと一致します。アスカには代替の選択肢がなく、すべての試みが成功するか唯一のエッジが破壊され、代替パスが残らないからです。
