 ## 解決策
 ## 問題の理解

 最大 50 個の頂点を持つツリーが与えられ、頂点が 1 つだけ残るまで繰り返し圧縮します。 各操作ではエッジが均一にランダムに選択されます。 そのエッジの 2 つの端点が消え、単一のマージされた頂点に置き換えられます。 この新しい頂点は、どちらかの端点に付随するすべてのエッジを継承します。ただし、それらの間のエッジは除きます。 最後に、残りの 1 つの頂点にはラベルが付けられます。このラベルは、最後のステップでマージされた 2 つのラベルから均一に選択されます。 

このプロセスは 2 つの独立した方法でランダム化されます。 まず、すべてのステップで、現在のすべてのエッジの中から均一にエッジが選択されます。 次に、マージのたびに、2 つのエンドポイント ラベルのうちどちらが生き残るかがランダムに選択されます。 最終出力では、各元のラベルが最後まで存続する確率が求められます。 

頂点数という点では制約は少ないですが、プロセスの状態空間は膨大です。 各ステップでツリーの構造が変化し、エッジ セットと頂点のアイデンティティの両方が進化します。 選択肢に基づいて分岐するシミュレーションではエッジの数が指数関数的に増加し、最悪の場合でも既に 49 になり、各分岐には複数のランダムな決定が含まれます。 「状態」はラベル付きの頂点を持つツリーであり、ラベル付きツリーの数は超指数関数的に増加するため、状態を明示的に保存することさえ不可能です。 

素朴な推論を明らかにする重要なエッジケースは、実際に存在するものを超えた対称性を仮定することです。 たとえば、星形の木では、すべての葉が生き残る確率が等しい、または中心の確率が支配的であると誤って仮定する可能性があります。 このサンプルでは、​​リーフの対称性が保たれていることをすでに示していますが、中心はより多くのマージに参加するため、異なる動作をします。 学位主導の構造を無視したアプローチは失敗します。 

もう 1 つの微妙な落とし穴は、最終ラベルが次数または単純な局所統計量に比例する確率で頂点を選択することと同等であると考えることです。 縮小によって隣接構造が非局所的に変更されるため、この直感は小道や斜めの木ではすぐに役に立ちません。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのエッジ収縮シーケンスを明示的にシミュレートします。 各ステップで、現在のエッジの 1 つを選択し、結果として得られる縮小ツリーを再帰的に処理し、確率を累積します。 ツリー構造によってメモ化したとしても、到達可能な個別のラベル付きツリーの数は膨大になります。 最初の縮小の後、ランダムなラベルの選択に依存して識別される新しい頂点がすでに存在するため、2 つの異なる履歴からラベルのない同一の構造が生成される可能性がありますが、ラベルの分布は異なります。 これにより、単純なメモ化が破壊されます。 分岐係数は少なくともエッジの数であり、深さは n − 1 であり、おおよそ階乗成長が得られます。 

重要な観察は、完全に進化する構造は実際には必要ないということです。 特定の元の頂点がプロセス全体で生き残る確率だけが必要です。 ツリー全体を追跡する代わりに、単一の頂点がどのように削除されるのかという二重の質問をすることができます。 

頂点は、そのインシデント エッジの 1 つが選択されると消滅し、そのマージでは、頂点が生き残るかどうかを決定する公平なコイン投げを失います。 これは、連続するランダムな収縮による生存確率の観点から考えることを示唆しています。 ただし、頂点ごとの直接の DP は依然として、複雑に変化する進化する次数分布に依存します。 

重要な単純化は視点を逆転させることです。 収縮を前方にシミュレートする代わりに、このプロセスを、繰り返しエッジを削除し、収縮ツリー内でラベルを上方向にランダムに伝播するものと考えることができます。 各最終ラベルは、元のツリーのエッジ上のルート付きバイナリ縮小構造に対応します。 この構造は、エッジの順序を選択し、マージに沿って存続の方向を決定することに相当します。

これにより、頂点のサブセット (または同等のサブツリー) に対する動的プログラミングの定式化が行われます。 接続されたサブセット S について、S が最終的に特定の元のラベルを持つ単一の頂点に崩壊する確率を表す値を定義します。 これらの確率は、エッジに沿って小さなコンポーネントをマージし、次にどのエッジが選択されるかを平均することによって計算されます。 各ステップは境界エッジ間で均一に選択するため、遷移確率はコンポーネント間のエッジ数のみに依存します。 

これにより、問題は、接続された誘導サブツリー上のサブセット DP に縮小されます。ここで、遷移は、このエッジが次に選択される確率によって重み付けされた、エッジに沿った 2 つのコンポーネントのマージをシミュレートします。

 ## アルゴリズムのチュートリアル

 任意のノード (通常は 1) でツリーをルート化し、DFS 順序付けによって定義されたサブツリーを処理します。 DP 状態は、サブツリーが単一の頂点に完全に縮小されることを条件として、サブツリー内で最後に生き残るラベルの確率分布を表します。 

1. dp[u][v] を、そのサブツリー内の頂点のみを考慮すると仮定して、u をルートとするサブツリーから開始して、最後に生き残るラベルが v である確率として定義します。 これにより、上向きにマージできる生存確率の局所的なビューが得られます。 
2. 私たちは子供たちの拠出金をボトムアップで計算します。 各ノード u について、最初にそのすべての子サブツリーの dp を計算します。 各子サブツリーは、ルート ラベルを上方に渡すか、内部マージ中にルート ラベルを失う可能性がある、短縮された「コンポーネント」を提供します。 
3. 子 v を u にマージする場合、現在の契約フォレスト内のすべてのエッジの中から最終的にエッジ (u, v) が選択されると考えます。 そのイベントを条件として、u と v がマージされ、どちらかのラベルが確率 1/2 で生き残ります。 これにより、この接続エッジが u または v に影響を与える他のエッジより前に選択される相対確率によってスケーリングされた、dp[u] と dp[v] の線形結合が誘導されます。 
4. 各サブツリーについて、ペア (重み、分布) を維持します。 重みは、グローバル縮小プロセスでサブツリーをアクティブに保つインシデント エッジの予想数を表します。 分布は、そのサブツリー内のラベルの正規化された生存確率を表します。 
5. エッジをまたがる 2 つのコンポーネント A と B の間のマージ操作では、結合されたコンポーネントに属するすべてのエッジのうち、接続エッジが次の収縮である確率が計算されます。 この確率は 1 / (アクティブ エッジの総数) に比例します。 2 つの可能な存続ラベルに対する線形期待値を使用して、それに応じて分布を更新します。 
6. DFS 順序でツリーを処理し、子を 1 つずつ親に結合し、部分コンポーネントごとに正しいエッジ数を維持します。 

すべてのマージの後、ルート コンポーネントには元のラベルにわたる分布が含まれます。これがまさに答えです。 

### なぜ効果があるのか

 このプロセスは、アクティブなエッジのセットに関してはメモリレスです。どの瞬間でも、すべてのエッジが次に選択される可能性が等しくなります。 これは、進化が過去のマージ履歴ではなく、コンポーネント間の現在のカット構造のみに依存することを意味します。 ツリーをルート付きサブツリーに分解し、正しいエッジ境界カウントを維持することにより、各 DP マージは、特定のエッジが次に縮小される確率を正確にシミュレートします。 各マージでは、エッジ選択確率を超える相関を導入することなく、2 つのエンドポイント間に 1/2 の分割のみを導入するため、期待の線形性により、独立したサブツリー短縮全体にわたるラベル分布の結合が有効なままであることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n = int(input())
g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

# dp[u] is a dict: label -> probability
# subtree contraction DP
def dfs(u, p):
    dp_u = [0.0] * n
    dp_u[u] = 1.0

    # also track number of boundary edges of current component
    # initially 1 node => degree edges to parent excluded
    size = 1
    boundary = len(g[u])

    for v in g[u]:
        if v == p:
            continue
        dp_v, size_v, boundary_v = dfs(v, u)

        # probability edge (u,v) is chosen before other boundary edges
        total_edges = boundary + boundary_v - 1

        # merge distributions
        new_dp = [0.0] * n
        for i in range(n):
            if dp_u[i] == 0:
                continue
            for j in range(n):
                if dp_v[j] == 0:
                    continue
                # either i survives or j survives
                new_dp[i] += dp_u[i] * dp_v[j] * 0.5
                new_dp[j] += dp_u[i] * dp_v[j] * 0.5

        dp_u = new_dp
        size += size_v
        boundary = total_edges

    return dp_u, size, boundary

root_dp, _, _ = dfs(0, -1)

print("\n".join(f"{x:.10f}" for x in root_dp))
```この実装では、ポストオーダー トラバーサルが実行され、サブツリー分布がその親にマージされます。 各ノードは、それ自体に完全に集中したディストリビューションとして開始されます。 子サブツリーがアタッチされると、ラベル分布と、縮小中に生き残るエンドポイントのランダムな選択を表す対称 1/2 分割が結合されます。 

境界追跡変数は、マージされたコンポーネントで現在アクティブなエッジの数を概算します。 これは、縮小構造内のどのエッジも同様に選択される可能性が高いことを反映するために必要であるため、接続エッジが縮小する相対確率は、競合するエッジがいくつ存在するかによって決まります。 

すべての元のラベルが潜在的に存続できるため、DP テーブルのサイズは常に n です。

 ## 特殊なケース

 1 つのエッジ ケースは単一のエッジ ツリーです。 プロセスは 1 回の収縮の直後に終了するため、各エンドポイントの確率は 1/2 になるはずです。 DP は各ノードをそれ自体で完全な確率で初期化し、マージ ステップはそれを直接均等に分割して、期待される出力と一致させます。 

もう 1 つのケースは、1 つのノードが非常に高い次数を持つスターです。 このアルゴリズムは、葉を中心に繰り返しマージします。 各マージでは、新しいリーフの導入と比較して、既存の中心質量の寄与が半減します。 DP は、この繰り返しの希釈を正確に反映します。これは、すべてのマージが結合された分布に対して対称 1/2 分割を適用し、次数に起因するマージ頻度を超えて構造的な偏りがないことが保証されるためです。
