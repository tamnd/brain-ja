### なぜ効果があるのか

 すべての接頭辞について、食品タイプに対して維持される残余は、正確にその出現回数を法にしたものになります。`k`。 2 つのプレフィックスについて考えてみましょう。1 つは間隔の前で終わり、もう 1 つはその右のエンドポイントで終わります。 すべての食品タイプの両方の接頭辞に同じ残基がある場合、それらの状態は正確に等しくなります。 2 つの接頭辞の数を減算すると、すべての食品の種類が次の倍数で出現することを意味します。`k`間隔内の回数。 このような間隔は、正確に次のグループに分けることができます。`k`餌の単位が等しいので、サメはそれを完全に食べることができます。 

逆に、インターバルを完全に食べることができる場合、各タイプは次の倍数で発生します。`k`したがって、後のプレフィックスからその間隔を削除しても、残りは変更されません。 2 つのプレフィックスの状態は等しいです。 したがって、有効な間隔は等しいプレフィックス状態に正確に対応します。 

ディクショナリは、等しい状態のすべてのペアを 1 回カウントするため、すべての有効な間隔がカウントされ、無効な間隔はカウントされません。 唯一の近似値はランダム化されたフィンガープリントです。理論的には 2 つの異なる州が同じ 128 ビット値を受け取る可能性がありますが、その確率は無視できます。 

## Python ソリューション```python
import sys
import random

input = sys.stdin.readline

MASK = (1 << 128) - 1

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    # A fresh random weight for every food type.
    rng = random.Random()
    weight = [0] + [rng.getrandbits(128) for _ in range(n)]

    # residue[x] = current frequency of type x modulo k.
    residue = [0] * (n + 1)

    # Frequency of every prefix fingerprint.
    seen = {0: 1}

    state = 0
    answer = 0

    for x in a:
        r = residue[x]

        if r == k - 1:
            # (k - 1) * w[x] -> 0
            state = (state - (k - 1) * weight[x]) & MASK
            residue[x] = 0
        else:
            state = (state + weight[x]) & MASK
            residue[x] = r + 1

        answer += seen.get(state, 0)
        seen[state] = seen.get(state, 0) + 1

    print(answer)

if __name__ == "__main__":
    solve()
```の`residue`配列には、新しい食品単位が処理されるときに変更される情報が正確に保存されます。 剰余が次の型の場合`r`、単位を 1 つ追加すると、次のように変わります。`r + 1`届かない限り`k`この場合、ゼロに戻ります。 

指紋はその残留物と一貫して保持されます。 通常の遷移では、寄与度は次のように変化します。`+weight[x]`。 ラップアラウンド移行では、古い貢献`(k - 1) * weight[x]`は完全に消えるので、その値を差し引きます。 

の`& MASK`操作では指紋モジュロが維持されます`2^128`。 Python の整数は任意に大きくなる可能性があるため、このマスクがないと状態に不必要に大きな値が蓄積されてしまいます。 マスクにより、固定の 128 ビットの指紋も得られます。 

辞書は次から始まります`{0: 1}`空のプレフィックスは実際のプレフィックス状態であるためです。 それを忘れると、位置から始まるすべての有効な間隔が失われます`1`。 答えは現在の状態を挿入する前に更新されるため、現在の位置で終了する間隔の形成には以前のプレフィックスのみが使用されます。 

Python の整数は最終的な答えを安全に処理します。 間隔の最大数は約`2 * 10^10`、これは Python の整数の範囲内に十分収まります。
