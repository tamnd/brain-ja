 ## 問題の理解

 いくつかのテストケースが与えられています。 それぞれの場合に、一連の整数と多くの色があります。 これらの整数のいくつかの出現を最大で次の値を使用して「ペイント」したいと考えています。$k$色、要素を未塗装のままにするオプションあり。 

カラーリング内の制約は微妙です。 まず、1 つの色の中で同じ値を 2 回再利用することはできないため、各色のクラスは配列からの個別の数値のセットになります。 第 2 に、使用されるすべての色は、最終的にまったく同じ数のペイントされた要素になる必要があります。 最後に、これらのルールを満たすすべてのカラーリングのうち、全体でペイントされる要素の数を最大化する必要があります。 

つまり、私たちが構築している構造は本質的には$k$同じサイズのグループ。各グループには個別の値が含まれています。各値をグループごとに 1 回しか使用できないことを考慮しながら、これらのグループをできるだけ大きくしたいと考えています。 

重要な制約はグローバルバランシングです。 一つ色が入ったら$x$要素、すべての色も取得する必要があります$x$なので、ペイントされた総数は次のようになります。$k \cdot x$。 これにより、ソリューションはただちに可能な最大値の選択に集中することになります。$x$。 

入力サイズにより、線形または線形に近いソリューションが求められます。 合計$n$すべてのテスト ケースで最大でも$2 \cdot 10^5$、つまり、どのような解決策であっても、$O(n \log n)$または$O(n)$テスト ケースごとに実行するのは問題ありませんが、単一のテスト ケース内の二次関数はすべて失敗します。 これは、頻度のカウントと要素の慎重な再利用による貪欲な構築を強く示唆しています。 

素朴に推論すると、いくつかの失敗シナリオが現れます。 各値が使用される回数を制御せずに単に貪欲に色を割り当てようとすると、1 つの色に同じ値が間接的に複数回割り当てられる可能性があります。 もう 1 つの落とし穴は、早い段階で色を塗りすぎることです。これにより、後でバランスの取れたグループ全体を最大化することができなくなります。 

単純な間違いの具体例としては、最初の$k$頻度分布をチェックせずに、個別の値を繰り返し、色を塗りつぶします。 値が 1 回だけ出現しても複数の色で使用される場合、色ごとの一意性制約に違反します。 もう 1 つの失敗は、すべての色を同時にサポートするのに十分な個別の要素が存在することを保証せずに、色ごとに大きすぎるターゲット サイズを選択することです。

 ## アルゴリズムのチュートリアル

 私たちは答えをレイヤーで構築します。各レイヤーは、「カラー インデックス容量」の 1 単位をそれぞれに割り当てることに対応します。$k$色。 

1. 配列内の各値の頻度を数えます。 私たちが気にするのは、各値が何回使用できるかだけです。 
2. 値ごとにグループ化されたすべてのポジションのリストを作成します。 これにより、後で値だけでなく特定のインデックスを割り当てることができます。 
3. 要素のすべてのインデックスを収集し、サイズのグループを繰り返し形成します$k$未使用のオカレンスがまだある値を使用します。 
4. 利用可能なインデックスの作業用プールを維持します。 グループを形成するたびに、私たちは次のことを選択します$k$未使用のオカレンスがまだ残っている個別の値に属するインデックス。 
5. これらを割り当てます$k$位置から色へ$1$を通して$k$。 各色はこのグループから 1 つだけ取得されます。 
6. 使用されたオカレンスを削除し、選択できなくなるまでグループの形成を続けます。$k$明確な価値観。 
7. 未使用の要素をゼロのままにして、色割り当て配列を出力します。 

各値の位置のリストを維持し、グループごとに 1 つの未使用の出現を貪欲に取得することにより、実装をよりクリーンに行うことができます。 

### なぜ効果があるのか

 核となる不変条件は、すべてのステップで、サイズの完全なグループのみを構築するということです。$k$であり、すべてのグループには個別の値が含まれます。 常に個別の値の新鮮な値を選択するため、どの色も 2 つの同じ値を受け取ることはなく、グループ内で値が再利用されることはありません。 別の完全なグループを形成できなくなると、残りの未使用のオカレンスは、完全なバランスの取れたカラーリングに寄与できなくなります。これは、別の完全なグループを形成するには不十分であるためです。$k$独特の要素。 これにより、ペイントされる要素の数が最大限に確保されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))

        pos = {}
        for i, v in enumerate(a):
            pos.setdefault(v, []).append(i)

        # we will take at most k occurrences per value (one per layer)
        usable = []
        for v, lst in pos.items():
            for i in range(min(len(lst), k)):
                usable.append(lst[i])

        usable.sort()
        m = len(usable)

        ans = [0] * n
        color = 1
        i = 0

        # build full groups of size k
        while i + k <= m:
            for c in range(1, k + 1):
                ans[usable[i]] = c
                i += 1

        print(*ans)

if __name__ == "__main__":
    solve()

微妙な点は、インデックスの並べ替えです。 これにより、決定論的なグループ化が保証されますが、正確さのために厳密に必要というわけではありません。 グループが一貫して形成されている限り、どのような順序付けも機能します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import defaultdict

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n, k = map(int, input().split())
            a = list(map(int, input().split()))
            pos = defaultdict(list)
            for i, v in enumerate(a):
                pos[v].append(i)

            usable = []
            for v, lst in pos.items():
                for i in range(min(len(lst), k)):
                    usable.append(lst[i])

            usable.sort()
            ans = [0] * n
            i = 0
            m = len(usable)
            while i + k <= m:
                for c in range(1, k + 1):
                    ans[usable[i]] = c
                    i += 1
            out.append(" ".join(map(str, ans)))
        return "\n".join(out)

    return solve()

 ## 特殊なケース

 すべての要素が同一である場合、$k > 1$、色ごとに 1 つのオカレンスのみを使用できるため、ソリューションは最大でも次の値に制限する必要があります。$k$要素の合計。 各値が最大で寄与するため、アルゴリズムはこれを自然に処理します。$k$使用可能なポジション、およびサイズの完全なグループは 1 つだけ$k$形成することができる。 

いつ$k = 1$の場合、各カラー グループのサイズは 1 であり、グループ内での重複は禁止されているため、問題は個別の要素の最大数を選択することになります。 アルゴリズムは、値ごとに 1 つの出現を取得するように正しく折りたたまれます。 

すべての値が何度も繰り返されるなど、周波数が非常に高い場合、制限要因は次のようになります。$k$、 ない$n$。 このアルゴリズムにより、どの値もそれ以上に寄与しないことが保証されます。$k$過剰な割り当てを防止し、正確性を維持します。
