 ## 解決策
 ## 問題の理解

 Polycarp は正確に支払う必要があります`n`1バールと2バール相当のコインのみを使用するバール。 させて`c1`は 1 バール コインの枚数であり、`c2`は2バールコインの枚数になります。 

支払いは以下を満たしている必要があります。$$c_1 + 2c_2 = n$$合計を計算するすべての有効な方法の中で`n`、2 つのコイン タイプのカウントが可能な限りバランスがとれるようにしたいと考えています。 言い換えれば、以下を最小限に抑える必要があります。$$|c_1 - c_2|$$テストケースごとに、最適なペアを 1 つ出力する必要があります。`(c1, c2)`。 

テストケースの数は 10,000 に達する可能性があり、`n`と同じ大きさにすることができます`10^9`。 単一のテスト ケースに対して多くの可能性を試すソリューションは、すぐに疑わしいものになります。 リニアスキャンでも、`n`1 つのテスト ケースに対して最大 10 億回の反復が必要になりますが、これは制限時間をはるかに超えています。 一定時間で答えを計算する直接的な数式が必要です。 

方程式だけを考えてバランスの要件を忘れると、いくつかの特殊なケースは簡単に誤って処理されてしまいます。 

考慮する`n = 1`。```
1
```有効な支払いは次のとおりです。```
1 0
```金額をやみくもに均等に分割する数式では、誤って負の値が生成されたり、合計が満たされなかったりする可能性があります。 

考慮する`n = 2`。```
2
```正しい答えは次のとおりです。```
0 1
```差は 1 です。一方のコインは 1 を提供し、もう一方のコインは 2 を提供するため、同じカウントは不可能です。 

検討してください`n = 5`。```
5
```最適な答えは次のとおりです。```
1 2
```不注意なアプローチは、`(3,1)`なぜなら、合計も 5 になりますが、その差は 1 ではなく 2 だからです。 

興味深いケースが発生するのは、`n`は 3 で割り切れません。これらの余りによって、どのコイン タイプが追加のコインを獲得するかが決まります。 

## アプローチ

 単純な総当たりソリューションでは、考えられるすべての値を試します。`c2`0から`n/2`。 それぞれの選択肢について、以下を計算できます。$$c_1 = n - 2c_2$$そして評価する`|c1 - c2|`。 差が最も小さいペアが答えです。 

これが機能するのは、すべての有効な支払いがちょうど 1 つの選択肢に対応しているためです。`c2`したがって、すべての可能性をチェックすることで、最適なものが確実に見つかります。 

問題はスケールです。 いつ`n = 10^9`の場合、ループは 1 つのテスト ケースに対して約 5 億回の反復を実行します。 最大 10,000 のテスト ケースでは、実行時間が完全に不可能になります。 

重要な観察は、方程式を見ることで得られます。$$c_1 + 2c_2 = n$$もし`c1`そして`c2`正確に等しい、両方とも等しいと言う`x`、 それから：$$x + 2x = 3x = n$$したがって、完全にバランスの取れたソリューションは分裂してしまいます。`n`3つの等しい部分に分けます。 これは、両方のカウントが可能な限り次の値に近づく必要があることを直ちに示唆しています。`n/3`。 

させて：$$n = 3k + r$$どこ`r`は 0、1、または 2 です。 

いつ`r = 0`、分割は完璧です:$$c_1 = k,\quad c_2 = k$$いつ`r = 1`、さらにもう 1 つのバールが必要です`3k`。 追加の 1 バール コインを 1 枚与えると、カウントのバランスを可能な限り保ちながら、合計がちょうど 1 増加します。$$c_1 = k+1,\quad c_2 = k$$いつ`r = 2`、さらに 2 つのバールが必要です`3k`。 さらに 2 バール コインを 1 枚与えると、合計がちょうど 2 増加します。$$c_1 = k,\quad c_2 = k+1$$これにより、直接定数時間の解が得られます。

 ## アルゴリズムのチュートリアル

 1. の値を読み取ります。`n`。 
2. 以下を計算します。$$k = n // 3$$1 バール コイン 1 枚と 2 バール コイン 1 枚で 3 バールとなるため、これがバランスのとれた基本額となります。 
3. 以下を計算します。$$r = n \bmod 3$$残りは、バランスのとれたベースを形成した後に残るバールの数を示します。 
4. もし`r = 0`、出力:$$c_1 = k,\quad c_2 = k$$量は正確に等しい数に分割できます。 
5. もし`r = 1`、出力:$$c_1 = k+1,\quad c_2 = k$$1 バール コインを 1 枚追加すると、合計がちょうど 1 増加し、差は最小限に抑えられます。 
6. もし`r = 2`、出力:$$c_1 = k,\quad c_2 = k+1$$2 バール コインを 1 枚追加すると、合計がちょうど 2 増加し、差は最小限に抑えられます。 

### なぜ効果があるのか

 この方程式では、当然のことながら、コインを 1 バール コイン 1 枚と 2 バール コイン 1 枚からなるペアにグループ化します。 このようなバランスの取れた各ペアは 3 つのバールに貢献します。 もし`n = 3k`、 それから`k`ペアはすでに正確な量を形成しており、カウントは等しいです。 

余りが 1 の場合、ちょうど 1 バールを追加する唯一の方法は、1 バール コインの数を 1 つ増やすことです。 残りが 2 の場合、バランスに最も近い状態を維持しながら正確にさらに 2 バールを追加する唯一の方法は、2 バール コインの数を 1 つ増やすことです。 

結果のカウントは常に次の条件を満たします。`c1 + 2*c2 = n`、その他の有効な解決策では、カウントがさらに離れてしまいます。 したがって、生成されたペアは次のように最小化されます。`|c1 - c2|`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())

    k = n // 3
    r = n % 3

    if r == 0:
        c1, c2 = k, k
    elif r == 1:
        c1, c2 = k + 1, k
    else:
        c1, c2 = k, k + 1

    print(c1, c2)
```実装は数学的導出に直接従います。 

変数`k`バランスのとれた基本分布を表します。 3 バールの各グループは、各タイプの 1 枚のコインで表すことができます。`n // 3`は、そのようなバランスの取れたグループの最大数を示します。 

剰余によって、追加の値をどこに置く必要があるかが決まります。 残りの 1 は、追加の 1 バール コイン 1 枚でのみ供給できます。 残りの 2 は、追加の 2 バール コイン 1 枚で供給できます。 

Python の整数は、`10^9`。 唯一の微妙な点は、残りに応じて追加のコインを正しい額面に割り当てることです。 これらのケースを交換しても合計は満たされますが、差は最小化されません。

import sys
import io

def solve():
    input = sys.stdin.readline

    t = int(input())

        n = int(input())

        k = n // 3
