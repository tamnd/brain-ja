[CF 1551C - 興味深いストーリー](https://codeforces.com/problemset/problem/1551/C)

 **評価:** 1500
 **タグ:** 貪欲、ソート、文字列
 **解決時間:** 4 分 47 秒
 **確認済み:** はい

 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースでは、単語のリストを受け取ります。選択したサブセットが特定の不均衡条件を満たすように、これらの単語をできるだけ多く選択したいと考えています。 

条件は、選択されたすべての単語にわたる文字の頻度を調べることによって評価されます。 手紙の中には`a, b, c, d, e`、選択した単語内の出現の合計数が、他のすべての文字を組み合わせた出現の合計数よりも厳密に大きい文字を見つけたいと考えています。 

これを確認するもう 1 つの方法は、いくつかの単語を選択し、各文字がグローバルに出現する回数を数えることです。 残りのアルファベットを組み合わせて「支配する」文字を探しています。 

タスクは、単語内の何かを最大化することではなく、サブセットをできるだけ大きく保ちながら、この優位性を可能にする単語のサブセットを選択することです。 

制約は大きく、すべてのテスト ケースにわたる単語の合計数は最大 2 · 10^5、文字の合計長は最大 4 · 10^5 です。 これにより、すべてのサブセットを試行したり、候補サブセットごとに文字数を繰り返し再計算したりするソリューションは除外されます。 テストケースごとのソリューションは、合計入力サイズが線形または線形演算に近い必要があります。 

単純な考えとしては、単語のすべてのサブセットを試してみることですが、それは n で指数関数的になるため、すぐには実行できません。 サブセットを並べ替えたり、プレフィックスごとに完全な頻度テーブルを再計算したりしようとしても、時間がかかりすぎます。 

より微妙な失敗モードは、すべての単語を貪欲に取得することから発生します。これは、単一の文字が全体的に支配的でない場合に明らかに失敗します。 たとえば、次のようなバランスの取れた単語`"abcde"`すべての文字に均等に貢献するため、どれだけ多く取られても支配は不可能になります。 

もう 1 つの微妙な問題は、選択した文字が単語内で頻繁に使用される単語を選択する必要があると仮定することです。 この条件は、ローカルで 1 つの文字を最大化するだけではなく、結合された他のすべての文字とのグローバルな比較に依存するため、これだけでは十分ではありません。 

## アプローチ

 主な難点は、条件が文字数を超えてグローバルであるにもかかわらず、決定は単語レベルで行われることです。 これは、各単語が候補文字にどれだけ「役立つ」か「傷つける」かに還元することを示唆しています。 

手紙を修正して、と言う`x`。 選択した単語のセットに対して、次のものが必要です。```
count_x > sum of counts of all other letters
```これを書き直すと、単語ごとに相対的なスコアを定義します。`x`:```
score(word, x) = (# of x in word) - (# of non-x letters in word)
```これを選択した単語で合計すると、条件は次のようになります。```
total_score(x) > 0
```したがって、固定文字の場合、各単語は単一の整数の寄与になります。 合計スコアがプラスになるように、できるだけ多くの単語を選択したいと考えています。 固定文字の最適な戦略は貪欲です。単語をスコアによって降順に並べ替え、累計が正のままである間に接頭辞を取得します。 

最終的な答えは、5 文字すべての中で最良の結果です。 

これが機能するのは、ターゲット文字を修正すると、問題はプレフィックス合計の単調制約のもとで最大サイズのプレフィックス選択になるためです。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 5 つの文字ごとに`a`に`e`、それを候補の支配的な文字として扱います。 

これにより、問題は、その文字が残りの文字を支配できるかどうかを確認することになります。 
2. 各単語について、選択した文字の寄与スコアを計算します。その文字の出現数から他のすべての文字の出現を差し引いたものです。 

これにより、各単語がこの文字に対する有用性を表す単一の整数値に変換されます。 
3. このスコアに従ってすべての単語を降順に並べ替えます。 

これにより、最も有益な単語が最初に考慮されるようになり、プレフィックスが正の状態を保つ時間を最大化します。 
4. ソートされたリストを調べて、現在の合計を維持します。 次の単語を追加しても合計が厳密に正になる限り、プレフィックスを拡張し続けます。 

合計が正でなくなると、停止します。 
5. この手紙で達成できる最大単語数を記録します。 
6. 5 文字すべてに対して繰り返し、それらの文字全体で最大の結果を取得します。 

### なぜ効果があるのか

 固定文字の場合、変換により元の制約が独立寄与の合計に関する線形不等式に縮小されます。 最適な選択は、限界利益が最も高い単語から最初に構成されなければなりません。 それ以外の場合、スコアの低い単語をスコアの高い単語と交換しても、合計が増加するだけか、サイズは減らずに合計が変更されないままになります。 この交換引数は、最も有効なサブセットがソートされた順序のプレフィックスに対応することを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(words):
    best = 0

    for target in "abcde":
        vals = []
        for w in words:
            c = 0
            for ch in w:
                if ch == target:
                    c += 1
                else:
                    c -= 1
            vals.append(c)

        vals.sort(reverse=True)

        s = 0
        cnt = 0
        for v in vals:
            if s + v <= 0:
                break
            s += v
            cnt += 1

        best = max(best, cnt)

    return best

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        words = [input().strip() for _ in range(n)]
        print(solve_case(words))

if __name__ == "__main__":
    main()
```このコードは、前述の削減に従っています。 各単語は、現在のターゲット文字に関連するスコアに変換されます。 並べ替えにより、優勢条件を最も強くサポートする単語が常に優先されるようになります。 プレフィックスの蓄積により、厳密な陽性要件が直接強制されます。 

微妙なディテールは停止条件です`s + v <= 0`。 単語を追加すると厳密な優位性が崩れる場合は、すぐに停止する必要があります。ソート順の関係上、これ以上単語を追加しても良くないからです。 もう 1 つの重要な点は、最適なサブセットはどの文字が優勢として選択されるかに大きく依存するため、文字ごとに個別にスコアを再計算することです。

    for _ in range(t):
        n = int(input())

        out.append(str(solve_case(words)))
    return "\n".join(out)

 ## 特殊なケース

 重要なエッジケースは、次のようにすべての単語が完全にバランスが取れている場合です。`"abcde"`。 このような入力では、すべての文字が均等に寄与するため、すべてのスコアは 0 になります。 最初の加算がすでに厳密な肯定に違反しているため、アルゴリズムはゼロをソートし、すぐに停止します。 

もう 1 つの特殊なケースは、すべての単語が単一の反復文字で構成されている場合です。たとえば、`"a", "a", "a"`。 対象文字について`a`、すべてのスコアが正であるため、すべての単語が採用されます。 他の文字の場合、すべてのスコアは負であり、選択はゼロになります。 最大値が正しくフルカウントになります。 

3 番目のケースは、単語が 1 つの文字を強くサポートするものの、全体としてはわずかに害を及ぼし、順序付け効果を強制する混合優勢です。 並べ替えステップにより、そのような単語が正しく配置されることが保証され、接頭辞ルールにより、無効な選択がシーケンスの後半に忍び込むことが防止されます。
