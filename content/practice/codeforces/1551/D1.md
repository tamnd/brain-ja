 ## 解決策
 ## 問題の理解

 長方形の板が与えられました。$n$行と$m$列、含む$n \cdot m$単位セル。 この積は偶数であるため、ボードをドミノで完全にタイル状に並べることができ、各ドミノは常に 1 辺を共有する 2 つの隣接するセルを正確にカバーします。 

すべての有効なタイリングは正確に使用します$\frac{n m}{2}$ドミノ。 これらのドミノの中で、正確に次のようにタイルを配置できるかどうかを知りたいと考えています。$k$ドミノは水平です。つまり、同じ行内の 2 つの隣接するセルをカバーします。残りのドミノはすべて垂直です。つまり、同じ列内の 2 つの隣接するセルをカバーします。 

タスクはそのようなタイルを構築することではなく、タイルが存在するかどうかを判断することだけです。 

重要な問題は、水平方向と垂直方向の配置が独立していないことです。 グリッド構造は、パリティとジオメトリに応じて、共存できる水平または垂直ドミノの数を制限します。 

制約は小さく、$t \le 10$、$n, m \le 100$。 これにより、タイリングまたはグラフの一致に対する検索が明示的に除外されます。 すべての一致の状態空間でさえも天文学的に大きくなります。$10 \times 10$ボードにはすでに指数関数的な数のドミノ タイリングが存在します。 解決策は、構築ではなく構造的なカウント制約に依存する必要があります。 

単純な間違いは、水平ドミノと垂直ドミノを合計まで自由に割り当てられるものとして扱うことです。 たとえば、次のように仮定することもできます。$k \in [0, \frac{nm}{2}]$可能です。 これは薄いグリッドでは失敗します。 

たとえば、次のことを考えてみましょう。$1 \times 4$ボード。 ドミノは合計 2 つだけで、両方とも水平でなければなりません。$k = 2$強制されます。 他の値は不可能です。 同様の問題が次の場所に表示されます。$2 \times 3$ここで、パリティと行構造は、ドミノの向きがどのように相互作用するかを制限します。 

もう一つの微妙なケースは、$n = 1$または$m = 1$、まったく 1 つの方向のみが可能です。 このケースを明示的に分離しないソリューションでは、混合タイリングが誤って許可されてしまいます。 

## アプローチ

 ブルートフォース手法では、グリッド グラフの完全一致をすべて列挙し、各一致で使用される水平エッジの数をカウントしようとします。 これは、2 部グリッド グラフのすべてのドミノ タイリングを生成し、方向カウントでフィルタリングすることと同じです。 

たとえ$4 \times 4$グリッドでは、ドミノ タイリングの数はすでに多く (100 をはるかに超えています)、面積が増えるにつれて指数関数的に増加します。 のために$10 \times 10$、これは完全に不可能になります。 複雑さは指数関数的に増加します$nm$したがって、このアプローチは小さなグリッドを超えて拡張することはできません。 

重要な観察は、ドミノの配置は気にせず、完全なマッチングで水平エッジの数が達成可能かどうかだけを気にするということです。 グリッド グラフでは、各行は限られた数の水平エッジに寄与します。各行では、水平ドミノが互いに素な隣接するペアをカバーするため、各行は最大でも寄与できます。$\lfloor m/2 \rfloor$水平ドミノ。 同様に、各列の貢献度は最大でも$\lfloor n/2 \rfloor$垂直ドミノ。 

ただし、より強力な構造上の制約は、行と列間のパリティから生じます。 タイリングによってカバレッジが交互に切り替わり、水平方向のドミノを配置できるかどうかは、垂直方向にペアにする必要がある残りの単一セルを行または列のどちらで強制するかによって決まります。 

最終的な特性評価は、パリティベースの実現可能性条件に単純化されます。 

1. 両方の場合$n$そして$m$均等であれば、ボードは両方向にきれいに分割できるため、$k$から$0$に$\frac{nm}{2}$達成可能です。 
2. 1 つの寸法が奇数の場合、一方向には避けられない「撚り」構造があるため、方向が制限されます。 具体的に言うと、$n$が奇数の場合、各列は奇数のセルを構成し、少なくとも 1 つの垂直方向の配置パターン制約が強制され、水平方向のドミノを行全体に分散する方法が制限されます。 対称的に$m$奇数。 

これにより、単純な境界が得られます。唯一の制限は、両方の次元が偶数の場合はすべてが可能であり、少なくとも 1 つの次元が奇数の場合は、次のパリティが得られることです。$k$奇数の次元によって作成された強制的な不均衡と一致する必要があります。 これは、残りの不一致構造が一貫してペアリングできるかどうかをチェックすることになります。 

重要な単純化は、グリッドが 2 部グラフのように動作し、水平エッジの数が微細構造ではなく次元のパリティによってのみ制限されることです。

 ## アルゴリズムのチュートリアル

 1.読む$n, m, k$テストケースごとに。 目標は、ドミノタイルの実現可能性を正確に判断することです。$k$水平ドミノ。 
2. ドミノの合計数を次のように計算します。$tot = \frac{n m}{2}$。 有効な構成はすべて次の条件を満たす必要があります$0 \le k \le tot$。 そうでない場合、答えは即座に「NO」です。 
3. 両方の場合$n$そして$m$偶数の場合は「YES」を返します。$k$範囲内です。 これは、ボードを独立して分割できるためです。$2 \times 2$各ブロック内で、グローバルな一貫性に影響を与えることなく、水平または垂直のペアを自由に選択できます。 
4. 少なくとも 1 つがあれば、$n$または$m$が奇数の場合、グリッドによって方向の不均衡が強制されることが観察されます。 この場合、水平方向のドミノ配置のパリティは、不一致のストリップの構造により固定法 2 になります。 かどうかを確認します$k$これは、このパリティ制約と一致しており、カバーされていない残りの構造が依然として両方向でペアリングできることを検証することになります。 
5. 制約が満たされている場合は「YES」を出力し、満たされていない場合は「NO」を出力します。 

### なぜ効果があるのか

 ドミノ タイリングは、グリッド グラフの完全な一致に対応します。 水平ドミノの数は、行内にある一致するエッジの数と正確に一致します。 両方の次元が偶数の場合、グリッドは独立した偶数サイクルに分解され、グローバルな有効性に影響を与えることなく、水平方向と垂直方向の選択の間でマッチングをローカルに反転できるため、すべてのカウントが達成可能になります。 

次元が奇数の場合、行または列にパリティ欠陥が発生し、完全な一致によって伝播します。 この欠陥により、実現可能な水平エッジ数のパリティ クラスが修正され、到達可能な値が制限されますが、パリティを超える全体的な構造は制限されません。 すべての有効なタイリングはこの不変条件を尊重する必要があるため、これに違反する構成は完全な一致に対応できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        total = (n * m) // 2

        if k < 0 or k > total:
            print("NO")
            continue

        # if both even, everything is achievable
        if n % 2 == 0 or m % 2 == 0:
            print("YES")
        else:
            # both odd
            # in this case, k must be even
            print("YES" if k % 2 == 0 else "NO")

if __name__ == "__main__":
    solve()
```コードは構造分割を直接実装します。 最初のガードは、ドミノの総数が自明な範囲内に収まるようにします。 主な分岐は次元のパリティから生じます。 少なくとも 1 つの辺が偶数であれば、グリッドを独立したペア領域に分解できるものとして扱います。$k$可能です。 両方が奇数の場合、避けられないパリティの不均衡により、水平方向のドミノのカウントは偶数に従うことになるため、偶数のみを受け入れます。$k$。 

微妙な点は、条件が次のように表現されることです。`n % 2 == 0 or m % 2 == 0`、これは「両方とも奇数」の正しい否定です。 ここで、ケースバイケースの間違いが多く発生します。
