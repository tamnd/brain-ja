 ## 解決策

 ## 問題の理解

 平面内には固定された点のセットが与えられています。 このセットから、菅野はランダム化された幾何学ルールを使用してこれらのポイント間を繰り返し移動します。 ランダム性は単純なグラフ構造からではなく、ジオメトリから来ます。各ステップで、現在の位置によってどのラインが適格であるかが決まり、ラインとそのライン上の目的点の両方が均一にランダムに選択されます。 

プロセスは次のように機能します。 選択した初期点 P から開始して、P を通過し、指定されたセットの少なくとも 2 つの点も通過するすべての線を調べます。 このような 1 つのラインが均一に選択されます。 次に、その線上にあるセットのすべての点のうち、菅野は一様にランダムな点に移動し、P 自体がそれらの点の 1 つである場合は、おそらくその位置に留まります。 

この手順を m 回繰り返した後、プロセスが特定の目標点で終了する確率に注目します。 

重要な点は、点セットによって決定される少なくとも 1 つの有効な線上にある限り、開始位置 P を選択できることです。 各クエリについて、固定ステップ数の後に指定されたターゲット ポイントで終了する確率を最大化するために、P を最適に選択する必要があります。 

制約は、最大 200 個のポイントと最大 200 個のクエリ (それぞれ最大 10^4 のステップを持つ) を持つ高密度の幾何学的構造を示します。 これは、ソリューションが n^2 または n^3 程度のサイズの構造を事前計算し、行列または DP 累乗スタイルの遷移で各クエリに応答する必要があることを強く示唆しています。 各移動は有効なラインと均一な選択の再計算に依存するため、ステップの単純なシミュレーションは不可能です。 

複数のポイントが大きなグループ内で同一線上にある場合、微妙なエッジ ケースが発生します。 このような場合、候補ラインの数とその重なりによって、単純な遷移のカウントが歪められる可能性があります。 たとえば、多くの点が 1 つの線上にある場合、その線が遷移確率を支配し、同一線上にある点を正しくグループ化できないと、不正確な均一性の仮定が生じます。 

別のエッジ ケースは、初期点 P の選択から発生します。これは S に限定されませんが、S の少なくとも 2 つの点によって決定される有効な線上になければなりません。単純なアプローチでは、P が S 内に存在する必要があると想定する可能性がありますが、これは不正確で、最適な初期分布を変更します。 

## アプローチ

 強引な解釈では、考えられるすべての開始点 P が、n 点にわたる異なるマルコフ連鎖を誘導するものとして扱われます。 P から、P を通るすべての有効なラインを列挙し、S のすべての点への遷移確率を計算します。次に、クエリごとに、すべての候補 P について m ステップをシミュレートし、ターゲットに最適な結果を選択します。 

P が連続であるため、これはすぐに失敗します。 P を、点のペアを通る線のすべての交点などの有限の候補セットに制限したとしても、そのような点の数は最悪の場合の構造ではすでに O(n^3) であり、あまりにも多すぎます。 P ごとに単一の遷移行列を構築することすら不可能です。 

重要な洞察は、P は変化する可能性がありますが、誘発される遷移の動作は、どのライン ファミリが P で「アクティブ化」されるかにのみ依存し、P の最適な選択は、最初に選択されたラインとして同一線上の点の 1 つのファミリを正確に選択する点に P を配置することに常に対応するということです。 これにより、問題は単一の最大共線グループに集中した初期分布の選択に帰着します。 

k 点を含むラインを修正すると、そのライン上の任意の一般的な点から開始して、最初の移動でそのラインが決定論的に選択され、最初の遷移がそれらの k 点内で均一なジャンプになります。 その瞬間以降、プロセスは点間の誘導遷移行列のみに依存し、幾何学的埋め込みには依存しません。

したがって、遷移確率が共線性クラスに依存する n 状態のマルコフ連鎖に問題を変換します。点のペアごとに、同じ線上にある点の数を数え、それを使用して重み付き遷移を定義します。 

次に、行列のべき乗を使用して m ステップの遷移確率を計算します。 n ≤ 200 であるため、3 次行列のべき乗は個別の構造ごとに実行可能ですが、クエリごとの再計算は避けなければなりません。 代わりに、完全な遷移行列を 1 回事前計算し、バイナリ リフティングまたは反復二乗を使用して必要なすべてのべき乗を累乗し、最良の開始分布を選択することで各クエリに答えます。これは、累乗後のターゲット エントリを最大化する特定の基底ベクトルに対応することがわかります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | P に対するブルート フォース | O(∞ または指数関数) | P あたり O(n^2) | 遅すぎる |
 | 完全な行列モデル + べき乗 | O(n^3 log m + q n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 このプロセスを n 点にわたるマルコフ連鎖として再解釈します。 

1. 点のペアごとに、それらが定義する線を計算し、その線上にあるすべての点を収集します。 これにより、ペアが共線性クラスに分割されます。 各クラスのサイズによって、その行が選択された後に存在する選択肢の数が決まります。 
2. 点 i と j の各ペアについて、i から始まる手が j に進む確率を計算します。 これには、j を含む i までのすべてのラインを合計する必要があります。ラインは現在位置までの有効なラインの中から均一に選択されるため、各ラインは均等に寄与します。 
3. n 行 n 列の遷移行列 T を構築します。ここで、T[i][j] はこの確率です。 この時点でジオメトリは消え、同一線上にあるトリプルとより大きなセットの組み合わせカウントに置き換えられます。 
4. クエリ全体で最大 m までの 2 進累乗を使用して T の累乗を事前計算します。 これにより、行列 T^1、T^2、T^4 などが生成されます。 
5. 各クエリ (t, m) について、事前に計算されたべき乗を組み合わせて T^m を構築します。 答えは、m ステップ後に t にある可能性のある最大確率であり、これは有効な初期状態を最大化することに対応します。 これは、すべての有効な開始状態にわたって T^m の列 t の最大エントリを取得することになります。 
6. この値を出力します。 

これが機能する主な構造的理由は、初期位置が固定されると、遷移確率が幾何学的配置ではなく共線性カウントのみに依存する定常マルコフ連鎖によってランダム性が完全に捕捉されるためです。 P に対する最適化は、誘導された状態空間で最適な開始状態を選択することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_transition(points):
    n = len(points)
    from collections import defaultdict

    line_map = defaultdict(set)

    for i in range(n):
        x1, y1 = points[i]
        for j in range(i + 1, n):
            x2, y2 = points[j]
            dx, dy = x2 - x1, y2 - y1
            g = abs(__import__("math").gcd(dx, dy))
            if g:
                dx //= g
                dy //= g
            line_map[(dx, dy, x1 * dy - y1 * dx)].add(i)
            line_map[(dx, dy, x2 * dy - y2 * dx)].add(j)

    T = [[0.0] * n for _ in range(n)]

    for group in line_map.values():
        group = list(group)
        k = len(group)
        if k <= 1:
            continue
        prob = 1.0 / k
        for i in group:
            for j in group:
                T[i][j] += prob / len(group)

    return T

def matmul(A, B):
    n = len(A)
    C = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if A[i][k] == 0:
                continue
            aik = A[i][k]
            for j in range(n):
                C[i][j] += aik * B[k][j]
    return C

def matpow(T, m):
    n = len(T)
    res = [[0.0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1.0
    base = T
    while m:
        if m & 1:
            res = matmul(res, base)
        base = matmul(base, base)
        m >>= 1
    return res

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    T = build_transition(pts)

    q = int(input())
    queries = [tuple(map(int, input().split())) for _ in range(q)]

    maxm = max(m for _, m in queries)
    P = matpow(T, maxm)

    for t, m in queries:
        best = 0.0
        for i in range(n):
            best = max(best, P[i][t - 1])
        print(best)

if __name__ == "__main__":
    solve()
```この構築では、最初にすべての共線関係を、正規化された方向とオフセットをキーとしたマップに圧縮します。 各キーは最大のライン グループを表します。 遷移行列は、そのような各グループからの寄与を集約し、グループ内で確率を均一に分配します。 

行列乗算は、複数のステップにわたって遷移を伝播するために使用されます。 べき乗により、必要な最大ステップ数までのすべてのクエリに効率的に答えることができます。 

各クエリについて、考えられるすべての開始状態をスキャンし、ターゲットで終了する確率を最大化する状態を選択します。 

## 実用的な例

 単一線上に 3 つの点がある簡略化されたシナリオをトレースします。すべての動きが同じセット内に留まります。 

1線上の点をA、B、Cとします。 

遷移行列を構築した後、すべての状態は 3 つのポイントすべての間で均一に遷移します。 

### クエリ: ターゲット C、m = 2

 | ステップ | 状態分布 |
 | --- | --- |
 | 0 | A、B、または C を選択します |
 | 1 | A、B、C にわたって均一 |
 | 2 | A、B、C にわたって均一 |

 すべての動きが対称であるため、分布はすぐに安定します。 

これは、構造が完全に対称である場合、べき乗によって長いシーケンスが定常的な動作に崩壊することを示しています。 

2 番目の例では、2 つの交差する線が導入されており、トランジションによって 2 つのクリークが混合されます。 行列の累乗は混合分布に向けた収束を示しており、最適な開始点は累乗行列の最も高い列エントリを持つノードです。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての点が 1 つの線上にある場合です。 その場合、すべての有効な移動は常に同じラインを選択し、遷移行列は完全に均一になります。 このアルゴリズムは、均一なマルコフ連鎖に正しく還元されます。 

もう 1 つの特殊なケースは、3 つの点が同一線上にない場合です。 この場合、各ラインには正確に 2 つのポイントが含まれ、すべての遷移は単純な交換プロセスになります。 行列の構築では、これをペアごとの確率 1/2 遷移として自然にエンコードし、累乗によって交互の動作を捕捉します。 

最後のエッジ ケースは、複数の大きな同一線上のグループが 1 つの点で重なる場合です。 ライン マップの構築により、各幾何学的ラインが 1 回だけカウントされることが保証されるため、確率質量が過剰にカウントされることはありません。
