 ## 解決策
 ## 問題の理解

 1 から 1 までの数字の順列を数えるように求められます。$n$まさに持っている$k$「良い」数字。 数字$x$以下を含むすべての連続する部分配列を見た場合、順列内の は良い if と呼ばれます。$x$、まさにあります$m$明確な最大値。 たとえば、順列 [1,3,2,4] の数値 1 は、部分配列 [1]、[1,3]、[1,3,2]、および [1,3,2,4] の一部です。 これらの部分配列の最大値は 1、3、3、および 4 であり、3 つの異なる最大値が得られます。 もし$m$が 3 の場合は 1 が適切です。 

入力は 4 つの整数で構成されます$n, m, k, p$、 どこ$n$は順列サイズ、$m$数値が適切であるために必要な個別の最大値の数です。$k$は順列に必要な適切な数値の正確な数であり、$p$は答えの係数です。 

境界$n \le 100$どれかであることを示します$O(n^4)$それ以上のアプローチでは遅すぎます。 すべての順列を直接カウントすることは不可能です。$n!$順列、より速く成長します$10^{100}$のために$n=100$。 この問題には、順列の明示的な列挙を回避する組み合わせアプローチが必要です。 

明らかではないエッジケースには、次のような状況が含まれます。$m=1$この場合、最大の数値のみが適切になります。 もう一つの厄介なケースは、$k=n$ここで、順列内のすべての数値が適切である必要がありますが、これは非常に制約された構成でのみ可能です。 素朴な解決策が順列ごとに部分配列をカウントする場合、これらの境界では失敗します。 

## アプローチ

 ブルートフォースアプローチでは、すべてが生成されます。$n!$順列を作成し、各数値を反復処理し、各数値に対してその数値を含むすべての部分配列を計算して、個別の最大値をカウントします。 このアプローチは論理的には正しいですが、階乗時間計算量があり、次のような場合には実行できません。$n>10$。 

重要な洞察は、数字を構成するものを理解することから得られます。$x$良い。 数字の場合$x$順列では、それを含む部分配列内の個別の最大値の数は、より大きい数値の相対位置によってのみ決定されます。$x$。 正確にあるなら$m-1$より大きい数値$x$順列を「分割」する$x$、 それから$x$良いでしょう。 したがって、問題を組み合わせ的に再構成できます。つまり、どの数値が適切であるかを選択し、最大数を満たすようにそれぞれの適切な数値に対して相対的に大きい数値を配置し、有効な配置を数えます。 

残りの位置と残りの「良好なスロット」の数に関する動的プログラミングを使用すると、有効な置換の総数を生成せずに計算できます。 これにより問題は次のように縮小されます$O(n^3)$または$O(n^2)$実装に応じて実現可能$n \le 100$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n^3) | O(n) | 遅すぎる |
 | 最適 | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ある数値が良いかどうかは、その数値より大きい数値と、その数値に対する相対的な位置にのみ依存することを認識します。 したがって、数値を最大から最小の順に処理します。 
2. しましょう$f(i,j)$最初の配置方法の数になります$i$まさにそのような数字$j$それらのうちは良いです。 この DP は、数値サイズごとに順列を増分的にカウントします。 
3. 最大数の場合$n$、それはいつでも良いです$m=1$そうでなければ良いことはできません。 初期化する$f(1,1) = 1$最大値が適切な場合、そうでない場合$f(1,0) = 1$。 
4. 数字ごとに$x$最大のものから最小のものまで、2 つのオプションを検討してください。それを良好または不良として配置します。 最大値のプロパティを維持するために、すでに配置されている数値の周囲の位置を選択する方法はいくつかあります。$\binom{remaining+1}{1}$セグメント間に挿入する方法。 
5. 挿入方法の数を使用して DP テーブルを更新します。$x$既存のシーケンスに組み込んで良好/不良ステータスを維持します。 係数を使用する$p$すべての操作において。 
6. すべての数値を処理した後、$f(n,k)$正確な順列の数が含まれます$k$良い数値の剰余$p$。 

機能する理由: DP 不変条件により、次のことが保証されます。$f(i,j)$最初の順列をすべてカウントします$i$正確に一致する最大の数値$j$小さい数値の相対的な順序とは無関係に、良好な数値が得られます。 最大から最小の順に処理し、挿入位置を組み合わせてカウントすることで、順列が 2 回カウントされることがなくなり、良好な数の状態が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import comb

def main():
    n, m, k, p = map(int, input().split())
    
    # Precompute factorials modulo p for combinations
    fact = [1]*(n+1)
    for i in range(1,n+1):
        fact[i] = fact[i-1]*i % p

    # Precompute binomial coefficients modulo p
    C = [[0]*(n+1) for _ in range(n+1)]
    for i in range(n+1):
        C[i][0] = 1
        for j in range(1,i+1):
            C[i][j] = (C[i-1][j-1]+C[i-1][j])%p

    # DP[i][j]: ways to arrange first i numbers with exactly j good numbers
    dp = [[0]*(k+2) for _ in range(n+2)]
    dp[0][0] = 1

    for i in range(1,n+1):
        for j in range(0,min(i,k)+1):
            # place current number as non-good
            dp[i][j] = dp[i-1][j] * (i-1 + 1) % p
            # place current number as good, if j>0 and possible
            if j>0 and m<=i:
                dp[i][j] = (dp[i][j] + dp[i-1][j-1] * C[i-1][m-1]) % p

    print(dp[n][k]%p)

if __name__ == "__main__":
    main()
```コードはまず階乗と二項係数の法を事前計算します。$p$挿入数を迅速に計算できるようにします。 DP テーブルは、現在の数値が良好な場合とそうでない場合の両方を考慮して、繰り返し更新されます。 組み合わせカウント$C[i-1][m-1]$正確に満たすために現在の数値より大きい数値の位置を選択することを反映します。$m$最大値。
