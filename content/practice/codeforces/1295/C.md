 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`。 最初は空の文字列があります`z`、そして私たちは変身したいのです`z`の中へ`t`。 許可される操作は、次のサブシーケンスを追加することです。`s`に`z`。 サブシーケンスは、次から文字を選択することによって形成されます。`s`相対的な順序を変えることなく。 操作を実行するたびに、次の文字を任意の数追加できます。`s`順番通りですが、再注文はできません`s`または外部で新しいキャラクターを使用する`s`。 

私たちの仕事は、構築するために必要なそのような操作の最小数を決定することです。`t`。 形成不可能な場合`t`なぜなら、あるキャラクターが`t`には現れない`s`、帰るべきです`-1`。 

制約が意味するのは、`s`そして`t`まで可能です`10^5`それぞれの文字数、すべてのテスト ケースの合計の長さは次のとおりです。`2*10^5`。 制限時間は 1 秒で、これよりも複雑なソリューションはすべて`O(|s| + |t|)`テストケースごとにタイムアウトになる可能性があります。 両方の文字列に対するネストされたループにより、次の結果が得られます`O(|s|*|t|)`それは遅すぎます。 

単純なソリューションが失敗する可能性があるエッジケースには次のようなものがあります。`t`に存在しない文字が含まれている`s`、 例えば、`s = "abc"`そして`t = "d"`。 正しい出力は次のとおりです`-1`。 もう一つの微妙なケースは次のような場合です。`t`再利用して形成できる`s`重複しないサブシーケンスで複数回。`s = "ab"`、`t = "ababab"`、慎重に回数を数える必要があります。`s`を追加する必要があります。 

## アプローチ

 ブルートフォースアプローチは、最初から開始することです。`t`そして、最長のサブシーケンスを見つけようと繰り返し試みます。`s`現在のサフィックスと一致するもの`t`。 サブシーケンスが使用されるたびに、次のように進みます。`t`一致したサブシーケンスの長さごとに、最後まで繰り返します。`t`。 これが機能するのは、各操作によって厳密に長さが増加するためです。`z`平行`t`。 ただし、単純にサブシーケンスを見つけるには、全体をスキャンする必要があります。`s`のすべての文字に対して`t`。 もし`s`そして`t`どちらも長さは同じです`10^5`、最悪の場合の複雑さは次のようになります。`O(|s|*|t|)`または`10^{10}`明らかに遅すぎる操作です。 

重要な洞察は、前処理ができるということです。`s`より高速なサブシーケンスのマッチングを可能にします。 各文字の位置を記録できます。`s`の各文字に対して`t`、次の出現箇所をすぐに見つけることができます。`s`指定されたインデックスの後。 これは、リストの辞書と二分探索を使用することで可能になります。 この前処理により、次のように実行できます。`t`効率的に一致を見つけながら直線的に`s`、複雑さが軽減されます`O(|s| + |t| log |s|)`。 

常に一致させようとしているため、ブルートフォースが機能します。`t`のサブシーケンスを使用して`s`、しかし次の場合は失敗します。`t`長いです。 という観察`s`は静的でインデックスを付けることができるため、次の文字の二分探索による線形スイープでのサブシーケンスの追加操作をシミュレートできます。

 ## アルゴリズムのチュートリアル

 1. 前処理`s`各文字のインデックスを記録します。 辞書を作成する`pos`そのような`pos[c]`すべてのインデックスのソートされたリストです。`c`で発生します`s`。 これにより、次に発生する問題を迅速に特定できるようになります。`c`指定されたインデックスの後、二分検索を使用します。 
2. カウンタの初期化`operations = 1`必要となるサブシーケンスの追加の数を追跡するために。 スキャンを開始する`t`最初の文字からポインタを保持します`current_index`の現在の位置に`s`ここで次の文字と一致させようとしています`t`。 
3. キャラクターごとに`c`で`t`、どうかを確認してください`c`に存在します`s`。 そうでない場合はすぐに返品してください`-1`形成するのは不可能だから`t`。 
4. 前処理されたリストの使用`pos[c]`、の最初の出現を見つけます。`c`で`s`それは後に来る`current_index`。 そのようなことがあった場合は移動してください`current_index`そのインデックスに + 1 を加えます。これはマッチングをシミュレートします。`c`現在のサブシーケンス内。 
5. 問題が発生しない場合`c`後`current_index`、これは、新しいサブシーケンスの追加を開始する必要があることを意味します。 インクリメント`operations`、設定します`current_index`最初の出来事に`c`で`s`+1。 
6. すべての文字が入力されるまでこのプロセスを続けます。`t`一致しています。 

### なぜ効果があるのか

 不変条件とは、`current_index`常に次の使用可能な文字を指します。`s`現在のサブシーケンスの追加の場合。 毎回、それを超えるキャラクターを一致させることはできません`current_index`、新しいサブシーケンスを開始します。 これにより、各追加の長さが確実に最大になり、操作の数が最小限に抑えられます。 どの文字もスキップされず、すべての文字がスキップされます。`t`の対応する文字と一致します`s`、正確性を保証します。 

## Python ソリューション```python
import sys
import bisect
input = sys.stdin.readline

def min_operations(s, t):
    pos = {}
    for i, c in enumerate(s):
        if c not in pos:
            pos[c] = []
        pos[c].append(i)
    
    operations = 1
    current_index = -1
    
    for c in t:
        if c not in pos:
            return -1
        idx_list = pos[c]
        i = bisect.bisect_right(idx_list, current_index)
        if i == len(idx_list):
            operations += 1
            current_index = idx_list[0]
        else:
            current_index = idx_list[i]
    return operations

T = int(input())
for _ in range(T):
    s = input().strip()
    t = input().strip()
    print(min_operations(s, t))
```コードは最初に前処理を行います`s`作成する`pos`、リストの辞書。 の各キャラクターごとに、`t`、それは使用します`bisect_right`の次の出現箇所を見つけるには`current_index`。 有効な位置が見つからない場合は、操作カウンタをインクリメントし、最初の位置から再開します。 これにより、追加されるサブシーケンスの最小数がカウントされることが保証されます。
