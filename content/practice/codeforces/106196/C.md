 ## 問題の理解

 私たちは持っています`n`人間と`n`火星人。 人間`i`火星人にしか負けない`i`つまり、それ以外の戦いは自動的に人間が勝つことになります。 最初の行は任意ではありません: 位置`i`数字を持った人間が立っている`i`一方、入力順列により、どの火星人が各位置の反対側に立っているかがわかります。 

指揮官は 1 つの操作を実行できます。つまり、戦列の最後尾にいる人間を先頭に移動させます。 これは人間の配置の正しい循環シフトです。 このようなシフトの最小限の回数が必要です。そうすれば、同じ回数で火星に直面する人間は存在しなくなります。 可能なシフト数がない場合は、次のように出力します。`-1`。 

入力サイズは以下に達します`2 * 10^5`したがって、考えられるすべてのシフトを試し、すべてのポジションをチェックするアプローチには時間がかかります。`O(n^2)`最悪の場合の運用。 何十万もの戦闘機がいるのに、それは遅すぎます。 順列を 1 回または数回処理して答えを見つける必要があります。 

微妙な点は、有効な配置では人間と火星人が同じ順序である必要はないということです。 唯一禁じられている状況は、立場における平等です。 例えば：```
5
1 4 2 3 5
```ゼロシフトでは、人間は`[1,2,3,4,5]`。 1 番目と 5 番目の位置は人間と火星の数が等しいため、答えは一致しません。`0`。 順列が既にソートされているかどうかだけをチェックする不注意な解決策は、ここで失敗します。 

もう 1 つのエッジ ケースは、考えられるすべてのシフトで少なくとも 1 つの衝突が発生する場合です。```
5
1 3 5 2 4
```この順列では、考えられるすべての回転により、同じ番号の火星人に面する人間が残るため、出力は次のようになります。`-1`。 すべての禁止されたシフトを追跡せずに、最初に欠けているように見える位置を常に選択するソリューションでは、無効な答えが生成されます。 

可能な限り最小の入力も考慮する価値があります。```
1
1
```戦闘機は1人だけです。 唯一の配置は人間が同じ火星人に面しているので、どのシフトも役に立たず、答えは次のとおりです。`-1`。 

## アプローチ

 簡単なアプローチは、可能な限りすべての操作をシミュレートすることです。 からのシフトごとに`0`に`n - 1`、結果として得られる人間の位置を構築または検査し、ある位置にそこにいる火星人と同じ番号が含まれているかどうかを確認します。 これは正しいです。なぜなら、到達可能な配置はすべて、元の人間のラインのちょうど 1 回の循環シフトだからです。 

問題は走行時間です。 がある`n`可能なシフトを確認するには、次の情報を確認する必要があります。`n`ポジション、与える`O(n^2)`仕事。 のために`n = 200000`、これは約400億の小切手を意味します。 

重要な観察は、考えられるすべてのシフトが単一の値で記述できるということです。 を実行するとします。`k`操作。 所定の位置に立つ人間`i`元の位置が によって前方に移動されたものです`k`、つまり、彼の番号は次のとおりです。```
((i - k - 1) mod n) + 1
```この値が次の場合に衝突が発生します。`a[i]`。 方程式を並べ替えると、シフトが示されます。`k`まさに次の場合に問題があります。```
k = (i - a[i]) mod n
```すべてのポジションについて、このポジションを無効にする 1 つのシフトをマークできます。 すべての位置を処理した後、答えはマークされていない最小のシフトになります。 

これにより、問題は禁止された剰余モジュロを収集することに変わります。`n`1 回のパスだけが必要です。

 ## アルゴリズムのチュートリアル

 1. 特定のシフト値が不可能かどうかを格納する配列を作成します。 まさにあります`n`可能なシフト、番号付き`0`に`n - 1`。 
2. ポジションごとに`i`、値を計算します`(i - a[i]) mod n`ゼロベースのインデックスを使用します。 この値は、人間の位置を決定する固有のシフトです。`a[i]`この位置では損失が発生します。 
3. この計算されたシフトを禁止としてマークします。 これが機能する理由は、どの位置でも 1 つの循環回転のみを無効にできるためです。 
4. 最小値から最大値までのシフトをスキャンします。 禁止されていない最初のシフトは、必要な最小限の操作数です。 
5. すべてのシフトが禁止されている場合、出力`-1`なぜなら、あらゆる最終的な取り決めには、少なくとも 1 つの負け戦が含まれるからです。 

なぜ機能するのか: すべての巡回シフトは正確に 1 つの剰余モジュロに対応します`n`。 人間の番号と火星の番号が一致するシフトだけ、位置が悪くなります。 このようなシフトをすべてマークすることで、不可能な答えの完全なセットを表します。 マークされていないシフトではどの位置でも衝突がないため、すべての人間が勝ちます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    bad = [False] * n

    for i, x in enumerate(a):
        shift = (i - (x - 1)) % n
        bad[shift] = True

    for ans in range(n):
        if not bad[ans]:
            print(ans)
            return

    print(-1)

if __name__ == "__main__":
    solve()
```配列`bad`禁止されたシフトを保存します。 コードではゼロから始まる位置を使用するため、火星番号は`x`に変換されます`x - 1`位置インデックスと比較する前に。 

式:```
(i - (x - 1)) % n
```派生した式を直接実装したものです。 人間が動く右回転の数を示します。`x`所定の位置に`i`。 このような回転は無効です。`x`火星人に会うでしょう`x`。 

最後のループは昇順に検索し、有効な最小操作数を自動的に指定します。 の`-1`このケースは、あらゆる回転が禁止されている場合にのみ発生します。

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    bad = [False] * n

    for i, x in enumerate(a):
        bad[(i - (x - 1)) % n] = True

    for i in range(n):
        if not bad[i]:
            return str(i)

    return "-1"

assert solve("5\n1 4 2 3 5\n") == "2"
assert solve("5\n1 3 5 2 4\n") == "-1"

assert solve("1\n1\n") == "-1"
assert solve("5\n1 2 3 4 5\n") == "1"
assert solve("6\n2 3 4 5 6 1\n") == "0"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`5 / 1 4 2 3 5`|`2`| 基本的な回転ケース |
 |`5 / 1 3 5 2 4`|`-1`| すべてのシフトは禁止 |

 ## 特殊なケース

 この場合の場合:```
1
1
```可能な位置は 1 つだけで、唯一の人間が唯一の火星人と向かい合うことになります。 計算された禁止シフトは次のとおりです。`0`、これは可能なシフトのセット全体です。 スキャンでは有効な値が見つからず、返されます。`-1`。 

この場合の場合:```
5
1 3 5 2 4
```考えられる周期的な動きごとに少なくとも 1 つの等しい人間と火星のペアが作成されるため、すべてのシフト値がマークされます。 このアルゴリズムは解が存在することを前提としていないため、すべてのシフトをチェックした後、正しく出力されます。`-1`。 

恒等置換の場合:```
5
1 2 3 4 5
```誰もが対応する敵に直面するため、ゼロシフトは無効です。 ただし、1 ずつ回転すると、すべての人間が自分の番号から遠ざかります。`1`マークされていない最初の値が返されます。 これにより、回転後の衝突をチェックするのではなく、順列がソートされているかどうかのみをチェックするというよくある間違いが見つかります。
