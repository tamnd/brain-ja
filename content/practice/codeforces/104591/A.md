 ## アルゴリズムのチュートリアル

 固定長の状態グラフを明示的に構築することで進めます。$L$。 

1. 長さのすべての数字列を列挙します。$L$各数字がどこにあるか$0..L$少なくとも 1 つの数字がゼロ以外です。 これにより、私たちが関心を持つ完全な状態空間が定義されます。 この制約により、有効な Google のみが考慮されるようになります。 
2. 州ごとに$s$、その減衰後続関数を計算します$f(s)$数字の出現を数える$1$を通して$L$、新しい長さを形成します-$L$弦。 このステップでは有向エッジを定義します$s \rightarrow f(s)$。 
3. すべての遷移に対して、逆隣接リストを作成します。$s \rightarrow t$、エッジを保存します$t \rightarrow s$。 これにより、関数グラフが、到達可能性クエリがサブツリーのような走査となる構造に変換されます。 
4. サイクル上にあるすべてのノードを特定します。 すべてのノードには出力エッジが 1 つだけあるため、これは標準の訪問マーキング手法を使用して実行できます。 DFS 中に再訪問されたノードは、サイクル メンバーシップを示します。 
5. 各テスト ケースについて、観察された文字列から開始します。$G$そして、リバース グラフに対してリバース DFS を実行しますが、ノードを再度訪問することは慎重に避けてください。 訪問したすべてのノードは、最終的には次のノードに進化できる有効な先行ノードです。$G$。 
6. 訪問セットのサイズを答えとして返します。 

微妙な点は、サイクルが逆走査でどのように動作するかです。 関数グラフでは、各ノードはアクセス時に 1 回だけカウントされるため、逆エッジによってカウントに曖昧さが生じません。 複数のパスがサイクルにつながる場合でも、DFS は各状態を 1 回カウントすることを保証します。 

### なぜ効果があるのか

 すべての有効なグーグルメントには 1 つの前方遷移があるため、システムは有限集合に対する決定論的な関数となります。 これにより、すべてのノードがサイクルにつながる固有の順方向パスを持つことが保証されます。 逆グラフには、ノードに到達できる可能性のあるすべての「以前の状態」が含まれています。 からのリバース DFS$G$したがって、前進軌道が最終的に到達するすべてのノードのセットを正確に探索します。$G$。 訪問したノードをマークするため、状態が二重にカウントされることはなく、到達可能なすべての状態が 1 回だけ含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def generate_states(L):
    states = []
    def dfs(pos, arr, has_nonzero):
        if pos == L:
            if has_nonzero:
                states.append("".join(map(str, arr)))
            return
        for d in range(L + 1):
            arr[pos] = d
            dfs(pos + 1, arr, has_nonzero or d != 0)
    dfs(0, [0] * L, False)
    return states

def decay(s, L):
    cnt = [0] * (L + 1)
    for ch in s:
        d = ord(ch) - 48
        if 1 <= d <= L:
            cnt[d] += 1
    return "".join(str(cnt[i]) for i in range(1, L + 1))

def solve_case(G):
    L = len(G)
    states = generate_states(L)
    idx = {s: i for i, s in enumerate(states)}
    n = len(states)

    nxt = [0] * n
    rev = [[] for _ in range(n)]

    for i, s in enumerate(states):
        t = decay(s, L)
        j = idx[t]
        nxt[i] = j
        rev[j].append(i)

    start = idx[G]

    visited = [False] * n
    stack = [start]
    visited[start] = True
    ans = 0

    while stack:
        u = stack.pop()
        ans += 1
        for v in rev[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)

    return ans

def main():
    T = int(input())
    for tc in range(1, T + 1):
        G = input().strip()
        print(f"Case #{tc}: {solve_case(G)}")

if __name__ == "__main__":
    main()

減衰関数は定義に厳密に従い、1 から 1 までの桁のみをカウントします。$L$。 この詳細は重要です。数字 0 は変換では無視され、これを含めると正確性が損なわれます。 

次にグラフはテスト ケースごとに 1 回構築され、各状態をその一意の後続の状態にマッピングします。 逆方向のエッジは、後方へのトラバースを可能にするために保存されます。 最後のステップは、観察された状態からの単純な DFS であり、それに到達できるすべてのノードをカウントします。 

一般的な実装の落とし穴は、生成時に「少なくとも 1 つの非ゼロ桁」制約を適用するのを忘れることです。 これがないと、グラフには、答えを人為的に膨らませる無効な状態が含まれます。
