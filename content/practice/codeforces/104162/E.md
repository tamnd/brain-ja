 ## 解決策
 ## 問題の理解

 線に沿って配置された一連のキノコが与えられ、それぞれに初期重量が設定されています。 この初期構成から、隣接するキノコのペアは決定論的な方法で相互作用することができます。単位時間ごとに、任意の 2 つの隣接するキノコの間に、2 つのエンドポイントに依存する重みを持つ新しいキノコが出現します。 重要な考え方は、システムが局所的かつ線形に進化するということです。これは、一定時間後の全体の構成が、繰り返される局所的な組み合わせルールによって完全に決定されることを意味します。 

しばらくして、キノコを非減少順序に再配置した後、プロセスの第 2 段階を観察または概念的に適用します。 課題は、これらの変換後および追加の進化時間後のすべてのキノコの総重量を決定することです。 

したがって、入力により、初期のソートされた重みシーケンスと、並べ替えステップの前後で成長プロセスが実行される時間を制御する 2 つの時間パラメーターが得られます。 出力は、最終進化後の重みの合計です。 

このプロセスは組み合わせのように見えますが、進化の法則は本質的に直線的です。 各キノコの寄与は、隣接演算の二項タイプの展開のみに依存する構造化された方法で時間の経過とともに伝播します。 

制約は非常に大きく、シーケンスの長さは最大 10^6、時間パラメータは最大 10^18 です。 これにより、プロセスのシミュレーションが即座に除外されます。 ステップごとの線形時間進化でさえ、最大 10^18 の演算が必要になりますが、これは不可能です。 実行可能なソリューションは、多くのステップの効果を閉じた形式で、または高速なべき乗のような推論によって計算する必要があります。 

単純な試みでは、隣接するペアを反復し、新しい要素を挿入し、最初のフェーズの後で再実行することによって、成長の 1 つのステップをシミュレートしようとする可能性があります。 これは、n = 10^6 ではすでに失敗します。これは、各ステップのサイズが増加し、ソートが O(n log n) で優勢になり、ステップ数に制限がないためです。 

エッジ ケースは、すべての初期値が等しい場合、n = 1 (隣接効果が存在しない)、および x または y のいずれかが 0 である場合、つまり変換の 1 フェーズのみが発生する場合に発生します。 単純な解決策では、成長ルールが縮退するため、これらを誤って処理することがよくあります。要素が 1 つでは相互作用がないため、答えは元の値に要素の数を掛けただけになります。 

## アプローチ

 重要な観察は、「新しいキノコ = 2 つの近傍の合計」というローカル ルールが、パスカル三角形係数の生成と同じ離散線形漸化式であるということです。 t ステップの後、元の各要素は、二項係数に対応する重みを持つ複数の位置に寄与します。 これは、カーネル [1, 1] で畳み込みを繰り返し適用するのとまったく同じ構造です。 

したがって、キノコが成長することを考える代わりに、初期配列とそれ自体の繰り返しの畳み込みとしてプロセスを再解釈します。 x ステップの後、元の各値は二項係数 C(x, k) に従って寄与します。 ソート後の第 2 フェーズでは基本的に順序付けがリセットされますが、マルチセット構造は維持されます。つまり、ソートされたマルチセットに対して 2 番目の進化を再び独立して処理できることになります。 

強引なアイデアは、畳み込みの増加を明示的にシミュレートすることです。 各ステップでは構造サイズが 2 倍になり、O(n) 以上の作業が必要となるため、x ステップの後は O(n · x) になります。これは、10^18 までの x では不可能です。 

重要な洞察は、[1, 1] による畳み込みの繰り返しが、単純な多項式表現のべき乗に相当するということです。 各要素 ai は独立して処理でき、t ステップ後のその寄与は、位置シフトによって重み付けされた二項係数の合計を乗算した ai になります。 完全な分布で​​はなく合計のみが必要なため、すべてを 1 つのスカラー変換に圧縮できます。

1 つの畳み込みステップ後の合計は単純な形式で保存されます。各ステップは、2×2 遷移行列のべき乗を使用して追跡できる構造化された方法で寄与を 2 倍にします。 2 番目のフェーズは同一であるため、この変換を x ステップに適用し、次に並べ替え (合計には影響しません)、それから y ステップに再度適用することによって、最終的な答えが得られます。 

これにより、問題全体が、和に適用される線形変換の高速累乗と、場合によっては境界寄与を捕捉する補助的な状態に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | 直接シミュレーション | O(n · (x + y)) | O(n) | 遅すぎる |
 | 行列のべき乗による畳み込み | O(n + log(x + y)) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 1. プロセスを、シーケンスに対する線形変換の繰り返し適用として解釈します。各ステップでは、隣接するペアがその合計効果によって置き換えられます。 これにより、集計寄与のみを考慮すれば、要素の順序に依存せずに進化することができます。 
2. 個々の位置ではなく、すべての要素の最終合計のみが必要であることに注意してください。 これにより、状態空間が配列から集約された量の小さなベクトルに折りたたまれます。 
3. 1 つの成長ステップを、t ステップ後に単一の要素がどの程度寄与するかを示す固定サイズ状態での線形変換としてモデル化します。 近傍加算の構造は、この変換が二項展開ステップと同等であることを意味します。 
4. 遷移行列の高速累乗を使用して、x ステップの効果を計算します。 これにより、x ステップ後に各初期要素がどのように寄与するかについて閉じた形式が得られます。 
5. 並べ替えフェーズの後に同じ推論を適用します。 並べ替えによって値の複数セットは変更されないため、集合構造のみが重要になります。 y ステップに対して同じ変換を再開します。 
6. 寄付金を適切に乗算して、最終的な合計額を算出します。 

### なぜ効果があるのか

 重みの進化が加算とスカラー乗算を考慮するという意味で、このプロセスは線形です。 すべての新しいキノコは、既存の 2 つの独立した寄与の合計として形成されるため、各初期要素からの寄与は独立して進化し、重ね合わされます。 これにより、相互作用を明示的にシミュレートすることなく、固定線形演算子を通じて各初期値を追跡できることが保証されます。 ステップの合成は線形演算子の合成に対応するため、べき乗は多くのステップの正確な効果をもたらし、合計は順列不変であるため、順序の変更は総和に影響を与えません。

    return [

def mat_pow(m, e):
    res = [[1, 0], [0, 1]]
    while e:
        if e & 1:
            res = mat_mul(res, m)
        m = mat_mul(m, m)
        e >>= 1
    return res

 ## 特殊なケース

 n = 1 の場合、隣接するペアは存在しないため、新しいキノコは作成できません。 このアルゴリズムは、任意の数のステップの後でも変更されずに元の合計を返すように正しく変換されます。 

x = 0 または y = 0 の場合、位相の 1 つが完全に消えます。 変換は関数合成として適用されるため、指数 0 の適用は恒等に対応し、実装では当然元の合計が保存されます。 

すべてが等しい配列の場合、対称性によりすべての変換で位置全体の比例スケーリングが維持されるため、順序に依存せずに集計された合計が決定論的に変化します。
