 ## 解決策
 ## 問題の理解

 ゲームは整数のリストから始まります。 アンナは、数字の桁を反転することによって最初に移動します。これにより、桁に応じて値が増加または減少します。 Sasha は、任意の 2 つの数値を連結して 2 番目に移動し、リストのサイズを 1 つ減らします。 このようにして、数字が 1 つだけ残るまでゲームが交互に行われます。 最終的な数字が少なくとも次の場合、サーシャの勝ちです$10^m$、そうでない場合はアンナの勝ちです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは整数の数を指定します$n$、しきい値$m$、および整数のリスト$a$。 各テスト ケースの出力は、両方のプレイヤーが最適にプレイしたと仮定した場合の勝者となります。 

制約が示すのは、$n$到達できる$2 \cdot 10^5$そしてすべての合計$n$テストケース全体の上限も次のとおりです。$2 \cdot 10^5$。 これにより、すべてのゲーム状態または順列をシミュレートするソリューションは除外されます。これは、潜在的な手の数が組み合わせによって増加するためです。$n$。 したがって、最適なプレイは、強引なゲーム ツリー探索ではなく、**数値操作に関する戦略的な観察**に依存する必要があります。 

エッジケースが発生するのは次の場合です$n = 1$なぜなら、アンナは逆転してゲームに影響を与えることができず、サーシャには何も動けないからです。 同様に、すでに数が多い場合、アンナの逆転はサーシャの勝利を妨げることはできません。 たとえば、唯一の数字が$9$そして$m = 1$, アンナはサーシャの勝利を避けることができません。$9 \ge 10^0 = 1$。 

## アプローチ

 単純なアプローチでは、アンナのターンですべての数字を反転し、サーシャのターンですべてのペアを連結して、ゲームをシミュレートしようとします。 これは正しいですが、順列の数は階乗であるため実行不可能です。$n$。 大型用$n$、制限時間を超えてしまいます。 

重要な観察は、**アンナは、サーシャが数値を作成するのを妨げるほど最大の数値を減らすことができないということです。$\ge 10^m$** 少なくとも 1 つの数値に十分な桁数がある場合。 連結によって桁数が増加するか、桁数が保持されるため、サーシャはいつでも 2 つの数値を連結して、少なくとも最大の要素と同じ大きさの数値を生成できます。 アンナのリバースは桁を交換するだけで、元の数値を超えて桁数を増やすことはできません。 

したがって、解決策は、**Sasha による最適な連結によって取得可能な最大の数** が少なくとも以下であるかどうかをチェックすることになります。$10^m$。 そうであれば、サーシャが勝ちます。 そうでなければ、アンナが勝ちます。 これにより、**最大桁に基づいた貪欲な評価**が可能になり、完全なシミュレーションを回避できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$m$、その後に整数のリストが続きます$a$。 
3. **最大桁数**の整数を特定します。$a$。 整数を反転しても桁数は変わりません。 
4. コンピューティング$10^m$。 
5. の最大の整数が$a$**少なくとも$10^m$**、サーシャはすぐに、または連結を通じて数値に到達できます。$\ge 10^m$。 サーシャを勝者と宣言します。 
6. そうしないと、アンナがサーシャの到達を妨げる可能性があります。$10^m$、そしてアンナが勝ちます。 

**これが機能する理由:** 不変条件は、Sasha の連結によって常に、現在のリストの最大の要素と少なくとも同じ大きさの数値が生成されるということです。 アンナの逆は桁数を増やすことはできません。 したがって、ゲームの結果は、サーシャによって最適に連結されたときに、いずれかの数値がすでにしきい値に達するのに十分な桁数を持っているかどうかにのみ依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        threshold = 10 ** m
        max_val = max(a)
        if max_val >= threshold:
            print("Sasha")
        else:
            print("Anna")

if __name__ == "__main__":
    solve()
```このソリューションは、高速 I/O を使用して入力を読み取ります。 各テスト ケースについて、最大要素を計算し、それを比較します。$10^m$勝者を決定します。 の使用`max(a)`テスト ケースごとに O(n) の評価を保証します。

## 特殊なケース

 リストに数字が 1 つしかない場合、アンナはゲームに影響を与えることはできず、結果はその数字が ≥ であるかどうかによってのみ決まります。$10^m$。 たとえば、入力の場合`1 1 10`, サシャはすぐに勝ちます。 リストに大きな数値が含まれているが、m が巨大な場合、最大の数値でも到達しない可能性があります。$10^m$、アンナの勝利を可能にします。 このアプローチでは、動きをシミュレートすることなく、これらのエッジケースを正確に考慮します。
