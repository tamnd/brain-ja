 ## 解決策
 ## 問題の理解

 この問題では、3 つのグループの平行線が得られます。 最初のグループには水平線が含まれ、2 番目のグループには 60 度傾いた線が含まれ、3 番目のグループには 120 度傾いた線が含まれます。 すべての線について、Y 軸と交差する場所がわかります。 タスクは、各グループからの 1 つの線の異なる選択肢が何個あり、縮退していない正三角形を作成するかを数えることです。 選択した 3 つの線のうち少なくとも 1 つが異なる場合、2 つの三角形は異なるものとみなされます。 

ジオメトリには便利な簡略化が施されています。 異なるグループからの 3 本の線は、正三角形を形成するか、すべてが 1 点で交わります。 カウントされない唯一のトリプルは、同時実行のものです。 入力サイズは各グループに最大 5000 行を許可し、座標は 10^9 までの大きさにすることができます。 すべてのトリプルを直接チェックするには、最大 50003 = 1,250 億回の操作が必要になります。これは、プログラムが数秒で実行できる量をはるかに超えています。 幾何学的条件をより高速な計数問題に還元する必要があります。 

厄介なケースは、複数の線が同じ点で交差することによって引き起こされます。 トリプルの合計数のみを計算するソリューションでは、縮退したケースが三角形としてカウントされます。 

例えば：```
2
0 0
2
1 1
2
1 1
```トリプルの合計数は 2 × 2 × 2 = 8 です。3 つの線のすべての選択肢が三角形を形成するため、正解は 8 です。 各ラインは別個のオブジェクトであるため、座標が重複しても重複したラインが削除されるわけではありません。 

別のケース:```
1
0
1
0
1
0
```選択された 3 つの直線はすべて原点を通過するため、三角形を形成しません。 答えは 0 です。グループ サイズを単純に乗算すると、誤って 1 が返されます。 

## アプローチ

 簡単なアプローチは、可能な 3 つの行をすべて試してみることです。 各水平線、各 60 度の線、および各 120 度の線について、それらの交点を計算し、それらが同時であるかどうかを確認できます。 これは正しいです。なぜなら、考えられるすべての三角形は、正確に 1 つのトリプル線で表されるからです。 ただし、各グループに 5,000 行あると、トリプルの数は 1,250 億に達し、このアプローチは不可能になります。 

重要な観察は、同時実行には単純な代数条件があるということです。 水平線に Y 切片があるようにします`x`、60 度の線には Y 切片があります。`y`、120 度の線には Y 切片があります。`z`。 それらの方程式は次のとおりです。```
Y = x
Y = sqrt(3)X + y
Y = -sqrt(3)X + z
```最後の 2 行の交点が最初の行にあるのは、次の場合です。```
2 * x = y + z
```したがって、ジオメトリは消えます。 この方程式を満たす数値の 3 倍がいくつあるかを数えるだけで済みます。 

考えられるすべてのトリプルから始めます。`a * b * c`。 次に、同時トリプルの数を減算します。 これらを効率的にカウントするために、2 つのグループからペアをカウントし、3 番目のグループで一致する値を探します。 

あらゆる価値観に対して`y`2 番目のグループとすべての値から`z`3 番目のグループから計算します`y + z`。 値を含む水平線`x`次の場合に不良トリプルが作成されます`2*x = y+z`したがって、最初のグループの 2 倍の値を保存し、一致する合計をカウントします。 最大のグループ サイズは 5000 であるため、2 つのグループ間のすべてのペアをチェックするには最大 2,500 万回の操作が必要ですが、これは十分に適合します。

 ## アルゴリズムのチュートリアル

 1. 3 セットのライン切片を読み取ります。 同時実行条件に次の値が含まれているため、水平線の 2 倍の値を格納します。`2*x`。 
2. 可能なトリプルの総数を数えます。 各方向からの 1 本の線のすべての選択肢が三角形の候補となるため、初期値は次のようになります。`a * b * c`。 
3. すべての値の頻度マップを構築する`2*x`水平線から。 複数のラインが同じ切片を持つ可能性があり、個々のラインごとに個別の可能なトリプルが作成されるため、周波数が必要になります。 
4. 1 本の 60 度ラインと 1 本の 120 度ラインで構成されるすべてのペアに対して繰り返します。 それらの合計を計算する`y + z`。 
5. の周波数を追加します。`y + z`無効なトリプルの数へのマップ内。 各一致は 1 本の水平線を表し、3 本の線が同時に表示されます。 
6. トリプルの総数から無効なトリプルを減算し、結果を出力します。 

それが機能する理由: 異なる方向からの 3 つの線のすべての選択は、有効な正三角形または同時三重のいずれかになります。 このアルゴリズムは、最初に考えられるすべてのトリプルをカウントし、次に導出された方程式を使用して三角形条件を満たさないトリプルを正確にカウントします。`2*x = y+z`。 他のタイプの失敗は存在しないため、これらのケースを削除すると、正確に三角形の数が残ります。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    a = int(input())
    first = list(map(int, input().split()))

    b = int(input())
    second = list(map(int, input().split()))

    c = int(input())
    third = list(map(int, input().split()))

    doubled = defaultdict(int)
    for x in first:
        doubled[2 * x] += 1

    bad = 0
    for y in second:
        for z in third:
            bad += doubled[y + z]

    answer = a * b * c - bad
    print(answer)

if __name__ == "__main__":
    solve()
```辞書`doubled`可能な各値を持つ水平線の数を格納します。`2*x`。 これにより、複数のラインに同じインターセプトがある場合に情報が失われることが回避されます。 

ネストされたループは、2 番目と 3 番目のグループのペアのみを通過します。 各ペアについて、コードは同時実行方程式を満たす水平ラインの数をチェックします。 トリプルの合計数の乗算には Python 整数が使用されるため、オーバーフローは問題になりません。 

減算の前に無効なトリプルをカウントする必要があるため、演算の順序は重要です。 最終的な答えは、すべての選択肢の数から、単一の交点に折りたたまれる選択肢の数を正確に引いたものになります。

 ## 特殊なケース

 のために```
1
0
1
0
1
0
```地図には含まれています`{0: 1}`。 斜めの線からの唯一のペアが合計を持ちます`0`、これは水平方向の 2 倍の値と一致します。 アルゴリズムは 1 つの不良トリプルをマークし、それを 1 つの可能なトリプルから減算し、0 を返します。 

のために```
2
0 0
2
1 1
2
1 1
```水平方向の地図は`{0: 2}`。 斜めの線の各ペアの合計が計算されます`2`、 ない`0`, したがって、同時トリプルは存在しません。 答えは残る`2 * 2 * 2 = 8`。 

一般に、重複切片の場合、周波数マップは間違いを防ぐ部分です。 3 つの異なる水平線が同じ切片を持つ場合、それらは 3 つの別個の選択肢となり、一致する斜めの線のペアが見つかったときにそれぞれが個別に寄与する必要があります。
