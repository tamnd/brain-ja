 ## 問題の理解

 この問題では、列を形成するマッチ棒に色を付ける有効な方法の数を数えるように求められます。`n`つながった四角形。 行には以下が含まれます`n + 1`縦棒と`2n`水平棒。 2 本のスティックが正方形の 1 つの角で交わる場合、競合しているとみなされます。そのため、競合するスティックは同じ色を受け取ることはできません。 使用可能な色の数は、`k`、答えはモジュロで計算する必要があります`998244353`。 これは、Codeforces Gym の問題「Хорозие раскраски - 2024」の問題です。 

の値`n`と同じ大きさにすることができます`10^18`これにより、正方形上のシミュレーションが即座に除外されます。 たとえ`O(n)`動的計画法による解決策は、演算数が約 1 京になるため不可能です。 解決策としては、行の繰り返し構造を小さい状態に縮小し、高速なべき乗を使用する必要があります。 

色の数`k`は係数より小さいですが、それでも非常に大きくなる可能性があります。 色を反復処理することはできないため、解決策では、次のような算術式のみを使用する必要があります。`k`。 

よくある間違いは、正方形の 4 つの辺をすべて互いに異なるものとして扱うことです。 正方形の上下の棒は決して触れませんし、左右の縦棒も決して触れません。 同じ正方形内の水平対垂直のペアのみが制限を作成します。 

のために`n = 1`そして`k = 5`、答えは`260`。 正方形の 4 つの辺すべてを異なる色にする必要がある不用意なアプローチは、カウントされるだけです。`5 * 4 * 3 * 2 = 120`反対側が一致する可能性があるため、これは間違っています。 

もう 1 つのエッジ ケースは、隣接する垂直スティックが同じ色である場合です。 例えば：```
n = 1
k = 3
```2 つの垂直の棒は両方とも赤である場合があります。 上下のスティックは赤を回避するだけでよいため、それぞれに 2 つの選択肢があり、この状況が貢献します。`4`可能性。 隣接する垂直スティックが異なる必要があると仮定したソリューションでは、有効な色が失われます。 

## アプローチ

 直接的な総当りの解決策では、すべてのスティックに可能なすべての色の割り当てを試みることができます。 がある`3n + 1`スティックなので、これには大まかに必要になります`k^(3n+1)`試み。 非常に小さいものでも`n`、検索空間は指数関数的に増大するため、この方法は構造を理解する方法としてのみ機能します。 

有益な観察は、各正方形内の水平棒は、その正方形の境界を接する 2 本の垂直棒の色のみを考慮するということです。 1つの正方形の左右の縦棒に色があるとします。`a`そして`b`。 

もし`a = b`、各水平スティックには`k - 1`選択肢があるため、正方形が貢献します`(k - 1)^2`。 

もし`a != b`、各水平スティックには`k - 2`選択肢があるため、正方形が貢献します`(k - 2)^2`。 

全体の問題は、色を選択することになります。`n + 1`垂直の棒。 隣接する垂直スティック間のすべてのトランジションには、2 つの重みのいずれかが含まれます。 これは 2 つの状態遷移システムです。現在の垂直色が選択した基準色と等しいか、異なるかを知る必要があるだけだからです。 

させて`same`を固定色で終わるすべての処理済み垂直シーケンスの合計重みとし、`diff`固定色とは異なる色で終わる合計重量になります。 移行は次のとおりです。```
new_same = same * (k - 1)^2 + diff * (k - 1) * (k - 2)^2
new_diff = same * (k - 2)^2 + diff * ((k - 2) * (k - 2) + (k - 2) * (k - 3))
```2 番目の式は、基準とは異なる 1 つの特定の色への遷移をカウントします。 現在の色は、前の同じ色から取得することも、別の異なる色から取得することもできるという 2 つの方法で参照と異なるままにすることができます。 

このトランジションを適用する必要があるため、`n`回と`n`は巨大であるため、行列として表し、2 進累乗を使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(k^(3n+1))`|`O(3n)`| 遅すぎる |
 | 最適 |`O(log n)`|`O(1)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1 つの色を基準色として固定します。 最初、最初の垂直スティックは、ある状態ではこの色を持ち、他の状態では別の色を持ちます。 これにより、考えられるすべての色を保存する必要がなくなります。 
2. を構築します。`2 x 2`遷移マトリックス。 この行列は、正方形をもう 1 つ追加すると 2 つの状態がどのように変化するかを示しています。 エントリには、もう 1 つの垂直エッジとそれに接続された水平スティックを処理した後に状態間を移動する方法の数が含まれています。 
3. 遷移行列のべき乗`n`2進累乗を使用します。 各乗算により処理される正方形の数が 2 倍になり、次の処理が可能になります。`10^18`正方形。 
4. 結果の行列を初期状態ベクトルに適用します。 結果として得られる 2 つの状態の合計により、最後の垂直スティックが基準色と等しいか異なる、完全な色の数が得られます。 
5. 結果を乗算します。`k`なぜなら、基準色自体は利用可能な色のいずれかである可能性があるからです。 

アルゴリズムの背後にある不変条件は、いくつかの正方形を処理した後、`same`そして`diff`は、最後の垂直スティックと 1 つの固定基準色との関係によって分類された部分色の重み付けされた数を正確に表します。 トランジションは、考えられる次の垂直方向の色をすべて 1 回だけカウントし、正しい数の水平方向の色の選択肢を追加するため、繰り返し適用しても状態の意味が保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def mul(a, b):
    return [
        [
            (a[0][0] * b[0][0] + a[0][1] * b[1][0]) % MOD,
            (a[0][0] * b[0][1] + a[0][1] * b[1][1]) % MOD
        ],
        [
            (a[1][0] * b[0][0] + a[1][1] * b[1][0]) % MOD,
            (a[1][0] * b[0][1] + a[1][1] * b[1][1]) % MOD
        ]
    ]

def mat_pow(a, e):
    res = [[1, 0], [0, 1]]
    while e:
        if e & 1:
            res = mul(res, a)
        a = mul(a, a)
        e >>= 1
    return res

def solve():
    n = int(input())
    k = int(input())

    x = (k - 1) % MOD
    y = (k - 2) % MOD

    a = x * x % MOD
    b = y * y % MOD

    trans = [
        [a, (k - 1) * b % MOD],
        [b, ((k - 2) * (k - 2) + (k - 2) * (k - 3)) % MOD]
    ]

    powered = mat_pow(trans, n)

    same = 1
    diff = 0

    end_same = (powered[0][0] * same + powered[0][1] * diff) % MOD
    end_diff = (powered[1][0] * same + powered[1][1] * diff) % MOD

    print((end_same + end_diff) % MOD * k % MOD)

if __name__ == "__main__":
    solve()
```乗算関数は 2 の乗算を処理します。`2 x 2`行列のモジュロ`998244353`。 行列のサイズは固定されているため、各乗算には一定数の演算がかかります。 

べき乗関数は標準の 2 進累乗です。 遷移行列を繰り返し 2 乗し、現在のビットが変化したときにそれを適用します。`n`が設定されています。 反復回数はビット数に比例します。`n`、最大入力の場合は約 60 です。 

遷移値は次を使用します。`(k - 1)^2`そして`(k - 2)^2`各正方形には 2 本の独立した水平棒があるからです。 2 行目の式は、色が変化する方法だけでなく、「基準と異なる」状態に留まるすべての方法をカウントするため、間違いやすいです。

import io

        return [

            ]
        ]

            if e & 1:
                r = mul(r, a)
            a = mul(a, a)
