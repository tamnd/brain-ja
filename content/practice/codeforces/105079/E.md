 ## 解決策
 ## 問題の理解

 次のサイズの正方形グリッドが与えられます$N \times N$、各セルはブロックされているか、使用可能です。 ブロックされたセルには のマークが付きます。$-1$、入力できません。 1 つおきのセルには、そのセルで利用できるカップケーキを表す非負の数値が含まれています。 アリスは左上隅から開始します$(1,1)$そして右下隅に到達する必要があります$(N,N)$、各ステップで右または下にのみ移動します。 彼女は独房に入るたびに、そこにあるすべてのカップケーキを集めます。 

このタスクは、アリスが開始から終了までの有効なパスに沿って収集できるカップケーキの最大合計を計算するか、そのようなパスが存在しないことを判断することです。 

グリッドサイズの制約$N \leq 1000$最大100万個の細胞を意味します。 すべてのパスを列挙しようとする解決策は、直ちに実行不可能になります。これは、単調パスの数が指数関数的に、およそ$\binom{2N}{N}$。 これは、たとえ中程度の人であってもすぐに天文学的に大きくなります。$N$したがって、ブルートフォースパス列挙はオプションではありません。 

代わりに、理想的には各セルを一定の回数だけ処理する方法が必要です。$O(N^2)$。 

セルがブロックされているために開始または終了のいずれかが到達不能になった場合、微妙なエッジ ケースが発生します。 もう 1 つは、ジオメトリの点ではセルに到達可能であるが、セルにつながるすべてのパスがブロックされている場合です。 たとえば:

 入力:```
3
0 1 1
-1 -1 1
1 1 1
```目的地が存在し、カップケーキが含まれている場合でも、中央のバリアによってグリッドが切断され、右下のセルに到達することができなくなります。 正しい答えは、$-1$、到達可能性を無視する単純な DP では、値が誤って到達不可能な状態に蓄積されてしまいます。 

## アプローチ

 ブルートフォース戦略では、左上から右下まですべての有効なパスを探索しようとし、途中でカップケーキ カウントを蓄積します。 移動は右と下に制限されているため、各パスは正確に次のシーケンスになります。$2N-2$移動し、そのようなシーケンスの数は指数関数的になります。$N$。 ぶつかる道を剪定しても$-1$セルの場合、障害物のない最悪の場合のグリッドでは、すべての単調パスの探索が強制されますが、これは大きすぎます。 

重要な観察は、任意のセルで収集される値は、そのセルに到達する最適な方法のみに依存するということです。 独房に到着したら$(i,j)$、可能な限り最高の累積値を除き、その時点までの最適なスコアは、そこに到達する方法とは無関係です。 これは典型的な最適な基礎構造の状況です。 

したがって、パスを探索する代わりに、動的プログラミング テーブルを計算します。$dp[i][j]$セルに到達したときに取得できるカップケーキの最大数を表します$(i,j)$。 各セルは、セルに入る唯一の方法であるため、上と左の隣接セルのみに依存します。 セルがブロックされている場合、そのセルは何も寄与せず、到達不能としてマークされます。 

これにより、問題は指数関数的なパスの列挙から、セルごとに一定の作業を行う単純なグリッド トラバースに軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^{2N})$|$O(N)$再帰スタック | 遅すぎる |
 | 動的プログラミング |$O(N^2)$|$O(N^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各州がそのセルに到達したときに達成可能な最高のカップケーキの合計を格納する DP テーブルを定義します。 到達不能な状態を表す方法も必要です。 

1. 2D 配列を初期化する$dp$サイズの$N \times N$、到達不能を表すセンチネル値が埋め込まれます。$-\infty$。 これにより、無効なパスが最大値に寄与するものとして誤って扱われることがなくなります。 
2. 開始セルを設定する$dp[0][0]$。 それがブロックされると、アリスはまったく動くことができないため、問題全体が即座に不可能になります。 それ以外の場合は、ゼロであることが保証されている開始セルの値に初期化します。 
3. グリッドを行ごとに繰り返します。 細胞ごとに$(i,j)$、ブロックされている場合は退出してください。$dp[i][j]$到達不能として。 これにより、パスが合法的に入ることができないため、正確さが保たれます。 
4. セルがブロックされていない場合は、セルに到着するための最善の方法を計算します。 アリスは上からしか来られない$(i-1,j)$または左から$(i,j-1)$したがって、到達可能な場合には、これら 2 つの dp 値の最大値を取得します。 現在のセル値がこの最大値に加算されます。 両方の隣接セルが到達不能な場合、セルは到達不能のままになります。 
5. 表に記入すると、答えは次のようになります。$dp[N-1][N-1]$。 それでも到達できない場合は、出力します$-1$、それ以外の場合は、保存された値を出力します。 

### なぜ効果があるのか

 すべてのセルで$(i,j)$、DP 値は、からのすべての有効なパスの中で達成可能な最大のカップケーキを表します。$(0,0)$に$(i,j)$。 そのようなパスはいずれかから到着することで終了する必要があります$(i-1,j)$または$(i,j-1)$、これらの状態の両方は、それぞれのプレフィックスの最適な値をすでに格納しています。 移行では両方が考慮され、最大値が採用されるため、より適切なプレフィックス パスが見逃されることはありません。 ブロックされたセルは、セルを通過するすべてのパスを排除し、到達不能な領域が今後の計算から除外されるようにするため、遷移を正しく中断します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    grid = [list(map(int, input().split())) for _ in range(n)]
    
    NEG = -10**18
    dp = [[NEG] * n for _ in range(n)]
    
    if grid[0][0] == -1 or grid[n-1][n-1] == -1:
        print(-1)
        return
    
    dp[0][0] = 0
    
    for i in range(n):
        for j in range(n):
            if grid[i][j] == -1:
                continue
            
            if i == 0 and j == 0:
                continue
            
            best = NEG
            if i > 0:
                best = max(best, dp[i-1][j])
            if j > 0:
                best = max(best, dp[i][j-1])
            
            if best == NEG:
                continue
            
            dp[i][j] = best + grid[i][j]
    
    print(dp[n-1][n-1] if dp[n-1][n-1] != NEG else -1)

if __name__ == "__main__":
    solve()
```この実装は DP 定義を直接ミラーリングします。 センチネル値$NEG$到達不可能な状態と有効な合計が混在するのを防ぎます。 開始セルは、その値を誤って 2 回追加したり、存在しない隣接セルに依存したりすることを避けるために、個別に初期化されます。 各遷移は境界を注意深くチェックし、ブロックされたセルを完全にスキップします。 

よくある間違いは、到達不可能なセルをゼロとして初期化し、パスが誤って「壁を通過」することを許可することです。 もう 1 つは、両方の親のチェックに失敗することです。これにより、一方向のみからアプローチする有効なパスが見逃されてしまいます。

 ## 特殊なケース

 主なエッジケースは、スタートまたはフィニッシュがブロックされた場合です。 アルゴリズムは、DP が開始される前にこれらを明示的にチェックします。 どちらかがあれば$-1$、関数はすぐに戻ります$-1$なぜなら、中間構造に関係なくパスは存在できないからです。 例えば：```
2
-1 0
0 0
```ここでは、宛先がグリッド的には到達可能であっても、開始が無効であるため、DP の初期化は決して行われず、正しい出力は次のようになります。$-1$。 

もう 1 つのエッジ ケースは、幾何学的には到達可能だが動的に到達できない孤立したセルです。 考慮する：```
3
0 1 1
-1 -1 1
1 1 1
```重要なセルの潜在的な親セルが両方ともブロックされるため、DP は右下の領域全体を到達不能として正確にマークします。 これは、到達可能性は座標のみに関するものではなく、DP 不変式によって自動的に適用される有効な先行チェーンの存在に関するものであることを示しています。
