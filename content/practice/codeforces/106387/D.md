 ## 問題の理解

 私たちは、固定数の位置と 2 種類の区別できないオブジェクトを含む構成の問題を検討しています。 がある$2n$一列に正確に配置$n$そのうちの残りはアメリカンストーンとラベル付けされています。$n$スウェーデンの石です。 すべての有効な取り決めは同様に可能性が高くなります。 

この質問は、最初の確率が$k$戦列のポジションは全員アメリカ人だ。 つまり、ランダムにどれを選ぶかというと、$n$の$2n$スロットはアメリカのものです。私たちは、ポジションが異なる選択肢の一部を望んでいます。$1$を通して$k$アメリカの地位に入ることが保証されている。 

入力は整数で構成されます$n$そして$k$、出力は、問題の出力形式要件に応じて、小分数または有理数として表される確率値です。 概念的には、考えられるすべての配置に対して有利な配置をカウントしています。 

重要な組み合わせ制約は、正確に選択していることです。$n$範囲外のポジション$2n$したがって、構成の合計数は次のようになります。$\binom{2n}{n}$。 問題は、プレフィックス条件によって制限が強制されることです。$k$ポジションは、選択されたアメリカのポジションのセットに含まれている必要があります。 

これにより、次の場合に微妙な境界条件が導入されます。$k > n$。 利用可能なアメリカ産石よりも多くのプレフィックス位置が必要な場合、確率はまったくゼロになります。 実現可能性をチェックせずに二項係数を盲目的に適用する単純な組み合わせ式では、ゼロ以外の値または未定義の組み合わせが誤って生成されます。 

別のエッジケースが発生するのは次の場合です。$k = 0$。 この場合、制限はないため、確率は正確に 1 でなければなりません。 空の制約を処理せずに階乗比を計算する実装は機能する可能性がありますが、数値的なキャンセルや除算のロジックは注意深く構成されていないと失敗する可能性があります。 

## アプローチ

 強引な解釈では、あらゆる選択方法が列挙されます。$n$アメリカの立場$2n$スロットを確認し、各構成をチェックして、位置が$1$を通して$k$はすべて選択されています。 これは、全体的な結果よりも好ましい結果としての確率の定義に直接従うため、正しいです。 ただし、構成の数は$\binom{2n}{n}$で指数関数的に増加します$n$。 中程度の場合でも$n$、サイズのすべてのサブセットを列挙するため、これは実行不可能になります。$n$から$2n$すでに数億ドル以上の規模になっています。 

重要な観察は、接頭辞制約は、最初の陣地を修正した後に配置されるアメリカ軍陣地の数にのみ影響するということです。$k$スロット。 最初の場合$k$彼らはすでにアメリカ人であることを強制されているので、残りを選択するだけで済みます$n-k$残っているアメリカの石$2n-k$ポジション。 これにより、有利なカウントが単一の二項係数に減ります。$\binom{2n-k}{n-k}$。 

分母は選択する方法の合計数のままです$n$アメリカの立場$2n$、つまり$\binom{2n}{n}$。 したがって、確率は 2 つの組み合わせ量の単純な比です。 

通常は階乗または事前計算された二項係数を使用して計算される直接組み合わせ論に問題を還元することで、総当り攻撃を完全に回避します。

 ## アルゴリズムのチュートリアル

 二項係数とその比率を使用して確率を計算します。 

1. 制約が実現可能かどうかを確認します。 もし$k > n$、すぐにゼロを返します。 これは、プレフィックスに合計で存在する以上のアメリカの石を強制することはできないという事実から生じます。 
2. 有効な構成の合計数を計算します。$\binom{2n}{n}$。 これは正確に配置するすべての方法をカウントします$n$アメリカの石の中でも$2n$制限のないポジション。 
3. 好ましい構成の数を計算します。$\binom{2n-k}{n-k}$。 これは最初の修正から来ています$k$アメリカ人としての地位を確立し、残りを分配する$n-k$残っているアメリカの石$2n-k$スロット。 
4. 全体に対する好ましい構成の比率を返します。 問題で既約分数が予想される場合は、最大公約数ステップを使用して削減します。 

微妙な点は、明示的にアレンジメントを構築することは決してないということです。 すべての決定は組み合わせを数えることに帰着するため、指数関数的な列挙が回避されます。 

### なぜ効果があるのか

 アメリカ産の石のすべての有効な構成は、サイズの 1 つのサブセットに正確に対応します。$n$から選ばれた$2n$。 最初のイベントの条件付け$k$位置が含まれている場合は、それらの位置が選択スペースから削除され、利用可能なスロットの数と必要な選択の両方が均一に減ります。 これによりカウントの均一性が維持されるため、確率は二項係数のきれいな比率になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def comb(n, r):
    if r < 0 or r > n:
        return 0
    r = min(r, n - r)
    res = 1
    for i in range(1, r + 1):
        res = res * (n - r + i) // i
    return res

n, k = map(int, input().split())

if k > n:
    print(0)
else:
    total = comb(2 * n, n)
    good = comb(2 * n - k, n - k)

    g = gcd(good, total)
    good //= g
    total //= g

    print(good, total)
```この実装は、組み合わせ導出を直接反映しています。 ヘルパー関数は、階乗オーバーフローや不必要なメモリ使用を回避するために、二項係数を繰り返し計算します。 対称性の最適化により、ループの長さは次のように短縮されます。$\min(r, n-r)$これにより、大きな値に対して計算が安定します。 

実現可能性チェックは、$k > n$無意味な結果を生み出す組み合わせ関数への無効な呼び出しを防ぎます。 最後のリダクション ステップでは、分数が最も単純な形式で出力されるようにします。これは通常、確率形式の出力で必要となります。 

## 実用的な例

 検討してください$n = 3, k = 1$。 我々は持っています$6$位置を決めて選択する$3$アメリカの石について。 構成の合計数は次のとおりです。$\binom{6}{3} = 20$。 有利な構成を実現するには、次の位置に配置します。$1$アメリカ人でなければならないので、残りを選択します$2$前回からのアメリカの順位$5$、与える$\binom{5}{2} = 10$。 

| ステップ | 値 |
 | --- | --- |
 | 合計$\binom{2n}{n}$| 20 |
 | 良好$\binom{2n-k}{n-k}$| 10 |

 これは、プレフィックスを固定すると、対称性を維持しながら有効な選択スペースが減少することを示しています。 

ここで考えてみましょう$n = 2, k = 2$。 ポジションは 4 つあり、アメリカのストーンを 2 つ選択する必要があります。 最初の 2 つのポジションが両方ともアメリカ人でなければならない場合、アメリカ人の配置には残りの選択肢はありません。 

| ステップ | 値 |
 | --- | --- |
 | 合計$\binom{4}{2}$| 6 |
 | 良好$\binom{2}{0}$| 1 |

 これは、接頭語がすべてのアメリカの石を完全に決定する場合でも、公式が依然としてきれいに機能することを裏付けています。

def run(inp: str) -> str:

 ## 特殊なケース

 のために$k > n$、入力など$n = 3, k = 5$の場合、アルゴリズムは組み合わせ論の前にすぐにゼロを返します。 これにより評価が回避されます$\binom{2n-k}{n-k}$負のパラメータを使用すると、誤った結果が生成されます。

のために$k = n$、 のような$n = 3, k = 3$、私たちは得ます$\binom{3}{0} / \binom{6}{3}$、これは、すべてのアメリカの石が接頭語を占める、まさに 1 つの有利な構成に対応します。
