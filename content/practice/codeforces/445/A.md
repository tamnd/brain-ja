 ## 解決策
 ## 問題の理解

 として表されるチェス盤が与えられています。`n`による`m`各セルが良好または不良であるグリッド。 正常なセルは「.」で示されます。 不良セルは「-」で表示されます。 すべての良いセルに、同じ色の 2 つのチェス駒が面を共有しないように、白 (「W」) または黒 (「B」) のチェス駒を配置する必要があります。 不良セルは空のままであり、隣接性チェックでは考慮されません。 タスクは、チェス駒の有効な配置を作成することです。 

入力サイズは控えめです: 両方とも`n`そして`m`n * m は 10,000 に達する可能性があり、二次因数や深い再帰を繰り返すアルゴリズムは非効率である可能性があるため、これにより、時間計算量が O(n * m) よりも悪い解は即座に除外されます。 メモリは、ボードの単純な 2D 配列表現にも十分です。 

正常なセルが完全に不良セルに囲まれている場合、微妙なエッジ ケースが発生します。 たとえば、入力が次の場合:```
3 3
---
-.-
---
```その場合、中央のセルは「W」または「B」のいずれかになります。 すべての近隣が良好であると仮定する単純な隣接関係ベースのアプローチでは、色が誤って配置される可能性があります。 もう 1 つのエッジケースはシングルセルボードです。`1 1`、どちらの色も有効です。 不注意なチェッカーは、近隣ノードの存在を必要とし、この最小限の入力で失敗する可能性があります。 

## アプローチ

 ブルートフォース手法では、良好な各セルに色を配置し、隣接性の制約を尊重しながら、考えられるすべての組み合わせを再帰的または反復的にチェックしようとします。 このアプローチは正しいですが、組み合わせ的に爆発的です。 のために`n * m`約半分が正常なセルを含むボードの場合、配置数はおよそ 2^(n*m/2) になります。 明らかに、これは、n = m = 10 の場合でも、実行可能な実行時間を超えており、上限の 100 では不可能です。 

重要な洞察は、チェス盤が 2 部構造であるということです。隣接する 2 つのセルが行と列の合計の同じパリティを共有しないように、チェッカー盤パターンでボードを色付けできます。 具体的には、位置 (i, j) のセルについて、(i + j) が偶数の場合は「B」を配置し、(i + j) が奇数の場合は「W」を配置します。 このパターンでは、隣接する良好なセルが反対の色を持つことが自動的に保証されます。 不良セルは無視されるため、「-」のままとなり、色付けには影響しません。 

これにより、問題はグリッド上での単純な反復、パリティの計算、セル タイプとパリティに基づいた適切な文字の割り当てに軽減されます。 再帰やバックトラックは必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n*m)) | O(n*m) | 遅すぎる |
 | 最適 | O(n*m) | O(n*m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 寸法を読む`n`そして`m`入力から、そして`n`ボードを表す文字列。 各文字列には長さがあります`m`。 
2. 空の出力ボードを文字列または文字のリストとして初期化します。 
3. 各行を反復処理します。`i`0からn-1まで。 各行に対して、各列を反復処理します。`j`0からm-1まで。 
4. (i, j) の各セルについて、不良セル (「-」) かどうかを確認します。 その場合は、それを出力に直接コピーします。 
5. セルが良好 (「.」) の場合は、合計を計算します。`i + j`。 もし`(i + j) % 2 == 0`、そのセルに「B」を配置します。 otherwise, place "W". どのパリティがどの色を取得するかの選択は任意です。 重要なのは全体的な一貫性です。 
6. 行内のすべての列を処理した後、その行を出力ボードに追加します。 
7. 出力ボードを行ごとに印刷します。 

機能する理由: 行 + 列のパリティにより、隣接する 2 つのセルが同じパリティを共有しないことが保証されます。 偶数和と奇数和に異なる色を割り当てるため、隣接する 2 つの良好なセルには自動的に反対の色が付きます。 不良セルは決して変更されないため、隣接ルールによって違反されることはありません。 これにより、どのボードでも有効なカラーリングが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
board = [input().strip() for _ in range(n)]
output = []

for i in range(n):
    row = []
    for j in range(m):
        if board[i][j] == '-':
            row.append('-')
        elif (i + j) % 2 == 0:
            row.append('B')
        else:
            row.append('W')
    output.append(''.join(row))

print('\n'.join(output))
```コードはアルゴリズムに直接に従います。 ボードを読むと使用されます`sys.stdin.readline`素早い入力のために。 各行は、効率を高めるために文字のリストを使用して段階的に構築され、文字列に結合されます。 パリティチェック`(i + j) % 2`一貫して色を割り当てます。 計算を超えて隣接セルが存在することを想定していないため、単一セルのボード、すべて不良の行、または不規則なパターンなどのエッジ条件が自然に処理されます。`(i + j)`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    board = [input().strip() for _ in range(n)]
    output = []
    for i in range(n):
        row = []
        for j in range(m):
            if board[i][j] == '-':
                row.append('-')
            elif (i + j) % 2 == 0:
                row.append('B')
            else:
                row.append('W')
        output.append(''.join(row))
    return '\n'.join(output)

# Provided samples
assert run("1 1\n.") == "B"
assert run("2 2\n..\n..") == "BW\nWB"

# Custom cases
assert run("3 3\n-..\n.-.\n..-") == "-BW\nW-B\nBW-", "mixed bad cells"
assert run("1 5\n.....") == "BWBWB", "single row"
assert run("5 1\n.\n.\n.\n.\n.") == "B\nW\nB\nW\nB", "single column"
assert run("2 3\n---\n...") == "---\nBWB", "top bad row"
assert run("3 3\n...\n...\n...") == "BWB\nWBW\nBWB", "full 3x3"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 3x3 の混合不良セル | -BW\nW-B\nBW- | 正常なセルと交互に配置された不良セルの正しい処理 |
 | 1x5 行 | BWBWB | 単一行の正しい色付け |
 | 5x1列 | B\nW\nB\nW\nB | 単一列の正しい色付け |
 | 2x3 の上部の悪い行 | ---\nBWB | 不正な行が確実に保存されるようにします。 
| 3x3 フル | BWB\nWBW\nBWB | 標準のチェッカーボードの色の正確さ |

 ## 特殊なケース

 シングルセルボード:```
1 1
.
```アルゴリズムは (0+0) % 2 = 0 を計算し、「B」を配置します。 隣接関係が存在しないため、色は有効です。 

不良セルに完全に囲まれたセル:```
3 3
---
-.-
---
```セル (1,1) のみが適切です。 (1+1)%2=2%2=0 なので「B」が配置されます。 隣接する良好なセルは存在しないため、隣接不変条件が自明に成り立ちます。 

不良セルの行または列全体:```
2 3
---
.W.
```不良セルは「-」のままで、良好なセルはパリティに基づいて割り当てられます。 (1+1)%2=0 であるため、アルゴリズムは (1,1) に「W」を配置し、パリティ ルールと一致します。 隣接する不良セルは干渉しません。
