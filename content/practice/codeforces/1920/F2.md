 ## 解決策
 ## 問題の理解

 いくつかのセルが島、いくつかのセルが外洋、いくつかのセルが水中火山である長方形のグリッドが与えられています。 トーマスは、島に足を踏み入れずに島を完全に取り囲むループを航行したいと考えています。 海洋または火山の開始セルごとに、最大の安全性を決定する必要があります。これは、任意のセルから最も近い火山までの往復におけるマンハッタンの最小距離として定義されます。 グリッドは、島がエッジから離れた単一の接続されたブロックを形成し、すべての海洋/火山セルが 1 つの接続されたコンポーネントを形成することを保証します。 

この制約では、最大 300,000 個のセルと 300,000 個のクエリが許可されるため、パスをシミュレートして各クエリを個別に処理するアルゴリズムは遅すぎます。 クエリごとの単純な BFS では、クエリごとに O(n*m) がかかり、最悪の場合、およそ 10^11 の操作が必要となり、これは容認できません。 課題は、すべての海洋/火山セルの安全性を効率的に事前計算し、O(1) 時間以内にクエリに答えることです。 

明らかではないエッジケースとしては、火山の隣から開始する場合、外海の隅から開始する場合、または島の周囲に狭い通路がある場合などが挙げられます。 不用意に実装すると、島を取り囲む単一のパスを想定し、複数の取り囲むルートが存在する場合に失敗したり、対角線に沿った距離とマンハッタンの距離の計算を誤ったりする可能性があります。 たとえば、火山が島の近くに孤立しているが、開始セルがさらに離れている場合、最大の安全性は、直線に沿った最も近い火山までのマンハッタンの直接距離ではなく、周囲を囲む経路上の最も近い点を反映する必要があります。 

## アプローチ

 強引なアプローチでは、各クエリ ポイントからの考えられるすべての往復を列挙し、各パスの火山までの最小距離を計算し、それらの中で最大値を取得します。 これは原理的には正しいですが、島の周囲に応じて周囲を囲むパスの数が指数関数的に増加するため、実行不可能になります。 3_10^5 セルと複数のクエリの場合、このアプローチは O(n_m*q) となり、失敗します。 

重要な洞察は、特定のセルからの最大の安全性は、島の周りを環状に形成することができながら、すべての火山から維持できる最大のマンハッタン距離に等しいということです。 これは幾何学的な問題として組み立てることができます。海洋/火山グリッドのみを考慮し、マルチソース BFS を使用して各セルの最も近い火山までの距離を計算します。その後、最大の安全性が島を完全に取り囲む経路を許可する最大値であることがわかります。 島はエッジから離れた単一の接続されたコンポーネントであるため、島の外側にある一連の海洋/火山セルが島の周囲に「フレーム」を形成します。 問題は、火山からすべての海洋セルまでの距離を伝播し、クエリごとにレポートすることに帰着します。 

BFS を使用してすべての火山セルからの距離を同時に計算し、海洋/火山セルごとに火山までのマンハッタンの最小距離を入力します。 次に、島の周囲のすべての海洋/火山セルに到達できるため、この距離がまさにそのセルから出発する往復の最大安全距離となります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n_m_q) | O(n*m) | 遅すぎる |
 | マルチソース BFS | O(n*m) | O(n*m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グリッドを文字の 2D 配列に解析します。 BFS のキュー内のすべての火山セルの位置を記録します。 
2. 2D 配列を初期化する`dist`グリッドと同じ寸法で、無限大で満たされます。 すべての火山セルについて`(r,c)`、 セット`dist[r][c]=0`そして追加します`(r,c)`BFS キューに追加します。 
3. すべての火山セルから BFS を同時に実行します。 デキューされた各セルについて、その 4 つの隣接セル (上、下、左、右) を調べます。 隣接するセルが海洋または火山セルであり、現在のパスの距離が以前に記録されたものよりも短い場合は、更新します。`dist[neighbor]=dist[current]+1`そしてそれをエンキューします。 
4. BFS が終了したら、`dist[r][c]`すべての海洋または火山セルについて、最も近い火山までのマンハッタンの距離が含まれています。 
5. 各クエリについて`(x,y)`、単純に出力します`dist[x-1][y-1]`。 これが機能するのは、島の周囲のすべての海洋/火山セルに到達できるため、事前に計算された距離が往復の最大の安全性と等しいためです。 

BFS によって維持される不変条件は、各セルの距離が火山までのマンハッタンの最小距離であるということです。 BFS は均一に拡張するため、一定の距離でセルに到達すると、より短いパスは存在しません。 これにより正確さが保証されます。 

## Python ソリューション```python
import sys
from collections import deque
input = sys.stdin.readline

n, m, q = map(int, input().split())
grid = [list(input().strip()) for _ in range(n)]
dist = [[-1]*m for _ in range(n)]
queue = deque()

for r in range(n):
    for c in range(m):
        if grid[r][c]=='v':
            dist[r][c]=0
            queue.append((r,c))

directions = [(0,1),(0,-1),(1,0),(-1,0)]

while queue:
    r, c = queue.popleft()
    for dr, dc in directions:
        nr, nc = r+dr, c+dc
        if 0<=nr<n and 0<=nc<m and grid[nr][nc] in {'.','v'} and dist[nr][nc]==-1:
            dist[nr][nc]=dist[r][c]+1
            queue.append((nr,nc))

for _ in range(q):
    x, y = map(int, input().split())
    print(dist[x-1][y-1])
```最初のセクションでは、グリッドを読み取り、BFS 初期化用の火山セルを特定します。 BFS は、距離が到達可能なすべての海洋/火山セルに伝播されることを保証します。 クエリは、次を使用して O(1) で応答されます。`dist`配列。 使用する`-1`未訪問のマーカーは、火山セルの有効な距離 0 との衝突を回避するためです。

 ## 特殊なケース

 開始セルが火山の場合、最大安全性はゼロです。 例えば、`(2,2)`火山のある 3x3 グリッド内`(2,2)`収量`0`。 セルがすべての火山から最大距離にある場合、BFS は正しい距離が計算されることを保証します。 BFS は到達可能なすべての海洋セルを通じて距離を伝播するため、狭い通路は正しく処理されます。 ループがコーナーを曲がる際に後戻りする必要がある場合でも、その距離はすでに最も近い火山までの最小値になっており、これは最大の安全性の定義に一致します。
