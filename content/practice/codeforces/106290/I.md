 ## 解決策
 ## 問題の理解

 各ノードが整数のラベルを持つルート付きツリーが与えられます。 すべてのノードについて、そのサブツリーに関心があります。これは、ノード自体と、ルート化されたツリー内のすべての子孫を意味します。 タスクは、各ノードについて、そのサブツリー内のラベルの中に現れない最小の非負の整数を計算することです。 

言い換えれば、ノードのサブツリーに存在するすべての値を調べ、それらをマルチセットとしてリストすると、そのマルチセットの mex、つまり欠落しているゼロから始まる最初の整数を見つけるように求められます。 

したがって、入力の構造は、エッジとノードに割り当てられた値の配列によって記述されるツリーになります。 出力はノードごとに 1 つの整数であり、そのサブツリー mex に対応します。 

この種の問題における主要な制約圧力は通常、ツリーのサイズによって決まります。 ノード数が約 200,000 に達すると、サブツリー情報を個別に再計算するソリューションは遅すぎます。 各ノードの直接再計算ではそのサブツリーがスキャンされますが、最悪の場合は線形となり、チェーン状のツリー全体で二次的な動作が発生します。 これはすでに限界を数桁超えています。 

2 番目の微妙な障害モードは、平均してサブツリー サイズが小さい場合でも mex を単純に再計算することで発生します。 Mex の計算では、ゼロから上に向かって値の存在を追跡する必要があり、グローバル構造なしでスキャンを繰り返すと、繰り返しの作業がひどく蓄積されてしまいます。 

単純なアプローチを破る典型的な例外ケースは、ルートにすべてのノードが子として含まれる星型ツリーです。 それぞれのリーフ サブツリーは些細なものですが、ルート サブツリーにはすべてが含まれています。 度数表を再構築してノードごとに個別に mex を再計算しようとすると、ルートのみで完全なスキャンが強制され、合計コストは 2 次になります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 各ノードについて、DFS を使用してそのサブツリーを走査し、すべての値をコンテナーに収集し、欠落している整数が見つかるまでゼロから始まる整数をチェックして mex を計算します。 これは、サブツリー セットの mex の定義に直接従うため、正しいです。 

問題は、各サブツリーの走査のコストがそのサイズに比例することです。 サブツリーが重なり合うツリー、特にチェーンでは、同じノードが何度も再訪されます。 長さ n のチェーンの場合、ルート サブツリーのコストは n、その子のコストは n マイナス 1 などとなり、およそ n の 2 乗演算が行われます。 さらに悪いことに、mex を毎回再計算すると、値の範囲にわたって余分なスキャンが追加されます。 

重要な点は、サブツリー クエリが独立していないということです。 それらは入れ子になっています。 この構造により、アクティブなトラバーサルに現在存在する値のグローバルな状態を維持しながら、ツリーを 1 回処理することができます。 現在のサブツリー内の値のセットを効率的に維持できれば、最初から再計算することなく動的に mex を計算できます。 

これはまさに、ツリー上の DSU または「小規模から大規模へ」テクニックが役立つ設定です。 サブツリーのサイズを計算し、ノードごとに、重い子のデータ構造をそのまま維持しながら、すべての軽い子を一時的に処理します。 この走査と並行して、現在含まれている値の頻度配列と、最小の欠損値を迅速に回答できるデータ構造を維持します。 その後、現在のアクティブ セットにノードを追加または削除するときに、mex を段階的に更新できます。 

値ドメイン上のセグメント ツリーは、mex を維持するためのクリーンな方法です。 各値は存在するか存在しないかのいずれかであり、頻度がゼロである最小インデックスを維持します。

 | ツリー + セグメント ツリー メックス上の DSU | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

ノード 1 でツリーをルート化し、サブツリーのサイズを計算します。 このステップは、最大のサブツリーを持つ子である重い子を識別するために必要です。 

次に、深さ優先トラバーサルを実行し、周波数配列と現在どの値が欠落しているかを追跡するセグメント ツリーで表されるグローバルな「現在アクティブなサブツリー状態」を維持します。 

1. まず DFS を実行してサブツリーのサイズを計算し、各ノードの重い子を特定します。 これにより、大きなサブツリーが再構築されるのではなく再利用されるようにトラバーサルを構造化できます。 
2. 現在の状態にノードを「追加」する関数を定義します。 ノードが追加されると、その値のカウントが増加します。 この値が存在しない状態から存在する状態に変化した場合、セグメント ツリーを更新して存在するとマークします。 mex は多重度ではなく存在のみに依存するため、このステップは不可欠です。 
3. 同様に、現在の状態からノードを「削除」する関数を定義します。 値のカウントが 0 に低下すると、セグメント ツリー内でその値が再び存在しないものとしてマークされます。 この可逆的なメカニズムにより、異なるブランチ間で同じ構造を再利用できます。 
4. DFS 中に、最初にすべてのライトの子を処理し、それぞれのサブツリーを完全に追加し、答えを再帰的に計算してから、それらを完全に削除します。 これにより、グローバル状態に留まることはなくなります。 
5. 次に、重い子を処理し、そのデータをグローバル状態に保持します。 重い子サブツリーは、繰り返しの再計算を避けるために保持されます。 
6. 子の処理後、現在のノード自体を追加し、残りのライト サブツリーをすべて現在の状態にマージします。 この時点で、グローバル状態は現在のノードのサブツリーを正確に表します。 
7. 現在存在しない最小のインデックスをセグメント ツリーに問い合わせます。 その値は現在のノードの mex です。 
8. 結果を保存して上に戻り、重いか軽いかに応じて必要に応じてサブツリーを削除します。 

正確さは、ノードの答えを計算した時点で、アクティブな構造のサブツリーに値のマルチセットが正確に含まれているという不変条件に依存します。 

## なぜ機能するのか

 すべてのノードで、アルゴリズムは、アクティブな周波数構造が DFS の接続された 1 つのサブツリー、具体的にはすべての子をマージした後のそのノードをルートとするサブツリーを正確に表すことを保証します。 軽い子は一時的に含まれてから削除されますが、重い子は再計算を避けるために残りますが、その寄与は走査全体にわたって一貫しています。 

すべての値は、そのノードが現在のサブツリー内にあるかどうかに基づいて正確に挿入および削除されるため、頻度配列は常に正しいメンバーシップを反映します。 セグメント ツリーは常に、頻度が 0 である最小のインデックスを維持します。これは、正確に現在のマルチセットに対する mex 定義です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

class SegTree:
    def __init__(self, n):
        self.n = n
        self.size = 1
        while self.size < n:
            self.size *= 2
        self.seg = [0] * (2 * self.size)
        for i in range(n):
            self.seg[self.size + i] = 1
        for i in range(self.size - 1, 0, -1):
            self.seg[i] = self.seg[2*i] + self.seg[2*i+1]

    def update(self, i, val):
        i += self.size
        self.seg[i] = val
        i //= 2
        while i:
            self.seg[i] = self.seg[2*i] + self.seg[2*i+1]
            i //= 2

    def mex(self):
        if self.seg[1] == self.n:
            return self.n
        i = 1
        while i < self.size:
            if self.seg[2*i] < (self.size >> (i.bit_length()-1)) if False else True:
                pass
            i *= 2
        # simpler correct walk
        i = 1
        l, r = 0, self.size
        while i < self.size:
            if self.seg[2*i] < (r - l) // 2:
                i = 2*i
                r = (l + r) // 2
            else:
                i = 2*i+1
                l = (l + r) // 2
        return l

n = int(input())
g = [[] for _ in range(n)]
for _ in range(n-1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

a = list(map(int, input().split()))
mx = n + 2

cnt = [0] * (mx + 5)
st = SegTree(mx)

sub = [1] * n
heavy = [-1] * n

def dfs_sz(u, p):
    sub[u] = 1
    maxsz = 0
    for v in g[u]:
        if v == p:
            continue
        dfs_sz(v, u)
        sub[u] += sub[v]
        if sub[v] > maxsz:
            maxsz = sub[v]
            heavy[u] = v

dfs_sz(0, -1)

ans = [0] * n

def add(u, p, val):
    x = a[u]
    if 0 <= x < mx:
        cnt[x] += val
        if cnt[x] == 1:
            st.update(x, 0)
        elif cnt[x] == 0:
            st.update(x, 1)
    for v in g[u]:
        if v == p:
            continue
        add(v, u, val)

def dfs(u, p, keep):
    for v in g[u]:
        if v == p or v == heavy[u]:
            continue
        dfs(v, u, False)

    if heavy[u] != -1:
        dfs(heavy[u], u, True)

    add(u, p, 1)

    for v in g[u]:
        if v == p or v == heavy[u]:
            continue
        add(v, u, 1)

    ans[u] = st.mex()

    if not keep:
        add(u, p, -1)

dfs(0, -1, True)

print(*ans)
```このソリューションは、相互作用する 2 つのコンポーネントに依存しています。 DFS 構造により、重い子の寄与は保持されながら、軽いサブツリーのみを最初から再計算することが保証されます。 セグメント ツリーは、現在のサブツリーにどの値が存在するかの動的表現を維持し、そのクエリ操作は対数時間で mex を返します。 

微妙な点の 1 つは、サブツリーの追加と削除の処理です。 の`add`関数は挿入と削除の両方に使用され、`val`パラメータ。 この対称性により、DSU-on-tree 技術が正しく機能することが可能になります。 

もう 1 つの重要な点は、カウントが 0 状態と 0 以外の状態の間で遷移するときに mex 構造体が即座に更新されるようにすることです。 これらの遷移を正しく同期できないと、プレゼンス情報が古くなり、mex 値が不正確になります。

 ## 特殊なケース

 単一ノード ツリーは、値が 1 つだけ存在する場合にアルゴリズムが mex を正しく初期化するかどうかをテストします。 アクティブな構造にはその値だけが含まれている必要があり、値がゼロでない場合、 mex はゼロになります。 

チェーン形状のツリーでは、サブツリーの再利用が頻繁に行われます。 各ステップで、アルゴリズムは構造の一部を正しく保存および破棄する必要があります。 そうしないと、再計算を繰り返すと時間がオーバーフローするか、不正確なオーバーラップが発生する可能性があります。 

星型ツリーは、多くの独立したサブツリーを 1 つのルート計算にマージすることで、すべての値が重複や欠落なく正しく蓄積されるかどうかをテストします。
