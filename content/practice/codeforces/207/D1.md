 ## 解決策
 ## 問題の理解

 この問題では、件名が 1、2、または 3 の 3 つのカテゴリのいずれかである文書が与えられます。各文書には、一意の識別子、タイトル、およびテキストの本文が含まれています。 また、各文書の主題がわかっている、ラベル付きのトレーニング用文書セットも提供されます。 このタスクは、新しい未見の文書の内容に基づいて、その正しい主題を予測することです。 出力は、予測された主題を示す 1 ～ 3 の単一の整数です。 

入力制約は、各ドキュメントが小さく、最大でも 10 キロバイトであることを示しています。 これにより、ドキュメント全体をメモリにロードし、テキストとして処理できるようになります。 トレーニング セット内の固有の単語の数は明示的に制限されていませんが、ドキュメント サイズによる実際的な制限により、標準的なテキスト処理アルゴリズムがメモリ制限内に快適に収まることがわかります。 2 秒という制限時間は、文書あたりの単語数を線形または線形に近いスケーリングにするアプローチが受け入れられることを示唆しています。 

トレーニング ドキュメントとの完全一致を単に検索する単純なアプローチは、ドキュメント ID が異なることが保証されており、テスト グループ 3 ～ 10 の多くのドキュメントがトレーニング セットに存在しないため、未確認のテスト ケースでは失敗します。 エッジ ケースには、主題間で共有されるあいまいな表現が含まれる文書や、有益であるように見えても内容が最小限のタイトルが付いた文書が含まれます。 たとえば、「Global Trade News」というタイトルの文書は主題 3 (貿易) に属する可能性がありますが、最初の数単語または識別子のみを考慮すると、単純な完全一致アプローチは失敗する可能性があります。 

この問題は本質的に、入力スペースが十分に小さいため、単純なバッグオブワード手法が効果的であるテキスト分類タスクです。 

## アプローチ

 ブルートフォースアプローチは、入力ドキュメントをトレーニングセット内のすべてのドキュメントと比較し、最も近い一致を選択することです。 距離は、正確なテキストの一致または編集距離によって計算できます。 これは、トレーニング セット内のドキュメントが正しくラベル付けされているため機能しますが、ドキュメントが最大 1000 個あり、各ドキュメントが最大 10 KB であるため、ペアごとの比較が高価になるため失敗します。 各トレーニング ドキュメントの文字列の類似性を計算すると、おおよその結果が得られます。$O(T \cdot L)$ドキュメントごとの操作。ここで、$T$はトレーニング ドキュメントの数であり、$L$平均的な単語数です。 これは非効率的であり、不必要です。 

重要な洞察は、文書が単語​​頻度ベクトルとして表現できるということです。 ある主題の文書に頻繁に出現する単語を特徴量として扱い、分類することができます。 各主題の文書内で各単語がどのくらいの頻度で出現するかを数えることができます。 新しい文書を分類するには、各主題の単語セットと重複する単語の数を数え、重複が最も多い主題を選択します。 これにより、問題が単純な検索とカウントのタスクに軽減され、コストのかかるペアごとの比較が回避されます。 

すべての被験者に均等に出現する単語は識別力を提供しないため無視し、単語を被験者にマッピングする辞書にトレーニング セットを前処理することで、さらに最適化できます。 これにより、ドキュメント サイズに線形にスケールする高速でメモリ効率の高いソリューションが得られますが、制約を考慮すると許容範囲内です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(T * L) | O(T * L) | 見たことのない文書を表示するには遅すぎる |
 | バグオブワードの頻度 | O(V + D) | O(V * 3) | 承認済み |

 ここ、$V$はトレーニングセット全体の一意の単語の総数であり、$D$新しい文書内の単語数です。 

## アルゴリズムのチュートリアル

 1. すべてのトレーニング ドキュメントをロードし、識別子とタイトルを取り除き、テキストを単語にトークン化します。 一貫性を確保するために単語を小文字に変換します。 各主題の頻度マップを保存し、その主題の文書内で各単語が何回出現するかを数えます。 
2. 各単語について、主題全体にわたる識別重みを計算します。 簡単な方法の 1 つは、各主題での出現を数え、複数の主題で同じように出現する単語を無視することです。 このステップにより、「the」や「and」などの一般的な単語によって予測が偏らないことが保証されます。 
3. 入力ドキュメントを読み取り、そのテキストからすべての単語を抽出し、正規化します。 各単語について、各主題の頻度マップでの出現を検索し、各主題のスコアを蓄積します。 
4. 最高得点の科目を選択します。 同点の場合は、最小の数値識別子を持つ主題を選択して、一貫してそれを破ります。 
5. 選択した件名を1～3の整数で出力します。 

それが機能する理由: 文書内の各単語は、1 つ以上の主題に対する証拠に貢献します。 寄与を合計することにより、最も高い集計証拠を持つ被験者が、トレーニング セットに基づいて最も可能性の高いカテゴリを反映します。 不変性とは、各単語の検索とスコアリングが独立しているため、単語が二重にカウントされたり見逃されたりすることがなく、最大限のサポートを持つ主題が正しく選択されることが保証されるということです。 

## Python ソリューション```python
import sys
import os
from collections import defaultdict, Counter

input = sys.stdin.readline

# Preprocess training set
train_dir = "train"  # path to unzipped train folder
subject_word_count = [Counter(), Counter(), Counter()]  # indices 0,1,2 for subjects 1,2,3

for subject in range(1, 4):
    path = os.path.join(train_dir, str(subject))
    for filename in os.listdir(path):
        filepath = os.path.join(path, filename)
        with open(filepath, encoding="utf-8") as f:
            f.readline()  # skip id
            f.readline()  # skip title
            for line in f:
                words = line.lower().split()
                subject_word_count[subject-1].update(words)

# Read input document
doc_id = input()
doc_title = input()
doc_words = []
for line in sys.stdin:
    doc_words.extend(line.lower().split())

# Score subjects
scores = [0,0,0]
for word in doc_words:
    for i in range(3):
        scores[i] += subject_word_count[i].get(word, 0)

# Output subject with maximum score
best_subject = scores.index(max(scores)) + 1
print(best_subject)
```コードはまず、トレーニング セットから主題ごとの単語頻度カウントを構築します。 新しいドキュメントを読むと、テキストがトークン化され、各主題の貢献が合計されます。 同点は次のように暗黙的に解決されます。`index(max(scores))`これにより、最初に出現した最大値が選択され、確定的な出力が保証されます。 すべての単語を小文字に変換すると、大文字の使用による不一致が回避されます。

## 特殊なケース

 空の文書は、どの主題についても証拠を提供しません。 アルゴリズムは引き続き主題 1 を選択します。`index(max(scores))`同点の場合、デフォルトは最初の最大値になります。 すべての主題に共通する単語のみを含む文書は、
