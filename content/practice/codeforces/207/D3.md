 ## 解決策
 ## 問題の理解

 この問題では、ドキュメントを 1、2、または 3 のラベルが付いた 3 つの主題のいずれかに分類するように求められます。各ドキュメントには、一意の識別子、タイトル、およびテキストの本文があります。 トレーニング データは主題ごとに多くの文書を提供します。課題は、テキストの内容に基づいて新しい文書の主題を決定することです。 識別子やタイトルには予測情報が含まれないため、使用する必要はありません。 分類はテキストの内容のみに依存する必要があります。 

この制約は、ドキュメントが比較的小さい (最大 10 キロバイト) ことを示しており、単純なテキスト処理または機械学習のアプローチが実現可能であると想定できます。 トレーニング セットは比較的大きいですが制限されているため、ドキュメント サイズが線形または線形に近い複雑さを持つアルゴリズムが許容されます。 主なエッジケースには、曖昧な表現、非常に短いテキスト、または主題間でほぼ同一のテキストを含む文書が含まれます。 たとえば、「レポート」という単語のみを含む文書は、どの主題にも属する可能性があります。 キーワード マッチングのような単純なアプローチは、重複を慎重に処理しない限り失敗する可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、問題をテキスト類似性検索として扱います。新しいドキュメントの場合、その内容をトレーニング セット内のすべてのドキュメントと比較し、類似性スコア (共有単語の数など) を計算し、最も類似したトレーニング ドキュメントの主題を割り当てます。 このアプローチは正しいですが、スケーリングが不十分です。 あれば$n$トレーニング文書と各文書には、$m$つまり、最悪の場合の複雑さは次のとおりです。$O(n \cdot m)$クエリごと。これは非常に小さなトレーニング セットの場合にのみ許容されます。 大規模なグループの場合、特に複数のテスト文書を分類する必要がある場合、このアプローチは時間がかかりすぎます。 

最適なアプローチは、文書の分類を頻度ベースのテキスト表現またはベクトル化されたテキスト表現に還元できるという観察に基づいています。 各文書を単語の集まりとして扱い、トレーニング セット全体で被験者ごとに各単語が出現する頻度を数え、新しい文書の場合は被験者ごとに各単語のスコアを合計します。 これにより、分類が単純な検索と加算の問題に変わります。各単語が対応する主題のスコアに寄与し、最高得点の主題が選択されます。 これは事実上、確率的正規化を行わないナイーブ ベイズ分類器です。 重要な洞察は、被験者全体の単語数により、テスト文書内の単語ごとに一定時間のスコアリングが可能であるため、全体の複雑さはトレーニング文書の数ではなく、文書のサイズと一意の単語の数に直線的に依存するということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n * m) | 大規模なトレーニング セットには遅すぎる |
 | 周波数ベースのルックアップ | O(L) | O(V) | 承認済み |

 ここ、$L$はテスト文書内の単語数であり、$V$トレーニングセットの語彙サイズです。 

## アルゴリズムのチュートリアル

 1. すべてのトレーニング ドキュメントを解析し、テキストを単語に分割します。 一貫性を保つために句読点を削除し、大文字と小文字を正規化します。 主題 1、2、および 3 について、各単語の頻度を個別にカウントします。これにより、単語をカウントにマッピングする 3 つの辞書が作成されます。 
2. テスト文書の場合、句読点や大文字小文字の違いを無視して、同じ方法でテキストを単語に分割します。 各被験者に 1 つずつ、合計 3 つのエントリを含むスコア配列を初期化します。 
3. テスト文書内の各単語について、その単語が主題固有の頻度辞書のいずれかに含まれているかどうかを確認します。 各主題におけるその単語の頻度を対応するスコアに加算します。 これにより、各主題を裏付ける証拠が効果的に合計されます。 
4. 3 つのスコアを比較します。 最も高いスコアを持つ主題がテスト文書の主題として予測されます。 同点の場合は、数字が小さいものを選択します。 
5. 予測した被写体を出力します。 

機能する理由: このアルゴリズムは、最も裏付けとなる証拠 (トレーニング セット内のその被験者に共通する単語) を持つ被験者が選択されることを保証します。 それぞれの単語は独立して寄与していますが、これは単語の数が多いことと、単語の使用パターンが被験者間で異なるという仮定によって正当化されます。 頻度カウントは特徴的なパターンを捕捉するため、最高のスコアは最も可能性の高い主題に対応します。 

## Python ソリューション```python
import sys
import re
from collections import defaultdict

input = sys.stdin.readline

# Preprocess: build frequency dictionaries for each subject from training data
# For simplicity, we simulate loading the training set
# In a real contest, one would read files from directories "1", "2", "3"

subject_word_count = [defaultdict(int) for _ in range(3)]

def preprocess_training(subject_docs):
    for subject, docs in enumerate(subject_docs):
        for text in docs:
            words = re.findall(r'\w+', text.lower())
            for word in words:
                subject_word_count[subject][word] += 1

# Example: placeholder for training data
training_docs = [
    ["this is document about finance trade"],    # subject 1
    ["this is document about sports"],           # subject 2
    ["this is document about trade"],            # subject 3
]

preprocess_training(training_docs)

# Read test document
doc_id = input()
title = input()
text_lines = sys.stdin.read().splitlines()
words = []
for line in text_lines:
    words.extend(re.findall(r'\w+', line.lower()))

scores = [0, 0, 0]
for word in words:
    for subj in range(3):
        scores[subj] += subject_word_count[subj].get(word, 0)

predicted_subject = scores.index(max(scores)) + 1
print(predicted_subject)
```コードはまず、主題ごとに頻度マップを構築します。 次に、テスト文書を読み取り、テキストを正規化し、被験者ごとの証拠をカウントします。 単語の出現頻度を単純に加算することで、各主題の際立った特徴が得られます。 の`max`関数は、信号が最も強い被験者を見つけ、1 を加算すると、ゼロから始まるインデックスが被験者番号に変換されます。
