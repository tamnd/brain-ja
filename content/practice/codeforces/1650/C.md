 ## 問題の理解

 私たちは数直線上に点を与えられます。 すべての点には座標と重みがあります。 きっちり選びたい$2n$これらのポイントをエンドポイントとして使用します。$n$セグメント。 

セグメントは完全にネストされた構造を形成する必要があります。 セグメントを最も外側から最も内側に並べ替える場合、すべてのセグメントは厳密に前のセグメントの内側に存在する必要があります。 幾何学的には、セグメントは数直線上の一連の一致する括弧のように見えます。 

目的はセグメントの長さを最小限に抑えることではありません。 重要なのは、構築で使用されるすべてのエンドポイントの重みの合計だけです。 

入力により提供されるのは、$m$候補点。 各ポイントは一意の座標とオリジナルのインデックスを持ちます。 出力には、可能な最小の総重量と有効なコレクションが含まれている必要があります。$n$ネストされたセグメントがその重みを達成します。 

この制約は、点のすべてのサブセットを検査できないことを直ちに示唆しています。 1 つのテスト ケースには最大で次のものを含めることができます。$2 \cdot 10^5$ポイント、すべてのテスト ケースの合計ポイント数も$2 \cdot 10^5$。 おおよそよりも悪いアルゴリズム$O(m \log m)$テスト ケースごとに制限時間内に収まりそうにありません。 二次方程式のアプローチは完全に除外されます。$m^2$到達できる$4 \cdot 10^{10}$。 

この問題の微妙な側面は、ネスト条件が制限的であるように聞こえるが、一度正しくなると、$2n$ポイントが選択されると、ネストされたセグメントの構築が簡単になります。

### なぜ効果があるのか

 証明は 2 つの独立した事実で構成されます。 

まず、すべてのソリューションでは正確に使用されます。$2n$エンドポイント。 目的はエンドポイントの重みの合計であるため、可能な最小の合計重みは、$2n$利用可能なすべてのポイントの中で最小の重み。 それ以外の選択をすると、選択した 1 つのポイントがより重いポイントに置き換えられ、合計を改善することはできません。 

次に、いずれかを選択した後、$2n$点を座標で並べ替え、対称位置をペアにすると、ネストされたセグメントが生成されます。 ソートされたポイントが$$p_1,p_2,\dots,p_{2n},$$そうすると、ペアは$$(p_1,p_{2n}), (p_2,p_{2n-1}), \dots$$連続するセグメントのペアごとに、$$p_i < p_{i+1} < p_{2n-i} < p_{2n-i+1},$$これはまさに入れ子状態です。 

可能な最小限のエンドポイントの重みを達成し、常に有効なネストされたシステムを構築するため、アルゴリズムは最適化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        input()  # consume blank line

        n, m = map(int, input().split())

        points = []
        for idx in range(1, m + 1):
            x, w = map(int, input().split())
            points.append((w, x, idx))

        points.sort()  # sort by weight

        chosen = points[:2 * n]
        total_weight = sum(w for w, _, _ in chosen)

        chosen.sort(key=lambda p: p[1])  # sort by coordinate

        pairs = []
        l = 0
        r = 2 * n - 1

        while l < r:
            pairs.append((chosen[l][2], chosen[r][2]))
            l += 1
            r -= 1

        out.append(str(total_weight))
        for a, b in pairs:
            out.append(f"{a} {b}")
        out.append("")

    sys.stdout.write("\n".join(out))

solve()
```最初の並べ替えでは、世界で最も安いものを見つけます$2n$エンドポイント。 これが最適化ステップです。 

2 番目の並べ替えでは重みを無視し、選択した点を座標によって配置します。 点の座標順序が整うと、対称ペアリングによって自動的にネストが作成されます。 

出力には座標ではなく入力からのポイント番号が必要であるため、元のインデックスを保存する必要があります。 

すべてのテスト ケースの前にある空白行は、誤って処理されやすいです。 公式入力には常にこれが含まれるため、各テスト ケースを処理する前に 1 行を読み取って破棄するだけで十分です。 

Python の整数は、可能な最大の大きさが Python の整数の制限をはるかに下回っているため、重みの合計を簡単に処理できます。
