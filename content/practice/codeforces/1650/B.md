 ## 解決策
 ## 問題の理解

 次のように定義された関数を最大化するように求められます。$f_a(x) = \lfloor x / a \rfloor + (x \bmod a)$からの整数の範囲にわたって$l$に$r$、 どこ$a$固定の正の整数です。 言い換えれば、連続する整数の特定のセグメントに対して、数値を選択する必要があります。$x$による整数除算の最大和を生成するもの$a$とその剰余モジュロ$a$。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはセグメントを提供します$[l, r]$そして約数$a$。 各ケースの出力は次の最大値です。$f_a(x)$そのセグメントで。 

制約は厳しいです:$l$そして$r$まで可能です$10^9$、最大で$10^4$テストケース。 計算する単純なソリューション$f_a(x)$あらゆる人にとって$x$間$l$そして$r$必要になる可能性があります$10^9$単一のテスト ケースで操作を行うことは不可能ですが、これは不可能です。 

微妙なエッジケースが現れるのは、$r$の倍数に非常に近い$a$またはいつ$a$に比べて非常に大きい$r-l$。 たとえば、次の場合$l=1$、$r=4$、 そして$a=3$、最大値はありません$r$しかし、で$x=2$。 セグメントのエンドポイントのみをチェックする不注意なアプローチでは、間違った答えが得られる可能性があります。 

## アプローチ

 ブルートフォースメソッドは次のように計算します。$f_a(x)$すべての整数に対して$x$から$l$に$r$、次に最大値を選択します。 これが機能する理由は、$f_a(x)$は単純な算術関数です。 その時間計算量は$O(r-l+1)$テストケースごとに。 とすれば$r-l$到達できる$10^9$、このアプローチは遅すぎます。 

重要な観察は次のとおりです$f_a(x)$として増加します$x \bmod a$増加しますが、次の場合には急激に減少します。$x$の倍数です$a$。 具体的には、固定の場合$a$、関数は区分線形です。$f_a(x) = \lfloor x / a \rfloor + (x \bmod a) = k + r$どこ$x = k \cdot a + r$と$0 \le r < a$。 各ブロック内では、$a$連続した整数の場合、最大値は次の場合に発生します。$r = a-1$、つまり、次の倍数の直前$a$。 したがって、確認するだけで十分です$x=r$そして$x=r - (r \bmod a) - 1$(最大数$[l, r]$の倍数の直前に$a$）。 

この観察により、問題はテスト ケースごとに最大 2 つの候補をチェックすることになり、次のようになります。$O(1)$テストケースあたりの時間。

 | ブルートフォース | O(r-l+1) | お(1) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$l$、$r$、 そして$a$。 
3. コンピューティング$f_a(r)$最大値が正しいエンドポイントで発生する可能性があるためです。 
4. コンピューティング$x = r - (r \bmod a) - 1$、以下の最大の整数です。$r$の倍数の直前に終了する$a$。 
5. もし$x \ge l$、計算する$f_a(x)$; それ以外の場合は、この候補を無視してください。 
6. 間の最大値を出力します。$f_a(r)$そして$f_a(x)$このテストケースの答えとして。 

正しさは次の性質から来ます。$f_a(x)$サイズのブロック内で直線的に増加します$a$の倍数に達するとドロップします$a$。 したがって、関数は次のいずれかの時点でのみ最大値を達成できます。$r$または次の倍数の直前に$a$セグメント内で。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def f(a, x):
    return x // a + x % a

t = int(input())
for _ in range(t):
    l, r, a = map(int, input().split())
    # candidate 1: at the right endpoint
    ans = f(a, r)
    # candidate 2: just before the previous multiple of a
    x = r - (r % a) - 1
    if x >= l:
        ans = max(ans, f(a, x))
    print(ans)
```機能`f(a, x)`問題の算術を分離します。 候補者`x = r - (r % a) - 1`サイズの最後のブロックのピークを確実にキャプチャします`a`セグメント内。 小切手`x >= l`セグメント外の数値の使用を避けます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        l, r, a = map(int, input().split())
        def f(x): return x // a + x % a
        ans = f(r)
        x = r - (r % a) - 1
        if x >= l:
            ans = max(ans, f(x))
        output.append(str(ans))
    return "\n".join(output)

 ## 特殊なケース

 セグメントに要素が 1 つだけ含まれている場合、`l=r`、両方の候補が同じ値に崩壊します。 例えば、`l=r=1, a=1`。 アルゴリズムは計算します`f(1)=1`、そして第二候補`x=0`破棄される理由は`x < l`。 出力は正しいです。 

いつ`r`の倍数です`a`、最大値は多くの場合次の時点で発生します。`r-1`。 のために`l=1, r=8, a=4`、での関数値`r=8`2ですが、`r-1=7`4. 私たちの公式を与えます`x = r - (r % a) - 1`これを正確に処理します。 小切手`x >= l`セグメントのアンダーフローを防止します
