 ## 解決策
 ## 問題の理解

 奇数の長さの文字列とターゲット文字が与えられます。 隣接する 2 文字を一度に削除することで、文字列を繰り返し短縮できます。 問題は、ターゲット文字だけが残るように一連のこのような削除を実行できるかどうかです。 

文字列の長さは最大 49 で、最大 1000 のテスト ケースを含めることができます。 この操作では一度に 2 文字が削除されるため、最終的な文字列は常に奇数の長さになるため、原則として 1 文字で終わることが確実に実行可能です。 課題は、ターゲット キャラクターがすべての削除後に確実に存続するようにすることです。 

重要な点は、偶数インデックスの文字 (1 から始まるインデックスを考慮) と奇数インデックスの文字の動作が異なることです。 隣接する 2 つの文字を 1 回削除すると、残りの文字のパリティがシフトします。 これは、削除の実行方法に応じて、文字が元々左から偶数の位置にある場合、または左から奇数の位置にある場合にのみ生き残ることができることを意味します。 キャラクターがどこかに存在するかどうかを単純にチェックする単純な実装は、すべての位置でキャラクターが最後の位置に到達できるわけではないため、失敗します。 

エッジ ケースには、長さが 1 の文字列 (その文字がターゲットと等しい場合にのみ答えが YES となる)、およびターゲットがその文字と一致する必要があるすべての同一の文字を含む文字列が含まれます。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての削除シーケンスをシミュレートします。 各ステップで、隣接する文字の考えられるすべてのペアを削除し、文字列の長さが 1 になるまで結果の文字列を再帰的に処理します。 これは正しいですが、現実的ではありません。 最悪の場合、$n = 49$、シーケンスの数が指数関数的に増加するため、複数のテスト ケースでは実行できなくなります。 

重要な観察は、ポジションの同等性のみが重要であるということです。 隣接する 2 つの文字を繰り返し削除した後、最後に残った文字は、削除順序に応じて、左から奇数のインデックス (1、3、5、…) または偶数のインデックスで始まる必要があります。 したがって、文字列を反復処理して、位置 0、2、4、… (0 ベース) および 1、3、5、… (0 ベース) でターゲット文字をチェックできます。 これらの位置のいずれかに存在する場合、適切な欠失順序の下で最後まで存続することが保証されます。 これにより、テスト ケースごとに問題が指数関数的な問題から線形問題に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) 再帰 | 遅すぎる |
 | パリティチェック | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. テスト ケースごとに、文字列を読み取ります。$s$そして対象キャラ$c$。 
3. 偶数のインデックス (0、2、4、…) で文字列を反復処理し、次のことを確認します。$s[i] = c$。 見つかった場合は、YES を出力し、次のテスト ケースに進みます。 
4. 見つからない場合は、奇数のインデックス (1、3、5、…) で文字列を反復処理し、$c$。 見つかった場合は、YES と出力します。 
5. キャラクタが存続できる位置に出現しない場合は、NO を出力します。 

機能する理由: 削除により隣接する 2 つの文字が削除されるため、インデックスのパリティが一貫して変化します。 文字は、必要な削除のパリティと一致する位置から開始する場合にのみ、最後に残った位置まで生き残ることができます。 各パリティを個別にチェックすることで、ターゲット キャラクターが生き残れる位置にいることを保証します。 この不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        c = input().strip()
        n = len(s)
        found = False
        # Check even indices first (0-based)
        for i in range(0, n, 2):
            if s[i] == c:
                found = True
                break
        if not found:
            # Check odd indices (0-based)
            for i in range(1, n, 2):
                if s[i] == c:
                    found = True
                    break
        print("YES" if found else "NO")

if __name__ == "__main__":
    solve()
```このソリューションは、高速 I/O を使用して入力を効率的に読み取ります。 各パリティを個別にチェックし、生き残った文字が最後に残ったインデックスに配置できることを確認します。 2 のステップで反復することは、off-by-one エラーを回避するために重要です。

 ## 特殊なケース

 長さが 1 の文字列の場合、アルゴリズムは 1 文字をチェックします。 ターゲットと一致する場合は、YES が出力されます。 それ以外の場合は「いいえ」です。 ターゲットが偶数インデックスと奇数インデックスの両方に現れる文字列の場合、どちらかのパリティで最初に出現するもので十分です。 このアプローチは、繰り返し文字を含む文字列や、削除しても存続できない位置にのみターゲットが存在する文字列を正しく処理します。 

例えば、`"x"`ターゲット付き`"y"`すぐに NO が出力されます。 で`"aaa"`ターゲット付き`"a"`、 最初`"a"`インデックス 0 が見つかり、YES が出力されます。 このアルゴリズムは、特殊な場合の分岐を行わずに、そのようなすべてのシナリオに自然に適応します。
