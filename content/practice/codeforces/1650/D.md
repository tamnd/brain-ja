 ## 解決策
 ## 問題の理解

 からの数値の順列が与えられます。$1$に$n$、最初は昇順です。 ペティアが演奏しました$n$それを変えるための操作。 で$i$- 回目の操作で、彼は最初の操作を循環的にシフトしました$i$要素を右側に何度でも追加できます。 すべての操作の後、最終的な配列が与えられるので、各ステップで実行されたシフトの数を再構築するか、それが不可能であると判断する必要があります。 

入力は複数のテスト ケースを提供します。 各テスト ケースが提供するのは、$n$そして最後の順列$a$。 出力は次のいずれかのリストです。$n$負でない整数$d_1, d_2, \dots, d_n$、各演算における右巡回シフトの数を表します。順列を取得できない場合は -1 を表します。 

制約は控えめです。$n$最大 2000 まで可能で、すべての合計$n$すべてのテスト ケースの数も ≤ 2000 です。これは、各テスト ケースを大まかに処理するアルゴリズムを用意できることを意味します。$O(n^2)$制限時間に達することなく時間を過ごすことができます。 メモリ制限は十分にあるため、補助配列を安全に保存できます。 

微妙なエッジ ケースは、シフトの最小数が明らかでないように、数値の順序が狂っている場合です。 たとえば、最後の配列が最大の要素で始まる場合、最初のいくつかの操作には最大の回転が含まれている必要があります。そうしないと、左から右への単純な再構成が失敗する可能性があります。 

## アプローチ

 ブルートフォース手法では、各操作で考えられるすべてのシフトの組み合わせをシミュレートします。 それぞれについて$i$、0から試してみることができます$i-1$配列を前方にシフトして伝播します。 これは原理的には機能しますが、最悪の場合は複雑になります$O(n!)$、これは非現実的です$n=2000$。 

重要な洞察は、プロセスを逆にすることです。 最終配列を前方に構築しようとする代わりに、最終配列から開始して操作を「元に戻す」ことができます。 最後の操作を考えてみましょう。それは最初の操作にのみ影響します。$n$要素（すべて）。 どこをチェックすることで、適用されたシフトの数を知ることができます。$n$終わった。 決定したら$d_n$、その操作を逆にして、次のことに進みます。$i=n-1$など、最初の操作に到達するまで続きます。 それぞれのステップは、$O(1)$オペレーションごとに全体的な再構築を行う$O(n)$テストケースごとに。 この方法では、各ステップで剰余を剰余として取得するため、最小限のシフトが保証されます。$i$。

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化する`res`各操作のシフト数を保存します。 最終配列から開始します`a`。 
2. 反復する`i`から$n$まで$1$。 各操作について、最初の操作のみを考慮します。`i`の要素`a`。 
3. のインデックスを見つけます。`i`最初に`i`要素。 この指標は、どれくらいの距離にあるのかを示します。`i`理想的な位置 (最初の位置の最後の位置) からずれています。`i`要素）。 
4. コンピューティング`d_i = index`数え方が右からずれる場合。 シフトはモジュロでラップアラウンドするため`i`、私たちは取る`d_i = index % i`。 
5. 逆シフトを適用します。最初のシフトを移動します。`i`が残した要素`d_i`操作を元に戻す位置。 これにより、次の反復のために配列が調整されます。 
6. 先頭に追加`d_i`結果リストに。 まで繰り返します`i=1`。 
7. 結果として得られるシフトのリストを出力します。 

**これが機能する理由:** 各ステップでシフトできる最大の数値は次のとおりです。`i`。 最大値から開始してシフトを元に戻すことにより、すでに処理されたより小さい数値の相対位置が保存されます。 モジュロにより、常に最小限のシフト数が選択されるようになります。 この不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        res = []
        for i in range(n, 0, -1):
            idx = a.index(i)
            d = idx % i
            res.append(d)
            # reverse the effect of this operation
            a = a[d:i] + a[:d] + a[i:]
        print(*res[::-1])

solve()
```テスト ケースの数を読み取り、ケースごとに次の値を読み取ります。`n`そして最後の並べ替え。 から反復します`n`まで`1`、現在の値のインデックスを見つけ、最小のシフトを計算し、操作を元に戻し、結果の先頭に追加します。 最後に、操作の順序に合わせて結果リストを反転します。

 ## 特殊なケース

 単一要素の最初の操作の場合、シフトは常に 0 です。 次のような完全に反転した配列の場合`[3,2,1]`、アルゴリズムは最小のシフトを正確に識別します。`[0,1,2]`最大から最小の順に処理します。 最大の要素が最後にない配列では、逆再構築により、要素を元の位置に戻すために必要な最小限の回転が常に決定されます。
