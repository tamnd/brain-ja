 ## 解決策
 ## 問題の理解

 ドミトリーには一連の試験日が与えられており、毎日 1 日から 1 日までの番号が付けられています。$d$。 彼は各試験の数日前に休むことができ、スケジュールの質を測る重要な尺度は次のとおりです。$\mu$、連続する試験の間（またはセッションの開始と最初の試験の間）の最小限の休憩。 この問題は最大化することを求めています$\mu$最大 1 つの試験を新しい日に移動し、2 つの試験が同じ日に行われないようにします。 

制約は重要です。$n$最大 200,000 まで可能で、$d$まで$10^9$したがって、試験の場所を変更するために、可能性のあるすべての日を繰り返すのは遅すぎます。 回避するアプローチが必要です$O(n \cdot d)$基本的に動作と動作$O(n)$テストケースごとに。 最大 10,000 のテスト ケースがあるため、累積的な複雑さは維持される必要があります$2 \cdot 10^5$全体の実行ごとの操作は 2 秒未満で快適にフィットします。 

エッジケースは微妙な場合があります。 セッションの長さの場合、$d$などの最小限のものです$n = d = 2$調整の余地がないので、$\mu = 0$。 長いセッションの開始時にすべての試験がぎっしり詰まっている場合、最初または最後の試験をもう一方の端に移動すると、大幅に時間がかかる可能性があります。$\mu$。 不用意に実装すると、中間試験のみを移動しようとしたり、試験をセッションの最初または最後に移動することを検討しなかったりする可能性があります。 

## アプローチ

 強引なアプローチでは、各試験を他の試験と競合しない可能な限りすべての日に移動してから計算することになります。$\mu$結果として得られるスケジュールごとに。 正しいとはいえ、このアプローチは扱いにくいものです。$n \le 2 \cdot 10^5$そして$d \le 10^9$。 操作数が次を超える可能性があります$10^{14}$最悪の場合。 

重要な洞察は、スケジュールはすでに整理されており、試験間のギャップによって決定されるということです。$\mu$。 単一の検査を最適に移動しても、意味のある増加のみが可能です$\mu$最大ギャップを拡大することによって。 具体的には、最初の試験を最大ギャップの中央に近づけるか、最後の試験をセッションの遠端に移動するだけで十分です。 他の動きは減少します。$\mu$もしくは改善しない。 

正式には、最適な新しい$\mu$は次の候補の最大値です: 現在の$\mu$試験を移動せずに、連続する 2 つの試験の間の最大の差の半分 (切り捨て)、1 日目と 2 回目の試験の間の差から 1 を引いた値、または最後から 2 番目の試験と当日の間の差$d$マイナス 1。最初と最後の試験、または最大間隔の中間のみが問題となります。 短い間隔内で試験を移動しても、最小限の休憩を改善することはできません。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n*d) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n, d$試験日のソートされたリスト$a$。 
2. 現在の休憩間隔を計算します。 させて$rest_0 = a_0 - 1$最初の試験と毎回の試験で$i$1から$n-1$、 させて$rest_i = a_i - a_{i-1} - 1$。 初期の$\mu$すべての休憩間隔の中で最小です。 
3. 連続する試験間の最大間隔を特定します。$max\_gap = \max(a_i - a_{i-1} - 1)$。 半分を切り捨てて計算し、$(max\_gap - 1) // 2$、新規候補として$\mu$。 
4. 最初の検査を最初の検査後の最大間隔の中央に近づけることを検討します。 候補者$\mu$は$(a_1 - 2) // 2$最初の試験を 1 日目または 2 日目に移動すると、明確な日が保持されるためです。 
5. 最後の試験をセッションの終わりに近づけることを検討してください。 候補者$\mu$は$(d - a_{n-2} - 1)$、最後から 2 番目の試験後のギャップ。 
6. 可能な限りの最大限の$\mu$オリジナルの中で一番大きいです$\mu$、最大ギャップの半分、および最初と最後の試験が候補者を移動します。 
7. この最大値を出力します$\mu$テストケース用。 

なぜ効果があるのか​​: 最小限の休息$\mu$スケジュール内の最小ギャップによって決定されます。 中間試験を移動すると、ギャップが局所的に移動するだけですが、エンドポイント試験を移動すると、日数を効果的に再配分してギャップのバランスをとることにより、最小のギャップを拡大できます。 このアルゴリズムは、すべての潜在的な位置を列挙することなく、これらの可能性を効率的に捕捉します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_mu(n, d, a):
    rest_intervals = [a[0] - 1] + [a[i] - a[i-1] - 1 for i in range(1, n)]
    mu_orig = min(rest_intervals)

    # gap candidates
    max_gap = max(a[i] - a[i-1] - 1 for i in range(1, n))
    half_max_gap = (max_gap - 1) // 2 if max_gap > 0 else 0

    # moving first exam
    move_first = (a[1] - 2) // 2 if n > 1 else 0

    # moving last exam
    move_last = d - a[-2] - 1 if n > 1 else d - 1

    return max(mu_orig, half_max_gap, move_first, move_last)

t = int(input())
for _ in range(t):
    input()  # skip empty line
    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    print(max_mu(n, d, a))
```このソリューションでは、まず休憩間隔を計算して、現在の最小休憩を見つけます。 次に、連続する試験間の最大ギャップを見つけて、その半分を候補として計算します。 最初と最後の試験を極端な位置に移動することを評価します。 の`max`これら 4 つの値のうち、増加する可能性のあるすべての意味のある動きが返されます。$\mu$。 

ハーフギャップと休憩間隔を計算する際に、1 つずつずれたエラーを避けるために注意が必要です。 1 を引くと、試験そのものが行われる日が計算されます。 整数除算による丸めにより、有効な整数の日数のみが考慮されるようになります。
