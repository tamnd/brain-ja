 ## 解決策
 ## 問題の理解

 間隔の集合が与えられます。各間隔は 2 つの整数で定義される数直線上のセグメントです。$x_i \le y_i$。 これらの間隔から、各間隔がノードであり、間隔が特定の交互の方法で「交差」する場合に 2 つのノードが接続される無向グラフを構築します。 具体的には、間隔$i$インターバルに接続します$j$ちょうど、一方の間隔が他方より先に始まり、その間隔内で終了し、もう一方の間隔がそれを超えて拡張され、次のようなパターンが形成されるときです。$x_i < x_j < y_i < y_j$または対称の場合。 

タスクは、隣接するノードが常に異なる色になるように、このグラフを 2 色で着色できるかどうかを判断することです。これは、グラフに奇数サイクルが含まれていないかどうかを確認するのと同じです。 

制約は非常に大きいです。 すべてのテスト ケースにわたる間隔の数は 50 万に達する可能性があり、エンドポイントは最大 50 万に達します。$10^{18}$。 これにより、明示的にエッジを構築したり、間隔のすべてのペアを比較したりするアプローチは即座に除外されます。 単純な構造は次のことを意味します$O(n^2)$これは、最適化された C++ や PyPy であっても、実現可能な限界をはるかに超えています。 

あまり目立たない問題は、間隔が重複またはネストされていることに起因します。 たとえば、次のような間隔$(1, 10), (2, 3), (4, 5)$交差点に関する素朴な幾何学的直観が誤解を招く可能性がある構造を形成します。 もう 1 つの微妙なケースは、複数の間隔がエンドポイントを共有している場合や深くネストされている場合で、慎重に処理しない限り順序付けだけでは十分ではありません。 

重要な課題は、グラフが幾何学的相互作用によって暗黙的に定義されており、グラフを明示的に構築せずに二部性について推論する必要があることです。 

## アプローチ

 定義から始めると、最も単純なアイデアは、間隔のすべてのペアを比較し、必要なパターンで交差するたびにエッジを追加することです。 グラフが構築されたら、BFS または DFS を実行してグラフを 2 色にすることができます。 これは正しいです。なぜなら、二部性はまさに明示的な隣接性に関する色付けの問題だからです。 

問題は規模だ。 まで$5 \cdot 10^5$間隔、すべてのペアをチェックするとおおよその結果が得られます$O(n^2)$比較すると、約$10^{11}$最悪の場合の運用。 エッジ構築のオーバーヘッドを無視しても、これはリモートでは使用できません。 

重要な構造的観察は、次のような状態であるということです。$x_i < x_j < y_i < y_j$は、任意のジオメトリではなく、基本的にエンドポイントの順序付けに関する交差パターンを説明しています。 左側のエンドポイントで間隔を並べ替えると、すべての間隔が「タイム スパン」になり、エンドポイントがどのようにインターリーブするかによって競合が決定されます。 

重要な変換は、各インターバルを開始イベントとして解釈することです。$x_i$そしてクロージングイベント$y_i$。 左から右にスイープする場合、アクティブな間隔は、右のエンドポイント順に並べられたセットを形成します。 交差条件は、アクティブな存続期間が特定のネストされた順序で重複する間隔間の関係に変換されます。 この構造は、区間競合グラフのように動作するグラフを生成することが知られており、エッジはアクティブな区間間の右端点の順序の反転に対応します。 

このように理解すると、問題は、動的に維持される構造において、誘導された制約グラフが奇数サイクルを強制するかどうかを検出することに帰着します。 これをモデル化する標準的な方法は、アクティブな間隔を正しいエンドポイントの順序で維持し、パリティとの素セット結合 (重み付き DSU とも呼ばれる) を介してパリティの競合を検出することです。この場合、各制約では、スイープ中に交差関係が検出されるたびに、2 つの間隔が反対の色を持つ必要があることが強制されます。 

スイープにより、「中間」間隔の 2 番目のエンドポイントが処理されるときに、すべてのインタラクションが 1 回だけ検出されることが保証されます。

 ## アルゴリズムのチュートリアル

 各間隔を 2 つのイベントとしてモデル化し、座標の昇順で処理します。 

1. 各区間を変換する$(x_i, y_i)$の開始イベントに$x_i$そして終了イベント$y_i$。 また、すべてのイベントを座標で並べ替え、終了前に開始が処理されるようにすることで関係を解消します。 これにより、インターバルをアクティブ化したときに、将来対話できるすべてのインターバルがまだ開いていることが保証されます。 
2. 現在開いている間隔のアクティブな構造を、右のエンドポイント順に並べて維持します。 新しい間隔が終了したときにどのアクティブな間隔が「交差」するかをクエリできる構造だけが必要なので、それらをその間隔でソートしておきます。$y$-価値観。 
3. インターバルの開始イベントを処理する場合$i$、それをアクティブ セットに挿入します。 現時点では、制約の相互作用が完全に決定されていないため、制約はまだ適用されていません。 
4. インターバル終了イベントを処理する場合$i$、すべての間隔を調べます$j$現時点でもまだ活動しているもの。 このような間隔ごとに、エンドポイントが包含または分離ではなく交差パターンを形成しているかどうかを判断します。 それらが交差する場合、私たちはそれを強制します$i$そして$j$反対の色でなければなりません。 

これで十分な理由は、相互作用の両方のエンドポイントが完全にわかっている場合、より早い終了間隔が終了する瞬間に、すべての交差ペアが一意に識別できるためです。 
5. パリティ ビットで強化された素セットの共用体構造を維持します。 各ノードは、その親と相対的に同じ色を持つか反対の色を持つかを格納します。 2 つの区間を結合すると、「異なっていなければならない」に対応するパリティ制約も強制されます。 
6. どこかの時点で、既に同じセットに属している 2 つの区間を結合しようとしたが、パリティ制約が以前の割り当てと矛盾した場合、グラフは 2 部ではないと即座に結論付けられます。 

### なぜ効果があるのか

 スイープにより、交差によって暗示されるすべてのエッジが、先に終了する間隔の 2 番目のエンドポイントが処理される瞬間に 1 回だけ検出されることが保証されます。 その瞬間、両方の間隔が完全にアクティブになるため、それらの関係は永久に固定されます。 パリティを備えた DSU は、接続された制約に対して一貫した色の割り当てを維持し、矛盾は暗黙的なグラフの奇数サイクルに正確に対応します。 すべてのエッジ制約は「異なっていなければならない」関係としてエンコードされるため、DSU の一貫性条件はグラフ全体の二部性と同等になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.parity = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            p = self.parent[x]
            self.parent[x] = self.find(p)
            self.parity[x] ^= self.parity[p]
        return self.parent[x]

    def get_parity(self, x):
        self.find(x)
        return self.parity[x]

    def union(self, x, y):
        rx = self.find(x)
        ry = self.find(y)
        px = self.get_parity(x)
        py = self.get_parity(y)

        if rx == ry:
            return px ^ py == 1

        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
            px, py = py, px

        self.parent[ry] = rx
        self.parity[ry] = px ^ py ^ 1

        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1

        return True

def solve():
    n = int(input())
    seg = []
    for i in range(n):
        x, y = map(int, input().split())
        seg.append((x, y, i))

    seg.sort()

    dsu = DSU(n)

    active = []

    for x, y, i in seg:
        new_active = []
        for ax, ay, j in active:
            if not (y <= ax or ay <= x):
                if not dsu.union(i, j):
                    print("NO")
                    return
        active.append((x, y, i))

    print("YES")

if __name__ == "__main__":
    solve()
```DSU は、2 つの間隔が交差することが判明した場合は必ず、それらの間隔が反対のカラー クラスに属さなければならないことを強制するコア構造です。 パリティ配列は、ノードが現在その DSU ルートに対して位置合わせされているか反転されているかを追跡し、ユニオン操作により「異なる色」制約が強制されます。 

アクティブ リストは、現在の間隔より前に開始され、まだ完全に解決されていないすべての間隔を表します。 新しい間隔が処理されると、その間隔がすべてのアクティブな間隔と比較され、それらのセグメントが交差パターンで重なっているかどうかが判断されます。 その場合、直ちに制約を適用します。 

条件`not (y <= ax or ay <= x)`区間交差の直訳です。 素の間隔をフィルタリングして除外し、間隔が時間的に重複する場合にのみ制約を適用するようにします。

 ## 特殊なケース

 重要なエッジケースは、間隔が厳密にネストされている場合です。 例えば、$(1,10), (2,9), (3,8)$。 これらは、指定された条件下では交差を生成しないため、制約は追加されません。 アルゴリズムは正しく DSU をそのままにし、YES を出力します。 

もう 1 つの微妙なケースは、次のようなインターバルがほぼ完全に交差する構造を形成する場合です。$(1,4), (2,5), (3,6)$。 ここでは、すべてのペアが重複しており、アルゴリズムは、パリティの伝播に応じて一貫性がある場合とそうでない場合がある複数の制約を生成します。 DSU は、矛盾が発生すると、パリティの不一致によって直ちに検出されるようにします。 

最後のエッジケースは単一要素入力です。 間隔が 1 つだけの場合はエッジがないため、グラフは自明のことながら 2 部構成となり、DSU は実行中影響を受けません。
