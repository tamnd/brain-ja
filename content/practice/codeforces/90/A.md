 ## 解決策
 ## 問題の理解

 索道は 1 分ごとに 1 台のケーブルカーを送り、色は一定のサイクルで繰り返されます。`red -> green -> blue -> red -> ...`各ケーブルカーには最大 2 人の学生を乗せることができ、頂上までは 1 回の乗車でちょうど 30 分かかります。 

私たちには 3 つの学生グループが与えられています。 1 つのグループは赤い車両のみに乗り、別のグループは緑の車両のみに乗り、最後のグループは青い車両のみに乗ります。 タスクは、すべての生徒が頂点に達した最も早い瞬間を計算することです。 

重要な点は、出発スケジュールが完全に固定されていることです。 色を並べ替えたり、速度を上げたりすることはできません。 唯一の選択肢は、到着する各ケーブルカーに何人の学生が乗車するかです。 

制限は非常に小さく、各グループのサイズは最大 100 です。直接シミュレーションを行っても、制限時間内に簡単に収まります。 つまり、本当の課題は、基礎となるパターンを正確に認識し、オフバイワンの間違いを回避することです。 

不注意に実装すると、出発時刻と到着時刻を簡単に混同してしまう可能性があります。 たとえば:

 入力:```
1 0 0
```赤いケーブルカーは時間通りすぐに到着します`0`、しかし学生は時間内にのみ頂点に到達します`30`。 

正しい出力:```
30
```もう 1 つの簡単な間違いは、各車両に 2 人の生徒が乗っていることを忘れることです。 次のことを考慮してください。 

入力:```
3 0 0
```時々赤い車が出てきます`0, 3, 6, ...`最初の赤い車は一度に 2 人の生徒を乗せます`0`、そして 2 台目の赤い車が残りの生徒を乗せます。`3`。 最終到着は次のとおりです`3 + 30 = 33`。 

正しい出力:```
33
```のような素朴な式`r * 3 + 30`誤って生成してしまう`39`。 

1 つまたは 2 つのグループが空の場合、微妙なエッジ ケースもあります。 次のように仮定します。 

入力:```
0 0 1
```青い車が時間ごとに最初に現れます`2`、時間ではありません`0`。 学生が到着するのは、`2 + 30 = 32`。 

正しい出力:```
32
```異なる色が異なるオフセットで始まることを忘れると、答えはすぐに間違ってしまいます。 

## アプローチ

 最も直接的なアプローチは、ケーブルカーを分刻みでシミュレートすることです。 毎分、到着する色を次のように決定します。`time % 3`。 その色の生徒がまだ待機している場合は、最大 2 名が乗車します。 すべてのグループが空になるまで続けます。答えは現在時刻に 30 を加えたものになります。 

スケジュールは決定的であり、すべての有用な車両は常に貪欲に満たされる必要があるため、このシミュレーションは正しいです。 将来同じ色の車が到着するのは後になってからなので、座席を空席のままにしても何の解決にもなりません。 

この強引なソリューションはここでは完全に許容されますが、それでも不必要な分刻みの作業が実行されます。 最悪の場合は150分程度のシミュレーションをさせていただく場合がございます。 これはまだ簡単ではありませんが、問題の構造により直接数学的に解決できます。 

重要な観察は、すべての色が 3 分ごとに定期的に表示されることです。 

赤い車両は次の場所から出発します。```
0, 3, 6, 9, ...
```グリーン車の出発時刻は次のとおりです。```
1, 4, 7, 10, ...
```青い車両は次の時刻に出発します。```
2, 5, 8, 11, ...
```各車両には 2 人の生徒が乗車します。`x`ニーズ：```
ceil(x / 2)
```その色の車。 

色が必要な場合`k`車両の場合、その色の最終出発時刻は次のとおりです。```
offset + (k - 1) * 3
```ここで、オフセットは次のとおりです。```
red   -> 0
green -> 1
blue  -> 2
```出発後、乗車にはまだ30分かかります。 答えは単純に、3 色の中での最大到達時間です。

 ## アルゴリズムのチュートリアル

 1. 3 つのグループ サイズを読む`r`、`g`、 そして`b`。 
2. 色ごとに、必要なケーブルカーの数を計算します。 

各ケーブルカーには最大 2 人の生徒が乗車できるため、必要な車両の数は次のようになります。```
(x + 1) // 2
```これは整数の上限除算です。`x / 2`。 
3. 各色の最後のケーブルカーの出発時間を計算します。 

赤い車は時間に合わせて発車します`0`、緑色で`1`、および青色`2`。 

色が必要な場合`k`最終車両は次の時刻に出発します。```
offset + (k - 1) * 3
```同じ色の連続した車両は 3 分間隔で配置されているためです。 
4. 生徒がゼロの場合は色を無視します。 

それらは最終的な答えには寄与しません。 
5. 各最終出発時刻に 30 分を加算して、到着時刻を取得します。 
6. 全色の中での最大到達時間を出力します。 

最も遅いグループがトップに到達したときにのみ、グループ全体が終了します。 

### なぜ効果があるのか

 学生は希望する色のみを搭乗するため、各色は独立して動作します。 各色のスケジュールは固定されており、定期的であるため、生徒全員を輸送する最も早い方法は、利用可能なすべてのケーブルカーをすぐに満席にすることです。 

必要なグループのために`k`乗り物、それらの乗り物は最初のを使用する必要があります`k`あの色のケーブルカー。 遅れが生じても最終到着が遅れるだけです。 乗車時間は常に 30 分であるため、最終出発時刻を最短にすると最終到着時刻も最短になります。 

すべてのグループが同時に独立して移動するため、色全体で最大値を取ることが機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    r, g, b = map(int, input().split())

    ans = 0

    groups = [
        (r, 0),  # red
        (g, 1),  # green
        (b, 2)   # blue
    ]

    for cnt, offset in groups:
        if cnt == 0:
            continue

        cars = (cnt + 1) // 2
        last_departure = offset + (cars - 1) * 3
        ans = max(ans, last_departure + 30)

    print(ans)

solve()
```解決策は数​​学的観察に直接従うものです。 

変数`cars`1 つのカラー グループに必要なケーブルカーの数を計算します。 使用する`(cnt + 1) // 2`は、天井を 2 で割る標準的な整数トリックです。 

式:```
offset + (cars - 1) * 3
```その色の最後の有効なケーブルカーの出発時間を計算します。 1の引き算が重要です。 必要なケーブルカーが 1 台だけの場合、最後の出発は最初のオフセットで正確に行われる必要があります。 

たとえば、1 人の青色の生徒の場合は次のようになります。```
cars = 1
last_departure = 2 + (1 - 1) * 3 = 2
```それは正しいです。 

乗車ごとに移動時間が決まっているため、最後に 30 分を追加します。

    sys.stdout = out

    solve()

    sys.stdout = sys.__stdout__
