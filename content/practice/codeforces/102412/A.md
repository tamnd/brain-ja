 ## 解決策
 ## 問題の理解

 プライムモジュラス (p)、モジュロ (p) を法とする残基のサブセット (S)、および別のサブセット (V) があります。 (S) の両方の値を持つすべての順序ペア ((a,b)) について、次のように評価します。 

[
 F(a,b)=
 \frac{(2a+3b)^2+5a^2}{(3a+b)^2}
 +
 \frac{(2a+5b)^2+3b^2}{(3a+2b)^2}
 \pmod p.
 ]

 出現するすべての分母がゼロ以外で、(F(a,b)) が (V) に属する場合、ペアは正確にカウントされます。 元の公式の積は、少なくとも 1 つの因子 (F(a,b)-z) が一部の因子 (z\in V) に対してゼロであることを簡潔に表現したものにすぎません。 

素数 (p) は (10^6) までの大きさになる可能性がありますが、(S) と (V) にはそれぞれすべての (p) 残基が含まれる可能性があります。 その結果、すべての順序付けされたペアに対する直接スキャンにより、約 (p^2) 個、または最大 (10^{12}) 個のペア チェックを実行できます。 4 秒の制限により、それは完全に排除されます。 有用なターゲットはおおよそ (O(p\log p)) で、これは (p) に比例するサイズの配列にわたる FFT または NTT のスケールです。 元のコンテストのソリューションでは、まさにこの削減が使用されています。 

個別に処理する必要がある 3 つの特殊なケースがあります。 

まず、ペア ((0,0)) は決してカウントされてはなりません。 例えば、```
2
1
0
1
0
```にはペア ((0,0)) しかありませんが、分母は両方ともゼロなので、答えは次のようになります。`0`。 最初にゼロ値を削​​除せずに (a/b) を置き換える不注意な実装では、このペアに有効な比率がなく、誤って特殊な比率として扱われる可能性があります。 

第 2 に、ゼロが 1 つだけあるペアは完全に有効な分母を持ち、破棄してはなりません。 (a=0,b\ne0) の場合、式は (16) になります。 (a\ne0,b=0) の場合、(13/9) になります。 例えば、```
7
2
0 1
2
2 3
```値が (16\equiv2\pmod7) であるペア ((0,1)) と、値が (13/9\equiv3\pmod7) であるペア ((1,0)) が含まれています。 ペア ((1,1)) の値 (0) は (V) になく、((0,0)) は無効です。 正しい出力は次のとおりです`2`。 (S) からゼロを単純に削除する実装では、これら 2 つの有効な順序付きペアが失われます。 

第三に、非ゼロ (a,b) であっても、比率によって分母が消える可能性があります。 たとえば、(p=7) の場合、(3a+b=0) は (a/b=2) を意味し、(3a+2b=0) は (a/b=4) を意味します。 したがって、```
7
2
1 2
1
0
```ペア ((1,1)) と ((2,2)) の比率 (1) と (1) は有効で値 (​​0) を与えますが、ペア ((1,2)) と ((2,1)) の比率はそれぞれ (4) と (2) であるため、分母はゼロです。 正しい出力は次のとおりです`2`。 分母をチェックせずにモジュラー反転後に有理式を単純に評価すると、無関係な値が生成される可能性があります。 

## アプローチ

 ブルートフォースの解決策は簡単です。 すべての (a\in S) とすべての (b\in S) について、2 つの分母を確認し、2 つの剰余分数を計算し、(F(a,b)) を取得し、その値が (V) に属するかどうかをテストします。 すべての順序付きペアが 1 回だけ検査されるため、これは正しいです。 問題は (p^2) 個のペア数です。 (p=10^6) では、モジュール逆行列やメンバーシップ チェックを考慮する前に、(10^{12}) 個のペアが存在する可能性があります。 それは制限時間をはるかに超えています。 

私たちを救う構造は均質性です。 式内のすべての分子と分母は、(a,b) で次数 2 を持ちます。 したがって、(a\ne0) と (b\ne0) の場合、両方の変数にゼロ以外の同じ値を乗算しても結果は変わりません。 値は比率のみに依存します

 [
 t=\frac{a}{b}\pmod p.
 ]

 この観察により、すべての (p^2) ペアの代数部分が、可能な非ゼロ比 (p-1) のみに縮小されます。 意図したソリューションでは、最初にそのような比率ごとに式を評価し、どの比率が (V) に属する値を生成するかを記録します。 

そうすれば、複雑な有理関数を忘れることができます。 残りの問題は、次を満たすペア (a,b\in S) を数えることです。 

[
 a b^{-1}\in L、
 ]

 ここで、(L) は許容される比率のセットです。 

通常の畳み込みは、乗算ではなく加算を処理します。 ただし、素数を法とする非ゼロ残基の乗法グループは循環的です。 原始ルート (g) を選択します。 ゼロ以外のすべての剰余は、(0\le x<p-1) として (g^x) として一意に書くことができます。 (a=g^x) かつ (b=g^y) の場合、

 [
 \frac ab=g^{x-y}。 
]

 乗算比は指数の差になっています。 巡回畳み込みを使用してこれらの差異をカウントできます。 便利な定式化の 1 つは、(S) のインジケーターと (L) のインジケーターを畳み込みます。 指数 (x) では、畳み込みは (y+r=x) で (y) と (r) の選択肢をカウントします。これは (r=x-y)、つまり (a/b) に正確に対応します。 これは、標準ソリューションで説明される中心的な変換です。 

畳み込み係数は最大 (p) であるため、曖昧さなく NTT モジュラス (998244353) を使用できます。 最大の畳み込み係数は最大でも (10^6) であり、NTT モジュラスよりもはるかに小さくなります。 NTT 長として、(2(p-1)-1) の 2 の次のべき乗、最大で (2^{21}) を使用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(p^2\log p)) 直接モジュラー反転を使用 | (O(p)) | 遅すぎる |
 | 比率削減 + NTT | (O(p\log p)) | (O(p)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (p)、(S)、および (V) を読み取り、両方のセットの定数時間メンバーシップ配列を構築します。 また、比 (a/b) は両方の値がゼロ以外の場合にのみ存在するため、(S) のゼロ以外の要素からゼロを分離します。 
2. ゼロが 1 つだけあるペアを処理します。 (0\in S) の場合、ゼロ以外のすべての (x\in S) は 2 つの順序付きペア ((0,x)) と ((x,0)) を作成します。 最初の値は (16)、2 番目の値は (13/9) です。 これらの値が (V) に属する場合は、対応するカウントを加算します。 ペア ((0,0)) は常に無効です。 
3. 原始根 (g) モジュロ (p) を求めます。 (p-1) を因数分解し、(p-1) のすべての異なる素因数 (q) について (g^{(p-1)/q}\ne1\pmod p) まで候補 (g) を検定します。 これにより、(g) のべき乗がすべての非ゼロ剰余を正確に 1 回列挙することが保証されます。 
4. 離散対数配列を構築します。 (x=1) から始めて、繰り返し (g) を掛けます。 指数 (e) で、現在の剰余が対数 (e) を持つことを記録します。 (p-1) 回の反復の後、すべての非ゼロ剰余は既知の指数を持ちます。 
5. 標準の線形漸化式を使用して、すべての非ゼロ剰余の逆モジュラーを事前計算します。 

p-\left\lfloor\frac pi\right\rloor
 \operatorname{inv}[p\bmod i]\pmod p.
 ]

 これにより、比率ごとに個別の (O(\log p)) べき乗を実行することがなくなります。 

1. ゼロ以外のすべての比率 (t) を列挙します。 分母は次のとおりです。 

[
 (3t+1)^2
 \quad\text{および}\quad
 (3t+2)^2。 
]

(3t+1) または (3t+2) のいずれかがゼロ モジュロ (p) である場合、元の式ではゼロによる除算が明示的に禁止されているため、この比率をスキップします。 

1. 残りの (t) ごとに、(a=t,b=1) を代入します。 結果の値は次のとおりです。 

[
 G(t)=
 \frac{(2t+3)^2+5t^2}{(3t+1)^2}
 +
 \frac{(2t+5)^2+3}{(3t+2)^2}。 
]

 (G(t)\in V) の場合、2 番目の畳み込み配列内の (t) の離散対数をマークします。 

1. (S) から最初の畳み込み配列を構築します。 (x\in S) および (x\ne0) の場合、インデックス (\log_g x) に 1 を置きます。 受け入れられた比率から 2 番目の配列を構築し、インデックス (\log_g t) に 1 を置きます。 
2. NTT との通常の畳み込みを計算します。 指数配列に (y) と (r) が含まれる場合、(y+r) の係数は次を満たすペアをカウントします。 

[
 \log_g(a)+\log_g(t)=\log_g(a)、
 ]

 最初の指数を (b) の指数として解釈した後。 より直接的には、目的の分子指数 (x) について、等式 (y+r=x) は正確に (r=x-y) であり、これは (t=g^{x-y}=a/b) を意味します。 

1. 畳み込みの後半を (p-1) だけ折り返す。 指数は (p-1) を法として生きているため、係数 (k+(p-1)) は係数 (k) と同じ乗法群指数を表します。 
2. ゼロ以外の値 (a\in S) ごとに、巡回畳み込み係数を (\log_g a) に追加します。 この係数は、(a/b) が許容される比率である (b\in S) の選択肢を正確にカウントします。 ステップ 2 からのゼロケースの寄与を追加して、最終的な答えを取得します。 

### なぜ効果があるのか

 すべての非ゼロのペア ((a,b)) について、(a=g^x) と (b=g^y) を書き込みます。 この式は次数 0 の同次なので、その値は (a/b=g^{x-y}) のみに依存します。 比率の前処理は、式が定義され (V) に属する指数 (r=x-y) を正確にマークします。 巡回畳み込みは、(x=y+r) を満たす指数のペアを正確にカウントします。これは (r=x-y) と同等です。 したがって、すべての有効な非ゼロ順序ペアは 1 回寄与し、無効なペアは寄与しません。 個別に処理されるゼロのケースは、比率表現が利用できないすべてのペアをカバーします。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

NTT_MOD = 998244353
NTT_ROOT = 3

def factorize(n):
    factors = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            factors.append(d)
            while n % d == 0:
                n //= d
        d += 1 if d == 2 else 2
    if n > 1:
        factors.append(n)
    return factors

def primitive_root(p):
    if p == 2:
        return 1

    factors = factorize(p - 1)
    for g in range(2, p):
        ok = True
        for q in factors:
            if pow(g, (p - 1) // q, p) == 1:
                ok = False
                break
        if ok:
            return g
    return -1

def ntt(a, invert, rev):
    n = len(a)

    for i in range(n):
        j = rev[i]
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        wlen = pow(
            NTT_ROOT,
            (NTT_MOD - 1) // length,
            NTT_MOD
        )
        if invert:
            wlen = pow(wlen, NTT_MOD - 2, NTT_MOD)

        half = length >> 1

        for start in range(0, n, length):
            w = 1
            end = start + half
            j = start

            while j < end:
                u = a[j]
                v = a[j + half] * w % NTT_MOD

                x = u + v
                if x >= NTT_MOD:
                    x -= NTT_MOD

                y = u - v
                if y < 0:
                    y += NTT_MOD

                a[j] = x
                a[j + half] = y

                w = w * wlen % NTT_MOD
                j += 1

        length <<= 1

    if invert:
        inv_n = pow(n, NTT_MOD - 2, NTT_MOD)
        for i in range(n):
            a[i] = a[i] * inv_n % NTT_MOD

def convolution(a, b):
    need = len(a) + len(b) - 1
    n = 1
    while n < need:
        n <<= 1

    fa = a + [0] * (n - len(a))
    fb = b + [0] * (n - len(b))

    rev = array('I', [0]) * n
    half = n >> 1
    for i in range(1, n):
        rev[i] = (rev[i >> 1] >> 1) | ((i & 1) * half)

    ntt(fa, False, rev)
    ntt(fb, False, rev)

    for i in range(n):
        fa[i] = fa[i] * fb[i] % NTT_MOD

    del fb

    ntt(fa, True, rev)
    return fa[:need]

def solve():
    p = int(input())

    n = int(input())
    s = list(map(int, input().split())) if n else []

    m = int(input())
    v = list(map(int, input().split())) if m else []

    in_s = bytearray(p)
    for x in s:
        in_s[x] = 1

    in_v = bytearray(p)
    for x in v:
        in_v[x] = 1

    ans = 0

    has_zero = in_s[0]

    # Handle (0, b), b != 0.
    # The value is 16.
    if has_zero and in_v[16 % p]:
        ans += n - 1

    # Handle (a, 0), a != 0.
    # The value is 13 / 9.
    # If 9 == 0 mod p, the denominator is zero and no such pair is valid.
    if has_zero and 9 % p != 0:
        value = 13 * pow(9, p - 2, p) % p
        if in_v[value]:
            ans += n - 1

    nonzero_count = n - (1 if has_zero else 0)

    if nonzero_count == 0 or m == 0:
        print(ans)
        return

    q = p - 1

    # Find a primitive root and construct discrete logarithms.
    g = primitive_root(p)

    log = array('i', [-1]) * p
    cur = 1
    for e in range(q):
        log[cur] = e
        cur = cur * g % p

    # Linear-time modular inverses.
    inv = array('I', [0]) * p
    if p > 1:
        inv[1] = 1
        for i in range(2, p):
            inv[i] = (
                p - (p // i) * inv[p % i] % p
            )

    # A[x] = 1 iff g^x is in S.
    a_poly = [0] * q
    for x in range(1, p):
        if in_s[x]:
            a_poly[log[x]] = 1

    # B[r] = 1 iff g^r is an accepted ratio.
    b_poly = [0] * q

    for t in range(1, p):
        d1 = (3 * t + 1) % p
        d2 = (3 * t + 2) % p

        if d1 == 0 or d2 == 0:
            continue

        u = (2 * t + 3) % p
        w = (2 * t + 5) % p

        num1 = (u * u + 5 * t * t) % p
        num2 = (w * w + 3) % p

        inv_d1 = inv[d1]
        inv_d2 = inv[d2]

        term1 = num1 * inv_d1 % p * inv_d1 % p
        term2 = num2 * inv_d2 % p * inv_d2 % p
        value = (term1 + term2) % p

        if in_v[value]:
            b_poly[log[t]] = 1

    c = convolution(a_poly, b_poly)

    # Convert ordinary convolution into cyclic convolution modulo p - 1.
    for i in range(q, len(c)):
        c[i - q] += c[i]

    # For a = g^x, c[x] counts b = g^y with
    # x = y + log(a / b).
    for x in range(1, p):
        if in_s[x]:
            ans += c[log[x]]

    print(ans)

if __name__ == "__main__":
    solve()
```入力は次のように読み取られます`input = sys.stdin.readline`、必要に応じて。 メンバーシップ セットが使用するのは、`bytearray`これにより、(p=10^6) の場合でも、剰余ごとのストレージが小さく保たれます。 

ゼロの処理は、離散対数が使用される前に行われます。 ((0,b)) の値は (16) ですが、((a,0)) の値は (13/9) です。 小切手`9 % p != 0`(b=0) の場合、(p=3) は 2 番目の分数の分母をゼロにするため、これが必要です。 

逆テーブルでは、(p-1) の比率ごとに 2 つのべき乗剰余演算を行う必要がなくなります。 一度`inv[d1]`そして`inv[d2]`が既知である場合、分母の二乗は、逆数を 2 回乗算することによって反転されます。 また、比率ループは最初に非二乗線形分母をチェックします。これは、元の二乗分母がゼロかどうかをチェックすることとまったく同じです。 

畳み込み配列は、次の指数インデックスを使用します。`0`を通して`p-2`。 最初の配列は (S) の非ゼロ要素を表し、2 番目の配列は許容される比率を表します。 グループの次数は (p-1) であるため、指数は回り込みます。 通常の畳み込みには、以下の合計が含まれます。`0`を通して`2(p-2)`、つまり 2 番目の部分は次のように折り返されます。`p-1`。 

NTT モジュラス (998244353) は十分に大きいため、正確な整数の畳み込み係数では NTT モジュラスを法としてラップすることができません。 係数は剰余のペアの集合をカウントするため、最大でも (p\le10^6) になります。 

Python の実装では、一般に受け入れられている C++ アプローチと同じアルゴリズムが使用されていますが、元々の 4 秒のコンテスト制限は、高度に最適化されたコンパイル済み NTT コードを中心に設計されています。 サイズ (2^{21}) の純粋な Python NTT にはかなりのインタープリタ オーバーヘッドがあるため、Codeforces の元の制限時間内では C++ が実用的な実装言語になります。 Python バージョンの数学と整数演算は正確です。

```(S) には 9 つの非ゼロ要素があります。 アルゴリズムはまず、ゼロを含む 2 つの可能な方向を処理します。 次に、(3t+1=0) または (3t+2=0) を満たす比率 (t) をスキップして、すべての非ゼロ比率モジュロ (19) の有理式を評価します。 

結果として得られる比率セットは、原始根の指数に変換されます。 次に、畳み込みでは、許容された各比率によって異なる指数の順序ペアがいくつあるかをカウントします。 

| ステージ | キーの状態 | 実行中の答え |
 | --- | --- | --- |
 | 入力 | ( | S | =10、 | V | =10) | 0 |
 | ゼロ件 | (9) 各方向の非ゼロ候補 | 部分的 |
 | レシオスキャン | (18) ゼロ以外の比率。無効な分母比率はスキップされます。 部分的 |
 | NTT | (18) を法とする指数上の畳み込み | 部分的 |
 | 最終合計 | 非ゼロ (a\in S) ごとに (c[\log_g a]) を加算します。 42 |

 最終的な出力は次のとおりです```
42
```この例の重要な部分は、畳み込みが順序付きペアをカウントすることです。 ((a,b)) と ((b,a)) は反対の指数の差に対応し、別個の順序ペアであるため、2 による除算はありません。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(p\log p)) | 原始根の前処理、比率評価、および NTT 畳み込みはすべてこの範囲内にあります。 
| スペース | (O(p)) | メンバーシップ配列、対数、逆テーブル、および NTT バッファーは (p) | で線形です。 

最大のインスタンスには (p=10^6) があります。 比率スキャンは線形ですが、畳み込みでは最大 (2^{21}) のサイズの NTT が使用され、意図した (O(p\log p)) の複雑さが得られます。 これは、元の 4 秒および 256 MiB の制限に対する正しい漸近スケールです。 元の受け入れられたアプローチも同様に、線形サイズの残基セットを持つ NTT を使用し、同じ (O(p\log p)) のアイデアを報告します。

 ## 特殊なケース

 ((0,0)) の場合、次のようにします。```
2
1
0
1
0
```アルゴリズムはゼロが (S) に属すると判断しますが、ゼロ以外の要素はないため、ゼロの場合の寄与はゼロになります。 意味のある比率コンボリューションを構築することなく、すぐに終了します。 元の分母は両方ともゼロであるため、これは正しいです。 

((0,b)) と (b\ne0) のペアの場合、最初の小数は次のようになります。 

[
 \frac{9b^2}{b^2}=9、
 ]

 そして2番目は次のようになります

 [
 \frac{28b^2}{(2b)^2}=7、
 ]

 したがって、合計は (16) になります。 (p=7) の場合、これは (2) になります。 アルゴリズムは、(2\in V) の場合、非ゼロ (b\in S) ごとにそのようなペアを 1 つ追加します。 

((a,0)) と (a\ne0) のペアの場合、最初の分数は (1)、2 番目の分数は (4/9) となり、(13/9) になります。 アルゴリズムは、この値を使用する前に (9\ne0\pmod p) をチェックします。 このチェックは (p=3) で重要になり、分母はゼロになります。 

分母とゼロの比率については、(p=7) および (t=a/b=2) と仮定します。 それから

 [
 3t+1=7\equiv0\pmod7。 
]

 アルゴリズムは、逆数を計算する前にこの比率を拒否します。 同様に (t=4) は (3t+2=14\equiv0\pmod7) を与えます。 これは、未定義の分母を持つ有理式をモジュール値として扱うのではなく、元の除算ルールと正確に一致します。 

(p=101) の全剰余の場合、(S=V=\mathbb F_{101})。 分母がゼロ以外のすべてのペアは (V) に何らかの値を持っているため、分母の失敗のみが除外されます。 各方程式 (3a+b=0) および (3a+2b=0) は (101) 個のペアを記述し、それらは ((0,0)) でのみ交差します。 したがって、(2\cdot101-1=201) 個の無効なペアが存在し、残ります。 

[
 101^2-201=10000。 
]

 畳み込みはすべての非ゼロ ペアを処理しますが、明示的なゼロ処理では離散対数をゼロに割り当てることなく残りの有効なペアを処理します。
