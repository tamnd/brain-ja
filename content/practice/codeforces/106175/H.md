 ## 解決策
 ## 問題の理解

 私たちには素数が与えられています$p$および未知の係数シーケンスに適用される隠れた数値プロセスの出力を表す文字列$a_0, a_1, \dots, a_{n-1}$、各係数は範囲内の整数です。$[0, p-1]$。 

ポジションごとに$k$1から$n$、値は多項式のような評価を使用して計算されます。$$f(k) = \sum_{i=0}^{n-1} a_i \cdot k^i \bmod p$$数値を見る代わりに、$f(k)$、私たちはそれらを文字に転写したものを与えられます。 値 1 ～ 26 は文字 a ～ z になり、0 はアスタリスクになります。 

私たちの仕事は、このプロセスを逆転させることです。 文字列とプライムを指定すると、$p$、元の係数シーケンスを再構築する必要があります。$a_0, \dots, a_{n-1}$モジュロ$p$と順番に出力していきます。 

重要な観察点は、文字列の長さが次のとおりであるということです。$n$、つまり、まさに$n$学位の評価 -$n-1$点における多項式$1, 2, \dots, n$、すべてのモジュロを取得$p$、 どこ$p > n$。 これは、フィールド上の多項式補間を扱っていることをすぐに示唆しています。 

制約は小さく、文字列の長さは最大 70 です。$p \le 30000$。 これは、$O(n^3)$ヴァンデルモンド系に対するガウス消去法はすでに受け入れられていますが、さらに改良して構造を活用することもできます。 

微妙なエッジ ケースは文字のマッピングです。アスタリスクは 0 に対応し、文字は 1 ～ 26 に対応します。 「a」を誤って 0 として扱うのは簡単で、再構成ができなくなります。 もう一つのエッジケースは、$p$は素数ですが必ずしも小さいわけではないため、すべての演算はモジュロで実行する必要があります$p$、整数演算ではありません。 

## アプローチ

 中心的な難しさは、連続した点で多項式の値が与えられ、その係数を単項式基底で回復しなければならないことです。 

直接解釈すると線形システムが構築されます。$$\begin{bmatrix}
1^0 & 1^1 & \dots & 1^{n-1} \\
2^0 & 2^1 & \dots & 2^{n-1} \\
\vdots & \vdots & \ddots & \vdots \\
n^0 & n^1 & \dots & n^{n-1}
\end{bmatrix}
\begin{bmatrix}
a_0 \\ a_1 \\ \vdots \\ a_{n-1}
\end{bmatrix}
=
\begin{bmatrix}
f(1) \\ f(2) \\ \vdots \\ f(n)
\end{bmatrix}
\pmod p$$これがヴァンデルモンドシステムです。 ブルートフォースソルバーは完全な行列を構築し、ガウス消去法を適用します。$p$。 それは機能します。$n \le 70$、 それで$O(n^3)$およそ 300k の操作ですが、これは些細なことです。 

ただし、この構造により、より直接的な補間アプローチが可能になります。 一般的な線形システムを解く代わりに、ラグランジュ補間を使用して多項式を再構築し、係数を抽出できます。 ラグランジュ形式では次のようになります。$$f(x) = \sum_{k=1}^{n} f(k) \cdot \ell_k(x)$$それぞれどこで$\ell_k(x)$は 1 である基底多項式です。$x=k$他の整数点では 0$[1,n]$。 これを係数に展開すると、次のようになります。$a_i$。 

以来$n$が小さい場合、明示的に多項式を構築し、それらを組み合わせることができます。 

主な利点は概念的な明瞭さです。つまり、密なシステムを解くのではなく、基底多項式を構築しているのです。

## アルゴリズムのチュートリアル

 この問題を、点 1 から点 1 までの値から係数形式で多項式を再構築するものとして扱います。$n$。 

1. 入力文字列を整数配列に変換します。$y$、各文字が数値になります。 マッピングは$a \to 1, \dots, z \to 26$、 そして$* \to 0$。 これにより評価ポイントが付与されます$f(1), \dots, f(n)$。 
2. それぞれについて$k$1から$n$、ラグランジュ基底多項式を構築します。$\ell_k(x)$。 この多項式は次のように定義されます。$$\ell_k(x) = \prod_{j \ne k} \frac{x - j}{k - j}$$定数多項式 1 から開始して線形係数を順次乗算することにより、係数形式で計算します。 

分母$\prod_{j \ne k}(k - j)$モジュロで計算されます$p$そして、フェルマーの小定理を使用して一度反転しました。$p$プライムです。 
3. 掛ける$\ell_k(x)$による$y[k]$、多項式をスケーリングします。 
4. スケーリングされた多項式を、最終結果を表すアキュムレータ多項式に加算します。 
5.すべての処理が完了したら$k$、アキュムレータは係数を保持します$a_0, \dots, a_{n-1}$。 昇順に出力します。 

主な計算作業は多項式乗算ですが、次数 70 まではまだ小さいです。 

### なぜ効果があるのか

 この構造では、各基底多項式が次のことを保証します。$\ell_k(x)$まさに貢献する$y[k]$で$x=k$セット内の他のすべての整数点はゼロ$\{1, \dots, n\}$。 結果の多項式は指定されたすべての評価に一致し、最大で次数を持ちます。$n-1$、フィールド内の補間の一意性により、それが元の多項式と正確に一致することが保証されます。 したがって、抽出された係数は隠れた係数と一致する必要があります。$a_i$順序。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD_LIMIT = 30000

def modinv(a, p):
    return pow(a, p - 2, p)

def parse_char(c):
    if c == '*':
        return 0
    return ord(c) - ord('a') + 1

def poly_add(a, b, mod):
    n = max(len(a), len(b))
    res = [0] * n
    for i in range(len(a)):
        res[i] = (res[i] + a[i]) % mod
    for i in range(len(b)):
        res[i] = (res[i] + b[i]) % mod
    return res

def poly_mul_linear(poly, c, mod):
    res = [0] * (len(poly) + 1)
    for i in range(len(poly)):
        res[i] = (res[i] - poly[i] * c) % mod
        res[i + 1] = (res[i + 1] + poly[i]) % mod
    return res

def solve():
    t = int(input())
    for _ in range(t):
        parts = input().strip().split()
        p = int(parts[0])
        s = parts[1]
        n = len(s)

        y = [parse_char(ch) for ch in s]

        res = [0] * n

        for k in range(n):
            # build numerator polynomial for basis k
            poly = [1]
            denom = 1

            xk = k + 1

            for j in range(n):
                if j == k:
                    continue
                poly = poly_mul_linear(poly, j + 1, p)
                denom = (denom * (xk - (j + 1))) % p

            coef = y[k] * modinv(denom, p) % p

            for i in range(len(poly)):
                res[i] = (res[i] + poly[i] * coef) % p

        print(*res)

if __name__ == "__main__":
    solve()

コア ループは、各ラグランジュ基底多項式を明示的に構築します。 ヘルパー乗算`poly_mul_linear`多項式を乗算します$(x - c)$係数をべき乗の昇順に維持しながら。 各基底多項式は差の積によって正規化する必要があるため、分母は個別に累積されます。$(k-j)$。 

微妙な詳細は、数学的定式化 (1 ベースの評価ポイント) と実装 (0 ベースのループ) の間の一貫したインデックスのシフトです。 あらゆる出来事が起こる$j$を使用して変換されます$j+1$、ターゲット位置は次を使用します$k+1$。

 ## 特殊なケース

 特殊なケースの 1 つは、すべての文字が`*`。 この場合はすべて$y[k]=0$したがって、すべての基底多項式にはゼロが乗算され、最終的な係数配列はすべてゼロのままになります。 スケーリングは蓄積の前に行われるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、すべての文字が同じ 0 以外の値にマップされる場合です。 各基底多項式は依然としてその点を分離しているため、結果は崩壊するのではなく、構造化された組み合わせになります。 正規化では逆モジュラーを使用するため、すべての評価点が個別であり、ゼロによる除算は発生しません。$p > n$。 

最後の微妙なケースはインデックス作成です。 評価点が 1 ではなく 0 から始まるものとして誤って扱われると、分母が正しくなくなり、補間が失敗します。 実装では一貫して使用します$j+1$そして$k+1$、全体を通して正しい座標系が使用されていることを確認します。
