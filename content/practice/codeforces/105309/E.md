 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースには、$n$円形に配置されたレッサーパンダと$k$パンダの最初のペアは、交差しないコードによってすでに接続されています。 各パンダはこれらの初期ペアの最大 1 つに出現するため、初期構造は交差のない部分一致になります。 

目標は、完全な非交差の完全マッチングで終了することです。すべてのパンダは 1 人のパートナーと一致する必要があり、すべての一致するエッジは円の内側に交差することなくコードとして描画可能でなければなりません。 最初のペアの一部を破棄することができます。 破棄した後、残りのペアは、現在一致していないパンダ間の追加ペアを使用して、そのような完全な非交差マッチングに拡張可能でなければなりません。 

出力は、残りの構成を有効な完全な非交差完全マッチングに完成させるために削除する必要がある初期ペアの最小数です。 

制約により、最大で$10^5$テスト ケースごとの合計ノード数、最大$10^4$テストケース。 これにより、二次関数は即座に除外されます。$n$テストケースごとに。 どのようなソリューションも、全体として本質的に線形またはほぼ線形である必要があります。$O(n \log n)$すべてのテストで、またはそれ以上の結果が得られます。 

単純な失敗モードは、最初のペアをすべて修正した後で「貪欲に完了」しようとすることから発生します。 たとえば、領域内に奇数の一致しない頂点が作成された場合でも、最初のペアをすべて保持するとします。 奇数のフリー頂点を持つ領域は、グローバルな頂点数が偶数であっても、内部的に完全に一致させることはできません。 

もう 1 つの微妙な問題は、初期エッジが交差していないため、常に安全に保持できると想定していることです。 それは誤りです。保持された単一のエッジでも、その囲まれたセグメント内に不可能なパリティ構造を強制することができます。 

## アプローチ

 ブルートフォースのアイデアでは、$k$最初のエッジを確認し、どのサブセットが拡張可能であるかを確認し、保持されるエッジの数を最大化します。 指数関数的なサブセットの列挙を無視したとしても、1 つのサブセットの有効性をチェックするには、すべての誘導領域内の残りの空き頂点が交差することなく完全に一致できるかどうかを検証する必要があります。 その検証自体は、$O(n)$、全体的な複雑さにつながります$O(2^k \cdot n)$、それは不可能です。 

重要な構造的観察は、最初のコードが交差していないということです。これは、それらが層状ファミリーを形成していることを意味します。つまり、すべてのコードは、別のコードの中に完全に存在するか、別のコードから完全に切り離されています。 これにより、構造が根を張った封じ込め林 (多くの場合、外側の間隔ごとに 1 本の木) に変わります。 このように見ると、各コードは内部に小さな独立した部分問題を含む音程を定義します。 

主な問題は、コードを維持すると、その領域内の一致しない頂点のパリティに影響を与えることです。 領域に奇数の一致しない頂点が存在する場合、その領域内で完全な一致を完了することは不可能になります。 したがって、各コードはそのサブツリーに「パリティ要求」を伝えます。つまり、コードの内部が偶数の空きエンドポイントを提供する必要があるか、そのコードを破棄する必要があります。 

これは、間隔ごとに内部的に一貫性があるかどうかを計算するという事後処理のアイデアにつながります。 そうでない場合は、コードを削除し、その端点を自由な頂点として動作させ、パリティの変更を上方向に伝播させます。

 ## アルゴリズムのチュートリアル

 ### 1. 封じ込め構造を構築する

 まず最初に各初期ペアを解釈します$(a_i, b_i)$円上の間隔として。 交差するエッジがないため、これらの間隔はネストされているか、互いに素になっています。 エンドポイントをソートし、各間隔に直接ネストされた間隔が子として含まれるツリーを構築します。 

これにより、各ノードが初期エッジとなり、その子が厳密にその内部のエッジとなるフォレストが得られます。 

### 2. 「ノード内で有効」の意味を定義する

 エッジを表すノードの場合$(u, v)$の間のセグメントを考えてみましょう。$u$そして$v$。 このセグメント内には次のものがあります。 

- 小さいエッジの端点、
 - 入射エッジが削除された場合、保持されたエッジによって頂点が使用されなくなります。 

維持すると決めた場合$(u, v)$の場合、最終的には内部領域が完全に一致する必要があります。 そのためには、領域内の空き頂点の数が偶数である必要があります。 

したがって、すべてのノードはパリティ条件を保持します。つまり、このエッジを維持する場合、そのサブツリーは偶数の空き頂点を生成する必要があります。 

### 3. 最初に子を処理する

 最も深い間隔から上に向かって深さ優先のトラバースを実行します。 各子サブツリーは、その親区間に対する固定パリティ効果に寄与します。つまり、削除されたすべてのエッジは 2 つの空き端点に寄与しますが、これらの端点は、ネストにより一貫性のある形で異なる領域に存在する可能性があります。 重要な状態はパリティのみであるため、各サブツリーは単一ビットとして要約できます。 

各ノードについて、ノードを保持しようとした場合にそのサブツリーが寄与する空き頂点のパリティを計算します。 

### 4. エッジを維持するか削除するかを決定します。 

ノードでは、すべての子からの寄与を集約した後、パリティ条件をチェックします。 

- 区間内の合計パリティが偶数の場合、エッジは保持されます。 
- 奇数の場合、それを保持するとその領域を完了できなくなるため、削除する必要があります。 

ノードを削除すると、その端点は自由な頂点になり、その祖先から見られるパリティ寄与が反転します。 

### 5. 上向きに伝播する

 DFS は、除去を適用した後、修正されたパリティ寄与を上方に返します。 削除するたびに回答数が増加します。 

### なぜ効果があるのか

 重要な不変条件は、サブツリーの処理後に報告されるパリティが、それが囲む間隔に寄与する空きエンドポイントの数を正しく表すことです。 間隔はネストされており、部分的に重なることはないため、各サブツリーはこのパリティ値を通じてのみ構造の残りの部分と相互作用します。 ノードにおける矛盾は、そのノードを破棄することによってのみ解決できます。そうすることで、他の素なサブツリーの内部の正確さに影響を与えることなく一貫性が復元されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        pairs = []
        pos = [[] for _ in range(n + 1)]

        for i in range(k):
            a, b = map(int, input().split())
            if a > b:
                a, b = b, a
            pairs.append((a, b))
            pos[a].append(i)
            pos[b].append(i)

        pairs.sort()

        stack = []
        children = [[] for _ in range(k)]
        parent = [-1] * k

        # Build nesting tree using sweep over endpoints
        endpoint_map = []
        for i, (l, r) in enumerate(pairs):
            endpoint_map.append((l, i, 0))
            endpoint_map.append((r, i, 1))
        endpoint_map.sort()

        active = []
        stack = []

        # Build parent-child relations
        for x, i, typ in endpoint_map:
            if typ == 0:
                if stack:
                    parent[i] = stack[-1]
                    children[stack[-1]].append(i)
                stack.append(i)
            else:
                stack.pop()

        sys.setrecursionlimit(10**7)

        ans = 0

        def dfs(u):
            nonlocal ans
            parity = 0
            for v in children[u]:
                parity ^= dfs(v)
            if parity == 1:
                ans += 1
                return 0
            return parity

        for i in range(k):
            if parent[i] == -1:
                if dfs(i):
                    ans += 1

        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、ソートされた順序でエンドポイントをスイープし、現在開いている間隔のスタックを維持することにより、ネスト構造を構築します。 左側のエンドポイントが表示されると、現在のアクティブな間隔が存在する場合は、その下に新しい間隔が接続されます。 正しい終点が表示されると、間隔が閉じます。 

DFS はノードごとに 1 つのパリティ ビットを計算します。 サブツリーがパリティ 1 を返す場合、その親間隔も維持されているとそのサブツリーは一貫性を保つことができないため、そのエッジを削除して反転し、パリティ 0 を上向きに寄与させます。 

微妙な点は、ルートが個別に処理されることです。ルート サブツリー自体に奇数のパリティがある場合、それも削除する必要があります。

 ## 特殊なケース

 主要なエッジ ケースは、複数のネストされた間隔を含む単一の間隔であり、その組み合わせ構造により、あるレベルで奇数パリティが強制されます。 このような場合、アルゴリズムは最初にすべての内側のエッジを保持し、それらのパリティを計算し、親に戻るときにのみ矛盾を検出しようとします。 

例えば：```
n = 8
(1,8), (2,3), (4,5), (6,7)
```内側のエッジは個別にパリティに寄与しないため、外側のエッジは一貫性を保って維持されます。 

1 つのサブツリーが奇数パリティを強制するように内部構造を変更すると、DFS はそれをローカルで検出し、正確にそのサブツリー ルートを削除し、上向きの一貫性を回復します。
