 ## 解決策
 ## 問題の理解

 同じ長さの 3 つの文字列が与えられており、最初の 2 つの文字列はテンプレートに一致するが、3 番目の文字列は一致しないようにテンプレート文字列を構築する必要があります。 テンプレート内の各位置には、小文字または大文字を使用できます。 小文字を使用すると、一致する文字列内の対応する文字が完全に同じになるように強制されますが、大文字を使用すると、対応する文字がテンプレート文字の小文字バージョンと等しくなることが禁止されます。 入力には複数のテスト ケースが含まれており、各文字列の長さは小さく、最大 20 です。この小さいサイズは、組み合わせ爆発を心配することなく、すべての位置を独立して推論できることを意味します。 

難しいのは、最初の 2 つの文字列が異なる位置を処理することです。 もし`a[i]`等しい`b[i]`、小文字のテンプレート文字を使用すると、両方が一致することが保証されますが、`a[i] != b[i]`、両方を一致させる小文字はないため、大文字を選択する必要があります。 テンプレートは次のことも保証する必要があります。`c[i]`少なくとも 1 回は一致ルールに違反しますが、次の場合には微妙になる可能性があります。`c[i]`と一致する`a[i]`または`b[i]`。 エッジ ケースには、ある位置にある 3 つの文字がすべて異なる場合や、`a[i] = b[i] = c[i]`、またはそれらのうち 2 つだけが等しい場合。 これらの区別を無視した単純なアプローチでは、誤ったテンプレートが生成されてしまいます。 

## アプローチ

 ブルートフォースアプローチは、すべてを列挙することです。`2^n * 26^n`考えられるテンプレートを確認し、`a`そして`b`マッチしながら`c`しません。 あっても`n`20までは不可能です。 重要な観察は、各位置を独立して解決できることです。 必要なのは、その位置で両方を許可する有効なテンプレート文字を決定することだけです。`a`そして`b`マッチしてブロックする`c`もし可能なら。 各位置にはいくつかのケースしかありません。`a[i] = b[i]`、小文字のいずれかを選択できます`a[i]`(合わせるために`a`そして`b`）一致しない限り`c[i]`、その場合は大文字`a[i]`動作します。 もし`a[i] != b[i]`、両方とは異なる大文字を選択する必要があります。`a[i]`そして`b[i]`; もし`c[i]`どちらとも一致しない`a[i]`または`b[i]`、これは簡単です。 なぜなら`n`が最大 20 である場合、位置ごとにこれらのオプションを繰り返すのが効率的です。

 ## アルゴリズムのチュートリアル

 1. 各位置を反復処理します。`i`から`0`に`n-1`。 
2. もし`a[i] == b[i]`、どうかを確認してください`c[i] == a[i]`。 「はい」の場合は、大文字バージョンを選択してください`a[i]`ブロックするテンプレートとして`c`。 それ以外の場合は、小文字を使用します`a[i]`。 
3. もし`a[i] != b[i]`、両方とは異なる大文字を選択する必要があります`a[i]`そして`b[i]`。 もし`c[i]`等しい`a[i]`または`b[i]`、大文字を選択すると自動的にブロックされます`c[i]`。 それ以外の場合は、次と異なる大文字`a[i]`そして`b[i]`十分です。 
4. どの位置にも有効な選択肢が存在しない場合は、「NO」を返します。 それ以外の場合は、すべての位置を確認した後、「YES」を返します。 

不変条件は、各位置で、両方を許可するテンプレート文字を選択することです。`a`そして`b`合わせるために。 この設計により、少なくとも 1 つの位置が一致に違反することが保証されます。`c`必要に応じて、次のいずれかの理由で`c[i]`と一致する`a[i]`または`b[i]`大文字を選択するか、次とは異なる大文字を選択します。`a[i]`そして`b[i]`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = input().strip()
        c = input().strip()
        possible = True
        template = []
        for i in range(n):
            if a[i] == b[i]:
                if c[i] == a[i]:
                    template.append(a[i].upper())
                else:
                    template.append(a[i])
            else:
                # need uppercase letter different from both a[i] and b[i]
                for ch in 'abcdefghijklmnopqrstuvwxyz':
                    if ch != a[i] and ch != b[i] and (ch != c[i] or c[i] == a[i] or c[i] == b[i]):
                        template.append(ch.upper())
                        break
                else:
                    possible = False
                    break
        print("YES" if possible else "NO")

if __name__ == "__main__":
    solve()
```各ループは位置を独立して処理します。 いつ`a[i] = b[i]`、大文字変換はブロックするために使用されます。`c[i]`。 いつ`a[i] != b[i]`、アルファベットが 26 文字で最大文字列長が短いため、すべての文字に対するループにより、少なくとも 1 つの大文字が有効であることが保証されます。 の`else`の条項`for`ループにより、不可能なケースを正しく検出できるようになります。 3 文字がすべて等しいエッジケースは、大文字に変換することで正しく処理されます。
