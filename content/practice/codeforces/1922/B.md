 ## 解決策
 ## 問題の理解

 それぞれ 2 のべき乗の長さを持つスティックのセットが与えられます。 入力は実際の長さを直接与えるのではなく、指数を与えます。$a_i$スティックの長さが$2^{a_i}$。 私たちの課題は、縮退していない三角形を形成できる正確に 3 本の棒を選択する方法の数を数えるということです。 任意の 2 つの辺の長さの合計が 3 番目の辺の長さを超える場合、三角形は非縮退です。 

各テスト ケースの出力は、有効なスティック トリプレットの数を表す単一の整数です。 スティックは 2 の累乗で定義されるため、多くのスティックは同じ長さになる可能性があり、三角形不等式は最大のスティックと他の 2 つの合計との単純な比較に帰着します。 

制約は次のことを教えてくれます$n$と同じ大きさにすることができます$3 \cdot 10^5$まであります$10^4$テスト ケース。すべてのテスト ケースにわたるスティックの合計数は次のとおりです。$3 \cdot 10^5$。 これは、より複雑なアルゴリズムを意味します。$O(n^2)$テストケースごとに実行すると遅すぎる可能性があります。 アン$O(n \log n)$または$O(n^2)$このアプローチは、慎重に実装されていれば受け入れられます。 

エッジ ケースは、すべてのスティックの長さが同じですべての 3 連符が有効になる場合、またはスティックが指数関数的に増加してほとんどの 3 連符が無効になる場合に発生します。 たとえば、指数が付いた棒があるとします。`[1, 2, 3]`長さに対応する`[2, 4, 8]`、三角形は形成できません。$2 + 4 = 6 \le 8$。 

## アプローチ

 素朴なアプローチは強引です。スティックのすべての 3 つ組を反復処理し、三角不等式を満たしているかどうかを確認します。 これは正しいですが、$O(n^3)$実行不可能な複雑さ$n$まで$3 \cdot 10^5$。 中程度の場合でも$n$、そのようなアプローチは遅すぎます。 

重要な観察は、スティックの長さが 2 の累乗であるということであり、これは三角形不等式が単純化できることを意味します。 指数によってスティックをソートすると、問題はソートされた配列の標準的な三角形カウント問題に変換されます。 ソートされたスティックの場合、3 つのインデックスを選択すると$i < j < k$、次の場合に非縮退三角形が存在します。$2^{a_i} + 2^{a_j} > 2^{a_k}$。 並べ替えは次のことを保証します$a_i \le a_j \le a_k$したがって、最大の要素と小さい 2 つの要素の合計をチェックするだけで済みます。 これにより、2 ポインターまたは 3 ポインターのアプローチで有効なトリプレットを効率的にカウントできるようになります。 

同じ長さのスティックの組み合わせ公式を使用してトリプレットの数を事前に計算し、ソートされた一意の長さをスキャンすることで異なる長さのスティックを考慮することができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | ソート + スリー ポインタ | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして指数$a_i$。 
2. 指数の配列を並べ替えます。 並べ替えを使用すると、最大の棒を小さい方の 2 つの合計と比較するだけで、三角不等式を迅速に適用できます。 
3. 有効なトリプレットのカウンターを初期化します。 
4. 3 つのインデックスを使用して配列を反復処理します。$i < j < k$。 修理$i$そして$j$そして最大値を見つけます$k$そのような$2^{a_i} + 2^{a_j} > 2^{a_k}$。 移動するにはsortedプロパティを使用します$k$条件が失敗するまで前進します。 
5. 有効なそれぞれについて$i, j$ペアに有効な数を加算します$k$カウンターへの位置。 
6. すべてのペアをスキャンした後、カウンターを出力します。 

機能する理由: ソートされた配列により、次のことが保証されます。$k$増加し、$2^{a_k}$も増えます。 前進することで$k$三角不等式が成り立つ場合にのみ、すべての 3 つ組を正確に 1 回カウントし、正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_triangles(n, a):
    a.sort()
    count = 0
    for i in range(n - 2):
        k = i + 2
        for j in range(i + 1, n - 1):
            while k < n and (1 << a[i]) + (1 << a[j]) > (1 << a[k]):
                k += 1
            count += k - j - 1
    return count

t = int(input())
results = []
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    results.append(str(count_triangles(n, a)))

print("\n".join(results))
```コードはまず指数配列を並べ替えます。 スティックのペアごとに進みます$k$三角不等式が崩れるまで。 有効枚数$k$各ペアごとに$(i, j)$まさに$k - j - 1$。 一度確認するためには並べ替えが必要です$2^{a_i} + 2^{a_j} \le 2^{a_k}$、その後のすべて$k$も失敗します。
