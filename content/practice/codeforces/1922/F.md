 ## 解決策
 ## 問題の理解

 それぞれ 1 から最大値までの整数の配列が与えられます。$x$。 特別な操作を使用してすべての要素を等しくしたいとします。配列の連続したサブセグメントと値を選択します。$k$現在そのサブセグメントに存在しない場合は、そのサブセグメント内のすべての要素を次の要素に置き換えます。$k$。 目標は、配列全体を均一にするために必要なそのような操作の最小数を計算することです。 

入力サイズ$n$最大でも 100 であり、$x \le n$、すべての合計$n$テスト ケースの数は 500 を超えません。これにより、$O(n^2 x)$または、タイムアウトなしでテスト ケースごとにわずかに高い操作を実行します。 境界が小さいということは、考えられるすべてのターゲット値 (配列に望む値) を反復処理して、各ターゲットの最小演算数を効率的に計算できることも意味します。 

考慮すべきエッジケースには、すでに均一な配列、すべての要素が異なる配列 (複数の操作が必要)、および最適な戦略が一部の要素をスキップして操作を最小限に抑える配列が含まれます。 たとえば、次のような配列`[1, 2, 1]`と$x = 2$を選択すると、1 回の操作ですべて 1 に変換できます。$k = 1$サブセグメントには中央の要素のみが含まれます。 連続する不一致を常に左から右に置き換える単純なアプローチでは、余分な操作が不必要に実行される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての操作シーケンスをシミュレートすることです。 サブセグメントごと、およびそのサブセグメントに存在しない値ごとに、置換を試みて再帰的に続行できます。 原理的には正しいですが、サブセグメントの数が異なるため、これは実現不可能です。$O(n^2)$、候補値の数は$x$、操作のシーケンスは組み合わせです。 これでも爆発する$n = 100$。 

重要な洞察は、配列を均一な値に変換するだけでよく、この操作により、隣接するサブセグメントをそのサブセグメントに現在存在しない新しい値に置き換えることができるという観察から得られます。 これにより、**まだターゲット値と等しくない**連続ブロックの数として、操作の最小数をカウントできます。 ターゲットとは異なる要素の 2 つのブロックがターゲット値によって分離されている場合、それらは別々の操作を必要とします。 連続している場合は、1 回の操作でセグメント全体をカバーできます。 したがって、ターゲット値の候補ごとに、配列をスキャンし、これらのブロックをカウントし、すべての可能なターゲット値の最小値を取得できます。

 | 最適 (ターゲットごとのブロック数) | O(n x) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`res`無限に。 これにより、すべての可能なターゲット値にわたる最小操作数が保持されます。 
2. 潜在的な各ターゲット値を反復処理します。`k`1から`x`。 
3. カウンタの初期化`ops`このターゲットの 0 とポインタ`i`配列を走査します。 
4. ながら`i < n`、どうかを確認してください`a[i]`等しい`k`。 そうなった場合はインクリメントします`i`そして続けます。 
5. もし`a[i]`等しくない`k`、不一致の連続ブロックの始まりが見つかりました。 インクリメント`ops`1までに。 
6. 前進`i`このブロックの終わりまで (`a[i] == k`または`i == n`）。 これにより、1 回の操作で置き換えることができる完全な連続セグメントがキャプチャされます。 
7. ターゲットのアレイをスキャンした後`k`、 アップデート`res`として`min(res, ops)`。 
8. すべてのターゲットを確認したら、`res`配列を均一にするために必要な最小限の操作が含まれています。 この値を印刷または保存します。 

機能する理由: この操作ではターゲットを含まないセグメントを変更できるため、選択したターゲットとは異なる要素の連続ブロックを 1 回の操作で置き換えることができます。 重複しないブロックは個別に処理する必要があり、ブロックをカウントすることで、それを正確に行うことができます。 考えられるすべての目標値をチェックすることで、グローバル最小値を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        res = float('inf')
        for k in range(1, x + 1):
            ops = 0
            i = 0
            while i < n:
                if a[i] == k:
                    i += 1
                    continue
                ops += 1
                while i < n and a[i] != k:
                    i += 1
            res = min(res, ops)
        print(res)

if __name__ == "__main__":
    solve()
```コードは、テスト ケースの数を読み取ることから始まります。 テスト ケースごとに、配列とそのパラメーターを読み取ります。 潜在的なターゲット値ごとに、ターゲットとは異なる連続ブロックをカウントし、すべてのターゲットにわたる最小数を追跡します。 内側の while ループは、ブロックが配列の最後に達するエッジ条件を処理し、二重にカウントすることなく完全なブロックを正確に識別することを保証します。
