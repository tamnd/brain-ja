## アルゴリズムのチュートリアル

 まず、次の異なる素因数を抽出します。$M$。 これらの素数は、どの数値が除外されるかを完全に決定します。 

次に関数を定義します$f(x)$、これは整数の個数を返します。$[1, x]$と互いに素である$M$。 これは、素因数のサブセットに対する包含-排他を使用して計算されます。 

1.因数分解$M$それぞれの異なる素因数に分けられます。 これにより小さなセットが得られます$P$。 
2. 関数を構築する$f(x)$の数を数える$[1, x]$どの素数でも割り切れない$P$。 
3. クエリごとに$k$、最小の二分探索$x$そのような$f(x) \ge k$。 
4.それを出力します$x$答えとして。 

重要な計算は内部にあります$f(x)$。 空ではない素数のサブセットごとに、そのサブセット内の素数の積を計算します。 サブセットのサイズが奇数の場合は、減算します。$x / product$そうでない場合は、それを追加し直します。 これにより、少なくとも 1 つの素因数で割り切れる整数が正しく数えられます。 

二分探索が機能する理由は、$f(x)$単調増加です: として$x$増加すると、互いに素な整数の数は最大で$x$決して減りません。 

### なぜ効果があるのか

 正しさは、有効なシーケンスのメンバーシップが素数の固定セットで割り切れる性質であるため、それらの素数に対する包含-排除によって完全に捕捉されるという事実にかかっています。 正しいプレフィックスカウント関数を取得したら$f(x)$、k 番目の有効な数値は、まさにこの単調関数の逆関数です。 二分探索が有効なのは、$f(x)$有効な整数ごとに 1 ずつ増加し、無効な整数では一定のままであるため、順序に違反することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import isqrt

def factorize(m):
    primes = []
    i = 2
    while i * i <= m:
        if m % i == 0:
            primes.append(i)
            while m % i == 0:
                m //= i
        i += 1
    if m > 1:
        primes.append(m)
    return primes

def count_coprime(x, primes):
    k = len(primes)
    res = 0
    for mask in range(1 << k):
        if mask == 0:
            res += x
            continue
        bits = 0
        prod = 1
        for i in range(k):
            if mask & (1 << i):
                prod *= primes[i]
                bits ^= 1
        if prod > x:
            continue
        if bits == 1:
            res -= x // prod
        else:
            res += x // prod
    return res

def kth(primes, k):
    lo, hi = 1, k * (max(primes) + 1) if primes else k
    while lo < hi:
        mid = (lo + hi) // 2
        if count_coprime(mid, primes) >= k:
            hi = mid
        else:
            lo = mid + 1
    return lo

def main():
    N, M = map(int, input().split())
    arr = list(map(int, input().split()))
    primes = factorize(M)
    out = []
    for k in arr:
        out.append(str(kth(primes, k)))
    print(" ".join(out))

if __name__ == "__main__":
    main()
