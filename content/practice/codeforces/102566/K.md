 ## 解決策
 ## 問題の理解

 有向都市グラフがあります。 すべての交差点は頂点であり、すべての道路は有向エッジです。 泥棒は銀行の交差点から始まる`A`そして最終的には既知の最後の場所に到達します`B`。 考えられるすべての誘導ルートの中で、`A`に`B`、すべてのルートに表示される必要があるすべての交差点を検索し、それらの交差点を遭遇した順序で出力する必要があります。 

この問題の背後にある重要なグラフの概念はドミネーターです。 頂点`v`支配する`B`すべてのパスからの場合`A`に`B`通り抜ける`v`。 答えはドミネーターの連鎖です`B`から始まる`A`そして終わる`B`。 

入力サイズが十分に大きいため、パス探索を繰り返し行うことは不可能です。 まで`2 * 10^5`交差点と`2 * 10^6`有向グラフ内の可能なパスの数が膨大になる可能性があるため、多くの異なるルートを探索するアプローチは指数関数的になる可能性があります。 グラフの走査を頂点ごとに 1 回実行するだけでも、およそのコストがかかります`O(N(N+M))`、これは 1 秒の制限をはるかに超えています。 グラフサイズが線形に近いアルゴリズムが必要です。 

いくつかのケースでは、単純なアイデアが崩れます。 1 つの最短パス上にある頂点は、必ずしも必須ではありません。 例えば：```
1
4 4
1 4
1 2
2 4
1 3
3 4
```正しい出力は次のとおりです。```
2
1 4
```次のような 1 つのパスを選択する`1 -> 2 -> 4`すべての頂点をマークすると、誤って次のものが含まれます。`2`。 

サイクルにも注意が必要です。 考慮する：```
1
4 4
1 4
1 2
2 3
3 2
3 4
```正しい出力は次のとおりです。```
2
1 4
```間のサイクル`2`そして`3`入力またはスキップできるため、どちらの頂点も保証されません。 

最後のエッジケースは次のような場合です。`A`そして`B`同じ頂点です。 泥棒はすでに最終地点にいるため、保証されているカメラはその 1 つの交差点だけです。 

## アプローチ

 直接的な解決策では、考えられるすべてのパスを列挙します。`A`に`B`すべてのパスに共通の交差点を設定します。 これは正しいです。交差点は、すべてのルートに交差点が含まれている場合にのみ存続します。 問題は、有向グラフには指数関数的な数のパスが含まれる可能性があることです。 頂点が数百しかないグラフであっても、個別に検査するにはルートが多すぎる可能性があります。 

より良い方向は、別の質問をすることです。 すべてのパスを比較するのではなく、どの頂点が到達可能性を制御しているかを尋ねます。`B`。 これはまさにドミネーターの定義です。 頂点の直接のドミネーターは、その前の最も近いドミネーターであり、頂点のすべてのドミネーターはドミネーター ツリー内のチェーンを形成します。 このツリーをルートとして計算すると、`A`、答えは単純に、の先祖です。`B`。 

Lengauer-Tarjan アルゴリズムは、ほぼ直線的な時間で即時ドミネーターを計算します。 これは、DFS 順序を割り当て、頂点を逆方向に処理し、素セット スタイル構造を使用して最適なドミネーター候補を維持することによって機能します。 ドミネーター関係は DFS 祖先間の最小セミドミネーターに依存し、効率的に維持できるため、この構造はここで役立ちます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | パス数の指数関数 | O(N+M) | 遅すぎる |
 | ドミネーター ツリーとレンガウアー タルジャン | O((N+M) α(N)) | O(N+M) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. DFS を実行します。`A`そして、到達可能なすべての頂点に DFS インデックスを割り当てます。 各頂点の親を DFS ツリーに保存します。 到達不可能な頂点はルート上に表示されないため、到達可能な頂点のみが重要になります。`A`に`B`。 
2. DFS 頂点を逆の順序で処理し、各頂点のセミドミネーターを計算します。 セミドミネーターは、DFS 構造を通じてまだこの頂点に到達できる最も古い頂点を表します。 これを実行している間、すべての入力エッジがそこに入る可能性があるため、現在の頂点のすべての先行要素を評価します。 
3. パス圧縮を使用して Union-Find スタイルの構造を維持し、最良の祖先候補を効率的にクエリします。 これにより、長いチェーンを繰り返しスキャンすることが回避されます。 
4. 即時ドミネーター配列を構築します。 頂点に対して見つかった候補がセミドミネーターではない場合、直接ドミネーターは別のドミネーター関係を通じて継承されます。 それ以外の場合は、セミドミネーター自体が即時ドミネーターになります。 
5. 直接の支配者をフォローします。`B`向かって戻る`A`。 ドミネーターは目的地から逆方向に検索され、答えには旅行命令が必要になるため、印刷する前にこの順序を逆にします。 

それが機能する理由: からのすべてのパスが正確に頂点に属するとき、頂点は答えに属します。`A`に`B`それが含まれています。 これはまさに支配の定義です`B`。 Lengauer-Tarjan アルゴリズムは、到達可能なすべての頂点の直接のドミネーターを計算します。また、任意の頂点のドミネーターは、ドミネーター ツリー内のその頂点の正確な祖先です。 からの親チェーンをたどります`B`したがって、すべての保証されたカメラが提供され、余分な交差はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(n, m, a, b, edges):
    g = [[] for _ in range(n + 1)]
    rg = [[] for _ in range(n + 1)]
    for x, y in edges:
        g[x].append(y)
        rg[y].append(x)

    sys.setrecursionlimit(1 << 25)

    arr = [0] * (n + 1)
    rev = [0] * (n + 1)
    parent = [0] * (n + 1)
    order = 0

    def dfs(v):
        nonlocal order
        order += 1
        arr[v] = order
        rev[order] = v
        for u in g[v]:
            if arr[u] == 0:
                dfs(u)
                parent[arr[u]] = arr[v]

    dfs(a)

    if arr[b] == 0:
        return []

    N = order
    pred = [[] for _ in range(N + 1)]
    for v in range(1, n + 1):
        if arr[v]:
            for u in g[v]:
                if arr[u]:
                    pred[arr[u]].append(arr[v])

    semi = list(range(N + 1))
    label = list(range(N + 1))
    ancestor = [0] * (N + 1)
    bucket = [[] for _ in range(N + 1)]
    idom = [0] * (N + 1)

    def compress(v):
        if ancestor[ancestor[v]]:
            compress(ancestor[v])
            if semi[label[ancestor[v]]] < semi[label[v]]:
                label[v] = label[ancestor[v]]
            ancestor[v] = ancestor[ancestor[v]]

    def eval_node(v):
        if ancestor[v] == 0:
            return label[v]
        compress(v)
        return label[v]

    for i in range(N, 1, -1):
        for p in pred[i]:
            x = eval_node(p)
            if semi[x] < semi[i]:
                semi[i] = semi[x]
        bucket[semi[i]].append(i)
        ancestor[i] = parent[i]
        for v in bucket[parent[i]]:
            x = eval_node(v)
            if semi[x] < semi[v]:
                idom[v] = x
            else:
                idom[v] = parent[i]
        bucket[parent[i]].clear()

    for i in range(2, N + 1):
        if idom[i] != semi[i]:
            idom[i] = idom[idom[i]]

    idom[1] = 0

    ans = []
    cur = arr[b]
    while cur:
        ans.append(rev[cur])
        cur = idom[cur]
    ans.reverse()
    return ans

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        a, b = map(int, input().split())
        edges = []
        for _ in range(m):
            x, y = map(int, input().split())
            edges.append((x, y))
        ans = solve_case(n, m, a, b, edges)
        out.append(str(len(ans)))
        out.append(" ".join(map(str, ans)))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```隣接リストには、送信情報と受信情報の両方が間接的に保存されます。 DFS 番号付けは、元の頂点をコンパクトなインデックスに変換します。`1`到達可能な頂点の数に換算します。これは、Lengauer-Tarjan によって使用されるインデックス システムです。 

配列`semi`、`label`、`ancestor`、 そして`bucket`セミドミネーターの計算を実装します。`compress`そして`eval_node`これは、祖先クエリの繰り返しを高速に行うための素セット操作です。 最後のループでは、即時ドミネーター チェーンを DFS インデックスから元の交差番号に変換します。 

再構築ステップは次から始まります`B`そして直接のドミネーターに繰り返し移動します。 これは次で止まります`A`これは、DFS ルートには直接のドミネーターがないためです。 収集されたリストを逆にすると、考えられるすべての強盗ルートに沿ったカメラの実際の順序がわかります。

## 特殊なケース

 複数の分岐が存在する場合、アルゴリズムは単一のルートを選択しません。 分岐の例では次のようになります。```
1
4 4
1 4
1 2
2 4
1 3
3 4
```ドミネーター ツリーには、`1 -> 4`。 頂点`2`そして`3`それぞれにそれを回避する代替パスがあるため、除外されます。 

サイクルが存在する場合、繰り返しアクセスしても追加の保証カメラは作成されません。 で：```
1
4 4
1 4
1 2
2 3
3 2
3 4
```アルゴリズムは両方を認識します`2`そして`3`バイパスされる方法があるため、直接のドミネーターチェーンは`4`のみが含まれます`1`。 

いつ`A == B`, DFS はルートを唯一のドミネーターとして割り当てます。 再構築ループはただちにその頂点を返し、唯一の保証されたカメラが開始交差点であるという事実と一致します。
