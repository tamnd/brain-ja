 ## 解決策
 ## 問題の理解

 絵文字値の配列がいくつかあります。 目的は、配列全体を並べ替えることではありません。 代わりに、配列の連続した部分を選択し、その部分内のいくつかの要素を削除して、残りの要素が非降順になるようにすることもできます。 選択した部分の前後の要素は重要ではないため、削除としてカウントされません。 

出力する必要がある最初の値は、残せる絵文字の最大数です。 2 番目の値は、そのような最適なシーケンスを取得するために、選択した間隔内で必要な削除された絵文字の最小数です。 

制約により、ほぼ線形の解が強制されます。 1 つのテスト ケースには最大 100,000 個の値を含めることができ、すべてのサイズの合計は最大 1000,000 です。すべての間隔を試行すると、すでに 2 次作業が行われ、最大のケースでは約 10^10 の演算が行われますが、これは制限をはるかに超えています。 O(N log N) メソッドが必要です。 

よくある間違いは、最長の減少しないサブシーケンスの長さだけを計算し、N からその値を引いた値を出力することです。 これにより、選択した間隔外の絵文字が削除されたものとしてカウントされますが、これは許可されていません。 たとえば、配列`1 2 3 100 0`を使用すると、長さ 4 の最長の非減少サブシーケンスがあります。`1 2 3 100`、しかし、答えは`0`間隔全体が選択された場合。 外側の要素は自動的には削除されません。 

もう 1 つのエッジ ケースは、配列全体がすでに減少していない場合です。 入力用`1 2 2 5`、正しい出力は次のとおりです。`4 0`。 削除された要素を常に次のようにカウントするソリューション`N - length`ここでは誤って動作する可能性がありますが、最良のサブシーケンスがより短い間隔内にある配列では失敗します。 

## アプローチ

 ブルートフォースアプローチは、可能なすべての間隔を試し、その中の最長の非減少サブシーケンスを計算し、最良の答えを保持することです。 O(N^2) 個の間隔があり、各間隔のサブシーケンスの計算にはすでにコストがかかるため、直接実装すると総作業量は O(N^3) になります。 

重要な観察は、残りの絵文字が元の配列の非減少サブシーケンスを形成する必要があるということです。 保持される絵文字の最大数は、減少しない最長のサブシーケンスです。 削除に関する追加の条件は、サブシーケンスの開始位置と終了位置を覚えておく必要があることを意味します。これは、それらの位置の間の要素のみを削除できるためです。 

最長の非減少サブシーケンスに対して忍耐のソートのアイデアを使用できます。 配列の処理中、サブシーケンスの長さごとに可能な最小の終了値を維持します。 その情報に加えて、最適なサブシーケンスを含む最適な間隔を再構築するのに十分な位置データを保持します。 

サブシーケンスの長さによって最初の答えが得られます。 選択された最適なサブシーケンスに最初のインデックスが設定されると、`l`そして最後のインデックス`r`、削除数は`(r - l + 1) - length`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N^3) | O(N) | 遅すぎる |
 | 最適 | O(N log N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 順序付けの目的のみで値を圧縮し、配列を左から右に処理します。 すべての値について、現在の要素によって拡張できる最適な非減少サブシーケンスを知る必要があります。 
2. 圧縮された値に対してフェンウィック ツリーを使用します。 各 Fenwick ノードは、そのプレフィックスの値で終わる最適なサブシーケンス状態を保存します。 状態には、サブシーケンスの長さ、その開始位置、および終了位置が含まれます。 
3. 現在値について`a[i]`、それ以下の以前の値をすべてクエリします。 返される最良の状態は、追加するため拡張できます。`a[i]`シーケンスを非減少に保ちます。 
4. 長さを 1 つ増やし、終了位置を に設定して、新しいステートを作成します。`i`。 圧縮された位置でフェンウィック ツリーを更新します。`a[i]`。 
5. すべての要素を処理した後、長さが最も大きい状態を選択します。 複数の状態の長さが同じ場合は、間隔サイズが最も小さい状態を選択します。 
6. 回答の長さは、選択された状態の長さです。 削除された絵文字の数は、その間隔のサイズから保持された長さを引いたものになります。 

なぜ効果があるのか:

 すべての有効な最終メッセージは、ある間隔内の非減少サブシーケンスに対応します。 フェンウィック ツリーでは、値がそれ自体より大きくない値で終わるサブシーケンスを正確に拡張できるため、考えられるすべての先行関係が考慮されます。 保存された最良の状態は、最適な結果をもたらす可能性のある候補を保存するため、最終的な最大長は可能な限り最長の非減少サブシーケンスとなり、選択された間隔は最適解の中で最小のものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(a):
    vals = sorted(set(a))
    comp = {v: i + 1 for i, v in enumerate(vals)}
    m = len(vals)

    bit = [(0, 0, 0)] * (m + 2)

    def better(x, y):
        if x[0] != y[0]:
            return x if x[0] > y[0] else y
        if x[0] == 0:
            return x
        sx = x[2] - x[1] + 1
        sy = y[2] - y[1] + 1
        return x if sx < sy else y

    def query(i):
        ans = (0, 0, 0)
        while i:
            ans = better(ans, bit[i])
            i -= i & -i
        return ans

    def update(i, value):
        while i <= m:
            bit[i] = better(bit[i], value)
            i += i & -i

    answer = (0, 0, 0)

    for i, x in enumerate(a):
        prev = query(comp[x])
        if prev[0] == 0:
            cur = (1, i, i)
        else:
            cur = (prev[0] + 1, prev[1], i)
        update(comp[x], cur)
        answer = better(answer, cur)

    return answer[0], answer[2] - answer[1] + 1 - answer[0]

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        x, y = solve_case(a)
        out.append(f"{x} {y}")
    print("\n".join(out))

if __name__ == "__main__":
    main()
```フェンウィック ツリーには、値の接頭辞に関する情報が保存されます。 以前に選択された値が現在の値を超えてはいけないため、プレフィックスのクエリはまさに非減少サブシーケンスに必要な操作です。 

状態には、長さだけではなく開始インデックスが保存されます。 これは、異常な削除ルールを処理する詳細です。 削除数に選択した間隔外の絵文字が含まれることを望まないため、間隔の境界を追跡する必要があります。 

絵文字の値は 10^9 まで大きくなる可能性がありますが、相対的な順序のみが重要であるため、圧縮された座標が必要です。 圧縮された値の数は最大 N であるため、すべての Fenwick 操作は O(log N) のままです。

## テストケース```python
import sys
import io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().strip().split()
    sys.stdin = old

    t = int(data[0])
    idx = 1
    ans = []
    for _ in range(t):
        n = int(data[idx])
        idx += 1
        arr = list(map(int, data[idx:idx+n]))
        idx += n
        x, y = solve_case(arr)
        ans.append(f"{x} {y}")
    return "\n".join(ans)

""") == "1 0"

""") == "5 0"

assert run("""1
5

""") == "1 0"

 ## 特殊なケース

 単一の絵文字の場合、選択された間隔にはその要素のみが含まれます。 このアルゴリズムは長さ 1 のサブシーケンスを作成し、間隔の長さも 1 であるため、削除の数は 0 です。 

値が繰り返される配列の場合、等価性が受け入れられる必要があります。 Fenwick クエリでは、現在の値以下の値が使用されます。これは、非減少シーケンスを処理する場合と厳密に増加するシーケンスを処理する場合の違いです。 

次のような配列を減少させる場合`5 4 3 2 1`、すべての要素は長さ 1 のサブシーケンスのみを開始できます。 このアルゴリズムは依然として正しい最大長を返し、選択された間隔の外側に不必要な削除を引き起こすことはありません。 

最適なサブシーケンスが無関係な要素に囲まれている場合、保存された開始位置と終了位置により、外側の要素が削除としてカウントされなくなります。 これが、この問題と通常の最長部分列問題との主な違いです。
