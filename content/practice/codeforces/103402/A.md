 ## 解決策
 ## セットアップ

 しましょう$a_{s+t-1}\dots a_1a_0$のバイナリ表現である$(s,t)$-組み合わせなので、それぞれ$a_i \in {0,1}$そして$\sum a_i = t$。 

長さのプレフィックスのローテーション$j+1$変身です$$a_j a_{j-1}\dots a_0 \;\leftarrow\; a_{j-1}\dots a_0 a_j,$$他のすべての桁は変更されません。 

目標は、すべてを示すことです$(s,t)$-この形式の連続したプレフィックス回転によって組み合わせを生成し、ビット文字列をマップする MMIX 命令シーケンスを導出することができます。$(a_{s+t-1}\dots a_0)_2$辞書編集上の後継者に$s+t<64$。 

## 解決策

 ### (a) 連続回転による生成

 しましょう$x = a_{s+t-1}\dots a_1a_0$バイナリで変換し、これらのビット文字列の辞書編集順に組み合わせを解釈します。 

させて$x$最終的ではないものでもよい$(s,t)$-組み合わせ。 書く$x$として$$x = u\,0\,1\,1^k\,0^\ell$$どこ$u$変更が可能な右から最初の位置がパターンで発生するような最長のプレフィックスです。$0,1$、 そして$1^k 0^\ell$は、固定重み条件によって決定されるゼロが続く末尾の 1 の最大の接尾辞です。 

同様に、標準の辞書編集上の後継形式では、次のようになります。$j$次のような最大のインデックスになります$$a_j = 0,\quad a_{j-1} = 1.$$そんな$j$文字列が存在しない限り存在します$1^t0^s$、これは端子の組み合わせです。 

サフィックスを分解してみましょう$j$なれ$$x = a_{s+t-1}\dots a_{j+1}\,0\,1\,a_{j-2}\dots a_0.$$させて$r$の数になります$1$にいる$a_{j-2}\dots a_0$。 の辞書編集上の後継者$x$交換することで得られます$01 \to 10$位置で$j,j-1$そして残りを移動します$r$できるだけ右のもの。 これにより、$$x' = a_{s+t-1}\dots a_{j+1}\,1\,0\,0^{s'}1^{r},$$一意に決定されたものに対して$s'$。 

次に接頭辞を考えてみましょう$a_j a_{j-1}\dots a_0$。 で$x$このプレフィックスの形式は次のとおりです$$a_j a_{j-1}\dots a_0 = 0\,1\,w,$$どこ$w$正確に含まれています$r$もの。 

で回転を適用します$j$:$$a_j a_{j-1}\dots a_0 \;\leftarrow\; a_{j-1}\dots a_0 a_j,$$したがって、プレフィックスは次のようになります$$1\,w\,0.$$接尾語$w$相対的な順序が維持され、単一の$0$回転したブロックの端に移動します。 この操作により、顕著な$1$ペアの左側$01$によって決定されたブロックを通過$w$これは、辞書編集の後続ルールで必要とされるものの再配布と正確に一致します。 

したがって、辞書編集順の各後続ステップは、右端の許容パターンの位置によって決定される単一の接頭辞ローテーションに対応します。$01$。 このルールを反復する$0^s1^t$に達する$(s,t)$- 各ステップで辞書編集上の後続が生成され、プロセスが終了するため、組み合わせは 1 回だけです。$1^t0^s$。 

これで証明は完了です。 ∎

 ### (b) 後継の MMIX 実装

 ビット文字列をレジスタに格納します$rA$、 と$s+t<64$したがって、ワード操作は有効です。 

固定ポップカウントのバイナリ ワードの辞書編集上の後継言語の標準 ID は次のとおりです。$$\text{next}(x) = r \;\;|\;\; \left(\frac{(r \oplus x) \gg 2}{c}\right),$$どこ$$c = x \,\&\, (-x), \quad r = x + c.$$これは、同じ数の次の整数を生成するよく知られた Gosper 変換と同等です。$1$一致するビット$(s,t)$-セクション 7.2.1.3 のバイナリエンコーディングに基づく組み合わせ。 

MMIX でのレジスタの使用$rA$(入力/出力)、$rB$、$rC$、$rD$:```
        SET     rB, rA
        NEG     rC, rA          % rC = -x
        AND     rC, rA, rC       % c = x & (-x)

        ADD     rD, rA, rC       % rD = r = x + c

        XOR     rB, rD, rA       % rB = r ^ x
        SR      rB, rB, 2        % rB = (r ^ x) >> 2
        DIV     rB, rB, rC       % rB = ((r ^ x) >> 2) / c

        OR      rA, rD, rB       % result = r | ...
```の出力$rA$入力が端末でない場合は常に、入力の組み合わせの辞書編集上の後続文字です。 

正確さは、標準の固定ポップカウント後継アイデンティティに基づいており、ポップカウントの数が保存されます。$1$ビットを分割し、辞書編集順に一致する最小の大きい整数を生成します。$(s,t)$- バイナリエンコーディングでの組み合わせ (セクション 7.2.1.3 の式 (2) ～ (4))。 

## 検証

 各操作はプレフィックス内のエントリのみを並べ替えるため、ローテーション ルールではビットのマルチセットが保持されます。$1$残っている$t$。 

選択した回転によりバイナリ値が辞書編集順に増加するため、各ステップでバイナリ値が増加します。$1$許容される右端の下の位置から$01$ゼロを左に押しながらパターンをより高い位置に移動し、固定重みを持つバイナリ文字列の後続変換と一致させます。 

MMIX シーケンスは、可逆算術恒等式のみを使用します。$c = x & (-x)$そして代数分解$x = r - c$、すべての中間値が 64 ビット レジスタ モデルで明確に定義されたままであることを保証します。$s+t<64$。 

## 注意事項

 回転の解釈は、組み合わせの回転ドア生成の循環形式に対応しており、各遷移は単一の移動を行います。$1$グローバルな並べ替えを実行するのではなく、制御されたプレフィックス サイクルを通じて。 

MMIX 式は、Knuth のマシン モデルに適合した古典的な Gosper の「次の組み合わせ」計算であり、セクション 7.2.1.3 で使用されるバイナリ エンコーディングの辞書編集上の後継のものと一致します。
