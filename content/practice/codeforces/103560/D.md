 ## 解決策
 ## 問題の理解

 それぞれのキャンディーが何らかの種類に属するキャンディーの入った箱が与えられます。 種類ごとに、その種類のキャンディーが何個存在するかを数えることができます。 このプールからいくつかのキャンディーを選択して「ギフト」を組み立てたいと思います。 

この制限は構造的なものです。最終的なギフトを見て、キャンディーをタイプごとにグループ化する場合、各タイプの選択されたキャンディーの数は、選択された他のすべてのタイプとは異なっていなければなりません。 言い換えれば、タイプ 1 がギフトに 5 回表示され、タイプ 2 が 3 回表示される場合、他の選択されたタイプは 5 回または 3 回正確に表示されることは許可されません。 一部のタイプは完全にスキップされる場合があり、選択したタイプについては、利用可能な供給量まで自由に正の数を取得できます。 

目的は、ギフト内のキャンディーの総数 (選択されたすべてのタイプの選択された数の合計) を最大化することです。 

これはグローバルな割り当ての問題です。整数の「クォータ」を容量制約の下でタイプに分配します (各タイプには最大頻度があります)。同時に、選択されたすべてのクォータがペアごとに異なることを強制し、それらの合計を最大化したいと考えています。 

制約は大きく、合計入力サイズはクエリ全体で最大約 20 万個のキャンディーになります。 これにより、すべての値に対する二次シミュレーションまたはクエリごとのネストされたシミュレーションが除外されます。 クエリごとにほぼ線形演算よりも遅いものは失敗します。 

周波数が非常に小さい場合、または非常に繰り返しが多い場合には、微妙なエッジ ケースが発生します。 たとえば、すべてのタイプが何度も出現する場合、キャパシティが存在する場合でも、大きな均等なクォータを割り当てることはできません。 逆に、多くの型が一度に出現する場合、重複が禁止されているため、すべての型に値 1 を割り当てることはできません。 

たとえば、それぞれ 2 回出現する 3 つのタイプがあるとします。 単純なアプローチでは 2、2、2 を割り当てる可能性がありますが、これは区別性ルールに違反します。 正しい動作は、2、1、0 を割り当て、合計が 3 になることです。もう 1 つのエッジ ケースは、多数の出現を伴う単一タイプであり、答えは単純にそのすべてです。 

これらのパターンは、単に型ごとの使用量を最大化するのではなく、割り当てられた値の間隔を注意深く配置していることを示唆しています。 

## アプローチ

 ブルートフォース戦略では、バックトラックまたは貪欲な推測によって各型に値を割り当てようとします。 タイプごとに、その頻度から 1 までの可能なすべてのカウントを試し、重複が使用されていないことを確認できます。 これはすぐに組み合わせ爆発を引き起こします。 最大 n までの頻度のみを考慮する場合でも、k 個の型にわたってすべての代入を試みると、型ごとに n 個の選択肢が得られ、これは k で指数関数的になります。 最大 20 万の要素では、これは不可能です。 

重要な観察は、正確にどのキャンディーが使用されるかではなく、最終的に選択されたカウントのみが重要であるということです。 各タイプの頻度を計算すると、問題は次のようになります。0 ≤ x_i ≤ c_i となるような整数 x_i を各タイプに割り当て、すべての正の x_i は個別であり、x_i の合計を最大化します。 

これは典型的な貪欲な構造です。 頻度の降順でタイプを並べ替える場合、常に、余裕のあるタイプにより大きなクォータを与えたいと考えます。 理由は簡単です。周波数を大きくすると柔軟性が増すため、大きな値を予約する必要があります。 より小さい周波数には制約があり、より小さいクォータを吸収するか、削除する必要があります。 

次に、可能な最大のクォータから下方向にソリューションを構築します。 私たちは、割り当て可能な最大の割り当てを維持します。 各周波数に対して降順で、以前に使用したものよりも厳密に小さく、かつその容量を超えない最大の有効な数値を割り当てます。 容量が小さすぎる場合は、その容量を引き継いで減少を続けます。

この構造が機能するのは、制約が「割り当てられた値はすべて異なるものである必要がある」だけであるためです。 これは、割り当てられた値の順列は実行可能性を変えることなくソートでき、値が大きいほど常に合計に大きく寄与するため、減少するシーケンスが最適であることを直ちに示唆します。

 ## アルゴリズムのチュートリアル

 まず、入力を各キャンディー タイプの周波数に圧縮します。 これにより、問題は個々の項目を扱うことから、複数の容量セットを扱うことに変わります。 

## アルゴリズムのチュートリアル

 1. 各タイプが出現する回数を数え、頻度の配列を生成します。 このステップが必要なのは、個々のキャンディーの ID ではなく、タイプごとのカウントのみが重要であるためです。 
2. 周波数配列を降順に並べ替えます。 これにより、実際にサポートできる型に大きなクォータを常に割り当てるように努め、小容量の型で高い値が早期に無駄になることを防ぎます。 
3. 変数を初期化する`cap`非常に大きな数であり、概念的には無限ですが、どの型も n 個を超えるキャンディーを受け取ることができないため、n のようなものとして実装されます。 
4. 並べ替えられた順序で周波数を繰り返します。 周波数ごとに`f`、値を割り当てたい`x`これは、≤ f であり、最後に割り当てられた値よりも厳密に小さい値です。`cap`。 
5.セット`x = min(f, cap - 1)`。 これにより、両方の制約が同時に適用されます。可用性を超えず、割り当てを厳密に減らすことで区別性を維持します。 
6. もし`x`ゼロまたは負になると、それ以上正の代入ができないため、プロセスを停止します。 残りのタイプはすべて何も貢献しません。 
7. それ以外の場合は追加します`x`答えと更新へ`cap = x`。 これにより、一意性を維持しながら、次に割り当てられる値が厳密に小さくなる必要があります。 

このプロセスでは、選択されたカウントの厳密に減少するシーケンスが構築され、それぞれのカウントは対応する周波数によって制限されます。 

### なぜ効果があるのか

 すべてのステップで、以前に選択されたすべての値が個別で大きいという制約の下で、現在の型に対して可能な最大の有効な値が決定されます。 周波数を降順で処理するため、早めに大きな値を割り当てたことを後悔することはありません。後で割り当てると容量はさらに小さくなり、スワップしても合計は増加しません。 貪欲な不変条件は、i 型を処理した後、i 個の別個の正の整数を使用して、それぞれの周波数限界を尊重し、可能な最大合計を構築しており、同じプレフィックス長を持つ代替配置は、順序付けまたは実現可能性に違反することなくその合計を超えることはできないということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    q = int(input())
    for _ in range(q):
        n = int(input())
        freq = {}
        for _ in range(n):
            a = int(input())
            freq[a] = freq.get(a, 0) + 1

        vals = sorted(freq.values(), reverse=True)

        cap = n
        ans = 0

        for f in vals:
            x = min(f, cap - 1)
            if x <= 0:
                break
            ans += x
            cap = x

        print(ans)

if __name__ == "__main__":
    solve()
```タイプごとのカウントのみが重要であるため、コードは各クエリを頻度マップに圧縮することから始まります。 降順での並べ替えは貪欲な戦略の根幹であり、常に最も柔軟なタイプを最初に考慮するようにします。 

変数`cap`割り当てのために残された使用可能な最大値を追跡します。 有効な割り当てはキャンディーの数を超えることができないため、n から始まります。 各ステップで、周波数と電流キャップから 1 を引いた値の両方によってクランプし、厳密な減少を保証します。 

ここでよくある間違いは、`-1`次に許可される値を計算するとき。 これがないと、等しい連続した割り当てが出現し、個別性制約に違反する可能性があります。 

早めの休憩のとき、`x <= 0`少なくとも 1 を割り当てることができないと、残りの寄与はすべてゼロになるため、これは重要です。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての周波数が 1 の場合です。アルゴリズムは 1 を割り当て、次に 0 を割り当て、すぐに停止します。 これにより、すべての型を誤って合計するのではなく、多くの型に対して 1 が正しく生成されます。 

もう 1 つのエッジ ケースは、頻度が非常に高い単一タイプです。 厳密に減少する正のシーケンスを維持する必要があるため、アルゴリズムはそれを正しく n-1 に削減します。 

3 番目のケースは、それぞれ周波数 3 を持つ複数のタイプなど、中間周波数が多数ある場合です。貪欲な順序により、最初のいくつかのタイプに 3、2、1 が割り当てられ、その後停止されます。 等しい値を割り当てようとすると制約に違反するため、上限を減らすメカニズムによって自然に正確さが強制されます。
