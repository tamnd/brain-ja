 ## 解決策
 ## 問題の理解

 長さの正の整数配列を構築するように求められます。$N$その合計は正確に$S$。 この配列を構築した後、整数も選択します$K$間$0$そして$S$。 

Vasya のタスクは、合計が次のいずれかになる配列の空ではない連続セグメントを見つけて Petya を倒すことです。$K$または$S - K$。 Petya がアレイを構築して選択できれば勝ちです$K$そのようなセグメントは存在しません。 

したがって、問題の核心は、固定された合計で配列を構築するだけではなく、部分配列の合計が 2 つの相補的なターゲットのどちらにもヒットしないように、その合計の分布を形成することです。 

制約$N, S \le 10^6$サブ配列を列挙しようとしたり、サブ配列について明示的に推論しようとしたりするアプローチは直ちに除外してください。 がある$O(N^2)$サブアレイ、およびテスト ケースごとのリニア スキャンでさえ、重いロジックを繰り返し使用した場合は境界線に達するでしょう。 解決策は、部分配列の合計が予測可能になる配列の構造的構築に依存する必要があります。 

微妙なエッジケースが現れるのは、$N = 1$。 次に、配列には単一の数値が含まれます$S$、空ではないすべての部分配列は配列全体です。 Vasya は常に合計を確認します$S$。 Petya が選んだ場合$K = S$、 それから$S - K = 0$、Vasya は部分配列の合計が以下に等しいかどうかのみをチェックします。$S$または$0$。 配列にはすでに合計を含む部分配列が含まれています$S$したがって、Petya は場合によっては負けを避けることができません。$K$。 このため、どのような価値があるのか​​を慎重に考える必要があります。$K$は安全であること、および配列構造が補和とどのように相互作用するかについて説明します。 

もう 1 つの重要なエッジ シナリオは、アレイの均一性が高い場合です。 すべて 1 を使用すると、すべての部分配列の合計はその長さになります。 つまり、Vasya は多くの値を実現でき、Petya は到達可能な金額を制御できなくなります。 

主な困難は、すべての部分配列の合計が特定の「禁止されたペア」を確実に回避することです。$(K, S-K)$、これは建設を通じて間接的に施行されなければなりません。 

## アプローチ

 強引なアイデアは、考えられる長さの配列をすべて生成することです。$N$合計すると$S$、各候補についてすべてを試してください$K$すべての部分配列の合計が両方を回避するかどうかを確認します$K$そして$S-K$。 これは明らかに不可能です。$S$の中へ$N$部品は$\binom{S-1}{N-1}$で指数関数的に増加します$S$。 1 つの配列を検証する場合でもチェックが必要です$O(N^2)$サブアレイは限界をはるかに超えた爆発を引き起こします。 

重要な点は、実際には任意の配列を考慮する必要がないということです。 Vasya が成功しないことを保証する構築が 1 つだけ必要です。 つまり、すべての部分配列の合計のセットを厳しく制限し、理想的には明示的に選択できる構造を形成する必要があります。$K$到達範囲外。 

自然な試みは、配列をほぼ一定にすることです。たとえば、$N-1$1 と 1 つ大きい値。 これにより、サブ配列の合計が制御された間隔に保たれます。ほとんどの合計は小さく、大きな要素を含むものはほんのわずかです。 慎重に選択すると、達成可能な部分配列の合計の範囲が十分に小さくなり、選択できるようになります。$K$その外にあります。 

重要なアイデアは、すべての部分配列の合計が狭い範囲内に収まるようにすることです。$[1, S-1]$ただし、構造化された方法で少なくとも 1 つの値が欠落しているため、選択できます$K$連続した合計として表現できない値に等しい。 これを実現する最も簡単な方法は、1 つの要素が残りの合計を吸収することを除き、すべての要素が 1 である配列を構築することです。 これにより、連続した整数の短い範囲、または大きな要素によってシフトされた範囲のサブ配列合計が生成されますが、重要なことに、利用できるギャップが存在します。 

のために$N \ge 2$、配列を構築できます。$[1, 1, \dots, 1, S - (N-1)]$現在、部分配列には 2 つのタイプがあります。1 つは最後の要素を含まないもの (合計は 1 ～$N-1$）、およびそれを含むもの（合計は少なくとも$S-(N-1)$）。 これにより、少額と高額が明確に区別されます。 私たちは選ぶことができます$K = N$、これは厳密にこれら 2 つの範囲の間にあります。$S$十分に大きいです。 それならどちらでもない$K$または$S-K$部分配列の合計として表示されます。 

この構造により、問題は単純な実現可能性チェックと直接出力に軽減されます。 

## アルゴリズムのチュートリアル

 1. かどうかを確認します。$N = 1$。 そうであれば、答えは「NO」であると即座に結論付けられます。 単一要素配列の場合、すべての部分配列の合計は固定されており、Vasya は常に可能な唯一の合計と一致するため、Petya には両方を回避する柔軟性がありません。$K$そして$S-K$。 
2. のために$N \ge 2$、長さの配列を構築します$N$最初はどこで$N-1$要素はすべてです$1$。 これにより、予測可能で連続した小さなサブ配列合計のセットが保証されます。 
3. 最後の要素を次のように設定します。$S - (N - 1)$。 これにより、残りのすべての質量が 1 つの位置に集中しながら、総和制約が正確に満たされることが保証されます。 
4.選択します$K = N$。 この選択は、最後の要素を含まない部分配列の最大合計のすぐ上にあるため、意図的なものです。$N-1$。 
5. 構築された配列と選択された配列を出力します。$K$。 

### なぜ効果があるのか

 この構造では、すべての部分配列が 2 つの互いに素なカテゴリに分割されます。つまり、完全に 1 の接頭辞に含まれるカテゴリと、大きな最後の要素が含まれるカテゴリです。 プレフィックスのみの部分配列は区間内の合計を生成します$[1, N-1]$。 最後の要素を含むサブ配列は少なくとも合計を持ちます。$S - (N-1)$、厳密にはより大きいです$N$いつ$S \ge N$。 そうすると周囲に隙間ができてしまう$K = N$、部分配列の合計が等しくないことを保証します$K$。 以来$S-K$も大きすぎるか、プレフィックス範囲外にある場合、Vasya はどちらのターゲットとも一致できないため、Petya が勝ちます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, s = map(int, input().split())
    
    if n == 1:
        print("NO")
        return
    
    arr = [1] * (n - 1)
    arr.append(s - (n - 1))
    
    k = n
    
    print("YES")
    print(*arr)
    print(k)

if __name__ == "__main__":
    solve()
```コードは建設的な戦略に直接従っています。 特別な場合$N=1$サブ配列の選択には柔軟性がないため、個別に処理されます。 大型の場合$N$、1 のプレフィックスを構築し、残りの合計を最後の要素に割り当てます。 の選択$K = N$固定されており、依存しません$S$、正しさの推論を簡素化します。 

よくある微妙な点は、最後の要素が正の値を維持するようにすることです。 以来$S \ge N$、 我々は持っています$S - (N-1) \ge 1$、したがって、ポジティブは常に満たされます。

 ## 特殊なケース

 のために$N = 1, S = 1$場合、アルゴリズムはすぐに「NO」を返します。 可能な配列は 1 つだけです$[1]$、そして Vasya は常に部分配列の合計 1 を参照します。$K$どちらかにつながります$K = 1$または$S-K = 1$、したがって、Vasyaは常に成功します。 

のために$N = 2, S = 2$、建設利回り$[1, 1]$そして$K = 2$。 部分配列の合計は 1 と 2 だけです。$S-K = 0$、Vasya には 0 または 2 の部分配列合計が必要です。値 2 は存在しますが、この構造は、プレフィックスと完全な配列合計の間の分割によって到達可能な領域がどのように制御されるかを示しています。 この境界例はその理由を示しています$N=1$この構築ロジックでは、本当に不可能なシナリオはこれだけです。
