 ## 解決策
 ## 問題の理解

 すべての要素が小さな整数、具体的には 6 ビット値である配列が与えられます。 この配列から、空ではない任意のサブシーケンスを選択できます。つまり、ビット単位の演算では順序は実際には重要ではありませんが、順序を維持しながらインデックスの任意のサブセットを選択できます。 

選択したサブシーケンスごとに、選択したすべての値のビット単位の AND を計算します。 これにより、0 ～ 63 の間の別の数値が生成されます。次に、バイナリ表現で正確に k ビットが設定されている、結果の AND 値の数を数えます。 最終的な答えは、個別の結果の数ではなく、有効なサブシーケンスの数です。 

重要な問題は、部分列が n とともに指数関数的に増加することです。 n = 40 の場合でも、ブルート フォースはすでに境界線になっています。 ここで、n は 2 × 10^5 に達する可能性があるため、指数列挙は不可能です。 値が小さく、AND 演算が制限的であるという事実を利用する必要があります。 

ゼロが存在する場合、微妙なエッジケースが発生します。 ゼロを含むサブシーケンスは、他の要素に関係なく、AND 結果としてゼロになります。 たとえば、配列が [0, 7] の場合、0 を含むすべてのサブシーケンスは AND = 0 を持ち、0 を含まないサブセットのみが通常どおり動作します。 k = 0 の場合、これらは非常に支配的になります。 ゼロを通常の値のように扱う単純なアプローチでは、ゼロはすべてのビットを消滅させるため、カウントを誤ることがよくあります。 

もう 1 つの特殊なケースは、k = 0 の場合です。AND にビットが設定されていないサブシーケンスを数えています。つまり、AND が 0 に等しいことを意味します。これには、共有ビットの競合により崩壊する多くの組み合わせが含まれます。 ビットカウントロジックだけでは十分ではないため、k = 0 を均一に処理することが重要です。 構築中にビット数だけでなく、正確な AND 状態を追跡する必要があります。 

## アプローチ

 直接的なアプローチは、すべてのサブシーケンスを列挙し、それらの AND を計算し、ビット数をチェックすることです。 各サブシーケンスの AND 計算では最大 n 個の要素をスキャンする可能性があるため、これには O(2^n · n) 時間が必要です。 メモ化しても部分列の数が支配的になるため、n ≈ 25 を超えると実行できなくなります。 

重要な観察は、各要素が 6 ビット マスクであるため、すべての AND 結果も 0 ～ 63 の範囲内であるということです。これにより、状態空間が指数関数的なサブセットから 64 個の可能な AND 値のみに大幅に減少します。 サブセットを直接追跡する代わりに、考えられる各 AND 結果を生成するサブシーケンスの数を追跡します。 

要素を 1 つずつ処理し、DP 配列を維持します。ここで、 dp[mask] は、プレフィックスを処理した後の AND がマスクと等しいサブシーケンスの数です。 新しい値 x が表示されると、既存の各サブシーケンスは x を除外するか、x を含みます。 x を含めると、既存の AND 値 m が (m & x) に変換されます。 x を除外すると、m は変更されません。 x だけからなる新しい部分列もカウントします。 

この遷移が機能するのは、AND がビット交差に関して結合的かつ単調であるためです。つまり、要素を追加してもビットが削減または保持されるだけです。 したがって、64 状態空間全体にカウントをきれいに伝播できます。 

最後に、popcount が k に等しいすべてのマスクの dp[mask] を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | お(1) | 遅すぎる |
 | ビットマスク DP オーバー AND 状態 | O(n · 64) | お(64) | 承認済み |

 ## アルゴリズムのチュートリアル

 すべての可能な AND 結果に対して度数表を維持します。

1. サイズ 64 の配列 dp をすべて 0 で初期化します。 これは、各 AND マスクを生成するサブシーケンスの数を表します。 
2. 配列内の各数値 x を反復処理します。 
3. dp のコピーとして初期化された新しい配列 ndp を作成します。 これは、以前のすべてのサブシーケンスが変更されない「x を取らない」ケースを処理します。 
4. 0 ～ 63 のマスク m ごとに、dp[m] を追加して ndp[m & x] を更新します。 これは、x を含めることによって既存の各サブシーケンスを拡張し、その AND 値を更新することを表します。 
5. ndp[x] をインクリメントすることで、x のみからなる新しい部分列も考慮します。 
6. dp を ndp に置き換えます。 
7. すべての要素を処理した後、popcount が k に等しいすべてのマスクの dp[mask] を合計します。 

最初に dp をコピーする必要がある理由は、各要素がサブシーケンスの状態遷移ごとに 1 回だけ考慮される必要があるためです。 インプレースで更新を混合すると、単一の反復内で同じ要素が誤って複数回再利用されます。 

### なぜ効果があるのか

 すべてのサブシーケンスは、要素に対する包含決定の一意のシーケンスに対応します。 DP 状態は、同じ結果の AND 値を共有するすべてのサブシーケンスを圧縮します。 すべてのサブシーケンスが現在の要素を使用しないか、または 1 回だけ使用し、AND 演算によって古い状態が新しい状態に決定的にマップされるため、遷移は正確さを維持します。 考えられるすべての遷移がカバーされ、単一の反復内で状態が二重にカウントされることはないため、 dp は常に、処理されたプレフィックスのサブシーケンス AND 結果の正確な分布を反映します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    dp = [0] * 64
    
    for x in a:
        ndp = dp[:]  # not take x
        
        # take x as a new subsequence
        ndp[x] = (ndp[x] + 1) % MOD
        
        # extend existing subsequences
        for m in range(64):
            if dp[m]:
                ndp[m & x] = (ndp[m & x] + dp[m]) % MOD
        
        dp = ndp
    
    ans = 0
    for m in range(64):
        if bin(m).count("1") == k:
            ans = (ans + dp[m]) % MOD
    
    print(ans)

if __name__ == "__main__":
    t = int(input())
    for _ in range(t):
        solve()
```DP アレイ`dp`可能な各 AND マスクを生成するサブシーケンスの数を追跡します。 重要な実装の詳細は、各要素を処理する前に配列をコピーし、同じ反復からの更新を再利用しないようにすることです。 

ライン`ndp[m & x] += dp[m]`は唯一の遷移です。現在の要素を含めてエンコードされます。 明示的な`ndp[x] += 1`シングルトンのサブシーケンスが確実にカウントされるようにします。 

最後に、k に等しいポップカウントによってマスクをフィルターします。 マスクは 0 ～ 63 のみであるため、この最終スキャンはテストごとに一定時間になります。 

## 実用的な例

 ### 例 1

 入力:```
3 1
1 3 2
```マスク上の dp を追跡します。 

| ステップ | × | 前の dp | トランジションのハイライト | |後の dp
 | --- | --- | --- | --- | --- |
 | 1 | 1 | {0:0} | 新しいサブシーケンスを開始 | {1:1} |
 | 2 | 3 | {1:1} | 1&3=1、プラスシングルトン 3 | {1:2、3:1} |

 ポップカウント 1 のマスクは 1、2、4、8、16、32 です。ここでは 1 と 2 のみが寄与し、答えは 3 になります。 

このトレースは、AND がどのようにビットを徐々に縮小し、時間の経過とともにより小さなマスクを生成するかを示しています。

 ## 特殊なケース

 重要なエッジケースは、多数のゼロが表示される場合です。 のような入力の場合`[0, 0, 0]`、空でないすべてのサブシーケンスは 0 に等しい AND を持ちます。x = 0 を含むすべての遷移はすべてのマスクを 0 にマップし、dp[0] にカウントが正しく蓄積されるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのケースは、すべての数値が同一である場合です。 各包含により組み合わせが 2 倍になりますが、AND は変更されません。 DP はカウントを 1 つのマスクに蓄積し、popcount フィルタリングは k に応じてすべてのサブシーケンスをカウントするか、まったくカウントしません。 

値に [1, 2, 4, 8] などの互いに素なビットがある場合、異なる要素間のすべての AND は 0 になります。DP はすべての混合サブシーケンスをマスク 0 に正しくルーティングしますが、シングルトン サブシーケンスは区別されたままであり、ビット交差の組み合わせ構造と一致します。
