 ## 解決策
 ## 問題の理解

 固定の 4 × 4 ボードでターンベースの配置ゲームをプレイしているため、合計で 16 個のセルしかありません。 テトロミノ駒はT字型駒とL型駒の2種類があります。 提供される供給量は限られており、各タイプ最大 3 個までです。 プレイヤーは交互にターンを行い、ターンでは、プレイヤーはいずれかのタイプの残りの駒を 1 つ選択し、駒の 4 つのセルすべてがグリッド内にあり、既に占有されているセルと重ならない限り、任意の向きでボード上に配置します。 一度配置すると、作品は永久に残ります。 自分のターンに有効な配置を行えなかったプレイヤーは負けます。 

入力は、T 個と L 個の初期カウントのみで構成されます。 ボードは空から始まると仮定します。 タスクは、最初のプレーヤーが最適なプレイの下で強制的に勝利するかどうかを判断することです。 

重要な構造上の制約は、システムが極度に小さいことです。 ボードはサイズ 2^16 の状態空間に寄与し、各ピース数は 0 ～ 3 で制限されます。すべてのボード構成と残りのピース数にわたる完全な状態探索も実現可能です。 これにより、貪欲な推論や組み合わせゲーム理論の閉じた形式への還元など、漸近的な最適化トリックの必要性が即座に排除されます。 ゲームグラフ全体の走査は許容されます。 

唯一の微妙なエッジ ケースは、ジオメトリと可用性の間の相互作用から生じます。 ピースが残っている場合でも、空きスペースの断片化により配置できない場合があります。 たとえば、ボード上に有効なテトロミノの形を形成できない単一の空のセルが散在している状態を考えてみましょう。 このような場合、x > 0 または y > 0 であっても、配置が存在しないため、プレイヤーは負ける可能性があります。 もう 1 つのエッジ ケースは、ピース タイプが使い果たされても、もう一方のピース タイプにはまだ配置がある場合です。 ゲームは続行されますが、移動オプションは減少するため、評価はカウントとジオメトリの両方に同時に依存する必要があります。 

## アプローチ

 ブルートフォース戦略は、あらゆるゲーム状態を明示的にモデル化します。 状態は、4 × 4 グリッドの現在の占有率と T ピースと L ピースの残りの数によって定義されます。 特定の状態から、利用可能なすべての駒タイプの可能なすべての合法的な配置を列挙し、結果の状態に移行し、その状態が勝っているか負けているかを再帰的に判断します。 少なくとも 1 つの手が相手の負け状態につながる場合、現在の状態は勝ちです。 

このアプローチは、有限のゲーム グラフ上で最適なプレイの定義を直接実装しているため、正しいです。 ただし、その効率は、存在する状態の数と遷移のコストによって異なります。 グリッドだけで 2^16 の構成が得られ、これをピース数と組み合わせると、およそ 2^16 × 4 × 4 の状態が得られます。 各状態では可能なすべての配置が試行され、各配置では 4 セル パターンをチェックする必要があります。 これは大きいとはいえ、それでも数百万回の遷移以内であり、メモ化を使用した Python では許容範囲です。 

これを実行可能にする重要な観察は、ボードが小さくて静的であるため、ゲーム全体を状態の有向非巡回グラフとして扱うことができ、メモ化を使用して各状態を 1 回評価できることです。 状態空間自体は十分に小さいため、網羅的に探索する必要はありません。ヒューリスティックな枝刈りや代数的単純化は必要ありません。

 ## アルゴリズムのチュートリアル

 16 ビット マスクを使用してボードを表します。各ビットは行優先の順序で 1 つのセルに対応します。 また、T ピースと L ピースが何個残っているかも追跡します。

1. 4 × 4 グリッド上の T および L テトロミノのすべての有効な配置を事前計算します。 各配置は、それが占めるセルを示す 16 ビット マスクとして保存されます。 これにより、再帰中の幾何学的妥当性の再計算が回避されます。 
2. 現在のプレーヤーがこの状態から勝利する戦略を持っているかどうかを返す関数 win(mask, xt, yl) を定義します。 
3. 状態から有効な手が存在しない場合、つまり空のセルに収まる残りの駒の配置がない場合、その状態は負けです。 これにより、プレイヤーが行き詰まった最終的な状態がキャプチャされます。 
4. それ以外の場合は、事前に計算されたすべての T 配置を繰り返します。 配置がスペースで使用されておらず、xt > 0 の場合、それを適用し、結果の状態を xt - 1 で再帰します。結果の状態が対戦相手に負けている場合は、現在の状態を勝利としてマークします。 
5. yl > 0 の場合、L 個の配置に対して同じロジックを繰り返します。 
6. どの手が相手の負けにつながらない場合、現在の状態は負けです。 

中心となる考え方は、移動するたびに残りの部分または空のセルの数が減少するため、状態空間が遷移に沿って厳密に減少し、再帰の終了が保証されるということです。 

正しさは標準的なミニマックス不変式にかかっています。つまり、対戦相手を強制的に負け状態に追い込む動きが少なくとも 1 つ存在する場合にのみ、状態は勝利となります。 考えられるすべての動きが明示的に考慮され、メモ化されるため、各状態はその子を完全に把握した状態で 1 回だけ評価され、循環依存や分岐の欠落がないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from functools import lru_cache

H = 4
W = 4
N = H * W

def cell(r, c):
    return r * W + c

def normalize(shape):
    xs = [x for x, y in shape]
    ys = [y for x, y in shape]
    minx, miny = min(xs), min(ys)
    norm = sorted((x - minx, y - miny) for x, y in shape)
    return tuple(norm)

def rot(shape):
    return [(y, -x) for x, y in shape]

def reflect(shape):
    return [(-x, y) for x, y in shape]

def to_mask(shape, dr, dc):
    mask = 0
    for x, y in shape:
        r = dr + x
        c = dc + y
        if r < 0 or r >= H or c < 0 or c >= W:
            return None
        mask |= 1 << cell(r, c)
    return mask

def gen_shapes(base):
    res = set()
    shapes = [base]
    for _ in range(4):
        new_shapes = []
        for s in shapes:
            rs = rot(s)
            new_shapes.append(rs)
            new_shapes.append(reflect(s))
        shapes = [normalize(s) for s in new_shapes]
        for s in shapes:
            res.add(s)
    return res

# Base T and L shapes (unanchored)
base_T = [(0,0),(1,0),(2,0),(1,1)]
base_L = [(0,0),(0,1),(0,2),(1,2)]

T_shapes = gen_shapes(base_T)
L_shapes = gen_shapes(base_L)

T_masks = []
L_masks = []

for shape in T_shapes:
    for r in range(H):
        for c in range(W):
            m = to_mask(shape, r, c)
            if m is not None:
                T_masks.append(m)

for shape in L_shapes:
    for r in range(H):
        for c in range(W):
            m = to_mask(shape, r, c)
            if m is not None:
                L_masks.append(m)

@lru_cache(None)
def win(mask, xt, yl):
    # try T
    if xt > 0:
        for m in T_masks:
            if (mask & m) == 0:
                if not win(mask | m, xt - 1, yl):
                    return True
    # try L
    if yl > 0:
        for m in L_masks:
            if (mask & m) == 0:
                if not win(mask | m, xt, yl - 1):
                    return True
    return False

def solve():
    x, y = map(int, input().split())
    print("Alice" if win(0, x, y) else "Bob")

if __name__ == "__main__":
    solve()
```このソリューションでは、2 つのテトロミノ タイプのすべての幾何学的実現を 4 × 4 グリッド上に構築し、それぞれをビットマスクとしてエンコードします。 その後、再帰は純粋に組み合わせになります。各移動はビットマスク OR 演算であり、有効性はビットごとの AND による重複のチェックに限定されます。 

メモ化デコレーターは、ボードの状態と残りの駒の各組み合わせが 1 回解決されることを保証します。 これは、指数関数的なゲーム ツリーが完全に拡張されないようにするための重要な実装の詳細です。

 ## 特殊なケース

 x と y の両方が 0 の場合、再帰にはルート状態から利用できる遷移がありません。 この関数はすぐに false を返し、最初のプレーヤーの負けの立場を反映します。 

駒が 1 種類しか存在しない場合、ゲームはそのテトロミノの配置が存在するかどうかを確認することになります。 再帰は、可用性と幾何学的適合の両方を満たす移動のみを考慮するため、これを正しく処理します。 

部分的な配置で孤立したセルが残った後など、ボードが断片化した場合でも、すべての動きが事前計算されたマスクに対して検証されるため、アルゴリズムは引き続き正しく評価されます。 たとえピースが残っていたとしても、有効なマスクが適合しない可能性があり、その状態が正しく負けとして認識されることになります。
