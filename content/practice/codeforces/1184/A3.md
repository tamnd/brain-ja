 ## 問題の理解

 同じ長さの 2 つの文字列が与えられており、多項式ローリング ハッシュの下で衝突を強制したいと考えています。 ハッシュは、各文字列を基底の多項式の係数として解釈することによって定義されます。$r$、そしてそれを素数を法として評価します$p$。 具体的には、各文字はその値に次の累乗を乗算して貢献します。$r$、すべてが剰余になります$p$。 

タスクはハッシュを計算することではなく、パラメーターを構築することです。 素数を選ばなければなりません$p$指定された範囲および整数ベースで$r$そのため、両方の文字列がその係数と基数に基づいてまったく同じハッシュ値を生成します。 

重要な隠された構造は、これがランダムなハッシュに関するものではないということです。 2 つの文字列から導出された整数係数を使用して 2 つの多項式間のモジュラー等式を作成するように求められています。 

この制約により、候補者ごとの強引な攻撃は避けられます。$p$または$r$。 文字列は最大で$10^5$したがって、多くの素数または塩基のハッシュを評価しようとする試みは、単純に繰り返されると非常に遅くなります。 単一のハッシュ評価は線形であるため、多くの候補をテストするとすぐに許容限界を超えてしまいます。 

文字列が同一の場合、微妙なエッジケースが発生します。 その状況では、すべての有効なペアが$(p, r)$限り働く$r \in [2, p-2]$。 差異を介して「衝突条件を見つけよう」とする不注意な解決策は、この些細なケースを誤って失敗したり、複雑にしすぎたりする可能性があります。 

文字列間の差異がまばらな場合、別の特殊なケースが発生します。 問題を 1 つの位置での等価性のチェックやヒューリスティック素数の使用に誤って還元すると、キャンセルがすべての位置に同時に依存することを見落とす可能性があります。

 ## アルゴリズムのチュートリアル

 常に有効なペアを生成する構築的なパスについて説明します。 

1. までの素数のリストを事前計算します。$10^5$ふるいを使って。 これらは、構築された値の素因数の候補になります。 範囲内に必要な素数は 1 つだけであるため、これで十分です$[m, 10^9]$、慎重に数値を構築すると、小規模または中程度の要因が許容されます。 
2. 小型の固定ベースを選択する$r$、通常はランダムな値$[2, 50]$。 これにより、2 つの文字列間の病的なキャンセル パターンが回避されます。 これが機能する理由は、ランダムな文字列が同一でない限り、小さな固定基数で多項式が等しくなる可能性は非常に低いためです。 
3. 多項式の差の値を計算します。$$D = \sum_{i=0}^{n-1} (w_1[i] - w_2[i]) r^i$$これは、オーバーフローや累乗の繰り返しを避けるために繰り返し行われます。 
4. もし$D = 0$、文字列は選択された基本解釈で同一です。 その場合は、任意の素数を選択してください$p \ge m$たとえば、最初の素数 ≥ m を選択し、有効な値を選択します。$r$。 同一の文字列は常に衝突するため、これは有効です。 
5. もし$D \neq 0$、 要素$|D|$ふるいから素数を試すことによって。 素約数を見つける$p$そのような$p \ge m$。 複数存在する場合は、いずれかを選択します。 
6. かつては$p$見つかった、出力$p$そして選ばれたもの$r$。 施工により、$D(r) \equiv 0 \pmod p$, したがって、ハッシュは一致します。 

### なぜ効果があるのか

 核となる不変条件は、多項式の差分を明示的に構築することです。$D(r)$そして係数を選択します$p$それがそれを分けるのです。 これにより次のことが保証されます。$$A(r) - B(r) \equiv 0 \pmod p$$したがって、ハッシュ衝突条件は正確に満たされます。 

選択する自由$p$多項式を評価した後、2 つの制約間のすべての結合が削除されます。 連立モジュラー方程式を解く代わりに、問題をゼロ以外の整数を見つけて適切な約数を選択することに変換します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    for i in range(2, int(n ** 0.5) + 1):
        if is_p[i]:
            for j in range(i * i, n + 1, i):
                is_p[j] = False
    return [i for i in range(2, n + 1) if is_p[i]]

def solve():
    n, m = map(int, input().split())
    w1 = input().strip()
    w2 = input().strip()

    # identical strings shortcut
    if w1 == w2:
        # any prime >= m works
        primes = sieve(200000)
        for p in primes:
            if p >= m:
                print(p, 2)
                return

    primes = sieve(100000)

    # try small bases
    for r in range(2, 51):
        val = 0
        powr = 1
        for i in range(n):
            val += (ord(w1[i]) - ord(w2[i])) * powr
            powr *= r

        if val == 0:
            primes2 = sieve(200000)
            for p in primes2:
                if p >= m:
                    print(p, r)
                    return

        v = abs(val)
        for p in primes:
            if p >= m and v % p == 0:
                print(p, r)
                return

    # fallback (problem guarantees existence)
    print(m, 2)

if __name__ == "__main__":
    solve()
```このコードはまず、単純な同一文字列の場合を処理します。この場合、多項式が同一であるため、有効な係数はすべて機能します。 

次に、因子チェックのために素数を事前計算します。 小さな塩基上のループは、病的なキャンセルを回避するための実用的な方法です。 各基数は、差分多項式の異なる評価を定義します。 

コードは、基底ごとに多項式の差を繰り返し計算します。 これにより、次の能力の再計算が回避されます。$r$。 結果がゼロの場合は、すぐに有効な素数係数の選択に切り替えます。 

それ以外の場合は、素数に対する割り算をチェックして絶対値を因数分解しようとします。 十分な大きさの素数が見つかったら、選択した基数とともにそれを出力します。 

問題は解決策を保証するため、フォールバックは完全性を確保するためにのみ存在します。
