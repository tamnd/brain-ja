 ## 解決策
 ## 問題の理解

 各宇宙船には攻撃力があります。 各帝国基地には防御値とゴールド量があります。 

宇宙船は、防御力が宇宙船の攻撃力以下のすべての基地を破壊できます。 基地を破壊するとすべてのゴールドが得られるため、宇宙船の答えは単純に、防御力が攻撃力以下のすべての基地のゴールドの合計になります。 

タスクは、元の宇宙船の順序を維持しながら、すべての宇宙船についてこの値を計算することです。 

制約は単純なシミュレーションを除外するのに十分な大きさです。 まであります$10^5$宇宙船と$10^5$基地。 すべての宇宙船のすべての基地をチェックするには、$10^{10}$最悪の場合の比較は、数秒以内に実行できる範囲をはるかに超えています。 

問題の構造は並べ替えに非常に適しています。 基地が宇宙船に貢献するかどうかは比較によってのみ決まる$$d \le a$$どこ$d$はベースディフェンスであり、$a$宇宙船の攻撃力です。 基地が防衛順に並べ替えられると、特定の宇宙船に適格なすべての基地が、その並べ替えられた順序のプレフィックスを形成します。 プレフィックス クエリでは、プレフィックスの合計と二分検索が提案されます。 

いくつかの特殊なケースは注目に値します。 

同じ防御力を持つ複数の拠点を考えてみましょう。```

5

```正しい答えは次のとおりです。```

```防御 5 が 1 回だけ見つかるような不注意な二分探索では、ゴールドを見逃してしまいます。 最後の防御値が攻撃力以下の後の位置を見つけなければなりません。 

どの基地も倒すことができない宇宙船を考えてみましょう。```
1 2
1
2 5
3 7
```正しい答えは次のとおりです。```
0
```二分検索は空のプレフィックスを正しく返す必要があります。 

どの基地よりも強力な宇宙船を考えてみましょう。```
1 3
100
1 2
5 3
10 4
```正しい答えは次のとおりです。```

```検索は、配列の境界を超えて実行されるのではなく、プレフィックスの合計全体を返す必要があります。 

もう 1 つの微妙なケースは、防御値 0 です。```
2 2
0 1

```答えは次のとおりです。```

```防御力0の拠点は攻撃力0の宇宙船でも攻撃可能です。 

## アプローチ

 最も直接的な解決策はブルートフォースです。 宇宙船ごとに、すべての基地を反復処理します。 基地の防御力が最大でも宇宙船の攻撃力に達するたびに、そのゴールドが合計に追加されます。 

これは、ステートメントの条件を正確にチェックするため、正しいです。 残念ながら、$10^5$宇宙船と$10^5$ベース、それは実行します$10^{10}$小切手。 そのほんの一部でもすでに遅すぎます。 

重要な観察は、基地が貢献するかどうかを決定する際に重要なのは防御値のみであるということです。 すべての拠点を防御力で分類すると、攻撃力ごとに$a$、攻撃可能なすべての基地は、ソートされたリストの連続したプレフィックスに表示されます。 

たとえば、防御を並べ替えた後は次のようになります。```
Defense: 0 2 4 9
Gold:    1 8 2 4
```攻撃力5の宇宙船なら最初の3拠点をきっちり倒すことができます。 問題は次のようになります。 

「最後の防御値が 5 を超えないプレフィックスには、どれだけのゴールドが含まれていますか?」

 プレフィックス合計は 2 番目の質問に即座に答えますが、二分探索は最初の質問に答えます。 

私たちは基地を防御力で分類し、金の接頭辞合計配列を構築し、各宇宙船について二分探索を使用して攻撃力を上回る最初の防御力を見つけます。 その位置より前のすべてが答えに貢献します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(s・b) | お(1) | 遅すぎる |
 | 最適 | O(b log b + s log b) | O(b) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての宇宙船の攻撃力を読み取ります。 
2. すべての塩基をペアとして読み取ります`(defense, gold)`。 
3. 守備値で拠点を並べ替えます。 

ソート後、すべての宇宙船の有効な塩基が配列の接頭辞を形成します。 
4. ソートされた防御のみを含む配列を作成します。 
5. 金のプレフィックスサム配列を構築します。 

させて`pref[i]`合計のゴールドを最初の場所に保管します`i`ソートされた順序のベース。 長さを使用する`b + 1`プレフィックス配列により、空のプレフィックスの処理が簡単になります。 
6. 各宇宙船の攻撃力について`a`、ソートされた防御配列に対して二分探索を実行します。 

守備力が以下の最初のポジションを見つけます`a`。 Python ではこれは`bisect_right`。 
7. 返された位置が`pos`、それから正確に最初の`pos`拠点は攻撃可能です。 

答えは`pref[pos]`。 
8. すべての回答を元の宇宙船の順序で出力します。 

### なぜ効果があるのか

 守備で並べ替えた後、最大で守備を持つすべての拠点`a`より高い防御力を持つすべての拠点の前に出現します`a`。 二分探索により、これら 2 つのグループ間の境界が見つかります。 

返された位置`pos`はまさに攻撃可能な拠点の数です。 以来`pref[pos]`最初に含まれる金の合計を保管します`pos`基地を分類すると、それは宇宙船が破壊できるすべての基地からのゴールドの合計に等しくなります。 この議論はすべての宇宙船に対して独立して成立するため、報告された答えはすべて正しいです。 

## Python ソリューション```python
import sys
from bisect import bisect_right

input = sys.stdin.readline

def solve():
    s, b = map(int, input().split())
    attacks = list(map(int, input().split()))

    bases = []
    for _ in range(b):
        d, g = map(int, input().split())
        bases.append((d, g))

    bases.sort()

    defenses = [d for d, _ in bases]

    pref = [0] * (b + 1)
    for i in range(b):
        pref[i + 1] = pref[i] + bases[i][1]

    ans = []
    for a in attacks:
        pos = bisect_right(defenses, a)
        ans.append(str(pref[pos]))

    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```並べ替えられた`bases`配列は、二分探索に必要な順序を確立します。 の`defenses`配列が抽出されるのは、`bisect_right`単一のソートされたリストに基づいて動作します。 

プレフィックスサム配列には長さがあります`b + 1`。 余分な先行ゼロは特殊なケースを削除します。 基地を攻撃できなければ、`bisect_right`返品`0`そして`pref[0]`はすでに正解です。 

使用する`bisect_right`の代わりに`bisect_left`重要です。 攻撃力以下の防御力を持つすべての拠点が必要です。`bisect_right`最後の等しい要素の後の最初の位置を返します。これには、すべての有効な基数が含まれます。 

Python の整数は、可能な最大のゴールド合計を自動的に処理します。 最大規模のテストでも、合計は問題なく適合します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from bisect import bisect_right

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    s, b = map(int, input().split())
    attacks = list(map(int, input().split()))

    bases = []
    for _ in range(b):
        d, g = map(int, input().split())
        bases.append((d, g))

    bases.sort()

    defenses = [d for d, _ in bases]

    pref = [0]
    for _, g in bases:
        pref.append(pref[-1] + g)

    ans = []
    for a in attacks:
        pos = bisect_right(defenses, a)
        ans.append(str(pref[pos]))

    return " ".join(ans)

1 3 5 2 4
0 1
4 2
2 8
9 4
"""
) == "1 9 11 9 11", "sample 1"

# minimum size

"""1 1
0
0 5
"""
) == "5", "minimum case"

# no attackable bases

"""2 2

3 7
"""

# all equal defenses

 ## 特殊なケース

 どの基地も倒すことができない宇宙船を考えてみましょう。```
1 2
1
2 5
3 7
```分類された防御は、`[2, 3]`。`bisect_right([2, 3], 1)`返品`0`。 アルゴリズムの出力`pref[0] = 0`を満たす塩基がないため、これは正しいです。`d ≤ 1`。 

同じ防御力を持つ複数の拠点を考えてみましょう。```
1 3
5
5 2
5 3
5 4
```並べ替え後の防御は、`[5, 5, 5]`。`bisect_right(..., 5)`返品`3`、 ない`1`。 答えは次のようになります`pref[3] = 9`、防御力が攻撃力と等しいすべての拠点を正しく含みます。 

どの基地よりも強力な宇宙船を考えてみましょう。```
1 3
100
1 2
5 3
10 4
```

`bisect_right([1, 5, 10], 100)`返品`3`、これは塩基の数に等しい。 アルゴリズムが使用するのは、`pref[3] = 9`、すべての金の合計。 

防御値がゼロであると考えます。```
2 2
0 1
0 5
1 7
```並べ替えられた防御は次のとおりです`[0, 1]`。 攻撃力に関しては`0`、バイナリ検索で返されるのは`1`、したがって、答えは次のとおりです`pref[1] = 5`。 攻撃力に関しては`1`、それは戻ります`2`、生産`12`。 どちらの出力も、意図した動作と正確に一致します。
