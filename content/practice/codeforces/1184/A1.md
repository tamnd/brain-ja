 ## 解決策
 ## 問題の理解

 問題は関数を与えます$H(x, y) = x^2 + 2xy + x + 1$、および正の整数$r$。 正の整数のペアが存在するかどうかを判断する必要があります$(x, y)$そのような$H(x, y) = r$。 複数のペアが存在する場合は、最小のペアを返す必要があります。$x$そうでない場合は、「NO」を返します。 入力$r$と同じ大きさにすることができます$10^{12}$したがって、どのソリューションでも非常に大きな整数を効率的に処理する必要があります。 

なぜなら$x$そして$y$が正の整数であれば、すぐにわかります。$H(x, y)$少なくとも二次関数的に成長します$x$そして直線的に$y$。 もし$r$小さい、大きいが多い$x$値は機能しない可能性があるため、反復処理が行われます$x$ある程度の合理的な範囲内でのみ実現可能です。 もし$r$非常に大きいため、可能なすべてを反復することはできません$x, y$単純にペアリングするため、$x$おおよそ最大まで上がる可能性があります$\sqrt{r}$、諦める$10^6$候補者と、$y$同様の規模まで上昇する可能性があり、実行不可能な事態が発生する可能性があります。$10^{12}$操作。 

次の場合、微妙なエッジケースが発生します。$x = 1$または$y = 1$、これらは最小の正の整数であり、次の最小出力を生成するためです。$H$。 たとえば、次の場合$r = 4$、 それから$H(1,1) = 1 + 2 + 1 + 1 = 5$、すでに よりも大きくなっています$r = 4$。 チェックを行わない単純なアルゴリズム$x = 1$誤って「NO」と結論付ける可能性があります。 もう 1 つのエッジケースは次のような場合です$r$それ自体は完全二乗に次のような小さな線形項を加えたものです。$r = 19$サンプル内で溶液が存在する場所$x = 1, y = 8$。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのことを繰り返すことになります。$x$1から$\sqrt{r}$、それぞれについて$x$、計算する$y$方程式を解くことで$H(x, y) = r$明示的に$y$。 書き直すと、$x^2 + 2xy + x + 1 = r \implies 2xy = r - x^2 - x - 1 \implies y = \frac{r - x^2 - x - 1}{2x}$。 この式は整数を保証します$y$分子が次で割り切れる場合$2x$。 ブルートフォースアプローチが機能する理由は、$x$おおよそを超えることはできません$\sqrt{r}$、それで、$r = 10^{12}$、$x$までしか行きません$10^6$, 動作に関しては許容範囲内です。 

最適な解決策につながる重要な観察は、次のことを考慮する必要がないということです。$y$独立して。 候補者ごとに$x$、直接計算できます$y$上の式より。 もし$y$結果が正で積分であれば、有効な解決策が得られます。 これにより、問題は単一のループに軽減されます。$x$両方をネストしたループではなく、$x$そして$y$。

| 最適 | O(sqrt(r)) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 反復から始める$x$1から。 最大$x$考慮するのは、次を満たす最大の整数です。$x^2 + x + 1 \le r$、 なぜなら$2xy$は常に非負であるため、$x^2 + x + 1 > r$方程式は不可能になります。 
2. それぞれについて$x$、分子を計算します$num = r - x^2 - x - 1$。 これは、正確に一致する必要がある残りの部分を表します。$2xy$方程式を満たすために。 
3. 次のことを確認します。$num$で割り切れます$2x$。 そうでない場合は整数なし$y$このために存在する$x$、次へ進みます$x$。 
4. 割り切れる場合は計算する$y = num // (2x)$。 もし$y$が正の場合、ペアを返します$(x, y)$スキャン中なのですぐに$x$昇順であり、これは可能な限り最小であることが保証されます$x$。 
5. そうでない場合$x$有効な正の整数を生成します$y$、「いいえ」を出力します。 

なぜそれが機能するのか: 公式$y = \frac{r - x^2 - x - 1}{2x}$正の整数解の検索空間全体をカプセル化します。 反復$x$昇順では、最初の有効なペアが最小であることが保証されます。$x$。 停止条件により、不可能とは決して考えられません$x$価値観。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

r = int(input())

x = 1
found = False
while x * x + x + 1 <= r:
    num = r - x * x - x - 1
    if num % (2 * x) == 0:
        y = num // (2 * x)
        if y > 0:
            print(x, y)
            found = True
            break
    x += 1

if not found:
    print("NO")
```ループは一旦停止します$x^2 + x + 1$を超える$r$、大きいので$x$ポジティブなものを生み出せない$y$。 モジュロチェックにより、$y$は整数です。 明示的にチェックします$y > 0$ポジティブ制約を強制します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    r = int(sys.stdin.readline())
    x = 1
    found = False
    out = ""
    while x * x + x + 1 <= r:
        num = r - x * x - x - 1
        if num % (2 * x) == 0:
            y = num // (2 * x)
            if y > 0:
                out = f"{x} {y}"
                found = True
                break
        x += 1
    if not found:
        out = "NO"
    return out
