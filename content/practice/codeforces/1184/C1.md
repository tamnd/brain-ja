 ## 解決策
 ## 問題の理解

 グリッド上に小さな点のセットが与えられます。ここでは、ほぼすべての点が軸に沿った正方形の境界上に正確に位置します。 1 点だけが例外で、厳密に正方形の内側にあります。 タスクは、その単一の内部点を特定することです。 

正方形は明示的には与えられません。 代わりに、点の分布からそれを推測します。その 4 つの側面のそれぞれに多くの点があり、境界に属さない点が 1 つだけあります。 正方形は軸に沿って配置されているため、その境界は次の形式の 4 本の線で構成されます。$x = L$、$x = R$、$y = B$、 そして$y = T$。 

入力サイズは非常に小さいです。 私たちはせいぜい$n = 10$, したがって、合計ポイント数は次のようになります。$4n + 1 \le 41$。 これにより、パフォーマンスに関する懸念が即座に排除されます。 たとえ$O(n^2)$または$O(n^3)$ここでのアプローチは簡単ですが、この構造により、正方形の境界が特定されるとさらに単純な線形スキャンが可能になります。 

点のサブセットのみを使用して正方形を推測しようとした場合、たとえば最初の数点を取得したり、最初の個別の x 値と y 値が境界に対応すると仮定したりすると、微妙な失敗のケースが発生します。 入力順序が敵対的である場合、これらの仮定は崩れます。 正しいアプローチは、順序ではなく、頻度または全体的な構造に依存する必要があります。 

## アプローチ

 ブルートフォース戦略では、各点を順番に削除し、残りの点が有効な正方形の境界を形成できるかどうかを確認することによって、どの点が内部の点であるかを推測しようとします。 候補を削除するたびに、x 値と y 値の最小値と最大値を再計算し、残りのすべての点がこれら 4 つの線上にあることを確認します。 これは、内部点が削除されると正方形が一意に決定されるため機能します。 

ただし、このアプローチでは境界条件が繰り返し再計算されるため、$O(N^2)$最大 41 ポイントをチェックします。 これでもまだ高速ですが、不必要なオーバーヘッドが発生し、問題の実際の構造が見えなくなります。 

重要な観察は、正方形の境界が 4 つの極値 (最小 x、最大 x、最小 y、および最大 y) によって完全に定義されていることです。 すべての有効な境界点は、これら 4 つの直線のうちの少なくとも 1 つになければなりません。 内部点はこの条件に違反する唯一の点です。つまり、その x は minX または maxX に等しくなく、その y は minY または maxY に等しくありません。 

したがって、候補をテストする代わりに、最初に完全なデータセットから正方形の境界を回復します。 minX、maxX、minY、maxY がわかったら、一度スキャンして、これらの境界線のいずれにも載っていない唯一の点を見つけます。

 | ブルートフォース | O(N^2) | お(1) | 受け入れられるが不要 |
 | 最適 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのポイントをリストに読み取り、グローバル極値を計算できるようにします。 これが必要なのは、正方形の境界が局所的な構造ではなくすべての点に依存するためです。 
2. コンピューティング`min_x`、`max_x`、`min_y`、 そして`max_y`すべてのポイントにわたって。 これらは正方形の境界候補を定義します。 
3. 各点を繰り返し処理し、それが境界線上にあるかどうかを確認します。 点が境界上にある場合`x == min_x`または`x == max_x`または`y == min_y`または`y == max_y`。 
4. この条件を満たさない最初の点は、内部点でなければなりません。 すぐに出力してください。 

ステップ 3 の背後にある理由は、軸に揃えられた正方形のすべての境界点が、その 4 つの辺のうちの少なくとも 1 つに正確に存在する必要があるということです。 これを満たさない点は厳密に内側でなければなりません。 

### なぜ効果があるのか

 境界点のセットは、極値の座標によって定義される完全な長方形を形成します。 この問題では、1 つを除くすべての点がこの境界上にあることが保証されているため、計算された極値が有効性を取り除くような形で内部点の影響を受けることはありません。すべての辺が十分に設定されている場合、内部点が両方の軸で同時に極値になることはありません。 したがって、真の正方形の境界は正確にグローバルな最小/最大値であり、内部点のみが 4 つの境界線の和集合のメンバーシップに違反します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    pts = []
    m = 4 * n + 1

    min_x = 10**9
    max_x = -10**9
    min_y = 10**9
    max_y = -10**9

    for _ in range(m):
        x, y = map(int, input().split())
        pts.append((x, y))
        if x < min_x:
            min_x = x
        if x > max_x:
            max_x = x
        if y < min_y:
            min_y = y
        if y > max_y:
            max_y = y

    for x, y in pts:
        if x != min_x and x != max_x and y != min_y and y != max_y:
            print(x, y)
            return

if __name__ == "__main__":
    solve()
```実装はアルゴリズムに直接に従います。 最初のパスでは、線形時間で外接する四角形を計算します。 2 番目のパスでは、境界線上にない固有の点を特定します。 条件は、ロジックを組み合わせた場合の間違いを避けるために明示的に記述されています。 内部条件は、少なくとも 1 つの境界上にあることの否定です。 

よくある間違いは、x 値または y 値のみに対して周波数ベースのヒューリスティックを使用しようとすることです。 境界点が垂直エッジと水平エッジの両方に表示され、周波​​数が一意に識別されないため、これは失敗します。 正しいテストは、境界線の結合における幾何学的メンバーシップです。

 ## 特殊なケース

 エッジ ケースの 1 つは、正方形が両方の軸の 0 から 1 など、可能な限り最小の座標に位置する場合です。 すべての境界点が存在するため、極値の計算では最小値と最大値が正しく識別されます。 

入力：```
1
0 0
0 1
1 0
1 1
0 2
```ここでは、min_x = 0、max_x = 1、min_y = 0、max_y = 2 です。アルゴリズムは、これらの値に対して各ポイントをチェックします。 (1,1) のみがすべての境界条件を満たさないため、正しく識別されます。 

もう 1 つのエッジ ケースは、入力順序が内部点を最初に置く場合です。 このアルゴリズムは順序に依存せず、フィルター処理の前にグローバル極値を計算するため、結果は変わりません。
