 ## 解決策
 ## 問題の理解

 少数の円またはリングの近くにある平面内のノイズの多い点のセットが与えられます。 各リングには中心と半径があり、サンプリングされた各点は正確な円周からわずかにずれています。 私たちの目標は、各リングのパラメータ (中心座標と半径) を復元し、再構築された各リングがハウスドルフ距離の観点から元のリングに近づくようにすることです。 

入力は次のもので構成されます$k$リング、それぞれ$n$ノイズの多いサンプル、合計$k \times n$ポイント。 各ポイントは整数座標で表されますが、ノイズによりリングの半径の最大 10% ずれる可能性があります。 リングが十分に分離されている (ハウスドルフ距離で少なくとも 600,000 単位離れている) ことが保証されており、リングを区別できることが保証されています。 

制約は小さいです$k$(1 ≤$k$≤ 4) ただし、中程度に大きい$n$(100 ≤$n$≤ 1000)。 これにより、二次関数的に、またはわずかに悪いスケールでスケールするアプローチが可能になります。$n$、ただし指数関数的ではありません$k \times n$。 明白でないエッジ ケースは、あるリングの点が別のリングの境界円の境界に近い場合、またはノイズの多いサンプルがわずかに非対称である場合に発生します。 単純な重心アプローチでは、点が正確に円上にないため、中心が移動する可能性があります。 重心からの平均距離を使用して不用意に半径を計算すると、10% 以上の誤差が生じる可能性がありますが、100,000 という寛大な許容値があれば、これは許容範囲です。 

## アプローチ

 最も単純なアプローチは、円に適合するように点の可能なすべてのサブセットを試行することですが、これは組み合わせになります。$O(n^3)$リングごとに 3 つのポイントを選択するため、これを繰り返します$k$リング。 と$n$1000 までは、これはすでに実用的ではありません。 より良い総当たりアプローチは、最初に点をクラスタリングしてから、各クラスタに円を当てはめることです。 クラスタリングは、リング間の大きな分離を利用します。異なるリングに属する点は遠く離れているため、単純な幾何学的クラスタリングによって、それらのリングに点が正しく割り当てられます。 

重要な洞察は、$k \le 4$リング間の距離が大きい場合は、ユークリッド距離に基づいて階層的クラスタリングを実行し、各クラスターの中心と半径を計算できます。 点の平均を中心の推定値として使用し、中心からの平均距離を半径の推定値として使用すると、100,000 ハウスドルフ許容値内に十分収まるパラメータが生成されます。 

すべてのリングが円を形成する点によって定義されるため、総当りのアプローチは機能しますが、指数関数的な数のサブセットを考慮する必要があるため、実際には失敗します。 リングが遠く離れているという観察により、クラスタリング ベースのアプローチで点をリングに対応するクラスターに分離し、単純な幾何学的計算でパラメーターを確実に回復できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのトリプレット) | O((kn)^3) | O(kn) | 遅すぎる |
 | クラスター + サークル フィット | O((kn)^2) | O(kn) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのポイントを読み取り、それらをリストとして保存します。$(x, y)$コーディネート。 クラスタリングはペアごとの距離に依存するため、最初はそれらを単一のコレクションとして処理します。 
2. 単純な素セットまたは貪欲な最近傍アプローチのいずれかを使用して、クラスタリング構造を初期化します。 まず、1 つの軸に沿ってポイントを並べ替え、保証された間隔である 600,000 よりも小さい距離しきい値内にあるポイントを繰り返しグループ化します。 これにより、同じリング クラスタからのポイントが確実に結合されます。 
3. 各クラスターについて、重心を計算します。$(cx, cy)$点の x 座標と y 座標を平均することによって。 これはリングの中心の推定値として機能します。 
4. 半径を計算する$r$重心からクラスター内の各点までの平均ユークリッド距離として。 これにより、サンプル内のノイズが滑らかになります。 
5. 各リングを次のように出力します。$(cx, cy, r)$。 スコアリングでは、各元のリングにハウスドルフ距離 100,000 以内に対応する出力があるかどうかのみがチェックされるため、順序は重要ではありません。 

機能する理由: 600,000 個の分離によりクラスターが異なるリングからのポイントを混合しないため、アルゴリズムは正確さを保証します。 重心は堅牢な中心推定値を示し、平均距離は真の値の 10% 以内の半径を示します。 ハウスドルフ許容値が 100,000 の場合、これらの推定値は回復基準を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import sqrt

def main():
    k = int(input())
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n * k)]

    clusters = []
    used = [False] * (n * k)

    # Greedy clustering based on nearest neighbor
    for i, p in enumerate(points):
        if used[i]:
            continue
        cluster = [p]
        used[i] = True
        for j, q in enumerate(points):
            if not used[j]:
                dx = p[0] - q[0]
                dy = p[1] - q[1]
                if dx*dx + dy*dy <= 6e5**2:
                    cluster.append(q)
                    used[j] = True
        clusters.append(cluster)

    # Fit circle to each cluster
    results = []
    for cluster in clusters:
        cx = sum(x for x, y in cluster) / len(cluster)
        cy = sum(y for x, y in cluster) / len(cluster)
        r = sum(sqrt((x - cx)**2 + (y - cy)**2) for x, y in cluster) / len(cluster)
        results.append((cx, cy, r))

    for cx, cy, r in results:
        print(cx, cy, r)

if __name__ == "__main__":
    main()
```この実装では、単純な貪欲クラスタリング ヒューリスティックを使用します。これで十分です。$k \le 4$大きな分離を伴う。 重心と平均距離の計算はノイズを処理し、許容されるハウスドルフしきい値内の推定値を生成します。

    main()
