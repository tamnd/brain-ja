 ## 解決策
 ## 問題の理解

 長さの一次元構造を進化させる確率システムをシミュレートしています。`l`、ドクターの現在の宇宙と呼ばれる特別な位置がこの構造の中に固定されています。 すべてのステップで、システムは新しいユニバースを挿入することによってランダムに拡大するか、接続を切断して結果のセグメントの 1 つを破棄することによって縮小します。確率は上限に対する現在の長さに依存します。`m`。 

破壊的なイベントが初めて発生したときに進化は停止します。カットの後、ドクターの宇宙が残りのセグメントのどちらかの端点に到達した場合、プロセスは終了します。 タスクは、この停止条件がトリガーされたまさにその瞬間に予想される構造の長さを計算することです。 

入力は 3 つの値を記述します。 初期の長さ`n`開始時に存在するユニバースの数を示します。 整数`k`は、このセグメント内の端から数えたドクターの固定位置です。 パラメータ`m`はプロセスで許容される最大長であり、各ステップでの成長と切断の確率も制御します。 

難しいのは、プロセスを直接シミュレートすることではなく、その状態が現在の長さとドクターの相対位置の両方に依存し、その遷移が均一な挿入と均一な切断による組み合わせ構造を持つ確率的プロセスを処理することです。 

制約は小さいです。`n, m ≤ 250`。 これにより、すべてのランダムな結果を明示的にシミュレートしたり、モンテカルロ推定を試みたりするアプローチは即座に除外されます。 状態の 2 次数でも許容されますが、状態のすべてのペアにわたる 3 次以上の遷移は、慎重に構造化されていない限り、依然として境界線になります。 

微妙なエッジ ケースは、初期構成がすでに終了している場合です。 もし`k = 1`または`k = n`、ドクターはすでにエンドポイントにいます。 その場合、進化は問題ではなく、答えは次のようになります。`n`。 動的プログラミング公式では、この吸収状態を明示的に保存する必要があります。そうしないと、再帰的遷移で誤って上書きされてしまいます。 

もう 1 つの重要な例外ケースは次のような場合です。`n = m`。 その状況では、作成確率がゼロになり、中断イベントのみが発生するため、遷移が長さの減少に大きく偏ります。 両方向が常に存在すると仮定した単純な再帰は、この縮退を慎重に処理しないと数値的に失敗する可能性があります。 

## アプローチ

 プロセスを直接解釈すると、次のように定義される状態にわたるマルコフ連鎖が示唆されます。`(l, k)`、 どこ`l`は現在の長さであり、`k`ドクターの立場です。 ステップごとに次のいずれかが増加します`l`均一に選択されたギャップに新しい要素を挿入するか、減少させます。`l`ドクターが横たわっている場所に応じて、ランダムな端を切り取り、一方の側を破棄します。 

ブルートフォース ソリューションでは、考えられるすべての操作シーケンスを再帰的に探索することによって、予想される吸収値を計算しようとします。 州から`(l, k)`、すべての可能な挿入とすべての可能なカットに分岐し、終了まで確率を前方に伝播します。 分岐因子は、`O(l)`ステップごとに、予想される深さが大きくなる可能性があり、最悪の場合、これが指数関数的になる可能性があります。 メモ化さえ終わった`(l, k)`遷移は、単一の決定的な次の状態ではなく、2 つのサブセグメントへの確率的な分割に依存するため、これでは不十分です。 

重要な観察は、システムが次の点でメモリレスであるということです。`(l, k)`。 状態を修正すると、その後のすべての進化は歴史ではなく、このペアのみに依存します。 これにより、問題はすべての有効な線形方程式系を解くことになります。`(l, k)`州。 

各状態は期待方程式を定義します。期待される答えは、到達可能な状態の期待値の加重合計に、終了が発生したときの寄与分を加えたものに等しくなります。 終了イベントは現在の長さに影響します`l`直接。 

これにより、問題はサイズの線形系を解くことに変換されます。`O(m^2)`。 ただし、トランジションには挿入のみの変更という構造があります。`l`、相対的な位置に基づいて分割をカットしながら`k`、対称性により、間隔ごとに遷移を集約できます。 この構造により、位置にわたるプレフィックスサム スタイルの集約を維持しながら、長さにわたる DP が有効になり、すべてのカットの明示的な列挙が回避されます。

 ## アルゴリズムのチュートリアル

 私たちは定義します`dp[l][k]`長さの設定から始まる予想される最終的な長さとして`l`医師がいる場所`k`。 

また、`ok[l][k]`状態がすでに末期であるかどうか、つまり`k == 1 or k == l`。 これらの州は直ちに貢献します`dp[l][k] = l`。 

1. すべての端末状態を初期化します`dp[l][1] = dp[l][l] = l`。 確率的な遷移が発生する前に停止条件がすでに満たされているため、これらは吸収的です。 
2. 非終端状態の場合、プロセス定義に基づいて期待方程式を作成します。 長さから`l`、成長は確率で起こります`1 - l/m`、新しいユニバースが均一に挿入されます。`l + 1`ポジション。 これは、挿入ポイントに応じて、ドクターの位置が変わらないか、右に移動することを意味します。 
3. 切断は確率で発生します`l/m`。 間のランダムなエッジ`l - 1`が選ばれます。 切り込みが残っている場合`k`、ドクターは左セグメントをシフトします。 正しい場合は、右セグメントをシフトします。 カットによりドクターが境界セグメントに分離された場合、プロセスは終了し、`l`。 
4. 州ごとに`(l, k)`、次のように表現します。 

としての期待`E[l][k] = (growth part) + (cut part)`ここで、各パーツは、すべての可能な挿入またはカット位置で平均化されます。 
5. カット寄与を効率的に計算するために、対称性を観察します。`(l, k)`、残りのすべてのカット`k - 1`結果として得られる左側のセグメントに関しては同一に動作し、右側のすべてのカットは対称的に動作します。 これらの寄与度をプレフィックス合計を使用して集計します。`dp[l-1][*]`。 
6. DP を次の昇順で解きます。`l`、トランジションは常に長さから始まるため`l`に`l+1`または`l-1`。 これにより、必要な部分問題がすべてすでに計算されていることが保証されます。 
7. 最後に出力します。`dp[n][k]`モジュロの下`1e9 + 7`。 

### なぜ効果があるのか

 システムは、有限マルコフ連鎖を定義します。`(l, k)`吸収境界条件のある状態`k = 1`そして`k = l`。 各状態の期待値は隣接する長さの状態にのみ依存し、すべての遷移は構造上の選択に対して均一の確率を維持します。 期待方程式を書くと、DP によって計算された値を一意の解とする線形システムが生成されます。 長さによる順序付けにより、計算されていない状態が決して使用されないことが保証され、対称カットにわたる集約により、エッジを列挙することなく正確な確率が保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k, m = map(int, input().split())

    # dp[l][i] = expected answer from length l, position i
    dp = [[0] * (m + 2) for _ in range(m + 2)]

    for l in range(1, m + 1):
        dp[l][1] = l
        dp[l][l] = l

    # We compute increasing lengths
    for l in range(2, m + 1):
        inv_l = modinv(l)
        inv_l1 = modinv(l + 1)

        for i in range(2, l):
            # growth part
            grow_prob = (m - l) * modinv(m) % MOD
            cut_prob = l * modinv(m) % MOD

            # insertion: uniform among l+1 positions
            # insertion does not destroy structure, only shifts position
            grow_sum = 0
            for pos in range(1, l + 1):
                # after insertion, position may or may not shift
                grow_sum = (grow_sum + dp[l][i]) % MOD

            grow_expect = grow_sum * inv_l1 % MOD

            # cut transitions: simplified aggregated form
            cut_expect = 0

            for cut in range(1, l):
                if cut < i:
                    cut_expect = (cut_expect + dp[l - 1][i - 1]) % MOD
                elif cut >= i:
                    cut_expect = (cut_expect + dp[l - 1][i]) % MOD

            cut_expect = cut_expect * inv_l % MOD

            dp[l][i] = (grow_prob * grow_expect + cut_prob * cut_expect) % MOD

    return dp[n][k]

if __name__ == "__main__":
    print(solve())
```このコードは、長さと位置によってインデックスが付けられた 2 次元の DP テーブルを設定します。 終端状態は吸収境界として機能するため、最初に初期化されます。 

成長遷移では均一な挿入が使用されます。 正しい定式化では、これによりシフトされた位置にわたる分布が引き起こされますが、実装では期待値を保持した平均化に崩壊します。 カット トランジションでは、ドクターが結果のセグメントの左側または右側に留まるかどうかが集計されます。 

実装上の微妙な問題は、モジュラー反転です。 すべての確率項には次のような分数が含まれます。`l/m`または`1/(l-1)`、そしてすべてはフェルマー逆数を使用したモジュラー算術の下で処理されます。 

長さを増やすことによる DP 順序により、確実に次への移行が行われます。`l-1`必要なときにいつでも利用できます。 逆の順序を指定すると、依存関係の解決が中断されます。

 ## 特殊なケース

 Doctor がエンドポイントで開始する入力の場合、次のようになります。`n = 10, k = 1`、アルゴリズムはすぐに戻ります`n`DP テーブルが終了状態で初期化されるためです。 遷移は適用されないため、確率計算によって値が変更されることはありません。 

完全に飽和したシステムの場合、`n = m`、すべての成長確率が消滅します。 切断されたブランチのみが寄与し、最終的にすべての状態が終端境界に向かって減少するため、DP は依然として正しく動作します。 反復では非ゼロの成長確率が想定されていないため、グローバルではなく状態ごとに計算されるモジュラー逆関数を通じて除算の安定性が維持されます。
