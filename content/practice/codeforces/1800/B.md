 ## 解決策
 ## 問題の理解

 クリスティーナには、小文字または大文字の文字列があります。 彼女は、小文字とそれに対応する大文字バージョンで構成される有効なペアごとに 1 バールを獲得します。 各文字は 1 つのペアにのみ参加できます。 さらに、彼女が実行できるのはせいぜい$k$単一の文字の大文字と小文字を小文字から大文字に、またはその逆に反転する操作。 目標は、最大数まで申請した後に形成できるペアの最大数を計算することです。$k$操作。 

入力は複数のテスト ケースで構成され、それぞれが文字列の長さを指定します。$n$、許可される操作の数$k$、および文字列$s$。 各テスト ケースの出力は、クリスティーナが形成できるペアの最大数です。 

制約により許可されるのは、$n$到達する$2 \cdot 10^5$すべてのテスト ケースの合計。 最悪の場合の操作数は指数関数的になるため、反転のすべてのサブセットを考慮したり、すべてのペアを明示的にチェックしたりする総当り的なアプローチは除外されます。 各文字列を線形に処理するソリューションが必要です。理想的には$O(n)$時間。 

小文字と大文字の数が 2 を超える場合、微妙なエッジケースが発生します。$2k$。 不注意な解決策は、単純に既存の文字を貪欲に組み合わせて、$k$残った文字が実際に新しいペアに変換できるかどうかを確認せずに操作を行うことになります。 たとえば、文字列の場合`aaaBBB`そして$k = 1$、3つあります`a`と３`B`s. 単純なアプローチでは、1 つの操作で 2 つの追加ペアを作成できると考えるかもしれませんが、実際には追加のペアを 1 つだけ変換するため、追加のペアは 1 つしか作成できません。`a`に`A`1 台のみとペアリング可能`B`。 

## アプローチ

 ブルートフォースソリューションでは、可能な限りすべての方法を列挙しようとします。$k$文字を調べ、それぞれの場合に形成されたペアの数を数えます。 これは明らかに実行不可能です。$n$まで$2 \cdot 10^5$そして$k$まで$n$、反転する文字のサブセットの数は組み合わせ的に増加します。 

重要な洞察は、文字の順序はペアを数えるのに重要ではないということです。 小文字と大文字のそれぞれの数のみを考慮します。 キャラクターごとに`x`、自然なペアの数は、次のカウントの最小値です。`x`そして`X`。 1 つの大文字の残りの文字は、2 つの残りの文字ごとに 1 つの操作を使用して他の大文字に変換して追加のペアを形成できる可能性があります。 たとえば、余分な小文字が 3 つある場合、`a`s と追加の大文字 1 つ`A`、1 回の操作で追加の 1 つを変換できます`a`に`A`追加のペアを作成します。 

最適な解決策は、文字を数え、自然なペアを形成し、その後、残りの文字を 2 つのグループとして使用し、利用可能な操作を使用して追加のペアを形成します。 これにより問題は次のように縮小されます$O(n)$テストケースあたりの時間と$O(1)$周波数配列を超える余分なスペース。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(26) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を初期化する`lower`そして`upper`サイズ 26 で、小文字と大文字のそれぞれの出現をカウントします。 
2. 文字列を反復処理します。 小文字の場合`c`、増分`lower[ord(c)-ord('a')]`。 大文字の場合`C`、増分`upper[ord(C)-ord('A')]`。 
3.初期化`pairs = 0`。 文字ごとのインデックス`i`0から25まで、計算します`natural_pairs = min(lower[i], upper[i])`。 追加`natural_pairs`に`pairs`。 減算`natural_pairs`両方から`lower[i]`そして`upper[i]`。 
4. 自然なペアを形成した後、各文字のインデックスについて`i`、大文字と小文字を反転して追加のペアを形成できる残りの文字を計算します。`extra_pairs_possible = min((lower[i] // 2) + (upper[i] // 2), k)`。 追加`extra_pairs_possible`に`pairs`そして減少します`k`による`extra_pairs_possible`。 
5. 戻る`pairs`。 

不変条件は、すべてのステップで、`pairs`考慮された文字のみを使用したペアの最大数を反映し、`k`はまだ利用可能なフリップの数です。 ペアでは、各ケースの 1 つまたは同じケースの 2 つを反転する必要があるため、アルゴリズムはペアの数を正しく最大化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_burles(n, k, s):
    lower = [0] * 26
    upper = [0] * 26
    
    for c in s:
        if c.islower():
            lower[ord(c) - ord('a')] += 1
        else:
            upper[ord(c) - ord('A')] += 1
            
    pairs = 0
    for i in range(26):
        natural_pairs = min(lower[i], upper[i])
        pairs += natural_pairs
        lower[i] -= natural_pairs
        upper[i] -= natural_pairs
        
    for i in range(26):
        extra_pairs = min((lower[i] // 2) + (upper[i] // 2), k)
        pairs += extra_pairs
        k -= extra_pairs
        if k <= 0:
            break
            
    return pairs

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    s = input().strip()
    print(max_burles(n, k, s))
```最初のループでは文字をカウントし、自然なペアを処理します。 2 番目のループでは、許可された操作を使用して、残った文字を追加の可能性のあるペアとして考慮します。 整数除算を使用すると、完全なペアのみがカウントされ、1 回だけ早期に分割されます。`k`を使い果たすことで、不必要な計算が防止されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 文字列を 1 回繰り返し、次に 26 文字を 2 回繰り返します。 |
 | スペース | お(1) | n に関係なく、サイズ 26 の配列が 2 つだけ使用されます。 |

 これは次の制約に当てはまります:$2 \cdot 10^5$、アルゴリズムは 2 秒以内に効率的に実行されます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    res = []
    for _ in range(t):
        n, k = map(int, input().split())
        s = input().strip()
        res.append(str(max_burles(n, k, s)))
    return "\n".join(res)

# Provided samples
assert run("5\n11 2\naAaaBACacbE\n2 2\nab\n4 1\naaBB\n6 0\nabBAcC\n5 3\ncbccb\n") == "5\n0\n1\n3\n2"

# Custom cases
assert run("1\n1 0\na\n") == "0", "single lowercase letter, no pair"
assert run("1\n2 1\nAa\n") == "1", "already a pair"
assert run("1\n4 2\naabb\n") == "2", "flip one pair possible"
assert run("1\n6 3\nAAaaaa\n") == "3", "maximize with flips"
assert run("1\n3 1\nABC\n") == "0", "all uppercase, insufficient flips"
