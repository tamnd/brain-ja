 **タグ:** 実装、文字列

 ## 解決策
 ## 問題の理解

 指定された文字列が猫の鳴き声を表すかどうかを判断するように求められます。 音声は「m-e-o-w」の順序に厳密に従う必要があり、各文字は連続して複数回出現でき、大文字と小文字の両方が許可されます。 つまり、最初の連続する文字セグメントはすべて「m」または「M」であり、その直後に「e」または「E」の連続セグメントが続き、次に「o」または「O」、最後に「w」または「W」が続く必要があります。 他の文字は許可されず、順序が中断されたり、空のセグメントが存在したりすることはできません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、文字列と文字列自体の長さが示されます。 境界は小さく、文字列の最大長は 50 で、最大 10,000 のテスト ケースを含めることができます。 これは、処理される文字の総数が最大 500,000 であるため、各文字列の単純な線形スキャンが効率的に実行されることを示唆しています。 

明らかではないエッジ ケースには、パターンにほぼ一致するものの、微妙な点で失敗する文字列が含まれます。 たとえば、「meowmeow」には有効な文字のみが含まれていますが、シーケンスが繰り返されているため無効です。 同様に、先頭に追加の「m」を含む「mmeow」は有効ですが、セグメントが欠落していたり​​文字の順序が乱れている「meoW」は無効です。 もう 1 つのトラップは、「m」などの 1 文字の文字列、または「meowA」などの無効な文字を含む文字列です。 

## アプローチ

 ブルートフォースアプローチは、繰り返される文字の有効な組み合わせをすべて列挙し、一致するかどうかをチェックすることです。 実際には、これは、異なる長さの「m」、「e」、「o」、「w」のすべてのシーケンスを生成し、それらに対して文字列をチェックすることを意味します。 これは理論的には正しいですが、不必要で非効率的です。 たとえば、長さ 50 の文字列の場合、50 のすべての分割を 4 つの正の整数に考慮する必要があり、これは組み合わせ的に急速に大きくなります。 

重要な洞察は、シーケンスを生成する必要がないということです。 予想される現在の文字グループを「m」、「e」、「o」、「w」の順に維持しながら、文字列を左から右にスキャンするだけです。 現在のグループと一致しない文字に遭遇した場合にのみ、次のグループに進みます。 無効な文字が見つかった場合、またはグループが正常に動作していない場合は、すぐに拒否できます。 これにより、問題は単純な線形スキャン (文字列あたり O(n)) に縮小されます。これは、指定された範囲には十分です。

 ## アルゴリズムのチュートリアル

 1. 比較を簡単にするために文字列を小文字に変換します。 これにより、大文字に対する繰り返しの条件チェックが不要になります。 
2. 文字列内の現在位置を追跡するポインタと、「m」で始まる期待される文字グループを追跡するインデックスを初期化します。 
3. 文字列を反復処理します。 各文字について、それが予期される文字グループと一致するかどうかを確認します。 存在する場合は、スキャンを続行します。 一致しない場合は、次の文字グループと一致するかどうかを確認します。 その場合は、グループ インデックスを進めて続行します。 それ以外の場合は、文字列を直ちに拒否します。 
4. 文字列全体をスキャンした後、4 つのグループすべてが順番に表示されていることを確認します。 グループが欠落している場合、または最後の文字が「w」グループに含まれていない場合は、文字列を拒否します。 
5. 文字列がすべての条件を満たしている場合は YES を返し、そうでない場合は NO を返します。 

機能する理由: このアルゴリズムは、各文字が現在予想されるグループまたはシーケンス内の次のグループのいずれかに属するという不変条件を維持します。 これにより、各文字グループの順序と空でない制約が尊重されることが保証されます。 逸脱は直ちに検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_meow(s: str) -> str:
    s = s.lower()
    pattern = "meow"
    index = 0
    n = len(s)

    i = 0
    while i < n:
        if s[i] == pattern[index]:
            i += 1
        elif index < 3 and s[i] == pattern[index + 1]:
            index += 1
            i += 1
        else:
            return "NO"
    
    return "YES" if index == 3 else "NO"

t = int(input())
for _ in range(t):
    n = int(input())
    s = input().strip()
    print(is_meow(s))
```大文字の個別の処理を避けるために、最初に文字列を小文字に変換します。 ポインタ`index`現在のシーケンスが終了したときにのみ、次の予期される文字に移動するようにします。 の`while`ループは繰り返しの文字と遷移をきれいに処理し、無効な文字または順序が検出された場合はすぐに「NO」を返します。 最終チェック`index == 3`これにより、必要な 4 つの文字グループがすべて処理されたことが確認されます。

 ## 特殊なケース

 のような文字列の場合`"meowmeow"`、アルゴリズムはそれを拒否します。 ポインタ`index`は、次に予期されるグループに一致する文字が見つかった場合にのみリセットされますが、最初の「w」グループが終了すると、文字列は「m」に続き、シーケンス内のそれ以上のグループには一致しません。 出力は正しく NO です。 

のために`"MmyaVW"`、アルゴリズムは小文字に変換します`'mmya vw'`。 インデックス 2 では、次のようになります。`'y'`これは「o」（現在のグループ）にも「w」（次のグループ）にも一致しないため、すぐに拒否されます。 

このアルゴリズムは、欠落しているグループ、余分な文字、繰り返されるグループ、および大文字のバリエーションを一貫して処理します。
