 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$頂点。 各頂点は次のいずれかで色付けされます。$k$色を付けるか、色を付けずに放置します。 木はつながっているので、$n-1$エッジ。 正確に選択するように求められます$k-1$エッジを削除して木を分割します。$k$コンポーネント。 コンポーネントに異なる色の頂点が含まれていない場合、エッジのサブセットは「良好」とみなされます。 色のない頂点は、色の付いたコンポーネントに自由に結合できます。 

入力により提供されるのは、$n$、$k$、各頂点の色 (0 は無色を意味します)、$n-1$ツリーを定義するエッジ。 出力は、素敵なサブセットの合計数を法的に計算したものです。$998244353$。 

制約により許可されるのは、$n$まで$3 \cdot 10^5$そして$k$まで$n$。 すべての総当たりの列挙$\binom{n-1}{k-1}$エッジ サブセットは、次の値を超える可能性があるため実行不可能です。$10^{20}$。 したがって、ソリューションは、時間に対して線形または線形に近い時間で動作する必要があります。$n$。 

エッジ ケースは、特定の色のすべての頂点がリーフである場合、複数の色がパスを共有する場合、または色の付いていない頂点が色付きの頂点の間に現れる場合に発生します。 コンポーネントに含まれる色が 1 つだけであることを確認せずに単純にツリーを分割すると、カウントが過剰になります。 たとえば、1-0-2 に色付けされた 3 つの頂点のチェーンでは、中央のエッジを削除すると、片側に異なる色の 2 つのコンポーネントが生成されますが、これは無効です。 

## アプローチ

 ブルートフォースアプローチはすべてを試みます$\binom{n-1}{k-1}$エッジのサブセットを作成し、接続をチェックし、各コンポーネントの色の制約を検証します。 これは小さな木に対しては正しく機能しますが、木にとっては扱いにくいです。$n \sim 10^5$。 

より高速なソリューションに対する重要な洞察は、優れたサブセットでは、異なる色の頂点を接続するエッジが同じコンポーネント内に残ることは決してないという観察から得られます。 同様に、異なる色の頂点を接続するエッジもカットする必要があります。 したがって、2 つの異なる色を接続するエッジとして_禁止エッジをマーク_し、同じ色の頂点または少なくとも 1 つの色のない頂点を接続するエッジとして_有効なエッジをカウント_することができます。 優れたサブセットとは、単に以下のものを選択したものです。$k-1$有効なエッジのうち、色分けに違反しないエッジ。 

これにより、単一の DFS を使用して問題を解決し、1 つの色のみまたは色のない頂点を接続するエッジを識別することができます。 異なる色を接続するエッジが除外されると、残りのエッジは独立したチェーンを形成します。$k-1$異なる色が結合しないエッジが有効です。 組み合わせ論とモジュラー演算を使用すると、すべての有効な選択を効率的にカウントできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((n-1 は k-1 を選択) * n) | O(n) | 遅すぎる |
 | DFS + 組み合わせ論 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーを隣接リストとして表します。 各頂点の色を保存します。0 は色なしを意味します。 
2. 任意の頂点から DFS を実行します。 各頂点で、そのサブツリーに特定の色が含まれているかどうかを記録します。 これにより、2 つの異なる色を接続するエッジを識別できます。 
3. 端点にゼロ以外の異なる色が含まれている場合、各エッジを「禁止」としてマークします。 これらのエッジは、適切なサブセットでは削除する必要があります。 
4. DFS 後、残りのエッジは同じ色の頂点または色のない頂点を接続します。 色を分離するには禁止エッジを削除する必要があるため、すべての素敵なサブセットにはすべての禁止エッジが含まれている必要があります。 
5. 有効な (禁止されていない) すべてのエッジを数えます。 選択する方法の数$k-1$削除するエッジは、各カラー サブツリー内のエッジの選択肢の数の積に等しくなります。 
6. モジュラー算術を使用して結果をモジュロで計算します$998244353$。 二項係数に組み合わせ式が必要な場合は階乗を事前計算します。 
7. 最終的なカウントを出力します。 

**機能する理由:** DFS 不変条件により、エッジごとに複数の色が接続されているかどうかがわかります。 正確に削除する$k-1$異なる色のマージを避けながらエッジを選択することは、許可された位置からのみエッジを選択することと同等であり、各コンポーネントに単一色の頂点が含まれることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

MOD = 998244353

def main():
    n, k = map(int, input().split())
    colors = list(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    for _ in range(n-1):
        u, v = map(int, input().split())
        adj[u-1].append(v-1)
        adj[v-1].append(u-1)

    # Mark edges that are "forbidden" (connect different colors)
    is_forbidden = [False] * (n-1)
    edge_index = {}
    idx = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                edge_index[(u, v)] = idx
                idx += 1

    def dfs(u, parent):
        # set of colors in subtree
        subtree_colors = set()
        if colors[u] != 0:
            subtree_colors.add(colors[u])
        for v in adj[u]:
            if v == parent:
                continue
            child_colors = dfs(v, u)
            # if both sides have different non-zero colors, mark edge forbidden
            if colors[u] != 0 and child_colors & {colors[u]} == set():
                e = (u, v) if u < v else (v, u)
                is_forbidden[edge_index[e]] = True
            subtree_colors |= child_colors
        return subtree_colors

    dfs(0, -1)

    # Count valid edges
    result = 1
    for forbidden in is_forbidden:
        if not forbidden:
            result = (result * 2) % MOD

    print(result)

if __name__ == "__main__":
    main()
```DFS は、異なる色を接続するエッジを正確に識別します。 次に、ナイスサブセットの数を次のように計算します。$2^{\text{number of valid edges}}$モジュロ$998244353$。 2 の乗算は、有効なエッジごとに、維持するか削除するかの 2 つの選択肢を表します。

```| ステップ | DFS リターン | エッジフォービドゥン |

### サンプル 2

 パスに沿って複数の色を使用して同様に構築されます。 DFS は、色を区切るエッジがマークされることを保証し、残りの有効なエッジが組み合わせの選択に寄与します。
