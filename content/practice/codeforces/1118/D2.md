 ## 解決策
 ## 問題の理解

 Polycarp は次のコースワークを書かなければなりません`m`しかし、彼はカフェインなしではいつまでも働くことができません。 彼は持っています`n`コーヒー1杯、それぞれにカフェインの摂取量が記載されている`a_i`。 彼は 1 日に何杯でも飲むことができますが、同じ日に飲む時間が遅くなるほど、各カップの生産性への貢献度は低くなります。 具体的には、その日の最初の一杯で、彼は書くことができるようになります。`a_i`ページ、2杯目`max(0, a_i - 1)`ページ、3番目`max(0, a_i - 2)`、 等々。 目標は、コースワークを完了するのに必要な日数を最小限に抑えることです。 

入力制約は大きくなります。`n`まで可能です`2 * 10^5`そして`m`まで`10^9`。 これにより、コーヒーカップの毎日のグループ分けをすべて試みるような強引なアプローチは即座に排除されます。なぜなら、コーヒーカップには指数関数的な可能性があるからです。`n`。 各カフェイン値も非常に大きくなり、最大で`10^9`したがって、累積和での整数のオーバーフローを避けるように注意する必要があります。 

主な微妙な点は、1 日あたりの収益が減少することにあります。 たとえば、Polycarp がカフェインの入ったカップを持っているとします。`[3, 1, 2]`コースワークを 1 日で完了したいと考えている場合、書かれたページ数を最大化するために、カップを高いものから低いものまで注文する必要があります。1 日の成果は次のとおりです。`3 + max(0,2-1) + max(0,1-2)=3 + 1 + 0 = 4`。 毎日カップを分類しない単純な貪欲な人は、生産性を過小評価する可能性があります。 カップが少なすぎて到達できない場合にも、別のエッジケースが発生します。`m`各カップを別々の日に消費した場合でも、ページ数は次のとおりです。`[1,1,1]`と`m=5`、答えは`-1`。 

## アプローチ

 強引な方法は、カップのすべてのパーティションを数日間試して、少なくとも書き込みが可能な配置かどうかを確認することです。`m`ページ。 これは理論的には正しいですが、パーティションの数は次のように指数関数的に増加します。`n`、したがってこれは不可能です`n`まで`2 * 10^5`。 

重要な観察は、日数を最小限にするには、毎日書き込まれるページを最大にする必要があるということです。 1日以内に、より大きなカフェインカップを最初に摂取する必要があります。これは、より早いカップの方がより効果的であるためです。 これにより、1 日の生産性を次の合計として計算できます。`max(0, a_i - j)`ソートされたリストに対して、`j`は、その日のカップの 0 から始まるインデックスです。 

次に、問題は次のような決定の質問に帰着します。`d`数日、ポリカープは完成できるだろうか`m`カップを最適に分配するとページ数はどうなるでしょうか? これは、カフェイン カップを降順に並べ替え、毎日のページ数を合計すると効率的に答えることができます。`d`-th カップ (初日に各ポジションでカップを獲得できるようにする)`0, d, 2d,...`、2日目`1, 1+d, 1+2d,...`等々）。 これにより、収益逓減を考慮しながら、毎日の生産性を最大化するためにカップが日にちに割り当てられるようになります。 特定の条件の実現可能性を確認できたら、`d`、二分探索`d`最小日数を与えます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (二分探索 + 貪欲) | O(n log n + n log n) = O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのコーヒーカップをカフェインの多い順に並べます。 これにより、1 日のうちで最も生産性の高いカップが最初に消費されることが保証されます。 
2. 関数を定義する`can_finish(days)`少なくとも書き込みが可能かどうかを決定します`m`のページ`days`日々。 この関数内で、毎日のインデックスを反復処理します。`i`から`0`に`days-1`。 
3. その日のために`i`、ページを次のように合計します`sum(max(0, cups[i + j*days] - j) for j in range(...))`。 ここ`i + j*days`日に割り当てられたカップのインデックスを作成します`i`位置にある`j`、前日に割り当てられたカップをスキップします。 この配分は収益逓減を考慮しています。`j`ペナルティを増額します。 
4. 全日のページ数の累計が少なくとも`m`、Trueを返します。 それ以外の場合は、False を返します。 
5.二分探索を適用します`d`から`1`に`n`。 もし`can_finish(d)`True です。小さくしてみてください`d`日数を最小限に抑える。 False の場合は増加します`d`。 
6. コースワークを完了できる日数がない場合は、出力します。`-1`。 それ以外の場合は、最小値を出力します`d`見つかった。 

これが機能するのは、カップを分類することで最も生産性の高いカップが最も早く使用されることが保証され、ラウンドロビン方式でカップが分配されるためです。`d`days は、収益逓減ルールに基づいて毎日の生産量を最大化します。 不変条件は、どのような割り当てでも、その日の早い時間にカフェイン カップを増やしても総ページ数を減らすことができないということです。そのため、貪欲な分散により、固定のページ数で可能な最大のページ数が達成されます。`d`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_finish(cups, days, m):
    total = 0
    n = len(cups)
    for i in range(days):
        j = 0
        while i + j * days < n:
            total += max(0, cups[i + j * days] - j)
            j += 1
            if total >= m:
                return True
    return total >= m

def main():
    n, m = map(int, input().split())
    cups = list(map(int, input().split()))
    cups.sort(reverse=True)

    left, right = 1, n
    answer = -1
    while left <= right:
        mid = (left + right) // 2
        if can_finish(cups, mid, m):
            answer = mid
            right = mid - 1
        else:
            left = mid + 1
    print(answer)

if __name__ == "__main__":
    main()
```このソリューションでは、最初にコーヒー カップを分類して、初期の生産性を最大化します。 ヘルパー関数は、数日間ラウンドロビンでカップを分配することにより、収益逓減をシミュレートします。 二分探索により、実行可能な最小日数が効率的に見つけられます。 主な微妙な点には、次のようなものがあります。`max(0, ...)`ペナルティがカフェインを超えた場合に何も貢献しないカップを処理するため、およびラウンドロビン インデックスの計算`i + j*days`。 

## 実用的な例

 サンプル 1:`5 8`と`cups=[2,3,1,1,2]`。 

| 日 | 選んだカップ | 書かれたページ | 累計 |
 | --- | --- | --- | --- |
 | 1 | 3 | 3 | 3 |
 | 2 | 2,5 | 2+(2-1)=3 | 6 |
 | 3 | 1,4 | 2+(1-1)=2 | 8 |

 答え: 4日です。 ラウンドロビン割り当てにより、最大生産性を超える日はなくなります。 

サンプル 2:`3 5`と`cups=[1,1,1]`。 

| 日 | 選んだカップ | 書かれたページ | 累計 |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 |
 | 2 | 1 | 1 | 2 |
 | 3 | 1 | 1 | 3 |

 答え: -1。 それぞれのカップを個別に使用しても、`m=5`到達できません。
