 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点。各頂点は赤、青に色付けされるか、または色付けされないままにすることができます。 このタスクは、削除されたときにツリーを 2 つのコンポーネントに分割し、どちらのコンポーネントにも赤と青の頂点の両方が含まれないようにするエッジを数えることです。 言い換えれば、そのようなエッジを切断した後、結果として得られる各ピースには、赤の頂点のみ、青の頂点のみ、または任意の数の無色の頂点を含めることができますが、赤と青が混在することはできません。 

入力により、頂点の数、各頂点の色のリスト、および`n-1`ツリーを定義するエッジ。 出力は単一の整数、つまり上記の条件を満たす「ナイス エッジ」の数です。 

制約は大きく、頂点数は最大 300,000 です。 これは、各エッジを削除して、結果として得られる各コンポーネントの色をスキャンすることをシミュレートする余裕がないことを意味します。 ナイーブ`O(n^2)`アプローチには横断が含まれる可能性があります`n`それぞれの頂点`n-1`エッジでは明らかに遅すぎます。 理想的には、直線的な時間で実行されるソリューションが必要です`O(n)`。 

明らかではないエッジ ケースには、(鎖のように) 大きく歪んだツリー、すべての色の頂点が 1 つの小さなサブツリーに集中している場合、または特定の色の葉に直接接続されているエッジが含まれます。 たとえば、中央のノードが赤で葉が青である 3 ノード チェーンは、赤のノードに接触するエッジを削除すると両方の色を含むコンポーネントが生成される可能性があることを正しく識別する必要があり、良好なものとしてカウントされるべきではありません。 

## アプローチ

 ブルートフォースアプローチでは、すべてのエッジを個別にチェックします。 各エッジについて、それを削除し、結果として得られる 2 つのコンポーネントに対して DFS を実行し、それぞれの色をカウントします。 いずれかのコンポーネントに赤と青の両方の頂点がある場合、エッジは適切ではありません。 これは原理的には正しいですが、`n = 3 * 10^5`、それは必要になります`O(n^2)`実行不可能な操作。 

最適なソリューションの重要な観察は、各エッジがツリーを正確に 2 つのコンポーネントに分割することです。 ツリー全体の赤と青の頂点の総数がわかっていて、エッジの片側をルートとするサブツリーに赤と青の頂点がいくつ存在するかを計算すると、このエッジの切断が有効かどうかを即座に判断できます。 具体的には、1 つの端点をルートとするサブツリーに赤い頂点や青い頂点がなく、ツリーの残りの部分にも赤い頂点や青い頂点がない場合、エッジは良好です。 これにより、問題は各サブツリーの赤と青の頂点の数を計算する単一の DFS トラバーサルに軽減され、その後、各エッジの単純なチェックが行われます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | サブツリーのカウント DFS | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 頂点数を読み取る`n`そしてカラーリスト。 色を数に変換します。`1`赤の場合、`2`青の場合、`0`無着色の場合。 
2. 以下からツリーの隣接リストを構築します。`n-1`エッジ。 
3. ツリー全体の赤と青の頂点の合計数を数えます。 これにより、各サブツリーをチェックするための参照が得られます。 
4. 任意のノード (root の) から DFS を実行します。`1`便宜上）。 For each node, compute the total number of red and blue vertices in its subtree by summing the counts from all children and adding 1 if the current node is colored.
 5. DFS の後、すべてのエッジに対して反復処理を行います。 親からのエッジを考慮する`u`子供に`v`。 をルートとするサブツリー`v`もっている`red_v`赤と`blue_v`青い頂点。 補完的なコンポーネントには、`total_red - red_v`赤と`total_blue - blue_v`青い頂点。 どちらかの場合`red_v == 0 or blue_v == 0`そして同時に`(total_red - red_v == 0 or total_blue - blue_v == 0)`、エッジはいいです。 
6. このプロパティを満たすすべてのエッジをカウントし、結果を出力します。 

機能する理由: DFS は、すべてのサブツリーに赤と青の頂点がいくつあるかを正確に知ることを保証します。 合計数を使用すると、「他のコンポーネント」を横断することなく、そのコンポーネント内の色付きの頂点の数を導き出すことができます。 これにより、DFS 後にすべてのエッジが一定時間内に正しく評価されるようになり、全体的な結果が得られます。`O(n)`複雑。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

n = int(input())
colors = list(map(int, input().split()))

adj = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

total_red = sum(1 for c in colors if c == 1)
total_blue = sum(1 for c in colors if c == 2)

subtree_counts = [[0, 0] for _ in range(n)]  # [red, blue]

def dfs(u, parent):
    red = 1 if colors[u] == 1 else 0
    blue = 1 if colors[u] == 2 else 0
    for v in adj[u]:
        if v == parent:
            continue
        dfs(v, u)
        red += subtree_counts[v][0]
        blue += subtree_counts[v][1]
    subtree_counts[u] = [red, blue]

dfs(0, -1)

result = 0
for u in range(n):
    for v in adj[u]:
        if v < u:
            continue  # ensure each edge is considered only once
        red_v, blue_v = subtree_counts[v]
        red_other = total_red - red_v
        blue_other = total_blue - blue_v
        if (red_v == 0 or blue_v == 0) and (red_other == 0 or blue_other == 0):
            result += 1

print(result)
```隣接リストにより効率的なトラバースが保証され、`dfs`すべてのサブツリーの赤と青のカウントを計算します。 エッジを 1 回だけ反復することで、二重カウントを回避できます。 使用する`v < u`これにより、各エッジが一方向に考慮されるようになります。 再帰制限を設定すると、深いツリーのスタック オーバーフローが防止されます。
