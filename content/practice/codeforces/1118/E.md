 ## 解決策
 ## 問題の理解

 私たちは舞踏会でダンサーに色を割り当てるという任務を負っています。 がある`n`それぞれ男性と女性からなるペア、そして`k`利用可能な色。 各ペアは、4 つのルールが満たされるように男性用の色と女性用の色を受け取る必要があります。つまり、同じペアは存在しない、同じペアの男性と女性が同じ色を持つことはない、連続するペアは男性と女性の両方で異なる色でなければなりません。 

入力はペアの数を示します`n`そして色の数`k`。 出力は、割り当てが不可能であることを示すか、有効な割り当てを 1 つ生成する必要があります。 と`n`そして`k`最大 200,000 で 2 秒の時間制限があるため、O(n) または O(n log n) より大幅に遅いアルゴリズムは実行できません。 あらゆる色の組み合わせを試す強引なアプローチには、大まかに次の作業が含まれます。`k^(2n)`可能性はありますが、それは完全に非現実的です。 

次の場合、微妙なエッジケースが発生します。`k = 2`そして`n > 2`。 たった 2 色では、「どの位置でも同じ色が連続しない」と「男女の色が異なる」という制約を両方とも満たすことはできません。`n`形成できる個別のペアの数を超えています。 たとえば、次の場合`n = 3`そして`k = 2`、次のようなペアを交互に試してみます`(1,2), (2,1)`ルールの 1 つが必然的に違反される 3 番目のペアが残ります。 

## アプローチ

 ブルートフォースアプローチでは、次のすべてのシーケンスを生成しようとします。`n`色のペアで、各シーケンスを 4 つのルールに照らしてテストします。 可能なシーケンスの総数は次のとおりです。`k^(2n)`、次のような控えめな値でも爆発的に増加します。`n=10`そして`k=5`。 理論的には正しいですが、これは完全に不可能です`n`200,000まで。 

高速なソリューションを構築するための重要な観察事項は、制約がローカルであるということです。つまり、各ペアは前のペアとのみ相互作用し、グローバルには、同一のペアが 2 つ存在することはできません。 これは、検索ではなく構築ベースのアプローチを示唆しています。 すべての有効なペアを生成できます`(b, g)`と`b ≠ g`次に、連続するペアが両方の位置で異なるようにシーケンスに配置します。 あるので`k*(k-1)`有効な個別のペア、有効なシーケンスが存在する場合`k*(k-1) ≥ n`。 これにより、不可能なケースが即座に除外されます。 

それが可能であることがわかったら、循環パターンを使用して色を割り当てることができます。 すべてのペアを反復処理できます`(b, g)`どこ`b ≠ g`そしてそれらを順番に割り当てます。 異なるペアの合計数は少なくとも`n`、開始点を選択し、必要に応じて折り返しながら、それらを順に実行できます。 これにより、同一の連続ペアが自動的に防止され、男性/女性の色が同じペアが存在しないことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^(2n)) | O(n) | 遅すぎる |
 | 建設的な循環 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.次のことを確認します`k = 2`そして`n > 2`。 その場合は、すぐに「NO」を出力して終了します。 のみ`n ≤ 2`連続ペア制約により 2 色で可能です。 
2. すべての個別の有効なペアのリストを初期化します。`(b, g)`どこ`b`そして`g`いる`1..k`そして`b ≠ g`。 
3. サイズの空の結果配列を準備します。`n`。 
4. ペアを周期的に割り当てます。`i`結果配列の - 番目のペアから、`(i mod total_pairs)`有効なペアのリストの - 番目のペア。 
5. 「YES」とその結果のペアを出力します。 

機能する理由: この構造では、事前計算のみを行うため、男性と女性で同じ色のペアが存在しないことが保証されます。`b ≠ g`。 連続するペアは、循環ステップが個別の有効なペアのリスト内の新しいペアに移動するため、異なります。 異なるペアの総数は`k*(k-1)`少なくとも`n`のために`k ≥ 2`、割り当てでは選択肢がなくなることはなく、ペアが繰り返されないことが保証され、4 つのルールがすべて満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())
    if k == 2 and n > 2:
        print("NO")
        return

    pairs = []
    for b in range(1, k+1):
        for g in range(1, k+1):
            if b != g:
                pairs.append((b, g))

    result = []
    for i in range(n):
        result.append(pairs[i % len(pairs)])

    print("YES")
    for b, g in result:
        print(b, g)

if __name__ == "__main__":
    main()
```このソリューションはまず、不可能なケースを処理します。`k = 2`そして`n > 2`。 次に、有効なものをすべて構築します`(b, g)`ペア。 これらのペアを循環して、`n`ポジションに応じて、4 つのルールすべてが保証されます。 モジュロにより、有効なペア配列外のインデックスにアクセスすることがなくなり、連続した差分に必要な循環プロパティが維持されます。

 ## 特殊なケース

 もし`n = 2`そして`k = 2`、解はペアを生成します`(1,2),(2,1)`。 循環アルゴリズムは、ペアを繰り返したり隣接制約に違反したりすることなく、この小さなケースを正しく処理します。 のために`k = 2`そして`n = 3`、ソリューションは不可能を検出し、「NO」を出力します。 大型用`k > n`、循環割り当てにより、ペアの繰り返しや連続した競合が保証されません。
