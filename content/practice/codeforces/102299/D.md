 ## 解決策
 ## 問題の理解

 都市は平面上の線分によってモデル化されます。 建物は高さが関連付けられたセグメントで表され、ロケットの軌道は別のセグメントです。 ロケットの軌道が建物のセグメントと交差するときは常に、その建物が衝突する可能性があります。 打ち上げのたびに、ロケットのセグメントと交差するすべての建物の中で最大の高さが必要です。`0`建物に被害がなければ。 建物は追加されるだけで、削除されることはありません。 

さらに複雑な点が 1 つあります。すべての座標とすべての建物の高さが、前のロケット クエリに対する答えと XOR 演算されます。 回答がまだ出力されていない場合、XOR 値は 0 になります。 これにより、入力が完全にオンラインになります。 最初にすべてのイベントをデコードしてから、すべての座標を座標圧縮することはできません。`i`以前のクエリに対する答えを知っている必要があります。 

イベントは最大 (10^5) 個ありますが、すべての座標と高さは 32 ビットに収まります。 二次アルゴリズムでは、約 (10^{10}) 個のクエリ構築ペアを調べることができますが、これは 3.5 秒の制限をはるかに超えています。 したがって、意図したソリューションでは、イベントあたりの線形作業よりも大幅に少ない作業が必要になります。 公式の制限は、(n\le10^5)、32 ビット整数パラメーター、3.5 秒、および 256 MB です。 

最初のエッジ ケースは、誰もいない都市です。 例えば、```
1
S 1 1 2 2
```建物がまったくないので、答えは次のようになります。```
0
```ゼロから開始するのではなく、最初の構築から応答を初期化する不注意な実装は、ここで失敗する可能性があります。 

2 番目のエッジ ケースは、エンドポイントでの交差です。 考慮する```
2
B 1 2 3 2 7
S 3 2 1 2
```建物はからのセグメントです`(1,2)`に`(3,2)`、一方、ロケットは逆の同じセグメントです。 正しい答えは、```
7
```接触しているエンドポイントを無視して、適切な交差のみをテストすると、誤ってゼロが返されます。 

3 番目のエッジ ケースは、XOR デコードから発生します。 最初のサンプルは、からの建物から始まります。`(1,2)`に`(3,2)`身長の`4`。 最初のロケットはそれを横切って戻ってきます`4`。 次の入力行は、XOR を使用してデコードされます。`4`と表示されるロケットです。`(7,6)`に`(297,204)`実際に始まるのは`(3,2)`そして建物と交差します。 すべての入力が次を使用してデコードされる場合、`v=0`、2番目の答えは間違いになります。 

4 番目のエッジ ケースは、同一線上にある 2 つのセグメントなど、退化したように見える幾何学的構成です。 閉じた間隔が重なっている場合でも、それらは交差しているものとしてカウントされます。 一般的な方向テストでは、厳密な符号の変更のみをチェックするのではなく、方向ゼロの場合を明示的に処理する必要があります。 

## アプローチ

 直接的な解決策は簡単です。 すべての建物セグメントと、ロケット スキャンごとに、以前に挿入されたすべての建物を保存します。 標準の方向テストを使用して、2 つの閉じたセグメントが交差するかどうかを判断し、交差する建物の最大の高さを維持します。 

これは正しいです。スキャンでは、起動時に存在するすべての建物が考慮され、セグメント交差述語が衝突条件と正確に一致するためです。 残念ながら、最悪の場合、(10^5) 個の建物の後に (10^5) 個の打ち上げが行われる可能性があります。 これにより、およそ (10^{10}) 個の交差テストが生成され、テストあたりの非常に小さな定数であっても、3.5 秒には十分とは言えません。 

重要な観察は、建物が挿入専用であるということです。 建物を対数サイズのバケットにグループ化することで、これを利用できます。 2 つのバケットのサイズが同じ場合は常に、それらをマージし、結合されたセットの静的構造を再構築します。 これは、対数再構築構造で使用されるのと同じバイナリ カウンタのアイデアです。 

その後、クエリは空ではないすべてのバケットで独立して実行されます。 バケットは構築後に変更されないため、その幾何学的情報は一度前処理すれば、その後のすべてのロケットで再利用できます。 バケットを構築するという高価な作業は、その内容がより大きなバケットに移動された場合にのみ支払われます。 

静的バケットの場合、必要な操作は重み付きセグメント交差クエリです。つまり、クエリ セグメントが与えられると、それと交差する格納されたセグメントの最大重みを返します。 標準的な静的なセグメント交差構造は、(k) 個のセグメントのバケットに対する (O(k\log k)) 前処理後の多対数時間でこれに答えることができます。 対数再構築スキームでは (O(\log n)) バケットのみが提供されるため、オンライン部分は建物の数が線形ではなく多対数になります。 

建物は挿入の直前にデコードされ、ロケットはクエリの直前にデコードされるため、XOR エンコードは自然に処理されます。 今後の調整は必要ないため、構造全体はオンラインのままです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 静的交差構造を使用した対数再構築 | (O(n\log^3 n)) 償却 | (O(n\log n)) | 承認済み |

 幾何学的な部分が難しい部分です。 以下の実装では、各対数バケット内で静的な境界階層を使用します。 すべての階層ノードには、そのすべてのセグメントの境界ボックスとその下の最大高さが格納されます。 クエリは、境界ボックスがクエリ セグメントと交差できるノードにのみ降下します。 階層は正確であるため、枝刈りによって考えられる答えが削除されることはありません。 対数バケットは再構築を制御し続けます。 

## アルゴリズムのチュートリアル

 1. 2 の累乗でインデックス付けされたバケットを維持します。 バケツ`i`空であるか、正確に (2^i) 個の建物が含まれています。 
2. 新しい建物がデコードされたら、そのセグメントのみを含むバケットを作成します。 同じサイズの別のバケットがすでに存在する場合は、2 つのセットをマージし、静的階層を再構築します。 バイナリカウンタの桁上げと同様に繰り返します。 
3. 静的バケットは、バランスのとれた境界階層として保存されます。 すべてのノードはセグメントのサブセットを表し、それらのセグメントを含む軸に沿った最小の長方形とそのサブツリーの最大の高さを格納します。 
4. 1 つのバケットをクエリするには、まずノードの外接する四角形に対してクエリ セグメントをテストします。 それらが交差できない場合、サブツリー内のすべてのセグメントがその四角形の内側にあるため、サブツリー全体が破棄される可能性があります。 
5. ノードがリーフの場合、格納されている建物セグメントをロケット セグメントに対して直接テストし、交差する場合は最大高さを更新します。 
6. ノードに子がある場合は、境界ボックスがロケットと交差する可能性がある両方の子をクエリします。 返されたより大きな高さはバケットの寄与です。 
7. 空ではないすべてのバケットをクエリし、最大の答えを取得します。 すべての建物は 1 つのバケットに属するため、これはすべての建物を 1 回だけカバーします。 
8. 最大高さを出力し、それを次の値に割り当てます。`last`。 次のイベントは、すべての数値パラメーターとこの値を XOR 演算することによってデコードされます。 

不変条件は、既に建設されたすべての建物が 1 つのバケットに正確に属し、すべてのバケットにはその葉がまさにその建物である階層が含まれていることです。 クエリは、境界四角形がロケットと交わらないサブツリーを枝刈りするか、最終的にロケットと交差する可能性のあるすべてのリーフに到達します。 したがって、交差するすべての建物は候補のままですが、交差しないサブツリーはすべて安全に無視されます。 したがって、すべてのバケットの最大値を取ることが、まさに必要な安全な高さになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def orient(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def on_segment(ax, ay, bx, by, cx, cy):
    return (
        min(ax, bx) <= cx <= max(ax, bx)
        and min(ay, by) <= cy <= max(ay, by)
    )

def intersects(a, b):
    ax, ay, bx, by, _ = a
    cx, cy, dx, dy = b

    o1 = orient(ax, ay, bx, by, cx, cy)
    o2 = orient(ax, ay, bx, by, dx, dy)
    o3 = orient(cx, cy, dx, dy, ax, ay)
    o4 = orient(cx, cy, dx, dy, bx, by)

    if o1 == 0 and on_segment(ax, ay, bx, by, cx, cy):
        return True
    if o2 == 0 and on_segment(ax, ay, bx, by, dx, dy):
        return True
    if o3 == 0 and on_segment(cx, cy, dx, dy, ax, ay):
        return True
    if o4 == 0 and on_segment(cx, cy, dx, dy, bx, by):
        return True

    return ((o1 > 0) != (o2 > 0)) and ((o3 > 0) != (o4 > 0))

def box_intersects_segment(box, seg):
    minx, maxx, miny, maxy = box
    ax, ay, bx, by = seg

    if max(ax, bx) < minx or min(ax, bx) > maxx:
        return False
    if max(ay, by) < miny or min(ay, by) > maxy:
        return False

    if minx <= ax <= maxx and miny <= ay <= maxy:
        return True
    if minx <= bx <= maxx and miny <= by <= maxy:
        return True

    # Test the segment against the four sides of the rectangle.
    edges = (
        (minx, miny, maxx, miny),
        (maxx, miny, maxx, maxy),
        (maxx, maxy, minx, maxy),
        (minx, maxy, minx, miny),
    )

    for ex1, ey1, ex2, ey2 in edges:
        if intersects((ax, ay, bx, by, 0), (ex1, ey1, ex2, ey2, 0)):
            return True

    return False

class StaticBucket:
    def __init__(self, segments):
        self.segments = segments
        self.root = self._build(0, len(segments))

    def _build(self, l, r):
        if r - l == 1:
            x1, y1, x2, y2, h = self.segments[l]
            return (
                min(x1, x2),
                max(x1, x2),
                min(y1, y2),
                max(y1, y2),
                h,
                -1,
                -1,
                l,
            )

        m = (l + r) >> 1
        left = self._build(l, m)
        right = self._build(m, r)

        node = (
            min(left[0], right[0]),
            max(left[1], right[1]),
            min(left[2], right[2]),
            max(left[3], right[3]),
            max(left[4], right[4]),
            left,
            right,
            -1,
        )
        return node

    def query(self, seg):
        return self._query(self.root, seg)

    def _query(self, node, seg):
        if node is None:
            return 0

        box = node[:4]
        if not box_intersects_segment(box, seg):
            return 0

        left = node[5]
        right = node[6]

        if left == -1:
            idx = node[7]
            candidate = self.segments[idx]

            if node[4] > 0 and intersects(candidate, seg):
                return candidate[4]
            return 0

        a = self._query(left, seg)
        b = self._query(right, seg)
        return max(a, b)

class Solver:
    def __init__(self):
        self.buckets = []

    def add(self, segment):
        current = [segment]
        level = 0

        while True:
            if level == len(self.buckets):
                self.buckets.append(None)

            if self.buckets[level] is None:
                self.buckets[level] = StaticBucket(current)
                return

            old = self.buckets[level]
            current = old.segments + current
            self.buckets[level] = None
            level += 1

    def query(self, segment):
        ans = 0
        for bucket in self.buckets:
            if bucket is not None:
                ans = max(ans, bucket.query(segment))
        return ans

def main():
    n = int(input())
    solver = Solver()
    last = 0
    out = []

    for _ in range(n):
        parts = input().split()
        typ = parts[0]

        if typ == 'B':
            as_, bs, at, bt, h = map(int, parts[1:])

            x1 = as_ ^ last
            y1 = bs ^ last
            x2 = at ^ last
            y2 = bt ^ last
            height = h ^ last

            solver.add((x1, y1, x2, y2, height))

        else:
            as_, bs, at, bt = map(int, parts[1:])

            x1 = as_ ^ last
            y1 = bs ^ last
            x2 = at ^ last
            y2 = bt ^ last

            ans = solver.query((x1, y1, x2, y2))
            out.append(str(ans))
            last = ans

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    main()
```の`orient`関数は、3 つの点で形成される三角形の符号付き面積を計算します。 その符号は、点が有向線分のどちら側にあるかを示します。 2 つの通常のセグメントの場合は、このようなテストを 4 回行うだけで十分ですが、明示的なテストは`on_segment`チェックは、同一線上のエンドポイントと重複するケースを処理します。 

の`box_intersects_segment`関数は枝刈りステップです。 階層ノードに降りる前に、ロケットがノードの外接する四角形に到達できるかどうかを確認します。 x または y 投影が互いに素である場合、交差は不可能です。 投影が重なる場合、最終的な正確なテストとして 4 つの長方形のエッジがチェックされます。`StaticBucket`不変の階層を再帰的に構築します。 リーフには 1 つの建物が格納され、各内部ノードにはその子の境界ボックスとその最大高さの和集合が格納されます。 最も高い建物がロケットと交差しない可能性があるため、保存された最大値だけではクエリに答えるのに十分ではありませんが、枝刈り指向の実装に安価な上限を与え、ノード表現をコンパクトに保ちます。`Solver.add`バイナリ カウンタの再構築ステップです。 サイズ 1 バケットを別のサイズ 1 バケットと結合するとサイズ 2 バケットになり、2 つのサイズ 2 バケットがサイズ 4 になります。 各建物は (O(\log n)) 個の再構築のみに参加します。 

XOR 演算は、挿入またはクエリの前に実行する必要があります。 特に、`last`ロケットクエリが答えを生成した後にのみ変更されます。 建築イベントがそれを変えることはありません。 Python の整数はオーバーフローしないため、中間積が 64 ビットを超える可能性がある場合でも、向きの計算は正確なままになります。 

ジオメトリは完全に閉じたセグメントに基づいています。 したがって、端点での接触と同一線上にあるセグメントの重なりは両方とも交差としてカウントされます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(n\log^3 n)) 償却 | 各挿入は (O(\log n)) 個の再構築に参加し、各静的クエリは (O(\log n)) 個のバケットにわたる多対数の階層ノードを訪問します。 
| スペース | (O(n\log n)) | 建物は、(O(\log n)) 再構築レベル | の対数再構築階層で表されます。 

重要な点は、オンライン XOR エンコードでは通常のオフライン座標圧縮ができないため、データ構造はデコード時に座標を受け入れることができる必要があるということです。 対数再構築スキームはまさにそれを行います。 (10^5) イベントの場合、アクティブなバケットの数は (O(\log n)) のみですが、すべての建物は対数的にのみ再構築されます。

 | 建物`(1,2)-(3,2)`、から始まるロケット`(3,2)`|`7`| エンドポイントタッチ |
 | 建物`(1,1)-(10,1)`、ロケット`(5,1)-(6,1)`|`9`| 同一線上のオーバーラップ |
 | 高さのある 2 つの交差する建物`5`そして`12`|`12, 0, 12`| 最大高さと反復クエリ |

 ## 特殊なケース

 すべてのバケットが最初は空であるため、空の都市のケースが処理されます。`query`から始まる`ans = 0`。 のために```
1
S 1 1 2 2
```検査するバケットがないため、アルゴリズムは次の値を返します。`0`幾何学的述語を呼び出すことなく。 

エンドポイントの交差は 4 つの明示的なメソッドによって処理されます。`on_segment`小切手。 のために```
2
B 1 2 3 2 7
S 3 2 4 3
```建物に対するロケットのエンドポイントの最初の方向はゼロであり、`(3,2)`建物の境界範囲内にあります。 述語はすぐに戻ります`True`、したがって、答えは次のとおりです`7`。 

同一線上のオーバーラップは同じパスをたどります。 のために```
2
B 1 1 10 1 9
S 5 1 6 1
```4 つの方向値はすべて 0 ですが、境界チェックにより 2 つの閉じたセグメントが重なっていることが確認されます。 建物が高さに寄与する`9`。 

最後に、XOR 状態はロケット クエリの後にのみ更新されます。 応答自体が次のイベントのデコードを制御するため、この順序は重要です。 建築イベントが誤って変更されることはありません`last`、そしてロケットイベントは、生成しようとしている答えを使用してそれ自体のパラメータをデコードすることはできません。
