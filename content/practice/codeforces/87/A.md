 ## 解決策
 ## 問題の理解

 Vasya は、2 つのエンドポイントを持つ地下鉄支線の中央駅にいます。 各エンドポイントは、彼のガールフレンドの 1 人 (Dasha または Masha) に対応します。 ダーシャ駅行きの電車は毎日到着します。`a`マーシャの駅行きの電車は毎分到着します。`b`分。 ヴァシャはふとした瞬間に駅に到着し、いつも最初に来る電車に乗ります。 2本の電車が同時に到着した場合、彼は本数が少ない方、つまり電車の間隔が長い彼女の方へ向かう電車に乗ります。 

入力は 2 つの整数を提供します`a`そして`b`、両端への列車の周波数を表します。 出力は、どちらのガールフレンドの Vasya が最終的により頻繁に訪問するか、または両方を同じ頻度で訪問する場合は「等しい」である必要があります。 

制約は、`1 ≤ a, b ≤ 10^6`そして`a ≠ b`は、不定のタイムラインを分単位でシミュレートできないことを意味します。 ソリューションでは、強引な列挙ではなく、周波数パターンと周期性について推論する必要があります。 毎分シミュレーションする素朴なアプローチでは、最大 10^6 回の反復が必要になりますが、これは許容範囲ですが、数論を使用すると、はるかに優れた結果を得ることができます。 

エッジケースは、次の最小公倍数の場合に発生します。`a`そして`b`最初に到着する列車が同時刻に到着する可能性がある間隔が生じるため、Vasya は頻度の低い列車を選択する必要があります。 たとえば、`a = 3`そして`b = 7`、一定の期間にわたって`21`分 (3 と 7 の最小公倍数)、周期は対称ではありません。 単に比較するだけの不用意な実装`a`そして`b`同率を考慮しないと、間違った答えが出力されてしまいます。 

## アプローチ

 ブルートフォースアプローチは、から毎分をシミュレートすることです。`0`に`LCM(a, b)`ダーシャまたはマーシャ行きの電車が何回先に到着するかを数えてください。 間隔ごとにカウンターをインクリメントし、同時到着を明示的に処理します。 これが機能するのは、列車のスケジュールが周期的に設定されているためです。`LCM(a, b)`。 操作数はおよそ`LCM(a, b) / min(a, b)`、最悪の場合は 10^12 に達する可能性があり、妥当な制限をはるかに超えています。 

重要な観察は、ヴァシャの決定は到着後の最初の電車にのみ依存するということです。 列車の到着間隔は一定であり、タイブレークルールにより、本数の少ない列車が優先されます。 の最大公約数 (GCD) に正規化することにより、`a`そして`b`に比例して期間をセグメントに分割できます。`a`そして`b`GCD を基準にして。 具体的には、各 LCM 期間で、ヴァシャはダーシャの列車に乗ります。`b / gcd(a, b)`時間とマーシャの列車`a / gcd(a, b)`回。 これら 2 つの回数を比較すると、彼がどちらのガールフレンドに頻繁に会いに行くかが分かります。 

この観察により、解は定数時間の比較に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(LCM(a, b)) | お(1) | a、b が大きい場合は遅すぎます |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り`a`そして`b`入力から。 これらはそれぞれダシャとマーシャまでの列車の間隔を表します。 
2. の最大公約数を計算します。`a`そして`b`。 この GCD は、到着パターンが繰り返される基本的な期間を表します。 
3. 1 LCM 期間内にダシャへの出発が何回発生するかを決定します。 これは`b // gcd(a, b)`。 同様に、マーシャへの出発を決定します。`a // gcd(a, b)`。 
4. カウントを比較します。 ダシャ行きの出発便の方が多い場合は「ダシャ」と印刷してください。 マーシャ側の数字が大きい場合は「マーシャ」と印刷します。 カウントが等しい場合は、「Equal」と出力します。 

不変条件は、どの LCM 期間内でも、Vasya の選択はこれらの回数に従って配分されることです。また、パターンは無限に繰り返されるため、これらの回数が彼の長期的な訪問頻度を完全に決定します。 GCD スケーリングにより、端数の間隔が失われないことが保証され、離脱を比例的にカウントすることでタイブレーカー ルールが自動的に取得されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

a, b = map(int, input().split())

g = math.gcd(a, b)
visits_dasha = b // g
visits_masha = a // g

if visits_dasha > visits_masha:
    print("Dasha")
elif visits_masha > visits_dasha:
    print("Masha")
else:
    print("Equal")
```コードはまず列車間隔を読み取り、基本的な繰り返し周期を与える GCD を計算します。 次に、反対側の間隔を GCD で割ることにより、列車の到着数をスケーリングします。 比較は、アルゴリズムのウォークスルーからの推論に直接続きます。 丸め誤差を避けるために、浮動小数点除算ではなく整数除算を使用するように注意する必要があります。 

## 実用的な例

 サンプル 1:`a = 3`、`b = 7`| ステップ | GCD | ダーシャ訪問 | マーシャを訪問 | 決定 |
 | --- | --- | --- | --- | --- |
 | GCD(3,7) を計算する | 1 | 7 | 3 | ダーシャ |

 これは、21 分間 (LCM 3 と 7) の間に、ヴァシャがダーシャの列車に 7 回、マーシャの列車に 3 回乗車したことを示しています。 したがって、彼はより頻繁にダシャに行きます。 

サンプル 2:`a = 4`、`b = 6`| ステップ | GCD | ダーシャ訪問 | マーシャを訪問 | 決定 |
 | --- | --- | --- | --- | --- |
 | GCD(4,6) を計算する | 2 | 3 | 2 | ダーシャ |

 このトレースは、アルゴリズムが GCD が 1 より大きい場合を処理し、正しい頻度カウントを生成していることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import math
    a, b = map(int, input().split())
    g = math.gcd(a, b)
    visits_dasha = b // g
    visits_masha = a // g
    if visits_dasha > visits_masha:
        return "Dasha"
    elif visits_masha > visits_dasha:
        return "Masha"
    else:
        return "Equal"

# provided samples
assert run("3 7\n") == "Dasha", "sample 1"

# custom cases
assert run("1 2\n") == "Dasha", "minimum a"
assert run("2 1\n") == "Masha", "minimum b"
assert run("5 5\n") == "Equal", "equal values (edge)"
assert run("1000000 999999\n") == "Dasha", "large numbers, a > b"
assert run("999999 1000000\n") == "Masha", "large numbers, b > a"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 入力用`a = 3`、`b = 7`、GCD は 1 です。訪問数 Dasha = 7、訪問数 Masha = 3。21 分間にわたって、考えられるすべての開始時間はこれらのカウントのいずれかにマップされるため、タイブレーカーは自然に処理されます。 Vasya が 0 分に到着し、電車が 3 分と 7 分に到着する場合、彼は最初に到着する方を選択します。 21 の倍数で同時に到着する場合は、カウント ロジックと一致する頻度の低い方を選択します。 

のために`a = 4`、`b = 6`、GCD = 2、周期は 12 分です。 Visits Dasha = 3、Visit Masha = 2。[0,12) の開始分は、これらのカウントに比例した選択肢になります。 これにより、アルゴリズムが GCD を使用してカウントを正しくスケーリングし、暗黙的にタイブレーカーを適用していることが確認されます。
