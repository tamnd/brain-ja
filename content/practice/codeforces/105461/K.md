 ## 解決策
 ## 問題の理解

 私たちは、いくつかのペアが宿題を交換したことが知られている一連の生徒を与えられました。 各レポートは 2 人の学生間の無向エッジであり、これらの 2 人が「不正行為の相互作用」グラフで接続されていることを意味します。 

私たちは、誘導された構造が非常に厳格なパターンと一致するように、すべての生徒を 2 つのグループ A と B に分割できるかどうかを決定する必要があります。 グループ A 内では、すべての学生ペアの間に報告されたエッジがなければなりません。これは、A が完全な部分グラフを形成する必要があることを意味します。 グループ B 内では、学生のペアは彼らの間でレポートを持つことを許可されません。つまり、B は独立したセットを形成する必要があります。 A と B の間のエッジには制限はありません。 

したがって、タスクは、グラフをクリーク A と独立集合 B に分割できるかどうかを確認することです。 

入力サイズは最大 100,000 ノードおよび最大 1,000,000 エッジになります。 これにより、すべてのサブセットまたは頂点のすべてのペアをチェックしようとするソリューションは即座に除外されます。 エッジを越える二次関数でさえ境界線に達するため、O(N + M) など、N と M に関して線形または線形に近い複雑さを目指す必要があります。 

微妙な問題は、この問題では M 境界を超える接続性やスパース構造などが保証されないことです。 また、重複したエッジが存在しないため、隣接性チェックが明確に定義されます。 

いくつかの特殊なケースが重要です。 

エッジがない場合でも、A はクリークである必要があるため、サイズが 1 より大きいクリークでない限り、A は最大 1 つのノードを持つことができますが、これはエッジがないと不可能です。 したがって、A には最大 1 つのノードしか配置できず、他のすべてのノードは B に移動する必要があります。B は独立している必要があり、エッジのないグラフがすでにそれを満たしているため、これは問題ありません。 

グラフが完成したら、A と B の全員を空にすることができます。 これは当然ながら両方の条件を満たします。 

一部のノードが部分的に接続されている場合、A は完全な接続を必要とするのに対し、B は内部エッジを禁止するため、厄介な状況が発生します。 

## アプローチ

 強引なアイデアは、頂点を A と B に分割できるすべての分割を試みることです。各サブセット A について、A がクリークであるかどうか、および補集合 B にエッジがないかどうかを確認します。 パーティションをチェックするには、A のすべてのペアをスキャンしてエッジが存在することを確認し、すべてのエッジをスキャンして B 内に存在しないことを確認する必要があります。 

高速エッジチェックに隣接行列を使用したとしても、すべてのサブセットの反復処理は O(2^N) であり、10^5 までの N では不可能です。 A は大きい可能性があるため、A サイズを制限しても役に立ちません。 

視点を逆転する必要があります。 セットを直接構築する代わりに、エッジおよび非エッジによって課される制約を分析します。 

重要な観察は、禁止パターンの観点から条件を書き換えることから得られます。 

B の内側ではエッジは許可されないため、グラフ内のすべてのエッジは A に少なくとも 1 つの端点を持たなければなりません。つまり、B は独立したセットでなければならないため、B にエッジの両方の端点を含めることはできません。 

A の内部では、すべてのペアにエッジがなければなりません。 つまり、2 つの頂点がエッジで接続されていない場合、両方の頂点を A に含めることはできません。 

したがって、エッジ以外のすべてのエンドポイントは両方のエンドポイントが同時に A に存在しないように強制し、すべてのエッジは両方のエンドポイントが同時に B に存在しないように強制します。 

これはまさに補対称制約です。 エッジが非エッジになる補グラフを考慮すると、条件は次のようになります。元のグラフでは A はクリークであるため、補グラフでは A は独立した集合になります。 同様に、B は元のグラフの独立集合です。 

したがって、補グラフでは、A と B は両方とも独立したセットであり、元のグラフのすべてのエッジは、両方の端点が B にあることを禁止する制約ですが、エッジ以外のすべての端点は、両方の端点が A にあることを禁止しています。この対称性は、二部構造を示唆しています。 

より明確な定式化は、各頂点にタイプ A または B を割り当てることです。すべてのエッジ (u、v) について、A-A、A-B、または B-A は許可されますが、B-B は許可されません。 すべての非エッジ (u、v) について、B-B、A-B、または B-A は許可されますが、A-A は許可されません。

したがって、エッジは B-B を禁止し、非エッジは A-A を禁止します。 これは、禁止された各ペアが一貫性ルールを課す派生競合グラフでグラフの色付けを介してテストできるペアごとの制約システムです。 

強制割り当てを伝播する頂点上に制約グラフを構築します。ノードを A に割り当てる場合、すべての非隣接ノードを A にすることはできないため、それらは B であるか、制約されないままでなければなりません。 同様に、B を割り当てる場合、すべての近傍を B にすることはできないため、それらは A または制約なしでなければなりません。 この構造は、すべての制約が満たされるように各頂点を一貫して割り当てることができるかどうかをチェックすることに要約され、これは 2-SAT スタイルの含意システムとしてモデル化できます。 

ただし、もっと単純な観察もあります。 この条件は、補グラフが構造化された方法で二部完全であると言うのと同じです。A のすべてのペアは元のグラフで接続されているため、A はクリークです。 したがって、A 内の任意の頂点を選択すると、A 内の他のすべての頂点がその頂点に接続される必要があります。 これは、A が A 内のすべての頂点の近傍集合の交差部分に含まれなければならないことを直ちに意味し、これは非常に制限的になります。 

より現実的なアプローチは、1 つの頂点が A に属すると推測することです。A はクリークであるため、A 内のすべての頂点は、その頂点と頂点自体の共通の近傍でなければなりません。 したがって、A は、選択した A 頂点の閉じた近傍のサブセットでなければなりません。 同様に、B はエッジを完全に回避する必要があります。 

これは検証戦略につながります。つまり、各頂点を A (または次数構造から導出された縮小候補セット) のアンカー候補として試し、可能な A および B パーティションを構築し、隣接セットを使用して制約を効率的に検証します。 しかし、もっと良くできるはずです。 

最後の重要な洞察は、問題を、追加の構造を備えた 2 つの独立したセットに分割できるかどうかを確認することに問題を変換することです。これは、グラフが完全であるか、または欠落しているすべてのエッジが 2 部グラフを形成する非常に特殊な構造を持っているかを確認することに帰着します。 これは、補グラフの二部性をチェックすることに相当します。 

具体的には、そのような分割が存在する場合、補グラフは 2 部である必要があることが観察できます。 これは、補数グラフでは A と B が両方とも独立したセットでなければならないため、補数のすべてのエッジが A と B を横切る必要があるという事実から来ています。 

したがって、補数グラフを暗黙的に計算し、それが二部であるかどうかを確認します。 補体は密であるため、明示的に構築することはできませんが、残りの頂点のセットを使用して未訪問の非エッジを効率的に追跡しながら、隣接セットと BFS を使用してトラバースすることができます。 

これにより、補完隣接関係をめぐる BFS の問題が軽減され、未訪問のノードと隣接関係のルックアップが注意深く維持されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^N · N^2) | O(N^2) | 遅すぎる |
 | 補完 BFS (暗黙的) | O(N + M) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての頂点の隣接セットを構築して、O(1) 平均時間でエッジが存在するかどうかをテストできるようにします。 これが必要なのは、補グラフが明示的に格納されておらず、非エッジを効率的に推論する必要があるためです。 
2. すべての未訪問の頂点のセットを維持します。 このセットは、補完 BFS 内のどのコンポーネントにもまだ割り当てられていないノードを表します。 
3. 未訪問の頂点がまだある間に、BFS 開始点として 1 つを選択し、カラー 0 を割り当てます。これにより、補数グラフ内の連結成分の調査が開始されます。 
4. BFS 中に頂点 u を処理するときに、未訪問のセット内で u の非隣接頂点をすべて決定します。 これらは、補数グラフの u に正確に隣接するものであるため、反対の色を割り当てる必要があります。 
5. 非近傍を効率的に見つけるには、現在の未訪問セットを反復処理し、隣接[u]にないセットをフィルタリングします。 これにより、補完エッジを明示的に構築することが回避されます。 
6. このような非隣接 v ごとに、反対の色を割り当て、BFS のキューに入れます。 頂点がすでに必要な色と異なる色を持っている場合に競合が検出された場合、分割は不可能です。 
7. BFS が競合することなくすべてのコンポーネントに対して完了した場合、補数グラフの有効な 2 分割が存在し、必要な構造が存在することを意味します。 

### なぜ効果があるのか

 補グラフの解釈は、元の制約を単一の要件に変換します。つまり、補グラフのエッジが単一のパーティションの辺の内側に存在することはできません。 それはまさに二大政党制です。 BFS は 2 色付けを強制し、検出されたすべての補色エッジが反対の色を強制します。 すべての補数の隣接関係はセットの差分によって検出されるか、存在しない場合は無視されるため、色付けではすべての制約が尊重されます。 色付け中の矛盾は補数グラフの奇数サイクルに対応し、必要な分割が不可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, m = map(int, input().split())

adj = [set() for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].add(v)
    adj[v].add(u)

unvisited = set(range(1, n + 1))
color = {}

while unvisited:
    start = next(iter(unvisited))
    unvisited.remove(start)
    color[start] = 0
    q = deque([start])

    while q:
        u = q.popleft()

        # nodes in complement graph: unvisited minus neighbors in original graph
        to_visit = []
        for v in list(unvisited):
            if v not in adj[u]:
                to_visit.append(v)

        for v in to_visit:
            unvisited.remove(v)
            if v in color:
                if color[v] == color[u]:
                    print("NO")
                    sys.exit(0)
            else:
                color[v] = 1 - color[u]
            q.append(v)

print("YES")
```エッジのメンバーシップ チェックが一定時間になるように、隣接構造はセットとして保存されます。 BFS はグローバル未訪問セットを使用するため、相補的な近傍を元のエッジによって接続されていない頂点として識別できます。 

微妙な点は、スナップショットを反復処理することです。`list(unvisited)`反復中にセットを変更するためです。 これにより、実行時エラーが回避され、正確さが保証されます。 

色付けロジックは補数グラフの二部性を強制します。 色の矛盾は補数のサイクルが奇数であることを示しており、分割が不可能になります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N + M) 償却 | 各ノードは 1 回処理され、隣接関係チェックはセット | を使用した平均 O(1) です。 
| スペース | O(N + M) | 隣接セットとカラーリングおよび訪問された構造 |

 各頂点が未訪問セットから正確に 1 回削除され、各隣接関係チェックがハッシュ化により効率的であるため、この解は制約内に収まります。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    unvisited = set(range(1, n + 1))
    color = {}

    while unvisited:
        start = next(iter(unvisited))
        unvisited.remove(start)
        color[start] = 0
        q = deque([start])

        while q:
            u = q.popleft()
            to_visit = []
            for v in list(unvisited):
                if v not in adj[u]:
                    to_visit.append(v)

            for v in to_visit:
                unvisited.remove(v)
                if v in color and color[v] == color[u]:
                    return "NO"
                color[v] = 1 - color[u]
                q.append(v)

    return "YES"

# provided samples
assert run("4 4\n1 2\n2 3\n3 4\n4 1\n") == "NO"
assert run("5 6\n1 2\n2 3\n3 1\n1 4\n1 5\n3 5\n") == "YES"

# custom cases
assert run("1 0\n") == "YES"
assert run("2 0\n") == "NO"
assert run("3 3\n1 2\n2 3\n1 3\n") == "YES"
assert run("3 0\n") == "NO"

 | --- | --- | --- |
 | 1 ノード、エッジなし | はい | シングルトンクリーク/独立した分裂 |
 | 2 ノード、エッジなし | いいえ | A をサイズ 2 のクリークにするのは不可能 |
 | 三角形 | はい | フルクリークケース |
 | 3 つのノードを持つ空のグラフ | いいえ | B の独立性は問題ありませんが、A 制約はサイズ 1 を超えると失敗します。 

## 特殊なケース

 次のような単一の頂点入力`1 0`はその頂点を A に割り当てますが、クリークまたは独立性の制約に違反するペアがないため、両方の条件が自明に当てはまります。 アルゴリズムはそのノードから BFS を開始し、相補的な隣接ノードを見つけず、ただちに YES で終了します。 

次のような 2 つの孤立した頂点を持つグラフ`2 0`A はクリークである必要があり、サイズ 2 のクリークには存在しないエッジが必要であるため、矛盾が強制されます。 処理中に、両方のノードが補色グラフの同じコンポーネントに配置されるため、色の競合が発生します。 

次のような完全なグラフ`3 3`すべてのペアが A のクリーク要件を満たしており、B が空である可能性があるため、受け入れられます。 BFS オーバー補数ではエッジが検出されないため、矛盾は発生せず、すべてのノードは単一の色の割り当ての下で一貫性を保ちます。
