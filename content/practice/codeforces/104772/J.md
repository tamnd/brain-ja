 ## 問題の理解

 番号が付けられたスイレンの葉の上に座っている同じ系統のカエルの 2 つのスナップショットが与えられます。 最初のスナップショットでは、カエルは厳密に増加する配列によって指定された位置を占めています。`a`、2 番目のスナップショットでは、別の厳密に増加する配列によって指定された位置を占めます。`b`。 すべての位置は両方のスナップショットで一意であるため、写真間で同じスイレンの葉の上に留まるカエルは存在しません。 

それぞれのカエルは、ある位置から移動します。`a`の位置に`b`、2 つの配列間で 1 対 1 のマッチングが形成されます。 2 つの配列間で座標が共有されていないため、すべてのカエルは厳密に左または厳密に右に移動します。 

タスクはマッチングを再構築することではありません。 代わりに、何匹のカエルが左に移動したかだけを気にします。 カエル間の有効なマッチングによって達成できるこのカウントの値をすべてリストする必要があります。 

制約は最大 200,000 要素まであり、二次または三次マッチング戦略は除外されます。 全単射の数は階乗であるため、すべての順列、さらにはすべてのマッチングを試みる解決策は実行不可能です。`n`。 

素朴だが重要な観察は、答えはカエルのアイデンティティではなく、2 つのソートされた配列が数直線上でどのようにインターリーブするかのみに依存するということです。 ただし、不注意な推論は、左の手の数が固定であると仮定することがよくあります。 間隔が特定の方法で重なっている場合、これは false です。 

配列が完全にインターリーブされている場合、微妙なエッジ ケースが発生します。 たとえば、次の場合`a = [1, 3, 5]`そして`b = [2, 4, 6]`、からのカエル`a`のどのカエルにもマッチします`b`with consistent direction choices, allowing multiple possible counts of left moves. A greedy matching would incorrectly suggest a fixed count.

 ## アプローチ

 A brute-force approach would try to assign each element of`a`のユニークな要素に`b`そして残りの割り当てがいくつあるか数えます。 これは完全な 2 部グラフにおける完全なマッチングの問題であり、すべてのマッチングを列挙することは不可能です。`n!`可能性。 すべての割り当てを試して固定数の左移動の実現可能性を判断するだけでも、時間は指数関数的に増加します。 

重要な構造的観察は、数直線上の点の相対的な順序のみが重要であるということです。 合併したら`a`そして`b`単一のソートされたシーケンスにまとめると、各位置が最初の写真に属するか 2 番目の写真に属するかを示すラベルのパターンが得られます。 このシーケンスはすべての制約をエンコードします。 

この問題は、次の要素を選択することと同じになります。`a`内の小さな要素とペアになっています`b`。 左に移動するカエルの数を修正すると、残りは強制的に右に移動しますが、実現可能性は順序付けの制約がそのような分割を許可するかどうかによって異なります。 

重要な洞察は、左から右にスキャンすると、どこから何匹のカエルを追跡できるかということです。`a`そして`b`見られてきました。 どのプレフィックスでも、左方向にすでに一致している必要があるカエルの数は、その数によって制限されます。`b`要素が対応する前に出現しました`a`要素。 これにより、有効なプレフィックス バランスの範囲を計算する問題が軽減され、グリーディ スイープで維持できるようになります。 

マージされたアレイ全体をスイープしながら、実行中の不均衡を維持します。 それぞれ`a`それぞれが将来の左の動きの可能性に貢献します。`b`1つ消費します。 有効な左移動数は、プレフィックスの実現可能性に違反することなく達成できるすべての可能な最終バランスに対応します。 これにより、問題は実行可能な最小および最大のマッチング フローを計算することになり、その間のすべての整数値が達成可能になります。

 ## アルゴリズムのチュートリアル

 1. 各要素を次のものとしてマークしながら、両方の配列を単一のソートされたシーケンスにマージします。`a`または`b`。 これにより、可能なすべての動きの相対的な幾何学形状が保存されます。 
2. マージされたシーケンスをスイープし、次のように定義された実行バランスを維持します。`a`表示された要素から数を引いたもの`b`要素はこれまでに見られました。 このバランスは、他に類を見ないカエルが何匹いるかを表します。`a`現在、ペアリングを「待機中」です。 
3. このバランスがスイープ全体にわたって達成できる最小値と最大値を追跡します。 これらの極値は、有効なマッチングにおいてどれだけの左右の割り当てが共存できるかについての構造的制約を表します。 
4. 最終的なバランス制約を左移動の可能な回数に変換します。 それぞれの実現可能な構成は、次の数を選択することに対応します。`a`要素は以前のものと一致します`b`有効なバランスの範囲は、可能な答えの連続した範囲に直接変換されます。 
5. この範囲内のすべての整数値を出力します。 

### なぜ効果があるのか

 マージされた注文のすべてのプレフィックスで、`b`出現した要素は、以前に出現した要素の数に下限を課します`a`要素はすでに右側に割り当てられている必要があります。 対称的に、比類のないまま`a`要素は、左に何回移動できるかを定義します。 

両方のシーケンスがソートされているため、実行可能な一致ではプレフィックスの順序付けの制約が考慮される必要があります。 これらの制約は、分散した可能性ではなく、実現可能な全体的なバランスの単一の間隔を形成します。 達成可能な最小および最大の不均衡が決定されると、プレフィックスの有効性を損なうことなく、ローカルで一致の決定を交換することによって、それらの間の任意の整数を実現できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

events = []
for x in a:
    events.append((x, 0))
for x in b:
    events.append((x, 1))

events.sort()

balance = 0
min_balance = 0
max_balance = 0

for _, t in events:
    if t == 0:
        balance += 1
    else:
        balance -= 1
    min_balance = min(min_balance, balance)
    max_balance = max(max_balance, balance)

start = -min_balance
end = n - max_balance

ans = list(range(start, end + 1))

print(len(ans))
print(*ans)
```この解決策は、両方の配列をタグとマージして起点を区別することから始まります。 並べ替えにより、両方のスナップショットに含まれるすべてのスイレンの葉の完全な左から右の構造が再構築されます。 

変数`balance`何個追跡するか`a`要素が先に現れています`b`要素。 いつ`balance`マイナスになると、より多くのことを意味します`b`利用可能な要素よりも多くの要素が見られました`a`候補者を指定し、有効な割り当てで特定のカエルを右側に一致させるように強制します。 このため、最小値を記録します。 

からの変革`(min_balance, max_balance)`の中へ`[start, end]`プレフィックス制約を左移動のグローバルカウントに変換します。 エンドポイントは、不均衡を次の間の絶対数にシフトします。`0`そして`n`。
