 ## 解決策
 ## 問題の理解

 2D 平面上の点の集合が与えられます。 各点は、整数の座標で位置を表します。 タスクは、これらすべての点をまとめて考慮し、辺が座標軸に平行で、すべての点を含む最小の長方形の面積を決定することです。 

より具体的には、指定されたすべての点を囲むように、x 方向と y 方向に合わせてゴムバンドを伸ばすことを想像してください。 左端、右端、下端、上端の位置によって形成される長方形が、対象となる領域を定義します。 出力はその長方形の面積です。 

すべての点が単一の垂直線または水平線上にある場合、長方形は一方向に折りたたまれ、面積はゼロになります。 

制約は十分小さいため、すべてのポイントを 1 回か 2 回スキャンするだけで済みます。 ポイントの数が最大 200,000 までと大きい場合でも、ポイントごとに一定量の作業を実行するソリューションであれば十分です。 これにより、点のペアを調べたり、凸包のような幾何学的構造を構築しようとするアプローチは即座に除外されます。これらのアプローチでは、軸が整列したエンクロージャには不要な少なくとも 2 次または対数線形のオーバーヘッドが導入されるからです。 

正確さのためには、いくつかの特殊なケースが重要です。 点が 1 つしかない場合、幅と高さの両方がゼロであるため、面積はゼロでなければなりません。 すべての点が同じ x 座標を共有する場合、y の変化に関係なく幅は 0 になります。 同様に、すべてが同じ y 座標を共有する場合、高さはゼロになります。 

具体的な失敗例として、点(0, 0)、(0, 5)、(0, 10)を考えてみましょう。 縮退していない長方形を誤って仮定する単純なアプローチでは、y 範囲のみに基づいて正の面積が返される可能性がありますが、正しい幅はゼロであるため、面積はゼロになります。 

もう 1 つの微妙なケースは、(-3, 2)、(4, -1)、(-2, 7) などの負の座標が表示される場合です。 min と max を誤って初期化する解法 (最初の点ではなく 0 から開始するなど) は、間違った境界ボックスを計算する可能性があります。 

## アプローチ

 この強引なアイデアは、すべての点のペアを考慮し、それらを軸に揃えられた長方形の候補の反対側の角として扱うことです。 このようなペアごとに、他のすべての点が長方形の内側または境界上にあるかどうかを確認し、その面積を計算します。 これが機能するのは、有効な囲み四角形には、点のサブセットによって境界が定義されている必要があるためです。 

ただし、このアプローチでは、最悪の場合、O(n^2) 個の四角形の候補で O(n^3) の操作が実行され、各候補に対して O(n) 個の点をスキャンして包含を検証します。 n = 10^4 のような控えめな制約があっても、これは実行不可能になります。 

重要な観察は、軸に揃えられた外接する四角形が、すべての点の最小 x 座標、最大 x 座標、最小 y 座標、および最大 y 座標の 4 つの値のみによって完全に決定されることです。 これらの極端な値が分かれば、ポイントの分布に関する他の情報は問題になりません。 

これにより、ペアに対する組み合わせ検索の問題が単一パスの集計問題に軽減されます。 入力を 1 回スキャンしながらこれら 4 つの値を追跡するだけです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | お(1) | 遅すぎる |
 | 最適 (最小/最大スキャン) | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 4 つの変数 (min_x、max_x、min_y、max_y) を維持しながら、すべてのポイントを 1 つずつ読み取ります。 これらは、これまでに見られた境界ボックスを追跡します。 
2. min_x と min_y を非常に大きな値で初期化し、max_x と max_y を非常に小さな値で初期化します。 これにより、特別なケースを使用せずに、最初の点がすべての境界を正しく設定することが保証されます。 
3. 各点 (x, y) について、min_x = min(min_x, x)、max_x = max(max_x, x) を更新し、y についても同様に更新します。 このステップでは、新しい極値が発見されるにつれて、境界長方形を徐々に拡大します。 
4. すべてのポイントを処理した後、幅を max_x - min_x として計算し、高さを max_y - min_y として計算します。 これらは、各軸に沿って設定された点の全範囲を表します。 
5. 幅と高さを乗算して、最終的な面積を求めます。 
6. 結果を直接出力します。 

各更新が正しい理由は、軸に揃えられた有効な囲み四角形には、極点以上の境界が必要だからです。 境界が小さい候補長方形は少なくとも 1 つの点を除外し、最小の囲いにはこれより大きな長方形は不要です。 

### なぜ効果があるのか

 入力のすべての接頭辞で、変数 min_x、max_x、min_y、および max_y は、これまでに処理された点の正確な境界ボックスを表します。 新しいポイントが到着したとき、これら 4 つの値だけがエンクロージャを変更できる可能性があります。 最終的な四角形はグローバルな極値のみに依存するため、これらの値を維持することで、最後の点以降、すべての点を含む正確な最小軸揃え四角形が得られることが段階的に保証されます。 内部点の構成は、極点の包含に違反せずに境界を変更することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    min_x = float('inf')
    max_x = float('-inf')
    min_y = float('inf')
    max_y = float('-inf')
    
    for _ in range(n):
        x, y = map(int, input().split())
        if x < min_x:
            min_x = x
        if x > max_x:
            max_x = x
        if y < min_y:
            min_y = y
        if y > max_y:
            max_y = y
    
    width = max_x - min_x
    height = max_y - min_y
    print(width * height)

if __name__ == "__main__":
    solve()
```実装ではロジックが厳密にストリーミングされるため、すべてのポイントが保存されることはありません。 無限大を使用した初期化により、最初の点の特殊ケースが回避され、座標が負の場合のエラーが防止されます。 

幅と高さの両方がゼロになるため、すべての点が同一の場合でも減算ステップは安全です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    min_x = float('inf')
    max_x = float('-inf')
    min_y = float('inf')
    max_y = float('-inf')

    for _ in range(n):
        x, y = map(int, input().split())
        min_x = min(min_x, x)
        max_x = max(max_x, x)
        min_y = min(min_y, y)
        max_y = max(max_y, y)

    return str((max_x - min_x) * (max_y - min_y))

 ## 特殊なケース

 単一点入力は最小値と最大値を同時に設定するため、実行中は幅と高さの両方が 0 のままとなり、特別な分岐を行わずに面積が 0 になります。 

すべての点が垂直線上にある場合 (すべての点で x = 2 など)、max_x と min_x は等しいままであるため、幅はゼロになります。 アルゴリズムは引き続き y 境界を正しく更新しますが、最後の乗算により領域がゼロに縮小されます。 

すべての点が水平線上にある場合、高さがゼロになる対称的な動作が発生します。 

負の座標の場合、無限大で初期化すると、最初の比較で実数値が正しく取得されます。 たとえば、(-3, 2) から開始すると、min_x と max_x の両方が -3 に、max_y が 2 に設定され、初期化でゼロが使用された場合に発生する誤ったバイアスが防止されます。
