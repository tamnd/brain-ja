 ## アルゴリズムのチュートリアル

 中心的な考え方は、基本表現にゼロがいつ現れるかを理解することです。 数字は、その位置での累乗の剰余を基数の累乗で割ったときに正確にゼロになります。 

拠点を見つけるという観点から問題を再定式化します。$n$は、基底のべき乗によって最も構造的に割り切れます。 

### ステップ

 1. 任意の基数で自明なベースラインを計算します。$b > n$、表現は 1 桁であるため、ゼロカウントは常に 0 です。$b \le n$。 
2.固定ベースの場合$b$、次の場合に限り、少なくとも 1 つのゼロが発生することを観察します。$b \mid n$、最後の桁が正確にゼロになるためです。$n \bmod b = 0$。 これはすでに約数が重要であることを示唆しています。 
3. 複数のゼロが必要な場合は、次の繰り返し割り算が必要です。$b$分割プロセス中。 これは次のような場合に起こります。$b^2 \mid n$、末尾に少なくとも 2 つのゼロが生成されます。 
4. より一般的に言えば、$b^k \mid n$、次に次の表現$n$基地内で$b$少なくとも含まれています$k$末尾のゼロ。 したがって、次の指数は$b$因数分解で$n$保証されたゼロカウントを直接制御します。 
5. したがって、可能な最大のゼロは、指数を最大化することによって得られます。$k$そのような$b^k \mid n$ある基地のために$b$、すべての拠点間で比較します。 
6. 考えられるすべての約数を因数分解して候補塩基を列挙します。$n$まで$\sqrt{n}$。 各約数について$d$、それを候補基底として扱い、それが何回分割されるかを計算します。$n$、指数を与える$k$。 私たちは最高の価値を追跡します$k$。 
7. 最大ゼロカウントを決定した後$k_{\max}$、すべての拠点を収集します$b$の指数が$b$で$n$まさに$k_{\max}$。 

### なぜ効果があるのか

 不変条件は、基底のすべてのゼロです。$b$表現は、現在の剰余が次で割り切れる完全な除算ステップに対応します。$b$。 ゼロ桁の繰り返しを保証する唯一の方法は、強制的に繰り返し割り算することです。$n$～の力によって$b$。 基数変換はユークリッド除算を正確に繰り返すので、次の指数は$b$分割する$n$後続ゼロステップが何回発生するかを完全に決定します。 末尾のゼロを超える追加のゼロがある場合は、中間商も次の値で割り切れる必要があります。$b$、同じ指数構造によってすでに捕捉されていない限り、これは不可能です。 したがって、最大ゼロカウントは、すべての候補塩基の中で最も高い検出力構造によって完全に特徴付けられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def factor_candidates(n):
    factors = {}
    i = 2
    x = n
    while i * i <= x:
        while x % i == 0:
            factors[i] = factors.get(i, 0) + 1
            x //= i
        i += 1
    if x > 1:
        factors[x] = factors.get(x, 0) + 1
    return factors

def solve_case(n):
    # factor n
    fac = factor_candidates(n)

    # maximum zeros equals maximum exponent among prime factors
    kmax = 0
    for p, e in fac.items():
        kmax = max(kmax, e)

    # collect bases achieving this exponent structure
    res = []

    # all prime factors themselves are candidate bases
    for p, e in fac.items():
        if e == kmax:
            res.append(p)

    # also include n itself if it matches (base n gives "10" -> 1 zero)
    if kmax == 1:
        res.append(n)

    res = sorted(set(res))
    return kmax, res

def main():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        k, bases = solve_case(n)
        out.append(f"{k} {len(bases)}")
        out.append(" ".join(map(str, bases)))
    print("\n".join(out))

if __name__ == "__main__":
    main()

次に、この最大指数を達成するすべての素数を収集します。これは、これらがまさに完全な割り算連鎖によって最長の 0 桁のシーケンスが生成される塩基であるためです。 数値自体は、最大指数が 1 である特殊な場合に含まれます。$n$常に表現を生成します$10$、これは 1 つのゼロに寄与します。 

並べ替えと重複排除により、出力順序の正確さが保証されます。 

微妙な点は、基本変換を明示的にシミュレートすることは決してないということです。 すべての推論は因数分解に変換され、次の段階まで実行可能です。$10^{18}$トライアル分割を使用して$O(\sqrt{n})$。
