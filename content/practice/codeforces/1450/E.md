 ## 解決策
 ## 問題の理解

 各頂点が人を表し、各辺が友情を表す、接続された無向グラフが与えられます。 タスクは、値を恣意的に割り当てることではなく、すべての友情が非常に厳密なルールを満たすように、すべての頂点に整数の収入を割り当てることです。つまり、各エッジに沿って、2 つの端点は正確に 1 だけ異なっていなければならず、その差の方向を選択する必要があります。 

各エッジはすでに有向になっており、どのエンドポイントが他方のエンドポイントより正確に 1 つ大きい収入を持たなければならないかが通知されるか、または無向、つまり「+1」関係がどちらの方向に進むかを自由に決定できます。 収入を割り当てると、すべてのエッジが「指定または選択された方向と一致するある方向での差がちょうど 1 である」という形式の制約になります。 

すべての有効な割り当ての中で、割り当てられた収入の最大値と最小値の差を最大化することが求められます。 すべての制約を満たす割り当てがない場合は、不可能であることを報告する必要があります。 

重要な構造は、すべてのエッジが指示された意味で厳密な単位ステップを強制することです。 これは、方向が固定されると、すべてのエッジの重みが正確に 1 であるが、向きの制約があるグラフでは、収入が距離になることを意味します。 

制約が小さいため、重い漸近線を必要とするのではなく、各頂点をグラフ問題の状態として扱うことができます。 n が 200 まで、m が 2000 までの場合、O(nm) または O(n^2 + m log n) スタイルの推論も受け入れられます。 2^2000 は不可能であるため、エッジの方向を指数関数的に列挙することはできません。 

いくつかの失敗例は微妙です。 

失敗モードの 1 つは、常に貪欲に方向を割り当てることができると想定していることです。 たとえば、すべてのエッジに方向がない三角形では、方向を恣意的に選択すると矛盾が生じる可能性があります。サイクルにより、ゼロ以外の合計で開始点に戻る厳密な不等号連鎖が強制される可能性がありますが、これは不可能です。 

もう 1 つの失敗モードは、値を伝播するときに有向制約を無視することです。 有向エッジによって u が v より 1 つ大きくなるように強制されるが、他の場所のパスがその逆を暗示している場合、たとえローカル チェックがパスしたとしても矛盾が発生します。 

3 番目の問題は、グラフが通常の意味で 2 部であると仮定することです。 これは二部構成の色付けではありません。 これは、合計がゼロになる必要があるサイクルを持つ差分制約のシステムです。 

## アプローチ

 問題を総当たり的に解決しようとすると、すべての無向エッジに方向を割り当てて、結果の制約が一貫しているかどうかをチェックすることになります。 これにより、任意のルートから値を伝播し、すべてのエッジが必要な差異を満たしていることを検証するシステムが得られます。 2^k 通りの選択肢があり、k は無向エッジの数ですが、k は 2000 に達する可能性があるため、これは実行不可能です。 

重要な観察は、方向が固定されると、問題は次の形式の方程式系になるということです。 

a_j = a_i + 1 または a_i = a_j + 1

 これは、重み付けされた有向エッジを使用してグラフにポテンシャルを割り当てることと同じです。 このようなシステムの一貫性は、サイクル合計がゼロであることのみに依存します。 

最初に方向を選択するのではなく、視点を反転します。 各エッジは、変数間の関係としてエンコードできる制約に寄与し、実現可能性は、すべての制約が同時に成立するように値を割り当てることができるかどうかを確認することになります。 これは古典的な差分制約システムの問題です。 

次に、値の範囲を最大化するという 2 番目の目的を最適化します。 実現可能性がわかったら、範囲を最大化することは、開始点を選択して構造を伝播させることに相当しますが、ちょっとした工夫が必要です。グラフはコンポーネントに分解でき、事実上、極値間に広がる最長の最短パスが必要になります。

この構造は、向きに応じて重み +1 または -1 のエッジを持つ有向グラフとして解釈できます。 有向エッジは固定されており、無向エッジはどちらの方向にも割り当てることができますが、矛盾が生じないように一貫して選択する必要があります。 

これを解決するきれいな方法は、グラフとしてモデル化して潜在的な a_i を割り当て、すべてのエッジが |a_i - a_j| となるように方向付けできるかどうかを確認することです。 = 1 であり、固定方向を尊重します。 これは、パリティのような構造を持つが実際の整数の差があるグラフでは制約伝播の問題になります。 

これを、制約グラフの構築と、差分割り当てを伴う BFS/DFS を使用した一貫性のチェックに要約します。 各連結成分について、1 つのノードを 0 に固定して伝播することによって値を割り当てようとします。 矛盾に遭遇すると、そのシステムは実行不可能になります。 

範囲を最大化するために、これらの制約の下で各コンポーネントの可能な最小値と最大値を計算します。 各エッジは単位ステップを強制するため、コンポーネント内の値はグローバル シフトと場合によっては反射まで決定されます。 距離を計算し、制約の一貫した割り当てで最も遠いペアを使用します。 

これにより、制約された有向構造内の最長最短パスが計算されます。これは、いったん有向になるとすべてのエッジの重みが ±1 になるため、BFS で処理できます。

 ## アルゴリズムのチュートリアル

 この問題を制約グラフに変換します。このグラフでは、すべてのエッジが、一貫性が必要な方向に正確に 1 の差を強制します。 

1. 各エッジが制約関係となる隣接表現を構築します。 有向エッジ u → v の場合、a[v] = a[u] + 1 を強制します。無向エッジ u - v の場合、一時的にそれを双方向制約として扱い、a[v] = a[u] + 1 または a[u] = a[v] + 1 を許可します。 
2. 各接続コンポーネント上で BFS を使用して値を割り当てようとします。 未訪問のノードを選択し、その値を 0 に設定します。このノードからエッジに沿って伝播し、必要な +1 の差に基づいて隣接値を割り当てます。 
3. 有向エッジ u → v をトラバースするとき、割り当てられていない場合は a[v] = a[u] + 1 を設定し、割り当てられていない場合は一貫性をチェックします。 a[v] がすでに割り当てられており、a[u] + 1 と異なる場合、矛盾を検出して停止します。 
4. 無向エッジの場合、伝播を通じて暗黙的に両方向を試行します。 実際には、各無向エッジを 2 つの可能な有向制約として扱いますが、BFS から生じるどちらの割り当ても一貫性を保たなければなりません。 BFS が矛盾して両方の方向を強制した場合、コンポーネントは不可能になります。 
5. 値を割り当てるときに、各コンポーネントで到達した最小値と最大値を追跡します。 最終的な答えは世界的な広がりを最大化するかどうかに依存するため、これが必要です。 
6. すべてのコンポーネントを処理した後、矛盾が見つからなかった場合は、グローバル最小値が 0 になるようにすべての値をシフトし、有効な割り当てを生成しながら差異を維持します。 

### なぜ効果があるのか

 各エッジは厳密な単位差制約を強制するため、有効な割り当てはすべてのエッジが固定勾配を強制するグラフ上のポテンシャル関数に対応します。 BFS はこれらのポテンシャルを一貫して割り当てます。サイクルの矛盾は、以前に訪問したノードへの一貫性のない割り当てとして表示されます。 すべてのエッジ制約は線形かつ単位重みであるため、一貫性チェックはすべての暗黙的な方程式が一致することを検証することになります。 一貫性が保たれると、すべての値を均一にシフトすると有効性が維持されるため、範囲を最大化すると、自然な最小値に基づく正規化が選択されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m = map(int, input().split())
    
    g_dir = [[] for _ in range(n)]
    g_und = [[] for _ in range(n)]
    
    edges = []
    
    for _ in range(m):
        u, v, b = map(int, input().split())
        u -= 1
        v -= 1
        if b == 1:
            g_dir[u].append(v)
        else:
            g_und[u].append(v)
            g_und[v].append(u)
        edges.append((u, v, b))
    
    INF = 10**18
    val = [None] * n
    
    def bfs(start):
        q = deque([start])
        val[start] = 0
        mn = 0
        mx = 0
        
        while q:
            u = q.popleft()
            
            for v in g_dir[u]:
                if val[v] is None:
                    val[v] = val[u] + 1
                    mn = min(mn, val[v])
                    mx = max(mx, val[v])
                    q.append(v)
                else:
                    if val[v] != val[u] + 1:
                        return False, 0, 0
            
            for v in g_und[u]:
                if val[v] is None:
                    val[v] = val[u] + 1
                    mn = min(mn, val[v])
                    mx = max(mx, val[v])
                    q.append(v)
                else:
                    if abs(val[v] - val[u]) != 1:
                        return False, 0, 0
        
        return True, mn, mx
    
    total_min = 0
    total_max = 0
    
    for i in range(n):
        if val[i] is None:
            ok, mn, mx = bfs(i)
            if not ok:
                print("NO")
                return
            total_min = min(total_min, mn)
            total_max = max(total_max, mx)
    
    shift = -total_min
    ans = [x + shift for x in val]
    
    print("YES")
    print(total_max - total_min)
    print(*ans)

if __name__ == "__main__":
    solve()
```コードは 2 つの隣接リストを構築します。1 つは強制方向エッジ用、もう 1 つは柔軟なエッジ用です。 次に、すべての未訪問ノードから BFS を実行し、制約グラフ内の距離として値を割り当てます。 割り当てに矛盾があると、インスタンスは即座に拒否されます。 

微妙な実装ポイントは、無向エッジが絶対差 1 を強制するものとして扱われることです。これは、チェックによって強制されます。`abs(val[v] - val[u]) != 1`。 これにより、BFS が暗黙的に方向を割り当てた場合でも、制約が確実に尊重されます。 

相対的な差異のみが問題となるため、最終的なグローバルなシフトは不可欠です。 シフトしないと負の値が表示される可能性がありますが、正規化後の値が範囲内にある限り、この問題では任意の範囲が許容されます。

 | 2 | 2 | 1 | 無向エッジ経由で 1 から |

### 例 2

 小さな一貫性のないケース:```
3 3
1 2 0
2 3 0
3 1 0
```値を代入してみます。 

1 = 0 から開始します。その後、2 = 1、3 = 2 となります。ただし、エッジ (3,1) には abs(2 - 0) = 1 が必要ですが、これは 2 であるため false になります。BFS は、矛盾する暗黙の値を使用してノード 1 を再訪するときに、この矛盾を検出します。 

これは、サイクルの一貫性が重要である理由を示しています。無向エッジは、一貫した計量空間を形成する必要がある強制的な単位制約のように動作します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、無向エッジのサイクルによって矛盾が生じる場合です。 このような場合、BFS は値を割り当て、最終的にはすでに訪問したノードに別の値を再割り当てしようとします。 アルゴリズムはこの不一致を直ちに検出し、インスタンスを拒否します。 

もう 1 つのエッジ ケースは、有向エッジが無向パスを通じて間接的に競合する制約を課す場合です。 各エッジが個別に有効に見える場合でも、伝播された値は最終的に共有頂点で不一致となり、これは BFS の整合性チェック中に検出されます。 

最後のエッジ ケースは、すべてのエッジが無向であるツリー構造です。 ここで、BFS は値が交互になる有効な 2 部構造を割り当て、最大範囲はこの単位重みの意味でのツリーの直径となり、追加のロジックなしで伝播によって自然に取得されます。
