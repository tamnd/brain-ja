 ## 解決策
 ## 問題の理解

 文字列が与えられています`a`英小文字で構成されます。 タスクは、その文字を文字列に並べ替えることです。`b`文字列「trygub」がサブシーケンスとして現れないようにします。`b`。 部分シーケンスは、残りの文字の相対的な順序を変更せずに、0 個以上の文字を削除することによって形成されます。 たとえば、次の場合`a = "xzyw"`の場合、「xy」はサブシーケンスですが、「yx」はサブシーケンスではありません。 

入力は複数のテスト ケースを提供します。 各テスト ケースでは、文字列と文字列自体の長さが示されます。 各テスト ケースの出力は、文字を削除しても "trygub" を取得できない文字列を再配置したバージョンです。 

制約は小さいです。`n`最大200まで上げることができ、`t`最大 100 です。つまり、処理する必要がある文字の総数は最大 20,000 です。 これは十分に小さいため、各文字列を線形に操作する単純なアルゴリズムでも高速になります。 複雑なデータ構造や非常に大規模な入力の最適化は必要ありません。 

文字列が次の場合に微妙なエッジケースが発生します。`a`すでにその中のどこかに文字「t」、「r」、「y」、「g」、「u」、「b」が正確な順序で含まれています。 ただ放置するだけの素朴な解決策`a`変更しないと、誤って「trygub」がサブシーケンスとして許可される可能性があります。 別の特殊なケースは、文字列が 6 文字より短い場合に発生します。その場合、「trygub」が出現することは不可能であるため、任意の順序が有効です。 文字列に繰り返し文字が含まれている場合は、「trygub」シーケンスを壊す順序で 6 文字を維持することにより、サブシーケンスの作成を回避する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、文字列のすべての順列が試行されます。`a`「trygub」がサブシーケンスであるかどうかを確認します。 このアプローチは正しいですが、順列の数が次のとおりであるため、非現実的です。`n!`これは天文学的な数字です`n = 10`。 サブシーケンスの各順列をチェックするのに O(n) かかるため、合計時間は許容範囲をはるかに超えています。 

重要な洞察は、サブシーケンスを明示的に検索する必要がないということです。 「Trygub」には6つの異なるキャラクターがいます。 これらの文字の少なくとも 1 つが、「trygub」を形成するために必要な元の順序で表示されないように、任意の文字列を再配置できます。 最も簡単な方法は、文字列をソートすることです。 ソートするとすべての文字の相対的な順序が変更されるため、元の文字列がその順序で正確に「bgrtuy」でない限り、正確なシーケンス「trygub」は保持されません。これはアルファベット順のソートでは不可能です。 ソートにより、「trygub」がサブシーケンスとして出現できないことが保証され、実装は簡単です。 

別の方法は、「t」、「r」、「y」、「g」、「u」、「b」のすべての出現を別の順序に移動することです（たとえば、それらを逆にするか、シャッフルします）。 並べ替えはより簡単で、どの入力に対しても動作することが保証されています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべての順列を試す) | お(ん!) | O(n) | 遅すぎる |
 | 文字列を並べ替える | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、長さを読み取ります。`n`そして文字列`a`。 
3. 文字列を文字のリストに変換します。 
4. リストをアルファベット順に並べ替えます。 これにより、すべての文字の相対的な順序が変更されます。 
5. ソートされた文字を結合して文字列に戻します。`b`。 
6. 印刷`b`。 

ソートが機能するのは、文字「t」、「r」、「y」、「g」、「u」、「b」が正確な順序「trygub」で出現してサブシーケンスが壊れることがないことが保証されるためです。 有効な並べ替えが許可されているため、並べ替えは問題の制約を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = input().strip()
    b = ''.join(sorted(a))
    print(b)
```コードは最初にテスト ケースの数を読み取ります。 それぞれのケースで、文字列を読み取り、空白を削除し、並べ替えて、結果を出力します。 ソートにより、「trygub」がサブシーケンスになり得ないことが保証されます。 使用する`input().strip()`ソートを妨げる可能性のある末尾の改行の問題を回避します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = input().strip()
        b = ''.join(sorted(a))
        output.append(b)
    return '\n'.join(output)
