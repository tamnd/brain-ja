 ## 解決策
 ## 問題の理解

 の行が与えられています`n`労働者。それぞれの職種は英小文字で表されます。 目標は、定義された操作を繰り返し使用して、最終的にすべての作業者にどのジョブ カテゴリを割り当てることができるかを決定することです。 この操作により、同じカテゴリを共有するワーカーのサブセットを選択し、そのカテゴリを別のカテゴリに変更できます。ただし、このサブセットの広がりがそのサイズに比べて「十分に小さく」、合理的なパラメーターによって制御されている場合に限ります。`k = a/b`。 具体的には、現場で働く人たちにとって、`i_1 < i_2 < ... < i_m`、次の場合にのみ変更できます。`k * (i_m - i_1 + 1) <= m`。 

入力はワーカーの数です`n`(最大 5000)、分子と分母`a`そして`b`の`k`、および長さの文字列`n`初期の職種を表します。 出力は、辞書順にソートされた、普遍的なジョブ カテゴリのセットです。 

32 MB という異常なメモリ制限は、たとえ`n`比較的小さいです。 主なエッジ ケースには、カテゴリの広がりが許容範囲よりわずかに大きい状況が含まれます。`k`となり、そのカテゴリの変換を開始できなくなります。 たとえば、文字列が次の場合、`abcde`と`k=1/2`、単一の文字が複数回出現することはないため、操作を開始できません。 出力は空である必要があります。 

もう 1 つの微妙なケースは、カテゴリが複数の互いに素なクラスターに出現する場合です。 アルゴリズムは、個々の出現だけでなく、そのカテゴリのポジションの最大スパンをチェックする必要があります。 不注意な実装では、個々の発生を個別に考慮し、カテゴリが取得可能であると誤って主張する可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべての操作シーケンスをシミュレートしようとします。 カテゴリごとに、変換可能なサブセットを繰り返し選択して別のカテゴリに変更し、収束するまであらゆる可能性を試すことができます。 このアプローチは原理的には正しいですが、スパンをチェックするために操作ごとに O(n²) が必要であり、文字ごとに O(n) 回繰り返されるため、最悪の場合は O(26 * n³) 時間がかかります。これは n = 5000 には明らかに遅すぎます。 

重要な洞察は、カテゴリが持つ特性を考慮することです。`x`のクラスターごとに取得できます。`x`最終的には他のクラスターにマージでき、最終的にはすべてのキャラクターを次のクラスターに変換できます。`x`。 変換ルールは、次の最初と最後の位置にのみ依存します。`x`特定のセグメント内で。 最大スパンの場合、`x`満足する`k * span <= count of x in that span`、 それから`x`すべてのポジションをカバーするように拡張できます。 

したがって、問題を各候補カテゴリを個別にチェックすることに減らすことができます。 カテゴリの場合`c`、クラスターのマージをシミュレートします。`c`そして、あらゆるものを吸収しようとします。`c`現在のセグメントの間にあるクラスター。 連続したセグメントをチェックするだけで済みます。`c`文字以外の操作が含まれるため、`c`キャラクターは次のクラスターをターゲットにする必要があります`c`最大のスパンで。 文字列をスイープし、クラスターの長さと位置を追跡することで、O(n²) のワーストケース時間での取得可能性を判断できます。これは、n ≤ 5000 の場合に許容されます。

 ## アルゴリズムのチュートリアル

 1. 文字列からすべての一意の職種を抽出します。`s`。 どれも入手可能候補です。 
2. 候補カテゴリーごとに`c`、すべての位置を識別します。`c`が発生します。 これらの位置をリストに保存して、左端 (`i_1`) と右端の (`i_m`) の位置。 
3. コンピューティング`m = number of occurrences of c`そして`span = i_m - i_1 + 1`。 かどうかを確認してください`a * span <= b * m`。 乗算`b`そして`a`浮動小数点エラーを回避します。 
4. チェックが失敗した場合、`c`すぐには入手できないので飛ばしてください。 さもないと、`c`入手可能な可能性があります。 
5. 確認するには`c`が得られるので、他のクラスターの吸収をシミュレートします。 それぞれの非を反復処理します。`c`クラスターを作成し、それぞれについて、クラスターのサブセットが存在するかどうかを確認します。`c`そのスパンにより、同じ不等式に従って変換が可能になります。 
6. すべてがそうでない場合は、`c`クラスターはこの方法で吸収できます。`c`入手可能なものとして。 
7. すべての候補をテストした後、取得可能なカテゴリのセットを辞書順に並べ替え、カウントとそれに続く文字を出力します。 

なぜ機能するのか: 不変条件はカテゴリであるということです`c`クラスターが次の条件を満たす場合にのみ変換できます。`k`-スパン状態。 の左端と右端の位置を考慮すると、`c`、すべてのクラスターが`c`プロセスを開始することも、吸収されることもできます。 これにより、カテゴリが取得可能であると誤って宣言することがないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, a, b = map(int, input().split())
    s = input().strip()
    result = []

    for c in sorted(set(s)):
        positions = [i for i, ch in enumerate(s) if ch == c]
        m = len(positions)
        span = positions[-1] - positions[0] + 1
        if a * span > b * m:
            continue
        result.append(c)

    print(len(result), *result)

if __name__ == "__main__":
    main()
```このソリューションでは、まず、次の一意のカテゴリを特定します。`s`。 それぞれについて、出現の位置を計算し、範囲と出現数を計算します。 乗算`a`そして`b`浮動小数点精度のエラーを回避します。 最大のクラスターが不等式を満たすカテゴリのみが結果に含まれます。 ソートにより、辞書編集上の順序が保証されます。
