 ## 問題の理解

 正方形のボードが与えられ、各セルは空であるか、または含まれている可能性があります。`X`。 目標は、連続するブロック内に 3 つの同一の空でないシンボルが含まれる行または列がないようにボードを変更することです。 言い換えれば、次のような長さ 3 のパターンの出現をすべて排除する必要があります。`XXX`水平方向または垂直方向。 

キャラクターを変更することは許可されており、変更を最小限に抑えるつもりはありません。 最終構成のどこにも勝ちトリプルがないことを保証する必要があるだけです。 

制約は十分に大きいため、どのアプローチでもテスト ケースごとのセル数が線形である必要があります。 の合計$n^2$せいぜい$4 \cdot 10^6$したがって、各セルを一定の回数スキャンすることは許容されます。 繰り返しの行の再チェックや後戻りを伴うものは、遅すぎます。 

微妙なエッジケースは、トリプルが重く重なる場合です。たとえば、次のような長いブロックです。`XXXXXX`。 最初に検出されたトリプルのみを対象とする単純な修正では、変更後に新しいトリプルが残る可能性があるため、正確さはローカルな修復ではなく、グローバルなパターンから得られる必要があります。 

## アプローチ

 ブルートフォース戦略では、ボードを繰り返しスキャンして、行または列に 3 つの連続する同一のトークンが出現するかどうかを確認し、そのセグメント内の文字を反転して再開します。 これは、最終的にすべての悪いパターンを削除できるという意味では正しいですが、各スキャンにはコストがかかります$O(n^2)$そして最悪の場合は実行するかもしれません$O(n^2)$変更につながる、$O(n^4)$、それは限界をはるかに超えています。 

重要な点は、設定にまったく反応する必要がないということです。 有効なボードを直接構築する必要があるだけです。 以来`X`簡易バージョンでは、すべてのセルが次のいずれかになります。`X`または空の場合、制約は 3 つの連続する実行のみを考慮します。`X`。 

これは、固定された周期構造を示唆しています。 すべての行と列で 3 つの連続が中断されることを確認すると、`X`を配置することでこれを強制できます`X`トリプルで整列していないポジションのみ。 単純な決定論的な構築は、慎重に選択されたサブセットを反転することを除いて、グリッドを変更しないままにすることです。`X`すべての行と列で、連続する 3 つのセルのセグメントに少なくとも 1 つの変更されたセルが含まれるようにします。 標準的な方法は、座標のパリティに基づくパターンを使用することです。連続する 3 つの位置ごとに、少なくとも 1 つが反転によって変更されるようにします。$(i + j) \bmod 3$。 

これにより、元のトリプルが連続しないことが保証されます。`X`は変更されずに存続し、制御された一部のセルのみを反転するため、許可された操作の範囲内に留まります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースのグリッドを読み取り、変更可能な文字配列として保存します。 
2. グリッドのすべてのセルを行優先の順序で繰り返します。 
3. を含む各セルに対して、`X`、決定論的なルールに基づいてそれを反転するかどうかを決定します。次を使用してその位置をモジュロ 3 で確認します。$(i + j) \bmod 3$。 
4. ルールが反転を示している場合は、変更します。`X`の中へ`.`または潜在的なトリプルを壊すための別の安全な文字。 
5. 決定はローカルでありながらグローバルに構造化されているため、前のセルに再度アクセスせずに続行します。 
6. すべてのセルを処理した後、結果のグリッドを出力します。 

これが機能する理由: 行または列内の 3 つの連続するセルのシーケンスには、3 を法とする異なる残基を持つ 2 つのインデックスが含まれている必要があります。したがって、そのうちの少なくとも 1 つは必ず反転されます。`X`、あらゆることを防ぎます`XXX`形成。 この構築では、長さ 3 の同種セグメントをすべて破棄するグローバル周期制約が強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        grid = [list(input().strip()) for _ in range(n)]

        for i in range(n):
            for j in range(n):
                if grid[i][j] == 'X':
                    if (i + j) % 3 == 0:
                        grid[i][j] = '.'

        for row in grid:
            print(''.join(row))

if __name__ == "__main__":
    solve()
```コードは各セルを 1 回だけ処理し、単純な算術規則を適用します。 モジュロ 3 条件は、3 回連続しないことを保証する中核的な構造保証です。`X`どの方向にも留まります。 この決定はローカルですが、グリッド全体で一貫しているため、変更後に追加の検証は必要ありません。 

よくある落とし穴は、トリプルを検出した後に貪欲なローカル修正を試みることです。これにより、以前に修正された領域が破壊されます。 ここでは、変換は検出とは独立しているため、出力は安定しています。
