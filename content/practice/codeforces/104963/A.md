 ## 解決策
 ## 問題の理解

 決まった金額を何通りの方法で数えるかを求められます$N$50、100、200 の紙幣を使用して正確に支払うことができ、各紙幣は何度でも使用できます。 おつりを渡すという概念がないため、有効な方法は単に合計額が以下の紙幣を複数セットにすることです。$N$。 

使用される 50 ルーブル紙幣、100 ルーブル紙幣、または 200 ルーブル紙幣の枚数が異なる場合、2 つの方法が異なるとみなされます。 ノートを選択する順序は重要ではなく、最後のものだけが重要です。 

計算の観点からは、次の形式の方程式の整数解を数えています。$$50a + 100b + 200c = N$$どこ$a, b, c \ge 0$。 

制約$N \le 10^6$すべてのトリプルを素朴に列挙することはすでに除外されています。 可能なカウントに対する 3 次または 2 次のスキャンは、最悪の場合には遅すぎる可能性があります。$N / 50 = 20000$これにより、ネストされたループが大きくなる可能性がありますが、慎重に境界を設定すれば管理可能です。 重要なのは、問題を単一のループまたは直接カウントに減らすことです。 

エッジケースは割り算からすぐに現れます。 もし$N$は 50 で割り切れません。すべての単位が 50 の倍数であるため、解はありません。たとえば、入力 36 はまったく形成できないため、答えは 0 でなければなりません。これを忘れた単純な実装では、無駄な反復で時間が無駄になります。 

もう一つの微妙なケースは、$N = 0$。 正しい解釈は、支払いをゼロにする方法は 1 つだけあり、それは紙幣をまったく使用しないことです。 回答を誤って初期化する実装や、空の組み合わせをスキップする実装は、ここで失敗します。 

最後に、次のような小さな値$N = 50$は、正確に 1 つの解を生成する必要があり、200 などのより大きな倍数は、複数の宗派にわたるすべての有効な分解を反映する必要があります。 

## アプローチ

 直接的な強引な方法は、可能なすべての枚数の 200 ルーブル紙幣を試し、次に可能なすべての枚数の 100 ルーブル紙幣を試し、残りの合計が 50 ルーブル紙幣を使用して形成できるかどうかを計算することです。 各ペアごとに$(b, c)$、次のように計算します。$$r = N - 200c - 100b$$かどうかを確認してください$r \ge 0$「はい」の場合、答えをインクリメントします。 

すべての有効なソリューションが 1 つのペアに正確に対応するため、これは機能します。$(b, c)$、そして50ルーブル紙幣の枚数は一意に決まります。 

複雑さは、次の値の数によって異なります。$c$そして$b$私たちは努力します。 以来$c \le N/200$そして$b \le N/100$、最悪の場合は約$O((N/200) \cdot (N/100)) = O(N^2)$最悪のスケーリングの意味での反復。 と$N$まで$10^6$、これは遅すぎます。 

重要な観察は、50 ルーブル紙幣すべてを明示的に繰り返す必要はないということです。 修正したら$b$そして$c$、の値$a$は一意に決まります。 したがって、問題は有効なものを数えるということになります$(b, c)$割り算の制約を満たすペア。これは次のように実行できます。$O(N/200)$繰り返して$c$そしてそれを解決する$b$算術的に。

 ## アルゴリズムのチュートリアル

 方程式を書き換えます。$$50a + 100b + 200c = N$$すべてを 50 で割ります。$$a + 2b + 4c = M$$どこ$M = N / 50$。 もし$N$が 50 で割り切れない場合、答えはすぐにゼロになります。 

非負の整数解をカウントするようになりました。$a + 2b + 4c = M$。 

### ステップ

 1. かどうかを確認します。$N \bmod 50 \neq 0$。 その場合、有効な紙幣の組み合わせではそのような合計を形成できないため、0 を返します。 これにより、不可能なケースが即座に排除されます。 
2.セット$M = N / 50$。 ここで問題は、正規化された単位で解を数えることになります。これにより、算術演算が簡素化され、乗算の繰り返しが回避されます。 
3. 200 ルーブル紙幣の枚数を繰り返す$c$。 それぞれ$c$貢献する$4c$単位を合計します。 可能な最大限の$c$は$M // 4$, このスケール化されたシステムでは各ユニットは 4 の価値があるためです。 
4. 固定ごとに$c$、残りの金額を計算します。$$rem = M - 4c$$これは、50 音符と 100 音符のみを使用して形成される部分を表します。 
5. 次に、次の解決策を数えます。$$a + 2b = rem$$固定の場合$b$、$a$次のように一意に決定されます$a = rem - 2b$したがって、有効なものだけが必要です$b$そのような$rem - 2b \ge 0$。 

有効枚数$b$値は次のとおりです。$$\left\lfloor \frac{rem}{2} \right\rfloor + 1$$6. このカウントをそれぞれの答えに加算します。$c$、すべての有効な分解を累積します。 

### なぜ効果があるのか

 あらゆるソリューション$(a, b, c)$の値によって一意に識別されます$c$。 固定ごとに$c$、残りの方程式は次の 1 次元の計数問題に帰着します。$b$、それぞれが有効です$b$正確に 1 つの有効な値に対応します$a$。 これにより、完全なソリューション空間が、次のようにインデックス付けされた互いに素なスライスに分割されます。$c$したがって、すべてのスライスを合計すると、すべての解が重複や省略なしに正確に 1 回カウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input().strip())

    if N % 50 != 0:
        print(0)
        return

    M = N // 50
    ans = 0

    for c in range(M // 4 + 1):
        rem = M - 4 * c
        ans += rem // 2 + 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、正規化された単位で簡略化された方程式に直接従うものです。 開始時の割り切りチェックは非常に重要です。これをスキップすると、不可能なケースが分数解を持つものとして誤って扱われてしまうからです。 

ループオーバー$c$200ルーブル紙幣の枚数を固定することを表します。 残りの合計は 100 ルーブル紙幣から 50 ルーブル紙幣に分配され、各 100 ルーブル紙幣は 2 正規化単位を消費します。 表現`rem // 2 + 1`100 ルーブル紙幣の可能なすべての枚数を 0 から残りの合計で許可される最大値まで数えます。

 ## 特殊なケース

 のために$N = 0$、アルゴリズムセット$M = 0$。 ループは次のようにして 1 回実行されます$c = 0$、与える$rem = 0$そして貢献する$0 // 2 + 1 = 1$。 これにより、空の組み合わせが正しくカウントされます。 

50 の倍数以外の場合、次のようになります。$N = 36$このガードがないと、整数の除算は誤って正規化された値を生成し、不可能な状態を過剰にカウントします。 

次のような小さな正確な倍数の場合$N = 50$、ループ構造は特別なケースなしでも機能します。 と$M = 1$、 のみ$c = 0$は有効であり、意図した解釈と一致する構成を 1 つだけ生成します。
