 ## アルゴリズムのチュートリアル

 1. 下限平方根条件で定義された整数間隔を計算します。 条件$\lfloor \sqrt{x} \rfloor = b$と同等です$b^2 \le x < (b+1)^2$。 これにより、すべての有効な候補者が存在しなければならないクローズドオープン範囲が得られます。 
2. すべての整数を反復処理します。$x$この間隔で。 この範囲のサイズは最大で$2b+1$、直接確認できるほど小さいです。 
3. 各候補者について$x$、計算する$x^2 \bmod n$そしてそれを比較してください$a$。 これにより、モジュラー方程式を解くことなく、モジュラー制約が直接強制されます。 
4. 最初の$x$モジュール条件を満たすものはすぐに返されます。 一意性の保証により、2 番目に有効な候補が存在しないことが保証されます。 

### なぜ効果があるのか

 正しさは、2 番目の条件が制限しているという事実に依存します。$x$モジュラス構造から独立した連続した区間に変換します。 検索がこの範囲に限定されると、モジュラー方程式は単純な述語になります。 この間隔内の整数が 1 つだけモジュラー制約を満たすため、間隔をスキャンすると正確さが保たれ、曖昧さのない終了が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input().strip())
    a = int(input().strip())
    b = int(input().strip())

    L = b * b
    R = (b + 1) * (b + 1)

    for x in range(L, R):
        if 1 <= x <= n - 1 and (x * x) % n == a:
            print(x)
            return

if __name__ == "__main__":
    main()

 ## 特殊なケース

 微妙なケースの 1 つは、次のように定義された間隔である場合です。$b$有効なドメインを超えて拡張される$[1, n-1]$。 たとえば、次の場合$n=10$そして$b=5$、 それから$x \in [25,36)$、これは完全に許容範囲外にあります。 ループは引き続きこれらの値に対して実行されますが、条件$1 \le x \le n-1$すべてをフィルタリングして除外するため、不正な値は考慮されません。 

もう 1 つのエッジケースは次のような場合です$b=0$。 すると間隔はこうなります$x \in [0,1)$、これは潜在的な可能性を除いて有効な候補を提供しません。$x=0$、しかし問題は次のことを必要とします$x \ge 1$したがって、実装では無効なソリューションが返されることが正しく回避されます。 

最後の重要なケースは一意性です。 複数の候補が区間内のモジュラー条件を満たした場合、単純なスキャンでは最初の候補が返されますが、正確性は失われます。 一意性が保証されているため、後戻りやモジュラー代数を使用せずに、アルゴリズムを単純かつ正確に保つことができます。
