 ## 解決策
 ## 問題の理解

 飛行機上にはいくつかのポイントがあります。 接続セグメントがセット内のすべての点の近くにある点のペアを数えたいと考えています。 より正確には、選択したペアに対して$(p_i,p_j)$、すべての点は最大でも離れたところにある必要があります$R$そのセグメントから。 

無限の線ではなく、セグメントが重要です。 点はセグメントの外側に突き出る場合があり、その場合、セグメントまでの距離は端点の 1 つまでの距離になります。 

ポイント数は最大3000ポイント程度です。$4.5\times 10^6$エンドポイントのペア。 すべてのポイントに対してすべてのペアをチェックするには、大まかに必要になります$$\binom{3000}{2}\cdot 3000 \approx 1.35\times 10^{10}$$距離の計算は 3 秒に収まる距離をはるかに超えています。 三次解は除外されます。 二次アルゴリズムは許容されます。$O(n^2\log n)$簡単に十分に高速です。 

誤って対処しやすい状況がいくつかあります。 

すべての点が 1 つの線上にあると仮定します。```
3 1
0 0
2 0
5 0
```正解は 1、つまり 2 つの極値を結ぶ線分です。 すべての点が無限支持線に近いことだけを要求する場合、3 つのペアすべてが有効であるように見えますが、中央のペアが 1 つの端点をセグメントの外側に残すため、これは誤りです。 

もう 1 つの微妙なケースは、支持線から最も遠い点が終点を超えて突き出る場合に発生します。```
3 2
0 0
3 0
10 1
```ポイント$(10,1)$無限直線からの距離はわずか 1 です$y=0$、ただし、からのセグメントまでの距離$(0,0)$に$(3,0)$はほぼ 7 です。ラインベースの定式化だけではこれを見逃します。 

3 番目の落とし穴は、セグメントがすべての点の投影をカバーする必要があることです。 のために```
4 2
-3 0
0 1
0 -1
3 0
```2 つの極値間のセグメントのみが機能します。 より短いセグメントでは、外側の点の 1 つが外側に残ります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての点のペアを列挙し、それらをセグメントの端点として扱い、すべての点からそのセグメントまでの距離を計算します。 すべての距離が最大の場合$R$、ペアを数えます。 

定義が直接チェックされるため、正確さがすぐにわかります。 問題はスピードです。 がある$O(n^2)$ペアと各ペアに必要なもの$O(n)$距離テスト、与える$O(n^3)$操作。 

これを改善するには、ジオメトリを理解する必要があります。 

何らかの方向性を持ってください$u$。 すべての点をその方向に投影します。 すべての予測には最小値と最大値が存在します。 これらの極端な投影を達成する点を結ぶセグメントは、サポート ラインが方向を持つ唯一の候補セグメントです。$u$。 同じ方向の他のペアは、セグメントの外側にいくらかの投影を残します。 

今度は垂直方向を見てください$v$。 への投影間の最大差$v$は、その方向で設定されたポイントの幅とまったく同じです。 すべての点は距離内にあります$$\frac{\text{width}}{2}$$真ん中のラインから。 したがって、方向を持つセグメント$u$に垂直な幅が正確に実現可能です。$u$せいぜい$2R$。 

これにより、問題は凸幾何学問題に変換されます。 内部点は決して極端な投影になることはないため、凸包の頂点のみが重要です。 凸包のエッジ方向ごとに、回転キャリパーを使用して垂直方向の最遠点を維持し、線形時間全体で幅を取得できます。 

幅を超えない場合$2R$、現在の方向に沿った 2 つの極端な点が 1 つの適格なセグメントを形成します。 

重要な観察は、各方向で決定される候補ペアは最大でも 1 つであり、何百万もの可能性が唯一の候補ペアに限定されるということです。$m$船体の頂点、ここで$m\le n$。

 ## アルゴリズムのチュートリアル

 ### 1. 凸包を計算します。 

内部点はいかなる方向の極端な投影も決定しないため、無視できます。 モノトーン チェーン アルゴリズムを使用して凸包を構築します。 

### 2. 小さな船体を扱います。 

ハルに 1 つの点が含まれている場合、セグメントは存在しません。 

ハルに 2 つの点が含まれている場合、そのセグメントが可能な唯一の答えであり、常に有効です。 

### 3. 回転キャリパーを使用して船体の端を横切ります。 

船体のあらゆるエッジに対して$H_iH_{i+1}$、その方向性を検討してください。 この方向に垂直な幅は、サポート ラインからエッジを通って船体の頂点までの最大距離に等しくなります。 

対蹠点は多角形の周囲を単調に移動するため、回転キャリパー技術により合計線形時間のこの最大値が更新されます。 

### 4. 幅を計算します。 

エッジベクトルの場合$e$、 させて$$A = |\text{cross}(e, H_k-H_i)|$$どこ$k$現在の対蹠点です。 

実際の幅は$$\frac{A}{|e|}.$$浮動小数点数を使用する代わりに、比較します。$$A^2 \le (2R)^2|e|^2.$$これにより、精度の問題が回避されます。 

### 5. エンドポイント ペアを回復します。 

現在のエッジ方向の場合、すべての投影にまたがるセグメントは、その方向の 2 つのサポート ポイントによって形成されます。 

キャリパーを回転させると、これらの極端な頂点が同時に維持されます。 幅条件が成立する場合、そのペアは 1 つの答えを提供します。 

### 6. 異なるペアを数えます。 

エッジの方向が異なると同じエンドポイントのペアが生成される可能性があるため、ペアをセットに保存します。 

### なぜ効果があるのか

 どの方向でも、すべての点投影は間隔を形成します。 投影間隔にすべての点が含まれるその方向の唯一のセグメントは、最小投影と最大投影を結合するセグメントです。 すべての投影が間隔内にあるため、このセグメントまでの点の距離は支持線までの距離と等しくなります。 

セグメント方向に垂直な幅は、まさにその最大距離の 2 倍になります。 したがって、「すべての点が距離内にある」という条件が成立します。$R$セグメントからの距離」は、「セグメントに垂直な点セットの幅は最大で$2R$回転キャリパーは関連するすべての方向を列挙するため、すべての有効なペアが検出され、無効なペアはカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    n, R = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(pts)
    m = len(hull)

    if m < 2:
        print(0)
        return

    if m == 2:
        print(1)
        return

    hull.extend(hull[:2])

    j = 1
    ans = set()

    for i in range(m):
        ni = i + 1
        ex = hull[ni][0] - hull[i][0]
        ey = hull[ni][1] - hull[i][1]

        while True:
            nj = (j + 1) % m

            cur = abs(ex * (hull[j][1] - hull[i][1]) -
                      ey * (hull[j][0] - hull[i][0]))
            nxt = abs(ex * (hull[nj][1] - hull[i][1]) -
                      ey * (hull[nj][0] - hull[i][0]))

            if nxt > cur:
                j = nj
            else:
                break

        area = abs(ex * (hull[j][1] - hull[i][1]) -
                   ey * (hull[j][0] - hull[i][0]))

        edge_sq = ex * ex + ey * ey

        if area * area <= 4 * R * R * edge_sq:
            a = i
            b = ni % m
            if a > b:
                a, b = b, a
            ans.add((a, b))

    print(len(ans))

solve()
```最初の部分では凸包を構築します。 使用する`<=0`同一線上にある内部点を削除し、極端な頂点のみを残します。 

回転キャリパーが対蹠点を維持`j`。 以来`j`前進のみの場合、ポインタが進む合計数は線形です。 

比較には二乗量が使用されます。 これにより、浮動小数点の不正確さが回避され、浮動小数点の小さな摂動が発生するというステートメントの保証と一致します。$R$答えを変えないでください。 

複数のエッジが同じセグメント方向に対応する可能性があるため、ペアがセットに挿入されます。

## 特殊なケース

 検討してください```
3 1
0 0
2 0
5 0
```船体には 2 つの極点のみが含まれています。 回転キャリパーを動かす必要はありません。 アルゴリズムは 1 を出力します。これは、中間点がセグメント上にあるため、正しい値です。 

のために```
3 2
0 0
3 0
10 1
```短いセグメントの方向に関する幅は小さいですが、投影は 3 番目の点にまたがりません。 その方向のサポートペアは次のようになります。$(0,0)$そして$(10,1)$、 ない$(0,0)$そして$(3,0)$、誤ったカウントを防ぎます。 

のために```
4 2
-3 0
0 1
0 -1
3 0
```複数のエッジ方向が幅条件を満たします。 それらはすべて、2 つの極点で構成される同じサポート ペアを生成します。 ペアのセットにより重複が削除され、正解 1 が残ります。
