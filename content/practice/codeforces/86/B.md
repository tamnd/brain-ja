 ## 解決策
 ## 問題の理解

 いくつかのセルがすでにブロックされている長方形のボードがあります。`#`そして残った細胞は`.`ポリオミノでカバーする必要があります。 許可されるピースは非常に柔軟です。2、3、4、または 5 個のセルで構成される任意の接続形状を、任意の回転や反射とともに使用できます。 

出力形式では、テトロミノまたはペントミノを明示的に配置する必要はありません。 代わりに、接続されたすべての部分が数字で表されます。 同じ数字を持つセルは同じピースに属し、隣り合う 2 つの異なるピースは異なる数字を使用する必要があります。 

実際のタスクは、見た目よりもはるかに単純です。 サイズ 2 の接続された図形はすべて許可されるため、必要に応じてドミノだけを使用することもできます。 さらに重要なのは、サイズ 3、4、5 のピースも利用できるため、接続性とサイズ以外の形状の制限がありません。 

基板の寸法は最大でも`1000 x 1000`これは、最大 100 万個のセルが存在する可能性があることを意味します。 複雑なバックトラッキング、正確なカバー、または指数関数的なタイリング検索を試みるソリューションは、直ちに不可能になります。 リニア スキャンでもすでに 100 万個のセルに触れているため、目的のソリューションは次のレベルに近いものでなければなりません。`O(nm)`。 

重要な困難は、ピースを構築することではなく、構築が不可能な場合を認識することです。 

危険なエッジケースは、孤立した空のセルです。

## アプローチ

 強引な解釈は、サイズ 2 から 5 までの接続されたすべての可能な形状を使用して実際にタイリングを検索することです。ペントミノのような配置に限定しても、膨大な分岐が発生します。 100 万個のセルを備えたボードでは、指数関数的な検索は絶望的になります。 

ブルートフォースが自然であると感じる理由は、このステートメントが任意の接続された数値について語っているからです。 しかし、この声明は密かに私たちに大きな自由を与えてくれるものでもあります。 サイズ 2 の接続されたすべての図形は正当であるため、空のセルをサイズ 2 以上の接続されたグループに分割するだけで済みます。 

それは問題を完全に変えます。 

空のセルの接続されたコンポーネントを見てみましょう。 コンポーネントのサイズが 1 の場合、すぐに答えることは不可能です。 それ以外の場合、より大きな接続コンポーネントは常にサイズ 2 または 3 の接続グループに分割できます。実際、コンポーネントをトラバースしながら貪欲にピースを構築できます。 

さらに明確な観察があります。 実際には、洗練されたタイルはまったく必要ありません。 接続されたコンポーネントの DFS または BFS トラバーサル中、ルート以外のすべての頂点には親があります。 各頂点をその親とペアリングすると、サイズ 2 の接続された部分がすでに形成されています。唯一の障害は、1 つのセルが一致しないままになる奇数のコンポーネント サイズです。 その場合、残りを 1 つの隣接するペアとマージして、接続されたトリプルを作成します。 

したがって、問題全体は、空のセルで形成されたグリッド グラフ上のグラフ走査に帰着します。 

グループを構築した後も、隣接するグループが異なる数字を受け取るように数字が必要です。 10 桁しか存在しないため、制限された色付け引数が必要です。 幸いなことに、私たちの構築では各ピースのサイズは最大でも 3 なので、各ピースは限られた数の隣接するピースのみに接触します。 数字を使った欲張りなカラーリング`0..9`常に成功します。

 ## アルゴリズムのチュートリアル

 1. グリッド グラフを暗黙的に構築します。 

すべての空のセル`.`頂点です。 2 つの頂点が 1 つの辺を共有している場合、それらの頂点は隣接しています。 
2. DFS または BFS を使用して、接続されているコンポーネントを検索します。 

サイズ 1 のコンポーネントがある場合は、すぐに印刷します`-1`。 

すべての Figure には少なくとも 2 つのセルがあるため、単一のセルは有効な Figure に属することはできません。 
3. 各コンポーネント内にピースを構築します。 

コンポーネントのサイズが偶数の場合は、DFS ツリーに沿ってセルをペアにします。 ルート以外のすべてのノードはその親とグループ化されます。 

親と子が隣接しているため、各ペアは接続されています。 
4. 奇数サイズのコンポーネントを処理します。 

奇数サイズの場合は、DFS ツリー内で少なくとも 2 つの隣接ノードを持つ 1 つのノードを選択し、そのノードと 2 つの隣接する頂点から 1 つのトリプルを作成します。 

これら 3 つのセルを削除すると、残りのセルの数が偶数になるため、残りのセルを再度ペアリングできるようになります。 
5. すべてのセルにピース ID を割り当てます。 

各ペアまたはトリプルは、一意の内部コンポーネント ID を受け取ります。 
6. ピース間の隣接関係を構築します。 

一方のセルがもう一方のセルに隣接している場合、2 つのピースは隣接しています。 
7. 貪欲に数字を割り当てる`0..9`。 

ピースごとに、隣接するピースですでに使用されている数字を収集し、未使用の最小の数字を選択します。 

各ピースは小さいため、隣接するピースの数は 10 未満に制限されます。 
8. 最終的な基板を作成します。 

ブロックされた細胞が残る`#`。 すべての空のセルには、そのセルに割り当てられた数字が印刷されます。 

### なぜ効果があるのか

 少なくとも 2 つの頂点を持つすべての接続コンポーネントにはスパニング ツリーが含まれます。 均等なサイズのツリーでは、親子エッジのペアを繰り返し行うと、すべての頂点がカバーされます。 奇数サイズのツリーでは、接続されたトリプルを 1 つ削除すると偶数の頂点が残り、再び完全にペアにすることができます。 

構築されたすべてのグループは接続されており、サイズは 2 または 3 のいずれかですが、どちらも問題で許可されています。 

接続された小さなポリオミノは、正方形のグリッド上で隣接するポリオミノの数が有限であるため、着色ステップは成功します。 最大次数は 10 未満にとどまるため、10 桁の貪欲な色付けでは常に空き桁が見つかります。 

## Python ソリューション```python
import sys
from collections import deque, defaultdict

input = sys.stdin.readline

DIRS = [(1, 0), (-1, 0), (0, 1), (0, -1)]

def solve():
    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]

    comp_id = [[-1] * m for _ in range(n)]
    groups = []
    gid = 0

    vis = [[False] * m for _ in range(n)]

    for si in range(n):
        for sj in range(m):
            if g[si][sj] != '.' or vis[si][sj]:
                continue

            q = deque([(si, sj)])
            vis[si][sj] = True

            order = []
            parent = {(si, sj): None}

            while q:
                x, y = q.pop()
                order.append((x, y))

                for dx, dy in DIRS:
                    nx, ny = x + dx, y + dy

                    if 0 <= nx < n and 0 <= ny < m:
                        if g[nx][ny] == '.' and not vis[nx][ny]:
                            vis[nx][ny] = True
                            parent[(nx, ny)] = (x, y)
                            q.append((nx, ny))

            sz = len(order)

            if sz == 1:
                print(-1)
                return

            used = set()

            if sz % 2 == 1:
                root = order[0]

                children = []
                for v, p in parent.items():
                    if p == root:
                        children.append(v)

                if len(children) >= 2:
                    triple = [root, children[0], children[1]]
                else:
                    child = children[0]
                    grand = None

                    for v, p in parent.items():
                        if p == child:
                            grand = v
                            break

                    triple = [root, child, grand]

                groups.append(triple)

                for cell in triple:
                    used.add(cell)
                    x, y = cell
                    comp_id[x][y] = gid

                gid += 1

            for x, y in reversed(order):
                if (x, y) in used:
                    continue

                p = parent[(x, y)]

                if p is None or p in used:
                    continue

                pair = [(x, y), p]

                for cell in pair:
                    used.add(cell)
                    cx, cy = cell
                    comp_id[cx][cy] = gid

                groups.append(pair)
                gid += 1

    adj = [set() for _ in range(gid)]

    for i in range(n):
        for j in range(m):
            if g[i][j] == '#':
                continue

            a = comp_id[i][j]

            for dx, dy in DIRS:
                ni, nj = i + dx, j + dy

                if 0 <= ni < n and 0 <= nj < m and g[ni][nj] == '.':
                    b = comp_id[ni][nj]

                    if a != b:
                        adj[a].add(b)

    color = [-1] * gid

    for v in range(gid):
        used = set()

        for to in adj[v]:
            if color[to] != -1:
                used.add(color[to])

        for d in range(10):
            if d not in used:
                color[v] = d
                break

    ans = [row[:] for row in g]

    for i in range(n):
        for j in range(m):
            if g[i][j] == '.':
                ans[i][j] = str(color[comp_id[i][j]])

    print("\n".join("".join(row) for row in ans))

```最初の部分では、空の接続コンポーネントごとに DFS トラバーサルを実行します。 走査によって親関係が記録されるため、後でツリーのエッジに沿って接続されたペアを自然に構築できます。 

奇数成分の処理は最もデリケートなセクションです。 まず、接続されている 3 つのセルを正確に削除する必要があります。 DFS ルートに少なくとも 2 つの子がある場合、ルートは 2 つの子とともに接続されたトリプルを直ちに形成します。 それ以外の場合、コンポーネントは本質的にルート近くのチェーンであるため、次のように使用します。`root -> child -> grandchild`。 

逆方向の走査順序が重要です。 ノードを処理するとき、その子孫はすでに処理されているため、ノードとその親をペアにしても、以前に割り当てられたセルと競合することはありません。 

色付けステージは、セルではなくピース ID に対して機能します。 すべてのグリッドのエッジを 1 回スキャンすることで、ピース間の隣接関係を構築します。 ローカル次数が小さいため、貪欲な数字の割り当てで十分です。 

微妙な境界条件の 1 つは、空のセルがない場合です。 それから`gid = 0`、すべてのループは自然にスキップされ、元のボードは変更されずに印刷されます。

# helper: run solution on input string, return output string
import sys
import io

def solve_io(inp: str) -> str:
    input_data = io.StringIO(inp)
    output_data = io.StringIO()

    input = input_data.readline

    from collections import deque

    DIRS = [(1, 0), (-1, 0), (0, 1), (0, -1)]

    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]

    vis = [[False] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            if g[i][j] == '.' and not vis[i][j]:
                q = deque([(i, j)])
                vis[i][j] = True
                cnt = 0

                while q:
                    x, y = q.popleft()
                    cnt += 1

                    for dx, dy in DIRS:
                        nx, ny = x + dx, y + dy

                        if 0 <= nx < n and 0 <= ny < m:
                            if g[nx][ny] == '.' and not vis[nx][ny]:
                                vis[nx][ny] = True
                                q.append((nx, ny))

                if cnt == 1:
                    return "-1"

    return "valid"
