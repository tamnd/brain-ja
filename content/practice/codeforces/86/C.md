 ## 解決策
 ## 問題の理解

 アルファベットの上にいくつかの短い DNA 断片が与えられます`{A, C, G, T}`。 より長い DNA 文字列は、文字列のすべての位置が指定されたフラグメントの 1 つが少なくとも 1 回出現する場合に有効であるとみなされます。 

フラグメントは任意に重複する可能性があります。 1 つのフラグメントが別のフラグメント内で開始することも、複数のフラグメントが同じ位置をカバーすることもできます。 唯一の要件は、文字列内のどこかにフラグメントのオカレンスを配置した後、すべての文字位置が少なくとも 1 つのオカレンスでカバーされることです。 

長さの文字列の数を数えなければなりません`n`この条件を満たします。 

制約は、ある次元では小さく、他の次元では一見大きく見えます。 多くてもあります`10`パターンとすべてのパターンの長さは最大です`10`なので、パターン全体の長さは非常に小さくなります。 これは、パターン上にある種のオートマトンを構築することを強く示唆しています。 一方で、`n`到達できる`1000`、指数関数的なものは即座に除外されます。`n`、またはポジション上に完全なカバレッジマスクを保存する任意の DP。 

この問題の危険な部分は、報道範囲が世界規模であることです。 ポジションがカバーされるかどうかは、より早く始まり、より遅く終了する可能性のあるパターンの出現によって作成される間隔によって決まります。 現在のオートマトンの状態を追跡するだけの単純な DP では十分ではありません。 

いくつかのエッジケースでは、より単純なアプローチが失敗します。 

考慮する：```
3 1
AA
```有効な文字列は次のとおりです。```
AAA
```文字列`"AAB"`位置が異なるため無効です`3`パターンがその位置で終了しているにもかかわらず、検出されません`2`。 どこかに何らかのパターンが現れるかどうかだけをチェックする不注意な DP は、それを誤って受け入れてしまうでしょう。 

もう一つの微妙なケース:```
4 2
AAA
AA
```文字列`"AAAA"`有効です。 カバレッジは、重複する発生から得られます。```
AAA
 AAA
```常に最長のパターンでカバレッジを拡張しようとする貪欲な戦略は、カバレッジに重複する短い一致が必要になる可能性があるため、失敗する可能性があります。 

重複したパターンも許可されます。```
3 2
A
A
```答えはまだです`1`、 ない`2`。 私たちは、それらをカバーする方法ではなく、個別の文字列をカウントします。 

最も難しい概念上の問題は次のとおりです。```
5 1
AT
```マッチングしたとしても`"AT"`位置で終わる`4`、 位置`5`まだ解明されていない可能性があります。 カバレッジは、文字列に多くの一致が含まれるかどうかではなく、すべてのインデックスを個別に対象とします。 

ソリューションでは、文字列を左から右にスキャンする際に、現在のカバレッジがどこまで広がっているかを記憶する必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべて生成`4^n`DNA 文字列のそれぞれについて、すべての位置がパターンの少なくとも 1 つの出現に属しているかどうかを確認します。 

1 つの文字列のチェックは、大まかに標準の部分文字列マッチングで実行できます。`O(n * total_pattern_length)`。 本当の問題は文字列の数です。 と`n = 1000`、私たちはそうするでしょう`4^1000`候補者は天文学的に不可能です。 

次に自然なアイデアは、プレフィックスを使用した動的プログラミングです。 文字列を左から右に構築するときに、現在どのパターンが接尾辞として一致しているかを知りたいと考えています。 これは、すべてのサフィックス一致情報をコンパクトに格納するため、Aho-Corasick オートマトンをすぐに示唆します。 

オートマトンだけではまだ不十分です。 

私たちがその位置にいると仮定します`i`。 現在のオートマトン ノードがわかれば、どのパターンがどのノードで終わるのかがわかります。`i`ただし、有効性は位置によって異なります。`i`それ自体はカバーされています。 カバレッジは、以前の試合によって作成されたインターバルから得られます。 長さのパターンの場合`L`で終わる`i`、その後、ポジションをカバーします`[i-L+1, i]`。 

重要な観察は、左から右にスキャンする際に重要なのは、既にカバーされていることが保証されている右端の位置だけであるということです。 

カバーされたポジションの正確なセットを保存する代わりに、1 つの数値を保存します。`rem = how many future positions are still guaranteed covered`長さのパターンの場合`L`現在の位置で終了し、その後カバレッジが拡張されます`L-1`未来へのポジション。 1文字進めながら、`rem`1つ減ります。 より長い一致が表示されるたびに、それを更新します。 

これにより、グローバル カバレッジ条件がローカル DP 遷移に変換されます。 

オートマトンは、現在の位置で終わるすべてのパターン一致を返します。 DP は残りの最大カバレッジを維持します。 これらは共に、州を完全に特徴づけます。 

パターンの合計の長さが最大で`100`。 残りの補償範囲は最大でも`10`、パターンの長さは最大でも`10`。 これにより、立体的な外観の DP が完全に実現可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^n · n · totalLen) | O(n) | 遅すぎる |
 | 最適 | O(n · 状態 · maxLen · 4) | O(状態 · maxLen) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのパターンから Aho-Corasick オートマトンを構築します。 

各ノードは、何らかのパターンのプレフィックスを表します。 遷移は DNA の特徴に従います。 障害リンクは、トライ内にも存在する最も長い適切なサフィックスにノードを接続します。 
2. すべてのオートマトン ノードについて、次の計算を行います。`best[node]`。`best[node]`このノードまたはその障害チェーンに沿って終了するパターンの最大長です。 

これが重要なのは、文字列のプレフィックスを読み取った後にノードに到達すると、ここで終わるすべての一致したパターンがカバレッジを拡張する可能性があるためです。 最も長いものだけが重要です。 
3. DP 状態を定義します。 

させて：`dp[pos][state][rem]`最初のものを構築する方法の数を示します`pos`次のような文字:`state`は現在のオートマトン ノードです。`rem`から始まるポジションの数は何ですか`pos+1`すでにカバーされることが保証されています。 
4. 初期化します。```
dp[0][root][0] = 1
```内容を読む前に、将来のポジションについては触れません。 
5. 文字を 1 つ追加して遷移します。 

から`(pos, state, rem)`:

 4 つの DNA 文字をすべて試してください。 

オートマトンの中を移動して、`next_state`。 
6. 残りのカバレッジを更新します。 

まず、ポジションを 1 つ進めたため、既存のカバレッジが 1 つ縮小します。```
new_rem = max(rem - 1, 0)
```次に、何らかのパターンがここで終了するかどうかを確認します。 一致した最長のパターンに長さがある場合`L`、それはカバーします`L-1`将来のポジション:```
new_rem = max(new_rem, L - 1)
```7. カバーされていないポジションを拒否します。 

現在の位置は、次のいずれかの場合にカバーされます。`rem > 0`または、ここで終わるパターンがすぐにカバーします。 

同様に、遷移の処理後、次の場合に限り、現在の位置が有効になります。```
max(rem, L) > 0
```すべてのパターンは正の長さを持っているため、この状態は更新ロジックを通じて自然に現れます。 
8. すべての処理が完了したら`n`文字、状態のみ`rem == 0`は自動的に有効になります。 

実際には、処理されたすべての位置は遷移中にすでにチェックされているため、残りの状態はすべて有効です。 すべての DP 値を長さで合計します。`n`。 

### なぜ効果があるのか

 不変条件は次のとおりです。 

加工後`pos`キャラクター、`rem`は、以前に完了したパターンの出現によってカバーされることがすでに保証されている将来のポジションの数に等しくなります。 

長さのパターンがあるたびに`L`現在の位置で終了すると、正確に次の位置のカバレッジに貢献します。`L-1`ポジション。 最大値を取ると、最も遠くに到達するアクティブな間隔のみが重要となるため、必要な情報がすべて保存されます。 

アクティブなカバレッジ間隔がなく、そこで終了する新しいパターンがない状態でその位置に進むと、その位置は正確に無効になります。 民進党はそのような移行を決して認めない。 

オートマトンはすべての位置で終わるすべてのパターンを正確に識別し、DP は将来のカバレッジ範囲を正確に追跡するため、受け入れられたすべての構造は有効なフィルター処理された文字列に対応し、すべての有効なフィルター処理された文字列は何らかの DP パスに従います。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

MOD = 1000000009
ALPHA = {'A': 0, 'C': 1, 'G': 2, 'T': 3}

def solve():
    n, m = map(int, input().split())
    patterns = [input().strip() for _ in range(m)]

    # trie
    nxt = [[-1] * 4]
    fail = [0]
    best = [0]

    for s in patterns:
        node = 0

        for ch in s:
            c = ALPHA[ch]

            if nxt[node][c] == -1:
                nxt[node][c] = len(nxt)
                nxt.append([-1] * 4)
                fail.append(0)
                best.append(0)

            node = nxt[node][c]

        best[node] = max(best[node], len(s))

    # build automaton
    q = deque()

    for c in range(4):
        if nxt[0][c] == -1:
            nxt[0][c] = 0
        else:
            v = nxt[0][c]
            fail[v] = 0
            q.append(v)

    while q:
        v = q.popleft()

        best[v] = max(best[v], best[fail[v]])

        for c in range(4):
            to = nxt[v][c]

            if to == -1:
                nxt[v][c] = nxt[fail[v]][c]
            else:
                fail[to] = nxt[fail[v]][c]
                q.append(to)

    states = len(nxt)
    max_len = 10

    dp = [[[0] * (max_len + 1) for _ in range(states)] for _ in range(n + 1)]
    dp[0][0][0] = 1

    for pos in range(n):
        for state in range(states):
            for rem in range(max_len + 1):
                cur = dp[pos][state][rem]

                if cur == 0:
                    continue

                for c in range(4):
                    ns = nxt[state][c]

                    longest = best[ns]

                    # current position must be covered
                    if rem == 0 and longest == 0:
                        continue

                    nrem = max(rem - 1, longest - 1)

                    dp[pos + 1][ns][nrem] += cur
                    dp[pos + 1][ns][nrem] %= MOD

    ans = 0

    for state in range(states):
        for rem in range(max_len + 1):
            ans += dp[n][state][rem]

    ans %= MOD

    print(ans)

solve()
```トライ構造では、すべてのパターンを 1 文字ずつ挿入します。 各終端ノードには、そこで終わる最大パターン長が格納されます。 将来の適用範囲では、長い間隔が短い間隔よりも優先されるため、最大値を使用するだけで十分です。 

BFS over the trie は、標準の Aho-Corasick とまったく同じように障害リンクを構築します。 この走査中に、障害リンクを通じてパターン情報を伝播します。```
best[v] = max(best[v], best[fail[v]])
```この行がないと、サフィックス マッチは失われます。 たとえば、パターンが`"AAA"`そして`"AA"`、読んだ後`"AAA"`私たちはそれを認識しなければなりません`"AA"`もそこで終わります。 

DP 寸法`rem`だけです`10`パターンの長さが超えないため`10`したがって、将来の補償範囲をこれ以上拡大することはできません。`9`。 

移行ロジックはソリューションの中核です。 

もし`rem == 0`現在の位置でパターンが終了していない場合は、現在位置がカバーされず、トランジションを破棄する必要があります。 

それ以外の場合は、次のように計算します。```
nrem = max(rem - 1, longest - 1)
```位置を 1 つ右に移動したため、前のアクティブな間隔は 1 ステップ失われます。 新しく一致したパターンにより、範囲がさらに拡大される可能性があります。 

すべての状態を詳しく合計する`n`は正しいです。移行中にカバレッジはオンラインで検証されます。 カバーされていないポジションはDPに生き残ることはできません。

import io

    input = sys.stdin.readline

    n, m = map(int, input().split())
    patterns = [input().strip() for _ in range(m)]

    fail = [0]
    best = [0]

    for s in patterns:

            c = ALPHA[ch]

            if nxt[node][c] == -1:
                nxt[node][c] = len(nxt)
                nxt.append([-1] * 4)
                fail.append(0)
                best.append(0)

            node = nxt[node][c]

        best[node] = max(best[node], len(s))

    q = deque()

    for c in range(4):
        if nxt[0][c] == -1:
            nxt[0][c] = 0
        else:
            v = nxt[0][c]
            q.append(v)

    while q:
        v = q.popleft()

        best[v] = max(best[v], best[fail[v]])

        for c in range(4):
            to = nxt[v][c]

            if to == -1:
                nxt[v][c] = nxt[fail[v]][c]
            else:
                fail[to] = nxt[fail[v]][c]
                q.append(to)

    states = len(nxt)

    dp = [[[0] * 11 for _ in range(states)] for _ in range(n + 1)]
    dp[0][0][0] = 1

    for pos in range(n):
        for state in range(states):
            for rem in range(11):
                cur = dp[pos][state][rem]

                    dp[pos + 1][ns][nrem] %= MOD

    ans = 0

    for state in range(states):
        for rem in range(11):
            ans += dp[n][state][rem]

    return str(ans % MOD) + "\n"

longest = 0

AA
```オートマトンが読み取るとき`"AAA"`、のノード`"AAA"`の一致も継承します`"AA"`障害リンクを通じて。 伝播しない場合:```

```DP は短い接尾辞の一致を見逃し、一部の有効な文字列を誤って拒否します。
