 ## 解決策
 ## 問題の理解

 グラフがあります`n`最初は都市も道路もありません。 一部の都市のペアは禁止されており、それらの間に直接道路を建設することは許可されていません。 

2 つの条件が成立するように、追加する道路の数は最小限にする必要があります。 

まず、すべての都市が他のすべての都市からアクセス可能である必要があります。 

次に、2 つの都市間の距離は最大 2 でなければなりません。これは、1 つの都市から別の都市へは 1 本の道路または 2 本の道路を使用して移動できることを意味します。 

入力は禁止されたペアを記述します。 リストにないすべてのペアは構築可能です。 この問題により、少なくとも 1 つの有効な解決策が存在することが保証されます。 

要件に関する重要な観察は、要件が非常に強力であるということです。 接続されたグラフ`n`少なくとも頂点が必要です`n - 1`すべての接続されたグラフにはスパニング ツリーが含まれているためです。 道路の最小数を尋ねられるので、有効な答えは正確に使用する必要があります。`n - 1`道路。 

グラフ`n - 1`エッジは木です。 木の中で直径が2以下のものは星だけです。 他のツリーには、少なくとも 3 の長さのパスが含まれています。 

これは、答えがどこかの都市を中心とする星であるに違いないことをすぐに示唆します。 

微妙なポイントは中心を選ぶことです。 別の都市と禁止されたペアを持つ都市を選択した場合、スター エッジをその都市に接続することはできません。 問題の保証は、禁止されたペアに関与していない都市が少なくとも 1 つ存在することを意味します。 その都市を見つけることがすべての問題です。 

インプットを考慮する```
4 1
1 3
```都市 2 は禁止されたペアには決して現れません。 都市 2 を中心とする星はエッジを使用します`(2,1)`、`(2,3)`、`(2,4)`。 すべての都市のペアは 2 に直接接続されているか、正確に 2 ステップで 2 を経由して出会うことができます。 

不用意なアプローチは、禁じられたエッジを避けながら貪欲に都市を接続しようとする可能性があります。 例えば、```
4 2
1 2
3 4
```任意の合法な道路を構築すると、接続されたグラフが生成される可能性がありますが、それ以上のものを使用する可能性があります。`n - 1`エッジが小さくなり、最小値ではなくなります。 

もう 1 つの簡単な間違いは、他のすべての都市と個別に禁止されていない都市を検索することです。 問題はもっと簡単です。 必要なのは、禁止されたペアにまったく出現しない都市だけです。 そのような都市は、すべての禁断の縁がそこに関与する必要があるため、すべての人とつながることができますが、それは決して起こりません。 

例えば、```
5 3
1 2
1 3
1 4
```都市 5 は禁止リストのどこにも載っていません。 あらゆるエッジ`(5,x)`は合法であるため、5 を中心とする星は有効です。 

## アプローチ

 ブルートフォースの観点は、禁止エッジ制約を満たすすべての可能なグラフを試し、すべてのペアごとの距離が最大 2 であるかどうかを確認することです。たとえ接続されたグラフに限定したとしても、可能なエッジのサブセットの数は、利用可能なエッジの数において指数関数的になります。 これはまったく実現不可能です。 

より合理的な強引なアイデアは、すべての都市を中心候補としてテストすることです。 各都市について、他のすべての都市に接続できるかどうかを確認し、対応するスターを構築します。 これはすでにソリューションの実際の構造を示唆しています。 

重要な観察は、2 つの事実を組み合わせることで得られます。 

接続されているグラフ`n`少なくとも頂点が必要です`n - 1`エッジ。 

まさに`n - 1`エッジは木です。 

すべてのツリーの中で、すべての頂点のペアを距離 2 以内に保つ唯一の方法は、星を使用することです。 

したがって、任意のグラフを作成する代わりに、スターを作成するだけで済みます。 残りの問題は、有効なセンターが存在するかどうかです。 

少なくとも 1 つの禁止されたペアに出現するすべての都市をマークしましょう。 各禁止エッジは両方の終点をマークするため、マークされていない都市は禁止ペアに参加することはありません。 その都市から別の都市までのすべての端は合法です。 

問題保証により、そのような都市が少なくとも 1 つ存在することが保証されます。 見つかったら、それを他のすべての都市に接続します。 結果はまさに星です。`n - 1`エッジ、これは可能な最小限です。

 ## アルゴリズムのチュートリアル

 1. 各都市が禁止されたペアに含まれるかどうかを示すブール配列を作成します。 
2. すべての禁止されたペアを読み取ります`(u, v)`。 
3. 両方にマークを付けます`u`そして`v`禁断のペアとして登場。 
4. すべてのペアを処理した後、都市を見つけます`center`それは決してマークされていませんでした。 

このような都市はどの禁止されたペアにも属さないため、からのすべての道は`center`別の都市への移動は許可されています。 
5. 出力`n - 1`、星が付いているので、`n`頂点には正確に含まれます`n - 1`道路。 
6. 異なる都市ごとに`center`、道路を出力します`(center, city)`。 

### なぜ効果があるのか

 しましょう`center`禁断のペアには決して登場しない都市であること。 

以来`center`すべての禁止されたペア、すべてのエッジに存在しない`(center, v)`合法です。 したがって、構築された星のすべての道路を構築できます。 

すべての都市が直接接続されているため、結果のグラフは接続されています。`center`。 

中心部以外の 2 つの都市は、次のルートで相互にアクセスできます。`center`ちょうど2つの道路にあります。 どの都市と中心部も一本の道路で結ばれています。 したがって、都市の各ペアの距離は最大 2 になります。 

グラフには正確に次の内容が含まれています`n - 1`エッジ。 接続されたグラフでは使用するエッジが少なくなるため、構築は最小限になります。 

この問題では解が存在することが保証されているため、禁止されたペアに決して出現しない都市が常に少なくとも 1 つ存在し、アルゴリズムは常にその都市を見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    used = [False] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        used[u] = True
        used[v] = True

    center = 1
    for i in range(1, n + 1):
        if not used[i]:
            center = i
            break

    print(n - 1)
    for i in range(1, n + 1):
        if i != center:
            print(center, i)

solve()
```最初の部分は、どの都市が少なくとも 1 つの禁止されたペアに参加しているかを記録します。 禁止されたエッジ自体を保存する必要はありません。 重要な情報は、その中に都市が登場するかどうかだけです。 

の検索`center`都市を一度スキャンします。 この問題では有効な解決策が保証されているため、マークされていない都市が少なくとも 1 つ存在します。 

中心を見つけたら、構築は簡単です。 私たちは中心部と他のすべての都市を結び、正確に生産します`n - 1`道路。 

よくある実装上の間違いは、禁止されたエッジを保存し、それを繰り返しチェックすることです。`(center, i)`は禁止されています。 その作業は不要です。 構造上、マークのない中心は禁止されたペアには決して現れないため、そのようなエッジはすべて自動的に合法になります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    n, m = map(int, input().split())

    used = [False] * (n + 1)

    for _ in range(m):
        u, v = map(int, input().split())
        used[u] = True
        used[v] = True

    center = next(i for i in range(1, n + 1) if not used[i])

    out = [str(n - 1)]
    for i in range(1, n + 1):
        if i != center:
            out.append(f"{center} {i}")

    return "\n".join(out) + "\n"
