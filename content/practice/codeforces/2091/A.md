 ## 解決策
 ## 問題の理解

 私たちは、1 つずつ描かれた一連の数字から特定の日付、2025 年 3 月 1 日を形成できる最も早い段階を見つけ出すように求められています。 区切り文字を除いた日付は、`01032025`したがって、目的は、これらの数字が順番に描画されたことを検出し、間にある余分な数字を無視できるようにすることです。 各テスト ケースでは、次のシーケンスが得られます。`n`時系列で描かれた数字。 シーケンスにすべての数字が正しい順序で含まれていない場合は、次の値が返されます。`0`。 

制約は小さいです。`n`これは、効率を気にせずに配列を複数回スキャンしたり、単純なカウンターを維持したりできることを意味します。 テストケースの数`t`最大 10^4 になる可能性があるため、テスト ケースごとの処理が高速で、理想的には線形であることを確認する必要があります。`n`。 

微妙な点は、日付の数字は先頭のゼロも含めて**順序**で表示される必要があることです。 たとえば、次のような場合`1 0 3 2 0 2 5`、最初のものは使用できません`1`日付の直後に続くため、`0 3`の代わりに`0 1`デートが始まると。 もう 1 つの注意が必要なシナリオは、数字の余分なコピーが早い段階で表示される場合です。`0 0 1 0 3 2 5 0 2 5`。 順序を付けずにすべての数字の存在をチェックするだけの不注意なアルゴリズムでは、日付が 2 番目以降であると誤って判断されてしまいます。`0`、ただし、正しい順序に従うには、次の手順に従う必要があります。`01032025`注文。 

## アプローチ

 強引なアプローチでは、これまでに描画された数字のすべての組み合わせを試し、それらが日付を形成できるかどうかを確認します。`01032025`。 以来`n`最大 20 まで指定できます。これには、最大で 20 までの検査が必要になります。`2^20`サブセット、これは 1 秒以内には実行不可能です。 すべてのサブシーケンスを明示的に生成することさえ過剰です。 

重要な洞察は、すべてのサブセットが必要ではなく、**順序で最も早い出現**のみが必要であるということです。 この問題は、日付へのポインターを照合しながらシーケンスを左から右にスキャンするものとして扱うことができます。 日付の現在のターゲットに等しい数字が見つかるたびに、ポインターを進めます。 ポインタが日付の終わりに到達すると、完全な日付を含む最小のプレフィックスが見つかりました。 これが機能するのは、スキップされた数字が順序に影響を与えないためです。 各日付桁の最初の出現のみが重要です。 以来`n`が小さい場合は、単純なリニア スキャンで十分です。

 ## アルゴリズムのチュートリアル

 1. ターゲット日付シーケンスを次のように定義します。`01032025`。 
2. ポインタを初期化する`j`に`0`。 このポインタは、現在照合しようとしている日付の桁を追跡します。 
3. ループインデックスを使用して、描画された数字を反復処理します。`i`から`0`に`n-1`。 
4. 現在描画されている数字が一致する場合`date[j]`、増分`j`。 これは、日付の次に必要な桁が正常に一致したことを意味します。 
5. 各増分後、次のことを確認します。`j`日付の長さに等しい (8)。 そうなった場合は返品してください`i+1`インデックス付けはゼロベースであるため、日付を形成するために必要な桁数として使用されます。 
6. ループが終了すると、`j`8 未満の場合、出力`0`、日付を形成できないことを示します。 

なぜ機能するのか: ポインタ`j`常に次の必要な数字を指します。`01032025`。 その数字を見るたびに、私たちは前進します。 これにより、数字が正しい順序で選択されることが保証されます。 スキップされた桁は問題ではありません。 初めて`j`8 に達するのは、日付を含む最も古いプレフィックスを順番に収集したときです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    digits = list(map(int, input().split()))
    date = [0,1,0,3,2,0,2,5]
    j = 0
    for i in range(n):
        if digits[i] == date[j]:
            j += 1
            if j == 8:
                print(i + 1)
                break
    else:
        print(0)
```このソリューションは複数のテスト ケースを読み取り、入力数値をリストに変換します。 ポインタ`j`ターゲット日付まで繰り返します。 の`else`で`for`ループは日付が完了していない場合を処理しますが、単純な実装では忘れがちです。 インクリメント`i+1`印刷時に、ゼロベースのインデックスではなく、描画された桁数が出力でカウントされるようにします。
