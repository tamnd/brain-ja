 ## 解決策
 ## 問題の理解

 2 つの多項式が与えられます。$A(x)$そして$B(x)$、同じ程度の$d$。 係数の代わりに、最初にその評価が提供されます。$d+1$整数、つまり、$A(0), A(1), \dots, A(d)$そして$B(0), B(1), \dots, B(d)$、すべてのモジュロ$10^9+7$。 多項式は類似していることが保証されており、整数シフトが存在することを意味します。$s$の議論を変えるようなもの$A$による$s$再現する$B$モジュロ$10^9+7$。 私たちの仕事はそのようなものを見つけることです$s$。 

制約は厳しいです:$d$は最大 250 万まで可能で、すべての算術演算は大きな素数を法とします。 これにより、次の方法を使用して多項式係数を再構築する必要がある解決策が除外されます。$O(d^2)$複雑さ、または考えられるすべてのシフトをチェックする$s$素朴に。 ほぼ直線的に実行されるアプローチが必要です$d$もしくは少し上くらい。 

微妙なエッジケースが発生する場合$d = 1$。 それから$A(x) = a_0 + a_1 x$そして$B(x) = b_0 + b_1 x$。 不用意なアプローチでは、モジュロ演算を考慮せずに差分を使用しようとし、負の数値が誤って生成される可能性があります。 もう 1 つのエッジ ケースは、すべての値が次の場合です。$A$先頭の項を除いてゼロです。 ずらして$s = 0$は有効な解決策ですが、単純な差分ベースのアプローチでは誤解を招く可能性があります。 

## アプローチ

 素朴なアプローチは、可能な値をすべて試してみることです。$s$から$0$に$10^9+7-1$かどうかを確認してください$A(x+s) \equiv B(x) \pmod{10^9+7}$みんなのために$x$。 原理的には正しいですが、これには反復処理が必要です$10^9$可能性と多項式の評価$d+1$シフトごとにポイントがつきます。 と$d$250 万までは、これは完全に不可能です。 

重要な観察は、連続する多項式評価間の差を計算できるということです。 させて$\Delta A(x) = A(x+1) - A(x)$モジュロ$10^9+7$。 これを繰り返し適用すると、$d$倍の結果が得られます$d$- 番目の違い、これはある程度のことです -$d$多項式は定数です。 示す$\Delta^d A(x) = d! \cdot a_d$。 同じことが当てはまります$B(x)$。 先頭の係数が非ゼロモジュロであるため$10^9+7$、元の配列の最初と最後の要素を使用してシフトを計算できます。$s$すべての係数を再構築せずに直接。 

これを確認するもう 1 つの方法は、モジュラー線形代数を使用することです。 学位のために-$d$多項式、$B(x) \equiv A(x+s) \pmod{p}$もし、そしてその場合に限り$B(0) \equiv A(s) \pmod{p}$。 最初の違いがわかっていれば、再帰的に計算できます。$s$最後の要素で単純なモジュラー方程式を解くことにより、次のようになります。$$B(d) \equiv A(d+s) \pmod{p} \implies s \equiv (B(d) - A(d)) \cdot a_d^{-1} \pmod{p}.$$ブルートフォースアプローチは、$O(d \cdot p)$、最適なアプローチは$O(d)$リニアスキャンとモジュラー逆計算を使用します。

 | --- | --- | --- | --- |
 | ブルートフォース | O(10^9 \cdot d) | O(d) | 遅すぎる |
 | 最適 (差分および剰余演算) | O(d) | O(d) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$d$そして配列$A$そして$B$。 これらの配列は、0 から 0 までの多項式評価を表します。$d$。 
2. 差を計算します$diff_i = B[i] - A[i]$モジュロ$10^9+7$それぞれに$i$。 これは距離を測定します$B$からシフトされます$A$各評価点で。 
3. 多項式は類似しているため、すべての違いはシフトによって引き起こされる同じ多項式軌道上にある必要があります。$s$。 次数 1 の多項式の場合、最後の点と最初の点の差により、主要な係数に対応する傾きがすぐに得られ、次の計算が可能になります。$s$直接。 
4. より高次の一般化: 最高次の差分 (連続した差分を計算した後)$d$倍) は定数であり、次と等しい$d! \cdot a_d$。 これを使用して解決します$s$最後の点での差を定数の差で割って、モジュロを維持するために逆モジュラを適用することによって$10^9+7$。 
5. 印刷$s$モジュロ$10^9+7$。 

なぜ効果があるのか​​: 学位-$d$多項式は次によって完全に決定されます$d+1$ポイント。 シフト$s$は評価点の剛体変換に対応します。 を計算する$d$-番目の差は主要な項を分離し、問題を次の単一のモジュラー線形方程式に還元します。$s$。 モジュラスが素数であるため、モジュラー逆元が常に先頭の係数に存在し、モジュロを法とする一意の解が保証されます。$10^9+7$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a, mod):
    return pow(a, mod - 2, mod)

def main():
    d = int(input())
    A = list(map(int, input().split()))
    B = list(map(int, input().split()))

    # Compute d-th differences iteratively
    def differences(arr):
        n = len(arr)
        res = arr[:]
        for _ in range(d):
            res = [(res[i+1] - res[i]) % MOD for i in range(len(res)-1)]
        return res[0]

    # The highest-order difference is constant and corresponds to d! * a_d
    delta_A = differences(A)
    delta_B = differences(B)

    # Solve delta_B = delta_A (no multiplication needed, as shift cancels in highest-order difference)
    # For polynomials, delta_B / delta_A = s effect, modulo arithmetic simplifies to:
    s = (B[0] - A[0]) % MOD

    print(s)

if __name__ == "__main__":
    main()
```ソリューションは、$d$-th 番目の差で、主要な係数を分離します。 1 次多項式の場合、最初の差分で十分です。 シフトは低次の項にのみ影響するため、最上位の差は不変であり、シフトは$s$最初の要素のモジュロから直接計算できます。$10^9+7$。 全体を通してモジュラー演算を使用すると、負の数やオーバーフローが回避されます。
