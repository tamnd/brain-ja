 ## 解決策
 ## 問題の理解

 一連の数字と、それを並べ替える非常に具体的な方法が与えられています。 1 回の操作で、任意の要素を選択し、それを配列の最前面または最後までプッシュします。 他のすべてはギャップを埋めるために移動しますが、触れられていない要素の相対的な順序は維持されます。 

目標は、できるだけ少ない操作を使用して配列を非減少シーケンスに変換することです。 各操作は 1 つの要素を正確に移動するため、コストはアクティブに再配置する要素の数になります。 

すべてを決定する重要な制約は、配列のサイズです。 まで$2 \cdot 10^5$すべてのテスト ケースで要素をテストする場合、操作をシミュレートしたり、サブセットを明示的に探索しようとするソリューションは合格しません。 平$O(n^2)$テストケースごとの推論はすでに遅すぎ、並べ替えの繰り返しシミュレーションを伴うものは完全に実行不可能です。 私たちは強制的に$O(n \log n)$またはテストケースごとの線形構造。 

局所的な修正の観点から考えると、微妙な障害モードが現れます。 たとえば、次のような配列では、$[0, 1, 0]$の場合、1 つの要素だけが「間違っている」ため、反転だけを修正して 1 つの手だけで十分であると仮定したくなります。 しかし、コストはローカルでの反転には関係しません。 それは、任意の前後の移動後にグローバルにソートされた構造を形成しながら、どれだけの要素をそのまま残せるかによって決まります。 

もう 1 つの落とし穴は、単一の連続したソート済みブロックを構築していると仮定していることです。 この直感は崩れます。操作によって要素を両端に引き出すことができるためです。つまり、最終的にソートされた配列が元の配列の連続セグメントに対応する必要がないことになります。 

## アプローチ

 最も直接的な考え方は、要素の可能なすべてのサブセットを変更しないように試みるという観点から考えることです。 どの要素を移動せずに配列に残すかを決定すると、他のすべての要素が個別に前または後ろに移動されます。 保持しないすべての要素は 1 つの操作にのみ寄与するため、これは原理的には正しいです。 

ただし、サブセットが所定の位置に残るかどうかを確認するには、変更されていない要素は順序が保持されるため、それらの要素が元の相対順序で非降順で表示できるかどうかを確認する必要があります。 これは、非減少サブシーケンスの定義にすぐに似ています。 

これをさらに進めると、問題は次のようになります。元の配列内ですでに有効な非減少シーケンスが形成されるように、そのままにしておくことができる要素の数を最大化します。 この構造の外側にあるすべての要素は、一度移動する必要があります。 

これはまさに最長非減少サブシーケンス (LNDS) です。 このサブシーケンス内の要素はまさに「そのままにしておく」ことができる要素であり、その他の要素はすべて、実現可能性に影響を与えることなく、ある順序で最後に移動されます。 

ブルート フォース ビューでは、すべてのサブセットを試して有効性をチェックしますが、その有効性は次のように増加します。$2^n$。 変更されていない要素に対する唯一の制約はサブシーケンスの順序であるという観察により、LNDS を見つける作業が軽減されます。LNDS は、二分探索を備えた貪欲な構造を使用して効率的に計算できます。

 | --- | --- | --- | --- |
 | ブルート フォース サブセット |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | LNDS (二分探索) |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 中心となるアイデアは、各長さの減少しないサブシーケンスの可能な最小の終了値を追跡することです。 

1. リストを管理する`dp`どこ`dp[k]`長さが減少しないサブシーケンスの可能な最小の最後の値です。`k + 1`これまで見られた。 この構造により、サブシーケンスを常に可能な限り「拡張可能」に保つことができます。 
2. 配列を左から右に繰り返し、一度に 1 つの値を処理します。 各値は、既存のサブシーケンスを拡張するか、悪い末尾を置き換えようとします。 
3. 各要素について`x`の最初の位置を見つけます。`dp`ここで、値は厳密に次より大きいです`x`。 この位置はどこにあるかを示します`x`非減少順序を維持しながら当てはめることができます。 
4. そのような位置が存在する場合は、次のように置き換えます。`x`。 それ以外の場合は追加します`x`最後まで`dp`。 これにより、次の不変条件が保存されます。`dp`すべてのサブシーケンスの長さに対して最適なままです。 
5. すべての要素を処理した後、`dp`最長の非減少サブシーケンスの長さです。 
6. テスト ケースの答えは、このサブシーケンスにない要素の数であり、次のように計算されます。`n - len(dp)`。 

これが機能する理由は、LNDS 内の要素がすでに正しい相対順序で表示されており、移動する必要がないためです。 他のすべての要素は、サブシーケンス構造を乱すことなく抽出して先頭または末尾に配置できるため、そのような要素ごとに 1 回の操作が必要になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        dp = []

        for x in a:
            lo, hi = 0, len(dp)
            while lo < hi:
                mid = (lo + hi) // 2
                if dp[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid
            if lo == len(dp):
                dp.append(x)
            else:
                dp[lo] = x

        print(n - len(dp))

if __name__ == "__main__":
    solve()
```この実装では、非減少サブシーケンスに対する古典的な忍耐ソート構造が維持されます。 二分探索では、次の最初の位置が見つかります。`x`サブシーケンスを拡張または改善できます。 使用する`<= x`サブシーケンスが厳密に増加するのではなく、非減少であることを保証します。これは、重複した値が与えられた場合の正確性を確保するための重要な詳細です。 

最後の減算では、削除された各要素が 1 つの操作に正確に対応するため、問題は「保存された構造の最大化」から「移動された要素の最小化」に変換されます。 

## 実用的な例

 ### 例 1

 入力:`[4, 7, 2, 2, 9]`| ステップ | 値 | dp 状態 |
 | --- | --- | --- |
 | 1 | 4 | [4] |
 | 2 | 7 | [4、7] |
 | 3 | 2 | [2、7] |
 | 4 | 2 | [2, 2] |
 | 5 | 9 | [2、2、9] |

 最終的な LNDS の長さは 3 なので、答えは次のようになります。$5 - 3 = 2$。 

これは、サブシーケンスの柔軟性を維持しながら、後で小さな値が現れたときに、以前の大きな値をどのように置き換えることができるかを示しています。 

### 例 2

 入力:`[3, 5, 8, 1, 7]`| ステップ | 値 | dp 状態 |
 | --- | --- | --- |
 | 1 | 3 | [3] |
 | 2 | 5 | [3、5] |
 | 3 | 8 | [3、5、8] |
 | 4 | 1 | [1、5、8] |
 | 5 | 7 | [1、5、7] |

 LNDSの長さは3なので、答えは次のようになります。$5 - 3 = 2$。 

これは、後の小さな値によってより適切なサブシーケンスを再開できることを示しており、そのため貪欲な置換が不可欠です。

 ## 特殊なケース

 単一要素の配列はすでに条件を満たしているため、操作は必要ありません。 LNDS の長さは 1 で、減算すると正しく 0 が返されます。 

すべての要素が等しい配列は、長さが減少しない完全なサブシーケンスを生成します。$n$。 再配置の必要な要素がないため、答えは 0 になり、二分探索によりすべての要素が同じ位置に正しく配置されます。`dp`。 

厳密に減少する配列では、すべての新しい要素が強制的に最初の位置を置き換えます。`dp`、長さを 1 に保ちます。これにより、次の答えが得られます。$n - 1$これは、正しい順序で変更されないままにできる要素は 1 つだけであるという事実と一致します。
