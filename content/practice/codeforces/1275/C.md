 ## 解決策
 ## 問題の理解

 C スタイルのマクロを使用して再帰的に定義された大規模な配列をシミュレートするように求められます。 マクロは非常に構造化された方法で展開されます。各マクロ レベルでは、単純なオフセットが追加されて、前のレベルによって生成された要素の数が 4 倍になります。 基本レベルでは、`A0(x)`単一の値を生成します`x`。 それから`A1(x)`4 つの値が生成されます。`x`、`x+1`、`x+3`、 そして`x+4`。 後続の各レベルは、オフセットを付けて前のレベルを 4 回繰り返します。`0`、`1`、`3`、 そして`4`。 このパターンは次まで続きます`A25(x)`。 

入力により、この配列内の多数の位置が得られます。これは非常に大きくなる可能性があり、最大約$10^{15}$、そしてそれらの位置の値を出力する必要があります。 サイズが大きいため、配列を直接構築することは不可能です。 代わりに、再帰構造を利用して各値を個別に計算する必要があります。 

制約が教えてくれる`n`最大 1000 まで可能です。つまり、おおよそ余裕があることを意味します$O(n \log N)$操作、どこで$N$は最大位置インデックスです。 位置は膨大になる可能性があるため、配列を構築したり、配列を線形に反復したりするソリューションは実行不可能です。 

エッジ ケースは、位置が配列の最初のいくつかの要素に含まれる場合に発生します。 たとえば、位置 0 ～ 3 は展開の最初のレベルから直接取得されますが、再帰オフセットを考慮しない単純な式ではこれらの計算を誤る可能性があります。 同様に、オフセットが正しく累算されない場合、非常に大きな位置により単純な算術演算でオーバーフローが発生する可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、要求されたインデックスに到達するまでマクロの展開を再帰的または反復的にシミュレートしようとします。 これは概念的には再帰的に機能します。`Ai(x)`、配列は 4 つのコピーです`A{i-1}`オフセットあり`0`、`1`、`3`、`4`。 ただし、各レベルでは要素の数が 4 倍になるため、`A25`配列には$4^{25} \approx 10^{15}$要素。 再帰の深さは 25 であり、各再帰にはレベルごとに 4 つの再帰呼び出しが含まれるため、完全な展開によって単一の値を計算することさえ不可能です。 最悪の場合の操作は次のとおりです。$4^{25}$これは天文学的な数字です。 

重要な洞察は、再帰的な構造を観察することで得られます。 それぞれのレベルで、`Ai(x)`サイズは 4 ブロックです`size(A{i-1})`オフセットあり`0`、`1`、`3`、`4`。 位置の値を見つけるには`pos`、完全な配列は必要ありません。 位置がどのブロックに該当するかを再帰的に決定し、調整することができます。`x`対応するオフセット分だけ移動し、再帰分岐を 1 つ下に進みます。 到着したら`A0(x)`、値はちょうどです`x`。 

この観察により、問題は配列サイズに対する対数ステップ数による再帰降下に帰着します。 各ステップには、ブロック サイズを計算し、小さなオフセットで基本値を調整するだけが含まれます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^25)​​ | O(4^25)​​ | 遅すぎる |
 | 再帰降下 | O(n * 25) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各レベルでの配列のサイズを計算します。 各レベルは前のレベルの 4 倍になるため、`size[i] = 4 * size[i-1]`そして`size[0] = 1`。 
2. 要求されたポジションごとに`pos`、一番上のマクロから開始します`A25(0)`4 つのサブブロックのどれを再帰的に決定します`pos`に属しています。 ブロックのオフセットは次のとおりです。`0`、`1`、`3`、`4`。 
3. ブロックの開始インデックスを減算してサブブロックに対する相対的な位置を取得し、ブロックのオフセットをベースに追加します。`x`。 
4. 到達するまでステップ 2 ～ 3 を繰り返します。`A0(x)`。 この時点での値は単純に`x`。 
5. 各クエリの値を出力します。 

不変条件は、各再帰ステップで、アルゴリズムが現在のマクロ展開のどの 4 分の 1 が含まれているかを正確に識別することです。`pos`。 ブロック サイズとオフセットは決定的であるため、完全な配列を構築しなくても、再帰によって常に正確な値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Precompute the size of arrays at each level
sizes = [1]  # size of A0
for _ in range(25):
    sizes.append(4 * sizes[-1])

# Offsets used at each macro level
offsets = [0, 1, 3, 4]

def find_value(pos, level, base):
    if level == 0:
        return base
    block_size = sizes[level - 1]
    for i in range(4):
        if pos < (i + 1) * block_size:
            return find_value(pos - i * block_size, level - 1, base + offsets[i])
    # Should never reach here if logic is correct
    raise RuntimeError("Position out of range")

n = int(input())
positions = [int(input()) for _ in range(n)]

for pos in positions:
    print(find_value(pos, 25, 0))
```このソリューションでは、まずサイズを事前計算して、サブブロックの境界を迅速に決定します。 各クエリは再帰的に下降し、各レベルで問題のサイズが 4 分の 1 に減少します。 再帰の前にブロックに対応するオフセットを適用するように注意してください。 使用する`sizes[level - 1]`再帰で位置をオーバーシュートしないようにします。

## 特殊なケース

 最小の位置では、`0`、アルゴリズムはすぐに戻ります`0`届くから`A0`再帰なしで。 最大のポジションについては、`4^25 - 1`、再帰的降下は各レベルの最後のサブブロックを選択し、パスに沿ったオフセットを正しく合計します。 繰り返される位置は独立して処理され、クエリ間で状態が誤って共有されていないことが確認されます。 最後に、最初の 4 つの位置によって、初期オフセットが`[0,1,3,4]`最上位レベルで正しく適用されます。
