 ## 解決策
 ## 問題の理解

 2 つの塩基を選択するように求められます。1 つは次の場合です。$x$そして1つは$y$, そのため、両方の数値がそれぞれの基数で書かれている場合、結果として得られる数字シーケンスは、最下位桁から最上位桁まで読んだときに同一になります。 

具体的には拠点としては$a$、分割を繰り返します$x$による$a$そして残りを記録して、一連の数字を生成します。 同じプロセスが行われます$y$基地内で$b$。 要件は、これら 2 つのシーケンスが、長さとすべての桁の位置を含めて正確に一致することです。 

これは、単に異なる基数で同じ数値を持つよりも強力です。 位置拡張の構造全体が整列している必要があります。つまり、両方の数値が、潜在的に異なる基数で同じ「桁パターン」に分解されなければなりません。 

制約により、次の値まで許容されます。$10^9$したがって、各基本表現は最悪の場合でも最大約 30 桁になります。 すべての数字シーケンスは両方の数値の標準的な基数表現に対応するため、これは有効なシーケンスの長さを即座に制限します。 

表現の長さが 1 の場合、微妙なエッジ ケースが発生します。 その場合の順序は次の通りです$[x]$基地内で$a > x$、同様に$[y]$基地内で$b > y$。 これにより、$x = y$、そうでない場合は一致できません。 この特別な構造を無視する単純なアプローチでは、実際の表現が 1 桁に崩れる場合に、誤って複数桁の一致を構築しようとする可能性があります。 

別の故障モードは、同じベースを使用する必要があると仮定することで生じます。 この問題では独立した塩基が許可されるため、1 つの塩基を固定し、もう 1 つの塩基のみを検索する方法では、有効な非対称解が失われます。 

## アプローチ

 強引なアイデアは、塩基のすべてのペアを試すことです。$(a, b)$、両方の数字シーケンスを計算し、比較します。 これは問題の定義に直接従うため、正しいです。 ただし、検索スペースは膨大です。$a$そして$b$まで行く$10^9$1 回のフルスキャンさえ実行不可能になります。 

重要な観察は、実際には塩基を直接比較する必要がないということです。 代わりに、固定基数の場合、数値によって一意の数字シーケンスが決まります。 2 つの有効なソリューションが存在する場合、それらはこのシーケンスを共有する必要がありますが、そのシーケンスは短い (最大でも約 30 要素)。 

これにより、問題が構造形式に移行します。つまり、有効な基数表現として同時に機能できる数字シーケンスを探しています。$x$どこかの基地で$a$、そしての$y$どこかの基地で$b$。 候補シーケンスが一方から固定されると、もう一方の側と比較して検証することは、基底の多項式を解くことになります。これは、非負の数字の評価が単調であるため、二分探索で効率的にチェックできます。 

すべての塩基を列挙する代わりに、有効な数字シーケンスが次の塩基表現によって誘導されるという事実を利用します。$x$そして$y$。 それぞれの実現可能なベースに対して、$x$、その数字シーケンスを生成し、それと照合しようとします。$y$互換性のあるベースを見つけることによって。 

これを実用化するために、自明ではない数字シーケンスが出現する範囲に制限します。 約より大きい塩基の場合$\sqrt{x}$、表現は非常に短くなり、そのようなケースは全体で少数しか存在しません。 これにより、すべてのテスト ケースにわたって列挙が扱いやすくなります。

 ## アルゴリズムのチュートリアル

 私たちは、すべての意味のある数字シーケンスを構築することに焦点を当てます。$x$候補塩基を試し、同じ配列が表現できるかどうかを検証することによって$y$どこかの基地で。 

### ステップ

 1. もし$x = y$、1 桁の表現の場合を考えてみましょう。 任意のベースを選択できます$a > x$そして$b > y$制限内にある限り。 そのような拠点が存在する場合$A$そして$B$、すぐに返品させていただきます。 これは縮退シーケンスを処理します$[x]$。 
2. すべての候補拠点について$a$2 から始まり、実際のカットオフまで$\sqrt{x}$、次の数字列を計算します。$x$基地内で$a$。 このシーケンスは、モジュロ演算と除算演算を繰り返して取得され、最下位桁から最上位桁までの数字が生成されます。 
3. 生成された各数字シーケンスについて$d$、それをベースとして解釈します-$b$未知の数の表現:$$f(b) = \sum_{i=0}^{k-1} d_i b^i$$基地が存在するかどうかを判断する必要があります$b$そのような$f(b) = y$、 と$2 \le b \le B$。 
4. すべての桁が非負であり、最上位桁が非ゼロであるため、$f(b)$に対して厳密に増加しています$b \ge 1$。 二分探索ができます$b$方程式が成り立つかどうかを確認します。 
5. 有効な情報が見つかった場合$b$、私たちはそれを確認します$b \le B$そして$a \le A$。 両方の制約が満たされる場合、ペアを出力します。 
6. 候補基地がない場合$x$一致が得られた場合は、同じプロセスを対称的に繰り返します。$y$。 

### なぜ効果があるのか

 すべての有効な解は、同時に両方の数値の有効な位置拡張である数字シーケンスに対応します。 このようなシーケンスは、いずれかの少なくとも 1 つの有効な基数表現の桁分解として現れる必要があります。$x$または$y$。 一方の側からすべての塩基誘導表現を列挙することにより、一致する可能性のあるすべての候補配列を列挙します。 各シーケンスについて、単調多項式形式により、他の数値と互換性のある塩基の存在をチェックすることは、単一の増加関数方程式を解くことと同等であることが保証されるため、二分探索では有効な一致を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def digits(n, base):
    d = []
    while n > 0:
        d.append(n % base)
        n //= base
    return d

def eval_poly(d, b):
    res = 0
    p = 1
    for x in d:
        res += x * p
        p *= b
    return res

def find_base(d, target, lim):
    lo, hi = 2, lim
    while lo <= hi:
        mid = (lo + hi) // 2
        val = eval_poly(d, mid)
        if val == target:
            return mid
        if val < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

def solve_case(x, y, A, B):
    if x == y:
        if x < A and y < B:
            return (x + 1, y + 1)
        return None

    def try_x():
        limit = int(x ** 0.5) + 2
        for a in range(2, min(A, limit) + 1):
            d = digits(x, a)
            if len(d) == 1:
                continue
            b = find_base(d, y, B)
            if b != -1:
                return a, b
        return None

    def try_y():
        limit = int(y ** 0.5) + 2
        for b in range(2, min(B, limit) + 1):
            d = digits(y, b)
            if len(d) == 1:
                continue
            a = find_base(d, x, A)
            if a != -1:
                return a, b
        return None

    ans = try_x()
    if ans:
        return ans
    return try_y()

t = int(input())
for _ in range(t):
    x, y, A, B = map(int, input().split())
    ans = solve_case(x, y, A, B)
    if not ans:
        print("NO")
    else:
        print("YES")
        print(ans[0], ans[1])
```コードは最初に、両方の数値が 1 桁のシーケンスとして表現できる縮退等価のケースを処理します。 その後、複数桁の表現が存在する縮小範囲のみで候補塩基を列挙します。 塩基ごとに数字列を構築し、単調多項式評価に対する二分探索を使用して、他の数値に一致する塩基を回復しようとします。 

よくある実装上の落とし穴は、二分探索のすべての中間点に対して多項式の評価を再計算する必要があることを忘れていることです。 べき乗の再利用や誤った事前計算は、特に中間値が超過する可能性があるため、オーバーフローや誤った比較につながる可能性があります。$10^9$たとえ最終的な答えが範囲内にあったとしても。

    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        x, y, A, B = map(int, input().split())

        def digits(n, base):
            d = []
            while n:
                d.append(n % base)
                n //= base
            return d

        def eval_poly(d, b):
            res = 0
            p = 1
            for x in d:
                res += x * p
                p *= b
            return res

        def find_base(d, target, lim):
            lo, hi = 2, lim
            while lo <= hi:
                mid = (lo + hi) // 2
                val = eval_poly(d, mid)
                if val == target:
                    return mid
                if val < target:
                    lo = mid + 1
                else:
                    hi = mid - 1
            return -1

        def solve(x, y, A, B):
            if x == y and x < A and y < B:
                return x + 1, y + 1
            limit = int(x ** 0.5) + 2
            for a in range(2, min(A, limit) + 1):
                d = digits(x, a)
                if len(d) > 1:
                    b = find_base(d, y, B)
                    if b != -1:
                        return a, b
            limit = int(y ** 0.5) + 2
            for b in range(2, min(B, limit) + 1):
                d = digits(y, b)
                if len(d) > 1:
                    a = find_base(d, x, A)
                    if a != -1:
                        return a, b
            return None

        ans = solve(x, y, A, B)
        output.append("NO" if not ans else f"YES\n{ans[0]} {ans[1]}")
    return "\n".join(output)

 いつ$x = y$の場合、アルゴリズムはすぐに 1 桁の表現を考慮します。 のような入力の場合$x = y = 5$、選択する$a = 6$そして$b = 7$数字シーケンスを生成します$[5]$そして$[5]$、一致します。 このアルゴリズムは、折りたたまれた表現のケースを明示的に処理するため、ベース検索を行わずにこれをキャプチャします。
