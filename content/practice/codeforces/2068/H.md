 ## 解決策
 ## 問題の理解

 配置を求められます`n`から始まる 2D 整数グリッド上の彫像`(0, 0)`そして終わる`(a, b)`、連続する彫像間のマンハッタン距離が指定されたシーケンスと正確に一致するようにする`d_1, ..., d_{n-1}`。 点間のマンハッタン距離`(x1, y1)`そして`(x2, y2)`は`|x1 - x2| + |y1 - y2|`。 

重要な課題は、距離は固定されていますが、同じ座標に複数の彫像を配置する可能性を含め、パスを自由に選択できることです。 パスが存在するかどうかを判断し、存在する場合はパスを構築する必要があります。 

制約は小さい`n`(最大50)、ただし`a`、`b`、 そして`d_i`と同じ大きさにすることができます`10^9`。 これにより、グリッド全体で動きをシミュレートしたり、すべての座標を反復しようとしたりするアルゴリズムが排除されます。 この問題では、考えられる場所を代数的または幾何学的に推論する解決策が必要です。 

シーケンス内の距離が 0 の場合、明らかではないエッジ ケースが発生します。不注意な解決策では、すべての移動で位置が変更されると想定される可能性がありますが、距離ゼロの移動は許可されます。つまり、2 つの連続する彫像が同じポイントを占有することができます。 マンハッタンからの距離が離れている場合、別の厄介なケースが発生します。`(0,0)`に`(a,b)`距離の合計が一致しません`d_i`パリティまたはマグニチュードが異なります。この場合、パスは存在しません。 

たとえば、次の場合`n=3`、`(a, b) = (5, 8)`、 そして`d = [9, 0]`、最初の動きは次のとおりです。`(0,0)`→`(x1,y1)`と`|x1| + |y1| = 9`、しかしその後に到達するために`(5,8)`と`d_2=0`必要`(x2,y2) = (x1,y1)`、同時に等しいことはできません`(5,8)`。 したがって、出力は次のようになります`NO`。 

## アプローチ

 ブルートフォースアプローチは、必要なマンハッタン距離に合計される軸に沿った移動の可能なシーケンスをすべて試行することです。 距離ごとに`d_i`、 がある`d_i + 1`可能`(dx, dy)`そのようなペア`dx + dy = d_i`。 シーケンスの数は次のように指数関数的に増加します。`n`そして`d_i`、実行可能な操作を急速に超えています。 たとえ`n=10`中程度の距離であれば、組み合わせの数は天文学的になります。 

重要な観察は、マンハッタンの距離が軸に沿って独立して分解されるということです。 させたら`dx_i`x 軸に沿った変化であり、`dy_i`i 番目のステップの y 軸に沿って、`dx_i + dy_i = d_i`そしてすべての合計`dx_i`等しい必要があります`a`そしてすべての合計`dy_i`等しい必要があります`b`。 それぞれ`dx_i`そして`dy_i`満たさなければなりません`0 ≤ dx_i ≤ d_i`そして`0 ≤ dy_i ≤ d_i`。 これは、単純なリソース割り当て問題と同等です。`a`x に沿って分配する単位`n-1`ステップ、各ステップの間で実行できる`0`そして`d_i`。 y についても同様です。 

この観察により、問題は貪欲なアプローチまたは建設的なアプローチに帰着します。 ステップを順番に処理し、超過することなく可能な限り x に割り当てることができます。`a`またはステップ制限、残りは y に任せます。 次に、y に沿った残りの距離が次と等しいかどうかを確認します。`b`。 どこかの時点で割り当てが制限を超えると、解決策は不可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(Π(d_i)) | O(n) | 遅すぎる |
 | 貪欲な軸の割り当て | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 合計距離を計算する`S = sum(d_i)`。 もし`S < a + b`または`S - (a + b)`奇数です、出力`NO`。 これは、マンハッタンパスの合計が正確に到達する必要があるためです。`(a,b)`軸に沿ったステップのパリティは一致する必要があります`(a+b)`。 
2.初期化`remaining_x = a`そして`remaining_y = b`。 
3. 各ステップごとに`i`1 から n-1 まで、代入`dx_i = min(d_i, remaining_x)`X軸に。 次に割り当てます`dy_i = d_i - dx_i`y 軸に。 もし`dy_i > remaining_y`、 減らす`dx_i`による`dy_i - remaining_y`満足させる`dy_i ≤ remaining_y`。 アップデート`remaining_x -= dx_i`そして`remaining_y -= dy_i`。 
4. すべてのステップを処理した後、次の場合は`remaining_x != 0`または`remaining_y != 0`、出力`NO`。 
5. それ以外の場合は、次から始まる座標を再構築します。`(0,0)`。 次の各座標は`(x_i + dx_i, y_i + dy_i)`。 複数の有効な解が存在する可能性があるため、任意の整数グリッド パスに一致する方向 (正/負) を任意に割り当てます。 

機能する理由: 構造上、各ステップはマンハッタン距離の制約を尊重し、各軸に沿って必要な移動の合計を超えません。 貪欲な割り当てでは、y 制約に違反することなく x が可能な限り満たされることが保証され、それが存在する場合には実現可能性が保証されます。 パリティとサムのチェックにより、不可能性が早期に検出されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a, b = map(int, input().split())
d = list(map(int, input().split()))

S = sum(d)
if S < a + b or (S - (a + b)) % 2 != 0:
    print("NO")
    sys.exit(0)

remaining_x, remaining_y = a, b
dx_list = []
dy_list = []

for dist in d:
    dx = min(dist, remaining_x)
    dy = dist - dx
    if dy > remaining_y:
        excess = dy - remaining_y
        dx -= excess
        dy -= excess
    dx_list.append(dx)
    dy_list.append(dy)
    remaining_x -= dx
    remaining_y -= dy

if remaining_x != 0 or remaining_y != 0:
    print("NO")
    sys.exit(0)

print("YES")
x, y = 0, 0
print(x, y)
for dx, dy in zip(dx_list, dy_list):
    x += dx
    y += dy
    print(x, y)
```コードは最初に、合計とパリティの制約を使用して実現可能性をチェックします。 次に、x と y に沿った動きを貪欲に割り当て、軸のオーバーシュートがないようにします。 最後に、座標を順番に構築します。 各ステップ内の調整を保証`dx_i`そして`dy_i`負でないままであり、ステップ距離を満たします。
