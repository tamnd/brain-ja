 ## 問題の理解

 細胞のすべてのセルで何が起こっているかについての完全な説明が与えられます。$n \times n$グリッドですが、圧縮された形式のみです。 開始セルごとに、グリッドに書かれた移動指示に繰り返し従った最終的な結果が告げられます。 

未知のグリッドの各セルには、5 つのシンボルのうちの 1 つが含まれます。 そのうちの 4 つは、隣接するセルへの決定論的な遷移のように動作し、そのうちの 1 つは、$X$、プロセスが直ちに停止する終了状態のように動作します。 任意のセルから開始して、これらの遷移を繰り返し適用すると、最終的には、$X$セルを終了してそこで停止するか、サイクルに入って永遠に移動します。 

この問題では、グリッドを提供する代わりに、すべてのセルに対するこの動的システムの結果が提供されます。 セルは最終的に特定の終端セルに到達します。$(x, y)$、または無限の動きにつながるものとしてマークされ、次のように書かれます。$(-1, -1)$。 私たちの仕事は、まさにこれらの結果を生み出すグリッドを再構築するか、そのようなグリッドが存在しないことを証明することです。 

制約により許可されるのは、$n$まで$10^3$、最大 100 万個のセルがあることを意味します。 どのソリューションも、セル数が線形またはほぼ線形である必要があります。 繰り返しシミュレーションで二次関数以上のものは実行不可能です。 

重要な微妙な点は、出力がグリッドを直接記述するのではなく、セル上に誘導された関数グラフを記述することです。 すべての割り当てがグローバルな到達可能性に影響を与えるため、セルごとに独立して方向を割り当てようとする単純な試みでは、一貫性が損なわれることがよくあります。 

重要なエッジ ケースの 1 つは、すべてのセルがラベル付けされている場合です。$(-1, -1)$。 これにより、すべてのセルが到達可能なターミナルのないサイクルの一部となることになります。つまり、$X$全然。 不注意な解決策を講じると、依然として問題が発生する可能性があります$X$しかし、それはそれらのセルを停止しなければならないという要件と直ちに矛盾します。 

もう 1 つのエッジ ケースは、単一セル グリッドです。 それ自体で終了するようにラベル付けされている場合は、次のようにする必要があります。$X$。 無限としてラベル付けされている場合は、サイクルを介してそれ自体を指す必要がありますが、方向制約を使用して明示的にサイクルを構築しない限り自己ループは許可されないため、これは不可能です。 

## アプローチ

 強引なアイデアは、各セルを 5 つの可能な状態を持つ変数として扱い、シミュレーションされた結果が指定されたターゲットと一致するように方向を割り当てようとすることです。 完全なグリッド割り当てごとに、すべてのグリッド割り当てをシミュレートします。$n^2$DFS または BFS を使用して開始位置を計算し、エンドポイントを計算し、必要な出力と比較します。 セルごとにいくつかの可能性だけを試したとしても、状態空間は指数関数的であるため、検証だけでは困難になります。$O(n^2)$、これは大規模では完全に不可能になります。 

視点を逆にすると、問題の構造がよりよく理解できます。 順方向のパスを構築する代わりに、逆方向の到達可能性の観点から考えます。最終的に端末に到達するすべてのセルは、その端末セルに向かうツリーに属している必要があります。 とラベル付けされたセル$(-1,-1)$サイクル内に存在する必要があり、どのターミナルにも到達できません。 

これは 2 つの部分に分解されることを示唆しています。 まず、最終的に何らかの端末で終了する必要があるすべてのセルを特定します。 これらのセルは、対応する末端セルをルートとする有向ツリーを形成します。 第 2 に、残りのすべてのセルは、すべての端末を完全に回避する少なくとも 1 つの有向サイクルを形成する必要があります。 

重要な洞察は、ターゲット エンドポイントから貪欲にグラフを構築できるということです。 有限のターゲットを持つ各セルに対して$(x, y)$、そのルートへの方向のあるパスがあることを確認します。 これは、各ターゲット セルを BFS ソースとして扱い、方向を逆方向に伝播し、ターゲットに近い隣接セルを指す方向を各セルに割り当てることで実現できます。 細胞$(-1,-1)$代わりに、単純な一貫したパターン (行優先の折り返しなど) でそれらを配線することによって構築できるグローバル サイクル構造に強制的に組み込む必要があります。 

問題を、所定の引力領域を備えた関数グラフの構築として再解釈すると、その構築は局所的かつ線形になります。

 ## アルゴリズムのチュートリアル

 ターゲットが有限かどうかに基づいて、セルを 2 つのカテゴリに分割します。$(-1,-1)$。 

1. まず、すべてのセルをターゲットの宛先ごとにグループ化します。$(x, y)$。 各グループは、最終的に同じ端末で終了する必要があるすべてのセルに対応します。 
2. 有限のターゲットを持つグループごとに、ターゲット セルから開始してグリッド全体に外側に拡張する BFS を実行します。 この BFS 中に、訪問先セルのそれぞれに、ターゲットに一歩近づいた隣接セルを指す方向を割り当てます。 これにより、矢印をたどることでルートまでの距離が厳密に減少することが保証されます。 
3. BFS 中に方向を割り当てる場合、同じグループ内での移動のみを許可します。これは、割り当てられた遷移が同じ目的地を共有するセル内のパスを確実に維持することを意味します。 これにより、異なる盆地間での偶発的な結合が防止されます。 
4. ラベル付けされたすべてのセルについて$(-1,-1)$、それらを個別に収集し、それらをカバーする有向サイクルの形成を試みます。 このような各セルを固定の順序 (たとえば、行優先の順序) で次のセルに接続し、最後のセルが最初のセルに接続し直します。 
5. この順序での隣接関係に従って、これらのサイクル セルに方向を割り当てます。 隣接が不可能な場合は、グリッド内での有効な移動を保証する単純な 2 方向のスネーク構造を使用して配線を試みます。 
6. 最後に、BFS 親構造およびサイクル構造との割り当ての一貫性をチェックすることによって、すべてのセルに方向が割り当てられていること、および制約に違反していないことを検証します。 

### なぜ効果があるのか

 有限の各ターゲット グループは、その目的地にルートを持つフォレストを形成します。 BFS 構造は、フォレスト内のすべてのエッジがルートまでの距離を厳密に短縮することを保証し、これによりサイクルが排除され、正しいセルでの最終的な終了が保証されます。 

マークされたセル$(-1,-1)$すべての末端盆地から意図的に分離されているため、誤って到達することはできません。$X$。 それらをスタンドアロン サイクルに強制することで、無限のトラバースが保証されます。 すべてのセルには出力エッジが 1 つだけあり、各コンポーネントはルート付きツリーまたはサイクルのいずれかであるため、グローバル関数グラフは必要な動作に正確に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n = int(input())
target = [[None]*n for _ in range(n)]

groups = {}
for i in range(n):
    row = list(map(int, input().split()))
    for j in range(n):
        x, y = row[2*j], row[2*j+1]
        if x == -1:
            target[i][j] = None
        else:
            x -= 1
            y -= 1
            target[i][j] = (x, y)
            groups.setdefault((x, y), []).append((i, j))

res = [['']*n for _ in range(n)]

dirs = [(-1,0,'D'), (1,0,'U'), (0,-1,'R'), (0,1,'L')]

def bfs(root):
    rx, ry = root
    dist = [[-1]*n for _ in range(n)]
    dist[rx][ry] = 0
    q = deque([(rx, ry)])

    while q:
        x, y = q.popleft()
        for dx, dy, _ in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if target[nx][ny] == (rx, ry) and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))

    for x, y in groups.get((rx, ry), []):
        for dx, dy, ch in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if dist[nx][ny] == dist[x][y] - 1:
                    res[x][y] = ch
                    break

for root in groups:
    bfs(root)

cycle = [(i, j) for i in range(n) for j in range(n) if target[i][j] is None]

if cycle:
    for k in range(len(cycle)):
        x, y = cycle[k]
        nx, ny = cycle[(k+1) % len(cycle)]
        if x == nx and y + 1 == ny:
            res[x][y] = 'R'
        elif x == nx and y - 1 == ny:
            res[x][y] = 'L'
        elif y == ny and x + 1 == nx:
            res[x][y] = 'D'
        elif y == ny and x - 1 == nx:
            res[x][y] = 'U'
        else:
            print("INVALID")
            sys.exit()

for i in range(n):
    for j in range(n):
        if res[i][j] == '':
            res[i][j] = 'X'

print("VALID")
for row in res:
    print(''.join(row))
```実装は、ターゲットを解析し、宛先ごとにセルをグループ化することから始まります。 各グループは、ターゲット セルをルートとする BFS を使用して独立して処理されます。 この BFS は、すべてのセルがその目的地に近い隣接セルを選択できる勾配フィールドを確立することを目的としており、これによりセルの方向が直接決定されます。 

すべての有限ターゲット グループを処理した後、残りの未割り当てのセルは、$(-1,-1)$。 これらは、行優先の順序で 1 つのサイクルに配置されます。 サイクルの構築は隣接性によって制約され、連続するペアが隣接していない場合、構築は失敗します。 

最後に、残りのすべてのセルが次のようにマークされます。$X$、これは有限盆地の停止条件として機能します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、グリッド全体が次のようにマークされている場合です。$(-1,-1)$。 この場合、アルゴリズムはグリッド上の完全なハミルトニアン サイクルが構築されることを保証する必要があります。 非隣接遷移は移動ルールに違反するため、サイクル内の隣接性を確保できなかった場合、解決策は直ちに無効になります。 

複数のセルがグリッド内で隣接する異なる有限ターゲットを共有する場合、別のエッジ ケースが発生します。 BFS 割り当てがグループごとに慎重に分離されていない場合、単純な伝播により 2 つの盆地が誤ってマージされ、セルが間違ったターミナルに到達する可能性があります。 グループ化ステップでは、方向を割り当てる前に各ターゲットの影響を分離することでこれを防ぎます。 

最後のエッジ ケースは、1 つのセルだけが有限で、他のすべてのセルが無限であるグリッドです。 サイクル構築では、有限セルの消費を回避する必要があります。 誤ってサイクルに含まれている場合、そのセルは終了しなくなるため、正当性条件が崩れます。
