 ## アルゴリズムのチュートリアル

 1. 整数を読み取る$n$、$m$、 そして$p$。 
2. 配列を読み取る$a$の係数を表す$f(x)$。 
3. 配列を読み取る$b$の係数を表す$g(x)$。 
4.スキャン$a$左から右へ。 最初のインデックスについては$i$そのような$a_i \% p \neq 0$、 店$i$として`idx_a`。 
5.スキャン$b$左から右へ。 最初のインデックスについては$j$そのような$b_j \% p \neq 0$、 店$j$として`idx_b`。 
6. 出力`idx_a + idx_b`インデックスとして$t$の係数の$h(x)$で割り切れない$p$。 

なぜ機能するのか: 不変条件は、それぞれが割り切れない 2 つの数値を乗算することです。$p$、で割り切れない数が生成されます。$p$。 それらのインデックスを加算すると、積多項式の対応するべき乗が得られます。 両方の多項式には以下と互いに素な係数が少なくとも 1 つ含まれているため、$p$(GCD は 1)、これは有効な答えが存在することを保証します。 他の係数を考慮する必要はありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m, p = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    idx_a = next(i for i in range(n) if a[i] % p != 0)
    idx_b = next(j for j in range(m) if b[j] % p != 0)
    return str(idx_a + idx_b)

# provided samples
assert run("3 2 2\n1 1 2\n2 1\n") == "1", "sample 1"
assert run("2 2 3\n1 2\n1 2\n") == "0", "sample 2"
