 ## 解決策
 ## 問題の理解

 数直線上に、それぞれ 1 または 2 の色が付けられたセグメントのセットが与えられます。セグメントのペアは、重なったり接触したり、色が異なる場合には不良とみなされます。 私たちの目標は、不良ペアを回避しながら、できるだけ多くのセグメントを選択することです。 言い換えれば、異なる色の 2 つのセグメントが交差しないセグメントのサブセットが必要です。 

セグメントは整数で定義されます$l_i$そして$r_i$まで及ぶ可能性があります$10^9$。 セグメント数$n$200,000 に達する可能性があるため、複雑なソリューションは除外されます$O(n^2)$なぜなら、その場合、2 秒の制限をはるかに超える約 400 億回の操作が必要になるからです。 もっと近いものが必要です$O(n \log n)$。 

単純なアプローチに引っかかる可能性のあるエッジ ケースには、ネストされているセグメントやエンドポイントで接触しているセグメントが含まれます。 たとえば、セグメント [1,3,1]、[3,5,2]、および [2,4,1] がある場合、不注意に選択すると 3 つすべてが含まれる可能性がありますが、最初と 2 番目は 3 で交差し、色が異なるため、不適切なペアになります。 もう 1 つの微妙なケースは、すべてのセグメントが同じ色の場合です。その場合、たとえ重なっている場合でも、すべてのセグメントを取得できます。 色を無視する単純な欲張りは、そのようなシナリオでは失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、セグメントの考えられるすべてのサブセットを考慮し、それぞれで不良ペアがないかチェックすることです。 サブセットごとに、セグメントのすべてのペアを比較する必要があるため、次のようになります。$O(2^n \cdot n^2)$時間。 これは明らかに不可能です$n=2 \cdot 10^5$。 

重要な洞察は、セグメントを色ごとに分離し、各色を独立して処理できることです。 1 つの色のセグメントを選択した場合、その色の中に不正なペアが存在するリスクはありません。 したがって、色ごとに、重ならないセグメントを選択するだけで済みます。 これにより、この問題は古典的な「重複しない間隔の最大数」の問題に帰着します。これは貪欲に解決できます。正しいエンドポイントで間隔を並べ替え、最後に選択した間隔の終了後に開始する最初の間隔を繰り返し選択します。 これを両方の色に対して個別に計算し、より多くのセグメントを許可する色を採用します。 

同じ色のセグメント間に不良ペアが存在しないという観察により、各色グループ内の交差を無視できるようになります。 この問題は 2 つの独立した間隔スケジュールの問題に帰着します。これは次のように解決できます。$O(n \log n)$仕分けのせいで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. セグメントを 2 つのリストに分割します。1 つは色 1 用、もう 1 つは色 2 用です。この手順により、各色で重複しない選択を個別に処理できるようになります。 
2. 各色のリストについて、セグメントを右のエンドポイントで並べ替えます。 正しいエンドポイントによる並べ替えは、最も早く終了するセグメントを貪欲に選択して、重複しないセグメントの数を最大化できるため、非常に重要です。 
3. 選択されたセグメントの数のカウンターと、最後に選択されたセグメントの右端点を追跡する変数を初期化します。最初は負の無限大に設定されます。 
4. ソートされたセグメントを繰り返し処理します。 各セグメントについて、その左端点が最後に選択したセグメントの右端点よりも厳密に大きい場合は、それを選択範囲に含めて、最後に選択した右端点を更新します。 それ以外の場合はスキップしてください。 これにより、選択した 2 つのセグメントが重複しないことが保証されます。 
5. 両方のカラー リストに対して手順 3 と 4 を繰り返し、2 つのカウントを取得します。`count_color1`そして`count_color2`。 
6. 最終的な答えは次の最大値です。`count_color1`そして`count_color2`単一色のすべてのセグメントを選択すると、不良ペアが存在しないことが保証されるためです。 

機能する理由: 一度に 1 つの色に焦点を当て、貪欲な間隔スケジュール アルゴリズムを使用することで、各色の重複しないセグメントの最大のサブセットが確保されます。 不良ペアは異なる色間でのみ発生するため、最大数が得られる色からすべてのセグメントを取得することが最適です。 最も早い終了間隔を貪欲に選択すると、最大値が保証されます。これは、後で開始される他の間隔は、選択された合計数と重複するか、減少するためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_non_overlapping(segments):
    segments.sort(key=lambda x: x[1])
    count = 0
    last_end = -1
    for l, r in segments:
        if l > last_end:
            count += 1
            last_end = r
    return count

def main():
    n = int(input())
    color1, color2 = [], []
    for _ in range(n):
        l, r, t = map(int, input().split())
        if t == 1:
            color1.append((l, r))
        else:
            color2.append((l, r))
    res = max(max_non_overlapping(color1), max_non_overlapping(color2))
    print(res)

if __name__ == "__main__":
    main()
```最初の機能`max_non_overlapping`指定されたセグメントのリストに対して貪欲な間隔スケジューリングを実装します。 適切なエンドポイントで並べ替えることで、次の互換性のあるセグメントを常に効率的に選択できるようになります。 main 関数は、セグメントを色ごとに分離し、各色の最大選択サイズを計算して、より大きい数を出力します。
