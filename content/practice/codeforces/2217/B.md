 ## 解決策
 ## 問題の理解

 長さのバイナリ配列が与えられます$n$および単一の特別なインデックス$p_1$（以来$k=1$）。 この特別なインデックスの要素には値があります$x$そして私たちの目標は、配列全体を次と等しくすることです。$x$。 これを行うには、特別なインデックスを含む連続したサブ配列に対して任意の数の反転操作を実行できます。 フリップは、選択した範囲内のすべてのビットを反転します。 

この問題は事実上、すべての要素がそのインデックスの値と一致するために必要な特別なインデックスを含む連続した部分配列の反転の最小数はいくらか、と尋ねます。 

なぜなら$n$まで可能です$2 \cdot 10^5$まであります$10^4$テストケース、複雑なソリューション$O(n^2)$テストケースごとに実行すると遅すぎます。 配列サイズに対する線形解が必要です。 

明らかではないエッジ ケースには、次のようなものがあります。すでにすべてが等しい配列$x$、またはいつ$x$は 0 で、すべての 1 が特別なインデックスの片側に連続して表示されます。 不注意で無差別に反転すると、不要な操作が実行される可能性があります。 

## アプローチ

 ブルートフォース手法では、特別なインデックスを含むすべての可能な範囲を考慮し、それらを反転し、再帰的に反転を最小限に抑えようとします。 これは正しいですが、実行不可能です。 単一の特別なインデックスの場合、ブルート フォースはそのインデックスを含むすべてのサブ配列を試行する可能性がありますが、大まかに$O(n^2)$そのような範囲。 それはすぐに制限時間を超えてしまいます。 

重要な観察は、要素の各連続セグメントが次の値に等しくないことです。$x$特別なインデックスの同じ側にあるインデックスは 1 回のフリップで固定できます。 このような複数のセグメントにまたがる反転は、既に正しい要素も反転してしまうため、役に立ちません。 したがって、フリップの最小数は、特別なインデックスの両側にある連続する「間違った」セグメントの数になります。 

これを効率的に実装するには、特別なインデックスの左右の配列をスキャンし、次の値に等しくない連続したセグメントをカウントします。$x$、これらのカウントを合計します。 これにより、最小限の操作が直接実行されます。$O(n)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 価値を特定する$x$特別なインデックスで。 
2. フリップ用のカウンターをゼロに初期化します。 
3. 特別なインデックスの左側にある配列を最も近いものから最も遠いものまでスキャンします。 要素の連続ブロックが異なる場合は常に、$x$、フリップカウンタを 1 つインクリメントし、ブロックをスキップします。 
4. 同じ手順を使用して、特別なインデックスの右側にある配列をスキャンします。 隣接する各ブロックは次のように異なります。$x$1回のフリップとしてカウントされます。 
5. フリップの合計数を返します。 

機能する理由: 各反転には特別なインデックスが含まれている必要があるため、反対側の要素を独立して反転することはできません。 両側で間違った値が連続するシーケンスは、シーケンスごとに 1 回だけフリップするだけで修正できるため、最小限の操作数が保証されます。 フリップを分割または結合しようとすると、間違ったビットがそのまま残されるか、冗長なフリップが実行されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        p = list(map(int, input().split()))
        x = a[p[0]-1]
        
        flips = 0
        # Left of special index
        i = p[0]-2
        while i >= 0:
            if a[i] != x:
                flips += 1
                while i >= 0 and a[i] != x:
                    i -= 1
            else:
                i -= 1
        # Right of special index
        i = p[0]
        while i < n:
            if a[i] != x:
                flips += 1
                while i < n and a[i] != x:
                    i += 1
            else:
                i += 1
        print(flips)

if __name__ == "__main__":
    solve()
```このソリューションは、まずテスト ケースの数を読み取り、それらを反復処理します。 テスト ケースごとに、配列と特別なインデックスを抽出し、0 から始まるインデックスを調整し、特別なインデックスから左右にスキャンして、間違った値の連続シーケンスをカウントします。 インナー`while`ループはセグメント全体をスキップして、各フリップが正確に 1 回カウントされるようにします。

 ## 特殊なケース

 単一要素の配列: 特別なインデックスが唯一の要素であり、すでにそれ自体と等しいです。 アルゴリズムは正しく 0 を返します。 

すべての要素が特別な値に等しい配列: 左右のスキャンは反転を増分することなく直ちに終了します。 

特別なインデックスの周りの交互シーケンス: 内部`while`ループにより、各連続セグメントが正確に 1 回カウントされるようになり、過剰カウントが防止されます。 

特別なインデックス自体を含むセグメント: 特別なインデックスから左右にスキャンするだけなので、二重カウントは発生しません。 

このアルゴリズムは、インデックス 0 と n-1 で停止することにより、境界を正しく処理します。 

これにより、簡単な構成と複雑な構成の両方が正しいことが確認されます。
