 ## 解決策
 ## 問題の理解

 正の整数の配列が与えられます。 2 人のプレイヤーがショーナクから順番に交互にターンします。 通常のターンは、値がまだ正であるポジションを選択し、それを 1 つ減らすことで構成されます。 すべてのエントリーがゼロになるとゲームは終了し、最後に有効な手を打った人が勝者となります。 

ショーナクには、通常の動きの代わりに最大 1 回使用できる追加のパワーが 1 つあります。 これを使用すると、配列全体が上書きされ、すべての位置が固定値に等しくなります。`k`。 

問題は、両方のプレーヤーが最適なプレーをしたと仮定して、ショーナクが勝利を勝ち取ることができるかどうかです。 

ゲームにおいて重要な唯一の実際の状態は、実行可能なユニット減少の合計数です。 配列の各要素`a[i]`まさに貢献する`a[i]`移動するため、特別な移動の前に、ゲームの長さは配列の合計で固定されます。 

必殺技は構造変化の唯一の源である。 現在の設定を破棄し、次のように置き換えます。`n`同じ大きさの山`k`。 From that point onward, the game length becomes`n * k`, しかし、ショーナクも自分のターンを費やしてそれをアクティブにします。 

制約は十分小さいため、テスト ソリューションごとに O(n) または O(n log n) で十分です。 テスト ケースは最大 500 個あり、各テスト ケースには最大 100 個の要素があるため、テストあたり O(n^2) であっても問題なく合格します。 これは、高度なデータ構造を必要とせずに、パリティと単純な遷移について直接推論できることを意味します。 

いくつかの微妙なケースが重要です。 

ショーナクが特別な動きをまったく使用しない場合、プレイヤーは厳密に 1 つの動きにつき 1 つのユニットを交互に取るため、結果は合計が奇数か偶数かによってのみ決まります。 

彼が特別な動きをすぐに、またはいくつかの動きの後に使用した場合、残りの動きのパリティは制御された方法で変化します。 

素朴な間違いは、特別な動きが常に役立つと考えることです。`k`大きい、または比較する`k`最大の要素で。 この操作は構造全体をリセットし、ローカルな意味での進行状況を保持しないため、これは誤りです。 パリティと総移動数のみが重要です。 

## アプローチ

 ブルート フォース ビューでは、ゲーム全体をシミュレートします。 各状態で、可能な限りのデクリメントを試し、ショーナクが特別な動きを使用するかどうかも検討します。 これにより、各ノードが最大で分岐するゲーム ツリーが生成されます。`n + 1`移動し、深さはすべての要素の合計と同じくらい大きくなります。 メモ化を行ったとしても、配列値によって状態が定義されるため、状態空間は膨大になり、要素ごとに最大 1000 個を占める可能性があります。 

重要な観察は、ターン構造を介する場合を除いて、個々のポジションが相互作用しないことです。 すべての移動により、「将来の移動」が 1 単位だけ削除されます。 したがって、ゲーム全体は、`S = sum(a[i])`トークンを削除し、プレイヤーは交互にトークンを 1 つ取り除きます。 特別な動きは、現在の杭構造を新しい固定サイズの総構造に置き換えます。`n * k`。 

したがって、ショーナクが持つ唯一の決定は、残りの合計手を次から切り替えるかどうかです。`S`の中へ`n * k`ある時点で、そうするために 1 つの移動を消費します。 両方のプレイヤーが最適にプレイするため、唯一関連する特性はショーナクが確実に最後の手を打つことができるかどうかであり、それは完全に作戦を最大限に活用した後の同等性に依存します。 

2 つのシナリオを比較します。 

ショーナクが特別な動きを使用しなかった場合、ショーナックは次の場合に勝ちます。`S % 2 == 1`。 

使用する場合は、最終的なパリティが有利になるように使用したいと考えます。 最良の瞬間は常に即時です。それを遅らせると無駄な動きが発生するだけで、パリティ構造が有利に変化することはありません。 使用後の残り手数の合計は、`n * k`、しかしすでに1手消費されています。 

したがって、有効残り長さは`n * k`、ショーナクが技を使用したため、ターンパリティが反転します。 したがって、この分岐ではショーナクが勝ちます。`(1 + n * k) % 2 == 1`彼の視点から見ると、単純化すると次のようになります。`n * k % 2 == 0`。 

したがって、ショーナクは次のいずれかの場合に勝つことができます。 

必殺技を使わずに勝つか、すぐに必殺技を使って勝つ。 

これにより、単純なパリティ条件が得られます。

 ## アルゴリズムのチュートリアル

 配列の合計とパリティの 2 つの量を計算します。`n * k`。 

1. コンピューティング`S = sum(a[i])`。 これは、特別な操作が使用されない場合のゲーム内の通常の手の数を表します。 この場合の勝者は次のとおりです。`S`奇数か偶数です。 
2. 次のことを確認します。`S`奇数です。 もしそうであれば、ショーナクは最初にスタートし、すべての動きがユニットを 1 つだけ削除するため、特別な動きを使用せずにすぐに勝つことができます。 
3. コンピューティング`P = (n * k)`。 特殊操作適用後の総手数です。 
4. 必殺技を使用した場合の効果をすぐに検討します。 ショーナクはそれをアクティブにするために 1 移動を費やすため、有効な残りのプレイは次のパリティによって支配されます。`P`ターン順序に関係します。 これは、次の場合にショーナクがこのブランチで勝つことを意味します。`P`は均等です。 
5. いずれかの条件がショーナックにとって有利な場合は「YES」を出力し、そうでない場合は「NO」を出力します。 

### なぜ効果があるのか

 ゲームは固定長の交互除去プロセスに縮小されます。 特別な操作を除いて構造を変更する動きはなく、その操作は残りの合計カウントをリセットするだけです。 各手は常に正確に 1 単位の進行を消費するため、ゲーム全体は残っている手数と最終手と一致するターンの数によって決まります。 特別な動きは合計カウントを変更するだけです`S`に`n * k`1 ターンのコストがかかるため、結果は配列内の値の分布ではなくパリティ比較のみに依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        s = sum(a)
        
        # option 1: no special move
        if s % 2 == 1:
            print("YES")
            continue
        
        # option 2: use special move immediately
        # after special move, total becomes n*k and parity flips due to move spent
        if (n * k) % 2 == 0:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```コードは最初に配列の合計を計算して、必殺技なしのシナリオを評価します。 その合計が奇数の場合、パリティ アドバンテージにより、ショーナクはすでに勝利の立場にあります。 

そうでない場合は、必殺技を使用した場合の効果をすぐに評価します。 この操作はゲームを均一なサイズの構造に変換するため、`n * k`、すでに費やされたターンを考慮した後、その数の同等性のみが重要になります。 決定は 2 つの勝利条件の間の単純な OR によって行われます。 

## 実用的な例

 次のような入力を考えてみましょう。`n = 3`、`k = 2`、配列は`[3, 3, 3]`。 

次のように計算します。 

| ステップ | 値 |
 | --- | --- |
 | 合計 S | 9 |
 | Sパリティ | 奇数 |
 | 決定 | 特別な動きなしで勝つ |

 以来`S`は奇数ですが、ショーナクは関係なくすぐに勝ちます`k`。 

ここで考えてみましょう`n = 2`、`k = 2`、 配列`[2, 2]`。 

| ステップ | 値 |
 | --- | --- |
 | 合計 S | 4 |
 | Sパリティ | 偶数 |
 | n * k | 4 |
 | (n*k) パリティ | 偶数 |

 ここでショーナクは待っていても勝つことはできませんが、特別な動きを使用すると合計 4 つの動きになり、それでも均等であるため、最後の動きはショーナクのターンシーケンスと一致します。 したがって、答えはYESです。 

これらの例は、総移動数のパリティのみが重要であり、配列内の値の分布が結果に影響を与えないことを示しています。

 ## 特殊なケース

 配列の要素が 1 つだけの場合、ゲームは 1 つの山に縮小されます。 その山が奇数の場合、ショーナクが最後のデクリメントを行うため、常に勝ちます。 互角の場合、特別な動きが結果を決定し、ロジックは次のとおりです。`n * k`は均等です。 

すべての要素が等しい場合、直観的には特別な動きが強力に見えても、合計ベースのロジックが結果を完全に決定します。 リセット操作ではパリティを超えた利点が保持されないため、大規模で均一な配列であっても特別な処理は必要ありません。 

いつ`k`が非常に大きいため、特別な動きが優勢であると考えてしまう誘惑にかられます。 ただし、重要なのはその等価性だけです。 大きさが最適なプレイに影響を与えることはありません。そのため、配列を合計した後も解は一定時間のままになります。
