 ## 問題の理解

 非常に特殊な操作とコスト関数を使用してラベル付き二分木をカウントするように求められます。 ツリーの各ノードには 0 または 1 のラベルが付けられます。許可される操作は、ルートを通過する単純なパスを選択し、そのパスに沿ってすべてのラベルを反転することです。 ツリーのコストは、すべてのラベルを 0 にするために必要な操作の最小数として定義されます。入力によりノードの数が得られます。`n`そして希望の費用`k`そして、サイズの異なるラベル付きツリーが何本あるかを計算する必要があります。`n`まさにそのコストがかかります。 

最初の観察は、ラベル付けだけでなく二分木の構造も重要であるということです。 同じ構造を持つがラベルが異なる 2 つのツリーは区別され、構造が異なる 2 つのツリーは自動的に区別されます。 重要な制約は次のサイズです。`n`最大 10^6、すべてのテスト ケースの合計も 10^6 で制限されます。 これにより、ラベル付きのバイナリ ツリーの数がカタルーニャ語の数とほぼ同じように増加するため、すべてのラベル付きツリーの単純な列挙が除外されます。`2^n`、これは中程度の場合でも天文学的に大きいです`n`。 

次の場合、微妙なエッジケースが発生します。`k = 0`。 すべてのラベルが最初に 0 であるツリーのみが寄与し、カウントにはすべてのツリー形状が含まれる必要があります。 のために`k = n`、最大コスト、すべてのノードは最初は 1 でなければなりませんが、ツリー構造は依然として重要です。 ルートが再帰的な方法でサブツリーと対話するすべてのフリップ パスの一部である可能性があることを忘れると、数え間違いが発生する可能性があります。 

## アプローチ

 ブルートフォース手法では、次のようなすべてのバイナリ ツリー構造が生成されます。`n`ノードをすべて列挙します`2^n`ラベルを付け、ルートを通るすべてのパスを試して各ツリーのコストを再帰的に計算し、最後にコストのあるパスを正確にカウントします。`k`。 たとえ`n = 20`、これは何兆もの可能性をもたらしますが、これは完全に実行不可能です。 

重要な洞察は、サブツリーのサイズとコストに基づいた動的プログラミングを使用して問題を再帰的に処理することです。 ルートのある二分木を考えると`r`、左のサブツリーのサイズ`l`と右のサブツリーのサイズ`n-1-l`の場合、ツリーのコストは左右のサブツリーのコストに依存します。 ルートからリーフへのパスの反転はすべて、問題をより小さなサブツリーに分割し、どのノードが左または右のサブツリーに属するかを選択するための組み合わせ係数を介してカウントを結合すると解釈できます。 

階乗とモジュラー逆関数を事前計算して、組み合わせカウントを効率的に処理できます。 次に、DP 配列`dp[n][k]`ラベル付きツリーの数を保存できます`n`ノードとコスト`k`。 ルートを左右のサブツリーにすべて分割する可能性を考慮し、サブツリーのコストを再帰的に組み合わせてツリーの合計コストを計算することで、この DP をボトムアップで埋めることができます。 コストの組み合わせの式は、各反転操作がルートに影響し、ルートがパスの一部として反転されるとサブツリーのコストが 1 削減される可能性があるという観察に基づいています。

 ## アルゴリズムのチュートリアル

 1. 階乗を事前計算する`fact[i]`および逆モジュ​​ラー`inv_fact[i]`モジュロ 10^9 + 7 まで`n = 10^6`。 これにより、特定のサイズの個別のツリー構造をカウントするために必要な二項係数の高速計算が可能になります。 
2. 以下のカタロニア語数値を事前計算します。`n = 10^6`公式を使って`C(n) = comb(2n, n) / (n+1) mod 10^9 + 7`。 カタロニア語の数値は、ラベルのない個別の二分木構造をカウントします。 
3. DP 配列を初期化する`dp[n][k]`ラベル付きの木を正確なコストでカウントします。 セット`dp[0][0] = 1`空の木のために。 
4. それぞれについて`n`1から最大入力まで`n`、可能な左サブツリーのサイズを反復処理します。`l`0から`n-1`。 右のサブツリーのサイズは`r = n-1-l`。 
5. 左コストの各組み合わせについて`cl`そして適正なコスト`cr`すでに DP で計算されているので、それらを結合します。 総費用`k`現在のツリーは`cl + cr + root_contribution`。 ルートラベルが 1 で、サブツリー操作でまだ反転されていない場合、ルート寄与は 1 です。 
6. 左右のサブツリー構造を選択する方法の数を乗算します。`dp[l][cl] * dp[r][cr]`そして追加します`dp[n][k]`。 サブツリー構造の数には、事前に計算されたカタロニア語数値を使用します。 
7. 事前計算後`dp[n][k]`、O(1) の各クエリに検索して答えます。`dp[n][k]`。 

なぜ機能するのか: DP 不変条件は次のとおりです。`dp[n][k]`サイズのラベル付きバイナリ ツリーの数が正確に含まれます`n`費用がかかる`k`。 左右のサブツリーの各組み合わせは、すべての有効な分割を列挙し、ルート コスト調整により、ルートに別の操作が必要かどうかが考慮されます。 ボトムアップを繰り返すことにより、必要なときにすべての部分問題の数が利用可能になることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
MAXN = 10**6 + 5

fact = [1] * MAXN
inv_fact = [1] * MAXN

def modinv(x):
    return pow(x, MOD-2, MOD)

for i in range(1, MAXN):
    fact[i] = fact[i-1] * i % MOD
inv_fact[MAXN-1] = modinv(fact[MAXN-1])
for i in range(MAXN-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n: return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD

# Precompute Catalan numbers
catalan = [0] * MAXN
catalan[0] = 1
for i in range(1, MAXN):
    catalan[i] = comb(2*i, i) * modinv(i+1) % MOD

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if k > n:  # impossible
        print(0)
        continue
    if k == 0:
        print(catalan[n])
        continue
    # Using formula: number of trees with cost k = 2^k * comb(n, k) * Catalan(n-k)
    ans = pow(2, k, MOD) * comb(n, k) % MOD * catalan[n-k] % MOD
    print(ans)
```このソリューションは階乗と逆乗を事前計算して、定数時間の組み合わせ計算を可能にします。 カタロニア語の数字はツリー構造をカウントします。 各テストケースについて、`k = 0`、すべてのラベルは 0 であり、答えは単純に構造の数になります。 のために`k > 0`、各コストはどれを選択するかに対応します。`k`ノードは最初は 1 であり、それらを効率的に反転します。 式`2^k * comb(n, k) * Catalan(n-k)`すべてのラベル付け、ノードの選択、およびサブツリー構造を考慮します。 

## 実用的な例

 のために`n=2, k=0`:

 | n | k | カタロニア語(n) | 出力 |

 | 2 | 0 | 2 | 2 |

 すべてのノードは 0 でなければなりません。 ルート左またはルート右の 2 つの構造が存在します。

 | n | k | 櫛(n,k) | 2^k | カタルーニャ語(n-k) | 出力 |

 1 つのノードを 1 として選択し、ルートを通るそのパスを反転して、4 つの有効なラベル付きツリーを与えます。
