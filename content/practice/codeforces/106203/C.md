 ## 解決策
 ## 問題の理解

 2D 整数グリッド上の隠れた点と対話しています。 まず最初にポイントがあります$(x_0, y_0)$それは私たちには分かりません。 システムが関数を定義する$f(x, y)$、ゾンビが移動するのに必要な最小時間を表します。$(x, y)$非常に珍しい移動ルールに基づいて原点に戻ります。ゾンビは軸に沿ったセグメントで移動し、各セグメントは整数の長さを持ちます。$d$、費用$d^2$時間単位であり、各セグメントの後に 90 度回転する必要があります。 

見る代わりに$f$ゾンビを移動したときにゾンビがどのように変化するかを直接クエリできます。 クエリ$(\Delta x, \Delta y)$ベクトルを現在の位置に追加し、値を受け取ります$$f(x + \Delta x, y + \Delta y) - f(x, y).$$応答後、システムはそれに応じて現在位置を更新します。 元の隠れた座標を決定する必要があります。 

主な問題は、クエリが適応性があることです。 クエリごとに状態が変化するため、後の応答は前の動きに依存します。 クエリは最大 100 に制限されており、座標は最大 100 個まで可能です。$10^9$絶対値で表現されるため、総当たり攻撃やスキャンは不可能です。 

微妙なエッジ ケースは、すべてのクエリで隠れたポイントが永久に移動することです。 たとえば、こう尋ねると、$(1,0)$、後続のすべての答えは相対的です$(x_0+1,y_0)$、元の位置ではありません。 クエリが独立していると仮定するアプローチでは、一貫性のない方程式が生成されます。 

もう 1 つの落とし穴は、直接回復できると仮定していることです$f(x,y)$。 私たちは決して絶対値を観察することはなく、変化する状態での差異のみを観察します。 このため、関数自体を再構築するのではなく、差分公式の代数構造を利用する必要があります。 

## アプローチ

 強引なアイデアは、関数を「調査」することです。$f$多くの方向を探索し、曲率を推測したり、局所的に値を再構築したりすることによって。 各クエリは移動点でのみ差を与えるため、これはすぐに矛盾します。各クエリの後、参照点が変化するため、システムは漂流する神託のように動作します。 偏導関数を近似しようとしても、同じ状態でサンプリングを繰り返す必要があり、これは不可能です。 

ターニングポイントは、ゾンビコスト関数が閉じた二次形式であることを認識することです。 間の最適なパス$(x,y)$また、固定変位を複数のセグメントに分割しても二乗和が増加するだけであるため、原点は最大 2 つの軸に整列したセグメントに減らすことができます。 これは次のことを意味します:$$f(x,y) = x^2 + y^2.$$これが分かれば、すべてのクエリは純粋に代数的になります。 拡張:$$f(x+\Delta x, y+\Delta y) - f(x,y)
= 2x\Delta x + \Delta x^2 + 2y\Delta y + \Delta y^2.$$これは次の線形式です。$x$そして$y$既知の定数を加えます。 各クエリは 1 つの座標を明確に分離するため、クエリごとに状態が変化しても、慎重に選択した 2 つのクエリで両方の変数を解決するのに十分です。

 ## アルゴリズムのチュートリアル

 各クエリが現在の座標における線形方程式を明らかにするという事実を利用します。 

1. まずクエリを実行します$(1, 0)$。 答えは$$(x+1)^2 + y^2 - (x^2 + y^2) = 2x + 1.$$これにより、元の状態をすぐに復元できるようになります$x$としてコーディネートする$(\text{res}_1 - 1)/2$。 
2. このクエリの後、システムは位置を次のように更新します。$(x+1, y)$。 私たちはこれを元に戻そうとはしません。 代わりに、それを自分たちの利益のために利用します。 
3. 次にクエリを実行します$(0, 1)$この新しい状態から。 答えは$$(x+1)^2 + (y+1)^2 - ((x+1)^2 + y^2) = 2y + 1.$$これにより、電流が絶縁されます$y$値、まだオリジナルのまま$y$, そこで計算します$y = (\text{res}_2 - 1)/2$。 
4. この時点で、オリジナルを再構築しました。$(x, y)$完全に完了し、直接出力できます。 両方の移動後のポイントの最終位置は使用しません。 中間成果物としてのみ使用します。 

重要な考え方は、各クエリの後に状態がドリフトするとしても、二次形式が独立した x 成分と y 成分にきれいに分離されるため、各座標を依然として分離できるということです。 

### なぜ効果があるのか

 機能$f(x,y)=x^2+y^2$は座標間で分離可能であり、各クエリは現在の状態では線形交差項のみを導入します。 常に単位軸ベクトルをクエリするため、各応答は 1 つの座標と既知の定数のみに依存します。 状態のシフトでは座標が混合されないため、各方程式は一度に 1 つの変数に対して有効なままになります。 これにより、2 つのクエリが元の点を一意に決定することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(dx, dy):
    print("?", dx, dy)
    sys.stdout.flush()
    return int(input().strip())

# Query 1: shift by (1,0)
r1 = ask(1, 0)
x = (r1 - 1) // 2

# Query 2: shift by (0,1)
r2 = ask(0, 1)
y = (r2 - 1) // 2

# After queries, current position is (x+1, y+1),
# but we must output original position.
print("!", x, y)
sys.stdout.flush()
```最初のクエリの抽出$x$直接二次展開から、$y$-規約はキャンセルされます。 2 番目のクエリは状態遷移後に評価されますが、次の構造は$f$同じキャンセルが確実に発生するようにします$y$。 

よくある実装上の間違いは、クエリによってポイントが永続的に移動されることを忘れることです。 ここでこれが無害なのは、各クエリが 1 つの座標を正確に分離するように設計されており、以前の状態に戻る必要がないためです。 

もう 1 つの微妙な点は、整数の除算です。どちらの結果も奇数であることが保証されています。$2x+1$そして$2y+1$常に表示されるため、引き算と割り算は正確になります。 

## 実用的な例

 初期点を考える$(3, -2)$。

 | --- | --- | --- | --- | --- |
 | 1 | (3,-2) | (1,0) | 7 | x = (7-1)/2 = 3 |

 この後の状態は、$(4,-2)$。 

| ステップ | 状態 | クエリ | 応答 | 推論 |

このトレースは、二次構造が軸と整列したままであるため、状態が変化した後でも各座標が分離されていることを示しています。

 ## 特殊なケース

 境界状況は、1 つの座標がゼロの場合に発生します。 たとえば、次から始まります$(0, 5)$、最初のクエリは生成します$1$、与える$x=0$。 2 番目のクエリでもまだ分離されています$y$状態遷移後は正しく動作します。 どちらの応答も奇数の整数のままであるため、除算の問題は発生しません。 

もう 1 つの特殊なケースは、次のような大きな振幅の座標です。$10^9$。 二次拡張でも 64 ビット範囲内の値が生成され、整数演算によって安全に計算が処理されます。 

最後の微妙なケースは、負の座標です。 式はのみに依存するため、$2x+1$そして$2y+1$、符号は自動的に保持され、整数の除算は特別な処理を行わなくても負の値を正しく再構築します。
