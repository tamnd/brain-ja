 ## 問題の理解

 焼けていないすべてのセルをグラフの頂点と考えてください。 2 つの頂点のセルが 1 つの辺を共有する場合、接続されます。 このステートメントは、このグラフが接続されていることを保証します。 すべてのパンケーキは最初は独自の頂点を占め、移動するたびに一番上のパンケーキが 1 つの頂点から隣接する頂点に移動します。 移動するとパンケーキが反転するため、奇数回移動すると正しい向きになり、偶数回移動すると元の向きに戻ります。 

スタックにより問題は欺瞞的になります。 パンケーキは一時的に他のパンケーキとセルを共有できますが、再び移動できるのは一番上のパンケーキだけです。 最後には、すべてのパンケーキは単独でなければならず、すべてのパンケーキは奇数回移動する必要があります。 

グリッド グラフは 2 部構成です。 行インデックスと列インデックスの合計が偶数の場合はセルを黒に色付けし、それ以外の場合は白に色付けします。 すべての動きは反対の色の間を移動します。 したがって、黒で始まり、最終的に正しい向きになるパンケーキは白で終わる必要があり、白で始まるパンケーキは黒で終わる必要があります。 最終的な位置は明確であるため、黒の最初のパンケーキの数は白のセルの数を超えることはできず、対称的に、最初の白のパンケーキの数は黒のセルの数を超えることはできません。 

最大 100 行と 100 列の場合、使用可能なセルは最大 10,000 個になります。 線形または線形に近いグラフ アルゴリズムは、1 秒の制限を十分に満たす速度です。 パンケーキの最大数も 10,000 であるため、パンケーキの数に指数関数的に依存するアルゴリズムは完全に実行不可能です。 

色カウント条件だけでは見逃される構造上のエッジケースが 1 つあります。 考慮する```
1 2
PP
```黒のセルと白のセルが 1 つあるため、カウントは完全にバランスが取れています。 それでも答えは`NO`。 隣接するセルが 2 つだけの場合、どちらのパンケーキをもう一方のパンケーキの上に移動しても、一番上のパンケーキになります。 下のパンケーキにアクセスするには前に戻らなければならないため、2 つのパンケーキを交換することはできません。 より一般的には、すべての使用可能なセルが占有されている場合、本物のバッファーを提供するために使用可能なセルのグラフにサイクルが必要になります。 

誤って扱いやすいもう 1 つのケースは、サンプルです。```
1 3
P.P
```2 つのパンケーキは両方とも同じ色のセル上にありますが、反対色のセルは 1 つだけあります。 両方のパンケーキを異なる色の反対色のセルで仕上げる必要がありますが、それは不可能です。 答えは`NO`。 

最後のエッジケースは 1 枚のパンケーキです。 例えば、```
1 2
P.
```黒いパンケーキが 1 つと白いターゲット セルが 1 つあるので、答えは次のようになります。`YES`。 パンケーキは一度動くだけです。 少なくとも 2 つのパンケーキを必要とするソリューションでは、このケースは誤って拒否されます。 

## アプローチ

 直接的な総当たりの解決策は、配置全体を状態として扱います。 州は、すべてのパンケーキの位置、向き、およびすべてのスタック内のパンケーキの順序を記録する必要があります。 各状態から、空ではないすべてのセルの一番上のパンケーキを、隣接する使用可能なセルに移動してみることができます。 すべての正当な操作は 1 つの遷移で表され、すべてのパンケーキが正しい向きで分離された状態に到達すると、有効なシーケンスが存在することが証明されるため、幅優先検索は正しいと考えられます。 

問題はその状態空間のサイズです。 (V) 個の使用可能なセルと (k) 個のパンケーキがある場合、ラベル付きパンケーキごとにセルを選択するだけで、(V^k) 個の可能性が得られます。 方向によってこれに (2^k) が乗算され、スタック内の可能な順序によって別の階乗サイズのコンポーネントが追加されます。 はるかに小さい上限 (2^kV^k) でさえ、(k,V) が 10,000 付近ではすでに絶望的です。 ブルート フォースはルールを理解するのには役立ちますが、実際の制約を解決するのには役立ちません。 

重要な観察は、動きの正確な順序は必要ないということです。 移動するたびに、パンケーキの位置の色と方向の両方が変化します。 したがって、黒で始まるパンケーキは白で終わる場合にのみ正しくなり、白で始まるパンケーキは黒で終わる場合にのみ正しくなります。 これにより、必要な色容量の不平等が即座に得られます。 

驚くべきことに、使用可能な空のセルが少なくとも 1 つある場合には、これらの不等式も十分に成立するということです。 使用可能なグラフが接続されているため、その空のセルはグラフを通じて転送され、バッファとして使用できます。 スタックを使用すると、バッファーが移動している間にパンケーキが占有されている頂点を通過できます。 その結果、2 つのカラー クラス間で必要なパンケーキの再配分を実現できます。 

使用可能なすべてのセルにすでにパンケーキが含まれている場合、空のバッファーは存在しません。 その場合、サイクルは必要かつ十分です。 サイクル上では、パンケーキをその周りに移動させることができるため、サイクル上のすべてのパンケーキはスタックを残さずに奇数回移動できます。 このサイクルは、接続されたグラフの残りの部分を再配置するための不足しているワークスペースとして機能します。 サイクルのない接続されたグラフはツリーであり、すべての頂点が占有されているため、永続的なワークスペースを作成して必要な配置を変更する方法はありません。 

したがって、問題全体は 2 つのチェックに集約されます。2 部構成のカラー容量と、すべての使用可能なセルが占有されている場合にのみ、使用可能なセルのグラフにサイクルが含まれているかどうかです。

 ## アルゴリズムのチュートリアル

 1. すべての細胞を異なるものとして扱う`#`使用可能なグラフの頂点として。 ((i+j)\bmod 2) に従って黒または白に色を付けます。 すべての正当な移動により 1 行または 1 列が 1 つずつ変更されるため、これは有効な 2 分割です。 
2. 使用可能な黒と白のセルの合計数を数え、最初に黒と白のセルを占めるパンケーキの数を個別に数えます。 黒いパンケーキの数が白い使用可能なセルの数より大きい場合は、次のように出力します。`NO`。 白いパンケーキの数が黒い使用可能なセルの数より大きい場合は、次のように出力します。`NO`。 各パンケーキは反対の色で仕上げる必要があり、最後のセルに 2 つのパンケーキを含めることはできません。 
3. 使用可能なセルとパンケーキを数えます。 パンケーキの数が使用可能なセルの数よりも少ない場合、少なくとも 1 つのセルは空になります。 接続されたグラフはその空のセルを移動バッファとして使用できるため、色の不平等は十分です。 印刷する`YES`。 
4. 使用可能なすべてのセルにパンケーキが含まれている場合、色の不平等は 2 つのカラー クラスのサイズが等しいことを意味します。 ここで、使用可能なグラフにサイクルが含まれているかどうかを判断する必要があります。 隣接する使用可能なセルのすべてのペアを無向エッジとしてカウントします。 グラフは接続されているため、エッジの数が少なくとも頂点の数である場合、グラフにはサイクルが含まれます。 
5. 使用可能なグラフ全体にサイクルが含まれている場合は、次のように出力します。`YES`; それ以外の場合は印刷します`NO`。 接続された非巡回グラフはツリーであり、すべての頂点が占有されると、パンケーキを再配置するために使用できる空のセルまたはサイクルがなくなります。 

これが機能する理由: すべての正当な動きは 2 分割を越えてパンケーキを裏返すため、正しい向きのパンケーキは開始セルの反対の色で終了する必要があります。 これは、2 つの容量の不平等が必要であることを証明しています。 空のセルが存在する場合、接続により、グラフ内でパンケーキを移動する際にそのセルをバッファーとして使用でき、スタック ルールにより一時的な衝突が許可されます。 空のセルがない場合、サイクルはまさに閉じたバッファ ルートを提供する構造になります。 ツリーにはそのようなルートがありませんが、サイクルでは占有された構成が回転され、残りの接続された部分がそれを通じて処理されます。 したがって、上記のチェックは、有効なシーケンスが存在する場合を正確に特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    cells = 0
    pancakes = 0

    black_cells = 0
    white_cells = 0
    black_pancakes = 0
    white_pancakes = 0

    edges = 0

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '#':
                continue

            cells += 1

            if (i + j) % 2 == 0:
                black_cells += 1
            else:
                white_cells += 1

            if grid[i][j] == 'P':
                pancakes += 1
                if (i + j) % 2 == 0:
                    black_pancakes += 1
                else:
                    white_pancakes += 1

            if i + 1 < n and grid[i + 1][j] != '#':
                edges += 1
            if j + 1 < m and grid[i][j + 1] != '#':
                edges += 1

    if black_pancakes > white_cells:
        print("NO")
        return

    if white_pancakes > black_cells:
        print("NO")
        return

    if pancakes < cells:
        print("YES")
        return

    # Every usable cell is occupied.
    # The usable graph is connected, so it has a cycle iff E >= V.
    if edges >= cells:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```最初のループは、使用可能なすべてのセルをその座標のパリティによって分類します。 両方の座標に 1 を加算すると、それらの合計が 2 だけ変化するため、ゼロベースのインデックスを使用しても 2 分割は変わりません。 

2 つのパンケーキ カウンターは初期位置の色を記録します。 正しく終了したすべてのパンケーキは奇数回 2 分割を通過している必要があるため、それらは反対色の利用可能なセルの数と比較されます。 

エッジカウンターは下と右のみを見ます。 したがって、すべての水平または垂直エッジは 1 回だけカウントされ、二重カウントと個別のグラフ データ構造の両方が回避されます。 

の`pancakes < cells`check は、2 つの構造的なケースの重要な違いです。 使用可能な空のセルが少なくとも 1 つある場合、buffer 引数が適用されます。 使用可能なセルがすべて占有されている場合は、グラフのサイクルを検査する必要があります。 

使用可能な領域は接続されていることが保証されているため、ツリーの標準的な特徴付けが適用されます。つまり、(V) 個の頂点を持つ接続されたグラフは、(V-1) 個のエッジがある場合に非循環になります。 したがって`edges >= cells`DFS のないサイクルまたは素セット構造を検出します。 

数万を超える演算はできないため、Python や一般的な C++ 実装では整数のオーバーフローは問題になりません。
