 ## 解決策
 ## 問題の理解

 Каждый этаж базни требует ровно один килограмм железа и один килограмм дерева. Если килограмм железа стоит`X`ロシア、今日の天気`Y`рублей、то один полностью построенный этаж всегда обходится в`X + Y`рублей。 

Вход содержит бюджет`N`、цену килограмма железа`X`и цену килограмма дерева`Y`。 Нужно найти максимальное целое количество этажей, для которого суммарная стоимость материалов не превыльноет だ。 Поскольку материалы для одного этажа нельзя заменить или купить частично, задача сводится к нахождению Ссимального`k`、такого что`k * (X + Y) <= N`。 

Ограничение`N <= 10^9`、 также ограничения`X <= 10^9`や`Y <= 10^9`必要に応じて、最高のパフォーマンスを実現します。 Перебирать количество этажей уже нельзя считать читать хорозим резением: при маленьких ценах число возможных этажей может достигать сотен миллионов. Резение должно работать за`O(1)`。 

Есть несколько границ, на которых легко озибиться. Например、при входе`3, 2, 1`один этаж стоит ровно`3`、 поэтому ответ равен`1`。 Если написать условие перебора как`cost < N`、、、`cost <= N`、такой случай будет пропущен и получится неверный ответ`0`。 

Другой случай возникает、когда денег недостаточно даже на один этаж。 ああ、`5, 1, 10`один этаж стоит`11`、 поэтому правильный ответ равен`0`。 Подход, который отдельно проверяет возможность покупки железа и дерева, может озибочно ресить, что железо あなたの情報は、жотя этаж требует оба материала.

 Наконец、нужно учитывать больгие значения цен。 При`N = 10^9`、`X = 10^9`、`Y = 10^9`стоимость одного этажа равна`2 * 10^9`、 поэтому ответ равен`0`。 В языках с фиксированными целочисленными типами важно хранить сумму`X + Y`достаточно сироком типе。 

## アプローチ

 Самый прямой способ заключается в последовательном построении этажей. Можно начать с нуля, каждый раз добавлять стоимость одного этажа и увеличивать количество построенных этажей、пока следующая покупка укладывается в бюджет。 Такой алгоритм корректен, потому что он проверяет этажи в порядке возрастания и останавливается ровно перед первым недоступным этажом。 

Проблема в количестве итераций。 В худвем случае`X = 1`や`Y = 1`、あー`N = 10^9`。 Тогда один этаж стоит всего 2 рубля, и перебор выполнит примерно`5 * 10^8`итераций。 ロシアは、ответ на которую можно получить одной арифметической операцией、это совер程енно избыточно。 

Ключевая идея состоит в том, что стоимость каждого этажа одинакова. Если один этаж стоит`X + Y`、 то два этажа стоят`2 * (X + Y)`、 три этажа стоят`3 * (X + Y)`、 так далее 。 Нам не нужно моделировать строительство каждого этажа, достаточно разделить весь бюджет на стоимость одного этажа と взять целую часть результата.

 Иными словами, искомое количество равно`N // (X + Y)`。 Целочисленное деление автоматически отбрасывает неполный последний этаж, а именно это нам и требуется.

 | アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(N / (X + Y))`、до`O(10^9)`|`O(1)`| 遅すぎる |
 | 最適 |`O(1)`|`O(1)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. Считаем бюджет`N`、 стоимость килограмма железа`X`и стоимость килограмма дерева`Y`。 Эти три числа полностью определяют стоимость любого возможного этажа.
 2. Вычисляем стоимость одного этажа как`cost = X + Y`。 Один этаж всегда требует оба материала, поэтому складывать цены нужно до вычисления ответа.
 3. 最後のメッセージ:`answer = N // cost`。 Полученное число показывает максимальное количество полных этажей、которые можно оплатить。 
4. Выводим`answer`。 Остаток от деления представляет деньги, которых недостаточно для ещё одного полного этажа, поэтому あなたの質問に答えてください。 

### なぜ効果があるのか

 Пусть алгоритм возвращает`k = N // (X + Y)`。 По свойству целочисленного деления выполняется`k * (X + Y) <= N`、 、`k`этажей действительно можно оплатить。 При этом`(k + 1) * (X + Y) > N`、 、 потому что`k`является целой частью частного。 Значит、построить`k + 1`этажей уже невозможно。 Следовательно、`k`Сляется не просто допустимым, а максимальным количеством этажей.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N = int(input())
    X = int(input())
    Y = int(input())

    cost = X + Y
    answer = N // cost

    print(answer)

if __name__ == "__main__":
    solve()
```Сначала программа читает три значения из отдельных строк, как задано форматом входа. Переменная`N`Ѕранит весь доступный бюджет, а`X`や`Y`задают цены двух материалов。 

Затем вычисляется`cost = X + Y`。 Здесь нет необходимости отдельно рассчитывать количество доступного железа и количество доступного дерева, поскольку каждый этаж требует одинаковое количество обоих материалов, ровно по одному килограмму.

 Строка`answer = N // cost`непосредственно реализует основную формулу。 Обычное`/`в Python を使用して、 плавающей точкой, а`//`Лазу возвращает нужное целое количество полностью оплаченных этажей。 

Граница включается автоматически。 Если бюджет делится на стоимость этажа без остатка, например`N = 3`や`cost = 3`、 результатом будет`1`、あーん`0`。 Python は、Python のテストを実行します。

 ## 特殊なケース

 При минимальном бюджете`N = 1`、`X = 1`、`Y = 1`стоимость этажа равна`2`。 Алгоритм вычисляет`1 // 2 = 0`、 поэтому возвращает`0`。 Олибочный перебор, который сначала увеличивает число этажей, а уже потом проверяет бюджет, может Молучайно получить отрицательный остаток или завысить ответ на единицу.

 При точном совпадении бюджета со стоимостью этажа вход`3, 2, 1`今日は`3`やあ`3 // 3 = 1`。 Здесь особенно легко олибиться, если проверять строгое неравенство`cost < N`और देखें`cost <= N`。 

Когда денег недостаточно на один этаж, например`5, 1, 10`、 стоимость равна`11`、 、`5 // 11 = 0`。 Наличие достаточного количества денег хотя бы на один из материалов ничего не меняет, поскольку этаж требует одновременно と железо, и дерево。 

При больсих значениях`N = 10^9`、`X = 10^9`、`Y = 10^9`Ѝтажа составляет`2 * 10^9`。 日付`0`。 Python は корректно хранит такую сумму как целое число, поэтому дополнительная защита от переполнения не нужна.

 Наконец, вход`19, 3, 2`あなたのことを忘れないでください。 Один этаж стоит`5`、 три этажа стоят`15`、 а четыре уже требуют`20`。 Формула`19 // 5 = 3`最高のパフォーマンスを見せてください。
