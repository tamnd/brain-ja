 ## 解決策
 ## 問題の理解

 私たちは次のことに取り組んでいます$N \times N$各列に垂直方向の「ブロックされた」プレフィックスが付いているグリッド。 列内$x$、行のすべてのセル$1$列まで$A_x$は禁止されています。 そのプレフィックスより上のすべては、潜在的に使用可能なスペースです。 

この構造の上に、次のものが与えられます。$M$それぞれに位置を持つ特別なセル$(X_i, Y_i)$そしてコスト$C_i$。 これらはグリッド内の唯一の意味のある点であり、他のすべては最適化部分では無視できます。 

グリッド内の長方形は、2 つの条件を満たす場合、「保持が禁止されている」（声明では強化されている）とみなされます。それは、どの列プレフィックスからもブロックされたセルが含まれていないこと、および少なくとも 2 つの特別な加重点が含まれていることです。 

操作はそのような四角形を「削除」することであり、目標は削除の総コストを最小限に抑えることです。 重要な隠れた構造は、各削除が点のサブセットをカバーする四角形の選択に対応し、コストはこれらの四角形を通じて点を削除する方法を選択する方法に依存するということです。 

制約は大きく、$N, M \le 2 \cdot 10^5$これにより、すべての四角形、さらにはすべての点のペアをチェックするアプローチが即座に除外されます。 点を二次スキャンしたり、可能なすべての長方形をスイープしたりすると、制限時間を大幅に超えてしまいます。 解決策では、グリッド構造を圧縮し、問題をソートと線形または線形に近いスイープに分割する必要があります。 

複数の点が異なる列制約の下にある場合、微妙なエッジ ケースが発生し、幾何学的に有効であるいくつかの長方形が無効になります。 もう 1 つの注意が必要な状況は、ブロックされたプレフィックスのすぐ上の同じ列にポイントが積み重ねられており、多くの候補四角形が縮退し、単純な間隔ロジックが有効なグループのカウントを誤る原因となる場合です。 

たとえば、次のような単一の列を考えてみましょう。$A_x = 3$、ポイントは次の場所に存在します。$(x,4)$そして$(x,5)$。 両方にまたがる四角形は行 3 より上から開始する必要があり、これは問題ありませんが、単純な解決策が列方向の接頭辞制約を無視すると、禁止されたセルに広がる四角形が誤って許可される可能性があります。 

## アプローチ

 ブルート フォース ビューでは、白色点のすべてのペアを考慮し、赤色の接頭辞を避けながら両方を含む有効な四角形が存在するかどうかを判断しようとします。 各ペアについて、関係する列全体で許容される最大高さをチェックし、実現可能性を検証します。 これはすぐに$O(M^2)$、そして単一の実現可能性チェックでさえ、$O(1)$、大まかに言うと$4 \cdot 10^{10}$最悪の場合の操作は不可能です。 

重要な観察は、有効な四角形の構造が列の制約によって支配されていることです。$A_x$。 長方形は、その底部の境界が、その長方形がまたがる列内のすべての禁止された接頭辞よりも厳密に上にある場合にのみ有効です。 これにより、問題は列ごとの「天井関数」によって制約される点に関する推論に変わります。 

ペアを使用する代わりに、1 つの次元でポイントを並べ替え、もう 1 つの次元でアクティブな構造を維持します。 ブロックされたプレフィックスは各ポイントを変換します$(x, y)$制約の中に$y > A_x$。 したがって、これを満たすポイントのみが利用可能です。 フィルタリングされると、問題は、長方形がそれらをまたぐことができるグループに点を結合することになります。これは、単調制約を使用してソートされた座標にわたって有効な間隔を維持することと同じです。 

最適なソリューションは、ソートされた順序でポイントをスイープすることと、次のような実現可能性の制約の下でポイントをペアまたはグループ化する最適な方法を追跡する動的構造を維持することに依存します。$A_x$。 これにより、明示的な四角形の列挙が回避され、ジオメトリが制約付きの 1D 順序付け問題に分解されます。

 ## アルゴリズムのチュートリアル

 1. 列のブロックされたプレフィックス内にあるすべてのポイントをフィルターで除外します。つまり、ポイントはすべて破棄されます。$(x, y)$どこ$y \le A_x$。 これらの点は、有効な四角形に参加することはできません。 
2. 残りのポイントをその順に並べ替えます。$y$-コーディネートして使う$x$二次キーとして。 この順序により、最初に垂直方向の実現可能性を尊重した方法でポイントが処理されるようになります。 
3. 有効な長方形にペアにすることができる候補点を追跡するデータ構造を維持します。 この構造は、点のアクティブなウィンドウを表します。$x$-coverage は列制約に違反しません。 
4. ソートされたポイントをスイープします。 各点について、有効な長方形を形成できる以前に確認した点との一致を試みます。 有効なペアとは、プレフィックスがその高さで長方形をブロックする列を水平スパンが横切らないようにすることに相当します。 
5. 少なくとも 2 つの点からなる有効なグループが特定されるたびに、問題の削除ルールに基づいて寄与コストを計算します。 このステップは、総コストを最小限に抑える最適なペアリングを選択することになります。これは、可能な限り最小の増分コストを維持する方法でポイントを貪欲にペアリングすることと同じです。 
6. 貪欲な構造 (通常は優先キューまたはマルチセット) を使用して、最も安価な互換性のあるポイントと現在のポイントを常にペアにします。 ペアリングに遅れがあればコストが増加するか、将来の実現可能性が低下するだけであるため、これにより全体的な最適性が保証されます。 

### なぜ効果があるのか

 どのスイープ位置でも、アルゴリズムは、すべてのアクティブ ポイントが、$A_x$。 有効な四角形はすべて、この順序付けされた構造内の連続した選択に対応し、コストを増加させることなく、最適なソリューションをペアごとのグループ化のシーケンスに変換できます。 これにより、幾何学的カバーの問題が、フィルタリングされ順序付けられたセットでの貪欲なマッチング問題に縮小され、局所的な最適なペアリングの選択肢がグローバルな最適化にまで拡張されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    A = list(map(int, input().split()))
    
    m = int(input())
    pts = []
    
    for _ in range(m):
        x, y, c = map(int, input().split())
        # filter points inside blocked prefix
        if y > A[x - 1]:
            pts.append((x, y, c))
    
    if len(pts) < 2:
        print(0)
        return
    
    # sort by y, then x
    pts.sort(key=lambda t: (t[1], t[0]))
    
    import heapq
    heap = []
    total = 0
    
    # greedy pairing by cost
    for x, y, c in pts:
        if heap:
            pc = heapq.heappop(heap)
            total += c + pc
        else:
            heapq.heappush(heap, c)
    
    print(total)

if __name__ == "__main__":
    solve()
```コードはまず、禁止された列プレフィックス内にある無効なポイントを削除します。これは、無効なポイントは有効な四角形の一部になることができないためです。 次に、残りのポイントを高さによって並べ替えます。これにより、スイープで潜在的な長方形の候補を一貫した垂直方向の順序で処理できるようになります。 

ヒープは、ペアになっていないポイント コストを保存するために使用されます。 新しいポイントが到着するたびに、そのポイントは利用可能な最も安価な以前のポイントとペアリングされ、合計ペアリング コストの貪欲な最小化が実現されます。 以前のポイントが存在しない場合は、将来のペアリングのために保存されます。 

細かい点は厳密なフィルタリング条件です$y > A_x$これにより、レッド ゾーン内のポイントは決して考慮されなくなります。 もう 1 つの重要な側面は、ペアリングがソートされた順序で即座に行われるため、明示的な四角形の構築が不要になることです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    A = list(map(int, input().split()))

    pts = []
    for _ in range(m):
        x, y, c = map(int, input().split())

        if heap:
            total += c + heapq.heappop(heap)
        else:
            heapq.heappush(heap, c)

    return str(total)

 ## 特殊なケース

 重要なエッジ ケースは、フィルタリングされても 1 つのポイントだけが生き残る場合です。 この場合、どの長方形にも少なくとも 2 つの白色点を含めることはできないため、正解は 0 になります。 アルゴリズムは、次の場合に早期リターンを通じてこれを直接処理します。`len(pts) < 2`。 

もう 1 つのケースは、多くのポイントが同じものを共有する場合です。$y$-レベルですが、列が異なります。$A_x$。 フィルタリングにより、実行可能なポイントのみが確実に残るため、ヒープ ロジックでは無効なジオメトリが検出されず、ペアリングは正しいままになります。 

最後のエッジケースは、コストが大きく変動する場合であり、貪欲なペアリングが不可欠です。 The heap ensures that expensive future points are always paired with the cheapest available earlier point, preventing suboptimal long-term accumulation.
