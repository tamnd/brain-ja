 ## 解決策
 ## 問題の理解

 私たちに与えられた通りは、`n`連なる家々に番号が付けられている`1`に`n`, ここで、各家には整数で表される色があります。 イリヤは、**異なる色**の 2 つの家を選び、それらの間を歩き、単純にインデックスの違いとして距離を測定したいと考えています。`(j - i)`のために`i < j`。 課題は、このルールの下で達成できる最大距離を見つけることです。 

入力により住宅の数が得られます`n`続いて色のリスト`c_1, c_2, ..., c_n`。 出力は単一の整数、つまり色の異なる 2 つの家の間の可能な最大距離です。 

以来`n`最大 300,000 件で、制限時間は 2 秒であるため、考えられるすべての家のペアを検査するソリューション (最悪の場合、約 450 億回の操作が必要となる) は実行不可能です。 これにより、ブルートフォースアプローチが排除されます。`O(n^2)`複雑。 線形の解決策が必要です`n`またはそれに近い。 

エッジケースには、最初と最後の家が異なる色を持つ (最大距離が生じる) 場合や、配列の終端を除いて同じ色の長いシーケンスがある場合が含まれます。 例えば、`[1, 1, 1, 1, 2]`返すべきです`4`、 ない`1`。 隣接するペアのみをスキャンする単純な実装では、間違った答えが返されます。 もう 1 つの微妙なケースは、最大距離が先頭から遅い異なるハウスまで、または終わりから早い異なるハウスまでに発生する場合です。そのため、ソリューションでは配列の両端を考慮する必要があります。 

## アプローチ

 ブルートフォース手法は、考えられるすべてのペアに対して反復されます。`(i, j)`と`i < j`色が異なるかどうかを確認し、最大値を追跡します`j - i`。 これは正しいですが、次のことが必要です`O(n^2)`操作が遅すぎるため、`n`300,000まで。 

この問題を最適化するための重要な観察は、最大距離には常に **エンドポイントの 1 つ**が含まれるということです。 最大化しようとしたら`j - i`、最大の違いは、最初の家から始まるか、最後の家で終わるかのいずれかで発生します。 したがって、異なる色の最初の家から最後の家までの距離と、異なる色の最後の家から最初の家までの距離を確認するだけで済みます。 これにより、問題は **2 つの候補をチェック**するだけになり、`O(n)`。 

最適なアプローチは両端からスキャンします。左から始めて、異なる色の右側の最も遠い家を見つけます。また、右から始めて、異なる色の左側の最も遠い家を見つけます。 これら 2 つの距離の最大値が答えになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.最初の家の色を記録します`c_first = c[0]`。 
2. アレイを端から逆方向にスキャンします。 各家ごとに色が違う場合は、`c_first`、計算する`distance = index_last - 0`最大距離を更新します。 **最も遠い色**のみを考慮するため、最後と異なる最初の色で停止します。 
3. 最後の家の色を記録します。`c_last = c[n-1]`。 
4. アレイを最初から順にスキャンします。 各家ごとに色が違う場合は、`c_last`、計算する`distance = n-1 - index_first`最大距離を更新します。 繰り返しますが、**最も遠い色**のみを考慮するため、最初から最初の異なる色で停止します。 
5. 見つかった 2 つの距離のうち大きい方を返します。 

**機能する理由:** 最大距離はエンドポイントによって制限されます。 配列内の異なる色の 2 つの家は、反対側の端で異なる色とペアになっている端点の 1 つよりも短い距離になります。 エンドポイントのみをチェックすることで、候補を見逃さずに可能な最大距離を見つけることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
colors = list(map(int, input().split()))

c_first = colors[0]
c_last = colors[-1]

# distance from the first house to the furthest differing color from the end
for i in range(n-1, -1, -1):
    if colors[i] != c_first:
        dist1 = i
        break

# distance from the last house to the furthest differing color from the start
for i in range(n):
    if colors[i] != c_last:
        dist2 = n - 1 - i
        break

print(max(dist1, dist2))
```コードは最初に最初と最後の色を割り当て、次に先頭と異なる最初の家を最後からスキャンし、最後と異なる最初の家を最初からスキャンします。 の`break`それぞれの場合において、可能な限り異なる家のみを選択するようにします。 使用する`i`Python は 0 から始まるインデックスなので、距離を直接指定しても安全です。`i - 0`は`i`、 そして`n - 1 - i`端からの距離を直接計算します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    colors = list(map(int, input().split()))
    c_first = colors[0]
    c_last = colors[-1]

    for i in range(n-1, -1, -1):
        if colors[i] != c_first:
            dist1 = i
            break
    for i in range(n):
        if colors[i] != c_last:
            dist2 = n - 1 - i
            break
    return str(max(dist1, dist2))

# Provided samples
assert run("5\n1 2 3 2 3\n") == "4", "sample 1"
assert run("2\n1 2\n") == "1", "sample 2"
assert run("7\n1 1 1 2 2 2 1\n") == "6", "sample 3"

# Custom cases
assert run("4\n1 1 1 2\n") == "3", "identical prefix"
assert run("4\n2 1 1 1\n") == "3", "identical suffix"
assert run("3\n1 2 1\n") == "2", "alternating colors"
assert run("6\n1 1 1 1 1 2\n") == "5", "large end distance"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`4\n1 1 1 2\n`| 3 | 先頭で同じ色を扱う |
 |`4\n2 1 1 1\n`| 3 | 最後に同じ色を扱う |
 |`3\n1 2 1\n`| 2 | 交互の色、短い配列 |
 |`6\n1 1 1 1 1 2\n`| 5 | 最大距離は、最初の異なる色から最後の色までに発生します。 

## 特殊なケース

 のような配列の場合`[1, 1, 1, 2]`、端からスキャンすると、インデックス 3 で異なる色が見つかり、距離は次のようになります。`3`。 最初からスキャンすると、最後のインデックスでも異なる色が見つかり、次の結果も得られます。`3`。 これにより、両端で同じ色のシーケンスが発生しても、アルゴリズムが正しい最大値を見逃すことがなくなります。 同様に、配列が`[2, 1, 1, 1]`、最初からスキャンすると、最後から異なる色のインデックス 0 が見つかり、正しい最大距離が生成されます。 このアルゴリズムは、条件を追加することなく、これらの特殊なケースを自然に処理します。
