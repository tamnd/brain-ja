 ## 解決策
 ## 問題の理解

 2 つの行列が与えられます。`A`そして`B`、サイズの`n × m`でいっぱい`0`と`1`s. 変更できます`A`少なくともサイズの部分行列を繰り返し選択することによって`2 × 2`そしてその 4 隅の値を反転します。 課題は、変換可能かどうかを判断することです。`A`の中へ`B`このようなコーナーフリップのシーケンスを使用します。 

実際には、コーナーをフリップするたびに、`0`に`1`または`1`に`0`。 長方形の角のみが影響を受けるため、操作できる最小の長方形は次のようになります。`2 × 2`。 単一のコーナーを単独で切り替えることはできず、少なくとも 1 つのコーナーに属さないエッジは切り替えることができません。`2 × 2`長方形を個別に変更することはできません。 たとえば、`1 × 1`行列はまったく変更できないため、単一行または単一列の行列は特殊なケースとなります。 

問題の範囲は中程度です。`n, m ≤ 500`。 最大 250,000 個のセルがある場合、行列内の四角形の数はおおよそ次のように増加するため、考えられるすべての部分行列をテストする総当りの試みは遅すぎます。`O(n²m²)`。 変革の実現可能性をチェックするアプローチが必要です`A`の中へ`B`すべての操作を明示的にシミュレートする必要はありません。 

エッジケースには非常に小さな行列が含まれます (`1 × n`または`n × 1`) 演算が不可能な場合、および最後の行または列のみが異なる行列。 たとえば、次の場合```
A = [[0, 1]]
B = [[1, 0]]
```いいえ`2 × 2`部分行列が存在するので、答えは次のようになります。`No`。 どのようなソリューションでも、これらの状況を注意深く考慮する必要があります。 

## アプローチ

 素朴なアプローチは、あらゆる可能性を試すことです`2 × 2`部分行列、常にコーナーを反転`A[i][j] ≠ B[i][j]`。 これは小さな行列では機能しますが、次の場合には実行不可能になります。`n`そして`m`500 に近づきます。最悪の場合の複雑さは次のようになります。`O(n²m²)`すべての四角形をチェックするだけでは、指定された制限に対して遅すぎます。 

重要な観察は、`2 × 2`反転は、長方形の左上、右上、左下、右下の 4 つのセルにのみ影響します。 したがって、一致するには`A`に`B`、2 つの行列の差は、左上から右下へ反転を伝播することでローカルに処理できます。 具体的には、ポジションでフリップを決めた場合`(i, j)`のコーナーにのみ影響します。`(i,j)`、`(i,j+1)`、`(i+1,j)`、`(i+1,j+1)`。 

これは **貪欲なアルゴリズム** につながります。つまり、現在のセルが異なる場合は常に左上隅から反復処理されます。`B`、裏返します`2 × 2`このセルを左上隅に持つ部分行列。 セルを順番に処理することにより、各フリップは、すでに正しい以前のセルを妨げることなく、現在の不一致に対処します。 カバーできない唯一のセル`2 × 2`反転は最後の行または最後の列にあるもので、すでに一致している必要があります`B`解決策が存在するために。

 | --- | --- | --- | --- |
 | ブルート フォース (すべての長方形) | O(n²m²) | O(nm) | 遅すぎる |
 | 貪欲な左上派の伝播 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 差分行列を計算する`D = A XOR B`。 それぞれの細胞は、`1`もし`A`とは異なります`B`そして`0`すでに等しい場合。 これにより、フリップが必要な場所がエンコードされます。 
2. 最後の行と最後の列を除き、行列を左上から右下まで繰り返します (`i = 0..n-2, j = 0..m-2`）。 細胞ごとに`(i,j)`：

- もし`D[i][j]`は`1`に反転を適用します。`2 × 2`左上隅の部分行列`(i,j)`。 
- の四隅を更新します`D`それらを切り替えることで (`D[i][j] ^= 1`、`D[i][j+1] ^= 1`、`D[i+1][j] ^= 1`、`D[i+1][j+1] ^= 1`）。 
3.可能な限りすべての処理を行った後`2 × 2`反転して、最後の行を確認してください (`i = n-1`) と最後の列 (`j = m-1`）。 もしあれば`D[i][j]`は`1`これらの領域では、出力`No`; それ以外の場合は出力`Yes`。 

機能する理由: 各フリップは、現在の左上の不一致を修正するために選択されます。`2 × 2`矩形。 以前の行と列はすでに修正されているため、将来の反転によってすでに修正されたセルが乱されることはありません。 このプロセスでは、すべての違いが次の方法で解決できるかどうかが保証されます。`2 × 2`反転すると、最後の行と列は自動的にゼロになります。 そうしないと、これらの領域の不一致を修正できず、変換が不可能であることを示します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
A = [list(map(int, input().split())) for _ in range(n)]
B = [list(map(int, input().split())) for _ in range(n)]

# Step 1: difference matrix
D = [[A[i][j] ^ B[i][j] for j in range(m)] for i in range(n)]

# Step 2: greedy top-left flips
for i in range(n - 1):
    for j in range(m - 1):
        if D[i][j]:
            D[i][j] ^= 1
            D[i][j+1] ^= 1
            D[i+1][j] ^= 1
            D[i+1][j+1] ^= 1

# Step 3: check last row and column
possible = True
for i in range(n):
    if D[i][m-1]:
        possible = False
for j in range(m):
    if D[n-1][j]:
        possible = False

print("Yes" if possible else "No")
```各部分はアルゴリズムのステップを反映しています。 XOR 演算によって差分行列が構築され、ネストされたループによって貪欲な反転が実装され、最終チェックによって、一致しないセルが残っていないことが確認されます。`2 × 2`フリップが届かない。 微妙な点は、インデックス エラーを避けるために貪欲ループから最後の行と列を除外することです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    A = [list(map(int, input().split())) for _ in range(n)]
    B = [list(map(int, input().split())) for _ in range(n)]
    D = [[A[i][j] ^ B[i][j] for j in range(m)] for i in range(n)]
    for i in range(n-1):
        for j in range(m-1):
            if D[i][j]:
                D[i][j] ^= 1
                D[i][j+1] ^= 1
                D[i+1][j] ^= 1
                D[i+1][j+1] ^= 1
    possible = all(D[i][m-1] == 0 for i in range(n)) and all(D[n-1][j] == 0 for j in range(m))
    return "Yes" if possible else "No"
