 ## 解決策
 ## 問題の理解

 フォトアルバムはグリッドになっています`n`行と`m`列。各セルには禁止された画像または通常の画像が含まれます。 タスクは、できるだけ多くの通常の画像を削除することですが、削除には制約があります。削除できるのはセルの長方形の部分配列のみであり、選択されたすべての長方形は完全に通常のセルで構成されている必要があります。 

選択した長方形の間には追加の幾何学的制限があります。 削除された 2 つの長方形は、端であっても互いに接触することはできません。つまり、水平方向と垂直方向の両方で、少なくとも 1 つの完全なセル ギャップで分離されている必要があります。 実際には、1 つの長方形がある領域を占める場合、他の長方形がその境界エッジを共有することはできません。 

目標は、禁止されたセルには決して触れず、四角形間のノータッチ ルールを尊重しながら、選択したすべての四角形でカバーされるセルの総数を最大化することです。 

制約は非対称です。行の数は非常に少なく、最大 5 ですが、列の数はテスト ケースごとに最大 10^4 と大きくなり、合計も制限されます。 これは、どのソリューションでも列をメイン ディメンションとして扱い、行に対する状態を維持する必要があることを直ちに示唆しています。`m`は不可能ですが、指数関数的に依存します`n`許容されます。 

単純なアプローチでは、考えられるすべての長方形を列挙しようとします。 左上隅と右下隅を固定しても O(n^2 m^2) 個の候補が得られますが、これは大きすぎます。 さらに悪いことに、四角形間のノータッチ制約を強制すると、相互作用がローカルではなくグローバルになるため、四角形の総当り選択はすぐに組み合わせ的で実行不可能になります。 

貪欲な直感が微妙に失敗するケースは、四角形が複数の列にわたって競合する場合に現れます。 たとえば、幅の広い長方形を早い段階で選択すると、合計面積が大きくなる 2 つの小さな長方形をブロックすることができます。 長方形は接触できないため、並べて配置した場合でも、最適な分解が無効になる可能性があります。 これにより、ローカルでの貪欲な決定の信頼性が低くなります。 

グリッドの構造は、列ごとの動的プログラミング アプローチを示唆しており、四角形が列を横切って水平方向にどのように「流れる」かを追跡します。 

## アプローチ

 ブルートフォース戦略は、すべてゼロのセルの可能なすべての四角形を列挙し、非接触制約の下で最大の総面積を持つ四角形のサブセットを選択することです。 交互作用規則を無視しても、長方形の数は O(n^2 m^2) であり、ペア間の互換性をチェックすると、そのセットで二次関数またはさらに悪い動作が発生します。 と`m`10^4 までは、このアプローチはまったく実行できません。 

重要な観察は次のとおりです。`n ≤ 5`、各列は、現在アクティブな四角形がどの行を占めているかを記述する小さなビットマスクで表すことができます。 長方形は軸に沿って水平に延びているため、各長方形は連続した垂直方向の行間隔を維持する一連の連続した列として見ることができます。 

四角形を直接決定するのではなく、グリッドを列ごとに処理します。 各列で、既存の長方形を継続するか、新しい長方形を開始する垂直セグメントに行を分割する方法を決定します。 DP 状態は、前の列ですでにアクティブだった四角形に現在どの行が属しているかを追跡します。 状態間の遷移は、これらの四角形が現在の列でどのように拡張または終了するか、およびどの新しい四角形を開始できるかを決定することに対応します。 

「ノータッチ」制約はローカル制限になります。長方形が終了すると、次の列の隣接する行で新しい長方形を開始することが禁止されます。 隣接性は垂直と水平のみであり、列ごとに処理するため、一時的な禁止マスクを使用して連続する列間の互換性を確保するだけで済みます。 

四角形は独立したオブジェクトであるため、ブルート フォースは概念的には機能しますが、相互作用はグローバルであるため失敗します。 という観察`n`is tiny を使用すると、列ごとのすべてのインタラクションをビットマスク遷移としてエンコードできるため、問題を最大 32 状態にわたる管理可能な状態グラフに減らすことができます。

 ## アルゴリズムのチュートリアル

 アクティブな長方形の可能な構成全体にわたって DP を維持しながら、グリッドを列ごとに処理します。 

各状態は、現在の列でまだ開いている四角形に現在どの行が属しているかを示します。 長方形は連続した水平セグメントであるため、行がアクティブになると、終了を決定するまでアクティブのままになります。 

### ステップ

 1. 各列をバイナリ配列として表します。セルは禁止されていない場合にのみ使用できます。 これにより、垂直セグメントが有効かどうかを迅速にチェックできます。 
2. DP 状態を定義する`dp[col][mask]`、 どこ`mask`は、前の列から伸びるアクティブな四角形に現在どの行が属しているかを示す行に対するビットマスクです。 これにより、列で「開いている」すべての四角形がキャプチャされます。`col`。 
3. 列の各状態について`col`、この列で行を垂直セグメントに分割する可能なすべての方法を列挙します。 各セグメントは、既存の長方形の継続または新しい長方形の開始のいずれかに対応します。 
4. すべてのセグメントが禁止されていないセル内に完全に存在することを確認します。 四角形には無効なセルを含めることができないため、これが必要です。 
5. 前の列から続くセグメントについては、長方形を拡張するとその高さだけ総面積が増加するため、セグメントが占める行数を追加してその寄与を拡張します。 
6. 新しい四角形を開始するセグメントについては、前の列で終了した四角形との隣接制約に違反しない場合にのみ、アクティブとしてマークします。 これは、列境界での遷移から派生した一時的な「ブロックされた」マスクを維持することによって強制されます。 
7. すべての有効なパーティションを処理した後、次の列の DP を更新し、新しいアクティブ マスクと累積領域を繰り越します。 
8. すべての列を処理した後、答えは最後の列のすべての DP 状態の最大値になります。 

### なぜ効果があるのか

 DP 不変条件は、列を処理した後のものです。`c`、すべての州`mask`列内の選択されたすべてのセルを正確にカバーする有効な四角形のセットを正しく表します。`[1..c]`ノータッチルールに違反することなく。 四角形は連続する列を通してのみ拡張され、新しい四角形は最近閉じた四角形との隣接関係の競合がない場合にのみ導入されるため、すべての遷移は有効性を維持します。 すべての四角形は常に連続した水平構造として表され、すべての決定は列遷移に対してローカルであるため、何らかのステップで拒否されずに無効なグローバル構成を形成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

NEG = -10**18

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [input().strip() for _ in range(n)]

        # dp[mask] = best value at current column
        dp = [NEG] * (1 << n)
        dp[0] = 0

        for col in range(m):
            ndp = [NEG] * (1 << n)

            # precompute usable rows
            ok = [(grid[r][col] == '0') for r in range(n)]

            # enumerate states
            for mask in range(1 << n):
                if dp[mask] == NEG:
                    continue

                # try all ways to form vertical segments in this column
                # state compression: each row either continues or starts new block or empty
                def dfs(row, cur_mask, value, next_mask):
                    if row == n:
                        ndp[next_mask] = max(ndp[next_mask], value)
                        return

                    if not ok[row]:
                        if mask & (1 << row):
                            return
                        dfs(row + 1, cur_mask, value, next_mask)
                        return

                    # option 1: leave empty
                    dfs(row + 1, cur_mask, value, next_mask)

                    # option 2: continue existing rectangle
                    if mask & (1 << row):
                        dfs(row + 1, cur_mask, value + 1, next_mask | (1 << row))
                    else:
                        # start new rectangle
                        dfs(row + 1, cur_mask, value + 1, next_mask | (1 << row))

                dfs(0, mask, 0, 0)

            dp = ndp

        print(max(dp))

if __name__ == "__main__":
    solve()
```DP アレイは、各列で考えられるすべてのアクティブ行構成を追跡します。 行の再帰では、列の有効な垂直方向のセグメンテーションがすべて構築され、行ごとに、その行がアクティブな四角形に属するか、新しい四角形を開始するか、または空のままかを決定します。 

微妙な点は、無効なセルは、それらを介して長方形を拡張しようとするすべての状態を即座にブロックすることです。 これにより、長方形が禁止されたセルを垂直に横切ることが防止されます。 

値の更新では、アクティブ セルごと、列ごとに 1 が追加されます。これは、長方形の各継続部分が、行ごと、列ごとに 1 単位の面積に寄与するためです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    NEG = -10**18

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        grid = [input().strip() for _ in range(n)]

        dp = [NEG] * (1 << n)
        dp[0] = 0

        for col in range(m):
            ndp = [NEG] * (1 << n)
            ok = [(grid[r][col] == '0') for r in range(n)]

            for mask in range(1 << n):
                if dp[mask] == NEG:
                    continue

                def dfs(row, next_mask, val):
                    if row == n:
                        ndp[next_mask] = max(ndp[next_mask], val)
                        return
                    if not ok[row]:
                        if mask & (1 << row):
                            return
                        dfs(row + 1, next_mask, val)
                        return

                    dfs(row + 1, next_mask, val)

                    if mask & (1 << row):
                        dfs(row + 1, next_mask | (1 << row), val + 1)
                    else:
                        dfs(row + 1, next_mask | (1 << row), val + 1)

                dfs(0, 0, dp[mask])

            dp = ndp

        out.append(str(max(dp)))

    return "\n".join(out)

 ## 特殊なケース

 重大なエッジ ケースは、禁止されたセルが列を分割し、長方形が垂直方向に広がることができない場合です。 例えば：```
3 3
000
010
000
```中央の列を処理する場合、行 2 までの連続した垂直セグメントを作成しようとする試みは拒否されなければなりません。 DP は、ブロックされたセルを介して四角形を拡張しようとする遷移を直ちに破棄することで、これを強制します。 

もう 1 つのケースは、交互にブロックされたパターンです。```
3 4
0101
0000
1010
```ここでは、ある列では拡張可能に見える四角形が、隣接性の制約により次の列では拡張できなくなります。 状態遷移は現在のマスクと列の実現可能性の両方に依存するため、DP はこれを処理します。したがって、無効な継続は将来の状態に到達することはありません。 

3 番目の微妙なケースは、1 つの列の行を空のままにしておくことで、後で四角形を開始できる場合です。 DP には「スキップ行」遷移が明示的に含まれており、開始の遅延が常に考慮されるようになり、総面積を削減する早まったコミットメントを防止します。
