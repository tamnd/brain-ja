 ## 解決策
 ## 問題の理解

 n 個の要素上の未知の順列 π が与えられますが、それを直接見ることはできません。 代わりに、システムに任意の順列 f を入力すると、π による共役によって定義された変換された順列 g を受け取ることができます。これは、すべての値が π でラベル付けされ、f が適用され、その後、π 逆数でラベル付けが戻されることを意味します。 

より具体的に言えば、π はラベル 1 から n の隠れた名前変更です。 順列 f を適用すると、f 自体が表示されるのではなく、π によって引き起こされる隠れラベル付けシステムで表現された同じ順列が表示されます。 システムは π⁻¹ ◦ f ◦ π で応答します。 

タスクは、テスト ケースごとにこのようなクエリを最大 2 つ使用して、π を正確に再構成することです。 

構造上の重要な点は、π の値を直接学習しているのではなく、選択した順列を π がどのようにインデックスし直すかということです。 したがって、すべてのクエリは、ノイズや部分的な情報損失のない、送信したクエリのラベルを変更したバージョンである完全な置換を提供します。 

この制約により、n はテスト ケースごとに最大 104 まで許可され、テスト全体の合計も 104 によって制限されます。 これは、テストごとに線形または線形に近い推論を行う余裕はありますが、多くの候補順列を繰り返し実験したりシミュレーションしたりすることはできないことを意味します。 2 つの相互作用のみに制限されているため、解決策は 2 つの共役観測値から十分な全体構造を抽出する必要があります。 

単純なアプローチでは要素ごとに π を推測しようとしますが、単一のクエリは f の再ラベルされたバージョンしか返さないため、2 番目の独立した構造がなければ、これは不十分に決定されます。 もう 1 つの単純なアイデアは、恒等性をクエリすることですが、これは π に関係なく常に恒等性を返すため、まったく情報が得られません。 

単一の n サイクルなど、対称性が高すぎる f を選択すると、さらに微妙な失敗ケースが発生します。 その場合、π のすべての回転により、そのクエリのみに対して同一の観察可能な動作が生成されます。これは、絶対的な位置合わせを特定することができないことを意味します。 

## アプローチ

 重要な観察は、各クエリが隠れて完全なグラフ同型問題を与えるということです。 関係 g = π⁻¹ f π は、π がまさに f の有向関数グラフを g の関数グラフに変換する再ラベル付けであることを意味します。 すべてのノードには両方のグラフに出力エッジが 1 つだけあるため、各順列は有向サイクルの素の集合となります。 隠れた置換 π は、これら 2 つの有向サイクル分解間の同型写像です。 

クエリが 1 つだけの場合、問題は同じ長さのサイクルの一致に帰着しますが、各サイクルは任意に回転できるため、各サイクルは独立して未知の循環シフトを持ちます。 このため、単一のクエリでは不十分です。 

2 つのクエリにより、2 つの独立した関数グラフ f1 および f2 と、それらに対応する再ラベル付けされたバージョン g1 および g2 が得られます。 ここで、π は同時に両方のペア間の同型でなければなりません。 この 2 番目の構造は回転の自由度を取り除きます。これは、f1 のサイクル内で位置合わせが正しくないと、ほぼ確実に f2 との一貫性が損なわれるためです。 

強引なアイデアは、考えられるすべての順列 π を試し、両方の共役方程式を検証することです。 これには、n をチェックする必要があります。 それぞれの候補には O(n) 検証が必要ですが、これは完全に不可能です。 

最適なアプローチは、π を未知のラベルとして扱い、制約を伝播することです。 単一ノードの π を固定すると、両方のクエリで、その割り当てを他のすべてのノードにどのように拡張するかについての決定的なルールが得られます。 各ノードには各順列で出力エッジが 1 つだけあるため、既知の割り当てごとにさらに 2 つの割り当てが強制されます。 これにより、問題は 2n の有向エッジを持つグラフ上の決定論的伝播システムに変わります。

残る唯一の微妙な点は、初期化の正確さです。 π[1] を任意の有効な値に固定して伝播することができます。 構造が一貫していれば、最終的にはすべての割り当てが独自に安定します。 有効な π の存在により、一貫したシードから開始する場合、この伝播自体が矛盾しないことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n) | O(n) | 遅すぎる |
 | 2 つのクエリによる制約の伝播 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 慎重に選択した 2 つの順列 f₁ と f₂ をクエリとして使用します。 

1. すべての要素にわたって単一サイクルを形成する固定順列 f₁ (例: 1 → 2 → … → n → 1) を構築し、それをクエリして g₁ = π⁻¹ f₁ π を取得します。 これにより、π の下で同型である 2 つの対応するサイクル構造が得られます。 
2. 異なる構造、たとえば別の完全なサイクルまたは決定論的な構造化置換を使用して 2 番目の置換 f2 を構築し、それをクエリして g2 を取得します。 
3. 両方のクエリを、同じ未知の頂点の再ラベル付けに関する 2 つの有向グラフが得られると解釈します。 各ノード i は、π(f₁(i)) = g₁(π(i)) および π(f₂(i)) = g₂(π(i)) という 2 つの制約を同時に満たします。 
4. 任意の開始点を修正します。たとえば、π(1) = 1 と設定します。この選択では、等価な再ラベル付けの中から代表的なアライメントが選択されるだけですが、2 番目の並べ替えにより一意のグローバル拡張が強制されます。 
5. 決定されたノードのキューを維持します。 π(i) がわかっている場合はいつでも、π(f₁(i)) を g₁(π(i)) として直接計算でき、同様に π(f₂(i)) を g₂(π(i)) として計算できます。 新しく検出された割り当てはキューに追加されます。 
6. 新しい割り当てができなくなるまで伝播を続けます。 すべてのノードには 2 つの出力制約があり、π は全単射であるため、このプロセスは決定論的にすべての位置を埋めます。 
7. πを出力します。 

重要な考え方は、既知のマッピングはすべて、両方の関数グラフに強制的な結果を生み出すということです。 シードが固定されると、分岐の選択肢はありません。 

### なぜ効果があるのか

 伝播は、π が両方の置換に対して同時に満たさなければならない等式系を定義します。 有効な解 π は、関数グラフの 2 つのペア間の準同型性です。 単一のノードで π を固定すると、すべての出力エッジ制約によってその近傍のイメージが強制され、これらの制約はすべて同じ隠れた全単射から派生するため一貫性があります。 π は全単射であり、f1 と f2 は両方とも順列であるため、順方向マッピングを繰り返すことで最終的にすべてのノードに到達できるようになり、隠れた π の存在と矛盾せずに矛盾する値を割り当てる 2 つの伝播パスは存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())

        # query 1: simple cycle
        f1 = list(range(2, n + 1)) + [1]
        print("?", *f1, flush=True)
        g1 = list(map(int, input().split()))

        # query 2: another deterministic permutation (reverse cycle)
        f2 = [n] + list(range(1, n))
        print("?", *f2, flush=True)
        g2 = list(map(int, input().split()))

        pi = [-1] * (n + 1)
        pi[1] = 1

        from collections import deque
        q = deque([1])

        while q:
            i = q.popleft()

            ni = f1[i - 1]
            if pi[ni] == -1:
                pi[ni] = g1[pi[i] - 1]
                q.append(ni)

            ni = f2[i - 1]
            if pi[ni] == -1:
                pi[ni] = g2[pi[i] - 1]
                q.append(ni)

        print("!", *pi[1:], flush=True)

if __name__ == "__main__":
    solve()
```この実装では、伝播規則 π(fk(i)) = gk(π(i)) を直接エンコードします。 配列はクエリ順列と応答の両方の直接マッピングとして使用されるため、各伝播ステップは定数時間になります。 BFS は、すべてのインデックスが 1 回処理されることを保証し、作業の繰り返しを防ぎます。 

微妙な点の 1 つはインデックス付けです。f₁ と f₂ は 0 ベースの Python リストに格納されますが、π は 1 ベースなので、アクセスするたびに f から読み取ったり π に書き込むときにインデックスが注意深くシフトされます。 

## 実用的な例

 元のステートメントは対話型であるため、小規模で一貫したシナリオをシミュレートします。 

### 例 1

 n = 4、隠れた π = [4, 1, 3, 2] と仮定します。 π[1] = 1 に固定した後、伝播を追跡します。 

| ステップ | ノード i | π(i) | f₁(i) → π(f₁(i)) | f₂(i) → π(f₂(i)) |
 | --- | --- | --- | --- | --- |
 | 開始 | 1 | 1 | 2 → 決定 | 4 → 決定 |
 | 次へ | 2 | 4 | 3 → 決定 | 1 → 既知 |
 | 次へ | 4 | 2 | 1 → 既知 | 3 → 決定 |
 | 次へ | 3 | 3 | 4 → 既知 | 2 → 既知 |

 伝播後、すべてのノードが一貫して割り当てられ、π が完全に再構成されます。 

このトレースは、1 つのシードが固定されると、f1 エッジと f2 エッジを交互に適用することですべてのノードに到達可能になることを示しています。 

### 例 2

 n = 3 の場合、π = [3, 2, 1] と仮定します。 π[1] = 1 から再度開始します。 

| ステップ | ノード i | π(i) |
 | --- | --- | --- |
 | 開始 | 1 | 1 |
 | f₁の伝播 | 2 | 決定 |
 | f₂ 伝播 | 3 | 決定 |

 対称性の高い順列であっても、2 番目の制約により、サイクル全体にわたって曖昧さが持続することが防止されます。

## 特殊なケース

 まれなケースは、隠れた順列が単一のサイクルで構成されている場合です。 その状況では、単一のクエリでは同じサイクルの回転バージョンのみが明らかになり、完全な回転のあいまいさが残ります。 2 番目の制約セットは同じシフトの下では不変ではないため、アルゴリズムは 2 番目の置換に依存して回転を解除することでこれを回避します。 

もう 1 つのケースは、π 自体が恒等である場合です。 この場合、両方の応答がクエリと等しいため、伝播によって各ノードがそれ自体に自明に割り当てられます。 π[1] = 1 はすでに両方の制約システムとグローバルに一致しているため、アルゴリズムはこれを即座に処理します。 

最後のケースは、n が最小の場合です。 n = 3 の場合、すべての順列は依然としてサイクルまたはサイクルに近いものですが、各クエリが完全なマッピングを定義し、割り当てられていないノードがないことが保証されるため、伝播によってすべてのノードがアクティブ化されます。
