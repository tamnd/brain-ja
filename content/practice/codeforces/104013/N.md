 ## 問題の理解

 私たちは一連のバイナリ「スティック」を使用しています。各スティックは一連の長さです。`n`ここで、すべての位置はクォーツまたはオニキスです。 完成品であるヌンチャクは、2 本の棒を選択し、端と端を結合することによって形成されます。 各スティックは反転できるため、結合する前にそのシーケンスを通常または逆の順序で使用できます。 

顧客は、可能な最終的なヌンチャク構成、つまり任意の長さのバイナリ文字列を要求します。`2n`それは正確に含まれています`k`全部でオニキス。 ネイサンは、そのような有効な最終構成ごとに、ストックから 2 つのスティックを選択し、それらの連結が要求に正確に一致するようにそれらの向きを変える方法が存在するように、スティックのコレクションをストックしたいと考えています。 

タスクは、有効な長さのすべてのスティックが保管されるように、保管に必要なスティックの最小数を決定することです。`2n`正確なバイナリ文字列`k`構築することができます。 

制約`n ≤ 50`そして`k ≤ 2n`答えは構成を明示的に列挙することに依存できないことをすぐに示唆します。 全体を通して推論しようとするアプローチ`2n`文字列またはスティックのすべてのペアには、次のような指数関数的な構造が含まれます。`2^{2n}`可能性は、たとえ小規模であっても実現可能性をはるかに超えています。`n`。 

重要な問題は、1 本のスティックが単なる固定されたシーケンスではなく、反転対称性を持つオブジェクトであり、2 本のスティックは連結によってのみ相互作用することです。 要件は、すべてのターゲット文字列を普遍的にカバーすることですが、これは通常、長さの等価クラスがいくつあるかという質問になります。`n`バイナリ文字列を表現する必要があります。 

微妙なエッジケースが現れるのは、`k`非常に小さいか非常に大きいです。 たとえば、次のようなとき`k = 0`、有効なヌンチャクはすべてすべてゼロである必要があるため、すべてゼロのスティックが 1 つあれば十分です。 同様に、`k = 2n`、すべてが 1 つであり、必要なスティックは 1 つだけです。 これらの極端な結果は、答えが対称性に大きく依存するのではなく、対称性に応じて大きく崩れる可能性があることを示唆しています。`k`。 

## アプローチ

 直接的な総当たりアプローチでは、考えられるスティックのマルチセットをすべて列挙し、すべての有効なヌンチャク構成が何らかのペアから形成できるかどうかをテストしようとします。 固定用でも`n`、可能なスティックの数は`2^n`、そしてそれらのコレクションを選択すると、`2^{2^n}`可能なサブセット。 サブセットごとに、スティックのすべてのペアとすべての方向をチェックし、有効なすべてに対して検証します。`2n`-length 文字列では、別の指数係数が導入されます。 たとえ`n = 10`、これはすでに完全に実行不可能です。 

重要な観察は、「すべての有効な最終文字列を形成できる」という条件は、半分間の 1 の正確な分布に依存しないということです。 任意の長さ-`n`文字列は、1 の数に限り、有効なヌンチャクの左半分として出現できます。`x`満足する`0 ≤ k - x ≤ n`これは、一部のパートナーの半文字列に対して常に当てはまります。 すべての長さのバイナリ文字列なので、`n`一部の構造では半分として有効ですが、要件は事実上、可能なすべての長さをカバーすることになります。`n`反転対称までのバイナリ文字列。 

これは、問題を古典的な表現の問題に変換します。つまり、長さのすべてのバイナリ文字列が一致するような最小の代表セットを選択しています。`n`は、選択されたスティックまたはその逆のいずれかに等しい。 の値`k`どのスティックにも総数条件を満たす互換性のあるパートナーが存在するため、必要な個々のスティックを制限しません。 

したがって、このタスクは、ある長さのバイナリ文字列の同値クラスをカウントすることに帰着します。`n`逆転中。 

各文字列は、その逆の文字列とペアを形成するか、回文形式になります。 答えは、明確な反転軌道の数です。

 ## アルゴリズムのチュートリアル

 長さの異なるバイナリ文字列の数を計算します。`n`同値関係の下では、「文字列はその逆に等しい」となります。 

1. 同じ長さのバイナリ文字列をすべてカウントします。`n`、つまり`2^n`。 
2. 回文でないものと回文であるものの 2 つのタイプに分割します。 
3. すべての非回文文字列はその逆とのペアを形成するため、そのような各ペアは正確に 1 つの代表に寄与します。 
4. 回文文字列は反転の下で固定され、それぞれが 1 つの代表に寄与します。 
5. 回文文字列を直接カウントします。 バイナリ文字列は最初の文字列によって決定されます。`ceil(n/2)`ポジションがあるので、`2^{ceil(n/2)}`回文文字列。 
6. 2 つの寄与を結合します。各非回文ペアは 1 つの要素に寄与し、回文は個別に寄与します。 これにより、反転時の標準的な軌道公式が得られます。`answer = (2^n + 2^{ceil(n/2)}) / 2`。 

### なぜ効果があるのか

 Reversal は、長さのすべてのバイナリ文字列のセットに対するインボリューションを定義します`n`。 すべての文字列は固定されているか (回文)、2 要素の軌道に属しています。`{s, reverse(s)}`。 有効なストレージ セットには、ヌンチャクの可能なすべての半分を再構築するために、軌道ごとに少なくとも 1 つの代表が含まれている必要があります。 任意の半分は、グローバル条件を満たす有効な反対側の半分と常にペアになることができるため、`k`制約がある場合、追加の制限はなく、必要な代表者のセットが減ります。 したがって、最小ストレージはまさに反転軌道の数になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())

    # total strings of length n
    total = 1 << n

    # palindromic strings determined by first ceil(n/2) bits
    half = (n + 1) // 2
    pal = 1 << half

    # number of orbits under reversal
    ans = (total + pal) // 2

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、軌道カウント式が直接適用されます。 唯一の微妙な点は、回文文字列の数を正しく計算することです。`(n + 1) // 2`、後半は対称性によって決定されるため。 Python は大きな整数を自然に処理するため、整数演算は安全です。`n ≤ 50`値を範囲内に十分に保ちます。

 ## 特殊なケース

 のために`k = 0`、すべての有効なヌンチャクはすべてゼロであるため、どのソリューションでもその単一の構成を形成できる必要があります。 アルゴリズムは依存しません`k`, したがって、同じ構造的な軌道数を返します。 たとえば、次のようなとき`n = 3, k = 0`、公式はまだ与えます`(8 + 4) / 2 = 6`これは、最終的に 1 つの完全な構成のみが使用される場合でも、すべての半分をカバーするために必要なスティック代表の数に対応します。 

のために`k = 2n`、有効な構成はすべて 1 ですが、ここでも同じ理由が当てはまります。 ストレージ要件は、どの完全な文字列が有効であるかによって決まるのではなく、有効なペアに参加できるすべての可能なハーフ構成を実現できるかどうかによって決まります。 

次のような回文文字列の場合`n = 4`、のような文字列`1001`は反転時に固定され、軌道カウントで 1 回だけカウントされます。 アルゴリズムは、このケースを次のように自然に処理します。`2^{ceil(n/2)}`代表者を過大に数えたり欠落したりしないようにします。
