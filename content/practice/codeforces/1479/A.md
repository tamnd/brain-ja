 ## 解決策
 ## 問題の理解

 1 から 1 までの整数の隠れた順列で極小値を見つけるように求められます。$n$。 順列とは数字を並べ替えることです$1$に$n$繰り返しなしで。 極小値はインデックスです$k$の値が$a_k$配列は概念的に両端で無限大の境界があることを理解した上で、隣接する配列よりも厳密に小さくなります。 言い換えると、$a_0 = a_{n+1} = +\infty$したがって、最初と最後の要素がその単一の隣接要素よりも小さい場合、それらも極小値になる可能性があります。 

順列は事前にわかりません。情報を取得する唯一の方法は、「? i」形式の対話型クエリを使用することです。$a_i$。 最大 100 個のクエリで極小値を見つける必要があります。 と$n$まで$10^5$クエリには厳しい制限があるため、要素を線形に検査するソリューションは最悪の場合、遅すぎます。 単純なスキャンには最大で$n$クエリは受け入れられません。 

明らかではないエッジ ケースは、配列の境界で発生し、極小値が中央付近に現れ、徐々に減少または増加する値に囲まれている場合に発生します。 たとえば、次の場合$n=3$そして配列は$[2,1,3]$、最小値はインデックス 2 です。境界を正しく処理しない不注意な二分探索では、配列の外側でクエリを実行したり、極小値を見逃したりする可能性があります。 もう 1 つのエッジ ケースは、最初または最後の要素が極小値である場合です。たとえば、$[1,3,2,4]$ここで、インデックス 1 は有効な極小値です。 

## アプローチ

 ブルート フォース アプローチは単純です。1 から 2 までの各インデックスをクエリします。$n$そして、近隣のものと比較して、それが極小値であるかどうかを確認します。 すべての順列には少なくとも 1 つの極小値があるため、この方法では解が見つかることが保証されていますが、時間がかかる場合があります。$O(n)$クエリが 100 の制限を超えると、$n > 100$。 

重要な洞察は、配列が順列であるため、等しい 2 つの要素はないということです。 これにより、より高い値からより低い値への移動が常に極小値に向かうことが保証されます。 真ん中のインデックスを選択すると$m$そしてクエリ$a_m$隣接するものと合わせて、3 つのケースが発生します。$a_m$両方の隣よりも小さい場合、それは極小値です。 左の近傍が小さい場合、極小値は左半分に存在し、右の近傍についても同様です。 これにより、バイナリ検索戦略が可能になります。つまり、現在のセグメントの中央を繰り返しクエリし、値が減少する方向に検索間隔を狭めます。 検索間隔は毎回半分になるため、次の極小値が見つかります。$O(\log n)$クエリ数は、最大値であっても 100 クエリの制限を大幅に下回っています。$n$。

 ## アルゴリズムのチュートリアル

 1. 1 から 1 までのインデックスの全範囲から開始します。$n$。 左ポインタを維持します`l`そして右ポインタ`r`現在の検索範囲を定義します。 
2. その間`l <= r`、中央のインデックスを選択します`m = (l + r) // 2`。 クエリ$a_m$。 それを比較するには、隣人が必要かもしれません$a_{m-1}$そして$a_{m+1}$。 もし$m$が境界にある場合、欠落している近傍を無限大として扱います。 
3. もし$a_m$隣の両方よりも小さい場合は、すぐに報告してください`m`を極小値として計算して終了します。 これは、極小値を直接チェックするものです。 
4. 左隣がより小さい場合$a_m$、検索間隔を左半分に移動します: set`r = m - 1`。 これが機能するのは、局所最小値が減少する傾きに存在する必要があるためです。 
5. それ以外の場合は、検索間隔を右半分に移動します: set`l = m + 1`。 右隣が小さい場合、極小値は残りの半分に存在する必要があります。 
6. 極小値が見つかるまで繰り返します。 検索間隔は各反復を半分にするため、アルゴリズムは最大で 2 時間以内に完了します。$\log_2 n$クエリ、100 をはるかに下回る$n \le 10^5$。 

機能する理由: すべてのステップがより小さい近傍に向かって移動し、局所最小値に向かって減少するパスをたどることが保証されます。 配列は個別の要素の順列であるため、プラトーに陥ることはありません。 左端または右端の要素は暗黙的な無限として機能するため、境界は自然に処理されます。 これにより、常に次の範囲内で極小値が見つかることが保証されます。$O(\log n)$クエリ。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def query(i):
    print(f"? {i}", flush=True)
    return int(input())

def find_local_minimum(n):
    l, r = 1, n
    while l <= r:
        m = (l + r) // 2
        am = query(m)
        if m == 1:
            left = float('inf')
        else:
            left = query(m - 1)
        if m == n:
            right = float('inf')
        else:
            right = query(m + 1)
        if am < left and am < right:
            print(f"! {m}", flush=True)
            return
        elif left < am:
            r = m - 1
        else:
            l = m + 1

n = int(input())
find_local_minimum(n)
```機能`query(i)`インタラクティブなクエリと出力のフラッシュを処理します。 範囲外の近傍に無限大を割り当てることで境界を明示的にチェックします。 各反復で、アルゴリズムは最大 3 つのインデックス (中央とその 2 つの近傍) をクエリし、クエリ制限を超えないようにします。 決定ロジックは、減少する傾き特性を使用して、保証された極小値に向かって移動します。
