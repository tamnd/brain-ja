 ## 問題の理解

 この問題により、それぞれ厳密に以下の整数係数を持つ最大 10 次の隠れ多項式が得られます。$10^6 + 3$。 タスクは整数を見つけることです$x_0$多項式がゼロモジュロとして評価されるようにする$10^6 + 3$。 係数を直接見ることはできません。 代わりに、最大 50 個の整数入力をクエリし、対応する多項式値のモジュロを受け取ることでシステムと対話できます。$10^6 + 3$。 解決策が存在しない場合は報告する必要があります$-1$。 

素数係数$10^6 + 3$は、必要に応じて徹底的な演算を実行できるほど十分に小さいですが、多項式の次数は低いため、多項式を再構築したり、その根を効率的に推論したりできることが示唆されます。 係数は法の下に制限されているため、素数を法とするすべての評価により、その時点での多項式に関する完全な情報が得られます。 

エッジケースは微妙です。 不用意なアプローチは、ランダムな値をクエリしてゼロを期待することです。 たとえば、多項式が次の場合、$f(x) = 1 + x^{10}$、0 をクエリすると 1 が返され、1 をクエリすると 2 が返されますが、実際のルートは次のように大きい可能性があります。$x = 10^6 + 2$。 アルゴリズムでは、根が小さいことや、最初のいくつかの整数の中にゼロが現れることを想定してはなりません。 別のケースは、次のような定数多項式です。$f(x) = 0$素数を法とする、自明にすべての根を持ちます。 逆に、$f(x) = c \neq 0$素数のモジュロには根がありません。 

## アプローチ

 素朴なアプローチは、すべてを試してみることです$x$0 からモジュラスまで。 各評価は定数時間であるため、理論的には機能しますが、係数は$10^6 + 3$したがって、ブルート フォースには 100 万を超えるクエリが必要となり、許可されている 50 クエリをはるかに超えています。 このアプローチは正しいですが、明らかに非現実的です。 

重要な洞察は、次数が最大 10 の多項式は、素数を法とする 11 の異なる点の値によって一意に決定されるということです。 11 点の値がわかったら、モジュラー演算のラグランジュ補間を使用して多項式を再構成できます。 再構築後、すべてをテストしてルートを見つけることができます。$x$素数を法として計算しますが、次数 10 が小さいため、あらゆる点での多項式の評価を最適化できます。 

ブルート フォースは次数の限界を無視するため失敗しますが、多項式再構成アプローチでは素数を法とする 10 次の多項式を決定するには 11 点で十分であるという事実を利用します。 多項式を完全に理解したら、0 から 0 までをすべてチェックすることで根を見つけるのは簡単です。$10^6 + 2$または、素数を法とする小次多項式の効率的な根探索を使用します。

 ## アルゴリズムのチュートリアル

 1. 11 個の異なる点 (0、1、2、…、10) で多項式をクエリします。その理由は、10 次多項式は素数を法とする 11 点によって一意に定義されるためです。 各クエリは次の値を返します。$f(x_i)$。 
2. ラグランジュ補間モジュロを使用する$10^6 + 3$多項式の係数を再構築します。 モジュラー逆変換は、法が素数であるため、ラグランジュの公式の分母で使用され、逆元が存在することが保証されます。 
3. すべての整数を反復処理します。$x$0から$10^6 + 2$。 再構築された多項式をそれぞれの位置で評価します。$x$モジュロ$10^6 + 3$。 次数が最大 10 であるため、ホーナー法を使用すると各評価が高速になります。 
4. 評価の結果、素数を法としてゼロが得られた場合、出力$x$根として。 評価がゼロの場合は報告する$-1$。 
5. インタラクション要件を満たすために、各クエリの後にフラッシュします。 

機能する理由: 多項式は、素数を法とする 11 点によって一意に決定されます。 再構築したら、任意の位置で多項式を評価します。$x$素数のモジュロは真の値を生成します。 サイズフィールド全体を反復処理するため、$10^6 + 3$、任意のルートが見つかります。 このアルゴリズムは、素数を法として正しいことが保証されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**6 + 3

def modinv(a, p):
    return pow(a, p-2, p)

def lagrange_interpolation(x_values, y_values, mod):
    k = len(x_values)
    coeffs = [0] * k
    for i in range(k):
        xi, yi = x_values[i], y_values[i]
        numerator = [1]
        denom = 1
        for j in range(k):
            if i == j:
                continue
            xj = x_values[j]
            denom = denom * (xi - xj) % mod
            numerator = poly_mul(numerator, [-xj % mod, 1], mod)
        inv_denom = modinv(denom, mod)
        for d in range(len(numerator)):
            coeffs[d] = (coeffs[d] + numerator[d] * yi * inv_denom) % mod
    return coeffs

def poly_mul(a, b, mod):
    res = [0] * (len(a) + len(b) - 1)
    for i in range(len(a)):
        for j in range(len(b)):
            res[i+j] = (res[i+j] + a[i]*b[j]) % mod
    return res

def eval_poly(coeffs, x, mod):
    res = 0
    for c in reversed(coeffs):
        res = (res*x + c) % mod
    return res

x_values = list(range(11))
y_values = []

for x in x_values:
    print(f"? {x}")
    sys.stdout.flush()
    y = int(input())
    y_values.append(y)

coeffs = lagrange_interpolation(x_values, y_values, MOD)

for x in range(MOD):
    if eval_poly(coeffs, x, MOD) == 0:
        print(f"! {x}")
        sys.stdout.flush()
        sys.exit(0)

print("! -1")
sys.stdout.flush()
```このソリューションでは、まず 11 個の点をクエリして多項式を再構築します。`lagrange_interpolation`逆モジュラーを使用して素数を法として係数を効率的に計算します。`eval_poly`Horner の方法を使用して迅速な評価を行います。 フィールド全体を反復処理することで、ルートが確実に見つかります。 すべての出力は、対話プロトコルに準拠するためにフラッシュされます。 

## 実用的な例

 補間後の多項式は次のようになります。$f(x) = 1000002 + x^2$。 0 を評価すると 1000002 が得られ、1 を評価すると 0 が得られるため、ルートは 1 になります。
