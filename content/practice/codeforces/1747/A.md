 ## 解決策
 ## 問題の理解

 一連の整数が与えられたので、それを 2 つの互いに素なグループに分割する必要があります。 すべての要素は 1 つのグループに入れる必要があり、両方のグループが空であってもかまいません。 

分割が修正されたら、各グループの合計を計算します。 次に、各合計の絶対値を取得し、これら 2 つの大きさの差を調べます。 目標は、考えられるすべてのパーティションにわたってこの差を最大化することです。 

主な困難は、単純な線形和を最適化するのではなく、絶対値の差を最適化するため、目的が 2 つのグループ間で正の数と負の数がどのように分布するかに敏感になることです。 

制約は大きく、最大で\(2 \cdot 10^4\)テストケースと配列の合計長は最大\(2 \cdot 10^5\)。 これにより、二次またはサブセットの列挙アプローチが即座に除外されます。 どのソリューションでも、各テスト ケースを線形時間で処理する必要があります。 

よくある落とし穴は、式を文字通りに解釈しすぎて、要素を 2 つの累計に貪欲に割り当てようとすることにあります。 これは、符号を混合するときに失敗することがよくあります。 

たとえば、常に次の要素を現在より小さい絶対和グループに入れることで和のバランスを取ろうとする素朴なアイデアを考えてみましょう。 入力時```
[10, -10]
```たとえ最適な答えが明らかにあったとしても、これは注文と同点の処理に応じてすでに一貫性のない動作をする可能性があります。\(0\)。 

この式の構造は、正と負の数値の合計寄与のみが重要であり、それらを 2 つの任意のセットに配置することは重要ではないことを示唆しています。 

## アプローチ

 ブルートフォースソリューションでは、すべてが列挙されます。\(2^n\)要素を 2 つのグループに割り当てます。 割り当てごとに、両方のグループの合計を計算し、目標を評価します。 これは正しいですが、指数関数的に増加し、\(n = 30\)。 

重要な簡素化は、合計額と記号の分割方法の観点から目標を書き直すことで実現します。 

合計を\(S = \sum a_i\)。 どのパーティションもサブセットの選択に対応します\(A\)のために\(s_1\)、残りが形成される\(s_2\)。 それから$$
s_1 = \sum_{i \in A} a_i, \quad s_2 = S - s_1.
$$したがって、目的は次のようになります$$
|s_1| - |S - s_1|.
$$ここで、この式は距離にのみ依存することに注目してください。\(s_1\)からです\(S/2\)、しかし、という事実によって制約されます。\(s_1\)は、任意の符号付き値のサブセット合計です。 

分割について推論する代わりに、プラスの寄与とマイナスの寄与を分離します。 させて$$
P = \sum_{a_i > 0} a_i, \quad N = \sum_{a_i < 0} a_i.
$$最適な戦略は、すべての正の数を 1 つのセットにグループ化し、すべての負の数をもう 1 つのセットにグループ化することです。同じグループ内で符号を混合すると、絶対的な大きさが減少するだけであるためです。 

次に、2 つの極端な構成を比較します。 
すべての数値を 1 つのグループに入れるか、符号で分割します。 

すべてが 1 つのグループ内にある場合、値は次のようになります。$$
|S| - 0 = |P + N|.
$$ポジティブとネガティブを分けると、次のようになります。$$
|P| - |N|.
$$以来\(P \ge 0\)そして\(N \le 0\)、これは次のようになります$$
P - (-N) = P + |N|.
$$したがって、答えは単純に次の最大値になります。$$
|P + N| \quad \text{and} \quad P + |N|.
$$しかし\(P + |N| = \sum |a_i|\)、 その間\(|P + N|\)せいぜい\(\sum |a_i|\)したがって、2 番目のケースが常に優先または一致します。 したがって、最適な値は次のようになります。$$
\sum |a_i|.
$$これにより、問題全体が絶対値の合計に帰着します。

 |---|---|---|---|

 | 最適 | \(O(n)\) | \(O(1)\) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数の配列を読み取ります。 目的の構造により直接的な単純化が可能であるため、まだ分割は試みません。 

2. すべての要素の絶対値を計算し、それらの合計を累積します。 これは、符号に関係なく、各要素を目的に可能な最大の大きさに寄与するものとして扱うことに対応します。 

3. この合計をテスト ケースの答えとして出力します。 

### なぜ効果があるのか

 目的は、2 つのグループの合計の大きさの間の分離を最大化することによって報酬を与えます。 どの要素も少なくとも 1 つの側にプラスに寄与しており、プラスとマイナスの寄与の間のキャンセルを減らす方法で要素を割り当てても、達成可能な大きさが減少するだけです。 最適な構成では、各要素の寄与が絶対的な大きさの形式に分離されます。これは、グループ内でキャンセルが発生しないときに達成されます。 これは、グローバル最大値としての絶対値の合計に直接つながります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        out.append(str(sum(abs(x) for x in a)))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は簡単です。各テスト ケースは独立して処理され、不必要な中間構造の保存を避けます。 唯一の微妙な点は、ループ内での Python 文字列の出力が遅くなる可能性があるため、高速な入力とバッチ出力を確保することです。\(2 \cdot 10^4\)テストケース。

 完全にゼロで構成される配列の場合、すべてのパーティションは両方のグループでゼロ和を生成し、すべての絶対値がゼロであるため、アルゴリズムは正しくゼロを返します。 単一要素の配列の場合、答えは 1 つのグループの合計を完全に決定するため、その要素の絶対値と等しくなります。 大きな正の値と負の値が交互に現れる場合、各要素は絶対累積を通じて独立して処理され、キャンセル効果が結果に影響を与えるのを防ぐため、解は安定したままになります。
