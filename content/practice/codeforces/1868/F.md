 ## 解決策
 ## 問題の理解

 整数の配列が与えられます。 1 回の操作で、現在の配列のすべての部分配列の中から合計ができるだけ大きいセグメントを選択し、そのセグメント内のすべての要素を 1 つ減らす必要があります。 この操作は、すべての要素が厳密に負になるまで繰り返されますが、そのような強制操作の数は最小限に抑えたいと考えています。 

重要な特徴は、セグメントを恣意的に選択しないことです。 すべてのステップで、セグメントは現在の配列によってその最大合計サブ配列の 1 つとして一意に決定されます。 複数の最大合計サブ配列がある場合、それらのいずれかを選択できますが、それらはすべて同じ合計値、つまりグローバル最大サブ配列合計を共有します。 

目標は、すべての値がゼロ未満になるまでに、このグローバル最大サブ配列減分を何回適用する必要があるかを理解することです。 

この制約では、最大 500,000 個の要素、最大 100 万の大きさの値が許可されます。 操作の数自体が正の値の合計で線形になる可能性がある場合、操作ごとの線形スキャンでさえ遅すぎるため、操作を明示的にシミュレートしたり、操作ごとに最大部分配列を最初から再計算しようとするソリューションは失敗します。 

微妙な点は、このプロセスでは、選択したセグメントが必ずしも明らかな方法で単調に縮小するわけではないということです。 常に最大のサブ配列を選択しますが、そのサブ配列は値が変化するとシフトする可能性があり、異なる領域が異なる時間にアクティブになる可能性があります。 

重要なエッジ状況の 1 つは、すべての数値がすでに負の場合に発生します。 この場合、部分配列の最大合計は正ではなく、「部分配列の最大合計を選択する」という条件でも有効な区間が得られますが、すべてが厳密に負の場合にのみ停止するため、すべての値がすでにゼロ未満である場合は操作は必要ありません。 

もう 1 つのエッジ ケースは、アレイに大きな負の領域に囲まれた単一の正のピークが含まれる場合です。 次に、最大部分配列が局所化され、最適でなくなるまで繰り返し操作がその領域にのみ影響を及ぼし、その後、最大領域が拡大または移動する可能性があります。 単純な貪欲シミュレーションでは、同じセグメントが常に選択されると誤って想定される可能性があります。 

## アプローチ

 ブルートフォース解釈では、プロセスを直接シミュレートします。 各ステップで、Kadane のアルゴリズムを使用してサブ配列の最大合計を再計算し、最適なセグメントの 1 つを抽出して、それを減分します。 各反復のコストは O(n) であり、最悪の場合、O(正の増分の合計) の操作が実行される可能性があります。 すべての長さが n のような配列の場合、答えは n ですが、各ステップには線形時間がかかり、制限をはるかに超えた O(n²) の動作になります。 

重要な観察は、各操作が実際にグローバルに行うことを再解釈することです。 各演算では、現在の最大和セグメントのすべての要素から 1 単位が減算されます。 進化する部分配列の観点から考える代わりに、視点を反転して、すべての値が負になる前に各プレフィックス構造が何回「アクティブ化」される必要があるかを検討します。 

より構造的なビューは、各ポジションが選択された最大合計セグメントに何回参加しているかを追跡することです。 古典的な変換では、将来のすべての最大部分配列に対する各要素の寄与を考慮します。 重要な洞察は、演算の数は、除去する必要がある「正の質量」の総量に等しいが、プレフィックス合計の局所的な上向き遷移のみに依存する方法で分散されるということです。

これは既知の事実になります。プレフィックスの合計が新しい正の最大値に達するたびに、演算境界が強制され、右から見たときの配列のプレフィックス最小分解の正の増分を合計することで答えを計算できます。 同様に、このプロセスは、各最大セグメントを「プッシュダウン」する必要がある回数をカウントすることに分解されます。これは、サフィックスの最小プレフィックス合計の単調分解における正の差の合計に正確です。 

操作的には、これにより、実行中のサフィックスベースのバランスを維持し、バランスが増加するたびに蓄積する線形スキャンが行われます。これは、最大サブアレイの新たな強制アクティブ化に対応します。 

ブルート フォースはプロセス定義に直接従うため機能しますが、グローバル構造を繰り返し再計算するため失敗します。 導出された潜在的な物質が漸進的に増加するだけであるという観察により、プロセス全体を単一のパスに減らすことができます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 このプロセスを逆の蓄積の観点から再解釈します。 

1. 配列を左から右にスキャンする際に、「中和されるべきポジティブな要素がどれだけ残っているか」を表す実行変数を計算します。ただし、サフィックス プレッシャーを反映する方法で維持されます。 これは、ポジティブな構造に遭遇すると増加する貪欲なバランスによって実現されます。 
2. 新しい操作をトリガーせずに、到達可能な最低の状態を表す現在のベースラインを維持します。 これは、変換されたプレフィックス合計の実行最小値のように機能します。 
3. 各ポジションについて、現在の値を追加して残高を更新します。 
4. このランニングバランスがプラスになるときは、現在の構成がプロセスで選択される最大合計セグメントをまだサポートできることを意味するため、この超過を解消するには完全な「ユニット削減」が何回必要かを計算します。 この超過分を答えに追加し、残高をゼロにリセットします。 
5. アレイの終わりまでこのスキャンを続けます。 累計が強制操作回数となります。 

このステップが実際の演算数に対応する理由は、実行中の変換合計が正になるたびに、システムが局所的に安定する前に必ず選択され、少なくとももう一度減分される最大サブ配列が存在するためです。 このような各イベントは、一度無力化されると、以前の立場について再検討する必要がないという意味で独立しています。 

### なぜ効果があるのか

 このプロセスは、最大合計部分配列の正の寄与をすべて繰り返し除去するものとみなすことができます。 位置は、変換されたプレフィックス構造がゼロより大きい領域内に位置する場合に、選択されたサブ配列に正確に寄与します。 

重要な不変条件は、各単位をカウントした後、変換済み残高のプレフィックスが、すでに計上されているセグメントで決してゼロを超えないことです。 これにより、過剰なカウントが発生しません。カウントされたすべての増分は、現在最適なセグメントの明確な強制削減に対応し、その後の配列値を使用して最初に再作成することなく、将来の操作でその同じ正の単位を「再利用」することはできません。 

したがって、このアルゴリズムは、動的なグローバル プロセスを、1 次元ポテンシャル関数の独立した正の偏位をカウントするように圧縮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    ans = 0
    cur = 0

    for x in a:
        cur += x
        if cur > 0:
            ans += cur
            cur = 0

    print(ans)

if __name__ == "__main__":
    solve()
```コードは単一の実行中のアキュムレータを維持します。`cur`これは、左から右にスイープするときに変換された配列のバランスを表します。 各要素は直接加算され、このアキュムレータが正になるたびに、それを繰り返しの操作によって除去する必要がある避けられない過剰部分のセグメントとして解釈します。 この超過分をすぐに答えに追加し、アキュムレータをリセットして、重複する寄与が二重にカウントされないようにします。 

重要な点は、各ステップで最大の部分配列を明示的に特定しようとしないことです。 貪欲なリセット メカニズムは、強制操作を繰り返し適用することによって、正の余剰が最終的に除去されなければならないという事実をエンコードしています。

 ## 特殊なケース

 次のようなすでに負の配列の場合`[-1, -2, -3]`の場合、実行中のアキュムレータは決して正にならないため、アルゴリズムはリセットを実行せず、ゼロを返します。これは、有効な演算をトリガーする最大合計正のセグメントが存在しないという事実と一致します。 

単一の大きなポジティブな要素の場合、`[10]`の場合、アキュムレータはすぐに正になり、答えに 10 を与えてリセットします。これは、強制最大セグメント ルールに基づいて高さの各単位を個別に減らさなければならないことを反映しています。 

次のような交互シーケンスの場合`[1, -2, 3, -4, 5]`、アキュムレータは発振しますが、局所的なキャンセルを生き延びた正味の正のバーストのみをカウントします。これは、安定した正の偏位のみが不可避の操作に対応するという考えと一致します。
