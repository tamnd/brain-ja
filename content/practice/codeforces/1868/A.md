 ## 問題の理解

各列について、下方向に見て、その列の MEX を計算します。 これにより配列が生成されます$v$長さの$m$。 最後に、この列 MEX 配列の MEX を計算します。これを行列の美しさと呼びます。 タスクは、順列を行に配置する方法を選択して、この最終的な MEX を最大化することです。 

重要な相互作用は、MEX の 2 つのレベル間で行われます。 内部 MEX は値が列内にどのように分散されるかに依存しますが、外部 MEX は小さな整数が列全体にどの程度「均一に存在する」かに依存します。 

制約により、最大で次のことが許可されます。$2 \cdot 10^5$すべてのテストにわたるセルの合計であるため、すべての解は行列サイズにおいて線形である必要があります。 二次関数の何か$m$テストケースごとには不可能です。 

単純なアプローチでは、順列を任意に割り当て、列の MEX 値を直接計算しようとします。 これは、誤ってすべての列に小さな値が表示され、列の MEX 値が途中で折りたたまれる可能性があるため、簡単に問題が発生する可能性があります。 

たとえば、すべての行で同一の順列を繰り返し使用すると、すべての列にまったく同じマルチセットが含まれます。 その場合、多くの列 MEX 値が同一で小さくなり、最終的な答えが制限されます。 構造では、一部の列が初期の数値を見逃すように、意図的に値をずらす必要があります。

 ## アルゴリズムのチュートリアル

 1. 答えを次のように計算します。$\min(n, m)$。 これは、使用可能な行または列の数を超えるすべての値をすべての列に強制的に含めることはできないという事実から生じます。 
2. 各行を基本配列の巡回シフトとして構築します。$[0, 1, \dots, m-1]$。 行$i$価値を置く$j$位置で$(j + i) \bmod m$。 
3. すべての行を出力します。 

この構築の背後にある理由は、巡回シフトにより列全体ですべての数値が一様に分散されることが保証されるためです。 各値は行ごとに 1 回だけ表示され、行全体ですべての列位置を均等に循環します。 

### なぜ効果があるのか

 重要な不変条件は、固定列に対する不変条件です。$c$、その列の値のマルチセットは、行インデックスのモジュロをシフトしたシーケンスです。$m$。 これにより、最初の$\min(n, m)$値をすべての列に含めると、使用可能な行全体で少なくとも 1 回は必要な値がすべて含まれるため、早期の MEX 崩壊が防止されます。 この範囲を超えると、少なくとも 1 つの列で一部の値が欠落している必要があり、外部 MEX が制限されます。 したがって、この構造は、完全に「カバーされた」値の可能な最大の接頭辞と厳密に一致します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        
        ans = min(n, m)
        print(ans)
        
        for i in range(n):
            row = [(j + i) % m for j in range(m)]
            print(*row)

if __name__ == "__main__":
    solve()
```コードは循環シフト構造を直接実装します。 各行は独立して生成されるため、列の追跡や MEX 計算の必要がなくなります。 

印刷された答えは証明された最適値です$\min(n, m)$これは、すべての列 MEX 計算に強制できる整数の最大プレフィックスに対応します。 

モジュロ シフトにより、各行が有効な置換であることが保証され、列全体の均一性が維持されます。これは、最終的な MEX を最大化するための中心的な要件です。

import sys, io

def run(inp: str) -> str:

 ## 特殊なケース

 いつ$n = 1$の場合、行列は単一の順列であるため、すべての列に 1 つの値が含まれ、すべての列の MEX 値は 1 になります。したがって、外側の MEX は 1 となり、巡回構造は恒等順列に正しく縮退します。 

いつ$m = 1$、すべての行は次のようにする必要があります$[0]$。 各列にはゼロのみが含まれているため、列 MEX は 1 で、最終的な答えは 1 です。この構築では、当然のことながらゼロの列が出力され、境界と一致します。 

いつ$n$大きいですが$m$が小さく、循環シフトが繰り返されることで、各列がすべての値を迅速に循環することが保証され、どの列も少なくとも 1 つの値が行間で繰り返されるという制約から逃れることができないため、構造の一貫性が維持され、最終的な MEX の意図しないインフレが防止されます。
