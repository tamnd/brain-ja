 ## 解決策
 ## 問題の理解

 私たちは一辺の長さの正方形のビリヤード台を与えられました$s$四隅にポケット付き。 このテーブルの上には、$n$ボールは厳密にテーブル内の整数座標に配置され、決して端や隅には配置されません。 各ボールは、ベクトルで指定された 4 つの対角方向のいずれかに 45 度の角度で同時に発射されます。$(d_x, d_y)$ここで、各成分は 1 または -1 です。 ボールは無限に速く動きますが、完全な弾性反射に従います。ボールが壁に当たると、同じ角度で跳ね返されます。 最終的に四隅のいずれかにボールが何個落ちるかを数える必要があります。 

各テスト ケースが提供するのは、$n$ボールとその初期位置と方向ベクトル。 出力は、最終的にコーナーに到達するボールの数です。 

制約が教えてくれる$n$最大1000まで可能です。$s$まで可能です$10^9$。 の合計$n$すべてのテスト ケースで最大 1000 です。これは、余裕があることを意味します。$O(n)$テストケースごとに解決策を講じるので、ボールの動きを段階的にシミュレートする必要はありませんが、これは不可能です。$s$この大きさ。 すべての座標と方向は整数なので、完全に整数演算で推論できます。 

明らかではないエッジケースは、ボールが壁に向かって移動し、何度か反射した後でのみコーナーに到達する場合に発生します。 たとえば、ボール$(1,1)$移動中$(1,-1)$2×2 テーブル上で、上と右側の壁に跳ね返り、最終的に角に落ちます。 最初の動きだけをシミュレートしたり、反射がないと仮定したりする単純なアプローチでは、これらのボールを誤って見逃してしまいます。 

## アプローチ

 強引な方法では、ボールが角に当たるか任意の制限を超えるまで、壁に反射しながら軌道に沿って移動する各ボールをシミュレートします。 反射ごとに、その位置と方向を更新します。 ただし、$s$と同じくらい大きい$10^9$の場合、ボールはコーナーに到達するまでに何度もバウンドする可能性があるため、このシミュレーションは遅すぎます。 

重要な洞察は、ボールが 45 度の角度に沿って移動し、反射が完璧であるため、各軸のボールの経路が周期的モジュロであるということです。$2s$。 言い換えれば、反射をテーブルの延長として想像することによって、テーブルを「展開」することができます。テーブルの鏡映コピーを繰り返し横切って斜めに移動するボールは、その傾き ±1 の線に沿ってある最初の角にぶつかります。 これにより、問題は単純なチェックに集約されます。$(x, y)$方向性あり$(d_x, d_y)$、場合に限り、最終的にはコーナーに到達します。$(s - x) \cdot d_y = (s - y) \cdot d_x$モジュロ$2s$。 さらに単純化すると、座標は整数で角が 4 つしかないため、壁に到達するまでに各方向に何歩必要か明示的に計算し、反射の数によって正確に角に到達するかどうかを確認できます。 これは、位置をループすることなく、単純な算術を使用して行うことができます。 

最適解は、ボールごとに、両方の軸に沿って 0 または s に達するまで x および y に沿った移動回数を計算し、それらが時間内に一致するかどうかを確認します。 動きは 1:1 の傾きで対角にあるため、x 軸と y 軸に沿った反射の数が両方とも偶数であるか、両方とも奇数であり、境界に到達するために必要な反射のパリティに対応する場合、ボールはコーナーに着地します。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$そして$s$。 ポットされたボールのカウンターを初期化します。 
2. 各ボールの開始座標を読み取ります。$(x, y)$そして方向$(d_x, d_y)$。 方向に応じて、x 方向と y 方向の両方で最も近い壁までの距離を計算します。 もし$d_x = 1$、右側の壁までの距離は$s - x$、それ以外の場合、左の壁までの距離は$x$。 y についても同様です。 
3. 角に到達するまでに x と y に沿って何回反射が必要かを計算します。 反射するたびに方向が反転するため、角に到達するまでの x に沿った合計距離は次の倍数でなければなりません。$s$。 同様にyに沿って進みます。 
4. 壁に到達するのに必要な x 軸と y 軸に沿った反射の数が同じであれば、ボールは最終的に角に到達します。 その場合はカウンタをインクリメントします。 
5. すべてのボールを処理した後、テスト ケースのカウンターを印刷します。 

重要な不変条件は、ボールが壁に当たった後、各軸に沿って方向を変えるということです。 初めて壁に到達したときの位置のモジュロ$s$は 0 または s に一致し、動きは 45 度であるため、x 軸と y 軸に沿った時間は壁の距離の整数倍で一致する必要があります。 パリティをチェックすると、コーナーでの位置合わせが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def will_pot(x, y, dx, dy, s):
    # distance to next wall along x
    if dx == 1:
        dist_x = s - x
    else:
        dist_x = x
    if dy == 1:
        dist_y = s - y
    else:
        dist_y = y
    # ball reaches a corner if dist_x % s == dist_y % s
    return dist_x % s == dist_y % s

t = int(input())
for _ in range(t):
    n, s = map(int, input().split())
    count = 0
    for _ in range(n):
        dx, dy, x, y = map(int, input().split())
        if will_pot(x, y, dx, dy, s):
            count += 1
    print(count)
```機能`will_pot`ボールの方向の壁までの距離を計算し、それが他の軸に沿った距離と一致しているかどうかを確認します。 ボールは斜めに移動するため、これらの距離が等しい角にのみ到達します。$s$。 これにより、反射のシミュレーションが回避され、$O(1)$ボールごとに。
