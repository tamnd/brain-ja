 ## 問題の理解

 軸が揃った 3 つの長方形が与えられます。 それらの寸法はすでに順序付けされているため、$$l_3 \le l_2 \le l_1$$そして$$b_3 \le b_2 \le b_1.$$長方形は回転できません。 3 つの長方形すべてを重なり合わずに配置して、正確に 1 つの正方形を形成できるかどうかを判断する必要があります。 

ディメンションは小さく、最大 100 です。テスト ケースの数は最大 100 です。これは、高度な最適化が必要ないことを意味します。 すべてのテスト ケースで少数の幾何学的構成をチェックする場合でも、事実上一定時間かかります。 

主な困難はパフォーマンスではなく、回転できない 3 つの長方形を組み合わせて正方形にするあらゆる可能な方法を特定することです。 

よくある間違いは、総面積が完全な正方形であるかどうかのみを確認することです。 等しい面積は必要ですが、十分とは言えません。 

考慮する：```
1
3 3 3 3 2 1
```総面積は$$9+9+2=20,$$これは正方形ではないので、答えは明らかに NO です。 

さらに微妙な例として、領域は正方形だが配置が不可能な場合があります。 

例えば：```
1
8 5 3 5 3 3
```総面積は$$40+15+9=64=8^2.$$不注意な解決策は、すぐに「YES」と答える可能性があります。 正解は「いいえ」です。辺の長さの関係で、長方形をタイル状に並べることはできないからです。$8 \times 8$四角。 

もう 1 つの見落としやすいケースは、3 つの長方形すべてを一方向に積み重ねる必要がある場合です。```
1
5 3 5 1 5 1
```幅はすべて同じです。 それらを上下に置くと、$5 \times 5$正方形なので、答えはYESです。 より複雑なレイアウトのみを検索するソリューションでは、このケースは誤って拒否されます。 

## アプローチ

 強引な考え方は良い出発点です。 長方形が 3 つしかないため、グリッド上のすべての可能な相対位置を列挙し、和集合が正方形を形成するかどうかを確認してみることができます。 

すべての有効な取り決めが最終的にテストされるため、このような検索は正しいでしょう。 問題は、幾何学的配置により多くの座標と重複チェックが発生することです。 実際の制約は小さいにもかかわらず、このアプローチは不必要に複雑になります。 

重要な点は、長方形が 3 つしかなく、回転が禁止されていることです。 正方形×3 つの長方形のタイリングは、非常に制限された構造を持つ必要があります。 

正方形の辺の長さを次のようにします$S$。 まず、合計面積が次の値に等しい必要があります。$S^2$。 領域が完全な正方形でない場合、答えは即座に「NO」になります。 

次に、正方形の外側の境界について考えてみましょう。 使用される長方形は 3 つだけなので、1 つの長方形が正方形の辺全体に接する必要があります。 これにより、可能なトップレベル レイアウトは 2 つだけ作成されます。 

1 つ目の可能性は、3 つの長方形すべてが正方形の全幅にまたがって垂直方向に積み重ねられるか、または対称的にすべての長方形が全高さにわたって水平方向に積み重ねられることです。 

2 番目の可能性は、1 つの長方形が正方形の 1 辺に沿った完全なストリップを占めることです。 残りの 2 つの長方形は、残った長方形を正確に埋める必要があります。 長方形は 2 つしか残っていないため、積み重ねるか並べて配置することによってのみそのスペースを埋めることができます。 

寸法はすでに順序付けされており、長方形が 3 つしかないため、これらのいくつかの構成を確認するだけで十分です。

 ## アルゴリズムのチュートリアル

 1. 合計面積を計算します。$$A=l_1b_1+l_2b_2+l_3b_3.$$1. しましょう$$S=\sqrt{A}.$$もし$S^2 \ne A$、正方形を形成することは不可能なので、NO と答えてください。 

1. 3 つの長方形すべてを垂直方向に積み重ねられるかどうかを確認します。 

これには必要です$$l_1=l_2=l_3=S$$そして$$b_1+b_2+b_3=S.$$true の場合は、YES と答えてください。 

1. 3 つの長方形すべてを水平に積み重ねられるかどうかを確認します。 

これには必要です$$b_1=b_2=b_3=S$$そして$$l_1+l_2+l_3=S.$$true の場合は、YES と答えてください。 

1. 各長方形を、正方形の全幅のストリップを占める長方形として試します。 

長方形だと仮定します$i$寸法があります$(l,b)$。 

満たさなければなりません$$l=S.$$設置後の残りの高さは$$H=S-b.$$他の 2 つの長方形は正確に満たさなければなりません$S \times H$矩形。 

長方形は 2 つだけ残っているため、次のいずれかを行う必要があります。$$h_1=h_2=H,\qquad w_1+w_2=S$$または$$w_1=w_2=S,\qquad h_1+h_2=H.$$いずれかの条件が当てはまる場合は、YES と答えてください。 

1. 対称的に、各長方形をフルハイトのストリップとして試します。 

これには必要です$$b=S.$$残りの幅は$$W=S-l.$$他の 2 つの長方形は正確に満たさなければなりません$W \times S$同じ 2 つの長方形チェックを使用した長方形。 

1. 上記のどの構成も機能しない場合は、「いいえ」と答えてください。 

### なぜ効果があるのか

 正方形を 3 つの軸に整列した長方形でタイリングすると、正方形の分割が発生します。 1 つの長方形は正方形の辺全体に接している必要があります。そうでない場合、すべての辺が複数の長方形に分割され、少なくとも 4 つの長方形が必要になります。 

その長方形を削除すると、長方形の領域が残ります。 2 つの長方形だけが残るため、その残りの長方形は、水平または垂直の 1 つの直線カットによってのみ分割できます。 

アルゴリズムはこれらの可能性を正確にチェックします。 すべての有効な正方形タイリングはそれらの 1 つに属し、受け入れられたすべての構成は明らかに重複のない正方形を形成します。 したがって、アルゴリズムは完全かつ正確です。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

def can_form_square(rects):
    area = sum(l * b for l, b in rects)
    s = isqrt(area)

    if s * s != area:
        return False

    # all stacked vertically
    if all(l == s for l, b in rects) and sum(b for l, b in rects) == s:
        return True

    # all stacked horizontally
    if all(b == s for l, b in rects) and sum(l for l, b in rects) == s:
        return True

    for i in range(3):
        l, b = rects[i]
        others = [rects[j] for j in range(3) if j != i]

        # full-width strip
        if l == s:
            h = s - b
            (l1, b1), (l2, b2) = others

            if b1 == h and b2 == h and l1 + l2 == s:
                return True

            if l1 == s and l2 == s and b1 + b2 == h:
                return True

        # full-height strip
        if b == s:
            w = s - l
            (l1, b1), (l2, b2) = others

            if l1 == w and l2 == w and b1 + b2 == s:
                return True

            if b1 == s and b2 == s and l1 + l2 == w:
                return True

    return False

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        l1, b1, l2, b2, l3, b3 = map(int, input().split())

        rects = [(l1, b1), (l2, b2), (l3, b3)]

        ans.append("YES" if can_form_square(rects) else "NO")

    sys.stdout.write("\n".join(ans))

solve()
```最初のセクションでは合計面積を計算し、それが完全な正方形であることを検証します。 このチェックがなければ、後で不可能な例が受け入れられる可能性があります。 

次の 2 つのチェックは、すべての長方形が最終的な正方形の幅全体または高さ全体にまたがる最も単純なレイアウトを処理します。 

次に、ループは各長方形を潜在的な外側のストリップとして扱います。 そのストリップが固定されると、2 つの長方形だけが残ります。 2 つの長方形は、水平分割または垂直分割の 2 つの方法でのみ長方形を分割できます。 対応する次元の等価性が直接チェックされます。 

この実装は浮動小数点の平方根に依存しません。 使用する`isqrt`精度の問題を完全に回避します。

 ## 特殊なケース

 次のことを考慮してください。```
1
5 3 5 1 5 1
```エリアは$25$、 それで$S=5$。 すべての長方形の幅は 5 で、高さの合計は 5 になります。アルゴリズムは垂直スタック チェック中に受け入れられ、YES を返します。 L 字型レイアウトのみを検索するソリューションでは、誤って拒否されてしまいます。 

考慮する：```
1
8 5 3 5 3 3
```エリアは$64$、与える$S=8$。 アルゴリズムによってチェックされたすべての幾何学的構成は失敗します。 たとえその領域が完全な正方形であっても、答えは「NO」です。 これにより、面積だけを基準として使用するというよくある間違いを防ぐことができます。 

考慮する：```
1
2 3 1 2 1 1
```エリアは$$6+2+1=9,$$それで$S=3$。 の$2 \times 3$長方形はフルハイトのストリップを占めます。 残りの幅は 1 です。他の長方形は次のようになります。$1 \times 2$そして$1 \times 1$、垂直方向に積み重ねて、$1 \times 3$地域。 フルハイト ストリップの場合、アルゴリズムはこれを検出し、YES を返します。 

考慮する：```
1
100 100 10 10 1 1
```エリアは$$10101,$$それは完全な正方形ではありません。 アルゴリズムは、幾何学的チェックを実行する直前に拒否します。 これにより、最大の寸法を安全かつ効率的に処理できます。
