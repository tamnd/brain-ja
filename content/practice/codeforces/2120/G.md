 ## 解決策
 ## 問題の理解

 単純な接続されたグラフが与えられました$G$と$n$頂点と$m$エッジがあり、その反復された折れ線グラフのプロパティを調べるように求められます。$L^k(G)$。 折れ線グラフ$L(G)$のエッジを変換します$G$頂点に、そして 2 つの頂点に$L(G)$の対応するエッジが接続されている場合、$G$頂点を共有します。 これを繰り返す$k$回が生み出す$L^k(G)$。 質問はこれがどうかを尋ねます$L^k(G)$オイラー トレイル (パスまたはサイクルの場合がある、各エッジを 1 回だけ訪れる一連のエッジ) があります。 

入力には最大で次のものを含めることができます$2 \cdot 10^5$すべてのテスト ケースにわたる頂点またはエッジ、最大$10^4$テストケース。 制約$n \le 2 \cdot 10^5$そして$m \le 2 \cdot 10^5$単純なグラフの構築や明示的な折れ線グラフの生成が不可能になります。$L(G)$エッジ間の隣接性を処理する必要があります。$O(m^2)$密なグラフで。 したがって、明示的に構築せずに、頂点と次数のローカル プロパティのみを使用するアプローチが必要です。$L(G)$。 

明らかではないエッジケースには、次のようなグラフが含まれます。$G$オイラー式 (すべての頂点が偶数次数を持つ) と半オイラー式 (ちょうど 2 つの頂点が奇数次数を持つ) です。 たとえば、余分な弦エッジが 1 つある五角形は接続されており、オイラー サイクルを持ちますが、$L(G)$次数が奇数になると、オイラー特性が維持されない可能性があります。 と仮定する素朴な解決策$L^k(G)$このようなグラフでは 1 回の反復が失敗すると、常にオイラー軌跡が残ります。 

## アプローチ

 ブルートフォースアプローチでは、次のようになります。$L(G)$これは、エッジの各ペアを反復処理し、端点を共有する頂点を接続することによって明示的に行われます。 これは繰り返される可能性があります$k$回。 施工後$L^k(G)$、各頂点の次数をチェックします。0 個または 2 つの頂点の次数が奇数の場合、$L^k(G)$オイラー軌跡を持っています。 それ以外の場合は、そうではありません。 最悪の場合の複雑さはおおよそ次のとおりです。$O(k \cdot m^2)$、到達できる$10^{15}$最悪の場合、明らかに遅すぎます。 

重要な洞察は、折れ線グラフの特性から得られます。 グラフの場合$G$接続されており、パスではない、頂点の次数$L(G)$の頂点の次数に関係します。$G$。 具体的には、非パス オイラー グラフでは、折れ線グラフを 2 回繰り返すと、ほとんどの頂点の次数が均等になるため、オイラー特性が安定することがよくあります。 のために$k \ge 2$、$L^k(G)$オイラー軌跡がある場合に限り、$G$(パス グラフのような) 些細な小さな例外ではありません。 のために$k = 1$に頂点があるかどうかを確認する必要があります。$G$次数 1 (ツリーまたはパスの葉) を持ちます。これは、対応する頂点が次数にあるためです。$L(G)$次数 1 になり、オイラー トレイル条件に違反します。 これにより、完全なグラフ構築ではなく、単純な程度の分析に問題が軽減されます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$、$m$、 そして$k$、続いて$m$の端$G$。 各頂点の次数を長さの配列に格納します$n$。 折れ線グラフのオイラー特性は度数に依存するため、度数のみが必要です。 
2. もし$k = 1$、すべての頂点の次数を確認します。 すべての頂点の次数が少なくとも 2 の場合、$L(G)$オイラー軌跡があります。 いずれかの頂点の次数が 1 の場合、対応する頂点は$L(G)$次数 1 なので、$L(G)$オイラー軌跡はありません。 
3. もし$k \ge 2$、どうかを確認してください$G$パスです。 問題は保証します$G$はパスではないので、実際には$L^k(G)$常にオイラー軌跡があります$k \ge 2$。 このような場合は「YES」を返します。 
4. 各テスト ケースに対する上記のチェックに基づいて、「YES」または「NO」を出力します。 

ここでの不変条件は次のとおりです$k \ge 2$、接続された非パス オイラー グラフ上で折れ線グラフを反復すると、オイラー トレイルが保存されます。 のために$k = 1$、次数 1 の頂点のみがトレイルを破ることができるため、次数チェックで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        deg = [0] * (n + 1)
        for _ in range(m):
            u, v = map(int, input().split())
            deg[u] += 1
            deg[v] += 1

        if k == 1:
            if min(deg[1:]) >= 2:
                print("YES")
            else:
                print("NO")
        else:
            print("YES")

if __name__ == "__main__":
    solve()
```このソリューションは入力を効率的に読み取り、頂点次数を蓄積し、オイラー トレイル ロジックを直接適用します。 チェック中`min(deg[1:]) >= 2`オイラー軌跡を分割する葉の頂点の状態をキャプチャします。`L(G)`。 のために`k >= 2`、非パス グラフの問題保証により、それ以上の計算を行わずに「YES」を返すことができます。
