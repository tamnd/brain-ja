 ## 解決策
 ## 問題の理解

 私たちは、Aryan が常に同じサイズの部分行列を見つけられることを保証するために、Aryan が Harshith に要求する行列の最小サイズを決定するように求められます。$a \times b$同じ数字で埋められています。 アーリアンは次元を選ぶ$n$そして$m$一方、Harshith は実際の要素を選択します。$n \times m$行列。1 から 2 までの数値に限定されます。$k$。 Harshith は最適に行動するため、あらゆる問題を阻止しようとします。$a \times b$均一になるのをブロックします。 私たちの仕事は選ぶことです$n$そして$m$そのため、Harshith が行列をどのように埋めても、Aryan は常に均一な部分行列を見つけることができます。 すべての可能なペアの中で、辞書編集的に最小のペアが必要です。 

制約は厳しいです。 それぞれの$a$、$b$、 そして$k$まで可能です$10^5$、まであるかもしれません$10^4$テストケース。 合計で線形に機能するアルゴリズムを設計する必要があります。$a+b+k$すべてのテストケースにわたって。 これにより、実際に行列をシミュレートしたり、部分行列を列挙したりするアプローチは除外されます。 代わりに、行列の内容とは無関係に、勝利を保証するには行と列の数が十分であるかどうかを組み合わせて推論する必要があります。 

重要なエッジケースが発生する場合$a=1$または$b=1$。 この場合、部分行列は行または列に縮小されます。 不注意なアプローチを行うと、正方部分行列を仮定して、必要以上に大きな答えが生成される可能性があります。 もう 1 つのエッジケースは次のような場合です$k=1$; どの行列も簡単に機能します。 のために$k>1$、鳩の巣原理によ​​って繰り返しを強制するには十分な行と列が必要です。 

## アプローチ

 強引なアイデアは、可能な限りすべてのことを試してみることです$n \ge a$そして$m \ge b$次に、一様部分行列を回避する Harshith による充填が存在するかどうかを確認します。 毎回チェックします$a \times b$等価性を表す部分行列。 このアプローチは原理的には正しいですが、次の理由により実行できません。$n$そして$m$そうかもしれない$10^5$、サイズの潜在的な行列を与える$10^{10}$。 すべての部分行列をチェックすることは不可能です。 

重要な観察は、これは組み合わせの問題であるということです。 1 つの次元、たとえば行について考えてみましょう。 回避するには$a \times b$一様部分行列、Harshith は各数値が最大で表示されるように配置できます。$a-1$すべての列ブロックで 1 回。 あるので$k$個別の数値、最小行数$n$それは少なくとも強制する$a$ある列内のある数値の繰り返しは、$n = k \cdot (a-1) + 1$。 鳩の穴の原理により、もしあなたが持っているなら、$k$「バケツ」と$k(a-1)+1$アイテム、少なくとも 1 つのバケットには$a$アイテム。 同じ理由が列にも当てはまります。$m = k \cdot (b-1) + 1$。 これにより、Harshith がマトリックスをどのように満たしても、少なくとも 1 つの要素が存在することが保証されます。$a \times b$均一部分行列。 辞書編集的には、$n$を最初に最小化する必要があります。これは、この式に対応します。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、整数を読み取ります。$a$、$b$、 そして$k$。 これらは、必要な一様な部分行列の次元とセルごとの可能な値の数を表します。 
2. 最小行数を計算する$n$鳩の巣式を使用すると、次のようになります。$n = k \cdot (a-1) + 1$。 これにより、すべての列で少なくとも 1 つの数値が繰り返されるようになります。$a$を見つけることが可能になります$a$同じ行。 
3. 最小限の列数を計算します。$m$同様に:$m = k \cdot (b-1) + 1$。 これにより、少なくとも 1 つの数字が繰り返されることが保証されます$b$ある行ブロック内で何度も実行され、$b$同じ列。 
4. 両方を取る$n$そして$m$モジュロ$10^9+7$整数のオーバーフローを防ぐため。 数値自体が次の値を超える可能性があるため、これは純粋に出力フォーマットのためのものです。$10^9+7$。 
5. ペアを印刷します$(n, m)$このテストケースでは。 

機能する理由: このアルゴリズムは、行次元と列次元の両方で鳩の巣原理を利用しています。 Harshith がどのように配布したとしても、$k$価値観、持っている$k(a-1)+1$行では少なくとも何らかの数字が表示されるようにする$a$列内で 1 回、列でも同様です。 これにより、$a \times b$均一部分行列。 式は直接最小化します$n$まずそして$m$2 番目に、辞書編集的に最小の解を与えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

t = int(input())
for _ in range(t):
    a, b, k = map(int, input().split())
    n = (k * (a - 1) + 1) % MOD
    m = (k * (b - 1) + 1) % MOD
    print(n, m)
```コードは、以下を使用して複数のテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 各テスト ケースについて、鳩の穴式を使用して行数と列数を計算し、剰余を取得します。$10^9+7$出力範囲内に収まるように調整します。 モジュロ演算は計算後に適用され、非常に大きな値のオーバーフローを防ぎます。$a$、$b$、 または$k$。 ループは各結果をすぐに出力して、大きな配列の保存を回避します。これは重要なことです。$t$まで可能です$10^4$。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    MOD = 10**9 + 7
    t = int(input())
    out = []
    for _ in range(t):
        a, b, k = map(int, input().split())
        n = (k * (a - 1) + 1) % MOD
        m = (k * (b - 1) + 1) % MOD
        out.append(f"{n} {m}")
    return "\n".join(out)
