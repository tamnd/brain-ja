 **解決時間:** 1 分 34 秒
 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 同じ頂点セットに複数のグラフが与えられています。 各グラフについて、優れたグラフの頂点が元のグラフの独立したセットまたはクリークのいずれかに対応する圧縮バージョンとして「優れたグラフ」を想像できます。 素晴らしいグラフの頂点間のエッジは、元のグラフの対応するセット間の完全な接続として反映され、非エッジは完全に切断されたセットとして反映されます。 優れたグラフには、頂点の数が最小限でなければなりません。これは、パーティション内の各セットができるだけ大きいことを意味します。 

課題は、他のグラフが存在するかどうかを判断することです$H_1, H_2, ..., H_k$与えられた各グラフが$G_i$の素晴らしいグラフです$H_i$、追加の制約を尊重しながら、頂点が任意の自明ではない独立集合に拡張される場合、$H_i$、別の重要なクリークの一部になることはできません。$H_j$。 

入力は頂点の数を指定します$n$とグラフの数$k$、その後に各グラフのエッジのリストが続きます。 出力はテスト ケースごとに単純に「はい」または「いいえ」で、構築が可能かどうかを示します。 

制約が意味するのは、$n$十分に小さい (≤300) ので扱いやすい$O(n^2)$これはグラフの隣接性チェックに適しています。 グラフの数$k$も小さい (≤10) ため、すべてのグラフを同時に含む操作が可能です。 非自明なエッジ ケースには、あるグラフでは孤立しているが別のグラフではクリークの一部である頂点や、グラフ全体で重複する複数の独立したセットに現れる頂点が含まれます。 

## アプローチ

 ブルートフォースアプローチでは、候補グラフを明示的に構築しようとします。$H_i$すべてのパーティションと拡張をチェックして、$G_i$まさに素晴らしいグラフです。 これには、考えられるすべてのパーティションをクリークと独立したセットに生成する必要があり、指数関数的にコストがかかります。 たとえ$n=20$、パーティションの数は天文学的です。 したがって、ブルートフォースはどのような場合でも失敗します。$n>10$。 

重要な洞察は、問題をすべてのグラフにわたって各頂点に割り当てられたタイプの一貫性チェックに変換することです。 各頂点は、自明ではない独立集合、自明ではないクリークに属することも、すべてのグラフ内でシングルトンのままであることもできます。 シングルトン頂点は柔軟性があり、他のグラフを制約しません。 したがって、問題は矛盾のチェックに帰着します。頂点が、あるグラフでは自明ではない独立集合にあり、別のグラフでは自明ではないクリークにある場合、構築は不可能です。 それ以外の場合、答えは「はい」です。 

グラフを作成する必要はありません$H_i$明示的に; 頂点タイプのみが重要です。 各グラフについて、その次数が 0 (独立集合)、またはその優れたグラフ コンポーネントのサイズから 1 を引いた値 (クリーク) に等しい場合、頂点は非自明集合の一部です。 優れたグラフにおいて頂点がシングルトンである場合、何の制限も課しません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * k) | O(n^2 * k) | 遅すぎる |
 | 型の整合性チェック | O(n^2 * k) | O(n * k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$。 配列を初期化する`type`サイズの$n$各頂点タイプを追跡するには: 0 = 不明、1 = 独立セット、2 = クリーク。 
2. 各グラフについて$G_i$:

 1. 隣接マトリックスまたは隣接リストを作成します。 
2. の接続されたコンポーネントごとに、$G_i$、そのコンポーネント内の頂点のセットを計算します。 
3. コンポーネントのタイプを決定します。 

・エッジがない場合は独立したセットとなります。 
- 完全に接続されている場合は、クリークです。 
- そうしないと、コンポーネントは有効な優れた頂点を形成できません (答えは「いいえ」です)。 
4. コンポーネント内の各頂点について、そのグローバルを更新します。`type`:

 - 頂点が現在のコンポーネント タイプと矛盾するタイプをすでに持っている場合、テスト ケースを不可能としてマークします。 
- それ以外の場合は、コンポーネント タイプを割り当てます。 
3. すべてのグラフを処理した後、矛盾が検出されなかった場合、答えは「はい」です。 それ以外の場合は「いいえ」です。 

**機能する理由:** 各頂点は、最大でも 1 つの非自明な独立セットまたはクリークに含めることができます。 タイプをグローバルに追跡することで、すべてのグラフにわたって優れたグラフ構築ルールに違反する頂点がないことを保証します。 シングルトン頂点には制限がありません。 隣接性チェックにより、各グラフが実際にいくつかの優れたグラフとして表現できることが保証されます。$H_i$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        impossible = False
        vertex_type = [0] * n  # 0=unknown, 1=independent, 2=clique
        for _ in range(k):
            m = int(input())
            adj = [set() for _ in range(n)]
            for _ in range(m):
                u, v = map(int, input().split())
                u -= 1
                v -= 1
                adj[u].add(v)
                adj[v].add(u)
            visited = [False] * n
            for v in range(n):
                if visited[v]:
                    continue
                queue = [v]
                visited[v] = True
                comp = [v]
                for u in queue:
                    for w in range(n):
                        if w != u and w in adj[u] or (w not in adj[u] and w != u):
                            # do nothing here, we'll BFS by edges
                            pass
                    for nei in adj[u]:
                        if not visited[nei]:
                            visited[nei] = True
                            queue.append(nei)
                            comp.append(nei)
                # check component type
                deg_sum = sum(len(adj[x]) for x in comp)
                size = len(comp)
                if deg_sum == 0:
                    ctype = 1  # independent
                elif deg_sum == size * (size - 1):
                    ctype = 2  # clique
                elif size == 1:
                    ctype = 0  # singleton
                else:
                    impossible = True
                    break
                for x in comp:
                    if vertex_type[x] == 0:
                        vertex_type[x] = ctype
                    elif vertex_type[x] != ctype and ctype != 0 and vertex_type[x] != 0:
                        impossible = True
                        break
                if impossible:
                    break
            if impossible:
                break
        print("No" if impossible else "Yes")

if __name__ == "__main__":
    solve()
```**説明:** 最初に頂点タイプを不明として初期化します。 各グラフについて、そのコンポーネントを調査し、分類し、頂点タイプを更新します。 BFS により、接続されているすべての頂点が確実にキャプチャされます。 頂点に以前に異なるタイプが割り当てられている場合、矛盾が検出されます。 シングルトンはニュートラルとして扱われます。
