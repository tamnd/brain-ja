 ## 解決策
 ## 問題の理解

 2 つのシンボルのみで構成される文字列が与えられます。OR のようなマージ操作の下で、1 つはニュートラル値のように動作し、もう 1 つは吸収される「真」値のように動作します。 この操作では、隣接する 2 つの文字を選択し、それらを削除し、それらの論理 OR で置き換えることができます。つまり、どちらかの文字が Y の場合、結果は Y になり、それ以外の場合は N になります。各操作で文字列が 1 文字だけ短くなり、1 文字だけが残るまでこれを繰り返します。 

制限は、いかなる時点でも 2 つの Y 文字を直接結合できないことです。 通常は Y が生成されるにもかかわらず、その移動は禁止されています。タスクは、YY ペアを選択せず​​に文字列を 1 つの文字に縮小するマージのシーケンスが存在するかどうかを判断することです。 

制約は小さく、各文字列の長さは最大 100 で、テスト ケースは最大 500 です。 これにより、大規模な状態に対する複雑な動的プログラミングや、すべてのマージ順序に対する検索の必要性が即座に排除されます。 理論的には、n = 100 の場合、すべてのマージ シーケンスの指数関数的な探索も考えられますが、YY マージを禁止する追加の制約により、構造が大幅に枝刈りされるため、直接的な組み合わせの特性評価が期待されます。 

重要な点は、マージによって隣接関係が変化することです。 素朴な解釈では、Y と N を数えるだけでよいと考えるかもしれませんが、削除後に Y が隣接する可能性があるため、隣接性が重要になります。 もう 1 つの微妙な落とし穴は、YY マージを避けるということは、Y は永遠に分離されたままでなければならないことを意味すると考えていることです。これは真実ではありません。なぜなら、Y は N マージを間接的に「通過」できるからです。 

たとえば、`YNY`、結合することが可能です`NY -> Y`与える`YY`、後で直接マージする必要がある場合、これはすでに無効です。 ただし、構成によっては、慎重に順序付けすることで、複数の Y が存在する場合でも、2 つの Y を直接マージする必要がなくなります。 

したがって、本当の問題は、マージの瞬間にどのステップも YY 隣接関係を生成しないようにマージをスケジュールできるかどうかです。 

## アプローチ

 この強引なアイデアは、YY マージが使用されたかどうかを追跡しながら、マージする隣接するペアを繰り返し選択することで、文字列を削減する可能なすべての方法をシミュレートすることです。 これにより、各状態が文字列である状態空間が形成され、遷移は隣接するペアのマージに対応します。 長さ n の文字列には、最初はおよそ n 個の選択肢があり、次に n−1 というように階乗増加が生じるため、可能なマージ シーケンスの数は膨大です。 n はわずか 100 ですが、これは調査するには大きすぎます。 

重要な観察点は、実際には中間文字列を詳細には気にしていないということです。 唯一の危険なイベントは、2 つの Y をマージしようと決めた瞬間に隣接することです。 これは、Y が隣接する可能性のあるすべての段階で少なくとも 1 つの N によって分離されなければならない障害物のように振る舞うことを示唆しています。 

次に、N が何をするかを見てみましょう。 N に関係するものをマージすると、N が削除されるか、Y に「吸収」される傾向があります。これは、N が安定したバリアではないことを意味します。 ただし、重要な構造の単純化が見られます。文字列内に少なくとも 2 つの Y がある場合、プロセス全体でそれらを区切る少なくとも 1 つの N が存在しない限り、リダクション中のある時点で、それらの Y は最終的な 1 文字のリダクションで必然的に隣接することになります。 ただし、N は消費されるため、複数の Y を永久に分離することはできません。 

これは強い二分法につながります。Y が 2 つ以上ある場合、YY マージを必要とせずにすべてを折りたたむことができる構造の場合を除いて、答えは通常 NO です。 少なくとも 2 つの Y がある場合、これは不可能であることがわかります。長さを 1 に減らす縮小プロセスは、最終的に Y の隣接を強制する境界を越えてマージする必要があるためです。 

生き残った唯一の安全なケースは次のとおりです。 

Y が存在しない場合、または Y が 1 つだけで、収縮中に Y が別の Y に遭遇しないように周囲の N が配置されている場合。 実際、これはクリーンな条件にさらに単純化します。つまり、文字列に含まれる Y が 1 つ以下であれば有効です。 

これは次のことを確認することで正当化できます。 

Y が 0 個の場合、すべてのマージは NN → N となるため、文字列は常にすべて N のままとなり、自明に削減可能です。 

Y が 1 つだけ存在する場合、それに関係する N とのマージはすべて Y を生成します。2 番目の Y は存在しないため、禁止された YY マージは発生しません。 

Y が 2 つ以上ある場合、単一の文字に縮小するには、最終的に Y を含む領域を結合する必要があり、マージのシーケンスのあるステップで YY 隣接が強制されます。 

したがって、問題は単純なカウント条件に帰着します。

 ## アルゴリズムのチュートリアル

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、文字列をスキャンし、Y に等しい文字の数を数えます。これにより、禁止されたマージを強制できるかどうかに関連するすべての情報が取得されます。 
2. Y のカウントが 0 の場合は、すぐに YES を出力します。 どの操作でも Y を作成することはできないため、文字列は N 値の純粋な折りたたみシーケンスとして動作します。 
3. Y のカウントがちょうど 1 の場合、YES を出力します。 その単一の Y が関与するマージには別の Y が関与することはできないため、禁止された操作がトリガーされることはありません。 
4. Y が 2 回以上の場合は NO を出力します。 複数の Y が存在する場合、単一の文字に完全に縮小すると、必ず中間段階で Y が隣接することになり、禁止されたマージが避けられなくなります。 

### なぜ効果があるのか

操作中に Y を生成する唯一の方法は、少なくとも 1 つの Y をマージすることです。複数の Y が存在すると、すべてのリダクション ステップでその数が保存または削減されますが、マージによって境界がなくなるため、永久に分離されたコンポーネントに分離することはできません。 このプロセスでは文字列を 1 文字に減らす必要があるため、最終的にはすべての領域が相互作用します。 これにより、2 つの Y 原点領域が隣接し、制約に違反して直接マージする必要がある段階が保証されます。 Y が 1 つだけであれば、Y 起点領域間にそのような相互作用は存在しないため、プロセスは常に安全に進むことができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    y_count = s.count('Y')
    if y_count <= 1:
        print("YES")
    else:
        print("NO")
```この実装では、Y 文字の数のみが重要であるという観察が直接適用されます。 の`.count()`この操作では、テスト ケースごとに 1 回文字列がスキャンされますが、制約を考慮するとこれで十分です。 

唯一の微妙な点は、すべてのケースを均一に扱うことです。空の N が優勢な文字列と単一の Y 文字列の両方が受け入れられますが、それ以上の数の Y は拒否されます。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    t = int(input())
    for _ in range(t):
        s = input().strip()
        print("YES" if s.count('Y') <= 1 else "NO")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    from contextlib import redirect_stdout
    out = io.StringIO()
    with redirect_stdout(out):
        solve()
    sys.stdin = old_stdin
    return out.getvalue().strip()

 ## 特殊なケース

 N とのマージでは新しい Y 相互作用が作成されないため、どの位置にある単一の Y も常に同じように動作します。 たとえば、`NYNN`、すべての有効なマージ シーケンスでは、最大 1 つの Y がアクティブに保たれるため、YY 隣接関係を形成することなく、プロセスは常に 1 文字まで安全に進むことができます。 

のような文字列`YNNY`隣接関係のみに基づいた素朴な推論の失敗モードを明らかにします。 最初は Y が分離されていたとしても、長さを短縮する一連のマージにより、最終的にはそれらの領域間の相互作用が強制されます。 その時点で、2 つの Y 派生コンポーネントが一致する必要があり、禁止された YY マージが必要になります。 これがまさに、Y を数えるだけで十分な理由です。収縮下では分離は保持されません。
