 ## 解決策
 ## 問題の理解

 一連の子があり、それぞれが整数のniceness値を持っています。 サンタは各子供たちを素敵なリストかいたずらなリストのどちらかに割り当てたいと考えていますが、列の先頭から子供たちを削除することしかできません。 各削除は 2 つの選択肢のいずれかです: 最初の子を取得し、そのナイスネスを実行スコアに追加します。$X$、または 2 番目の子供を連れて、その優しさを から差し引きます。$X$。 これは、割り当てられていない子が 1 つだけ残るまで続き、最終的な値を最大化するように求められます。$X$。 

入力には複数のテスト ケースがあり、それぞれが子の数を指定します。$n$そしてその良さの価値観。 出力は最大です$X$各テストケースで達成可能。 それぞれ$n$まで可能です$2 \cdot 10^5$、およびすべての合計$n$テストケース全体での制限も次のとおりです。$2 \cdot 10^5$。 これは、各テスト ケースを大まかに解決する必要があることを意味します。$O(n)$時間; 二次関数はすべてタイムアウトになります。 

単純な解決策では、最初と 2 番目の選択肢のすべての可能な順序を調査しようとする可能性があります。 たとえ$n=20$、 がある$2^{19}$考慮すべきシーケンス。 明らかに、この強引なアプローチは実行不可能です。 また、最適な選択は、多くの場合、現在の子の絶対値ではなく、最初の子の選択と 2 番目の子の選択の違いに依存することにも気付きます。 エッジケースが発生するのは次のような場合です$n=2$: 許可される演算は 1 つだけなので、解は単純に最初の演算を加算するか、2 番目の演算を減算する最大値になります。 一部の値が負の場合、別の微妙なシナリオが発生します。 マイナスを引くと増加する可能性があります$X$したがって、常に最初のものを選択することが最善であるとは限りません。 

## アプローチ

 ブルートフォースアプローチは、現在の値を追跡しながら、すべての選択を再帰的にシミュレートすることです。$X$。 子を削除するたびに、最初の子を選択するか 2 番目の子を選択するかの 2 つのオプションに分岐します。 すべてのシーケンスを探索するため、これは正しいですが、シーケンスの数は$2^{n-1}$、これは天文学的に大きくなります$n \sim 10^5$。 明らかに、このアプローチは非常に小規模なものに限定されています。$n$。 

重要な洞察は、これを配列のプレフィックスに対する動的プログラミングの問題として定式化できることです。 させて$dp[i]$最大になる$X$最初のものだけを考慮すると達成可能$i$子どもたちとパフォーマンス$i-1$操作。 各状態について、最初の子を選択することは、追加することに相当します。$a[i]$、2 番目の子を選択することは、減算に相当します。$a[i+1]$。 最高の状態を維持することで、$dp$各プレフィックスの値を設定すると、複雑さを次のように軽減できます。$O(n)$テストケースごとに。 もう 1 つの単純化は、最後に残った子が元の配列のいずれかになる可能性があることに注目することです。 次に、最大化します$X$つまり、最初の子を継続的に選択するためのプレフィックスの合計を計算し、2 番目の子を継続的に選択するためのサフィックスの合計を計算します。 これらの合計の組み合わせを比較すると、最適な結果が得られます。

 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 テスト ケースごとに、次の内容を読んでください。$n$そして配列$a$素敵さの価値観。 変数を初期化する`X_max`最大値を追跡するには負の無限大まで$X$。 
2. もし$n=2$、操作は 1 つだけです。 コンピューティング`X`最大として`a[0]`（最初のものを選択）そして`-a[1]`（2番目を選択）。 これは、最小のエッジケースを直接処理します。 
3. 大型の場合$n$、最後に残った子が次のいずれかである可能性を考えてみましょう。$n$子供たち。 重要な観察は、最終的な`X`は、選択された最初の子のすべての合計から、選択された 2 番目の子の合計を引いたものとして表すことができます。ただし、1 つの子のみが除外されます。 考慮すべき 3 つの自然なシナリオがあります。 

- すべての子を前から順番に削除し、最後の子を残します。 最後を除くすべてを合計します。 
- 前から子を削除しますが、場合によっては 2 番目の子を選択して増やします`X`。 最初の除去と 2 番目の除去の間の分割については、`X`最初の選択肢の接頭辞から 2 番目の選択肢の接尾辞を引いた合計に等しい。 
4. 最適な`X`したがって、は次の最大値になります。 

-`a[0]`(最初の操作で最初のものを選択)
 -`-a[1]`(最初の操作で 2 番目を選択)
 -`sum(a[0..i]) - min(a[i+1..])`配列に沿って適切に分割するため
 5. 反復中に実行中のプレフィックス合計とサフィックス合計を維持することにより、これを実装します。 最後の子となる可能性のあるそれぞれについて、左側の最初の選択肢の合計と右側の 2 番目の選択肢の合計を計算し、更新します。`X_max`組み合わせが以前の最大値を超えた場合。 
6. 考えられるすべての最後の子を評価した後、出力します。`X_max`。 

### なぜ効果があるのか

 正確さは演算の線形性にかかっています。最初の子の加算と 2 番目の子の減算は、値が線形です。 各操作は影響のみを及ぼします`X`したがって、操作の順序は、どちらの子が最初に削除されるか 2 番目に削除されるかという点のみが重要になります。 すべての潜在的な最後の子を考慮し、左と右からの合計寄与を計算することにより、実行可能なシーケンスをすべて網羅し、最大値を保証します。`X`が見つかりました。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 2:
            print(max(a[0], -a[1]))
            continue
        # Consider leaving last child at position i
        X_max = -10**18
        total_sum = sum(a)
        # Removing first child sequentially
        prefix = 0
        for i in range(n-1):
            prefix += a[i]
            X_max = max(X_max, prefix)
        # Removing second child sequentially (subtracting them)
        suffix = 0
        for i in range(n-1, 0, -1):
            suffix -= a[i]
            X_max = max(X_max, suffix)
        # Check the edge case of first or second operation only
        X_max = max(X_max, a[0], -a[1])
        print(X_max)

if __name__ == "__main__":
    solve()
```このソリューションではまず、$n=2$エッジケースを直接。 次に、常に最初の子を選択すると仮定してプレフィックスの合計を計算し、常に 2 番目の子を選択すると仮定してサフィックスの合計を計算します。 これらすべての合計の最大値により、最適な値が得られます。`X`。
