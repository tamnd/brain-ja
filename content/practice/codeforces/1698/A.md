 ## 問題の理解

 長さの配列が与えられます`n`元の長さの配列を取得して生成されたもの`n-1`、すべての要素の XOR を計算し、その XOR を配列に追加して、結果をシャッフルします。 タスクは、シャッフルされた配列のみを指定して、追加された XOR 値を回復することです。 各テスト ケースではそのような配列が 1 つ提供され、追加された XOR に対応するテスト ケースごとに 1 つの整数を生成する必要があります。 

制約は控えめです。`n`最大 100 まで、テスト ケースは最大 1000 まで可能です。 配列内の各要素は 0 ～ 127 の小さな整数です。これは、最悪の場合でも必要な操作は約 100,000 回のみであり、最新の CPU ではわずかであるため、テスト ケースあたりの複雑さ O(n) のアルゴリズムは効率的に実行されることを意味します。 これにより、複雑なデータ構造や最適化の必要性も排除されます。 

エッジケースには、すべての要素が同一である配列が含まれます。`x`元の要素の 1 つと一致する可能性があります。または、`x`はゼロです。 たとえば、配列が`[6, 6, 6, 6, 6, 6]`、正解は 6 です。もう 1 つのトリッキーなケースは次のとおりです。`[100, 100, 0]`、元の 2 つの要素の XOR は 0 です。たとえば、重複を削除しようとしたり、次のように仮定したりする単純なアプローチ`x`これらの入力で失敗する可能性がある最大の要素です。 

## アプローチ

 ブルートフォース手法では、各要素を順番に削除し、残りの XOR を計算して、削除された要素と一致するかどうかを確認します。 それぞれについて、`n`要素に対して XOR を計算します。`n-1`要素が含まれるため、テスト ケースごとに O(n²) の操作が発生します。 これは、指定された制約に対して技術的には実現可能ですが、XOR 演算にはより単純な解決策を可能にする特性があるため、その必要はありません。 

重要な洞察は、XOR が結合的であると同時に可換的であるということです。 これは、最終的な配列のすべての要素を XOR 演算すると、元の配列を 2 回、追加された値を 1 回 XOR 演算した場合と同じ結果が得られることを意味します。 元の配列の XOR を次のようにすると、`x`、最後の配列には、すべての元の要素に加えて、`x`。 すべてを XOR すると、次のようになります`x ⊕ a1 ⊕ a2 ⊕ ... ⊕ a(n-1)`。 しかし`a1 ⊕ a2 ⊕ ... ⊕ a(n-1)`ちょうどです`x`したがって、合計 XOR は次のようになります。`x ⊕ x = 0`プラス追加`x`、出発`x`。 したがって、最終的な配列のすべての要素の XOR により、次の値が直接得られます。`x`。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`n`整数。 
3. 変数を初期化する`x`これにより、すべての要素の XOR が保持されます。 
4. 配列を反復処理し、各要素を XOR 演算します。`x`。 このループの後、`x`すべての XOR が含まれます`n`要素。 
5. 出力`x`現在のテストケースの場合。 

なぜ機能するのか: XOR には次のような特性があります。`a ⊕ a = 0`そして`a ⊕ 0 = a`。 最終的な配列では、元の要素はすべて 1 回出現し、`x`が一度出現します。 これらすべてを XOR 演算すると、元の要素がすべてキャンセルされます。`a1 ⊕ a2 ⊕ ... ⊕ a(n-1) ⊕ x = x`。 これにより、シャッフルに関係なく、追加された正しい XOR が常に復元されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    x = 0
    for num in a:
        x ^= num
    print(x)
```このソリューションはテスト ケースの数を読み取り、それらをループします。 配列ごとに、単純な for ループを使用してすべての要素の XOR を計算します。 XOR アキュムレータは 0 から始まり、配列を正しく処理できるようにします。`x`XOR は重複を自動的にキャンセルするため、シャッフルまたは繰り返される要素を特別に処理する必要はありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        x = 0
        for num in a:
            x ^= num
        print(x)
    return output.getvalue().strip()

 ## 特殊なケース

 配列の場合`[6, 6, 6, 6, 6, 6]`、アルゴリズムは XOR を次のように計算します。`6 ⊕ 6 ⊕ 6 ⊕ 6 ⊕ 6 ⊕ 6 = 6`。 The repeated elements cancel in pairs, leaving the appended XOR intact. のために`[100, 100, 0]`、XOR`100 ⊕ 100 ⊕ 0 = 0`元の 2 要素配列に追加された XOR を正しく復元します。`[100, 100]`。 これらの例は、追加のロジックなしでソリューションが重複とゼロを正しく処理することを確認します。
