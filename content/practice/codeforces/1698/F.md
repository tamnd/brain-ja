 ## 解決策
 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、それぞれの長さ`n`。 配列`b`の順列です`a`したがって、同じ複数の値セットが含まれていますが、順序が異なる可能性があります。 特別な操作を実行できます`a`: 2 つのインデックスを選択します`l`そして`r`どこ`a[l] == a[r]`そして部分配列を元に戻します`l`に`r`。 課題は、変革できるかどうかを判断することです`a`の中へ`b`せいぜい使用`n^2`このタイプの操作を指定し、存在する場合は操作を提供します。 

制約は十分小さいので、`O(n^2)`このアプローチは次の合計であるため実現可能です。`n`すべてのテスト ケースの数は最大 500 です。各要素は次のように制限されます。`n`したがって、大きな数を気にせずに、周波数ベースの推論や単純な線形スキャンを使用できます。 

厄介なケースは、要素が 1 回しか出現しない場合です。 この操作には一致するエンドポイントが必要であるため、値が 1 回だけ表示され、配置が間違っている場合、これらの操作を使用して値を移動することはできません。 たとえば、次の場合`a = [1,2]`そして`b = [2,1]`、 どちらでもない`1`または`2`は 2 回発生するため、逆転は不可能であり、正しい出力は次のようになります。`NO`。 

もう 1 つの微妙な点は、複数の重複が存在する場合です。 元に戻すことはできますが、前の配置を壊さずに必要な要素が所定の位置に移動するように、インデックスを慎重に選択する必要があります。 

## アプローチ

 素朴なアプローチは、考えられるすべてのペアを試すことです`(l,r)`どこ`a[l] == a[r]`セグメントを反転し、次まで繰り返します。`a`マッチ`b`。 理論的には正しいですが、面倒で効率的に実装するのが難しく、不必要な逆転が行われる可能性があります。 最悪の場合には、`O(n^2)`可能性のあるセグメントをすべて試してみると、反転のすべての順列を試行すると指数関数的になるため、強引な方法は非現実的です。 

重要な観察は、少なくとも 2 回出現する要素は反転によって自由に移動できるということです。 具体的には、値をもたらしたい場合は、`v`位置を決める`i`、次の 2 つの出現が見つかります。`v`そして配置するセグメントを反転します`v`セグメントの外側の他の要素の相対的な順序を乱すことなく、目的の位置に配置できます。 これにより、問題は建設的なアルゴリズムに集約されます: スキャン`b`左から右へ、それぞれの位置で正しい値を次から取得します。`a`最大でも 2 つの反転を使用します。 必要な値が 1 回だけ表示され、まだ設定されていない場合は、すぐにレポートされます。`NO`。 

この洞察をもとに、`O(n^2)`変換する一連の操作を決定論的に構築するアルゴリズム`a`の中へ`b`推測せずに。

 | --- | --- | --- | --- |
 | ブルートフォースオールリバーサル | 指数 | O(n) | 遅すぎる |
 | 二点反転で建設的 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 一番左のインデックスから開始します`i = 0`。 私たちの目標は、`a[i] = b[i]`。 
2. もし`a[i] == b[i]`、増分`i`そして続けます。 要素はすでに配置されています。 
3. それ以外の場合は、2 つの同一の要素を検索します。`v = b[i]`残りの配列で`a[i+1:]`。 それらのインデックスを次のようにします`j`そして`k`と`j < k`。 
4. 同一の要素が 2 つも存在しない場合`a[i:]`のために`v`、 報告`NO`。 これは、必要な反転を実行できないことを意味します。 
5. それ以外の場合は、サブ配列を反転します`a[j:k+1]`。 これにより、`v`位置まで`j`次のステップに進むために必要な重複を保持しながら。 
6. サブ配列を反転します`a[i:k+1]`。 今`v`所定の位置に移動します`i`。 
7. 両方の反転を記録する`(j+1, k+1)`そして`(i+1, k+1)`1 から始まるインデックスを使用します。 
8. インクリメント`i`配列全体になるまで繰り返します`a`マッチ`b`。 

機能する理由: 反復ごとに正しい値が位置に配置されます。`i`位置の要素を変更せずに`< i`。 反転は少なくとも 2 つの同一要素を含むセグメントにのみ適用されるため、操作は常に有効です。 これにより、私たちが変革できることが保証されます`a`の中へ`b`せいぜい`n^2`各ポジションは最大で 2 回の反転を必要とするため、操作は困難になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        ops = []
        impossible = False
        
        for i in range(n):
            if a[i] == b[i]:
                continue
            
            # Find two identical elements in a[i:] equal to b[i]
            indices = [j for j in range(i, n) if a[j] == b[i]]
            if len(indices) < 2:
                impossible = True
                break
            
            j, k = indices[0], indices[1]
            
            # First reverse to bring one occurrence to position j
            a[j:k+1] = a[j:k+1][::-1]
            ops.append((j+1, k+1))
            
            # Second reverse to bring it to position i
            a[i:k+1] = a[i:k+1][::-1]
            ops.append((i+1, k+1))
        
        if impossible:
            print("NO")
        else:
            print("YES")
            print(len(ops))
            for l, r in ops:
                print(l, r)

if __name__ == "__main__":
    solve()
```コードは最初に次の位置を反復処理します。`b`。 不一致が発生した場合、残りのターゲット値の最初の 2 つの出現を検索します。`a`。 これは 2 つの反転を実行します。1 つ目は重複が利用可能な状態を維持することを保証し、2 つ目は値を正しい位置に配置します。 重複が存在しない場合、アルゴリズムは停止して出力します。`NO`。 操作を保存する場合は、1 から始まるインデックスが適用されます。
