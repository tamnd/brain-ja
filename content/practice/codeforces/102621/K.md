 ## 解決策
 ## 問題の理解

 寸法が記載された長方形の紙があります`a × b`そして`n`長方形のシール。 各シールは配置すると長方形を作成し、90 度回転できます。 2 つの異なるシールを選択し、両方を紙の上に重ならないように配置する必要があります。 2 つの長方形は用紙の端に揃える必要があり、カバーされる領域の合計を最大化することが目標です。 

入力では、用紙サイズと、その後に利用可能なすべてのシールの寸法が記述されます。 出力は、両方に配置できる 2 つのシールの面積の最大合計です。 どのシールも嵌合できない場合、答えは次のとおりです。`0`。 

制約は小さいです。`n`、`a`、 そして`b`せいぜい`100`。 これにより戦略は完全に変わります。 アン`O(n²)`enumeration は最大で約 10,000 個のペア チェックを実行しますが、これは通常の制限時間としては非常に小さいです。 動的プログラミングまたはジオメトリ構造を使用するより複雑なアプローチは、不必要な複雑さを追加します。 

主なトラップは、回転と、2 つの長方形をコーナー配置にのみ配置する必要がないという事実によって発生します。 水平方向または垂直方向に並べて配置できます。 

例えば：```
Input:
2 2 2
1 2
2 1

Output:
4
```回転を無視した不用意な解決策では、たとえ回転させると 2 つのシールが紙を正確に埋めるとしても、2 番目のシールが拒否されてしまいます。 

もう 1 つのエッジ ケースは、1 つのシールが個別に適合するが、2 番目のシールがそのシールとスペースを共有できない場合です。```
Input:
3 10 10
6 6
7 7
20 5

Output:
0
```3 番目のシールは使用できません。また、最初の 2 つのシールは、どの配置でも合計寸法が紙を超えるため、組み合わせることができません。 

最後によくある間違いは、用紙の 1 つの方向だけをチェックすることです。 サイズの長方形`x × y`として配置できます`y × x`したがって、すべての候補ペアは両方のローテーションを考慮する必要があります。 

## アプローチ

 簡単な解決策は、すべてのシールを試してみることです。 ペアごとに、各シールをどのように回転させるかを決定し、2 つの長方形を一緒に配置できるかどうかをテストします。 最初の長方形に寸法がある場合`w1 × h1`2番目には寸法があります`w2 × h2`、2 つの基本レイアウトで用紙を共有できます。 垂直方向に積み重ねることができるため、`w1`そして`w2`用紙の幅に収まるように、`h1 + h2`用紙の高さ内に収まるように調整します。 並べて配置することもできます。`w1 + w2`幅内に収まるには両方の高さが高さ内に収まるようにします。 

この強引なアイデアは、制約に対してすでに十分です。 多くてもあります`100 × 100`各ペアは一定数の回転とレイアウトのみをチェックします。 総作業量はわずか数万回です。 

有益な観察は、非表示の配置の選択肢がないことです。 どちらのシールも紙に沿って配置された長方形であるため、有効な配置はすべて、一方の長方形がもう一方の長方形の真上、真下、左または右に配置される配置に変換できます。 用紙内の位置は重要ではなく、幅と高さの組み合わせが制限を満たしているかどうかのみが重要です。 

シール数が少ないので力技が効きます。 すべてのペアをチェックすると二次関数になるため、何十万ものシールがある場合は失敗します。 ここでは、制約によって許可されているため、同じアイデアが意図された解決策となります。

 ## アルゴリズムのチュートリアル

 1. シールの寸法をすべて読み、保管してください。 
2. 異なるシールのすべてのペアを検討します。 最終的な答えには正確に 2 つのシールが含まれている必要があるため、ペアのみが重要です。 
3. 各ペアについて、最初のシールの両方の向きと 2 番目のシールの両方の向きを試します。 回転すると寸法は変わりますが、面積は変わりません。 
4. すべての方向の組み合わせについて、可能な 2 つのレイアウトを確認します。 最初のレイアウトではシールを垂直に配置するため、シールの幅と高さの合計が用紙の高さ内に収まる必要があります。 2 番目のレイアウトでは水平に配置されるため、高さと幅の合計が用紙幅内に収まる必要があります。 
5. 取り決めが有効な場合は、2 つの長方形の領域の合計で答えを更新します。 

これがあらゆる可能な配置をカバーする理由は、重ならない 2 つの軸が整列した長方形は常に水平軸または垂直軸のいずれかに沿って分離できるためです。 その分離は、アルゴリズムによってチェックされた 2 つのレイアウトに正確に対応します。 

### なぜ効果があるのか

 このアルゴリズムは、2 つのシールのあらゆる可能な選択と、それらのシールのあらゆる回転を検査します。 有効な配置では、2 つの四角形の一方の四角形がもう一方の四角形の完全に左または右に配置されるか、一方の四角形がもう一方の完全に上または下に配置される必要があります。 対応するディメンション チェックが直接実行されるため、すべての有効なペアが考慮されます。 有効と考えられるすべての配置はその面積を最大限に活用し、無効な配置は拒否されるため、最終的な答えはまさに可能な限り最良のカバー領域になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, a, b = map(int, input().split())
    seals = [tuple(map(int, input().split())) for _ in range(n)]

    ans = 0

    def check(w1, h1, w2, h2):
        if w1 <= a and w2 <= a and h1 + h2 <= b:
            return True
        if h1 <= b and h2 <= b and w1 + w2 <= a:
            return True
        return False

    for i in range(n):
        for j in range(i + 1, n):
            x1, y1 = seals[i]
            x2, y2 = seals[j]

            for w1, h1 in ((x1, y1), (y1, x1)):
                for w2, h2 in ((x2, y2), (y2, x2)):
                    if check(w1, h1, w2, h2):
                        ans = max(ans, x1 * y1 + x2 * y2)

    print(ans)

if __name__ == "__main__":
    solve()
```ネストされたループは、順序付けされていない各ペアを 1 回だけ列挙します。 使用する`i + 1`シールをそれ自体と比較したり、同じペアを逆の順序で繰り返すことを避けます。 

回転ループは、シールごとに 2 つの可能な方向を生成します。 長方形を回転しても面積は変わらないため、面積の計算では元の寸法が使用されます。 

の`check`関数には完全なジオメトリ条件が含まれています。 最初の条件は垂直方向の積み重ねを表し、2 番目の条件は水平方向の配置を表します。 これらのチェックを別々にしておくと、幅と高さが入れ替わるミスを回避できます。 

Python の整数はこれらの制約に対してオーバーフローしません。これは、可能な最大領域が`100 × 100 + 100 × 100`。

 ## 特殊なケース

 回転が必要な場合、アルゴリズムは明示的に両方の方向を試みます。 入力の場合:```
2 2 2
1 2
2 1
```2番目のシールは`1 × 2`回転後、ペアが紙全体を占めるようになります。 指定された方向のみをチェックするソリューションでは、誤った出力が発生します。`0`。 

適合するペアがない場合、すべての向きの組み合わせは失敗します。 のために：```
3 10 10
6 6
7 7
20 5
```最初の 2 つのシールは、それらを合わせた幅または高さが大きすぎるため配置できず、3 番目のシールは使用できません。 答えは残っている`0`。 

寸法が正確に境界線に接する場合、不等式は等価性を許容する必要があります。 のために：```
2 5 5
5 2
2 5
```シールは横に並べたり、未使用スペースを残さずに積み重ねたりすることができます。 アルゴリズムが使用するのは、`<=`、つまり正しく返されます`20`取り決めを拒否する代わりに。
