 ## 問題の理解

### なぜ効果があるのか

 OR ゼータ変換は、各値をサブセットの合計として書き換え、OR 畳み込みを点ごとの乗算に変換します。 変容したこの空間で 組み合わせて$k$独立した選択は選択に相当します$k$複数のサイズのセット間での貢献$A[i]$。 二項係数は、順序なしの選択を正確にカウントし、多重度を維持します。 変換は反転可能なため、逆変換を適用すると、重複を過剰にカウントすることなく、正確な和集合マスクのカウントが回復されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353  # typical CF modulus assumption

def modinv(x):
    return pow(x, MOD - 2, MOD)

def fwt_or(a, invert=False):
    n = len(a)
    step = 1
    while step < n:
        for i in range(0, n, step * 2):
            for j in range(step):
                u = a[i + j]
                v = a[i + j + step]
                if not invert:
                    a[i + j + step] = (u + v) % MOD
                else:
                    a[i + j + step] = (v - u) % MOD
        step <<= 1

def binom(x, k, fact, invfact):
    if x < k:
        return 0
    return fact[x] * invfact[k] % MOD * invfact[x - k] % MOD

def solve():
    n, m, k = map(int, input().split())
    size = 1 << m

    a = [0] * size

    for _ in range(n):
        mask = int(input().strip())
        a[mask] += 1

    fwt_or(a, invert=False)

    maxv = max(a) if a else 0
    fact = [1] * (maxv + 1)
    invfact = [1] * (maxv + 1)

    for i in range(1, maxv + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact[maxv] = modinv(fact[maxv])
    for i in range(maxv, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    for i in range(size):
        a[i] = binom(a[i], k, fact, invfact)

    fwt_or(a, invert=True)

    print(*a)

if __name__ == "__main__":
    solve()
```この実装では、まずマスクを周波数配列に圧縮し、次に OR ゼータ変換をその場で実行します。 その後、変換された最大値まで階乗が事前計算されるため、マスクごとの定数時間の二項評価が可能になります。 逆変換により、元のドメイン数が再構築されます。 唯一のデリケートな部分は、逆 OR 変換でモジュラー演算の減算が正しく使用されていることを確認することです。 そうしないと、組織的な過剰カウントが発生します。

 ## 特殊なケース

 すべてのオブジェクトが同じマスクを共有している場合、微妙な失敗のケースが発生します。 その状況では、OR-FWT は多くのマスクにわたって同一の値を生成し、二項ステップは次の場合にのみすべてを単一の非ゼロ構成に正しく還元する必要があります。$k$合計数に等しい。 アルゴリズムはこれを処理します。$\binom{x}{k}$そうでない限り、ゼロに崩壊します。$k$は利用可能な多重度と一致し、逆変換ではそのスパース性が維持されます。 

別の特殊なケースが発生するのは、$k = 1$。 二項関数は恒等式になるため、解決策は OR-FWT とその逆関数を適用することになり、完全に相殺されます。 逆変換符号の処理で実装エラーが発生すると、このケースは直ちに中断されます。 

3 番目のケースは、すべてのマスクが互いに素な単一ビット マスクである場合です。 ここで、OR 構造は独立したビットをカウントするサブセットに縮退します。 OR-FWT はすべてのサブセットを自然に蓄積し、二項選択では重複するインフレを発生させずに個別の要素の組み合わせを正しくカウントするため、変換は引き続き正しく機能します。
