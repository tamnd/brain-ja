 ## 問題の理解

 私たちには無限の水が 2 つ与えられています。1 つは温度に応じたものです。`h`そしてもう一つは温度で`c`、 と`c < h`。 空のコンテナーに一連の注入を構築します。 注ぐ順序は固定されており、熱いものから始まり、最初は熱いもの、次に冷たいもの、そして再び熱いもの、というように交互に始まります。 何回注いだ後でも停止することができますが、少なくとも 1 回は注ぐ必要があります。 

後`k`注ぐ場合、容器内の最終温度は注がれたすべての温度の算術平均です。つまり、最初のカップの中で何個の温かいカップと冷たいカップが取られたかによってのみ決まります。`k`この交互シーケンスの要素。 

目的は停止点を選択することです`k`この結果の平均温度が目標値にできるだけ近づくようにする`t`。 複数の値がある場合、`k`同じ最小の絶対差を達成するには、そのような最小のものを選択する必要があります`k`。 

主要な構造は、すべての有効な状態が決定的なシーケンスのプレフィックスに対応するというものです。`h, c, h, c, ...`したがって、それぞれに対して可能な構成は 1 つだけです。`k`。 

制約は次のとおりです`3 * 10^4`テストケースと最大温度`10^6`。 これは、各テストが対数時間または定数時間で解決される必要があることを強く示唆しています。 テスト ケースごとに多くの注ぎをシミュレートするアプローチは、カップ数が大きな値まで線形である場合、制限を超える危険があります。 

単純な考えとしては、平均値が明らかに次の値から離れるまで注入をシミュレーションすることです。`t`ただし、シーケンスは収束が遅く、傾向が明らかになるまでに多くのステップが必要な値まで拡張される可能性があります。 

最適解が大きい場合、微妙なエッジケースが現れます。 たとえば、次のようなとき`t`に近いです`(h + c) / 2`、最良の近似値を得るには、その値付近で安定するまでに数百または数千回の注入が必要になる場合があります。 平均が早期停止を保証するような単調ではないため、単純で貪欲な最初の改善で停止する戦略は失敗する可能性があります。 

## アプローチ

 注ぐ回数を修正すると`k`、構成が完全に決まります。 ホットカップの数は、`(k + 1) // 2`そして冷たいカップは`k // 2`。 結果の温度は次のようになります。$$T(k) = \frac{h \cdot \lceil k/2 \rceil + c \cdot \lfloor k/2 \rfloor}{k}$$ブルートフォースアプローチでは、増加を試みます`k`から`1`上向きに計算する`T(k)`毎回、最良の結果を追跡します。 これは正しいです。有効な構成はすべてプレフィックスであるため、すべてを列挙する必要があります。`k`検索スペース全体をカバーします。 ただし、最悪の場合、`k`それは大きいかもしれない。 機能が近づきます`(h + c) / 2`として`k`成長するので、もし`t`がこの値に近い場合、差が再び増加し始める前に、多くの候補を評価する必要がある可能性があります。 これにより、テスト ケースごとに線形スキャンが行われることになり、最悪の場合、速度が非常に遅くなります。 

重要な観察は、`T(k)`実際的な意味では単峰性です: 増加するにつれて`k`、温度は に向かって単調に移動します。`(h + c)/2`、そして安定します。 これは、関数値が最も近い点を検索していることを意味します。`t`、二分探索を使用して実行できます`k`。 

可能な長さにわたって検索します`k`そして、最良の点の周囲で 2 つの隣接する候補を比較します。 答えは必ずしもどこにあるわけではありません`T(k) = t`ただし、絶対的な差が最小化される場合。 この関数は滑らかで単峰性であるため、次の点を二分探索できます。`T(k)`交差するか、またはそれに最も近づく`t`、次に近くの候補を明示的にチェックします。

 ## アルゴリズムのチュートリアル

 整数を見つけたい`k`間の絶対差を最小化するもの`T(k)`そして`t`。 

1.固定の場合`k`、ホットカップの数を次のように計算します。`(k + 1) // 2`そして冷たいカップとして`k // 2`。 これはホットで始まる交互パターンを直接反映し、構成の正確さを保証します。 
2. 温度の合計を次のように計算します。`S = h * hot + c * cold`。 平均は`S / k`。 相互乗算を使用して比較することにより、可能な場合は浮動小数点除算を回避します。 
3. 関数を定義する`diff(k)`それは戻ってきます`|S/k - t|`。 この関数は、指定されたプレフィックス長がターゲットからどれだけ離れているかを評価します。 
4. 二分探索を実行します。`k`範囲内で`[1, MAX]`、 どこ`MAX`すべての意味のある遷移をカバーするのに十分な大きさです。 各中間点で比較します`diff(mid)`そして`diff(mid + 1)`。 右に移動すると値が向上する場合は、検索を右半分に移動します。 それ以外の場合は左にシフトします。 
5. 二分探索が収束した後、候補領域の周囲の小さな近傍をチェックします。通常は、`k - 2`を通して`k + 2`整数の丸め効果により、真の最小値が隣接する可能性があるためです。 
6. これらの候補の中から、差が最も小さいものを選択し、同点の場合は最も小さいものを選択します。`k`。 

### なぜ効果があるのか

 機能`T(k)`決定論的な交互作用によって駆動され、熱いカップと冷たいカップの割合が近づきます。`1/2`として`k`成長します。 これはつまり`T(k)`～からスムーズに移行します`h`向かって`(h + c)/2`パリティに応じて。 その結果、絶対的な差は、`t`は整数に対して単峰性のランドスケープを形成するため、二分探索の絞り込みによって見つかった局所最小値は大域最小値に対応する必要があります。 小さな近傍をチェックすることで、二分探索だけでは見逃す可能性のあるパリティ効果を確実に捕捉できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def calc(k, h, c, t):
    hot = (k + 1) // 2
    cold = k // 2
    s = hot * h + cold * c
    # compare |s/k - t| without float:
    # |s - k*t| / k, denominator irrelevant for comparison across same k
    return abs(s - k * t), k

def solve_one(h, c, t):
    if t * 2 <= h + c:
        return 2

    lo, hi = 1, 2 * 10**6
    best = (abs(h - t), 1)

    while lo <= hi:
        mid = (lo + hi) // 2
        mid_diff = calc(mid, h, c, t)
        next_diff = calc(mid + 1, h, c, t)

        if next_diff < mid_diff:
            lo = mid + 1
        else:
            hi = mid - 1

    for k in range(max(1, lo - 3), lo + 4):
        best = min(best, calc(k, h, c, t))

    return best[1]

def main():
    tcs = int(input())
    for _ in range(tcs):
        h, c, t = map(int, input().split())
        print(solve_one(h, c, t))

if __name__ == "__main__":
    main()
```このソリューションは、まず、ターゲットが中間点以下にあるときの特別な観測を処理します。`(h + c) / 2`、最適な答えは常に`2`なぜなら、その体制ではすでに1つの暑さと1つの寒さが最も近づいているからです。 

の`calc`関数は比較することによって浮動小数点誤差なしで偏差を計算します。`s - k*t`、これは絶対差に比例します。 これにより、精度の問題が完全に回避されます。 

二分探索を使用して、増加する領域を特定します。`k`近似の改善を停止します。 この関数はパリティ発振のため厳密には凸ではないため、見つかった位置の周囲の小さなウィンドウをチェックすることで改良します。

 ## 特殊なケース

 いつ`t`等しい`h`、最適な戦略は、言うまでもなく熱いカップ 1 杯です。 アルゴリズムはこれを処理します。`k = 1`エラーはゼロであり、他の構成は純粋な高温に正確に一致することはできません。 

いつ`t`等しい`c`、最良の答えは、コールド貢献を可能な限り優勢にすることによってのみ達成されます。 シーケンスは常にホットから始まるため、ソリューションには慎重なバランスが必要であり、二分探索は自然に大きな方向にドリフトします。`k`冷たいカップがシーケンスのほぼ半分になります。 

いつ`t`まさにそこにあります`(h + c) / 2`、シーケンスは交互のペアの周りで安定し、`k = 2`が最適です。 このアルゴリズムは、初期の比較と近傍検索によってこれを捕捉し、パリティ効果によって検索が誤解されないようにします。
