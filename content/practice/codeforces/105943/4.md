 ## アルゴリズムのチュートリアル

 まず、すべての大きな値が最後にグループ化されるように配列を並べ替えます。 

1. 配列を降順でない順に並べ替えます。 これにより、スキャンする代わりに位置を確認することで、特定の値以上の要素がいくつあるかを素早く数えることができます。 
2. 回答変数をゼロに初期化します。 これにより、これまでに見つかった最良の有効なレベルが追跡されます。 
3. 可能な値を反復処理します。$K$1から$n$。 上限は$n$レベルだから$K$少なくとも必要です$K$要素。 
4. それぞれについて$K$、少なくともいくつの要素が存在するかを調べます。$K$。 ソートされた配列では、これは値が到達する最初のインデックスを見つけることと同じです。$K$、次に接尾辞の長さを計算します。 
5. この数が少なくとも$K$、回答を更新します。 
6. すべての候補をチェックした後、有効な最大値を出力します$K$。 

重要な設計上の選択は、配列をスキャンしてカウントを再計算しないことです。 代わりに、ソートではすべての周波数情報が暗黙的にインデックス位置にエンコードされます。 

### なぜ効果があるのか

 ソート後の条件は「少なくとも」$K$要素は$\ge K$」は、最初の値から始まるサフィックスに含まれる要素の数にのみ依存します。$\ge K$。 これにより、各候補チェックがソートされた順序の決定論的な関数に縮小されます。 すべての有効な$K$並べ替えでは要素の値は変更されず、その位置のみが変更され、条件は順序ではなくしきい値を超えた数のみに依存するため、並べ替え時に保存されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]
    
    a.sort()
    
    ans = 0
    for k in range(1, n + 1):
        # find first index with value >= k
        lo, hi = 0, n
        while lo < hi:
            mid = (lo + hi) // 2
            if a[mid] >= k:
                hi = mid
            else:
                lo = mid + 1
        
        cnt = n - lo
        if cnt >= k:
            ans = k
    
    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、ソートとそれに続く各候補のバイナリ検索に依存しています。$K$。 二分探索では、以下の値の間の境界を見つけます。$K$そして少なくとも価値観$K$、接尾辞の長さによってカウントが直接わかります。 唯一の微妙な点は、二分探索において正しい不等式の方向を維持することです。 混ぜ合わせる`>=`そして`>`境界が移動し、正確性が損なわれる可能性があります。
