 ## 解決策
 ## 問題の理解

 この問題では、少し変わったレイアウトの建物内の特定のアパートの階数を見つけるように求められます。 1 階には常に 2 つのアパートメントがあり、それ以降の各階には同じ数のアパートメントがあり、これは次の式で与えられます。$x$。 アパート番号は次から始まります$1$1階にあり、建物の上に上がるにつれて順番に増加します。 アパート番号を指定すると、$n$および各フロアのアパート数$x$最初のタスクの後、タスクはどの階にアパートがあるかを計算することです$n$。 

入力は複数のテスト ケースで構成され、各テスト ケースに対して次のものが与えられます。$n$そして$x$。 制約は小さいです -$n$そして$x$せいぜい$1000$、最大で$1000$テストケース。 これは、実行されるソリューションがすべて$O(t)$または$O(t \cdot 1)$テストケースごとに完全に許容されます。 テスト ケースごとの操作は単純な算術計算であるため、制限時間を超過する危険はありません。 

注意すべきエッジケースは、特にアパートの 1 階です。$n = 1$または$n = 2$。 後続のフロアに常に式を適用する不用意な実装は、これらのケースの計算を誤る可能性があります。 もう 1 つの潜在的な落とし穴は次のような場合です。$n$ちょうど 2 つのフロアの境界に着地します。 たとえば、次の場合$x = 3$、アパート$3$、$4$、 そして$5$2階に住んでるのでアパートです$n = 5$3 階ではなく 2 階にあると正しく認識される必要があります。 

## アプローチ

 素朴なアプローチは、フロアを 1 つずつシミュレートし、到達するまでアパートを数えることです。$n$。 1階にある2つのアパートメントから始めて、その後追加します$x$次の階ごとにアパートメントを追加し、現在の階にアパートメントが含まれるまでフロアカウンターをインクリメントします。$n$。 これは正しいですが、単純な算術を使用する問題としてはやや冗長であり、制約には不必要です。 

最適なアプローチでは、単純な公式を使用します。 もし$n \le 2$、アパートは1階にあります。 それ以外の場合は、1 階のアパートを差し引いて、後続のフロア全体が何階必要になるかを計算します。 これは次のように表現できます$(n - 3) // x + 2$、整数の除算を使用します。 その理由は、$n - 2$1階以降はアパートが残ります。 で割る$x$は最初の上に追加の階数を与え、次を追加します。$1$1階を説明します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | シミュレーション | テスト ケースあたり O(n) | お(1) | 正しいが不要 |
 | 式 | テスト ケースごとに O(1) | お(1) | 最適で受け入れられています |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$x$。 
3. 次のことを確認します。$n$は$1$または$2$。 そうであれば、出力フロア$1$直接。 
4. それ以外の場合は減算します$2$から$n$1階を説明します。 
5. 追加の階数を次のように計算します。$(n - 3) // x + 2$。 による引き算$1$部門の内側では、正確な倍数の正しい床の丸めが保証されます。$x$。 
6. 計算された階数を出力します。 

なぜ機能するのか: この式はアパートを 2 つの 1 階に分割し、その後、同じサイズの連続した階に分割します。$x$。 整数除算により、部分的に埋まった最終階の一部であるアパートメントがその階数に正しく四捨五入されます。 エッジケース$n \le 2$負の除算を避けるために個別に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        if n <= 2:
            print(1)
        else:
            # subtract first floor, then compute which floor
            floor = (n - 3) // x + 2
            print(floor)

if __name__ == "__main__":
    solve()
```最初の条件は 1 階のエッジ ケースを処理します。 他のすべてのアパートメントの場合は、減算します。$3$そして追加$2$数式では、アパート番号と階数が正しく一致します。 整数除算により、フロアの端にあるアパートメントが正しいフロアで数えられるようになります。

 ## 特殊なケース

 重大なエッジケースは次のような場合です$n$1階に落ちます。 ソリューションはアパートを正確に識別します$1$そして$2$床にいるのと同じように$1$。 別の微妙なケースが発生する場合$n$最初のアパートメントの後の、フロアの最後のアパートメントに正確に着地します。 整数の除算式により、自動的に正しいフロアに配置されます。 例えば、$n = 5$、$x = 3$: 1 階 (2 つのアパートメント) を差し引きます → 残りの 3 つのアパートメント。 それから$(5-3)//3 + 2 = 2$フロア 2 を正しく識別します。
