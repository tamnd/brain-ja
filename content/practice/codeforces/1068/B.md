 ## 問題の理解

## アプローチ

 式の定義から始めます。 アイデンティティの使用$$\mathrm{lcm}(a,b) = \frac{ab}{\gcd(a,b)},$$式を次のように書き換えます$$\frac{\mathrm{lcm}(a,b)}{a} = \frac{b}{\gcd(a,b)}.$$これにより、問題は最小公倍数に関する問題から、純粋に gcd 値に関する問題に変換されます。 今、式は次だけに依存します$\gcd(a,b)$、これはの約数でなければなりません$b$。 これにより、次の無限領域が直ちに縮小されます。$a$可能な gcd 値の有限セットに変換します。 

させて$g = \gcd(a,b)$。 それから$g \mid b$、式は次のようになります$b/g$。 したがって、ボードに書かれた各値は、約数の選択に正確に対応します。$g$の$b$ただし、そのような gcd が実際に何らかの方法で達成できる場合に限ります。$a$。 すべての約数$g$の$b$を取ることで達成可能です$a = g \cdot k$どこ$k$と互いに素である$b/g$なので、約数は除外されません。 

したがって、書き込まれる個別の値のセットは正確に次のようになります。$$\left\{ \frac{b}{d} \mid d \mid b \right\}.$$異なる約数$d$さまざまな価値を生み出す$b/d$、したがって、個別の結果の数は正確に次の約数の数になります。$b$。 

問題は、約数を数えることに帰着します。$b$これは素因数分解によって行われます。

### なぜ効果があるのか

 式のすべての可能な値は、次の約数によって一意に決定されます。$b$、式は次のように簡略化されるため、$b/g$どこ$g \mid b$。 逆に、すべての約数は$g$を構築することで gcd として実現できます。$a$適切な共有素因数を使用し、gcd を増加させる追加の素因数を避けます。 これにより、約数間に 1 対 1 の対応関係が確立されます。$b$ボードに書かれた明確な値。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    b = int(input().strip())
    x = b
    ans = 1

    p = 2
    while p * p <= x:
        if x % p == 0:
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            ans *= (cnt + 1)
        p += 1

    if x > 1:
        ans *= 2

    print(ans)

if __name__ == "__main__":
    solve()
```コードはまず因数分解します$b$トライアル分割により。 素因数が見つかるたびに、その多重度がカウントされ、除数の積が更新されます。 ループ後に 1 より大きい剰余が残った場合、その剰余は指数 1 に寄与する素因数となり、除数の数が 2 倍になります。 

微妙な点は、決して反復しないということです$a$。 問題全体が内部の構造に崩壊する$b$、そして gcd 再定式化により、次の巨大な上限への依存が除去されます。$a$。
