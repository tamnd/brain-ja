 ## 解決策
 ## 問題の理解

 平面上の整数グリッド点を調べており、各点には座標があります。$(x, y)$ここで、両方の値は整数です。 各テスト ケースの半径$r$が与えられると、原点を中心とする細い円形リングの中に格子点が何個あるかを数える必要があります。 

点は、原点からのユークリッド距離が少なくとも 100 以上である場合にカウントされます。$r$厳密にそれより小さい$r+1$。 代数的に言えば、ある点については、$(x, y)$、次の場合にカウントします。$$r^2 \le x^2 + y^2 < (r+1)^2.$$したがって、問題は、二乗距離が 2 つの連続する円の間の非常に特定の環の内側に収まる整数グリッド点の数を求めることになります。 

入力サイズは、すべてのクエリの合計で最大 1000 クエリを示唆します。$r$までの値$10^5$。 これにより、各テスト ケースのグリッド全体にわたって再計算されるものはすべて除外されます。 正方形の側面にわたる単純なスキャン$2r$費用がかかるだろう$O(r^2)$、次の場合には大きすぎます。$r$到達する$10^5$。 

重要な微妙な点は、これが連続的な幾何学の問題ではなく、離散的な計数の問題であるということです。 小さな変化$r$答えはスムーズに変更されません。また、整数の二乗を扱うため、正確な整数での境界の動作が重要になります。 

よくある失敗例は、面積の差を近似しようとすることに起因します。 たとえば、次のように使用します。$\pi((r+1)^2 - r^2)$与える$2\pi r + \pi$、これは答えに近いですが、正確ではありません。 のために$r=1$、この近似は約$3\pi \approx 9.4$、真の答えは 8 です。不一致は、円の境界付近の格子の不規則性によるものです。 

もう 1 つの失敗例は、対称性を誤って二重にカウントすることです。 1 つの象限内の点を数えて 4 倍することもできますが、軸上の点の動作は異なり、リングの境界が一様な対称性を破ります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべての整数のペアを列挙します。$(x, y)$と$|x| \le r+1$そして$|y| \le r+1$、計算する$x^2 + y^2$、区間内にあるかどうかを確認します$[r^2, (r+1)^2)$。 これは定義を直接実装しているため、これは正しいです。 ただし大まかに検査します$(2r+2)^2 \approx 4r^2$テスト ケースあたりのポイントは不可能になります。$r = 10^5$。 

重要な観察は、条件は次のもののみに依存するということです。$x^2 + y^2$, したがって、問題は放射状に対称です。 点を反復する代わりに、可能な整数を反復できます。$x$値を取得し、有効な範囲を計算します。$y$それぞれの値$x$。 固定の場合$x$、不等式は次のようになります。$$r^2 - x^2 \le y^2 < (r+1)^2 - x^2.$$これにより、問題は整数のカウントに変わります$y$正方形の間隔内の値。整数平方根を使用して計算できます。 それぞれ$x$有効な点の垂直スライスに寄与するので、すべてを合計するだけで済みます。$x$から$-(r+1)$に$r+1$、つまり$O(r)$。 

これは効率的です。なぜなら、$r$テストケース全体の境界は次のとおりです$10^5$したがって、テスト ケースごとの反復は全体として線形のままです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(r^2)$テストごと |$O(1)$| 遅すぎる |
 | 最適 |$O(r)$テストごと |$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 整数を数えるという観点から問題を書き直します$y$それぞれの固定値$x$。 

1. 半径のある各テスト ケースについて$r$を繰り返します$x$から$-(r+1)$に$r+1$。 

この範囲は十分であるため、それを超えると、$y=0$与えるだろう$x^2 \ge (r+1)^2$, そのため、条件を満たすポイントはありません。 
2. 固定ごとに$x$、下限と上限を計算します。$y^2$:$$L = r^2 - x^2,\quad U = (r+1)^2 - x^2.$$これらは許容範囲を表します。$y^2$。 
3. もし$U \le 0$、整数なし$y$このために機能します$x$なので省略します。 

これは可能な最大値でも発生します$y^2$小さすぎて内側の円に到達できません。 
4. クランプ$L$少なくとも 0 である必要があります。$y^2$マイナスにはできません。 

負の下限を指定すると、すべての小さい値が誤って許可されてしまいます。$y$ので、修正します。 
5. 正方形の境界を整数の境界に変換します。$y$:$$|y| \in [\lceil \sqrt{L} \rceil, \lfloor \sqrt{U-1} \rfloor].$$次のように計算します。$$y_{\min} = \lceil \sqrt{L} \rceil,\quad y_{\max} = \lfloor \sqrt{U-1} \rfloor.$$6. 有効な整数を数える$y$この範囲内で。 それぞれの有効な大きさは 2 つの対称点に寄与します ($+y$そして$-y$）、 を除外する$y=0$これは 1 回としてカウントされます。 

これは、間隔の長さを使用して慎重に計算され、二重カウントを避けます。 
7. 全体の貢献度を合計する$x$、最終的な答えを導き出します。 

### なぜ効果があるのか

 アルゴリズムはすべての格子点をその格子点によって分割します。$x$-座標。 固定ごとに$x$、すべての有効な点は、$y$連続不等式を満たす$y^2$。 平方は非負の整数に対して単調であるため、有効な$y$値は 2 つの対称区間を形成します$[-k, -m]$そして$[m, k]$、または空の可能性があります。 二乗境界を整数ルート境界に変換することにより、すべての整数解を省略や重複なく正確に取得します。 すべての格子点には 1 つだけあります$x$スライスなので、スライスを合計すると、各ポイントが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def isqrt(x):
    # integer square root (safe fallback using binary search)
    lo, hi = 0, x
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= x:
            lo = mid + 1
        else:
            hi = mid - 1
    return hi

def count_y(L, U):
    # count integers y such that L <= y^2 < U
    if U <= 0:
        return 0
    if L < 0:
        L = 0

    # y^2 < U  => |y| <= floor(sqrt(U-1))
    r = isqrt(U - 1)
    # y^2 >= L => |y| >= ceil(sqrt(L))
    l = isqrt(L)
    if l * l < L:
        l += 1

    if l > r:
        return 0

    # count integers in [-r, -l] and [l, r]
    # careful with zero
    total = 2 * (r - l + 1)
    if l == 0:
        total -= 1
    return total

t = int(input())
for _ in range(t):
    r = int(input())
    ans = 0

    rr = r * r
    rp = (r + 1) * (r + 1)

    for x in range(-(r + 1), r + 2):
        x2 = x * x
        L = rr - x2
        U = rp - x2
        ans += count_y(L, U)

    print(ans)
```コア構造は可能な限りすべてを反復します$x$- 環と交差する可能性のある座標。 それぞれについて$x$、2D 条件を 1D 制約に変換します。$y^2$、平方根境界を使用して有効な整数解をカウントします。 

最もデリケートな部分は、包括性を正しく処理することです。 外側の境界は厳密に以下です$(r+1)^2$の使用を強制します。$U-1$整数の平方根に変換する場合。 内部境界は包括的であるため、$L$同じようにはシフトされません。 

対称性の処理は、正と負を別々に繰り返す代わりに、カウント関数に組み込まれています。$y$、絶対値の範囲を計算し、それらを整数カウントに変換し直します。

    input = sys.stdin.readline

        lo, hi = 0, x
        while lo <= hi:
            mid = (lo + hi) // 2
            if mid * mid <= x:
                lo = mid + 1
            else:

        return hi

        if U <= 0:

        if L < 0:

 ## 特殊なケース

 のために$r = 1$、有効なポイントが満たされている$1 \le x^2 + y^2 < 4$。 アルゴリズムチェック$x \in [-2, 2]$。 のために$x=0$、それは計算します$y^2 \in [1,4)$、生産$y = \pm 1$、2ポイントに貢献します。 のために$x=1$、同じことが起こり、対称性によりすべてのスライスにわたって寄与が正しく 2 倍になり、合計 8 点が生成されます。 

のために$r = 2$、アルゴリズムの処理$x \in [-3, 3]$。 で$x=0$、それは重要です$y^2 \in [4,9)$、与える$y = \pm2, \pm3$。 で$x=1$、わずかに短い間隔をカウントします。 アウター$x$値はすぐに負の境界を生み出し、ゼロに寄与します。 これは、無効なスライスは不等式の処理によって消えるため、このメソッドが明示的な枝刈りを行わずに検索空間を自然にトリミングする方法を示しています。
