 ## 解決策
 ## 問題の理解

 平面上に一連の点が与えられますが、直線上に 3 つが横たわらないという約束があります。 これらの点から任意のサブセットを選択し、選択した点を周期的な順序で配置して単純な多角形を形成できます。 ポリゴンは自己交差してはならず、厳密に正の面積を持つ必要があります。 このような有効なポリゴンすべての中で、可能な限り最大の面積を持つポリゴンが必要ですが、追加の制限があります。つまり、ポリゴンは凹型である必要があります。つまり、凸型であることは許可されません。 

出力には、達成可能な最大面積の 2 倍が必要です。または`-1`凹型の単純な多角形を形成することが不可能な場合。 

制約は大きく、テストあたり最大 100,000 ポイント、テスト全体で合計最大 200,000 ポイントとなります。 これにより、すべてのサブセットまたはポリゴンの順序に対する 3 次または 2 次の構築が即座に除外されます。 ソートベースでも$O(n \log n)$ソリューションはテストごとに許容されますが、多くのサブセットまたは順列のチェックを伴うものは許容されません。 

重要な構造観察は、ジオメトリが凸包によって支配されていることです。 点セットから描画された単純な多角形は、凸包がすべての点を含む最小の凸領域であるため、その面積は最大でも凸包の面積となります。 これは、可能な限り最適な領域が凸包の計算に密接にリンクされていることを意味します。 

単純なアプローチでは、点のさまざまなサブセットやさまざまな巡回次数を考慮しようとする可能性がありますが、固定サブセットであっても、単純性と計算領域の検証は線形であるため、そのようなアプローチは実行不可能になります。 

すべての点が凸包上にある場合、微妙なケースが 1 つ現れます。 その場合、単純さを損なうことなく反射角を導入するための内部点がないため、すべての点を使用する単純な多角形は凸状でなければなりません。 たとえば、正方形を形成する 4 つの点は、有効な単純な多角形として凸の四角形しか持たないため、多角形が存在する場合でも、凹の要件により答えは不可能になります。 

もう 1 つのケースは、内部点が 1 つだけ存在する場合です。 凹面の多角形を作成するにはこれで十分ですが、不注意な推論では、内部の点によって面積が増加すると考えられる可能性があります。 実際には、内部点は達成可能な最大面積を増やすことはなく、凹面の実現可能性を助けるだけです。 

## アプローチ

 ブルート フォース パースペクティブは、点のサブセットを選択することから始まり、次にそのサブセットのすべての順列をポリゴンの頂点順序として試し、どの順列が単純なポリゴンを形成しているかを確認し、その面積を計算します。 たとえサイズのサブセットに限定したとしても$k$、 がある$k!$順列があり、$2^n$サブセット。 これは、たとえ$n = 20$。 

正しい方向は、単純な多角形が完全な点セットの凸包の内側にあるため、その面積が凸包の面積を超えることができないことを認識することによって得られます。 これにより、目標はポリゴンの検索から、おそらく内部点を追加することによって、凸包自体が凹ポリゴンとしていつ実現できるかを理解することに変わります。 

すべての点が凸包境界上にある場合、すべての単純な多角形はそれらの点を正確に使用し、凸状の順序でそれらをトレースする必要があり、凸状多角形のみを生成します。 シンプルさを損なわずにリフレックス頂点を導入する方法はありません。 したがって、凹多角形は不可能です。 

少なくとも 1 つの点が厳密に凸包の内側にある場合、柔軟性が得られます。 すべてのハル頂点を循環順序で使用することで最大面積を維持し、単純さを維持しながら反射角を作成する方法で少なくとも 1 つの内部点を順序付けに挿入できます。 その内側の点は外側の境界を変更することなく「へこみ」として機能するため、その領域は正確に凸包領域のままになります。 

したがって、問題は凸包を計算し、そのサイズを$n$、その面積を計算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットと順列に対するブルート フォース | 指数 | O(n) | 遅すぎる |
 | 凸包 + 状態チェック | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 次に、点セットの幾何学的構造を抽出します。 

1. すべての点を x 座標で辞書順に並べ替え、y 座標で分けます。 これにより、単調な凸包構造の準備が整います。 
2. モノトーン チェーン法を使用して凸包を構築します。 左から右に反復してスタックを維持し、最後の 3 点が左折しない場合は常に最後の点を削除することによって、船体下部を構築します。 船体上部については逆の順序で対称的に繰り返します。 連結により、反時計回りの順序で完全な凸包が得られます。 
3. 靴紐の式を使用して凸包の面積を計算し、出力形式の要求に応じて結果を整数に保つために 2 を掛けます。 
4. 凸包上のポイントの数をポイントの総数と比較します。 
5. すべての点が船体上にある場合は、戻ります。`-1`内部点は存在せず、単純な多角形は凸型でなければならないためです。 
6. それ以外の場合は、凸包面積の 2 倍を達成可能な最大値として返します。 

ハルのサイズのみをチェックする理由は、凹面は少なくとも 1 つの反射頂点を導入できるかどうかにのみ依存し、それには内部点が必要であるためです。 船体自体がすでに面積を最大化しているため、代替サブセットを使用しても結果を改善できません。 

### なぜ効果があるのか

 凸包は、すべての点を含む固有の最小凸領域であり、その点から形成された単純な多角形はすべてその中に含まれます。 したがって、ポリゴンはその面積を超えることはできません。 内部点が存在する場合、内部頂点が反射角を作成している間もハル頂点は循環順序で表示できるため、外部境界トラバースを変更せずに非凸順序を構築できます。 内部点が存在しない場合、単純なポリゴンはハル頂点のみを使用する必要があり、それらの頂点によって凸状の順序が適用されるため、凹面は不可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def area2(poly):
    s = 0
    n = len(poly)
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s)

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        pts = [tuple(map(int, input().split())) for _ in range(n)]

        hull = convex_hull(pts)

        if len(hull) == n:
            out.append("-1")
        else:
            out.append(str(area2(hull)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```凸型ハルの構造は標準的なモノトーン チェーン アプローチを使用しており、一貫したターン方向を繰り返し強制することに依存しています。 重要な実装の詳細は次のとおりです。`<= 0`外積チェックで条件を確認し、同一線上および右折点を削除して厳密な凸性を確保します。 

面積の計算では、船体の頂点に対して靴紐の式を順番に使用します。 ハルはすでに巡回順序になっているため、追加の並べ替えは必要ありません。 

船体のサイズと合計ポイントの最終比較により、内部ポイントが存在するかどうかが直接取得されます。 

## 実用的な例

 点が 1 つの内部点を持つ正方形を形成する小さな集合を考えてみましょう。 船体には 4 つの頂点がありますが、内側に追加の点が 1 つあります。 

各段階で、船体構造により外側の境界として正方形が生成されます。 内部ポイントが船体に含まれることはありません。 

| ステップ | 船体構造 | 船体サイズ | 内部点が検出されました |
 | --- | --- | --- | --- |
 | すべての点を処理した後 | 正方形の境界 | 4 | はい |

 ポリゴン順序に内部点を挿入することで凹面を実現できるため、アルゴリズムは正方形の面積を返します。 

ここで、内点のない凸四角形を形成する 4 つの点を考えます。 

| ステップ | 船体構造 | 船体サイズ | 内部点が検出されました |
 | --- | --- | --- | --- |
 | すべての点を処理した後 | 四角形 | 4 | いいえ |

 船体のサイズは n に等しいため、アルゴリズムは次の値を返します。`-1`、凹面の単純な多角形の不可能性を反映しています。 

これらの例は、アルゴリズムが点セットが凸境界を越えた内部構造を持つかどうかによって完全に駆動されることを示しています。

 ## 特殊なケース

 すべての点が凸状の境界上にある場合、包にはすべての点が含まれます。 アルゴリズムは、船体のサイズを n と比較することでこれを検出します。 この状況では、多くの単純なポリゴンが存在するとしても、反射角を作成するために利用できる内部頂点がないため、どれも凹面にすることはできません。 

内部点が 1 つだけ存在する場合、船体は変化しませんが、不等式は次のようになります。`len(hull) < n`ポジティブケースを引き起こします。 このアルゴリズムは引き続きハル領域を出力し、内部ポイントは概念的には非凸順序付けを可能にするためだけに使用され、ジオメトリを変更するためではありません。 

三角形を形成する 3 つの点など、点セットがすでに最小である場合、ハルは完全なセットと等しいため、出力は次のようになります。`-1`ポリゴンが存在するにもかかわらず。 凹面の要件はブロック条件であり、ポリゴンの存在ではありません。
