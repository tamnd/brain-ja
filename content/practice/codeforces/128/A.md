 ## 解決策
 ## 問題の理解

 8×8のボードがあります。 マリアは左下隅から始まり、アンナは右上隅に常駐し、いくつかの彫像が他のセルを占めています。 

ゲームはラウンド形式で進行します。 マリアが最初に移動し、次にすべての彫像が同時に 1 列下に移動します。 ボードの下に移動する彫像は永久に消えます。 

マリアは 8 つの隣接するセルのいずれかに移動するか、その場に留まることができます。 彼女は現在彫像が占有している独房に移動することはできません。 彼女の移動後、彫像は下に移動します。 彫像がマリアの独房に着くと、彼女は即座に負けます。 マリアがアンナの独房に到達すれば、即座に彼女の勝ちです。 

基板は非常に小さいです。 セルは 64 個しかなく、彫像は完全に決定的な方法で動きます。 最大 8 回の彫像の移動の後、すべての彫像がボードから落ちるため、ゲームの危険な段階は短時間で終わります。 つまり、到達可能なすべてのゲーム状態を直接検索する余裕があるということです。 

主な難点は、ボードが時間の経過とともに変化することです。 今は安全な位置でも、彫像が移動すると安全でなくなる可能性があります。 現在のボード構成をチェックするだけの不注意な検索では、不正な状態が受け入れられてしまいます。 

微妙なエッジ ケースの 1 つは、マリアが現在は空の独房に移動するが、彫像が移動するとすぐに占有される場合です。

## アプローチ

 最も直接的なアイデアは、総当たりシミュレーションです。 毎ターン、マリアには最大 9 つの選択肢があり、隣接する 8 つのセルと静止したままで構成されます。 各ターンで彫像の動きをシミュレートしながら、可能なすべての一連の動きを再帰的に試すことができます。 

ボードが小さく、ゲームの展開が決定的であるため、これは概念的に機能します。 問題は、移動シーケンスの数が指数関数的に増加することです。 20ターン後にはすでに約$9^{20}$可能性のあるパスですが、これは完全に実行不可能です。 

重要な観察は、ボードの状態は時間のみに依存するということです。 マリアの行動に関係なく、彫像は常に同じように下に移動します。 ボードには 8 列しかないため、最大 8 ターン後にすべての彫像が消えます。 

それは問題を完全に変えます。 任意の長さの移動シーケンスを探索する代わりに、次のものを追跡するだけで済みます。 

1. マリアの現在の位置。 
2. 現在の時間ステップ。 

各タイム ステップでは、最大 64 個の可能な位置が存在します。 意味のある状態の総数は、大まかに言うとごくわずかです$64 \times 9$。 

これにより、当然、状態を超えた BFS または DFS が発生します。$(row, col, time)$。 1 つの状態から 9 つの移動をすべて試し、像の移動の前後に目的地が安全かどうかを確認してから続行します。 

重要な洞察は、二重の安全性チェックです。 

1. 現時点では、マリアは彫像のある独房に移動できません。 
2. マリアはまた、像が降臨した後、像が置かれる独房に留まることはできません。 

2 番目の条件がなければ、マリアが移動直後に押しつぶされる位置も検索で受け入れられます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(9^T) | O(T) | 遅すぎる |
 | 状態に応じた最適な BFS/DFS | O(64 × 9 × 9) | O(64×9) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 初期の 8 × 8 ボードを読み取ります。 
2. 初期構成からのすべてのスタチュー位置を保存します。 
3. 関数を定義する`safe(r, c, t)`セルかどうかをチェックします`(r, c)`時々彫像がありません`t`。 

もともとあった彫像`(sr, sc)`にあります`(sr + t, sc)`後`t`動きます。 もし`sr + t >= 8`、その像は消えました。 
4. マリアの初期位置から BFS を開始します。`(7, 0)`時に`0`。 
5. 州ごとに`(r, c, t)`、最初に現在のセルがすでに安全ではないかどうかを確認します`t`。 

彫像が現在位置を占めている場合、この状態は無効であるため、スキップする必要があります。 
6. マリアが届いたら`(0, 7)`、 戻る`"WIN"`。 
7. 9 つの可能なアクションをすべて試してください。 

1. 8 つの方向のいずれかに移動します。 
2. その場に留まります。 
8. 各候補ポジションについて`(nr, nc)`:

 1. ボードの外側のポジションは無視します。 
2. 同時に彫像が占有するセルを無視する`t`。 
3. 同時に占有されるセルを無視する`t + 1`。 

2 番目の条件により、マリアはすぐに彫像に足を踏み入れることができなくなります。 3つ目は、彫像が動いた後に彼女が押しつぶされるのを防ぎます。 
9. 有効な次の状態をプッシュします`(nr, nc, min(t + 1, 8))`列に並びます。 

時間の上限を 8 に設定するのは、8 移動後にすべての彫像が消え、ボードが再び変更されないためです。 
10. アンナに到達せずに BFS が終了した場合は、戻ります。`"LOSE"`。 

### なぜ効果があるのか

 いつでも、将来のボード構成は時間によって完全に決定されます。 BFS は、各タイム ステップでマリアが占めることができる、到達可能なすべての安全な位置を探索します。 

遷移は、スタチューの移動前と移動後の両方で宛先セルが安全な場合にのみ追加されます。 それはまさにゲームのルールと一致しています。 

考えられるすべての正当な動きシーケンスが状態グラフで表現されるため、BFS は勝利パスが存在する場合は必ずそれを見つけます。 BFS がアンナに連絡できない場合、法的戦略は存在しません。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

DIRS = [
    (-1, -1), (-1, 0), (-1, 1),
    (0, -1),  (0, 0),  (0, 1),
    (1, -1),  (1, 0),  (1, 1)
]

def solve():
    board = [input().strip() for _ in range(8)]

    statues = []

    for r in range(8):
        for c in range(8):
            if board[r][c] == 'S':
                statues.append((r, c))

    def safe(r, c, t):
        for sr, sc in statues:
            nr = sr + t
            if nr < 8 and nr == r and sc == c:
                return False
        return True

    q = deque()
    q.append((7, 0, 0))

    visited = set()
    visited.add((7, 0, 0))

    while q:
        r, c, t = q.popleft()

        if not safe(r, c, t):
            continue

        if (r, c) == (0, 7):
            print("WIN")
            return

        nt = min(t + 1, 8)

        for dr, dc in DIRS:
            nr = r + dr
            nc = c + dc

            if not (0 <= nr < 8 and 0 <= nc < 8):
                continue

            if not safe(nr, nc, t):
                continue

            if not safe(nr, nc, t + 1):
                continue

            state = (nr, nc, nt)

            if state in visited:
                continue

            visited.add(state)
            q.append(state)

    print("LOSE")

solve()
```解決策は、最初の像の位置を収集することから始まります。 スタチューの動きは決定論的であるため、タイム ステップごとにボードを明示的に再構築する必要はありません。 

の`safe`関数は、特定の時点でセルが空いているかどうかを計算します。 動きを繰り返しシミュレートするのではなく、各彫像の位置を元の列から直接導き出します。 

同じボード セルがある瞬間には安全でも、後で危険になる可能性があるため、BFS 状態には時間が含まれます。 治療中`(r, c)`単独で訪問すると、異なるゲーム状況が誤ってマージされてしまいます。 

安全チェックの順序は重要です。 まず、像が移動する前に目的地が空いていることを確認し、次に像が降下した後も目的地が空いていることを確認します。 2 番目のチェックが欠けているのは、この問題で最も一般的なバグです。 

すべての彫像が消えるため、時間は 8 に制限されます。 この上限がなければ、BFS は同等の将来の状態を永久に生成し続ける可能性があります。
