 ## 解決策
 ## 問題の理解

 正確に _k_ 個の直線カットを使用して、_n_ 個の重ならない円形のバナナで装飾されたバースデー ケーキからマリアが製造できるバナナの個数の最大数を決定するように求められました。 各円には中心座標があります`(x, y)`そして半径`r`。 目標は、ケーキを均等に分割したり、ケーキのスライスの数を最大化することではなく、バナナの輪自体の中にあるピースの数を最大化することです。 カットは交差する場合があり、複数のカットが同じ円を通過する場合があります。 

入力により、円の数 _n_、カットの数 _k_、および各円の座標と半径が提供されます。 出力は単一の整数、つまり指定されたカットで達成可能なバナナ片の最大数です。 

とすれば`n ≤ 1000`しかし`k`まで行くことができます`10^5`、考えられるすべての行の配置を繰り返すことは現実的ではありません。 強引な幾何学的シミュレーションはすぐに遅くなりすぎます。 これは、円が独立して生成できるピースの最大数を計算し、これをすべての円にわたって集計する、円ごとのアプローチが必要であることを意味します。 エッジ ケースには、円よりもカットが少ない状況 (一部の円はまったくカットできない) や、円の数に対してカットが多く、特定の円が過剰に分割される可能性がある状況が含まれます。 

単純な間違いは、すべてのカットが円を 1 回分割すると仮定したり、最大の円を優先せずにカットを不均等に分配したりすることです。 たとえば、1 つの円と 1 つのカットの場合、最大ピースは 1 ではなく 2 です。同様に、2 つの円と 1 つのカットの場合、合計 2 ピースを超えて両方を同時に分割することはできません。 

## アプローチ

 ブルートフォースアプローチでは、平面を通るすべての線をシミュレートし、すべての円との交点を計算しようとします。 カットごとに、すべての円を反復処理して、作成される新しい部分の数を決定できます。 これは正しいですが、各円と線の交差の計算が自明ではないため、法外に遅くなります。`k`まで`10^5`、操作の数は次を超えます`10^8`簡単に。 

最適なアプローチのための重要な洞察は、古典的な円の幾何学から得られます。つまり、単一の円を分割できる部分の最大数です。`m`直線カットは次の式で与えられます。`(m * (m + 1)) // 2 + 1`。 この式は、円内の線の交差によって作成されたすべてのピースをカウントします。最初のカットは円を 2 に分割し、2 番目のカットは最初のカットと交差して最大 2 つの追加のピースを作成することができます。 各サークルは独立しているため、私たちの目標は、`k`間のカット`n`合計ピース数を最大化するために円を配置します。 

ピースを最大化するために、円にカットを貪欲に割り当てます。 各サークルのカットがゼロの状態から開始し、ピースの合計数が最も多くなるサークルに次のカットを繰り返し割り当てます。 円上の追加カットの限界利得は`cuts + 1`(からの増加`m`に`m+1`カットは`(m+1) - m`式の観点から)、並べ替えたり、優先キューを使用して、マージン ゲインが最も高い円に次のカットを常に割り当てることができます。 式は 2 次であるため、円上の初期のカットのゲインは小さくなります。そのため、すべてのカットが使用されるまで、円全体で均等にカットのバランスをとります。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n * k) | O(n) | 遅すぎる |
 | 欲張りカット配信 | O(k * log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 長さ _n_ の配列を初期化して、各円が受け取ったカットの数をカウントします。 最初はすべての値がゼロです。 
2. 優先キュー (最大ヒープ) を使用して、各サークルの次の潜在的なゲインを追跡します。 円にカットを追加することで得られるメリット`m`カットは`m + 1`。 
3. _k_ カットごとに次のようにします。 

ａ． ヒープから最大の電流ゲインを持つ円をポップします。 

b. カット数を 1 つ増やします。 

c. この円上の次のカットの新しいゲインを計算し、それをヒープに戻します。 
4. すべてのカットが配布されたら、次の式を使用して各円のピースの合計数を計算します。`(cuts * (cuts + 1)) // 2 + 1`そしてそれらを合計します。 
5. 合計値をバナナの最大本数として出力します。 

機能する理由: 円ごとの最大個数の計算式は数学的に正しいです。 限界ゲインによってカットを貪欲に割り当てることで、各カットが適用された時点で可能な最大数の新しいピースに寄与することが保証されます。 各円は独立しており、関数はカットに関して凹型であるため、この戦略はグローバル最大値を保証します。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

n, k = map(int, input().split())
circles = [tuple(map(int, input().split())) for _ in range(n)]

# initialize heap with (-gain, cuts, index)
# gain is negative because heapq is min-heap in Python
heap = [(-1, 0, i) for i in range(n)]  # initial gain is 1 for each circle
heapq.heapify(heap)

for _ in range(k):
    gain, cuts, i = heapq.heappop(heap)
    cuts += 1
    new_gain = -(cuts + 1)
    heapq.heappush(heap, (new_gain, cuts, i))

total_pieces = 0
for _, cuts, _ in heap:
    total_pieces += (cuts * (cuts + 1)) // 2 + 1

print(total_pieces)
```ヒープは、次のカットから最大の増加をもたらす円を効率的に選択するために使用されます。 負の値を使用すると、Python の最小ヒープが最大ヒープに変換されます。 カットを分配した後、標準の公式を使用して円ごとの最終的なピース数が計算されます。 ゼロカットで初期化し、_k_ で許可されているカットのみを追加するため、境界条件は自然に処理されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

## テストケース```python
import sys, io
def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import heapq
    n, k = map(int, input().split())
    circles = [tuple(map(int, input().split())) for _ in range(n)]
    heap = [(-1, 0, i) for i in range(n)]
    heapq.heapify(heap)
    for _ in range(k):
        gain, cuts, i = heapq.heappop(heap)
        cuts += 1
        heapq.heappush(heap, (-(cuts+1), cuts, i))

    return str(total)

 ## 特殊なケース

 カットがゼロの場合、各円は完全なままになります。`n`個。 1 つの円と 1 つのカットで、出力は次のようになります。`2`。 円よりも多くのカットが含まれるため、貪欲な配分により、カットのバランスが確実に保たれます。
