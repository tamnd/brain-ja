 ## 問題の理解

 バイナリ文字列が与えられます`s`そして長さ`n`。 すべてのバイナリ文字列を構築したい`t`長さの`n`。 そういったそれぞれの`t`は円形として扱われます。これは、その終わりがその始まりに折り返されることを意味します。 

円形の文字列`t`そのサイクルのどこかで見つけることができれば、有効であるとみなされます。`s`連続したセグメントとして。 同様に、読み始めると、`t`ある位置から折り返しを続けると、文字列全体と一致します。`s`。 

タスクは、異なるバイナリ文字列の数を数えることです。`t`この条件を満たします。 

重要な問題点は、`s`の終わりに折り返すことができます`t`したがって、の部分文字列をチェックするだけでは十分ではありません。`t`通常の直線的な意味で。 

制約は小さいです。`n ≤ 40`そして`|s| ≤ n`。 これは、文字列の総数が`2^40`、どのソリューションでも、それらを直接列挙することは避けなければなりません。 

すべてを生み出す素朴なアプローチ`2^n`文字列とチェックのそれぞれはすでに境界線に達していますが、それでも概念的には正しいです。 ただし、文字列ごとに周期的な出現をチェックするにはコストがかかります`O(n * |s|)`、完全なソリューションを大まかに作成します`O(n * |s| * 2^n)`が遅すぎます。 

さらに微妙な問題は、ラップアラウンド一致の処理です。 不注意な実装では、次の部分文字列のみがチェックされる可能性があります。`t + t`長さまで`n`ただし、境界でのオーバーラップの処理が間違っていたり、2 つのコピー間の分割にまたがるオカレンスが二重にカウントされたりします。 

正しいソリューションでは、線形文字列をカウントしながら、円形構造上でパターン マッチングがどのように動作するかを注意深くモデル化する必要があります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。すべてのバイナリ文字列を生成します。`t`長さの`n`、次に、次のことを確認します。`s`の回覧版に掲載されています`t`。 循環チェックは次の形式でシミュレートできます。`t + t`そして探しています`s`すべての有効な開始位置で。 これは正しいです。なぜなら、ラップアラウンド部分文字列は`t`の通常の部分文字列に対応します`t + t`。 

問題は複雑さです。 がある`2^n`文字列、各チェックは次の長さの文字列をスキャンします`O(n)`、おそらく長さのパターン一致を使用します`O(|s|)`。 これはおおよそ次のことにつながります`O(2^n * n * |s|)`、これは実現不可能です。 

重要な点は、完全な文字列を構築してからチェックするのではなく、文字列を 1 文字ずつ構築しながら、同時にパターンが正しいかどうかを追跡できることです。`s`循環構造に現れてきました。 パターン マッチングは、次の接頭辞に対する有限オートマトンとして表現できます。`s`。 これにより、すべての部分文字列チェック ロジックを小さなサイズの状態空間に圧縮できます。`O(|s|)`。 

残る難関は周回条件。 単一の文字列`t`の 2 つの重複スキャンを誘発します。`s`: 1 オン`t`それ自体と、複製された文字列の途中から始まるシフトされたコピー上の 1 つです。 これにより、循環連結の各半分に 1 つずつ、2 つの同時オートマトン プロセスを追跡する必要があります。

 ## アルゴリズムのチュートリアル

 二重化された文字列を使用して循環条件を再解釈します。`t + t`。 文字列`s`のサイクルで出現します`t`それが部分文字列として現れる場合に限り、`t + t`。 

今構築します`t`左から右へシミュレーションしながら`t + t`進化するだろう。 

1. パターンの接頭辞オートマトンを構築する`s`。 

各状態は何文字かを表します`s`現在、処理されたストリームのサフィックスとして一致しています。 トランジションは、読み取り後に一致の長さがどのように変化するかを示します。`0`または`1`。 
2. の構築を処理する DP 状態を定義します。`t`からのインデックスごとのインデックス`0`に`n - 1`。 

位置で`i`、2 つのオートマトンの状態を追跡します。 最初の状態は、次のプレフィックスのスキャンに対応します。`t`自体。 2 番目は、次のコピーのスキャンに対応します。`t`、ただし、効果的に開始されるのは位置の後でのみです`n`。 
3. 両方のオートマトン状態をゼロにして DP を初期化します。これは、文字がまだ処理されておらず、パターンが一致していないことを意味します。 
4. ポジションごとに`i`で`t`、どちらかを置いてみてください`0`または`1`。 

この選択により、最初のコピーのオートマトンの状態が遷移します。 もし`i ≥ n`、後半以降、同じキャラクターが 2 番目のコピーのオートマトン状態も遷移します。`t + t`今明らかにされつつある。 
5. 各遷移後、いずれかのオートマトンの状態が完全に一致したかどうかを確認します。`s`。 

そうである場合は、DP 状態を「一致」としてマークします。 一度一致すると、永久に一致したままになります。 
6. すべてのポジションを処理した後、一致に達したすべての DP 状態を合計します。 

DP は、少なくとも 1 回の発生を引き起こすすべてのバイナリ文字列を効果的にカウントします。`s`二重構造になっています。 

### なぜ効果があるのか

 すべてのバイナリ文字列`t`各位置は独立して決定されるため、この DP を通る 1 つのパスに正確に対応します。 オートマトンの状態は、どれだけの量を正確にエンコードします。`s`両方の関連するスキャンの各ポイントで一致します。`t + t`。 起こり得るすべての出来事から、`s`サイクル内の は、これら 2 つのスキャンのいずれかに出現する必要があり、状態を成功としてマークすることで、`t`有効です。 有効な文字列が失われることはありません。`t`が探索され、オートマトン内で実際の完全一致が形成された場合にのみ成功が記録されるため、無効な文字列はカウントされません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_automaton(s):
    m = len(s)
    pi = [0] * m
    for i in range(1, m):
        j = pi[i - 1]
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
        if s[i] == s[j]:
            j += 1
        pi[i] = j

    nxt = [[0, 0] for _ in range(m + 1)]
    for st in range(m + 1):
        for c in range(2):
            if st < m and int(s[st]) == c:
                nxt[st][c] = st + 1
            else:
                if st == 0:
                    nxt[st][c] = 0
                else:
                    nxt[st][c] = nxt[pi[st - 1]][c]
    return nxt

def solve():
    n = int(input().strip())
    s = input().strip()
    m = len(s)

    nxt = build_automaton(s)

    # dp[i][a][b][f]
    dp = [[[[0] * 2 for _ in range(m + 1)] for _ in range(m + 1)] for _ in range(n + 1)]
    dp[0][0][0][0] = 1

    for i in range(n):
        for a in range(m + 1):
            for b in range(m + 1):
                for f in range(2):
                    cur = dp[i][a][b][f]
                    if not cur:
                        continue

                    for c in (0, 1):
                        na = nxt[a][c]
                        nb = b
                        if i >= n:
                            nb = nxt[b][c]

                        nf = f or (na == m) or (nb == m)
                        dp[i + 1][na][nb][nf] += cur

    ans = 0
    for a in range(m + 1):
        for b in range(m + 1):
            ans += dp[n][a][b][1]

    print(ans)

if __name__ == "__main__":
    solve()
```コードは、パターンのプレフィックス オートマトンを構築することから始まります。`s`、一致状態間の一定時間の遷移が可能になります。 次に、DP はターゲット文字列の位置を反復処理します。`t`。 各位置で、可能な 2 つのバイナリ選択肢に分岐し、両方のオートマトンの状態を更新します。1 つは、最初のコピーを追跡するオートマトンです。`t`1 つと、インデックス後にアクティブになった 2 番目のコピーを追跡する 1 つ`n`。 

ブール次元`f`シミュレートされた円形スキャンのいずれかの時点でパターンがすでに一致したかどうかを記録します。 これにより、後の遷移によりオートマトンが完全な一致状態から離れるときに、以前の一致に関する情報が失われることが回避されます。 

最終的な答えは、少なくとも 1 つの一致が発生したすべての州を集計します。
