 ## 解決策
 ## 問題の理解

 各ブロックは 2 つの色の間の重み付けされた無向エッジとして見ることができ、各端点は方向に応じて 2 つの可能な色のいずれかになります。 方向を選択することは、パス内のエッジの方向を決定することと同じです。シーケンス内のブロックの順序を固定すると、隣接するすべてのペアが接触する色を正確に一致させるためです。 

タスクは、すべてのブロックを配置することではなく、サブセットを選択して単一のチェーンに配置し、選択したブロック値の合計を最大化しながら、隣接するブロックが同じ色で接続されるようにすることです。 各ブロックは最大 1 回使用され、ブロックを反転すると、その値は変更されずにエンドポイントが交換されるだけです。 

色空間は小さく、わずか 4 色ですが、ブロックの数は最大 100 個であるため、実際の難しさは組み合わせになります。どのサブセットをチェーンできるか、および最大の重みを蓄積するためにカラー グラフ内でチェーンをどのようにルーティングするかを決定することです。 

重要な構造上の制約は、有効なシーケンスが最大 4 つの頂点を持つマルチグラフ内のトレイルを形成するということです。 すべてのブロックはエッジであり、シーケンスはエッジを最大 1 回使用するウォークです。 

ローカルに考えると素朴な失敗モードが現れます。 たとえば、貪欲に常に最高値の互換性のあるブロックをアタッチすると、初期の選択がわずかに悪い別の順序で後でより多くの高値のエッジがロック解除される場合でも、構築が早期にトラップされる可能性があります。 もう 1 つの微妙な失敗は、構造が常にパスであると仮定していることです。最適な解決策では色を複数回再検討する可能性がありますが、エッジは依然として再利用されません。 

色は 1 ～ 4 のみであるため、接続状態空間は十分に小さいため、部分ソリューションがエンドポイントをどのように接続するかを明示的に追跡できます。 

## アプローチ

 ブルートフォース解釈では、ブロックのすべてのサブセットとすべての順序を両方の方向で試し、それが有効なチェーンを形成しているかどうかを確認します。 注文しなくても、サブセットを選ぶだけで$2^n$、それらを配置すると階乗複雑さが追加されます。 これは直ちに実行不可能です$n=100$。 

本当の単純化は、部分的な構築において重要なのは、チェーンの端でどの色が現在「開いている」かということだけであることに気づくことから来ます。 色は 4 つしかないため、状態はエンドポイントによって記述することができ、基本的には重み付きのエッジを使用して 4 ノードのグラフ上に接続された構造を構築しています。 

シーケンスの観点から考えるのではなく、選択されたすべてのエッジが 1 つのトレイル内にある接続されたサブグラフを構築することとして問題を再解釈します。 トレイル制約は、選択したエッジのマルチセット内で最大 2 つの頂点が奇数次数を持つようにすることで強制できます。 ただし、特定の色で開始または終了する必要はないため、任意のエンドポイントのペアを許可できます。 

これにより、エッジによって引き起こされる色のサブセットに対する動的プログラミングが可能になります。 これを解決する標準的な方法は、グラフを 4 つのノードに圧縮し、色のペア間のすべてのエッジを考慮することです。 色のペアごとにエッジを重みで並べ替え、各ペア間の上位 k 個のエッジを取ることを検討します。 次に、4 つのノードの次数パリティ状態に対して DP を実行します。 

より直接的で標準的な解決策は、これをマルチグラフ内で接続されたオイラー軌跡を形成するエッジのマルチセットを選択するものとして解釈することです。 4 つのノードでは接続性が自明であるため、制約はパリティになります。つまり、奇数次の頂点の数は 0 または 2 でなければなりません。この制約に従って総重みを最大化します。 

dp[mask] を、奇数の次数を持つ頂点のセットがマスクと等しくなるように、選択されたエッジの最大合計重みとして定義します。 各エッジはその 2 つのエンドポイントのパリティを反転するため、遷移は単純な XOR 更新になります。 

エッジを1つずつ処理してDPを更新しますが、各エッジを選択またはスキップでき、nは100だけなので、これで十分です。

 ## アルゴリズムのチュートリアル

 反転すると端点が交換されるだけなので、各ブロックを 2 つの色の方向のないエッジとして扱います。方向は無視されます。 

1. 各エッジが 2 つの色を接続し、重みを持っているエッジのリストを作成します。 これにより、問題は 4 つの頂点にわたる重み付けされたエッジのマルチセットの選択に変換されます。 
2. サイズ 16 の DP 配列を初期化します。ここで、各インデックスは 4 色のパリティ マスクを表します。 選択されたエッジのサブセット内で対応する色が現在奇数次数を持っている場合、ビットは 1 になります。 
3. dp[0] = 0 に設定します。これは、エッジが選択されていない場合、奇数の度数は発生せず、値は 0 になることを意味します。 他のすべての状態はまだ到達できないため、負の無限大に初期化されます。 
4. 各エッジに対して繰り返します。 u と v を重み w で接続する各エッジについて、スキップするかそのままにするかの 2 つの選択肢を検討します。 これを採用した場合、ビット u と v を切り替えてパリティを更新し、合計値に w を加算します。 
5. 各エッジに対して、次に新しい DP 配列を計算します。これは最初に dp からコピーされ、エッジをスキップするオプションを表します。 次に、すべての状態マスクについて、重みを追加したマスク XOR (1<<u) XOR (1<<v) に移行します。 
6. 各エッジを処理した後、dp を next に置き換えます。 これにより、各エッジが最大 1 回使用されることが保証されます。 
7. すべてのエッジを処理した後、答えはすべてのマスクの最大 dp[mask] になります。マスクには 0 または 2 ビットが設定されています。これらのビットは有効なオイラー軌跡に対応するためです。 

### なぜ効果があるのか

 有効なシーケンスはすべて、軌跡を形成するエッジの選択に対応します。これは、おそらく 2 つを除くすべての頂点が偶数次であることを意味します。 DP は、選択された各エッジの後の次数パリティを明示的に追跡し、エンドポイントの反転が次数パリティの更新と正確に一致するため、すべての遷移が正確さを維持します。 エッジのすべてのサブセットは何らかの選択シーケンスによって表現できるため、DP はすべての有効な構成をカバーします。 有効なパリティ マスクを最大化することで、サイクルとオープン トレイルの両方が確実に含まれるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def popcount(x):
    return bin(x).count("1")

def solve():
    n = int(input())
    edges = []
    
    for _ in range(n):
        a, w, b = map(int, input().split())
        u = a - 1
        v = b - 1
        edges.append((u, v, w))
    
    INF = -10**18
    dp = [INF] * 16
    dp[0] = 0
    
    for u, v, w in edges:
        ndp = dp[:]  # skip edge
        bit = (1 << u) ^ (1 << v)
        for mask in range(16):
            if dp[mask] == INF:
                continue
            nm = mask ^ bit
            ndp[nm] = max(ndp[nm], dp[mask] + w)
        dp = ndp
    
    ans = 0
    for mask in range(16):
        if dp[mask] == INF:
            continue
        if popcount(mask) in (0, 2):
            ans = max(ans, dp[mask])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP アレイは、エッジのプレフィックスを処理した後、到達可能なすべてのパリティ構成をエンコードします。 遷移ステップはエッジを無視するか、エッジを含めます。また、包含によって端点のパリティが反転されます。これはまさにグラフにエッジを追加した場合の効果です。 

最後のフィルタリング ステップでは、オイラー トレイル条件を適用します。 奇数頂点が 0 個あるマスクはサイクルに対応し、奇数頂点が 2 つあるマスクはオープン パスに対応します。 

実装の微妙な点は、遷移の前に dp を ndp にコピーする必要があることです。 そうしないと、更新で 1 回の反復内で同じエッジが複数回再利用されます。 

## 実用的な例

 ### サンプル 1

 エッジの縮小表示で dp がどのように変化するかを追跡するだけです。 マスクは 4 ビット値として表示されます。 

| ステップ | エッジ | アクション | dp 更新 (非無限状態) |
 | --- | --- | --- | --- |
 | 0 | なし | 初期化 | dp[0000] = 0 |
 | 1 | 2-1 (w=1) | テイク/スキップ | dp[0000]=0、dp[0011]=1 |
 | 2 | 1-4 (w=2) | 蓄積する | dp は両方の状態からの遷移とともに増加します。 
| ... | ... | ... | 最終ベスト = 63 |

 これは、DP 内に複数のパスが同時に共存し、異なるパリティ状態を組み合わせることで最適な解が現れることを示しています。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n = int(input())
    edges = []
    for _ in range(n):
        a, w, b = map(int, input().split())
        edges.append((a, w, b))

    INF = -10**18
    dp = [INF] * 16
    dp[0] = 0

    def popcount(x):
        return bin(x).count("1")

    for a, w, b in edges:
        u, v = a - 1, b - 1
        ndp = dp[:]
        bit = (1 << u) ^ (1 << v)
        for mask in range(16):
            if dp[mask] == INF:
                continue
            nm = mask ^ bit
            ndp[nm] = max(ndp[nm], dp[mask] + w)
        dp = ndp

    ans = 0
    for m in range(16):
        if dp[m] != INF and popcount(m) in (0, 2):
            ans = max(ans, dp[m])

    return str(ans)

 ## 特殊なケース

 初期 DP ではすでにエッジなしまたは単一エッジの選択が許可されており、単一エッジが常に有効なシーケンスを形成するため、1 つのブロックを持つ最小入力は正しく処理されます。 

エッジ (1,2) や (3,4) などの素な色のペアの場合、DP は両方の寄与を独立して保持し、パリティ遷移で相互作用しないため、最終的な答えはそれらを正しく合計します。 

ゼロ奇数次数のマスクは自然に閉じたサイクルを表すため、サイクルの多い入力が処理されます。DP ではエンドポイントを必要とせずに閉サイクルを形成できるため、完全なサイクルの重みが確実に保持されます。 

最も微妙なケースは、より大きなチェーンを有効にするために、値の高いエッジを一時的にスキップする必要がある場合です。 DP は貪欲にコミットしないため、スキップと取得の両方が並行して探索され、最大値が最終状態に保持されます。
