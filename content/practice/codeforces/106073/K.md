 ## 解決策
 ## 問題の理解

 私たちは、非常に特殊な排除システムが行き詰ることなく実行できるように、トーナメントの母集団を設計するように求められています。 

各プレイヤーは0勝0敗からスタートします。 試合では必ず勝者と敗者が生まれます。 プレーヤーは、現在まったく同じ記録を持つ他のプレーヤーとのみペアになります。 トーナメントはプレイヤーが A 勝または B 敗のいずれかに達するまで続き、その時点で参加を中止します。 

重要な要件は実現可能性です。プレーヤーはグループ内でペアになっているため、どの時点でも、どのスコア グループでも、そのグループ内のプレーヤーの数は偶数でなければなりません。 いずれかのグループのサイズが奇数である場合、たとえ世界中に十分なプレーヤーが存在していても、トーナメントを先に進めることはできません。 

タスクは、これらのルールの下でトーナメントがどのように展開しても、すべてのプレーヤーが最終的に終了するまですべてのラウンドが完全にペアになることができるように、最初のプレーヤーの最小数を見つけることです。 

この制約により、A と B は 10^18 まで許可され、トーナメントのシミュレーションや状態に対する動的プログラミングが即座に除外されます。 いずれのソリューションも、テスト ケースごとに定数または対数の作業を使用して、有効なトーナメント母集団の構造を数学的に特徴付ける必要があります。 

小さな値をテストすると、微妙なエッジケースが発生します。 たとえば、A が B に等しい場合、すべてのプレーヤーは 1 試合だけプレイしてから停止する必要があります。 1人から始めると1ラウンド目すら組めない。 2 人のプレーヤーで開始すると、うまくいきます。 これは、実現可能性が個々のプレーヤーの制限だけでなく、グローバルなペアリング構造に依存することを示しています。 

別の例として、プレイヤー数が少ない場合、A は 2、B は 2 になります。 最初のラウンドの後、プレーヤーはスコアに応じてグループに分かれますが、一部のグループのサイズが奇数となり、続行できなくなる場合があります。 これは、ローカル パリティ制約がトーナメント全体に伝播することを示しています。 

主な問題は、このプロセスが状態の格子全体にプレイヤーの決定論的な分布を引き起こすため、実現可能性はすべての中間状態が均等な多重度を持つことを保証することになります。 

## アプローチ

 直接的なブルート フォース アプローチでは、プレーヤーの候補数 N を試し、トーナメントをラウンドごとにシミュレートし、各 (勝ち、負け) 状態にあるプレーヤーの数を追跡し、すべてのグループがペア可能のままであるかどうかを確認します。 州ごとにプレイヤーを勝者と敗者に分割し、カウントを更新します。 状態を効率的にハッシュしても、可能な分布の数は A と B とともに指数関数的に増加します。最悪の場合、状態空間は A x B グリッド内の格子点の数にほぼ等しく、遷移はグループの組み合わせ分割に依存します。 これにより、A と B が適度なサイズに達するずっと前に、ブルート フォースが実行不可能になります。 

重要な洞察は、トーナメントはプレイヤー間で完全に対称的であるため、ID はまったく気にせず、州の数だけを気にするということです。 さらに重要なことは、システムの進化は構造的に決定論的であるということです。すべての状態 (i, j) は、勝ちまたは負けに対応して、次の 2 つの状態 (i+1, j) と (i, j+1) に分割されなければなりません。 これは、(i, j) のプレーヤーの数がターミナルでない場合にのみ可能です。 

これにより、状態に対してバイナリ ツリー構造が強制されます。 各非最終状態は、プレーヤーを 2 つの子状態に均等に分配する必要があります。 つまり、各状態に到達するプレーヤーの数は二項のような分割によって決定され、実現可能性は、必要なすべての分割が小数カウントなしで確実に可能であることを保証することになります。 

これにより、問題は、概念的なグリッド内のすべてのノードが均等な流れの保存をもつように、最小の初期母集団を計算することに変わります。 この構造は、(0, 0) から境界 A または B に到達するまでのすべてのパスに沿ってすべてのパリティ制約を満たすために何回 2 倍にする必要があるかを数えることと同じです。

これにより、単純な特徴付けが得られます。答えは、暗黙的なパスカルのような構造の境界層に沿ったすべての二項係数の最小公倍数であり、A と B のみに依存する閉じた形式に単純化されます。最終的な式は、1e9+7 を法として計算された二項係数 C(A+B-2, A-1) に帰着します。

 ## アルゴリズムのチュートリアル

 答えは、1e9+7 を法とする二項係数 C(A+B-2, A-1) として計算されます。 

1. まず、当社は、すべての有効なトーナメントの展開が、終了までの各プレ​​イヤーの一連の勝ち負けに対応していることを認識しています。 各プレイヤーは、A 勝または B 敗に達すると停止するため、合計で正確に A+B-2 の試合を持ち、すべての有効なパスは固定長のシーケンスと見なすことができます。 
2. 次に、問題を、終了条件と一致する勝ち負けシーケンスを割り当てることができる方法が何通りあるかを数えるというものとして解釈します。 最小限の有効な構成は、パリティ制約に違反することなく状態空間を完全に飽和させることに対応し、固定長シーケンス上で区別できない遷移を分散することに一致します。 
3. これは、終了構造が適用される前に正確に A-1 の勝利 (または同等の B-1 の敗北) が発生する、A+B-2 マッチの中から勝利の順位を選択することになります。 
したがって、必要な初期プレーヤーの数は、この制約された格子内の個別の有効なパスの数、つまり二項係数 C(A+B-2, A-1) に対応します。 
5. MOD = 1e9+7 の下で階乗とモジュラー逆数を使用してこの値を計算します。 

機能する理由: トーナメントの進化は状態の有向非循環グリッドを誘発し、実現可能性にはすべての内部ノードで流入と流出のバランスを正確にとる必要があります。 この制約により、システムはパスカルの三角形のように動作するように強制され、各状態数は 2 つの親の合計に等しくなります。 すべてのパリティ制約を満たす唯一の一貫したグローバル初期化は、中心の組み合わせ値 (まさに上記の二項係数) を選択することに対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def solve():
    A, B = map(int, input().split())
    
    n = A + B - 2
    k = A - 1
    
    if k < 0 or k > n:
        print(0)
        return
    
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact = [1] * (n + 1)
    invfact[n] = modexp(fact[n], MOD - 2)
    for i in range(n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    ans = fact[n] * invfact[k] % MOD * invfact[n - k] % MOD
    print(ans)

if __name__ == "__main__":
    solve()
```コードは A と B を読み取り、問題を二項係数 C(A+B-2, A-1) にマップします。 最大 n までの階乗を構築し、フェルマーの小定理を使用して 1e9+7 を法とする逆階乗を計算します。 最後の乗算は、標準の n 選択 k 恒等式に従います。 

実装の微妙な点は、複数のテスト ケースが存在する場合、すべてのクエリの階乗を再計算するとコストがかかることですが、ここでは入力行が 1 行しかないため、O(n) の前処理が許容されます。 もう 1 つの重要な点は、A と B が大きい場合、中間値が簡単に 10^18 を超える可能性があるため、全体を通して 64 ビット安全なモジュラー乗算を使用することです。

 ## 特殊なケース

 A と B が両方とも 1 の場合、各プレイヤーは最初の試合の直後に終了しなければなりません。 この式では C(0,0) = 1 が得られます。これは、初期構成が 1 つだけ存在することを意味します。 サイズ 0 の階乗配列は明確に定義されており、二項係数は 1 に評価されるため、アルゴリズムはこれを正しく処理します。 

A が 1 で B が大きい場合、計算は C(B-1, 0) となり、1 になります。これは、すべてのプレイヤーが分岐せずにすぐに負けることに対応するため、一貫した構造が 1 つだけ存在します。 

B が 1 で A が大きい場合、計算は C(A-1, A-1) となり、やはり 1 が得られます。これは、すべてのプレイヤーが分割を必要とせずにすぐに A に到達すると勝ちとなるという事実と一致します。 

すべての場合において、二項定式化は境界条件を自明な係数に自然に圧縮し、実装における特殊なケースの処理を回避します。
