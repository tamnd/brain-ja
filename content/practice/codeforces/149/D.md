 ## 問題の理解

 有効な括弧シーケンスが与えられています。 すべての開始括弧には一意の対応する終了括弧があり、そのペアは適切にネストされています。 

2 つのルールに従って括弧に色を割り当てたいと考えています。 一致するすべてのペアについて、2 つのブラケットのうちの 1 つだけを色付けする必要があり、もう 1 つは色付けしないでください。 色付きブラケットは赤または青のいずれかになります。 2 番目のルールは、隣接する色付きブラケットが同じ色を共有することを禁止します。 

タスクは、有効な色がいくつ存在するかを数えることです。`10^9 + 7`。 

シーケンスの長さは最大 700 です。これにより、ブルートフォース列挙が即座に除外されます。 すべてのブラケットのペアには、次の 4 つの可能なローカル状態があります。 

- 左側のブラケットを赤に色付けします
 - 左側のブラケットを青色に色付けします
 - 右側のブラケットを赤に色付けします
 - 右側のブラケットを青色に色付けします

 文字列に 350 ペアがある場合、ブルート フォースで検査されます。`4^350`任務、それは完全に不可能です。 

700 という制限は、間隔 DP を強く示唆しています。 括弧の一致に関する問題は、多くの場合、自然にネストされた間隔に分解されます。`O(n^3)`または`O(n^4)`通常、このサイズでは動的プログラミングが許容されます。 

厄介な点は、隣接関係の制約が間隔の境界を越えることです。 2 つの独立して有効なサブインターバルは、隣接する括弧が同じ色を受け取るため、連結すると無効になる場合があります。 

いくつかのエッジケースでは、単純な実装が静かに破壊されます。 

最小の有効なシーケンスを考えてみましょう。```

```答えは`4`。

- 左が赤
 - 左青
 - 右赤
 - 右青

 不注意な実装では、各ペアの 1 つの括弧が色付けされていない必要があることを忘れることがあります。 

別の微妙なケースは次のとおりです。```

```外側の左括弧と内側の左括弧は隣接する文字です。 両方が青色に着色されている場合、たとえそれらが異なるペアに属していても、その色付けは無効です。 外側のペアとその内側の間隔を組み合わせる遷移では、この隣接性をチェックする必要があります。 

この問題の最も難しい部分は、マージ中にこれらの隣接する競合を検証できるように、間隔の境界で色を正しく追跡することです。 

## アプローチ

 ブルートフォースアプローチは概念的には単純です。 まず、スタックを使用して、一致するすべてのブラケットのペアを計算します。 次に、すべてのペアについて、次の 4 つの状態のいずれかを選択します。 

- 開始ブラケットを赤に色付けします
 - 開始ブラケットを青色に色付けします
 - 閉じ括弧を赤色に色付けします
 - 閉じ括弧を青色に色付けします

 すべてのペアに状態を割り当てた後、シーケンスをスキャンし、隣接する色の括弧が同じ色を共有していないことを確認します。 

これは、制約がローカルであるため機能します。 すべての完全な割り当ては直線的な時間でチェックできます。 

問題は課題の数です。 長さ 700 のシーケンスには 350 ペアが含まれており、`4^350`可能性。 その数を保存するだけでも途方もなく大きいです。 

重要な観察は、正しい括弧シーケンスには再帰的な構造があるということです。 

すべての間隔は次のいずれかです。 

- 別の正しいシーケンスを囲む単一の一致するペア
 - または 2 つの正しいシーケンスの連結

 この再帰構造は、まさに DP が利用する間隔です。 

隣接条件は隣接する文字にのみ依存するため、2 つの間隔を結合する場合は、それらの境界の色のみを知る必要があります。 中身はすべて検証済みです。 

これにより、インターバルにわたる DP が発生します。 

定義する：`dp[l][r][a][b]`どこ：

-`s[l...r]`正しい括弧サブシーケンスです
 -`a`位置の色の状態です`l`-`b`位置の色の状態です`r`次の 3 つの状態を使用します。 

-`0`= 無着色
 -`1`= 赤
 -`2`= 青

 DP 値には、その間隔で有効なカラーリングの数が保存されます。 

なぜ境界色だけで十分なのでしょうか?

 マージ中に作成される唯一の新しい隣接関係は、サブ間隔間の接触位置で発生するためです。 内部隣接性はすでに再帰的にチェックされています。 

一致するペアごとに`(l, r)`構造的には 2 つのケースがあります。 

もし`l`直接一致する`r`、その後、その中に別の間隔をラップすることによって間隔が形成されます。 どちらかを着色する有効な方法をすべて試します`l`または`r`、次に内部間隔境界との隣接性を確認します。 

区間が 2 つの平衡区間を連結したものである場合、左側の部分と右側の部分の境界を確認しながらそれらを結合します。 

これにより、多項式 DP への指数関数的な検索が削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(4^(n/2) * n) | O(n) | 遅すぎる |
 | 最適 | O(n^3 * 9) | O(n^2 * 9) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. スタックを使用して一致する括弧の位置を計算します。 

私たちが見るたびに`'('`、そのインデックスをプッシュします。 私たちが見るたびに`')'`、対応する開始ブラケットをポップします。 
2. DP テーブルを定義します。`dp[l][r][a][b]`どこ`a`そして`b`ポジションの色です`l`そして`r`。 
3. 3 つの色の状態を使用します。 

-`0`無着色を意味します
 -`1`赤を意味します
 -`2`青を意味します
 4. 最小間隔を処理する`"()"`。 

もし`l`マッチ`r`そして`r = l + 1`、有効な状態は正確に 4 つあります。 

- 左が赤
 - 左青
 - 右赤
 - 右青
 5. 長さを増やして間隔を処理します。 

遷移はより短い間隔に依存するため、より短いセグメントを最初に解決する必要があります。 
6. 一定の間隔で、`match[l] = r`、内側の間隔をラップする外側のペアとして扱います。 

外側のペアは 4 つの可能性をもたらします。 

- 左が赤
 - 左青
 - 右赤
 - 右青

 すべての内部状態について、隣接性を確認します。 

-`l`そして`l+1`-`r-1`そして`r`2 つの隣接する色付き括弧がゼロ以外の同じ色を共有する場合、トランジションを破棄します。 
7. 間隔が連結の場合は、有効な中間点ごとに分割します。 

次のように仮定します。 

- 左の間隔は`[l, k]`- 正しい間隔は`[k+1, r]`両方の区間のすべての境界状態を結合します。 
8. 2 つの区間をマージしながら、中央の境界を確認します。 

ポジション`k`そして`k+1`フルシーケンスで隣接するようになります。 両方がゼロ以外の同じ色で着色されている場合、マージは無効です。 
9. すべての有効なトランジションをモジュロで加算します`10^9 + 7`。 
10. 最終的な答えは、全区間のすべての境界状態の合計です。`[0, n-1]`。 

### なぜ効果があるのか

 すべての有効なカラーリングは、ブラケット シーケンスの 1 つの再帰的分解にのみ属します。 

DP は、各間隔のすべての有効なカラーリングを、後でその間隔を隣接する間隔に安全に接続するために十分な情報とともに保存します。 隣接制約には隣接する位置のみが含まれるため、外部的に必要な情報は境界括弧の色だけです。 

間隔をラップするときは、外側のペアと内側の間隔の間に新しく作成された 2 つの隣接関係を明示的に検証します。 間隔を連結するときは、マージ境界で単一の新しい隣接関係を明示的に検証します。 

他のすべての隣接関係はすでに再帰的に検証されています。 すべての正当なカラーリングは 1 回だけ生成され、生成されたすべてのカラーリングはすべての制約を満たすため、DP は正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

s = input().strip()
n = len(s)

match = [-1] * n
stack = []

for i, ch in enumerate(s):
    if ch == '(':
        stack.append(i)
    else:
        j = stack.pop()
        match[i] = j
        match[j] = i

# dp[l][r][a][b]
dp = [[[[0] * 3 for _ in range(3)] for _ in range(n)] for _ in range(n)]

for length in range(2, n + 1):
    for l in range(n - length + 1):
        r = l + length - 1

        if match[l] != r:
            continue

        # Base case: "()"
        if l + 1 == r:
            dp[l][r][1][0] = 1
            dp[l][r][2][0] = 1
            dp[l][r][0][1] = 1
            dp[l][r][0][2] = 1
            continue

        # Case 1: outer pair wraps entire interval
        if match[l + 1] == r - 1:
            inner = dp[l + 1][r - 1]

            for a in range(3):
                for b in range(3):
                    val = inner[a][b]
                    if val == 0:
                        continue

                    # color left bracket
                    for c in [1, 2]:
                        if not (c == a and c != 0):
                            dp[l][r][c][0] = (
                                dp[l][r][c][0] + val
                            ) % MOD

                    # color right bracket
                    for c in [1, 2]:
                        if not (c == b and c != 0):
                            dp[l][r][0][c] = (
                                dp[l][r][0][c] + val
                            ) % MOD

        else:
            # General wrapped structure:
            # [l ... m] + [m+1 ... r]
            m = match[l]

            left_dp = dp[l][m]
            right_dp = dp[m + 1][r]

            for a in range(3):
                for b in range(3):
                    left_val = left_dp[a][b]
                    if left_val == 0:
                        continue

                    for c in range(3):
                        for d in range(3):
                            right_val = right_dp[c][d]
                            if right_val == 0:
                                continue

                            if b != 0 and b == c:
                                continue

                            dp[l][r][a][d] = (
                                dp[l][r][a][d]
                                + left_val * right_val
                            ) % MOD

answer = 0

for a in range(3):
    for b in range(3):
        answer = (answer + dp[0][n - 1][a][b]) % MOD

print(answer)
```最初の部分では、スタックを使用して一致する括弧を計算します。 これにより、文字列が再帰間隔構造に変換され、DP はこれに依存します。 

考えられる境界状態は 3 つだけであるため、DP 次元は十分に小さいです。 間隔カウントは`O(n^2)`、各間隔に格納されます。`3 * 3 = 9`州。 

最も微妙な部分は、ラッピングと連結を区別することです。 

もし`match[l] == r`の場合、間隔全体が 1 つの外側のペアでラップされます。 内側の間隔は次のようになります。`[l+1, r-1]`。 どちらかの外側のブラケットに色を付けて、内側の境界との隣接性を確認します。 

外側のペアが早く閉じる場合、シーケンスは 2 つの連続するバランスの取れた部分に分解されます。 分割点は次のように一意に決定されます。`match[l]`。 

隣接性チェックは間違いやすいものです。 2 つの隣接する括弧が両方とも色付きで同じ色を共有している場合にのみ拒否されます。 色の付いていない括弧が競合することはありません。 

もう 1 つの簡単な間違いは、任意の分割点を反復することによって連結を二重にカウントすることです。 正しい分解は、最初に一致するペアによって一意に決定されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^3) | 一定サイズの状態遷移による O(n^2) 間隔 |

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

MOD = 10**9 + 7

def solve():
    input = sys.stdin.readline

    s = input().strip()
    n = len(s)

    match = [-1] * n
    stack = []

    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)
        else:
            j = stack.pop()
            match[i] = j
            match[j] = i

    dp = [[[[0] * 3 for _ in range(3)] for _ in range(n)] for _ in range(n)]

    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1

            if match[l] != r:
                continue

            if l + 1 == r:
                dp[l][r][1][0] = 1
                dp[l][r][2][0] = 1
                dp[l][r][0][1] = 1
                dp[l][r][0][2] = 1
                continue

            if match[l + 1] == r - 1:
                inner = dp[l + 1][r - 1]

                for a in range(3):
                    for b in range(3):
                        val = inner[a][b]

                        for c in [1, 2]:
                            if not (c == a and c != 0):
                                dp[l][r][c][0] += val

                        for c in [1, 2]:
                            if not (c == b and c != 0):
                                dp[l][r][0][c] += val

            else:
                m = match[l]

                for a in range(3):
                    for b in range(3):
                        left = dp[l][m][a][b]

                        for c in range(3):
                            for d in range(3):
                                right = dp[m + 1][r][c][d]

                                if b != 0 and b == c:
                                    continue

                                dp[l][r][a][d] += left * right

    ans = 0

    for a in range(3):
        for b in range(3):
            ans += dp[0][n - 1][a][b]

    print(ans % MOD)

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue().strip()
