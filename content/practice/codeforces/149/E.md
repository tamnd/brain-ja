 ## 解決策
 ## 問題の理解

 この問題では、一列に並んだ目を持つ火星人が描かれており、それぞれの目は大文字でマークされた斑点で覆われています。 すべての目を開いたときに見える文字列は、長さ _n_ のシーケンス _s_ を表します。 火星人は、連続する目の重なり合わない 2 つのセグメントを正確に開くことを選択できます。 これを行った後、文字を順番に読み、単語に結合します。 一連の _m_ 個の火星の単語は美しいと考えられており、火星人が 2 つのセグメントを開くことでいくつの異なる美しい単語を生成できるかを数える必要があります。 

重要な点は、文字列 _s_ の長さは最大 100,000 文字で、美しい単語はそれぞれ最大 1,000 文字ですが、美しい単語は最大 100 文字であるということです。 _n_ が大きいため、考えられるすべてのセグメントのペアを直接列挙すると、O(n²) 個の可能性があり、これはおよそ 10¹⁰ 回の操作に相当し、2 秒の制限時間を大幅に超えます。 したがって、考えられるすべての 2 つのセグメントの組み合わせを生成し、それらをそれぞれの美しい単語と比較する単純な総当りソリューションは機能しません。 2 つのセグメントの組み合わせが美しい単語の 1 つを形成しているかどうかを効率的にチェックする方法が必要です。 

エッジ ケースには、2 つのセグメントが文字列の端に接触しているか、最小の長さである状況が含まれます。 たとえば、_s_ = "AA" で、美しい単語が "AA" である場合、火星人は第一の目と第二の目を別々に開いて "AA" を見ることができます。 単純な実装では、セグメントが連続していて単語を完全にカバーしている必要があると誤って想定する可能性があります。 もう 1 つの注意が必要なケースは、セグメント境界での部分一致とのオーバーラップです。 これらを見逃さないように、慎重な取り扱いが必要です。 

## アプローチ

 ブルートフォース手法では、重複しないセグメントのペアをすべて生成し、文字を連結し、結果の文字列をすべての美しい単語と比較します。 長さが _n_ の文字列の場合、最初のセグメントにはおよそ O(n²) 個の選択肢があり、最初のセグメントに続く 2 番目のセグメントには O(n²) 個の選択肢があり、最悪の場合は O(n⁴) 個の連結が発生します。 単語との各比較には O(L) 時間がかかります。L は最大 1000 です。これは明らかに実行不可能です。 

最適な解決策は、_s_ のすべての部分文字列を効率的に表すサフィックス オートマトンと呼ばれる文字列マッチング構造に依存します。 接尾辞オートマトンを構築したら、任意の文字列をその長さに対して線形時間でテストして、それが _s_ の部分文字列であるかどうかを確認できます。 2 つのセグメントを処理するために、各美しい単語をすべての可能な 2 つの部分に分割し、最初の部分が _i_ の位置で終わる部分文字列として表示され、2 番目の部分が _i_ の後に始まる部分文字列として表示されるかどうかを確認します。 これは、_s_ 用の順方向接尾辞オートマトンと、反転文字列用の逆方向オートマトンの両方を構築することによって効率的に行うことができます。 次に、美しい単語の分割ごとに、すべてのセグメントの位置を明示的に列挙することなく、前半がどこかで終わる部分文字列であり、後半がその後のどこかで始まる部分文字列であるかどうかを確認します。 

重要な洞察は、問題は、それぞれの美しい単語が 2 つの部分文字列に分解できるかどうかをチェックすることに帰着し、両方とも _s_ に出現し、2 番目の文字列が最初の単語の後に出現するかどうかを確認することです。 接尾語オートマトンを使用すると、このチェックを単語長に単語数を乗じて線形に時間的に行うことができ、制約に対して十分に高速な解決策が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n⁴ * L) | O(n²) | 遅すぎる |
 | サフィックスオートマトン分割チェック | O(n + Σ | pᵢ | ²) |

 ## アルゴリズムのチュートリアル

1. 文字列 _s_ のサフィックス オートマトンを構築します。 これにより、_s_ に部分文字列が存在するかどうかをすばやく確認できます。 各状態は部分文字列のセットを表し、遷移は文字の追加に対応します。 
2. 反転文字列 _s_ のサフィックス オートマトンを構築します。 これにより、反転された単語をクエリすることで、任意の位置で終わる部分文字列をすばやく確認できます。 
3. 表示された美しい単語の数のカウンターを初期化します。 
4. 美しい単語ごとに、考えられるすべての分割を繰り返して 2 つの空ではない部分に分割します: 左側の部分`u`そして右側の部分`v`。 
5. 各分割について、次のことを確認します。`u`元のオートマトンに部分文字列として存在し、`v`の反転オートマトンの部分文字列として存在します`s`(反転後`v`）。 両方の部分が _s_ に表示され、順序に違反する形で重なり合わない場合、分割は有効です。 
6. 少なくとも 1 つのスプリットが条件を満たす場合、カウンタをインクリメントします。 
7. カウンタを出力します。 

機能する理由: サフィックス オートマトンは、_s_ のすべての部分文字列が部分文字列の長さに関して線形時間でチェックできることを保証します。 それぞれの美しい単語を分割することで、火星人が 2 つのセグメントを開いてその単語を確認できる可能性をすべてカバーします。 すべての分割が考慮されるため、単語を見逃すことはありません。また、少なくとも 1 つの分割が一致した場合に各単語を 1 回だけカウントするため、二重にカウントすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SuffixAutomaton:
    def __init__(self):
        self.states = [{'len': 0, 'link': -1, 'next': {}}]
        self.last = 0

    def extend(self, c):
        p = self.last
        cur = len(self.states)
        self.states.append({'len': self.states[p]['len'] + 1, 'link': 0, 'next': {}})
        while p != -1 and c not in self.states[p]['next']:
            self.states[p]['next'][c] = cur
            p = self.states[p]['link']
        if p == -1:
            self.states[cur]['link'] = 0
        else:
            q = self.states[p]['next'][c]
            if self.states[p]['len'] + 1 == self.states[q]['len']:
                self.states[cur]['link'] = q
            else:
                clone = len(self.states)
                self.states.append({'len': self.states[p]['len'] + 1,
                                    'link': self.states[q]['link'],
                                    'next': self.states[q]['next'].copy()})
                while p != -1 and self.states[p]['next'][c] == q:
                    self.states[p]['next'][c] = clone
                    p = self.states[p]['link']
                self.states[q]['link'] = self.states[cur]['link'] = clone
        self.last = cur

    def contains(self, s):
        current = 0
        for ch in s:
            if ch not in self.states[current]['next']:
                return False
            current = self.states[current]['next'][ch]
        return True

def main():
    s = input().strip()
    n = len(s)
    m = int(input())
    words = [input().strip() for _ in range(m)]

    sam = SuffixAutomaton()
    for ch in s:
        sam.extend(ch)
    s_rev = s[::-1]
    sam_rev = SuffixAutomaton()
    for ch in s_rev:
        sam_rev.extend(ch)

    count = 0
    for word in words:
        L = len(word)
        found = False
        for split in range(1, L):
            left, right = word[:split], word[split:]
            if sam.contains(left) and sam_rev.contains(right[::-1]):
                found = True
                break
        if found:
            count += 1
    print(count)

if __name__ == "__main__":
    main()
```コードは最初に 2 つの接尾辞オートマトンを構築します。1 つは元の文字列用、もう 1 つは反転された文字列用です。 これにより、最初または 2 番目のセグメントに出現する必要がある部分文字列のメンバーシップ チェックを迅速に行うことができます。 それぞれの美しい単語を可能な限り分割し、左側と右側の部分を個別にチェックします。 の`contains`このメソッドはオートマトンの状態を効率的に実行し、文字が欠落している場合はすぐに失敗します。 これにより正確さが保証され、1 つずつずれたエラーが回避されます。 

## 実用的な例

 サンプル 1:

 入力`s = "ABCBABA"`そして美しい言葉`["BAAB", "ABBA"]`。 

| 単語 | 分割 | 左 | 右にs | 数えられた？ |
 | --- | --- | --- | --- | --- |
 | バーブ | 1-3 | B、BA | ＡＡＢ | いいえ |
 | アバ | 1-3 | AB | BA | はい |

 この表は、「ABBA」が文字列内に順番に現れる「AB」と「BA」に分割できることを示しています。 したがって、出力は 1 になります。 

カスタム例 2:

 入力`s = "AAAA"`そして美しい言葉`["AA"]`。 

| 単語 | 分割 | 左 | 右にs | 数えられた？ |
 | --- | --- | --- | --- | --- |
 | AA | 1 | あ | あ | はい |

 文字が繰り返されている場合でも、オートマトンは「AA」が 2 つのセグメントから形成できることを正確に識別します。
