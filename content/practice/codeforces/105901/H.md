 ## 解決策
 ## 問題の理解

 非常に特殊な幾何学的特性を持つ 2 つの非常に大きな正の整数 (x と y と呼ぶ) を構築するように求められます。 

整数のペアに対して許可される唯一の操作は、1 つの座標をプラスまたはマイナス 1 だけ変更することによってグリッド内を移動することです。そのような移動にはそれぞれ 1 単位のコストがかかります。 (x, y) から始めて、最大公約数が 1 であるペア (x', y') に到達するまで、整数グリッド内を歩くことができます。問題のコストは、そのような互いに素なペアに到達するために必要な最小ステップ数です。 

したがって、固定開始点の場合、注目する値は、gcd(a, b) = 1 となる最も近い点 (a, b) までのグリッド内の L1 距離です。 

ここで、タスクは逆になります。 最大 20 までのターゲット値 k が与えられており、最も近い互いに素のペアが正確に k ステップ離れたところにあるように x と y を構築する必要があります。 

x と y の制約は、大きさが 10^1500 までと非常に緩いため、実際には、オーバーフローを心配することなく、多くの桁の数値を自由に作成したり、中国の剰余定理積のような巨大な構造に依存したりできることを意味します。 

主な微妙な点は、答えが (x, y) の周囲全体に依存することです。 単一の gcd 値を制御しているのではなく、(x, y) の周囲の半径 k のダイヤモンド内のすべての点の構造を制御しています。 gcd(x, y) のみを考慮する単純な試みでは、最適な共素点が (x, y) 自体から遠く離れている可能性があるため、直ちに不十分になります。 

一般的な失敗モードは、x と y に大きな共通因数を共有させると大きな答えが得られると仮定することです。 単一の増分によって構造が完全に破壊され、ほぼ即座に互いに素のペアが生成される可能性があるため、これは誤りです。 

もう 1 つの微妙な問題は、x と y を高度に合成するように強制したとしても、近くの摂動によって意図したよりも少ないステップで誤って互いに素のペアが作成される可能性があるため、gcd のローカル制御では十分ではないことです。 半径 k の近傍内のすべての点を明示的に制御する必要があります。 

したがって、主な困難は、L1 距離の (x, y) の周囲に「禁止領域」を構築することです。この領域では、すべての点の gcd が 1 より大きいことが保証されますが、正確に距離 k に少なくとも 1 つの互いに素な点が存在することが保証されます。 

## アプローチ

 強引なアイデアは、候補ペア (x, y) を選択し、BFS で拡張するか、L1 半径を増加させながらすべてのオフセット (dx, dy) をチェックすることによって、互いに素なペアまでの最小距離を計算することです。 k が小さいため、これは概念的に機能します。そのため、半径が正確に k になるまで x と y をランダムに操作しようとする可能性があります。 ただし、これは基本的に不安定です。gcd 構造は非常に不規則であり、ランダムまたはヒューリスティックな構築によって正確な半径が分離されるという保証はありません。 さらに、候補を検証するには、グリッド内で成長するダイヤモンドを探索する必要があり、x と y が大きいか構造化されている場合、テストの繰り返しは予測できなくなります。 

実際の所見は、モジュラー制約を使用することで、有界近傍内のすべての点の gcd 動作を完全に規定できるということです。 gcd について直接推論する代わりに、gcd(x+dx, y+dy) が「悪い」オフセットごとに選択された素数で割り切れるように強制します。 すべての近くの点が少なくとも 1 つの共通の素因数を共有する場合、それらの点はどれも互いに素ではないため、事実上禁止領域を切り開いたことになります。 

k は最大 20 なので、格子点の数は |dx| になります。 + |dy| < k はわずか約 400 です。これは、そのようなオフセットのそれぞれに個別の素数を割り当て、割り算を保証する合同系を適用できるほど十分に小さいです。 

この構築は、モジュラー演算に対する制約充足問題になります。 不正なオフセットはそれぞれ、素数 p と 2 つの条件、x ≡ -dx (mod p) および y ≡ -dy (mod p) に影響します。 これにより、(x+dx) と (y+dy) はどちらも p で割り切れるため、それらの gcd は少なくとも p であることが保証されます。

中国の剰余定理によってすべての制約が結合されると、すべての局所的な「不良」条件を同時に満たす単一のペア (x, y) が得られます。 

残りの唯一の要件は、正確に k の距離に (x, y) と互いに素な点が少なくとも 1 つ存在することを確認することです。 特定のターゲット点 (x+k, y) を選択し、構築に使用される素数が両方の座標を同時に除算しないようにします。 これは、構成内に現れる小さなオフセットを誤って分割できないように、2k より大きい素数を選択することで処理されます。

 ## アルゴリズムのチュートリアル

 1. |dx| となるようなすべての整数ペア (dx, dy) を列挙します。 + |dy| < k かつ (dx, dy) は (0, 0) ではありません。 これらは、厳密に原点から k ステップよりも近いすべてのグリッド ポイントを表します。 このような各オフセットは強制的に「不良」になります。これは、互いに素のペアを生成できないことを意味します。 
2. それぞれのオフセットに個別の素数 p を割り当てます。 選択されたすべての素数は 2k より大きいとみなされ、後で発生する小さな算術値に干渉することはありません。 
3. 割り当てられた素数 p を持つ各オフセット (dx, dy) に対して、2 つの合同式を課します。 

x ≡ -dx (mod p) および y ≡ -dy (mod p)。 

これにより、シフトされた点 (x+dx, y+dy) で両方の座標が p で割り切れるため、gcd が少なくとも p になることが保証されます。 
4. 中国の剰余定理を使用してすべての合同式を結合します。 すべてのモジュライは別個の素数であるため、それらはペアごとに互いに素であるため、その積を法とする一意の解が存在します。 これにより、具体的な整数 x と y が生成されます。 
5. 距離 k にある「安全な」目標点、たとえば (x+k, y) を選択します。 この点については、いかなる制約も課しません。 
6. 構築に使用されるすべての素数について、x+k と y の両方を同時に除算できないことを確認します。 これが成り立つのは、y が dy = 0 のオフセットに対応する素数でのみ割り切れ、それらの素数に対して x+k が素数自体よりも小さい非ゼロの整数に評価されるため、割り切れないからです。 
7. 距離 < k 内のすべての点は互いに素ではないが、距離 k には互いに素のペアが存在するため、最小コストは正確に k であると結論付けます。 

### なぜ効果があるのか

 この構築により、gcd 上の幾何学的条件が、格子点の有限セットにわたるカバー システムに変換されます。 禁断のダイヤモンド内のすべての点には、シフト後の両方の座標を分割する少なくとも 1 つの素数が割り当てられます。 これにより、硬いバリアが作成されます。半径 k 内の点は互いに素になる可能性はありません。 

同時に、k シフトによって引き起こされる最大可能な剰余範囲よりも大きな素数を選択することにより、強制された可分性が誤って距離 k の境界まで拡張されないことを保証します。 重要な不変条件は、すべての「悪い」点が少なくとも 1 つの素数制約によってカバーされる一方、「良い」点はすべての素数で同時に割り切れることを避けることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# simple prime generator (enough for k <= 20, need < 400 primes)
def sieve(n):
    is_p = [True] * (n + 1)
    is_p[0] = is_p[1] = False
    for i in range(2, n + 1):
        if is_p[i]:
            for j in range(i * i, n + 1, i):
                is_p[j] = False
    return [i for i in range(2, n + 1) if is_p[i]]

def crt(residues, mods):
    x = 0
    mod = 1
    for r, m in zip(residues, mods):
        # merge x ≡ r (mod m)
        # solve: x = r mod m
        # since mod and m are coprime, adjust incrementally
        # brute modular inverse via pow
        t = (r - x) % m
        inv = pow(mod, -1, m)
        k = (t * inv) % m
        x = x + mod * k
        mod *= m
    return x, mod

def solve():
    k = int(input().strip())

    primes = sieve(5000)
    mods = []
    rx = []
    ry = []

    idx = 0

    for dx in range(-k + 1, k):
        for dy in range(-k + 1, k):
            if abs(dx) + abs(dy) >= k:
                continue
            if dx == 0 and dy == 0:
                continue

            p = primes[idx]
            idx += 1

            mods.append(p)
            rx.append((-dx) % p)
            ry.append((-dy) % p)

    x, mod = crt(rx, mods)
    y, _ = crt(ry, mods)

    print(x)
    print(y)

if __name__ == "__main__":
    solve()
```コードは最初に、半径 k の L1 ボールの内側にあるすべての格子オフセットを厳密に列挙します。 このような各オフセットは、別個の素数とペアになります。 制約は座標ごとに分離できるため、CRT ルーチンは x と y に対して独立して 2 回適用されます。 各ステップでは、1 つの合同式が累積された解に徐々にマージされます。 

重要な設計上の選択は、gcd を直接制御しようとしないことです。 代わりに、シフトされた座標の割り算のみを制御します。これは、モジュラー演算を使用して強制するのがはるかに簡単です。 

## 実用的な例

 k が小さく、構築が決定論的であるため、完全な数値トレースは、特定のサンプル出力よりもわかりやすくなります。 

k = 2 とします。 |dx| による有効なオフセット + |ディ| < 2 は (±1,0)、(0,±1) です。 これら 4 つの点のそれぞれに個別の素数 (2、3、5、7 など) が与えられ、x ≡ -1 mod 2、y ≡ 0 mod 2 などの合同式が適用されます。 

| オフセット (dx, dy) | プライムp | x mod p | y mod p |
 | --- | --- | --- | --- |
 | (1, 0) | 2 | 1 | 0 |
 | (-1, 0) | 3 | 1 | 0 |
 | (0, 1) | 5 | 0 | 4 |
 | (0, -1) | 7 | 0 | 1 |

 CRT の後、すべての制約を満たす具体的な x と y が得られます。 (x, y) から距離 1 にある点は、これらの素数の少なくとも 1 つを gcd を持つように強制されるため、互いに素になるものはありません。 ただし、距離 2 では、(2, 0) のような方向は制約がなく、素数のサイズ分離により同時割り算が回避されます。 

このトレースは、近傍の各格子点に素の障害物を割り当てることによって、共素性への潜在的な短経路をこの構築がどのように体系的に排除するかを示しています。 

k = 3 の 2 番目の概念的なトレースは、同じパターンをより大きなダイヤモンドに拡張します。 制約の数は増加しますが、それぞれは独立したままであり、CRT 機構は一貫したグローバル ソリューションを生成し続けます。 この構造は、純粋にモジュール条件の数を増やすことによって拡張されます。

 ## 特殊なケース

 k = 0 では微妙なエッジ ケースが発生します。この状況では、必要な構成は、すでに互いに素である任意のペア (x, y) です。 制約されたオフセットがないため、アルゴリズムは自然に縮退します。そのため、CRT は空のシステムに適用され、自明な解を返します。 (1, 1) のようなペアは、互いに素なペアまでの距離がゼロであるという要件を満たします。 

もう 1 つのエッジ ケースは k = 1 です。ここでは、4 つの基本方向ですべてのすぐ隣を制約します。 これらはそれぞれ非共素である必要があり、この構造では (1,0)、(-1,0)、(0,1)、および (0,-1) に素数を割り当てることによって保証されます。 CRT の後は、隣接するすべての点がシフトされた座標と素因数を共有するため、互いに素になる点はありません。 最初に考えられる共素点は、単一の素数制約によって同時にカバーされない対角方向の距離 1 に現れ、モジュラー分離によりそこで gcd が 1 になることが保証されます。 

これらのケースは、特別なケースを使用せずに、構造が自明な動作から完全に制約された動作にスムーズに移行することを確認します。
