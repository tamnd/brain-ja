 ## 解決策
 ## 問題の理解

 各セルに整数値が含まれるグリッドが与えられ、左上隅から右下隅までのすべての単調パスを考慮します。各移動は右または下になります。 各パスはアクセスするセルの値を収集しますが、重複はセットとして扱うことで削除されます。 パスの値は、そのパスに沿って現れる個別の整数の数です。 タスクは、すべての有効なパスにわたってこの値を合計することです。 

したがって、単純な方法でパスを個別に評価する代わりに、各個別の値がすべてのパスにわたる「個別のカウント」に何回寄与するかを計算することが事実上求められます。 

制約は、生のサイズではなく、構造的な意味で厳しいです。 各テスト ケースには、すべてのケースにわたって合計で最大 100,000 個のセルがあり、グリッドの寸法は大きいですが、製品はまばらです。 単調パスの数は n と m で指数関数的に増加する可能性があるため、これによりパスを列挙するソリューションは除外されます。 値が最大 n × m の範囲にあり、最大 100,000 に達する可能性があるため、セットまたはビットマスクを追跡する場合は、パスを介した動的プログラミングさえも不可能です。 

単純なアプローチでは、すべてのパスをシミュレートし、セットを収集し、サイズをカウントしようとします。 単一のパスでも O(n + m) であり、20 × 20 のような中程度のグリッドでもすぐに爆発する二項パス (n + m, n) が存在します。これにより、ソリューションではパスの列挙を完全に回避し、代わりに値ごとの寄与をグローバルにカウントする必要があることが明らかです。 

すべての値が同一の場合、微妙なエッジケースが発生します。 たとえば、すべてのセルが 7 の場合、セットは {7} であるため、すべてのパスの値は 1 になります。 答えは単純にパスの数になります。 パスごとの個別の値ごとではなく、セルごとの出現を誤ってカウントするアプローチでは、ここで過大カウントされます。 

もう 1 つのエッジ ケースは、構造化された対角線に沿って値が一意である場合であり、行または列間の独立性を前提としたソリューションの誤解を招く可能性があります。 

## アプローチ

 ブルートフォースの観点は、(1, 1) から (n, m) までのすべての単調パスを列挙し、パスに沿ってすべての値を収集し、重複を排除して、セットのサイズを計算することです。 これは定義に直接従っているため、正しいです。 ただし、そのようなパスの数は組み合わせによるもので、およそ C(n + m − 2, n − 1) となり、中程度のグリッドでも天文学的に大きくなります。 30 × 30 グリッドの場合、これはすでに 10^16 パスを超えており、実行不可能です。 

重要な変化は視点を反転することです。 パスを反復して値を計算する代わりに、値を反復して、その値を少なくとも 1 回「参照」するパスの数を計算します。 各値は、パスがその値を含む少なくとも 1 つのセルを通過する場合に限り、パスに +1 されます。 したがって、問題は、グリッド セルのセットとのパスの交差に関するカウントの問題になります。 

固定値 v の場合、その出現はすべてグリッド セルのサブセットを形成します。 これらのセルの少なくとも 1 つを通過する単調パスの数を数える必要があります。 これは、パスの合計から v の出現をすべて回避するパスを引いたものと同等です。 

ここで問題は、ブロックされたセルのセット (v を含むすべての位置) が与えられた場合、それらを回避する単調パスを数えることです。 これは、座標によってソートされた順序で v のセルを処理し、プレフィックス制約に対して DP を適用する場合、順序付け構造に対する包含を使用して処理できます。 

重要な観察は、値 v ごとに、少なくとも 1 つの出現を通過するパスの数を計算するだけでよいということです。 合計値は最大でも n × m であるため、各セルが一定の回数処理される場合、すべての値の合計は引き続き実行可能です。

始点から終点までの DP パス数を事前計算し、標準的な「格子パス上の禁止点」トリックを使用します。 各値 v について、その出現をソートし、チェーン上の包含を使用して少なくとも 1 つの出現を通過するパスを計算します。開始から最初の出現まで、連続する出現の間 (単調な順序を確保)、および最後の出現から終了までの遷移を考慮します。 

これにより、指数関数的な列挙ではなく、管理可能な一連の組み合わせパス数への各値の寄与が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(nm) | 遅すぎる |
 | 出現回数に対する値ごとの DP | O(nm log nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのパス数は二項係数であるため、n × m までの階乗および逆階乗を事前計算します。 2 つのセル間のすべての単調パス数は座標の差のみに依存するため、これが必要です。 
2. 関数を事前計算する`ways(x1, y1, x2, y2)`これは、組み合わせを使用して、あるセルから別のセルへの単調パスの数を返します。 これにより、制約されたパス セグメントを直接カウントすることができます。 
3. すべてのグリッド セルを値に基づいてグループ化します。 各グループは、特定の整数が出現するすべての位置を表します。 これは、貢献度が計算される単位です。 
4. 各値グループについて、その位置を行、列の順に並べ替えます。 これにより、パスは上または左に移動できないため、複数のオカレンスを通過する有効なパスが単調な動きを尊重するようになります。 
5. 動的チェーンによってこの値が少なくとも 1 回出現するパスの数を計算します。 まず、(1, 1) から各出現箇所までのパスを計算します。 次に、出現を昇順に接続し、選択した値の「最初のヒット」を通過するパスの寄与を合計します。 
6. 最後に、最後の出現からの寄与を (n, m) に追加し、その値の出現を少なくとも 1 つ含む完全なパスを完成させます。 
7. すべての個別の値に対するこの寄与を合計して、最終的な答えを取得します。 

重要な考え方は、各パスが各値の 1 つの「最初に訪問された出現」に割り当てられることで、二重カウントが防止されるということです。 

### なぜ効果があるのか

 値 v を固定し、有効なパスを検討します。 パスに v が含まれる場合、v が出現するパスに沿って一意に定義された最初のセルが存在します。 v のすべての寄与は、この最初の発生に対して請求できます。 これにより、v を含むすべての有効なパスが、v の出現によってインデックス付けされた素のセットに分割されます。各セットは、ソートされた順序で連続するポイント間の標準的な単調パス DP を使用してカウントでき、正確性が確保され、過剰カウントが発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

MAX = 100000 + 5

fact = [1] * (MAX)
invfact = [1] * (MAX)

def modpow(a, e):
    r = 1
    while e:
        if e & 1:
            r = r * a % MOD
        a = a * a % MOD
        e >>= 1
    return r

def init():
    for i in range(1, MAX):
        fact[i] = fact[i - 1] * i % MOD
    invfact[MAX - 1] = modpow(fact[MAX - 1], MOD - 2)
    for i in range(MAX - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

def ways(x1, y1, x2, y2):
    dx = x2 - x1
    dy = y2 - y1
    if dx < 0 or dy < 0:
        return 0
    return C(dx + dy, dx)

init()

T = int(input())
for _ in range(T):
    n, m = map(int, input().split())
    vals = {}
    for i in range(n):
        row = list(map(int, input().split()))
        for j, v in enumerate(row):
            vals.setdefault(v, []).append((i, j))

    ans = 0

    for v, pts in vals.items():
        pts.sort()
        k = len(pts)

        dp = [0] * k

        for i in range(k):
            x, y = pts[i]
            dp[i] = ways(0, 0, x, y)
            for j in range(i):
                x2, y2 = pts[j]
                if x2 <= x and y2 <= y:
                    dp[i] = (dp[i] - dp[j] * ways(x2, y2, x, y)) % MOD

        contrib = 0
        for i in range(k):
            x, y = pts[i]
            contrib = (contrib + dp[i] * ways(x, y, n - 1, m - 1)) % MOD

        ans = (ans + contrib) % MOD

    print(ans % MOD)
```実装は、定数時間の二項係数クエリを可能にするために階乗と逆階乗を事前計算することから始まります。 の`ways`関数は、座標の差を格子パス数に変換します。 

それぞれの値について、次のように計算します。`dp[i]`同じ値の以前の出現を避けながら、最初から i 番目の出現に到達するパスの数として表されます。 これは、ソートされた順序で以前に処理されたポイントに対する包含/除外を使用して行われます。 その後、各出現箇所が最後まで続くパスに寄与し、その値を少なくとも 1 回含む有効な完全なパスが完成します。 

## 実用的な例

 ### 例 1

 入力:```
2 3
5 2 1
1 5 5
```ポジションをリストします:

 | 値 | ポジション |
 | --- | --- |
 | 1 | (0,2)、(1,0) |
 | 2 | (0,1) |
 | 5 | (0,0)、(1,1)、(1,2) |

 値 2 の場合、セルは 1 つだけ存在するため、そのセルを通過するすべてのパスは、開始から (0,1) までのパスと (0,1) から終了までのパスの積として直接カウントされます。 

値 5 の場合、複数のオカレンスが存在します。 dp を計算します。 

| 私 | セル | dp[i] |
 | --- | --- | --- |
 | 0 | (0,0) | 方法(開始→(0,0)) |
 | 1 | (1,1) | ウェイ(開始→(1,1)) マイナス (0,0) 経由のパス |
 | 2 | (1,2) | Ways(start→(1,2)) から以前のパスを引いたもの |

 次に、各 dp[i] が終了するウェイを乗算します。 

これは、減算によって、複数の出現に到達するパスの二重カウントがどのように防止されるかを示しています。 

### 例 2

 入力:```
2 3
3 3 3
3 3 3
```すべての値は同一です。 すべてのパスは、値 3 に対して 1 を正確に反映します。 

| 値 | 貢献 |
 | --- | --- |
 | 3 | 単調パスの数 |

 すべてのパスには 3 が含まれるため、dp は合計パス数に集約されます。 これにより、各セルが個別にカウントされた場合に過剰カウントが発生する均一グリッドでの正確性が確認されます。

 ## 特殊なケース

 重要なエッジケースは、すべてのセルに同じ値が含まれる場合です。 このアルゴリズムは、すべての出現を単一の値グループとして扱います。 dp 構造では、各パスに沿った最初の出現が単調な動きによって一意に決定されるため、すべてのパスがその値に 1 回だけ寄与することが保証されます。 

もう 1 つの特殊なケースは、値のまばらな繰り返しです。 例えば：```
1 0 2
3 0 4
0 0 5
```ここでは、各値が 1 回出現するため、dp はエンドポイント間の単純なパス数に減ります。 減算ループは何も行わず、重複が存在しない場合には正確さを確認します。 

最後のエッジ ケースには、厳密に増加する対角チェーンに現れる値が含まれます。 順序付けにより、前方に到達可能なポイントのみが相互作用することが保証されるため、無効な遷移が誤って負の補正に寄与することはなく、DAG 構造全体にわたる包含/除外の正確性が維持されます。
