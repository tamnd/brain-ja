 ## 解決策
 ## 問題の理解

 記入するよう求められます$n \times n$以下のすべての整数を含むグリッド$1$に$n^2$、それぞれが 1 回だけ使用されます。 したがって、グリッドは行列に再形成された単なる順列です。 

次に、しきい値のプロパティを定義します。$x$。 行は良いと呼ばれます$x$その行のすべての数値が最大でも$x$。 コラムが良いのは$x$その列のすべての数値が最大でも$x$。 値$x$少なくとも 1 つの行または少なくとも 1 つの列が適切な場合、それは特別と呼ばれます。$x$。 

として$x$増加すると、より多くの値が許可されるため、より多くの行と列が適切になります。 キーの数量は最小です$x$ある行または列が完全に含まれているもの$[1, x]$。 

同様に、各行を見ると、その「アクティブ化ポイント」がその最大値になります。これは、それが最小値であるためです。$x$それは良いことです。 各列についても同様です。 したがって、特別な値のセットは、正確にすべての行の最大値と列の最大値のセットです。 私たちが求める答えは、すべての行の最大値と列の最大値の中の最小値です。 

したがって、タスクは次のようになります。行の最大値または列の最大値の最小値が正確に一致するような置換行列を構築します。$k$。 

制約は小さいです。$n \le 50$、だからどれでも$O(n^2)$テスト ケースごとの構築は簡単に十分に高速です。 本当の難しさは純粋に構造的なものです。 

実現可能性に関する重要な観察が 2 つあります。 

まず、もし$n > 1$そして$k = 1$、答えは不可能です。 行または列が適している$1$すべてのエントリが正確であることを意味します$1$、これは順列では不可能です。$n=1$。 

第二に、もし$n > 1$そして$k = n^2$、それも無理です。 を含むユニークなセル$n^2$は正確に 1 行 1 列に配置され、これら 2 行の最大値が$n^2$。 1 つおきの行と列には値のみが含まれます$\le n^2-1$、つまり、すでに良いことになっています。$n^2-1$、特殊な最小値を最大でも強制的に設定します。$n^2-1$。 

唯一興味深い政権は$2 \le k \le n^2 - 1$ここで、グリッドを明示的に構築する必要があります。 

主な隠れた制約は次のとおりです。行または列が早期に良好になることを回避するには、次の値より大きい値を少なくとも 1 つ含める必要があります。$k$。 それ以外の場合、その最大値は次のようになります。$\le k$、潜在的に答えが意図したよりも小さくなる可能性があります。 したがって、値がより大きい場所を慎重に制御する必要があります。$k$行く。 

単純な考えでは、すべての数値を「パック」しようとするでしょう$\le k$単一の行または列に分割します。 これはすぐに失敗します$k > n$、行には$n$スロット。 したがって、小さな値がすべて 1 行に集中しないように構成する必要があります。 

## アプローチ

 ブルートフォース構築の試みでは、グリッドのすべての順列を試行し、すべての行と列の最大値をチェックして結果の答えを計算します。 これは階乗です$n^2$、たとえ$n = 4$、構造的な洞察は得られません。 

重要な観察は、答えは内部配置ではなく、行の最大値と列の最大値のみに依存するということです。 したがって、値をどこに置くかを制御するだけで済みます。$k$次の 2 つのプロパティを確保します。 

まず、最大値が正確に一致する行または列が少なくとも 1 つ存在する必要があります。$k$。 これにより、答えは最大でも$k$。 

次に、すべての値を含む行や列があってはなりません。$\le k-1$。 それ以外の場合、答えは以下より小さくなります$k$。 

これは値を「強制」するきれいな方法を示唆しています$k$初めて完全な行または列が安全になるようにするには、次のようにします。$k$すべての行と列にすでに何らかの値が含まれるように、値を慎重に分散します。$>k$ただし、しきい値を定義するために使用する特定の構造は除きます。 

これを達成する確実な方法は、値を分離することです。$k$他のすべての値が単一行であることを確認します。$\le k$すべての値は同じ行に留まります$> k$その外側に置かれています。 これにより、その行が最初の完全に「小さい」行となり、それより前の行や列が完全に小さくなることはありません。 

唯一の制約は、その行に必要なセルの数が正確に一致することです。$n$、セットを正確に使用する必要はないので、これは常に問題ありません。$[1, k]$その行には値のみ$\le k$。 残りの値がグリッドの残りの部分を埋め、自動的に 1 行おきの行と列に値が含まれるようになります。$>k$。 

これは直接的な建設的なパターンにつながります。

 ## アルゴリズムのチュートリアル

 グリッドを行ごとに構築します。 

1. 行を選択します$r$それが答えを定義します。 行が正確に最大値を持っていることを確認します$k$。 これにより、答えは最大でも次のようになります。$k$。 
2.値を配置します$k$列の内側のどこか$r$、位置上の便宜のため$(r, 0)$。 これにより列が確保されます$r$少なくとも最大値がある$k$。 
3. 残りの行を埋めます$r$からの値を使用して$[1, k-1]$勝手に。 これにより、その行が保証されます$r$値のみが含まれます$\le k$、したがって、その最大値は正確に$k$。 
4. すべての値を次から配置します。$k+1$に$n^2$グリッドの残りのセルに任意の順序で入力します。 これにより、1 行おきの行に少なくとも 1 つの値が含まれるようになります。$>k$したがって、他の行は最大値を持つ候補にはなりません。$\le k$。 
5. どの列も満杯になっていないことを暗黙的に検証します。$\le k-1$。 すべての列が行と交差するか、$r$または少なくとも 1 つの値が含まれています$>k$したがって、すべての列には少なくとも最大値があります$k$。 

### なぜ効果があるのか

 構造はその行を保証します$r$最大値が以下で制御される唯一の構造です$k$。 他のすべての行には、次より大きい値が少なくとも 1 つ含まれます。$k$、したがって、それらの最大値は次を超えます$k$。 したがって、すべての行と列の最大値の最小値は、まさに行の最大値になります。$r$、つまり$k$。 行や列が完全に含まれていないため、$[1, k-1]$、これより小さいしきい値は行全体または列全体をアクティブにすることができないため、答えはそれを下回ることはできません。$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, k = map(int, input().split())

        if n > 1 and (k == 1 or k == n * n):
            print("No")
            continue

        grid = [[0] * n for _ in range(n)]

        used = [False] * (n * n + 1)

        r = 0

        cur = 1

        # Fill row r with 1..k
        for c in range(n):
            if cur <= k:
                grid[r][c] = cur
                used[cur] = True
                cur += 1
            else:
                break

        # ensure k is in row r
        if grid[r][0] != k:
            # swap k into position (0,0)
            for i in range(n):
                for j in range(n):
                    if grid[i][j] == k:
                        grid[i][j], grid[0][0] = grid[0][0], grid[i][j]
                        break

        # fill remaining cells
        val = 1
        for i in range(n):
            for j in range(n):
                if grid[i][j] == 0:
                    while val <= n * n and used[val]:
                        val += 1
                    grid[i][j] = val
                    used[val] = True

        print("Yes")
        for row in grid:
            print(*row)

if __name__ == "__main__":
    solve()
```この実装では概念的に、グリッドを制御された行と自由な残りの部分に分離します。 制御された行は、次の値までのすべての値をホストすることを目的としています。$k$、 と$k$存在することが保証されているため、その最大値は正確に一致します$k$。 グリッドの残りの部分は未使用の数値で貪欲に埋められ、順列特性が保証されます。 

重要な点は、`used`配列を使用し、フィル順序によって、割り当てられる前に制御された構造の外側に小さな数値が誤って配置されることがないようにします。 次の未使用の値を貪欲にスキャンすることで、後戻りすることなく正確性が保証されます。 

## 実用的な例

 小さなケースを考えてみましょう$n = 3, k = 5$。 最大値が次の行を強制することを目指しています。$5$。 

まずは配置から始めます$1,2,3,4,5$行 0 を優先してグリッドに追加します。 

| ステップ | アクション | グリッド状態 |
 | --- | --- | --- |
 | 1 | 1、2、3 を行 0 に配置します。 [1 2 3 / . 。 。 / 。 。 ] |

 完了後、行 0 には値のみが含まれます$\le 5$、および含まれます$5$したがって、その最大値は$5$。 他のすべての行には少なくとも 1 つの値が含まれます$>5$、したがって、それらの最大値は次を超えます$5$。 

これにより、構築されたグリッドが以下に等しい最小の特別な値を持っていることが確認されます。$5$。 

ここで考えてみましょう$n = 4, k = 7$。 同じメカニズムが適用されます。行 0 は、次の値までのすべての値が含まれるように配置されます。$7$それらがそれに適合し、残りの値がグリッドの残りの部分を埋めます。 価値観以来$>7$他の行に強制的に配置され、他の行は完全に小さくなることはできませんが、行 0 がしきい値で最初にアクティブ化された構造になります。$7$。

 ## 特殊なケース

 最もデリケートなケースは、$n=1$、グリッドには単一のセルがあります。 その状況で可能な唯一の値は次のとおりです。$1$、唯一可能な特別な値も次のとおりです。$1$。 単一の行は行と列の両方であることが自明であるため、その最大値は以下に等しいため、構造は正しく縮退します。$k$そのときだけ$k=1$。 

2 番目のエッジケースは、$k=1$と$n>1$。 複数の個別の値を含む行または列には最大値を設定できません$1$したがって、有効な構造は存在しません。 アルゴリズムはこれを即座に正しく拒否します。 

3 番目のエッジケースは、$k=n^2$と$n>1$。 1つのセルのみに含まれるため、$n^2$、他のすべての行と列はそれを回避し、最大値を最大値にします$n^2-1$、そのため、最小の特別な値に達することはできません$n^2$。 この構造もこのケースを正しく拒否します。
