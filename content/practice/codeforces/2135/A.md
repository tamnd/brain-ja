 ## 解決策
 ## 問題の理解

 整数の配列が与えられているので、「ブロック」に分割できる最長のサブシーケンスの長さを見つけたいと考えています。 ブロックは、すべての要素がそのシーケンスの長さに等しい連続したシーケンスとして定義されます。 例えば、`[3, 3, 3]`は長さが 3 で、すべての要素が 3 であるためブロックです。`[2, 2, 1]`はブロックではありません。 1 つ以上のブロック (場合によっては 0) の連結として表現できる場合、配列は適切です。 私たちの仕事は、適切なサブシーケンスの最大長を見つけることです。 

入力は複数のテスト ケースを提供します。 各テストケースは長さを示します`n`配列と配列要素自体の。 各要素が満たす`1 <= a_i <= n`。 すべての合計`n`テスト ケース全体の数は最大 200,000 であるため、テスト ケースごとにほぼ直線的な時間で実行されるアルゴリズムを目指す必要があります。 すべてのサブシーケンスを試すなどの 2 次アルゴリズムでは、次のオーダーが必要になります。`O(2^n)`まったく実行不可能な操作です。 平`O(n^2)`アプローチは遅すぎるだろう`n`20万近く。 

微妙なエッジ ケースには、ブロックを形成するのに十分な回数出現する要素がない配列、または小さなブロックしか存在できない配列が含まれます。 たとえば、`a = [5, 1, 2]`、数値のカウントが必要なブロック長と一致しないため、ブロックを形成できません。そのため、最も長い整った部分列は空になります。 もう 1 つのケースは、複数の同一の数字が出現するが、ブロックを形成するには数が不十分である場合です。`[2, 2, 2]`1ブロックを許可します`[2, 2]`しかし3番目の`2`新しいブロックを形成できないため、慎重に数える必要があります。 

## アプローチ

 ブルートフォース手法では、すべてのサブシーケンスを列挙し、それぞれをブロックに分割できるかどうかを確認し、最大長を記録します。 これは原理的には正しいですが、扱いが困難です。サブシーケンスには次のような問題があります。`2^n`天文学的に大きな可能性がある`n = 2 * 10^5`。 たとえ`O(n^2)`サブ配列または位置に対して動的プログラミングを試みるアプローチは、次のオーダーが必要になるため遅すぎます。`4*10^10`最悪の場合の運用。 

重要な洞察は、要素の順序はサブシーケンスの選択以外には重要ではないことに気づくことです。 重要なのは、それぞれの数字の頻度です。 数字の場合`x`、サイズの整ったブロックに寄与できる要素の最大数`x`の最大倍数です`x`そのカウント以下です。 たとえば、次の場合`4`表示されます`9`2 回、サイズ 4 のブロックを 2 つ形成できます (`4*2 = 8`要素)、残り 1 つを残す`4`それはブロックを形成できません。 各数値の最大寄与を計算したら、これらを合計すると、最も長い整った部分列の長さが得られます。 

したがって、最適なアプローチは、頻度カウントに基づく貪欲な選択です。各数値の出現をカウントし、そのカウント以下の各数値の最大倍数を計算し、これらの寄与を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 頻度配列または辞書を初期化して、各整数の出現回数をカウントします。`a`。 
4. 変数を初期化する`max_neat_length`ゼロに。 
5. それぞれの個別の数値を反復処理します。`x`周波数配列内で。 
6. 数字ごとに`x`、計算する`k = (count[x] // x) * x`。 これにより、要素の最大数が得られます。`x`完全なブロックを形成することができます。 
7.追加`k`に`max_neat_length`。 
8. すべての数値を処理した後、出力します`max_neat_length`現在のテストケースの場合。 

機能する理由: ブロックの長さが一定であるため、貪欲な選択は有効です。`x`正確に使用する必要があります`x`要素と、その倍数を超える追加要素`x`きちんとしたサブシーケンスに貢献することはできません。 周波数をカウントすることで、考えられるすべての要素を確実に考慮します。 最大の寄与を合計すると、最長のサブシーケンスが確実に捕捉されます。 部分列は任意に並べ替えることができるため、順序によって解決策が制約されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def longest_neat_subsequence(n, a):
    from collections import Counter
    freq = Counter(a)
    length = 0
    for x, count in freq.items():
        length += (count // x) * x
    return length

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(longest_neat_subsequence(n, a))
```ソリューションでは、`Counter`の発生を効率的にカウントするには`O(n)`時間。 ループオーバー`freq.items()`それぞれの異なる数値が 1 回だけ考慮されるようにします。 割り算と掛け算`(count // x) * x`各数値から使用可能な要素の最大数を決定します。 高速 I/O を使用すると、厳しい入力制約下でもソリューションが効率的に実行されます。
