 ## 問題の理解

 未知の整数パラメータを決定しようとしています$W$、テキストエディタの行の幅。 私たちが送信する各記事は、単語の長さを表す一連の正の整数です。 エディターは記事を行にフォーマットし、単語の追加が制限を超えるまで単語を 1 行に順番に配置します。$W$、その後、新しい行に折り返されます。 いずれかの単語が超過した場合$W$、記事がまったく表示されません。 エディターは、使用された行数、または記事を表示できない場合はゼロを通知します。 を決定するために、テスト ケースごとに最大 2 つのクエリが許可されます。$W$。 

制約により、最大で次のことが許可されます。$10^5$クエリごとの単語数と$W \le 10^5$したがって、アルゴリズムはクエリごとに線形時間で動作する必要があります。 重要なエッジケースには、非常に小規模または非常に大規模なものが含まれます$W$私たちが提出する言葉に関連して。 たとえば、未知の単語に等しい 1 つの単語を送信すると、$W$より長い単語を送信する場合は常に成功します。$W$すぐに失敗します。 単純に語長の多くの組み合わせをクエリすると、クエリの制限を超えてしまいます。 

不注意な実装では、たとえば、語長を合計し、行数で割って推測する可能性があります。$W$。 改行が行で割られた合計と完全に一致していない場合、これは失敗します。 具体的な例:$W=20$そして私たちは提出します`[1,9,4,6,1]`、エディターは 2 行を生成しますが、単純に 21 (全長) を 2 で割ると 10.5 になります。$W$。 正しい推論では、改行の発生方法を考慮する必要があります。 

## アプローチ

 総当りのアプローチでは、切り分けられるまで、返される行数に基づいて調整しながら、語長を増やして記事を投稿することになります。$W$。 This is correct in principle, because observing how many lines a sequence occupies constrains$W$。 ただし、許可されている 2 つのクエリを超える多くのクエリが必要になる場合があります。 また、初期の失敗を避けるために、慎重に単語シーケンスを選択する必要もあります。 

重要な観察は、クエリを構造化して正確に特定できることです。$W$まさに2ステップで。 最初のクエリは 1 行で飽和し、複数行の応答を生成するように設計できます。$W$全長よりも短いです。 2 番目のクエリでは、全長が候補と同じになるように、すべての単語を 1 行に配置しようとします。$W$。 編集者が成功を報告すれば、それがわかります$W$少なくともその合計である。 それが失敗した場合、$W$少ないです。 慎重に構築された 2 つのクエリを使用して、次のことを判断できます。$W$正確に。 

エディターの行折り返しルールが決定的であるため、最適なアプローチが機能します。 すべての単語が同じサイズであるか、全長が制御されている一連の単語を送信することで、返される行数をエンコードすることができます。$W$。 たとえば、1 行の長さが$W$は失敗を保証しますが、行をほぼ埋めるシーケンスにより計算が可能になります。$W$返答より。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テストケースごとに、次のことを決定する必要があります。$W$独立して。 
2. テストケースごとに、長い全長をカバーする一連の単語を使用してクエリを構築します。たとえば、短い単語の後に非常に長い単語が続き、その和が最大値を超えるようにします。$W$。 これにより、編集者が行を折り返したり記事を拒否したりできるようになり、上限に関する情報が提供されます。$W$。 
3. 最初のクエリを送信し、返された行数を読み取ります。$l_1$。 エディターがゼロを返した場合、クエリ内の最大の単語は次の値を超えます。$W$。 この場合、$W$はその単語の長さより短いため、最大値の候補がすぐにわかります。$W$。 
4. 単語の合計の長さが候補と等しくなるように 2 番目のクエリを構築します。$W$ステップ 3 から。このクエリが 1 行で成功した場合、正確な結果がわかります。$W$。 失敗したら、$W$使用した全長より 1 つ小さい必要があります。 通常、シーケンスを選択すると、`[W_candidate // 2, W_candidate - W_candidate // 2]`記事が適合するか不適合であるかを明確に保証します。 
5. 回答を次の形式で印刷します。`! W`。 

正確さを保証する不変条件は、エディタが常にその改行ルールに従って一貫して応答することです。 ぎりぎり収まる、またはそれを超えるシーケンスを作成することによって$W$、返される行数は、次の線形不等式をエンコードします。$W$。 1 つは上限を特定でき、もう 1 つは正確な値を確認できるため、2 つのクエリで十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        # First query: choose two words, one small, one large
        q1 = [1, 100000]
        print("?", len(q1), *q1)
        sys.stdout.flush()
        l1 = int(input())
        if l1 == -1:
            exit(0)
        
        # If first query failed, W < max(q1)
        if l1 == 0:
            W = q1[1] - 1
            print("! {}".format(W))
            sys.stdout.flush()
            continue
        
        # If first query succeeded, compute W using total length and lines
        # Use second query to determine W precisely
        total_length = sum(q1)
        # We attempt to fit in 1 line
        q2 = [total_length]
        print("?", len(q2), *q2)
        sys.stdout.flush()
        l2 = int(input())
        if l2 == -1:
            exit(0)
        if l2 == 1:
            W = total_length
        else:
            W = total_length - 1
        
        print("! {}".format(W))
        sys.stdout.flush()

if __name__ == "__main__":
    main()
