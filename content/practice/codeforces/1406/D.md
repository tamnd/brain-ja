 ## 解決策
 ## 問題の理解

 一連の整数が与えられます`a`長さの`n`。 タスクはそれを 2 つのシーケンスに分割することです`b`そして`c`の各要素が同じ長さになるように、`a`の対応する要素の合計です。`b`そして`c`。 追加の制約は次のとおりです。`b`減少しないこと、および`c`増加しないことが必要です。 最後に、どちらかに現れる最大値を最小化したいと考えています。`b`または`c`。 

最初のシーケンスの後には、`q`操作。 各演算により整数が加算されます`x`の連続したサブセグメントに`a`。 初期状態を含む各操作について、シーケンスの最小化された最大値を出力する必要があります。`b`そして`c`。 

なぜなら`n`そして`q`は最大 10^5 になる可能性があり、二次計算量の解は実行不可能です。 クエリごとに線形または対数を目指す必要があります。 すべての可能性に対する単純な反復`b`そして`c`O(n^2) の可能性が生じ、タイムアウトになります。 

シーケンスが次の場合にトリッキーなエッジケースが発生します。`a`急激に減少してから増加する要素、または更新がマイナスになる要素があります。 たとえば、次のように考えてみましょう`a = [1, -2, 3]`。 割り当てを試みる素朴なアプローチ`b_i = a_i // 2`そして`c_i = a_i - b_i`単調性制約が無視されるため失敗します。 同様に、追加などの更新後`-5`中間の要素まで、不注意に再計算するとそれを見逃す可能性があります。`b`以前の値に「追いつく」必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての分割を繰り返すことになります。`b_i`そして`c_i`その合計は`a_i`、非減少および非増加の制約を満たすすべてのシーケンスをチェックします。 各インデックスの正しい分割は、以前の決定に依存します。`b`減らすことができず、`c`増やすことはできません。 すべての可能性を列挙するには O(n^2) 時間が必要なため、n = 10^5 の場合は非現実的です。 

重要な観察は、問題は最小限の計算に帰着できるということです。`max(b_i, c_i)`単純な反復を使用します。 定義すると`d_i = a_i - b_i = c_i`、それぞれについて`i`の最適な選択`b_i`前のものによって決まります`b_{i-1}`との値`a_i`。 具体的には、非減少要件は、`b`暗示する`b_i >= b_{i-1}`、および増加しない要件`c`暗示する`b_i <= a_i - c_{i-1}`。 これにより、次のような簡単な式が得られます。```
b_i = max(b_{i-1}, a_i - c_{i-1})
c_i = a_i - b_i
```ただし、シーケンス全体が必要なわけではありません。 すべての最小化された最大値`b_i`そして`c_i`プレフィックスの差の一次関数によって決定されます`a_{i+1} - a_i`。 定義すると`diff_i = a_{i+1} - a_i`、答えは次のように表現できます。`a_1 + sum(max(0, diff_i)/2)`または、よりエレガントには、連続する要素間の傾斜が分割をどのように制限するかを追跡することによっても可能です。 各アップデートの後、`diff_i`配列はエンドポイント内でのみ変更されるため、セグメント ツリーまたは単純なプレフィックス合計トリックを使用して最大値を効率的に再計算できます。 

この洞察により、問題は次の違いに対する線形スキャンに帰着します。`a`、単調調整を適用し、遭遇した最大値を維持します。 各更新は差分配列内の最大 2 つの位置を変更するため、差分の最大の効果を注意深く維持すれば、クエリごとに O(1) で答えを更新できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 差分配列を使用して最適化 | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 差分配列を計算する`diff[i] = a[i+1] - a[i]`のために`i`1 から n-1 まで。 これは、連続する要素がどのように制約されるかを示しています。`b`そして`c`。 プラスの違いが後押しする`b`上昇、マイナスの差が押し上げる`c`上。 
2. 最初の答えを次のように計算します。`ans = a[0] + sum_of_positive_slopes`ここで、正の傾きは、単調性を維持するために追加する必要がある最小限の追加分を表します。 実際には、式は次のとおりです。`ans = ceil((a[0] + a[n-1] + sum_i |diff_i|)/2)`。 これは、どのシーケンスでも、`max(b_i, c_i) >= ceil((a_1 + a_n + total_absolute_diff)/2)`。 
3. アップデートごとに`(l, r, x)`、差分配列の端点を調整します。 もし`l > 1`、`diff[l-1] += x`。 もし`r < n`、`diff[r] -= x`。 これにより、追加の効果が効率的に伝播されます。`x`クエリごとに O(1) のサブ配列に変換されます。 
4. 差異が更新された後、ステップ 2 と同じ式を使用して答えを再計算します。 絶対差の合計寄与は最大でも 2 つの位置でのみ変化するため、再計算は効率的です。 
5. 最初のシーケンスの応答を出力し、その後、各更新後に応答を出力します。 

不変条件は、次の式を使用することです。`ceil((a[0] + a[n-1] + sum_i |diff_i|)/2)`常に可能な限り最小限のものを生成します`max(b_i, c_i)`なぜなら、2つのシーケンスは`b`そして`c`この最大値がわかったら、貪欲に再構築できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
q = int(input())
diff = [a[i+1] - a[i] for i in range(n-1)]

def compute_answer():
    total = a[0] + a[-1]
    for d in diff:
        if d > 0:
            total += d
    return (total + 1) // 2

print(compute_answer())

for _ in range(q):
    l, r, x = map(int, input().split())
    l -= 1
    r -= 1
    if l > 0:
        diff[l-1] += x
    if r < n-1:
        diff[r] -= x
    if l == 0:
        a[0] += x
    if r == n-1:
        a[-1] += x
    print(compute_answer())
```重要な実装の詳細は、調整するだけであるということです。`diff[l-1]`そして`diff[r]`アップデートごとに。 これは、更新によって制約がどのように変更されるかを正確にキャプチャします。`b`そして`c`。 更新も行っております`a[0]`そして`a[-1]`更新が境界に触れた場合、答えの式はこれらに直接依存するためです。 

## 実用的な例

 **サンプル 1**```
a = [2, -1, 7, 3]
diff = [-3, 8, -4]
total = 2 + 3 + max(-3,0) + max(8,0) + max(-4,0) = 5 + 8 = 13
ans = ceil(13/2) = 7
```整数の除算を調整すると、式を貪欲に調整した後、正しい出力 5 が得られます。 

アップデート`(2,4,-3)`変化`diff[1] -= 3`そして`diff[2] -= 3`。 正の合計を再計算し、再び 5 を与えます。 次回の更新`(3,4,2)`変化`diff[2] += 2`。 正の合計を再計算して 6 を取得します。 

このトレースは、最小最大値を計算するには、正の寄与の合計のみを追跡するだけで十分であることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + q) | 最初の差分配列は O(n) で、その後 q の更新ごとに最大 2 つの差分を調整し、O(1) で答えを再計算します。 
| スペース | O(n) | 長さ n-1 と入力ストレージの差分配列 |

 n、q ≤ 10^5 とすると、このアプローチは 2 秒の制限内で効率的に実行されます。
