 ## 問題の理解

 このタスクでは、長さの配列を構築するように求められます。`n`厳密に増加する整数で、すべての境界は次のとおりです。`m`、特定のスコアが最大化されるようにします。 スコアは次の合計です`v(i, a_i)`から`i=2`に`n`、 どこ`v(b, x)`最大の力です`k`そのような`b^k`分割する`x`。 基本的にはポジションごとに`i`2 から始めて、その位置の要素ができるだけ次の値で割り切れるようにする必要があります。`i`。 

複数のテストケースが与えられます。 各テスト ケースが提供するのは、`n`そして`m`。 制約により許可されるのは、`n`そして`m`最大200,000ですが、すべての合計`m`テスト ケース全体の値も 200,000 によって制限されます。 この制限は、テスト ケースごとにおよそ O(m log m) または O(n log n) のソリューションが必要であることを示唆しています。 最悪の場合、O(n*m) は遅すぎます。 

明らかではないエッジケースには、次のようなシナリオが含まれます。`n`等しい`m`、配列には 1 から 1 までのすべての数値が含まれている必要があることを意味します。`m`。 別の厄介なケースが発生するのは、`m`小さい数字ですが、`n`が大きいため、配列はほぼすべての数値を連続して選択する必要があります。 このような場合、単純に貪欲な選択をすると、最適な指数の合計が過小評価される可能性があります。これは、配列の後半で割り切れる最大の数値を取得すると、合計スコアが高くなる可能性があるためです。 

小さな例:`n=3, m=6`。 素朴なアプローチでは、`[1,2,3]`。 の`v`値は`v(2,2)=1`そして`v(3,3)=1`、合計は 2 です。しかし、`[1,2,6]`与える`v(2,2)=1`、`v(3,6)=1`、合計は 2 のままです。これは、より良く割り切るために、最大要素を後の位置に押し込む必要がある場合があることを示しています。 

## アプローチ

 ブルートフォースアプローチでは、厳密に増加するすべての配列が考慮されます。`a`内で`[1, m]`そしてスコアを計算します。 がある`C(m, n)`このような配列、および各配列の合計を計算するには、`n`可分性チェック。 べき乗を事前に計算したとしても、これは組み合わせ論的に爆発し、実現可能な限界をはるかに超えます。 

重要な洞察は次のとおりです`v(b, x)`最大化されるのは`x`は可能な最大のべき乗で割り切れます`b`。 それぞれについて`i`で`[2, n]`の貢献`i`合計が最高です`k`そのような`i^k ≤ a_i`。 配列は厳密に増加する必要があるため、最適な`a_i`上限に近いことが多い`m`、ただし、シーケンスが増加し続けることを確認する必要があります。 したがって、問題は「厳密に増加する制約の下で指数の合計を最大化する」という形式に帰着します。これは、優先キューのアプローチを使用して解決できます。つまり、常に最大の残りを割り当てます。`a_i`最大の数値から下に向かって反復して、スコアを最も高めることができるインデックスに到達します。 事前計算`v(b, x)`みんなのために`b≤n`そして`x≤m`寄与を効率的に計算できるようになります。 

もう 1 つの観点は動的プログラミングです。定義する`dp[pos][val]`最大スコアとして、ポジションを埋めることができます`pos..n`と`a_pos ≥ val`。 この繰り返しを使用して不可能な範囲を枝刈りすることは、合計が小さいため機能します。`m`テストケース全体にわたる制約。

 ## アルゴリズムのチュートリアル

 1. 事前計算`v(b, x)`みんなのために`b`2から`n`そしてすべて`x`1から`m`。 これは、それぞれのべき乗を反復することで実行できます。`b`そして複数をマークします。 事前計算により、あらゆるものの定時間ルックアップが保証されます。`(b, x)`。 
2. 配列を初期化する`a`長さの`n`ゼロ付き。 厳密に増加順序を維持しながら指数を最大化するために、最大の数値から下に埋めていきます。 
3. 各インデックスの潜在的な寄与の優先キューを維持する`i=2..n`。 候補者ごとに`x`、計算する`v(i, x)`そして押します`(v(i,x), i, x)`山の中へ。 最大ヒープを使用して、限界寄与が最大の選択肢を常に選択します。 
4. ヒープから繰り返しポップし、番号を割り当てます。`x`位置を決める`i`配列が厳密に増加し続ける場合。 重複を避けるために使用された番号を追跡します。 
5. 配列を埋めた後、合計します。`v(i, a_i)`のために`i=2..n`最大のスコアを獲得するために。 
6. すべてのテスト ケースに対して繰り返します。 

機能する理由: 各ステップで、合計スコアへのわずかな寄与を最大化する利用可能な番号と位置を常に選択します。 厳密に昇順が適用されるため、以前の選択を無効にする割り当てはありません。 事前計算`v(b, x)`指数の寄与を決して過小評価しないことを保証します。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        v = [0] * (m + 1)
        res = 0
        # We process from largest i to 2 to maximize exponents
        for i in range(2, n + 1):
            power = i
            while power <= m:
                cnt = m // power
                res += cnt
                if power > m // i:
                    break
                power *= i
        print(res)

solve()

このアプローチは、`v(i, a_i)`、正確な配列は必要ありませんが、次で割り切れる数値のカウントだけが必要です。`i^k`。 配列は厳密に増加しているため、それぞれ`i`電力レベルごとに最大 1 つの数値を寄与し、最も高いものから数えます`i`下向きにすると最適な分散が保証されます。
