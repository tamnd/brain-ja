 ## 解決策
 ## 問題の理解

 としてマークされたいくつかのエントリを含む非負の整数の配列が与えられます。`-1`, representing blanks. 私たちのタスクは、各空白を負でない整数に置き換えて、連続する要素間の差の合計の絶対値を最小化することです。 Formally, if we define`b[i] = a[i+1] - a[i]`すべて有効な`i`を最小限に抑えたい`|sum(b)|`空白を埋めた後。 さらに、この最小値を達成するすべての配列の中で、辞書編集的に最小の配列が必要です。 

最初の観察は、差分配列の合計が`b`単純に`a[n] - a[1]`。 これにより問題が単純化されます。各差を個別に最適化しようとするのではなく、絶対和にとって重要な唯一の数値は、すべての空白を埋めた後の配列の最初と最後の要素の差です。 

制約が教えてくれるのは`n`最大 200,000 個、最大 10,000 個のテスト ケースを含めることができます。 これは、テスト ケースごとに O(n) よりも複雑なアプローチは遅すぎることを意味します。 ネストされたループや空白の位置に対する指数関数的な列挙を回避する、線形スキャン戦略が必要です。 

すべての要素が次の場合に、微妙なエッジケースが発生します。`-1`。 ここで、すべてのゼロを選択してゼロ差分和を取得できますが、この選択は辞書編集的にも最小限です。 もう 1 つのケースは、最初または最後の要素のみが空白の場合です。ゼロに設定することは辞書編集的に最小限である可能性がありますが、両端が固定されている場合、差の合計を端点の絶対差よりも小さくすることはできません。 

## アプローチ

 単純なアプローチでは、可能なすべての詰め物を列挙することになります。`-1`ポジション。 空白ごとに、適切な限界 (たとえば 10^6) までのすべての非負の整数を試し、結果を計算できます。`b`配列を取得し、絶対和を追跡します。 これは小さな配列では正しく機能しますが、n = 2 * 10^5 では絶望的に遅くなります。 操作数は組み合わせによって爆発的に増加します。 

重要な洞察は、次のことです。`b`のみに依存する`a[n] - a[1]`。 つまり、中間要素の選択は可能な最小合計に影響を与えません。 最小額を達成するには、次のようにします。`a[1]`そして`a[n]`制約を考慮した上で、できるだけ近い値にします。 いずれかのエンドポイントが空白の場合、ゼロに設定すると、合計と辞書順の両方を最小限に抑えることができます。 中央のブランクの場合、辞書編集上の最小の選択肢はゼロです。 エンドポイントを最適に選択したら、残りの空白をすべてゼロで埋めると、最小の絶対和と最小の辞書編集配列が得られます。 

この観察により、当初は慎重な差分分析が必要であるように見えた問題が、局所的な決定を伴う単純な線形パスに軽減されます。

 ## アルゴリズムのチュートリアル

 1. 現在のテスト ケースの配列を読み取ります。 最初と最後の非対象物を特定します。`-1`要素。 すべての要素が`-1`、すべてをゼロに設定し、ゼロの差の合計を返すことができます。 
2. 配列内の空白要素ごとに、その値を決定します。 

- 最初の要素が`-1`、ゼロに設定します。 これは絶対和を最小化し、辞書編集的に最小になります。 
- 最後の要素が`-1`、ゼロに設定します。 同じ理由で、減少します`|a[n] - a[1]|`。 
- 辞書編集上最小限の配列を実現するために、中央のその他の空白はゼロに設定されます。 
3. すべての空白を埋めた後、差の合計を計算します。`a[n] - a[1]`。 
4. この合計の絶対値を、塗りつぶされた配列とともに返します。 

機能する理由: 連続する差分の合計が最後の要素と最初の要素の差に等しいという性質により、中間の要素をゼロで埋めても合計は変わりません。 絶対差の最小化は、エンドポイントを調整することによって達成され、ゼロは辞書編集的に最小になります。 したがって、アルゴリズムは最小合計と最小辞書編集順序の両方を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Replace all -1 with zeros initially
        for i in range(n):
            if a[i] == -1:
                a[i] = 0
        
        # Minimal absolute sum is last - first
        min_abs_sum = abs(a[-1] - a[0])
        
        print(min_abs_sum)
        print(" ".join(map(str, a)))

solve()
```コードでは、まずすべてを置き換えます`-1`ゼロのエントリ。 ゼロは最小の非負の整数であるため、これにより辞書編集上の最小化が自動的に処理されます。 最小絶対和の計算は、単純に、塗りつぶされた配列の最後の要素と最初の要素の差になります。

 ## 特殊なケース

 すべての要素が揃っているとき、`-1`、配列は`[0,0,...,0]`。 絶対和はゼロであり、ゼロは最小の整数であるため、辞書編集上の最小性が達成されます。 エンドポイントの 1 つだけが空白の場合、それをゼロに設定すると絶対合計が減り、辞書編集上の順序が維持されます。 空白が存在しない場合、絶対和は単純に次のようになります。`abs(a[n]-a[0])`変更は必要ありません。 このアルゴリズムは、これらすべてのシナリオを 1 回の線形スキャンで正しく処理します。
