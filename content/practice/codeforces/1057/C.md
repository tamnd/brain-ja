 **タグ:** *スペシャル、DP

 ## 解決策
 ## 問題の理解

 キャンディーボックスの列が与えられ、それぞれが整数座標に配置されています。 各ボックスには固定数のキャンディーが含まれており、すべて同じ色を共有し、各ボックスは赤、緑、または青のいずれかです。 特定のボックスから始めます。 そこから、移動ごとに 1 秒かかり、隣接するボックスまで左または右に歩くことも、現在のボックス内のすべてのキャンディーを即座に消費することもできます。 

食べるプロセスは、キャンディーが食べられる箱の順序に適用される 2 つの条件によって制約されます。 まず、連続して食べられたボックスは異なる色でなければなりません。 第二に、新しく食べた各ボックス内のキャンディーの数は、以前に食べたボックスの数を厳密に超えていなければなりません。 総歩行時間を最小限に抑えながら、収集されたキャンディーの総数が少なくとも k になるように、これらの制約を満たす食べた箱のシーケンスを選択したいと考えています。 

重要な構造は、食事は時間内に無料ですが、移動は無料ではないということです。そのため、コストは完全に、増加し、色が交互に変化する有効なボックスのサブシーケンスに到達するために、どのようにラインをナビゲートするかによって決まります。 

n ≤ 50 および k ≤ 2000 という制約は、サブセットまたは位置にわたるかなり高密度の動的計画法を考慮できるが、構造のない完全な配列の指数関数的探索は考慮できないことを強く示唆しています。 食べられたボックスのすべてのシーケンスに対する単純な指数関数的な検索は 3^n またはそれ以上に大きくなりますが、強い順序付けの制約を考慮すると、これは不必要です。 

最良の解決策が近くの「見栄えの良い」ボックスをスキップする必要がある場合、微妙なエッジケースが発生します。 たとえば、たくさんのキャンディーが入った箱は、その色が最後に食べた色と一致する場合、またはキャンディーの数が厳密な増加に違反する場合、早期に使用できなくなる可能性があります。 常に最も近い有効なボックスを選択する貪欲なアプローチは失敗する可能性があります。 

もう 1 つの失敗モードは、ボックスの有効な増加シーケンスを選択したら、以前の決定を再考することなくそれらの間を貪欲に移動できると仮定することです。 移動コストは順序の妥当性だけでなくグローバルな位置に依存するため、ローカルな決定により最適ではない移動ルートが生じる可能性があります。 

## アプローチ

 強引な解釈は、食べる箱の考えられるすべてのシーケンスを選択し、それが色の変更と厳密な増加制約を満たすかどうかをチェックし、s から順にそれらを訪問するのに必要な最小歩行コストを計算することを想像することです。 たとえシーケンスを修正したとしても、左右に自由に移動でき、すでに訪問したボックスを通過する可能性があるため、最小の移動コストを計算することは簡単ではありません。 

有効なシーケンスの数は n で指数関数的になります。 たとえサブシーケンスに限定したとしても、依然として巨大な状態空間に直面します。 このアプローチは、n = 50 付近ですでに実行不可能になります。 

重要な観察は、「状態」の唯一の意味のある構造は、最後に食べられた箱であるということです。 最後に食べた箱がわかれば、その後のすべての決定はその位置、色、キャンディーの数のみに依存します。 これは、エンドポイントを介した動的プログラミングの定式化を示唆しています。 

ボックスのペア i → j の間の dp 遷移を定義します。ここで、j は、色が異なり、キャンディーの数が大きい場合、i の次に食べられる有効なボックスです。 遷移コストは、現在位置と j の間の最短歩行距離です。 ただし、i で食事をした後は位置が i になるため、移動は単純に |i − j| になるという事実も考慮する必要があります。 

これにより、問題は、ノードがボックスでエッジがキャンディー数の増加と色の交互を考慮し、エッジの重みがインデックス間の絶対距離である有向グラフで最小コストのパスを見つけることに問題が軽減されます。 また、最初に選択したボックスに自由に移動できる、初期位置 s から開始できるようにする必要もあります。

収集されたキャンディーの総数も追跡するため、これまでに食べられたキャンディーの数という追加の次元が必要になります。 ただし、k ≤ 2000 であり、各ボックスには最大 50 個のキャンディーが入っているため、ナップザック スタイルの寸法も実現可能です。 

dp[i][t] を、ボックス i がちょうど t 個のキャンディーを食べて終了するまでの最小時間として定義します。 トランジションでは、キャンディーの数が少なく、色が異なる以前のすべてのボックス j が考慮されます。 dp[j][t − r[i]] から、コスト dp[j][t − r[i]] + |i − j| で dp[i][t] を更新します。 初期状態では、コスト |s − i| で s から開始することができます。 そして、t = r[i]。 

これにより、ボックスとキャンディー全体にきれいなレイヤード DP が生成されます。

2. dp[i][c] が正確に c 個のキャンディーを食べた後、ボックス i で終了するのに必要な最小歩行時間を表す DP テーブルを作成します。 最小化しているため、すべての値を無限大に初期化します。 
3. 各ボックス i について、開始位置 s から直接シーケンスを開始する状態を初期化します。 ボックス i を最初に食べる場合、時間コストは |s − i| です。 キャンディーの数は r[i] になります。 これにより、すべての有効な最初の動きがキャプチャされます。 
4. 次に、シーケンスの拡張を検討します。 r[i] > r[j] かつ c[i] ≠ c[j] であるボックスのペア (j, i) ごとに、j から i への遷移を許可します。 この遷移のコストは dp[j][c − r[i]] + |i − j| です。 絶対差は、j で終了した後、j から i まで歩いたことを反映しています。
