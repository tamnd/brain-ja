 ## 解決策
 ## 問題の理解

 長方形の迷路があります。 空のセルは通過可能、セルはマークされています`X`ブロックされています。 プレイヤーは左上隅から開始し、4 方向の移動を使用して右下隅に到達したいと考えています。 

空のセルに追加の障害物を 1 つだけ配置したいと考えています。 セルをブロックした後、パスがまだ存在しているにもかかわらず、開始から終了までの最短パスが厳密に長くなった場合、そのセルは有効です。 

出力は元の迷路ですが、すべての有効なセルが次のように置き換えられます。`*`。 

グリッドの大きさは次のとおりです。`1000 × 1000`、これは最大 100 万個のセルを意味します。 空のセルごとに最短パスを再計算するソリューションはまったく実行不可能です。 単一の BFS でさえ、すでに約 100 万の頂点に触れているため、グリッドのサイズは線形の複雑さに非常に近いものが必要です。 

微妙な点は、最短経路の長さを増やすことと迷路を切断することは同じではないということです。 

次の迷路を考えてみましょう。```
...
...
...
```左上隅から右下隅までのすべての最短パスの長さは 4 ですが、そのようなパスは多数あります。 単一の内部セルをブロックしても、長さ 4 の別の最短パスが残るため、回答セルは存在しません。 

ここで次のことを考えてみましょう。```
.....
.XXX.
.....
```中央の通路が唯一の最短ルートです。 内部セルの 1 つをブロックすると、最短経路はすべて破壊されますが、より長い迂回路がまだ存在します。 それらのセルは有効です。 

別のトラップが真のボトルネックです。```
...
.X.
...
```一部のセルがすべての最短パスだけでなく、考えられるすべてのパス上にある場合、それをブロックすると開始と終了が切断されます。 このステートメントではパスがその後も存在することが要求されるため、このようなセルをマークしてはなりません。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての空のセルについて、それを一時的にブロックし、最初から BFS を実行し、新しい最短距離を計算し、有限のままで大きくなったかどうかを確認します。 

グリッドに 100 万個のセルが含まれる場合、最大 100 万回の BFS 実行を意味します。 各 BFS はすでに`O(NM)`, したがって、作業の合計はおおよそ次のようになります。`O((NM)^2)`、これは現実的な限界をはるかに超えています。 

重要な観察は、セルが**すべての最短パス**に属している場合にのみ、最短パスの長さを増やすことができるということです。 

セルを回避する最短経路が存在すると仮定します。`v`。 ブロック後`v`、同じ最短経路が依然として存在するため、最短距離が増加することはありません。 

これにより、問題は 2 つの独立した質問に変わります。 

まず、すべての最短経路にどのセルが属するでしょうか?

 させて`distS[v]`スタートからの距離であり、`distT[v]`フィニッシュまでの距離。 セルは、まさに次のような場合に最短パスに属します。```
distS[v] + distT[v] = D
```どこ`D`スタートからゴールまでの最短距離です。 

すべての最短パス セルは階層化された DAG を形成します。 すべての最短パスは、離れたところにある 1 つの頂点を正確に訪れます。`0`、遠くに1つ`1`、遠くに1つ`2`、 等々。 

レイヤーに最短パス セルが 1 つだけ含まれている場合、すべての最短パスはそのセルを強制的に通過します。 レイヤーに 2 つ以上のセルが含まれている場合、それらの中から最短のパスを選択できます。 

したがって、最短パス セルは、その距離レイヤー内で一意の最短パス セルである場合に限り、すべての最短パスに属します。 

これにより、削除によってすべての最短パスが破壊されるすべてのセルが識別されます。 

2 番目の疑問は、そのようなセルを削除しても何らかの経路が残るかどうかです。 

これは典型的なグラフの質問です。 細胞が`s-t`頂点をカットします。 それを削除すると、スタートとフィニッシュが切断される場合、それは有効な答えではありません。 開始点と終了点が接続されたままの場合、すべての最短パスが消え、新しい最短距離は厳密に大きくなります。 

これは、単一の低リンク DFS で確認できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((NM)²) | O(NM) | 遅すぎる |
 | 最適 | O(NM) | O(NM) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 開始セルから BFS を実行し、計算します。`distS`。 
2. 終了セルから BFS を実行し、計算します。`distT`。 
3. しましょう`D = distS[finish]`。 
4. フリーセルごとに`v`、どうかを確認してください```
distS[v] + distT[v] = D
```true の場合、セルは少なくとも 1 つの最短パス上にあります。 
5. 各距離レイヤーに表示される最短経路セルの数を数えます。`distS[v]`。 
6. 最短経路セル`v`レイヤー数が等しい場合、すべての最短パスに属します`1`。 

その理由は、すべての最短パスにはすべてのレイヤーの 1 つの頂点が含まれている必要があるためです。 レイヤーに候補が 1 つしかない場合、すべての最短パスがそのレイヤーを強制的に通過します。 
7. フリーセル グラフ全体に対してローリンク DFS を最初から実行します。 
8. 各頂点について、頂点を削除すると開始と終了が切断されるかどうかを判断します。 そのような頂点を次のようにマークします`st_cut`。 
9. 次のすべてが当てはまる場合、セルは答えになります。```
it is free
it is not start
it is not finish
it belongs to every shortest path
it is not an s-t cut vertex
```10. グリッドを出力し、それらのセルを次のように置き換えます。`*`。 

### なぜ効果があるのか

 最短距離は、元の最短経路がすべて破壊された場合にのみ増加します。 セルは、すべての最短パスに属する場合、すべての最短パスを正確に破壊します。 

distance-layer 引数は、それらのセルを正確に識別します。 すべての最短パスはレイヤー内を順番に進み、単一の最短パス頂点を持つレイヤーはその頂点をすべての最短パスに強制します。 

このようなセルを削除すると、最短パスがすべて消えます。 開始点と終了点が接続されたままの場合、より長いパスがまだ存在するため、新しい最短距離は厳密には大きくなります。 スタートとフィニッシュが外れると移動は無効となります。 

アルゴリズムは両方の条件を満たすセルを正確にマークするため、報告されたすべてのセルが有効となり、すべての有効なセルが報告されます。 

## Python ソリューション```python
import sys
from collections import deque
from array import array

input = sys.stdin.readline

n, m = map(int, input().split())
g = [input().strip() for _ in range(n)]

V = n * m

def idx(r, c):
    return r * m + c

start = 0
target = V - 1

free = bytearray(V)
for r in range(n):
    row = g[r]
    base = r * m
    for c in range(m):
        if row[c] != 'X':
            free[base + c] = 1

def bfs(src):
    dist = array('i', [-1]) * V
    q = deque([src])
    dist[src] = 0

    while q:
        v = q.popleft()
        r = v // m
        c = v - r * m

        nv = v - m
        if r and free[nv] and dist[nv] == -1:
            dist[nv] = dist[v] + 1
            q.append(nv)

        nv = v + m
        if r + 1 < n and free[nv] and dist[nv] == -1:
            dist[nv] = dist[v] + 1
            q.append(nv)

        nv = v - 1
        if c and free[nv] and dist[nv] == -1:
            dist[nv] = dist[v] + 1
            q.append(nv)

        nv = v + 1
        if c + 1 < m and free[nv] and dist[nv] == -1:
            dist[nv] = dist[v] + 1
            q.append(nv)

    return dist

distS = bfs(start)
distT = bfs(target)

D = distS[target]

cnt = array('i', [0]) * (D + 1)
on_shortest = bytearray(V)

for v in range(V):
    if free[v] and distS[v] != -1 and distS[v] + distT[v] == D:
        on_shortest[v] = 1
        cnt[distS[v]] += 1

mandatory = bytearray(V)
for v in range(V):
    if on_shortest[v] and cnt[distS[v]] == 1:
        mandatory[v] = 1

tin = array('i', [0]) * V
low = array('i', [0]) * V
parent = array('i', [-1]) * V
contains_t = bytearray(V)
st_cut = bytearray(V)

timer = 0

stack = [(start, 0)]
parent[start] = start

while stack:
    v, it = stack[-1]

    if tin[v] == 0:
        timer += 1
        tin[v] = low[v] = timer
        if v == target:
            contains_t[v] = 1

    r = v // m
    c = v - r * m

    neigh = []

    if r:
        neigh.append(v - m)
    if r + 1 < n:
        neigh.append(v + m)
    if c:
        neigh.append(v - 1)
    if c + 1 < m:
        neigh.append(v + 1)

    advanced = False

    while it < len(neigh):
        to = neigh[it]
        it += 1
        stack[-1] = (v, it)

        if not free[to]:
            continue

        if tin[to] == 0:
            parent[to] = v
            stack.append((to, 0))
            advanced = True
            break

        if to != parent[v]:
            if tin[to] < low[v]:
                low[v] = tin[to]

    if advanced:
        continue

    stack.pop()

    if v != start:
        p = parent[v]

        if contains_t[v] and low[v] >= tin[p]:
            st_cut[p] = 1

        if low[v] < low[p]:
            low[p] = low[v]

        if contains_t[v]:
            contains_t[p] = 1

ans = [list(row) for row in g]

for v in range(V):
    if v == start or v == target:
        continue

    if mandatory[v] and not st_cut[v]:
        r = v // m
        c = v - r * m
        ans[r][c] = '*'

print("\n".join("".join(row) for row in ans))
```2 つの BFS が実行された後、すべての空きセルは両端からの距離を認識します。 平等```
distS[v] + distT[v] = D
```少なくとも 1 つの最短パスに参加するセルを正確にフィルタリングします。 

Layer-Count 配列には、開始点からの各距離に表示される最短パス セルの数が格納されます。 カウント 1 は、そのレイヤーが強制されることを意味します。 

DFS は標準的なローリンク トラバーサルです。 余分な`contains_t`flag は、DFS サブツリーに終了頂点が含まれているかどうかを追跡します。 いつ```
low[child] >= tin[parent]
```子サブツリーには終了が含まれており、開始と終了を区切る親を削除します。 それらの頂点は除外されます。 

この実装では、反復 DFS を使用して、最大 100 万個のセルを含むグリッドでの再帰の深さの問題を回避します。
