 ## 解決策
 ## 問題の理解

 イゴールは`n`壁。 すべての壁の高さはちょうど 3 メートルで、`i`- 番目の壁には幅があります`a_i`。 

高さ3メートルのロール壁紙も販売しているので、高さがあっても無駄になりません。 各ロールは正確にカバーします`k`幅メートル。 

幅のある壁の場合`a_i`, イゴールは非常に具体的な方法で壁紙を貼り付けます。 彼はできるだけ多くの全幅ロールを使用します。 幅がこれよりも小さい場合`k`残っている場合は、新しいロールから必要な部分を切り取り、そのロールの残りをすぐに廃棄します。 ある壁で残ったものを別の壁に再利用することはできません。 

タスクは、購入する必要があるロールの総数を決定することです。 

制約が非常に大きいため、複雑なものをシミュレートすることはできません。 まであります`10^6`それぞれの幅は次のように大きくできます。`10^9`。 どのソリューションでも、各壁を一定時間内に個別に処理する必要があります。 壁上の線形スキャンは完全に安全ですが、二次スキャンは不可能です。 

間違いの主な原因は、部分的なロールがどのように機能するかを解釈することです。 

考慮する：```
n = 1, k = 5
a = [13]
```壁には 10 メートルの完全なロールが 2 つ必要で、残りの 3 メートルの場合は追加のロールが 1 つ必要です。 答えは`3`、 ない`2`最後のロールから残った 2 メートルは再利用できないためです。 

もう 1 つの簡単な間違いは、壁の幅がすでに で割り切れる場合に発生します。`k`。```
n = 1, k = 5
a = [10]
```答えは`2`、 ない`3`。 露出した残りがないため、追加のロールは必要ありません。 

最後のエッジケースは、`k = 1`。```
n = 1, k = 1
a = [7]
```各ロールはちょうど 1 メートルをカバーするため、答えは次のようになります。`7`。 すべての幅は 1 で割り切れるため、ロールが部分的に使用されることはありません。 

壁に必要なロールの数はちょうど天井です`a_i / k`。 

## アプローチ

 単一の壁について考える最も直接的な方法は、引き算を繰り返すことです。`k`その幅から何も残らないまで。 すべての減算は 1 つのロールに対応します。 これは正しいです。なぜなら、各ロールは最大で貢献するからです。`k`幅メートル。 

幅のある壁の場合`a_i`、これにはおおよその必要があります`a_i / k`繰り返し。 以来`a_i`と同じくらい大きいかもしれない`10^9`1 つの壁にすでに 10 億回の操作が必要になる可能性があります。 まで`10^6`壁がある場合、このアプローチは完全に実行不可能です。 

繰り返しの減算は単に天井除算を計算しているだけであることが観察されます。 

壁の幅が次の場合`a_i`、 それから：```
rolls = ceil(a_i / k)
```いつ`a_i`で割り切れます`k`、すべてのロールが完全に使用されます。 

いつ`a_i`残りは、幅の完全なブロックすべてを残します`k`ロールを完全に使用し、残りの部分には追加のロールが 1 つ必要になります。 

したがって、答えは次のようになります。```
sum(ceil(a_i / k))
```整数演算を使用する:```
ceil(a_i / k) = (a_i + k - 1) // k
```この式を壁ごとに評価し、結果を蓄積します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(Σ(a_i / k)) | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`k`。 
2. すべての壁の幅を読み取ります。 
3.初期化`answer = 0`。 
4.壁幅ごとに`a`:

 コンピューティング```
rolls = (a + k - 1) // k
```これは次の整数形式です`ceil(a / k)`。 
5.追加`rolls`に`answer`。 
6.すべての壁を処理した後、印刷します`answer`。 

### なぜ効果があるのか

 あらゆる壁幅に対応`a`、 書く：```
a = qk + r
```どこ`0 ≤ r < k`。 

もし`r = 0`、 その通り`q`フルロールで壁を覆います。 

もし`r > 0`、`q`フルロールカバー`qk`残りの幅をカバーするには追加のロールが 1 つ必要です。`r`幅。 

したがって、ロール数は次のようになります。```
q            if r = 0
q + 1        if r > 0
```それはまさに`ceil(a / k)`。 

壁は独立しており、残り物は壁間で再利用できないため、合計の答えはすべての壁にわたるこれらの値の合計になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = map(int, input().split())

ans = 0
for x in a:
    ans += (x + k - 1) // k

print(ans)
```プログラムは壁の幅を 1 回通過します。 

表現`(x + k - 1) // k`整数のみを使用して上限除算を実装します。 これにより、浮動小数点演算が回避され、非常に大きな値でも正しく動作します。 

答えはさらに大きくなる可能性があります`10^9`まであるかもしれないので、`10^6`壁。 Python の整数は、そのような値を自動的に安全に処理します。 

入力自体以外に追加の配列やデータ構造は必要ないため、メモリ使用量は一定のままです。

# helper: run solution on input string, return output string

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

 ## 特殊なケース

 次のことを考慮してください。```
1 5
10
```アルゴリズムは以下を計算します。```
(10 + 4) // 5 = 2
```余りがないので追加のロールは追加されません。 出力は次のとおりです。```
2
```それは正しいです。 

ここで次のことを考えてみましょう。```
1 5
13
```アルゴリズムは以下を計算します。```
(13 + 4) // 5 = 3
```2 つのロールで 10 メートルをカバーし、3 番目のロールで残りの 3 メートルを供給します。 出力は次のとおりです。```
3
```これは、部分的に使用されたロールは再利用できないというステートメントの制限と一致します。 

ついに：```
1 1
7
```アルゴリズムは以下を計算します。```
(7 + 0) // 1 = 7
```各ロールは正確に 1 メートルをカバーするため、7 つのロールが必要です。 出力は次のとおりです。```
7
```これにより、天井分割式が可能な最小のロール幅も正しく処理できることが確認されます。
