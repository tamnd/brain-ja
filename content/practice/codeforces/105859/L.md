 ## 問題の理解

各セクションには 2 つの整数が与えられます。$k$そして$d$。 目標は、離れたところにある左ミラーの整数の位置を選択することです。$x$そして遠くにある右のミラー$y$、両方とも少なくとも 1 であるため、$k$- 番目の可視反射 (2 つの平行な鏡の間で跳ね返る物理学によって記述される鏡構造に現れる反射を、距離が増加する順に数えます) は、正確に距離が離れたところで現れます。$d$観察者から。 そのような整数のペアが存在しない場合は、不可能であることを報告する必要があります。 

システムを再解釈する有効な方法は、空間の無限の展開という観点から考えることです。反射は 2 つの境界間を跳ね返る繰り返しの「歩行」に対応し、観測された距離は、長さの交互のセグメントから導出される構造化された等差数列を形成します。$x$そして$y$。 問題は本質的に、特定のインデックス付き用語が特定のターゲット値と等しくなるようにそのシーケンスをパラメータ化できるかどうかを尋ねることです。

 ## アルゴリズムのチュートリアル

 1. 反射を長さの交互のセグメントとして解釈する$x$そして$y$、反射位置の決定的なシーケンスを生成します。 

各反射は、ミラー間を何回か完全に横断した後、左または右のミラーに到達することに対応します。 
2. シーケンスを 2 つの独立したサブシーケンスに分割します。左側のミラーで終わる反射と、右のミラーで終わる反射です。

### なぜ効果があるのか

 不変条件は、2 つの平行なミラー内のすべての反射パスが、各タイルが長さを持つ無限のタイル ライン内の直線横断にマッピングできることです。$x + y$、の位置$k$回目の反射は、通過したタイルの数と、エンドポイントがタイルの左側または右側の境界にあるかどうかにのみ依存します。 これにより、リフレクション プロセスのすべての分岐が削除されます。 各反射はこの展開された線の一意の端点に対応するため、代数マッピングはロスレスであり、有効な幾何学的構成が正確に 1 つの算術表現に対応すること、およびその逆が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    for _ in range(n):
        k, d = map(int, input().split())

        # If k is 1, first reflection is simply 2x (or symmetric),
        # but from symmetry we can assume a direct construction.
        # We try a simple constructive approach derived from parity structure.

        if k == 1:
            # first reflection distance must be 2x or 2y depending on direction
            # we choose x = d//2 if even, otherwise impossible
            if d % 2 == 0 and d // 2 >= 1:
                x = d // 2
                y = 1
                print(x, y)
            else:
                print("impossible")
            continue

        # For k >= 2, construct using simple decomposition:
        # treat k-th reflection as (k-1) full cycles plus one offset
        # we choose a simple valid structure:
        # x = 1, solve y from d = k*x + (k-1)*y or symmetric form

        x = 1
        # derived linear model: d = k + (k-1)*y
        num = d - k
        den = k - 1

        if num > 0 and num % den == 0:
            y = num // den
            if 1 <= y <= 10**9:
                print(x, y)
            else:
                print("impossible")
        else:
            print("impossible")

def main():
    solve()

if __name__ == "__main__":
    main()
