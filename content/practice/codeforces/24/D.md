 ## 解決策
 ## 問題の理解

 ボードには、`N`行と`M`列。 ロボットはセルから起動します`(i, j)`そしてランダムな動きを1つ繰り返し実行します。 内部セルからは、同じ確率で 4 つの選択肢があります。その場に留まる、左に移動する、右に移動する、または下に移動するです。 左の境界では左への移動は不可能なので、ロボットは滞在、右、下のみを選択します。 同じことが右側の境界線にも対称的に当てはまります。 

このプロセスは、ロボットが初めて最後の行に到達したときに終了します。 それが起こる前に、予想される移動数が必要です。 

これは最短経路の問題ではありません。 ロボットは最終的に最下位の行に到達するまで永遠にランダムに動作するため、必要な量は無限に多くのランダム ウォークに対する期待値になります。 

制約は次のとおりです`1000 x 1000`これにより、収束するまで遷移を繰り返しシミュレートする状態空間メソッドが即座に除外されます。 単純なマルコフ連鎖定式化では、最大 100 万の状態が作成されます。 そのサイズの高密度線形システムを解くことは完全に不可能です。 単一の長さの行の偶数立方時間`1000`はすでに遅すぎるでしょう。 

ムーブメントの構造が重要な観察点です。 ロボットは下方向にのみ移動し、上方向には移動しません。 それは列への期待を意味します`r`行のみに依存する`r + 1`, そのため、行を下から上に独立して処理できます。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

ロボットがすでに最終行からスタートしている場合、すでにゴールに到達しているため、答えは正確にゼロになります。 

例：```
Input
3 5
3 2
```正しい出力:```
0.0
```不用意に実装すると、依然としてこの行の方程式が構築され、正の期待値が生成される可能性があります。 

ケース`M = 1`動作も異なります。 列が 1 つしかないため、ロボットは確率で留まるか下に移動することができます。`1/2`。 漸化式は、一般的な三重対角系よりもはるかに単純になります。 

例：```
Input
2 1
1 1
```予想されるステップ数は、`2`、それぞれの動きは確率で成功するため、`1/2`。 

もう 1 つの微妙な問題は、境界確率に起因します。 内側のセルには 4 つの可能な動きがありますが、端のセルには 3 つしかありません。 どこでも同じ繰り返しを再利用すると、境界付近で誤った期待が生じます。 

例：```
Input
2 2
1 1
```から`(1,1)`ロボットには、留まる、右、下という 3 つの選択肢しかありません。 これを内部セルのように扱うと、下に移動する確率が過小評価され、誤った期待が与えられます。 

## アプローチ

 直接的な強引なアイデアは、セルごとに 1 つの方程式を定義することです。 させて`E[r][c]`は、そのセルからの予想される残りのステップを示します。 州ごとに次のように書きます。```
E[state] = 1 + average(E[next states])
```これにより、最大で次の線形システムが生成されます。`10^6`変数。 一般的なガウス消去法では、大まかに次のことが必要になります。`10^18`操作、完全に実行不可能。 

反復緩和法にも問題があります。 期待はグリッド全体にゆっくりと伝播する可能性があり、収束するには 100 万の州を何度も完全に通過する必要があります。 

重要な構造上の観察は、ロボットが決して上方に移動しないということです。 一度列を離れると、決して戻ってくることはありません。 そのため、現在の行は、その下のすでに計算された行にのみ依存します。 

行に対するすべての期待がすでにわかっていると仮定します。`r + 1`。 次に列について`r`, すべての式は、同じ行内のセルと次の行の定数のみを参照します。 これにより、問題は 1 次元システムの解決に変換されます。 

内部列の場合:```
E[c] = 1 + (E[c-1] + E[c] + E[c+1] + below[c]) / 4
```並べ替え:```
3E[c] - E[c-1] - E[c+1] = 4 + below[c]
```これは三重対角線形システムです。 このようなシステムは、前方消去と後方置換を使用して線形時間で解くことができます。 

すべてのセルにわたる 1 つの巨大なシステムを解決する代わりに、行ごとに 1 つの三重対角システムを解決します。 あるので`N`行があり、各行には`M`列の合計の複雑さは次のようになります。`O(NM)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((NM)^3) | O((NM)^2) | 遅すぎる |
 | 最適 | O(NM) | お(お) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 定義する`dp[c]`列からの予想される残りのステップ数として`c`現在の行の下の行にあります。 

最初に、一番下の行では、ロボットがすでにターゲットに到達しているため、すべての期待値はゼロです。 
2. からの行を処理します。`N - 1`上向きに`1`。 

各行はその直下の行にのみ依存するため、ボトムアップ処理により、必要な値がすべて既知であることが保証されます。 
3. もし`M = 1`、行を直接処理します。 

ロボットの可能な動作は 2 つだけです。留まるか下に移動するかです。 

方程式は次のとおりです。$E = 1 + \frac{E + below}{2}$並べ替えると次のようになります。$E = 2 + below$4. それ以外の場合は、行の三重対角システムを構築します。 

左側の境界の場合:$2E_1 - E_2 = 3 + below_1$使える手は3つしかないからです。 
5. すべての内部列について:$3E_i - E_{i-1} - E_{i+1} = 4 + below_i$6. 右側の境界の場合:$2E_M - E_{M-1} = 3 + below_M$7. 順消去法を使用して三重対角系を解きます。 

各式から左側の係数を削除して、すべての行がそれ自体と次の変数のみに依存するようにします。 
8. 右から左へ逆置換を実行します。 

これにより、現在の行に対するすべての期待が回復されます。 
9. 交換`dp`新しく計算された行を使用します。 
10. 開始行まで処理後、開始列の期待値を出力`j`。 

### なぜ効果があるのか

 重要な不変条件は、行を処理するときです。`r`、行への期待`r + 1`はすでに正しく、最終的なものです。 

行のすべての方程式`r`は期待値の定義から直接得られます。```
expected steps = 1 + expected future value
```行内の未知の要素は隣接する列だけであり、三重対角線形システムが作成されます。 前方消去と後方置換はこのシステムを正確に解決するため、行に対して計算されるすべての期待値は数学的に正確になります。 行は上位の行に依存しないため、下から上への処理により、到達可能なすべての状態の正確な期待値が計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    start_row, start_col = map(int, input().split())

    if start_row == n:
        print("0.0000000000")
        return

    dp = [0.0] * m

    for _ in range(n - 1, start_row - 1, -1):
        if m == 1:
            dp[0] += 2.0
            continue

        a = [0.0] * m
        b = [0.0] * m
        c = [0.0] * m
        d = [0.0] * m

        b[0] = 2.0
        c[0] = -1.0
        d[0] = 3.0 + dp[0]

        for i in range(1, m - 1):
            a[i] = -1.0
            b[i] = 3.0
            c[i] = -1.0
            d[i] = 4.0 + dp[i]

        a[m - 1] = -1.0
        b[m - 1] = 2.0
        d[m - 1] = 3.0 + dp[m - 1]

        for i in range(1, m):
            factor = a[i] / b[i - 1]
            b[i] -= factor * c[i - 1]
            d[i] -= factor * d[i - 1]

        ndp = [0.0] * m
        ndp[m - 1] = d[m - 1] / b[m - 1]

        for i in range(m - 2, -1, -1):
            ndp[i] = (d[i] - c[i] * ndp[i + 1]) / b[i]

        dp = ndp

    print(f"{dp[start_col - 1]:.10f}")

solve()
```このソリューションでは、一度に 1 行の期待値のみが保存されます。`dp[c]`は常に、現在の行の下の行に対する計算済みの期待値を表します。 

特別な取り扱いは、`M = 1`ゼロ除算を回避し、単一列ボード内の異なる遷移構造を反映します。 この分岐がないと、三重対角構造は存在しない近傍を誤って参照してしまいます。 

配列`a`、`b`、 そして`c`三重対角システムの左、中央、右の係数を保存します。`d`定数項を格納します。 これは、標準的な Thomas アルゴリズムのレイアウトと一致します。 

前方削除により、システムが適切に変更されます。 インデックス処理後`i`、変数`E[i-1]`以降の方程式には表示されなくなります。 

逆置換では、行が右から左に再構築されます。 各変数はその右側にある計算済みの値に依存するため、順序は重要です。 

ループは、からの行を正確に処理します。`n - 1`まで`start_row`。 開始位置より上の行は答えに影響を与えることがないため、計算する必要はありません。

 ## 特殊なケース

 ロボットが既に最終行からスタートしている場合を考えてみましょう。 

入力：```
3 5
3 2
```アルゴリズムチェック`start_row == n`DP 作業が始まる前に。 ロボットはすでにターゲット行に到達しているため、予想される残りの移動数はちょうど 0 になります。 

次に、単一列のボードについて考えてみましょう。 

入力：```
2 1
1 1
```繰り返しは次のようになります。$E = 1 + \frac{E + 0}{2}$解くと次が得られます:$E = 2$実装は直接更新でこれを処理します`dp[0] += 2`。 

最後に、境界の動作を考慮します。 

入力：```
2 2
1 1
```方程式は次のとおりです。$2E_1 - E_2 = 3$

$-E_1 + 2E_2 = 3$解決の結果:$E_1 = E_2 = 3$このアルゴリズムはエッジ セルに対してこれらの正確な方程式を構築するため、境界を内部セルのように扱うことなく期待値が正しく計算されます。
