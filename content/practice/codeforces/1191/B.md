 ## 解決策
 ## 問題の理解

 ちょうど 3 枚の麻雀牌が与えられました。 各タイルは 1 から 9 までの数字とスートで構成され、スートは次のいずれかになります。`m`、`p`、 または`s`。 

この簡略化されたゲームで勝利するハンドには、メンツが 1 つだけ存在する必要があります。 メンツは、同じタイルの 3 つ組、または同じスート内の 3 つの連続する数字のシーケンスのいずれかになります。 

必要に応じて追加のタイルを描画することができ、タイルのコピーの数に制限はありません。 タスクは、保持するタイルの中に有効なトリプレットまたはシーケンスが少なくとも 1 つ存在するように、必要な追加のタイルの最小数を見つけることです。 

入力サイズが異常に小さいです。 常に正確に 3 つのタイルを受け取ります。 ゲームには異なるタイル タイプが 27 種類しかないため、かなり強引なアプローチも実行可能です。 課題はパフォーマンスではなく、現在のハンドが有効なメルドの形成にどれだけ近づいているかを正確に識別することです。 

いくつかの特殊なケースでは、誤った実装が容易に発生する可能性があります。 

考慮する：```
1m 1m 2m
```正しい答えは次のとおりです。```
1
```別の絵を描く`1m`トリプレットが完成します。 シーケンスのみをチェックするソリューションでは、誤って 2 が返されます。 

次のことを考慮してください。```
1m 2m 4m
```正しい答えは次のとおりです。```
1
```描画`3m`シーケンスを作成します`1m 2m 3m`。 すでに存在する隣接する番号のみを検索する不注意な実装では、これを見逃す可能性があります。 

考慮する：```
1m 3m 5m
```正しい答えは次のとおりです。```
2
```1 回の描画でシーケンスを完了できるほど近くにあるタイルのペアはありません。 有効なメルドには少なくとも 2 つの追加タイルが必要です。 

考慮する：```
9m 9m 9m
```正しい答えは次のとおりです。```
0
```ハンドにはすでにトリプレットが含まれているため、ドローする必要はありません。 

重要な観察は、答えは 0、1、または 2 のみであるということです。3 つのタイルから始めて、任意の 1 つのタイルを選択すると、追加の 2 つのコピーによって常にトリプレットが作成されます。 したがって、常に 2 回のドローで十分です。 

## アプローチ

 ブルートフォース手法では、描画できるすべてのタイルが試行されます。 タイル タイプは 27 種類あるため、可能なすべての 1 タイル拡張とすべての 2 タイル拡張をテストし、メルドが存在するかどうかを確認できます。 総作業量は少ないです:

 - 1 回のドローで 27 の可能性があります。 
-$27^2 = 729$2ドローの可能性。 

各候補ハンドについて、少数のタイルのみを検査します。 このアプローチでも簡単に制限内に収まります。 

ただし、問題の構造ははるかに単純です。 実際の将来のハンドを構築する必要はありません。 現在のハンドがすでにメルドにどれだけ近づいているかを知る必要があるだけです。 

メルドは 3 つのタイルで構成されます。 すでに 3 つのタイルを保持しているため、潜在的なメルドはすべて、それらの 1 つ、2 つ、または 3 つすべてを使用する必要があります。 

現在の 3 つのタイルすべてがすでにメルドを形成している場合、答えは 0 です。 

タイルを 1 つ追加した後、現在の 2 つのタイルがメルドの一部になることができる場合、答えは 1 です。 

それ以外の場合、答えは 2 です。 

これにより、タスクが、一部のメルドにすでに寄与しているタイルの最大数を測定することになります。 

トリプレットの場合、同一のタイルが一緒に貢献します。 2 つの等しいタイルには、もう 1 つのコピーが必要です。 3 つの等しいタイルは必要ありません。 

シーケンスの場合、同じスーツのタイルのみが重要です。 同じスーツの 2 つのタイルは次のようになります。 

- 連続したものなど`4m`そして`5m`、エンドポイント タイルが 1 つ必要です。 
- 1 つのギャップで区切られている、など`4m`そして`6m`、中央のタイルが必要です。 
- 同一。シーケンスには役に立ちませんが、トリプレットには役立つ可能性があります。 

すべてのタイルのペアを評価し、既に存在するメルドのタイルの数を決定します。 見つかった最良の値が答えを決定します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(27²) | お(1) | 承認済み |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 3 つのタイルを読み取ります。 
2. 答えを 2 として初期化します。 

どのタイルでもさらに 2 枚引くことでトリプレットに変えることができるため、常に 2 枚引くだけで十分です。 
3. すべてのタイルを個別に確認します。 

単一のタイルはすでに将来の融合に向けて 1 つのタイルに貢献しているため、答えは 2 を超えることはできません。 
4. タイルのすべてのペアを確認します。 

2 つのタイルが同一である場合、それらはすでにトリプレットの 3 分の 2 を形成しています。 回答を最大 1 に更新します。 
5. 同じスートを持つすべてのペアについて、その数値を比較します。 

数値の差を次のようにします`d`。 
6. もし`d = 0`、ペアはトリプレットに向けて 2 つのタイルを提供します。 

回答を最大 1 に更新します。 
7. もし`d = 1`または`d = 2`、適切なタイルを 1 つ追加した後、ペアはシーケンスになる可能性があります。 

例:

 -`3m, 4m`ニーズ`2m`または`5m`。 
-`3m, 5m`ニーズ`4m`。 

回答を最大 1 に更新します。 
8. 3 つのタイルすべてがすでにトリプレットを形成しているかどうかを確認します。 

そうであれば、答えは0です。 
9. 3 つのタイルすべてが同じスーツのシーケンスを形成しているかどうかを確認します。 

数値を並べ替えて、連続していることを確認します。 

そうであれば、答えは0です。 
10. 答えを出力します。 

### なぜ効果があるのか

 すべてのメルドにはちょうど 3 つのタイルが含まれています。 ハンドにはすでに 3 つのタイルが含まれているため、重要なのは、メルドのタイルがすでに何枚存在するかだけです。 

メルドの 3 つのタイルがすべて存在する場合、引く必要はありません。 

メルドのタイルが 2 つある場合は、1 回のドローで完了します。 

メルドに複数の現在のタイルが含まれていない場合は、少なくとも 2 回の描画が必要です。 既存のタイルからトリプレットを完成させれば常に 2 回のドローで十分なので、答えは正確に 2 になります。 

このアルゴリズムは、2 つのタイルが同じトリプレットまたはシーケンスに属することができるあらゆる方法と、3 つのタイルすべてが既にメルドを形成している可能性があるあらゆる方法を明示的にチェックします。 したがって、常に必要な描画の最小数を返します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

tiles = input().split()

ans = 2

for i in range(3):
    for j in range(i + 1, 3):
        a, sa = int(tiles[i][0]), tiles[i][1]
        b, sb = int(tiles[j][0]), tiles[j][1]

        if tiles[i] == tiles[j]:
            ans = min(ans, 1)

        if sa == sb:
            d = abs(a - b)
            if d <= 2:
                ans = min(ans, 1)

# triplet
if tiles[0] == tiles[1] == tiles[2]:
    ans = 0

# sequence
nums = []
suit = tiles[0][1]

same_suit = True
for t in tiles:
    if t[1] != suit:
        same_suit = False
        break
    nums.append(int(t[0]))

if same_suit:
    nums.sort()
    if nums[0] + 1 == nums[1] and nums[1] + 1 == nums[2]:
        ans = 0

print(ans)
```解決策は、答えが 2 を決して超えないという観察から始まります。`ans = 2`次に、必要なドローが 1 つだけであるか、ドローが 0 つであるという証拠を探します。 

ネストされたループは、タイルのすべてのペアを検査します。 タイルが 3 つしかないため、正確に 3 つのペアが存在します。 2 つのタイルが同じである場合、それらはすでにトリプレットの 3 分の 2 です。 2 つのタイルが同じスートを持ち、その数字の違いが最大 2 つである場合、1 つのタイルでシーケンスを完了できます。 

ペアの処理後、ハンドがすでに完了しているかどうかを確認します。 3 つのタイル文字列はすべて等しい必要があるため、トリプレットは簡単に検出できます。 

シーケンスでは、3 つのスーツがすべて一致する必要があります。 次に、数値を並べ替えて、それらが連続した値を形成していることを確認します。 並べ替えにより、入力順序への依存が回避されます。 

よくある間違いは、ギャップがちょうど 2 である場合を忘れることです。たとえば、`3m`そして`5m`。 1 つのタイル、つまり`4m`、シーケンスが完了します。 チェック中`d <= 2`隣接するペアと 1 ギャップのペアの両方を正しく処理します。
