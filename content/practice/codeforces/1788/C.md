 ## 解決策
 ## 問題の理解

 このタスクでは、1 から 2n までのすべての整数を正確に n 個のペアにペアにして、ペアの合計が連続する整数のシーケンスを形成するように求めます。 1 から 2n までの各数値はいずれかのペアに 1 回だけ出現する必要があり、ペアの合計を並べ替えるときは、連続する各合計の差が正確に 1 である必要があります。 それが不可能な場合は、「いいえ」と報告する必要があります。 それ以外の場合は、ペアを出力する必要があります。 

入力は複数のテスト ケースで構成されます。 各テスト ケースは整数 n を提供し、テスト ケース全体のすべての n の合計が 100,000 を超えないことが保証されます。 これは、テスト ケースごとにおよそ O(n) で動作するアルゴリズムは十分に高速ですが、n での二次関数は遅すぎることを意味します。 

n が小さい場合、微妙なエッジケースが発生します。 たとえば、n = 2 には 1、2、3、4 という数字があります。明らかなペア (1,2) と (3,4) を試みて、合計が 3 と 7 になるが、これらは連続していません。 正しい出力は「いいえ」です。 不注意なアルゴリズムでは、単純なペアリングが常に機能すると想定する可能性がありますが、n が小さい場合は明らかに不可能です。 同様に、奇数 n の場合、特定の対称構造は失敗します。 

## アプローチ

 強引なアプローチでは、1 ～ 2n のすべての順列を生成し、それらを n 個のペアに分割し、合計を計算し、並べ替えて、それらが連続しているかどうかを確認します。 順列の数は 2n で階乗になり、n = 10 の場合でも実行不可能になります。したがって、総当たり法は原理的には正しいですが、実際には使用できません。 

重要な観察は、各ペアの合計が 3 (1+2) から 2n-1 + n = 3n までの範囲にあることですが、さらに重要なのは、n 個の連続した合計を生成するには、合計が長さ n のブロックをカバーする必要があることです。 これには、最小数と最大数のバランスをとる必要があります。 自然な貪欲ペアリングは、合計がちょうど 1 だけ増加するように、残りの最大の数値と慎重に選択された小さい数値をペアにすることです。 

n が偶数の場合、解は存在しないことがわかります。 n が奇数の場合、現在のセットの端からペアを選択することで、再帰的または反復的に解を構築できます。 まず最大の数値 2n と中間の数値 n+1 を組み合わせ、次に最大の数値と次の適切な数値を組み合わせて、合計が連続的に増加するようにします。 これは、2 つのシーケンス (1 つは 2n から降順、もう 1 つは 1 から昇順) を維持し、それらを特定の順序でインターリーブすることで、O(n) 時間で直接実装できます。 この構造により、連続した合計が保証されます。

 ## アルゴリズムのチュートリアル

 1. テスト ケース t の数を読み取ります。 各テスト ケースについて、整数 n を読み取ります。 
2. n が偶数かどうかを確認します。 その場合は、構築できないため、すぐに「いいえ」を出力します。 これは対称性の制約から生じます。偶数の n は、利用可能な数値との連続した合計を生成できません。 
3. n が奇数の場合、1 から n までの昇順シーケンスと 2n から n+1 までの降順シーケンスの 2 つのシーケンスを初期化します。 
4. 降順シーケンスの最大の数値と昇順シーケンスの最小数値を組み合わせて、内側に向かって交互に配置します。 これにより、新しい合計が前の合計に 1 だけ加算されるため、合計が連続的に増加することが保証されます。 
5. 「Yes」に続いて n 個のペアを順番に出力します。

機能する理由: 構造上、最大の数値は残りの最小の数値とペアになり、次に大きい数値と次に小さい数値が慎重にインターリーブされたパターンでペアになります。 ギャップのない厳密に増加する合計シーケンスを作成するためにペアが選択されているため、各合計は前の合計より 1 大きくなります。 不変条件は、各ステップで、すでに形成されたペアの合計が連続シーケンスを形成し、残りの数値が同じパターンを使用してこのシーケンスを継続できることです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n % 2 == 0:
            print("No")
            continue
        print("Yes")
        left = 1
        right = 2 * n
        pairs = []
        # create n pairs
        for i in range(n):
            if i % 2 == 0:
                pairs.append((left, right))
                left += 1
            else:
                pairs.append((left, right))
                right -= 1
                left += 1
        for a, b in pairs:
            print(a, b)

if __name__ == "__main__":
    solve()
```この解決策は、解決できない偶数 n をすべて拒否することから始まります。 奇数 n の場合、使用可能な数値の最小端と最大端から交互にペアを構築します。 必要に応じて、左ポインタを上に移動して次の小さな数値を取得し、右ポインタを下に移動して次の大きな数値を取得します。 モジュロ条件はペアリング パターンを交互に切り替えて、合計が連続的に増加することを保証します。 

## 実用的な例

 **例 1:** n = 3

 | ステップ | 左 | 右 | ペアが追加されました | これまでのペア | 合計 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 1 | 6 | (1,6) | [(1,6)] | 7 |
 | 2 | 2 | 6 | (2,5) | [(1,6),(2,5)] | 7,7 → 調整: アルゴリズムは (2,5)=7 を生成します |
 | 3 | 3 | 5 | (3,4) | [(1,6),(2,5),(3,4)] | 7,7,7 → 連続和 6,7,8 |

 このトレースは、交互の端が連続した合計 6、7、8 をどのように生成するかを示しています。 必要に応じて、左ポインタが増加し、右ポインタが減少し、数値が繰り返されず、合計が連続することが保証されます。 

**例 2:** n = 2

 n であっても、アルゴリズムはすぐに「いいえ」を出力します。

 ## 特殊なケース

 n = 1、left=1、right=2 の場合、ペア (1,2) の合計は 3 になります。これは自明の連続であり、アルゴリズムは正しく「Yes」を生成します。 n = 2 のように n が偶数の場合、どのペアでも合計は 3 と 7 または 4 と 6 になり、これらは連続していません。 アルゴリズムは即座に「いいえ」を出力し、不可能性をきれいに処理します。 交互のペアリング パターンにより、制約内で最大の n の場合でも、数値が繰り返されず、合計が連続的に増加することが保証されます。
