 ## 解決策
 ## 問題の理解

 各要素が 1 または 2 である一連の数値が与えられます。私たちの目標は、最初の部分の数値の積が 2 番目の部分の数値の積と等しくなるように、シーケンスを 2 つの連続する部分に分割することです。 具体的には、最小のインデックスを見つけたいと考えています。`k`この分割が機能する場所。 分割が機能しない場合は戻ります`-1`。 

入力サイズはテスト ケースごとに最大 1000 要素に達する可能性があり、テスト ケースは最大 100 個存在できます。 これは、考えられるすべての分割の積を計算する単純なアプローチでは、最悪の場合、約 500,000 回の積計算が必要になることを意味します。これは、慎重に実行すれば Python では実現可能ですが、シーケンス値に関する単純な数学的観察を使用することで、より良い結果を得ることができます。 すべての数値は 1 または 2 であるため、積は非常に予測どおりに増加します。1 を掛けても何も起こりませんが、2 を掛けても積が 2 倍になるだけです。 

すべての数値が 1 の場合、エッジ ケースが発生します。たとえば、入力の場合`[1, 1, 1, 1]`、すべての分割で等しい積が生成され、答えが最初のインデックスになるはずです`1`。 もう 1 つのエッジ ケースは、分割が存在しない可能性がある、2 が大半を占めるシーケンスです。`[2, 2, 2]`、2 は反対側の 1 の積と一致しないため、等しい積に分割することはできません。 

## アプローチ

 ブルートフォース手法では、考えられるすべての分割について左側の部分の積を計算し、次に右側の部分の積を計算して、それらを比較します。 これが機能するのは、すべての分割が明示的にチェックされ、正確さが保証されるためです。 Python では、最大 1000 要素の積を繰り返し計算すると、時間計算量が O(n^2) に達する可能性があり、許容範囲内ですが非効率的です。 

重要な観察は、1 と 2 のシーケンスの積は完全に 2 の数によって決まるということです。 1 を乗算しても積は変化しないため、両側の 2 の累積累乗を追跡するだけで済みます。 させて`total_twos`配列全体の 2 の数になります。 その後の左側の部分`k`要素には`left_twos`2 の数、右側の部分には`total_twos - left_twos`。 マッチする商品としては、`2^left_twos = 2^(total_twos - left_twos)`保持する必要がありますので、`left_twos`等しい必要があります`total_twos - left_twos`、つまり、`left_twos = total_twos / 2`。 もし`total_twos`は奇数です。分割は存在しません。 それ以外の場合は、左からスキャンして、2 のちょうど半分を含む最小のプレフィックスを見つけて、最小値を得ることができます。`k`。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、配列内の 2 の合計数を数え、それを次の場所に保存します。`total_twos`。 1 を掛けても積は変わらないため、1 は問題ではありません。 
2. もし`total_twos`が 0 の場合、すべての要素が 1 であるため、すべての分割の積は等しくなります。`1`最小の分割インデックスが常に有効であるためです。 
3. もし`total_twos`が奇数の場合、シーケンスを同じ数の 2 で 2 つの部分に分割する方法がないため、積は一致できません。 戻る`-1`。 
4. それ以外の場合、目標は、2 のカウントが正確に一致する最小のプレフィックスを見つけることです。`total_twos / 2`。 変数を初期化する`left_twos`0 に設定し、配列を反復処理します。 インクリメント`left_twos`2に遭遇するたびに1ずつ増加します。 
5. すぐに`left_twos`到達する`total_twos / 2`、現在のインデックスに最小値として 1 を加えた値を返します。`k`。 
6. 2 秒の半分に到達せずに反復が終了した場合 (次の場合には起こらないはずです)`total_twos`は偶数です)、戻ります`-1`。 

機能する理由: 2 のカウントが製品を完全に決定します。 シーケンスを 2 単位で均等に半分に分割すると、2 つの部分の積が自動的に一致します。 この不変式により、最小のインデックス分割が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        total_twos = a.count(2)
        if total_twos == 0:
            print(1)
            continue
        if total_twos % 2 == 1:
            print(-1)
            continue
        half_twos = total_twos // 2
        left_twos = 0
        for i in range(n):
            if a[i] == 2:
                left_twos += 1
            if left_twos == half_twos:
                print(i + 1)
                break

if __name__ == "__main__":
    solve()
```コードはまずテスト ケースの数を読み取り、次に各テスト ケースをループします。 1 は製品に影響を与えないため、2 の合計数を数えることが最初のステップです。 ゼロ 2 のエッジ ケースを処理することで、最小分割が正しく返されることが保証されます。 2 秒の半分のスキャンにより、最小限のインデックスが保証されます`k`。 ブレークにより、正しい分割が見つかるとすぐに停止するため、1 つずれたエラーが防止されます。

## 特殊なケース

 配列に 1 だけが含まれる場合、次のようになります。`[1, 1, 1, 1]`、`total_twos`アルゴリズムは最小分割として 1 を即座に返し、それ以上反復することなくこのシナリオを正しく処理します。 奇数の 2 の場合、次のようになります。`[2, 1, 2]`、`total_twos`は 2 (偶数) ですが、half_twos は 1 です。反復すると最初の 2 がインデックス 0 で見つかり、次の 2 がインデックス 2 で見つかります。そのため、left_twos はインデックス 0 のhalf_twos に到達します。`k = 1`が返されます。 これは確認します
