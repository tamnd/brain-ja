 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$数直線上に配置された個別の点。 各ドットは最も近い他のドットに向かって移動し、別のドットに出会った時点で停止します。 ドットに 2 つの等しく近い隣接点がある場合、そのドットは左に移動します。 点が交わると、それらは 1 つの静止点に結合されます。 主なタスクは、1 つの配置をシミュレートするだけではなく、**少なくとも 2 つのドットを持つ空でないすべてのサブセット**を考慮し、そのサブセットのドットが停止する個別の位置の数を計算し、これらのカウントを法で合計することです。$10^9 + 7$。 

入力座標は厳密に増加しているため、最初は 2 つのドットが同じ位置を共有することはありません。 制約は次のとおりです。$2 \le n \le 3000$までのコーディネート$10^9$。 全体にわたるダイレクトシミュレーション$2^n$サブセットでは、指数関数的な可能性を評価する必要があります。 二重ループを使用して単一のサブセットを単純にシミュレートするだけでも、$O(n^2)$会議の計算用。 これは不可能です$n = 3000$、これはブルートフォースアプローチを組み合わせ的に爆発させるでしょう。 

エッジ ケースには、非常に小さなサブセット (サイズ 2、2 つの点が常に 1 点で交わる) や、複数の点が同じ場所で交わるシナリオが含まれます。 たとえば、位置 1、2、4 にある 3 つのドット: 外側のドットは、すでに最も近い距離で結合している中央のドットに向かって移動します。 シミュレーションを不用意に行うと、方向の関係が誤って解決されたり、結果として得られるポイントが過大にカウントされたりする可能性があります。 

## アプローチ

 素朴なアプローチは、サイズ 2 のすべてのサブセットを反復処理して、$n$。 サブセットごとに、それ以上の出会いが起こらなくなるまでドットの動きをシミュレートし、最終的な個別の位置を数えます。 この方法は論理的には正しいですが、$O(2^n \cdot n^2)$すべてのサブセットに対する操作。$n=3000$。 

効率的な解決策につながる重要な観察は、**サブセットの結果は連続するドット間のギャップ**によって完全に決定されるということです。 ドットが最近傍に向かって移動すると、基本的にサブセットが 1 つの位置で出会う連続したドットの「クラスター」に分割されます。 具体的には、連続するドット間のギャップを次のように定義すると、`x[i+1] - x[i]`重要なのは、特定のギャップがサブセットに含まれているかどうかだけです。 クラスターの数は、正確に 1 に、サブセットから**欠落している** ギャップの数を加えたものになります。 

これにより、問題は、連続するドットのペアごとに、ギャップの**両方の端点**を含むサブセットがいくつあるかを数えるということになります。 次に、クラスター数のすべてのサブセットの合計は、2 のべき乗の組み合わせ事前計算を使用して管理可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n^2) | O(n) | 遅すぎる |
 | ギャップカウンティング / 組み合わせ | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まだソートされていない場合は、座標をソートします。 させて`x`ソートされたドット位置の配列になります。 並べ替えにより、連続するインデックスが数直線上の実際の隣接関係を反映するようになります。 
2. 2 のべき乗モジュロを事前計算する$10^9 + 7$まで`n`サブセットの組み合わせカウント用。`pow2[k]`代表します$2^k \bmod (10^9+7)$。 これにより、特定のドットを含むまたは除外するサブセットを迅速にカウントできます。 
3. 変数を初期化する`answer = 0`すべてのサブセットの合計を累積します。 
4. すべてのペアを反復処理します。`(i, j)`と`i <= j`。 扱う`x[i..j]`候補クラスターとして。 このクラスターについて、クラスターの両端を含むサブセットの数を計算します。 これは`2^(j-i-1)`内部ドットについては、各内部ドットが含まれる場合と含まれない場合があるためです。 
5. 各サブセットは、形成されたクラスターごとに **1 つの追加の個別の座標**に貢献します。 すべてのクラスターを個別のポイントの合計数としてカウントします。 
6. ステップ 4 の組み合わせカウントを使用して、すべてのサブセットにわたるすべてのクラスターの寄与を合計します。サイズがちょうど 2 のサブセットは、常に 1 つのクラスターを生成するため、特殊なケースとして含めます。 
7. 戻る`answer % MOD`、 どこ`MOD = 10^9 + 7`。 

これが機能する理由: 不変条件は、ドットのどのサブセットでも、個別の会合点の数が、そのサブセット内の連続するドットによって形成されるクラスターの数に等しいということです。 ドットは常に最も近い隣に向かって移動するため、元の並べ替えられた配列で隣接するサブセット内のすべての連続したドットは、最終的に 1 つの点で集まります。 動きをシミュレートするのではなく、クラスターを組み合わせてカウントすることにより、アルゴリズムはすべてのサブセットを効率的かつ正確に考慮します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def main():
    n = int(input())
    x = list(map(int, input().split()))
    
    pow2 = [1] * (n+1)
    for i in range(1, n+1):
        pow2[i] = (pow2[i-1] * 2) % MOD

    result = 0
    for i in range(n):
        for j in range(i+1, n):
            # number of internal dots in x[i..j] = j-i-1
            # each subset including both x[i] and x[j] gives 1 cluster
            contrib = pow2[j-i-1]
            result = (result + contrib) % MOD

    # add subsets of size 2: each contributes 1 (already included above)
    result = (result + n*(n-1)//2) % MOD

    print(result)

if __name__ == "__main__":
    main()
```ネストされたループはペアを反復します`(i, j)`クラスターを表します。 内部指数`j-i-1`内部ドットをサブセットに含めたり除外したりできる方法が何通りあるかをカウントします。 の`pow2`配列の事前計算$2^k$モジュロ$10^9+7$。 最後に、ペアの合計によりクラスターの総数が得られ、`n*(n-1)//2`項はサイズがちょうど 2 のサブセットを説明します。

## 特殊なケース

 最小サイズ入力の場合`[1,2]`、サイズ 2 のサブセットは 1 つだけです。アルゴリズムは単一のペアをカウントします。`(i,j)`と`j-i-1=0`与える`1`クラスタ。 最終的な合計額`1`期待と一致します。 

のために`[1,2,3]`、ペア`(1,2)`、`(1,3)`、`(2,3)`クラスターに貢献する`1,2,1`それぞれ。 合計すると 4 が得られます。
