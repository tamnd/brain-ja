 ## 問題の理解

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n, st, en = map(int, input().split())

        g = [[] for _ in range(n + 1)]

        for _ in range(n - 1):
            u, v = map(int, input().split())
            g[u].append(v)
            g[v].append(u)

        parent = [-1] * (n + 1)
        depth = [0] * (n + 1)

        stack = [en]
        parent[en] = 0

        while stack:
            u = stack.pop()

            for v in g[u]:
                if v == parent[u]:
                    continue

                parent[v] = u
                depth[v] = depth[u] + 1
                stack.append(v)

        order = list(range(1, n + 1))
        order.sort(key=lambda x: depth[x], reverse=True)

        print(*order)

solve()
```DFS は以下からの距離を計算します。`en`、根が生えた木の深さになります。 

親配列は、エッジを親に向かって逆に横断することを防ぎます。 グラフはツリーであるため、すべての頂点を正確に 1 回訪問するだけで十分です。 

深さがわかったら、残る作業は仕分けだけです。 より遠い頂点`en`順列の最初の方に現れます。 なぜなら`en`深さがある`0`, 当然、最後の要素になります。 

特別な処理は必要ありません`st`。 この構築はあらゆる開始位置で機能します。

def run(inp: str) -> str:
