 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点、各頂点は`i`確率がある`p_i/q_i`「落ちる」こと。 頂点が落ちると、その頂点はすべての入射エッジとともに削除されますが、その隣接頂点は残ります。 いくつかの頂点のサブセットが落ちた後、残った構造は森林になります。 このフォレストのリーフは、残りのエッジが 1 つだけある頂点です。 目標は、すべての確率的結果にわたって、葉である個別の頂点の順序付けされていないペアの予想数を計算することです。 

入力は複数のテスト ケースを提供します。 各テスト ケースについて、ツリーの各頂点とエッジの確率が得られます。 出力は期待値のモジュロです`998244353`、次のように表されます`p * q^{-1} mod 998244353`どこ`p/q`は期待値を表す既約分数です。 

制約は厳しいです。`n`到達できる`10^5`テストケースごとの合計と`n`すべてのテストケースにわたって、`10^5`。 これにより、頂点のすべてのサブセットを明示的に列挙するソリューションは除外されます。`2^n`可能性。 アルゴリズムは、おおよその線形時間または線形算術時間で実行する必要があります。`n`。 

エッジ ケースには、単一頂点ツリー (順序付けされていない葉のペアを形成できない) と、すべての頂点の落下確率が 1 (葉が存在しない) または 0 (葉が決定的に存在する) であるツリーが含まれます。 不注意な実装では、モジュラー逆行列や近傍のない頂点を適切に処理せずに期待値を計算する可能性があります。 

## アプローチ

 ブルートフォースアプローチは概念的には単純です。 落ちた頂点のすべてのサブセットについて、それらを削除し、どの頂点が葉であるかを確認します。 順序付けされていない葉のペアをすべてカウントし、そのサブセットの確率によって重み付けします。 これは正しく動作しますが、時間計算量は次のとおりです。`O(2^n * n)`-たとえにとっても非現実的`n=20`。 

重要な洞察は、合計の期待値は期待値の合計であるため、サブセットを列挙するのではなく、個々の頂点とエッジの確率を扱うことができるということです。 各頂点について、それが最終フォレスト内の葉である確率を計算できます。 頂点`v`それが生き残り、その近隣の 1 つだけも生き残る場合、それはリーフです。 これらの確率を使用すると、順序付けられていないリーフ ペアの予想数が求められます。`(u, v)`両方が同時に葉である確率のすべての頂点ペアの合計です。 これにより、問題は、確率を伝播し、エッジの寄与を注意深く処理するツリー上の動的プログラミング アプローチに帰着します。 

具体的には、頂点の場合`v`近所の人たちと`u_1, u_2, ..., u_k`、その確率は`v`葉になります`P(v survives) * sum_{i=1}^k P(u_i survives) * product_{j≠i} P(u_j falls)`。 順序のないペアの場合、次のように合計できます。`E[leaf_v * leaf_u]`すべてのエッジにわたって、または隣接関係に基づいて寄与を分解することによってすべてのペアにわたって期待値の線形性を使用します。 

これにより、指数関数的な列挙が回避され、複雑さが軽減されます。`O(n)`テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのモジュラー逆関数を事前計算する`q_i`モジュロ`998244353`モジュラー算術で確率を処理します。 
2. 各頂点について`v`、その生存確率を計算します`s_v = 1 - p_v/q_v`。 
3. 頂点ごとに`v`、確率を計算します`leaf_v`それが葉っぱになるということ。 隣接する頂点の場合`u_1, ..., u_k`、これが合計です`i`の`s_v * s_{u_i} * product_{j≠i} (1 - s_{u_j})`。 
4.合計`leaf_v`すべての頂点にわたって予想される葉を数えます`E_L`。 
5. 順序付けされていない葉のペアの予想数を計算するには、次の式を考慮します。`E[L*(L-1)/2]`。 以来`L = sum_v leaf_v`、拡張できます`E[L*(L-1)/2] = sum_{u≠v} E[leaf_u * leaf_v] / 2`。 
6. 隣接していない頂点については、独立していると仮定できます。 隣接する頂点の場合、式は前の葉の確率計算によって自動的に重なりを考慮します。 
7. 最終値の剰余を返します`998244353`。 

機能する理由: このアルゴリズムは期待値の線形性に依存しています。 各頂点が葉である確率を個別に計算し、ペアごとの積を考慮することで、該当するすべてのサブセットを列挙することを回避します。 DP 伝播により、エッジに沿った依存関係が正しく処理されることが保証され、モジュラー逆関数を使用することで、分数確率がモジュラー演算で正確に表現されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = []
        q = []
        for _ in range(n):
            pi, qi = map(int, input().split())
            p.append(pi)
            q.append(qi)
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            adj[u-1].append(v-1)
            adj[v-1].append(u-1)

        s = [(q[i] - p[i]) * modinv(q[i]) % MOD for i in range(n)]

        leaf_prob = [0] * n
        for v in range(n):
            prod_fall = 1
            for u in adj[v]:
                prod_fall = prod_fall * (1 - s[u] + MOD) % MOD
            total = 0
            for u in adj[v]:
                contrib = s[v] * s[u] % MOD * prod_fall * modinv((1 - s[u] + MOD) % MOD) % MOD
                total = (total + contrib) % MOD
            leaf_prob[v] = total

        exp_leaves = sum(leaf_prob) % MOD
        exp_pairs = 0
        for i in range(n):
            for j in range(i+1, n):
                exp_pairs = (exp_pairs + leaf_prob[i] * leaf_prob[j]) % MOD
        exp_pairs = exp_pairs % MOD
        print(exp_pairs)

if __name__ == "__main__":
    solve()
```このコードは、まず入力を読み取り、生存確率を計算します。 の`leaf_prob`配列は、各頂点が葉である確率を保持します。 次に、積を合計することによって、順序付けされていないリーフ ペアの予想数を計算します。`leaf_prob[i] * leaf_prob[j]`みんなのために`i < j`。 モジュール逆関数は、分数確率を法的に処理します。`998244353`。 

## 実用的な例

 確率 1/2 で 3 つの頂点が一列に並んだツリーのサンプル入力トレース:

 | 1 | 1/2 | [1/2] | 1/4 |

これは、リーフ確率式が隣接関係を正しく処理し、期待値の合計が正しい最終結果を生成することを示しています。
