 ## アルゴリズムのチュートリアル

 XOR 線形代数の構造を使用して、どのような構成に到達できるかを理解します。 

### ステップ

 1. すべての要素の XOR を計算し、それを呼び出します`S`。 各操作では同じ値が 2 つの位置に XOR され、グローバルに相殺されるため、この値はすべての許可された操作の下で不変です。 
2. 配列要素から GF(2) に対する線形基底を構築します。 この基礎により、配列から形成できるすべての XOR の組み合わせが取得されます。 
3. 基礎を使用して、位置間でビット寄与をどの程度自由に再配分できるかを決定します。 この基礎により、どのビットが独立して制御可能であるかがわかります。 
4. 最上位ビットから下に向かって、次の配列の構築を試みます。`n`XOR が成り立つ数値`S`最大要素を最小限に抑えながら。 これは、ビット制限を尊重しながら、基底ベクトルを数値に貪欲に分配することによって行われます。 
5. 制限要因は、実行可能な分布では回避できない最上位ビットになります。 そのビットが答えを決定します。 

### なぜ効果があるのか

 この操作ではグローバル XOR が保持され、インデックス間で XOR 寄与を転送できるため、到達可能な領域は、合計 XOR が同じである配列のセットになります。 線形基底では、入力の考えられるすべてのビットの再結合が捕捉されます。 最大要素を最小限に抑えているため、最適な配置は、基底ベクトルを最もバランスよく分散させることです。`n`スロット。 計算された境界よりも最大値を減らそうとする構成では、基底によってエンコードされた XOR 不変式を破る必要がありますが、これは不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        x = 0
        for v in a:
            x ^= v
        
        # build linear basis
        basis = [0] * 30
        for v in a:
            cur = v
            for b in range(29, -1, -1):
                if not (cur >> b) & 1:
                    continue
                if basis[b] == 0:
                    basis[b] = cur
                    break
                cur ^= basis[b]
        
        # try to reduce x using basis
        for b in range(29, -1, -1):
            if basis[b] and (x >> b) & 1:
                x ^= basis[b]
        
        # remaining x determines unavoidable structure
        print(x)

if __name__ == "__main__":
    solve()
```コードは、システムの重要な不変条件である合計 XOR を計算することから始まります。 次に、配列からバイナリ線形基底を構築し、以前に保存された基底ベクトルに対して各要素を削減します。 この基準は、利用可能なすべての独立した XOR 方向を表します。 

その後、アルゴリズムはグローバル XOR を削減しようとします。`x`同じベースを使用します。 基底ベクトルが最も高い設定ビットを削除できる場合、`x`、適用されます。 残りの値は、再配布できない既約 XOR 構造を表します。 

その残差値は、XOR 質量の最適な再配分後の最小の避けられない最大値に対応するため、答えとして出力されます。 

微妙な点は、適切な標準形式を確保するために基底の挿入を最上位ビットから最下位ビットに進める必要があることです。 この順序を逆にすると、後のベクトルが上位ビット構造を誤って使用する可能性があるため、正確性が失われます。
