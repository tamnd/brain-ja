 ## 解決策
 ## 問題の理解

 長さのバイナリ文字列を構築しています`n`そして、その逆とは正確に異なるようにしたいのです`k`ポジション。 ポジションごとに`i`で文字を比較します。`i`キャラクターがミラーリングされた位置にある`n-i+1`。 すべての不一致がスコアに 1 つ寄与します。これを問題では回文と呼びます。 

重要な観察は、ポジションが対称的にペアになっているということです。`i`は常に一致します`n-i+1`。 したがって、文字列は実際には、おそらく中央の文字を除いて、独立したミラーリングされたペアで構成されています。`n`奇数です。 各ペアは次のいずれかに貢献します`0`(両側が一致する場合) または`2`(異なる場合)、一方の端での不一致は、自動的にもう一方の端での不一致を意味するためです。 

それはすぐにどのような値を制約するか`k`可能です。 それぞれの不一致ペアはちょうど 2 つの違いに寄与するため、`k`均等である必要があり、それを超えることはできません`n`しかないから`n`ポジションの合計。 いつ`n`が奇数である場合、中央の文字はそれ自体と一致するため、回文に寄与することはありません。 

単純な試みでは、不一致を貪欲に配置するか、すべてのバイナリ文字列を総当たり攻撃してスコアをチェックすることによって文字列を構築しようとします。 それは次のように爆発します`2^n`、これは不可能です`n`まで`2·10^5`。 もう 1 つのよくある間違ったアプローチは、反転がミラーリングされたペアを介して結合されていることを忘れて、個々の位置を独立して反転しようとすることです。 これにより、過大なカウントや不可能な構成が発生します。`k`奇妙であるか、ペアの寄与と構造的に互換性がありません。 

エッジケースは次の場合に発生します。`k`構造が存在しない場合は奇妙です。 もう一つは、いつ`k`よりも大きいです`n`、すべてのペアが完全に不一致であっても、せいぜい結果しか得られないため、これも不可能です。`n`不一致はポジション全体でカウントされます。 

## アプローチ

 ブルート フォース ビューでは、長さのすべてのバイナリ文字列が生成されます。`n`、その逆を計算し、不一致の位置をカウントします。 これにより有効な回答が正しく特定されますが、コストがかかります`O(n·2^n)`これは中程度の人でも限界をはるかに超えています`n`。 

重要な構造的洞察は、文字列がミラーリングされたペアに分解されるということです。`(i, n-i+1)`。 各ペアは独立して動作し、次のいずれかに貢献します。`0`または`2`スコアに。 したがって、問題は正確に選択することになります。`k/2`ペアを不等にしますが、残りは等しいままです。 これがわかると、構築は直接的になります。一致または不一致を強制するために、各ペア内の値を割り当てるだけで済みます。 

これにより、問題は文字列に対する指数関数的な検索からペアに対する線形構築へと軽減されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n・2^n) | O(n) | 遅すぎる |
 | ペア構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. かどうかを確認します。`k`有効です。 もし`k`奇数である場合、すぐに出力されます`NO`それぞれの不一致が位置のペアに寄与し、奇数の合計が不可能になるためです。 もし`k > n`、出力も`NO`。 
2. 設定によりターゲットをペア形式に変換します`pairs = k / 2`。 異なるペアを作成するたびに、スコアに正確に 2 が寄与するため、正確に`pairs`対称ペアが一致していません。 
3. 長さの配列を初期化する`n`でいっぱい`'0'`。 これにより、現在すべてのペアが一致し、寄与がゼロであるクリーンなベースラインが得られます。 
4. 最初のものを繰り返します`n/2`ミラーリングされたペア。 各ペアごとに`(i, n-i-1)`それでも不一致のペアが必要な場合は、次のように割り当てます。`s[i] = '0'`そして`s[n-i-1] = '1'`、不一致予算の 1 単位を消費します。 
5. 不一致バジェットが残っていない場合は、残りのペアを同一に保ちます (`'0'/'0'`)、貢献度ゼロを維持します。 
6. もし`n`奇数であるため、中央の要素をそのままにしておきます`'0'`スコアには影響しないので。 
7. 構築された文字列を出力します。 

### なぜ効果があるのか

 各ミラーリングされたペアは独立しており、回文性への寄与は次のいずれかに固定されます。`0`または`2`。 正確に選択することで`k/2`ペアが異なる場合、合計不一致数が正確に一致する構成を構築します。`k`。 異なるペア間には相互作用がないため、左から右へ不一致を貪欲に割り当てても実現可能性を侵害することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())

        if k % 2 == 1 or k > n:
            print("NO")
            continue

        s = ['0'] * n
        need = k // 2

        i, j = 0, n - 1
        while i < j and need > 0:
            s[i] = '0'
            s[j] = '1'
            need -= 1
            i += 1
            j -= 1

        print("YES")
        print("".join(s))

if __name__ == "__main__":
    solve()
```この実装では、構築ループは対称ペア上でのみ実行され、奇数長の文字列の中央の要素を誤って変更することがなくなります。 変数`need`不一致ペアの正確な数を強制し、それがゼロに達すると、残りのペアはすべて同一のままになります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    return main(inp)

def main(inp):
    data = inp.strip().split()
    t = int(data[0])
    idx = 1
    out = []
    for _ in range(t):
        n = int(data[idx]); k = int(data[idx+1]); idx += 2
        if k % 2 or k > n:
            out.append("NO")
            continue
        s = ['0'] * n
        need = k // 2
        i, j = 0, n - 1
        while i < j and need > 0:
            s[i] = '0'
            s[j] = '1'
            need -= 1
            i += 1
            j -= 1
        out.append("YES")
        out.append("".join(s))
    return "\n".join(out)

assert run("1\n5 4\n") != "", "construct valid even k"

 ## 特殊なケース

 いつ`n = 1`、ミラーリングされたペアがないため、不一致数はゼロでなければなりません。 アルゴリズムは当然のことながら肯定的なものを拒否します`k`少なくとも 1 つのペアが必要になるためです。 

いつ`k = 0`、構築ループは決して実行されず、文字列は完全に対称のままになります。 これにより、回文性は正確にゼロになります。 

いつ`k = n`、考えられるすべてのペアが不一致として使用され、ループが枯渇するまで満たされます。 もし`n`が奇数の場合、中間の要素は無関係で有効性に影響を与えないため、構造は依然として成立します。 

これらのケースは、アルゴリズムが極端な制約とパリティ制約の両方を一貫して処理していることを確認します。
