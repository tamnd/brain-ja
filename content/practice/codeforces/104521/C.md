 ## 解決策
 ## 問題の理解

 私たちには一組のレッサーパンダが与えられていますが、線上での位置は分からず、各ペアのパンダの距離だけが与えられます。 それとは別に、数直線上の実際の座標のソートされたリストも与えられます。 タスクは、すべてのペアごとの距離が、割り当てられた座標間の絶対差と一致するように、どのパンダがどの座標に行くかを決定することです。 

言い換えれば、パンダの各ペアについて、入力行列内の距離が割り当てられた点間の幾何学的距離と等しくなるような、指定された位置へのパンダの未知の順列が存在します。 有効な割り当てはすべて回復する必要があります。 

制約は十分に厳しいので、テスト ケースごとの 2 次再構成は許容されますが、3 次の再構成や、ノードの 3 つのトリプルごとに大量の再計算が繰り返される場合は失敗します。 すべての n の合計は最大 1000 です。これは、テスト ケースごとに O(n^2) が安全であることを直ちに示唆しますが、O(n^3) も技術的に許容できる境界線ですが、Python では不要で危険です。 

対称性から微妙な問題が生じます。 構成が有効な場合は、その順序全体を逆にすると、別の有効な解決策が得られます。 つまり、一意の答えはなく、一貫した再構成で十分です。 2 番目の微妙な点は、距離だけでは座標が直接明らかにならず、相対的な順序のみが明らかになることです。 

素朴な間違いは、パンダ 1 までの距離によってパンダを並べ替えると正しい順序が得られると仮定することです。 これは、パンダ 1 が線分の端点ではない場合は常に失敗します。 

たとえば、3 匹のパンダが座標 0、5、10 にいて、パンダ 1 は 5 にあるとします。この場合、パンダ 1 からの距離は両方とも 5 であるため、どちらが左か右かを区別することはできません。 単純なソートでは、構造が誤って崩壊したり、関係が恣意的に切れたりして、他のペアごとの距離に違反します。 

## アプローチ

 ブルートフォースアプローチでは、すべての順列を試し、距離行列が誘導された絶対差と一致するかどうかを確認することによって、パンダを位置に割り当てようとします。 これは概念的には単純です。順列ごとに、すべてのペアごとの距離を検証します。 検証だけでも O(n^2) かかり、n 個あります。 そのため、このアプローチは n = 10 の場合でも完全に実行不可能になります。 

重要な構造的洞察は、2 つの端点を特定すると、ライン メトリック空間上の点が反射と平行移動に至るまで完全に決定されるということです。 1 つの端点 A を選択した場合、そこから最も遠い点は反対側の端点 B でなければなりません。これら 2 つのアンカーが固定されると、他のすべての点はその軸に沿った一意の座標を持ち、純粋に距離から計算できます。 

これが機能する理由は、実際のライン メトリックでは、エンドポイント間のパスが一意であり、他のすべてのポイントがその線上にあるためです。 距離の関係により、そのライン上に一貫した投影が強制されます。 

これにより、問題は、組み合わせ割り当てから、ソートが続く決定論的な座標再構成へと軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! · n^2) | O(n) | 遅すぎる |
 | エンドポイントの再構築 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 点がライン メトリック上に正確に位置するという事実を利用します。 

## アルゴリズムのチュートリアル

 1. 任意のパンダ (便宜的にパンダ 0) を選択し、距離行列を使用してそこから最も遠いパンダを見つけます。 これをパンダ A と呼びます。端点は離心率を最大化するため、ライン メトリック内の任意の点から最も遠い点は端点の 1 つである必要があります。 
2. A から、もう一度すべてのパンダをスキャンし、A までの距離が最大のものを見つけます。それを B とします。これにより、A と B が回線の 2 つのエンドポイントであることが保証されます。 
3. A と B を軸を定義するものとして扱います。 すべてのパンダ i について、次の式を使用してその座標を計算します。

x[i] = (d[A][i] - d[B][i] + d[A][B]) / 2。 

この式は、連立方程式 |x[i] - x[A]| を解くことから得られます。 および |x[i] - x[B]| A と B が直線の端であるという仮定の下で。 
4. 計算された座標でパンダを並べ替えます。 これにより、ライン上の左から右の順序が回復し、数値が安定します。 
5. ソートされたパンダを、指定されたソート位置 p1 < p2 < ... < pn の順に割り当てます。 対応するインデックスを出力します。 

### なぜ効果があるのか

 正しさは、1D 計量空間では、任意の点 i が端点 A と B の間の一意の線分上にあるため、その位置は A と B までの距離によって完全に決定されるという事実に左右されます。導出された座標式は、i を A と B によって定義される軸に投影することと同等です。座標がすべてのペアごとの距離と一致すると、実際の位置 p は同じ軸に沿って並べ替えられているため、それらの並べ替えは真の幾何学的順序と一致する必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = list(map(int, input().split()))
        d = [list(map(int, input().split())) for _ in range(n)]

        if n == 1:
            print(1)
            continue

        A = 0
        for i in range(n):
            if d[0][i] > d[0][A]:
                A = i

        B = A
        for i in range(n):
            if d[A][i] > d[A][B]:
                B = i

        dab = d[A][B]

        coords = []
        for i in range(n):
            x = (d[A][i] - d[B][i] + dab) / 2
            coords.append((x, i + 1))

        coords.sort()

        ans = [0] * n
        for i in range(n):
            ans[i] = coords[i][1]

        print(*ans)

if __name__ == "__main__":
    solve()
```実装では、まずテスト ケースごとに距離行列を構築します。 次に、任意の開始点から最も遠いノードを選択してエンドポイント A を識別し、A からの距離を最大化することでエンドポイント B を識別します。 

座標式は、2 による除算を超える整数の丸め処理を行わずに直接適用されます。入力は有効なライン メトリックであることが保証されているため、すべての中間値に一貫性があり、除算により整数が生成されます。 

最後に、これらの再構成された座標による並べ替えにより、正しい順序が得られ、並べ替えられた位置に直接マッピングされます。 

一般的な実装の落とし穴は、エンドポイント B の 2 番目のスイープをスキップすることです。エンドポイントが 2 つないと、座標があいまいになり、ソートが劣化して不正確なクラスタリングになります。 

## 実用的な例

 パンダが隠れた位置 0、3、7 に配置されている小さな構成を考えてみましょう。距離行列はこれらの違いをエンコードします。 

任意のノードから最も遠い A を選択します。A が位置 0 に対応すると仮定します。その場合、B は位置 7 のノードになります。 

| ステップ | あ | B | d[A][i] | d[B][i] | 座標 x[i] |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 0 | - | - | - | - |
 | Aを選択 | 0 | - | 0から最大 | - | - |
 | Bを選択 | 0 | 2 | - | Aからの最大値 | - |
 | i=0 を計算します | 0 | 2 | 0 | 7 | 0 |
 | i=1 を計算します | 0 | 2 | 3 | 4 | 3 |
 | i=2 を計算します | 0 | 2 | 7 | 0 | 7 |

 これにより、座標が元の順序を再構築していることが確認されます。 

ここで、エンドポイントの解釈が逆になる対称的なケースを考えてみましょう。 計算された座標は符号を反転するかシフトするだけですが、ソートは逆の順序でも同一のままであり、これは依然として有効です。 

| ステップ | あ | B | 座標 (未分類) | ソート順 |
 | --- | --- | --- | --- | --- |
 | エンドポイントの選択 | 右端 | 左端 | 逆の値 | 逆順 |

 これは、アルゴリズムが反射を許容することを示しています。

 ## 特殊なケース

 すべてのパンダが等間隔に配置されている場合、複数のパンダは非エンドポイント ピボットに対して同一の距離パターンを共有できます。 エンドポイントには常に一意の最大離心率があるため、エンドポイントベースの再構成ではこの曖昧さが回避されます。 

中間点が最初の基準として選択されている小さな 3 点ラインでは、両側が対称に見えるため、距離による単純な並べ替えは失敗します。 エンドポイント戦略は、末端から固定し、座標系に非対称性を強制することでこれを解決します。 

n = 1 の場合、エンドポイントの選択や分割が必要なく、正確さを期すために単一のパンダを直接出力する必要があるため、アルゴリズムは短絡する必要があります。
