 ## 解決策
 ## 問題の理解

 Nezzar には、指定された長さのチョコレート バーのコレクションがあります。 彼の目標は、しきい値よりも長いバーを繰り返し分割することです$k$すべてのバーが最長の長さになるまで$k$。 各分割は確率的です: 長さのバー$x$に比例する確率で選択されます$x$、その後、その長さに沿ったランダムな点で均一に分割されます。 すべてのバーが最大で安定した状態に達するために必要な分割の予想数を計算するように求められます。$k$。 

入力はバーの数を与えます$n$そして閾値$k$、その後に長さのリストが続きます$l_1, l_2, \ldots, l_n$。 出力は、予期される演算数を法的に表す単一の整数です。$998\,244\,353$、モジュラー逆算を使用します。 

制約が非常に厳しいため、プロセスの単純なシミュレーションは不可能です。 と$n$50までと$\sum l_i \le 2000$それぞれの長いバーは​​任意の実長に分割できるため、各分割を個別にシミュレートすると、組み合わせによる爆発的な可能性が生成される可能性があります。 エッジケースには、すべてのバーが以下の値よりも短いことが含まれます。$k$(期待値はゼロ)、単一の長いバー、または正確に等しいバーを持つ$k$。 

たとえば、次の場合$n=1$、$k=1$、バーの長さは$2$、単純なアプローチでは、連続分割を確率的にシミュレートしようとする可能性がありますが、正しい期待は次のとおりです。$4$、連続一様分割分布を考慮した再帰式から導出されます。 

## アプローチ

 ブルートフォースアプローチでは、モンテカルロ法を使用するか、チョコレートの長さの考えられるすべての組み合わせを追跡することによって、分割プロセスをシミュレートしようとします。 各操作によりバーの数が 2 倍になる可能性があり、バーは任意の実数で分割できるため、状態空間は連続です。 整数に離散化した場合でも、指数関数的に増加します。 最大全長 2000 の場合、$2^{2000}$計算上実​​行不可能な最悪の場合の状態。 

重要な洞察は、**期待値を再帰的に**使用して問題をモデル化することです。 させて$f(x)$バーの長さを減らすために必要な予想される操作の数を示します。$x$せいぜい$k$。 もし$x \le k$、$f(x) = 0$。 それ以外の場合は、最初の分割に条件を付けることができます。バーは均一にランダムな点で分割されます。$r \in (0,x)$、長さの 2 つのバーを作成します$r$そして$x-r$。 予想される操作数は次のようになります。$1 + \mathbb{E}[f(r) + f(x-r)]$。 期待値の線形性と一様分布を使用すると、これは、以下のすべての整数の長さの合計に換算されます。$x-1$、整数の離散化を仮定し、**動的計画法による解決策**を提供します。 

計算したら$f(x)$みんなのために$x \le \text{sum of all lengths}$、初期構成で予想される操作数は、次の加重合計です。$f(l_i)$、各バーの長さに比例し、全長で割られます。

 ## アルゴリズムのチュートリアル

 1. 合計を計算する$S = \sum l_i$。 これは、個々のバーが到達できる最大長を表します。 
2. 配列を初期化する$f[0 \ldots S]$可能なバーの長さごとに予想される操作を保存します。 セット$f[x] = 0$のために$x \le k$バーがすでに十分に短い場合は操作が必要ないためです。 
3.長さごとに$x$から$k+1$に$S$、計算する$f[x]$再帰的に。 ある長さのバーを考えてみましょう$x$。 整数点で均等に分割すると$1, 2, \ldots, x-1$、各分割により 2 つの小さなバーが生成されます。 期待値の線形性により、期待される演算数は次のようになります。$$f[x] = 1 + \frac{1}{x-1} \sum_{r=1}^{x-1} \big(f[r] + f[x-r]\big)$$による除算$x-1$考えられるすべての分割点にわたる一様な確率を反映します。 
4. もう一度$f[x]$が計算されたら、初期構成で予想される操作数を計算します。 長さのバーなので$l_i$に比例する確率で選択されます$l_i$、合計の期待値は次のとおりです。$$\text{answer} = \frac{\sum l_i \cdot f[l_i]}{\sum l_i}$$5. 全体にモジュラー演算を適用します。 分母モジュロの逆モジュラを使用します。$998\,244\,353$最終的な答えを計算します。 

機能する理由: 再帰は、あらゆるバーの長さに対して予想される操作数を正確に取得します。 短い長さから上に向かって構築することで、$f[r]$そして$f[x-r]$はすでに知られています。 期待値の線形性を使用すると、確率的分岐の処理が回避され、長さによる重み付けによって比例選択確率が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def solve():
    n, k = map(int, input().split())
    l = list(map(int, input().split()))
    S = sum(l)
    
    f = [0] * (S+1)
    
    for x in range(k+1, S+1):
        total = 0
        for r in range(1, x):
            total += f[r] + f[x-r]
            if total >= MOD:
                total -= MOD
        f[x] = (total * modinv(x-1) + 1) % MOD
    
    numerator = sum(li * f[li] for li in l) % MOD
    denominator = sum(l)
    
    ans = numerator * modinv(denominator) % MOD
    print(ans)

solve()
```コードはまず入力を読み取り、合計を計算します。 配列`f`可能なバーの長さごとに予想される操作を保存します。 ネストされたループが埋められます`f`上記のすべての長さについて`k`、漸化関係を使用します。 最後に、最初のバーの期待値が計算され、バーの長さによって重み付けされ、モジュロ 998244353 が出力されます。
