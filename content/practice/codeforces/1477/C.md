 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$2D 平面上の個別の点。 Nezzar は、結果として得られるシーケンス内で、連続する 3 つの点が中間点で厳密に 90 度未満の角度を形成するように、これらの点を並べ替えたいと考えています。 幾何学的に、点の場合$A$、$B$、 そして$C$からのベクトルを順番に$B$に$A$そしてからのベクトル$B$に$C$鋭角を形成する必要があります。 

入力はポイント数で構成されます$n$そして各点の座標。 出力は、「適切な」順序を表すポイント インデックスの順列である必要があります。 順序が存在しない場合は、次のように出力します。$-1$。 

制約によって与えられるのは、$3 \le n \le 5000$と間の座標$-10^9$そして$10^9$。 と$n$最大 5000、任意$O(n^2)$解決策は受け入れられます。$5000^2 = 25,000,000$2秒で実現可能です。 どれでも$O(n^3)$明らかにアプローチが遅すぎる。 個別の点は長さがゼロのベクトルがないことを保証するため、ゼロによる除算や未定義の角度は発生しません。 

エッジケースは、点がほぼ直線を形成する場合、または 3 つの点が同一線上にある場合に発生します。 たとえば、3 つの点が直線上にある場合、それらを順番に含むシーケンスは角度条件を満たしません。 ポイントを並べ替える素朴なアプローチ$x$または$y$同一線上の点が連続して配置されている場合、座標は失敗する可能性があります。 小さな入力$n=3$3 点の順列は自明の候補ですが、角度条件は依然として失敗する可能性があるため、処理する必要があります。 

## アプローチ

 ブルートフォースの解決策は、すべてを生成することです。$n!$点の順列を調べ、それぞれの鋭角特性を確認します。 これは正しいですが、実行不可能です。$5000!$天文学的に大きいです。 各順列チェックには計算が必要です$n-2$ただし、階乗爆発が支配的であるため、次のような角度には使用できません。$n$10か12以上。 

重要な洞察は幾何学から得られます。 任意の3点につき$A$、$B$、$C$、の角度$B$内積の場合は鋭角です$(A-B) \cdot (C-B) > 0$。 この条件が連続するすべてのトリプルに対して当てはまるシーケンスを構築したいと考えています。 貪欲な構築は、開始点を選択し、最後の点を追加して鋭角を保つ次の点を繰り返し選択する場合に機能します。 座標による並べ替えは不要です。 代わりに、現在の端に追加しても最後の 2 点と直角または鈍角を形成しないように、任意の点を繰り返し選択してシーケンスを構築できます。 

慎重に選択すると、縮退の場合を除いて、ほとんどすべてのポイント構成に対して有効なシーケンスを確保できます。 のために$n=3$、3 つのポイントを直接並べ替えることができます。 大型の場合$n$の場合、問題は、次の候補との最後の 2 つの点が鋭角を形成するという不変条件を維持しながら点を挿入することに帰着します。 角度条件に違反しないポイントを常に追加することで、有効な「素晴らしい」ビートマップを貪欲に生成できます。

 ## アルゴリズムのチュートリアル

 1. 入力を読み取り、ポイントとそのインデックスを保存します。 元の入力の順列を出力する必要があるため、インデックスが必要です。 
2. もし$n=3$、6 つの可能な注文をすべて直接確認してください。 中点で鋭角条件を満たす最初の順序を返します。 どれも満たさない場合は、戻ります$-1$。 
3. のために$n>3$、初期シーケンスとして入力の最初のポイントから開始します。 
4. 後続の各ポイントについて、現在のシーケンスの最後に追加してみます。 シーケンス内の最後の 2 点と候補点の間の内積を計算します。 内積が正の場合、点を追加します。 そうでない場合は、前のポイントと位置を交換して、状態が復元できるかどうかを確認してください。 
5. すべての点がシーケンス内に配置されるまで繰り返します。 点は個別であり、平面は連続しているため、この貪欲なアプローチは、順序が鋭角条件を満たすことができない方法で点が同一線上にない限り、常に解を見つけます。これは一般的な入力では非常にまれです。 
6. シーケンスのインデックスを出力します。 

機能する理由: 各ステップで、シーケンスの最後の 2 点と新しく追加された点が常に 90 度未満の角度を形成するという不変条件が維持されます。 角度が鋭角である場合、ドット積は厳密に正になります。 この不変条件を維持するために次のポイントを慎重に選択するため、最終シーケンスは nice-beatmap プロパティを満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dot(a, b, c):
    # vector AB dot vector BC
    return (a[0]-b[0])*(c[0]-b[0]) + (a[1]-b[1])*(c[1]-b[1])

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) + (i+1,) for i in range(n)]
    
    # Start with the first point
    res = [points[0]]
    
    for i in range(1, n):
        res.append(points[i])
        # Maintain acute angles at each step by swapping if needed
        while len(res) >= 3 and dot(res[-3], res[-2], res[-1]) <= 0:
            res[-2], res[-1] = res[-1], res[-2]
    
    # Output permutation of original indices
    print(" ".join(str(p[2]) for p in res))

solve()
```順序を維持します`res`ポイントを 1 つずつ追加します。 の`dot`関数はベクトル間のドット積を計算します`(last2 - last1)`そして`(new - last1)`。 内積が正でない場合は、最後の 2 つの点を交換し、鈍角を解決できます。 この貪欲な修正により、連続するすべてのトリプルが鋭角になることが保証されます。 エッジケースのような$n=3$自然にループによって処理されます。
