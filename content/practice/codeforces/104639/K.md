 ## 解決策
 ## 問題の理解

 平面内の安全な領域を表す凸多角形が与えられます。 エアドロップ クエリごとに、直径の端点によって定義された円も取得します。 各エアドロップは、その円内のどこにでも均一にランダムに着地します。 

クエリごとに、多角形内の 1 つの点を選択する必要があります。 その点は、固定着陸基準として機能します。 選択のコストは、この選択された点と円内の均一にランダムな点の間の二乗ユークリッド距離の期待値です。 タスクは、多角形内の点のすべての選択に対してこの期待値を最小化し、各円の結果の最小値を出力することです。 

多角形は固定されていますが、円はクエリごとに異なります。 この制約では、最大 5000 個の頂点と 5000 個のクエリが許可され、座標は最大 1e9 になります。 

単純な解釈では、各クエリには凸多角形にわたる連続関数の最適化が必要であるということになります。これは、ジオメトリと凸のプロパティが中心となることをすでに示唆しています。 

重要な構造的観察は、期待値は選択した点と円内のランダムな点の間の相対位置のみに依存し、選択した点の実現可能性を除いて多角形の形状には依存しないということです。 

微妙なエッジ ケースは、円の最適な点が多角形の外側にある場合です。 たとえば、ポリゴンが非常に小さく、円が遠くにある場合、最適な非拘束点は円の中心になる可能性がありますが、ポリゴンは境界上に投影を強制します。 これは、単に円の幾何学的特性を計算しているのではなく、凸集合に対する制約付きの最適化を計算していることを意味します。 

## アプローチ

 まずポリゴン制約を無視します。 固定円の場合、点 P を選択し、ランダムな点 X が円盤内に均一に分布しているとします。 目的は、E[|P − X|²] を最小化することです。 

正方形を展開すると、E[|P − X|²] = |P|² − 2P・E[X] + E[|X|²] が得られます。 重要な単純化は、期待値が分布の平均までの距離によってのみ P に依存するということです。 円盤上の均一な分布の場合、平均値はまさに円の中心になります。 したがって、P が円の中心にできるだけ近いときに式は最小化され、最小の非拘束値は中心に等しい P で達成されます。 

したがって、問題は円の中心を凸多角形に投影することに帰着します。 最適な P は、ユークリッド距離で円の中心に最も近い多角形内の点です。 射影点 Q が得られると、答えは E[|Q − X|²] となり、これは |Q − C|² + E[|X − C|²] として展開できます。ここで、C は円の中心です。 

したがって、問題は 2 つの部分に分かれます。円のみに依存する幾何定数項と、円の中心から多角形までの二乗距離です。 

残りのタスクは、クエリ ポイント C ごとに、C から凸多角形までの二乗距離を計算することです。 n が最大 5000、q が最大 5000 の場合、O(nq) 個のポリゴン内ポイントまたはエッジまでの距離のスキャンで十分です。 多角形は凸面であり、頂点が順序付けされているため、外部点に最も近い点は、セグメント内で垂直投影が到達する頂点またはエッジ上にあります。 これは、クエリごとに線形時間でチェックできます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべてのエッジにわたるクエリごとのブルート フォース プロジェクション | O(nq) | O(n) | 承認済み |
 | 凸形状の簡略化を使用した上記と同じ最適 | O(nq) | O(n) | 承認済み |

 制約が十分に小さいため、より高度なデータ構造は必要なく、期待値が正しく書き換えられればジオメトリは簡単になります。 

## アルゴリズムのチュートリアル

1. 各クエリの円の中心と半径の 2 乗を事前計算します。 中心は直径の端点の中点であり、半径の二乗は端点間の距離の二乗の 4 分の 1 です。 これにより、クエリ固有の幾何学的データがすべて分離されます。 
2. 各クエリについて、円の中心から凸多角形までの最小二乗距離を見つける問題として問題を扱います。 これは正当化されます。なぜなら、期待値は円と選択した点から中心までの距離の 2 乗にのみ依存する定数に分解されるからです。 
3. 指定された中心点 C について、すべてのポリゴン エッジを反復処理します。 各エッジ AB について、線 AB への C の投影を計算します。 
4. 投影パラメータがセグメント内にある場合は、C から投影点までの二乗距離を計算します。 それ以外の場合は、A と B の間で最も近い端点までの二乗距離を計算します。これにより、そのエッジ セグメント上の最も近い点までの距離が確実に計算されます。 
5. すべてのエッジと頂点にわたって最小二乗距離を維持します。 これにより、C から凸多角形までの二乗距離が得られます。 
6. 円板内のランダムな点からその中心までの二乗距離の一定の期待値 (R²/2 に等しい) を加算し、合計を出力します。 

ステップ 6 が機能する主な理由は、一様なディスクの場合、2 次元の分散が軸間で均等に分割され、E[|X − C|²] = R²/2 が得られるためです。 

### なぜ効果があるのか

 期待値 E[|P − X|²] は |P − C|² + E[|X − C|²] に分解できます。ここで、C は円の中心です。 2 番目の項は P から独立しているため、期待値を最小化すると、正確には P から C までの二乗距離を最小化することになります。実行可能領域は凸状であるため、最も近い実行可能点は明確に定義され、頂点またはエッジ投影上にあります。 アルゴリズムはそのような候補をすべて列挙するため、真の最近接点が含まれている必要があり、したがってグローバル最小値が達成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def dist2(ax, ay, bx, by):
    dx = ax - bx
    dy = ay - by
    return dx * dx + dy * dy

def clamp01(t):
    if t < 0.0:
        return 0.0
    if t > 1.0:
        return 1.0
    return t

def solve():
    n, q = map(int, input().split())
    poly = [tuple(map(int, input().split())) for _ in range(n)]

    for _ in range(q):
        x1, y1, x2, y2 = map(int, input().split())

        cx = (x1 + x2) / 2.0
        cy = (y1 + y2) / 2.0

        dx = x2 - x1
        dy = y2 - y1
        r2 = (dx * dx + dy * dy) / 4.0

        best = float('inf')

        for i in range(n):
            x3, y3 = poly[i]
            x4, y4 = poly[(i + 1) % n]

            ex = x4 - x3
            ey = y4 - y3

            vx = cx - x3
            vy = cy - y3

            e2 = ex * ex + ey * ey
            t = 0.0
            if e2 != 0:
                t = (vx * ex + vy * ey) / e2
                t = clamp01(t)

            px = x3 + t * ex
            py = y3 + t * ey

            best = min(best, dist2(cx, cy, px, py))

        ans = best + r2 / 2.0
        print(f"{ans:.10f}")

if __name__ == "__main__":
    solve()
```この解決策では、まず各直径を円の中心と半径の二乗に変換します。 中点の公式は期待中心を直接与えますが、半径の計算は純粋に代数的です。 

ポリゴン ループは、投影を使用して各セグメント上の最も近い点を計算します。 クランプステップにより、突起がセグメント内に確実に留まります。 それ以外の場合は、エンドポイントが優勢になります。 これは、セグメントに対する標準のユークリッド投影です。 

最後に、答えは、円の中心から多角形までの二乗距離と固定分散項 R²/2 を組み合わせます。
