 ## 解決策

 ## 問題の理解

 2 つの同時制約の下で、いくつの画面サイズが可能かを調べます。 まず、テレビの幅は制限を超えてはなりません`a`、高さは制限を超えてはなりません`b`。 次に、画面は固定アスペクト比に従う必要があります。`x : y`つまり、すべての有効な画面は、この比率の整数スケーリングでなければなりません。 

したがって、有効な画面には次の形式があります。`(w, h) = (kx, ky)`何らかの正の整数の場合`k`。 タスクは、次の値がいくつあるかを数えることです。`k`両方を保管してください`kx ≤ a`そして`ky ≤ b`。 

したがって、問題は、境界ボックス内に基本長方形の整数倍がいくつ収まるかを見つけることになります。 

制約は 10^18 までであり、考えられるすべての幅または高さでの反復処理が即座に除外されます。 リニアスキャンすら不可能です。 有効な解決策では、問題を一定数の算術演算に減らす必要があります。 

すべてをチェックしようとするのは単純な間違いです`w`まで`a`そして、`w * y % x == 0`、次に計算`h = w * y / x`。 これは遅すぎるため、乗算を慎重に処理しないとオーバーフローの危険性があります。 

もう 1 つの微妙な問題は、整数の除算の切り捨てです。 計算してみると`a // x`または`b // y`派生形式で誤って計算すると、一方の制約が他方よりも厳しい境界ケースを誤って数えてしまう可能性があります。 

最も難しいのは、幅と高さの独立した選択ではなく、有効な倍率をカウントしていることを認識することです。 

## アプローチ

 ブルートフォース解釈では、考えられるすべての整数のペアが試行されます。`(w, h)`そのような`w ≤ a`そして`h ≤ b`、そして、次のことを確認します。`w / h = x / y`。 各ペアについて、交差乗算を使用して比率条件を検証します。`w * y == h * x`。 

このアプローチは正しいですが、非常に高価です。 ペア数は`a × b`、最悪の場合は`10^36`。 概念的な反復さえ不可能です。 

重要な観察は、比率条件により、すべての有効なペアがスケーリングされた長方形の単一の等差数列上に強制的に配置されることです。 修正したら`(x, y)`、すべての有効な画面は倍率によって一意に決定されます。`k`。 したがって、2D グリッドを検索する代わりに、整数の個数を見つけるだけで済みます。`k`両方の境界を満たします。 

から`(kx ≤ a)`私たちは得ます`k ≤ a / x`、そしてから`(ky ≤ b)`私たちは得ます`k ≤ b / y`。 両方が同時に成立する必要があるため、制限要因はこれら 2 つの上限の最小値になります。 

したがって、答えは単純です`min(a // x, b // y)`。

 ## アルゴリズムのチュートリアル

 1. アスペクト比の制約をスケーリング ルールとして解釈します。 有効な画面はすべて次のとおりである必要があります。`(w, h) = (k·x, k·y)`ある整数に対して`k ≥ 1`。 これにより、幅と高さを個別に選択する必要がなくなります。 
2. 幅制約を不等式に変換します。`k`。 以来`kx ≤ a`、私たちは導き出します`k ≤ a // x`。 完全な有効なスケーリングのみをカウントするため、整数の除算は安全です。 
3. 高さの制約を別の不等式に変換します。`k`。 以来`ky ≤ b`、私たちは導き出します`k ≤ b // y`。 
4. 両方の制約を結合します。 同じ`k`両方の上限を満たす必要があるため、有効な最大値は`k`は`min(a // x, b // y)`。 
5. 有効な解を数えます。 すべての整数`k`から`1`この最大値までは有効なペアが 1 つだけ生成されるため、答えはその最大値になります。 

### なぜ効果があるのか

 すべての有効なペアは比率を正確に満たす必要があり、幅と高さの間に比例関係が強制されます。 これにより、検索空間が 2D グリッドから単一のパラメータに折りたたまれます。`k`。 の制約`w`そして`h`独立した上限となる`k`、これらの制約の交差部分は、導出された 2 つの制限の正確な最小値になります。 すべての実行可能な画面が一意の整数に対応するため、有効なペアが失われることはありません`k`、無効なペアは含まれていません。`k`いずれかの境界を超えると、少なくとも 1 つの制約に違反します。

 ## 特殊なケース

 いつ`a < x`または`b < y`の場合、少なくとも 1 つの除算がゼロになるため、数式はすぐにゼロになります。 たとえば、入力`a = 4, b = 100, x = 5, y = 1`与える`4 // 5 = 0`、したがって有効なテレビが存在しません。 アルゴリズムは、特別な条件なしでこれを自然に処理します。
