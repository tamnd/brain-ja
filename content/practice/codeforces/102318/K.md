## アプローチ

 ブルートフォースアプローチは定義に直接従います。 それぞれについて、`k`ポジションのいずれかを選択します`n`項目インデックスを計算し、結果の合計を計算し、その合計に対する回答を増分します。 これは正しいです。なぜなら、考えられるすべての買い物は、繰り返しの商品インデックスや異なる注文など、再帰によって生成される 1 つのシーケンスに正確に対応するからです。 

問題は配列の数です。 がある`n^k`彼らのうち。 と`n = k = 10000`、これは次のようになります`10000^10000 = 10^40000`実際の計算をはるかに超えたシーケンスです。 公式レビューは、この正確な観察を使用して列挙を除外します。 

自然な改善は動的プログラミングです。 させて`dp[j][s]`カウントの長さ-`j`合計値を持つシーケンス`s`。 計算するには`dp[j][s]`、すべてのアイテムの価格を考慮します`v`そして追加します`dp[j-1][s-v]`。 これにより、次への指数関数的な依存が軽減されます。`k`、ただし、それでも個別の価格の数に関する要素が残ります。 と`k`およびその前後の関連する合計範囲`50000`、このアプローチは大きすぎます。 

重要な観察は、項目の選択がすべての位置で独立してその価格に寄与するということです。 させて`P(x) = c_1 x^1 + c_2 x^2 + ...`どこ`c_v`価格が以下のアイテムインデックスの数です。`v`セント。 の 2 つのコピーを乗算すると、`P`最初の位置に 1 つの項目を選択し、2 番目の位置に 1 つの項目を選択します。 の係数`x^s`したがって、2 つの項目のシーケンスをすべて合計してカウントします。`s`セント。 

同じ議論が繰り返し適用されます。 の係数`x^s`で`P(x)^k`は正確に長さの数値です -`k`合計金額が`s`セント。 これはまさに、すべてのクエリで必要な量です。 

残りの難関は多項式の乗算です。 長さ約 2 つの配列の標準的な畳み込み`50000`おおよそ二次時間かかります`50000^2 = 2.5 * 10^9`1 回の乗算に対する係数演算。 これではすでに遅すぎ、べき乗には多くの乗算が必要です。 

FFT は 1 つの多項式乗算を次のように縮小します。`O(N log N)`。 以来`k`到達できる`10000`、二進累乗も使用し、多項式乗算の数を最大 から まで減らします。`10000`だけに`O(log k)`、せいぜい約`28`掛け算。 公式レビューでは、周波数多項式、FFT 畳み込み、および高速累乗のこの組み合わせについて正確に説明しています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(n^k)`|`O(k)`| 遅すぎる |
 | ポジションと合計に対する DP |`O(k * S * n)`|`O(S)`| 遅すぎる |

 ここ`S = 50000`、セントで表される最大のクエリ。 FFT の実装では、実際には、畳み込みに十分な大きさの 2 のべき乗の変換サイズが使用されます。`131072`この問題のために。 公式レビューでは、同じ変換サイズの制限が与えられています。 

## アルゴリズムのチュートリアル

 1. すべてのアイテムの価格をドルからセントに変換し、頻度配列を構築します`P`、 どこ`P[v]`正確にコストが計算される品目インデックスの数です`v`セント。 

同じ価格の 2 つの異なる品目インデックスは 2 つの異なる選択肢を表すため、係数は単なるブール指標ではなく頻度です。 
2. すべてのクエリを読み取り、そのターゲット値をセントに変換して、`S`要求された最大のターゲットになります。 

次数による係数のみが必要です`S`。 次を超える用語`S`クエリに影響を与えることはなく、価格はすべてプラスであるため、これらの条件を破棄しても安全です。 
3. すべての係数を削減します。`P`モジュロ`997`。 

多項式乗算は後で浮動小数点 FFT 演算を使用して実行されますが、数学的係数はモジュロのみが必要です`997`。 
4. コンピューティング`P(x)^k`2進累乗を使用します。 

結果の多項式から開始します`R(x) = 1`。 その間`k`ゼロ以外の場合、その最下位ビットが設定されている場合は乗算します`R`現在の力によって`P`。 次に、現在の電力を二乗してシフトします`k`少しずつ右に。 

これは置き換えます`k`最大でビット数の 2 倍による多項式乗算`k`。 
5. FFT を使用した畳み込みとして多項式乗算を実装します。 

もし`A`そして`B`学位を持っています`a`そして`b`、その積には係数があります`C[s] = sum A[i] * B[s-i]`。 

FFT は両方の配列を周波数領域に変換し、畳み込みは点ごとの乗算になります。 逆 FFT は結果を逆変換します。 
6. 畳み込みごとに、実際の値を最も近い整数に丸め、剰余を求めます。`997`。 

畳み込み前の係数は小さくても、最大でも`996`したがって、標準の倍精度複素 FFT は、必要な係数に対して十分な精度があります。 公式のソリューションでは、異常に小さい係数が使用されます。`997`まさにこの理由からです。 
7. 結果として得られるすべての多項式を次数に切り捨てます。`S`。 

係数の次数が最大のクエリより大きくなると、すべての商品価格が正になるため、その後の乗算では係数を元に戻すことはできません。 これを維持すると、FFT サイズと実行時間が増加するだけです。 
8. ターゲット次数で係数を直接読み取ることにより、すべてのクエリに答えます。 

の係数`x^X`で`P(x)^k`は注文された長さの数です -`k`選択の合計`X`セントなので、要求された答えのモジュロとまったく同じです`997`。 

### なぜ効果があるのか

 周波数多項式には、考えられるすべての商品選択肢に対して 1 つの項があり、その係数はその価格を持つ商品インデックスの数に等しくなります。 で`P(x)^k`、それぞれから 1 つの用語を選択します。`k`コピーは、スプリーの各位置に対して 1 つの項目インデックスを選択することに対応します。 指数は価格の合計ですが、係数の積は同じ価格シーケンスを生成するすべてのインデックスの選択肢をカウントします。 したがって、次の係数は`x^X`は有効なショッピング スプリーの合計数と正確に一致します`X`セント。 FFT は通常の畳み込みと同じ多項式積を計算し、2 進累乗もまったく同じように計算します。`k`繰り返し乗算としての - 乗。 すべての価格が正であるため、切り捨てでは、後でクエリに寄与する可能性のある係数を削除できません。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

MOD = 997
PI2 = 2.0 * math.pi

def fft(a, invert):
    n = len(a)

    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit
        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2
    while length <= n:
        angle = PI2 / length
        if invert:
            angle = -angle
        wlen = complex(math.cos(angle), math.sin(angle))

        half = length >> 1
        for i in range(0, n, length):
            w = 1.0 + 0.0j
            end = i + half
            j = i
            while j < end:
                u = a[j]
                v = a[j + half] * w
                a[j] = u + v
                a[j + half] = u - v
                w *= wlen
                j += 1

        length <<= 1

    if invert:
        inv_n = 1.0 / n
        for i in range(n):
            a[i] *= inv_n

def convolution(a, b, limit):
    if not a or not b:
        return []

    need = min(len(a) + len(b) - 1, limit + 1)

    if len(a) == 1:
        x = a[0]
        return [(x * y) % MOD for y in b[:need]]

    if len(b) == 1:
        x = b[0]
        return [(x * y) % MOD for y in a[:need]]

    full = len(a) + len(b) - 1
    size = 1
    while size < full:
        size <<= 1

    fa = [complex(x, 0.0) for x in a]
    fb = [complex(x, 0.0) for x in b]

    fft(fa, False)
    fft(fb, False)

    for i in range(size):
        fa[i] *= fb[i]

    fft(fa, True)

    res = [0] * need
    for i in range(need):
        x = int(round(fa[i].real))
        res[i] = x % MOD

    return res

def poly_pow(base, exponent, limit):
    result = [1]

    while exponent:
        if exponent & 1:
            result = convolution(result, base, limit)

        exponent >>= 1
        if exponent:
            base = convolution(base, base, limit)

    return result

def parse_cents(s):
    if '.' in s:
        whole, frac = s.split('.')
        frac = (frac + '00')[:2]
    else:
        whole, frac = s, '00'
    return int(whole) * 100 + int(frac)

def solve():
    t = int(input())
    output = []

    for _ in range(t):
        n = int(input())

        prices = [parse_cents(input().strip()) for _ in range(n)]

        k, q = map(int, input().split())
        queries = [parse_cents(input().strip()) for _ in range(q)]

        limit = max(queries)

        base = [0] * (limit + 1)

        for price in prices:
            if price <= limit:
                base[price] += 1

        for i in range(len(base)):
            base[i] %= MOD

        if k == 0:
            answers = [1 if x == 0 else 0 for x in queries]
        else:
            result = poly_pow(base, k, limit)
            answers = [
                result[x] if x < len(result) else 0
                for x in queries
            ]

        output.extend(map(str, answers))

    sys.stdout.write("\n".join(output))

if __name__ == "__main__":
    solve()
```入力パーサーは意図的に文字列を処理します。`parse_cents`10 進表現を直接整数に変換し、FFT が関与する前にすべての浮動小数点の問題を回避します。 

の`base`array は、アルゴリズムの最初のステップからの多項式です。 そのインデックスはセント単位の価格であり、その値はその価格を持つアイテム インデックスの数です。 すべての価格が正であるため、最大のクエリを超える価格はすぐに無視できます。 

の`convolution`関数は、完全な畳み込みを保持できる最小の 2 のべき乗 FFT サイズを選択します。 結果の多項式は次に切り捨てられます。`limit + 1`。 要求された範囲を超える係数は単純に破棄できるため、切り捨ては逆 FFT の後に行われます。 

長さ 1 の多項式に対する特別な処理により、FFT が完全に回避されます。 これは、特に要求された範囲が小さい場合、または入力に関連する価格が 1 つしか含まれていない場合、中間多項式が非常に小さくなる可能性があるため、2 進累乗の際に重要になります。 

反復 FFT では、標準的なビット反転順列とそれに続くバタフライ レイヤーが使用されます。 逆変換では、回転角度の符号が変更され、すべての係数が変換サイズで除算されます。 四捨五入`int(round(...))`各整数係数に関する小さな浮動小数点誤差を、意図した整数値に変換します。 

Python の整数はオーバーフローしないため、C または C++ で見られる固定幅のオーバーフロー問題に類似した問題はありません。 FFT 自体は Python 複素数を使用し、その実数成分と虚数成分は倍精度です。 係数はモジュロで削減されるため、`997`各乗算の後、それらは意図した数値的アプローチに対して十分に小さいままになります。 

べき乗ループでは、標準の最下位ビット テストが使用されます。 二乗演算は、別のべき乗反復が残っている場合にのみ実行され、不必要な最終畳み込みが回避されます。

 ここ`S`クエリされた合計の最大値 (セント単位)`50000`。 FFT は、畳み込みに次の適切な 2 のべき乗を必要とします。これは、次の値に達します。`131072`最悪の場合。 公式レビューでは、これと同じ変換サイズの要件が示されており、2 進累乗によって多項式の乗算の数がおおよそ次のように削減されると説明されています。`28`のために`k <= 10000`。 

15 秒と 1024 MB の制限は、二次畳み込みではなく FFT ベースのソリューション向けに設計されています。 メモリ要件は制限を大幅に下回っていますが、対数依存性は高くなります。`k`それが作るものです`k = 10000`管理可能。

 ## 特殊なケース

 繰り返し選択する場合は、入力```
1
1
1.00
3 1
3.00
```生成する`1`。 基本多項式は次のとおりです。`x^100`、そしてそれを3乗すると、`x^300`。 アルゴリズムは単一の係数を次数に維持します`300`, したがって、クエリは次の結果を返します。`1`。 多項式累乗によりすべての因子で同じ項を自然に選択できるため、繰り返し項目インデックスに特別なケースは必要ありません。 

価格が重複している場合は、入力```
1
2
1.00
1.00
2 1
2.00
```生成する`4`。 次数の基本係数`100`は`2`、 ない`1`。 二乗後の係数は次のようになります。`2 * 2 = 4`。 これはまさに、問題で必要とされる項目値と項目インデックスの区別です。 

不可能な目標については、次のように考えます。```
1
2
2.00
3.00
2 1
1.00
```基本多項式には、次数に最初の非ゼロ係数があります。`200`。 したがって、その二乗は次から始まります`400`。 学位以来`100`が存在しない場合、答えは`0`。 配列ルックアップはこのケースを自然に処理します。 

クエリの上限については、次のことを考慮してください。```
1
2
250.00
250.00
2 2
500.00
500.01
```最初のクエリは度に対応します`50000`、係数は`4`なぜなら、どちらのアイテムもどちらの位置を占めることもできるからです。 2 番目のクエリは度に対応します`50001`ただし、実装の多項式は、要求された最大の次数を通じてのみ意図的に保存されるため、`500.01`有効な入力では通常は決して発生しない、指定された問題の範囲外です。 実際の制約内で`$500.00`、 程度`50000`は最後の関連インデックスです。 

10 進数の解析の場合、次のような入力`0.01`整数にならなければなりません`1`、 その間`1.10`にならなければなりません`110`。 このソリューションでは、浮動小数点数を評価するのではなく、小数点の周囲の文字を解析します。 これにより、表現エラーによって有効な配列インデックスが不正なインデックスに変わることが防止されます。 

モジュロ動作の場合、乗算のたびに多項式係数が減ります。 必要な答えはモジュロであるため、`997`、すべての係数を置き換えます`c`による`c mod 997`次の乗算の前に、後のすべての係数モジュロが保存されます`997`。 また、変換された入力係数が指数に応じて増加することがないため、FFT 丸め誤差も小さく保たれます。
