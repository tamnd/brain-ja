 ## 解決策
 ## 問題の理解

 原点を中心にダーツボードを設置しています。 ボードは放射状に分割されており、`w`均等なウェッジであり、3 つの同心円状のスコアリング領域があります。 半径の最も内側の円`b`は的であり、常に 50 ポイントを与えます。 半径間`b`そして`d`は、ウェッジの値を 2 倍した倍精度領域です。半径の間`d`そして`s`は単一の領域であり、ウェッジの通常の値が使用されます。 ダーツの半径の外側`s`スコアは0です。 

正の X 軸からすぐ反時計回りにあるウェッジの値は 1 です。ウェッジを反時計回りに移動すると値が 1 ずつ増加するため、正の X 軸からすぐに時計回りにウェッジの値が決まります。`w`。 すべてのテストケースについて、ボードの寸法とそれに続くすべてのダーツの座標が与えられ、それらのスコアの合計が必要になります。 元のコンテストの声明では次のようになります。`2 <= w <= 20`、`0 < b < d < s < 100`、テスト ケースごとに最大 100 個のダーツ。 ダーツの座標は次の間にあります。`-100`そして`100`、中にダーツはありません`10^-5`ウェッジ境界または円形境界の。 

これらの境界により、問題は多くの幾何学問題よりもはるかに単純になります。 たとえ`O(tw)`ソリューションのパフォーマンスは最大でも`100 * 20 = 2000`ウェッジ チェックは 1 つのテスト ケースで実行されるため、単純なソリューションでもすでに十分に高速です。 それでも、各ダーツを次のように処理できます。`O(1)`角度を直接くさび数に変換すると、次のようになります。`O(t)`時間。 

最も関連性の高いエッジ ケースは、大きな入力サイズではなく、ジオメトリによって引き起こされます。 たとえば、ちょうど中心にあるダーツ```
1
2 1 2 3
1
0.000 0.000
```スコアは 0 やウェッジ値ではなく、50 です。 最初に角度を計算し、中心を通常のウェッジとして扱うソリューションでも値が生成される可能性はありますが、ブルズアイは角度のスコアリングよりも優先されるため、その値は無意味です。 

ボードの外側のダーツは、たとえその角度が高価値のウェッジを向いていたとしても、スコアはゼロでなければなりません。 例えば、```
1
2 1 2 3
1
0.000 4.000
```原点からの距離が外側の半径より大きいため、スコアは 0 になります。 

ダブルリング内のダーツはウェッジ値の 2 倍を使用する必要があります。 と```
1
2 1 5 8
1
0.000 3.000
```ダーツは二重リング内にあり、値が 1 である上部ウェッジにあります。したがって、正しい出力は次のようになります。`2`。 乗数を忘れると、`1`。 

マイナスアングルの場合も扱いを間違えやすいです。 と```
1
4 1 5 8
1
1.000 -1.000
```角度は`-45`度。 これは最初のウェッジではなく 4 番目のウェッジに属するため、ダーツは 4 番目のウェッジの値を取得します。 単純に負の角度をウェッジの幅で割る不注意な実装では、負のインデックスが取得されます。 

アーカイブされた 2017 年の声明の最初のサンプルにも歴史的な矛盾があります。 それは与える`4 7 13 10`述べられた関係にもかかわらず、`b < d < s`。 期待される答えは扱います`13`は double 領域の外側の境界であるため、以下の実装は記述どおりに変数に従い、元のサンプル出力を再現します。 後のサンプルと採点ルールはこの解釈と一致しています。 

## アプローチ

 最も直接的なアプローチは、すべてのダーツを個別に処理することです。 まず原点からの二乗距離を計算します。 その値が以下の場合`b²`それ以外の場合は、どのウェッジにダーツが含まれているかを判断し、半径領域に応じてそのウェッジの値に 2、1、または 0 を掛けます。 

ブルートフォース実装の場合、ダーツの角度がわかったら、その角度をすべてのダーツに対してテストできます。`w`一致するウェッジが見つかるまでウェッジ間隔を続けます。 くさびが完全な円を分割しているため、これは正しいです。 最大で 20 個のウェッジと 100 個のダーツがあるため、最悪のケースでは、テスト ケースごとにちょうど 2000 個のウェッジ チェックが行われることになります。 これは 1 秒の制限を脅かすほど十分な作業ではないため、このバージョンはすでに受け入れられています。 

より明確な観察は、ウェッジが同じサイズであるということです。 それらを検索する必要はまったくありません。 1回転で角度がつきます`2π`、したがって、各ウェッジは次の角度を占めます。`2π / w`。 

ダーツの角度が正規化されている場合`θ`で`[0, 2π)`、そのゼロベースのウェッジインデックスは単純に次のようになります。`floor(θ / (2π / w))`。 

1 を追加すると、そのインデックスが 1 から 1 までのダーツボードのスコアに変換されます。`w`。 これにより、角度の仕事が軽減されます。`O(w)`に`O(1)`。 

すべてのダーツを個別に分類できるため、総当たり法は機能しますが、直接計算できるウェッジを探すために不必要な作業が費やされます。 等しい角幅はまさに直接式を可能にするものです。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースは 1 つの独立したダーツボードとそのスローを記述しているため、各ケースの開始時に合計スコアを 0 にリセットできます。 
2.読む`w`、`b`、`d`、 そして`s`、番号を読み取ってください。`t`ダーツの。 半径の二乗を次のように保存します`b²`、`d²`、 そして`s²`。 二乗距離を比較すると、不必要な平方根が回避され、放射状領域の正確な順序が維持されます。 
3. ダーツごとに`(x, y)`、計算する`r² = x² + y²`。 もし`r² < b²`、すぐに50ポイントを追加します。 ブルズアイのスコアは固定されているため、角度は関係ありません。 
4. ダーツがブルズアイ内にない場合は、次のコマンドを使用してダーツの角度位置を決定します。`atan2(y, x)`。 この関数は、4 つの象限すべてで正しい角度を提供します。`atan(y / x)`、象限情報が失われます。 
5. 角度が負の場合は、`2π`それがそこにあるように`[0, 2π)`。 これにより、円座標が、等しいウェッジ幅に分割できる通常の非負の区間に変わります。 
6. コンピューティング`wedge = int(angle / (2π / w)) + 1`。 この除算は、ダーツの角度の前に完全なウェッジ間隔が何回発生するかを決定します。`+1`ゼロから始まるインデックスをボードのスコア番号に変換します。 
7. 半径位置から乗数を決定します。 ダーツ`r² < d²`は double 領域にあり、乗数 2 を取得します。`r² < s²`単一領域にあり、乗数 1 を取得します。`s`乗数 0 を取得します。 
8.追加`wedge * multiplier`テスト ケースの合計を計算し、すべてのダーツが処理された後に合計を出力します。 

### なぜ効果があるのか

 すべてのダーツについて、二乗距離が一意にどの同心円状のスコアリング領域に含まれるかを決定します。`atan2`方向を一意に決定します。 すべてのウェッジの角度幅は同じであるため、正規化された角度を次の値で割ります。`2π/w`ダーツを含むウェッジのインデックスを正確に返します。 次に、放射乗数によってその領域のスコアリング ルールが適用されます。 唯一の特殊なケースはブルズアイで、その固定スコアがウェッジ スコアをオーバーライドするため、最初にチェックされます。 この問題により、ダーツが境界近くに存在しないことが保証されるため、浮動小数点の丸めでは隣接する領域間で有効なダーツの切り替えを行うことができません。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    tc = int(input())
    out = []

    for _ in range(tc):
        w, b, d, s = map(int, input().split())
        t = int(input())

        b2 = b * b
        d2 = d * d
        s2 = s * s

        wedge_angle = 2.0 * math.pi / w
        total = 0

        for _ in range(t):
            x, y = map(float, input().split())
            r2 = x * x + y * y

            if r2 < b2:
                total += 50
                continue

            angle = math.atan2(y, x)
            if angle < 0:
                angle += 2.0 * math.pi

            wedge = int(angle / wedge_angle) + 1

            if r2 < d2:
                total += 2 * wedge
            elif r2 < s2:
                total += wedge

        out.append(str(total))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```ボードはダーツ間で変化しないため、最初の 3 つの二乗半径変数はテスト ケースごとに 1 回計算されます。 比較する`r2`これらの値を使用すると、`sqrt`したがって、すべての放射分類では算術比較のみが使用されます。 

ブルズアイ チェックは角度の計算の前に行われます。 わずかに安いことに加えて、これはスコアの階層を直接反映しています。ブルズアイ内のダーツは、方向に関係なく常に 50 のスコアを獲得します。`atan2(y, x)`の代わりに使用されます`atan(y / x)`なぜなら`atan`たとえば区別できない`(1, -1)`から`(-1, 1)`。`atan2`完全な円を正しく処理します。 否定的な結果は次のようにシフトされます。`2π`、範囲内の角度を生成します`[0, 2π)`。 

表現`int(angle / wedge_angle) + 1`重要な幾何学的計算です。 ダーツがウェッジの境界に近づかないことが保証されているため、イプシロンの調整は必要ありません。 同じ境界保証により、厳密な境界を使用できます。`<`半径の比較。 

Python の整数には任意の精度があるため、整数のオーバーフローの心配はありません。 浮動小数点値は座標と角度にのみ使用され、最終スコアはすべて整数のままです。
