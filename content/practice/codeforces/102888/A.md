 ## 解決策
 ## 問題の理解

 三角形は常に直角をもつ直角三角形です。$(x_0, y_0)$。 他の 2 つの頂点は次のとおりです。$(x_0 + a, y_0)$そして$(x_0, y_0 + b)$。 垂直線を選択する必要があります$x = c$、 どこ$x_0 \le c \le x_0 + a$、線の左側の三角形の部分と右側の部分の面積がまったく同じになるようにします。 

入力により、三角形の位置とその寸法が与えられます。 出力は単一の浮動小数点値です$c$。 必要な浮動小数点許容誤差内の任意の回答が受け入れられます。 

境界は非常に小さいです。 すべての座標の大きさは最大 1000、両辺の長さは最大 1000 です。三角形は 1 つしかないため、反復数値法でも問題なく制限内に収まります。 それでも、ジオメトリには閉形式の解があるため、問題は反復なしで一定時間で解くことができます。 

主な問題は、左側の領域が切断位置に応じて直線的に成長しないことです。 底辺に沿った中間点も面積を半分にするという仮定は正しくありません。 

インプットを考慮する```
0 0 1 1
```正解はおよそ```
0.292893218...
```切断位置$x = 0.5$右に行くほど三角形が短くなるので、左側に大きな領域が残ります。 

もう 1 つの簡単な間違いは、三角形が原点から始まらない可能性があることを忘れることです。 

例えば、```
100 200 4 5
```答えは間隔から直接計算されません。$[0,4]$。 ローカル座標で解決した後、次の値を追加して結果を元に戻す必要があります。$x_0$。 

3 番目のよくあるエラーは、整数演算を使用していることです。 

例えば、```
0 0 3 2
```答えは不合理です。 整数の除算や途中で切り捨てを行うと、明らかに不正確なカット位置が生成されます。 

## アプローチ

 直接的な数値的アプローチは、切断位置を二分探索することです。 どの候補者にとっても$c$、左側の面積を計算し、それを合計面積の半分と比較し、検索間隔を調整します。 カットが右に進むにつれて左側の領域が連続的に増加するため、二分探索は正しいです。 約 60 回の反復により、必要な精度をはるかに上回る精度がすでに得られているため、このアプローチは一定時間で実行されます。 

興味深いのは、面積の公式を導き出すことです。 させて$$t = c - x_0,$$となることによって$t$三角形の左側からの水平距離を測定します。 

斜辺が結合します$(0,b)$そして$(a,0)$ローカル座標では、その方程式は次のようになります。$$y = b\left(1-\frac{x}{a}\right).$$三角形の左側の部分$x=t$平行な辺に高さがある台形です$$b,\qquad b\left(1-\frac{t}{a}\right).$$そのエリアは$$S_{\text{left}}
=
\frac{
b+b\left(1-\frac{t}{a}\right)
}{2}
\cdot t
=
bt-\frac{bt^2}{2a}.$$三角形の面積の合計は、$$\frac{ab}{2},$$したがって、左側の領域を合計領域の半分に設定すると、次のようになります。$$bt-\frac{bt^2}{2a}
=
\frac{ab}{4}.$$で割る$b$そして並べ替えると、$$2t-\frac{t^2}{a}
=
\frac{a}{2},$$または$$t^2-2at+\frac{a^2}{2}=0.$$間隔内の有効なルート$[0,a]$は$$t=a\left(1-\frac{1}{\sqrt2}\right).$$ついに、$$c=x_0+t.$$これにより、すぐに答えが得られます。

 ## アルゴリズムのチュートリアル

 1.読む$x_0$、$y_0$、$a$、 そして$b$。 のみ$x_0$そして$a$すべての垂直断面は次のように比例するため、答えに影響を与えます。$b$。 
2. 水平オフセットを計算します。$$t=a\left(1-\frac{1}{\sqrt2}\right).$$これは、左側の領域が合計領域のちょうど半分になる二次方程式を解くことによって得られます。 
3. コンピューティング$$c=x_0+t.$$これにより、ローカル座標が元の座標系に変換されます。 
4. 結果を浮動小数点数として出力します。 

### なぜ効果があるのか

 三角形の高さは左から右に直線的に減少するため、累積面積は 2 次式である一次関数の積分になります。 総面積のちょうど半分についてその二次方程式を解くと、区間内で一意の解が得られます。$[0,a]$。 すべての導出は正確であるため、計算された値は常に三角形を 2 つの等面積領域に分割します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

x0, y0, a, b = map(int, input().split())

c = x0 + a * (1.0 - 1.0 / math.sqrt(2.0))

print(c)
```プログラムは最初に 4 つの整数を読み取ります。 入力には座標と両側の長さの両方が含まれますが、最終的な式には水平位置と水平長のみが表示されます。 

計算には、面積方程式から導出された閉形式の式が使用されます。 使用する`math.sqrt`計算を浮動小数点で維持するため、必要な誤差許容度を容易に満たすことができます。 

最後に、プログラムは答えを直接出力します。 Python のデフォルトの浮動小数点出力はすでに十分な精度を備えているため、特別な書式設定は必要ありません。

## テストケース```python
# helper: run solution on input string, return output string
import io
import math
import sys

def solve():
    input = sys.stdin.readline
    x0, y0, a, b = map(int, input().split())
    print(x0 + a * (1 - 1 / math.sqrt(2)))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    sys.stdout = out
    solve()
    sys.stdin = backup_stdin
    sys.stdout = backup_stdout
    return out.getvalue().strip()

def check(inp, expected):
    ans = float(run(inp))
    assert abs(ans - expected) <= 1e-6

# provided samples
check("0 0 1 1\n", 0.2928932188134524)
check("347 -685 868 194\n", 601.2313139300767)
check("-110 -319 376 122\n", 0.12785027385811532)

# custom cases
check("0 0 1000 1000\n", 292.89321881345245)
check("100 200 4 5\n", 101.17157287525382)
check("-1000 0 1 7\n", -999.7071067811865)
check("0 500 10 1\n", 2.9289321881345245)
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

```ローカルな解決策は、$$4\left(1-\frac1{\sqrt2}\right)\approx1.171572875.$$水平オフセットを追加すると、```
101.171572875...
```変換は最後の追加にのみ影響し、ジオメトリは変更されません。 

最後に、不合理な答えが得られるケースを考えてみましょう。```

```アルゴリズムは計算します$$3\left(1-\frac1{\sqrt2}\right)\approx0.878679656.$$浮動小数点演算を使用すると必要な精度が維持されますが、整数演算では結果が誤って丸められ、判定に失敗します。
