 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースには n 個の実数があり、それぞれが数直線上の点を表します。 これらの点から、正確に k 個の互いに素な点のペアを選択する必要があります。これは、各点が最大 1 つの選択されたペアで使用できることを意味します。 すべてのペアは、2 つのエンドポイントの差の絶対値に等しい値を与えます。目標は、k 個のペアすべての可能な最小の総和と最大の可能な合計という 2 つの極値を決定することです。 

この構造は本質的に、線上の一連の点に対してサイズ k のマッチングを構築し、その制約の下でエッジの長さの合計を最適化することを求めています。 

制約は非常に直接的な意味で重要です。 すべてのテスト ケースにわたるポイントの合計数は最大 10^6 であるため、全体でおよそ O(n log n) よりも悪い解は存続できません。 これにより、すべてのペアの組み合わせを考慮しようとするものや、n での動的計画法を使用するものは直ちに除外されます。 また、直線上の距離は点を順序付けした後でのみ意味を持つようになるため、この問題はソートを中心に明確に構成されています。 

ポイントが密集している場合、または繰り返されている場合、微妙なエッジ状態が現れます。 複数の点が同じ座標を共有する場合、長さゼロのエッジが可能になるため、正しく処理する必要があります。 もう 1 つの自明ではない状況は、k が n/2 に近い場合 (本質的にほぼすべての点が使用される場合) と、k が小さい場合 (少数のペアのみが選択される場合) に発生します。 戦略は両極端でも一貫して動作する必要があります。 

単純なアプローチでは、k ペアの可能な一致をすべて列挙し、それらの合計を計算し、最小値と最大値を追跡します。 貪欲にマッチングを生成しようとしても、k 個の素なペアを選択する方法の数は組み合わせ的に増加するため、n が 30 程度であってもすぐに実行できなくなります。 

## アプローチ

 ブルートフォースの見方は、n 個の点から k 個の互いに素なペアを選択するあらゆる可能な方法を考えることです。 2k 点のすべてのサブセットを生成し、それらをあらゆる方法でペアにすることを想像することもできます。 これは原理的には正しいです。すべての有効な解は、2k 点のサブセットとその内部の完全な一致に対応するからです。 問題は、サブセットを選択すること自体がすでに行われていることです。\(\binom{n}{2k}\)、その中の一致の数は階乗的に増加します。 これは、実行可能な計算をはるかに超えて爆発します。 

重要な構造観察は、点が直線上に存在していることです。 それらを並べ替えると、距離はインデックスの分離に関して単調に動作します。 これにより、強力な単純化が可能になります。最適なソリューションでは、複雑な方法で交差するインデックス間の任意のペアを作成する必要がありません。 代わりに、注文とローカル交換の観点から推論することができます。 

最大の合計を得るために、目標は距離を最大化することであり、これにより遠く離れた点をペアにする方向に進みます。 分類後の最善の戦略は、極端なものに集中することです。 2,000 点のセットを選択した場合、そのセット内の最適な組み合わせは、最小値と最大値、2 番目に小さい値と 2 番目に大きい値などを一致させることです。 この構造は、配列から k 個の最小点と k 個の最大点を取得し、それらをペアにすることによって全体最適が達成されることを意味します。 

最小の合計を得るには、逆の動作、つまりポイントをできるだけ近くにペアにすることが必要です。 非隣接ペアリングは端点を内側に交換することで改善できるため、ソート後の自然な候補は隣接する要素になります。 これにより、エッジが連続する点の間にのみ存在し、各エッジが隣接する差分に等しい重みを持つパスから k 個の互いに素なエッジを選択するという問題が軽減されます。 

これは、パス グラフ上のサイズ k の最小重みマッチングになります。 貪欲な戦略が機能します。つまり、利用可能な最小の隣接ギャップを繰り返し選択し、そのペアを取得し、両方のエンドポイントを今後の検討から除外します。 このプロセスは、k 個のペアが形成されるまで続きます。

 ## アルゴリズムのチュートリアル

 まず、すべてのポイントを降順ではない順に並べ替えます。 最適なペアリングに関するすべての推論は、ライン上の近接性を表すソート順の隣接性に依存するため、ソートは不可欠です。 

次に、すべての隣接する差分を計算します。 それぞれの違いは、ローカル ペアリングを使用することを決定した場合に、2 つの隣接するポイントをペアリングするコストを表します。 

第三に、最大の答えを得るために、ソートされた配列の外側の構造のみに焦点を当てます。 k 個の最小要素と k 個の最大要素を取得します。 最小のものと最大のもの、2 番目に小さいものと 2 番目に大きいものなどを組み合わせます。 貢献度の合計は、これらの k 個の差異の合計として累積されます。 

第 4 に、最小の答えを得るために、隣接する各ペアをパス内の候補エッジとして扱います。 利用可能な最小のエッジを繰り返し選択できる構造を維持します。 i と i+1 の間のエッジが選択されると、重複するペアが形成されないように、両方のインデックスが使用不可としてマークされます。 

第 5 に、k 個のエッジを選択するまでこの選択プロセスを繰り返します。 選択された各エッジは、対応する隣接する差分を合計に寄与します。 

最終出力は、累積された最小値と最大値の合計です。 

これが機能する理由は、双方向での引数の交換に基づいています。 最大限の効果を得るには、内部構造を使用するペアリングは、エンドポイントを外側に交換することで改善でき、総距離が長くなります。 これにより、すべての質量が極端なペアに向かって押し上げられます。 最小限の場合、非隣接ペアリングは、エンドポイントが隣接するまで内側に縮小することで局所的に改善できます。また、隣接する選択肢の間で、最初に小さいギャップを選択することは、使用されているポイントの削除によって競合が処理されるため、実現可能性を損なうことはありません。 

## Python ソリューション```python
import sys
import heapq

input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        # maximum: pair k smallest with k largest
        max_ans = 0
        for i in range(k):
            max_ans += a[n - 1 - i] - a[i]

        # minimum: greedy on adjacent gaps
        if k == 0:
            min_ans = 0
        else:
            used = [False] * (n - 1)
            heap = []
            for i in range(n - 1):
                heapq.heappush(heap, (a[i + 1] - a[i], i))

            taken = 0
            min_ans = 0

            while heap and taken < k:
                w, i = heapq.heappop(heap)
                if used[i]:
                    continue
                if used[i + 1]:
                    continue

                used[i] = used[i + 1] = True
                min_ans += w
                taken += 1

        print(f"Case #{tc}: {min_ans} {max_ans}")

if __name__ == "__main__":
    solve()
```コードの最大部分は、並べ替え後の極端なペア引数を直接実装します。 屈折率の対称性により、選択された各ペアが独立していることが保証され、両端間の距離が正確に決まります。 

最小部分はすべての隣接する差分を構築し、ヒープを使用して常に最小の残りの候補を選択します。 の`used`配列は、ポイントが消費されると、それに関係するすべてのエッジが暗黙的に無効になることを保証します。 これが、スキップされたヒープ エントリがポップされたときに単純に無視される理由です。 

ここでよくある間違いは、素性を強制せずに k 個の最小ギャップを選択しようとすることです。 2 つの小さなギャップが 1 つの点を共有する場合、両方を同時に選択することはできないため、これは失敗します。 

## 実用的な例

 インプットを考慮する`a = [1, 3, 4]`、`k = 1`。 

最大の場合、ソートすると同じ配列が得られます。 1 と 4 をペアにして、距離 3 を与えます。最小値の場合、最小の隣接ギャップは 3 と 4 (1) の間にあるため、そのペアを選択します。 

| ステップ | ヒープ/ペアの選択 | 中古 | 現在の合計 |
 |---|---|---|---|
 | 1 | (3,4) | {3,4} | 1 |

 これは、貪欲な最小戦略がローカルの近さを優先していることを示しています。 

ここで考えてみましょう`a = [2, 1, 4, 3]`、`k = 2`、これは次のように並べ替えられます`[1,2,3,4]`。 

最大値を得るには、(1,4) と (2,3) をペアにして、3 + 1 = 4 を与えます。 

最小の場合、隣接するギャップは 1,1,1 になります。 ヒープは、最初に任意の 1 を選択します (たとえば (1,2)、次に (3,4))。 

| ステップ | 選択されたエッジ | 中古 | 合計 |
 |---|---|---|---|
 | 1 | (1,2) | {1,2} | 1 |
 | 2 | (3,4) | {3,4} | 2 |

 これは、ローカルの貪欲な選択によって有効な素のペアが生成されることを確認します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from math import isclose

    input = sys.stdin.readline

    T = int(input())
    out = []
    for tc in range(1, T + 1):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        a.sort()

        max_ans = sum(a[n-1-i] - a[i] for i in range(k))

        if k == 0:
            min_ans = 0
        else:
            import heapq
            used = [False] * (n - 1)
            heap = [(a[i+1] - a[i], i) for i in range(n - 1)]
            heapq.heapify(heap)

            min_ans = 0
            while heap and taken < k:
                w, i = heapq.heappop(heap)
                if used[i] or used[i+1]:
                    continue
                used[i] = used[i+1] = True
                min_ans += w
                taken += 1

        out.append(f"Case #{tc}: {min_ans} {max_ans}")

    return "\n".join(out)

 ## 特殊なケース

 等点の場合、次のようになります。`a = [5, 5, 5, 5]`と`k = 2`、隣接するギャップはすべてゼロです。 ヒープベースの最小戦略では、重みゼロのエッジが繰り返し選択されますが、すべてのエッジのコストが同一であるため、有効な素の選択では合計がゼロになります。 最大値も極値をペアにしますが、それでもゼロが生成されるため、両方の出力は自然に一致します。 

次のような密集した点の場合`[1,2,3,4,100]`と`k = 2`、最大解では、極端のペア化が強制され、(1,100) に加えて残りの点間で別の極値ペアのような大きな寄与が生成されます。 代わりに、最小解は (1,2) と (3,4) を消費し、外れ値 100 を未使用のままにし、合計の膨張を正しく回避します。 

等間隔のシーケンスなど、n が大きく k が小さい場合、アルゴリズムは最小部分に対して k 回の選択を実行し、最大部分に対して k 回の直接計算のみを実行するため、ランタイムは安定しており、不必要な構造から独立しています。
