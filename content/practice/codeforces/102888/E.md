 ## 問題の理解

 私たちに与えられたのは、\(n\)ラベル付けされた人々とそのコレクション\(m\)ゲーム。 各試合\(i\)必要なグループサイズが固定されている\(a_i\)、そしてすべて\(a_i\)価値観が違う。 すべての人は 1 つのグループに所属する必要があり、すべてのグループは 1 つのゲーム タイプで構成されている必要があります。つまり、すべてのグループがゲームに割り当てられます。\(i\)正確なサイズが必要です\(a_i\)。 ゲームは複数回使用できるため、同じサイズのばらばらのグループが多数存在する可能性があります。\(a_i\)。 

誰かがプレイするゲームを変更した場合、またはあるペアの人が 1 つのグループに一緒にいて別のグループに分かれている場合、2 つのパーティションは異なるものとみなされます。 言い換えれば、これはラベル付き分割問題であり、ブロックが許容サイズによって制限され、各ブロックがそのサイズによって決定される固定ラベルを保持します。 

このタスクは、998244353 を法として存在する有効なパーティションの数をカウントすることです。 

制約\(n, m \le 500\)\(O(n^2)\) または \(O(nm)\) 動的計画法による解法が実現可能であることを示唆しています。 指数関数的なものは何でも\(n\)中程度のパーティション数でも不可能なので、\(n\)非常に早く成長します。 階乗またはサブセット列挙アプローチは直ちに除外されます。 

重要な点は、グループが順序付けされておらず、同じサイズの 2 つのグループを交換しても新しいソリューションが作成されないことです。 これは重要です。なぜなら、単純な「グループを 1 つずつ選択する」アプローチでは、グループの順序を重要なものとして扱うため、簡単に過大評価されてしまう可能性があるからです。 

よくある失敗例の 1 つは、対称性を固定せずに各グループを独立して扱うことです。 たとえば、次の場合\(n = 4\)許容されるサイズは\(\{2\}\)の場合、有効なパーティションは単なるペアになります。\(\{\{1,2\}, \{3,4\}\}\)、\(\{\{1,3\}, \{2,4\}\}\)、\(\{\{1,4\}, \{2,3\}\}\)。 最初にペアを選択し、次に対称性の処理を行わずに別のペアを選択する単純な構造では、同じパーティションが異なる順序で複数回カウントされる可能性があります。

1 つの特徴的な要素、たとえば人物に焦点を当てると、その構造は管理しやすくなります。\(1\)。 すべてのグループを対称的に構築する代わりに、すべての有効なパーティションが人物を含むグループによって記述されるように強制します。\(1\)。 そのグループにはある程度の許容サイズが必要です\(k\)、サイズを決定したら、残りを選択します\(k-1\)他のメンバー\(n-1\)人々。 そのグループを修正すると、残りの問題は独立し、サイズが決まります。\(n-k\)。

 ## アルゴリズムのチュートリアル

 私たちは定義します\(dp[x]\)有効な分割方法の数として\(x\)ルールの下にある人々。 

1.初期化\(dp[0] = 1\)。 これは、有効な分解が 1 つだけ含まれる空のセットを表します。 

2. 各サイズについて\(k\)許可されるグループ サイズのセットで、最大で二項係数を事前計算します。\(n\)。 これらは、グループのサイズが固定された後にグループのメンバーを選択する方法の数を表します。 

3. 合計サイズごとに\(x\)から\(1\)に\(n\)、計算する\(dp[x]\)人を含むグループを考慮して\(1\)。 このグループにはある程度の許容サイズが必要です\(k \le x\)。 

4. それぞれについて\(k\)、 選ぶ\(k-1\)残りからさらに人が増える\(x-1\)に貢献します\(\binom{x-1}{k-1}\)。 残り\(x-k\)人々は独立して分割できます\(dp[x-k]\)方法があるので追加します\(\binom{x-1}{k-1} \cdot dp[x-k]\)答えに。 

5. 有効なすべての合計\(k\)入手する\(dp[x]\)、次の値までのすべての値を計算します。\(dp[n]\)。 

人を直す背後にある重要な考え方\(1\)それはグループ間の対称性を排除することです。 すべてのパーティションは、区別された要素を含むグループによって一意に表現されるため、複数回カウントされる構成はありません。 

### なぜ効果があるのか

 すべての有効なパーティション\(x\)要素には、要素を含むグループが 1 つだけ含まれます\(1\)。 そのグループはサイズを一意に決定します\(k\)そして次の選択肢\(k-1\)仲間たち。 そのグループを削除した後、残りの要素は、次のサイズの独立した有効なパーティションを形成します。\(x-k\)。 逆に、以下を含むグループの有効な選択は、\(1\)そして、残りの要素の有効なパーティションがあれば、一意の完全なパーティションが生成されます。 これにより、繰り返しによってカウントされた構成と実際の有効なパーティションとの間に 1 対 1 の対応関係が確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, m = map(int, input().split())
a = list(map(int, input().split()))

allowed = set(a)

# precompute binomial coefficients
C = [[0] * (n + 1) for _ in range(n + 1)]
for i in range(n + 1):
    C[i][0] = 1
    for j in range(1, i + 1):
        C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

dp = [0] * (n + 1)
dp[0] = 1

for x in range(1, n + 1):
    total = 0
    for k in allowed:
        if k <= x:
            total += C[x - 1][k - 1] * dp[x - k]
            total %= MOD
    dp[x] = total

print(dp[n])
```コードは繰り返しの後に直接続きます。 二項テーブルは \(O(n^2)\) で 1 回構築され、DP 遷移は各状態の許容されるすべてのサイズにわたって反復されます。 引き算\(x-k\)要素を含むグループの削除に相当します\(1\)、 その間\(\binom{x-1}{k-1}\)そのグループの残りの部分を選択するためのアカウント。 

微妙な点は、オーバーフローを避けるために、各累算の後にモジュラー演算が適用されるようにすることです。 もう 1 つは、繰り返しでは常に次を使用することです。\(x-1\)選ぶ\(k-1\)、 ない\(x\)選ぶ\(k\)1 つの要素が区別されたグループ内で固定されているためです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    a = list(map(int, input().split()))
    MOD = 998244353

    allowed = set(a)

    C = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        C[i][0] = 1
        for j in range(1, i + 1):
            C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD

    dp = [0] * (n + 1)
    dp[0] = 1

    for x in range(1, n + 1):
        total = 0
        for k in allowed:
            if k <= x:
                total += C[x - 1][k - 1] * dp[x - k]
                total %= MOD
        dp[x] = total

    return str(dp[n])

# provided sample
assert run("3 3\n1 2 3") == "5"

# all singletons only
assert run("3 1\n1") == "1"

# impossible sizes
assert run("4 1\n3") == "0"

# mixed sizes
assert run("5 2\n1 2") == "26"

 ## 特殊なケース

 重要なエッジケースは、サイズのみの場合です\(1\)許可されています。 このアルゴリズムは、すべての状態をシングルトンの選択に削減し、再帰により、どの状態に対しても 1 つのパーティションが正確に生成されます。\(n\)。 DP は常に選択します\(k=1\)、 そして\(\binom{x-1}{0}=1\)、 それで\(dp[x]=dp[x-1]\)。 

もう 1 つのエッジ ケースは、許可されるサイズの組み合わせの合計を合計できない場合です。\(n\)。 この場合、すべての\(dp[x]\)最終的にはゼロになりますが、\(dp[0]\)、すべての遷移が完全に分解できないため\(x\)。 最終的な答えは正しくゼロになります。 

いつ\(n\)小さいですが複数のサイズが存在します。すべての構造は要素を含む一意のグループによって固定されているため、繰り返しでは自然にすべてのパーティションが重複せずにカウントされます。\(1\)、グループ順序間での対称的な過剰カウントを防止します。
