 ## 解決策
 ## 問題の理解

 山の輪郭は区分的線形関数です。 入力は頂点を左から右に点として与えます`(x_i, y_i)`、連続した点の間では、山はそれらを結ぶ直線になります。 指定された範囲外では、標高はゼロになります。 カメラは固定幅の水平間隔を選択します`W`、つまり`[x, x + W]`、その区間内で可能な限り最大の平均標高が必要です。 すべての画像の幅は同じであるため、平均を最大化することは、間隔内の山の下の面積を最大化することとまったく同じです。 公式の制約は次のとおりです`n <= 10^5`、`x_i <= 10^9`、`y_i <= 10^4`、 そして`W <= 10^9`。 

大きな値`n`山セグメントのすべてのペアを明示的に比較するアルゴリズムを除外します。 アン`O(n^2)`メソッドは大まかに実行されます`n(n-1)/2`、 ほとんど`5 * 10^9`、でのペアチェック`n = 10^5`、これは 7 秒の制限がサポートできる範囲をはるかに超えています。 座標も大きいため、X 軸を離散化することはできません。 連続区分線形関数を直接操作する必要があります。 

一般に不正な実装を引き起こす境界状況は 3 つあります。 まず、最適な間隔は山の頂点で正確に開始または終了することができます。 たとえば、`W = 1`そしてポイント`(0, 10), (1, 20)`、間隔`[0, 1]`平均的です`15`したがって、正しい出力は次のようになります。`15.000000000`。 セグメント内のみを厳密に検索する実装では、最適なものを見逃す可能性があります。 

第 2 に、最適な開始位置は山の頂点やずれた頂点である必要はありません。 考慮する```
3 2
0 0
2 10
4 0
```間隔`[1, 3]`面積がある`15`、したがって平均的です`7.5`。 正しい出力は次のとおりです`7.500000000`。 位置だけを確認する検索`x_i`そして`x_i-W`検査するだろう`0`、`2`、 そして`4`で真の最適値を逃してしまいます。`x = 1`。 

第三に、カメラ間隔の一部が指定された山の外側にある可能性があります。 のために```
2 10
0 10
1 20
```山全体が含まれています`[0, 10]`。 その面積は三角形/台形の面積です`15`、したがって、答えは次のとおりです`1.500000000`。 最後の入力ポイントを山が最後の傾斜を続けるかのように扱うと、まったく異なる答えが生成されます。 このステートメントは、指定された景観の外側の標高がゼロであると明示的に定義しています。 

## アプローチ

 直接的な総当たりアプローチにより、すべてのセグメントを処理できます。`y(x)`およびシフトされた関数のすべてのセグメント`y(x + W)`可能なペアとして。 両方が固定線形関数である区間では、それらの差は線形であるため、面積関数は初等微積分で正確に処理できます。 問題は、最初の関数の 1 つのセグメントが 2 番目の関数の多くのシフトされたセグメントと重なる可能性があり、最悪の場合、`O(n^2)`そんなペアたち。 と`n = 10^5`、つまり約`5 * 10^9`それぞれに対して行われる演算を考慮する前に、ペアの関係を確認します。 

重要な観察は、セグメントの任意のペアを考慮する必要がまったくないということです。 定義する`F(x) = integral from x to x+W of y(t) dt`。 

望ましい平均値は`F(x) / W`、 そして`W`は固定されているため、平均を最大化することは最大化を意味します`F(x)`。 

微積分の基本定理により、`F'(x) = y(x + W) - y(x)`。 

これにより問題が大幅に変わります。 の式が適用される唯一の位置`F'(x)`変更できるのは、次のいずれかの位置です。`x`元の山の頂点を越えた​​り、`x + W`1つを越えます。 それらの位置はまさに`x_i`そして`x_i - W`。 

これらのイベント位置を分類すると、連続する 2 つのイベント間のすべての間隔は非常に単純な構造になります。 両方`y(x)`そして`y(x+W)`そこでは線形なので、`F'(x)`直線的であり、`F(x)`二次関数です。 

1 つの区間の 2 次式では、その最大値を達成する方法が 2 つしかありません。 それは端点で、または二次関数が凹面の場合はその定常点で達成できます。 したがって、各イベント間隔には 2 つのエンドポイントと最大 1 つの内部候補のみが必要です。 

エリア自体は、山の接頭積分を構築した後、定数時間で評価できます。 The event positions can be sorted in`O(n log n)`、各イベントは二分探索で関連する山セグメントを見つけることができます。 これにより、`O(n log n)`解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 区分線形マウンテンとプレフィックスエリア配列を構築します。 頂点ごとに`x_i`、山の下の最初の頂点から頂点までの領域を保存します。`x_i`。 これにより、任意の間隔で面積を計算できます`[a,b]`として`A(b) - A(a)`。 
2. 定義する`F(x) = A(x + W) - A(x)`。 これはまさに、左端が次の位置にあるカメラによってキャプチャされた領域です。`x`なので最大化します`F`元の問題を解決します。 
3. すべてのイベント位置を作成する`0`、 毎`x_i`、およびすべての非負`x_i - W`。 最初のグループはどこをマークしますか`y(x)`線形セグメントを変更します。 2 番目にシフトされたグループはどこをマークしますか`y(x + W)`セグメントを変更します。 位置`0`カメラは非負の X 軸から開始するため、 が含まれます。 
4. イベントの位置を並べ替えて重複を排除します。 連続する 2 つのイベントの間`[L,R]`、 どちらでもない`y(x)`または`y(x+W)`は頂点を横切るため、両方の関数はその区間全体で線形になります。 
5. 評価する`F(L)`そして`F(R)`イベント間隔ごとに。 イベントで発生するすべてのグローバル最大値がカバーされるようになりました。 
6. インターバルの中`[L,R]`、の傾きを取得します。`y(x)`そしてその傾きは`y(x+W)`中間点で両方を評価することによって。 それらの違いは、`F'(x)`。 以来`F'(x)`は線形であり、その傾きは区間全体にわたって一定です。 
7. の傾斜がある場合、`F'`マイナスです、`F`凹面になっている`[L,R]`。 その静止点は可能な内部最大値です。 のゼロを計算します`F'(x)`そして評価する`F`間隔内にある場合はそこにあります。 傾きが負でない場合、`F`は線形または凸であるため、区間の最大値はすでに終点にあります。 
8. 見つかった最大面積を保持し、それを次の値で割ります。`W`答えを印刷するとき。 小数点以下 9 桁を印刷するだけで、必要な情報を得ることができます。`10^-6`許容範囲。 

アルゴリズムの背後にある不変条件は、考えられるすべてのマキシマイザーがイベント位置、または正確に 1 つのイベント間隔内に存在するということです。 そのような間隔ごとに、`F'(x)`線形なので、`F(x)`二次関数です。 二次関数には他の種類の極大値はありません。 したがって、二次関数が凹である場合の端点と単一の静止点をチェックすると、考えられるすべてのグローバル最大値がカバーされます。 

## Python ソリューション```python
import sys
from bisect import bisect_right

def solve():
    input = sys.stdin.readline

    n, W = map(int, input().split())
    xs = [0] * n
    ys = [0] * n

    for i in range(n):
        xs[i], ys[i] = map(int, input().split())

    # pref[i] = area under the mountain from xs[0] to xs[i].
    pref = [0.0] * n
    for i in range(1, n):
        dx = xs[i] - xs[i - 1]
        pref[i] = pref[i - 1] + dx * (ys[i - 1] + ys[i]) * 0.5

    total_area = pref[-1]

    def area(t):
        """Integral of y from xs[0] to t."""
        if t <= xs[0]:
            return 0.0
        if t >= xs[-1]:
            return total_area

        i = bisect_right(xs, t) - 1
        dx = t - xs[i]
        slope = (ys[i + 1] - ys[i]) / (xs[i + 1] - xs[i])

        return pref[i] + ys[i] * dx + 0.5 * slope * dx * dx

    def value_slope(t):
        """Return y(t) and the slope of y at t."""
        if t < xs[0] or t > xs[-1]:
            return 0.0, 0.0

        if t == xs[-1]:
            return float(ys[-1]), 0.0

        i = bisect_right(xs, t) - 1
        dx = t - xs[i]
        slope = (ys[i + 1] - ys[i]) / (xs[i + 1] - xs[i])
        value = ys[i] + slope * dx

        return value, slope

    # The derivative can change only when x or x + W
    # reaches an input vertex.
    events = {0}
    for x in xs:
        events.add(x)
        if x >= W:
            events.add(x - W)

    events = sorted(events)

    def captured_area(x):
        return area(x + W) - area(x)

    best = captured_area(0)

    for k in range(len(events) - 1):
        L = events[k]
        R = events[k + 1]

        if L == R:
            continue

        best = max(best, captured_area(L), captured_area(R))

        mid = (L + R) * 0.5

        y1, s1 = value_slope(mid)
        y2, s2 = value_slope(mid + W)

        # F'(x) = y(x + W) - y(x)
        # Its slope is s2 - s1.
        derivative_slope = s2 - s1

        derivative_at_mid = y2 - y1
        derivative_at_left = (
            derivative_at_mid
            + derivative_slope * (L - mid)
        )

        # F is concave exactly when F' is decreasing.
        if derivative_slope < 0.0:
            root = L - derivative_at_left / derivative_slope

            if L < root < R:
                best = max(best, captured_area(root))

    print(f"{best / W:.9f}")

if __name__ == "__main__":
    solve()
```プレフィックス配列には台形領域が格納されます。 連続する頂点の間には、山は方程式を持っています`y(x) = y_i + s(x-x_i)`したがって、部分セグメント上の領域は次のようになります。`y_i * dx + s * dx² / 2`。 の`area`関数は、その部分的な台形と既に蓄積されているプレフィックス領域を結合します。 

の`value_slope`関数は、座標の標高と傾斜の両方を返します。 指定された山の外側では両方ともゼロであり、エンドポイントを越えて必要なゼロ標高を処理します。 最後の頂点では、風景がそこで終わるため、右側の傾斜もゼロになります。 

イベントセットには以下が含まれます`x_i - W`カメラの左端は非負の x 軸に制限されているため、非負の場合のみです。 含む`x_i - W`は、カメラの右端が山の頂点を横切ることによって引き起こされる変化を捉えたものです。 

中間点は、イベント間隔内の傾きを取得するために使用されます。 イベントと同時に発生することはできないため、どの線形セグメントを使用するかについて曖昧さはありません。 次に、一定の微分勾配に沿って中点から移動することにより、左端点の微分値が取得されます。 

表現`root = L - derivative_at_left / derivative_slope`線形方程式を解くことから直接得られます`F'(x) = 0`。 このルートを検査するのは次の場合のみです。`F'`減少しているのは、そのときのみ、対応する静止点が最小値ではなく最大値になるからです。 

すべての座標と面積の計算は、Python の整数および浮動小数点表現に快適に適合します。 可能な最大の面積は次のとおりです。`10^13`一方、倍精度は、絶対誤差または相対誤差に必要な精度を大幅に上回る精度を提供します。`10^-6`。

    ys = [0] * n

    for i in range(n):
        xs[i], ys[i] = map(int, input().split())

        dx = t - xs[i]

    events = {0}

        if x >= W:

    print(f"{best / W:.9f}")

2 10
4 0
```イベントセットは`{0, 2, 4}`。 の上`[0,2]`、`y(x)`傾斜とともに上がる`5`、 その間`y(x+2)`斜面で落ちる`-5`。 したがって、`F'(x)`傾斜がある`-10`。 で`x = 0`、`F'(0) = 10`、そのゼロは次のとおりです`x = 1`。 アルゴリズムはその点を評価し、面積を取得します。`15`、平均を与える`7.5`。 これはまさに、ブレークポイントのみをチェックするアルゴリズムを無効にするケースです。 

風景より広いカメラの場合、```
2 10
0 10
1 20
```イベントセットには以下が含まれます`0`そして`1`。 後`x = 1`、左端はすでに山を越えているため、キャプチャされたエリアはゼロです。 で`x = 0`、カメラは山全体と 9 つの高さゼロの地形をカバーします。 エリアは`15`したがって、平均は次のようになります。`1.5`。 最終点を超えるゼロ拡張は、によって直接処理されます。`area(t)`。 

同じ高さの場合、```
4 3
0 7
5 7
10 7
15 7
```両方`y(x)`そして`y(x+W)`カメラが完全に山の上にある場合は、傾斜がゼロになります。 その結果`F'(x) = 0`そしてそのような位置はすべて最適です。 このアルゴリズムでは、このための特別なケースは必要ありません。 導関数の傾きもゼロであるため、すべてが同じ面積を持つ終点値を単純に保持します。 

最大サイズの場合、生成される入力には次のものが含まれます。`100000`頂点と一定の標高`7`。 山の内側にあるすべてのカメラ位置が正確にキャプチャします`7 * W`エリアなので、答えは正確です`7.000000000`。 イベントの構築とバイナリ検索は残ります`O(n log n)`、これは公式の意図されたスケールです`n <= 10^5`制約。
