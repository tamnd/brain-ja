 ## 問題の理解

 More or Less は小さなラテン方陣のパズルです。 (n \times n) 個のボードがあり、すべての行とすべての列に (1) から (n) までの各値が 1 回だけ含まれている必要があります。 一部のセルはすでに埋められています。 水平方向または垂直方向に隣接するセル間には、いくつかの不等式が与えられる場合もあります。 タスクは、すべての行と列の制約、すべての固定値、およびすべての不等式が維持されるように、すべての空白セルを埋めることです。 入力は、正確に 1 つの有効な完成ボードを含むパズルを記述することが保証されます。 必要な出力は完成したボードであり、1 行につき 1 行、スペースは含まれません。 元のコンテスト ステートメントでは、(n) を最大 7 に制限し、セルと不等式にコンパクトな文字表現を使用します。 

(n) の小さな境界が中心的な手がかりです。 セルは最大 49 個存在でき、各セルには最大 7 つの可能な値があります。 多項式時間アルゴリズムは快適ですが、根底にあるラテン平方補完問題は組み合わせの問題であるため、実際的な解決策は、可能な限り早い段階で不可能な部分ボードを拒否しながら探索することです。 (n=7) の場合、すべての可能性を盲目的に探索することは絶望的ですが、制約に基づくバックトラッキング検索は 5 秒の制限内に十分収まるほど小さいものです。 Codeforces ページでは、元の制限が 256 MB のメモリで 5 秒であることが確認されています。

## アプローチ

 最も直接的な総当たりの解決策は、ボードをセルごとに埋めて、1 から (n) までのすべての値を試し、最後に完成したボードをチェックします。 最終的には考えられるすべての割り当てが考慮されるため、これは正しいです。 残念ながら、最大 (n^{n^2}) 個の代入が調査されます。 (n=7) では、およそ (7^{49})、およそ (2\times10^{41}) となり、これはまったく実行不可能です。 

ボードを構築する際にラテン二乗特性を使用することで、ブルート フォースを大幅に改善することができます。 各行に任意の値を許可する代わりに、行ごとに (1,\ldots,n) の順列を列挙することができます。 (7! = 5040) 行が考えられるため、これほど賢い総当たり攻撃でも、最悪のケースはおよそ次のとおりです。

 (7!)^7 \約 8.2\times10^{25}
 】

 行の組み合わせ。 まだ大きすぎます。 

有益な観察は、ほとんどすべての部分代入に、ほとんどの値を除外するのに十分な情報がすでに含まれていることです。 セルは、その行または列にすでに存在する値を使用できません。 不等式は、隣接するセルがわかっている場合、すぐに値を削除できます。 不等式の両方のセルがまだ不明な場合でも、それらの可能な値のセットは相互に制限します。 たとえば、(x<y) で、(y) の可能な最大値が 4 の場合、(x) は 4 以上にはなりません。 同様に、(x) の可能な最小値が 3 の場合、(y) は 1、2、または 3 にすることはできません。 

したがって、最適なアプローチは、制約を伝播するバックトラッキング検索です。 すべての再帰的状態について、すべての未入力セルの現在の候補セットを構築します。 これらの候補セット間で不等式制約を繰り返し伝播します。 次に、残りの候補が最も少ない未記入のセルを選択し、それらの値にのみ分岐します。 これは標準的な最小残存値の考え方ですが、ボードにはセルごとに 7 つの可能な値しかなく、割り当てのたびにその値が行全体と列全体から即座に削除されるため、ここでは特に効果的です。 

ブルートフォース検索は最終的にすべてのボードを検査するため機能します。 これらのボードのほとんどすべてが非常に早い段階で制約に違反するため、失敗します。 セルが永続的にコミットされる前に、行、列、および不等式の制約を適用できるという観察により、巨大な検索ツリーがはるかに小さな制約検索に変わります。

 ## アルゴリズムのチュートリアル

 1. ボードを (n\times) の整数グリッドに解析します。 あ`0`空白のセルを表します。 すべての行と列でどの値がすでに使用されているかをビットマスクとともに保存します。 (n\le7) なので、行または列のすべての値を表すには 1 つの整数で十分です。 
2. すべての不等式を形式 (a<b) の有向関係に変換します。 水平の場合`<`、左のセルは右のセルより小さいです。 のために`>`、関係が逆転します。 縦型の場合`^`、上のセルは下のセルより小さいですが、`v`は逆の意味です。 
3. 各検索状態で、すべてのセルの候補ビットマスクを計算します。 空白のセルの場合は、1 から (n) までのすべての値から始めて、その行または列ですでに使用されているすべての値を削除します。 不等式内の隣接セルがすでに割り当てられている場合は、それに応じて候補セットを制限します。 
4. 円弧の一貫性を不等式関係に適用します。 関係 (a<b) の場合、(a) のすべての候補は (b) に少なくとも 1 つのより大きな候補を持たなければなりません。 (b) の最大の候補が (k) である場合、候補 (k,\ldots,n) は (a) から削除できます。 対称的に、(a) の最小候補が (k) である場合、値 (1,\ldots,k) を (b) から削除できます。 候補セットが変更されなくなるまで、このプロセスを繰り返します。 
5. 埋められていないセルがすべての候補を失った場合、現在の部分的なボードでは解決策を導き出すことができないため、すぐにバックトラックします。 不等式が不可能になった場合も同様です。 
6. すべての未入力のセルの中で、候補セットが最小のものを選択します。 これが最小残存値ルールです。 最も制限されたセルを最初に選択すると、ボードの大部分を埋めた後ではなく、ほんの数回の割り当て後に矛盾が表示されます。 
7. 選択したセルのすべての候補値を試します。 グリッド値と対応する行マスクと列マスクを更新し、より小さな問題を再帰的に解決します。 再帰呼び出しが成功した場合は、その値を保持します。 失敗した場合は、割り当てを元に戻し、次の候補を試してください。 
8. 空白セルがなくなった場合、ボードは有効な解決策です。 入力によって一意性が保証されるため、最初に見つかった完全なボードが必要な答えとなります。 

### なぜ効果があるのか

 不変条件は、すべての候補セットに、固定値、行の一意性、列の一意性、および現在伝播されているすべての不等式と互換性のある正確な値が含まれていることです。 円弧の整合性は、不等式の反対側に互換性のある値が存在しない場合にのみ値を削除するため、有効な補完に属する値を削除することはできません。 検索で候補が割り当てられると、その値が同じ制約に対して明示的にチェックされます。 したがって、すべての再帰的分岐は潜在的に有効な部分ボードを表し、すべての無効な分岐はその不可能性が確立された後にのみ破棄されます。 残りのすべての候補は必要に応じて最終的に試行されるため、有効な完了をスキップすることはできません。 一意性が保証されているということは、正常に完了したボードが必要なボードであることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(lines):
    n = int(lines[0])
    board = [[0] * n for _ in range(n)]

    row_mask = [0] * n
    col_mask = [0] * n

    # inequalities are stored as (a, b), meaning value[a] < value[b]
    less_edges = []

    def cell_id(r, c):
        return r * n + c

    # Read the rows containing cells and horizontal inequalities.
    for r in range(n):
        s = lines[1 + 2 * r]
        for c in range(n):
            ch = s[2 * c]
            if ch != '-':
                v = ord(ch) - ord('0')
                board[r][c] = v
                bit = 1 << (v - 1)
                row_mask[r] |= bit
                col_mask[c] |= bit

            if c + 1 < n:
                sign = s[2 * c + 1]
                a = cell_id(r, c)
                b = cell_id(r, c + 1)

                if sign == '<':
                    less_edges.append((a, b))
                elif sign == '>':
                    less_edges.append((b, a))

    # Read the rows containing vertical inequalities.
    for r in range(n - 1):
        s = lines[2 + 2 * r]
        for c in range(n):
            sign = s[2 * c]
            a = cell_id(r, c)
            b = cell_id(r + 1, c)

            if sign == '^':
                less_edges.append((a, b))
            elif sign == 'v':
                less_edges.append((b, a))

    ALL = (1 << n) - 1

    neighbors = [[] for _ in range(n * n)]
    for a, b in less_edges:
        neighbors[a].append((b, True))
        neighbors[b].append((a, False))

    def build_domains():
        domains = [0] * (n * n)

        for r in range(n):
            for c in range(n):
                idx = cell_id(r, c)

                if board[r][c] != 0:
                    domains[idx] = 1 << (board[r][c] - 1)
                    continue

                mask = ALL & ~(row_mask[r] | col_mask[c])

                for other, is_less in neighbors[idx]:
                    orow = other // n
                    ocol = other % n
                    v = board[orow][ocol]

                    if v == 0:
                        continue

                    if is_less:
                        # Current value must be smaller than v.
                        mask &= (1 << (v - 1)) - 1
                    else:
                        # Current value must be greater than v.
                        mask &= ALL ^ ((1 << v) - 1)

                    if mask == 0:
                        return None

                domains[idx] = mask

        # Arc consistency for all inequalities.
        changed = True
        while changed:
            changed = False

            for a, b in less_edges:
                ma = domains[a]
                mb = domains[b]

                if ma == 0 or mb == 0:
                    return None

                max_b = mb.bit_length()
                new_ma = ma & ((1 << (max_b - 1)) - 1)

                if new_ma != ma:
                    domains[a] = new_ma
                    ma = new_ma
                    changed = True

                if ma == 0:
                    return None

                min_a = (ma & -ma).bit_length()
                new_mb = mb & (ALL ^ ((1 << min_a) - 1))

                if new_mb != mb:
                    domains[b] = new_mb
                    mb = new_mb
                    changed = True

                if mb == 0:
                    return None

        return domains

    def dfs():
        domains = build_domains()
        if domains is None:
            return False

        best = -1
        best_mask = 0
        best_count = n + 1

        complete = True

        for r in range(n):
            for c in range(n):
                if board[r][c] == 0:
                    complete = False
                    idx = cell_id(r, c)
                    mask = domains[idx]
                    count = mask.bit_count()

                    if count < best_count:
                        best_count = count
                        best = idx
                        best_mask = mask

        if complete:
            return True

        r = best // n
        c = best % n

        mask = best_mask
        while mask:
            bit = mask & -mask
            mask -= bit

            v = bit.bit_length()

            board[r][c] = v
            row_mask[r] |= bit
            col_mask[c] |= bit

            if dfs():
                return True

            row_mask[r] ^= bit
            col_mask[c] ^= bit
            board[r][c] = 0

        return False

    dfs()

    return [''.join(str(board[r][c]) for c in range(n)) for r in range(n)]

def main():
    first = input().strip()
    if not first:
        return

    n = int(first)
    lines = [first]

    for _ in range(2 * n - 1):
        lines.append(input().rstrip('\n'))

    answer = solve_case(lines)
    sys.stdout.write('\n'.join(answer))

if __name__ == "__main__":
    main()
```パーサーは交互文字レイアウトに直接に従います。 通常の行では、セル値はインデックスで発生します。`0, 2, 4, ...`、水平方向の不等式がインデックスで発生します。`1, 3, 5, ...`。 垂直区切り行では、有用な位置が再び次のとおりです。`0, 2, 4, ...`、そのため、コードは次のようになります`s[2 * c]`。 

行マスクと列マスクでは、値 (v) にビット (v-1) が使用されます。 すでに使用されている値の削除は、単一のビット単位の操作で行われます。 Python の整数には任意の精度がありますが、ここで必要なのは 7 ビットだけであるため、オーバーフローは心配ありません。 

の`build_domains`この関数は、複雑なロールバック構造を維持するのではなく、再帰呼び出しごとに意図的にドメインを再構築します。 最大でも 49 個のセルを使用すると、コストはほとんどかからず、バックトラッキング状態の破損がはるかに困難になります。 

不等式の伝播も、再帰状態ごとに最初から実行されます。 (a<b) の場合、(b) の可能な最大値が (a) の上限を与え、(a) の可能な最小値が (b) の下限を与えます。 これらの制限を繰り返すと、不平等の連鎖を通じて情報が伝播します。 

検索では、候補が最も少ないセルが選択されます。 これは、セルを単に左上から右下に埋めるよりも効果的です。これは、セルが強く制約されているとすぐに矛盾が露呈する可能性があるためです。 割り当ては、現在の伝播がすべて成功した後にのみ行われ、行マスクと列マスクはバックトラック中に XOR で復元されます。

 ## 特殊なケース

 (n=1) の場合、区切り線はまったくありません。 入力は単純に`1`続いて単細胞。 パーサーは水平および垂直の不等式に対して 0 回ループし、ボードはすでに完成しています。 出力は`1`。 これにより、実装ではすべてのパズルに少なくとも 1 つの不等式があると想定することができなくなります。 

境界不平等の場合、```
2
-<-
^.v
-.-
```水平関係は、最初の行が (x<y) の形式を持つことを意味します。 行には 1 と 2 が含まれている必要があるため、次のようにする必要があります。`12`。 の`^`最初の垂直位置では (1<2) を意味します。`v`2 番目の手段 (2>1)。 したがって、2行目は`21`。 パーサーは、位置 0 と 2 から垂直記号を読み取り、指定された形式と正確に一致します。 

行と列の両方によって強制されるセルについては、次のことを考慮してください。```
3
1.2.3
2.3.1
3.-.2
.....
.....
```空白セルは 3 と 2 を含む行にあり、1 だけが残ります。その列にも 2 と 3 が含まれており、やはり 1 だけが残ります。`build_domains`は、これらの制限の交差を値 1 の 1 ビット マスクとして計算するため、MRV 検索はそれをすぐに割り当てます。 

ボードの最大サイズについては、7x7 テストには 49 個のセルとブランクが 1 つだけあります。 すべての行と列のマスクは 7 ビットを使用し、欠落しているセルの候補は 1 つだけです。 ソルバーは大規模な検索ツリーを探索する必要はありませんが、入力では許容される最大値 (n) ですべての配列次元を実行します。 

最後に、不注意に不等式を実装すると、誤って平等を許してしまう可能性があります。 ソルバー内のすべての関係は厳密な境界を使用します。 (a<b) の場合、(a) に許可される最大の候補は (b) の可能な最大値より 1 小さい値であり、(b) に許可される最小の候補は (a) の可能な最小値より 1 大きい値です。 ボードの値は整数であるため、これらの厳密な境界はまさに必要なものです。`<`そして`>`セマンティクス。
