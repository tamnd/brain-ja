 ## 解決策
 ## 問題の理解

 ベッドは軸に沿って整列した長方形で、その左下隅が`(0, 0)`そして右上隅は誰のものですか`(W, L)`。 Anya は長さの線分としてモデル化されます。`H`。 彼女の頭はそのセグメントの 1 つの端点であり、次の位置にあります。`(x, y)`、角度`a`頭から足に向かう方向を表します。 の角度`0`は右を指しますが、`90`は上を向いているため、通常の数学的規則が適用されます。 

タスクは、セグメント全体がベッドの内側にあるかどうかを判断することです。 境界に触れることは許可されているため、正確な座標を持つエンドポイント`0`、`W`、`0`、 または`L`はまだ有効です。 

入力には 6 つの整数のみが含まれており、`L`そして`W`せいぜい`500`、`H`せいぜい`200`、頭の座標はベッドに拘束されます。 これらの境界は非常に小さいですが、実際の単純化は計算上のものではなく構造的なものです。 処理する大きなグラフ、配列、または検索スペースはありません。 一定数の算術演算で十分です。 

主なエッジケースは、頭がベッド内にあることが保証されているが、他のエンドポイントはそうではないという事実から生じます。 例えば、```
100 100 20
90 50 0
```2 番目のエンドポイントを与える`(110, 50)`、したがって、答えは次のとおりです`NO`。 頭の位置だけをチェックする不用意な実装は、誤って受け入れられてしまいます。 

境界エンドポイントは有効です。 例えば、```
100 100 20
80 50 0
```2 番目のエンドポイントを次の場所に置きます`(100, 50)`、ちょうど右端にあります。 正しい出力は次のとおりです`YES`。 次のような厳密な不等式を使用します。`0 < x < W`誤って拒否してしまうでしょう。 

方向は下または左を指すことができるため、単純に次のように追加します。`H * cos(a)`そして`H * sin(a)`彼らの兆候を考慮しないことも、よくある間違いです。 例えば、```
100 100 20
50 50 270
```で終わる`(50, 30)`、ベッドの中です。 正しい出力は次のとおりです`YES`。 

1 つの水平または垂直投影が大きく見える場合でも、セグメントが斜めに適合する場合もあります。 例えば、```
100 100 50
50 75 225
```およそで終了します`(14.64, 39.64)`したがって、両方のエンドポイントが内部にあり、答えは次のようになります。`YES`。 

## アプローチ

 直接的な幾何学的なアプローチでは、アーニャの体に沿った多くの点を調べて、各点が長方形の内側にあるかどうかを確認しようとします。 身体を 1 センチメートルの断片に離散すると、最大でも`H + 1 <= 201`ポイントがあるため、このバージョンは実際には制限内で快適に動作します。 その弱点は実際的というよりもむしろ概念的なものです。連続した線分には無限に多くの点が含まれており、有限サンプルをチェックするだけでは、サンプリングされていない部分が内部にあることは証明されません。 

有益な観察は、ベッドが凸型セットであるということです。 2 つの端点が凸集合内にある線分は、完全にその集合内にあります。 長方形は凸面なので、アーニャの体の内部を調べる必要はまったくありません。 頭はすでに与えられているため、計算して確認する必要があるのは足元の終点だけです。 

ブルートフォースのアイデアは、セグメント全体を点ごとに検証しようとするため機能しますが、それは不必要であり、当然のことながら正確な連続証明は得られません。 凸面観察により、問題全体が 1 つのエンドポイントの計算と 4 つの座標比較の実行に軽減されます。 

終点は標準の極座標変位から取得されます。`dx = H * cos(a)`

`dy = H * sin(a)`それで足はここにあります`(x + dx, y + dy)`。 

三角関数はラジアンを使用するため、最初に入力角度を次のように変換する必要があります。`a * pi / 180`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | セグメントを離散化する | O(H) | お(1) | これらの範囲では受け入れられますが、概念的には不要です。 
| 2 番目のエンドポイントを確認します | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ベッドの寸法を読む`L`そして`W`、アーニャの身長`H`、頭の位置`(x, y)`角度も合わせて`a`。 頭自体はベッド上にあることがすでにわかっているため、個別の幾何学的検索は必要ありません。 
2. 角度を度からラジアンに変換します。 パイソンの`math.sin`そして`math.cos`ラジアンを想定しているため、度の値を直接使用すると、まったく異なる方向が生成されます。 
3. 次の式を使用して、アーニャの足の頭からの変位を計算します。`H * cos(a)`水平方向と`H * sin(a)`垂直に。 Anya は左または下を向いている可能性があるため、負の値が有効です。 
4. 変位を頭の座標に追加して、2 番目の終点を取得します。`(fx, fy)`。 
5. かどうかを確認します。`fx`間にあります`0`そして`W`そしてどうか`fy`間にあります`0`そして`L`、包括的な比較を使用します。 次のような値があるため、小さな浮動小数点許容誤差が使用されます。`cos(90°)`は正確なゼロではなく近似的に表されます。 
6. 印刷`YES`両方の座標がそれぞれの範囲内にある場合。 それ以外の場合は印刷します`NO`。 

重要な特性は、アルゴリズム全体を通じて、Anya のセグメントの両方の端点が長方形の内側にあるという事実を維持するだけでよいということです。 入力仕様では頭が内側になっており、最終座標確認後は足も内側になっています。 長方形は凸状であるため、これら 2 つの端点間のすべての点もその内側にあります。 したがって、計算された 2 番目のエンドポイントが適合すると、セグメント全体が正確に適合します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    L, W, H = map(int, input().split())
    x, y, angle = map(int, input().split())

    rad = math.radians(angle)

    foot_x = x + H * math.cos(rad)
    foot_y = y + H * math.sin(rad)

    eps = 1e-9

    if -eps <= foot_x <= W + eps and -eps <= foot_y <= L + eps:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```最初の入力行は、長方形の寸法とセグメントの長さを示します。 2 行目は頭の座標と方向を示します。`math.radians(angle)`必要な度からラジアンへの変換を実行します。 終点の計算は、長さを持つベクトルの幾何学的変位から直接計算されます。`H`。 

ベッド境界に触れても適合とみなされないため、比較は包括的です。 許容値は、正確な境界ケースに近い浮動小数点ノイズを処理します。 たとえば、数学的には`cos(90°) = 0`、ただし、計算された値は次のような小さな数値になる可能性があります。`6.12e-17`。 

Python では整数オーバーフローの懸念はなく、すべての座標と長さが最大でも数百であるため、浮動小数点値は小さくなります。 操作の順序も重要です。呼び出す前に角度を変換する必要があります。`sin`そして`cos`。

import sys
import io
import math

def solve():
    input = sys.stdin.readline

    L, W, H = map(int, input().split())
    x, y, angle = map(int, input().split())

    rad = math.radians(angle)

    foot_x = x + H * math.cos(rad)
    foot_y = y + H * math.sin(rad)

    eps = 1e-9

    if -eps <= foot_x <= W + eps and -eps <= foot_y <= L + eps:
        print("YES")
    else:
        print("NO")

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    try:
        sys.stdin = io.StringIO(inp)
        sys.stdout = io.StringIO()
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

 ## 特殊なケース

 頭がベッドの中にあるからといって、アーニャがフィットするわけではありません。 のために```
100 100 20
90 50 0
```変位は`(20, 0)`、つまり足元は`(110, 50)`。 X 座標が違反しています`0 <= x <= 100`、そしてアルゴリズムは出力します`NO`。 

正確な境界接触を受け入れる必要があります。 のために```
100 100 20
80 50 0
```足はここにあります`(100, 50)`。 条件`foot_x <= W`は正確に満たされるため、答えは次のようになります。`YES`。 また、小さなイプシロンは、無害な浮動小数点表現エラーからこの比較を保護します。 

円の下半分の角度は、負の垂直変位を生成します。 のために```
100 100 20
50 50 270
```エンドポイントは数学的には`(50, 30)`。 両方の座標が長方形内にあるため、アルゴリズムは次のように出力します。`YES`。 角度を常にポジティブな動きが生成されるかのように扱うと、ここでは失敗します。 

斜め方向では、両方の座標を同時に変更できます。 のために```
100 100 50
50 75 225
```エンドポイントはおよそ`(14.64, 39.64)`。 両方の座標はベッドの内側に残り、凸面により頭と足の間のすべての点も内側に残ることが保証されます。 答えは、`YES`。 

最後に、長さ 0 のセグメントは、その頭部によってすでに完全に決定されています。 と```
1 1 0
0 0 0
```両方のエンドポイントは`(0, 0)`、ベッドの左下隅にあります。 境界点は有効であるため、正しい出力は次のようになります。`YES`。
