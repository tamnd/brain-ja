 ## 解決策
 ## 問題の理解

 この問題は、ロリポップ分布を有向加重グラフとしてモデル化します。 頂点 (1) から (N) で表される (N) 人の退職チーム メンバーと、頂点 (N+1) から (M) で表される (M-N) 人の他の UCF 学生がいます。 脱退するメンバーはそれぞれ、ある程度の数のロリポップから始まり、指定された端数に従ってコレクション全体を数人の生徒に分配するという意志を持っています。 遺言により、別の脱退メンバーにロリポップを送ることができるため、複数の人を通じて配布を続けることができます。 

意図されたプロセスでは、脱退するすべてのメンバーの意志が、そのメンバーが現在保持しているロリポップに繰り返し適用されます。 すべての学生が受け取った最終的な金額を尋ねられます。 一部のロリポップが離脱メンバーのグループ内に永遠に残る可能性がある場合、それらのロリポップは破棄されます。 公式の制約は、(N \le 500)、(M \le 50{,}000)、合計で最大 (1{,}000{,}000) のエントリです。 公式の制限時間は 7 秒、メモリ制限は 1024 MB です。 

重要な違いは、最大で 500 人の脱退メンバーと、潜在的には合計 50,000 人の生徒との間の違いです。 (M) の値が大きいということは、全生徒の数を 2 次にする余裕はないが、再帰的プロセスには離脱メンバーのみが参加することを意味します。 (N) は 500 しかないので、原理的には (O(N^3)) 回の線形代数計算が可能です。 100 万エントリの境界は、入力自体が大きくなる可能性があることも意味するため、入力は効率的に処理される必要があります。 

直接シミュレーションの信頼性を低くする微妙なケースが 2 つあります。 まず、クローズドサイクルでは通常の生徒には何も送信されない可能性があります。 考慮する```
2 3
1 1
2 1.0
1 1
1 1.0
```生徒 1 と 2 はロリポップを永遠に交換し続けますが、生徒 3 は何も受け取りません。 正しい出力は次のとおりです```
0.0
0.0
0.0
```退会メンバーの金額が小さくなるのを待つシミュレーションは決して終了しません。 

2 番目の問題は、訪問するたびにごく一部だけが漏れるサイクルです。 例えば、```
2 3
1 2
2 0.999999
3 0.000001
1 1
1 1.0
```すべてのロリポップは最終的に生徒 3 に到達するため、最終出力は次のようになります。```
0.0
0.0
2.0
```一定のラウンド数の後にシミュレーションが停止すると、ほとんどすべてのロリポップがサイクル内に残っている可能性があり、著しく間違った答えが得られる可能性があります。 正の分数における (10^{-6}) の下限により、この種の遅い収束が可能になります。 

3 番目の簡単な間違いは、最初 (N 人) の生徒を通常の出力対象者として扱うことです。 彼らは全員脱退メンバーなので、最終的な答えは常にゼロです。 彼らのロリポップは、出発しない生徒に届くか、閉じたコンポーネントの中に消えます。 このステートメントでは、最初 (N) の出力行がゼロであることが明示的に要求されます。 

## アプローチ

 最も直接的なアプローチは、プロセスをシミュレートすることです。 脱退するメンバー全員の現在のロリポップの数を維持し、すべての意志を適用し、脱退するメンバーの残りの総量が十分に少なくなるまで繰り返します。 これは定義を正確に反映しているため、終了時に適切な配布が行われます。 

問題は、実用的な速度での終了が保証されていないことです。 サイクルは、完全なラウンドごとにその質量 (0.999999) を保持できます。 初期量約 (500{,}000) を (10^{-5}) 未満に減らすには、次のオーダーが必要です。 

[
 \frac{\log(10^{-5}/500000)}{\log(0.999999)}
 】

 これは約 (2.5\times 10^7) ラウンドです。 (10^6) 個ものエントリがある場合、これはおよそ (10^{13}) 個の遷移操作を意味します。 閉じたサイクルでは、シミュレーションが停止条件に到達しないため、さらに悪化します。 

有益な観察は、繰り返されるプロセスが線形方程式系であるということです。 (x_i) を、最初のコレクションとその後そこに到着するすべてのコレクションを数えた、出発メンバー (i) を通過するロリポップの総量とします。 メンバー (j) の意志がメンバー (i) に端数 (p_{j,i}) を与える場合、

 [
 x_i = L_i + \sum_{j=1}^{N} x_jp_{j,i}。 
】

 左側は、(i) に到達するすべてのものを表します。 右側には、(i) が最初に所有していたロリポップに加えて、他の脱退メンバーから到着したすべてのものが含まれています。 

値 (x_i) がわかれば、普通の生徒 (k) の答えは次のようになります。 

[
 \text{答え}_k =
 \sum_{i=1}^{N}x_i p_{i,k}。 
】

 したがって、無限プロセスは有限線形システムになりました。 

複雑な問題が 1 つあります。 脱退したメンバーのグループは、一般の学生には決して届かない閉じた構成要素を形成する可能性があります。 このような成分の場合、その総質量は永久に循環する可能性があるため、対応する行列は特異になります。 これらの変数を解決する必要はまったくありません。 まず、普通の学生への何らかの方向性を持ったすべての脱退メンバーを見つけることができます。 これらはまさに、ロリポップが最終的に必要な出力に貢献できるメンバーです。 他のすべてのメンバーは、全体の質量が最終的に破棄されるグラフの一部に属します。 

これらの無関係なメンバーを削除した後、残ったすべての州は最終的には一般の学生に到達できるようになります。 結果として得られる遷移システムは非定常であるため、(I-Q^T) は非特異的であり、線形システムには固有の解があります。 ガウス消去法で解決できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 潜在的に (O(TK))、(T) は任意に大きい | (O(M+K)) | 遅すぎて終了しない可能性があります |
 | 最適 | (O(N^3 + K)) | (O(N^2 + K + M)) | 承認済み |

 ここで (K) は遺言書の総数であり、最大 (10^6)、および (N\le500) です。 (N^3) 項はガウス消去法から来ていますが、遺言の処理と最終出力の構築は合計サイズが線形です。 

## アルゴリズムのチュートリアル

1. すべての遺言書を読み、各脱退メンバーからすべての受取人への移行確率を保存します。 同時に、出発するメンバー間に逆エッジを構築します。 最終的な出力を計算するには後で完全な遺書が必要ですが、逆グラフを使用して、どのメンバーが最終的に一般の学生に到達できるかを判断できます。 
2. 一般の生徒に直接プラスの端数を与える意志を持つ脱退メンバー全員に印を付けます。 これらは、出発するグループの外に集団を即座に送信できるため、一連の有用な状態の開始点となります。 
3. マークされたメンバーから逆方向のグラフをたどります。 出発するメンバーがすでにマークされているメンバーに到達できる場合は常に、そのメンバーもマークします。 この横断の後、マークされたメンバーは一般の学生への方向付けられたパスを持ちますが、マークされていないメンバーはすべて、一般の学生が決して到達できない領域に閉じ込められます。 
4. マークされた離脱メンバーごとに 1 つの線形方程式を作成します。 (x_i) がそのメンバーを通過した合計金額を表すものとします。 (i) のマークが付いたそれぞれについて、次のように書きます。 

[
 x_i-\sum_{j\text{ マーク付き}}x_jp_{j,i}=L_i。 
】

 マークのないメンバーから送信された確率は表示されません。そのメンバーは最終回答に決して貢献できないためです。 

1. 結果として得られるシステムをガウス消去法で解きます。 浮動小数点計算をより安定させるために、部分ピボットを使用します。 右側は 1 つだけなので、通常の消去とその後の後方置換で十分です。 
2. 脱退するメンバー全員の答えをゼロに設定します。 これらのロリポップは中間的な数量であり、最終的な受け取り者ではありません。 
3. 受取人 (k) が一般学生であるすべての遺言書 ((i,k,p)) について、(k) の答えに (x_i p) を追加します。 これにより、各脱退メンバーがこれまでに処理した合計金額が、最終的に脱退グループ外に配信された金額に直接変換されます。 
4. すべて (M 個) の回答を学生 ID の昇順に印刷します。 必要な精度は (10^{-5}) であるため、小数点以下の数桁を出力するだけで十分です。 

これが機能する理由: 中心的な不変条件は、(x_i) が単に現在そこに保持されている量ではなく、メンバー (i) によって処理されるすべてのロリポップを表すということです。 このようなロリポップはすべて、(i) が最初に所有していた (L_i) のいずれか、または別の脱退メンバー (j) から (x_jp_{j,i}) の量で到着したものです。 したがって、この線形方程式は無限プロセスを正確に特徴づけます。 普通の学生に到達できる状態の場合、繰り返し適用すると、最終的にその確率質量のすべてが出発状態から転送されるため、対応するサブシステムは固有の有限解を持ちます。 通常の学生に到達できない状態は、他のそのような状態を循環または供給することしかできず、その質量は問題で指定されたとおりに正確に破棄されます。 (x_i) の値がわかったら、それぞれの値にその分数を乗算することで、すべての最終転送が 1 回だけ行われることになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    initial = [0.0] * n
    wills = [[] for _ in range(n)]
    rev = [[] for _ in range(n)]

    for i in range(n):
        l, k = map(int, input().split())
        initial[i] = float(l)

        entries = []
        for _ in range(k):
            x, p = input().split()
            x = int(x) - 1
            p = float(p)
            entries.append((x, p))

            if x < n:
                rev[x].append(i)

        wills[i] = entries

    # Find all departing members that can eventually reach
    # at least one ordinary student.
    useful = [False] * n
    stack = []

    for i in range(n):
        for x, p in wills[i]:
            if x >= n:
                if not useful[i]:
                    useful[i] = True
                    stack.append(i)
                break

    while stack:
        v = stack.pop()
        for u in rev[v]:
            if not useful[u]:
                useful[u] = True
                stack.append(u)

    ids = [i for i in range(n) if useful[i]]
    s = len(ids)

    ans = [0.0] * m

    if s:
        pos = [-1] * n
        for i, v in enumerate(ids):
            pos[v] = i

        # A[i][j] = delta(i,j) - probability(j -> i)
        a = [[0.0] * (s + 1) for _ in range(s)]

        for i, v in enumerate(ids):
            a[i][i] = 1.0
            a[i][s] = initial[v]

        for u in ids:
            pu = pos[u]
            for v, p in wills[u]:
                if v < n and useful[v]:
                    pv = pos[v]
                    a[pv][pu] -= p

        # Gaussian elimination with partial pivoting.
        for col in range(s):
            pivot = col
            best = abs(a[col][col])

            for row in range(col + 1, s):
                value = abs(a[row][col])
                if value > best:
                    best = value
                    pivot = row

            if pivot != col:
                a[col], a[pivot] = a[pivot], a[col]

            inv = 1.0 / a[col][col]

            # Normalize the pivot row.
            row = a[col]
            for j in range(col, s + 1):
                row[j] *= inv

            # Eliminate below.
            for row_idx in range(col + 1, s):
                row2 = a[row_idx]
                factor = row2[col]
                if factor == 0.0:
                    continue

                row2[col] = 0.0
                for j in range(col + 1, s + 1):
                    row2[j] -= factor * row[j]

        x = [0.0] * s

        # Back substitution.
        for i in range(s - 1, -1, -1):
            value = a[i][s]
            row = a[i]
            for j in range(i + 1, s):
                value -= row[j] * x[j]
            x[i] = value

        # Distribute the total amount processed by each useful
        # departing member to ordinary students.
        for i, v in enumerate(ids):
            amount = x[i]
            for to, p in wills[v]:
                if to >= n:
                    ans[to] += amount * p

    sys.stdout.write("\n".join(f"{v:.10f}" for v in ans))

if __name__ == "__main__":
    solve()
```最初の部分には、最初のロリポップの数と遺言が保存されます。 の`rev`グラフには、離脱メンバー間のエッジのみが含まれています。これは、状態が最終的に普通​​の学生に逃れられるかどうかの決定に関連する唯一のエッジであるためです。 

逆走査は、ステップ 2 と 3 を実装します。メンバーは、その意志が一般の学生に直接影響する場合、最初は役に立ちます。 逆エッジをたどると、最終的にこれらの有用なメンバーの 1 つに到達できるすべてのメンバーが見つかります。 これは、閉じたサイクルを明示的に検出しようとするよりも望ましい方法です。 メンバーが無関係であるためには、強く接続されたコンポーネントに属している必要はありません。 必要な唯一のプロパティは、最終受信者へのパスがあるかどうかです。 

マトリックスは次の方程式を使用します。 

[
 x_i-\sum_j x_jp_{j,i}=L_i。 
】

 これは、行列の向きが少し直感的ではないことを説明しています。 (j) が (i) に向かうという意志に格納された確率は、行 (i)、列 (j) に属します。 対角線は 1 から始まり、入ってくる遷移ごとにその確率が減算されます。 

ガウス消去では、各ピボット行を正規化し、それより下のすべての行からピボット係数を削除します。 部分ピボットでは、現在の列で使用可能な最大の係数が選択され、確率によってシステムの条件が悪くなった場合の数値誤差が減少します。 行列には最大 500 行があるため、密な表現はメモリ制限に対して十分小さいです。 

逆置換により、有効な各離脱メンバーによって処理された合計量 (x_i) が回復されます。 その後、遺言書の原本を再度スキャンして送信します。`amount * p`すべての一般的な受信者に。 卒業する生徒の要求する成果はゼロであるため、私たちは意図的に何も追加しません。 

Python では整数オーバーフローの問題はありません。 潜在的に大きな中間値は浮動小数点量であり、最小の正の確率は (10^{-6}) のみであるため、倍精度により、目的のシステムで必要な (10^{-5}) の出力許容誤差に対して十分な相対精度が得られます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(N^3+K+M)) | 線形システムには最大 (N=500) 個の変数が含まれますが、遺言には (K\le10^6) 個のエントリが含まれます。 
| スペース | (O(N^2+K+M)) | 密行列には (O(N^2))、保存された意志には (O(K))、出力には (O(M)) が必要です。 

(N\le500) の場合、ガウス消去法の三角形構造を利用した後、3 次部分には最大でもおおよそ (500^3/3) 個の消去更新が含まれます。 100 万件の入力は直線的に処理されます。 これは、学生と意志のエントリの総数が大きくなる可能性があるにもかかわらず、再帰的に対話する人々の数が少ないという問題の設計と一致します。 公式の制限は、1024 MB のメモリで 7 秒です。

# The helper above needs stdout captured as well.
def run(inp: str) -> str:
    global input
    old_stdin = sys.stdin
    old_stdout = sys.stdout

        sys.stdout = io.StringIO()
        input = sys.stdin.readline
        solve()
        return sys.stdout.getvalue()
