 ## 解決策
 ## 問題の理解

 1 から n までの番号が付けられたリンゴの列が与えられます。 各リンゴは、アーサーまたはアレクサンダーの 2 匹のハムスターのうちの 1 匹に与えることができます。 唯一の制限は、アーサーは自分の好きなリンゴだけを受け取らなければならず、アレクサンダーは自分の好きなリンゴだけを受け取らなければならないということです。 両方のハムスターが好むリンゴもあり、それらはどちらのハムスターにも与えられますが、それでもどちらか一方だけです。 

私たちの仕事は、両方の優先リストを尊重しながら、すべてのリンゴを 1 匹のハムスターに割り当てることです。 入力により n が与えられ、次に Arthur が好むインデックスのリストと Alexander が好むインデックスのリストが与えられます。 所有権を示す 1 と 2 からなる長さ n の文字列を出力する必要があります。 

制約は小さく、n は最大 100 です。これにより、O(n²) またはブルート割り当て戦略でも十分に高速であることがすぐにわかります。 高度なデータ構造や最適化のテクニックは必要ありません。 問題は基本的に、重複を一貫して解決することです。 

重要な微妙な点は、どちらのリストにも属さないリンゴです。 このステートメントは解決策が存在することを保証しますが、単純な実装ではこれらのケースが無視されたり、決定論的に割り当てられなかったりする可能性があります。 

2 番目の微妙なケースは、設定間の重複です。 リンゴが両方のハムスターに好かれている場合、それを任意に割り当てることはまだ機能しますが、不用意に「バランス」または「最適化」しようとすると、誤っていくつかのリンゴが割り当てられないままになる可能性があります。 

## アプローチ

 ブルートフォースの観点では、2 匹のハムスターに対する n 個のリンゴの可能な割り当てをすべて試して、妥当性をチェックすることになります。 各リンゴには 2 つの選択肢があるため、2^n 個の割り当てがあります。 課題ごとに、リンゴが嫌いなハムスターにはリンゴを与えないことを確認します。 検証コストは O(n) なので、総作業量は O(n・2^n) となり、n = 100 の場合でも不要になります。 

問題の構造により、個々の互換性を超えたグローバル制約の相互作用がないため、総当り攻撃が過剰になります。 それぞれのリンゴは独立しています。 つまり、検索する必要はまったくありません。 リンゴごとにローカルに割り当てるだけで済みます。 

重要な観察は、すべてのリンゴが 3 つのカテゴリのいずれかに分類されるということです。つまり、アーサーのみが好む、アレクサンダーのみが好む、または両方が好む (またはどちらも好まない) ということです。 このステートメントは解決策の存在を保証するため、どちらにも好まれないリンゴが問題のある形で存在してはなりません。そうでない場合は、有効性を損なうことなく任意に割り当てることができます。 したがって、各ポジションは独立して決定できます。 

これにより、問題は単純なスキャンに短縮されます。リンゴごとに、それを好むハムスターに割り当てます。 両方とも気に入っている場合は、一貫してまたは任意に選択してください。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n・2^n) | O(n) | 遅すぎる |
 | 貪欲な割り当て | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. n、a、b、および 2 つの設定リストを読み取ります。 

設定リストを高速検索構造に変換して、メンバーシップを一定時間でテストできるようにします。 
2. 2 つのブール配列またはセットを作成します。1 つはアーサーの好きなリンゴ用、もう 1 つはアレクサンダーの好きなリンゴ用です。 

これにより、リンゴごとに O(1) のメンバーシップ チェックが保証されます。 
3. 長さ n の応答配列を初期化します。 
4. 1 から n までのすべてのリンゴを繰り返します。 

それぞれのリンゴについて、好みのみに基づいて所有者を決定します。 
5. リンゴがアーサーに好まれ、必ずしも制限されない場合は、それをアーサーに割り当てます (出力 1)。 

この選択は重複する場合には任意ですが、一貫性があり安全です。 
6. それ以外の場合は、それを Alexander (出力 2) に割り当てます。 

入力によって実現可能性が保証されるため、すべてのリンゴが少なくとも 1 匹のハムスターに気に入られる必要があるため、このフォールバックは常に有効です。 
7. 結果の割り当てを印刷します。 

### なぜ効果があるのか

正しさは決定の独立性から生まれます。 各リンゴは他のリンゴに依存しません。 唯一の制約はローカル妥当性です。アーサーに割り当てられたリンゴはアーサーのセット内に存在する必要があり、アレクサンダーについても同様です。 リンゴを好むハムスターにのみリンゴを割り当てるため、すべての制約が満たされます。 リンゴを嫌いなハムスターにリンゴを割り当てることはないので、重複によって衝突が生じることはありません。 各リンゴは正確に 1 回処理され、すぐに割り当てられるため、後で矛盾が発生する可能性はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, a, b = map(int, input().split())

arthur = set(map(int, input().split()))
alex = set(map(int, input().split()))

res = []

for i in range(1, n + 1):
    if i in arthur:
        res.append("1")
    else:
        res.append("2")

print(" ".join(res))
```### 実装メモ

 メンバーシップ チェックにセットを使用するのは、平均 O(1) ルックアップが得られ、解が線形に保たれるためです。 

決定ルールは可能な限りアーサーを優先します。 これは任意です。 メンバーシップの制約を尊重する限り、Alexander を最初に選択することも機能します。 

ステートメント形式の要求に応じて、スペースで区切られた文字を出力します。 

## 実用的な例

 入力:```

 アーサー = {1, 2}
