 ## 解決策
 ## 問題の理解

 英小文字のみで構成される文字列が与えられます。 1 回の操作で、文字列の連続したセグメントを選択して反転することも、文字列を変更しないままにすることもできます。 目標は、このような反転を 1 回だけ使用して生成できる辞書編集上最小の文字列を取得することです。 

ここでの辞書編集上の順序は辞書の順序と同じように動作します。2 つの文字列を左から右に比較し、それらが異なる最初の位置によってどちらが小さいかが決まり、前のアルファベット文字ほど小さくなります。 

入力には複数のテスト ケースが含まれており、テスト ケース全体のすべての文字列の合計長は最大約 150 万文字と大きくなります。 これにより、すべての部分文字列を列挙することはテスト ケースごとに 2 次的であり、時間制限を数桁超えてしまうため、可能なすべての反転を明示的に試みるアプローチは即座に除外されます。 

単純な間違いは、スワップやローカルの改善だけを考えることから生じます。 たとえば、入力時`ba`、文字列全体を反転すると、`ab`、これは最適ですが、次のようなものです`abac`、全体的な戦略を持たずに任意のセグメントを反転すると、小さなキャラクターを左端に移動することが、たとえ中央を妨げたとしても有益な場合があるということを見逃してしまう可能性があります。 

もう 1 つの微妙な失敗ケースは、局所的に良好な反転が全体的には最適ではない場合に発生します。 たとえば、`cab`、後進のみ`ca`与える`acb`これは最適ですが、長い文字列では、戦略が全体的な最小性を保証しない限り、初期の改善を貪欲に選択すると、後のより良い改善が妨げられる可能性があります。 

最大の問題点は、1 回の反転が 3 つの領域 (セグメントの前のプレフィックス、反転されたセグメント自体、およびその後のサフィックス) に同時に影響することです。 サフィックスは変更されませんが、反転されたセグメントの順序が内部で変更されるため、すべての部分文字列に対する総当たり推論のコストが高くなります。 

## アプローチ

 ブルートフォースソリューションでは、すべてのペアが試行されます。`(l, r)`そのセグメントを反転した後に結果の文字列を計算し、最小値を選択します。 がある$O(n^2)$このようなペアと各反転コスト$O(n)$実現するため、全体の複雑さは次のようになります。$O(n^3)$文字通りに、あるいは少なくとも$O(n^2)$綿密なシミュレーションを行います。 と$n$まで$10^5$、これは不可能です。 

文字列を完全に再構築せずに候補を比較するだけで最適化したとしても、依然として次のような問題に直面します。$O(n^2)$最悪の場合、各比較には直線的な時間がかかる可能性があります。 したがって、セグメントの列挙を完全に回避する方法が必要です。 

重要な観察は、辞書編集上の順序ができるだけ早く決定されるということです。 私たちは、文字列が小さくなる可能性がある最初の位置を改善することだけに関心があります。 これは、1 回の反転でより優れたキャラクターを前面に出すことができる最も早いインデックスに焦点を当てる必要があることを示唆しています。 

ポジションを固定したら`i`、唯一の有用な操作は、サフィックスから文字を取得することです。`[i+1, n-1]`位置を決める`i`その文字で終わるセグメントを反転することによって。 反転後、その選択した文字が位置の新しい値になります。`i`。 

したがって、戦略は次のようになります。各位置について、文字列の後ろに小さな文字が存在するかどうかを尋ねます。 「はい」の場合、そのような最小の文字が必要であり、その出現の中で最も右の文字が優先されます。これは、右端の出現に戻すと、将来の選択を制限することなく、以前の位置の辞書編集上の改善が最大化されるためです。 

これにより、問題は、すべてのサフィックスについて、最小の文字とその出現位置を追跡することになります。

 ## アルゴリズムのチュートリアル

 反転を実行する必要があるかどうか、実行する場合はどこで実行するかを決定することで、答えを構築します。 

1. すべてのポジションの事前計算`i`で始まるサフィックスの最小文字`i`、この最小の文字が表示される最後の位置も表示されます。 これは、最小限の文字と代表的なインデックスの両方を維持できるように、右から左に行われます。 これにより、その位置で逆転を開始した場合に、前方に持ち込める最高のキャラクターに即座にアクセスできるようになります。`i`。 
2. 文字列を左から右にスキャンします。 位置で`i`、 比較する`s[i]`で始まるサフィックスの最小文字`i + 1`。 接尾辞に厳密に小さい文字が含まれている場合、位置`i`小さなキャラクターを前面に出すことで改善できます。 
3. 最初の位置を見つけたら`i`改善が可能な場合は、最適な文字列がこの位置から始まる元の文字列と異なる必要があるという決定を修正します。 これは、辞書編集的に小さい結果は、可能な限り最も早い不一致点を減らす必要があるためです。 
4. サフィックスに最適な文字を次のようにします。`c`、そしてさせてください`j`～の最後の出現となる`c`。 の部分文字列を反転します。`i`に`j`。 これは動きます`c`位置を決める`i`そして、その間にあるすべてのものを逆の順序で 1 ステップ右にシフトします。 
5. この 1 回の反転を実行した後、結果の文字列を出力します。 ポジションがない場合`i`改善できる場合は、元の文字列を出力します。 

なぜそれが機能するかというと、最初の異なる位置を制御することにあります。 有効な最適解は、ある位置までは元の文字列と一致する必要があります。`i`そして、どちらかを維持します`s[i]`またはもっと小さいものに交換してください。 したがって、置換が可能な最も早いインデックスが唯一の意味のある決定点となります。 ポジションを改善することを選択したら`i`、それを占有することができる最小の文字が必要であり、それを右端の出現から配置することで、文字列の前半でさらに優れた構成を誤って妨げることがなくなります。 以前のインデックスを変更したり、より大きな文字を使用したりする代替の反転では、辞書編集的にこの構造よりも小さな結果を生成することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(s: str) -> str:
    n = len(s)
    if n <= 1:
        return s

    suf_min = [''] * n
    suf_pos = [0] * n

    suf_min[-1] = s[-1]
    suf_pos[-1] = n - 1

    for i in range(n - 2, -1, -1):
        if s[i] < suf_min[i + 1]:
            suf_min[i] = s[i]
            suf_pos[i] = i
        elif s[i] > suf_min[i + 1]:
            suf_min[i] = suf_min[i + 1]
            suf_pos[i] = suf_pos[i + 1]
        else:
            suf_min[i] = s[i]
            suf_pos[i] = suf_pos[i + 1]

    s = list(s)

    for i in range(n - 1):
        if suf_min[i + 1] < s[i]:
            j = suf_pos[i + 1]
            s[i:j + 1] = reversed(s[i:j + 1])
            return ''.join(s)

    return ''.join(s)

def main():
    t = int(input())
    for _ in range(t):
        s = input().strip()
        print(solve(s))

if __name__ == "__main__":
    main()
```このソリューションは、各位置の右側にある利用可能な最小の文字と、その文字が出現する位置の両方を追跡する接尾語構造を構築します。 これにより、インデックスごとにスキャンを再計算する必要がなくなります。 

辞書編集上の最小化は文字を削減できる最も早い位置に依存するため、最初の改善ポイントのスキャンは非常に重要です。 見つかったら、すぐに反転を適用して停止します。これは、後で変更すると、より大きなプレフィックスが変更されないままになり、結果が悪化するためです。 

反転自体はリストの Python スライスを使用します。これはテスト ケースごとに最大 1 回しか発生しないため、十分効率的です。

        if n <= 1:
            return s

                suf_min[i] = suf_min[i + 1]
                suf_pos[i] = suf_pos[i + 1]
