 ## 解決策
 ## 問題の理解

 単一の正の整数が与えられます$X$, そして、2つの条件を同時に満たす数値を構成するように求められます。 まず、次で割り切れる必要があります。$X$。 次に、それは完全二乗でなければなりません。つまり、素因数分解の指数がすべて偶数であることを意味します。 

このタスクについての別の考え方は、次のことを掛け算することができるということです。$X$何らかの正の整数によって$k$の可能な限り小さな値が必要です。$X \cdot k$結果が完全な正方形になるようにします。 

制約$X \le 10^9$これは、倍数を反復したり正方形を上方に検索したりすることに依存するアルゴリズムを許容できないことを意味します。 チェックのような素朴なスキャン$X, 2X, 3X,\dots$そして、最小の平方倍数はそれよりもはるかに大きい可能性があるため、それぞれが正方形であるかどうかをテストすることは、最悪の場合には非常に遅くなります。$X$、特に次のような場合に$X$には多くの異なる素因数があります。 

あまり目立たない困難が現れるのは、$X$スクエアフリーまたはスクエアフリーに近い。 たとえば、次のようなとき$X = 30$、答えは$900$、すでに 30 倍の大きさです$X$。 直線的に検索しようとすると、妥当な制限時間をすぐに超えてしまいます。 

重要なエッジ ケースの構造は、答えが加算パターンや割り算パターンからではなく、素因数分解における指数のパリティから導出されるということです。 因数分解を無視する素朴なメソッドは、次のような場合に失敗します。$X = 12$、答えはどこにありますか$36$、 ない$12$または$24$、構造的な理由がなければ、正しい乗数は明らかではありません。 

## アプローチ

 ブルートフォースアプローチは以下から始まります$X$そして小切手$X \cdot 1, X \cdot 2, X \cdot 3,\dots$、各値が完全な平方であるかどうかをテストします。 各チェックでは、整数の平方根を計算するか、整数の 2 乗が数値と等しいかどうかを検証する必要があります。 最悪の場合、正解ははるか遠くにある可能性があるため、これは広範囲の整数をスキャンすることになり、簡単に範囲を超えます。$10^9$操作。 

構造観察は素因数分解から得られます。 数値は、因数分解のすべての素指数が偶数である場合に限り、完全な平方になります。 書くとしたら$X$素数と指数の積として、どの素数がこの条件に違反するかを正確に確認できます。 奇数の指数を持つ各素数は、指数を偶数にするために、それ自体のもう 1 つのコピーと組み合わせる必要があります。 つまり、単に乗算するだけで済みます$X$すべての指数のパリティを固定する最小係数によって。 

これにより、問題が決定論的な構造に変わります: 因数分解$X$、指数が奇数の素数をすべて集めて、それらを 1 回掛け合わせます。 この積は、すべての指数を偶数にし、最小二乗倍を生成する最小の数です。

 ## アルゴリズムのチュートリアル

 1.因数分解$X$約数をテストすることで、$\sqrt{X}$。 各約数について$p$、分割を繰り返します$X$による$p$その指数を数えます。 これは素数構造が正方形性を決定するため必要です。 
2. 1 に初期化された実行結果を維持します。この変数には、指数のパリティを修正するために必要な最小の乗数が格納されます。 
3. 各素因数について$p$、何回に分割されるかを確認します。$X$。 指数が奇数の場合は、結果に次の値を掛けます。$p$。 のコピーを 1 つ追加するため、これによりパリティが修正されます。$p$奇数の指数を偶数の指数に変換します。 
4. 以下のすべての素数を処理した後、$\sqrt{X}$、残っている場合は、$X$が 1 より大きい場合、指数 1 の素因数です。これは常に奇数なので、結果にこの残った素数を掛けます。 
5. 原本を返却する$X$計算された補正係数が乗算され、完全な二乗になることが保証されます。 

ステップ 4 の背後にある推論は重要です。つまり、以下より大きい素数はすべてです。$\sqrt{X}$は 2 回出現できないため、指数は正確に 1 でなければなりません。これにより、自動的に奇数になります。 

### なぜ効果があるのか

 すべての整数には固有の素因数分解があります。 この因数分解のすべての指数が偶数である場合に限り、数値は完全二乗になります。 このアルゴリズムは、各奇数指数を独立して 1 回正確に修正することによって、すべての指数を偶数にする最小の乗数を構築します。 異なる素数間には相互作用が存在しないため、乗数を最小化すると局所的なパリティの修正が行われます。 奇数の素因数をそれぞれ 1 回ずつ加算するだけなので、結果として得られる積は可能な限り最小の補正係数になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())
    original = x
    res = 1

    i = 2
    while i * i <= x:
        if x % i == 0:
            cnt = 0
            while x % i == 0:
                x //= i
                cnt += 1
            if cnt % 2 == 1:
                res *= i
        i += 1

    if x > 1:
        res *= x

    print(original * res)

if __name__ == "__main__":
    solve()
```この解決策は、標準的な試行除算因数分解ループに依存します。 変数`res`元の入力の因数分解で奇数回出現する素数を正確に累積します。 

微妙な点は、元の値を保存する必要があるということです。$X$因数分解の前にそれは 1 に減ります。最後の乗算では元の値が使用されます。`x`因数分解時に減算された余りになります。

 ## 特殊なケース

 のために$X = 1$、因数分解ループは何も行わず、`res`は 1 のままなので、出力は次のようになります。$1$。 アルゴリズムは 1 を完全な正方形として正しく処理します。 

次のような素数の場合$X = 2$、因数分解すると指数 1 が得られるため、`res`が 2 になり、結果は次のようになります$2 \cdot 2 = 4$、これは最小の平方倍数です。 

のような数値の場合$X = 18 = 2 \cdot 3^2$、素数 2 のみが奇数の指数を持ちます。 アルゴリズムは 2 を乗算し、$36$、どの正方形にも少なくとも次の要素が含まれている必要があるため、これより小さい正方形の倍数は存在しません。$2^2$。 

のような完全な正方形の場合$X = 49$、すべての指数は偶数であるため、`res = 1`そして出力は変化しません。
