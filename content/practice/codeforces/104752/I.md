 ## 解決策
 ## 問題の理解

 各ゲームは次のシーケンスで構成されます。$N$一致します。 スコアは 1 から始まり、一致するたびに現在のスコアに次のいずれかが乗算されます。$A$、それを乗算します$B$、誰も問題を解決しない場合は変更しないままにします。 

重要な点は、単一のシーケンスを選択しているわけではないということです。 試合を独立して解決できるあらゆる可能な方法を検討する必要があります。各試合には 3 つの可能性がありますが、そのうち 2 つはスコアに影響します。 少なくとも 1 つの試合が別の人によって解決された場合、2 つのゲームは異なるものとみなされます。 

このような結果の完全なシーケンスごとに、最終スコアを計算し、考えられるすべてのシーケンスにわたってこれらのスコアを合計します。 

入力には複数のテスト ケースが含まれており、それぞれのテスト ケースは次のようになります。$N$、$A$、 そして$B$。 すべての有効な結果シーケンスのスコアの合計を法で出力する必要があります。$10^9 + 7$。 

制約により、最大で$10^5$テストケースと$N$まで$1000$。 これにより、結果を列挙しようとするソリューションは即座に除外されます。単一のテスト ケースであっても、$3^N$可能性。 代わりに、ソリューションではポジションごとの貢献を集約するか、閉じた形式の組み合わせ構造を使用する必要があります。 

微妙なエッジケースが現れるのは、$A = B = 1$。 この場合、すべてのシーケンスがスコア 1 を生成するため、答えは正確にシーケンスの数になります。$3^N$。 で割る導出$A - B$または、チェックなしの可逆性はここで失敗すると仮定します。 もう一つのエッジケースは、$A = B \neq 1$、対称性が構造を崩壊させ、キャンセルを伴う素朴な公式が再び壊れます。 

## アプローチ

 ブルートフォース解釈では、各試合は、フランコが解決する、ラファが解決する、または誰も解決しないという 3 つの結果から独立して選択するものとして扱われます。 固定シーケンスの場合、スコアはシーケンスに沿った寄与の積です。 これは直接的に次のことにつながります$3^N$シーケンス、それぞれに必要な$O(N)$乗算して評価することは、たとえ$N = 30$。 

重要な観察は、乗算が独立した選択に分散されるということです。 完全なシーケンスについて考える代わりに、すべてのシーケンスにわたって独立した要素に寄与する各一致について考えることができます。 各一致について、3 つの選択肢にわたる寄与を効果的に合計しています。$A$、乗算します$B$、または 1 を掛けます。 

これは、すべてのシーケンスを展開すると、合計が因数分解されることを意味します。 各位置は、すべての選択肢にわたる局所的な寄与の合計に等しい乗法係数に寄与します。選択肢は位置間で独立しているため、全体的な答えはその局所的な合計の累乗になります。 

各試合で、合計額に寄与する可能性があるのは次のとおりです。 

誰も解決しない場合は - 1、
 -$A$フランコが解決したら、
 -$B$ラファが解決したら。 

したがって、各ポジションが要因に寄与します$1 + A + B$。 すべての位置は独立しているため、すべてのシーケンスの合計は次のようになります。$$(1 + A + B)^N.$$これにより、問題全体が高速なべき乗剰余演算に帰着します。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(3^N \cdot N)$|$O(1)$| 遅すぎる |
 | 最適 |$O(T \log N)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### べき乗剰余による最適な計算

 1. 各テスト ケースについて、次の内容を読んでください。$N$、$A$、 そして$B$。 問題の構造全体は、式を介してこれらの値にのみ依存します。$1 + A + B$。 
2. 基本値を計算します$x = (1 + A + B) \bmod (10^9 + 7)$。 これは、考えられるすべての結果を合計した後の 1 つの試合の合計貢献度を表します。 
3. コンピューティング$x^N \bmod (10^9 + 7)$2進累乗を使用します。 このステップでは、すべての一致の独立した寄与を集計します。 
4. 結果を出力します。 

直接乗算するため、2 進のべき乗が必要です。$N$時間が大規模には遅すぎる$N$そしてそれを繰り返しました$10^5$テストケース。 

### なぜ効果があるのか

 各試合は、すべての完全なゲーム構成に独立して寄与します。 すべての構成を合計すると、実質的に同じ合計の積が拡張されます。$$\prod_{i=1}^{N} (1 + A + B).$$役職間に相互作用がないため、他の役職の決定に依存する任期はありません。 この独立性により、位置間の乗算により、シーケンスを過剰にカウントしたり欠落したりすることなく、完全な組み合わせ展開が正しく再構築されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    while e:
        if e & 1:
            res = (res * a) % MOD
        a = (a * a) % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    base = (1 + a + b) % MOD
    print(modexp(base, n))
```中心となるアイデアは、組み合わせプロセス全体を 1 つのべき乗計算に縮小することです。 機能`modexp`バイナリ累乗を実装し、テスト ケースごとの対数時間を確保します。 

よくある落とし穴は、中立的な「解決しない」という結果を忘れることです。$1$基地内で。 それを逃すとコンピューティングにつながる$(A + B)^N$、一致がスキップされたすべてのシーケンスを少なくカウントします。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    MOD = 10**9 + 7

    def modexp(a, e):
        res = 1
        while e:
            if e & 1:
                res = (res * a) % MOD
            a = (a * a) % MOD
            e >>= 1
        return res

    t = int(sys.stdin.readline())
    for _ in range(t):
        n, a, b = map(int, sys.stdin.readline().split())
        base = (1 + a + b) % MOD
        output.append(str(modexp(base, n)))

    return "\n".join(output)

 ## 特殊なケース

 いつ$A = 0$そして$B = 0$、「解決なし」の結果のみが寄与します。 底は1になるので、答えは次のようになります。$1^N = 1$。 アルゴリズムは、基本計算を通じてこれを直接処理します。 

いつ$A = B = 1$、すべての一致は均等に寄与し、基数は 3 になります。答えは次のとおりです。$3^N$、すべての可能な結果シーケンスの数と一致します。 対称性を誤って単純化するアプローチは、これを誤って 1 または 1 に折りたたむ可能性があります。$2^N$ただし、べき乗の公式では正確さが保たれます。 

いつ$A$そして$B$が大きい場合、モジュラーリダクションは基底計算時とべき乗ステップ中にのみ発生します。 すべての演算は全体的にモジュール化されているため、オーバーフローが回避され、中間値は制限されたままになります。
