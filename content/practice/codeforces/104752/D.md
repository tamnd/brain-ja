 ## 解決策
 ## 問題の理解

 小文字のラテン文字で構成される 1 つの文字列が与えられますが、入力形式の例では数字や他の文字も含まれる場合があるため、文字列を一連の記号として扱います。 この文字列から、複数の文字セットを選択し、それらを任意の順序で並べ替えることができます。 目的は、回文に並べ替えることができるこれらの文字の空でない選択が存在するかどうかを判断することです。 

回文には、中心周りの対称性が必要です。 この対称性により、各キャラクターが何回出現できるかについて厳しい条件が課されます。 キャラクターは反対側でペアを組む必要があり、最大 1 人のキャラクターがペアにならずに中央の位置に残ることが許可されます。 

文字列の長さは最大 100000 であり、これは、どのソリューションも線形時間またはそれに近い時間で実行する必要があることを直ちに示唆しています。 二次または指数関数的なアプローチは不可能です。$O(n^2)$チェックはすでに行われているでしょう$10^{10}$最悪の場合の運用。 

微妙な特殊なケースは、すべての文字を使用する必要がないことです。 これは、文字列全体に対する通常の「周波数パリティ」制約を取り除くため、重要です。 たとえば、一度登場する文字が 1 つだけの場合、それを単純に無視して残りから回文を作成できます。これは、少なくとも 1 つの文字が存在する場合に常に有効です。 もう 1 つの特殊なケースは、すべて異なる文字を含む文字列です。 そこでも、任意の 1 文字を選択して長さ 1 の回文を形成できます。 

すべての文字を使用しなければならないと考えるのは単純な間違いです。 たとえば、入力`abc`すべての文字を使用する必要があると仮定すると、誤って拒否されますが、実際には選択できます。`a`単独で回文を形成します。 

## アプローチ

 ブルートフォース解釈では、文字のすべてのサブセットをテストし、サブセットごとに回文に置き換えることができるかどうかをチェックしようとします。 順序を無視して文字数だけを考慮した場合でも、サブセットの数は$2^n$、これは完全に不可能です$n = 10^5$。 状態空間は指数関数的なままであるため、周波数ベクトルに換算しても役に立ちません。 

重要な点は、文字を自由に破棄できるため、回文を構築するための唯一の要件は、少なくとも 1 つの文字を選択できることであるということです。 任意の 1 文字が、長さ 1 の有効な回文を形成します。 これにより、問題は直ちに解消されます。文字列が空でない限り、答えは常に YES です。 

意図されたより深い視点は、回文の実現可能性はパリティ制約に依存するが、それらの制約は単一の文字出現を選択することで常に満たされるということです。 複数の異なる文字の使用を強制する制限はありません。 

したがって、問題は、入力文字列に少なくとも 1 つの文字が含まれているかどうかをチェックすることに帰着します。これは、制約が与えられた場合に常に真となります。

 ## アルゴリズムのチュートリアル

 ### 最適なアイデア

 1. 入力文字列を読み取る$s$。 空かどうかだけを知る必要があります。 
2. もし$s$長さが少なくとも 1 であれば、回文を形成できるとすぐに結論付けられます。 
3. 「はい」と印刷します。 

ステップ 2 の背後にある理由は、単一の文字はすでに回文であるということです。 文字のサブセットを選択できるため、常に 1 つの出現を選択して、長さ 1 の有効な回文を形成できます。 

## なぜ機能するのか

 回文条件では、おそらく 1 つを除くすべての文字が、選択されたマルチセット内で均等な頻度を持つことが必要です。 正確に 1 つの文字を選択した場合、その頻度は 1 であり、それは中央の文字であるため、条件を自明に満たします。 したがって、サイズ 1 の空でないマルチセットはすべて有効です。つまり、空でない入力文字列には有効な選択が自動的に含まれます。 

不変条件は、すべての文字を使用する必要はなく、回文に再配置できる 1 つのサブセットを表示するだけでよいということです。 シングルトンのサブセットは常にこの不変条件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().rstrip("\n")
    if len(s) > 0:
        print("YES")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```ソリューションは入力文字列を読み取り、その長さをチェックします。 文字を破棄する機能によりパリティ制約が簡単になるため、頻度をカウントする必要はありません。 唯一の微妙な点は、改行を正しく削除することです。 それ以外の場合でも、長さチェックは機能しますが、環境によっては改行文字が含まれる可能性があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from sys import stdout
    out = io.StringIO()
    sys.stdout = out

    s = sys.stdin.readline().rstrip("\n")
    print("YES" if len(s) > 0 else "NO")

    sys.stdout = sys.__stdout__
    return out.getvalue().strip()

# provided samples
assert run("3aab\n") == "YES"
assert run("3abc\n") == "YES"
assert run("6aaaaaa\n") == "YES"

# custom cases
assert run("a\n") == "YES", "single character"
assert run("z\n") == "YES", "any single char works"
assert run("1234567890\n") == "YES", "mixed digits still valid"
assert run("\n") == "NO", "empty string"
```| テスト入力 | 期待される出力 | 検証内容 |

 ## 特殊なケース

 空の文字列の場合は、唯一意味のある境界条件です。 入力行が空の場合、長さ 1 の回文でも形成できる文字がないため、アルゴリズムは正しく NO を出力します。 

入力用`"a"`の場合、アルゴリズムは空ではない文字列を読み取り、長さをチェックし、すぐに YES を返します。 選択されたサブセットは`{a}`、回文を形成します`"a"`。 

入力用`"abcde"`の場合、アルゴリズムは完全なセットに対して対称性を強制しようとしないため、再び YES を返します。 代わりに、次のような単一の文字が暗黙的に選択されます。`"c"`そして有効な回文を形成します。 

他のすべてのケースも同じパターンに従い、決定は常に少なくとも 1 つの文字が存在するかどうかによってのみ決定されます。
