 ## 解決策
 ## 問題の理解

 平面内に一連の点が与えられ、それぞれが拡大する円形の「光の球」の源を表します。 すべてのポイントはレベル 1 の大惨事として始まり、その影響は時間の経過とともに一定の割合で均一に外側に拡大します。$M$。 時間に$t$、各点には半径の円盤があります。$M \cdot t$。 

既存の 2 つの大惨事領域が接触または重なり合うと、それらは結合されて 1 つの複合大惨事となり、そのレベルは前の 2 つのレベルの合計となります。 このマージは推移的です。ポイントのグループが 1 つの接続されたクラスターにマージされると、別のクラスターとのさらなる交差によって 2 つのクラスターがマージされ、レベルが追加されます。 

タスクは、少なくとも 1 つの接続されたクラスターの合計レベルが少なくとも 1 つになる最も早い時間を見つけることです。$K$。 各初期点はレベル 1 を持つため、これは、少なくとも$K$ポイント。 

2点の幾何条件$i$そして$j$時に繋がること$t$は：$$M \cdot t \ge \frac{d_{ij}}{2}$$どこ$d_{ij}$点間のユークリッド距離です。 同様に:$$t \ge \frac{d_{ij}}{2M}$$したがって、時間の経過とともにエッジが「アクティブ」になるグラフを効果的に構築し、接続されたコンポーネントがサイズに達する最も早い時間を求めます。$K$。 

制約により、最大で次のことが許可されます。$N = 1000$したがって、完全なグラフには最大約$5 \times 10^5$エッジ。 による解決策$O(N^2 \log N)$または$O(N^2)$構造は与えられたテストケースごとに許容可能です$T \le 200$しかし、定数には注意が必要です。 

微妙なエッジケースは次のような場合です$K = 1$。 この場合、各点は時間 0 ですでにレベル 1 の災害を形成しているため、答えは常に 0 になります。 

もう 1 つの特殊なケースは、ポイントが非常に近いか同一である場合です。 2 つの点が一致する場合、距離はゼロであるため、時間 0 で即座にマージされます。これは、union-find が重みゼロのエッジを正しく処理する必要があることを意味します。 

## アプローチ

 ブルートフォースのアイデアは、時間を継続的にシミュレートし、特定の時点でどの点が接続されているかを繰り返し再計算することです。$t$。 固定の場合$t$、距離が最大で次のすべてのペアを接続するグラフを構築できます。$2Mt$次に、DFS または Union-find を実行してコンポーネントのサイズを計算し、サイズに達したコンポーネントがあるかどうかを確認します。$K$。 その後、二分探索を使用して時間をかけて検索することができます。 

これが機能するのは、接続関係が時間的に単調であるためです。つまり、2 つの点が一度接続されると、それらは永久に接続されたままになります。 ただし、総当たりアプローチは各チェックにコストがかかるためコストが高くなります。$O(N^2)$エッジを構築し、$O(N^2)$または$O(N \alpha(N))$コンポーネントを結合します。 浮動時間 (たとえば 60 回の反復) にわたる二分探索では、総コストが最悪の場合には大きすぎます。$T = 200$。 

重要な観察は、実際には時間をシミュレートする必要がないということです。 ポイントの各ペアには固定のアクティブ化時間があります。$$w_{ij} = \frac{d_{ij}}{2M}$$私たちが気にするのはエッジがいつ現れるかだけであり、時間が連続的にどのように進むかではありません。 これにより、問題は重み付けされたエッジを使用した古典的なオフライン接続の問題に変換されます。 すべてのエッジをアクティブ化時刻でソートし、union-find 構造を使用して時間の昇順にコンポーネントをマージします。 マージ中にコンポーネントのサイズを追跡し、コンポーネントがサイズに達した瞬間を追跡します。$K$、現在のエッジ時間が答えです。 

これにより、問題は完全なグラフのクラスカル スタイルの処理に帰着し、必要なコンポーネントが表示されるとすぐに停止します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース + 二分探索 |$O(T \cdot \log R \cdot N^2)$|$O(N^2)$| 遅すぎる |
 | クラスカル + DSU |$O(T \cdot N^2 \log N)$|$O(N^2)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適なアルゴリズム

 1. 各テスト ケースについて、すべての点を読み取り、すべてのペアごとのユークリッド距離を計算します。 これが必要なのは、2 つの球体間で起こり得るすべての相互作用は、それらの幾何学的分離によってのみ決定されるためです。 
2. ペアごとに$i, j$、球が最初に接触した時間を計算します。$$t_{ij} = \frac{\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}}{2M}$$これにより、継続的な成長プロセスが、ペアごとに 1 つの個別のイベント セットに変換されます。 
3. すべてのエッジを保存する$(t_{ij}, i, j)$リストで。 各エッジは、時間が経過したときの 2 つのコンポーネント間の将来のマージ イベントを表します。$t_{ij}$。 
4. すべてのエッジを昇順に並べ替えます。$t_{ij}$。 これにより、物理的に可能になった正確な順序でマージを処理できるようになります。 
5. 各ポイントがサイズ 1 の独自のコンポーネントで開始する素集合共用体 (DSU) 構造を初期化します。これは、最初はすべての災害がレベル 1 であることを反映しています。 
6. ソートされた順序でエッジをトラバースします。 各エッジについて$(t, u, v)$を含むコンポーネントを結合しようとします。$u$そして$v$。 すでに同じコンポーネント内にある場合は、接続が冗長であるため、スキップしてください。 
7. 2 つのコンポーネントをマージする場合、結果のコンポーネントのサイズを更新します。 いずれかの時点でコンポーネントのサイズが少なくとも$K$、現在の時刻を記録します$t$答えとして、それ以降のエッジの処理を停止します。 
8. テストケースの記録時間を出力します。 

早期に停止できる理由は、コンポーネントがサイズに達すると、$K$、残りのエッジはすべて同じかそれ以上の時間で発生するため、後のエッジはより短い有効時間を生成することはできません。 

### なぜ効果があるのか

 いつでも$t$、エッジによって形成されるグラフ$t_{ij} \le t$どの球が交差したかを正確に表します。 DSU は、エッジが昇順に追加されるときに、このグラフの接続されたコンポーネントを維持します。$t_{ij}$。 コンポーネントのサイズは初期ユニット レベルの正確な合計であるため、サイズに達すると、$K$レベルがあることに正確に対応します$K$大惨事。 エッジの順序が増加して最初にこれが発生する時間は、可能な限り最小でなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, M, K = input().split()
        n = int(n)
        M = float(M)
        K = int(K)

        pts = []
        for _ in range(n):
            x, y = map(int, input().split())
            pts.append((x, y))

        if K == 1:
            print("0.0")
            continue

        edges = []
        for i in range(n):
            x1, y1 = pts[i]
            for j in range(i + 1, n):
                x2, y2 = pts[j]
                dx = x1 - x2
                dy = y1 - y2
                dist = (dx * dx + dy * dy) ** 0.5
                edges.append((dist / (2.0 * M), i, j))

        edges.sort()

        parent = list(range(n))
        size = [1] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return 0
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]
            return size[ra]

        for t, u, v in edges:
            new_size = union(u, v)
            if new_size >= K:
                print(f"{t:.10f}")
                break
        else:
            print("0.0")

if __name__ == "__main__":
    solve()
```この解決策は、幾何学的なエッジのアクティブ化時間を超えたクラスカル スタイルのマージを直接実装することです。 DSU はコンポーネントのメンバーシップを効率的に維持し、サイズ配列は壊滅的なレベルを追跡します。 

実装の微妙な詳細は、浮動小数点平方根を使用してユークリッド距離を計算することです。 必要な精度公差は次のとおりです。$10^{-6}$、標準の浮動小数点演算で十分です。 もう 1 つの重要な点は、早期終了です。有効なコンポーネントが表示されたら、続行すると時間が長くなるだけであり、不要です。

 ## 特殊なケース

 いつ$K = 1$の場合、アルゴリズムはすべてのジオメトリをバイパスし、すぐに 0 を返します。 これは正しいです。なぜなら、各初期点は相互作用なしにすでにレベル 1 の災害を形成しているからです。 

複数のポイントが一致する場合、それらのペアごとの距離はゼロになるため、それらのマージ時間はゼロになります。 DSU は最初のステップでそれらを結合し、より大きなコンポーネントを瞬時に形成します。また、サイズ追跡は、当面の壊滅的な増加を正確に反映します。 

すべてのポイントが遠く離れている場合、非常に長い時間が経過するまでエッジは表示されません。 このアルゴリズムは引き続きすべてのエッジをソートされた順序で処理し、最初に必要なマージが表示された後にのみ戻り、疎な相互作用シナリオでも正確性を保証します。
