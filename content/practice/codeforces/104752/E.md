 ## 解決策
 ## 問題の理解

 この店には単一の固定紙幣があり、すべての商品にはドルで価格が設定されています。 観光客は商品の代金を支払いたいと考えていますが、フアンはその 1 つの額面の紙幣しか使用できません。 タスクは、その合計額が商品価格に達するために必要な請求書の枚数を決定することです。 

各請求書は正確に寄与するため、$A$ドル、私たちは事実上価格を分解しています$B$の倍数に$A$。 価格が正確に割り切れない場合でも、この解釈では不足額の支払いは許可されていないため、価格を完全にカバーするのに十分な請求書が必要になります。 これにより、問題は最小の整数を計算することになります。$k$そのような$k \cdot A \ge B$。 

制約は次のとおりです$10^9$したがって、どのソリューションもテスト ケースごとに一定時間で実行する必要があります。 請求書の追加を反復またはシミュレーションするには、最大で次の時間が必要になります。$10^9$最悪の場合、1 秒の制限をはるかに超えるステップ数になります。 これは、シミュレーションではなく算術を使用して答えを導き出す必要があることを直ちに示唆しています。 

微妙なエッジケースは次のような場合です$B$は正確に割り切れます$A$。 たとえば、次の場合$A = 5$そして$B = 10$、答えは正確に 2 です。$A = 5$そして$B = 11$の場合、2 つの請求書では 10 しか得られず、不十分であるため、答えは 2 ではなく 3 になります。 

別の例外的なケースが発生する場合$A > B$。 例えば、$A = 10$、$B = 3$。 端数支払いは不可能であり、0 枚の請求書では価格をカバーできないため、1 つの請求書が必要です。 

## アプローチ

 ブルートフォースアプローチでは繰り返し減算が行われる$A$から$B$余りが正でなくなるまで。 それぞれの減算が 1 枚の紙幣の使用に対応するため、これは正しいです。 ただし、最悪の場合、$A = 1$そして$B = 10^9$、これには必要です$10^9$反復が遅すぎます。 

重要な観察は、サイズの完全なブロックがいくつあるかを計算していることです。$A$に適合する$B$、残りがある場合は追加のブロックが 1 つ追加される可能性があります。 まさに部門の天井です$B / A$。 これを認識すると、問題は 1 つの整数算術演算に集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース減算 |$O(B/A)$|$O(1)$| 遅すぎる |
 | 天井区分 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 最適な戦略

 1. 整数の読み取り$A$そして$B$。 これらは、固定請求金額と必要な支払い金額を表します。 
2. 次のことを計算します。$B$で割り切れます$A$。 もしそうなら、答えはまさにそのとおりです$B / A$、お札が無駄なくぴったり収まるので。 
3. もし$B$で割り切れない$A$、計算する$B // A + 1$。 整数の除算により、適合する全額の請求書の数が得られ、余分な 1 つで残りの未払い金額がカバーされます。 
4. 計算値を出力します。 

重要な決定点は、残りの処理です。 それを無視すると、支払額が不足することになります。 追加請求額を 1 つだけ超過補正した場合、最小限の超過で常に目標を達成または上回ります。 

### なぜ効果があるのか

 すべての解は整数の選択に対応します$k$そのような$kA \ge B$。 このような整数のセットは次から始まります。$\lceil B/A \rceil$。 より小さい値$k < \lceil B/A \rceil$暗示する$kA < B$、価格をカバーできません。 値を大きくすると、コストが不必要に増加します。 したがって、天井分割は独自の最小有効な選択です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

A = int(input().strip())
B = int(input().strip())

# compute ceiling of B / A
ans = (B + A - 1) // A

print(ans)
```この解決策は、古典的な整数上限トリックに依存しています。 明示的に可分性をチェックする代わりに、恒等式を使用します。$\lceil B/A \rceil = (B + A - 1) // A$。 これにより、分岐が回避され、計算が 1 つの算術式に保持されます。 

分子内で 1 を減算することで、正確な倍数が誤って切り上げられることがなくなります。 たとえば、次のようなとき$B = 10$そして$A = 5$、私たちは得ます$(10 + 4) // 5 = 2$、その間、いつ$B = 11$、私たちは得ます$(11 + 4) // 5 = 3$。
