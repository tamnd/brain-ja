 ## 解決策
 ## 問題の理解

 固定ステップサイズが与えられています$k$。 私たちにも与えられている$n$時間間隔。各間隔は、特定の商品が販売される日数の範囲を表します。 

販売者は、開始日の選択に応じて定期的に表示されます$s$。 選択したら$s$、商人は日に現れる$s, s+k, s+2k,\dots$。 各アイテムは、販売者の訪問日のうち少なくとも 1 日がアイテムの販売間隔内にある場合にのみ購入できます。$[L_i, R_i]$。 

私たちの仕事は開始日を選択することです$s$販売者の訪問数の等差数列ができるだけ多くの品目間隔と交差するようにします。 少なくとも 1 つの一致する値を含む区間の数を最大化したいと考えています。$s \bmod k$。 

これを再構成すると、毎日は剰余剰余によって分類されます。$k$。 選択したら$s$、剰余クラスを修正しています$r = s \bmod k$。 それから商人は、ちょうど次の日に合わせて訪問します。$r$モジュロ$k$そして問題は、剰余のある数値が少なくとも 1 つ含まれる間隔がいくつあるかを数えるということになります。$r$。 

したがって、目標は次のようになります: 残基を選択する$r \in [0, k-1]$間隔の数を最大化する$[L_i, R_i]$に合同な整数を少なくとも 1 つ含む$r \pmod{k}$。 

制約は大きく、最大で$2 \cdot 10^5$間隔と最大値$10^9$したがって、残基ごとのブルートフォースは不可能です。 解決策は、次の場合にすべての残基を明示的に反復することを避けなければなりません。$k$大きいです。 

素朴な推論による微妙な失敗例は、区間の開始点または終了点に最も一致する残基を選択できると仮定した場合です。 たとえば、次のように考えてみましょう$k=3$と間隔$[1,1], [2,2], [3,3]$。 各間隔は「タイト」であり、各残基は正確に 1 つの間隔を捕捉しますが、間隔をわずかにシフトすると、そのようなヒューリスティックが完全に崩れる可能性があります。これは、カバレッジがエンドポイントではなく、間隔に残基クラス内の数値が含まれているかどうかに依存するためです。 

別の失敗例は、1 つの区間が複数の残基をカバーする可能性があるという事実を考慮せずに、区間を残基ごとに独立して寄与するかのように扱うことです。 

## アプローチ

 ブルートフォースのアイデアは単純です。すべての残基を試してください。$r$から$0$に$k-1$。 インターバルごとに$[L, R]$、整数が存在するかどうかを確認します$x$そのような$x \equiv r \pmod{k}$そして$L \le x \le R$。 この条件は、最初の数値が以下に一致するかどうかをチェックすることと同じです。$r$またはその後$L$中にある$R$。 

固定の場合$r$、各区間について、それが以下に含まれるかどうかを計算できます。$O(1)$、したがって、各残差はコストがかかります$O(n)$、につながる$O(nk)$。 これはすぐに失敗します。$k$まで可能です$10^9$、均等にする$10^5$残留は不可能。 

重要な観察は、各間隔が の正確な値を気にしないことです。$r$、剰余のモジュロについてのみ$k$その中に現れます。 各区間はモジュラー円上の連続した範囲に対応しますが、視点を反転することができます。残基を反復する代わりに、各区間をそれがカバーするすべての残基に割り当て、各残基が受け取る区間の数を数えます。 

モジュラー演算の観点から考えると、構造がより明確になります。 しばらくの間$[L, R]$、「悪い」残基は、以下に一致する数がない残基です。$r$間隔の中にあります。 これらはまさに間隔を完全に回避する残基であり、ギャップ パターンを形成します。 カバレッジを直接マークする代わりに、間隔ごとに補体構造を計算できます。不合格となる残基は、その残基の最も近い番号が前にある残基です。$L$またはその後$R$。 

より有用な変換は、各間隔が周期的に剰余に制約を課すことに注目することです。 固定剰余の場合$r$、区間内の最初の候補は次のとおりです。$$x = L + ((r - L) \bmod k)$$もし$x \le R$、その後残留物$r$はこの間隔で有効です。 

この不等式は、モジュロをラップアラウンドする場合を除き、有効な剰余の連続範囲を定義します。$k$。 したがって、各間隔は 1 つまたは 2 つの範囲に寄与します。$[0, k-1]$そして、これらすべての範囲にわたって最大の重複を持つ剰余が必要です。 

各間隔を円の長さの軸上の最大 2 つのセグメントに変換します。$k$次に、すべてのセグメントの端点にスイープ ラインを使用します。 以来$k$が大きい場合、すべての残基ではなくエンドポイントのみを処理します。 

各間隔は最大 2 つのイベントに寄与するため、次のようになります。$O(n)$セグメント。 エンドポイントを並べ替えてスイープすると、最大のオーバーラップ ポイントが効率的に得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 残基に対するブルートフォース |$O(nk)$|$O(1)$| 遅すぎる |
 | 区間から剰余までの掃引線 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各区間を剰余のセットに変換したいと考えています$r$そのような$[L, R]$～に一致する何らかの数字が含まれている$r \pmod{k}$。 

1. インターバルごと$[L, R]$、区間に「ヒット」する可能性のある最初と最後の可能な残基を計算します。 これは条件をマッピングすることで行われます$L \le r + t k \le R$ある整数に対して$t$の制約に$r$。 
2. すべてを見つけるように条件を書き換えます。$r$整数が存在するように$t$と：$$L \le r + tk \le R$$これは、剰余クラスが区間と交差するかどうかを確認することと同じです。 
3. 修正されていることを観察します。$r$、区間内の最小の候補は次のとおりです。$x = L + ((r - L) \bmod k)$。 この値が以内であれば$R$、残差は有効です。 
4. 残基を個別にチェックするのではなく、条件を反転して、どの残基が対象であるかを決定します。$r$ずれた位置は間隔内に収まります。 これにより、モジュール円上に有効な残基の連続セグメントが生成されます。 
5. 間隔ごとに、このセグメントを計算します。 セグメントが折り返さない場合は、次のように直接記録します。$[a, b]$。 ラップする場合は、分割します。$[a, k-1]$そして$[0, b]$。 
6. すべてのセグメントをスイープ イベントに変換します。セグメント開始時に +1、セグメント終了後に -1 となります。 
7. イベントを位置によってソートし、カバレッジを蓄積する残差ライン全体をスイープします。 
8. スイープ中に検出された最大プレフィックス合計が答えです。 

### なぜ効果があるのか

 残留物を修正する$r$。 等差数列の少なくとも 1 つの要素が正確に一致すると、区間の答えに貢献します。$r, r+k, r+2k,\dots$中にある$[L, R]$。 変換により、このメンバーシップ条件が残基の幾何学的区間に変換され、各区間が重複することなく正しい残基セットに正確に寄与することが保証されます。 次に、スイープ ラインは各残基について、その残基が含まれる間隔の数をカウントし、最大の重複は最良の開始残基に正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def add_interval(events, l, r, val, k):
    if l <= r:
        events.append((l, val))
        events.append((r + 1, -val))
    else:
        events.append((l, val))
        events.append((k, -val))
        events.append((0, val))
        events.append((r + 1, -val))

def solve():
    n, k = map(int, input().split())
    events = []

    for _ in range(n):
        L, R = map(int, input().split())

        L_mod = L % k
        R_mod = R % k

        if R - L + 1 >= k:
            events.append((0, 1))
            events.append((k, -1))
            continue

        if L_mod <= R_mod:
            events.append((L_mod, 1))
            events.append((R_mod + 1, -1))
        else:
            events.append((L_mod, 1))
            events.append((k, -1))
            events.append((0, 1))
            events.append((R_mod + 1, -1))

    events.sort()

    cur = 0
    ans = 0
    for pos, delta in events:
        cur += delta
        if cur > ans:
            ans = cur

    print(ans)

if __name__ == "__main__":
    solve()
```コードは各間隔を処理し、それを残差寄与のセットに変換します。 重要な分岐は、間隔の長さが少なくとも$k$なぜなら、すべての剰余クラスが区間内のどこかに現れるため、全範囲に寄与するからです。$[0, k-1]$。 

短い間隔の場合は、モジュール式エンドポイントに依存します。 有効な残基の間隔は、単一の連続セグメントまたはラップアラウンド セグメントのいずれかです。そのため、必要に応じて 2 つに分割します。 

スイープ ラインはすべての寄与を集計します。 ソートにより、剰余位置が順番に処理されることが保証され、実行合計は各剰余をサポートする間隔の数を追跡します。

 ## 特殊なケース

 クリティカルなエッジケースは、間隔の長さが少なくとも$k$。 この場合、すべての残基は間隔内に表示されるため、完全なカバレッジに寄与する必要があります。 たとえば:

 入力:```
1 5
1 100
```アルゴリズムが検出するのは、$R - L + 1 \ge k$フルレンジのカバレッジを割り当てます。 その後、スイープ ラインはすべての剰余を均一に増分し、結果 1 が得られます。 

もう 1 つの特殊なケースは、ラップアラウンド間隔です。 考慮する：```
1 5
4 6
```残差 mod 5:

 - 4 → 0 → 1 の 4 ～ 6 ラップ

 アルゴリズムは [4,4] と [0,1] に分割されます。 スイープ ラインは残基 0 と 4 のカバレッジを正確に蓄積し、有効な一致が失われないことを保証します。
