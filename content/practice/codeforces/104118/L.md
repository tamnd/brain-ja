 ## 解決策
 ## 問題の理解

 係数の下で線形漸化によって生成される決定論的シーケンスが与えられます。 初期値から始める`s`、次のすべての値は、前の値に次の値を乗算することによって生成されます。`a`、追加`b`、そして大きな素数を法として削減します`p`。 これにより、サイズが有限な空間に存在するため、最終的に循環する単一の無限シーケンスが作成されます。`p`。 

各テスト ケースについて、次のような直接的な到達可能性の質問が行われます。`s`、シーケンスが最初にターゲット値に達するまでに必要なトランジションの数`v`、もしそうなった場合。 決して表示されない場合は、不可能であることを報告する必要があります。 

の制約`p`重要です。 以来`p`は最大約 21 億であり、素数であるため、状態空間は十分に大きいため、シーケンスを単純にシミュレートすると非常に高価になる可能性があります。 各テスト ケースでは、最悪の場合、ほぼすべてのテスト ケースを横断する必要がある可能性があります。`p`どちらかを見つける前の状態`v`またはサイクルを検出します。 最大 40 のテスト ケースでは、全空間にわたるリニア スキャンは直ちに実行できなくなります。 

微妙なエッジ ケースは、シーケンスが周期的であるものの、その周期が非常に大きい場合です。 たとえば、たとえ`v`は必ず表示されますが、非常に長いプレフィックスの後にのみ表示される場合があります。 もう 1 つのエッジケースは次のような場合です`v`等しい`s`ここで、正解は 0 であり、次の状態から検索を開始するメソッドは誤ってこれを見逃してしまいます。 

## アプローチ

 直接シミュレーションのアプローチが最も自然な出発点です。 繰り返し再帰を適用し、生成された各値を次の値と比較します。`v`。 これは正しいです。シーケンスは完全に決定的であるため、最初に遭遇したときは`v`最小のインデックスを与えます。 ただし、このアプローチでは、状態空間の大部分をカバーするまでシーケンスが繰り返されない可能性があるため、最悪の場合、テスト ケースごとに O(p) に低下する可能性があります。 

重要な構造的観察は、これが有限体上の線形関数であるということです。 移行`x -> a x + b (mod p)`が全単射の場合`a != 0 (mod p)`、これはここで成立します。`a > 0`そして`p`プライムです。 これは、シーケンスが状態空間の順列であり、方程式を変換するかどうかに応じて、すべての状態が単一のサイクル上にあるか、または尾部のあるサイクル上にあることを意味します。 

やみくもにシミュレーションする代わりに、漸化式を閉じた形式に変換できます。 いつ`a != 1`、シーケンスをシフトして定数項を削除できます。 させて`c = b * (a - 1)^{-1} mod p`、定義します`y_n = x_n - c`。 すると再発はこうなる`y_n = a * y_{n-1} mod p`、これは純粋に乗算です。 これにより、問題は離散対数を解くことになり、最小のものを見つけます。`n`そのような`a^n * (s - c) ≡ (v - c) (mod p)`。 

これはまさにモジュラー離散対数問題であり、O(√p) のベイビーステップ ジャイアントステップで解決できます。 以来`p`は約 2e9、√p は約 46000 であり、これは実現可能です。 

特殊な場合については`a = 1`の場合、再発は純粋に線形になります。`x_n = s + n * b mod p`、そして次の場合には逆モジュラーでそれを解くことができます。`b != 0`。 

したがって、各テスト ケースを離散対数問題またはモジュラー算術方程式のいずれかに縮小します。

 ## アルゴリズムのチュートリアル

 再発の治療法は次のとおりです。`a`1に等しい。 

1.次のことを確認します`a == 1`。 この場合、シーケンスは等差数列モジュロです。`p`。 価値は次のように進化します`x_n = s + n * b mod p`。 これにより、乗算の複雑さがすべて回避されます。 
2. もし`a == 1`、2 つのサブケースを処理します。 もし`b == 0`、シーケンスは一定であるため、次の場合にのみ成功します。`s == v`。 If not equal, there is no solution.
 3. もし`a == 1`そして`b != 0`、方程式を書き換えます`s + n b ≡ v (mod p)`として`n b ≡ v - s (mod p)`。 以来`p`プライムであり、`b != 0`、の逆モジュラーを計算します。`b`そして解決します`n ≡ (v - s) * b^{-1} mod p`。 結果は、最小の非負の剰余に正規化する必要があります。 
4. 次に考えてみましょう`a != 1`。 まず、反復の固定点、つまり値を計算します。`c`満足のいく`c = a c + b mod p`。 解くと得られるもの`c = b * (1 - a)^{-1} mod p`。 この変更により、加法項が削除されます。 
5. 開始値とターゲット値の両方をシフトされた空間に変換します。`y_s = s - c`そして`y_v = v - c`、すべてのモジュロ`p`。 
6. もし`y_s == 0`の場合、シーケンスは永久にゼロのままになるため、唯一の有効な答えは、次の場合です。`y_v == 0`。 
7. それ以外の場合、再発を次のように減らします。`y_n = a^n * y_s mod p`。 私たちは最小のものを望んでいます`n`そのような`a^n ≡ y_v * y_s^{-1} mod p`。 
8. モジュラー逆関数を計算します。`y_s`、目標比率を形成し、離散対数を解きます。`a^n ≡ target mod p`ベイビーステップ・ジャイアントステップを使用します。 答えは非負の最小値です`n`。 

### なぜ効果があるのか

 重要な不変条件は、固定小数点を減算すると、アフィン変換が有限体での純粋な乗算に変換されるということです。 乗算形式になると、すべての状態は次のべき乗として一意に表現されます。`a`初期オフセットの倍になります。 なぜなら`p`が素数の場合、ゼロ以外のすべての要素は逆元を持つため、変換ではゼロを除いて衝突することなく構造が維持されます。 離散対数ステップは到達可能性を正確に特徴付け、BSGS はサイクル サイズまでのすべての可能性を列挙するため、最小の指数が見つかることを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import isqrt

def modinv(x, p):
    return pow(x, p - 2, p)

def bsgs(g, h, p):
    # solve g^x = h mod p
    if h == 1:
        return 0
    m = isqrt(p) + 1

    table = {}
    cur = 1
    for j in range(m):
        if cur not in table:
            table[cur] = j
        cur = cur * g % p

    factor = pow(g, m * (p - 2) % (p - 1), p)
    # g^{-m} mod p

    gamma = h
    for i in range(m + 1):
        if gamma in table:
            return i * m + table[gamma]
        gamma = gamma * factor % p

    return None

def solve_case(a, b, s, p, v):
    if a == 1:
        if b == 0:
            return 0 if s == v else None
        return (v - s) * modinv(b, p) % p

    c = b * modinv((1 - a) % p, p) % p

    ys = (s - c) % p
    yv = (v - c) % p

    if ys == 0:
        return 0 if yv == 0 else None

    rhs = yv * modinv(ys, p) % p

    return bsgs(a, rhs, p)

T = int(input())
for _ in range(T):
    a, b, s, p, v = map(int, input().split())
    ans = solve_case(a, b, s, p, v)
    print(ans if ans is not None else "IMPOSSIBLE")
```実装では、アフィンの場合と乗算の場合を最初に分離します。これは、それらを混合すると不必要な逆変換が発生するためです。 逆モジュラーではフェルマーの小定理が使用されます。`p`プライムです。 

ベイビーステップ ジャイアントステップ ルーチンは、次のべき乗のハッシュ テーブルを構築します。`g`√p まで上昇し、その後、モジュール逆べき乗を使用してサイズ √p のジャンプで後方に歩きます。 よくある落とし穴はコンピューティングです`g^{-m}`間違って; それはモジュロで実行する必要があります`p`、モジュロではありません`p-1`。 

アフィン変換のステップも繊細です。 固定小数点の計算では、`(1 - a)^{-1}`モジュロ`p`すべてを内部に保管するには注意が必要です`[0, p)`引き算の前に。 

## 実用的な例

 サンプルの再発を考慮する`(a, b, s, p) = (7, 1, 2, 31)`そしてターゲット`v = 24`。 以来`a != 1`、固定小数点を計算します。 

固定点は`c = 1 * (1 - 7)^{-1} mod 31 = (-6)^{-1} mod 31 = 26`。 シフトすると得られるもの`y_s = 2 - 26 ≡ 7`そして`y_v = 24 - 26 ≡ 29`。 

解決します`7^n * 7 ≡ 29 mod 31`、 または`7^n ≡ 29 * 7^{-1}`。 このアルゴリズムはこれを離散対数計算に変換し、BSGS がシーケンスと一致する最小の指数を見つけます。 

| ステップ | 値 |
 | --- | --- |
 | c | 26 |
 | y_s | 7 |
 | y_v | 29 |
 | 目標比率 | 29 * 9 ≡ 5 |

 この表は、アフィン構造が単一のモジュラ指数方程式にどのように分解されるかを示しています。 これにより、変換ステップが正しいことが確認されます。 

次に、より単純な算術の場合を考えてみましょう`(a, b, s, p) = (1, 3, 10, 17), v = 2`。 

解決します`10 + 3n ≡ 2 mod 17`、与える`3n ≡ 9`、 それで`n ≡ 3`。 

| ステップ | 値 |
 | --- | --- |
 | s | 10 |
 | v | 2 |
 | b^{-1} | 6 |
 | n | 9 * 6 mod 17 = 3 |

 このトレースは、モジュラー反転処理と最小の非負の解への正規化が正確であることを確認します。

 ## 特殊なケース

 シーケンスが一定の場合、1 つのエッジ ケースが発生します。 たとえば、次の場合`a = 1`そして`b = 0`の場合、すべての項は次と等しくなります`s`。 アルゴリズムはすぐに戻ります`0`もし`s == v`そうでない場合は、不可能を返します。 ここでモジュラー逆関数を適用しようとするアプローチは失敗します。`b^{-1}`存在しません。 

もう 1 つのエッジ ケースは、アフィンから乗算への変換でシフトされた開始値がゼロになる場合です。 その状況では、シーケンスは即座に固定点に崩壊します。 このアルゴリズムは、離散対数を試行する前にこの条件を明示的にチェックし、無効な逆変換を防ぎます。 

最後のエッジケースは、離散対数に解がない場合です。 変換によって問題がきれいに軽減されたとしても、すべてのターゲットが、によって生成されたサブグループに含まれるわけではありません。`a`。 その場合、BSGS ルーチンは失敗を返し、メイン ソルバーはそれを正しく次のように変換します。`"IMPOSSIBLE"`。
