 ## 解決策
 ## 問題の理解

 私たちは、_n_ 個のバケツの 1 つを使用して、長さ _k_ の直線状の庭に水をやるように求められています。 各バケツは 1 時間ごとに庭の固定部分、具体的には _a_i_ の長さの連続した部分に水をまきます。 ルバは隙間を残さず庭全体に水をまく必要があり、どの部分にも二度水をまくことはできません。 私たちのタスクは、どのバケットが必要な合計時間を最小化するかを判断することです。 

入力では、最初の行にバケツの数と庭の長さが示され、その後に各バケツが 1 時間で水をまくことができる長さが続きます。 出力は単一の整数、つまり単一のバケツを使用して庭に水をやるのに必要な最小時間数です。 

制約は小さく、_n_ と _k_ は両方とも最大 100 です。つまり、すべてのバケットを反復する単純なアプローチでも効率的です。 各バケツを順番に安全にチェックし、簡単な計算を実行して、庭が均等に分割されているかどうかを確認できます。 単純な実装が失敗する可能性があるエッジケースは、バケツの水やりの長さが庭の長さを均等に分割していない場合です。 たとえば、_k_ = 6 でバケツが [5, 2] の場合、長さ 5 のバケツでは庭に完全に水をまくことができませんが、2 は 6 を正確に分割し、3 時間になります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各バケツについて、水やりの長さが庭の長さを正確に分割しているかどうかを確認します。 存在する場合、必要な時間数を次のように計算します。`k // a_i`。 すべてのバケットにわたる最小時間数を追跡します。 これは正しいです。水やりはバケツの長さちょうどの連続したセグメントでのみ実行でき、セグメントの部分的な水やりは許可されないからです。 

単純なバリエーションでは、一定の長さのセグメントの配置をシミュレートしようとする可能性があります。`a_i`庭沿いにありますが、部門が直接処理するためその必要はありません。 _n_ と _k_ の最大値は 100 であるため、すべてのバケットの反復処理と整数除算の実行は非常に高速であり、演算カウントは最大でも 100 であり、無視できる程度です。 

この問題を単純化するための重要な洞察は、問題が整数の除算に帰着することを理解することです。 庭の長さを正確に分割するバケツごとに、時間数は次のようになります。`k // a_i`。 セグメントが大きくなると時間数が減るため、そのような最大のバケットのみを選択する必要があります。 という観察`k % a_i == 0`整数時間以内に庭に水を十分に供給できないバケツを破棄できるようになります。

 ## アルゴリズムのチュートリアル

 1. バケット数を読み取ります。`n`そして庭の長さ`k`。 
2. バケットの長さのリストを読む`a`。 
3. 変数を初期化する`min_hours`最小時間を追跡するには、多数の値を設定します。 
4. 各バケット長を反復処理します。`length`で`a`。 
5.次のことを確認します`k % length == 0`。 そうでない場合は、整数時間以内に庭に完全に水をやることができないため、このバケツをスキップします。 
6. 時間数を次のように計算します。`hours = k // length`。 
7.アップデート`min_hours`もし`hours`現在よりも小さいです`min_hours`。 
8. すべてのバケットを確認した後、印刷します。`min_hours`。 

ここで不変なのは、庭を正確に分割するバケツの長さのみを考慮するということです。 この問題では少なくとも 1 つの有効なバケットが保証されるため、`min_hours`常に正しい値で更新されます。 セグメントが大きくなると時間数が減るため、このアプローチにより最小時間数が確実に見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

min_hours = float('inf')
for length in a:
    if k % length == 0:
        hours = k // length
        if hours < min_hours:
            min_hours = hours

print(min_hours)
```このソリューションは、入力を効率的に読み取ります。`sys.stdin.readline`。 初期化する`min_hours`有効な時間数を確実に小さくするには、無限大に設定します。 すべてのバケットを反復処理し、庭の長さとの可逆性を確認し、最小時間を更新します。 小切手`k % length == 0`庭を完全にカバーできることが保証されるため、これは非常に重要です。 最終的な印刷では、最小時間が出力されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    min_hours = float('inf')
    for length in a:
        if k % length == 0:
            hours = k // length
            if hours < min_hours:
                min_hours = hours
    return str(min_hours)

# provided samples
assert run("3 6\n2 3 5\n") == "2", "sample 1"
assert run("1 1\n1\n") == "1", "sample 2"

# custom cases
assert run("2 7\n1 3\n") == "7", "only bucket 1 works"
assert run("5 100\n1 2 4 5 10\n") == "10", "bucket 10 is optimal"
assert run("3 15\n4 5 6\n") == "3", "bucket 5 is best"
assert run("1 100\n100\n") == "1", "single bucket matches exactly"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 2 7\n1 3 | 7 | バケット 1 のみが機能します |
 | 5 100\n1 2 4 5 10 | 10 | 最大の除数を持つバケットが選択されます |
 | 3 15\n4 5 6 | 3 | 複数の約数の中から正しい選択 |
 | 1 100\n100 | 1 | 単一のバケツは庭の長さに等しい |

 ## 特殊なケース

 庭の長さが最大のバケットと等しい場合 (k = 100、バケット = 100 など)、アルゴリズムは 1 時間を正確に識別します。 k = 7 およびバケット = 1 のように、最小のバケットが唯一の約数である場合、アルゴリズムは 7 時間を生成します。 アルゴリズムは分割されていないバケツを自動的に無視し、間違った部分的な水やりを防ぎます。 すべてのエッジケースは、可分性チェックと、少なくとも 1 つのバケットが機能することの保証によってカバーされます。
