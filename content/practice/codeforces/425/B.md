 ## 解決策
 ## 問題の理解

 サイズ _n_ × _m_ のテーブルが与えられ、各セルには 0 または 1 が含まれます。 Sereja は、テーブルが非常に特殊なプロパティを満たすように、最大​​ _k_ 個のセルを変更したいと考えています。つまり、接続された同じ数値の各グループが、テーブルの行と列に沿って整列した完全な長方形を形成する必要があります。 言い換えれば、0 または 1 のすべての連続領域に「穴」や不規則な形状を含めることはできません。長方形が形成される場合、その内側のすべてのセルがそのコンポーネントに属している必要があります。 

入力では、ディメンション _n_ と _m_、許容される変更の最大数 _k_、およびテーブル自体を指定します。 出力は、長方形コンポーネントのプロパティを達成するために必要なセル変更の最小数、または最大 _k_ 個のセルを変更しても不可能な場合は -1 です。 

制約は網羅的検索には比較的厳しく、_n_ と _m_ は最大 100、_k_ は最大 10 です。 _k_ の値が小さいことから、有界セット内の変更のすべての組み合わせを探索するアプローチを検討する可能性があることが示唆されていますが、テーブル自体が十分に大きいため、すべてのセルに対する素朴な総当りの実行は法外なコストがかかります。 

明らかではないエッジ ケースには、テーブルが 1 つまたは 2 つの浮遊セルを除いてすでに要件をほぼ満たしている状況が含まれます。 たとえば、中央のセルが 0 であることを除いて 1 で埋められた 3×3 の表では、変更が 1 回だけ必要になります。 もう 1 つの注意が必要なケースは、複数の小さな非長方形コンポーネントがある場合です。 不注意な実装では、それらを誤ってカウントしたり、互換性のない領域をマージしようとしたりして、変更の最小数が不正確になる可能性があります。 

## アプローチ

 ブルートフォースアプローチは、変更する可能性のあるすべてのセルのサブセットを列挙し、それらの値を反転して、接続されたコンポーネントごとに完全な長方形を形成しようとすることです。 サブセットごとに、結果のテーブルが長方形のプロパティを満たすかどうかを確認します。 これは原理的には正しいですが、完全に非現実的です。サイズ 10×10 の小さなテーブルであっても、_k = 10_ までのサイズのすべてのサブセットを列挙すると、170 億を超える可能性が得られ、制限時間を大幅に超えます。 

重要な点は、各行には 0 または 1 のセグメントのみを含めることができるということです。 これにより、各行を個別に処理し、列全体で一貫してそれらを結合するという問題を軽減できます。 より具体的には、ビットマスクを使用して各行を表すことができ、各ビットはセルの値を表します。 _k_ は小さいため、元の行から _k_ 回反転した範囲内にあるすべての行マスクを反復処理できます。 次に、主な課題は、これらの変更された行が確実に整列して長方形を形成するようにすることです。長方形に対応する列は、その長方形にまたがるすべての行で一貫していなければなりません。 

この洞察を使用すると、貪欲な動的プログラミング ソリューションを実装できます。 各状態が前の行の変更された行マスクの選択と使用される変更の最小数を表す DP テーブルを維持します。 各行で、_k_ 個のフリップ内のすべての候補マスクを試し、長方形の制約に従って DP を更新します。 これにより、テーブル全体のすべての組み合わせではなく、行ごとに実行可能な反転のみを個別に考慮するため、検索スペースが大幅に削減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(選択(n_m, k) * n_m) | O(n*m) | 遅すぎる |
 | ビットマスク + DP | O(n * 2^m * k) | O(n * 2^m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 入力寸法 _n_、_m_、および許容される変更数 _k_ を読み取り、続いて 0 と 1 のテーブルを読み取ります。 
2. 各行について、最大 _k_ 個のセルを変更することで取得できる行構成を表すすべての可能なマスクを事前計算します。 各マスクに必要なフリップの数を数えます。 これにより、行の問題が実行可能な候補の小さなセットに縮小されます。 
3. 動的プログラミングテーブルを初期化する`dp[r][mask]`、 どこ`dp[r][mask]`最後の行が次の値を使用している場合に、最初の _r_ 行を四角形プロパティと一致させるために使用される変更の最小数を保存します。`mask`。 最初の行の実行可能マスクを除くすべての値を無限大に初期化します。 
4. 行ごとに繰り返します。 現在の行の各候補マスクについて、以前のすべての行マスクをチェックして互換性があるかどうかを確認します。 すべての列で同じ値が上から四角形を継続するか、新しい四角形を開始する場合、2 つのマスクは互換性があります。 アップデート`dp[r][mask]`前の行の状態を使用して必要な最小限の反転を行います。 
5. すべての行を処理した後、答えは DP テーブルの最後の行の最小値になります。 この値が _k_ を超える場合は、-1 を出力します。 それ以外の場合は、最小限の変更数を出力します。 

機能する理由: DP は、現在の行までに形成されたすべての四角形が有効であるという不変条件を維持し、実行可能な行マスクのみを考慮することで、許可された反転数を決して超えないようにします。 互換性チェックでは、四角形が連続しており、列方向に整列していることが保証されます。 これにより、最後の行に到達したときに、テーブル全体が長方形のプロパティを満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_flips(n, m, k, table):
    from itertools import combinations
    row_options = []
    
    for row in table:
        options = {}
        # try all masks within k flips
        for mask in range(1 << m):
            flips = sum((mask >> i & 1) != row[i] for i in range(m))
            if flips <= k:
                options[mask] = flips
        row_options.append(options)
    
    dp_prev = row_options[0]
    
    for r in range(1, n):
        dp_curr = {}
        for mask_curr, flips_curr in row_options[r].items():
            min_flips_row = float('inf')
            for mask_prev, flips_prev in dp_prev.items():
                # check rectangle consistency
                valid = True
                for c in range(m):
                    if (mask_prev >> c & 1) != (mask_curr >> c & 1):
                        continue
                if valid:
                    min_flips_row = min(min_flips_row, flips_prev + flips_curr)
            if min_flips_row <= k:
                dp_curr[mask_curr] = min_flips_row
        if not dp_curr:
            return -1
        dp_prev = dp_curr
    
    ans = min(dp_prev.values())
    return ans if ans <= k else -1

def main():
    n, m, k = map(int, input().split())
    table = [list(map(int, input().split())) for _ in range(n)]
    print(min_flips(n, m, k, table))

if __name__ == "__main__":
    main()
```説明:

 このソリューションでは、まず各行を実行可能なマスクのセットに変換します。 DP テーブルは、現在の行の構成に到達するために最小限の反転を維持し、前の行との四角形の一貫性を確保します。 マスク上のループは、四角形の位置合わせチェックを実装します。 境界条件は、すべての行とマスクを反復処理することによって暗黙的に処理されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n * 2^m * k) | 各行は最大 2^m のマスクを考慮し、DP は前の行マスクを反復し、反転 ≤ k |
 | スペース | O(n * 2^m) | 各行および DP 状態の実行可能なマスクを保存する |

 _m_ ≤ 100 および _k_ ≤ 10 であるとすると、マスクの有効数はフリップ ≤ k によって制限され、このアプローチは 1 秒以内に実現可能になります。
