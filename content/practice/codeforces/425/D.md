 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$2D 平面上の点はそれぞれ整数の座標を持ち、すべての点は個別です。 タスクは、このセットの 4 隅がすべて点である、軸に沿った正方形がいくつ存在するかを数えることです。 軸に沿った正方形とは、各辺が水平または垂直の正方形です。 出力は単一の整数、つまりそのような正方形の合計数です。 

与えられた$n$まで可能です$10^5$、座標は最大で$10^5$、すべての 4 倍の点を調べる総当り的なアプローチは実行不可能です。 たとえば、4 つの点のすべての組み合わせを反復するには、大まかに次の作業が必要になります。$O(n^4)$操作、つまり大まかに言うと$10^{20}$最大限に$n$。 明らかに、理想的には次のような、より効率的なアプローチが必要です。$O(n \log n)$または$O(n \sqrt{n})$。 

明らかではないエッジ ケースには、複数の点が同じ線上にある状況が含まれます。 たとえば、点の垂直線だけでは、水平の点がなければ正方形を形成できません。 もう 1 つの注意が必要なケースは、2 つの点が対角線上の潜在的な正方形を形成しているが、他の 2 つの角が欠けている場合です。$(0,0), (2,2)$なしでは単独で正方形を形成することはできません$(0,2)$そして$(2,0)$。 潜在的な対角線をカウントする単純なアプローチでは、4 隅すべてを検証しないと過剰にカウントされてしまいます。 

## アプローチ

 素朴な解決策では、すべての 4 つの点を反復処理します。 それぞれの 4 つの要素について、距離を比較し、軸の位置が揃っているかどうかを確認して、正方形を形成しているかどうかを確認します。 これは正しいですが、非常に遅いです。 その複雑さは$O(n^4)$。 のために$n=10^5$、これは現実的ではありません。 

より賢いアプローチでは、他の 2 つの角はこれら 2 つによって固定されるため、任意の正方形はその左下と右上の角 (または左上と右下) によって一意に決定できることが観察されます。 したがって、4 倍体をチェックする代わりに、正方形の対角の対角として機能する可能性のある点のすべてのペアを反復処理できます。 各候補対角線について、他の 2 つの角が直接計算されます。 次に、それらの点がセット内に存在するかどうかを効率的にチェックする必要があります。 すべてのポイントをセットまたはハッシュ マップに保存すると、この検索は次のようになります。$O(1)$平均して。 

これにより、複雑さが軽減されます。$O(n^2)$すべてのペアを反復する最悪のケースでは、これは許容されます。$n$最大数千ですが、大きすぎる可能性があります$n=10^5$。 さらに最適化するには、座標ハッシュを利用できます。 点を x 座標でグループ化し、潜在的な y 距離を効率的にスキャンしたり、y 座標でグループ化したりできます。 これにより、不必要なペア チェックが回避され、制約の下で実用的なパフォーマンスが実現されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (4 回転) | O(n^4) | O(n) | 遅すぎる |
 | ペアベースの対角チェック | O(n^2) | O(n) | 中程度の n については許容可能 |
 | 座標ハッシュによる最適化 | O(n√n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.すべて読む$n$ポイントを取得し、それらを O(1) 存在クエリのセットに格納します。 
2. 点の各ペアを反復処理します。$(x_1, y_1)$そして$(x_2, y_2)$。 それらを正方形の対角線上にある可能性のある角として扱います。 
3. ペアをスキップする場合$x_1 = x_2$または$y_1 = y_2$なぜなら、正方形の幅や高さをゼロにすることはできないからです。 
4. 他の 2 つの角を次のように計算します。$(x_1, y_2)$そして$(x_2, y_1)$。 
5. これらの点の両方がセット内に存在するかどうかを確認します。 存在する場合は、平方数を増やします。 
6. 各正方形は 2 回 (対角ごとに 1 回) カウントされるため、最終的なカウントを 2 で割ってから出力します。 

機能する理由: 各正方形には、正確に 2 つの異なる対角線があります。 すべての点のペアを反復処理し、それらを対角線とみなすことで、各正方形が正確に 2 回カウントされることが保証されます。 セットを使用すると、残りのコーナーの存在を迅速にチェックできます。 これにより正確さが保証され、過剰なカウントが回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_squares():
    n = int(input())
    points = set()
    coords = []
    for _ in range(n):
        x, y = map(int, input().split())
        points.add((x, y))
        coords.append((x, y))
    
    count = 0
    for i in range(n):
        x1, y1 = coords[i]
        for j in range(i + 1, n):
            x2, y2 = coords[j]
            if x1 == x2 or y1 == y2:
                continue
            if (x1, y2) in points and (x2, y1) in points:
                count += 1
    print(count // 2)

count_squares()
```このソリューションでは、まず高速検索のためにポイントをセットに保存し、ペアの反復のためにそれらをリストに保持します。 各ペアは対角線として扱われます。 このチェックにより、垂直または水平のペアが対角線として考慮されないことが保証されます。 最後に、2 で割ることで二重カウントが修正されます。
