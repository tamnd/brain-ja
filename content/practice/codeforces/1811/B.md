 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$マトリックス、ここで$n$は常に均等です。 マトリックスは同心円状の層として構築され、各層は時計回りに移動するサイクルを形成します。 指定されたセルから開始します$(x_1, y_1)$別のセルに到達したい$(x_2, y_2)$。 コンベア ベルトに沿った移動は自動的に行われるため、エネルギーはかかりません。 いつでも、1 エネルギー単位を消費して隣接するセルに移動でき、これを瞬時に何度でも行うことができます。 目的は、目的地に到達するために必要な最小限のエネルギーを見つけることです。 

重要な入力特徴は行列サイズです$n$開始座標と終了座標。 出力は単一の整数、つまり出発地から目的地まで移動するための最小エネルギーコストです。 

制約が厳しい:$n$まで可能です$10^9$まであります$2 \cdot 10^5$テストケース。 マトリックスに沿って移動する単純なシミュレーションは直ちに実行不可能です。 レイヤー内のすべてのセルを反復処理するだけでも、$O(n^2)$テストケースごとに、これは遅すぎます。 これは、純粋に数学的または数式に基づいたアプローチが必要であることを示しています。 

明らかではないエッジ ケースには、開始セルと終了セルが同じサイクル上にある場合が含まれます。 この場合、コンベアが自然に目的地まで移動すれば、エネルギーは必要ありません。 もう 1 つのエッジ ケースは、開始点が内層で目的地が外層 (またはその逆) の場合です。この場合、最小限のエネルギーで、ベルトに従うのではなく層間を移動する必要があります。 

## アプローチ

 ブルートフォースアプローチは、各レイヤーのサイクルを明示的にシミュレートし、すべての動きを試すことです。 各セルをベルトに沿った位置にマッピングし、サイクルに沿った距離を計算します。 小型用$n$、これは機能しますが、$n = 10^9$それは不可能です。 全サイクル長を計算したり、すべてのセル座標を生成すると、メモリと時間の制限を超えます。 

重要な洞察は、エネルギーコストは単に層数の差とベルトに沿った位置ずれを加えたものであるということです。 各レイヤーは正方形の境界線です。 セルから任意の端までの最小距離を取得することで、セルの層を決定できます。 開始と終了の両方のレイヤー番号がわかれば、最小のエネルギーはレイヤーの差になります。これは、ベルトに沿った移動にはコストはかからず、レイヤー間を直接移動するにはステップごとに 1 エネルギーがかかるためです。 ベルトが自動的に一方向に移動するため、同じレイヤーに沿った動きは無視できます。 

最適解では層番号を次のように計算します。$\text{layer} = \min(x-1, y-1, n-x, n-y)$。 そのとき、目的地に到達するためのエネルギーは、$|\text{layer}_1 - \text{layer}_2|$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n^2) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n, x_1, y_1, x_2, y_2$。 
2. 開始セルの層を次のように計算します。$\text{layer}_1 = \min(x_1 - 1, y_1 - 1, n - x_1, n - y_1)$。 これは最も近いエッジからの距離を測定します。 
3. 宛先セルの層を次のように計算します。$\text{layer}_2 = \min(x_2 - 1, y_2 - 1, n - x_2, n - y_2)$。 
4. 必要な最小エネルギーは$|\text{layer}_1 - \text{layer}_2|$。 これは、通過する必要があるレイヤーの数をカウントし、各レイヤーに 1 エネルギー単位のコストがかかります。 
5. エネルギーコストを出力します。 

これが機能する理由は、層に沿って移動するのにエネルギーがかからないためです。ベルトがあなたを運ぶからです。 唯一のエネルギー コストは層間の移動で発生し、隣接する層の任意のセルに移動するとちょうど 1 単位のコストがかかります。 この性質はどんなサイズにも当てはまります$n$そして偶数でも$n \ge 2$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x1, y1, x2, y2 = map(int, input().split())
    layer1 = min(x1 - 1, y1 - 1, n - x1, n - y1)
    layer2 = min(x2 - 1, y2 - 1, n - x2, n - y2)
    print(abs(layer1 - layer2))
```このコードは、エッジまでの最小距離を測定することによって各セルのレイヤーを計算します。 1 を減算すると、1 ベースのインデックスが調整されます。 層間の絶対的な差が最小のエネルギーを与えます。 このソリューションは、ループやメモリを大量に使用する構造を回避し、大規模なデータを処理します。$n$効率的に。

 ## 特殊なケース

 開始と終了が同じレイヤー上にある場合、エネルギーは 0 になります。$2 \times 2$開始位置の行列$(1,1)$そしてで終わります$(2,2)$、両方とも最外層にあるため、アルゴリズムは正しく計算します。$|0-0|=0$。 

次のような大きな行列の場合$10^9 \times 10^9$、レイヤー計算では、オーバーフローすることなく 1 から始まるインデックスが処理されます。 式`min(x-1, y-1, n-x, n-y)`最大の制約に合わせて正確にスケーリングし、レイヤーの差を直接計算して、極端な座標であっても最小限のエネルギー計算を保証します。
