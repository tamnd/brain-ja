 ## 解決策
 ## 問題の理解

 正確に _k_ 個の異なる小文字を含む長さ _n_ の文字列を構築するように求められます。連続する 2 つの文字は同じではなく、文字列はすべての可能性の中で辞書編集的に最小になります。 入力は整数 _n_ と _k_ を提供し、出力は目的の文字列であるか、構築できない場合は -1 でなければなりません。 

制約は、_n_ は最大 10^6、_k_ は最大 26 であることを示しています。文字列は非常に長くなる可能性があるため、すべての可能性を構築してチェックするアルゴリズムは実行不可能です。 2 秒の制限内にとどまるためには、O(n) アプローチが必要です。 

明らかではないエッジ ケースは、要求された個別の文字の数が文字列の長さまたは使用可能な文字の合計を超える場合に発生します。 たとえば、n = 2 および k = 3 の場合、3 つの異なる文字を長さ 2 の文字列に収めることはできないため、これは不可能です。 k = 1 の場合、別の微妙なケースが発生します。繰り返される文字の文字列は、n = 1 の場合にのみ許可されます。 そうしないと、隣接する 2 つの等しい文字がルールに違反します。 

## アプローチ

 強引なアプローチは、正確に _k_ 個の異なる文字を含む長さ _n_ のすべての文字列を生成して、それぞれに連続した重複がないかチェックすることです。 概念的には正しいですが、文字列の数が k^n として指数関数的に増加するため、このアプローチは絶望的に遅くなります。 中程度の n の場合でも、これには制限時間よりもはるかに長い時間がかかります。 

重要な洞察は、連続した繰り返しのない辞書編集上最小の文字列を貪欲に構築できるということです。 最小の文字「a」、「b」、「c」、... から始まり、k 番目の文字まで続きます。 これらの文字を順番に交互に配置すると、区別性と最小限の辞書編集順序の両方が保証されます。 k 個の文字を繰り返しパターンに配置した後、パターンを継続して文字列全体を埋めることができます。 k = 1 の場合、これを個別に処理します。n = 1 の場合、文字列は 'a' を 1 回繰り返すだけです。 そうでなければ不可能です。 

この観察により、文字列の保存とは別に、線形時間 O(n) と一定の追加スペースで文字列を構築することができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^n) | O(n) | 遅すぎる |
 | 貪欲なパターンの構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. k > n かどうかを確認します。 要求された個別の文字の数が文字列の長さを超える場合は、位置より多くの個別の文字を持つことは不可能であるため、すぐに -1 を出力します。 これは最も単純な不可能なケースを処理します。 
2. k = 1 の場合、使用できる文字は 1 つだけです。 n = 1 の場合、結果は「a」になります。 そうしないと、これより長い文字列では 1 つの文字が連続して繰り返されるため、これは不可能です。 それに応じて出力します。 
3. 最初の k 個の小文字を「a」、「b」、「c」、... の順に k 番目の文字まで使用して文字列を構築します。 これにより、すべての k 文字を 1 回含む最小の辞書編集シーケンスが形成されます。 
4. 文字列が長さ n に達するまで、このシーケンスを繰り返します。 入力する際は、連続する 2 つの文字が等しくないことを確認してください。 この構造では、k > 1 であるため、シーケンスの最初の文字が前のシーケンスの最後の文字と異なるため、k 文字シーケンスの繰り返しによって隣接する文字が異なることが保証されます。 
5. 結果の文字列を出力します。 構造上、辞書編集的に最小限であり、正確に k 個の異なる文字が含まれています。 

機能する理由: アルゴリズムは 2 つの不変条件を維持します。 まず、文字列には常に k 個の異なる文字が含まれています。 第 2 に、繰り返しシーケンスには異なる文字が順番に含まれており、k ≥ 2 により、連続するセグメントの最初と最後の文字が異なることが保証されるため、隣接する 2 つの文字は等しくありません。 利用可能な最小の文字を貪欲に選択することで、最小限の辞書編集順序が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())

if k > n:
    print(-1)
elif k == 1:
    if n == 1:
        print('a')
    else:
        print(-1)
else:
    pattern = [chr(ord('a') + i) for i in range(k)]
    result = []
    for i in range(n):
        result.append(pattern[i % k])
    print(''.join(result))
```コードは、不可能なケースを事前に処理することから始まります。 パターン リストは最初の k 文字を生成し、これにより区別性と辞書編集上の最小限性が保証されます。 ループはこのパターンを繰り返すことで文字列を埋め、モジュロ演算によりパターンが正しく折り返されるようにします。 k = 1 や k > n などのエッジ ケースは、エラーを回避するために明示的に処理されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    if k > n:
        return "-1"
    elif k == 1:
        return 'a' if n == 1 else "-1"
    else:
        pattern = [chr(ord('a') + i) for i in range(k)]
        result = [pattern[i % k] for i in range(n)]
        return ''.join(result)

# Provided samples
assert run("7 4\n") == "abcdabc", "sample 1"
assert run("2 3\n") == "-1", "sample 2"

# Custom cases
assert run("1 1\n") == "a", "minimum n and k"
assert run("26 26\n") == "abcdefghijklmnopqrstuvwxyz", "all letters once"
assert run("5 2\n") == "ababa", "alternating pattern"
assert run("3 1\n") == "-1", "single letter impossible for n > 1"
assert run("10 3\n") == "abcabcabca", "pattern repeats"
