 ## 解決策
 ## 問題の理解

 同じラベル付き頂点セット上の 2 つの単純な無向グラフが与えられます。 最初のグラフは初期状態、2 番目のグラフはターゲット状態です。 特定の操作を繰り返し適用することで、初期グラフを変換できます。3 つの異なる頂点を選択します。$a, b, c$、それらの間の 3 つのエッジすべての存在を反転し、それぞれを意味します。$(a,b)$、$(b,c)$、 そして$(a,c)$存在と不在が切り替わります。 

タスクは最小シーケンスを見つけることではなく、ターゲット グラフを取得できるかどうかを判断し、取得できる場合はそのようなトリプル フリップの有効なシーケンスを構築することです。 

この制約により、解は次の点でほぼ線形または線形でなければならないことがわかります。$n + m$。 まで$10^5$頂点とエッジの場合、頂点のペアを考慮したり、グラフ全体のグローバル検索を試みたりするアプローチは遅すぎます。 操作自体は常に正確に 3 つのエッジに影響を与えるため、解決策は明示的な構造変更ではなくエッジ パリティの観点から推論する必要があります。 

微妙な点は、操作が可逆的であり、純粋にパリティ ベースであることです。 各操作により、正確に 3 つのエッジのパリティが反転され、完全なグラフ内に三角形が形成されます。 これは、エッジの多重性や適用順序ではなく、エッジのパリティのみが重要であることを直ちに示唆しています。 

単純な間違いは、貪欲にエッジごとの修正を試みることです。 たとえば、不一致のエッジを修正しようとすると、$(u,v)$すべての操作が一度に 3 つのエッジに影響を与えるため、局所的な修正が全体的に干渉するため、単独では失敗します。 

もう 1 つの失敗例は、接続性または次数の制約が重要であると仮定することです。 それらは実現可能性を直接制約するものではありません。 代わりに、実現可能性は、グラフの対称的な差を三角形の反転に分解できるかどうかによって決まります。 

## アプローチ

 重要な観察は、両方のグラフをグラフのエッジ全体にわたるビット状態としてエンコードすることです。 差分グラフを定義します$D$、最初のグラフと最後のグラフの間でエッジが異なる場合、エッジが存在します。 各操作は、三角形を選択し、その中の 3 つのエッジをすべて切り替えることに正確に対応します。 したがって、エッジセットが$D$三角形の XOR 和として表すことができます。 

これはグラフ理論における古典的な事実です。三角形は、完全なグラフのサイクル空間を生成します。$\mathbb{F}_2$、偶数次の条件は三角演算を使用して削減できます。 ただし、サイクル スペースで直接作業するのは抽象的すぎて構築できません。 

より具体的なビューは、固定ピボット頂点に付随するエッジを段階的に削除することです。 頂点 1 を固定するとします。すべてのエッジについて$(u,v)$どちらの端点も1でない差分グラフでは、三角形を使用してそれを削除しようとします$(1,u,v)$。 その操作が切り替わります$(u,v)$また、1 に付随する 2 つのエッジを切り替えます。これにより、1 に付随する未解決のエッジの構造を維持する簿記プロセスが作成されます。 

このアイデアは、すべての「不良」エッジを頂点 1 を中心とするスターに押し込み、エッジをペアにすることでそのスターを解決することです。 

ブルートフォース手法では、対称差を減らす三角形を繰り返し検索することになり、コストがかかる可能性があります。$O(n^3)$最悪の場合の運用。 代わりに、トライアングル フリップの構造により、ピボット頂点を中心とした制御された削除プロセスを使用して常に解を表現できることが保証され、隣接リストとパリティの管理の問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォーストライアングルサーチ |$O(n^3)$|$O(n^2)$| 遅すぎる |
 | ピボットベースの消去 |$O(n + m + k)$|$O(n + m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 対称差分グラフに取り組みます$D$、最初と最後のグラフのエッジを XOR することによって構築されます。 エッジ$D$奇数回反転する必要があることを意味します。 

隣接セットを維持します$D$、頂点 1 に付随しないエッジを体系的に削除します。 

1. 差分グラフの隣接セットを構築する$D$。 エッジごとに、その存在を切り替えます。 これにより、修正する必要がある一連のエッジが正確に生成されます。 
2. エッジが存在する間$(u, v)$で$D$両方とも$u \neq 1$そして$v \neq 1$、そのようなエッジを選択し、操作を適用します$(1, u, v)$。 これは反転します$(u,v)$から削除します$D$、また切り替えます$(1,u)$そして$(1,v)$。 

この操作は 1 つの非スター エッジをターゲットにし、それを 2 つのスター エッジに変換するため、このステップは有効です。 
3. ステップ 2 の後、残りのすべてのエッジが$D$は頂点 1 に付随します。$D$は 1 を中心とする星になりました。 
4. 次にエッジを検討します$(1, x)$で$D$。 ステップ 2 で使用される場合、各操作は常に 2 つのエッジを反転するため、パリティ構造により、そのようなエッジの数が偶数であることが保証されます。 これらの近傍を任意にペアにします: 2 つの頂点を取ります$x, y$両方とも$(1,x)$そして$(1,y)$いる$D$、操作を適用します$(1, x, y)$。 これにより両方のエッジが反転します$(1,x)$、$(1,y)$、また切り替えます$(x,y)$、これは現在存在しません (すべての非 1 エッジがすでに除去されているため、問題が再発生することはありません)。 
5. エッジがなくなるまでペアリングを繰り返します。 いずれかの時点で残りのスター エッジの数が奇数の場合は、NO を出力します。 
6. 記録されたすべての操作を出力します。 

### なぜ効果があるのか

 各操作では、現在の差分グラフが常に元のターゲット差分の有効な XOR の組み合わせであるという不変条件が保持されます。 ステップ 2 では、星形でないエッジの数を厳密に減らします。 ステップ 4 では、スター以外のエッジがすべて存在しないことが維持されます。$(x,y)$そこで作成された構造は、ステップ 2 の処理順序で既に削除された構造に直ちに対応します。 頂点 1 に付随するエッジのパリティは、すべての三角形の反転が消去フェーズで 2 回または 0 回影響するため、均等に維持する必要があります。 

したがって、プロセスは、差分グラフが三角形で生成されたサイクル空間内にある場合に限り、グラフを空に削減し、構築はその分解を明示的に実現します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())

edges = set()

def add(u, v):
    if u > v:
        u, v = v, u
    if (u, v) in edges:
        edges.remove((u, v))
    else:
        edges.add((u, v))

for _ in range(m):
    u, v = map(int, input().split())
    add(u, v)

for _ in range(k):
    u, v = map(int, input().split())
    add(u, v)

ops = []

from collections import defaultdict

adj = defaultdict(set)
for u, v in edges:
    adj[u].add(v)
    adj[v].add(u)

def remove_edge(u, v):
    adj[u].remove(v)
    adj[v].remove(u)

def add_edge(u, v):
    adj[u].add(v)
    adj[v].add(u)

# eliminate non-1 edges
for u in list(adj.keys()):
    if u == 1:
        continue
    while adj[u]:
        v = next(iter(adj[u]))
        if v == 1:
            continue
        ops.append((1, u, v))
        remove_edge(u, v)
        if 1 in adj[u]:
            remove_edge(1, u)
        else:
            add_edge(1, u)
        if 1 in adj[v]:
            remove_edge(1, v)
        else:
            add_edge(1, v)

# collect star edges
stars = []
for v in list(adj[1]):
    stars.append(v)

if len(stars) % 2 == 1:
    print("NO")
    sys.exit()

# pair them
i = 0
while i < len(stars):
    a = stars[i]
    b = stars[i + 1]
    ops.append((1, a, b))

    for x, y in [(1, a), (1, b), (a, b)]:
        if y in adj[x]:
            adj[x].remove(y)
            adj[y].remove(x)
        else:
            adj[x].add(y)
            adj[y].add(x)

    i += 2

if any(adj[v] for v in adj):
    print("NO")
else:
    print("YES")
    print(len(ops))
    for a, b, c in ops:
        print(a, b, c)
```コードは最初に対称的な差分を構築し、実際に修正が必要なエッジのみを処理するようにします。 次に、隣接構造を使用して、頂点 1 に接触していない内部エッジを繰り返し削除します。エッジが見つかるたびに、$(u,v)$、頂点 1 を含む三角形を使用してこれをすぐに解決します。これにより、制御されたスター構造に複雑さを加えながら正確性が維持されます。 

最後のペアリング ステップでは、残りのエッジがすべて頂点 1 に属すると仮定します。パリティ チェックにより実現可能性が保証されます。 トグルロジックは慎重に対称的であり、完全な更新を必要とせずに隣接関係の更新の一貫性が保たれるようにします。$n^2$マトリックス。 

実装の微妙な点は、繰り返しの切り替えには O(1) の挿入/削除動作が必要なため、隣接関係にセットを使用することです。

    import sys

        add(u, v)

        add(u, v)

    from collections import defaultdict
    adj = defaultdict(set)
    for u, v in edges:
        adj[u].add(v)
        adj[v].add(u)

    ops = []

    def rem(u, v):
        adj[u].remove(v)
        adj[v].remove(u)

    def add_e(u, v):

        adj[v].add(u)

            else:

                rem(1, v)

            else:
                adj[x].add(y)
                adj[y].add(x)

 ## 特殊なケース

 エッジ ケースの 1 つは、差分グラフにすでに頂点 1 の周囲のスター エッジのみが含まれている場合です。この状況では、消去フェーズは完全にスキップされます。 アルゴリズムはパリティを直接チェックし、エッジをペアにするか拒否します。 

もう 1 つのエッジ ケースは、対称的な差分を構築した後にエッジが存在しない場合です。 変換が必要ないため、アルゴリズムは操作なしで正しく YES を出力します。 

最後の微妙なケースは、トグルを繰り返すと、削除後に隣接するエッジが再び表示される場合です。 セットベースの表現では、各トグルが対称的で常に両方のエンドポイントに一貫して適用され、中間状態中のグラフの不変性が維持されるため、正確さが保証されます。
