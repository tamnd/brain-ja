 ## 問題の理解

 無向木が与えられています。$n$頂点。 ルートのあらゆる選択に対して$r$、木は根を張ります。 あらゆる人にとって$k$-要素の頂点セット$S$のすべての頂点を含む最小のルートサブツリーを調べます。$S$。 

ルート付きサブツリーは、単なる接続されたサブグラフではありません。 頂点がそれに属している場合、その頂点のすべての子孫もその頂点に属している必要があります。 その定義により、ルートが固定されると、次の内容を含む最小のルート付きサブツリーが作成されます。$S$は一意に決まります。 

すべてのペアについて$(r,S)$、 させて$f(r,S)$は、その最小ルートサブツリー内の頂点の数になります。 この値をすべての根とすべてにわたって合計する必要があります。$k$-要素のサブセット。 

ツリーには以下が含まれます$2 \cdot 10^5$頂点。 サブセットの数だけでもすでに天文学的な数に達するため、サブセットを反復するアプローチは不可能です。 平$O(n^2)$この制限には大きすぎます。 ターゲットは本質的に直線的であるか、$O(n \log n)$。 

難しいのは、ルートが変わることです。 すべてのルートに対して個別に答えを計算する直接的な試みには、すでに次のものが必要になります。$O(n^2)$サブセットを処理する前に作業を行う必要があります。

## アプローチ

 ブルートフォースソリューションでは、すべてのルートが列挙されます。$r$、 毎$k$-サブセット$S$、最小のルートサブツリーを構築し、そのサイズを追加します。 たとえ$O(1)$1ペアの公式$(r,S)$、 がある$$n \cdot \binom{n}{k}$$ペア、これは完全に不可能です。 

重要な観察は、ルーツについて個別に考えるのをやめるべきだということです。 

サブセットを修正する$S$。 コンピューティングの代わりに$f(r,S)$ルートごとに個別に、$$F(S)=\sum_{r=1}^{n} f(r,S).$$表現できれば$F(S)$ツリーの構造特性を使用すると、各構造構成を生成するサブセットの数を数えるだけで済みます。 

固定の場合$S$に属している場合、頂点を **クリティカル** として定義します。$S$、またはその子サブツリーの少なくとも 2 つに次の頂点が含まれている場合$S$。 これらはまさに、選択したすべての頂点を接続するために必要な分岐点です。 

すべての非クリティカル頂点は、クリティカル スケルトンにアタッチされた接続コンポーネントに属します。 そのようなコンポーネントにサイズがある場合$sz$次に、そのコンポーネント内のすべてのルートに対して、$$f(r,S)=n-sz.$$すべての根を合計すると、非常に単純な式が得られます。$$F(S)=n^2-\sum sz_i^2,$$どこで$sz_i$すべての重要でないコンポーネントのサイズです。 この観察により、問題はコンポーネントの寄与をカウントすることに変わります。 

次の洞察は、考えられるすべてのコンポーネントは、単に木の端の片側にすぎないということです。 あるのは$2(n-1)$このようにつながった地域。 サブセットを反復する代わりに、エッジの特定の側面がそれらのコンポーネントの 1 つとなるサブセットの数を数えます。 

そのカウントは、サブツリーのサイズと二項係数によって完全に表現できます。 

結果として得られるアルゴリズムは、単一の DFS を実行し、頂点ごとに一定数の組み合わせ式を評価します。

 | 最適 |$O(n)$階乗事前計算後 |$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ツリーを頂点で一度根付けます$1$。 

1. 階乗および逆階乗モジュロを事前計算する$10^9+7$すべての二項係数を次のように評価できるようにします。$O(1)$。 
2. DFS を実行して以下を計算します。$$SZ[u]$$これはサブツリーのサイズです$u$、 そして$$p[u]=\sum_{v \text{ child of }u}\binom{SZ[v]}{k}.$$値$p[u]$1 つの子サブツリー内に完全に含まれるサブセットをすぐに数えてみましょう。 
3. ルート以外の頂点ごとに$u$、コンポーネントが次のサブツリーに等しいとみなします。$u$。 そのサイズは$SZ[u]$。 

何個数えますか$k$-subsets は、このコンポーネントを非クリティカル ブロックとして表示します。 結果のカウントは次のようになります。$$\binom{n-SZ[u]-1}{k-1} + \binom{n-SZ[u]-1}{k} - \Bigl(p[fa[u]]-\binom{SZ[u]}{k}\Bigr) - \binom{n-SZ[fa[u]]}{k}.$$乗算$SZ[u]^2$このコンポーネントの寄与を与える$$\sum sz_i^2.$$4. 間のエッジを削除して得られる補完成分も考慮します。$u$とその親。 そのサイズは$$n-SZ[u].$$この領域を非クリティカル コンポーネントにするサブセットの数は次のとおりです。$$\binom{SZ[u]-1}{k-1} + \binom{SZ[u]-1}{k} - p[u].$$乗算$(n-SZ[u])^2$の貢献を追加します。 
5. すべての非ルート頂点にわたるこのような寄与をすべて合計すると、次の結果が得られます。$$X=\sum_{S}\sum_i sz_i^2.$$6.以来$$F(S)=n^2-\sum_i sz_i^2,$$すべてのサブセットを合計すると、$$\text{Answer} = n^2 \binom{n}{k} - X.$$すべてを剰余として取得します$10^9+7$。 

### なぜ効果があるのか

 固定サブセットの場合$S$、すべての非クリティカル頂点は、正確に 1 つの最大非クリティカル連結成分に属します。 同じコンポーネント内のすべてのルートは同じ値を生成します$f(r,S)$、つまり$n-sz$、 どこ$sz$そのコンポーネントのサイズです。 

ルートを合計すると、問題はルート付きサブツリーのカウントからコンポーネント サイズの平方のカウントに変換されます。 このようなコンポーネントはすべて、まさにあるエッジの片側です。 組み合わせ公式は、その側が最大の非クリティカルコンポーネントを形成するサブセットを正確にカウントします。 すべてのコンポーネントは 1 回だけカウントされるため、累積された値は次のようになります。$$\sum_S \sum_i sz_i^2.$$に代入する$$F(S)=n^2-\sum_i sz_i^2$$必要な合計が生成されます。 

カウント式と実装は、公式の編集ソリューションに従います。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

n, k = map(int, input().split())

g = [[] for _ in range(n + 1)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

fac = [1] * (n + 1)
for i in range(1, n + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (n + 1)
invfac[n] = pow(fac[n], MOD - 2, MOD)
for i in range(n, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def C(a, b):
    if b < 0 or b > a:
        return 0
    return fac[a] * invfac[b] % MOD * invfac[a - b] % MOD

parent = [0] * (n + 1)
sz = [0] * (n + 1)
p = [0] * (n + 1)

order = [1]
parent[1] = -1

for u in order:
    for v in g[u]:
        if v == parent[u]:
            continue
        parent[v] = u
        order.append(v)

for u in reversed(order):
    sz[u] = 1
    cur = 0
    for v in g[u]:
        if v == parent[u]:
            continue
        sz[u] += sz[v]
        cur += C(sz[v], k)
    p[u] = cur % MOD

ans_sub = 0

for u in range(2, n + 1):
    par = parent[u]

    cnt1 = (
        C(n - sz[u] - 1, k - 1)
        + C(n - sz[u] - 1, k)
        - (p[par] - C(sz[u], k))
        - C(n - sz[par], k)
    ) % MOD

    ans_sub = (ans_sub + sz[u] * sz[u] % MOD * cnt1) % MOD

    cnt2 = (
        C(sz[u] - 1, k - 1)
        + C(sz[u] - 1, k)
        - p[u]
    ) % MOD

    comp = n - sz[u]
    ans_sub = (ans_sub + comp * comp % MOD * cnt2) % MOD

total = n * n % MOD * C(n, k) % MOD
answer = (total - ans_sub) % MOD

print(answer)
```階乗配列と逆階乗配列は、定数時間の二項係数を提供します。 以来$n$到達する$2 \cdot 10^5$、この前処理は必須です。 

DFS は反復的に実装されます。 Python のデフォルトの再帰制限は、長さのチェーンに対して十分な大きさではありません$2 \cdot 10^5$。 

配列`p[u]`パフォーマンスが重要な最適化です。 これがなければ、カウント式の計算は親の子を繰り返し実行することになり、星型ツリーでは二次時間に縮退する可能性があります。 この理由から、社説ではこの事前計算を明示的に導入しています。 

すべての組み合わせ式は剰余化されます$MOD$。 負の中間値は許可されており、`% MOD`最後にそれらを正しく正規化します。

 ## 特殊なケース

 いつ$k=1$、すべてのサブセットには頂点が 1 つだけ含まれます。 次のような用語があるため、カウント式は引き続き有効です。$\binom{x}{k-1}$なる$\binom{x}{0}=1$。 このアルゴリズムは、最小のルート付きサブツリーが選択された頂点の通常のルート付きサブツリーであるすべてのルートを自然にカウントします。 

いつ$k=n$、上の引数が以下のすべての二項係数$n$ゼロになります。 すべてのコンポーネントの寄与が消え、残ります。$$n^2 \binom{n}{n}=n^2.$$これは、ツリー全体が常に含まれなければならないという事実と一致します。 

チェーンの場合、多くのエッジカットの片側にサイズがあります$1$。 数式は明示的に使用します$SZ[u]-1$そして$n-SZ[u]-1$。 この結合関数は、上の引数が負であるか、下の引数より小さい場合には常にゼロを返し、チェーンの終端での off-by-one エラーを防ぎます。
