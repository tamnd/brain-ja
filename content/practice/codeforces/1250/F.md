 ## 解決策
 ## 問題の理解

 対象地域が与えられています$n$、辺が整数で、面積がちょうど である長方形を構築したいとします。$n$。 すべての有効な四角形は 2 つの整数の選択に対応します$a$そして$b$そのような$a \cdot b = n$。 このようなすべての因子ペアの中で、周囲長が最小の長方形が必要です。$2(a + b)$。 

したがって、このタスクは純粋に因数分解に関するものです。積が固定されているすべての整数のペアのうち、その和を最小にするペアが必要です。 幾何学的には、バランスの取れた辺が固定領域の周囲を減らすため、これは長方形を可能な限り正方形に近づけることに相当します。 

制約$n \le 10^5$まで反復できるほど小さい$\sqrt{n}$テストごとに一定時間で実行可能です。 考えられるすべての要素に対する総当り攻撃$n$それでも通過しますが、その必要はありません。 

不用意な解決策による微妙な失敗例としては、$a = \lfloor \sqrt{n} \rfloor$常に有効な長方形を返します。 それは次の場合にのみ機能します$n$は完全な正方形です。 たとえば、次の場合$n = 13$、$\lfloor \sqrt{13} \rfloor = 3$、 しかし$13$で割り切れない$3$、 それで$3 \times 3$は無効です。 正しい答えは次のとおりです$1 \times 13$。 

もう一つのエッジケースは、$n = 1$。 唯一の長方形は、$1 \times 1$ですので、周長は$4$。 因子検索に依存するロジックでは、これを適切に処理する必要があります。 

## アプローチ

 簡単なアプローチは、考えられるすべてのペアを列挙することです。$(a, b)$そのような$a \cdot b = n$、計算する$2(a+b)$、そして最小限のものを取ります。 すべての有効な四角形をチェックするため、正確性がすぐにわかります。 問題は効率です。すべての値をスキャンします。$a$から$1$に$n$につながる$O(n)$小切手は不必要で無駄ですが、$n$だけです$10^5$。 

重要な観察は、要因がペアで存在するということです。$\sqrt{n}$。 もし$a \cdot b = n$、その後、少なくとも 1 つ$a, b$以下である$\sqrt{n}$。 つまり、反復するだけで済みます$a$まで$\sqrt{n}$、いつでも$a$分割する$n$、対応するペアを評価します$(a, n/a)$。 

これにより、すべての有効な因子のペアを確実に検査しながら、検索空間が線形から平方根のサイズに縮小されます。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(n)$|$O(1)$| 遅すぎる |
 | 最適 (ファクタースキャン) |$O(\sqrt{n})$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 変数を初期化する`best`これまでに見つかった最小周囲長を格納するには、非常に大きな値を指定します。 これにより、有効な四角形があれば確実に改善されます。 
2. 反復する$a$から$1$に$\lfloor \sqrt{n} \rfloor$。 すべての因子のペアにはこの範囲内に少なくとも 1 つの要素が含まれている必要があるため、平方根までのみ検索します。 
3. それぞれについて$a$、どうかを確認してください$n \bmod a = 0$。 そうでない場合は、有効な長方形の辺を形成できないため、スキップしてください。 
4. 均等に割れる場合は計算します。$b = n / a$。 これにより有効な長方形が得られます$a \times b$。 
5. 境界を計算する$p = 2(a + b)$そして更新します`best = min(best, p)`。 有効な各因子ペアが形状の候補となります。 
6. ループ終了後、出力`best`。 

### なぜ効果があるのか

 すべての有効な四角形は 1 つの因子ペアに正確に対応します$(a, b)$と$a \le \sqrt{n}$または$b \le \sqrt{n}$。 このループは、より小さい係数を通じて、そのようなペアすべてに 1 回だけ遭遇することを保証します。 外周は和のみに依存するため$a + b$、すべての有効なペアをチェックすることで、候補を見逃すことなく最小値が見つかるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

best = 10**18
i = 1

while i * i <= n:
    if n % i == 0:
        j = n // i
        best = min(best, 2 * (i + j))
    i += 1

print(best)
```このソリューションは、すべての有効な因子ペアにわたって実行最小値を維持します。 ループ条件`i * i <= n`浮動小数点平方根を回避し、整数安全な反復を保証します。 除数が見つかるたびに、整数の除算を使用してペアの因数を即座に形成し、精度の問題が発生しないようにします。

## テストケース```python
import sys, io

def solve():
    import sys
    input = sys.stdin.readline
    n = int(input())

    best = 10**18
    i = 1
    while i * i <= n:
        if n % i == 0:
            j = n // i
            best = min(best, 2 * (i + j))
        i += 1

    print(best)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)
    from io import StringIO
    out = StringIO()
    old_stdout = sys.stdout
    sys.stdout = out
    solve()
    sys.stdout = old_stdout
    sys.stdin = old_stdin
    return out.getvalue().strip()

# provided samples
assert run("36\n") == "24"
assert run("13\n") == "28"

# custom cases
assert run("1\n") == "4"
assert run("2\n") == "6"
assert run("49\n") == "28"
assert run("100000\n") == str(min(2*(i + 100000//i) for i in range(1, 100000+1) if 100000 % i == 0))

 ## 特殊なケース

 のために$n = 1$、唯一の有効な長方形は$1 \times 1$。 ループは引き続き 1 回実行されます。$i = 1$、割り算を検出し、周囲を計算します。$2(1+1) = 4$, which matches the correct answer.

 次のような素数の場合$n = 13$を除き、約数は存在しません。$1$したがって、アルゴリズムは自然に次のようになります。$1 \times 13$、周囲を生成する$28$。 内部除数がない場合でも、特別な処理は必要ありません。 

次のような完全な正方形の場合$n = 36$、複数の因子ペアが発見され、最小値が中央ペアで発生します。$6 \times 6$。 反復により、このペアが明示的に評価されることが保証されるため、最適な構造が見逃されることはありません。
