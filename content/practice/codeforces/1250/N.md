 **タグ:** dfs および類似の、グラフ、貪欲

 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 各ワイヤは 2 つの接点を接続します。2 つのワイヤが少なくとも 1 つの端点を共有する場合、または連続するワイヤが端点を共有するワイヤのチェーンがある場合、2 つのワイヤは関連していると言います。 これにより、ワイヤ自体を介した接続の概念が作成されます。つまり、ワイヤはノードであり、接点を共有すると、それらの間に無向の関係が作成されます。 

目標は、すべてのワイヤがこの関係に基づいて接続されるように、変更するワイヤ エンドポイントをできるだけ少なくすることです。つまり、どのワイヤからでも共有エンドポイントを介して他のワイヤに到達できるようになります。 

変更は、ワイヤの 2 つの端点が別個である限り、ワイヤの 1 つの端点を取得し、それを許容範囲内の任意の整数に変更することで構成されます。 このような変更にはそれぞれ 1 単位の時間がかかります。 

すべてのテスト ケースにわたる n の合計が最大 100000 であるという制約は、テスト ケースごとにすべての解が線形に近くなければならないことを意味します。 O(n log n) または O(n α(n)) のアプローチは許容されますが、テスト ケースごとのワイヤ数が 2 次の場合は失敗します。 これは、インスタンスの構造を、接続されたコンポーネントを効率的に計算できるグラフに圧縮する必要があることを強く示唆しています。 

単純な試みでは、ワイヤのすべてのペアをスキャンし、最小限の変更で接続できるかどうかを確認することによって、コンポーネントを繰り返しマージしようとする可能性があります。 これは、仮説を変更するたびに接続性をチェックするのにすでに O(n) のコストがかかり、それを繰り返し実行すると O(n²) 以上のコストがかかるため、失敗します。 

2 番目の単純なアイデアは、各ワイヤを独立して扱い、それを成長する構造に貪欲に接続することです。 これも微妙に失敗します。ワイヤがすでに接続されているかどうかは、ローカル構造だけでなく、共有エンドポイントを介した間接的なチェーンに依存するためです。 

すべてのワイヤがすでに単一の接続コンポーネントを形成している場合、小さいながらも重要なエッジ ケースが発生します。 その場合、修正は必要ありません。 もう 1 つのエッジ ケースは、エンドポイントがまったく共有されていない場合です。 次に、すべてのワイヤが分離され、エンドポイントを明示的に再はんだ付けしてすべてのコンポーネントを接続する必要があります。 

## アプローチ

 システムをグラフとして再解釈します。各ワイヤはノードであり、2 つのワイヤが接触点を共有している場合、2 つのワイヤは隣接しています。 このグラフを明示的に構築すると、タスクはエンドポイントを変更してグラフを接続することになり、各変更により、切断された 1 つのコンポーネントが別のコンポーネントにマージされます。 

ブルート フォース アプローチでは、仮想エンドポイントが変更されるたびに接続性が明示的に再計算されます。 試行ごとに隣接関係を再構築するか、有線で BFS/DFS を実行する必要があり、チェックごとに O(n) のコストがかかります。 潜在的に O(n) 回の変更が必要になるため、O(n²) となり、100,000 本のワイヤには遅すぎます。 

重要な点は、ワイヤ間の接続は共有エンドポイントによって完全に決定され、エンドポイントを変更することは、選択した接点を強制的に共有することによってワイヤを別のコンポーネントに「再割り当て」することと同じであるということです。 変更を動的にシミュレートする代わりに、最初に元の構成でワイヤの接続コンポーネントを計算します。 各コンポーネントは共有エンドポイントで最大限に機能するため、内部接続するために内部変更を行う必要はありません。 

コンポーネントがわかったら、問題はこれらのコンポーネントを接続することになります。 c 個のコンポーネントがある場合は、少なくとも c − 1 回のマージが必要です。これは、各変更により、以前は別個だった 1 つのコンポーネントが既に接続されている構造に接続される可能性があるためです。 最適な戦略は、1 つのコンポーネントをルートとして選択し、単一の代表的なワイヤの 1 つのエンドポイントだけを変更することによって、他のすべてのコンポーネントをそれに接続することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(n²) | O(n) | 遅すぎる |
 | コンポーネント + 貪欲なマージ | O(n α(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

2 本のワイヤが端点を共有する場合、エッジが存在するグラフ内のノードとしてワイヤをモデル化します。 すべてのペアワイズ エッジを明示的に構築する代わりに、エンドポイントからそれに接続するワイヤのリストへのマッピングを使用します。 

1. ワイヤー上に空の素集合構造を構築します。 各接点について、それに付随するすべてのワイヤを収集し、それらを 1 つのコンポーネントに結合します。 このステップでは、合計ワイヤ発生数に対して線形時間で接続コンポーネントを構築します。 
2. ユニオン操作後、ワイヤの接続されたコンポーネントを抽出します。 各コンポーネントは、共有エンドポイントを通じてすでに相互に到達可能な最大のグループを表します。 
3. コンポーネントが 1 つだけの場合、変更は必要ないため、答えはゼロになります。 
4. それ以外の場合は、基本コンポーネントとして 1 つのコンポーネントを選択します。 このコンポーネントから任意のワイヤを選択し、その端点の 1 つをグローバル アンカー ポイントとして選択します。 
5. 他のすべてのコンポーネントについて、その内部の任意のワイヤを選択します。 そのワイヤーについて、どのエンドポイントを変更するかを決定します。 一方のエンドポイントが選択したアンカー ポイントと等しい場合は、もう一方のエンドポイントを変更します。 それ以外の場合は、どちらかのエンドポイントを任意に変更します。 選択したエンドポイントをアンカー ポイントに設定し、このコンポーネントをベースに効果的に接続します。 
6. このような演算ごとにコンポーネントの数が 1 つ減るため、正確に c − 1 個の演算を実行します。 

これが機能する理由は、コンポーネントの単一ワイヤがアンカー ポイントを共有すると、そのコンポーネント内のすべてのワイヤがコンポーネントの元の内部接続を介して接続されるため、コンポーネント全体がメイン構造にマージされるためです。 

### なぜ効果があるのか

 初期グラフの各コンポーネントは、エンドポイント共有接続の下で閉じられています。これは、コンポーネントの外部のワイヤが内部のワイヤとエンドポイントを共有しないことを意味します。 コンポーネント内の任意のワイヤーの 1 つのエンドポイントをアンカー ポイントに一致するように変更することで、コンポーネント全体をルート コンポーネントに接続する新しい共有エンドポイントを導入します。 変更前はコンポーネントが互いに素であるため、各操作は内部の有効性に影響を与えることなく 1 つのコンポーネントだけをマージします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return
        if self.r[a] < self.r[b]:
            a, b = b, a
        self.p[b] = a
        if self.r[a] == self.r[b]:
            self.r[a] += 1

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        edges = []
        mp = {}

        for i in range(n):
            x, y = map(int, input().split())
            edges.append((x, y))
            if x not in mp:
                mp[x] = []
            if y not in mp:
                mp[y] = []
            mp[x].append(i)
            mp[y].append(i)

        dsu = DSU(n)

        for lst in mp.values():
            if len(lst) > 1:
                first = lst[0]
                for v in lst[1:]:
                    dsu.union(first, v)

        comp = {}
        for i in range(n):
            r = dsu.find(i)
            comp.setdefault(r, []).append(i)

        comps = list(comp.values())

        if len(comps) == 1:
            print(0)
            continue

        base_wire = comps[0][0]
        bx, by = edges[base_wire]

        ops = []
        for ci in range(1, len(comps)):
            w = comps[ci][0]
            x, y = edges[w]

            if x == bx or (y != bx):
                ops.append((w + 1, x, bx))
            else:
                ops.append((w + 1, y, bx))

        print(len(ops))
        for w, a, b in ops:
            print(w, a, b)

if __name__ == "__main__":
    solve()
```DSU は、共有エンドポイントを介して接続されたワイヤの暗黙的なグラフを圧縮します。 Each endpoint acts as a hub linking all wires that touch it, and unioning those wires ensures each connected component is found without explicitly building a quadratic adjacency list.

 ベース ワイヤーを選択すると、安定したアンカー エンドポイントが得られます。 他の各コンポーネントは、そのワイヤーの 1 つがそのエンドポイントを共有するように強制する 1 つの操作に寄与し、マージを保証します。 

どのエンドポイントを置き換えるかを条件付きで選択することで、同一のエンドポイントを持つ無効なワイヤが作成されることがなくなります。

 ## 特殊なケース

 すべてのワイヤがすでに推移的にエンドポイントを共有している場合、DSU は単一のコンポーネントを生成し、アルゴリズムはただちにゼロ操作を返します。 これは、それぞれが 1 つのエンドポイントを次のエンドポイントと正確に共有する一連のワイヤなど、接続が間接的な長いチェーンをカバーします。 

エンドポイントがまったく共有されていない場合、すべてのワイヤが独自のコンポーネントを形成します。 アルゴリズムは 1 つのベース ワイヤーを選択し、残りの各ワイヤーをアンカー エンドポイントに直接接続し、正確に n − 1 個の操作を生成します。 各操作でメイン構造にマージできるコンポーネントは 1 つだけであるため、これは最適です。 

複数のワイヤが同じエンドポイントを共有しているが、それ以外の場合は分離されている場合、DSU は操作が計画される前にそれらを単一のコンポーネントに正しくマージします。 これにより、必要なマージを過剰にカウントすることがなくなり、不必要な再はんだ付けが行われることがなくなります。
