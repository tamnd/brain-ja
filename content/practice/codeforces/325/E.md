 ## 解決策
 ## 問題の理解

 ノード 0 が特別なサイズ _n_ の循環システムの一連のノード解除を見つけるように求められます。 ノード 0 は 2 回出現する必要があります。最初は最初、最後は最後です。 他のノードはすべて 1 回だけ出現する必要があります。 ノード _i_ を解除した後、次のノードは次のいずれかでなければなりません。`(2*i) % n`または`(2*i + 1) % n`。 問題は、これらの倍加とオフセットの規則によって定義された、ノード 0 で開始および終了する有向グラフ内にハミルトニアンのようなパスを構築することに帰着します。 

入力は、最大 100,000 までの単一の整数 _n_ です。 これは、O(n²) 時間を必要とする解法は遅すぎる可能性があることを意味します。 アルゴリズムは各ノードをおよそ 1 回か 2 回処理する必要があるため、実際には O(n) から O(n log n) 程度の解決策が必要です。 

エッジ ケースには、次のノードの選択がすぐに循環する小さな _n_ が含まれます。 たとえば、n = 2 の場合、ノード 0 と 1 のみがあり、正しい出力は次のようになります。`0 1 0`。 メモ化を行わずに不注意に再帰的にアプローチすると、無限ループが発生したり、無効なノードが試行されたりする可能性があります。 もう 1 つの注意が必要なシナリオは、_n_ が 2 の累乗である場合です。 この場合、2 倍化ルールによりモジュロ演算でバイナリ ツリーのような構造が作成され、0 に戻る前にすべてのノードを 1 回正確にトラバースする必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのシーケンスを再帰的に探索しようとします。 ノード 0 から始めて、次のように分岐します。`(2*i) % n`そして`(2*i + 1) % n`各ステップで、ノードを訪問済みとしてマークします。 これは原理的には正しいですが、複雑さが爆発的に増加します。 各ノードには 2 つの選択肢があり、2ⁿ の可能なシーケンスが得られます。 n = 20 の場合、これはすでに約 100 万シーケンスになります。 n = 100,000 の場合、これは不可能です。 

重要な洞察は、モジュロ _n_ 算術の下でノード接続をバイナリ ツリーとして表すことです。 各ノード i には 2 つの子があります。`(2*i) % n`そして`(2*i + 1) % n`。 すべてのノードに 1 回だけ (0 と 2 回を除く) タッチし、これらのエッジを尊重するトラバーサルが必要です。 この問題は、組み合わせ論では de Bruijn のようなシーケンスを法 _n_ で生成するものとして知られており、n が 2 の累乗である場合にきちんとした構成になっています。 _n_ が 2 の累乗でない場合、2 倍化ルールが最終的に衝突するかギャップが生じ、有効なシーケンスを構築できなくなります。 したがって、最初に _n_ が 2 の累乗であるかどうかを確認します。 存在する場合、次を使用した再帰的な深さ優先トラバーサルが行われます。`(2*i) % n`それから`(2*i + 1) % n`有効なシーケンスを保証します。 それ以外の場合は、-1 を返します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. _n_ が 2 の累乗かどうかを確認します。 そうでない場合は、-1 を出力して終了します。 これは、_n_ が 2 の累乗である場合にのみ、_n_ を法とする二分木構造がギャップなしですべてのノードをカバーするためです。 
2. 空のリストを初期化する`order`解除シーケンスを保存します。 
3. 再帰関数を定義する`dfs(node)`モジュロバイナリ ツリー上で事後探索を実行します。 子どもたちを訪ねて`(2*node + 1) % n`そして`(2*node) % n`ノード自体を追加する前に再帰的に`order`。 子どもたちを訪問する順序によって、デ・ブライジンのようなサイクルの正しい順序が確実に構築されます。 
4. 電話をかける`dfs(0)`ノード 0 からトラバースを開始します。 
5. 収集したシーケンスを反転します。`order`。 後続トラバーサルではノードの前に子が追加されるため、反転が必要ですが、最初にノード 0 が出現する必要があります。 
6.末尾に0を追加します。`order`ノード 0 が最初と最後に 2 回出現するという要件を満たすためです。 
7. シーケンスを印刷します。 

これが機能する理由: ダブリング ルールは、モジュロ _n_ でバイナリ ツリーのような構造を定義します。 2 の累乗の場合、このツリーは完璧です。すべてのノードに 1 回だけ到達可能です。 ポストオーダー DFS では、各子ノードがその親の前に必ず表示され、順序を逆にするとノード 0 が先頭に配置されます。 The appended 0 at the end closes the cycle. このアルゴリズムは各ノードを 1 回通過するため、O(n) 時間が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_power_of_two(n):
    return (n & (n - 1)) == 0

def solve():
    n = int(input())
    if n == 1:
        print("0 0")
        return
    if not is_power_of_two(n):
        print(-1)
        return

    order = []

    def dfs(v):
        if v >= n:
            return
        l = (2 * v) % n
        r = (2 * v + 1) % n
        if l != 0:
            dfs(l)
        if r != 0:
            dfs(r)
        order.append(v)

    dfs(0)
    order = order[::-1]
    order.append(0)
    print(' '.join(map(str, order)))

solve()
```機能`is_power_of_two`必要な条件を素早く確認します。 DFS はノードを事後順序で収集します。 ツリーを終了する前に繰り返しアクセスすることを避けるために、0 の子はスキップされます。 シーケンスを逆にして 0 を追加すると、最終的な有効な武装解除シーケンスが生成されます。 小さい n の境界条件は明示的に処理されます。

 ## 特殊なケース

 n = 3 (2 のべき乗ではない) の場合、アルゴリズムはすぐに -1 を出力します。 これにより、不可能なシーケンスの探索が回避され、非 2 の累乗を法とする 2 倍ルールの微妙な失敗が処理されます。 n = 1 の場合、明示的に [0, 0] を返し、ノード 0 が他のノードなしで 2 回出現するという要件を満たします。 2 の累乗が大きい場合、DFS はノードの順序を正しく処理し、子のノード 0 をスキップし、最終シーケンスが 0 で始まり 0 で終わるようにします。
