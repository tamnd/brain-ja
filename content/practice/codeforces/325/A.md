 ## 解決策
 ## 問題の理解

 平面上に最大 5 つの軸に整列した長方形が与えられます。 各四角形は、左下と右上の座標によって定義されます。 2 つの長方形は重なりませんが、端や角で接触する場合があります。 タスクは、これらの長方形の結合が正確に完全な正方形を形成するかどうかを判断することです。 これは、長方形でカバーされる結合領域が、ギャップや穴のない、軸に平行な辺を持つ正方形を形成する必要があることを意味します。 

長方形の数が最大 5 つであるという制約は重要です。 これにより、複雑な計算幾何学やグリッド シミュレーションに依存する代わりに、考えられるすべての配置について幾何学的に推論することができます。 各四角形の座標は 31,400 で区切られており、Python では単純な算術演算や比較で整数オーバーフローが発生する危険がありません。 

明らかではないエッジ ケースには、長方形が角でのみ接触する配置、内側に穴のある正方形を形成する長方形、または正方形ではない直線に並んだ長方形が含まれます。 たとえば、正方形の一部のように見える L 字型を形成する 3 つの長方形は、境界座標のみに基づく単純なチェックを誤解させる可能性があります。 

## アプローチ

 ブルートフォース手法では、すべての四角形の境界ボックスをカバーするのに十分な大きさの 2D ブール グリッドを作成し、四角形内にあるすべてのセルをマークする必要があります。 次に、グリッドを反復処理して、境界正方形内のすべてのセルがカバーされているかどうかを確認できます。 これは、四角形の数が非常に少ないため機能しますが、洗練されておらず、境界座標が最大値の 31,400 に近い場合、潜在的に大量のメモリを必要とします。 

最適なアプローチは幾何学的推論に依存します。 まず、最小の長方形を見つけて、すべての長方形を含む最小境界正方形を計算します。`x1`そして`y1`そして最大の`x2`そして`y2`。 この境界ボックスの幅と高さが等しくない場合、長方形は正方形を形成できません。 それらが等しい場合、次のステップは、長方形の合計面積がこの境界正方形の面積と等しいことを確認することです。 個々の長方形の面積の合計が境界ボックスの面積と一致し、重なりが存在しない場合 (問題文で保証されています)、長方形は正確に正方形を形成します。 

重要な洞察は、少数の重なり合わない長方形の場合、正方形を形成する組み合わせは、その境界ボックスが正方形であり、その合計面積が境界ボックスの面積と一致することと同等であるということです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッド | O(S^2) ここで、S は境界ボックスの辺の長さです | O(S^2) | 機能しますがやりすぎです |
 | 幾何学的境界 + 領域チェック | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 長方形の数を読み取る`n`そしてその座標。 
2.初期化`min_x`、`min_y`無限にそして`max_x`、`max_y`ゼロに。 これらは外接する四角形を追跡します。 
3.初期化`total_area`ゼロに。 これはすべての長方形の面積を合計します。 
4. 各四角形を繰り返します。 座標を含む各四角形について`(x1, y1, x2, y2)`、 アップデート`min_x`そして`min_y`現在の値の小さい方と、`x1`、`y1`。 アップデート`max_x`そして`max_y`現在の値のうち大きい方に、`x2`、`y2`。 追加`(x2 - x1) * (y2 - y1)`に`total_area`。 
5.幅を計算する`w = max_x - min_x`と高さ`h = max_y - min_y`外接する四角形の。 
6. もし`w != h`、「NO」を出力して終了します。 それ以外の場合は、次のことを確認してください`total_area == w * h`。 true の場合、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

このアルゴリズムが機能するのは、長方形が重ならないという不変条件により、面積の合計が和集合面積の計算と同等であることが保証されるためです。 境界ボックスをチェックすると、形状が正方形であることが保証されます。 長方形は境界ボックスを越えて拡張することも、重なり合うこともできないため、領域が一致する場合は隙間は生じません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
min_x = float('inf')
min_y = float('inf')
max_x = 0
max_y = 0
total_area = 0

for _ in range(n):
    x1, y1, x2, y2 = map(int, input().split())
    min_x = min(min_x, x1)
    min_y = min(min_y, y1)
    max_x = max(max_x, x2)
    max_y = max(max_y, y2)
    total_area += (x2 - x1) * (y2 - y1)

width = max_x - min_x
height = max_y - min_y

if width != height or total_area != width * height:
    print("NO")
else:
    print("YES")
```コードはアルゴリズムを直接実装します。 境界ボックスの初期化を慎重に処理すると、ゼロから始まる四角形のエラーが回避されます。 使用する`float('inf')`あらゆる入力が最小値を正しく更新することを保証します。 この問題では重複がないことが保証されているため、四角形領域の合計は機能し、二重にカウントされません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    min_x = float('inf')
    min_y = float('inf')
    max_x = 0
    max_y = 0
    total_area = 0

    for _ in range(n):
        x1, y1, x2, y2 = map(int, input().split())
        min_x = min(min_x, x1)
        min_y = min(min_y, y1)
        max_x = max(max_x, x2)
        max_y = max(max_y, y2)
        total_area += (x2 - x1) * (y2 - y1)

    width = max_x - min_x
    height = max_y - min_y

    return "YES" if width == height and total_area == width * height else "NO"

# provided samples
assert run("5\n0 0 2 3\n0 3 3 5\n2 0 5 2\n3 2 5 5\n2 2 3 3\n") == "YES", "sample 1"

# custom cases
assert run("1\n0 0 1 1\n") == "YES", "single rectangle square"
assert run("2\n0 0 1 2\n1 0 2 2\n") == "NO", "rectangles form rectangle, not square"
assert run("3\n0 0 2 1\n0 1 1 2\n1 1 2 2\n") == "YES", "L-shaped fills 2x2 square"
assert run("2\n0 0 3 3\n3 0 6 3\n") == "NO", "two rectangles side by side non-square"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 つの長方形 1x1 | はい | 最小入力、正方形を形成する単一の長方形 |
 | 2 つの長方形 1x2 + 1x2 | いいえ | 長方形結合は正方形ではなく長方形です |
 | 2x2 の L 字型を形成する 3 つの長方形 | はい | 面積の合計は正方形に等しく、角が接触しているかどうかを確認します。 
| 2 つの長方形を並べて 3x3 | いいえ | 境界ボックスは長方形、面積の合計は一致しますが、正方形ではありません |

 ## 特殊なケース

 L 字型の配置は、エッジまたはコーナーでのみ接触する長方形が正しく処理されることを示しています。 このアルゴリズムは面積合計と境界ボックスに依存しているため、2x1 + を形成する 2 つの長方形など、ギャップのある構成は自動的に拒否されます。
