 ## 問題の理解

 プレイしなければならないフットボールの試合の正確な数が与えられているので、特定のトーナメント形式で正確にその数の試合を行うチームの可能な初期数をすべて見つける必要があります。 

トーナメントはエリミネーションラウンドから始まりますが、これは残りチームの数が同数の間のみです。 このような各ラウンドでは、チームがペアになり、ペアごとに 1 つのゲームが行われ、チームの半分が敗退します。 

最終的には残りチーム数が奇数になってしまいます。 1 チームだけが残った場合、トーナメントは直ちに終了します。 それ以外の場合は、残りのすべてのチームが完全な総当たりトーナメントをプレイし、各チームのペアが 1 回ずつ対戦します。 

入力は単一の整数です`n`、必要な合計ゲーム数。 出力は、正確に次の結果につながるすべての初期チーム数です。`n`ゲーム、昇順に印刷されます。 

制約が重要な問題です。 の値`n`と同じ大きさにすることができます`10^18`, したがって、多くの候補チームのカウントを直接試行するアルゴリズムは不可能です。 まで繰り返しても`√n`すでにそこら中にあるだろう`10^9`operations in the worst case. 実行時間が関係する数値のサイズに対数的にのみ依存するソリューションが必要です。 

いくつかの特殊なケースは見落とされがちです。 

考慮する`n = 1`。 不注意な解決策では、すべての有効なトーナメントが最終的にラウンドロビン ステージに到達すると想定する可能性があります。 それは誤りです。 2 つのチームで開始すると、1 つのエリミネーション ゲームが行われ、その後 1 つの勝者が与えられます。 正しい出力は次のとおりです。```
2
```考慮する`n = 3`。 有効な答えは 2 つあります。```
3
4
```3 つのチームで開始すると、すぐに 3 試合のラウンドロビンが行われます。 4 チームで開始すると 2 つのエリミネーション ゲームが生成され、2 つのチームが残り、さらに 1 つのエリミネーション ゲームが行われ、合計 3 つのゲームになります。 奇数のチーム数のみを検索するソリューションでは失敗します。`4`。 

もう 1 つの微妙なケースは、複数の異なる 2 のべき乗が同じ回答構造を分割する場合です。 初期チーム数が異なると、ゲーム合計が同じになる可能性があるため、最初の試合後に停止するのではなく、すべての有効な解を収集して並べ替える必要があります。 

## アプローチ

 最も直接的なアプローチは、考えられるすべての初期チーム数を試すことです`m`、トーナメントをシミュレートし、ゲーム数を計算し、それが等しいかどうかを確認します。`n`。 

シミュレーションは簡単です。 チーム数が偶数である間に繰り返し半分にし、追加します`m/2`毎回ゲーム。 奇数のとき`k`残っている、追加する`k(k-1)/2`ラウンドロビンゲーム。 

この強引な方法は、トーナメントのルールに正確に従っているため、正しいです。 問題は検索スペースです。 答えはこれよりもはるかに大きくなる可能性があります`10^9`実際、有効なチーム数は約数ある可能性があります。`10^18`。 候補者を列挙することはまったく不可能です。 

トーナメントの構造は、よりよく説明されています。 

初期のチーム数が$$m = 2^t \cdot k$$どこ`k`奇数です。 

最初のエリミネーションラウンド後のチーム数は、$$2^{t-1}k$$2回目以降は、$$2^{t-2}k$$等々。 

まさにその後`t`除去段階、`k`チームは残り、そして`k`奇数です。 

エリミネーションゲームが貢献する$$2^{t-1}k + 2^{t-2}k + \cdots + k$$それは$$k(2^t-1).$$最終ラウンドロビンで貢献$$\frac{k(k-1)}2.$$したがって、すべての有効なトーナメントは次の条件を満たします。$$n = k(2^t-1)+\frac{k(k-1)}2.$$並べ替えた後、$$n=\frac{k(2^{t+1}+k-3)}2.$$これで、検索スペースが小さくなります。 以来`k`奇数で正であり、`2^t ≤ 10^{18}`、指数`t`約 60 個の値しか取ることができません。 

固定の場合`t`、方程式は二次式になります。`k`:$$k^2+(2^{t+1}-3)k-2n=0.$$これは整数演算を使用して解決できます。 それぞれの可能性について`t`、二次方程式に正の奇数の整数根があるかどうかを確認します。 このようなルートごとに有効なチーム数が得られます$$m=2^t k.$$これにより、検索の問題が軽減されます。`10^{18}`候補者は約 60 の指数だけをチェックします。

 ## アルゴリズムのチュートリアル

 1. しましょう`n`必要なゲーム数になります。 
2. すべての指数を反復処理する`t`から`0`上向きにしながら`2^t ≤ 10^18`。 
3. 現在のところ`t`、 定義する$$a = 2^{t+1}-3.$$方程式は次のようになります$$k^2+ak-2n=0.$$1. 判別式を計算する$$D=a^2+8n.$$整数解は次の場合にのみ存在します。`D`は完全な正方形です。 

1. しましょう`s = √D`。 もし`s² ≠ D`、この指数をスキップします。 
2. 二次公式は次のようになります。$$k=\frac{-a+s}{2}.$$分子が正で偶数であることを確認してください。 

1. 次のことを確認します。`k`ポジティブで奇数です。 すべてのエリミネーション ステージ後の残りのチームには、奇数の値のみが対応します。 
2.構築する$$m = 2^t k.$$1. トーナメントのゲーム数を次から再計算します。`m`導出された式を使用して、それが等しいことを確認します`n`。 これにより、算術上の間違いを防ぐことができます。 
2. 有効なものをすべて保存します`m`。 
3. すべての指数を処理した後、答えを並べ替えて印刷します。 存在しない場合は印刷します`-1`。 

### なぜ効果があるのか

 すべての初期チーム数は次のように一意に書くことができます。`m = 2^t k`どこ`k`奇数です。 トーナメントでは常に正確なパフォーマンスが行われます`t`消去段階で終了します。`k`チーム。 

除去フェーズはまさに貢献します`k(2^t-1)`ゲーム、ラウンドロビンフェーズはまさに貢献します`k(k-1)/2`ゲーム。 したがって、有効な解決策はすべて次の条件を満たす必要があります。$$n=\frac{k(2^{t+1}+k-3)}2.$$逆に、奇数の正の整数の場合は常に`k`一部の場合はこの式を満たします`t`、チーム数`m=2^t k`正確に生成します`n`ゲーム。 アルゴリズムは考えられるすべての指数を列挙します`t`、すべての整数の根を検索します`k`したがって、すべての有効な初期チーム数が 1 回だけ検出されます。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

def main():
    n = int(input())

    ans = []

    p = 1  # 2^t
    while p <= 10**18:
        a = 2 * p - 3
        D = a * a + 8 * n

        s = isqrt(D)
        if s * s == D:
            num = s - a

            if num > 0 and num % 2 == 0:
                k = num // 2

                if k > 0 and k % 2 == 1:
                    games = k * (p - 1) + k * (k - 1) // 2

                    if games == n:
                        ans.append(p * k)

        p <<= 1

    ans.sort()

    if not ans:
        print(-1)
    else:
        print("\n".join(map(str, ans)))

if __name__ == "__main__":
    main()
```ループは、可能なすべての値を列挙します。`2^t`。 超過するまでのそのような値は 60 個未満です`10^18`そのため、アルゴリズムは非常に高速です。 

各指数について、奇数の剰余の二次方程式を導出します。`k`。 判別テストは重要です。 整数係数を持つ二次式は、判別式が完全二乗である場合にのみ整数根を持ちます。 

表現```
num = s - a
```は二次公式から直接得られます。 それが正で 2 で割り切れることを検証する必要があります。そうでない場合は、`k`は整数ではありません。 

ゲームカウントの最終的な再計算は完全に整数演算で実行されます。 Python の任意精度の整数ではオーバーフローの懸念が解消されますが、真に有効な解のみが出力されることが保証されるため、検証ステップは依然として役立ちます。
