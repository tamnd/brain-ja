 ## 解決策
 ## 問題の理解

 無向グラフが与えられ、すべての頂点に整数の色を割り当てる必要があります。 色付けは、自明ではない方法で相互作用する 2 つのグローバル条件によって制約されます。 

まず、単一色のすべての頂点に注目すると、それらの頂点には、誘導されたサブグラフ内にサイクルが含まれていてはなりません。 つまり、各色のクラスがフォレストを形成する必要があります。 

第二に、カラーリングは色全体にわたって構造が豊かでなければなりません。 グラフに表示される個別の色のすべてのペアについて、これら 2 つの色の頂点のみを使用し、両方の頂点を少なくとも 1 回使用するサイクルが元のグラフに少なくとも 1 つ存在する必要があります。 

したがって、各色は個別に「非周期的」ですが、任意の 2 つの色はグラフ内のどこかで「周期的に相互作用」する必要があります。 

入力は複数のグラフで構成されます。 各グラフについて、そのような色付けを作成するか、それが不可能であると報告します。 

制約は非常に大きく、1 つのテスト ファイルに最大 2×10^6 の頂点と 3×10^6 のエッジが含まれます。 これにより、素朴な方法でエッジごとに二次関数や超線形さえも即座に除外されます。 有効なソリューションは基本的に、グラフのサイズが線形である必要があり、おそらく対数オーバーヘッドが小さい必要があります。 これは、色分けを検索するのではなく、そのような色分けを認めるグラフの構造的特徴付けを期待する必要があることも示唆しています。 

重要な微妙なエッジ ケースは、グラフにサイクルがまったくない場合です。 その場合、複数の色が使用されると、いかなる種類のサイクルも存在しないため、2 番目の条件は不可能になります。 したがって、単一の色を使用するか、失敗するかのどちらかです。 ただし、1 つの色を使用する場合は、異なる色のペアが存在しないため、2 番目の条件は事実上真になります。 このため、木はきれいに扱わなければならない特別なケースになります。 

グラフが切断されると、別のエッジ ケースが発生します。 二色サイクルに関する条件は、コンポーネント内に個別に存在するのではなく、グラフ自体に存在するサイクルに依存します。 接続されたコンポーネントごとに独立して推論する素朴なアプローチは失敗します。色を混合するサイクルでは、たとえサイクル自体がコンポーネント内にあるとしても、色分布の論理的な意味でコンポーネント間のエッジが依然として必要になる可能性があるためです。 

最後に、ブリッジを含むグラフには問題があります。 ブリッジはどのサイクル上にも存在できないため、ブリッジの端点をそのエッジを含む 2 色のサイクルに強制することはできません。 これはすでに橋の構造が中心であることを示唆しています。 

## アプローチ

 ブルートフォース解釈では、色の割り当てと両方の制約のチェックを試行します。 色付け後、すべての単色サブグラフを計算して非循環性を検証し、次に色のペアごとに二色サイクルが存在するかどうかを確認します。 効率的なサイクル検出を行ったとしても、色のペアの数は色の数において 2 次であり、サイクルの存在チェックはグラフの大部分を繰り返し実行することになるため、これは実行不可能になります。 最悪の場合、これは O(n^2 + m・colors) のようなものにまで縮退し、これは限界をはるかに超えています。 

重要な観察は、サイクルが重要な唯一の構造であり、橋はまさにどのサイクルにも参加しないエッジであるということです。 すべてのブリッジを縮小すると、すべてのエッジが少なくとも 1 つのサイクル上にあるグラフが残ります。 これはまさに、グラフの 2 つのエッジが接続されたコア、つまりブリッジ ツリー分解です。 

2 つのエッジで接続された各コンポーネント内では、任意のエッジがサイクルに参加し、特に頂点間を移動する方法が複数あります。 この構造はまさに二色サイクルの存在を可能にします。

次に、2 番目の条件が何を要求しているかを考えてみましょう。 任意の 2 つの色 c1 と c2 については、両方の色を含み、他の色を含まないサイクルが存在する必要があります。 これは、すべての色のペアが単一のサイクルを含む領域内に共存する必要があることを強く示唆しています。 これをグローバルに保証する唯一の方法は、すべての色付きの頂点が単一の 2 エッジ接続コンポーネント内に存在するようにすることです。 そうしないと、ブリッジで区切られた部分に分割された色が一緒にサイクルを形成できなくなります。 

これは、複数の色が必要な場合、グラフ全体が 2 つのエッジで接続されている必要があることをすでに暗示しています。 グラフにブリッジがある場合、それらのブリッジはグラフをコンポーネントのツリーに分割し、すべてのサイクルは 1 つのコンポーネントに限定されます。 したがって、別のブリッジ コンポーネントに表示される色は、サイクル内で別のコンポーネントの別の色と相互作用することができず、要件に違反します。 

したがって、非自明な解の場合、グラフは 2 エッジ接続されている必要があります。 2 つのエッジが接続されたグラフになった後も、単色サイクルを避ける必要があります。 これにより、各色のクラスが強制的にフォレストになります。 これを強制する自然な方法は、どのサイクルも単色ではないことを保証する方法で、DFS 順序付けパリティ構造に基づいて色を割り当てることです。 

2 エッジ接続グラフで両方の制約を満たす最も単純な構造は、正確に 3 つの色を使用し、バック エッジが各サイクルで色の混合を強制するように DFS トラバーサルに基づいてそれらを割り当てることです。 中心となるアイデアは、DFS ツリーを使用し、深度法 3 に従って頂点に色を付けることです。または、より慎重には、各サイクルで必ず 3 つの残基すべてが少なくとも 1 回使用されるように、すべてのエッジが色の異なる頂点を接続するようにすることです。 

2 エッジ接続グラフでは、すべてのエッジが少なくとも 1 つのサイクルの一部であるため、DFS 深度に沿った一貫したモジュロ カラーリングにより、サイクルが単色のままにならないことが保証されます。 同時に、3 色すべてが十分に豊富なサイクル構造ごとに出現し、すべての色のペアに二色サイクルが存在することが保証されます。 

グラフがツリーの場合は、単一色を出力します。 

グラフが接続されていない場合、またはブリッジがある場合、唯一の一貫した解決策は、サイクルが存在するかどうかに応じて、不可能であるか、単純な単色の場合に限定されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースカラーリング + 検証 | O(n^2 + nm) | O(n + m) | 遅すぎる |
 | ブリッジ分解 + DFS カラーリング | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちはブリッジ分解と DFS 構造に依存しています。 

1. 標準の DFS ローリンク アルゴリズムを使用して、グラフ内のすべてのブリッジを計算します。 これにより、どのサイクルにも属さないエッジが識別されます。 これが必要な理由は、ブリッジの境界を越えてサイクルベースの要件を満たすことができないためです。 
2. グラフにエッジがない場合は、n = 1 でない限り NO を返します。この場合、任意の簡単な色付けが機能します。 これは、サイクルが存在できない縮退ケースを処理します。 
3. グラフにブリッジが含まれており、他の場所に少なくとも 1 つのサイクルがある場合、構造が有効な色付けをサポートできるかどうかを確認します。 すべてのブリッジはサイクル ドメインの分離を意味し、すべての色のペアがサイクルを共有する必要があるため、複数のサイクルで分離された領域には互換性がありません。 したがって、ブリッジがあり、複数の頂点がサイクルに参加している場合は、単一の色にフォールバックしない限り拒否します。 
4. グラフがツリー (m = n − 1) の場合、SI 1 を出力し、すべてを 1 で色付けします。サイクルがないため、両方の条件が空虚に成立します。 
5. それ以外の場合、グラフは 2 エッジ接続構造として扱われるか、その循環コアに制限されます。 DFS を実行し、深度モジュロ 3 に基づいて色を割り当てます。 
6. SI 3 と割り当てられた色を出力します。 すべての頂点には、深さに応じてカラー 1、2、または 3 が割り当てられます。

この選択が機能する理由は、グラフ内のすべてのサイクルに DFS ツリー内に少なくとも 1 つの前方エッジと 1 つの後方エッジが含まれている必要があるためです。 モジュロ 3 深度は、そのようなサイクルに異なる深度 mod 3 の頂点を強制的に含めることを強制し、単色サイクルを防ぎます。 同時に、グラフはサイクルが豊富であるため、DFS 構造内の迂回によって形成されたサイクル内にすべての色のペアが一緒に表示されます。 

### なぜ効果があるのか

 不変条件は、DFS ツリー パスに沿って、深度に応じて色が周期的に変化し、すべてのバック エッジが、端点の深さが少なくとも 1 異なるサイクルを閉じるということです。 深度モジュロ 3 が使用されるため、どのサイクルにも少なくとも 2 つの異なる剰余が含まれている必要があり、実際、2 エッジ接続グラフでは、隣接制約を破ることなく 3 つの剰余すべてを一貫して回避することはできません。 これにより、サイクルが単色になることがなくなります。 

二色条件の場合、任意の 2 色が 2 つの剰余 mod 3 に対応します。2 エッジ接続グラフでは、DFS サイクルは必然的に複数の深さレベルを横断するため、サイクルの適切なセグメントを選択することで 3 番目の残基を除外しながら、両方の残基を含めるのに十分な深さの変動にわたるサイクルが存在します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    edges = []

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    if m == n - 1:
        print("SI 1")
        print(" ".join(["1"] * n))
        return

    tin = [-1] * n
    low = [0] * n
    timer = 0
    bridges = set()

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to in g[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.add((min(v, to), max(v, to)))

    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)

    if bridges:
        print("NO")
        return

    color = [-1] * n

    def dfs2(v, p, d):
        color[v] = d % 3 + 1
        for to in g[v]:
            if to == p:
                continue
            if color[to] == -1:
                dfs2(to, v, d + 1)

    for i in range(n):
        if color[i] == -1:
            dfs2(i, -1, 0)

    print("SI 3")
    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
```このソリューションは、最初にグラフを構築し、すぐにツリーのケースを処理します。これは、サイクルが存在しないが制約は依然として満たされる唯一の状況であるためです。 

ブリッジ検出 DFS は、標準の錫および低アレイを使用します。 子のローリンク値が親の検出時間を超えるエッジを検出すると、そのエッジはブリッジになります。 ブリッジが存在すると、マルチカラーの周期的相互作用の要件が無効になるため、直ちに拒否します。 

ブリッジが存在しない場合、グラフは各コンポーネントで完全に 2 エッジ接続されます。 次に、深度を追跡し、深度モジュロ 3 として色を割り当てる 2 番目の DFS を使用して色を割り当てます。減算とモジュロ演算は、それ以上のブックキーピングを必要とせずに、3 つの色にわたる分布を確保するのに十分です。 

重要な点は、色付け後にサイクルを明示的にチェックする必要がないことです。 ブリッジがないことにより、すべてのエッジが何らかのサイクルの一部であることが保証され、モジュロ 3 の割り当てにより、サイクルが単一の剰余クラス内に留まらないことが保証されます。

 ## 特殊なケース

 重要なエッジ ケースは、ほぼツリーであるが、単一のサイクルを形成する 1 つの余分なエッジを含むグラフです。 例えば：```
4 4
1 2
2 3
3 4
4 2
```ブリッジ検出中、サイクルの外側のエッジのみがブリッジですが、少なくとも 1 つのサイクルが存在するため、グラフがマルチカラーリングに有効であれば、コア サイクル構造にブリッジが残らないようにする必要があります。 DFS カラーリングは深さを割り当て、mod 3 を交互に繰り返す残基を生成します。サイクル 2-3-4 には異なる色の頂点が含まれるため、単色にすることはできず、すべての色のペアがそのサイクル内に表示されます。 

もう 1 つのエッジケースは純粋なツリーです。 ブリッジ検出ではすべてのエッジがブリッジとして検出され、マルチカラー ロジックで即座に拒否されます。 特別な m = n − 1 処理により、インスタンスを誤って拒否するのではなく、単一の色を出力することが保証されます。
