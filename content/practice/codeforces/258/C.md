 ## 問題の理解

 配列が与えられています`a`。 あらゆるポジションについて`i`、整数を選択する必要があります`b_i`そのような`1 ≤ b_i ≤ a_i`。 

シーケンス`b`最小公倍数が最大要素と等しい場合、それは良好であると呼ばれます。 

適切なシーケンスを直接数えるのではなく、両方の数量が共有する必要がある値を考える方が有益です。 もし$$\operatorname{lcm}(b_1,\dots,b_n)=\max(b_1,\dots,b_n)=m,$$その場合、選択された値はすべて除算する必要があります`m`そうでない場合、LCM は次の値よりも大きくなります。`m`。 同時に、少なくとも 1 つの位置に正確に含まれている必要があります。`m`それ以外の場合、最大値は以下より小さくなります。`m`。 

タスクは、すべての有効なシーケンスをカウントすることです`b`～によって課される上限を満たす`a`、モジュロ$10^9+7$。 

制約は、ソリューションの形状を完全に決定します。 まであります$10^5$ポジション、そしてあらゆる`a_i`せいぜい$10^5$。 二次的な方法で位置と値を一緒に処理するアルゴリズムは不可能です。 平$10^5 \times 10^5$operations would be far beyond the limit. の小さな値の境界$10^5$が重要な観察です。 値の範囲に該当する配列要素の数を数えて、考えられる最大値を反復処理することを提案します。

## アプローチ

 最も直接的なアプローチは、考えられるすべてのシーケンスを列挙することです。`b`、その最小公倍数と最大値を計算し、それらが一致するかどうかを確認します。 

これは文字通り定義に従っているので正しいです。 残念ながら、たとえすべてが終わったとしても、`a_i = 10`、すでにあります$10^n$可能なシーケンス。 と$n = 10^5$、力技は絶望的です。 

次のアイデアは、共通の値を固定することです$$m=\operatorname{lcm}(b)=\max(b).$$固定の場合`m`、選択されたすべての値は次の約数である必要があります。`m`。 また、少なくとも 1 つの選択された値が正確に一致する必要があります。`m`。 

ここで問題は、除数制約の下で代入をカウントすることになります。 

すべての約数がわかっているとします。`m`昇順で:$$d_1 < d_2 < \dots < d_k=m.$$制限がかかるポジションについては、`x`、許可される選択肢の数は、`m`を超えないもの`x`。 

これにより、問題がカウントの積に変換されます。 

残りの課題は、これらの製品をあらゆるレベルで効率的に評価することです。`m ≤ 100000`。 

重要な観察は、約数の数が以下を超えないことです。`x`変更されるのは次の場合のみです`x`の約数と交差します`m`。 

もし$$d_r \le x < d_{r+1},$$それから正確に`r`の約数`m`利用可能です。 

配列の各位置を個別に処理する代わりに、配列の位置がいくつあるかを数えます。`a_i`連続する約数間の各間隔に該当します。 すべての値が最大であるため、`100000`、プレフィックス周波数配列を使用すると、これらのカウントを一定時間で取得できます。 

すべての整数の中で出現する約数の合計数。`100000`は$$\sum_{i=1}^{100000}\tau(i)\approx 1.17\times10^6,$$管理が簡単です。

 ## アルゴリズムのチュートリアル

 1. 配列を読み取り、値の頻度表を計算します。 
2. プレフィックス数の配列を構築する`pref`、 どこ`pref[x]`インデックスの数と等しい`a_i ≤ x`。 
3. 最大のすべての整数の除数リストを事前計算します。`100000`除数ふるいを使用します。 
4. しましょう`m`は、最小公倍数と最大値の両方の候補値になります。 
5. ソートされた約数を取得します。`m`:$$d_1<d_2<\dots<d_k=m.$$6. インターバルごとに$$[d_r,\ d_{r+1}-1],$$その中に含まれる配列要素の数を数えます。$$E_r = \text{pref}[d_{r+1}-1] - \text{pref}[d_r-1].$$このような位置はすべて正確に`r`利用可能な約数`m`。 
7. 乗算$$\prod_{r=1}^{k-1} r^{E_r}.$$これにより、上限が以下のすべてのポジションの選択肢がカウントされます。`m`。 
8. しましょう$$C=n-\text{pref}[m-1].$$これらはまさに次のような位置です`a_i ≥ m`。 

それぞれが次のいずれかを使用できます。`k`の約数`m`。 
9. これらの代入のうち、除数を使用しないものを減算します。`m`。 

有効な割り当ての数は次のとおりです。$$k^C-(k-1)^C.$$これは標準的な包含/除外ステップです。 
10. ステップ 7 の結果とステップ 9 の結果を乗算し、それを全体的な答えに追加します。 
11. ごとに繰り返します`m`から`1`に`100000`。 

### なぜ効果があるのか

 値を修正する`m`。 

LCM と最大値が等しいすべての良好なシーケンス`m`2つの条件を満たさなければなりません。 すべての要素は分割する必要があります`m`、それ以外の場合は LCM が超過します`m`。 少なくとも 1 つの要素が等しい必要があります`m`、それ以外の場合、最大値は以下より小さくなります`m`。 

区間分解では、約数が何個あるかを正確にカウントします。`m`各ポジションでご利用いただけます。 間隔にわたる積は、次の除数を使用してすべての割り当てをカウントします。`m`。 要因$$k^C-(k-1)^C$$少なくとも 1 つの位置で除数が使用されている割り当てを正確に保持します。`m`。 

すべての良好なシーケンスは、次の 1 つの値にのみ寄与します。`m`、つまり、その共通の LCM と最大値です。 さまざまな値`m`素のシーケンスのセットを生成します。 すべての寄与を合計すると、すべての良好なシーケンスが 1 回だけカウントされます。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

MOD = 1000000007
MAXV = 100000

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    freq = [0] * (MAXV + 1)
    for x in a:
        freq[x] += 1

    pref = [0] * (MAXV + 1)
    for i in range(1, MAXV + 1):
        pref[i] = pref[i - 1] + freq[i]

    divisors = [[] for _ in range(MAXV + 1)]
    for d in range(1, MAXV + 1):
        for multiple in range(d, MAXV + 1, d):
            divisors[multiple].append(d)

    max_tau = max(len(divisors[i]) for i in range(1, MAXV + 1))

    pw = [None] * (max_tau + 1)
    pw[0] = array('I', [0] * (n + 1))

    for base in range(1, max_tau + 1):
        arr = array('I', [0] * (n + 1))
        arr[0] = 1
        for e in range(1, n + 1):
            arr[e] = (arr[e - 1] * base) % MOD
        pw[base] = arr

    ans = 0

    for m in range(1, MAXV + 1):
        ds = divisors[m]
        k = len(ds)

        cur = 1

        for r in range(1, k):
            left = ds[r - 1]
            right = ds[r] - 1

            cnt = pref[right] - pref[left - 1]
            cur = (cur * pw[r][cnt]) % MOD

        c = n - pref[m - 1]

        add = pw[k][c]
        if k > 1:
            add -= pw[k - 1][c]

        cur = (cur * add) % MOD
        ans += cur

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```周波数配列とプレフィックス配列を使用すると、範囲カウントのクエリに一定時間で答えることができます。 連続する約数間のすべての間隔は、2 つのプレフィックス値の単純な減算になります。 

除数ふるいが標準です$$O(M \log M)$$工事。 各整数は、その倍数の除数リストに挿入されます。 

電力テーブルは、値ではなく除数ランクによってインデックス付けされます。 までの任意の数の約数の数`100000`決して超えない`128`したがって、事前に計算する必要があるのは少数の基数だけです。 これにより、メインループ内で 100 万を超えるべき乗剰余演算を実行することが回避されます。 

最もデリケートな部分が要因です$$k^C-(k-1)^C.$$少なくとも 1 つの位置で除数が使用されている割り当てをカウントします。`m`。 この減算を忘れると、実際には最大値が以下のシーケンスを多数カウントすることになります。`m`。 

もう一つの微妙なケースは、`m = 1`。 それから`k = 1`、減算項はゼロでなければなりません。 コードではこれを個別に処理します。
