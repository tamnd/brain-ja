 ## 解決策
 ## 問題の理解

 平面上に A、B、C、D という固定順序で 4 つの点が与えられます。課題は、D から A に戻るエッジも含めて、この順序でそれらを接続すると幾何学的正方形を形成するかどうかを判断することです。 

これは、任意に並べ替えることができる「4 点のセット」の問題ではありません。 エッジは明示的に AB、BC、CD、DA であるため、順序は重要です。 したがって、この正確なサイクルが正方形を表すかどうかを確認しています。 

各点には適度な範囲内に制限された整数座標があるため、すべての幾何学的計算は整数を使用して安全に実行できます。 座標の大きさは最大 10^4 であるため、距離の 2 乗は 64 ビット整数に快適に収まり、浮動小数点演算は必要ありません。 

単純な間違いは、4 つの点を順序のないセットとして扱い、距離または角度を並べ替えることによって正方形を推測しようとすることです。 有効な正方形は巡回順序に依存するため、これは失敗します。 たとえば、同じ 4 つの点を正しく順序付けすると正方形を形成できますが、並べ替えると自己交差形状または非正方形の四角形になります。 

もう 1 つのよくある落とし穴は、浮動小数点ジオメトリ、特に角度の比較に依存することです。 これは不必要であり、精度誤差のため危険です。 ドット積と二乗長を使用すると、すべてを正確に表現できます。 

微妙なエッジケースは、点が正方形ではないひし形を形成する場合です。 すべての辺を等しくすることはできますが、角度は 90 度ではありません。 もう 1 つは、正方形ではない長方形で、向かい合う辺は等しいが、隣接する辺が異なります。 どちらも拒否する必要があります。 

## アプローチ

 強引なアイデアは、4 つの点のすべての順列を考慮し、それらをサイクルとして解釈し、順序が正方形を形成するかどうかをテストすることです。 各順列について、4 辺すべての長さと角度を計算します。 4つあるので！ = 24 の順列、これはテスト ケースごとに一定の作業であり、依然として実行可能です。 

ただし、問題によって順序がすでに固定されているため、このアプローチは概念的に無駄です。 ポイントを再配置することはできません。 指定されたサイクルを直接検証する必要があります。 

重要な観察は、4 つの辺がすべて等しい、そして少なくとも 1 つの角が直角であるという 2 つの条件が成立する場合に限り、四角形は正方形であるということです。 ベクトル用語では、AB、BC、CD、DA がエッジの場合、隣接するエッジ間の二乗長と直交性が等しいことが必要です。 

これにより、問題全体が 4 つのベクトル、4 つの二乗長、およびいくつかのドット積の計算に軽減されます。

 ## アルゴリズムのチュートリアル

 連続した点によって形成されたベクトルを直接操作します。 

1. 4 つのエッジ ベクトル AB、BC、CD、DA を構築します。 各ベクトルは、座標を減算することによって計算されます (例: AB = B − A)。これにより、方向と長さが整数演算に適した形式でエンコードされます。 
2. 4 つのエッジすべての二乗長を計算します。 長さの二乗では平方根が回避され、長さの比較には等しいことのみが必要となるため、すべてが正確に保たれます。 
3. 4 つの平方の長さがすべて等しいことを確認します。 正方形には合同な 4 つの辺があるため、いずれかのエッジが異なる場合、その形状は正方形にはなりません。 
4. 1 つの頂点 (たとえば点 B) を選択し、隣接するエッジ AB と BC の内積を計算します。 内積が 0 であることは、B での 90 度の角度に相当します。 
5. AB と BC が直角であることを確認します。 そうでなければ、すべての辺が等しいとしても、図形は単なるひし形になるため、正方形ではありません。 
6. 両方の条件が成立する場合は「SIM」を出力し、そうでない場合は「NAO」を出力します。 

1 つの角度だけをチェックする理由は、すべての辺が等しい四角形では、1 つの直角があるとすべての角度が強制的に直角になり、これが正方形を完全に特徴付けるためです。 

### なぜ効果があるのか

このアルゴリズムでは、すべての辺が合同であることが強制され、形状が菱形に制限されます。 ひし形では、すべての頂点は 180 度回転すると対称になり、すべての角度はペアで等しくなります。 1 つの角度が 90 度の場合、すべてが 90 度になる必要があり、ひし形は正方形になります。 したがって、等しい辺の長さと単一の直交隣接条件は完全な正方形構造を保証するのに十分であり、固定された順序により、サイクルを検索するのではなく正しいサイクルを検証することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sq_len(ax, ay, bx, by):
    dx = bx - ax
    dy = by - ay
    return dx * dx + dy * dy

def dot(ax, ay, bx, by, cx, cy):
    # AB · BC where A->B->C
    return (bx - ax) * (cx - bx) + (by - ay) * (cy - by)

def solve():
    pts = [tuple(map(int, input().split())) for _ in range(4)]
    A, B, C, D = pts

    ax, ay = A
    bx, by = B
    cx, cy = C
    dx, dy = D

    d1 = sq_len(ax, ay, bx, by)
    d2 = sq_len(bx, by, cx, cy)
    d3 = sq_len(cx, cy, dx, dy)
    d4 = sq_len(dx, dy, ax, ay)

    if not (d1 == d2 == d3 == d4):
        print("NAO")
        return

    if dot(ax, ay, bx, by, cx, cy) != 0:
        print("NAO")
        return

    print("SIM")

if __name__ == "__main__":
    solve()
```この実装では、まず 4 つの点をロードし、指定された順序で連続する各エッジの二乗距離を計算します。 等価性チェックにより、ひし形の候補を扱っていることが確認されます。 頂点 B での内積テストにより、AB と BC の間の直角が強制されます。 他の角度や対角のプロパティは、閉じたサイクル内の等しい辺と 1 つの直交する角の組み合わせによって暗示されるため、明示的にチェックする必要はありません。 

すべての計算は整数のみで行われるため、精度の問題は完全に回避されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、正方形が回転する場合です。 (1,0)、(2,1)、(1,2)、(0,1) などの入力の場合、アルゴリズムは引き続き 2 番目の点で等しい二乗長とゼロのドット積を計算するため、正しく「SIM」を返します。 これにより、メソッドが回転不変であることが確認されます。 

もう 1 つのケースは、(0,0)、(1,0)、(2,1)、(1,1) など、点が正方形ではない長方形を形成する場合です。 ここでは辺の長さがすぐに異なるため、アルゴリズムは角度チェックを必要とせずにそれを拒否します。 

縮退しているように見えるケースは、(0,0)、(1,1)、(2,2)、(3,3) のような同一直線上またはほぼ同一直線上にある順序付けです。 距離が部分的な対称性を示す場合でも、少なくとも 1 つの側の比較が失敗するか、内積が 0 以外であれば、確実に拒否されます。
