 ## 問題の理解

 最初の行に単一の値が含まれる三角形から始めます`k`。 

以降の行はすべて、前の行から構築されます。 2 つの境界要素は上の行からコピーされますが、すべての内部要素はその上の 2 つの隣接する要素の XOR になります。 

三角形を次のように表すと、`T`、そして漕ぎます`n`含まれています`n`数字。 タスクは全体を出力することです`n`-投げる。 

一見すると、これはパスカルの三角形に非常によく似ています。 唯一の違いは、加算が XOR に置き換えられたことです。 この類似性が問題を解決する鍵となります。 

制約が十分に大きいため、三角形全体を明示的に構築することは不可能です。 単一のテスト ケースで要求される可能性があるのは、`n = 10^6`。 そのレベルまですべての行を構築するには、おおよその必要があります$$1+2+\cdots+n = O(n^2)$$操作、これは約になります$5 \cdot 10^{11}$いつ更新されるか$n=10^6$。 それはまったく手の届かないところにあります。 

要求されたすべての行の長さの合計は最大でも$10^6$。 これは重要なことを教えてくれます。$O(n)$すべてのテスト ケースにわたる合計作業量は線形のままであるため、テスト ケースごとのソリューションは許容されます。 

いくつかの特殊なケースは見落とされがちです。 

考慮する`n = 1`。 

入力：```
1 52
```出力：```
52
```適用する再発はありません。 答えは単純に最初の行です。 

もう 1 つの微妙なケースは、要求された行インデックスが 2 の累乗 + 1 である場合です。 

例えば：```
n = 9, k = 1
```答えは次のとおりです。```
1 0 0 0 0 0 0 0 1
```小さな行で数値パターンを検索する単純な試みは、ここで失敗することがよくあります。 正しい構造は、値自体からではなく、二項係数のパリティ特性から得られます。 

最後の落とし穴は、答えが次のビットに依存すると仮定していることです。`k`。 行全体は、特定の係数が奇数か偶数かによってのみ決定されます。 ゼロ以外のすべてのエントリは正確に`k`決してそれの変形バージョンではありません。 

## アプローチ

 最も直接的な解決策は、再発をシミュレートすることです。 

から始まる`[k]`、次の行を繰り返し構築します。 各内部位置は、前の行の 2 つの隣接する値の XOR であり、境界線がコピーされます。 

このアプローチは定義に正確に従っているため、正しいです。 残念ながら、すべての行を次から構築する必要があります。`1`を通して`n`。 総作業量は、$$1+2+\cdots+n = O(n^2).$$のために`n = 10^6`、それは遅すぎます。 

漸化式はパスカルの三角形に非常に似ています。 パスカルの三角形の行のエントリ`r`そしてコラム`c`等しい$$\binom{r}{c}.$$加算を XOR に置き換えることは、モジュロ 2 を効果的に実行することを意味します。XOR はフィールド GF(2) に対する加算であるため、行内の各位置は`n`に等しい$$k \cdot \left(\binom{n-1}{j-1}\bmod 2\right).$$二項係数が奇数の場合、値は次のようになります。`k`。 偶数の場合、値は次のようになります。`0`。 

ここで問題は、次のことを判断することになります。$$\binom{n-1}{j-1}$$奇数です。 

ルーカスの定理の古典的な帰結は次のようになります。$$\binom{a}{b}$$すべてのビットが設定されているときは奇数になります`b`にも設定されています`a`。 ビット単位の形式では次のようになります。$$(b \,\&\, \sim a)=0.$$同様に、$$(a \,\&\, b)=b.$$させて$$m=n-1.$$ポジションについて`j`、 定義する$$r=j-1.$$するとエントリーは`k`もし`(r & m) == r`、 さもないと`0`。 

各要素を一定時間内に独立して生成できるようになり、全体として線形のソリューションが得られます。

 ## アルゴリズムのチュートリアル

 1.読む`n`そして`k`。 
2. コンピューティング`m = n - 1`。 

行内のすべての係数`n`行の二項係数に対応します`m`パスカルの三角形の。 
3. ポジションごとに`j`から`0`に`n-1`、どうかを確認してください`(j & m) == j`。 

まさにその状態です`C(m, j)`奇数です。 
4. 条件が true の場合、追加します`k`答えに。 

奇数の係数は 1 つのコピーを意味します`k`XOR の蓄積後も存続します。 
5. それ以外の場合は追加します`0`。 

偶数の係数は XOR では相殺されます。 
6. 生成された行を出力します。 

### なぜ効果があるのか

 三角形のすべての要素は、加算法 2 である XOR を繰り返し適用することによって形成されます。したがって、漸化式は GF(2) に対して計算されたパスカルの三角形と同じになります。 

元の値の係数`k`位置にある`j`並んで`n`まさに`C(n-1, j)`。 XOR はパリティのみを考慮するため、奇数の係数は 1 つのコピーに寄与します。`k`一方、偶数の係数は何も寄与しません。 

ルーカスの定理は次のことを示しています`C(m, j)`のすべての設定ビットが正確に奇数になる`j`にも存在します`m`。 ビットごとのテスト`(j & m) == j`その状態を正確にチェックします。 したがって、各位置は次のいずれかに正しく分類されます。`k`または`0`、アルゴリズムの正しさを証明します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, k = map(int, input().split())
        m = n - 1

        row = []
        for r in range(n):
            if (r & m) == r:
                row.append(str(k))
            else:
                row.append("0")

        out.append(" ".join(row))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は数学的特徴付けに直接従います。 

変数`m = n - 1`Pascal-triangle 行インデックスに対応します。 あらゆるポジションについて`r`を表します。`j - 1`1 ベースのインデックス付けでは、次のすべてのビットが有効かどうかをテストします。`r`中に含まれている`m`。 

もし`(r & m) == r`、対応する二項係数は奇数であるため、値は次のようになります。`k`。 それ以外の場合はそうです`0`。 

三角形は構築されません。 このコードは、要求された行を線形時間で直接生成します。 

最も一般的な実装上の間違いは、1 から始まるインデックスと 0 から始まるインデックスを混合することです。 パリティテストを適用する必要があるのは、`r = j - 1`、これはまさにループ変数が表すものです。 

もう 1 つのよくある間違いは、二項係数を明示的に計算しようとすることです。 彼らの価値はずっと前に巨大になる`n`が制限に達すると、パリティ テストによってそのような計算がすべて回避されます。
