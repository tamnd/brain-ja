 ## 解決策
 ## 問題の理解

 この問題では、長さの配列を構築するように求められます。`n`その要素がターゲット値に対してビットごとに OR されるようにする`x`配列の MEX を最大化しながら。 MEX (最小除外値) は、配列内に存在しない最小の非負の整数です。 それぞれのテストケースで得られるものは、`n`そして`x`、可能な限り高い MEX で OR 要件を満たす配列を作成する必要があります。 

制約は重要です。`n`最大 200,000 に達する可能性があり、すべてのテスト ケースの合計は 200,000 に制限されます。 これは、考えられるすべてのサブセットを反復する、または実行するソリューションはすべて、`O(n^2)`操作は不可能です。 代わりに、`O(n)`テストケースごとのソリューション。 の値`x`最大で 10 億近くになる可能性があるため、個々の配列要素は次の値より小さくする必要があります。`2^30`。 

エッジケースとは、`n = 1`。 ここで、配列は次のようにする必要があります。`[x]`要素が 1 つしか存在しないためです。 この場合の MEX は、次の場合に 0 になります。`x > 0`、または 1 の場合`x = 0`。 もう 1 つの注意を要するシナリオは次のような場合です。`x`小さいし、`n`大きいです。 素朴に数値を埋める`0`を通して`n-1`を超える可能性があります`x`前の数値と OR をとった場合、注意が必要です。 例えば、`n = 7`、`x = 3`持つことができない`[0,1,2,3,4,5,6]`なぜなら`OR`すべての要素が超過する`3`。 

明らかではない部分は、OR を尊重しながら MEX を最大化することです。 MEX を最大化するには、0 から始まる連続した数値が必要ですが、各数値は次の条件によって「許可」される必要があります。`x`- その設定ビットは、次の設定ビットのサブセットである必要があることを意味します。`x`。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての組み合わせを列挙します。`n`より小さい数値`2^30`OR が次と等しい`x`、それぞれの MEX を計算し、最大値を選択します。 たとえ`n = 20`、組み合わせの数は天文学的に多いため、総当たりは不可能です。 

重要な点は、配列に含まれる数値はビットの外側に設定してはいけないということです。`x`。 つまり、ビットが次のサブセットである数値を自由に使用できるということです。`x`配列を形成します。 また、数字が含まれていることにも注意してください。`0`を通して`k-1`継続的に少なくとも MEX を保証します`k`。 したがって、戦略は、外側のビットを必要とする数字をスキップして、0 から始まるできるだけ多くの連続する数字を選択することです。`x`。 いっぱいになったら`n-1`このように要素を追加すると、最後の要素は必要な OR を達成するために残ったものであれば何でも構いません。`x`。 

問題を 2 つのステップに分割します。ビットが次のサブセットである 0 から始まる数値を生成します。`x`、最後に数値を追加して、OR が正確であることを確認します。`x`。 この貪欲で建設的なアプローチは、`O(n)`与えられた制約の下では十分です。

 | ブルートフォース | O((2^30 n を選択)) | O(n) | 遅すぎる |

 ## アルゴリズムのチュートリアル

 1. 空の配列を初期化する`a`。 
2. から始める`i = 0`かどうかを繰り返し確認します`i`の外にビットがある`x`。 すべてのビットが入っている場合`i`も入っています`x`、 追加`i`に`a`。 いつ停止するか`len(a) = n-1`。 これにより、含まれるすべての数値が OR 制約に違反しないことが保証されます。 
3. 配列の現在の OR を計算します。 配列の最後の要素は次のようにする必要があります。`x`現在の OR を XOR して、合計 OR が等しいことを確認します。`x`。 
4. この最後の要素を`a`。 最後の要素が既存の数値と重複する場合、MEX はすでに最大化されている 0 から始まる連続した数値によって決定されるため、問題にはなりません。 
5. 配列を出力します。 

機能する理由: 貪欲なステップでは、0 から始まる可能な最大の連続した数値ブロックがすべて許可されることを保証します。`x`、が含まれます。 最終的な XOR により、OR 要件が正確に満たされることが保証されます。 追加の操作は必要なく、最大化された MEX を含む有効な配列が生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = []
        i = 0
        while len(a) < n - 1:
            if (i | x) == x:
                a.append(i)
            i += 1
        current_or = 0
        for num in a:
            current_or |= num
        a.append(x ^ current_or)
        print(' '.join(map(str, a)))
```このソリューションは入力を迅速に読み取り、配列を貪欲に構築し、XOR を使用して OR を満たす最終数値を追加します。 ビットが次のサブセットである数値のみを含めるように細心の注意が払われます。`x`。 ループ停止条件`len(a) < n-1`最終的な XOR 要素用のスペースを確保します。

 ## 特殊なケース

 いつ`n = 1`、充填用のループ`n-1`要素はスキップされ、XOR の最後の要素は次のようになります。`x`。 のために`x = 0`、アルゴリズムはゼロを埋め、最後の要素もゼロになります。 のために`x`より小さい`n`、アルゴリズムは外側のビットを持つ数値を自動的にスキップします。`x`配列を貪欲に埋めて、OR を超えることなく最大の MEX を確保します。 各シナリオは、ループ条件と最終的な XOR 計算によって自然に処理されます。
