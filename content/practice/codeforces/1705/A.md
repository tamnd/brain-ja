 ## 解決策
 ## 問題の理解

 合計で$2n$身長がわかっている人。 マークはそれらを 2 列に配置したいと考えています。$n$人はそれぞれ前列と後列です。 要件は、どのポジションでも$j$（から$1$に$n$）、後列の人は少なくとも$x$直前の人よりも背の高いユニット。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$、$x$、およびリスト$2n$ハイツ。 出力は、そのような配置が存在する場合は「YES」、存在しない場合は「NO」のいずれかになります。 

制約は小さいです。$n$せいぜい$100$そして高さはせいぜい$1000$。 これは、$O(n \log n)$ソートベースのソリューションは十分に効率的です。 エッジケースには、すべての高さが等しい状況が含まれます。$x$身長が最も高い人と最も低い人の差よりも大きい場合、または$n = 1$(シングルペア)。 不用意に実装すると、高さを任意にペアにしようとする可能性があり、これらの最小または等しい高さの場合の解決策が失敗する可能性があります。 

たとえば、入力について考えてみましょう。`1 100`高さのある`50 50`。 並べ替えを行わない単純なペアリングは成功したと主張する可能性がありますが、後列の人は前列より 100 単位背が高い人はいないため、正しい出力は「いいえ」になります。 

## アプローチ

 ブルートフォース ソリューションでは、考えられるすべてのサブセットが考慮されます。$n$後列の人々と、前列の残りの人々のすべての順列。 各ペアリングについて、身長差が少なくとも以下であるかどうかを確認します。$x$すべてのポジションに。 これには次のような複雑さがあります$O(\binom{2n}{n} \cdot n!)$、これは、たとえ$n=10$。 

重要な観察は、すべての順列を考慮する必要はないということです。 身長要件を満たす可能性を最大限に高めるには、前列の背が低い人と、後列でその人より背が高く背が低い人をペアにする必要があります。 これは自然にすべてを並べ替えることにつながります$2n$身長別の人。 次に、最初の値を割り当てることができます$n$最前列と最後列までの高さ$n$後列までの高さ。 を確認する$j$-th ペアは、配置が可能かどうかを判断するのに直接十分です。 

この貪欲なアプローチが機能するのは、一度高さがソートされると、他の配置では最小の差を改善できないためです。 後列の背の高い人と前列の背の低い人とを組み合わせると、後列の残りの差が減少します。 ソートでは、ソートされた順序のいずれかのペアで最小条件が満たされない場合、他の順序では成功できないことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2n)! / (n!)²) | O(2n) | 遅すぎる |
 | 選別 + 貪欲 | O(n log n) | O(2n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$、$x$、およびリスト$2n$ハイツ。 
3. 高さのリスト全体を昇順に並べ替えます。 これにより、最小の人が最初に配置され、最も背の高い人が最後に配置されます。 
4. 最初の値を割り当てます$n$最前列と最後列までの高さ$n$後列までの高さ。 
5. 各位置を反復処理します。$j$から$0$に$n-1$。 後列の人の身長から前列の人の身長を引いた値が少なくとも以上であるかどうかを確認します。$x$。 
6. すべての差が一致またはそれを超えている場合$x$、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

機能する理由: 並べ替えにより、最前列に座る可能性のあるすべての人物について、対応する後列の人物が利用可能な最小の身長の高い人物であることが保証されます。 この最小限の構成が失敗した場合、並べ替えによって差異が減少するか、変更されないままになるため、有効な配置は存在しません。 不変条件は、$j$- ソートされた割り当ての後ろの行の高さは、常に、その割り当ての他の考えられる後行の候補以上になります。$j$-最前列の人。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x = map(int, input().split())
    heights = list(map(int, input().split()))
    heights.sort()
    front = heights[:n]
    back = heights[n:]
    possible = True
    for j in range(n):
        if back[j] - front[j] < x:
            possible = False
            break
    print("YES" if possible else "NO")
```このソリューションは、次を使用して入力を効率的に読み取ることから始まります。`sys.stdin.readline`。 並べ替えにより、高さの差を最大化するために前列と後列が確実に選択されます。 ループは各位置を明示的にチェックし、違反が検出された場合は早期のブレークにより不必要な比較を回避します。 微妙な点ですが、次のことを覚えておいてください。`heights[n:]`後列の背の高い半分を正しくスライスします。

                break
