 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、それを一定数の連続するセグメントに分割するように求められます。 各セグメントには、その中のすべての要素をビットごとの演算スコア (問題全体の定式化に応じて AND/OR 集計から構築) と組み合わせて定義された値があります。 すべてのセグメントにスコアが付けられると、最終的な答えは、クエリの種類に応じて、最適なパーティショニングの下で​​可能な最大値または最適なパーティショニングの下で​​可能な最小値として定義されます。 

最大の難点は、セグメントのスコアが通常の意味での加算的または凸的ではないことです。 これはビット単位の構造に依存し、セグメントを拡張または縮小すると、その値が長さに関して非線形ではあるが単調に変化する可能性があります。セグメントを拡張しても、そのスコアは低下するか、または安定したままになるだけです。 

入力サイズが十分に大きいため、すべてのパーティションを列挙するソリューションは不可能です。 プレフィックス上の二次動作でさえすでに遅すぎるため、二分探索またはパラメトリック最適化と組み合わせた線形または線形に近いスキャンを余儀なくされます。 これは、各実現可能性チェックが最大でも O(N) または O(N log N) でなければならないことを直ちに示唆しており、すべてのパーティションを列挙することを伴う解決策は除外されます。 

セグメント間の独立性を仮定すると、常に微妙な失敗例が発生します。 たとえば、将来の制約を考慮せずに各セグメントを貪欲に最大化すると、作成するセグメントが少なすぎたり、多すぎたりする可能性があります。 セグメント スコアが要素間で共有されるビット単位の構造に依存することを無視して、セグメント スコアを独立したスカラー値として扱う場合、別の失敗ケースが発生します。 

たとえば、スコアがしきい値を超えている間は常にセグメントを拡張する単純な貪欲を考えてみましょう。 これは実現可能性に関しては機能しますが、セグメントの数を正確に制御する必要がある場合には機能しません。 のような小さな入力`[1, 2, 3]`厳密なパーティション数の制約がある場合、貪欲な選択によっては、すでにセグメント数の不一致が発生する可能性があります。 

## アプローチ

 このソリューションは、自然に 2 つの相互作用する問題に分割されます。それは、パーティション全体にわたるグローバル目標の最大化または最小化と、指定されたしきい値の実現可能性の確認です。 

ブルート フォース アプローチでは、考えられるすべての分割を M 個の連続セグメントに試行し、各セグメントのスコアを計算して、グローバル目標を評価します。 これは正しいですが、パーティションの数が N で指数関数的 (およそ O(2^N) 個の分割点) であり、各評価のコストが少なくとも O(N) であるため、すぐには実行不可能です。 動的計画法に制限しても O(N^2) 以上の結果になり、大きな制約には遅すぎます。 

重要な構造的観察は、どちらの最適化方向もしきい値 X に関する決定問題に還元できるということです。答えを直接最適化する代わりに、特定のプロパティが成立するように配列を分割できるかどうかを尋ねます。つまり、すべてのセグメント スコアが最大問題については少なくとも X であるか、少なくとも一定数のセグメントのスコアが最小問題について最大 X です。 これにより、問題が X に関する単調述語に変換され、二分探索が可能になります。 

問題が決定問題になると、次の重要なアイデアは、セグメント スコアが拡張に関して単調であるということです。 これにより、実現可能性を維持しながら各セグメントを可能な限り貪欲に拡張し、O(N) で正規のセグメンテーションを生成することができます。 これにより、最大バージョンの線形時間実行可能性チェックが行われます。 

最小バージョンはさらに複雑です。 パーティションを直接チェックする代わりに、間隔の選択という観点から条件を再定式化します。`[i, Ri]`ここで、各間隔は、スコアがしきい値未満に留まる i から始まる最大セグメントを表します。 次に、これらの間隔のサブセットを選択し、必要な数のセグメントを形成するために十分なカバーされていないスペースが残っていることを確認する必要があります。 

これは、間隔にわたる組み合わせの最適化になります。 主な難しさは、カバーされる全長を最小化する T の互いに素な間隔を選択することです。これにより、T の凸構造が得られます。凸構造が確立されたら、ラグランジュ緩和 (エイリアン DP) を適用できます。 これにより、制約付き最小化問題がパラメトリック最短経路問題に変換され、ペナルティ λ によって選択される間隔の数が制御されます。 

最短経路の定式化は、各位置が間隔を開始するか前方にスキップするため、各間隔はその長さと λ に応じたコストに寄与するために生じます。 最適な構造は 1 から N+1 へのパスになります。 

最後に、答えは比率または有理閾値に依存するため、直接浮動二分探索は不安定です。 代わりに、ビット単位の AND/OR 動作から導出されるすべての可能なセグメント スコアを列挙することによって、候補値を離散化します。 各右端点は O(w) 個の状態変化のみを引き起こすため、候補値の総数は O(wN) となり、インデックスに対する二分探索が可能になります。

 ## アルゴリズムのチュートリアル

 両方とも同じデシジョン コアに依存するため、最小/最大の統合フレームワークのワークフローについて説明します。 

### 1. 最適化を意思決定問題に変換する

 候補しきい値 X を固定し、セグメント スコアに必要な制約を満たす有効なパーティションが存在するかどうかを尋ねます。 

これが機能する理由は単調性です。しきい値 X が実行可能であれば、それより小さい (定式化によっては大きい) しきい値も引き続き実行可能です。 このモノトーン構造により二分探索が可能になります。 

### 2. 最大限の有効なセグメントを構築する

 各開始インデックス i について、i から Ri までのセグメント スコアがしきい値条件を満たすように、最も遠いエンドポイント Ri を計算します。 

スライディング ウィンドウを使用して Ri を計算します。これは、セグメントを拡張してもスコアが低下するだけであるため、一度違反が発生すると、それ以上拡張しても再度有効になることはありません。 

### 3. 区間選択として再定式化する

 各 i は区間 [i, Ri] を定義します。 このような間隔を選択することは、しきい値を満たすセグメントにコミットすることに相当します。 

問題は、どれだけの覆われていないスペースが残っているかに関する制約を伴う T 個の互いに素な間隔を選択することになります。 

### 4. 選択した間隔の数に対するコスト関数を定義します

 T 個の独立した間隔を選択する場合、f(T) をカバーされる最小合計長として定義します。 

区間を結合または分割すると限界利得が減少するため、この関数は T に凸です。 交換議論は、T-1 と T+1 の最適解を組み合わせると、f(T) を境界とする T の 2 つの有効な解に再配置できることを示します。 

### 5. ラグランジュ緩和を適用する

 間隔ごとにペナルティ λ を導入することで、制約付きの最適化を制約のない最適化に変換します。 

次に、f(T) - λT を最小化します。これは最短経路で計算できます。 

各位置 i は、コスト 0 の i+1 (スキップ)、またはコスト Ri - i + 1 - λ の Ri+1 (間隔を取る) に遷移します。 

これにより、1 から N+1 への DAG 最短パスが生成されます。 

### 6. λ の二分探索により正しい T を回復する

 λ が増加するにつれて、選択される間隔の数は単調に減少します。 必要な T = M - K + 1 に一致するように λ を二分探索します。 

### 7. 最終的な実現可能条件を抽出する

 最適な合計カバー長 f(T) がわかったら、残っている空き要素の数を計算し、残りのセグメントに分割できるかどうかを確認します。 これは、残りの位置と必要なセグメント数に関する単純な不等式に帰着します。 

### なぜ効果があるのか

正しさは 2 つの不変条件に基づいています。 まず、すべての有効な分割は、実現可能な最大拡張から導出された素の区間の選択に対応するため、[i, Ri] に注意を限定することで解を失うことはありません。 第 2 に、f(T) の凸性により、ラグランジュ緩和が λ の単調制御下で正しい基数を生成することが保証されます。 最短パスの定式化は、線形ペナルティの下で最適な間隔パッキングを正確にエンコードするため、計算された解は制約された最適値と一致します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての要素が独自の有効なセグメントを形成する場合です。 その場合、すべての i に対して Ri = i となり、アルゴリズムはすぐに N 個のセグメントを生成します。 貪欲セグメンテーションではしきい値に違反せずに間隔をマージできないため、実現可能性チェックでは N より小さい M が正しく拒否されます。 

アレイ全体が単一の有効なセグメントを形成する場合、別のエッジ ケースが発生します。 この場合、R1 = N となり、貪欲チェックによりセグメントが 1 つだけ生成されます。 これにより、バイナリ検索では、複数のセグメントが出現するまでしきい値を下げてセグメンテーションを拡張し、正しい収束が保証されます。 

最後の微妙なケースは、複数の間隔構成が同じコストをもたらす場合です。 凸性ベースの緩和により、T-1 と T+1 の間の最適な混合をコストを増加させることなく有効な T 構成に再配置できるため、安定性が保証され、ラグランジュ探索のあいまいさが防止されます。
