 ## 問題の理解

 非常に大きな制限 (最大$10^{16}$）。 有効な整数の各ペアは、その gcd に関係する特定の算術条件を満たしている場合、エッジで接続できます。

ステートメント内の主要な変換は、任意のペアの観点から考えるのではなく、意図した構造をすでに示唆しています。$(i, j)$、トリプルに移動します$(g, x, y)$どこ$g$は共有 gcd 係数であり、$x, y$は互いに素のスケーリング係数です。 有効な各トリプルは、間のエッジを定義します。$gx$そして$gy$、両方の値が超えない場合に限ります。$10^{16}$。 

実際のタスクは、この暗黙的なグラフに対する接続クエリに答えることです。 グラフのノード空間は巨大ですが、エッジ生成はまばらであるため、すべての有効なエッジを事前計算し、union-find 構造を使用してクエリに答えることが期待されます。

すべてのペアを列挙しようとすると、微妙な失敗例が発生します。$(i, j)$そしてその場で gcd を計算します。 ノードのサブセットに制限することもできます。$10^7$それでも、ペアごとのチェックが多すぎることになります。 もう 1 つの落とし穴は、共素性条件を忘れていることです。$x$そして$y$これは、同じエッジの表現を過剰にカウントすることを避けるために不可欠です。

 ## アルゴリズムのチュートリアル

 1.パラメータを抽出する$B$入力からその正の約数をすべて列挙します。 各約数は、gcd 係数の候補値を表します。$g$。 このステップは実行可能です。$2 \times 10^8$約数は最大でも約 1000 個です。 
2. 各約数について$g$、値を計算します$K = A + \frac{B}{g}$。 この値は製品を表します$x y$元の方程式を次のように書き換えた後、$g$、$x$、 そして$y$。 
3. すべての因子ペアを列挙する$(x, y)$そのような$x y = K$。 これは、次までを繰り返すことによって行われます。$\sqrt{K}$そして割り算の確認。 有効な各約数$x$対応するを定義します$y = K / x$。 
4. ペアごとに$(x, y)$、どうかを確認してください$\gcd(x, y) = 1$。 この条件により、表現が有効な分解に対応することが保証されます。$(i, j)$gcd で正確に$g$、スケールされた重複表現ではありません。 
5. 有効なペアごとに、候補ノードを構築します。$i = g x$そして$j = g y$。 両方の値が以下の場合にのみエッジを維持します$10^{16}$。 この制約により、コンストラクション スペース内のオーバーフローのような増加が除去されます。 
6. を含むセットをマージして、エッジを Union-find 構造に挿入します。$i$そして$j$。 
7. すべてのエッジが処理された後、2 つのノードが同じ接続コンポーネントに属しているかどうかを確認して、各クエリに答えます。 

これが機能する理由は、gcd 分解の独自性から来ています。 すべてのペア$(i, j)$独特の表現力を持つ$i = gx$、$j = gy$と$\gcd(x, y) = 1$。 この変換により、有効な構造をそれぞれ 1 回ずつ、約数を介して列挙することが保証されます。$B$派生積の因数ペア。 すべての解が有効な gcd を 1 つだけ誘導するため、有効なエッジが失われることはありません$g$、共主性フィルタリングにより冗長な因数分解が除去されるため、無効なエッジは生成されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

class DSU:
    def __init__(self):
        self.parent = {}
        self.size = {}

    def find(self, x):
        if x not in self.parent:
            self.parent[x] = x
            self.size[x] = 1
            return x
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def divisors(n):
    res = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            res.append(i)
            if i * i != n:
                res.append(n // i)
        i += 1
    return res

def solve():
    A, B = map(int, input().split())
    q = int(input())

    dsu = DSU()

    divs = divisors(B)

    for g in divs:
        K = A + B // g
        i = 1
        while i * i <= K:
            if K % i == 0:
                x = i
                y = K // i
                import math
                if math.gcd(x, y) == 1:
                    u = g * x
                    v = g * y
                    if u <= 10**16 and v <= 10**16:
                        dsu.union(u, v)
                if x != y:
                    x, y = y, x
                    if math.gcd(x, y) == 1:
                        u = g * x
                        v = g * y
                        if u <= 10**16 and v <= 10**16:
                            dsu.union(u, v)
            i += 1

    out = []
    for _ in range(q):
        u, v = map(int, input().split())
        if dsu.find(u) == dsu.find(v):
            out.append("YES")
        else:
            out.append("NO")

    print("\n".join(out))
```ノード ラベルは次のような大きさになるため、DSU は固定配列ではなく辞書を使用して実装されます。$10^{16}$。 各ノードは、エッジまたはクエリで最初に検出されたときに遅延初期化されます。 

の除数の列挙$B$は単純で、外側のループの境界になります。 内部で計算します$K = A + B/g$、次に、次のすべての因子ペアを列挙します。$K$。 gcd チェックは、表現が次の観点から既約であることを確認するために必要です。$x$そして$y$。 

実装の微妙な詳細は、因子ペアでの対称性の処理です。 両方$(x, y)$そして$(y, x)$別個の有向表現ですが、同じ無向エッジに対応するため、両方が考慮され、重複を避けるためのガードが付いています。$x = y$。 

## 実用的な例

 小さな実例を考えてみましょう。$A = 2$、$B = 6$そして、生成されたいくつかのノード間の接続をクエリします。

 ## 特殊なケース

 エッジケースの 1 つが発生するのは、$x = y$。 この場合、そのペアは自己ループ候補に相当します。 アルゴリズムはこれを自然に処理します。$\gcd(x, x) = x$したがって、次の場合を除き、共原理性チェックは失敗します。$x = 1$。 これにより、次のような有効な縮退エッジのみを受け入れることが保証されます。$g \cdot 1$。 

もう 1 つのエッジケースは次のような場合です$B = 1$。 それからのみ$g = 1$が存在し、構造全体は次の因子ペアに還元されます。$A + 1$。 このアルゴリズムは、特別なケースを使用せずに、標準の約数列挙問題にきれいに縮退します。 

3 番目のケースは次の場合に発生します。$A + B/g$は完全な正方形です。 それから$x = y$、そして再び、平方根がそうでない限り、gcd 条件はそれを拒否します。$1$、ノードの誤った重複を防ぎます。
