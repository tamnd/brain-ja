 ## 解決策
 ## 問題の理解

 私たちは、実効抵抗が与えられた実際の値に近似する電気ネットワークを構築するように求められます。$D$、非常に高い精度で。 構築は任意ではありません。ネットワークは、有理数の連分数表現に対応する特定の構造化ガジェットを使用して構築する必要があります。 

連分数$[a_0; a_1, a_2, \dots, a_k]$実数の有理近似をエンコードします。 ここで使用される重要な事実は、このような連分数は、特に線形数のエッジを使用して抵抗ネットワークに変換できるということです。$a_0 + a_1 + \dots + a_k$エッジ。 各係数は、直列および並列の抵抗器構造の繰り返し構成に対応し、連分数の値に等しい最終的な等価抵抗を生成します。 

したがって、タスクは物理学を直接シミュレートすることではなく、次の合理的な近似を選択することです。$D$連分数展開では最大 300 個のエッジが使用されますが、結果の値は絶対誤差以内に保たれます。$10^{-6}$。 

入力形式はステートメントの抜粋には明示的に示されていませんが、意図された構造は概念的には単純です。ターゲットの実数が与えられています。$D$そして、それを近似する抵抗ネットワークを定義する構造を (連分数係数または同等のエンコーディングを介して) 出力する必要があります。 

最大 300 エッジという制約が重要な制限要因です。 無制限の連分数を使用した素朴な高精度の有理近似アプローチは、非常に正確な値を生成できますが、合計が 300 を超える係数が生成され、構築が無効になる可能性があります。 課題は、近似の品質と係数の増加のバランスをとることです。 

唯一の微妙な数値的失敗のケースは、過度の切り捨てまたは適切に選択されていない有理近似に起因します。 係数の合計を監視せずに継続分数を貪欲に拡張すると、簡単にエッジ バジェットを超えたり、精度を意味的に改善しない不必要な深さが蓄積したりする可能性があります。 

2 番目の故障モードは、浮動小数点の不安定性です。 注意深い終了条件を持たずに単純な浮動演算を使用して連分数を再構築しようとすると、丸め誤差によって不正確な係数が生成され、別の有理ネットワークが生成され、潜在的に誤差しきい値を超える可能性があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。非常に正確な近似値を計算します。$D$長期連分数展開を使用した有理数として。 各ステップで、整数部分を計算し、それを減算し、余りを反転して続行します。 これにより、急速に近似する収束が生成されます。$D$。 十分に長く続けると、近似誤差は非常に小さくなります。 

これが機能するのは、各切り捨てが分母のサイズに対して可能な限り最良の合理的な近似を与えるという意味で、連分数が最適であるためです。 したがって、制約を無視する場合は、誤差が以下になるまで十分な項を取るだけで済みます。$10^{-6}$。 

この直接的なアプローチの問題は、係数の合計が$a_0 + a_1 + \dots + a_k$は制限されていません。 数値によっては、大きな係数を持つ連分数が生成され、中程度の深さでもすでに 300 エッジの制限を超える可能性があります。 特に次のような病的なケースは、$D = \sqrt{3720}$依然として正確であるが、大きな部分商のエッジを無駄にする展開を生成します。 

重要な点は、完全な精度は必要ないということです。 以下のエラーのみが必要です$10^{-6}$また、表現の総コストを明示的に制御する必要もあります。 これは、制約付きの切り捨て戦略につながります。つまり、連続分数を段階的に生成しますが、エッジ バジェットに達したとき、または目標精度にさらなる調整が必要ないときに停止します。 収束は分母のサイズが指数関数的に速く改善するため、慎重に選択された少数の項で十分です。 

これにより、問題は、線形予算制約の下で最良の合理的近似を貪欲に構築するという問題に変換されます。

 ## アルゴリズムのチュートリアル

 の連分数を構築します$D$残りのエッジ バジェットを追跡しながら。 

1. 実際の値から始める$x = D$、および係数の空のリスト。 これは、段階的に構築している継続部分を表します。 
2. 残りの予算はプラスであり、近似誤差は依然として$10^{-6}$、整数部分を抽出します$a_i = \lfloor x \rfloor$。 これは次の連分数係数であり、抵抗器構造における繰り返しの直列加算に対応します。 
3. 整数部分を減算して小数点以下の剰余を取得します。$r = x - a_i$。 もし$r$が非常に小さい場合、数値は機械精度で事実上有理数であるため、連分数は自然に終了します。 
4. 予算がまだ残っている場合は、残りを反転します。$x = 1 / r$。 このステップは、電気的解釈における直列構成と並列構成の切り替えに相当します。 この反転により、次の近似スケールが生成されます。 
5.追加$a_i$係数リストに追加し、残りの予算を次のように削減します。$a_i$なぜなら、この係数は最終的な構築における多くのエッジに直接変換されるからです。 
6. 次の係数の追加が 300 エッジを超える場合は、早めに停止します。 その場合、最後のステップを切り捨て、すでに構築された収束に依存します。 
7. 問題ステートメントの要求に応じて、最終的な係数リストを抵抗ネットワーク表現に変換します。これは暗黙的に連分数展開に対応する一連の直列および並列演算になります。 

### なぜ効果があるのか

 連分数の切り捨てごとに、特定の分母サイズに対して可能な限り最良の有理近似である収束が生成されます。 収束のシーケンスは、近似誤差の点で厳密に改善されています。 各ステップは正確に精度を向上させるか、予算の制約により停止するかのいずれかであるため、係数をコミットした後にそれより悪い近似値に移行することはありません。 

重要な不変条件は、すべてのステップで、現在の連分数が次の最良の近似を表すということです。$D$現在またはそれ以下のエッジ バジェットを使用して達成可能です。 これにより、一度停止すると、同じまたはより少ないエッジを使用した代替配置では大幅に優れた精度が得られないことが保証されます。そのような改善は連分数の最適性特性と矛盾するためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_cf(x, limit=300):
    coeffs = []
    used = 0

    while used < limit:
        a = int(x)
        if used + a > limit:
            a = limit - used

        coeffs.append(a)
        used += a

        r = x - int(x)
        if r < 1e-15:
            break

        x = 1.0 / r

    return coeffs

def main():
    D = float(input().strip())
    coeffs = build_cf(D)

    # Output format is not explicitly specified in excerpt,
    # so we assume standard continued fraction output.
    print(len(coeffs))
    print(*coeffs)

if __name__ == "__main__":
    main()
```このソリューションは、制御された連続分数展開を中心にしています。 機能`build_cf`エッジ制限を適用しながら係数を 1 つずつ構築します。 変数`used`現在の表現が消費するエッジの数を追跡します。 各係数はこのコストに直接寄与するため、追加後すぐに予算を削減します。 

減算ステップでは次を使用します。`int(x)`浮動不一致を避けるために一貫して。 終了条件は`r < 1e-15`は、浮動小数点誤差を増幅させる非常に小さな値による除算を防ぐ数値的保護手段です。 

出力は連分数エンコードの標準形式を想定しており、係数の数に続いて係数自体を出力します。 

## 実用的な例

 しましょう$D = 3.25$。 

連分数の構築を追跡します。 

| ステップ | × | あ_い | 剰余 r | 中古 | 係数 |

 反転後に剰余がゼロになるため、アルゴリズムは停止します。 結果の値は正確に$3 + \frac{1}{4} = 3.25$、単純で合理的な場合に構築が正確であることを確認します。 

### 例 2

 しましょう$D = \sqrt{2} \approx 1.4142135$。 

| ステップ | × | あ_い | 剰余 r | 中古 | 係数 |

 展開は安定して繰り返しパターンになります。 項の数が少ない場合でも、近似は次のようになります。$\sqrt{2}$、急速な収束を示しています。 

トレースは、係数の合計が予算内に収まるようにゆっくりと増加する一方で、各反転ステップが近似のスケールをどのように調整するかを示しています。

 ## 特殊なケース

 次のような整数入力の場合$D = 5$、アルゴリズムはすぐに抽出します$a_0 = 5$、余りはゼロになります。 連続部分は 1 ステップで終了し、単純な単一ノード構造が生成されます。 

次のような非常に小さな入力の場合$D = 0.5$、整数部分はゼロなので、最初の係数は次のようになります。$0$。 反転ステップにより生成されるのは、$2$、展開はすぐに安定します。 これは、連分数表現ではゼロ値の先行係数が有効であり、必要であることを示しています。 

次のような整数に近い浮動小数点値の場合$D = 3.0000001$、最初のステップの後の残りは非常にわずかです。 不安定な反転が発生する前に終了条件がトリガされ、浮動小数点増幅による係数の爆発が防止されます。
