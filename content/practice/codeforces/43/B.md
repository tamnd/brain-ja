 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられます。 最初の文字列は新聞の見出しで、2 番目の文字列は Vasya がそこから作成したい匿名の手紙です。 

見出しのスペース以外の文字はすべて、最大 1 回使用できます。 スペースは特別であり、何も消費しません。 手紙のテキストにスペースが含まれている場合、Vasya は見出しに実際のスペース文字を必要とせずに、文字間にギャップを残すだけで済みます。 

タスクは、ターゲット テキスト内のすべての必要な文字が十分な頻度で見出しによって提供できるかどうかを判断することです。 大文字と小文字は別の文字として扱われるため、`'A'`そして`'a'`交換可能ではありません。 

文字列は短く、最大でも 200 文字です。 200 文字を超える 2 次スキャンでは約 40,000 回の演算しか実行されないため、非効率なソリューションでも問題なく制限内に収まります。 これは、問題は高度な最適化に関するものではなく、文字数の正確な処理に関するものであることを意味します。 

難しいのは、スペースを完全に無視する必要があることです。 不用意に実装すると、スペースが通常の文字としてカウントされ、有効な回答が誤って拒否される可能性があります。 

次の入力を考えてみましょう。```
abc
a c
```正しい答えは次のとおりです。```
YES
```見出しにはスペースは含まれませんが、スペースを切り取る必要がないため、文字をそのまま使用できます。 

大文字と小文字の区別もバグのよくある原因です。```
Abc
abc
```正しい答えは次のとおりです。```
NO
```見出しに大文字が含まれている`A`、ただし、文字には小文字が必要です`a`。 

もう 1 つの微妙なケースは、見出しに文字が存在するものの、十分な回数が存在しない場合に発生します。```
hello
helloo
```正しい答えは次のとおりです。```
NO
```各文字が少なくとも 1 回出現するかどうかだけをチェックするソリューションは、ターゲットには 2 つ必要であるため、ここでは失敗します。`'o'`文字。 

## アプローチ

 最も直接的な総当たり手法は、ターゲット文字列を 1 文字ずつ処理することです。 レター内のスペース以外の文字ごとに、一致する未使用の文字が見つかるまで見出しに目を通します。 使用したら、その文字にマークを付けて、後で再利用できないようにします。 

これが機能するのは、ターゲット内の各文字がソースから一致する 1 つの文字を明示的に消費するためです。 問題は、検索のたびに見出しのほぼ全体がスキャンされる可能性があることです。 両方の文字列に長さがある場合`n`、これは次のことにつながります`O(n^2)`時間の複雑さ。 

と`n ≤ 200`、このアプローチでも簡単に合格します。 最悪の場合、私たちは約`200 × 200 = 40,000`比較。 それでも、一度数えられる文字を繰り返し検索するのに時間がかかるため、この方法は不器用です。 

もっと良い観察は、重要なのは周波数だけだということです。 見出しの文字の順序は関係ありません。 手紙に 3 通必要な場合`'a'`見出しには少なくとも 3 文字を含める必要があります`'a'`どこかのキャラクター。 

これにより、問題は数を数えるタスクに変わります。 スペース以外の各文字が見出しに出現する回数を数え、ターゲット テキストを調べて、必要な文字ごとに 1 つの出現を消費します。 どこかの時点でキャラクターが利用できない場合でも、すぐに答えが得られます。`"NO"`。 

これにより、すべての文字が 1 回処理されるため、ロジックが線形時間に短縮されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 承認済み |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 見出し文字列と対象文字列を読み取ります。 
2. 見出しの文字の頻度マップを作成します。 

スペースは無料であり、新聞から切り取る必要がないため、スペース以外の文字のみをカウントします。 
3. ターゲット文字を一度に 1 文字ずつたどります。 
4. 現在の文字がスペースの場合、それをスキップします。 

スペースは見出しから何も消費しません。 
5. すべての非スペース文字について、マップ内のその頻度が正であるかどうかを確認します。 

カウントが 0 の場合、見出しにはその文字のコピーが十分に含まれていないため、次のように出力します。`"NO"`そしてすぐにやめてください。 
6. それ以外の場合は、その文字の頻度を 1 つ減らします。 

これは、見出しから 1 つの切り抜き文字を使用してモデル化します。 
7. ターゲット文字列全体が正常に処理された場合は、次のように出力します。`"YES"`。 

### なぜ効果があるのか

 このアルゴリズムは、頻度マップが見出しから利用可能な残りの未使用の文字を常に表すという不変条件を維持します。 

ターゲットが文字を必要とするときは常に、一致するオカレンスを 1 つ消費します。 必要な文字が使用できない場合、使用可能なすべての文字がすでに 1 回だけ考慮されているため、どの配置でもターゲットを構築できません。 

スペースは無視され、他のすべての文字が利用可能な文字と照合されるため、アルゴリズムは構成可能な文字を正確に受け入れ、不可能な文字をすべて拒否します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

headline = input().rstrip('\n')
letter = input().rstrip('\n')

freq = {}

for ch in headline:
    if ch != ' ':
        freq[ch] = freq.get(ch, 0) + 1

for ch in letter:
    if ch == ' ':
        continue

    if freq.get(ch, 0) == 0:
        print("NO")
        break

    freq[ch] -= 1
else:
    print("YES")
```最初の部分では、両方の行が入力されたとおりに正確に読み取られます。 使用する`rstrip('\n')`これは、文字列に属する内部スペースや先頭のスペースではなく、入力によって追加された末尾の改行のみを削除したいため、重要です。 

辞書`freq`見出しに各文字の未使用のコピーが何個残っているかを保存します。 スペースは構造に関係がないため省略されます。 

2 番目のループでは、ターゲット文字を処理します。 スペースが出現すると、アルゴリズムはそれを直ちに無視します。 通常の文字の場合、辞書検索では、未使用のコピーが少なくとも 1 つ存在するかどうかがチェックされます。 

の`for ... else`ここの構造は便利です。 の`else`ブロックはループがヒットせずに終了した場合にのみ実行されます。`break`。 つまり、答えは`"YES"`まさに文字不足が検出されなかったとき。 

微妙な実装の詳細は、`freq.get(ch, 0)`。 デフォルト値を使用しない場合`0`、見出しに出現したことのない文字をクエリすると、エラーが発生します。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    headline = input().rstrip('\n')
    letter = input().rstrip('\n')

    freq = {}

    for ch in headline:
        if ch != ' ':
            freq[ch] = freq.get(ch, 0) + 1

    for ch in letter:
        if ch == ' ':
            continue

        if freq.get(ch, 0) == 0:
            print("NO")
            return

        freq[ch] -= 1

    print("YES")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run(
    "Instead of dogging Your footsteps it disappears but you dont notice anything\n"
    "where is your dog\n"
) == "NO\n", "sample 1"

# minimum-size input
assert run(
    "a\n"
    "a\n"
) == "YES\n", "single character"

# spaces should not matter
assert run(
    "abc\n"
    "a c\n"
) == "YES\n", "spaces ignored"

# case sensitivity
assert run(
    "Abc\n"
    "abc\n"
) == "NO\n", "uppercase and lowercase differ"

# insufficient frequency
assert run(
    "hello\n"
    "helloo\n"
) == "NO\n", "repeated character shortage"

# large repeated input
assert run(
    "a" * 200 + "\n" +
    "a" * 200 + "\n"
) == "YES\n", "maximum equal strings"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`a / a`| はい | 最小の有効なケース |
 |`abc / a c`| はい | スペースは文字を消費しません。 
|`Abc / abc`| いいえ | 大文字と小文字の区別 |
 |`hello / helloo`| いいえ | 周波数カウント |

 ## 特殊なケース

 ターゲットにはスペースが含まれているが、見出しにはスペースが含まれていない場合を考えてみましょう。 

入力：```
abc
a b c
```アルゴリズムは次の周波数マップを構築します。```
a:1, b:1, c:1
```ターゲットのスキャン中、スペースは完全にスキップされます。 のみ`'a'`、`'b'`、 そして`'c'`カウントを消費します。 すべてのカウントは有効なままであるため、出力は次のようになります。```
YES
```これにより、スペースが正しく無視されることが確認されます。 

ここで、大文字と小文字の区別を考慮してください。 

入力：```
A
a
```周波数マップには大文字のみが含まれています`'A'`。 

アルゴリズムが小文字をチェックする場合`'a'`、`freq.get('a', 0)`返品`0`。 アルゴリズムは即座に以下を出力します。```
NO
```これは、大文字と小文字が別の記号として扱われることを示しています。 

最後に、繰り返しの文字不足について考えてみましょう。 

入力：```
banana
bananaa
```初期周波数:

 | キャラクター | カウント |
 | --- | --- |
 | b | 1 |
 | | 3 |
 | n | 2 |

 ターゲットには 4 つ必要です`'a'`文字。 最初の 3 つを消費すると、残りのカウントはゼロになります。 アルゴリズムが 4 番目に到達したとき`'a'`、不足を検出し、次のように出力します。```

```これにより、アルゴリズムが単純な存在ではなく正確な周波数を追跡していることが検証されます。
