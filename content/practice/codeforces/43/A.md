 ## 解決策
 ## 問題の理解

 サッカーの試合中に得点された一連のゴールが与えられています。 最初の行以降の各行には、1 ゴールを決めたチームの名前が含まれます。 課題は、どちらのチームが全体的により多くのゴ​​ールを獲得したかを判断することです。 

入力により、最大 2 つの異なるチーム名が表示され、試合が引き分けで終わることがないことが保証されます。 これは、一方のチームが常に他方のチームよりも厳密に多くのゴール数を持っていることを意味します。 

制約は非常に小さいです。 ゴールの数は最大 100 で、各チーム名の長さは最大 10 です。すべてのゴールを他のすべてのゴールと比較する非効率的なソリューションであっても、制限時間内に問題なく収まります。 これにより、積極的な最適化ではなく、明確さを重視する自由が得られます。 

主な課題はパフォーマンスではなく、各チームのゴールを正しくカウントすることです。 

簡単な間違いの 1 つは、常に 2 つのチームが存在すると仮定することです。 考慮する：```
1
ABC
```正しい答えは次のとおりです。```
ABC
```2 つの異なる名前をすぐに読み取る不用意な実装は、1 つのチームしか表示されないため失敗します。 

もう 1 つの微妙な問題は、同じチームが複数回登場した場合にカウントが正しく更新されないことです。 例えば：```
5
A
B
A
A
B
```正しい出力は次のとおりです。```
A
```カウントをインクリメントせずに上書きすると、最終結果は間違ったものになります。 

隣接するゴールのみを比較すると、別の落とし穴が発生します。 考慮する：```
4
A
B
B
A
```ここでは最終スコアは同点であり、問​​題では決して起こらないとされていますが、この例は、隣接関係から勝者について何も分からない理由を示しています。 すべての発生をグローバルにカウントする必要があります。 

## アプローチ

 最も直接的な強引なアイデアは、各チーム名を調べて、それが完全なリストに何回出現するかを数えるというものです。 目標エントリごとに、配列全体を再度スキャンし、その頻度を計算します。 

あれば`n`目標、これは実行されます`n * n`最悪の場合の比較。 と`n = 100`、これはわずか 10,000 回の操作であり、ここでは完全に許容されます。 勝者はまさに最も頻度の高いチームであるため、総当り的なアプローチは正しいです。 

非効率性は、同じカウントを繰り返し再計算することから発生します。 もし`"A"`が 50 回出現しても、遭遇するたびに 100 エントリすべてを数え直します。`"A"`。 

重要な観察は、この問題は基本的に頻度カウントの問題であるということです。 リストを繰り返しスキャンする代わりに、入力を読み取りながら各チームの実行数を維持できます。 

ここでは、Python 辞書として実装されたハッシュ マップが最適です。 チーム名を読み取るたびに、保存されている数が 1 ずつ増えます。 すべてのゴールを処理した後、辞書には各チームが得点した正確なゴール数が含まれます。 

チームは最大でも 2 つなので、後で勝者を見つけるのは簡単です。 単純にカウントが大きいチームを選択します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 承認済み |
 | 最適 | O(n) | O(k) | 承認済み |

 ここ、`k`は個別のチームの数で、最大 2 です。 

## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、試合中に得点されたゴール数。 
2. という名前の空の辞書を作成します。`count`。 

辞書は、チーム名をそのチームが得点したゴール数にマッピングします。 
3. 繰り返します`n`回:

 1. チーム名を読み上げます。 
2. 辞書内の頻度を増やします。 

チームがこれまでに登場したことがない場合は、最初にそのカウントをゼロに初期化します。 
4. すべての目標を処理した後、辞書エントリを繰り返し処理し、最大数でチームを追跡します。 
5. 最も高い頻度でチームを印刷します。 

### なぜ効果があるのか

 アルゴリズムは、最初の処理後の不変条件を維持します。`i`ゴール数に応じて、辞書にはその内のすべてのチームが獲得した正確なゴール数が保存されます。`i`エントリ。 

新しい目標ごとに 1 つのチームのカウントが 1 ずつ更新されるため、不変条件はプロセス全体を通じて true のままです。 

最後に、すべてのゴールが処理されます。つまり、辞書には各チームの最終スコアが含まれています。 この問題では同点がないことが保証されているため、カウントが最大のチームが一意に勝者となります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    
    count = {}
    
    for _ in range(n):
        team = input().strip()
        count[team] = count.get(team, 0) + 1
    
    winner = ""
    best = 0
    
    for team, goals in count.items():
        if goals > best:
            best = goals
            winner = team
    
    print(winner)

solve()
```解決策は、ゴール数を読み取ることから始まります。 という名前の辞書`count`各チームの出現回数を保存します。 

式:```
count.get(team, 0) + 1
```両方のケースを適切に処理するため、これは重要です。 チームがディクショナリにすでに存在する場合は、その現在の値を増分します。 さもないと、`get`返品`0`、チームは1つの目標から始まります。 

すべての目標を数えた後、もう一度辞書をスキャンして最大頻度を見つけます。 この問題では唯一の勝者が保証されているため、同点処理ロジックは必要ありません。 

使用する`strip()`チーム名を読むときに、誤って改行文字が文字列の一部になることを避けます。 これを忘れることは、文字列の問題でよくあるバグです。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())

    count = {}

    for _ in range(n):
        team = input().strip()
        count[team] = count.get(team, 0) + 1

    winner = ""
    best = 0

    for team, goals in count.items():
        if goals > best:
            best = goals
            winner = team

    print(winner)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run("1\nABC\n") == "ABC\n", "sample 1"

# minimum size input
assert run("1\nTEAM\n") == "TEAM\n", "single team"

# alternating goals
assert run("5\nA\nB\nA\nB\nA\n") == "A\n", "alternating sequence"

# all goals by same team
assert run("4\nX\nX\nX\nX\n") == "X\n", "all equal"

# long names
assert run("3\nBARCELONA\nREALMADRID\nBARCELONA\n") == "BARCELONA\n", "string handling"

# winner decided late
assert run("7\nA\nB\nB\nA\nA\nB\nA\n") == "A\n", "late lead"
