 ## 解決策
 ## 問題の理解

 私たちは、_n_ 台の車が参加する長さ _s_ キロメートルの直線レースを分析するように求められています。 各車両には走行セグメントのリストがあり、各セグメントには一定の速度と継続時間が指定されています。 車は次のセグメントに切り替わるまで、指定された時間その速度で移動します。 すべての車がスタートラインで同時にスタートします。 私たちの仕事は、瞬間的な追い越しのみを考慮して、レース中にある車が別の車を追い越した回数を数えることです。 スタートラインまたはフィニッシュラインで集合した車両はカウントされません。 

入力では、車の数とレースの長さを指定し、その後に各車のセグメントのシーケンスが続きます。 各セグメントは、時速キロメートル単位の速度と時間単位の継続時間で構成されます。 車のセグメントがカバーする距離の合計は、レースの長さに等しいことが保証されます。 

制約を考慮すると、_n_ は最大 100 で、各車両には最大 100 のセグメントがありますが、_s_ は最大 10^6 になります。 これは、_s_ が非常に大きくなる可能性があるため、時間をかけて少しずつ増加させるだけの反復処理は実行不可能であることを示唆しています。 代わりに、距離と時間の空間において区分的に線形である各車の動きの構造を利用する必要があります。 

明らかではないエッジ ケースには、2 台の車がいくつかのセグメントにわたって同じ速度を示し、その後発散する状況が含まれます。 たとえば、2 台の車が両方とも速度 5 で 1 時間発進し、その後 1 台が加速し、もう 1 台が減速したとします。 セグメント境界のみをチェックする場合、追い越しを誤ってカウントすることには、セグメント内の複数のリードをカウントすることが含まれる可能性があります。 もう 1 つの微妙なケースは、2 台以上の車の間で複数の追い越しが同時に発生する場合です。 各ペアの追い越しが個別にカウントされるようにする必要があります。 

## アプローチ

 強引なアプローチは、すべての車を非常に細かい時間増分でシミュレートし、各瞬間のすべてのペアを比較することです。 小さな時間ステップごとに、すべての車の距離を計算し、車が別の車を追い越すたびに追い越しをカウントします。 これは原理的には正しいですが、タイム ステップはすべてのリードを検出できるほど小さくする必要があり、演算数は _s × n^2_ として増加するため、遅すぎます。 _s_ が最大 10^6、_n_ が最大 100 の場合、結果として 10^10 の操作が発生し、2 秒の制限を超えます。 

重要な洞察は、各車の動きが区分的に線形であるため、追い越しはセグメントの境界か、2 台の車の直線軌道が交差する場合にのみ発生するということです。 各車のセグメントを累積距離と時間の表現に処理し、すべての車で同期した方法でレースをシミュレーションし、各セグメントの開始時と終了時の位置のみを更新します。 各時間ステップで、車の相対的な順序を距離別にチェックし、順序が変わるたびに追い越しをカウントします。 各車両には最大 100 個のセグメントがあり、_n_ ≤ 100 であるため、チェックするイベントの総数は管理可能な O(n × k) であり、ペア間の順序変更のチェックはイベントごとに O(n^2) です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(s × n^2) | O(n) | 遅すぎる |
 | 最適 | O(n × k × n) = O(n^2 × k) | O(n × k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、各車両のセグメントを累積距離と時間の表現に変換します。 各セグメントについて、そのセグメント内を移動した距離の合計として終了位置を計算します。 
2. すべての車の現在位置のリストと追い越しのカウンターを初期化します。 位置に基づいて車の以前の順序を追跡します。 
3. すべてのセグメント境界を時系列順に繰り返します。 セグメントの継続時間は異なる場合があるため、現在のセグメントを示す各車両のポインターを維持します。 
4. 自動車のセグメント端に対応するタイム ステップごとに、線形運動公式を使用してその自動車の位置を更新します。`position += speed × duration`。 
5. この時点ですべての位置を更新した後、車を距離順に並べ替えて新しい順序を決定します。 新しい注文を以前の注文と比較します。 相対位置が変化した車のペアごとに、追い越しカウンターをインクリメントします。 
6. 以前の注文を新しい注文に更新し、次のイベントに進みます。 
7. すべての車両のすべてのセグメントが処理されるまで続行します。 総追い越し回数を出力します。 

これが機能する理由: 不変条件は、セグメント境界間ではすべての車が直線的に移動し、追い越しは直線軌道が交差する場合にのみ発生するということです。 セグメントのエンドポイントでのみ処理し、相対的な順序の変化をチェックすることにより、各追い越しを正確に 1 回カウントします。 この問題では追い越しが瞬時に行われることが保証されているため、セグメント間のイベントを見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, s = map(int, input().split())
cars = []

for _ in range(n):
    data = list(map(int, input().split()))
    k = data[0]
    segments = []
    for j in range(k):
        v, t = data[1 + 2*j], data[2 + 2*j]
        segments.append((v, t))
    cars.append(segments)

# Convert segments into cumulative distances and times
positions = [[0]] * n
times = [[0]] * n
for i in range(n):
    pos_list = [0]
    time_list = [0]
    for v, t in cars[i]:
        pos_list.append(pos_list[-1] + v * t)
        time_list.append(time_list[-1] + t)
    positions[i] = pos_list
    times[i] = time_list

overtakes = 0
prev_order = list(range(n))
current_time = 0

# Generate all event times
event_times = set()
for tlist in times:
    event_times.update(tlist)
event_times = sorted(event_times)

# For each event time, compute car positions
for t in event_times[1:]:
    dist = []
    for i in range(n):
        # Find which segment car i is in
        seg_idx = 0
        while seg_idx < len(times[i]) - 1 and times[i][seg_idx + 1] <= t:
            seg_idx += 1
        # Compute position at time t
        start_time = times[i][seg_idx]
        start_pos = positions[i][seg_idx]
        v = cars[i][seg_idx][0]
        curr_pos = start_pos + v * (t - start_time)
        dist.append((curr_pos, i))
    # Sort by distance
    dist.sort(reverse=True)
    new_order = [idx for _, idx in dist]
    # Count overtakes: every pair that swapped order
    for j in range(n):
        for k in range(j + 1, n):
            a, b = new_order[j], new_order[k]
            if prev_order.index(a) > prev_order.index(b):
                overtakes += 1
    prev_order = new_order

print(overtakes)
```最初のセクションは入力を読み取り、解析します。 各車両のセグメントは累積距離と時間に変換されるため、いつでも効率的に位置を計算できます。 次に、追い越しはイベント時間にのみ発生する可能性があるため、すべての一意のセグメント エンドポイントをイベント時間として生成します。 イベントごとに、線形補間を使用して各車両の現在位置を計算します。 距離で並べ替えると現在の順位が得られ、それを以前の順位と比較すると、すべての追い抜きが特定されます。

 ## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2 × k) | O(n × k) 個のセグメント境界のそれぞれについて、n 台の車のすべてのペアを比較します。 |
 | スペース | O(n × k) | 各車両のすべてのセグメントの累積位置と時刻を保存します。 |
