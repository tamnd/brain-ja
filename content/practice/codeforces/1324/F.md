 ## 解決策

 ## 問題の理解

 すべての頂点が白または黒のいずれかに着色されたツリーが与えられます。 頂点ごとに$v$、以下を含むツリーのすべての接続されたサブグラフを調べたいとします。$v$、その中から、白い頂点の数から黒い頂点の数を引いたものとして定義されるスコアを最大にするものを選択します。 

別の考え方としては、各ノードが貢献しているということです。$+1$それが白であれば、$-1$黒なら。 頂点ごとに$v$を含める必要がある、接続されたノードのセット全体のノード値の最大合計が必要です。$v$。 

制約$n \le 2 \cdot 10^5$ノードごとにグローバル検索を再計算するアプローチは直ちに除外されます。 各頂点から BFS または DP を実行しようとする単純なソリューションではコストがかかります$O(n^2)$最悪の場合、制限時間を大幅に超えてしまいます。 平$O(n \log n)$ノードごとに実行することは不可能です。 線形または線形に近い解決策が必要です。 

微妙な問題は、ノードにとって最適なサブツリーが、ルートのある意味での独自のサブツリーであるとは限らないことです。 すべての方向に拡張でき、さまざまな頂点に最適な構造が重なり合います。 もう 1 つの潜在的な落とし穴は、ツリー全体または固定ルートのサブツリーを取得することで答えが得られると仮定することですが、大きな負の領域が含まれるとスコアが低下する可能性があるため、これは誤りです。 

たとえば、チェーンについて考えてみましょう。```
1 - 2 - 3 - 4
colors: 1 0 0 1
```頂点 2 の場合、ツリー全体を取得すると合計が得られます。$0$ですが、2 を含む最適な接続されたサブツリーは次のようになります。$\{2\}$与える$-1$、したがって、局所的な剪定さえも重要です。 頂点 3 の場合、最適なのは$\{3,4\}$合計付き$0$木全体ではありません。 これは、貢献がどのように伝播するかを慎重に制御する必要があることを示しています。 

## アプローチ

 まず総当たり戦略を考えます。 頂点ごとに$v$、それをルートとして扱い、それを含むすべての接続されたサブツリーを探索できます。 これは、以下を含むすべての接続された誘導サブグラフを列挙することと同等です。$v$これは一般的なツリーでは指数関数的です。 近隣諸国のサブセットに対する DP に限定したとしても、州の数は依然として指数関数的に増加します。 もう 1 つのより構造化されたブルート フォースは、ツリーを次の場所にルート化することです。$v$そして、子サブツリーを選択できる DP を実行しますが、これは下向きのサブツリーのみをキャプチャし、異なるルートを介した上向きの展開を見逃します。 これをノードごとに繰り返すと、$O(n^2)$全体的にトランジションが遅すぎるため、$2 \cdot 10^5$。 

重要な観察は、問題がツリー上の最大部分配列合計の変形であるが、選択された部分グラフにはルート頂点が含まれなければならないという追加の制約があるということです。 これは、双方向の動的プログラミングのアイデアを示唆しています。まず、すべてのノードについて、その下向きのサブツリーからの最良の寄与を計算し、次に親側から情報を伝播することで、各ノードも上向きに拡張することで何が得られるかを知ることができます。 

最初の DP パスはクラシック ツリー DP です。$down[v]$で始まる接続されたサブツリーの最適な合計として$v$そして下に行くだけです。 これはポストオーダー トラバーサルを使用して計算されます。 

2 番目のパスは再ルートです。 付加価値を伝播します$up[v]$、サブツリーの外側から得られる最大の貢献を表します。$v$、接続されたままで親方向を通過するパスに制限されます。 組み合わせる$down[v]$そして$up[v]$これにより、各ノードが構造の中心であるかのように、そのノードに対する最適な答えを計算できます。 

これはまさに、子からの貢献が親ノードを介さない限り独立している種類の構造であり、線形の再ルートが可能です。

 ## アルゴリズムのチュートリアル

 各ノードに値を割り当てます$w[v]$、 どこ$w[v] = 1$白の場合と$w[v] = -1$黒なら。 

### ステップ 1: ツリーを任意にルート化する

 ノード 1 でツリーをルートにします。すべての有効な接続されたサブツリーは任意のルートに対して相対的に記述できるため、これによって答えは変わりません。 

### ステップ 2: 下方寄与を計算する

 私たちは計算します$down[v]$、以下を含む必要がある接続されたサブツリーの最適な合計。$v$そしてその子にのみ拡張されます。 

各ノードについて$v$、から始めます$down[v] = w[v]$。 それから、子供たち一人一人に$u$、その子に拡張することでスコアが向上するかどうかを検討します。 もし$down[u] > 0$に追加します$down[v]$。 それ以外の場合は無視します。 

これが機能するのは、子サブツリーがマイナスまたはゼロのゲインに寄与する場合、それを含めても、次のルートにある接続された構造は改善されないからです。$v$。 

### ステップ 3: 最初の DFS トラバーサル

 私たちは計算します$down[v]$postorder DFS を使用して、子が親よりも前に処理されるようにします。 

### ステップ 4: リルートを使用して答えを計算する

 現在、親から子へ情報が伝播されています。 させて$ans[v]$頂点のベストアンサーになります$v$。 

当初は、$ans[v] = down[v]$ルートが 1 の場合。 

親元から引っ越しする場合$v$子供に$u$、それを考慮する必要があります。$u$サブツリーの外側にあるすべてのものから貢献を得ることができます。 値を渡します$up[u]$からの最高の貢献を表す$v$さん側を除く$u$のサブツリー。 

計算するには$up[u]$、以下を組み合わせます。 

- 親からの寄付$v$、
 - 兄弟からの寄稿$u$、
- そして$w[v]$自体。 

重要な考え方は、各ノードが近隣ノードを独立したブランチと見なし、それらの中で最も優れたプラスの寄与のみを知る必要があるということです。 

### ステップ 5: 結果を結合する

 各ノードについて$v$、最終的な答えは次のとおりです。$$ans[v] = w[v] + \sum \max(0, best\_branch\_contribution)$$ここで、分岐には子と上方向の両方が含まれます。 

### なぜ効果があるのか

 このアルゴリズムは、どのノードについても、それを含む最適な接続されたサブツリーがその近傍を介して独立したブランチに分解できるという不変式に依存しています。 各ブランチは、正のゲインに寄与するか、完全に除外されます。 再ルート DP により、すべてのノードが潜在的な中心として扱われ、すべてのインシデントの方向が正しいコンテキストで 1 回だけ評価されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

n = int(input())
a = list(map(int, input().split()))

g = [[] for _ in range(n)]
for _ in range(n - 1):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

w = [1 if x == 1 else -1 for x in a]

parent = [-1] * n
down = [0] * n

order = []

def dfs(v, p):
    parent[v] = p
    down[v] = w[v]
    for to in g[v]:
        if to == p:
            continue
        dfs(to, v)
        if down[to] > 0:
            down[v] += down[to]

dfs(0, -1)

ans = [0] * n
ans[0] = down[0]

def reroot(v, p):
    ans[v] = down[v]
    for to in g[v]:
        if to == p:
            continue

        # remove contribution of child and recompute "up" effect
        if down[to] > 0:
            down[v] -= down[to]

        if down[v] > 0:
            down[to] += down[v]

        reroot(to, v)

        if down[v] > 0:
            down[to] -= down[v]
        if down[to] > 0:
            down[v] += down[to]

    ans[v] = max(ans[v], w[v])

reroot(0, -1)

print(*ans)
```このコードは 2 パス戦略を実装しています。 最初の DFS は下方寄与を計算し、各ノードは正の子寄与のみを集計します。 リルート関数は、親側から各子に有益な寄与を転送しようと試み、視点のシフトをシミュレートするために値を一時的に変更します。 重要な考え方は、正の寄与だけが伝播する価値があるため、負の分岐は常に除外されるということです。 

微妙な実装上の問題は、次のように変更することです。`down`再ルート中に所定の位置に配置されます。 正確さを維持するには、再帰後に慎重に復元する必要があります。 この構造により、いつでも`down[v]`現在のルート方向の正しい寄与を反映しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべてのノードが黒である場合です。 その場合、すべてのサブツリーの合計は非正となり、各ノードの最適な選択はノード自体であり、ゼロが与えられます。 すべての寄与が負であるため、アルゴリズムがこれを処理します。そのため、DP には子が追加されず、各答えはゼロになります。 

もう 1 つのケースは、1 つの白い中心と多数の黒い葉を持つ星形グラフです。 中心の最適なサブツリーにはそれ自体のみが含まれますが、葉の場合は中心と、おそらく他の正の寄与が存在する場合はそれらも含まれます。 再ルート化により、各リーフはセンターの寄与を上向きのブランチとして認識するようになります。 

最後のケースは、ポジティブがネガティブによって分離されている長いチェーンです。 このアルゴリズムは、負のセグメントが下向き DP で正のゲインに寄与することがないため、正しく切断し、再ルートによって有益なセグメントのみが再結合されるため、有害なノードが強制的に含まれることはありません。
