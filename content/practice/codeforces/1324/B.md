 ## 解決策

 ## 問題の理解

 いくつかの独立した整数配列が与えられ、それぞれについて、左から右、右から左に同じ内容を読み取る、少なくとも 3 の長さのサブシーケンスを抽出できるかどうかを判断する必要があります。 

ここでのサブシーケンスとは、要素を削除することはできるが、残っている要素を並べ替えることはできないことを意味します。 したがって、タスクは連続したセグメントに関するものではなく、元の順序を維持しながらいくつかの要素を選択するものです。 このようなすべての選択肢の中で、長さが 3 以上の回文が少なくとも 1 つ存在するかどうかを知りたいと考えています。 

全体的な意味で制約は小さいです。 各テスト ケースには、すべてのケースで合計最大 5000 個の要素があります。 これはすぐに次のことを示唆しています。$O(n^2)$テスト ケースごとのソリューションは問題ありませんが、すべてのテストにわたって 3 次以上のソリューションを不用意に実装すると危険です。 ただし、本当のブレークスルーは、サブシーケンスを明示的に構築する必要がないことに気づくことからもたらされます。 

素朴な考え方では、少なくとも 3 つの長さの部分列をすべて生成し、回文であるかどうかを確認しようとします。 それは不可能です。$n = 50$、部分列の数は指数関数的です。 もう 1 つの素朴な試みは、すべてのトリプルまたはギャップのあるすべてのトリプルをチェックすることですが、これでは長い回文が見逃されます。 

貪欲な直感を打ち破る微妙なケースもあります。 たとえば、次のような配列では、$[1, 2, 3, 2, 1]$答えは明らかに「はい」ですが、隣接する重複または単純な対称パターンのみに焦点を当てると、一致する要素が分離されているため失敗します。 

重要な隠された構造は、少なくとも 3 の長さの有効な回文部分列には、端を形成する繰り返し値、または重複を含むより単純な条件に還元できるパターンのいずれかが含まれている必要があるということです。 

## アプローチ

 ブルートフォースの観点から始めます。 長さが少なくとも 3 の部分連続回文には、最初と最後の要素が等しく、それ自体が回文である中間部分があります。 直接的なアプローチは、すべてのサブシーケンスを列挙し、それぞれを構築して、それが回文であるかどうかを確認することです。 これは指数関数的です$n$、 だいたい$O(2^n \cdot n)$、これはたとえ$n = 30$。 

建設ではなく構造に焦点を当てることで、問題を大幅に軽減できます。 少なくとも 3 の長さの回文部分列は、2 つのパターンのいずれかに該当する必要があります。 

少なくとも 3 回出現する値があり、それを最初と最後の要素として、また中間の要素として選択して、次のようなサブシーケンスを形成することができます。$[x, x, x]$または、外側のペアが一致し、それらの間に何かが存在する 2 つの異なる値を使用して、より長い対称構造を形成することもできます。 

重要な観察は、値が少なくとも 3 回出現する場合、答えは即座に「はい」であるということです。 そうでない場合、すべての値は最大 2 回出現することになり、構造は十分に制約されるため、最初と最後の出現の間に少なくとも 1 つの要素を含む 2 回出現する値が存在するかどうかを確認するだけで済みます。 これにより、次の形式の回文部分列が得られます。$[x, y, x]$どこ$x$2回登場し、$y$それらの間にあります。 

これにより、問題全体が周波数と位置のチェックに軽減され、サブシーケンスの列挙が回避されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース サブシーケンス |$O(2^n \cdot n)$|$O(n)$| 遅すぎる |
 | 周波数+位置チェック |$O(n)$テストごと |$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. 配列をスキャンし、各値の位置を保存します。 これにより、重複と間隔について推論できるようになります。 
2. 値が少なくとも 3 回出現すると、すぐに「YES」を返します。 これは、最初、2 番目、および 3 番目の出現を選択して長さ 3 の回文部分列を形成できるため機能します。 
3. 値が 3 回出現しない場合、値は 1 回か 2 回しか出現しません。 
4. 正確に 2 回出現するすべての値について、2 つの出現が隣接していないかどうかを確認します。 それらの間に少なくとも 1 つのインデックスがある場合、これら 2 つの等しい要素をサブシーケンスの終端として選択できます。 
5. 次に、間に回文の中央として使用できる要素が存在するかどうかを確認します。 どの要素も中間として機能するため、条件は単に 2 つの要素が少なくとも 1 つのインデックスによって区切られているということだけです。 
6. そのようなペアが存在する場合、「YES」を返します。 
7. どちらの条件も当てはまらない場合は、「NO」を返します。 

重要なステップは、分離された重複が存在すると、中間要素が中心として機能し、長さ 3 の回文部分列が保証されることを認識することです。 

### なぜ効果があるのか

 少なくとも 3 の長さの回文部分列は、最初と最後の要素が等しくなければなりません。 したがって、エンドポイントとして機能できる繰り返し値を常に探しています。 値が 3 回以上出現する場合、有効な回文を簡単に構築できます。 正確に 2 回出現する場合、それらの 2 つの出現によって、その値の唯一の可能なエンドポイントが定義されます。 順序を維持しながらその間の任意の要素を選択できるため、有効な中間要素が自動的に存在します。 この構造上の制限により、考えられるすべての構造が網羅されるため、周波数とギャップをチェックすることで答えが完全に特徴づけられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = {}
        for i, x in enumerate(a):
            pos.setdefault(x, []).append(i)

        ok = False

        for x, idxs in pos.items():
            if len(idxs) >= 3:
                ok = True
                break

        if ok:
            print("YES")
            continue

        for x, idxs in pos.items():
            if len(idxs) == 2:
                i, j = idxs
                if j - i > 1:
                    ok = True
                    break

        print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```コードは最初に各値の位置を収集して、繰り返しパターンを推論できるようにします。 最初のループは、同じ値が 3 回出現するという単純なケースを検出します。 2 番目のループは、ちょうど 2 つのオカレンスが存在する場合を処理し、それらが隣接していないことを確認します。 条件`j - i > 1`それらの間に少なくとも 1 つの要素が存在することを保証し、長さ 3 の回文部分列を形成できます。 

## 実用的な例

 ### 例 1

 入力:```
5
3
1 2 1
```出現を追跡します。1 は [0, 2] の位置に出現し、2 は [1] に出現します。 値が 3 回表示されません。 値 1 が 2 回出現し、位置 0 と 2 の間のギャップは空ではないため、サブシーケンス [1, 2, 1] を選択できます。 これにより、回文が有効であることが確認されます。 

| 値 | ポジション | トリプルカウント | ギャップチェック | 決定 |
 | --- | --- | --- | --- | --- |
 | 1 | [0, 2] | 2 | ギャップが存在します | はい |

 これは、単一の中間要素によって有効な回文サブシーケンスがどのように有効になるかを示しています。 

### 例 2

 入力:```
5
1 2 3 4 5
```すべての値は 1 回出現するため、繰り返されるエンドポイントは存在しません。 エンドポイントが繰り返されないと、少なくとも 3 つの長さの回文サブシーケンスを形成できません。 

| 値 | ポジション | 周波数 | 決定 |
 | --- | --- | --- | --- |
 | 1 | [0] | 1 | いいえ |
 | 2 | [1] | 1 | いいえ |
 | 3 | [2] | 1 | いいえ |
 | 4 | [3] | 1 | いいえ |
 | 5 | [4] | 1 | いいえ |

 これにより、有効な構築には繰り返しが必要であることがわかります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        pos = {}
        for i, x in enumerate(a):
            pos.setdefault(x, []).append(i)

        ok = False

        for x, idxs in pos.items():
            if len(idxs) >= 3:
                ok = True
                break

        if not ok:
            for x, idxs in pos.items():
                if len(idxs) == 2 and idxs[1] - idxs[0] > 1:
                    ok = True
                    break

        out.append("YES" if ok else "NO")

    return "\n".join(out)

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、値がちょうど 2 回出現するが、出現が隣接している場合です。 たとえば、`[1, 1, 2]`の場合、2 つの 1 の間に中間要素を配置するスペースがないため、その値を使用して長さ 3 の回文部分列を形成することはできません。 

もう 1 つのケースは、複数の値が 2 回出現するが、すべて隣接するペアである場合です。 例えば`[1, 1, 2, 2, 3, 3]`には多くの重複がありますが、どれもギャップを提供しないため、答えは依然として「いいえ」です。 すべてのペアが分離条件を満たさないため、アルゴリズムはこれを正しく拒否します。 

3 番目のケースは、値が 3 回出現するが分散している場合です。`[1, 2, 1, 3, 1]`。 出現が連続していない場合でも、最初、3 番目、および 5 番目の出現を選択すると有効な回文サブシーケンスが形成されるため、アルゴリズムは頻度のみを正しく即座に受け入れます。
