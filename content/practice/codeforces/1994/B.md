 ## 問題の理解

 同じ長さの 2 つのバイナリ シーケンスが与えられています。`s`そして`t`。 Vanya は特定の操作を実行できます`s`繰り返し: 彼は位置から連続した部分配列を選択します`l`に`r`、各ポジションごとに`i`その部分配列では、`s[i]`と`s[i] XOR s[i - l + 1]`。 目的は、これらの操作をいくつでも使用して、変換できるかどうかを判断することです。`s`の中へ`t`。 

最初の重要な観察は、演算がビットに対して完全に線形であるということです。 各ビットは、少なくとも 1 つ存在する場合にのみ反転できます。`1`XOR を介して伝播できるプレフィックス内。 最初の要素が`0`、後のビットに直接影響を与えることはできません。 逆に、1つでもあれば、`1`で`s`、適切な操作を通じて他のビットを反転するためにそれを伝播できます。 

入力制約により、最大で次のシーケンスが許可されます。`2·10^5`テスト ケースあたりのビット数、およびテスト ケース全体のすべてのシーケンス長の合計も最大`2·10^5`。 つまり、`O(n)`テストケースごとのソリューション。 操作を直接シミュレートしようとするソリューション、特に入れ子になったループ上での操作は、非常に遅すぎます。 エッジケースが発生するのは次の場合です`s`すべて 0 であるか、シーケンスの長さが 1 である場合、XOR 伝播は不可能です。 

操作をシミュレートしようとする不注意な実装は、次のような入力で失敗する可能性があります。`s = 0`そして`t = 1`なぜなら、単一のゼロを 1 に変更する操作は存在しないからです。 

## アプローチ

 ブルート フォース アプローチでは、可能なすべての XOR 演算をシミュレートしようとします。`(l, r)`までペアリングを繰り返します`s`等しい`t`。 この操作は決定論的であり、有限の位置に限定されるため、これは原理的に機能します。 ただし、大まかには、`O(n^2)`操作ごとにペアが発生し、操作が多数繰り返される可能性があり、最悪の場合の複雑さは次のとおりです。`O(n^3)`あるいはさらに悪いことに。 最大の制約の場合 (`n ≈ 2·10^5`）、これはまったく実現不可能です。 

重要な洞察は、各ビットが`s`少なくとも 1 つのビットがある場合、XOR を介して後のビットにのみ影響を与えることができます。`1`その前に。 具体的には、インデックスでの操作`i`反転することしかできません`0`に`1`(またはその逆) 少なくとも 1 つ存在する場合`1`接頭辞で`s[0..i-1]`。 したがって、次の場合にのみ変換は不可能です。`s`すべてゼロであり、`t`少なくとも 1 つ含まれています`1`。 それ以外の場合、ゲームは「興味深い」ものになります。なぜなら、一致するように既存のゲームを建設的に伝播できるからです。`t`。 

これにより、問題は単純なチェックに減ります。`s`すべてゼロであり、`t`そうでない場合は、「いいえ」を出力します。 の最初の要素の場合、`s`の最初の要素に等しい`t`そして少なくとも1つはあります`1`どこかで`s`、またはシーケンスが同一の場合は、「Yes」を出力します。 このアプローチは、`O(n)`テストケースごとに、制限時間内に快適に収まります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。`n`とシーケンス`s`そして`t`。 
2. もし`s`に等しい`t`すでに「Yes」と出力して続行します。 操作は必要ありません。 
3. の数を数えます`1`にいる`s`。 誰もいなかったら(`count_1 == 0`） そして`t`少なくとも 1 つ含まれています`1`、「いいえ」を出力します。 ゼロを 1 に反転することは不可能です。 
4. それ以外の場合は、次の最初のビットが`s`は`0`そして最初のビット`t`は`1`。 その場合、最初の位置は変更できないため、「No」を出力します。`0`に`1`事前に伝播するものはありません。 
5. それ以外の場合は、「Yes」を出力します。 少なくとも 1 つはあります`1`伝播し、必要な構成に到達するため`t`。 

なぜ機能するのか: 不変条件は、どの位置でも`i`少なくとも 1 つ存在する場合にのみ反転できます。`1`接頭辞で`s[0..i-1]`。 数えることによって`1`s と最初の要素をチェックすると、妨げとなるすべての制約が取得されます。`t`達成可能から。 残りは、XOR 伝播の建設的な性質によって保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    q = int(input())
    for _ in range(q):
        n = int(input())
        s = input().strip()
        t = input().strip()
        
        if s == t:
            print("Yes")
            continue
        
        if '1' not in s:
            if '1' in t:
                print("No")
            else:
                print("Yes")
            continue
        
        if s[0] == '0' and t[0] == '1':
            print("No")
        else:
            print("Yes")

if __name__ == "__main__":
    main()
```このソリューションでは、最初に等価性をチェックして、些細なケースをすぐに処理します。 の数`1`にいる`s`XOR 演算が可能かどうかを識別します。 最初のビットをチェックすることで、変更できない位置が確実に尊重されます。 すべてのステップが実行されます`O(n)`テストケースごとに。

## 特殊なケース

 重大なエッジケースは次のような場合です。`s`から始まる`0`そして`t`から始まる`1`。 例えば、`s = 0xxxx`そして`t = 1xxxx`。 このシナリオでは、どの操作も最初のビットを変更することはできません。`0`に`1`、XOR は前の XOR に依存するためです。 アルゴリズムは正しく「いいえ」を返します。 もう 1 つのエッジケースは次のような場合です`s`ちょうど 1 つあります`1`最初のビットの後に位置し、`t`前のビットを反転する必要があります。 この伝播チェックでは最初のビットのみが重要であるため、この解決策は機能します。 後続のビットは、一度存在すると常に伝播できます。`1`。
