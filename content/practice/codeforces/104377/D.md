 ## 問題の理解

 配列と、この配列の選択されたセグメントからインデックスを均一に繰り返しサンプリングするランダム プロセスが与えられます。 k 個の独立したサンプルを取得した後、サンプルされた最小および最大のインデックスを調べ、その間隔にわたる配列の合計を返します。 

重要なランダム性は、配列内の値を直接表すのではなく、k 個の均一なピックによって形成されるランダムな範囲です。 すべての実験ではランダムな間隔が生成されます$[l, r]$、出力はその間隔内の値の合計です。 

元の配列の連続したサブ配列を選択することができます。 それを選択すると、すべてのサンプリングはその内部でのみ発生し、インデックスはその部分配列に対して再正規化されます。 私たちの目標は、返される間隔の合計が少なくとも以下である確率を最大化するサブ配列を選択することです。$v$。 

制約が十分に大きいため、すべてのサブ配列またはエンドポイントのすべてのペアを反復する解法は直ちに不可能になります。 と$n$まで$3 \cdot 10^5$、たとえ$O(n^2)$候補セグメントまたは区間のスキャンは考慮できません。 の値$k$は小さく、最大でも 5 です。これは、ランダム間隔の分布が小さな組み合わせ項にのみ依存し、事前計算できる閉じた形式であることを強く示唆しています。 

配列に多くの小さな値が含まれているが、長いセグメントが合計を超えるほど十分に蓄積されている場合、微妙なエッジ ケースが発生します。$v$。 単純なアプローチでは、高い個々の要素のみが重要であると想定される可能性がありますが、合計条件は区間ベースであり、長い低値ストレッチによって満たされる可能性があります。 

もう 1 つの例外的なケースは次のような場合です$v = 0$。 その場合、すべての有効な部分配列は自明のことながら確率 1 を与えますが、確率で除算したり、縮退区間を無視したりすると、間違った導出により数値が不安定になる可能性があります。 

## アプローチ

 ブルートフォースの見方は簡単です。 サブ配列を選択します$[L, R]$、次に、ジェネレーターの考えられるすべての結果を列挙します。 試行ごとに、k 個のインデックスをサンプリングし、誘導間隔を計算し、合計が少なくとも以下であるかどうかを確認します。$v$。 これを何度も繰り返すことで確率を推定します。 これは原理的には正しいですが、考えられる結果の状態空間は指数関数的です。$k$、部分配列の数は 2 次です。$n$, したがって、それは完全に不可能です。 

より構造的なアプローチは、ランダム性を配列値から分離することです。 固定長セグメントの場合$m$、の分布$(\min, \max)$k 個の均一なサンプルがどのように内部に収まるかによってのみ決まります$[1, m]$、アレイ自体ではありません。 最小値が次と等しい確率$i$そして最大値は以下に等しい$j$すべてのサンプルが存在するイベントに対して包含-除外を使用して計算できます。$[i, j]$両方のエンドポイントが少なくとも 1 回出現すること。 

これにより、ランダム性が、間隔の長さにわたって事前計算可能な重み関数に低減されます。 これが分かると、問題は次のようになります。選択した部分配列について、すべての内部区間の重みを合計します。$a$少なくとも$v$、そしてこれをすべての選択肢にわたって最大化します$[L, R]$。 

残りの問題は、「部分配列の合計」という制約が存在することです。$\ge v$” は、固定された右端点の左端点で単調です。これにより、有効な開始位置の 2 ポインターの特徴付けが可能になります。この構造により、各右端点について、有効な左端点の範囲を計算し、それを確率に寄与する間隔の長さの範囲に変換できます。

 ## アルゴリズムのチュートリアル

 1. 可能なすべての間隔の長さについて確率の重みを事前計算します。$d$。 

ある長さのセグメントの場合$d$、k 個のサンプルが正確にその範囲の間隔を生成する確率は、k と d にのみ依存し、包含排除を使用して導出できます。 

「すべてのサンプルが選択された部分間隔内にある」イベントから、1 つのエンドポイントが欠落しているケースを差し引いたもの。 
2. O(1) の長さの範囲にわたる合計をクエリできるように、これらの重みのプレフィックス合計を事前計算します。 
3. 元の配列について、すべての右端点を計算します。$r$左の最小インデックス$i^*(r)$間隔の合計が$[i^*(r), r]$少なくとも$v$。 

左端点を増加しても合計が減少するだけであるため、これは標準の 2 ポインター スライディング ウィンドウで実行できます。 
4. 次に、セグメントの選択を検討します。$[L, R]$。 右端ごとに$r \in [L, R]$、このセグメント内の有効な左端点は次のとおりです。$i \in [L, R]$そのような$i \le i^*(r)$。 もし$i^*(r) < L$の場合、次で終わる有効な間隔はありません。$r$このセグメント内に存在します。 
5. 有効な左範囲を間隔の長さの範囲に変換します。 固定の場合$r$、左側のエンドポイントを選択します$i$間隔の長さに対応します$d = r - i + 1$。 これはそれぞれを回転させます$r$連続する長さの範囲にわたる寄与に変換され、事前に計算された重みのプレフィックスを使用して合計できます。 
6. 可能性のあるスイープによる候補セグメントの評価$L$すべての人々からの貢献を維持する$r \ge L$、効率的に更新します$L$動く。 最良のセグメントは、最大の累積確率を持つセグメントです。 

重要な不変条件は、各固定右端点に対する$r$の場合、有効な左端点のセットはインデックスのプレフィックスを形成するため、誘導された間隔の長さのセットは可能な長さの連続したサフィックスを形成します。 この連続性により、重み関数のプレフィックス合計がすべての明示的な列挙を置き換えることができるようになります。$(i, r)$ペア。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_weights(k, max_n):
    # w[d] = P(min/max span is exactly d)
    w = [0.0] * (max_n + 1)
    for d in range(1, max_n + 1):
        # inclusion-exclusion on boundaries
        a = d ** k
        b = (d - 1) ** k if d - 1 >= 0 else 0
        c = (d - 2) ** k if d - 2 >= 0 else 0
        w[d] = a - 2 * b + c
    return w

def solve():
    T = int(input())
    for _ in range(T):
        n, k, v = map(int, input().split())
        a = list(map(int, input().split()))

        w = build_weights(k, n)
        pw = [0.0] * (n + 1)
        for i in range(1, n + 1):
            pw[i] = pw[i - 1] + w[i]

        # i_star[r] = smallest i with sum(i..r) >= v
        i_star = [0] * n
        cur = 0
        l = 0
        for r in range(n):
            cur += a[r]
            while l <= r and cur >= v:
                cur -= a[l]
                l += 1
            # now sum(l..r) < v, so i_star is l-1 if possible
            i_star[r] = l - 1

        ans = 0.0

        # sweep L
        for L in range(n):
            cur_prob = 0.0
            for r in range(L, n):
                i_star_r = i_star[r]
                if i_star_r < L:
                    continue

                left_i = max(L, i_star_r)
                if left_i > r:
                    continue

                d_min = r - left_i + 1
                d_max = r - L + 1

                cur_prob += pw[d_max] - pw[d_min - 1]

                ans = max(ans, cur_prob)

        print(f"{ans:.12f}")

if __name__ == "__main__":
    solve()
```実装は、包含/除外アイデンティティを使用して間隔の長さの確率の重みを構築することから始まります。 これらの重みはプレフィックスの合計に変換されるため、連続する長さの範囲を一定時間で評価できます。 

スライディング ウィンドウ セクションは、すべての右端点について、間隔の合計を以下に維持しながら左方向にどこまで拡張できるかを計算します。$v$。 次に、保存された境界が逆に使用されます。有効な左端点は、この境界より前の端点です。 

ダブルループオーバー$L$そして$R$貢献を集計します。 各ペアごとに$(L, R)$、各エンドポイント$R$間隔の長さの範囲とプレフィックスの合計に寄与します。$w$それを O(1) の作業に変換します。

 ## 特殊なケース

 重大なエッジケースは次のような場合です。$v = 0$。 この状況では、すべての間隔が自動的に条件を満たすため、空でないセグメントの確率は正確に 1 になるはずです。 すべての右エンドポイントがすべての可能な長さを即座に提供し、重みに対するプレフィックスの合計が合計確率質量に集約されるため、アルゴリズムはこれを処理します。 

別のエッジケースは、すべての配列値がゼロである場合に発生しますが、$v > 0$。 スライディング ウィンドウは有効な左境界を決して見つけられないため、$i^*(r)$無効となります。 これにより、すべての寄与が強制的にゼロになります。これは、区間の合計が正のしきい値に到達できないという事実と一致します。 

最後の微妙なケースは、k が 1 の場合です。その場合、最小値と最大値は常に一致し、返される間隔の長さは常に 1 になります。重み関数は折りたたまれて、単一要素の間隔のみが問題になり、アルゴリズムは正しく、少なくとも要素の割合を最大化するセグメントを選択します。$v$。
