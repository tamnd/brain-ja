 ## 解決策
 ## 問題の理解

 各エッジがしきい値のように動作する重みをもつ無向グラフが与えられます。 値 k を保持するノード S から開始し、ノード T に到達したいとします。重み w のエッジをトラバースすると、現在の値は非常に特殊な形で影響を受けます。現在の値が最大でも w の場合は何も起こりませんが、w より大きい場合は、正確に w に減らされます。 

これは、どのパスに沿っても、値が増加することはなく、エッジの重みによって繰り返し「固定」されることを意味します。 一連のエッジを歩いた後の最終値は、開始値 k とそのパス上のすべてのエッジの重みの最小値になります。 

タスクは、この最終値を最大化する S から T へのパスを選択することです。 パスが存在しない場合、答えはゼロになります。 

制約は非常に大きく、最大 100 万のノードと 100 万のエッジがあります。 これにより、すべてのパスを明示的に検査するアプローチは即座に除外されます。 ノード数が 2 次または 3 次のアルゴリズムであっても不可能です。 O(m log n) や O(m α(n)) など、線形に近い時間、または線形に近い時間が必要です。 

S と T が切断されると、微妙なエッジ ケースが発生します。 たとえば、グラフに 2 つのコンポーネントがあり、S と T が異なるコンポーネントにある場合、走査は不可能であり、k に関係なく正解は 0 になります。 もう 1 つの特殊なケースは、すべてのエッジの重みが 0 である場合です。この場合、どのパスでも値がすぐに 0 に折りたたまれます。そのため、到達可能な場合、答えは 0 ですが、そうでない場合は 0 のままです。 

## アプローチ

 重要な観察は、パスに沿って運ぶ値が常に k とこれまでに発生した最小エッジ重みの間の最小値であるということです。 したがって、固定パスの場合、最終値はボトルネック エッジのみに依存します。 

これにより、問題は古典的な最大ボトルネック パス問題に変わります。 パスに沿った最小エッジ重みを最大化する S から T へのパスが必要です。 ボトルネック値 B が見つかると、最終的な答えは min(k, B) になります。 

ブルートフォース手法では、S から T までのすべての可能なパスを列挙し、各パスに沿った最小のエッジの重みを計算し、最大値を取得します。 これは原理的には正しいですが、グラフ内のパスの数は指数関数的に増加する可能性があります。 まばらなグラフであっても、これはすぐに実行不可能になります。 

問題の構造により、より良い戦略が可能になります。 パスを探索する代わりに、逆に考えることができます。少なくとも X の重みを持つエッジのみを保持する場合、S と T が接続されているかどうかを尋ねることができます。 そうである場合、最小エッジ重みが少なくとも X であるパスが存在します。これは、エッジしきい値に対する単調な特性を示唆しています。 

この単調性により、貪欲な構築が可能になります。 エッジを重みで降順に並べ替え、Union-Find 構造に徐々に追加すると、S と T が接続された瞬間に、接続を許可する最大のしきい値が見つかります。 このしきい値はまさに最適なボトルネック値です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n + m) | 遅すぎる |
 | ソート付きの Union-Find | O(m log m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 この問題を、S から T のパスに沿って可能な限り最も強力な最小エッジを見つけることに変換します。

1. すべてのエッジを重みの降順に並べ替えます。 これにより、常に最初に最も強い制約を使用してグラフの接続を試行し、高いボトルネック パスが発生する可能性が維持されます。 
2. 各ノードが独自のコンポーネントで始まる Union-Find 構造を初期化します。 この構造は、これまでに処理されたエッジを使用して、現在どのノードが接続されているかを追跡します。 
3. ソートされた順序でエッジを反復処理します。 各エッジ (u、v、w) について、u と v を含むコンポーネントをマージします。その理由は、このエッジは、少なくとも w の重みのエッジを使用するパスの一部として使用できるようになるためです。 
4. 各和集合演算の後、S と T が同じ連結成分に属しているかどうかを確認します。 これが起こる最初の瞬間は、それらの間のパスを依然として許可する最も強いしきい値に相当します。 
5. このエッジの重みをボトルネックの回答として記録し、それ以降のエッジの処理を停止します。 それ以降のエッジの重みは小さくなり、より弱いボトルネックのみが生成されます。 
6. S と T が接続されない場合、答えは 0 です。 

処理後、元の問題の答えは min(k, bottleneck) になります。これは、グラフでより強力なパスが許可されている場合でも、初期値が結果を制限するためです。 

### なぜ効果があるのか

 スイープ中のどの時点でも、Union-Find 構造は、現在のしきい値以上の重みを持つエッジのみを使用して接続を表します。 S と T が重み w で接続される場合、すべてのエッジが少なくとも w の重みを持つパスが存在することを意味します。 したがって、そのパス上の最小エッジは少なくとも w です。 

エッジを最大から最小の順に処理するため、接続の最初の瞬間で最大性が保証されます。 それ以降の接続では弱いエッジを使用する必要があるため、最初の成功しきい値を超えてボトルネックを改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)
        if ra == rb:
            return False
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]
        return True

n, m, S, T, k = map(int, input().split())
edges = []

for _ in range(m):
    u, v, w = map(int, input().split())
    edges.append((w, u, v))

edges.sort(reverse=True)

dsu = DSU(n)
best = -1

for w, u, v in edges:
    dsu.union(u, v)
    if dsu.find(S) == dsu.find(T):
        best = w
        break

if best == -1:
    print(0)
else:
    print(min(k, best))
```このコードは、まず動的接続を維持するために DSU を構築します。 エッジを降順に並べ替えると、常に可能な限り高いしきい値を最初に使用してグラフの接続が試行されるようになります。 S と T が初めて接続されるとき、現在のエッジの重みは達成可能な最良のボトルネックを表します。 

パスでより高いボトルネックが許容される場合でも、開始値が k を超えることはできないため、k との最終比較が必要です。 

## 実用的な例

 サンプルグラフを考えてみましょう。 

入力:```
4 5 1 4 6
1 2 1
1 4 2
1 3 3
2 4 3
3 4 1
```エッジを重みで並べ替えます。 

| ステップ | エッジ | アクション | コンポーネント | コンポーネント(T) | 接続済み | ベスト |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | (1-3,3) | 組合 | {1,3} | {4} | いいえ | - |
 | 2 | (2-4,3) | 組合 | {1,3} | {2,4} | はい | 3 |

 ステップ 2 では、ノード 1 と 4 が重み 3 以上のエッジを介して接続されます。これは、ボトルネック 3 を持つパスが存在することを意味します。 

最終的な答えは min(k, 3) = min(6, 3) = 3 です。 

これは、最短経路や特定のルートを選択しているのではなく、最も強い最も弱いエッジを持つ経路を選択していることを裏付けています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(m log m) | ソートエッジが優勢で、DSU の動作はほぼ一定です。 
| スペース | O(n + m) | グラフ エッジと DSU 配列の保存 |

 この制約では最大 100 万エッジが許可されており、このスケールでの並べ替えは、効率的な入力処理を使用して Python で 3 秒以内に実行可能です。 DSU の動作は基本的に直線的なため、ボトルネックになることはありません。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n + 1))
            self.size = [1] * (n + 1)

        def find(self, x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a, b):
            ra = self.find(a)
            rb = self.find(b)
            if ra == rb:
                return False
            if self.size[ra] < self.size[rb]:
                ra, rb = rb, ra
            self.parent[rb] = ra
            self.size[ra] += self.size[rb]
            return True

    n, m, S, T, k = map(int, input().split())
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        edges.append((w, u, v))

    edges.sort(reverse=True)
    dsu = DSU(n)

    best = -1
    for w, u, v in edges:
        dsu.union(u, v)
        if dsu.find(S) == dsu.find(T):
            best = w
            break

    return str(0 if best == -1 else min(k, best)) + "\n"

# sample
assert run("""4 5 1 4 6
1 2 1
1 4 2
1 3 3
2 4 3
3 4 1
""") == "3\n"

# disconnected graph
assert run("""3 1 1 3 10
1 2 5
""") == "0\n"

# all edges zero
assert run("""3 2 1 3 5
1 2 0
2 3 0
""") == "0\n"

# direct edge dominates
assert run("""2 1 1 2 100
1 2 50
""") == "50\n"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | サンプルグラフ | 3 | ボトルネックの正しい計算 |
 | 切断されました | 0 | 到達不能なケース |
 | すべてゼロの重み | 0 | 崩壊動作 |
 | シングルエッジキャップ | 50 | k と直接パスとの相互作用 |

 ## 特殊なケース

 次のような切り離されたグラフ`1 2 1 3 10`1 と 2 の間に単一のエッジがあることは、S と T を接続する共用体が存在しないことを示しているため、最適な値は設定されず、出力は 0 になります。 

すべてのエッジの重みが 0 であるグラフは、接続性が存在する場合でも、すべてのパスがキャリー値を即座に 0 に減らすため、k に関係なく答えは 0 のままでなければならないことを示しています。 最初に成功した接続は重み 0 で発生し、min(k, 0) は正しく 0 を返すため、アルゴリズムはこれを処理します。 

シングルエッジ グラフは、S と T が直接接続されている境界をテストします。 DSU はそれらを即座にマージし、そのエッジの重みを最適なものとし、それを k と比較して、キャップが正しく適用されていることを確認します。
