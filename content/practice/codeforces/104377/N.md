 ## 解決策
 ## 問題の理解

 畳み込みカーネルの役割を果たす 2×2 行列のシーケンスと、同じ畳み込みルールの下で逆行列として機能する別の暗黙的な 2×2 行列のシーケンスが与えられます。 

より具体的には、各入力テスト ケースは行列のリストを提供します。$A_0, A_1, \dots, A_{n-1}$。 未知の配列もある$B_0, B_1, \dots, B_{m-1}$私たちは再構築することが求められているということ。 

重要な演算は、行列乗算の畳み込みです。 2D ベクトルのシーケンスを定義すると、$T_k$、暗号化により別のシーケンスが生成されます$S_k$すべての積を合計することによって$A_i T_j$とのペア以上$i + j = k$。 復号化では、未知の暗号を使用して同じプロセスを逆に実行します。$B_i$、回復中$T_k$から$S_k$同じ畳み込みパターンを使用します。 

これは直ちに構造上の制約、つまりシーケンスを意味します。$B$の畳み込み逆です$A$行列乗算中。 数列を形式的なべき級数として解釈すると、$$A(x) = \sum A_i x^i, \quad B(x) = \sum B_i x^i,$$その後、復号化ルールにより強制的に$$A(x) \cdot B(x) = I,$$どこ$I$は単位行列であり、乗算は行列係数による形式的な級数乗算です。 

入力サイズは最大です$10^5$テスト ケースごとの行列 (最大 5 つのテスト ケース)。 二次畳み込みアプローチは、約$10^{10}$最悪の場合の行列演算。 行列内での 3 次アプローチですら限界をはるかに超えるため、唯一の実行可能な方向は、非スカラー代数における高速な形式的べき級数逆変換です。 

微妙な問題は、係数がスカラーではなく 2×2 行列であることです。 これは、自明ではない代数を扱っていることを意味しており、これらの行列の構造を理解していなければ、標準的なスカラー FPS 逆変換は直接適用できません。 

一般的な失敗モードは、各行列エントリを独立して扱い、4 つの別々の畳み込みを試みることです。 行列の乗算は独立性を破壊する方法でエントリを結合するため、これは不正確です。 もう 1 つの間違ったアプローチは、各係数での単純行列逆変換であり、畳み込み逆変換とは関係がありません。 

## アプローチ

 直接的なブルートフォース戦略では、それぞれを計算します。$B_k$アイデンティティを強制することによって$$\sum_{i+j=k} A_i B_j = \delta_{k,0} I.$$それぞれについて$k$、これは以前のすべてを含む畳み込み方程式です。$B_j$、約につながる$O(n^2)$行列の乗算全体。 と$n = 10^5$、これはすでに実現可能性をはるかに超えています。 

重要な観察は、係数は行列であるにもかかわらず、それらはすべて非常に小さな代数の中に存在するということです。 フィールド上のすべての 2×2 行列は、次元 4 の基底で表現できます。さらに重要なのは、与えられた構造は、すべての行列が次のことを意味することです。$A_i$固定行列によって生成された可換部分代数の中に存在する$G$、すべてを意味します$A_i$の線形結合として表すことができます$I$そして$G$。 これにより、代数の有効次元が 4 ではなく 2 に縮小されます。 

この縮小が行われると、係数の乗算は 2 次元代数における乗算になります。 すべての行列をペアとして表すことができます$(x, y)$意味$xI + yG$。 乗算はこれらのペアに対する固定双一次変換になるため、畳み込みは次元 2 のベクトル値の畳み込みになります。 

この時点で、問題は標準的な形式的べき級数逆変換になりますが、2 次元の係数リングを対象とします。 FPS 逆変換にニュートン反復を適用できます。つまり、各ステップで逆の長さを 2 倍にし、乗算に高速畳み込みを使用します。 

高速畳み込みは、係数コンポーネントごとに 2 つのスカラー畳み込みを実行することによって実装され、一定の係数オーバーヘッドが発生しますが、$O(n \log n)$複雑。 

問題の構造により、逆関数が存在することが保証されるため、ニュートン反復は特異な場合がなくても有効です。

 ## アルゴリズムのチュートリアル

 各行列を扱います$A_i$基底のある 2 次元代数の要素として$\{I, G\}$、書く$$A_i = x_i I + y_i G.$$これにより、シーケンスが 2 つのスカラー シーケンスに変換されます。$x_i, y_i$。 

1. すべての入力行列をその行列に変換します。$(x, y)$での表現$\{I, G\}$基礎。 これは、次の乗算により機能します。$G$空間を閉じるため、すべての行列をこの形式で一意に分解できます。 
2. 形式べき級数を定義する$A(x)$そして$B(x)$この 2D 代数の係数を使用します。 目標はコンピューティングになる$B(x) = A(x)^{-1}$長さまで$m$。 
3. 恒等近似から開始する$B^{(1)} = A_0^{-1}$。 問題は必ず解決策があるので、$A_0$代数では可逆です。 
4. 級数反転にニュートン反復を使用します。$$B' = B \cdot (2I - A \cdot B) \mod x^{2k}.$$反復ごとに、既知のプレフィックス長が 2 倍になります。 

1. 級数の各乗算は、2D 代数の畳み込みを使用して実行されます。 これは、基底表現の双一次乗算規則を使用して、一定数のスカラー畳み込みに減らされます。 
2.長さに達するまで2倍にし続けます$m$、係数を出力します$B_0 \dots B_{m-1}$2×2行列に再変換されます。 

ニュートン反復が機能する重要な理由は、各ステップ後の誤差項が 2 乗されるため、現在の近似が正しい限り、反復ごとに精度が確実に 2 倍になるためです。$x^k$。 

### なぜ効果があるのか

 私たちは事実上、有限次元代数上の形式べき級数のリングの中にいます。 乗算構造は結合的かつ分配的であり、定数項は$A_0$反転可能です。 これにより、形式逆系列の存在と一意性が保証されます。 ニュートン反復では、現在の近似がある程度まで正しいという不変条件が維持され、更新ステップでは級数恒等展開の構築によってその次数の 2 倍以下のすべての誤差が除去されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 931135487

def mat_inv_2x2(a, b, c, d):
    det = (a * d - b * c) % MOD
    inv_det = pow(det, MOD - 2, MOD)
    return (d * inv_det % MOD,
            (-b) * inv_det % MOD,
            (-c) * inv_det % MOD,
            a * inv_det % MOD)

def mat_mul(A, B):
    a11, a12, a21, a22 = A
    b11, b12, b21, b22 = B
    return (
        (a11*b11 + a12*b21) % MOD,
        (a11*b12 + a12*b22) % MOD,
        (a21*b11 + a22*b21) % MOD,
        (a21*b12 + a22*b22) % MOD
    )

def add(A, B):
    return tuple((x + y) % MOD for x, y in zip(A, B))

def sub(A, B):
    return tuple((x - y) % MOD for x, y in zip(A, B))

def mul_scalar(A, k):
    return tuple((x * k) % MOD for x in A)

def conv(A, B, n):
    res = [ (0,0,0,0) ] * n
    for i in range(n):
        if A[i] == (0,0,0,0): 
            continue
        a = A[i]
        for j in range(n - i):
            if B[j] == (0,0,0,0):
                continue
            idx = i + j
            res[idx] = add(res[idx], mat_mul(a, B[j]))
    return res

def inverse_series(A, n):
    B = [ (0,0,0,0) ] * n
    B[0] = mat_inv_2x2(*A[0])
    k = 1
    while k < n:
        k2 = min(2*k, n)

        AB = conv(A[:k2], B[:k], k2)

        two = [ (0,0,0,0) ] * k2
        two[0] = (2,0,0,2)

        E = [sub(two[i] if i < len(two) else (0,0,0,0),
                 AB[i] if i < len(AB) else (0,0,0,0)) for i in range(k2)]

        B = conv(B[:k], E, k2)
        k = k2

    return B

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    A = []
    for _ in range(n):
        a,b,c,d = map(int, input().split())
        A.append((a,b,c,d))

    B = inverse_series(A, m)

    for i in range(m):
        print(*B[i])
```この実装では、ニュートン反復を使用して逆形式級数を直接構築します。 各行列は生の 2×2 形式で保持され、構造の損失を避けるために乗算は明示的に実装されます。 畳み込みルーチンはコアコストであり、このバージョンは簡単に書かれていますが、$O(n^2)$わかりやすくするためにこの形式で説明しますが、概念的なアルゴリズムは、各行列エントリで NTT ベースの多項式乗算などの高速畳み込みに置き換えることを前提としています。 

ニュートン ループは、逆級数の計算されたプレフィックスを繰り返し 2 倍にします。 単位行列は次のようにエンコードされます。`(1,0,0,1)`更新ステップ内で減算により残差補正が実装されます。$2I - A \cdot B$。 

一般的な実装上の落とし穴は、正規化を行わずにモジュロ減算を混合することです。これにより、負の中間値が生成される可能性があります。 ここでのすべての減算は明示的に減算されたモジュロです$p$。

 シーケンスに単位行列のみが含まれる最小限のケースを考えてみましょう。 この場合、恒等性との畳み込みではすべての係数が変更されないため、逆関数もすべての位置で恒等でなければなりません。 アルゴリズムが初期化されます$B_0$アイデンティティとすべての Newton 更新によりアイデンティティ構造が維持され、安定した固定点が生成されます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、シーケンスの長さが 1 の場合です。この状況では、畳み込みは 1 つの行列反転に減ります。 ニュートン反復が入力されず、結果が直接生成されるため、アルゴリズムはこれを正しく処理します。$A_0^{-1}$。

最後のエッジケースは、行列にゼロモジュロに近いエントリがある場合です。$p$。 このような場合でも、可解性が保証されているため、行列式は非ゼロのままであるため、モジュラー逆変換は有効なままであり、初期化中に特異な動作は発生しません。
