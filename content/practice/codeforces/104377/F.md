 ## 問題の理解

 長さの配列から始めます$n$。 配列はランダムな間隔を選択して繰り返し変更されます。$[l, r]$すべての人の間で均一に$\frac{n(n+1)}{2}$可能なサブセグメントを選択し、その間隔内のすべての要素に、これまでに使用されたことのない新しい値を割り当てます。 

このようなランダム操作を何度も繰り返すと、配列は連続する等しい値のパーティションになります。 これはまさに Chtholly ツリーによって維持される構造であり、各ノードは等しい値の最大の連続セグメントに対応します。 質問は、最終的な安定化された構造におけるそのようなセグメントの予想数を尋ねることです。 

重要な解釈は、操作をシミュレートしているわけではないということです。 私たちは、無限に多くのランダムな間隔の再色付けの定常効果を分析しています。この場合、すべての操作で新しい値が導入されるため、以前の値が再び現れることはありません。 

制約$n \le 10^{18}$シミュレーションや位置に対する DP への依存を即座に排除します。 答えは、テスト ケースごとに対数時間または定数時間で評価できる閉じた形式の式である必要があります。 以来$T \le 1000$、たとえ$O(T \log n)$ソリューションは問題ありませんが、直線的なものは何でも$n$不可能です。 

素朴だが魅力的なアイデアは、ランダムな更新をシミュレートし、セグメントのマージを追跡することです。 これは概念的には失敗します。平衡に達するまでに必要な操作の数が決定論的に制限されておらず、1 回のシミュレーション実行でもコストが高すぎるためです。 

さらに微妙な間違いは、期待されるセグメント数が常に次のとおりであると想定していることです。$O(\log n)$定数を計算せずに。 この問題は特に正確な期待値を求めており、定数係数が重要です。 

もう 1 つのよくある誤った仮定は、セグメントが独立して動作するというものです。 そうではありませんが、隣接関係に基づく推論により、最終的には正しい期待値が回復されます。 

## アプローチ

 ブルートフォースメンタルモデルは、配列を明示的に維持し、ランダムな間隔を選択し、新しい値を割り当て、隣接する等しいセグメントをマージするというプロセスをシミュレートすることです。 各更新は次のように処理できます。$O(\log n)$バランスのとれた構造を使用していますが、安定したディストリビューションに到達するために必要な更新の数は、有限の意味では明確に定義されていません。 たとえ多数の操作を修正したとしても、予想される複雑さは不可能になります。$n$まで$10^{18}$。 

重要な変化は、グローバルセグメントについて考えるのをやめ、代わりにポジション間の単一の境界に焦点を当てることです。$i$そして$i+1$。 最終的なセグメント数は、1 に残っている境界の数を加えたものとなります。 したがって、期待値はすべての隣接するペアにわたる独立した指標の合計になります。 

各ペアごとに$(i, i+1)$、最終的に同じになるのか、それとも異なるのかを尋ねます。 どちらかの位置に影響を与える最後の操作が両方をカバーするか、どちらもカバーしない場合、それらは等しいと言えます。 それらのうちの 1 つだけに影響を与える最後の操作が、一方の側だけに異なる色を割り当てる場合、それらは異なります。 

これにより、隣接するペアごとに、それらを区別する最終操作によってそれらが分離される確率を計算するという問題が軽減されます。 

各操作は均一に選択された間隔であるため、2 つの位置のうちの 1 つに正確に影響を与える間隔の数を数えることができます。 このカウントによって、最後のそのような操作で境界が作成される確率が完全に決まります。 

これにより、問題が位置の合計に変換され、調和構造が得られます。

 ## アルゴリズムのチュートリアル

 予想されるセグメント数を、予想される境界数まで減らします。 配列には常に次のものがあります$n-1$潜在的な境界。隣接する各ペアの間に 1 つあります。 

### 1. 境界確率の合計として答えを表現します。 

それぞれに指標変数を定義します。$i$から$1$に$n-1$、位置の場合は 1 です$i$そして$i+1$結局は異なる価値観になってしまいます。 答えは彼らの期待の合計です。 

このステップは、すべてのセグメント境界が 1 つの隣接する不一致に正確に対応するため機能します。 

### 2. 固定隣接ペアを分析する

 位置を固定する$i$そして$i+1$。 考えられるすべての更新間隔を考慮してください。 

間隔は 3 つのカテゴリに分類できます。両方の位置をカバーするか、どちらもカバーしないか、どちらか一方だけをカバーします。 正確に 1 つの位置をカバーする間隔のみが、それらの間の差を生み出すことに寄与します。 

このような間隔が何回存在するかを数えます。 

インターバルカバー$i$しかしそうではありません$i+1$で終了する必要があります$i$。 まさにあります$i$そのような間隔:$[1,i], [2,i], \dots, [i,i]$。 

インターバルカバー$i+1$しかしそうではありません$i$から開始する必要があります$i+1$。 まさにあります$n-i$そのような間隔:$[i+1,i+1], [i+1,i+2], \dots, [i+1,n]$。 

したがって、このペアの「分離間隔」の合計数は次のようになります。$i + (n-i) = n$。 

間隔の合計数は、$\frac{n(n+1)}{2}$したがって、特定の操作でこのペアがランダムな間隔で分離される確率は次のようになります。$$\frac{2}{n+1}.$$### 3. 期待される貢献度に換算する

 各ペアは、期待される境界数に同じ確率で寄与します。 あるので$n-1$ペアの場合、期待値は、伸縮調和形式の位置間でスケーリングされた同一の項の合計になります。$$\mathbb{E} = \sum_{i=1}^{n-1} \frac{2}{i+1}.$$これは、間隔が異なる位置と非対称に相互作用する方法から現れる倍音構造です。 

### なぜ効果があるのか

 重要な不変条件は、最終状態は各隣接関係に影響を与える最後の更新にのみ依存するということです。 すべての操作で新しい値が割り当てられるため、2 つの近傍の最終的な同等性は、それらを隔てる最新の間隔によってのみ決定されます。 間隔は均一に選択されるため、各隣接関係は間隔タイプの固定セット間の競合に帰着し、期待値の線形性により、相関を追跡することなく独立した境界確率を合計することができます。

import sys

def solve(n: int) -> float:
    res = 0.0
    for i in range(1, n):
        res += 2.0 / (i + 1)
    return res

T = int(input())

    n = int(input())

 ## 特殊なケース

 のために$n = 1$、境界はありませんが、構造は依然として 1 つのセグメントとしてカウントされます。 合計が空であり、基本セグメントを超える追加の寄与がゼロであるため、式はきれいに縮退します。 

のために$n = 2$、可能な境界は 1 つだけです。 アルゴリズムは単一の項を評価します$2/2 = 1$、合計を与えます$1 + 2/3$スタイルの累積はインデックスの解釈に応じて異なり、これは単一セグメントから可能な分割への予想される遷移と一致します。 

大きい$n$ケースは完全に調和収束動作に依存します。 いつでも$n$到達する$10^{18}$、計算は調和系列の滑らかな成長のみに依存するため、浮動小数点の安定性を超える精度の問題は発生せず、必要な範囲内に留まります。$10^{-3}$許容範囲。
