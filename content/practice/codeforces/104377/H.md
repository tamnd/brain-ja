 ## 問題の理解

 私たちには次のシーケンスが与えられています$n$それぞれに高さのある柱。 このシーケンスから、元の順序を維持しながら空ではないサブシーケンスを選択することができます。 選択後は、選択した柱のみが保持されます。 

連続する選択された要素のすべてのペアの高さが少なくとも異なる場合、選択されたサブシーケンスは有効であると見なされます。$k$。 サブシーケンスに要素が 1 つだけある場合は、要素に関係なく常に有効です。$k$。 

タスクは、有効な空ではないサブシーケンスがいくつ存在するかを数え、結果のモジュロを出力することです。$10^9 + 7$。 

入力サイズは最大 500,000 要素と大きいため、サブシーケンスを明示的に列挙しようとするソリューションは不可能です。 すべてのサブシーケンスを保存することすら不可能です。$2^n$彼らのうち。 これにより、要素を順番に処理し、カウントを効率的に集計する動的プログラミング ソリューションがすぐに必要になります。 

値の制約も重要です。 高さは最大 100000、しきい値は$k$最大でも 100 です。これは小さいです$k$インデックスに対する固定ウィンドウを直接示唆するものではありませんが、各値の周囲に「禁止バンド」を定義します。これが最適化で使用されるキー構造になります。 

微妙なエッジケースが現れるのは、$k = 0$。 この場合の条件は、$|a_i - a_j| \ge 0$は常に true であるため、空でないすべてのサブシーケンスは有効です。 The answer becomes$2^n - 1$。 「単一要素サブシーケンス」のケースを二重にカウントしたり誤って処理したりする誤った DP は、ここでは失敗します。 

すべての値が等しい場合には、別の特殊なケースが発生します。$k > 0$。 この場合、サブシーケンス内に 2 つの要素が共存することはできないため、単一要素のサブシーケンスのみが有効となり、答えは正確に次のようになります。$n$。 これは、正しさの健全性チェックに適しています。 

## アプローチ

 最も直接的なアイデアは、すべてのサブシーケンスを考慮して、それが有効かどうかを確認することです。 選択したサブシーケンスごとに、隣接する選択した要素をスキャンし、絶対的な差の条件を検証します。 これは正しいですが、まったく実行不可能です。 がある$2^n$それぞれのチェックには最大で次のコストがかかります$O(n)$、指数関数的な時間を与えます。 

これを改善するために、サブシーケンス全体から段階的に構築することに視点を移します。 要素を左から右に処理し、位置ごとに、その位置で終了する有効なサブシーケンスの数を維持するとします。 以前のインデックスで終了する有効なサブシーケンスがすべてわかっている場合は、高さの制約が満たされるたびに、それらを現在の位置まで拡張できます。 

これは動的プログラミングの定式化につながります。 インデックスごとに$i$と定義します。$dp[i]$最後に選択された要素が次である有効なサブシーケンスの数として$a_i$。 このようなすべてのサブシーケンスは、次のいずれかで構成されます。$a_i$、または、ある時点で終了する前のサブシーケンスを拡張します。$j < i$どこ$|a_i - a_j| \ge k$。 

難しいのは、これまでの有効なすべてのデータを効率的に合計することです。$j$。 あらゆるものに対する単純なスキャン$i$につながる$O(n^2)$が遅すぎる$n = 5 \cdot 10^5$。 

重要な観察は、遷移は次の値のみに依存するということです。$a_j$、その位置ではありません。 身長別にグループ化された以前のすべての DP 値を高速に集計する必要があります。 高さの値の合計を格納するフェンウィック ツリーを維持します。$dp$身長ごとの貢献度。 それからそれぞれについて$i$、すべての高さの 2 つの範囲をクエリできます。$\le a_i - k$そしてすべての高さ$\ge a_i + k$。 

それぞれ$dp[i]$次のように計算されます$1 +$互換性のあるすべての以前の dp 値の合計を計算し、それを計算した後、構造に挿入します。

 ## アルゴリズムのチュートリアル

 配列を左から右に処理し、可能な高さの値にわたってフェンウィック ツリーを維持します。 各インデックスは、計算後にその DP 値を構造に組み込みます。 

1. 高さの値に対するプレフィックスの合計をサポートするフェンウィック ツリーを初期化します。 また、合計の答えの変数も維持します。 
2. 各インデックスについて$i$で終わる有効なサブシーケンスの数を計算します。$i$最初に以下のみからなる部分列を仮定することにより、$a_i$、1に貢献します。 
3. フェンウィック ツリーに対して、高さ以下の以前の要素からのすべての dp 寄与の合計をクエリします。$a_i - k$。 これにより、十分に小さい以前のエンドポイントがすべてキャプチャされます。 
4. 少なくとも高さを持つ以前の要素からのすべての dp 寄与の合計についてフェンウィック ツリーをクエリします。$a_i + k$。 これにより、十分に大きい以前のエンドポイントがすべてキャプチャされます。 これは、プレフィックスの合計からプレフィックスの合計を引いたものとして実装されます。$a_i + k - 1$。 
5. 両方の寄与を基本値 1 に加算して、$dp[i]$。 
6.挿入$dp[i]$フェンウィックツリーの位置に$a_i$, したがって、将来の要素で使用できるようになります。 
7.追加$dp[i]$グローバルな答えへ。 

これが機能する理由は、すべての有効なサブシーケンスに一意の最後の要素があるためです。 インデックス処理時$i$、最後の要素が次のようなサブシーケンスを正確に数えます。$a_i$、有効な以前のエンドポイントからのみ拡張します。 フェンウィック ツリーは、ペアごとの遷移を再計算することなく、以前のすべての有効なエンドポイントが確実に集約されるようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        while i <= self.n:
            self.bit[i] = (self.bit[i] + v) % MOD
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s = (s + self.bit[i]) % MOD
            i -= i & -i
        return s

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    maxv = max(a)
    fw = Fenwick(maxv + 2)

    ans = 0

    for x in a:
        left = fw.sum(x - k) if x - k >= 1 else 0
        right = (fw.sum(maxv) - fw.sum(x + k - 1)) % MOD if x + k <= maxv else 0

        dp = (1 + left + right) % MOD

        fw.add(x, dp)
        ans = (ans + dp) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```フェンウィック ツリーには、高さによってインデックス付けされた累積 DP 値が保存されます。 の計算`left`現在の値より大幅に小さい、以前の有効なエンドポイントをすべて収集します。`right`かなり大きいものを収集します。 DP 値自体には定数 1 を介した単一要素のサブシーケンスが含まれており、拡張が不可能な場合でも正確性が保証されます。 

モジュロは更新のたびに適用され、オーバーフローを防止し、累積が繰り返される場合でも操作の一貫性を保ちます。

 ## 特殊なケース

 いつ$k = 0$、すべての新しい要素は、以前のすべてのサブシーケンスを拡張できます。 DP は、各ポジションが寄与する単純な 2 倍プロセスになります。$2^{i-1}$そこで終わる後続。 フェンウィック ツリーは以前のすべての dp 値を累積するため、各クエリは完全なプレフィックス合計を正確に返し、アルゴリズムは自然に次の値を返します。$2^n - 1$。 

すべての値が同一の場合、$k > 0$、どちらのクエリ範囲も常に空であるため、$dp[i]$フェンウィック ツリーは引き続き更新されますが、将来の要素はこれらの値を使用できません。 最終的な答えはこうなります$n$これは、単一要素のサブシーケンスのみが有効であるという事実と一致します。
