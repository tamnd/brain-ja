 ## 問題の理解

 私たちは、$k$- 大きな軸が整列した超立方体が存在する次元グリッド空間$A$原点から点までの範囲$(n, n, \dots, n)$。 この大きなハイパーキューブの内部で、軸が整列した整数座標の可能な限り小さなハイパーキューブを考慮します。$B$内側に完全に収まる$A$。 このような各立方体は、開始隅と辺の長さを選択することによって定義され、有効な選択肢はすべて同じ確率で選択されます。 

タスクは、ランダムに選択された立方体の予想されるハイパーボリュームを計算することです。$B$。 ハイパーボリュームは単純に$(\text{side length})^k$、私たちはいるので$k$寸法。 答えは以下の剰余分数として出力する必要があります。$10^9 + 7$、つまり効率的に計算します。$\frac{p}{q} \bmod (10^9 + 7)$どこ$p/q$は最低条件での期待値です。 

入力制約は大きくなります。$n$まで可能です$10^9$、したがって、どのような解決策も線形に依存します$n$あるいは、考えられるすべてのキューブを反復処理することは不可能です。 次元$k$まで可能です$2 \times 10^5$これにより、二次シミュレーションまたは次元ごとのネストされたシミュレーションが除外されますが、線形または線形に近い依存関係は依然として許可されます。$k$。 

微妙なエッジケースが現れるのは、$n = 1$。 この場合、辺の長さが 1 の立方体が 1 つだけ存在するため、答えは常に 1 になります。$k$。 あらゆる組み合わせ公式は、この自明な状況に正しく縮退する必要があります。 もう 1 つの潜在的な落とし穴は、立方体の数え方の誤解です。立方体は辺の長さだけでなく位置によっても決定されるため、大きな立方体ほど配置が少なくなり、確率分布に大きな偏りが生じます。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての辺の長さを列挙します。$s$から$1$に$n$、何個数えますか$k$-側面の次元立方体$s$中に収まる$A$、ボリュームへの合計貢献度を累積します。 

辺の長さが固定の場合$s$、配置数は$(n - s + 1)^k$、各次元で開始座標を選択するためです。$0$に$n - s$。 このような立方体のそれぞれが体積に貢献します$s^k$、したがって、合計貢献度は次のようになります。$$s^k \cdot (n - s + 1)^k$$キューブの総数は次のとおりです。$$\sum_{s=1}^{n} (n - s + 1)^k$$したがって、ブルートフォースは次のように計算します。$$\frac{\sum_{s=1}^{n} s^k (n - s + 1)^k}{\sum_{s=1}^{n} (n - s + 1)^k}$$これは数学的には正しいですが、次まで繰り返すことになります。$10^9$不可能です。 たとえ$k$範囲は小さかった$n$直接の列挙が不可能になります。 

重要な洞察は、依存関係が次のように表現されるように表現を変換することです。$n$列挙的ではなく代数的になります。 構造は対称です。各立方体は各次元で独立して決定されるため、辺の長さの分布の観点から考える代わりに、期待値を独立した 1 次元の寄与の積として再解釈します。 

各次元で、立方体を選択することは、2 つの整数を選択することに相当します。$l_i \le r_i$で$[0, n]$、辺の長さは$r_i - l_i$。 次元を超えて、これらの選択肢は独立しており、同一です。 これにより、製品の期待値が単一の 1D 期待値の累乗に換算されます。$$\mathbb{E}[\text{volume}] = \mathbb{E}[(\text{side length})^k] = (\mathbb{E}[\text{side length}])^k$$したがって、問題全体は、ランダムに選択されたセグメントの予想される長さを計算することに帰着します。$[0, n]$、それをべき乗に上げます$k$。 

1 次元の場合、長さのセグメントの数$d$は$n - d + 1$、 それで：$$\mathbb{E}[d] = \frac{\sum_{d=1}^{n} d(n - d + 1)}{\sum_{d=1}^{n} (n - d + 1)}$$分子と分母は両方とも閉形式の多項式和になり、次の式に簡略化できます。$n$、$n^2$、 そして$n^3$。 これにより、反復への依存がなくなり、$O(1)$基本期待値の計算と、その後のべき乗のための高速累乗$k$。

 ## アルゴリズムのチュートリアル

 ### 1. セグメントエンドポイントを介してキューブを再解釈する

 それぞれ$k$-次元立方体は、各次元で独立してペアを選択することによって決定されます。$(l_i, r_i)$と$0 \le l_i < r_i \le n$。 辺の長さは、$r_i - l_i$。 これにより、幾何学的オブジェクトが独立した 1D 選択肢に変換されます。 

これが役立つ理由は、ボリュームが次元間で同一の確率変数の積になるためです。 

### 2. 製品の期待値を期待値で乗算します。 

各次元は独立して同一にサンプリングされるため、各次元の辺の長さは同じ分布になります。 ハイパーボリュームは次の製品です。$k$確率変数は同一であるため、次のようになります。$$\mathbb{E}[\prod_{i=1}^k X_i] = (\mathbb{E}[X])^k$$これは有効です。$X_i$は独立しており、同一に分散されています。 

### 3. 予想されるセグメント長を 1 次元で計算します。 

1 次元で、固定長の場合$d$、 がある$n - d + 1$有効なセグメント。 それで：$$\mathbb{E}[X] = \frac{\sum_{d=1}^n d(n - d + 1)}{\sum_{d=1}^n (n - d + 1)}$$分母はセグメントの総数です。$$\sum_{d=1}^n (n - d + 1) = \frac{n(n+1)}{2}$$分子は次のように展開されます。$$\sum d(n+1) - \sum d^2$$これにより、以下の使用が簡素化されます。$$\sum d = \frac{n(n+1)}{2}, \quad \sum d^2 = \frac{n(n+1)(2n+1)}{6}$$これにより、次の閉形式の有理関数が得られます。$n$。 

### 4. 剰余分数に変換する

 分子と分母のモジュロを計算します$10^9+7$、分子に分母の逆モジュラーを乗算します。 

### 5.べき乗する$k$最終的な期待は、$(\mathbb{E}[X])^k$。 高速累乗を使用します。 

### なぜ効果があるのか

 変換全体は、次元間の独立性とセグメント選択の均一な構造に基づいています。 すべての立方体は独立した 1D セグメントのタプルに一意に対応するため、確率空間はきれいに因数分解されます。 これにより、重み付け情報を失うことなく、期待値が単一の基本期待値のべき乗に分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, k = map(int, input().split())

    n %= MOD

    # sums
    # S1 = sum d
    S1 = n * (n + 1) % MOD * modinv(2) % MOD
    # S2 = sum d^2
    S2 = n * (n + 1) % MOD * (2 * n + 1) % MOD * modinv(6) % MOD

    # numerator = sum d(n - d + 1) = (n+1)S1 - S2
    num = ((n + 1) % MOD * S1 - S2) % MOD

    # denominator = sum (n - d + 1) = n(n+1)/2
    den = S1

    # expected 1D length
    inv_den = modinv(den)
    exp1 = num * inv_den % MOD

    # final answer = exp1^k
    print(pow(exp1, k, MOD))

if __name__ == "__main__":
    solve()
```コードはまず、閉じた形式の合計を使用して、1 次元で予想される辺の長さを導出します。 分母は等差級数の和を再利用し、分子は線形和と二次和を組み合わせます。 逆モジュラーは、モジュラスの下で除算をきれいに処理します。 最後に、べき乗により次元間の独立性が適用されます。 

微妙な実装の詳細は、$S1$これにより、2 番目の同一の式の再計算が回避されます。 値を正のモジュロに保つために減算には注意が必要です$10^9+7$。

 ## 特殊なケース

 のために$n = 1$、両方の理由により、アルゴリズムは正しく減少します。$S1$そして$S2$1 に単純化すると分子と分母が等しくなり、次のようになります。$E[X] = 1$。 任意の累乗を上げる$k$は結果を 1 に保ち、可能な立方体は 1 つだけであるという事実と一致します。
