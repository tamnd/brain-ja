 ## 解決策
 ## 問題の理解

 無向接続グラフが与えられます。$N$頂点と$M$エッジ。 各頂点は観光名所を表し、エッジは両方向に移動できる通りを表します。 このグラフでは、2 つのアトラクション間の距離が通常の最短経路長として定義されています。 

有効な観光サーキットは、少なくとも 3 つの長さの個別の頂点のシーケンスによって記述される自転車のようなルートであり、シーケンス内の連続する頂点が道路によって接続され、最後の頂点も最初の頂点に接続されます。 シーケンス内のすべての頂点は、その回路内に 1 回だけ出現する必要があります。 

目標は、すべての頂点を最小限の数の回路に分割し、各頂点が 1 つの回路にのみ属するようにすることです。 この最小数の回路を回路自体と一緒に出力するか、または$-1$それが不可能な場合。 

制約$N \le 10^5$そして$M \le 10^6$サイクルを列挙したり頂点のサブセットをテストしようとするアプローチはすべて除外されます。 どのソリューションも、グラフのサイズが線形または線形に近いものでなければなりません。 

重要な問題は、サイクルがグラフ構造自体に存在しなければならないことです。 次数 1 の頂点は、単純なサイクル上に存在できないため、すぐに問題が発生します。 たとえば、4 つのノードのチェーンのようなツリーでは、サイクルがまったく存在しないため、有効なパーティションは存在せず、答えは次のようになります。$-1$。 対照的に、4 つのノード上の完全なグラフでは、すべてのペアが接続されているため、すべての頂点を含む 1 つのサイクルが可能になります。 

グラフが接続されて多くのエッジがあるにもかかわらず、次数 1 の頂点またはブリッジが含まれている場合、微妙なエッジ ケースが発生します。 たとえ距離が所定の 4 点条件を満たしていても、そのようなグラフは有効な回路カバーをサポートできません。 

## アプローチ

 単純なアプローチでは、グラフ内のすべての単純なサイクルを明示的に構築し、これらのサイクルへの頂点の分割を選択しようとします。 密なグラフには指数関数的に多くの単純なサイクルが含まれる可能性があるため、すべてのサイクルを列挙しても、最悪の場合は指数関数的になります。 その後、最小のカバーを選択することがサイクルにわたるセット分割の問題になりますが、これもこの規模では対処が困難です。 

重要な観察は、ステートメントで指定されたメトリック条件が非常に制限的であるということです。 4 点不等式は、ツリー メトリクスの古典的な特徴付けです。 ただし、グラフは重み付けされておらず、メトリックは任意の重み付けされたツリー埋め込みではなく、単純なグラフ内の最短パスから取得されます。 

この条件下では、グラフの構造が崩壊します。最短経路距離が一貫して動作する唯一の方法は、すべての頂点をカバーするサイクルに必要な接続性の観点から、グラフが完全なグラフのように動作することです。 エッジが欠落していると、メトリック条件によって暗示される構造を尊重しながら、有効なサイクル カバーに同時に配置できない頂点が作成されます。 

これにより、問題は構造チェックに帰着します。グラフが完全である場合 (この場合、すべての頂点にわたって単一のハミルトニアン サイクルを形成できます)、または完全ではない場合 (この場合、一部の頂点は有効な回路分割に含めることができず、答えは不可能です) のどちらかです。 

有効な場合の答えの構築は簡単です。すべての頂点を任意の順序で含む単一サイクルを出力します。

 ## アルゴリズムのチュートリアル

 1. グラフを読み取り、すべてのエッジを処理しながらすべての頂点の次数を計算します。 これは、頂点のすべてのペアが接続されているかどうかを検出する直接的な方法を提供します。 
2. すべての頂点に次数があることを確認して、グラフが完全であるかどうかを確認します。$N-1$そしてエッジの数が正確に$N(N-1)/2$。 これが必要なのは、エッジが欠落していると、すべての頂点を含む 1 つのサイクルを構築できなくなるためです。 
3. グラフが完成していない場合は、出力$-1$。 その理由は、隣接関係が欠落していると、問題の構造によって暗示される制約の下で、少なくとも 1 つの頂点がフル サイクル カバー内で使用できなくなるためです。 
4. グラフが完成したら、すべての頂点を任意の順序 (たとえば 1 から 1 まで) にリストして単一の回路を構築します。$N$、最初の頂点に戻ります。 
5. 出力$K = 1$その後に構築されたサイクルが続き、シーケンスの長さが少なくとも 3 であることが保証されます。$N \ge 1$ただし、有効なサイクルには次のことが必要です$N \ge 3$。 もし$N < 3$、答えは自明の理不可能です。 

### なぜ効果があるのか

 コア制約により、グラフの最短パス ジオメトリが非常に厳格に動作するようになります。 エッジが欠落していると、その最短経路距離がすべてのノードをカバーする素のサイクル内に一貫して配置されることと一致しない頂点が生じます。 結果として、唯一の実現可能な構成は、すべての頂点のペアが直接接続されている構成であり、これにより、すべての頂点をカバーする単一のハミルトニアン サイクルが可能になります。 その場合、複数の回路に分割する必要はなく、ソリューションのサイズを改善することはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    
    deg = [0] * (n + 1)
    edges = set()

    for _ in range(m):
        a, b = map(int, input().split())
        if a > b:
            a, b = b, a
        edges.add((a, b))
        deg[a] += 1
        deg[b] += 1

    if n < 3:
        print(-1)
        return

    if m != n * (n - 1) // 2:
        print(-1)
        return

    for i in range(1, n + 1):
        if deg[i] != n - 1:
            print(-1)
            return

    print(1)
    print(n, *range(1, n + 1))

if __name__ == "__main__":
    main()
```この実装では、最初にすべてのエッジを読み取り、次数を追跡します。 決定的なチェックはエッジ数と均一次数条件であり、これらはすべてのペアを明示的に検証する必要なく完全性を証明します。 いずれかの条件が失敗した場合、グラフはすべての頂点をカバーする完全なサイクルをサポートできないため、プログラムはすぐに戻ります。$-1$。 

グラフが完成すると、構築された回路は頂点の自然な順序に過ぎません。 すべての頂点のペアが接続されているため、シーケンス内のすべての連続するペアが有効になり、最初の頂点に戻る最後のエッジも存在します。

 ## 特殊なケース

 少なくとも 3 つ以上の長さのサイクルが存在できないため、2 ノード グラフはすぐに失敗します。 アルゴリズムはこれを次の方法で捕捉します。$N < 3$構造検証の前に確認してください。 

ツリーなどの疎に接続されたグラフでは、葉の次数が常に 1 であるため、次数条件は失敗します。完全性チェックでは、サイクルを検索する必要なくこれを検出します。 

ほぼ完成しているが 1 つのエッジが欠落しているグラフでは、エッジ数のチェックはすでに失敗しています。 度が明示的にチェックされていない場合でも、次の間の不一致は$M$そして$N(N-1)/2$不可能性を保証するため、誤ったサイクルが生成されることはありません。
