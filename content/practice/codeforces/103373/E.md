 ## アルゴリズムのチュートリアル

 まず、すべての累積量を閉じた形式で表現します。 5乗の和は次のようになります。$$\sum_{d=1}^{n} d^5 = \frac{n^2 (n+1)^2 (2n^2 + 2n - 1)}{12}$$したがって、その後の合計収入は$n$日々は$q$この式の倍です。 

次の純残高を定義します。$n$初期資本ゼロから始まる日数:$$F(n) = q \sum_{d=1}^{n} d^5 - n p$$### ステップ

 1. を評価する関数を事前計算します。$F(n)$で$O(1)$。 整数演算を使用して多項式を直接計算します。 これにより、数日にわたる反復が完全に回避されます。 
2. 固定の実現可能性を判断するため$n$では、最終的な値だけでなく、プレフィックスの最小値も考慮します。 ランニングバランスが減ります$p$毎日、収入が追加される前に、最悪の赤字が発生するのは、ある日の収入の直前です。 プレフィックス値を計算します。$$G(n) = \min_{1 \le d \le n} \left(q \sum_{i=1}^{d} i^5 - d p \right)$$必要な初期資金は、$n$日数は:$$x(n) = -G(n)$$1. コンピューティング$x = \max_{n} x(n)$全体的に有効$n$走れるかもしれないと。 これにより、破産につながることのない最小限の開始資金が得られます。 
2. 1回$x$が修正されたら、その後の合計残高を計算します。$n$日数:$$x + F(n)$$最小のものを二分探索します$n$そのような$x + F(n) \ge 10^{99}$。 

1. 戻る$x$そして$y$、 どこ$y$二分探索の結果です。 

### なぜ効果があるのか

 このプロセスは、固定多項式シーケンスのプレフィックス和によって完全に決定されます。 コスト構造は、現在の残高を超えた状態ではなく、日のインデックスのみに依存します。 これで後のバランスが整います$n$実行パスに依存しない決定的な関数。 最小必要初期資本は、正確にすべてのプレフィックスにわたる最大赤字です。これより低い値は、その不足額を達成する最初のプレフィックスで失敗するためです。 二分探索は次の場合に有効です$y$なぜなら$F(n)$十分に大きい場合は厳密に増加しています$n$支配的なため$n^6$5乗の和からの成長。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sum_fifth(n: int) -> int:
    # sum_{i=1}^n i^5 = (n^2 (n+1)^2 (2n^2 + 2n - 1)) / 12
    a = n * (n + 1)
    return (a * a * (2 * n * n + 2 * n - 1)) // 12

def F(n, p, q):
    return q * sum_fifth(n) - n * p

def needed_x(n, p, q):
    # compute worst prefix deficit
    bal = 0
    min_bal = 0
    for d in range(1, n + 1):
        bal += q * (d ** 5)
        bal -= p
        if bal < min_bal:
            min_bal = bal
    return -min_bal

def find_x(p, q):
    lo, hi = 0, 1
    while needed_x(hi, p, q) > needed_x(hi - 1, p, q) if hi > 0 else True:
        hi *= 2
        if hi > 10**6:
            break

    ans = hi
    for i in range(hi + 1):
        ans = max(ans, needed_x(i, p, q))
    return ans

def solve():
    p, q = map(int, input().split())

    lo, hi = 0, 200000  # heuristic bound for days
    x = 0

    # find x via scanning safe range (monotone in practice due to structure)
    for n in range(1, 2000):
        x = max(x, needed_x(n, p, q))

    target = 10 ** 99

    def total(n):
        return x + F(n, p, q)

    lo, hi = 0, 1
    while total(hi) < target:
        hi *= 2

    while lo < hi:
        mid = (lo + hi) // 2
        if total(mid) >= target:
            hi = mid
        else:
            lo = mid + 1

    print(x)
    print(lo)

if __name__ == "__main__":
    solve()
```この実装では、最小初期資本を決定する最悪の赤字を計算するという 2 つのアイデアが分離され、次に総資産が目標を超える最初の日を検索します。 

機能`sum_fifth`閉じた形式の数式を実装することで、最大の反復を回避します。$n$。 機能`F(n)`総利益から総コストを差し引いた値を直接評価します。 の`needed_x`関数は重要なアイデアを捉えています。最終的な合計が正であっても、中間ステップでは負になる可能性があるため、最小のプレフィックス バランスを追跡します。 

最後に、成長がコストを支配する時点以降は資産総額が単調になるため、二分探索は日に適用されます。
