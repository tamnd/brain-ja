 ## 解決策
 ## 問題の理解

 色付きのタイルが 2 行あり、各行には同じ数の列があります。 各タイルは、赤 (R)、緑 (G)、または青 (B) にすることができます。 この質問は、2 種類の色覚のみを使用して、各列で両方のタイルが同じ色になるようにタイルの色を変更できるかどうかを尋ねます。 最初のタイプはすべての色を区別できますが、2 番目のタイプは赤と緑を同一のものとして認識しますが、それでも青を区別します。 赤緑色覚異常の人が各列を単色に見えるかどうかを判断するように求められます。 

入力は、列の数と、それに続く上部と下部の行の色を表す 2 つの文字列で構成されます。 出力は、2 つの行がすべての列の赤緑色盲下で区別できない場合は「YES」、そうでない場合は「NO」のいずれかです。 

キーの制約は小さいです: 列の数`n`これは、高度に最適化されたデータ構造や高速 I/O について心配する必要がない一方で、O(n) または O(n log n) のソリューションが完全に許容されることを意味します。 エッジ ケースには、両方のタイルがすでに同じ色である列、一方のタイルが赤でもう一方のタイルが緑である列、および青の列が含まれます。 

明白ではないエッジケースには、通常の視覚では異なる色の列が含まれますが、色盲の視覚では同じに認識されます。 たとえば、次のような列があります。`R`上と`G`たとえ 2 つのタイルが実際には異なっていたとしても、下のタイルは赤緑色盲の人にとっては単色であると考えるべきです。 単純に文字を文字通り比較するだけのアプローチでは、誤って「NO」が出力されてしまいます。 単一列の場合も正しく処理する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、リテラル等価性を使用して各列を 1 文字ずつ比較します。 これは正常な視覚では機能しますが、赤緑色盲では機能しません。 たとえば、次の列には「NO」が出力されます。`R`そして`G`たとえ、色盲の観察者にはこれらが同じように認識されるとしてもです。 最悪の場合、このアプローチは O(n) 操作を実行します。これは n ≤ 100 の場合には十分高速ですが、色の認識ルールを無視するため、間違った答えが得られます。 

最適なアプローチでは、赤緑色覚異常を考慮して比較が変更されます。 知覚される色をマッピングするヘルパー関数を定義します。赤と緑は両方とも同じシンボルにマッピングされます (たとえば、`X`)、青色は鮮明なままです。 次に、各列を反復処理して、マップされた色が上部と下部の行で一致するかどうかを確認します。 これにより、O(n) 時間の複雑さが維持されますが、問題の色覚ルールに従って正しい答えが生成されます。 

この単純化を可能にする観察結果は、考えられるすべての再色付けを考慮する必要がないということです。 各列で知覚される色を直接比較するだけで済みます。 知覚される色がすべての列で一致すると、答えは「YES」になります。 それ以外の場合は「いいえ」です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 色覚異常の知覚には不正確 |
 | 最適 | O(n) | O(n) | 正しくて十分に速い |

 ## アルゴリズムのチュートリアル

 1. 列数を読み取り、`n`。 これにより行の長さが決まります。 
2. 上部と下部の行を表す 2 つの文字列を読み取ります。 
3. ヘルパー関数を定義する`perceived(c)`それは戻ってきます`'X'`色が赤か緑の場合、`'B'`色が青の場合。 これは、赤緑色盲の知覚をモデル化します。 
4. 0 から n-1 までの各列インデックスを繰り返します。 
5. 各列に、`perceived`上部と下部のタイルに関数を適用し、結果を比較します。 
6. 知覚される色が異なる列がある場合は、直ちに「NO」を出力して終了します。 
7. すべての列が一致する場合は、「YES」を出力します。 

機能する理由: 各ステップで、アルゴリズムは赤と緑の色覚異常下でのタイルの認識をチェックすることを保証します。 赤と緑を同じシンボルにマッピングすると、赤と緑のタイルのみが含まれる列はすべて単色として扱われます。 青は明確なままであるため、青のタイルと赤または緑のタイルを持つ列は不一致として検出されます。 すべての列を一度だけチェックするため、不一致を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    top = input().strip()
    bottom = input().strip()

    def perceived(c):
        if c in 'RG':
            return 'X'
        return c

    for i in range(n):
        if perceived(top[i]) != perceived(bottom[i]):
            print("NO")
            return
    print("YES")

if __name__ == "__main__":
    main()
```解決策は、列の数と 2 つの色の文字列を読み取ることから始まります。 の`perceived`関数は、赤と緑を単一の代表的な文字に正規化します。 ループは各列を反復して知覚される色を比較し、不一致が発生した場合はすぐに「NO」を返します。 不一致が見つからない場合は、「YES」が出力されます。 入力から改行文字を取り除くように注意が払われます。これは、競技プログラミングで使用する場合に一般的です。`sys.stdin.readline`。
