 ## 解決策
 # 問題の理解

 この問題は、寸法のある長方形の保管室を説明します。`X × Y × Z`。 4 つの壁は壁紙で覆う必要がありますが、反対側の壁には常に同じ種類の壁紙を使用する必要があります。 壁紙は2種類ご用意しております。 最初のタイプには、`S1`利用可能な平方メートルと費用`C1`2 番目のタイプは 1 平方メートルあたり`S2`利用可能な平方メートルと費用`C2`平方メートルあたり。 それなりのサイズのドア`A × B`ちょうど 1 つの壁に配置することができ、ドア部分には壁紙が必要ありません。 課題は、壁を覆うことができるかどうかを判断し、カバーできる場合は最小限のコストを見つけることです。 

寸法は以下に制限されています`10000`、したがって、面積計算はおよそに到達できます。`10^8`。 壁紙の金額と価格は、`10^8`つまり、最終的なコストはおよそになる可能性があります`10^16`。 解決策では、固定サイズの整数を使用する言語での整数オーバーフローを回避する必要がありますが、Python はこれらの値を自然に処理します。 部屋は 1 つだけで、壁紙の選択肢は 2 つだけであるため、線形または一定時間のソリューションが期待されます。 利用可能な在庫に達するまで可能な限り壁紙の割り当てを試みるアプローチは、在庫のサイズが最大であるため、遅すぎます。`10^8`。 

主なエッジケースはジオメトリに由来します。 ドアがどの壁にも適合しない場合があります。 例えば：```
5 5 4
100 1 100 1
2 5
```出力は次のとおりです。```
-1
```ドアの高さが部屋の高さより大きいため、配置できません。 不注意な解決策では、ドアを物理的に配置できない場合でも、壁の総面積からドアの面積を差し引いて受け入れるだけになる可能性があります。 

もう 1 つの注意が必要なケースは、壁紙の総面積は十分であるが、反対側の壁に関する要件により配布が不可能になる場合です。```
10 10 10
150 5 150 5
1 2
```出力は次のとおりです。```
-1
```向かい合う壁の各ペアには面積があります`200`したがって、1 つのペアに使用される壁紙の種類は両方の壁に正確に十分な量を提供する必要があります。 どちらのタイプも1足分の在庫が無く、合計金額が`300`壁紙を任意に分割できないため、役に立ちません。 

# アプローチ

 簡単なアプローチは、可能な限りあらゆる方法を試して、どの反対側の壁のペアに最初の壁紙タイプを割り当てるかを選択することです。 ドアの位置を選択すると、残りの壁は自然に 2 つのペアに分割されます。 ブルートフォース ソリューションでは、考えられる 3 つのドアの向きをすべてチェックし、それぞれについて 2 つの壁のペアに対する壁紙の種類の両方の割り当てを試行できます。 これが機能するのは、構造上の選択肢がわずかしかないためです。 

問題は方向の数ではなく、壁の面積を慎重に考慮する必要があることです。 部屋の寸法は直接計算するには十分小さいですが、実装が悪いと、可能な量の壁紙の使用量を試行したり、平方メートルにわたって反復したりする可能性があります。 までの在庫あり`10^8`、そのようなループは何億回もの反復を実行することになります。 

重要な観察は、反対側の壁の条件により、問題が 2 つの独立した壁グループのみに限定されるということです。 ドアの位置が固定されると、2 つの壁のペアの領域が固定されます。 意味のある決定は 2 つだけです。どのペアが壁紙タイプ 1 を受け取り、どのペアが壁紙タイプ 2 を受け取るかです。 選択した壁ペアの平方メートルごとに同じタイプを使用する必要があるため、数量を検索する必要はありません。 

考えられるドアの配置ごとに、必要な 2 つの壁紙の量を計算します。 次に、両方の割り当てを確認します。 割り当てが利用可能な在庫に適合する場合、その価格を計算し、最小値を維持します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | ストック上で反復する場合は O(S1 + S2) またはそれ以上になります。 お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 # アルゴリズムのチュートリアル

 1. 部屋の寸法、壁紙情報、ドアの寸法を確認します。 面積とコストが大きくなる可能性があるため、64 ビット スタイルの演算を使用してください。 
2. 適切なサイズの壁にドアを設置することを検討してください。`X × Z`。 ドアは次の場合に適合します`A <= X`そして`B <= Z`、またはドアが回転している場合、`A <= Z`そして`B <= X`。 適合する場合は、その壁ペアの計算からドアの面積を差し引きます。 ドアを含む 2 つの向かい合う壁が 1 つのグループを形成し、壁紙の総必要量がドアの面積分だけ減ります。 
3. 有効なドアの配置ごとに、2 つの反対側の壁グループの必要な面積を計算します。 ドアが上にある場合は、`X × Z`壁、最初のグループが必要とするもの`2 * X * Z - A * B`壁紙と 2 番目のグループのニーズ`2 * Y * Z`。 同じ考え方が他の壁の向きにも当てはまります。 
4. 壁紙タイプ 1 を最初のグループに割り当て、壁紙タイプ 2 を 2 番目のグループに割り当ててみます。 両方の必要な領域が在庫の範囲内にあることを確認し、合計コストを計算します。 
5. 逆の割り当ても試してください。 これは、安価な壁紙には十分な在庫がない可能性があるため、より高価なタイプは別の壁のペアをカバーする必要がある可能性があるため重要です。 
6. すべての有効な割り当ての中で、最小コストを出力します。 割り当てが機能しない場合は、出力します`-1`。 

アルゴリズムの背後にある不変条件は、すべての可能な最終的な配置が、チェックされたケースの 1 つによって正確に表現されるということです。 ドアは 3 つの壁の方向のうち 1 つだけを占有することができ、その方向を選択した後、2 つの壁のペアにそれぞれ 1 つの壁紙タイプを適用する必要があります。 これらの選択肢のすべての組み合わせが評価されるため、有効な配置が欠落することはありません。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    X, Y, Z = map(int, input().split())
    S1, C1, S2, C2 = map(int, input().split())
    A, B = map(int, input().split())

    ans = float('inf')

    def try_case(pair1, pair2, door_area):
        nonlocal ans

        need1 = pair1 - door_area
        need2 = pair2

        if need1 < 0:
            return

        if need1 <= S1 and need2 <= S2:
            ans = min(ans, need1 * C1 + need2 * C2)

        if need1 <= S2 and need2 <= S1:
            ans = min(ans, need1 * C2 + need2 * C1)

    door_area = A * B

    if (A <= X and B <= Z) or (B <= X and A <= Z):
        try_case(2 * X * Z, 2 * Y * Z, door_area)

    if (A <= Y and B <= Z) or (B <= Y and A <= Z):
        try_case(2 * Y * Z, 2 * X * Z, door_area)

    if ans == float('inf'):
        print(-1)
    else:
        print(ans)

if __name__ == "__main__":
    solve()
```機能`try_case`は、可能なドアの方向の 1 つを表します。 最初の壁のペアはドアを含む壁ペアであるため、ドアの面積はそのグループからのみ減算されます。 2 番目の壁ペアはそのままです。 

2 つの割り当ては明示的にチェックされます。 最初のチェックでは、壁紙のタイプ 1 が最初のペアに、タイプ 2 が 2 番目のペアに与えられます。 2 番目のチェックではそれらが交換されます。 向かい合う壁が一致する必要があるため、可能な選択肢はこれら 2 つだけです。 

すべての乗算は Python 整数を使用して直接行われるため、次のような大きな値は`area * cost`オーバーフローしないでください。 ドアの取り付け条件は両方の向きで記載されているため、ドアを回転不可として扱うというよくある間違いを防ぐことができます。

# テストケース```python
import sys, io

def solve_case(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    X, Y, Z = map(int, input().split())
    S1, C1, S2, C2 = map(int, input().split())
    A, B = map(int, input().split())

    ans = float('inf')

    def check(a, b, d):
        nonlocal ans
        x = a - d
        y = b
        if x < 0:
            return
        if x <= S1 and y <= S2:
            ans = min(ans, x * C1 + y * C2)
        if x <= S2 and y <= S1:
            ans = min(ans, x * C2 + y * C1)

    door = A * B

    if (A <= X and B <= Z) or (B <= X and A <= Z):
        check(2 * X * Z, 2 * Y * Z, door)
    if (A <= Y and B <= Z) or (B <= Y and A <= Z):
        check(2 * Y * Z, 2 * X * Z, door)

    return str(-1 if ans == float('inf') else ans)
