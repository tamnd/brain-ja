 ## 解決策
 ## 問題の理解

 平面上の一連の点が与えられます。 すべての点がその内側または境界上に位置するように、非常に特殊な三角形を配置する必要があります。 The triangle is not arbitrary, it is constrained to be isosceles and aligned with the coordinate axes in the sense that its two equal sides lie along the axes. 課題は、すべての点をカバーしながら、「短い辺の長さ」ができるだけ小さい三角形を選択することです。 

Geometrically, this reduces the freedom we have: once the triangle is positioned, its shape is essentially fixed by one parameter, the length of its equal legs. この長さを増やすとカバーされる領域が拡大し、減らすと縮小します。 目標は、すべてのポイントがカバーされるようにこのパラメーターの最小値を見つけることです。 

The input size goes up to 100,000 points, so any solution that tries to simulate triangle placement for every candidate point or checks geometric coverage in a naive nested manner will not work. 二次スキャンには約$10^{10}$最悪の場合、1 秒の制限をはるかに超える操作が行われなくなります。 これは、答えがペアごとの交互作用ではなく、点セットの何らかの集合特性に依存する必要があることを直ちに示唆しています。 

エッジケースのほとんどは幾何学的縮退です。 すべての点が一致する場合、答えは最小になるはずです。 点が一方向にのみ極端に離れている場合、答えはその広がりによって支配されます。 よくある失敗は、凸包構造または三角形の向きの選択について推論しようとすることですが、これはここでは不必要であり、コア境界を改善することなく過度の複雑化につながります。 

## アプローチ

 この問題を考える強引な方法は、候補となる三角形のサイズを固定し、すべての点がその三角形の配置内に収まるかどうかを確認することです。 これには、多くの可能な配置を試すか、少なくとも異なるアンカー位置に関してカバレッジを検証する必要があります。 それぞれの検証には費用がかかります$O(n)$そして、多くの候補サイズや構成を探索すると、全体の複雑さは少なくとも 2 次以上になります。 問題は、三角形は制約されているものの、連続的に配置できるため、単純なシミュレーションでは検索空間が自然に離散化されないことです。 

重要な観察は、三角形の構造が軸に沿って整列しているということです。これは、その境界制約が効果的に x 座標と y 座標の独立した条件に減少することを意味します。 ジオメトリをグローバルに考える代わりに、極端な座標値によって決定される形状内の点の境界としてカバー条件を再解釈できます。 

三角形は辺の長さに応じて均一に拡大するため、制限要因は常に、三角形の向きによって引き起こされる座標系内で最も遠い点がどれだけ離れているかによって決まります。 ジオメトリを軸制約に変換した後、問題は、特定の線形結合で水平方向と垂直方向の両方の広がりを同時に支配する値を見つけることになります。 これにより、幾何学的最適化が、変換された座標の極値に対する単純な計算に分解されます。 

したがって、すべての配置を試す代わりに、点セットから少数のグローバル統計、特に座標から導出される特定の線形式の最小値と最大値を計算するだけで済みます。 答えは、これらの導出範囲の最大値になります。

 ## アルゴリズムのチュートリアル

 まず、幾何拘束を座標の端だけに依存するものに書き換えます。 各点は、三角形の辺がカバーされる領域に含まれるためにどのくらいの大きさでなければならないかに関する制約に影響します。 

1. すべての点を読み取り、最小および最大の X 座標と最小および最大の Y 座標を追跡します。 これらの値は、点セットの完全な水平方向および垂直方向の広がりをキャプチャします。 
2. 水平スパンを次のように計算します。$x_{\max} - x_{\min}$。 これは、ポイントが左から右にどれだけ離れているかを表します。 
3. 垂直スパンを次のように計算します。$y_{\max} - y_{\min}$。 これは上下の広がりを表します。 
4. 軸を揃えた二等辺三角形の形状に従って、これら 2 つの値を組み合わせます。 制限要因は純粋に水平または垂直ではなく、最悪の場合の方向であり、三角形が両方の極端な値を同時にカバーするのに十分な大きさにする必要があります。 
5. 必要な最大スパンを返します。これにより、両方の方向の制約が確実に満たされます。 

### なぜ効果があるのか

 重要な不変条件は、三角形の有効な配置が、x で分離された極端な点と y で分離された極端な点を同時に収容できる十分な大きさでなければならないということです。 三角形はその定義軸に沿って均一に拡大するため、賢明なシフトによってこれらの極端な条件によって課せられる要件を軽減することはできません。 すべての点セットには、必要な最小サイズを直交方向に独立して決定する点のペアがあり、最適な配置はこれらの制約を揃えるだけであり、縮小することはできません。 したがって、解は座標範囲のみの関数に正しく帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    xmin = ymin = 10**18
    xmax = ymax = -10**18

    for _ in range(n):
        x, y = map(int, input().split())
        xmin = min(xmin, x)
        xmax = max(xmax, x)
        ymin = min(ymin, y)
        ymax = max(ymax, y)

    print(max(xmax - xmin, ymax - ymin))

if __name__ == "__main__":
    solve()
```このソリューションは、入力の読み取り中にグローバル極値を追跡するだけです。 これにより、すべてのポイントの保存が回避され、線形時間が保証されます。 実現可能な三角形は、誘導座標系で設定された点の水平直径と垂直直径の両方にまたがる必要があるため、最終的な答えはこれらの極値から直接計算されます。 

微妙な点は初期化です。単一点入力を正しく処理するには、極値は十分に大きな正および負のセンチネルから開始する必要があります。 もう 1 つは、座標が次の範囲に達するため、すべての算術演算が整数の範囲内に収まることです。$10^9$、差異は内に残ります$10^9$規模。

 ## 特殊なケース

 ワンポイントの場合、例えば`(5, 5)`、極値は決して変化せず、両方のスパンがゼロであるため、アルゴリズムは正しく 0 を返します。三角形はポイント サイズのカバーに縮退する可能性があります。 

のような水平線の場合`(1,1), (5,1), (10,1)`、垂直方向のスパンは 0 ですが、水平方向のスパンは 9 です。アルゴリズムは水平方向の広がりのみが重要であることを正確に識別し、9 を生成します。 

みたいな縦線の場合`(2,1), (2,4), (2,8)`の場合、水平スパンは 0、垂直スパンは 7 なので、答えは 7 になります。これは、この方法が軸を対称的に扱っていることを確認します。 

完全な正方形の境界の場合、すべての極値がアクティブになり、結果は境界ボックスの最大辺の長さによって決まります。 これは、隠れた幾何学的構成によって、必要なサイズを極値が適用するサイズよりも小さくすることができないことを裏付けています。
