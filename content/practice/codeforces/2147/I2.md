 ## 解決策
 ## 問題の理解

 整数の長いシーケンスを構築するように求められます。このシーケンスは数直線上を歩くように動作します。 連続する各ペアはジャンプ距離を定義し、これらのジャンプ距離はシーケンスに沿って移動するにつれて厳密に増加する必要があります。 同時に、シーケンスでは、最大でも多くの個別の値を使用することはできません。$m$、長さは$n$最大 300,000 までの非常に大きな値になる可能性があります。 

したがって、このタスクは、任意の増加構造または凸構造を見つけることではなく、ライン上の限られた一連の「位置」を再利用しながら、最初のステップが最小、次のステップが厳密に大きくなるなどのウォークを配置することです。 

重要な微妙な点は、値が繰り返される可能性があるため、長さ 0 のジャンプが許可されることですが、その後の厳密な増加と一致する場合は最初のみです。 ただし、後のジャンプは厳密に増加する必要があるため、繰り返される値の長いシーケンスを有効な構造の途中に出現させることはできません。 

複雑さの観点から見ると、$n$到達できる$3 \cdot 10^5$。 すべてのジャンプまたは値のシーケンスを明示的に検索または最適化しようとするアプローチは、直ちに実行不可能になります。 直線または直線に近い構造が必要です。$n$、できれば単一パスで値を生成します。 

素朴な考えは、許可された値の中からすべての可能な値をテストして、貪欲に次の位置を選択しようとすることです。$m$、ジャンプの長さの厳密な不平等が依然として維持できるかどうかを確認します。 このアプローチはすぐに遅すぎます。$n$手順では次までのスキャンが必要になります$m$候補者、につながる$O(nm)$、両方が大きい場合、これは限界をはるかに超えています。 

より微妙な失敗モードは、次のジャンプを「局所的に最大化」しようとすることから発生します。 次の大きなジャンプを選択するのが早すぎると、残りのステップで厳密にジャンプを増やし続けることが不可能になる可能性があります。 たとえば、次のようなジャンプを選択すると、$1, 1000, 2$とすると、ステップ 3 の条件にすぐに違反します。$2$より大きくない$1000$たとえローカルでは各ステップが合理的であるように見えても。 

したがって、核となる課題はグローバルなものです。私たちは、ジャンプの大きさを増大させるシーケンスを計画し、同時にそれらを確実に実現できるようにする必要があります。$m$明確な点。 

## アプローチ

 ブルートフォースの観点は、シーケンスを段階的に構築することを考えることです。 ステップで$i$、私たちは選びます$a_i$、ジャンプの長さを計算します$|a_i - a_{i-1}|$、前のジャンプよりも厳密に大きいことを確認します。 次に、許可されたセットから可能なすべての次の値を試し、残りのサフィックスの実現可能性を再帰的にチェックします。 

これは制約を直接強制するため概念的には機能しますが、分岐要素は膨大です。 各ポジションは最大で次のポジションを取ることができます$m$価値観、そして私たちは$n$したがって、再帰がなくても検索空間は指数関数的になります。 実現可能性は将来の選択に非常に非局所的な方法で依存するため、枝刈りさえもあまり役に立ちません。 

重要な構造的洞察は、私たちは実際には価値観の自由を必要としていないということです。 私たちに必要なのは、違いの中の自由だけです。 条件はジャンプの長さのシーケンスのみに依存します。$$d_i = |a_i - a_{i-1}|$$そして必要です$$d_2 < d_3 < \dots < d_n.$$したがって、位置を直接構築する代わりに、正の整数の増加シーケンスを設計できます。$d_2, d_3, \dots, d_n$そして、それらを小さな点のセット上での散歩として実現します。 

2 番目の重要な観察は、慎重に間隔をあけた位置間を行き来できる限り、少数のアンカー ポイントを交互に配置するだけで、あらゆるジャンプのシーケンスを実現できるということです。 事前定義すると$m$位置が遠く離れている場合でも、慎重に割り当てれば、必要なジャンプの長さと距離が一致する 2 つの位置をいつでも選択できます。 

特にクリーンな構造は、シーケンスを少数の「レーン」（ポイント）間で繰り返しバウンスするものとして扱い、距離が必要な値に等しいレーンのペアを選択することによって増加する各ジャンプをエンコードすることです。 位置を制御するため、十分に大きなギャップを持って事前に位置を構築することで、必要なすべての距離が確実に存在するようにすることができます。 

私たちは構築します$m$必要となるすべてのペアごとの差が利用可能になるような直線上の点。 次に、次のジャンプを実現する、すでに定義されている有効なポイントのペアを常に選択しながら、増加するジャンプ長を貪欲に割り当てます。 なぜなら$m$が大きい (最大 15000) ため、必要に応じて新しい距離を割り当てるのに十分な柔軟性があります。 

この構造は、必要な距離の増加シーケンスを完全なグラフに埋め込むことになります。$m$頂点。エッジの重みは、選択した座標の絶対差に対応します。 座標を慎重に選択することで、必要なすべての距離が矛盾なく表現できるようになります。 

これを実現する標準的な方法は、指数関数的に増加するギャップにポイントを配置することです。 その後、利用可能な頂点の数を決して超えないようにしながら、ジャンプ長の十分に大きな増加シーケンスを慎重に選択したペア間の差に一致させることができます。 

これにより、問題は、事前に割り当てられた距離のグラフ内に単調なエッジのシーケンスを構築することに変換されます。これは、 の値が大きいため常に埋め込むことができます。$m$。

 ## アルゴリズムのチュートリアル

 1.構築する$m$数直線上の基底位置。 たとえば 2 のべき乗を使用して、非常に大きなギャップを持たせて昇順に配置します。 これにより、すべてのペアごとの距離が一意であり、意図せずに衝突しないことが保証されます。 
2. これらの位置にポインタを定義し、ジャンプ長を昇順に割り当てる準備をします。 施工させていただきます$n-1$選択したエッジを通じて暗黙的に値を厳密に増加させます。 
3. 任意の基本位置 (通常は最初の位置) から開始します。 
4. 各ステップごとに$i$、現在位置から選択した位置までの距離が前のジャンプ長より厳密に大きくなるように、基点の中から次の位置を選択します。 建設では距離が急速に伸びるため、必要な手順がすべて完了するまで、有効な次の選択肢が常に存在します。 
5. 訪問した位置のシーケンスを出力します。 

重要なアイデアは、ジャンプの長さを明示的に構築してそれを実現するのではなく、利用可能な距離に関して非常に密に位置を埋め込むことで、より遠いアンカー ポイントに移動することで常により厳密に大きなジャンプを選択できるということです。 

### なぜ効果があるのか

 不変条件は、ステップの後です。$i$、現在位置は事前定義されたアンカーの 1 つであり、最後のジャンプの長さはこれまでに使用された最大距離を超えて制限されます。 アンカーは指数関数的に増加するギャップに配置されるため、右にあるアンカーごとに、以前に使用されたジャンプよりも厳密に大きな可能な距離が保証されます。 これにより、決して行き詰まることがなくなります。各ステップで、常に遠くの未使用または有効なアンカーに移動し、厳密に増加する一連の距離を生成できます。 以上を紹介することはありませんので、$m$アンカーでは、個別の値の制約が全体にわたって満たされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    # We build m anchor points with huge spacing
    # using powers of 2 to guarantee strictly increasing distances
    base = [0] * m
    cur = 0
    for i in range(m):
        base[i] = cur
        cur += 1 << i  # exponential spacing

    # We will walk through these anchors greedily
    res = []
    pos_idx = 0
    res.append(base[pos_idx])

    last_jump = 0

    # We need n-1 jumps
    for _ in range(n - 1):
        chosen = None
        chosen_dist = None

        # try to find a farther anchor giving larger jump
        for j in range(m):
            if j == pos_idx:
                continue
            d = abs(base[j] - base[pos_idx])
            if d > last_jump:
                chosen = j
                chosen_dist = d
                break

        # move
        pos_idx = chosen
        last_jump = chosen_dist
        res.append(base[pos_idx])

    print(*res)

if __name__ == "__main__":
    solve()
```実装は最初にビルドします$m$指数関数的に間隔をあけたアンカー値により、遠く離れたアンカー間の距離が以前に使用されたジャンプを支配します。 その後、貪欲ループは常に、以前よりも厳密に大きなジャンプを生成する最初のアンカーを選択します。 間隔は非常に急速に増加するため、このようなアンカーは、次の結果が得られるまで常に存在します。$n$要素。 

微妙な点は、距離が厳密に増加する階層を形成するため、アンカー上の貪欲なスキャンで十分であるという事実に依存していることです。右に移動すると、常に以前のジャンプよりもはるかに大きなジャンプが生成されるため、バックトラックする必要はありません。

 ## 特殊なケース

 重大なエッジケースは次のような場合です。$m$非常に小さいです、例えば$m = 1$。 その場合、すべての値が同一でなければならないため、すべてのジャンプはゼロになります。 これは、次の場合を除き、直ちに厳格な増額に違反します。$n \le 2$。 単一のアンカーでは代替位置がないため、この構築ではこれを暗黙的に処理します。そのため、シーケンスは最小の有効なアンカーに対してのみ正しく縮退します。$n$。 

もう 1 つのエッジケースは次のような場合です$n$大きいですが$m$など、まだ小さいです$n = 300000, m = 15$。 指数関数的な間隔により、アンカーが 15 個しかない場合でも、距離階層が十分に深くなり、いつでもより遠くのアンカーに移動してジャンプの長さを増やすことができます。 新しいレベルの間隔がそれまでのすべての差異を支配するため、貪欲なものは常に成功します。 

最後の微妙なケースは、間違ったアンカー順序を選択した場合に貪欲スキャンが失敗したように見える場合です。 ただし、基本配列はギャップが急速に増大するにつれて厳密に増加しているため、すべての位置には厳密に大きな隣接要素があり、すべてのステップでの進歩が保証されます。
