入力により得られるのは、$m$3 つの整数の積として$x$、$y$、 そして$z$、それぞれ最大$10^6$。 テストケースの数は最大です$10^4$。 これは、すべての整数を反復する解が存在することを意味します。$1 \le a \le m$それは遅すぎるでしょう、なぜなら$m$それ自体は次のように大きくできます$10^{18}$。 したがって、ソリューションは、総当たりシーケンス シミュレーションではなく、数理論的プロパティを使用して機能する必要があります。 

明らかではないエッジケースには、次のような状況が含まれます。$m$プライムとコンポジットです。 たとえば、次の場合$m = 2$、奇数ごとに$a$は自明のことながら 2 四進法です。$1^n \equiv 1 \pmod 2$そして$a^1 \equiv 1 \pmod 2$のために$a$奇数ですが、偶数はそうではありません。 別の微妙なケースが発生する場合$m$シーケンスの素数モジュロべき乗の動作が素数モジュロとは異なるため、素因数が繰り返されています。

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

def factor_small(n):
    d = {}
    i = 2
    while i * i <= n:
        cnt = 0
        while n % i == 0:
            n //= i
            cnt += 1
        if cnt > 0:
            d[i] = cnt
        i += 1
    if n > 1:
        d[n] = 1
    return d

def density(m):
    factors = factor_small(m)
    numerator = 1
    denominator = 1
    for p, k in factors.items():
        if p == 2:
            if k == 1:
                num, den = 1, 1
            else:
                num, den = 1, 2
        else:
            num, den = 1, p
        numerator *= num
        denominator *= den
    return numerator * modinv(denominator) % MOD

t = int(input())
for _ in range(t):
    x, y, z = map(int, input().split())
    m = x * y * z
    print(density(m))
