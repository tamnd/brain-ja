 ## 解決策
 ## 問題の理解

 放物線ごとに、原点を通過し、放物線とまったく交差しない直線を選択するように求められます。 各直線はその傾きによって与えられます$k$、つまり、この行は$y=kx$。 各放物線は次のように与えられます。$y = ax^2 + bx + c$と$a>0$, なので上に開きます。 重要なのは、「交差しない」ということは、次のように解くと$ax^2 + bx + c = kx$、本当の解決策はないはずです。 同様に、二次方程式は$ax^2 + (b-k)x + c = 0$負の判別式がなければなりません。 

入力により複数のテスト ケースが提供されます。 各テスト ケースには最大で次のものを含めることができます。$10^5$線と放物線。 すべてのテスト ケースの合計は、$n$そして$m$は$10^5$。 各テスト ケースには多数の放物線と線が含まれる可能性があるため、$O(n \cdot m)$ブルートフォースアプローチは遅すぎます。 単一のテストケースであっても、$n=m=10^5$必要になるだろう$10^{10}$操作。 

エッジ ケースには、非常に急な放物線、または定数が非常に大きい放物線、傾きがゼロの線、同じ傾きが繰り返される線が含まれます。 すべての放物線のすべての線を単純にチェックすると、複数の放物線が線を共有する可能性があること、または放物線の頂点接線とまったく同じ傾きを持つ線が表示される可能性があるという事実を見逃してしまう可能性があります。 

## アプローチ

 ブルートフォースソリューションでは、各放物線を反復処理し、次に各直線を反復処理して、二次方程式が正しいかどうかを確認します。$ax^2 + (b-k)x + c = 0$本当のルーツがあります。 これは正しいですが、最悪の場合の時間計算量は次のとおりです。$O(n \cdot m)$、大まかに言うと$10^{10}$最大の入力に対する操作が必要になるため、実行不可能になります。 

最適なアプローチのための洞察は、二次式の判別式を分析することで得られます。 放物線の場合$y=ax^2 + bx + c$そして一行$y=kx$、判別式は$\Delta = (b-k)^2 - 4ac$。 もし$\Delta < 0$、線は放物線と交差しません。 必要なのは 1 行だけです$\Delta < 0$放物線あたり。 指定された直線の最小および最大の傾きを事前に計算すると、この範囲外の傾きを選択することで放物線を分離できるかどうかを確認できます。 放物線は上向きに開いているため、放物線の頂点の傾斜から遠く離れた傾斜を持つ線は、正しい側にあれば放物線と交差しないことが保証されます。 これにより、問題は、放物線の「禁止された」間隔がすべての線と重なっているかどうかを確認することになります。 テスト ケースごとに行を 1 回並べ替えることで、迅速なチェックが可能になります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m) | O(n + m) | 遅すぎる |
 | 最適 | O(n log n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての勾配を読み取る$k_i$テストケース内の行について。 昇順に並べ替えます。 ソートにより、最小および最大の傾きを効率的に見つけることができます。 
2. 各放物線について$y=ax^2 + bx + c$、頂点での傾きを計算します。$x_v = -b/(2a)$。 頂点により、接線である最も急な傾斜の線が得られます。 任意の行$y=kx$放物線との交差は間にある必要があります$k = b - 2\sqrt{ac}$そして$k = b + 2\sqrt{ac}$判別式不等式から導出された傾き$(b-k)^2 - 4ac \ge 0$。 
3. この間隔に対して並べ替えられた線の傾きを確認します。 線の傾きがある場合$k$未満$b - 2\sqrt{ac}$以上$b + 2\sqrt{ac}$、「YES」を出力すると、$k$。 それ以外の場合は「NO」を出力します。 ソートされたリストを使用すると、ソート後のこのチェックが放物線ごとに一定時間行われることが保証されます。 
4. テスト ケース内のすべての放物線に対してこの手順を繰り返します。 すべてのテスト ケースに対して繰り返します。 

これが機能する理由: 判別式は、線が放物線と交差するかどうかを正確に特徴づけます。 区間の外側の線の傾きを見つけることによって、$\Delta \ge 0$、私たちはそれを保証します$\Delta < 0$。 並べ替えにより、最小値または最大値の行を効率的に選択できるようになります。 アルゴリズムは禁止区間を明示的にチェックするため、交差する傾きを選択することはありません。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        lines = sorted(int(input()) for _ in range(n))
        min_line = lines[0]
        max_line = lines[-1]

        parabolas = [tuple(map(int, input().split())) for _ in range(m)]
        res = []

        for a, b, c in parabolas:
            sqrt_disc = 2 * math.isqrt(a * c) if a * c >= 0 else 0
            low = b - sqrt_disc
            high = b + sqrt_disc

            if min_line < low:
                res.append(f"YES\n{min_line}")
            elif max_line > high:
                res.append(f"YES\n{max_line}")
            else:
                res.append("NO")
        print("\n".join(res))

if __name__ == "__main__":
    solve()
```このソリューションは、すべての線の傾きを読み取り、並べ替えて、整数の平方根を使用して各放物線の判別区間を計算します。 利用可能なラインの両端のみをチェックし、正確性を保証します。 使用する`math.isqrt`誤った比較を引き起こす可能性のある浮動小数点の不正確さを回避します。
