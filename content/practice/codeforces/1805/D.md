 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、$n$頂点を指定し、一連のグラフを生成するよう求められます。$G_k$のために$k = 1$に$n$。 それぞれのグラフで$G_k$、頂点間にエッジが存在します$u$そして$v$間の距離が$u$そして$v$元のツリーには少なくとも$k$。 それぞれについて$k$、接続されているコンポーネントの数を数えなければなりません。$G_k$。 

入力により提供されるのは、$n-1$ツリーを定義するエッジ。 以来$n$まで可能です$10^5$、二次時間を使用する任意の解$n$はすぐに除外されます。 すべてのペアのペアごとの距離を明示的に計算するには、$O(n^2)$動作が遅すぎます。 したがって、おおよその範囲で機能するソリューションが必要です。$O(n \log n)$または$O(n)$。 

微妙なエッジケースが発生する場合$k$木の直径より大きいです。 その場合、2 つの頂点が接続されることはなく、各頂点が独自のコンポーネントを形成します。 たとえば、頂点が 5 つあるスター ツリーと、$k = 3$任意の 2 つの葉の間の最大距離は 2 であるため、5 つのコンポーネントが生成されます。ツリー構造を考慮しない単純なアルゴリズムでは、離れすぎている頂点を誤って接続してしまいます。 

別の特殊なケースが発生するのは、$k = 1$。 定義上、すべての頂点ペアは距離要件を満たしているため、$G_1$は完全に接続されており、ツリーの構造に関係なく、正確に 1 つのコンポーネントが生成されます。 

## アプローチ

 ブルートフォースアプローチは、$G_k$それぞれに対して明示的に$k$。 それぞれについて$k$場合は、頂点のすべてのペア間の距離を確認し、DFS または BFS を実行してコンポーネントをカウントします。 このアプローチは正しいですが、$n = 10^5$おおよそ必要です$n^2$ごとの距離チェック$k$、合計は$O(n^3)$操作。 これは不可能です。 

重要な洞察は、問題は本質的に木の直径とサブツリーの深さにあるということです。 接続されているコンポーネント$G_k$ツリー内の頂点の「深さ」と、コンポーネントを分割する頂点に到達することなく存在するパスの長さから推測できます。 より具体的には、任意の頂点でツリーをルート化し、各頂点についてそのサブツリー内の最長パスを計算できます。 サブツリーの深さが距離に達するのに十分でない場合$k$、それは別のコンポーネントを形成します$G_k$。 

最後の最適化では、ツリー上で動的プログラミングを使用します。 各頂点で、その下の最長 2 つのサブツリーの高さを追跡します。 これらの高さにより、それぞれの高さを決定することができます。$k$頂点がより大きなコンポーネントに参加するか、新しいコンポーネントを開始するか。 高さを効率的に組み合わせ、カウントをツリーの上に伝播することで、すべてのコンポーネントの数を計算できます。$k$で$O(n \log n)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n^2) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーのルートを任意に、たとえば頂点 1 に設定します。これは、サブツリーの計算を簡素化するための簿記上の選択です。 
2. ルートから DFS を実行します。 各頂点で、その最も深い 2 つの子サブツリーの高さを計算します。 これらの高さは、サブツリー内の最長距離に対応します。 
3. 各頂点のサブツリーの高さのマルチセットを維持します。 これにより、頂点を通過する最大のパスと、そのパスが少なくとも$k$長さ。 
4. 各頂点について、コンポーネントの数への寄与を上方に伝播します。 サブツリーの最大の高さに 1 を加えた値が以下の場合$k$、その頂点とそのサブツリーが新しいコンポーネントを形成します。 それ以外の場合、サブツリーはより大きなコンポーネントにマージされます。 
5. それぞれのコンポーネントの数を集計します。$k$独特の深さのスイープを使用します。 これにより、コンポーネントの数が変更された時点でのみカウントが更新されることが保証されます。 
6. すべてのコンポーネントについて計算されたコンポーネント数を出力します。$k = 1$に$n$。 のために$k$木の直径より大きい、生産量$n$各頂点が独自のコンポーネントになるためです。 

機能する理由: このアルゴリズムは、各頂点でそのサブツリー内で到達可能な最大深度がわかっているという不変条件を維持します。 この深さが少なくとも距離を維持するには不十分な場合$k$、サブツリーは新しいコンポーネントに分割されます。 これにより、距離制約を満たすすべてのパスが正しく接続され、距離に到達できない頂点がないことが保証されます。$k$が間違ってマージされています。 

## Python ソリューション```python
import sys
from collections import defaultdict, deque
input = sys.stdin.readline

n = int(input())
edges = defaultdict(list)
for _ in range(n-1):
    u, v = map(int, input().split())
    edges[u].append(v)
    edges[v].append(u)

# BFS to get heights from farthest node (tree diameter ends)
def bfs(start):
    dist = [-1]*(n+1)
    q = deque([start])
    dist[start] = 0
    while q:
        u = q.popleft()
        for v in edges[u]:
            if dist[v] == -1:
                dist[v] = dist[u]+1
                q.append(v)
    farthest = max(range(1,n+1), key=lambda x: dist[x])
    return farthest, dist

# first BFS to find one end of diameter
u, _ = bfs(1)
# second BFS to find other end and distances
v, dist_u = bfs(u)
_, dist_v = bfs(v)

diameter = max(dist_u)
