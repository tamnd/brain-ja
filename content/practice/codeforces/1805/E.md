 ## 解決策
 ## 問題の理解

 接続された非巡回グラフであるツリーが与えられます。`n`頂点。 各頂点には整数のラベルが付いています。 このタスクは、MAD (「最大倍数」) と呼ばれるパラメータを中心に展開します。これは、木の頂点で少なくとも 2 回発生する最大の整数として定義されます。 整数が繰り返されない場合、MAD はゼロです。 

ツリー内のすべてのエッジについて概念的に削除し、ツリーを 2 つの小さなツリーに分割します。 これら 2 つのツリーのそれぞれについて、MAD を個別に計算し、2 つの MAD 値の大きい方を取得します。 エッジ除去後のこの最大 MAD が、そのエッジに関連付けられた値になります。 これを入力で指定された順序ですべてのエッジに対して計算する必要があります。 

制約により許可されるのは、`n`100,000まで。 各エッジを個別に削除した後、サブツリーごとに MAD を再計算する単純なアプローチでは、最大で次のトラバースが必要になります。`n`それぞれの頂点`n-1`エッジに相当するため、およそ O(n²) 回の操作が必要になります。 これは n = 10⁵ には遅すぎるため、O(n log n) または O(n) に近いアプローチが必要です。 

明らかではないエッジ ケースには、すべての値が一意である (MAD が常に 0) ツリー、最も頻繁に使用される値がちょうど 2 回出現するツリー、繰り返される値が 1 つのサブツリーに大きく偏っているツリーなどがあります。 たとえば、値が含まれるサイズ 3 のツリーを考えてみましょう。`[1, 1, 2]`そしてエッジ`1-2`、`2-3`。 エッジの除去`1-2`サブツリーを生成します`[1]`そして`[1,2]`。 のMAD`[1,2]`1 はそのサブツリー内で繰り返されるため、1 になります。 ツリー全体のみを確認するか、周波数マップを慎重にマージしない不注意なアプローチは、MAD を誤って計算する可能性があります。 

## アプローチ

 ブルート フォース手法は簡単です。エッジごとにエッジを削除し、結果として得られる 2 つのツリーを走査し、値の頻度をカウントし、各サブツリーの MAD を計算します。 これは正しいですが、最悪の場合は O(n²) 回の操作が必要になります。 n=10⁵ の場合、これは約 10¹⁰ の操作となり、制限時間内に終了しません。 

重要な洞察は、問題を「サブツリー頻度管理」の 1 つとして扱うことで得られます。 各エッジは、ツリーをサブツリーとその補数に分割します。 DFS を使用して値の頻度を計算できます。 ツリー上の DSU と同様の手法 (小から大へのマージとも呼ばれる) を使用して、各サブツリーの頻度マップを維持します。 ノードにアクセスすると、その子の周波数マップがマージされ、常に小さいマップが大きいマップにマージされます。 これにより、挿入の総数は n² ではなく n log n に比例するようになります。 

サブツリーの周波数マップを取得したら、そのサブツリー内の MAD を効率的に計算できます。 補数 (エッジを削除した後のツリーの残りの部分) を処理するには、MAD がツリー全体の各値のカウントと合計カウントに依存するという事実を利用します。 値の合計数がわかっている場合、補数の MAD は、サブツリー内のその値の頻度を合計頻度から減算することによって導出されます。 これにより、ノードを何度も走査することなく、両方の部分の MAD を計算できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 (DFS + 小規模から大規模まで) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーと値を読むことから始めます。 ツリーの隣接リストを作成します。 ツリー内の各整数の合計数を計算します。 これにより、後で補数 MAD を高速に計算できるようになります。 
2. 任意のルート (ノード 1 など) から DFS を実行します。 各ノードについて、そのサブツリー内のすべての値の頻度マップを維持します。 マップでは、各値が出現する回数がカウントされます。 
3. 子の周波数マップを親にマージする場合は、常に小さいマップを大きいマップにマージします。 これにより、すべてのノード値がマップ間で O(log n) 回のみ移動され、合計作業量が O(n log n) に保たれることが保証されます。 
4. マージ中は、マージされたサブツリーの現在の MAD を維持します。 値が少なくとも 2 の頻度に達すると、それが新しい MAD になる可能性があります。 
5. サブツリーを処理すると、頻度マップにはそのサブツリー内のすべての値のカウントが含まれます。 子エッジごとに、子をルートとするサブツリーの MAD を計算します。 補数の MAD は、ツリー全体の合計頻度から各子の頻度を減算し、残りのカウント ≥ 2 の最大数を見つけることによって導出されます。 
6. 各エッジの答えは、子サブツリーの MAD と補部分の MAD の最大値です。 

機能する理由: 小から大へのマージにより、すべての値の頻度が各サブツリーで正しく考慮されることが保証されます。 値の合計頻度により、明示的に走査することなく補数を計算できます。 MAD 不変式 (頻度 ≥2 の最大数を追跡) により、各エッジの正確性が保証されます。 ツリーを再帰的に処理し、慎重にマージすることで、すべてのエッジを 1 回だけカバーし、結果として得られる両方のコンポーネントの正しい MAD を計算します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

sys.setrecursionlimit(1 << 20)

def solve():
    n = int(input())
    edges = []
    adj = [[] for _ in range(n)]
    
    for _ in range(n - 1):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, len(edges)))
        adj[v].append((u, len(edges)))
        edges.append((u, v))
    
    values = list(map(int, input().split()))
    
    total_count = defaultdict(int)
    for val in values:
        total_count[val] += 1
    
    ans = [0] * (n - 1)
    
    def dfs(u, parent):
        freq = defaultdict(int)
        freq[values[u]] = 1
        mad = 0
        for v, idx in adj[u]:
            if v == parent:
                continue
            child_freq, child_mad = dfs(v, u)
            if len(child_freq) > len(freq):
                freq, child_freq = child_freq, freq
            for k, cnt in child_freq.items():
                freq[k] += cnt
                if freq[k] >= 2:
                    mad = max(mad, k)
            # Compute MAD for edge u-v
            complement_mad = 0
            for k, total in total_count.items():
                remain = total - freq.get(k, 0)
                if remain >= 2:
                    complement_mad = max(complement_mad, k)
            ans[idx] = max(mad, complement_mad)
        if freq[values[u]] >= 2:
            mad = max(mad, values[u])
        return freq, mad
    
    dfs(0, -1)
    
    print('\n'.join(map(str, ans)))

solve()
```DFS は各サブツリーの頻度マップを構築し、小から大へのトリックを使用して子を親にマージします。 MAD はマージ時に更新されます。 補数 MAD を計算するには、合計ツリー数からサブツリー数を減算します。 エッジ応答は、入力順序を尊重するため、DFS 中に即座に記録されます。
