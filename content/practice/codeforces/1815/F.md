 ## 解決策
 ## 問題の理解

 次のような無向グラフが与えられます。$n$頂点と$3m$エッジ、組織化$m$三角形。 各三角形は 3 つの異なる頂点によって記述され、グラフのすべてのエッジがこれらの三角形の 1 つに正確に現れることが保証されます。 各頂点には、初期の非負の整数の重みがあります。 私たちのタスクは、各エッジに 1 ～ 4 の数値を割り当て、エッジの両方のエンドポイントをその数値だけ増やすことによってこれらの数値を「適用」することです。 すべてのエッジを処理した後、接続された頂点の各ペアは異なる重みを持つ必要があります。 エッジ値を適用する順序は重要ではありません。 

制約は、最大で次のものを持つことができることを意味します。$10^6$頂点と$4 \cdot 10^5$テスト ケースごとの三角形。すべてのテスト ケースの頂点と三角形の合計が次のように制限されます。$10^6$そして$4 \cdot 10^5$、 それぞれ。 これは、どのソリューションもエッジの数に対してほぼ直線的な時間で実行する必要があることを意味します。$O(n + m)$実現可能ですが、$O(n^2)$または、すべての頂点ペアを反復処理するものは遅すぎます。 

複数の三角形が頂点を共有する場合、明らかではないエッジ ケースが発生します。 たとえば、すべての頂点が最初に同じ重みを持っている場合、すべてのエッジに同じ増分を割り当てる単純なアプローチでは、隣接する 2 つの頂点が同じ値になる可能性があります。 もう 1 つの微妙な点は、いくつかの頂点が多くの三角形に参加し、他の頂点が少数の三角形に参加しているグラフの処理です。これは、慎重に割り当てないと、増分の不均衡により、接続された頂点が等しくなる可能性があるためです。 

## アプローチ

 ブルート フォース アプローチでは、各エッジに対して 1 ～ 4 の値の割り当てをすべて試し、結果の重みが隣接制約を満たしているかどうかを確認します。 これはすべての可能性を検討するため、原理的には正しいですが、実際には実行できません。 と$3m$エッジとそれぞれ 4 つの選択肢、構成の合計数は次のとおりです。$4^{3m}$、小さいものでも爆発します。$m$。 

重要な観察は、各三角形には正確に 3 つのエッジがあり、最終的に 3 つの頂点に個別のウェイトが設定されることを確認するだけでよいということです。 各エッジに 1 ～ 4 の整数を追加できるため、この小さな範囲を利用してエッジの増分を割り当て、三角形の周囲の合計によって 3 つの頂点が確実に区別されるようにすることができます。 具体的には、各三角形内で循環的に番号を割り当てることができます。 頂点を持つ三角形の場合$u,v,w$、エッジを割り当てることができます$(u,v)$、$(v,w)$、$(w,u)$価値観$1,2,3$ある順序で。 これにより、3 つの頂点の合計が異なることが保証され、1 から 4 までの数値を使用することで、許容される増分を決して超えないことが保証されます。 

このパターンは、各三角形が増分割り当てに関して独立しているため機能します。 三角形が頂点を共有している場合でも、三角形内の 2 つのエッジ間の最小差は 1 であるため、異なる三角形の割り当てによって生じた差異は等価性を生み出すことなく蓄積されます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、頂点の数を読み取ります。$n$そして三角形の数$m$、その後に初期頂点の重みのリストが続きます。 
3. 各三角形について、3 つの頂点を読み取ります。$a, b, c$。 各三角形は 3 つのエッジを定義します。$(a,b)$、$(b,c)$、 そして$(c,a)$。 
4. 三角形のエッジに増分 1、2、3 を順番に割り当てます。 この割り当てにより、それぞれの頂点に増分を追加した後、各頂点がエッジから異なる寄与を受け取るため、3 つの頂点が異なる重みを持つことが保証されます。 
5. 各三角形のすべてのエッジに割り当てられた増分を出力します。 

機能する理由: 各三角形内で、各頂点は 2 つのエッジの影響を受けます。 エッジに 1、2、および 3 を割り当てると、三角形の各頂点の増分の合計が明確になります。 頂点が複数の三角形に参加している場合でも、初期重みは負でない任意の整数にすることができ、増分は常に正であり、制限されています。 したがって、すべての三角形に対してこの循環割り当てに従った場合、接続された 2 つの頂点が等しくなることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        triangles = [tuple(map(int, input().split())) for _ in range(m)]
        result = []
        for tri in triangles:
            # Assign 1, 2, 3 to edges (a,b), (b,c), (c,a)
            result.append((1,2,3))
        for r in result:
            print(*r)

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`、三角形の頂点を保存し、エッジの固定循環割り当てを出力します。 各三角形のエッジは割り当てに関して独立しています。 選択`(1,2,3)`その三角形の頂点の個別の最終値を保証します。 増分は厳密に正であり、保証された差が生じるため、増分の割り当ては初期の重みには依存しません。
