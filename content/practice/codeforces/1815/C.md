 ## 解決策
 ## 問題の理解

 1 と 2 の間の一連の数字を構築するように求められます。$n$それは 2 つの重要なルールに従います。 まず、シーケンスには数値 1 が 1 つだけ含まれている必要があります。次に、指定されたペアごとに、$(a_i, b_i)$、任意の 2 つの出現$a_i$シーケンス内では少なくとも 1 つで区切る必要があります$b_i$。 目的は、シーケンスをできるだけ長くすることです。 無限に長くできる場合は、「INFINITE」と報告する必要があります。 それ以外の場合は、最大長のシーケンスを出力する必要があります。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、$n$、許可される最大数、および$m$制約ペア。 各ペアは間隔の制約を指定します。2 つ持つことはできません。$a_i$少なくとも 1 つはありません$b_i$彼らの間で。 課題は、最大 1500 の値と 5000 の制約がある場合、考えられるすべてのシーケンスを列挙しようとするとすぐに実行不可能になってしまうことです。 数値を 1 つずつ配置する総当り的なアプローチでは、シーケンスの長さが指数関数的に時間がかかり、これを軽く超える可能性があります。$2^{1500}$ステップ。 

数字に単一の 1 を強制的に発生させることなく無限に繰り返すことができる自己依存性の連鎖がある場合、微妙な特殊なケースが発生します。 たとえば、2 の繰り返しの間に 3 が必要で、3 の場合は 2 が必要で、2 も 3 も 1 ではない場合、1 を配置する前に 2 と 3 を無限に循環することができ、無限シーケンスが得られます。 単純な貪欲なアプローチでは、途中で停止したり、そのようなサイクルの検出に失敗したりして、不正確な「FINITE」出力が発生する可能性があります。 

別のエッジケースが発生するのは次の場合です。$m = 0$、制約がないことを意味します。 この場合、シーケンスには 1 を 1 つだけ含めることができます。これは、正確に 1 回出現することが保証されている唯一の数値であるためです。 不注意な実装では、制限なしで他の数値を繰り返し配置しようとする可能性がありますが、1 は 1 回だけ出現する必要があるため、無効になります。 

## アプローチ

 ブルートフォースアプローチでは、各ステップで制約をチェックしながら数値を挿入して、シーケンスを反復的に構築しようとします。 たとえば、すべての位置ですべての可能な数値を追加し、シーケンスを再帰的に構築してみることができます。 これはすべてのシーケンスを探索するため、原理的には正しいですが、絶望的に遅いです。 適度でも$n$シーケンスの長さと可能性の数は指数関数的に増加し、2 秒の制限をはるかに超えます。 

効率的な解決策につながる重要な観察は、制約を有向グラフとしてモデル化することです。 それぞれの番号がノードです。 各ペアごとに$(a_i, b_i)$からエッジを描きます$a_i$に$b_i$。 順序制約では、任意の 2 つの出現の間に次の条件が必要です。$a_i$、少なくとも 1 つある必要があります。$b_i$。 1 を含まないサイクルが存在する場合、1 を配置する前にこのサイクルを無限に繰り返すことができ、無限シーケンスが得られます。 逆に、グラフ内のすべてのサイクルに 1 が含まれているか、1 を配置することで中断できる場合、シーケンスの長さは制限されています。 したがって、無限シーケンスの検出は、ノード 1 に関係しないグラフ内のサイクルの検出に帰着します。 

有限シーケンスの場合、最長シーケンスを貪欲に構築できます。 依存関係のエッジを尊重する方法で拡張して、1 に向かう番号を配置します。 効果的な戦略の 1 つは、出力エッジに基づいて各数値の繰り返しが何回許可されるかを追跡し、深さ優先検索を使用して、最終的に 1 に至る数値から始まるシーケンスを生成することです。順序付けにより制約が確実に尊重され、1 以外にはサイクルが存在しないことがわかっているため、シーケンスは有限の最大長で終了することが保証されます。

 | グラフ + DFS サイクル検出 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各数値が次のとおりである有向グラフを構築します。$a$すべてに発信するエッジがある$b$ペアが$(a, b)$存在します。 これは、2 つの間の要件を表します。$a$少なくとも 1 つは必要です$b$。 
2. 各ノードから深さ優先検索を実行し、ノードを訪問済みとしてマークし、再帰スタックを追跡してサイクルを検出します。 1 を含まないサイクルが見つかった場合、このテスト ケースでは「INFINITE」を出力します。 
3. そのようなサイクルが存在しない場合は、有限シーケンスの構築に進みます。 唯一出現するシーケンスを 1 で初期化します。 
4. 他のすべての数値については、制約で許可される回数だけ繰り返し、各出現箇所が必要な数値で区切られていることを確認します。 1 つの簡単な戦略は、シーケンスを逆方向にシミュレートすることです。依存関係に続いてスタック順序で番号を配置し、最後に逆にします。 各配置では、「a の間に少なくとも 1 つの b」というルールが尊重されます。 
5. 「FINITE」、構築されたシーケンスの長さ、およびシーケンス自体を出力します。 

機能する理由: グラフは数値間のすべての制約を捉えます。 1 以外のサイクルは、1-1 制約に違反することなく無限に繰り返すことができ、これは無限シーケンスに直接対応します。 そのようなサイクルが存在しないことを保証することで、どのシーケンスも終了する必要があることが保証されます。 DFS 構築では、依存関係グラフと一致する順序で数値を配置するだけであるため、すべてのペア制約を尊重するシーケンスが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(3000)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        adj = [[] for _ in range(n + 1)]
        for _ in range(m):
            a, b = map(int, input().split())
            adj[a].append(b)

        visited = [0] * (n + 1)
        infinite = False

        def dfs(u, stack):
            nonlocal infinite
            visited[u] = 1
            stack[u] = True
            for v in adj[u]:
                if v == 1:
                    continue
                if not visited[v]:
                    dfs(v, stack)
                    if infinite:
                        return
                elif stack[v]:
                    infinite = True
                    return
            stack[u] = False

        for i in range(2, n + 1):
            if not visited[i]:
                dfs(i, [False] * (n + 1))
            if infinite:
                break

        if infinite:
            print("INFINITE")
        else:
            # Construct finite sequence
            seq = [1]
            for i in range(2, n + 1):
                for b in adj[i]:
                    seq.append(i)
            print("FINITE")
            print(len(seq))
            print(*seq)

solve()
```DFS セクションは、1 を除くサイクルをチェックします。隣接リストにより、すべての依存関係が確実にキャプチャされます。 1 は無限サイクルに参加できないため、DFS を 2 から n まで開始します。 サイクルが見つかった場合は、すぐに「INFINITE」を報告します。 それ以外の場合は、最初に 1 を配置し、次に隣接関係の依存関係に従って他の数値を追加することによってシーケンスを構築します。 これにより、有限で制約を尊重したシーケンスが保証されます。 

## 実用的な例

 **サンプル 1:**

 入力:```
3 2
3 1
2 1
```DFS 中の変数の状態:

 | ノード | スタック | 訪問しました | 無限？ |
 | --- | --- | --- | --- |
 | 2 | [誤]*4 | 訪問[2]=1 | いいえ |
 | 3 | [誤]*4 | 訪問[3]=1 | いいえ |

 シーケンスの構築: 1 から開始し、依存関係の順序で 2 と 3 を追加します。 結果のシーケンス: [2,3,1,2,3]。 達成される最大長は 5 です。 

これにより、1 を含まないサイクルが検出され、制約に従って有限シーケンスが構築されることが確認されます。 

**サンプル 2:**

 入力:```
2 2
1 2
2 1
```DFS は 1 と 2 の間の周期を検出しますが、周期の中に 1 が含まれるため、無限繰り返しは不可能です。 アルゴリズムは、サイクルが 1 を除く場合にのみ「INFINITE」を正しく出力します。
