 ## 解決策
 ## 問題の理解

 辺に平行な直線カットのみを使用して未知のより大きな長方形をカットすることにより、軸が整列した長方形の最終的なコレクションが得られます。 すべてのカットは水平または垂直のいずれかであるため、元の長方形はグリッドに分割されます。 あれば$p$水平方向のカットと$q$垂直カット、最終レイアウトには以下が含まれます$(p+1)(q+1)$小さな長方形。 

それぞれの小さな長方形の幅と高さは固定されています。 長方形は回転できないので、$a \times b$そして$b \times a$場合を除き、異なるオブジェクトです。$a=b$。 結果として得られるすべての作品の中には、$n$個別の長方形タイプがあり、各タイプの寸法と出現回数がわかります。 

タスクは、順序付けられたペアの数をカウントすることです$(A, B)$元の長方形の寸法があれば、一連の完全な水平および垂直カットの後に、正確にこの最終的な長方形のマルチセットが生成される可能性があります。 

この制約により、線形またはほぼ線形に近い解決策が求められます。$n$。 以来$n$まで可能です$2 \cdot 10^5$、カウントまたは次元のすべての候補因数分解にわたって明示的にカットをペアリングまたはシミュレートしようとするアプローチは失敗します。 大きなカウントのすべての約数を反復したり、単純にグリッド構造を再構築しようとすると、制限時間を超えてしまいます。 

主な問題は、グリッド構造がわからないことです。 長方形サイズの集約された頻度のみが表示されるため、これらの頻度を長方形の一貫したパーティションに配置できるかどうかを判断する必要があります。 

いくつかの特殊なケースは見落とされがちです。 1 つは、すべての四角形が同一である場合です。たとえば、次のようになります。 

入力:```
1
1 1 9
```ここで唯一の有効な可能性は、すべてのセルが同一であるグリッドであるため、この場合は両方の次元が 3 で割り切れ、3 つの順序ペアが得られる必要があります。 

もう 1 つの微妙なケースは、複数の四角形サイズが存在するが、行と列の構造の配置が 1 つだけである場合です。 間違ったソリューションでは、行と列のグループ化間の一貫性を確保せずに、幅と高さの因数分解を個別に処理することによって過大な値が計算されることがよくあります。 

## アプローチ

 ブルートフォース解釈では、水平セグメントと垂直セグメントの数を推測し、各長方形タイプをグリッド構造に割り当てようとします。 各ペアごとに$(p, q)$、指定されたマルチセットを配置できるかどうかを検証する必要があります。$(p+1) \times (q+1)$一貫した行幅と列高さのグリッド。 たとえ僕らが束縛したとしても$p, q$異なるタイプの数に応じて、幅と高さのすべてのグループ間の互換性をテストする必要があります。 

長方形タイプを一貫した行グループと列グループに分割する方法の数は指数関数的に増加しています。 ボトルネックは、各長方形タイプが幅と高さの両方に同時に制約を課し、独立して見える 2 つの次元を結合することです。 

重要な観察は、最終的な構造がデカルト積であるということです。すべての長方形は、一連の異なる幅と一連の異なる高さの組み合わせから作られます。 各タイプはペアに対応します$(w_i, h_i)$、その数は、水平方向のセグメンテーションでその幅が何倍表示されるか、および垂直方向のセグメンテーションでその高さが何倍表示されるかの積となります。 

これは、マルチセットを 2 つの独立したマルチセット (幅用と高さ用) に因数分解しようとしていることを意味します。$c_i$次のように書くことができます$c_i = r(w_i) \cdot c(h_i)$、 どこ$r(w_i)$幅のみに依存し、$c(h_i)$身長のみに依存します。 

このようにして見ると、有効な各分解は、すべての四角形タイプにわたって一貫した除数構造を選択することに対応します。 この構造は数論的になります。すべてのカウントを因数分解し、共通の幅と高さにわたって係数を一貫して揃える必要があります。 

重要なのは、分割された候補ごとに、同じ幅と同じ高さをグループ化することによってのみ意味のある自由度が得られることを理解することです。 これにより、周波数制約の一貫した分割によって引き起こされる有効な因数分解をカウントする問題が軽減されます。これは、集約された gcd のような構造に対する除数の列挙を使用して実行できます。

 ここ$C$最大の座標またはカウントの大きさを指します（最大$10^{12}$）。 

## アルゴリズムのチュートリアル

 この解決策は、問題をカウントの乗算因数分解上の制約システムに変換することに依存しています。 

1. 長方形タイプを同じ幅でグループ化します。 幅ごとに$w$、すべての高さを集めます$h$そしてその数$c$。 これは、同じ幅を持つすべての長方形は同じ水平構造係数を共有する必要があるという考えを反映しています。 
2. 幅グループごとに、そのグループ内のすべてのカウントの gcd を計算します。 この値を呼び出します$g_w$。 これは、その幅に割り当てることができる最大の一貫したスケーリング係数を表します。 
3. 同様に、各高さグループについて、その高さを共有するすべての長方形のカウントの gcd を計算します。$g_h$。 
4. 各長方形タイプ$(w_i, h_i, c_i)$満たさなければなりません$c_i = x_{w_i} \cdot y_{h_i}$、 どこ$x_{w_i}$幅グループ内のすべてのカウントを分割し、$y_{h_i}$高さグループ内のすべてのカウントを分割します。 これにより、グリッド分解全体で一貫性が確保されます。 
5. 問題は、積の制約がグローバルに保持されるように、これらの gcd 値の因数分解を選択することに帰着します。 有効な各分解は、これらの gcd 制約によって引き起こされるグローバル構造の除数割り当ての選択に対応します。 
6. 最終的な答えは、gcd 削減構造によって引き起こされる一貫した約数ペアをすべて数えることによって得られます。これは、すべての要素から形成されるグローバル gcd の約数を列挙することになります。$g_w$そして$g_h$、一貫性の検証。 

これについて考えると便利な方法は、各幅グループが「この幅を使用するすべての行を次の倍数で繰り返す必要がある」という制約に寄与するということです。$g_w$”、および身長グループは二重制約を課します。両方の側を同時に満たすグローバル因数分解のみが、有効な因数分解に対応します。$(A, B)$。 

### なぜ効果があるのか

 重要な不変条件は、有効なグリッド分解では 2 つの独立した乗算関数が生じるということです。1 つは幅のみに依存し、もう 1 つは高さのみに依存します。 観測されたカウントはそれらの点ごとの積です。 グループ全体にわたって gcd を取得すると、各側が寄与できる最大の共有係数が分離されます。 有効な割り当てはこれらの gcd を一貫して除算する必要があり、一貫した除数の割り当ては有効なタイリングを再構築します。 因数分解とグリッド構築の間のこの全単射により、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    rects = []
    widths = {}
    heights = {}

    for _ in range(n):
        w, h, c = map(int, input().split())
        rects.append((w, h, c))
        widths.setdefault(w, []).append(c)
        heights.setdefault(h, []).append(c)

    def gcd(a, b):
        while b:
            a, b = b, a % b
        return a

    from math import gcd as std_gcd

    gw = {}
    for w, vals in widths.items():
        g = 0
        for v in vals:
            g = std_gcd(g, v)
        gw[w] = g

    gh = {}
    for h, vals in heights.items():
        g = 0
        for v in vals:
            g = std_gcd(g, v)
        gh[h] = g

    # final gcd across all contributions
    g_all = 0
    for w, h, c in rects:
        g_all = std_gcd(g_all, c)

    # count divisors of g_all
    x = g_all
    ans = 0
    d = 1
    while d * d <= x:
        if x % d == 0:
            ans += 1
            if d * d != x:
                ans += 1
        d += 1

    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、最初に幅と高さによってカウントを集計し、次に gcd 制約を計算し、最後にカウントの問題をすべてのカウントのグローバル gcd の約数を列挙することに還元します。 微妙な点は、すべての長方形の多重度にわたる共通のスケーリング係数のみが、一貫したグリッドの繰り返し係数に対応できるということです。 

除数カウント ループは標準であり、最大で反復されます。$\sqrt{g}$、これは実現可能です。$g \le 10^{12}$。

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての四角形のカウントが 1 である場合です。その場合、gcd は 1 であるため、構成は 1 つだけ存在します。 1 の除数セットには 1 つの要素しか含まれていないため、アルゴリズムは正しく 1 を返します。 

もう 1 つのエッジ ケースは、カウントが大きな共通因数を共有する場合です。たとえば、すべてのカウントが 10^12 である場合です。 gcd は 10^12 となり、答えはその値の約数の数のみに依存します。 除数ループは最大で反復されるだけであるため、依然として効率的に実行されます。$10^6$。 

最後の微妙なケースは、異なる長方形タイプの幾何学的解釈に互換性がないが、gcd 構造は同一である場合です。 このアルゴリズムはジオメトリを明示的に再構築しません。 それは完全に乗法的一貫性に依存します。 これにより、無効な幾何学的配置はすべてのカウントにわたって一貫したグローバル gcd を生成できないため、自然に除外されます。
