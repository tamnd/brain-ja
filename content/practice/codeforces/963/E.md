 ## 解決策

 ## 問題の理解

 チップは整数グリッドの原点から始まります。 入力パラメータから導出された確率で、毎秒、4 つの基本的な方向 (左、下、右、または上) のいずれかに 1 つのランダムな移動が実行されます。 動作には記憶がなく、ステップ間で独立しています。 

チップが半径の円から初めて離れたときにプロセスが停止します$R$原点を中心とし、距離はユークリッドです。 タスクは、この終了が発生するまでに予想されるステップ数を計算し、結果を分数モジュロとして出力することです。$10^9+7$。 

主な問題点は、状態空間が幾何学的で原理的には無限であることですが、停止条件により、半径円の内側または上のすべての格子点に注意が制限されることです。$R$。 以来$R \le 50$、関連する州の数は最大で約$\pi R^2$これは、8000 未満です。これは、すべての整数点にわたる動的計画法を直ちに示唆します。$(x,y)$と$x^2 + y^2 \le R^2$。 

予想される時間が非常に大きくなる可能性があり、ランダム性は正確な予想を計算するのに役立たないため、単純なシミュレーションは不可能です。 

微妙なエッジケースは次のような場合です$R = 0$。 この場合、チップはすでに境界上にあるため、いかなる手も即座に終了します。 期待値は確率に関係なく正確に 1 です。 

動きの確率が大きく偏っている場合、別の微妙な状況が発生します。 素朴な直感は、ドリフトが速度にのみ影響することを示唆するかもしれませんが、正しい定式化では、境界領域内の対称的な反復を考慮する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべてのランダムウォークをシミュレートし、終了時間を平均化します。 たとえ深い深さで切り詰められたとしても、パスの数は時間の経過とともに指数関数的に増加します。 各ステップで分岐が 4 倍になるため、その後$t$ステップがあります$4^t$可能な軌道。 これは非常に小さい場合でも使用できません$t$。 

正しい観察は、これが吸収マルコフ連鎖であるということです。 円の内側のすべての格子点は状態であり、外側のすべての状態は追加コストなしで終端状態を吸収します。 吸収の予想打撃時間が欲しい。 

させて$E(x,y)$から開始して終了するまでの予想されるステップ数を示します。$(x,y)$。 もし$(x,y)$すでに輪の外にいる、$E(x,y)=0$。 それ以外の場合は、$(x,y)$、一歩踏み出すと、4 つの隣り合うものの 1 つに移動します。 これにより、線形回帰が得られます。$$E(x,y) = 1 + p_1 E(x-1,y) + p_2 E(x,y-1) + p_3 E(x+1,y) + p_4 E(x,y+1)$$これは、すべての有効な状態にわたる線形方程式系です。 状態の数が少ないため、ガウス ジョルダン消去法またはスパース線形解法を使用して直接解くことができます。 

構造は重要です。各方程式は 1 つの点をその 4 つの近傍に接続するだけで、自然な順序を持つ疎なシステムが生成されます。 すべての有効な状態にインデックスを付けて、すべての期待値を同時に解決します。 

ブルート フォースはパスが指数関数的に爆発するため失敗しますが、線形システムは期待によってランダム性が決定論的な制約に線形化されるため機能します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | 指数 | お(1) | 遅すぎる |
 | 線形システム (ガウス消去法) | O(N^3) | O(N^2) | 承認済み |

 ここ$N \approx \#\{(x,y): x^2+y^2 \le R^2\}$、最大でも ~8000。 

## アルゴリズムのチュートリアル

 ランダム ウォークをすべての有効な格子点にわたる有限線形システムに変換します。 

1. すべての整数点を列挙します$(x,y)$そのような$x^2 + y^2 \le R^2$。 このような各点にインデックスを割り当てます。 これは未知数を定義します$E(x,y)$。 外側の点は期待値 0 を持つものとして扱われるため、変数は必要ありません。 
2. 有効な状態ごとに$(x,y)$、方程式を書きます$$E(x,y) - p_1 E(x-1,y) - p_2 E(x,y-1) - p_3 E(x+1,y) - p_4 E(x,y+1) = 1$$近傍が円の外側にある場合、その寄与は 0 に置き換えられます。ここで境界条件が適用されます。 
3. 確率をモジュラー演算に変換します。 以来$p_i = a_i / (a_1+a_2+a_3+a_4)$、和の逆モジュラーを事前計算し、それに応じてすべての係数を乗算します。 
4. サイズの密なマトリックスを構築する$N \times N$ここで、各行は 1 つの状態方程式をエンコードします。 対角エントリは常に 1 であり、遷移に応じて最大 4 つの非対角エントリが減算されます。 
5. ガウス消去法を使用して線形システムを解きます。$10^9+7$。 慎重にピボットし、除算の代わりに逆モジュラーが使用されていることを確認します。 
6. 答えは次のとおりです。$E(0,0)$、開始状態に対応します。 

正確さは、各方程式を期待値の最初のステップの分解として解釈することで得られます。 このシステムは、すべての状態が有限集合内で遷移するか有限集合外で終了するため、マルコフ連鎖を吸収して一意の解を保証するため、すべての予想されるヒット時間を一意に特徴付けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(x):
    return pow(x, MOD - 2, MOD)

R, a1, a2, a3, a4 = map(int, input().split())
s = a1 + a2 + a3 + a4
p1 = a1 * modinv(s) % MOD
p2 = a2 * modinv(s) % MOD
p3 = a3 * modinv(s) % MOD
p4 = a4 * modinv(s) % MOD

pts = []
idx = {}
for x in range(-R, R + 1):
    for y in range(-R, R + 1):
        if x * x + y * y <= R * R:
            idx[(x, y)] = len(pts)
            pts.append((x, y))

n = len(pts)

mat = [[0] * (n + 1) for _ in range(n)]

dirs = [(-1, 0, p1), (0, -1, p2), (1, 0, p3), (0, 1, p4)]

for i, (x, y) in enumerate(pts):
    mat[i][i] = 1
    mat[i][n] = 1
    for dx, dy, p in dirs:
        nx, ny = x + dx, y + dy
        if (nx, ny) in idx:
            mat[i][idx[(nx, ny)]] = (mat[i][idx[(nx, ny)]] - p) % MOD

def gauss(a):
    n = len(a)
    m = len(a[0]) - 1
    row = 0
    for col in range(m):
        pivot = -1
        for i in range(row, n):
            if a[i][col]:
                pivot = i
                break
        if pivot == -1:
            continue
        a[row], a[pivot] = a[pivot], a[row]
        inv = modinv(a[row][col])
        for j in range(col, m + 1):
            a[row][j] = a[row][j] * inv % MOD
        for i in range(n):
            if i != row and a[i][col]:
                factor = a[i][col]
                for j in range(col, m + 1):
                    a[i][j] = (a[i][j] - factor * a[row][j]) % MOD
        row += 1
    return a

mat = gauss(mat)
print(mat[idx[(0, 0)]][n])
```コードはまず確率をモジュール形式に正規化します。 円内の各格子点が変数になります。 行列は、すべての状態に対して定数項を 1 に設定して、期待方程式を直接エンコードします。 

ガウス消去はモジュラー演算で実行されます。 各ピボット行は、除算の代わりに逆モジュラーを使用して正規化されます。 次に、消去によって他のすべての方程式から変数が削除され、各変数が決定される縮小システムが生成されます。 

最終値は、対応する行から読み取られます。$(0,0)$。 

## 実用的な例

 ### 例 1

 入力:```
0 1 1 1 1
```原点のみが円の中にあります。 

| 状態 | 方程式 | 右側 |
 | --- | --- | --- |
 | (0,0) | E(0,0) = 1 | 1 |

 すべての動きが円を離れるので、答えはすぐにわかります。 

これは境界処理を裏付けています。すべての近傍は外側にあるため、それらの寄与は消滅します。 

### 例 2

 入力:```
1 1 0 0 0
```左移動のみ可能です。 

有効な状態は (-1,0)、(0,0)、(1,0)、(0,±1) です。 (0,0) からは左の手だけが中に残ります。 

| 状態 | 移行 |
 | --- | --- |
 | (0,0) | 1 + E(-1,0) |
 | (-1,0) | すぐに終了します |

 解くと有限の期待時間が得られ、システムは出口に向かう決定論的なドリフトを正確に捕捉します。 

これは、構造を変更せずに非対称確率がどのように処理されるかを示しています。

 ## 特殊なケース

 いつ$R = 0$、唯一の有効な状態は$(0,0)$。 方程式は次のようになります$E(0,0)=1$、すべての動きがすぐに終了するため。 このアルゴリズムは 1×1 システムを構築し、期待される動作と一致する 1 を直接返します。 

すべての質量が一方向にあるなど、確率が大きく歪んでいる場合でも、線形方程式は対称性を仮定していないため、システムは依然として有効です。 すべての状態が境界に近づくか、すぐに終了するため、削除ステップでもすべての依存関係が解決され、システム内で縮退サイクルが発生しないことが保証されます。 

近傍が円の外側にある場合、その期待値はゼロとして扱われます。 これは、行列の構築中に、方程式からその変数を単純に省略することとして現れます。 これにより、吸収状態を明示的に追加しなくても、境界の正確さが保証されます。
