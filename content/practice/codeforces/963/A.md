 ## 問題の理解

 各位置が 2 つの独立した基数の累乗に寄与する、長い重み付けされた合計が与えられます。 インデックス時$i$、貢献度は次のいずれかです$+1$または$-1$、乗算$a^{n-i} b^i$。 記号の順序はすべての人にとって任意ではありません$n+1$位置、代わりに最初のみ$k$値が与えられ、残りは毎回繰り返されます$k$ステップ。 

したがって、タスクは、係数が周期的に繰り返される、周期的に交互する多項式のような式を評価することです。$k$ただし、指数はシーケンス内の絶対位置に依存します。 係数は大きな素数のような数です$10^9 + 9$したがって、算術演算はモジュラー リダクションの下で実行する必要があります。 

この困難は、周期係数と重みの幾何学的増加という 2 つの相互作用する構造に起因します。$a^{n-i} b^i$。 指数$n$と同じ大きさにすることができます$10^9$したがって、数列を直接構築したり、項ごとに直接累乗したりすることは不可能です。 

単純な評価では、すべてを反復処理する必要があります。$n+1$位置を計算し、各項のモジュラーべき乗を計算します。 たとえ各べき乗が対数時間で計算されたとしても、これではまだ遅すぎます。$n$までです$10^9$、最大 10 億語までを意味します。 

周期性が指数構造と相互作用する場合、エッジ ケースが発生します。 たとえば、次の場合$k = 1$の場合、数列は一定であり、答えは閉形式の幾何学和になります。 もう 1 つの例外的なケースは次のような場合です。$a = b$ここでは、すべての重みが 1 つのべき乗に崩壊し、キャンセルは純粋に交互の周期的な合計に依存するため、符号の処理ミスが容易に発生する可能性があります。 

一般的な障害モードは、サイクルを誤って繰り返すことです。 以来$n+1$の倍数ではない可能性があります$k$素朴な推論ですが、問題はそれを保証します$k$分割する$n+1$この事実を無視すると、部分ブロックが正しく処理されなくなります。 

## アプローチ

 ブルートフォース ソリューションでは、各項が直接評価されます。$$s_i \cdot a^{n-i} b^i$$みんなのために$i$から$0$に$n$。 これは定義に正確に従っているため、正しいです。 ただし、必要なのは$n+1$べき乗剰余計算、それぞれの原価計算$O(\log n)$、約につながる$10^9 \log 10^9$実行可能な限界をはるかに超えた最悪の場合の操作。 

重要な観察は、係数シーケンスと重み構造の両方に乗法的な規則性があるということです。 各用語を次のように書き換えます。$$a^{n-i} b^i = a^n \left(\frac{b}{a}\right)^i$$これにより定数が計算されます$a^n$、等比数列を残します$\frac{b}{a}$、周期的な符号シーケンスを乗算します。 

合計は次のようになります。$$a^n \sum_{i=0}^{n} s_i r^i, \quad r = b \cdot a^{-1}$$すべては、等比数列によって重み付けされた周期シーケンスを評価することに帰着します。 

剰余モジュロでインデックスを分割します$k$。 各剰余クラスはブロックにわたって等比級数を形成します。$$i = t k + j$$どこ$j$固定されており、$t$すべてのフルブロックにわたって実行されます。 これにより、合計は次のように変換されます。$$\sum_{j=0}^{k-1} s_j r^j \sum_{t=0}^{m-1} r^{tk}$$どこ$m = \frac{n+1}{k}$。 

内和は標準等比級数です。$r^k$、外側の和だけが終わります$k$計算が効率的に行われます。

 ## アルゴリズムのチュートリアル

 私たちは完全にモジュロの下で作業します$M = 10^9 + 9$。 

1. 符号列を数値に変換する$s_j \in \{+1, -1\}$。 このステップでは、後の代数がきれいに機能するように、周期係数パターンを明示的に確立します。 
2. モジュラー逆関数を計算します。$a$、必要なので$r = b \cdot a^{-1}$。 これにより、混合指数式が単一の等比数列基底に書き換えられます。 
3. 事前計算$r^k$。 これは、長さの連続するブロック間の成長率を表します。$k$。 これが重要な理由は、各剰余クラスが次の累乗で等比数列を形成するためです。$r^k$。 
4. コンピューティング$m = (n+1)/k$、完全な期間の数。 これは次の保証から導かれます。$k$分割する$n+1$したがって、部分ブロックの処理は必要ありません。 
5. ポジションごとに$j$基準期間で寄与度を計算します$s_j \cdot r^j$。 これにより、発生する完全なサイクルの数に関係なく、ブロック内オフセットの寄与が分離されます。 
6. 各寄与にブロック全体の幾何学和を乗算します。$$1 + (r^k) + (r^k)^2 + \dots + (r^k)^{m-1}$$もし$r^k \neq 1$、これは標準の閉じた形式を使用して計算されます。 1 に等しい場合、合計は次のように減ります。$m$。 
7. すべての剰余寄与を合計し、次の乗算を行います。$a^n$、取り除かれた電力を復元します。 

### なぜ効果があるのか

 すべてのインデックス$i$は次のように一意に表されます$i = tk + j$。 その位置の項は次のようになります。$$s_j \cdot a^{n-(tk+j)} b^{tk+j}$$これは次の要素を考慮します。$$s_j a^{n-j} (b^j a^{-j}) (b^k a^{-k})^t$$したがって、各剰余クラスは次の等比級数になります。$t$。 このアルゴリズムは、これらの独立した進行を正確に再構築して合計し、クラス間の相互作用が見逃されたり二重にカウントされたりしないようにします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 9

def modpow(x, e):
    res = 1
    while e:
        if e & 1:
            res = res * x % MOD
        x = x * x % MOD
        e >>= 1
    return res

def modinv(x):
    return modpow(x, MOD - 2)

def solve():
    n, a, b, k = map(int, input().split())
    s = input().strip()

    vals = [1 if c == '+' else -1 for c in s]

    inv_a = modinv(a)
    r = b * inv_a % MOD

    r_k = modpow(r, k)
    m = (n + 1) // k

    # geometric sum over blocks
    if r_k == 1:
        geom_blocks = m % MOD
    else:
        geom_blocks = (modpow(r_k, m) - 1) * modinv(r_k - 1) % MOD

    ans = 0

    # contribution per residue class
    for j in range(k):
        term = vals[j] * modpow(r, j) % MOD
        ans = (ans + term) % MOD

    ans = ans * geom_blocks % MOD
    ans = ans * modpow(a, n) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```実装は代数変換に直接続きます。 最もデリケートな部分は、基準を変更することです。$a^{n-i} b^i$の中へ$a^n r^i$これにより、大きなべき乗を繰り返し再計算することがなくなります。 

幾何和を計算するときは注意が必要です: 分母$r^k - 1$剰余をとらなければなりません$M$、ゼロにすることもできます。これは、すべてのブロックが均等に寄与し、合計が線形になる特殊なケースに対応します。$m$。 

最終的な乗算$a^n$変換開始時に引き出された因子を復元します。

 ## 特殊なケース

 いつ$k = 1$、シーケンス全体は一定です。 The algorithm reduces to a single geometric series in$b/a$1 つの残差クラスのみが寄与するため、実装はこれを正しく処理します。 幾何学的なブロック和はすべての項をキャプチャし、インデックス作成の問題は発生しません。
