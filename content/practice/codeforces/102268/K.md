 ## 問題の理解

 アルファベットの上にバイナリ文字列があります`a, b`。 許可される操作は、次の 3 つの特殊ブロックのいずれかを挿入または削除します。`aa`、`bbb`、 そして`ababab`。 挿入と削除はどちらも許可されているため、次の関係を使用して一方を他方に変換できる場合、2 つの文字列は正確に同じクラスに属します。 

[
 a^2 = 1、\qquad b^3 = 1、\qquad (ab)^3 = 1。 
】

 初期文字列`s`はそのような等価クラスの 1 つを決定します。 以下から取得できる実際の文字列を構築する必要はありません。`s`。 代わりに、所定の長さに対して`x`、同じクラスに属する正確にその長さのバイナリ文字列がいくつあるかを数える必要があります。`s`。 

入力長さ`n`最大 (300000) なので、処理します`s`線形または線形に近い値である必要があります。 すべての部分文字列の状態を保持したり、変換される可能性のある文字列を列挙しようとするアルゴリズムは、すでにコストが高すぎます。 もっと真剣に、`x`(10^9) までの大きさになる可能性があるため、アルゴリズムは次のように線形に依存します。`x`不可能です。 同値クラスを一定数の状態に圧縮してから、対数べき乗を使用して巨大な長さを処理する必要があります。 

誤った解釈を露呈する傾向にある 3 つの特殊なケースがあります。 初め、`x`ゼロにすることもできます。 例えば、```
1
a
0
```答えがあります`0`空の文字列は ID を表すため、`a`しません。 ターゲットに常に少なくとも 1 つの文字があると想定する解決策では、これが間違ってしまいます。 

第 2 に、開始文字列は空でなくてもすでに ID を表すことができます。 例えば、```
2
aa
0
```答えがあります`1`、 なぜなら`aa`空の文字列を残して削除できます。 同値クラスではなくリテラル文字列を比較するソリューションは、誤ってゼロを返します。 

第三に、関係は境界を越えて相互作用するため、単純に、`aa`または`bbb`完全な正規化戦略ではありません。 例えば、`ababab`の正体と答えを表します```
6
ababab
3
```は`1`。 アイデンティティを表す唯一の長さ 3 は次のとおりです。`bbb`。 3 番目の関係を考慮しないローカル リダクション アルゴリズムでは、この等価性を簡単に見逃す可能性があります。 公式サンプルでは、​​これらの出力が確認されています。 

## アプローチ

 直接的なアプローチでは、長さの (2^x) 個のバイナリ文字列をすべて列挙します。`x`、正規化して、次のクラスに属するかどうかを確認します。`s`。 これは正しいです。考えられるすべてのターゲット文字列が明示的に考慮されるからです。 正規化に (O(x)) 時間がかかる場合、最悪の場合の合計作業量は (\Theta(x2^x)) となり、(2^x) 個の候補と各候補で (x) 個の文字が検査されます。 これはもう絶望的だ`x = 30`、ましてや (10^9)。 

この操作では等価関係が定義されているため、ブルート フォースは機能しますが、文字列の数が要求された長さに対して指数関数的であるため、この操作は失敗します。 重要な観察は、これら 3 つの関係が無限に多くの異なる同値クラスを作成するわけではないということです。 それらはわずか 12 個の要素からなる有限群を形成します。 

グループを確認する便利な方法は、2 つの文字に順列を割り当てることです。 しましょう

 [
 a=(12)(34)、\qquad b=(123)。 
】

 順列`a`次数は 2 ですが、`b`次数が 3 であり、`ab`の次数は 3 であるため、問題の 3 つの関係はすべて当てはまります。 これら 2 つの順列により、(A_4) と同形の四面体の回転対称群が生成され、(A_4) はちょうど 12 個の要素を持ちます。 

同様に、12 の同値クラスは次の単語で表すことができます。 

[
 \epsilon,\ a,\ b,\ ab,\ ba,\ bb,\ aba,\ abb,\ bab,\ bba,\ babb,\ bbab。 
】

 すべての文字列は、指定された関係を使用してこれらの代表の 1 つに還元でき、その代表は (A_4) の個別の要素に対応します。 これにより、ちょうど 12 の状態を持つ有限オートマトンが得られます。 これと同じ 12 状態構造が、この問題に対する既存のソリューションで使用される中心的な観察です。 

一旦状態が`s`がわかっている場合、問題の残りの部分は歩行カウント問題になります。 ID 状態から開始し、次のいずれかを追加します`a`または`b`その通り`x`で表される状態で何回歩行が終了したかを尋ねます。`s`。 状態は 12 個しかなく、各状態からの出力遷移は 2 つしかないため、隣接行列がカウントを処理します。 以来`x`(10^9) に達する可能性がある場合、12 x 12 の行列を次のように計算します。`x`2進累乗を使用した-乗。 

結果として得られる複雑さは (O(n+12^3\log x)) であり、これは容易に制約内に収まります。 これは、標準的なソリューションのアプローチで説明される複雑さでもあります。

 ## アルゴリズムのチュートリアル

 1. 3 つの削除操作をグループ関係として解釈します。 削除中`aa`意味 (a^2=1)、削除`bbb`は (b^3=1) を意味し、削除します。`ababab`((ab)^3=1) を意味します。 逆の演算も許可されるため、これらの関係は両方向に機能します。 
2. 2 つのジェネレーターを 4 つのオブジェクトの順列として表します。 (a=(12)(34)) と (b=(123)) を使用します。 恒等順列は空の文字列を表します。 
3. 4 つの要素の 12 個の偶数順列をすべて生成します。 これらはまさに (A_4) の要素であるため、オートマトンでは各同値クラスが 1 つの状態を持ちます。 
4. 文字を追加するということは、右側の現在の順列にその文字の順列を乗算することを意味するように、順列合成を定義します。 現在の状態が次の場合`g`そして次の文字は`h`、新しい状態は (g\circ h) です。 
5. 元の文字列をスキャンします`s`左から右へ。 恒等順列から始めて、各文字に対応する順列を掛けます。 スキャン後の結果の順列は、まさに次の等価クラスになります。`s`。 
6. 12 × 12 の遷移マトリックスを構築する`T`。 すべての州について`u`、追加`a`そして`b`、結果の状態を計算します`v`、増加します`T[v][u]`1つずつ。 状態カウントの列ベクトルが (dp' = Tdp) として変換されるため、この方向を使用します。 
7. 空の文字列のベクトルは、アイデンティティ状態では 1 つのカウントを持ち、それ以外の場合は 0 を持ちます。 まさにその後`x`文字の場合、状態カウント ベクトルは次のようになります。 

[
 T^x e、
 】

 どこで`e`はアイデンティティ状態ベクトルです。 

1. 2 進累乗によって (T^x) を計算します。 各二乗は、行列で表される追加文字数の 2 倍を表します。 現在のビットが`x`が 1 の場合、解答行列に現在の累乗を掛けます。 
2. の状態に対応するエントリを読み取ります。`s`アイデンティティの開始状態から。 その値は長さの数値です。`x`と同等の文字列`s`。 

### なぜ効果があるのか

 不変条件は、すべてのバイナリ文字列が 12 要素グループ内で 1 つの状態を正確に持ち、2 つの文字列が同じ状態を持つ場合に限り、相互に変換可能であるということです。 許可された挿入および削除では、(a^2)、(b^3)、または ((ab)^3) のいずれか 1 つが挿入または削除され、そのすべてが ID に等しいため、グループ要素が保持されます。 

逆に、12 の状態はすべての等価クラスを表すのに十分です。 ジェネレータ (a=(12)(34)) および (b=(123)) は (A_4) を生成し、上にリストされた 12 個の標準語はその 12 個の異なる要素を表します。 したがって、群状態は 2 つの真に異なる同値クラスをマージしません。 

ターゲットの長さの場合、すべてのバイナリ文字列は、長さの 1 つのウォークに正確に対応します。`x`アイデンティティから始まり、`a`そして`b`各位置で 2 つの可能なトランジションを選択します。 行列乗算では、多重度も含めてこれらのウォークをカウントします。 したがって、恒等式から次の状態への行列入口は、`s`必要なターゲット文字列を正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353
K = 12

def compose(p, q):
    """Return p o q, where permutations are stored by their images."""
    return tuple(p[q[i]] for i in range(4))

def parity(p):
    """Return 0 for even and 1 for odd permutation."""
    inv = 0
    for i in range(4):
        for j in range(i + 1, 4):
            if p[i] > p[j]:
                inv += 1
    return inv & 1

def mat_mul(a, b):
    n = K
    c = [[0] * n for _ in range(n)]

    for i in range(n):
        ci = c[i]
        ai = a[i]
        for k in range(n):
            x = ai[k]
            if x == 0:
                continue
            bk = b[k]
            for j in range(n):
                ci[j] = (ci[j] + x * bk[j]) % MOD

    return c

def mat_pow(a, e):
    n = K
    r = [[0] * n for _ in range(n)]
    for i in range(n):
        r[i][i] = 1

    while e:
        if e & 1:
            r = mat_mul(r, a)
        a = mat_mul(a, a)
        e >>= 1

    return r

def solve():
    n = int(input())
    s = input().strip()
    x = int(input())

    # All even permutations of four elements are the 12 states of A4.
    states = []
    for p in __import__("itertools").permutations(range(4)):
        if parity(p) == 0:
            states.append(p)

    index = {p: i for i, p in enumerate(states)}

    # a = (12)(34), b = (123)
    a = (1, 0, 3, 2)
    b = (1, 2, 0, 3)

    generators = {
        'a': a,
        'b': b,
    }

    identity = (0, 1, 2, 3)

    # Find the group element represented by s.
    g = identity
    for ch in s:
        g = compose(g, generators[ch])

    target = index[g]
    start = index[identity]

    # T[v][u] = number of one-character transitions u -> v.
    T = [[0] * K for _ in range(K)]

    for u, state in enumerate(states):
        va = index[compose(state, a)]
        vb = index[compose(state, b)]
        T[va][u] += 1
        T[vb][u] += 1

    T = mat_pow(T, x)

    print(T[target][start] % MOD)

if __name__ == "__main__":
    solve()
```順列構造により、リダクション テーブルをハードコーディングする代わりに、ソリューションにクリーンな実装が提供されます。 タプル`(p[0], p[1], p[2], p[3])`4つのポイントがそれぞれ発信される店舗。 その正体は、`(0, 1, 2, 3)`、 その間`a = (1, 0, 3, 2)`((12)(34)) を表し、`b = (1, 2, 0, 3)`((123))を表します。 

の`compose`関数は数学的合成 (p\circ q) を実装します。 現在の単語が表すとき`p`そしてジェネレーターを追加します`q`、新しい単語は次のことを表します`p q`、まさにその通りです`compose(p, q)`この条約の下では。 この順序を一貫して保つことが重要です。 これを逆にすると、別のオートマトンが構築され、静かに不正解が生成される可能性があります。 

スキャン終了`s`直線的です`n`。 部分文字列を削減したり、スタックを維持したりする必要はありません。 現在の順列には、将来の変換に関連するすべての情報が含まれています。 

マトリックスが使用するのは、`T[new][old]`それよりも`T[old][new]`。 この規則に従って、乗算すると、`T`列ベクトルによる次の状態の分布が得られます。 したがって、アイデンティティからターゲットまでの数は次のようになります。`T[target][identity]`べき乗後。 

すべての行列積はモジュロ (998244353) で実行されます。 Python の整数はオーバーフローしませんが、乗算中に削減すると中間値が小さく保たれ、不必要な増加が回避されます。 

指数`x`はビット シフトで処理されるため、(O(\log x)) 個の行列乗算のみが必要になります。 行列の次元は 12 に固定されているため、この部分は元の文字列のスキャンと比較すると非常に小さいです。
