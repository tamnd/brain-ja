 ## 解決策
 ## 問題の理解

 頂点が座標によって与えられ、エッジが直線セグメントである接続された無向平面グラフがあります。 ランダム ウォークは頂点 (1) から開始します。 ウォークが頂点にあるときは常に、その入射エッジの 1 つを均一に選択し、それを横切って移動します。 プロセスは最初に頂点 (n) に到達したときに停止します。また、モジュロ (998244353) で表される予想される移動数が必要です。 

ランダム ウォーク自体には座標は必要ありません。 それらの目的は、エッジの数に関する重要な構造的境界を与える平面の埋め込みを記述することです。 (n\ge 3) 個の頂点を持つ単純な平面グラフには、最大で (3n-6) 個のエッジがあります。 したがって、このステートメントでは構文的に結合された一般的な完全なグラフが許可されていますが、実際の入力グラフは (m=O(n)) で疎です。 公式問題は (n\le 3000) を使用するため、(O(n^2)) アルゴリズムは現実的ですが、密な (O(n^3)) 線形代数法は遅すぎます。 

問題の確率的な性質には別の制約が隠されています。 打撃時間は (n) によって制限されないため、固定歩数の歩行をシミュレートしても正確な答えを直接得ることはできません。 (n) 個の頂点を持つパスの予想ヒット時間はすでに (n(n-1)) であり、より複雑なグラフではヒット時間が長くなる可能性もあります。 生存確率の無限シーケンスを有限の計算に変換する必要があります。 

最初のエッジ ケースは、可能な限り最小のグラフです。 2 つの頂点と 1 つのエッジ (1\mathbin{-}2) を使用すると、答えは正確に (1) になります。```
2
0 0
5000 5000
1
1 2
```一時グラフのみを構築し、すべての一時頂点に出力遷移があると想定する不用意な実装は、ターゲットを削除した後にエッジが残らないため、ここで失敗する可能性があります。 正しい解釈は、ウォークによって頂点 (2) に直接移動するため、出力は (1) になるということです。 

2 番目のエッジ ケースは、より大きなグラフ内のターゲットへの直接エッジです。 考慮する```
3
0 0
1 0
5000 5000
2
1 2
1 3
```頂点 (1) から開始して、歩行は確率 (1/2) で頂点 (3) に到達し、確率 (1/2) で頂点 (2) に移動し、そこから頂点 (1) に戻らなければなりません。 期待値は (3) です。 
[
 E_1=1+\frac12E_2,\qquad E_2=1+E_1,
 】
 したがって (E_1=3)。 よくある間違いは、ターゲットを削除した後に一時遷移確率を正規化してしまうことです。 これにより、誤って頂点 (1) が確率 (1) で頂点 (2) に移動しますが、元のウォークでは依然として元のすべての近傍の中から選択されます。 

3 番目のエッジ ケースは、ターゲットに入射するエッジが多数あるグラフです。 これらのエッジは、ターゲットに到達する真の可能性を表すため、他のエンドポイントの度合いに影響を与えます。 それらは、たとえ過渡状態遷移行列から消えても、遷移確率に使用される次数に残らなければなりません。 

## アプローチ

 最も直接的なアプローチは、すべての頂点に対して最初のステップの方程式を記述することです。 (E_v) を (v) から (n) に到達するまでの予想残り時間をとします。 次に (E_n=0)、1 つおきの頂点について
 [
 E_v=1+\frac{1}{\deg(v)}\sum_{u\sim v}E_u。 
】
 (E_n=0) を固定すると、これは (n-1) 個の未知数を持つ線形システムになります。 

このシステムは数学的には完璧ですが、通常の密ガウス消去法では (\Theta(n^3)) の算術演算が実行されます。 削除更新数だけでもおおよそ
 [
 \sum_{k=0}^{n-2}(n-k-1)^2
 =\frac{(n-1)(n-2)(2n-3)}6,
 】
 これは、(n=3000) の場合、約 (9\times10^9) 更新されます。 スパース入力では消去によるフィルインが生じるため、単純な実装は保存されません。 強引な線形システム定式化は、正確性を理解するのに役立ちますが、グラフ構造を十分に活用していません。 

意図した解決策を解く観察は、期待を直接求めるのをやめるということです。 非負の整数値の確率変数 (T) の場合、
 [
 E[T]=\sum_{i\ge0}\Pr(T>i)。 
】
 (S_i=\Pr(T>i)) とします。 1 つの期待値を解決する代わりに、シーケンス (S_i) の最初の (2(n-1)) 値を生成します。 

ターゲット頂点 (n) を状態空間から削除しますが、元の次数は変更しません。 (f_i(v)) を、正確に (i) 移動した後、歩行者が一時的な頂点 (v) にいて、(n) を一度も訪れたことがない確率とします。 遷移は直線的です。 
[
 f_{i+1}(v)=\sum_{u\sim v,\ u\ne n}\frac{f_i(u)}{\deg(u)}。 
】
 生存確率は単純に
 [
 S_i=\sum_{v\ne n}f_i(v)。 
】

 過渡状態は (n-1) 個しかないため、これは繰り返し適用される固定線形変換です。 ケイリー・ハミルトンの定理によれば、((n-1)\times(n-1)) 行列のべき乗から得られるすべてのシーケンスは、最大で次数 (n-1) の線形漸化式を満たします。 したがって、(S_i) もこのような漸化式を満たします。 Berlekamp-Massey は、最初の (2(n-1)) 項から最短の再発を回復できます。 標準 (2N) 項境界は、この本来なら無限のシーケンスの有限のプレフィックスのみが必要なまさにその理由です。 

最後に、漸化式により、それ以上の項を生成することなく無限和が得られます。 もし
 [
 C(x)=c_0+c_1x+\cdots+c_Lx^L
 】
 は Berlekamp-Massey によって返される接続多項式です。 
[
 F(x)=\sum_{i\ge0}S_ix^i
 】
 (F(x)C(x)=R(x)) を満たします。ここで、(R) の次数は (L) よりも小さいです。 したがって、
 [
 F(1)=\frac{R(1)}{C(1)}。 
】
 これは、まさにこの問題の既知の解決策で使用されている技術です。 平面グラフ境界 (m=O(n)) では、すべての項の生成に (O(nm)=O(n^2)) の演算がかかりますが、Berlekamp-Massey では (O(n^2)) がかかります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^3)) | (O(n^2)) | 遅すぎる |
 | 最適 | (O(nm+n^2)=O(n^2)) | (O(n+m)) | 承認済み |

 ## アルゴリズムのチュートリアル

1. グラフを読み取り、すべての頂点の元の次数を計算します。 これらのエッジはランダム ウォークによって実際に選択されたものであるため、次数には頂点 (n) に直接向かうエッジが含まれている必要があります。 
2. 過渡状態空間から頂点 (n) を削除します。 2 つの端点が (n) と異なるすべてのエッジを保存します。 このようなエッジは両方向の遷移に寄与します。 (n) に付随するエッジは、そのうちの 1 つを取るとプロセスが終了するため、一時的な遷移として保存されません。 
3. すべての過渡頂点次数のモジュラー逆数を計算します。 (u) における現在の確率が (f(u)) である場合、各近傍に寄与する量は (f(u)/\deg(u)) となります。 すべての除算はモジュロ (998244353) で実行されます。 
4. (f_0(1)=1) および他のすべての過渡確率をゼロに初期化します。 その結果、(S_0=1) となります。これは、歩行の歩数がゼロであり、確かに (n) に到達していないためです。 
5. 過渡遷移行列を繰り返し適用して (S_1,S_2,\ldots,S_{2N-1}) を生成します (N=n-1)。 内部エッジ ((u,v)) の場合、次の確率は (v) で (f(u)/\deg(u)) を受け取り、(u) で (f(v)/\deg(v)) を受け取ります。 したがって、すべての無向エッジを 1 回処理すると、両方の有向遷移が実行されます。 
6. 結果のシーケンスに Berlekamp-Massey を適用します。 を満たす係数 (C_0,\ldots,C_L) を返します。 
[
 \sum_{j=0}^{L}C_jS_{i-j}=0
 】
 (C_0=1) で (i\ge L) ごとに。 再発の次数は最大 (N) であるため、無限再発を決定するには (2N) 項で十分です。 
7. 定義する
 [
 F(x)=\sum_{i\ge0}S_ix^i,\qquad
 C(x)=\sum_{j=0}^{L}C_jx^j。 
】
 それらを乗算すると、
 [
 F(x)C(x)=R(x)、
 】
 ここで、(x^L) 以降の係数は正確に漸化式であるため、消滅します。 したがって、(R) の次数は最大でも (L-1) です。 
8. (x=1) で評価します。 (F(1)=E[T]) なので、
 [
 E[T]=\frac{R(1)}{C(1)}。 
】
 分子は (S_i) のプレフィックスの合計から計算できます。 
[
 R(1)=
 \sum_{j=0}^{L-1}C_j
 \left(\sum_{k=0}^{L-1-j}S_k\right)。 
】
 分母は単純に
 [
 C(1)=\sum_{j=0}^{L}C_j。 
】
 9. 分子に (C(1)) の逆モジュラーを乗算し、結果を出力します。 問題のモジュラー分数の解釈により、この逆数が指定されたテストに対して定義されることが保証されます。 

### なぜ効果があるのか

 重要な不変条件は、(i) がターゲットを訪問せずに移動した後、ターゲット以外の各頂点に存在する確率が (f_i) に正確に含まれていることです。 すべての元の選択には確率 (1/\deg(u)) があるため、遷移ではその意味が保持されますが、(n) への遷移は生き残る確率集合から単純に省略されます。 したがって、(S_i=\sum_v f_i(v)) は正確に (\Pr(T>i)) になります。 

過渡遷移は、固定行列 (M) による乗算です。 Cayley-Hamilton は、(M) を消滅させる最大次数 (N=n-1) の多項式を与えるため、(S_i) を含む (M^i) から得られるすべてのスカラー列は最大次数 (N) の漸化式を満たします。 Berlekamp-Massey は (2N) 項からその漸化式を回復します。 再帰性が判明すると、(F(x)C(x)) には最初の (L) 係数のみが含まれるため、(x=1) で有理母関数を評価すると、すべての生存確率の無限和が得られ、これがまさに予想されるヒット時間になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def berlekamp_massey(s):
    # C[0] = 1 and
    # sum(C[i] * s[n-i]) = 0
    # for all sufficiently large n.
    C = [1]
    B = [1]

    L = 0
    m = 1
    b = 1

    for n in range(len(s)):
        d = s[n]
        for i in range(1, L + 1):
            d = (d + C[i] * s[n - i]) % MOD

        if d == 0:
            m += 1
            continue

        old_C = C[:]
        coef = d * pow(b, MOD - 2, MOD) % MOD

        need = m + len(B)
        if len(C) < need:
            C.extend([0] * (need - len(C)))

        for i in range(len(B)):
            C[i + m] = (C[i + m] - coef * B[i]) % MOD

        if 2 * L <= n:
            L = n + 1 - L
            B = old_C
            b = d
            m = 1
        else:
            m += 1

    return C[:L + 1]

def solve():
    n = int(input())

    # Coordinates only describe the plane embedding.
    for _ in range(n):
        input()

    m = int(input())

    target = n - 1
    deg = [0] * n
    internal_edges = []

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1

        if u != target:
            deg[u] += 1
        if v != target:
            deg[v] += 1

        if u != target and v != target:
            internal_edges.append((u, v))

    inv_deg = [0] * (n - 1)
    for v in range(n - 1):
        inv_deg[v] = pow(deg[v], MOD - 2, MOD)

    N = n - 1
    terms = [1]

    # f[v] is the probability of being at v without
    # having visited the target.
    f = [0] * N
    f[0] = 1

    # We need 2N terms: S_0 ... S_{2N-1}.
    for _ in range(1, 2 * N):
        scaled = [0] * N
        for v in range(N):
            scaled[v] = f[v] * inv_deg[v] % MOD

        nxt = [0] * N

        # Each undirected internal edge represents two
        # possible directed transitions.
        for u, v in internal_edges:
            x = nxt[u] + scaled[v]
            if x >= MOD:
                x -= MOD
            nxt[u] = x

            x = nxt[v] + scaled[u]
            if x >= MOD:
                x -= MOD
            nxt[v] = x

        total = 0
        for v in range(N):
            total += nxt[v]
            if total >= MOD:
                total -= MOD

        terms.append(total)
        f = nxt

    C = berlekamp_massey(terms)
    L = len(C) - 1

    # prefix[i] = S_0 + ... + S_i
    prefix = [0] * len(terms)
    cur = 0
    for i, x in enumerate(terms):
        cur += x
        if cur >= MOD:
            cur -= MOD
        prefix[i] = cur

    # R(1) = sum_{j=0}^{L-1} C[j] *
    #              (S_0 + ... + S_{L-1-j})
    numerator = 0
    for j in range(L):
        numerator = (
            numerator + C[j] * prefix[L - 1 - j]
        ) % MOD

    denominator = sum(C) % MOD
    answer = numerator * pow(denominator, MOD - 2, MOD) % MOD

    print(answer)

if __name__ == "__main__":
    solve()
```入力パーサーは最初にすべての座標を読み取り、それらを破棄します。 これらはステートメントが平面グラフを記述するために必要ですが、ランダム ウォークは隣接性にのみ依存します。 

次数配列は、ターゲットが遷移システムから削除される前に計算されます。 これは、実装の中で最も微妙なグラフの詳細です。 エッジ (u-n) が存在する場合、エッジは決して寄与しないにもかかわらず、(\deg(u)) を増加させる必要があります。`nxt`なぜなら、そのエッジを選択することはまさに散歩を終わらせる出来事だからです。 

両方の端点が一時的なエッジのみが保存されます。 無向エッジ ((u,v)) を処理すると、両方が更新されます`nxt[u]`そして`nxt[v]`これにより、2 つの有向エッジを明示的に保存する場合と比較して、遷移ループがおよそ半分になります。 

確率ベクトルはモジュロに保たれます`MOD`すべての移行後。 実装では、代わりに条件付き減算を使用します。`% MOD`エッジの追加ごとに。 両方のオペランドはすでに範囲 ([0,\mathrm{MOD})) 内にあるため、1 回の減算で十分です。 

Berlekamp-Massey は、現在および以前の接続多項式のみを保存します。 したがって、この実装では、不必要なすべての中間多項式を保存するのではなく、(O(n)) 個のメモリが使用されます。 

最終的な母関数の計算には特別な注意が必要です。 (C(x)=\sum C_jx^j) の場合、(F(x)C(x)) の (x^k) の係数は次のようになります。 
[
 \sum_{j=0}^{k}C_jS_{k-j}。 
】
 (k\ge L) では消滅するため、(k<L) のみが (R(1)) に寄与します。 コード内の prefix-sum 式は、別の (O(L^2)) ネストされたループを使用する代わりに、これらすべての寄与を (O(L)) 時間で評価します。 

すべての値は剰余 (998244353) として減算されるため、数学的計算では整数のオーバーフローは発生しません。 Python の整数では、C++ に存在する固定幅のオーバーフローの問題も解消されますが、パフォーマンスのためには値を減らしておくことが依然として必要です。 

## 実用的な例

 ### サンプル 1

 グラフには頂点 (1) と (2) のみがあり、(2) がターゲットになります。 

| ステップ | (f(1)) | (S_i) | BM 状態 |
 | --- | --- | --- | --- |
 | (0) | (1) | (1) | イニシャル |

### サンプル 2

 グラフには 6 つの頂点があり、頂点 (6) がターゲットです。 過渡度は次のとおりです。

】

| ステップ | (f(1)) | (f(2)) | (f(3)) | (f(4)) | (f(5)) | (S_i) |

実際の期待値は、最初のステップの方程式から直接確認することもできます。 頂点 (i) からの予想時間を (E_i) と書くと、次のようになります。 
[
 E_1=1+\frac{E_2}{2}、
 】
 [
 E_2=1+\frac{E_1+E_3+E_4}{4}、
 】
 [
 E_3=1+\frac{E_2+E_4}{2}、
 】
 [
 E_4=1+\frac{E_2+E_3+E_5}{3}、
 】
 [
 E_5=1+\frac{E_4}{2}。 
】
 これを解くと (E_1=18/5) が得られます。 モデューロ (998244353)、
 [
 18\cdot5^{-1}\equiv798595486、
 】
 これはサンプル出力と一致します。 

BM ステージでは、(2(n-1)=10) 生存値の完全な接頭辞が使用され、シーケンスの再発が検索され、生成関数の評価は同じ (18/5) を返します。 このトレースは、すでに目標に達している確率が状態ベクトルから永久に消えなければならない理由を示しています。

(n\ge3)、(m\le3n-6) の単純な平面グラフの場合、(nm=O(n^2)) となります。 したがって、合計の複雑さは (O(n^2)) になります。 (n\le3000) の場合、これが問題の意図されたスケールですが、密なガウス消去には 3 次作業が必要になります。 平面グラフのスパース性は、まさに行列とベクトルの繰り返し乗算を実行可能な演算に変えるものです。
