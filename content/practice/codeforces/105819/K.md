 ## 解決策
 ## 問題の理解

 三角配列の最後の行しかわかっていません。 その上のすべての値は、その直下の 2 つの値の最小値として再帰的に定義されます。 

最後の行が$$b_1,b_2,\dots,b_n$$次に、その上の行に含まれる$$\min(b_1,b_2),\min(b_2,b_3),\dots$$そしてプロセスは上向きに続きます。 

タスクは、三角形全体を明示的に再構築することではありません。 必要なのは各行の合計だけです。 

再発をいくつかのレベルに拡大すると、有用な観察結果がすぐに現れます。 

ある行については、$k$最下位より上のレベルでは、各エントリは最下位行の連続セグメントの最小値になります。 より正確には、$$a_{i,j}=\min(b_j,b_{j+1},\dots,b_{j+n-i})$$したがって、行の合計は$i$は、長さを持つ最下行のすべての部分配列の最小値の正確な合計です。$$n-i+1.$$この問題は、すべての部分配列の長さについての計算と同等です。$L$、長さのすべての部分配列の最小値の合計$L$。 

制約$n \le 10^5$三角形の行を明示的に生成するアプローチは直ちに除外されます。 三角形の中に含まれるのは、$O(n^2)$およその値$5 \cdot 10^9$最悪の場合は細胞も。 

に近いものが必要です$O(n \log n)$または$O(n)$。 

よくある間違いの原因は、どの要素が部分配列の最小値とみなされるかを決定する際に、等しい値を誤って処理することです。 

考慮する：```
3
5 5 5
```すべてのサブ配列の最小値は 5 です。両方向で厳密な比較が使用される場合、一部のサブ配列は複数回カウントされます。 両方向で非厳密な比較を使用する場合、一部のサブ配列が失われます。 標準的な修正では、厳密な側と非厳密な側を 1 つずつ使用します。 

もう 1 つの簡単な間違いは、一番上の行がサブ配列の最長の長さに対応することを忘れていることです。 

例：```
3
1 2 3
```行の合計は次のとおりです。```
1
2
6
```一番上の行は配列全体の最小値であり、単一要素の最小値ではありません。 

## アプローチ

 直接シミュレーションは説明が簡単です。 

最後の行から開始して、隣接する最小値を取得して上の行を繰り返し構築します。 各行の長さには線形時間がかかります。 総作業量は、$$n+(n-1)+\cdots+1 = O(n^2).$$これは三角形の定義に正確に従っているため、正しいです。 残念ながら、$n=10^5$、大まかに必要になります$5 \cdot 10^9$操作。 

重要な観察は、すべての行が一番下の行の固定長部分配列の最小値に対応しているということです。 

させて$$S_L$$長さのすべての部分配列の最小値の合計になります$L$。 

その場合、必要な答えは次のとおりです。$$S_n,S_{n-1},\dots,S_1.$$ここで問題は、可能な長さごとに部分配列の最小値の合計を同時に計算することです。 

固定位置の場合$i$、 仮定する$b_i$は部分配列の代表的な最小値として選択されます。 

単調スタックを使用すると、次のことがわかります。$$A=i-\text{previous strictly smaller}$$そして$$B=\text{next smaller-or-equal}-i.$$それから$b_i$まさに最小値です$A \cdot B$サブアレイ。 

さらに重要なのは、サブ配列の長さごとに、そのようなサブ配列の数が非常に単純な形状を形成することです。$$1,2,3,\dots,x,x,\dots,x,\dots,3,2,1$$どこ$$x=\min(A,B).$$この区分的線形構造により、すべての長さを個別に変更するのではなく、範囲の更新による寄与を追加できます。 

2 つの差分配列を使用すると、次の区間にわたる線形関数を追加できます。$O(1)$要素ごとに。 すべての要素を処理した後、プレフィックス スイープによってすべての要素が再構築されます。$S_L$。 

ソリューション全体は線形時間で実行されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォーストライアングル構築 |$O(n^2)$|$O(n)$| 遅すぎる |
 | 単調スタック + 範囲線形更新 |$O(n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 一番下の行を読む$b$。 
2. 増加する単調スタックを使用して、すべての位置について以前の厳密に小さい要素を計算します。 
3. 別の単調スタックを使用して、すべての位置について次に小さいか等しい要素を計算します。 
4. ポジションごとに$i$、 させて$$A=i-\text{prevLess}[i]$$そして$$B=\text{nextLessEq}[i]-i.$$これらは、有効な左右の拡張子の数です。$b_i$選択された最小値として。 
5. しましょう$$x=\min(A,B), \quad y=\max(A,B).$$サブ配列の長さごとに、この要素によって寄与される数は次のとおりです。$$1,2,\dots,x,$$その後、価値の停滞期に入る$x$、

それから$$x-1,x-2,\dots,1.$$6. 投稿を追加する$b_i \cdot \text{count}$3 つの範囲更新を使用して、影響を受けるすべての長さに変換します。$$b_i \cdot L$$の上$[1,x]$、$$b_i \cdot x$$の上$[x+1,y]$、

そして$$b_i \cdot (A+B-L)$$の上$[y+1,A+B-1]$。 
7. 範囲の更新を、次の形式の関数を表す差分配列に保存します。$$p \cdot L + q.$$8. プレフィックス スイープを実行して、すべての状態を回復します。$S_L$。 
9. 出力$$S_n,S_{n-1},\dots,S_1,$$列があるので$i$ウィンドウの長さに対応します$n-i+1$。 

### なぜ効果があるのか

 単調スタックで使用される厳密/非厳密なタイブレーク規則により、各サブ配列には代表的な最小値が 1 つだけあります。 

固定要素の場合$b_i$、有効な左拡張子と右拡張子のすべての組み合わせにより、正確に 1 つの部分配列が生成されます。$b_i$は選択された最小値です。 特定の長さを生成する組み合わせの数は、次の条件のみに依存します。$A$そして$B$、上記の三角形-プラトー-三角形のパターンが得られます。 

このアルゴリズムは、すべての代表的な最小値の寄与を、それが属するすべての長さに追加します。 すべての部分配列は 1 回だけカウントされるため、結果の値は$S_L$は正確にすべての長さの最小値の合計です-$L$サブアレイ。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def add_linear(diff_a, diff_b, l, r, a, b):
    if l > r:
        return
    diff_a[l] += a
    diff_a[r + 1] -= a
    diff_b[l] += b
    diff_b[r + 1] -= b

n = int(input())
arr = list(map(int, input().split()))

prev_less = [-1] * n
stack = []
for i in range(n):
    while stack and arr[stack[-1]] >= arr[i]:
        stack.pop()
    prev_less[i] = stack[-1] if stack else -1
    stack.append(i)

next_less_eq = [n] * n
stack = []
for i in range(n - 1, -1, -1):
    while stack and arr[stack[-1]] > arr[i]:
        stack.pop()
    next_less_eq[i] = stack[-1] if stack else n
    stack.append(i)

diff_a = [0] * (n + 3)
diff_b = [0] * (n + 3)

for i, v in enumerate(arr):
    A = i - prev_less[i]
    B = next_less_eq[i] - i

    x = min(A, B)
    y = max(A, B)

    add_linear(diff_a, diff_b, 1, x, v, 0)

    add_linear(diff_a, diff_b, x + 1, y, 0, v * x)

    add_linear(
        diff_a,
        diff_b,
        y + 1,
        A + B - 1,
        -v,
        v * (A + B)
    )

sums = [0] * (n + 1)

cur_a = 0
cur_b = 0

for length in range(1, n + 1):
    cur_a += diff_a[length]
    cur_b += diff_b[length]
    sums[length] = cur_a * length + cur_b

ans = [str(sums[length]) for length in range(n, 0, -1)]
print(" ".join(ans))
```最初のスタックは、以前の厳密に小さい要素を計算します。 等しい値は削除されるため、部分配列の一意の所有権ルールが保証されます。 

2 番目のスタックは、次に小さいか等しい要素を計算します。 逆の不等式を使用すると、等しい値が現れた場合の二重カウントを防ぐことができます。 

ヘルパーさん`add_linear`フォームの関数の範囲更新を実行します$$a \cdot L + b.$$すべての更新が記録された後、単一のプレフィックス パスが各長さの実際の寄与を再構築します。 

最後の逆転が大事。 長さ$n$一番上の行の長さに対応します$1$一番下の行に相当します。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n = int(input())
    arr = list(map(int, input().split()))

    prev_less = [-1] * n
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] >= arr[i]:
            stack.pop()
        prev_less[i] = stack[-1] if stack else -1
        stack.append(i)

    next_less_eq = [n] * n
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and arr[stack[-1]] > arr[i]:
            stack.pop()
        next_less_eq[i] = stack[-1] if stack else n
        stack.append(i)

    da = [0] * (n + 3)
    db = [0] * (n + 3)

    def add(l, r, a, b):
        if l > r:
            return
        da[l] += a
        da[r + 1] -= a
        db[l] += b
        db[r + 1] -= b

    for i, v in enumerate(arr):
        A = i - prev_less[i]
        B = next_less_eq[i] - i

        x = min(A, B)
        y = max(A, B)

        add(1, x, v, 0)
        add(x + 1, y, 0, v * x)
        add(y + 1, A + B - 1, -v, v * (A + B))

    cur_a = cur_b = 0
    res = [0] * (n + 1)

    for L in range(1, n + 1):
        cur_a += da[L]
        cur_b += db[L]
        res[L] = cur_a * L + cur_b

    return " ".join(str(res[L]) for L in range(n, 0, -1))

 ## 特殊なケース

 次のことを考慮してください。```
3
5 5 5
```以前のレススタックは厳密な境界を使用し、次の境界は非厳密です。 中央のサブ配列`[5,5]`両方ではなく、正確に 1 つの位置に割り当てられます。 アルゴリズムにより次のものが生成されます。```
5 10 15
```これは実際の行の合計と一致します。 

考慮する：```
3
1 2 3
```一番上の行は配列全体の最小値に対応します。```
[1]
```単一の下部要素ではありません。 計算された長さの合計は次のとおりです。```
L=1 -> 6
L=2 -> 2
L=3 -> 1
```出力は次のようになります。```
1 2 6
```これはまさに上から下への行合計のシーケンスです。 

考慮する：```
4
4 3 2 1
```長いサブ配列はすべて右端に最小値を持ちます。 単調スタックでも正しいスパンが得られます。```
length 1 -> 10
length 2 -> 6
length 3 -> 3
length 4 -> 1
```出力は次のとおりです。```
1 3 6 10
```非常に不均衡なスパンが区分線形寄与公式によって正しく処理されることを示しています。
