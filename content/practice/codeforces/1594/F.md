 ## 解決策
 ## 問題の理解

 農場が以下のものであるかどうかを判断するように求められます。`s`動物と`n`ペンは「理想的」です。 農場は、動物がどのように檻を空けずに檻全体に分散されているかに関係なく、正確に含まれる檻の連続したセグメントが存在する場合に理想的です。`k`動物。 複数のテスト ケースが与えられ、それぞれが指定されています。`s`、`n`、 そして`k`。 

エンティティを具体的な言葉で言い換えると、`n`ペンは一列に並べられた箱の形をしており、`s`動物を同じボールとしてこれらのボックスに置きます。 すべてのボックスには少なくとも 1 つのボールが入っていなければなりません。 重要なのは、理想的であるという性質は普遍的であるということです。この性質は、ボックス内へのボールの有効な配分すべてに当てはまらなければなりません。 

制約は大きいです:`s`、`n`、 そして`k`最大 10^18、最大 10^5 のテスト ケースを使用できます。 これにより、分布またはセグメントを明示的に列挙するアルゴリズムは除外されます。これは、1 回の総当り攻撃でも天文学的に遅いためです。 

明らかではないエッジケースが現れるのは、`k`～に比べて非常に小さい、または非常に大きい`n`そして`s`。 たとえば、次の場合`s = 1`、`n = 1`、`k = 2`、唯一の配布は`[1]`そして、合計する連続セグメントはありません。`2`。 不用意に実装すると、いつでもすべての単一ペン ファームが理想的であると想定される可能性があります。`k <= s`、しかしそれは間違いです。 別の微妙なケースが発生する場合`s`の倍数です`n`そして`k`間にあります`n`そして`s`一部のディストリビューションでは合計を含むセグメントの生成をスキップできる方法で`k`。 このような極端なケースを理解することが重要です。 

## アプローチ

 単純なアプローチでは、すべての有効な分布を生成しようとします。`s`動物を中へ`n`ペンを押して、合計する連続セグメントを確認します。`k`。 分布の数はおおよその組み合わせになります。`C(s-1, n-1)`、これは完全に不可能です`s`そして`n`最大 10^18。 各ディストリビューションのプレフィックス合計に制限するだけでも大きすぎます。`n`ディストリビューションごとのセグメント、および`n`それ自体は 10^18 に達する可能性があります。 

重要な洞察は、農場の理想的な特性がモジュラー算術問題として言い換えられるということです。 各ペンに少なくとも 1 匹の動物がいるとします。 させて`r = s - n`各囲いに一匹ずつ入れた後の「追加の」動物の数になります。 したがって、任意のディストリビューションはパーティショニングに対応します。`r`追加の動物を`n`ペン、および各連続セグメントの合計は次のように書くことができます。`length_of_segment + sum_of_extras_in_segment`。 

ファームはすべてのディストリビューションにとって理想的である必要があるため、`k`**到達不能になることはありません** モジュロ`n`。 具体的に定義すると、`r = s - n`。 農場は次のような場合に理想的です`k % n <= r`。 これは、任意の長さのセグメントの最小合計が`l`は`l`、最大合計は`l + r`。 剰余がある場合`n`それを超える`r`、一部のディストリビューションは、合計するセグメントの生成をスキップします。`k`。 

これにより、問題はテスト ケースごとの一定時間のチェックに軽減されます。

 ## アルゴリズムのチュートリアル

 1.読む`s`、`n`、 そして`k`テストケース用。 コンピューティング`r = s - n`。 これは、各囲いに 1 匹を配置した後に自由に分配できる動物の数を表します。 
2. コンピューティング`k % n`。 これをそのままにしておきます`rem`。 これは、最小合計に対する目的のセグメント合計の「オフセット」を表します。`n`。 
3. 比較する`rem`に`r`。 もし`rem <= r`の場合、連続するセグメントの合計が正確に一致するように動物の分布を選択することができます。`k`あらゆる可能な分布に対応します。 それ以外の場合は、合計を持つ連続セグメントが存在する分布が存在します。`k`不可能です。 
4. 次の場合は「YES」と印刷します。`rem <= r`それ以外の場合は「NO」です。 

なぜ機能するのか: 空のペンを持たない分布は、次のような分布で表すことができます。`r`追加の動物を囲いの中で任意に追加できます。 セグメント合計`k`の残りの場合にのみ達成可能です。`k`モジュロ`n`追加動物の合計を超えない`r`。 この不変式は、セグメントに沿って動物を分布させる際に可能な最大の「柔軟性」を捕捉するため、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        s, n, k = map(int, input().split())
        r = s - n
        if k % n <= r:
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```私たちが使用するのは`sys.stdin.readline`最大 10^5 のテスト ケースを効率的に処理します。 コアチェック`k % n <= r`モジュール推論を直接実装します。 引き算`s - n`慎重に行わなければならないので、`s`そして`n`は非常に大きくなる可能性がありますが、Python は大きな整数を自動的に処理します。
