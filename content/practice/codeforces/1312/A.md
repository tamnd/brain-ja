 ## アルゴリズムのチュートリアル

 周期対称性を使用して、幾何学的条件を数論的な条件に変換します。 

1. 整数の読み取り$n$そして$m$。 これらは、完全なサイクル長と必要なサブシーケンス サイクル長を表します。 
2. コンピューティング$g = \gcd(n, m)$。 これは、同じ円に埋め込まれたときに 2 つのサイクル サイズがどのように相互作用するかを示しています。 
3. かどうかを確認します。$\frac{n}{g} = m$。 この条件により、頂点を等しい増分でステップスルーすることで正確に生成されることが保証されます。$m$繰り返す前に別の位置に移動します。 
4. 条件が成立する場合は「YES」を出力し、成立しない場合は「NO」を出力します。 

ステップ 3 で十分な理由は、有効な選択はすべて、次の循環サブグループに対応する必要があるためです。$n$-gon の回転対称グループとサブグループのサイズは、gcd 構造によって完全に決定されます。 

### なぜ効果があるのか

 正規の頂点$n$-gon は回転下で循環グループを形成します。 どれも定期的$m$同じ中心に揃えられた -gon は、正確に後に閉じる回転のサブグループの選択に対応する必要があります。$m$ステップ。 順序の循環群で可能な唯一のサブグループ サイズ$n$の約数に対応する$n$、ステップ サイズによってジェネレーターが決まります。 gcd 条件により、誘導サイクル長が正確に一致することが保証されます。$m$、早期の繰り返しや不完全な適用を防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    g = gcd(n, m)
    if n // g == m:
        print("YES")
    else:
        print("NO")
```実装は、派生条件を直接変換したものです。 gcd 計算により、頂点セットの基本的な周期構造が分離されます。 次に、整数除算によって、誘導されたサイクル長がターゲットのポリゴン サイズと一致するかどうかがチェックされます。 

唯一の微妙な点は、確実に比較することです$n // gcd(n, m)$単純な可分性では、回転構造がまだ整列していないケースを見逃すため、可分性のみに依存するのではありません。

## テストケース```python
import sys, io
from math import gcd

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        g = gcd(n, m)
        out.append("YES" if n // g == m else "NO")
    return "\n".join(out)

# provided samples

# divisible but invalid structure

 ## 特殊なケース

 いつ$m = 3$、多くの構成は視覚的に可能であるように見えますが、ステップ構造が 3 回移動した後に正確に閉じない限り、循環位置合わせは依然として失敗します。 例えば、$n = 7, m = 3$3 が「視覚的に適合する」ほど十分小さい場合でも、失敗します。 

いつ$n$は均等であり、$m = n/2$の場合、2 つおきの頂点を取ると正多角形が形成されるため、答えは常に YES です。 これは最も単純で自明ではない循環サブグループのケースであり、実装の適切な健全性チェックとして機能します。
