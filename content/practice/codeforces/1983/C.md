 ## 解決策
 ## 問題の理解

 直線状のケーキを分割するように求められています。`n`アリス、ボブ、チャーリーの間でピース。 それぞれのピースの価値は人それぞれ異なりますが、すべてのピースの合計価値は誰にとっても同じです。 課題は、ピースが共有されないように連続したスライスを各人に割り当て、各人のスライスがケーキの総額の少なくとも 3 分の 1 に達するようにすることです。 出力は各人のスライスの開始インデックスと終了インデックスである必要があります。`-1`そのような部門が存在しない場合。 

の制約`n`テスト ケースごとに最大 200,000、すべての合計`n`テスト ケース全体の上限も 200,000 です。 2 秒の時間制限があるため、サブ配列の可能なすべてのトリプレットを明示的に考慮するソリューションには、最大で`O(n^3)`実行不可能な操作。 本質的に線形なソリューションが必要です。`n`テストケースごとに。 エッジケースには、単一のピースがすでに合計値の 3 分の 1 を超えているケーキ、連続した割り当てが機能する統一された値のケーキ、および合計要件を満たすために最後のピースを誰かに強制する必要があるケーキが含まれます。 常に最初の 3 番目を盲目的に試行する単純な実装は、配列の最後に大きな値が集まっている場合に失敗する可能性があります。 

## アプローチ

 ブルートフォース手法では、重複しない 3 つのサブ配列の可能なすべての組み合わせを試行し、それらの合計をチェックします。 これは原理的には正しいですが、最悪の場合は複雑になります。`O(n^3)`、それは不可能です`n`20万件。 

重要な洞察は、各人のスライスがしきい値に達するだけで十分であり、プレフィックスの合計を使用して貪欲にスキャンできるということです。 アリスのクォータに達する最小限のサブ配列を特定したら、残りのケーキをボブの新しい配列として扱うことができます。 プレフィックス合計を使用すると、任意の左境界に対する最小の右境界を効率的に見つけることができ、各スライスの検索をネストされたループではなく線形スキャンに効果的に削減できます。 人物を順番に (アリス、ボブ、チャーリー) 処理し、累積合計を維持することで、3 つすべてを満たす最初の有効な分割を決定できます。 

これにより、問題は次のように変換されます。`O(n^3)`リニアスキャンへ`O(n)`テストケースごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | プレフィックスの合計に貪欲 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. アリス、ボブ、チャーリーのプレフィックスの合計を個別に計算します。 これにより、連続した部分配列の合計を計算できるようになります。`O(1)`としての時間`prefix[r] - prefix[l-1]`。 
2. 各人の閾値を次のように計算します。`ceil(total / 3)`。 これは、各サブ配列が到達する必要がある最小合計です。 
3. ケーキの左側から始めて、アリスの最小のスライスを見つけます。 前方にスキャンし、プレフィックスの合計を使用して最初の`r_a`インデックスからの合計が`1`に`r_a`というのは、アリスは閾値に達しているからだ。 
4. ボブの場合、アリスのスライスの直後にスキャンを開始します (`r_a + 1`）。 プレフィックスの合計を使用して、ボブのしきい値に達する最小の連続部分配列を見つけます。結果は次のようになります。`r_b`。 
5. 残ったケーキは自動的にチャーリーに送られます。 チャーリーのスライスの合計が次の値であるかどうかを確認します。`r_b + 1`に`n`彼の閾値を満たしています。 存在する場合はインデックスを返します`(1, r_a, r_a+1, r_b, r_b+1, n)`。 
6. いずれかの時点で、アリスまたはボブが残りのピースでしきい値に到達できない場合、出力`-1`。 

機能する理由: 貪欲スキャンが有効なのは、アリス、次にボブに対して最小限のスライスが選択されると、総和が等しいため、チャーリーに残ったスライスがしきい値を満たさなければならないためです。 常にしきい値を満たす最小限のサブ配列を選択することで、オーバーシュートや後続の人々に不十分なケーキを残すことを回避します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        c = list(map(int, input().split()))
        
        total = sum(a)
        threshold = (total + 2) // 3  # ceiling division
        
        # prefix sums
        pa = [0]*(n+1)
        pb = [0]*(n+1)
        pc = [0]*(n+1)
        for i in range(n):
            pa[i+1] = pa[i] + a[i]
            pb[i+1] = pb[i] + b[i]
            pc[i+1] = pc[i] + c[i]

        # find Alice slice
        r_a = -1
        for i in range(1, n+1):
            if pa[i] >= threshold:
                r_a = i
                break
        if r_a == -1:
            print(-1)
            continue

        # find Bob slice
        r_b = -1
        for i in range(r_a+1, n+1):
            if pb[i] - pb[r_a] >= threshold:
                r_b = i
                break
        if r_b == -1:
            print(-1)
            continue

        # check Charlie slice
        sum_charlie = pc[n] - pc[r_b]
        if sum_charlie < threshold:
            print(-1)
            continue

        print(1, r_a, r_a+1, r_b, r_b+1, n)

solve()
```このコードでは、迅速な合計計算のためにプレフィックス合計を使用します。 の`r_a`ループは、アリスの最初の有効な部分配列を見つけます。 の`r_b`ループは、アリスのスライスの直後にあるボブの次の有効な部分配列を見つけます。 残りのインデックスは自動的に Charlie に属します。 エッジケースはチェックによって処理されます`-1`しきい値に到達できない場合。
