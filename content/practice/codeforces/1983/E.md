 ## 解決策
 ## 問題の理解

 ボールは2種類あります。 最初`k`ボールは特別です、残りは`n-k`普通です。 すべてのボールには価値があります。 

ボールは均一にランダムな順序で 1 つずつ取り除かれます。 現在のプレーヤーは選択したボールを受け取り、その値をスコアに追加します。 興味深いルールは、次に何が起こるかです。 

選んだボールが普通の場合は他のプレイヤーにターンが移ります。 

選択したボールが特別な場合は、同じプレーヤーがすぐにもう一度プレーします。 

アリスが始まります。 

アリスの予想される最終スコアとボブの予想される最終スコアが必要です。 答えは有理数なので、それを剰余として出力します。`10^9+7`モジュラーインバースを使用します。 

すべてのテスト ケースにわたるボールの合計数は最大で`5 · 10^5`。 部分集合にわたる順列、ゲーム状態、または確率分布を列挙しようとするアルゴリズムは絶望的です。 平`O(n^2)`最悪の場合、テスト ケースごとにコストがかかりすぎる可能性があります。 ボールの数が本質的に線形になるものが必要です。 

主な危険は、すべてのボールに確率があると仮定することです`1/2`アリスに所属していること。 それは誤りです。なぜなら、ターンが変わるのは通常のボールを取ったときだけだからです。 

考慮する：```
n = 2, k = 1
special value = 10
ordinary value = 20
```考えられる順序は次の 2 つです。```
S N
```アリスは両方のボールを獲得します。```
N S
```アリスは普通のボールしかもらえません。 

アリスの予想スコアは`25`、 ない`(10+20)/2 = 15`。 

もう 1 つの簡単な間違いは、特別なボールと通常のボールを同じように扱うことです。 それらの所有確率は異なります。 

例えば：```
n = 3, k = 1
values = [100, 1, 1]
```特別なボールは通常のボールよりもアリスのものである可能性がはるかに高くなります。 すべてのボールに対して単一の確率を計算するソリューションでは、誤った期待が生じます。 

ケース`k = n`も特別です。 普通のボールは存在しないため、順番が変わることはなく、アリスはすべてのボールを確率で受け取ります。`1`。 

## アプローチ

 強引な解決策では、考えられるすべての順序のボールが生成されます。 順列ごとにゲームをシミュレートし、結果のスコアを計算し、すべての順列の平均を計算できます。 

すべての削除命令の可能性が等しいため、これは正しいです。 問題は状態空間のサイズです。 がある`n!`可能な注文。 たとえ`n = 15`、これはすでに 1 兆を超える順列になります。 

重要な観察は、期待値が線形であるということです。 

スコア分布全体を尋ねる代わりに、はるかに小さな質問をすることができます。 

「特定のボールがアリスのものである確率はどれくらいですか?」

 その確率がわかっていれば、ボールは貢献します```
value × probability
```アリスの予想スコアに。 

すべてのスペシャル ボールは対称です。 普通のボールはすべて対称です。 したがって、必要なのは 2 つの確率だけです。```
pS = probability a specific special ball belongs to Alice
pN = probability a specific ordinary ball belongs to Alice
```これらが分かれば、```
Alice =
pS × (sum of special values)
+
pN × (sum of ordinary values)
```そしてボブは残りの期待値を受け取ります。 

残りのタスクは純粋に組み合わせです。 

重要な単純化は、特別なボールが誰の順番になるかは決して変わらないということです。 オルタネーションを引き起こすのは普通のボールのみです。 通常のボールの順序だけを見ると、アリスが 1 番目のボールを所有し、ボブが 2 番目のボールを所有し、アリスが 3 番目のボールを所有する、というようになります。 

特殊なボールは、通常のボールによって生じる隙間に挿入されるだけです。 

これにより、ゲーム全体がギャップとランクをカウントするようになり、線形時間のソリューションが得られます。

 ## アルゴリズムのチュートリアル

 しましょう```
m = n - k
```普通のボールの数になります。 

### スペシャルボールの確率

 特殊なボールをすべて取り外して、ボールだけを保持することを想像してください。`m`普通のボール。 

彼らは正確に作成します`m + 1`ギャップ:```
before first ordinary
between ordinary 1 and 2
between ordinary 2 and 3
...
after last ordinary
```普通のボールを取るたびに、プレーヤーのアイデンティティが変わります。 

したがって、ギャップの所有権は交互になります。```
Alice, Bob, Alice, Bob, ...
```特別なボールを 1 つ取りましょう。 

普通のボール間の相対的な位置は、その前に普通のボールが何個出現するかによってのみ決まります。 この数値は次のいずれかの値になります。`0`に`m`。 

対称性により、すべて`m + 1`可能性も同様にあります。 

したがって、特別なボールは、ギャップの間で均一にギャップを選択します。`m + 1`ギャップ。 

アリスが所有する```
ceil((m + 1) / 2)
```それらのギャップの。 

したがって```
pS = ceil((m + 1) / 2) / (m + 1)
```### 普通のボールの確率

 特定の普通のボールを考えてみましょう。 

その中で、`m`通常のボールの場合、そのランクは以下のいずれかの値になる可能性が等しくなります。`1`に`m`。 

1番目の普通のボールはアリスのものです。 

2番目はボブのものです。 

3番目はアリスのものです。 

等々。 

アリスはまさに奇数のランクを所有しています。 

奇数ランクの数は```
ceil(m / 2)
```したがって```
pN = ceil(m / 2) / m
```いつ`m > 0`。 

### 期待値の計算

 しましょう```
special_sum = sum of first k values
ordinary_sum = sum of remaining values
```それから```
Alice =
special_sum × pS
+
ordinary_sum × pN
```すべての算術はモジュロで実行されます`10^9+7`。 

ボブは残りの期待値を受け取ります。```
Bob =
(total_sum - Alice)
```### なぜ効果があるのか

 ボールの所有権は、そのボールの前に現れる普通のボールの数にのみ依存します。 特別なボールはターンパリティを決して変更しません。 

特別なボールの場合、唯一関連する量は、それが着地する通常のボール間のギャップです。 すべてのギャップは同様に発生する可能性があり、ギャップの所有権は交互に変化します。 

通常のボールの場合、唯一の関連数量は、通常のボールの中でのそのランクです。 すべてのランクは同様の確率であり、所有権はランクの同等性によって交互に切り替わります。 

期待値は線形であるため、合計値にすべてのボールの所有確率を乗算すると、正確な期待スコアが得られます。 対称性により、計算はすべての特別なボールに対して 1 つの確率と、すべての通常のボールに対して 1 つの確率に削減されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

t = int(input())

for _ in range(t):
    n, k = map(int, input().split())
    v = list(map(int, input().split()))

    m = n - k

    special_sum = sum(v[:k]) % MOD
    ordinary_sum = sum(v[k:]) % MOD

    if m == 0:
        alice = special_sum
        bob = 0
        print(alice, bob)
        continue

    pS = ((m + 2) // 2) * pow(m + 1, MOD - 2, MOD)
    pS %= MOD

    pN = ((m + 1) // 2) * pow(m, MOD - 2, MOD)
    pN %= MOD

    alice = (special_sum * pS + ordinary_sum * pN) % MOD

    total = (special_sum + ordinary_sum) % MOD
    bob = (total - alice) % MOD

    print(alice, bob)
```最初のステップでは、すべてのスペシャル ボールとすべての普通ボールの合計値を個別に計算します。 

普通玉がない場合はターンは変わりません。 アリスはすべてを集めているので、答えはすぐにわかります。 

のために`m > 0`の場合、コードは上記で導出された 2 つの確率を評価します。 モジュロ算術による除算は、フェルマーの定理を使用して実装されます。```
x / y  ->  x * y^(MOD-2)
```アリスの期待スコアは、期待の線形性から直接計算されます。 

ボブの期待スコアは、合計値からアリスの期待値を引くことによって得られます。 これにより、確率計算の重複が回避され、2 つの期待値の合計が合計値となる不変式が自動的に保存されます。 

唯一の微妙なケースは、`m = 0`、 なぜなら`pN`ゼロ除算が必要になります。 その場合は別途処理されます。

 | 測定 | 複雑さ | 説明 |

| スペース |`O(1)`| 入力配列以外の変数はわずか数個だけ |

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 10**9 + 7

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n, k = map(int, input().split())
        v = list(map(int, input().split()))

        m = n - k

        ss = sum(v[:k]) % MOD
        sn = sum(v[k:]) % MOD

        if m == 0:
            out.append(f"{ss} 0")
            continue

        pS = ((m + 2) // 2) * pow(m + 1, MOD - 2, MOD) % MOD
        pN = ((m + 1) // 2) * pow(m, MOD - 2, MOD) % MOD

        alice = (ss * pS + sn * pN) % MOD
        bob = (ss + sn - alice) % MOD

        out.append(f"{alice} {bob}")

    return "\n".join(out)

# sample
assert run(
"""1
5 2
10 20 5 15 25
"""
) == "45 30"

# minimum size
assert run(
"""1
1 1
7
"""
) == "7 0"

# all balls special
assert run(
"""1
4 4
1 2 3 4
"""
) == "10 0"

# one special, one ordinary
assert run(
"""1
2 1
10 20
"""
) == "25 5"

# all values equal
assert run(
"""1
5 2
1 1 1 1 1
"""
) == "3 2"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 1 / 7`|`7 0`| 可能な最小のインスタンス |

 |`2 1 / 10 20`|`25 5`| 特別なボールと通常のボールの異なる確率 |

 ## 特殊なケース

 ### すべてのボールは特別です

 入力:```
1
4 4
1 2 3 4
```普通のボールはありません。 ターンは決して変わりません。 

アリスはすべてのボールを受け取ります。```
Alice = 10
Bob = 0
```実装では、モジュラー逆関数を計算する前にこれを処理します。 

### 普通のボール 1 つだけ

 入力:```
1
2 1
10 20
```通常のボールの前後に 1 つのギャップがあります。 

特別なボールは同じ確率でどちらかのギャップに着地します。```
pS = 1/2
pN = 1
```アリスの期待は次のようになります。```
10 × 1/2 + 20 × 1 = 25
```これは直接列挙に一致します。 

### 特殊なボールが多く、パリティには影響なし

 入力:```
1
5 4
10 10 10 10 100
```普通のボールは 1 つだけ存在します。 

4 つの特別なボールはすべて同じ確率を共有します。```
pS = 1/2
```スペシャルボールの数に関係なく。 ターン変化に影響を与えるのは普通玉のみであるため、導出は普通玉の数のみに依存する。 これはまさにアルゴリズムで使用されるプロパティです。 

### 普通のボールの偶数個と奇数個

 入力:```
1
3 1
100 1 1
```ここ`m = 2`。 

アリスは 3 つのギャップのうち 2 つを所有しており、```
pS = 2/3
```の代わりに`1/2`。 

すべての特別なボールがどちらかのプレーヤーに属する可能性が等しいと仮定する解決策は、この例では失敗します。 ギャップカウント引数は、より大きな確率を正しく生成します。
