 ## 解決策
 ## 問題の理解

 いくつかの飲み物が与えられますが、それぞれの飲み物には何パーセントかのオレンジジュースが含まれています。 Vasya は、すべての飲み物を同量ずつ混ぜて 1 つのカクテルを作ります。 

質問は簡単です。これらを混ぜた後、最終的なカクテルの何パーセントがオレンジジュースになりますか?

 入力には、飲み物の数と各飲み物のオレンジ ジュースの割合が含まれます。 出力は、混合物中のオレンジ ジュースの割合です。 

制約は非常に小さいです。 ドリンクの数は最大でも 100 なので、各割合を 1 回処理するアルゴリズムは即座に終了します。 不必要に複雑なシミュレーションであっても、制限内に問題なく収まります。 これは、課題はアルゴリズムの効率ではなく、同量の混合がパーセンテージにどのように影響するかを正しく理解することであることを意味します。 

よくある間違いは、実際の量を考えてシミュレーションすることです。 この問題では、それぞれの飲み物から何ミリリットルが摂取されるかはわかりません。 幸いなことに、どの飲み物からも同じ量が摂取されるため、この値は問題になりません。 最終的なパーセンテージは、単に個々のパーセンテージの平均です。 

飲み物によってはオレンジジュースがまったく含まれていない場合にも、微妙なケースが発生します。 

入力：```
2
0 100
```出力：```
50
```ゼロ値を無視したり、間違った量で除算したりする不注意な実装では、誤った結果が生成される可能性があります。 この混合物には、純粋なオレンジジュース飲料と何も含まない飲料が同量含まれているため、平均はちょうど 50% になります。 

もう 1 つのエッジ ケースは、すべての飲み物に 0% オレンジ ジュースが含まれている場合です。 

入力：```
3
0 0 0
```出力：```
0
```ゼロを平均してもゼロになるため、答えは有効のままです。 

同様に、すべての飲み物に 100% オレンジ ジュースが含まれている場合:

 入力:```
4
100 100 100 100
```出力：```
100
```混合物は純粋なオレンジジュースのままです。 

## アプローチ

 直接的な強引な解釈は、ヴァシャがすべての飲み物から一定量、たとえば100ミリリットルを摂取すると仮定することです。 各飲み物からオレンジ ジュースが何ミリリットル入るかを計算し、それらの量を合計し、カクテルの総量を計算し、最後に割ることができます。 

パーセンテージのあるドリンクの場合`p`、100ミリリットル摂取すると貢献します`p`オレンジジュースのミリリットル。 すべての飲み物を処理した後のオレンジジュースの割合は、$$\frac{\text{total orange juice}}{\text{total volume}} \times 100.$$このアプローチは物理的な混合プロセスに正確に従うため、正しいです。 その時間計算量は$O(n)$、各ドリンクが一度処理されるため。 

式を詳しく見てみると、もっと単純なことがわかります。 すべての飲み物から同じ量を摂取した場合、その量は分子と分母の両方に表示され、相殺されます。 残るのは、すべてのパーセンテージの算術平均だけです。$$\frac{p_1 + p_2 + \cdots + p_n}{n}.$$問題はすぐに平均化タスクになります。 すべての割合の合計を求めて、それを飲み物の数で割るだけです。 

ブルート フォース シミュレーションは、指定された制約に対してすでに十分な速度で実行されていますが、平均化観測により不必要な計算が削除され、基礎となる数学が直接表現されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、飲み物の数。 
2. を読んでください。`n`パーセント値。 
3. すべてのパーセンテージの合計を計算します。 
4. 合計を次の値で割ります。`n`平均パーセンテージを取得します。 
5. 結果を浮動小数点数として出力します。 

唯一の数学的観察は、すべての飲み物から同じ量が取られるということです。 すべての飲み物は同じ体積に寄与するため、最終濃度は元の濃度の平均に等しくなります。 

### なぜ効果があるのか

 Vasyaが取ると仮定します`x`各飲み物からミリリットル。 

飲む`i`貢献する$$x \cdot \frac{p_i}{100}$$純粋なオレンジジュースのミリリットル。 

オレンジジュースの総量は$$x \cdot \frac{p_1+p_2+\cdots+p_n}{100}.$$カクテルの総量は$$nx.$$最終的な割合は、$$\frac{x \cdot \frac{p_1+p_2+\cdots+p_n}{100}}{nx}\times100 = \frac{p_1+p_2+\cdots+p_n}{n}.$$アルゴリズムはこの量を正確に計算するため、常に正しいオレンジ ジュースの割合を返します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
p = list(map(int, input().split()))

answer = sum(p) / n
print(answer)
```最初の行にはドリンクの数が表示されます。 2 行目は、すべてのパーセンテージをリストに読み込みます。 

表現`sum(p)`すべての飲み物からの寄与率の合計を計算します。 で割る`n`算術平均が得られ、これが最終的なカクテル中のオレンジ ジュースの濃度となります。 

Python は、使用時に浮動小数点除算を自動的に実行します。`/`したがって、結果は必要な誤差許容範囲を十分に満たす精度で出力されます。 

難しい境界条件はありません。 値の範囲は 0 ～ 100 で、合計の最大値は 10,000 にすぎず、数値制限をはるかに下回ります。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    n = int(input())
    p = list(map(int, input().split()))
    print(sum(p) / n)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    global input
    input = sys.stdin.readline

    solve()

    out = sys.stdout.getvalue().strip()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert abs(float(run("3\n50 50 100\n")) - 66.666666666667) < 1e-6

# minimum size
assert abs(float(run("1\n0\n")) - 0.0) < 1e-6

# all equal values
assert abs(float(run("4\n25 25 25 25\n")) - 25.0) < 1e-6

# all maximum values
assert abs(float(run("5\n100 100 100 100 100\n")) - 100.0) < 1e-6

# mixture of extremes
assert abs(float(run("2\n0 100\n")) - 50.0) < 1e-6

# maximum n
assert abs(float(run("100\n" + " ".join(["100"] * 100) + "\n")) - 100.0) < 1e-6
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1 / 0`|`0`| 最小入力サイズ |
 |`4 / 25 25 25 25`|`25`| すべての値は等しい |
 |`5 / 100 100 100 100 100`|`100`| パーセンテージの上限 |
 |`2 / 0 100`|`50`| 極端な混合 |
 |`100`全部飲む`100`|`100`| 最大入力サイズ |
