 ## 解決策
 ## 問題の理解

 試験の成績に応じて一定の奨学金予算を学生に配分するよう求められています。 各学生には 3、4、または 5 のマークが付けられ、同じマークの学生は同じ奨学金を受け取る必要があります。 _c3_、_c4_、_c5_ を 3 年生、4 年生、5 年生の生徒の数とし、_k3_、_k4_、_k5_ をそれぞれの奨学金とします。 制約は、奨学金が整数で減少しないこと (_k3 ≤ k4 ≤ k5_)、および支出総額が予算 _s_ に等しいことです。 さらに、「最適な」配分は奨学金の特定の機能を最小限に抑えます。これは結局、奨学金間の差異のバランスを取ることになります。 

入力により、生徒の数 _n_ (3 ≤ n ≤ 300)、総予算 _s_ (1 ≤ s ≤ 3・10^5)、および各生徒の得点が得られます。 出力では、制約を満たす奨学金の分布が提供されるか、そのような分布が存在しない場合は -1 が提供されます。 

小さい整数の四捨五入によって総予算が正確に等しくなることが妨げられる可能性があるため、この問題は微妙です。 比例配分を試みる単純なアプローチは、整数の要件に黙って違反する可能性があります。 たとえば、_c3 = 2_、_c4 = 1_、_c5 = 2_、および _s = 7_ の場合、予算を単純に比例的に分割すると 2.8 ルーブルなどの端数が生じる可能性があり、これは無効です。 整数解を探索するには注意が必要です。 

## アプローチ

 ブルートフォース手法では、0 ≤ k3 ≤ k4 ≤ k5 を満たす _k3_、_k4_、_k5_ のすべての値を反復処理し、合計予算が一致するかどうかを確認します。 各奨学金は最大 _s_ までであるため、およそ O(s^3) の可能性が得られます。 3·10^5 までの s の場合、これは大きすぎます。 

重要な観察は、_k3_ と _k5_ を修正すると、_k4_ が総バジェットによって決定されることに注意することで、検索スペースを削減できるということです。```
k4 = (s - c3*k3 - c5*k5) / c4
```これは整数であり、k3 ≤ k4 ≤ k5 を満たし、予算を正確に満たす必要があります。 これにより、問題は考えられる k3 と k5 にわたる二重ループに縮小されます。n ≤ 300 および s ≤ 3・10^5 であるため、これは実現可能です。 k3 と k5 の範囲は、それぞれ、floor(s / c3) と Floor(s / c5) によってさらに制限され、ループをタイトに保つことができます。 

最後に、各候補 (k3、k5) について、この方法で計算された k4 が有効かどうかを確認します。 「最適」関数は、奨学金間の差異が可能な限り小さい場合に最小化されるため、k3 を 0 から上へ、k5 を実現可能な最小値から反復すると、最小の広がりが生成される傾向があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(s3) | お(1) | 遅すぎる |
 | ダブルループ (最適) | O((s/c3)*(s/c5)) | お(1) | 承認済み |
