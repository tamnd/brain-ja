 ## 解決策
 ## 問題の理解

 この問題では、平面上に配置された一連の家の上に提案された多数のケーブル線を処理するように求められます。 すべての線について、家からその線までの最大の垂直距離が必要です。 公式声明では、住宅は点、ケーブル計画は線の形で説明されています。`Ax + By + C = 0`。 

点からの距離`(x, y)`そのような行は次のようになります。$$\frac{|Ax + By + C|}{\sqrt{A^2+B^2}}$$1 つのクエリ内のすべての住宅の分母は同じであるため、実際のタスクは、次の最大値を見つけることです。`|Ax + By + C|`すべての点の中で。 

入力サイズが大きいです。 まで`2 * 10^5`家と`2 * 10^5`クエリ、クエリが実行されるたびにすべての家をチェックするソリューション`4 * 10^10`これはコンテストの制限時間の許容範囲をはるかに超えています。 各クエリが対数時間に近づくようにハウスを前処理する必要があります。 

重要な幾何学的観察は、一連の点にわたる線形関数の最大値が常に凸包上に到達するということです。 ハル内のすべての点は他の点の凸状の組み合わせであるため無関係であり、線形関数は厳密な最大値を持つことができません。 この問題は、凸包サポート クエリの問題になります。 

不注意な解決策を打ち破る特殊なケースがいくつかあります。 すべての家が 1 つの線上にある場合、凸包には頂点が 2 つだけあります。 例えば：```
2 1
0 0
5 5
1 -1 0
```ライン`x - y = 0`には両方の家が含まれるため、答えは次のようになります。```
0.0000000000
```少なくとも 3 つのハル ポイントを想定したソリューションは失敗する可能性があります。 

もう 1 つの問題は、答えが絶対値を使用していることです。 考慮する：```
2 1
0 0
1 1
1 0 -10
```式の値は次のとおりです。`-10`そして`-9`したがって、最大絶対値は次のようになります。`10`。 符号付きの最大値のみを検索すると、誤って返されます。`9`。 

3 番目の微妙なケースは、最適なポイントが元の入力ポイントではない場合です。 ある方向から最も遠いポイントは常に船体上にありますが、必ずしも入力順序の最初または最後のポイントであるとは限りません。 入力の順序に依存するソリューションは、何も通知せずに失敗します。 

## アプローチ

 直接的な解決策は簡単です。 すべてのクエリについて、すべての住宅のライン式の値を計算し、最大の絶対値を保持し、正規化係数で除算します。 これは、答えの正確な定義をチェックするため、正しいです。 ただし、`n`家と`q`クエリの複雑さは`O(nq)`、おおよそ次のようになります`4 * 10^10`最大入力サイズでの評価。 

改善は式の構造を認識することで実現します。 クエリ法線ベクトルの場合`(A, B)`、次のものが必要です。$$\max |A x + B y + C|$$の`C`この部分はすべての値を均等にシフトするだけなので、次の最大値と最小値が必要です。$$A x + B y$$すべての家の上に。 凸包には、あらゆる方向の極点が正確に含まれています。 これにより、問題は凸多角形のサポート ポイントを見つけることに変換されます。 

凸包を構築した後、各クエリは凸包に対する二分探索になります。 固定方向の内積は凸多角形の周りで単峰的に変化するため、対数時間で極点の頂点を見つけることができます。 凸包ベースの極端なクエリは、凸多角形の順序付けられた構造の標準的な使用法です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(nq) | お(1) | 遅すぎる |
 | 最適 | O(n log n + q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのハウス座標を読み取り、単調連鎖アルゴリズムを使用して凸包を構築します。 内側の点は線形式を最大化できないため、削除します。 
2. ハルの頂点を反時計回りの順序で保存します。 凸多角形の周囲の内積値は二分探索が可能な形状を形成するため、順序は重要です。 
3. 各クエリ行について、次の内容を抽出します。`A`、`B`、 そして`C`。 方向性`(A, B)`船体のどちら側が最も遠いかを教えてくれます。 
4. の最大値を求めます。`A*x + B*y`船体の上で。 これは、環状凸多角形に対する二分探索によって行われます。 
5.同様に方向で検索して最小値を見つけます`(-A, -B)`。 方向を否定すると、最小クエリが最大クエリに変わります。 
6. 2 つの極端な値を組み合わせます。 最大の絶対式値は次のとおりです。$$\max(\text{maxValue}+C,\;-(\text{minValue}+C))$$次に、で割ります`sqrt(A^2+B^2)`。 

機能する理由: 凸包には、元の点セットの考えられるすべての極点が含まれています。 どの方向ベクトルについても、一次関数は船体上で最大値と最小値に達します。 距離の式は絶対線形式を定数で割ったものにすぎないため、2 つのサポート クエリにより、答えに必要な 2 つの候補が正確に得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def build_hull(points):
    points = sorted(set(points))
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def dot(p, a, b):
    return p[0] * a + p[1] * b

def support(poly, a, b):
    n = len(poly)
    if n == 1:
        return dot(poly[0], a, b)

    l, r = 0, n - 1
    while l < r:
        m = (l + r) // 2
        cur = dot(poly[m], a, b)
        nxt = dot(poly[(m + 1) % n], a, b)
        if cur <= nxt:
            l = m + 1
        else:
            r = m
    ans = dot(poly[l], a, b)
    ans = max(ans, dot(poly[(l - 1) % n], a, b))
    ans = max(ans, dot(poly[(l + 1) % n], a, b))
    return ans

def solve():
    n, q = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    hull = build_hull(pts)

    out = []
    for _ in range(q):
        A, B, C = map(int, input().split())

        mx = support(hull, A, B)
        mn = -support(hull, -A, -B)

        value = max(abs(mx + C), abs(mn + C))
        ans = value / math.sqrt(A * A + B * B)
        out.append(f"{ans:.12f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```ハルの構築により、ポリゴン内に隠れているポイントが削除されます。 の`cross`関数は、ハルの最後の 2 つのエッジが非左折を作成するかどうかをチェックします。これは、中間点が凸状の境界に属することができないことを意味します。 

の`support`関数は最適化の中核です。 への投影が行われる頂点を検索します。`(A, B)`が最大です。 見つかったインデックスの最終チェックでは、平坦なエッジが処理され、投影値が等しいことによる問題が回避されます。 

クエリ処理では 2 つのサポート クエリが実行されます。 1 つは最大投影を見つけ、もう 1 つは方向ベクトルを反転して最小を見つけます。 絶対値は両方の極値がわかった後にのみ適用されるため、負の側を忘れるというよくある間違いが回避されます。

 ## 特殊なケース

 同一線上にある家の場合:```
2 1
0 0
5 5
1 -1 0
```ハルには 2 つのエンドポイントのみが含まれています。 The support query checks both possible vertices, and the line expression is zero for both, giving the correct answer.

 絶対値の問題の場合:```
2 1
0 0
1 1
1 0 -10
```2 つの式の値は次のとおりです。`-10`そして`-9`。 アルゴリズムは最大予測と最小予測の両方を計算し、絶対値を適用して次の結果を生成します。`10`。 

入力順序が誤解を招く場合:```

```最も遠い点は、有用な順序付けによる最初の入力点ではありません。 ハルによって順序付けの仮定が削除され、サポート検索によって正しい極点の頂点が見つかります。
