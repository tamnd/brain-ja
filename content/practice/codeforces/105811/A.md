 ## 問題の理解

 このタスクは、ASCII 文字を使用して長方形の水槽を描くことです。 タンクのサイズは常に 15 行 25 列の固定サイズになります。 境界線が使用するのは、`o`、`-`、 そして`|`、中は空きスペースです。 正確に配置する必要があります`n`水槽の中の魚。各魚の長さは 3 文字で、次のいずれかに見えます。`><>`または`<><`。 魚は境界に触れることはできず、2 匹の魚が重なることもできません。 必要な出力は完成した図面だけです。 この問題では、一意の配置ではなく、有効な配置が求められます。 

入力には、出現する必要がある魚の数を表す 1 つの整数が含まれます。 制限は最大 10 匹にすぎないため、主な課題はパフォーマンスではなく、常に十分な有効なポジションを残すシンプルな構造を見つけることです。 可能な図面を検索するアプローチは不要です。 出力サイズ自体は 15 x 25 文字に固定されているため、一定時間の構築で十分です。つまり、375 個のセルしか作成されません。 

よくある間違いは、使用可能な内部幅を確認せずに魚を配置することです。 魚は連続する 3 列を占めるため、内側エリアの最後の 2 列に 1 匹を配置すると、境界線を越えることになります。 

例えば：```
1
```水槽の幅が列 24 で終わるため、出力では行の列 23 から始まる魚を配置できません。正しい考え方は、安全な内部位置のみを使用することです。 

もう 1 つの特殊なケースは、すべての魚が同じ列に配置されている場合です。 不用意に実装すると接触してしまう可能性があります。 例えば：```
3
```次のような行:```
|><><><><>|
```魚が重なっているため無効です。 魚は少なくとも 1 つの空文字で区切る必要があります。 

最後のエッジケースは、魚の最大数です。 魚は 10 匹しかいないため、建設ではそれらすべてに十分なスペースを確保する必要があります。 行と列の固定パターンにより、スペース不足が回避されます。 

## アプローチ

 強引なアプローチは、水槽内の魚のあらゆる配置を試し、各候補図に必要な数の重複しない魚が正確に含まれているかどうかを確認することです。 最終的にはすべての可能な描画が考慮されるため、これは正しいですが、検索スペースは小さな入力に比べて膨大です。 それぞれの魚には何百もの可能なポジションがあり、ポジションの組み合わせを試すことは飛躍的に増加します。 すべての配置をチェックする前であっても、候補の数は固定サイズの出力問題に必要な数よりもはるかに多くなります。 

問題を変える観察は、裁判官は最終的な写真が有効かどうかのみを検証するということです。 魚の位置や方向は気にしません。 可能な魚は 10 匹だけなので、十分なスロットを備えた決定的なレイアウトを準備し、最初のスロットを埋めることができます。`n`スロット。 問題は単純な構築問題になります。 

水槽を完全に初期化してから、魚を安全な場所に入れることができます。 空のセルで区切られた位置を選択すると、2 つの魚が重ならないことが保証されます。

 ## アルゴリズムのチュートリアル

 1. スペースで埋められた 15 × 25 のグリッドを作成します。 これにより、タンクの内部が空になります。 
2. を配置して境界線を描画します`o`四隅に、`-`上下にまたがって、`|`左側と右側に沿って。 これにより、必要なタンク形状が再現されます。 
3. 魚を配置できる安全な位置のリストを作成します。 各位置は境界線の内側にあり、連続する 3 つの列が使用可能である必要があります。 
4. 必要な魚ごとに、`><>`次に利用可能な位置にあるパターン。 唯一の要件は、各魚が 2 つの有効な形状のいずれかを持っていることであるため、正確な方向は重要ではありません。 
5. 完成したグリッドを行ごとに印刷します。 

なぜ効果があるのか:

 描画を無効にする可能性があるのは、魚の形が間違っている場合、重なっている場合、または境界に触れている場合のみです。 選択したすべての位置はタンク内にあり、3 人のキャラクターを配置するのに十分なスペースが残されています。 位置は再利用せずに間隔をあけて選択されるため、挿入されたすべての魚は独立しています。 正確に配置した後`n`魚の場合、グリッドには必要な数の有効な魚が正確に含まれています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    h, w = 15, 25
    grid = [[' ' for _ in range(w)] for _ in range(h)]

    for j in range(w):
        grid[0][j] = '-'
        grid[h - 1][j] = '-'

    for i in range(h):
        grid[i][0] = '|'
        grid[i][w - 1] = '|'

    grid[0][0] = 'o'
    grid[0][w - 1] = 'o'
    grid[h - 1][0] = 'o'
    grid[h - 1][w - 1] = 'o'

    positions = []
    for r in range(1, h - 1):
        for c in range(2, w - 3, 4):
            positions.append((r, c))

    for i in range(n):
        r, c = positions[i]
        grid[r][c] = '>'
        grid[r][c + 1] = '<'
        grid[r][c + 2] = '>'

    print('\n'.join(''.join(row) for row in grid))

if __name__ == "__main__":
    solve()
```個々のセルを変更する必要があるため、グリッドは文字リストの変更可能なリストとして表されます。 まず境界線を構築すると、コンテナー内に何かを追加する前に、コンテナーが有効であることが保証されます。 

位置の生成は内側の行から開始され、開始列間に十分な距離が残ります。 4 列のステップは意図的です。 魚は 3 本の柱を使用しており、魚の間に余分な柱があるため、誤って接触することはありません。 

挿入ループは最初の部分のみを使用します。`n`生成されたポジション。 問題が保証されているため、`n`最大 10 の場合、リストには常に十分な安全な場所が含まれます。 

出力変換では、各行が文字列に結合されます。 Python では文字を結合するときにスペースが保持されるため、スペースを特別に処理する必要はありません。
