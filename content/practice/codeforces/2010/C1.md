 ## 問題の理解

 単一の文字列を受け取ります`t`サーバーによってキャプチャされたメッセージを表します。 サーバーは最初に何らかの文字列を送信します`s`2回連続で。 通常の状態では、トランスミッションは次のようになります。`s + s`ただし、ネットワークによって特定の破損が発生する可能性があります。つまり、最初のコピーの終わりです。`s`重複部分の長さが厳密に 1 と 2 の間である限り、2 番目のコピーの先頭と重複することができます。`len(s) - 1`、重なっている文字が完全に一致します。 

したがって、受信した文字列はクリーンな連結のいずれかです`s + s`、これは有効であるとみなされ、無視する必要があります。または、`s`。 重複する場合、最初のコピーの一部のサフィックスが 2 番目のコピーのプレフィックスと一致し、より短い結合文字列が生成されます。 

タスクは、次のことを決定することです。`t`ある文字列の 2 つの同一のコピーの重複によって生成された可能性があります`s`。 「はい」の場合、有効な値を出力する必要があります。`s`。 

という制約が`|t| ≤ 100`すぐに、3 次または 2 次の解が適切であることがわかります。 すべての分割点候補に対してネストされたチェックを行うリニア スキャンは安全です。 たとえ$O(n^2)$この限界の下では、文字列照合アプローチは自明です。 

重要な微妙な点は、完全なオーバーラップとゼロのオーバーラップは「エラー」として許可されていないことです。 つまり、再構築された場合、`s`重なり合う長さを意味します`0`または`|s|`の場合、その状況は通常の送信とみなされ、拒否される必要があります。 

いくつかのエッジの状況が重要です。 

もし`t = "abcd"`、選択する`s = "abcd"`完全な重複が発生し、これはエラーケースとして無効であるため、答えは次のようになります。`NO`。 

もし`t = "abcabc"`、選択する`s = "abc"`ゼロオーバーラップに対応し、エラーケースとしても無効です。 

もし`t`は長さ 1 のように非常に短いため、2 つの重なり合うコピーから適切な重なり長さでそれを形成する方法はありません。そのため、答えは常に次のようになります。`NO`。

重要な観察は、次のような場合です。`t`の 2 つのコピーから形成されます`s`オーバーラップすると、`s`の接頭辞として現れる必要があります`t`。 最初のコピー`s`位置 0 から始まり、オーバーラップした後でも、完全な最初のコピーが先頭に埋め込まれます。`t`。 したがって、`s`のプレフィックスを選択することによって完全に決定されます。`t`、プレフィックス候補をテストするだけで済みます。

 ## アルゴリズムのチュートリアル

 候補文字列の可能なすべての長さを反復処理します。`s`。 

1.修正`s`接頭辞として`t[0:i]`一部の人にとっては`i`から`1`に`n-1`。 除外します`i = n`これは、エラーとして許可されない完全なオーバーラップまたはゼロオーバーラップのケースに対応するためです。 
2. このために`s`のコピーが 2 つあるかどうかを判断しようとします。`s`重ねて生成することができます`t`。 オーバーラップ長さ`k`満たさなければなりません`1 ≤ k ≤ i-1`。 
3. 選択したオーバーラップについて`k`、結果の文字列は次のようになります。 

最初に取る`s`、次に追加します`s[k:]`。 これにより、次の長さの文字列が生成されます。`i + (i - k)`。 
4. 存在するかどうかを確認します`k`この構築された文字列が次と等しくなるように`t`。 「はい」の場合、戻ります`s`。 

重要な部分は、重複が接尾辞の一致と同等であることを認識することです。`s`という接頭辞が付く`s`、マージされた結果は一度完全に決定されます`k`が選ばれます。 

### なぜ効果があるのか

 あらゆる有効な構造`t`の完全コピーから始める必要があります`s`なぜなら、最初のメッセージは重複によって末尾でのみ切り詰められ、先頭では決して切り詰められないからです。 したがって`s`のプレフィックスでなければなりません`t`。 逆に、プレフィックスが 1 回だけ`s`選択されるのは、形成における唯一の自由です`t`はオーバーラップの長さで、境界線の選択に正確に対応します。`s`。 アルゴリズムはそのような可能性をすべて網羅するため、有効な構造を見逃すことはできず、無効な構造を受け入れることもできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = input().strip()
n = len(t)

for i in range(1, n):
    s = t[:i]

    # try all possible overlap lengths
    for k in range(1, i):
        merged = s + s[k:]
        if merged == t:
            print("YES")
            print(s)
            sys.exit()

print("NO")
```実装はアルゴリズムの構造に直接に従います。 すべてのプレフィックス長を反復処理します。`s`、次に有効なオーバーラップ長をすべて試します`k`。 建設`s + s[k:]`重なり合いの効果をモデル化します。`k`文字。 

よくある落とし穴は除外を忘れることです`k = 0`そして`k = i`、これはオーバーラップなしと完全なオーバーラップに対応します。 問題定義ではどちらも明示的に無効であるため、内側のループは 1 で始まり で終了します。`i - 1`。 もう 1 つの微妙な点は、有効になったらすぐに停止しなければならないことです。`s`有効な構造が 1 つあれば十分なので、 が見つかります。
