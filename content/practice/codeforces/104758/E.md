 ## 解決策
 ## 問題の理解

 私たちは航空便で結ばれた都市の直接ネットワークを与えられています。 各フライトには方向と料金があるため、都市 U から都市 V への移動にそのフライトを利用すると、お金が C 減ります。 移動と並行して、都市に到着するたびに、その都市に関連付けられた固定利益が得られます。この利益は、一度だけではなく、その都市を訪れるたびに収集されます。 

私たちは都市 S から出発し、都市 T に到着したいと考えています。目標は、一連のフライトと都市訪問の後に蓄積されたお金の合計を最大化することです。 重要な問題は、都市の再訪問が許可されており、再訪問するたびに再び利益が得られるため、サイクルが悪用される可能性があることです。 ただし、端を通過するたびに航空運賃が発生します。 

出力は、T で達成可能な最終資金の最大値、または T に到達できる間に利用できる好循環により利益を任意に大きくできる、または T には到達できないという宣言のいずれかです。 

ノードに関しては制約は小さく、N ≤ 100 ですが、エッジは最大 10000 まで可能です。これは、O(N^3) または O(N・M) のアプローチが許容される一方で、パス上の指数関数的なものは不可能であることをすぐに示唆しています。 潜在的に悪用可能なサイクルの存在は、純粋に貪欲なアプローチや非巡回グラフ内の DP アプローチではなく、負のサイクルによる最短経路の定式化を強く示唆しています。 

最も重要なエッジケースは、サイクルで正味の利益（利益から交通費を差し引いたもの）が得られる場合です。 そのようなサイクルが S から到達可能であり、依然として T につながる可能性がある場合は、それを任意に何度もループして、際限なく利益を増やすことができます。 単純な最短パス アルゴリズムは、これらの無限ゲイン状態を明示的に検出して伝播しない限り、依然として有限値を返す可能性があります。 

たとえば、総利益が総コストを超えるサイクル 1 → 2 → 3 → 1 を考えてみましょう。 このサイクル内のいずれかのノードが T に到達できる場合、答えは無限になります。 サイクル推論を行わずに最適な距離だけを追跡する単純な緩和では、早期に終了してこれを見逃す可能性があります。 

もう 1 つのエッジ ケースは、T が S から到達できない場合です。最短パス アルゴリズムは依然としてすべてのノードの距離を計算できますが、答えは T に到達しなかったことを明示的に検出する必要があります。 

## アプローチ

 この問題を直接的に考える方法は、各都市訪問を利益の追加として扱い、各フライトのコストの減算として扱うことです。 各都市の州の値を定義し、そこに到着したときに持つことができる最大のお金を表すと、すべてのフライト U → V が遷移します。 

値[V] = 値[U] - コスト(U,V) + 利益(V)

 これは、可能なサイクルを含む有向グラフにおける標準的な最長経路問題です。 グラフが非巡回の場合は、位相順序で動的計画法を実行するとすぐに解決されます。 問題は、サイクルが存在し、それが有益になる可能性があるということです。 

ブルート フォース アプローチでは、S から T までの考えられるすべてのパスを列挙し、その純利益を計算しようとします。 各パスには明確に定義された総利益からコストを引いた値があるため、これは概念的には正しいです。 ただし、サイクルを含むグラフ内のパスの数は無限であり、単純なパスに制限した場合でも、N で指数関数的に複雑になります。最大 100 個のノードでは、これは完全に不可能です。 

重要な洞察は、問題を負のサイクルの可能性がある最短経路問題に変換することです。 遷移を次のように書き換えると、

 コスト(U → V) = フライトコスト(U,V) - 利益(V)

 初期費用 - 利益(S) から始めて、総費用を最小化することが利益を最大化することに対応します。 これにより、問題は標準的な最短経路の計算に変換されます。 

この形になると、負のサイクルを検出できるため、ベルマン・フォードが自然に現れます。 この変換されたグラフの負のサイクルは、元の問題の正の利益サイクルに正確に対応します。

ただし、負のサイクルを検出するだけでは十分ではありません。 そのサイクルが S から T へのパスに影響を与える可能性があるかどうかだけを考慮します。したがって、負のサイクルの一部であるか負のサイクルから到達可能なすべてのノードを検出した後、それらのいずれかが T に到達できるかどうかを確認する必要があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース パスの列挙 | 指数 | O(N) | 遅すぎる |
 | ベルマンフォード + サイクル伝播 | O(N・M) | O(N + M) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各エッジ U → V が重み W = コスト(U,V) - 利益(V) を持つようにグラフを変換します。 また、S の開始値を -profit(S) として初期化します。 これにより、利益の最大化が総重量の最小化に変換されます。 
2. すべてのエッジに対して Bellman-Ford を N 回反復して実行し、S からの最短距離を計算します。N 回目の反復でもエッジを緩和できる場合は、目的地を負のサイクルの一部または負のサイクルの影響を受けるものとしてマークします。 このステップでは、値を無制限に減少させることができるすべてのノードを特定します。 
3. グラフ隣接リストを構築または再利用し、負のサイクルの影響を受けるとマークされたすべてのノードから到達可能性検索 (BFS または DFS) を実行します。 このような領域に入ると任意の利益増幅が可能になるため、これによりサイクルの影響がそこから到達可能なすべてのノードに拡大されます。 
4. この伝播されたセット内のいずれかのノードが T に到達できるかどうかを確認します。そうであれば、利益サイクルをループさせても最終的に T に到達できるため、答えは「マネー ハック!」になります。 
5. そもそも S から T に到達できない場合は、「Bad Trip」を出力します。 
6. それ以外の場合は、最大利益に対応する T への最短距離を出力します。 

正確さは、ベルマン フォードが変換されたグラフ内の S から到達可能なすべての負のサイクルを捕捉し、伝播により、それらのサイクルが T へのパスに影響を与える可能性がある場合にのみ無限大を宣言するという事実に依存します。 

### なぜ効果があるのか

 変換後、すべてのパスのコストは元の利益のマイナスに等しくなります。 したがって、パスコストを最小化することは、利益を最大化することと同じです。 Bellman-Ford は、負のサイクルのないグラフ内の正しい最短経路を保証し、負のサイクルによりさらなる改善が可能になる時期を検出します。 このようなサイクルは、コストの恣意的な減少、つまり利益の恣意的な増加を意味します。 

最後の伝播ステップでは、宛先に影響を与える可能性のあるサイクルのみが問題となることが保証されます。 存在していても T へのパスから分離されているサイクルは、有効な S → T 行程では使用できないため、問題ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M, S, T = map(int, input().split())
    S -= 1
    T -= 1

    edges = []
    adj = [[] for _ in range(N)]

    P = list(map(int, input().split()))

    for _ in range(M):
        u, v, c = map(int, input().split())
        u -= 1
        v -= 1
        w = c - P[v]
        edges.append((u, v, w))
        adj[u].append(v)

    INF = 10**18
    dist = [INF] * N
    dist[S] = -P[S]

    for _ in range(N - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break

    bad = [False] * N

    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            bad[v] = True

    from collections import deque
    q = deque(i for i in range(N) if bad[i])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if not bad[v]:
                bad[v] = True
                q.append(v)

    if dist[T] == INF:
        print("Bad trip")
        return

    if bad[T]:
        print("Money hack!")
        return

    print(-dist[T])

if __name__ == "__main__":
    solve()
```この実装では、まず問題を最短経路モデルに変換し、利益がエッジの重みに吸収されます。 Bellman-Ford は N-1 回反復して実行され、それ以上の改善が行われると、ノードは問題のあるサイクルの影響の一部としてマークされます。 

微妙な点は、初期化することです。`dist[S] = -P[S]`S で開始するとすぐに利益が得られるためです。もう 1 つの微妙な点は、「悪い」状態を発信エッジを通じて前方にのみ伝播することです。 これにより、サイクルに入った後に実際に到達可能なノードのみをマークすることが保証されます。 

最後に、元の問題では最大の利益が求められるのに対し、変換コストが最小になるように最適化したため、答えは否定されます。

 ## 特殊なケース

 クリティカル エッジ ケースとは、収益性の高いサイクルが存在するものの、T に到達できないことです。アルゴリズムは、そのようなサイクルを`bad`配列ですが、伝播は T に達しないため、誤って無限の利益を出力することはありません。 たとえば、ノード 2、3、4 が正のサイクルを形成しているが、ノード 1 のみが T に接続している場合、そのサイクルからの BFS は決して T に到達せず、アルゴリズムは有限の最短パスを安全に計算します。 

もう 1 つのケースは、S 自体が収益サイクル内にある場合です。 初期化と最初の緩和ラウンドにより、S がサイクル検出に正しく参加できるようになり、T が下流にある場合、伝播によって到達可能な領域全体が無限としてマークされることが保証されます。 

最後の微妙なケースは、複数のサイクルが相互作用する場合です。 Bellman-Ford では、N 回目の反復で距離が改善したノードをマークし、伝播によってそのような領域がすべてマージされます。 これにより、連鎖サイクルであっても、最終的に T に影響を与える場合には、単一の悪用可能な構造として扱われることが保証されます。
