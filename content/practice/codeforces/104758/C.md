 ## 解決策
 ## 問題の理解

 三角飾りを作っています。$N$水平レベル。 レベル$i$正確に含まれています$i$すべてのステッカーは、赤、緑、青の 3 色のいずれかを使用して色付けする必要があります。 各色の供給量には制限があり、これらの供給量を超えずに三角形全体を埋める方法が何通りあるかを数えなければなりません。 

各レベルには、色の表示方法に関する制約があります。 レベルは、すべてのステッカーが同じ色であることを意味する単色にすることも、完全にバランスのとれた方法でのみ複数の色を使用することもできます。レベルで複数の色が使用される場合は常に、使用されるすべての色がそのレベル内で同じ回数出現する必要があります。 これにより、レベル上で選択された各カラー セットが強制的にレベル サイズを均等に分割されます。 

サイズのレベルについては$i$、私たちが選択するなら$k$そのレベルの色、そして$k$分けなければなりません$i$、選択された各色が正確に寄与します$i/k$ステッカー。 選択はレベルごとに独立して行われますが、各色の利用可能な合計数によってグローバルに制限されます。 

出力は、有効な完全な構造の数を法で表したものです。$10^9 + 7$。 

制約$N \le 20$までの供給$100$色ごとに、ソリューションの構造が純粋に貪欲な形式や組み合わせの閉じた形式ではないことがすぐにわかります。 三角形の高さは小さいですが、レベル全体の色の分布により、状態に依存したカウント プロセスが作成されます。 本当の制約はそうではありません$N$、ただしレベル間のリソース使用量の累積。 

単純な考えは、世界的な消費量を追跡せずに、各レベルの有効なカラーリング パターンを個別に選択することです。 同じローカル選択では色が早期に使い果たされ、後のレベルが無効になる可能性があるため、これはすぐに失敗します。 もう 1 つの微妙な間違いは、レベルを独立して扱い、カウントを乗算することです。これは、グローバル結合を完全に無視します。 

2 番目の素朴なアプローチは、残りの数を追跡しながらレベルごとに色を割り当てることです。 これは正しいですが、メモ化しないと、各レベルが複数の色のサブセットの選択肢に分岐するため、爆発的に増加します。 

## アプローチ

 ブルートフォース手法では、レベルごとに三角形を構築し、各レベルで、割り算ルールを満たす有効な色の割り当てをすべて試行します。 レベルについて$i$のすべてのサブセットを考慮します。$\{R,G,B\}$、サイズが分割されているかどうかを判断します$i$、そして割り当てを試みます$i/k$選択したカラーごとのステッカー。 これは、すべての法的な構成を直接列挙しているため、正しいです。 

ただし、このアプローチでは同じ状況が繰り返し発生します。 いくつかのレベルを処理した後、以前の決定の異なるシーケンスを通じて、同一の残りのリソース状態に到達する可能性があります。 ブルート フォースはこれらの重複を認識しないため、同じ部分問題を何度も再計算します。 と$N \le 20$、各レベルは最大 7 つの有効なカラーセットの選択肢に分岐し、全体の検索ツリーの深さはおおよそ指数関数的になります。$7^{20}$、これは実現可能性をはるかに超えています。 

重要な観察は、将来の決定において重要なのは、赤、緑、青のステッカーがどれだけ残っているか、そして現在どのレベルを処理しているかだけであるということです。 これにより、問題は標準的な多次元動的計画法状態に変わります。 それぞれの状態は、どのようにしてそこに到達したかには関係なく、プロセスの接尾辞を表します。 

次に、各州の結果をメモします$(i, r, g, b)$、 どこ$i$は現在のレベルであり、$r,g,b$残りの物資です。 これにより、各レベルではカウントが減少するだけなので、指数関数的再帰が管理可能な数の到達可能な状態に折りたたまれます。$N$小さいです。

 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的$N$(≈$7^N$) |$O(N)$再帰スタック | 遅すぎる |
 | 最適な DP (メモ化された再帰) |$O(N \cdot R \cdot G \cdot B \cdot 7)$|$O(N \cdot R \cdot G \cdot B)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. レベル 1 からレベル 1 までを処理する再帰関数を定義します。$N$の残りのカウントを追跡しながら、$R, G, B$。 これにより、あらゆる決定が早期の消費を尊重するようになります。 
2. すべてのレベルを処理した場合は、有効な完全な構成が形成されたため、1 を返します。 これは再帰ツリーの基本ケースとして機能します。 
3. 現在のレベルについて$i$、色のサブセットをすべて列挙します。$\{R,G,B\}$。 各サブセットは、このレベルで使用される色を表します。 
4. サイズのサブセットごとに$k$、どうかを確認してください$i$で割り切れます$k$。 そうでない場合、均等配分では整数が生成されないため、この割り当ては不可能です。 
5. 有効な場合、色ごとに必要な割り当てを次のように計算します。$i/k$。 残りのリソースからこれらの量を減算し、次のレベルを再帰的に解決します。$i+1$。 
6. 減算後にいずれかの色が負になった場合は、リソース制約に違反するため、その分岐を直ちに破棄します。 
7. すべての有効なサブセットからの結果を合計し、計算された値をキーがキーのメモ化テーブルに保存します。$(i, r, g, b)$。 

### なぜ効果があるのか

 すべての有効な装飾は、レベルごとの決定の 1 つのシーケンスに正確に対応し、そのような各シーケンスは状態空間を通るパスを一意に決定します。 再帰によってそのようなパスがすべて探索され、メモ化によって各状態が 1 回解決されることが保証されます。 将来の決定は以前のレベルが選択された順序に依存しないため、DP 状態はすべての関連情報を完全に取得し、繰り返しを完全かつ非冗長にします。 

## Python ソリューション```python
import sys
from functools import lru_cache

input = sys.stdin.readline
MOD = 10**9 + 7

def solve():
    n, R, G, B = map(int, input().split())

    colors = (0, 1, 2)

    @lru_cache(maxsize=None)
    def dp(level, r, g, b):
        if level > n:
            return 1

        total = 0
        req = level

        # iterate all subsets of {R,G,B}
        for mask in range(1, 8):
            cnt = (mask & 1) + ((mask >> 1) & 1) + ((mask >> 2) & 1)
            if req % cnt != 0:
                continue

            share = req // cnt
            nr, ng, nb = r, g, b

            if mask & 1:
                nr -= share
            if mask & 2:
                ng -= share
            if mask & 4:
                nb -= share

            if nr < 0 or ng < 0 or nb < 0:
                continue

            total = (total + dp(level + 1, nr, ng, nb)) % MOD

        return total

    print(dp(1, R, G, B))

if __name__ == "__main__":
    solve()
```このソリューションは、複数のレベルにわたるメモ化された再帰を中心としています。 機能`dp(level, r, g, b)`構築プロセスに残っている自由度を正確にエンコードします。 1 から 7 までの各マスクは、現在のレベルで使用される色の選択を表します。 可分性チェックにより、選択した色間でレベルを均等に分割できることが保証され、減算ステップによりグローバルなリソースの一貫性が確保されます。 

多くの異なるレベル割り当てシーケンスによって残りのカウントが同一になるため、メモ化は非常に重要です。 キャッシュがなければ、これらの状態は指数関数的に何度も再計算されます。

 ## 特殊なケース

 1 レベルを除くすべてのリソースがゼロの場合、有効なサブセットにはポジティブな割り当てが必要なため、再帰はすべての分岐に直ちに失敗します。 状態遷移は、最初の減算ステップですべての無効なパスを正しくプルーニングします。 

単一レベルの場合$N=1$、アルゴリズムは空ではないすべてのサブセットをチェックします。 レベル サイズがサブセット サイズで割り切れるサブセットのみが受け入れられます。この場合、レベル サイズが 1 であるため、すべてのサブセットが含まれます。結果は正確に次のようになります。$2^3 - 1 = 7$、空ではないすべての可能な色の選択に一致します。 

非常に不均衡な供給の場合、$R=100, G=0, B=0$、単色の赤の割り当てのみが残ります。 DP は引き続き他のブランチを探索しますが、負のカウントが発生するとすぐにそれらをプルーニングし、追加のロジックなしで正確さを保証します。
