 ## 解決策
 ## 問題の理解

 各セルが花の美しさを表す数値を持つグリッドが与えられます。 「写真」は、このグリッドの連続するサブ長方形を選択することに対応します。 選択した各サブ長方形について、その中のすべての行を調べ、その行セグメントの最大値を取得します。 これらの行ごとの最大値を合計すると、1 つの数値が得られます。 サブ長方形内の各列に対して同じことを行い、列方向の最大値を合計します。 写真の美しさは、この 2 つの和の積です。 

タスクは、998244353 を法として、考えられるすべての部分長方形の全体的な美しさを計算することです。 

この制約では、最大 1000 × 1000 のセル、つまり最大 100 万個の要素が許可されます。 セルごとの二次関数に近いソリューションや、各四角形の最大値を再計算するものは、非常に遅すぎます。 候補が約 10^12 あるため、すべての O(n^2 m^2) 部分長方形を反復処理することすら不可能です。 

微妙な問題は、行の最大値と列の最大値の両方が選択した四角形に依存し、乗算的に相互作用することです。 行と列は独立して処理できると単純に期待するかもしれませんが、製品はそれらをすべての部分行列にわたって結合します。 

一般的な失敗例は、行の寄与と列の寄与を別々に事前計算してグローバル合計を乗算しようとしたときに発生します。 これは、両方を同じサブ四角形で計算する必要があることを無視します。 たとえば、2×2 グリッドでは、異なるサブ四角形は行と列の最大値の異なる組み合わせを生成するため、集計を四角形レベルで分離することはできません。 

もう 1 つの落とし穴は、ダイレクト スキャンを使用して各部分行列を個別に計算しようとすることです。 各部分行列がその領域内で線形時間で処理されたとしても、総コストは依然として 3 倍以上に爆発的に増加します。 

## アプローチ

 ブルート フォース ソリューションでは、上の行、下の行、左の列、右の列で定義されたすべての部分行列を列挙します。 このような四角形ごとに、各行セグメントをスキャンすることによって行の最大値を計算し、各列セグメントをスキャンすることによって列の最大値を計算します。 これにはすでに長方形あたり O(nm) のコストがかかり、O(n^2 m^2) 個の長方形があるため、実現可能な限界をはるかに超えています。 

重要なアイデアは、プロダクト構造を長方形レベルではなくセル寄与レベルで分離することです。 行の寄与は列のみに依存し、列の寄与は行のみに依存します。 これにより、合計の答えを個々のセルの合計として書き直すことができ、各セルが構造化された方法で独立して寄与します。 

固定サブ四角形の場合、各行の最大値は、その行の 1 つのセル、つまりその行セグメントの最大要素から得られます。 同様に、各列の最大値は、その列セグメント内の 1 つのセルから取得されます。 これにより、問題は行セグメントまたは列セグメント内で特定のセルの最大値となる四角形の数を数えるという問題に変わります。 

これにより、2D 相互作用が 2 つの独立した 1D 問題に縮小されます。1 つは列に対する行に関する問題、もう 1 つは行に対する列に関する問題です。 それぞれは古典的な「サブアレイの最大寄与の合計」問題に帰着し、線形時間で単調スタックで解くことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 m^2 (n + m)) | お(1) | 遅すぎる |
 | 最適 | O(nm) | O(nm) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、各セルの値が行セグメントと列セグメントで最大値になる頻度を決定するように問題を書き直します。

1. 各セルについて、その行の最大となる連続列間隔の数を決定します。 これはセルを含む行にのみ依存し、行ごとに独立して計算できます。 
2. 各行について、すべての列インデックスについて、左右に最も近い厳密に大きい要素を計算します。 これは、現在の要素がその行セグメント内で最大値を維持する範囲を定義します。 
3. セルが行内で最大となる有効な列間隔の数は、最大値を維持しながら左右にどれだけ拡張できるかの積です。 これにより、行の影響に対する寄与数が得られます。 
4. 転置構造でも同じロジックを繰り返します。列ごとに、最も近い大きい要素を上下に計算し、列セグメント内でセルが最大になる行間隔の数を求めます。 
5. 各セルについて、これら 2 つのカウントを結合し、その値の 2 乗を掛けます。 これは、セルを修正すると行の寄与と列の寄与が独立しているため機能します。 
6. この値をすべてのセルで合計して、最終的な答えを取得します。 

重要な単純化は、すべての四角形の寄与が「行ごとの行最大セル」と「列ごとの列最大セル」の独立した選択肢に分解され、これらの選択がセルごとのカウント問題の要素となることです。 

### なぜ効果があるのか

 長方形内の各行の最大値は、その行セグメント内の単一のセルによって一意に決定され、同様に、各列の最大値は、その列セグメント内の単一のセルによって一意に決定されます。 したがって、すべての四角形は、行の最大値 (列によって決定) と列の最大値 (行によって決定) の 1 つの選択のペアにマップできます。 行制約は列間隔のみに依存し、列制約は行間隔のみに依存するため、それらのカウントはセルごとにきれいに分離されます。 これにより、二重カウントが防止され、次元間の独立性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

# row contribution: for each cell, count subarrays in its row where it is maximum
row_cnt = [[0] * m for _ in range(n)]
col_cnt = [[0] * m for _ in range(n)]

# process rows
for i in range(n):
    stack = []
    left = [0] * m
    right = [0] * m

    # previous greater (strict)
    for j in range(m):
        while stack and a[i][stack[-1]] < a[i][j]:
            stack.pop()
        left[j] = j - (stack[-1] if stack else -1)
        stack.append(j)

    stack = []
    for j in range(m - 1, -1, -1):
        while stack and a[i][stack[-1]] <= a[i][j]:
            stack.pop()
        right[j] = (stack[-1] if stack else m) - j
        stack.append(j)

    for j in range(m):
        row_cnt[i][j] = left[j] * right[j]

# process columns
for j in range(m):
    stack = []
    up = [0] * n
    down = [0] * n

    for i in range(n):
        while stack and a[stack[-1]][j] < a[i][j]:
            stack.pop()
        up[i] = i - (stack[-1] if stack else -1)
        stack.append(i)

    stack = []
    for i in range(n - 1, -1, -1):
        while stack and a[stack[-1]][j] <= a[i][j]:
            stack.pop()
        down[i] = (stack[-1] if stack else n) - i
        stack.append(i)

    for i in range(n):
        col_cnt[i][j] = up[i] * down[i]

ans = 0
for i in range(n):
    for j in range(m):
        ans = (ans + (a[i][j] * a[i][j] % MOD) * row_cnt[i][j] % MOD * col_cnt[i][j]) % MOD

print(ans)
```行処理ブロックは、各要素をその行の最大値として扱う列間隔の数を計算します。 単調スタックでは、より大きな要素が現れる境界が正しく識別されるように、減少シーケンスが維持されます。 左右のコントリビューションに分割することで、すべての有効なサブ配列が正確に 1 回カウントされるようになります。 

列処理ブロックはこのロジックを縦軸に反映し、各セルが列を最大にする行間隔の数を計算します。 

最後に、各セルは、その値の 2 乗にこれら 2 つの独立したカウントを乗算した値を提供します。

 ## 特殊なケース

 単一セル グリッドは、行と列のスパンが両方とも 1 つであり、答えは値の 3 乗に帰着する最も単純なケースです。 両方の単調スタック パスがセルを両方向で独自の最大値のままにするため、アルゴリズムはこれを正しく処理します。 

単調スタックでのタイブレークが正確さを決定するため、すべてが等しいグリッドはより繊細です。 非対称的な使用`<`一方向に、そして`<=`もう 1 つは、各サブ配列が重複によって過剰にカウントされるのではなく、正確に 1 回カウントされることを保証します。 

高値と低値が交互に現れる小さなグリッドでは、特に最も近い大きな要素が直接隣接している場合に、境界計算が行われます。 このような場合、スタック ロジックにより、スパンがサイズ 1 に正しく縮小されることが保証されます。
