 ## 解決策
 ## 問題の理解

 この問題では、2 つのサッカー チームが試合を行っています。 各チームは、次のように示される特定の数のプレーヤーで開始します。`a1`そして`a2`。 試合中、主審は次のように示しています。`n`選手にイエローカード。 各チームにはイエローカードの基準値があり、最初のチームのプレーヤーはイエローカードを受け取った場合に退場になります。`k1`イエローカードが出され、セカンドチームの選手は退場処分を受ける`k2`イエローカード。 審判はどの選手がカードを受け取ったかの記録を紛失しており、合計だけを考慮して、退場になった可能性のある選手の最小数と最大数を決定する必要がある。 

入力は、プレーヤーの数、個々のイエロー カードの制限、および表示されたイエロー カードの総数を表します。 出力は 2 つの整数、つまり退場選手の最小可能数と退場選手の最大数です。 

制約は小さく、すべての値は最大 1000 です。これらの範囲での演算の計算コストは​​無視できるため、パフォーマンスを気にすることなく直接数学的アプローチが可能になります。 重要なエッジケースは、イエローカードの数がプレーヤーのしきい値の合計よりも少ない場合に発生します。 このようなシナリオでは、退場選手が一人も出ない可能性もある。 もう 1 つのエッジ ケースは、イエロー カードの合計が最大の退場を引き起こすことなく配布できる枚数を超えた場合に発生します。 見送りの最大数はプレーヤーの総数を超えることはできません。 

単純なアプローチでは、各イエロー カードを個々のプレーヤーに配布するシミュレーションを試行する可能性がありますが、すべてのカードを反復処理することなく、慎重に数えることでこの問題を解決できます。 

## アプローチ

 ブルートフォースアプローチでは、それぞれのプロセスを反復することになります。`n`イエローカードをいくつかの順番で選手に割り当て、何枚退場になるかを数えます。 これは原理的には機能しますが、`n`まで`a1*k1 + a2*k2`最悪の場合は 1,000,000 になる可能性があるため、カードごとに繰り返す必要はありません。 シミュレーションは正しいですが、冗長で非効率的になります。 

重要な洞察は、個々のカードの割り当てではなく、しきい値の観点から推論することです。 退場選手の最小数については、必要になるまで退場基準に達する選手がいないように、カードをできるだけ均等に分散したいと考えています。 イエローカードの合計が以下の場合`a1*(k1-1) + a2*(k2-1)`、誰かを送り出すことを避けることができます。 それ以外の場合、最小数は、この安全な分布を超えた余分なカードになります。 最大限の効果を得るために、最初に最も閾値の低いプレイヤーにカードを集中させ、できるだけ多くのプレイヤーを退場させます。 これにより、問題は単純な算術に縮小されます。

 ## アルゴリズムのチュートリアル

 1. 誰も退場させずに渡すことができる安全なカードの最大数を計算します。`(a1*(k1-1) + a2*(k2-1))`。 これは、各プレーヤーに退場基準値より 1 つ少ない額を与えることを表します。 これを合計から引きます`n`退場させなければならない選手の最小数を見つけるためです。 結果が負の場合は、見送りの数を 0 より少なくすることはできないため、ゼロに設定します。 
2. 退場選手の最大数については、最初に最低基準値の選手にカードを貪欲に配布したいと考えています。 見送りが最大になるように最適にカードを配った場合、各チームが何回見送りを行えるかを計算します。 これは単純に、`min(a1, n // k1)`最初のチームにとって、そして`min(a2, n // k2)`2 番目のチームの場合は、両方を合計します。 ここ`//`は整数の除算で、各チームが到達できる完全なしきい値の数を表します。 
3. 計算された最小値と最大値を答えとして返します。 

機能する理由: このアルゴリズムが機能するのは、最小値と最大値がしきい値の合計とイエロー カードの合計によって完全に決定されるためです。 カードを広げたり集中させたりする場合、個々のプレイヤーを追跡する必要はありません。 合計は十分です。 私たちが使用するプロパティ、つまり各プレイヤーが吸収できるプロパティ`k1-1`または`k2-1`カードは安全に、そしてそれは`n // k`完全な見送りを表し、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a1 = int(input())
a2 = int(input())
k1 = int(input())
k2 = int(input())
n = int(input())

# Minimum number of players sent off
safe_cards = a1 * (k1 - 1) + a2 * (k2 - 1)
min_sent_off = max(0, n - safe_cards)

# Maximum number of players sent off
max_sent_off = min(a1, n // k1) + min(a2, n // k2)

print(min_sent_off, max_sent_off)
```このソリューションでは、最初に最小限の計算のためにカードの安全な分布を計算します。 最大値については、整数除算により、各チームが吸収できる最大しきい値の数がすぐにわかります。 負の最小値などのエッジ処理は次のように行われます。`max(0, ...)`。 ループは必要ないため、パフォーマンスは一定時間です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a1 = int(input())
    a2 = int(input())
    k1 = int(input())
    k2 = int(input())
    n = int(input())
    safe_cards = a1 * (k1 - 1) + a2 * (k2 - 1)
    min_sent_off = max(0, n - safe_cards)
    max_sent_off = min(a1, n // k1) + min(a2, n // k2)
    return f"{min_sent_off} {max_sent_off}"

# Provided samples
assert run("2\n3\n5\n1\n8\n") == "0 4", "sample 1"
assert run("1\n1\n1\n1\n2\n") == "2 2", "sample 2"

# Custom cases
assert run("1\n1\n2\n3\n0\n") == "0 0", "no yellow cards"
assert run("10\n10\n1\n1\n20\n") == "10 20", "all thresholds minimal"
assert run("2\n3\n5\n5\n5\n") == "0 1", "enough cards for minimal send-off"
assert run("1000\n1000\n1000\n1000\n2000000\n") == "1000 2000", "max input"

## 特殊なケース

 いつ`n`の合計より小さいです`a1*(k1-1) + a2*(k2-1)`、最低見送りはゼロです。 例えば、`a1=2`、`a2=3`、`k1=5`、`k2=5`、`n=10`。 安全なカードは、`2*4 + 3*4 = 20`。`n - safe_cards = -10`、最小値は 0 です。アルゴリズムはこれを正しく計算します。
