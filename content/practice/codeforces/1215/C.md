 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`そして`t`、文字「a」と「b」のみで構成される同じ長さ。 課題は、`s`そして`t`許可された一連のスワップ操作を使用して同一になります。 各操作で次から 1 文字を選択できます。`s`そしてからの1つ`t`そしてそれらを交換します。 目標は、最小限のスワップ数で平等を達成するか、それが不可能であると判断することです。 

重要な観察は、スワップは 2 つのポジションにのみ影響するということです。`s`そして1つは`t`。 ある位置で文字がすでに等しい場合、それらを交換する必要はありません。 したがって、次の位置のみを考慮する必要があります。`s[i] != t[i]`。 これにより、問題は一連の不一致ペアに帰着します。 それぞれの不一致は、次の 2 つのタイプのいずれかに分類できます。`s[i] = a, t[i] = b`(これをAB型と呼びます)`s[i] = b, t[i] = a`(タイプBA)。 

とすれば`n`最大 200,000 で、2 秒の時間制限があるため、考えられるすべてのスワップを単純にチェックするソリューションでは遅すぎます。 すべての組み合わせを試す強引なアプローチは O(n²) となり、これは受け入れられません。 線形時間ソリューションが必要です。 エッジケースには、特定の不一致タイプが奇数に存在することが含まれており、問題が解決不能になる可能性があります。 たとえば、AB の不一致が 1 つだけあり、BA の不一致がない場合、スワップでは解決できないため、出力は -1 になる必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのポジションを反復処理します。`s`そして`t`不一致がある場合は常に交換し、可能な限りあらゆる組み合わせを試します。`s`等しい`t`。 可能であれば、最終的にはすべての不一致が解決されるため、これは正しいです。 ただし、このアプローチは遅すぎます。最悪の場合、考慮される操作の数が n² に近づく可能性があり、これは n = 200,000 としては多すぎます。 

最適なアプローチは、同じタイプの不一致をペアにしてスワップの数を減らすことができるという洞察に基づいています。 具体的には、2 つの AB の不一致は、次の 1 つの文字を交換することで解決できます。`s`最初の不一致と 2 番目の不一致により、両方が修正されます。 同様に、2 つの BA の不一致も同じ方法で解決できます。 1 つの残りの AB と 1 つの残りの BA の不一致がある場合、最初に文字列内で「自己スワップ」を実行できます。`s`解決可能なペアに変換してから交換します`s`そして`t`。 このアプローチでは、不一致の位置のみを反復してペアで処理するため、スワップの数を最小限に抑え、線形時間で実行できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つのリストを初期化します。`ab`そして`ba`、タイプ AB および BA の不一致がそれぞれ発生するインデックスを格納します。 このステップにより、不一致を効率的に分類できます。 
2. 文字列を反復処理する`s`そして`t`並行して。 いつでも`s[i] != t[i]`、追加`i`適切なリスト (`ab`もし`s[i]='a'`そして`t[i]='b'`、`ba`もし`s[i]='b'`そして`t[i]='a'`）。 これにより、問題が不一致タイプごとに独立したサブ問題に分割されます。 
3. 不一致の合計数が奇数の場合、各スワップで 2 つの不一致が解決されるため、すべての不一致を解決することは不可能です。 この場合は -1 を返します。 具体的に言うと、`(len(ab) + len(ba)) % 2 != 0`の場合、-1 を出力します。 
4. 内のインデックスをペアにします。`ab`連続した順序でリストします。 各ペア`(i, j)`間で 1 回のスワップが必要です`s[i]`そして`t[j]`。 同じプロセスを繰り返します`ba`リスト。 これにより、スワップごとに 2 つの不一致が解決され、操作の数が削減されます。 
5. 両方の場合`ab`そして`ba`奇数の長さの場合、それぞれに 1 つのインデックスが残ります。 まず内部でスワップを実行します`s`残りの AB インデックスと同じインデックスで`t`問題を BA の不一致のペアに変換します。 次に、これらの変換された位置の間で交換を実行します。 これには、正確に 2 つの追加のスワップが必要です。 このトリックにより、すべての不一致が最小限の操作で確実に解決されます。 
6. スワップの総数とスワップ操作のリストを順に出力します。 各操作はインデックスで表されます`(pos_s, pos_t)`。 

機能する理由: 各ステップで、同じタイプの不一致をペアにするか、不一致のペアを解決可能な構成に変換します。 新たな不一致を引き起こす操作はありません。 不変条件は、すべてのペアを処理した後、すべての不一致が解決され、文字列が等しいということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()
t = input().strip()

ab = []
ba = []

for i in range(n):
    if s[i] != t[i]:
        if s[i] == 'a' and t[i] == 'b':
            ab.append(i + 1)  # using 1-based indexing
        else:
            ba.append(i + 1)

if (len(ab) + len(ba)) % 2 != 0:
    print(-1)
else:
    ops = []

    for i in range(0, len(ab) - len(ab) % 2, 2):
        ops.append((ab[i], ab[i + 1]))
    for i in range(0, len(ba) - len(ba) % 2, 2):
        ops.append((ba[i], ba[i + 1]))

    if len(ab) % 2 == 1:
        last_ab = ab[-1]
        last_ba = ba[-1]
        ops.append((last_ab, last_ab))
        ops.append((last_ab, last_ba))

    print(len(ops))
    for x, y in ops:
        print(x, y)
```このソリューションは、まず不一致を特定し、次にペアリングによってそれらを効率的に解決し、最後に 2 段階のスワップで残りの奇数ペアを処理します。 微妙な点は、出力に対して 1 から始まるインデックスを付けることと、残った単一のペアを正しく処理することです。
