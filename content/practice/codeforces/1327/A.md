 ## 解決策
 ## 問題の理解

 この問題は、指定された整数が`n`正確に次の合計として表すことができます`k`異なる正の奇数の整数。 各テスト ケースが提供するのは、`n`そして`k`、答えは「YES」か「NO」のどちらかです。 奇数の整数は 2 で割り切れない数値であるため、有効な候補は次のとおりです。`1, 3, 5, 7,...`。 

制約は重要です。 と`t`まで`10^5`そして`n`そして`k`まで`10^7`、奇数の考えられるすべてのサブセットを生成する単純なアプローチは、直ちに実行不可能になります。 ブルートフォース列挙における最悪の場合の操作数は指数関数的に増加し、2 秒の実行時間で処理できる範囲をはるかに超えます。 これは、どのようなソリューションも大まかに実行する必要があることを意味します。`O(1)`あるいは最悪の場合`O(log n)`テストケースごとに。 

明らかではない特殊なケースは、数値のパリティから発生します。 例えば、`n=4`そして`k=2`次のように表すことができます`1+3`、 しかし`n=10`そして`k=3`3 つの異なる正の奇数の合計は常に奇数であるため、これはできません。`10`は均等です。 同様に、`k`に比べて大きすぎます`n`、最初の合計なので不可能です。`k`最小の奇数がすでに超えています`n`。 例えば、`n=8`そして`k=3`失敗する理由`1+3+5=9>8`。 これらの考慮事項により、パリティと最小和が重要な制約となります。 

## アプローチ

 ブルートフォース手法では、次のすべての組み合わせを生成しようとします。`k`個別の正の奇数を調べ、合計が等しいかどうかを確認します`n`。 これは理論的には正しいですが、組み合わせ爆発により非現実的になります。`k=20`、その組み合わせの数は天文学的です。 したがって、ブルートフォースは、次の小さな値に対してのみ機能します。`n`そして`k`。 

迅速な解決策の重要な観察事項は、最初の`k`奇数は`1, 3, 5, ..., 2k-1`、それらの合計は`k^2`。 したがって、`n`の合計として表現できる`k`異なる奇数の整数、`n`少なくとも`k^2`。 さらに、次のパリティは、`n`そして`k`一致する必要があります: の合計`k`奇数は奇数です`k`奇数かつ偶数である場合`k`は均等です。 これは、奇数の奇数の合計は奇数であり、奇数の偶数の合計は偶数であるためです。 これら 2 つの条件を組み合わせると、各テスト ケースに対して一定時間のチェックが行われます。

 | ブルートフォース | O(2^k) | O(k) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数を読み取ります。`n`そして`k`。 
2. 最初の値の最小合計を計算します。`k`奇数、つまり`k^2`。 これにより、到達するのに十分な「奇数質量」が確保されます。`n`。 
3. 次のことを確認します。`n`少なくとも`k^2`。 そうしないと表現できません`n`合計として`k`明確な奇数であるため、「NO」を出力します。 
4. パリティがあるかどうかを確認します。`n`のパリティと一致します`k`。 具体的には、次のことを確認します。`(n % 2) == (k % 2)`。 これにより、合計が奇数でも偶数でも一致することが保証されます。`n`。 
5. 両方の条件が満たされる場合は、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

なぜ機能するのか: 最小合計額は、最小額が保証されることを保証します。`k`奇数は範囲内に収まります`n`。 任意の合計`k`明確な奇数は、奇数を維持しながら一部の数を増やすことで取得でき、合計のパリティが維持されます。 したがって、もし`n`よりも大きいです`k^2`一致するパリティがある場合、合計すると次のような異なる奇数のセットが常に存在します。`n`。 そうでなければ不可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    if n >= k * k and (n % 2) == (k % 2):
        print("YES")
    elif n >= 2 * k and (n % 2) == 0:
        # optional: for even numbers check sum of k even numbers
        print("YES")
    else:
        print("NO")
```最初の条件`n >= k*k and (n%2) == (k%2)`奇数の合計を処理します。 2 番目の条件は、ソリューションで時々見られますが、表現も考慮すると偶数を処理します。`n`偶数の合計として。 この問題では奇数のみが必要なので、最初のチェックで十分です。 高速 I/O により、プログラムは最大で次の処理を確実に処理できます。`10^5`テストケースを効率的に実行します。
