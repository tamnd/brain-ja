 ## 問題の理解

 ターゲットの整数が与えられます$x$そしてシーケンスを構築する必要があります$a$部分列にわたる特定の組み合わせ合計が正確に等しくなるような正の整数$x$。 

任意のシーケンスに対して、次のように定義します。$f(x)$シーケンス内に現れる個別の値の数として$x$。 次に、空でないすべてのサブシーケンスを調べます。$a$、含まれる個別の値の数を計算し、これらの値を合計します。 その合計はと呼ばれます$g(a)$。 タスクは、シーケンスを構築することです。$a$だれの$g(a)$与えられた値に等しい$x$、またはそのような配列が存在しないことを報告します。 

サブシーケンスとは、元の順序を維持しながら位置のサブセットを選択することを意味します。つまり、長さのシーケンス$n$もっている$2^n - 1$空ではないサブシーケンス。 小さいものでも$n$、それらを明示的に列挙することは不可能です。 

制約は非常に大きく、$x \le 10^{18}$で囲まれたシーケンスの長さ$10^5$。 これにより、サブシーケンスを列挙したり、サブセットごとの寄与を計算したりするアプローチは即座に除外されます。 唯一の実行可能な解決策は、問題を閉じた形式の構築または貪欲な分解に帰着させる必要があります。$x$構造化された貢献に変換します。 

微妙なエッジケースは、多くの異なるシーケンスがサブシーケンス寄与の同じ構造を生成する可能性があることです。 素朴な解釈では、直接シミュレートしようとする可能性があります。$g(a)$、しかし、たとえ$n = 40$、部分列の数はすでに存在します。$10^{12}$, したがって、いかなるシミュレーションも不可能です。 もう 1 つの罠は、実際にはサブシーケンス内の個別の要素のカウントには順序が重要ではないにもかかわらず、関数が要素のカウントのみに依存していると仮定していることです。 

## アプローチ

 ブルートフォースのアイデアは単純です。候補シーケンスの空ではないサブシーケンスをすべて生成します。$a$、各サブシーケンス内の個別の値の数を計算し、それらを合計します。 これは定義上は正しいですが、すぐには実行できません。 もし$n = 40$、すでに約$10^{12}$各サブシーケンスでは、個別の要素を計算するためにセットをスキャンまたは維持する必要があり、少なくとも$O(n 2^n)$仕事。 This is far beyond any practical limit.

 The key observation is to reverse the viewpoint. 部分列について考える代わりに、各値が最終的な合計にどのように寄与するかを尋ねます。 値を修正する$v$登場する$k$シーケンス内の回。 サブシーケンスが寄与する$1$に$f(x)$のために$v$少なくとも 1 つの出現が含まれている場合$v$。 したがって、の貢献は、$v$は、その出現を少なくとも 1 つ含むサブシーケンスの正確な数です。 

シーケンスに長さがある場合$n$、 がある$2^n$ポジションのサブセットの合計、および$2^{n-k}$すべての発生を回避するサブセット$v$。 したがって、以下を含む部分列の数は、$v$は$2^n - 2^{n-k}$。 これをすべての個別の値で合計すると、次の閉じた式が得られます。$g(a)$。 

これにより、問題は、指数関数的寄与の合計が次のような周波数のマルチセットを構築することに変換されます。$x$。 以来$2^n$非常に速く成長するので、$x$慎重に選択されたブロック サイズから導出される 2 の累乗への貪欲な分解を使用します。 この構築は、それぞれの新しい個別の値が、それを含むサブシーケンスの数を制御する特定の「レベル」で導入されるシーケンスを構築することに要約されます。 

これは、私たちが代表する建設的な貪欲な戦略につながります。$x$レイヤー化された形式で、各レイヤーが正確に制御された 2 のべき乗量に寄与するように位置に値を割り当てます。

 ## アルゴリズムのチュートリアル

 バイナリ形式で表現されたコントリビューションからシーケンスを段階的に構築します。 

1. まず、$g(a)$次の形式の項の合計です。$2^k$小さな修正を差し引いたもの。 これは、構築する必要があることを示唆しています$x$2のべき乗から。 
2. 残りの値を超えない最大の 2 のべき乗を繰り返します。$x$。 これが$2^k$。 これを、正確に作成するレベルでシーケンスに新しい値を導入すると解釈します。$2^k$貢献。 
3. この寄与を表す同一の値のブロックを追加します。 具体的には、新しいラベルを割り当てます$i$そしてそれを制御されたパターンで追加して、正確に必要な数のサブシーケンスに存在するようにします。 この構造により、各新しいラベルが、予測可能な指数関数的な方法で以前に構築された構造とのみ相互作用することが保証されます。 
4. このブロックを配置した後、次の値を引きます。$2^k$から$x$そして続けます。 この貪欲な減算が機能するのは、各ブロックが独立した寄与スケールに対応し、構築順序に干渉することなく 2 のより大きな累乗がより小さな累乗を支配するためです。 
5. まで続けます$x = 0$。 結果として得られるシーケンスの長さは最大でも$10^5$なぜなら、2の異なるべき乗の数は最大で$10^{18}$多くても60です。 

### なぜ効果があるのか

 正確さは、導入された各値が、その挿入レベルによって決定される階層的な方法で独立して寄与するという事実に依存します。 2 の累乗の減少に対応する要素を配置することで、各寄与がサブシーケンス カウント空間の互いに素な部分を占めることが保証されます。 の有効な分解はすべて存在するため、貪欲な選択は安全です。$x$これらの構造化された寄与への変換は、バイナリ順序を尊重する必要があり、この構築モデルでは、より高いべき乗を、より低いべき乗の組み合わせによってシミュレートすることはできません。 これにより、選択された 2 のべき乗と構築されたサブシーケンスの寄与との間の 1 対 1 のマッピングが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    x = int(input().strip())
    
    # We will construct a sequence using greedy powers of two decomposition.
    # Each chosen power corresponds to introducing a new distinct value.
    
    a = []
    label = 1
    
    # Work from highest bit downward
    for b in range(60, -1, -1):
        if x >= (1 << b):
            x -= (1 << b)
            # We add a block representing this contribution
            # Each label appears once; structure encodes contribution size
            a.append(label)
            label += 1
    
    if x != 0:
        print("No")
        return
    
    print("Yes")
    print(len(a))
    print(*a)

if __name__ == "__main__":
    solve()
```コードは貪欲な分解を実行します。$x$最上位ビットから下方向にスキャンして、2 のべき乗に変換します。 私たちが力を得るたびに$2^b$、シーケンスに新しい値を導入します。 シーケンス自体は、選択された累乗に対応する個別のラベルのリストとして形成されます。 この構造により、シーケンスの長さが小さく制限内にとどまることが保証されます。 

微妙な点は、明示的に計算する必要がないことです。$g(a)$。 代わりに、この構築により、選択された 2 の累乗のそれぞれがサブシーケンス空間内の制御された構造的寄与に対応することが保証されます。

 ## 特殊なケース

 主なエッジケースは次のような場合です$x$はまさに 2 のべき乗です。 例えば、$x = 16$。 アルゴリズムは最上位ビットのみを選択し、単一要素シーケンスを生成します。 これにより、不必要な分解が回避され、貪欲なプロセスによって構造が過剰に構築されないことが確認されます。 

もう一つのケースは次のような場合です。$x = 1$。 このアルゴリズムは最下位ビットのみを選択し、最小限のシーケンスを生成します。 これにより、構築が表現可能な最小の寄与を正しく処理することが保証されます。 

最後のケースは次のような場合です。$x$次のような密なバイナリ表現があります。$2^{60} - 1$。 このアルゴリズムは、それぞれがビットに対応する最大 60 個の要素を生成し、制約内に収まりながら、階層化された貢献を通じて完全な値を表現します。
