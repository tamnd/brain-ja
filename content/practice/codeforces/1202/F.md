### なぜ効果があるのか

 正しさは、周期性によって文字列が重み付き割り当て問題に帰着するという事実に基づいています。`k`パターンの位置。 すべての有効な文字列は、どのパターン インデックスが A であるかを選択することに対応し、誘導される合計数は、高周波剰余ブロックに分類されるインデックスの数にのみ依存します。 周波数構造は完全に決定されるため、`n mod k`そして`n // k`、ピリオドを含むすべての可能な文字列`k`同じ実現可能条件にマッピングされます。 逆に、パターン位置への A の有効な割り当ては、そのピリオドを含む有効な文字列を構築します。 これにより、実現可能な期間と導出された制約システムの整数解との間に 1 対 1 の対応関係が確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(n, k, a):
    q = n // k
    r = n % k
    # We try all possible t: number of A's placed in the r high-frequency slots
    # total A = t*(q+1) + (x-t)*q = x*q + t
    # so total A ≡ t (mod q), and 0 <= t <= r
    # and x = (a - t) / q must be integer in [0,k]
    for t in range(min(r, q) + 1):
        if (a - t) % q == 0:
            x = (a - t) // q
            if 0 <= x <= k:
                return True
    return False

def solve():
    a, b = map(int, input().split())
    n = a + b

    ans = 0
    k = 1
    while k <= n:
        q = n // k
        if q == 0:
            k += 1
            continue
        l = k
        r = n // q
        for kk in range(l, r + 1):
            if ok(n, kk, a):
                ans += 1
        k = r + 1

    print(ans)

if __name__ == "__main__":
    solve()
```コードはまず、次の値をグループ化することで検索スペースを圧縮します。`k`同じ商を共有するもの`q = n // k`。 各グループ内では、繰り返しの構造は剰余位置の境界まで同一です。 候補期間ごとに`k`、関数`ok`正確に結果をもたらす、パターン スロット全体にわたる A の有効な割り当てが存在するかどうかをチェックします。`a`繰り返し後の合計A。 

よくある間違いは、次の約数のみが考慮されると想定することです。`n`案件。 実装では、剰余ブロックを明示的に処理することでこれを回避します。`r = n % k`、不完全な繰り返しが頻度分布にどのような影響を与えるかをキャプチャします。

 ## 特殊なケース

 微妙なケースの 1 つは、すべての文字が同一である場合です。`a = n, b = 0`。 どの繰り返しでも均一性が保たれるため、すべての周期構造が有効になります。 実行可能条件は常に成功するため、アルゴリズムはこれを自然に処理します。`k`、A の分布には制約がないためです。
