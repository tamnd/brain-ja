 ## 問題の理解

 3 つの整数配列が与えられます`a`、`b`、`c`、それぞれの長さ`n`。 配列`a`更新可能な動的シーケンスを表します。 配列`b`そして`c`関係を定義する固定マッピングです。`b[x]`に関連付けられた値を与えます`x`から`a`、 そして`c[x]`インデックスに関連付けられた別の値を与えます。 

操作には 2 つのタイプがあります。 最初のメソッドは、次の単一要素を更新します。`a`。 2 番目の関数は、増加する三つ子の数を求めます。`(i, j, k)`と`i < j < k ≤ r`中央の要素が`a[j]`等しい`b[a[i]]`そして最後の要素`a[k]`等しい`c[a[i]]`。 タイプ 2 の各操作は配列のプレフィックスをクエリするため、結果はインデックス 1 から 1 までの要素のみに依存します。`r`。 

制約は重要です。`n`最大 200,000、操作数は 50,000 です。 三重項を数える単純な三重ループは次のように実行されます。`O(n^3)`クエリごとの操作が大きすぎます。 平`O(n^2)`最悪の場合は受け入れられません。 どのソリューションも動的更新を効率的に処理し、二次時間以内にクエリに応答できる必要があり、理想的にはプレフィックス全体のカウントを蓄積し、変更に迅速に対応できるデータ構造を使用します。 

明らかではないエッジ ケースには、多くの値が含まれるシナリオが含まれます。`a`配列の境界に等しいか、境界に近い値です。 たとえば、次の場合`a = [1,1,1]`、`b = [1,1,1]`、`c = [1,1,1]`、配列全体をクエリします。トリプレットの数には、有効なすべてのものが正しく含まれている必要があります。`(i,j,k)`組み合わせ。 不用意に実装すると、繰り返される値が無視されるため、過小評価される可能性があります。 もう 1 つの注意が必要なケースは、タイプ 1 の更新により、`a[i]`これは多くの既存のトリプレットに関与しており、以前にカウントされたトリプレットが無効になる可能性があります。 アップデートを適切に処理することが重要です。 

## アプローチ

 ブルートフォースアプローチでは、可能な限りすべての攻撃が繰り返されます。`i, j, k`タイプ 2 のクエリごとに 3 つずつ抽出し、条件を満たすものをカウントします。 これは正しいですが、実際には機能します`O(r^3)`クエリごとの操作。 と`r`まで`n = 200,000`複数のクエリがあると、これはすぐに実行不可能になります。 更新には、すべてを最初から再計算する必要もあります。 

重要な観察は、この問題がプレフィックス合計またはセグメント ツリーを使用する計数問題に還元できるということです。 インデックスごとに`j`、有効な数が必要です`i`前に`j`どこ`b[a[i]] = a[j]`そして有効枚数`k`後`j`どこ`c[a[k]] = a[j]`。 これらのカウントを効率的に前処理または維持すると、各クエリは次のように解決できます。`O(n log n)`あるいは、フェンウィック ツリーまたはバイナリ インデックス付きツリーを使用する方がよいでしょう。 洞察は、トリプレット条件を 2 つの独立したカウント (左側) に分離することです。`i`そして右側`k`) そして、各中間に対してこれらのカウントを乗算します。`j`。 

また、更新を効率的に処理する必要もあります。 いつ`a[k]`が変更されると、多くのトリプレットに影響を与える可能性があります。 の値をキーとしたフェンウィック ツリーの使用`a`すべてのトリプレットを再計算せずにカウントを動的に更新できます。

 ## アルゴリズムのチュートリアル

 1. 2 つのフェンウィック ツリー (バイナリ インデックス付きツリー) を構築します。1 つは左側のカウント用です (`i`) と右側のカウント用の 1 つ (`k`）。 左側のツリーはインデックスの数を追跡します`i`満足する`b[a[i]] = val`可能な限り`val`。 右側のツリーはインデックスの数を追跡します`k`満足する`c[a[k]] = val`それぞれに`val`。 これにより、トリプレット条件が 2 つの管理可能なカウントに分割されます。 
2. 配列の前処理`a`右側のツリーにデータを入力します。 インデックスごとに`k`、カウントをインクリメントします`c[a[k]]`。 これにより、最初は可能な限りすべてのことが確実に行われます。`a[j]`、適切なツリーは、潜在的な可能性の数をすぐに教えてくれます。`k`はその後も存在します`j`。 
3. タイプ 2 クエリを処理するときに配列を反復処理します。 中間インデックスごとに`j`、 取り除く`a[j]`右の木から（なぜなら`k`厳密に後である必要があります`j`) 有効な数を読み取ります。`i`左の木から（`b[a[i]] = a[j]`) と有効な数`k`右の木から（`c[a[k]] = a[j]`）。 これらのカウントを乗算して結果に加算します。 
4. 左側のツリーを更新して次の内容を追加します。`a[j]`有効なものとして`i`その後の`j`s. これにより、左側のツリーが常に現在のインデックスの厳密に前のカウントを表すという不変条件が維持されます。`j`。 
5. タイプ 1 更新の場合、両方のツリーを調整します。`a`変更がある場合は、右側のツリー (以前のツリーに影響を与える場合は左側のツリー) の古い値をデクリメントします。`j`) して、新しい値をインクリメントします。 これにより、すべてを再計算しなくてもクエリ ロジックが動作し続けることが保証されます。 
6. タイプ 2 のクエリごとに手順 3 ～ 5 を繰り返します。 

機能する理由: このアルゴリズムは、フェンウィック ツリー内の潜在的な左右のトリプレット メンバーの数を維持します。 各中間インデックスで`j`、有効なトリプレットの数は、正確に有効なトリプレットの数の積です。`i`そして`k`。 更新では関連するカウントのみが更新されるため、すべてのクエリは現在の状態を反映します。`a`。 3 連符は 2 回数えられません。`j`は 1 回だけ考慮されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.tree = [0]*(n+2)
    def add(self, i, x):
        while i <= self.n:
            self.tree[i] += x
            i += i & -i
    def sum(self, i):
        res = 0
        while i > 0:
            res += self.tree[i]
            i -= i & -i
        return res
    def range_sum(self, l, r):
        return self.sum(r) - self.sum(l-1)

n, m = map(int, input().split())
a = list(map(int, input().split()))
b = [0]+list(map(int, input().split()))
c = [0]+list(map(int, input().split()))

ops = [input().split() for _ in range(m)]

from collections import defaultdict

for op in ops:
    if op[0] == '2':
        r = int(op[1])
        left = Fenwick(n)
        right = Fenwick(n)
        for k in range(1, r+1):
            right.add(c[a[k-1]], 1)
        res = 0
        for j in range(1, r+1):
            val = a[j-1]
            right.add(c[val], -1)
            count_i = left.sum(val) - left.sum(val-1)
            count_i = left.range_sum(val, val)
            count_i = left.sum(val) - left.sum(val-1)
            count_i = left.range_sum(b[val], b[val])
            count_k = right.range_sum(val, val)
            res += count_i * count_k
            left.add(b[val], 1)
        print(res)
    else:
        _, k, x = op
        k = int(k)-1
        x = int(x)
        a[k] = x
