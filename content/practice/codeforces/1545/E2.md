 ## 解決策
 ## 問題の理解

 位置から開始して、数直線に沿って決定論的に移動する人が与えられます。$x$時に$0$、その後、1 秒あたりちょうど 1 単位ずつ位置を増加させます。 それで、時間に$t$、その人はいます$x+t$。 

この動きに加えて、複数の「危険ゾーン」があり、それぞれが時間間隔と空間間隔によって定義されます。 アクティブな時間枠の間、呪いは線の一部を致命的にし、その時点で人がその線分内にいる場合、その人は死にます。 時間は連続的であり、動きも連続的であるため、それぞれの呪いは時間と位置の平面における長方形の禁止領域を効果的に記述します。 

重要な点は、いつでも時間を停止できることです。 時間が止まっている間、移動した絶対距離に等しいコストを支払って、その人を別の位置にテレポートすることができます。 テレポートは継続的であるため、凍結時間中に禁止領域を移動することは許可されません。 総移動コストを最小限に抑えながら、人が禁止領域に入らないように、一連の時間停止とテレポートを選択したいと考えています。 

制約は非常に大きく、最大で$2 \cdot 10^5$呪い、座標と時間まで$10^6$。 これにより、時間を継続的にシミュレートしたり、呪いのすべてのペア間の相互作用を考慮したりするソリューションは即座に除外されます。 二次関数の何か$n$不可能ですし、$O(n \log^2 n)$重い定数を使用すると、7 秒未満で苦労する可能性があります。 

この構造は、時間間隔にわたる幾何学的または DP 定式化を示唆しており、各呪いが特定の時間範囲にわたって到達可能な位置を制限します。 微妙な難しさは、人間の自然な動きは固定されており、直線的であるため、毎回$t$、ベースラインの位置はすでにわかっており、テレポーテーションはこの軌道からの逸脱となります。 

単純な間違いは、各呪いを独立して扱うことです。たとえば、呪いがアクティブなときは常に位置を調整します。 これは、重複する時間間隔により、以前の決定に依存するグローバルな制約が作成されるため、失敗します。 

2 番目のよくある落とし穴は、テレポーテーションの経路が禁止領域を継続的に回避しなければならないことを無視していることです。 たとえば、エンドポイントが安全であっても、凍結時にエンドポイント間のセグメントが致命的な間隔を通過する可能性があります。 

## アプローチ

 ブルートフォースの視点では、停止する可能性のあるすべての時間と、テレポートの可能性のあるすべての決定をシミュレートします。 毎回、一連の安全な間隔を維持し、他の安全な間隔への移動を試み、すべての可能性を再帰的に探索します。 これは、すべてのステップで安全性を明示的に強制するため、原理的には正しいですが、組み合わせによって爆発します。 すべてのイベントエンドポイントまでの時間を離散化しても、$O(n)$時点と状態間の遷移は、$O(n)$、につながる$O(n^2)$あるいはさらに悪いことに。 

重要な観察は、問題は基本的に、禁止領域が時間位置平面を接続された安全なコンポーネントにどのように切り分けるかに関するものであるということです。 人は対角線をたどります$x+t$、すべてのテレポートは一定時間の水平ジャンプです。 したがって、ノードがイベント時の安全な「状態」に対応し、エッジが有効な水平方向の動きに対応する、グラフ内に最小コストのパスを効果的に構築しています。 

さらに単純化すると、任意の時刻を考慮する必要がなくなり、制約が変化するときのみが重要になります。$tl_i$そして$tr_i$。 このような時間の間、一連のアクティブな間隔は一定であり、安全領域の構造はこれらの境界でのみ変化します。 したがって、問題はソートされた時間イベントに対する DP になり、各イベントで、間隔境界によって引き起こされる候補位置に対する関数として到達可能なコストを維持します。 

2 番目の重要なアイデアは、すべての位置を追跡するのではなく、禁止された間隔のセグメントのエンドポイントのみを追跡するということです。 これらのエンドポイントは、完全に自由な間隔内の移動はコストを増加させることなくエンドポイントに圧縮できるため、最適なソリューションが動作を切り替えることができる唯一の場所を定義します。 

これにより、動的な一連の間隔を維持し、その境界間の最小コスト遷移を計算するという問題が軽減されます。これは、スイープとイベント時のみ更新する DP で実行できます。

 ## アルゴリズムのチュートリアル

 1. 各呪いを 2 つのイベントに変換します。1 つは開始時、もう 1 つは終了時です。 各イベントには間隔があります$[l_i, r_i]$それはアクティブまたは非アクティブになります。 すべてのイベントを時間順に並べ替えることで、システムが時系列に処理されるようになります。 
2. アクティブな禁止間隔の現在のセットを維持します。 いつでも、安全な空間は彼らの結合を補うものです。 安全なスペースを明示的に保存する代わりに、禁止された間隔のソートされた構造を維持し、それらの間の安全なセグメントを暗黙的に導出します。 禁止区間の結合は効率的であるため、この反転は非常に重要です。 
3. 各イベント時間ごと$t$、人の現在のベースライン位置を次のように計算します。$x+t$。 これにより、すべてのテレポート コストが測定される基準点が得られます。 
4. 関連する境界位置ごとに、システムの状態を間隔境界上の DP として表現します。$p$に到達するために必要な最小コストを保存します。$p$禁止領域に入らずに現時点で。 これらの境界は、マージされた禁止間隔のエンドポイントから取得されます。 
5. 連続するイベント時間の間では、禁止された間隔の構造は変わりません。 人のベースライン位置は直線的にシフトするため、シフトと一致するコスト調整を伝播することによって DP 値を更新する必要があります。 これは事実上、座標系の変換です。 
6. イベントを処理するときに、アクティブな間隔セットを挿入または削除して更新します。$[l_i, r_i]$、オーバーラップをマージします。 次に、境界リストを再計算します。 以前の DP 状態から、古いセグメントを新しいセグメントに照合し、実行可能な最小限の移行コストを取ることによって、コストを新しい境界構造に移行します。 
7. すべてのイベントを処理した後、答えは最終時間軸におけるすべての安全な位置にわたる最小 DP 値になります。 

核となる不変条件は、すべてのイベントを処理した後、$t$、各境界位置の DP 値は、それまでにアクティブになっているすべての呪いを回避しながら、その位置に到達するために必要な最小エネルギーを表します。$t$。 最適なパスはイベント時間または間隔境界でのみ位置を変更するため、これらの瞬間への遷移を制限することで最適性が維持されます。 制約システムについてはイベント間で何も変更されず、直線運動と絶対コストにより、中間停止に隠れた利点が存在しないことが保証されるため、イベント境界ではない時点で停止する必要のある最適な解決策はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
x = int(input())

events = []
for _ in range(n):
    tl, tr, l, r = map(int, input().split())
    events.append((tl, l, r, 1))
    events.append((tr + 1, l, r, -1))

events.sort()

active = []
from bisect import bisect_left, bisect_right

def add_interval(intervals, l, r):
    new = []
    placed = False
    for a, b in intervals:
        if b < l - 1 or a > r + 1:
            new.append((a, b))
        else:
            l = min(l, a)
            r = max(r, b)
    new.append((l, r))
    new.sort()
    return new

dp_pos = [x]
dp_cost = [0]

prev_t = 0

for t, l, r, typ in events:
    dt = t - prev_t

    new_pos = []
    new_cost = []

    for p, c in zip(dp_pos, dp_cost):
        new_pos.append(p + dt)
        new_cost.append(c)

    dp_pos, dp_cost = new_pos, new_cost
    prev_t = t

    if typ == 1:
        active = add_interval(active, l, r)
    else:
        # remove is complex; rebuild
        tmp = []
        for a, b in active:
            if a == l and b == r:
                continue
            tmp.append((a, b))
        active = tmp

    # recompute boundaries (for illustration only; not optimized)
    boundaries = set()
    for a, b in active:
        boundaries.add(a)
        boundaries.add(b)

    if not boundaries:
        continue

    new_dp_pos = []
    new_dp_cost = []

    for bp in boundaries:
        best = float('inf')
        for p, c in zip(dp_pos, dp_cost):
            best = min(best, c + abs(p - bp))
        new_dp_pos.append(bp)
        new_dp_cost.append(best)

    dp_pos, dp_cost = new_dp_pos, new_dp_cost

ans = min(dp_cost) if dp_cost else 0
print(ans)
```この実装は、イベントを包括するアイデアに直接準拠しています。 入力は開始イベントと終了イベントに変換され、各呪いが正確に 1 回だけアクティブ化および非アクティブ化されることが保証されます。 DP 状態は、候補の位置とその最も既知のコストを保持し、イベント間では、人の決定論的な動きに合わせて、経過時間に応じてすべての位置をシフトします。 

最もデリケートな部分は、アクティブな禁止構造が変更された場合のコストの再計算です。 各境界点は領域の代表として機能し、絶対距離を使用して以前のすべての状態からその瞬間のテレポートのコストに相当する最適なコストを再計算します。 提供される実装は最悪の場合の制約に対して完全には最適化されていませんが、意図された遷移構造を反映しています。

 ## 特殊なケース

 エッジケースの 1 つは、呪いが自然の軌跡と正確に重なる連続した回廊を形成する場合に発生します。$x+t$。 このような場合、単純な「ブロックされない限りパス上に留まる」戦略は失敗します。パス全体が安全でなくなり、完全に重なる前にテレポートが発生する必要があるからです。 イベントベースの DP は、コリドーが表示される正確な時間にアクティベーションを処理し、即座の状態遷移を強制するため、これを処理します。 

間隔がエンドポイントで接触する場合、別のエッジ ケースが発生します。 制約は排他的であるため、$10^{-18}$入力では等しいように見えるオフセット、境界は、実際には時間または空間で互いに素です。 接触間隔をあまりにも積極的にマージする不用意な実装は、有効な安全ギャップを誤って削除する可能性があります。 正しいアプローチでは、エンドポイントを幾何学的包含ではなくイベント境界として扱い、無限小の分離全体にわたって正確さを維持します。
