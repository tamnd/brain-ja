 ## 解決策
 ## 問題の理解

 幅によって定義される長方形のゲーム レベルが与えられます。`a`と高さ`b`。 レベル内には、`n`それぞれが独自の位置にいる敵`(x_i, y_i)`。 すべての敵は基本またはアップグレードのいずれかです。基本の敵は軸に沿って 4 つのレーザーを発射し、アップグレードされた敵は軸と対角に沿ってレーザーを発射します。 各敵には確率がある`p_i`他のものとは独立してアップグレードされること。 

レーザーは長方形を領域に分割します。 必要な出力は、すべてのレーザーによって形成される予期される領域の数です。`998244353`。 各敵はアップグレードできるかどうかが異なるため、領域の総数はランダム変数になります。 期待値は、その構成の確率とそれが生成する領域の数を掛けたすべての構成の合計です。 

問題の制約は中程度です。`n`は最大 100、長方形のサイズは最大 100x100 です。 構成数は`2^n`可能な組み合わせをすべて列挙することは、最大の組み合わせでは実行不可能です。`n`。 構造を活用した、よりスマートなアプローチが必要です。 

明らかではないエッジ ケースには、すべての敵が 1 つの行または列に配置され、複数のレーザーが同じ線に沿って重なる場合が含まれます。 すべてのレーザーを新しい領域の作成として扱う単純なカウントでは、過剰にカウントされてしまいます。 もう 1 つのエッジ ケースは、2x2 グリッド内の単一の敵です。敵のタイプに応じて 4 つまたは 8 つの領域が生成され、確率的な組み合わせがテストされます。 

## アプローチ

 ブルートフォースアプローチは、すべてを反復処理することです。`2^n`基本/アップグレード状態の可能な割り当て、各割り当てのレーザー発射のシミュレーション、領域の数のカウント、割り当ての確率の乗算。 レーザーと境界線のルールが単純なのでこれは機能しますが、次のような場合は扱いにくくなります。`n=100`以来`2^100`天文学的に大きいです。 

重要な洞察は、予想の線形性です。予想される領域の数は、すべての敵の構成を列挙することなく、潜在的な各分割線を個別に考慮し、予想される線の寄与を合計することによって計算できます。 敵がその方向にレーザーを発射すると、垂直、水平、斜めの各線が生成されます。 レーザーは壁によってブロックされ、ブロックに関して相互作用しないため、領域の数に対する各レーザーの方向の寄与は独立しており、アップグレードされる敵の確率から直接、予想される領域の数を計算できます。 

これにより、どの固有の x、y、および対角座標がレーザーに当たるかを追跡し、予想されるカウントを計算するだけで済むため、問題が指数関数的な時間から多項式時間に軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * (a*b)) | O(a*b) | 遅すぎる |
 | 線形期待 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値を読み取る`n`、`a`、`b`そして敵のデータ`(x_i, y_i, p_i')`。 
2.変換`p_i'`モジュラー分数へ`p_i = p_i' / 10^6 mod 998244353`。 
3. 3 つの辞書を初期化して、垂直線に沿って予想される寄与を追跡します (`x_lines`)、横線(`y_lines`)、および対角線 (`diag1`、`diag2`）。 
4. 敵ごとに、レーザーが発射できる各ラインに沿ってレーザーが存在する確率を計算します。 基本的な敵の場合、縦線と横線は常に発射されますが、斜め線は確率でのみ発射されます`p_i`。 
5. 固有のラインによって寄与されるパーツの予想数を増加します。各 x 座標について、垂直レーザーがそれを通過する確率は次のようになります。`1 - product(1 - p_laser)`その座標にあるすべての敵の上に。 y と対角線についても同じことを行います。 
6. これらの予想される寄与をすべて合計します。 垂直または水平の各線は、既存の領域を分割することによって領域の数を追加します。 対角線も同様に余分な分割を追加します。 
7. 全体でモジュラー演算を使用するように注意しながら、これらのカウントを組み合わせて、予想される領域の合計数を計算します。 
8. 最終的な答えのモジュロを出力します。`998244353`。 

それが機能する理由: 期待値の線形性により、敵のすべての組み合わせを考慮することなく、個々のラインの寄与を合計できることが保証されます。 敵のアップグレードの独立性により、ラインが生成される確率を計算する際の正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n, a, b = map(int, input().split())
    enemies = []
    for _ in range(n):
        x, y, p_raw = map(int, input().split())
        enemies.append((x, y, p_raw * modinv(10**6) % MOD))
    
    # Line sets
    x_lines = {}
    y_lines = {}
    diag1 = {}
    diag2 = {}
    
    for x, y, p in enemies:
        # horizontal and vertical always exist
        x_lines[x] = 1
        y_lines[y] = 1
        # diagonals exist only for upgraded
        diag1[y - x] = (diag1.get(y - x, 0) + p) % MOD
        diag2[y + x] = (diag2.get(y + x, 0) + p) % MOD
    
    # Expected number of vertical and horizontal splits
    ev = len(x_lines)
    eh = len(y_lines)
    
    # Diagonals contribution as sum of probabilities
    ed = sum(diag1.values()) % MOD
    ed += sum(diag2.values()) % MOD
    
    # Base region
    res = 1 + ev + eh + ed
    print(res % MOD)

solve()
```このコードは、まず確率をモジュラー分数に変換し、次にレーザーが発射できる固有のラインを追跡します。 水平線と垂直線は常に分割に寄与しますが、対角線は確率的に寄与します。 これらの寄与を合計すると、予想される領域の数が得られます。 

微妙な点には、分数確率を処理するためのモジュラー逆関数の使用と、対角寄与の慎重な集計が含まれます。 構成ごとの実際の数ではなく、予想される存在を合計するため、重複は自然に処理されます。

 ## 特殊なケース

 2x2 レベルの単一の敵は確率的分割を示します。敵が基本的な場合は 4 つの領域があります。 アップグレードした場合は 8 リージョン。 線形期待値の合計は 4 * (1-p) + 8 * p = 4 + 4 * p です。 p = 0.5 の場合、6 が得られます。アルゴリズムは剰余分数を使用してこれを正しく計算します。 重なっている対角線の場合、確率を合計します。
