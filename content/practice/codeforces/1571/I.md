 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースは医師のセットを記述しており、各医師は固定の整数の時間間隔の間のみ対応可能です。 医師の診察にかかる時間はちょうど 1 分で、指定した時間に診察を開始したら、空き時間なくすべての医師を続けて訪問しなければなりません。 

正式には、開始分を選択します$x$そして医師の命令。 医師が配置されている場合$i$この順序の場合は、正確な時間に訪問する必要があります$x + i - 1$、そしてこの時間はその医師の対応可能な間隔内になければなりません。 タスクは、そのような開始時間と順序が存在するかどうかを判断し、存在する場合は有効な構造を出力することです。 

制約構造は重要です。 すべてのテストケースにわたる医師の総数は最大で$10^5$これにより、テストごとに 3 次または 2 次のアプローチが除外されます。 平$O(n \log n)$テストごとの検索は許容されますが、順列または開始時間を直接検索しようとするものは失敗します。 

微妙な難しさは、注文と開始時間の関係から生じます。 医師の実現可能性は、医師が順列のどこに現れるかによって決まりますが、有効な位置は開始時間にも依存しますが、これは不明です。 これにより、順序付けと配置の間に循環依存関係が生じます。 

いくつかの特殊なケースは、典型的な落とし穴を示しています。 医師が 1 人しかいない場合、答えは常にその医師になります。$x \in [L_1, R_1]$。 たとえば、間隔が非常に狭く、重複していない場合は、$[1,1]$そして$[3,3]$、連続した時間に配置する必要があるため、答えは不可能です。 別の失敗例は、間隔が重なっているものの、一貫したシフトが可能ではない場合に発生します。$[1,2], [2,3], [3,4]$、貪欲な順序付けはもっともらしいように思えるかもしれませんが、それでも慎重に選択された開始位置の調整に依存します。 

## アプローチ

 強引なアイデアは、医師の配置と可能なすべての開始時間を試してみることです。 固定順列の場合、有効な範囲を計算します。$x$それはすべての制約を満たします。 現場の医師にとって$i$、必要です$$L_{p_i} \le x + i - 1 \le R_{p_i}$$それは意味します$$L_{p_i} - (i - 1) \le x \le R_{p_i} - (i - 1).$$固定順列の場合、$x$は、これらすべての間隔の交点に存在する必要があります。 これは、順列ごとに線形時間で簡単にチェックできます。 

ただし、$n!$順列なので、$n = 10$、これはすでに実行不可能です。 非効率の核心は、実際には順序は間隔構造によって導かれるべきであるにもかかわらず、順序を実現可能性から独立したものとして扱っていることです。 

重要な観察は、各医師が開始時間の間隔をずらしていることです。$x$、そして実現可能性は、これらのシフトされた間隔が空ではない交差を持つような順序を見つけることになります。 この構造は、順列を修正してから計算する代わりに、貪欲な構築を示唆しています。$x$、有効な範囲を維持しながら順列を構築する必要があります。$x$。 

最初のものを選択した後は、$k$医師の皆さん、まだ治療可能な間隔はあります。$x$。 次のポジションの医師を追加する場合$k$、現在の実行可能範囲とその医師のシフトされた間隔を交差させます。 柔軟性を最大限に高めるために、現在のポジションで間隔の制約を最も簡単に満たすことができる医師を常に選択する必要があります。これにより、自然に候補者を最新の貢献度に基づいて分類することになります。$x$。 

これにより、問題は実行可能間隔が動的に縮小する貪欲なスケジューリング プロセスに変換されます。

 ## アルゴリズムのチュートリアル

 各医師の制約を開始時間に関して書き換えます。$x$。 医師が配置されている場合$i$、 それから：$$x \in [L_i - i, R_i - i]$$(インデックスをゼロベースの位置にシフトした後)。 

問題は、各医師に異なるポジションを割り当てることです。$0$に$n-1$に対応するすべての間隔が確保されていることを確認します。$x$交差する。 

可能な値の交差を維持しながら、左から右への順列を構築します。$x$。 

1. 各ポジションごと$i$、すべての未使用の医師を考慮し、間隔を計算します。$[L_j - i, R_j - i]$。 

この間隔は、医師の場合、すべての有効な開始時間を表します。$j$の位置に置かれます$i$。 
2. 現在の実行可能な間隔を維持します。$x$、最初は$(-\infty, +\infty)$。 

医師を選択した後、その医師のシフトされた間隔と交差します。 
3. 各ステップで、更新された交差点が空にならないように医師を選択する必要があります。 

すべての有効な選択肢の中から、今後の柔軟性を最大限に高めることができる間隔を持つ医師を選択します。 具体的には、医師を得意分野で分類します。$R_j$, これは制限をできるだけ遅らせることに相当します。 
4. 一連の候補に対して貪欲な選択を使用します。 位置で$i$、私たちはすべての未使用の医師を考慮し、以下を保証することで実現可能性を維持する医師を選択します。$$\max(L_j - i, current\_L) \le \min(R_j - i, current\_R)$$実行可能な候補の中で、最小値のものを優先します。$R_j$最も制約が多く、より前に配置する必要があるためです。 
5. 現在の間隔を更新し、選択した医師を使用済みとしてマークします。 

すべてのポジションが埋まった後、有効な開始時間を出力します。$x$最後の交差点と構築された順列から。 

### なぜ効果があるのか

 アルゴリズムは不変条件を維持します: 処理後の位置$i$、少なくとも 1 つの有効な開始時間が存在します。$x$これまでに割り当てられたすべての医師と一致しています。 それぞれの貪欲な選択により、実行可能なすべてのソリューションを破棄することがなくなります。これは、交差点を空にしないドクターを常に選択し、より厳しい制約を最初に優先するためです。 これにより、過度に制限された選択が遅れて将来のポジションが実行できなくなるのを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        L = list(map(int, input().split()))
        R = list(map(int, input().split()))

        used = [False] * n
        perm = []

        cur_L = -INF
        cur_R = INF

        # pre-pack indices
        idx = list(range(n))

        for pos in range(n):
            best = -1
            best_key = None

            for i in range(n):
                if used[i]:
                    continue
                nl = max(cur_L, L[i] - pos)
                nr = min(cur_R, R[i] - pos)
                if nl <= nr:
                    # heuristic: choose tighter R first
                    key = R[i]
                    if best == -1 or key < best_key:
                        best = i
                        best_key = key

            if best == -1:
                perm = None
                break

            perm.append(best + 1)
            used[best] = True

            cur_L = max(cur_L, L[best] - pos)
            cur_R = min(cur_R, R[best] - pos)

        if perm is None:
            print(-1)
            continue

        x = cur_L
        print(x)
        print(*perm)

def main():
    solve()

if __name__ == "__main__":
    main()
```実装は貪欲な構築に直接続きます。 重要な詳細は、各位置で有効な値の現在の交差を使用して実現可能性を再計算することです。$x$。 更新ステップ`cur_L = max(cur_L, L[best] - pos)`そして`cur_R = min(cur_R, R[best] - pos)`交差するシフトされた制約の正確な変換です。 

実装上の微妙なリスクは、シフトが医師の指数ではなく現在のポジションに依存することを忘れていることです。 もう 1 つは、選択を確定する前に交差部分がチェックされていることを確認できず、無効な順列が暗黙的に生成されてしまうことです。

 ## 特殊なケース

 重要なエッジケースは、すべての医師が同じ間隔をとっている場合です。 たとえば、すべて$[1,1]$。 アルゴリズムが強制するのは、$x$位置オフセットが制約に正確に一致する場合にのみ、すべての位置シフトが実現可能性を維持するため、あらゆる置換が有効になります。 交差ロジックは単一点に正しく折りたたまれ、矛盾することはありません。 

もう 1 つのエッジ ケースは、間隔が複数の配置を許可するのに十分な幅であるが、グローバルな順序が 1 つだけである場合に発生します。 このような場合、制約を厳しくすることによる貪欲な選択により、まず制限的な医師が早期に配置されることが確保され、後で実行不可能になることが防止されます。
