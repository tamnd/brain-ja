 ## 問題の理解

 いくつかの文字列のペアが与えられ、それぞれが韻を踏む必要があるか、明示的に韻を踏まないかのいずれかとしてマークされています。 2 つの文字列が正の整数で韻を踏む$k$もし彼らが最後なら$k$文字が同一であり、各文字列が少なくとも長さがある$k$。 私たちのタスクは、可能なすべての非負の整数値を決定することです。$k$つまり、韻を踏むとマークされたすべてのペアは実際に韻を踏み、韻を踏まないとマークされたすべてのペアは韻を踏みません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは文字列ペアの数を指定します。$n$その後$n$2 つの文字列と韻インジケーターを含む行。 すべてのテスト ケースにわたるすべての文字列の合計長は次のように制限されます。$4 \cdot 10^5$したがって、すべての文字列のすべての文字を反復する解決策は実行可能です。 ペア数$n$まで高くすることができます$10^5$、すべての可能性をチェックするアルゴリズムを除外します。$k$からの値$0$各ペアの最大文字列長まで個別に設定できます。 代わりに、ペア全体の制約を効率的に集約する方法が必要です。 

文字列の長さが大幅に異なる場合、特に「韻を踏まなければならない」ペアの場合、明らかではないエッジケースが発生します。 たとえば、1 つのペアが`abc`そして`abcde`そしてそれは韻を踏んでいるはずです$k$短い方の文字列の長さは 3 を超えることはできません。 1 つの文字列が空であるか、次の文字列より短い「韻を踏んではいけない」ペアの場合$k$、 どれでも$k$短い文字列よりも長い文字列は自動的に条件を満たします。 

不注意なアプローチはすべてを試す可能性があります$k$から$0$「韻を踏まなければならない」ペアの最小長を考慮せずに文字列の最大長を設定するか、「韻を踏んではいけない」ペアの最後の文字が最大の重複で異なる場合にのみ韻を踏めないと仮定する可能性があります。 どちらも不正確な答えを生成します。 

## アプローチ

 ブルートフォースアプローチは簡単です。 各テストケースについて、すべてのことをチェックできます。$k$から$0$すべてのペアの最大文字列長まで。 それぞれについて$k$、すべての「韻」のペアには一致する接尾辞があり、すべての「非韻」のペアには一致しないことを確認します。 原理的には正しいですが、これは遅すぎます。 最大文字列長が約$2 \cdot 10^5$そして私たちは持っています$10^5$ペアの場合、このアプローチでは最大で$2 \cdot 10^5 \cdot 10^5 = 2 \cdot 10^{10}$制限時間を超えた比較。 

重要な洞察は、それぞれの「韻」のペアに上限が設けられているということです。$k$: ペアの共通サフィックスの長さを超えることはできません。 逆に、各「韻を踏まない」ペアには下限が設定されます。$k$一致するサフィックスの長さと同じにすることはできません。また、サフィックスが一致する場合は、ペア内の最も短い文字列よりも長くすることもできません。 すべての「韻」ペアの中から最も長い共通接尾辞を見つけ、その長さで完全に一致する「非韻」ペアがないことを確認することで、有効な接尾辞のセットを決定できます。$k$効率的に価値を高めます。 接尾辞の一致をペアごとに 1 回計算するだけで済むため、操作の数がすべての文字列の長さのおおよその合計に減り、問題の制約内に収まります。

 ## アルゴリズムのチュートリアル

 1. 2 セットの変数を初期化します。1 つはすべての「韻」ペアの最小接尾辞長を追跡するため、もう 1 つは「非韻」ペアからのすべての禁止された接尾辞長を保存するためです。 
2. 各「韻」のペアを繰り返します。 各ペアについて、最長の共通接尾辞の長さを計算します。 すべての「韻」ペアの最小サフィックス長を、これらの値の最小値に更新します。 この値は可能な最大値です$k$韻を踏むことは許されています。 
3. 各「非韻」ペアを繰り返します。 それらの共通の接尾辞の長さを計算します。 1 からこの共通接尾辞の長さまでのすべての長さを禁止されたセットに追加します。 どれでも$k$これらの長さのいずれかに等しいと、「非韻」ペアが誤って韻を踏んでしまいます。 
4. 有効なリストの最終リストを作成する$k$価値観。 これらはすべて、0 から「韻」ペアの最小接尾語長までの​​整数です。ただし、「非韻」ペアから収集された禁止された長さは除きます。 
5. リストとリスト自体のサイズを出力します。 

正確さを保証する不変条件は、「韻」ペアの共通接尾辞の最小長が厳密な上限を設定することです。$k$一方、「非韻」ペアからの禁止された長さにより、許可されていない韻が発生しないことが保証されます。 これらを組み合わせて考えられるものを列挙すると、$k$効率的に。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def longest_common_suffix(a, b):
    la, lb = len(a), len(b)
    i = 0
    while i < la and i < lb and a[la - 1 - i] == b[lb - 1 - i]:
        i += 1
    return i

t = int(input())
for _ in range(t):
    n = int(input())
    rhyme_pairs = []
    non_rhyme_pairs = []
    for _ in range(n):
        s, t_str, r = input().split()
        if r == '1':
            rhyme_pairs.append((s, t_str))
        else:
            non_rhyme_pairs.append((s, t_str))

    max_k = float('inf')
    for s, t_str in rhyme_pairs:
        max_k = min(max_k, longest_common_suffix(s, t_str))

    forbidden = set()
    for s, t_str in non_rhyme_pairs:
        lcs = longest_common_suffix(s, t_str)
        for k in range(1, lcs + 1):
            forbidden.add(k)

    result = [k for k in range(max_k + 1) if k not in forbidden]
    print(len(result))
    if result:
        print(*result)
```このソリューションでは、まず「韻」ペアの最長の共通接尾辞を計算して、許容可能な最大値を取得します。$k$。 次に、禁止されたセットを構築します。$k$「非韻」ペアの値。 最終リストには有効なすべてが含まれます$k$禁止値を除く、0 から最小サフィックス長までの値。 境界例のような場合$k = 0$または非常に短い文字列は範囲ロジックによって自然に処理されます。
