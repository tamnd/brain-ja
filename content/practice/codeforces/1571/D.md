 ## 解決策
 ## 問題の理解

 私たちはとの競争を与えられました`n`プログラマーとの調査`m`観客はそれぞれ、誰が最初と最後にゴールするかを予想します。 あなたは最初の観客として、あなたの予想を提出しました`(f_1, l_1)`。 主催者は、正解した予想の数に基づいて観客をランク付けします。2 つの正解した予想が 1 位にランクされ、1 つの正解した予想がすべての完璧な予想の後にランクされ、0 つの予想が正解した場合は他の人の後にランクされます。 他の観客の予想を考慮して、実際のコンテストの結果は不明ですが、**最悪の順位**を決定するよう求められています。 

この課題は、どのプログラマーが実際に勝つか負けるかがわからないという事実から生じます。 最悪のランクを取得するには、競争結果があなたのランキングにできるだけ悪影響を与えるように**敵対的**に選択されている、つまりできるだけ多くの観客があなたよりも正しい推測をすることになると仮定する必要があります。 

制約は中程度です。`n`最大 1000 ですが、これは可能な最初と最後の位置の割り当てを反復することを検討するには十分小さい値です。`m`は最大 2 × 10^5 になる可能性があるため、候補結果ごとに観客を複数回ループするアプローチは遅すぎます。 すべての観客ペアとすべての結果に対する総当りチェックには O(n^2 * m) がかかり、実行可能をはるかに超えて 2 × 10^11 の演算に達する可能性があります。 したがって、すべての結果を明示的にシミュレートすることを避け、代わりにカウントと重複について推論するアプローチが必要です。 

注意すべきエッジケースとしては、プログラマーが 2 人だけの場合、最初に予測すると最後に自動的に修正される場合、または複数の観客が同じ回答をし、順位が同点になる可能性がある場合などがあります。 もう 1 つの注意が必要なシナリオは、自分の予測が他の複数の予測と一致する場合です。 単純なカウントではランクが過小評価される可能性があります。これは、最悪の場合の結果によって、同じ予測がすべて 2 つ正解する一方で、正しい予測が 0 になる可能性があるためです。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのことを繰り返すことです。`(first, last)`結果ごとに、2、1、または 0 の予測を正解した観客の数を数え、得られた順位を追跡します。 これは論理的には正しいですが、その複雑さは O(n^2 * m) であり、n = 1000 および m = 2 × 10^5 では受け入れられません。 

重要な洞察は、あなたのランクは、厳密にあなたよりも優れた成績を収めることができる観客が何人いるかによってのみ決定されるということです。 最悪の場合のランクについては、あなたの推測が完全に間違っていると想定します。 これにより、ユーザーの助けを借りずに、できるだけ観客の予想と一致するようにコンテストの結果を選択した場合、**最初と最後の両方を正確に推測できた観客の数**を数えることに問題が軽減されます。 

カウントについて推論することができます。`x`予測された最初の名前があなたの最初の名前と一致する観客の数、そして`y`予測された最後があなたの最後と一致する観客の数。 最悪のランクは、あなたの予測が完全に外れ、他の観客の最大数が少なくとも 1 人を正しく推測した場合に発生します。 コンテストの結果が賢明に選ばれた場合、最初の予想も最後もあなたの予想と一致しない観客も、完全に予想することを強いられる可能性があります。 これにより、すべての結果を反復するのではなく、重複を計算し、組み合わせ推論を使用することで問題が軽減されます。 

慎重に数えることで、敵対シナリオで 2 正解、1 正解、0 正解となる可能性のある観客の数を計算できます。 この公式は、要約すると、あなたの予測と相対的な予測を考慮して、あなたに勝つ観客を最大化することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n² * m) | O(m) | 遅すぎる |
 | 最適 | O(m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力値の読み取り`n`そして`m`。 すべての観客の予想をリストに保存します。最初に自分の予想を入れます。 
2. 何人の観客 (あなたを除く) があなたと同じ最初のプログラマを予測したか数えます。 これに電話してください`same_first`。 
3. 何人の観客があなたと同じ最後のプログラマーを予測したか数えてください。 これに電話してください`same_last`。 
4. 何人の観客が、あなたと同じ最初と最後のプログラマーを予想したか数えてください。 これに電話してください`same_both`。 
5. 最悪のシナリオは、あなた自身の予測が両方とも間違っていることを前提としています。 したがって、2 つの正解を推測できる観客の数は、`same_both`(あなた自身を除く) なぜなら、コンテストの結果が彼らの予測と完全に一致する可能性があるからです。 
6. 1 回正解できた観客の数は`max(same_first - same_both, same_last - same_both)`。 これは、コンテストの結果がこれら 2 つのグループのうち大きい方に有利になるように選択される可能性があるため、最初か最後を共有するが両方ではない人を考慮します。 
7. あなたの最悪のランクは、2 つ正解した観客と 1 つ正解した観客の合計に、自分の 1 を加えたものになります。 つまり`worst_rank = c2 + c1 + 1`。 
8. 計算された結果を印刷します。`worst_rank`。 

機能する理由: このアルゴリズムは、コンテストの結果を敵対的に選択できるという不変条件を維持するため、あなたの予測は完全に外れ、できるだけ多くの他の観客が少なくとも 1 人は正解します。 正確な重複をカウントすることで、あなたを破る観客の数を過小評価していないことを保証します。 この公式により、同順位が正しく処理されることが保証されます。複数の観客があなたの予想を共有した場合、最悪の場合の結果でも、あなたは全員の後に順位が付けられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
predictions = [tuple(map(int, input().split())) for _ in range(m)]
f1, l1 = predictions[0]

same_first = same_last = same_both = 0

for f, l in predictions[1:]:
    if f == f1 and l == l1:
        same_both += 1
    elif f == f1:
        same_first += 1
    elif l == l1:
        same_last += 1

c2 = same_both
c1 = max(same_first, same_last)

worst_rank = c2 + c1 + 1
print(worst_rank)
```最初の部分では、高速 I/O を使用して入力を効率的に読み取ります。 数える`same_first`、`same_last`、 そして`same_both`1 つのループで実行されますが、これは O(m) の複雑さにとって重要です。 の`c1`計算で使用する`max`なぜなら、最悪の場合の結果はより大きなグループに有利になる可能性があるからです。 ついに、`worst_rank`これらのカウントに自分のカウントを 1 加えたものを合計し、主催者のランキング システムと一致します。

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(m) | すべての観客の予測を 1 回通過して重複をカウントします。 
| スペース | O(m) | 入力予測の保存 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    predictions = [tuple(map(int, input().split())) for _ in range(m)]
    f1, l1 = predictions[0]

    same_first = same_last = same_both = 0

    for f, l in predictions[1:]:
        if f == f1 and l == l1:
            same_both += 1
        elif f == f1:
            same_first += 1
        elif l == l1:
            same_last += 1

    c2 = same_both
    c1 = max(same_first, same_last)

    worst_rank = c2 + c1 + 1
    return str(worst_rank)

# provided samples
assert run("2 3\n1 2\n2 1\n2 1\n") == "3", "sample 1"
assert run("3 6\n1 2\n1 2\n2 1\n3 1\n2 3\n3 2\n") == "4", "sample 2"
