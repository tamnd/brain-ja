 ## 解決策
 ## 問題の理解

 サイズの正方形グリッドを数える必要があります`n × n`数字で埋め尽くされた`0..9`。 

グリッドは 2 つの構造規則を満たす必要があります。 

最初のルールでは、エッジに隣接する 2 つのセルの差は最大でも次のとおりです。`1`。 

2 番目のルールは、すべての`2 × 2`ブロックの対角和は等しい。 ブロックがある場合$$\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}$$それなら私たちは持っている必要があります`a + d = b + c`。 

このようなすべてのグリッドの中で、すべての不良長方形の面積が最大でも小さいものだけが必要です。`k`。 

長方形の場合、`mx`そして`mn`その中の最大値と最小値になります。 以来$$\text{next}=mx+1,\qquad \text{prev}=mn-1,$$状態$$\text{next}-\text{prev}=l+b$$と同等です$$mx-mn=l+b-2.$$したがって、値の範囲が長方形の寸法の可能な最大値に達したとき、長方形は不良になります。`l × b`。 

制約`n ≤ 500`実際のグリッドを考慮したアプローチは直ちに除外されます。 グリッドには以下が含まれます`250000`セルの数が多く、可能な詰め物の数は天文学的です。 解決策は、調和条件によって課せられる強力な代数構造を利用する必要があります。 

開始桁を選択する前にパターンが桁範囲外の値に達すると、微妙なエッジ ケースが発生します。 

たとえば、行パターンは次のようになります。`-5`そして`4`。 後で適切な開始桁を選択することでグリッド全体を上にシフトできるため、これは依然として有効です。 このようなパターンを早期に拒否すると、有効な解決策が失われます。 

もう 1 つの簡単な間違いは、最大の不良四角形が行パターンの合計の変動に依存すると考えることです。 順番を考えてみる```
0 1 2 1 2
```その合計範囲は`2`、しかしその最長は完全に単調です`±1`縞には長さがある`3`。 不正な長方形は、範囲全体ではなく、これらの縞によって制御されます。 

## アプローチ

 強引なアイデアは、すべてのグリッドを生成して条件をテストすることです。 たとえ`n = 3`、 がある`10^9`可能なグリッド。 検索スペースは、実際の限界に達するずっと前に爆発的に増加します。 

重要な観察は、対角和条件から得られます。 させて`h[i][j]`グリッド値になります。 

から$$h[i][j] + h[i+1][j+1]
=
h[i][j+1] + h[i+1][j]$$あらゆる人にとって`2 × 2`ブロックでは、グリッドは加法的な意味でランク 1 を持ちます。$$h[i][j] = s + r_i + c_j.$$ここ`s`は開始値であり、`r_i`行オフセットについて説明します。`c_j`列オフセットについて説明します。 

隣接条件は非常に単純になります。 連続する行オフセットの差は最大でも`1`、連続する列オフセットの差は最大でも`1`。 

したがって、グリッド全体を構築する代わりに、必要なのは 2 つの 1 次元パターンだけです。 

次のステップは、不正な四角形を理解することです。 

長方形にまたがる場合`l`行と`b`列、$$mx-mn
=
(\max r-\min r)
+
(\max c-\min c).$$連続差分が入っているため、`{-1,0,1}`、行の寄与は最大で`l-1`、列の貢献度は最大で`b-1`。 

両方の寄与がそれぞれの最大値に達すると、長方形は正確に不良になります。 これは、対応する行セグメントが純粋な場合にのみ発生します。`+1,+1,+1,...`縞または純粋`-1,-1,-1,...`列セグメントにも同じことが当てはまります。 

そのような最長の列ストリークに長さがある場合`S1`最長のカラムストリークの長さは`S2`の場合、最大の不良長方形には面積があります。$$S_1 \cdot S_2.$$したがって、「以下の面積をもつ不良な長方形はない」という条件は、`k`」になります$$S_1S_2 \le k.$$ここで問題は、長さの一次元パターンを数えることに縮小されます。`n`。 

各パターンの始まりは、`0`、によって移動します`-1`、`0`、 または`1`そして、次のことを知る必要があります。 

- 到達した最大値、
 - 到達した最小値、
 - 最長のモノトーン`±1`縞模様。 

最後のグリッドは数字を使用するため、`0..9`、合計範囲が以内に収まるパターンのみ`9`有効な回答に参加することはできます。 これにより、コンパクトな動的プログラミング状態が可能になります。

 ## アルゴリズムのチュートリアル

 ### 1. すべての高調波グリッドを 2 つの 1 次元パターンで表現します

 最初のセル値をシフトとして固定します`s`。 

行オフセットと列オフセットを次から開始します。`0`。 

その後、すべてのセルは次のように書くことができます$$h[i][j]=s+r_i+c_j.$$連続するオフセットは次のように異なります`-1`、`0`、 または`1`。 

### 2. 1 次元パターン上に DP を構築する

 長さのパターンを生成します`n`から始まる`0`。 

DP には以下が保存されます。 

- 現在の位置、
 - 現在のオフセット、
 - 最大オフセットに達しました。 
- 最小オフセットに達しました。 
- 現在の署名されたストリーク、
 - これまでに達成された最大のストリーク長。 

現在の連勝は連続してプラスです`+1`移動、連続の場合はマイナス`-1`移動、最後の移動があったときはゼロ`0`。 

### 3. 可能な 3 つの動きによるトランジション

 現在のオフセットから次のことを行うことができます。 

- 増加`1`、
 - 変わらないまま、
 - 減少`1`。 

そうすることで、以下を更新します。 

- 現在のオフセット、
 - グローバル最大値、
 - グローバル最小値、
 - 現在の連続記録、
 - 最大ストリーク。 

オフセットは以下に制限されます`[-9,9]`というのは、より大きなエクスカーションは決して数字グリッド内に収まらないからです。 

### 4. パターン数の集計

 加工後長さ`n`、 集める$$cnt[mx][mn][streak]$$どこ：

-`mx`到達した最大オフセットです。 
-`mn`到達した最小の負のオフセットの大きさです。 
-`streak`は最長の単調縞の長さです。 

### 5. 2 つのパターンを組み合わせる

 1 つのパターンは行パターンになり、もう 1 つは列パターンになります。 

開始桁`s`の場合に有効です$$s+mx_1+mx_2 < 10$$そして$$s-mn_1-mn_2 \ge 0.$$同様に、すべてのグリッド値は内部に残ります。`0..9`。 

### 6. 不正な長方形の制限を強制する

 最長のストリークの長さが`st1`そして`st2`の場合、最大の不良長方形には面積があります。$$st1 \cdot st2.$$満足のいくペアのみを維持する$$st1 \cdot st2 \le k.$$### 7. すべての有効な組み合わせのモジュロを合計します。`10^9+7`すべての有効なパターンのペアとすべての有効な開始桁が答えに影響します。 

### なぜ効果があるのか

 対角和条件により、グリッドが独立した行コンポーネントと列コンポーネントの合計として表現可能になります。 この方法でグリッドを作成すると、すべての四角形範囲が行範囲と列範囲に分解されます。 

長方形は、その行セグメントと列セグメントの両方が独自の理論上の最大値に達した場合にのみ、可能な最大範囲に達します。 各ステップの変化はせいぜい`1`、これはまさに中断なく発生します`+1`または`-1`縞模様。 このような最長のストリークによって、その次元で考えられる最大の不良長方形が完全に決まります。 

DP は、許容されるすべての 1 次元パターンを 1 回だけ列挙し、後で必要になる情報 (値の範囲と最長ストリーク) を正確に記録します。 2 つのパターンを組み合わせると、すべての高調波グリッドが 1 回だけ再構築されるため、最終的なカウントは正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    n, k = map(int, input().split())

    # dp[pos][mx][mn][streak][best]
    # rolled over current offset dimension as in the official solution idea

    dp = [[[[[0] * 10 for _ in range(19)] for _ in range(10)]
            for _ in range(10)] for _ in range(19)]

    dp[9][0][0][9][0] = 1

    for _ in range(1, n):
        ndp = [[[[[0] * 10 for _ in range(19)] for _ in range(10)]
                 for _ in range(10)] for _ in range(19)]

        for cur in range(-9, 10):
            curi = cur + 9

            for mx in range(10):
                for mn in range(10):
                    for streak in range(-9, 10):
                        sti = streak + 9

                        row_dp = dp[curi][mx][mn][sti]

                        for best in range(10):
                            val = row_dp[best]
                            if not val:
                                continue

                            if cur < 9 and streak < 9:
                                ncur = cur + 1
                                nmx = max(mx, ncur)

                                nstreak = max(1, streak + 1)
                                nbest = max(best, nstreak)

                                ndp[ncur + 9][nmx][mn][nstreak + 9][nbest] = (
                                    ndp[ncur + 9][nmx][mn][nstreak + 9][nbest]
                                    + val
                                ) % MOD

                            ndp[cur + 9][mx][mn][9][best] = (
                                ndp[cur + 9][mx][mn][9][best] + val
                            ) % MOD

                            if cur > -9 and streak > -9:
                                ncur = cur - 1

                                nmn = max(mn, -ncur)

                                nstreak = min(-1, streak - 1)
                                nbest = max(best, abs(nstreak))

                                ndp[ncur + 9][mx][nmn][nstreak + 9][nbest] = (
                                    ndp[ncur + 9][mx][nmn][nstreak + 9][nbest]
                                    + val
                                ) % MOD

        dp = ndp

    cnt = [[[0] * 10 for _ in range(10)] for _ in range(10)]

    for cur in range(19):
        for mx in range(10):
            for mn in range(10):
                for streak in range(19):
                    arr = dp[cur][mx][mn][streak]
                    for best in range(10):
                        cnt[mx][mn][best] = (
                            cnt[mx][mn][best] + arr[best]
                        ) % MOD

    ans = 0

    for s in range(10):
        for mx1 in range(10):
            for mx2 in range(10):
                for mn1 in range(10):
                    for mn2 in range(10):

                        if s + mx1 + mx2 >= 10:
                            continue

                        if s - mn1 - mn2 < 0:
                            continue

                        for st1 in range(1, 11):
                            lim = min(10, k // st1)

                            for st2 in range(1, lim + 1):
                                ans = (
                                    ans
                                    + cnt[mx1][mn1][st1 - 1]
                                    * cnt[mx2][mn2][st2 - 1]
                                ) % MOD

    print(ans)

solve()
```DP はオフセットのみを内部に保存します`[-9,9]`。 この間隔から外れるパターンには、すでに数字に収まる範囲を超える範囲が必要になります。`0..9`, したがって、そのような状態は無関係です。 

最小値は、負でない大きさとして保存されます。 散歩が届いたら`-4`、私たちは保管します`4`。 これにより、インデックス付けがコンパクトになり、負の配列インデックスが回避されます。 

ストリーク状態はサイン入りです。 正の値は、現在のストリークが次のもので構成されていることを意味します。`+1`移動、負の値の意味`-1`移動、ゼロは最後の移動が`0`。 これにより、ストリークを正しく延長またはリセットできます。

 ## 特殊なケース

 次のことを考慮してください。```
1 1
```あ`1 × 1`グリッドには 1 桁の数字が含まれています。 すべての桁`0..9`有効です。 DP はオフセットから始まります`0`、正または負の値に達せず、ちょうど 10 個の有効なシフトが生成されます。 答えは`10`。 

正と負の両方のオフセットを訪問するパターンを考えてみましょう。```
0 1 0 -1
```その最大値は`1`そしてその最小値は`-1`。 DP はこれを次のように保存します`mx = 1`、`mn = 1`。 有効な開始桁は次の条件を満たす必要があります。$$s-1 \ge 0,\qquad s+1 < 10.$$だからそれだけ`s = 1..8`仕事。 アルゴリズムはそれらのシフトを正確にカウントします。 

長い単調シーケンスを考えてみましょう。```
0 1 2 3 4
```最長の縞の長さは`4`。 このパターンを使用する長方形は、可能な最大の行範囲を実現できます。 カラムパターンのストリーク長も最長の場合`3`の場合、最大の不良長方形には面積があります。`12`。 条件はこうなります`12 ≤ k`。 DP には最長のストリークのみが保存されます。これはまさにこのチェックに必要な量です。
