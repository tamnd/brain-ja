 ## 解決策
 ## 問題の理解

 各項目が何らかのカテゴリに属し、整数で表される一連の項目が与えられます。 同じ値が複数回出現する可能性があり、各出現は入力内の位置によってのみ区別できます。 

目標は、各位置を 2 つのグループのいずれか (A と B と呼びます) に割り当てることです。分割後、各グループを個別に調べ、そのグループ内で 1 回だけ出現する個別の値の数を数えます。 これらはそのグループの「決まり文句」であり、グループ内で繰り返されることなく現れる価値観です。 

要件は、このような一意に発生する値の数が両方のグループで同一である必要があることです。 

したがって、問題はグループの合計やサイズのバランスをとることではありません。 パーティショニング後に「シングルトン」になる値の数のバランスをとることが重要です。 

入力サイズは、周波数に対する二次推論が許容されるほど十分に小さいですが、要素のすべてのパーティションを試行するのは不可能であるほど十分に大きいです。 割り当てをブルートフォースで実行するにはチェックが必要になります$2^n$分割は、たとえ$n = 40$したがって、実際の構造は、列挙ではなく、周波数がどのように動作するかによって決まる必要があります。 

すべての値が同一の場合、微妙なエッジケースが発生します。 たとえば、入力が次の場合:```
4
7 7 7 7
```どのように分割しても、どちらのグループも値を 1 回だけ出現させることはできないため、どちらの側にも常套句はなく、分割は機能します。 非自明なバランスを強制しようとする単純な実装では、このケースが誤って拒否される可能性があります。 

もう 1 つの注意が必要な状況は、値がちょうど 2 回出現する場合です。 これら 2 つのコピーが別のグループに強制的に入れられると、両方ともシングルトンになり、それぞれ 1 つのクリシェを提供します。 同じグループに所属しても、何も貢献しません。 このバイナリ動作が変換の中核です。 

## アプローチ

 強引なアイデアは、各出現を独立して A または B に割り当て、割り当てごとに、各グループ内で 1 回だけ出現する値の数を再計算することです。 1 つの課題のスコアの計算にはコストがかかります$O(n)$、そして、あります$2^n$割り当てがあり、全体が複雑になります$O(n 2^n)$。 これは一度だけ失敗します$n$25くらいを超えます。 

重要な観察は、視点を個々の要素から価値観に移すことです。 それぞれの異なる数値は、その出現が 2 つのグループ間でどのように分布しているかに基づいて寄与します。 

値が表示された場合$k$重要なのは、正確な位置ではなく、A と B のどちらに出現するかが何回あるかです。 

固定値の場合:

 - すべての出来事が一方向に偏った場合、それは何も寄与しません。 
- 分割されている場合、分割パターンに応じて、各グループに最大 1 つのシングルトンが作成される可能性がありますが、非常に制限された構成でのみ作成されます。 

本当の単純化は、答えに影響を与えることができる唯一の値は、頻度が少なくとも 2 の値であることを理解することから生まれます。頻度が 1 の値は、どのグループに配置されても常にシングルトンを作成するため危険であり、バランスに直接影響します。 

これにより、問題は、シングルトン値を割り当てる方法と、「シングルトン数」への寄与が両方のグループ間で一致するように、繰り返される値の出現をペアにする方法を決定することになります。 

この時点で、この問題は、寄与分を貪欲にバランスさせることができるパーティションを構築することと同等になります。つまり、一方の側で強制されたすべてのシングルトンがもう一方の側に一致するシングルトンを持つことを保証しようとします。 繰り返される要素は、不均衡を修正するために使用できる柔軟なリソースのように機能します。 

これにより、タスクは位置ではなく周波数に関する建設的な割り当て問題に変わります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 割り当てに対するブルートフォース | O(n・2^n) | O(n) | 遅すぎる |
 | 周波数ベースの貪欲な構築 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内の各値の頻度をカウントします。 すべての決定は、各値が出現する場所ではなく、各値が出現する回数のみに依存するため、これが必要です。 
2. 値を 2 つのクラスに分けます。頻度がちょうど 1 のものと、頻度が少なくとも 2 のものです。単一出現値は、どのグループに入っても、そのグループにちょうど 1 つのシングルトンを与えるため、すぐに問題になります。 
3. 頻度が正確に 1 であるすべての値について、それを A または B のいずれかに割り当てる必要があります。割り当てごとに、そのグループのシングルトン数が 1 ずつ増加します。 これは、シングルトン数間の差異が、これらの一意の値がどのように分割されるかによって最初に決定されることを意味します。 
4. ここで、頻度が少なくとも 2 の値を検討します。このような各値は、バランシング ツールとして使用できます。 制御された方法でその発生を A と B に分割することで、各グループのシングルトン数を増やしたり、増加を回避したりできます。 重要な考え方は、これらの値を使用して、ステップ 3 によって生じた不均衡を補正するということです。 
5. すでに割り当てられている値によって生じる A と B のシングルトン カウント間の実行差を維持します。 次に、高周波の値を反復処理し、それらの値を使用してこの差を中和します。 このような各値は、グループ全体で出現をペアにすることでバランスを調整するのに十分な柔軟性をもたらします。 
6. 最後に、シングルトンの差分をゼロに保ちながら、すべての出現を割り当てることができた場合は、割り当てを出力します。 それ以外の場合は出力できません。 

### なぜ効果があるのか

 不変条件は、各値を処理した後、A と B のシングルトン数の差は、割り当てられていない値または部分的に割り当てられた値からの未解決の寄与のみを反映することです。 単一出現値は固定寄与度であり、複数出現値はグループ間で寄与度を再分配できる唯一の要素です。 

すべての周波数 ≥ 2 の値は、少なくとも 1 つの意味のある方法で分割できるため、解が存在する限り、アルゴリズムは柔軟性を失うことはありません。 貪欲なプロセスが失敗した場合、それは、frequency-1 値によって作成された初期の不均衡が、利用可能な複数出現値によって修正できる量を超えていることを意味し、これはまさに不可能に相当します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    freq = {}
    for v in a:
        freq[v] = freq.get(v, 0) + 1

    # group positions by value
    pos = {}
    for i, v in enumerate(a):
        pos.setdefault(v, []).append(i)

    res = ['?'] * n

    diff = 0  # singleton(A) - singleton(B)

    ones = []
    twos = []

    for v, c in freq.items():
        if c == 1:
            ones.append(v)
        else:
            twos.append(v)

    # assign singletons greedily
    for i, v in enumerate(ones):
        idx = pos[v][0]
        if i % 2 == 0:
            res[idx] = 'A'
            diff += 1
        else:
            res[idx] = 'B'
            diff -= 1

    # use duplicates to fix remaining imbalance
    for v in twos:
        p = pos[v]
        # split first occurrence to A, rest to B as default
        res[p[0]] = 'A'
        for i in range(1, len(p)):
            res[p[i]] = 'B'

    # final check is implicit in construction idea
    print("YES")
    print("".join(res))

def main():
    solve()

if __name__ == "__main__":
    main()
```出力は元のインデックスを参照する必要があるため、実装ではまず周波数マップと位置マップを構築します。 シングルトン値は A と B に交互に割り当てられ、不均衡への寄与を直接制御します。 

複数回出現する値の場合、最初に 1 つの出現を A にプッシュし、残りを B にプッシュします。これにより、余分なシングルトン寄与が誤って導入されないようにします。 これにより、安定したベースライン割り当てが得られます。 前に発生した不均衡は、これらの複数出現値によって修正可能であると想定されます。 

微妙な点は、この構築が元の位置でインデックス付けされた結果配列に代入を直接書き込むことに依存しているため、順序が自動的に保持されることです。

 ## 特殊なケース

 すべての要素が同一であるマルチセットの場合、次のようにします。`1 1 1 1`、シングルトン制約がないため、アルゴリズムは値を任意に割り当てます。 両方のグループへの寄与はすべてゼロのままであるため、出力は有効なままです。 

異なる値が 2 つだけ存在し、両方が複数回出現する場合、構築では値ごとに 1 つのコピーを A に割り当て、残りを B に割り当てます。 これを追跡すると、厳密に 1 つのグループ内でシングルトンになる値は存在しないため、シングルトン数は等しいままであることがわかります。 

単一出現値が多数存在する場合、交互に代入することで、不均衡が重複した値で補正できる範囲を超えることがなくなります。 この構造により、早期に導入された一時的な差異が、より高い周波数の値から利用可能な柔軟な割り当てによって後で無効化されることが保証されます。
