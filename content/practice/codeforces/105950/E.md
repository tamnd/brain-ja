 ## 解決策
 ## 問題の理解

 隠れた数値のペアを表す 2 つの整数が与えられます。 2 つの未知の値を考えます$A$そして$B$。 それらは直接与えられるのではなく、その代わりに、それらの合計とそれらの間の絶対的な差が示されます。 形式的には、1 つの値は次と等しくなります。$A + B$、他は等しい$|A - B|$。 タスクは、有効なペアを再構築することです。$(A, B)$それは両方の関係を満たします。 

出力の順序は一意ではないため、印刷$(A, B)$または$(B, A)$2 つの方程式が成り立つ限り、 は同様に有効です。 問題ステートメントは、指定された入力に対して少なくとも 1 つの有効なペアが常に存在することを保証します。 

制約は次のとおりです$10^9$、候補者を総当たりで攻撃しようとするアプローチは直ちに排除されます。$A$そして$B$。 考えられるすべての値を単純に検索するには、次の値までをチェックする必要があります。$10^9$1秒の制限時間をはるかに超えた可能性があります。 これにより、いかなる形式の列挙ではなく、直接的な代数的再構成が求められます。 

微妙なケースが現れるのは、$A < B$。 その状況では、絶対値の符号が反転するため、システムは未知数の順序に応じて異なる動作をします。 を前提とした不注意な実装$A \ge B$対称の場合を考慮しないと、多くの場合、隠れたテストには合格しますが、実際の順序が逆になっている入力では失敗します。 たとえば、次の場合$X = 3$そして$Y = 7$、有効な解決策は次のとおりです$(-2, 5)$。 強制するあらゆる試み$A = (X + Y)/2$そして$B = (X - Y)/2$符号の一貫性を処理しないと、両方の値が負ではない、または固定された方法で順序付けされていると誤って想定されてしまいます。 

別のエッジケースが発生するのは次の場合です。$Y = 0$。 これにより、$A = B$、両方の値が等しくなければなりません$X/2$。 これを明示的に考慮しないソリューションも引き続き機能しますが、システムが単一の自由度に退化することが強調されます。 

## アプローチ

 強引なアイデアは、考えられるすべての整数のペアを試してみることです。$(A, B)$妥当な範囲で調整し、両方の式を満たすかどうかを確認します。 各チェックは定数時間ですが、検索空間は入力境界の大きさにおいて 2 次です。 までの値$10^9$、検索を妥当な範囲に制限した場合でも、次のような結果が得られます。$10^{18}$最悪の場合の組み合わせは完全に不可能です。 

重要な観察は、方程式系が小さく、完全に決定されているということです。 我々は持っています：$$A + B = X$$

$$|A - B| = Y$$絶対値を複雑なものとして扱うのではなく、それを 2 つの線形ケースに分割します。 どちらか$A - B = Y$または$A - B = -Y$。 それぞれのケースで、問題は 2×2 線形システムを解くことに帰着します。 これにより、タスクが検索問題から単純な代数に変わります。 

私たちが取るなら$A - B = Y$、次に 2 つの方程式を加算すると、次のようになります。$2A = X + Y$、そして減算すると、$2B = X - Y$。 代わりに$A - B = -Y$、の役割$A$そして$B$対称的に交換します。 この問題では任意の順序で出力できるため、一貫した 1 つの解を計算し、それを直接出力できます。

 | 代数系の解法 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 値を読み取る$X$そして$Y$。 これらは、未知のペアの合計と絶対差を定義します。 
2. を仮定して候補を計算します。$A \ge B$を使用して$A = (X + Y) / 2$。 これは追加から来ています$A + B = X$そして$A - B = Y$、隔離します$A$。 
3. 対応する値を計算します。$B = X - A$。 これにより、丸めの不一致を引き起こすことなく合計制約が正確に満たされることが保証されます。 
4. 出力$(A, B)$。 代替順序が非表示ペアによって意図されている場合、スワップはどちらの方程式にも違反しないため、この出力は依然として有効です。 

### なぜ効果があるのか

 核となる不変条件は、有効な解は絶対差の 2 つの可能な符号の 1 つを選択して導出される線形システムを満たさなければならないということです。 この変換により、問題は決定論的な線形方程式系を解くことに帰着します。 2 つの符号の選択のうち正確に 1 つによって制約と一致する整数解が生成され、問題の存在が保証されるため、計算されたペアは両方の元の方程式を満たさなければなりません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    X = int(input().strip())
    Y = int(input().strip())

    A = (X + Y) // 2
    B = X - A

    print(A, B)

if __name__ == "__main__":
    main()
```実装では、代数導出を直接エンコードします。 この問題では有効な整数解が存在することが保証されているため、整数除算は安全です。$X + Y$is always even in valid cases.

 の建設$B$として$X - A$2 番目の方程式を個別に再計算することを回避し、合計制約との一貫性を保証します。 出力の対称性によりどちらの有効な順序付けも可能となるため、絶対差の符号に基づいて明示的に分岐する必要はありません。 

## 実用的な例

 次の入力を考えてみましょう。```
10
2
```私たちは計算します$A = (10 + 2)/2 = 6$、 それから$B = 4$。 

| ステップ | X | や | あ | B |
 | --- | --- | --- | --- | --- |
 | 開始 | 10 | 2 | - | - |
 | A | を計算する 10 | 2 | 6 | - |
 | B を計算する | 10 | 2 | 6 | 4 |

 これにより有効なペアが生成されます。$6 + 4 = 10$そして$|6 - 4| = 2$。 

ここで次のことを考えてみましょう。```
3
7
```私たちは計算します$A = (3 + 7)/2 = 5$、 それから$B = -2$。 

| ステップ | X | や | あ | B |
 | --- | --- | --- | --- | --- |
 | 開始 | 3 | 7 | - | - |
 | A | を計算する 3 | 7 | 5 | - |
 | B を計算する | 3 | 7 | 5 | -2 |

 これにより、$(5, -2)$、を満たす$5 + (-2) = 3$そして$|5 - (-2)| = 7$。 順序はサンプル出力とは異なりますが、それでも正しいです。

 ## 特殊なケース

 いつ$Y = 0$、システムは崩壊します$A = B = X/2$。 次のような入力の場合:```
4
0
```計算により得られる$A = 2$、$B = 2$。 両方の制約はすぐに満たされ、絶対差は追加情報に寄与しないため、あいまいさは生じません。 

いつ$X = Y$の場合、いずれかの値がゼロになります。 例えば：```
10
10
```生成する$A = 10$、$B = 0$。 絶対差は合計構造と正確に一致し、式は特別なケースなしで依然として成立します。 

いつ$Y > X$、いずれかの値が負になります。 のために：```
3
7
```私たちは得ます$A = 5$、$B = -2$。 これは、非負であると仮定するのが正しくなく、代数導出が符号付き整数を正しく処理することを示しています。 

これらすべてのケースにおいて、方程式が強制するものを超える順序付けや符号の制約を決して仮定しないため、同じ構造が引き続き有効です。
