 ## 解決策
 ## 問題の理解

 長さは何個かを数えるように求められます。`n`を使用して構築できるシーケンス`k`記号。各位置はクイズの答えの選択肢です。 この制約では、4 つの同一の連続値の実行が禁止されます。 言い換えると、シーケンスでは値を繰り返すことができますが、次のようなブロックを含めることはできません。`x x x x`。 

2 番目の動機があります。教授は同じ答えが連続して続くこと、特に 3 つ連続することを好みますが、最終的な要件は純粋に組み合わせです。 スコアを最適化しているわけではありません。 すべての有効なシーケンスをカウントしています。 

したがって、タスクは次のとおりです: 長さのシーケンスをすべてカウントします。`n`アルファベット以上の大きさ`k`文字が 4 回連続して出現しないようにします。 

制約は次のとおりです`n, k ≤ 10^6`これにより、シーケンスを明示的に構築しようとしたり、状態ごとに O(nk) または O(n) 個の遷移を持つ DP を使用しようとしたりするソリューションは直ちに除外されます。 閉じた形式、または最悪の場合でも O(n) で評価できる線形漸化式が必要です。 

単純な動的プログラミングのアプローチでは、位置と現在のランレングスによって状態を定義します。たとえば、`dp[i][len]`、 どこ`len`は 1 ～ 3 です。これにより、O(n) 個の状態が得られますが、依然として O(n) 個の遷移が発生します。これは理論的には問題ありませんが、遷移が定数時間であり、次の要素に依存しない場合に限ります。`k`。 ただし、遷移は次の値が等しいか異なるかを選択することに依存するため、すべてを一定数の反復変数に圧縮できることを確認する必要があります。 

ここではエッジケースが重要です。 のために`n = 1`、いずれかの`k`記号が機能します。 のために`n = 2`そして`n = 3`、連続する 4 つの同一の値を形成することは不可能であるため、すべてのシーケンスは有効です。 のために`n = 4`、唯一の無効なシーケンスは、4 つの位置がすべて等しいものであり、これらは正確に一致します。`k`シーケンス。 どのような解も、これらの小さなケースに正しく帰着する必要があります。そうしないと、再発が誤ってモデル化される可能性があります。 

## アプローチ

 ブルートフォース手法では、すべてが生成されます。`k^n`シーケンスを調べて、4 つの連続する等しい値の違反がないかどうかをそれぞれチェックします。 これは明らかに指数関数的であり、`n = 20`。 この失敗は、ほぼ同一のプレフィックス構造を繰り返し再チェックしているために発生します。 

重要な観察は、妥当性は履歴全体ではなく、最後のいくつかの要素にのみ依存するということです。 具体的には、唯一の禁止パターンは長さ 4 のランであるため、3 を上限とする最後の値の現在のラン長を追跡するだけで済みます。 

これは、動的プログラミング圧縮を示唆しています。完全なシーケンスを追跡する代わりに、同じ値の長さ 1、2、または 3 の連続で終了する有効なシーケンスの数を追跡します。 新しい要素は実行を拡張するか、異なる値で新しい実行を開始します。 「異なる価値」の寄与は常に倍増する`k-1`、歴史に依存しない、これが決定的な単純化です。 

これにより、問題は線形再帰を伴う一定サイズの状態システムに縮小されます。`n`、`10^6`。

 | 実行状態を含む DP | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 各位置に対して 3 つの量を定義します`i`:`a1[i]`: 長さの有効なシーケンスの数`i`まったく同じ値が 1 つ連続して終わる`a2[i]`: 正確に 2 つの同一の値の連続で終わる`a3[i]`: 正確に 3 つの同一の値の連続で終わる

 すべてのシーケンスはこれら 3 つのカテゴリに分類されます。 

1. の初期化`i = 1`。 のいずれか`k`値は長さ 1 の連続を形成するため、`a1[1] = k`、 その間`a2[1] = a3[1] = 0`。 
2. ポジションごとに`i > 1`、長さのシーケンスがどのように構成されるかを考えてください。`i-1`新しい値を追加することで拡張できます。 
3. 計算するには`a1[i]`、シーケンスの最後の要素とは異なる値を位置に追加します。`i-1`。 任意の長さのシーケンス`i-1`で拡張できます`k-1`終了ランの長さに関係なく、方法を変更できます。 したがって`a1[i] = (a1[i-1] + a2[i-1] + a3[i-1]) * (k-1)`。 
4. 計算するには`a2[i]`、最後の要素と同じ値を追加する必要がありますが、正確に 1 の実行で終了するシーケンスにのみ追加する必要があります。そうしないと、3 の実行を超えてしまいます。`a2[i] = a1[i-1]`。 
5. 計算するには`a3[i]`、同じ値をもう一度繰り返すことで長さ 2 のランを拡張します。`a3[i] = a2[i-1]`。 
6. 最終的な答えは次のとおりです。`a1[n] + a2[n] + a3[n]`。 

この分解が有効な理由は、長さ 1、2、または 3 のランで終わるすべてのシーケンスが一意に「4 連続禁止」ルールに違反せずに拡張できる方法を決定し、他の隠れた状態が必要ないためです。 

### なぜ効果があるのか

 制約全体は、最後のランレングスが 4 に達するかどうかのみに依存します。最後のランレングスが同じ 2 つのシーケンスは、拡張下では同じように動作します。異なる値を追加すると常にランがリセットされ、同じ値を追加するとランが 1 増加します。 ランレングスが 3 を超えることは決して許可されないため、これら 3 つの状態はすべての有効な履歴を完全にキャプチャします。 これにより、終了状態ごとに有効なシーケンスの完全な分割が作成され、すべての遷移が重複や省略なく有効性を保持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n, k = map(int, input().split())
    
    if n == 1:
        print(k % MOD)
        return
    
    a1 = k % MOD
    a2 = 0
    a3 = 0
    
    for _ in range(2, n + 1):
        total = (a1 + a2 + a3) % MOD
        
        na1 = total * (k - 1) % MOD
        na2 = a1 % MOD
        na3 = a2 % MOD
        
        a1, a2, a3 = na1, na2, na3
    
    print((a1 + a2 + a3) % MOD)

if __name__ == "__main__":
    solve()
```この実装は、スリーステート モデルを直接反映しています。 の`total`変数は、その位置で終わるすべてのシーケンスを表します`i-1`への遷移を計算するために使用されます。`a1`。 への移行`a2`そして`a3`ランレングスの厳密なシフトです。つまり、以前のランの構造のみに依存し、依存しません。`k`。 

微妙な点は扱い方`k-1`いつ`k = 1`。 その場合、`a1`最初のステップの後、遷移は常に 0 になります。これは、単一の定数シーケンスのみが存在し、長さが 3 を超えると無効になることを正しく反映しています。

 ## 特殊なケース

 のために`n = 1`、アルゴリズムが初期化されます`a1 = k`、すべての有効な単一質問クイズを直接カウントします。 遷移は実行されないため、出力は正しいままになります。 

のために`k = 1`、すべてのシーケンスは強制的に一定になります。 再発はまだ機能します。`k-1 = 0`、 それで`a1`最初の遷移の後はゼロになりますが、`a2`そして`a3`崩壊する前にちょうど 3 ステップ進化します。 のために`n ≥ 4`の場合、考えられる唯一のシーケンスが制約に違反するため、結果は正しくゼロになります。 

のために`n = 4`の場合、DP はゼロ以外のカウントを生成しますが、すべての要素が同一である単一の無効なシーケンスを除外します。 これは、シンボルの選択ごとに禁止された構成が 1 つだけ存在するという事実と一致し、`k^4 - k`有効なシーケンス。再帰によりランレングス 4 への移行が禁止されることで暗黙的に強制されます。
