 ## 解決策
 ## 問題の理解

 私たちは同一の「ペア」の箸のコレクションを与えられ、各ペアは単一の整数の長さによって特徴付けられます。 各ペアから、2 本の箸を長方形の 2 つの等しい辺として扱うことができます。 長方形を形成するには、2 つの異なるペアを選択する必要があります。1 つのペアは垂直辺を提供し、もう 1 つのペアは水平辺を提供します。 長さのあるものを選ぶなら`a`そして長さのある別のペア`b`、長方形の領域は次のようになります。`a × b`。 

課題は、2 つの異なるペアのすべての選択肢に対してこの積を最大化することです。 

入力サイズは小さく、最大でも 100 ペアです。 これにより、高次の複雑さの制約に関する懸念が即座に排除されます。 最悪のケースでも 100 万回程度の操作しかないため、O(N3) ソリューションでも問題なく合格します。 ただし、Python は大きな整数を安全に処理しますが、10⁹ までの大きな値が存在するため、整数の乗算には注意する必要があります。 

微妙なポイントは、個別の箸ではなく、ペアの箸を選択していることです。 これは、選択された各長さがペアの長さのリストからそのまま取得されることを意味します。 個々のスティックを分割したり一致させたりする必要はありません。 

エッジケースは主にパフォーマンスではなく構造に関するものです。 すべての長さが等しい場合、どの 2 つのペアでも同じ長方形が生成されます。 ちょうど 2 つのペアがある場合、答えは単純にその積になります。 最大値が複数回発生する場合は、値が一致しても同じペアを 2 回使用することはできないため、同じ最大値が 2 回出現することを確認する必要があります。 

## アプローチ

 最も直接的なアプローチは、個別のインデックスのすべてのペアを試してみることです。 各ペアごとに`(i, j)`、計算する`l[i] * l[j]`そして最大値を追跡します。 これは正しいです。すべての有効な四角形は 2 つの異なるペアの選択に正確に対応しており、そのようなすべての選択を評価するからです。 

この総当たりアプローチは O(N²) 時間で実行されます。 N ≤ 100 の場合、これは最大 4950 回の乗算を意味しますが、これは簡単です。 したがって、厳密に言えば、これはすでに合格しています。 

ただし、実際に何が重要であるかに注目することで、推論を単純化することはできます。 リストから選択した 2 つの数値の積を最大化するので、最適解には配列内の最大の 2 つの値が含まれている必要があります。 より小さな要素と最大値の積は、2 番目の最大値と最大値の積を超えることはできません。 したがって、上位 2 つの値をソートまたは追跡するだけで十分です。 

これにより、問題が 1 回スキャンされ、最大値と 2 番目に大きい値が保持されるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースペア列挙 | O(N²) | お(1) | 承認済み |
 | 上位 2 つの値を追跡 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 2 つの最大値を抽出する線形解に焦点を当てます。 

1. 2 つの変数を初期化する`first`そして`second`ゼロに。 これらには、これまでに確認された最大の長さと 2 番目に長い長さが格納されます。 すべての入力値が正であるため、ゼロを使用します。 
2. 各長さを反復処理します。`x`入力リストにあります。 
3. もし`x`以上です`first`、 シフト`first`の中へ`second`、次に設定します`first = x`。 これにより、以前の最大値が失われず、2 位の候補が残ることが保証されます。 
4. それ以外の場合、`x`より大きい`second`、 アップデート`second = x`。 これにより、最大値ではない最適な値が追跡されます。 
5. すべての値を処理した後、次のように答えを計算します。`first * second`。 

重要な点は、最大値の重複を処理することです。 最大値が少なくとも 2 回表示される場合、この手順では両方の値が正しく設定されます。`first`そして`second`を最大値にすると、正しい二乗結果が得られます。 

### なぜ効果があるのか

 配列の任意のプレフィックスで、`first`そして`second`は、これまでに発生した最大値と 2 番目に大きい値を表します。 将来の要素は、新たな最大値になるか、2 位を争うかのいずれかになります。 この不変式は、すべての要素を処理した後、配列内の値のペアがこれより大きい積を持たないことを保証します。`first × second`なぜなら、どの候補ペアにもこれら 2 つの最大値以下の値が含まれている必要があるからです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    first = 0
    second = 0
    
    for x in arr:
        if x >= first:
            second = first
            first = x
        elif x > second:
            second = x
    
    print(first * second)

if __name__ == "__main__":
    solve()
```ソリューションはリストを読み取り、2 つの実行最大値を維持します。 重要な実装の詳細は次のとおりです。`>=`アップデート時の状態`first`。 これにより、重複した最大値が正しく伝播されます。`second`のような場合に必要です。`[3, 3]`、両方の値を使用する必要があります。 

ソートは不必要なオーバーヘッドになるため避けますが、ソートすることも正しいことです。 シングルパス更新はより簡単で、余分なメモリを必要としません。

 最終的な答えは、`3 × 2 = 6`。 

これにより、アルゴリズムがこれまでに確認された上位 2 つの値を常に保持していることが確認されます。

 | --- | --- | --- | --- |
 | 1 | 1 | 0 | 最初に更新されました |

これは、最大値の重複を正しく処理することの重要性を示しています。 なしで`>=`状態、`second`誤って 2 のままになり、9 ではなく 6 が生成されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 ## 特殊なケース

 最大値が複数回出現する場合は入力を考慮してください。`3 3 3`。 スキャンは設定によって進行します`first = 3`、`second = 0`最初の要素について。 2番目に`3`、条件`x >= first`再びトリガー、シフト`first`の中へ`second`最後の要素は何も変更しません。 結果は次のようになります`3 × 3 = 9`たとえ値が同じであっても 2 つの異なるペアを選択できるため、これは正しいです。 

次のような厳密に増加するシーケンスの場合`1 2 3`、アルゴリズムは当然次のように終了します。`first = 3`そして`second = 2`。 製品`6`これは、利用可能な 2 つの最大のペア長を選択することに相当します。ペアを小さくすると、一方の要素が増加することなく一方の要素が減少するため、これが最適です。
