 ## 解決策
 ## 問題の理解

 1 から 1 までの数字の順列が与えられます。$n$。 このタスクは、アレイ内の「適切な」位置を特定することを中心に展開します。 左側のすべての要素が小さく、右側のすべての要素が大きい場合、その位置は良好であると呼ばれます。 たとえば、配列では`[1, 3, 2]`、要素`3`インデックス 2 の要素は適切ではありません。`2`その右側の方が小さいです。 私たちは定義します$f(p)$良いポジションの総数として。 

許可される操作は、任意の 2 つの異なる要素を 1 回だけ交換することであり、可能な最大値を決定するように求められます。$f(p)$この交換後。 配列がすでに最適になっている場合でも、スワップを実行する必要があります。 

制約とは次のようなものです$n$まで行くことができます$2 \cdot 10^5$と合計$n$すべてのテストケースでも以下にとどまります$2 \cdot 10^5$。 これにより、スワップのすべてのペアを考慮して再計算する単純なアプローチが除外されます。$f(p)$で$O(n)$スワップごとに、その結​​果、$O(n^3)$最悪の場合。 テスト ケースごとに線形または線形演算のソリューションが必要です。 

エッジ ケースには、すでに並べ替えられている配列、反転されている配列、または境界に極端な要素が含まれている配列が含まれます。 たとえば、厳密に増加する配列`[1,2,3,4,5]`交換後はさらに悪化しますが、それでも交換を実行する必要があります。 厳密に減少する配列`[5,4,3,2,1]`には良いポジションがほとんどないため、慎重に交換することでさらに多くのポジションを生み出すことができます。 

## アプローチ

 ブルートフォース手法では、すべてのペアに対して反復処理が行われます。$(i,j)$、それらを交換し、良いポジションの数を数えます。$O(n)$交換ごとに。 これにより、$O(n^3)$最悪の場合、遅すぎる時間です。$n = 2 \cdot 10^5$。 

複雑さを軽減するための重要な洞察は、「適切な」インデックスはその極大値/極小値の条件によって完全に決定されるということです。 プレフィックス最大値とサフィックス最小値の配列を事前に計算できます。 ポジション$x$あれば良いです`prefix_max[x-1] < p[x] < suffix_min[x+1]`。 これを使用すると、現在の良好なインデックスを特定できます。$O(n)$。 

スワップは 1 回だけ許可されるため、適切な位置の数が最大に増加するのは、境界要素または局所的な位置ずれを修正することによって得られます。 最初と最後の要素と現在の適切な位置に注目することで、プレフィックス配列とサフィックス配列を事前計算した後、一定時間内に最適なスワップを決定できます。 

したがって、最適なアプローチはテスト ケースごとに線形です。つまり、接頭辞と接尾辞の極値を計算し、最初と最後の要素または近くの位置の交換候補を特定し、その影響を評価します。$f(p)$。 これにより、可能な最大値が得られます$f(p)$で$O(n)$時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コンピューティング`prefix_max[i]`最大として`p[0..i]`そして`suffix_min[i]`最小限として`p[i..n-1]`。 これにより、インデックスが現在良好であるかどうかを定期的にチェックできます。 
2. 条件を使用して、現在良好なインデックスをすべて特定します。`prefix_max[i-1] < p[i] < suffix_min[i+1]`。 カウントを次のように保存します`current_good`。 
3. 配列が厳密に増加または厳密に減少している場合、スワップによって良好な位置が最大 1 または 2 だけ減少または増加することに注意してください。 
4. 最初の要素または最後の要素と他の要素の交換を検討します。 境界にある最大要素と最小要素が共通のブロッカーとなるため、境界を交換すると、多くの場合、適切なインデックスの数を最大化できます。 
5. スワップ候補ごとに、スワップされたインデックスとその近傍の新しい適切なポジションのみをチェックします。 交換された位置の周囲の局所的な最大値/最小値の条件のみが変更されるため、配列の残りの部分は影響を受けません。 
6. 最大値を追跡する`f(p)`遭遇して出力しました。 

機能する理由: 交換された位置に隣接する要素のみが、良好なインデックス ステータスを変更できます。 プレフィックス最大値とサフィックス最小値を事前に計算することで、各候補スワップの定数時間評価が保証されます。 スワップを境界または境界に近い要素に制限することで、すべての要素を列挙することを回避します。$O(n^2)$良いポジションを最大化するために重要なスワップをキャプチャしながらペアを構築します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_good_after_swap(n, p):
    if n == 2:
        return 1

    prefix_max = [0]*n
    suffix_min = [0]*n

    prefix_max[0] = p[0]
    for i in range(1,n):
        prefix_max[i] = max(prefix_max[i-1], p[i])

    suffix_min[-1] = p[-1]
    for i in range(n-2,-1,-1):
        suffix_min[i] = min(suffix_min[i+1], p[i])

    good = [0]*n
    total_good = 0
    for i in range(n):
        left = prefix_max[i-1] if i>0 else 0
        right = suffix_min[i+1] if i<n-1 else n+1
        if left < p[i] < right:
            good[i] = 1
            total_good += 1

    max_good = total_good

    # Try swaps involving first or last element
    candidates = [0, n-1]
    for i in range(n):
        for j in candidates:
            if i == j:
                continue
            p[i], p[j] = p[j], p[i]
            new_good = 0
            for k in range(max(0,min(i,j)-1), min(n,max(i,j)+2)):
                left = prefix_max[k-1] if k>0 else 0
                right = suffix_min[k+1] if k<n-1 else n+1
                if left < p[k] < right:
                    new_good += 1
            new_good += total_good - (good[i]+good[j])
            max_good = max(max_good, new_good)
            p[i], p[j] = p[j], p[i]

    return max_good

t = int(input())
for _ in range(t):
    n = int(input())
    p = list(map(int,input().split()))
    print(max_good_after_swap(n,p))
```このソリューションでは、まずプレフィックスの最大値とサフィックスの最小値を計算して、適切なインデックスを効率的に特定します。 現在の良好なインデックスの数をカウントし、効果を最大化するために境界要素のみを含むスワップを試みます。 各スワップは影響を受けるポジションのみを再評価し、テスト ケースごとにアルゴリズムを線形に保ちます。 全体的なロジックにより、すべてのスワップにわたる完全な再計算が回避されますが、これは実行不可能です。
