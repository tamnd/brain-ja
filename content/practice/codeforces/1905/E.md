 ## 解決策
 ## 問題の理解

 ある長さの配列に基づいて構築されたセグメント ツリーを操作するように求められます。$n$ここで、セグメント ツリーは標準的なバイナリ再帰構造です。 ツリーの各ノードは配列のセグメントに対応し、ルート ノードには というラベルが付けられます。$1$。 その左と右の子にはラベルが付けられます$2v$そして$2v+1$、 どこ$v$は現在のノードです。 葉は単一要素のセグメントに対応します。 

中心的なタスクは、リーフの空ではないすべてのサブセットを考慮し、それらの最も共通しない祖先のノード数を合計することです。 たとえば、葉に から始まる連続した番号が付けられている場合、$n$、リーフのサブセットごとに、LCA であるツリー内のノードを決定し、その数を累計に加算します。 サブセットの数は指数関数的に増加するため、総当たりの列挙は不可能です。 最大の$n$は$10^{18}$したがって、時間計算量が次の値に比例するアプローチはすべて、$n$はすぐに除外されます。 

明らかではないエッジケースが現れるのは、$n$セグメント ツリーのバランスが崩れるため、 は 2 の累乗ではありません。 たとえば、$n=3$、葉はノード 2、3、4、ルートは 1 です。完全な高さのツリーを想定した素朴なアプローチ$\lceil \log_2 n \rceil$不均衡な分岐をまたぐサブセットの LCA 数値が誤って計算されます。 非常に大きな取り扱い$n$また、ツリーを明示的に構築できないことも意味します。 定型的なアプローチが必要です。 

## アプローチ

 ブルートフォース手法では、リーフのすべてのサブセットを反復処理し、LCA を計算し、ノード数を合計します。 バイナリ ツリー内の 2 つのノードの LCA は通常の親ポインタを介して計算できるため、これは原理的に機能します。 ただし、サブセットの数は$2^n - 1$でさえ天文学的な大きさです。$n=60$したがって、明らかにこのアプローチは次の場合に失敗します。$n$までです$10^{18}$。 

重要な洞察は、セグメント ツリー内のすべてのノードが、各子サブツリーからの少なくとも 1 つの葉を含む、サブツリー内の葉の空でないサブセットごとに 1 回だけ合計に寄与するということです。 させたら$f(v)$ノードの下にある葉の空ではないサブセットの数になります。$v$、ノードによって寄与された合計$v$は、左と右の両方の子にまたがるサブセットの数とノード番号の積として再帰的に表現できます。 もっと正式に言えば、$L$そして$R$左右のサブツリーの葉の数です。ノード$v$貢献する$v \times ((2^L - 1) \times (2^R - 1))$。 リーフ自体は、自分の番号を 1 回だけ提供します。 

この観察により、セグメント ツリーを明示的に構築することなく、問題がセグメント ツリーに対する再帰式に帰着します。 2 のべき乗とべき乗剰余を使用することで、巨大な場合でも結果を効率的に計算できます。$n$。

 ## アルゴリズムのチュートリアル

 1. 現在のサブツリー内のリーフの数を決定します。 セグメントに対応するノードの場合$[l,r]$、葉の数は$r-l+1$。 もし$l=r$、葉そのものです。 
2. 現在のノードがリーフの場合は、その寄与として独自の番号と 1 リーフのカウントを返します。 
3. それ以外の場合は、次を使用してセグメントを左半分と右半分に分割します。$m = \lfloor (l+r)/2 \rfloor$、そして左と右の子の寄与を再帰的に計算します。 
4. しましょう$L$そして$R$は、左右のサブツリーの葉の数になります。 各子からの少なくとも 1 つのリーフを含むサブセットの数は次のとおりです。$(2^L - 1) \times (2^R - 1)$。 これに現在のノード番号を乗算して、このノードの寄与を取得します。 
5. 左の子、右の子、および現在のノードからの寄与の合計 (モジュロ 998244353) と、このノードの下にあるリーフの合計数を返します。 
6. セグメントに対応するルートノードから再帰を開始します$[1,n]$。 

機能する理由: 不変条件は、リーフのすべてのサブセットが、そのサブセットの LCA であるノードに 1 回だけ寄与するということです。 左と右のサブツリーのサブセットを再帰的にカウントし、両方にまたがる組み合わせを考慮して乗算することで、LCA としてこのノードを持つすべてのサブセットが正確に 1 回カウントされるようにします。 シングルトン サブセットには LCA としてリーフがあるため、リーフ ノードは自動的に自身を提供します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modpow(a, b):
    res = 1
    while b > 0:
        if b % 2:
            res = res * a % MOD
        a = a * a % MOD
        b //= 2
    return res

def sum_lca(v, l, r):
    if l == r:
        return v, 1  # contribution, number of leaves
    m = (l + r) // 2
    left_sum, left_count = sum_lca(2*v, l, m)
    right_sum, right_count = sum_lca(2*v+1, m+1, r)
    cross = (modpow(2, left_count) - 1) * (modpow(2, right_count) - 1) % MOD
    total = (left_sum + right_sum + v * cross) % MOD
    return total, left_count + right_count

t = int(input())
for _ in range(t):
    n = int(input())
    ans, _ = sum_lca(1, 1, n)
    print(ans)
```機能`modpow`計算する$a^b \mod 998244353$効率的に。`sum_lca`をルートとするサブツリー内の LCA 数値の合計を再帰的に計算します。`v`。 再帰呼び出しは寄与の合計とリーフの数の両方を返します。これにより、LCA 寄与のクロスサブツリー サブセットの数を計算できます。 モジュロ演算により、整数のオーバーフローが確実に回避されます。
