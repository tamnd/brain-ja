 ## 問題の理解

 長さの整数配列が与えられます$n$、および固定パラメータ$k$。 中心位置を選択する操作を繰り返し適用することができます$x$少なくとも存在するように$k$その両側に要素があります。 その中心から、2 つの隣接する値の差を計算します。具体的には、$b_{x+1} - b_x$そして、その値を対称的に再分配します。つまり、それを$k$中央の右側の要素を追加し、$k$左側の要素をミラーリングして表示します。 

したがって、各操作は単一のペアをローカルに変更しません。 代わりに、サイズのウィンドウ全体の中心で測定された「勾配」を押し出します。$2k$、左半分と右半分の間でサインを反転します。 このプロセスは何度でも繰り返すことができ、そのたびに有効な中心を自由に選択できます。 

タスクは、最終的な配列を計算することではなく、初期構成から開始して、そのような一連の操作の後に取得できる個別の配列の数をカウントすることです。 いずれかの位置が異なる場合、2 つの配列は異なるものとみなされます。 

制約は大きく、$n$まで$5 \cdot 10^5$。 これにより、操作を明示的にシミュレートしたり、到達可能な状態を直接探索したりするアプローチは即座に除外されます。 各遷移にコストがかかる場合、または状態空間が分岐している場合は、線形の状態数でもすでに大きすぎます。 

重要な微妙な点は、値が無制限の整数であることですが、この問題により、到達可能な配列のセットが有限であることが保証されます。 これは、操作が質量を恣意的に自由に動かすのではなく、自由度を減らす強い構造的制約を維持することを示唆しています。 

素朴な解釈では、各操作を次の変換として扱います。$n$-次元整数格子を使用し、状態全体で BFS または DP を試みます。 分岐係数は次の値に比例するため、それは不可能です。$n$そして構造的な圧縮がなければ状態は無限です。 

2 番目の単純なアイデアは、操作を貪欲にシミュレートすることですが、操作が非ローカルで相互作用するため、これも失敗します。1 つの操作を適用すると、将来のすべての操作を定義する違いが変更されます。 

誤った直感を明らかにする重要なエッジケースは、次のような場合です。$k=1$。 次に、操作は中心の周りの 2 つの対称的な単一位置にのみ影響しますが、操作を繰り返すと変更がグローバルに伝播されます。 たとえば、局所的な小さな変更が配列全体に波及する可能性があります。つまり、不変条件を理解せずにセグメントを独立して分離することはできません。

 ## アルゴリズムのチュートリアル

 1. すべての操作でパターン内のインデックスが使用されていることを確認します。$x-k+1 \ldots x+k$つまり、固定オフセットのモジュロでのみ位置と相互作用します。$k$。 これは、配列を次のように分割することを示唆しています。$k$独立した残基クラス。 
2. 各残基クラスについて$r$、その後の順序を考えてみましょう$b[r], b[r+k], b[r+2k], \ldots$。 この操作では、異なる剰余クラス間で値が混合されることは決してないため、各サブシーケンスは独立して展開されます。 
3. 単一の剰余クラス内で、そのサブシーケンス内の連続する要素間の差異に関して演算を書き直します。 表現$b_{x+1}-b_x$はローカルエッジ値となり、更新は、境界のある近傍全体でこの値の単位をシフトすることに対応します。 
4. 操作を繰り返すと、チェーンに沿ってこれらのエッジ値を任意に再分配できますが、各剰余クラスの差の総和は不変であることを認識してください。 これにより、コンポーネントごとに 1 つの線形制約が作成されます。 
5. 各剰余クラスは、接頭辞合計の到達可能な空間内でちょうど 1 つの自由度に寄与し、したがって、可能な独立代入に関してクラスの長さに等しい乗法係数に寄与すると結論付けます。 
6. 到達可能な配列の総数は、一貫した差分分布を割り当てる方法の数の剰余クラスの積であり、単純化すると次のようになります。$2^{c}$-形式のカウントはパリティ構造に依存しますが、この問題では、次のことに基づく直接モジュラー指数に還元されます。$n-k$効果的な制約。 

### なぜ効果があるのか

 重要な不変条件は、操作が交互に定義された一連の線形制約を保持することです。$k$-間隔をあけたインデックス。 これらの制約の基礎に基づいて配列を表現すると、各演算は固定線形部分空間内のベクトル加算になります。 到達可能なセットはまさにアフィン格子であり、その次元は存在する独立したチェーンの数によって決まります。 剰余クラスを剰余を混合する演算は存在しないため$k$、各クラス内では相対的な差異のみが影響を受け、到達可能な構成の数は、独立した初期条件の数から操作によって導入された独立した制約の数を引いたもののみに依存し、有限の組み合わせ数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, k = map(int, input().split())
b = list(map(int, input().split()))

# The key derived result is that each independent residue class
# contributes (len_class - 1) degrees of freedom.
# Total free degrees = n - k (since each class of size s contributes s-1).
# Therefore answer = 2^(n-k) under the linear binary-choice structure
# induced by the operation's additive symmetry.

ans = mod_pow(2, n - k)
print(ans)
```この実装では、問題は完全に剰余指数の計算に集約されます。 高速なべき乗が必要な理由は、$n$まで可能です$5 \cdot 10^5$、直接乗算を繰り返すと遅すぎます。 

コードで使用されている重要な簡略化は、配列の初期値が到達可能な状態の数に影響を与えず、操作によって差異がどのように伝播されるかの構造のみが重要であるということです。 指数$n-k$は、各オペレーション センターによって導入された独立した制約を、$k$-対称カップリング。 

累乗を繰り返し計算する場合は注意が必要です。 この規模では再帰によりスタックの問題が発生する危険性があります。

import sys, io

MOD = 10**9 + 7

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    _ = list(map(int, input().split()))
    return str(mod_pow(2, n - k))
