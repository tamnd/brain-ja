 ## 問題の理解

 2 つの非常に大きな正の整数が与えられています。`a`そして`b`そして、テストケースごとに、別の正の整数が存在するかどうかを判断する必要があります。`x`(によって制限される$10^{18}$) 2 つの条件を同時に満たします。 

最初の条件強制`x`～と素因数を共有しない`a`、 意味`x`と互いに素でなければならない`a`。 2 番目の条件には次の条件が必要です`x`少なくとも 1 つの素因数を共有する`b`、の最大公約数を意味します`x`そして`b`は厳密に 1 より大きくなります。 そのような場合`x`存在する場合は、有効なものを出力できます。 

制約が十分に大きいため、いかなる形式の列挙も試みることはできません。`x`。 平方根まで反復したり、テスト ケースごとに候補となる約数をスキャンしたりすることさえ、最大数がある場合は安全ではありません。$10^4$テストケースと値が到達する$10^{18}$。 実行可能な解決策は、問題を次の素因数に関する推論に帰着させる必要があります。`a`そして`b`の候補値を操作するのではなく、`x`。 

微妙な失敗例が現れるのは、`b`～に欠けている素因数はありません`a`。 たとえば、次の場合`a = 6`そして`b = 3`、で割り切れるすべての数`b`は 3 で割り切れますが、3 は割り切れるので、`a`、そのようなもの`x`共素性条件に違反します。 共有素構造の観点から考えずに可分性関係のみをチェックする単純なアプローチでは、解が存在すると誤って仮定する可能性があります。 

もう 1 つのエッジケースは次のような場合です`b = 1`。 この場合、`gcd(b, x)`は常に 1 であるため、2 番目の条件は決して満たされず、答えは常に不可能になります。`a`。 

## アプローチ

 強引な解釈では、次の候補を構築しようとします。`x`2 つの gcd 条件を直接テストします。 テスト ケースごとに、考えられる約数を反復してみるとよいでしょう。`b`、または素数の倍数による除算でも`b`のすべての素因数を回避しているかどうかを確認します。`a`。 これは概念的には正しいです。`x`少なくとも 1 つの素因数が含まれている必要があります`b`、しかし、このアプローチは入力の規模の下では崩壊します。 数値が次の値に達すると、数値を繰り返し因数分解したり、多数の候補をテストしたりすることさえ不可能になります。$10^{18}$。 

重要な観察は、重要なのは次の素因数集合だけであるということです。`a`そして`b`。 満足するために`gcd(a, x) = 1`、どの素数も分割しないことを確認する必要があります。`x`に登場する`a`。 満足するために`gcd(b, x) > 1`、少なくとも 1 つの素数除算が必要です`b`分けることも`x`。 これら 2 つの制約は、少なくとも 1 つの素因数が存在する場合にのみ満たされます。`b`それは分けない`a`。 

そのアイデアが定まると、構築は簡単になります。 私たちは考慮します`b`異なる素因数に分割し、それぞれの素因数に対して`p`かどうかを確認します。`p`分割する`a`。 もしそのようなものが存在するなら`p`それは分けない`a`、単純に選択できます`x = p`。 これは両方の条件を自動的に満たします。つまり、次の素因数を共有します。`b`と互いに素である`a`。 

すべての素因数が`b`も分割します`a`、次に因数を共有する任意の数`b`必然的に因子を共有します`a`、条件が両立しなくなります。

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 

1. もし`b = 1`、すぐに出力`-1`。 これは整数がないためです`x`作ることができます`gcd(b, x)`1 より大きいとき`b`には素因数がありません。 
2.因数分解`b`異なる素約数に変換します。 までの試行分割で行います。$\sqrt{b}$、各素因数を 1 回抽出し、重複をスキップします。 
3. 各素因数について`p`の`b`、どうかを確認してください`a % p != 0`。 これが成り立つ場合、以下に属する素数が見つかったことになります。`b`しかしそうではありません`a`、安心して選ぶことができます。`x = p`そしてすぐに出力します。 
4. すべての素因数のスキャンが完了すると、`b`そしてそれぞれが分裂する`a`の場合、有効な構造が存在しないため、次のように出力します。`-1`。 

選んだ理由`x = p`それは、それが保証される最小の構造であるということです。`gcd(b, x) > 1`。 因子を追加しても交差するリスクが増加するだけであるため、複合値を構築する必要はありません。`a`。 

### なぜ効果があるのか

 このアルゴリズムは、単純な構造的不変条件、つまり有効なすべての条件に依存します。`x`以下の素因数を少なくとも 1 つ含める必要があります`b`、そして次のすべての素因数を避ける必要があります。`a`。 したがって、実現可能性は、次の素因数の集合が適切であるかどうかにのみ依存します。`b`の素因数のサブセットではありません`a`。 素数が存在する場合`b`欠席`a`、その素数を選択するだけで両方の制約が満たされます。 そのような素数が存在しない場合、約数を共有する任意の数`b`因子を自動的に共有します`a`、条件は相互に排他的になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_case(a, b):
    if b == 1:
        return -1

    x = b
    i = 2
    found = False

    # try to extract prime factors of b
    while i * i <= x:
        if x % i == 0:
            if a % i != 0:
                return i
            while x % i == 0:
                x //= i
        i += 1

    if x > 1:
        if a % x != 0:
            return x

    return -1

def main():
    t = int(input())
    out = []
    for _ in range(t):
        a, b = map(int, input().split())
        out.append(str(solve_case(a, b)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```実装は因数分解ロジックに直接続きます。 削減します`b`約数をスキャンする際に、各素因数が 1 回だけ考慮されるようにします。 小切手`a % i != 0`選択された素数が次の領域に出現してはならないという要件をエンコードします。`a`。 最後に残ったもの`x > 1`次の場合を処理します`b`それ自体がプライムです。 

よくある落とし穴は、小さな要素を分割した後、残りの要素が重要であることを忘れることです。`x`は 1 または素数のいずれかです。 これは、次の場合に正確性を保つために不可欠です。`b`平方根の範囲を超える大きな素因数が含まれています。
