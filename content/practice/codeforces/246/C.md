 ## 解決策
 ## 問題の理解

 私たちは、数日間にわたる美人コンテストに参加する大隊から兵士を選出するように求められます。 各兵士は独自の美しさの価値を持っています。 毎日、他の日と比べて独特の美しさを兼ね備えた兵士のグループを派遣しなければなりません。 毎日の分遣隊を空にすることはできず、この一意性条件を満たす毎日の兵士のリストを作成する必要があります。 

入力により、兵士の数、ページェントが続く日数、兵士の個々の美しさの値が得られます。 出力では、選択した兵士の数とそれらの兵士の特定の美しさを毎日印刷する必要があります。 

制約は次のことを教えてくれます`n`は最大 50 まで可能で、美しさ自体は最大 10^7 の正の整数です。 なぜなら`n`が小さいため、理論的にはすべてのサブセットの数が指数関数的であっても、パフォーマンスの限界に達することなく兵​​士のサブセットを考慮するアプローチが可能になります。 問題によって解決策が存在することが保証されるため、解決不可能なケースを処理する必要はありません。 

エッジケースは、日数が`k`兵士の数を超える`n`。 たとえば、次の場合`n = 3`そして`k = 5`、兵士が足りないため、単純に 1 日に 1 人の兵士を割り当てることはできません。 次に、兵士を複数メンバーの分遣隊にまとめて、毎日の合計が固有になるようにする必要があります。 常に単一の兵士を選択するような不注意な解決策は、ここでは失敗します。 

もう 1 つの微妙な点は、サブセットの合計が区別できる必要があることです。 個々の美しさはすべてユニークであるため、単一の兵士を選択すると確実に`n`ユニークな合計。 いつ`k > n`、兵士を分遣隊にまとめる必要がありますが、これはいつでも建設的に行うことができます。 

## アプローチ

 単純な総当り的なアプローチでは、毎日、考えられるすべての兵士のサブセットを試し、合計が一意であるかどうかを確認します。 空でないサブセットの総数`n`兵士は`2^n - 1`。 のために`n = 50`、これは 10^15 を超えており、明らかに実行不可能です。 組み合わせを確認しようとしても`k`日数がかかるとさらにこれが倍増するため、中程度の場合はブルート フォースはすぐに失敗します。`n`。 

重要な洞察は、すべてのサブセットが必要なわけではないということです。 最初のそれぞれに割り当てることができます`n`1 人の兵士が 1 日分の日数を確保し、その日数分の独自の金額を確保します。 もし`k > n`、最小限の追加兵士を選択し、既存の各兵士と組み合わせて、追加の一意の合計を生成するだけです。 美しさはユニークであるため、他の兵士の美しさを追加すると、常に以前のすべての合計とは異なる新しい合計が生成されます。 これにより、サブセットを列挙したり合計を繰り返しチェックしたりすることなく、単純な構築的なアルゴリズムが可能になります。 

このアプローチは、貪欲な方法で分遣隊を直接構築するため、拡張性に優れています。最初は個々の美女から始めて、より独自の合計が必要な場合にのみ追加の兵士を組み合わせます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n × k) | O(2^n) | 遅すぎる |
 | 建設的な貪欲さ | O(n + k) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 兵士を美しさ順に並べ替えます。 このステップは正確さを保つために厳密には必要ありませんが、決定的な選択と出力を簡素化します。 
2. 毎日の分遣隊を保持するリストを初期化します。 
3. まず最初に`n`日ごとに、ユニークな美しさを持つ兵士を 1 人割り当てます。 これにより保証されます`n`ユニークなシム。 
4. もし`k > n`、残りについては`k - n`日ごとに、最初の兵士とその日にまだ使用されていない他の兵士の 1 人を割り当てます。 合計には複数の美しさが含まれるため、新しい組み合わせごとに、以前のすべての合計とは異なる合計が生成されます。 
5. 分遣隊を日ごとに印刷します。最初に兵士の数を印刷し、その後に美女を任意の順序で印刷します。 

機能する理由: このアルゴリズムは、毎日、美しさの合計がユニークである分離があるという不変条件を維持します。 単一の兵士を使用すると、最初は一意性が確保され、追加の日数で兵士を組み合わせると、すべての合計が少なくとも追加の美しさの値だけ変化するため、一意性が維持されます。 建設的な性質により、合計の衝突が回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, k = map(int, input().split())
a = list(map(int, input().split()))

# Sort for deterministic output
a.sort()

detachments = []

# Step 1: assign one soldier per day
for i in range(min(n, k)):
    detachments.append([a[i]])

# Step 2: if more days are needed, add extra soldiers to first
extra_needed = k - n
idx = 0
for _ in range(extra_needed):
    # Take first soldier plus another
    detachments.append([a[0], a[idx + 1]])
    idx += 1

# Output
for det in detachments:
    print(len(det), *det)
```コードはまず、最初のそれぞれに割り当てます。`n`日々、一人の兵士。 さらに日数が必要な場合は、最初の兵士と他の兵士を組み合わせて新しい合計が生成されます。 並べ替えは単純な決定的なパターンを維持するのに役立ちますが、任意の順序でも機能します。 使用する`len(det)`各行の最初の数値が正しいことを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()
    detachments = []
    for i in range(min(n, k)):
        detachments.append([a[i]])
    extra_needed = k - n
    idx = 0
    for _ in range(extra_needed):
        detachments.append([a[0], a[idx + 1]])
        idx += 1
    out = []
    for det in detachments:
        out.append(f"{len(det)} {' '.join(map(str, det))}")
    return "\n".join(out)

# provided sample
assert run("3 3\n1 2 3\n") == "1 1\n1 2\n1 3", "sample 1"

# custom cases
assert run("3 5\n4 5 7\n") == "1 4\n1 5\n1 7\n2 4 5\n2 4 7", "k > n case"
assert run("1 1\n10\n") == "1 10", "single soldier single day"
assert run("2 3\n100 200\n") == "1 100\n1 200\n2 100 200", "two soldiers three days"
assert run("4 4\n1 3 6 10\n") == "1 1\n1 3\n1 6\n1 10", "n=k case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 3 5 \n4 5 7 | 1 4\n1 5\n1 7\n2 4 5\n2 4 7 | k > n | の処理
 | 1 1 \n10 | 1 10 | 最小入力 |
 | 2 3 \n100 200 | 1 100\n1 200\n2 100 200 | 追加の日数のために兵士を結合する |
 | 4 4 \n1 3 6 10 | 1 1\n1 3\n1 6\n1 10 | 日と兵士の完全一致 |

```生成する```

```1 日しかないため、一意性が満たされます。 のために`k > n`と`n > 1`、アルゴリズムは決定論的な順序で兵士を結合し、すべての合計が明確になるようにします。 これにより、特殊な場合のロジックを使用せずに、すべてのエッジ条件が確実に処理されます。
