 ## アルゴリズムのチュートリアル

 中心となるアイデアは、明示的に構築することなく、すべての有効な順列を特徴付けることです。 

### 1. 1 を除くすべての位置の構造を修正します。 

あらゆる人にとって$i \ge 2$、割り当て$p[i] = i$各数値はそれ自体を除算するため、常に有効です。 これにより、位置を除くすべての制約をすでに満たすベースライン構成が形成されます。$1$。 

このベースラインはすべての値を使用します$2..n$正しくは、値だけを残します$n+1$未使用。 

### 2. ポジション 1 の役割を理解する

 ポジション$1$「すべては 1 で割り切れる」という割り切り制限がないため、残りの値を任意に取ることができます。 置き換えによってもたらされる柔軟性を吸収できるのはこのポジションだけです$1$と$n+1$。 

### 3. 位置 1 を別のインデックスと交換することを検討します。 

割り当てれば$p[1] = k$、次に値$k$自然な位置から外されます。 他の立場をあまり邪魔せずに有効性を維持する唯一の方法は、$n+1$所定の位置に$k$、つまり$p[k] = n+1$他のすべての位置を固定したままにします。 

これにより、次の間のきれいな 2 サイクルが作成されます。$1$そして$k$、他のすべてはアイデンティティのままです。 

### 4. このスワップの実現可能性を確認する

 割り当てがその位置で有効になるようにするには$k$、次のものが必要です。$$k \mid (n+1)$$なぜなら$p[k] = n+1$。 

したがって、有効な構成はすべて、除数の選択に正確に対応します。$k$の$n+1$と$1 \le k \le n+1$。 

### 5. 有効な選択肢をすべて数えます

 すべての約数$k$の$n+1$有効な構成が 1 つ与えられますが、$k=1$パッティングに対応$1$所定の位置に$1$、これは不可能です。$1$は利用できません。 

したがって、答えは次のとおりです。$$\text{number of divisors of } (n+1) - 1$$### なぜ効果があるのか

 すべてのポジション$i \ge 2$ID 割り当てに基づく制約をすでに満たしています。 を使用することによって導入される唯一の妨害$k \neq n+1$ローカライズされています: スワッピング$1$そして$k$位置のみに影響します$k$、そして実現可能性は単一の割り算条件に帰着します。$k \mid (n+1)$。 これを超える 2 番目の「追加の自由度」がないため、より大きなサイクルは形成できません。$n+1$, そのため、システムは複数の指数にわたる独立した調整をサポートできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 100000 + 5

# smallest prime factor sieve
spf = list(range(MAXN))
for i in range(2, int(MAXN ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXN, i):
            if spf[j] == j:
                spf[j] = i

def count_divisors(x):
    res = 1
    while x > 1:
        p = spf[x]
        cnt = 0
        while x % p == 0:
            x //= p
            cnt += 1
        res *= (cnt + 1)
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    x = n + 1
    print(count_divisors(x) - 1)
```この解決策は、事前に計算された最小素因数ふるいに依存して、数値を迅速に因数分解します。 各テスト ケースについて、次の約数の数を計算します。$n+1$素因数分解を使用し、1 を減算して無効な約数を除外します$1$。 

引き算は不可欠です。これにより、次のような不可能なケースが排除されます。$p[1] = 1$、以降の値$1$新しいシャツのセットには存在しません。

## テストケース```python
import sys, io

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    MAXN = 100000 + 5
    spf = list(range(MAXN))
    for i in range(2, int(MAXN ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, MAXN, i):
                if spf[j] == j:
                    spf[j] = i

    def count_divisors(x):
        res = 1
        while x > 1:
            p = spf[x]
            cnt = 0
            while x % p == 0:
                x //= p
                cnt += 1
            res *= (cnt + 1)
        return res

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        out.append(str(count_divisors(n + 1) - 1))
    return "\n".join(out)

 ## 特殊なケース

 いつ$n=1$、システムは値が設定された単一の位置に縮退します。$\{2\}$。 唯一の有効な代入は、以下に対応する自明なものです。$n+1=2$除外した後、有効な約数の選択肢が 1 つだけ存在する$1$。 

いつ$n$素数マイナス 1 だとします$n+1 = p$、約数の数は正確に$2$。 取り外し後$1$、アイデンティティのような割り当てに対応する 1 つの構成だけが残ります。 除数カウントの式により次のような結果が得られるため、アルゴリズムはこれを自然に処理します。$2 - 1 = 1$。 

いつ$n+1$高度に複合的であるため、有効な構成の数は増加しますが、それぞれの構成は依然として位置を含む 1 つのスワップに対応します。$1$, そのため、選択肢間の干渉は発生しません。
