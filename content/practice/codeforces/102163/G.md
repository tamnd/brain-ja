 ## 解決策
 ## 問題の理解

 アリは、度単位で測定された間隔 ([L,R]) から均一に打ち出し角度を選択します。 茶滴は速度 (V) で原点から始まり、重力 (g=10) の下で通常の発射体の動きに従い、(X) 軸に戻ります。 各友人は、その軸上の間隔 ([X_1,X_2]) で表されるカップを所有しています。 すべてのカップについて、着地座標がその区間に属するようにする打ち出し角度の割合が必要です。 カップは重複する場合があり、それぞれの確率は独立して計算されます。 

角度 (\theta) の発射範囲は次のとおりです。 

[
 x(\theta)=\frac{V^2\sin(2\theta)}{g}
 =\frac{V^2}{10}\sin(2\θ)。 
]

 入力では (N\le 1000) が許可されるため、テスト ケースごとに (O(N)) 個のソリューションがあれば十分に高速になります。 (O(N\log N)) でも快適に収まりますが、各カップは独立して処理できるため、ここで何かを並べ替える理由はありません。 座標と速度は (10^9) に到達できるため、(V^2) は (10^{18}) に到達できます。 Python の整数はこれを正確に処理しますが、答えは小数点以下 4 桁まで出力されるため、最終的な逆三角関数の計算には浮動小数点精度のみが必要です。 

幾何学的な主な問題は、(x(\theta)) が (0^\circ) から (90^\circ) の区間全体にわたって単調ではないことです。 (45^\circ) まで増加し、その後減少します。 逆正弦角を 1 つだけ計算する不注意な実装では、2 番目の分岐を見逃します。 たとえば、(V=10) の場合、角度 (30^\circ) と角度 (60^\circ) は両方とも (10\sin60^\circ) の着地位置を生成します。 両方の角度が確率に寄与する必要があります。 

エンドポイントにも注意が必要です。 考慮する```
1
1 10 0 90
0 10
```可能な最大範囲は (10) であるため、正解は次のようになります。`1.0000`。 小さな浮動小数点誤差のために (x=V^2/10) を逆正弦領域の外側にあるものとして扱う数式は、誤ってゼロまたは領域エラーを生成する可能性があります。 

ケース (L=R) も特殊な状況です。 例えば、```
1
1 10 45 45
9 10
```打ち出し角は (45^\circ) に固定され、(x=10) になります。したがって、正解は次のようになります。`1.0000`。 このケースを処理せずに (R-L) で除算すると、ゼロで除算されます。 

最後に、カップは発射体の最大射程を完全に超えて横たわることもあります。 のために```
1
1 10 0 90
11 20
```答えは`0.0000`というのは、ドロップは (10) よりも遠くに到達することはできないからです。 同じ推論で、(0) で始まるカップも処理されます。角度間隔が正の長さの場合、正確な終点 (x=0) の確率はゼロになります。 

## アプローチ

 直接的な強引なアイデアは、多くの打ち出し角度をサンプリングし、対応する着地位置をシミュレートし、各カップに入るサンプルの数をカウントすることです。 角度が唯一の確率変数であるため、これは近似としては機能しますが、競合プログラミングのソリューションとしては適切ではありません。 たとえば、(90^\circ) 間隔で (10^{-5}) 度ごとにサンプリングするには、1 杯あたり約 (9\cdot10^6) 個のサンプルが必要です。 (N=1000) の場合、およそ (9\cdot10^9) カップのチェックになります。 さらに重要なことは、サンプリング誤差が慎重に制御されない限り、サンプリングでは必要な小数第 4 位の四捨五入に対する明確な数学的保証が得られないことです。 

答えは有効な角度のセットの正確な測定値であるため、総当りの力が機能します。 有益な観察は、そのセットを分析的に説明できるということです。 

から始まる

 [
 x=\frac{V^2}{10}\sin(2\θ),
 ]

 着陸座標 (x) は次のようになります。 

[
 \sin(2\theta)=\frac{10x}{V^2}。 
]

 (0\leq x\leq V^2/10) の場合、

 [
 \alpha=\frac{1}{2}\arcsin\left(\frac{10x}{V^2}\right)。 
]

 (0^\circ\leq\theta\leq90^\circ) 内では、方程式 (x(\theta)=x) には 2 つの可能な解があります。 

[
 \シータ=\アルファ
 ]

 そして

 [
 \シータ=90^\circ-\alpha。 
]

 さらに重要なのは、不等式 (x(\theta)\leq x) が 2 つの区間で成り立つことです。 

[
 \theta\leq\alpha
 ]

 または

 [
 \theta\geq90^\circ-\alpha.
 ]

 したがって、任意の座標 (x) について、要求された角度間隔 ([L,R]) のうち最大でどのくらいの着地座標 (x) が生成されるかを正確に計算できます。 この量を (F(x)) と呼びます。 カップ内に着地する確率 ([X_1,X_2]) は単純に次のようになります。 

[
 \frac{F(X_2)-F(X_1)}{R-L}。 
]

 問題を (O(N)) に変える観察は、すべてのカップがこの同じ累積関数の評価を 2 回だけ必要とするということです。 カップ間には相互作用がないため、カップが重なっても特別な処理は必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(NM))、ここで (M) はサンプリングされた角度の数 | (O(1)) | 遅すぎるし、近似値しかない |
 | 最適 | (O(N)) | (O(1)) 入出力ストレージ以外 | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (L) と (R) を度からラジアンに変換します。 Python の三角関数ではラジアンが使用され、計算全体をラジアン単位にしておくと、角度を繰り返し変換する必要がなくなります。 
2. 可能な最大水平範囲を定義します。 

[
 X_{\max}=\frac{V^2}{10}。 
]

 クエリされた座標 (x) が少なくとも (X_{\max}) である場合、考えられるすべての発射角は (x) またはそれより前に着地します。 (x\leq0) の場合、正確に (x=0) での着陸は孤立した終点角度でのみ発生するため、非縮退角度間隔の累積確率はゼロになります。 

1. (0<x<X_{\max}) について、計算します。 

[
 \alpha=\frac12\arcsin\left(\frac{10x}{V^2}\right)。 
]

 (x(\theta)\leq x) の有効な角度は次のとおりです。 

[
 [0,\alpha]\cup[90^\circ-\alpha,90^\circ]。 
]

 これが重要なステップです。 (45^\circ) 以降は発射体の射程が減少するため、2 番目の間隔が必要です。 

1. 両方の有効な角度間隔を実際のランダム間隔 ([L,R]) と交差させます。 最初の交点の長さは

 [
 \max(0,\min(R,\alpha)-L),
 ]

 2番目の長さは

 [
 \max(0,R-\max(L,90^\circ-\alpha))。 
]

 それらの合計は、着陸座標が最大 (x) である合計角度測定値です。 

1. すべてのカップ ([X_1,X_2]) について、両方のエンドポイントの累積測定値を計算します。 それらの違いはまさに角度の尺度です。 

[
 X_1\leq x(\theta)\leq X_2。 
]

 (R-L) で割って確率を求めます。 

1. (L=R) の場合、正の長さのランダム区間がないため、累積計算をスキップします。 単一の軌道を直接評価します。 着地座標がカップに属している場合は、印刷します`1.0000`; それ以外の場合は印刷します`0.0000`。 

### なぜ効果があるのか

 正の長さの角度間隔の場合、関数 (F(x)) は、着陸座標が最大 (x) である ([L,R]) 内の角度の尺度を正確にカウントします。 2 つの逆サイン分岐は、(2\θ) が (0) と (\pi) の間にあり、サインが最初に増加し、次に減少するため、その不等式を満たすすべての角度を記述します。 したがって、(F(X_1)) ではなく (F(X_2)) によってカウントされる角度は、正確にカップ内に着地する角度です。 打ち出し角度は均一であるため、その角度測定値を角度の合計長さで割ると、必要な確率が得られます。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

PI = math.pi
HALF_PI = math.pi / 2.0

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n, v, L, R = map(int, input().split())

        lrad = math.radians(L)
        rrad = math.radians(R)
        total = rrad - lrad

        v2 = v * v

        if L == R:
            # The angle is fixed, so the result is deterministic.
            landing = (v2 / 10.0) * math.sin(2.0 * lrad)

            for _ in range(n):
                x1, x2 = map(int, input().split())

                # Small tolerance protects exact endpoint cases such as
                # sin(0) and sin(pi/2) from floating-point noise.
                eps = 1e-9 * max(1.0, abs(landing))

                if x1 - eps <= landing <= x2 + eps:
                    out.append("1.0000")
                else:
                    out.append("0.0000")

            continue

        def measure_leq(x):
            """
            Return the angular length inside [lrad, rrad]
            for which the landing coordinate is <= x.
            """
            if x <= 0:
                return 0.0

            # Compare using integers before converting to float.
            # x >= v^2 / 10  <=>  10*x >= v^2
            if 10 * x >= v2:
                return total

            y = (10.0 * x) / v2

            # y is mathematically in (0, 1), but clamp against
            # a possible floating-point overshoot.
            y = max(0.0, min(1.0, y))

            alpha = 0.5 * math.asin(y)

            # First branch: theta <= alpha.
            left = max(0.0, min(rrad, alpha) - lrad)

            # Second branch: theta >= pi/2 - alpha.
            second_start = HALF_PI - alpha
            right = max(0.0, rrad - max(lrad, second_start))

            return left + right

        for _ in range(n):
            x1, x2 = map(int, input().split())

            m1 = measure_leq(x1)
            m2 = measure_leq(x2)

            probability = (m2 - m1) / total

            # Protect the printed value from tiny accumulated
            # floating-point errors such as 1.0000000000000002.
            probability = max(0.0, min(1.0, probability))

            out.append(f"{probability:.4f}")

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```すべてのカップが同じ間隔を使用するため、ソリューションではまずテスト ケースごとに 1 回角度境界を変換します。 整数`v2`(V^2) を正確に格納します。 比較`10 * x >= v2`浮動小数点に変換する前に意図的に実行されるため、重要な最大範囲境界は精度を損なうことなく決定されます。 

の`measure_leq`function は、ウォークスルーの累積関数の実装です。 インテリアコーディネートに、`alpha`は最初の逆正弦分岐を表します。 変数`second_start`(45^\circ) の後の対称分岐を表します。 各ブランチは、次を使用して実際のランダム間隔と交差します。`max`そして`min`、交差がない場合は当然ゼロになります。 

カップ確率は差を利用します`m2 - m1`。 正の長さの連続ランダムな角度間隔の場合、個々の角度の確率はゼロであるため、カップの端点自体が含まれるかどうかを心配する必要はありません。 

固定角度の場合は、累積関数を定義する前に分離されます。 さもないと`total`はゼロになり、確率の式はゼロで除算されます。 その分岐の許容値は、決定論的な浮動小数点軌道と整数カップ境界を比較するためにのみ使用されます。 

Python の任意サイズの整数により、32 ビット実装に存在するオーバーフローの問題も解消されます。 唯一の浮動小数点演算は三角関数の計算と最終確率であり、小数点以下 4 桁まで十分に正確です。

]

 ランダムな角度間隔は (30^\circ) から (45^\circ) で、その長さは (15^\circ) です。

2 番目と 3 番目のカップは、重複または隣接する間隔には全体的な処理が必要ないことを示しています。 それぞれの答えは同じ累積関数から得られます。 最後のカップには着地可能な範囲全体が含まれているため、その確率は正確に 1 です。

import sys
import io
import math

PI = math.pi
HALF_PI = math.pi / 2.0

def solve_text(inp: str) -> str:
    data = io.StringIO(inp)
    input_ = data.readline
    t = int(input_())
    out = []

    for _ in range(t):
        n, v, L, R = map(int, input_().split())

        lrad = math.radians(L)
        rrad = math.radians(R)
        total = rrad - lrad
        v2 = v * v

        if L == R:
            landing = (v2 / 10.0) * math.sin(2.0 * lrad)

            for _ in range(n):
                x1, x2 = map(int, input_().split())
                eps = 1e-9 * max(1.0, abs(landing))

                if x1 - eps <= landing <= x2 + eps:
                    out.append("1.0000")
                else:
                    out.append("0.0000")

            continue

        def measure_leq(x):
            if x <= 0:
                return 0.0

            if 10 * x >= v2:
                return total

            y = (10.0 * x) / v2
            y = max(0.0, min(1.0, y))

            alpha = 0.5 * math.asin(y)

            left = max(0.0, min(rrad, alpha) - lrad)

            second_start = HALF_PI - alpha
            right = max(0.0, rrad - max(lrad, second_start))

            return left + right

        for _ in range(n):
            x1, x2 = map(int, input_().split())

            probability = (
                measure_leq(x2) - measure_leq(x1)
            ) / total

            probability = max(0.0, min(1.0, probability))
            out.append(f"{probability:.4f}")

    return "\n".join(out)

    return solve_text(inp)

 ## 特殊なケース

 (L=R) の場合、ランダムな角度間隔の幅はゼロになるため、通常の確率公式では (R-L) で割ることができません。 のために```
1
1 10 45 45
9 10
```アルゴリズムは単一の着地位置 (10) を計算し、それを確認して (9\leq10\leq10)、出力します。`1.0000`。 もしそのカップが`[0,9]`、同じ決定論的な計算では次のようになります。`0.0000`。 

カップが可能な最大範囲を超えて伸びると、累積関数はすぐに上端点の角度測定値全体を返します。 のために```
1
1 10 0 90
11 20
```最大範囲は (10) であるため、カップの両端点はそれを超えています。 2 つの累積測定値の差はゼロであり、次のようになります。`0.0000`。 

カップが到達可能な範囲全体を含む場合、すべての打ち出し角度が有効になります。 のために```
1
1 10 0 90
0 10
```下限のエンドポイントはゼロの累積測定値に寄与し、上限のエンドポイントはすべて (90^\circ) に寄与します。 それらの差は完全なランダムな間隔であるため、答えは次のようになります。`1.0000`。 

非単調な発射範囲は、2 つの角度間隔をカウントすることによって処理されます。 (V=10)、(L=0)、(R=90)、カップ付き`[0,5]`、条件 (x\leq5) は (\sin(2\theta)\leq0.5) と同等です。 これは (\theta\in[0,15^\circ]) と (\theta\in[75^\circ,90^\circ]) で発生し、(90^\circ) のうち有効な角度は (30^\circ) になります。`0.3333`。 最初の逆正弦分岐のみを使用する実装では (15^\circ) のみがカウントされ、誤った値が返されます。`0.1667`。 

(x=0) の場合、可能な角度は (0^\circ) と (90^\circ) のみです。 (L<R) の場合、これらは孤立点であり、確率はゼロです。 したがって```
1
2 10 0 90
0 1
1 10
```生成する`0.0000`最初の一杯と、`1.0000`2番目に。 これは累積計算で自然に処理されます。`measure_leq(0)`その間、ゼロを返します`measure_leq(10)`全角度の測定値を返します。 

それぞれの確率が独自の間隔を求めるため、重なり合うカップには特別な処理は必要ありません。 サンプルでは、`[16,21]`、`[21,22]`、 そして`[22,30]`エンドポイントを共有しますが、各答えは 2 つの累積値から独立して計算されます。 地面を分割したり、着地点を 1 つのカップだけに割り当てたりすることはありません。
