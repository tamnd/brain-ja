 ## 問題の理解

 各生徒の試験用紙は整数としてエンコードされます。 その整数のバイナリ表現は、学生の回答を記録します。`1`つまり、その質問に対する答えは正しく、`0`それは間違っていたという意味です。 タスクは、すべての生徒の正解の数を決定することです。したがって、各値について`A_i`の数が必要です`1`バイナリ表現のビット。 

例えば、`5`は`101`バイナリなので 2 つが含まれます`1`ビットと対応する生徒が受け取ります`2`マーク。 同様に、`8`は`1000`、したがって、その答えは次のとおりです`1`。 

1 つのテスト ケースで到達できる生徒の数は、`10^5`、それぞれのエンコードされた紙の大きさは次のとおりです。`10^9`。 以来`10^9 < 2^30`、すべての数値には最大 30 個の関連する 2 進ビットが含まれます。 ビットごとに一定量の作業を実行するアプローチは、すでに事実上線形です。`N`、最大で約 300 万ビットの演算を実行するためです。`10^5`学生たち。 すべての生徒のペアを比較するアプローチには、約`10^10`比較するとすぐに不適切になります。 入力には複数のテスト ケースが含まれているため、ビットを明示的にシミュレートするよりも、Python の整数ビット演算を直接使用することをお勧めします。 

実装が失敗する可能性のある小さなケースがいくつかあります。 有効な最小の用紙は次のとおりです。`1`、そのバイナリ形式は次のとおりです`1`、したがって、答えは次のとおりです`1`。 誤って位置からビットのチェックを開始する実装`1`立場の代わりに`0`誤ってゼロが生成されてしまいます。 

もう 1 つの境界ケースは 2 の累乗です。 たとえば、入力```
1
4
1 2 4 8
```生産しなければならない```
1 1 1 1
```2 の累乗ごとに 1 つのセット ビットが存在します。 バイナリ表現ではなく数値の大きさからマークの数を推測しようとするコードは、これを簡単に間違える可能性があります。 

逆の場合は、複数のビットが設定された数値です。 のために```
1
1
7
```出力は```
3
```なぜなら`7 = 111₂`。 よくある間違いは、2 進数の桁数ではなく、2 進数の桁数を数えることです。`1`数字、これも偶然にも機能します`7`しかし、次のような値の場合は失敗します`8`、正解は次のとおりです。`1`一方、バイナリの長さは`4`。 

最後に、上限が重要です。`10^9`は特別なバイナリ値ではありません。 その答えは、通常のバイナリ表現における設定ビット数であり、Python 整数はオーバーフローすることなくこの値を直接処理します。 

## アプローチ

 直接的なアプローチは、すべての生徒の番号の 2 進数表現を調べ、その数をカウントすることです。`1`ビット。 文字列を構築せずにこれを行う 1 つの方法は、次のようにして最下位ビットを繰り返し検査することです。`x & 1`、それを答えに追加し、シフトします`x`一つ右の位置にあります。 この方法は正しいです。反復ごとに 2 進数が 1 つだけ削除され、元の 2 進数もすべて削除されます。`1`カウントに 1 回だけ寄与します。 

以来、`A_i`せいぜい`10^9`、1 つの数値に対して最大 30 回の反復が必要です。 のために`N = 10^5`、つまり、せいぜい約`3 × 10^6`1 つのテスト ケースのビット検査。 これは漸近的に悪いことではありませんが、Python では組み込みの整数演算を使用して同じ演算をより効率的に実行できます。`int.bit_count()`、最適化されたネイティブ コードでポップカウントを実行します。 

重要な観察は、必要なマークが正確に整数の母集団数であるということです。 学生同士のやり取りはなく、質問自体を再構成する必要もありません。 それぞれ`A_i`独立して処理でき、`A_i.bit_count()`設定されたビット数をバイナリ表現で直接返します。 

このブルート フォース手法は、ビット数が制限されているため機能しますが、それでもすべての数値のすべてのビットに対して Python でループを実行します。 答えが正確に整数のポップカウントであるという観察により、生徒ごとの作業を 1 つの最適化された操作に減らすことができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N log A) | O(1) 補助 | 受け入れられますが、不要な Python レベルのループです。 
| 最適 | ビット複雑さは O(N log A)、整数あたりのネイティブ ポップカウント | 格納された入力/出力の場合は O(N) | 承認済み |

 ここ`A`は、エンコードされた用紙の最大値を示します。 と`A ≤ 10^9`、`log A`最適バージョンの実際的な利点は、ビットカウント自体が明示的な Python ループではなく Python の整数機構によって実装されることです。 

## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各テスト ケースを個別に処理します。 各生徒の結果は、その生徒のエンコードされた論文にのみ依存するため、テスト ケース間で共有する必要がある状態はありません。 
2. を読んでください。`N`試験問題を配列にエンコードします。 値自体は、マークを計算するために必要な完全な情報です。

4. 結果のカウントを、入力に表示される生徒と同じ順序で保存します。 出力は位置ごとに入力配列に対応するため、この順序を維持することが必要です。

### なぜ効果があるのか

 任意の正の整数の場合`x`、そのバイナリ表現には、整数で表される質問ごとに 1 つのバイナリ数字が含まれます。 正解は、`1`, したがって、生徒の点数はちょうど の数になります。`1`数字。 パイソンの`x.bit_count()`正確にその量を返します。 操作はすべてに独立して適用されるため、`A_i`、すべての出力値は対応する生徒の正しいマークであり、入力順序を保持すると、必要な生徒の順序が保持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        ans = [x.bit_count() for x in a]
        print(*ans)

if __name__ == "__main__":
    solve()
```の最初の行`solve`テストケースの数を読み取ります。 次に、外側のループは各検査の処理を分離します。 

テストケースごとに、`map(int, input().split())`エンコードされた論文を Python 整数に変換します。 リスト内包表記が適用されます`bit_count()`すべての値に対して独立して、まったく同じ順序でマークを生成します。 

2 のべき乗、多くのビットが設定された数値、または上限を特別に処理する必要はありません。`10^9`。 Python の任意精度の整数は、整数のオーバーフローの問題がないことも意味します。 

このコードは、入力が指定された形式に従っていることを前提としています。`N`テスト ケースの値は次の行にあります。 与えられた問題に対してはこれで十分です。 出力は次のように生成されます。`print(*ans)`、回答の間にスペースが挿入され、行が正しく終了します。

## テストケース```python
import sys
import io

def solve():
    input = sys.stdin.readline
    t = int(input())

    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        out.append(" ".join(str(x.bit_count()) for x in a))

    sys.stdout.write("\n".join(out))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

# Provided sample
assert run(
    """2
5
1 2 3 4 5
4
2 4 8 16
"""
) == """1 1 2 1 2
1 1 1 1
""", "sample 1"

# Minimum-size case
assert run(
    """1
1
1
"""
) == """1
""", "minimum-size input"

# All values equal
assert run(
    """1
5

"""
) == """4 4 4 4 4
""", "all-equal values"

""", "boundary values"

assert run(inp) == expected, "maximum-size input"
