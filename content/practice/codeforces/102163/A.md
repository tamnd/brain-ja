# アプローチ

 直接的なアプローチでは、すべての水平セグメントをすべての垂直セグメントとともに考慮します。 各ペアについて、x 座標と y 座標が対応する間隔内にあるかどうかをテストします。 交差する場合は、4 つの腕の長さを計算し、答えを更新します。 これは正しいです。考えられるすべてのプラス記号は、正確に 1 つの水平セグメントと 1 つの垂直セグメントによって決定されるため、すべてのペアを調べても最適値を見逃すことはありません。

重要な観察は、答えを直接構築するのではなくテストできるということです。 少なくとも長さのプラス記号があるかどうかを尋ねるとします。`d`存在します。 水平セグメントの場合`[x1, x2]`、交差の x 座標は次の条件を満たす必要があります。`x1 + d <= x <= x2 - d`。 

したがって、水平セグメントは、短縮された間隔を通じてのみ参加できます。`[x1 + d, x2 - d]`の場合にのみ使用できます。`x2 - x1 >= 2d`。 

同様に、垂直セグメント`[y1, y2]`の場合にのみ参加できます`y1 + d <= y <= y2 - d`。 

したがって、修正の問題は`d`これは、縮小された x 間隔に使用可能な垂直セグメントの x 座標が含まれ、水平セグメントの y 座標がその垂直セグメントの縮小された y 間隔の内側にある水平セグメントを見つけることになります。 

これは、左から右にスイープすることで処理できます。 垂直セグメントを x で並べ替えます。 x で垂直セグメントに到達すると、縮小された左端点が最大でも x であるすべての水平セグメントがアクティブになります。 水平セグメントは、縮小された右端点が x より小さくなるまでアクティブのままです。 

残る唯一の問題は、アクティブな水平セグメントの y 座標が垂直セグメントの短縮された y 間隔内にあるかどうかを確認する方法です。 各アクティブな水平線はその y 座標で 1 つの点に寄与するため、フェンウィック ツリーは各 y にいくつのアクティブな水平線が存在するかを維持できます。 範囲の合計により、少なくとも 1 つのアクティブな水平線が必要な y 間隔内にあるかどうかがわかります。 

述語は単調です。 長さのプラス記号の場合`d`存在する場合、より小さい長さごとにプラス記号も存在します。 したがって、実現可能な最大値を二分探索で求めることができます。`d`。 

すべての候補が明示的に検査されるため、総当り攻撃は機能しますが、ペアが多すぎるため失敗します。 固定された答えがすべてのセグメントを個別に削減するという観察により、2 次元の交差問題をフェンウィック ツリーを使用した 1 次元のスイープに変えることができます。

### なぜ効果があるのか

 固定の場合`d`、水平セグメントはスイープ内で正確に表現されますが、その x 座標は両方の水平アームが少なくとも長さになるように選択できます。`d`。 したがって、アクティブな水平セグメントは次の条件と同等です。`x1 + d <= x <= x2 - d`。
