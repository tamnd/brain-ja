 ## 解決策
 ## 問題の理解

 2 つの整数配列が与えられています。`a`そして`b`、長さの`n`、固定整数とともに`v`。 2 種類のクエリを処理するように求められます。 最初のタイプは、次の単一要素を更新します。`b`。 2 番目のタイプは、すべての連続するサブ配列の中で最小限の「美しさ」を要求します。`[l_0, r_0]`与えられた範囲内で`[l, r]`のすべての要素のビット単位の OR が得られるように、`b`その部分配列には少なくとも`v`。 部分配列の「美しさ」は、対応する部分配列内の最大の要素です。`a`。 OR 条件を満たすサブ配列がない場合は、戻り値が返されます。`-1`。 

重要な課題は、`n`そして`q`それぞれ最大 2×10^5 に達する可能性があり、すべてのテスト ケースの合計も 2×10^5 に制限されます。 クエリごとにすべての部分配列を列挙する単純なアプローチでは、クエリごとに O(n^2) の操作が実行されますが、これは明らかに実行不可能です。 更新またはクエリごとに対数演算または償却演算を使用して、テスト ケースごとに O(n log n) に近いか、それ以上のアプローチが必要です。 

明白でないエッジケースには、単一の要素が満たされない区間が含まれます。`b[i] >= v`しかし、組み合わせは可能です。 例えば、`b = [1, 2, 4]`と`v = 7`単一要素の良好な間隔はありませんが、`[1,3]`満足する`1|2|4 = 7`。 不注意な解決策では、間隔ではなく個々の要素のみをチェックする可能性があり、`-1`間違っています。 同様に、次の更新も`b`複数の適切な間隔を作成または破棄する可能性があるため、前処理は動的更新をサポートする必要があります。 

## アプローチ

 ブルートフォース手法はすべてのサブ配列に対して反復されます。`[l_0, r_0]`内部`[l, r]`タイプ 2 クエリの場合、対応するクエリの OR を計算します。`b`セグメントを作成し、最大値を追跡します`a`。 各タイプ 2 クエリでは、O(n^2) OR および最大の計算が必要になる場合があります。 最大 2×10^5 のクエリと最大 2×10^5 の n では、これは完全に実行不可能です。 すべてを再計算しない限り前処理は無効になるため、タイプ 1 クエリの更新は役に立ちません。 

重要な洞察は、OR 演算が単調であるということです。間隔を右に拡張しても OR は決して減少しません。 これにより、2 ポインタ アプローチが可能になります。 それぞれの時点から最小間隔を維持できます。`l`OR が到達するのは`v`右ポインタを進めると`r`OR がそれを超えるまで`v`。 OR 条件を満たす間隔がわかったら、必要なのは最大値のみです。`a[i]`その間隔にわたって。 複数のクエリを効率的に処理するために、前処理を行うことができます。`a`範囲最大クエリ用のセグメント ツリーまたはスパース テーブルに変換し、維持します。`b`効率的なインクリメンタル OR 計算をサポートする構造になっています。 

最終的な戦略は、これらの洞察を組み合わせたものです。クエリごとに、2 ポインター法を使用して、クエリ内のすべての開始位置に対する最小の正しいエンドポイントを見つけます。`[l, r]`、セグメント ツリーに最大値を問い合わせます。`a[i]`それらの間隔を超えて。 への更新`b`今後のクエリのために OR 計算を更新するだけで済みます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(n^2) | O(n) | 遅すぎる |
 | ツーポインタ + セグメント ツリー | テスト ケースごとに O(n log n + q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. セグメントツリーを構築します。`a`範囲最大クエリをサポートします。 これにより、任意の区間の美しさをすばやく計算できます。 
2. 各タイプ 2 クエリについて`[l, r]`、右ポインタを初期化します`r_ptr = l`そして`current_or = 0`。 このポインタは、OR が満たすか超える最小間隔を見つけるために拡張されます。`v`。 
3. 可能な左側のエンドポイントを反復処理します。`l`に`r`。 左側の端点ごとに、次へ進みます。`r_ptr`その間`current_or | b[r_ptr] < v`。 OR が単調であるため、各拡張は正当化されます。 私たちは延長するだけです`r_ptr`OR条件が満たされるまで。 
4. もし`r_ptr > r`、現在の左端点から始まる適切な間隔がないため、次の左端点まで続行します。 
5. それ以外の場合は、セグメント ツリーにクエリを実行します。`max(a[l], ..., a[r_ptr])`そして、左側のすべてのエンドポイントの中で最小の美しさを追跡します。 
6. タイプ 1 クエリの場合、次の値を更新します。`b[i]`。 これは、将来の OR 計算に影響を与える可能性があります。 セグメントツリーを更新する必要はありません。`b`2 ポインターの計算でのみ使用されるためです。 
7. タイプ 2 クエリで見つかった最小の美しさを出力する、または`-1`OR 条件を満たす間隔がなかった場合。 

なぜ機能するのか: OR の単調性により、確実に前進します。`r_ptr`指定された左端点から最小の満足区間を見つけます。 セグメント ツリーにより、最大値を効率的に計算できることが保証されます。`a`任意の間隔にわたって。 考慮されたすべての間隔が有効であり、最小の美しさを追跡するため、ソリューションは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegmentTree:
    def __init__(self, data):
        n = len(data)
        self.N = 1
        while self.N < n:
            self.N *= 2
        self.tree = [0] * (2 * self.N)
        for i in range(n):
            self.tree[self.N + i] = data[i]
        for i in range(self.N - 1, 0, -1):
            self.tree[i] = max(self.tree[2*i], self.tree[2*i + 1])
    def update(self, i, val):
        i += self.N
        self.tree[i] = val
        while i > 1:
            i //= 2
            self.tree[i] = max(self.tree[2*i], self.tree[2*i + 1])
    def query(self, l, r):
        l += self.N
        r += self.N
        res = 0
        while l <= r:
            if l % 2 == 1:
                res = max(res, self.tree[l])
                l += 1
            if r % 2 == 0:
                res = max(res, self.tree[r])
                r -= 1
            l //= 2
            r //= 2
        return res

t = int(input())
for _ in range(t):
    n, v = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    seg = SegmentTree(a)
    q = int(input())
    res = []
    for _ in range(q):
        parts = input().split()
        if parts[0] == '1':
            i, x = int(parts[1])-1, int(parts[2])
            b[i] = x
        else:
            l, r = int(parts[1])-1, int(parts[2])-1
            ans = float('inf')
            r_ptr = l
            current_or = 0
            for left in range(l, r+1):
                if r_ptr < left:
                    r_ptr = left
                    current_or = 0
                while r_ptr <= r and (current_or | b[r_ptr]) < v:
                    current_or |= b[r_ptr]
                    r_ptr += 1
                if r_ptr > r:
                    continue
                max_a = seg.query(left, r_ptr)
                ans = min(ans, max_a)
                current_or &= ~b[left]
            res.append(str(ans if ans != float('inf') else -1))
    print(' '.join(res))
```セグメント ツリーは、一定時間範囲の最大クエリに使用されます。 左側の端点ごとに、`r_ptr`OR 要件を満たす最小間隔を維持するために、段階的に移動されます。 間隔を処理した後、`b[left]`から`current_or`次の左の終点に向けて準備します。 Python での off-by-one インデックス (0 ベース) と問題 (1 ベース) の管理には細心の注意が必要です。 への更新`b`即時に反映され、後続のクエリに正しく影響を与えます。 

## 実用的な例

 **例 1:**`a = [2,1,3]`、`b = [2,5,3]`、`v = 7`、クエリ`[2,3]`。 
| 左 | r_ptr | 現在または | max(a[left..r_ptr]) | と |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 2 | - | - |
 | 2 | 3 | 5 | 3 | 3 |
 2つのポインタはそれを識別します`[2,3]`が唯一の適切な間隔です。 最大値`a[2..3]`は 3 で、これが正解です。
