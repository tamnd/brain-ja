 ## 問題の理解

 整数の配列が与えられると、配列のコピー全体のクローンを作成するか、任意の 2 つのコピー間で要素を交換するという 2 種類の操作を実行できます。 私たちの目標は、最小限の操作を使用して、すべての要素が同一である配列を少なくとも 1 つ作成することです。 各テスト ケースでは新しい配列が提供され、すべてのテスト ケースの配列サイズの合計には制限があるため、テスト ケースごとの配列サイズに線形にスケールするアルゴリズムを設計する必要があります。 

重要な点は、最も効率的な戦略は、配列内で最も頻繁に出現する要素に焦点を当てることです。これは、配列の残りの部分をこの値で埋めるために必要なスワップが最も少ないためです。 すべての要素がすでに等しい場合、操作は必要ありません。 それ以外の場合は、配列全体のコピーを支配するまで最も頻繁に使用される要素を増幅するために、クローン作成とスワッピングのステップの最小限のシーケンスを決定する必要があります。 

エッジ ケースには、単一の要素を持つ配列、すべての要素が等しい配列、およびすべての要素が異なる配列が含まれます。 たとえば、配列`[1]`必要`0`操作、`[1, 1, 1]`も必要です`0`操作、および`[1, 2, 3, 4]`より慎重なクローン作成と交換が必要になります。 

制約は、以下よりも悪い解決策が存在することを意味します。`O(n)`テストケースごとに実行すると遅すぎます。`n`到達できる`10^5`。 すべての操作シーケンスをブルートフォースで調査することは不可能です。 

## アプローチ

重要な洞察は、最も頻繁に使用される要素のみに焦点を当てる必要があることに気づくことから生まれます。`x`。 何回数えられるか`x`最初に発生する場合は、これを呼び出します`freq`。 その後、次の内容を含む配列を繰り返しクローンできます。`x`そして交換する`x`これらのコピーの値を別のコピーにコピーします。 クローンを作成するたびに、`x`移動することができ、交換するたびにカウントが増加します。`x`ターゲット配列内。 問題は、伝播するクローン作成とスワッピングのステップの最小数を見つけることに帰着します。`x`ターゲットアレイがいっぱいになるまで`x`。

 ## アルゴリズムのチュートリアル

 1. 配列内の各要素の頻度を数えます。 要素を特定する`x`最も高い頻度で`freq`。 必要な操作が少なくなるため、これが最終的な配列を埋めることを目的とした要素です。 
2. 2 つのカウンターを初期化します。`current`に等しい`freq`の数を表す`x`作業配列内にある、そして`operations`に等しい`0`操作全体を追跡します。 
3. その間`current`未満です`n`、一連の操作を実行します。 各ラウンドで、次の内容を含む作業配列のクローンを作成します。`current`のコピー`x`。 インクリメント`operations`による`1`クローンのために。 
4. このラウンドで必要なスワップの数を計算します。 私たちができる最大限のことは、`current`スワップ（それぞれ`x`クローン化されたアレイ内の要素はターゲット アレイにスワップできます)。 これらの交換後、`x`ターゲット配列内の s は 2 倍になるか、`n`オーバーシュートしてしまうと。 インクリメント`operations`実行されたスワップの数によって異なります。 
5.アップデート`current`新しいカウントに`x`ターゲット配列内の s。 まで繰り返します`current >= n`。 
6. 戻る`operations`最小限の移動数として。 

機能する理由: 各ラウンドで利用可能な最大値が最適に使用されます。`x`ターゲット配列に伝播します。 プールを増やすにはクローン作成が必要です`x`■ ターゲット配列を破壊することなく。 スワップはそれぞれについて正確にカウントされます`x`挿入されました。 ループの不変条件は、各反復後に次のようになります。`current`の数に等しい`x`s in the target array, and this number grows exponentially with each clone-and-swap round, guaranteeing minimal steps.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = max(Counter(a).values())
        if freq == n:
            print(0)
            continue
        operations = 0
        current = freq
        while current < n:
            clone_ops = 1
            swaps = min(current, n - current)
            operations += clone_ops + swaps
            current += swaps
        print(operations)

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して複数のテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 の`Counter`各要素の出現をカウントして、最も頻度の高い値を見つけます。 の`while`ループは倍加戦略を実装します。各反復はクローン作成とスワッピングを表します。 の`min(current, n - current)`スワップ時に配列サイズをオーバーシュートしないようにします。 Off-by-one エラーはインクリメントすることで回避されます。`current`各スワップラウンドの後。
