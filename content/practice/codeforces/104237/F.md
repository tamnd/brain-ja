 ## 解決策
 ## 問題の理解

 木の高さの目標配置が与えられます。ここで、高さは繰り返しのない 1 から N までの整数です。 配列`a`ラリーは、木々を位置ごとに線に沿って表示する方法を説明します。 ハリーは同じ高さのマルチセットを配置する必要があります。これも正確に 1 から N までの数字ですが、任意の順列で配置します。`b`。 

ラリーの不満は、すべての位置を調べ、配置された高さが希望の高さからどれだけずれているかを計算し、すべての位置にわたるこれらの偏差の最小値を取ることによって決定されます。 つまり、一つでも意図した高さに近い位置であればラリーの怒りは小さく、ハリーはそれを避けたいのです。 目標は、最も近い一致でもできるだけ遠くなるように数値を並べ替えることです。 

出力は 2 つあります。 まず、この最小絶対差の可能な最大値を報告する必要があります。 次に、順列を構築する必要があります。`b`この値を達成するものです。 

最大 100000 までの制約 N は、すべての順列、または候補配置ごとの二次関数を評価しようとする解法を即座に除外します。 完全な順列空間は階乗であり、配置ごとに 1 つの順列をチェックするだけでもすでに大きすぎます。 最大でも O(N log N) または O(N) の構造が必要です。 

微妙な点は、答えはポジションごとのローカルな貪欲な決定ではなく、グローバル構造に依存するということです。 「各位置で利用可能な最も遠い番号を一致させる」などの単純な貪欲な割り当ては失敗する可能性があります。これは、初期の選択により、後で避けられない近い一致が作成される可能性があるためです。 

もう 1 つの失敗例は、対称性を仮定したり、配列を反転したりすることによって発生します。 たとえば、後退しても、大きな最小距離は保証されません。 もし`a = [1, 100, 2, 99]`、逆転すると与えられます`[99, 2, 100, 1]`、位置 2 は非常に近くなり、他の場所では大きなグローバルな分離にもかかわらず、小さな最小距離が生成されます。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列が試行されます。`b`、の最小値を計算します。`|a[i] - b[i]|`を選択し、最良の結果を追跡します。 これは、目的の定義を直接評価するため、正しいです。 しかし、Nがある！ 順列を計算し、それぞれのスコアを計算するには O(N) が必要で、O(N・N!) 回の演算が行われますが、これは N が 10 程度の小さい場合でも完全に実行不可能です。 

改善するには、何が最小距離を小さくするのかを理解する必要があります。 最小値は「最悪の一致」位置によって決定されます。これは、次のような単一の位置を意味します。`b[i]`近くにあります`a[i]`。 この最小値を最大化するには、値が近いペアリングを避けたいと考えます。 

これは、順列に関する古典的な「固定近接マッチングを避ける」問題になります。 両方なので`a`そして`b`は 1 から N までの順列であるため、任意の値ではなくランクの観点から考えることができます。 重要な観察は、ポジションをその順位に従って並べ替えると、`a[i]`値を指定する場合、同様のランクの整列を避ける方法で、これらの位置に 1 から N までの値を割り当てるとして問題を扱うことができます。 

最適な構成は、範囲を 2 つの半分に分割し、それらを交換することで得られます。 小さな値を大きな位置にマッピングし、大きな値を小さな位置にマッピングすると、分離が最大化されます。 より正確に言うと、インデックスを次のように並べ替えると、`a[i]`、次に利用可能な最小の数値を最大の数値に割り当てます。`a[i]`値の逆も同様で、すべてのペアを強制します`(a[i], b[i])`ランク空間で大きく離れていること。 これにより、どの位置にも最適なしきい値を下回る小さな絶対差が存在することがなくなります。 

残りのタスクは、正確な達成可能なしきい値を決定することです。 私たちが保証できる最善のことは、すべての値が範囲の少なくともおよそ半分だけ置き換えられることです。これは、並べ替え順序とその逆割り当てを組み合わせることで実現できます。

 ## アルゴリズムのチュートリアル

 問題の構造は、次の相対的な順序にのみ依存することを認識することから始めます。`a[i]`、したがってインデックスを並べ替えます`a[i]`分離を強制する制御された方法を提供します。 

1. インデックスの並べ替え`i`の値の増加に基づいて`a[i]`。 これにより、問題は生の値ではなくランクに基づいて処理されるようになります。 最小の`a[i]`が最初に処理され、最大のものが最後に処理されます。 
2. アレイを準備する`b`最終的な順列が保存されます。 また、1 から N までの値のリストも用意し、一度だけ割り当てます。 
3. ミラーリング方式で値を割り当てます: 最小値`a[i]`位置は利用可能な最大値を受け取り、最大値は`a[i]`位置は利用可能な最小値を受け取ります。 具体的には、インデックスをソートした後、`b[sorted[i]] = i+1`逆の順序で。 

この逆転が核となるアイデアです。 これにより、高い目標位置が低い実際の値を強制的に取得されるようになり、その逆も同様になります。 

1.施工後`b`、の最小値を計算します。`|a[i] - b[i]|`すべてのポジションにわたって。 これは簡単な検証であり、達成された怒りレベルを確認します。 

この割り当てが最適である理由は、どの順列でもソートされたデータの「中間バンド」内に何らかの値を配置する必要があるという事実から来ています。`a`価値観。 私たちにできる最善のことは、ランク空間の最小距離を最大化することであり、すべてのペアを可能な限り均等に分散させる唯一の配置は反転です。 完全な逆転からの逸脱により、少なくとも 1 つのより近いペアが導入され、最小の差が減少します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

idx = list(range(n))
idx.sort(key=lambda i: a[i])

b = [0] * n

for i, pos in enumerate(idx):
    b[pos] = n - i

ans = min(abs(a[i] - b[i]) for i in range(n))

print(ans)
print(*b)
```ソリューションはまず順列を読み取ります。`a`。 インデックス配列を構築し、次の値で並べ替えます。`a`。 これにより、値自体の移動が回避され、ポジションがそのまま維持されます。 構築ループは、使用可能な最大値を最小値に割り当てます。`a[i]`順位は、ソートされたリストを移動するにつれて着実に減少します。 

最終スキャンでは最小絶対差が直接計算されますが、構造によって正確性が保証されており、必要なのは検証パスだけであるため安全です。 

微妙な点は、`n - i`の代わりに`i + 1`。 ソート順と完全に逆である限り、どちらの方向でも機能します。 重要な要件は単調反転であり、特定のラベル付けではありません。

 ## 特殊なケース

 のために`N = 1`、唯一の順列は自明です。 アルゴリズムは次のように割り当てます。`b = [1]`、最小絶対差は次のようになります。`|1 - 1| = 0`、代替が存在しないため、これは最適な値と一致します。 

厳密に増やすために`a = [1, 2, 3, 4]`、ソートされたインデックスはすでに自然な順序になっています。 アルゴリズムは次のように割り当てます。`b = [4, 3, 2, 1]`、最小の差を生成します`1`。 完全な反転から逸脱すると、値が元のランクに近すぎる位置が発生するため、反転の必要性が確認されます。 

厳密に減少させる場合`a = [N, N-1, ..., 1]`、ソートされたインデックスは順序を反転しますが、代入により完全に増加する値が生成されます。`b`。 これは、アルゴリズムが入力順序に関して対称であり、元のレイアウトではなくランク順序のみに依存することを示しています。
