 ## 解決策
 ## 問題の理解

 平面上に配置された無限の直線の集合が与えられます。 各線は、固定の x 座標で大通りを表す垂直線か、固定の y 座標で道路を表す水平線のいずれかです。 すべての垂直線はすべての水平線と 1 回だけ交差し、そのような交差はそれぞれ交差点としてカウントされます。 

タスクは、指定されたすべての線の中にそのような交点がいくつ存在するかを計算することです。 

入力サイズは最大 1000 行です。 これは、線のすべてのペアをチェックするソリューションは最大でも約 10^6 の演算を実行するため、二次アプローチが受け入れられることを直ちに示唆しており、これは Python の制限内に十分収まります。 

ここではいくつかの特殊なケースが重要です。 すべての線が垂直の場合、交差する水平線はないため、答えはゼロになります。 すべての線が水平であれば、同じことが対称的に当てはまります。 もう 1 つの微妙なケースは、垂直線または水平線が 1 本だけの場合です。 その状況では、答えは反対側のグループのサイズに等しく、同じタイプのラインをペアにしようとする誤った実装により、誤って余分なカウントが生成されてしまいます。 

単純ですがよくある間違いは、すべてのラインのペアを比較し、座標が異なる場合に増分することで交差を数えることです。これは問題の幾何学とは論理的に無関係です。 交差は垂線間でのみ発生し、任意のペア間では発生しません。 

## アプローチ

 強引なアイデアは、すべての線のペアを検討し、それらが交差するかどうかを確認することです。 ただし、ほとんどのペアは無関係です。2 本の垂直線が互いに交差することはなく、2 本の水平線が互いに交差することもありません。 意味のある相互作用は、垂直線と水平線の間のみです。 

入力を垂直線と水平線の 2 つのグループに分けると、問題は大幅に単純化されます。 x = a のすべての垂直線は、y = b のすべての水平線と 1 回だけ交差します。 つまり、各ペアは 1 つの交差に寄与します。 

したがって、N 行のすべてのペアをチェックする代わりに、垂直方向の線数と水平方向の線数を数えるだけで済みます。 最終的な答えは彼らの製品です。 

ブルートフォースアプローチでも、行とチェックタイプのすべてのペアを反復処理するため、O(N²) チェックが発生します。 最適化されたバージョンでは、問題は O(N) で周波数を数えることに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N²) | お(1) | 遅すぎるが不要 |
 | 最適 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 幾何学的問題を 2 つのカテゴリの線を数える問題に変換します。 

1. ライン数 N を読み取り、垂直ライン用と水平ライン用の 2 つのカウンターを初期化します。 交差はカテゴリ間でのみ発生するため、この分離は不可欠です。 
2. 各行について、そのタイプを読み取ります。 垂直の場合は、垂直カウンタをインクリメントします。 水平の場合は、水平カウンタをインクリメントします。 垂直線は位置に関係なくすべての水平線と交差するため、実際の座標値は無関係です。 
3. すべてのラインを処理した後、vertical_count とhorizo​​ntal_count の積として交差の数を計算します。 これは、各垂直線が各水平線と交差するという事実から直接得られます。 
4. 結果を出力します。 

### なぜ効果があるのか

各垂直線は固定の x 座標によって定義され、両方向に無限に伸びます。 各水平線は固定の y 座標によって定義されます。 1 本の垂直線と 1 本の水平線で構成される選択されたペアについては、単一の点 (x, y) を定義するため、それらの交差は保証され、一意になります。 重複する線がないため、そのようなペアはすべて 1 つの交差に寄与し、他のタイプのペアは何も寄与しません。 これにより、交点と垂直線と水平線の順序付きペアとの間に 1 対 1 の対応関係が確立されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    v = 0
    h = 0
    
    for _ in range(n):
        t, x = input().split()
        if t == 'v':
            v += 1
        else:
            h += 1
    
    print(v * h)

if __name__ == "__main__":
    solve()
```このソリューションは、入力を 1 回スキャンする間、2 つの単純なカウンターを維持します。 座標値は読み取られますが、交差点が存在するかどうかには影響しないため、意図的に無視されます。 方向性のみが重要です。 

最後の乗算は、2 つのラインセット間のデカルト積をエンコードします。 実装でよくある間違いは、座標を保存して等しいか近接しているかをチェックしようとすることですが、これは不必要であり、ロジックを誤って複雑にしてしまいます。
