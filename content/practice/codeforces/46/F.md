 **解決時間:** 1分1秒

 ## 解決策
 ## 問題の理解

 私たちは、ドアでつながった一定数の部屋のある家を与えられ、各ドアには固有の鍵が付いています。 家には数人の住人がいて、最初はそれぞれがいくつかの鍵を持った部屋にいます。 また、すべての居住者の役職や主要な所有物も後でわかります。 問題は、鍵を使ってドアを開ける、開いたドアを通して部屋間を移動する、同じ部屋の他の居住者と鍵を交換するという一連の法的行為を通じて、最初の構成から 2 番目の構成に到達することが可能かどうかです。 「はい」の場合は、「YES」と出力します。 それ以外の場合は「いいえ」。 

家はグラフとしてモデル化できます。部屋はノード、ドアはエッジです。 居住者は、所有する鍵または他の人から取得した鍵によってエッジのロックが解除されると、エッジに沿って移動します。 各ドアには、住民のどこかに必ず 1 つの鍵があります。 どのドアも何度でも開け閉めでき、同じ部屋にいる住人は鍵を共有できます。 この問題は、これらのキー共有制約の下で、各居住者の最初の部屋から最終的な部屋に到達できるかどうかを実質的に問うものです。 

制約は小さいです。$n, m, k \le 1000$。 各居住者に対して可能なすべての動きを試す総当たりシミュレーションでは、一連の動きの数が指数関数的に増加するため、時間がかかりすぎます。 ただし、この制約により、最大 1000 個のノードおよびエッジにわたる BFS または DFS などのグラフ トラバーサル メソッドが許可されます。 エッジケースには、同じ接続されたコンポーネント内に誰も鍵を持っていないためにドアが最初に隔離されている状況、またはすべての居住者が 1 つの部屋にいるが、最終的には切り離された部屋に移動する必要がある状況が含まれます。これは、自由な移動を想定した単純なアプローチでは失敗します。 

不注意な実装が失敗する例としては、2 つの部屋がドアでつながっており、各部屋に 1 人がいて、ドアの鍵を反対側の部屋の人が持っている場合があります。 「全員が他の全員に連絡できる」という単純なロジックでは誤って「YES」となりますが、会議や鍵の交換のためにドアのロックを開ける人は誰もいないため、正解は「NO」です。 

## アプローチ

 ブルートフォース ソリューションでは、ドアの開閉、居住者の動き、鍵の交換といった考えられるあらゆるシーケンスをシミュレートしようとします。 時間ステップごとに、各居住者を反復処理し、彼らが開けることができるすべてのドアを通過することを検討します。 これにより正しい答えが得られますが、可能性の数は天文学的であり、簡単に超えます。$2^{1000}$最悪の場合シーケンスが発生するため、実用的ではありません。 

重要な洞察は、コンポーネント内の居住者が利用できるキーを介してアクセスできる部屋の接続された各コンポーネントをモデル化することです。 同じコンポーネント内の居住者はいつでも自由にキーを共有できます。 コンポーネント内に存在するすべてのキーが到達可能なルームを介して伝播されると、それらのキーによって接続されているすべてのルームが単一の「到達可能なコンポーネント」を形成します。 これはまさに、Disjoint Set Union (DSU) または Union-Find が威力を発揮する問題です。各ドアは部屋間のブリッジであり、ドアに必要なキーはシステム内のどこかにあります。 コンポーネント内の現在のキーのセットを使用してロックを解除できる部屋を繰り返し結合することで、各居住者のグループがアクセスできる部屋の最大セットを決定できます。 最終的に、各居住者の目標部屋が最初の部屋の到達可能なコンポーネント内にある場合、構成は達成可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(k * 2^m) | O(n + m + k) | 遅すぎる |
 | DSU/コンポーネントの伝播 | O(m + n + k) | O(n + m + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、部屋とドアのグラフを保存します。 各ドアについて、そのエンドポイントを維持し、一意のキーに関連付けます。 
2. 各居住者の最初の位置と彼らが保持している鍵を追跡します。 各居住者のターゲットの場所も追跡します。 キーから最初にそれを保持する居住者までのマッピングを維持します。 
3. 現在使用可能なキーで到達可能なルームのコンポーネントを追跡するために、Disjoint Set Union (DSU) 構造を初期化します。 最初は、各部屋は独自のコンポーネントです。 
4. 各居住者について、現在開くことができるドアにマークを付けます。 開閉可能なドアごとに、DSU 内で接続されている 2 つの部屋を結合します。 これは、鍵を持っている人がそれらの部屋の間を自由に移動できることを表します。 
5. コンポーネントを通じてキーを繰り返し伝播します。 コンポーネントごとに、コンポーネント内の居住者が保持しているすべてのキーを収集します。 ドアが異なるコンポーネント内の 2 つの部屋を接続しているが、そのドアのキーがいずれかのコンポーネントに存在する場合は、コンポーネントをマージします。 新しいマージができなくなるまでこれを繰り返します。 
6. 伝播が安定したら、各居住者について、ターゲットの部屋が最初の部屋と同じ DSU コンポーネント内にあるかどうかを確認します。 すべての居住者がこの条件を満たしている場合は、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 

機能する理由: DSU の結合により、同じコンポーネント内の居住者が使用できるキーを使用して、同じコンポーネント内の任意の 2 つの部屋に相互に到達できることが保証されます。 キーの伝播により、ある部屋でキーにアクセスできるようになるとすぐに、そのキーで開くことができるすべてのドアが考慮され、到達可能なエリアが拡大されます。 居住者はコンポーネント内でキーを自由に交換できるため、これによりすべての合法的な動きが捕捉されます。 ターゲットの部屋がコンポーネントの外側にある場合、制約があるため到達できません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root != y_root:
            self.parent[y_root] = x_root

def solve():
    n, m, k = map(int, input().split())
    doors = []
    for _ in range(m):
        u, v = map(int, input().split())
        doors.append((u-1, v-1))
    
    residents_init = {}
    residents_final = {}
    key_owner_init = [None] * m
    
    for i in range(k):
        parts = input().split()
        name = parts[0]
        room = int(parts[1]) - 1
        num_keys = int(parts[2])
        keys = [int(x)-1 for x in parts[3:]]
        residents_init[name] = (room, set(keys))
        for key in keys:
            key_owner_init[key] = name

    for i in range(k):
        parts = input().split()
        name = parts[0]
        room = int(parts[1]) - 1
        residents_final[name] = room

    dsu = DSU(n)
    
    changed = True
    while changed:
        changed = False
        component_keys = [set() for _ in range(n)]
        for name, (room, keys) in residents_init.items():
            root = dsu.find(room)
            component_keys[root].update(keys)
        for idx, (u, v) in enumerate(doors):
            ru, rv = dsu.find(u), dsu.find(v)
            if ru != rv:
                if idx in component_keys[ru] or idx in component_keys[rv]:
                    dsu.union(ru, rv)
                    changed = True
    
    possible = all(dsu.find(residents_init[name][0]) == dsu.find(residents_final[name]) for name in residents_init)
    print("YES" if possible else "NO")

solve()
```このコードは、到達可能な部屋を追跡するために DSU を維持し、各コンポーネント内のすべてのキーを収集し、コンポーネント内の任意のキーでドアを開けることができる場合にコンポーネントを繰り返しマージします。 の`changed`このフラグは、マージが不可能になるまで伝播が継続されることを保証します。 最終チェックでは、各居住者が目的の部屋に到達できるかどうかを確認します。
