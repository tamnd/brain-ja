 ## 解決策
 ## 問題の理解

 文字で構成されるテキスト文字列が与えられ、そのタスクは、それぞれの異なる文字が何回出現するかを計算することです。 出力はこれらの頻度の要約であり、通常はアルファベット順などの固定順序で表示されるため、すべての文字の寄与を直接比較できます。 

入力は、アルファベットでインデックス付けされたカウンター配列を流れる一連の文字と考えることができます。 キャラクターが登場するたびに、そのバケットが増加します。 最終的な答えは単にこの度数表の内容です。 

制約の観点から見ると、重要な詳細は、文字列が 10^5 以上の文字などの一般的な Codeforce 制限まで大きくなる可能性があるということです。 これにより、文字ごとに文字列を繰り返しスキャンしたり、クエリごとに並べ替えベースのカウントを実行したりするソリューションは即座に除外されます。 O(n^2) の動作は制限時間内に通過しませんが、小さな定数を持つ O(n) または O(n log n) は制限時間内に通過するため、単一の線形パスが必要です。 

文字列に異なる文字が 1 つだけ含まれている場合、微妙なエッジ ケースが発生します。 たとえば、次のように入力します`aaaaa`単一の非ゼロ周波数を生成し、他の場所ではゼロを生成する必要があります。 もう 1 つのエッジ ケースは、文字列に大文字と小文字が混在していたり​​、予期しない文字が含まれている場合です。 問題のステートメントに応じて、それらは無視するか、別のカテゴリとして扱う必要があります。 単純な解決策では、小文字のみを想定し、大文字が出現すると警告なしに中断される可能性があるため、文字マッピングを慎重に扱うことが重要です。 

## アプローチ

 最も直接的なアイデアは、これを計数問題として扱うことです。 文字列内のすべての文字をスキャンし、各文字の出現頻度を追跡する辞書または固定サイズの配列を維持します。 これが機能するのは、各キャラクターが独立して最終的な答えに貢献し、立場間の相互作用がないためです。 

ブルートフォースの変形では、個別の文字ごとに文字列全体を再度スキャンし、出現回数をカウントします。 使用可能な文字が k 個あり、文字列の長さが n の場合、これは O(k・n) になります。 k = 26 の場合でも場合によっては問題なく動作する可能性がありますが、アルファベットが大きくなったり、制約が厳しくなったりすると、不必要に非効率になり、メモリ トラバーサルの繰り返しにより TLE が発生する危険があります。 

重要な観察は、数を数えるのに繰り返し作業が必要ないということです。 各文字は 1 回だけ処理され、単一のアキュムレータが更新されます。 これにより、計算全体が入力の 1 回のパスに削減され、その後は保存された結果のみが出力されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (文字ごとに再カウント) | O(26・n) | お(1) | 通常、厳しい制約の下では遅すぎます。 
| シングルパス周波数配列 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 アルファベットは英小文字で構成されていると想定しているため、サイズ 26 の配列を維持します。 

1. 配列を初期化する`freq`サイズ 26 ですべてゼロ。 この配列は文字の数を表します`'a'`を通して`'z'`、各インデックスは 1 つの文字に直接対応します。 
2. 入力文字列内の各文字を繰り返し処理します。 キャラクターごとに`c`を減算してインデックスに変換します。`'a'`。 インクリメント`freq[index]`。 このステップは、すべての出来事が正確に 1 回記録されることを保証するため、ソリューションの中核です。 
3. 文字列全体を処理した後、頻度配列をインデックス 0 から 25 まで反復処理します。位置ごとに、それを文字として再解釈し、出力形式を準備します。 
4. 頻度を必要な順序で出力します。通常はスペースで区切るか、書式設定ルールに応じて 1 行に 1 つずつ出力します。 

### なぜ効果があるのか

 正確さは、周波数の累積が次数に依存しないという事実から得られます。 各文字は 1 つのバケットに 1 つのユニットを提供し、加算による集計を除き、その後の操作で以前のカウントが変更されることはありません。 文字列内のすべての文字が正確に 1 回訪問され、各訪問で正確に 1 つの増分が実行されるため、最終的な配列は入力内の文字の正確なマルチセット数を表します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    s = input().strip()
    
    freq = [0] * 26
    
    for ch in s:
        freq[ord(ch) - ord('a')] += 1
    
    # output as space-separated frequencies
    print(*freq)

if __name__ == "__main__":
    solve()
```このソリューションは、O(n) 時間で文字列を読み取り、固定サイズの配列を更新します。 マッピング`ord(ch) - ord('a')`これは、辞書を使用せずに定数時間のインデックス作成を保証するため、実装の詳細として重要です。 

最終的な出力ではアンパックが使用されており、周波数配列の一般的な Codeforce 形式と一致します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各文字は 1 回のパスで 1 回だけ処理されます。 
| スペース | お(1) | 入力サイズに関係なく、26 個の整数の固定サイズの配列 |

 頻度を決定するにはすべての文字を少なくとも 1 回読み取る必要があるため、文字列の線形スキャンが最適です。 アルファベットのサイズは入力サイズとともに増加しないため、メモリ使用量は一定のままであり、大きな文字列であってもソリューションを制限内に十分に保つことができます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    
    solve()
    
    sys.stdout = sys.__stdout__
    return output.getvalue().strip()

def solve():
    s = input().strip()
    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - ord('a')] += 1
    print(*freq)

# provided-like samples
assert run("abac\n") == "2 1 1 " + "0 "*23, "sample 1"
assert run("zzza\n") == "1 " + "0 "*25 + "3", "sample 2"

# custom cases
assert run("a\n") == "1 " + "0 "*25, "single character"
assert run("abcdefghijklmnopqrstuvwxyz\n") == "1 "*26, "all letters once"
assert run("aaaaaa\n") == "6 " + "0 "*25, "all same letters"
assert run("\n") == "0 "*26, "empty string edge case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`a`|`1 0 ... 0`| 単一文字の処理 |
 |`abcdefghijklmnopqrstuvwxyz`| すべてのもの | フルカバレッジのアルファベット |
 |`aaaaaa`| 最初のエントリ 6 | 繰り返し文字の蓄積 |

 ## 特殊なケース

 空の文字列または空白のみの文字列の場合、文字に対するループは更新を行わず、頻度配列は完全にゼロのままになります。 入力用`"a"`の場合、アルゴリズムはインデックス 0 を 1 回だけインクリメントし、他のすべてのインデックスは変更されず、特別な分岐を行わずにクリーンなスパース結果が生成されます。 

次のような非常に偏った入力の場合`"aaaaaa"`、すべての反復は同じインデックスをターゲットにしており、操作は代入ベースではなく加算的であるため、繰り返された増分は正しく累積されます。 これにより、カウントをインクリメントせずに上書きするというよくある間違いを回避できます。 

入力にすべて異なる文字が含まれている場合、すべてのインデックスが 1 回だけヒットし、均一な配列が生成され、衝突やインデックス作成エラーが発生しないことが確認されます。
