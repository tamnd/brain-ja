 ## 解決策
 ## 問題の理解

 長さ (n) のターゲット ベクトル (a) が与えられます。ここで、すべての座標は (-1)、(0)、または (1) であり、少なくとも 1 つの座標は非ゼロです。 すべての非ゼロ ベクトル (b\in{-1,0,1}^n) の中で合同となるような別の整数ベクトル (x) と法 (m) を構築する必要があります。 

[
 \sum_{i=1}^{n} b_i x_i \equiv 0 \pmod m
 】

 は、正確に 2 つのベクトル、つまり (b=a) と (b=-a) に対して当てはまります。 

難しいのは、固定された (x) と (m) の解を見つけるように求められていないことです。 符号を変えるまでは所定のベクトルが唯一の解となるように(x)と(m)を設計しています。 

境界 (n\le 30) が重要な数値制約です。 これにより、(2^{29}) までの 2 のべき乗を含む数値を使用できるようになりますが、これはすべての (x_i) について許容範囲内にあります。 同時に、係数は厳密に (2^n) より小さくなければならないため、任意の独立した構成の積と同じくらい大きな係数を単純に使用することはできません。 以下の構造では、座標を 2 つの独立したモジュラー システムに分割することで、必要な量のスペースを正確に取得します。 

特別な注意が必要な 2 つの特殊なケースがあります。 (a) に 0 以外の座標が 1 つだけある場合、入力は次のようになります。```
3
0 -1 0
```(2^k-1) の一般的な構成は使用できません。(k=1) は法 (1) を与え、すべての整数は (1) で割り切れるためです。 代わりに、(m=2^n-1) を使用し、(x_2=-m) を置き、他の座標に累乗 (1,2) を与えます。 それらの符号付き合計の絶対値は (m) より小さいため、ゼロ以外の別の解を作成することはできません。 

2 番目のエッジ ケースは、ゼロ座標が存在しない場合です。 例えば、```
3
1 -1 1
```建設はまだ機能しています。 構造のゼロ座標部分は単純に消えるため、それに対応する係数は (1) になります。 次に、2 の剰余 (2^n-1) の累乗により、ターゲット ベクトルとその負の値が強制されます。 

## アプローチ

 直接的なアプローチでは、考えられるすべての生徒の回答を列挙します (b)。 各座標には 3 つの選択肢があるため、(3^n-1) 個の非ゼロの候補があります。 候補ごとにスカラー積を計算し、割り切れる可能性を確認できます。 これは文字通りすべての可能な答えをチェックするので正しいですが、(n=30) の場合はおおよその値が必要です。 

[
 3^{30}\約 2.06\cdot 10^{14}
 】

 制限時間を大幅に超えています。 

有益な観察は、(x) と (m) の両方を制御しているということです。 さまざまな係数の係数を使用して、さまざまな座標グループを表示できます。 (a) の (k) 座標がゼロでなく、(z=n-k) 座標がゼロであると仮定します。 (k\ge2) については、次を選択します。 

[
 M_1=2^k-1,\qquad M_2=2^z,
 】

 そして使用します

 [
 m=M_1M_2。 
】

 (M_1<2^k) なので、

 [
 m=(2^k-1)2^z<2^{k+z}=2^n。 
】

 非ゼロ座標は (M_2) の倍数になるため、(M_2) を法として消えます。 ゼロ座標は (M_1) の倍数になるため、(M_1) を法として消えます。 単一の割り算条件モジュロ (m=M_1M_2) は、2 つの独立した条件に分割されます。 

非ゼロ座標の場合、2 の累乗は重要な一意性の特性を与えます。 (k) 個の非ゼロ座標に累乗 (1,2,\ldots,2^{k-1}) が割り当てられている場合、次のようになります。 

[
 1+2+\cdots+2^{k-1}=2^k-1=M_1。 
】

 したがって、目的のベクトルは正確に (M_1) を生成します。 (M_1) の倍数を生成する他のベクトルは、絶対値が最大でも (M_1) であるため、実際には (0)、(M_1)、または (-M_1) を生成する必要があります。 バイナリ表現の通常の一意性により、係数ベクトルは (0)、すべて (1)、またはすべて (-1) になります。 

ゼロ座標の場合、2 のべき乗モジュロ (2^z) には別の有用な特性があります。 それらの符号付き絶対和は最大でも

 [
 1+2+\cdots+2^{z-1}=2^z-1、
 】

 これは厳密に (2^z) よりも小さいです。 したがって、符号付き和は、正確にゼロの場合にのみ (2^z) で割り切れます。 バイナリの一意性により、すべてのゼロ座標係数が強制的にゼロになります。 

ブルートフォース手法は、可能なベクトルのセットが有限で明示的であるため機能しますが、そのセットのサイズが (3^n) であるため失敗します。 係数が因数分解できるという観察により、1 つの大規模な検索をバイナリ表現に基づく 2 つの一意性引数に置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(3^n n)) | (O(n)) | 遅すぎる |
 | 最適 | (O(n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (a) の非ゼロエントリの数 (k) を数え、(z=n-k) とします。 ゼロ以外の座標を使用して所定の符号をエンコードし、ゼロ座標を使用して、それらの変化を防ぐ独立した制約を作成します。 
2. (k=1) かつ (n=1) の場合、(m=1) および (x_1=1) を出力します。 ゼロ以外の選択肢は (1) と (-1) だけであるため、これらの選択肢の両方または唯一が割り算条件を満たします。 
3. (k=1) かつ (n>1) の場合、(m=2^n-1) を選択します。 (x_j=a_jm) をゼロ以外の固有の座標 (j) に置きます。 残りの座標に累乗 (1,2,\ldots,2^{n-2}) を任意の順序で割り当てます。 目的の座標は (\pm m) に寄与しますが、他の座標の符号付きの組み合わせは最大でも絶対値 (2^{n-1}-1<m) を持ちます。 したがって、どの解でも他の座標はすべて 0 でなければならず、固有の非ゼロ座標は (1) または (-1) でなければなりません。 
4. (k\ge2) について、(M_1=2^k-1) と (M_2=2^z) を定義します。 (m=M_1M_2) を設定します。 不等式 (m<2^n) は (M_1<2^k) から直接導かれます。 
5. (a) のゼロ以外の位置を列挙します。 (r) 番目のそのような位置に (a_i) が含まれる場合、次のように設定します。 

[
 x_i=a_iM_2 2^r。 
】

 (M_2) を乗算すると、この座標はモジュロ (M_2) で非表示になりますが、モジュロ (M_1) では符号付きバイナリ重み (a_i2^r) とまったく同じように動作します。 

1. (a) のゼロの位置を列挙します。 (s) 番目のそのような位置については、次のように設定します。 

[
 x_i=M_1 2^s。 
】

これらの座標は非表示のモジュロ (M_1) ですが、モジュロ (M_2) では通常のバイナリの重み (1,2,\ldots,2^{z-1}) を形成します。 

1. 任意の候補ベクトル (b) を検討します。 (M_1) と (M_2) は互いに素であるため、その積で割り切れるのは各因数で割り切れるのと同じです。 モジュロ (M_1) では、すべてのゼロ座標の寄与が消え、非ゼロ座標のみが残ります。 モジュロ (M_2) では、すべての非ゼロ座標の寄与が消え、(a_i=0) の座標だけが残ります。 
2. モジュロ (M_2) 条件により、(b) のすべてのゼロ座標エントリが強制的にゼロになります。 残りのモジュロ (M_1) 条件は、非ゼロ座標の係数がすべてゼロであるか、すべて (a) の対応するエントリに等しいか、すべてその負の値に等しいかのいずれかである必要があることを示します。 すべてゼロの場合は問題によって除外され、正確に (a) と (-a) が残ります。 

### なぜ効果があるのか

 中心的な不変条件は、2 つの座標グループが互いに素な係数によって分離されていることです。 (a) のサポートに属する座標は (M_2) の倍数であるため、(M_2) の条件に影響を与えることはできません。 サポートの外側の座標は (M_1) の倍数であるため、(M_1) の状態に影響を与えることはできません。 その結果、ゼロ座標は強制的にゼロのままになりますが、ゼロ以外の座標は (0)、(M_1)、または (-M_1) の符号付き 2 進数表現に減らされます。 バイナリの一意性により、正確に 3 つのベクトル (0、a、-a) が得られ、ゼロ ベクトルは生徒の解答として許可されません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    nonzero = [i for i in range(n) if a[i] != 0]
    zero = [i for i in range(n) if a[i] == 0]

    k = len(nonzero)
    z = len(zero)

    # Special case: n = 1, necessarily k = 1.
    if n == 1:
        print(1)
        print(a[0])
        return

    # Special case: exactly one nonzero coordinate.
    if k == 1:
        m = (1 << n) - 1
        x = [0] * n

        j = nonzero[0]
        x[j] = a[j] * m

        value = 1
        for i in zero:
            x[i] = value
            value <<= 1

        print(m)
        print(*x)
        return

    # General case.
    m1 = (1 << k) - 1
    m2 = 1 << z
    m = m1 * m2

    x = [0] * n

    # Encode nonzero coordinates modulo m1.
    weight = 1
    for i in nonzero:
        x[i] = a[i] * m2 * weight
        weight <<= 1

    # Encode zero coordinates modulo m2.
    weight = 1
    for i in zero:
        x[i] = m1 * weight
        weight <<= 1

    print(m)
    print(*x)

if __name__ == "__main__":
    solve()
```入力は、まず (a) のサポートとその補数に分割されます。 これらのインデックス リストを維持するだけで、配列の元の順序を変更せずに連続したバイナリの重みを割り当てることができます。 

(k=1) 分岐が必要なのは、主要な構築では (M_1=2^1-1=1) を使用するためであり、これには有用なモジュール制限がありません。 (n=1) の場合、ゼロ以外のベクトルは (1) と (-1) だけであるため、実際には法 (1) で十分です。 

一般的なケースとしては、`m1`は (2^k-1) であり、`m2`は (2^z) です。 それらの積は厳密に (2^n) より小さく、係数制限を正確に満たします。 

ゼロ以外の座標に割り当てられた値は次のように乗算されます。`m2`。 ゼロ座標に割り当てられた値は次のように乗算されます。`m1`。 これは、証明で使用される CRT スタイルの分離です。 

ゼロ以外の座標に割り当てられる最大値は次のとおりです。 

[
 2^z 2^{k-1}=2^{n-1}、
 】

 最大のゼロ座標値は以下です

 [
 (2^k-1)2^{z-1}<2^{n-1}。 
】

 したがって、(n\le30) の場合、すべての (x_i) は厳密に (-2^{30}) と (2^{30}) の間にあります。 Python の整数はオーバーフローしませんが、その構築は Python の任意の精度に依存するのではなく、元の数値範囲内に留まります。

### 例 2

 検討してください```
4
1 0 -1 0
```ここでは (k=2) および (z=2) です。 したがって、

 [
 M_1=3、\qquad M_2=4、\qquad m=12。 
】

 2 つの非ゼロ座標は、(M_2) を乗算した重み (1) と (2) を受け取ります。 2 つのゼロ座標は (1) と (2) を受け取り、(M_1) で乗算されます。 

| 座標 | (a_i) | 役割 | (x_i) |
 | --- | --- | --- | --- |
 | 1 | 1 | ゼロ以外の重み (1) | (4) |
 | 2 | 0 | ゼロ、重み (1) | (3) |
 | 3 | -1 | 非ゼロ、重み (2) | (-8) |
 | 4 | 0 | ゼロ、重み (2) | (6) |

 ターゲットベクトルについては、

 [
 1\cdot4+0\cdot3+(-1)(-8)+0\cdot6=12、
 】

 したがって有効です。 負の場合は (-12) が生成され、これも有効です。 

次に、2 つのモジュラー コンポーネントを個別に検査します。 モジュロ (4)、非ゼロ座標は消滅し、ゼロ座標が寄与します

 [
 3(b_2+2b_4)。 
】

 (3) は (4) を法とする可逆であるため、これには次のことが必要です。 

[
 b_2+2b_4\equiv0\pmod4。 
】

 その絶対値は最大 (3) であるため、実際にはゼロに等しくなければなりません。 これを満たす唯一の三項選択は (b_2=b_4=0) です。 

モジュロ (3) では、座標 (1) と (3) のみが残ります。 彼らの状態はこうなる

 [
 b_1-2b_3\equiv0\pmod3。 
】

 唯一の可能性は ((b_1,b_3)=(1,-1),(-1,1),(0,0)) です。 ゼロ ベクトルは除外され、指定されたベクトルとその負のベクトルがそのまま残ります。

## テストケース

import io

def solve_data(inp: str) -> str:

    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n = int(sys.stdin.readline())

            print(1)

            print(*x)

    assert len(x) == n
