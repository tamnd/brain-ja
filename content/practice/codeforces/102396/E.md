 ## 解決策
 ## 問題の理解

 非ゼロの 3 値ベクトル a が与えられます。ここで、すべての a i は −1、0、または 1 です。すべての非ゼロの 3 値ベクトル c の中で、割り算条件が満たされるような別の整数配列 x と法 m を構築する必要があります。 

i=1 ∑ n c i x i ≡0(modm)

 は、正確に 2 つのベクトル、つまり規定のベクトル a とその否定 -a について成り立ちます。 構築自体が答えであるため、処理する入力係数や配列 x はありません。 

n≤30 という制限が中心的な数値制限です。 最大 2 29 までの 2 のべき乗が許可されますが、それでもすべての x i に必要な 2 30 の境界を厳密に下回ります。 同時に、係数は 2 n より小さくなければならないため、2 進数 2 n -1 に基づく構成は特に自然です。 すべての三値ベクトルをブルートフォースする場合、3 n -1 個の候補が必要になります。これは、n=30 の場合、約 2.06×10 14 個の候補になります。 各候補を定数時間でチェックすることさえ絶望的であり、その内積を O(n) でチェックすることはさらに悪いことです。 

不注意な構築によって誤って処理される可能性がある 2 つのエッジケースがあります。 たとえば、```
1
1
```非ゼロの 3 値ベクトルは 1 と −1 だけであるため、m=1、x 1 =1 はすでに有効です。 m>1 を主張する構築はここで不必要に失敗します。 

ターゲット ベクトル内のゼロはより微妙です。 のために```
2
1 0
```(1,0) を (1,1) および (1,−1) と区別しなければなりません。 単純に x i =a i 2 i と設定すると x 2 =0 となり、2 番目の係数の選択はすべて無関係になり、多くの望ましくない解が作成されます。 この構築では、ゼロ ポジションに独自の重みを与えながらも、ゼロ ポジションが可算和に参加するのを防ぐ必要があります。 

公式問題では、有効な構築が許可されていますが、必ずしもサンプル構築が許可されているわけではありません。 

## アプローチ

 直接的なアプローチでは、すべてゼロのベクトルを除くすべてのベクトル c∈{−1,0,1} n を列挙し、∑c i x i を計算し、m で割り切れるかどうかをテストします。 このようなベクトルは正確に 3 n −1 個あります。 n=30 の場合、これはおよそ 2.06×10 14 の可能性であるため、ブルート フォースは完全に実行不可能です。 

有益な観察は、実際には x を検索する必要がないということです。 係数セット {−1,0,1} は 2 のべき乗と非常にきれいに相互作用します。 座標の重みに 1、2、4、… を与えると、すべての符号付き合計は厳密な 2 値構造になります。 特に、重み 1,2,…,2 k−1 の {−1,0,1} の係数を使用して 2 k −1 を取得する唯一の方法は、すべての係数を +1 として使用することであり、その負の値を取得する唯一の方法は、すべての係数を −1 として使用することです。 

残りの困難は、一部のターゲット係数がゼロになる可能性があることです。 重要なのは、ゼロの位置と非ゼロの位置を大きさによって区別することです。 すべてのゼロの位置に 2 の最小の累乗を与え、ゼロ以外のすべての位置により大きな累乗を与えます。 次に、ターゲット ベクトルはより大きな重みをすべて正確に使用するため、その内積は慎重に選択された係数になります。 

z をゼロエントリの数、k=n−z をゼロ以外のエントリの数とする。 ゼロ位置に重みを割り当てます

 1,2,…,2 z−1 、

 ゼロ以外の位置を割り当てます

 2 z ,2 z+1 ,…,2 n−1 。 

ゼロ以外のターゲット エントリの場合、割り当てられた重みに a i を乗算し、ターゲットの符号が x i に直接組み込まれるようにします。 ターゲット エントリがゼロの場合は、割り当てられた正の重みを使用します。 

ターゲットのドット積は次のようになります。 

a i  =0 ∑ a i (ai 2 j )= j=z ∑ n−1 2 j =2 n −2 z 。 

まさにこの値を m として選択します。 k≥1 であるため正であり、必要に応じて 2 n より小さいです。 

3 項の組み合わせの絶対値の合計が最大でも次の値であるため、この構造は機能します。 

1+2+⋯+2 n−1 =2 n −1。 

係数は m≥2 n−1 を満たすため、この範囲で可能な m の倍数は 0、m、および −m のみです。 次に、低位 z ビットによってすべてのゼロ位置係数が強制的に消失し、その後、残りの問題は 2 k −1 の一意のバイナリ表現に帰着します。

 ## アルゴリズムのチュートリアル

 1. ターゲット ベクトルのエントリが 0 である個数を数えます。 この数をzとします。 他の k=n−z エントリは非ゼロであり、k≥1 です。 
2.セット

 m=2 n −2 z 。 

これは正確にパワー 2 z 、2 z+1 、…、2 n−1 の合計であり、非ゼロのターゲット位置に割り当てられる重みになります。 k≥1 なので、m≥1 となり、明らかに m<2 n になります。

1. ターゲット配列を走査します。 ゼロのエントリごとに、1 から始まる次の未使用の 2 の低いべき乗を割り当てます。したがって、ゼロの位置は 2 0 ,2 1 ,…,2 z−1 を受け取ります。 
2. ゼロ以外のエントリ a i ごとに、次に未使用の 2 の高いべき乗を割り当て、それに a i を乗算します。 したがって、ターゲット値 1 には正の重みが付けられ、ターゲット値 -1 には対応する負の重みが付けられます。 
3. 結果として得られるターゲット内積は正確に m です。 その否定は内積 -m を持つため、規定された両方の解は有効です。 
4. 割り算条件を満たす非ゼロの 3 値ベクトル c を考えます。 その絶対内積は最大でも 2 n -1 ですが、m≧2 n-1 です。 したがって、その内積は 0、m、−m のいずれかでなければなりません。 
5. 内積がゼロの場合は、係数がゼロ以外の 2 の最大累乗を調べます。 その電力は厳密にすべての小さい電力の合計よりも大きいため、キャンセルすることは不可能です。 したがって、すべての係数はゼロでなければならず、c がゼロ以外であるという要件に反します。 
6. 内積が m または -m であると仮定します。 方程式を 2 z を法として換算します。 すべての高い重みは 2 z で割り切れますが、ゼロ位置の重みは正確に 1,2,…,2 z−1 です。 それらの符号付き合計は 2 z よりも小さい絶対値を持つため、実際にはゼロに等しくなければなりません。 符号付きバイナリ表現の一意性により、ゼロ ターゲット位置のすべての係数が強制的にゼロになります。 
7. これらのゼロ位置を削除し、残りの方程式を 2 z で除算すると、重みは 1,2,…,2 k−1 になり、必要な絶対和は 2 k −1 になります。 唯一可能な 3 値表現は、元の合計の符号に応じて、すべて +1 またはすべて -1 です。 x i に保存されている符号を元に戻すと、解は a と −a だけになります。 

### なぜ効果があるのか

 重要な不変条件は、2 の低い累乗は、目的の答えが 0 である座標のみに属し、ゼロ以外のすべてのターゲット座標は 2 z の倍数を受け取るということです。 割り切れる組み合わせは、最初にその下位部分が 0 に等しくなければならず、ゼロのターゲット係数はすべて強制的に消去されます。 残りの高べき乗は完全な 2 値シーケンスを形成し、その 2 k −1 および −(2 k −1) の 3 値表現のみがすべて正およびすべて負の選択肢となります。 x i に格納されている符号は、これらの選択肢を正確に a と −a に変換します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    z = a.count(0)

    # Sum of powers 2^z, ..., 2^(n-1).
    m = (1 << n) - (1 << z)

    x = [0] * n

    low_power = 0
    high_power = z

    for i in range(n):
        if a[i] == 0:
            x[i] = 1 << low_power
            low_power += 1
        else:
            x[i] = a[i] * (1 << high_power)
            high_power += 1

    print(m)
    print(*x)

if __name__ == "__main__":
    solve()
```の最初の行`solve`ターゲットベクトルを読み取り、`z`最終的に係数 0 を持たなければならない座標の数を記録します。 このカウントにより、2 の低いべき乗と高いべき乗の境界がどこにあるかが決まります。 

係数は次のように計算されます。`(1 << n) - (1 << z)`。 これは 2 z から 2 n−1 までのすべての累乗の合計であるため、目的のベクトルによって得られる絶対内積と正確に一致します。 

2 つのカウンターには異なる役割があります。`low_power`はゼロから始まり、ターゲットのゼロにのみ使用されます。`high_power`から始まります`z`ゼロ以外のターゲット エントリにのみ使用されます。 その結果、2 つのグループはバイナリ位置の互いに素な範囲を占めます。 

ゼロ以外の場合`a[i]`、式`a[i] * (1 << high_power)`目的の符号を直接保存します`x[i]`。 ターゲット係数が -1 の場合、対応する`x[i]`はマイナスです。 生徒が目標係数 −1 を選択すると、次の積が得られます。`x[i]`は正であり、必要な 2 の累乗が目標合計に寄与します。 

割り当てられる最大の絶対値は 2 n−1 です。 n≤30 であるため、最大でも 2 29、厳密には 2 30 未満になります。Python の整数には任意の精度もあるため、オーバーフローの問題はありません。 

元の入力にはインスタンスが 1 つだけ含まれているため、複数のテストケースのループはありません。 この構築では、整数シフトと配列を通る 1 つの線形パスのみを使用します。

## テストケース

import sys
import io
from itertools import product

def solution(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    z = a.count(0)
    m = (1 << n) - (1 << z)

    x = [0] * n
    low_power = 0
    high_power = z

    for i in range(n):
        if a[i] == 0:
            x[i] = 1 << low_power
            low_power += 1
        else:
            x[i] = a[i] * (1 << high_power)
            high_power += 1

    print(m)
    print(*x)

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout
    return out

def validate(inp: str) -> str:
    out = solution(inp).split()
    data = list(map(int, out))

    n = int(inp.split()[0])
    a = list(map(int, inp.split()[1:n + 1]))

    m = data[0]
    x = data[1:]

    assert len(x) == n
    assert 1 <= m < (1 << n)
    assert all(-(1 << 30) < v < (1 << 30) for v in x)

    found = []

    for c in product((-1, 0, 1), repeat=n):
        if all(v == 0 for v in c):
            continue

        s = sum(c[i] * x[i] for i in range(n))
        if s % m == 0:
            found.append(c)

    expected = {tuple(a), tuple(-v for v in a)}
    assert set(found) == expected

    return out

# Provided sample
validate("""\
2
1 -1
""")

# Minimum-size input
validate("""\
1
1
""")

# A zero coordinate, catching constructions that accidentally set x_i = 0
validate("""\
2
1 0
""")

# Mixed signs and zeros
validate("""\
6
0 -1 1 0 1 -1
""")

# Maximum-size input
validate("30\n" + " ".join(["1"] * 30) + "\n")

# All nonzero values with mixed signs
validate("""\
8
1 -1 1 -1 -1 1 -1 1
""")
