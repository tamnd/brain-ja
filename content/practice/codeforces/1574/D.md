 ## 解決策
 ## 問題の理解

 この問題では、それぞれが異なる強度の複数のアイテムを備えた一連の装備スロットから、可能な限り最強のヒーロー ビルドをイワンが選択するのを手伝うように求められます。 各スロットには独自のアイテムのリストがあり、強さの増加順にすでに並べ替えられています。 Ivan はスロットごとに 1 つのアイテムを正確に選択して、ビルドを形成する必要があります。 一部のビルドは明示的に禁止されており、タスクは禁止されていない最大の総合強度を持つビルドを見つけることです。 出力は、単に各スロット内の項目の選択されたインデックスです。 

制約はアルゴリズムを設計するために重要です。 スロットの数、$n$は最大でも 10 であり、非常に小さいです。 これは、指数関数的にアプローチすることを示唆しています。$n$まだ実現可能かもしれない。 各スロットには最大で$2 \cdot 10^5$アイテムですが、すべてのスロットのすべてのアイテムの合計は次のように制限されます。$2 \cdot 10^5$したがって、考えられるすべての組み合わせを単純に列挙するわけにはいきません。最悪の場合、ビルドの総数は$c_i$を簡単に超える可能性があります$10^{18}$力ずくで試してみたら。 

明白ではないエッジケースには、最も強いビルド (すべてのスロットで最後の最大のアイテムを選択する) が禁止されるシナリオが含まれます。 その場合、常にスロットごとに最大のアイテムを選択する単純なソリューションは失敗します。 たとえば、アイテムが入っているスロットが 2 つある場合、`[1, 2]`そして`[1, 3]`、禁止されたビルドは`[2, 2]`、アルゴリズムは正しく選択する必要があります`[2, 1]`代わりに、次に高い総合強度を持っています。 

## アプローチ

 最も単純な総当たりアプローチは、アイテムの可能なすべての組み合わせを生成し、各ビルドの強度を計算し、禁止されているビルドを除外することです。 原理的には正しいですが、このアプローチは実行不可能です。$n = 10$それぞれ長さ 20 の小さなリストがある場合、$20^{10} \approx 10^{13}$構築します。 

より良いアプローチでは、小さな要素を利用します。$n$そして各スロットのアイテムがソートされているという事実。 禁止がない場合の最適なビルドは、常に各リストの最後のアイテムを使用するビルドです。 したがって、問題は、この「すべての最終項目」ビルドが禁止されているかどうかを確認することになります。 そうである場合、次の候補ビルドは、1 つのスロットが 1 つのインデックスによって削減されるものになります。つまり、次のビルドを試みます。`[c_1 - 1, c_2, ..., c_n]`、`[c_1, c_2 - 1, ..., c_n]`、など、総強度の最大の減少を優先します。 この構造は最大ヒープ検索の問題を形成します。つまり、ビルドを合計強度を持つノードとして扱い、まだ禁止されていない最も強度の高いノードを常に拡張します。 

優先キュー (最大ヒープ) を使用して、強度によってソートされた候補ビルドを維持します。 最初、ヒープには最大のビルドが含まれています。 最強のビルドをポップします。 禁止されていないのであれば、それが私たちの答えです。 それ以外の場合は、各スロットのインデックスを 1 つ減らすことによって新しい候補ビルドを生成します (ただし、結果のビルドがまだアクセスされていない場合に限ります)。 このようにして、すべての可能性を列挙することなく、強度の降順でビルドを探索します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(∏c_i) | O(∏c_i) | 遅すぎる |
 | 最大ヒープ検索 | O(m log m + n log n * m) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべてのスロット データと禁止されたビルドを読み取ります。 禁止されたビルドをタプルに変換し、O(1) ルックアップ用のセットに保存します。 
2. 各スロットから最後のアイテムを選択して、初期ビルドを構築します。 その合計強度を計算します。 
3. タプルを使用して最大ヒープを初期化する`(-strength, build)`Python の最小ヒープを使用して最大ヒープをシミュレートします。 
4. 同じビルドを複数回再処理することを避けるために、訪問したビルドのセットを維持します。 
5. ヒープが空でない間に、現在の最高強度でビルドをポップします。 禁止されていない場合は、回答として印刷して終了します。 
6. それ以外の場合は、スロットごとに、そのスロットのインデックスを 1 つ減らして新しいビルドを作成します (ただし、インデックスがまだ 1 以上である場合に限ります)。 この新しいビルドにアクセスしていない場合は、その強度を計算してヒープにプッシュします。 
7. 禁止されていないビルドが見つかるまで続行します。 初期ビルドは禁止されないことが保証されているため、このループは常に終了します。 

機能する理由: すべてのステップで、ヒープは合計強度の厳密な降順でビルドを処理することを保証します。 禁止されているビルドのみをスキップし、未訪問のビルドよりも強力である可能性のあるすべての候補はヒープ内にあるか、ヒープにプッシュされます。 訪問済みセットにより、同じビルドに再度アクセスすることができなくなります。 これにより、禁止されていないヒープからポップされた最初のビルドが可能な限り最大の強度を持つことが保証されます。 

## Python ソリューション```python
import sys
import heapq
input = sys.stdin.readline

n = int(input())
slots = []
for _ in range(n):
    data = list(map(int, input().split()))
    c_i = data[0]
    slots.append(data[1:])

m = int(input())
banned = set()
for _ in range(m):
    b = tuple(map(int, input().split()))
    banned.add(b)

# Initial build: last item from each slot
init_build = tuple(len(slot) for slot in slots)
init_strength = sum(slots[i][idx - 1] for i, idx in enumerate(init_build))

heap = [(-init_strength, init_build)]
visited = set()
visited.add(init_build)

while heap:
    neg_strength, build = heapq.heappop(heap)
    if build not in banned:
        print(' '.join(map(str, build)))
        break
    for i in range(n):
        if build[i] > 1:
            new_build = list(build)
            new_build[i] -= 1
            new_build = tuple(new_build)
            if new_build not in visited:
                new_strength = -neg_strength - slots[i][build[i]-1] + slots[i][new_build[i]-1]
                heapq.heappush(heap, (-new_strength, new_build))
                visited.add(new_build)
```この解決策は、入力を読み取り、スロット配列を作成することから始まります。 禁止されたビルドは、メンバーシップを迅速にチェックできるようにセットに保存されます。 初期ビルドは各スロットから最後の要素を取得して構築され、可能な限り最大の強度が得られます。 ヒープにより、常に最も強力な未訪問の候補が次に考慮されることが保証されます。 近傍を生成するときは、毎回合計を再計算することを避けるために、古い項目を減算し、新しい項目を加算することによって新しい強度を慎重に計算します。 訪問セットにより、同じビルドを 2 回プッシュすることがなくなり、無限ループや非効率が発生する可能性があります。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(m log m + k n log m) | ヒープにプッシュされる各ビルドは一意であり、答えが見つかるまでに処理されるビルドの数以下です。 ヒープ操作はヒープ サイズのログであり、隣接生成はビルドごとに O(n) です。 |
 | スペース | O(m + k) |`banned`set は O(m) を使用します。`visited`set は、解決策が見つかるまで O(k) ビルドを保存します。 |

 与えられた$n \le 10$そして$m \le 10^5$、アルゴリズムのプロセスは最も強力なものに近いもののみを構築し、時間とメモリの制限内ですぐに終了します。
