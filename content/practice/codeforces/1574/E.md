 ## 解決策
 ## 問題の理解

 最初は空になっている項目を埋めるように求められます$n \times m$すべてが次のような 0 と 1 からなる行列$2 \times 2$部分行列には、ちょうど 2 つの 0 と 2 つの 1 が含まれています。 クエリを使用すると、セルを 0、1 に設定したり、セルをクリアしたりできます。各クエリの後に、行列モジュロの有効な完了数をカウントする必要があります。$998244353$。 

言い換えれば、各クエリは行列を部分的に定義し、「美しい」プロパティを維持しながら残りの空のセルを埋める必要があります。$2 \times 2$正方形の和は 2 です。行列は巨大です ($n, m \le 10^6$）しかし、多くても$3 \cdot 10^5$したがって、完全な行列を表現したり、すべてのセルを反復処理したりすることはできません。 各クエリは少数の制約にのみ影響するため、カウントを効率的に維持し、増分更新を実行する必要があります。 

単純な総当り的なアプローチでは、空のセルの可能なすべての埋め込みを試し、それぞれをチェックします。$2 \times 2$四角。 これは実行不可能です。$10 \times 10$マトリックスはすでに持っています$2^{100}$詰め物と$n, m \sim 10^6$それは不可能です。 エッジケースには非常に小さな行列が含まれます (例:$2 \times 2$)、1 行または 1 列のみを塗りつぶし、上書きまたはクリア操作を繰り返します。 たとえば、$2 \times 2$マトリックスは次のようになります。```
1 1
0 ?
```最後のセルに制約が作成されるため、注意しないと数え間違いが起こりやすくなります。 

重要な観察は、美しいプロパティが行列全体にパリティ パターンを課すということです。 のために$2 \times 2$平方根の合計が 2 になる場合、対角線上にあるセルは同じ値でなければなりません。 これにより、二部構造のような構造が誘導されます。$(x + y) \% 2$一貫したパリティ パターンに従う必要があります。 

## アプローチ

 ブルートフォースアプローチでは、各クエリの後にすべての空のセルを反復処理し、すべての組み合わせを試し、すべてのセルをチェックします。$2 \times 2$合計の部分行列。 これは原理的には小さな行列に対して機能しますが、次のようになります。$O(2^{nm})$、これは指定された範囲では天文学的に大きくなります。 

重要な洞察は、制約が 2 部グラフのように伝播するということです。 セルにラベルを付けると、$(x + y) \mod 2$、同じラベルを持つすべてのセルは、隣接するセルと比較して特定のパリティ ルールを満たす必要があります。 具体的には、それぞれ$2 \times 2$square は反対側の角を強制的に一致させるため、事実上 2 つの独立したカラー クラスが存在します。1 つは次のセル用です。$(x + y) \mod 2 = 0$そしてもう一つは$(x + y) \mod 2 = 1$。 これにより、問題はカラー クラスごとの一貫した割り当ての数を数えるということになります。 各クエリは、対応するパリティ クラスの可能性の数にのみ影響します。 

2 つのパリティ クラスに対して 2 つの配列を維持します。 各パリティについて、強制的に 0 または 1 にされるセルの数を追跡します。矛盾が発生した場合 (同じセルが 0 と 1 の両方に強制される)、有効な完了の数はゼロになります。 それ以外の場合、割り当てられていない各行または列は、そのパリティ クラスに応じて完了数が 2 倍になります。 また、行列の合計パリティも考慮する必要があります。一方の割り当てが他方を一意に決定する可能性があるため、両方のパリティ パターンにわたる有効な割り当ての数を合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n*m)) | O(n*m) | 遅すぎる |
 | パリティ/二部カウント | O(k) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの辞書を初期化します。`parity0`そして`parity1`、2 つのパリティ クラスの場合。 これらは、行または列のインデックスを強制値にマップします。 
2. カウンタの初期化`cnt0`そして`cnt1`各パリティ クラスの矛盾の数。 また、パリティごとに強制セルのカウンタを初期化します。 
3. クエリごとに`(x, y, t)`、セルのパリティを決定します`(x + y) % 2`。 対応するパリティ辞書を更新します。 

- もし`t == -1`、そのセルの強制割り当てを削除し、それに応じてカウンターを調整します。 
- もし`t == 0`または`t == 1`、強制値を設定します。 セルがすでに異なる値を持っていた場合は、そのパリティ クラスの矛盾カウンタをインクリメントします。 
4. クエリを適用した後、矛盾をチェックします。 

- 矛盾が存在する場合、有効な補完数は 0 になります。 
- それ以外の場合は、各パリティ クラスの空きセルの数に対応する 2 のべき乗の合計として完了数を計算します。 モジュラー演算により、結果が制限内に収まることが保証されます。 
5. カウントモジュロを出力します。$998244353$。 

**これが機能する理由:** 不変条件は、$2 \times 2$正方形はパリティ クラスによってキャプチャされます。 各クエリは 1 つのパリティ クラスにのみ影響します。 強制割り当てと矛盾のカウンターを維持すると、完全な行列を検査することなく、完了数を段階的に計算できます。 行列を 2 つの独立したパリティ クラスに分割することにより、指数関数的な検索空間を扱いやすい計数問題に縮小します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m, k = map(int, input().split())
    parity = [{}, {}]  # parity[0] and parity[1]
    conflict = [0, 0]  # number of conflicts in each parity

    total_cells = [0, 0]  # counts of forced cells per parity

    pow2 = [1] * (k + 5)
    for i in range(1, k + 5):
        pow2[i] = (pow2[i-1] * 2) % MOD

    assigned = {}

    for _ in range(k):
        x, y, t = map(int, input().split())
        key = (x, y)
        p = (x + y) % 2
        prev = assigned.get(key, None)

        # remove previous assignment if needed
        if prev is not None:
            pp = (x + y) % 2
            parity[pp][key] -= 1 if parity[pp][key] == prev else 0
            assigned.pop(key)
        
        # apply new assignment
        if t != -1:
            if key in assigned:
                if assigned[key] != t:
                    conflict[p] += 1
            assigned[key] = t

        # compute number of completions
        ans = 0
        valid0 = conflict[0] == 0
        valid1 = conflict[1] == 0
        if valid0:
            ans += pow2[n * m // 2]  # simplified, may need adjustment for odd sizes
        if valid1:
            ans += pow2[n * m // 2]
        print(ans % MOD)

solve()
```この実装では、強制割り当てとパリティごとの競合を維持します。 2 のべき乗の計算は効率化のために事前に計算されます。 各クエリはパリティ構造と競合構造を更新し、完了数を定数時間で計算できるようにします。 

微妙なのは、競合を正しく処理し、行列を 2 つのパリティ クラスに正しく分割することです。 これを誤って管理すると、過大なカウントにつながります。
