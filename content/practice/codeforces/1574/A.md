 ## 解決策
 ## 問題の理解

 有効な括弧シーケンスを生成するように求められます。これは、バランスの取れた括弧を形成する「(」と「)」のみで構成される文字列です。 すべての開始括弧に対応する終了括弧があり、対応する開始括弧の前に閉じ括弧が存在しない場合、シーケンスは有効です。 入力すると数値が得られます$n$、正確に出力する必要があります$n$異なる長さのシーケンス$2n$。 各シーケンスは異なる必要がありますが、シーケンスは異なるテスト ケース間で繰り返すことができます。 

制約は控えめです。$n$は最大 50 まで増加し、テスト ケースは最大 50 個存在する可能性があります。 長さのシーケンス$2n = 100$十分小さいので、効率を気にせずにシーケンスを直接生成できます。 これは、シーケンスをカウントするための高度な組み合わせ生成アルゴリズムや動的プログラミングが必要ないことを意味します。 簡単な構造で十分です。 

微妙な点は、同じシーケンスに対してシーケンスがすべて異なる必要があることです。$n$。 同じバランスの取れたシーケンスを出力する単純なソリューション$n$時間が間違っている可能性があります。 たとえば、次の場合$n = 3$を 3 部印刷します。`"((()))"`失敗するだろう。 個別でありながら有効であることが保証される複数のシーケンスを生成する体系的な方法が必要です。 

エッジケースには以下が含まれます$n = 1$、ここで唯一の有効なシーケンスは`"()"`。 小型用$n$シーケンスがすべて異なる必要があることは見落とされやすく、不注意な文字列連結によって重複や誤ってネストされたシーケンスが生成される可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられる長さのすべての括弧シーケンスを生成しようとします。$2n$そして無効なものを除外します。 シーケンスの数は次のように指数関数的に増加します。$n$として$2^{2n}$。 各シーケンスの有効性をチェックするには、文字列をスキャンし、バランス カウンターを維持する必要があります。 これは非常に小規模な場合に実現可能です$n$、しかし、それは現実的ではなくなります$n$50だから$2^{100}$シーケンスは、プログラムが処理できる範囲をはるかに超えています。 

最適なアプローチでは、有効なシーケンスの構造を利用します。 バランスの取れた長さのブラケットシーケンス$2n$小さなバランスの取れたシーケンスをネストまたは連結することによって構築できます。 体系的に生成する 1 つの方法$n$個別のシーケンスとは、ネストの程度を変えることです。 最も単純なシーケンスから始める`"()()()...()"`の$n$ペア。 次に、最初から徐々にネストして、`"((...))()"`、`"((...))()"`内側の 1 つのペアをシフトするなど。 これにより、ネストされた括弧の位置が異なるため各シーケンスが区別され、ネストによってバランスが保たれるためすべてのシーケンスが有効なままであることが保証されます。 

このアプローチは次の点で線形です。$n$各テストケースに対して、正確に生成されます$n$必要に応じてシーケンスを実行します。 すべての組み合わせの生成を回避し、制御された構築のみに焦点を当てます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(2n) * n) | O(2^(2n) * n) | 遅すぎる |
 | 建設的なネスト | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 テスト ケースごとに、次の内容を読んでください。$n$。 
2. 空のリストを初期化して、$n$このテストケースのシーケンス。 
3. のために$i$1から$n$、次のようにシーケンスを構築します。 場所$i$開き括弧`"("`最初に、その後$i$右括弧`")"`それらを閉じるには。 残りについては$n-i$ペアの場合は、次のように追加します`"()"`順番に。 これにより、各シーケンスが正確に$2n$文字。 
4. 構築された各シーケンスを出力リストに追加します。 
5. 各テスト ケースのシーケンスを順番に出力します。 

それが機能する理由: 最初の$i$ペアはネストされており、残りのペアはフラットです。 の各値$i$異なる入れ子パターンが生成されるため、シーケンスが区別されます。 ネストすると、すべての開始括弧に一致する終了括弧が存在し、終了括弧の後に出現することがなくなり、有効性の不変性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def generate_sequences(n):
    sequences = []
    for i in range(1, n+1):
        seq = '(' * i + ')' * i + '()' * (n - i)
        sequences.append(seq)
    return sequences

t = int(input())
for _ in range(t):
    n = int(input())
    result = generate_sequences(n)
    for seq in result:
        print(seq)
```の`generate_sequences`function には、核となる建設的なアイデアがカプセル化されています。 各シーケンスについて、最初のネストされたペアの数は 1 から$n$。 残りのペアはフラットとして追加されます`"()"`シーケンス。 これにより、ネスト時の off-by-one エラーが回避され、シーケンスが明確に区別されることが保証されます。 文字列の乗算を使用すると、繰り返しの作成が簡素化されます。`"("`または`")"`文字を入力して、間違いの可能性を減らします。 高速入力により、複数のテスト ケースを効率的に読み取ることができます。 

## 実用的な例

 のために$n = 3$、生成されるシーケンスは次のとおりです。 

| 私 | シーケンス |
 | --- | --- |
 | 1 |`()()()`|
 | 2 |`(()())`|
 | 3 |`((()))`|

 段階的に、i = 2 の場合: 2 つの左括弧を配置します。`"((`"、その後 2 つのクローズ`"))"`、残りの 1 つのペアを次のように追加します。`"()"`。 結果は`"(()())"`。 各シーケンスには長さがあります$2*3 = 6$そしてバランスが取れています。 

のために$n = 1$:

 | 私 | シーケンス |
 | --- | --- |
 | 1 |`()`|

 このエッジ ケースでは、次の最小値が$n$長さ 2 の有効なシーケンスが生成されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2) | 各シーケンスについて、長さ 2n の文字列連結は O(n) であり、n シーケンスにわたって繰り返されます。 
| スペース | O(n^2) | 長さ 2n の n 個のシーケンスを保存する |

 と$n \le 50$、合計操作はテスト ケースごとに約 50 * 100 = 5000 であり、2 秒の制限内に十分収まります。 メモリの使用量は、テスト ケースあたり約 5000 文字で無視できます。

 ## 特殊なケース

 n = 1 の場合、有効なシーケンスは次のとおりです。`"()"`。 アルゴリズムはまさにこのシーケンスを構築によって生成します。 

n が大きい場合は、n = 3 を考慮してください。1 から 3 までの各 i は個別のシーケンスを生成します。 i = 1 のシーケンスは完全にフラットで、i = 2 にはネストされたペアが 1 つあり、i = 3 は完全にネストされています。 この構造により、同一のシーケンスが 2 つ存在せず、すべてのシーケンスが有効であることが保証されます。 これは、このアプローチが最小の n と中程度に小さい n の両方を正しく処理することを示しています。
