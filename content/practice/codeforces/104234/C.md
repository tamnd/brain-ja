 ## 解決策
 ## 問題の理解

 私たちは、1 から n までの隠された数字を特定しようと繰り返し試みています。 隠れた数値は一様に選択されません。各値 i には特定の重み p_i があり、正解である実際の確率はこれらの重みに比例します。 推測が外れるたびに実験はリセットされ、パラメータ c に応じて、隠れた数値が同じ分布から再サンプリングされるか、変更されないままになります。 

事前に固定の推測戦略を選択することができます。推測するたびに、確率 q_i でインデックス i を選択します。 推測が隠された数字と一致する場合、プロセスは終了します。 それ以外の場合は失敗し、別のラウンドが始まります。 

目標は、成功するまでの予想される推測数を最小限にする分布 q を選択することです。 

重要な微妙な点は、(c に応じて) 隠れた数値がいくつかの失敗にわたって持続する可能性があるにもかかわらず、ソルバーの観点からは各ラウンドが定常プロセスの下での新たな試行のように動作することが実験によって保証されることです。 つまり、プロセス全体は、p と q によって同時に引き起こされる推測ごとの成功確率を理解し、それを最適化することに帰着します。 

制約では n は最大 100,000 まで許可されるため、解は最大でも O(n log n) または O(n) でなければなりません。 すべての分布に対する二次関数またはシミュレーションベースのアプローチは、直ちに実行不可能です。 

一般的な失敗モードは、貪欲に推測する (最も可能性の高い p_i を常に選択する) ことが最適であると仮定することです。 目的は p のモードだけでなく 2 つの分布間の相互作用に依存するため、その直感は崩れます。 

もう 1 つの微妙な落とし穴は、c の効果を無視することです。 ラウンド間にメモリが導入されているように見えますが、定常的な成功率構造は変化せず、試行間の相関関係のみが変化します。 単純なシミュレーションやマルコフ連鎖展開は、期待を打ち消す履歴への依存性を誤って示唆する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、n 個の結果にわたって q 個の可能なすべての推測分布を列挙し、それぞれについて予想される試行回数を計算しようとします。 確率を離散化したとしても、探索空間は n において指数関数的であり、非常に小さい n を超えると粗いサンプリングさえ不可能になります。 

2 番目の単純なアイデアは、毎回最も可能性の高い値を推測し、実質的に q を argmax p_i でのデルタ分布に設定することです。 これは高速ですが、成功確率が p 単独だけでなく p と q の重複に依存することを無視しているため、必ずしも最適であるとは限りません。 

重要な洞察は、各推測が 2 つの分布 p と q の内積によって決定される確率で成功することを認識することです。 これが観察されると、予想される推測数はその成功確率の逆数になります。 問題は、q が確率分布であるという制約の下でこの内積を最大化することに帰着します。 

これは、シンプレックスに対する制約付きの最適化問題です。 この構造は、すべての確率質量を p の最もよく調整された座標に集中させることが最適であることを意味しますが、p の正規化の存在により、その調整の動作が変化します。 確率的スケーリングを単純化した後、目的は p_i の合計を含む比率の最適化に減ります。 

隠れた数値がリサンプリングされるかどうかは、定常状態における試行ごとの成功確率には影響せず、試行間の一時的な相関のみが変化するため、c の効果は定常期待値では消滅します。

 ## アルゴリズムのチュートリアル

 S をすべての p_i の合計として示し、正規化された確率分布 p_i / S を扱います。

1. すべての結果の合計重みである S を計算します。 これにより、指定された重みが隠れた数値の実際の確率分布に変換されます。 
2. 任意の固定推測分布 q の場合、単一の推測の成功確率は、隠れた数字が i と等しく、i を推測する確率 (p_i / S) * q_i の i にわたる合計であることに注目してください。 これは、p と q の間の双一次形式です。 
3. 隠れ状態の永続性にもかかわらず、各試行は分布効果において独立しているため、成功するまでの予想される推測数はこの成功確率の逆数になります。 
4. 予想される推測を最小限に抑えるために、成功確率の合計(p_i * q_i)を最大化します。 q は単体上にあるため、最大の p_i を持つインデックスにすべての質量を集中させることによって、これが最大化されます。 
5. したがって、p_k が最大であり、他のすべての q_i がゼロである q_k = 1 を設定します。 
6. 結果の成功確率は max(p_i) / S となり、予想される推測数は S / max(p_i) となります。 

### なぜ効果があるのか

 重要な不変条件は、過去の結果や隠れた値が再サンプリングされたかどうかに関係なく、すべての試行の限界成功確率が同じであるということです。 c パラメータは、単一の試行の期待値ではなく、連続する隠れ状態間の相関にのみ影響します。 期待値は試行ごとのわずかな成功にのみ依存するため、プロセスは p と q のオーバーラップに等しいパラメータを持つ幾何学的分布に崩壊します。 シンプレックス上で線形関数を最適化すると、常にすべての質量が単一のインデックスに対応する極点に配置されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, c = map(int, input().split())
    p = list(map(int, input().split()))
    
    s = sum(p)
    mx = max(p)
    
    print(s / mx)

if __name__ == "__main__":
    main()
```実装は、2 つの単純な集計の比率への削減の直後に行われます。 必要な唯一の注意は、必要な精度を満たすために浮動小数点除算を使用することです。 

重要なステップは、状態に対する動的プログラミングが必要ないことを認識することです。 正しい成功確率が特定されると、確率的プロセス全体が単一の幾何学的期待値に崩壊します。
