 ## 解決策
 ## 問題の理解

 数値の配列が与えられ、それを任意に並べ替えることができます。 選択した順序ごとに、隣接する要素間の連続した差分で構成される 2 番目の配列を構築します。 タスクは、元のマルチセットの異なる順列の数を数えることで、前後に同じものを読み取る差分配列が生成されます。 

入力は複数のテスト ケースであり、各テスト ケースは整数の複数セットを返します。 2 つの順列は、少なくとも 1 つの位置が異なる場合、異なるものとみなされます。 答えはモジュロで計算されます$10^9 + 9$。 

合計に関する制約$n$テストケース全体で到達$5 \cdot 10^5$強制的に$O(n \log n)$またはテストケースごとの線形ソリューション。 順列の列挙、さらには位置のペアの明示的な列挙を伴うものは直ちに実行不可能です。$n!$たとえ成長が早すぎる$n = 20$。 

すべての要素が同一である場合、微妙なエッジケースが発生します。 すべての順列は同一であり、すべての差分配列はすべてゼロであり、これは自明のことながら回文です。 正しい解は、1 ではなく、多項カウントを返す必要があります。もう 1 つの自明ではないケースは、値が異なるが、一貫した構造に対称的にペアにすることができない場合であり、有効な順列が 0 になるはずです。 

## アプローチ

 ブルートフォースアプローチでは、マルチセットのすべての個別の順列を生成し、それぞれをチェックします。 各順列について、その差分配列を計算し、それが回文であるかどうかを検証します。 チェックを最適化したとしても$O(n)$、これにはまだ費用がかかります$O(n \cdot n!)$、それは限界をはるかに超えています。 

重要な観察は、差異に対する回文性の制約により、順列自体に強い対称性が生じるということです。 条件を書き出して、反対の違いを比較します。$$(p_{i+1} - p_i) = (p_{n-i+1} - p_{n-i})$$これを並べ替えると次のようになります。$$p_{i+1} + p_{n-i} = p_i + p_{n-i+1}$$これは、すべての対称的な位置のペアの合計が同じであることを意味します。 その合計は定数です$C$、インデックスとは独立しています。 

したがって、有効な順列はすべて次の条件を満たす必要があります。$$p_i + p_{n-i+1} = C$$これにより、問題は差異に関するグローバル条件からペアリングの問題に変換されます。つまり、各ペアの合計が同じ定数になるように、すべての要素が別の要素と一致する必要があります。 

この構造が認識されると、並べ替えはもはや恣意的ではなくなります。 マルチセットからの値を効果的にペアリングしているため、各ペアは次のようになります。$(x, C-x)$必要な回数だけ使用されます。 

ブルート フォースは順列を直接探索するため失敗しますが、正しいアプローチでは、すべてが固定合計制約の下で有効なマルチセットのペアを数えることになります。

 ## アルゴリズムのチュートリアル

 次に、構造観察を計数手順に変換します。 

1. マルチセット内の最小値と最大値を計算します。 これらは有効な置換において対称位置を占める必要があるため、それらの合計により定数が決まります。$C = \min(a) + \max(a)$。 最小の要素は可能な限り最大の補数とペアになる必要があるため、これが強制されます。 
2. すべての値の頻度マップを作成します。 それぞれの値をペアリングしてみます$x$と$C-x$。 必要な補数が存在しない場合、有効な並べ替えはできません。 
3. 各値について$x$、その補数と比較します$y = C-x$。 各ペアを 1 回だけ処理するため、次のような場合を考慮します。$x < y$、$x = y$、スキップしてください$x > y$。 
4. もし$x < y$、のすべての出現$x$の出現とペアにする必要があります$y$。 これには必要です$\text{freq}[x] = \text{freq}[y]$。 このような各ペアは貢献します$\text{freq}[x]$対称位置ペア。 
5. もし$x = y$、値はそれ自体とペアになります。 要素をペアに分割する必要があるため、これには偶数の周波数が必要です。 提供されるセルフペアの数は、$\text{freq}[x] / 2$。 
6. もし$n$奇数の場合、対になっていない中心要素が 1 つあります。 これは満足するはずです$2 \cdot x = C$、中心値が正確に一致する必要があることを意味します$C/2$、ペアリング後にちょうど 1 つの要素が残るように、奇数の頻度を持つ必要があります。 
7. すべての制約を検証した後、結果のペアの配置をカウントします。 あると仮定します$m = \lfloor n/2 \rfloor$合計ペア。 これらのペアは、$m$対称的な位置であり、次の要因に寄与します。$m!$。 
8. 複数の同一のペアタイプが存在する場合、同一のペア間の区別できないスワップを考慮して、それらの階乗多重度で除算します。 
9. すべての非対称ペアについて$(x, C-x)$と$x \ne y$、各ペアは対称位置にわたって 2 つの方法で配向でき、次の要因に寄与します。$2$そのようなペアごとに。 

### なぜ効果があるのか

 重要な不変条件は、すべての有効な順列がインデックスの完全な一致を引き起こすということです。$(i, n-i+1)$、差分回文条件により、一致するすべてのペアが同じ和を共有するように強制されます。 これにより、順列構造が独立した順序のないペア ブロックに崩壊します。 マルチセットがこれらのブロックに分割されると、どのような配置も、これらのブロックを並べ替え、オプションで非対称ペアの方向を選択することに正確に対応し、カウント式は過剰カウントせずにそれを捕捉します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

MOD = 10**9 + 9

MAXN = 5 * 10**5 + 5
fact = [1] * (MAXN)
for i in range(1, MAXN):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (MAXN)
inv_fact[MAXN - 1] = pow(fact[MAXN - 1], MOD - 2, MOD)
for i in range(MAXN - 2, -1, -1):
    inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        cnt = Counter(a)

        if n == 2:
            out.append(str(2 % MOD))
            continue

        mn, mx = min(a), max(a)
        C = mn + mx

        used = set()
        ok = True
        pairs = Counter()
        odd_center = 0
        asym_pairs = 0

        for x in list(cnt.keys()):
            if x in used:
                continue
            y = C - x
            if y not in cnt:
                ok = False
                break

            if x == y:
                if cnt[x] % 2:
                    if n % 2 == 0:
                        ok = False
                        break
                    odd_center += 1
                    if odd_center > 1:
                        ok = False
                        break
                pairs[x] = cnt[x] // 2
            else:
                if cnt[x] != cnt[y]:
                    ok = False
                    break
                pairs[x] = cnt[x]
                asym_pairs += cnt[x]
                used.add(y)

        if not ok:
            out.append("0")
            continue

        total_pairs = sum(pairs.values())
        m = n // 2

        if total_pairs != m:
            out.append("0")
            continue

        res = fact[m]

        for k in pairs.values():
            res = res * inv_fact[k] % MOD

        res = res * pow(2, asym_pairs, MOD) % MOD

        out.append(str(res))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装では、最初に最小値と最大値を使用してグローバル ペアリングの合計をロックします。 次に、すべての値がその補数とペアにできることを検証し、ペアタイプのマルチセットを構築します。 階乗と逆階乗は事前に計算されており、これらのペアが対称位置に沿ってどのように配置されているかを多項式で高速に計数できるようになります。 2 の累乗は、非対称ペアにおける方向の自由度を説明します。 

各値と補数のペアは 1 回のみ処理するように注意する必要があります。そうしないと、カウントが誤って複製されます。 奇数のセンター処理$n$分離されるのは、ペアリングに参加せず、組み合わせ構造が破損するためです。

 ## 特殊なケース

 すべての要素が同一の場合、アルゴリズムは次のように設定します。$C = 2x$そしてすべての要素を自己ペアとして扱います。 すべての組み合わせが同一であるため、多項式は 1 に減り、この条件下ではすべての順列が区別できないという事実と一致します。 

ある値に対して有効な補数が存在しない場合、たとえ 1 つの欠落ペアでも全体的な対称性の要件が破られるため、アルゴリズムは構成を即座に拒否します。 

奇数の場合$n$、中心要素は正確に$C/2$。 複数の候補がペアになっていないままである場合、対称構造には中心位置が 1 つだけ存在するため、アルゴリズムはそのケースを拒否します。
