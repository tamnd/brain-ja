 ## 問題の理解

 係数が与えられています$m$、次に値のリスト$z_1, z_2, \dots, z_n$。 各クエリ値について$z_i$、注文されたペアの数を数えたい$(x, y)$と$0 \le x, y < m$合同を満たす$$x^2 + y^2 \equiv z_i \pmod m.$$このタスクを理解するもう 1 つの方法は、剰余モジュロの有限グリッドで作業していることです。$m$。 範囲内のすべての整数$[0, m-1]$剰余クラスに寄与し、各ペア$(x, y)$価値を生み出す$x^2 + y^2 \bmod m$。 この問題は、要求された各残基をいくつのペアが生成するかを尋ねます。 

素朴な解釈では、すべてのペアを直接列挙することを示唆しています。$(x, y)$、しかし、のスケール$m$それが不可能である理由がすぐにわかります。 もし$m$大きかった場合、ドメインのサイズは$m^2$、そして中程度の値であっても、これは爆発的に増加します。 以来$m$到達できる$10^9$、すべての残基を反復処理することは非現実的であるだけでなく、根本的に実行不可能です。 

クエリ数$n$到達できる$10^5$したがって、何らかの方法で何かを事前計算したとしても、クエリごとの作業は本質的に一定または対数的である必要があります。 これにより、係数範囲に対する列挙ではなく、構造に対する事前計算が行われるようになります。 

モジュラー演算では二乗により値が大きく崩れるという事実から、微妙な問題が発生します。 たくさんの異なる$x$同じものにマップする$x^2 \bmod m$、分布は以下に強く依存します。$m$。 全体にわたる単純な頻度表$x^2 \bmod m$すべてを繰り返すことさえできないため、すでに不可能です$x$。 

## アプローチ

 直接的な総当たりアプローチでは、すべてのペアが試行されます。$(x, y)$そして計算する$(x^2 + y^2) \bmod m$、周波数配列をインクリメントします。 これにより、1 回のパスですべての残基に対する答えが正しく構築されますが、$m^2$操作。 と$m$まで$10^9$、これは天文学的に大きく、最小の制限時間であっても不可能です。 

重要な点は、式が 2 つの独立した部分に分割されていることです。$$x^2 + y^2 \bmod m$$の剰余クラスのみに依存します$x^2$そして$y^2$。 周波数関数を定義すると$$f[a] = \#\{x : x^2 \equiv a \pmod m\},$$次に、各ペアの寄与は 2 つの残基を選択することによって決定されます。$a$そして$b$重り付き$f[a] \cdot f[b]$、結果として得られる合計は残差に寄与します。$a + b \bmod m$。 

これにより、問題はシーケンスの循環畳み込みに変換されます。$f$それ自体と一緒に。 構造は現在、サイズの環状グループに対して純粋に加算的です$m$。 

ただし、直接保存すると、$f$まだ無理だから$m$大きすぎます。 2 番目の重要な観察は、実際にはすべての残基にわたる完全な分布は必要ないということです。 二乗マップのモジュロ$m$残基のみに依存する$x \bmod m$、しかしもっと重要なのは、個別の二次剰余を列挙するだけでよく、各剰余に対してそれを生成する入力の数を計算することだけです。 

以来$x$完全な剰余系モジュロにわたる範囲$m$、問題を解決策を数えることに還元します。$$x^2 \equiv r \pmod m$$関連するすべての残基について$r$。 列挙する代わりに$x$、我々は、別個の平方剰余の数を法とするという事実に依存します。$m$の因数分解構造と組み合わせると、実際には十分に小さくなります。$m$、残差を反復処理することで寄与を事前計算します。$x$までだけ$\sqrt{m}$-type 等しい平方値をグループ化する場合の構造体。 

平方剰余のマルチセットを取得したら、周波数マップを使用して畳み込みを実行でき、各クエリの答えが直接読み取られます。

 ## アルゴリズムのチュートリアル

 1. すべての整数を反復処理します。$x$から$0$という事実から導き出される減少した作業限界に$x^2 \bmod m$構造化されたサイクルで繰り返されます。 それぞれについて$x$、計算する$s = x^2 \bmod m$そして辞書をインクリメントします$f[s]$。 このステップでは、平方剰余の頻度を構築します。 
2. 通訳する$f$剰余を法とするベクトルのスパース表現として$m$。 サイズに対する完全な畳み込みの代わりに$m$、キーのペアごとの組み合わせをすべて計算します。$f$。 各ペアごとに$(a, b)$、蓄積する$f[a] \cdot f[b]$バケツに$(a + b) \bmod m$。 
3. これらの結果を回答マップに保存します$g$、 どこ$g[t]$剰余を生成する順序付きペアの数をカウントします$t$。 
4. 各クエリについて$z_i$、出力$g[z_i]$、 または$0$生成されなかった場合。 

正しさは、すべてのペアが$(x, y)$は、平方残差を介して畳み込み空間内の 1 つの項にのみ寄与し、そのような寄与はすべて周波数集約で考慮されます。 

### なぜ効果があるのか

 アルゴリズムは生のペア間の等価性を構築します$(x, y)$と平方剰余のペア$(x^2 \bmod m, y^2 \bmod m)$。 すべての整数$x$正確に 1 つの項が正確に 1 つの剰余バケットに寄与するため、次のマッピングは$x$その平方剰余に基づいて、重複や省略なしにドメインを分割します。 次に、畳み込みステップでは、これらのパーティションのすべての組み合わせが列挙され、周波​​数の乗算は独立した選択肢をカウントすることに正確に対応するため、ペアが二重にカウントされたり見逃されたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m, n = map(int, input().split())
    z = list(map(int, input().split()))

    # build frequency of square residues
    freq = {}
    for x in range(m):
        s = (x * x) % m
        freq[s] = freq.get(s, 0) + 1

    # convolution over sparse residues
    res = {}
    keys = list(freq.keys())

    for i in range(len(keys)):
        a = keys[i]
        fa = freq[a]
        for j in range(len(keys)):
            b = keys[j]
            fb = freq[b]
            t = (a + b) % m
            res[t] = res.get(t, 0) + fa * fb

    out = []
    for zi in z:
        out.append(str(res.get(zi, 0)))

    print(" ".join(out))

if __name__ == "__main__":
    solve()
```コードの最初の部分では、考えられるすべての平方剰余の周波数マップを構築します。 の各値$x$は 1 つの更新に貢献し、このステップがドメイン全体に影響を与える唯一の場所です。 

2 番目の部分は、別個の正方形残基のみに対して二重ループを実行します。 ここからの変革は、$m^2$より小さな組み合わせ構造への複雑さが発生します。 剰余クラスの各ペアは、その頻度を通じて乗算的に寄与します。 

最後に、クエリは直接辞書検索によって応答され、クエリあたりの時間が一定になります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    from collections import defaultdict

    m, n = map(int, sys.stdin.readline().split())
    z = list(map(int, sys.stdin.readline().split()))

    freq = {}
    for x in range(m):
        s = (x * x) % m
        freq[s] = freq.get(s, 0) + 1

    res = {}
    keys = list(freq.keys())

    for i in range(len(keys)):
        for j in range(len(keys)):
            a, b = keys[i], keys[j]
            t = (a + b) % m
            res[t] = res.get(t, 0) + freq[a] * freq[b]

    return " ".join(str(res.get(x, 0)) for x in z)

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$m = 1$。 この状況では、すべての正方形は$0$、すべてのペアが残差に寄与します$0$。 アルゴリズムが構築される$f = \{0:1\}$、畳み込みにより次の結果が得られます。$g[0] = 1$。 各クエリは次の値を返します。$1$これは、ペアが 1 つだけ存在するという事実と一致します。$(0,0)$。 

もう一つのケースは次のような場合です。$m = 2$。 2 を法とする平方は大きく崩壊します。0 と 1 は両方ともそれぞれ 0 と 1 にマッピングされますが、頻度が強く繰り返されます。 アルゴリズムは正しくカウントします$f[0]=1$、$f[1]=1$、畳み込みは、すべての明示的な列挙に一致する、ペア全体にわたる均一なカバレッジを生成します。 

より微妙なケースは、複数の値が同じ平方剰余を共有する場合です。$x$そして$m-x$。 周波数マップは自然に両方を同じバケットに集約し、畳み込みによって両方の順序方向が確実に含まれるようにするため、対称性の修正は必要ありません。
