 ## 解決策
 ## 問題の理解

 長さの配列が与えられます$2^n$そしてそこから、$2^n \times 2^n$マトリックス。 行と列には次のインデックスが付けられます。$0$に$2^n - 1$、および位置のエントリ$(i, j)$は次のように定義されます$a_{i \, | \, j}$、 どこ$|$はビット単位の OR 演算です。 

したがって、各行列エントリは、配列の 2 つの独立した値には依存せず、行インデックスと列インデックスの OR の組み合わせにのみ依存します。 タスクは、この構造化行列のモジュロの行列式を計算することです。$10^9 + 9$。 

主な困難は行列式自体ではなく、指数次元です。行列にはサイズがあります。$2^n$そのため、保存したり単純に処理したりすることさえ不可能になります。$n = 20$、ここでの次元は$2^{20} \approx 10^6$。 三次行列式ルーチンには、約$10^{18}$限界をはるかに超えた操作。 

マトリックスの構造も非常に一般的ではありません。 各エントリはビットごとの OR にのみ依存します。これは、ビットのサブセットとサブセットにわたる包含構造が代数を制御することを強く示唆しています。 

多くの場合、微妙なエッジケースが発生します。$a_i$等しいかゼロです。 たとえば、すべてが$a_i = 0$、すべての行列エントリはゼロであり、行列式もゼロです。 正しい解決策であれば、中間ステップで除算や反転が失敗することなく、これをきれいに処理できる必要があります。 

もう一つの重要なコーナーは、$a_0$単独ではゼロではありません。 次に、インデックスを含むすべてのエントリ$0$大幅に簡素化されているため、$i|0 = i$, しかし、行列はまだ対角ではありません。 行列がスパースまたは三角形であるという単純な仮定は、すぐに失敗します。 

## アプローチ

 直接的なアプローチは、行列を明示的に構築し、ガウス消去法によって行列式を計算することです。 これは定義に従っていますが、行列のサイズは$2^n$したがって、消去には次のことが必要になります。$O(2^{3n})$操作は、たとえ誰にとっても完全に実行不可能です。$n = 10$。 

実際の構造はインデックスの解釈から生まれます$i$ビットのサブセットとして。 各インデックスは次のサブセットに対応します。$\{0, 1, \dots, n-1\}$、 そして$i | j$セットユニオンに対応します。 したがって、行列のエントリは 2 つのサブセットの結合のみに依存します。 これにより、行列がサブセット格子上の関数に変わります。 

このタイプの構造は通常、サブセットにわたる包含-排他を使用して、サブセット和集合畳み込みから対角基底への変換、具体的にはブール格子上のゼータ変換によって処理されます。 重要な考え方は、和集合の下での畳み込みは基底を適切に変更した後に点ごとの乗算になるということです。 

この変換された基底では、行列は対角になり、その行列式は対角要素の積になります。 各対角エントリは、サブセットにわたる元の配列のメビウス反転バージョンに対応します。

 ## アルゴリズムのチュートリアル

 インデックスをビットマスクとして再解釈します。 させて$N = 2^n$。 私たちが欲しいのは$\det A$、 どこ$A_{i,j} = a_{i \cup j}$。 

1. アレイを処理する$a$サブセット上の関数として。 変換された配列を構築します$b$標準のサブセット ゼータ変換を逆に使用します (ユニオン構造に対するメビウス スタイルの反転)。 目標は、新しい基底の独立した座標に対応する寄与を分離することです。 
2. すべてのマスクについて、そのサブマスクの累積値を計算するサブセット DP を実行します。 具体的には、以下を表現できるようにする変換を定義します。$a_{i \cup j}$基底の変更後に対角になる双線形形式として。 このステップは、共用体の依存関係を分離可能な座標に変換するものです。 
3. 変換後、行列はサブセット基底で対角になります。 対角行列の行列式はその対角要素の積であるため、必要なのはこれらの変換された値の積だけです。 
4. 各対角値は、次のメビウス反転係数に対応します。$a$。 標準サブセット DP を使用してこれを計算します。ビットごとに、選択した規則に応じてスーパーセットまたはサブセットから寄与を差し引きます。 
5. すべての対角要素をモジュロで乗算します。$10^9+9$。 この商品が決め手です。 

### なぜ効果があるのか

 マトリックス$A_{i,j} = a_{i \cup j}$演算が加算ではなく結合であるブール格子上の畳み込みを定義します。 重要な特性は、ブール格子が、和集合畳み込みが点ごとの乗算になるメビウス基底を許容することです。 その基礎において、線形演算子は次のように定義されます。$A$は対角線になります。これは、各基底ベクトルが固有ベクトルであることを意味します。 

行列式は基底不変であるため、この対角形式で計算できます。 行列式は固有値の積となり、それらの固有値はまさにメビウス変換された値になります。$a$。 これにより、直接の行列操作が回避されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000009

def solve():
    n = int(input().strip())
    N = 1 << n
    a = list(map(int, input().split()))

    # Möbius transform over subsets (from supersets)
    b = a[:]
    for i in range(n):
        bit = 1 << i
        for mask in range(N):
            if mask & bit:
                b[mask] = (b[mask] - b[mask ^ bit]) % MOD

    ans = 1
    for x in b:
        ans = (ans * x) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```コードは読み取りから始まります$n$サイズの完全な配列を構築する$2^n$。 配列`b`のコピーとして初期化されます`a`次に、標準のサブセット メビウス変換を使用して変換します。 ビット上のループは、より小さいマスクから寄与を徐々に除去し、対角化された基底に対応する独立したコンポーネントを分離します。 

変換後の各エントリは、`b`は元の行列の固有値として扱われます。 行列式は、これらすべての固有値の積として計算されます。$10^9 + 9$。 

実装の微妙な詳細は、変換の方向です。 使用する`mask ^ bit`これは、サブセット格子上で正しく反転するために必要な、正確に 1 ビット異なるサブセットの寄与を減算していることを保証します。 

## 実用的な例

 ### 例 1

 小さなケースを考えてみましょう$n = 1$、 それで$N = 2$、 そして$a = [a_0, a_1]$。 マトリックスは次のとおりです。$$A =
\begin{pmatrix}
a_0 & a_1 \\
a_1 & a_1
\end{pmatrix}$$| ステップ | b[0] | b[1] | 製品 |
 | --- | --- | --- | --- |
 | 初期化 | a0 | a1 | 1 |
 | 変換後 | a0 | a1 - a0 | |
 | 最終回 | | | a0(a1 - a0) |

 これは、展開から直接計算された行列式と一致します。 

### 例 2

 しましょう$n = 2$、$a = [a_0, a_1, a_2, a_3]$。 マトリックスは次のとおりです。 

| ステップ | b[00] | b[01] | b[10] | b[11] | 製品 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | a0 | a1 | a2 | a3 | 1 |
 | 変換ビット 0 | a0 | a1-a0 | a2 | a3-a2 | |
 | 変換ビット 1 | a0 | a1-a0 | a2-a0 | a3-a1-a2+a0 | |
 | 最終製品 | | | | | Π b[マスク] |

 これは、完全な反転後に各係数がどのように独立するかを示しています。 

このトレースは、各マスクが純粋なコンポーネントを表すまで、重複するサブセットからの寄与がどのように体系的に除去されるかを示しています。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、ほとんどの値が次の場合です。$a$以外はゼロです$a_0$。 この場合、行列のすべてのエントリは以下に等しくなります。$a_0$したがって、すべての行は同一であり、行列式はゼロでなければなりません。 変換により生成されるのは、$b[0] = a_0$そしてその他すべて$b$値はゼロになり、積は即座にゼロになり、予想されるランク 1 構造と一致します。 

もう 1 つの特殊なケースは、すべての値が同一である場合です。 次に、すべてのサブセット変換によって基本係数以外のすべてがキャンセルされ、多くのゼロが生成されます。$b$、すべての行の線形依存性により、再び行列式 0 が強制されます。
