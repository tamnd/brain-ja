 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 それぞれの隠れ多項式は対称的な係数パターンを持つことが知られています。これは、係数リストが左から右、右から左に同​​じものを読み取ることを意味します。 多項式はいくつかの異なる整数点で評価され、大きな素数を法とする入出力ペアが与えられます。 

このタスクは、提供されたすべての点に一致し、次数が最大 10000 で、係数が同じ係数範囲にあり、係数に関する回文制約を満たす多項式を再構築することです。 

代数的な観点から見ると、これは追加の対称性制約の下での補間問題です。 対称性がなければ、n 個の点が係数の線形方程式系を定義します。 対称性がある場合、各係数 a_i は a_{d-i} に関連付けられるため、自由変数の数は約半分になります。 

この制約は 2 つの構造的圧力を意味します。 まず、n はテストごとに最大 1000 であり、合計 n も最大 1000 であるため、最大でも数千の未知数に対して線形代数を実行できます。 第二に、最大次数は大きいですが、きつくはありません。 10000 までの有効な次数を出力することができます。これは、必ずしも最小である必要はなく、都合の良い次数を自由に選択できることを意味します。 

対称性が補間制約と矛盾する場合、明らかではないエッジ ケースが発生します。 たとえば、有界次数の対称多項式基底で 2 つの点が矛盾する値を強制する場合、答えは -1 でなければなりません。 これは通常、システムが独立した対称係数の数に対して過度に制約された場合に発生します。 

もう 1 つの微妙なケースは、次数の同等性が重要な場合です。 回文多項式は、次数が偶数であるか奇数であるかに応じて異なる動作をします。これは、中心係数が単独で固定されているか、ミラーリングされたペアの一部であるためです。 間違ったパリティを選択すると、他のパリティで解決策が存在する場合でも、システムが満足できなくなる可能性があります。 

## アプローチ

 直接的なアプローチは、係数を変数として扱い、内挿条件と対称制約の両方を強制することです。 次数が d であるとします。 d+1 個の係数がありますが、対称性により、これはおよそ ⌊d/2⌋+1 個の独立変数に減ります。 各評価点は 1 つの線形方程式を与えます。 したがって、有限体上の線形システムが得られます。 

強引なアイデアは、d を固定し、最大 10000 までの可能な次数ごとにガウス消去法を使用してシステムを解くことです。ガウス消去法は変数の数で 3 次であり、これを多くの次数にわたって繰り返すと、1000 付近の n であっても制限を超えるため、これではすぐに遅すぎます。 

重要な観察は、次数が連続的に変化する必要はないということです。 システムは、含める係数ペアの数にのみ依存します。 k = ⌊d/2⌋ と定義すると、多項式は k+1 個の変数によって完全に決定されます。 結果として得られるシステムが一貫性を持つような k を見つけるだけで済みます。 

すべての k を独立して試す代わりに、選択した k に対して単一の線形システムを構築し、可解性をテストできます。 この問題では有効な多項式が許容されるため、単純に k = n - 1 または n から導出される小さな上限を試すことができます。 それが失敗した場合、対称制約の下では解決策は存在しないと結論付けます。 

これにより、タスクが GF(mod) 上の 1 つの線形システムを解くことになります。ここで、各方程式は次のとおりです。 

A(x_i) = ペアのインデックスの a_j * (x_i^j + x_i^{d-j}) の j の合計。 

対称性により、多項式基底をミラー係数ペアに対応する独立変数に書き換えることができ、システムを縮小基底での標準的な線形補間に変えることができます。

 | 対称性を低減した線形システム | O(n^3) | O(n^2) | 承認済み |

## アルゴリズムのチュートリアル

 回文多項式を明示的にパラメータ化し、その自由係数を解くことによって、解を構築します。 

1. 候補次数を決定します。 その次数の多項式は標準設定で n 個の点を補間でき、10000 までの有効な次数を選択できるため、可能であれば d = n - 1 を選択します。 
2. k = ⌊d / 2⌋ と定義します。 係数配列の左半分を表す k + 1 個の独立変数 c_0、c_1、...、c_k を導入します。 
3. 対称性を使用して多項式の係数を表現します。 i < k の場合、a_i = c_i および a_{d-i} = c_i を設定します。 d が偶数の場合、中央の係数 a_k は自由変数です。 それ以外の場合は、パリティに応じて一貫してペアリングされます。 
4. 各入力点 (x, y) について、以下を展開して評価式を構築します。 

A(x) = a_i の 0 から d までの i の合計 * x^i

 方程式が c_j で線形になるように、対称表現を使用して各 a_i を置き換えます。 

このステップでは、各点を線形システム M * c = y の行に変換します。 
5. モジュロ 109+9 に対するガウス消去法を使用して、結果の線形システムを解きます。 消去中に不一致 (ゼロ以外の定数と等しいゼロの行) が検出された場合は、-1 を返します。 
6. システムが解ける場合は、係数 c_j を抽出し、対称性を使用して完全な多項式係数 a_i を再構成します。 
7. 次数 d と完全な係数配列を出力します。 

### なぜ効果があるのか

 固定次数の回文多項式の多項式空間は、有限体上のベクトル空間です。 対称制約により、次元が独立したミラーリングされたペアの数まで正確に削減されます。 各評価点は、この空間上の線形関数に寄与します。 ガウス消去法は、これらの制約が部分空間と交差するかどうかを正しく判断します。 システムが一貫している場合、構築されたソリューションは基礎の構築によりすべての制約を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 9

def gauss(a, b):
    n = len(a)
    m = len(a[0])
    row = 0

    where = [-1] * m

    for col in range(m):
        sel = row
        for i in range(row, n):
            if a[i][col] != 0:
                sel = i
                break
        if a[sel][col] == 0:
            continue

        a[row], a[sel] = a[sel], a[row]
        b[row], b[sel] = b[sel], b[row]

        inv = pow(a[row][col], MOD - 2, MOD)
        for j in range(col, m):
            a[row][j] = (a[row][j] * inv) % MOD
        b[row] = (b[row] * inv) % MOD

        for i in range(n):
            if i != row and a[i][col]:
                factor = a[i][col]
                for j in range(col, m):
                    a[i][j] = (a[i][j] - factor * a[row][j]) % MOD
                b[i] = (b[i] - factor * b[row]) % MOD

        where[col] = row
        row += 1
        if row == n:
            break

    for i in range(row, n):
        if b[i] != 0:
            return None

    x = [0] * m
    for i in range(m):
        if where[i] != -1:
            x[i] = b[where[i]]
    return x

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        xs = list(map(int, input().split()))
        ys = list(map(int, input().split()))

        d = n - 1
        k = d // 2 + 1

        a = [[0] * k for _ in range(n)]
        b = ys[:]

        for i in range(n):
            x = xs[i]
            p = 1
            for j in range(k):
                a[i][j] = (p + pow(x, d - j, MOD)) % MOD if d - j != j else p
                p = (p * x) % MOD

        sol = gauss(a, b)
        if sol is None:
            print(-1)
            continue

        res = [0] * (d + 1)
        for i in range(k):
            res[i] = sol[i]
            res[d - i] = sol[i]

        print(d)
        print(*res)

if __name__ == "__main__":
    solve()
```この実装では、各変数が 1 つのミラー係数ペアに対応する線形システムが構築されます。 点の行列行は、多項式の両端からの寄与を同時に蓄積し、事後的ではなく構造的に対称性が強制されることを保証します。 

ガウス消去はモジュロ演算上でその場で実行されます。 ピボット選択ではゼロ除数が回避され、係数が素数であるため、逆計算ではフェルマーの小定理が使用されます。 

微妙な点は、多項式基底を単項式のみに明示的に還元することは決してないということです。 代わりに、対称ペアを各方程式に直接エンコードします。 これにより、変数が 2 倍になることが回避され、システムの寸法が約半分の度に保たれます。 

## 実用的な例

 ### 例 1

 入力:```
n = 3
x = [0, 1, 2]
y = [2, 10, 36]
```d = 2 を選択したため、係数は [a0, a1, a2] (a0 = a2) となります。 

| ステップ | x における方程式 | システムフォーム |
 | --- | --- | --- |
 | x=0 | a0 = 2 | a0 = 2 |
 | x=1 | a0 + a1 + a0 = 10 | 2a0 + a1 = 10 |
 | x=2 | 4a0 + 2a1 + a0 = 36 | 5a0 + 2a1 = 36 |

 これを解くと、a0 = 2、a1 = 3、a2 = 2 が得られます。 

これは、対称性によって未知数が 2 つの変数に削減され、すべての方程式が一貫したままであることが確認されます。

ガウス消去法では、右側がゼロではないゼロの行が生成され、拒否が引き起こされます。 

これは、実現可能性が一般的な補間多項式の存在によってではなく、完全に線形一貫性によって決定されることを示しています。

 ## 特殊なケース

 重要なエッジケースは、多項式が定数に崩壊する場合です。 その場合、a0 を除くすべての係数はゼロとなり、対称性は自明に満たされます。 システムは単一変数の線形システムに帰着するため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、すべての xi がフィールド構造を法として等しい場合ですが、この問題では個別の xi が保証されるため、内挿行列は適切に定義されたままになります。 

パリティの問題は、係数を常に対称的にペアにすることによって暗黙的に処理されます。 偶数または奇数の次数に対する特別な分岐はなく、不一致の中間係数の処理が回避されます。
