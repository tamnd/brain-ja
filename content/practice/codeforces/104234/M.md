 ## 解決策
 ## 問題の理解

 離散ビート上で繰り返されるジャグリング パターンを記述するシーケンスが与えられます。 各ビートで、指定された遅延でスローが発生するか、何も発生しません。 位置 i でスローが発生すると、オブジェクトは i に指定された値を加えたものによって決定される将来のビートに「移動」され、そのオブジェクトは到着時に再び処理されます。 パターンが有効であることが保証されているため、各タイム ステップは一貫して動作します。どのビートも複数の到着オブジェクトを受信せず、システムは競合することなく無限に繰り返すことができます。 

重要な観点は、パターン内の各位置が有向グラフ内のノードのように機能し、ゼロ以外の各値が i から i + ai までの有向エッジを作成するということです (パターンの長さにわたる周期的な時間動作を伴う)。 有効なパターンは、このグラフが順列構造であることを保証します。つまり、すべてのアクティブな位置が正確に 1 つの有向サイクルに属することになります。 

各サイクルは、ジャグリングの解釈における 1 つの物理オブジェクトに対応します。 サイクルをたどるにつれて、このオブジェクトが処理されるビートを繰り返し確認します。 ビートはパリティによってハンドを交互に切り替えるため、奇数のインデックスが最初のハンドに対応し、偶数のインデックスが 2 番目のハンドに対応します。 

タスクは、使用される場所に応じて各オブジェクトを分類することです。 周期内のすべての拍が奇数の場合は、初手のみで処理されます。 全て揃った場合は秒針のみの扱いとなります。 それ以外の場合は、サイクル全体でハンドが交互に切り替わり、共有オブジェクトとしてカウントされます。 

入力サイズは合計 100,000 ポジションに達する可能性があります。 これにより、すべての遷移にわたる二次シミュレーションが即座に除外されます。 正しいソリューションでは、各インデックスを一定回数処理する必要があります。これは、誘導された関数グラフを線形に走査することを示唆しています。 

値がゼロの位置からは、微妙なエッジ ケースが発生します。 これらは、そのビートでスローが発生しないことを表し、そのトランジションにオブジェクトが関連付けられていないことを意味します。 依然としてゼロのエッジを強制する単純なグラフ構築では、偽のサイクルが誤って作成されてしまいます。 もう 1 つのエッジ ケースは、モジュラー インデックスとリニア インデックスの混同であり、慎重に扱わないとサイクル構造を誤って壊す可能性があります。 

## アプローチ

 直接シミュレーションでは、時間の経過とともに各オブジェクトを繰り返し追跡し、原点に戻るまで段階的に進みます。 各位置は n に比例する長さのチェーンにつながる可能性があり、n 個の位置があるため、このアプローチは最悪の場合、二次時間に縮退します。 

すべてのポジションには最大 1 つの発信トランジションがあり、有効性によってアクティブなポジションについても同様に 1 つの着信トランジションが保証されるため、問題の構造はこの爆発を回避します。 これにより、構造が強制的に分離されたサイクルに分解されます。 時間の経過に伴うオブジェクトの動きをシミュレートする代わりに、システム全体を、各ノードが 1 つのサイクルに属し、各サイクルが 1 つのオブジェクトを表すグラフに圧縮できます。 

この再定式化が行われると、問題は関数グラフ内のすべてのサイクルを横断することになります。 各サイクルについて、そのノードのパリティを検査するだけで済みます。 サイクル内のすべてのノードがパリティを共有する場合、オブジェクトは一方に留まります。 それ以外の場合は、ハンドが切り替わります。

 ## アルゴリズムのチュートリアル

 各インデックスを有向グラフのノードとして解釈します。 i の値がゼロ以外の場合、i から (i + ai) を法とする n までの有向エッジを作成します。

1. ゼロ以外の値を持つ場合、各位置が次の位置を指す後続配列を​​構築します。 ゼロの位置は意味のある遷移がないものとして扱われ、トラバーサルではスキップされます。 
2. サイクル検出中に各ノードが正確に 1 回処理されるように、訪問済みのアレイを維持します。 これにより、サイクル間の冗長な走査が防止されます。 
3. 有効な発信遷移を持つ未訪問のポジションごとに、訪問済みノードに戻るまで後続者の追跡を開始します。 この走査で遭遇するすべてのノードは 1 つのサイクルを形成します。 
4. サイクルトラバーサル中に、すべてのインデックスが奇数であるか、すべてが偶数であるか、または混合であるかを記録します。 これは、両方のパリティが出現するとすぐに無効になる 2 つのフラグを追跡することによって実行できます。 
5. サイクルが完全に収集されたら、それを分類します。 すべてのノードが奇数の場合は、先手専用カウンターをインクリメントします。 すべてが偶数の場合、中古専用カウンタをインクリメントします。 それ以外の場合は、共有オブジェクト カウンタをインクリメントします。 

これが機能する理由は、遷移によって引き起こされるグラフがサイクルの素結合であるためです。 すべてのオブジェクトは 1 つのサイクルに正確に対応し、そのサイクル内のすべてのビートは、そのオブジェクトが処理されるときのまさに 1 つの瞬間です。 ハンドの割り当てはビート インデックスのパリティのみに依存するため、分類は時間の経過に伴う進化ではなく、サイクル全体にわたる特性のチェックに帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # Build successor graph (0-indexed)
    nxt = [-1] * n
    for i in range(n):
        if a[i] != 0:
            nxt[i] = (i + a[i]) % n
    
    vis = [False] * n
    
    only_first = 0
    only_second = 0
    both = 0
    
    for i in range(n):
        if vis[i] or nxt[i] == -1:
            continue
        
        cur = i
        cycle = []
        
        while not vis[cur]:
            vis[cur] = True
            cycle.append(cur)
            cur = nxt[cur]
        
        has_odd = False
        has_even = False
        
        for v in cycle:
            if v % 2 == 0:
                has_even = True
            else:
                has_odd = True
        
        if has_odd and has_even:
            both += 1
        elif has_odd:
            only_first += 1
        else:
            only_second += 1
    
    print(only_first, only_second, both)

t = int(input())
for _ in range(t):
    solve()
```この構築では、直接の後続マッピングを使用して、アクティブ時に各ノードが正確に 1 つの次の状態を指すようにします。 ゼロ値の位置はオブジェクトのサイクルに寄与しないため、明示的にスキップします。 

サイクル検出は、標準の訪問済みマーキング手法を使用して行われます。 未訪問のノードに遭遇するたびに、すでに訪問したノードに戻るまでそのチェーンをたどり、サイクル内のすべてのノードを収集します。 

パリティ分類はサイクルが完全に収集されるまで延期され、サイクル間で部分的な情報が混在しないようにします。 

よくある間違いは、サイクルを分離せずに走査中にパリティを処理しようとすることです。これにより、グラフが慎重に分離されていない場合、関連のないコンポーネント間で情報が誤ってマージされる可能性があります。

 ## 特殊なケース

 縮退のケースは、すべての値がゼロの場合です。 この状況では、遷移は存在せず、サイクルも形成されません。 すべてのインデックスには後続がないため、アルゴリズムはすべてのノードを正しくスキップし、すべてのカテゴリでカウントが 0 になります。 

もう 1 つのケースは、1 → 3 → 1 をマッピングする小さなパターンなど、奇数のインデックス内に完全に含まれるサイクルです。走査中には奇数パリティのみが観察されるため、サイクルは曖昧さなくファーストハンドのみとして分類されます。 

最後の微妙なケースは、サイクルが両方のパリティにまたがるが、切り替え前に均一なパリティが長く続く場合です。 パリティ フラグはサイクル全体にわたってグローバルにのみ更新されるため、最終的な分類では、切り替えがトラバーサル順序のどこで発生するかに依存することなく、両方の存在が正しく検出されます。
