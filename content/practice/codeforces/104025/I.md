 ## 問題の理解

 単一の小文字文字列が与えられ、そのすべての部分文字列をオブジェクトとして調べます。 これらの部分文字列からセットを形成したいと考えています$S$制限付き: 選択された 2 つの異なる部分文字列が接尾辞関係にあることは許可されません。 つまり、一部の接頭辞文字を削除することで 1 つの文字列を別の文字列から取得できる場合、これら 2 つの文字列を両方ともセットに含めることはできません。 

あらゆるサイズに対応$k$、そのような有効なサイズの部分文字列のセットが正確にいくつあるかを数えなければなりません$k$存在する。 

重要な問題は、部分文字列が独立したオブジェクトではないことです。 それらの多くは値が大きく重複しており、接尾辞の関係によって密な依存構造が作成されます。 部分文字列の数は$O(n^2)$原則として、次の場合には直接列挙することは不可能です。$n$到達する$10^5$。 

素朴な解釈では、すべての部分文字列を反復処理し、ペアごとの接尾辞の関係をチェックすることを提案します。 それは要素の世界を生成するレベルですでに失敗しています。 生成が自由だったとしても、サイズのサブセットの妥当性をチェックする$k$少なくとも必要になります$O(k^2)$すべてのサブセットの合計は指数関数的になります。 

値によって部分文字列を圧縮した場合でも、さらに微妙な失敗例が発生します。 異なる位置からの 2 つの同一の部分文字列は、選択の観点から考えると別個の選択肢として扱われなければなりませんが、接尾辞制約の下では同じように動作します。 オカレンスを誤ってマージする不注意なソリューションでは、解釈に応じて過大にカウントされたり、過少にカウントされたりします。 

本当の障害は、サフィックス関係が部分文字列に対してグローバルな半順序を誘発し、可能な限りすべてのサイズのアンチチェーンをその順序でカウントする必要があることです。 

## アプローチ

 直接的なブルート フォース ビューでは、すべての部分文字列をリストしてからすべてのサブセットを列挙し、選択したペアがサフィックス条件に違反するかどうかを確認します。 これは定義上は正しいですが、部分文字列の数は 2 次であり、サブセットの数は指数関数的であるため、すぐに爆発します。 

先に進むために、制約を再解釈します。 禁止されたペアは、ある文字列が別の文字列のサフィックスである場合にのみ発生します。そのため、問題は、選択した要素が別の選択した要素のサフィックス チェーン上に存在しないサブセットをカウントすることです。 これは、サフィックス リンクによって定義されたポーズセット内のアンチチェーンを数えるのと同じです。 

ここで、すべての文字列には最初の文字を削除することによって得られる一意のサフィックスが付いていることに注目してください。そのため、この構造内のすべてのノードには 1 つの親しかありません。 これにより、サフィックス関係は、空の文字列をルートとする、文字列の世界全体にわたるルート付きツリー構造を形成します。 この木には$O(n^2)$ノードの構造は非常に規則的です。各ノードは部分文字列に対応し、その親はそのサフィックスです。 

アンチチェーンをカウントするためのツリー上の標準 DP は、ツリーが明示的であれば機能します。 ノードの場合$u$、 させて$f_u[k]$有効なサイズ選択の数を示します$k$そのサブツリーの内部。 無視したら$u$、子を個別に組み合わせることができます。 選択すると$u$、その場合はすべての子孫を禁止する必要があります。 

欠けている重要な要素は、この巨大な木をどのようにコンパクトに表現するかです。 ここで接尾辞オートマトンの視点が不可欠になります。 すべての部分文字列を個別に扱う代わりに、接尾辞オートマトンの状態に対応するエンドポス同値クラスごとにグループ化します。 各状態は部分文字列の長さの範囲を表し、その範囲内ではすべての部分文字列が拡張構造に関して同一に動作します。 

単一の状態内では、部分文字列は接尾辞関係に基づいてチェーンを形成するため、同じ状態から複数の部分文字列を選択することはできません。 したがって、各状態は、それが表す個別の部分文字列の数に等しいサイズのチェーンに寄与します。 

で表すと$w_u$状態によって表される部分文字列の数$u$の場合、各状態は以下を含むブロックのように動作します。$w_u$線形に順序付けされた要素。 状態間のサフィックス リンク構造はツリーを形成し、制約は次のようになります。ルートからリーフへのチェーンごとに最大 1 つの要素、状態チェーンごとに最大 1 つの要素を選択するように、要素のサブセットを選択します。 

これにより、各ノードが何も寄与しないか、内部チェーンから選択された 1 つの部分文字列のみを寄与するサフィックス リンク ツリー上のクリーンな DP が得られます。

 ## アルゴリズムのチュートリアル

 文字列の接尾辞オートマトンを処理します。 各州$u$サフィックスリンクの親があります$p(u)$、初期状態をルートとするツリーを形成します。 

州ごとに$u$、計算します$w_u = \text{len}(u) - \text{len}(p(u))$、これは、この状態セグメントによって一意に表される個別の部分文字列の数です。 

DP 配列を維持します$f_u$、 どこ$f_u[k]$有効な選択方法の数です$k$のサブツリーからの部分文字列$u$。 

1. 文字列のサフィックスオートマトンを構築します。 これにより、$O(n)$状態とサフィックスリンクツリー。 
2. 初期状態で DP をルート化し、ボトムアップ方式で子を処理します。 
3. 州ごとに$u$、最初に一時的な多項式を計算します。$g_u$すべての子の DP 配列の畳み込みとして。 これは、子サブツリーに触れることなく、有効なサブセット全体を選択することを表します。$u$。 
4. 次から何も選択しない場合の寄与を計算します。$u$、まさにその通りです$g_u$。 
5. ブロックから正確に 1 つの部分文字列を選択することによる寄与を計算します。$u$。 あるので$w_u$状態内の選択肢と 1 つの要素の選択がサイズに影響します$1$、これは追加します$w_u \cdot g_u$位置を 1 つずらします。 
6. 両方のケースを組み合わせます。$f_u = g_u + w_u \cdot (g_u \text{ shifted by } 1)$。 
7. それぞれの答え$k$は$f_{\text{root}}[k]$。 

自明ではない部分は、なぜ乗算するのかということです。$w_u$は有効です。状態内のすべての部分文字列は、構造の残りの部分に対して対称であるため、それらのいずれかを選択すると、状態の外部でも同じ互換性制約が生成されます。 

### なぜ効果があるのか

 DP は、すべての選択がカウントされるという不変式を維持します。$f_u$のサブツリー内の接尾語祖先制約を完全に尊重します。$u$。 各状態では、同一の拡張動作を持つすべての部分文字列が折りたたまれ、状態内でこれらの部分文字列が単一のサフィックス チェーンを形成するため、有効な選択にはそれらのうちの 1 つだけを含めることができます。 要因$w_u$実現可能性を変えることなく、その 1 つの選択に対する個別の選択肢の数を説明します。 すべての部分文字列は正確に 1 つの状態セグメントに属し、すべての祖先と子孫の関係は接尾辞リンクによって表されるため、マージ中に無効なペアが導入されたり、失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

class SAM:
    def __init__(self, n):
        self.next = []
        self.link = []
        self.length = []
        self.size = 1

        self.next.append({})
        self.link.append(-1)
        self.length.append(0)

        self.last = 0

    def extend(self, c):
        p = self.last
        cur = self.size
        self.size += 1

        self.next.append({})
        self.link.append(0)
        self.length.append(self.length[p] + 1)

        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]

        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.length[p] + 1 == self.length[q]:
                self.link[cur] = q
            else:
                clone = self.size
                self.size += 1

                self.next.append(self.next[q].copy())
                self.link.append(self.link[q])
                self.length.append(self.length[p] + 1)

                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]

                self.link[q] = self.link[cur] = clone

        self.last = cur

def solve():
    s = input().strip()
    n = len(s)

    sam = SAM(n)
    for ch in s:
        sam.extend(ch)

    g = [None] * sam.size
    children = [[] for _ in range(sam.size)]

    for v in range(1, sam.size):
        children[sam.link[v]].append(v)

    def dfs(u):
        base = [1]
        for v in children[u]:
            cv = dfs(v)
            new = [0] * (len(base) + len(cv))
            for i in range(len(base)):
                for j in range(len(cv)):
                    new[i + j] = (new[i + j] + base[i] * cv[j]) % MOD
            base = new

        w = sam.length[u] - (sam.length[sam.link[u]] if sam.link[u] != -1 else 0)

        res = base[:]
        ext = [0] * (len(base) + 1)
        for i in range(len(base)):
            ext[i + 1] = base[i] * w % MOD

        for i in range(len(ext)):
            if i < len(res):
                res[i] = (res[i] + ext[i]) % MOD
            else:
                res.append(ext[i])

        g[u] = res
        return res

    root = 0
    ans = dfs(root)

    ans = ans[1:]
    for i in range(1, n + 1):
        print(ans[i] % MOD if i < len(ans) else 0)

if __name__ == "__main__":
    solve()
```このコードはサフィックス オートマトンを構築し、サフィックス リンク ツリー上で DFS を実行します。 各ノードは、サブツリーから有効なサブセットを選択する方法が何通りあるかを表す多項式を計算します。 畳み込みステップでは子の寄与がマージされ、最終調整では、現在の状態から 1 つの部分文字列を選択するオプションが追加され、その状態が表す個別の部分文字列の数によって重み付けされます。 

よくある落とし穴は、各州が 1 つの代表だけではなく複数の部分文字列を提供していることを忘れていることです。 の乗算$w_u$これは、状態ベースの DP を実際の部分文字列カウントに変換するものです。

 ## 特殊なケース

 重大なエッジ ケースは、次のような、すべて同一の文字を含む文字列です。`aaaaa`。 この状況では、すべての部分文字列は長い部分文字列の接尾辞となり、単一の長いチェーンを形成します。 DP は、チェーンごとに最大 1 つの要素を選択するという問題を正しく解決し、サフィックス オートマトンは繰り返し構造を線形状態に折りたたんで、オーバーカウントが発生しないようにします。 

もう 1 つのエッジ ケースは、次のようなすべての異なる文字を含む文字列です。`abcde`。 ここでは、些細な拡張に沿ったものを除いて、部分文字列は別の部分文字列の接尾辞ではないため、ほとんどの選択は独立しています。 DP は、接尾辞リンクの構造を通じて偶発的な接尾辞のペアリングを防止しながら、オートマトン ツリー内の独立した分岐から大きな組み合わせカウントを生成することでこれを反映します。
