 ## 解決策
 ## 問題の理解

 2 人が飛行機上の 2 つの与えられた座標からスタートし、一定の時間内にそれぞれの目的地まで直線で走ります。 どちらも一定の速度で移動するため、各人の位置は開始点と終了点の間の線形補間になります。 

タスクは、動作全体を通してそれらの間の距離を追跡し、開始と終了の間の任意の瞬間に発生する最大の分離を報告することです。 それがいつ起こるかは尋ねられず、その距離の最大値だけが求められます。 

各ランナーの経路は 2 点によって完全に決定されるため、システム全体は平面上の 2 つの移動点に減り、両方の線分が同じ時間間隔で同時にトレースされます。 

入力サイズは定数 (8 つの整数) であるため、制約はスケーラビリティに関するものではなく、数値的な堅牢性に関するものです。 定数時間ジオメトリを使用したソリューションが期待されています。 最大値はサンプリングされた点の間で発生する可能性があるため、時間またはサンプリングの離散化を伴うものはすべて不必要であり、不正確である可能性があります。 

素朴な考えによる微妙な失敗例は、最大距離がエンドポイントの 1 つで発生するはずだと仮定することです。 直線的に移動する 2 つの点間の距離関数は線形ではないため、これは常に当てはまります。 

たとえば、一方のランナーがもう一方のランナーの周囲を円のような相対運動で移動する場合 (たとえ両方が直線的に移動していても、相対運動によって回転距離曲線が作成される可能性があります)、最大値は t = 0 または t = 1 ではなく、時間間隔の内側で発生する可能性があります。 

もう 1 つの故障モードは、1000 回の等間隔の時間をチェックするなど、均一なサンプリングです。 放物線が狭い場合、鋭いピークを見逃す可能性があります。 

重要な困難は、動きは幾何学的であるにもかかわらず、距離関数が 1 つの変数の単純な代数曲線になることを認識することです。 

## アプローチ

 ブルートフォース手法では、時間を連続的にシミュレートするか、高密度のサンプリングを使用してシミュレートします。 0 から 1 までの多くの時点で 2 人のランナー間の距離を評価できます。関数は連続であるため、これは概念的には正しいため、十分に高密度のサンプリングが最大値に近似します。 

ただし、正確な正確性を求める場合、サンプリングは受け入れられません。 有限の離散化では、真の最大値を逃す危険があります。 たとえ 100 万点をサンプリングしたとしても、最大点はそれらの間にある可能性があります。 

構造的な洞察は、各ランナーの各座標が時間的に線形であるということです。 つまり、それらの間の差分ベクトルも時間的に線形になります。 距離の二乗は時間の二次関数になります。 閉じた区間上の 2 次関数はよく知られた形状をしています。つまり、上向きまたは下向きに開き、その最大値は端点か、頂点が区間内にある場合は頂点で発生する必要があります。 

これにより、問題は平面での幾何学的な推論から単一変数の 2 次多項式の解析に縮小されます。

 ## アルゴリズムのチュートリアル

 時間を 0 から 1 の範囲の t としてパラメータ化します。

1. カリの位置を時間の関数として表現します。 彼女が A で始まり C で終わる場合、彼女の位置は A + t(C − A) になります。 これは等速直線運動をエンコードします。 
2. オラの位置を同様に B + t(D − B) と表現します。 
3. 時間 t におけるそれらの間の差分ベクトルを計算します。 これは、(A − B) + t((C − A) − (D − B)) となります。 このステップは、問題を単一の移動ベクトルに帰着させるため重要です。 
4. 二乗距離を、それ自体との差分ベクトルの内積として書き込みます。 これにより、 f(t) = at² + bt + c という形式の式が生成されます。ここで、a、b、c は座標から導出されたスカラー値です。 
5. t* = −b / (2a) を計算して、二次方程式が極値に達する候補時間を決定します。 これは、二次関数の頂点がゼロである導関数に由来します。 
6. 動作は実行期間に制限されるため、t* を区間 [0, 1] にクランプします。 頂点が外側にある場合、その頂点は区間内の最大値にはなりません。 
7. t = 0、t = 1、およびクランプされた t* で f(t) を評価します。 これらの値の最大値は、最大二乗距離です。 
8. この最大値の平方根を返し、実際のユークリッド距離を取得します。 

### なぜ効果があるのか

 二乗距離関数は、各座標が t において線形であり、二乗により最大次数 2 項が導入されるため、t における二次多項式です。 閉区間上の二次関数は複数の内部臨界点を持つことができず、その極値は端点とその臨界点によって完全に決定されます。 二乗では非負の値の順序が維持されるため、二乗距離の最大化は距離の最大化と同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def clamp(x, lo, hi):
    return max(lo, min(hi, x))

def dist2(x1, y1, x2, y2):
    dx = x1 - x2
    dy = y1 - y2
    return dx * dx + dy * dy

def solve():
    data = list(map(int, input().split()))
    ax, ay, bx, by, cx, cy, dx, dy = data

    # direction vectors
    pax, pay = cx - ax, cy - ay
    pbx, pby = dx - bx, dy - by

    # relative motion: P(t) - Q(t) = (A-B) + t((C-A)-(D-B))
    rx = ax - bx
    ry = ay - by
    vx = pax - pbx
    vy = pay - pby

    # f(t) = |r + t v|^2 = (v·v)t^2 + 2(r·v)t + (r·r)
    a = vx * vx + vy * vy
    b = 2 * (rx * vx + ry * vy)
    c = rx * rx + ry * ry

    best = c  # t = 0

    # t = 1
    best = max(best, a + b + c)

    if a != 0:
        t = -b / (2 * a)
        t = clamp(t, 0.0, 1.0)
        val = a * t * t + b * t + c
        best = max(best, val)

    print((best) ** 0.5)

if __name__ == "__main__":
    solve()
```コードは、両方の軌道を速度形式に書き直すことから始まり、これにより補間の繰り返しが回避されます。 二次方程式の係数は、一次式の二乗ノルムを拡張することで直接得られます。 エンドポイント チェックは t = 0 および t = 1 に対応します。内部候補は 2 次式が平坦でない場合にのみ計算されます。 

微妙な点は数値の安定性です。 t に浮動小数点を使用すると、この問題では小さな相対誤差または絶対誤差が許容され、最終的な計算は二乗距離で単調になるため、安全です。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys as _sys
    from math import sqrt

    data = list(map(int, inp.split()))
    ax, ay, bx, by, cx, cy, dx, dy = data

    pax, pay = cx - ax, cy - ay
    pbx, pby = dx - bx, dy - by

    rx = ax - bx
    ry = ay - by
    vx = pax - pbx
    vy = pay - pby

    a = vx * vx + vy * vy
    b = 2 * (rx * vx + ry * vy)
    c = rx * rx + ry * ry

    best = c
    best = max(best, a + b + c)

    if a != 0:
        t = -b / (2 * a)
        t = max(0.0, min(1.0, t))
        best = max(best, a * t * t + b * t + c)

    return str(math.sqrt(best))

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、両方のランナーが同じ速度でまったく同じ方向に移動するときに発生します。 その状況では相対速度はゼロであるため、二次項は消え、距離は一定になります。 アルゴリズムは、頂点の評価をスキップする a != 0 のチェックを通じてこれを処理します。 

もう 1 つのケースは、両方が同じ点から始まり、異なる方向に分岐する場合です。 最大値は t = 1 で発生し、アルゴリズムはエンドポイントを明示的に正しく評価します。 

縮退の場合は、動きが正確にキャンセルされ、距離が最初に増加し、次に対称的に減少する場合です。 これにより明確な内部最大値が生成され、計算された頂点 t* は厳密に [0,1] の内側に位置し、正しくクランプおよび評価されます。
