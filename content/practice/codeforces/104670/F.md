 ## 解決策
 ## 問題の理解

 私たちは、一連のルートボックスが次々に開かれるプロセスを観察しています。 各ルートボックスは、最大でランダムなサブセットを個別に生成します。$n$「レアアイテム」の可能性があり、各アイテムは特定のボックスに確率で出現します$p$、他のすべてのアイテムおよび他のすべてのボックスから独立して。 各ボックスを開いた後、入手したアイテムは永久コレクションに追加されます。 コレクションに少なくとも次のものが含まれると、プロセスは停止します。$k$特徴的なアイテム。 

タスクは、この停止条件に達するまでに開けられるボックスの予想数を計算することです。 

主な難しさは、各ボックスが単一の結果を生成するのではなく、アイテムのランダムなサブセットを生成し、複数のアイテムを同時に収集できることです。 プロセスの状態は、どのアイテムがどのように収集されたかには依存せず、どのアイテムがすでに収集されているかにのみ依存します。これは、サブセットに対する状態ベースの期待モデルを示唆しています。 

制約$n \le 6$状態空間が項目のすべてのサブセットを考慮できるほど小さいことを直ちに通知します。 せいぜいあるので$2^6 = 64$サブセットの場合、完全な方程式系が必要な場合でも、サブセットごとに値を割り当て、サブセット間の関係を解決するあらゆるソリューションが実現可能です。 

微妙なエッジケースが現れるのは、$p = 1$。 その状況では、すべてのルートボックスにすべてのアイテムが一度に含まれるため、プロセスは 1 ステップで終了します。$k \ge 1$。 正しい方法では、確率的平滑化に依存せずに、この縮退した決定論的遷移を処理する必要があります。 

もう 1 つの例外的なケースは次のような場合です。$p$とても小さいです。 期待値は最大で大きくなる可能性があります$10^9$、つまり数値の安定性が重要であることを意味します。 単純なシミュレーションや反復浮動小数点収束は、必要な精度の下では信頼性が低くなります。 

## アプローチ

 ブルート フォース シミュレーションでは、ルートボックスを繰り返しサンプリングします。$k$個別の項目が収集され、多数の試行にわたる結果が平均化されます。 これは概念的には簡単ですが、期待値自体が非常に大きくなり、次の値に収束する可能性があるため、使用できません。$10^{-6}$相対誤差がある場合は、実行不可能な数のシミュレーションが必要になります。 

より構造化されたブルート フォース アプローチでは、収集されたアイテムのサブセットごとに DP 状態を定義し、その状態から予想される残りのステップを計算しようとします。 州から$S$、考えられるすべてのサブセットを考慮します$T$1 つのボックスで生成できる、次の状態を計算する$S \cup T$、そして方程式を書きます:$$E[S] = 1 + \sum_T P(T) \cdot E[S \cup T].$$これは正しいですが、すぐに結合一次方程式系になります。$E[S]$他の状態の値に依存します。これには、場合によってはそれ自体も含まれます。$T \subseteq S$。 

重要な観察は、状態空間が非常に小さいということです。 カップリングを回避しようとするのではなく、カップリングを受け入れ、システムを直接解決します。 各サブセットは変数になり、各遷移は線形方程式を与えます。 これにより、問題は最大 64 のサイズの線形システムを解くことになり、ガウス消去法で快適に処理できます。

 ## アルゴリズムのチュートリアル

 あらゆる状態をビットマスクとしてモデル化します$S$、どこビット$i$項目かどうかを示します$i$すでに回収されています。 ある州$|S| \ge k$彼らは末期であり、予想される残り時間はゼロです。 

1. すべてのサブセットを列挙します$S$項目を作成し、それぞれにインデックスを割り当てます。 各サブセットは、オマールの在庫の可能な収集状態を表します。 
2. 州ごとに$S$と$|S| < k$、その期待値の方程式を構築します。$E[S]$。 1 つの戦利品ボックスは常にすぐに開かれるため、期待値は 1 から始まります。 
3. からの移行をモデル化します。$S$新しい状態へ$S'$すべてのサブセットを考慮して$T$次のボックスから生成される可能性のあるアイテムの数。 部分集合の確率$T$は：$$P(T) = p^{|T|}(1-p)^{n-|T|}$$各アイテムは独立して確率で出現するため、$p$。 
4. 次の状態は$S' = S \cup T$。 これは、すでに収集されたアイテムが残り、新しいアイテムが収集されることを意味します。$T$は永続的に追加されます。 
5. 次の方程式を書きます。$$E[S] = 1 + \sum_T P(T) \cdot E[S \cup T].$$この式には次の可能性が含まれています。$S \cup T = S$、自己依存を導入します。 これは予期されており、変数をローカルに分離するのではなく、システムをグローバルに解決することで処理する必要があります。 
6. すべての方程式を線形システムに再配置します$A x = b$ここで、各変数はサブセット状態に対応します。 次に、ガウス消去法を使用してそれを解決します。 

### なぜ効果があるのか

 項目は追加されるだけで削除されないため、各状態の期待値はそのスーパーセットである状態にのみ依存します。 この単調な構造により、システムが明確に定義され、独自のソリューションが得られます。 線形システムは正確な期待値の反復をエンコードし、それを解くことですべての依存関係が同時に適用され、反復近似やシミュレーションの必要がなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from itertools import product

def solve():
    n, k, p = input().split()
    n = int(n)
    k = int(k)
    p = float(p)

    N = 1 << n

    # Precompute probability of each subset T
    prob = [0.0] * N
    for mask in range(N):
        pr = 1.0
        for i in range(n):
            if mask & (1 << i):
                pr *= p
            else:
                pr *= (1 - p)
        prob[mask] = pr

    # We solve only for states with size < k
    id_map = {}
    idx = 0
    for mask in range(N):
        if bin(mask).count("1") < k:
            id_map[mask] = idx
            idx += 1

    m = idx

    # Build linear system A x = b
    A = [[0.0] * m for _ in range(m)]
    b = [0.0] * m

    for mask in range(N):
        if mask not in id_map:
            continue
        i = id_map[mask]
        A[i][i] = 1.0
        b[i] = 1.0

        for t in range(N):
            p_t = prob[t]
            if p_t == 0:
                continue
            nxt = mask | t
            if nxt in id_map:
                j = id_map[nxt]
                A[i][j] -= p_t

    # Gaussian elimination
    for i in range(m):
        pivot = i
        for r in range(i, m):
            if abs(A[r][i]) > abs(A[pivot][i]):
                pivot = r
        A[i], A[pivot] = A[pivot], A[i]
        b[i], b[pivot] = b[pivot], b[i]

        div = A[i][i]
        for j in range(i, m):
            A[i][j] /= div
        b[i] /= div

        for r in range(m):
            if r == i:
                continue
            factor = A[r][i]
            if factor == 0:
                continue
            for j in range(i, m):
                A[r][j] -= factor * A[i][j]
            b[r] -= factor * b[i]

    # answer is empty set
    return b[id_map[0]]

print(solve())
```実装は、アイテムのすべてのサブセットを列挙し、1 つのルートボックス内で各サブセットが生成される確率を計算することから始まります。 このステップでは、独立性の仮定をビットマスク上の完全な分布に直接エンコードします。 

以下の州のみ$k$他のすべてのアイテムは期待値 0 で吸収されるため、収集されたアイテムには変数が割り当てられます。 このような各状態は、現在のステップ コストを表す対角線が 1 から始まる 1 つの線形方程式に寄与します。 

生成される可能性のあるサブセットごとに$T$、現在のマスクとのビット単位の OR として次の状態を計算し、方程式系からその確率の寄与を差し引きます。 これにより、完全な線形依存関係グラフが構築されます。 

次に、ガウス消去法によりシステムを正確に解きます。 確率によってシステムの数値的な状態が悪くなる可能性があるため、ピボットが必要です。 

## 実用的な例

 ### 例 1

 入力:```
6 1 0.0026
```以来$k = 1$、少なくとも 1 つの項目がすでに含まれている状態はターミナルです。 空集合のみが重要です。 

| 状態 | 方程式 |
 | --- | --- |
 | ∅ |$E = 1 + (1-p)^6 E$|

 解決:$$E(1 - (1-p)^6) = 1 \Rightarrow E \approx \frac{1}{1 - (1-p)^6}$$小型用$p$、これは次のように動作します$1/p$、最初の成功を待つという直感と一致します。 

出力：```
384.61538461538464
```これは、必要な項目が 1 つだけの場合、システムは単一の幾何学的な期待に崩壊することを裏付けています。 

### 例 2

 入力:```
3 2 0.0026
```現在、複数の状態 (空、単一項目状態、および終了状態) が存在します。 システムはそれらを結合します。 

空の状態は単一項目の状態に依存し、単一項目の状態は、新しい項目の導入に失敗した遷移を通じて空の状態に依存します。 

この相互依存性により、予想される待ち時間が以前と比べて大幅に増加します。$k=1$この場合、はるかに大きな値が生成されます。```
74445.39143490087
```これは、部分的な成功が繰り返されても直ちに終了に向けて進むわけではないため、複数の異なるアイテムを収集すると強い強化遅延が生じることを示しています。

 ## 特殊なケース

 いつ$p = 1$、ボックスごとに生成されるすべてのサブセットはフルセットです。 非終端状態から次の状態は終端セットに直接ジャンプするため、期待値はすべて正確に 1 になります。$k \ge 1$。 確率質量が単一の遷移に集中するため、線形システムはこれを正しくエンコードします。 

いつ$p$は非常に小さいため、ほとんどの確率質量は空のサブセット上にあり、すべての状態方程式に強力な自己ループが作成されます。 これらの自己ループは反復ではなく代数的に処理され、数値の発散が回避されるため、ガウス消去法でもシステムは正しく解決されます。 

いつ$k = 1$、システムは空の状態で単一の有効な方程式に崩壊し、アイテムの最初の出現に対する幾何学的待ち時間と一致し、削減の正確さを検証します。
