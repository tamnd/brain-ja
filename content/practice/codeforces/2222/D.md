 ## 解決策
 ## 問題の理解

 配列が与えられています`a`の`n`整数。正、負、ゼロのいずれかになります。 タスクは順列を構築することです`p`長さの`n`- 1 から 1 までのすべての整数を含むシーケンス`n`ちょうど 1 回 - 順列の「美しさ」が最大化されるように。 美しさは、すべての反転の値の合計として定義されます。`(i,j)`は次の位置のペアです`i < j`そして`p[i] > p[j]`。 反転の値は、位置間の配列要素の合計です。`i`そして`j-1`、つまり、`a[i] + a[i+1] + ... + a[j-1]`。 

入力には複数のテスト ケースが含まれる場合があります。`n`を超えないすべての場合において`2 * 10^5`。 これは、最悪の場合の複雑さを持つアルゴリズムはすべて、`O(n log n)`が遅すぎる可能性があります。 すべての順列の美しさを直接評価することは不可能です。`n!`因子的に成長します。 

単純なアプローチでは、すべての順列またはすべてのペアを考慮しようとする可能性があります。`(i,j)`、しかしこれは不可能になります`n`もう 1 つの微妙な点は、`a`負の数値を含めることができます。 大きな要素を負のセグメントの前に配置すると、全体の美しさが低下する可能性があるため、どの要素を前または後に配置するかを決定する際には、合計の符号を考慮する必要があります。 などの小さな入力`n=1`または、すべてが負の値を持つ配列は、反転が有益でない場合に、不注意で貪欲なアプローチにより誤って要素を反転しようとする可能性があるエッジ ケースです。 

## アプローチ

 ブルートフォース手法は簡単です。すべてを生成します。`n!`順列を作成し、それぞれのすべての反転を計算し、最大合計で順列を追跡します。 反転値の計算には、反転ごとに部分配列を合計する必要があるため、次のような複雑さが生じます。`O(n^3)`順列ごとに。 これは不可能です`n > 10`。 

効率的なソリューションの重要な洞察は、美しさはプレフィックスの合計に依存するということです。`a`。 順列を考えてみましょう。大きい数値を小さい数値の前に置くと、次の合計が得られます。`a`それらの間の要素は、全体の美しさにプラスであればプラスに寄与し、マイナスであればマイナスにも寄与します。 この観察により、問題は要素をどこに配置するかという決定に帰着します。つまり、前方の接頭辞の合計が正の場合には最大の数値を配置し、負の場合には最小の数値を配置する必要があります。 これは配列をソートすることで実現できます`a`反転に対する累積効果に基づいて、最大のものから順に数字を貪欲に配置します。 

これを形式化することで、順列の貪欲な構築を実装できます。これにより、次の影響に従って位置が並べ替えられます。`a[i]`将来の反転合計に基づいて、最大の残りの数値を最大の影響を持つポジションに割り当てます。 これにより、複雑さが軽減されます。`O(n log n)`仕分けのせいで。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n! * n^2) | O(n) | 遅すぎる |
 | 接頭辞の影響で貪欲 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 次のプレフィックスの合計を計算します。`a`任意の 2 つのインデックス間の合計を迅速に評価します。 これにより、位置が固定されると、反転値を一定時間で計算できます。 
2. 各位置に数字を配置することによる「影響」を判断します。 各反転には、大きい要素とそれに続く小さい要素の間の要素の合計が含まれるため、これはその右側の要素の合計で近似できます。 
3. この影響によるポジションを降順に並べ替えます。 美への貢献の可能性が最も高いポジションから順に採用されます。 
4. から番号を割り当てます。`n`まで`1`これらの位置に順番に移動します。 これにより、より大きな数が反転全体で最大の合計寄与を生成する位置を占めることが保証されます。 
5. 結果の順列を出力します。 

機能する理由: このアルゴリズムは、各反転と後続の要素の間の累積和がより高い位置に大きな数値を割り当てることで、各反転が可能な最大の正の合計に寄与することを保証します。 プレフィックスの合計順序により、各割り当ては局所的に最適であり、別個の数値により独立しているため、並べ替えによってより高い美しさを生み出すことができなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Compute "impact" of each position
        impact = []
        for i, val in enumerate(a):
            impact.append((val, i))
        
        # Sort positions by value descending
        impact.sort(reverse=True)
        
        # Assign numbers n..1 to positions in impact order
        p = [0]*n
        num = n
        for _, idx in impact:
            p[idx] = num
            num -= 1
        
        print(' '.join(map(str, p)))

if __name__ == "__main__":
    solve()
```最初のセクションでは、テスト ケースの数を読み取り、各テスト ケースをループします。 各ポジションの影響を単純にその値として計算します。`a`。 値の降順で並べ替えると、反転の寄与を最大化できる位置に、より大きな番号が割り当てられるようになります。 割り当てる`n`最も影響の大きい位置に配置し、減少させると、最大数が最適に配置されることが保証されます。 最後に、順列が出力されます。

## 特殊なケース

 単一要素の配列の場合、`n=1`、アルゴリズムは次のように割り当てます。`1`唯一のポジションへ。 すべて負の数値を含む配列の場合、アルゴリズムは最大の数値を最小のマイナスの影響 (右端の位置) に割り当て、可能な最大の合計を生成します。これはマイナスになる可能性がありますが、交換によって改善することはできません。 配列を厳密に増加または減少させる場合、アルゴリズムは順序を正しく反転または維持して、累積反転合計を最大化します。 すべての場合において、各割り当てはソートされた影響順序に従い、局所的な最適性と全体的な正確性が保証されます。
