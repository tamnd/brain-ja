 ## アルゴリズムのチュートリアル

 1. 複数のテスト ケースの入力を読み取り、抽出する`n`、`k`、 そして`r`。 
2. 周波数ベクトルをそれに到達する配列の数にマッピングするメモ化テーブルを初期化します。 
3. 考えられるすべての配列を列挙します`[a_1, ..., a_n]`によって制約される部分和に対して DP を効率的に使用する`r_i`。 
4. 配列ごとに、その周波数ベクトルを計算します。`f(a)`。 各周波数ベクトルにマッピングされる初期配列のカウントを保存します。 
5. 変形を繰り返す`f`安定するまで各ベクトルに適用します。 シーケンス内の個別のアレイごとに、この安定化長に達するアレイの数を数え続けます。 
6. 最終的な配列に従って、すべての初期配列のカウントを集計します。`g(a)`彼らが生み出す価値。 
7. 出力、モジュロ 998244353、それぞれの配列の数`p`から`1`に`k`。 

機能する理由: 周波数ベクトル上の DP により、明示的に列挙することなく、その境界内で考えられるすべての初期配列が確実に考慮されます。 変換ごとに配列がカウントのマルチセットに減らされ、メモ化によって同じ部分問題が再計算されないことが保証されます。 すべてのシーケンスは最終的に安定するため、サイクル内の個別の配列をカウントすると正確に次の結果が得られます。`g(a)`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

from collections import Counter, defaultdict
from itertools import product

def solve_case(n, k, r):
    # dp[count vector] = number of arrays that lead to this vector
    dp = defaultdict(int)
    dp[tuple([0]* (n+1))] = 1

    # build all arrays using bounded DP
    for i in range(n):
        ndp = defaultdict(int)
        for vec, cnt in dp.items():
            for x in range(r[i]+1):
                new_vec = list(vec)
                new_vec[x] += 1
                ndp[tuple(new_vec)] = (ndp[tuple(new_vec)] + cnt) % MOD
        dp = ndp

    # memoize g values
    g_count = defaultdict(int)
    for vec, cnt in dp.items():
        seen = []
        while vec not in seen:
            seen.append(vec)
            c = [0]*(n+1)
            for idx, val in enumerate(vec):
                if idx <= n:
                    c[val] += 1
            vec = tuple(c)
        g_count[len(seen)] = (g_count[len(seen)] + cnt) % MOD

    res = [g_count[p] if p in g_count else 0 for p in range(1, k+1)]
    return res

def main():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        r = list(map(int, input().split()))
        ans = solve_case(n, k, r)
        print(' '.join(map(str, ans)))

if __name__ == "__main__":
    main()
