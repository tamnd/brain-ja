 ## 解決策
 ## 問題の理解

 奇数長の正の整数のシーケンスが与えられます。 タスクは、このシーケンスを、それぞれが奇数の長さの連続したサブ配列に分割し、これらすべてのサブ配列が同じ中央値を共有するようにすることです。 私たちの目標は、そのようなパーティション内のサブ配列の数を最大化することです。 各部分配列の中央値は、部分配列を並べ替えた後の中央の要素として定義されます。 

重要な課題は、絡み合った 2 つの制約から生じます。 まず、サブ配列の長さが奇数でなければなりません。 次に、すべての中央値が同一である必要があります。 配列の長さが奇数であるため、単一要素のサブ配列が許可されます。 これは、すべての要素が等しい場合、配列を次のように分割できることをすぐに示唆しています。`n`単一要素の部分配列。 

の制約`n`と合計`n^2`ということを暗示します`O(n^2)`解決策は受け入れられます。 具体的には、次の合計`n^2`すべてのテストケースで次を超えない`5000^2`つまり、二次時間ですべての部分配列またはすべての位置をチェックするソリューションを提供できるということです。 ただし、すべての奇数長の部分配列を共通の中央値かどうかチェックする素朴な総当たりは無駄であり、シーケンス内のパターンを観察することで最適化できます。 

エッジ ケースには、すべての要素が同一であるシーケンス、中央値が配列の端にあるシーケンス、および大きな変動があるシーケンスが含まれます。 連続する等しい要素のみをチェックする単純なアプローチは、中央値が明白でない位置で繰り返されるシーケンスでは失敗する可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのパーティションを反復処理し、各部分配列の長さが奇数であるかどうかをチェックし、その中央値を計算します。 これが機能するのは、有効なパーティションは開始位置と終了位置の列挙から構築できるためです。 主な問題は、候補部分配列ごとに中央値を繰り返し計算するのにコストがかかることです。`O(n log n)`サブ配列ごとに、およそ`O(n^2)`部分配列、与える`O(n^3 log n)`複雑。 これでは遅すぎます。 

重要な洞察は、中央値をサブ配列ごとに最初から再計算する必要がないということです。 すべての中央値は同一である必要があるため、配列内の各要素を候補中央値として試すことができます。 次に、配列をその中央値を基準とした「スコア配列」に変換できます。`+1`要素が大きい場合、`-1`小さければ、そして`0`等しい場合。 部分配列がこの中央値を持つには、中央値要素が適切にカウントされた状態で、部分配列に中央値以下の要素よりもそれ以上の要素が含まれている必要があります。 これにより、問題は、候補中央値に対する要素の「バランス」が負でない場合に、プレフィックス合計の最長シーケンスを見つけるという問題に軽減されます。 

配列がこのスコア配列に変換されると、動的プログラミング アプローチを使用できるようになります。`dp[i]`インデックスで終わる有効なパーティションの最大数を表します`i`。 各サブ配列は前の奇数インデックスから始まり、負でないバランスを持っています。 すべての候補中央値を反復処理することで、グローバル最大値を決定できます。 問題の構造 (奇数長の部分配列と一意の中央値) により、各候補をチェックすることができます。`O(n^2)`部分配列を繰り返しソートする必要はありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3 log n) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内のすべての一意の要素を候補中央値として特定します。 有効な部分配列を定義できるのは中央値自体だけであるため、これらの候補を反復処理することで、可能性が失われることがなくなります。 
2. 候補中央値ごとに、配列を差分配列に変換します。`+1`中央値より大きい要素の場合、`-1`要素が小さい場合、および`0`要素が等しい場合。 これにより、中央値付近の相対的なバランスが把握されます。 
3. この差分配列に対してプレフィックス合計配列を初期化します。 インデックスのプレフィックスの合計`i`開始から終了までの累計残高を表します。`i`- 番目の要素。 
4. 各インデックスについて`i`配列内で、動的プログラミングを使用して、次で終わるパーティションの最大数を計算します。`i`。 以前のすべてのインデックスを考慮する`j`サブ配列が`[j+1..i]`は奇数の長さを持ち、プレフィックス合計配列のバランスは負ではありません。 アップデート`dp[i] = max(dp[i], dp[j] + 1)`それに応じて。 
5. 特定の候補中央値の結果は、`dp`配列。 すべての候補中央値にわたるグローバル最大値を追跡します。 

機能する理由: 候補中央値を基準にして配列を変換し、接頭辞の合計を使用することにより、選択された部分配列が奇数長の中央値条件を満たすことを保証します。 動的プログラミングにより、重複するサブ配列が正しくカウントされ、サブ配列の総数が最大化されることが保証されます。 このアプローチは、すべての一意の配列要素が中央値として試行され、すべてのパーティションのバランスと奇数の長さが評価されるため、網羅的です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def max_subarrays(a):
    n = len(a)
    ans = 1
    for median in set(a):
        diff = [0] * n
        for i, val in enumerate(a):
            if val > median:
                diff[i] = 1
            elif val < median:
                diff[i] = -1
            else:
                diff[i] = 0
        prefix = [0] * (n + 1)
        for i in range(n):
            prefix[i + 1] = prefix[i] + diff[i]
        last_occurrence = {}
        last_occurrence[0] = 0
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = dp[i - 1]
            for j in range(i - 1, -1, -2):
                if prefix[i] - prefix[j] >= 0:
                    dp[i] = max(dp[i], dp[j] + 1)
        ans = max(ans, dp[n])
    return ans

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    print(max_subarrays(a))
```このコードは、まず各配列を候補中央値に対する相対的なスコア配列に変換します。 効率的なサブ配列チェックのためにプレフィックスの合計が計算され、有効なパーティションの最大数を見つけるために動的プログラミングが使用されます。 奇数の長さの慎重な処理は、正しいインデックス パリティを持つサブ配列をチェックすることによって保証されます。
