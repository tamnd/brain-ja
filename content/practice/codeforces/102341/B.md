 ## 解決策
 ## 問題の理解

 グラフは (n) 個のレイヤーで構成され、各レイヤーには正確に (k) 個の頂点が含まれます。 エッジはレイヤー (i) からレイヤー (i+1) までのみ進みます。 つるは有向パスであり、2 つのつるは頂点またはエッジを共有できません。 2 つの層 (i<j) の場合、(f(i,j)) は層 (i) から層 (j) への頂点の共通でない有向パスの最大数です。 タスクは、個別のレイヤーのすべてのペアにわたってこの値を合計することです。 

固定 (i,j) の場合、これは頂点容量が 1 に等しい最大フロー問題です。 すべての頂点を、間に容量 1 のエッジを挟んで、内頂点と外頂点に分割します。 トンネルは無限の容量を受け取り、スーパーソースは層 (i) のすべての頂点に接続され、層 (j) のすべての頂点はスーパーシンクに接続されます。 結果として得られる最大フローは正確に (f(i,j)) です。 

制約 (k\leq 9) がキーです。 層の数は (40000) に達する可能性があるため、(n) の二次関数はすでに大きすぎます。 (n=40000) の場合、層のペアはおよそ (8\cdot 10^8) あるため、すべてのペアの流れの問題を明示的に解決することは不可能です。 一方、(2^k\leq512) は、サブセット動的プログラミングを実用的にします。 受け入れられているアプローチは、まさにこの非対称性を利用し、区間の 2 次数を (2^k) 個のサブセットにわたる (n) 個の遷移で置き換えます。 結果として得られる複雑さは (O(nk^2 2^k)) です。 

誤って処理されやすい境界ケースがいくつかあります。 (k=1) の場合、単一のトンネルが失われると、そのトンネルを横切るすべての区間のフローが直ちにゼロになります。 例えば、```
2 1
0
```答えがあります`0`。 隣接する層のすべてのペアが少なくとも 1 つのパスに寄与すると仮定したソリューションでは、誤った値が返されます。`1`。 

逆の場合も便利です。 (k=1) ですべてのトンネルが存在する場合、```
3 1
1
1
```レイヤーの各ペアには 1 つのパスがあるため、答えは次のようになります。`3`。 最大長のパスのみをカウントするソリューションでは、レイヤー 1 からレイヤー 2 までの間隔を見逃して、結果が返されます。`1`。 

2 番目の微妙なケースは、中間層の 1 つの頂点が使用できない場合に発生します。 最初のサンプルでは、​​最後の行列に 0 行が含まれているため、層 3 から層 4 に渡ることができるパスは 3 つだけです。つまり、前の層では 4 つの互いに素なパスが許容されているにもかかわらず、(f(3,4)=3) となります。 すべてのレイヤーを独立して処理し、接続性をチェックせずに最小数の頂点を取得することは正しくありません。 

## アプローチ

 直接的なアプローチは、すべての間隔 ([i,j]) を考慮し、その頂点容量を持つフロー ネットワークを構築し、最大フロー アルゴリズムを実行することです。 これは正しいです。メンガーの定理により、最小の頂点カットで頂点が互いに切り離されたパスの最大数が特定されるからです。 頂点を分割すると、問題は通常のエッジ容量フローになります。 

問題は間隔の数です。 (\Theta(n^2)) 個あります。 長さ (L) の間隔には、(O(Lk)) 個の頂点と (O(Lk^2)) 個の可能なトンネル エッジが含まれます。 Ford-Fulkerson スタイルの実装でも、最大 (k) 個の拡張が必要で、1 つの間隔で (O(Lk^3)) 個の作業が行われます。 すべての間隔を合計すると、合計は (O(n^3k^3)) になります。 (n=40000) の場合、区間の長さだけの合計は次のようになります。 

[
 \sum_{1\leq i<j\leq n}(j-i)
 =\frac{n(n-1)(n+1)}6,
 】

 これは約 (1.07\cdot10^{13}) です。 (k=9) の場合、フロー オーバーヘッドを考慮する前に、対応する (k^3) 係数により、おおよそ (7.8\cdot10^{15}) 個のエッジ処理ユニットが得られます。 

個々のフロー値が最大 (k) と小さいため、ブルート フォースは機能しますが、基本的に同じ小さな問題を層のペアごとに個別に解決するため、失敗します。 

重要な点は、流量値を直接計算するのではなく、最小カット公式を使用することです。 固定右端点 (r) の場合、(c\in[1,k]) ごとに、最大層 (L_c) を次のように定義します。 

[
 f(L_c,r)\geq c.
 】

 間隔を左に拡張すると、互いに素なパスの収集が難しくなるだけであるため、(c) パスをサポートする左の端点のセットはサフィックスです。 したがって、(f(i,r)\geq c) の左端点 (i<r) の数は単純に (r-L_c) になります。 以来

 [
 f(i,r)=\sum_{c=1}^{k}[f(i,r)\geq c],
 】

 私たちは得ます

 \sum_{c=1}^{k}(r-L_c)。 
】

 したがって、全体の問題は、グラフを左から右にスキャンしながら、これらの (k) 個のしきい値の位置を維持することになります。 

残りの困難は、すべての頂点を明示的に保存せずに最小カットを記述することです。 各レイヤーには (k\leq9) 個の頂点のみが含まれているため、現在のレイヤーでまだ到達可能な頂点をビットマスク (S) で表します。 各サブセット (S) および各カットしきい値 (c) について、必要なサイズのカットが正確に (S) に到達可能な最大の左側のエンドポイントを維持します。 1 つの行列を移動すると、その近傍に変換 (S) され、到達可能なセットから頂点を削除すると、カットで使用される頂点の数が増加します。 どちらの操作もサブセット DP を使用して実行できます。 

これは、標準的に受け入れられているソリューションの背後にある同じ狭い幅の状態圧縮です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^3k^3)) | 1 つのフロー ネットワークの場合 (O(nk^2)) | 遅すぎる |
 | 最適 | (O(nk^2 2^k)) | (O(k2^k)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在のレイヤーのすべてのサブセットを (k) ビット マスクで表します。 ビットが設定されているということは、対応する頂点がカットの左側からまだ到達可能であることを意味します。 
2. すべてのマスク (S) およびすべての (c\in[0,k]) について、`dp[S][c]`。 その値はレイヤーインデックスです。 これは、対応するカット コストを支払った後、少なくとも (c) 単位の接続を保持しながら、現在到達可能なセットが正確に (S) になる、最も左のエンドポイントを表します。 この状態から必要な唯一の情報は、可能な最大の左端点です。これがまさに、答えに寄与する間隔の数を決定するものだからです。 
3. 最初はレイヤー 1 にいます。(S) の頂点が到達可能なままであれば、他の (k-|S|) 頂点は削除できます。 これにより初期しきい値が得られます
 [
 dp[S][c]=1
 】
 いつでも (c\leq k-|S|)。 これより大きいしきい値は不可能であるため、これらのエントリはセンチネル値 (n+1) を受け取ります。 
4. 現在の層と次の層の間のマトリックスを読み取ります。 古いレイヤーのすべての頂点について、その出力近傍のビットマスクを保存します。 サブセット (S) の場合、その完全な近傍はそれらのマスクの結合です。 
5. 新しいレイヤーの頂点を削除する前に、すべての状態を (S) からその近傍 (N(S)) に転送します。 いくつかの古いサブセットが同じ新しいサブセットを生成する場合、それらの状態は同じ到達可能なセットを達成するための代替方法を記述するため、すべての (c) に対して最適なしきい値を維持することによってそれらをマージします。 
6. 次に、新しいレイヤー内の頂点の削除を処理します。 到達可能な集合が (S) の場合、頂点 (u\in S) を削除すると、状態が (S\setminus{u}) に変更され、削除された頂点の数が 1 つ増加します。 DP では、これは 1 ビットのサブセット遷移です。 
[
 dp[S\setminus{u}][c]
 \左矢印
 \max(dp[S\setminus{u}][c],dp[S][c-1])。 
】
 これを設定されたビットごとに適用すると、新しいレイヤーのカット構築全体が実行されます。 
7. 空のセットは、現在のレイヤーのどの頂点も左端点から到達できない状態です。 したがって`dp[0][c]`は、正確に、しきい値 (c) に対応するカットによってそのエンドポイントを現在の層から切断できる最大の左エンドポイントです。 
8. すべての (c=1,\ldots,k) に対して、次を追加します。 
[
 r-dp[0][c]
 】
 答えに。 これは、少なくとも (c) 個の互いに素なパスが存在する左端点 (i<r) をカウントします。 これを (c) で合計すると、層 (r) で終わるフロー値の正確な合計になります。 
9. すべての (n-1) 行列を続けます。 必要な DP 層は 2 つだけであるため、メモリ消費量は残ります (O(k2^k))。 

正確性不変条件は、層 (r) を処理した後、すべての状態が`dp[S][c]`は、層 (r) で到達可能な正確な (S) を残し、しきい値 (c) をサポートするカットと互換性のある最も左のエンドポイントを保存します。 近傍トランジションはまさに頂点をカットせずに次のレイヤーを横切る効果ですが、サブセットトランジションはそのレイヤー内のカット頂点の可能な選択肢をすべて列挙します。 したがって、空集合状態では、考えられるすべての頂点カットが考慮されます。 最大フロー最小カット定理によれば、そのしきい値は、対応する頂点分離パスの数に相当します。 最後に、左エンドポイントの単調性により、各しきい値が単純なカウント (r-dp[0][c]) に変換されるため、すべての (f(i,r)) が寄与するフロー単位ごとに 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, k = map(int, input().split())

    size = 1 << k
    inf = n + 1

    popcnt = [0] * size
    for mask in range(1, size):
        popcnt[mask] = popcnt[mask >> 1] + (mask & 1)

    bits = [[] for _ in range(size)]
    for mask in range(1, size):
        x = mask
        cur = bits[mask]
        while x:
            b = x & -x
            cur.append(b.bit_length() - 1)
            x ^= b

    dp = [[inf] * (k + 1) for _ in range(size)]

    for mask in range(size):
        lim = k - popcnt[mask]
        row = dp[mask]
        for c in range(lim + 1):
            row[c] = 1

    ans = 0

    def merge(dst, src):
        a0 = dst[0]
        b0 = src[0]

        if a0 <= b0:
            base = a0
            for c in range(1, k + 1):
                x = src[c]
                if x == b0:
                    x = base
                if x > dst[c]:
                    dst[c] = x
        else:
            base = b0
            old0 = a0
            for c in range(1, k + 1):
                x = dst[c]
                if x == old0:
                    x = base
                y = src[c]
                if y > x:
                    x = y
                dst[c] = x
            dst[0] = base

    def merge_shift(dst, src):
        a0 = dst[0]
        b0 = src[0]

        if a0 <= b0:
            base = a0
            for c in range(1, k + 1):
                x = src[c - 1]
                if x == b0:
                    x = base
                if x > dst[c]:
                    dst[c] = x
        else:
            base = b0
            old0 = a0
            for c in range(1, k + 1):
                x = dst[c]
                if x == old0:
                    x = base
                y = src[c - 1]
                if y > x:
                    x = y
                dst[c] = x
            dst[0] = base

    for layer in range(2, n + 1):
        to = [0] * k

        for u in range(k):
            s = input().strip()
            while not s:
                s = input().strip()

            mask = 0
            for v, ch in enumerate(s):
                if ch == '1':
                    mask |= 1 << v
            to[u] = mask

        # neigh[mask] = union of all outgoing neighbors of vertices in mask.
        neigh = [0] * size
        for mask in range(1, size):
            b = mask & -mask
            u = b.bit_length() - 1
            neigh[mask] = neigh[mask ^ b] | to[u]

        nxt = [[inf] * (k + 1) for _ in range(size)]

        # Cross the current matrix without deleting a vertex.
        for mask in range(size):
            merge(nxt[neigh[mask]], dp[mask])

        dp = nxt

        # Delete vertices in the new layer.
        for mask in range(size - 1, 0, -1):
            src = dp[mask]
            for u in bits[mask]:
                merge_shift(dp[mask ^ (1 << u)], src)

        # A cut cannot need a left endpoint beyond the current layer.
        for mask in range(size):
            lim = k - popcnt[mask]
            row = dp[mask]
            for c in range(lim + 1):
                if row[c] > layer:
                    row[c] = layer

        empty = dp[0]
        for c in range(1, k + 1):
            ans += layer - empty[c]

    print(ans)

if __name__ == "__main__":
    main()
```実装の最初の部分では事前計算が行われます。`popcnt`そして各マスクのセットビット。 すべてのレイヤで同じサブセット構造が使用されるため、これを一度実行すると、マスクを繰り返しデコードする必要がなくなります。 

の`to`配列は、1 つの頂点の出力近傍をビットマスクとして保存します。 の`neigh`次に、配列は標準の最下位ビット反復によって構築されます。 もし`b`の 1 ビットです`mask`の近所`mask`の近所です`mask ^ b`その単一の頂点の近傍を結合します。 これにより、すべての (2^k) サブセットの近傍計算がレイヤーごとに (O(2^k)) に削減されます。 

の`merge`ルーチンには特別な注意が必要です。 DP 行は、単に独立した値の集合ではありません。 その 0 番目のエントリは、表現されたしきい値間隔の境界を決定します。 同じサブセットを取得する 2 つの方法を組み合わせる場合、コンポーネントごとの最大値を取得する前に、ソース行の 0 番目の境界に等しいエントリをより適切な境界にシフトする必要があります。 これはまさに参照遷移によって実行される正規化です。`merge_shift`頂点を 1 つ削除した後も同じ操作です。 一時的にシフトされた配列を構築する代わりに、ソースエントリを直接処理します。`src[c - 1]`目的地のエントリとして`c`。 遷移はすべてのサブセットおよびすべての設定ビットに対して実行されるため、一時的な行割り当てを回避することが重要です。 

削除フェーズでのマスクの降順は意図的なものです。 のための状態`mask`より大きなサブセットを表す状態が現在の遷移に必要な情報を上書きする前に、これを使用する必要があります。 ソース コードの同等の操作は、完全なマスクから下方向にマスクを処理します。 

答えは Python の任意精度の整数型で保存されるため、オーバーフローの問題はありません。 考えられる最大の答えは (k\binom n2) であり、Python の整数で簡単に表現できます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | (O(nk^2 2^k)) | (2^k) 個のサブセット状態があり、各遷移では最大 (k) 個の頂点と (k) 個のしきい値が考慮されます。 |
