 ## 解決策
 ## 問題の理解

 長さのシーケンスを構築するように求められます$n$、各要素は固定の整数間隔内にあります$[l, r]$。 シーケンスは任意ではありません。連続する要素は、隣接する要素間のステップ サイズが常に素数である制約付きウォークのように動作する必要があり、同時にすべての連続するペアがシーケンス内でこれまでに出現したことのない合計を生成する必要があります。 

したがって、境界付きセグメント内の整数に対して効果的にパスを構築していることになります。 からの各ステップ$a_i$に$a_{i+1}$差の絶対値が素数であり、トラバースするすべてのエッジが「合計ラベル」を生成する場合にのみ許可されます。$a_i + a_{i+1}$これはパス全体でグローバルに一意である必要があります。 

境界は十分に小さいので、値が 2000 を超えることはありません。$n$最大 1000 のテスト ケースで、テスト ケースごとに最大 1000 になります。 これにより、大幅に枝刈りされない限り、テスト ケースごとに二次関数以上の構築が除外されます。 ただし、値の範囲がわずか 2000 であることが重要な構造上の制約です。状態空間は十分に小さいため、単純な貪欲な構造や固定パターンが実行可能になります。 

素朴な解釈では、これを完全なグラフ パス構築問題のように扱おうとします。つまり、次の整数に対してグラフを構築します。$[l, r]$、絶対差が素数の場合はエッジを接続し、次の長さのパスを見つけようとします。$n$エッジラベルの一意性制約付き。 「合計は別個でなければならない」という条件はすべてのエッジをローカルではなくグローバルに結合するため、これはすぐに困難になります。 

微妙なエッジ ケースは、間隔が小さすぎて有効なプライム ステップを 1 つも許可できない場合です。 たとえば、次の場合$l = r$、その場合、移動は不可能になり、$n > 1$答えが不可能になります。 別の失敗例が発生するのは、$r - l$は小さく、素数 2 のみが使用できるため、単一のパリティ クラスでの移動が強制され、貪欲な構造がすぐにトラップされる可能性があります。 

## アプローチ

 ブルートフォース試行では、DFS またはバックトラッキングを使用してすべての可能なシーケンスを構築し、各ステップで素数によって異なる次の値を選択し、そのペアの合計がすでに使用されているかどうかを確認します。 各状態は、最後の値と使用された合計のセットを保存します。 

各ステップでは、最大でも約$r - l \le 2000$しかし、一意性制約がグローバルヒストリーに依存するため、枝刈りは弱いです。 最悪の場合、これは指数関数的に増加します。$O((r-l)^n)$、それはたとえ小さなものであっても完全に実行不可能です$n$。 

重要な点は、グラフを探索する必要がまったくないということです。 必要なのは単一の有効な構造だけであり、最適パスや最大パスは必要ありません。 制約は対称的で、動きに関しては局所的ですが、合計の一意性においてのみグローバルです。 これは、合計を繰り返すような方法で値を再検討することを避け、代わりに設計により合計が自動的に区別される構造を強制する必要があることを示唆しています。 

明確な合計を保証する簡単な方法は、連続する値の各ペアが固定パターンの互いに素な「レベル」から取得されるように強制することです。あるいはさらに強力には、すべての遷移で合計の繰り返しを防ぐ固定ステップ パターンが使用されるようにすることです。 素数には 2 が含まれるため、最も安定した構成は、差が固定され、合計が厳密に増加する 2 つの値を交互に配置することです。 

これにより、2 つの値を選択する構造が得られます。$x$そして$y$そのような$|x - y|$は素数であり、それらをパターンで繰り返します。 合計は次のいずれかです$x + y$繰り返したり、$x + x$、$x + y$、$y + x$、$y + y$パターンの選択によります。 ただし、合計の繰り返しは禁止されているため、唯一の安全な方法は、すべてのエッジで個別のペアを使用することを保証することです。これは、順序付けされていないペアを再利用しない場合に最も簡単です。 これにより、固定素数ステップを使用して厳密に一方向に移動し、合計が厳密に増加することを保証する、ライン上のパス状のトラバースに向けて推進されます。 

より明確な洞察は、主要なステップを選択すると、$p$そして構築する$a_i = l + (i-1)p$、差は一定ですが合計は繰り返され、条件に違反します。 そこで、差分をプライムのままにしながら、各ペアの合計が一意になるように、オフセットを増やして方向を交互に変えます。 

最後の建設的なアイデアは、固定プライム ステップを使用して区間を直線的に歩くことです。$p = 2$(最小の素数) ただし、エッジの再訪を避けることで合計を再利用しないようにします。境界に達するまで前に進む単純なパスを構築し、必要に応じて開始点を移動して方向を調整します。 ドメインが小さいため、単調和シーケンスを生成する有効な開始オフセットと方向を常に見つけることができます。 

実際には、決定論的な構造が存在します。$p = 2$、から始めます$l$、エッジを再利用しないジグザグのパスを構築します。 各エッジは一意であり、走査は単純であるため、合計は自動的に区別されます。

 ## アルゴリズムのチュートリアル

 可能な限り 2 の固定プライム ステップを使用して単純なパスを構築し、範囲内に収まるように方向を調整します。 

1. 事前に計算するか、2 が素数であると仮定するため、範囲内であれば ±2 による移動は常に有効です。 これにより、間隔全体にわたって機能する安定したステップが得られます。 
2. から始める$l$最初の要素として。 これによりシーケンスが下限の境界に固定され、上方に移動する余地が最大化されます。 
3. 次の各位置について、それが ≤ r のままであれば +2 ずつ移動しようとします。 そうでない場合は、≧ l のままであれば -2 ずつ移動するように切り替えます。 
4. まで続けます$n$要素が生まれます。 これにより、間隔内で決定的なウォークが作成されます。 
5. いずれかの点で +2 も -2 も不可能な場合は、間隔が小さすぎて長さをサポートできません。$n$シーケンスなので、-1 を出力します。 

これが機能する理由は、すべてのステップが固定の大きさ 2 (素数) を持ち、シーケンスが値を再利用することがないため、隣接するすべての合計が 2 つの異なる連続状態の間にあるためです。 ウォークではエッジを逆の順序で再利用したり、ペアを繰り返したりすることがないため、合計は自動的に区別されます。 

### なぜ効果があるのか

 この構造では、単純な不変条件が強制されます。つまり、連続するすべてのペアは、整数線上の単一の単純なパスに沿った一意の順序付けされた遷移になります。 各遷移は固定ステップの大きさによって定義され、ウォークは決してエッジを再訪問しないため、ペアは存在しません。$(a_i, a_{i+1})$を繰り返します。 合計を繰り返すには、ペアを繰り返すか、ペアの注文を交換する必要がありますが、どちらも有向ウォーク構造によって阻止されます。 したがって、両方の制約が同時に成立します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, l, r = map(int, input().split())

        # If we only have one value, trivial case
        if l == r:
            if n == 1:
                print(l)
            else:
                print(-1)
            continue

        # Try to construct a simple alternating path using step 2
        # We will attempt to build a forward walk first
        cur = l
        res = [cur]

        direction = 2  # +2 initially

        possible = True

        for _ in range(n - 1):
            nxt = cur + direction

            if nxt < l or nxt > r:
                # flip direction
                direction *= -1
                nxt = cur + direction

            if nxt < l or nxt > r:
                possible = False
                break

            res.append(nxt)
            cur = nxt

        if not possible:
            print(-1)
        else:
            print(*res)

if __name__ == "__main__":
    solve()
```このコードは、次から始まる単一のチェーンを構築します。$l$そして繰り返し移動しようとします$+2$。 間隔を離れると方向を変えて移動します$-2$。 これにより、すべての差が正確に 2 になることが保証され、主条件が満たされます。 

境界の処理は非常に重要です。方向を反転した後に 2 回目のチェックを行わないと、間隔が小さすぎる場合に境界の外へ移動しようとする可能性があります。 この構築は、十分に広い間隔内で、必要な長さの ±2 ウォークが常に存在するという事実に基づいています。

 ## 特殊なケース

 いつ$l = r$、すべての要素が等しい配列のみが可能です。 もし$n = 1$、これは有効であり、単一の値を返します。 もし$n > 1$、素数の差は不可能であるため、アルゴリズムは構築を試みる直前に -1 を正しく出力します。 

間隔が非常に短い場合（次のような場合）$l = 2, r = 3$、唯一可能な違いは 1 であり、これは素数ではありません。 このアルゴリズムは、±2 の移動を試み、すぐに両方の無効な方向を検出し、不可能に一致する -1 を返します。 

間隔が大きい場合、±2 ウォークは多くのステップで境界に到達することなく進行し、全長シーケンスが生成されます。 決定論的なステッピングにより、バックトラッキングが必要ないことが保証されるため、シーケンスは次のステップまでクリーンに構築されます。$n$要素が生まれます。
