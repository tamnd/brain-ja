 ## 解決策
 ## 問題の理解

 私たちは、すべてのセルが白から始まる無限の正方形グリッドに取り組んでいます。 次に、正確に選択します`n`セルを赤く再ペイントします。 グリッドは、各セルが単位エッジによって隣接する 4 つのセルに接続されているグラフと見なされます。 

色を塗った後、赤のセルと白のセルを接続するすべてのエッジを調べます。 これらはブルーエッジと呼ばれます。 任務は、`n`このような境界エッジの数ができるだけ少なくなるように赤セルを作成し、その最小値を計算します。 

重要な問題は、同じ数の赤血球でも形状が異なると境界サイズが異なることです。 細長い形状は周囲長を大きくし、コンパクトな形状は周囲長を最小限に抑えます。 問題は本質的に、接続または切断された結合の最小周囲長を求めることです。`n`グリッドセル。 

制約`n ≤ 10^18`建設的なシミュレーションやシェイプ上の DP は即座に除外されます。 形状を明示的に構築したり、グリッド セルを反復したりするアプローチは不可能です。 閉じた形式または直接的な数学的特徴付けが必要です。 

微妙なエッジケースが現れるのは、`n`is small. たとえば、次のようなとき`n = 1`, 赤のセルには青い端が 4 つあります。 いつ`n = 2`、2 つのセルが隣接しているかどうかに応じて、境界が変わります。 セルを直線的に配置する素朴な貪欲なアプローチは、共有エッジによって境界コストが削減されるという事実を無視するため、必ずしも境界を最小化するとは限りません。 

## アプローチ

 この問題を考える強引な方法は、考えられるすべての構成を考慮することです。`n`赤血球を検出し、その境界を計算します。 これは概念的に、各構成をグリッド点のサブセットとして扱い、その後、白いセルに接触するすべてのエッジをカウントすることによって機能します。 ただし、たとえ控えめであっても、`n`を選択しているため、構成の数は組み合わせで増加します。`n`無限グリッドからのセル。 境界ボックスに制限しても形状の列挙は指数関数的に増加するため、これは完全に不可能になります。 

重要な洞察は、問題をグリッド上の幾何最適化問題として再構成することです。 一連のグリッド セルの境界は周囲のように動作し、最適な形状は常に可能な限りコンパクトになります。 グリッドでは、コンパクトとは正方形に近い領域を形成することに対応します。 これは、L1 隣接制約の下では正方形が最適な、連続ジオメトリの固定領域の周囲を最小化することに似ています。 

最適な形状が長方形に似ていることを受け入れたら、問題は寸法の選択に集約されます。`a × b`そのような`a * b ≥ n`そして周囲`2(a + b)`最小化されます。 最適な構成は、少なくとも面積のある長方形です。`n`それは周囲が最も小さいものです。 

四角形内で未使用のセルを自由に残しておくことができるため (少なくとも`n`スロット)、最大の候補ディメンションを試す必要があるだけです。`sqrt(n)`。

 ## アルゴリズムのチュートリアル

 次に、幾何学的な洞察を具体的な手順に変換します。 

1. 最適な構成はすべて次元の長方形として扱うことができることに注目してください。`a × b`と`a * b ≥ n`。 これは、不規則な形状を局所的に再配置して、セルの数を減らすことなく周囲を縮小できるためです。 
2. 固定幅の場合`a`、最小の高さを決定します`b`すべてに適合するために必要な`n`細胞、つまり`b = ceil(n / a)`。 これにより、長方形に十分なセルが含まれるようになります。 
3. この長方形の周囲の寄与を次のように計算します。`2(a + b)`。 これは、4 つの側面すべてで白セルに露出しているエッジの数を表します。 
4. 可能なすべての値を反復処理します。`a`から`1`に`floor(sqrt(n))`。 平方根まで行く必要があるだけです。それを超えると、ペアの次元が`b`は小さくなり、別の反復ですでに考慮されているはずです。 
5. 有効なすべての最小周囲長を追跡します。`(a, b)`ペア。 見つかった最小値が答えになります。 

### なぜ効果があるのか

 重要な不変条件は、最適な構成は境界を増やすことなく単調な凸形状に変換できるということです。 グリッド上で、固定数のセルに対して最も周効率の高い凸形状は、可能な限り正方形に近い長方形です。 すべての因子ペアに対する反復により、このようなコンパクトな配置から生じる可能性のあるすべての候補アスペクト比を確実に検査できるため、最小周囲長方形が必然的に検索空間に表示されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        
        ans = 10**30
        
        a = 1
        while a * a <= n:
            b = (n + a - 1) // a
            ans = min(ans, 2 * (a + b))
            a += 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```コードは各テスト ケースを個別に処理し、可能な四角形の幅に対して直接検索を適用します。 変数`a`は候補行数を表し、`b`すべてをカバーするために必要な最小列数として計算されます。`n`細胞。 

表現`2 * (a + b)`長方形の周囲を直接エンコードします。 整数の上限除算は次を使用して実装されます。`(n + a - 1) // a`、浮動小数点演算を回避し、最大の大きな値の正確性を保証します。`10^18`。 

ループバウンド`a * a <= n`重要です。 これにより、平方根までのみ反復処理が行われるようになり、次元を交換しても周囲長が改善されない対称ケースの不必要な再計算が防止されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    t = int(input())

        n = int(input())

    return "\n".join(out)

 ## 特殊なケース

 のために`n = 1`、アルゴリズムがチェックします`a = 1`、与える`b = 1`と周囲`2(1+1) = 4`。 これは、1 つのセルが 4 つの白い隣接セルと接触するという事実と一致します。 

のために`n = 2`、候補者は`(1,2)`そして`(2,1)`、両方とも周囲を生成します`2(3) = 6`。 これにより、アルゴリズムが非対称の最小形状を正しく処理していることが確認されます。 

次のような完全な正方形の場合`n = 100`、ループは到達します`a = 10`、生産`b = 10`と周囲`40`。 これを改善する要因ペアは他にありません。これは、アルゴリズムがバランスのとれた構成を最適なものとして正しく識別していることを示しています。
