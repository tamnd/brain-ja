 ## 解決策
 ## 問題の理解

 私たちには、強さと知性という 2 つの基本属性を持つキャラクターが与えられます。 また、追加の経験値のプールも与えられており、すべて分配する必要があります。 各ポイントは、強さまたは知性のいずれかを正確に 1 単位だけ増加させることができます。 すべての点を分配した後、最終的な値のペアが得られます。 

タスクは、単一の最適なビルドを計算することではなく、制約の下で有効なさまざまな最終構成がいくつあるかを数えることです。すべての経験値を費やした後、結果として得られる強さは、結果として得られる知性よりも厳密に大きくなければなりません。 最終的な強さまたは最終的な知能のいずれかが異なる場合、2 つの構成は異なるものとみなされます。 

重要な構造は、すべての有効な結果は、強さに割り当てるポイントの数によって完全に決定されるということです。 それが修正されると、すべてのポイントを使用する必要があるため、知能は自動的に決定されます。 

制約はすべてのパラメーターに対して最大 10^8 で、テスト ケースは最大 100 個です。 これにより、テスト ケースごとに exp を反復しても、最悪の場合、すでに 10^10 の演算に達する可能性があるため、すべての分布を明示的に試行するアプローチは直ちに除外されます。 解はクエリごとに O(1) である必要があります。 

有効な分布がない場合、微妙なエッジケースが発生します。 これは、知力が強さに比べて大きすぎる場合に発生するため、すべての経験を強さに注ぎ込んだとしても、厳密には強さが大きくなるわけではありません。 もう 1 つの境界ケースは、exp が 0 の場合です。この場合、可能なビルドは 1 つだけあり、初期不等式がすでに成立している場合にのみ有効です。 

## アプローチ

 直接的なアプローチでは、経験値の可能な限りの分割を試みることになります。 x ポイントを強さに割り当て、exp - x を知力に割り当てると、最終的な値は次のようになります。 

強度 = str + x

 知能 = int + (exp - x)

 x を 0 から exp まで反復して、各ケースの不等式をチェックできます。 これは、考えられるすべての分布を列挙しているため正しいですが、exp は線形です。 経験値が 10^8 までになると、これは完全に不可能になります。 

重要な観察は、不等式制約を x の線形不等式に書き換えることができるということです。 これにより、問題は、制限された区間内の整数解をカウントすることに変わります。 それが完了したら、制約を満たす x の範囲を見つけて、その中に含まれる整数の数を数えるだけで済みます。

 | ブルートフォース | O(exp) | お(1) | 遅すぎる |
 | 最適 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 x は強さに割り当てられる経験値の数を示します。 その後、知力は経験値 - x ポイントを獲得します。 

1. 最終的な属性を方程式として表現します。 

強さ = str + x、知性 = int + exp - x。 
2. 強度 > 知能という条件を不等式に変換します。 

str + x > int + exp - x。 
3. x に関係するものをすべて片側に並べ替えます。 

2x > int + exp - str.
 4. x を整数の下限として解きます。 

x > (int + exp - str) / 2.
 5. 厳密な不等式を最小の整数 x に変換します。 

x_min = フロア((int + exp - str) / 2) + 1。 
6. x の定義方法に基づく実現可能性の制約を強制します。 

0 ≤ x ≤ exp.
 7. 有効なビルドの数は、間隔 [x_min, exp] (存在する場合) のサイズです。 

これが機能する理由: すべての有効なビルドは、[0, exp] 内の 1 つの整数 x に正確に対応します。 この不等式は単一の線形制約に帰着するため、有効なビルドのセットは連続した整数の間隔になります。 解をカウントすることは、その区間内の整数点をカウントすることになり、2 つの異なる x 値が同じ (強さ、知能) ペアを生成することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    out = []
    
    for _ in range(T):
        str_val, int_val, exp = map(int, input().split())
        
        # Solve inequality:
        # str + x > int + (exp - x)
        # 2x > int + exp - str
        
        rhs = int_val + exp - str_val
        
        # minimal integer x satisfying strict inequality
        # x > rhs / 2
        x_min = rhs // 2 + 1
        
        if x_min < 0:
            x_min = 0
        
        if x_min > exp:
            out.append("0")
        else:
            out.append(str(exp - x_min + 1))
    
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装の中核は、x の有効な最小値を計算することです。 この不等式により厳密な半境界が生成されるため、整数の除算を使用して慎重に変換します。 Python は負の無限大に向かって下降するため、次を使用します。`rhs // 2 + 1`正と負の両方の rhs ケースを正しく処理します。 

計算後`x_min`、有効なドメイン [0, exp] にクランプします。 exp を超える場合は、有効な構成が存在しません。 それ以外の場合、x_min から exp までのすべての整数は 1 つの有効なビルドに対応するため、それらを直接カウントします。

 ## 特殊なケース

 exp がゼロの場合、x は強制的にゼロになります。 アルゴリズムは不等式に基づいて x_min を設定し、それを [0, exp] にクランプします。 制約で x = 0 が許可されている場合は、正確に 1 つのビルドがカウントされます。 それ以外の場合、x_min が exp を超え、答えはゼロになります。 

知力が体力よりもはるかに大きい場合、rhs は大きくて正になり、x_min が経験値を超えます。 その場合、間隔 [x_min, exp] は空であり、アルゴリズムは反復なしで正しく 0 を返します。 

強度がすでに大きい場合、rhs は負になり、x_min は負の数に評価されます。 これをゼロに固定すると、すべての分割が強さの優位性を維持するという事実と一致して、すべての可能な割り当てが確実にカウントされます。
