 ## 解決策
 ## 問題の理解

 私たちは、`N × M`長方形の板。 チップは左上のセルから始まり、ボードを覆うらせん状のパスに沿って移動します。 まさにその後`k`移動した場合、チップが停止するセルの色を決定する必要があります。 ボード自体は大きすぎるため付属しておりません。 そのカラーリングは繰り返される虹のパターンに従っています。すべての斜めのストライプには 7 つの色のいずれかがあり、その色は周期的に繰り返されます。 答えは、最後のセルに割り当てられた 1 から 7 までの数字です。 

寸法は次のように大きくできます。`10^9`, そのため基板の構築は不可能です。 すべてのセルを反復処理することすら不可能です。`10^18`細胞。 このソリューションでは、少数の算術演算のみを実行する必要があるため、状況に応じたアプローチは除外されます。`N`、`M`、または訪問されたセルの数。 

The difficult cases are caused by the huge dimensions and by the fact that the spiral changes direction only at borders. A direct simulation often fails at exactly those places.

 たとえば、単一セルボードの場合は次のようになります。```
1 1 0
```チップは開始セルから離れることはありません。 答えはきっと次の色です`(0, 0)`、スパイラルステップを実行しようとした結果ではありません。 

もう 1 つの重要なケースは、非常に薄い基板です。```
1 5 3
```螺旋はただの直線です。 すべての層に空ではない 4 つの側面があると想定した実装では、ボードの外側のセルにアクセスできます。 

最終的な境界ケースは次のような場合です。`k`まさにレイヤー上の最後の動きです。 例えば：```
3 3 8
```8 回移動した後、チップは外側の正方形の最後のセルに到達します。 現在のレイヤーを確認する前に次のレイヤーを見つけるソリューションでは、間違った座標が生成されます。 

## アプローチ

 簡単な解決策は、ボードを保管するか、スパイラルをシミュレートすることです。 現在の位置と方向を覚えておくだけで済むので、シミュレーションは簡単です。 移動するたびに、次のセルがボード内にあるかどうか、およびそのセルがすでに訪問されているかどうかがチェックされます。 後`k`移動すると色が計算されます。 

これが機能するのは、スパイラル パスに単純なローカル ルールがあるためです。 問題は制約です。 最悪の場合、`N`そして`M`両方です`10^9`、ということもありえます。`10^18`セルとシミュレーションには約`10^18`操作。 数十億回の操作でも制限時間をはるかに超えています。 

重要な観察は、スパイラルが長方形の層で構成されていることです。 すべてのステップを実行する代わりに、外側のレイヤーを完全にスキップすることもできます。 取り外し後`s`外側からのレイヤー、残りの長方形のサイズ`(N - 2s) × (M - 2s)`。 レイヤーに入る前にすでに通過したセルの数`s`直接計算できます。 これにより、二分探索で正しいレイヤーを見つけることができます。 

層が判明すると、残りの移動回数はその層の周囲に比べて少なくなります。 現在の長方形のどちら側に残りの距離が含まれているかを確認することで位置を決定できます。 次に、色は対角インデックスの直後に続きます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k) | O(NM) | 遅すぎる |
 | 最適 | O(log(分(N, M))) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 二分探索を使用して、答えを含むスパイラル層を見つけます。 レイヤー`s`行の四角形が含まれています`s`漕ぐ`N-1-s`そしてコラムから`s`列へ`M-1-s`。 この層の前のセルの数は、外側から削除された領域です。`N*M - (N-2*s)*(M-2*s)`。 

すでに開始点に到達している最大の有効な層は、チップを含む層です。 

1. 座標系を選択したレイヤーに移動します。 前のレイヤーに費やされた移動数をから引きます。`k`。 チップはこの小さな長方形の左上隅から開始されます。 
2. この層の周囲を数学的に歩き回ります。 螺旋は最初に右に進み、次に下に進み、次に左に進み、次に上に進みます。 各辺の長さから、残りの距離がその辺にあるかどうかがわかります。 
3. 最終的なゼロベースの座標を色に変換します。 斜めのストライプは次のように決定されます。`row + column`。 必要な色は次のとおりです。`(row + column) mod 7 + 1`。 

これが機能する理由は、スパイラルのすべての完全な外側の層がその内側の層から独立しているためです。 チップは、現在の層のすべてのセルが通過する前に内層に入ることができません。 二分探索によりチップが停止する層が正確に検出され、副次的な計算では元のスパイラルと同じ順序が維持されます。 最終的な座標は、完全なシミュレーションが到達する座標と同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M, k = map(int, input().split())

    def before(layer):
        return N * M - (N - 2 * layer) * (M - 2 * layer)

    lo, hi = 0, min(N, M) // 2
    while lo <= hi:
        mid = (lo + hi) // 2
        if before(mid) <= k:
            lo = mid + 1
        else:
            hi = mid - 1

    layer = hi
    k -= before(layer)

    top = layer
    left = layer
    bottom = N - 1 - layer
    right = M - 1 - layer

    r, c = top, left

    if top == bottom:
        c += k
    elif left == right:
        r += k
    else:
        top_len = right - left
        if k <= top_len:
            c += k
        else:
            k -= top_len
            down_len = bottom - top
            if k <= down_len:
                r += k
            else:
                k -= down_len
                left_len = right - left
                if k <= left_len:
                    c = right - k
                    r = bottom
                else:
                    k -= left_len
                    r = bottom - k
                    c = left

    print((r + c) % 7 + 1)

if __name__ == "__main__":
    solve()
```機能`before(layer)`が中心的なショートカットです。 要求された層よりも前のすべての外側層に属するセルの数をカウントします。 コーディネートや商品が届くので`10^18`, Python の整数は、オーバーフローを心配することなく自然に使用されます。 

二分探索では、可能なレイヤーの数だけを検索します。`5 * 10^8`したがって、必要な反復回数は 30 回未満です。 

レイヤーを見つけた後、コードはまず縮退ケースを処理します。 1 行または 1 列の残りの長方形には意味のある 4 辺がないため、個別に扱うことで無効な長さを回避できます。 

通常の長方形の場合、残りの動きをスパイラル順に 4 つの辺と比較します。 比較では、セルではなく移動単位で測定された辺の長さを使用するため、コーナーでの 1 つ違いのミスが回避されます。 

## 実用的な例

 指定されたサンプルを使用して:```
5 9 25
```レイヤーは次のように処理されます。 

| ステップ | レイヤー | レイヤー前のセル | 残りの手数 | ポジション |
 | --- | --- | --- | --- | --- |
 | 開始 | 0 | 0 | 25 |`(0,0)`|
 | 上面 | 0 | 0 | 17 |`(0,8)`|
 | 右側 | 0 | 8 | 13 |`(4,8)`|
 | 底面 | 0 | 12 | 5 |`(4,0)`|
 | 左側 | 0 | 20 | 2 |`(2,0)`|
 | 再び上面 | 0 | 23 | 2 |`(1,2)`|

 最後のセルは、`(1,2)`。 その対角インデックスは`1 + 2 = 3`、色は`4`。 

小さな薄い基板の例:```
1 5 3
```唯一の層には 1 つの行があるため、チップは行を直接横切って移動します。 

| ステップ | 残りの手数 | ポジション |
 | --- | --- | --- |
 | 開始 | 3 |`(0,0)`|

 | 移動 | 0 |`(0,3)`|

 対角インデックスは`3`、色を与える`4`。 

これらのトレースは、アルゴリズムが個々の動きをすべて回避しながら、元のスパイラルと同じ順序を維持していることを示しています。

 ## 特殊なケース

 のために`1 × 1`ボードの場合、二分探索によりレイヤー 0 が選択され、残りの長方形の寸法は両方とも 1 になります。 単一セルの特別な処理では開始位置が返されるため、入力```
1 1 0
```色を生み出す`1`。 

などの単列基板の場合```
1 5 3
```残りの長方形には`top == bottom`。 このアルゴリズムは、存在しない垂直辺を横断しようとせず、単に行に沿って列に移動します。`3`、色を与える`4`。 

レイヤーの境界で正確に終了する移動の場合:```
3 3 8
```アルゴリズムはチップをレイヤー 0 内に保持します。`k`はまだその層の境界内にあります。 届く`(2,0)`、対角インデックスは`2`、色を生み出す`3`。 これにより、内層に切り替えるのが 1 つ早すぎるというよくある間違いを回避できます。
