 ## 問題の理解

 整数の複数セットが与えられます。これは、各ビー玉が数値で表される色を持つビー玉の袋と考えることができます。 タスクは新しいマルチセットを生成することです`s`まず元のマルチセットを空ではない任意の数のサブセットに分割し、次に各サブセットからそのモードの 1 つ (そのサブセット内で最も頻繁に出現する数) を選択します。 結果のマルチセット`s`これらの選択されたモードで構成されます。 個別のマルチセットがいくつあるかを数える必要があります`s`この方法で生成できます。 

入力は複数のテスト ケースで構成されます。 それぞれの場合にサイズが与えられます`n`マルチセットと要素自体の。 各要素は次の範囲内にあることが保証されます`1`そして`n`。 出力は個別のマルチセットの数です。`s`モジュロ`998,244,353`。 

制約は非常に重要です。 すべての合計`n`これは、合計で最大 5000 個の要素を持つことができても、非常に大規模なデータセットを扱っているわけではないことを意味します。 ただし、組み合わせ爆発には注意する必要があります。 すべてのパーティションを明示的に試行する単純なアプローチでは、サイズのベル数を列挙しようとします。`n`、超指数関数的に成長し、実行不可能になります。 平`n=20`数百万のパーティションを作成できます。 

すべての要素が等しい場合、エッジ ケースが発生します。 たとえば、次の場合`a = [1,1,1]`、すべてのパーティションに同じモードがあるため、カウントが大幅に減少します。 逆に、すべての要素が異なる場合、空でないすべてのサブセットが異なるマルチセットを生成する可能性があります。 不注意なアルゴリズムは、マルチセットを二重にカウントしたり、モードの多重度を尊重しなかったりする可能性があります。 

## アプローチ

 ブルート フォース アプローチでは、マルチセットの考えられるすべてのパーティションが列挙されます。 パーティションごとに、サブセットからモードの可能なすべての選択肢を計算し、結果として得られるマルチセットを収集します。 このアプローチは原理的には正しいですが、次のような人にとっては扱いにくくなります。`n > 10`セットのパーティションの数は、`2^n`。 各パーティションでは、そのサブセットのモードを計算する必要もあり、追加のオーバーヘッドが追加されます。 

これを高速化するための重要な洞察は、元のマルチセット内の頻度を考慮して、問題がサブセット内の各要素がモードとして出現できる回数を数えることに帰着するという観察から得られます。 の各数値の頻度を考えてみましょう。`a`。 させて`cnt[x]`数のカウントになる`x`。 各数値は、結果として得られるマルチセットに影響を与える可能性があります`s`ゼロ倍からその周波数までの範囲です。 次に、問題は、すべての数値にわたるこれらの寄与の組み合わせを数えることに帰着します。 

動的プログラミングは自然にここに当てはまります。 させて`dp[i][j]`マルチセットを正確に生成する方法の数を表します`j`最初の要素を使用する`i`個別の数値を表現し、各数値がモードとして現れる可能性があるすべての方法を考慮します。 各数値のすべてのカウントを反復して DP テーブルを更新し、すべてのパーティションが暗黙的に考慮されるようにします。 合計から`n`小さい、DP テーブルのサイズ`n × n`実現可能です。

 ## アルゴリズムのチュートリアル

 1. 階乗とモジュラー逆数を最大まで事前計算する`n`二項係数の高速計算を可能にします。 サブセットを形成する要素を選択する方法を数えるには、組み合わせが必要になります。 
2. 各テスト ケースについて、マルチセット内の各個別の数値の頻度をカウントします。`a`。 させて`cnt[x]`数値の周波数になる`x`。 
3. DP 配列を初期化する`dp`と`dp[0][0] = 1`。 ここ`dp[i][j]`サイズのマルチセットを形成する方法の数を保存します`j`最初のものを使用して`i`明確な数字。 
4. それぞれの個別の数値を反復処理する`x`周波数付き`f = cnt[x]`。 考えられる合計サイズごとに`j`から`n`ゼロまで下げる、更新する`dp[j+k]`みんなのために`k`から`1`に`f`追加することで`dp[j] * C(f, k)`モジュロ`998244353`。 これは選択の理由になります`k`番号のコピー`x`その周波数からモードとして。 
5. すべての数値を処理した後、すべてを合計します。`dp[j]`のために`j >= 1`空ではないマルチセットの総数を取得します。 
6. 和の剰余を出力する`998244353`。 

**機能する理由:** 各数値は、最終的なマルチセットへの寄与の可能性について独立して考慮されます。 すべてのカウントを反復処理し、DP を介してそれらを組み合わせることで、元のマルチセットのすべてのパーティションを明示的に列挙することなく暗黙的に考慮します。 DP の不変条件は次のとおりです。`dp[j]`常にサイズのマルチセットの数を表します`j`これまでに処理された数値から形成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

# Precompute factorials and inverses
MAXN = 5000 + 5
fact = [1] * MAXN
inv_fact = [1] * MAXN

for i in range(1, MAXN):
    fact[i] = fact[i-1] * i % MOD

inv_fact[MAXN-1] = pow(fact[MAXN-1], MOD-2, MOD)
for i in range(MAXN-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def comb(n, k):
    if k < 0 or k > n:
        return 0
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    from collections import Counter
    cnt = Counter(a)
    dp = [0] * (n+1)
    dp[0] = 1
    for f in cnt.values():
        ndp = dp[:]
        for j in range(n+1):
            if dp[j] == 0:
                continue
            for k in range(1, f+1):
                if j+k <= n:
                    ndp[j+k] = (ndp[j+k] + dp[j] * comb(f, k)) % MOD
        dp = ndp
    print(sum(dp[1:]) % MOD)
```このコードは、効率的な二項係数計算のために階乗とモジュラー逆行列を最初に事前計算します。 テスト ケースごとに、数値の頻度をカウントし、DP 配列を初期化し、すべての数値を反復処理して DP テーブルを埋めます。 最後に、空ではないすべてのマルチセット数を合計します。
