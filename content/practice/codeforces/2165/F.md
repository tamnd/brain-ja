 ## 問題の理解

 長さの順列が与えられています$n$、1 から 2 までの異なる整数の配列です。$n$何らかの順序で並べられています。 このタスクは、21435 サブシーケンスと呼ばれる、特定のパターンを含む連続したサブ配列 (間隔) の数をカウントすることです。 具体的には、5 つのインデックスを選択できる場合、部分配列はギザギザになります。$i_1<i_2<i_3<i_4<i_5$サブ配列内で、それらの位置の値が次を満たすようにする$a_{i_2} < a_{i_1} < a_{i_4} < a_{i_3} < a_{i_5}$。 出力はテスト ケースごとに 1 つの整数、つまりギザギザの部分配列の総数です。 

制約により次の合計が得られます。$n$最大のすべてのテスト ケースにわたって$10^6$。 これは、複雑なアルゴリズムはすべて、$O(n^2)$テスト ケースごとにそれ以上では遅すぎます。$n \approx 10^5$につながるだろう$10^{10}$これは 5 秒の制限をはるかに超えています。 したがって、おおよそ線形または線形演算のアルゴリズムが必要です。$n$。 

明らかではないエッジケースには、非常に小さな配列が含まれます。 たとえば、次の場合$n<5$の場合、サブ配列には 21435 のサブシーケンスを含めることはできないため、答えはゼロになります。 すでに昇順または降順にソートされている配列には、ギザギザの間隔がほとんどなく、場合によってはまったくゼロになることもあります。これは、単調なシーケンスでは必要な山と谷の交互が不可能であるためです。 

## アプローチ

 ブルートフォースアプローチはすべてを反復することになる$\frac{n(n+1)}{2}$考えられる部分配列を調べ、それぞれについて 21435 パターンのインデックスの 5 つ組をすべてチェックします。 1 つのサブ配列の長さを確認する$k$費用$O(k^5)$したがって、全体の複雑さは次のようになります。$O(n^7)$最悪の場合。 これは明らかに実行不可能です。 

重要な洞察は、21435 パターンが相対値の観点から「固定されたローカル構成」を持っているということです。 以来$n$は、線形スキャンには十分小さいですが、完全な組み合わせチェックには十分ではありません。ギザギザの間隔の最小値は長さ 5 であるため、長さ 5 のすべての部分配列を調べることができます。長さ 5 の任意の間隔が 21435 パターンを満たす場合、それを含む大きな間隔もすべてギザギザになります。 これは、長さ 5 インチのすべてのパターンをスキャンできることを意味します。$O(n)$時間を計算し、単純な算術を使用して各パターンが「カバーする」間隔の数を数えます。 順列は明確であるため、比較は複雑な等価性ではなく、位置のチェックに限定されます。 

さらに単純化するには、21435 のサブシーケンスは、単調スタック アプローチまたは境界付きウィンドウ スキャンを使用して効率的に見つけることができることに注意する必要があります。考えられる中間要素 (21435 の「1」) ごとに、左側の最大値と右側の最小値を維持し、パターンが存在するかどうかを確認できます。 有効な 21435 として機能する左端と右端の位置を特定したら、組み合わせ論を使用してこれらの位置が含まれる間隔の数を計算できます。$L$そして一番右$R$、 がある$L \cdot (n-R+1)$完全なパターンを含むサブ配列。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。$n$そして順列配列。 変数を初期化する`total_jagged`ゼロに。 ここでギザギザの間隔のカウントを蓄積していきます。 
2. もし$n<5$、すぐに 0 を返します。どの間隔にも 21435 のサブシーケンスを含めることはできません。 
3. 配列をスキャンして、21435 パターンを満たす長さ 5 の連続するセグメントをすべて見つけます。 このような 5 つ組ごとに、左端と右端の位置を記録します。 
4. 識別された各 5 つ組について、それが含まれる間隔の数を計算します。 一番左のインデックスを次のようにします$L$そして右端のインデックスは$R$。 それを含む区間の数は$(L) \cdot (n-R+1)$、間隔は 1 から 1 までのどこからでも開始できるため、$L$そしてどこからでも終わります$R$に$n$。 
5. 識別されたすべての 5 つの組からのカウントを合計します。`total_jagged`。 出力`total_jagged`。 

機能する理由: 21435 パターンの長さ 5 の 5 倍子を少なくとも 1 つ含むすべての間隔はギザギザになります。 5 つの組の可能なすべての位置を列挙し、それらを含む間隔をカウントすることで、すべてのギザギザの間隔を正確にカウントします。 順列は明確であるため、パターンが誤って二重にカウントされることはありません。重複する 5 つの組が、それらを含む間隔に自然に正しく寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def is_21435(sub):
    # Check if a list of length 5 matches 21435 pattern
    return sub[1] < sub[0] < sub[3] < sub[2] < sub[4]

def count_jagged(n, a):
    if n < 5:
        return 0
    total = 0
    # Iterate over all 5-length windows
    for i in range(n - 4):
        window = a[i:i+5]
        if is_21435(window):
            total += (i+1) * (n - (i+4))
    return total

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(count_jagged(n, a))

if __name__ == "__main__":
    main()
```このソリューションは、21435 パターンを含むすべてのサブ配列をカウントするロジックを直接実装します。 機能`is_21435`明示的であるため、off-by-one エラーの可能性が減少します。 長さ 5 の固定ウィンドウを使用すると、インデックス作成が簡素化され、式は次のようになります。`(i+1) * (n-(i+4))`5 倍を含むすべての間隔を正しくカウントします。
