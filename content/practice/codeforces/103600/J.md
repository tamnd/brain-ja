 ## 解決策
 ## 問題の理解

 塩濃度によって特徴付けられる、いくつかの利用可能なソリューションが与えられています。 各溶液から整数グラムを取り出すことができますが、上限は溶液あたり 104 グラムです。 混合後の総質量は選択した質量の合計であり、総塩量は濃度に応じて重み付けされた合計です。 

目標は、濃度が正確に Q パーセントである新しい混合物を少なくとも 100 グラム作成することです。 言い換えれば、濃度 Ti の溶液 i から採取した質量を xi で表すと、最終的な比率は次の条件を満たす必要があります。 

(xi * Ti の合計) / (xi の合計) = Q。 

これは、両辺に分母を掛けることで、より代数的な形式に書き直すことができます。 

合計 xi * (Ti − Q) = 0。 

したがって、各解は係数 ai = Ti − Q に寄与し、0 ≤ xi ≤ 10⁴ と総質量が少なくとも 100 であることを考慮しながら、ai の重み付き合計がゼロになるような非負の整数ベクトル x が必要です。 

この制約では最大 10⁵ の解が許可されるため、解のペアに対する二次戦略は即座に疑われます。 直線または直線に近い構造が必要です。 

微妙な制約は、有効な線形結合が存在する場合でも、少なくとも 100 グラムの総質量を生成する必要があるということです。 等しい大きさの係数を 1 回キャンセルするような縮退した解は、方程式を満たしても質量要件を満たさない可能性があります。 

エッジケースは、解決策がまったく不可能な場合に発生します。 たとえば、すべての Ti が厳密に Q より大きい場合、すべての ai は正となり、非ゼロ、非負の組み合わせの合計がゼロになることはありません。 同様に、すべての Ti が厳密に Q より小さい場合も、同じ不可能性が発生します。 もう 1 つの特殊なケースは、一部の Ti が Q に等しい場合です。 その場合、その解決策のみを使用する自明な構築が存在します。 

## アプローチ

 強引なアイデアは、解のサブセットを選択し、それらに整数の質量を割り当て、結果の加重平均が Q に等しいかどうかをチェックすることです。これはすぐに、n 個の変数で有界整数線形方程式を解く問題になります。 境界を無視したとしても、サブセットの組み合わせを試すとすでに指数関数的な動作が発生し、係数に上限を追加すると直接検索が不可能になります。 

条件を合計 xi(Ti − Q) = 0 として書き直すと、問題は正と負の寄与のバランスに変わります。 各 Ti > Q は正の重みのように機能し、各 Ti < Q は負の重みのように機能します。 一部の Ti がすでに Q に等しい場合を除き、有効な解決策は両方の側面を混合する必要があります。 

重要な単純化は、ゼロ和を構築するには 2 つの値だけで十分であるということです。1 つは正側から、もう 1 つは負側からです。 ai > 0 および aj < 0 のインデックス i と j を選択する場合、次のようにする必要があります。 

xi * ai = xj * (−aj)。 

g を gcd(ai, −aj) とします。 最小の整数解は次のとおりです。 

xi = (−aj / g)、xj = (ai / g)、

 そして、このペアのスケーリングされたバージョンは引き続き有効です。 

xi ≤ 10⁴ および xj ≤ 10⁴ の制約により、このペアをどの程度スケールできるかが制限されます。 考えられるすべてのペアの中で、結果の合計質量が少なくとも 100 になるように、十分に大きなスケーリング係数を許可するペアが必要です。 

すべてのペアを試すと O(n²) になるため、代わりに構造を利用します。実現可能性に関して重要なのは ai の大きさだけです。 係数を小さくすると、10⁴ の上限に達する前に大きなスケーリングが可能になるため、極端な選択が最適になる傾向があります。 

したがって、|Ti − Q| を最小化する正側インデックスと負側インデックスを選択するように検索を簡素化します。 両側にあります。 これにより、通常、比率を単純に保ちながら、使用可能なスケーリング係数が最大化されます。

 ## アルゴリズムのチュートリアル

各濃度を ai = Ti − Q に変換し、指数を正、負、ゼロの 3 つのグループに分けます。 

ai = 0 のインデックスが存在する場合、その溶液 100 グラムを取得し、他のすべての溶液から 0 を取得することで、有効な答えをすぐに構築できます。これは、すでに目標濃度と一致しているためです。 

すべての ai がゼロでなく、すべて同じ符号を持つ場合、負でない組み合わせでゼロを生成することはできず、答えは不可能です。 

それ以外の場合は、1 つの正の値と 1 つの負の値を組み合わせる必要があります。 

1. ポジティブインデックスの候補とネガティブインデックスの候補を選択します。 自然な選択は、最小の正の ai と最小の大きさの負の ai を選択することです。これらは最も単純な比率を与え、10⁴ 制限に達する前に大きなスケーリングを可能にするからです。 
2. 選択したペアについて、gcd を使用して縮小率を計算します。 ai = p > 0 および −aj = q > 0 とします。 g = gcd(p, q) を計算し、基本量 x0 = q / g および y0 = p / g を定義します。 
3. 境界を尊重しながら、このペアを何回スケーリングできるかを決定します。 スケーリング係数 k は、xi ≤ 10⁴ と yi ≤ 10⁴ の両方の制約によって制限されます。 

kmax = min(10⁴ / x0, 10⁴ / y0)。 

1. 可能な最大のスケーリングを使用することで十分な総質量がすでに生成されているかどうか、つまり kmax * (x0 + y0) ≥ 100 であるかどうかを確認します。そうでない場合、このペアは要件を満たすことができません。 
2. 十分であれば、xi = kmax * x0 および yi = kmax * y0 を出力し、その他の値はすべてゼロになります。 

どのペアも機能しない場合、答えは不可能です。 

正しさは、有効な解決策がプラスとマイナスの寄与のバランスをとらなければならないという事実に依存します。 このような解決策はいずれもペアごとのキャンセルに分解でき、少なくとも 1 つのキャンセル ペア自体が、制約の下で必要な総質量に達するのに十分なスケーラビリティを備えている必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    n, Q = map(int, input().split())
    T = list(map(int, input().split()))

    pos = []
    neg = []
    zero = []

    for i, t in enumerate(T):
        a = t - Q
        if a > 0:
            pos.append((a, i))
        elif a < 0:
            neg.append((a, i))
        else:
            zero.append(i)

    # if exact match exists
    if zero:
        res = [0] * n
        res[zero[0]] = 100
        print(*res)
        return

    if not pos or not neg:
        print(-1)
        return

    # pick minimal absolute representatives
    pos.sort()
    neg.sort(key=lambda x: x[0], reverse=True)  # closest to zero negative

    candidates = []
    candidates.append((pos[0][0], neg[0][0]))

    # try a few more extreme combinations (safety)
    for i in range(min(3, len(pos))):
        for j in range(min(3, len(neg))):
            candidates.append((pos[i][0], neg[j][0]))

    best = None

    for p, nval in candidates:
        a = p
        b = -nval
        g = gcd(a, b)
        x0 = b // g
        y0 = a // g

        kmax = min(10000 // x0, 10000 // y0)
        if kmax <= 0:
            continue

        total = kmax * (x0 + y0)
        if total >= 100:
            best = (x0, y0, kmax, p, nval)
            break

    if best is None:
        print(-1)
        return

    x0, y0, kmax, p, nval = best

    res = [0] * n
    # find indices
    for i, t in enumerate(T):
        if t - Q == p and x0 > 0:
            res[i] = kmax * x0
            x0 = 0
        elif t - Q == nval and y0 > 0:
            res[i] = kmax * y0
            y0 = 0

    print(*res)

if __name__ == "__main__":
    solve()
```解決策は、濃度条件を線形方程式に変換することから始まります。 次に、インデックスを Q からの正、負、およびゼロ偏差に分割します。ゼロの場合は、100 グラムで要件を直接満たすため、すぐに処理されます。 

ゼロ以外の場合、アルゴリズムは候補バランシング ペアを構築します。 各ペアについて、gcd を使用して縮小整数比を計算し、成分ごとに 10⁴ 制限に達する前にどこまでスケールできるかをチェックします。 少なくとも合計 100 グラムを生産できるペアのみが受け入れられます。 

最後の割り当てでは、計算された金額が選択されたインデックスに分配されます。

 ## 特殊なケース

 解に Q に正確に等しい Ti が含まれている場合、アルゴリズムはその成分のみを使用して有効な構成を即座に返します。 これにより、不必要なバランシング ロジックが回避され、実現可能性が保証されます。 

すべての偏差が同じ符号を持つ場合、すべての組み合わせは Q の片側に留まるため、線形方程式はゼロに到達できません。 アルゴリズムは正しく -1 を返します。 

バランシング ペアが存在するが、gcd 換算係数が大きい場合、スケーリングは 104 キャップによってブロックされます。 アルゴリズムは、kmax を通じてこれを明示的にチェックし、方程式が無制限に解ける場合でも、無効な代入が構築されないことを保証します。
