 ## 解決策
 ## 問題の理解

 複数の数値セットがあり、配列に単一のピークが含まれるようにそれらの数値を並べ替えることで、異なる配列がいくつ形成できるかを数えたいと考えています。 ピークは配列内の最大値です。 この最大値より前のすべては厳密に増加しており、それ以降はすべて厳密に減少している必要があります。 

たとえば、マルチセットが`{1, 2, 3, 1}`、最大値は`3`したがって、可能な唯一の形状は、で終わる増加するシーケンスです。`3`、その後に減少シーケンスが続きます。 配列`(1,2,3,1)`左側は厳密に増加し、右側は厳密に減少するため、機能します。 

入力により、配列のサイズと再配置する必要がある値が得られます。 出力は、ピーク条件を満たす個別の配列の数です。 

重要な制約は、要素の数が十分に大きくなり、すべての順列を試すことが不可能になる可能性があることです。 と`n`要素をブルートフォースで調べると、`n!`非常に小さな値であっても使用できなくなるアレンジメント`n`。 ソリューションでは、値の頻度を検査し、有効な構造を直接カウントする必要があります。 

難しいのは、重複した値を処理することです。 最大値より小さい値は左側、右側、または両方に表示できますが、各側は厳密に単調である必要があるため、どの側にも同じ値を 2 回含めることはできません。 最大値は唯一のピークである必要があるため、それ自体が特別です。 

マルチセットを考えてみましょう。```
3
1 2 2
```正しい出力は次のとおりです。```
0
```不用意にアプローチすると、危険な状態に陥る可能性があります。`2`ピークとその他として`2`片側に。 ただし、どちらか`(1,2,2)`または`(2,2,1)`隣接する等しい最大値が含まれるため、固有のピークはありません。 

もう 1 つのエッジ ケースは、最大値の 3 倍低い値が表示されることです。```
5
1 2 2 2 3
```正しい出力は次のとおりです。```
0
```値`2`ピークの両側に分散する必要があります。 それぞれの面に1枚ずつしか入れられないので3枚は置けません。 

最後の境界ケースは、最大以外の値がすべて一意である場合です。```
4
1 2 3 4
```正しい出力は次のとおりです。```
8
```それぞれの`1`、`2`、 そして`3`増加側または減少側に独立して割り当てることができます。 割り当てごとに、異なる有効な配列が生成されます。 

## アプローチ

 直接的なアプローチは、入力マルチセットのすべての順列を生成し、それが素晴らしいかどうかを確認することです。 候補の順列については、最大の位置を見つけて、その前で値が増加し、その後で値が減少することを確認できます。 考えられるすべての配置がテストされるため、これによりすべての回答が正しくカウントされます。 

問題は順列の数です。 と`n`明確な価値観が存在する`n!`可能な取り決め。 平`10!`すでに何百万もの可能性がありますが、階乗増加によりこれはすぐに不可能になります。 

優れた配列の構造は、問題についてはるかに小さな方法で考えることができます。 中央で最大値が固定されたら、残りの値は 2 つの辺のうちの 1 つに割り当てるだけで済みます。 左側は自動的に昇順にソートされ、右側は自動的に降順にソートされます。 

最大値より小さい値の場合、厳密な順序付けルールにより、各辺にこの値を最大 1 回だけ含めることができます。 値が 1 回出現した場合は、どちらの側を選択しても構いません。 2 回出現する場合は、各側に 1 部ずつコピーする必要があります。 2 回以上出現する場合、有効な配置はありません。 

最大値は複数回出現することはできません。 2 番目のコピーを両側のいずれかに配置する必要がありますが、別の最大値が作成され、単一ピーク構造に違反します。 

これにより、順列生成から頻度カウントまでの問題が軽減されます。 それぞれの値が 2 つの独立した選択肢に寄与するため、最大値を下回る値が 1 回だけ出現する数を数えるだけで済みます。

 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列内のすべての値の頻度を数えます。 

各側の最終的な順序付けは強制されるため、周波数情報で十分です。 それぞれの値が何通りに分散できるかを知る必要があるだけです。 
2. 最大値を見つけて、その周波数を確認します。 

最大値が複数回出現する場合、素晴らしい配列には単一のピークが必要であるため、答えはゼロになります。 
3. 最大値より小さい値をすべて調べます。 

値が 2 回以上出現する場合、2 つの単調な辺は同じ値の 3 つのコピーを保持できないため、答えはゼロになります。 

値がちょうど 2 回出現する場合、各側に 1 回ずつ出現する必要があります。 これでは選択の余地がありません。 

値が 1 回だけ出現する場合は、最大値の前または後に配置できます。 この値を得るには、答えに 2 を掛けます。 
4. 累積選択肢数を出力します。 

すべての柔軟な値が 1 つの独立した二分決定に寄与するため、選択肢の数は常に 2 の累乗になります。 

なぜ効果があるのか:

 最大要素は、すべての有効な配列の中心を固定します。 どちらの小さい値が左側と右側に属するかを選択した後、左側は増加し、右側は減少する必要があるため、順序付けが強制されます。 頻度ルールは、それらの辺にいつ値を配置できるかを正確に記述します。 すべての有効な素晴らしい配列は、側面への値の 1 つの一意の割り当てに対応し、すべての有効な割り当てによって 1 つの素晴らしい配列が作成されるため、カウントは正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1

        mx = max(a)

        if freq[mx] > 1:
            ans.append("0")
            continue

        ways = 1
        possible = True

        for x, c in freq.items():
            if x == mx:
                continue
            if c > 2:
                possible = False
                break
            if c == 1:
                ways *= 2

        ans.append(str(ways if possible else 0))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```辞書`freq`各値のコピーが何個存在するかを格納します。 これにより、マルチセットのみが重要となるため、元の配列の順序に依存することがなくなります。 

最初に最大値がチェックされます。 これにより、より小さい値を処理する前に特別なピーク要件が処理されます。 

値が小さい場合、頻度が 2 の場合は、その値が最大値の両側に 1 回出現する必要があることを意味し、頻度が 1 の場合は 2 つの配置が可能になります。 乗算は、これらの単一の出現に対してのみ発生します。 

Python の整数はオーバーフローしないため、2 倍を繰り返しても安全です。 周波数マップの反復により、入力値の数において解も線形に保たれます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各数値は周波数マップに 1 回挿入され、それぞれの個別の値が 1 回検査されます。 |
 | スペース | O(n) | 周波数マップには、あらゆる個別の入力値を含めることができます。 |

 ## 特殊なケース

 入力の場合:```
3
1 2 2
```最大値の周波数`2`は2つです。 アルゴリズムはすぐにゼロを返します。 これは、素晴らしい配列には最大値が複数発生するのではなく、1 つのピークがあるという要件と一致します。 

入力の場合:```
5
1 2 2 2 3
```最大値は一意ですが、値は`2`3回登場します。 アルゴリズムは、両側を厳密に順序付けしながらすべてのコピーを分離するには 2 つの側面だけでは不十分であることを検出し、ゼロを返します。 

入力の場合:```
4
1 2 3 4
```最大値は一意であり、より小さい値はすべて 1 回表示されます。 アルゴリズムはカウントを 3 倍にして、`2 * 2 * 2 = 8`。 各結果は、より小さい値ごとにピークの側を選択することに対応し、順序は自動的に決定されます。
