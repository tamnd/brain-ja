 ## 解決策
 ## 問題の理解

 _n_×_n_ バイナリ行列が与えられます。これは、すべての要素が 0 または 1 であることを意味します。行列の「異常な平方」は、行 _i_ と列 _i_ の内積の全行にわたる合計であり、モジュロ 2 で計算されます。つまり、行列の対角位置ごとに、その行と対応する列の内積を計算し、これらの結果をすべて合計し、モジュロ 2 を減算します。 

これに加えて、3 種類のクエリを処理する必要があります。 1 つ目は行のすべてのビットを反転し、2 つ目は列のすべてのビットを反転し、3 つ目は現在の異常な正方形を要求します。 入力行列のサイズは最大 1000×1000、クエリ数は最大 10^6 です。 反転するたびに異常な正方形を再計算する単純なアプローチでは、タイプ 3 クエリごとに O(n^2) の作業が必要になります。 10^6 クエリの場合、これは明らかに実行不可能です。10^12 のオーダーの操作が必要となり、これは妥当な時間制限をはるかに超えています。 

また、オフバイワンエラーとモジュロ演算にも注意する必要があります。特に反転は位置に依存して微妙な方法で異常な正方形に影響を与えるためです。 たとえば、行列がすべて 0 で行を反転すると、どの列ビットが一致するかによって、異常な正方形が変化する場合と変化しない場合があります。 同様に、同じ行を 2 回反転すると、異常な正方形が前の値に戻るはずです。 これらのケースを素朴に扱うと、間違った答えにつながる可能性があります。 

## アプローチ

 ブルート フォース ソリューションは簡単です。行列を保存し、タイプ 3 クエリごとに各行を反復処理し、対応する列との内積を計算し、結果を合計し、モジュロ 2 を出力します。これは定義を直接実装しているため正しいですが、クエリごとに O(n^2) の操作が必要です。 n が最大 1000、クエリが最大 10^6 の場合、約 10^12 の操作が必要になる可能性がありますが、これは 1 秒の制限時間には遅すぎます。 

最適化するための重要な洞察は、行列がバイナリであり、すべての演算がモジュロ 2 であることに注意することです。行または列を反転しても、交差する各行と列のペアの合計のパリティのみが変更されます。 具体的には、行 _i_ を反転すると行 _i_ に関係するすべての内積に影響し、列 _j_ を反転すると列 _j_ に関係するすべての内積に影響します。 したがって、異常な正方形は、各対角要素の寄与のパリティのみを維持することにより、行または列のフリップごとに O(1) 更新で追跡できます。 

クエリごとにドット積全体を再計算する代わりに、行と列のフリップのパリティを表す単一の配列を追跡できます。 各タイプ 3 クエリでは、n 値のパリティ合計、つまり O(n) を計算するだけで済みます。 n ≤ 1000 であるため、これは 10^6 クエリに対して十分な速度であり、合計操作数はおよそ 10^9 となり、許容範囲内となります。

 | 最適 | O(n + q・n) | O(n^2 + n + n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 行列を読み取り、2D 配列に保存します。 これは、行と列の反転のための行列の初期状態を知るために必要です。 
2. 長さ n の 2 つの配列を初期化します。`row_flip`そして`col_flip`。 各配列は、その行または列が奇数回 (1) 反転されたか偶数回 (0) 反転されたかを格納します。 
3. 各行 _i_ を反復処理して、最初の異常な正方形を計算します。 各行について、行 _i_ と列 _i_ の 2 を法とするドット積を計算し、これらの値を合計します。 これを次のように保存します`current_square`。 
4. クエリごとに、次のように処理します。 

- クエリが行 _i_ を反転する場合、切り替えます`row_flip[i]`。 次に、影響を受ける各対角要素 (要素 (i,i) のみ) について、現在の値を使用して異常な正方形への寄与を再計算します。`row_flip`そして`col_flip`配列。 必要に応じてモジュロ 2 を加算または減算します。 
- クエリが列 _j_ を反転する場合、切り替えます`col_flip[j]`そして同様に対角要素 (j,j) の寄与を更新します。 
- クエリが異常な正方形を要求する場合、次を使用して各対角要素のパリティを計算します。`matrix[i][i] ^ row_flip[i] ^ col_flip[i]`この値を出力文字列に追加します。 
5. 蓄積された回答の文字列を出力します。 

### なぜ効果があるのか

 このアルゴリズムが機能するのは、各行または列の反転がその行または列に関係するドット積のパリティにのみ影響するためです。 フリップパリティ配列を維持し、2 を法とする対角要素の寄与を計算することで、行列全体を再計算することなく、異常な正方形を正しく追跡できます。 タイプ 3 の各クエリは寄与を合計し、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
matrix = [list(map(int, input().split())) for _ in range(n)]
q = int(input())

row_flip = [0] * n
col_flip = [0] * n

# Compute initial unusual square
def compute_usquare():
    total = 0
    for i in range(n):
        val = matrix[i][i] ^ row_flip[i] ^ col_flip[i]
        total ^= val
    return total

res = []

for _ in range(q):
    query = input().split()
    if query[0] == '1':
        i = int(query[1]) - 1
        row_flip[i] ^= 1
    elif query[0] == '2':
        j = int(query[1]) - 1
        col_flip[j] ^= 1
    else:
        res.append(str(compute_usquare()))

print(''.join(res))
```の`row_flip`そして`col_flip`配列は、各行または列が奇数回反転されたかどうかを追跡します。 の`compute_usquare`関数は、元の対角値と現在の反転状態との XOR を計算します。これにより、異常な正方形のパリティが直接得られます。 XOR を使用すると、加算モジュロ 2 を手動で処理する必要がなくなります。
