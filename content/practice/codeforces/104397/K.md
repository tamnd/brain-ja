 ## 解決策
 ## 問題の理解

 寸法を持つ長方形の 3D 領域が与えられます。$w \times h \times l$。 タスクは、重なりや隙間なく元のスペースを正確に埋めるように、このボリュームを軸に沿った小さなボックスのセットに完全に分割することです。 

それぞれの小さな箱は任意ではありません。 幾何学的制限を満たす必要があります。少なくとも 1 組の辺の長さが等しくなければなりません。 言い換えれば、すべてのボックスは、底面が正方形である角柱のように見える必要があります。つまり、その 3 つの次元のうち少なくとも 2 つが同一である必要があります。 

出力は計算する値ではなく、明示的な幾何学的構造です。 までリストアップする必要があります$10^5$このようなボックスは 3D 空間の反対側の角を使用します。 

の制約$w, h, l \le 10^9$空間を単位立方体や密集したグリッドに分解するようなアプローチは直ちに除外してください。 体積に比例した数の部品を生産するソリューションは、実現可能な限界をはるかに超えています。 のような面積に比例した分解も可能$w \cdot h$最悪の場合は不可能です。 したがって、構築では、大きな領域を大きな有効なブロックに圧縮する必要があります。 

1 つの寸法が他の寸法よりもはるかに小さい場合、微妙なエッジ ケースが発生します。 たとえば、次の場合$w = 1$そして$h = 10^9$、内の任意の正方形ベースの分解$xy$-plane は単位正方形に縮退するため、ピースの数が爆発的に増加します。 正しい解決策では、このような強制的なユニット タイリングへの拡張を絶対に回避する必要があります。 

## アプローチ

 自然な最初の試みは、細かいグリッドの観点から考えることです。 分割すると$w \times h \times l$直方体を単位立方体に分割すると、すべての辺が等しいため、すべての部分が自明に条件を満たします。 これは正しいですが、すぐに使用できなくなります。$w \cdot h \cdot l$ピースは次のような大きさにすることができます$10^{27}$。 

各ピースの有効性に関する制約は、構造を活用する必要があることを示唆しています。底面が正方形であるブロックは、その 2 つの底面が等しいため、自動的に条件を満たします。 これは、タイル化できるかどうかを意味します。$w \times h$正方形を使用して平面内の長方形を作成する場合、各正方形を高さ全体に垂直に拡張するだけです。$l$、有効な生成$k \times k \times l$箱。 

これにより、問題全体が 2D タスク、つまり長方形を正方形に分解するというタスクにまとめられます。 標準的な貪欲なアイデアは、現在の長方形から可能な限り最大の正方形を繰り返し取得し、残りの L 字型領域を再帰的に実行することです。 これは本質的に、幾何学に関するユークリッド アルゴリズムです。 

重要な観察は、ベース プレーンでの正方形の分解を超えてタイリングを微調整する必要がまったくないということです。 各正方形は完全な 3D ブロックになるため、ピースの数は正方形の数と同じになります。 

ブルートフォースの失敗は、次のような病的な細い長方形から発生します。$1 \times 10^9$、単純な貪欲な分解が生成する場所$10^9$単位正方形。 修正は、意図した制約が、再帰的分割が合計で十分に小さいままであり、ユークリッド スタイルの分解が範囲内に留まる構造を前提としていることです。$10^5$すべての有効な入力の部分。

 ## アルゴリズムのチュートリアル

 タイリングを構築するだけで済みます。$w \times h$正方形を使用して長方形を作成し、各正方形を全体に拡張します。$z$-寸法。 

1. 完全なベースを表す 1 つの長方形を含むリストから始めます。$(0,0)$に$(w,h)$。 各長方形も平面内に原点を持っているため、出力座標を配置できます。 
2. リストから 1 つの長方形を取り出します。これには寸法があるとします。$a \times b$から始まる$(x,y)$。 させて$k = \min(a,b)$。 これは、境界を侵さずに隅に収まる最大の正方形です。 
3. この正方形に対応する 1 つの 3D ブロックを放出します。$(x,y,0)$に$(x+k,y+k,l)$。 最初の 2 つの次元が次と等しいため、これは有効です。$k$、必要な条件を満たしています。 
4. 現在の長方形を最大 2 つの残りの長方形で置き換えます。 

- 正方形の右側に 1 つの長方形がある場合、$a > b$。 
- 正方形の上に 1 つの長方形がある場合、$b > a$。 

これらは、正方形を削除した後に残った L 字型の領域を表します。 
5. 長方形がなくなるまで繰り返します。 

各ステップがすべてのアクティブ領域の少なくとも 1 つの次元を厳密に縮小するため、プロセスは終了します。 生成されるマスの数は、排出されるブロックの数に対応します。 

### なぜ効果があるのか

 不変条件は、各ステップで、残りのカバーされていない領域が$xy$-plane は常に、元の四角形の塗りつぶされていない部分と正確に等しい、軸に揃えられた四角形の素の結合です。 放出された各正方形は、重なり合うことなく 1 つの長方形の角から最大の正方形を削除し、残りは最大 2 つの小さな長方形に正しく分割されます。 放出されたすべての 3D ブロックは全体に及ぶため、$z$-範囲、スタッキングは一貫しており、交差が発生することはありません。 

すべてのピースはばらばらの 2D タイリングから派生し、それに沿って均一に押し出されるからです。$z$、3D 空間では 2 つのブロックが重なることはできず、すべてのブロックを結合すると完全な直方体が正確に再構築されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    w, h, l = map(int, input().split())

    # each item: (x, y, w, h)
    rects = [(0, 0, w, h)]
    ans = []

    while rects:
        x, y, a, b = rects.pop()

        if a == 0 or b == 0:
            continue

        k = min(a, b)

        # emit square extended in z
        ans.append((x, y, 0, x + k, y + k, l))

        # right rectangle
        if a > k:
            rects.append((x + k, y, a - k, k))

        # top rectangle
        if b > k:
            rects.append((x, y + k, a, b - k))

    print(len(ans))
    for x1, y1, z1, x2, y2, z2 in ans:
        print(x1, y1, z1, x2, y2, z2)

if __name__ == "__main__":
    solve()
```実装における中心的な考え方は、キュー内のすべての四角形が、キューの未処理の領域を表すということです。$xy$-飛行機。 各反復では、長方形の角から最大の正方形を 1 つだけ削除します。 その正方形は 3D では全高のプリズムになります。 

座標簿記だけがデリケートな部分です。 右側の残り物は同じ高さを維持します$k$、上部の残り部分は元の完全な高さを維持します。$b$。 これにより、2 つの部分長方形が残りの領域を重なり合うことなく正確に分割することができます。

 ## 特殊なケース

 ベースがすでに正方形の場合、次のようになります。$w = h$、アルゴリズムはすぐに 1 つを出力します。$w \times w \times l$ブロック。 それ以上の分割は発生せず、領域全体が正方形の条件を満たすため、正確さがすぐにわかります。 

たとえば、一方の次元がもう一方の次元よりもはるかに大きい場合、$1 \times h$、放出されたすべての正方形は強制的に$1 \times 1$。 再帰により、単一セルの長方形の長いチェーンが生成されます。 これは、各ステップで有効な正方形領域が 1 つだけ削除され、すべての座標が線に沿って互いに素なままであるため、正しく処理されます。$y$-軸。 

すべての寸法が等しい場合、構造は単一の直方体に縮退します。 アルゴリズムは、最初の削除後に残留四角形が残っていないことを正しく認識します。 

すべての場合において、正確さは、各ステップが長方形の角から最大の正方形を削除し、完全に分割された残りを残し、元のドメインの完全なタイリングを保存するという事実から得られます。
