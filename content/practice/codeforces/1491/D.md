 ## 問題の理解

 無限有向グラフの到達可能性を判断するように求められます。 各頂点は正の整数であり、頂点からの有向エッジが存在します。$u$頂点へ$u+v$次のビット単位の AND が成立する場合に限り、$u$そして$v$等しい$v$。 言い換えれば、すべてのエッジで数値を加算できるということです。$v$現在の頂点へ$u$すべてのビットが 1 の場合のみ$v$も 1 ビットです$u$。 2 つの整数で構成されるクエリごとに$u_i$そして$v_i$に到達できるかどうかを答える必要があります。$v_i$から始まる$u_i$このようなエッジのシーケンスを使用します。 

入力は最大で可能です$10^5$クエリ、各頂点の大きさは次のとおりです。$2^{30}-1$。 からのすべての可能なパスをシミュレートしようとする単純なアプローチ$u_i$に$v_i$クエリごとに指数関数的な数の頂点を探索する可能性がありますが、これは実行不可能です。 これは、どのソリューションもパスを列挙するのではなく、数値のビット パターンを直接操作する必要があることを意味します。 

明らかではないエッジ ケースには、次のようなクエリが含まれます。$u_i = v_i$。 この状況では、エッジは必要ありませんが、すでにターゲットに達しているため、正解は「YES」です。 別のエッジケースが発生するのは次の場合です。$v_i < u_i$。 すべてのエッジは頂点値を厳密に増加させるため、答えは「いいえ」でなければなりません。 最後に、次のようなケース$u_i$そして$v_i$一部のビットを共有し、他のビットが異なる場合は、AND 条件によって特定のビットに到達できない可能性があるため、慎重に処理する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、次から始まるグラフをシミュレートしようとします。$u_i$、有効な頂点を繰り返し追加することで、到達可能なすべての頂点を生成します。$v$それは満足する$u \& v = v$。 これは少数の場合には機能しますが、次の場合は絶望的です。$u_i$と同じくらい大きい$2^{30}$または、各シミュレーションに時間がかかる可能性があるため、多くのクエリの場合は、$10^9$最悪の場合の運用。 

重要な点は、各ステップで、現在の頂点に 1 ビットがすでに存在する数値のみを追加できるということです。 つまり、到達するには$v_i$から$u_i$、1 ビットごとに$v_i$最終的には何らかの 1 ビットでサポートされる必要があります$u_i$。 より正確には、最下位から最上位までビットをスキャンすると、次の 1 ビットの数になります。$u_i$任意の位置までは、少なくとも 1 ビットの数でなければなりません。$v_i$同じ位置まで。 少しでも累積カウントが$v_i$それを超える$u_i$、到達することは不可能です$v_i$。 これにより、問題はクエリごとに 30 ビットにわたる線形スキャンに変換されます。

 ## アルゴリズムのチュートリアル

 1. クエリ数を読み取る$q$。 
2. 各クエリについて、次の内容を読み取ります。$u$そして$v$。 もし$u > v$、すべてのエッジが頂点を増加させるため、すぐに「NO」を出力します。 
3. 2 つのカウンターを初期化します。$count_u$そして$count_v$、で見られる累積 1 ビットを追跡します。$u$そして$v$最下位ビット (ビット 0) から 29 番目のビットまでスキャンします。 
4. 0 ～ 29 の各ビット位置について、ビットが設定されているかどうかを確認します。$u$そして$v$。 設定されている場合は増加します$count_u$または$count_v$それぞれ。 
5. 各ビットのカウントを更新した後、次のことを確認します。$count_v > count_u$。 true の場合、1 ビットがあるため、すぐに「NO」を出力します。$v$によってサポートできないこと$u$これまでのところ。 
6. スキャンが失敗せずに完了した場合は、すべてのビットが 1 であるため、「YES」を出力します。$v$からの 1 ビットを使用して増分的に構築できます。$u$。 

これが機能する理由: スキャン中に維持される不変条件は、各ビット位置での 1 ビットの累積数です。$u$少なくとも次の数値です$v$。 これにより、すべての 1 ビットが$v$1 ビットがすでに存在する数値を加算することによって形成できます。$u$、AND 条件を尊重します。 不変条件が少しでも失敗すると、到達することは不可能になります。$v$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

q = int(input())
for _ in range(q):
    u, v = map(int, input().split())
    if u > v:
        print("NO")
        continue
    count_u = 0
    count_v = 0
    possible = True
    for i in range(30):
        if (u >> i) & 1:
            count_u += 1
        if (v >> i) & 1:
            count_v += 1
        if count_v > count_u:
            possible = False
            break
    print("YES" if possible else "NO")
```このソリューションは各クエリを読み取り、ビット数を直接処理します。 累積カウントを使用すると、グラフのバックトラッキングやシミュレーションが回避され、アルゴリズムがビット数とクエリ数において線形に保たれます。 最下位から最上位へのビット スキャンにより、小さいビットが最初に満たされることが保証されます。これは、AND 加算エッジが伝播を可能にする方法と一致します。
