 ## 解決策
 ## 問題の理解

 1 から n までの整数のセットを扱っており、非常に厳密な構造を持つサイズ k のサブセットがいくつあるかを数えたいと考えています。選択した数値のすべてのペアは素数距離で区切られている必要があります。 

言い換えれば、サブセットから要素 a と b を選択すると、絶対差 |a − b| は次のようになります。 は常に素数でなければなりません。 この条件は、並べ替えられた順序で隣接するものの間だけでなく、サブセット全体にグローバルに適用されます。 したがって、隣接しない要素であっても同じ素数距離規則を満たさなければならないため、サブセットは非常に制約されます。 

各テスト ケースに対して、n と k が与えられ、{1, 2, …, n} 内に正確に k のサイズの有効なサブセットがいくつ存在するかを数えなければなりません。 答えは 104206969 を法として求められます。 

制約はスケール的に非常に厳しく、n は 10^7 まで大きくなり、テスト ケースの数は 2 × 10^5 に達することがあります。 これにより、各クエリを個別に処理したり、テストごとの構造を構築したりするソリューションは即座に除外されます。 クエリごとに O(n) さえもかかるアプローチは不可能です。 唯一実行可能な方向は、最大 n までの 1 回の事前計算と、それに続く O(1) クエリ応答です。 

微妙な難しさは、この条件には連続したものだけでなく、すべてのペアごとの違いが含まれることです。 このため、有効なセットの構造は一見しただけでは非常にわかりにくくなり、どのような構成が可能であるかを理解しなければ、サブセットに対する単純な組み合わせ推論はすぐに手に負えなくなります。 

## アプローチ

 直接的な総当たりアプローチでは、{1..n} のすべての k 要素サブセットを列挙し、すべてのペアごとの差が素数であるかどうかを確認しようとします。 サブセットを修正したとしても、それを検証するには O(k^2) 回のチェックが必要です。$\binom{n}{k}$サブセット。 探索空間は指数関数的に増大するため、これはたとえ小さな n であってもすぐに爆発します。 

重要な単純化は、条件が差分のみに依存し、すべてが同時に素数でなければならない場合、差分は非常に厳密に動作することに気づくことから来ています。 有効なサブセット a1 < a2 < … < ak を並べ替えると、すべての制約を連続したギャップで表現できます。 di = a(i+1) − ai とします。 各 di は素数である必要があり、さらに重要なことに、隣接しない差分に対応するため、連続する di の合計も素数である必要があります。 

これにより、強力な算術制限が生じます。 2 つの素数の合計が素数になることはほとんどありません。 唯一の例外は 2 + 3 = 5 です。この 1 つの観察により、構造の複雑さが崩れます。連続したギャップを追加するときは常に、2 と 3 の非常に短い交互パターンのみを許可する方法でそれらをペアにする必要があります。 

このことから、有効な構成を任意に大きくすることはできないことがわかります。 実際、より長い交互構造では必然的に素数ではない連続ギャップの合計が生成されるため、自明ではない方法で存在できるのはサイズ 4 までのサブセットのみです。 これにより、問題全体が整数直線内の少数の固定幾何学パターンを数えるということになります。 

次に、考えられる各構造を明示的に数えます。 サイズ 1 と 2 のサブセットは、素数と素数の差のグローバルな数のみに依存します。 サイズ 3 と 4 は、オフセットが小さい固定等差数列に対応します。

 ## アルゴリズムのチュートリアル

 構造はサイズによって完全に異なるため、答えをサブセット サイズ k ごとに分けます。 

まず、ふるいを使用して、すべてのテスト ケースにわたって最大 n までのすべての素数を事前計算します。 それに加えて、素数の接頭辞の合計と素数の接頭辞の数を計算するので、任意の範囲のすべての素数の合計を迅速に評価できます。 

次に、有効なサブセットをサイズ別に分析します。 

1. k = 1 の場合、条件に違反するペアがないため、すべての単一要素が有効になります。 したがって、答えは単純に n です。 
2. k = 2 の場合、b − a が素数となるようなペア (a, b) が必要です。 固定素数 p の場合、a + p ≤ n であるすべての開始位置 a が有効なペアを形成します。 したがって、各素数 p は正確に (n − p) 個のペアに寄与します。 これをすべての素数 p ≤ n − 1 について合計します。 
3. k = 3 の場合、サブセットを a < b < c としてソートします。 ギャップを x = b − a および y = c − b とします。 両方とも素数でなければならず、x + y も素数でなければなりません。 2 つの素数の和が 1 つの素数になる唯一の方法は、それらが何らかの順序で 2 と 3 である場合です。 これにより c − a = 5 が強制され、中間点は a + 2 または a + 3 のいずれかになります。したがって、すべての開始位置 a ≤ n − 5 に対して、正確に 2 つの有効なトリプルが得られます。 
4. k = 4 の場合、3 つのギャップ x、y、z が導入されます。 同じ推論により、隣接するギャップのすべてのペアが (2, 3) または (3, 2) になります。 すべての制約にわたる一貫性により、有効なパターンは 2、3、2 の 1 つだけになります。これは、セット {a、a + 2、a + 5、a + 7} に対応します。 したがって、すべての a ≤ n − 7 は 1 つの有効な 4 倍数に寄与します。 
5. k ≥ 5 の場合、有効な構成は存在しません。 交互構造を拡張しようとすると、最終的にはより長いセグメントの端点間の合計距離が素数にならなくなり、すべてのペアごとの差が素数のままでなければならないという要件が破られます。 

### なぜ効果があるのか

 核となる不変条件は、有効なサブセットがソートされると、すべての内部構造が素数ギャップのシーケンスとして強制的にエンコードされ、そのすべての連続和も素数でなければならないということです。 2 つの素数の合計が素数になることはほとんどないため、構造は境界のある交互のパターンのセットに崩壊します。 この制限により、大規模な構成がすべて排除され、直接カウントできる一定サイズのテンプレートのみが残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 104206969

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    primes = []
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
            step = i
            if i * i <= n:
                for j in range(i * i, n + 1, i):
                    is_prime[j] = False
    return is_prime, primes

def solve():
    T = int(input())
    queries = []
    max_n = 0

    for _ in range(T):
        n, k = map(int, input().split())
        queries.append((n, k))
        max_n = max(max_n, n)

    is_prime, primes = sieve(max_n)

    # prefix sums over primes and prefix counts by value
    prime_prefix_sum = [0] * (max_n + 1)
    prime_prefix_cnt = [0] * (max_n + 1)

    ps = 0
    pc = 0
    for i in range(1, max_n + 1):
        if is_prime[i]:
            pc += 1
            ps += i
        prime_prefix_cnt[i] = pc
        prime_prefix_sum[i] = ps

    out = []

    for n, k in queries:
        if k == 1:
            out.append(str(n))
        elif k == 2:
            cnt = prime_prefix_cnt[n - 1]
            s = prime_prefix_sum[n - 1]
            ans = (cnt * n - s) % MOD
            out.append(str(ans))
        elif k == 3:
            if n < 5:
                out.append("0")
            else:
                out.append(str(2 * (n - 5) % MOD))
        elif k == 4:
            if n < 7:
                out.append("0")
            else:
                out.append(str(n - 7))
        else:
            out.append("0")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```ふるいは、グローバルで負荷の高い唯一の前処理ステップであり、k = 2 が n までのすべての素数の寄与の合計に依存するためのみ必要です。 素数とそのプレフィックスの合計が判明すると、各クエリは定数時間の演算に減ります。 

k = 2 の場合、式 n * (#primes) − (素数の合計) は、素数ギャップごとにすべての有効な順序付き開始を直接カウントします。 k = 3 および k = 4 の場合、式は有効な算術パターンを列挙し、それらを整数ライン上でシフトすることで直接得られます。 

サイズ 4 を超えるペアごとの素数差制約に耐えられる構成はないため、k ≥ 5 の分岐は安全にゼロになります。 

## 実用的な例

 n = 10、k = 2 について考えます。9 までの素数、2、3、5、7 を調べます。それぞれが n − p 個の開始位置に寄与します。 

| 素数 p | n − p |
 | --- | --- |
 | 2 | 8 |
 | 3 | 7 |

 合計すると、23 個の有効なペアが得られます。 これは、各素数ジャンプが完全な差分グラフの有効なエッジを定義するという考えと一致します。 

ここで、n = 10、k = 3 について考えてみましょう。有効なトリプルの形式は (a, a+2, a+5) および (a, a+3, a+5) です。 最大の開始点は a = 5 です。

 ## 特殊なケース

 k = 1 の場合、サブセット制約は完全に消えます。 このアルゴリズムは、sieve 構造に依存せずに n を正確に返します。 

n < 5 の小さい n の場合、最小のパターンでもスパン 5 が必要なため、k = 3 は有効な設定になりません。(n − 5) が負になり、条件によってクランプされるため、式は当然ゼロを返します。 

k = 4 の場合、最小有効構造は長さ 7 に及びます。n < 7 の場合、パターン {a, a+2, a+5, a+7} の開始位置が存在しないため、出力は正確に 0 になります。 

k ≥ 5 の場合、アルゴリズムは常に 0 を返します。 これは、累積和に必然的に合成値が含まれる素数ギャップを交互に強制することで生じる構造上の不可能性と一致し、グローバルなペアごとの制約を破ります。
