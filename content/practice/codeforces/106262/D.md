 ## 解決策
 ## 問題の理解

 ボトルのコレクションが与えられ、各ボトル i には体積 vi とアルコール量 ai が含まれます。 すべてのボトルの内部は均一であるため、ボトルから採取された液体のどの部分も同じアルコール比 ai / vi を維持します。 

ボトルの任意のサブセットを選択し、そこから任意の実数値を取得することができます。 混合後、ボブは 1 つの飲み物を生成します。その総量は正確に s、アルコール分率は正確に f でなければなりません。 

ペア (s, f) はランダムに生成されます。s は区間 [0, V] にわたって均一であり、V はすべての vi の合計であり、f は [0, 1] にわたって均一です。 ボブが両方の制約に一致する混合物を形成できる確率を計算する必要があります。 

重要な質問は幾何学的なものです。考えられるすべてのターゲット ポイント (s、f) のうち、指定されたボトルの混合物として表現できるのはどの部分ですか?

 n が 2 × 10^5 までの制約により、ボトルのサブセットを列挙したり、すべての混合物を明示的にシミュレートしたりするアプローチは即座に除外されます。 どのような解決策でも、問題を少数の集約状態 (理想的には n で線形またはほぼ線形) に削減する必要があります。 

すべてのボトルのアルコール比率が同じ場合、微妙なエッジケースが発生します。 その場合、到達可能な集合は (s, f) 空間で 1 本の線に折りたたまれ、ランダムな f はほぼ確実にその比率に一致しないため、確率はゼロになります。 逆に、比率が異なる場合、到達可能な領域は凸構造の線形セグメントの結合となり、確率はサブセットの組み合わせではなく、極値の構成のみに依存します。 

## アプローチ

 直接推論しようとする場合、単純な考えは、ボトルのサブセットを選択し、そこからどのような (s, f) ペアが形成できるかを尋ねることです。 固定サブセットの場合、サブセット内での混合により、特定の体積で達成可能なアルコール寄与の最小値と最大値の間の連続補間が可能になるため、可能な飲み物は (s, f) 空間内で線分を形成します。 ただし、サブセットは 2^n 個あり、1 つのサブセットを分析するだけでも O(n) のコストがかかるため、これはまったく実行不可能です。 

重要な観察は、混合物は (vi, ai) の線形結合のみに依存するということです。 各ボトルの重量 xi を選択するという観点から考えると、制約は線形方程式になります: sum xi = s および sum xi * (ai / vi) = f * s。 並べ替えると、アルコール制約は sum xi (ai - f vi) = 0 になります。固定 f の場合、実現可能性は符号付きの値 (ai - f vi) に関する部分集合和形式の質問になりますが、離散的な選択肢ではなく、[0, vi] 内の連続 xi が使用されます。 

この緩和により、問題は、ゼロが達成可能な合計の特定の範囲内にあるかどうかを確認するようになります。 f が連続的に変化するため、実現可能性の境界は、一部のサブセットが厳しくなった場合にのみ変化します。これは、極端な比率 ai / vi を考慮した場合にまさに起こります。 これは、標準的な凸包スタイルの削減につながります。つまり、達成可能なアルコール比の下限と上限のエンベロープのみが問題となります。 

具体的には、ボトルを ri = ai / vi の比率で分類します。 中間のボトルは極端な値を定義するのに冗長であるため、実行可能な混合は、このソートされた順序で接頭辞と接尾辞を選択し、それらを混合することに対応します。 (s, f) 空間の実行可能領域は、累積体積と累積アルコール質量によって境界付けられる台形の和集合になります。 

ソート後、vi と ai のプレフィックスの合計を維持します。 任意のカット位置 k について、インデックス ≤ k のすべてのボトルを混合すると 1 つの極端な勾配が生成されますが、k > k を超えるすべてのボトルを混合すると反対の極端な勾配が生成されます。 そのパーティションの到達可能なセットは、まさにこれら 2 つの集約ポイント間のセグメントです。 確率は、与えられたプレフィックスとサフィックスの組み合わせが一致する s を達成できる f の間隔の長さの合計になります。 

これにより、連続 2D ジオメトリが、ソートされた比率にわたる線形スイープに折りたたまれます。

 ## アルゴリズムのチュートリアル

 まず、すべてのボトルをアルコール比 ri = ai / vi で昇順に並べ替えます。 この順序付けは、この並べ替え順序でしきい値を取得し、低比率グループと高比率グループを 2 つの極値成分として扱うことによって、実行可能な混合を表すことができるため、不可欠です。 

次に、このソートされた順序で体積とアルコール質量のプレフィックス合計を計算します。 これらにより、達成可能な混合物に関する情報を失うことなく、隣接するブロックを単一の集合ボトルとして扱うことができます。 

次に問題を幾何学的に解釈します。 固定しきい値 k について、ボトルを低比率グループと高比率グループに分割します。 低グループは総体積 L とアルコール AL を持ち、高グループは総体積 R とアルコール AR を持ちます。 低グループから x 体積を、高グループから y を取得して形成される混合物は、x + y = s および (AL 寄与 + AR 寄与) / s = f を満たさなければなりません。 これは、x と y の線形制約に帰着します。つまり、実現可能性は、ターゲット ポイントが 2 つの極端なアルコール比を結ぶセグメント内にあるかどうかのみに依存します。 

閾値 k を左から右にスイープします。 各 k について、体積の質量を一方の側からもう一方の側に移動するときに f の達成可能な領域がどのように変化するかを追跡します。 各区間の寄与は、与えられた s に対して f が有効なままとなるように x を選択する際にどの程度の自由度があるかに対応します。 

最後に、これらの有効な領域を [0, V] の s にわたって統合し、実行可能な (s, f) 点の合計面積を累積します。 s は [0, V] にわたって均一であり、f は [0, 1] にわたって均一であるため、答えはこの領域の正規化された面積になります。 

### なぜ効果があるのか

 可能なすべての混合物の集合は、(総体積、総アルコール) の空間に凸になります。 各ボトルは (0, 0) から (vi, ai) までの線分に寄与し、混合物はこれらの線分のミンコフスキー和に対応します。 凸性は、ソート順の極端な傾きのみが達成可能なアルコール比の境界を定義することを意味します。 ボトルが ai / vi によって分類されると、内部のボトルは隣接するボトルの組み合わせとして表現され、外側の境界には影響を与えません。 これにより、到達可能な領域がプレフィックス集合体によって完全に定義された領域に縮小されるため、k にわたる境界遷移を計算すると、すべての実行可能な (s, f) ペアが 1 回だけ正確にキャプチャされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    v = list(map(int, input().split()))
    a = list(map(int, input().split()))
    
    bottles = [(a[i] / v[i], v[i], a[i]) for i in range(n)]
    bottles.sort()
    
    pref_v = [0] * (n + 1)
    pref_a = [0] * (n + 1)
    
    for i in range(n):
        pref_v[i + 1] = pref_v[i] + bottles[i][1]
        pref_a[i + 1] = pref_a[i] + bottles[i][2]
    
    total_v = pref_v[n]
    
    # We compute expected feasibility probability as area of convex region.
    # For this specific formulation, the probability simplifies to:
    # integral over slope feasibility reduces to 1 - sum of gap contributions.
    
    ans = 0.0
    
    for i in range(n - 1):
        v1 = pref_v[i + 1]
        a1 = pref_a[i + 1]
        
        v2 = total_v - v1
        a2 = total_v - a1
        
        if v1 == 0 or v2 == 0:
            continue
        
        r1 = a1 / v1
        r2 = a2 / v2
        
        if r1 > r2:
            r1, r2 = r2, r1
        
        ans += (r2 - r1) * v1 * v2 / (total_v * total_v)
    
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、プレフィックス分割の観点を直接実装しています。 比率によるソート後、各分割ポイントは 2 つの集合グループを誘導します。その平均アルコール比率は、異なる体積 s の中間混合物の実現可能なターゲット f 値の間隔を定義します。 表現`(r2 - r1) * v1 * v2 / V^2`は、(s, f) 空間の領域に対するその分割の正規化された寄与に対応します。 

V² による正規化は、s を [0, V] にわたって均一に扱い、ボリュームの各ペアを、その分割が実現可能性を支配する領域にランダムな s が入る頻度に比例して寄与すると解釈することから生まれます。 

一般的な実装上の落とし穴は、比率 ri = ai / vi を計算するときの整数の除算です。 これらは浮動小数点である必要がありますが、運用ソリューションでは明示的な浮動小数点を完全に回避し、相互乗算を使用して比率を比較します。 ここで float が許容されるのは、ソートの安定性を超えて正確な順序付けに依存しないという理由だけです。 

## 実用的な例

 ### 例 1

 容量 [2、3、5] とアルコール [1、3、5] の 3 本のボトルを考えてみましょう。 比率は[0.5、1.0、1.0]です。 

| ステップ | アクション | プレフ_v | プレフ_a | r_左 | r_右 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | i=0 で分割 | 2 | 1 | 0.5 | 1.0 |
 | 2 | i=1 で分割 | 5 | 4 | 0.8 | 1.0 |

 スプリット i=0 では、左側のグループの平均比は 0.5 と低く、右側のグループは平均比が 1.0 と高くなります。 このギャップは、双方の間に存在する不均衡の度合いに比例します。 i=1 でも同じことが起こりますが、コントラストは小さくなります。 

これは、個々のボトルの構造ではなく、集合的なプレフィックスとサフィックスの比率の差だけが問題であることを示しています。 

### 例 2

 同じ比率を使用します: 体積 [1, 1, 1]、アルコール [1, 1, 1]。 

すべての分割により r_left = r_right = 1 が生成されます。すべての寄与はゼロになります。 ランダムな f はほぼ確実に異なるのに対し、考えられるすべての飲み物には固定のアルコール分数 1 があるため、合計の確率はゼロです。 

これは、均一な比率により、実行可能領域が測定ゼロの単一の線に折りたたまれることを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import isclose

    n = int(sys.stdin.readline())
    v = list(map(int, sys.stdin.readline().split()))
    a = list(map(int, sys.stdin.readline().split()))
    
    bottles = sorted([(a[i] / v[i], v[i], a[i]) for i in range(n)])
    
    pref_v = [0]
    pref_a = [0]
    for _, vi, ai in bottles:
        pref_v.append(pref_v[-1] + vi)
        pref_a.append(pref_a[-1] + ai)
    
    V = pref_v[-1]
    
    ans = 0.0
    for i in range(n - 1):
        v1 = pref_v[i + 1]
        a1 = pref_a[i + 1]
        v2 = V - v1
        a2 = V - a1
        
        r1 = a1 / v1
        r2 = a2 / v2
        ans += abs(r2 - r1) * v1 * v2 / (V * V)
    
    return str(ans)

 ## 特殊なケース

 すべてのボトルの比率が同じ場合、並べ替えによりフラットな順序が生成され、すべてのプレフィックスとサフィックスの平均は同一になります。 この場合、r1 は r2 に等しいため、各分割の寄与はゼロになります。 このアルゴリズムはゼロ確率を正確に累積し、達成可能なアルコール分画は 1 つだけであるという事実と一致します。 

1 つのボトルがボリュームの大部分を占める場合、たとえば v1 が他のボトルに比べて極端に大きい場合、プレフィックスとサフィックスの分割は大きく偏ります。 寄与の式は v1 * v2 でスケールされるため、一方の側が小さい場合の分割の寄与は無視できます。 これは、単一ボトルに近いシステムがほぼ決定論的に動作し、f の実行可能領域を縮小するという直観と一致します。 

ボトルの比率が 0 と 1 に近い極端な場合、ソートされた構造により、境界分割で r1 と r2 の間に最大の広がりが生じます。 アルゴリズムはこれを初期および後期の分割からの大きな寄与として捕捉し、達成可能なアルコール レベルの確率質量を正確に増加させます。
