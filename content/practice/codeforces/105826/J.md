 ## 解決策
 ## 問題の理解

 カットは軸に沿った閉じたポリラインを形成します。 すべてのセグメントは水平または垂直であり、各セグメントは前のセグメントが終了した場所から始まり、最後のセグメントは開始点に戻ります。 これらのカットラインは、無限のチョコレート平面をいくつかの接続された領域に分割します。 

描かれたカットで完全に囲まれた領域のみが食べられます。 無限に接続されている領域は無視する必要があります。 タスクは、最大の境界領域の面積を見つけることです。 

座標は小さく、各頂点座標は最大でも 1000 ですが、セグメントの数は最大 1000 に達します。$10^4$。 

セグメントによって多くの異なる領域が作成される可能性があるため、連続平面上での直接的な幾何学的シミュレーションは扱いにくいです。 有益な観察は、すべての境界が x 座標と y 座標の有限セット上にあるということです。 2 つの隣接する x 値と 2 つの隣接する y 値の間では興味深いことは何も起こらないため、すべての領域を圧縮されたグリッド上に表現できます。 

よくある間違いは、歩行全体で囲まれたエリアのみを計算することです。 これは単純なポリゴンの場合は機能しますが、カットによって内部がいくつかの部分に分割される場合は失敗します。 もう 1 つの間違いは、境界があるように見えるすべての領域を、実際に切り込みで遮られていない廊下を通って無限につながっているかどうかを確認せずに数えることです。 

単純な長方形を考えてみましょう。```
(1,1) -> (1,4) -> (5,4) -> (5,1) -> (1,1)
```境界領域は 1 つだけあり、その面積は 12 です。 

ここで、2 つのチャンバーを作成する内部カットを含む形状を考えてみましょう。 答えは密閉面積の合計ではなく、チャンバーの面積が大きいことにあります。 図形全体を 1 つのポリゴンとして扱うとオーバーカウントになります。 

## アプローチ

 この強引なアイデアは、座標面全体を単位解像度で離散化し、隣接する整数座標のすべてのペアの間で塗りつぶしを実行することです。 座標は最大でも 1000 であるため、これはすでに約 100 万個の基本セルになります。 この問題には有効ですが、何も変化しない領域の探索にほとんどの時間を費やします。 

重要な観察は、ジオメトリはセグメントの端点に現れる x 座標と y 座標でのみ変化するということです。 2 つの連続するそのような座標の間では、平面は均一です。 関連するすべての x 値と y 値を圧縮すると、圧縮された各セルは元の平面の長方形全体に対応します。 

圧縮後、すべてのセグメントは隣接する圧縮セル間の壁になります。 問題はグラフ問題に変わります。 

それぞれの圧縮された四角形がノードです。 

隣接する 2 つの長方形は、それらを分離するカット セグメントがない場合に接続されます。 

外側マージンからの塗りつぶしにより、境界のないコンポーネントが識別されます。 他の接続コンポーネントはすべて、境界のあるチョコレート片です。 コンポーネント内の長方形の領域を合計すると、その幾何学的領域が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ユニットグリッドに対するブルートフォース | 実装に応じて O(10^6) から O(10^7) | O(10^6) | 許容できるが無駄である |
 | 座標圧縮 + 塗りつぶし | O(Ux・Uy + n) | O(Ux・Uy) | 承認済み |

 ここ$Ux$そして$Uy$は、圧縮された x 座標と y 座標の数です。 

## アルゴリズムのチュートリアル

 1. 閉じたウォークのすべての頂点を読み取ります。 
2. 頂点に現れるすべての x 座標と頂点に現れるすべての y 座標を収集します。 
3. 各軸に最小値より厳密に小さい座標と最大値より厳密に大きい座標を 1 つずつ追加します。 これらの追加の座標により、保証された外側のセルが作成されます。 
4. X 値と Y 値を並べ替えて重複を排除します。 
5. インターバルごと$[x_i, x_{i+1}]$そして$[y_j, y_{j+1}]$圧縮された長方形のセルを定義します。 
6. 2 つの壁構造を作成します。 

垂直の壁には、固定 X 座標を横切る動きがブロックされているかどうかが保存されます。 

水平壁には、固定 y 座標を横切る動きがブロックされているかどうかが保存されます。 
7. 歩行のすべてのセグメントを処理します。 

垂直セグメントの場合、対応する垂直壁内でそのセグメントが交差するすべての圧縮された Y 間隔をマークします。 

水平セグメントの場合は、水平壁で同様の操作を実行します。 
8. 圧縮されたセルを塗りつぶします。 

隣接するセルは、共有側を遮る壁がない場合にのみ到達可能です。 
9. 各接続コンポーネントについて、その幾何学的領域を累積します。$$(x_{i+1}-x_i)\cdot(y_{j+1}-y_j)$$10. 外側のマージンを含むコンポーネントは無限領域であり、無視する必要があります。 
11. 残ったすべてのコンポーネントのうち、最大の面積を出力します。 

### なぜ効果があるのか

 圧縮されたグリッドは、内部をカットが通過しない最大の長方形に平面を分割します。 すべての切断セグメントは圧縮されたセル間の境界上に正確に位置するため、壁にマーキングすると元の平面のすべての接続情報が保存されます。 

2 つの点は、圧縮されたセルがブロックされていない遷移を通じて接続されている場合に限り、チョコレート平面の同じ領域に属します。 したがって、圧縮されたグラフを埋めるフラッドは、すべてのカットの後に、平面の接続された領域を正確に見つけます。 

外側のマージンは、1 つのコンポーネントが無限大に対応することを保証します。 他のすべてのコンポーネントは境界付きです。 圧縮されたセルは平面の互いに素な分割を形成するため、コンポーネント内の長方形の領域を合計すると、その領域の正確な幾何学的な領域が得られます。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

n = int(input())

pts = [tuple(map(int, input().split()))]
for _ in range(n):
    pts.append(tuple(map(int, input().split())))

xs = [p[0] for p in pts]
ys = [p[1] for p in pts]

cx = sorted(set(xs + [min(xs) - 1, max(xs) + 1]))
cy = sorted(set(ys + [min(ys) - 1, max(ys) + 1]))

xid = {x: i for i, x in enumerate(cx)}
yid = {y: i for i, y in enumerate(cy)}

w = len(cx) - 1
h = len(cy) - 1

vertical = [bytearray(h) for _ in range(len(cx))]
horizontal = [bytearray(len(cy)) for _ in range(w)]

for i in range(n):
    x1, y1 = pts[i]
    x2, y2 = pts[i + 1]

    if x1 == x2:
        if y1 > y2:
            y1, y2 = y2, y1

        xi = xid[x1]
        y_from = yid[y1]
        y_to = yid[y2]

        for y in range(y_from, y_to):
            vertical[xi][y] = 1

    else:
        if x1 > x2:
            x1, x2 = x2, x1

        yi = yid[y1]
        x_from = xid[x1]
        x_to = xid[x2]

        for x in range(x_from, x_to):
            horizontal[x][yi] = 1

visited = [bytearray(h) for _ in range(w)]

def cell_area(i, j):
    return (cx[i + 1] - cx[i]) * (cy[j + 1] - cy[j])

answer = 0

for si in range(w):
    for sj in range(h):
        if visited[si][sj]:
            continue

        q = deque([(si, sj)])
        visited[si][sj] = 1

        area = 0
        touches_outside = False

        while q:
            x, y = q.popleft()

            area += cell_area(x, y)

            if x == 0 or x == w - 1 or y == 0 or y == h - 1:
                touches_outside = True

            if x > 0 and not vertical[x][y] and not visited[x - 1][y]:
                visited[x - 1][y] = 1
                q.append((x - 1, y))

            if x + 1 < w and not vertical[x + 1][y] and not visited[x + 1][y]:
                visited[x + 1][y] = 1
                q.append((x + 1, y))

            if y > 0 and not horizontal[x][y] and not visited[x][y - 1]:
                visited[x][y - 1] = 1
                q.append((x, y - 1))

            if y + 1 < h and not horizontal[x][y + 1] and not visited[x][y + 1]:
                visited[x][y + 1] = 1
                q.append((x, y + 1))

        if not touches_outside:
            answer = max(answer, area)

print(answer)
```座標圧縮フェーズでは、平面の長方形の分解が構築されます。 壁アレイは、切断されたセグメントをエンコードします。 垂直セグメントは、そのすぐ左と右のセル間の動きをブロックします。 水平セグメントは、そのすぐ下と上のセル間の移動をブロックします。 

フラッド フィルは、この圧縮された配置で連結成分を計算します。 の`touches_outside`flag は、無限大に接続された一意のコンポーネントを識別します。 すべての有界コンポーネントが回答候補に寄与します。 

面積の計算では、圧縮されたインデックスではなく、元の座標の差が使用されます。 これは、真の幾何学的な領域を維持するための詳細です。

 ## 特殊なケース

 可能な最小の囲まれた領域を考慮します。```
4
1 1
1 2
2 2
2 1
1 1
```圧縮されたグリッドには、エリア 1 の境界セルが 1 つだけ含まれています。フラッド フィルは外側を個別に識別し、1 を返します。 

x 値と y 値が多数繰り返される形状を考えてみましょう。 圧縮では同一の座標が 1 つのインデックスにマージされるため、重複する座標線によって人工的なセルが作成されることはありません。 壁の建設により、ブロックされたすべての境界線が正しくマークされます。 

境界領域が頂点を共有するが面積を共有しない図を考えてみましょう。 圧縮されたセル間の移動は共有エッジ間でのみ発生するため、点をタッチしてもコンポーネントはマージされません。 フラッド フィルでは、正しい平面接続が維持され、各部分が個別に計算されます。
