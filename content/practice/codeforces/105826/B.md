 ## 問題の理解

 正多角形があります`n`番号が付けられた頂点。 最初の頂点から始めて、一定のステップで繰り返し移動します`k`ポリゴンの周りに移動し、訪問した頂点の間にセグメントを描画します。 このプロセスで到達したすべての頂点がペイントされます。 タスクは、有効な最小値を選択することです`k`ペイントされる頂点の数ができるだけ少なくなるようにします。 

入力には頂点の数のみが含まれます。 出力は、すべての最適な選択肢の中から最小のステップが選択された、訪問頂点の可能な限り最小のセットを作成するステップ サイズです。 

重要な制約は、`n`と同じ大きさにすることができます`10^10`したがって、考えられるすべてのステップまたはすべての頂点を反復する解決策は不可能です。 たとえ`O(n)`アルゴリズムは最大 100 億の操作を実行する可能性があり、これは通常のコンテストの制限をはるかに超えています。 数論を使用し、約数を扱う必要があります。`n`ポリゴン自体の代わりに。 

よくある間違いは、大きなステップでは常に描画されるポイントが少なくなると想定することです。 ペイントされた頂点の数は、ステップがどのように相互作用するかによってのみ異なります。`n`の数値サイズではありません`k`。 

たとえば、次の場合`n = 9`、選択する`k = 8`大きいように見えますが、訪問した頂点は次のとおりです。```
1, 9, 8, 7, 6, 5, 4, 3, 2
```9 つの頂点すべてがペイントされているため、答えは 8 ではありません。正解は次のとおりです。`3`、訪問するため:```
1, 4, 7
```3 つの頂点のみをペイントします。 

もう 1 つのエッジ ケースは、頂点が素数である場合です。 のために`n = 7`、ゼロ以外のすべてのステップは互いに素です。`7`したがって、可能なすべてのステップがすべての頂点に到達します。 最小限の有効なステップは次のとおりです。`1`。 

## アプローチ

 直接的なアプローチは、あらゆる可能性を試すことです`k`から`1`に`n - 1`。 各ステップで、開始頂点に戻るまで多角形の周りの動きをシミュレートし、到達した個別の頂点の数を数えることができます。 これは塗装プロセスに正確に従っているため、これは正しいです。 

問題は、1 回のシミュレーションに最大で 4 時間かかることです。`n`動く。 全部試してみる`n - 1`可能な値は約`n^2`操作。 と`n`到達`10^10`、これはまったく不可能です。 

重要な観察は、訪問した頂点がサイクルを形成していることです。 後`t`移動すると、現在の頂点は次のようになります。```
1 + t * k (mod n)
```このシーケンス内の 2 つの位置は、それらの差が次の倍数である場合に同じになります。`n`。 このサイクルの一意の位置の数は正確に次のとおりです。```
n / gcd(n, k)
```したがって、ポリゴンをシミュレートする代わりに、最大化するだけで済みます。`gcd(n, k)`。 この gcd ができるだけ大きい場合、ペイント数は最小になります。 

間の可能な最大の gcd`n`そして適切なポジティブ`k`の最大の適切な約数です`n`。 もし`n`は合成であり、その最小の素因数は`p`、この約数は`n / p`。 最小の`k`その gcd も`n / p`。 

もし`n`は素数であり、これより大きい適切な約数はありません`1`したがって、各ステップですべての頂点がペイントされます。 可能な最小のステップは、`1`。

 ## アルゴリズムのチュートリアル

 1.読む`n`それが素数であるかどうかを判断するか、最小の素因数を見つけます。 
2. もし`n`それ自身より小さい約数はなく、それは素数です。 可能なすべてのステップがすべての頂点を訪問するため、戻ります`1`。 
3. それ以外の場合は、`p`～の最小の素因数となる`n`。 戻る`n / p`、これは最大の適切な約数であり、可能な最大の gcd を与えるためです。`n`。 

なぜ機能するのか: 動きは常にサイクルを作成し、その長さは次のように制御されます。`gcd(n, k)`。 gcd が大きいほど、サイクル内の頂点が少なくなります。 最大 gcd は、次の最大の約数です。`n`それはより小さいです`n`、そしてそれを生み出す最小のステップはまさにその除数です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n % 2 == 0:
        print(n // 2)
        return

    d = 3
    while d * d <= n:
        if n % d == 0:
            print(n // d)
            return
        d += 2

    print(1)

if __name__ == "__main__":
    solve()
```この解決策は最初に偶数を処理します。`2`可能な最小の素因数です。 偶数の場合`n`、最良のステップは`n / 2`。 

奇数の場合、次から始まる最小の奇数約数を検索します。`3`。 の平方根までチェックするだけで済みます。`n`、なぜなら、`n`の係数が平方根より大きい場合、マッチング係数は小さくなります。 

最初に見つかった約数が最小の素因数です。 戻る`n / divisor`最大の適切な約数が得られます。これは必要なステップです。 除数が見つからない場合は、`n`は素数であり、答えは`1`。 

ポリゴン構造全体が gcd 関係によって表されるため、配列や訪問セットは必要ありません。
