 ## 解決策
 ## 問題の理解

 この機械には 5 つの垂直コラムがあります。 最初の 3 つのボールがすでに落ちていると、現在各列にボールがいくつあるかがわかります。 ドロップするボールはまだ 2 つ残っており、それぞれが 5 つの列のいずれかに入る可能性があります。 

賞品は、5 つのボールすべての最終的な配置によって決まります。 垂直線は、必要なすべてのボールが 1 つの列にあることを意味します。 水平線は、ボールが異なる列にわたって同じ行を占めることを意味します。 課題は、残り 2 つのボールでプレーヤーがグランプリを獲得できるか、ベーシック賞のみを獲得できるか、または賞品を獲得できないかを決定することです。 

入力は 5 つの整数です。 位置の値`i`現在その中にあるボールの数です。`i`- 番目のスロット。 ちょうど 3 つのボールがすでにプレーされているため、それらの合計は常に 3 になります。 出力は、最後の 2 つのボールがどこに落ちるかを選択した後に可能な最良の結果を示します。 

スロット数が少ないことが重要な制約です。 残りの 2 つのボールのそれぞれに考えられる目的地は 5 つだけであるため、考えられる結末の総数はわずかです。 あらゆる可能性を直接シミュレーションしても、チェックできるのは 25 件だけです。 これは、大規模な配列の一次または二次の複雑さに関する通常の懸念がここでは当てはまらないことを意味します。 

主なエッジケースは、ボードのジオメトリと列数だけを混同することに起因します。 

たとえば、入力```text
1 1 1 0 0
```大賞になる可能性があります。 残りの 2 つのボールをスロット 4 と 5 に入れると、次のようになります。```text
1 1 1 1 1
```各列にはボールが 1 つあるため、一番下の水平行には 5 つのボールがすべて含まれます。 

よくある間違いは、1 つの列が高さ 5 に到達できるかどうかだけを確認することです。 それは水平方向の勝利を逃します。 

もう 1 つの注意が必要なケースは次のとおりです。```text
3 0 0 0 0
```正しい出力は次のとおりです`add oil`。 両方のボールを最初のスロットに追加すると、1 つの列に 5 つのボールが得られますが、他の列は空のままであるため、大賞は不可能です。 列にボールを 5 個入れることができるかどうかだけをチェックするソリューションでは、誤ってグランプリが報告されてしまいます。 

最終的な境界ケースは次のとおりです。```text
1 1 1 0 0
```正しい出力は次のとおりです`op`、 ない`add oil`, 残りの2つのボールで横一列を完成させることができるためです。 既存の列のボールの数だけをチェックするソリューションは、勝ちの配置がまだ存在しないために失敗する可能性があります。 

## アプローチ

 最も簡単な解決策は、最後の 2 つのボールの可能な配置をすべて試してみることです。 2 つの目的地スロットの選択ごとに、最終的な 5 つの列の高さを作成し、ボードにグランプリまたはベーシック賞が含まれているかどうかを確認します。 

最初に残ったボールには 5 つの選択肢しかなく、2 番目に残ったボールには 5 つの選択肢しかないため、この総当たりはすでに十分に高速です。 したがって、シミュレーションの数は次のようになります。`5 * 5 = 25`。 各シミュレーションでは 5 つの列のみを検査し、125 の単純な演算を行います。 

有益な観察は、問題の状態空間が非常に小さいということです。 あらゆる可能な配置について複雑な条件を導き出そうとする代わりに、あらゆる可能な未来を直接探索することができます。 これにより、シミュレーションによって最終的なボードが自然に構築され、実際の勝利条件がチェックされるため、横の列に関する間違いが回避されます。 

可能な未来の数は一定であるため、総当り攻撃が機能します。 多くの列を含む同じ問題のより大きなバージョンでは、数学的な観察が必要になりますが、ここでは徹底的なチェックが最もクリーンで安全なアプローチです。 

必要な最適化は、基本賞の前に大賞をチェックすることだけです。 少なくとも 1 つの結末が大賞を与える場合、答えは次のようになります。`op`たとえ他の多くのエンディングでは基本賞しか与えられなかったとしても。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 |---|---|---|---|
 | ブルートフォース | O(25 * 5) | お(5) | 承認済み |
 | 最適 | O(25 * 5) | お(5) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在の 5 つの列の高さを読み取ります。 

2. 4 番目のボールの可能なすべてのスロットを試します。 そのような選択をするたびに、5 番目のボールの可能なすべてのスロットを試してください。 

3. 選択の各ペアについて、対応する列の高さを増やし、結果として得られる基板を検査します。 いずれかの列の高さが 5 であれば、長さ 5 の垂直行が存在します。 すべての列に少なくとも 1 つのボールがある場合、長さ 5 の水平行が存在します。 

4. グランプリを生み出すエンディングがある場合、答えは次のとおりであることを覚えておいてください。`op`。 

5. グランプリを作成するエンディングがない場合は、同じ検索を繰り返して、ベーシック賞を作成するエンディングがあるかどうかを確認します。 縦の基本賞は、列の高さが少なくとも 4 の場合に存在します。 水平基本賞は、少なくとも 4 つの列が少なくとも 1 つの高さを持っている場合に存在します。 

6. どちらの賞も獲得できない場合は、出力`gg`。 

それが機能する理由: すべての法的な将来の取り決めは、残りの 2 つのボールに対する正確に 1 組の選択肢によって表されます。 アルゴリズムはそのようなペアをすべてチェックするため、勝ちの配置を見逃すことはありません。 賞金チェックはボードのルールを直接翻訳したもので、報告されたすべての勝利が有効であり、すべての可能な勝利が検出されることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def check_grand(a):
    if max(a) == 5:
        return True
    if all(x >= 1 for x in a):
        return True
    return False

def check_basic(a):
    if max(a) >= 4:
        return True
    if sum(x >= 1 for x in a) >= 4:
        return True
    return False

def solve():
    c = list(map(int, input().split()))

    grand = False
    basic = False

    for i in range(5):
        for j in range(5):
            a = c[:]
            a[i] += 1
            a[j] += 1

            if check_grand(a):
                grand = True
            if check_basic(a):
                basic = True

    if grand:
        print("op")
    elif basic:
        print("add oil")
    else:
        print("gg")

if __name__ == "__main__":
    solve()
```の`check_grand`関数は、5 つのボールすべてを含む 2 つの可能な形状をテストするだけです。 垂直グランプリには、5 つのボールすべてを保持するために 1 つの列が必要です。 水平グランプリでは、すべての列に一番下のボールが含まれている必要があります。 

の`check_basic`この関数は、4 つのボールを一列に並べる 2 つの方法を処理します。 縦型ケースは、`max(a) >= 4`一方、水平方向の場合は、空ではない列の数をカウントします。 条件は以下を使用します`>= 1`なぜなら、水平行は列がその高さに達した場合にのみ存在できるからです。 

ネストされたループは、残りの 2 つのボールを完全に検索します。 配列を変更する前にコピーすると、異なるシミュレートされたエンディング間の干渉が回避されます。 配列の長さは 5 であるため、このコピーのコストは無視できます。 

最終チェックの順序が重要です。 大賞は基本賞よりも優れているため、コードは次のようになります。`op`可能な継続が最高の報酬に達するたびに。 

## 実用的な例

 ### サンプル 1

 入力:```text
1 2 0 0 0
```考えられる有用な配置には、空のスロットに 2 つのボールを入れて 4 つの占有列を作成するか、1 つのボールを 2 番目のスロットに入れることが含まれます。 

| 最初の新しいボール | 2番目の新しいボール | 最終的な高さ | 大賞 | 基本賞 |
 |---|---|---|---|---|
 | 2 | 2 | 1 4 0 0 0 | いいえ | はい |
 | 3 | 4 | 1 2 1 1 0 | いいえ | はい |
 | 3 | 5 | 1 2 1 0 1 | いいえ | いいえ |

 どのエンディングも 5 つの列すべてを埋めることも、高さ 5 の列を作成することもできないため、考えられる最高の結果は基本賞です。 

出力：```text
add oil
```このトレースは、アルゴリズムが最初の有用な配置が最良のものであると仮定するのではなく、考えられるすべての結末をチェックする理由を示しています。 

### サンプル 2

 入力:```text
1 0 1 0 1
```スロット 2 と 4 の残りのボールを試してみると、次のようになります。 

| 最初の新しいボール | 2番目の新しいボール | 最終的な高さ | 大賞 | 基本賞 |
 |---|---|---|---|---|
 | 2 | 4 | 1 1 1 1 1 | はい | はい |

 各列に 1 つのボールが配置され、完全な水平列が形成されます。 

出力：```text
op
```この例は、水平グランプリ条件を示しています。

 ## 特殊なケース

 入力用```text
3 0 0 0 0
```アルゴリズムは、残りの 2 つのボールの可能な配置をすべて試みます。 最良の選択は、両方を最初の列に配置し、高さを与えることです。`5 0 0 0 0`。 最初の列には 5 つのボールが含まれているため、縦方向の大賞が存在します。 ただし、実際には正しい出力は`op`、これは大賞ですから。 出力が次のように予想される場合`add oil`、これは賞品の優先順位が正しく実装されていないことを示しています。 アルゴリズムは、最初に大賞をチェックすることでこれを処理します。 

入力用```text
1 1 1 0 0
```残りのボールをスロット 4 と 5 に入れると、`1 1 1 1 1`。 大賞チェックでは、すべての列が空ではないことが確認されるため、次の結果が返されます。`op`。 これにより、垂直線のみを検査するソリューションが捕捉されます。 

入力用```text
0 0 0 0 3
```唯一の有益な改善は、最後の列を増やすことです。 最良の最終状態は、`0 0 0 0 5`、垂直線は得られますが、水平線は作成できません。 アルゴリズムは宛先のすべてのペアをテストするため、依然としてそれを見つけます。 

入力用```text
1 2 0 0 0
```残りの両方のボールを 2 番目のスロットに入れると、`1 4 0 0 0`、縦に4つのボールを与えます。 5 つの列すべてを空にしない、または高さを 5 にすることはできないため、アルゴリズムは次の値を返します。`add oil`。 これにより、2 つの賞レベルの違いが検証されます。
