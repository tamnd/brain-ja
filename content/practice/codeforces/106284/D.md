 ## 解決策
 ## 問題の理解

 非負の整数の count 3 倍が必要です`(A, B, C)`3 つの指定された間隔内で、2 つの合計の最大公約数が約`B`2 つの外側の値の合計と等しくなります。`gcd(A + B, B + C) = A + C`。 

入力により、可能な値の左右の境界が与えられます。`A`、`B`、 そして`C`。 出力は、等式を満たすトリプルの数です。 

興味深いのは、範囲が非常に大きく、最大で`10^9`したがって、可能なすべてのトリプルを反復処理することは不可能です。 ただし、各間隔の長さは最大で`300000`これは、アルゴリズムが数十万回の演算を行うことが予想されることを意味します。 3 つのネストされたループを含むソリューションには、最大で`300000^3`制限をはるかに超えています。 すべての値のペアをチェックするだけでも、すでにコストがかかりすぎます。 

主な罠は、平等とは単に平等を実現することではないということです。`A + C`gcd の両方の引数を除算します。 gcd は正確に次のようにする必要があります`A + C`。 また、ゼロを含む割り算引数では情報が失われる可能性があるため、ゼロ値の動作は異なります。 

たとえば、次のことを考えてみましょう。```
A: 1 1
B: 2 2
C: 3 3
```可能なトリプルは 1 つだけです`(1,2,3)`。 我々は持っています`gcd(3,5)=1`、 しかし`A+C=4`、したがって、答えは次のとおりです`0`。 かどうかだけをチェックするソリューション`A+C`最終的な gcd の同等性の方が強いため、両方の gcd 引数を除算してもここでは失敗します。 

別のエッジケースは次のとおりです。```
A: 0 0
B: 0 5
C: 0 0
```のみ`(0,0,0)`動作します。 のために`(0,B,0)`の状態になります。`gcd(B,B)=B`に等しい`0`そのときだけ`B=0`。 ゼロの場合を無視すると、すべての値が誤ってカウントされる可能性があります。`B`。 

最後の境界ケースは、外側の値の 1 つが 0 で、もう 1 つはゼロではない場合です。```
A: 0 0
B: 1 10
C: 5 5
```ここでの有効な値は、`B`の倍数です`5`、 なぜなら`gcd(B,B+5)=gcd(B,5)`でなければなりません`5`。 のみ`B=5`そして`B=10`仕事。 

## アプローチ

 直接的なアプローチでは、可能なすべてのトリプルを試して gcd 条件をテストします。 すべての有効な答えがチェックされるため、これは正しいですが、操作の数は 3 つの間隔の長さの積になります。 最大長さあり`300000`、これくらいになります`2.7 * 10^16`チェック、それは不可能です。 

重要な観察は、平等によって何が強制されるのかを理解することから生まれます。 させて`S = A + C`。 必要なものは次のとおりです。`gcd(A+B, B+C) = S`。 

gcd は次とのみ等しいことができます`S`もし`S`両方の引数を分割します。 から`S | A+B`そして`S | B+C`、減算すると、`S | A-C`。 以来`S = A+C`、わかりました`S`両方を分割します`A+C`そして`A-C`。 これら 2 つの値を加算すると、`S | 2A`。 

なぜなら`0 <= A <= S`、唯一可能な値は、`2A`は：`0`、`S`、 または`2S`。 

これにより、構造的なケースが 3 つだけ残ります。 

もし`A = 0`、 それから`C = S`、条件は次のように減少します。`C | B`。 

もし`C = 0`、同様に必要です`A | B`。 

もし`A = C`の場合、2 つの gcd 引数が等しいため、gcd は次のようになります。`A+B`。 必要です`A+B = 2A`、それは与える`B=A`。 

特別な場合`A=C=0`だけを与える`B=0`。 

したがって、トリプルを検索する代わりに、範囲内の倍数と等しい値の交差部分をカウントするだけで済みます。

 ## アルゴリズムのチュートリアル

 1. 3 つの間隔を読み取ります。 境界線を次のように保存します`LA, RA`、`LB, RB`、 そして`LC, RC`。 
2. 症例を数える`A = 0`そして`C > 0`。 あらゆる可能なポジティブな要素に対して`C`、の値がいくつあるか数えます。`B`その区間内では次のように割り切れます。`C`。 の倍数`x`で`[l, r]`は：`r // x - (l - 1) // x`。 

この場合の数学的条件は正確に次のとおりであるため、これは機能します。`C | B`。 
3. 症例を数える`C = 0`そして`A > 0`同じように。 あらゆる可能なポジティブな要素に対して`A`の倍数を加算します。`A`の中で`B`間隔。 
4. 症例を数える`A = C > 0`。 同じ値が 3 つの間隔すべてに属している必要があるため、寄与は 0 を除いた 3 つの間隔の交差部分のサイズになります。 
5.ハンドル`(0,0,0)`別に。 3 つの間隔すべてに 0 が属する場合は、1 を追加します。 

これが機能する理由: gcd が正確に一致するため、すべての有効なトリプルは派生ケースの 1 つを満たす必要があります。`A+C`力`A+C`分ける`2A`。 考えられる 3 つの位置`A`に対して`A+C`すべての可能性をカバーし、各ケースは同等のより単純な条件を使用してカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_multiples(x, l, r):
    return r // x - (l - 1) // x

def solve():
    LA, RA = map(int, input().split())
    LB, RB = map(int, input().split())
    LC, RC = map(int, input().split())

    ans = 0

    if LC > 0:
        for c in range(LC, RC + 1):
            ans += count_multiples(c, LB, RB)

    if LA > 0:
        for a in range(LA, RA + 1):
            ans += count_multiples(a, LB, RB)

    left = max(LA, LC, 1)
    right = min(RA, RC, RB)
    if left <= right:
        ans += right - left + 1

    if LA == 0 and LB == 0 and LC == 0:
        ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```ヘルパーさん`count_multiples`を繰り返すことを避けます`B`間隔。 整数除算を使用して、固定値で割り切れるすべての数値をカウントします。 

最初のループは、`A=0`支店。 スキップします`C=0`そのケースは個別のオールゼロ処理に属しているためです。 2 番目のループは対称です。`C=0`。 

交差の計算には次のものを使用します。`max`そして`min`なぜなら`A`、`B`、 そして`C`すべて同じ正の数でなければなりません。 下限は少なくとも強制されます`1`ゼロは別個に扱われるためです。 

Python では整数オーバーフローの危険はありません。 固定サイズの整数を使用する言語では、答えはステートメントに従って適合しますが、中間積は避けるべきです。
