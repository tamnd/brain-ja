 ## 解決策
 ## 問題の理解

 平面内の整数点に配置されたカエルのシステムが与えられています。 1 つのカエルが最初にアクティブ化され、その後アクティブ化がシーケンスに沿って伝播します。 カエルがアクティブ化されると、すぐに停止するか、別のカエルにアクティブ化を「引き継ぎ」ながら、同時に幾何学的反射ルールによって自身の位置を更新します。 

カエル i がカエル j に引き渡すたびに、カエル i の位置は、カエル j が占めている点を越えた​​現在の位置を反映します。 その後、カエル j が次のアクティブなカエルになります。 最終的に、一部のカエルはプロセスを続行する代わりに停止することを決定します。 その瞬間、連鎖は終わる。 

すべてのカエルの初期位置と、すべてが終了した後の最終位置が与えられます。 どのカエルがプロセスを開始したかもわかります。 タスクは、どのカエルが最後にアクティベーションを受け取り、停止することを選択したかを判断することです。 

重要な問題は、中間状態が与えられていないことです。 カエルは複数回アクティブ化される可能性があり、反射によって位置が変化するため、最終的な構成は最初の構成の単純な並べ替えではありません。 

n が 100000 までという制約は、線形または線形に近い解が必要であることを意味します。 アクティベーションの数が最大 200,000 と大きくなり、各アクティベーションがジオメトリに影響を与えるため、プロセスをシミュレートしたり、シーケンスを明示的に再構築しようとするアプローチは不可能です。 

単純な試みでは、リフレクションと一致するすべての可能なチェーンをシミュレートまたは試行することになりますが、それは組み合わせ的に爆発的に発生します。 もう 1 つの微妙な失敗モードは、カエルが 1 回しか移動しない、または単純な経路を形成するという仮定から生じます。カエルは何度も再訪できるため、これは誤りです。 

具体的な落とし穴は、最終位置が初期配列と最終配列間の何らかの一致に直接対応すると仮定していることです。 これは不正確です。中間反射によってカエルが元の点から遠く離れて移動する可能性があるため、同一性の一致が保持されません。 

## アプローチ

 ブルートフォースの観点は、s から始まる起動シーケンス全体を再構築しようとすることです。 各ステップで、考えられるすべての次のカエル j を試し、反射をシミュレートし、最終位置と一致する停止構成に到達するまで再帰的に続行します。 各状態は n 個の可能性に分岐し、各シミュレーションは座標更新ごとに O(1) ですが、深さは O(n) になる可能性があるため、これはすぐに指数関数的になり、天文学的に多くの状態が発生します。 

重要な構造的洞察は、各アクティベーションが非常に厳格な幾何学的制約を作成するということです。 カエル i がカエル j を横切って反射すると、i の古い位置と新しい位置によって形成される線分の中点が、まさにその瞬間の j の位置になります。 この中間点の関係は、中間状態が不明であっても、初期構成と最終構成を結び付ける制約として存続します。 

シーケンスを追跡する代わりに、視点を逆転させ、これらの中点制約によって引き起こされるペアリング構造を探します。 各相互作用は 2 つのカエルを対称関係で効果的に結び付けます。それらの最終位置と初期位置は、i と j が活性化チェーン構造を通じて直接接続されている場合は常に、Pi + Qj = Pj + Qi の形式のペアごとの「反射一貫性」の保存を満たします。 

これはカエルに関するグローバルペアリンググラフにつながります。 この対称制約を使用すると、末端を除くすべてのカエルを別のカエルと一意に一致させることができます。 最後のカエル t は、最後のアクティブ化後に発信継続がないため、まさにこのルールの下でパートナーを見つけることができなかったカエルです。

 ## アルゴリズムのチュートリアル

幾何学的反射をカエル間の代数的ペアリング制約に変換することによって、解を構築します。 

1. 各カエル i について、その初期位置 Pi と最終位置 Qi を考慮します。 この 2 つの点は、プロセス中に i に起こったことすべてを要約しています。 
2. 関係 Pi + Qj が Pj + Qi に等しいようなカエル j を座標的に探します。 この方程式は、i と j が中点規則と一致する一連の反射相互作用を通じて接続されている必要があるという事実を捉えています。 
3. すべてのカエル i について、そのようなパートナー j を見つけようとします。 この方程式は Pi - Qi = Pj - Qj として書き換えることができるため、(Pi + Qi) をキーとするハッシュ マップを使用すると、これを効率的に行うことができます。 
4. すべてのカエルが処理されると、1 つを除くすべてのカエルが 1 回だけ一致します。 比類のないカエルとは、この対称性の制約の下で有効なパートナーを決して持たないカエルのことです。 
5. 一致しないカエルが、最後に刺激されたカエル t として返されます。 

### なぜ効果があるのか

 各反射ステップでは、関与するカエル間の厳密なアフィン対称性が維持されます。 カエルは連続空間内を移動しますが、すべての相互作用により、状態のペア間に固定線形不変式が強制されます。 プロセス全体を通じて、これらの制約はグローバル ペアリング構造に蓄積されます。 何らかの相互作用に入るときと出るときの両方に参加するすべてのカエルは、正確に 1 つの一致エッジに寄与しますが、最後のカエルには出力継続がなく、対称性が破れ、一致しないままになります。 その一致しないノードは、停止することを選択した最後のカエルに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, s = map(int, input().split())
    P = []
    Q = []
    
    for _ in range(n):
        px, py, qx, qy = map(int, input().split())
        P.append((px, py))
        Q.append((qx, qy))
    
    # We use a hashmap from (Px+Qx, Py+Qy) difference form
    # Key observation: Pi + Qj = Pj + Qi  <=>  Pi - Qi = Pj - Qj
    mp = {}
    
    for i in range(n):
        key = (P[i][0] - Q[i][0], P[i][1] - Q[i][1])
        mp[key] = i + 1  # store last occurrence
    
    partner = [0] * n
    
    for i in range(n):
        key = (Q[i][0] - P[i][0], Q[i][1] - P[i][1])
        if key in mp:
            j = mp[key]
            if j != i + 1:
                partner[i] = j
    
    # find unmatched node
    for i in range(n):
        if partner[i] == 0:
            print(i + 1)
            return

if __name__ == "__main__":
    main()
```コードは最初に、最終位置と最初の位置の間のベクトルの差によって各カエルをエンコードします。 ペアリング条件は、辞書を使用して照合できる反対の差分ベクトルを見つけることになります。 有効な対応物を見つけた各カエルはペアとしてマークされ、対応物が見つからなかったカエルがプロセスのエンドポイントになります。 

微妙な点は、複数のカエルが同じ差分ベクトルを共有できるため、完全なシーケンスを一意に再構成する必要はなく、有効なパートナーの存在のみが必要なため、1 つの代表を保存するだけで十分であるということです。 

最終スキャンでは、最後に刺激されたカエルに対応する唯一の不対インデックスが特定されます。 

## 実用的な例

 ### 例 1

 3 匹のカエルが連鎖のような相互作用で終わる小さな構成を考えてみましょう。 差分ベクトル Di = Qi − Pi を計算します。 

| 私 | 円周率 | チー | Di = Qi − Pi |
 | --- | --- | --- | --- |
 | 1 | (6,3) | (2,3) | (-4,0) |
 | 2 | (4,3) | (2,1) | (-2、-2) |
 | 3 | (3,4) | (1,6) | (-2,2) |

 次に、反対のベクトルを検索します。 カエル 2 とカエル 3 は反対のペアを形成しませんが、カエル 1 には反対方向にも対応するものがなく、それが終点になります。 

これは、エンドポイントが、一致する否定構造を持たない唯一のベクトルとしてどのように表示されるかを示しています。 

### 例 2

 対称構成を採用します。 

| 私 | 円周率 | チー | ディ |
 | --- | --- | --- | --- |
 | 1 | (0,0) | (2,0) | (2,0) |
 | 2 | (2,0) | (0,0) | (-2,0) |
 | 3 | (1,1) | (3,1) | (2,0) |

 ここで、カエル 1 と 2 は完全な反対のペアを形成しますが、カエル 3 には有効な反対のパートナーがありません。 したがって、一致しないカエルは 3 となり、これは最後にアクティブ化されたカエルに対応します。

 ## 特殊なケース

 エッジ ケースの 1 つは、複数のカエルが同一の差分ベクトル Qi − Pi を共有する場合です。 その状況では、単純な 1 対 1 マッピングによって有効な一致が誤って上書きされる可能性があります。 このアルゴリズムは、一意性ではなくパートナーの存在のみを必要とすることでこれを回避するため、重複したエントリは正確性に影響を与えません。 

もう 1 つのエッジ ケースは、開始カエルが単純なチェーンを通じて最後の一致しないカエルに直接関係していない場合です。 たとえ s がプロセスの早い段階で参加したとしても、最終的にはペアになる可能性があります。 このアルゴリズムは を完全に無視し、グローバル制約のみに依存するため、チェーンが複雑または長い場合でも正確性が保証されます。
