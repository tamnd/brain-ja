 ## 解決策
 ## 問題の理解

 平面上に 2 つの凸多角形が与えられます。 それらを 2 つの厳密な「衝突形状」と考えてください。 1 つのポリゴン (P と呼びます) は固定されたままになります。 もう一方の多角形 Q は、回転や反射を行わずに、平面内のベクトル t によって平行移動されます。 

Q の任意の位置について、P と Q のシフトされたコピーの間の重複領域を計算できます。この重複領域は「損傷」として解釈されます。 

ここで、単一のランダムな位置を選択する代わりに、2 つの多角形が実際に正の領域と重なるすべての平行移動 t を考慮します。 そのようなすべての翻訳の中から一様にランダムに 1 つを選択し、予想される重複領域が必要になります。 

したがって、タスクは「交差点を 1 つ見つける」ことではなく、「衝突を引き起こすすべてのシフトにわたる交差点エリアを平均する」ことです。 

入力により、2 つの凸多角形が反時計回りの順序で与えられます。 出力は、テスト ケースごとに 1 つの実数、つまりゼロ以外のオーバーラップを生成するすべての平行移動ベクトルにわたる交差領域の条件付き期待値です。 

制約の合計サイズはテスト ケース全体で小さく、全体で最大でも数千の頂点しかありません。 これは、テスト ケースごとに O(n + m) または O((n + m) log(n + m)) の幾何学的解法が意図されていることを強く示唆しており、変換の空間が連続しているため、変換のサンプリングやシフトごとのペアごとの重複のチェックなどは直ちに実行不可能です。 

微妙なエッジケースは、コンディショニングを理解することです。 境界ボックスまたは無限平面内のすべての平行移動の平均を計算するわけではありません。 ポリゴンが交差する平行移動のみを平均します。 そのセット自体は、移動平面内の幾何学的オブジェクトです。 

もう 1 つの微妙な点は、「交差には正の面積がある」ということは、境界に接触する構成を除外することです。 これは最終的な連続積分には影響しませんが、メジャー ゼロの境界について推論するときに概念的に重要になります。 

## アプローチ

 直接解釈では、翻訳をサンプリングし、それぞれの交差領域を計算して、期待値を近似しようとします。 たとえ空間を離散化したとしても、並進領域は無制限であり、有効な衝突の領域はそれ自体が複雑な凸形状になります。 ミンコフスキー差の周囲の境界ボックスに限定したとしても、単純なグリッドでは多角形交差の評価が多すぎる必要があり、それぞれのコストが O(n + m) となり、正確な計算には受け入れられない O(K(n + m)) のような値になります。 

重要な観察は、これが隠れた畳み込み問題であるということです。 P(x) と Q(x) を 2 つの多角形の指標関数とします。 この場合、平行移動 t 後の交差領域は、平面上の P(x)Q(x − t) の積分になります。 これをすべての t にわたって積分すると、構造は標準の畳み込み恒等式になります。変換 t = p − q に対して、点の各ペア (P の p、Q の q) は 1 回だけ寄与します。 

これは、無限小の面積要素の各ペアが正確に 1 つの平行移動ベクトルに対して重複するため、すべての平行移動にわたる交差面積の合計積分は正確に area(P) と area(Q) の積であることを意味します。 

したがって、期待値の分子は簡単で、多角形の面積の積になります。 

残る唯一の困難は正規化ドメイン D、つまり交差が空ではない翻訳のセットです。 これはまさにミンコフスキー和 P + (−Q) です。 実際、t によって変換された Q は、t がミンコフスキー差 P − Q 内にある場合に限り、P と交差します。これは P ⊕ (−Q) と等価です。 両方の多角形が凸多角形であるため、このミンコフスキー和も凸多角形になります。 

したがって、問題はコンピューティングに帰着します。 

P の面積、Q の面積、凸多角形の面積 P ⊕ (−Q)。 答えは (面積(P) · 面積(Q)) / 面積(P ⊕ (−Q)) となります。 

2 つの凸多角形のミンコフスキー和の構築は、エッジ方向シーケンスのマージに基づく標準的な線形時間手順です。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースサンプリング翻訳 | O(K(n + m)) | お(1) | 遅すぎて不正確です |
 | 畳み込み洞察 + ミンコフスキー和 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 中心的なアイデアは、すべてをポリゴン領域の計算と変換平面での 1 つのミンコフスキー和構築に変換することです。 

1. 靴紐の式を使用して P の符号付き面積を計算し、その絶対値を取得します。 これにより、最初の多角形の幾何学的領域が得られます。 
2. 同様に Q の面積を計算します。 これは後で分子の 2 番目の要素を形成します。 
3. Q のすべての座標を否定して、-Q を取得します。 これにより、Q が原点から反転され、変換関係が差分ではなくミンコフスキー和になります。 衝突条件は当然 P ⊕ (−Q) として表されるため、このステップが必要です。 
4. ミンコフスキー和 R = P ⊕ (−Q) を構築します。 P と −Q は両方とも凸であり、反時計回りの順序で与えられるため、それらのエッジ方向シーケンスをマージします。 各多角形の辞書編集上の最も低い頂点 (最小の y、次に x) から開始し、角度の増加順にエッジに沿って歩き、極角が小さい方の多角形から次のエッジ ベクトルを繰り返し追加します。 
5. マージ中に、エッジ ベクトルを蓄積することによって R の頂点シーケンスを構築します。 各ステップで 1 つのポリゴンのエッジ ポインタを進め、すべての可能な合計 p + q の凸包を常にたどることを保証します。 
6. R が構築されたら、靴紐の公式を使用してその面積を再度計算します。 この領域は、まさに、重複が発生する翻訳セット D の尺度です。 
7. (面積(P)・面積(Q)) / 面積(R)を返します。 

これが機能する理由は、すべての平行移動にわたるオーバーラップの積分が点 (p, q) の微小な各ペアを 1 回だけカウントし、平行移動ベクトル t = p − q の単位に寄与するためです。 一方、分母は「オーバーラップを生成する翻訳の量」を正確に測定します。これはまさにミンコフスキー和領域です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def polygon_area(poly):
    n = len(poly)
    s = 0
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        s += x1 * y2 - x2 * y1
    return abs(s) / 2.0

def subtract(p, q):
    return (p[0] - q[0], p[1] - q[1])

def add(p, q):
    return (p[0] + q[0], p[1] + q[1])

def cross(a, b):
    return a[0] * b[1] - a[1] * b[0]

def build_minkowski(a, b):
    # both a and b are convex CCW
    def edges(poly):
        n = len(poly)
        res = []
        for i in range(n):
            x1, y1 = poly[i]
            x2, y2 = poly[(i + 1) % n]
            res.append((x2 - x1, y2 - y1))
        return res

    ea = edges(a)
    eb = edges(b)

    i = j = 0
    pa = a[0]
    pb = b[0]
    start = add(pa, pb)
    res = [start]

    while i < len(ea) or j < len(eb):
        if i == len(ea):
            e = eb[j]
            j += 1
        elif j == len(eb):
            e = ea[i]
            i += 1
        else:
            if cross(ea[i], eb[j]) >= 0:
                e = ea[i]
                i += 1
            else:
                e = eb[j]
                j += 1
        start = add(start, e)
        res.append(start)

    return res

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        P = [tuple(map(int, input().split())) for _ in range(n)]
        Q = [tuple(map(int, input().split())) for _ in range(m)]

        areaP = polygon_area(P)
        areaQ = polygon_area(Q)

        Q_neg = [(-x, -y) for x, y in Q]
        mink = build_minkowski(P, Q_neg)
        areaD = polygon_area(mink)

        ans = areaP * areaQ / areaD
        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、ポリゴン領域、エッジ抽出、ミンコフスキー和の構築という 3 つの幾何学的プリミティブが分離されます。 最もデリケートな部分はマージのステップです。 これは、外積を使用したエッジ方向の比較に依存しています。これは、極角を明示的に計算せずに比較するのと同じです。 

最初の頂点の選択は、指定された凸順序を使用し、一貫した開始点を仮定することによって暗黙的に処理されます。 累積された点列により、ミンコフスキー和の境界が順番に構築されます。 

## 実用的な例

 両方の多角形が頂点 (0,0)、(1,0)、(0,1) を持つ同一の直角三角形である最小のケースを考えてみましょう。 直観的には、ある三角形を別の三角形の上に移動すると、重なり合いの動作は対称になり、ミンコフスキー和はエッジを追加することによって形成されるより大きな凸多角形になります。 

| ステップ | 面積(P) | エリア(Q) | ミンコフスキー建設 | エリア(D) | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 初期化 | 0.5 | 0.5 | 建物のエッジ | 保留中 | 保留中 |
 | 最終 | 0.5 | 0.5 | 凸六角形 | 凸六角形 計算された | 0.25 / 面積(D) |

 このトレースは、分子が固有のポリゴン領域のみに依存する一方、有効な平行移動のジオメトリはミンコフスキー和によって完全に捕捉されることを示しています。 

ここで、Q が P 内の小さな三角形である、縮退のような形状の違いを考えてみましょう。オーバーラップが大きいことが多いにもかかわらず、オーバーラップが存在する並進空間は依然として純粋にミンコフスキー加算によって定義される凸領域です。 これは、分母が、ポリゴンが特定の位置にどの程度「適切に配置されているか」とは無関係であることを確認します。

 ## 特殊なケース

 重要なエッジ ケースは、ポリゴンが非常に小さな三角形である場合です。 この場合、ミンコフスキー構造は平行エッジに応じて六角形または五角形に縮退し、エッジの順序が正しくないと自己交差する多角形が生成されます。 このアルゴリズムは、エッジを角度順に厳密にマージし、凸性を確保することでこれを回避します。 

もう 1 つのエッジ ケースは、一方のポリゴンが実質的に他方のポリゴンの変換されたコピーである場合に発生します。 その後、ミンコフスキー和は対称で大きくなりますが、分子と分母が一貫してスケールされるため、式は依然として成り立ちます。
