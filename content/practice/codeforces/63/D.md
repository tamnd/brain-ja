 ## 問題の理解

 島を複数の関係者が接続された領域に分割するように求められます。 島は、並べて配置された 2 つの長方形で表されます。1 つは次のサイズです。`a`による`b`そして別のサイズの`c`による`d`。 これらは 1 つのエッジに沿った水平方向の配置を共有していますが、高さは異なる場合があります (`b ≠ d`）。 各当事者は、指定された数の単位正方形からなる接続部分を望んでいます。 課題は、パーティの領域がグリッドのエッジに沿って連続するようにすべての正方形をパーティに割り当てるか、それが不可能かどうかを判断することです。 

入力は長方形のサイズとパーティの数を提供します。`n`、およびエリアのリスト`x_i`各当事者が占めるべきマスの数を表します。 出力は、パーティー地域を示すために小文字を使用した視覚的なマップである必要があります。`.`未割り当てのマス目（海）に使用されます。 すべての領域を重複せずに連続した領域に割り当てることができれば、解決策は存在します。 

制約は小さく、すべての長方形の寸法が 50 以下、パーティの数が 26 以下です。これにより、正方形の総数に比例した演算を処理できるようになります。最悪の場合、`50 * 50 + 50 * 50 = 5000`、一般的な 2 秒の制限を余裕で下回ります。 ただし、難しい部分は計算時間ではなく、特に 2 つの長方形の高さが異なる場合に、連続した領域を正しく生成することです。 単純な行ごとの塗りつぶしは、長方形の位置ずれを注意深く処理しないと失敗する可能性があります。 

一方の長方形が他方の長方形よりも高い場合、明らかではないエッジ ケースが発生します。 たとえば、最初の長方形が 2×3 で、2 番目の長方形が 2×2 の場合、高低差を考慮せずに領域を割り当てようとすると、単純にジグザグに塗りつぶしただけでは隙間や四角形の途切れが生じる可能性があります。 もう 1 つのエッジ ケースは、パーティが両方の長方形で共有される列内にちょうど 1 つの正方形を必要とする場合に発生します。間違った開始点を選択すると、切断された領域が作成される可能性があります。 

## アプローチ

 強引なアプローチは、各パーティに長方形を配置するあらゆる方法を試みることです。 これには、DFS またはバックトラッキングを使用して、それぞれの隣接する配置をすべて調査する必要がある場合があります。`x_i`。 これは正しいですが、計算上実行不可能です。合計約 5000 の正方形と最大 26 のパーティーでは、配置の組み合わせの数は指数関数的に増加します。 

重要な洞察は、問題を組み合わせ検索ではなく、建設的な充填手順に帰着できるということです。 島のグリッドが小さく、面積の合計が正方形の総数と正確に一致するため、一貫した予測可能なパターンで長方形を塗りつぶすことができます。 最も単純な戦略は、各行を個別に処理し、各行を左から右に埋めていき、パーティの割り当てがなくなったら次の行に切り替えることです。 接続性を維持するために、各行の塗りつぶし方向を交互に (スネーク パターン)、新しい行が前の行の最後の正方形から続くようにすることができます。 このアプローチは、エッジに沿った接続を保証し、高さの異なる長方形に対して機能します。 

島全体を同じサイズの単一の長方形グリッドとして扱うことで、長方形の高さの違いを処理します。`max(b, d)`による`(a + c)`そして空いたスペースを`.`海を表現するために。 これにより、アルゴリズムは、短い長方形に対して特別な場合を必要とせずに均一に動作することができます。

 ## アルゴリズムのチュートリアル

 1. 最終的なグリッドの合計の高さを次のように計算します。`H = max(b, d)`そして合計幅は次のようになります`W = a + c`。 サイズの 2D グリッドを初期化します`H × W`でいっぱい`.`。 
2. 各パーティの割り当てを繰り返し文字に拡張して、すべてのパーティ割り当てのフラット リストを作成します。たとえば、最初のパーティが 5 つの正方形を必要とする場合は、5 つ追加します。`'a'`をリストに追加すると、3 つの正方形を持つ 2 番目のパーティが 3 つ追加します。`'b'`など。 これにより、各パーティの合計エリアが 1 回だけ割り当てられることが保証されます。 
3. グリッドの各行を繰り返します。 偶数インデックスの行の場合は、左から右に入力します。 奇数のインデックスが付いている行の場合は、右から左に入力します。 各位置が長方形の 1 つの内側にある場合は、フラット パーティー リストから次のキャラクターを配置します。 それが外側（より高い長方形の拡張グリッド内）にある場合は、そのままにしておきます。`.`。 
4. 次にどの文字を配置するかを追跡するために、フラット パーティ リストへのポインタを維持します。 グリッド全体を通過するまでこのプロセスを続けます。 
5. 記入後、「YES」に続いてグリッドの各行を印刷します。 

ヘビ パターンは、パーティーの各マスが前の列または同じ列の同じパーティーの少なくとも 1 つの他のマスと接触するため、接続性を保証します。 フラット リストの順序で埋めることにより、各当事者が正確に正方形の割り当てを受け取ることが保証されます。

import sys
input = sys.stdin.readline

a, b, c, d, n = map(int, input().split())
x = list(map(int, input().split()))

H = max(b, d)
W = a + c
grid = [['.'] * W for _ in range(H)]

letters = []
for i, count in enumerate(x):
    letters.extend([chr(ord('a') + i)] * count)

idx = 0
for r in range(H):
    if r % 2 == 0:
        rng = range(W)
    else:
        rng = range(W - 1, -1, -1)
    for c_idx in rng:
        # Check if the position is inside the island
        if (c_idx < a and r < b) or (c_idx >= a and r < d):
            grid[r][c_idx] = letters[idx]
            idx += 1

print("YES")
for row in grid:
    print(''.join(row))

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    a, b, c, d, n = map(int, input().split())
    x = list(map(int, input().split()))
    H = max(b, d)
    W = a + c
    grid = [['.'] * W for _ in range(H)]
    letters = []
    for i, count in enumerate(x):
        letters.extend([chr(ord('a') + i)] * count)
    idx = 0
    for r in range(H):
        rng = range(W) if r % 2 == 0 else range(W - 1, -1, -1)
        for c_idx in rng:
            if (c_idx < a and r < b) or (c_idx >= a and r < d):
                grid[r][c_idx] = letters[idx]
                idx += 1
    out = ["YES"]
    out.extend(''.join(row) for row in grid)
    return '\n'.join(out)

# single party
assert run("3 2 2 2 1\n10\n") == "YES\naaaaa\naaaaa", "single party fills all"
