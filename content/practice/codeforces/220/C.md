 ## 問題の理解

 2 つの順列が与えられています`a`そして`b`長さの`n`。 各順列には 1 から 1 までのすべての整数が含まれます。`n`まさに一度。 循環シフトごとに計算するように求められます。`b`、距離と呼ばれる量。 間の距離`a`そして、そのシフトされたバージョン`b`すべての数値について、対応する要素の位置の最大絶対差として定義されます。`x`1から`n`のインデックスを取得します。`x`で`a`とそのシフトされたインデックス`b`、計算する`i - j`、そのシフトの全体の距離は、すべての数値が揃うために必要な最大のシフトになります。 

言い換えれば、次の数を合わせているということです。`a`そして回転した`b`各要素を元の位置に揃える最小限のシフトが必要です。`a`。 すべての人にとってこの距離を効率的に計算することが求められます。`n`の循環回転`b`。 

制約により、`n`100,000まで上がります。 すべてのシフトを直接シミュレートし、要素ごとに距離を計算する総当り的なアプローチでは、最大で`n^2`操作。 と`n`= 10^5 の場合、これは 10^10 回の演算に相当し、2 秒の時間制限をはるかに超えています。 したがって、ほぼ線形、または最悪の場合でも O(n log n) の解が必要です。 

エッジ ケースには、シフトが 1 つだけあるサイズ 1 の最小の順列と、次のような順列が含まれます。`a`そして`b`すでに同一であるか、完全に逆になっています。 単純な実装が循環ラップアラウンドの処理を忘れた場合、負のインデックスを返したり、シフトの計算を誤ったりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。`n`循環シフトの`b`、すべてを繰り返します`n`要素を使用して位置の差を計算します。`a`、次に最大絶対差を取得します。 これは文字通り定義に従っているので正しいですが、その複雑さは O(n^2) であり、大規模な場合は失敗します。`n`。 

最適化の重要な観察点は、各要素が固定位置にあるということです。`a`そして`b`。 各数値のインデックスを事前に計算すると、`a`そして`b`、特定のシフトの距離`s`次のように表現できます`(pos_in_a[x] - (pos_in_b[x] + s) % n + n) % n`。 この式はどれだけ回転する必要があるかを示します`b`となることによって`x`と一致します`a`。 次に、シフトする距離`s`すべての中で最大です`x`これらの必要な回転のうち。 シフトは連続したシーケンスを形成するため、カウント配列を使用して各シフトを優先する要素の数を追跡し、考えられる各回転を考慮しながら更新できます。 これにより、複雑さが O(n) に軽減されます。 

つまり、ブルート フォースは距離を直接計算するため機能しますが、次の場合には失敗します。`n`大きいです。 位置を事前に計算し、回転をカウントの配列に変換できるという観察により、すべての距離を線形時間で計算できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 つの配列を作成します。`pos_a`そして`pos_b`、 どこ`pos_a[x]`数値のインデックスです`x`順列で`a`そして`pos_b[x]`のインデックスです`x`順列で`b`。 これにより、位置の O(1) ルックアップが可能になります。 
2. 配列を初期化する`shift_count`長さの`n`ゼロに。 この配列は、各循環シフトを整列させるために優先される要素の数を追跡します。`a`。 
3. 数字ごとに`x`1から`n`、シフトを計算します`s`それは一致します`x`で`b`の位置で`a`。 数式を使用する`s = (pos_a[x] - pos_b[x] + n) % n`。 インクリメント`shift_count[s]`このステップでは、考えられる各回転後に配置されている数値の数を効果的にカウントします。 
4. 各シフトの答え`i`0からn-1までは`n - shift_count[i]`距離は、要素が移動する必要がある位置の最大数として定義されており、位置がずれている要素の総数に相当するためです。 
5. シフト 0 から n-1 までの順序で距離を出力します。 

機能する理由: 要素ごとに、その位置を一致させるために必要な回転を正確に計算します。`a`。 各シフトで整列している要素の数をカウントすると、位置を繰り返し再計算することなく、すべての要素の最小シフトを計算できます。 モジュロ演算により、循環回転の適切なラップアラウンドが保証され、すべてのエッジ ケースの正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))
b = list(map(int, input().split()))

pos_a = [0] * (n + 1)
pos_b = [0] * (n + 1)

for i in range(n):
    pos_a[a[i]] = i
    pos_b[b[i]] = i

shift_count = [0] * n

for x in range(1, n + 1):
    shift = (pos_a[x] - pos_b[x] + n) % n
    shift_count[shift] += 1

for i in range(n):
    print(n - shift_count[i])
```このソリューションでは、まず高速検索のために位置をマッピングし、次に回転ごとに整列する数値の数をカウントします。 モジュロ演算を使用すると、周期的な性質が正しく処理されます。`shift_count`はアライメントを効率的に追跡するため、O(n^2) の計算は必要ありません。
