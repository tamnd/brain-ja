 ## 解決策
 ## 問題の理解

 すべての格子点が長方形の中にあります$$0 \le x \le w,\qquad 0 \le y \le h.$$有効な答えは、面積が正の整数である非縮退三角形を形成する、**順序付けられた** 点のトリプルです。 順序が重要であるため、すべての幾何学的三角形は次のようになります。$3! = 6$異なるトリプル。 

長方形の中に含まれるのは、$$N=(w+1)(h+1)$$ポイント。 と$w,h \le 4000$、グリッドには 1,600 万を超えるポイントを含めることができます。 すべてのポイントを反復するアルゴリズムは不可能であり、ましてやすべてのトリプルを反復することは不可能です。 

重要な問題は、この状態が単に「非退化」ではないことです。 面積も整数でなければなりません。 格子点の場合、面積の 2 倍は常に整数となるため、2 倍の面積がいつ偶数になるかを理解する必要があります。 

よくある間違いは、面積が偶数 2 倍の三角形をすべて数えて、同一線上にある三角形を削除するのを忘れることです。 たとえば:

 入力```
2 1
```3つのポイント$(0,0)$、$(1,0)$、$(2,0)$面積が2倍になった$0$、これは偶数ですが、三角形を形成しないため、数えてはなりません。 

もう 1 つの簡単な間違いは、順序付けされていないトリプルを数えることです。 この声明では、注文が異なれば答えも異なると明確に述べられています。 すべての有効な幾何学的三角形は 6 つの順序付きトリプルに寄与します。 

## アプローチ

 ブルートフォースのアイデアは単純です。 順序付けられた点のトリプルをすべて列挙し、計算します$$|(x_2-x_1)(y_3-y_1)-(x_3-x_1)(y_2-y_1)|$$そして、それがゼロ以外で 2 で割り切れるかどうかを確認します。 

これは正しいですが、まったく実行不可能です。 グリッドには以上のものが含まれる可能性があります$16$100 万ポイントなので、トリプルの数は次のとおりです。$10^{21}$。 

画期的な進歩は、2 つの要件を分離することから生まれます。 

整数領域の条件は、2 倍の領域のパリティのみに依存します。 モジュロ$2$の場合、行列式は座標のパリティ クラスにのみ依存します。 パリティ クラスは 4 つだけです。$$(0,0),\ (0,1),\ (1,0),\ (1,1).$$パリティ クラスが判明すると、2 倍になった領域のパリティが決定されます。 

2 倍の面積が偶数である順序付けられたトリプルをすべて数えた後、面積が実際に 0 であるトリプルを減算します。 これらはまさに共線トリプルです。 

同一線上にあるトリプルを数えるのは幾何学的に見えますが、格子幾何学を使用するときれいな式が得られます。 2 つの格子点が異なる場合$(dx,dy)$、セグメントには以下が含まれます$$\gcd(dx,dy)+1$$格子点。 端点間のすべての内部格子点は、それらの端点と同一線上にある 1 つのトリプルを作成します。 これにより、ジオメトリが以下を含む合計に変換されます。$\gcd$、オイラーのトーティエント関数を使用して効率的に評価できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルートフォース |$O(N^3)$|$O(1)$| 遅すぎる |
 | 最適 |$O(\min(w,h)\log\log(\min(w,h)))$|$O(\min(w,h))$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### 整数の 2 倍の領域を持つ順序付きトリプルのカウント

 1. 4 つのパリティ クラスのサイズを計算します。 
2. しましょう$$N=(w+1)(h+1).$$個別の点の順序付けされたトリプルの数は次のとおりです。$$N(N-1)(N-2).$$1. 行列式は奇数モジュロです$2$3 つのポイントが 3 つの異なるパリティ クラスに属している場合に限ります。 
2. 3 つの異なるパリティ クラスを選択するたびに、次を追加します。$$6 \cdot c_i c_j c_k$$奇数の行列式の数を数えます。 

1. 合計カウントから奇数カウントを引きます。 結果は、2 倍の面積が偶数である、順序付けられた個別のトリプルの数になります。 

### 共線的順序トリプルのカウント

 1. エンドポイントの差が次のセグメントであると考えます。$(dx,dy)$。 
2. そのセグメント上の格子点の数は次のとおりです。$$\gcd(dx,dy)+1.$$1. 内部格子点の数は$$\gcd(dx,dy)-1.$$各内部点と 2 つの端点は、1 つの順序のない共線トリプルを形成します。 

1. このようなセグメントの配置数は$$(w-dx+1)(h-dy+1).$$1. 両方の場合$dx$そして$dy$両方の傾きが正である$+\frac{dy}{dx}$そして$-\frac{dy}{dx}$存在するので、乗算します$2$。 
2. すべての寄与を合計して、順序付けされていない共線トリプルの数を取得します。 
3. 乗算$6$なぜなら、答えには順序付けられたトリプルが必要だからです。 

### gcd sum の高速化

 のために$dx>0$そして$dy>0$、必要です$$\sum (w-dx+1)(h-dy+1)(\gcd(dx,dy)-1).$$使用する$$\gcd(a,b)-1=\sum_{\substack{d\mid \gcd(a,b)\\ d>1}}\varphi(d),$$私たちは得ます$$\sum_{d\ge2}\varphi(d)\,S_x(d)\,S_y(d),$$どこ$$S_x(d)=\sum_{k=1}^{\lfloor w/d\rfloor}(w-dk+1),$$

$$S_y(d)=\sum_{k=1}^{\lfloor h/d\rfloor}(h-dk+1).$$どちらの合計も閉じた形式になります。$$S_x(d)=m(w+1)-d\frac{m(m+1)}2, \quad m=\left\lfloor\frac wd\right\rfloor.$$同じ公式が機能します$S_y$。 

### なぜ効果があるのか

 パリティ引数は、2 倍の面積が偶数である順序付けされたトリプルを正確にカウントします。 すべての有効な整数面積三角形はそのセットに属します。 

そこでカウントされる有効でないトリプルは、同一線上にあるものだけです。 同一線上のトリプルにはエリア 0 があるため、エリア 0 が 2 倍になるため、常にパリティ カウントに含まれます。 

格子点の公式$\gcd(dx,dy)+1$セグメント上のすべての格子点をカウントします。 2 つの極点と 1 つの内点を選択すると、一意の共線トリプルが得られるため、縮退したトリプルはすべて 1 回だけカウントされてから乗算されます。$6$注文用に。 

したがって、最終的な答えは、$$\text{even-area triples} - \text{collinear triples}.$$## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    w, h = map(int, input().split())

    n = (w + 1) * (h + 1)

    ex = w // 2 + 1
    ox = (w + 1) - ex

    ey = h // 2 + 1
    oy = (h + 1) - ey

    c = [
        ex * ey,
        ex * oy,
        ox * ey,
        ox * oy,
    ]

    total = n * (n - 1) * (n - 2)

    odd = 0
    for i in range(4):
        for j in range(i + 1, 4):
            for k in range(j + 1, 4):
                odd += 6 * c[i] * c[j] * c[k]

    even_area = total - odd

    m = min(w, h)

    phi = list(range(m + 1))
    for i in range(2, m + 1):
        if phi[i] == i:
            for j in range(i, m + 1, i):
                phi[j] -= phi[j] // i

    unordered_collinear = 0

    for dx in range(1, w + 1):
        unordered_collinear += (dx - 1) * (w - dx + 1) * (h + 1)

    for dy in range(1, h + 1):
        unordered_collinear += (dy - 1) * (h - dy + 1) * (w + 1)

    diag = 0
    for d in range(2, m + 1):
        mx = w // d
        my = h // d

        sx = mx * (w + 1) - d * mx * (mx + 1) // 2
        sy = my * (h + 1) - d * my * (my + 1) // 2

        diag += phi[d] * sx * sy

    unordered_collinear += 2 * diag

    ordered_collinear = 6 * unordered_collinear

    ans = (even_area - ordered_collinear) % MOD
    print(ans)

solve()
```最初のブロックは 4 つのパリティ クラス サイズを計算し、それらを使用して、2 倍の面積が偶数である順序付けされたトリプルをすべてカウントします。 

2 番目のブロックは、オイラーの合計値を最大で計算します。$\min(w,h)$。 これらの値は、次の除数展開に表示されます。$\gcd(a,b)-1$。 

座標の 1 つがゼロであるため、軸に揃えられた寄与は個別に処理されます。 水平セグメントの場合、$\gcd(dx,0)=dx$。 垂直セグメントは対称です。 

対角線の寄与は全体同一性を使用します。 閉じられたフォーム$S_x(d)$そして$S_y(d)$座標上でネストされたループを避けてください。 

すべての算術演算は Python 整数を使用して実行され、これよりもはるかに大きな値を安全に処理します。$64$-ビット制限。

 ## 特殊なケース

 次のことを考慮してください。```
1 1
```グリッドには 4 つの点だけが含まれています。 すべての三角形には面積があります$1/2$、決して整数ではありません。 パリティをカウントするステップでは、すべての非縮退三角形の面積が奇数の 2 倍であることが正確に検出されるため、答えはゼロになります。 

考慮する：```
2 1
```各水平行の点は、同一直線上にあるトリプルを形成します。 面積が2倍になるため、パリティ数にはそれらも含まれます。$=0$は均等です。 共線減算では、これら 12 個の順序付きトリプルが正確に削除され、正解 36 が生成されます。 

次のことを考慮してください。```
1 2
```縮退していない三角形もあるが、誰もが面積を持っている$1/2$。 パリティ クラスの計算では、2 倍になった領域が奇数であることが検出されるため、最初は何もカウントされません。 共線補正は無関係で、最終的な答えはゼロのままです。 

「偶数 2 倍領域」と「同一直線上」への分離は、これらすべてのケースを均一に処理します。
