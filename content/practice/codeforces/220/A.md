 ## 解決策
 ## 問題の理解

 元々は非降順でソートされた配列が与えられています。 ある時点で、何も起こらないか、要素の 1 つのペアだけが交換された可能性があります。 

問題は、任意の 2 つの位置の最大 1 つの交換を使用して、現在の配列を完全にソートされた配列に変換できるかどうかです。 答えが「はい」の場合、印刷します`"YES"`。 それ以外の場合は印刷します`"NO"`。 

配列の長さは次のように大きくできます。$10^5$。 あらゆる可能なスワップを試行するアルゴリズムでは、おおよそ次のものが必要になります。$n^2$試み。 と$n = 10^5$、つまり約$10^{10}$2秒の制限時間内ではまったく実現不可能です。 に近いものが必要です$O(n \log n)$または$O(n)$。 

この問題の微妙な側面は、値が必ずしも明確ではないことです。 重複があると、一部の直感的なアプローチが失敗します。 

考慮する：```
4
1 3 2 2
```ソートされた配列は次のとおりです。```
1 2 2 3
```現在の配列は、ソートされた配列とは位置 2 と位置 4 のみが異なるため、1 回の交換で修正されます。 正しい答えは次のとおりです。```
YES
```逆変換だけを探す不用意な解決策は、さらなる作業が必要であるという誤った結論を下す可能性があります。 

もう 1 つの重要なケースは、配列がすでにソートされている場合です。```
5
1 2 2 3 4
```答えはまだ次のとおりです。```
YES
```ゼロスワップが許可されているためです。 要件は「最大 1 つのスワップ」であり、「厳密に 1 つのスワップ」ではありません。 

3 番目のエッジ ケースは、3 つ以上の位置が並べ替え順序と一致しない場合に発生します。```
4
4 3 2 1
```ソートされたバージョンは次のとおりです。```
1 2 3 4
```4 つのポジションはすべて異なります。 単一のスワップですべてを解決できるわけではないため、答えは次のようになります。```
NO
```逆変換の数が少ないかどうかだけをチェックするソリューションは、ここでは失敗します。 

## アプローチ

 簡単な総当り的な方法は、スワップを実行しない可能性も含め、可能なすべてのスワップを試行することです。 選択ごとに、結果の配列がソートされているかどうかを確認します。 

がある$O(n^2)$交換の可能性。 配列がソートされているかどうかを確認するには$O(n)$時間。 全体の複雑さは次のようになります。$O(n^3)$。 

のために$n = 10^5$、これは絶望的に遅いです。 平$O(n^2)$すでに大きすぎるでしょう。 

重要な観察は、現在の配列と完全にソートされたバージョンを比較することで得られます。 

配列のソートされたコピーを作成するとします。 現在の配列とソートされた配列がすでに一致している位置は変更する必要はありません。 1 回のスワップは 2 つのポジションにのみ影響します。 したがって、ソートされた配列と 3 つ以上の位置が異なる場合、1 回の交換では配列を同一にすることはできません。 

これにより、問題は非常に単純なチェックに変わります。 

配列のソートされたバージョンを構築します。 元の配列とソートされた配列に異なる値が含まれるインデックスがいくつあるかを数えます。 

不一致の位置の数が次の場合:

 - 0、配列はすでにソートされています。 
- 2、これら 2 つの位置を交換すると、配列が修正されます。 
- 2 つ以上、1 つのスワップが不足します。 

すべてのスワップはちょうど 2 つの位置を変更するため、答えは次のようになります。`"YES"`正確には、不一致数が最大 2 の場合です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(n^3)$|$O(1)$| 遅すぎる |
 | 最適 |$O(n \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取ります。 
2. 並べ替えられた配列のコピーを作成します。 

ソートされたコピーは、到達したいターゲット構成を表します。 
3. 元の配列とソートされた配列を位置ごとに比較します。 

異なる値を含むインデックスがいくつあるかを数えます。 
4. 不一致の数が最大 2 の場合、出力します。`"YES"`。 

1 回のスワップはちょうど 2 つのポジションに影響します。 不一致がゼロの場合は、配列がすでにソートされていることを意味しますが、2 つの不一致は、スワップに関係する 2 つの位置に対応します。 
5. それ以外の場合は、印刷します`"NO"`。 

### なぜ効果があるのか

 ソートされたコピーを次のようにします$b$。 

元の配列を最大 1 つのスワップを使用してソートできる場合は、スワップされた 2 つの位置を除くすべての位置がすでに一致している必要があります。$b$。 したがって、元の配列との間の不一致の数は、$b$2を超えることはできません。 

逆に、不一致の位置が 2 つだけ存在する場合、それらの位置の値を交換すると、両方の位置がソートされた配列に同時に一致します。 不一致がゼロの場合、配列はすでにソートされています。 

したがって、配列は、不一致数が最大 2 である場合にのみ、最大 1 回のスワップでソート可能です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    b = sorted(a)

    mismatches = 0
    for x, y in zip(a, b):
        if x != y:
            mismatches += 1

    print("YES" if mismatches <= 2 else "NO")

if __name__ == "__main__":
    solve()
```実装はアルゴリズムに直接に従います。 

ソートされたコピー`b`が目標の配置です。 次に、両方の配列を同時にスキャンし、値が異なる位置をカウントします。 

重要な観察は、反転ではなく不一致の位置をカウントしていることです。 重複があると反転ベースの推論の信頼性が低くなる可能性がありますが、ソートされた配列との比較により、どの位置が間違っているかが正確に把握されます。 

すでにソートされた配列には特別な処理は必要ありません。 この場合、不一致数はゼロであり、条件は`mismatches <= 2`自然に戻る`"YES"`。 

Python の整数は、次の値まで簡単に処理できます。$10^9$なので、オーバーフローの心配はありません。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
