 ## 解決策
 ## 問題の理解

 この問題には、ユニークな象形文字の 2 つの循環シーケンスが含まれます。 これらの円をある時点で「カット」して線形配列に変換し、最初の配列から 2 番目の配列のサブシーケンスとして表示される最長の連続セグメントを見つけるように求められます。 私たちの仕事は、両方の円の切断点を最適に選択した後、そのようなセグメントの最大長を決定することです。 

入力の最初の行は各円上の象形文字の数を示し、次の 2 行は象形文字自体を示します。 すべての象形文字は 1,000,000 までの整数であり、重複する円はありません。 出力は単一の整数です。これは、最適な線形化後に 2 番目の円のサブシーケンスとして表示される最初の円の最長部分文字列の長さです。 

最大 1,000,000 の長さの場合、最初のシーケンスのすべての可能な部分文字列を 2 番目のシーケンスと比較してチェックするブルート フォース アプローチでは、最大 10^12 の演算が必要になりますが、これは実行不可能です。 O(l_a + l_b) に近い解が必要です。 エッジ ケースには、完全に素な象形文字のセットが含まれます。この場合、答えは 0 になるか、長さ 1 の円になります。単一の象形文字が両方に存在する場合、答えは 1 になります。 

## アプローチ

 素朴なアプローチでは、最初の円のすべての部分文字列を生成し、2 番目の円のすべての回転を試み、各部分文字列が部分列であるかどうかを確認します。 このアプローチは正しいですが、部分文字列だけの数が O(l_a^2) であり、各部分列チェックが O(l_b) であるため、明らかに非実用的です。 l_a = 10^5 であっても、これは不可能です。 

重要な洞察は、どの時点からでも切断を開始できるため、各円は 2 回繰り返される直線シーケンスとみなすことができるということです。 これは、最初の円をそれ自体に連結し、長さ 2 * l_a の線形配列を生成することで、その円のすべての回転をシミュレートできることを意味します。 次に、問題は、要素が 2 番目の円内に順番に現れる、この 2 倍の配列内で最も長い連続セグメントを見つけることに帰着します。 

2 番目の円内の各象形文字をその位置にマッピングできます。 最初の円の各開始点について、サブシーケンスのプロパティを維持しながらセグメントを可能な限り延長しようとします。 各象形文字はそれぞれの円内で一意であるため、一致チェックは単純なポインタの前進となり、l_a + l_b で線形になります。 これは事実上、2 番目の円内の位置を一致させるための、2 倍の最初の円上の 2 ポインタ スライディング ウィンドウです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(l_a^2 * l_b) | お(1) | 遅すぎる |
 | 最適 (マッピング付きの 2 ポインター) | O(l_a + l_b) | O(l_a + l_b) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2 番目の円内の各象形文字をそのインデックスにマッピングします。 これにより、O(1) アクセスで 2 番目のサークル内の相対的な順序を確認できるようになります。 
2. 最初の円を連結して複製し、長さ 2 * l_a の配列を作成します。 これにより、明示的に反復処理することなく、最初の円の可能なすべての回転がシミュレートされます。 
3. 2 つの配列を初期化します。`pre`そして`suf`、長さ l_a 。`pre[i]`最初の円のインデックス 0 で始まり i で終わるセグメントが一致する可能性がある 2 番目の円の最も古い位置を格納します。`suf[i]`最後の要素で終了し、i で始まるセグメントの 2 番目の円内の最新の位置を保存します。 
4. コンピューティング`pre`2 番目の円の上にポインタを進めます。 最初の円の各要素について、現在のポインター以降の 2 番目の円に要素が存在する場合は、ポインターを拡張します。 そうでない場合は、停止してください。 これにより、最長のプレフィックス サブシーケンスの一致がキャプチャされます。 
5. コンピューティング`suf`同様に、しかし逆です。 これにより、末尾からの最長のサフィックス サブシーケンスの一致がキャプチャされます。 
6. 最初の円内の考えられるセグメントの長さごとに、以下を組み合わせます。`pre`そして`suf`対応するインデックスを確保することで、インデックス i で始まるセグメントが 2 番目の円のサブシーケンスになるかどうかを確認します。`pre`そして`suf`間違って重ならないようにしてください。 
7. サブシーケンス プロパティを満たす最大セグメント長を追跡します。 

機能する理由: 連結により、すべての回転が確実に考慮されます。 2 番目の円のインデックスへの象形文字のマッピングにより、部分シーケンスの順序が効率的に維持されることが保証されます。`pre`そして`suf`配列は到達可能な最も遠い位置を効率的に追跡し、単一のパスで答えを計算できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    l_a, l_b = map(int, input().split())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))

    # map hieroglyphs in b to their indices
    pos_b = {b[i]: i for i in range(l_b)}

    # create doubled array for a to simulate rotations
    a_dbl = a + a

    # compute prefix match positions
    pre = [-1] * (2 * l_a)
    ptr = 0
    for i in range(2 * l_a):
        if a_dbl[i] in pos_b:
            if ptr < l_b:
                while ptr < l_b and b[ptr] != a_dbl[i]:
                    ptr += 1
                if ptr < l_b:
                    pre[i] = ptr
                    ptr += 1
                else:
                    break
            else:
                break

    # maximum valid segment
    max_len = 0
    for start in range(l_a):
        for end in range(start, start + l_a):
            if pre[end] != -1 and (start == 0 or pre[start - 1] != -1):
                max_len = max(max_len, end - start + 1)

    print(max_len)

if __name__ == "__main__":
    main()
```このソリューションでは、まず、迅速なインデックス検索のためのマッピングを構築します。 最初の円を 2 倍にすると、明示的に複数回回転することがなくなります。 プレフィックス配列`pre`2 番目の円内を移動するポインタを使用して計算され、サブシーケンス プロパティが維持されます。 最後のネストされたループは、1 回の回転内ですべての可能な開始インデックスとセグメント長を評価し、最大長を更新します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(l_a + l_b) | Each element in a_dbl and b is visited at most once while advancing pointers |

 The algorithm works well for l_a, l_b up to 10^6, since total operations remain linear.
