 ## 解決策
 ## 問題の理解

 飛行機には最大 1000 ポイントが与えられており、正確に削除する必要があります。`k`彼らのうち。 これらの点を削除した後、残りのセットの直径は可能な限り小さくなるはずです。 

セットの直径は、残りの 2 つの点の間の最大ユークリッド距離です。 距離は相互に相対的にのみ重要であるため、完全に距離の 2 乗を使用して作業し、浮動小数点の精度の問題を回避できます。 

入力は幾何学的な点の集合であり、偽装されたグラフや配列の問題ではありません。 サイズのサブセットを選択しています`n-k`最も遠いペアが可能な限り近いもの。 

制約によってソリューションが完全に形作られます。 サイズのすべてのサブセットに対する総当たり攻撃`n-k`不可能です。 たとえ`n = 1000`そして`k = 30`、サブセットの数は天文学的に多くなります。 私たちはこの事実を利用する必要があります。`k`小さいです。 

の小さな値`k`最適解は、完全なセットとは、削除された点がわずか数点だけ異なることを示唆しています。 これは多くの場合、分岐検索または限定検索手法につながります。 

重要な観察は、現在のセットの直径が 2 つの点によって決定される場合、`u`そして`v`の場合、直径が小さい有効なソリューションは、次の少なくとも 1 つを削除する必要があります。`u`または`v`。 そうしないと両方が残り、直径は減少できません。 

これにより、分岐係数 2 と最大深さの再帰的分岐プロセスが得られます。`k`。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

多くの点が一致するとします。 

入力：```
4 1
0 0
0 0
0 0
100 100
```正解は点 4 を削除することです。削除すると直径がゼロになります。 浮動小数点比較を使用する不注意な実装では、精度ノイズのせいで一致点が誤って別個のものとして扱われる可能性があります。 

もう 1 つの微妙なケースは、複数のペアが同じ最大距離を共有する場合です。 

入力：```
5 1
0 0
10 0
0 10
10 10
5 5
```直径はいくつかのペアによって達成されます。 1 つのペアからポイントを削除しても、別の直径ペアが残っている場合、直径は自動的に減少しません。 直径が小さいすべての解はすべての最大距離ペアにヒットする必要があり、そのようなペアの 1 つで再帰的に分岐すると、最終的には十分な削除が強制されるため、再帰的議論は依然として機能します。 

最後のエッジ ケースは、最適な残りのセットにポイントが 1 つしかない場合です。 

入力：```
2 1
0 0
1000 1000
```残りの 1 つの点は直径がゼロになります。 実装では、ペアが存在しないサイズ 1 のセットを正しく処理する必要があります。 

## アプローチ

 ブルートフォースのアイデアは単純です。 サイズのすべてのサブセットを列挙します`n-k`、その直径を計算し、最適なものを保持します。 

1 つのサブセットの直径を計算するには、その中のすべてのペアをチェックする必要があり、コストがかかります`O(n^2)`。 サブセットの数は次のとおりです。$$\binom{1000}{970}$$それは完全に不可能です。 

ブルート フォースは、残りのすべての可能なセットを明示的にチェックするため正しいですが、検索スペースが膨大であるため、すぐに失敗します。 

重要な観察は、組み合わせによるものではなく、構造的なものです。 

現在のアクティブなポイントのセットを取得します。 させて`(u,v)`現在の直径を達成するペアになります。 最終的な直径を厳密に小さくしたい場合は、次の少なくとも 1 つを使用します。`u`または`v`削除する必要があります。 

これにより、分岐プロセスが作成されます。 

現在の直径がすでに目標値以下の場合`D`、終わりました。 

それ以外の場合は、違反ペアが 1 つ見つかります`(u,v)`距離を超える人`D`。 有効な解決策はいずれかを削除する必要があります。`u`または`v`。 そこで、両方の可能性を再帰的に試します。 

各再帰ステップで 1 つの点が削除されるため、再帰の深さは最大で`k`。 検索ツリーには最大でも`2^k`葉。 と`k ≤ 30`、これは大きいですが、それでも積極的な剪定で管理できます。 

現在も、固定の実現可能性だけではなく、最適な直径が必要です。`D`。 

ポイント間の距離は、実際のポイントのペアから得られます。 あるのは`O(n^2)`明確な二乗距離。 これらの候補値を二分探索できます。 

固定直径境界の場合`D`、私たちは尋ねます：

 せいぜい削除してもいいでしょうか`k`残りのすべてのペアが最大でも距離を持つようにポイントします。`D`?

 これは、グラフ上の有界分岐問題になります。 

頂点は点です。 

エッジはより遠いペアを接続します`D`。 

せいぜい削除する必要があります`k`エッジが残らないように頂点を調整します。 それはまさに頂点カバー問題です。 

一般に頂点カバーは NP ハードですが、ここではパラメータ`k`小さいです。 標準の分岐アルゴリズムは完全に機能します。 

再帰的なルールは次のとおりです。 

任意のエッジを選択します`(u,v)`。 有効な頂点カバーには次のものが含まれている必要があります。`u`または`v`。 両方の選択肢を再帰的に実行します。 

これにより、大まかに複雑さが得られます`O(2^k * n^2)`実現可能性チェックごとに。 

しかないので、`O(n^2)`候補距離の場合、二分探索では別の対数係数が追加されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的`n`|`O(n)`| 遅すぎる |
 | 最適 |`O(2^k * n^2 * log n)`|`O(n^2)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を読み取り、すべての点のペア間の二乗距離を事前計算します。 

二乗距離を使用すると、浮動小数点演算が回避され、すべての比較が正しく保存されます。 
2. すべての個別の二乗距離をソートされた配列に収集します。 

直径は常に残りの点のペアによって決定されるため、最適な直径はこれらの値のいずれかに等しくなければなりません。 
3. ソートされた候補距離に対する二分探索。 

候補者ごとに`D`、最大でも削除できるかどうかを確認します`k`残りのすべてのペアが最大でも 2 乗距離になるようにポイントします。`D`。 
4. 現在の暗黙的な競合グラフを構築します。`D`。 

2 つの点の二乗距離を超えると接続されます。`D`。 有効な残りのセットは、そのようなエッジの両方のエンドポイントを保持することはできません。 
5. 再帰的な有界頂点カバー検索を実行します。 

競合エッジが残っていない場合、現在の削除はすでに直径制約を満たしています。 

それ以外の場合は、任意の競合エッジを選択します`(u,v)`。 
6. 2 つの可能性に分岐します。 

最初のブランチで、削除します`u`。 

2 番目のブランチで、削除します`v`。 

有効なソリューションでは、残りのすべての競合エッジの少なくとも 1 つのエンドポイントを選択する必要があります。 
7. 次の値を超える場合は再帰を停止します。`k`削除が使用されます。 

その分岐では有効な解決策を生成できません。 
8. 実行可能性チェックが成功した場合、二分探索は左から小さい直径に向かって移動します。 

それ以外の場合は右に移動します。 
9. 実現可能な最小直径を見つけたら、正確な直径のセットを出力します。`k`削除されたポイント。 

再帰的検索では、最大で 1 つのサイズの有効な削除セットが得られます。`k`。 未満の場合`k`ポイントが必要な場合は、追加のポイントを削除しても直径が増加することはないため、削除されていない追加のポイントを任意に追加できます。 

### なぜ効果があるのか

 固定直径境界の場合`D`、より遠いすべてのペア`D`同時に残ることはできません。 このようなペアをグラフのエッジとして表すと、問題は最大で次のサイズの頂点カバーを見つけることに変換されます。`k`。 

すべてのエッジには少なくとも 1 つのエンドポイントが削除されている必要があるため、再帰的分岐は正しいです。 アルゴリズムが分岐するとき`(u,v)`、すべての有効なソリューションは 2 つのブランチのいずれかに属します。 

実現可能性は単調であるため、二分探索は正しいです。 ある程度の直径であれば`D`が達成可能であれば、さらに大きな直径も達成可能です。 

最適な直径はペアごとの距離のいずれかに等しくなければならないため、これらの値の中から検索することで、正確な最適な直径が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(1 << 25)

def solve():
    n, k = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    dist = [[0] * n for _ in range(n)]
    vals = set()

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            d = (x1 - x2) ** 2 + (y1 - y2) ** 2
            dist[i][j] = dist[j][i] = d
            vals.add(d)

    vals = sorted(vals)
    if not vals:
        vals = [0]

    answer = None

    def feasible(limit):
        deleted = [False] * n
        chosen = []

        def dfs(rem):
            edge = None

            for i in range(n):
                if deleted[i]:
                    continue
                for j in range(i + 1, n):
                    if deleted[j]:
                        continue
                    if dist[i][j] > limit:
                        edge = (i, j)
                        break
                if edge:
                    break

            if edge is None:
                return True

            if rem == 0:
                return False

            u, v = edge

            deleted[u] = True
            chosen.append(u)

            if dfs(rem - 1):
                return True

            chosen.pop()
            deleted[u] = False

            deleted[v] = True
            chosen.append(v)

            if dfs(rem - 1):
                return True

            chosen.pop()
            deleted[v] = False

            return False

        ok = dfs(k)

        if ok:
            return chosen[:]
        return None

    left = 0
    right = len(vals) - 1
    best = vals[-1]

    while left <= right:
        mid = (left + right) // 2
        cand = vals[mid]

        res = feasible(cand)

        if res is not None:
            best = cand
            answer = res
            right = mid - 1
        else:
            left = mid + 1

    deleted = set(answer)

    while len(deleted) < k:
        for i in range(n):
            if i not in deleted:
                deleted.add(i)
                break

    print(*[x + 1 for x in deleted])

if __name__ == "__main__":
    solve()
```最初のセクションでは、すべてのペアごとの二乗距離を計算します。 浮動小数点平方根は不必要な精度の問題を引き起こすだけで何のメリットもないため、二乗距離を使用することが不可欠です。 

二分検索は、任意の数値ではなく、並べ替えられた個別の距離に基づいて動作します。 最適な直径は正確なペアごとの距離の 1 つでなければならないため、これは重要です。 

再帰的実現可能性チェックは、有界頂点カバーを実装します。 検索では常に 1 つの競合エッジが選択され、そのエンドポイントで分岐します。 

実装の微妙な詳細は、再帰によって共有配列が変更されることです。 すべての再帰的ブランチは、戻る前に変更を元に戻す必要があります。 復元を忘れる`deleted[u]`または`chosen`枝間の汚染を引き起こし、不正確な答えを生成します。 

もう 1 つの重要な詳細は、有効な分岐が成功すると再帰がすぐに戻ることです。 この枝刈りがなければ、検索ツリーは劇的に大きくなってしまいます。 

最終的な出力には、以下の内容が含まれる可能性があります。`k`再帰的なプロセスからポイントを削除しました。 実現可能性チェックで要求されるのは最大でも次のとおりであるため、これは有効です。`k`削除。 正確に完了するまで、削除セットを任意に延長します。`k`ポイント。
