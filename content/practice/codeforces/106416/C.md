 ## 問題の理解

 私たちは平面上に一連の円形の灌漑源を与えられています。 各水源には固定位置と固定散水半径があり、その円内または円上のすべてを完全にカバーします。 カミラは飛行機内の任意の場所に別の円を配置したいと考えています。 この新しい円の唯一の要件は、境界上のすべての点が少なくとも 1 つの灌漑円内に存在する必要があることです。 カミラの円の内側はまったく問題なく、周囲だけが完全に覆われていなければなりません。 

タスクは、この新しい円の半径を最大化することです。 

したがって、幾何学的には、その境界が指定された円盤の結合によって完全に覆われるような、可能な限り最大の円を検索します。 私たちが構築する円はどこにでも自由に配置でき、その半径は整数に制限されません。 必要なのは、高精度の実数値の最大半径だけです。 

制約は小さく、スプリンクラーは最大 40 個です。 これは、ペアまたはトリプル相互作用を含む解決策が受け入れられ、サブセットに対する三次推論さえも合格する可能性があることを直ちに示唆します。 任意の配置に対する継続的な最適化を伴うものはすべて、候補構成の有限セットに減らす必要があります。 

中心と半径は両方とも実数値であり、カバレッジ条件は無限に多くの境界点に依存するため、単純な連続検索は失敗します。 すべての円をチェックする直接的な幾何学的シミュレーションは実現できません。 

最適な円がスプリンクラーまたは交差点の中心にない場合、微妙なエッジ ケースが発生します。 多くの幾何学的問題では、境界相互作用で極端な構成が発生するという事実が隠されていますが、ここでは、円が円盤の結合に対してどのように「緊密」になるのかを明確に推論する必要があります。

 ## アルゴリズムのチュートリアル

 この問題を半径に関する決定問題に変換し、最適な有効値を検索することで問題を解決します。 

1. 関数を定義します`can(R)`半径の円が存在するかどうかを確認します$R$その境界は少なくとも 1 つのスプリンクラー ディスクで完全に覆われています。 これにより、最適化問題が単調な実現可能性問題に変換されます。 
2. 二分探索を行います$R$。 半径の場合$R$円を縮小すると範囲が容易になるだけなので、さらに小さな半径も実現可能です。 この単調性により、二分探索が正当化されます。 
3.固定の場合$R$、候補センターを生成します。 重要なアイデアは、最適な半径円が$R$が存在する場合、その中心は少なくとも 1 つまたは 2 つのスプリンクラーによって拘束される必要があります。これは、スプリンクラーの位置から導出される円の交点にあることを意味します。 幾何学的な構築を使用して、スプリンクラーのペアからそのような候補中心を列挙します。 
4. 候補中心ごとに、角度範囲間隔を計算します。 各スプリンクラーについて、そのスプリンクラーが境界点をカバーする円上の角度範囲を計算します。 これは、中心からスプリンクラーまでの距離と円の交差のジオメトリを使用して行われます。 
5. すべての角度間隔を次のように正規化します。$[0, 2\pi]$、必要に応じてラップアラウンド間隔を分割し、並べ替えます。 
6. これらの間隔が円を完全にカバーしているかどうかを確認します。 これは、ソートされた間隔をスイープするときに、カバーされていないギャップがないことを確認することと同じです。 
7. 候補中心が半径に対して機能するかどうか$R$、マークします$R$可能な限り。 
8. 必要な精度に達するまで二分探索が続けられます。 

### なぜ効果があるのか

 正確さは、最適解の境界が少なくとも 1 つのスプリンクラーによってしっかりとサポートされている必要があるという事実に依存します。 これにより、候補中心の有限の組み合わせ構造が作成されます。 中心が固定されると、カバレッジは角度に関する 1 次元の区間和集合問題に縮小されます。 実現可能性は半径において単調であるため、二分探索は最大有効半径への収束を保証します。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

EPS = 1e-7

def dist(a, b):
    return math.hypot(a[0] - b[0], a[1] - b[1])

def get_intervals(cx, cy, R, spr):
    intervals = []
    for x, y, r in spr:
        dx = x - cx
        dy = y - cy
        d = math.hypot(dx, dy)

        if d > R + r:
            continue

        if d + R <= r:
            return [(0.0, 2 * math.pi)]

        ang = math.atan2(dy, dx)
        cosv = (d*d + R*R - r*r) / (2*d*R)
        cosv = max(-1.0, min(1.0, cosv))
        delta = math.acos(cosv)

        l = ang - delta
        rgt = ang + delta

        if l < 0:
            l += 2 * math.pi
        if rgt < 0:
            rgt += 2 * math.pi
        if l > 2 * math.pi:
            l -= 2 * math.pi
        if rgt > 2 * math.pi:
            rgt -= 2 * math.pi

        if l > rgt:
            intervals.append((l, 2 * math.pi))
            intervals.append((0.0, rgt))
        else:
            intervals.append((l, rgt))

    intervals.sort()
    cover = 0.0
    for l, r in intervals:
        if l > cover + EPS:
            return False
        cover = max(cover, r)

    return cover >= 2 * math.pi - EPS

def can(R, spr):
    n = len(spr)

    for i in range(n):
        for j in range(i, n):
            x1, y1, r1 = spr[i]
            x2, y2, r2 = spr[j]

            if i == j:
                cx, cy = x1, y1
                if get_intervals(cx, cy, R, spr):
                    return True
                continue

            midx = (x1 + x2) / 2
            midy = (y1 + y2) / 2
            dx = x2 - x1
            dy = y2 - y1
            d = math.hypot(dx, dy)

            if d == 0:
                continue

            h = math.sqrt(max(0.0, 1 - (d / (2 * R)) ** 2)) if R > 0 else 0

            px = -dy / d
            py = dx / d

            cx1 = midx + px * R * h
            cy1 = midy + py * R * h
            cx2 = midx - px * R * h
            cy2 = midy - py * R * h

            if get_intervals(cx1, cy1, R, spr):
                return True
            if get_intervals(cx2, cy2, R, spr):
                return True

    return False

def solve():
    n = int(input())
    spr = []
    for _ in range(n):
        x, y, r = map(int, input().split())
        spr.append((x, y, r))

    lo, hi = 0.0, 3000.0

    for _ in range(60):
        mid = (lo + hi) / 2
        if can(mid, spr):
            lo = mid
        else:
            hi = mid

    print(f"{lo:.10f}")

if __name__ == "__main__":
    solve()

角度間隔は自然に線ではなく円上に存在するため、最もデリケートな部分は、円弧の回り込みを正しく処理することです。
