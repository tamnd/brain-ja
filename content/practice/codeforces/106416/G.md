 ## 解決策
 ## 問題の理解

 アルファベットの上に短い DNA のような文字列を構築するように求められます。`{C, G, A, T}`。 各クエリは 2 つのターゲット値を与えます: に等しいサブシーケンスの数`C-A-T`(CAT 次数) と次の部分列の数に等しい`G-A-T-A`(GATA 度)、サブシーケンスは順序を保持しますが、文字をスキップする場合があります。 

クエリごとに、CAT サブシーケンス数が指定された値と等しい長さ 500 以内の任意の文字列を出力する必要があります。`C`、その GATA サブシーケンス数が指定された値と等しい`G`。 2 つのパターンは共通の手紙を通じて対話します`A`そして`T`したがって、主な困難は、構築を短くしながら両方のカウントを独立して制御することです。 

制約では最大 1000 個のクエリが許可され、各ターゲット値は 1e6 まで大きくすることができます。 長さ 500 の文字列には長さ 3 のサブシーケンスが最大約 125k あるため、単純なランダム構築では不十分です。 ただし、500 は十分小さいので、文字列に対する動的プログラミングではなく、構造化ブロックと明示的なカウント式に依存できます。 

単純な考えとしては、文字列をブルート フォースしてサブシーケンスをカウントするというものがありますが、1 つの文字列を評価するだけでもパターンごとに O(n) が必要で、検索スペースは 4^500 であり、まったく実行不可能です。 

さらに微妙な問題は、サブシーケンスがローカルではないことです。 たとえば、単一の`A`に対する相対的な位置に応じて、CAT と GATA の両方のカウントをさまざまな方法で変更します。`C`、`G`、 そして`T`。 順序を制御せずにパターンを独立して処理するソリューションでは、予期しない方法で過剰カウントが発生します。 

主な課題は、両方のサブシーケンス カウントが単純な算術式に組み込まれる構造を設計することです。 

## アプローチ

 ブルートフォース戦略は、文字列の構築を試行し、組み合わせ DP を使用して CAT および GATA カウントを直接計算することです。 固定文字列の場合、3 状態または 4 状態のオートマトンを使用してサブシーケンスをカウントできます。 これは評価あたり O(n) で機能しますが、文字列の検索は指数関数的になります。 1 つの文字を変更すると、多くのサブシーケンスがグローバルに影響を受ける可能性があるため、貪欲なローカル変更でも失敗します。 

このブレークスルーは、各文字のすべての出現が連続したブロックにグループ化される、厳格なグローバル構造を強制することによってもたらされます。 このようなレイアウトでは、ブロック間の順序が固定されると、サブシーケンスの選択は各ブロック内の位置を個別に選択することになるため、サブシーケンスはブロック サイズの積に分解されます。 

問題は、CAT と GATA の依存関係が重複していることです。`A`そして`T`したがって、2番目の部分がどこにあるかを慎重に制御しない限り、それらを独立した製品に完全に分離することはできません。`A`in GATAはから来ています。 コツは分割すること`A`2 つのブロックに分割し、そのうちの 1 つだけが最終的な結果に寄与するようにします。`A`GATAパターンで。 

この構造を使用すると、両方のカウントが単純な乗算式になり、クエリごとに小さな整数の因数分解問題を解くだけで済みます。

 ## アルゴリズムのチュートリアル

 5 つの連続したブロックを使用して文字列を構築します。`G-block + C-block + A-block-1 + T + A-block-2`それらのサイズを`g1, c1, a1, a2, t`、どこを修正しますか`t = 1`。 

2 つのサブシーケンス数を制御したいと考えています。 

猫用（`C-A-T`)、すべての有効なサブシーケンスは以下を選択します。 

ある`C`Cブロックからは、`A`Aブロック、シングルどちらからも`T`。 これにより、次のようになります。`CAT = c1 * (a1 + a2) * 1`。 

ガタの場合 (`G-A-T-A`)、すべての有効なサブシーケンスは以下を選択します。 

ある`G`Gブロックからは、`A`前に`T`(A ブロックのいずれか)、その後`T`、そして決勝`A`後`T`、これは 2 番目の A ブロックからのみ可能です。 これにより、次のようになります。`GATA = g1 * (a1 + a2) * a2`。 

ここで名前を変更します。`X = a1 + a2`

`Y = a2`それで`a1 = X - Y`。 

すると、方程式は次のようになります。`CAT = c1 * X`

`GATA = g1 * X * Y`。 

ここで、全長を小さく保ちながら両方の方程式を満たす整数値を検索します。`g1 + c1 + X + Y + 1 ≤ 500`。 

この構築は、次の因数分解を選択することになります。`c`の中へ`c1 * X`、そして同時にそれを保証します`g / (X * Y)`一部の人にとっては整数です`Y ≤ X`。 

## 段階的な構築

 1. 可能な値を反復処理します。`X`1から500まで。解釈します。`X`2 つの A ブロックに分割された A の合計数として。 
2. それを要求する`X`CATターゲットを分割します`C`、 以来`c1 = C / X`整数でなければなりません。 そうでない場合は、これをスキップしてください`X`。 
3. コンピューティング`g' = G / X`。 もし`X`分けない`G`、GATA には次の係数が必要なのでスキップします。`X`。 
4. 次に選択する必要があります`Y`そのような`Y`分割する`g'`、`Y ≤ X`、 そして`g1 = g' / Y`は整数です。 
5. 選択したら`Y`では、次のように定義します。`a2 = Y`

`a1 = X - Y`

`c1 = C / X`

`g1 = G / (X * Y)`6. 全長を確認します。`g1 + c1 + X + Y + 1 ≤ 500`。 有効な場合は、文字列を構築します。 
7. 出力:`G * g1 + C * c1 + A * a1 + T + A * a2`。 

### なぜ効果があるのか

 正確さは、ブロックの厳密な順序付けによってもたらされ、不要なインターリーブを防ぎます。 すべての有効な CAT サブシーケンスは、ブロック順に文字を選択する必要があるため、C ブロック → A ブロック → T に進む必要があります。同様に、すべての GATA サブシーケンスは、G ブロック → A (T 前) → T → A (T 後) を選択する必要があります。 T の後には A ブロックが 1 つだけあるため、2 番目の A の選択肢は一意に決定され、カウントの曖昧さがなくなります。 これにより、部分列のカウントが独立した選択に対する純粋な乗算に変わり、まさに因数分解ベースの構築が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

Q = int(input())
for _ in range(Q):
    G, C = map(int, input().split())

    if G == 0 and C == 0:
        print("T")
        continue

    ans = None

    for X in range(1, 501):
        if C % X != 0:
            continue
        c1 = C // X

        if G % X != 0:
            continue
        g_prime = G // X

        for Y in range(1, X + 1):
            if g_prime % Y != 0:
                continue
            g1 = g_prime // Y

            a2 = Y
            a1 = X - Y
            if a1 < 0:
                continue

            if g1 + c1 + X + Y + 1 > 500:
                continue

            ans = (
                "G" * g1 +
                "C" * c1 +
                "A" * a1 +
                "T" +
                "A" * a2
            )
            break
        if ans:
            break

    print(ans)

の`a1 = X - Y`T の前後の A の合計数が正確に一致するように制約が適用されます。`X`。 長さチェックにより、500 文字の制限内に収まることが保証されます。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    Q = int(input())
    out = []
    for _ in range(Q):
        G, C = map(int, input().split())

        if G == 0 and C == 0:
            out.append("T")
            continue

                    continue

                a1 = X - Y

                    continue
                if g1 + c1 + X + Y + 1 > 500:
                    continue
                ans = "G"*g1 + "C"*c1 + "A"*a1 + "T" + "A"*Y
                break
            if ans:
                break

        out.append(ans)

    return "\n".join(out)

 ## 特殊なケース

 のために`(0, 0)`の場合、この構造は因数分解ロジックをバイパスし、単一の文字を直接出力します。 これは、未定義の除算のケースを回避し、空の構造体には両方のサブシーケンスの出現が依然としてゼロであるという事実と一致します。 

いつ`C = 0`しかし`G > 0`を選択できるため、ループは引き続き機能します。`X = 0`は許可されていないため、代わりに建設部隊が`c1 = 0`選ぶことによって`X = 1`。 これにより、CAT の寄与が完全に削減され、すべての構造が GATA を満たすことに専念します。 

いつ`G = 0`しかし`C > 0`、選択する`Y = 1`力`g1 = 0`、GATA をゼロに崩壊させながら、純粋に C および A 構造から CAT を形成できるようにします。
