 ## 解決策
 ## 問題の理解

 一連のカラーボールが与えられ、それが成長する構造物に 1 つずつ挿入されます。 各ボールは最終的に安定した山に置かれ、すべてのボールが地面に置かれるか、その真下にあるちょうど 2 つのボールによって支えられる必要があります。 ゴロは連続した位置を占めなければならないので、ゴロの間に隙間があってはならない。 これにより、ベースレイヤーは常に連続セグメントのように動作するようになります。 

ボールは決められた順序で挿入されるため、構造は任意ではありません。 各挿入は安定性を維持する必要があり、複数の有効な位置が存在する場合、ボールは可能な限り高い位置に配置され、同じ高い位置の間で任意のタイブレークが行われます。 これにより、標準的な貪欲な構築プロセスが生成されますが、重要な問題は、タイブレークによって複数の有効な最終構造が依然として許容されることです。 

すべての挿入後、接触関係を通じて接続性を調べ、同じ色のボールで構成される接続されたコンポーネントとしてクラスターを定義します。 タスクは、構築中にタイを解決できるすべての有効な方法で、最大の単色連結コンポーネントのサイズを最大化することです。 

制約は小さく、最大でも 150 個のボールと 150 色です。 これは、3 次または 4 次の動的計画法のアプローチが受け入れられることを直ちに示唆しますが、すべてのパイル構成またはすべての挿入選択肢の指数関数的な列挙は除外されます。 すべての有効な配置を明示的にシミュレートしようとする単純な試みは、各挿入に複数の有効な位置が含まれる可能性があり、構造が組み合わせ的に増大するため、爆発的に増加します。 

微妙なエッジケースは、決着の曖昧さから生じます。 貪欲なルールが「可能な限り高い位置」を示している場合でも、同じ高さに複数の位置があり、将来の接続性が異なる可能性があります。 単純な決定論的シミュレーションでは、有効ではあるが、異なるタイブレークの選択が必要な構成を見逃してしまいます。 

たとえば、色の異なる 2 つの野球ボールが配置されている場合、2 番目のボールは左右のグラウンドに挿入される可能性があります。 その後の挿入では、その選択に応じて異なる方法で接続することができ、クラスター サイズが変わります。 このサンプルは、同一の挿入配列によって最終的なクラスター サイズが異なる可能性があることをすでに示しています。 

中心的な問題は、ローカルの貪欲な配置ではグローバル接続が一意に決定されないため、到達可能なすべての安定した構成を暗黙的に推論する必要があることです。 

## アプローチ

 強引なアイデアは、考えられるすべての有効な杭建設をシミュレートすることです。 各挿入ステップで、「可能な限り最高の」ルールを尊重しながら新しいボールを配置できるすべての有効な位置を列挙し、複数の配置が可能な場合は常に分岐します。 全体の幾何学的構造と接続性グラフを維持します。 

ただし、構成の数は指数関数的に増加します。 各ステップの分岐係数が小さい場合でも、N ステップの後、パイルの数は N で指数関数的に増加する可能性があります。N が 150 までの場合、これは完全に不可能です。 

重要な観察は、ジオメトリが非常に硬いということです。 2 つのサポートの上に配置されたボールはそれらのサポートによって完全に決定され、グラウンド ボールは連続している必要があるため、構造は段階的に構築される平面三角形分割のように動作します。 ジオメトリを明示的に追跡する代わりに、共有サポートを通じて色間の接続がどのように形成されるかのみを考慮します。 

これは、問題を広告掲載オーダーの間隔にわたる動的プログラミングとして再構成することを示唆しています。 有効なパイルは最終的に、シーケンスのサブ構造への階層的分解に対応し、各「上部ボール」が 2 つの隣接するサブ構造を 1 つの大きな構造にマージします。 これは、インターバルにわたるバイナリ マージ DP と構造的に同じです。

シーケンスのセグメントにわたって DP 状態を定義し、そのセグメントから発生する可能性のある最良のクラスター情報を追跡します。 2 つのセグメントが新しい支持ボールの下で結合するとき、その上部のボールを介して接続されている場合、同じ色のクラスターが結合する可能性があります。 すべての色にわたる最大クラスター サイズのみを考慮するため、各間隔について、色ごとの達成可能な最良の寄与と境界接続の動作を追跡できます。 

この構造は、行列チェーンの乗算やポリゴンの三角形分割で使用される区間 DP に似ており、各分割点は 2 つの部分問題をマージする最後の演算を表します。

 ## アルゴリズムのチュートリアル

 挿入オーダーに対して完全なバイナリ構造を構築するプロセスをモデル化します。各内部ノードは、以前の 2 つの構造によってサポートされるボールを表します。 各間隔 [l, r] は、これらのボールが何らかの内部構造をルートとする有効なサブパイルを形成する可能性を表します。 

2 つのサブパイルがマージされたときに色がどのように接続されたコンポーネントを形成できるかに焦点を当て、間隔に関する DP 情報を維持します。 

### 1. 間隔にわたる DP 状態を定義する

 各区間 [l, r] について、有効なサブパイルのベースとなり得るあらゆる方法を考慮します。 最適なタイブレークの下で、この間隔に完全に含まれる連結成分の最大サイズに関する情報を色ごとに保存します。 

これが機能するのは、最終的なパイルを特定のルート配置でマージする独立したサブパイルに分解できるためです。 

### 2. 単一ボールの基本ケース

 l == r の場合、ボールは 1 つだけであるため、唯一のクラスターの色がサイズ 1 になります。 これにより、DP が簡単に初期化されます。 

### 3. 最後のマージによる間隔の分割

 区間 [l, r] については、それを統合する最後に挿入された構造的接続が (l, r) 内のルート位置 k の選択に対応すると仮定します。 このルートは、左側のサブパイル [l, k] と右側のサブパイル [k, r] を接続します。 

重要なのは、同じ色を共有している場合、根鉢が両側からクラスターを接続し、クラスターのサイズが大きくなる可能性があることです。 

### 4. DP 状態のマージ

 分割点 k ごとに、DP[l][k] と DP[k][r] を組み合わせます。 各色について、3 つの可能性を検討します。クラスター全体が左側にある場合、全体が右側にある場合、または両側が寄与してルートを通じて接続される構成によってマージされる場合です。 

タイブレークでは有効な構築を選択できるため、すべての分割ポイントにわたって可能な限り最良の結果が得られます。 

### 5. すべての色にわたる最大値を追跡する

 各 DP 間隔には、色ごとに達成可能な最適なクラスター サイズが格納されます。 最終的な答えは、DP[1][N] のすべての色の最大値です。 

### なぜ効果があるのか

 すべての安定したパイルは、サポート関係によって引き起こされる挿入配列の階層的なバイナリ分解に対応します。 各内部ボールは正確に 2 つのサポートに依存するため、構造は区間にわたる二分木になります。 DP は、すべての分割点を試すことによって、そのようなツリーの可能性をすべて暗黙的に列挙します。 

同じ色のボールの接続性は、それらが何らかの祖先を介してマージされたサブツリーに到達するかどうかによってのみ決まります。 DP は考えられるすべてのマージ ポイントを考慮するため、安定したパイルによって引き起こされる有効な接続パターンは、少なくとも 1 つの DP 構成で表現できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # dp[l][r][c] = max cluster size of color c in interval [l, r]
    dp = [[[0] * 151 for _ in range(n)] for _ in range(n)]
    
    for i in range(n):
        dp[i][i][a[i]] = 1
    
    for length in range(2, n + 1):
        for l in range(n - length + 1):
            r = l + length - 1
            
            # combine splits
            for k in range(l, r):
                left = dp[l][k]
                right = dp[k + 1][r]
                
                for c in range(1, 151):
                    val = max(left[c], right[c])
                    
                    # attempt to merge contributions
                    # if both sides contain same color, merging is possible
                    val = max(val, left[c] + right[c])
                    
                    if val > dp[l][r][c]:
                        dp[l][r][c] = val
    
    ans = 0
    for c in range(1, 151):
        ans = max(ans, dp[0][n - 1][c])
    
    print(ans)

if __name__ == "__main__":
    solve()
```DP テーブルには間隔境界によってインデックスが付けられます。 各基本セルは単一ボール クラスターを初期化します。 2 つのセグメントを結合するときは、すべての分割ポイントを試し、色の寄与をマージします。 アップデート`left[c] + right[c]`有効なサポート構成を通じて両側の同じ色のクラスターが接続される可能性を反映しています。 

この解決策は、最適な構築はシーケンスのバイナリ分割によって表現できるため、すべての分割をチェックするだけで十分であるという事実に基づいています。 

よくある微妙な点はインデックス付けです。正しいセグメントは次の位置で開始する必要があります。`k+1`、 ない`k`そうでない場合、間隔が重なり、要素が誤って二重にカウントされます。

 ## 特殊なケース

 主なエッジ ケースは、間隔の両端に同じ色が表示されるが、それらが複数の異なる色で区切られている場合です。 単純な貪欲なシミュレーションでは接続できないと想定されますが、DP では、より高いサポートを通じて接続性を高める方法で中間ボールを配置する構造が可能です。 間隔 DP は、中間ブロッキングをバイパスする分割を明示的に考慮します。 

別のエッジ ケースは、同じ間隔に複数の最適な分割ポイントが存在する場合に発生します。 1 つの分割のみを決定論的に保持すると、後でより大きなクラスターを可能にする代替構造が失われることになります。 DP は、[l, r) 内のすべての k を探索し、接続構成が破棄されないようにすることでこれを回避します。 

最後のエッジケースは、次のような交互シーケンスにおける単色優勢です。`1 2 1 2 1`。 ここでは、特定の階層マージのみが 3 つの 1 を接続できるため、隣接関係に基づく誤った推論は失敗します。 DP は隣接関係に依存せず、完全な間隔の再結合に依存するため、これを捕捉します。
