 ## 解決策
 ## 問題の理解

 2 つの整数が与えられます。$a$そして$b$、一列に配置された図形の線形配置を表します。 この行にはちょうど 2 つの三角形があり、残りの形状はすべて正方形です。 

幾何拘束は相対的な方法で記述されます。 最初の三角形を見つけて、その右に移動すると、最終的に 2 番目の三角形に到達します。それらの間には、正確に$a$正方形。 対称的に、2 番目の三角形から開始して左に移動すると、最初の三角形に正確に遭遇します。$b$間の正方形。 

これにより、残りの位置が正方形で埋められるシーケンス内の 2 つの三角形の位置に対する相対的な順序制約が完全に決定されます。 タスクは、配置自体を構築することではなく、指定された条件と一致するすべての有効な構成の下で、行が持つことができる合計位置の数を決定することです。$a$そして$b$。 

重要な問題は、三角形は同一性を除いて区別できないため、相対的な順序のみが問題となることです。 最終レイアウトで最初の三角形が 2 番目の三角形の左側に配置されるか右側に配置されるかによって、シーケンスの全長がわずかに異なる場合があります。 出力では、可能な最小および最大の形状の合計数が求められます。 

制約により許可されるのは、$a, b$まで$10^9$これにより、行を明示的に構築またはシミュレートするアプローチは直ちに除外されます。 どのソリューションでも、構成を相対配置ロジックから導出された定数時間式に削減する必要があります。 

2 つの三角形がある方向に隣接している場合、微妙なエッジ ケースが発生します。 たとえば、次の場合$a = 0$そして$b = 0$、両方の三角形は方向に関係なく隣り合っており、不注意な推論により二重にカウントされたり、両方の順序が同じレイアウト長に折りたたまれるという事実を見落としたりする可能性があります。 

## アプローチ

 ブルートフォース解釈では、連続する 2 つの三角形の可能な配置をすべて列挙し、必要な正方形の数が一致するかどうかをチェックしようとします。 最初の三角形の位置を固定し、次に 2 番目の三角形をその左または右に配置し、それらの間の正方形を数えることが想像できます。 ただし、正方形の総数には原理的に制限がなく、位置が任意にシフトする可能性があるため、このアプローチは多くのオフセットを試行することになります。 たとえ実行可能な範囲に注意を限定したとしても、候補構成の数はシーケンスの最終的な長さに応じて増加し、最悪の場合は次のようになります。$a + b$、許容範囲をはるかに超えている場合$a, b \le 10^9$。 

問題の構造により、この検索の必要性がなくなりました。 唯一の自由度は、2 つの三角形の順序と、それらの間の正方形のブロックが方向に応じて入力によって固定されるという事実です。 どの三角形が左端とみなされるかを修正すると、レイアウトは固定的になります。つまり、一方向にギャップが強制されます。$a$正方形の場合、逆方向ではギャップが強制されます。$b$正方形。 したがって、全体の構成は、2 つのマーカーを一定の間隔で線上に配置し、残りのスペースに押し込まれる正方形のスロットの数を数えることによって決定されます。 

これにより、問題は、同じ制約の 2 つの可能な方向を分析し、それぞれのケースで結果として生じる全長を計算することに減ります。

 ## アルゴリズムのチュートリアル

 1. 2 つの三角形を直線上の順序付けられた位置として扱い、そのうちの 1 つを一番左の三角形とみなします。 この方向では、2 番目の三角形がその右側に正確に表示されます。$a$それらの間にある正方形。 これは、左の三角形が位置 0 にある場合、右の三角形は位置 0 にあることを直接意味します。$a + 1$したがって、この順序付けによって寄与される最小スパンは次のようになります。$a + 2$両方の三角形を含む位置。 
2. 視点を反転し、2 番目の三角形が最初の三角形の左側に配置されていると仮定します。 この場合、与えられた条件は、$b$それらの間には正方形があるため、この向きの三角形間の距離は次のようになります。$b + 1$。 これにより、次のスパンが生成されます。$b + 2$ポジション。 
3. 両方の解釈が同じ物理構成に対応する必要があることに注意してください。これは、両方の三角形の順序付けが、同じ基礎となる制約を記述する有効な方法であることを意味します。 行の全長は、シーケンスを構築するときにどの解釈に従うかによって異なります。 
4. 最小の全長は、よりタイトな構成を選択したときに発生します。これは、強制正方形ギャップとの重なりを最小限に抑える順序で三角形を配置することに対応します。 これにより、基本長は次のようになります。$\min(a, b) + 2$三角形の端点の位置ですが、正方形は解釈の両方向に存在する必要があるため、実際の最小行全体の長さは次のようになります。$a + b + 2$1 つの共有エンドポイント構造のオーバーラップ調整を差し引いたものです。 
5. 可能な最大の長さは、どちらかの順序が独立して構造を支配できるという事実を考慮したときに発生します。これにより、次のような 2 番目の有効な解釈が得られます。$a$そして$b$反対方向に完全に表現されます。 

構造をより安定して見る方法は、2 つのマークされた位置を配置することによって行が完全に決定され、正方形が正確に残りのギャップであることを理解することです。 唯一のあいまいさは、説明でどの三角形が最初に考慮されるかであるため、全長は次のいずれかになります。$a + 2 + b$または$a + b + 2$, しかし、これらは同じ表現です。 代わりに、変動は、端点が包括的にカウントされるか、または 1 つの三角形が一方の方向では境界の一部として扱われるが、もう一方の方向では境界の一部として扱われないかどうかによって生じます。 これにより、2 つの連続する整数の可能性が得られます。 

## なぜ機能するのか

 核となる不変条件は、構成が 2 つの三角形間の相対距離によって完全に決定され、その距離が次の式によって両方向に固定されるということです。$a$そして$b$。 すべての有効な配置は、三角形の順序を選択し、それらの間に固定数の正方形を配置することに対応するため、すべての解決策は 1 次元格子上の線形スパンの計算に帰着します。 相対的な順序を変更せずに中間構成が平方数に違反することはできませんが、これは問題の説明で禁止されています。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    a = int(input())
    b = int(input())

    # minimal arrangement: triangles as close as constraints allow
    mn = min(a, b) + 2

    # maximal arrangement: triangles as far apart as constraints force
    mx = a + b + 2

    print(mn, mx)

if __name__ == "__main__":
    solve()
```この実装は、2 つの三角形が線形構造の端点を形成し、すべての有効な行が方向制約の解釈方法を選択することによって取得されるという観察を直接エンコードします。 

唯一の微妙な点は、一貫したエンドポイントのカウントです。 各三角形は 1 つの位置に寄与し、各正方形は三角形の間または外側のギャップに 1 つの追加位置に寄与します。 すべての式が次の一次関数に帰着するのはこのためです。$a$そして$b$定数オフセットは 2 です。

 ## 特殊なケース

 いつ$a = 0$そして$b = 0$、両方の解釈において、両方の三角形が隣接している必要があります。 計算された両方のスパンが同じ最小構成に折りたたまれ、単一の可能な長さが得られるため、アルゴリズムは引き続き一貫した結果を生成します。 

のために$a = 0, b > 0$、左から右への解釈では、片側に隣接性が強制され、反対側にはゼロ以外のギャップが強制されます。 一方の方向はタイトなレイアウトを生成し、もう一方の方向はそれを完全に拡張するため、アルゴリズムはこれらを最小構成と最大構成に自然に分離します。$b$正方形。 

のために$a, b$最大値では、最大値の加算のみが使用されるため、計算は安定したままになります。$2 \cdot 10^9$これは、Python の 32 ビット整数の安全性の範囲内に十分に収まっており、特別な処理は必要ありません。 

単純な実装が配置をシミュレートしようとすると、潜在的に配置に沿って位置を列挙しようとします。$10^9$-length 行は、時間とメモリの制約によりすぐに失敗します。
