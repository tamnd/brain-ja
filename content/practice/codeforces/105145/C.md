 ## 解決策
 ## 問題の理解

 教室にいる各生徒は、理解しているさまざまなトピックに関連付けられています。 教師がトピックについて質問すると、すべての生徒は、そのトピックが学習範囲内にある場合は肯定的に反応し、範囲外にある場合は否定的に反応します。 肯定的な反応は生徒のスコアを 1 増加させ、否定的な反応はその生徒のスコアを 1 減らします。教師は各トピックについて最大 1 回質問できます。目標は、生徒の最終的な最高スコアと最低スコアの差を最大化するトピックのサブセットを選択することです。 

プロセスを理解するもう 1 つの方法は、数直線上の一連の点を選択し、各生徒がこれらの点に対して関数を提供することです。セグメントの内側では、選択した点ごとに +1 を獲得し、セグメントの外側では、選択した点ごとに -1 を失います。 これらの累積された線形スコアの最終的な広がりができるだけ大きくなるようにポイントを選択したいと考えています。 

m は 10^9 に達する可能性があるため、この制約により、トピックを直接反復することを回避する解決策が求められます。 重要な唯一の構造は、生徒のインターバルエンドポイントの配置であり、トピック自体ではありません。 

単純なアプローチでは、トピックのサブセットの選択をシミュレートしたり、質問の候補セットを貪欲にテストしたりしようとしますが、m の範囲が膨大であるため、候補トピックを列挙することさえ不可能です。 たとえ区間エンドポイントのみに限定したとしても、それらに対する単純なサブセット検索は依然として指数関数的になります。 

すべての間隔がバラバラであるか、ほぼ同一である場合、微妙な失敗のケースが発生します。 たとえば、すべての生徒が同じ間隔を持っている場合、選択されたすべてのトピックは全員に同じように貢献し、戦略に関係なく最終的な答えはゼロのままでなければなりません。 他人に引き起こされる損失を追跡せずに、個々の生徒の利益を最大化しようとする不注意な貪欲さは、答えを過大評価することになります。 

## アプローチ

 重要な観察は、トピックについて明確に考える必要がないということです。 各生徒にとって重要なのは、選択した点が自分の区間内と区間外にどれだけ当てはまるかだけです。 一連のトピックを選択すると、各生徒の最終的な価値は次のようになります。 

スコア(i) = 内側(i) − 外側(i)

 ここで、 inside(i) は [li, ri] に含まれる選択されたトピックの数であり、outside(i) は選択されたトピックの合計から inside(i) を差し引いたものです。 

選択されたトピックの合計を K とします。 

スコア(i) = 2 * 内部(i) − K

 したがって、2 人の生徒を比較すると -K 項がキャンセルされるため、最大スコアと最小スコアの差を最大化することは、生徒間のインサイド カウントの差を最大化することと同等になります。 

したがって、各区間に含まれる選択されたポイントの数の広がりを最大化するトピックのセットを選択するだけで済みます。 

ここで、選択した各トピック k を、区間に k が含まれるすべての生徒に「1 を加える」ポイントとして再解釈します。 したがって、各トピックは一連の間隔にわたるカバレッジ数に対応します。 ポイントのサブセットを選択しており、各ポイントは、それをカバーするすべての間隔にわたって +1 のベクトルに寄与します。 

重要な構造的洞察は、カバレッジの変更のみが重要であり、それらの変更は間隔のエンドポイントで発生するということです。 ラインに沿ってスイープすると、アクティブな間隔のセットは l と r+1 でのみ変化します。 したがって、最適な選択は、ソートされたエンドポイント間のセグメントに対する決定に圧縮できます。 

連続する臨界座標間では、カバー間隔の数は一定です。 セグメントにカバレッジ c がある場合、その内部の任意のポイントを選択しても同じ効果があるため、各セグメントから選択するポイントの数だけを気にします。 

これにより、問題は、生徒がそこで活動しているかどうかに応じて、各セグメントが各生徒に固定の「重み」を与えるという線形構造に帰着します。

次に、目標を再度解釈し直します。間隔インジケーター ベクトルを使用して、これらのセグメント上で選択した 0 ～ 1 ベクトルの最大ドット積と最小ドット積の差を最大化したいと考えています。 これは、極端なカバレッジ パターンを持つセグメント内のすべてのポイントを選択することになります。つまり、十分にカバーされている生徒への寄与を最大化し、まばらにカバーされている生徒への寄与を最小限に抑えます。 

最適な構成は、ソートされたエンドポイント構造のプレフィックスまたはサフィックス内のすべてのセグメントを選択し、1 つのスチューデントを最大化し、別のスチューデントを最小化する方向にすべての質量をプッシュするという 2 つの極端な構造のみを評価することによって最終的に達成されます。 

これにより、エンドポイントの並べ替え、カバレッジの徹底的な調査、およびプレフィックス集約による最善の極端な追跡によって推進されるソリューションが実現します。

 ## アルゴリズムのチュートリアル

 1. 各間隔 [li, ri] を 2 つのイベント (li で +1、ri + 1 で -1) に変換します。これにより、任意の座標でアクティブな間隔の数を示すスイープ ライン表現が構築されます。 
2. すべてのイベントポイントを並べ替えます。 これらを昇順に処理して、アクティブ セットが一定である連続セグメントを再構築します。 
3. 現在のアクティブ数 c を維持しながら、並べ替えられたイベントをスイープします。c は、インターバルが現在スイープ位置をカバーしている生徒の数です。 
4. あるイベント座標から次のイベント座標に移動するたびに、範囲が一定である長さ L のセグメントが形成されます。 このセグメントは一様な貢献者として扱うことができます。 
5. 個々のトピックを明示的に選択する代わりに、セグメント内のポイントの選択が生徒にどのような影響を与えるかという観点から推論します。選択されたポイントごとに、アクティブな生徒全員が 1 ずつ増加し、非アクティブな生徒が 1 ずつ減少します。 
6. 各セグメントについて、考えられる最も優秀な生徒と最も劣った生徒の差に及ぼす影響を計算します。 重要な削減点は、最も頻繁に活動する生徒への貢献を最大化し、最も活動的でない生徒への貢献を最小化する極端な構造のみを考慮する必要があることです。 
7. セグメントにわたる寄与を累積して、達成可能な最良のスプレッドを計算します。これは、カバレッジ加重和の最大値と最小値の差を最大化することに対応します。 

### なぜ効果があるのか

 スイープ ラインは、数直線を最大領域に分割し、選択した点に関してすべての生徒が同じ動作をします。 このような領域内では、選択するポイントの数によるスケーリングまではすべての選択肢が同等であるため、問題は各領域にどれだけの重みを割り当てるかを決定することになります。 各生徒の最終スコアはこれらの重み付けにおいて線形であるため、極端な差は極端な割り当てで達成される必要があります。つまり、混合分数戦略や内部調整は必要ありません。 間隔の構造により、目的がセグメントの重みに対して線形関数になることが保証されるため、その最大値と最小値は境界が揃った構成で発生します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    events = []
    
    for _ in range(n):
        l, r = map(int, input().split())
        events.append((l, 1))
        events.append((r + 1, -1))
    
    events.sort()
    
    active = 0
    prev = 1
    segments = []
    
    for x, delta in events:
        if x > prev:
            segments.append((prev, x - 1, active))
        active += delta
        prev = x
    
    if prev <= m:
        segments.append((prev, m, active))
    
    # We now have segments with constant coverage
    # Each segment contributes length * (2*active - n) structure indirectly
    # We reduce to computing max possible spread
    
    vals = []
    for l, r, c in segments:
        length = r - l + 1
        if length > 0:
            vals.append((c, length))
    
    vals.sort()
    
    prefix = 0
    total = sum(length for _, length in vals)
    
    best = 0
    cur = 0
    
    for c, length in vals:
        cur += length
        best = max(best, cur - (total - cur))
    
    return 2 * best

def main():
    print(solve())

if __name__ == "__main__":
    main()
```実装は、間隔のエンドポイントにわたる標準のスイープ ラインの構築から始まります。 各間隔は 2 つのイベントに寄与するため、m にわたって反復することなく、数直線の任意のセグメントにわたってアクティブな生徒の数を再構成できます。 

イベントを並べ替えた後、アクティブな数が一定である最大のセグメントを構築します。 各セグメントは、そのカバレッジ レベルと長さによって要約されます。 これにより、m への依存が完全に削除されます。 

次に、この問題を 2 つの区分の間の不均衡を最大化するセグメントを選択するものとして扱います。1 つは仮想の「成績の高い」生徒に利益をもたらし、もう 1 つは仮想の「成績の低い」生徒に害を及ぼすものです。 カバレッジ別にセグメントを並べ替えると、並べ替えられたセグメント内でカット ポイントを移動し、累積された重みと累積されていない重みの差を最大化することで、最良の分離を貪欲に累積することができます。 

選択された各セグメントが一方の極値を増加させ、もう一方の極値を減少させることに対称的に寄与するため、最終的な答えは 2 倍になります。

 ## 特殊なケース

 重要なエッジケースは、すべての間隔が同一である場合です。 すべてのトピックはすべての生徒に平等に影響を与えるため、すべての生徒のスコアは常に同じ量だけ変化し、その差はゼロのままでなければなりません。 スイープ構造により単一のカバレッジ レベルが生成され、プレフィックス カットによって不均衡が生じることはありません。 

もう 1 つの特殊なケースは、完全に独立した間隔です。 選択した各トピックは 1 人の生徒にのみプラスの影響を与え、他の生徒にはマイナスの影響を与えます。 最適な戦略は、分離された各間隔に対応するエンドポイントを選択して、最大の分離を生成することです。 セグメント モデルは、これらをカバレッジ 1、1、1 の個別のブロックとして正しく分離し、ベスト カットにより均等に分割されます。 

最後の微妙なケースは、最大の重なりが 1 点ある場合に発生します。 このアルゴリズムにより、このピーク カバレッジを含むセグメントが確実に分離され、プレフィックスの累積により、最終的な差異の主な寄与要因としてそのセグメントが自然に選択されます。
