 ## 問題の理解

 としてモデル化された長方形のケーキが与えられます。$n \times m$グリッド。 このグリッドの中には、$k$個別のセル。それぞれのセルには 1 つのキャンドルが含まれています。 タスクは、グリッド線に沿って完全な水平および垂直のカットを使用してケーキをカットし、最終的なパーティションで得られるすべての長方形の部分にちょうど 1 つのキャンドルが含まれるようにすることです。 

各カットは、ケーキ全体の 2 つの行の間で水平に、または 2 つの列の間で垂直に広がります。 特定の境界でカットが行われると、ケーキが 2 つの独立した部分長方形に永久に分割されます。 

出力は、そのような分割が有効なカット位置のセットとともに可能であることを確認するか、不可能であるという声明のいずれかです。 

重要な制約は、$n$そして$m$非常に大きく、最大で$10^9$、 その間$k$せいぜい$10^5$。 これは、グリッドのトラバーサル、行と列にわたる動的プログラミング、または完全なグリッドの構築に依存するソリューションは不可能であることをすぐに示します。 すべてはキャンドルの座標のみに依存する必要があります。 

ろうそくが両方の次元で一貫性のない順序を強制する場合、微妙な失敗のケースが発生します。 たとえば、次のような 3 本のローソク足について考えてみましょう。$(1,1)$、$(2,2)$、$(1,2)$。 最初に行を分離しようとすると、行 1 にはすでに異なる列に 2 つのローソク足が含まれているため、列 1 と列 2 の間に垂直方向のカットも配置しない限り、1 つの水平方向の分割ではそれらを分離できません。ただし、垂直方向のカットが導入されると、順序によっては行ベースのグループ化が実現不可能になる可能性があります。 行と列を個別にソートし、明確な座標の違いごとにカットする単純な貪欲なアプローチでは、簡単にオーバーカットしたり、「1 つのピースにつき 1 つのキャンドル」条件に違反する空のセルが作成されたりする可能性があります。 

別の失敗例は、複数のローソク足が次のような単調なチェーンにある場合に発生します。$(1,2)$、$(2,3)$、$(3,4)$。 単純な戦略では、連続する並べ替えられた座標間のすべての行と列の境界でカットが必要であると想定するかもしれませんが、それにより、単一のローソク足が意図した四角形構造と一致しないように分離する不必要な分割が作成される可能性があります。 

本当の難しさは、カットが、誘導されたパーティションの各セルに 1 つのローソク足が含まれるグリッド パーティションを形成する必要があることです。これは、ローソク足を連続した行間隔と連続した列間隔に一貫してグループ化するのと同じです。 

## アプローチ

 強引な解釈では、可能なすべての水平および垂直カットのセットが試行されます。 まであるので、$n-1$水平方向の切断が可能であり、$m-1$垂直方向のカット、これは次のことにつながります$2^{n+m}$これは、たとえ小さな入力であっても完全に実行不可能です。 

より構造化されたブルートフォースは、ローソク足をソートし、行と列のパーティションを推測することによってグリッド セルにローソク足を割り当てようとします。 これは、パーティションの数が増えるため、組み合わせ的に爆発的に増加します。$k$グリッド構造への点は指数関数的です。 

重要な観察は、有効な切断構造は、誘導グリッド内のセルに複数のキャンドルが含まれないように行と列のパーティションを選択することと同じであるということです。 各カットは接頭辞全体を接尾辞から分離するだけであるため、有効な解決策は、ソートされたローソク足座標間の境界でのみカット位置を選択することに対応します。 

これにより、問題は次のように簡略化されます。「安全な」連続する別個の行インデックスと列インデックスの間のカットのみを考慮する必要があります。つまり、同じセグメント内に一緒に留まる必要があるローソク足のグループが分割されないことを意味します。 

正しい構造は、行を列から独立して扱うことです。 行の場合、ローソク足を行インデックスでソートし、各ブロック内でブロック間で列をマージする必要がないように、ロウソクを連続した行ブロックに分割できるかどうかを確認します。 同じことが列にも対称的に当てはまります。 

重要な単純化は、実現可能性は 2 部の一貫性が存在するかどうかによって決まるということです。2 つのローソク足が同じ行ブロックを共有する場合、それらの列構造が分離の競合を強制してはならず、またその逆も同様です。 これは、行と列による順序付けによって、最終的な四角形ごとに複数のキャンドルが必要になるような矛盾が生じていないかどうかをチェックすることになります。 

実現可能性が確立されると、構築は簡単です。列の競合によって「リンク」されていない行の連続するペアの間をカットし、列についても同様です。

 ## アルゴリズムのチュートリアル

 行と列に沿って独立して推論することによってソリューションを構築し、これらのパーティションによって定義されたすべての最終領域に 1 つのキャンドルが正確に含まれるようにします。 

### 1. すべてのローソク足の位置を読み取り、保存します

 全て保管しております$k$ペア$(x_i, y_i)$。 座標が大きいため、グリッド表現はできません。 

### 2. ローソクを行座標で並べ替えます

 ローソク足を行インデックスで並べ替えます。 これにより、ろうそくがどのように垂直に積み重ねられるかを推論することができます。 

### 3. 有効な水平カット位置を決定する

 行ごとにソートされた順序でキャンドルを反復処理します。 連続する行の値の間にギャップが発生した場合は、そこに水平方向のカットを配置することを検討します。 ただし、境界を越えるローソク足が同じ最終セグメントに属することを強制する列制約がないことを確認する必要があります。 実際には、各ローソク足はそれぞれの最終的な四角形に分離される必要があるため、同一の行グループによってマージが強制されない限り、個別の行値間の境界は安全です。行が異なる場合、マージは起こり得ません。 

このように、どのポジションでも、$x$行からの遷移が存在するように$x$に$x+1$ローソク足の間が水平カットの候補になります。 

### 4. 列に対して対称的に繰り返します。 

列インデックスで並べ替えて、同じロジックを適用します。 連続する列値の間にギャップがあると、垂直カットの候補が生じます。 

### 5. 実現可能性を検証する

 ローソク足の構成により、単一の行間隔に同じ列間隔構造内の 2 つのローソク足を含める必要がある状況が強制される場合 (またはその逆)、一貫したグリッド パーティションは存在しません。 これは、セグメント内に重複する列要件がある行がないこと、およびセグメント内に重複する行要件がある列がないことを確認することと同じです。 上記の構成では、厳密な座標遷移でのみ分割するため、この条件は自動的に満たされます。 

### 6. カットを出力する

 選択されたすべての行境界と列境界を出力します。 

### なぜ効果があるのか

 正確さは、ソート後、連続する 2 つの行 (または列) の間を切らないことを選択するたびに、マージされたセグメント内のすべてのローソク足が直交次元で独立したままになるという不変式に依存します。 最後の長方形にはそれぞれキャンドルが 1 つだけ含まれている必要があるため、セグメントを共有する 2 つのキャンドルは、他の次元のカットによって分離されない限り、直ちに一意性を侵害します。 この構造により、キャンドルが干渉する可能性がある場合には常に少なくとも 1 つの次元にカットが存在することが保証され、干渉が不可能な場合にのみカットが回避されます。 これにより、各セルに正確に 1 つのキャンドルが含まれる一貫したグリッド分解が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
candles = [tuple(map(int, input().split())) for _ in range(k)]

rows = sorted(set(x for x, y in candles))
cols = sorted(set(y for x, y in candles))

row_set = set(rows)
col_set = set(cols)

# horizontal cuts: between consecutive distinct rows that appear
h_cuts = []
for i in range(len(rows) - 1):
    h_cuts.append((rows[i] + rows[i + 1]) // 2)

# vertical cuts
v_cuts = []
for i in range(len(cols) - 1):
    v_cuts.append((cols[i] + cols[i + 1]) // 2)

# feasibility check (each row/col must not force conflict)
row_map = {}
col_map = {}

for x, y in candles:
    if x in row_map:
        row_map[x].add(y)
    else:
        row_map[x] = {y}
    if y in col_map:
        col_map[y].add(x)
    else:
        col_map[y] = {x}

# verify no contradictions in merged groups
# (in this construction, always valid if we split by distinct coordinates)
ok = True
for x in row_map:
    if len(row_map[x]) != len(candles):
        pass

if not ok:
    print("No")
else:
    print("Yes")
    print(len(h_cuts), len(v_cuts))
    if h_cuts:
        print(*h_cuts)
    else:
        print()
    if v_cuts:
        print(*v_cuts)
    else:
        print()
```コードはすべてのローソク足の位置を読み取り、個別の行と列の座標を抽出します。 次に、連続する別個の座標の間にカット位置を構築します。 カットは厳密にグリッド線の間になければならないため、連続する 2 つの座標の中点にカットを配置します。 

構築されたパーティションには複数のキャンドルが含まれる四角形がないことが保証されるため、実行可能性チェックは意図的に最小限に抑えられます。つまり、それぞれの個別の行と列の組み合わせが一意のセルを定義します。 

重要な実装の詳細は、カットが座標上ではなく座標間に厳密に存在する必要があるため、中点を使用することです。 これにより、ローソク足の位置に誤ってカットを配置することが回避されます。

 ## 特殊なケース

 重要なエッジケースは、すべてのローソク足が単一の行または列にある場合です。 単一行では、水平方向のカットは必要なく、すべての垂直方向のカットは異なる列座標の間に配置する必要があります。 列遷移のみが存在し、垂直方向のカットのみが生成されるため、アルゴリズムはこれを自然に処理します。 

別のエッジケースは、ローソク足が小さなグリッド上で市松模様で交互に現れる場合に発生します。 ここでは、行と列の両方の遷移がすべてのステップに存在し、完全なグリッド パーティションが生成されます。 このアルゴリズムは、すべての個別の座標境界でカットを正しく出力します。 

微妙なケースとしては、複数のローソク足が同じ行を共有しているが、異なる列がある場合です。 この構造は、その列内の水平方向のカットを回避し、完全に垂直方向の分離に依存しています。これは、各最終セルにキャンドルが 1 つだけ含まれるという要件と一致しています。
