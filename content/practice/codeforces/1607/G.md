 ## 解決策
 ## 問題の理解

 魚と肉の不均衡を最小限に抑えるために、テイスターがいくつかの料理から食べる量を分配するように求められます。 各料理には一定量の魚と肉が含まれています。 テイスターは正確に食べなければなりません`m`各料理からグラムを選択し、その料理から魚と肉の任意の組み合わせを選択します。 目標は、試食者が食べた後に食べた魚の総量と肉の総量との絶対的な差を最小限に抑えることです。 

入力として、各テスト ケースは次のようになります。`n`料理と量`m`テイスターはそれぞれの料理を食べ、その後、`n`ペア`(a_i, b_i)`各料理に含まれる魚と肉のグラム数を示します。 出力には、まず達成可能な最小限のバランスが必要であり、次にテイスターが各料理から魚と肉を正確に何グラム食べるかの説明が必要です。 

問題のサイズにより、`n`すべてのテスト ケースで最大 200,000 件、個別の`m`最大 10^6 の値。 これにより、料理ごとに可能なすべての組み合わせを試みるアルゴリズムが除外されます。これは、それが指数関数的になるためです。`m`。 O(n*m) アルゴリズムでも、次の場合には遅すぎます。`m`大きいです。 線形か、最大でも`O(n log n)`テストケースごとのアプローチ。 

考慮すべきエッジケースには、すべての食品が 1 種類である料理が含まれます。`(0, 7)`または`(3, 0)`、および次のような状況`m`1つのコンポーネントの量を超えています。 各料理から魚と肉を半分ずつ食べるという素朴なアプローチは、その料理が 1 種類の必要な量を提供できない場合、または料理間で消費量を再分配することで不均衡をさらに軽減できる場合に失敗する可能性があります。 

## アプローチ

 強引なアプローチでは、各料理に魚と肉の可能な限りの割り当てが試行されます。 それぞれの料理について、あらゆる組み合わせを試してみると`(x_i, y_i)`そのような`x_i + y_i = m`そして`0 ≤ x_i ≤ a_i`、`0 ≤ y_i ≤ b_i`、私たちは生成します`min(a_i, m) + 1`料理ごとの可能性。 横切って`n`料理の場合、これは指数関数的になり、明らかに実行不可能です。 

重要な洞察は、問題が部分集合和問題の変形に帰着するということです。 試食者が各料理から食べられる「余分な魚」を間隔として定義すると、`[max(0, m - b_i), min(a_i, m)]`、この範囲内でのあらゆる選択が、消費される魚の総量に影響します。 させる`total_extra`これらの魚の寄与の合計であるため、魚の合計から肉の合計を差し引いた値をできるだけゼロに近づけたいと考えています。 すべての料理の魚と肉の合計を計算し、許容範囲内で各料理から食べる魚の量を調整することで、達成可能な最小限の不均衡を検討できます。 

この洞察により、貪欲で線形な時間配分が可能になります。つまり、各料理からの最小および最大の魚の寄与の累計を保持します。 次に、目標は、合計が魚と肉の合計から必須の肉を除いた半分にできるだけ近くなるように、実際の魚の量を選択することです。 これは、それぞれの料理で食べる魚を許容範囲内で貪欲に調整し、全体の差のバランスをとるようにすることで実現できます。

 ## アルゴリズムのチュートリアル

 1. 各料理について、テイスターが消費できる魚の最小グラムと最大グラムを計算します。次式で与えられます。`lo_i = max(0, m - b_i)`そして`hi_i = min(a_i, m)`。 肉の残りグラムは自動的に計算されます。`m - x_i`。 
2. すべての魚の合計を計算します。`sum_a`そしてすべての肉`sum_b`すべての料理にわたって。 テイスターの介入がなかった場合の最初の不均衡は、`|sum_a - sum_b|`。 
3. 変数を初期化する`target_adjustment`テイスターが食べた総食物の半分からマイナスしたものに等しい`sum_a`。 これは、私たちが目指す魚肉の差の純変化を表しています。 
4. ディッシュを反復処理し、貪欲に割り当てます`x_i`魚のグラム数`[lo_i, hi_i]`総魚数を次の値に近づけるには`target_adjustment`。 各ステップでクランプします。`x_i`許容間隔に合わせて調整します`target_adjustment`それに応じて。 
5. すべての料理を処理した後、食べた魚の合計と調整を加えた合計の不均衡は、可能な限りゼロに近くなります。 最小バランスと選択された値を出力します`(x_i, m - x_i)`各料理のペア。 

効果がある理由: 各料理は、魚の摂取可能範囲に制限を設けています。 世界的な目標に近づくために、これらの範囲内で魚を貪欲に選択することで、合計が絶対差を最小化する値にできるだけ近くなるようにします。 各選択は実行可能な範囲内にとどまるため、解決策は常に有効です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        input()  # blank line
        n, m = map(int, input().split())
        a, b = [], []
        for _ in range(n):
            ai, bi = map(int, input().split())
            a.append(ai)
            b.append(bi)
        
        # Step 1: compute allowed fish range for each dish
        lo = [max(0, m - b[i]) for i in range(n)]
        hi = [min(a[i], m) for i in range(n)]
        
        total_lo = sum(lo)
        total_hi = sum(hi)
        total_fish = sum(a)
        total_meat = sum(b)
        
        # target: total fish eaten should ideally be close to (total_fish + total_meat)/2
        diff = total_meat - total_fish + n * m  # initial diff if we eat lo[i] fish from each
        # final total fish after eating lo[i] fish from each = total_lo
        # extra fish we can distribute = total_hi - total_lo
        extra_needed = (total_fish + total_meat + n * m) // 2 - total_lo
        
        # clamp extra_needed to feasible
        extra_needed = max(0, min(extra_needed, total_hi - total_lo))
        
        res = []
        for i in range(n):
            take = lo[i] + min(extra_needed, hi[i] - lo[i])
            extra_needed -= min(extra_needed, hi[i] - lo[i])
            res.append((take, m - take))
        
        total_fish_eaten = sum(x for x, y in res)
        total_meat_eaten = sum(y for x, y in res)
        balance = abs(total_fish_eaten - total_meat_eaten)
        
        print(balance)
        for x, y in res:
            print(x, y)

if __name__ == "__main__":
    solve()
```この解決策は、入力を読み取り、各料理に対して実行可能な魚の間隔を計算することから始まります。 貪欲な割り当てでは、目標の差に近づくためにこれらの間隔内で追加の魚を分配し、最終的に最小バランスと皿ごとの割り当ての両方を出力します。 値をクランプし、正確な合計を確保するために注意が払われます`m`一皿あたりのグラム数。
