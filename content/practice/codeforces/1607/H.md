 ## 解決策
 ## 問題の理解

 私たちには、数グラムの魚と数グラムの肉からなる一連の料理が与えられます。 すべての料理について、テイスターは一定の総量の食物を消費しますが、その料理からどれだけの魚とどれだけの肉を食べるかを選択できます。 試食後、残りの魚と肉が同じであれば、2 つの料理は同じとみなされます。 目標は、味見者が各料理からどれだけの魚や肉を食べるかを選択し、結果として得られる個別の料理の数を最小限に抑えることです。 

各テスト ケースでは、料理の数、各料理の最初の魚と肉の量、テイスターが食べなければならない合計グラムが提供されます。 出力には、テイスティング後の最小限の個別の料理と、テイスターの実際の食事計画が必要です。 

制約により、すべてのテスト ケースで合計最大 200,000 の料理が許可され、各料理の魚と肉の量は最大 100 万になります。 すべての料理の組み合わせについて、食べられる食べ物のすべての可能な割り当てを比較するという単純なアプローチでは、可能性の数が二次関数的に増加するため、あまりにも遅すぎます。`n`。 テイスターはそれぞれの料理の限界を尊重しなければなりません。`0 <= fish eaten <= a_i`そして`0 <= meat eaten <= b_i`、合計を食べると、トリッキーなエッジケースが発生する可能性があります`m_i`どちらのコンポーネントよりも小さいです。 たとえば、料理に次のようなものがある場合、`(2, 2)`魚や肉のグラム数と`m_i=3`、テイスターは魚と肉に分けて3グラムを食べる必要があります。 選ぶとしたら`(3, 0)`または`(2, 1)`残りの皿を任意に変更しますが、間違った割り当てを選択すると、複数の皿が同じ最終状態に崩れることを防ぐ可能性があります。 

明らかではないエッジケースとしては、魚や肉がまったく含まれていない料理や、`m_i`はコンポーネントの 1 つと正確に等しいため、特定の割り当てが強制されます。 たとえば、料理`(0, 5)`と`m_i=3`しか持つことができない`(0, 3)`食べて、去る`(0, 2)`後ろに。 これらの境界を無視した不用意な実装は、無効な結果を生成する可能性があります。 

## アプローチ

 強引なアプローチでは、テイスターが各料理を食べることができるすべての可能な方法を列挙し、考えられるすべての方法を生成します。`(remaining_fish, remaining_meat)`ペアを作成し、個別の最終料理を数えます。 最終的な種類はこれらのペアによって決定されるため、これは機能しますが、サイズが大きい場合は失敗します。`n`各料理には最大まであるので、`m_i + 1`可能性があり、指数関数的な検索スペースが生成されます。 と`n`2*10^5 までは不可能です。 

重要な観察は、個別の料理の数を最小限に抑えるために、できるだけ多くの料理に同じ魚と肉が残るようにしたいということです。 各料理には、どれくらいの魚を食べられるかについての実行可能な範囲があります。`max(0, m_i - b_i)`に`min(a_i, m_i)`。 そうすると残った魚は`a_i - eaten_fish`そして残った肉は`b_i - eaten_meat = b_i - (m_i - eaten_fish)`。 私たちが選ぶなら`eaten_fish`この実現可能な範囲内で、結果として`(remaining_fish, remaining_meat)`整数格子内の直線に沿った値を取ることができます。 

この洞察により、可能であればすべての料理の実行可能な範囲内にある残りの魚の単一の値を見つけるとして問題を扱うことができます。 具体的には、すべての料理について残りの魚の最小値と最大値を計算します (`a_i - min(a_i, m_i)`そして`a_i - max(0, m_i - b_i)`) そして、これらの範囲の交点を求めます。 この交差内の値はすべて、すべての料理の残りの魚として使用でき、最小の種類が保証されます。 交差部分が空の場合、最小の種類は 2 です。つまり、料理の半分には実行可能な範囲内の値を選択し、残りには別の値を選択します。

 ## アルゴリズムのチュートリアル

 1. 各料理について、試食後に残る可能性のある最小および最大の魚を計算します。 テイスターは少なくとも食べることができます`max(0, m_i - b_i)`魚とせいぜい`min(a_i, m_i)`魚。 残った魚は、`a_i - eaten_fish`、実行可能な間隔を与える`[a_i - min(a_i, m_i), a_i - max(0, m_i - b_i)]`。 
2. これらすべての間隔を取得し、すべての皿の交差を計算します。 させて`low`すべての間隔の下限の最大値であること、および`high`すべての上限の最小値になります。 
3. もし`low <= high`, すべての料理に共通する残りの魚の値が存在します。 選ぶ`remaining_fish = low`各料理の食べた魚を次のように計算します。`a_i - remaining_fish`。 それから`eaten_meat = m_i - eaten_fish`。 結果として得られる残りの料理はすべて同じであるため、最小の種類は 1 です。 
4. もし`low > high`、間隔は交差しません。 独自の間隔を使用して、各料理に実行可能な残りの魚を個別に選択します。 最小の種類は少なくとも 2 です。簡単な戦略は、各料理の下限を選択することです。 結果として残る残りの皿は、最大で 2 つの異なるパターンに分類されます。 
5. 最小の種類とそれに続くテイスターの食事計画を出力する`(eaten_fish, eaten_meat)`料理ごとに。 

これが機能する理由: 各料理の実行可能な残りの魚の間隔を表し、それらを交差させることで、すべての料理に対して同時に有効な値を確実に選択します。 これにより、テイスターが正確に食べることが保証されます`m_i`各料理からの料理を選択し、残りの料理を同じものにできるため、多様性が最小限に抑えられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        input()  # blank line between test cases
        n = int(input())
        a, b, m = [], [], []
        for _ in range(n):
            ai, bi, mi = map(int, input().split())
            a.append(ai)
            b.append(bi)
            m.append(mi)

        low = -1_000_000_000
        high = 1_000_000_000
        for i in range(n):
            min_remain_fish = a[i] - min(a[i], m[i])
            max_remain_fish = a[i] - max(0, m[i] - b[i])
            low = max(low, min_remain_fish)
            high = min(high, max_remain_fish)

        res = []
        if low <= high:
            remaining_fish = low
            for i in range(n):
                eaten_fish = a[i] - remaining_fish
                eaten_meat = m[i] - eaten_fish
                res.append((eaten_fish, eaten_meat))
            print(1)
        else:
            for i in range(n):
                eaten_fish = a[i] - (a[i] - min(a[i], m[i]))
                eaten_meat = m[i] - eaten_fish
                res.append((eaten_fish, eaten_meat))
            print(2)
        for x, y in res:
            print(x, y)

if __name__ == "__main__":
    solve()
```このソリューションはまず入力を解析し、料理情報をリストに保存します。 各料理の実行可能な残りの魚の間隔が計算され、間隔の交差が決定されます。 共通の値が存在する場合は、それが選択されます。 それ以外の場合は、単純なフォールバックが使用されます。 テイスターの食事計画は、これらの選択された残りの魚の量から導き出されます。 各料理の境界を尊重し、食べた料理の合計が同じになるように注意が払われます。`m_i`。
