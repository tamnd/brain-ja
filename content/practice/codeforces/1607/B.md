 ## 解決策
 ## 問題の理解

 バッタの動きを数直線上でシミュレーションするように求められます。 バッタはある整数座標から開始します$x_0$そして、離散的な分ごとにジャンプします。 ジャンプ距離はステップごとに 1 ずつ増加します。最初のジャンプは 1、2 回目は 2、3 回目は 3 というように増加します。 ジャンプの方向は、現在位置のパリティによって決まります。バッタが偶数の座標にある場合、左にジャンプします。 奇数の座標にある場合は、右にジャンプします。 タスクは、正確な後の最終座標を決定することです。$n$ジャンプします。 

入力は大規模です:$x_0$まで可能です$10^{14}$絶対値で、そして$n$までにすることもできます$10^{14}$。 これにより、ジャンプの単純なシミュレーションが除外されます。これは、1 つずつ反復する必要があるためです。$10^{14}$これは、1 秒の時間制約の許容限界をはるかに超えています。 代わりに、最終的な位置を効率的に計算できるパターンまたは式を特定する必要があります。 

重要な観察は、ジャンプ方向は現在位置のパリティのみに依存し、距離は連続する整数であるということです。 これは、複数のジャンプの影響が、奇数と偶数の整数の累積和を分析することによって、または正味効果のモジュロ 4 を考慮することによって決定できることを示唆しています。注目すべきエッジ ケースには、0 から始まる、負の座標、非常に大きいなどがあります。$n$、 そして$n = 0$ジャンプが行われない場所。 

たとえば、次から始まります$x_0 = 0$と$n = 2$シーケンスは次のようになります。左に 1 から -1 にジャンプ (偶数 -> 左)、右に 2 から 1 (奇数 -> 右) にジャンプします。 単純なシミュレーションは小規模な場合に機能します$n$、しかし大きい場合は失敗します$n$。 

## アプローチ

 ブルート フォースのアプローチは簡単です。ジャンプの回数を繰り返します。$n$、パリティに基づいて方向を決定し、位置を更新します。 これは小規模な場合に機能します$n$、しかしそれ以来$n$到達できる$10^{14}$、時間計算量$O(n)$全く実現不可能です。 

最適なアプローチは、動きの中で繰り返されるパターンを検出するかどうかにかかっています。 4 つの連続したジャンプの効果は、開始パリティに応じて、正味変位の観点からサイクルを形成することに注意してください。 たとえば、偶数から開始すると、最初の 4 つのジャンプで位置が変わります。$-1, +2, -3, +4$順に実行され、正味変位は +2 になります。 同様に、パターンは 4 つのジャンプごとに繰り返されます。 減らすことで$n$モジュロ 4 を計算し、完全なサイクルを個別に合計すると、テスト ケースごとに一定時間で最終位置を計算できます。 

ブルート フォース シミュレーションは、パリティ ベースのジャンプのルールに正しく従うため機能しますが、次の場合には失敗します。$n$非常に大きいです。 ジャンプが予測可能な 4 ステップのパターンを形成していることを観察すると、各ジャンプをシミュレートせずに最終的な座標を計算できます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取り、各ペアを反復処理します。$(x_0, n)$。 もし$n = 0$、結果はすぐにわかります$x_0$ジャンプが起こらないからです。 
2. 開始位置のパリティを決定する$x_0$。 もし$x_0$が偶数の場合、「偶数開始」ジャンプ パターンを使用します。 奇数の場合は、「奇数開始」パターン。 
3. 4 つのジャンプの完全なサイクル数を計算します。$k = n // 4$。 各サイクルの正味変位は、開始パリティに応じて +2 または -2 になります。 
4. 残りのジャンプの変位を計算します。$r = n \% 4$。 サイクル パターンに基づいて残りの移動を列挙し、それらの寄与を合計変位に追加します。 
5. 完全なサイクルからの累積変位を加算し、残りを初期位置にジャンプして最終座標を取得します。 

これが機能する理由: 4 を法とするジャンプのシーケンスにより、ディスプレイスメントの繰り返しパターンが生成されます。 開始位置のパリティによって最初のジャンプの方向が決まり、それによって後続の 3 つのジャンプの符号パターンが固定されます。 ジャンプを 4 つのサイクルにグループ化することで、潜在的に膨大な数の演算が単純な算術計算に削減されます。 この不変パリティによってジャンプ方向が決まり、4 つの連続したジャンプによって固定ネットの動きが生成され、正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def final_position(x, n):
    if n == 0:
        return x
    parity = x % 2
    cycles = n // 4
    remainder = n % 4
    pos = x
    if parity == 0:
        pos += cycles * 2
        if remainder == 1:
            pos -= n
        elif remainder == 2:
            pos += 1
        elif remainder == 3:
            pos += n + 1
    else:
        pos -= cycles * 2
        if remainder == 1:
            pos += n
        elif remainder == 2:
            pos -= 1
        elif remainder == 3:
            pos -= n + 1
    return pos

t = int(input())
for _ in range(t):
    x0, n = map(int, input().split())
    print(final_position(x0, n))
```コードはまずジャンプがゼロかどうかをチェックします。 次に、パリティを計算し、完全な 4 ジャンプ サイクルがいくつあるか、および残りのジャンプがいくつあるかを計算します。 サイクルと残りのジャンプからのディスプレイスメントを個別に適用します。 開始パリティに応じて、符号を正しく処理するように注意が必要です。 演算は純粋に算術演算であり、テスト ケースごとに一定の時間が保証されます。
