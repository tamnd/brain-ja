 ## 解決策
 ## 問題の理解

 等間隔の位置でサンプリングされた地形の高さの長いシーケンスが与えられます。 このシーケンスから、高さが最初に j まで減少せず、j 以降増加しないように、i < j < k で 3 つのインデックス i、j、k を選択することによって定義される特別な種類の「ピーク」を特定したいと考えています。 言い換えれば、シーケンスは j を中心とする丘の形を形成しますが、両側に平坦部が認められます。 

有効なピーク トリプルの品質は、上部の絶対的な高さではなく、ピークが両側と比較してどれだけ高いかによって測定されます。 具体的には、ピーク高さ hj と左端点 hi の差、および hj と右端点 hk の差を調べ、これら 2 つの値のうち小さい方を採用します。 この値は丘の最も弱い側を表しており、すべての有効なピークにわたって最大化したいと考えています。 

入力サイズは最大 200000 ポイントまで可能で、トリプルの 3 次または 2 次の列挙は直ちに除外されます。 すべての i、j、k の組み合わせを明示的にテストしようとするソリューションでは、N^3 または N^2 程度の演算が必要になりますが、これは実行可能な限界をはるかに超えています。 N log N の解であっても、前処理やチェックにおける隠れた二次関数の動作を避けるために、慎重に構造化する必要があります。 

各 j を中心とするすべての可能なピークを事前に計算し、すべての i と k のペアを外側にスキャンする単純なアプローチは、シーケンスが単調または単調に近い場合に大きく失敗します。これは、中心ごとの有効な (i, k) ペアの数が O(N) になり、再び 2 次の合計作業が発生するためです。 

エッジケースは、配列が一定またはほぼ一定の場合に発生します。 たとえば、すべての高さが等しい場合、技術的にはすべてのトリプルは平坦なピークであり、差 hj − hi と hj − hk が両方ともゼロであるため、答えはゼロでなければなりません。 もう 1 つの特殊なケースは、厳密に増加するシーケンスまたは厳密に減少するシーケンスです。 厳密に増加する配列では、右側が平坦であるか慎重に選択されたピークのみが有効なピークとなるため、不注意に解釈すると、有効なピークが存在しないと誤って仮定されたり、正の値が返されたりする可能性があります。 

## アプローチ

 定義を直接解釈すると、中央のインデックス j を固定し、最適な i と k を見つけるために左右に拡張しようとすることが示唆されます。 固定 j の場合、j に対する単調制約を尊重しながら、hi が小さくなるように i をできるだけ左に、k を hk が小さくなるようにできるだけ右にしたいと考えます。 これは、両側の極端な値が局所的な構造よりも重要であることをすでに示唆しています。 

ブルートフォースソリューションでは、各 j の周りのすべての可能なペア (i, k) を列挙し、シーケンスが j まで減少せず、j 以降増加しないかどうかを確認します。 単調な妥当性チェックを事前に計算したとしても、各センターは依然として両側で O(N) 個の候補をスキャンする必要がある可能性があります。 これにより、全体の複雑さは O(N^2) 以上になります。 

重要な構造的観察は、条件 hi ≤ hj ≥ hk により、hj が選択されたエンドポイントに対する極大値として機能するように強制されることですが、順序付け制約は、固定 j に対する最適な i と k が、単調な実現可能性を維持しながら、左側と右側で到達可能な最小値によって決定されることを意味します。 すべてのエンドポイントを考慮するのではなく、各位置について、単調な構造の左側と右側から達成可能な最適な「サポート」を知るだけで済みます。

これは古典的な変換になります。配列を最大の非減少ランと非増加ランに分解します。 これらの構造内で、位置 j ごとに、j まで減少せずに左方向にどこまで拡張できるかを計算できます。また、同様に、j から増加せずに右方向にどこまで拡張できるかを計算できます。 これらの境界が分かると、各 j の最適な i と k は、これらの単調領域の端点によって決定されます。 残りのタスクは、これらの事前計算された境界値のみを使用して、各 j の候補値を評価することになります。 

ブルート フォースは、重複する区間にわたって単調な実行可能性を繰り返し再計算するため失敗します。一方、最適化されたアプローチでは、これらの区間が到達可能な極値を記録する線形時間スキャンに圧縮されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (i、j、k をすべてチェック) | O(N^3) | お(1) | 遅すぎる |
 | スキャンによるセンター拡張 | O(N^2) | お(1) | 遅すぎる |
 | モノトーン境界の前処理 | O(N) | O(N) | 承認済み |

 ## アルゴリズムのチュートリアル

 単調制約が各位置から自然にどこまで伸びるかをキャプチャする 2 つのヘルパー配列を構築します。 

1. 各インデックス j について、非減少条件が崩れる左に最も近い位置を計算します。 現在の非減少セグメントの開始を追跡するポインターを維持しながら、左から右にスキャンします。 これにより、j に関連する hi 値を安全に選択できる左側の境界が得られます。 
2. 各インデックス j について、非増加条件が崩れる右側の最も近い位置を対称的に計算します。 右から左にスキャンし、増加しない各セグメントの開始を追跡するポインターを維持します。 これにより、j に関連する hk 値を安全に選択できる適切な境界が得られます。 
3. 各候補ピーク中心 j について、これらの境界を使用して、j に対する単調制約を満たす最良の左端点 i と右端点 k を特定します。 内側に移動しても hi または hk が増加するだけで目的が悪化するため、最良の選択は常に有効な単調セグメントの端にあります。 
4. 各 j について、候補ピーク値を min(hj − h[left_best[j]], hj − h[right_best[j]]) として計算します。 
5. すべての j の最大値を返します。 

重要な考え方は、単調な妥当性が強制されると、最適なエンドポイントは常に到達可能な極端な位置によって決定されるため、内部スキャンは必要ないということです。 

### なぜ効果があるのか

 このアルゴリズムは、有効なピーク形状が両側の単調性によって制約されるという事実に基づいています。 j で終わる非減少プレフィックス内では、可能な限り最小の hi がそのセグメントの先頭に発生します。 j に近い i をその他に選択すると、hi が大きくなるか等しいため、hj − hi を改善することはできません。 同じロジックが右側にも対称的に適用されます。 これにより、潜在的に 2 次の検索空間が方向ごとに 1 つのパスに縮小され、すべての最適な構成が境界構成によって表現されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    h = list(map(int, input().split()))

    # left[i] = start of non-decreasing segment ending at i
    left = [0] * n
    for i in range(1, n):
        if h[i] >= h[i - 1]:
            left[i] = left[i - 1]
        else:
            left[i] = i

    # right[i] = end of non-increasing segment starting at i
    right = [0] * n
    right[n - 1] = n - 1
    for i in range(n - 2, -1, -1):
        if h[i] >= h[i + 1]:
            right[i] = right[i + 1]
        else:
            right[i] = i

    ans = 0
    for j in range(n):
        l = left[j]
        r = right[j]
        # choose endpoints
        if l < j and j < r:
            ans = max(ans, min(h[j] - h[l], h[j] - h[r]))

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では 2 つの線形スキャンが構築されます。 の`left`配列は、各位置を現在の非減少実行の先頭に圧縮します。 これにより、有効な左端点がそのセグメント内に存在することが保証され、最良の候補はセグメントの最初の要素になります。 

の`right`配列は、非増加実行に対しても同じことを行い、各インデックスからの降下が終了する場所を格納します。 最後のループでは、考えられるすべての中心 j を一定時間で評価します。 

微妙な点はコンディションです`l < j and j < r`。 これにより、セグメントが実際に左側と右側で有効なピーク形状を形成することが保証されます。 これがないと、フラットまたは縮退したセグメントが誤って意味のない値を与える可能性があります。

 ## 特殊なケース

 次のような厳密に単調なシーケンスの場合`1 2 3 4 5`、すべてのインデックスの左側の境界はインデックス自体まで折りたたまれますが、右側の境界は最初の違反まで最後まで延長されます。 これにより、有効なトリプルがピークの両側を形成することがなくなり、厳密な左右の要件を同時に満たす j がないため、アルゴリズムは正しくゼロを返します。 

次のような定数配列の場合`7 7 7 7`、すべての位置が同じ左右の境界を共有します。 計算された差はどこでもゼロになり、最大値はゼロのままです。 モノトーン セグメント圧縮により、すべてのトリプルが正の高さゲインを生成するものとして誤って扱われることがなくなります。 

のような形状の場合`1 3 2 4 3`、複数の局所的なピークが存在します。 このアルゴリズムは各中心候補を個別に評価しますが、境界圧縮により、各ピークが真の制限エンドポイントを使用して評価されることが保証されるため、重複する部分構造を列挙することなく、グローバル最大値が正しく特定されます。
