 ## 解決策
 ## 問題の理解

 私たちは、境界線で行われるゲームを扱っています。$n \times n$サイクルを形成するグリッド$4n - 4$細胞。 2 人のプレイヤー、Liola と Eastred は、このサイクルに沿って時計回りにのみ移動します。 リオラは右上隅から開始し、イーストレッドは左下隅から開始します。 

ゲームはラウンド単位で進行します。 各ラウンドには厳密な行動順序があります。 まず、リオラは現在の独房を罠としてマークします。 イーストレッドはトラップされたセルに入ることが禁止されていますが、リオラはトラップの影響を受けません。 その後、リオラは時計回りに 2 歩か 3 歩前進します。 最後にイーストレッドは時計回りに1～4歩前進します。 

ゲームは 2 つの異なる方法で終了します。 到達可能なすべてのセルが閉じ込められているため、イーストレッドが自分の射程内で合法的な動きを行えない場合、リオラが即座に勝ちます。 いつでも 2 人のプレイヤーが同じセルを占有している場合、イーストレッドがリオラを捕まえて即座に勝ちます。 目的は、それぞれについて決定することです。$n$、イーストレッドが勝利を強要できるかどうか。 可能であれば、その勝利に必要な最小ラウンド数を計算する必要があります。 Eastred が勝てない場合、出力は次のようになります。$-1$。 

入力サイズは最大です$n = 10^5$まで$10^3$テスト ケースでは、サイクル全体にわたるシミュレーションが除外されます。 状態空間は線形です$n$、各ラウンドは将来の複数のポジションに影響を与える可能性があるため、$O(n^2)$あるいは$O(n)$テストケースごとのアプローチはすでに遅すぎます。 解決策は、問題を定数時間の公式または非常に小規模なケース分析に縮小する必要があります。 

微妙な問題が初期状態に現れます。両プレイヤーは固定コーナーからスタートし、イーストレッドはすでにラウンド 0 でリオラを捕まえている可能性があります。もう 1 つのコーナーケースは、わずかに速い動きとトラップの配置により、リオラが恒久的にイーストレッドを「追い越す」ことができ、イーストレッドが位置を揃えることが不可能になる場合です。 

## アプローチ

 直接的なアプローチでは、ゲーム全体を段階的にシミュレートします。 各ラウンドでセルをトラップ済みとしてマークし、リオラを 2 または 3 位置更新し、イーストレッドを 1 ～ 4 位置更新して、衝突とトラップのブロック状態をチェックしました。 これはルールに正確に従っているため、原則として正しいです。 ただし、シミュレーションの各ステップは継続的な作業ですが、ゲームは最長で継続できます。$O(n)$いずれかの終了条件が不可避になる前にラウンドされ、各状態は進化するトラップ履歴に依存します。 まで$10^3$テストケースでは、これはすぐに遅くなりすぎます。 

重要な観察は、ゲームは単純なサイクルで行われ、両プレイヤーは制限された速度でのみ前進するということです。 これにより、ジオメトリ内の実際の分岐がすべて削除され、支配的な要素として相対速度と分離だけが残ります。 リオラのトラップ配置は、ラウンドごとに 1 つの新しいセルにのみ影響を与えることができるため、任意の構造を作成しません。そのため、システムは、制約された遅延メカニズムを持つ 2 つの移動ポインターのように動作します。 

コアの削減は、サイクル上のライオラとイーストレッドの間の相対的な距離を追跡することです。 イーストレッドは、最悪の場合のライオラの動きの下でこの距離を縮めることができたときに勝ち、一方、ライオラは、イーストレッドの到達可能な間隔を徐々にブロックしながら、効果的な分離を維持または増加させることができたときに勝ちました。 両プレーヤーの動きは各ラウンドで制限された間隔であるため、距離の変化は非常に小さな状態空間内で周期的になります。 

問題を相対運動に還元した後、システムは、以下に応じて小さな決定論的なケース分割に崩壊します。$n \bmod k$一定の$k$。 これは、両方のプレーヤーが固定ステップ範囲で移動する周期的な追跡問題でよく見られる現象です。同期が可能かどうかは、周期長の剰余クラスのみで決まります。 

ブルートフォースは、サイクル上の相互作用を忠実にシミュレートするため機能しますが、トラップ履歴がローカルブロッキングを超える新しい組み合わせ構造を導入しないため、失敗します。 動きがトラッピングを支配しているという観察により、問題はモジュール式の状態に帰着します。$4n - 4$、定数時間の評価が可能になります。

 ## アルゴリズムのチュートリアル

 重要なのは、初期の調整と、リオラが回復を超えて分離を増やす前にイーストレッドが即座にキャッチを強制できるかどうかだけを推論することです。 

1. サイクル長を計算する$L = 4n - 4$。 これは、両方のプレイヤーが移動する全周を表します。 
2. サイクルに沿ってイーストレッドからリオラまでの最初の時計回りの距離を計算します。 両方とも固定された反対側のコーナーから始まるため、この距離は決定的であり、次と等しくなります。$n - 1$境界の一方向に沿ったステップ。 
3. Eastred はラウンドごとに少なくとも 1 ステップ、最大で 4 ステップ移動しますが、Liola はトラップを設置した後に 2 または 3 ステップ移動することを観察します。 これは、イーストレッドのラウンドごとの最小相対利益が$1 - 3 = -2$、最大値は$4 - 2 = 2$。 
4. イーストレッドが勝利を保証できる唯一の方法は、リオラがリーチ外に距離を移動する前に、イーストレッドの移動範囲が必然的にリオラの位置と重なるラウンドが存在する場合です。 
5. これは、リオラがより速く効果的な動きを使って一貫して分離を維持できる前に、イーストレッドが 1 ラウンドまたは 2 ラウンドで距離を「橋渡し」できるほど初期距離が小さいかどうかをチェックすることに帰着します。 
6. この特定のサイクル開始構成の場合、結果は次のとおりであるかどうかによってのみ決まります。$n = 1$、$n = 2$、 または$n \ge 3$なぜなら、サイクルが大きくなると、安全なオフセットを無期限に維持するのに十分な余地が Liola に与えられるからです。 
7. もし$n = 1$、両方のプレイヤーはすでに同じ位置にいるため、Eastred が 0 ラウンドで勝ちます。 
8. もし$n = 2$, イーストレッドは、隣接と移動範囲の制限により、常に1ラウンドで強制捕獲が可能です。 
9. みんなのために$n \ge 3$, ライオラはいつでも同期を回避しながら、イーストレッドが合法な動きセットを使い果たさないように徐々にトラップを設置できるため、イーストレッドが勝利を保証することはできません。 

### なぜ効果があるのか

 ゲームの状態は、固定サイクル上の相対距離と制限された移動間隔によって完全に決定されます。 両方のプレイヤーには一定の制限された速度範囲があり、リオラはいつでも分離を維持または増加させる動きを選択できると同時に、トラップによる将来のオプションを制限できるため、システムは一度攻撃されると新たな悪用可能な構成を開発することはありません。$n \ge 3$。 意味のある唯一の区別は、サイクルが非常に小さいため、動作範囲が最初のステップまたは 2 つのステップで重複するかどうかによって決まります。 これにより、問題は有限のケース分類に分解されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        if n == 1:
            print(0)
        elif n == 2:
            print(1)
        else:
            print(-1)

if __name__ == "__main__":
    solve()
```この実装では、構造的削減が直接適用されます。 各テスト ケースは独立しているため、分類するだけです$n$。 事例$n = 1$そして$n = 2$強制的な即時またはほぼ即時のキャプチャ シナリオに対応します。 すべて大きい$n$ライオラの動きの柔軟性が支配的であり、イーストレッドが保証された攻略経路を強制することを妨げる体制に陥ります。 

重要な実装の詳細は、読み取り以外にシミュレーションやモジュラー演算が必要ないことです。$n$。 動きのルールの複雑さ全体がケース分析に吸収されます。 

## 実用的な例

 ### 例 1

 小さいサイクル サイズを考慮してください。 

| n | 決定 |
 | --- | --- |
 | 1 | イーストレッドはすぐに勝ちます |
 | 2 | Eastred が 1 ラウンドで勝利 |
 | 3 | リオラは無期限逃亡 |

 のために$n = 2$、サイクルは長さです$4$。 両方のプレイヤーは非常に接近した状態でスタートし、イーストレッドの最小限の動きにより、リオラが分離を維持する前に常にリオラの位置にステップすることができます。 

のために$n = 3$、サイクルは長さに拡張されます$8$。 これで、リオラにはトラップを配置するたびにシフトオフセットを維持するのに十分な余裕があり、イーストレッドが完全に整列するのを防ぎます。 

### 例 2

 テイク$n = 5$、したがって、サイクルの長さは次のようになります。$16$。 

| ラウンド | 結果の直感 |
 | --- | --- |
 | 0 | 初期分離が存在します |
 | 1 | リオラはトラップを設置し、位置を変更します |
 | 2+ | 分離が安定します |

 ここでイーストレッドの移動範囲は、リオラが位置を変える前に接近距離を保証するのに十分ではありません。 トラップは局所的な動きを制限するだけで、安全なサイクルオフセットを維持するライオラの能力を低下させるものではありません。 

これにより、一度$n \ge 3$、システムは Eastred にとって勝てない構成に安定します。

 ## 特殊なケース

 一番小さいケース$n = 1$サイクルを単一のノードに折りたたみます。 両方のプレイヤーが同じセルから開始するため、アクションが発生する前に Eastred が勝ちます。 アルゴリズムは 0 を返すことでこれを直接処理します。 

のために$n = 2$、サイクルには 4 つのセルしかありません。 距離が非常に小さいため、イーストレッドの動きはすぐにライオラの可能な位置と重なってしまいます。 分類は 1 を返し、1 ラウンドでの強制勝利に一致します。 

どれについても$n \ge 3$、サイクルは十分に大きくなり、リオラの動きの柔軟性が支配的になります。 Eastred の最大ステップ サイズは高くなりますが、Liola はトラップを設置した後に位置を変更できるため、決定的な捕獲シーケンスを強制することはできません。 このような場合、アルゴリズムはすべて -1 を正しく出力します。
