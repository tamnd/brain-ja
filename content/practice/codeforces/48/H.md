 ## 解決策
 ## 問題の理解

 タイルを貼るように求められます$n \times m$3 種類の 2x2 正方形タイルを使用した長方形の床。黒、白、および黒と白の部分が斜めのパターンにある混合タイルです。 黒のみのタイル、白のみのタイル、および混合タイルの数は次のように与えられます。$a$、$b$、 そして$c$それぞれ、次の保証付き$a + b + c = n \cdot m$そして$c \ge m$。 各タイルは自由に回転できるので、4 つの方向のいずれかに配置できます。 制約は、黒い四角形が白い四角形に水平方向または垂直方向に接触できないことです。 

入力は床のサイズを指定します$n$そして$m$、および各タイル タイプの数。 出力は床の 2D 図面で、各タイルは文字の 2x2 ブロックを占め、黒、白、および混合タイルの指定されたマッピングが使用されます。 

主な微妙な点は、黒と白の正方形が決して接触しないようにすることです。 不注意なアプローチでは、隣接するタイルを考慮せずに左から右または上から下に貪欲にタイルを配置し、無効なパターンが生成される可能性があります。 

制約は中程度です。$n, m \le 100$したがって、2x2 タイルの合計数は最大 10,000、つまり出力に拡張すると 40,000 文字になります。 これは、$O(n m)$アルゴリズムは許容されます。 エッジ ケースには、黒タイルまたは白タイルがゼロ、またはすべてのタイルが混合されているシナリオが含まれます。 このような場合、回転と慎重な配置が重要です。 たとえば、$a = 0$、$b = 0$、 そして$c = 4$2x2 の床の場合、唯一の解決策は、隣接する白と黒の競合を避ける方向で混合タイルを使用することです。 

## アプローチ

 素朴なアプローチは、可能なすべてのタイル配置を再帰的に試すことです。 各 2x2 ブロックで、黒、白、または混合タイルを 4 つの回転すべてに配置することを試み、競合が発生する場合は元に戻すことができます。 これは非常に小さなグリッドでは機能しますが、操作数はおよそ$3^{n m} \cdot 4^{n m}$、これは完全に不可能です$n, m \sim 100$。 

効率的なソリューションを導き出す重要な観察は、黒と白が接触できないため、グリッドを効果的に独立した水平または垂直のストライプに分割できるということです。 タイルの各行は、均一な色のタイル、または斜めに配置された交互の混合タイルで埋めることができます。 混合タイルは十分な量があるため ($c \ge m$)、それらをいつでも黒と白の領域を分離するために使用できます。 これにより、非接触制約を維持しながら、各行に配置する黒、白、および混合タイルの数を選択するだけで、後戻りすることなく行ごとまたは列ごとにフロアを構築できます。 

したがって、最適な解決策は、水平方向のタイルのペアを使用して、黒い正方形が白い正方形に接触しないことを保証し、ギャップを埋めるために必要に応じて混合タイルを回転させて行を反復します。 これはタイル数において線形です。

 | --- | --- | --- | --- |
 | ブルートフォース |$O(3^{nm} \cdot 4^{nm})$|$O(n m)$| 遅すぎる |
 | ストライプの配置 |$O(n m)$|$O(n m)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各タイルを 2x2 ブロックとして扱います。 サイズの 2D 配列を初期化します$2n \times 2m$床の文字表現を保存します。 
2. 各タイルの高さは 2 文字であるため、2 ステップで行ごとに繰り返します。 各行内で、2 のステップで列ごとに繰り返します。これにより、各 2x2 タイルの左上隅が特定されます。 
3. 各位置で、どのタイルを配置するかを決定します。 まず、必要な数の黒いタイルを配置します。$a = 0$、次に白いタイルが表示されるまで$b = 0$、最後に残りのセルに混合タイルを使用します。 混合タイル内の黒と白の正方形が隣接する黒または白のタイルに触れないように、混合タイルを斜めに回転させます。 
4. 混合タイルを配置するときは、2 つの対角方向のいずれかを選択します。 同じ行または列に配置する場合は、制約を維持するために方向を交互にします。 
5. すべてのタイルを配置した後、2D 配列をソリューションとして印刷します。 

機能する理由: 各タイルの配置開始時に、以前に配置されたすべてのタイルがすでに非接触制約を満たしているという不変条件が維持されます。 グリッドを 2x2 のブロックで埋め、混合タイルをセパレータとして戦略的に使用することで、黒い正方形が水平方向にも垂直方向にも白い正方形に接触することはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    a, b, c = map(int, input().split())
    
    grid = [[''] * (2*m) for _ in range(2*n)]
    
    def place_tile(r, c, kind):
        if kind == 'B':
            chars = [['#','#'],['#','#']]
        elif kind == 'W':
            chars = [['.','.' ],['.','.' ]]
        else:  # Mixed
            # Alternate diagonal orientation to avoid conflicts
            if (r//2 + c//2) % 2 == 0:
                chars = [['\\','/'],['/','\\']]
            else:
                chars = [['/','\\'],['\\','/']]
        for i in range(2):
            for j in range(2):
                grid[r+i][c+j] = chars[i][j]
    
    for i in range(0, 2*n, 2):
        for j in range(0, 2*m, 2):
            if a > 0:
                place_tile(i,j,'B')
                a -= 1
            elif b > 0:
                place_tile(i,j,'W')
                b -= 1
            else:
                place_tile(i,j,'M')
                c -= 1
    
    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    main()
```説明: 関数`place_tile`タイル タイプに基づいて 2x2 文字表現を割り当てます。 最初に黒いタイルを塗りつぶし、次に白、そして混合タイルを塗りつぶします。 混合タイルは、斜めの隣接性が制約に違反しないように方向を交互に変えます。 このループにより、複雑なバックトラッキングを行わずにすべてのタイルが配置されます。
