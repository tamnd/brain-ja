 ## 問題の理解

 3 人のプレーヤーが同時に古典的なジャンケンのジェスチャーの 1 つを選択します。`"rock"`、`"paper"`、 または`"scissors"`。 プレーヤーは、自分のジェスチャーが他の両方のプレーヤーが示すジェスチャーを破った場合にのみ勝ちます。 

つまり、次の状況でのみ勝者が存在します。 

- 1 人のプレーヤーがロックを示し、他の 2 人がチョキを示します。 
- 1 人のプレイヤーがはさみを見せ、他の 2 人が紙を見せます。 
- 1 人のプレーヤーが紙を見せ、他の 2 人が石を見せます。 

他の構成では勝者は生まれません。 

入力はちょうど 3 つの文字列で構成されます。 1つ目はフョードルおじさん、2つ目はマトロスキン、3つ目はシャリッチのものです。 出力は勝者を表す 1 文字です。`"F"`、`"M"`、`"S"`、 または`"?"`誰も一意に勝てない場合。 

プレーヤーは常に 3 人だけで、可能なジェスチャーは 3 つだけであるため、制約は非常に小さいです。 どのソリューションも即座に実行されます。 考えられるすべてのインタラクションを手動でチェックするだけでも、一定の時間がかかります。 本当の課題は、エッジケースを見逃さずにゲーム ロジックを正しく実装することです。 

厄介なのは、多くの州に勝者がいないということだ。 不注意な実装では、常に 1 つが存在する必要があると想定していることがよくあります。 

次の入力を考えてみましょう。```
rock
paper
scissors
```すべてのジェスチャーは、別のジェスチャーに対して勝ちもあれば負けもします。 両方の対戦相手に勝つ人はいないので、正解は次のとおりです。```
?
```単純にペアごとの勝利をチェックする単純な実装では、ここで勝者を誤って宣言する可能性があります。 

もう 1 つの簡単な間違いは、2 人のプレーヤーが同じジェスチャーで引き分けたときに発生します。```
paper
rock
rock
```正しい出力は次のとおりです。```
F
```紙はロックに勝ち、両方の対戦相手がロックを示したので、ヒョードルおじさんは両方を同時に倒します。 

逆の状況も正しく処理する必要があります。```
rock
paper
paper
```さて、正しい答えは次のとおりです。```
M
```たとえ 2 人のプレーヤーが勝利のジェスチャーを示したとしても、ルールに従って唯一の勝者はまだ存在しません。 ゲームではジェスチャーを集合的に行うのではなく、プレイヤーを個別に識別するため、最初のペーパー プレイヤーが勝ちます。 マトロスキンは両方の対戦相手を倒す動きをした唯一のプレイヤーであるため、彼が勝者となります。 

最後に、全員が同じジェスチャーを選択すると、次のようになります。```
scissors
scissors
scissors
```誰も勝者にならないため、出力は次のようになります。```
?
```## アプローチ

 最も直接的なアプローチは、説明どおりにゲームをシミュレートすることです。 各プレイヤーについて、自分のジェスチャが他の両方のプレイヤーのジェスチャを無効にするかどうかを確認します。 そうなれば、そのプレイヤーが勝ちます。 

プレイヤーは 3 人だけなので、この強引なアプローチはすでに完全に機能しています。 次のようなヘルパー ルールを定義できます。 

- ロックははさみを打ちます
 - ハサミは紙を打ちます
 - 紙はロックに勝つ

 次に、すべてのプレーヤーについて、他の 2 人のジェスチャーと比較します。 

少数の比較しか実行しないため、合計の作業量は一定です。 最も単純な実装でも、簡単に制限内に収まります。 

重要な観察は、じゃんけんの構造により、勝利条件が非常に小さくなっているということです。 プレーヤーは、他の 2 つのジェスチャーが同一で、特に勝者のジェスチャーに対して脆弱な場合にのみ勝ちます。 

たとえば:

 - ロックは 2 つのチョキに対してのみ勝ちます
 - チョキは 2 枚の紙に対してのみ勝ちます
 - 紙は 2 つの石に対してのみ勝ちます

 これにより、実装をさらに簡素化できます。 すべての決闘をシミュレーションする代わりに、考えられる 3 つの勝ちパターンを直接確認できます。 

これにより、短くてクリーンな定時間ソリューションが得られます。

 ## アルゴリズムのチュートリアル

 1. 3 つのジェスチャを、フョードル、マトロスキン、シャリッチを表す変数に読み込みます。 
2. どのジェスチャがどのジェスチャを無効にするかを説明するマッピングを作成します。 

-`"rock"`敗北`"scissors"`-`"scissors"`敗北`"paper"`-`"paper"`敗北`"rock"`3. フョードルが他のプレイヤー両方に勝つかどうかを確認します。 

これは、フョードルのジェスチャーがマトロスキンのジェスチャーを破り、シャリッチのジェスチャーも破る場合に当てはまります。 
4. フョードルが勝った場合、印刷します`"F"`そしてやめてください。 
5. マトロスキンについても同じチェックを繰り返します。 

彼のジェスチャーが両方の対戦相手を破った場合、印刷します`"M"`。 
6. Sharic についても同じチェックを繰り返します。 

彼のジェスチャーが両方の対戦相手を破った場合、印刷します`"S"`。 
7. 3 つの条件のいずれも成功しなかった場合は、次のように出力します。`"?"`。 

これには、じゃんけんのようなサイクルや、すべてのジェスチャーが等しい場合が含まれます。 

### なぜ効果があるのか

 ルールでは、ジェスチャーが他の両方のジェスチャーを同時に破った人が勝者と定義されています。 アルゴリズムは、プレーヤーごとにその正確な状態を個別にチェックします。 

じゃんけんの結果は決定的です。 あるジェスチャーが他のジェスチャーを打ち負かすか、そうでないかのどちらかです。 すべての勝者はアルゴリズムによってチェックされる条件を満たさなければならず、チェックされるすべての条件はゲーム ルールと正確に一致するため、アルゴリズムは有効な勝者を見逃したり、無効な勝者をでっち上げたりすることはできません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# solution

f = input().strip()
m = input().strip()
s = input().strip()

beats = {
    "rock": "scissors",
    "scissors": "paper",
    "paper": "rock"
}

if beats[f] == m and beats[f] == s:
    print("F")
elif beats[m] == f and beats[m] == s:
    print("M")
elif beats[s] == f and beats[s] == m:
    print("S")
else:
    print("?")
```プログラムは、ステートメントで要求される固定順序で 3 つのジェスチャを読み取ることから始まります。 使用する`.strip()`入力行に改行文字が含まれるため、これが必要です。 

の`beats`辞書はゲームのルールを直接エンコードします。 例えば：```
beats["rock"] == "scissors"
```ロックがハサミに勝つという意味です。 

各条件は、1 人のプレイヤーが両方の対戦相手に勝つかどうかをチェックします。 例えば：```
beats[f] == m and beats[f] == s
```フョードルのジェスチャーがマトロスキンのジェスチャーとシャリッチのジェスチャーを同時に打ち負かすかどうかを尋ねます。 

勝利条件を満たすことができるプレイヤーは最大でも 1 人であるため、チェックの順序は重要ではありません。 どの条件も一致しない場合、ゲームには唯一の勝者がいないため、プログラムは次のように出力します。`"?"`。 

微妙なポイントは、ネクタイが自然に処理されることです。 入力が次のとおりであるとします。```
paper
rock
rock
```それから：```
beats["paper"] == "rock"
```は両方の対戦相手に当てはまります。したがって、フョードルが正しく勝ちます。

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    f = input().strip()
    m = input().strip()
    s = input().strip()

    beats = {
        "rock": "scissors",
        "scissors": "paper",
        "paper": "rock"
    }

    if beats[f] == m and beats[f] == s:
        print("F")
    elif beats[m] == f and beats[m] == s:
        print("M")
    elif beats[s] == f and beats[s] == m:
        print("S")
    else:
        print("?")

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    out = io.StringIO()
    backup = sys.stdout
    sys.stdout = out

    solve()

    sys.stdout = backup
    return out.getvalue()

# provided sample
assert run("rock\nrock\nrock\n") == "?\n", "sample 1"

# custom cases

assert run("rock\nrock\npaper\n") == "S\n", "Sharic wins"
assert run("rock\npaper\nscissors\n") == "?\n", "cyclic case"
assert run("scissors\nscissors\nscissors\n") == "?\n", "all equal"
