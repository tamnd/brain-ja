 ## 解決策
 ## 問題の理解

 1 から n までの島の線形チェーンが与えられます。 連続するアイランドは i から i+1 までの有向エッジによって接続されており、そのような各エッジには固定コストがあります。 さらに、すべての島 i は、コスト Wi の無向エッジを持つ特別な「エア ノード」に直接接続されており、これにより、任意の島とエア ノード間のテレポートが効果的に可能になります。 

i 日目には、島 1 から i のみに興味があります。 ランダムな「ストーム」により、最初の i-1 エッジの中からチェーン エッジの 1 つの連続ブロックが削除されます。 具体的には、1 ≤ l ≤ r ≤ i のすべてのペアから均等にペア (l, r) を選択し、[l, r) の x に対するエッジ (x, x+1) をすべて削除します。 l = r の場合、削除されたセグメントは空になる可能性があり、これは削除なしに相当します。 

この削除後、島 1 から島 i までの最短パス距離が必要になります。 各 i に必要な答えは、(l, r) のすべての選択肢にわたるこの距離の期待値 (998244353 を法とする) です。 

制約は最大 5 × 10^5 のアイランドに及ぶため、クエリごとに二次関数を実行することは不可能です。 全体として線形または線形に近い解が必要なため、i ごとに再計算される O(n^2) 前処理でも遅すぎます。 この構造は、各除去をシミュレートするのではなく、すべての間隔の寄与を集計して計算する必要があることを強く示唆しています。 

チェーンが「切れるか、切れていないか」だけを考えていると、素朴な間違いが生じます。 実際には、セグメントが削除される場合、エア ノードの使用を強制される前にアイランド 1 からどれだけの距離を移動できるかが決まるため、ブレーク位置が重要になります。 もう 1 つの微妙な失敗は、l = r の場合を無視することで発生します。これにより、削除は発生せず、同じ l で始まる他のすべての間隔とは異なる動作が行われます。 

## アプローチ

 ブルート フォース アプローチでは、すべての i に対して反復し、次に考えられるすべての (l, r) に対して反復し、削除をシミュレートして、1 から i への最短パスを計算します。 最短パスが貪欲に計算されたとしても、各チェックのコストは O(i) であり、i ごとに O(i^2) の間隔があるため、全体では O(n^3) になります。 これは大きすぎます。 

重要な構造の単純化は、削除後のグラフが非常に制御された形式になることです。 セグメント [l, r) を削除すると、チェーンに 1 つの切断が導入されるだけで、到達可能なランドがプレフィックス部分 [1, l] とサフィックス部分 [r, i] に分割されます。 島 1 から見て、唯一有用な「カット ポイント」は、休憩前に到達可能な最後の島、l です。 r 以降のすべては、エア ノードを経由する場合を除き、i に到達するのには無関係です。 

これは、最短パスは l と区間が空かどうかのみに依存することを意味します。 これが観察されたら、各 l に対応する r の選択肢の数を数え、削除がないケースを分離することによって、すべて (l, r) にわたる寄与を集計できます。 

次に、問題を l の関数にわたってプレフィックス集合体を維持することに縮小し、プレフィックスの前処理後に各 i を O(1) で処理できるようにします。

 ## アルゴリズムのチュートリアル

 まず、いくつかのヘルパー量を修正します。 pref[x] を 1 から x までのチェーン エッジの重みの合計とすると、pref[x] はチェーン エッジのみを使用したアイランド 1 からアイランド x までの距離になります。 

各 i について、空気を通る一定のベースライン代替経路を A = W1 + Wi として定義します。 

ここで、固定間隔 (l, r) が i への最短経路にどのような影響を与えるかを分析します。 

1. l = r の場合、エッジは削除されません。 グラフはそのままなので、最適なパスは pref[i−1] と A の間の最小パスになります。 
2. l < r の場合、チェーンは l と r−1 の間で切断されます。 島 1 からは、チェーン エッジを使用して最大 l までしか到達できません。 その後、i に到達するにはエアノードを経由する必要があります。 最良のパスは、pref[l−1] + Wl + Wi、または直接 W1 + Wi になります。 したがって、コストは Wi + min(W1, pref[l−1] + Wl) となります。

次に、各状況に対応する間隔の数を数えます。 

固定 l の場合、r = l の場合は 1 つの区間が存在し、r > l の場合は i − l 区間が存在します。 

したがって、固定 i に対する寄与の合計は次のように計算されます。 

1. すべての削除なしのケースはコスト C = min(pref[i−1], W1 + Wi) に寄与し、そのような間隔が i 個あります (r = l の各 l に 1 つ)。 
2. すべての削除ケースは、各 l に対して (i − l) 回繰り返された Wi + min(W1, pref[l−1] + Wl) に寄与します。 

ここで、l に対するプレフィックス集約を使用してすべてを書き換えます。 

B[l] = pref[l−1] + Wl とし、M[l] = min(W1, B[l]) と定義します。 

プレフィックスの合計を維持します。 

S1[i] = l ≤ i の場合の M[l] の合計

 S2[i] = l ≤ i の場合の l · M[l] の合計

 この場合、M[l] に関係する削除寄与は次のようになります。 

合計 (i − l) M[l] = i · S1[i] − S2[i]

 すべての削除に対する純粋な Wi の寄与は次のとおりです。 

sum_{l=1..i} (i − l) = i^2 − i(i+1)/2

 すべてをまとめると:

 合計(i) =

 i・C

 - Wi · (i^2 − i(i+1)/2)
 - (i · S1[i] − S2[i])

 最後に、剰余演算により区間の総数 i(i+1)/2 で除算します。 

### なぜ効果があるのか

 r 以降のすべてのエッジは 1 からの接続性には無関係であるため、すべての間隔は最初のカット位置 l を通るパスにのみ影響します。r にわたるランダム性は、破壊的な場合と単一の特殊な非破壊的な場合の単純な多重度 (i − l) に変換されます。 これにより、(l, r) にわたる 2 次元の平均が l にわたる 1 次元のプレフィックス構造に分解され、線形プレフィックス統計から期待値を計算できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    n = int(input())
    w = list(map(int, input().split()))
    W = list(map(int, input().split()))

    pref = [0] * (n + 1)
    for i in range(1, n):
        pref[i] = pref[i - 1] + w[i - 1]

    inv2 = modinv(2)

    S1 = [0] * (n + 1)
    S2 = [0] * (n + 1)

    ans = []

    for i in range(1, n + 1):
        if i == 1:
            ans.append(W[0] % MOD)
            continue

        B = pref[i - 1] + W[i - 1]
        C = min(pref[i - 1], W[0] + W[i - 1])

        # update S1, S2 at i
        if i > 1:
            mval = min(W[0], pref[i - 1] + W[i - 1])
            S1[i] = S1[i - 1] + mval
            S2[i] = S2[i - 1] + i * mval
        else:
            S1[i] = 0
            S2[i] = 0

        total_no = i * C % MOD

        sum_m = S1[i]
        sum_im = S2[i]

        del_min_part = (i * sum_m - sum_im) % MOD
        del_wi_part = (i * i - i * (i + 1) // 2) % MOD

        total = (total_no + W[i - 1] * del_wi_part + del_min_part) % MOD

        denom = i * (i + 1) // 2
        total = total % MOD * modinv(denom) % MOD

        ans.append(total)

    print("\n".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```実装は派生した式に直接に従います。 必要な前処理は、変換された値 M[l] に対するチェーンの重みと 2 つの実行集計 S1 および S2 のプレフィックス合計だけです。 インデックスの一貫性を保つには注意が必要です。W[0] は W1 で、pref[i−1] はチェーンを通じてアイランド i に到達することに対応します。 

i(i+1)/2 による除算は、i ごとに計算されるモジュラー逆関数を使用してモジュラスの下で行われますが、実際には、さらに最適化するためにすべての i について事前計算することができます。 

## 実用的な例

 n = 3、チェーンの重み w = [2, 3]、空気の重み W = [5, 1, 4] の小さなインスタンスを考えてみましょう。 

プレフィックス値 pref = [0, 2, 5] を計算します。 

i = 2 の場合:

 | コンポーネント | 値 |
 | --- | --- |
 | プレフィ[i−1] | 2 |
 | C = min(pref[1], W1 + W2) | 最小(2, 6) = 2 |
 | M[1] | 最小(5, 0+5) = 5 |
 | S1 | 5 |
 | S2 | 1・5 = 5 |

 ここで次を計算します。 

合計非削除 = 2 × 2 = 4

 削除連鎖部分 = 2×5 − 5 = 5

 削除 Wi 部分 = 2² − 3 = 1

 合計 = 4 + 1・1 + 5 = 10

 3 つの間隔で割ると 10/3 になります。 

これは、カット位置とノーカットの場合の両方が個別にどのように寄与するかを示しています。 

i = 3 の場合、構造は似ていますが、l の範囲は 3 つの位置にまたがり、各 l は破壊区間の多重度が異なります。これは、S1 と S2 が区間ごとに再計算せずにすべての寄与をどのように蓄積するかを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n) | 各 i は、一定数のプレフィックス集合体を更新し、一定数の算術演算を計算します。 
| スペース | O(n) | チェーン合計と集計値のプレフィックス配列 |

 すべての作業が線形であり、間隔ごとの列挙が回避されるため、この解は n の制限内に問題なく収まります (最大 5 × 10^5)。
