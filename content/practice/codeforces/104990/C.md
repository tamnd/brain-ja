 ## 問題の理解

 長さのシーケンスを数えるように求められます$N$、各要素は整数から選択されます$1$に$M$、隣接する要素のすべてのペアは互いに素である必要があります。これは、最大公約数が 1 に等しいことを意味します。シーケンス内のすべての位置は、その直前の先行要素にのみ依存するため、構造は本質的にローカルですが、シーケンスが非常に長くなる可能性があります。 

制約における重要な張力は次のようなものから生じます。$N$と同じくらい大きい$10^8$、 その間$M$これにより、シーケンスの各位置を明示的に処理するアプローチは即座に除外されます。 シーケンスの長さにわたって反復する解決策は不可能です。$O(N)$仕事はすでに大きすぎます。 唯一の実行可能な方向は、問題を圧縮して、$N$対数的になるか、通常は行列のべき乗または遷移システムでの高速べき乗を通じて消去されます。 

微妙な点は、隣接条件は値にのみ依存し、位置には依存しないことです。 これは、問題全体が、サイズが固定されたグラフ上をたどると見ることができることを意味します。$M$、ノードは整数です$1 \dots M$、およびエッジは互いに素のペアを接続します。 シーケンスは長さのウォークになります$N$このグラフでは。 

切り分ける価値のあるエッジケースには次のようなものがあります。$N = 1$、ここでの任意の値$1$に$M$有効であり、かつ$M = 1$、ここで唯一可能なシーケンスはすべて 1 です。 もう 1 つのデリケートなケースは、多くの数値が互いに素でない場合です。これにより、グラフがまばらになる可能性がありますが、計数問題の指数関数的な増加の性質は変わりません。 

## アプローチ

 直接的なアプローチは、すべての有効なシーケンスを再帰的に構築することです。 最初の数字を自由に選択し、次に各位置で前の数字と互いに素な任意の数字を選択します。 これは、サイズのグラフにわたる分岐プロセスを定義します。$M$。 隣接条件を直接適用するため、正確性がすぐにわかります。 

失敗点は成長率です。 各ノードに平均して数個の隣接ノードしかない場合でも、シーケンスの数は次のように指数関数的に増加します。$N$。 のために$N = 10^8$、単一のパスさえ列挙できません。 したがって、問題は正確さではなく、繰り返し構造を効率的に表現できないことです。 

重要な観察は、これがサイズの固定状態空間上のマルコフ過程であるということです。$M$。 私たちが気にするのは、その後の各値で終了できる方法が何通りあるかだけです。$k$ステップ。 ベクトルを格納すると$dp[k][x]$長さのシーケンスの数を意味します$k$値で終わる$x$の場合、遷移は共素性にのみ依存します。 これは、サイズのベクトルに対する線形変換になります。$M$、行列の乗算としてエンコードできます。 

させて$T[i][j] = 1$もし$\gcd(i, j) = 1$、 さもないと$0$。 それから：$$dp_{k+1}[j] = \sum_{i=1}^M dp_k[i] \cdot T[i][j]$$したがって、$dp_k$固定値を繰り返し乗算することで進化します$M \times M$マトリックス。 必要です$T^N$初期ベクトルに適用されます。 以来$N$は巨大なので、行列のべき乗を計算します。$O(M^3 \log N)$。 と$M \le 100$、これは実現可能です。

 ## アルゴリズムのチュートリアル

 1. 以下の値を表す状態のセットを構築します。$1$に$M$。 各状態は、部分シーケンスの最後の要素に対応します。 
2. 移行マトリックスを構築する$T$、 どこ$T[i][j] = 1$もし$i$そして$j$は互いに素である。 これは値から移動できるかどうかをエンコードします$i$大切にする$j$ワンステップで。 
3. 基底ベクトルを初期化する$v$どこ$v[i] = 1$で終わる単一要素シーケンスのため、$i$有効です。 
4. シーケンスを 1 要素だけ拡張すると、現在のベクトルに次の値を乗算すると解釈されます。$T$。 これにより、計数の問題が繰り返しの線形変換に変換されます。 
5. コンピューティング$T^{N-1}$行列に対して 2 進累乗を使用します。 各乗算により、2 つの遷移システムがより長い遷移システムに構成されます。 
6. 結果の行列に基底ベクトルを乗算して、ある長さのシーケンスの数を取得します。$N$各値で終了します。 
7. 結果のベクトルのすべてのエントリを合計して、有効なシーケンスの総数を取得します。 

### なぜ効果があるのか

 重要な不変条件は、処理後に$k$ステップ、状態のベクトル エントリ$i$有効な長さのシーケンスの数に等しい$k+1$で終わる$i$。 すべての有効な長さのシーケンスのため、すべての拡張ステップではこの不変式が維持されます。$k+1$長さの有効な先行要素を追加することによって一意に形成されます$k$、遷移行列はすべての有効な隣接関係を正確にエンコードします。 すべての遷移は独立して考慮され、繰り返しはすべての先行遷移にわたって網羅されるため、シーケンスが二重にカウントされたり省略されたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(a, b):
    n = len(a)
    m = len(b[0])
    p = len(b)
    res = [[0] * m for _ in range(n)]
    for i in range(n):
        ai = a[i]
        ri = res[i]
        for k in range(p):
            if ai[k]:
                aik = ai[k]
                bk = b[k]
                for j in range(m):
                    ri[j] = (ri[j] + aik * bk[j]) % MOD
    return res

def mat_pow(mat, exp):
    n = len(mat)
    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    while exp > 0:
        if exp & 1:
            res = mat_mul(res, mat)
        mat = mat_mul(mat, mat)
        exp >>= 1
    return res

def solve():
    N, M = map(int, input().split())

    if N == 1:
        print(M)
        return

    T = [[0] * M for _ in range(M)]
    for i in range(M):
        for j in range(M):
            if __import__("math").gcd(i + 1, j + 1) == 1:
                T[i][j] = 1

    P = mat_pow(T, N - 1)

    ans = 0
    for i in range(M):
        ans = (ans + sum(P[j][i] for j in range(M))) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、値に対して完全な隣接行列を構築します。$1 \dots M$ここで、エッジは gcd 制約の下で有効な遷移を表します。 べき乗により、この遷移システムの長さが増加します。$N-1$、長さのシーケンスなので$N$もっている$N-1$トランジション。 

乗算の順序は重要です。行列は前の状態 (行) から次の状態 (列) への遷移を表します。 最終的な合計では、考えられるすべての終了状態が集計されます。 特別な場合$N=1$すべての単一値が有効であるため、べき乗を完全に回避します。 

## 実用的な例

 ### 例 1:$N = 2, M = 3$値 1 から 3 までの遷移を構築します。 

| 私 | j | gcd(i,j) | T[i][j] |

 のために$N=2$、トランジションを 1 つ適用します。 有効なペアの数は、単にこの行列内の 1 の数、つまり 7 です。 

これは、シーケンスの長さが最小の場合に、アルゴリズムが問題を有効なエッジのカウントに正しく還元していることを確認します。 

### 例 2:$N = 2, M = 10$ここでは構造は大きくなっていますが、それでも単一ステップの遷移の問題です。 マトリックスは、次のペアの数を数えます。$1 \dots 10$は互いに素である。 このアルゴリズムは、共素性グラフ内のすべての有効な有向辺を合計し、63 を生成します。 

これは、この方法がシーケンスの列挙には依存せず、gcd 関係の構造特性のみに依存していることを示しています。

 のために$N = 1$、からのすべての値$1$に$M$長さ 1 の有効なシーケンスを形成します。 このアルゴリズムは行列のべき乗をバイパスし、直接出力します。$M$。2 番目の要素がなければ隣接性制約は適用されないため、これは定義と一致します。
