 ## 解決策
 ## 問題の理解

 1 から _n_ までの整数の順列が与えられています。これは、その範囲内の各整数が配列内に 1 回だけ出現することを意味します。 目標は、この配列を昇順に並べ替えることですが、実行できる交換には特別な制限があります。 具体的には、位置が素数長の距離にある 2 つの要素のみを交換できます。 つまり、インデックス _i_ と _j_ を選択した場合、両端を含むそれらの間の位置の数 (_j_ - _i_ + 1) は素数でなければなりません。 出力には、配列のソートに使用されたスワップのシーケンスがリストされます。 最大 5_n_ スワップが許可されており、この制限内で配列をソートする有効なソリューションであればどれでも受け入れられます。 

_n_ が 10^5 まで大きくなり、制限時間が 2 秒であることを考えると、O(n log n) よりも複雑なアルゴリズムは遅すぎる可能性があります。 すべての位置のペアを繰り返しチェックする単純なアプローチでは、O(n^2) の操作が必要になる可能性がありますが、これは実行不可能です。 この問題により、明確な整数が保証され、重複する値や安定性を考慮する必要がないため、処理が簡素化されます。 明らかではないエッジケースには、ほとんどソートされている配列、反転された配列、または要素 1 がターゲット位置から遠く離れている配列が含まれます。 たとえば、入力`[5, 1, 2, 3, 4]`1 をインデックス 2 から 1 に移動する必要があり、不注意なアプローチでは素数長ルールに違反するスワップを試行したり、5_n_ を超える非効率的な長いシーケンスを生成したりする可能性があります。 

## アプローチ

 ブルートフォース手法では、距離が素数であり、スワップによって少なくとも 1 つの要素がソートされた位置に近づくインデックスのペアを繰り返し検索します。 これは正しいです。理論的には、これらの許可されたスワップを使用して任意の順列を並べ替えることができますが、すべてのペアを繰り返しチェックすると O(n^2) の操作が必要になります。 n = 10^5 の場合、これには 10^10 の操作が含まれる可能性があり、制限時間を大幅に超えます。 

効率的な解決策につながる重要な観察は、主距離制約により、スワップを連鎖させることで要素を任意の距離に移動できるということです。 まず、エラトステネスのふるいを使用して、n までのすべての素数を事前計算します。 正しい位置にない各要素について、現在のインデックスから距離 p のターゲット インデックスへの交換が可能となるように、最大​​の素数 p を選択します。 これにより、要素を正しい位置に貪欲に「バブル」することができます。 すべての要素は、制限された数のスワップでソートされた位置に直接移動するため、スワップの総数は O(n) で、各スワップ計算には、事前に計算された素数を使用した O(1) 個の素数チェックが含まれます。 このアプローチは、不必要な試行を減らし、すべての操作の生産性を保証するため、ブルートフォースよりもはるかに高速です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | Prime Precomputation で欲張りに | ふるいの場合は O(n log log n) + O(n log n) スワップ | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. エラトステネスのふるいを使用して、_n_ までのすべての素数を生成します。 これらの素数は、すべての有効なスワップ長を表します。 
2. 各値から現在のインデックスへのマッピングを構築します。 これにより、配列内の要素がどこにあるかをすばやく検索できます。 
3. 配列を左から右に繰り返します。 位置 _i_ については、_i_ の要素が _i_ (ターゲット値) と等しいかどうかを確認します。 そうであれば、次の位置に進みます。 
4. _i_ の要素が正しくない場合は、マッピングを使用してターゲット インデックスを見つけます。 
5. 現在のインデックスとターゲット インデックスの間の距離を計算します。 最大の素数 p ≤ 距離を見つけます。 この素数は、要素をターゲットに向かってどこまでスワップできるかを決定します。 
6. 現在のインデックスとターゲットに向かって距離 p にあるインデックスとの間でスワップを実行します。 それに応じてマッピングを更新します。 
7. 要素が正しい位置に到達するまで、ステップ 5 を繰り返します。 次に、配列内の次の位置に移動します。 
8. すべてのスワップをリストに記録します。 配列全体を処理した後、スワップ数とスワップ操作を出力します。 

機能する理由: このアルゴリズムは、スワップのたびに有効な素数長の移動を使用して要素を正しい位置に近づけるという不変条件を維持します。 素数は十分に密であり、すべての要素は最終的に正しい位置に移動されるため、配列は確実にソートされます。 マッピングにより、スワップが常に正確であることが保証され、更新により不整合が防止されます。 この戦略では、無効なスワップは決して生成されず、5_n_ 制限をはるかに下回る制限された数の操作で完了します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n+1, i):
                is_prime[j] = False
    primes = [i for i, val in enumerate(is_prime) if val]
    return primes

def main():
    n = int(input())
    a = list(map(int, input().split()))
    pos = [0] * (n + 1)
    for idx, val in enumerate(a):
        pos[val] = idx
    primes = sieve(n)
    swaps = []

    for i in range(n):
        while a[i] != i + 1:
            target_idx = pos[i + 1]
            dist = target_idx - i + 1
            # find largest prime <= dist
            p = max(p for p in primes if p <= dist)
            j = target_idx - (p - 1)
            # perform swap
            a[i], a[j] = a[j], a[i]
            pos[a[i]] = i
            pos[a[j]] = j
            swaps.append((i + 1, j + 1))
    
    print(len(swaps))
    for x, y in swaps:
        print(x, y)

if __name__ == "__main__":
    main()
```ふるいは _n_ までのすべての素数を生成し、スワップが素数の長さの制約を満たすことを保証します。 の`pos`配列を使用すると、任意の要素の現在位置に定数時間でアクセスできます。 内側の while ループは、効率を高めるために最大許容素数を選択し、すべての要素が正しい位置に到達することを保証します。 Off-by-one の処理は、出力内の 1 から始まるインデックスと一致するように慎重に管理されます。 スワップごとに、配列とマッピングの両方が更新されます。
