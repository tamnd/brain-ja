 ## 解決策
 ## 問題の理解

 無限整数グリッド上の点灯セルの最終構成が与えられます。 最初は、最初にオンになっていた 1 つの隠れた「元の」セルを除いて、すべてのセルがオフになっています。 次に、歪んだ 2 行 2 列の形状を形成する 4 つのセルを正確に切り替える操作を繰り返し適用します。$(x, y)$、反転します$(x, y)$、$(x, y+1)$、$(x+1, y)$、 そして$(x+1, y-1)$。 

このような一連の未知の操作の後、現在オンになっているすべてのセルのセットを観察します。 タスクは、単一の点灯セルの可能な初期位置を回復することです。 

重要な観点は、操作によって任意のパターンが作成または破壊されないということです。 グリッド上で特定の線形不変量が保存されます。 最終的な構成は、1 つの開始点をとり、演算形状によって生成される XOR のような「パリティ シフト」をいくつか追加することと同等です。 

制約の合計サイズは大きく、最大で$2 \cdot 10^5$すべてのテスト ケースにわたるポイント。 これにより、すべての点に対して候補原点を試行したり、操作を逆方向にシミュレートしたりするような二次関数は即座に除外されます。 すべてのポイントの集計情報から原点を計算する必要があります。 

微妙だが重要なエッジ ケースは、点灯しているセルが 1 つだけある場合です。 この場合、操作は必要ありません。したがって、答えはまさにその座標でなければなりません。 ポイントを「平均」したり結合しようとするメソッドは、このケースを正確に保持する必要があります。 

別のエッジ ケースは、操作中に局所的なキャンセルが発生する構造化された形状をポイントが形成する場合に発生します。 たとえば、対称に見える構成や相互にシフトされたコピーのように見える構成は、不変条件を慎重に選択しない限り、単純な重心ベースの推論を誤解させる可能性があります。 

## アプローチ

 この操作は 4 つの点を反転します。$(x, y)$、$(x, y+1)$、$(x+1, y)$、$(x+1, y-1)$。 

ブルートフォースアプローチでは、最初の宝物の位置を推測しようとします。$(s, t)$、操作で最終セットがどのように生成されるかをシミュレートし、一貫性を検証します。 ただし、可能な操作シーケンスの空間は無制限で組み合わせ的であるため、再構築は不可能です。 

正しいアプローチは、操作が座標全体にわたって線形不変式を保持することを認識することから生まれます。 グリッド全体を追跡するのではなく、すべての操作の下で安定した状態を保つ、慎重に選択された座標の線形結合を追跡します。 

座標合計に対する 1 つの演算の影響を調べてみましょう。 次のような値を維持するとします。$$S = \sum x_i \quad \text{or} \quad \sum y_i$$または次のような組み合わせ$\sum (ax_i + by_i)$。 目標は係数を見つけることです$a, b$そのため、操作を適用しても合計寄与率は変わりません。 

反転された 4 つの点の x 座標の変化は次のようになります。$x, x, x+1, x+1$、合計$2x + 2(x+1) = 4x + 2$。 

y 座標の場合:$y, y+1, y, y-1$、 合計$4y$。 

これは、単純な合計は不変ではないが、慎重に選択された加重合計間の差は不変である可能性があることを示唆しています。 重要なトリックは、変換された座標系に移動することです。$$u = x + y, \quad v = x - y$$これらの座標では、パリティ構造の 1 つが崩壊するほど操作が対称的になります。 各操作はポイントのセットを切り替え、その組み合わせ効果によりすべてのポイントの XOR が維持されます。$u$値とすべての XOR$v$価値観。 ペアごとのキャンセルを伴うマルチセットの XOR は原点と平衡演算を反映するため、すべてのポイントの最終 XOR は初期位置をエンコードします。 

したがって、次のように計算すると、$$U = \bigoplus (x_i + y_i), \quad V = \bigoplus (x_i - y_i)$$その後、次のように回復します。$$x = \frac{U + V}{2}, \quad y = \frac{U - V}{2}$$これが機能するのは、各操作が不変空間で影響を受ける各点に偶数回寄与するためです。つまり、XOR 空間ではその正味の効果はゼロになります。

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、すべてのポイントを読みます。$(x_i, y_i)$。 目標は、構成の安定した署名を抽出することです。 
2. 2 つのアキュムレータを計算します。1 つは変換された座標です。$u_i = x_i + y_i$、そして 1 つ以上$v_i = x_i - y_i$。 演算構造はパリティ空間でキャンセルするように設計されているため、累積は合計ではなく XOR を使用して行われます。 
3. すべての XOR$u_i$値を使用して単一の値を取得する$U$。 これは、対角軸に沿った構成の正味の不均衡を表します。 
4. すべての XOR$v_i$取得する値$V$、反対角軸に沿った不均衡を表します。 
5. 線形システムを解くことで元の点を回復します。$x = (U + V) / 2$、$y = (U - V) / 2$。 
6. 出力$(x, y)$。 

操作によって生成された有効な構成によって次のことが保証されるため、2 による除算は常に有効です。$U$そして$V$一致するパリティを持っています。 

### なぜ効果があるのか

 この操作では、両方の対角パリティを独立して保持する方法で配置された 4 つのポイントを切り替えます。 変身した中で$(u, v)$スペースでは、各操作は XOR が 0 である値のセットを反転します。 これは、すべての XOR を意味します。$u_i$そしてすべて$v_i$最終構成上の は、単一の初期点の XOR に等しくなければなりません。 XOR は操作によって導入されたすべてのペアの寄与をキャンセルするため、元の宝の位置のみが両方の不変条件でエンコードされたままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        U = 0
        V = 0
        for _ in range(n):
            x, y = map(int, input().split())
            U ^= (x + y)
            V ^= (x - y)
        x = (U + V) // 2
        y = (U - V) // 2
        print(x, y)

if __name__ == "__main__":
    solve()
```このソリューションは各テスト ケースを独立して処理し、変換された座標に対する XOR を蓄積します。 重要な実装の詳細は、すべての値が符号付き整数の範囲内に留まり、オーバーフローが発生しないため、Python の整数演算を XOR で安全に使用することです。 

再構成ステップは整数の 2 による除算に依存しますが、パリティ構造により偶数の合計が保証されるため安全です。

 ## 特殊なケース

 単一点入力は最も直接的なケースです。両方の XOR アキュムレータはその点の変換された座標に減算され、再構築はすぐにそれを返します。 ポイントの正規化や並べ替えを試みる間違った実装はここでも機能しますが、その必要はありません。 

次のような対称構成$(0,0)$、$(1,1)$XOR を一方向に強制的にキャンセルし、もう一方の方向を強化します。 この変換により、システムが誤って折りたたまれるのではなく、有効な原点の 1 つに解決されることが保証されます。 

大きい値の座標では、中間ステップが整数の制限を超えていないことをテストします。 すべての演算は XOR と加算であるため、Python はこれを安全に処理し、パリティは大きさに関係なく正しいままになります。
