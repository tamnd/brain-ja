 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、その広がりに基づいて単一の派生値を計算するように求められます。 「興味深い値」は、シーケンスの長さとシーケンスの範囲という 2 つの量の積として定義されます。範囲とは、最大要素と最小要素の差です。 

したがって、タスクは、すべての値を読み取り、最小要素と最大要素を特定し、それらの差を計算し、その差に要素の数を乗算することになります。 

制約は十分小さいため、1 回のリニア スキャンで十分です。 最大 10,000 個の要素を使用すると、各要素を一定回数検査するソリューションであれば、十分に高速になります。 きれいに実装されていれば、数百万のプリミティブ操作であっても、Python の 0.5 秒の制限の下では簡単です。 

整数の範囲と符号の処理という、不注意な実装でつまずく可能性がある微妙な落とし穴が 1 つあります。 値は負の値になる可能性があるため、最小値は負、最大値は正になる可能性があり、範囲が大きくなる可能性があります。 たとえば、配列が次の場合、`[-100000, 100000]`、範囲は`200000`と乗算する`n`部分的な仮定を使用したスキャン中にではなく、正しい極値を計算した後に実行する必要があります。 

もう 1 つの特殊なケースは、単一要素の配列です。 もし`n = 1`の場合、最大値と最小値の両方が等しく、範囲はゼロとなり、値自体に関係なく答えはゼロになる必要があります。 最初の要素を適切に使用せずに min または max を誤って初期化する実装は、ここで中断される可能性があります。 

## アプローチ

 ブルートフォース解釈では、考えられるすべての部分構造の範囲を計算したり、極値を繰り返し再計算したりしようとする可能性がありますが、シーケンスは固定されており、グローバルな最小値と最大値は 1 回だけ必要なので、その必要はありません。 

簡単で乱暴なアイデアは、各要素を他のすべての要素と比較して最小値と最大値を決定するというものです。 n 個の要素のそれぞれが n 回の比較に参加するため、O(n²) アプローチが得られます。 それは正しいのですが、必要な機能をはるかに超えており、同じグローバル プロパティを繰り返し再計算することで作業が無駄になります。 

重要な点は、範囲がシーケンス全体の最小値と最大値の 2 つの値のみに依存するということです。 これらが分かれば、他の構造は問題になりません。 これにより、ペアごとの比較の問題が単一パスの累積問題に分解されます。 

アレイを 1 回スキャンしている間、最小値と最大値の実行を維持できます。 新しい要素はそれぞれ、現在の最小値または最大値を一定時間で更新します。 スキャン後、計算します`(max - min) * n`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | シングルパスの最小/最大 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`、処理する値の数を決定します。 これにより、最終回答の乗数も定義されます。 
2. 2 つの変数を初期化する`mn`そして`mx`シーケンスの最初の要素を使用します。 これにより、不正確なセンチネル値が回避され、すべての数値が負または同一である場合でも正確さが保証されます。 
3. シーケンスの残りの要素を繰り返し処理します。 要素ごとに比較します。`mn`そして更新します`mn`それが小さい場合。 に対しても同じことを行います`mx`それが大きい場合。 これにより、すべてのステップで正しいグローバル極値が維持されます。 
4. すべての要素を処理した後、範囲を次のように計算します。`mx - mn`。 これが機能する理由は、`mx`そして`mn`は、完全なシーケンスの真の最大値と最小値を表します。 
5. 範囲を乗算します。`n`最終的な「面白い値」を取得して出力します。 

### なぜ効果があるのか

 反復のあらゆる時点で、`mn`そして`mx`は、これまでに処理されたプレフィックスの正確な最小値と最大値です。 この不変式は、新しい要素が境界を越える場合には無視されるか、いずれかの要素に置き換わるため成り立ちます。 最後の要素の後のプレフィックスは配列全体であるため、`mn`そして`mx`は真の世界的な極値です。 範囲はこれらの極値のみに依存し、順序とは独立しているため、最終的な計算は正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n_and_rest = sys.stdin.read().strip().split()
n = int(n_and_rest[0])
arr = list(map(int, n_and_rest[1:]))

mn = arr[0]
mx = arr[0]

for x in arr[1:]:
    if x < mn:
        mn = x
    if x > mx:
        mx = x

answer = (mx - mn) * n
print(answer)
```このソリューションは、繰り返しの入力呼び出しによるオーバーヘッドを回避するために、すべての入力を一度に読み取ります。 これは、n が 10,000 までの場合は厳密には必要ありませんが、実装をクリーンかつ堅牢に保ちます。 

の初期化`mn`そして`mx`最初の要素からが重要です。 次のようなプレースホルダーを使用する`float('inf')`は機能しますが、配列に直接アンカーすると、エッジケースの間違いが回避され、整数型間での比較の一貫性が保たれます。 

最終的な乗算は範囲を計算した後に実行され、中間値が正確さに影響を与えないようにします。

import sys, io

def run(inp: str) -> str:

 ## 特殊なケース

 次のような単一要素入力の場合`1 100000`、アルゴリズムは両方を初期化します`mn`そして`mx`に`100000`。 反復中に更新は行われません。 範囲は次のようになります`0`と乗算する`n`まだ収穫できる`0`、単一値の広がりがゼロであるという定義と一致します。 

次のような完全な負のシーケンスの場合、`3 -5 -2 -10`、実行最小値は次のようになります`-10`そして最大値は`-2`。 範囲は`8`、そして答えは`24`。 すべての比較は純粋にリレーショナルであるため、アルゴリズムは値が正でなければならないという仮定を正しく回避します。 

次のような極端な混合シーケンスの場合`2 -100000 100000`、`mn`になる`-100000`そして`mx`になる`100000`、さまざまな製品を生産します`200000`。 の乗算`n`与える`400000`これにより、すべての演算が Python の任意精度の整数演算の範囲内にとどまるため、オーバーフローや符号処理の問題が発生しないことが確認されます。
