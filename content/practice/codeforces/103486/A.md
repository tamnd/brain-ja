 ## 解決策
 ## 問題の理解

 一連の整数が与えられ、それがパリティの観点から「バランスが取れている」ように見えるかどうかを判断する必要があります。 それぞれの数値は奇数または偶数であり、各カテゴリに該当する数を単純に数えます。 

ルールは非常に厳密です。奇数の値の数と偶数の値の数を計算し、それらの絶対差を計算します。 その差が最大でも 1 である場合、ジェネレーターは許容できると見なされますが、それ以外の場合は許容されません。 

入力サイズは最大 100,000 個の数値に達するため、配列を 1 回スキャンするソリューションであれば、十分に高速です。 二次アプローチでは、要素をペアで比較するか、リストを繰り返しフィルタリングしようとしますが、最悪の場合、10¹⁰ 程度の演算が行われ、明らかに制限を超えます。 これは、要素ごとに一定の作業を行う 1 つのパスだけが必要であることをすぐに示唆しています。 

ここでのエッジケースは主に小さな入力に関するものです。 N が 1 の場合、カウントは (1,0) または (0,1) で、その差は正確に 1 であるため、答えは常に「良好」です。 N が 2 の場合、1 つの奇数と 1 つの偶数のような構成は良好ですが、差は 2 - 0 が 2 に等しいため、同じパリティの 2 つも良好ですが、これは許可されません。 したがって、「1 1」または「2 2」は「Not Good」を出力し、「1 2」は「Good」を出力する必要があります。 不用意に実装すると、カウントを正しく比較せずに、誤って両方のパリティが存在するかどうかだけをチェックする可能性があります。 

## アプローチ

 この問題を考える強引な方法は、配列を奇数と偶数の 2 つのグループに分割し、複数回スキャンまたはフィルタリングして両方のグループを明示的にカウントすることです。 すべての数値を反復処理し、要素ごとに奇数か偶数かをチェックし、カウンターをインクリメントすることを想像することもできます。 これはすでに十分ですが、代わりに誰かが繰り返し配列をフィルター処理したり、入れ子になったループ内でカウントを再計算したりすると、配列の各パスが O(N) であり、それが要素ごとに繰り返される可能性があるため、複雑さは O(N²) に低下します。 

重要な観察は、要素間の順序や関係には何も依存しないということです。 各数値は独立して 2 つのカウンタのうちの 1 つに影響します。 これを理解すると、問題は 2 つの整数 (奇数カウント用と偶数カウント用) を維持する 1 つの線形スキャンに集約されます。 すべての数値を処理した後、その差を比較するだけです。

 ## アルゴリズムのチュートリアル

 1. 2 つのカウンタを初期化します。1 つは奇数用、もう 1 つは偶数用で、両方とも 0 に設定されます。 これにより、単一パスで周波数を蓄積する準備が整います。 
2. 配列内の各数値を繰り返し処理します。 各値について、条件を使用してパリティを決定します。`value % 2 == 0`。 この操作は一定時間であり、入力サイズには依存しません。 
3. 数値が偶数の場合は、偶数カウンタをインクリメントします。 それ以外の場合は、奇数カウンタをインクリメントします。 これにより、すべての要素が正しいカテゴリに 1 回だけ寄与することが保証されます。 
4. すべての数値を処理した後、2 つのカウンター間の絶対差を計算します。 
5. この差が 1 以下の場合、「良好」を出力します。 それ以外の場合は「Not Good」を出力します。 

### なぜ効果があるのか

 入力内の各要素は、2 つの素なセット (奇数または偶数) のいずれかに正確に属します。 このアルゴリズムは、近似や重複を行わずに、両方のセットの正確なカウントを維持します。 すべての要素は一度だけ処理されるため、最終的なカウンターは 2 つのセットの正確なカーディナリティになります。 決定ルールはこれらの基数のみに依存するため、正確さはカウントが正確であり、分類を超えてデータの変換が実行されないという事実から直接得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    odd = 0
    even = 0
    
    for x in arr:
        if x % 2 == 0:
            even += 1
        else:
            odd += 1
    
    if abs(odd - even) <= 1:
        print("Good")
    else:
        print("Not Good")

if __name__ == "__main__":
    solve()
```実装はアルゴリズムに直接に従います。 すべての値を 1 回読み取り、2 つのカウンターを維持します。 パリティ チェックではモジュロ 2 が使用されます。これは、値が最大 10⁹ であるため、すべての制約に対して安全です。 最終的な比較では絶対差を使用し、奇数カウントと偶数カウントの間の対称性を確保します。 

微妙な点は入力解析です。1 回の呼び出しで 2 行目全体をリストに読み込みます。 N は最大でも 10⁵ なので、メモリ使用量は無視できるため、これは安全です。
