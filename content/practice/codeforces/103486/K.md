 ## 解決策
 ## 問題の理解

 全長の有効なブラケット構造がいくつあるかを数えるように求められます。$2N$あるときは存在する$K$さまざまな種類のブラケット。 それぞれの種類は一致したペアのように動作します。たとえば、タイプ 1 は「()」、タイプ 2 は「[]」などになります。 有効なシーケンスは、通常の平衡括弧とまったく同じように構築されます。すべての開始括弧は同じタイプの終了括弧と一致する必要があり、ネストは適切に構造化されている必要があり、有効なシーケンスの連結も有効です。 

古典的なカタロニア語の数え方との唯一の本当の違いは、一致するペアを導入するたびに、$K$タイプごとに独立した選択が可能です。 したがって、この問題は、各ペアが乗法的な色係数を持つことを除いて、バランスの取れた括弧を数えるのと構造的には同じです。 

制約は次のとおりです$N \le 10^5$したがって、構造を列挙したりスタック状態をシミュレートしようとするソリューションは直ちに不可能になります。 プレフィックスを介した動的プログラミングでも、依存している場合は遅すぎます。$O(N^2)$トランジション。 ほぼ線形時間で評価できる閉じた形式の組み合わせ式が必要です。 

微妙なエッジケースは次のような場合です$N = 1$。 答えは単純です$K$有効なシーケンスは 1 つの左括弧とそれに対応する右括弧のみであり、タイプは自由に選択できるためです。 

素朴な推論による自明ではないもう 1 つの失敗例は、各立場を独立して扱えると仮定することです。 たとえば、次のものがあると考えます。$K^N$型を割り当てて正当な理由なくカタロニア語の数値を乗算する方法は、構造とラベルを正しく分離しない限り、過大なカウントにつながります。 

## アプローチ

 この構造を少し無視して、再帰的に考えてみましょう。各ステップで、何らかのタイプの開始括弧または終了括弧を配置します。 これにより、必然的に DP オーバー プレフィックス バランスが発生し、場合によってはスタック状態が発生します。 古典的な解決策$K=1$DP または二項係数を介して計算されるカタロニア語の数値です。 

ただし、$N$まで$10^5$、階乗を介してカタロニア数を計算することさえ境界線にありますが、逆モジュラーを使用すればまだ実行可能です。 本当に重要な観察は、有効な括弧シーケンスの構造が型にまったく依存しないということです。 シーケンスの形状は標準の括弧とまったく同じです。$C_N$有効な _shapes_、ここで$C_N$です$N$-番目のカタルーニャ語番号。 

形が決まったら型を割り当てていきます。 すべての一致したペア (ブラケット分解の暗黙的なツリー構造内のすべてのエッジ) は、次のいずれかを独立して選択できます。$K$種類。 まさにあるので、$N$ペアの場合、これは次の要因に寄与します。$K^N$。 

したがって、答えは次のようになります。$$\text{Answer} = C_N \cdot K^N \pmod{10^9+7}$$以下を使用してカタロニア語の数値を計算します。$$C_N = \frac{1}{N+1} \binom{2N}{N}$$これにより、問題は階乗事前計算とべき乗剰余計算に集約されます。

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗を最大で事前計算します。$2N$。 これにより、二項係数の高速計算が可能になります。 階乗が必要になるのは、$\binom{2N}{N}$カタルーニャ語の数字の中核です。 
2. コンピューティング$\binom{2N}{N}$標準のモジュラー式を使用すると、次のようになります。$$\binom{2N}{N} = \frac{(2N)!}{(N!)^2}$$除算の代わりに逆モジュラーを使用します。 
3. カタロニア語番号を計算します。$$C_N = \binom{2N}{N} \cdot (N+1)^{-1}$$の逆$N+1$べき乗剰余を使用して計算されます。 
4. コンピューティング$K^N \bmod (10^9+7)$2進累乗を使用します。 これは、次のいずれかを独立して割り当てることを表します。$K$それぞれのタイプに$N$一致したペア。 
5. 2 つの結果を乗算し、モジュロの答えを出力します。$10^9+7$。 

### なぜ効果があるのか

 すべての有効な括弧シーケンスは、次の有効なバイナリ ツリー構造に一意に対応します。$N$内部ノード。カタロニア語番号でカウントされます。 括弧 _types_ は、正しさの制約に影響しません。これは、マッチングには、開始括弧とそれに対応する終了括弧の間の型の同一性のみが必要であり、異なるペア間の入れ子の相互作用が制限されないためです。 したがって、構造骨格が固定されると、それぞれの$N$ペアは独立して次のいずれかを選択できます$K$ラベル、きれいな乗算係数を与える$K^N$。 この独立性により、ケースの過剰カウントや欠落がないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    
    if n == 0:
        print(1)
        return
    
    maxv = 2 * n
    
    fact = [1] * (maxv + 1)
    invfact = [1] * (maxv + 1)
    
    for i in range(1, maxv + 1):
        fact[i] = fact[i - 1] * i % MOD
    
    invfact[maxv] = modpow(fact[maxv], MOD - 2)
    for i in range(maxv, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD
    
    def C(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * invfact[b] % MOD * invfact[a - b] % MOD
    
    catalan = C(2 * n, n) * modpow(n + 1, MOD - 2) % MOD
    ways_types = modpow(k, n)
    
    print(catalan * ways_types % MOD)

if __name__ == "__main__":
    solve()
```階乗前処理によりルックアップ テーブルが構築されるため、クエリごとに二項係数を一定時間で計算できます。 カタロニア語の計算は、閉じた形式から直接続き、モジュラー逆関数になります。$n+1$モジュロ演算で除算を安全に処理します。 

のべき乗$K^N$は独立かつ乗法的であり、一致する各ペアが独立したラベルの選択を保持しているという事実を反映しています。

 ## 特殊なケース

 の$N = 0$case は空のシーケンスに対応します。 Catalan(0) は 1 であり、$K^0$も 1 なので、積は 1 のままです。 

いつ$K = 1$、問題は正確に、標準のバランスのとれた括弧シーケンスをカウントすることに帰着します。 アルゴリズムはカタロニア数のみを計算するように崩壊し、オーバーカウントは発生しません。$1^N = 1$。 

いつ$N = 1$、計算により不要な構造が回避されます: Catalan(1) は 1 であり、結果は正確に次のようになります。$K$、単一ペアの直接列挙に一致します。 

潜在的な実装上の落とし穴は、中間階乗乗算でモジュロを適用する前の整数オーバーフローです。 これは、すべての乗算ステップでモジュロを取得することで回避され、次の場合でも正確さを保証します。$2N$まで$2 \cdot 10^5$。
