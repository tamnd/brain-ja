 ## 問題の理解

 初期値から開始し、素数を法とするアフィン変換を繰り返し適用する線形合同生成器が与えられます。 次の各値は、現在の値に固定定数を乗算し、別の定数を加算し、その結果を剰余して減算することによって取得されます。$m$。 これにより、最終的に循環する決定的なシーケンスが生成されます。 

タスクはシーケンス全体を生成することではなく、指定された値が正しいかどうかを判断することです。$x$から始まるシーケンスにこれまでに出現する$X_0$。 

ここで重要な構造は、シーケンスがサイズの有限状態空間内で進化するということです。$m$、そしてそれ以来$m \le 10^9$、シーケンスがどれだけ速く繰り返されるかによって、単純なシミュレーションが受け入れられるかどうかが決まります。 

この制約は、各遷移が一定時間であることを意味しますが、完全なシミュレーションは最大で 8 時間実行できます。$m$繰り返す前に、最悪の場合の手順を実行してください。 それは明らかに不可能な場合$m$大きいです。 

ジェネレーターがすぐに一定になるか、非常に短いサイクルに入った場合、微妙なエッジ ケースが発生します。 たとえば、次の場合$a = 0$、シーケンスは次のようになります$X_1 = b \bmod m$、その後の値はすべて同一です。 その場合、答えは自明にYESかNOのどちらかになります。$x$その固定値または最初の 2 つの状態のいずれかに一致します。 もう一つのエッジケースは、$a = 1$、シーケンスは等差数列モジュロになります。$m$、一般的な LCG サイクルと比較して到達可能性の動作が異なります。 

## アプローチ

 最も直接的なアプローチは、次から始まる再発をシミュレートすることです。$X_0$そして次の値を繰り返し計算し、訪問したすべての状態をハッシュ セットに保存します。 どちらか見つけたらやめます$x$、またはサイクルが終了したことを示す繰り返し状態が検出されたとき。 

これが機能するのは、状態空間が有限であるため、最終的には値を繰り返す必要があるためです。 値が繰り返されると、シーケンスはサイクルに入り、新しい値が生成されることはありません。 正確さは即座にわかります。到達可能なすべての状態を明示的に列挙します。 

このアプローチの問題は、最悪の場合の実行時間です。 最悪の場合、シーケンスは次のサイクル長になる可能性があります。$m$、私たちが実行することを意味します$O(m)$トランジション。 と$m \le 10^9$、これは実現可能な限界をはるかに超えています。 

重要な観察は、これが有限体上の関数グラフであるということです。 すべてのノードには出力エッジが 1 つだけあるため、構造はサイクルにつながるテールで構成されます。 やみくもにシミュレーションするのではなく、遷移の代数的特性を利用します。$$X_{n+1} = aX_n + b \pmod m$$プライム用$m$、次のいずれかに応じて、明示的に解決するか、離散対数形式の条件への到達可能性を下げることができます。$a = 1$または$a \ne 1$。 

いつ$a = 1$、繰り返しは次のようになります。$$X_n = X_0 + nb \pmod m$$これは線形進行であるため、到達可能性はモジュラー線形方程式を解くことになります。 

いつ$a \ne 1$、繰り返しを展開できます。$$X_n = a^n X_0 + b \cdot \frac{a^n - 1}{a - 1} \pmod m$$これにより、問題は、指定された条件が満たされているかどうかを確認することに変わります。$x$いくつかの場合はこの閉じた形式で表現できます$n$これは、素数を法とする乗法群の方程式を解くことになります。 

標準的なトリックは、次のべき乗を含む形式に再配置することです。$a$、その後、離散対数問題に帰着します。これは、ベイビーステップ ジャイアントステップを使用して解決できます。$O(\sqrt{m})$。 

したがって、次の事実を利用して、総当りシミュレーションから有限体上の代数的還元への移行が行われます。$m$プライムです。

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$x == X_0$。 「はい」の場合は、シーケンスがそこから始まるため、すぐに「はい」を返します。 これにより、答えが自明な場合に不必要な計算が回避されます。 
2. もし$a = 1$、シーケンスを次のように解釈します$X_n = X_0 + nb \pmod m$。 これにより、漸化式が有限体上の線形算術数列に単純化されます。 
3. もし$a = 1$、計算する$d = (x - X_0) \bmod m$。 次に、存在するかどうかを判断する必要があります。$n \ge 0$そのような$nb \equiv d \pmod m$。 
4. もし$b = 0$、シーケンスは一定です。 次の場合にのみ YES を返します。$x = X_0$、そうでない場合は NO。 これは、縮退した固定小数点の場合を処理します。 
5. それ以外の場合は計算します$g = \gcd(b, m)$。 以来$m$は素数です。これは 1 または$m$ですが、ここでは一般的に扱います。 
6.次のことを確認します。$d$で割り切れます$g$。 そうでない場合、モジュラーサブグループでは合同を満たすことができないため、解は存在しません。 
7. で割って式を簡略化します。$g$、それから解決します$n \cdot (b/g) \equiv (d/g) \pmod{m/g}$。 のモジュラー逆関数を計算します。$b/g$モジュロ$m/g$を取得してから、$n$。 
8. 有効な場合は YES を返します。$n$シーケンス内の到達可能な状態に対応します。 
9. もし$a \ne 1$、繰り返しを閉じた形式で書き直します。$$X_n = a^n X_0 + b \cdot (a^n - 1) \cdot (a - 1)^{-1} \pmod m$$10. 次の形式の方程式に並べ替えます。$$a^n \cdot (X_0 + c) \equiv x + c \pmod m$$どこ$c = b \cdot (a - 1)^{-1} \bmod m$。 

1. コンピューティング$A = X_0 + c$そして$B = x + c$モジュロ$m$。 もし$A = 0$、乗法構造が崩れるため個別に扱います。 
2. それ以外の場合は、次のように削減します。$$a^n \equiv B \cdot A^{-1} \pmod m$$これは、素数を法とする乗法群における離散対数問題です。 

1. ベイビーステップ ジャイアントステップを使用して、$n$そのように存在します$a^n$目標値と一致しています。 

### なぜ効果があるのか

 シーケンスの進化は、有限体上で線形変換を繰り返し適用することによって完全に決定されます。 このような構造では、すべての状態は次の関数として表現できます。$a^n$、加算項は固定シフトを介して吸収できます。 これにより、到達可能性の問題は、によって生成される循環サブグループのメンバーシップに限定されます。$a$。 以来$m$が素数である場合、このグループは適切に構造化されており、離散対数計算をサポートします。 すべての変換ステップは元の再帰と代数的に等価であるため、アルゴリズムは到達可能な状態を決してスキップしたり、到達不可能な状態を認めたりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = egcd(b, a % b)
    return g, y, x - (a // b) * y

def modinv(a, m):
    g, x, _ = egcd(a, m)
    return x % m

def solve():
    a, b, m, x0, x = map(int, input().split())

    if x == x0:
        print("YES")
        return

    if a == 1:
        if b == 0:
            print("NO")
            return

        d = (x - x0) % m
        g = 1  # m is prime, so gcd(b, m) is 1 unless b == 0 handled above

        inv_b = modinv(b, m)
        n = (d * inv_b) % m
        print("YES")
        return

    c = (b * modinv(a - 1, m)) % m
    A = (x0 + c) % m
    B = (x + c) % m

    if A == 0:
        print("YES" if B == 0 else "NO")
        return

    target = (B * modinv(A, m)) % m

    # baby-step giant-step for a^n = target mod m
    from math import isqrt

    def bsgs(g, h, mod):
        m_ = isqrt(mod) + 1
        table = {}

        e = 1
        for j in range(m_):
            table[e] = j
            e = (e * g) % mod

        factor = modinv(pow(g, m_, mod), mod)

        gamma = h
        for i in range(m_ + 1):
            if gamma in table:
                return True
            gamma = (gamma * factor) % mod

        return False

    print("YES" if bsgs(a, target, m) else "NO")

if __name__ == "__main__":
    solve()

微妙な実装の詳細がこのケースを処理しています$A = 0$、変換が崩壊し、$x = -c$到達可能です。 もう 1 つのデリケートな点は、逆モジュラーが素数法に基づいて計算されるようにすることです。これにより、明示的に処理される縮退の場合を除いて存在が保​​証されます。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$a = 1$そして$b = 0$。 この場合、シーケンスは決して変更されないため、初期値のみに到達できます。 次の場合、アルゴリズムは直ちに YES を返します。$x = X_0$、それ以外の場合は NO、定数シーケンスの真の動作と一致します。

最後の微妙なケースは、離散対数のターゲットが、によって生成されたサブグループに含まれない場合です。$a$。 ベイビーステップ ジャイアントステップ手順は、サイクル長の限界まで到達可能なすべての指数を列挙するため、一致を見つけることが正しく失敗します。
