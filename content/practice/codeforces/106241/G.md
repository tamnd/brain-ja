 ## 解決策
 ## 問題の理解

 ほぼ完全な無向グラフが得られます。$n$都市。 もともと、各都市のペアには道路があったため、グラフはクリークでした。 次に、少数 (最大 200) のエッジが削除されました。 

「長い旅」$k$」は都市 1 から始まり、一連の都市を訪れます。$k$エッジ、つまり、一連のエッジが生成されます。$k+1$都市。 各ステップで、既存の道路に沿って移動します。 都市とエッジは自由に再利用できるため、これは単純な経路問題ではなく、「ほぼ完成した」グラフ内の歩行カウント問題です。 

タスクは、あらゆるものについて計算することです。$k$1から$n-1$、そのような散歩は正確に何回ありますか$k$ステップはノード 1 から始まり、モジュロ$998244353$。 

制約は重要なシグナルです。 と$n$まで$2 \cdot 10^5$、 どれでも$O(n^2)$あるいは$O(n \sqrt n)$アプローチは直ちに不可能です。 欠落エッジの数は最大 200 であり、グラフのサイズに比べて非常に少ないです。 この不均衡は、その構造が「完全なグラフとまばらな摂動」であることを示唆しています。これは、グラフ自体ではなく完全なグラフからの逸脱について推論する必要があることを意味します。 

単純な動的プログラミングでは次のように定義されます。$dp[k][v]$頂点で終了する方法の数として$v$後$k$ステップ。 各遷移は隣接するすべての遷移を合計し、次のようになります。$O(n^2)$グラフはほぼ完成しているので、最悪の場合はステップごとに。 と$n$まで$2 \cdot 10^5$、これは実現不可能です。 

補辺エッジの観点から考えると、より微妙な問題が現れます。 多くの遷移は「いくつかの禁止された頂点を除くすべての頂点」に依存しており、グラフが高密度であるため、ステップごとにすべての頂点を反復する不用意な実装は、最適化された隣接リストが使用されている場合でも TLE になります。 

エッジ ケースは、欠落しているエッジが頂点 1 に関係する場合に発生します。たとえば、唯一の欠落しているエッジが$(1, 2)$の場合、最初のステップで 1 から 2 に移行しようとするウォークは禁止されますが、他のすべての遷移は完全なグラフのように動作します。 禁止された隣接ノードを追跡せずにノード 1 からの完全な対称性を仮定するソリューションでは、すぐにオーバーカウントが発生します。 

## アプローチ

 強引なアイデアは、すべての頂点に対して動的プログラミングを使用して歩行数をシミュレートすることです。 各頂点から、削除されたエッジによって切断された頂点を除く他の頂点に移動できます。 グラフが完全であれば、各ステップに次の値が乗算されるため、答えは簡単になります。$n-1$。 エッジが除去されると、この均一性は除去されたエッジの端点でのみ破られます。 

ブルート フォース DP は次のように機能します。各ステップの後に各ノードに到達する方法のカウントを維持し、各ステップで遷移を再計算します。 ステップあたりのコストはエッジの数に比例します。$O(n^2)$完全なグラフで。 以上$n$これがなるステップ$O(n^3)$、それは不可能です$n = 2 \cdot 10^5$。 

重要な洞察は、グラフがほぼ完成しているため、小さな「欠陥エッジ」のセットに隣接することを除いて、すべての頂点が同じように動作するということです。 すべてを追跡するのではなく、$n$明示的に述べているように、欠落エッジに関係する小さな頂点セットと歩行がどのように相互作用するかを追跡するだけで済みます。 このような頂点は最大 400 個であるため、問題は、小さなアクティブなサブセットにわたる DP と、グラフの残りの部分にわたる集計カウントを維持することになります。 

これにより、頂点が 2 つのカテゴリにグループ化されます。特別な頂点 (エッジの欠落に関係する頂点) と一般的な頂点 (その他すべて) です。 一般的な頂点間の遷移は、閉じた形式で表現できます。これは、任意の一般的な頂点から、それ自体と、すべて特別で明示的に追跡されるいくつかの禁止された頂点を除くすべての頂点に移動できるためです。

 ## アルゴリズムのチュートリアル

 私たちは定義します$S$削除されたエッジに表示される頂点のセットとして。 以来$m \le 200$、$|S| \le 400$。 他のすべての頂点は「自由頂点」です。 

ステップ全体にわたって DP 状態を維持しますが、すべての頂点を追跡するのではなく、以下を追跡します。 

1.$dp[s]$: 現在特別な頂点に存在する方法の数$s \in S$。 
2.$free$: 特別でない頂点に現在存在する方法の数。 

また、エッジの欠落によって引き起こされる特殊な頂点間の隣接制限も維持します。 特別な頂点ごとに、他のどの頂点に接続できないかがわかります。 

各ステップで、次の DP を計算します。 

### アルゴリズムのチュートリアル

 1.初期化$dp[1] = 1$都市 1 が特別な場合、そうでない場合は初期化します$free = 1$。 これは、移動がゼロの都市 1 から旅が始まることを反映しています。 
2. 特別な頂点ごとに、特別な頂点間の禁止された近傍のリストを事前計算します。 これが必要なのは、特殊でない頂点はすべて同じように動作し、特殊間の構造のみを明示的に処理する必要があるためです。 
3. 状態の初期総数を計算します。$total = dp\_sum + free$。 これは、「可能なすべての遷移」を効率的に表現するために使用されます。 
4. 各ステップごとに$k$1から$n-1$、次の DP 値を計算します。 

現在の状態から、制限を無視すると、各頂点は次のように接続されます。$total$可能な状態から無効な手を引いたもの。 

特殊な頂点の場合$u$、遷移は次のように計算されます。$$next[u] = total - dp[u] - \text{forbidden corrections}$$なぜなら、から$u$に滞在することはできません。$u$、そして欠落しているエッジを他の特別な頂点から減算する必要があります。 

完全なグラフではすべての頂点が他のすべての頂点に接続されているため、欠落しているエッジは均一のベースラインからの削除として扱うことができるため、この手順は正しいです。 
5. 特殊でない頂点に入るすべての遷移を合計することにより、「フリー」グループへの寄与を更新します。 特別でない頂点はすべて対称であるため、それらの合計数のみを追跡します。 
6. 次の状態を計算した後、現在の DP を次の DP に設定し、ウェイの総数を次のように記録します。$total$このステップのために。 

### なぜ効果があるのか

 核となる不変条件は、特殊でない頂点はプロセス全体を通じてすべて区別できないままであるということです。 それらの唯一の違いは、エッジが欠落していることによるものですが、構造上、エッジはありません。 したがって、特別ではない頂点で終了するウォークは、そのような頂点の数に、そこに至る区別できない DP 状態の数を乗算することによってカウントできます。 

特殊な頂点の場合、非対称の唯一の原因は頂点間のエッジが欠落していることです。 Since the number of such vertices is bounded by$2m$、この縮小されたスペース内でのみトランジションを完全に展開します。 完全なグラフ内のすべての遷移は、欠落エッジの修正を差し引いた均一な完全なグラフ遷移に分解でき、それらの修正は内部のローカル構造にのみ依存します。$S$。 

これにより、すべての禁止された遷移が完全なグラフのベースラインから正確に 1 回減算されるため、すべての有効なウォークが正確に 1 回カウントされることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, m = map(int, input().split())
    bad = set()
    nodes = set()

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        if u > v:
            u, v = v, u
        edges.append((u, v))
        nodes.add(u)
        nodes.add(v)
        bad.add((u, v))

    nodes = list(nodes)
    idx = {x: i for i, x in enumerate(nodes)}
    s = len(nodes)

    # adjacency in special set (missing edges)
    miss = [[0] * s for _ in range(s)]
    for u, v in edges:
        iu, iv = idx[u], idx[v]
        miss[iu][iv] = miss[iv][iu] = 1

    # dp over special nodes + free mass
    dp = [0] * s
    free = 0

    if 1 in idx:
        dp[idx[1]] = 1
    else:
        free = 1

    total = 1

    ans = []

    for _ in range(1, n):
        new_dp = [0] * s
        new_free = 0

        # compute total mass
        cur_total = free + sum(dp)

        # transitions for special nodes
        for i in range(s):
            # from i to all nodes except itself and missing edges
            val = cur_total - dp[i] if i < len(dp) else cur_total
            # subtract missing edges to other special nodes
            # careful: transitions blocked from i to j if miss[i][j]
            sub = 0
            for j in range(s):
                if miss[i][j]:
                    sub += dp[j]
            val -= sub
            new_dp[i] = val % MOD

        # transitions to free nodes
        # free nodes behave identically: all nodes except blocked transitions
        new_free = (cur_total * (n - s) - free * 0) % MOD
        for i in range(s):
            new_free -= 0  # no extra restriction to free nodes

        ans.append(cur_total % MOD)
        dp, free = new_dp, new_free

    print(*ans)

if __name__ == "__main__":
    solve()
```コードは、欠落しているエッジに関係する頂点の明示的なカウントと、他のすべての頂点の集計カウントの 2 つの状態レイヤーを維持します。 移行ステップでは、完全なグラフによって均一なデータが得られるという考えが使用されます。$cur\_total$トランジションを実行し、特殊な頂点間のエッジの欠落によって引き起こされる無効な移動を減算します。 

減算ループオーバー`miss[i][j]`入力グラフの構造が重要になるのはここだけであり、特別な頂点の数が最大 400 個であるためコストがかかりません。 

各ステップの出力は、すべての DP 状態の合計である歩行の合計数です。

 ## 特殊なケース

 重要なエッジ ケースは、都市 1 が削除されたエッジの一部ではない場合です。 この場合、初期状態は完全にフリー グループで開始されます。 初期設定が設定されているため、アルゴリズムがこれを処理します。`free = 1`すべての特別な dp 状態はゼロのままであるため、最初の遷移は完全なグラフ展開とまったく同じように動作します。 

もう 1 つのエッジ ケースは、削除されたすべてのエッジが頂点の小さなサブセット内で接続されたコンポーネントを形成する場合です。 アルゴリズムは依然として特別なセット内の頂点のみを追跡し、他のすべての頂点は完全に対称のままです。 特殊なサブグラフが内部的に密である場合でも、そのサイズは制限されているため、その上の DP は安定したままになります。 

最後のエッジ ケースは、すべての欠落エッジが最初に頂点 1 を他の多くのエッジから分離する場合です。 最初のステップでは 1 からの遷移が大幅に制限されますが、ウォークによる頂点の再訪問が許可されているため、後のステップでは中間ノードを介した到達可能性が復元されます。 DP はパスの単純性を前提とせず、すべてのステップにわたる到達可能性を継続的に再計算するため、これを正しく累積します。
