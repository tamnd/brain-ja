 ## 解決策
 ## 問題の理解

 サイズのアルファベットがあります`m`、最初のものから構成されます`m`シーケンスからのシンボル`a..zA..Z`。 一部のシンボルの順序付きペアは禁止されています。 ペアの場合`(x, y)`禁止されている場合はシンボル`y`記号の直後には指定できません`x`DNA 文字列の中にあります。 

タスクは、長さの DNA 文字列が何本あるかを数えることです。`n`すべての隣接制限を満たします。 答えはモジュロで報告する必要があります`10^9 + 7`。 

問題を有向グラフとして表示するのは便利な方法です。 各ヌクレオチドは頂点です。 頂点からの有向エッジがあります`u`頂点へ`v`ペアなら`(u, v)`許可されています。 有効な DNA シーケンスは、このグラフのウォークに対応します。 シーケンス内の隣接する文字のペアはすべて、許可されたエッジに従う必要があります。 

制約によって、意図したソリューションが完全に決まります。 アルファベットのサイズは最大です`52`、小さいです。 一方で、`n`と同じ大きさにすることができます`10^15`これにより、位置を 1 つずつ反復する動的プログラミングが除外されます。 たとえ`O(n)`アルゴリズムは不可能です。 非常に小さな状態空間と非常に長い長さを組み合わせた問題がある場合、通常、行列のべき乗は正しい方向になります。 

誤って対処しやすい特殊なケースがいくつかあります。 

長さ 1 の DNA を考えてみましょう。```
1 3 2
ab
ba
```答えは`3`、禁止されたペアの影響を受けません。 長さ 1 の文字列には、隣接するペアがまったく含まれません。 

もう 1 つの重要なケースは、すべての遷移が禁止されている場合です。```
2 1 1
aa
```答えは`0`。 シンボルは 1 つありますが、それ自体に続くことはできないため、長さ 2 のシーケンスは存在しません。 

3 番目のケースは次の場合です。`n`非常に大きいですが、`m = 1`:```
1000000000000000 1 0
```有効なシーケンスは 1 つだけあります。`"aaaa..."`。 位置を反復するソリューションは決して完了しません。 

## アプローチ

 最も直接的なアプローチは、ポジションに対する動的プログラミングです。 

させて`dp[i][j]`有効な長さの文字列の数になります`i`記号で終わる`j`。 次の層を計算するために、許可されたすべての遷移を試します。$$dp[i+1][v] += dp[i][u]$$これは正しいです。すべての有効な文字列は次で終わります。`u`まで拡張できます`v`いつでも`(u,v)`許可されています。 

問題は次の値です。`n`。 小さなアルファベット サイズを使用してトランジションを最適化したとしても、実行時間は DNA の長さに比例します。 と`n`まで`10^{15}`、これは絶望的です。 

重要な観察は、DP 遷移が線形であるということです。 すべての終了シンボルのカウントをベクトルに格納すると、1 つの DP ステップは単なる行列の乗算になります。 

させて`A`になる`m × m`遷移行列:$$A[u][v] = \begin{cases} 1 & \text{if transition } u \to v \text{ is allowed}\\ 0 & \text{otherwise} \end{cases}$$もし`f_i`長さのカウントの行ベクトルです`i`、 それから$$f_{i+1} = f_i A$$トランジションを繰り返し適用すると、$$f_n = f_1 A^{n-1}$$今、その巨大な価値は、`n`管理可能になります。 以来`m ≤ 52`で、バイナリべき乗を使用して行列をべき乗することができます。`O(m^3 log n)`時間。 

任意の記号を最初の文字として選択できるため、長さ 1 の初期ベクトルにはすべて 1 が含まれます。 

計算後`A^(n-1)`、初期ベクトルを乗算し、最終的なカウントをすべて合計します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ポジションに対するブルートフォース DP | O(nm²) | O(m) | 遅すぎる |
 | 行列のべき乗 | O(m3 log n) | O(㎡) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 文字のインデックス マッピングを作成します。 記号`'a'..'z'`にマップします`0..25`、 そして`'A'..'Z'`にマップします`26..51`。 
2. を構築します。`m × m`遷移行列`A`。 

最初はすべてのエントリが`1`、すべての遷移が許可されることを意味します。 
3. 各禁止ペアを読み取ります`(x, y)`対応する行列エントリを次のように設定します`0`。 

マトリックスは、許可された遷移のグラフを正確に表すようになりました。 
4. 特殊なケースに対処する`n = 1`。 

すべてのシンボルは単独で有効な DNA 文字列を形成するため、答えは単純です。`m`。 
5. コンピューティング`A^(n-1)`2進累乗を使用します。 

各行列の乗算はモジュロで実行されます。`10^9 + 7`。 
6. 初期行ベクトルを作成する$$f_1 = [1,1,\ldots,1]$$任意の記号を最初の文字として選択できるためです。 
7. 乗算`f_1`による`A^(n-1)`。 

結果のベクトルには、有効な長さの数が含まれます。`n`各記号で終わる文字列。 
8. 結果として得られるベクトルモジュロのすべてのエントリを合計します。`10^9 + 7`。 

これにより、有効な DNA 文字列の総数が得られます。 

### なぜ効果があるのか

 遷移行列は、通常の動的プログラムとまったく同じ繰り返しをエンコードします。 エントリ`(u,v)`文字列が次で終わる場合、正確に 1 に等しくなります。`u`シンボルによって拡張できます`v`。 

カウントベクトルを乗算する`A`1 つの DP 遷移を実行します。 乗算`A²`2 つのトランジションを実行します。 帰納法、乗算により`A^k`実行します`k`連続した DP 遷移。 長さがあるので、`n`文字列は 1 つの最初の記号とその後に続く記号で構成されます。`n-1`トランジション、長さのカウント ベクトル`n`まさに$$f_1 A^{n-1}.$$最終的なベクトルを合計すると、終了記号に関係なく、すべての有効な文字列がカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def char_id(c):
    if 'a' <= c <= 'z':
        return ord(c) - ord('a')
    return ord(c) - ord('A') + 26

def mat_mul(a, b):
    n = len(a)
    res = [[0] * n for _ in range(n)]

    for i in range(n):
        ai = a[i]
        ri = res[i]

        for k in range(n):
            if ai[k] == 0:
                continue

            val = ai[k]
            bk = b[k]

            for j in range(n):
                ri[j] = (ri[j] + val * bk[j]) % MOD

    return res

def mat_pow(mat, exp):
    n = len(mat)

    res = [[0] * n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1

    while exp:
        if exp & 1:
            res = mat_mul(res, mat)

        mat = mat_mul(mat, mat)
        exp >>= 1

    return res

def solve():
    n, m, k = map(int, input().split())

    trans = [[1] * m for _ in range(m)]

    for _ in range(k):
        s = input().strip()
        u = char_id(s[0])
        v = char_id(s[1])
        trans[u][v] = 0

    if n == 1:
        print(m)
        return

    power = mat_pow(trans, n - 1)

    ans = 0

    for col in range(m):
        total = 0
        for row in range(m):
            total += power[row][col]
        ans = (ans + total) % MOD

    print(ans)

solve()
```遷移行列は、禁止ペア情報から直接構築されます。 許可された隣接関係はすべて、`1`、すべての禁止された隣接関係は、`0`。 

べき乗ルーチンは、標準の 2 進累乗パターンを使用します。 以来`n`と同じ大きさにすることができます`10^15`、必要な行列の二乗は約 50 個だけです。 

最終的な計算は注目に値します。 初期ベクトルは完全に 1 で構成されます。 すべて 1 の行ベクトルにべき乗行列を乗算することは、その行列の各列を合計することと同じです。 この実装ではこの事実を利用し、余分なベクトル行列の乗算を回避します。 

すべての算術はモジュロで実行されます`10^9 + 7`。 Python の整数はオーバーフローしませんが、累積するたびに剰余を減らすことで計算の効率が維持されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(m3 log n) | 3 次行列乗算による行列のべき乗 |
 | スペース | O(㎡) | 複数の保管`m × m`行列 |

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 1000000007

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def char_id(c):
        if 'a' <= c <= 'z':
            return ord(c) - ord('a')
        return ord(c) - ord('A') + 26

    def mat_mul(a, b):
        n = len(a)
        res = [[0] * n for _ in range(n)]

        for i in range(n):
            for k in range(n):
                if a[i][k] == 0:
                    continue
                for j in range(n):
                    res[i][j] = (res[i][j] + a[i][k] * b[k][j]) % MOD

        return res

    def mat_pow(mat, exp):
        n = len(mat)
        res = [[0] * n for _ in range(n)]

        for i in range(n):
            res[i][i] = 1

        while exp:
            if exp & 1:
                res = mat_mul(res, mat)
            mat = mat_mul(mat, mat)
            exp >>= 1

        return res

    n, m, k = map(int, input().split())

    trans = [[1] * m for _ in range(m)]

    for _ in range(k):
        s = input().strip()
        trans[char_id(s[0])][char_id(s[1])] = 0

    if n == 1:
        return str(m)

    power = mat_pow(trans, n - 1)

    ans = 0
    for col in range(m):
        for row in range(m):
            ans = (ans + power[row][col]) % MOD

    return str(ans)

# sample
assert run("3 3 2\nab\nba\n") == "17"

# minimum size
assert run("1 1 0\n") == "1"

# single symbol, self-transition forbidden
assert run("2 1 1\naa\n") == "0"

# all transitions allowed
assert run("2 3 0\n") == "9"

# n=1 ignores restrictions
assert run("1 2 4\naa\nab\nba\nbb\n") == "2"

 |`1 1 0`|`1`| 可能な最小のインスタンス |
 |`2 1 1 / aa`|`0`| 禁断のセルフループ |
 |`2 3 0`|`9`| 全結合グラフ |

## 特殊なケース

 次のことを考慮してください。```
1 2 4
aa
ab
ba
bb
```あらゆる移行は禁止されていますが、答えは次のとおりです。`2`。 アルゴリズムは次の場合にすぐに戻ります。`n = 1`1 文字の文字列には隣接関係が存在しないためです。 やみくもに累乗したり、遷移を適用したりするソリューションでは、誤ってゼロが生成される可能性があります。 

考慮する：```
2 1 1
aa
```遷移行列は次のとおりです。$$[0]$$以来`n-1 = 1`、パワードマトリックスはまだ`[0]`。 列の合計はゼロなので、答えはゼロです。 これは、可能な隣接ペアのみが禁止されているという事実を正しく捉えています。 

考慮する：```
1000000000000000 1 0
```マトリックスは次のとおりです。$$[1]$$この行列のパワーは残ります`[1]`。 2 進累乗は対数時間で巨大な指数を処理し、答えを生成します。`1`。 これはまさに、位置ごとの動的プログラミング アプローチを排除するシナリオです。
