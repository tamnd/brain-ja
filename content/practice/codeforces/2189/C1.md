 ## 問題の理解

 以下の数値の順列を構築する必要があります。`1`に`n`。 

あらゆるポジションについて`i`と`2 ≤ i ≤ n-1`、何らかの立場が存在するはずです`j`満足のいく`i ≤ j ≤ n`そのような$$p_i = p_j \oplus i.$$順列全体を自由に選択できるため、これは建設的な問題です。 私たちは何も数えたり、何かを最適化したりすることを求められるのではなく、有効な取り決めを 1 つ作成することだけを求められます。 

制約`n ≤ 2 · 10^5`そしてすべての合計`n`テストケース全体で最大でも`2 · 10^5`すぐに示唆する`O(n)`テストケースごとの構築は完全に安全です。 順列を検索するアプローチは絶望的です。 可能な位置のすべてのペアをチェックするだけでも、すでに`O(n²)`、次の場合には大きすぎます。`n`およそ20万です。 

問題の微妙な部分は、XOR 条件に位置と値の両方が含まれることです。 貪欲に数字を配置しようとする単純な試みにより、ある位置では有効な関係が簡単に作成され、別の位置ではそれが破壊されてしまう可能性があります。 

考慮する`n = 4`。 単純に恒等順列を使用する場合`[1,2,3,4]`、次に、`i = 2`以下に等しい値が必要になります`2 ⊕ 2 = 0`の順列では出現できません。`1..n`。 条件はすぐに失敗します。 

もう 1 つの簡単な間違いは、順列プロパティを保存せずにローカルでペアを構築することです。 たとえば、すべての必要な位置を XOR する必要があると判断した場合、`1`、割り当ててみるかもしれません`p_i = i ⊕ 1`。 のために`n = 3`、これは値を与えます`[?,3,2]`、場所を残さない`1`からのすべての数値が保証されるわけではありません`1`に`n`ちょうど 1 回出現します。 

この構造は XOR 要件を満たし、真の順列を維持する必要があります。 

## アプローチ

 ブルートフォースの考え方では、順列を検索し、すべての位置が条件を満たすかどうかを確認することから始まります。 候補の順列が与えられた場合、検証には時間がかかります`O(n²)`可能な限りすべてをテストしたら`j`価値観。 順列の数は`n!`、したがって、これは明らかに不可能です。`n`。 

重要な観察は、この条件が必要とするのは、何らかの適切な条件が存在することのみであるということです。`j`。 異なる立場では異なる証人を使用しなければならないということは何もありません。 

これは、すべての位置が同じ場所を指すようにすることを示唆しています。 

最も簡単な選択は最後の位置です。 手配すれば$$p_n = 1,$$そうすれば、必要なすべての位置を満たすだけで済みます。$$p_i = 1 \oplus i.$$問題ははるかに単純になります。 任意の整数の場合`i ≥ 2`、値`i ⊕ 1`はその隣の番号です。$$2 \leftrightarrow 3,\quad 4 \leftrightarrow 5,\quad 6 \leftrightarrow 7,\ldots$$なぜなら、`1`最下位ビットのみを反転します。 

したがって、連続する数字をペアにすることができます。$$2 \leftrightarrow 3,\quad 4 \leftrightarrow 5,\quad 6 \leftrightarrow 7,\ldots$$そして場所$$p_i = i \oplus 1$$あらゆるポジションに対して`2`に`n-1`。 

使用されていない唯一の残りの番号が位置に配置されます。`1`。 これにより完全な順列が得られ、必要なすべての位置を選択できます。`j = n`。 この構造は、まさに簡単なバージョンとして受け入れられているアイデアです。

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`p`長さの`n`。 
2.置く`1`最後の位置なので、`p[n] = 1`。 
3. ポジションごとに`i`から`2`に`n-1`：

もし`i`偶数、設定`p[i] = i + 1`。 

もし`i`奇数です、設定されています`p[i] = i - 1`。 

これはまったく同じです`p[i] = i ⊕ 1`。 
4. からの 1 つの値`1..n`未使用のままです。 

もし`n`奇数である場合、その未使用の値は`n - 1`ので、設定します`p[1] = n - 1`。 

もし`n`が偶数である場合、その未使用の値は`n`ので、設定します`p[1] = n`。 
5. 順列を出力します。 

### なぜ効果があるのか

 あらゆるポジションについて`i`と`2 ≤ i ≤ n-1`、構造は与える$$p_i = i \oplus 1.$$以来`p_n = 1`、$$p_n \oplus i = 1 \oplus i = i \oplus 1 = p_i.$$したがって、選択する`j = n`常に必要な条件を満たします。 

位置に割り当てられる値`2..n-1`それぞれの連続するペアを交換することによって得られる数値です。`(2,3)`、`(4,5)`、`(6,7)`、 等々。 番号は繰り返されません。 と共に`p_n = 1`、ちょうど 1 つの数値が未使用のまま残り、位置に配置されます。`1`。 したがって、からのすべての数字は、`1`に`n`は 1 回だけ出現するため、配列は有効な順列になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    
    for _ in range(t):
        n = int(input())
        
        p = [0] * (n + 1)
        p[n] = 1
        
        for i in range(2, n):
            if i & 1:
                p[i] = i - 1
            else:
                p[i] = i + 1
        
        if n & 1:
            p[1] = n - 1
        else:
            p[1] = n
        
        print(*p[1:])

solve()
```構築は証明に直接続きます。

唯一の境界条件は位置です`1`。 簡単なバージョンでは位置を要求するだけであるため、XOR 要件を満たす必要はありません。`2`に`n-1`。 他の位置を埋めた後、ちょうど 1 つの値が未使用のままになります。 奇数の場合`n`それはです`n-1`、一方、偶数`n`それはです`n`。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve_io():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n = int(input())

        p = [0] * (n + 1)
        p[n] = 1

        for i in range(2, n):
            p[i] = i - 1 if i & 1 else i + 1

        p[1] = n - 1 if n & 1 else n
        ans.append(" ".join(map(str, p[1:])))

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve_io()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample-sized cases

 ## 特殊なケース

 のために`n = 3`、制約された位置は 1 つだけです。`i = 2`。 建設が生み出すのは、`[2,1,3]`。 以来`3 ⊕ 2 = 1`、条件はすぐに満たされます。 これにより、可能な限り最小の入力がチェックされます。 

のために`n = 4`、構造は与える`[4,3,2,1]`。 必要なポジションは、`2`そして`3`。 我々は持っています$$1 \oplus 2 = 3,$$そして$$1 \oplus 3 = 2.$$どちらも対応するエントリと一致するため、条件が成立します。 

次のような奇数の値の場合`n = 5`、最初の位置が受け取ります`n-1 = 4`。 この値は他の場所では決して使用されません。`2..4`正確に含む`{3,2,1}`そして最後の位置にはすでに含まれています`1`。 順列プロパティはそのまま残ります。 

大きな偶数値の場合は、同じ引数が機能します。 中間位置ごとに収納`i ⊕ 1`、それぞれが最後の位置を指し、残りの未使用の値が先頭に配置されます。 パリティを超える特別な処理は必要ありません。
