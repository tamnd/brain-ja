 ## 解決策
 ## 問題の理解

 一連の道路標識の中を移動するドライバーをシミュレートしています。各標識は特定の制限速度を設定するか、現在の制限を解除して元の全国制限速度に戻します。 

重要な詳細は、国の制限速度が10の倍数であり、これまで示された明示的な制限速度標識よりも厳密に高いことを除いて、私たちには不明であるということです。 これは、「リセット」のサインが表示されたときはいつでも、固定された数値を直接復元することはできないことを意味します。 代わりに、これまでに観察されたすべてのものと一致する最大可能速度を推測する必要があります。 

タスクは順次実行されます。 各標識の後に、それまでに見られたすべての制約を考慮して、合法であることが保証される最高速度を出力する必要があります。 

入力は操作のストリームです。 各操作は、最大許容速度をその値に即座に制限する数値制限、または明示的な制限をすべて削除して未知の国の速度制限体制に戻すリセットを示すスラッシュ記号のいずれかです。 

制約は小さく、最大でも 100 個の記号があります。 これは、二次時間までの解はすでに安全であることを意味しますが、問題の構造は線形シミュレーションで十分であるほど単純です。 

微妙な失敗例がリセット付近に現れます。 全国の制限速度が固定されていると誤って仮定したり、推測値を「記憶」しようとしたりすると、論理が破綻します。 

たとえば、次のことを考えてみましょう。 

入力:```
/
```最初の標識は速度制限でなければならないため、これは不可能ですが、問題が浮き彫りになります。リセット後は、以前の制限値から導き出さない限り、具体的な数値が得られません。 

より現実的なエッジケースは次のとおりです。 

入力:```
50
80
/
```正しい推論:

 50 を超えると、制限は 50 になります。 

80 を超えると、制限は 50 になります (これまでに確認された最小の制限に常に従うため)。 

リセット後、制限は未知の国内制限速度になります。これは、実際に確認されている制限よりも厳密に大きい必要があり、少なくとも 90 (10 の倍数である必要があるため) でなければなりません。 したがって、答えは90になります。 

単純に「制約を忘れ」、リセット後に無制限の値またはゼロを出力する単純な実装は正しくありません。 

重要な問題は、リセットでは単に状態をクリアするだけでなく、履歴から一貫した上限を再構築する必要があることです。 

## アプローチ

 強引な解釈では、すべての標識の後に、以前のすべての制約を再検討して、有効な最大速度を再計算しようとします。 リセットするたびに、逆方向にスキャンしてこれまでに確認された最高速度制限を見つけ、国の速度制限がそれよりも厳密に大きい 10 の最小倍数であると想定します。 国内制限は以前のすべての制限と一致する必要があるため、これは概念的に機能します。 

ただし、このアプローチは、大きな入力に拡張すると非効率的になります。リセットのたびに、以前のすべての符号のフル スキャンがトリガーされ、最悪の場合は 2 次の動作が発生する可能性があるためです。 ここでは N が小さいにもかかわらず、これが状態を単純化する動機になります。 

重要な点は、最初から再計算する必要がないということです。 重要な情報は、最後のリセット以降に確認された最大速度制限だけです。 この値だけで、可能な最小の国内速度制限が決定されます。つまり、最小の 10 の倍数がそれより厳密に大きくなります。 したがって、スキャン履歴の代わりに、スラッシュが表示されるたびにリセットされる実行最大値を維持します。 

これにより、プロセス全体が 1 つのパスに短縮され、サインごとに一定時間の更新が行われます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N^2) | お(1) | 受け入れられるが不要 |
 | 最適 | O(N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 私たちは 1 つの状態、つまり最後のリセット以降に確認された明示的な最大速度制限を維持します。 

1. 変数を初期化する`mx`これは、現在アクティブな最も強い制約を表します。 
2. 数値であることが保証されている最初の符号を読み取り、設定します。`mx`その値に。 すぐに出力してください。 
3. 後続の各記号について、順番に処理します。 
4. 符号が数字の場合`L`、 アップデート`mx`なる`max(mx, L)`。 出力`mx`なぜなら、法定速度は常にこれまでに見られた中で最も厳しい制限によって制限されるからです。 
5. サインが`/`、厳密に次の値よりも大きい 10 の最小倍数として全国制限速度を計算します。`mx`。 これは次のように行うことができます`((mx // 10) + 1) * 10`。 この値を出力しますが、重要なのはリセットしないことです`mx`ゼロへ。 代わりに、概念的には「国内制限を除き制限なし」モードに切り替えます。これは、将来の明示的な制限がそのベースラインから始まる制約を再度確立することを意味します。 
6. すべての標識が処理されるまで続行します。 

重要なアイデアは次のとおりです`mx`リセット間の現在のセグメント内の最も強い明示的制約を常に追跡します。 スラッシュは正確性を保つために履歴を消去するものではなく、次のセグメントの解釈方法を変更するだけです。 

### なぜ効果があるのか

 リセットを行わない場合、合法性は、最後のリセット以降に確認されたすべての速度制限の最小値によって完全に支配されます。 その最小値はまさに現在です`mx`。 リセットが発生すると、欠落している値は国の速度制限だけですが、この問題により、それが観測された制限よりも厳密に 10 の倍数であることが保証されます。 そのような最小値は次によって完全に決定されます。`mx`なので、他に何も推測せずに安全に出力できます。 現在の回答に影響を与える他の履歴情報はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    mx = 0
    first = True
    
    for _ in range(n):
        s = input().strip()
        
        if s == "/":
            # restore national speed limit
            mx = ((mx // 10) + 1) * 10
            print(mx)
        else:
            val = int(s)
            if first:
                mx = val
                first = False
            else:
                mx = max(mx, val)
            print(mx)

if __name__ == "__main__":
    solve()
```実装により実行最大値が維持されます`mx`これは、現在のセグメントで最も厳しい明示的な制限を表します。 数値記号に遭遇すると、この最大値が更新されます。 スラッシュに遭遇した場合、次の 10 の倍数に切り上げて、現在の最大値を暗黙の国内制限に変換します。 

の`first`この問題により、最初の標識が常に速度制限であることが保証されるため、フラグを使用すると、初期状態が適切に処理されることが保証されます。 

よくある落とし穴はリセットです`mx`ゼロオンする`/`。 これは誤って制限がないことを意味しますが、正しい動作は前の最大値から具体的な境界を推測することです。
