 ## 解決策
 ## 問題の理解

 単一の整数が与えられます`s`そしてそれを 2 つの整数に分割する必要があります`a`そして`b`それらの合計が等しくなるように`s`。 両方`a`そして`b`はゼロ以外でなければならず、両方とも 3 桁の整数の範囲内、つまり -999 ～ 999 の範囲内になければなりません。 

タスクは、長さや絶対値などを最適化することではありません。 制約を尊重する限り、有効な分解はどれも受け入れられます。 出力は単純に 2 つの整数が 1 行に出力されます。 

制約ウィンドウは非常に小さいです。 すべての有効な候補は、サイズが約 2,000 × 2,000 の有限のボックス内にあります。 これは、すべての可能性を単純に検索しても、Python では十分に高速であることがすぐにわかります。 ただし、問題の構造から、検索を完全に避ける必要があることがわかります。 

微妙な失敗のケースは、制約の境界に起因するものだけです。 いつも使っているような素朴な発想`a = 0`そして`b = s`ゼロは禁止されているため、すぐに失敗します。 もう 1 つのよくある間違いは、3 桁の境界を無視することです。`a = s`そして`b = 0`、または次の場合に ±999 の範囲外の値を生成する`s`境界に近く、調整が正しく行われていません。 

具体的な問題事例としては、`s = 0`。 試してみると`a = 0`、`b = 0`、どちらも無効です。 もう一つは`s = 1000`、素朴な対称分割は次のようになります`a = 500`、`b = 500`動作しますが、`a = 0`、`b = 1000`両方の制約に同時に違反します。 

## アプローチ

 ブルートフォース手法では、すべての整数が列挙されます。`a`有効な範囲内で計算します`b = s - a`、次に、両方が有効でゼロ以外であるかどうかを確認します。 これは、検索スペースが最大 1999 個の候補であるため機能します。`a`、各チェックは一定時間です。 したがって、合計で約 2,000 回の操作が行われますが、これは非常に高速です。 

ただし、問題の構造により、有効な構造を直接簡単に作成できることが保証されているため、これは不要です。 ゼロ以外の数値が 2 つだけ必要なため、最初に 1 つの数値を意図的に選択し、減算によってもう 1 つを定義できます。 

重要な点は、単一の悪い値、つまりゼロだけを回避する必要があるということです。 選ぶなら`a = 1`、 それから`b = s - 1`。 唯一のリスクがあるのは、`b = 0`、それはまさに次のときに起こります。`s = 1`。 その場合、代わりに選択できます`a = 2`、`b = -1`。 どちらもゼロではなく、依然として範囲内です。 なぜなら`s`は ±999 に制限されており、これらの固定選択肢が許容範囲を超えることはありません。 

したがって、解決策は、検索ではなく、一定時間の条件付き構築に帰着します。

 ## アルゴリズムのチュートリアル

 ゼロを注意深く避けて、答えを直接構築します。 

1. 整数を読み取る`s`。 これは、2 つの非ゼロ部分に分割する必要がある合計です。 
2. もし`s`1に等しくない場合は設定します`a = 1`。 この選択は安全です。`a`はゼロ以外であり、範囲内にあるため、2 番目の数値の構築が簡素化されます。 
3. コンピューティング`b = s - a`。 以来`a`が固定されている場合、これにより必要な合計条件が直接強制されます。 
4. もし`b`ゼロになる場合は、代わりに設定して構造を調整します。`a = 2`そして`b = s - 2`。 これにより、合計を維持しながら両方の数値がゼロ以外であることが保証されます。 
5. 出力`a`そして`b`。 

私たちが明示的に回避する唯一の例外的なケースは、最初の試行でゼロが生成され、2 番目の有効な分解でそれを修正する場合です。 

### なぜ効果があるのか

 私たちは常に強制します`a + b = s`構造上、以来`b`は次のように定義されます`s - a`。 違反できる唯一の制約は、`b ≠ 0`の場合にのみ発生します。`a = s`。 デフォルトを選択すると`a = 1`、このケースはすべて回避します`s ≠ 1`。 いつ`s = 1`、修正`a = 2, b = -1`許可された範囲内で有効な分解を提供します。 許可される間隔は、これらの固定フォールバック値に対応できるほど十分に広いため、境界違反は発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = int(input())

a = 1
b = s - a

if b == 0:
    a = 2
    b = s - 2

print(a, b)
```実装はまさに建設的な戦略に従います。 最も単純なゼロ以外の値から始めます。`1`、パートナーの値を導出します。 唯一の修正は、これにより強制的に発生するまれなケースです。`b`ゼロになることは、`s = 1`。 その場合、2 番目の固定ペアに切り替えます。 

この 1 つの修正を超えると、ループ、検索、およびエッジケースの分岐はありません。
