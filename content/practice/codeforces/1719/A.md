 ## 解決策
 ## 問題の理解

 私たちは、$n \times m$ボードと左下隅から始まるチップ。 各ターンで、プレイヤーは上または右のいずれか 1 つの方向を選択し、その方向に奇数のセルだけチップを移動します。 チップはボードから離れることができません。 

チップが正当な手が存在しない位置に到達すると、ゲームは終了します。 プレイヤーは交互にターンし、両方とも最適にプレイするため、開始位置が最初のプレイヤーである Burenka が勝つか、最初のプレイヤーが負けるかを判断する必要があります。この場合、Tonya が勝ちます。 

入力は複数の独立したゲーム ボードで構成されます。 各ボードについて、完璧なプレイを想定して勝者を出力する必要があります。 

制約は、数学的解決策が存在することを示す主な手がかりです。 どちらの次元も次のように大きくできます。$10^9$、これにより、ボードの状態を調査するアプローチは不可能になります。 1 つのボードでも最大$10^{18}$細胞が存在する可能性があります$10^4$テストケース。 解は、テスト ケースごとに一定時間で計算される単純な式に還元できる必要があります。 

よくある間違いは、ゲームのパリティ構造ではなく、チップの正確な座標に焦点を当てることです。 

ボードについて考えてみましょう。```
1 1
```上にも右にもセルがないため、最初のプレイヤーは移動できません。 正しい答えは次のとおりです。```
Tonya
```最初のプレイヤーが常に少なくとも 1 つの奇妙な手を持っていると仮定する不注意な実装は、ここで失敗します。 

もう 1 つの注意が必要なケースは次のとおりです。```
2 2
```唯一の合法的な動きは、一歩前進するか、一歩右へ進むことです。 どちらの動きも即座に相手に最後の動きを与えます。 正しい答えは次のとおりです。```
Tonya
```多くのプレイヤーは最初、どのボードもこれより大きいと推測します。$1 \times 1$が勝っていますが、それは真実ではありません。 

最後の例は次のとおりです。```
1 4
```最初のプレイヤーは 3 つのセルを右に移動し、即座にゲームを終了できます。 正しい答えは次のとおりです。```
Burenka
```パリティではなく基板サイズのみに基づいたアプローチでは、その理由を説明するのが難しいでしょう。$1 \times 4$そして$1 \times 3$違う行動をする。 

## アプローチ

 最も直接的なアプローチは、すべてのボードの位置をゲーム状態としてモデル化し、勝ちか負けかを計算することです。 状態がチップの現在の座標を表すものとします。 負けている州への動きが存在する場合、州は勝利しており、すべての合法的な動きが勝利している州につながる場合は負けています。 

この再帰は、公平なゲームの標準定義に従っているため、正しいです。 残念ながら、それはすぐに実行不可能になります。 ささやかなものでも$1000 \times 1000$ボードには 100 万の州があり、各州には何百もの発信手がある可能性があります。 実際の制約では、次の寸法まで許容されます。$10^9$、州の探索が完全に不可能になります。 

パターンを見つけるには、いくつかの小さなボードを手動で計算します。 させて$f(n,m)$チップが左下隅から開始したときのゲーム状態を示します。$n \times m$ボード。 

端子の位置は、$f(1,1)$、負けています。 

次に、小さな値を調べます。 

| ボード | 結果 |
 | --- | --- |
 | 1×1 | Ｌ |
 | 1×2 | W |
 | 1×3 | Ｌ |
 | 1×4 | W |
 | 2×1 | W |
 | 2×2 | Ｌ |
 | 2×3 | W |
 | 3×3 | Ｌ |

 くっきりとした模様が現れます。 位置$n$そして$m$同じパリティを持っている人は負けています。 等価性が異なるポジションが勝利します。 

なぜパリティが重要なのでしょうか?

 移動すると、ちょうど 1 つの座標が奇数だけ変更されます。 奇数を加算すると常にパリティが反転します。 したがって、すべての動きは、正確に 1 つの次元のパリティを反転します。 

状態をパリティ ペアのみで表現します。$$(n \bmod 2,\; m \bmod 2)$$負けている状態$(1,1)$端子台に対応$1 \times 1$。 

両方の次元が同じパリティを持つ場合、すべての正当な移動によりパリティ ビットが 1 つだけ変更され、異なるパリティを持つ状態が生成されます。 

次元の等価性が異なる場合、それらを等しくする動きが常に存在します。 奇数の量だけ移動すると 1 つのパリティが反転するため、1 つの次元を適切に削減して同一パリティの状態に達する正当な奇数の移動を選択できます。 

したがって:

 - 同一パリティ$\rightarrow$負け。 
- 異なるパリティ$\rightarrow$勝つこと。 

ゲーム全体がパリティチェックに崩壊します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的 / 州の DP による取締役ポジション | O(nm) | 遅すぎる |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$n$そして$m$。 
2. 次を使用して両方の次元のパリティを計算します。$n \bmod 2$そして$m \bmod 2$。 
3. パリティが等しい場合は、次のように出力します。`"Tonya"`。 

これらのポジションは、すべての手がちょうど 1 つのパリティを反転し、ゲームを異なるパリティのポジションに送るため、負けています。 
4. それ以外の場合は、印刷します`"Burenka"`。 

異なるパリティの位置から、最初のプレイヤーはいつでも同じパリティを生み出す奇妙な手を打つことができ、相手を負けの状態に陥らせることができます。 

### なぜ効果があるのか

 重要な不変条件は、すべての合法的な動きが正確に 1 つの次元のパリティを反転するということです。 これは、パリティ ペアを通じてゲーム全体を分析できることを意味します。$(n \bmod 2, m \bmod 2)$。 

すべての手が異なるパリティの状態に到達するため、等しいパリティを持つ州は負けています。 異なる平価を持つ州が勝利しているのは、等しい平価州への移行が存在しているためです。 すべての位置はこれら 2 つのカテゴリのいずれかに正確に属するため、分類は完全かつ正確です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    if (n & 1) == (m & 1):
        print("Tonya")
    else:
        print("Burenka")
```この解には 2 つの次元のパリティのみが必要です。 使用する`n & 1`そして`m & 1`は、各数値が奇数か偶数かを計算するコンパクトな方法です。 

比較により、パリティが一致するかどうかがチェックされます。 同等の場合は開始位置が負けることを意味するため、Tonya が勝ちます。 パリティが異なるということは、勝利の開始位置を意味するため、ブルレンカが勝ちます。 

シミュレーションは必要なく、パリティのみが使用されるため、オーバーフローの心配もありません。 寸法は次のように大きくなる可能性があります$10^9$、ただし、計算は定数時間のままです。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    t = int(input())
    ans = []

    for _ in range(t):
        n, m = map(int, input().split())
        ans.append("Tonya" if ((n & 1) == (m & 1)) else "Burenka")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out
