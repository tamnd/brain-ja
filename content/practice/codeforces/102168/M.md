 ## 解決策
 ## 問題の理解

 座標平面上には、正確に 4 つの異なる点があります。 そのうち 3 つが同一線上にありません。 これら 4 つの点のうち、4 点すべての凸包の境界に属する点がいくつあるかを判断する必要があります。 

1 つの直線上に 3 つの点が存在しないため、可能な幾何学的構成は 2 つだけです。 4 つの点すべてが凸四角形の頂点である場合、答えは 4 になります。または、1 つの点が他の 3 つによって形成される三角形の内側に厳密に存在する場合、外側の 3 つの点のみが凸包に属し、答えは 3 になります。 

座標は -100 から 100 の間で、常にちょうど 4 つの点があります。 これにより入力サイズが一定になるため、考えられるすべての構成を直接チェックするだけでも十分に高速になります。 大規模な点セットを対象とした O(n log n) 凸包実装は必要ありません。 座標範囲が狭いということは、すべての外積が通常の整数演算に快適に収まることも意味します。 いずれにせよ、Python の整数には任意の精度があります。 

主なエッジ ケースは、入力順序が完全に任意である場合でも、4 つの点が凸状の四角形を形成できることです。 例えば、```
0 0
3 3
0 3
3 0
```答えがあります`4`。 入力ポイントがすでに境界の周囲に与えられていると仮定したソリューションでは、間違ったポリゴンが構築される可能性があります。 

もう 1 つの重要なケースは、他の 3 つによって形成される三角形の厳密に内側の 1 点です。 例えば、```
-1 -1
2 -1
2 2
1 0
```答えがあります`3`、 なぜなら`(1, 0)`最初の 3 点によって形成される三角形の内側にあります。 単純に個別のポイントを数えたり、すべての入力ポイントをハルの頂点として扱う不注意な解決策では、誤って出力されます。`4`。 

保証では 3 つの同一線上の点は除外されるため、船体のエッジの中央にある点が境界に属するかどうかを判断する必要はありません。 たとえば、次のような入力```
0 0
1 0
2 0
0 1
```起こり得ない。 したがって、正しいソリューションでは、ゼロクロス積を処理せずに厳密な配向テストを使用できます。 

ステートメントでは 2 つの点が一致しないことが保証されているため、4 つの座標がすべて等しい入力も不可能です。 したがって、そのようなケースはアルゴリズムの有効なテストとして追加されるべきではありません。 

## アプローチ

 点が 4 つしかないため、直接的な幾何学的なアプローチですでに十分です。 各点を順番に選択し、それが他の 3 つの点によって形成される三角形の内側にあるかどうかを尋ねることができます。 候補点には 4 つの選択肢があり、1 つの点を他の 3 点と比較してテストするには 3 つの方向計算が必要です。 したがって、総当たりチェック全体では、最大 12 個の製品間評価が実行されます。 その時間計算量は O(1) であり、この問題にとって遅すぎるものではありません。 

重要な観察は、3 つの同一直線上にない 4 点の幾何学形状が非常に制限されていることです。 1 つの点が他の 3 つの三角形の内側にある場合、その点は凸包の頂点になることはできません。 逆に、他の 3 つによって形成される三角形の内側に点がない場合は、4 つの点すべてが極点でなければならないため、凸状の四角形を形成します。 

これにより、船体を完全に構築する必要がなくなります。 候補点 P と他の 3 点によって形成される三角形 ABC の場合、3 つの有向辺すべてに対する P の方向が同じ符号を持つ場合、P は厳密に三角形の内側にあります。 AB と AP、BC と BP、CA と CP の外積を計算できます。 3 つの値がすべて正であるか、3 つすべてが負の場合、P は内側になります。 

ここでは、総当たりアプローチと最適アプローチは両方とも一定時間です。 違いは、直接ハル アプローチでは必要以上に一般的な問題が解決されるのに対し、三角形包含観測では点がちょうど 4 つあるという特別な事実が使用されることです。

 ## アルゴリズムのチュートリアル

 1. 4 つの点を読み取り、座標ペアとして保存します。 
2. 各点 P について、他の 3 点を三角形の頂点 A、B、C とみなします。 内部点はまさに凸包上に現れないタイプの点であるため、P が厳密にこの三角形の内側にあるかどうかをテストします。 
3. 三角形の各辺に対する P の方向を計算します。 2 つのベクトルの場合`(x1, y1)`そして`(x2, y2)`、それらの外積は`x1 * y2 - y1 * x2`。 その符号は、一方のベクトルが他方のベクトルの左側にあるか右側にあるかを示します。 
4. 3 つの方向の値がすべて正、またはすべて負の場合、P は厳密に ABC の内側にあります。 同一線上にあるトリプルが存在しないため、これらの値がいずれもゼロではないことが保証されます。 
5. 他の 3 つの三角形によって形成される三角形の内側に点が見つかった場合は、出力します。`3`。 まさにその点が凸包から除外されます。 
6. このような三角形の内側に点がない場合は、次のように出力します。`4`。 すべての点は極点となるため、凸包には 4 つの頂点があります。 

### なぜ効果があるのか

 3 つの同一直線上にない 4 つの点を検討します。 1 つの点 P が他の 3 つの三角形の内側にある場合、4 つの点すべてを含む最小の凸多角形がまさにその三角形となるため、3 つの入力点はハルの境界上にあります。 

他の 3 つによって形成される三角形の内側に点がない場合は、矛盾のために、船体の頂点の数が 4 つ未満であると仮定します。 4 つの異なる点があるため、そのうちの 1 つは、他の 3 つによって形成される三角形の内側になければなりません。 それはテストと矛盾します。 したがって、4 つの点はすべて船体の頂点であり、答えは 4 になります。 

厳密に三角形の内部の点は、三角形の 3 つの有向エッジのそれぞれの同じ側にあるため、方向テストでは三角形の内部の点が正確に識別されます。 同一直線上にあるトリプルは禁止されているため、厳密な内部ケースと境界ケースは曖昧さなく分離されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    """Cross product of AB and AC."""
    return (b[0] - a[0]) * (c[1] - a[1]) - \
           (b[1] - a[1]) * (c[0] - a[0])

def inside_triangle(p, a, b, c):
    x1 = cross(a, b, p)
    x2 = cross(b, c, p)
    x3 = cross(c, a, p)

    return (x1 > 0 and x2 > 0 and x3 > 0) or \
           (x1 < 0 and x2 < 0 and x3 < 0)

def solve():
    points = [tuple(map(int, input().split())) for _ in range(4)]

    for i in range(4):
        p = points[i]
        others = [points[j] for j in range(4) if j != i]

        if inside_triangle(p, others[0], others[1], others[2]):
            print(3)
            return

    print(4)

if __name__ == "__main__":
    solve()
```の`cross`関数は、次のように形成される三角形の符号付き面積式を計算します。`a`、`b`、 そして`c`。 その符号のみが重要です。 正の値は C が有向線 AB の一方の側にあることを意味し、負の値は C が反対側にあることを意味します。`inside_triangle`3 つの有向辺すべてに対して候補点を評価します。 方向は次のように周期的に選択されます。`AB`、`BC`、 そして`CA`, したがって、三角形の内側の点は、一致する 3 つの符号を示します。 三角形の 2 つの可能な方向は、3 つの正の値または 3 つの負の値をチェックすることによって処理されます。 

メイン ループは、4 つの点すべてを可能な内部点として試みます。 リスト内包表記では他の 3 つの点が正確に選択されるため、入力の順序に依存することがなくなります。 

浮動小数点演算はありません。 整数の外積を使用することは、角度や線の交点を計算するよりも簡単で信頼性が高くなります。 -100 から 100 までの座標では、中間値は非常に小さく、Python の整数演算によりオーバーフローの懸念が解消されます。

 ## 特殊なケース

 アルゴリズムでは連続した入力ポイントがハル エッジを形成すると想定していないため、任意の入力順序のケースが処理されます。 のために```

1 1
0 1
1 0

内点の場合は、三角形テストによって直接処理されます。 のために```
0 0
10 0
0 10
1 1
```要点`(1,1)`頂点を持つ三角形の内側にあります`(0,0)`、`(10,0)`、 そして`(0,10)`。 3 つの外積はすべて同じ符号を持つため、`inside_triangle`true を返します。答えは次のとおりです。`3`。 という事実`(1,1)`すべての計算では正確な整数が使用されるため、対角エッジに近い場合でも精度の問題は発生しません。
