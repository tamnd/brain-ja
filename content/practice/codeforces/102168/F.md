 ## 問題の理解

 Перед нами интерактивная задача с чалечными весами. 3 日から 1000 分以内に到着します。 Настоящие монеты имеют одинаковый вес, а фальзивая отличается от них, причем заранее неизвестно, тяжелее она というか。 За одно взвество монет, после чего жюри сообщает, какая чаза тяжелее、или что чали равны。 9 番目のメッセージが表示されます。

Во-вторых、после неравенства направление фальсивой монеты уже связано с результатом.  ## アルゴリズムのチュートリアル

 1. Разделим все`n`монет на две одинаковые группы размера`k = floor(n / 3)`。 Положим первую группу на левую чазу, вторую на правую. Все остальные монеты пока не используем. Обе чази содержат одинаковое количество монет, поэтому запрос корректен.
 2. Если первое взвеbolьзование оказалось равным, фальсивая монета находится среди не использованных`m = n - 2k`分。 ああ`2k`монет с чал становятся заведомо настоящими и будут использоваться как безопасные гири для выравнивания следующих взвезиваний。 
3. Если первое взвезивание оказалось неравным, фальзивая монета находится среди`2k`そうです。 Например, если левая чаза тяжелее, возможны только состояния «монета с левой чали тяжелая» и «монета с правой чази легкая»。 Все остальные монеты являются настоящими. Таким образом, появляется не более`2k <= 666`жезвестным направлением отличия。 
4. В случае равенства разобьем оставлиеся монеты на три группы как можно ближе к одинаковым. Положим первую группу слева、вторую справа、третью оставим вне весов. Если результат равен`=`、кандидаты находятся в третьей группе、причем для каждой из них все еще возможны оба направления。 Если результат`<`とか`>`、кандидаты находятся на соответствующей чаля и направление для каждой гипотезы определяется положением Понеты и результатом.
 5. Когда каждая гипотеза имеет вид`(coin, type)`、、`type`パービューン`heavy`とか`light`、разделим гипотезы на три группы примерно одинакового размера. Для первой группы подберем положение монеты так, чтобы она давала`<`、для второй так、чтобы она давала`>`、а монеты третьей группы вообще не будем класть на весы。 
6. Количество монет на левой и правой чалах может различаться из-за такого разбиения. Возьмем заведомо настоящие монеты и добавим их на меньлою чазу до равенства. Настоящие монеты не меняют результат, зато удовлетворяют формальному требованию задачи.
 7. После ответа жюри оставим только те гипотезы, которые действительно могли привести к этому результату. Повторяем процесс, пока не останется одна гипотеза. Ее номер монеты и есть ответ.

 Почему это работает: инвариантом является множество всех состояний`(монета, направление)`、которые еще совместимы со всеми полученными ответами。 Каждое новое строится так, чтобы каждая гипотеза заранее имела один конкретный ожидаемый результат。 После ответа жюри мы удаляем все гипотезы с другим результатом, поэтому настоящая гипотеза никогда не そうだ。 В конечном счете остается ровно одна гипотеза, а значит, ее монета гарантированно является фальзивой.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def ask(left, right):
    k = len(left)
    print("?", k)
    print(*left)
    print(*right)
    sys.stdout.flush()

    return input().strip()

def finish(coin):
    print("!", coin)
    sys.stdout.flush()

def solve():
    n = int(input())

    coins = list(range(1, n + 1))

    k = n // 3

    left = coins[:k]
    right = coins[k:2 * k]
    rest = coins[2 * k:]

    result = ask(left, right)

    # Candidates are represented as (coin, sign).
    # sign = +1 means fake is heavier.
    # sign = -1 means fake is lighter.

    if result == "=":
        # Coins on the scales are genuine.
        good = left + right
        candidates = rest

        # We still do not know whether each candidate is heavy or light.
        while len(candidates) > 1:
            m = len(candidates)

            # Split into three groups as evenly as possible.
            a = (m + 2) // 3

            g_left = candidates[:a]
            g_right = candidates[a:2 * a]
            g_rest = candidates[2 * a:]

            # For this stage the fake may be either heavy or light.
            result = ask(g_left, g_right)

            if result == "=":
                candidates = g_rest
                states = [(c, s) for c in candidates for s in (1, -1)]
            elif result == ">":
                states = (
                    [(c, 1) for c in g_left] +
                    [(c, -1) for c in g_right]
                )
                candidates = None
            else:
                states = (
                    [(c, -1) for c in g_left] +
                    [(c, 1) for c in g_right]
                )
                candidates = None

            # After the first non-balanced result, every remaining
            # hypothesis has a known direction.
            if candidates is None:
                break

        else:
            states = [(c, s) for c in candidates for s in (1, -1)]

        # If the last unknown-direction weighing was balanced,
        # states has already been constructed.
        if len(states) == 1:
            finish(states[0][0])
            return

    else:
        # The first weighing was unbalanced.
        # All coins not placed on the scale are genuine.
        good = rest

        if result == ">":
            states = (
                [(c, 1) for c in left] +
                [(c, -1) for c in right]
            )
        else:
            states = (
                [(c, -1) for c in left] +
                [(c, 1) for c in right]
            )

    while len(states) > 1:
        m = len(states)
        q = (m + 2) // 3

        less = states[:q]
        greater = states[q:2 * q]
        equal = states[2 * q:]

        left = []
        right = []

        # Arrange candidate hypotheses so that they produce
        # their designated result.
        for coin, sign in less:
            if sign == 1:
                right.append(coin)
            else:
                left.append(coin)

        for coin, sign in greater:
            if sign == 1:
                left.append(coin)
            else:
                right.append(coin)

        # Add genuine coins to make the two pans equal.
        target = max(len(left), len(right))

        need_left = target - len(left)
        need_right = target - len(right)

        pos = 0

        if need_left:
            left.extend(good[pos:pos + need_left])
            pos += need_left

        if need_right:
            right.extend(good[pos:pos + need_right])
            pos += need_right

        result = ask(left, right)

        if result == "<":
            states = less
        elif result == ">":
            states = greater
        else:
            states = equal

    finish(states[0][0])

if __name__ == "__main__":
    solve()

 После первого равенства мы действительно еще не знаем направление фальствой монеты. Поэтому первый следующий запрос обрабатывается отдельно. Если он дает равенство, остается третья группа, причем для каждой ее монеты сохраняются оба состояния.

 В основном цикле`q = (m + 2) // 3`является округлением`m / 3`いや。 Первые`q`гипотез назначаются результату`<`、、、`q`さいきょう`>`、 остальные получают результат`=`。 Ни одна группа не превылает`ceil(m / 3)`。

import io
import sys

def run_simulated(n, fake_coin, fake_sign):
    """
    fake_sign = +1 for heavy, -1 for light.

    Returns the coin printed by the interactive algorithm.
    """

    input_stream = io.StringIO(str(n) + "\n")
    output_stream = io.StringIO()

    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = input_stream
    sys.stdout = output_stream

    try:
        # The actual interactive program is replaced by the same
        # decision logic, but ask() is connected to the simulator.
        coins = list(range(1, n + 1))
        good = []
        states = None

        def ask(left, right):
            assert len(left) == len(right)
            assert len(set(left)) == len(left)
            assert len(set(right)) == len(right)
            assert set(left).isdisjoint(right)

            def contribution(coin, side):
                if coin != fake_coin:
                    return 0
                return fake_sign * side

            left_effect = sum(contribution(c, 1) for c in left)
            right_effect = sum(contribution(c, 1) for c in right)

            if left_effect > right_effect:
                return ">"
            if left_effect < right_effect:
                return "<"
            return "="

        k = n // 3
        left = coins[:k]
        right = coins[k:2 * k]
        rest = coins[2 * k:]

        result = ask(left, right)

        if result == "=":
            good = left + right
            candidates = rest

            while len(candidates) > 1:
                m = len(candidates)
                a = (m + 2) // 3

                g_left = candidates[:a]
                g_right = candidates[a:2 * a]
                g_rest = candidates[2 * a:]

                result = ask(g_left, g_right)

                if result == "=":
                    candidates = g_rest
                elif result == ">":
                    states = (
                        [(c, 1) for c in g_left] +
                        [(c, -1) for c in g_right]
                    )
                    break
                else:
                    states = (
                        [(c, -1) for c in g_left] +
                        [(c, 1) for c in g_right]
                    )
                    break
            else:
                states = [(c, s) for c in candidates for s in (1, -1)]

            if states is None:
                states = [(c, s) for c in candidates for s in (1, -1)]

        else:
            good = rest

            if result == ">":
                states = (
                    [(c, 1) for c in left] +
                    [(c, -1) for c in right]
                )
            else:
                states = (
                    [(c, -1) for c in left] +
                    [(c, 1) for c in right]
                )

        while len(states) > 1:
            m = len(states)
            q = (m + 2) // 3

            less = states[:q]
            greater = states[q:2 * q]
            equal = states[2 * q:]

            left = []
            right = []

            for coin, sign in less:
                if sign == 1:
                    right.append(coin)
                else:
                    left.append(coin)

            for coin, sign in greater:
                if sign == 1:
                    left.append(coin)
                else:
                    right.append(coin)

            target = max(len(left), len(right))

            need_left = target - len(left)
            need_right = target - len(right)

            pos = 0

            left.extend(good[pos:pos + need_left])
            pos += need_left

            right.extend(good[pos:pos + need_right])

            result = ask(left, right)

            if result == "<":
                states = less
            elif result == ">":
                states = greater
            else:
                states = equal

        return states[0][0]

    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout
