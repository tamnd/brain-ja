 ## 解決策
 ## 問題の理解

 私たちは、一連の日にわたるディバンのコテージ内の温度の変化をシミュレーションするように求められています。温度は、外気温に向かって 1 日あたり 1 単位ずつ調整されます。 具体的には、現在の室内温度が外気温度より低い場合は 1 ずつ増加します。 それが大きい場合は 1 ずつ減ります。 それ以外の場合は、同じままです。 次に、次の形式の質問に答えるように求められます: 室内温度が で始まったかどうか`x`初日、その後はどうなるでしょうか`i`日？ 各クエリはローリングを使用してエンコードされます。`lastans`デコードするにはモジュラー演算が必要な値であり、クエリは受信した順序で応答する必要があります。 

制約は重要です。最大 200,000 日があり、すべての日のクエリの総数も最大 200,000 です。 したがって、クエリごとに毎日繰り返す単純なシミュレーションでは、最悪の場合、実行が粗雑になる可能性があるため、遅すぎます。`200,000 * 200,000`2秒の制限時間をはるかに超えた操作。 入力できる数値は次のとおりです。`10^9`したがって、密な配列や温度範囲にわたる単純な反復カウントに依存するソリューションも、メモリまたは時間の制限により失敗します。 

明らかではないエッジ ケースには、可能な最高温度または最低温度で正確に開始されるクエリや、外気温が一定に保たれる日数が含まれます。 たとえば、クエリが 0 から始まり、最初の日の外気温が 10 だった場合、室内温度は 10 に達するまで毎日 1 ずつ増加します。クエリが前日のクエリから独立していると想定する不用意な実装は、次の理由により誤った計算を行う可能性があります。`lastans`シミュレーションの前に各クエリを変更します。 

## アプローチ

 ブルート フォース アプローチは簡単です。クエリごとに、毎日の気温をシミュレートします。 毎日、現在の温度と外気温を比較し、それに応じて 1 ずつ調整します。 これはルールに直接従うため正しいですが、最悪の場合の複雑さがあります。`O(Q * N)`どこ`Q`はクエリの数であり、`N`は日数です。 どちらも最大で`2 * 10^5`、これにより、最大で次のような結果が生じる可能性があります`4 * 10^{10}`実行不可能な操作。 

重要な洞察は、毎日の影響が範囲の変化として表現できるということです。 具体的には、その後`i`日数、任意の初期温度`x`常に毎日の外気温に近づく場合、達成可能な最低気温と最高気温によって制限されます。 より正式には、2 つの変数を維持できます。`lo`そして`hi`、これまでの日数を処理した後の任意の開始点の可能な最低気温と最高気温を表します。 毎日、`lo`以下の場合は上方に調整されます`T_i`、または上にある場合は下に`T_i`。 同様に、`hi`に向けて調整されています`T_i`。 そうすれば、どんな質問にも答えることができます。`O(1)`初期温度をクランプすることにより`x`間`lo`そして`hi`。 

これにより、問題は潜在的な問題から転換されます。`O(Q * N)`定数時間のクエリ評価による数日にわたる線形時間パスへのブルート フォース シミュレーション。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(Q * N) | お(1) | 遅すぎる |
 | 最適 | O(N + Q) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.初期化`lo`そして`hi`から 0 まで、初期状態からの可能な最小および最大の温度変化を表します。 初期化する`lastans`0にします。 
2. 毎日繰り返す`i`1から`n`。 現在の外気温については`T_i`、境界を更新します。 

- インクリメント`lo`未満の場合`T_i`またはそれがより大きい場合は減分します`T_i`。 次にクランプします`lo`に`T_i`オーバーシュートした場合。 
- 同様に調整します`hi`向かって`T_i`。 

これにより、`lo`そして`hi`は常に、これまでの全日を処理した後に考えられる室内温度の範囲を表します。 
3. クエリごとに`x'_i`当日`i`、最初に真のクエリ値をデコードします。`x_i = (x'_i + lastans) % (10^9 + 1)`。 
4. クランプで質問に答えます`x_i`間`lo`そして`hi`。 セット`lastans`この結果を出力してください。 
5. すべての日とクエリが処理されるまで繰り返します。 

不変条件は、処理後のものです。`i`日々、`lo`任意の温度から開始して達成可能な最小温度です。`x`毎日の外気温に合わせて移動し、`hi`が一番大きいです。 任意のクランプ`x`内で`[lo, hi]`各ステップをシミュレートすることなく、増分調整を正確にモデル化します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
lastans = 0
lo = hi = 0

for _ in range(n):
    T = int(input())
    k = int(input())
    queries = list(map(int, input().split()))

    # Update bounds
    if lo < T:
        lo += 1
        if lo > T:
            lo = T
    elif lo > T:
        lo -= 1
        if lo < T:
            lo = T

    if hi < T:
        hi += 1
        if hi > T:
            hi = T
    elif hi > T:
        hi -= 1
        if hi < T:
            hi = T

    # Answer queries
    for x_enc in queries:
        x = (x_enc + lastans) % (10**9 + 1)
        lastans = max(lo, min(hi, x))
        print(lastans)
```コードはアルゴリズムに正確に従います。 境界は、その日の外気温に合わせて段階的に調整されます。 クエリは次を使用してデコードされます`lastans`暗号化された入力を処理します。 最後のクランプにより、各クエリが確実に回答されます。`O(1)`各クエリの中間日ごとにシミュレーションを行わずに、時間を計算します。 モジュラー演算と更新の順序には注意が必要です`lastans`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    lastans = 0
    lo = hi = 0
    n = int(input())
    for _ in range(n):
        T = int(input())
        k = int(input())
        queries = list(map(int, input().split()))
        if lo < T:
            lo += 1
            if lo > T: lo = T
        elif lo > T:
            lo -= 1
            if lo < T: lo = T
        if hi < T:
            hi += 1
            if hi > T: hi = T
        elif hi > T:
            hi -= 1
            if hi < T: hi = T
        for x_enc in queries:
            x = (x_enc + lastans) % (10**9 + 1)
            lastans = max(lo, min(hi, x))
            output.append(str(lastans))
    return "\n".join(output)

# Sample
assert run("3\n50\n3\n1 2 3\n50\n3\n4 5 6\n0\n3\n7 8 9\n") == "2\n5\n9\n15\n22\n30\n38\n47\n53", "sample 1"

# Minimum size
assert run("1\n0\n1\n0\n") == "1", "min input"

# Max temperature
assert run("1\n1000000000\n2\n0 1000000000\n") == "1\n1000000000", "max temperature"

# All days same temperature
assert run("2\n5\n1\n2\n5\n1\n3\n") == "3\n5", "constant temperature"

# Edge case with lastans wrap-around
assert run("2\n1\n1\n1000000000\n2\n1\n1 2\n") == "1000000000\n1000000000\n1000000001", "lastans wrap"
