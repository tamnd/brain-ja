 ## 解決策
 ## 問題の理解

 原点のチップから始めます`(0, 0)`そして目標点に到達したい`(x, y)`。 

現在の位置と次の位置の間のユークリッド距離が整数の場合、移動は許可されます。 タスクは、ターゲットに到達するために必要な最小移動数を見つけることです。 

座標は非常に小さく、せいぜい`50`、多くても`3000`テストケース。 多少非効率なソリューションであっても、制限内に問題なく収まります。 それでも、この問題には、すべてをテスト ケースごとの一定時間に短縮するという単純な数学的観察が含まれています。 

重要な量は、出発地から目的地までの距離です。$$d = \sqrt{x^2 + y^2}$$この距離がすでに整数の場合は、から直接移動できます。`(0,0)`に`(x,y)`1回の操作で。 

目的地自体が出発地である場合には、特殊なケースが発生します。 もし`(x,y) = (0,0)`、移動する必要はないので、答えは次のようになります。`0`。 

主な微妙な点は、距離が整数でない場合に何が起こるかを理解することです。 不注意な解決策では、場合によっては 2 つ以上の手が必要になる可能性があると考えられる可能性があります。 たとえば:

 入力:```
1
9 15
```距離は$$\sqrt{9^2+15^2}=\sqrt{306}$$これは整数ではありません。 直接移動は不可能ですが、それでも正解は`2`、もっと大きな数ではありません。 

もう 1 つの簡単な間違いは、元のケースを忘れることです。 

入力:```
1
0 0
```出力：```
0
```距離は整数です (`0`)、ただし最小移動数はそうではありません。`1`、もう目的地に着いているからです。 

## アプローチ

 この問題を考える強引な方法は、中間点を探すことです。 目的地に直接到達できない場合は、すべての格子点を試すことができます`(a,b)`両方の距離が一致しているかどうかを確認します$$\sqrt{a^2+b^2}$$そして$$\sqrt{(x-a)^2+(y-b)^2}$$は整数です。 

座標はせいぜい`50`、このような検索は実際にはここでは十分に高速です。 テスト ケースごとに数千の候補点を調べ、有効な中間点が見つかった時点で停止します。 

座標が小さいため、強引なアイデアは機能しますが、基礎となる構造が完全に欠落しています。 

重要な観察は、原点以外の点は常に最大 2 回の移動で到達できるということです。 

ターゲットが`(x,y)`原点からの距離は整数ではありません。 一度の行動でそこに到達することはできません。 

ただし、まず次のことから始めることができます。`(0,0)`に`(0,0)`原点から整数の距離にある点を加えたもの。たとえば、`(x,0)`もし`x > 0`、または他の適切な格子点。 より一般的には、より強力な幾何学的事実が当てはまります。つまり、平面内のすべての点は、長さが整数である 2 つのベクトルの合計として表すことができます。 ラティス ポイントの場合は、常に 2 回の移動で十分です。 

原点からの距離が整数の場合は 1 つの移動が可能であり、それ以外の場合は常に 2 つの移動で十分であるため、答えは 3 つだけになります。`0`、`1`、 または`2`。 

これにより、問題は次のような単純な分類に変わります。`x² + y²`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | テスト ケースごとの O(C²) | お(1) | 受け入れられるが不要 |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ここ`C`は座標境界を表します。 

## アルゴリズムのチュートリアル

 1. 目標座標を読み取る`(x, y)`。 
2. もし`x == 0`そして`y == 0`、出力`0`。 

すでに目的地に着いているので、移動する必要はありません。 
3. コンピューティング$$s = x^2 + y^2$$原点からの距離は`√s`。 
4. かどうかを確認します。`s`は完全な正方形です。 

そうであれば、`√s`は整数なので、からの直接移動`(0,0)`に`(x,y)`合法です。 
5. もし`s`は完全二乗、出力`1`。 
6. それ以外の場合は出力`2`。 

距離は整数ではないため 1 回の移動は不可能であり、2 回の移動で常に十分です。 

### なぜ効果があるのか

 答えは決して超えられない`2`。 

目的地が出発地である場合、最小値は明らかに`0`。 

その他の点については、`x² + y²`が完全な正方形である場合、からの距離は`(0,0)`に`(x,y)`は整数です。 直接的な移動が存在するため、答えは次のようになります。`1`。 

もし`x² + y²`は完全な正方形ではないため、直接移動することはできません。 公式解法で使用される既知の幾何学的特性は、すべての格子点が 2 回の整数長の移動で到達できるということです。 1 つの手は機能せず、2 つの手は常に機能するため、最小値は正確に次のようになります。`2`。 

これら 3 つのケースは相互に排他的であり、すべての入力をカバーするため、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
from math import isqrt

input = sys.stdin.readline

t = int(input())

for _ in range(t):
    x, y = map(int, input().split())

    if x == 0 and y == 0:
        print(0)
        continue

    s = x * x + y * y
    r = isqrt(s)

    if r * r == s:
        print(1)
    else:
        print(2)
```最初のブランチは原点を処理します。 それがなければ、`(0,0)`1 回の移動が必要であると誤って分類されてしまいます。`0`は完全な正方形です。 

変数`s`二乗距離を格納します。 二乗距離を使用すると、浮動小数点演算が完全に回避されます。`isqrt(s)`の整数の下限を返します`√s`。 数値が完全二乗になるのは、次のとおりです。`isqrt(s)^2 == s`。 

距離が整数かどうかが分かれば、答えは前述の 3 つの場合の分類から直接得られます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io
from math import isqrt

def solve():
    input = sys.stdin.readline
    t = int(input())

    ans = []
    for _ in range(t):
        x, y = map(int, input().split())

        if x == 0 and y == 0:
            ans.append("0")
            continue

        s = x * x + y * y
        r = isqrt(s)

        ans.append("1" if r * r == s else "2")

    sys.stdout.write("\n".join(ans))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return out

# provided sample
assert run(
"""3
8 6
0 0
9 15
"""
) == "1\n0\n2"

# origin
assert run(
"""1
0 0
"""
) == "0"

# classic Pythagorean triple
assert run(
"""1
3 4
"""
) == "1"

# non-perfect-square distance
assert run(
"""1
1 1
"""
) == "2"

# maximum coordinates
assert run(
"""1
50 50
"""
) == "2"
```| テスト入力 | 期待される出力 | 検証内容 |

 |`0 0`|`0`| 目的地にすでに到着しました |
 |`3 4`|`1`| ピタゴラス 3 倍による整数距離 |
 |`1 1`|`2`| 非正方形の距離には 2 つの移動が必要です。 
|`50 50`|`2`| 制約内の最大の座標 |

入力：```
1

```二乗距離は$$24^2+7^2=576+49=625$$以来`625 = 25²`、アルゴリズムの出力`1`。 長さの直接移動`25`合法です。 

距離が整数ではない点を考えてみましょう。 

入力：```
1
1 1
```二乗距離は`2`、完全な正方形ではありません。 完全二乗テストは失敗し、アルゴリズムは次のように出力します。`2`。 

これはまさに正しいです。1 つの手は不可能ですが、2 つの手は常に十分であるためです。 

境界値入力を考えてみましょう。 

入力：```
1
50 50
```二乗距離は$$50^2+50^2=5000$$

`5000`は完全な正方形ではないため、アルゴリズムの出力は次のようになります。`2`。 座標のサイズによって推論が変わることはありません。これは、解決策が許容範囲全体を均一に処理することを示しています。
