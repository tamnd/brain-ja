 ## 解決策
 ## 問題の理解

 タスクは、括弧文字列から「適切な」プレフィックスを繰り返し削除することです。 プレフィックスは、通常の括弧シーケンスまたは少なくとも 2 つの長さの回文のいずれかである場合に適しています。 適切なプレフィックスが存在しなくなるまでこのプロセスを継続し、実行した削除の数と残っている文字の数を報告します。 各テスト ケースでは文字列が与えられるため、複数の文字列を効率的に処理する必要があります。 

この制約は、すべての文字列の合計の長さが 500,000 を超えないことを示しており、考えられるすべてのプレフィックスを繰り返し検査するアルゴリズムは除外されます。これは、O(n²) 個の作業が発生する可能性があるためです。 したがって、単一の線形パスまたはそれに近いパスで文字列を処理する必要があります。 

考慮すべきエッジ ケースには、完全に同じ括弧で構成されるシーケンス、閉じ括弧で始まるシーケンス、すでに規則的であるシーケンス、および小さな回文プレフィックスを含むシーケンスが含まれます。 たとえば、入力`((((`1 を超える通常の接頭辞はありませんが、繰り返される文字は少なくとも 2 の長さの回文を形成します。 通常の括弧シーケンスのみをチェックする不注意な解決策は、この点では失敗します。 

## アプローチ

 ブルートフォース手法では、文字列の考えられるすべてのプレフィックスをチェックして、それが通常の括弧シーケンスであるか回文であるかを確認しようとします。 通常の括弧シーケンスを検証するには、バランス カウンターを維持することで実行できます。つまり、「(」で増分し、「)」で減分し、バランスが決してマイナスにならず、ゼロで終了することを確認します。 回文をチェックするには、プレフィックスの末尾から対称に文字を比較する必要があります。 すべてのプレフィックスに対してこれらのチェックを実行すると、文字列あたりの複雑さが O(n²) になりますが、制約を考慮すると遅すぎます。 

最適なアプローチにつながる重要な観察は、任意のプレフィックスをチェックする必要がないということです。 **最も短い適切なプレフィックス**のみが必要です。 このプレフィックスは、文字列を反復処理するときに貪欲に見つけることができます。 長さが 2 以上の回文の場合、連続する 2 つの同一文字が有効なプレフィックスを形成します。 通常のブラケット シーケンスの場合、継続的なバランスを維持します。バランスがゼロに達すると、現在のプレフィックスは通常になります。 したがって、文字列を 1 回のパスで処理し、プレフィックスを識別して削除し、操作の数をカウントすることができます。

 ## アルゴリズムのチュートリアル

 1. 2 つのカウンターを初期化します。`operations`削除されたプレフィックスの数と`i`文字列内の現在のインデックス。 
2. その間`i`が文字列の長さより短い場合は、次から始まる最短の適切なプレフィックスを見つけようとします。`i`。 
3. 通常のブラケット シーケンスであるプレフィックスを見つけるには、ゼロから始まるバランス カウンタを維持します。 から前方に反復処理`i`、「(」の場合は 1 を加算し、「)」の場合は 1 を減算します。 ある位置で残高がゼロになった場合`j`、接頭辞`s[i:j+1]`は有効な正規シーケンスです。 インクリメント`operations`、設定します`i = j + 1`。 
4. 規則的なシーケンスがすぐに見つからない場合は、長さ 2 の回文プレフィックスを確認します。`s[i] == s[i+1]`、これら 2 つの文字を接頭辞として削除します。 インクリメント`operations`、設定します`i = i + 2`。 
5. どちらの条件も満たされない場合は、適切なプレフィックスが残っていないため、ループを終了します。 
6. 反復が終了すると、残りの文字が表示されます。`n - i`。 報告`operations`そして残りの長さ。 

### なぜ効果があるのか

 このアルゴリズムは、各ステップで可能な限り短いプレフィックスを削除するという不変条件を維持します。 定義上、適切な長いプレフィックスは、同じ位置から始まる複数の短い適切なプレフィックスに分解できます。 バランスカウンターを使用して通常のブラケットシーケンスをチェックすることで、その条件が正しいことを確認します。 最も短い回文は少なくとも 2 文字である必要があるため、回文の検出は長さ 2 に制限されます。 これにより、有効な操作を見逃すことなく、できるだけ多くのプレフィックスを削除することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        operations = 0
        i = 0
        while i < n:
            if i + 1 < n and s[i] == s[i + 1]:
                # Palindrome of length 2
                operations += 1
                i += 2
            else:
                balance = 0
                j = i
                while j < n:
                    if s[j] == '(':
                        balance += 1
                    else:
                        balance -= 1
                    if balance == 0:
                        break
                    j += 1
                if balance == 0:
                    operations += 1
                    i = j + 1
                else:
                    # No good prefix can be found
                    break
        print(operations, n - i)

if __name__ == "__main__":
    solve()
```このソリューションは複数のテスト ケースを読み取ります。 各文字を反復処理して、長さ 2 の回文をチェックするか、規則的なシーケンスのバランスを維持します。 インデックス`i`どれだけの文字列が削除されたかを追跡し、`operations`成功した削除の数をカウントします。 残りの文字は単純に`n - i`。 これにより、文字列ごとに O(n) 時間と O(1) 個の追加スペースが確保されます。
