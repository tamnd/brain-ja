 ## 解決策
 ## 問題の理解

 同じ長さの 2 つのバイナリ文字列があります。 一部の位置は移動可能としてマークされており、一部はロックされています。 

移動は 2 つの隣接するキャラクターを交換することで構成されますが、交換に参加できるキャラクターのみを移動できます。 スワップは隣接しており、任意に何度でも繰り返すことができるため、ポジションの最大連続セグメントごとにマークが付けられます。`1`マスク内の は、自由に置換可能なブロックのように動作します。 キャラクターはロックされた位置を越えることはできません。 

いずれかの文字列に対してこのような交換を任意の回数実行した後、最後の 2 つの文字列に同じ文字が含まれる位置の数を最大化したいと考えます。 

各文字列の長さは次のとおりです。$10^5$、複数のテストケースがあります。 スワップを繰り返しシミュレートしたり、さまざまな再配置を試行したりするソリューションは、直ちに除外されます。 テスト ケースごとに線形に近い時間が必要です。 アン$O(n^2)$アプローチには前後が必要です$10^{10}$限界をはるかに超えた最悪の場合の動作。 

主な微妙な点は、可動キャラクターが世界中で無料ではないということです。 キャラクターは、可動位置の最大セグメント内でのみ移動できます。 ロック位置によって分離された 2 つのセグメントは完全に独立しています。 

簡単な例を考えてみましょう。```
s1 = 01
s2 = 10
t1 = 11
t2 = 00
```2番目の文字列は固定されています。 最初の文字列は、その 2 つの文字を再配置できます。 移動させることで、`1`最初の位置に到達すると、2 つの一致が得られます。 可動位置を独立して扱うと、この可能性が失われます。 

もう 1 つの簡単な間違いは、キャラクターがロックされた位置を横切ることを許可することです。```
s1 = 101
t1 = 101
```中間位置はロックされています。 2 つの可動位置は異なるセグメントに属しているため、2 つの可動位置は`1`センター経由での交換はできません。 

## アプローチ

 強引なアイデアは、両方の文字列の到達可能な配置をすべて明示的に生成し、等しい位置の最大数をチェックすることです。 一定の長さの可動セグメント内$k$、任意の順列に到達できるため、状態の数は階乗的に増加します。 長さ 15 のセグメントでも、すでにそれ以上のものがあります。$10^{12}$順列。 このアプローチは絶望的です。 

重要な観察は、可動セグメント内では、`0`そして`1`案件。 どのような順序でも作成できるため、正確な順序は関係ありません。 

まず、各文字列をコンポーネントに分解します。 

ロックされた位置は、値が永久に固定されるサイズ 1 のコンポーネントを形成します。 

マスク値を持つポジションの連続する最大値`1`可動部品を形成します。 このようなコンポーネント内では、その数だけを知る必要があります。`0`何個`1`が利用可能です。 

ここで、一方の側が固定され、もう一方の側が可動コンポーネントに属する位置を考えてみましょう。 可動コンポーネントに必要な数字がまだ含まれている場合、ここでの一致は常に有益です。 一致は答えに 1 つだけ寄与します。また、どの文字も最大 1 回しか寄与できないため、文字を使用しても将来の寄与の最大値を減らすことはできません。 

したがって、少なくとも 1 つの側面が固定されているすべての位置を貪欲に処理します。 可動コンポーネントが必要な数字を提供できる場合は常に、1 つの出現を消費し、一致をカウントします。 

あとは両側が可動する位置だけが残ります。 このような位置で、2 つの対応するコンポーネントにまだ両方とも`0`、を一致させることができます`0`ここ。 それ以外の場合、両方にまだ`1`、を一致させることができます`1`。 どちらの桁も両側に存在しない場合、この位置は等しくなりません。 

すべてのコンポーネントの残りのカウントは未使用の文字を完全に表すため、可能な限り貪欲に一致を作成することが最適です。

 ## アルゴリズムのチュートリアル

 ### ステップ 1

 両方の文字列のコンポーネント ID を構築します。 

ロックされた位置は独自のコンポーネントを取得します。 

可動位置の最大連続ランは 1 つのコンポーネント ID を共有します。 

すべての可動コンポーネントについて、その数を保存します`0`何個`1`s 現在含まれています。 

### ステップ 2

 すべてのポジションを処理します。 

両方の位置がロックされている場合、それらの値は永久に固定されます。 桁がすでに等しい場合は、答えに 1 を加えます。 

最初の側がロックされ、2 番目の側が移動可能な場合は、2 番目のコンポーネントに必要な数字がまだ含まれているかどうかを確認してください。 存在する場合は、1 つのオカレンスを消費し、回答に 1 つを追加します。 

2 番目の側がロックされ、1 番目の側が移動可能な場合は、対称操作を実行します。 

これを最初に行う理由は、固定位置には取り得る値が 1 つしかないためです。 可動コンポーネントがその値を満たすことができる場合は、すぐに一致するものを選択しても問題はありません。 

### ステップ 3

 すべての位置を再度処理します。 

両側が可動する位置のみを考慮してください。 

対応する可動コンポーネントを次のようにします。$A$そして$B$。 

両方にまだ`0`、1つ消費します`0`それぞれから 1 つを答えに追加します。 

それ以外の場合、両方にまだ`1`、1つ消費します`1`それぞれから 1 つを答えに追加します。 

それ以外の場合は、この位置で一致することはできません。 

### ステップ 4

 蓄積された回答を出力します。 

### なぜ効果があるのか

 すべての可動コンポーネントは、残りのコンポーネントの数によって完全に特徴付けられます。`0`そして`1`。 

位置に固定文字が含まれる場合、一致が成功するには、可動側からその固定数字が 1 回出現する必要があります。 消費されたキャラクターはどこにいても最大 1 つの試合に貢献できるため、その試合を遅らせてもメリットはありません。 

すべての固定位置の要求が可能な限り満たされた後、残りのすべての位置には 2 つの可動側が存在します。 このような位置での一致には、両方のコンポーネントが同じ桁を保持していることだけが必要です。 共通の数字が存在する場合、その一致を取得すると、両側の文字が 1 つずつ消費され、答えが 1 つ増えます。 今後の取り決めでは、これら 2 つの消費されたキャラクターから複数の貢献を抽出することはできません。 

したがって、すべての貪欲な一致は局所的に最適であり、将来の達成可能な一致の最大数が減少することはありません。 このプロセスを繰り返すことで、全体的に最適な答えが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())

    for _ in range(T):
        n = int(input())
        s1 = input().strip()
        s2 = input().strip()
        t1 = input().strip()
        t2 = input().strip()

        comp1 = [-1] * n
        comp2 = [-1] * n

        cnt1 = []
        cnt2 = []

        cid = 0
        i = 0
        while i < n:
            if t1[i] == '0':
                comp1[i] = -1
                i += 1
            else:
                cnt1.append([0, 0])
                j = i
                while j < n and t1[j] == '1':
                    comp1[j] = cid
                    cnt1[cid][int(s1[j])] += 1
                    j += 1
                cid += 1
                i = j

        cid = 0
        i = 0
        while i < n:
            if t2[i] == '0':
                comp2[i] = -1
                i += 1
            else:
                cnt2.append([0, 0])
                j = i
                while j < n and t2[j] == '1':
                    comp2[j] = cid
                    cnt2[cid][int(s2[j])] += 1
                    j += 1
                cid += 1
                i = j

        ans = 0

        for i in range(n):
            a_fixed = (t1[i] == '0')
            b_fixed = (t2[i] == '0')

            if a_fixed and b_fixed:
                if s1[i] == s2[i]:
                    ans += 1

            elif a_fixed and not b_fixed:
                need = int(s1[i])
                c = comp2[i]
                if cnt2[c][need] > 0:
                    cnt2[c][need] -= 1
                    ans += 1

            elif not a_fixed and b_fixed:
                need = int(s2[i])
                c = comp1[i]
                if cnt1[c][need] > 0:
                    cnt1[c][need] -= 1
                    ans += 1

        for i in range(n):
            if t1[i] == '1' and t2[i] == '1':
                c1 = comp1[i]
                c2 = comp2[i]

                if cnt1[c1][0] > 0 and cnt2[c2][0] > 0:
                    cnt1[c1][0] -= 1
                    cnt2[c2][0] -= 1
                    ans += 1
                elif cnt1[c1][1] > 0 and cnt2[c2][1] > 0:
                    cnt1[c1][1] -= 1
                    cnt2[c2][1] -= 1
                    ans += 1

        print(ans)
