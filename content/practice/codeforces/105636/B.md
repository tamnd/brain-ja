 ## 解決策
 ## 問題の理解

 変数の連鎖があります$x_1, x_2, \dots, x_n$、それぞれの値は次のとおりです。$1$に$v$。 

すべての隣接するペアには、次の形式のバイナリ制約があります。$$x_i=a_i \implies x_{i+1}=b_i$$価値観$a_i$そして$b_i$は不明です。 特定の変数を固定するいくつかの単項制約しかわかっていません。$$x_{c_j}=d_j$$タスクは、すべてのペアの選択肢が何個あるかを数えることです。$(a_i,b_i)$システム全体を満足可能にします。これは、すべての単項制約および二項制約を満たすすべての変数の割り当てが少なくとも 1 つ存在することを意味します。 

入力には複数のテスト ケースが含まれています。 各テスト ケースが提供するのは、$n,m,v$、続いて$m$単項制約。 

この問題の特殊な部分は、制約のサイズです。 到達できる変数の数は$10^9$, そのため、位置を 1 つずつ処理するアルゴリズムは不可能です。 一方、単項制約の数は最大でも$10^5$これは、固定された位置のみが重要であり、それらの間のすべては公式で処理される必要があることを強く示唆しています。 

最初のエッジ ケースは、同じ位置に対する矛盾した単項制約です。 

例：```
n = 2, v = 2
x1 = 1
x1 = 2
```変数を代入しても両方の要件を満たすことはできないため、答えは 0 になります。 

2 番目のエッジケースは、固定位置が 1 つしかない場合です。 この場合、固定値間に相互作用はありません。 その変数の規定値を選択するだけで、問題の暗示を引き起こすことを回避できます。 すべてのバイナリ制約の割り当てが有効になります。 

例：```
n = 3, v = 2
x2 = 1
```全て$(v^2)^{n-1}=4^2=16$選択肢は有効です。 

3 番目のエッジ ケースは、2 つの固定位置が隣接している場合です。 

例：```
x1 = 1
x2 = 2
```それらの間には、バイナリ制約が 1 つだけ存在します。 選択肢はひとつだけ$(a_1,b_1)$矛盾が生じます、つまり$(1,1)$。 他のすべての選択肢は依然として満足のいくものです。 

不注意な推論は、制約が次の場合にのみアクティブになることを忘れてしまうことがよくあります。$x_i=a_i$。 

## アプローチ

 ブルートフォースソリューションでは、すべての可能な値をすべて列挙します。$a_i$そして$b_i$。 各ペアにはあるので、$v^2$可能性はあります$n-1$エッジ、これにより得られます$$(v^2)^{n-1}$$構成。 

構成ごとに、変数の割り当てがすべての制約を満たすかどうかをテストできます。 

これは正しいですが、たとえ小さな入力でもすぐに爆発します。 

重要な観察は、バイナリ制約が非常に弱いということです。 制約は、左の変数が 1 つの特定の値に等しい場合にのみアクティブになります。$a_i$。 もし私たちが選択できるなら$x_i\neq a_i$、その制約は無関係になります。 

このため、矛盾は、活性化された含意の連続的な連鎖を通じてのみ伝播することができます。 

2 つの位置を想定します$l$そして$r$単項制約によって固定されます。 私たちはこう尋ねます:

 それらの間の 2 値制約の選択肢がいくつあれば、システムは満足できるでしょうか?

 逆に数えたほうが簡単です。 

位置に固定値がある場合にのみ矛盾が発生します。$l$独自のチェーンを強制的に配置します$r$、そして最終的な強制値は固定値と一致しません。$r$。 

そのためには、パスに沿ったすべての影響が有効になる必要があります。$$a_l=x_l,\quad
a_{l+1}=b_l,\quad
a_{l+2}=b_{l+1},\dots$$そして最後のエッジでは、次の値とは異なる値を強制する必要があります。$x_r$。 

距離が$d=r-l$、 それから：$$b_l,b_{l+1},\dots,b_{r-2}$$任意に選択できます。$v^{d-1}$可能性。 

最後の値$b_{r-1}$とは異なっていなければなりません$x_r$、与える$v-1$可能性。 

したがって、不正な構成の数は次のようになります。$$v^{d-1}(v-1).$$そのセグメント内のすべてのバイナリ制約には、$$(v^2)^d=v^{2d}$$考えられる割り当てなので、適切な割り当ての数は次のようになります。$$f(d)=v^{2d}-v^{d-1}(v-1).$$ここで、さらに強力なものに注目してください。 

単項制約によって固定された位置のみが重要です。 最初の固定位置の前と最後の固定位置の後の領域では、厄介な影響のアクティブ化を回避する変数値を常に選択できます。 そこにあるすべてのバイナリ制約の割り当ては有効です。 

したがって、全体の答えは、連続する固定位置間の独立したセグメントに因数分解されます。

 ## アルゴリズムのチュートリアル

 1. すべての単項制約を読み取ります。 
2. 位置をキーとしたマップにそれらを保存します。 
3. 同じ位置が異なる必須値で出現した場合は、単項制約がすでに矛盾しているため、すぐに 0 を出力します。 
4. 残りの固定位置を並べ替えます。 
5. ソートされた固定位置を次のようにします。$$p_1<p_2<\dots<p_k.$$1. 答えを掛ける$$v^{2(p_1-1)}$$最初の固定位置の前にある制約のないプレフィックスの場合。 

1. 連続するペアごとに$(p_i,p_{i+1})$、 させて$$d=p_{i+1}-p_i.$$答えを乗算します$$v^{2d}-v^{d-1}(v-1).$$これにより、そのセグメント内の有効なバイナリ制約の割り当てがすべてカウントされます。 

1. 答えを掛ける$$v^{2(n-p_k)}$$最後の固定位置の後の制約のない接尾辞の場合。 

1. 答えのモジュロを出力します$10^9+7$。 

### なぜ効果があるのか

 2 つの固定位置で囲まれたセグメントは、左側の固定値がセグメント内のすべての含意をアクティブにし、右側の終点に到達してその固定値とは異なる値を要求する強制チェーンを作成する場合にのみ満足できなくなります。 

残りの変数は自由に選択できるため、その連鎖が切れるとすぐに満足度が回復します。 

不適切な構成とは、まさに上記で説明した継続的な強制チェーンであり、その数は次のとおりです。$v^{d-1}(v-1)$。 

異なるセグメントには、互いに素なバイナリ制約のセットが含まれるため、それらの選択は独立しています。 各セグメントの寄与を乗算すると、有効な割り当ての総数が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007

def solve():
    t = int(input())

    for _ in range(t):
        n, m, v = map(int, input().split())

        fixed = {}
        ok = True

        for _ in range(m):
            c, d = map(int, input().split())

            if c in fixed and fixed[c] != d:
                ok = False
            fixed[c] = d

        if not ok:
            print(0)
            continue

        pos = sorted(fixed.keys())

        ans = 1

        first = pos[0]
        ans = ans * pow(v, 2 * (first - 1), MOD) % MOD

        for i in range(len(pos) - 1):
            d = pos[i + 1] - pos[i]

            total = pow(v, 2 * d, MOD)
            bad = pow(v, d - 1, MOD) * ((v - 1) % MOD) % MOD

            ans = ans * ((total - bad) % MOD) % MOD

        last = pos[-1]
        ans = ans * pow(v, 2 * (n - last), MOD) % MOD

        print(ans)

solve()
```コードの最初の部分では、単項制約が自己矛盾しているかどうかをチェックします。 位置に 2 つの異なる値が割り当てられている場合、解は存在せず、答えはすぐにゼロになります。 

ソートされた固定位置は、満足可能性を実際にテストできる唯一の場所を定義します。 これらのポジション以外のすべてのものは、純粋な力に貢献します。$v^2$なぜなら、そこでのバイナリ制約は任意に選択できるからです。 

セグメントごとに次のように計算します。$$v^{2d}$$考えられるすべてのバイナリ制約の代入と減算$$v^{d-1}(v-1)$$矛盾を生み出すユニークな任務群に対して。 

すべてのべき乗には Python のモジュラーを使用します`pow`、これは対数時間で実行され、次の理由により不可欠です。$n$そして$v$どちらも到達できる$10^9$。

import sys, io

MOD = 1000000007

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n, m, v = map(int, input().split())

        fixed = {}
        ok = True

        for _ in range(m):
            c, d = map(int, input().split())

                ok = False
            fixed[c] = d

            continue

        pos = sorted(fixed)

        ans = pow(v, 2 * (pos[0] - 1), MOD)

        ans = ans * pow(v, 2 * (n - pos[-1]), MOD) % MOD

    return "\n".join(out)
