 ## 解決策
 ## 問題の理解

 都市がノード、魔法のポータルが有向エッジである有向グラフが与えられます。 各ポータルは一方通行の移動ルートを表します。 ミサカは、クローンと呼ばれる複数の独立したエージェントを使用して、できるだけ多くのポータルを「調査」したいと考えています。 

ポータルは、単一のクローンがポータルを 2 回通過した場合にのみ、調査に成功したとみなされます。 エッジには方向があるため、これは暗黙的に、クローンがそのエッジに沿って移動し、後で戻って同じ方向に再度横断できる必要があることを意味します。 したがって、ポータルは、グラフ構造が同じエージェントによる有向エッジの繰り返しの横断を許可する場合にのみ使用できます。 

追加の制約があります。異なるクローンは、互いに素な都市セットで動作する必要があります。 複数のクローンが都市を訪れることはできません。 各クローンには開始都市が割り当てられ、他のクローンが訪れた頂点と交差することなくそこから探索します。 

タスクには 2 つの出力があります。 まず、これらの制約の下で調査できるポータルの数を最大化する必要があります。 第二に、その最大値を達成するすべての戦略の中で、必要なクローンの数を最小限に抑える必要があります。 

入力サイズは 5 万都市と 5 万エッジに達しており、線形または線形に近いグラフ アルゴリズムであることが強く示唆されています。 ノードまたはエッジ上の二次関数はすべて即座に失敗します。 これにより、明示的なパス列挙の形式ではなく、強く接続された構造の分析が行われるようになります。 

重要なエッジケースは、グラフがすでに非循環である場合に発生します。 この状況では、指示に従って開始エンドポイントに戻る方法がないため、同じクローンによって有向エッジを 2 回横断することはできません。 正解は、調査されたポータルもクローンもゼロになります。 

もう 1 つのエッジ ケースは、単一の強く接続されたコンポーネントであるグラフです。 ここでは、すべてのノードが他のすべてのノードに到達できるため、すべてのエッジが潜在的に使用可能になり、反復的な走査が可能になります。 

## アプローチ

 直接的な試みでは、クローンの移動をシミュレートします。クローンを開始ノードに割り当て、エッジに沿って歩くことを試み、クローン間でノードが再利用されないよう強制します。 各クローンは、2 回横断できるエッジの数を最大化しようとします。 これはすぐに、共有除外制約を持つ有向グラフ内のパスに対する組み合わせ割り当ての問題になり、可能なパス割り当ての数は都市の数に応じて指数関数的に増加します。 どのクローンがどの都市を訪問するかについてのローカルな選択により、強く接続された大規模な領域の最適な使用が妨げられる可能性があるため、貪欲なヒューリスティックでも失敗します。 

重要な観察は、「ポータルを 2 回通過する」には実際に何が必要かを再構成することから得られます。 クローンが有向エッジ u → v を使用し、後でそれを再度使用する場合、方向制約に違反することなく v から u に戻ることができなければなりません。 これは、u と v がサイクル内に存在し、実際には同じ強く接続された領域内に存在する必要があることを直ちに意味します。 強く接続された 1 つのコンポーネントから別のコンポーネントに向かうエッジは、それを通過した後に戻る方向のパスがないため、最大 1 回しか使用できません。 

これにより、問題の構造が強く接続されたコンポーネントの凝縮グラフに還元されます。 凝縮グラフは DAG であり、エンドポイントが同じコンポーネント内にあるエッジのみが繰り返しの走査に使用できます。 したがって、調査されたポータルを最大化することは、SCC 内に完全に存在するすべてのエッジをカウントすることと同じです。 

これが確立されると、後半の部分が簡単になります。 クローンは都市を共有できないため、各クローンは完全に独立した SCC リージョン グループ内で動作する必要があります。 単一のクローンをコンポーネントまたは共有都市に分割できないため、使用可能なエッジを少なくとも 1 つ含む SCC には、少なくとも 1 つのクローンを割り当てる必要があります。 内部エッジのない SCC は目的に何も貢献しないため、クローンを必要としません。

これにより、クリーンな SCC ベースのソリューションが実現します。つまり、強接続コンポーネントを計算し、エッジを内部コンポーネントまたはクロスコンポーネントとして分類し、内部エッジをカウントし、少なくとも 1 つの内部エッジを含むコンポーネントの数をカウントします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 ## アルゴリズムのチュートリアル

 次に、グラフを強く接続されたコンポーネントに圧縮し、コンポーネント レベルでエッジを分析します。 

### 1. 強結合成分を計算する

 Kosaraju や Tarjan などの標準的な SCC アルゴリズムを実行します。 各都市にはコンポーネント識別子が割り当てられます。 重要な特性は、1 つのコンポーネント内のすべてのノードが、有向パスを使用して相互に到達できることです。 

このステップでは、元のグラフを、サイクルが完全に短縮されたコンポーネントの DAG に変換します。 

### 2. 各エッジを分類する

 すべてのポータル u → v について、両方のエンドポイントが同じ SCC に属しているかどうかを確認します。 

存在する場合、このエッジはサイクル構造の内側にあり、クローンによって 2 回横断される可能性があります。 私たちはそれを調査可能なポータルとして数えます。 

それらが異なる SCC に属している場合、エッジは最初の応答では無視されます。これは、一度交差すると、有向構造内に戻りパスがないためです。 

### 3. 内部エッジのコンポーネントを数える

 SCC ごとにブール値マーカーを維持します。 コンポーネント内の内部エッジに遭遇するたびに、そのコンポーネントを「アクティブ」としてマークします。 

これは、SCC 内の少なくとも 1 つのポータルを調査できることを表します。つまり、少なくとも 1 つのクローンをその領域に割り当てる必要があります。 

### 4. 答えを導き出す

 最初の答えは、すべての SCC にわたる内部エッジの合計数です。 

2 番目の答えは、アクティブとマークされた SCC の数です。 

### なぜ効果があるのか

 強く接続されたコンポーネント内では、すべてのノードが他のすべてのノードに到達できるため、そのコンポーネント内の任意の場所に配置されたクローンは、サイクルでエッジを横断し、必要に応じてエッジを再訪問できます。 SCC の外側のエッジはサイクルの一部になることはできないため、同じクローンによって 2 回横断することはできません。 クローンは都市を共有できないため、作業を必要とする各 SCC を個別に処理する必要があり、アクティブな SCC ごとに 1 つのクローンが強制されます。 これにより、SCC 構造と最適なクローン割り当ての間に直接マッピングが作成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

def kosaraju(n, adj, radj):
    visited = [False] * (n + 1)
    order = []

    def dfs1(u):
        visited[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(1, n + 1):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * (n + 1)

    def dfs2(u, c):
        comp[u] = c
        for v in radj[u]:
            if comp[v] == -1:
                dfs2(v, c)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    return comp, cid

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    radj = [[] for _ in range(n + 1)]

    edges = []

    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)
        radj[b].append(a)
        edges.append((a, b))

    comp, c = kosaraju(n, adj, radj)

    internal_edges = 0
    active = [0] * c

    for a, b in edges:
        if comp[a] == comp[b]:
            internal_edges += 1
            active[comp[a]] = 1

    clones = sum(active)

    print(internal_edges)
    print(clones)

if __name__ == "__main__":
    main()
```実装ではまず、Kosaraju の 2 パス SCC 分解に必要な前方隣接リストと逆隣接リストの両方を構築します。 コンポーネントのラベルを計算した後、各エッジが一定時間でチェックされ、コンポーネント内に留まるかどうかが判断されます。 

微妙な点は、クローンがエッジごとではなく、少なくとも 1 つの内部エッジを含む SCC ごとにカウントされることです。 この区別は、コンポーネントに多くのエッジが含まれているものの、完全な内部接続により 1 つのクローンのみが必要な場合に重要になります。 

## 実用的な例

 ### サンプル 1

 複数のサイクルと相互接続を含むグラフから始めます。 

| ステップ | アクション | 内部エッジ | アクティブな SCC |
 | --- | --- | --- | --- |
 | 1 | SCC を計算する | 0 | 0 |
 | 2 | エッジを処理し、同じコンポーネントのエッジを検出する | 17 | 部分的なマーキング |
 | 3 | 少なくとも 1 つの内部エッジを含む SCC をマークします。 17 | 6 |

 凝縮により、強く結合したいくつかの領域が明らかになります。 これらの領域内に完全に含まれるエッジのみがカウントされます。 コンポーネント間のエッジはすぐに破棄されます。 6 つのコンポーネントには少なくとも 1 つの内部エッジが含まれるため、6 つのクローンが必要です。 

### サンプル 2

 入力は、サイクルを形成しない 2 つの切断されたエッジで構成されます。 

| ステップ | アクション | 内部エッジ | アクティブな SCC |
 | --- | --- | --- | --- |
 | 1 | SCC を計算する (すべての単一ノード) | 0 | 0 |
 | 2 | コンポーネント間のすべてのエッジをチェックします。 0 | 0 |
 | 3 | 内部エッジを含む SCC はありません。 0 | 0 |

 有向サイクルが存在しないため、ポータルを 2 回通過することはできません。 したがって、両方の出力はゼロになります。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | SCC の 2 つの DFS パスとエッジ上の 1 つのリニア スキャン |
 | スペース | O(n + m) | 隣接リスト、逆グラフ、コンポーネント配列 |

 この制約では最大 50,000 のノードとエッジが許可されるため、線形時間 SCC アルゴリズムは制限内に問題なく適合します。

 ## 特殊なケース

 グラフにサイクルがまったくない場合、すべてのノードが独自の SCC を形成します。 このアルゴリズムは内部エッジをマークしないため、両方のカウンターはゼロのままで、ポータルを 2 回通過できないという事実と一致します。 

完全に強接続されたグラフでは、すべてのエッジが内部にあります。 SCC 分解では単一のコンポーネントが生成されるため、すべてのエッジがカウントされ、そのコンポーネント内で動作するには正確に 1 つのクローンが必要です。 

有向エッジによって接続された SCC が複数ある場合、それらのコンポーネント間エッジは最初の応答では無視され、少なくとも 1 つの内部エッジを含む SCC のみがクローンに割り当てられます。 これにより、調査可能なポータルに寄与しない領域のクローンが過剰にカウントされるのを防ぎます。
