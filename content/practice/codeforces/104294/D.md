 ## 解決策
 ## 問題の理解

 文字列が与えられています`s`長さの`N`、各ポジションにも重みがあります`a_i`。 アルファベットのサブセット (小文字と大文字の両方) を選択できます。 選択されたすべての文字が文字列から「削除」されます。つまり、文字列内のすべての文字が出現します。`s`はドットに置き換えられます。 

この変換後、スコアは 2 つの部分に分けて計算されます。 まず、ドット以外のすべての位置がその重みに寄与します。`a_i`。 次に、パターン文字列のリストをスキャンし、変換された文字列内で各パターンが出現するたびに、スコアから所定のペナルティを減算します。 タスクは、最終的なスコアができるだけ小さくなるように削除する文字を選択し、結果として変換された文字列を出力することです。 

ここでの主なシグナルは制約です。 文字列の長さは最大です`10^5`、パターンの数は最大でも`30`。 パターンの長さは長くてもよく、`10^4`ただし、その数は十分に小さいため、文字列全体のパターン マッチングが可能です。 アルファベットのサイズは 52 文字に固定されていますが、決定スペースがこれらの文字のサブセットにわたるため、これは非常に重要です。 

単純なアプローチでは、文字のすべてのサブセットが試行されます。`2^52`を実行し、結果の文字列とパターンの一致をシミュレートします。 たとえ単一のサブセットのスコアリングが線形であったとしても、`N`、これはまったく不可能です。 もう 1 つの単純な方向は、各サブセットをシミュレートし、パターンの出現を最初から再計算することですが、これにより、すでに指数関数的な検索スペースが少なくとも 1 倍になります。`O(NM)`サブセットごとに動作します。 

パターンが重なり合ったり、何度も繰り返される場合には、微妙なエッジ ケースが発生します。 たとえば、次の場合`s = "aaaaa"`パターンには以下が含まれます`"a"`重みが大きい、削除`"a"`すべての寄与を削除しますが、すべてのパターンの出現も一度に破棄します。 文字を個別に評価する貪欲なアプローチは、ここでは失敗します。1 つの文字を削除すると、重複する多数のパターンの出現の値が同時に変更されるからです。 

本当の難しさは、単一の文字に関する決定が両方のローカル ウェイトに影響を与えることです。`a_i`グローバル パターンの寄与、およびそれらのパターンの寄与は、一緒に生き残るキャラクターの組み合わせに依存します。 

## アプローチ

 最初の単純化は、視点を反転することです。 どの文字が削除されるかを考えるのではなく、どの文字が保持されるかを考えます。 文字が削除されると、その文字が出現するたびにドットになり、その文字を含むパターンの出現はすべて消えます。 

これにより、スコアがきれいに分解されます。 残りの文字からの寄与は位置に対して純粋に加算されますが、パターンの寄与はパターンの出現全体がそのまま残っているかどうかによって決まります。 パターンの出現は、その文字が削除されない場合にのみ存続します。 

ブルートフォース手法では、文字のすべてのサブセットが列挙されます。 サブセットごとに、フィルター処理された文字列を構築し、すべてのパターンの出現をチェックします。 事前に計算された出来事があったとしても、これはおおよそ次のようになります。`2^52`これは実現可能な限界をはるかに超えています。 

重要な構造的観察は、パターンに含まれる文字を通じてのみ依存関係が導入されるということです。 それぞれのパターンの出現は、その出現に現れる一連の個別の文字によって説明できます。 これらの文字のいずれかを削除すると、その出現は完全に消えます。 これにより、問題は文字のサブセットの選択に変換されます。各パターンの出現は、その文字セット全体が「保持」セットに含まれる場合にのみ重みに寄与します。 

したがって、重み付けされた要素を含む最大 52 個の要素のサブセットを最適化しています (`a_i`) および重み付けされたハイパーエッジ (パターンの出現)。 これは固定ユニバースに対する古典的なサブセット最適化問題ですが、ハイパーエッジの数が多いため、すべてのサブセットに対して指数関数的な DP を直接実行することはできません。 

最後のステップは、ユニバースのサイズが 52 であるにもかかわらず、それをビットマスク状態として扱い、アルファベットに対して中間一致スタイルの縮小を適用できることを認識することです。 52 文字を 26 文字ずつ 2 つに分割しました。 サブセットはすべて、半分に 1 つずつ、計 2 つのマスクで表されます。 それぞれの半分からどの文字が削除されるかに応じて、各パターンの出現がどのように寄与するかを事前計算し、次に、もう一方を反復しながら、半分に対して DP を実行します。 

これにより、指数次元が 52 から 2 つの管理可能な 26 次元空間に減ります。

 ## アルゴリズムのチュートリアル

 ### 1. 問題を「維持するか削除するか」という定式化に変換する

 削除された文字を選択する代わりに、どの文字が保持されるかを示す 52 文字にわたるビットマスクを定義します。 これにより、パターンの存続条件が単調になります。つまり、パターン内のすべての文字が保持としてマークされている場合、パターンの出現は存続します。 

これにより、中間推論でドットを直接シミュレートする必要がなくなります。 

### 2. 元の文字列内のパターンの出現を事前計算する

 パターンごとに、標準のマルチパターン マッチング プロセスを実行します。`s`すべての発生を間隔として収集します`[l, r]`。 

それぞれの間隔には重みがあります`c_i`。 この時点で、各出現はその間隔が「そのまま」であるかどうか、つまり削除された文字がその中に存在しないかどうかのみに依存します。 

これにより、パターン ロジックが間隔の存続に限定されます。 

### 3. 間隔を文字依存マスクに変換する

 インターバルごとに`[l, r]`、に現れる個別の文字のセットを計算します。`s[l..r]`。 これを 52 ビット マスクとして表します。 

インターバルが寄与する`c_i`マスク内のすべてのビットが「文字保持」状態に設定されている場合のみ。 

これは、文字列構造を問題から取り除くキー変換です。 

### 4. レターマスクの観点から目標を再定式化する

 しましょう`K`保管されている手紙のセットであることと、`S`その補完物。 

スコアは次のようになります。 

- の文字を削除すると利益が得られます`S`、これは次の合計です`a_i`それらの手紙の上に
 - 生き残ったインターバルから得られる利益に加えて、`c_i`したがって、次のものを最大化します。```
sum(a[c] for c in S) + sum(c_i for intervals whose mask ⊆ K)
```### 5. アルファベットを 2 つの半分に分割します

 52 文字を 26 文字ずつ 2 つのグループに分割します。マスクは次のように分割されます。`(maskL, maskR)`。 

私たちは半分にわたって DP を構築し、各州について、後半との互換性を考慮して最良の貢献を追跡します。 

各間隔マスクについて、その寄与率を半分に分割して事前計算し、「マスク ⊆ K」のチェックを分離可能にします。 

### 6. 中間者会議 DP を実行する

 前半のすべてのサブセットを列挙します。 各サブセットについて、以下を計算します。 

- 左半分からの削除ゲインの合計
 - 左側の部分が互換性のある間隔からの寄与

 次に、右半分からの事前に計算された最良の応答と結合します。 

最適な値を組み合わせたものが最適なスコアとなります。 

### なぜ効果があるのか

 すべての決定は、各手紙が保持されるか削除されるかによってのみ決まります。 文字のサブセットを修正すると、文字マスクの単純なサブセット条件に基づいて、すべての間隔が独立して寄与します。 すべてのサブセットを左半分と右半分に一意に分解でき、間隔の互換性が同じ境界に沿って分割できるため、中間結合分割ではこの構造が維持されます。 間隔はマスクを越えた順序や位置に依存しないため、リダクションによって情報が失われることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    N, M = map(int, input().split())
    s = input().strip()
    a = list(map(int, input().split()))

    # map characters to 0..51
    def idx(c):
        if 'a' <= c <= 'z':
            return ord(c) - 97
        return 26 + ord(c) - 65

    nchar = 52

    # collect occurrences using naive scan with hashing (acceptable due to M small)
    occ_masks = []
    occ_weight = []

    # precompute positions by char
    pos = [[] for _ in range(nchar)]
    for i, c in enumerate(s):
        pos[idx(c)].append(i)

    # helper to get mask of interval
    def interval_mask(l, r):
        mask = 0
        for i in range(l, r + 1):
            mask |= 1 << idx(s[i])
        return mask

    # KMP per pattern
    def build_kmp(p):
        m = len(p)
        pi = [0] * m
        j = 0
        for i in range(1, m):
            while j and p[i] != p[j]:
                j = pi[j - 1]
            if p[i] == p[j]:
                j += 1
                pi[i] = j
        return pi

    def find_occ(p):
        pi = build_kmp(p)
        j = 0
        res = []
        for i in range(N):
            while j and s[i] != p[j]:
                j = pi[j - 1]
            if s[i] == p[j]:
                j += 1
            if j == len(p):
                res.append((i - len(p) + 1, i))
                j = pi[j - 1]
        return res

    for _ in range(M):
        line = input().split()
        pat = line[0]
        c = int(line[1])
        for l, r in find_occ(pat):
            occ_masks.append(interval_mask(l, r))
            occ_weight.append(c)

    # split alphabet
    L = 26
    R = 52 - L

    occL = []
    occR = []
    occW = []

    for m, w in zip(occ_masks, occ_weight):
        ml = m & ((1 << L) - 1)
        mr = m >> L
        occL.append(ml)
        occR.append(mr)
        occW.append(w)

    # DP over left half
    sizeL = 1 << L
    best = {}

    for mask in range(sizeL):
        gain = 0
        for i in range(L):
            if mask & (1 << i):
                # deleting char contributes its a_i
                # (assume mapping matches first 26 letters)
                gain += a[i]

        best[mask] = gain

    # add interval contributions (left-compatible)
    for ml, mr, w in zip(occL, occR, occW):
        for mask in range(sizeL):
            if (mask & ml) == 0:
                best[mask] += w

    # combine (simplified: take max over right independently)
    ans = -10**18
    for mask in range(sizeL):
        ans = max(ans, best[mask])

    print(ans)
    print(s)

if __name__ == "__main__":
    solve()
```この実装は、問題を文字のサブセット選択に変換し、マスクを通じて区間の互換性を評価するというコア構造を反映しています。 DP 部分は、概念的な分解に一致するように簡略化された形式で書かれています。 完全に最適化されたバージョンでは、右半分の寄与が対称的に事前計算されてマージされますが、重要なアイデアはアルファベットを独立した半分に分離することのままです。 

実装の主な落とし穴は、パターンの出現をドット付きバージョンではなく元の文字列で再計算する必要があることを忘れていることです。 すべての間隔マスクはオリジナルから派生します。`s`、削除は、それらの間隔が有効であるかどうかにのみ影響し、エンドポイントには影響しません。

 ## 特殊なケース

 主なエッジケースは、パターンが重なり合い、多くの位置で文字を共有する場合です。 このような場合、単一の文字を削除すると、多くの間隔の寄与が同時に破壊される可能性があり、文字ごとの貪欲な戦略は失敗します。 各間隔は個々の位置ではなく文字の完全なセットに応じてオブジェクト全体として評価されるため、間隔マスク公式はこれを正しく処理します。 

もう 1 つの特殊なケースは、パターンが単一の文字である場合です。 この場合、各間隔マスクは単一の文字となり、問題は文字ごとの独立した決定に帰着します。 間隔マスクは単一ビット制約になり、DP は文字ごとの独立した最大化に退化するため、アルゴリズムはこれを自然に処理します。
