 ## 解決策
 ## 問題の理解

 私たちは鏡面反射の下で平面内を移動する点をシミュレートしています。そして、移動する点が原点にどれだけ近づくか、もう 1 つは原点を通過する 2 本の固定線で何回反射するかという 2 つのことを考慮します。 

ジオメトリは完全に決定的です。 相手は原点に座ります。 原点を通る 2 本の無限の線はミラーとして機能します。 1 つは正の x 軸から角度 α で配向され、もう 1 つは角度 β (α < β < 180) で配向されているため、原点によって分割されたくさび状の領域が形成されます。 点は (px, py) から始まります。 その点から、θ によって決定される方向に直線で移動します。θ は、説明したように、開始点のローカル フレームに固定された正の x 軸方向に対して相対的に与えられます。 点がいずれかの線に当たると、光線のように反射します。これは、入射角が反射角に等しいことを意味します。 

完全な無限の軌跡を追跡し、2 つの値を抽出する必要があります。1 つはこの破線のパス上の任意の点から原点までの最小ユークリッド距離、もう 1 つは衝突が発生せずに軌跡が無制限になるまでの反射の総数です。 

制約は重要です。角度は固定精度の実数であり、壁上で正確に開始したり、無限にかすめたりするような退化が回避されることが保証されます。 特に、軌道は病理学的にゼロに極端に近づくことはなく、任意の多数のイベントに対する数値シミュレーションではなく、きれいな幾何学構造または周期構造を強く示唆しています。 

線の交差と反射を繰り返し計算する単純な連続シミュレーションは理論的には正しいですが、浮動小数点ジオメトリが不安定になるリスクがあり、エスケープする前にパスが何度もバウンスする場合は反復回数が大きくなる可能性があります。 

「原点への最近接距離」について推論するときに、微妙な問題が発生します。最小値は、開始点、反射点、またはセグメントに沿ったどこかで発生する可能性があるため、各線形セグメントを、原点に最も近い点が明確に定義された幾何学的光線セグメントとして扱う必要があります。 

単純なアプローチを破るエッジ ケースには、逃げる前に多くの反射を生成するほぼ平行な軌道や、光線が非常に長い周期的なバウンスを引き起こす方法で角度ウェッジの境界に接するケースが含まれます。 たとえば、軌道が 2 つの壁の二等分線に関してほぼ対称である場合、繰り返しバウンドする可能性があります。 

入力:```
0.00000 90.00000
1 0
45.00000
```ここで、光線は (1,0) から始まり 45 度に向かいます。 どちらの線にも当たらずに外側に向かって直進するため、バウンス カウントは 0 になります。交差点の方向を誤ってチェックする単純なシミュレータでは、浮動小数点誤差により誤って誤って壁に当たったことが記録される可能性があります。 

別のケース:

 入力:```
45.00000 90.00000
2 3
270.00000
```これにより、ウェッジ内に下向きの光線が作成され、出る前に複数の反射が強制されます。正しい答えは、数値ドリフトを蓄積することなく、繰り返される反射を適切に処理するかどうかによって決まります。 

## アプローチ

 直接的な総当たり法は、レイを段階的にシミュレートすることです。 各ステップで、両方の線との交点を計算し、順方向に最も近い有効な交点を選択し、方向ベクトルを反映して、これを繰り返します。 各セグメントは、原点をセグメントに投影し、端点にクランプすることによって、原点からの最小距離の候補にも寄与します。 

これは正しいですが、最悪の場合の複雑さには原則として制限がありません。 ほぼ周期的なジオメトリでは、光線は逃げる前に非常に多くの回数反射する可能性があり、浮動小数点の累積により正確性が低下する可能性があります。 壁の間の角度が小さい場合、または軌道がウェッジとほぼ共鳴している場合、入力サイズが一定であっても、反射の数が入力サイズに比べて非常に大きくなる可能性があります。 

重要な観察は、原点を通る 2 本の無限の線が平面を角度セクターに分割し、原点を通る線を横切る反射が方向角の単純な変換に対応するということです。 デカルト空間でジオメトリをシミュレートする代わりに、反射を「展開」できます。線を横切って反射するたびに、その線を横切って平面全体を等価的に反射し、光線を真っ直ぐに続けることができます。 この展開図では、平面を繰り返しミラーリングしたタイリングで、軌道は直線になります。 

これにより、問題は一連の反射座標系内の直線の追跡に変換されます。 原点への最も近い距離は、原点からこれらの鏡像化された線までの最小距離となり、反射の回数は、鏡像化されたセクター間の境界を横切った回数に対応します。 

壁は原点を通過するため、反射により原点構造までの距離が非常にきれいな角度で維持されます。 したがって、方向角を追跡し、α と β で角度境界の交差を数え、対称反射規則によって光線の方向を更新するプロセスを減らすことができます。

 ## アルゴリズムのチュートリアル

1. すべての角度を度からラジアンに変換し、一貫した角度系に正規化します。 これにより、すべての幾何学的操作が安定し、比較可能になります。 私たちは、生の角度ではなく、角度から導出された方向ベクトルを扱います。 
2. 現在の動きを、(px, py) から始まり方向ベクトル (dx, dy) を持つパラメトリック光線として表します。 これにより、標準の 2D ライン交差公式を使用して 2 つのラインとの交差を計算できるようになります。 
3. 光線と各壁との最初の交点を計算します。 各壁について、角度 α または β で原点を通る無限線上にある t in (px, py) + t(dx, dy) を求めます。 負の t 値は光線の原点の後ろにあるため、無視します。 
4. 最小の正の交差時間を選択します。 これにより、最初にどの壁にぶつかるかが決まります。 交差が存在しない場合、光線が再び壁に当たることはありません。そのため、この無限光線セグメントの原点までの最小距離を計算し、反射処理を終了できます。 
5. 壁にぶつかると、バウンスカウンターが増加し、その壁を横切る方向ベクトルが反映されます。 反射は標準式 v' = v - 2 (v・n)n を使用して計算されます。ここで、n は壁の単位法線です。 これにより、正確なミラー動作が保証されます。 
6. 反映後、交差を再計算し、繰り返します。 各セグメントで、原点をセグメントの支持線に投影し、パラメーター t を [0,segment_length] にクランプすることにより、原点から現在のセグメントまでの最も近い距離を計算します。 グローバル最小距離を更新します。 
7. 光線がどちらの壁にも再び交差せずに逃げたら停止します。 累積バウンス数と見つかった最小距離を返します。 

### なぜ効果があるのか

 重要な不変条件は、動きの各セグメントがユークリッド空間内の直線であり、反射は原点で定義された壁との幾何学的交差の正確さを維持しながら方向のみを変更するということです。 このプロセスでは、軌道の途切れのない最大の直線セグメントをすべて 1 回だけ列挙します。 原点までの潜在的な最小距離はそれぞれ、セグメントの開始点、終了点、またはそのセグメントへの原点の投影のいずれかで発生する必要があるため、すべてのセグメントを評価することでグローバル最小値が確実に捕捉されます。 反射ルールでは角度の等価性が維持されるため、有効な軌道セグメントがスキップされたり複製されたりすることはありません。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1]

def sub(a, b):
    return (a[0]-b[0], a[1]-b[1])

def add(a, b):
    return (a[0]+b[0], a[1]+b[1])

def mul(a, t):
    return (a[0]*t, a[1]*t)

def norm2(a):
    return a[0]*a[0] + a[1]*a[1]

def reflect(v, ang):
    # reflect vector v across line through origin with direction ang
    # line unit direction
    lx, ly = math.cos(ang), math.sin(ang)
    # projection onto line
    proj = dot(v, (lx, ly))
    parallel = (lx * proj, ly * proj)
    perp = sub(v, parallel)
    # reflection: v' = parallel - perp
    return sub(parallel, perp)

def intersect_time(p, d, ang):
    # line through origin direction ang: all points t*(cos, sin)
    lx, ly = math.cos(ang), math.sin(ang)
    # solve p + t d = s l
    # cross product method
    denom = d[0]*ly - d[1]*lx
    if abs(denom) < 1e-12:
        return None
    t = (lx*p[1] - ly*p[0]) / denom
    if t <= 1e-12:
        return None
    return t

def dist_to_origin_segment(p, d, t):
    # segment from p to p + t d
    # projection parameter
    pd = dot(p, d)
    dd = dot(d, d)
    if dd == 0:
        return math.sqrt(norm2(p))
    u = -pd / dd
    u = max(0.0, min(t, u))
    x, y = p[0] + u*d[0], p[1] + u*d[1]
    return math.hypot(x, y)

def solve():
    alpha, beta = map(float, input().split())
    px, py = map(float, input().split())
    theta = float(input())

    alpha = math.radians(alpha)
    beta = math.radians(beta)
    theta = math.radians(theta)

    # initial direction is theta from +x axis
    d = (math.cos(theta), math.sin(theta))
    p = (px, py)

    ans = math.hypot(px, py)
    bounces = 0

    for _ in range(200):  # safety cap
        t1 = intersect_time(p, d, alpha)
        t2 = intersect_time(p, d, beta)

        ts = []
        if t1 is not None:
            ts.append((t1, alpha))
        if t2 is not None:
            ts.append((t2, beta))

        if not ts:
            # no more intersections
            ans = min(ans, dist_to_origin_segment(p, d, 1e18))
            break

        t, ang = min(ts)

        ans = min(ans, dist_to_origin_segment(p, d, t))

        p = add(p, mul(d, t))
        d = reflect(d, ang)
        bounces += 1

    print(f"{ans:.10f} {bounces}")

if __name__ == "__main__":
    solve()
```このソリューションでは、光線を移動点と方向ベクトルとして維持します。 各反復では、外積定式化を使用して次の壁の交差を計算します。これにより、不安定性を明示的に解決する線分が回避されます。 反射は、方向を壁の方向に平行な成分と垂直な成分に分解することによって行われます。 距離の計算では、両方の端点と各セグメントへの原点の内部投影が注意深くチェックされ、候補の最小値が見逃されないことが保証されます。 

ジオメトリが最終的なエスケープを保証するため、ループはキャップされています。 実際には、与えられた制約の下では反射の数は少なく、ステートメント内の数値安定性の仮定により、無限のバウンス縮退が発生しないことが保証されます。

 ## 特殊なケース

 重要なケースの 1 つは、光線がどちらの壁にも当たらない場合です。 たとえば、方向が両方の線から離れる方向を指している場合:

 入力:```

45
```アルゴリズムは直ちに交差時間を検出し、開始時に発生する光線全体にわたる最小距離を計算します。 原点の投影が光線の始点の後ろにあるため、端点のみが問題となるため、セグメント距離の計算によりこれが確認されます。 

もう一つのケースは、逃げる前に何度も反省を繰り返すケースです。 例えば：```

2 3

```ここで、光線はほぼ即座に境界に到達し、反射して継続します。 各反復では、更新された方向から交差時間を再計算し、反射がスキップされないようにします。 バウンス カウンタは、物理モデルに一致して、壁に当たるたびに 1 回だけ増加します。 

3 番目のケースには、セグメントの内部にあるセグメントへの原点の投影が含まれます。 このような場合、最小距離は端点ではなく、垂直の足の部分になります。 セグメント距離ルーチンは、投影パラメータをセグメント間隔に明示的にクランプし、飛行中に最接近が発生した場合でも正確さを保証します。
