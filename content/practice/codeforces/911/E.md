 ## 解決策
 ## 問題名: **削除後の最大合計**

 **問題の説明:**

 整数の配列が与えられます$a_1, a_2, \dots, a_n$そして整数$k$。 パフォーマンスできるのはせいぜい$k$操作。 各操作で、配列の **最初または最後の要素** を削除できます。 まで演奏した後、$k$操作では、残りの要素の **最大合計** を見つけます。 

**制約:**

 -$1 \le n \le 2 \cdot 10^5$-$1 \le k \le n$-$-10^9 \le a_i \le 10^9$## ソリューションの概要

 この問題では、エッジから要素を削除した後の合計を最大化することが求められます。 

所見:

 1. エッジから要素を削除することは、プレフィックスとサフィックスをいくつか削除した後、**中間のどこかにある連続したサブ配列を選択する**ことと同じです。 
2. 削除する要素の合計数は最大で次のとおりです。$k$。 取り外すと$x$左から、最大で削除できます$k - x$右から。 

これは、**プレフィックス-サフィックス アプローチ** を示唆しています。つまり、左側から削除された要素の有効な数をすべて試し、右側から削除された要素との対応する合計を計算し、最大値を取得します。 

## 詳細な解決策

 1. **プレフィックス合計配列**を計算します$P[i] = a_1 + a_2 + \dots + a_i$。 させて$P[0] = 0$。 
2. **サフィックス合計配列**を計算します$S[i] = a_n + a_{n-1} + \dots + a_{n-i+1}$。 させて$S[0] = 0$。 

削除したい$x$要素は左から、$y$右から次のような要素$x + y \le k$。 残りの要素の合計は次のようになります。$$\text{sum\_remaining} = \text{total\_sum} - P[x] - S[y]$$どこ`total_sum`すべての要素の合計です。 

1. 反復する$x$から$0$に$\min(k, n)$、それぞれについて$x$、反復します$y$から$0$に$\min(k - x, n - x)$。 **最大残高**を記録してください。 
2. 特別な場合:$k \ge n$、すべての要素を削除して、合計を 0 (空の配列の合計を別の方法で解釈した場合は負の無限大になる可能性があります) を残すことができます。 

### Python コードの実装```python
n, k = map(int, input().split())
a = list(map(int, input().split()))

total_sum = sum(a)
prefix = [0] * (n + 1)
suffix = [0] * (n + 1)

for i in range(1, n + 1):
    prefix[i] = prefix[i-1] + a[i-1]

for i in range(1, n + 1):
    suffix[i] = suffix[i-1] + a[n-i]

max_sum = -float('inf')
for x in range(0, min(k, n) + 1):
    for y in range(0, min(k - x, n - x) + 1):
        remaining = total_sum - prefix[x] - suffix[y]
        max_sum = max(max_sum, remaining)

print(max_sum)
```### 複雑さの分析

 - **時間計算量:**$O(k^2)$最悪の場合ですが、それ以来$k \le n$、許容範囲です$n \le 2 \cdot 10^5$さらに最適化された場合。 
- **空間の複雑さ:**$O(n)$プレフィックス配列とサフィックス配列の場合。 

**最適化された注:** までの時間を短縮できます。$O(k)$それぞれを観察することで$x$、サフィックスの最大合計が必要なだけです。$k-x$要素。 

### 例

 **入力:**```
5 2
1 2 3 4 5
```**出力：**```
12
```**説明:**

 - 左から 1 つの要素と右から 1 つの要素を削除します: 残り`[2, 3, 4]`→ 合計 = 9
 - 左から 2 つの要素を削除します: 残り`[3, 4, 5]`→ 合計 = 12 (**最大値**)

 このアプローチはプレフィックスとサフィックスの削除問題の標準であり、注意深く最適化することで適切に拡張できます。
