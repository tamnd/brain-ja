 ## 解決策
 ## 問題の理解

 整数で表されるパティケーキのマルチセットが与えられます。 等しい整数は等しい充填を意味します。 食べる順番は自由です。 

複数回出現するすべてのフィリングについて、食べる順番で連続して出現する間の距離を調べることができます。 距離は厳密にはそれらの間のパティケーキの数として定義されます。 たとえば、次のようなシーケンスになります。```
1 2 3 1
```充填の 2 つの発生`1`距離がある`2`。 

私たちの目標は、すべての等しいフィリング間の最小距離ができるだけ大きくなるように、すべてのパティ ケーキを配置することです。 達成可能な最小距離を出力する必要があります。 

テスト ケースの数は最大 100 ですが、重要な制約は、すべてのテスト ケースにわたるパティ ケーキの総数が最大 100 であることです。`10^5`。 これはすぐに次のような解決策を示唆しています。`O(n log n)`テスト ケースごとのテストは許容されますが、二次関数は不可能です。 再配置を繰り返しシミュレーションする構築は、回答時間に比例した作業を実行すると遅すぎます。`n`。 

いくつかの特殊なケースは判断を誤りやすいものです。 

考慮する：```
3
3 3 3
```可能な順序は次のとおりです。```
3 3 3
```距離は`0`そして`0`、したがって、答えは次のようになります。```
0
```個別の詰め物の数のみに基づく単純な式は、詰め物が 1 つしかないため、ここでは失敗します。 

考慮する：```
6
1 1 1 2 2 3
```最も頻繁な充填は 3 回表示されます。 3 つのコピーを均等に広げてみることもできます。```
1 2 1 3 1 2
```最短距離はただ`1`。 答えは、頻度そのものだけではなく、最も頻度の高い値によって生じるギャップにどれだけの要素を配置できるかによって決まります。 

別の微妙なケースは次のとおりです。```
6
2 5 2 3 1 4
```解答例は、`4`。 値以来`2`2 回出現する場合は、残りの 4 つの要素をすべてそれらの間に配置できます。```
2 5 3 1 4 2
```距離は`4`。 これは、距離が複製された値の頻度よりもはるかに大きくなる可能性があることを示しています。 

## アプローチ

 ブルートフォースアプローチでは、マルチセットの順列を生成し、各順列での等しい充填間の最小距離を計算し、最良の値を取得します。 これは、解空間全体を直接検索するため、正しいです。 残念ながら、たとえ`n = 15`、すでに以上のものがあります`10^12`順列。 実際の制限は`10^5`, そのため網羅的な検索は全く不可能です。 

重要な観察は、最大頻度の詰め物のみが重要であるということです。 

最大の周波数が`mx`。 させて`cnt`正確に発生する詰め物の数になります`mx`回。 

最も頻繁に発生するすべての詰め物を最初に配置することを想像してください。 それぞれの具材が登場するので、`mx`彼らが生み出すのは、`mx - 1`連続するコピー間の内部ギャップ。 

たとえば、2 つの具材がそれぞれ 4 回出現する場合:```
A A A A
B B B B
```それからあります`3`連続するコピーを分離する必要があるギャップの層。 

他のパティケーキはこれらの隙間を埋めるためにのみ使用できます。 させて```
rest = n - mx * cnt
```頻度が最大値よりも厳密に小さいパティ ケーキの数になります。 

これら`rest`要素は次の間で分散できます。`mx - 1`ギャップグループ。 各ギャップが受信した場合```
rest // (mx - 1)
```要素が含まれており、一部のギャップには追加の要素が 1 つ追加されるため、最小のギャップ サイズは正確になります。```
rest // (mx - 1)
```あるという事実を考慮した上で、`cnt`同じ構造を共有する最大周波数の充填の場合、最終的な式は次のようになります。```
(rest // (mx - 1)) + cnt - 1
```これは公式ソリューションで証明された値です。 

問題全体は頻度を数えるということに帰着します。

 ## アルゴリズムのチュートリアル

 1. すべての充填の頻度を数えます。 
2. 最大周波数を見つける`mx`。 
3. 充填が何回行われたかを正確に数えます`mx`回。 この値を呼び出します`cnt`。 
4. 残りのパティケーキの数を計算します。```
rest = n - mx * cnt
```5. もし`mx = 1`、すべての詰め物はユニークです。 この問題では少なくとも 1 つの重複が保証されますが、このケースを処理すると式が完全になります。 答えは次のようになります。`n - 1`。 
6. それ以外の場合は、次のように計算します。```
answer = rest // (mx - 1) + cnt - 1
```7. 答えを出力します。 

ステップ 6 が機能する理由は、`mx - 1`最も頻繁に充填される充填物によって形成される必須の分離層がボトルネックとなります。 残りの要素はすべて、それらのレイヤー間で分散する必要があります。 この商は、各層がどれだけのフィラーを受け入れることができるかを示します。`cnt - 1`は、各層内の位置を占める追加の最大周波数充填を考慮します。 

### なぜ効果があるのか

 最大の頻度を持つ塗りつぶしを支配的な色とします。 有効な配置では、各ドミナントカラーの連続する出現をいくつかの要素で区切る必要があります。 それぞれのドミナントカラーが現れるので、`mx`回、まさにあります`mx - 1`埋める必要がある間隔。 

非支配的元素の総供給量は`rest`。 それらをできるだけ均等に分散すると、最小間隔が最大になります。 すべての間隔をこれより大きくすることはできません。`rest // (mx - 1)`、しかないからです。`rest`フィラー要素が利用可能です。 

複数のドミナントカラーが存在する場合、それらは互いにインターリーブすることができます。 これは効果的に貢献します`cnt - 1`すべてのインターバルに追加のポジションを追加します。 結果として得られる値は達成可能かつ最適であり、次のようになります。```
rest // (mx - 1) + cnt - 1
```## Python ソリューション```python
import sys
from collections import Counter

input = sys.stdin.readline

def solve():
    t = int(input())

    ans = []

    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        freq = Counter(a)

        mx = max(freq.values())
        cnt = sum(1 for v in freq.values() if v == mx)

        rest = n - mx * cnt

        answer = rest // (mx - 1) + cnt - 1
        ans.append(str(answer))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```実装は数式に直接に従います。`Counter`すべての周波数を線形時間で計算します。 変数`mx`最大周波数を格納します。 変数`cnt`どれだけの充填がその頻度に達したかをカウントします。 

表現```
rest = n - mx * cnt
```最大頻度の塗りつぶしがすべて削除されます。 残っているのは、まさにギャップを埋めるために利用できる要素だけです。 

最後の式では整数の除算が使用されます。 フィラー要素を複数の場所に分散させるため、これは重要です。`mx - 1`完全なグループのみが最小ギ​​ャップ サイズに寄与します。 

すべての計算は標準の Python 整数に快適に適合します。
