 ## 解決策
 ## 問題の理解

 私たちは与えられています`n`ギフト。各ギフトは特定の数のキャンディーと特定の数のオレンジで構成されます。 それぞれのプレゼント`i`もっている`a_i`キャンディーと`b_i`オレンジ。 私たちの目標は、可能な限り少ない手数で、キャンディーとオレンジの両方の点ですべてのギフトを同一にすることです。 1 回の行動で、1 つの贈り物からキャンディー 1 つ、オレンジ 1 つ、またはその両方を食べることができますが、贈り物に含まれている以上のものを取り出すことはできません。 

入力は複数のテスト ケースで構成されます。 各テスト ケースには、ギフトの数と 2 つの配列 (キャンディー用とオレンジ用) が与えられます。 すべてのギフトを同等にするために必要な最小の手数を出力する必要があります。 

制約は中程度です。`n`最大50まで上げることができ、それぞれ`a_i`または`b_i`と同じ大きさにすることができます`10^9`。 これは、数値が大きい場合、すべての動きを個別にシミュレートすることはできないことを意味します。それは遅すぎるためです。 代わりに、差から直接総手数を計算するアプローチが必要です。 

素朴な解決策がつまずく可能性のあるエッジケースとしては、すべてのギフトにすでに同じ数のキャンディーまたはオレンジが含まれている場合、または 1 つのギフトに他のギフトに比べて非常に多くのキャンディーまたはオレンジが含まれている場合などがあります。 たとえば、次の場合`a = [1, 1000000000]`そして`b = [1, 1]`、一度に 1 つのキャンディーを削除する単純なシミュレーションは実行不可能です。 

## アプローチ

 ブルートフォースアプローチでは、すべてのギフトが一致するまで繰り返しギフトを選択し、キャンディーやオレンジを減らそうとします。 これは正しいですが、各操作を最大で繰り返す可能性があるため、非効率的です。`10^9`いくつかの贈り物のための時間。 と`n=50`、その結果、`50 * 10^9`1秒以内には不可能な操作です。 

最適な解決策につながる重要な観察は、すべてのギフトのキャンディーの目標数が、すべてのギフトの中で少なくとも最小でなければならないということです。`a_i`同様に、オレンジの目標数は、すべてのオレンジの中で少なくとも最小でなければなりません。`b_i`。 すべてのギフトをそれぞれの最小値まで減らすことは常に実行可能であり、ギフトごとに必要な手数は最小限に抑えられます。 1 つのギフトに対して、「両方を同時に」最適な動作を実行できます。 具体的には、`a_i`キャンディーと`b_i`オレンジを減らしたい場合は、`min_a`そして`min_b`、両方を同時に何回でも減らすことができます`min(a_i - min_a, b_i - min_b)`、残りを個別に完了します。 この貪欲なアプローチにより、最小限の移動が保証されます。 

ブルートフォースアプローチと最適アプローチの比較は次のとおりです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * max(a_i, b_i)) | O(n) | 遅すぎる |
 | 最適 | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`そして`b`キャンディーとオレンジを表します。 
2. コンピューティング`min_a = min(a)`そして`min_b = min(b)`。 これらは、すべてのギフトのキャンディーとオレンジの目標数を表します。 
3.初期化`moves = 0`。 これにより、必要な移動の合計が蓄積されます。 
4. 各ギフトを反復処理する`i`0から`n-1`。 
5. ギフト用`i`、余ったキャンディーを計算します。`delta_a = a[i] - min_a`そして余ったオレンジ`delta_b = b[i] - min_b`。 
6. このギフトの手数は`max(delta_a, delta_b)`。 可能な限りキャンディーとオレンジの両方を同時に減らすことができるため、最大値を使用します。 たとえば、次の場合`delta_a=3`そして`delta_b=1`、1 つの移動で両方を減らすことができ、キャンディーだけで 2 つの移動が残り、合計で`max(3,1)=3`。 
7. このギフトの動きを`moves`。 
8. すべてのギフトを処理した後、合計を出力します`moves`。 

それが機能する理由: 不変の条件は、各贈り物を常に最小限のキャンディーとオレンジに正確に減らすことです。 「両方同時に」の動きを貪欲に行うことで、不必要な単品削減は一切行いません。 各ギフトに必要な動きは独立しているため、それらを合計するとグローバル最小値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    b = list(map(int, input().split()))
    
    min_a = min(a)
    min_b = min(b)
    
    moves = 0
    for i in range(n):
        delta_a = a[i] - min_a
        delta_b = b[i] - min_b
        moves += max(delta_a, delta_b)
    
    print(moves)
```コードは最初にテスト ケースの数を読み取ります。 テスト ケースごとに、配列を読み取り、最小のキャンディーとオレンジを計算し、各ギフトを反復処理して、最大の差を使用して最小の手を計算します。 このアプローチは、最適なアルゴリズムを直接実装し、非常に大きな数値を効率的に処理します。 の選択`max(delta_a, delta_b)`これにより、最初に組み合わせた削減を最適に適用できるようになります。
