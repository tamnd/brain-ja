 ## 解決策
 ## 問題の理解

 4 つの整数が与えられます$l, r, x, y$。 タスクは順序付きペアをカウントすることです$(a, b)$両方の数値が区間内に収まるように$[l, r]$、そしてそれらの最大公約数は正確に$x$一方、それらの最小公倍数は正確に$y$。 

任意の整数の観点から考える代わりに、条件を、どのように行うかに関する非常に厳密な構造的制約として見ると役立ちます。$a$そして$b$構築されています。 GCD は両方の数値に共通の基数因数を共有させるのに対し、LCM は結合した素数構造を正確に一致させるように強制します。$y$。 したがって、区間内を自由に検索するのではなく、固定された算術パターンと完全に一致する必要があるペアを検索します。 

境界$l, r \le 10^9$すべての候補ペアを反復するアプローチは除外します。 単一の変数を反復処理する場合でも、構造を持たずにテストごとに実行すると限界に達します。 解決策は、検索空間を約数または因数分解に依存するものに縮小する必要があります。$y$、間隔のサイズではありません。 

重要なエッジ状況が発生するのは次の場合です。$y$で割り切れない$x$。 その場合、GCD が LCM を分割する必要があるため、ペアは存在できず、有効なペアはいずれも次の条件を満たす必要があります。$x \mid y$。 もう 1 つの微妙なケースは、割り算を満たした後でも、変換された変数の 1 つが正規化後に許容範囲外になる場合です。 

たとえば、次の場合$l = 1, r = 2, x = 2, y = 3$、ペアがありません。$x$分けない$y$両方の境界が十分に小さいため、ブルートフォースで候補者を試す可能性があります。 

## アプローチ

 直接的なアプローチでは、すべてのペアが試行されます$(a, b)$範囲内で$[l, r]$GCD が以下であるかどうかを確認します。$x$そしてLCMは$y$。 これは正しいですが、最悪のケースがあります。$(r-l+1)^2$小切手。 と$r$まで$10^9$、間隔を短くしても、列挙するには大きすぎる可能性があります。 

重要な点は、最初に両方の数値を正規化することで GCD 制約を削除することです。 設定すると$a = x \cdot A$そして$b = x \cdot B$、 それから$\gcd(A, B) = 1$。 この変換により、共通因数が分離され、問題は互いに素のペアを数えることに減ります。 

LCM 条件に代入すると、次のようになります。$$\text{lcm}(a, b) = x \cdot A \cdot B = y$$これは次のことを意味します:$$A \cdot B = \frac{y}{x} = k$$したがって、問題全体は、順序付き因子のペアを数えることに帰着します。$(A, B)$そのような$A \cdot B = k$、$\gcd(A, B) = 1$、そして両方$xA, xB$寝そべる$[l, r]$。 

これにより、きれいな構造が得られます。約数を列挙するだけで済みます。$k$、そして各約数について$A$、 定義する$B = k / A$、次に共素性と間隔制約を確認します。 

ブルート フォースは、次のサイズの 2D 空間で検索するため失敗します。$O(r^2)$一方、変換された問題は、除数構造にのみ依存します。$O(\sqrt{k})$。

 | ブルートフォース |$O((r-l+1)^2)$|$O(1)$| 遅すぎる |
 | 最適 |$O(\sqrt{y/x})$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず次のことを確認します。$y$で割り切れます$x$。 そうでない場合、GCD のスケーリングは非倍数 LCM を生成できないため、答えはすぐにゼロになります。 これにより、不必要な作業が回避されます。 
2. コンピューティング$k = y / x$。 ここで、次の因子ペアの観点から問題を再解釈します。$k$、各有効なペアは以下に対応します。$(A, B)$。 
3. すべての整数を反復処理します。$A$そのような$A \cdot A \le k$。 そういったそれぞれの$A$は潜在的な約数を表します$k$、そして我々は計算することができます$B = k / A$いつ$A$分割する$k$。 
4. 各約数について$A$、どうかを確認してください$k \bmod A = 0$。 そうでない場合は、有効なペアを形成できないため、スキップしてください。 
5. しましょう$B = k / A$。 かどうかを確認してください$\gcd(A, B) = 1$。 この条件により、元の数値が$xA$そして$xB$GCD を正確に持っている$x$、大きくはありません。 
6. 境界を確認して、元のドメインに戻します。$l \le xA \le r$そして$l \le xB \le r$。 
7. すべての条件が成立する場合、順序付きペアを数えます。 もし$A \ne B$、 両方$(A, B)$そして$(B, A)$は有効なので、2 を追加します。$A = B$、1を追加します。 

### なぜ効果があるのか

 任意の有効なペア$(a, b)$最大公約数を共有する必要がある$x$したがって、両方の数値を次のように割ります。$x$整数を生成します$A$そして$B$それは互いに素です。 LCM 条件により、製品は正確に次のようになります。$y/x$したがって、すべての有効なペアは、次の共素因数分解に全単射的に対応します。$k$。 境界は、これらの因数分解のどれが実際に区間内にあるかをフィルタリングするだけです。 すべてのステップで両方向の等価性が維持されるため、有効なペアが失われることも、無効なペアが導入されることもありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    l, r, x, y = map(int, input().split())
    
    if y % x != 0:
        print(0)
        return
    
    k = y // x
    ans = 0
    
    for a in range(1, int(math.isqrt(k)) + 1):
        if k % a != 0:
            continue
        b = k // a
        
        if math.gcd(a, b) != 1:
            continue
        
        A = x * a
        B = x * b
        
        if l <= A <= r and l <= B <= r:
            if a == b:
                ans += 1
            else:
                ans += 2
    
    print(ans)

if __name__ == "__main__":
    solve()
```コードは、次の間で必要な割り切り条件を検証することから始まります。$x$そして$y$。 それがなければ、変換された方程式は$A \cdot B = k$整数ですらないため、検索空間はすぐに崩壊します。 

除数に対するループでは、$\sqrt{k}$すべての約数のペアが 1 回だけ出現するため、$a$そして$k/a$。 gcd チェックは、削除後に余分な共通因数が残らないように強制します。$x$これは、逆変換を正確に行うために不可欠です。 

境界チェックは元の値を再構築した後に適用されます。$a = xA$そして$b = xB$制約は正規化されたドメインではなく元のドメインで定義されているためです。

 ## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$y$で割り切れない$x$。 たとえば、入力の場合$l=1, r=100, x=4, y=6$、変換には次のことが必要になります$A \cdot B = 1.5$、それは不可能です。 このアルゴリズムは、除数検索を試行する前にすぐに 0 を返します。 

もう 1 つのエッジケースは次のような場合です$A = B$、 意味$k$は完全な正方形です。 この状況では、順序付けは 2 つではなく 1 つだけ存在します。 例えば、$x=2, y=8$与える$k=4$、とペア$A=B=2$有効な構成を 1 つだけ生成します。 

3 番目のケースは境界クリッピングです。因子のペアが正規化された形式で有効であっても、次のようにスケーリングします。$x$外に押し出すことができる$[l, r]$。 例えば、$l=10, r=12, x=3, y=12$正規化されたペアを生成します$(1,4)$、 しかし$3\cdot4=12$の間有効です$3\cdot1=3$ではないため、境界フィルタリング後には 1 方向のみが残ります。
