 ## 問題の理解

 2 つのバイナリ文字列が与えられます`s`そして`t`長さの`n`。 文字列は次のもので構成されます`0`と`1`s. Sasha は次のことに興味があります: 指定された部分文字列範囲について`[l, r]`、部分文字列を考慮します`a = s[l..r]`と部分文字列`b = t[l..r]`。 2 つの操作が可能なコンピューティング マシンがあります。`a`1 つのインデックスで区切られた位置にゼロのペアが表示される場合、中間の位置を次のように設定できます。`b`に`1`。 同様に、`b`間に 1 つのインデックスを挟んで 1 のペアが表示される場合は、中間位置を設定できます。`a`に`1`。 私たちの目標は、`a`これらの操作を何度でも適用した後。 

入力は大きくなる可能性があります:`n`すべてのテストケースにわたって、`2*10^5`そしてクエリの合計`q`までです`2*10^5`。 これにより、各部分文字列に対してすべての操作を明示的にシミュレートするアプローチは除外されます。これは、最悪の場合、次のような事態につながる可能性があるためです。$O(n^2)$テストケースごとにそれ以上の場合もあります。 前処理後に定数または対数時間のクエリを可能にするアプローチが必要です。 

エッジケースは、部分文字列にゼロと 1 が交互に含まれる場合に発生します。`010101`。 既存のものだけをカウントする単純なアプローチ`a`この操作では新しい 1 が伝播できるため、1 の数は過小評価されます。`b`。 もう 1 つのエッジケースは次のような場合です`a`すべてが 1 であるか、`b`すべてゼロ - 操作によって何も変化が生じない可能性があります。 長さ 1 または 2 の小さな部分文字列も、操作に 3 つの要素が必要なため、慎重に処理する必要があります。 

## アプローチ

 ブルート フォース ソリューションでは、クエリごとにマシンをシミュレートします。 部分文字列を反復処理して、対象となるすべてのトリプルをチェックすることができます。`a`そして`b`、変更が発生しなくなるまで中央の要素を更新します。 これは正しいですが、最悪の場合の複雑さは次のとおりです。$O((r-l+1)^2)$クエリごとに、これでは遅すぎるでしょう`q`まで`2*10^5`そして`n`まで`2*10^5`。 

重要な洞察は、操作が予測可能な方法で操作を伝播することを観察することです。 のために`a`、ゼロは 2 つの 1 の間にある場合にのみ 1 になります。`b`。 同様に、`b`のゼロ間で生成できます`a`。 ただし、1 と 0 の相対的な順序は重要です。1 は交互のパターンで伝播する可能性があります。 この問題は、貪欲な戦略に還元できます。つまり、各連続セグメントは、`0`にいる`a`潜在的に次のように反転することができます`1`もし`b`対応するものが正しい位置にあります。 伝播パターンを分析した後、1 の最大数がわかります。`a`特定のクエリの場合、部分文字列の長さから、連続するゼロのセグメントの数を引いたものになります。`a`のものから隔離されているもの`b`。 これにより、1 と 0 のプレフィックスの合計を前処理できるようになります。`s`そして`t`O(1) 内の任意のクエリに対する答えを計算します。

 ## アルゴリズムのチュートリアル

 1. 文字列ごとに`s`そして`t`、プレフィックス合計配列を計算します`ones_s`そして`ones_t`、 どこ`ones_s[i]`1の数を格納します`s[0..i-1]`そして`ones_t[i]`に対しても同じことをします`t`。 これにより、任意の部分文字列内の 1 の数をすばやく計算できます。 
2. クエリごとに`[l, r]`、部分文字列内の 1 の数を抽出します。`a = s[l-1..r-1]`プレフィックスの合計を使用します。 
3. ゼロの数を数えます`a`。 各ゼロが「到達可能」であれば、潜在的に 1 になる可能性があることに注意してください。`b`。 操作にはゼロインが必要なので、`a`距離 2 にゼロを付けて反転します`b`、およびその逆、それぞれの連続するゼロのセグメント`a`に 1 が入っています`b`手の届く範囲で反転することができます。 
4. のプレフィックスの合計を使用する`b`、ゼロが入っているかどうかを確認できます`a`に少なくとも 1 つあるかどうかを確認することで反転可能です。`b`機械を通して伝播する可能性のある位置にあります。 実際には、対称パターンにより、これは部分文字列内の 1 の総数に減ります。`b`。 
5. 各クエリの最終的な答えは、次の 1 の合計数です。`a`にゼロの数を加えたもの`a`それはひっくり返すことができます。 ほとんどの場合、ゼロで区切られたものを除くすべてのゼロを数えることが単純化されます。`b`。 
6. クエリごとに計算された数値を出力します。 

機能する理由: この操作は、1 つのインデックスで区切られた位置を介してのみ値を伝播します。 ポジションを反転可能にすると、他の反転可能なポジションとは独立して更新できます。 したがって、1 と到達可能な 0 を数えることによって、考えられるすべての反転を捕捉し、1 の最大数を保証します。`a`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        b = input().strip()
        q = int(input())
        prefix_s = [0]*(n+1)
        prefix_b = [0]*(n+1)
        for i in range(n):
            prefix_s[i+1] = prefix_s[i] + (s[i] == '1')
            prefix_b[i+1] = prefix_b[i] + (b[i] == '1')
        for _ in range(q):
            l, r = map(int, input().split())
            ones_a = prefix_s[r] - prefix_s[l-1]
            zeros_a = (r - l + 1) - ones_a
            ones_b = prefix_b[r] - prefix_b[l-1]
            # maximum ones in a: existing ones plus zeros that can be flipped if there is at least one one in b
            max_ones = ones_a + min(zeros_a, ones_b)
            print(max_ones)

if __name__ == "__main__":
    main()
```コードはまず、プレフィックスの 1 の合計を事前計算します。`s`そして`b`定数時間の範囲クエリを許可します。 クエリごとに、既存のクエリをカウントします。`a`そしてゼロの数。 各 0 は、対応する部分文字列に 1 が少なくとも 1 つある場合にのみ 1 になります。`b`それを広めるために。 最小のゼロを取り込むことで、`a`そして中のもの`b`、過剰カウントがないことを保証します。 ゼロまたは 1 が含まれない部分文字列などのエッジ ケース`b`によって自動的に処理されます。`min`関数。
