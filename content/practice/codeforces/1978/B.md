 ## 解決策
 ## 問題の理解

 この問題では、ボブは特別プロモーションを使用してパンを販売することで利益を最大化しようとしています。 彼は持っています`n`販売するパン、通常の価格`a`各パンとプロモーションパラメータ`b`。 プロモーションにより、整数を選択できるようになります`k`そして最初のものを売ります`k`バンズの価格が～から下落`b`まで`b - k + 1`。 パンが余った場合は通常価格で販売します`a`。 課題は、最適な方法を選択することによってボブが得られる最大の総利益を決定することです。`k`。 

入力は複数のテスト ケースで構成されます。 各テスト ケースが提供するのは、`n`、`a`、 そして`b`。 出力は各ケースの最大利益です。 以来`n`、`a`、 そして`b`と同じ大きさにすることができます`10^9`まであります`10^4`テストケースでは、個々のパンを反復処理するソリューションは遅すぎます。 制限時間内に収まるように、テスト ケースごとに定数時間の式が必要です。 

次の場合、微妙なエッジケースが発生します。`b`～に比べて非常に小さい、または非常に大きい`a`そして`n`。 たとえば、次の場合`b <= a`、プロモーション価格でバンズを販売しても利益は増加しません。 逆に、もし`b`規模が大きいため、プロモーションで許可される限り多くのパンを販売するのが最適である可能性があります。 すべての値を試す素朴な解決策`k`タイムアウトになるため、直接計算する必要があります。 

## アプローチ

 素朴なアプローチが繰り返される`k`0から`min(n, b)`、最初の合計を計算します。`k`価格を下げる、追加する`(n - k) * a`、最大値を追跡します。 これは正しいですが、最大で`10^9`最悪の場合、テスト ケースごとに操作が行われますが、これは実行不可能です。 

最適なアプローチは、総利益関数が次の点で関数になるという観察から得られます。`k`二次で凹です。 の利益`k`プロモーション価格で販売されているバンズは、`sum_{i=1}^k (b - i + 1) = k * b - k*(k-1)/2`。 残ったパンは`(n - k) * a`。 これらを組み合わせると、合計利益関数は次のようになります。`profit(k) = k*b - k*(k-1)/2 + (n - k)*a`。 これは凹二次関数です。`k`したがって、最大値は境界または頂点で発生します。 頂点は次のとおりです`k = b - a`、 しかし`k`に限定されています`[0, min(n, b)]`。 したがって、最適な`k`は`max(0, min(b - a, min(n, b)))`。 

これにより、問題はループなしでテスト ケースごとに 1 回の計算に減ります。 算術式は一定時間で直接評価できます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`a`、 そして`b`。 
3. 販促用パンの候補数を計算する`k`として`b - a`。 これは、二次利益関数を微分することから得られます。 それは制約のない最適値です。 
4. クランプ`k`実現可能な範囲まで`[0, min(n, b)]`使用して`max(0, min(k, min(n, b)))`。 
5.最初の利益から計算します`k`減少する価格の合計としてのバンズ:`k * b - k * (k - 1) // 2`。 
6. 残りから利益を計算します。`n - k`パンは定価で`a`:`(n - k) * a`。 
7. 2 つのコンポーネントを加算して合計利益を取得します。 
8. 合計利益を出力します。 

なぜ機能するのか: という観点からの利益関数`k`は凹二次関数であるため、最大値は頂点または境界のいずれかで発生します。 クランピング`k`バンズの数とプロモーションの制限を確実に遵守します。 数式を使用して合計を計算すると、ループが回避され、テスト ケースごとに O(1) の計算が確実に行われます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    results = []

    for _ in range(t):
        n, a, b = map(int, input().split())
        k = b - a
        k = max(0, min(k, n, b))
        profit = k * b - k * (k - 1) // 2 + (n - k) * a
        results.append(str(profit))

    sys.stdout.write("\n".join(results) + "\n")

solve()
```### 説明

 コードは、次を使用してすべてのテスト ケースを効率的に読み取ります。`sys.stdin.readline`。 ケースごとに、導出された式を使用して販促用のパンの最適な数を計算します。 クランプにより確実に`k`すべての制約を尊重します。 最初の合計`k`価格の減少は等差級数の公式を使用して計算されます。 残ったパンは通常の価格に掛けられます。 結果は効率的に収集され、最後に印刷されます。

 ## 特殊なケース

 いつ`b <= a`、計算された`k`マイナスになる。 ゼロにクランプすると、プロモーションでバンズが販売されなくなります。これが最適です。 例えば、`n=10, a=10, b=5`結果として`k = max(0, min(-5, 10, 5)) = 0`。 利益は`10*10 = 100`、期待される結果と一致します。 同様に、`b`を超える`n`、クランプにより確実に`k <= n`バンズの数を超えないようにするためです。 これにより、すべての境界条件の正確さが保証されます。
