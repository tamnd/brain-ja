 ## 解決策
 ## 問題の理解

 この問題では、次のシーケンスが与えられます。`n`カードを一列に並べたもの。 各カードには 0 または 1 のいずれかを示す面があります。許可される唯一の操作は、カードの連続したセグメントを選択し、そのセグメント内のすべてのカードを裏返すことです (0 が 1、1 が 0 になります)。 私たちの目標は、元のシーケンスをすべてのカードが 1 を示すシーケンスに変換することです。これを達成するために必要な操作の最小数を決定する必要があります。 

入力は整数で構成されます`n`続いて長さの文字列が続きます`n`カードの面を表します。 出力は単一の整数、つまり最小の反転数です。 

という制約を考えると、`n`最大 10^5 で、制限時間は標準 (通常 1 ～ 2 秒) であるため、最悪の場合でもおよそ 10^8 の操作が実行されることが予想されます。 セグメントの数は n(n+1)/2 として二次関数的に増加するため、これにより、考えられるすべての連続セグメントを明示的に試行するアルゴリズムは除外されます。 

明らかではないエッジ ケースには、0 と 1 が交互に存在するシーケンス、すべてのカードがすでに 1 であるシーケンス、すべてのカードが 0 であるシーケンスが含まれます。`1010`、一度に 0 を 1 つずつ反転する単純なアプローチには 4 つの操作が必要になる可能性がありますが、2 つの操作のみを使用する一連の反転が存在します。`1-1`そして`3-3`。 すべてのカードがすでに 1 の場合、答えは 0 です。すべてのカードが 0 の場合、配列全体を 1 回連続して反転するだけで十分で、1 回の演算が行われます。 不注意な実装では、各 0 を個別に反転することで演算を過剰にカウントすることがよくあります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。すべての連続セグメントを反復して反転し、結果のシーケンスをすべて 1 に到達するまで再帰的にチェックします。 これが機能するのは、任意のセグメントの反転が許可されており、最終的にシーケンスがすべて 1 に変換されるためです。 ただし、連続するセグメントの数は n(n+1)/2 であり、すべての可能な組み合わせをチェックすることは n では指数関数的であり、n=10^5 ではまったく実行不可能です。 

重要な観察は、個々のフリップを明示的に追跡する必要がないということです。 それぞれの反転は、0 を 1 にどのように変更するかという点のみが重要です。 シーケンスを左から右にスキャンして、連続する 0 のセグメントの数を数えます。 このような各セグメントには少なくとも 1 つの反転が必要であり、1 を含む大きなセグメントを反転すると操作数が減らずに不必要に複雑さが増すため、1 回の操作で反転するのが最適です。 したがって、フリップの最小数は、連続する 0 セグメントの数に等しくなります。 

ブルートフォースは最終的にすべて 1 のシーケンスに到達するため機能しますが、指数関数的な複雑さのために失敗します。 連続する 0 を一緒に反転できるという観察により、問題は配列の 1 回のパスに縮小され、O(n) の解が得られます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`flips`これには、必要な操作の数が保存されます。 
2. インデックスを初期化する`i`0 にすると、左端のカードからスキャンを開始します。 
3. その間`i`未満です`n`、現在のカードを確認します。 

ａ． 1の場合はインクリメントします`i`反転する必要はないので続行します。 

b. 0の場合はインクリメントします`flips`1 ずつ移動し、連続する 0 をすべてスキップします。`i`1 またはシーケンスの終わりに達するまで前進します。 これにより、0 の各セグメントが正確に 1 回カウントされるようになります。 
4. シーケンスの終わりに達したら、出力します。`flips`。 

機能する理由: 不変条件は、0 のすべての連続セグメントが 1 回だけカウントされるということです。 そのセグメントを反転すると、1 回の操作ですべての 0 が 1 に変わりますが、セグメントを超えて反転すると、すでに正しい 1 に不必要に影響を及ぼします。 左から右にスキャンしてセグメントを数えることで、フリップの最小数が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_flips_to_all_ones(cards: str) -> int:
    n = len(cards)
    flips = 0
    i = 0
    while i < n:
        if cards[i] == '1':
            i += 1
        else:
            flips += 1
            while i < n and cards[i] == '0':
                i += 1
    return flips

def main():
    n = int(input())
    cards = input().strip()
    print(min_flips_to_all_ones(cards))

if __name__ == "__main__":
    main()
```機能`min_flips_to_all_ones`シーケンスの単一の線形スキャンを実行します。 内側の while ループにより、連続する 0 が単一のセグメントとして扱われるようになります。 使用する`strip()`入力時に非表示の改行文字がインデックス作成に干渉するのを防ぎます。

 ## 特殊なケース

 交互パターンの場合`010101`を使用すると、アルゴリズムは孤立した各ゼロを個別のセグメントとして正確にカウントします。 インデックス 0 から開始して 1 をスキップし、インデックス 1 で 0 のフリップをカウントし、インデックス 2 (1) にスキップし、インデックス 3 (0) でフリップをカウントし、インデックス 5 (0) でフリップをカウントし、正確に 3 つのフリップを生成します。 これは可能な最小限の操作と一致します。 

オール 1 シーケンスの場合、アルゴリズムはすべてのカードをスキップし、インクリメントしません。`flips`、0 が生成されますが、これは正しいです。 シングルカードシーケンスの場合、0 と 1 の両方を正しく処理し、必要な場合にのみ反転します。
