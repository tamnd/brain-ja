 ## 解決策
 ## 問題の理解

 長さ (n) の文字列が 2 つあります。 文字列 (s) はボックスの現在のスタックを表し、(t) は前のスタックを表します。 (s) を循環的に左にいくらか (k) 回転させてから、すべての文字に同じシーザー シフトを適用することができます。 タスクは、(s) を (t) に変換する任意のペア ((k,d)) を見つけるか、そのようなペアが存在しないことを報告することです。 

(k) による回転の場合、位置 (i) の結果の文字は (s[(i+k)\bmod n]) になります。 シーザー シフトによってすべての文字が (d) だけ後方に移動する場合、必要な等式は次のようになります。 

[
 t_i \equiv s_{(i+k)\bmod n}-d \pmod{26}。 
】

 長さは (200,000) に達する可能性があり、公式の制限は 2 秒および 512 MB です。 (O(n^2)) アルゴリズムは、最悪の場合でも約 (4\cdot10^{10}) 個の文字比較を実行できますが、これは制限時間内に収まる量をはるかに超えています。 (O(n)) または (O(n\log n)) の解が必要ですが、線形文字列マッチング アルゴリズムで十分です。 

直接実装すると誤解を招く可能性のあるいくつかの特殊なケースがあります。 (n=1) の場合、可能な回転は (k=0) のみですが、シーザー シフトによって任意の 2 つの文字を相互に変換できます。 例えば、```
1
z
a
```次のような有効な答えがあります`Success`に続く`0 25`。 隣接する文字を比較するメソッドは、1 文字の文字列には通常の隣接するペアがないため、まったく情報がないように見えます。 

2 番目のエッジ ケースは、文字列の端を横切る回転です。 例えば、```
5
abcde
cdeab
```答えがあります`Success`と`3 0`。 正しい回転は、最初の 3 文字が一番下に移動されることです。 文字列を循環的に処理するのではなく、(s) の通常の部分文字列のみをチェックする実装では、この答えが得られません。 

文字が繰り返されると、別の微妙なケースが作成されます。 のために```
4
aaaa
zzzz
```すべての回転は有効であり、単一のシーザー シフトで十分です。 ソリューションでは、一致する回転が一意であると想定してはなりません。 

最後に、文字列は同じ文字頻度を持つことができますが、依然として変換は不可能です。 例えば、```
3
abc
aba
```不可能です。 どちらの文字列にも 3 つの小文字が含まれていますが、循環ローテーションはありません。`aba`なることができる`abc`1回の均一なシフトの後。 文字数のみを比較すると、これが誤って認識されてしまいます。 

## アプローチ

 直接的なアプローチは、すべての回転 (k) を試すことです。 ローテーションごとに、構築または概念的に検査します

 [
 s[k],s[k+1],\ldots,s[n-1],s[0],\ldots,s[k-1]。 
】

 最初の文字は、唯一可能なシーザー シフトを決定します。 そのシフトがわかったら、残りのすべての文字を (t) の対応する文字と比較します。 これは正しいです。固定回転の場合、最初の文字を等しくできるシーザー シフトは最大でも 1 つしかないからです。 

問題は比較の回数です。 最悪の場合、(n) 回の回転と各回転ごとの (n) 個の文字チェックがあり、(O(n^2)) 時間がかかります。 (n=200,000) の場合、約 400 億回の比較になります。 

有益な観察は、シーザー シフトではすべての文字が同じ量だけ変更されるため、連続する文字間の違いは変わらないということです。 すべての巡回隣接差分を次のようにエンコードします。 

[
 D_i=(x_{i+1}-x_i)\bmod 26、
 】

 ここで (x_n=x_0)。 たとえば、次のような違いがあります。`abc`いる

 [
 [1,1,24]、
 】

 なぜなら`c`に`a`は (0-2\equiv24\pmod{26}) です。 

(s) の回転バージョンがシーザー シフト後に (t) になると仮定します。 回転された (s) 内のすべての隣接する差は、(t) 内の対応する隣接する差と等しくなければなりません。 (s) の回転は、その差分配列を同じ量だけ回転させるだけです。 したがって、元の問題は標準的な巡回文字列マッチング問題になります。つまり、(s) の差分配列の 2 つの連続するコピー内で (t) の差分配列を見つけます。 

この観察は別の方向にも当てはまります。 差分配列が何らかの回転の下で一致する場合、連続するすべてのペアは 2 つの文字列内で同じ量だけ異なります。 1 つの文字から開始して、その定数オフセットが文字列全体に伝播するため、単一のシーザー シフトが存在します。 

Knuth-Morris-Pratt アルゴリズムを使用して、必要な回転を見つけることができます。 KMP は、すべての回転を個別にチェックすることなく、線形時間で (D_s+D_s) 内のパターン (D_t) を見つけます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n^2)) | (O(n)) | 遅すぎる |
 | 差分配列 + KMP | (O(n)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (s) と (t) のすべての文字を (0) ～ (25) の整数に変換します。 巡回差分配列を構築します。 文字列 (x) の場合、位置 (i) には ((x[(i+1)\bmod n]-x[i])\bmod26) が格納されます。 回転によって最後の位置と最初の位置の間のエッジも保存されるため、循環的な最後から最初への差が必要になります。 
2. (A) を (s) の差分配列、(B) を (t) の差分配列とする。 (s) × (k) の左回転は、(A) を正確に (k) 位置だけ左に回転します。 したがって、(A+A) のある位置 (k) から始まる長さ (n) のセグメントとして (B) を見つける必要があります。 
3. (B) の KMP プレフィックス関数を構築します。 プレフィックス関数は、不一致が発生した後もパターンのどの程度がまだ使用可能であるかを示し、検索を最初からやり直す代わりに比較をスキップできるようにします。 
4. (A) の 2 つのコピーに対して KMP を実行します。 (B) の完全な出現が位置 (k<n) で開始されるたびに、すべての周期的な差分を保存する回転が見つかりました。 最初のそのような出来事が発生した時点で停止できます。 
5. (k) がわかったら、回転された (s) の最初の文字 (s[k]) を (t[0]) と比較します。 シーザー変換は文字を(d)だけ後ろに移動させるので、

 [
 t_0\equiv s_k-d\pmod{26}、
 】

 それで

 [
 d\equiv s_k-t_0\pmod{26}。 
】

 (0) ～ (25) から代表を選択すると、常に必要な範囲 (-26<d<26) を満たします。 

1. KMP が最初の (n) 位置で始まる出現を検出しなかった場合、必要な循環差分を備えた回転は存在しないため、有効な変換は存在しません。 

### なぜ効果があるのか

 不変条件は、一様なシーザー シフトでは、すべての巡回隣接差分が変更されないことです。 したがって、有効な変換は、(t) の差分配列が (s) の差分配列の回転であることを意味するため、KMP はそれを見つける必要があります。 

逆に、KMP が 2 つの差分配列が同一となる回転 (k) を見つけたとします。 次に、連続するすべてのペアについて、回転された (s) と (t) の差は同じモジュロ (26) になります。 したがって、対応するすべての文字は 1 つの定数値だけ異なります。 その定数は正確に最初の文字から計算されたシーザー シフト (d) であるため、回転 (k) を適用すると、そのシフトは (s) を (t) に変換します。 

ケース (n=1) も同じ推論から導き出されます。 両方の差分配列には単一の値 (0) が含まれているため、KMP は唯一の可能な回転を見つけ、最初の文字の計算によって必要なシーザー シフトが提供されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def differences(s):
    n = len(s)
    a = [ord(c) - 97 for c in s]
    return [(a[(i + 1) % n] - a[i]) % 26 for i in range(n)], a

def prefix_function(p):
    pi = [0] * len(p)
    for i in range(1, len(p)):
        j = pi[i - 1]
        while j > 0 and p[i] != p[j]:
            j = pi[j - 1]
        if p[i] == p[j]:
            j += 1
        pi[i] = j
    return pi

def solve():
    n = int(input())
    t = input().strip()
    s = input().strip()

    dt, tv = differences(t)
    ds, sv = differences(s)

    pi = prefix_function(dt)

    j = 0
    rotation = -1

    # We only need starts from 0 through n - 1.
    # Two copies of ds contain every cyclic rotation.
    for i in range(2 * n):
        value = ds[i % n]

        while j > 0 and value != dt[j]:
            j = pi[j - 1]

        if value == dt[j]:
            j += 1

        if j == n:
            start = i - n + 1
            if start < n:
                rotation = start
                break
            j = pi[j - 1]

    if rotation == -1:
        print("Impossible")
        return

    # t[0] = s[rotation] - d (mod 26)
    d = (sv[rotation] - tv[0]) % 26

    print("Success")
    print(rotation, d)

if __name__ == "__main__":
    solve()
```の`differences`この関数は文字を (0) から (25) までの値に変換し、すべての循環差分を計算します。 表現`(i + 1) % n`(n=1) の場合を含め、最後のエッジを最初の文字に戻して処理します。 

プレフィックス関数は標準の KMP 前処理です。 そのインデックスは常にパターン内にあり、`while`ループは、以前に計算されたプレフィックス長を繰り返しフォールバックします。 すべてのフォールバックが移動するため、`j`値を小さくしても、総仕事量は線形のままです。 

検索は次のように繰り返されます`2 * n`ポジションとアクセス`ds[i % n]`これは、別のリストを割り当てずに巡回差分配列の 2 つのコピーを表します。 から始まる試合`start`によって左に回転することに正確に対応します`start`。 の`start < n`この条件は、最初の (n) 位置の後に始まる重複した出現を拒否します。 

シーザー シフトは、有効な回転が見つかった後にのみ計算されます。 私たちが使用するのは`(sv[rotation] - tv[0]) % 26`変換は後方シフトであるためです。 結果の値は (0,\ldots,25) にあり、許可された出力範囲内にあります。 Python の整数はオーバーフローしないため、特別な算術処理は必要ありません。

## テストケース

 以下のテスト ハーネスでは、問題では有効な変換が明示的に許可されているため、成功した回答を 1 つの固定ペア ((k,d)) と比較しません。 代わりに、報告されたペアが範囲内にあることを確認し、実際に (s) を (t) に変換します。 あり得ないケースも正確に比較されます。```python
import sys
import io

def solve_case(inp: str) -> str:
    old_stdin = sys.stdin
    sys.stdin = io.StringIO(inp)

    n = int(sys.stdin.readline())
    t = sys.stdin.readline().strip()
    s = sys.stdin.readline().strip()

    def differences(x):
        values = [ord(c) - 97 for c in x]
        return [
            (values[(i + 1) % n] - values[i]) % 26
            for i in range(n)
        ], values

    def prefix_function(p):
        pi = [0] * len(p)
        for i in range(1, len(p)):
            j = pi[i - 1]
            while j > 0 and p[i] != p[j]:
                j = pi[j - 1]
            if p[i] == p[j]:
                j += 1
            pi[i] = j
        return pi

    dt, tv = differences(t)
    ds, sv = differences(s)

    pi = prefix_function(dt)

    j = 0
    rotation = -1

    for i in range(2 * n):
        value = ds[i % n]

        while j > 0 and value != dt[j]:
            j = pi[j - 1]

        if value == dt[j]:
            j += 1

        if j == n:
            start = i - n + 1
            if start < n:
                rotation = start
                break
            j = pi[j - 1]

    if rotation == -1:
        result = "Impossible\n"
    else:
        d = (sv[rotation] - tv[0]) % 26
        result = f"Success\n{rotation} {d}\n"

    sys.stdin = old_stdin
    return result

def is_valid(inp: str, out: str) -> bool:
    lines = inp.strip().splitlines()
    n = int(lines[0])
    t = lines[1]
    s = lines[2]

    out_lines = out.strip().splitlines()

    if out_lines[0] == "Impossible":
        return False

    assert out_lines[0] == "Success"
    k, d = map(int, out_lines[1].split())

    assert 0 <= k < n
    assert -26 < d < 26

    for i in range(n):
        source = ord(s[(i + k) % n]) - 97
        target = (source - d) % 26
        if target != ord(t[i]) - 97:
            return False

    return True

# Provided samples.
sample1 = """3
abc
fde
"""
assert is_valid(sample1, solve_case(sample1)), "sample 1"

sample2 = """3
abc
aba
"""
assert solve_case(sample2).strip() == "Impossible", "sample 2"

sample3 = """1
z
a
"""
assert is_valid(sample3, solve_case(sample3)), "sample 3"

# Minimum size, where the difference arrays contain only zero.
case1 = """1
a
z
"""
assert is_valid(case1, solve_case(case1)), "minimum size"

# Rotation crosses the end of the string.
case2 = """5
abcde
cdeab
"""
assert is_valid(case2, solve_case(case2)), "wrap-around rotation"

# All characters are equal, and n is at the maximum allowed size.
n = 200000
case3 = f"{n}\n" + "a" * n + "\n" + "z" * n + "\n"
assert is_valid(case3, solve_case(case3)), "maximum size and all equal"

# Almost matching strings, designed to reject a wrong rotation.
case4 = """4
abca
caab
"""
assert solve_case(case4).strip() == "Impossible", "invalid rotation"

print("All tests passed.")
