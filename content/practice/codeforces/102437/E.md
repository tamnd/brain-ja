 ## 問題の理解

 У нас есть две строки длины`n`。 Строка`s`описывает текущую стопку коробок сверху вниз, а`t`описывает предыдущую стопку。 Разрезено выполнить над`s`две операции с общими параметрами: циклически сдвинуть все буквы на одну и ту же величину по алфавиту и Іиклически повернуть саму строку. Нужно определить, можно ли получить ровно`t`、и если можно、вывести величину поворота`k`и величину сдвига`d`。 

Поворот на`k`означает、что первые`k`さいふ`s`Серемещаются в конец. Например、`abcdef`やっぱ`k = 2`ありがとうございます`cdefab`。 После этого каждый символ дополнительно сдвигается назад на`d`Іиклическому алфавиту です。 Если`d = 3`、、`f`ありがとうございます`c`。 

При`n`до`200000`ありがとうございます`n`возможных поворотов и для каждого сравнить все`n`ありがとうございます。 В худбуем случае это потребует порядка`n² = 4 * 10^10`сравнений、что слиском много для обычного лимита времени。 Нам нужен линейный или близкий к линейному алгоритм.

 Есть несколько краевых случаев, на которых легко осибиться. Первый связан с циклическим переходом между последним и первым символом. Например, ドイツ```

## アプローチ

 Самый прямой способ перебрать все варианты поворота. Для каждого`k`必要があります`s[k:] + s[:k]`。 Затем пытаемся подобрать один общий сдвиг`d`。 Если первый символ после поворота должен перейти в`t[0]`、 、`d`же определяется однозначно. После этого остаётся проверить все остальные позиции.

 Такой алгоритм корректен, потому что для фиксированного поворота значение`d`действительно определяется первым символом, а затем вся строка проверяется непосредственно. Но для каждого из`n`поворотов мы можем просмотреть`n`そうですね。 В худвем случае это`n²`операций、то есть около`4 * 10^10`やっぱ`n = 200000`。 Такой подход слизком медленный。 

Нужно воспользоваться тем, что Caesar-сдвиг одинаков для всех символов. Рассмотрим не сами символы, а разности между соседними символами по модулю`26`。 

ロシア語`abcde`Ѝти разности равны`1, 1, 1, 1`。 Если каждый символ сдвинуть на одно и то же значение, например превратить строку в`defgh`、 разности останутся`1, 1, 1, 1`。 シーザーは、最高のパフォーマンスを発揮します。 

Нужно также учитывать циклическую структуру。 ロシア語`abcd`最高の結果をもたらします`b - a`、`c - b`、`d - c`、`a - d`。 

Получается массив из ровно`n`Сазностей、последняя из которых соединяет конец строки с её началом。 

Теперь исходная задача превращается в более простую. Нужно найти такое циклическое положение массива разностей`s`、 которое совпадает с массивом разностей`t`。 Если такое положение найдено, исходные строки отличаются только одним глобальным Caesar-сдвигом. Этот сдвиг затем легко восстанавливается по одному символу.

 Осталось быстро найти один массив внутри циклического массива другого. Стого построим`diff_s + diff_s`と найдём в нём`diff_t`Кнута、Морриса、Пратта。 Любое совпадение, начинающееся в позиции от`0`до`n - 1`、соответствует некоторому циклическому повороту`s`。 

Таким образом, задача о двух параметрах, повороте и Caesar-сдвиге, сначала сводится к задаче о совпадении Іиклических массивов разностей、а затем один параметр восстанавливается напрямую.

 ## アルゴリズムのチュートリアル

 1. Представим каждую букву числом от`0`до`25`。 ロシア語`x`Іиклический массив разностей`diff_x`、、```
diff_x[i] = (x[(i + 1) mod n] - x[i]) mod 26.
```Так мы сохраняем относительное расположение букв, но полностью убираем общий Caesar-сдвиг.

 1. Построим`diff_s + diff_s`。 Вторая копия нужна потому, что любой циклический поворот`diff_s`теперь появляется как обычный непрерывный отрезок этой удвоенной последовательности.
 2. Найдём`diff_t`ヴンヌル`diff_s + diff_s`KMP です。 Если первое совпадение начинается в позиции`k < n`、 то именно`k`является нужным поворотом исходной строки`s`。 
3. Если совпадения нет, выведем`Impossible`。 Отсутствие совпадения означает, что никакой поворот не может сделать циклические разности двух строк одинаковыми, а значит никакой общий Caesar-сдвиг уже не поможет.
 4. Если совпадение найдено, вычислим значение`d`そうです。 После поворота символ на позиции`0`パービューン`s[k]`。 Нам нужно получить`t[0]`、 、```
s[k] - d ≡ t[0] (mod 26),
```откуда```
d ≡ s[k] - t[0] (mod 26).
```Можно вывести остаток от`0`до`25`、 потому что весь этот диапазон удовлетворяет условию`-26 < d < 26`。 

1. ロシア`n = 1`最高です。 KMP также корректно обработает этот случай, но отдельно рассматривать его не требуется. Найденный поворот будет`k = 0`、あー`d`Сосстановится из единственной пары символов.

 Почему это работает: Caesar-сдвиг прибавляет одну и ту же величину ко всем символам, поэтому при вычитании соседних символов эта величина сокращается。 Следовательно, если некоторое преобразование переводит`s`×`t`、их циклические массивы разностей обязательно совпадают после соответствующего поворота. Обратно, если два таких массива разностей совпадают, то после выбранного поворота разность между Пответствующими символами`s`や`t`одинакова на каждой позиции. Значит, существует один общий Caesar-сдвиг, переводящий всю повернутую`s`×`t`。 Алгоритм находит ровно такие повороты и затем восстанавливает этот общий сдвиг по первой позиции.

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_diff(s):
    n = len(s)
    a = [ord(c) - ord('a') for c in s]
    return [(a[(i + 1) % n] - a[i]) % 26 for i in range(n)]

def kmp_search(pattern, text, limit):
    m = len(pattern)

    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pattern[i] != pattern[j]:
            j = pi[j - 1]
        if pattern[i] == pattern[j]:
            j += 1
        pi[i] = j

    j = 0
    for i, value in enumerate(text):
        while j > 0 and value != pattern[j]:
            j = pi[j - 1]

        if value == pattern[j]:
            j += 1

        if j == m:
            start = i - m + 1
            if start < limit:
                return start
            j = pi[j - 1]

    return -1

def solve():
    n = int(input())
    t = input().strip()
    s = input().strip()

    diff_t = build_diff(t)
    diff_s = build_diff(s)

    text = diff_s + diff_s
    k = kmp_search(diff_t, text, n)

    if k == -1:
        return "Impossible\n"

    s_first = ord(s[k]) - ord('a')
    t_first = ord(t[0]) - ord('a')

    d = (s_first - t_first) % 26

    return f"Success\n{k} {d}\n"

if __name__ == "__main__":
    sys.stdout.write(solve())
```

`build_diff`Ликлические разности をご覧ください。 Индекс`(i + 1) % n`最高のサービス、最高のサービス、最高のサービスを提供します。 Это необходимо для корректного определения циклического поворота.

 В`kmp_search`сначала строится префиксная функция для`diff_t`。 Затем саблон ищется в удвоенном`diff_s`。 Параметр`limit = n`最高のパフォーマンス、最高のパフォーマンスを実現します。`n`Мозже、поскольку такие позиции не соответствуют различным поворотам исходной строки.

 После совпадения значение`k`же является индексом первого символа повернутой строки. Формула для`d`использует именно`s[k]`、あーん`s[0]`。 Это частая причина обки на задаче: поворот выполняется до Caesar-сдвига, поэтому первым символом после поворота Сляется`s[k]`。 

Вычисления выполняются по модулю`26`、 поэтому переходы вроде`z -> a`обрабатываются обычным остатком。 Python は、Python を使用して、さまざまな機能を実行します。
