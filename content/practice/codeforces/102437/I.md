 ## 解決策
 ## 問題の理解

 最初は空の (n \times m) グリッドがあります。 移動は、すべてのセルがまだ空であり、面積が最大 (s) である軸に整列した長方形を選択し、その長方形のすべてのセルを構築済みとしてマークすることで構成されます。 プレイヤーは交互に手を動かし、最後の正当な手を行ったプレイヤーが勝ちます。 

タスクは、最初のプレイヤーであるサムが勝利する戦略を持っているかどうかを判断することだけです。 動きを組み立てる必要はありません。 制約とステートメントは、Codeforces の問題ページで提供されます。 

寸法は最大 (1000) であるため、ボード自体には最大 (10^6) 個のセルを含めることができます。 これにより、考えられるすべてのゲーム状態を明示的に維持するものは除外されます。 選択したセルは空の長方形を形成する必要があるため、このゲームは単にセルの数を選択するだけではありません。 ソリューションは、ゲームをシミュレートするのではなく、ボード全体の幾何学的対称性を利用する必要があります。 

最も有用なエッジ ケースは、まさにパリティによってボードの中心の形状が変化するケースです。 

のために```
1 4 1
```唯一可能な移動はエリア (1) であるため、すべての移動で 1 つのセルが構築されます。 セルは 4 つあるため、4 つの手が行われ、2 番目のプレーヤーが勝ちます。 正しい答えは、`NO`。 隣接するセルの存在がファースト プレイヤーの戦略に十分であるとみなす実装では、この点が誤ってしまいます。 

のために```
2 2 3
```ボードには 4 つのセルがありますが、許可される最大の長方形の面積は (3) です。 (180^\circ) 回転に関して対称な最小の長方形のサイズは (2 \times 2)、したがって面積は (4) になります。 このような長方形を占有する正当な手は存在しないため、2 番目のプレーヤーは回転対称を使用して勝ちます。 答えは、`NO`。 

のために```
2 3 2
```中心対称の最小の長方形は中央の列で、サイズ (2 \times 1) と面積 (2) を持ちます。 サムが最初にこの列を構築できます。 残りの 2 つの側面は互いに正確に回転するため、後のすべての動きをミラーリングできます。 答えは、`YES`。 

のために```
3 3 1
```中心は単一の細胞です。 サムは最初にそのセルを構築し、次に中央を通過するすべての敵の動きをミラーリングします。 答えは、`YES`。 このケースは、奇数の次元が最小の対称四角形に 1 つのセルだけを寄与する理由を示しています。 

## アプローチ

 直接的な解決策は、ポジションを一般的な公平なゲームとして扱うことになります。 現在の構築されたセルのセットから、最大でも領域の空の長方形をすべて列挙し、結果の位置を再帰的に解決し、少なくとも 1 つの手が負けの位置に到達した場合に、その位置が勝利であると宣言できます。 

すべての合法的な手が考慮され、ゲームは有限であるため、これは正しいです。 問題は州の数です。 (nm) 個のセルでは、最大 (2^{nm}) 個の異なるビルドセル構成が可能です。 すべての四角形を一定時間内にチェックできたとしても、(n \times m) 枚のボード内で可能な四角形の数は次のようになります。 

[
 \frac{n(n+1)m(m+1)}{4},
 ]

 したがって、徹底的なミニマックスアプローチには次のことが必要になります。 

[
 O\left(2^{nm} n^2m^2\right)
 ]

 最悪の場合は動作します。 (nm) が (10^6) に達すると、これはとうてい実現不可能です。 

ゲームはすでに構築されたセルのセットによって完全に決定されるため、総当り攻撃が機能しますが、その表現には最初の空の四角形に必要な情報よりもはるかに多くの情報が含まれています。 重要な観察は、ボードが自然な (180^\circ) 回転対称性を持っていることです。 

任意の長方形を取り、ボードの中心を中心に (180^\circ) 回転させます。 元の長方形とその回転されたコピーが互いに素である場合、一方のプレーヤーが元の長方形を構築した後、もう一方のプレーヤーがその回転されたコピーを構築できます。 回転によって形状と領域の両方が保存されるため、元のものが正当である限り、応答は常に正当な動きとなります。 

これにより、すべての正当な四角形がその回転されたコピーから切り離されるたびに、2 番目のプレーヤーに勝利戦略が与えられます。 長方形が (180^\circ) 回転と交差できる唯一の方法は、長方形が両方の次元でボードの中心を横切ることです。 

これにより、問題はすぐに、回転されたコピーと交差できる長方形の最小の領域を見つけることになります。 奇数次元の場合は、中央の 1 つの行または列で十分です。 偶数次元の場合、中心は 2 行または 2 列の間にあるため、少なくとも 2 行または 2 列が必要です。 

定義する

 [
 c(x)=
 \begin{ケース}
 1,&x\text{ は奇数です},\
 2,&x\text{ は偶数}。 
\end{ケース}
 ]

 中心対称の最小の長方形の寸法は (c(n)\time c(m)) であるため、その面積は次のようになります。 

[
 c(n)c(m)。 
]

 (s) がこの値より小さい場合、正当な手は両方向に中心を横切ることができません。 2 番目のプレーヤーはすべての動きを反映できるため、サムは負けます。 

(s) が少なくともこの値であれば、サムは最初の動きとして中心対称の長方形を作成できます。 それを削除した後は、回転によってセルが固定されないため、残っているすべての正当な長方形には、個別の互いに素な回転されたパートナーが含まれます。 その後、サムは敵のあらゆる動きを反映し、最後の動きをします。 

その結果、ゲーム全体が 1 つの比較に減ります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(2^{nm}n^2m^2)) | (O(2^{nm})) | 遅すぎる |
 | 最適 | (O(1)) | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ボードの垂直方向の中心を横切るために長方形が占有する必要がある最小行数を決定します。 (n)が奇数の場合は(1)、(n)が偶数の場合は(2)となります。 
2. 長方形が水平方向の中心を横切るために占有する必要がある最小列数を決定します。 (m)が奇数の場合は(1)、(m)が偶数の場合は(2)となります。 
3. これら 2 つの値を乗算します。 結果を呼び出します`need`。 これは、独自の (180^\circ) 回転を満たすことができる最小の長方形の面積です。 
4. と比較します`need`。 (s \geq \text{need}) の場合、サムは最初に中央の長方形を構築し、回転対称性によって勝ちます。 
5. (s < \text{need}) の場合、正当な最初の移動は回転されたコピーと交差できません。 2 番目のプレイヤーはすべての手を (180^\circ) だけ回転させ、常に別の正当な手を取得できるため、サムは負けます。 

### なぜ効果があるのか

 ボードの (180^\circ) 回転を考えてみましょう。 長方形は、その回転されたイメージと交差する場合にのみ、別の回転されたパートナーを持つことができません。 2 つの長方形が交差するには、元の長方形が両方の次元に沿ってボードの中心を横切る必要があります。 このような可能な最小の長方形には、対応する次元が奇数の場合は中央の 1 行があり、偶数の場合は中央の 2 行があり、列については同じ規則が適用されます。 したがって`need`は、回転ペアリングを妨げる可能性のある長方形のまさに最小の領域です。 

(s < \text{need}) の場合、すべての有効な四角形は回転された画像から切り離されます。 2 番目のプレーヤーが回転した四角形で応答した後、2 つの四角形は互いにつながっていないため、応答は既に構築されているものと重なり合うことはできません。 回転によって面積も維持されるため、応答は正当です。 サムのすべての動きは 1 つの応答と対になっており、サムは最後の動きをすることができません。 

(s \geq \text{need}) の場合、サムはまず中央の長方形を構築します。 これは回転下でも不変であるため、削除された後は、残りのすべてのセルが回転下の個別のセルのペアに属します。 それ以降の正当な長方形は、それ自体の回転されたイメージと交差することはできません。そのような長方形は、すでに占有されている中央領域に接触する必要があるからです。 その結果、サムはあらゆる敵の動きを反映し、最終的には最後の動きをすることができます。 

との比較`need`したがって、必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, s = map(int, input().split())

    need_n = 1 if n % 2 else 2
    need_m = 1 if m % 2 else 2

    need = need_n * need_m

    print("YES" if s >= need else "NO")

if __name__ == "__main__":
    solve()
```入力にはテスト ケースが 1 つだけ含まれているため、`solve()`3 つの整数を 1 回読み取ります。 価値観`need_n`そして`need_m`長方形がボードの中心を横切るために必要な行と列の最小数を表します。 

乗算により、(180^\circ) 回転に重なることができる長方形の最小面積が得られます。 (1) または (2) の中央の行と列が正の次元に対して常に存在するため、その四角形が物理的に適合するかどうかを確認する必要はありません。 

比較は包括的です。 いつ`s == need`、中央の長方形は正当であるため、答えは次のようになります。`YES`。 使用する`>`の代わりに`>=`(2\times3) with (s=2) など、境界が完全に一致するケースをすべて誤って拒否してしまいます。 

Python の整数は任意の精度を持ちますが、実際には大規模な算術演算は必要ありません。 関連する最大の値は (4) のみです。

```最初の次元は奇数であるため、中心に到達するには 1 行で十分です。 2 番目の次元は偶数であるため、2 つの列が必要です。 したがって、中心対称の最小の長方形の面積は (1\cdot2=2) になります。
