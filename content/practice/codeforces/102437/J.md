 ## 問題の理解

 ロボットは整数グリッド上を移動します。 2 つの固定回転中心があり、最初の回転中心は (0,0) にあり、2 番目の回転中心は (1,0) にあります。 各コマンドは、これら 2 つの中心のいずれかを中心に、現在位置を時計回りまたは反時計回りに正確に 90 °回転させます。 

4 つのコマンドは座標変換として直接記述することができます。 (0,0) 付近では、コマンド 1 と 2 が右回りと左回りの回転になります。 (1,0) 付近では、コマンド 3 と 4 が対応する回転です。 (x 1 ,y 1 ) から開始し、(x 2 ,y 2 ) に到達する必要があり、最大 10 6 個のコマンドを生成するか、ターゲットに到達できないことを報告します。 

すべての座標の絶対値は最大 100000 です。出力制限は座標範囲よりもはるかに大きいため、変位単位ごとに一定数の演算を使用する構築は容易に十分に高速になります。 私たちに許容できないのは、指数関数的な数のコマンド シーケンスを検索したり、大きな半径を持つ平面の 2 次サイズの領域を探索したりすることです。 

最初の明白ではない問題は到達可能性です。 許可されたすべての回転では、x+y のパリティが維持されます。 たとえば、(0,0) からどちらかの塔の周りを回転すると、座標の合計が偶数になる点が常に生成されます。 したがって、(0,0) は (1,0) に到達できません。これは、それらの合計のパリティが異なるためです。 座標の差が整数であるかどうかのみをチェックする不用意な構成では、このターゲットが到達可能であると誤って主張することになります。 

2 番目の問題は、2 つのタワーが任意の単位変換を直接生成しないことです。 有用な翻訳には斜めの方向があります。 たとえば、コマンド`23`コマンドを実行しながら、すべての点を (1,1) ずつ移動します。`14`すべての点を (1, −1) だけ移動します。 したがって、これら 2 つの変換の係数は整数でなければなりません。 これはまったく同じパリティ条件です。 

a(1,1)+b(1,−1)=(dx,dy)

 与える

 a= 2dx+dy 、b= 2dx−dy 。 

たとえば、入力```
0 0
1 0
```生産しなければならない`-1`座標和のパリティが異なるためです。 1 単位の移動によって x と y を独立して固定しようとする方法では、存在しない操作シーケンスが黙って構築されてしまいます。 

送信元と宛先は異なることが保証されます。 したがって、ゼロのコマンドを出力する必要はありません。 のようなケース```
5 5
5 -5
```両方の座標の合計が偶数であるため、 は有効であり、到達可能です。 また、両方の座標が変更される必要があると想定する実装も検出します。 

## アプローチ

 直接的な総当たりアプローチは、コマンド シーケンスを列挙し、ターゲットが見つかるまでロボットをシミュレートすることです。 これは、考えられるすべてのシーケンスが考慮されるため正しいですが、すぐに役に立たなくなります。 長さ k 以下のシーケンスをすべて列挙すると、シーケンスの数は次のようになります。 

1+4+4 2 +⋯+4 k = 3 4 k+1 −1 。 

許容限界 k=10 6 では、これは約 4 10 6 /3 となり、実行可能な計算をはるかに超えます。 数十のコマンドのシーケンスだけをチェックすることさえ、すでに非現実的です。 

多くの異なるコマンド シーケンスが同じ位置に到達できるため、位置をまたいだ BFS の方が優れています。 到達可能なコンポーネントは正しく検出されますが、それでも少数の状態の後に停止する理由はありません。 ターゲット座標は 100,000 単位離れている場合があるため、一般的なグリッド検索では、適切なパスを見つける前に膨大な領域を訪問する可能性があります。 

重要な点は、2 つのコマンドを組み合わせて純粋な変換を行うことができるということです。 コマンド 2 (0,0) を中心に反時計回りに回転し、続いてコマンド 3 (1,0) を中心に時計回りに回転します。 点 (x,y) について、コマンド 2 は次のようになります。 

(−y,x)、

 そしてコマンド 3 は次のようになります

 (1+x,1+y)。 

したがって`23`すべての点を正確に (1,1) で変換します。 

同様に、コマンド 1 の後にコマンド 4 を実行すると、次のようになります。 

(x,y)→(y,−x)→(x+1,y−1)、

 それで`14`すべての点を (1, −1) で変換します。 

4 つのコマンドが完全な遷移グラフを記述するため、総当り攻撃が機能します。 グラフが巨大なため失敗します。 2 つのコマンドの組み合わせが変換であるという観察により、グラフ検索を 2 変数線形方程式を解くことに置き換えることができます。 

しましょう

私たちが欲しいのは

 dx=a+b、dy=a−b、

 ここで、翻訳のコピー (1,1) と翻訳のコピー (1,−1) の b が使用されます。 これにより、

 a= 2dx+dy 、b= 2dx−dy 。 

dx と dy が同じパリティを持つ場合、これらの値は正確に整数になります。これは、開始点と終了点が x+y の同じパリティを持つのと同等です。 

負の係数は問題を引き起こしません。 の逆`23`は`41`、 それで`41`(−1,−1) によって変換されます。 の逆`14`は`32`、 それで`32`(−1,1) で変換されます。

 ## アルゴリズムのチュートリアル

 1. 変位を計算します

 dx=x 2 −x 1 、dy=y 2 −y 1 。 

問題全体は、2 つの対角線の平行移動を使用してこの変位を構築するものとみなすことができます。 
2. x 1 +y 1 と x 2 +y 2 が同じパリティを持つかどうかを確認します。 同様に、dx+dy と dx−dy の両方が偶数であるかどうかを確認します。 そうでない場合は出力`-1`。 

これは単に当社の建築物に特有のものではありません。 許可されたすべての回転では x+y のパリティが維持されるため、パリティが異なるということは、ターゲットが本当に到達不可能であることを意味します。 
3. コンピューティング

 a= 2dx+dy 、b= 2dx−dy 。 

値 a は、変換 (1,1) を適用する回数を示し、値 b は、変換 (1,−1) を適用する回数を示します。 
4. a>0 の場合、追加します。`23`ちょうど1回。 a<0 の場合は追加`41`ちょうど -a 回です。`23`(1,1) によって変換され、`41`はその逆なので、(−1,−1) によって変換されます。 
5. b>0の場合、追加`14`まさにb倍。 b<0の場合は追加`32`ちょうど -b 回です。`14`(1,−1) によって変換されますが、`32`その逆数 (−1,1) で変換します。 
6. 結果のコマンド文字列を出力します。 元の位置とターゲットの位置が異なるため、少なくとも 1 つの係数がゼロ以外であるため、コマンド数は正になります。 

### なぜ効果があるのか

 不変量は、生成されたコマンド プレフィックスによって表される変位です。 すべてのペア`23`すべてのペアで正確に (1,1) に寄与します`41`すべてのペアで正確に (−1, −1) に寄与します`14`正確に (1, −1) とすべてのペアに寄与します`32`正確に (−1,1) に寄与します。 選択された係数は次の条件を満たします

 a(1,1)+b(1,−1)=(dx,dy)、

 したがって、シーケンス全体を実行した後、ロボットは (x 1 ,y 1 ) から必要な変位だけ正確に移動し、(x 2 ,y 2 ) に到達します。 

パリティ テストが失敗した場合、個々の回転は x+y モジュロ 2 を保持するため、シーケンスは機能しません。したがって、アルゴリズムは到達不可能なケースを正確に拒否します。 

## Python ソリューション

 編集```python
import sys
input = sys.stdin.readline

def solve():
    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1

    # Every operation preserves (x + y) modulo 2.
    if ((x1 + y1) & 1) != ((x2 + y2) & 1):
        print(-1)
        return

    a = (dx + dy) // 2
    b = (dx - dy) // 2

    ans = []

    if a > 0:
        ans.append("23" * a)
    elif a < 0:
        ans.append("41" * (-a))

    if b > 0:
        ans.append("14" * b)
    elif b < 0:
        ans.append("32" * (-b))

    s = "".join(ans)

    print(len(s))
    print(s)

if __name__ == "__main__":
    solve()
```最初の部分では 2 つの位置を読み取り、問題を変位 (dx,dy) に変換します。 ディスプレイスメントを操作することは、個別のコマンドごとに現在の位置を操作するよりも簡単です。 

パリティ チェックは除算の前に行われます。 パリティが異なる場合、dx+dy は奇数になるため、必要な係数 a は整数になりません。 もっと根本的に言えば、目標は達成不可能であるため、建設を試みるべきではありません。 

の表現`a`そして`b`整数の除算は、パリティ条件によって両方の分子が偶数であることが確立された後にのみ使用してください。 Python の整数にも任意の精度がありますが、指定された境界は十分小さいため、他の言語では通常の固定幅の整数演算で十分です。 

各係数は、繰り返される 2 つのコマンドの変換に直接変換されます。 翻訳は交換されるため、2 つの翻訳ファミリー間の順序は重要ではありません。そのため、実装では、一方のタイプのすべてのコピーを発行し、その後にもう一方のタイプのすべてのコピーを発行できます。 

問題では実際のシーケンスが要求されるため、出力文字列は明示的に保存されます。 最大長は 400000 であるため、使用するのは数百キロバイトと通常の Python 文字列のオーバーヘッドだけです。

## テストケース

import sys
import io

def solve():
    input = sys.stdin.readline

    x1, y1 = map(int, input().split())
    x2, y2 = map(int, input().split())

    dx = x2 - x1
    dy = y2 - y1

    if ((x1 + y1) & 1) != ((x2 + y2) & 1):
        print(-1)
        return

    a = (dx + dy) // 2
    b = (dx - dy) // 2

    ans = []

    if a > 0:
        ans.append("23" * a)
    elif a < 0:
        ans.append("41" * (-a))

    if b > 0:
        ans.append("14" * b)
    elif b < 0:
        ans.append("32" * (-b))

    s = "".join(ans)
    print(len(s))
    print(s)

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        solve()
        return sys.stdout.getvalue()
    finally:
        sys.stdin = old_stdin
        sys.stdout = old_stdout

def validate(inp: str, out: str):
    data = list(map(int, inp.split()))
    x1, y1, x2, y2 = data

    lines = out.strip().splitlines()

    if lines[0] == "-1":
        assert (x1 + y1) % 2 != (x2 + y2) % 2
        return

    k = int(lines[0])
    s = lines[1].strip()

    assert k == len(s)
    assert 0 < k <= 10**6
    assert all(c in "1234" for c in s)

    x, y = x1, y1

    for c in s:
        if c == "1":
            x, y = y, -x
        elif c == "2":
            x, y = -y, x
        elif c == "3":
            x, y = 1 + y, 1 - x
        else:
            x, y = 1 - y, x - 1

    assert (x, y) == (x2, y2)

validate(sample1, out)

# Sample 2
sample2 = "0 1\n1 1\n"

validate(case1, out)

# Same x coordinate, negative y displacement.

validate(case2, out)
