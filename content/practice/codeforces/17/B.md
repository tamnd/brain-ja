 ## 解決策
 ## 問題の理解

 当社には従業員と直属の上司がおり、その間にオファーがあります。 オファー`(a, b, c)`従業員を意味します`a`従業員を監督する意欲がある`b`費用のために`c`。 オファーごとに資格は厳密に減少しているため、`q[a] > q[b]`。 

最終階層はルート付きツリーである必要があります。 従業員 1 名が総責任者となり、上司は存在しません。 他のすべての従業員は、受信エッジを 1 つだけ持つ必要があります。つまり、直属の上司は 1 人だけです。 選択したすべてのオファーの合計コストは、可能な限り小さくする必要があります。 

資格制限は重要な構造特性です。 すべてのエッジは上位の資格から下位の資格に移行するため、サイクルは存在できません。 グラフはすでに条件順に並べられた DAG です。 

この制限は、二次関数の動作を伴うグラフ アルゴリズムを許可するのに十分なほど小さいです。 私たちはせいぜい`1000`従業員と`10000`オファーします。 アン`O(m log m)`または`O(m α(n))`ソリューションは簡単に十分に高速です。 平`O(n^2)`パスは受け入れられます。 エッジのすべてのサブセットを網羅的に検索することは不可能です。`2^10000`選択肢。 

危険なのは、すべてのノードの最小コストの受信エッジが有効な階層を自動的に保証しないことです。 選択したエッジは、すべての従業員を 1 つのルート構造に接続する必要があります。 

次の例を考えてみましょう。```
3
10 9 8
2
1 2 1
1 3 1
```答えは`2`。 従業員`1`はルートであり、他の両方は、選択したエッジを通じて間接的にルートを指します。 

次に、次のことを考えてみましょう。```
3
10 9 8
1
1 2 1
```従業員`3`監督者となる可能性のある人はまったくいません。 正しい答えは、`-1`。 

不注意な実装では、グラフを無向の意味で接続することが誤って要求される可能性があります。 修飾順序によってすでにサイクルが禁止されているため、これは不要です。 ルート以外のすべてのノードが 1 つの親を持つ必要があるだけです。 

もう 1 つの微妙なケースは、複数の従業員が内定を受け取っていない場合です。```
4
10 8 6 4
1
1 2 5
```従業員`3`そして`4`誰にも監督されることはできません。 根を張った木は根を 1 つだけ持つことができるので、答えは次のようになります。`-1`。 

資格の順序付けは、より強力なものを意味します。 最高の資格を持つ従業員は、それ以上の資格を持つ従業員が存在しないため、上司を持つことはできません。 同じ最大資格を持つ複数の従業員がいる場合、オファーには厳密な不平等が要求されるため、それらの間にエッジは存在できません。 その場合、複数のルートが避けられなくなり、答えはすぐに得られます。`-1`。 

## アプローチ

 ブルートフォースソリューションでは、オファーのすべてのサブセットを正確に試します。`n - 1`エッジを確認し、それらが有効なルート付きツリーを形成しているかどうかを確認します。 グラフが非循環であるため検証自体は簡単ですが、サブセットの数は天文学的な数になります。 と`10000`エッジでは、すべてのサブセットを反復処理することさえ絶望的です。 

よりインテリジェントな総当り攻撃のアイデアは、受信エッジの観点から考えることです。 ルートを除くすべての従業員は、スーパーバイザーを 1 人だけ選択する必要があります。 グラフはすでに非巡回であるため、1 つを除くすべてのノードがちょうど 1 の次数を持っている場合、構造は自動的にルート付きツリーになります。 

この観察により、問題は完全に変わります。 

資格はエッジに沿って厳密に減少するため、サイクルは不可能です。 つまり、DSU、MST ロジック、サイクル検出はまったく必要ありません。 重要なのは、ルート以外のすべての従業員が少なくとも 1 つの内定を持っているかどうかだけです。 その場合、そのような従業員ごとに最も安価な受信エッジを選択することが常に最適です。 

なぜ？ なぜなら、ある従業員の選択が他の従業員の選択の正当性に影響を与えることは決してないからです。 誤ってサイクルが作成されることはありません。 グラフ構造により一貫性が自動的に保証されます。 

したがって、最適なアルゴリズムは次のようになります。 

すべての従業員について、最小コストの受信エッジを見つけます。 1 人の従業員だけが受信エッジを持つことはできず、その従業員がルートになります。 複数の従業員が入力エッジを欠いている場合、階層を構築することは不可能です。 

これにより、問題はすべてのエッジにわたる単純なスキャンに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m) | O(m) | 遅すぎる |
 | 最適 | O(n + m) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を作成する`best`どこ`best[i]`エッジに入る従業員の最小コストを保存します`i`。 
2. のすべての値を初期化します。`best`無限大は、スーパーバイザーのオファーがまだ見つかっていないことを意味します。 
3. すべての申請を処理する`(a, b, c)`。 

従業員`a`従業員を監督できる`b`費用のために`c`。 最も安価な受信エッジのみが重要であるため、次のように更新します。```
best[b] = min(best[b], c)
```4. すべてのオファーを処理した後、すべての従業員をスキャンします。 

もし`best[i]`まだ無限です、従業員`i`監督候補者がいない。 
5. 着信エッジを持たない従業員の数を数えます。 

有効な階層には、そのような従業員が 1 人だけ、つまりルートを持つ必要があります。 
6. カウントが正確に 1 でない場合は、次のように出力します。`-1`。 

グラフは非巡回であるため、ゼロ根は不可能です。 ルートが複数あるということは、会社が切り離されたコンポーネントに分割されることを意味します。 
7. それ以外の場合は、すべての有限値を合計します。`best`。 

これらはまさに、選択したスーパーバイザ エッジのコストです。 

### なぜ効果があるのか

 重要な不変条件は、条件がすべてのエッジに沿って厳密に減少するため、オファー グラフが非循環であることです。 

1 人を除くすべての従業員が 1 つの入力エッジを持っていると仮定します。 有限の DAG では、その構造はルート付きツリーを形成する必要があります。 サイクルは存在できず、すべてのノードは最終的に次数 0 の一意のノードまで上向きにトレースされます。 

ある従業員の親の選択が別の従業員の実現可能性に影響を与えることは決してないため、各入力エッジを個別に最小化することで全体的な総コストが最小化されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**18

n = int(input())
q = list(map(int, input().split()))

m = int(input())

best = [INF] * n

for _ in range(m):
    a, b, c = map(int, input().split())
    b -= 1
    best[b] = min(best[b], c)

roots = 0
answer = 0

for x in best:
    if x == INF:
        roots += 1
    else:
        answer += x

if roots != 1:
    print(-1)
else:
    print(answer)
```配列`best`各従業員の最小受信エッジ コストを保存します。 最終的な答えはノードごとの最も安価な着信エッジのみに依存するため、隣接リストは必要ありません。 

修飾値は読み取られますが、直接使用されることはありません。 それらの目的は、エッジに関する保証の中にすでにエンコードされています。 どのオファーも満足できるものであるため、`q[a] > q[b]`、グラフは自動的に非循環になります。 

よくある間違いは、Kruskal または Prim を実行しようとすることです。 最小スパニング ツリー アルゴリズムは無向接続の問題を解決しますが、この問題は根本的に異なります。 グラフの方向によってサイクルが排除されることはすでにわかっているため、独立した局所最小化で十分です。 

もう 1 つの簡単な間違いは、入力内の従業員番号付けが次のとおりであることを忘れることです。`1`-ベース。 コードは変換されます`b`に`0`更新前の -ベースのインデックス作成`best`。 

変数`roots`着信エッジのない従業員をカウントします。 そのような従業員は 1 人だけ存在する必要があります。 上司のいない従業員が複数いる場合、それらの従業員を 1 つの階層に接続することはできません。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 従業員と特典を 1 回渡す |

せいぜい`10000`リニアスキャンは非常に高速です。 サイズの配列が 1 つだけであるため、メモリ使用量はごくわずかです`n`維持されている。 

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    INF = 10**18

    n = int(input())
    q = list(map(int, input().split()))

    m = int(input())

    best = [INF] * n

    for _ in range(m):
        a, b, c = map(int, input().split())
        b -= 1
        best[b] = min(best[b], c)

    roots = 0
    ans = 0

    for x in best:
        if x == INF:
            roots += 1
        else:
            ans += x

    print(ans if roots == 1 else -1)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out.strip()

# provided sample
assert run(
"""4
7 2 3 1
4
1 2 5
2 4 1
3 4 1
1 3 5
"""
) == "11", "sample 1"

# impossible case
assert run(
"""3
10 9 8
1
1 2 1
"""
) == "-1", "multiple roots"

# minimum size
assert run(
"""1
5
0
"""
) == "0", "single employee is root"

# choose cheapest incoming edge
assert run(
"""3
10 5 1
3
1 2 10
1 2 3
2 3 7
"""
) == "10", "minimum incoming edge"

# disconnected components
assert run(
"""4
10 9 8 7
2
1 2 1
3 4 1
"""
) == "-1", "two roots"

# chain structure
assert run(
"""5
9 8 7 6 5
4
1 2 1
2 3 2
3 4 3
4 5 4
"""
) == "10", "simple chain"
```| テスト入力 | 期待される出力 | 検証内容 |

 | 従業員は 1 人、エッジなし | 0 | 1 ノード階層 |

 ## 特殊なケース

 複数のオファーが同じ従業員を対象とする場合を考えてみましょう。```
3
10 5 1
3
1 2 10
1 2 3
2 3 7
```従業員`2`入ってくるコストがある`10`そして`3`。 アルゴリズムは最小限のみを保存します。`3`。 従業員`3`コストを受け取る`7`。 合計は次のようになります`10`。 グラフはすでに非循環であるため、より高価な入力エッジを選択する理由はありません。 

ここで、避けられない複数のルートを考えてみましょう。```
4
10 9 8 7
2
1 2 1
3 4 1
```従業員`1`そして`3`どちらも入力エッジを持ちません。 アルゴリズムは 2 つの根を数えてすぐに返します。`-1`。 他の従業員にはそれぞれ上司がいますが、会社は 2 つの独立した階層に分かれています。

3
10 8 6

```従業員`3`着信エッジを受け取ることは決してないので、両方の従業員が`1`そして`3`ルートである必要があります。 アルゴリズムは、無限の受信コストを持つ 2 つのノードを検出し、出力します。`-1`。
