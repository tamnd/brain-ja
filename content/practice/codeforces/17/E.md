 ## 解決策
 ## 問題の理解

 文字列が与えられ、その中のすべての回文部分文字列を考慮します。 2 つの部分文字列が同じテキストを持つ場合でも、それぞれの出現は個別に問題になります。 たとえば、`"aaa"`3つの異なる発生があります`"a"`。 

すべての回文は間隔に対応します`[l, r]`。 個別の回文間隔の順序のないペアがいくつ交差するかを数えなければなりません。 2 つの間隔は、少なくとも 1 つの位置を共有する場合に交差します。 

直接的な解釈は次のとおりです。 

1. すべての回文部分文字列を列挙します。 
2. それらのすべてのペアを検討します。 
3. 間隔が重なるペアを数えます。 

文字列の長さは次のとおりです`2 * 10^6`、実現可能なことが完全に変わります。 たとえ`O(n^2)`ここではアルゴリズムは不可能です。 すべてのペアにわたる二次スキャンには約`4 * 10^12`最悪の場合の運用。 線形時間に近いものが必要です。 

もう 1 つの隠れた問題は、回文部分文字列の数自体が既に 2 次になる可能性があることです。 のような文字列`"aaaa....a"`おおよそ含まれています`n(n+1)/2`回文。 すべての間隔を明示的に保存することはできません。 

弾性率`51123987`も重要です。 中間カウントは膨大になる可能性があるため、すべての算術演算はこの値を法として維持する必要があります。 

見落としやすいエッジケースがいくつかあります。 

最小の入力を考えてみましょう。```
1
a
```回文は 1 つだけなので、答えは次のようになります。`0`。 実装を不注意にすると、それ自体とペアになった回文を誤ってカウントしてしまう可能性があります。 

次に、次のことを考えてみましょう。```
2
aa
```回文は次のとおりです。 

-`[1,1]`-`[2,2]`-`[1,2]`交差するペアは次のとおりです。 

-`[1,1]`と`[1,2]`-`[2,2]`と`[1,2]`答えは`2`。 重複しないペアを数えて合計ペアから減算する場合、順序付きペアを二重にカウントしないように注意する必要があります。 

もう 1 つの厄介な例は次のとおりです。```
4
abba
```回文:

 - 4 つの単一文字
 -`"bb"`-`"abba"`回文`"abba"`1 つおきの回文と交差します。 局所的に中心だけを調べるアルゴリズムは、多くの小さな回文をカバーする長い回文を忘れてしまうことがよくあります。 

最悪のケースは、文字列が繰り返される場合です。```
5
aaaaa
```すべての部分文字列は回文です。 がある`15`回文の合計は次のようになります。`105`順序のないペア。 素の間隔のペアのみを除外する必要があります。 すべての回文を明示的に生成する実装では、大規模な処理では時間とメモリの両方が不足します。`n`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての回文部分文字列を列挙し、すべての間隔を保存して、すべてのペアの重複をテストします。 

部分文字列が回文であるかどうかを確認すること自体は線形の時間がかかる可能性がありますが、中心拡張またはマナハのアルゴリズムを使用してそれを最適化したとしても、回文の総数は依然として変わらない可能性があります。`O(n^2)`。 それらを生成した後、すべてのペアをテストするには、別の二次係数がかかります。 

ある長さの文字列の場合`2 * 10^6`、回文の数は約`2 * 10^12`。 ペアごとの比較は天文学的に大きくなります。 

重要な点は、交差するペアを直接カウントするのは面倒ですが、交差しないペアをカウントする方がはるかに簡単であるということです。 

次のことがわかっているとします。 

-`T`= 回文部分文字列の総数。 
-`D`= 互いに素な回文の順序のないペアの数。 

その場合、答えは簡単です。```
T choose 2 - D
```2 つの回文は、一方が開始する前に終了する場合、正確に互いに素になります。 

これにより、問題はより構造化されたものに変わります。 計算できれば:

 - 各位置で終わる回文の数、
 - 各位置で始まる回文の数、

 次に、接頭辞の合計を使用して素のペアをカウントできます。 

残りの課題は、すべての回文を個別に列挙せずにこれらのカウントを取得することです。 

Manacher のアルゴリズムが役立つのはまさにここです。 Manacher は線形時間で次のように計算します。 

- 各中心における奇数回文の最大半径、
 - 各中心における最大の偶数回文半径。 

各半径は多くの回文をコンパクトに表します。 

これらの半径から、差分配列を使用して、各インデックスで開始または終了する回文の数を再構築できます。 すべての回文を個別に繰り返す代わりに、範囲全体を一度に追加します。 

それは`O(n)`解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^4) はナイーブ、O(n^2) は Manacher 列挙型 | O(n^2) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. Manacher のアルゴリズムを実行して奇数回文半径を計算します。 

ポジションごとに`i`、`d1[i]`を中心とする奇数回文の数を格納します。`i`。 

例: もし`d1[i] = 3`、回文の半径は`1,2,3`。 
2. Manacher のアルゴリズムを実行して、回文半径を計算します。 

ポジションごとに`i`、`d2[i]`間の中心にある偶数回文の数を格納します。`i-1`そして`i`。 
3. 回文の総数を計算します。 

すべての半径が、まさにその数の回文に寄与します。```
total = sum(d1) + sum(d2)
```4. アレイの構築`start[]`そして`end[]`。`start[i]`位置から始まる回文の数が含まれます`i`。`end[i]`位置で終わる回文の数が含まれます`i`。 
5. 差分更新を使用してこれらの配列を埋めます。 

を中心とする奇数回文の場合`i`半径あり`k`:

 - 範囲を開始します`i-k+1`に`i`- 終了範囲は次のとおりです`i`に`i+k-1`各回文を個別に追加する代わりに、次のように追加します。`+1`差分配列を使用してこれらの間隔にわたって。 
6. 偶数の回文に対して同じプロセスを繰り返します。 

偶数回文に中心がある場合`i`と半径`k`:

 - 範囲を開始します`i-k`に`i-1`- 終了範囲は次のとおりです`i`に`i+k-1`7. プレフィックス合計を使用して、差分配列を実際のカウントに変換します。 
8. プレフィックスの合計を計算します`end[]`。 

させて：```
pref[i] = number of palindromes ending at or before i
```9. 互いに素なペアを数えます。 

すべての開始位置について`i`、で始まるすべての回文`i`前に終わるすべての回文から切り離されている`i`。 

そこで、次のように追加します。```
start[i] * pref[i-1]
```10. 最終的な答えを計算します。 

順序なしペアの合計:```
total * (total - 1) / 2
```互いに素なペアを減算し、剰余を求めます。 

### なぜ効果があるのか

 異なる回文のすべてのペアは、次の 2 つのカテゴリのいずれかに正確に分類されます。 

- 交差する、
 - バラバラ。 

右側の回文が始まる前に左側の回文が終了する場合、ペアは正確に素です。 右の回文の開始位置を固定することで、終了位置にわたる接頭辞の合計を使用して、互換性のあるすべての左の回文をカウントできます。 

Manacher のアルゴリズムは、すべての回文がその中心と半径を通過して正確に 1 回表現されることを保証します。 すべての有効な半径が、一意の開始と終了を持つ 1 つの回文に寄与するため、差分配列の再構成では多重度が正しく保存されます。 

すべての素なペアは 1 回だけカウントされるため、順序付けされていないペアの総数から減算すると、交差するペアが正確に残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 51123987

def solve():
    n = int(input())
    s = input().strip()

    # Manacher odd
    d1 = [0] * n
    l = 0
    r = -1

    for i in range(n):
        k = 1 if i > r else min(d1[l + r - i], r - i + 1)

        while i - k >= 0 and i + k < n and s[i - k] == s[i + k]:
            k += 1

        d1[i] = k

        if i + k - 1 > r:
            l = i - k + 1
            r = i + k - 1

    # Manacher even
    d2 = [0] * n
    l = 0
    r = -1

    for i in range(n):
        k = 0 if i > r else min(d2[l + r - i + 1], r - i + 1)

        while i - k - 1 >= 0 and i + k < n and s[i - k - 1] == s[i + k]:
            k += 1

        d2[i] = k

        if i + k - 1 > r:
            l = i - k
            r = i + k - 1

    total = (sum(d1) + sum(d2)) % MOD

    start_diff = [0] * (n + 1)
    end_diff = [0] * (n + 1)

    # Odd palindromes
    for i in range(n):
        k = d1[i]

        L = i - k + 1
        R = i

        start_diff[L] += 1
        if R + 1 < n:
            start_diff[R + 1] -= 1

        L = i
        R = i + k - 1

        end_diff[L] += 1
        if R + 1 < n:
            end_diff[R + 1] -= 1

    # Even palindromes
    for i in range(n):
        k = d2[i]

        if k == 0:
            continue

        L = i - k
        R = i - 1

        start_diff[L] += 1
        if R + 1 < n:
            start_diff[R + 1] -= 1

        L = i
        R = i + k - 1

        end_diff[L] += 1
        if R + 1 < n:
            end_diff[R + 1] -= 1

    start = [0] * n
    end = [0] * n

    cur = 0
    for i in range(n):
        cur += start_diff[i]
        start[i] = cur

    cur = 0
    for i in range(n):
        cur += end_diff[i]
        end[i] = cur

    pref = [0] * n
    pref[0] = end[0]

    for i in range(1, n):
        pref[i] = pref[i - 1] + end[i]

    disjoint = 0

    for i in range(1, n):
        disjoint += start[i] * pref[i - 1]
        disjoint %= MOD

    total_pairs = total * (total - 1) // 2
    total_pairs %= MOD

    ans = (total_pairs - disjoint) % MOD

    print(ans)

solve()
```最初の部分は標準的な Manacher のアルゴリズムです。 奇数バージョンと偶数バージョンは、対称規則がわずかに異なるため、別々になります。`d1[i]`文字の半径の長さではなく、カウントを保存します。 もし`d1[i] = 3`、実際の回文の長さは次のとおりです。`1,3,5`。 

差分配列セクションは微妙な部分です。 

仮定する`d1[i] = k`。 それから、まさにあります`k`を中心とする奇妙な回文`i`。 それらの開始位置は 1 つの連続した間隔を形成します。 すべての半径を反復する代わりに、その間隔全体をインクリメントします。`O(1)`時間。 

同じロジックが終了位置にも適用されます。 

再構築後`start[]`そして`end[]`、素のペアを数えます。 あらゆるポジションについて`i`、そこから始まるすべての回文は、その前で終わるすべての回文とペアになります。`i`。 

ここでは順序が重要です。 左側の回文が早く終了するペアのみをカウントするため、順序付けされていない素のペアはそれぞれ 1 回だけカウントされます。 

もう 1 つの重要な詳細は、整数の増加です。 回文の総数は約`2 * 10^12`そのため、固定幅の整数を使用する言語ではオーバーフローが発生します。 Python の整数は安全ですが、それでも頻繁に剰余を削減します。

    input = sys.stdin.readline

    n = int(input())
    s = input().strip()

    l = 0
    r = -1

    for i in range(n):
        k = 1 if i > r else min(d1[l + r - i], r - i + 1)

            k += 1

        d1[i] = k

        if i + k - 1 > r:
            l = i - k + 1
            r = i + k - 1

    d2 = [0] * n
    l = 0
    r = -1

    for i in range(n):
        k = 0 if i > r else min(d2[l + r - i + 1], r - i + 1)

            r = i + k - 1

    for i in range(n):

        start_diff[i - k + 1] += 1
        if i + 1 < n:
            start_diff[i + 1] -= 1

        end_diff[i] += 1
        if i + k < n:
            end_diff[i + k] -= 1

    for i in range(n):
        k = d2[i]

        if k == 0:
            continue

        start_diff[i - k] += 1
        if i < n:
            start_diff[i] -= 1

        end_diff[i] += 1
        if i + k < n:
            end_diff[i + k] -= 1

    start = [0] * n
    end = [0] * n

    cur = 0
    for i in range(n):
        cur += start_diff[i]
        start[i] = cur

    cur = 0
    for i in range(n):
