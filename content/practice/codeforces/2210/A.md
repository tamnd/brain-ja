 ## 解決策
 ## 問題の理解

 1 から 1 までの整数の順列を構築するように求められます。$n$連続する剰余のシーケンスが増加しないようにします。 より具体的には、順列の場合$a_1, a_2, \ldots, a_n$、シーケンス$a_1 \bmod a_2, a_2 \bmod a_3, \ldots, a_{n-1} \bmod a_n$満たさなければなりません$$a_1 \bmod a_2 \ge a_2 \bmod a_3 \ge \ldots \ge a_{n-1} \bmod a_n$$入力は複数のテスト ケースで構成され、それぞれが 1 つの整数を与えます。$n$。 出力は、上記のモジュラー シーケンス プロパティを満たす任意の順列です。 制約は控えめで、$2 \le n \le 100$最大 100 のテスト ケース。 これにより、次のようなアルゴリズムが可能になります。$O(n^2)$タイムアウトの危険がなく、それ以上の速度で実行できます。 

注意すべきエッジケースは次のような場合です$n=2$。 ここで、順列はサイズ 2 でなければならず、自明でない唯一の条件は次のとおりです。$a_1 \bmod a_2 \ge 0$。 注文$[2, 1]$動作します、以来$2 \bmod 1 = 0$。 別の非自明なシナリオはより大きなものです$n$単純な昇順または降順は失敗します。 たとえば、単純に返すと、$1,2,3,4$満足しない$1 \bmod 2 \ge 2 \bmod 3$、 なぜなら$1 \ge 2$は誤りです。 アルゴリズムは、モジュラー シーケンスが増加しないように、戦略的に大きな数値を配置する必要があります。 

## アプローチ

 ブルートフォースアプローチは、すべてを生成することです。$n!$順列を確認し、それぞれのモジュラー プロパティを確認します。 順列ごとに、次のように計算します。$n-1$mod の操作と比較。 これは正確性を保証しますが、明らかに非現実的です。$n = 100$、 以来$100!$天文学的に大きいです。 

重要な観察は、より大きな数によるより小さな数の法は常にそれ自体であるということです。 これにより、モジュロ値が強制的に減少する位置に残りの最大の数値を配置することによって順列を構築することができます。 シンプルで効果的な戦略は、最大の数値を 2 番目の位置に配置し、その後、残りの最大の数値を逆方向に偶数の位置に再帰的に配置し、奇数の位置を残りの最小の数値で埋めることです。 実際には、より簡単な解決策は数​​値を降順で出力することですが、それぞれの数値がその右側のすべての数値よりも大きいことを常に確認するという工夫が必要です。 堅牢な構築パターンの 1 つは、配列を反転し、モジュロ シーケンスが自然に減少するように要素を周期的にシフトすることです。 のために$n \le 100$、これらの単純な構造は常に機能します。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、整数を読み取ります。$n$。 
3. 最大から最小の位置を埋めることによって順列を構築します。 最大の数値から始めて最初の位置に配置し、次に降順で次に大きい数値を 2 番目の位置に配置します。 
4. 各テスト ケースの順列を出力します。 

この単純な降順構造が機能する理由は、$a \bmod b \le b-1$、最初に大きな数値を配置すると、連続する剰余が減少するか、同じままになります。 1からすべての数字なので、$n$が 1 回だけ使用されると、順列プロパティが維持されます。 重要な不変条件は、すべてのステップで$a_i > a_{i+1}$保証する$a_i \bmod a_{i+1} < a_{i+1}$、増加しないシーケンスが生成されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # Construct permutation using descending order
    perm = list(range(n, 0, -1))
    print(' '.join(map(str, perm)))
```このソリューションは高速 I/O を使用してすべての入力を読み取り、テスト ケースごとに次の降順シーケンスを構築します。$n$1. Python の使用`range(n, 0, -1)`オフバイワンエラーがないことを保証します。 の`join`call は、整数を単一行の文字列に効率的に変換します。

 ## 特殊なケース

 のために$n=2$、アルゴリズムは [2,1] を構築します。 mod シーケンスは [0] であり、非増加特性を自明に満たします。 のために$n=100$、降順では、連続する各モジュロが前のモジュロ以下であることが保証され、順列ではすべての数値が 1 回だけ使用されます。 オフバイワンエラーはありません。`range(n,0,-1)`正しくは 1 が含まれます。
