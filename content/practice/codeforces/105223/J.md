 ## 解決策
 ## 問題の理解

 軸に整列した正方形と、その中に水平または垂直のいくつかの直線セグメントが与えられます。 セグメントは厳密には正方形の内側にありますが、重なったり、一致したりする場合があります。 両方のセグメントを無限の線に拡張すると、これら 2 つの線は正方形を軸に沿った小さな長方形のセットに分割し、結果として得られる長方形の中に、正確に 2 回現れる長方形の形状の値が存在するように、2 つの異なるセグメントを選択するように求められます。 

2 つの長方形は、1 つを 180 度回転または反転できる場合、同じとみなされます。つまり、方向ではなく辺の長さだけが重要になります。 

幾何学的には、2 つの軸に整列したセグメントを延長するということは、正方形の中に 2 本の完全な水平または垂直のカット ラインを追加することを意味します。 このような線のペアは、交差するか平行するかに応じて、正方形を最大 6 つまたは 9 つの長方形領域に分割します。 この問題の条件は、形成される領域の数ではなく、生成される複数の長方形形状の集合に関するものです。つまり、1 つの形状タイプが 2 回出現する必要があり、他のすべての形状は多くても 1 回出現する必要があります。 

入力サイズは最大 10 万セグメントに達するため、セグメントのすべてのペアを試行するソリューションは、n 乗のオーダー (最悪の場合約 100 億) の演算が必要になるため、直ちに実行不可能になります。 これは一般的な 2 秒の制限をはるかに超えています。 

主な問題点は、選択した 2 つのセグメントの効果が、正確な終点ではなく、サポート ラインのみに依存することです。 任意のセグメントは、垂直線 x = c または水平線 y = c のいずれかを定義します。 したがって、複数のセグメントを同じ有効カット ラインに対応させることができます。 この冗長性は重要です。同じ座標を持つ異なるセグメントを選択すると、同一の幾何学的パーティションが生成されます。 

単純な間違いは、セグメントを一意の x または y 位置に圧縮せずに独立して扱うことです。 もう 1 つの微妙な落とし穴は、すべてのセグメントが有用であると想定していることです。 同じ線上にある多くのセグメントは交換可能であり、それらの線の座標のみが重要です。 

## アプローチ

 ブルートフォース手法では、セグメントのすべてのペアがチェックされます。 各ペアについて、それらを実線まで拡張し、結果として得られる正方形の分割を計算し、次に長方形の形状を数えて、正確に 2 つの長方形が同じ寸法を共有しているかどうかを確認します。 各チェックでは正方形の境界との交差を計算し、最大一定数の長方形を導出する必要があるため、各ペアのコストは O(1) です。 ただし、O(n^2) 個のペアがあり、約 10^10 の演算が必要となり、これは現実的ではありません。 

重要な観察は、パーティションの構造は、垂直線を選択するか水平線を選択するか、およびその座標にのみ依存するということです。 2 本の線が固定されると、作成される長方形のサイズは、正方形の境界線とこれらの線の間の距離によって決まります。 したがって、重要なのは、相対的な配置によって繰り返される長方形領域構成を生成する 2 つの行が存在するかどうかだけです。 

問題は、一度に 1 つの次元でのカットのペアについての推論に帰着します。 垂直カットは X 座標のみに依存し、水平カットは Y 座標のみに依存します。 したがって、セグメントを垂直セットと水平セットに分離し、それぞれのタイプを個別に分析できます。 

垂直線の場合、その x 座標を並べ替えることで、隣接する位置または同一の位置を推論することができます。 水平線についても同様です。 正確に 1 つの複製された長方形を作成するための条件は、同じ位置のカットのペア、または 1 つの繰り返し長方形を強制する非常に特殊な対称構成を見つけることになります。

実際、正方形内の 2 つの軸を揃えたカットから得られるすべてのピースの中で、正確に 2 つの同一の長方形を取得する唯一の方法は、選択した両方のセグメントが同じ向きに対応し、対称的な分割を誘発する場合です。これは、投影が同じ幅または同じ高さのパーティションを作成するように位置合わせされた 2 つのセグメントを選択した場合に発生します。 これは、同じ座標 (x または y のいずれか) を共有する 2 つのセグメントの検索に集約されます。 セグメント間にいずれかの座標が少なくとも 2 回出現する場合、その座標を持つ任意の 2 つのセグメントを選択すると条件が満たされます。これは、両方のカットが一致し、反対側の軸に沿って複製された長方形のストリップが作成されるためです。 

したがって、問題は、垂直セグメントの x 座標または水平セグメントの y 座標における重複の検出に帰着します。

 ## アルゴリズムのチュートリアル

 1. すべてのセグメントを読み取り、各セグメントを垂直または水平に分類します。 x1 が x2 に等しい場合、セグメントは垂直であり、そうでない場合は水平です。 誘導カットラインでは軸に沿った方向のみが重要となるため、この分類が必要です。 
2. 垂直セグメントの場合、その x 座標を抽出します。 水平セグメントの場合は、その y 座標を抽出します。 これらの座標によってグループ化されたインデックスを保存します。 
3. 座標を挿入するときに、以前に座標がすでに出現していないかどうかを確認します。 垂直セグメントに繰り返される x または水平セグメントに繰り返される y があれば、すぐに有効な答えが得られ、対応する 2 つのセグメント インデックスを出力できます。 
4. 垂直座標にも水平座標にも重複が存在しない場合は、有効なペアが存在しないと判断し、-1 -1 を出力します。 

早期停止の背後にある理由は、最初に繰り返される座標によって、同一のフルライン カットを引き起こす 2 つの異なるセグメントがすでに保証されているためです。 

### なぜ効果があるのか

 セグメントが延長されると、そのサポートラインのみが重要になります。 2 つの異なるセグメントが同じ垂直線 x = c 上にある場合、それらを選択すると 2 つの同一の垂直カットが生成されます。これは、異なる表現で 1 つのカットを 2 回選択する場合と異なり、パーティションを変更しません。 これにより、結果として得られる長方形の分解には、水平方向に沿って繰り返される同一領域が含まれることが保証され、形成されたすべての長方形のうち、正確に 2 つの等しい長方形という要件が満たされます。 条件を満たす有効な構成では、繰り返しの有効なカット ラインを必ず導入する必要があります。これは、カット位置が重複しないと、結果として得られるすべての長方形の寸法が、軸に合わせたグリッドの構築によって異なるためです。 したがって、繰り返される座標を検出することは必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, xs, ys, xe, ye = map(int, input().split())

    seen_v = {}
    seen_h = {}

    for i in range(1, n + 1):
        x1, y1, x2, y2 = map(int, input().split())

        if x1 == x2:
            x = x1
            if x in seen_v:
                print(seen_v[x], i)
                return
            seen_v[x] = i
        else:
            y = y1
            if y in seen_h:
                print(seen_h[y], i)
                return
            seen_h[y] = i

    print(-1, -1)

if __name__ == "__main__":
    solve()
```このコードは、まずエンドポイントを比較して垂直セグメントと水平セグメントを分離します。 垂直セグメントの場合、X 座標をそれを生成した最初のセグメント インデックスにマッピングする辞書を使用します。 水平セグメントの場合、y 座標についても同じことが行われます。 重複する座標が見つかった瞬間に、2 つのセグメント インデックスが出力されます。 

実装の微妙な詳細は、各座標の最初の出現のみを保存することです。 この問題では有効なペアのみが必要であるため、これで十分です。 もう 1 つの重要な点は、セグメントのエンドポイントは方向と位置の決定以外には無関係であるため、エンドポイントを正規化したり並べ替えたりしないことです。

    import sys

 ## 特殊なケース

 微妙なエッジ ケースは、複数のセグメントが同じ行上にあるにもかかわらず、逆のエンドポイントで書かれている場合です。 例えば、`1 5 1 9`そして`1 9 1 5`は依然として同じ垂直線 x = 1 を表します。アルゴリズムはチェックのみを行うため、これを正しく処理します。`x1 == x2`、注文を完全に無視します。 

もう 1 つのケースは、複数の重複です。3 つ以上のセグメントが同じ座標を共有している場合、最初に繰り返された検出ですでに有効な応答がトリガーされます。 例えば：```
3 0 0 10 10
2 1 2 9
2 3 2 8
2 4 2 7
```2 番目のセグメントは最初のセグメントとすでに一致しているため、出力は即時に行われます`1 2`たとえ3番目が存在したとしても。 

最後のケースは、すべてのセグメントの向きが混合しているが、重複する座標がまだ存在しない場合です。 このような入力では、アルゴリズムは正しく返します。`-1 -1`同一の有効カットラインを定義する 2 つのセグメントがないため、誘導された長方形構造に繰り返しが発生することはありません。
