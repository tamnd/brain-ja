 ## 問題の理解

 時間の経過とともに変化する配列が与えられます。 更新のたびに、2 つのレイヤーで構築されたグローバル量を計算するように求められます。 

まず、現在の配列の空でないサブシーケンスを取得します。 このような各サブシーケンスについて、それ自体の空でないサブシーケンスすべてに対する XOR の合計を計算します。 これにより、サブシーケンスごとに値がすでに生成されています。 

次に、元の配列の空ではないサブシーケンスをすべて再度取得し、最初のステップで計算された値をそれらすべてについて合計します。 

したがって、実際には、配列のすべての可能なサブシーケンスが複数回寄与し、各サブシーケンス内ですべてのサブシーケンスを再度列挙し、XOR 値を合計します。 

入力サイズは大きく、最大 100 万の要素と 100 万の更新があります。 これにより、サブシーケンスを明示的に列挙するアプローチは即座に除外されます。 単一の配列を処理する場合でも、$2^n$これは実現不可能です。 どのようなソリューションでも、指数関数的に多くのサブシーケンスの寄与を閉じた形式の式に圧縮し、それをポイント更新時に維持する必要があります。 

微妙な問題は、サブシーケンスが値ではなくインデックスによって定義されることです。 異なる位置にある 2 つの等しい値は別個の要素であるため、位置に対して組み合わせカウントを実行する必要があります。 

素朴な考えを打ち破るエッジケースの 1 つは、小さな重複です。 たとえば、配列の場合$[x, x]$、次のような部分シーケンス$[x]$は 2 回出現し、サブシーケンスのカウントによってこの重複が再び増幅されます。 ポジションではなく値を扱うアプローチでは、貢献度が過小評価されます。 

もう 1 つの失敗モードは、各サブシーケンスが元の配列のスーパーセットに含まれる数によって重み付けされていることを忘れることです。 サイズのサブシーケンス$k$は、一度だけではなく、多くの大きな部分列に現れるため、直接的な「部分列の部分列の合計」解釈では、多重性を注意深く考慮する必要があります。

 ## アルゴリズムのチュートリアル

 式を段階的に保守可能なものに変換します。 

### 1. double 部分列の合計を書き換えます。 

最終的な答えを空ではないすべての部分列の合計として再解釈します。$t$配列の。 そういったそれぞれの$t$XOR 値にスーパーセットの数を乗算した値を提供します。$t$配列のサブシーケンス格子内。 サイズのサブシーケンス$k$もっている$2^{n-k}$スーパーセットなので、答えはすべてのサブシーケンスの加重合計になります。 

これにより、問題の外側の層が完全に除去されます。 

### 2. 世界的な権力を因数分解する

 重みを書き換えます$2^{n-k}$として$2^n \cdot (1/2)^k$。 要因$2^n$現在の配列の長さにのみ依存するため、保守が簡単です。 コアは、各要素が係数に寄与するサブシーケンスにわたる重み付けされた合計になります。$w = 1/2$選択した要素ごとに。 

### 3. XOR をビット寄与に減らす

 XOR をビットの合計として拡張します。 固定ビットの場合$b$、XOR(t) への寄与は次のとおりです。$2^b$要素の数が奇数の場合$t$噛んだ$b$設定されている場合、それ以外の場合はゼロ。 

したがって、ビットごとに、バイナリ配列のすべてのサブシーケンスの重み付けされた合計を計算する必要があります。ここで、選択された要素のパリティを追跡し、選択された各要素が重みに寄与します。$w$。 

### 4. 状態遷移としてのモデルサブシーケンス構築

 固定ビットの場合、すべての要素は「0 ビット」または「1 ビット」のいずれかになります。 

ゼロビット要素はパリティに影響しませんが、パリティを取得することも、取得しないこともできます。 これは、すべての状態に単純に乗算します。$(1 + w)$。 

1 ビット要素はパリティに影響します。偶数状態の場合、それを選択すると奇数に移動し、その逆も同様です。 これは 2 状態の線形変換を定義します。 

したがって、各 1 ビット要素は同じ行列を適用します。$$\begin{bmatrix}
1 & w \\
w & 1
\end{bmatrix}$$この行列を、そのビットが設定された要素ごとに 1 回繰り返し適用します。 

### 5. 繰り返される同一の変換を圧縮する

 すべての 1 ビット要素は同じ行列を使用し、順序は重要ではないため、この行列をそのような要素の数に等しい累乗にします。 

行列は固有値を介して閉じた形式になります。 その固有値は次のとおりです。$1 + w$そして$1 - w$。 これにより、その k 乗を直接計算できるようになります。 

結果を初期状態に適用する$[1, 0]$偶数および奇数の寄与に対して閉じた形式を提供します。 

### 6. ゼロビットスケーリングを組み合わせる

 1 ビット要素を処理した後、次のように乗算します。$(1+w)^{z}$、 どこ$z$はゼロビット要素の数です。 

これにより、このビットの最終的な奇数パリティの合計が得られます。 

### 7. 更新中のカウントを維持する

 各ビット位置について、そのビットが設定されている配列要素の数のカウントを維持します。 残りは暗黙的にゼロビット要素です。 

更新によって値が変更されると、古い値のビットのカウントがデクリメントされ、新しい値のビットのカウントがインクリメントされます。 各更新は 30 ビットのみに影響するため、寄与を効率的に再計算できます。 

### なぜ効果があるのか

 計算全体はサブシーケンスにわたる線形結合であり、各要素がビットごとにグローバル 2 状態システムへのローカル変換に独立して寄与します。 サブシーケンスの選択では要素を因数分解するため、最終的な合計は同一の可換変換の積になります。 これにより、すべての要素をビットごとのカウントに圧縮すると、重み付けされたサブシーケンスの正確な分布が維持されるため、構造情報が失われないことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
INV2 = (MOD + 1) // 2

MAXB = 31

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    n = int(input())
    arr = list(map(int, input().split()))
    q = int(input())

    cnt = [0] * MAXB
    for x in arr:
        for b in range(MAXB):
            if x >> b & 1:
                cnt[b] += 1

    def bit_contribution(b):
        k1 = cnt[b]
        k0 = n - k1

        w = INV2

        a = mod_pow((1 + w) % MOD, k1)
        b_ = mod_pow((1 - w) % MOD, k1)

        odd = (a - b_) * ((MOD + 1) // 2) % MOD
        odd = odd * mod_pow((1 + w) % MOD, k0) % MOD

        return odd * pow(2, b, MOD) % MOD

    total_2n = mod_pow(2, n)

    for _ in range(q):
        i, x = map(int, input().split())
        i -= 1

        old = arr[i]
        if old != x:
            for b in range(MAXB):
                if old >> b & 1:
                    cnt[b] -= 1
                if x >> b & 1:
                    cnt[b] += 1
            arr[i] = x

        ans = 0
        for b in range(MAXB):
            ans = (ans + bit_contribution(b)) % MOD

        ans = ans * total_2n % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、アレイ全体で設定ビットのビットごとの頻度を維持します。 各クエリはこれらのカウントのみを更新します。 各ビットのコア計算では、明示的なサブセットの列挙を回避し、閉形式行列の累乗結果を使用してすべてのサブシーケンスの寄与を再構築します。 

要因$2^n$は状態ごとに 1 回再計算されますが、すべての面倒な作業は小さな整数のべき乗剰余演算にプッシュされます。 

## 実用的な例

 動作を手動で追跡できる小さな配列を考えてみましょう。$[1, 2]$。 

最初は、ビット 0 とビット 1 のカウントは両方とも 1 です。ビットごとに寄与を個別に計算し、それらを組み合わせます。 更新により値が変更されると、それらのビット数のみが調整され、すべてのサブシーケンスの寄与が一貫してシフトされます。 

2番目の例は$[3, 3]$。 ここで重複が重要になります。 インデックスが異なるため、各サブシーケンスは複数回存在します。また、行列ベースの定式化は値ではなく位置を操作するため、自然に両方の出現を別々にカウントします。 

これらの例では、このメソッドが位置の多重性を尊重し、同一の値を誤って折りたたまないことが確認されています。

 ## 特殊なケース

 重要なエッジケースは、すべての要素が同一である場合です。 例えば、$[5,5,5]$多くの繰り返しサブシーケンスが生成されます。 単純な価値ベースのアプローチでは、これらを 1 つにまとめてしまいますが、正しい定式化では各立場を個別に扱います。 ビットカウント方式では、出現するたびに同じカウンタが独立してインクリメントされるため、多重度が維持されます。 

もう 1 つのケースは、2 つの値の間で 1 つの要素が頻繁に切り替わることです。 更新ごとに変更されるのは 30 ビットのみであるため、アルゴリズムは影響を受けるカウンターのみを正しく更新し、影響を受けない構造の再計算を回避しながら、サブシーケンスの正確な寄与を維持します。
