 ## 解決策
 ## 問題の理解

 さまざまな長さの横型ブラインド ストライプのセットがあり、私たちの目標は、これらのストライプを使用して窓用の長方形のブラインドを構築することです。 各ストライプはより小さな断片に切断できますが、断片は所定の最小長よりも短くすることはできません。`l`。 最終的なブラインドは、窓の幅をカバーするために同じ長さのピースをいくつか並べて構築されます。 ブラインドの幅は、列で使用されるピースの数に等しく、高さは各ピースの長さに等しい。 タスクは、利用可能なストライプでカバーできるウィンドウの領域を最大化することです。 

入力はストライプの数を提供します`n`および最小許容ピース長さ`l`、ストライプ長のリストが続きます。 出力は、完全にカバーできる最大のウィンドウの領域である必要があります。 制約の下でブラインドを構築できない場合、出力は 0 になります。 

制約を考慮すると (`n`≤ 100、長さ ≤ 100) の場合、可能なピースの長さを総当たりで探索することが可能です。 単純なソリューションがつまずく可能性があるエッジケースには、すべてのストライプが以下の値よりも短いことが含まれます。`l`(0 を返すはずです)、次と正確に等しいストライプを持ちます。`l`、長いストライプと短いストライプが混在しており、最善の解決策を得るには慎重なカットが必要です。 

たとえば、ストライプがある場合`[1, 2, 3, 4]`そして`l = 2`、単純なアプローチでは最長のストライプのみを使用しようとする可能性がありますが、最適な解決策は、長さ 2 のいくつかの部分を組み合わせて最大のウィンドウ領域をカバーし、領域 8 の 2 × 4 ウィンドウを生成します。 

## アプローチ

 最も単純な総当たりアプローチでは、考えられるすべてのピースの長さを考慮します。`d`から`l`最大ストライプ長まで。 それぞれについて`d`、長さが何個あるか数えます`d`すべてのストライプから入手できます。 次に、これらすべてのピースを使用して、一定のサイズの正方形または長方形のブラインドを構築できると仮定して、面積を計算します。`k × d`、 どこ`k`個数です。 これが機能するのは、すべてのブラインド行が同じ長さのピースで構成されている必要があり、ピースの合計数によって高さまたは幅が得られるためです。 

単純な総当たりの問題は、有効な長方形を形成できるピースの数が制限されていないことです。 面積を最大化するには、その面積の合計ピース数のすべての約数をテストする必要があります。`d`。 洞察は、各ピースの長さについて次のとおりです。`d`、最適なブラインド幅はピースの総数を割る必要があります。 そうしないと、一部のピースが使用できなくなります。 なぜなら`n`長さが 100 以下の場合、候補の数が少ないため、すべてを反復処理します。`d`可能な幅は実現可能です。 

重要な観察点は、ピースの長さです。`d`そしてピースの数`k`一緒にエリアを定義する`k * d`。 すべてのピースの長さを試してみると有効です`k`s、最大面積が見つかることを保証できます。 これにより、問題が構造化されていない総当たり攻撃から、管理可能な複雑さを持つ構造化された検索に変換されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * 最大長 * n) | お(1) | n が大きいと遅すぎます |
 | 最適 | O(n * 最大長 * n) | お(1) | 承認済み |

 ここ`max_length`≤ 100 および`n`≤ 100 なので、`100 * 100 * 100 = 10^6`操作は 2 秒間受け付けられます。 

## アルゴリズムのチュートリアル

 1. ストライプ間の最大長を特定します。`max_a`。 これにより、テストするピースの長さの上限が設定されます。 
2. 考えられるすべてのピースの長さを反復処理します。`d`から`l`に`max_a`。 それぞれ`d`は視覚障害者向けの候補となるピースの長さです。 
3. それぞれについて`d`、長さが何個あるかを計算します。`d`すべてのストライプから入手できます。 長さのあるストライプの場合`a_i`、私たちは得ることができます`a_i // d`個。 以下より短いストライプを無視する`d`。 
4.本品の合計個数について`d`、可能なすべての幅にわたって反復します。`k`1から`total_pieces`。 すべてのピースを使用して列を形成できるように、ピースの合計数を分割する幅のみを考慮してください。 面積を次のように計算します。`k * d`そして最大値を追跡します。 
5. すべてをテストした後`d`、見つかった最大領域を出力します。 ピースの長さが有効なブラインドを生成しない場合、最大値は 0 のままです。 

機能する理由: 候補となるピースの長さごとに、整数ピースを完全に使用するすべての可能なブラインド構成を体系的に計算します。 実現可能なすべてのピースの長さと合計ピースのすべての約数を反復することにより、有効な構成が欠落しないことを保証します。 このアルゴリズムは、長さとカウントの離散的な性質を利用して、正確さを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, l = map(int, input().split())
a = list(map(int, input().split()))

max_area = 0
max_length = max(a)

for d in range(l, max_length + 1):
    pieces = sum(ai // d for ai in a)
    for k in range(1, pieces + 1):
        if pieces >= k:
            area = k * d
            if area > max_area:
                max_area = area

print(max_area)
```コードはまず入力を読み取り、初期化します。`max_area`～ 0. 各候補ピースの長さについて`d`、整数除算で得られる合計個数を計算します。 次に、各行数を考慮します。`k`そして面積を計算して最大値を更新します。 整数除算を使用すると、これより短い部分がないことが保証されます。`d`、合計部分の約数を反復処理することで、完全なカバレッジが保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, l = map(int, input().split())
    a = list(map(int, input().split()))
    max_area = 0
    max_length = max(a)
    for d in range(l, max_length + 1):
        pieces = sum(ai // d for ai in a)
        for k in range(1, pieces + 1):
            if pieces >= k:
                area = k * d
                if area > max_area:
                    max_area = area
    return str(max_area)

# provided sample
assert run("4 2\n1 2 3 4\n") == "8", "sample 1"

# minimum inputs
assert run("1 1\n1\n") == "1", "min input"

# all stripes too short
assert run("3 5\n1 2 3\n") == "0", "no valid pieces"

# all equal
assert run("3 2\n4 4 4\n") == "6", "all equal lengths"

# mix of short and long
assert run("5 3\n1 2 3 4 5\n") == "9", "mix lengths"

# max size inputs
assert run("100 1\n" + " ".join(["100"]*100) + "\n") == "10000", "max size inputs"
