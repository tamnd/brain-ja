 ## 解決策
 ## 問題の理解

 各ノードが初期値と目標値を持つ、接続された無向グラフが与えられます。 任意のエッジを選択して、両方のエンドポイントに同じ整数を追加できます。 タスクは、すべてのノードの初期値をそのターゲット値に変換する一連の操作が存在するかどうかを判断することです。 

各テスト ケースでは、ノードとエッジの数、初期値の配列、ターゲット値の配列、およびエッジのリストを指定します。 変換が可能であれば出力は YES、それ以外の場合は NO になります。 

問題の制約により、すべてのテスト ケースにわたって累積で最大 200,000 個のノードとエッジが許可されるため、テスト ケースごとの線形または線形演算よりも複雑なアルゴリズムはタイムアウトになります。 エッジごとの整数演算の数には制限がないため、考えられるすべての演算を試す単純なシミュレーションは実行不可能です。 

注意すべきエッジケースは、すべてのノードの差が合計で奇数になる場合に発生します。 たとえば、初期値 [1, 1] とターゲット値 [2, 3] のエッジで接続されている 2 つのノードがある場合、合計の差は 3 です。各操作は 2 つのノードを同時にインクリメントするため、増分の合計は偶数である必要があります。 パリティをチェックせずに貪欲に値を追加しようとする単純なアプローチでは、解決策が存在するという誤った示唆を与えることになります。 二部グラフでは、別の微妙なケースが発生します。 グラフを 2 つのセットに色分けできる場合、操作はセット間でパリティに異なる影響を与えるため、一部の変換が不可能になる可能性があります。 

## アプローチ

 ブルートフォース手法では、エッジに沿って任意の整数を追加して、すべての一連の操作をシミュレートします。 これは原理的には正しいですが、加算する整数の選択肢が無限にあり、シーケンスの数はエッジの数に応じて指数関数的に増加するため、計算的には不可能です。 最小限の操作に制限しても、検索スペースは効率的に削減されません。 

重要な洞察は、**目標値と初期値の違い**に焦点を当てることです。 させて`delta[i] = t[i] - v[i]`。 エッジ上の各操作`(u, v)`追加します`k`両方に`delta[u]`そして`delta[v]`。 すべての合計`delta[i]`によって変化します`2*k`したがって、2 を法とする差の合計は不変です。 したがって、解の必要条件は、差の和が均等であることです。 

2 番目の洞察は、グラフ構造に関するものです。 グラフが **非 2 部**の場合、偶数の合計をノード全体に任意に分配する一連の操作を常に見つけることができます。 グラフが **2 部**の場合、エッジでの操作は異なるパーティション内のノードのみを接続するため、各パーティション内の差の合計は同じパリティを持つ必要があります。 具体的には、次の合計`delta[i]`一方のパーティションの合計からもう一方のパーティションの合計を引いた値は偶数である必要があります。 

これらの観察を使用すると、問題を、差の総和が偶数であるかどうか、およびグラフが 2 部構成の場合は分割の合計がパリティ制約を満たすかどうかをチェックすることに減らすことができます。 これにより、ソリューションは単純な DFS ベースのカラーリングと合計チェックに集約され、ノードとエッジに対して線形時間で実行されます。

 ## アルゴリズムのチュートリアル

 1. 差を計算する`delta[i] = t[i] - v[i]`各ノードごとに。 これは、各ノードに追加する必要がある合計値を表します。 
2.合計金額を確認する`delta`。 奇数の場合は、各演算で合計が偶数ずつ変化するため、すぐに NO を返します。 
3. DFS を使用してグラフを 2 色化し、二部性を検出します。 開始ノードに色 0 を割り当て、隣接するノードに交互の色を割り当てます。 競合 (同じ色の 2 つのノードを接続するエッジ) が検出された場合、グラフは非 2 部になります。 
4. グラフが非 2 部グラフで、合計が偶数の場合は、YES を返します。 差を均等に分散することも可能です。 
5. グラフが 2 部の場合、次の合計を計算します。`delta`各パーティションの値。 パーティションの合計の差が均等であるかどうかを確認します。 そうである場合は、YES を返します。 それ以外の場合は NO を返します。 
6. テスト ケースごとに繰り返します。 

**機能する理由**: 非 2 部グラフでは奇数長のサイクルが許可され、これを使用してノード間で任意の整数の変更を伝播できます。 2 部グラフにはそのようなサイクルがないため、パーティション間のパリティが制限されます。 各操作で合計が偶数に変化するという不変条件と、パーティション間のパリティ制約により、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        v = list(map(int, input().split()))
        tvals = list(map(int, input().split()))
        delta = [tvals[i] - v[i] for i in range(n)]
        adj = [[] for _ in range(n)]
        for _ in range(m):
            a, b = map(int, input().split())
            adj[a-1].append(b-1)
            adj[b-1].append(a-1)

        color = [-1]*n
        is_bipartite = True
        part_sum = [0, 0]

        def dfs(u, c):
            nonlocal is_bipartite
            color[u] = c
            part_sum[c] += delta[u]
            for vtx in adj[u]:
                if color[vtx] == -1:
                    dfs(vtx, c^1)
                elif color[vtx] == color[u]:
                    is_bipartite = False

        dfs(0, 0)
        total = sum(delta)
        if total % 2 != 0:
            print("NO")
        elif not is_bipartite:
            print("YES")
        elif (part_sum[0] - part_sum[1]) % 2 == 0:
            print("YES")
        else:
            print("NO")

solve()
```このコードは入力を読み取り、差分を計算し、DFS を実行してパーティションごとの差分を合計しながら二部性を判断します。 2 部グラフのパリティ条件と総和は、説明したとおりに正確にチェックされます。
