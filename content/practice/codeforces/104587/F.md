 ## 解決策
 ## 問題の理解

 固定サイズのテキスト ブロックを未知の正方行列で乗算して変換する古典的な線形暗号化モデルが与えられています。 長さ n の各ブロックはベクトルとして解釈され、行列がそれを変換し、入力ベクトルとそれに対応する出力の両方を観察します。 タスクは、これらの観察されたペアから変換行列を復元することです。 

各文字は固定アルファベット (大文字、数字、スペース) の整数に暗黙的にマップされるため、すべてのブロックは整数上のベクトルになります。 ブロック サイズ n が与えられ、平文文字列とその暗号文文字列が与えられます。 どちらも n で割り切れる長さを持つことが保証されているため、次元 n のいくつかのペアの入出力ベクトルを形成します。 

出力は、これらのペアによって誘導される線形方程式系に解がないのか、一意の解があるのか​​、あるいは無限に多くの解があるのか​​によって異なります。 すべてのマッピングを満たすことができる行列がない場合は、失敗を報告する必要があります。 複数の行列がすべてのマッピングを満たす場合、曖昧性が報告されます。 それ以外の場合は、一意の行列を出力します。 

重要な構造上の制約は、n が最大 10 であるため、各ブロックが小さな線形システムを与えることです。 文字列が長くても、未知数の数はわずか n² であるため、ガウス消去法は実行可能です。 

エッジ ケースは、提供されたブロック ペアが十分な制約に及ばない場合に発生します。 たとえば、すべての平文ブロックが線形依存している場合、システムは、一貫性があっても一意の行列を決定できません。 もう 1 つの失敗例は、暗号文がどの線形変換にも一致しない場合に発生し、システムの一貫性が失われます。 3 番目の微妙なケースは、方程式の数が未知数を超えているがランク不足があり、無限に多くの解が存在する場合です。 

## アプローチ

 ブルートフォースのアイデアは、行列のすべてのエントリを変数として扱い、この行列を乗算した各平文ブロックが対応する暗号文ブロックと等しいことを直接強制することです。 各ブロックは n 個の方程式に寄与し、各方程式は n² 個の未知数で線形です。 k 個のブロックを使用すると、kn 個の方程式が得られます。 整数行列の空間は指数関数的に増大するため、単純な列挙や置換によってこれを解決することは不可能です。 

重要な観察は、これがフィールド上、または一貫性制約のある整数上の標準的な線形システムであるということです。 行列をサイズ n² のベクトルに平坦化し、各平文と暗号文のペアが線形制約に寄与するシステム A x = b を構築できます。 ガウス消去法を使用すると、システムの解が 0 つであるか、1 つであるか、あるいは無限に多く存在するかを判断できます。 

各ブロックが独立して完全な線形変換制約に寄与し、それらすべてを 1 つの拡張行列にスタックできるため、構造はさらに簡素化されます。 問題は、このシステムのランク分析に帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース列挙 | 指数関数 | 高い | 遅すぎる |
 | ガウス消去法 | O((n²)³) 最悪の場合、ただし n ≤ 10 | O(n⁴) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、演算を実行できるように、各文字を固定アルファベットの整数インデックスに変換します。 

次に、平文と暗号文の両方をサイズ n のブロックに分割します。 各ブロックのペアは n 個の方程式を与えます。 行列の単一行 (行 i など) の場合、出力座標はその行と入力ベクトルのドット積です。 

未知数が行列のエントリであり、行ごとに平坦化される線形システムを構築します。 各ブロックは次の形式の制約を提供します。 

sum_j M[i][j] * P[k][j] = C[k][i]

 各ブロック k と各出力座標 i について。 

n² の未知数を使用してガウス消去法のための拡張行列を構築します。

実数 (または、制約が正確であるため有理数として扱われる整数) に対して消去を実行します。 エリミネーション中にピボット位置を追跡します。 

消去後、システムを分類します。 

すべての係数がゼロであるが RHS が非ゼロである矛盾行が見つかった場合、解は出力されません。 

ランクが n² 未満の場合、自由変数が存在するため、無限に多くの解が存在します。 

ランクが n² に等しい場合、一意に解決し、行列のエントリを再構築します。 

### なぜ効果があるのか

 すべての有効な暗号化行列は、観測されたすべての入出力ペアから導出された線形制約の完全なシステムを満たさなければなりません。 これらの制約は線形変換を完全に記述します。 ガウス消去法は、このシステムが一貫しているかどうか、およびその解空間の次元が 0、正、または空であるかどうかを決定します。 変換は線形で有限次元であるため、ランクは一意性を完全に特徴づけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

ALPH = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789 "

mp = {c:i for i,c in enumerate(ALPH)}

def gauss(a, b, n):
    m = len(a)
    N = n*n
    row = 0
    where = [-1]*N

    for col in range(N):
        sel = row
        for i in range(row, m):
            if abs(a[i][col]) > abs(a[sel][col]):
                sel = i
        if abs(a[sel][col]) < 1e-12:
            continue
        a[row], a[sel] = a[sel], a[row]
        b[row], b[sel] = b[sel], b[row]
        where[col] = row

        div = a[row][col]
        for j in range(col, N):
            a[row][j] /= div
        b[row] /= div

        for i in range(m):
            if i != row and abs(a[i][col]) > 1e-12:
                f = a[i][col]
                for j in range(col, N):
                    a[i][j] -= f * a[row][j]
                b[i] -= f * b[row]

        row += 1

    for i in range(m):
        s = 0
        for j in range(N):
            s += a[i][j] * 0
        if abs(b[i]) > 1e-9:
            ok = True
            for j in range(N):
                if abs(a[i][j]) > 1e-12:
                    ok = False
                    break
            if ok:
                return None, False, False

    x = [0]*N
    for i in range(N):
        if where[i] != -1:
            x[i] = b[where[i]]
    free = any(where[i] == -1 for i in range(N))
    return x, True, free

def solve():
    n = int(input())
    p = input().rstrip("\n")
    c = input().rstrip("\n")

    k = len(p) // n

    A = []
    B = []

    for t in range(k):
        pv = [mp[ch] for ch in p[t*n:(t+1)*n]]
        cv = [mp[ch] for ch in c[t*n:(t+1)*n]]

        for i in range(n):
            row = [0]*(n*n)
            for j in range(n):
                row[i*n + j] = pv[j]
            A.append(row)
            B.append(cv[i])

    x, ok, free = gauss(A, B, n)

    if not ok:
        print("No solution.")
        return
    if free:
        print("Too many solutions")
        return

    mat = [[0]*n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            mat[i][j] = x[i*n + j]

    for row in mat:
        print(" ".join(str(int(round(v))) for v in row))

if __name__ == "__main__":
    solve()
```このソリューションは、各行列エントリが変数である完全な線形システムを構築します。 各平文-暗号文ブロックは、出力座標ごとに 1 つずつ、n 個の方程式に寄与します。 ガウス消去法により、システムが矛盾しているか、過小決定されているか、完全に決定されているかが決まります。 

実装の微妙な点は、数値の不安定性を回避することです。 このソリューションでは、公差チェックを伴う浮動小数点消去を使用します。これは、n ≤ 10 という小さな制約を考慮すると許容されますが、より厳密な設定では、モジュラー算術または有理消去を使用することをお勧めします。 

消去後の分類ステップは不可欠です。どの変数にもピボットが存在しない場合は、無限に多くの解が存在することを意味しますが、矛盾行は解がないことを意味します。

 ## 特殊なケース

 重要なエッジケースは、平文ブロックが線形に依存している場合です。 多くのサンプルがあっても、システムはランクを獲得できない可能性があり、多くの方程式にもかかわらず、無限に多くの解が導き出されます。 アルゴリズムは、ピボットの欠落によってこれを正しく検出します。 

もう 1 つの特殊なケースは、一貫した平文セットに対する矛盾した暗号文です。 これにより、消去後に RHS がゼロ以外のゼロ行が生成され、解が存在しないケースがトリガーされます。 

最後に、n が 1 の場合、システムは単一のスカラー方程式システムに崩壊し、正確性はスカラー乗算器の一貫性をチェックすることになりますが、これは同じ消去フレームワークが自動的に処理します。
