 ## 問題の理解

 閾値発見実験と数学的に同一のストレージ シナリオが与えられています。 未知の限界がある$x$積み重なると$x$パレット上の同一の箱は安全ですが、積み重ねるのは危険です$x+1$箱が故障の原因となります。 の値$x$0 から 0 までの間にあることが保証されます$n$、包括的。 

数字を選択して実験を実行できます$k$、スタック$k$箱をパレット上に置き、パレットが生き残るかどうかを観察します。 それが壊れた場合、私たちはそれを学びます$x < k$。 それが生き残れば、私たちはそれを学びます$x \ge k$。 私たちは実験を繰り返すことが許されており、$m$パレット、つまり最大まで許容できる$m$リソースがなくなる前に「休憩」します。 

各実験のコストは 1 であり、確実に識別できる戦略が必要です。$x$最悪の場合は、実験をできるだけ少なくします。 すべての最適な戦略の中で、最初の実験サイズの有効な値の範囲を報告する必要もあります。 

制約$n \le 5000$これは、隠れたしきい値が比較的狭い離散範囲内にあるが、パレットの数が異なることを意味します。$m \le 20$意思決定をシミュレートするのではなく、動的プログラミング ソリューションを慎重に構築する必要があることを示唆しています。 すべての戦略に対する単純なシミュレーションでは、各実験が 2 つの結果に分岐し、指数関数的な決定木につながるため、組み合わせ爆発が起こります。 

微妙なエッジケースが現れるのは、$n = 0$。 この場合、実験は必要ありませんが、多くの実装では依然として最初の手を計算しようとし、ゼロ以外の実験サイズが誤って出力される可能性があります。 別の特殊なケースが発生する場合$m = 1$、ここで、唯一の実行可能な戦略は線形探索に退化し、最初の実験範囲は単一の値に折りたたまれなければなりません。 

## アプローチ

 直接的なアプローチは、決定ツリーの観点から考えることです。 各実験では値が選択されます$k$、成功または失敗に応じて、問題はより短い間隔に分割され、1 つのブランチで使用できるパレットが少なくなります。 考えられるすべての戦略を列挙しようとすると、各ノードは考えられるすべての戦略に分岐します。$k$、深さは最悪の場合の実験数に依存します。 これはすぐに実行不可能になります。$n$、可能な適応戦略の数は指数関数的に増加します。$n$。 

重要な観察は、実際には完全な決定木を構築することに関心がないということです。 特定の実験回数についてのみ知る必要があります。$t$そしてパレット$m$、の値はいくつありますか$x$区別することができます。 これは、卵を落とす問題と同じ古典的な再発につながります。 

させて$f[t][e]$を使用して区別できるしきい値の最大数になります。$t$実験と$e$パレット。 1 つの実験を実行する場合、いくつかの実験を選択します$k$。 パレットが破損した場合は、$t-1$実験と$e-1$パレット、まで区別できます$f[t-1][e-1]$以下の小さい値$k$。 それが生き残った場合、次のように削減されます。$t-1$実験、そしてまだ$e$パレットを使用して、以下を区別できるようになります。$f[t-1][e]$上記の値$k$。 現在のテストポイントを含めて、再帰を取得します$f[t][e] = f[t-1][e-1] + 1 + f[t-1][e]$。 

増やします$t$それまで$f[t][m]$少なくとも$n+1$、あるので$n+1$可能な値$x$0から$n$。 これにより、最悪の場合でも最小限の実験数が得られます。 

最適な実験回数になったら$t$がわかっている場合、すべての有効な初手を再構築します。 最初の実験の選択$k$両方の分岐が解決可能なままであれば有効です。$t-1$実験。 パレットが壊れた場合、私たちは解決できなければなりません$k-1$の値$t-1$実験と$m-1$パレットなので、$k-1 \le f[t-1][m-1]$。 それが生き残るならば、私たちは解決できるはずです$n-k$の値$t-1$実験と$m$パレットなので、$n-k \le f[t-1][m]$。 これらの制約の交差により、有効な最初の選択肢の全範囲が得られます。

 ## アルゴリズムのチュートリアル

 次に、到達可能な識別可能な範囲の動的プログラミング テーブルを構築します。 

1. DP 配列を初期化します。$f[0][e] = 0$みんなのために$e$実験がゼロの場合、しきい値を区別できないためです。 これにより、繰り返しのベースが設定されます。 
2. 実験回数を繰り返す$t$1から。 それぞれについて$t$、すべてのパレット数の値を計算します$e$1から$m$再発を利用して$f[t][e] = f[t-1][e-1] + 1 + f[t-1][e]$、値の上限は$n+1$不必要な成長を避けるため。 このステップでは、各実験が残りの探索空間を 2 つの独立した部分問題に分割するという事実をモデル化します。 
3. 最初で停止$t$そのような$f[t][m] \ge n+1$。 これは、考えられるすべてのボックス制限を区別するために必要な実験の最小数です。 
4. しましょう$t$この最小値になります。 最初の実験の選択を検討する$k$。 固定の場合$k$、失敗ブランチが処理する必要があります$k-1$使用する値$t-1$実験と$m-1$パレット、一方成功ブランチは処理する必要があります$n-k$使用する値$t-1$実験と$m$パレット。 
5. これらの制約を不等式に変換します。$k \le f[t-1][m-1] + 1$そして$k \ge n - f[t-1][m]$。 有効な範囲は、これら 2 つの条件の交差部分であり、次のように固定されます。$[1, n]$。 
6. 出力$t$そして計算された範囲。 下限と上限が一致する場合は、範囲ではなく単一の値を出力します。 

正しさは次の不変条件に基づいています。$f[t][e]$常に正確に使用して、区別可能なしきい値の最大数を表します。$t$実験と$e$パレット。 すべての実験は残りの空間を独立した部分問題にきれいに分割するため、再帰はすべての可能な戦略を完全に捕捉します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())

    if n == 0:
        print(0, 1)
        return

    # f[t][e]: max number of distinguishable thresholds
    # we only need up to n+1
    dp_prev = [0] * (m + 1)
    dp_curr = [0] * (m + 1)

    t = 0
    while True:
        t += 1
        for e in range(1, m + 1):
            val = dp_prev[e] + dp_prev[e - 1] + 1
            if val > n + 1:
                val = n + 1
            dp_curr[e] = val

        if dp_curr[m] >= n + 1:
            break

        dp_prev, dp_curr = dp_curr, dp_prev

    # dp_prev is t-1 layer, dp_curr is t layer
    prev = dp_prev

    # compute range for first move
    left = n - prev[m] + 1
    right = prev[m - 1] + 1

    left = max(1, left)
    right = min(n, right)

    if left > right:
        left = right = 1

    if left == right:
        print(t, left)
    else:
        print(t, f"{left}-{right}")

solve()
```次の層を計算するには前の層のみが必要なため、DP はローリング方式で実装されます。 これにより、メモリ使用量が線形に保たれます。$m$、それは重要なことですが、$m \le 20$小さいです。 

停止条件は、現在のレイヤーが少なくとも区別できる時期をチェックします。$n+1$価値観。 これは、0 から 0 までのすべての可能なボックス制限をカバーすることに直接対応します。$n$。 

再構成ステップでは、最後の 2 つの DP レイヤーのみが使用されます。 有効な範囲の式は、両方の再帰的分岐が範囲内で実行可能であることを強制することによって直接得られます。$t-1$実験。 

## 実用的な例

 ### 例 1:$n = 3, m = 1$1 つのパレットでは、反復は直線的な成長に退化します。 DP 層は次のように進化します。 

| t | e=1 (容量) |
 | --- | --- |
 | 1 | 1 |
 | 2 | 2 |
 | 3 | 3 |
 | 4 | 4 |

 に止まります$t = 3$3 回の実験で 4 つの値 (0 ～ 3) を区別できるためです。 最初の移動制約により、$f[2][0] = 0$暗黙的にそして$f[2][1] = 2$。 唯一有効な最初の動きは、$k = 1$より大きなジャンプは、シングルパレット戦略が失敗後に回復できる範囲を超えるためです。 

出力は$3\ 1$。 

このトレースは、1 つのパレットを使用すると、戦略が順次検索に減り、DP が線形成長を正しくエンコードしていることを示しています。 

### 例 2:$n = 4, m = 2$レイヤーを計算します。 

| t | e=1 | e=2 |
 | --- | --- | --- |
 | 1 | 1 | 1 |
 | 2 | 2 | 3 |
 | 3 | 3 | 6 |

 に止まります$t = 3$以来$f[3][2] = 6 \ge 5$。 今$prev = f[2]$、 それで$prev[1]=2$、$prev[2]=3$。 

有効な範囲:$left = 4 - 3 + 1 = 2$、$right = 2 + 1 = 3$。 

したがって、最初の実験は 2 または 3 になります。 

これは、残りの同じ数の実験で両方のブランチのバランスが保たれている場合に、複数の最適な最初の手がどのように自然に発生するかを示しています。

 ## 特殊なケース

 いつ$n = 0$の場合、正しい動作はゼロの実験と任意の最初の手を出力することです。通常、これは 1 に正規化されます。この場合、DP は必要ありません。また、早期のリターンによって無効な範囲へのアクセスが回避されます。 

いつ$m = 1$、失敗するたびにプロセスが直ちに終了するため、DP は次のように減少します。$f[t][1] = t$。 より大きな最初の実験は唯一の実現可能な線形探索構造をオーバーシュートするため、アルゴリズムは単一の有効な最初の移動 1 を正確に生成します。 

いつ$n$大きいですが$m$も 20 に近く、DP は十分な速さで成長します。$f[t][m]$到達する$n+1$比較的少ないステップで。 両方の分岐からの制約が凸状の範囲で重複し、最適な決定において不連続なギャップが存在しないことが保証されるため、再構成式は依然として有効な最初の動きの連続した間隔を生成します。
