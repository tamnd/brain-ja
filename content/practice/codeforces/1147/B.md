 ## 解決策
 ## 問題の理解

 この問題では、金属板上のパターンを表す文字の長方形グリッドが得られます。各セルには、次のいずれかが含まれます。`.`(空) または`*`(満たされています)。 タスクは、すべての要素を含む最小の長方形を見つけることです。`*`文字。 この四角形は、1 から始まるインデックスを使用して、最上行、最下行、左端の列、および右端の列によって記述されます。 

入力では最初に行と列の数が与えられ、次にグリッド自体が続きます。 出力は、すべての星の外接する四角形を定義する 4 つの整数である必要があります。 

グリッドは 500x500 まで大きくなる可能性があるため、考えられるすべての四角形を明示的に検査するアプローチは実行不可能です。 上下および左右の座標のすべてのペアを考慮して、すべての星が含まれているかどうかを確認する単純な総当り攻撃には、最大で`(500^2)^2`これは、一般的な 2 秒の制限には遅すぎます。 

注意すべきエッジケースには、単一のグリッドが含まれます。`*`、すべてのグリッド`*`単一の行または列、およびグリッド内にあります。`*`境界線に触れます。 たとえば、次のようなグリッドです。```
3 4
*...
....
....
```返すべきです`1 1 1 1`。 複数の行または列が失敗することを想定した不用意なアプローチ。 

## アプローチ

 ブルートフォース手法では、考えられるすべての長方形をスキャンし、すべての星が含まれているかどうかを計算し、そのような最小の長方形を追跡します。 これは、四角形のチェックが簡単であるため機能しますが、グリッドが大きい場合は失敗します。n 行 m 列の場合、演算回数は O(n^2 * m^2) であり、n=m=500 では遅すぎます。 

重要な点は、すべての四角形をチェックする必要はないということです。 各星は長方形の端にのみ寄与します。 長方形の一番上の行は、`*`、一番下の行は、`*`、左端の列は、最小の列インデックスです。`*`、右端の列は最大の列インデックスであり、`*`。 グリッドを 1 回スキャンして、これらの極値を記録するだけで十分です。 

これにより、問題は 4 つのネストされたループの総当たり攻撃から 1 回の O(n*m) スキャンに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * m^2) | お(1) | 遅すぎる |
 | 最適 | O(n*m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 四角形の境界を追跡するために 4 つの変数を初期化します。 セット`top`大きな値 (可能な行よりも大きい値)、`bottom`-1まで、`left`大きな値に設定し、`right`-1まで。 これらは初期化されていない極値を表します。 
2. 各行を反復処理します。`i`0からn-1まで。 各行に対して、各列を反復処理します。`j`0からm-1まで。 セルの場合`(i,j)`含まれています`*`、極値を更新します。 

- セット`top`に`min(top, i)`。 
- セット`bottom`に`max(bottom, i)`。 
- セット`left`に`min(left, j)`。 
- セット`right`に`max(right, j)`。 
3. グリッドをスキャンした後、すべての星を含む長方形が一番上の行になります。`top+1`、下段`bottom+1`、左の列`left+1`、右列`right+1`。 の`+1`1 から始まるインデックス付けを考慮します。 

なぜ機能するのか: 変数`top`、`bottom`、`left`、`right`常に、これまでに観測された星の極端な指数を保持します。 グリッド全体をスキャンするため、星を見逃すことはありません。 座標の最小値と最大値を取得することで、長方形がすべての星の境界を正確に囲むことが保証されます。 それぞれの境界を見失うリスクはありません。`*`個別に検討しております。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    top, bottom = n, -1
    left, right = m, -1

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '*':
                top = min(top, i)
                bottom = max(bottom, i)
                left = min(left, j)
                right = max(right, j)

    print(top + 1, left + 1, bottom + 1, right + 1)

if __name__ == "__main__":
    main()
```このソリューションの各部分は、アルゴリズムのウォークスルーに直接対応しています。 極値を初期化すると、それぞれを比較できるようになります`*`正しく。 二重ループによりすべてのセルがチェックされ、星の見逃しが防止されます。 最後に追加したのは、`+1`converts from 0-based Python indexing to the 1-based output required by the problem.

## 特殊なケース

 シングルの場合`*`どこでも、アルゴリズムは上、下、左、右を同じ値に設定し、サイズ 1x1 の長方形を生成します。 左上隅の星については、`top`そして`left`ゼロのまま、そして最終`+1`1 から始まるインデックスに変換されます。 右下の星については、`bottom`そして`right`が最大インデックスとして正しく更新されます。 すべての場合において、アルゴリズムはオーバーシュートやアンダーシュートを発生させることなく、すべての星を正しく境界付けします。 

このアルゴリズムは、最小値と最大値が実際の位置に収束するため、すべての星が 1 行または 1 列に配置されているグリッドを正しく処理します。 これにより、単純なアプローチで必要以上に大きい最小サイズの長方形を想定する可能性がある落とし穴が回避されます。
