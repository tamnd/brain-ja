 ## 解決策
 ## 問題の理解

 この問題では、非常に厳密な割り算特性を備えた配列を構築することが求められます。 配列が完全であると呼ばれるためには、長さや位置に関係なく、すべての部分配列がその長さで割り切れる合計を持っていなければなりません。 唯一の追加の制約は、配列の各要素が 1 から 100 までの値でなければならないことです。 複数のテスト ケースが与えられ、それぞれが必要な配列の長さを指定します。`n`、条件を満たすその長さの配列を出力する必要があります。 

制約を見てみると、`n`は最大でも 100 であり、テスト ケースの数も最大でも 100 です。これは、テスト ケースごとにおよそ O(n) または O(n²) で動作するアルゴリズムはすべて効率的に実行されることを意味します。これは、演算の合計数が最大でも約 10⁴ になるためです。 高度なデータ構造や最適化テクニックは必要ありません。 

この問題の重要な非明白な部分は、完全な配列の定義です。 単純な試みでは、考えられるすべての数値シーケンスをテストしたり、すべての部分配列の合計を構築したりする可能性がありますが、これは不要です。 強いパターンに注意する必要があります。配列のすべての要素が等しい場合、すべての部分配列も同じ数値で構成され、合計は長さで割り切れます。 例えば、`[5,5,5]`すべての部分配列の合計は次のとおりであるため、機能します。`5*k`一部の人にとっては`k`で割り切れます。`k`。 

エッジケースには最小のものが含まれます`n = 1`、これは 1 から 100 までの任意の数値で簡単に機能します。もう 1 つのエッジケースは次のとおりです。`n = 100`、許可される最大の長さ。すべての数値が範囲内にあり、同一であることを確認する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、配列を生成し、すべてのサブ配列をチェックしようとします。 指定された長さの配列の場合`n`、 がある`n*(n+1)/2`サブ配列の場合、各合計のチェックには最悪の場合 O(n) かかります。 これにより、テスト ケースあたり O(n³) の操作が行われます。 と`n`100 までの場合、これはテスト ケースごとに 100 万操作に達する可能性があります。これは 1 つのテストでは実行可能ですが、無駄で不必要です。また、合計を繰り返して単純に実装すると、簡単に時間制限を超える可能性があります。 

最適なアプローチは、配列のすべての要素が等しい場合、すべての部分配列には合計があるという観察から得られます。`element_value * length_of_subarray`。 この合計は明らかに部分配列の長さで割り切れるため、配列は自動的に完全になります。 要素の値は 1 から 100 までの任意の数値であるため、次の値を選択できます。`1`またはその範囲内の任意の定数を指定すると、配列は条件を満たします。 

このアプローチでは、長さの配列を生成する問題が軽減されます。`n`単一の数字で埋められます。 これはテスト ケースごとに O(n) であり、境界とすべての条件を自明に満たします。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、整数を読み取ります。`n`目的の配列の長さを表します。 
3. 長さの配列を生成する`n`すべての要素がどこにあるのか`1`。 1 から 100 までの任意の数値が機能しますが、`1`はシンプルです。 
4. 配列をスペース区切りの行として出力します。 

これが機能する理由は、どの長さの部分配列も`k`合計があるでしょう`1*k`で割り切れます。`k`。 この不変条件はすべてに当てはまります`k`1から`n`。 他の値や組み合わせを考慮する必要はなく、これにより正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        # perfect array: all elements equal, choose 1
        print(' '.join(['1'] * n))

if __name__ == "__main__":
    solve()
```コードの各部分はアルゴリズムに直接対応します。 テストケースの数を読み取り、それぞれについて`n`1 の配列を生成します。 の使用`' '.join(['1'] * n)`は、出力をスペース区切りの文字列として構築する Python の方法で、手動ループやフォーマット エラーを回避します。

 ## 特殊なケース

 のために`n = 1`、アルゴリズムの出力`[1]`。 すべての部分配列は長さが 1 で、合計は 1 で割り切れます。`n = 100`、出力は`[1]*100`。 任意の長さの部分配列`k`合計があります`k`、で割り切れる`k`。 1 を選択すると、すべての値が範囲 1 ～ 100 内に収まることが保証されます。 すべての算術演算は自明であるため、off-by-one や sum のオーバーフローの問題はありません。
