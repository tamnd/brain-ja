 ## 解決策
 ## 問題の理解

 私たちには番号が与えられています`n`10 進数表現にゼロが含まれておらず、いくつかの桁を削除して、**素数** ではない数値 (合成数または`1`。 目標は、結果が素数でないことを確認しながら、できるだけ多くの桁を削除することです。 入力には複数のテスト ケースが含まれており、それぞれのテスト ケースで桁数が指定されています。`k`そしてその番号`n`自体。 各テスト ケースの出力は、残りの数値と削除後の数値自体の長さです。 

制約は中程度です。`k`は最大でも 50 であり、次の合計は`k`すべてのテスト ケースの数は最大 10,000 です。 これは、数字の部分列の数が指数関数的に増加するため、数字の部分列をすべて列挙するアルゴリズムを用意する余裕がないことを意味します。`k`。 ほぼ直線的なアプローチが必要です。`k`テストケースごとに。 

素朴な解決策を打ち破る可能性があるエッジケースは、1 桁またはペアが素数である小さな数です。 たとえば、次の場合`n = 53`、素数以外の数字はありませんが、そのペアは`53`それ自体が素数であるため、解ではペアまたは他の短い部分列を考慮する必要があります。 もう 1 つの微妙なケースは、次のように完全に同じ数字で構成される数字です。`4444`、1 桁を除くすべての桁を削除しても、合成結果が得られます。 

## アプローチ

 ブルートフォース手法では、長さ 1 から 1 までの数字のすべてのサブシーケンスを生成します。`k-1`そして、各数値が素数でないかどうかを確認します。 これは原理的には機能しますが、サブシーケンスの数は`2^k - 1`、これは天文学的に大きいです`k = 50`。 数値ごとの線形素数テストでさえ遅すぎます。 

問題を単純化する重要な観察は、理想的には長さが 1 または 2 の **小さな非素数** を見つける必要があるだけであるということです。これが機能するのは、常に 1 桁の合成 (`4, 6, 8, 9`)、または 2 桁の非プライムを形成する 2 桁の数字。 以来`n`ゼロはなく、任意の数字が含まれます`1, 4, 6, 8, 9`すぐに長さ 1 の有効な答えが得られます。単一の数字が機能しない場合は、すべての数字のペアをチェックすることが可能です。`k*(k-1)/2`ペア、つまり最大 1,225`k = 50`、そして 2 桁の数値が非素数かどうかを検証するのは定数時間です。 

したがって、最適な解決策は次のとおりです。最初に 1 桁の合成をスキャンします。 存在しない場合は、2 桁の数字をすべてスキャンします。 この問題では、少なくとも 1 つの解決策が存在することが保証されているため、常に解決策が見つかります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * k) | O(k) | 遅すぎる |
 | 最適 | O(k^2) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`k`そして`n`。 変換する`n`操作を容易にするために数字のリストに変換します。 
2. 数字を左から右にスキャンし、セット内に数字があるかどうかを確認します。`{1, 4, 6, 8, 9}`。 これらは素数ではない 1 桁の数値です。 見つかった場合は出力します`1`そしてその数字を入力し、次のテスト ケースに進みます。 
3. 1 桁の合成が見つからない場合は、すべての桁のペアを取得して 2 桁の数値をすべて生成します。`(i, j)`と`i < j`。 
4. 2 桁の数字ごとに、**素数でない**かどうかを確認します。 2 桁の最大の数値は 99 であるため、事前に計算された小さな素数セット内の単純な検索または定数時間のチェックで十分です。 
5.長さを出力する`2`素数以外の最初の 2 桁の数字が見つかりました。 次のテスト ケースに進みます。 

**機能する理由**: アルゴリズムの構造上、まず 1 桁の合成を優先します。これは、数値を減らすために行うことができる最大の削除です。 存在しない場合は、問題の制約に従って、2 桁の非素数が存在することが保証されます。 これにより、正確性と最小限の計算が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Helper: check if 2-digit number is prime
def is_prime_2digit(x):
    if x < 2: return False
    for p in [2, 3, 5, 7]:
        if x == p: return True
        if x % p == 0: return False
    return True

t = int(input())
for _ in range(t):
    k = int(input())
    n = input().strip()
    
    # Step 1: check single-digit non-prime
    for d in n:
        if d in '14689':
            print(1)
            print(d)
            break
    else:
        # Step 2: check two-digit non-prime
        found = False
        for i in range(k):
            for j in range(i+1, k):
                num = int(n[i] + n[j])
                if not is_prime_2digit(num):
                    print(2)
                    print(n[i] + n[j])
                    found = True
                    break
            if found:
                break
```コードは、すぐにプライムではない数字をチェックすることから始まります。 の`else`その後`for`ループにより、1 桁の解が存在しない場合にのみ 2 桁の検索に入ることが保証されます。 2 桁の数値の場合は、小規模な定数時間の素数チェックを使用して各組み合わせをチェックします。数値はすべて最大 99 であるため安全です。 

## 実用的な例

 ### サンプル入力 1

 | n | 1 桁の複合値が見つかりました | 2 桁のペアが見つかりました | 出力 |
 | --- | --- | --- | --- |
 | 237 | 2、3、7 → なし | 23、27 → 27 は合成です | 2/27 |
 | 44444 | 4 が存在します | - | 1 / 4 |

 トレースは、237 については 1 桁の解が存在しないことを示しているため、最初の非素数ペアは`27`が選択されます。 44444 の場合は、1 桁の 4 で十分です。 

### サンプル入力 2

 | n | 1桁の複合 | 2 桁のペア | 出力 |
 | --- | --- | --- | --- |
 | 773 | なし | 77 → 77 は複合です | 2 / 77 |
 | 35 | なし | 35 → 35 は複合です | 2 / 35 |

 ここでは、1 桁の複合データのスキャンが失敗します。 ペアを生成すると、最初の非素数が生成されます。
