 ## 解決策
 ## 問題の理解

 幽霊の列があり、それぞれが整数の年齢を持っています。 移動は、年齢の異なる 2 つの隣接するゴーストを選択することで構成されます。 若い幽霊は消えますが、年上の幽霊は残り、1歳年を取ります。 ゴーストが去った後も、残ったゴーストの順序は変わりません。 

タスクはプロセスをシミュレートすることではありません。 必要なのは、ブーがゴーストを 1 つだけ残すように、ある順序で動きを選択できるかどうかだけです。 

入力により、ゴーストの数とその年齢が行順に表示されます。 1 つを除くすべてのゴーストを除去する一連の有効な一致が存在する場合、出力は YES であり、それ以外の場合は NO です。 

重要な制約は、ゴーストの数が最大 10,000 になる可能性があることです。可能な一致順序の数は非常に急速に増加するため、可能なすべての選択肢をシミュレーションすることは不可能です。 隣接する選択肢のすべてのペアを試しても、検索空間は指数関数的に増加します。 答えを直接決定する年齢のプロパティが必要です。 

エッジケースは小さいですが、見落としやすいです。 ゴーストが 1 つだけ存在する場合、残りのゴーストはすでに 1 つだけ存在するため、答えはすぐに「YES」になります。 

例えば：```
Input
1
7

Output
YES
```すべての年齢が等しいかどうかのみをチェックするソリューションでは、このケースが誤って拒否される可能性があります。 

もう 1 つの重要なケースは、すべての幽霊の年齢が同じで、複数の幽霊が存在する場合です。```
Input
4
5
5
5
5

Output
NO
```隣接する 2 つのゴーストの年齢が異なることはないため、最初の動きを開始することさえできません。 

最後のケースは、等しい年齢がすべて同じ値ではない場合です。```
Input
5
4
4
3
4
4

Output
YES
```不注意なアプローチでは、繰り返される値が進歩を妨げると考えるかもしれませんが、中年 3 は隣人と戦うことができ、1 つの幽霊が成長し、最終的には他の幽霊を排除することができます。 

## アプローチ

 ブルートフォースアプローチとは、考えられるすべての戦いのシーケンスを試すことです。 状態ごとに、異なる年齢の隣接するペアをすべて選択し、小さい方を削除し、大きい方を増やして、単一のゴーストに到達できるかどうかを再帰的に確認します。 これはプロセスを正確にモデル化しているため、正しいのですが、状態の数が多すぎます。 ゴーストが 10,000 個あると、最初のいくつかの選択肢だけですでに巨大な分岐ツリーが作成されます。 

重要な観察は、戦いを開始できない唯一の状況は、すべての幽霊が同じ年齢である場合であるということです。 少なくとも 2 つの異なる年齢があれば、いつでも進歩することができます。 

他の幽霊とは年齢が違う幽霊がいるとします。 現在隣人とは異なるゴーストと繰り返し戦って、ラインを通過することを検討してください。 戦いのたびに古いゴーストが生き残り、年齢を重ねます。 ゴーストが別のゴーストよりも厳密に年上になると、より若い隣人を倒し続けることができます。 より強いゴーストが有効な戦いをすることになるため、より強いゴーストが到達するまでは、同じ年齢は無視できます。 最終的には、1 つの幽霊が他の幽霊をすべて吸収することができます。 

問題全体は、すべての年齢が同一であるかどうかをチェックすることに帰着しますが、1 つのゴーストがすでに目標を満たしているという特殊な場合を除きます。

 ## アルゴリズムのチュートリアル

 1. ゴーストエイジをすべて読みます。 ゴーストが 1 つしかない場合は、一致する必要がないため、YES が出力されます。 
2. 各年齢を最初の幽霊の年齢と比較します。 すべての年齢が等しい場合は、隣接するペアが異なる年齢を持つことはできないため、NO を出力します。 
3. 少なくとも 1 つの年齢が最初の年齢と異なる場合は、YES を出力します。これは、2 つの異なる年齢の存在により、1 人の生存者を残すようにプロセスを調整できることが保証されるためです。 

これが機能する理由は、戦闘の正確な順序が決定に重要ではないためです。 不均一な配列には常に、戦闘が成功するたびに古くなるゴーストを作成するために必要な開始点が含まれています。 生き残った幽霊は決して若くなることはないため、成長は将来の戦いに役立つだけです。 

なぜ効果があるのか:

 すべてのゴーストの年齢が同じで、複数のゴーストがある場合、隣接する比較はすべて失敗するため、手は存在しません。 

それ以外の場合は、年齢の異なる 2 人の幽霊が存在します。 年長者は隣接すると年少者を倒すことができ、勝利すると年齢が増加します。 年齢が上がると対戦相手の可能性が増えるだけなので、年齢が上がっても将来の戦いが難しくなるということはありません。 このアイデアを繰り返すと、単一のゴーストがすべての試合で生き残ることができます。 したがって、唯一不可能な状況は、同じ年齢の複数の幽霊が存在することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    ages = [int(input()) for _ in range(n)]

    if n == 1:
        print("YES")
        return

    first = ages[0]
    for age in ages[1:]:
        if age != first:
            print("YES")
            return

    print("NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、入力には 1 行に 1 つの値が与えられ、最も単純な実装はそれらを配列に読み取るため、年齢のみが保存されます。 実際のアルゴリズムに必要なのは、最初の年齢と、別の年齢が存在するかどうかのみであるため、一定の追加メモリを使用して同じアイデアを実装できます。 

の`n == 1`任意の年齢を持つ単一のゴーストはすでに有効な最終状態であるため、チェックは等価性チェックの前に行われます。 より大きな入力の場合、一連の喧嘩が存在することを証明するには、異なる年齢を 1 つ見つけるだけで十分です。 

大きな値を伴う算術演算はないため、Python では整数のオーバーフローは問題になりません。 この実装では、不必要な複雑さの主な原因である戦闘のシミュレーションも回避されます。

 単一のゴーストの場合:```

```アルゴリズムチェック`n == 1`すぐにYESを返します。 目的はすでに満たされているので、戦う必要はありません。 

すべて等しい場合:```

```スキャンでは、すべての値が最初の経過時間と比較されます。 すべての比較は等しいため、アルゴリズムは NO を返します。 これは、隣接するペアの年齢が異なるため、Boo は 1 つの操作も実行できないため、プロセスと一致します。 

異なる年齢の同じグループの場合:```
Input
5
4
4
3
4
4
```スキャンの結果、3 番目のゴーストの年齢は 3 であるのに対し、最初のゴーストの年齢は 4 であることがわかります。これは、ラインがフリーズしていないことを証明します。 年上のゴーストは最終的には若いゴーストを利用して年齢を上げ、戦いに勝ち続けることができるので、答えは「YES」です。 

異なる年齢が末尾にある場合:```

```アルゴリズムは最後の値が最初の値と異なることを検出し、YES を返します。 最後のゴーストは、他のすべてのゴーストの隣で開始する必要はありません。 成長する生存者を戦線に導くために戦闘を手配できるため、何らかの違いが存在するだけで十分です。
