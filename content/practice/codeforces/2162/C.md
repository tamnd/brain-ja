 ## 問題の理解

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`a`そして`b`。 もし`a = b`、変更は必要ないため、すぐにゼロの操作を返します。 
2. コンピューティング`c = a XOR b`。 これは、回転させるために変更する必要があるビットを表します`a`の中へ`b`。 
3. もし`c ≤ a`、 選ぶ`x = c`そして単一の操作を実行します。`a := a XOR x`。 これは変わります`a`の中へ`b`直接。 
4. もし`c > a`、直接のシングルステップ XOR は不可能です。`x`を超えてはなりません`a`。 この場合、操作を 2 つのステップに分けることができます。 まず、選択してください`x1`の最上位ビットとして`a`(またはその一部`a`) 減らす`a`残りの必要な部分が反転するように`c`現在、更新された値以下になっています`a`。 次に、選択します`x2 = a XOR b`変換を完了します。 
5. もし`a = 0`そして`b ≠ 0`、出力`-1`、有効なものがないため、`x`ゼロからビットを作成できる。 

機能する理由: XOR 演算はそれ自体の逆演算であり、各ビットに対して独立して動作します。 コンピューティングによって`a XOR b`、どのビットを変更する必要があるかが正確にわかります。 これらのビットはすべて 1 回の操作で設定可能であるか、または、これらのビットを最大 2 つの操作に分割して、`x ≤ a`制約。 不変条件は、各操作の後、適用したすべての反転が、次のビットのサブセットに対応するということです。`c`、目標を決してオーバーシュートしないことを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        a, b = map(int, input().split())
        if a == b:
            print(0)
            continue
        if a > b:
            # Try one-step solution
            x = a ^ b
            if x <= a:
                print(1)
                print(x)
            else:
                # Two-step solution
                x1 = 1
                while x1 <= a:
                    x1 <<= 1
                x1 >>= 1
                a1 = a ^ x1
                x2 = a1 ^ b
                print(2)
                print(x1, x2)
        else:
            # a < b
            print(-1)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず次のような些細なケースを処理します。`a = b`操作はゼロです。 もし`a > b`を使用してシングルステップ XOR を試行します。`x = a XOR b`。 それを超えた場合`a`の最大ビットを反転することにより、操作を 2 つのステップに分割します。`a`まず、残りの XOR を終了します。 いつ`a < b`、XOR は存在するビットよりも新しい上位ビットを作成できないため、それは不可能です。`a`。 while ループは次の最上位ビットを見つけます。`a`効率的に。
