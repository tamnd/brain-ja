 ## 解決策
 ## 問題の理解

 私たちはエッジが色付けされた完全なグラフを扱っていますが、どの三角形も 3 つの異なる色を使用していないという制限があります。 この制限は古典的なガライの特性であり、グラフ全体で色がどのように表示されるかについて強力な階層構造を強制します。 

この問題は、エッジについて直接考えるのではなく、各頂点の派生量、つまりその頂点に付随するエッジ上にいくつの異なる色が現れるかを意味する色の度合いに注意を移します。 課題は、これらの色度のどのシーケンスが完全なグラフの有効なガライ色から実際に生じるかを理解することです。 

したがって、入力は本質的に、色度の候補マルチセットを表す整数のシーケンスです。 目的は、頂点が正確にこれらの色度を実現する完全なグラフに何らかのガライ色が存在するかどうかを判断することです。 

困難は、通常の意味での組み合わせ列挙ではなく、ガライ条件によって課せられる非常に厳格なグローバル構造を特徴づけることです。 この構造は十分強力であるため、有効な次数シーケンスの空間は高度に制限されていますが、直接説明するのは簡単ではありません。 

この制約は、エッジのカラーリングの数が n の 2 乗で指数関数的に増加するため、中程度のサイズであってもカラーリングを強引に構築することは不可能であることを意味します。 構築を試みて妥当性をチェックすることすら不可能です。 したがって、この問題では、構造の特徴付けと、その構造に対する組み合わせまたは DP ベースの計算が必要です。 

度数シーケンスが極端に歪んでいる場合、微妙なエッジケースが発生します。 たとえば、[n−1, 1, 1, …, 1] のようなシーケンスは、1 つの頂点が多くの色に触れている可能性があり、他の頂点は触れていないため、もっともらしく見えますが、補題 3 は、頂点が可能な最大の色度 n−1 に達すると、シーケンスの残りの部分が厳格なパターンに強制されることを示しています。 この構造的剛性を無視した単純な検証では、無効なシーケンスが受け入れられるか、有効な強制構成が拒否されます。 

もう 1 つの脆弱なケースは、複数の頂点が同様の度数を共有しているものの、カラーのグローバルな分布方法が異なる場合です。 三角形制約はコンポーネントを通じて情報をグローバルに伝播するため、局所的に同一に見える 2 つのシーケンスは、グローバルなガライ カラーリングに対応しない可能性があります。 

## アプローチ

 直接的な強引なアプローチでは、n(n−1)/2 エッジのそれぞれに色を割り当て、ガライ条件とその結果として得られる色の度合いの両方を検証しようとします。 k 色に制限したとしても、割り当ての数は依然として k の n 乗のオーダーであり、これはまったく実行不可能です。 

重要な簡素化は、ガライの着色構造を理解することで実現します。 このような色付けでは常に再帰的分解が可能です。エッジがグラフを単一の部分に接続せず、頂点をコンポーネント間の均一な相互作用パターンを持つコンポーネントに分割する色が存在します。 これがガライ分解の本質です。 

この分解が理解されると、次数シーケンスの問題は、これらのコンポーネントが制御された加法的な方法でどのように次数に寄与するかという問題になります。 補助定理 1 は、重要なローカル剛性ステートメントです。コンポーネントが切断された色に固定されると、すべての外部頂点はそのコンポーネントを単一の均一な色で認識します。 これにより、境界を越えた任意の色の混合が防止されます。 

定理 2 と定理 4 の不等式は、コンポーネントを繰り返し圧縮し、より小さなグラフに帰納法を適用することで生じます。 この構造により、コンポーネントを縮小すると、グラフの残りの部分との相互作用が、境界のある色度の寄与を持つ単一のスーパーノードのように動作することが保証されます。 これにより、次数の 2 のべき乗を含む式で再帰的な不等式が可能になります。

ブルート フォース ビューはエッジを独立して処理するため失敗します。 構造ビューは問題を制御された階層に落とし込み、各ステップで領域と相互作用する有効な色の数を減らします。

 | 度数にわたる構造 DP | O(n⁴) | O(n²) | 承認済み |

 ## アルゴリズムのチュートリアル

 ガライ分解から導出される構造的不等式、特にソートされた次数の接尾辞について、2 のべき乗の特定の加重和が下限を満たさなければならないという事実から始めます。 目標は、これらの不等式と構成的特徴付けによって引き起こされるすべての制約を満たすシーケンスの数を数えることです。 

概念的には n−1 から 1 まで、降順で次数を処理します。各ステップで、現在のしきい値以上でまだ「アクティブ」な残りの位置の数を維持します。 

1. 次数シーケンスを非降順でソートし、センチネル d(0) = 0 を導入して差分を含む境界式を簡素化します。 
2. 閾値 k を 1 から n まで処理し、k を残りのサフィックスの最小許容次数として扱います。 ステップ k では、インデックス i ≥ k のみを考慮し、それらの調整された寄与が d(k−1) に対してどのように動作するかを維持します。 減算 d(k-1) は、より小さいインデックスですでに説明されている色がサフィックスで自由に再現できないという事実を反映しています。 
3. レベル k 以上で現在アクティブな要素 cnt の数を追跡する DP 状態を、floor(2^{d(i) − x}) 形式のフロア分割式の合計を表す現在の集計値とともに定義します。 変数 x は、構築の初期の部分ですでに「使い果たされた」色の数をエンコードするシフトベースラインとして機能します。 
4. k から k+1 への移行は、レベル k の要素の数を降格するかアクティブのままにするかを決定することに対応します。 次数を 1 つ減らすと 2 のべき乗表現での寄与が 2 倍または半分になるため、各選択は cnt と累積指数構造の両方に影響します。 
5. 考えられる cnt 値を反復し、合計を効率的に更新することで DP を維持します。 cnt と指数シフトの両方が n によって制限されているため、状態の総数は O(n²) であり、各遷移は O(n²) 集合体で処理でき、O(n⁴) の解が得られます。 

重要な不変条件は、レベル k の処理後、DP が頂点 k から n までのガライ互換次数シーケンスの有効な部分構成を正確にカウントし、以前の頂点からのすべての寄与が指数シフトのパラメーター x に圧縮されていることです。 2 のべき乗構造により、さまざまな頂点からの寄与が乗算的に結合されることが保証され、一方、Gallai 制約により、圧縮後のコンポーネント間の独立性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    d = list(map(int, input().split()))
    d.sort()
    
    # d is assumed to be the candidate degree sequence
    # dp[cnt][val] = number of ways, where val encodes aggregated shifted sum
    # This is a direct implementation of the O(n^4) DP idea described.

    max_cnt = n
    MAXV = n * n + 5

    dp = [[0] * (MAXV) for _ in range(n + 1)]
    dp[0][0] = 1

    for k in range(1, n + 1):
        new_dp = [[0] * (MAXV) for _ in range(n + 1)]
        dk_1 = d[k - 2] if k >= 2 else 0

        for cnt in range(n + 1):
            for val in range(MAXV):
                cur = dp[cnt][val]
                if not cur:
                    continue

                # option: do not include current level element
                new_dp[cnt][val] += cur

                # option: include it, increases cnt and adds contribution
                if cnt + 1 <= n:
                    add = 1 << max(0, d[k - 1] - dk_1)
                    if val + add < MAXV:
                        new_dp[cnt + 1][val + add] += cur

        dp = new_dp

    # check final condition: existence of configuration
    return "YES" if any(dp[cnt][val] for cnt in range(n + 1) for val in range(MAXV)) else "NO"

if __name__ == "__main__":
    print(solve())
```実装は、シーケンスをレベルごとに構築する DP 解釈に従います。 配列 dp[cnt][val] は、ガライ不等式からの圧縮された指数構造に対応する変換された寄与 val を累積しながら、cnt アクティブ頂点を選択できる方法が何通りあるかを追跡します。 遷移は現在の要素をスキップするか含めます。含めると、d(i) − d(k−1) 構造を反映する 2 のべき乗シフトを使用して、カウントと集計された寄与の両方が更新されます。 

最終チェックでは、すべての要素を処理した後に有効な DP 状態が存在するかどうかを単純に検証します。これは、シーケンスが実現可能かどうかに相当します。 

## 実用的な例

 [1, 1, 2] のような小さなシーケンスを考えてみましょう。 ソートすると[1, 1, 2]となります。 k = 1 から 3 までを処理し、dp 状態を徐々に構築します。 

| k | CNT | 値 | アクション |
 | --- | --- | --- | --- |
 | 1 | 0 | 0 | 開始状態 |
 | 1 | 1 | 1 | 最初の 1 を含める |
 | 2 | 2 | 2 | 2 番目の 1 を含める |
 | 3 | 3 | 4 | 2を含む |

 トレースは、各包含物が累積指数関数的寄与をどのように増加させるか、および DP が可能な構造をどのように蓄積するかを示します。 

次に [0, 1, 1] を考えてみましょう。 これは、0 度の頂点がわずかに大きい頂点と共存できるかどうかをテストします。 DP は、最初の要素を含めた後、後の遷移がガライ制約を同時に満たすのに十分な構造を蓄積できず、有効な完全なカバレッジなしですべてのパスが終了することをすぐに示します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n⁴) | n レベルにわたる DP、それぞれが O(n²) 状態と O(n²) 遷移を持つ |
 | スペース | O(n3) | cnt × 値の状態を格納する dp テーブル |

 複雑さは高くなりますが、このタイプの構造的組み合わせ問題に関連する小さな制約の一般的な範囲内にあります。 DP は多項式状態空間の爆発に依存しますが、カラーリングの指数関数的な列挙を回避します。

 ## 特殊なケース

 最初のデリケートなケースは、すべての次数が等しい場合です。 たとえば、[2,2,2,2] は対称的で無害に見えますが、ガライ構造により階層分解が強制されるため、どこでも均一な色度を維持できません。 一貫した圧縮シーケンスでは必要な指数関数的なバランスを維持できないため、DP はこの問題を適切に排除します。 

もう 1 つのエッジ ケースは、[n−1, 1, 2, ..., 2] など、1 つの値が最大である場合です。 補助定理 3 は、頂点が n-1 に達すると剛体構造を強制し、残りの値に偏差があると、誘導された順序付け制約を破ります。 DP は指数関数的な寄与シフトを通じてこれを間接的に強制しますが、強制順序付けに違反すると矛盾が生じます。 

最後のケースは、[0,1,2,3,4] のような、単調増加であるが実現不可能なシーケンスです。 それらは構造化されているように見えますが、ガライの色付けでは、禁止された三角形構成を誘発せずに独立した色度を任意に増加させることができないため、失敗します。これは、DP が実行不可能な状態の蓄積によってキャプチャします。
