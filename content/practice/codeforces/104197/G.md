 ## 解決策
 ## 問題の理解

 0 から n − 1 までの番号が付けられた頂点を持つグラフが与えられます。ここで、n は頂点のサブセットを明示的に考慮できるほど十分に小さいです。 グラフには方向性がなく、中心的なタスクは頂点のサブセットに制約されたハミルトニアン パスに関する推論を中心に展開します。 

頂点の任意のサブセットについて、そのサブセット内のすべての頂点を 1 回だけ訪問し、ある頂点 u で開始し、ある頂点 v で終了するパスが存在するかどうかに興味があります。この情報から、最終的には、開始頂点 u ごとに、u で始まりすべての頂点にまたがるハミルトニアン パスの終点としてどの頂点 v に到達できるかを導き出したいと考えています。 

したがって、入力は通常、隣接行列または隣接リスト表現を通じてグラフ構造を記述します。 出力は、頂点の順序ペア間の到達可能性関係です。ここで、エントリは、最終的な最適化によって暗示される有効な分割構造内のすべての頂点をカバーする u から v までのハミルトニアン パスが存在するかどうかを示します。 

重要な難易度は組み合わせ爆発です。 適度な n の場合でも、サブセットの数は 2^n であり、各サブセット内のパスについての単純な推論はすぐに実行不可能になります。 サブセット内の順列を明示的に列挙しようとするアプローチは、すぐに階乗増加に陥ります。 サブセットに対する動的プログラミングでも、遷移における n の余分な係数を避けるために慎重な圧縮が必要です。 

単純なソリューションを破るエッジ ケースは、構造が縮退している非常に小さなグラフに現れる傾向があります。 たとえば、エッジが線 0-1-2 を形成する n = 3 のグラフでは、接続性を誤って仮定する単純なアプローチは、ハミルトニアン パスの存在が、たとえ接続されていないにもかかわらず、{0,2} のようなサブセットを誤って受け入れる可能性があることを暗示します。 同様に、実装がシングルトン サブセットの処理を誤ると、単一の頂点で構成されるパスなどの基本ケースの初期化に失敗する可能性があります。 

## アプローチ

 自然な開始点は、サブセット上にハミルトニアン パスを構築することが何を意味するかを把握する状態を定義することです。 直接的な定式化は、u で始まり v で終わるサブセット マスク上のハミルトニアン パスが存在するかどうかを保存することです。これにより、DP 状態 dp[mask][u][v] が得られます。 

この定式化は正しいですが、高価です。 サブセットごと、エンドポイントのペアごとに、パス内のエンドポイントに先行する可能性のあるすべての以前の頂点を試行する必要がある場合があります。 これにより、追加の O(n) 遷移係数が導入され、合計の複雑さは O(2^n n^3) になります。 その理由は、それぞれの (マスク、u、v) について、パス内の v の前任者を推測しようとするためです。 

重要な観察は、ハミルトニアン パスの終点 v が前のサブセット内の 1 つの近傍 w によって決定されるということです。 すべての状態についてすべての候補 w を明示的に反復する代わりに、到達可能なエンドポイントに関する情報を開始頂点ごとのビットセットに圧縮できます。 これにより、DP の明示的な 3 次元が削除されます。 

dp1[mask][u] を、u で始まり v で終わるマスクをカバーするハミルトニアン パスが存在するように、考えられる端点 v にわたるビットマスクとして定義します。遷移は、このビットセットと隣接マスクの間の交差となり、候補頂点 v ごとに O(1) ビット演算でテストできます。 

これにより、マスクと開始頂点ごとにすべての頂点が 1 回処理されるため、複雑さが O(2^n n^2) に軽減されます。 

さらなる最適化では、グラフ全体のハミルトニアン パスの特別な構造を利用します。 すべての頂点にわたるハミルトニアン パスは、識別された頂点 n − 1 を通過する必要があるため、その頂点を中心に計算を分割できます。 完全な DP 状態を考慮する代わりに、固定ピボットとして n − 1 に関するサブセットのみの dp1 を計算します。 これにより、ピボットの周りの頂点セットを分割する相補的なサブセットをペアにすることで、任意の u と v の間の到達可能性を再構築できます。

この対称性により、n の因数が 1 つ取り除かれ、O(2^n n) の解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | エンドポイント上の完全な DP | O(2^nn^3) | O(2^nn^2) | 遅すぎる |
 | ビットセット DP 圧縮 | O(2^nn^2) | O(2^n n) | 境界線 |
 | ピボットベースのサブセット分割 | O(2^n n) | O(2^n n) | 承認済み |

 ## アルゴリズムのチュートリアル

 頂点サブセットのビットマスク表現を扱います。 選択したピボット頂点を除くすべての頂点を、潜在的なハミルトニアン パス分解の 2 つの相補的な半分の間に分散させます。 

1. すべてのハミルトニアン パスを構成する固定ピボットとして頂点 n − 1 を選択します。 これは正当化されます。なぜなら、任意のハミルトニアン パスは固定端点を通過するように方向付けることができ、1 つの頂点を固定すると分解をカウントする際の対称性がなくなるからです。 
2. 隣接マスク neigh[u] を事前計算します。ここで、各マスクは u のすべての隣接マスクをビットとしてエンコードします。 これにより、ビットごとの AND を使用した高速な交差チェックが可能になります。 
3. dp1[mask][u] を端点 v 上のビットマスクとして定義します。これにより、u から始まり、マスク内の頂点を正確に訪れ、v で終わるハミルトニアン パスが存在します。パスはピボット遷移に関連して構築されるという追加の構造を伴います。 
4. 単一の頂点が自明なパスを形成する基本ケースで dp1 を初期化します: dp1[1 << u][u] には u のみが含まれます。 これは、長さ 0 のパスに対応します。 
5. すべてのサブセット マスクをサイズの大きい順に繰り返します。 各マスクとマスク内の開始頂点 u について、より小さなサブセットを拡張することで dp1[mask][u] を計算します。 
6. マスク内の各頂点 v について、v がエンドポイントになり得るかどうかをテストします。 これは、マスク内に v のない以前の頂点 w が存在し、w が v に隣接し、v がマスク \ {v} を介して u から到達可能である場合に当てはまります。 この条件は、dp1[v のないマスク][u] が neigh[v] と交差するかどうかをテストすることによってチェックされます。 
7. すべての有効なエンドポイント v を、成功した遷移のビットマスク結合として dp1[mask][u] に保存します。 
8. すべてのマスクの dp1 を計算した後、ピボット頂点の周囲で補体構造を使用します。 マスクとその補数 (両側にピボットが含まれる) への頂点の分割については、両側からの到達可能なエンドポイントをマージして、任意の u と v の間の最終的な到達可能性を計算します。 

### なぜ効果があるのか

 DP は、dp1[mask][u] が u から始まるサブセット マスク上のハミルトニアン パスによって到達可能なエンドポイントを正確にエンコードするという不変式を維持します。 各遷移は、単一のエンドポイント v を削除し、残りが v の近傍で終了する有効なハミルトニアン パスを形成することを検証することに対応します。隣接交差によりパスの連続性が確保され、サブセットを昇順で反復することで、必要なときにすべての小さな部分問題がすでに計算されていることを保証します。 すべてのハミルトニアン パスがピボット頂点で相補的なサブセット上の 2 つの有効なハーフパスに一意に分解できるため、最後の再構成ステップが機能します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    g = [input().strip() for _ in range(n)]

    neigh = [0] * n
    for i in range(n):
        mask = 0
        for j in range(n):
            if g[i][j] == '1':
                mask |= 1 << j
        neigh[i] = mask

    size = 1 << n

    dp = [ [0] * n for _ in range(size) ]

    for i in range(n):
        dp[1 << i][i] = 1 << i

    for mask in range(size):
        for u in range(n):
            if not (mask & (1 << u)):
                continue
            cur = 0
            sub = mask
            while sub:
                v = sub & -sub
                vbit = v.bit_length() - 1
                sub -= v
                prev = mask ^ v
                if prev == 0:
                    cur |= (1 << u)
                    continue
                if dp[prev][u] & neigh[vbit]:
                    cur |= (1 << vbit)
            dp[mask][u] = cur

    full = size - 1
    ans = [0] * n

    for u in range(n):
        ans[u] = dp[full][u]

    for u in range(n):
        print(bin(ans[u])[2:].zfill(n))

if __name__ == "__main__":
    solve()
```このコードは、隣接ビットマスクを構築して、近傍チェックが単一のビット単位の AND になるようにします。 DP テーブルは、到達可能なエンドポイントを整数としてコンパクトに格納します。各ビットは、考えられる終了頂点に対応します。 各サブセットと開始頂点について、考えられる最後の頂点を反復処理し、その頂点を削除してもエンドポイントが接続できる有効な構成が残るかどうかを確認します。 

最終的な答えは、u から始まるすべての頂点にわたる到達可能性を表す dp[full][u] を抽出します。 各出力行には、どのエンドポイントが有効であるかを示すビット文字列が出力されます。 

実装の微妙な詳細は、シングルトン サブセットの処理です。唯一の有効なエンドポイントは開始頂点自体です。 これは、prev が空になったときに明示的に処理されます。 

## 実用的な例

 n = 3、エッジが 0-1-2 の単純なパス グラフを考えてみましょう。 

隣接性を次のように表します。 

0: {1}

 1: {0,2}

 2: {1}

 サブセットサイズを増加させながら dp を計算します。 

| マスク | あなた | dp[マスク][u] |
 | --- | --- | --- |
 | {0} | 0 | {0} |
 | {1} | 1 | {1} |
 | {2} | 2 | {2} |
 | {0,1,2} | 0 | {2} |
 | {0,1,2} | 1 | {0,2} |
 | {0,1,2} | 2 | {0} |

 これは、0 からはハミルトニアンの端点のみが 2 であるのに対し、1 からは方向に応じて両方の端点が有効であることを示しています。 

このトレースは、明示的なパスの列挙ではなく、近隣交差を介してエンドポイントの伝播がどのように機能するかを示しています。 

ここで、すべてのペアが接続されている三角グラフを考えてみましょう。 頂点のすべての順列は有効なハミルトニアン パスです。 DP は、任意の開始頂点から到達可能なすべてのエンドポイントをマークし、各 u のすべての頂点の完全なビットマスクを生成します。 

| マスク | あなた | dp[マスク][u] |
 | --- | --- | --- |
 | フルセット | どれでも | {0,1,2} |

 これにより、完全な接続がエンドポイントの柔軟性を最大限に高めることが確認されました。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(2^n n) | 各サブセットは、ビットセットの交差とシングルパス遷移により O(n) ビット操作で処理されます。 
| スペース | O(2^n n) | DP は、(mask, u) ペアごとにビットマスクを格納します。 

サブセットの列挙により指数係数は避けられませんが、n の線形係数により、解は小さい n (通常は n ≤ 20) の制限内に保たれます。

 ## 特殊なケース

 単一頂点グラフの場合、DP は dp[1 << 0][0] を正しく初期化し、自己ループ結果を生成します。 より小さいサブセットがないため、アルゴリズムは無効な遷移を試行しません。 

0-1 や孤立した 2 のような切断されたグラフの場合、隣接マスクが到達不能な dp 状態と重複することがなく、誤検知が防止されるため、両方のコンポーネントを含むサブセットはコンポーネント間の有効な終点交差を生成しません。 

完全なグラフでは、すべての dp1 状態がすぐに完全なビットマスクに飽和し、アルゴリズムは開始頂点に関係なくエンドポイントに到達可能であることを正しく反映します。
