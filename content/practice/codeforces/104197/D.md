 ## 解決策
 ## 問題の理解

 仮説的なグラフ内のノード間のペアごとの距離の完全な説明が与えられていますが、問題となるのはそれらの距離のパリティだけです。 すべての頂点のペアについて、それらの最短経路距離が奇数であるか偶数であるかがわかります。タスクは、実際の最短経路距離がまったく同じパリティ パターンを生成する無向グラフが少なくとも 1 つ存在するかどうかを判断することです。 

したがって、出力は二者択一です。つまり、最短経路距離のパリティがすべてのペアの指定された仕様に一致するグラフを構築できるか、構築できないかのどちらかです。 

主な困難は、重み付けされた自由度を備えた特定のグラフを構築しているのではなく、全ペアの最短パスに対するグローバル パリティ制約が、基礎となる重み付けされていないグラフ構造と一致するかどうかを検証していることです。 

元の問題ステートメントによって暗示される制約は、3次フロイド・ウォーシャル形式の推論が可能であることを示唆しているため、ノードの数が十分に少ないため、すべてのペアに関する推論またはすべてのペアの最短経路緩和の実行が許容されます。 これは、約 O(n^3) よりも悪いものを必要とするアプローチを即座に除外し、ペアごとの整合性チェックまたは推移閉包スタイルの推論が中心であることを強く示唆しています。 

ローカル パリティ制約は一貫しているが、グラフ メトリックに埋め込むことがグローバルに不可能である場合、微妙な失敗ケースが発生します。 

検出する必要がある不一致の簡単な例は、3 つのノードが矛盾するパリティ要件のサイクルを形成する場合です。 たとえば、ノード 1、2、3 があり、必要なパリティが dist(1,2) が奇数、dist(2,3) が奇数であるが、dist(1,3) も奇数であることを暗示しているとします。 重み付けされていないグラフでは、チェーンされた 2 つの奇数長の最短パスは通常、連結を介してエンドポイント間の偶数パリティを強制するため、このような構成は中間構造に応じて実現可能である場合と不可能である場合があります。 アルゴリズムは、このような全体的な矛盾が存在するかどうかを検出する必要があります。 

## アプローチ

 ブルートフォース解釈では、グラフを構築し、その最短経路距離が必要なパリティ行列と一致するかどうかを検証します。 考えられるすべてのエッジを試し、最短パスを計算し、パリティの一致をチェックすることができます。 重み付けされていないグラフに限定したとしても、グラフの探索空間は 2^{n(n-1)/2} であり、1 つの候補を検証する場合でも、全ペアの最短経路の計算が必要です。 これはまったく実現不可能です。 

より構造化されたブルート フォース アプローチは、候補グラフを仮定し、各ノードから BFS を使用してすべてのペアの最短パスを計算し、パリティ行列を比較することです。 これにより、候補グラフごとのチェックが O(n(n + m)) に削減されますが、グラフの構築または検索の問題は依然として残ります。 

重要な点は、実際にはグラフを明示的に構築する必要がないということです。 問題のステートメント自体は、建設的な変換を示唆しています。必要な距離パリティが奇数である頂点のペアごとに、それらの間にエッジを追加することを想像できます。 これは必ずしも最終的なグラフではありませんが、便利な方法でパリティ制約を保存する正規スーパーグラフを作成します。 

重要な考え方は、パリティ制約が最短パス構造上の二分割条件のように動作するということです。 距離を mod 2 で解釈すると、すべてのエッジがパリティを反転し、最短パス パリティは、2 つのノードが、ある BFS ツリーに対して同じパリティ層にあるか反対側のパリティ層にあるかに相当します。 これは、この構造が基本的に、暗黙のパリティ関係が最短パス層によって引き起こされる有効な 2 カラーリングと一致しているかどうかをチェックしていることを示唆しています。

「奇数の距離のペア」をパリティ閉鎖の意味で隣接性が必要なものとして扱うと、結果として得られる誘導グラフが一貫しているかどうかをチェックすることに問題を縮小できます。これは、BFS レイヤ化での接続性とパリティの一貫性になります。 これは、Floyd-Warshall またはマルチソース BFS パリティ伝播を実行し、矛盾をチェックすることで検証できます。 

最後の単純化は、パリティ制約を 0/1 でラベル付けされた完全なグラフとして扱い、パリティが最短パス パリティと等しいグラフ メトリックにノードを埋め込むことを試みることです。 これは、最短パス層の一貫した割り当てが存在するかどうかをチェックすることと同等であり、クロージャの一貫性を介して O(n^3) で検証できます。

 | --- | --- | --- | --- |
 | ブルート フォース グラフ構築 + APSP | O(2^{n^2} · n^3) | O(n^2) | 遅すぎる |
 | フロイド-ウォーシャルのパリティの一貫性 | O(n^3) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 与えられたパリティ行列を最短経路距離にわたる制約システムとして扱います。 

1.行列を初期化する`d`どこ`d[i][j]`必要なパリティが偶数の場合は 0、奇数の場合は 1 です。 この行列は、グラフ内の最短パス パリティを使用して満たしたい制約を表します。 
2. Floyd-Warshall と同様のクロージャ プロセスを実行しますが、数値的な距離ではなくパリティの実現可能性に基づいて動作します。 トリプルごとに`(i, j, k)`からの最短経路がある場合、と解釈します。`i`に`k`そしてから`k`に`j`、次にからのパリティ`i`に`j`パスに沿ったパリティの合計と一致している必要があります。 
3. 推移性を強制して制約を更新する: パリティ関係がわかっている場合`i -> k`そして`k -> j`、 それから`i -> j`等しい必要があります`(i -> k + k -> j) mod 2`。 以前に設定された値がこの導出された値と矛盾するという矛盾が発生した場合、設定は不可能になります。 
4. 奇数パリティによって暗示されるエッジを接続性を強制する関係として扱うことにより、接続性の一貫性を同時に確保します。 暗黙の構造でいずれかのノードが到達不能になった場合、その構成は無効になります。 
5. クロージャが完了したら、すべての制約がすべてのトリプルにわたって一貫しているかどうかを確認します。 矛盾がなければYESを出力し、矛盾がなければNOを出力します。 

なぜ効果があるのか

 重み付けされていないグラフ内の最短パスのパリティは、メトリック換算法 2 のように動作します。これにより、すべての中間ノードがパスに沿ってパリティの加法性を強制する制約システムが誘導されます。 Floyd-Warshall スタイルのクロージャは、最短パスを定義できるすべての可能な中間ノードを列挙します。 パリティ制約が実現可能な場合、すべての中間でのクロージャは一貫性を保たなければなりません。 クロージャ中に発見された矛盾は、どのグラフ メトリックにも埋め込むことができないパリティ制約の不可能なサイクルに対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    g = [list(map(int, input().split())) for _ in range(n)]

    # interpret as parity constraints (0 = even, 1 = odd)
    d = [[g[i][j] % 2 for j in range(n)] for i in range(n)]

    # consistency matrix
    ok = True

    for k in range(n):
        for i in range(n):
            for j in range(n):
                via = (d[i][k] + d[k][j]) & 1
                if d[i][j] != via:
                    # if already assigned and conflict arises, impossible
                    ok = False
                d[i][j] = via

    print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
```奇数または偶数の性質のみが重要であるため、コードは、指定されたすべてのペア値をパリティ情報に分解することから始まります。 次に、トリプル ループ クロージャを適用し、各ノードを最短パス分解の潜在的な中間点として扱います。 各反復では、パリティが中間ノードを介して一貫して伝播する必要があります。 矛盾が検出された場合、システムは無効とマークされます。 

課題`d[i][j] = via`一貫したパリティ パスが中間ノードを通じて検出されると、それが前方に伝播されるため、後の反復は安定した制約システムで動作します。 旗`ok`以前の割り当てが、後の暗黙の構造によって違反されているかどうかを追跡します。 

## 実用的な例

 ### 例 1

 3 つのノードによる小規模で一貫した構成を考えてみましょう。 

入力パリティ行列:```
0 1 1
1 0 0
1 0 0
```閉鎖を追跡します:

 | k | 私 | j | [i][k] | d[k][j] | |経由 | 前に d[i][j] 衝突 |
 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 0 | 1 | 2 | 1 | 1 | 0 | 0 | いいえ |
 | 1 | 0 | 2 | 1 | 0 | 1 | 1 | いいえ |

 伝播後は矛盾が生じないため、出力は YES となります。 

これは、パリティ制約が推移的伝播の下でグローバルに一貫している構成を示しています。 

### 例 2

 矛盾した構成:

 入力:```
0 1 1
1 0 1
1 1 0
```ここでは、すべてのペアが奇数になるように制約されます。 

| k | 私 | j | [i][k] | d[k][j] | |経由 | 前に d[i][j] 衝突 |
 | --- | --- | --- | --- | --- | --- | --- | --- |
 | 0 | 1 | 2 | 1 | 1 | 0 | 1 | はい |
 | 1 | 0 | 2 | 1 | 1 | 0 | 1 | はい |

 複数のステップでは、必要なパリティは中間ノードを介して 0 に戻りますが、直接制約では 1 が要求されます。この矛盾により拒否が発生します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^3) | すべての中間ノードにわたるトリプルネストされたクロージャ |
 | スペース | O(n^2) | パリティ行列の保存 |

 三次複雑さは、意図したフロイド ウォーシャル スタイルの解空間と一致し、問題ステートメントによって暗示される制約に適切です。

    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

        for i in range(n):

                d[i][j] = via

assert run("1\n0\n") == "YES", "single node"

# consistent small case
assert run("2\n0 1\n1 0\n") == "YES", "simple bipartite parity"

# inconsistent triangle
assert run("3\n0 1 1\n1 0 1\n1 1 0\n") == "NO", "all odd triangle impossible"

# all zero
assert run("3\n0 0 0\n0 0 0\n0 0 0\n") == "YES", "all even trivial"

# mixed consistent
assert run("3\n0 1 0\n1 0 1\n0 1 0\n") == "YES", "path structure"

 ## 特殊なケース

 エッジ ケースの 1 つは、すべての非対角エントリが 1 である場合です。これは、すべてのペアが奇数の距離を持つ必要があることを意味します。 クロージャを実行すると、中間体を介してパリティの伝播が繰り返され、完全な制約システムの三角形分解では奇数パリティの一貫性を保つことができないため、最終的にシステム自体が矛盾します。 

もう 1 つのケースは、パリティ形式に埋め込まれた、まばらに見えるが一貫した二部構造のような構造です。 例えば：```
0 1 0
1 0 1
0 1 0
```ここで、中間パリティ合計がすでに直接制約と一致しており、矛盾が現れないため、クロージャーはすぐに安定します。 

最後のエッジ ケースは、行列が自明に一貫している単一ノード グラフです。 三重反復で矛盾が生じず、初期状態がすでに閉包を満たしているため、アルゴリズムはこれを正しく処理します。
