 ## 解決策
 ## 問題の理解

 完全なグラフが表示されます。$n$これは、頂点のすべてのペアがエッジによって接続されていることを意味します。 この密な構造から、スパニング ツリーを繰り返し抽出することができますが、選択した 1 つのツリーでエッジが使用されると、他のツリーでは再度使用することはできないという制限があります。 頂点は全体的に利用可能なままですが、エッジは永続的に消費されます。 

抽出された各スパニング ツリーには、その直径に等しいコストがあり、これは、そのツリー内の 2 つの頂点間の最大の最短パス距離を意味します。 可能な限り多くのエッジ分離スパニング ツリーを抽出することが求められますが、この最大数を達成するすべての方法の中で、直径の合計を最小化する必要があります。 

主な困難は、単一のツリーを最適化しているのではなく、エッジが互いに切り離されたスパニング ツリーのコレクションを最適化していることです。そのため、エッジの密度がどの程度であるかを推論する必要があるためです。$K_n$構造を制御しながらツリーに分割できます。 

制約$n \le 1000$すでに、ツリーを列挙したり、複数の構造にわたる組み合わせ検索を試みたりすることは期待されていないことがわかります。 すべてのスパニング ツリーについて明示的に推論しようとするアプローチは、直ちに実行不可能になります。これは、完全なグラフ内のスパニング ツリーの数が増加するにつれて増加するためです。$n^{n-2}$。 

微妙なエッジケースが現れるのは、$n=2$。 エッジは 1 つだけなので、存在するスパニング ツリーは最大 1 つで、その直径は自明のことながら 1 です。「中心頂点」を想定するか、少なくとも 3 つの頂点を必要とする構築では、これを明示的に処理する必要があります。 

もう一つの重要なコーナーは、$n=3$。 ここで、エッジが分離された 2 つのスパニング ツリーには少なくとも 1 つのスパニング ツリーが必要となるため、存在できるスパニング ツリーは 1 つだけです。$2(n-1)=4$エッジですが、$K_3$エッジが 3 つしかありません。 これは、答えが構造的な列挙ではなくエッジのカウントに密接に関連していることをすでに示唆しています。 

## アプローチ

 最も直接的な解釈から始めます。 上のスパニングツリー$n$頂点は正確に使用します$n-1$エッジ。 もし望むなら$k$エッジ非結合スパニング ツリーを使用する必要があります。$k(n-1)$明確なエッジ$K_n$、それは$\frac{n(n-1)}{2}$エッジ。 これによりすぐに上限が決まります。$$k \le \left\lfloor \frac{n}{2} \right\rfloor.$$したがって、最初の隠れた構造は、スパニング ツリーの数を最大化する問題は基本的にエッジ分割の問題であるということです。 その限界を受け入れると、問題は実際に構築できるかどうかになります。$\lfloor n/2 \rfloor$木々にまたがる。 

単純に構築しようとすると、貪欲にスパニング ツリーを構築し、そのエッジを削除して、それを繰り返す可能性があります。 これは原理的には正しいですが、最適性と最小直径合計の両方を保証できるほど十分に制御されていません。 特に、貪欲なツリーは長いパスになり、大きな直径を生成し、エッジの構造化された再利用を妨げる可能性があります。 

重要な観察は、完全なグラフでは、頂点の一致を中心にペアのスパニング ツリーを意図的に設計できるということです。 いつ$n$が偶数であれば、頂点をペアにすることができます$(1,2), (3,4), \dots$。 各ペアは木の「ベース エッジ」として機能し、残りの頂点は構造化された方法で接続できるため、木が重なり合わず、直径が小さいままになります。 いつ$n$は奇数であり、1 つの頂点がペアリングで省略され、当然、それに関係するすべての構築において中心的な接続点になります。 

より深い構造的洞察は、エッジを分解できるということです。$K_n$の中へ$\lfloor n/2 \rfloor$頂点の役割を回転させることにより、星状またはほぼ星状のスパニング ツリーを作成できます。 各ツリーは基本的に異なるペアリング パターンに基づいて構築されており、直径を最小限 (通常はパリティ制約に応じて 2 または 3) に保ちながら、エッジの切り離しを保証します。 

ブルートフォースアプローチでは、エッジのパーティションを列挙してスパニングツリーにしようとしますが、スパニングツリーは超指数関数的に成長します。$n^2$、実現可能性をはるかに超えています。 建設的なペアリングのアプローチにより、エッジの素性とスパニング接続性の両方を保証する決定論的なパターンに頂点を配置するという問題が軽減されます。

 ## アルゴリズムのチュートリアル

 まず最大数のスパニング ツリーを構築し、それからそれらを明示的に構築します。 

1. コンピューティング$k = \lfloor n/2 \rfloor$。 これは、各スパニング ツリーが消費するという事実から直接得られます。$n-1$エッジの合計を超えることはできません。$K_n$。 
2. 頂点を次のようにペアリングします$(1,2), (3,4), \dots, (2k-1, 2k)$。 もし$n$奇数です、頂点です$n$ペアリングされていない状態のままです。 このペアリングは、コア エッジの分離を保証するため、構造のバックボーンとなります。 
3. ペアごとに$(2i-1, 2i)$、1つのスパニングツリーを構築します。 ツリーを端から始めます$(2i-1, 2i)$。 これにより、各ツリーが一意の専用エッジを持つことが保証され、基本レベルでのエッジの非結合性が保証されます。 
4. 他のすべての頂点を、ツリー全体でエッジを再利用することを避ける一貫した方法でこの基本構造に接続します。 たとえば、木の場合$i$、頂点を接続します$v$どちらかに$2i-1$または$2i$パリティやインデックスの比較などの決定的なルールに応じて。 目的は、別のツリーで使用されているエッジを再利用せずに接続を確保することです。 
5. すべての頂点がツリーごとに 1 つの接続された構造に正確に表示されること、および正確に$n-1$エッジが使われています。 すべての頂点をベースペアに接続するだけでサイクルなしで接続するため、構築では常にツリーが生成されます。 
6. 構築されたすべてのエッジをツリーごとに出力します。 

### なぜ効果があるのか

 正しさは 2 つの特性に基づいています。 まず、各ツリーは、互いに素な頂点のペアからの一意のベース エッジを使用するため、ツリー間でエッジが再利用されることはありません。 第 2 に、追加の接続はすべて、ベース ペアに付随するエッジを常に使用する決定論的な方法で行われます。これにより、各ツリーには個別のベース ペアがあるため、ツリー間の衝突が確実に発生しません。 

すべての頂点が基本構造にアタッチされているため、接続性が保証され、各非基本頂点が 1 つの親エッジとともに追加されるため、非循環性が維持されます。 したがって、すべての構造はスパニング ツリーになります。 正確に達成しているので、$\lfloor n/2 \rfloor$これがエッジ数の上限と一致すると、最適性が続きます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    k = n // 2
    
    # store edges for each tree
    trees = [[] for _ in range(k)]
    
    # build pairing-based construction
    for i in range(k):
        a = 2 * i + 1
        b = 2 * i + 2
        
        # base edge of tree i
        trees[i].append((a, b))
        
        # attach remaining vertices
        for v in range(1, n + 1):
            if v == a or v == b:
                continue
            # deterministic attachment avoiding reuse pattern
            # connect based on parity relative to tree index
            if v % 2 == 1:
                trees[i].append((a, v))
            else:
                trees[i].append((b, v))
    
    # output
    print(k)
    for i in range(k):
        for u, v in trees[i]:
            print(u, v)

if __name__ == "__main__":
    solve()
```コードは、ツリーの最大数を半分として計算することから始まります。$n$。 各ツリーには、構造上のアンカーとして機能する一意の頂点ペアが割り当てられます。 次に、この構築では、決定論的なパリティ ベースのルールを使用して、1 つおきの頂点をこのペアの 1 つのエンドポイントに接続します。 これにより、ツリー内ではすべての頂点が接続され、各ツリーのアタッチメントは常にその一意のペアに付随するため、ツリー全体でエッジが再利用されることはありません。 

重要な実装の詳細は、各ツリーが正確に終わる必要があるということです。$n-1$エッジ。 アンカー以外の頂点を常にツリーごとに 1 回だけ接続するため、この不変式は自動的に成り立ちます。

 ## 特殊なケース

 のために$n=2$、アルゴリズムは次のように計算します。$k=1$正確に 1 つのエッジを生成します。 ペアリングステップでは単一のペアが作成されます$(1,2)$であり、それ以上の添付ファイルは存在しないため、出力は自明ながら正しいものになります。 

のために$n=3$、$k=1$再び頂点 (1,2) がベースを形成し、頂点 3 が 1 つの端点に接続されます。 結果として得られる構造はスターであり、これはエッジ非結合パッキングの点で唯一可能なスパニング ツリーです。 

偶数の場合$n$、すべての頂点は正確に 1 つの塩基対に参加するため、構造化されていない頂点は存在しません。 構造は均一にスケールされ、正確に生産されます$n/2$ツリーは、それぞれが決定論的なアタッチメントを通じてすべての頂点に独立して広がり、素性と接続性の両方を維持します。
