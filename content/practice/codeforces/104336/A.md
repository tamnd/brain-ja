 ## 問題の理解

 私たちはパスカルの三角形を使用しています。各行は隣接するペアを追加することによって前の行から構築され、エッジは常に 1 です。各行は 0 から始まるインデックスが付けられ、行内の位置も 0 からインデックスが付けられます。 

通常の作図問題とは逆のタスクになります。 三角形を構築する代わりに、数字が与えられます。`n`そしてそれが無限のパスカル三角形のどこかに現れるかどうかを尋ねました。 表示された場合は、有効なペアを返す必要があります。`(row, position)`その値が発生する場所。 表示されない場合は出力します`-1`。 

重要な問題は、三角形の幅と値が非常に速く増加することですが、入力`n`比較的小規模で、最大でも 100 万です。 これは、二項係数がこの範囲をはるかに超えて急速に増加するため、三角形のはるか下にある任意の組み合わせ値を扱うことができないことをすぐに示唆しています。 したがって、有効なソリューションは、深い列挙ではなく、小さな行の構造または初期の繰り返しパターンに依存する必要があります。 

素朴な解釈では、値が次の値を超えるまで行を生成することになります。`n`しかし、これには微妙な落とし穴が隠されています。パスカルの三角形の値の大きさは急速に増加しますが、小さな値は特定の位置でのみ再表示され、次のような値もあります。`1`または`2`が何列にも出てきます。 不注意なジェネレーターは、行のプレフィックスのみを追跡する場合、停止が早すぎたり、有効なオカレンスを見逃したりする可能性があります。 

値が小さい場合、エッジ ケースがすぐに表示されます。 のために`n = 1`に存在します。`(0,0)`すべての行境界にもあります。 のために`n = 2`に表示されます。`(2,1)`そして`(2,0)`対称性に関してだけでなく、後の大きな行でも同様です。`(3,1)`または`(3,2)`? 実はパスカルの三角形では、`2`は行 2 以降の特定の二項係数でのみ表示されるため、値が行ごとに一意であるという誤った仮定は誤った枝刈りにつながります。 もう一つのエッジケースは、`n = 0`これは入力ドメインの一部ではありませんが、正のエントリのみが重要であることを思い出させます。 

最も重要な隠れた制約は、パスカルの三角形の値が二項係数であるということです。`n ≤ 10^6`、そのような値を含めることができるのは非常に小さな行のみです。 この観察により、問題は扱いやすくなります。 

## アプローチ

重要な観察は、二項係数が非常に急速に増加するということです。 中心二項係数`C(r, r/2)`およそ`2^r / sqrt(r)`。 これは超えます`10^6`その周り`r ≈ 20`。 つまり、すべての値が次の値よりも大きくなる前に、数十行程度の非常に少数の行を検索するだけで済みます。`n`。 したがって、境界のない三角形を構築する代わりに、値が次の値を超えるまでシミュレーションするだけです。`n`、作業を小さく抑えます。

 ## アルゴリズムのチュートリアル

 パスカルの三角形を行ごとに構築しますが、行が大きすぎて含められない場合は早めに停止します。`n`。 

1. 行から始める`0 = [1]`。 これは三角形の底辺であり、当然ながら値が 1 つだけ含まれます。 もし`n == 1`、すぐに戻れます`(0, 0)`これは最初の行の唯一の要素であるためです。 
2. 後続の各行について`r`、標準の繰り返しを使用して前の行から構築します。 最初と最後の要素は常に`1`、すべての内部要素は、前の行の 2 つの隣接する要素の合計です。 
3. 行の作成中に、すぐに各値を確認します。 いずれかの要素が等しい場合`n`、 戻る`(r, c)`どこ`c`はその要素のインデックスです。 有効な事象が見つかったら、問題はあらゆる答えを許容するため、この早期の終了は非常に重要です。 
4. 次の行を作成する前に、その行の最大値が依然として許容できるかどうかを確認します。`n`それ以下。 値が急速に増加するため、すべてのエントリがこの値を超えた時点で安全に停止できます。`n`これは、二項係数の指数関数的な増加により非常に急速に発生します。 

この正しさは、パスカルの三角形のすべての要素が二項係数であり、そのようなすべての係数がこの構造によって 1 回だけ生成されるという事実から得られます。 三角形の領域をスキップするのではなく、有効な答えがそれを超えて見逃されないことを保証する値の境界に基づいて深さを制限しているだけです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input().strip())

if n == 1:
    print("0 0")
    sys.exit()

prev = [1]

if n == 1:
    print("0 0")
    sys.exit()

for r in range(1, 60):
    cur = [1]
    found = False

    if n == 1:
        print(f"{r} 0")
        sys.exit()

    for i in range(1, r):
        val = prev[i - 1] + prev[i]
        cur.append(val)

    cur.append(1)

    for i, v in enumerate(cur):
        if v == n:
            print(r, i)
            sys.exit()

    if min(cur) > n:
        break

    prev = cur

print(-1)
```このソリューションでは、再帰関係を使用して行を直接構築します。 値は指数関数的に増加し、長期間小さいままではいられないため、外側のループは行数を安全な定数境界に制限します。 各行は前の行から線形時間で構築され、すべての値が次と等しいかどうか直ちにチェックされます。`n`。 

微妙な点は、行内のすべての値が次の値を超えると早期に終了することです。`n`パスカルの三角形の加法構造により、後続の行では値がさらに増加するだけであるためです。 もう 1 つの重要な点は、行境界の処理です。値は常に`1`。 これらは明示的に追加されるため、省略してはなりません。省略しないと、三角形構造が壊れます。
