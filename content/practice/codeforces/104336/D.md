 ## 解決策
 ## 問題の理解

 それぞれ整数の高さを持つバラの列が与えられています。 個人の身長を何度でも 1 増やすことができ、増加ごとに 1 単位のコストがかかります。 目標は、すべてのバラがローカル パリティ条件を満たすようにすることです。エッジではないバラの場合、その 2 つの隣接するバラは互いに同じパリティを持たなければなりません。 最初と最後のバラは、隣接するバラに関係なく、自動的に有効とみなされます。 

条件はローカルですが、位置ごとに独立していません。 1 つの変更が隣接する 2 つの有効性チェックに影響を与える可能性があるため、配列の構造はグローバルに重要になります。 タスクは、配列全体を有効にするために必要な +1 演算の最小合計数を見つけることです。 

n が 100000 までの制約により、考えられるすべての増分やパターンを試行する指数関数や二次関数のアプローチは即座に除外されます。 構成ごとの O(n^2) 推論でも遅すぎます。 配列には 1 回のパスまたは一定数のパスしかないため、解は線形または線形に近いもの (おそらく O(n)) である必要があります。 

すべての要素がすでに条件を満たしている場合、微妙なエッジ ケースが発生します。 たとえば、[5, 4, 5] や [5, 5, 5] のような配列では、すべての内部位置に一致するパリティを持つ隣接位置がすでに存在するため、操作は必要ありません。 もう 1 つのエッジ ケースは、[3、12、4、6、2、3、3] など、1 つの位置の固定がカスケードする可能性がある交互パリティ構造です。この場合、局所的な不一致が頻繁に発生しますが、最小限の増分で解決できます。 

単純な間違いは、増分がパリティ変更を前方にどのように伝播するかを考慮せずに、1 つの隣接要素または中間要素を調整することで、各無効な位置を個別に修正することです。 

## アプローチ

 ブルートフォース解釈では、すべての内部位置がパリティ制約を満たすまで、要素を増やすあらゆる方法をシミュレートしようとします。 各要素は任意に増やすことができるため、状態空間には制限がありませんが、実際にはパリティ クラスによって値を制限することが考えられます。 その場合でも、素朴なアプローチでは、最終的な配列のすべてのパリティ割り当てを試行し、それらの値に到達するまでに必要な増分数を計算しようとする可能性があります。 これは、n で指数関数的な最終パリティまたは構造のすべての割り当てを考慮することになります。 

これは失敗します。各位置の値はその前に適用された増分の数に依存するため、位置を個別に扱うと変更の伝播が捕捉されません。 

重要な観察は、この条件が隣接するペアのパリティのみに依存し、単一要素の反転パリティのみを増加させるということです。 各操作でパリティが切り替わるので、すべての内部インデックス i が最終状態で a[i-1] % 2 == a[i+1] % 2 を満たすように、最終的なパリティを配列に割り当てようとしています。 

これは、有効な各構成が 2 番目の要素間で一貫性を持たなければならないことを意味します。これにより、配列が奇数インデックスと偶数インデックスの 2 つの独立したパリティ チェーンに自然に分割されます。 この分離が認識されると、各位置がどのような最終パリティを持つべきかを決定することによって、各チェーンを個別に調整できます。 コストは、初期パリティを選択したターゲット パリティに反転するのに必要な増分数であり、各反転には 1 操作のコストがかかります。 

したがって、問題は、距離 2 の関係全体で一貫性を確保するグローバル制約を尊重しながら、インデックスごとに最適なパリティ割り当てを個別に選択することに帰着します。

 ## アルゴリズムのチュートリアル

1. 概念的に、インデックス パリティに基づいて配列を 2 つのグループに分割します。1 つのグループにはインデックス 1、3、5 が含まれ、もう 1 つのグループには 2、4、6 が含まれます。制約では常に同じグループに属する i-1 と i+1 が比較されるため、これは自然なことです。 
2. グループごとに、そのグループ内のすべての要素を偶数にするか、すべて奇数にするかを決定します。 各操作でパリティが反転されるため、各要素は独立して 0 コスト (すでにターゲット パリティと一致している) または 1 コスト (反転するには 1 つの増分が必要) のいずれかに寄与します。 
3. 両方の選択肢で各グループのコストを計算します。 たとえば、奇数インデックス グループの場合、すでに偶数である要素の数と、すでに奇数である要素の数を計算します。 ターゲットパリティを選択するということは、不一致の数を支払うことを意味します。 
4. 各グループについて、可能な 2 つのターゲット パリティの選択肢のうち最小のものを選択します。 これにより、そのグループに最適なコストが得られます。 
5. 両方のグループの最適コストを合計します。 この合計は、必要な最小増分数です。 

重要な推論ステップは、インデックスが 2 つの独立したチェーンに分割されると、一方のチェーンともう一方のチェーンのパリティ ターゲットの選択の間に相互作用がなくなるということです。 グローバル制約は、各チェーン内の内部整合性のみを強制します。 

### なぜ効果があるのか

 すべての有効な最終構成では、各パリティ クラスのすべてのインデックスが、距離 2 の伝播までの単一のパリティ割り当てと一致するようにする必要があります。 1 つのチェーンに違反があると、すぐに中間インデックスの条件に違反します。 インクリメントはパリティにローカルでのみ影響するため、コストはインデックスごとに独立した決定にきれいに分解され、各インデックスは、選択したターゲット パリティに一致するかどうかに応じて、正確に 0 または 1 に寄与します。 したがって、グループごとに独立して最小化すると、全体的な最適値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    # count parity mismatches for indices 0 and 1 groups
    # group 0: indices 0,2,4,...
    # group 1: indices 1,3,5,...
    
    cnt = [[0, 0], [0, 0]]  # cnt[group][parity]
    
    for i, x in enumerate(a):
        g = i % 2
        p = x % 2
        cnt[g][p] += 1
    
    # for each group, choose best target parity
    def best(group):
        # make all even or all odd
        return min(cnt[group][0], cnt[group][1])
    
    print(best(0) + best(1))

if __name__ == "__main__":
    solve()
```この実装は、パリティごとにインデックスをグループ化し、各グループ内で既に偶数または奇数になっている要素の数をカウントすることに依存しています。 グループごとに、すべての要素を強制的に偶数にするか、すべてを奇数にするコストを評価し、より安価なオプションを選択します。 最終的な答えは合計です。 

ここでよくある間違いは、反復中に配列の更新をシミュレートしようとすることです。 グループ化の洞察が適用されると、各要素の寄与は独立するため、これは不要です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    
    n = int(input())
    a = list(map(int, input().split()))
    
    cnt = [[0, 0], [0, 0]]
    for i, x in enumerate(a):
        cnt[i % 2][x % 2] += 1
    
    return str(min(cnt[0][0], cnt[0][1]) + min(cnt[1][0], cnt[1][1]))

## Edge Cases

One edge case is a single element array. Since there are no neighbors to validate, the answer must always be zero. The algorithm handles this naturally because one group will be empty and the other will contain a single parity count, and the minimum mismatch is zero.

Another case is a two-element array like [1, 2]. There is no middle element to violate the condition, so again zero cost is correct. The grouping logic still assigns each element to its own parity class, and both classes can be left unchanged.

A more illustrative case is an alternating array such as [1, 2, 3, 4]. Group 0 contains 1 and 3, group 1 contains 2 and 4. Each group has mixed parity, so one flip per mismatch is required. The algorithm correctly counts mismatches without trying to propagate changes across the array, confirming that independence of parity groups is sufficient.
