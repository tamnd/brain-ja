 ## 解決策
 ## 問題の理解

 最も安い購入方法を正確に計算するように求められます`n`店が 2 つの購入オプションを提供している場合、ミルク ティーを 1 杯購入する: 原価で 1 杯購入する`a`、またはコストのために 2 つのカップのバンドルを購入する`b`。 各束は分割できず、ちょうど 2 杯分になります。 目標は正確に達成することです`n`少なくともカップ`n`総コストを最小限に抑えながら。 

重要な問題は、カップを 1 杯にするのではなく、束を何個摂取するかを決めることです。 バンドルがお金を節約できるのは、シングルを 2 つ購入するよりもカップあたりのコストが安い場合に限られます。ただし、バンドルの方が安い場合でも、バンドルは常に偶数のカップを提供するため、パリティが重要になります。 もし`n`というのは奇妙ですが、どんなに安いバンドルであっても、少なくとも一杯のカップは避けられません。 

制約により、最大で次のことが許可されます。`10^4`テストケースと最大値`10^9`。 これは、各テスト ケースを一定時間内に解決する必要があることを意味します。`O(n)`次の場合、テストケースごとに遅すぎるでしょう`n`集合体としては大きいです。 ソリューションでは、量に関するシミュレーションを避け、代わりに直接の算術推論に依存する必要があります。 

よくある間違いは、バンドルコストと単一コストを誤って比較するときに発生します。 たとえば、次の場合`a = 10`、`b = 9`、 そして`n = 1`、単純な戦略では、2 カップあたりの価格が安いため、バンドルを使用しようとする可能性がありますが、バンドルを分割できないため、それは不可能です。 別の微妙な問題が発生する場合、`n = 1`：バンドルは極端に安くても使えない。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての数のバンドルが試行されます。`k`、 から`0`に`n // 2`、残りを埋めます`n - 2k`単品購入のカップ。 それぞれの選択にかかる費用は、`k * b + (n - 2k) * a`。 これは正しいです。なぜなら、有効な分解をすべて列挙しているからです。`n`ペアとシングルに分かれます。 ただし、このアプローチには次の手順が必要です`O(n)`テストケースごとに、最大で`n/2`可能なバンドル数。 と`n`まで`10^9`、これはまったく不可能です。 

重要な観察は、これが組み合わせ検索の問題ではなく、単純な局所最適化であるということです。 各バンドルは 2 つのシングルを置き換えます。 シングルを 2 つ購入する場合とバンドルを 1 つ購入する場合の価格の差は次のとおりです。`2a - b`。 この値が正の場合、バンドルは有益です。 それ以外の場合はそうではありません。 したがって、最適な解決策では、できるだけ多くのバンドルを取得するか、まったく取得しません。 

残る唯一の複雑さはパリティです。 もし`n`が偶数であれば、バンドルのみを使用することも、バンドルとシングルを自由に混在させることもできます。 もし`n`これは奇妙です。シングルとして購入するにはちょうど 1 杯を残しておかなければなりません。残りは`n-1`カップはペアで扱われます。 

したがって、解決策は、バンドルが 2 つのシングルよりも安いかどうかを確認し、可能な限り多くのバンドルを貪欲に使用し、残りのカップをシングルで満たすことになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | テストあたり O(n) | お(1) | 遅すぎる |
 | 最適 | テストごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 バンドルの費用対効果に基づいて個別に推論します。 

1. 比較して、シングルを 2 枚購入する方がバンドルを 1 枚購入するよりも高価かどうかを計算します。`2a`そして`b`。 もし`b >= 2a`、バンドルは決して役に立たないため、最適な戦略はすべてのカップを個別に購入することです。 
2. バンドルの方が安い場合 (`b < 2a`)、各バンドルは 2 つのシングルと比較して厳密にコストを削減するため、使用するバンドルの数を最大化したいと考えています。 
3. 使用できるバンドルの数を計算します。`n // 2`。 これにより、正確な要件に違反することなく、可能なすべてのペアが使用されます。 
4. もし`n`が偶数であれば、答えは単純です。`(n // 2) * b`。 
5. もし`n`それは奇妙です、私たちは受け入れます`(n // 2)`のバンドル`n - 1`カップ、残りの 1 カップのために追加のシングル カップ。 費用は`(n // 2) * b + a`。 

### なぜ効果があるのか

 各バンドルはちょうど 2 つの単一カップを置き換えます。 この決定は、ローカル交換の議論に帰着します。2 つのシングルを 1 つのバンドルに置き換えることでコストが削減される場合、最適なソリューションは、利用可能なすべてのペアに対してその置き換えを実行する必要があります。 バンドルはカウントによる以外は対話しないため、有益な交換をすべてすでに使用しているソリューションを再配置しても改善できません。 唯一のグローバル制約はパリティです。これは、次の場合に 1 つのカップを強制的に強制します。`n`奇数です。 これにより、最適解の構造が完全に決まります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())

    # compare cost of 2 singles vs 1 bundle
    if b >= 2 * a:
        # bundles are not useful
        print(n * a)
    else:
        # use as many bundles as possible
        pairs = n // 2
        cost = pairs * b
        if n % 2 == 1:
            cost += a
        print(cost)
```コードは、exchange 引数を直接実装します。 比較`b >= 2a`バンドルを使用する価値があるかどうかを決定します。 そうでない場合は、純粋なシングルに戻ります。 それ以外の場合は、整数除算を使用して要素を貪欲にペアリングすることで、バンドルの使用量を最大化します。 

微妙な点は、オーバーフローまたは大きな乗算の処理ですが、Python 整数はこれを安全に処理します。 もう 1 つの重要な詳細は、`n // 2`反復するのではなく、テスト ケースごとに一定の時間が保証されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    t = int(input())
    out = []
    for _ in range(t):
        n, a, b = map(int, input().split())
        if b >= 2 * a:
            out.append(str(n * a))
        else:
            pairs = n // 2
            cost = pairs * b
            if n % 2:
                cost += a
            out.append(str(cost))
    return "\n".join(out)

 ## 特殊なケース

 いつ`n = 1`、アルゴリズムはバンドルを正しくバイパスします。`n // 2 = 0`、単一の購入コストのみを残します`a`。 例えば、`n = 1, a = 10, b = 1`収量`10`, カップあたりの方が安くてもバンドルは使えないので。 

いつ`n = 2`、両方の戦略は直接比較できます。 もし`b < 2a`、アルゴリズムは 1 つのバンドルを選択します。 それ以外の場合は、2 つのシングルが使用されます。 例えば、`n = 2, a = 5, b = 8`結果として`10`、 その間`n = 2, a = 5, b = 9`結果的にも`10`、正しい比較ロジックを確認します。 

いつ`n`が奇数でバンドルが安い場合でも、アルゴリズムは依然として 1 つのカップを正確に保存します。 のために`n = 5, a = 3, b = 4`、2 つのバンドルと 1 つのシングルを使用し、`11`。 シングルカップを回避しようとする試みはパリティのため不可能であり、バンドルは厳密に有益であるため、完全なペアリングから逸脱するとコストが増加するだけです。
