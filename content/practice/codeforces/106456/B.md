 ## 解決策
 ## 問題の理解

 私たちには一列に並んだ座席が与えられており、各座席は使えるか壊れているかのどちらかです。 2 人のプレイヤーがアリスから順番に乗客を使用可能な座席に配置します。 移動は、現在空いている使用可能な座席を選択して占有することで構成されます。ただし、すでに占有されている座席が距離内にない場合に限ります。`k`それの。 距離は元のラインで測定されるため、壊れたシートによって距離が妨げられたり、リセットされたりすることはありません。 

一度座席が取られると、その座席は永久に占有されたままとなり、半径方向をブロックすることにより、将来の移動の可用性に影響を与える可能性があります。`k`その周り。 現在のプレイヤーに正当な手が存在しない場合、ゲームは終了します。 アリスは占有座席の総数を最大化したいと考えていますが、ボブはそれを最小化したいと考えています。 どちらも最適なプレイを行うため、最適なプレイと一致するシートの最終構成を出力する必要があります。 

制約`n ≤ 20`これは、状態空間の構造がビットマスク動的プログラミングに十分小さいことを即座に示唆しています。 各座席は占有されているかいないかのどちらかであり、壊れた座席は固定されています。 それはせいぜい`2^n`可能な占有状態と遷移は、ローカル制約を尊重するトークンの配置にのみ依存します。 

微妙な点は、移転の合法性は、壊れた議席ではなく、既存の占有議席に依存するということだ。 素朴な解釈では、壊れた議席を誤って妨害者として扱う可能性がありますが、選択できないことを除けば、議席は無関係です。 

もう 1 つの明白ではない問題は、現在のプレイヤーが何も動かなくなるとゲームが終了することです。 これは、深さを盲目的に最大化または最小化しているのではなく、到達可能な構成に応じて異なるパリティで端末状態が発生する有限の公平なゲームを評価していることを意味します。 

最後のエッジケースが発生するのは、`k = 0`。 その場合、空の使用可能な座席はすべて常に合法であるため、ゲームは使用可能な座席がすべて埋まるまで単純な交互配置になります。 ゼロを正しく処理せずに、厳密な不等式として近傍チェックを誤って強制するソリューションは引き続き機能しますが、非効率な実装では近傍を不必要に再計算するために時間を浪費する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、初期状態からゲームをシミュレートし、あらゆる可能な動きシーケンスを探索します。 各状態で、すべての有効な座席を列挙し、アリスまたはボブのターンを再帰的にシミュレートし、最適なプレイに従って結果を選択します。 これは概念的に機能します。なぜなら、状態はどの席が占有されているか、そして誰の順番であるかによって完全に決定されるからです。 

ただし、分岐係数は大きくなる可能性があります。 最悪の場合、空席はすべて有効な移動となるため、`t`空席があれば分岐いたします`t`大まかに言うと`n!`可能なシーケンス。 たとえ`n ≤ 20`、これはメモ化しないと大きすぎます。 

重要な観察は、ゲームが状態グラフ上の有限決定論的な 2 人用ゲームであり、各状態が占有席のビットマスクとパリティ ビットであるということです。 多くても`2^n * 2`州。 各状態から、任意の有効な位置にトークンを配置することで遷移します。 以来`n`が小さい場合は、メモ化された再帰または反復 DP を使用してすべての状態の結果を計算できます。 

最適なプレイの下で、各状態を現在のプレーヤーの勝ちまたは負けとして扱います。 これが分かれば、有効な最終構成を再構築するには、最適な動きに従うだけになります。

 ## アルゴリズムのチュートリアル

 ビットマスクを使用してボードを表します`mask`、どこビット`i`座席かどうかを示します`i`占領されています。 壊れた座席は別に保管されており、選択することはできません。 

関数を定義します`dp(mask)`現在のプレイヤーがこの状態から勝利する戦略を持っているかどうかを返します。 

1. 与えられた条件に対して`mask`、すべての座席を反復処理します`i`壊れていない、占有されていない。 このような各座席について、距離内に占有されている座席がないことを確認することで、そこにトークンを置くことが合法かどうかを確認します。`k`。 

この合法性チェックにより、トークンを次の場所に置いた場合に、`i`、全席`[i-k, i+k]`現在のマスクでは空でなければなりません。 
2. 少なくとも 1 回の法的措置が存在する場合`i`そのような`dp(mask | (1 << i))`次のプレイヤーが負けている場合、`dp(mask)`勝っている。 

これは標準的なミニマックス原則に従い、相手を不利な立場に追い込むことを試みます。 
3. そのような動きが存在しない場合、`dp(mask)`負けています。 

一度`dp(0)`が計算されると、1 つの最適なプレイを再構築します。 から始まる`mask = 0`そしてアリスの番では、できれば相手が負けるような手を選択することを繰り返します。 そのような手が存在しない場合、現在のプレーヤーはパスし、ゲームは終了します。 

再構築中にターンパリティを追跡することで、どのプレイヤーが各席に配置したかを記録します。 アリスには偶数ターンに移動が割り当てられ、ボブには奇数ターンに移動が割り当てられます。 

### なぜ効果があるのか

 各州`mask`将来の動きに関連するすべての情報を完全に取得します。禁止された地区を定義するため、占有された座席のみが重要ですが、壊れた座席は選択を制限するだけで、動的に相互作用しません。 したがって、マスク サイズを大きくして見ると、ゲームは有限の有向非巡回グラフになります。 DP は、このグラフ内の各ノードの標準的な勝敗分類を計算します。 すべての移行では占有シート数が厳密に増加するため、サイクルは不可能であり、メモ化された評価の終了と正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k, m = map(int, input().split())
    broken = set(map(lambda x: int(x) - 1, input().split())) if m else set()

    full_mask = 0
    for i in broken:
        full_mask |= (1 << i)

    # precompute valid positions
    valid_positions = [i for i in range(n) if i not in broken]

    # precompute neighborhood masks for fast validity checks
    neigh = []
    for i in range(n):
        mask = 0
        for j in range(n):
            if abs(i - j) <= k:
                mask |= (1 << j)
        neigh.append(mask)

    from functools import lru_cache

    @lru_cache(None)
    def dp(mask):
        # try all moves
        for i in valid_positions:
            if mask & (1 << i):
                continue
            # check legality: no occupied in neighborhood
            if mask & neigh[i]:
                continue
            if not dp(mask | (1 << i)):
                return True
        return False

    # reconstruct
    res = ['.'] * n
    turn = 0
    mask = 0

    while True:
        move = -1
        for i in valid_positions:
            if mask & (1 << i):
                continue
            if mask & neigh[i]:
                continue
            if not dp(mask | (1 << i)):
                move = i
                break
        if move == -1:
            break
        if turn % 2 == 0:
            res[move] = 'a'
        else:
            res[move] = 'b'
        mask |= (1 << move)
        turn ^= 1

    for i in broken:
        res[i] = 'x'

    print(''.join(res))

if __name__ == "__main__":
    solve()
```このソリューションは、占有されているすべての構成上にビットマスク DP を構築します。 の`neigh[i]`マスクは、トークンを配置することで無効になるすべての位置をエンコードします。`i`、常時合法性チェックを可能にします。 

再構築フェーズは DP 評価とは別のものです。 クエリを繰り返します`dp`選択した動きが確実に相手の不利な立場につながり、最適なプレイが強制されます。 ターン カウンタはラベル付けのみに使用され、DP の正確さには使用されません。 

よくある落とし穴は、壊れたシートはマスク遷移の一部ではないものの、移動生成と近隣制約の両方から除外する必要があることを忘れていることです。 もう 1 つの微妙な点は、民進党諸国は占有議席のみに依存していることです。 壊れた座席が誤って州に含まれていた場合、複雑さは不必要に 2 倍になります。

 ## 特殊なケース

 使用可能な 1 議席を除いてすべての議席が壊れた場合、DP はただちに 1 つの強制移動を特定します。 マスクは空で始まり、有効な位置が 1 つだけ存在し、それを配置するとそれ以上の移動は行われません。 

いつ`k = 0`、空いている使用可能な座席は、隣に関係なく常に有効です。 DP は単純に残りの座席を数えるようになり、最適なプレーは使い果たされるまで交互にフィルを行うことになります。 

座席が壊れると、ラインがより短い孤立したセグメントに分割されます。`2k + 1`、それらのセグメントは独立したサブゲームになります。 DP はこれを自然に捉えています。1 つのセグメントに配置しても、ローカル近傍を超えて他のセグメントに影響を与えることはなく、マスク表現はインタラクションを依然としてきれいに分離しているからです。
