 ## 解決策
 ## 問題の理解

 あります`n`多肢選択式の質問で、アユーブは各質問に 1 通の手紙で答えました。`a`を通して`e`。 重要な追加情報は、正解はすべての質問で同じ文字であるということです。 それが 5 つの文字のどれであるかはわかりません。 

正しい文字を固定的に選択する場合、アユーブは、その位置での答えが選択した文字と等しい場合に、正確に質問を正解します。 したがって、正しい文字があった場合、`c`、彼のスコアは単純に`c`彼の回答文字列内の文字。 

考えられる 5 つの正しい文字をすべて考慮する必要があります。 可能な最小スコアは、次の中で最も小さい頻度です。`a`、`b`、`c`、`d`、 そして`e`、可能な最大スコアは最大頻度です。 

質問数は満たしている`1 <= n <= 1000`。 これは入力サイズが非常に小さいため、すべての質問に対して正しい可能性のある 5 文字すべてをチェックするだけでも十分です。`5 * 1000 = 5000`キャラクターの比較。 リニア スキャンは十分すぎる速度であり、単純な 5 パス ソリューションでも問題なく制限時間内に収まります。 並べ替え、動的プログラミング、またはさらに複雑なデータ構造は必要ありません。 

実装が静かに失敗する可能性があるケースがいくつかあります。 入力すると`3`そして`aaa`、答えは`0 3`。 正しい文字であれば、`a`、3 つの答えはすべて正解ですが、他の文字の場合はどれも正解ではありません。 正しい文字が文字列内に出現する必要があると想定する不用意な実装により、誤って最小値が生成される可能性があります。`1`。 

もう 1 つの特殊なケースは、考えられるすべての文字が同じ頻度で出現する場合です。 たとえば、`5`質問と文字列`abcde`、考えられるすべての正しい文字は正確に 1 つの正解を与えるため、出力は次のようになります。`1 1`。 この場合、間違った周波数から最小値または最大値を初期化する実装は失敗する可能性があります。 

最小の有効な入力も役に立ちます。 のために`n = 1`そして`s = a`、可能なスコアは次のとおりです。`1, 0, 0, 0, 0`、したがって、答えは次のとおりです`0 1`。 文字列内に出現しない 4 文字も考慮する必要があります。 

## アプローチ

 直接的な総当たりの解決策では、考えられる 5 つの正しい文字のそれぞれを試すことができます。 選択した文字について、回答文字列全体をスキャンし、その文字が含まれる位置の数をカウントします。 これを実行した後、`a`、`b`、`c`、`d`、 そして`e`、5 つのスコアの最小値と最大値を取得します。 これは正しいです。このステートメントは、実際の試験には共通の正解文字が 1 つだけ存在し、その選択肢が 5 つしかないことを保証しているからです。 

最悪の場合の動作`5n`キャラクターの比較。 と`n <= 1000`、それはせいぜい`5000`したがって、このブルートフォース手法は、指定された制約の下では実際には遅くなりすぎることはありません。 その漸近的な複雑さはまだ続いています`O(n)`5 の因数が定数であるためです。 

候補文字のスコアが文字列内のその頻度と正確であることを観察することで、同じ推論をより明確にすることができます。 候補ごとに文字列全体を 1 回スキャンする代わりに、文字列を 1 回スキャンして 5 つのカウンターを維持できます。 すべての文字はちょうど 1 つのカウンタをインクリメントします。 周波数がわかれば、最小周波数と最大周波数から必要な答えがすぐに得られます。 

正解の可能性が 5 つしかないため、総当たり法が機能しますが、同じ文字を繰り返し検査します。 候補者のスコアが単にその頻度であるという観察により、1 回のスキャン中に 5 つのスコアすべてを収集できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(5n) = O(n) | お(1) | 承認済み |
 | 最適 | O(n) | お(1) | 承認済み |

 最適なバージョンが望ましいのは、問題との関係が直接的であるためです。つまり、各文字を 1 回数えてから 5 つのカウントを検査します。 

## アルゴリズムのチュートリアル

 1. 周波数を表す 5 つのカウンターを作成します。`a`、`b`、`c`、`d`、 そして`e`。 各カウントは、その文字が普遍的な正解である場合にアユーブが受け取るスコアを表すため、考えられるすべての正解には独自のカウントが必要です。 
2. 応答文字列内のすべての文字をスキャンし、その文字に対応するカウンタをインクリメントします。 文字列の接頭辞を処理した後、各カウンタは、その文字がその接頭辞に出現した回数と等しくなります。 
3. 文字列全体が処理された後、5 つのカウンタの中で最小のものと最大のものを見つけます。 特定の文字を正解として選択すると、その文字を含む位置で正確に正解が Ayoub に与えられるため、これらの値は正確に最小スコアと最大スコアです。 
4. 最小周波数を出力し、その後に最大周波数を出力します。 

### なぜ効果があるのか

 しましょう`count[x]`アユーブが手紙で答えた質問の数`x`。 もし`x`は実際の一般的な正解です。アユーブは、まさにその答えが次のような質問で正しいです。`x`、つまり、彼のスコアは`count[x]`。 共通の正解は 5 つの文字のいずれかである可能性があるため、すべての可能なスコアのセットは正確に 5 つの周波数になります。 最小値を取得すると可能な限り最小のスコアが得られ、最大値を取得すると可能な限り最大のスコアが得られます。 カウント パスではこれらの周波数がすべて正確に計算されるため、最終的なペアは正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

count = [0] * 5

for ch in s:
    count[ord(ch) - ord('a')] += 1

print(min(count), max(count))
```最初の行は次のようになります`n`ただし、文字列を読み取った後はアルゴリズムでは必要ありません。 文字列自体には、5 つの可能なスコアを計算するために必要なすべての情報が含まれています。 

の`count`配列には 5 つの位置があります。 入力にはからの文字のみが含まれているため、`a`を通して`e`、式`ord(ch) - ord('a')`これらの文字をインデックスにマップします`0`を通して`4`。 したがって`a`アップデート`count[0]`、`b`アップデート`count[1]`、 等々。 

ループはすべての文字を 1 回だけ処理します。 どのカウンタを増加させる必要があるかはその文字自体が正確に決定するため、各文字を 5 文字すべてと比較する必要はありません。 

文字は決して表示されない可能性があるため、ゼロの初期化は重要です。 たとえば、`aaa`、カウンターは次のようになります`[3, 0, 0, 0, 0]`。 これらのゼロ値は、Ayoub の回答に正しい文字が存在しない有効な可能性を表します。 

ここでは Python 整数にはオーバーフローの問題はなく、すべてのカウンターは最大でも`1000`。 標準入力の改行が応答文字として扱われないように、入力文字列は削除されます。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def solve():
    input = sys.stdin.readline

    n = int(input())
    s = input().strip()

    count = [0] * 5

    for ch in s:
        count[ord(ch) - ord('a')] += 1

    print(min(count), max(count))

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

# Provided samples
assert run("10\naaaaaabcde\n") == "1 6", "sample 1"
assert run("3\naaa\n") == "0 3", "sample 2"

# Minimum-size input
assert run("1\na\n") == "0 1", "single question"

# All five letters occur equally often
assert run("5\nabcde\n") == "1 1", "all letters equally frequent"

# All answers are the same
assert run("7\nbbbbbbb\n") == "0 7", "all equal values"

# Maximum-size input
assert run("1000\n" + "a" * 1000 + "\n") == "0 1000", "maximum n"

# Boundary distribution that catches incorrect min/max initialization
assert run("5\naaaab\n") == "0 4", "zero-frequency letters and maximum frequency"
```| テスト入力 | 期待される出力 | 検証内容 |

 |`1 / a`|`0 1`| 最小入力サイズと欠落文字 |
 |`5 / abcde`|`1 1`| 周波数が等しい、最小値と最大値が等しい |
 |`7 / bbbbbbb`|`0 7`| すべての答えは同じです |

 ## 特殊なケース

 単一の質問の場合は、次のように考えます。`n = 1`そして`s = a`。 カウンターは、`[1, 0, 0, 0, 0]`。 もし`a`が正解の場合、アユーブは 1 ポイントを獲得します。 他の文字が正しい場合、彼は 0 点を獲得します。 アルゴリズムは出力します`0 1`、考えられる 5 つの正解すべてを正しく説明しています。 

異なる文字が 1 つだけ含まれる応答文字列については、次のことを考慮してください。`n = 3`そして`s = aaa`。 カウンターは、`[3, 0, 0, 0, 0]`。 最大スコアは`3`、いつ得られるか`a`は正しいですが、最小値は`0`、他の 4 つの正しい文字のいずれかについて取得されます。 結果は`0 3`。 

すべての文字が 1 回だけ出現する場合については、次のように考えます。`n = 5`そして`s = abcde`。 カウンターは、`[1, 1, 1, 1, 1]`。 どの文字が普遍的な正解であるかに関係なく、アユーブは 1 問だけ正解します。 したがって、両方の極値は次のようになります。`1`、与える`1 1`。 

最大入力サイズについては、次のことを考慮してください。`n = 1000`および 1,000 を含む文字列`a`文字。 カウンターは、`[1000, 0, 0, 0, 0]`、結果は次のようになります`0 1000`。 ループは依然として文字ごとに 1 つの操作のみを実行します。これは、ソリューションが入力サイズに直接応じてスケールされることを示しています。
