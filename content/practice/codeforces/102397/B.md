 ## 解決策
 ## 問題の理解

 長方形の土地の寸法をその面積から再構築する必要があります。 入力には単一の整数が含まれています`n`、長方形の面積を表します。 2 つの正の整数を出力する必要があります`height`そして`width`正確には誰の製品ですか`n`。 

たとえば、次の場合`n = 20`、 両方`4 5`そして`2 10`この問題では、有効なペアを明示的に許可するため、一意の長方形を見つけたり、寸法を最適化したりする必要はありません。 

制約`1 <= n <= 200`問題が非常に小さくなります。 1 から 1 までのすべての整数をチェックするアルゴリズムも`n`最大 200 回の反復を実行しますが、これは 1.5 秒の制限を十分に上回る速度です。 それでも、数学的構造により、より明確な情報が得られます。`O(sqrt(n))`アプローチ。 これは概念的に重要です。なぜなら、因数ペア問題にははるかに大きな制限があり、最大のすべての値をチェックするためです。`n`高価になりすぎてしまいます。 

主要なエッジ ケースは、完全な正方形と可能な限り最小の面積から得られます。 のために`n = 1`、可能な寸法は次のとおりです。`1 1`。 2 からチェックを開始する不注意な実装では、要素が見つからず、何も出力されない可能性があります。 

次のような完全な正方形の場合`n = 16`、寸法`4 4`同じ係数を 2 回使用できるため、有効です。 2 つの異なる因子のみを誤って検索する実装では、等しい次元が完全に有効であっても、このケースが拒否される可能性があります。 

などの一等地向け`n = 7`、2 と の間に因数はありません。`sqrt(7)`。 有効な長方形は次のとおりです。`1 7`。 すべての数値に自明ではない要素があると想定する実装は、ここで失敗する可能性があります。 

提供されたステートメントのサンプル書式設定では、対応する入力行が省略されていますが、表示される出力ペアは明らかに領域に対応しています。`20`、`16`、 そして`6`:`4 * 5 = 20`、`4 * 4 = 16`、 そして`2 * 3 = 6`。 

## アプローチ

 最も直接的なアプローチはブルートフォースです。 1 から 1 までの可能なすべての高さを試してください`n`、いつでも`n`はその高さで割り切れます。`n / height`幅として。 最初に成功した除数はすぐに有効なペアを与えます。`height * (n / height) = n`。 最悪の場合、これは実行されます`n`可分性チェック。 実際の制約がある場合`n <= 200`、つまり最大 200 チェックを意味するため、ここでは総当たり攻撃が完全に受け入れられます。 速度が非常に遅くなるのは、制約が大幅に増加した場合のみです (たとえば、次のような値に)。`10^9`以上のパフォーマンスを発揮する場合`n`反復はもはや現実的ではありません。 

有益な観察は、因子がペアで存在するということです。 もし`a * b = n`そして`a <= b`、 それから`a <= sqrt(n)`。 したがって、以下から下方向に検索すると、`floor(sqrt(n))`、除算する最初の値`n`因数ペアを即座に与えます。 これより大きいものを検査する理由はありません`sqrt(n)`、そのマッチング係数はすでに以下であるためです。`sqrt(n)`。 

これにより、検索が最大で 1 回まで減少します。`n`最大でもチェックします`sqrt(n)`小切手。 この問題では、どちらの方法でも十分高速ですが、平方根アプローチの方が因子ペア問題の背後にある標準的な推論を捉えており、より適切に拡張できます。

 ## アルゴリズムのチュートリアル

 1. エリアを読む`n`。 の正の約数を見つける必要があります`n`そしてその補完的な要素を別の次元として使用します。 
2. コンピューティング`floor(sqrt(n))`。 因子のペアは常に、小さい方の因子が最大で次の値になるように配置できます。`sqrt(n)`なので、この境界を越えて検索する必要はありません。 
3. から開始します`floor(sqrt(n))`下方向に検索すると、問題ではこの特定のペアが必要ではありませんが、可能な限り最大の小さい次元を持つ因子のペアが見つかるため便利です。 
4. 各候補者について`h`、どうかを確認してください`n % h == 0`。 If the remainder is zero,`h`エリアを正確に分割するので、`n // h`は整数とそのペアです`h, n // h`有効な長方形を形成します。 
5. 印刷`h`そして`n // h`そしてやめてください。 1 はすべての正の整数を除算するため、除数は必ず見つかるはずです。 

### なぜ効果があるのか

 不変条件は、ループで考慮されるすべての候補が最大でも`sqrt(n)`。 有効な因数分解ごとに`n = a * b`、少なくとも 1 つ`a`そして`b`せいぜい`sqrt(n)`。 ループはすべての整数をチェックするので、`floor(sqrt(n))`1 まで下げると、最終的にはそのような要因に遭遇するはずです。 そうなると、補完的な値が`n // a`満足する`a * (n // a) = n`したがって、印刷される寸法には常に必要な領域が正確に含まれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

h = int(n ** 0.5)

while h >= 1:
    if n % h == 0:
        print(h, n // h)
        break
    h -= 1
```最初の行は単一の領域値を読み取ります。 テスト ケースは 1 つだけであるため、外部のテスト ケース ループは必要ありません。 

表現`int(n ** 0.5)`これらの非常に小さな制約の平方根の整数部分を与えます。 次に、その値から 1 までの可能なより小さい寸法を検査します。 

可分性テストが中心的な操作です。 もし`n % h`がゼロの場合、整数除算により正確な相補次元が得られます。 有効なペアは受け入れられるため、すぐに印刷されます。 

ループ条件では、`h >= 1`それよりも`h > 1`1 はすべての陽性に対するフォールバック係数であるため、`n`。 これは素数と`n = 1`特別なケースなしで。 

Python では整数オーバーフローの心配はなく、割り算は割り切れることが確認された後にのみ実行されます。

 20 の平方根は約 4.47 であるため、ループは 4 から始まります。20 は 4 で割り切れるので、アルゴリズムはすぐに相補的な因数 5 を取得します。次の理由により、不変式は満たされます。`4 * 5 = 20`。 

### サンプル 2

 2 番目に表示されるサンプルの場合、エリアは次のようになります。`16`、予想される寸法は次のとおりです。`4 4`。

 ここ`sqrt(16) = 4`, したがって、ループは正確に平方根から始まります。 平方根係数は数値を除算し、2 つの等しい次元を生成します。 これは、完全正方形に特別な処理が必要ない理由を示しています。

## テストケース

 この問題では有効な因子のペアを受け入れるため、以下のテスト ヘルパーは、特定の 1 つのペアを必要とするのではなく、出力の数学的特性を検証します。 サンプルのアサーションは、ステートメントに示されている正確なディメンションを受け入れますが、返されたディメンションが要求された領域に乗算されるかどうかもチェックします。```python
import sys
import io

def solve():
    input = sys.stdin.readline
    n = int(input())

    h = int(n ** 0.5)

    while h >= 1:
        if n % h == 0:
            print(h, n // h)
            break
        h -= 1

def run(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()
    result = sys.stdout.getvalue().strip()

    sys.stdin = old_stdin
    sys.stdout = old_stdout

    return result

def check(inp: str, expected_area: int):
    out = run(inp)
    a, b = map(int, out.split())
    assert a * b == expected_area, (
        f"Invalid rectangle for area {expected_area}: {a} {b}"
    )
    assert a >= 1 and b >= 1

# Provided samples, whose input lines are omitted in the supplied statement.
assert run("20\n") == "4 5", "sample 1"
assert run("16\n") == "4 4", "sample 2"
assert run("6\n") == "2 3", "sample 3"

# Minimum-size input.
assert run("1\n") == "1 1", "minimum area"

# Maximum-size input.
check("200\n", 200)

# Another perfect square.
assert run("25\n") == "5 5", "perfect square"

# Prime number, where only 1 and n are factors.
check("197\n", 197)
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1`|`1 1`| 1 | での最小面積とループ境界
 |`200`|`10 20`| 最大制約と非正方形の複合体 |
 |`25`|`5 5`| 完全二乗処理 |

 ## 特殊なケース

 のために`n = 1`、`floor(sqrt(1))`は 1 です。最初の割り算チェックは次のとおりです。`1 % 1 == 0`、アルゴリズムは次のように出力します`1 1`。 個別の特殊なケースは必要なく、ループの下限境界は正しく処理されます。 

完全な正方形の場合`n = 16`、ループは 4 から始まります。`16 % 4 == 0`、印刷されます`4 4`。 長方形の高さと幅が異なる必要はないため、等しい寸法が許可されます。 

プライム入力の場合`n = 7`、`floor(sqrt(7))`2.アルゴリズムチェック`7 % 2`はゼロ以外であり、その後 1 になります。`7 % 1 == 0`、印刷されます`1 7`。 これは、すべての正の整数が約数として 1 を持つため機能します。 

最大入力の場合`n = 200`、ループは 14 から始まり、下方向にチェックします。 最初に見つかった約数は 10 です。`200 % 10 == 0`。 補完的な次元は、`200 // 10 = 20`したがって、出力は次のようになります`10 20`。 彼らの製品はちょうど 200 で、必要な長方形の面積を満たしています。
