## アプローチ

 ブルート フォース アプローチでは、考えられるすべての連続セグメントをチェックし、すべてのサブセットの積をテストします。`x`。 これは正しいですが、長さのサブセットの数が異なるため、実用的ではありません。`n`は`2^n`そしてセグメント自体は`O(n^2)`。 小さいものでも`n`、これは計算上不可能になります。 

重要な洞察は、製品を直接扱う代わりに、素因数に基づいて推論できるということです。 要素`x`その主力に。 カードごとに`a_i`、各素数がそれを何回割るかを計算し、対応する累乗を上限にします。`x`。 次に、現在のセグメントの累積素数パワーの現在の集計を維持します。 いずれかの時点で、セグメントの累積検出力が次の検出力に達するか、それを超えると、`x`すべての素数に対して、次のように乗算されるサブセットが存在します。`x`。 したがって、セグメントはそこで終了します。 次のセグメントはその時点の後に始まります。 このアプローチを使用すると、各要素を 1 回処理し、セグメント境界を更新できます。`O(n * log x)`制限を考慮すると許容できる時間です。

 ## アルゴリズムのチュートリアル

 1. の素因数分解を事前に計算します。`x`。 各素数を必要な指数にマッピングする辞書として保存します。 
2. 作成された不良セグメントの数を追跡するカウンタを初期化します。 現在のセグメントをインデックス 0 から開始します。 
3. 現在のセグメント内の各素因数の累積指数の辞書を維持します。 
4. カードを繰り返し処理します。 

1. 現在のカードを因数分解し、各素数の累積指数を増分します。 
2. 累積指数がすべての素数に必要な指数に達するか超える場合、次のように乗算されるサブセットが生成されます。`x`可能です。 現在のセグメントはこのカードの前で終了します。 
3. 不良セグメントの数を増やし、累積指数をリセットし、現在のカードで新しいセグメントを開始します。 
5. すべてのカードを処理した後、最後のセグメントが次の積を形成しなかった場合、`x`、不良セグメントとしてカウントされます。 
6. 合計不良セグメント数を出力します。 

**これが機能する理由**: 維持される不変条件は、形成されるセグメントの累積素因数が決して満たされないということです。`x`。 一度そうなると、セグメントが不良のままになることはできないため、すぐにセグメントを閉じます。 常に最初の瞬間にセグメントを終了することで、サブセットが次のように増殖する可能性があります。`x`、不良セグメントの数を最小限に抑えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict
from math import isqrt

def prime_factors(x):
    factors = defaultdict(int)
    for p in range(2, isqrt(x) + 1):
        while x % p == 0:
            factors[p] += 1
            x //= p
    if x > 1:
        factors[x] += 1
    return factors

def solve():
    t = int(input())
    for _ in range(t):
        n, x = map(int, input().split())
        a = list(map(int, input().split()))
        pf_x = prime_factors(x)
        primes = list(pf_x.keys())
        
        count = 0
        cum = defaultdict(int)
        
        for val in a:
            # factor val with respect to primes in x
            for p in primes:
                temp = val
                cnt = 0
                while temp % p == 0:
                    cnt += 1
                    temp //= p
                cum[p] += min(cnt, pf_x[p])
            
            # check if any subset could form x
            if all(cum[p] >= pf_x[p] for p in primes):
                count += 1
                cum = defaultdict(int)
        
        if any(cum[p] > 0 for p in primes):
            count += 1
        
        print(count)

if __name__ == "__main__":
    solve()
```**実装の選択肢の説明**: 素因数に関する数値のみを因数分解します。`x`、無駄な作業を防ぎます。 累積辞書は、セグメントが次の可能な積に達するたびにリセットされます。`x`、セグメントが最小限に保たれるようにします。 使用する`min(cnt, pf_x[p])`指数の過剰カウントを防ぎ、セグメントのクロージャが時期尚早にトリガーされるのを防ぎます。
