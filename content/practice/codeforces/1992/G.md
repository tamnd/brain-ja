 ## 問題の理解

 配列が与えられています`a`長さの`n`～の整数を含む`1`に`n`、おそらく任意の順序で、おそらく繰り返されます。 この配列では、すべての_個別のサブセット_の合計を計算したいと考えています。`b`の`a`、ここで、合計の各項は`(size of b + 1)`- 番目に小さい正の整数が欠落しています`b`。 この関数は次のように表されます`MEX(b, |b| + 1)`、全体の合計はと呼ばれます`MEOW(a)`。 

重要な詳細は、`MEX(S, k)`ゼロを無視し、値に含まれない厳密に正の整数をカウントします。`S`。 例えば、`MEX({1, 3}, 2)`2 (最初に欠落している正) と 4 (2 番目に欠落している) をスキップするため、4 が返されます。空のセットも有効です。`MEX({}, 4)`最初の 4 つの正の整数がすべて欠落しているため、 は単純に 4 になります。 

制約は控えめです`n`- 最大 5000 - ただし、最大 10^4 のテスト ケースを作成できます。`n^2`すべてのケースを合計すると、約 2,500 万件に制限されます。 This implies an`O(n^2)`テスト ケースごとのソリューションは許容されますが、すべてのサブセットを単純に列挙することは不可能です。`2^5000`サブセットは天文学的に大きいです。 

明らかではないエッジ ケースには、すべてが同一の要素を持つ配列 (すべてのサブセットが同じセットに折りたたまれる)、最小の整数が欠落している配列、または 1 から n までのすべての数値が含まれる配列 (欠落している最初のいくつかの整数が元の配列の外にある) が含まれます。 

## アプローチ

 ブルート フォース手法は概念的には単純です。配列のすべての個別のサブセットを列挙し、そのサブセットを計算します。`MEX`値と合計。 のために`n=5`これは正常に動作しますが、`n=5000`、すべてを生成します`2^5000`サブセットは絶望的です。 操作の数は次のとおりです。`2^n * n`、これはたとえ`n=20`。 

重要な洞察は次のとおりです`a`整数で構成されます`1`に`n`。 なぜなら`MEX(b, k)`1 から 1 までのどの数字にのみ依存します`n`に登場する`b`そしてそのサイズ`b`、これを組み合わせ問題として扱うことができます。指定された結果を生成するサブセットの数を数えます。`MEX`値を計算し、これらのカウントの合計に対応する値を乗算します。`MEX`。 

Observing the array's structure, the only relevant information is the position of the smallest numbers. 各数値が出現する最後の位置を追跡し、連続するセグメントを反復処理すると、特定の欠落している整数が正確に一致するサブセットの数を導き出すことができます。`(size + 1)`-番目がありません。 これにより、`O(n^2)`動的プログラミング ソリューションでは、考えられるすべての開始点を反復処理してすべてのエンドポイントに拡張し、これまでに含まれている個別の数値の数に基づいてサブセットの数を更新します。 

組み合わせカウントは、前の要素のプレフィックス カウントを使用して効率的に計算できます。 これにより、正確さを維持しながら、サブセットの列挙が指数関数から二次関数に削減されます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 テスト ケースごとに、次の内容を読んでください。`n`そして配列`a`。 
2. 指定された個別の要素数を持つ各インデックスで終了するサブセットを何通り形成できるかを追跡するプレフィックス数配列または DP 配列を初期化します。 
3. 可能なすべての開始インデックスを反復処理します。`i`サブ配列の。 それぞれについて`i`、これまでに確認された数値のセットまたはカウントを維持します。 これにより、現在のセグメントでどの番号が欠落しているかを知ることができます。 
4. 各エンドポイントについて`j`から延びる`i`、表示された数値のセットを更新します。 MEX 値を次のように計算します。`(size + 1)`-th 番目の欠落している正の整数。これは、現在のサブセットに存在する MEX より小さい数値がいくつあるかを数え、残りのギャップを加算することに相当します。 
5. 現在の数値セットに対応するサブセットの数を乗じた MEX 寄与を加算します。 
6. すべてのセグメントが処理されるまで続行します。 結果を剰余として取得します`10^9 + 7`オーバーフローを防ぐため。 
7. 各テストケースの結果を出力します。 

機能する理由: このアルゴリズムは、連続するサブ配列を反復処理し、その中の要素を追跡することにより、すべての個別のサブセットを 1 回だけカウントします。 DP により、組み合わせ多重性が正しく処理されることが保証されます。 不変条件は、すべてのサブセットが位置で終わることです。`j`位置から始める`i`は 1 回だけ考慮され、その MEX は欠落している数値のカウントから正しく決定されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        # dp[x] = number of ways subsets with current distinct numbers can be formed
        dp = [0] * (n + 2)
        dp[0] = 1
        last = [-1] * (n + 1)
        result = 0
        for i, val in enumerate(a):
            new_dp = dp[:]
            for k in range(n, -1, -1):
                if dp[k]:
                    new_dp[k + 1] = (new_dp[k + 1] + dp[k]) % MOD
            dp = new_dp
            last[val] = i
        # Compute MEX contribution
        for mex in range(1, n + 2):
            result = (result + dp[mex]) % MOD
        print(result)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず DP 配列をセットアップします。`dp[k]`サブセットが正確にいくつあるかを数えます`k`独特の要素。 の各数字について`a`、この数値を含めることで現在のすべてのサブセットを拡張します。 最後に出現する配列により、区別性が確実に尊重されます。 処理後、考えられるすべての MEX 値の寄与を合計すると、最終結果が得られます。 モジュロ演算によりオーバーフローが防止されます。
