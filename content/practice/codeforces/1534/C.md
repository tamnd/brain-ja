 ## 解決策
 ## 問題の理解

 2 行 n 列のグリッドが与えられ、各行は 1 から n までの数値の順列になります。 したがって、すべての数値は各行に 1 回だけ表示され、すべての列には 2 つの異なる値が含まれます。 

許可される唯一の操作は、列内の 2 つの値を交換することです。 このような列の交換を任意の回数実行した後でも、各列には依然として同じ 2 つの数値が含まれていますが、それらの垂直方向の順序は独立して反転する可能性があります。 

すべての列が交換された後、両方の行が 1 から n の順列を維持するように、個別の有効な最終グリッドをいくつ取得できるかを数えるよう求められます。 少なくとも 1 つの行がシーケンスとして異なる場合、2 つの構成は異なるものとみなされます。 

重要な制約は、列を個別に交換した後も、行にはすべての数値が 1 回だけ含まれていなければならないということです。 これは、列を任意に反転できないことを意味します。反転の選択によっては、行内に重複が作成され、無効になります。 

入力サイズは大きく、すべてのテスト ケースで n は最大 4e5 です。 すべての列反転の組み合わせを試行するソリューションでは 2^n 状態を調べることになりますが、これは不可能です。 n で二次的なグラフ構築でも失敗するため、テスト ケースごとに線形または線形に近いものを探します。 

サイクルが相互作用する場合、微妙なエッジケースが現れます。 

たとえば、列について考えてみましょう。```
1 2
2 1
```ここでは両方の列が対称であり、どちらかの列を反転しても有効性は変わりません。 これにより、複数の有効なグローバル構成が発生し、一貫性の制約を考慮しない限り、列ごとの単純な独立した推論では過大な計算が行われてしまいます。 

もう 1 つのエッジ ケースは、構造が列全体で単一の交互チェーンを形成し、多数のローカル状態ではなく、正確に 2 つのグローバル状態を強制する場合です。 

## アプローチ

 各列には値のペアが含まれており、唯一のアクションはそれらの垂直位置を交換することです。 これは、すべての列が二者択一のように動作することを示唆しています。 制約を無視すると、答えは単純に 2^n になります。 

この素朴な見方は、構成を生成するという点では正しいですが、グローバル制約を無視しています。つまり、反転後も各行は順列でなければなりません。 つまり、各数値は各行に 1 回だけ出現する必要があるため、列の方向が一貫していないために数値が行内で重複することはありません。 

この問題は次のように再解釈できます。 各数値は、最初は上の行の 1 列に表示され、下の行の 1 列に表示されます。 各数値が 2 つの列を接続していると考えると、各列はグラフ内の 2 つの位置間の接続を引き起こします。つまり、行 1 と行 2 の値の位置がエッジを定義します。 各列は 2 つの数値の間のエッジであり、列を反転すると、どのエンドポイントがどの行に属するかが入れ替わります。 

これにより、各列が無向エッジとなる数値のグラフが形成されます。 行が順列のままであるという制約は、最終的な向きにおいて、各ノードが行 1 への出力エッジを 1 つと行 2 への出力エッジを 1 つずつ持つことを要求することになり、接続されたコンポーネントに沿った方向の一貫性が強制されます。 

接続された各コンポーネントは独立して動作します。 コンポーネント内で 1 つの列の方向を固定すると、残りは伝播によって強制されます。1 つの列を反転することで、重複を避けるために隣接する制約をどのように解決する必要があるかが決まります。 ツリー状コンポーネントの場合、これにより、有効なグローバル方向が 2 つだけ生成されます。 サイクルのあるコンポーネントの場合、整合性により正確に 2 が許容される可能性がありますが、重要な観察は、すべての接続コンポーネントが答えに 2 の係数を与えるということです。 

したがって、タスクは値 1 ～ n にわたるグラフを構築し、同じ列に表示される 2 つの値を接続し、連結成分をカウントすることに要約されます。 答えは 2^(成分数) です。 

ブルート フォースでは、すべての 2^n 反転パターンを試し、チェックごとに O(n) で妥当性をチェックし、結果は O(n・2^n) になります。 最適なアプローチでは、すべての制約を DSU 構造に圧縮し、問題を O(n α(n)) のコンポーネントを数えることに削減します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n · 2^n) | O(n) | 遅すぎる |
 | 最適 (DSU コンポーネント) | O(n α(n)) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 1 から n までの各値をグラフ内のノードとして扱います。 各列は、その列に表示される 2 つの値を接続します。 これにより、n 個のノードにわたる無向グラフが構築されます。 
2. すべてのノードにわたって素セット共用体構造を初期化します。 この構造は、列によって引き起こされる値間の接続性を追跡します。 
3. すべての列について、2 つの値 x と y を取得し、DSU でそれらをマージします。 これは、それらが一緒に表示され、交換は方向にのみ影響し、ペアには影響しないため、それらは同じ接続された構造に属している必要があることをエンコードします。 
4. すべての列を処理した後、DSU 内の接続コンポーネントの数を計算します。 各代表ルートは、制約の 1 つの独立した構造に対応します。 
5. k を連結成分の数とします。 最終的な答えは 2^k モジュロ 1e9+7 です。 

べき乗が現れる理由は、各コンポーネントが 2 つの一貫したグローバル方向を正確に許容するためです。 コンポーネントの方向を選択すると、その内部のすべての列が強制され、競合は発生しません。 

### なぜ効果があるのか

各列は、2 つの値間の厳密な関係を定義します。 スワップは隣接関係を壊すものではなく、行への割り当てを変更するだけです。 これらの関係は、接続されたコンポーネント全体に伝播します。つまり、コンポーネント内のすべての値が相互に制約されます。 構成空間全体がコンポーネントを因数分解し、各コンポーネントには、伝播の初期方向の選択に対応して、行メンバーシップを割り当てるための 2 つの一貫した方法があります。 コンポーネントの独立性により、乗算的なカウントが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.size = [1] * (n + 1)

    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.size[ra] += self.size[rb]

def mod_pow(a, e):
    res = 1
    while e:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

t = int(input())
for _ in range(t):
    n = int(input())
    top = list(map(int, input().split()))
    bottom = list(map(int, input().split()))

    dsu = DSU(n)

    for i in range(n):
        dsu.union(top[i], bottom[i])

    roots = set()
    for i in range(1, n + 1):
        roots.add(dsu.find(i))

    print(mod_pow(2, len(roots)))
```DSU は、同じ列に表示されるすべての値をマージするために使用され、それらの値が同じ接続された構造に属するという制約を取得します。 すべての列を処理した後、すべてのノードをスキャンして、残っている個別の代表の数を数えます。 

各連結成分が二項選択に寄与するため、べき乗ステップが必要となります。 高速な電力実装により、最大 4e5 の合計サイズを効率的に処理できることが保証されます。 

一般的な実装の落とし穴は、パス圧縮を忘れたり、すべてのノードに find を適用せずにコンポーネントを誤ってカウントしたりすることです。これにより、ルートの数が過小評価されてしまいます。 

## 実用的な例

 ### 例 1

 入力:```
n = 4
top    = [1, 4, 2, 3]
bottom = [3, 2, 1, 4]
```結合は列ごとに処理されます。 

| ステップ | ユニオン | DSU コンポーネント |
 | --- | --- | --- |
 | 1 | (1,3) | {1,3}、{2}、{4} |
 | 2 | (4,2) | {1,3}、{2,4} |
 | 3 | (2,1) | {1,2,3,4} |
 | 4 | (3,4) | {1,2,3,4} |

 最終的な成分数は 1 なので、答えは 2^1 = 2 となります。 

これは、複数の列があるにもかかわらず、すべての値が 1 つの制約システムに接続され、一貫したグローバル方向が 2 つだけ残っていることを示しています。 

### 例 2

 入力:```
n = 8
top    = [2,6,5,1,4,3,7,8]
bottom = [3,8,7,5,1,2,4,6]
```もう一度各列のペアをマージします。 

すべての結合を処理した後、4 つの連結成分が得られます。 

{1,3,5}、{2,6,8}、{4}、{7}

 したがって、k = 4、答え = 2^4 = 8 となります。 

この例は、切断された構造が独立して進化し、それぞれが乗算因子に寄与することを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    MOD = 10**9 + 7

    class DSU:
        def __init__(self, n):
            self.parent = list(range(n + 1))
            self.size = [1] * (n + 1)

        def find(self, x):
            while self.parent[x] != x:
                self.parent[x] = self.parent[self.parent[x]]
                x = self.parent[x]
            return x

        def union(self, a, b):
            ra, rb = self.find(a), self.find(b)
            if ra == rb:
                return
            if self.size[ra] < self.size[rb]:
                ra, rb = rb, ra
            self.parent[rb] = ra
            self.size[ra] += self.size[rb]

    def mod_pow(a, e):
        res = 1
        while e:
            if e & 1:
                res = res * a % MOD
            a = a * a % MOD
            e >>= 1
        return res

    t = int(input())
    out = []
    for _ in range(t):
        n = int(input())
        top = list(map(int, input().split()))
        bottom = list(map(int, input().split()))

        dsu = DSU(n)
        for i in range(n):
            dsu.union(top[i], bottom[i])

        roots = set(dsu.find(i) for i in range(1, n + 1))
        out.append(str(mod_pow(2, len(roots))))

    return "\n".join(out)

 ## 特殊なケース

 のような最小限の構成`n = 2`ここで、両方の列が同一のペアであることは、各列が独立しているように見えても、DSU がすべてを 1 つのコンポーネントにまとめていることを示しています。 アルゴリズム Union (1,2) を 2 回実行し、単一のルートを残して 2 つの状態を生成し、可能な 2 つのグローバル行スワップに一致します。 

すべての列がすでに同一のペアを接続する完全に切断された構成では、反対の極端な結果が得られます。 各ノードは分離されたままであるため、それぞれが独自のコンポーネントを提供し、2^n 構成になります。 コンポーネントをマージするユニオンがないため、DSU はこれを自然に保持します。 

単一の大きなサイクルは、制約の伝播効果を最も明確に示します。 すべての値が接続されているにもかかわらず、DSU がすべてを 1 つのコンポーネントにマージすると、アルゴリズムは構成空間全体を正確に 2 つの有効なグローバル方向に正確に縮小します。
