 ## 解決策
 ## セットアップと前提条件

 一定容積の密閉容器を考えてみましょう$V$バルク温度が次のような理想気体を含む$T_1$。 容器の壁は一定の温度に維持されます$T$、 そして$T$等しい必要はない$T_1$。 この問題は、ガスと壁が熱平衡にないときに、ガスによって壁にかかる瞬間的な圧力を求めます。 

重要な点は、壁に到達する分子は気体から来ており、次の速度分布に相当する速度分布を持っているということです。$T_1$、一方、壁温度に順応した後に壁から離れる分子は、 に対応する速度分布を持ちます。$T$。 圧力は壁に伝わる運動量の割合であるため、両方の温度が計算に含まれます。 

壁で完全な熱調節が行われることを想定します。 壁に衝突する分子は温度によって特徴付けられる$T_1$、壁から再放出される分子は温度によって特徴付けられます。$T$。 ガスは十分に希薄化されているため、分子流束の動力学理論式を壁で局所的に使用できます。 

容器は密閉されており、機械的平衡は熱平衡よりもはるかに早く確立されるため、圧力は$P$は気体全体にわたる単一の量です。 壁に隣接する分子密度は、外部から規定された定数ではありません。 容器内のどこにでも同じ圧力がかかるように調整されます。 以下の計算により、次の関係が決まります。$P$、$T$、壁密度$n$。 

## 物理的原理

 壁にかかる圧力は、単位面積当たり、単位時間当たりにその壁に伝わる通常の運動量に等しくなります。 

させて$n$壁に隣接する分子数密度になります。 温度のマクスウェル気体の場合$T_1$、単位時間当たりに壁の単位面積に衝突する分子の流束は、$$\Phi_{\rm in}=n\sqrt{\frac{k_B T_1}{2\pi m}},$$どこ$m$は分子量です。 

入射分子が運ぶ平均法線運動量は次のとおりです。$$\langle p_x\rangle_{\rm in} = \frac{\displaystyle\int_0^\infty m v_x^2 e^{-m v_x^2/(2k_B T_1)}\,dv_x} {\displaystyle\int_0^\infty v_x e^{-m v_x^2/(2k_B T_1)}\,dv_x} = \sqrt{\frac{\pi m k_B T_1}{2}}.$$入射光束に入射分子あたりの平均運動量を乗算すると、次のようになります。$$J_{\rm in} = n\sqrt{\frac{k_B T_1}{2\pi m}} \sqrt{\frac{\pi m k_B T_1}{2}} = \frac12 n k_B T_1.$$壁から出る分子には温度がある$T$。 Let their number density just at emission be$n_w$。 放出されたマクスウェル分布に対して同じ計算を繰り返すと、次のようになります。$$J_{\rm out} = \frac12 n_w k_B T.$$壁にかかる圧力は、入ってくる運動量束と出ていく運動量束の大きさの合計です。$$P=J_{\rm in}+J_{\rm out}.$$静止した壁には分子が蓄積できません。 単位面積および単位時間あたりに壁に到達する分子の数は、壁から出ていく分子の数と等しくなければなりません。 したがって、$$n\sqrt{\frac{k_B T_1}{2\pi m}} = n_w\sqrt{\frac{k_B T}{2\pi m}},$$結果が得られる$$n_w=n\sqrt{\frac{T_1}{T}}.$$## 導出

 置き換える$$n_w=n\sqrt{\frac{T_1}{T}}$$出ていく運動量フラックスの式に代入すると、$$J_{\rm out} = \frac12 n\sqrt{\frac{T_1}{T}}\,k_B T = \frac12 n k_B\sqrt{T_1T}.$$入ってくる磁束はそのまま残ります$$J_{\rm in} = \frac12 n k_B T_1.$$したがって、$$P = \frac12 n k_B T_1 + \frac12 n k_B\sqrt{T_1T} = \frac12 n k_B\left(T_1+\sqrt{T_1T}\right).$$この段階では$n$壁に隣接する密度です。 密閉容器内の圧力は固有の機械的圧力であるため、この関係は壁密度に関して次のように解くことができます。$$n = \frac{2P} {k_B\left(T_1+\sqrt{T_1T}\right)}.$$一定圧力の場合$P$および固定ガス温度$T_1$、壁の温度が上昇すると、この式に従って壁の密度が減少します。 壁の密度は正確に調整され、同じ圧力が維持されます。 

の表現$P$したがって、上記で導出された値は、次のときに圧力が変化するという予測ではありません。$T$変化します。 間の関係です$P$そして局所密度$n$。 以来$n$密閉容器内で独立して固定されていないため、処理によって異なる壁温度での圧力を比較することはできません。$n$一定として。 

圧力は容器内のガスの状態によって決まりますが、壁の温度によって壁に隣接するクヌーセン層の密度が変化します。 

## 結果

 運動理論の計算により次のことが得られます。$$P = \frac12 n k_B\left(T_1+\sqrt{T_1T}\right),$$どこ$n$壁に隣接する分子密度です。 

密閉容器の中で、$n$が固定されていないとき$T$変化します。 その代わり、$$n = \frac{2P} {k_B\left(T_1+\sqrt{T_1T}\right)}$$容器全体に同じ機械的圧力が存在するように調整します。 

したがって、この計算は、圧力がより大きいという主張を裏付けません。$T>T_1$以下の場合$T<T_1$。 壁近傍の密度が変化しても、圧力は同じままにすることができます。 問題で与えられた情報から、不等式はありません$$P(T>T_1)>P(T<T_1)$$または$$P(T>T_1)<P(T<T_1)$$が確立されています。 

動力学理論分析からの正しい結論は、より熱い壁はより低い壁隣接密度に対応し、より冷たい壁はより高い壁隣接密度に対応する一方、圧力自体は壁温度だけによって決まるわけではないということです。 

## 健全性チェック

 いつ$T=T_1$、$$P = \frac12 n k_B(T_1+T_1) = n k_B T_1,$$これは標準の理想ガス圧力です。 

を解決する$n$与える$$n=\frac{P}{k_B T_1},$$平衡理想気体関係を再度再現します。 

いつ$T\to0$、$$P = \frac12 n k_B T_1,$$したがって$$n=\frac{2P}{k_B T_1}.$$壁の密度は、同じ圧力を維持するために必要な平衡値の 2 倍です。 

いつ$T\gg T_1$、$$P \sim \frac12 n k_B\sqrt{T_1T},$$それで$$n \sim \frac{2P}{k_B\sqrt{T_1T}}.$$壁密度は次のように減少します。$T^{-1/2}$一方、圧力は有限のままです。 

これらの限定的なケースは、密閉容器の圧力を直接決定するのではなく、壁温度が壁のすぐ近くの密度を変化させるという解釈と一致しています。
