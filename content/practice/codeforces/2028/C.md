 ## 解決策
 ## 問題の理解

 長いシートケーキを分割して提供されます。`n`セクションごとに美味しさの値が設定されています。 アリスはパーティーに参加しています`m`生き物たち、そして彼女はケーキを切りたいと思っています`m + 1`連続した部分。 それぞれの生き物は、少なくともその部分が美味しければ幸せになるのです`v`。 アリスは、すべての生き物を満足させながら、自分だけのものの美味しさを最大限に引き出したいと考えています。 すべての生き物を満たすことが不可能な場合、出力は次のようになります。`-1`。 

入力により複数のテスト ケースが提供されます。 各テスト ケースは次のように指定します`n`、`m`、 そして`v`、その後に美味しさの値の配列が続きます。 出力は、テスト ケースごとに 1 つの数値、アリスが達成できる最大の美味しさ、または`-1`有効なパーティションが存在しない場合。 

制約を考慮すると、`n`1 つのテスト ケースで最大 2×10^5 になる可能性があり、次の合計`n`すべてのテスト ケースでも ≤2×10^5 です。 これは、テスト ケースあたりの複雑さが O(n log n) を超えるアルゴリズムはタイムアウトする可能性が高いことを意味します。 すべての部分配列をチェックするという O(n^2) の総当りアプローチを行う余裕はありません。 

重要なエッジケースは、`m`少なくとも美味しさの最大の連続部分配列`v`ケーキの合計を超えます。 そのような場合、アリスが自分の駒を最大限に活用しようとしても、すべての生き物を満足させるのに十分なケーキがない可能性があります。 たとえば、次の場合`a = [1,1,1]`、`m=2`、 そして`v=2`、美味しさ ≥2 の 2 個をそれぞれ与える方法はないため、正しい出力は次のようになります。`-1`。 

もう 1 つの微妙な点は、アリス自身のピースが空になる可能性があることです。 クリーチャーの幸福を侵害せずに大きなピースを取得できない状況では、彼女の最適な戦略は、セクションをゼロにすることを含む可能性があり、これは有効です。 

## アプローチ

 ブルートフォースアプローチでは、配列のすべてのパーティションが試行されます。`m + 1`連続したピースを選択し、どれが生き物の美味しさの最低条件を満たしているかを確認します。 有効なパーティションごとに、アリスの個数合計を計算し、最大値を選択します。 配列を分割する方法は指数関数的に多く存在するため、このアプローチは現実的ではありません。 たとえクリーチャーの部分の連続した部分配列に制限したとしても、O(n から m を選択) 個の可能性があり、これは最大 2×10^5 の n には大きすぎます。 

重要な洞察は、問題がバイナリ検索と組み合わせた貪欲なスタイルのプレフィックス合計アプローチに帰着するということです。 アリスがおいしいものを欲しがっていると仮定します。`x`。 各クリーチャーが美味しさ ≥ v の一部を取得し、アリスが美味しさの一部を取得するように、左から右にクリーチャーに貪欲にピースを割り当てることを試みることができます。`x`どこでも。 どうかを確認できます`x`シングルパスを使用して O(n) 時間で達成可能です。 次に、二分探索を実行すると、`x`0からケーキの合計まで、アリスの達成可能な最大の美味しさを効率的に見つけることができます。 

貪欲チェックは次のように機能します。ケーキのセクションを反復処理して、実行中の合計を累積します。 合計額がそれ以上になったとき`v`、それをクリーチャーの駒として割り当て、合計をリセットして続行します。 すべてのクリーチャーが割り当てられた後に残ったセクションは、アリスの部分である可能性があります。 残った合計が ≥ の場合`x`、アリスはそれを受け取ることができます。 アリスの駒を残したまますべてのクリーチャーを割り当てることができない場合 ≥`x`、 それから`x`不可能です。 問題が単調であるため、これにより正しさが保証されます。`x`、彼女はどんな小さな部分でも取ることができます。 彼女が受け入れられない場合`x`、彼女はそれ以上大きな部分を取ることができません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n を選択して m) | O(n) | 遅すぎる |
 | 貪欲 + 二分探索 | O(n log S) | お(1) | 承認済み |

 ここ、`S`はケーキ内のすべての美味しさの値の合計であり、制約を考慮すると最大でも 2×10^14 です。 

## アルゴリズムのチュートリアル

 1. 二分探索の上限としてケーキ セクションの合計を計算します。 
2. 二分探索境界を設定する`low = 0`そして`high = total sum`。 
3. その間`low ≤ high`、 取る`mid = (low + high) // 2`アリスの作品の美味しさ候補として。 
4. 貪欲チェックを実行して、Alice がサイズを取得できるかどうかを確認します。`mid`与えながら`m`少なくとも`v`:

 1.初期化`current_sum = 0`そして`creatures_assigned = 0`。 
2. ケーキのセクションを反復処理します。 

1. 現在のセクションを`current_sum`。 
2. もし`current_sum ≥ v`、それをクリーチャーに割り当ててリセットします`current_sum`0から増分`creatures_assigned`。 
3. もし`creatures_assigned == m`、 壊す。 
3. すべてのクリーチャーが割り当てられた後、未割り当てセクションの残りの合計がアリスの潜在的なピースになります。 
5. アリスの残額が ≥`mid`、それは実現可能です。 動く`low = mid + 1`より大きな部分を試してみる。 
6. それ以外の場合は、設定します`high = mid - 1`。 
7. 二分探索の最後に、`high`アリスの美味しさを最大限に詰め込みました。 たとえさえあれば`0`実行不可能です、出力`-1`。 

不変条件は、すべての二分探索ステップで、指定された条件に対して貪欲な代入が成功するか失敗するかのいずれかであるということです。`mid`。 問題が単調なので最大`mid`成功することが答えです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, v = map(int, input().split())
        a = list(map(int, input().split()))
        total = sum(a)
        low, high = 0, total
        ans = -1
        while low <= high:
            mid = (low + high) // 2
            current_sum = 0
            creatures_assigned = 0
            for val in a:
                current_sum += val
                if current_sum >= v:
                    creatures_assigned += 1
                    current_sum = 0
                    if creatures_assigned == m:
                        break
            # Alice's remaining sum
            remaining = sum(a[a.index(val)+1:]) if creatures_assigned == m else 0
            if remaining >= mid:
                ans = mid
                low = mid + 1
            else:
                high = mid - 1
        print(ans)
        
solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 二分探索ではアリスにとっての美味しさの可能性を探りますが、貪欲チェックでは、`m`生き物も満足できる。 難しいのは、残りの合計を正しく処理することです。 最後のクリーチャーを割り当てた直後に中断し、アリスの残りを合計します。 の`ans`変数には実現可能な最大値が格納されます。
