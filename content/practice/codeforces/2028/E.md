 ## 解決策
 ## 問題の理解

 私たちに与えられた木は、`n`頂点どこの頂点`1`はウサギの穴の出口とみなされ、アリスはある頂点から始まります`v`。 各ターンに公正なコインが投げられます。 表の場合、アリスは移動先の隣接する頂点を選択します。 裏では、ハートの女王がアリスを移動させる隣接する頂点を選択します。 アリスはルート以外の葉に着地すると即座に負け、頂点に到達すると勝ちとなります。`1`。 目標は、すべての頂点について、両側による最適なプレイの下でアリスが逃げる確率を計算することです。 これらの確率はモジュロで出力する必要があります`998244353`。 

入力は複数のテスト ケースで構成され、それぞれが頂点の数とツリー エッジを与えます。 の合計`n`すべてのテスト ケースの境界は次のとおりです`2*10^5`。 これは、およそより遅いアルゴリズムは使用できないことを意味します。`O(n log n)`最悪の場合のテストケースごとに。 特に、すべてのパスを組み合わせて探索する単純なアプローチは実行不可能です。 この問題では、素数を法とする正確な分数も必要となるため、逆剰余を慎重に処理する必要があります。 

明らかではないエッジ ケースには、ルートに直接接続されたリーフ、アリスが前進するパスが 1 つしかないチェーン、または女王がアリスを強制的に負けリーフにできる複数の子を持つ頂点が含まれます。 たとえば、エッジのある木`1-2`、`2-3`、`3-4`頂点にアリスがいる`3`。 アリスが移動すると、次の場所に行くことができます`2`または`4`、しかし女王はいつでも彼女を次の場所に移動させることができます`4`、葉、脱出の確率を作る`0`。 クイーンの最適なカウンタームーブを無視する不注意な BFS は、確率を過大評価することになります。 

## アプローチ

 ブルートフォース ソリューションでは、再帰的またはメモ化を使用して、各開始頂点から考えられるすべてのゲーム シーケンスをシミュレートしようとします。 これは原理的には正しいですが、最悪の場合、ゲーム状態の数はツリーの深さで指数関数的に増加します。 アリスの選択と女王の反対の選択によってすべてのエッジに条件付き確率が作成されるため、頂点によるメモ化でも不十分です。 と`n`まで`2*10^5`、このアプローチは完全に実行不可能です。 

重要な洞察は、ツリー構造を使用して各頂点の確率を再帰的に定義できることを理解することです。 させて`f(v)`アリスが頂点から逃げ出す確率を表す`v`。 もし`v`以外の葉です`1`、`f(v)=0`。 もし`v=1`、`f(1)=1`。 それ以外の場合、アリスは次から選択します`deg(v)`隣人たち。 彼女の番では、最大化する隣人を選ぶことができます`f(u)`。 女王の番では、女王は最小化する隣人を選びます。`f(u)`。 コインは公平なので、確率は`f(v) = (f_max + f_min)/2`どこ`f_max`が最大です`f(u)`近所の人たちと`f_min`最低です`f(u)`。 DFS を使用してこれをリーフからルートに向かって再帰的に計算でき、線形複雑さが保証されます。`O(n)`木ごとに。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 (ツリー上の DFS + DP) | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーのエッジを読み取り、隣接リストを作成します。 これにより、DFS 中に隣接するものを効率的に反復できるようになります。 
2. 再帰的 DFS 関数を定義する`dfs(v, parent)`確率を計算するもの`f(v)`。 通ります`parent`元のノードに再度アクセスするのを避けるためです。 
3. もし`v`根です`1`、リターン確率`1`。 もし`v`ルート以外の葉である場合の戻り確率`0`。 
4.すべての隣人のために`u`の`v`除く`parent`、再帰的に計算します`dfs(u, v)`子供たちから逃げられる確率を求めます。 
5. これらの子の確率の最大値と最小値を計算します。 最大値はアリスの最適な手を表し、最小値はクイーンの最適な手を表します。 
6. コンピューティング`(max + min) / 2`モジュラー演算を使用した分数として。 保管してください`v`再計算を避けるため。 
7. DFS 後、頂点の確率を出力します。`1`を通して`n`モジュロ`998244353`。 

機能する理由: DFS は葉から上に向かって確率を計算します。 各頂点でアリスとクイーンの両方にとって最適な動きを常に考慮することで、次の不変条件が維持されます。`f(v)`完璧なプレーの下での脱出の確率を正確に表します。 モジュラー演算を使用すると、分数計算の正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

MOD = 998244353
INV2 = pow(2, MOD-2, MOD)  # Modular inverse of 2

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        adj = [[] for _ in range(n)]
        for _ in range(n-1):
            x, y = map(int, input().split())
            adj[x-1].append(y-1)
            adj[y-1].append(x-1)
        
        dp = [0]*n
        visited = [False]*n
        
        def dfs(v, parent):
            visited[v] = True
            children = [u for u in adj[v] if u != parent]
            if v == 0:
                dp[v] = 1
                return dp[v]
            if not children:
                dp[v] = 0
                return dp[v]
            child_probs = [dfs(u, v) for u in children]
            max_prob = max(child_probs)
            min_prob = min(child_probs)
            dp[v] = (max_prob + min_prob) * INV2 % MOD
            return dp[v]
        
        dfs(0, -1)
        print(' '.join(map(str, dp)))

if __name__ == "__main__":
    solve()
```このソリューションは隣接関係リストを構築し、ルートから DFS を実行します。 リーフの検出は自動的に行われます。親を除く子のないノードはすべてリーフです。 モジュラーの逆`2`2 による除算を処理します。結果を次の場所に保存します。`dp`各ノードが 1 回処理されるようにします。 確率を頂点の順序で出力します。
