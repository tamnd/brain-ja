 ## 解決策
 ## 問題の理解

 アリスは 2 次元グリッド上の原点から開始し、4 つの基本方向に移動できます。 彼女には決まった一連の動作があり、それを無限に繰り返します。 赤の女王は固定座標に位置します`(a, b)`、そしてアリスが最終的にその場所に到達するかどうかを判断するように求められます。 入力は複数のテスト ケースを提供し、それぞれが移動シーケンスの長さ、ターゲット座標、および移動文字列を指定します。 

グリッド座標が小さい (`1 ≤ n, a, b ≤ 10`)、シーケンスの長さも非常に短いです。 これにより、パフォーマンスを気にせずに、アリスのモーションを直接シミュレートできます。 重要な課題は、アリスが移動シーケンスを永遠に繰り返すため、パスが周期的であるとみなせることです。 シーケンスの 1 回の走査だけでなく、繰り返しサイクルにわたって彼女が占めるすべての位置を考慮する必要があります。 

明らかではないエッジ ケースには、ループ内で移動するシーケンスや、ターゲットをオーバーシュートする可能性のある方法で移動するシーケンスが含まれます。 たとえば、アリスのシーケンスが次の場合、`NESW`そして赤の女王はここにいます`(1,1)`、最初のサイクルで彼女は乗り越えます`(0,1) → (1,1) → (1,0) → (0,0)`、2番目のステップで目標に到達します。 シーケンスが完了した後でのみチェックする単純なアプローチでは、これを見逃す可能性があります。 

## アプローチ

 ブルートフォース手法では、アリスがターゲットに到達するか、繰り返し位置が検出されるまで、アリスの動きを無期限にシミュレートします。 最悪の場合、これには無限に時間がかかる可能性がありますが、制約を考慮すると、実際にはステップ数を制限することができます。 ターゲットの最大座標は 10 で、移動シーケンスの長さは最大 10 であるため、アリスは 1 サイクルで原点からどの方向にも 10 ユニットを超えて移動することはできません。 シーケンスを数回繰り返すと、次のように定義された境界ボックス内のすべての到達可能な位置がカバーされます。`[-10,10] × [-10,10]`。 これらすべての位置をシミュレーションすると、アリスは目標に到達したか、到達できないかのどちらかになります。 

より数学的なアプローチは、シーケンスの 1 つの完全なサイクルの合計変位を計算し、ターゲット座標がこの変位とサイクルのプレフィックスの非負の整数の組み合わせとして表現できるかどうかを判断することです。 最大座標は小さいため、これはすべてのプレフィックスを反復処理して、ターゲットとプレフィックス変位の差が全サイクル変位の倍数であるかどうかを確認することになります。 

制約を考慮すると、最初のアプローチの方が単純で、完全に受け入れられます。

 ## アルゴリズムのチュートリアル

 1. For each test case, read the sequence length`n`、ターゲット座標`(a, b)`、および移動文字列`s`。 
2. アリスの現在位置を初期化します。`(0,0)`そして、辞書マッピングが変更を調整するために移動します。`'N' → (0,1)`、`'E' → (1,0)`、`'S' → (0,-1)`、`'W' → (-1,0)`。 
3. 1 つの完全なシーケンス後の各移動の変化を合計することにより、合計変位を計算します。`s`。 
4. シーケンスの各プレフィックスで到達した位置を反復します。 プレフィックスごとに、到達するために必要な残りの変位を計算します。`(a,b)`いくつかの完全なサイクルを完了した後。 
5. 残りの変位が x 方向と y 方向の両方で全サイクル変位の整数倍であるかどうかを確認します。 アリスはサイクル内でしか前進できないため、非負の倍数のみが有効です。 
6. いずれかのプレフィックスにそのような組み合わせが存在する場合は、「YES」を出力します。 それ以外の場合は「NO」を出力します。 

**機能する理由**: アリスが到達できる各位置は、プレフィックス変位とフルサイクル変位の非負倍数の合計です。 すべてのプレフィックスをチェックし、ターゲットからプレフィックスを引いた値がサイクル ディスプレイスメントの非負の倍数であるかどうかを検証することで、アリスが占有することができるすべての位置をカバーします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can_meet(a, b, s):
    n = len(s)
    dx = {'N': 0, 'E': 1, 'S': 0, 'W': -1}
    dy = {'N': 1, 'E': 0, 'S': -1, 'W': 0}

    # prefix positions
    px = [0]
    py = [0]
    for move in s:
        px.append(px[-1] + dx[move])
        py.append(py[-1] + dy[move])

    total_dx = px[-1]
    total_dy = py[-1]

    for i in range(n + 1):
        rem_x = a - px[i]
        rem_y = b - py[i]

        # check if the remaining displacement can be reached via full cycles
        if total_dx == 0 and total_dy == 0:
            if rem_x == 0 and rem_y == 0:
                return True
        elif total_dx == 0:
            if rem_x == 0 and rem_y % total_dy == 0 and rem_y // total_dy >= 0:
                return True
        elif total_dy == 0:
            if rem_y == 0 and rem_x % total_dx == 0 and rem_x // total_dx >= 0:
                return True
        else:
            if rem_x % total_dx == 0 and rem_y % total_dy == 0:
                kx = rem_x // total_dx
                ky = rem_y // total_dy
                if kx == ky and kx >= 0:
                    return True
    return False

def main():
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        s = input().strip()
        print("YES" if can_meet(a, b, s) else "NO")

if __name__ == "__main__":
    main()
```**説明**: このソリューションは、すべての到達可能な位置を、プレフィックス ディスプレイスメントと完全なシーケンス ディスプレイスメントの倍数の合計として計算します。 変位ゼロの場合を処理し、負の倍数を回避し、両方の軸が等しいかどうかをチェックします。
