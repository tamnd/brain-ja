 ## 解決策
 ## 問題の理解

 1 から 6 までの一連の数字が与えられ、任意の要素を 1 から 6 までの他の値に変更することができます。目標は、隣接する要素のすべてのペアが標準的なサイコロの有効な遷移のように動作するようにシーケンスを変換することです。 

標準的なダイは、(1,6)、(2,5)、(3,4) としてペアになった反対側の面を持つと考えることができます。 2 つの数値が等しくなく、向かい合った面でもない場合、隣接関係に互換性があるとみなされます。 したがって、どの面から見ても、有効な近傍はちょうど 4 つ存在します。 

面の割り当ての下ですべての連続するペアがこの隣接規則を満たすように、配列の変更を最小限に抑えたいと考えています。 

重要な問題は、トランジションを独自に選択していないことです。 位置 i に割り当てられる値は、その前および次の近隣の選択の両方と一致する必要があります。これにより、ノードの変更を最小限に抑えながらグラフに沿って歩くのと同様のグローバルな一貫性制約が作成されます。 

制約は大きく、テスト ケース全体の合計 n は最大 3⋅10^5 です。 これにより、テスト ケースごとに二次関数が即座に除外されます。 すべてのソリューションは、合計入力サイズにおいて線形またはほぼ線形である必要があります。 定常状態の位置ごとの DP は妥当です。 

微妙なエッジケースは、ローカルでの貪欲な選択が失敗する場合です。 たとえば、各ステップで常に最適な有効な近傍を選択すると、余分な変更を加えずに後の位置を一致させることが不可能になる窮地に陥る可能性があります。 これは通常、互換性のない強制移行が交互に繰り返されるようなシーケンスで発生し、早期の決定により将来の柔軟性が低下します。 

## アプローチ

 強引に試す場合は、各位置を 1 ～ 6 の値を選択するものとして扱い、隣接するもの間の隣接性制約を確保します。 これは基本的に、すべての有効なシーケンスに対する最小の不一致数をカウントします。 素朴な方法は、位置ごとに 6 つの選択肢をすべて試して 6^n 個のシーケンスを与えることですが、これは n = 20 を超えると完全に実行不可能です。 

この問題を位置に関する動的計画法として再構成できます。 各インデックス i でどの値で終了するかを決定し、それが元の a[i] と異なる場合はコストを支払います。 i-1 と i の間の遷移は、2 つの値が立方体上で隣接している場合にのみ許可されます。 

これにより、階層化されたグラフが作成されます。各位置には 6 つの状態があり、有効な隣接面の間にエッジが存在します。 レイヤ 1 からレイヤ n への最小コストのパスが必要です。 

重要な観察は、立方体の構造が固定されており、非常に小さいということです。 各面にはちょうど 4 つの隣接面があるため、遷移は定数時間になります。 これにより、問題は O(n⋅6) 状態と状態ごとの一定の遷移による DP に縮小されます。 

また、DP は考えられるすべての最後の面の選択を同時に転送し、後で最適である可能性のあるパスを決して破棄しないようにするため、貪欲な間違いも回避できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(6^n) | O(n) | 遅すぎる |
 | 最適なDP | O(n) | O(n) または O(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 最終シーケンスで a[i] を値 x に設定した場合に、インデックス i までのプレフィックスに必要な変更の最小数として dp[i][x] を定義します。 

1. 1 ～ 6 のすべての x の dp[1][x] を、x が a[1] に等しい場合は 0、それ以外の場合は 1 に初期化します。 

これは、最初の値を選択し、それを上書きする場合にコストを支払うことを表します。 
2. 2 ～ n の位置 i ごとに、1 ～ 6 のすべての x について dp[i][x] を計算します。 

各状態は、位置 i を強制的に値 x にすることを表します。 
3. 位置 i の各候補値 x について、y が立方体上の x に隣接するように、以前のすべての値 y を考慮します。 

無効なペアはシーケンスを壊すため、有効なダイス隣接からの遷移のみを許可します。 
4. dp[i][x] を、dp[i−1][y] +cost(i, x) のすべての有効な y の最小値に設定します。ここで、cost(i, x) は、a[i] ≠ x の場合は 1、それ以外の場合は 0 です。

これにより、移行の有効性と変更コストの両方が確実に考慮されます。 
5. 答えは、1 ～ 6 の x に対するすべての dp[n][x] の最小値です。 

中心的な考え方は、すべてのステップで可能なすべての最終面構成を維持し、有効なキューブの前進のみを伝播するということです。 

### なぜ効果があるのか

 各位置 i で、DP 状態は、特定の面 x で終わるプレフィックスを構築するためのすべての有効な方法を完全に要約します。 有効な完全なシーケンスは、これらの状態を通る 1 つのパスに正確に対応する必要があります。 遷移では隣接する立方体面のみが許可されるため、すべての DP 遷移ではサイコロ条件の有効性が維持されます。 考えられるすべての以前の有効な状態を試して最小コストを取るため、どのステップでも全体的に最適な構成を除外することはできません。 

これは階層化グラフ上の標準的な最短パスであり、ノードは (位置、面) ペアであり、エッジはユニット コストまたはゼロ コストの有効な立方体遷移を表します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# adjacency list for a standard die
adj = {
    1: [2, 3, 4, 5],
    2: [1, 3, 6, 4],
    3: [1, 2, 6, 5],
    4: [1, 2, 6, 5],
    5: [1, 3, 6, 4],
    6: [2, 3, 4, 5]
}

INF = 10**9

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    dp_prev = [INF] * 7
    dp_cur = [INF] * 7

    for x in range(1, 7):
        dp_prev[x] = 0 if a[0] == x else 1

    for i in range(1, n):
        for x in range(1, 7):
            best = INF
            cost = 0 if a[i] == x else 1
            for y in adj[x]:
                best = min(best, dp_prev[y])
            dp_cur[x] = best + cost

        dp_prev, dp_cur = dp_cur, [INF] * 7

    print(min(dp_prev[1:]))
```各ステップで必要なのは前の行のみであるため、DP は 2 つのローリング配列を使用して実装されます。 隣接リストはキューブ ジオメトリを明示的にエンコードし、遷移が正しいことを保証します。 

よくある間違いは、遷移の方向を逆にしてしまうことですが、ここでは隣接関係が対称であるため、以前の状態で x の近傍を反復処理しても、すべての有効な遷移が正しくキャプチャされます。 もう 1 つの微妙な点は、遷移制約がまだ存在しない最初の要素に対して dp を適切に初期化することです。 

## 実用的な例

 ### 例 1

 入力:```
3
1 4 2
```dp を i = 1 で初期化します。 

| 顔× | コスト |
 | --- | --- |
 | 1 | 0 |
 | 2 | 1 |
 | 3 | 1 |
 | 4 | 0 |
 | 5 | 1 |
 | 6 | 1 |

 i = 2 および i = 3 では、遷移は変更を必要とせずに常に実行可能であるため、コストは 0 のままです。シーケンスではすでにキューブの隣接関係が考慮されているため、DP はゼロコストのパスを伝播します。 

これにより、DP が不必要な変更を強制することなく、有効な既存のシーケンスを正しく保存していることが確認されます。 

### 例 2

 入力:```
3
3
3 4 6 3
```関連する状態のみを追跡します。 

| 私 | 選択された x | 過去の最高の y | コスト | dp[i][x] |
 | --- | --- | --- | --- | --- |
 | 1 | 3 | - | 0 | 0 |
 | 2 | 4 | 4 の有効な近傍には 3 が含まれます | 0 | 0 |
 | 3 | 6 | 6 | の有効な近隣から取得する必要があります。 0 | 0 |
 | 4 | 3 | 移行には調整が必要な場合があります | 1 | 1 |

 最後のステップで、有効な継続を強制するには、1 つの要素を変更する必要があります。 DP は、最適なパスには以前の手順をローカルで修正するのではなく、1 回の変更が必要であることを捉えています。 

これは、貪欲な修正が失敗する理由を示しています。ローカルな妥当性は、以前の選択を再考することなく、グローバルな実現可能性を保証しません。

        n = int(input())

        dp_cur = [INF] * 7

    return "\n".join(out)

 ## 特殊なケース

 厄介な状況は、シーケンスに有効な遷移ではない繰り返し値が含まれている場合です。`[1,1,1,1]`。 DP は、有効な隣接面を通過する遷移を強制することでこれを処理するため、有効な隣接面パスにマッピングできない限り、繰り返しごとにコストが発生します。 このアルゴリズムは、無効な等しい隣接関係を繰り返し保持しようとするのではなく、変更を最小限に抑える一貫した面の割り当てを自然に選択します。 

別のケースは、長さ 2 の短いシーケンスで、ペアが次のような反対側の面になります。`[1,6]`。 1 と 6 は隣接していないため、少なくとも 1 つは変更する必要があります。 DP は両方の可能性を正しく評価し、コスト 1 を選択します。 

局所的に最適な遷移がグローバルに拡張されない場合、より微妙なケースが発生します。たとえば、`[3,4,6,3]`。 中間要素を 1 つだけ固定すれば十分ですが、貪欲なアプローチでは複数の位置を誤って固定しようとする可能性があります。 DP はすべてのパスを同時に正しく評価し、単一変更の解決策を見つけます。
