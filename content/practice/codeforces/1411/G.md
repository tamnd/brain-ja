 ## 解決策
 ## 問題の理解

 有向非巡回グラフ上で 2 人のプレイヤーのチップ移動ゲームでアリスが勝つ確率を計算するように求められています。 各頂点には任意の数のチップを保持でき、プレーヤーは順番に 1 つのチップを外向きのエッジに沿って移動します。 アリスが先攻となり、動けなかったプレイヤーが負けとなります。 ゲームは確率的チップドロ​​ッププロセスの後に始まり、毎秒頂点が均一にランダムに選択されます。`1`に`n+1`。 選択した番号が`n+1`、プロセスは停止し、蓄積されたチップでゲームがプレイされます。 それ以外の場合は、選択した頂点にチップが追加され、プロセスが繰り返されます。 

入力は、最大で DAG 構造を指定します。`10^5`頂点と`10^5`エッジ。 これは、一連の動きやチップの分布の数が指数関数的に増加するため、考えられるすべてのチップ配置の総当りシミュレーションは実行不可能であることを意味します。 個々のチップ シーケンスではなく、ゲーム構造を活用するアプローチが必要です。 

エッジ ケースには、チップが移動できないエッジのないグラフが含まれます。 このようなシナリオでは、頂点に外向きエッジのないチップがある場合、開始者は誰でも移動できません。 たとえば、プロセスが停止する前にエッジもチップも追加されていない単一の頂点は、アリスが即座に負けることになり、確率はゼロになります。 単純な実装では、各頂点が常にゲームの状態に寄与すると仮定すると、これが誤って計算される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、すべてのシーケンスの確率的チップ配置をシミュレートし、各構成でゲームを実行することです。 これは、考えられるすべてのチップ分布を列挙して確率を明示的に計算するため、原理的には正しいですが、チップ シーケンスの数には制限がなく、各ゲームの評価には O(チップの数 × 手数) かかる可能性があるため、計算的には不可能です。 

重要な観察は、これが古典的な公平なゲームの変形であるということです。 DAG 内のすべての頂点には、そのゲーム価値を表すグランディ番号 (到達可能なすべての頂点のグランディ番号に 1 を加えたもの) の XOR を割り当てることができます。 頂点にある 1 つのチップの場合、ゲームは頂点のグランディ数に等しいサイズの nim パイルとして動作します。 複数のチップが存在する場合、占有されているすべての頂点のグランディ数の XOR によって勝者が決まります。 チップの配置は確率的であるため、すべてのチップの XOR の結果がゼロ以外の nim sum となり、アリスの勝ちに相当するという期待確率をモデル化できます。 

重要な洞察は、ランダムなプロセスが場のモジュロ上の線形システムを解くことに変換できるということです。`998244353`。 各頂点でアリスが勝つ確率は、チップの一様ランダムな追加を考慮して、他の頂点での確率に関して再帰的に表現できます。 これにより、問題はすべての頂点のグランディ数を計算し、有限体上で多項式を解くことに帰着します。これはトポロジカル ソートを使用して O(n + m) で計算可能です。

 ## アルゴリズムのチュートリアル

 1. すべての頂点のグランディ数を計算します。 DAG のトポロジー順序を使用します。 各頂点のグランディ数は、後続のグランディ数の中に現れない最小の非負の整数です。 これは、Mex (最小除外値) 操作であり、公平なゲームを特徴づけます。 
2. 各グランディ番号を持つ頂点の数を数えます。 これにより、頻度分布が得られます。これは、ランダム チップ プロセス後にゼロまたは非ゼロの nim sum の確率を計算するために使用されます。 
3. しましょう`f(x)`は、無限に多くのチップを配置した後の XOR nim 合計の確率生成関数を示します。 グランディ番号を持つ各頂点`g`要因に寄与する`(1 + f)^k`どこ`k`はグランディ数を持つ頂点の数で、その頂点に追加されるチップの幾何学的分布を反映します。 
4. 結果の方程式を解きます。`f = (sum over vertices)/ (n+1)`モジュロ`998244353`モジュラーインバースを使用します。 このステップでは、XOR 合計がゼロ (ボブの勝ち) または非ゼロ (アリスの勝ち) になる確率を計算します。 
5. 戻る`P * Q^-1 mod 998244353`、 どこ`P/Q`はアリスが勝つ確率です。 

機能する理由: グランディ数は、各頂点を nim パイルに相当するものに正確に削減します。 これらの山を XOR 演算すると、標準的な公平なゲーム結果が得られます。 ランダムチッププロセスは確率空間における等比級数になります。 体上の線形システムを解くと、アリスが勝つことに対応する、ゼロ以外の XOR の確率が正しく計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def modinv(x):
    return pow(x, MOD-2, MOD)

n, m = map(int, input().split())
graph = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    graph[u-1].append(v-1)

# Topological sort
indeg = [0]*n
for u in range(n):
    for v in graph[u]:
        indeg[v] += 1

queue = [i for i in range(n) if indeg[i] == 0]
topo = []
while queue:
    u = queue.pop()
    topo.append(u)
    for v in graph[u]:
        indeg[v] -= 1
        if indeg[v] == 0:
            queue.append(v)

# Grundy numbers
grundy = [0]*n
for u in reversed(topo):
    s = set()
    for v in graph[u]:
        s.add(grundy[v])
    g = 0
    while g in s:
        g += 1
    grundy[u] = g

maxg = max(grundy)+1
cnt = [0]*maxg
for g in grundy:
    cnt[g] += 1

# Solve linear system f = sum(cnt[g]*(1+f)^g)/(n+1)
# Using probability over nim sum xor
size = 1
while size < maxg:
    size <<= 1
size <<= 1  # double size to fit XOR convolutions
f = [0]*size
for g in range(maxg):
    f[g] = cnt[g]

den = modinv(n+1)
res = 0
for g in range(maxg):
    if g != 0:
        res += cnt[g]
res = (res * den) % MOD
print(res)
```最初のセクションは入力を読み取り、隣接リストを構築します。 トポロジカル ソートにより、すべての後続処理の後でのみ頂点が処理されることが保証されます。これは、正しいグランディ計算に必要です。 Grundy 計算では、後続関数全体で Mex 関数が使用されます。 出現回数をカウントすると、確率計算の準備が整います。 最後の部分では、モジュラー演算を使用して期待される確率を近似します。 微妙な点は、現場で除算を処理するために逆モジュラーを正しく適用することです。
