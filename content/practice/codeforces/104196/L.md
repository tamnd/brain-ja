 ## 解決策
 ## 問題の理解

 公園を表す小さなグリッドが与えられています。 各セルは、-1 でマークされた空の水か、固有の正の高さを持つ彫像を含んでいます。 すべての彫像は個別であるため、最小から最大までの厳密なグローバル順序があると考えることができます。 

公園の管理者は、非常に特殊なルールに基づいて彫像を「再配置」したいと考えています。 まず、グリッドの 4 つの隅の 1 つを選択します。 この選択により、対角線のファミリーが決定されます。セルは、その角からのマンハッタン スタイルの対角線距離によってグループ化されます。 この角が固定されると、すべてのセルは角から離れて昇順に番号が付けられた対角線上に配置されます。 

次に、すべての彫像を高さの順に並べ替え、これらの対角線のグループに順番に割り当てます。 最も小さな彫像は最初の対角線のグループに配置され、次のグループは 2 番目の対角線に配置され、以下同様になります。 各バッチのサイズは、各対角線に存在する非水セルの数によって決まります。 水セルは無視され、彫像を受け取りません。 

対角グループ内では、配置は柔軟です。 その対角線に割り当てられた彫像は、その対角線の任意の有効なセルに配置できます。 この自由は、重要なのは彫像が最終的にどの対角線に割り当てられるかだけであり、対角線内の正確な位置ではないことを意味します。 

構成のコストは、割り当てられた対角線と一致するセルにまだ存在していないスタチューの数です。 同様に、元の位置の対角線と一致する対角線に最終的に割り当てられる彫像の数を最大化したいと考えています。 

タスクは、4 つの隅の選択肢をすべて試して、移動する必要がある彫像の数を最小限に抑えながら、可能な限り最適な配置を選択することです。 

グリッドは最大 50 x 50 なので、セルの数は最大 2500 個になります。 これにより、割り当てを明示的に並べ替えたり、階乗または指数関数的な方法で再配置をシミュレートしようとするソリューションは即座に除外されます。 平$O(n^3)$アプローチは安全ですが、制限が小さいことを考慮すると、構成ごとのソートや繰り返しのマッチングを伴うものでも問題ありません。 

微妙なエッジ ケースは、水のセルが斜めに不均一に壊れることです。 たとえば、同じ幾何学的構造を持つ 2 つの対角線は、存在する水セルの数に応じて異なる容量を持つ可能性があります。 これは、彫像の割り当てがジオメトリのみではなく、対角線の容量のみに依存するため、重要です。 

もう 1 つの落とし穴は、対角線の内側に彫像を個別に配置し、各セルを貪欲に処理できると仮定していることです。 それは誤りです。この制限は高さによるランク順から来ており、どの彫像がどの対角線に入るのかをグローバルに固定します。 

## アプローチ

 強引な解釈では、プロセス全体をシミュレートしようとします。 コーナーを固定し、残りの最小の彫像を現在の対角線にいっぱいになるまで繰り返し割り当て、次の対角線に移動して続行します。 完全な最終配置を構築した後、それを元のグリッドと比較し、不一致をカウントします。 これはすでに意図したプロセスに近づいており、それは正しいことですが、これをコーナーごとに注意深く行うには、依然として分類と簿記が必要です。 

重要な観察は、実際には対角線内の個々の彫像の動きをシミュレートする必要がないということです。 コーナーが修正されると、割り当て構造は決定的になります。 

各対角線には、その中の非水セルの数に等しい固定容量があります。 彫像を高さで分類すると、これらの容量に一致するサイズの連続したブロックに分割されます。 したがって、すべての彫像には、ソートされたリスト内のランクに純粋に基づいて対角線が割り当てられます。 

これにより、問題全体が比較問題に帰着します。 固定コーナーの場合、すべてのセルの対角インデックスと、その対角に割り当てられたランク間隔の 2 つを計算します。 次に、割り当てられている対角線と対角線のインデックスが一致するセルに、もともと彫像がいくつあるかを確認するだけです。 

最適な答えは、4 隅にわたって最高です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | コーナーごとの割り当てをシミュレートする |$O(4 \cdot n m \log(nm))$|$O(nm)$| 承認済み |
 | 直接対角マッピング + カウンティング |$O(4 \cdot n m \log(nm))$|$O(nm)$| 承認済み |

 どちらも最終的には同様の複雑さになりますが、2 番目の方法では不必要なシミュレーションが回避され、正確性が透明になります。 

## アルゴリズムのチュートリアル

 考えられる 4 つの角をそれぞれ個別に処理します。 

### 1. 対角恒等式を計算する

 固定コーナーの場合は、すべてのセルにそのコーナーからの距離に基づいて対角インデックスを割り当てます。 たとえば、左上隅から対角線には次のようにインデックスが付けられます。$i + j$。 他のコーナーからは、それに応じて式が変わります。 

水セルは構造的には依然として対角線の一部ですが、容量には寄与しません。 

このステップが必要なのは、その後のすべての推論が、選択した方向による一貫したセルのグループ化に依存しているためです。 

### 2. 対角線の容量を数える

 対角インデックスごとに、水ではないセルの数を数えます。 これにより、その対角線に割り当てられる彫像の数が決まります。 

この容量は、各対角線に入るランクの数を決定する唯一のものです。 

### 3. 彫像を高さ順に並べ替える

 グリッドからすべての彫像の値を抽出し、それらを徐々に並べ替えます。 すべての高さは異なるため、最小値から最大値までの厳密な順序が作成されます。 

この順序は、割り当てに使用されるグローバル シーケンスです。 

### 4. 対角ごとのランク間隔を構築する

 インデックスの昇順で対角線を移動します。 ソートされた彫像リスト上で実行中のポインタを維持します。 容量のある対角ごとに$c$、次に割り当てます$c$ソートされた順序での彫像。 これにより、各対角線に連続したランクの間隔が作成されます。 

このステップでは、割り当てルール全体を単純なインデックス範囲にエンコードします。 

### 5. 元の配置と比較する

 グリッド内のすべての彫像について、元の対角インデックスとソートされたリスト内のランクの 2 つの値を決定します。 ランクを使用して、それがどの対角間隔に割り当てられているかを見つけます。 これらが一致する場合、像を移動する必要はありません。 

この条件を満たす彫像の数を数えてください。 

### 6. すべてのコーナーを試す

 4 隅すべてに対して手順 1 ～ 5 を繰り返し、固定スタチューの最大数を取得します。 答えは、合計ステータスからこの最大値を引いたものです。 

### なぜ効果があるのか

 コーナーが修正されると、プロセスはソートされたランクから対角線への決定論的なマッピングを定義します。 各対角線の内側では、完全な柔軟性により位置の制約が取り除かれます。 重要な唯一の不変条件は、彫像の元の対角線が割り当てられた対角線の間隔と一致するかどうかです。 すべての割り当ては連続するランク セグメントにのみ依存するため、問題は同じセルのセットの 2 つの固定ラベルの一致に帰着します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [list(map(int, input().split())) for _ in range(n)]

    statues = []
    for i in range(n):
        for j in range(m):
            if grid[i][j] != -1:
                statues.append((grid[i][j], i, j))

    if not statues:
        print(0)
        return

    statues.sort()  # by height
    total = len(statues)

    def get_diag_id(i, j, corner):
        if corner == 0:  # top-left
            return i + j
        if corner == 1:  # top-right
            return i + (m - 1 - j)
        if corner == 2:  # bottom-left
            return (n - 1 - i) + j
        return (n - 1 - i) + (m - 1 - j)

    best = 0

    for corner in range(4):
        diag_cells = {}
        diag_id = [[0] * m for _ in range(n)]

        for i in range(n):
            for j in range(m):
                d = get_diag_id(i, j, corner)
                diag_id[i][j] = d
                if grid[i][j] != -1:
                    diag_cells[d] = diag_cells.get(d, 0) + 1

        # build assignment ranges
        order = sorted(diag_cells.keys())
        start = {}
        cur = 0
        for d in order:
            start[d] = cur
            cur += diag_cells[d]

        # for each statue, check match
        fixed = 0
        for rank, (val, i, j) in enumerate(statues):
            d = diag_id[i][j]
            # find which diagonal this rank goes to
            # locate d's interval by checking next boundary
            # since small, linear scan over keys is fine
            # but we precompute list of boundaries
            # build once
            pass

        # rebuild intervals properly
        boundaries = []
        for d in order:
            boundaries.append((start[d], start[d] + diag_cells[d], d))

        fixed = 0
        for rank, (val, i, j) in enumerate(statues):
            d_orig = diag_id[i][j]
            for L, R, dd in boundaries:
                if L <= rank < R:
                    if dd == d_orig:
                        fixed += 1
                    break

        best = max(best, fixed)

    print(total - best)

```コードは、すべての彫像セルを抽出し、高さによって並べ替えることから始まります。これにより、グローバルな割り当て順序が決まります。 コーナーごとに、すべてのセルの対角識別子を一貫して計算します。 次に、各対角線が受け取る必要がある彫像の数をカウントします。これにより、ソートされたランクを対角線の間隔に分割することが完全に決定されます。 

少し間接的な部分は、ランクを対角間隔にマッピングし直すことです。 これは、間隔リストをスキャンすることによって実装されます。これは、対角線の数が最大でも次のとおりであるため、許容されます。$n + m$、100 で区切られます。 

最後に、各彫像の元の対角線とそのランクに割り当てられた対角線を比較します。 すべての一致は、その場に留まる彫像に対応します。

 ## 特殊なケース

 特殊なケースは、対角線に水セルのみが含まれる場合に発生します。 この状況では、その容量はゼロであるため、ランクは割り当てられません。 このような対角線は割り当て間隔には決して現れないため、アルゴリズムはこれを自然に処理します。 

別のケースは、すべての彫像が 1 つの角の下で同じ対角線上にある場合です。 この場合、すべての彫像は単一の間隔に属します。つまり、すべての彫像が同じ対角線に割り当てられます。 すべてのランクがその 1 つの間隔にマッピングされ、比較は元の対角の一貫性をチェックするだけなので、アルゴリズムは引き続き機能します。 

3 番目のケースは、複数のコーナーが同一の斜めのパーティションを生成する場合です。 アルゴリズムはそれぞれを独立して評価するため、構造が繰り返されても正確性やパフォーマンスに影響を与えません。 

これらの動作は、対角線が純粋に容量バケットとして扱われ、空のバケットは単にランク割り当ての間隔に寄与しないという事実から直接得られます。
