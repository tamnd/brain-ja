 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースは、数直線上の閉じたセグメントのコレクションを提供します。 タスクは、一方のグループのセグメントがもう一方のグループのセグメントと重ならないように、すべてのセグメントを 2 つのグループのいずれかに割り当てることです。 ここでのオーバーラップとは、2 つのセグメントの交差点が空ではないことを意味します (単一点での接触を含む)。 

要件を理解する別の方法は、グループ 1 から任意のセグメントを選択し、グループ 2 から任意のセグメントを選択する場合、これら 2 つのセグメントは線上で完全に切り離されている必要があるということです。 

このようなセグメントの 2 分割が存在するかどうかを判断し、存在する場合は 1 つの有効な割り当てを出力する必要があります。 

制約が非常に厳しいため、テスト ケースごとにセグメントのすべてのペアを比較するソリューションは失敗します。 最悪の場合、1 つのテストに 100,000 のセグメントが含まれ、最大 50,000 のテスト ケースが存在します。 各テスト内の二次チェックでは、合計で約 10^10 の比較が行われることになりますが、これは 2 秒の制限をはるかに超えています。 これにより、ペアごとのチェックや、セグメントごとに完全なセットを繰り返しスキャンするアプローチが即座に排除されます。 

すべてのセグメントが間接的であってもオーバーラップを介して接続されている場合、微妙なコーナーケースが発生します。 たとえば、セグメント A が B と重なり、B が C と重なる場合、A が C と重ならなくても、3 つすべてが効果的に接続された構造を形成します。 その場合、両方のグループが空でない必要がある場合、交差することなくそれらを 2 つのグループに分離することは不可能になります。 この状況は、オーバーラップの下で単一の連結コンポーネントを形成するセット全体に対応します。 

セグメントがすでに「ギャップ」によってきれいに分離できる場合、別の特殊なケースが発生します。 たとえば、すべてのセグメントが [1, 10] または [20, 30] にあり、2 つのクラスター間に重複がない場合、有効なパーティションが自然に存在します。 課題は、そのような分割が存在するかどうかを検出し、それを効率的に構築することです。 

## アプローチ

 単純なアイデアは、各セグメントをグラフ内のノードとして扱い、セグメントが交差する場合は 2 つのノードを接続するというものです。 その場合、条件は次のようになります。異なる色を接続するエッジが存在しないように、ノードに 2 つの色を割り当てる必要があります。 ただし、これは標準の 2 部条件ではありません。同じ色のエッジを避ける必要はなく、交差する色のエッジを避ける必要があるためです。 これは論理を反転させます。隣接するノードを分離する代わりに、接続されているすべてのコンポーネントが完全に 1 つのグループ内にあることを確認する必要があります。 

したがって、単純な解決策では、最初にセグメントのすべてのペアをチェックすることによって完全な交差グラフを構築します。 2 つのセグメントが重なっている場合は、それらを結合して 1 つのコンポーネントにします。 次に、コンポーネントを 2 つのグループに割り当ててみます。 しかし、コンポーネントが 1 つしかない場合、それを 2 つの空でないグループに分割することはできないため、答えは不可能です。 少なくとも 2 つのコンポーネントがある場合は、各コンポーネント全体をグループ 1 またはグループ 2 に割り当て、両方のグループが空でないことを確認できます。 

課題は交差点構造の構築です。 すべてのペアをチェックすると O(n^2) のコストがかかります。 たとえわずかに最適化したとしても、遅すぎるままです。 

重要な観察は、セグメント上の交差点の接続性がソートによって取得されることです。 左端点とスイープによってセグメントを並べ替えると、重複するチェーンを単一の間隔コンポーネントにマージできます。 現在の最大右エンドポイントの後にセグメントが開始されるたびに、新しいコンポーネントが開始されることがわかります。 

したがって、グラフを構築する代わりに、ソート後に単一パスを使用して区間を連結成分にマージするだけで済みます。 コンポーネントが特定されると、問題は複数のコンポーネントが存在するかどうかを確認することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (ペアワイズ オーバーラップ グラフ) | O(n^2) | O(n^2) | 遅すぎる |
 | 最適 (ソート + スイープ マージ) | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

各テストケースを個別に処理します。 

1. すべてのセグメントを読み取り、元のインデックスを保持します。 出力はソート順ではなく入力順に一致する必要があるため、インデックスが必要です。 
2. セグメントを左の端点で並べ替えます。 並べ替えにより、ペアごとの比較ではなく単一のスキャンを使用して重複を検出できるため、並べ替えは不可欠です。 
3. 最初のセグメントを使用して現在のコンポーネント間隔を初期化します。 コンポーネント ID カウンターも維持します。 
4. セグメントを左から右に移動します。 各セグメントについて、その左端点と現在のコンポーネントの最大右端点を比較します。 
5. 現在のセグメントが現在の最大右端点の前または時点で開始する場合、現在のコンポーネントと重なるため、必要に応じて最大右端点を延長してセグメントをマージします。 
6. 現在の最大右端点の後に開始する場合、これは、現在のコンポーネント内の何も交差していないことを意味します。 前のコンポーネントを終了し、新しいコンポーネントを開始します。 
7. すべてのセグメントが処理されると、セグメントが接続されたコンポーネントに分割されます。各コンポーネントは、重なり合うセグメントの最大チェーンになります。 
8. コンポーネントが 1 つだけの場合、分割によりグループ間で少なくとも 1 つの重複が強制されるため、-1 を出力します。 
9. それ以外の場合は、最初のコンポーネントのすべてのセグメントにグループ 1 を割り当て、残りのすべてのコンポーネントにグループ 2 を割り当てます。 

### なぜ効果があるのか

 2 つのセグメントを接続するペアごとに交差するセグメントのチェーンが存在する場合、それらのセグメントは正確に同じコンポーネント内にあります。 1 つのコンポーネント内のセグメントは、そのコンポーネント内の他のすべてのセグメントと (直接的または間接的に) オーバーラップするため、それらを異なるグループに配置すると、グループ間の交差が強制的に発生します。 逆に、異なるコンポーネント内のセグメントは、ソートされたスイープ内のギャップによって分離されます。これは、あるコンポーネント内のセグメントが別のコンポーネント内のセグメントと重なることができないことを意味します。 これにより、コンポーネント全体をグループに割り当てると有効なソリューションが生成され、少なくとも 2 つのコンポーネントが存在する場合にのみソリューションが存在することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        segs = []
        for i in range(n):
            l, r = map(int, input().split())
            segs.append((l, r, i))

        segs.sort()

        comp = [0] * n
        cid = 0

        cur_l, cur_r, idx = segs[0]

        comp[idx] = cid

        for l, r, i in segs[1:]:
            if l <= cur_r:
                if r > cur_r:
                    cur_r = r
                comp[i] = cid
            else:
                cid += 1
                cur_r = r
                comp[i] = cid

        if cid == 0:
            out.append("-1")
            continue

        ans = [0] * n
        for i in range(n):
            ans[i] = 1 if comp[i] == 0 else 2

        out.append(" ".join(map(str, ans)))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は左エンドポイントによるソートに依存しているため、重複検出は現在の最大の右エンドポイントとの単純な比較に減ります。 変数`cur_r`はキーの状態です。現在接続されているコンポーネントの最も遠い範囲を追跡します。 セグメントがこの範囲内にある場合、そのセグメントは同じコンポーネントに吸収されます。 それが外側にある場合、新しいコンポーネントを開始します。 

よくある落とし穴は、元のインデックスの保存を忘れることです。 並べ替えによりセグメントが再配置されるため、割り当てを元の順序に戻して保存する必要があります。 もう 1 つの微妙な問題は、マージには最大の右エンドポイントの追跡のみが必要であることです。 オーバーラップは現在のリーチが終了する前に次のセグメントが始まるかどうかによって完全に決定されるため、左側の境界を追跡する必要はありません。

 | --- | --- | --- | --- | --- |

コンポーネント0→グループ1、コンポーネント1→グループ2

これにより、重複しないセグメントが異なるコンポーネントにきれいに分離されていることを確認できます。

3
3
3 5
2 3
2 3
```並べ替え:

 (2,3)、(2,3)、(3,5)

 | ステップ | セグメント | cur_r | コンポーネント | アクション |
 | --- | --- | --- | --- | --- |
 | 1 | (2,3) | 3 | 0 | 開始 |

すべてのセグメントはオーバーラップを介して接続されているため、分割すると 1 つのグループが強制的に空になるか、グループ間のオーバーラップが発生します。 出力は`-1`。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque
    input = sys.stdin.readline

    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        segs = []
        for i in range(n):
            l, r = map(int, input().split())
            segs.append((l, r, i))

        segs.sort()

        comp = [0] * n
        cid = 0

        cur_r = segs[0][1]
        comp[segs[0][2]] = 0

        for l, r, i in segs[1:]:
            if l <= cur_r:
                cur_r = max(cur_r, r)
                comp[i] = cid
            else:
                cid += 1
                cur_r = r
                comp[i] = cid

        if cid == 0:
            out.append("-1")
        else:
            ans = [1 if comp[i] == 0 else 2 for i in range(n)]
            out.append(" ".join(map(str, ans)))

    return "\n".join(out)

 ## 特殊なケース

 完全に接続された重なり合うセグメントのチェーン。`[1, 5], [2, 6], [3, 7]`は、実行中の最大右エンドポイントが決してドロップしないため、スイープ中に単一のマージされたコンポーネントが生成されます。 アルゴリズムはすべてのセグメントをコンポーネント 0 に割り当て、正しく出力します。`-1`。 

次のような完全に素な集合`[1,2], [5,6], [10,11]`新しいセグメントはそれぞれ前のセグメントの後に始まるため、3 つのコンポーネントが作成されます。`cur_r`。 スイープはギャップごとに正しくリセットされ、複数のコンポーネントが生成され、有効な 2 つのグループ分割が可能になります。 

などの接触セグメント`[1,3]`そして`[3,5]`重複しているものとして扱われます。`l <= cur_r`。 これにより、それらが同じコンポーネント内に留まることが保証されます。これは、それらが点を共有し、グループ間で分離できないため必要です。
