 ## 解決策
 ## 問題の理解

 この問題は因数分解された形式で多項式を与えます

 [
 P(X)=(X+a_1)(X+a_2)\cdots(X+a_n)、
 】

 ここで (1\le n\le 9) およびすべての (a_i) は (-10) から (10) までの整数です。 これを展開し、結果として得られる多項式を必要なコンパクトな表記法で出力する必要があります。 公式問題は Codeforces 100F「Polynom」で、2 秒の制限と 64 MB のメモリを備えた特別な実装問題です。 

たとえば、

 [
 (X-1)(X+1)=X^2-1、
 】

 したがって、出力は`X^2-1`。 もし

 [
 (X+1)(X+1)=X^2+2X+1、
 】

 コンパクトな出力は`X^2+2*X+1`。 この声明では、すべての用語が概念的に次のように説明されています。`C*X^K`ですが、不要な部分は省いています。 したがって、係数 (1) は出力されず、指数 (1) も出力されず、定数項には次の値が含まれません。`*X^0`。 ゼロ項は完全に省略されます。 

境界が小さい (n\le9) ということは、かなり直接的な実装でも十分高速であることを意味します。 係数自体も、通常の Python 整数に対して十分小さいですが、Python はいずれにせよ、はるかに大きな整数を安全に処理します。 次数は最大 9 であるため、高度な多項式アルゴリズムは必要ありません。 有用なターゲットは単純に (O(n^2)) であり、これはこれらの制約に対して事実上一定です。 

正しい多項式展開が間違った答えを生成する可能性がある書式設定のケースがいくつかあります。 入力用```
1
0
```多項式は (X) なので、正しい出力は次のようになります。`X`、 ない`1*X^1`。 後者は同じ数学的値を表しますが、必要な最短表現ではありません。 

のために```
1
-5
```多項式は (X-5) なので、出力は次のようになります。`X-5`。 すべての係数を均一に扱うフォーマッタは、誤って生成する可能性があります。`X+-5`。 

のために```
2
0
0
```多項式は (X^2) であるため、出力は次のようになります。`X^2`。 低次の係数は両方ともゼロであり、消滅する必要があります。 不注意に実装すると、次のように出力される可能性があります。`X^2+0*X+0`。 

最後に、```
2
-1
1
```中間の係数はゼロであり、`X^2-1`。 これは、負の係数の前にプラス記号を出力したり、中間項のゼロを保持したりするというよくある間違いを捕らえます。 公式サンプルには、まさにこのケースが含まれています。 

## アプローチ

 各係数を取得する強引な方法は、多項式乗算の定義を直接使用することです。 (n) 個の因子のサブセットごとに、(X) 部分または (a_i) 部分のいずれかを選択します。 サイズ (k) のサブセットは、選択された (a_i) の積に等しい値を持つ (X^{n-k}) の係数に寄与します。 すべての (2^n) 個のサブセットを列挙し、サブセットごとに最大 (n) 個の要素を処理すると、コストがかかります (O(n2^n))。 指定された最大値 (n=9) では、これは (9\cdot512=4608) 個の基本選択のみであるため、元の制約に対して実際には十分な速度です。 問題は、このメソッドが指数関数的にスケールし、(n=30) で約 (30\cdot2^{30})、つまり 320 億操作を超えることになることです。 

さらに良い観察は、すべてのサブセットを個別に考慮することなく、多項式の乗算によって必要な情報が正確に得られるということです。 多項式 (1) から始めます。 係数 (X+a_i) を処理する場合、現在の多項式にこの線形多項式を乗算します。 現在の係数配列が (c) の場合、次数 (j) の新しい係数は 2 つの寄与を受け取ります: (X) の選択による (c_j)、および (a_i) の選択による (a_i c_{j-1})。 現在の次数が (k) の場合、各乗算には (O(k)) がかかるため、すべての (n) 個の因数を処理するには (O(n^2)) のコストがかかります。 

すべての係数は最終的にはすべての因子から 1 つの項を選択することによって得られる積の和であるため、総当り攻撃が機能しますが、通常の多項式乗算ではすぐに集計される組み合わせを繰り返し再構築します。 それぞれの新しい因子には 2 つの項しかないという観察により、すべての係数を 1 回のパスで更新できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | (O(n2^n)) | (O(n)) | (n\le9) は受け入れられますが、スケーラビリティが低い |
 | 最適 | (O(n^2)) | (O(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. (n) と (n) の値 (a_i) を読み取ります。 現在の多項式を配列で表現します`coef`、 どこ`coef[j]`は (X^j) の係数です。 最初の多項式は (1) なので、`coef = [1]`。 
2. すべての要素 (X+a_i) を処理します。 現在の多項式の次数 (k) があるとします。 線形係数を掛けると次数が 1 増えるため、長さ (k+2) の新しい配列を作成します。 
3. 既存の係数ごとに`coef[j]`に追加します`new[j + 1]`。 これは、(X+a_i) の (X) 部分を取ることに相当し、次数が 1 つ増加します。 
4. 同じ係数の場合、次を追加します。`coef[j] * a_i`に`new[j]`。 これは定数部分 (a_i) を取得することに対応し、次数は変更されません。 
5. 現在の係数配列を新しく計算された係数配列に置き換えます。 すべての因数を処理した後、配列には、インデックス 0 の定数項からインデックス (n) の先頭の係数まで、完全な多項式の係数が含まれます。 
6. 係数を次数 (n) からゼロまでたどります。 その項は多項式に何も寄与しないため、ゼロに等しいすべての係数をスキップします。 
7. ゼロ以外の係数ごとに、その最短の表現を構築します。 次数 0 の場合は、係数のみを出力します。 1 度の場合は、印刷します`X`絶対係数が 1 の場合、それ以外の場合は出力します`C*X`。 より高い学位を取得するには、印刷してください`X^K`絶対係数が 1 の場合、それ以外の場合は出力します`C*X^K`。 
8.追加`+`正の非先行用語の前、および`-`負の非先行用語の前。 絶対値が 1 の係数については、数値係数そのものを出力しません。 

重要な不変条件は、最初の (i) 因子を処理した後、`coef[j]`はまさに次の (X^j) の係数です。 

[
 \prod_{k=1}^{i}(X+a_k)。 
】

 この多項式に (X+a_{i+1}) を乗算すると、既存の項ごとに 2 つの寄与が作成され、1 つは 1 度シフトされ、もう 1 つは (a_{i+1}) で乗算されます。 したがって、更新では 1 つの追加係数を使用して多項式の係数が正確に計算されます。 帰納法により、最終因子の後はすべての係数が正しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = [int(input()) for _ in range(n)]

    # coef[j] is the coefficient of X^j.
    coef = [1]

    for value in a:
        new = [0] * (len(coef) + 1)

        for j, c in enumerate(coef):
            # Take X from (X + value).
            new[j + 1] += c

            # Take value from (X + value).
            new[j] += c * value

        coef = new

    terms = []

    for power in range(n, -1, -1):
        c = coef[power]

        if c == 0:
            continue

        if power == 0:
            body = str(abs(c))
        elif power == 1:
            if abs(c) == 1:
                body = "X"
            else:
                body = f"{abs(c)}*X"
        else:
            if abs(c) == 1:
                body = f"X^{power}"
            else:
                body = f"{abs(c)}*X^{power}"

        if not terms:
            if c < 0:
                terms.append("-" + body)
            else:
                terms.append(body)
        else:
            if c < 0:
                terms.append("-" + body)
            else:
                terms.append("+" + body)

    print("".join(terms))

if __name__ == "__main__":
    solve()
```係数配列は次のように初期化されます。`[1]`多項式乗算の中立要素は定数多項式 (1) であるためです。 各入力値に対して、`new[j + 1] += c`(X) の貢献を処理し、`new[j] += c * value`一定の貢献を処理します。 

表現は次数の昇順で保存されるため、乗算の更新が特に簡単になります。 標準の多項式表記では最高次数が最初に出力されるため、最後の走査は逆方向に進みます。 

書式設定コードは意図的に使用します`abs(c)`用語の本文用。 符号は個別に処理されるため、次のような出力が防止されます。`X+-5`。 最初の項も明示的な情報を受け取らないため、個別に処理されます。`+`サイン。 

Python の整数には任意の精度があるため、オーバーフローの問題はありません。 (n\le9) と (|a_i|\le10) では、いずれにしても係数は実際には非常に小さいです。

import io

def solve_data(inp: str) -> str:
    old_stdin = sys.stdin
    old_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    try:
        n = int(sys.stdin.readline())
        a = [int(sys.stdin.readline()) for _ in range(n)]

        coef = [1]

        for value in a:
            new = [0] * (len(coef) + 1)
            for j, c in enumerate(coef):
                new[j + 1] += c
                new[j] += c * value
            coef = new

        terms = []

        for power in range(n, -1, -1):
            c = coef[power]
            if c == 0:
                continue

            if power == 0:
                body = str(abs(c))
            elif power == 1:
                body = "X" if abs(c) == 1 else f"{abs(c)}*X"

        print("".join(terms))

        return sys.stdout.getvalue()
    finally:

        sys.stdout = old_stdout

 ## 特殊なケース

 最小サイズの入力の場合```
1
0
```アルゴリズムはで始まります`[1]`。 (X+0) を掛けると次のようになります。`[0, 1]`。 次数 1 の係数は 1 であるため、フォーマッタは次のように出力します。`X`それよりも`1*X`。 定数係数はゼロとなり消滅します。 

のために```
1
-10
```係数配列は次のようになります`[-10, 1]`。 1 度の用語が主要です`X`、定数項は負です。 2 番目の項なので、フォーマッタは追加します`-`そしてその絶対値を出力し、`X-10`。 

のために```
2
0
0
```最初の乗算は次のようになります`[0, 1]`、そして2番目は与えます`[0, 0, 1]`。 低次の係数は両方ともゼロであるため、唯一生き残る項は次のとおりです。`X^2`。 すべての学位を出力するフォーマッタは、誤って生成します。`X^2+0*X+0`。 

のために```
2
-10
10
```最初の要素が生成する`[-10, 1]`。 (X+10) を掛けると、`[−100, 0, 1]`。 中間の係数は正確にキャンセルされるため、出力は次のようになります。`X^2-100`。 これにより、ゼロ項処理と符号処理の両方が捕捉されます。 

最も微妙な書式設定のケースは、係数が (1) または (-1) に等しい場合です。 例えば、```
2
-1
-1
```与える

 [
 (X-1)^2=X^2-2X+1。 
】

 2 次係数は次のとおりです。`1`, となるので、`X^2`; 1 次係数は`-2`, となるので、`-2*X`; そして定数係数は`1`, となるので、`+1`。 最終的な出力は次のとおりです`X^2-2*X+1`、不必要な係数や指数表記はありません。
