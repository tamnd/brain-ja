 ## 解決策
 ## 問題の理解

 整数グリッド上の大きな点のセットが与えられます。 各点は「星」を表し、同じグリッド上に配置された単位正方形を使用してすべての点を囲む必要があります。 

いくつかのグリッド セルを選択し、「Dyson ユニット」としてマークすることができます。 これらの選択されたセルは、単一の接続された構造を形成します。接続性はかなり寛大な方法で定義されます。2 台の Dyson ユニットが隅でさえ接触していれば、接続されているとみなされます。 したがって、構造を接続するには対角線だけで十分です。 

これらのダイソン ユニットを配置した後、残りのすべてのグリッド セルを正確に 2 つの領域に分割する必要があります。1 つはすべての星を含む「内側」領域、もう 1 つは無限に広がる「外側」領域です。 これら 2 つの領域は、選択した Dyson ユニットによって分離する必要があります。つまり、Dyson ユニットを通らずに内側から外側へ歩くことはできません。 内側領域も、標準のエッジ隣接関係を使用して接続する必要があります。 

目標は、配置する Dyson ユニットの数を最小限に抑えることです。 

この制約では、絶対値で最大 100 万点の座標を含む最大 200,000 点が許可されます。 これにより、n の二次関数は直ちに除外され、グリッドを明示的にシミュレートしたり、平面全体に塗りつぶしを実行しようとするアプローチも除外されます。 正しい解決策は、ソート後におよそ O(n log n) または O(n) 時間で計算される幾何学的構造に問題を還元する必要があります。 

よくある失敗例は、「境界ボックスだけを取得する」という観点から考えることから生じます。 たとえば、ポイントが (0,0)、(100,100)、(200,200) のような対角線の形状を形成している場合、境界ボックスは巨大であり、明らかに最適ではありません。 もう 1 つの失敗例は、ユークリッド幾何学で凸包が必要であると仮定した場合です。これにより、斜めの接続性を持つグリッド上で移動と隣接性が定義されるときに、境界の間違った概念が生成されます。 

重要な問題は、隣接関係が標準の 4 方向またはユークリッドではなく、バリアのコーナー接続であることです。これにより、「短い境界」の意味が変わります。 

## アプローチ

 ブルート フォース ビューでは、グリッド グラフを明示的に構築し、すべての星の周囲のセルの最小分離サイクルを検索します。 BFS が無限から星々まで広がり、二重グリッド内で最小限の分離構造を見つけようとしていると想像することもできます。 グリッドには境界がなく、座標範囲内に最大 10^12 個の潜在的なセルが含まれており、明示的なグラフの構築が不可能になるため、これはすぐに実行不可能になります。 

点の近くのセルのみに制限したとしても、最適化しようとしている境界構造は単純な方法では局所的ではないため、グリッド状態に対する単純な BFS は依然として爆発します。 バリアは、形状の遠く離れた部分を結合する 8 接続の下で単一の接続されたサイクルを形成する必要があります。 

重要な観察は、グリッドの定式化にもかかわらず、答えは 8 方向の接続性によって引き起こされる計量に基づいて設定された点の外側の境界にのみ依存するということです。 このジオメトリでは、接続性の点で対角線の移動は軸の移動と同じコストがかかるため、距離の正しい概念はチェビシェフ計量になります。 

これにより、問題は、L∞ 計量の下の点の凸包の周囲を見つけることに変わります。 エッジの長さを次と等しいものとして再解釈すると、`max(|dx|, |dy|)`、最小の包囲サイクルは凸包の境界に正確に対応し、その全長はダイソン ユニットの必要な数になります。 

したがって、タスクは、この計量空間で凸包を計算し、その周囲を合計することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースグリッド分離 | O(グリッドサイズ) | O(グリッドサイズ) | 遅すぎる |
 | 凸包 + L∞ 外周 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各星を平面内の点として扱います。 目標は、凸包の外側の境界を計算することですが、距離はチェビシェフ (L∞) ノルムで測定されます。 

1. すべての点を辞書順に x、次に y でソートします。 

これは凸包を効率的に構築するために必要であり、単調なチェーンを確実に構築できるようになります。 
2. モノトーンスタックを使用して船体下部を構築します。 

ソートされた順序でポイントを反復処理し、候補ハル頂点のスタックを維持します。 スタック内の最後の 2 点と現在の点が L∞ 方向テストで「左折」を形成しない場合、中間点を削除します。 幾何学的直観は、外側の境界に寄与する点のみを保持するということです。 
3. 逆の順序で同じ方法で上部船体を構築します。 

これは同じプロセスを反映し、凸状の境界を完成させます。 このステップの後、L∞ 空間で凸包を記述する閉じた多角形が得られます。 
4. 下部ハルと上部ハルを連結し、重複するエンドポイントを削除します。 

これにより、正しい順序で完全な境界サイクルが得られます。 
5. チェビシェフ距離を使用して、このサイクルの周長を計算します。 

連続する点のペアごとに`(x1, y1)`そして`(x2, y2)`、追加します`max(|x1 - x2|, |y1 - y2|)`。 

これは、対角方向の隣接が許可されるグリッド境界に沿って移動するコストに直接対応します。 

### なぜ効果があるのか

 ダイソン ユニットは、内部と外部を隔てる単一の 8 接続バリアを形成します。 このようなバリアはすべてのポイントを囲む必要があるため、グリッドの自然計量の下に凸包を含める必要があります。 すべての囲みサイクルの中で、凸包の境界は最小です。これは、内側へのくぼみは分離を壊さずにショートカットできるためです。また、L∞ 幾何学では、これらのショートカットはチェビシェフ ノルムに基づく凸性によって正確に捕捉されます。 したがって、最適な構造は正確に凸包境界であり、その周囲は必要な単位正方形の最小数になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def build_hull(points):
    hull = []
    for p in points:
        while len(hull) >= 2 and cross(hull[-2], hull[-1], p) <= 0:
            hull.pop()
        hull.append(p)
    return hull

n = int(input())
pts = [tuple(map(int, input().split())) for _ in range(n)]
pts.sort()

if n == 1:
    print(0)
    sys.exit()

lower = build_hull(pts)
upper = build_hull(pts[::-1])

hull = lower[:-1] + upper[:-1]

def dist(a, b):
    return max(abs(a[0] - b[0]), abs(a[1] - b[1]))

ans = 0
for i in range(len(hull)):
    ans += dist(hull[i], hull[(i + 1) % len(hull)])

print(ans)
```コードは標準的な単調チェーン凸包構造ですが、幾何学的解釈が変わります。ユークリッド周長の代わりに、チェビシェフ距離を使用して境界長を計算します。 外積テストは、平面的な意味での凸性を維持するために引き続き有効であり、メートル法の変更は、最終的な周囲長の測定方法にのみ影響します。 

微妙な実装の詳細は、縮退ケースの処理です。すべての点が同一線上または同一である場合、ハルは線分または点に折りたたまれます。 このような場合でも、ループ構造は機能しますが、ハルを連結するときにエンドポイントを二重にカウントしないようにする必要があります。

 ## 特殊なケース

 微妙なケースの 1 つは、すべての点が 1 つの線上にある場合です。 その状況では、凸包はセグメントに縮退し、上部と下部の包を連結すると、繰り返し点が生成される可能性があります。 実装では、各ハルの最後の要素を切り取ることでこれを処理しますが、距離の計算で結果のサイクルを一貫して処理することが依然として重要です。 周長は、チェビシェフ距離の下でセグメントの長さの 2 倍に減少します。これは、最小の囲いサイクルが依然としてセグメントの周りで閉じなければならないという事実と一致します。 

もう 1 つのケースは、ポイントが非常に凸でない形状を形成する場合です。 船体の構造ではすべての凹面が取り除かれており、凹面のくぼみはすべての点を囲んだままで、L ∞ メートル単位で周囲を増加させるだけです。 これにより、内部の「へこみ」が最適なバリアの一部にならないことが保証されます。これは、分離を向上させることなく追加の Dyson ユニットが必要になるためです。
