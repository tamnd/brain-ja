 ## 解決策
 ## 問題の理解

 長方形の部屋内を移動するロボットがあります。$n$行と$m$列。 ロボットはあるセルから起動します$(r_b, c_b)$斜めに移動します。一度に 1 歩下に、1 歩ずつ右に進みます。 部屋には壁があるため、ロボットが境界を越えて移動するたびに、ロボットは境界で「跳ね返り」、その軸に沿って方向を反転します。 ロボットは移動するだけでなく、現在の行と列にあるすべてのセルを毎秒掃除します。 目標は、ロボットが 1 つの汚れたセルを掃除するのにどれくらいの時間がかかるかを判断することです。$(r_d, c_d)$。 

入力により複数のテスト ケースが提供され、それぞれが部屋のサイズ、ロボットの開始位置、ダーティ セルの位置を指定します。 出力は、ロボットが汚れたセルを最初に掃除する時間 (秒単位) です。 

制約は小さいです。$n, m \le 100$そして最大まで$10^4$テストケース。 これは、最悪の場合でも、ロボットが前の位置と方向に戻るまでに各テスト ケースに最大約 200 ステップが必要となるため、ロボットの動きを段階的にシミュレートできることを意味します。 大規模な最適化は不要です。 境界の正確さと慎重な取り扱いがより重要です。 

注意すべきエッジ ケースには、ロボットがダーティ セルと同じ行または列で開始する状況が含まれます。これにより、時間がゼロになるはずです。 もう 1 つの微妙なケースは、ダーティ セルが隅にある場合です。これは、境界が不注意に扱われると、1 回のシミュレーション ステップで複数の方向の反転が発生する可能性があります。 

## アプローチ

 ブルートフォース手法では、ロボットの動きを毎秒シミュレートし、現在の方向に従って行と列を更新し、必要に応じて壁に反射し、現在の行または列がダーティ セルと一致するかどうかを確認します。 これが機能する理由は、$n$そして$m$小さいです。 各テスト ケースについて、ロボットが必要とするのは次のとおりです。$2(n-1) + 2(m-1)$斜めのパターンに沿ってダーティ セルに到達するまでの手順。 したがって、ここではブルートフォースアプローチが許容されます。 

重要な洞察は、ロボットの経路全体を追跡する必要はなく、その位置と移動方向のみを追跡する必要があるということです。 各ステップは決定的であり、ロボットは現在の位置で行と列全体をクリーンアップするため、現在の行または列がダーティ セルと一致するかどうかを確認するだけで済みます。 リフレクション ロジックは単純です。次の行が部屋の制限を超える場合は、垂直方向を反転します。 次の列が部屋の制限を超える場合は、水平方向を反転します。

 | --- | --- | --- | --- |
 | ブルートフォース | テスト ケースごとに O(n + m) | お(1) | 承認済み |
 | 最適 (反射ありのシミュレーション) | テスト ケースごとに O(n + m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 各テスト ケースをループします。 
2. 各テストケースについて、部屋の寸法を読み取ります。$n$そして$m$、ロボットの初期位置$(r_b, c_b)$、そして汚れた細胞$(r_d, c_d)$。 
3. ロボットの移動方向を初期化します。$(dr, dc) = (1, 1)$。 
4. タイマ変数の初期化`time = 0`。 
5. ロボットが汚れたセルを掃除していない間、ループします。 

1. ロボットの現在の行を確認します。`r_b`等しい`r_d`またはその現在の列`c_b`等しい`c_d`。 その場合は、ダーティ セルがクリーンアップされるため、ループを中断します。 
2. 次の行を計算します`next_r = r_b + dr`そして次のコラム`next_c = c_b + dc`。 
3. もし`next_r`部屋の境界を超える可能性があります (1 未満または 1 より大きい)$n$）、 逆行する`dr`そして再計算します`next_r`。 
4. もし`next_c`部屋の境界を超える可能性があります (1 未満または 1 より大きい)$m$）、 逆行する`dc`そして再計算します`next_c`。 
5. ロボットの位置を更新します。`(r_b, c_b) = (next_r, next_c)`。 
6. インクリメント`time`1つずつ。 
6. を出力します。`time`現在のテストケースの場合。 

機能する理由: 各ステップで、ロボットは斜めに移動するか壁に反射し、最終的にダーティ セルと交差する行または列に到達することが保証されます。 部屋は有限であり、動きは周期的であるため、ロボットは汚れたセルを掃除しない限り無限ループに入ることができません。 各秒は動作ステップに正確に対応するため、タイマーはクリーニングまでの秒数を追跡します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def robot_cleaner():
    t = int(input())
    for _ in range(t):
        n, m, r_b, c_b, r_d, c_d = map(int, input().split())
        dr, dc = 1, 1
        time = 0
        while r_b != r_d and c_b != c_d:
            if r_b + dr < 1 or r_b + dr > n:
                dr = -dr
            if c_b + dc < 1 or c_b + dc > m:
                dc = -dc
            r_b += dr
            c_b += dc
            time += 1
        print(time)

robot_cleaner()
```解決策では、`dr`そして`dc`垂直方向と水平方向を追跡します。 操作の順序により、ロボットが壁を横切る場合には、移動する前に方向が反転されます。 while ループは、ロボットが移動する前にダーティ セルを既にクリーニングしたかどうかをチェックします。 これにより、秒数をカウントする際の 1 つずつの誤差が回避されます。
