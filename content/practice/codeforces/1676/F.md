 ## 解決策
 ## 問題の理解

 整数の配列としきい値の数値が与えられます。$k$。 私たちの目標は、連続した範囲の整数を見つけることです。$[l, r]$この範囲内のすべての整数が少なくとも出現するようにする$k$配列内の回数。 すべての可能な範囲の中で、可能な限り最大の差を持つものが必要です$r-l$。 少なくとも数字が出現しない場合$k$回の場合は -1 を返します。 

入力には複数のテスト ケースが含まれます。 それぞれの場合において、配列は次のように大きくなります。$2 \cdot 10^5$、すべてのテスト ケースにわたるすべての配列の長さの合計は次のように制限されます。$2 \cdot 10^5$。 これは、各テスト ケースの配列長がほぼ線形になるソリューションが必要であることを意味します。 二次解は遅すぎます。 

明らかではないエッジ ケースには、すべての要素が異なる配列が含まれます。$k > 1$、複数の小さな範囲がしきい値を満たしているが、最大値となる範囲が 1 つだけである配列、および数値が繰り返されているが連続した範囲を分断するギャップがある配列。 たとえば、配列$a = [1,1,3,3,5,5]$と$k=2$には、少なくとも 2 回出現する連続する数値を含む範囲がないため、出力は -1 になるはずです。 もう 1 つの微妙なケースは、最大範囲が十分な回数繰り返される単一の数値である場合です。 私たちは対処しなければなりません$l=r$正しく。 

## アプローチ

 ブルートフォース手法は、配列内のすべての可能な数値のペアを反復処理し、それらの出現をカウントし、どの連続する数値がしきい値を満たすかを確認することです。 これは原理的には正しいですが、時間が複雑になります$O(n^2)$なぜなら、一意の数値のセット内のすべての可能な部分間隔をチェックする必要があるからです。 と$n$まで$2 \cdot 10^5$、このアプローチは実現不可能です。 

重要な洞察は、すべての部分区間を明示的に考慮する必要はないということです。 まず、ハッシュ マップを使用して各数値の頻度を数えます。 少なくとも表示される数字のみ$k$時間は範囲の候補です。 これらの候補番号をソートすると、ソートされたリスト内で最も長く連続する部分列を見つけるものとして問題を扱うことができます。 2 つのポインターを使用した単純なリニア スキャンにより、最大範囲が得られます。 

この観察により、問題は次のように簡略化されます。$O(n \log n)$候補者を並べ替えるためにプラス$O(n)$スキャン用。 周波数を数えるのも、$O(n)$辞書を使って。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 頻度辞書を初期化し、配列内に各数値が何回出現するかを数えます。 
2. 次の値よりも少ない数字を除外します。$k$回。 これらを有効な範囲の一部にすることはできません。 
3. 残りの数字を並べ替えます。 並べ替えると、並べ替えられたリスト内の連続する番号が数値的にも連続することが保証されます。 
4. 線形スキャンを使用して、このソートされたリスト内で最も長く連続するサブシーケンスを見つけます。 現在の候補範囲の開始と終了を追跡します。 次の番号が連続していない場合は、現在の開始をリセットします。 
5. 違いを比較して、これまでに見つかった最適な範囲を追跡します。$r-l$より長い範囲に遭遇したときはいつでも。 
6. 最適な範囲を出力します。 しきい値に一致する数値がない場合は、-1 を出力します。 

不変条件は、線形スキャンのすべての点で、現在のサブシーケンスには少なくとも出現する数値のみが含まれるということです。$k$と は連続しています。 これにより、最終的に記録された範囲がそのような連続したサブシーケンスの中で最も長いことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        freq = {}
        for num in a:
            freq[num] = freq.get(num, 0) + 1
        
        # Only consider numbers appearing at least k times
        candidates = [num for num, count in freq.items() if count >= k]
        if not candidates:
            print(-1)
            continue
        
        candidates.sort()
        
        best_l = best_r = candidates[0]
        cur_l = cur_r = candidates[0]
        
        for i in range(1, len(candidates)):
            if candidates[i] == cur_r + 1:
                cur_r = candidates[i]
            else:
                if cur_r - cur_l > best_r - best_l:
                    best_l, best_r = cur_l, cur_r
                cur_l = cur_r = candidates[i]
        
        if cur_r - cur_l > best_r - best_l:
            best_l, best_r = cur_l, cur_r
        
        print(best_l, best_r)

if __name__ == "__main__":
    solve()
```コードはまず周波数をカウントし、候補をフィルターします。 ソートされたリスト内の連続した数値のみが有効な範囲を形成できるため、ソートは非常に重要です。 開始ポインタと終了ポインタを使用したリニア スキャンでは、現在の連続した範囲が維持されます。 最適な範囲を更新すると、最大の差が確実に選択されます。 単一要素の範囲や最長範囲を形成するリストの最後の要素などの境界条件は、明示的にチェックされます。

## 特殊なケース

 しきい値を満たす数値がない配列の場合、たとえば、$a = [1,1,2,3]$と$k=3$、候補リストは空です。 アルゴリズムはすぐに -1 を出力します。 1 つの数値が十分な回数繰り返される配列の場合、アルゴリズムは cur_l=cur_r をその数値に設定し、それが最適な範囲として正しく識別されます。 最長の範囲を形成する最後の要素については、ループ後の最終チェックで最適な範囲が更新されていることを確認し、off-by-one エラーを防ぎます。 すべての境界条件は、線形スキャンと最終比較によって自然に処理されます。
