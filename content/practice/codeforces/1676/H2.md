 ## 問題の理解

 インデックスごとに 1 つずつ、ワイヤーのコレクションが与えられます。`i`位置から始まります`i`上部レール上とその位置で終了`a[i]`下のレールの上。 端点が 2 つのレールに固定されると、すべてのワイヤは直線セグメントになりますが、セグメントの順序を尊重し、端点をセグメントの境界上に正確に配置しない限り、各セグメント内の正確な接続点を自由に選択できます。 

重要なのは、各レールに沿ったエンドポイントの相対的な順序だけです。 2 本のワイヤ間の交差は、それらの上端と下端が逆の順序で現れるかどうかによって決まります。 ワイヤーの場合`i`ワイヤーの左側から始まります`j`上部レール上にありますが、下部レールの右側で終わる場合、2 本のワイヤを交差するように引くことができます。 両方の注文が一致する場合、それらの間の交差を回避できます。 

課題は、最適な幾何学的配置を選択することにより、すべてのワイヤ ペアにわたるこのような交差の数を最大化することです。 これにより、問題は、一貫した埋め込みの下で最上位と最下位の間で「反転」できるペアの数を数えることに減ります。 

制約は私たちを`O(n log n)`または`O(n)`テストケースごとのソリューション。 合計から`n`すべてのテスト ケースで最大でも`2 × 10^5`、すべてのペアを直接比較する二次アプローチは、約`4 × 10^10`最悪の場合の運用。 

微妙な点は、`a`案件。 複数のワイヤが同じ下位位置で終了する場合、下側での相対的な順序は、交差を自動的に回避する方法で固定されません。 標準的な意味で反転のみをカウントする単純な貪欲型は、等しい値を正しく処理せずにエンドポイントの厳密な順序付けを前提とすると失敗する可能性があります。 

たとえば、すべてが`a[i]`が等しい場合、ワイヤの各ペアは同じ下端のエンドポイントを共有します。 上部の順序はすべてのペア間に交差を作成しますが、正しい答えは「構造がない」ではなく、同一のエンドポイント間のペアの総数であり、これはまだ完全に決定されています。 

## アプローチ

 幾何学的な観点から考えると、各ワイヤのペアは、それらの端点の順序を不一致にできるかどうかに応じて、1 つの交差またはゼロ交差のいずれかに寄与します。 したがって、この問題は、2 つのシーケンス間の反転の数を最大化する順序付け解釈、つまり固定上位順序を選択することと同じです。`1..n`そして、同じ値によって制約される柔軟なボトム配置。 

強引なアイデアは、同じ下位エンドポイントを共有するワイヤの順序をすべて並べて試してみることです。 選択ごとに、上部と下部の位置間の反転数を計算できます。 値が 1 つも表示されるため、これはすぐに実行不可能になります。`k`回が貢献する`k!`内部の順列が変化し、合計の組み合わせが指数関数的に爆発的に増加します。 

重要な構造的観察は、最上位の次数がすでに次のように固定されていることです。`1, 2, ..., n`。 したがって、各ペア`(i, j)`と`i < j`交差に貢献するのは次の場合です。`a[i] > a[j]`、または次の場合はそれを回避するように手配できます。`a[i] ≤ a[j]`。 したがって、最適な戦略は、マルチセット シーケンス内の反転の数を最大化することです。`a`ただし、相互作用を最大化するために下部レール上でエンドポイントを任意に順序付けることができるため、等しい要素も交差に寄与するという重要な工夫が施されています。 

これは、修正を伴う標準的な反転カウントの問題につながります。つまり、すべてのペアをカウントする必要があります。`(i, j)`どこ`i < j`そして`a[i] ≥ a[j]`最高のアレンジメントという意味で。 これをモデル化するきれいな方法は、前の要素の数が厳密にそれ以上か等しいかを維持しながら、要素を左から右に処理することです。ただし、値は次の制限によって制限されます。`n`、周波数構造またはフェンウィック ツリーを使用して寄与を計算できます。 

エンドポイントを配置するという観点から考える代わりに、問題を次のように再解釈します。非交差に強制しない限り、すべてのペアは交差に寄与します。 交差を回避する唯一の方法は、両側で相対的な順序を一貫して保つことです。これは次のような場合に起こります。`a[i] < a[j]`そして一貫した順序を選択します。 交差を最大化するには、そのような「交差互換性のない」ペアを最小限に抑える必要があります。これにより、ソートされた構造によって決定される最小構造を差し引いたすべてのペアをカウントすることになります。`a`。 

編集ソリューションで使用されるより直接的で標準的な洞察は、インデックスを次の基準で並べ替えることです。`a[i]`、最適な交差は、値で並べ替えた後に逆の順序になっているペアの数をカウントすることに対応するだけでなく、等しい値の寄与も考慮していることを観察します。 クリーンな実装では、配列内の反転をカウントするだけで済み、重複はグループ化するか、頻度カウントを含むフェンウィック ツリーを使用して慎重に処理されます。 

## アルゴリズムのチュートリアル

 1. 制約は追加的であり、状態は共有されないため、各テスト ケースを個別に処理します。 
2. の値に基づいて、インデックスのペア間の寄与をカウントするという問題を解釈します。`a`。 順序の柔軟性を利用して、強制的に交差させることができるペアの数を計算します。 
3. 値に対するフェンウィック ツリー (または頻度配列) を維持しながら、配列を左から右にトラバースします。`1..n`。 この構造体は、各値を持つ要素がすでにいくつ存在したかを格納します。 
4. ポジションごとに`i`、前の要素の数が必然的に次の要素との交差に寄与するかどうかを数えたいとします。`a[i]`。 最大の交差を目指しているため、値以上の以前のすべての要素が`a[i]`を組み合わせて、最適な配置で交差を生成できます。 したがって、前の要素の数を値でクエリします。`≥ a[i]`。 
5. このカウントをそれぞれの答えに加算します。`i`を挿入してから、`a[i]`フェンウィックの木の中へ。 
6. すべての要素を処理した後、累積結果を出力します。 

### なぜ効果があるのか

 重要な不変条件は、スキャンのどの時点でも、フェンウィック ツリーが固定順序で上側に配置されているすべてのワイヤを表すということです。 value で終わる新しいワイヤーの場合`x`、少なくとも下端点を持つ以前に確認されたワイヤ`x`上位の順序に対して下位の順序が反転するように配置して、交差を保証することができます。 各ペアは後のインデックスが処理されるときにカウントされ、Fenwick クエリは強制的に交差構成にすることができる以前のインデックスのセットを正確にキャプチャするため、貪欲な累積ではすべてのペアが 1 回だけ正確にカウントされます。 

これにより、グローバルな幾何学的最適化が、プレフィックス状態に対するローカルなカウント プロセスに縮小され、各挿入は集約された周波数情報のみに依存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def add(self, i, v):
        while i <= self.n:
            self.bit[i] += v
            i += i & -i

    def sum(self, i):
        s = 0
        while i > 0:
            s += self.bit[i]
            i -= i & -i
        return s

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))

    fw = Fenwick(n)
    ans = 0

    for i, x in enumerate(a):
        seen = i
        less = fw.sum(x - 1)
        ans += seen - less
        fw.add(x, 1)

    print(ans)
```フェンウィック ツリーは、これまでに確認された値の頻度カウントを維持します。 要素ごとに`x`、`fw.sum(x - 1)`厳密に小さい以前の値がいくつあるかをカウントします。`seen`以前の値がどれだけ大きいか等しいかを示します。 これらはまさに、最適な配置での交差に寄与するペアです。 

微妙な点は、等価性を正しく処理することです。 使用する`≥`それよりも`>`最適な配置でも等しい値でも交差が生成され、Fenwick クエリ構造はこれを自然に取得するため、これは不可欠です。`seen - less`。

 ## 特殊なケース

 単一ワイヤの場合、アルゴリズムは空のフェンウィック ツリーを初期化し、寄与を蓄積することはなく、予想どおりゼロクロッシングを生成します。
