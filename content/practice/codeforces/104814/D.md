 ## 問題の理解

 固定整数が与えられます$x$、直角三角形の片方の脚の長さを表します。 タスクは、脚の 1 つが正確​​に一致するような、整数の辺の長さをもつ個別の直角三角形がいくつ存在するかを数えることです。$x$。 回転、反射、または平行移動後に辺の長さが一致する場合、2 つの三角形は同じであるとみなされます。これは事実上、向きではなく辺の長さの 3 倍だけを考慮することを意味します。 

整数の辺を持つ直角三角形はピタゴラスのトリプルによって完全に決定されます$(a, b, c)$満足のいく$a^2 + b^2 = c^2$。 この例では、脚の 1 つが次のように固定されています。$x$したがって、次のいずれかの整数解を数えます。$x^2 + y^2 = z^2$または$y^2 + x^2 = z^2$。 脚は対称であるため、一般性を失うことなく、2 番目の脚は次のように仮定できます。$y$、整数のペアを検索します$(y, z)$そのような$$x^2 + y^2 = z^2, \quad x, y, z > 0.$$制約こそが本当の課題です。$x \le 10^9$テストケースは最大 5 つあります。 候補を列挙するソリューション$y$または$z$まで$x$すぐには実行不可能です。 二次関数または偶数$O(x)$スキャンは許容限界をはるかに超えているため、解決策はピタゴラス トリプルの構造特性に依存する必要があります。 

微妙なエッジケースは、複数の異なるトリプルが同じ固定脚を共有できることです。$x$サンプルに見られるように、$x = 15$4 つの異なる三角形が生成されます。 もう 1 つの重要な詳細は、スケーリングが重要であるということです。$(8, 15, 17)$、$(15, 20, 25)$、$(15, 36, 39)$、 そして$(15, 112, 113)$プリミティブと非プリミティブの両方のトリプルをカウントする必要があることを示しています。

 ## アルゴリズムのチュートリアル

 中心となるアイデアは、条件を書き直すことです$x^2 + y^2 = z^2$因数分解制約として$(z-y)(z+y)$。 展開すると得られる$$z^2 - y^2 = x^2 \Rightarrow (z-y)(z+y) = x^2.$$これにより、幾何学問題は次の因子ペアを見つけることに変換されます。$x^2$。 

### ステップ

 1.修正$x$そして計算する$x^2$。 すべてのペアが欲しい$(u, v)$そのような$u \cdot v = x^2$、 どこ$u = z-y$そして$v = z+y$。 この置換が機能するのは、両方の式が整数であり、正の制約​​が保持されているためです。 
2. すべての約数を列挙します$u$の$x^2$まで$\sqrt{x^2} = x$。 各約数について$u$、 定義する$v = x^2 / u$。 これにより、すべての因子ペアが 1 回だけ考慮されることが保証されます。 
3. ペアごとに$(u, v)$、再構築する$$z = \frac{u + v}{2}, \quad y = \frac{v - u}{2}.$$これらは整数である必要があるため、$u \equiv v \pmod{2}$。 パリティが異なる場合、ペアは無効となりスキップされます。 
4. 積極性を確保する:$y > 0$。 これは次の場合に自動的に成立します。$u < v$、したがって、私たちはのみを考慮します$u < v$悪化したケースや二重カウントを避けるため。 
5. それぞれの有効な再構成を 1 つの三角形として数えます。 

### なぜ効果があるのか

 すべての整数直角三角形は、次の因数分解に一意に対応します。$x^2$アイデンティティを通じて$(z-y)(z+y) = x^2$。 逆に、パリティを満たすすべての有効な因数ペアは、有効な整数を生成します。$y$そして$z$。 これらの制約の下で、マッピングは有効な三角形と有効な因子のペアの間で全単射であるため、これらのペアを正確にカウントすると、重複することなく三角形がカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def count_triangles(x):
    n = x * x
    ans = 0

    i = 1
    while i * i <= n:
        if n % i == 0:
            j = n // i

            # pair (i, j)
            if i < j and ((i + j) % 2 == 0):
                ans += 1

            # pair (j, i) is same, so no need to process separately
        i += 1

    return ans

t = int(input())
for _ in range(t):
    x = int(input())
    print(count_triangles(x))
```この実装では、因子ペアの再定式化が直接適用されます。 まで繰り返します$x$以来$\sqrt{x^2} = x$のすべての約数を確実にカバーします。$x^2$。 条件$i < j$対称ペアの二重カウントを防ぎます。 パリティ チェックにより、再構築されたデータが確実に再構築されます。$y$は両方とも整数なので、$z-y$そして$z+y$同じパリティを持つ必要があります。

 ## 特殊なケース

 のために$x = 1$、私たちは得ます$x^2 = 1$。 唯一の因子ペアは$(1, 1)$、ただし、有効な三角形は生成されません。$y = 0$。 アルゴリズムはこれを正しく破棄します。$u = v$は除外されます。 

のために$x = 2$、私たちは得ます$x^2 = 4$ペアで$(1, 4)$そして$(2, 2)$。 のみ$(1, 4)$有効な結果を生成します$y = \frac{3}{2}$試みましたがパリティが失敗したため、結果はゼロになります。 これは、整数の直角三角形は長さ 2 の脚を持つことができないという事実と一致します。
