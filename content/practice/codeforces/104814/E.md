 ## 問題の理解

 高さが次のような大きな長方形のグリッドが与えられます。$2^N$そして幅は$2^N - 1$。 グリッドは任意ではありません。長方形領域を小さな領域に繰り返し分割することによって再帰的に構築されます。 構築は大きなブロックが配置される左側から始まり、すべてが分割されるまで再帰的に徐々に小さなブロックが右側に取り付けられます。$2 \times 1$個。 これにより、グリッド セル上に完全なバイナリのような空間階層が定義されます。 

幾何学的構造が固定された後、各再帰ブロックに色が割り当てられます。 最大のブロックは黒色です。 ブロックが左側の 2 つの接続されたサブブロックに分割されるたびに、下のブロックは親と同じ色を継承し、上のブロックは反対の色に反転します。 この構造は純粋に再帰的かつ決定論的であるため、グリッド内のすべてのセルは最終的に黒または黄色になります。 

仕事は複数の質問に答えることです。 各クエリでは、この巨大なグリッド内の部分四角形が得られ、その部分四角形内の黒いセルの数を数えなければなりません。 

重要な問題はスケールです。 グリッドの辺の長さは最大です。$2^{30}$、これは明示的に構築するには大きすぎます。 単一行を最大解像度で明示的に保存することさえ不可能です。 したがって、着色の直接シミュレーションは直ちに除外されます。 どのソリューションも再帰構造を利用し、クエリごとに対数時間で答えを計算する必要があります。 

微妙なエッジケースは、幅が$2^N - 1$、2の累乗ではありません。 これは、完全な正方形の対称性または両方の軸に沿った完全なバイナリの細分化の単純な仮定が、不正確なインデックス作成につながることを意味します。 もう 1 つの落とし穴は、局所的な周期性を仮定することです。これは、再帰深度を通じて伝播する交互のカラー反転のため、グローバルには当てはまりません。 

## アプローチ

 ブルートフォース手法では、グリッドを明示的に生成するか、少なくとも各セルの色を個別に計算しようとします。 単一のセルについては、再帰的降下をシミュレートできます。各レベルで、それがどのサブブロックに属しているかを判断し、色が反転するかどうかを追跡します。 各ステップで次元が半分になるため、1 つのセルを決定するには時間がかかります$O(N)$。 クエリ長方形の領域全体にわたって、$2^{2N}$、これは完全に不可能になります。 

各クエリ セルを反復処理し、再帰によってその色を再計算するなど、少し慎重にブルート フォースを実行すると、次のような結果が得られます。$O(h \cdot w \cdot N)$クエリごとに、これは制限をはるかに超えています。$h, w$アプローチ$2^N$。 

重要な観察は、その構造が決定論的なパリティ フリップ ルールを備えた再帰的タイルであるということです。 これは、セルの色が再帰的分解ツリー内の位置にのみ依存することを意味します。 各セルを個別に評価するのではなく、任意の接頭辞または四角形内に黒のセルがいくつ存在するかを計算し、問題を再帰的に定義された色に対する 2D 接頭辞の合計の計算に事実上変換したいと考えています。 

重要な洞察は、各再帰レベルでグリッドが単純な関係で 2 つの半分に分割されるということです。一方の半分はカラー パリティを保持し、もう一方の半分はカラー パリティを反転します。 これにより、再帰境界に沿って整列された正準ブロックに四角形を分解することで、四角形内の黒セルの数を計算できます。 各ブロックは、パリティに応じてその全領域または補数のいずれかに寄与し、再帰の深さは対数的に減少します。 

各クエリを合計に換算します。$O(N)$各レベルでは、最大でも一定数の整列されたセグメントのみを処理します。

 ## アルゴリズムのチュートリアル

 暗黙的な構造に対する再帰を使用して、長方形内に黒のセルがいくつあるかを計算する関数を定義します。 

1. グリッドを再帰的に定義された領域として表します。 レベルで$N$、グリッドは高さの分解に対応する 2 つの部分構造に分割されます。$2^N$。 一方の側はカラーパリティを維持し、もう一方の側はそれを反転します。 幅は常に$2^N - 1$したがって、分割は構造内の 2 の累乗の最も高い構造によって決定されます。 
2. クエリ四角形の場合、最初に、それが何らかの再帰レベルで単一の同種ブロック内に完全に収まるかどうかを確認します。 そうであれば、ブロックのパリティに応じて、面積またはその補数として答えをすぐに計算できます。 これにより、それ以上の降下が回避されます。 
3. 長方形が分割境界を越える場合は、その境界に従って長方形を部分に分割します。 各部分は、対応するサブブロック座標にマッピングされます。 このステップにより、各サブブロックが暗黙的な「反転状態」を保持するため、グローバル パリティを決して見失うことがなくなります。 
4. 各部分を再帰的に評価し、構造を深くするたびに有効レベルを 1 ずつ下げます。 降下するたびにパリティ フラグを更新します。「上位」ブロックを入力するとカラー パリティが反転し、「下位」ブロックを入力するとカラー パリティが維持されます。 
5. サイズのベースブロックに到達すると再帰は停止します$2 \times 1$。 この時点での答えは簡単です。2 つのセルのうち 1 つは黒で、もう 1 つは黄色であり、どちらがどちらであるかはパリティによって決まります。 
6. クエリの最終的な答えは、分解されたすべての部分からの寄与の合計です。 

### なぜ効果があるのか

 この構造では、各レベルでカラーを維持するか反転するかの二者択一のみを導入する階層パーティションが定義されます。 これは、任意のセルの色が、再帰ツリーの一意のパスに沿った上位/下位の選択肢のシーケンスによって完全に決定されることを意味します。 私たちの分解はまさにこの構造を尊重するため、すべてのサブ四角形は、そのようなパスの素のセットに対応するコンポーネントに分割されます。 パリティは再帰によって一貫して保持されるため、すべてのセルが正しい色の解釈で正確に 1 回カウントされ、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_one(n, r, c, h, w, parity):
    if h <= 0 or w <= 0:
        return 0

    if n == 1:
        # base: 2 x 1
        # one black, one white depending on parity
        # cells: (r,c) top, (r+1,c) bottom
        if h == 1 and w == 1:
            return 1 if parity == 0 else 0
        if h == 2 and w == 1:
            return 1
        return 0

    height = 1 << n
    width = (1 << n) - 1

    mid = height // 2

    res = 0

    # top half
    if r < mid and c < width and h > 0 and w > 0:
        nr = r
        nh = min(h, mid - r)
        res += solve_one(n - 1, nr, c, nh, w, parity ^ 1)

    # bottom half
    if r + h > mid:
        nr = max(0, r - mid)
        nh = h - max(0, mid - r)
        res += solve_one(n - 1, nr, c, nh, w, parity)

    return res

def solve():
    n, q = map(int, input().split())
    out = []
    for _ in range(q):
        r, c, h, w = map(int, input().split())
        r -= 1
        c -= 1
        out.append(str(solve_one(n, r, c, h, w, 0)))
    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この実装は、前に説明した再帰的分解に従います。 機能`solve_one`指定された再帰レベルと現在のパリティ状態の下で、サブ四角形内の黒のセルを数える役割を果たします。 構造の上半分に移動するとパリティが反転し、上部の付加領域の色が反転するというルールを反映しています。 

重要な実装の詳細は、下半分に降下するときの座標のシフトです。 各再帰呼び出しはローカル座標で機能するため、行インデックスを再ベースする必要があります。 この調整を忘れると、重複計算が不正確になり、二重カウントが発生します。 

もう 1 つの微妙な点は、正中線との部分的な重なりの処理です。 以下を使用して、長方形の各半分にどれだけの量が含まれるかを明示的に計算します。`min`オフセット減算により、各再帰呼び出しが適切にクリップされたサブ四角形を確実に受け取ります。 

## 実用的な例

 概念的な小さなケースを考えてみましょう。$N = 2$したがって、グリッドの高さは 4、幅は 3 です。行 1 から 4、列 1 から 3 にまたがる四角形をクエリするとします。 

長方形がどのように分割されるかを追跡します。 

| ステップ | レベル$n$| 領域 (r, h) | パリティ | アクション |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 完全な長方形 | 0 | 上下に分割 |
 | 2 | 1 | 上半分 | 1 | 再帰 |
 | 3 | 1 | 下半分 | 0 | 再帰 |

 上半分はパリティを反転しますが、下半分はパリティを維持します。 それぞれがその還元された構造に基づいて寄与し、合計により合計の黒セルが得られます。 

ここで、グリッドの下半分内に完全に収まる小さなクエリを考えてみましょう。 その場合、再帰によってパリティが反転されることはなく、結果は純粋に基本構成に依存します。 

これは、パリティの伝播がトラバーサル パスに対してローカルであり、互いに素なサブ領域間では干渉しないことを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、クエリの四角形が再帰的な半分の間の中間点にまたがる場合です。 たとえば、小さなインスタンスでは、$N=3$の場合、四角形は、上部の再帰ブロックに部分的に存在し、下部の再帰ブロックに部分的に存在する行をカバーする場合があります。 この状況では、中間点で正確に分割できないと、二重にカウントされたり、サブ領域全体が欠落したりすることになります。 再帰により、四角形が 2 つの独立した部分に明示的にクリップされ、重なり合わなくなります。 

別のケースは、長方形が完全に半分の内側にあるが、その境界に位置合わせされていない場合に発生します。 たとえば、上部ブロックの中央で始まるクエリは、たとえ分割線に触れていなくても、反転されたパリティを継承する必要があります。 このアルゴリズムは、幾何学的配置とは独立した状態としてパリ​​ティを渡し、位置に関係なく正確さを保証します。 

最後に、基本レベルで$2 \times 1$、パリティ反転の処理が間違っていると、黒と黄色のセルが入れ替わってしまい、たとえ高次の再帰が正しかったとしても、体系的に間違った答えが生成されてしまいます。
