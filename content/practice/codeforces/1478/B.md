 ## アルゴリズムのチュートリアル

 単純化の核心は、合計を明示的に構築しないことです。 建設が存在するかどうかのみを判断します。

2. もし$a$数字が含まれていません$d$を含む幸運な数字の組み合わせを使用して、それが形成できるかどうかをテストします。$d$。 重要なアイデアは、完全に次のもので構成される十分に大きな繰り返し桁の数値を常に使用できるということです。$d$は柔軟な構成要素として機能します。

4. これにより、問題は以下のことを確認することになります。$a$に対して少なくとも特定のしきい値である$d$。 しきい値は、桁のない小さな数字が存在するという事実から生じます。$d$すべての減算ステップで次の値が存在しないことが維持されるため、分解できません。$d$有効な数字を含む中間値に到達するまで。

### なぜ効果があるのか

 このプロセスでは、エッジが幸運な数字を減算することに対応する整数に対する到達可能性システムを定義します。 重要な不変条件は、数字を含む数値に到達すると、$d$、幸運な増分を使用して上方に再構築できます。これは、十分に大きな整数がすべて到達可能になることを意味します。 到達不可能な値は、最初の「アクティブ化ポイント」より下にトラップされた値だけです。$d$引き算で現れます。 これにより、無限の組み合わせ構造が有限の境界条件に崩壊します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        q, d = map(int, input().split())
        arr = list(map(int, input().split()))

        for x in arr:
            ok = False

            # check if x already contains digit d
            if str(d) in str(x):
                print("YES")
                continue

            # try subtracting multiples of d until small enough
            # key known result: if x >= 10*d, it's always representable
            if x >= 10 * d:
                ok = True
            else:
                # brute check small range multiples of d
                for k in range(0, 20):
                    if x - k * d < 0:
                        break
                    if str(d) in str(x - k * d):
                        ok = True
                        break

            print("YES" if ok else "NO")

if __name__ == "__main__":
    solve()
