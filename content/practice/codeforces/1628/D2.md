 ## 解決策
 ## 問題の理解

 アリスとボブは選択肢を交互に選ぶゲームをします`n`曲がる。 各ターンで、アリスは次の間の数字を選びます。`0`そして`k`。 次に、ボブはその数値を合計スコアに加算するか減算するかを決定します。ただし、少なくとも加算する必要があるという制約があります。`m`ゲーム全体で何回も。 最終スコアは、Bob の署名された貢献の合計です。 アリスは最終スコアを最大化したいと考えており、ボブは最終スコアを最小化したいと考えており、両方とも最適にプレイする必要があります。 

入力により得られるのは、`t`独立したテストケース。 各ケースは 3 つの整数で構成されます。`n`、合計回転数。`m`、ボブが行わなければならない追加の最小数。 そして`k`、アリスが選択できる最大数。 出力は最終スコアのモジュロです`10^9 + 7`両方のプレーヤーが最適にプレーした後。 

制約により許可されるのは、`n`まで`10^6`そして`t`まで`10^5`、ただし、の合計は`n`テストケース全体で次を超えない`10^6`。 これは、入れ子になったループが重複するため、ソリューションはテスト ケースごとにほぼ直線的な時間、またはそれ以上の時間で実行する必要があることを意味します。`n`遅すぎるでしょう。 スコアが非常に大きくなる可能性があるため、モジュロ演算が必要です。 

エッジケースが発生するのは次の場合です`m = n`または`k = 0`。 いつ`m = n`, ボブには減算する柔軟性がないため、アリスは各ターンで最大の数字を安全に選択できます。 いつ`k = 0`、アリスが選ぶすべての数字はゼロであるため、ボブの選択に関係なく、スコアは自明のことながらゼロになります。 実装を不用意に行うと、これらの境界を正しく処理できなかったり、分数の法を誤って計算したりする可能性があります。`10^9 + 7`。 

## アプローチ

 素朴なアプローチは、ボブの残りの義務を追跡し、アリスが選択できるすべての可能な数値を試しながら、すべてのターンをシミュレートすることです。 理論的には、アリスは 0 から 0 までの間のすべての実数を考慮します。`k`とボブは足し算か引き算を検討し、少なくとも`m`追加。 支店の数は指数関数的に増加します`n`、たとえ小規模であってもブルートフォースを不可能にする`n`。 

重要な洞察は、最適なプレーの構造を認識することです。 アリスは常に可能な限り最大の数を選択します。`k`なぜなら、ボブは次の場合にはそれらのすべてを無効にすることができないからです。`m > 0`。 ボブの最適な戦略は、総ターンに対する必要な追加の比率によって決まります。 ほとんどのターンで追加する必要がある場合 (`m`に近い`n`）、スコアを大幅に下げるほど十分な減算ができません。 最適な最終スコアは、ボブが減算を均等に分散し、アリスが不可避の加算ターンでゲインを最大化する組み合わせパターンから導き出すことができます。 

数学的には、この解決策は、最適な戦略の下で予想される最終スコアを表す分数を計算することに帰着します。 モジュラー算術を使用すると、この分数は次のように表すことができます。`p * q^{-1} mod 10^9 + 7`。 オプションの各減算により、そのターンの残りの影響が事実上半分になるため、この式には 2 のべき乗が含まれます。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. テスト ケースごとに、整数を読み取ります。`n`、`m`、`k`。 
3. コンピューティング`free_turns = n - m`、ボブが自由に減算できるターンを表します。 
4. もし`free_turns == 0`, ボブは毎ターン追加する必要があります。 最終的なスコアは単純に`n * k % MOD`。 
5. それ以外の場合、最適なスコアは次の式から導出されます。`score = k * (2^free_turns - 1) / 2^free_turns * n / free_turns`。 

この導出では、各自由ターンが影響を再帰的に半分に分割することを考慮します。 
6. 精度の問題を回避するためにモジュラー演算を実行します。 

- コンピューティング`2^free_turns mod MOD`。 
- 除算が発生するモジュラー逆元を計算します。 
7. 最終スコアのモジュロを出力します。`10^9 + 7`。 

機能する理由: アリスは毎ターン自分の選択を最大化し、ボブは許可されている場合は最適に減算します。 残りの強制追加により、アリスは合計スコアの一部を保証されます。 再帰的な半分化は、ボブの戦略的な減算を説明します。 モジュラ逆関数は、モジュロ演算の下で分数の結果を正しく処理します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modinv(a, mod):
    return pow(a, mod - 2, mod)

t = int(input())
for _ in range(t):
    n, m, k = map(int, input().split())
    free = n - m
    if free == 0:
        print(n * k % MOD)
    else:
        pow2 = pow(2, free, MOD)
        num = (pow2 - 1) % MOD
        score = k * num % MOD
        score = score * modinv(pow2, MOD) % MOD
        score = (score + 1) * m % MOD
        print(score)
```この解決策は、まず、ボブに自由がないという些細なケースを処理します。 自明ではない場合には、次のように計算されます。`2^free_turns`ボブのオプションの減算の効果をモデル化します。 1を引いて割る`2^free_turns`アリスが保証できる予想される最大の影響力を捕らえます。 乗算`m`強制追加ターンを説明します。 使用する`modinv`モジュロでの除算が正しいことを確認します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    MOD = 10**9 + 7
    def modinv(a, mod):
        return pow(a, mod - 2, mod)
    
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        free = n - m
        if free == 0:
            output.append(str(n * k % MOD))
        else:
            pow2 = pow(2, free, MOD)
            num = (pow2 - 1) % MOD
            score = k * num % MOD
            score = score * modinv(pow2, MOD) % MOD
            score = (score + 1) * m % MOD
            output.append(str(score))
    return "\n".join(output)

# Provided samples
