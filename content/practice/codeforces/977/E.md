 ## 解決策

 ## 問題の理解

 無向グラフが与えられ、そのタスクは、単純なサイクルを形成する接続コンポーネントの数を数えることです。 すべての頂点がコンポーネント内にちょうど 2 つの隣接点を持ち、リングを形成する頂点を越える余分なエッジがないように、すべての頂点をリング状に配置できる場合、コンポーネントはサイクルとみなされます。 

グラフ用語で言えば、これは、そのコンポーネント内ですべての頂点の次数がちょうど 2 である接続コンポーネントを探していることを意味します。 余分な分岐や内部コードを持つコンポーネントは、たとえ内部のどこかにサイクルが含まれていたとしても失格となります。 三角形や四角形のような孤立したサイクルは有効ですが、「サイクルとテール」構造は有効ではありません。 

この制約では、最大 200,000 個の頂点とエッジが許可されます。 これにより、すべてのサブセットをチェックしたり、接続を繰り返し再計算しようとするものは即座に除外されます。 どのソリューションも線形または線形に近い時間で実行する必要があるため、DFS、BFS、または DSU ベースのグループ化などのグラフ トラバーサルが必要です。 

いくつかの微妙なエッジケースが自然に現れます。 

正確に 1 つのサイクルを持つ単一の連結成分があるが、余分なエッジがあると条件が崩れます。 たとえば、追加のリーフ ノードが接続された三角形は接続されており、サイクルを含んでいますが、サイクル コンポーネントではありません。 正解寄与度はゼロです。 

純粋なサイクルには少なくとも 3 つの頂点が必要です。 単一エッジを持つサイズ 2 のコンポーネントは、両方の頂点の次数が 1 であっても、閉じたループを形成できないため無効です。 

最後に、孤立した頂点またはツリーは、すべての頂点が次数 2 を持つサイクルを含まないため、常に無効になります。 

## アプローチ

 強引なアイデアは、連結成分を計算し、それぞれの連結成分がサイクルを形成しているかどうかを明示的に検証することです。 これは、コンポーネント内のすべての頂点を収集し、コンポーネント内のすべての頂点の次数がちょうど 2 であり、エッジの数が頂点の数に等しいという 2 つの条件をチェックすることで実行できます。 これが機能するのは、単純なサイクルでは、閉じたループ内でエッジと頂点が 1 対 1 で一致するためです。 

単純なアプローチの問題は、正確さではなく、実装の非効率性にのみ現れます。 隣接リストを繰り返しスキャンしたり、コンポーネントのメンバーシップを非効率的に再計算したりすると、二次的な動作に向かう可能性があります。 ただし、コンポーネントを一度収集して次数をチェックする単純な DFS であっても、線形のままです。 

重要な観察は、接続されたコンポーネントがそのコンポーネント内のすべての頂点の次数が正確に 2 である場合に限り、そのコンポーネントがサイクルであるということです。 これにより、エッジのカウントや構造の再構築が不要になります。 走査中に、コンポーネントのサイズと内部次数の合計を計算したり、コンポーネント内のすべてのノードの次数条件を単純に検証したりできます。 

DFS または BFS を使用して各コンポーネントを 1 回探索し、訪問したノードをマークします。 各コンポーネントについて、すべての頂点が次数 2 を満たすかどうかを確認します。 「はい」の場合、コンポーネントはサイクルです。

 | --- | --- | --- | --- |
 | ブルートフォース (構造を繰り返し再チェック) | O(n²) | O(n) | 遅すぎる |
 | 学位検証付き DFS/BFS | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. グラフの隣接リスト表現を構築します。 これにより、トラバーサル中に各頂点の近傍を一定時間反復することができます。 
2. すべての頂点に対して false に初期化された訪問済み配列を維持します。 これにより、各ノードがすべてのコンポーネントにわたって正確に 1 回処理されるようになります。 
3. 1 から n までのすべての頂点を繰り返します。 頂点が未訪問の場合、その頂点は新しい接続コンポーネントの開始点になります。 
4. この頂点から DFS または BFS を実行し、到達可能なすべてのノードを同じコンポーネントの一部としてマークします。 走査中に、このコンポーネントに属するすべての頂点をリストに収集します。 
5. コンポーネントの走査が終了したら、そのコンポーネント内のすべての頂点をチェックし、その隣接リストのサイズが正確に 2 であることを確認します。この条件により、各頂点がコンポーネント内の 2 つのエッジに正確に参加することが強制され、これは 1 つのサイクルに必要です。 
6. コンポーネント内のすべての頂点がこの条件を満たし、コンポーネントに少なくとも 3 つの頂点がある場合、答えをインクリメントします。 
7. すべての頂点が処理されるまで続行し、最終的な数を出力します。 

### なぜ効果があるのか

 どの接続コンポーネントでも、すべての頂点の次数がちょうど 2 である場合、構造は分岐したり終了したりできません。 任意の頂点から開始してエッジに従うと、最終的には反復せずに開始点に戻り、単一の単純なサイクルを形成する必要があります。 逆に、単純なサイクル グラフには、次数のすべての頂点がちょうど 2 つあります。 したがって、次数条件は、無向グラフのサイクル成分を識別するために必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

sys.setrecursionlimit(10**7)

n, m = map(int, input().split())
g = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    g[u].append(v)
    g[v].append(u)

visited = [False] * (n + 1)

def dfs(start):
    stack = [start]
    comp = []
    visited[start] = True

    while stack:
        u = stack.pop()
        comp.append(u)
        for v in g[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)

    return comp

ans = 0

for i in range(1, n + 1):
    if not visited[i]:
        comp = dfs(i)

        ok = True
        if len(comp) < 3:
            ok = False
        else:
            for u in comp:
                if len(g[u]) != 2:
                    ok = False
                    break

        if ok:
            ans += 1

print(ans)
```このソリューションは隣接リストを構築し、未訪問の各ノードから DFS を実行して、各接続コンポーネントが 1 回だけ抽出されるようにします。 DFS はコンポーネント内のすべてのノードを収集します。 

コンポーネントを抽出した後、コードはまずそのサイズをチェックします。 サイクルには少なくとも 3 つの頂点が含まれている必要があるため、小さいコンポーネントはすぐに拒否されます。 次に、サイクル グラフの定義特性を検証します。つまり、すべての頂点はグラフ全体で正確に 2 つの近傍を持たなければなりません。これは、単純な連結成分では、その頂点が 1 つのサイクル上にあることを意味します。 

よくある間違いは、重複やトラバース状態を慎重に処理せずに、コンポーネント内のエッジを数えようとして頂点と比較しようとすることです。 グローバル隣接リスト次数を使用すると、再計算が回避され、微妙な簿記エラーが回避されます。 

DFS は、200,000 ノードの上限を考慮して、再帰の深さの問題を回避するために反復されます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, input().split())
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        g[u].append(v)
        g[v].append(u)

    visited = [False] * (n + 1)

    def dfs(start):
        stack = [start]
        comp = []
        visited[start] = True
        while stack:
            u = stack.pop()
            comp.append(u)
            for v in g[u]:
                if not visited[v]:
                    visited[v] = True
                    stack.append(v)
        return comp

    ans = 0
    for i in range(1, n + 1):
        if not visited[i]:
            comp = dfs(i)
            if len(comp) >= 3 and all(len(g[u]) == 2 for u in comp):
                ans += 1
    return str(ans)

 ## 特殊なケース

 次のような単一のエッジコンポーネント`1 - 2`サイズは 2 であり、サイクルの最小サイズ要件を満たしていないため、正しく処理されます。 DFS は両方のノードを収集しますが、チェックでは即座に拒否されます。 

次のような三角形`1 - 2 - 3 - 1`すべてのノードの隣接リスト サイズが 2 であるため、合格します。DFS は 3 つのノードすべてを 1 つのコンポーネントに収集し、この条件は各ノードに当てはまります。 

みたいな星図`1 connected to all others`中心ノードの次数が 2 より大きいため、グラフが接続されているにもかかわらず、サイクル条件に違反しているため失敗します。
