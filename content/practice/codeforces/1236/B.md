 ## 解決策
 ## 問題の理解

 いくつかの種類のアイテムが与えられますが、それぞれの種類は無制限に供給されます。 また、それぞれが異なる友人に属する別個のボックスがいくつかあるため、ボックスにはラベルが付けられており、交換することはできません。 

アイテムの種類ごとに、アリスはその種類を入れるボックスのサブセットを選択します。 単一のボックス内に同じ種類のアイテムを複数入れることはできませんが、種類がボックスに入れられるか入れられないかのどちらかであるため、その制限は自動的に満たされます。 重要な制約は、すべての種類が少なくとも 1 つのボックスに表示される必要があるため、完全に使用されない種類はないということです。 

したがって、問題は、m 個のラベル付きボックスの空でないサブセットを n 種類のそれぞれに割り当てることができる方法が何通りあるかを数えることに帰着します。 

各種類は選択の点で独立していますが、「すべての種類がどこかで少なくとも 1 回は使用される」というグローバル要件が種類ごとにすでに適用されているため、異なる種類間の結合はありません。 微妙なのは、種類間の相互作用ではなく、各種類がボックスのサブセットを選択し、すべてのサブセットが空であってはいけないことを正しく解釈することです。 

入力サイズは最大 10^9 であるため、サブセットの列挙、ボックスの反復、または n または m に対する動的プログラミングの使用などのアプローチは不可能です。 テスト ケースごとの O(n) または O(m) でも大きすぎます。 ソリューションでは、べき乗モジュラーを使用して対数時間で計算できる閉形式の式にすべてを還元する必要があります。 

よくある失敗例は、各ボックスに種類のサブセットを個別に割り当てるとして条件を誤って解釈し、(2^n - 1)^m のカウントや同様の誤った式につながることです。 もう 1 つの間違いは、種類ごとに空の選択が禁止されていることを忘れていることです。これにより、誤ってゼロの割り当てが含まれてしまいます。 

## アプローチ

 まずは 1 種類に焦点を当てます。 固定の 1 種類については、どのボックスに表示されるかを決定します。 m 個の異なるボックスがあるため、すべてのボックスがこの種類に対して選択されるか、選択されないかのいずれかになります。 これにより、2^m 個の可能なサブセットが得られます。 ただし、空のサブセットは禁止されています。すべての種類が少なくとも 1 つのボックスに表示される必要があるため、1 種類の有効な選択肢の数は 2^m - 1 になります。 

次に複数の種類を考えてみましょう。 それぞれの種類は、空ではないボックスのサブセットを独自に独立して選択します。 異なる種類の選択肢は互いに干渉しないため、n 種類すべてにわたって選択肢の数を増やします。 これにより、(2^m - 1)^n が得られます。 

これは重要な構造の単純化です。問題はボックス間でオブジェクトを分散することではなく、各タイプにコンテナのサブセットを割り当てることです。 型の独立性により、組み合わせ論が単純な累乗式に折りたたまれます。 

強引なアイデアは、各種類のボックスのすべてのサブセットを反復処理してから、グローバル制約を強制することです。 それは O(2^m * n) となり、10^9 はおろか、m = 20 であっても不可能です。 それぞれの種類が独立しているという観察により、列挙する必要がなくなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットのブルートフォース列挙 | O(n · 2^m) | お(1) | 遅すぎる |
 | べき乗モジュラーを使用した閉じた形式 | O(log n + log m) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 固定された種類の場合、各ボックスがその種類が含まれるかどうかを独立して決定することに注目してください。 これにより、1 つの種類に対して 2^m 通りの割り当てが可能になります。 
2. すべての種類が少なくとも 1 回は出現する必要があるため、ボックスにその種類が含まれていない場合は除外します。 これにより、カウントは 2^m − 1 に減ります。 
3. 異なる種類の選択は相互に影響を及ぼさないため、各種類を独立して扱います。 この独立性により、あらゆる種類の可能性が増大します。 
4. 種類ごとのカウントを n 乗して、(2^m − 1)^n を求めます。 
5. 高速 2 進累乗を使用して 2^m モジュロ MOD を計算します。 
6. 負の値を避けるために、モジュロ演算で 1 を慎重に減算します。 
7. 再度べき乗剰余を使用して結果を n 乗します。 

機能する理由: それぞれの有効な構成は、種類ごとに空ではないボックスのサブセットを個別に選択することによって一意に決定されます。 グローバル構成と、m 要素セットの n 個の空でないサブセットのタプルとの間には全単射があります。 デカルト積構造が正確に保持されるため、カウントの乗算は正確であり、オーバーカウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

n, m = map(int, input().split())

# number of non-empty subsets of boxes for one kind
base = modexp(2, m) - 1
base %= MOD

# total ways
ans = modexp(base, n)

print(ans)
```このソリューションでは、まず高速累乗を使用して 2^m モジュロ MOD を計算します。 1 を減算すると空のサブセットが削除されるため、負の値を避けるためにモジュロ MOD を実行する必要があります。 結果として得られる塩基は、1 つの種類に対する有効な選択肢を表します。 次に、2 番目のべき乗により、この底が n に引き上げられ、各種類のサブセットの独立した割り当てが反映されます。 

一般的な実装上の落とし穴は、減算の後に剰余を取るのを忘れることです。これにより、負の中間値が生成され、その後のべき乗が中断される可能性があります。 もう 1 つの微妙な問題は、モジュロ演算でマイナス 1 を慎重に処理せずに、Python の組み込み pow だけで十分であると想定していることです。 

## 実用的な例

 ### 例 1

 入力:```
1 3
```ここで、n = 1 および m = 3 です。単一種類の場合、3 つのボックスの空でないすべてのサブセットが有効です。 

| ステップ | 値 |
 | --- | --- |
 | 2^m | 8 |
 | 2^m - 1 | 7 |
 | (2^m - 1)^n | 7 |

 出力は7です。 

これは、唯一の種類のボックスの空ではないサブセットを選択しているだけであるという解釈を裏付けます。 

### 例 2

 入力:```
2 2
```ここで、n = 2、m = 2 となります。 

| ステップ | 値 |
 | --- | --- |
 | 2^m | 4 |
 | 2^m - 1 | 3 |
 | (2^m - 1)^n | 9 |

 2 種類のそれぞれは、{box1, box2} の 3 つの空でないサブセットの 1 つを独立して選択します。 

これにより、種類間の独立性が確認され、乗法構造が示されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 | 時間 | O(log n + log m) | 2 進累乗を使用した 2 つのべき乗剰余演算 |

## テストケース```python
import sys, io

MOD = 10**9 + 7

def modexp(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, m = map(int, input().split())
    base = modexp(2, m) - 1
    base %= MOD
    return str(modexp(base, n))

# provided samples
assert solve("1 3\n") == "7"

# minimum edge case
assert solve("1 1\n") == "1"

# symmetric case
assert solve("2 2\n") == "9"

# larger small case
assert solve("3 2\n") == str(pow((pow(2,2,MOD)-1),3,MOD))

# large exponent sanity check
assert solve("10 10\n") == str(pow((pow(2,10,MOD)-1),10,MOD))
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 1 | 1 | 最小構成の正確さ |
 | 2 2 | 9 | 種類を超えた独立性 |
 | 3 2 | 計算された | べき乗の正確さ |
 | 10 10 | 計算された | 大きな値の安定性 |

 ## 特殊なケース

 m = 1 の場合、各種類は 1 つのボックスにのみ配置できるため、有効なサブセットは 1 つだけになります。 この式は 2^1 − 1 = 1 を与え、n に引き上げても 1 を維持します。これは、すべての種類が唯一の利用可能なボックスに入れられる必要があるという直観と一致します。 

n = 1 の場合、問題は単一の種類のボックスの空でないサブセットを選択することになります。 この式では、2^m − 1 が正しく得られます。たとえば、m = 3 の場合、結果は 7 となり、すべての可能な配置と一致します。 

潜在的な失敗例は、空のサブセットの 1 の減算を忘れることです。 2^(m・n) を誤って使用すると、一部の種類が配置されない構成が過大にカウントされてしまいます。 正しい構造では、種類ごとに空でないことが強制されるため、べき乗の前に減算を行う必要があります。
