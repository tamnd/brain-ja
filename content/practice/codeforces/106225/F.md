 ## 問題の理解

 私たちは、非常に構造化された構造から来ていると主張される配列を与えられました。 正の整数を固定する$k$。 すべての商品を列挙すると$i \cdot j$のために$1 \le i \le k$そして$1 \le j \le k$行ごとに長さを取得します$k^2$順序。 各行$i$で構成されています$i, 2i, 3i, \dots, ki$、すべての行が昇順に連結されます。$i$。 

入力により、このような平坦化された乗算表の連続セグメントが得られます。 私たちの仕事は、可能な限り最小のものを決定することです$k$このセグメントは、$k \times k$九九。 

主要な構造上の制約は、セグメントが行のグローバルな順序と一致していなければならないことです。 セットを照合するのではなく、非常に厳格で繰り返される算術パターンの部分文字列を照合します。 

制約は十分小さいので、$n \le 100$したがって、テスト ケースごとに 3 次でもよい解であれば問題ありませんが、各候補の妥当性について慎重に推論する必要があります。$k$、テーブルは次のように成長するため、$k^2$そして構造は可分性パターンに依存します。 

値が頻繁に繰り返される場合、微妙な問題が発生します。 たとえば、次のようなシーケンス$[2, 2, 2, 2]$または$[1, 1, 1]$さまざまな場所で複数の方法で現れる可能性があります$k$、単純な貪欲マッチングでは、矛盾した行の解釈が簡単に選択されてしまう可能性があります。 もう 1 つの注意が必要なケースは、セグメントが行境界を越える場合です。これは、平坦化によって区切り文字が挿入されないためです。 有効な一致は行の途中で始まり、別の行の途中で終了する場合があります。 

たとえば、$k = 4$、テーブルは次のように始まります。$[1,2,3,4,2,4,6,8,3,6,\dots]$。 

のようなセグメント$[4,6,8,10]$は単一の行に対応しませんが、より大きなテーブルの行 2 と行 5 にまたがります。 行内のみをチェックするという単純な考えでは、このようなケースを見逃してしまいます。

 ## アルゴリズムのチュートリアル

 主な困難は、配列が乗算表からのものである場合に、配列がどのような構造を満たす必要があるかをリバース エンジニアリングすることです。 

各行は行インデックスに等しい差を持つ等差数列であるという事実を利用します。 したがって、2 つの連続する要素が同じ行に属している場合、それらの差は一定であり、行番号と等しくなります。 

行の境界がわからないため、各セグメントに一貫した行インデックスを割り当てようとします。 重要な考え方は、連続セグメントの有効な表現はすべて 1 行内に収まる最大のランに分解でき、それらのランは行インデックスの増加と一致する必要があるということです。 

したがって、候補者をチェックします$k$無限の平坦な行グリッドをたどることによってシーケンスが生成されたものとして解釈しようとすることによって$1$に$k$、各行は$i, 2i, \dots, ki$を概念的に順番に繰り返します。 

### ステップ

 1. 候補者が確定している場合$k$、行が次のような概念的なグリッドを考えてみましょう。$i$シーケンスです$i, 2i, \dots, ki$。 明示的に構築するわけではありませんが、どの位置からでも$(i,j)$、次の要素は一意に決まります。 
2. 可能なすべての開始セルを試します$(i,j)$と$1 \le i \le k$そして$1 \le j \le k$。 開始値は一致する必要があります$a_0$したがって、次の候補のみを保持します。$i \cdot j = a_0$。 
3. 有効な開始ペアごとに、シーケンスを順方向にシミュレートします。 ステップで$t$、私たちはここにいます$(i_t, j_t)$かどうかを確認します。$i_t \cdot j_t = a_t$。 そうでない場合、この開始は無効です。 
4. 決定的に前進する:$j_t < k$に移動します$(i_t, j_t + 1)$、それ以外の場合は、に移動します$(i_t + 1, 1)$。 もし$i_t > k$、テーブルを離れるので早めに終了します。 
5. いずれかの開始状態がすべての要素と正常に一致すると、現在の状態が$k$実現可能です。 
6. 答えは最小限です$k$for which feasibility holds.

 ### なぜ効果があるのか

 フラット化されたテーブルは、すべてのペアにわたる単一の決定論的な走査です。$(i,j)$行と列の辞書編集順。 連続したサブ配列は、この走査の連続したセグメントに正確に対応します。 したがって、すべての有効な解はこのトラバーサルの開始位置に対応する必要があり、開始位置が固定されると、シーケンスが強制されます。 これにより曖昧さがなくなり、正確性とは、考えられるすべての開始をチェックし、一貫性を検証することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def ok(a, k):
    n = len(a)

    # try every starting position (i, j)
    for i in range(1, k + 1):
        for j in range(1, k + 1):
            if i * j != a[0]:
                continue

            x, y = i, j
            good = True

            for t in range(n):
                if x > k:
                    good = False
                    break
                if x * y != a[t]:
                    good = False
                    break

                # move to next cell in flattened table
                if y < k:
                    y += 1
                else:
                    x += 1
                    y = 1

            if good:
                return True

    return False

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        mx = max(a)

        # k must be at least sqrt(max value) in any valid table
        lo, hi = 1, int(mx ** 0.5) + 2
        ans = hi

        for k in range(lo, hi + 1):
            if ok(a, k):
                ans = k
                break

        print(ans)

if __name__ == "__main__":
    solve()

開始フィルター`i * j == a[0]`ほとんどの無効な状態を即座に削除します。 この枝刈りがなければ、シミュレーションは依然として正確ですが、速度が 1 倍遅くなります。$k^2$。 

外側のループが増加します$k$最小の有効なテーブル サイズが必要なので、小さいものから大きいものまで、最初の実行可能な値で停止します。

 ## 特殊なケース

 微妙なケースの 1 つは、すべての値が同一である場合です。$[1,1,1,1]$。 アルゴリズムはこれを正しく処理します。$k \ge 1$、複数の開始位置が存在します。$i \cdot j = 1$、具体的にのみ$(1,1)$。 からのシミュレーション$(1,1)$決定論的に進行する$(1,2), (1,3), \dots$、一定の値ではなく、長期的に増加する値が生成されます。 したがって、のみ$k = 1$機能し、アルゴリズムはより大きなものを正しく拒否します$k$。 

もう 1 つのエッジ ケースは、シーケンスで複数の行の境界を即座に越える必要がある場合です。$[k, k+1, k+2]$ある候補者にとって$k$。 遷移ルール​​により、列の後に行が強制的に増分されます。$k$、そのため、予想されるジャンプに不一致があると、早期のスタートが無効になります。 行遷移は決定的で固定されているため、シミュレーションでは無効な行スキップが発生しないことが保証されます。
