 ## 解決策
 ## 問題の理解

 各値がモンスターのタイプを表す配列が与えられます。 残っているすべての型がその値と同じ回数だけ出現する場合、レベルはバランスが取れていると見なされます。 たとえば、次のように入力した場合、`4`が存在する場合、それは正確に 4 回発生する必要があります。 完全に削除されたタイプには要件は課されません。 タスクは、残りのマルチセットがこのルールを満たすように、できるだけ少ない要素を削除することです。 

入力は次のもので構成されます`n`モンスターの種類ごとに、`0`そして`n`。 削除のみが許可されるため、値の頻度を増やすことはありません。 タイプごとに、その値と正確に同じ頻度で保持するか、そのタイプのすべてのコピーを削除します。 

バウンド`n ≤ 1000`は小さいので、二次解でも快適に適合します。 それでも、問題の構造により、周波数を数えた後に線形の解決策が得られます。 重要な情報は、配列の順序ではなく、各値が何回出現するかということだけです。 

誤って対処しやすい状況がいくつかあります。 

値がそれ自体の値よりも出現回数が少ないとします。```
3
2 2 1
```タイプ`2`は 2 回表示されるため、そのまま残ります。 タイプ`1`は一度出現するので、そのままにすることもできます。 削除は必要ありません。答えは次のとおりです。`0`。 カウントがその値より大きくない値を削除する不用意なアプローチは、タイプを誤って削除します。`1`。 

もう 1 つのケースは、値の出現回数が少なすぎる場合です。```
2
3 3
```タイプ`3`は 2 回しか出現しませんが、残るには 3 つのコピーが必要です。 要素を追加することは不可能なので、両方のコピーを削除する必要があります。 答えは`2`。 

特別な値は`0`。```
4
0 0 1 1
```タイプの場合`0`残る場合は、出現回数がちょうど 0 回である必要があり、まったく存在できないことを意味します。 両方のゼロを削除する必要があります。 タイプ`1`が 2 回表示されるため、1 つのコピーは削除され、もう 1 つは保持されます。 答えは`3`。 ゼロにはゼロの出現が必要であることを忘れると、間違った答えにつながります。 

## アプローチ

 最も直接的な総当り攻撃のアイデアは、それぞれの異なる値を個別に処理することです。 価値のために`x`周波数付き`f`、あらゆる可能性を試して、一部のコピーを保持することが合法かどうかを判断できます。 唯一の有効な残りの周波数は正確に`x`、意味のある選択肢は 2 つだけです。 もし`f ≥ x`、私たちは保つかもしれません`x`コピーして削除する`f - x`そうでない場合は、すべてを削除する必要があります`f`コピー。 

組織化されていないブルート フォースの実装では、値ごとに配列を繰り返しスキャンする可能性があり、その結果、`n²`最悪の場合の運用。 と`n = 1000`、これでも機能しますが、不必要な作業が行われます。 

重要な観察は、異なる値は相互作用しないということです。 タイプの決定`5`タイプの決定には影響しません`7`。 すべての値の頻度がわかれば、各タイプの最小削除数が個別に決定されます。 

値の場合`x`表示されます`f`場合によっては 2 つのケースが発生します。 いつ`f < x`追加のコピーを作成できないため、タイプを維持することは不可能です。`f`出現箇所は削除されます。 いつ`f ≥ x`、正確に保ちます`x`コピーして余分なものを削除する`f - x`。 

周波数マップは必要なすべての情報を提供し、それぞれの個別の値は 1 回処理されます。

 ## アルゴリズムのチュートリアル

 1. 配列を読み取り、各値が出現する回数を数えます。 
2. 答えをゼロに初期化します。 
3. 個別の値ごとに`x`周波数付き`f`、型を保持するのに十分なコピーが存在するかどうかを判断します。 
4. もし`f < x`、 追加`f`この値のすべてのコピーを削除する必要があるため、答えに戻ります。 

値は、以下の値では存続できません。`x`要素の追加は許可されていません。 
5. それ以外の場合は追加します`f - x`まさにその答えに`x`コピーは残しておかなければなりません。 

必要以上のコピーは不要ですので削除してください。 
6. 蓄積された回答を出力します。 

### なぜ効果があるのか

 各値は他の値から完全に独立しています。 タイプの場合`x`、残りの合法的な周波数は次のとおりです。`x`。 現在の周波数であれば、`f`よりも小さいです`x`、そのタイプを含む有効な構成が存在しないため、すべてのコピーを削除することは避けられません。 もし`f`少なくとも`x`、正確に保つ`x`より小さな正の周波数は無効であり、より大きな周波数は条件に違反するため、コピーにより削除が最小限に抑えられます。 すべての値の最適コストを合計すると、全体的な最適値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# solution
from collections import Counter

n = int(input())
a = list(map(int, input().split()))

cnt = Counter(a)

ans = 0

for x, f in cnt.items():
    if f < x:
        ans += f
    else:
        ans += f - x

print(ans)
```最初の部分では、次を使用してすべてのモンスター タイプの頻度をカウントします。`Counter`。 配列の順序は無関係であるため、周波数には必要な情報がすべて含まれています。 

変数`ans`削除の合計数を保存します。 それぞれの値について`x`、コードはアルゴリズムで説明されている 2 つのケースを区別します。 

いつ`f < x`、頻度に達したため、すべての出現が削除されます。`x`不可能です。 それ以外の場合は、正確に`x`コピーは保管され、超過分は`f - x`コピーは削除されます。 

値`0`自動的に処理されます。 以来`f < 0`は決して true ではありません。2 番目のブランチが寄与します`f - 0 = f`、すべてのゼロが削除されることを意味し、定義と一致します。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    cnt = Counter(a)

    ans = 0
    for x, f in cnt.items():
        if f < x:
            ans += f
        else:
            ans += f - x

    return str(ans)

# provided samples
assert run("5\n1 1 2 2 3\n") == "2", "sample 1"
assert run("10\n1 2 3 2 4 4 4 4 5 2\n") == "3", "sample 2"

# custom cases
assert run("1\n1\n") == "0", "minimum size"
assert run("4\n0 0 0 0\n") == "4", "all zeroes"
assert run("5\n5 5 5 5 5\n") == "0", "all equal and already balanced"
assert run("2\n3 3\n") == "2", "frequency smaller than value"
assert run("6\n2 2 2 2 1 1\n") == "3", "excess copies"
```| テスト入力 | 期待される出力 | 検証内容 |

ここで考えてみましょう```

```周波数は次のとおりです。`0 → 2`そして`1 → 2`。 価値のために`0`、アルゴリズムが貢献します`2 - 0 = 2`、すべてのゼロを削除します。 価値のために`1`、貢献します`2 - 1 = 1`、コピーを 1 つだけ保持します。 最終的な答えは、`3`。 

最後に考えてみましょう```

```タイプ`2`2 回表示され、次のように入力します`1`が一度出現します。 両方の頻度はすでにその値と一致しているため、それぞれの欠失はゼロです。 答えは`0`、アルゴリズムがすでにバランスの取れた構成を変更しないことを確認します。
