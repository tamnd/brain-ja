 ## 解決策
 ## 問題の理解

 この問題は数字の文字列を提示し、最大 1 つの連続した削除を使用して文字列「2020」に変換できるかどうかを尋ねます。 Polycarp は、文字列内の任意の場所にある 0 個以上の連続した文字を削除することがあります。 入力は複数のテスト ケースで構成され、それぞれが文字列の長さと文字列自体を提供します。 各テスト ケースの出力は、そのような変換が可能であれば「YES」、それ以外の場合は「NO」になります。 

制約は中程度です。文字列の長さは 4 ～ 200 で、テスト ケースは最大 1000 個まで存在できます。 各文字列は比較的短いため、ソリューションでは時間制限を超えることなく、複数の削除の可能性をチェックできます。 エッジケースには、正確に「2020」である文字列、先頭または末尾に「2020」を含む文字列、内部ブロックを削除することで「2020」が形成される可能性がある文字列が含まれます。 たとえば、「22020」は最初の文字を削除すると「2020」になり、「20202」は最後の文字を削除すると「2020」になります。 単純なアプローチでは、連続する部分文字列として「2020」のみをチェックする場合、これらの位置を見逃す可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべての部分文字列の削除を試み、残りの文字列を再構築して、「2020」と比較します。 ある長さの文字列の場合`n`、 がある`n*(n+1)/2`部分文字列、複雑さは次のとおりです。`O(n^3)`各削除を確認するため。 ターゲット文字列が小さい「2020」と問題の構造を考慮すると、これは不要です。 

重要な洞察は、「2020」の長さが 4 であるため、元の文字列の最大 4 文字が文字列の形成に関連するということです。 最初のものかどうかを確認するだけで済みます。`k`文字列の文字と最後の文字`4-k`一部の文字は「2020」を構成します`k`これは、単一の連続した削除によって「2020」がそのまま残される可能性があるすべてのシナリオをカバーします。 この観察により、問題は、すべての削除を考慮することから、文字列ごとに正確に 5 つのケース (接頭辞のみ、接尾辞のみ、および接頭辞と接尾辞の組み合わせの合計 4 文字) をチェックすることに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | プレフィックスとサフィックスのチェック | 文字列ごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. テスト ケースごとに、文字列を読み取ります。`s`そしてその長さ`n`。 
3. 次のことを確認します。`s`それ自体は「2020」です。 そうであれば、「YES」と出力します。 
4. それ以外の場合は反復します`k`0 ～ 4 で、先頭からの文字数を表します。`s`。 最初を取る`k`登場人物とラスト`4-k`文字を連結して「2020」と比較します。 
5. いずれかの組み合わせが一致する場合は、「YES」を出力します。 どれも一致しない場合は、「NO」を出力します。 

これが機能する理由は、次の有効な単一削除変換が存在するためです。`s`「2020」にするには、元の文字列の一部のプレフィックスと一部のサフィックスをそのままにしておく必要があります。 「2020」の長さは4で固定されているため、手付かずの文字は開始と終了の間にのみ配置できます。 これにより、すべてのチェックが保証されます。`k`0 から 4 までの値は、考えられるすべての有効な削除をカバーします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        target = "2020"
        found = False
        for k in range(5):
            if s[:k] + s[n-(4-k):] == target:
                found = True
                break
        print("YES" if found else "NO")

if __name__ == "__main__":
    solve()
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 各文字列について、「2020」に対して 5 つの潜在的なプレフィックスとサフィックスの組み合わせがチェックされます。 スライス操作は安全です。`n >= 4`保証されています。 不必要なチェックを避けるために、一致が見つかるとループは直ちに中断されます。
