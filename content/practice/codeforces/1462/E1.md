 ## 解決策
 ## 問題の理解

 各要素が 1 から 1 までの範囲にある整数の配列が与えられます。`n`、トリプルの数を数えるように求められます`(i, j, z)`トリプル内の最大値が最小値と最大 2 だけ異なるようにします。配列には重複が含まれる可能性があるため、複数のテスト ケースを効率的に処理することが求められます。 各テスト ケースには独自の配列があり、すべてのテスト ケースの長さの合計が 200,000 を超えることはありません。 

この問題では、制限された範囲を持つ 3 つの要素の組み合わせを数える必要があります。 単純な実装では、すべてのトリプルを明示的に考慮します。`O(n^3)`そして実行不可能`n`2・10^5まで。 複雑さを軽減するために並べ替えやカウントを活用する方法が必要です。 明らかでないエッジ ケースには、すべてが同一の要素を持つ配列、有効なトリプルが存在しない分散した数値を持つ配列、および答えが 0 でなければならない 3 要素より短い配列が含まれます。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべてのトリプルを反復処理することです。`(i, j, z)`3 つのネストされたループを使用して、`max - min ≤ 2`。 これは正しいですが、複雑すぎて遅すぎます`O(n^3)`。 

重要な洞察は、配列をソートすることです。 ソート後、有効なトリプルはソートされた配列内の連続する要素で構成されている必要があります。これより離れた要素を含めると最大差を超えることになるためです。 2 つのポインターを使用して、配列を反復処理できます。開始インデックスを修正します。`l`そして終了インデックスを拡張します`r`できる限りそのように`a[r] - a[l] ≤ 2`。 次に、有効なトリプルの数は、`a[l]`最小の要素は、追加要素から 2 つを選択する方法の数です。`r - l`残りの要素。 これは以下を使用した組み合わせ計算です。`C(n, 2)`。 

アレイコストの並べ替え`O(n log n)`、および 2 ポインター スイープのコスト`O(n)`、全体的な結果を与える`O(n log n)`テストケースごとに。 この方法は、制約を考慮すると効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | お(1) | 遅すぎる |
 | 並べ替え + 2 つのポインター | O(n log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 並べ替え`a`降順ではない順に。 並べ替えにより、有効なトリプル内の要素が連続していることが保証されます。 
4. ポインタを初期化する`l = 0`候補セグメントと変数の開始をマークする`ans = 0`有効なトリプルの合計数を累積します。 
5. 反復する`r`配列インデックス上で。 その間`a[r] - a[l] > 2`、増分`l`差分制約を満たすまでセグメントを縮小します。 
6. 各ポジションについて`r`、セグメント内の要素の数を計算します。`length = r - l`。 もし`length ≥ 2`を使用してトリプルの数を計算します。`length * (length - 1) // 2`そして追加します`ans`。 
7. すべての処理が完了したら`r`、印刷`ans`。 

機能する理由: 並べ替えにより、差が 2 を超えるトリプルには有効なセグメント外の要素が含まれないことが保証されます。 2 ポインターのアプローチにより、考えられるすべての有効なセグメントが 1 回カウントされることが保証されます。 組み合わせ式は、各セグメントのトリプルの数を正確にカウントします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        ans = 0
        l = 0
        for r in range(n):
            while a[r] - a[l] > 2:
                l += 1
            length = r - l
            if length >= 2:
                ans += length * (length - 1) // 2
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず配列を並べ替えて、連続する要素をトリプルの唯一の候補にします。 左のポインタ`l`差が 2 を超えた場合にのみ処理が進み、無効な要素が決して含まれないことが保証されます。 組み合わせ式は、位置で終わるすべての有効なトリプルをカウントします。`r`効率的に、ネストされたループを回避します。 3 要素よりも短いセグメントなどの境界条件は自然に処理されます。`length < 2`追加はゼロになります。

### 例 2

 入力:`a = [1, 1, 1, 1]`すべての要素は同一であるため、3 つのインデックスのすべての組み合わせが有効です。 セグメントの長さは 0 から 3 まで増加します。`r`動きます。 のために`r = 2`、トリプルを1つ追加します。 のために`r = 3`、トリプルを3つ追加します。 合計: 4。出力: 4。

 ## 特殊なケース

 要素が 3 つ未満の配列の場合、`r-l`2 に達することはないので、答えは自動的に 0 になります。すべての要素が等しい配列の場合、セグメントは配列全体の長さまで拡大され、組み合わせカウントによってすべてのトリプルが含まれることが保証されます。 有効なトリプルを持たない配列の場合、ポインタ`l`無効な差分を防ぐために移動し、カウントがゼロになります。 各シナリオは、2 ポインタと組み合わせのアプローチによって自然に処理されます。
