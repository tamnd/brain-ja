 ## 解決策
 ## 問題の理解

 Polycarp にはお気に入りの整数列がありますが、それを直接見ることはできません。 代わりに、彼が実行した特別な執筆プロセスの結果が表示されます。 最初の要素をホワイトボードの左端に書き込み、2 番目の要素を右端に書き込み、次に使用可能な要素をできるだけ左、次に可能な限り右に交互に配置し、シーケンス全体が書き込まれるまでこのジグザグを続けます。 私たちのタスクは、最終的なホワイトボードの状態から元のシーケンスを再構築することです。 

入力により、テスト ケースの数、各テスト ケースのホワイトボード シーケンスとシーケンス自体の長さが得られます。 各テスト ケースに対して Polycarp のオリジナルのお気に入りシーケンスを出力する必要があります。 

とすれば$n$最大 300 個のテスト ケースを含めることができ、ソリューションは大まかに実行されます。$O(n)$テストケースごとに許容されます。 より高速なものを必要とするような制約はありません。$O(n^2)$アプローチが通る可能性がある理由$300^2 \cdot 300$操作数は 3,000 万件弱ですが、さらに改善できるはずです。 

エッジ ケースは、シーケンスに単一の要素がある場合、すべての要素が同一である場合、または最大または最小の要素が最後に現れる場合に発生します。 たとえば、ホワイトボードのシーケンスが次の場合、`[42]`、出力は単に次のようにする必要があります`[42]`。 すべての要素が等しい場合、たとえば`[1, 1, 1, 1]`、出力は同じシーケンスです。 厳密に増加または減少するパターンを想定した不用意な実装は、このような場合に失敗する可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、Polycarp の書き込みプロセスを逆にシミュレートしようとします。 元の配列を再構築するために、左右の挿入の可能なすべての組み合わせを試すこともできますが、それはすぐに不可能になります。$n$順列の階乗数によって増加します。 

重要な観察は、Polycarp が常にホワイトボードの端の 1 つに残りの最大の数字を書き込むことです。 つまり、ホワイトボード シーケンスの最初の要素は、元のシーケンスの最初の要素です。 その後、2 つのポインター (ホワイトボード シーケンスの先頭に 1 つと最後に 1 つ) を維持し、ジグザグ配置を再構築する順序でどちらかの端から要素を選択します。 使用されていない 2 つの極端な値のうち大きい方を繰り返し選択することで、1 回のパスで元のシーケンスを再構築できます。 

この観察により、問題は 2 つのポインタのトラバーサルに帰着します。ホワイトボード シーケンスから利用可能な 2 つの極値のうち大きい方を常に選択し、それを再構成されたシーケンスに追加し、考慮から除外します。 これが機能するのは、Polycarp が次に大きい未配置の数値を常に端に配置し、配置の順序が左から右に交互になるためですが、最大値による選択により正しい順序を貪欲に再構築できることが保証されます。

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化する`a`再構築されたお気に入りのシーケンスを保持します。 
2. 2 つのポインターを使用します。`l`ホワイトボードシーケンスの開始時`b`そして`r`最後に。 
3. 繰り返しながら`l <= r`:

 1. 比較する`b[l]`そして`b[r]`。 
2. 2 つのうち大きい方をシーケンスに追加します。`a`。 
3. もし`b[l]`大きかった、増分`l`。 それ以外の場合はデクリメント`r`。 
4. すべての要素が処理されたら、出力します。`a`再構成されたシーケンスとして。 

これが機能する理由は、ホワイトボード シーケンスに残っている最大の要素が、Polycarp がホワイトボードの両端に配置する次の要素に対応している必要があるためです。 利用可能な 2 つの極端な値のうちの最大値を常に選択することで、交互の配置順序が尊重され、元のシーケンスが正しく再構築されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        a = []
        l, r = 0, n - 1
        while l <= r:
            if b[l] > b[r]:
                a.append(b[l])
                l += 1
            else:
                a.append(b[r])
                r -= 1
        print(' '.join(map(str, a)))

if __name__ == "__main__":
    solve()
```このコードはテスト ケースの数を読み取り、各テスト ケースに対してホワイトボード シーケンスを読み取ります。 2 ポインターのアプローチにより、元のシーケンスを再構築するために常に正しい要素が選択されることが保証されます。 ポインターを慎重に処理して、off-by-one エラーを回避し、すべての要素が含まれていることを確認します。 印刷は各テスト ケースの最後に行われます。
