 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースには、数直線上の閉区間の集合があります。 このコレクションでは、できるだけ多くの間隔を維持したいと考えていますが、それは構造的な制約の下でのみです。 

間隔のサブセットは、そのサブセット内の 1 つおきの間隔と交差する間隔がサブセット内に少なくとも 1 つ存在する場合、有効であるとみなされます。 言い換えれば、選択したサブセット内で、少なくとも 1 つの点を共有するか、重複領域を完全にカバーすることによって、この間隔が他のすべての間隔と重複するように「代表的な」間隔を選択できなければなりません。 

タスクは、サブセットを直接構築することではなく、残りのセットがこの特性を満たすためにどれだけの間隔を削除する必要があるかを決定することです。 

制約は大きく、すべてのテスト ケースにわたる間隔の合計数は 200,000 に達する可能性があります。 これにより、すべてのペアをチェックしたり、すべての候補サブセットを明示的にテストしたりするなど、間隔にわたる二次解が即座に除外されます。 すべての解は、テスト ケースごとに線形または対数に近くなければなりません (通常は O(n log n))。 

単一の「外れ値」間隔により間隔が条件をほとんど満たさない場合、微妙なエッジ ケースが発生します。 

たとえば、間隔について考えてみましょう。```
[1, 2], [2, 3], [3, 5], [4, 5]
```他のすべての間隔と交差する間隔はありません。 チェーン内に重なりが存在する場合でも、両極端に接する単一の間隔は存在しません。 オーバーラップ チェーンで十分であると仮定する素朴な貪欲な戦略では、すべての間隔が誤って維持されてしまいます。 

もう 1 つの重要なエッジ ケースは、すべての間隔が 1 つの点で交差する場合です。```
[1, 10], [2, 3], [4, 5], [6, 7]
```ここでは、最初の間隔が他のすべての間隔と交差するため、答えは削除がゼロになります。 グローバルな「ハブ」間隔を追跡せずにペアごとのオーバーラップ密度のみをチェックする方法では、この構造が見逃される可能性があります。 

最も難しいのは、この条件が、1 つの間隔が普遍的な交差ハブとして機能する大きなサブセットを見つけて、そのようなサブセットのサイズを最大化することと同等であることを認識することです。 

## アプローチ

 ブルートフォース手法では、間隔のすべてのサブセットを試し、そのサブセット内の他のすべての間隔と交差する間隔が存在するかどうかを確認します。 候補となる「ハブ」間隔を修正したとしても、選択した他のすべての間隔との交差を検証する必要があります。 これにより、最悪の場合、サブセットがおよそ O(n²) になり、サブセットあたりのチェックが O(n) になり、これは実現可能な限界をはるかに超えています。 

代わりに、視点を反転することができます。 どの区間が最終セットでユニバーサル交差区間として機能するかを推測するとします。 その間隔が固定されている場合、他のすべての間隔はその間隔と交差する必要があります。 これにより、問題は、指定された間隔に重なる間隔の数を数えるということになります。 

固定間隔 [l, r] の場合、次の場合に限り、別の間隔 [L, R] がその間隔と交差します。```
L ≤ r and R ≥ l
```したがって、各間隔について、その間隔と交差する間隔の数を計算できます。 このカウントが最大になる間隔を選択すると、必要なハブとして機能するため、可能な限り最良の有効なセットが得られます。 

したがって、問題は次のようになります。各間隔について、重複する間隔の数を計算し、最大値を取得し、n から減算します。 

オーバーラップ数を効率的に計算するために、左側のエンドポイントで間隔を並べ替え、右側のエンドポイントで二分探索を使用します。 ソートされた配列とプレフィックス構造を使用すると、指定された r より前に開始する間隔の数を数え、l より前に終了する間隔を減算できます。 

これにより、すべてのペアのチェックから間隔ごとの対数クエリへの問題が軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての間隔を左側のエンドポイントでソートし、ソートされた右側のエンドポイントのリストを別途保持します。 

並べ替えにより、ペアごとの比較の代わりに二分検索を使用して重複をカウントできる構造が作成されます。 
2. 各区間 [l, r] について、左端点 ≤ r を持つ区間の数を計算します。 

これにより、右側で交差する可能性のある区間のスーパーセットの候補が得られます。 
3. これらの候補のうち、右端点が l 未満の区間を減算します。 

これらの間隔は完全に左側にあり、[l, r] と交差することはできません。 
4. 残りのカウントは、現在の間隔と交差する間隔の数です。 
5. すべての間隔にわたってそのような最大数を追跡します。 

この最大値は、単一の間隔を中心とする可能な最大の「良好な」サブセットを表します。 
6. n からこの最大値を引いた値を出力します。 

### なぜ効果があるのか

 有効なセットには、セット内の他のすべての間隔と交差する 1 つの間隔が存在する必要があります。 その間隔はセット自体に属している必要があります。 したがって、すべての有効なセットは、候補区間を選択し、それと交差するすべての区間を取得することに正確に対応します。 このようなユニバーサル交差区間のない集合は直ちに定義に違反するため、より大きな構造は不可能です。 したがって、すべての候補にわたる交差数を最大化すると、最適なサブセット サイズが得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        segs = []
        L = []
        R = []
        
        for _ in range(n):
            l, r = map(int, input().split())
            segs.append((l, r))
            L.append(l)
            R.append(r)
        
        L.sort()
        R.sort()
        
        def count_leq(arr, x):
            lo, hi = 0, n
            while lo < hi:
                mid = (lo + hi) // 2
                if arr[mid] <= x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo
        
        best = 0
        
        for l, r in segs:
            # intervals with L <= r
            left_part = count_leq(L, r)
            # intervals with R < l
            right_bad = count_leq(R, l - 1)
            overlap = left_part - right_bad
            if overlap > best:
                best = overlap
        
        print(n - best)

if __name__ == "__main__":
    solve()
```このソリューションでは、2 つの並べ替えられた配列 (左側のエンドポイント用と右側のエンドポイント用に 1 つ) を構築します。 間隔ごとに、右側の境界より前または右側の境界で開始する間隔がいくつあるかを計算し、左側の境界より厳密に手前で終了する間隔を削除します。 この差は、それと交差する間隔を正確にカウントします。 

二分探索機能`count_leq`オーバーヘッドを回避し、クエリごとに O(log n) を確保するために手動で実装されます。 各間隔は潜在的なハブとして扱われ、最大の重複が追跡されます。 

減算ステップでは次を使用します。`l - 1`厳密な不等号処理を通じて暗黙的に。 これにより、現在の間隔が始まる前に終了する間隔をカウントすることがなくなります。

 入力:```

```L = [1,2,3]、R = [3,4,6]を計算します。 

| 間隔 | 左_leq_r | 右_悪い | 重なる |

これは、すべての区間が共通の構造を介して交差する場合を裏付けます。

 最大重複は 2 であるため、答えは 2 つの削除です。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、すべての間隔が 1 つの点で交差する場合です。 例えば：```
[1, 10], [2, 3], [4, 5], [6, 7]
```このアルゴリズムは、各間隔を潜在的なハブとして評価します。 [1, 10] の場合、すべての区間が満たされます。`L ≤ 10`1 より前で終わるものはないため、オーバーラップは 4 となり、最大になります。 出力は欠失ゼロであり、予想される結果と一致します。 

もう 1 つのエッジ ケースは、グローバル交差を持たない厳密な連鎖です。```
[1,2], [2,3], [3,4], [4,5]
```各間隔は隣接する間隔とのみオーバーラップします。 最大オーバーラップ数は 2 であるため、アルゴリズムは 2 つの削除を返します。これは、有効なハブ構造を取得するには少なくとも 2 つの間隔を削除する必要があることを正しく示しています。 

最後のエッジケースは、次のような同一間隔です。```
[1,5], [1,5], [1,5]
```すべての間隔は他のすべての間隔と重複するため、各候補の重複は 3 となり、答えは 0 になります。
