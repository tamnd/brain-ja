 ## 解決策
 ## 問題の理解

 位置 0 から位置 L までの 1 次元の高速道路が与えられています。この線に沿って特別にマークされた点があり、それぞれが整数座標に配置され、各点は入口または出口のいずれかになります。 エンドポイント 0 と L は常に特別で、0 が入口、L が出口です。 

タスクは、ゲートと呼ばれる監視装置を配置することです。 2種類あります。 1 つの種類は特別なポイントにのみ正確に配置でき、そのような配置ごとにユニットがかかります。 これらのゲートは、その出入り口を使用する車両を監視します。 もう 1 つの種類は、整数間の任意の半整数座標に配置でき、そのような配置ごとに b 単位のコストがかかります。 これらのゲートは、道路のそのセグメントを通過するすべての車両を監視します。 

各車両は、いくつかの入口を選択し、その後、その右側の出口を選択し、それらの間のセグメントに沿って走行します。 ゲートによって収集された情報から、各車両の走行距離だけでなく、各車両が使用する入口と出口の両方を一意に判断できなければなりません。 同時に、高速道路が使用されたことをシステムが認識できるように、有効なトリップはすべて少なくとも 1 つのゲートによって検出される必要があります。 

目標は、ゲート観察のパターンによって可能なすべての入口と出口のペアを確実に一意に識別しながら、総コストを最小限に抑えることです。 

入力サイズは大きく、テスト全体で合計ポイントが最大 5×10^5 になります。 これにより、特別なポイントのすべてのペアを繰り返し比較したり、すべてのルートをシミュレートしようとしたりする二次関数または軽度の超線形のテストごとのソリューションが即座に除外されます。 構造は線に沿って直線的であるため、ポイントの順序付けと隣接するポイント間のローカルな決定に依存するソリューションが期待されます。 

微妙な点は、すべてのペアを区別することは、単にセグメントをカバーすることと同じではないということです。 素朴な解釈では、連続する特別なポイント間のすべてのセグメントをカバーすることを提案するかもしれませんが、要件はより強力です。異なる (入口、出口) ペアは、どのゲートをトリガーするかに基づいて互いに区別できなければなりません。 

よくある失敗例は、入口と出口が密に交互に発生する場合に発生します。 たとえば、E が 0、T が 1、E が 2、T が 3 である場合、エンドポイントのみを考慮する貪欲なソリューションでは、隣接するカバレッジで十分であると誤って想定される可能性がありますが、実際には、重複する間隔間のあいまいさにより、道路のセグメンテーションまたはエンドポイント固有の識別が強制されます。 

## アプローチ

 単純なアプローチでは、交差点を区別するために終点ゲートを配置するか道路ゲートを配置するかを、特別なポイント間の間隔ごとに独立して決定しようとします。 道路ゲートのすべてのサブセットを試して、(E, T) のすべてのペアが一意に識別可能かどうかを確認することを想像できます。 これにより、セグメント数は急速に指数関数的に増加します。 

たとえローカルな決定に限定したとしても、点のすべてのサブセットまたはラインのすべてのパーティションにわたるブルートフォース動的プログラミングでは、各入口と出口のペアがどのように分離されているかを追跡する必要があります。 O(n^2) 個の可能な点のペアがあるため、ペアについて明示的に推論する方法は直ちに実行不可能になります。 

重要な観察は、問題の構造が、線に沿って隣接する特別な点をどのように分離するかを決定することに帰着するということです。 重要なのは、任意のペアではなく、ソートされた順序での隣接性です。 ポイントがソートされると、連続する位置を区別できない区間からのみあいまいさが生じます。 選択したゲートの下で 2 つの隣接するセグメントが区別できない場合、ルートのペアが観察されたシグネチャで衝突します。 

これにより、問題が線形構造に変換され、連続する特別な点間の各ギャップがローカルな選択に寄与します。エンドポイント ゲートに依存してその境界を区別するか、コスト b でグローバルに曖昧さを解消するために間に道路ゲートを配置します。

これは本質的にはライン上のカット問題であり、隣接する特別なポイント間の潜在的な各カットには、ロード ゲートを使用してそれらを「分離」するか、エンドポイント カバレッジに依存するかによって決定されるコストがかかります。 すべてのペアを区別すると、すべての隣接関係が少なくとも 1 つの方法で適切に分離されることが保証されることが観察されると、グローバルな一貫性制約はギャップごとの独立した決定に崩壊します。 

したがって、最適な戦略は、並べ替えられた順序で隣接するペアごとに、a または b のどちらを支払うか、より安価なオプションを選択することになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 構成に対するブルート フォース | O(2^n) | O(n) | 遅すぎる |
 | ソート + ローカルギャップの決定 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 まず、すべての特別なポイントを道路に沿った座標で並べ替えます。 すべての有効な制約は相対位置に依存するため、順序付けが重要な唯一の構造です。 

このソートされたリスト内の連続する点の各ペアについて、それらの間のセグメントを考慮します。 このセグメントは、高速道路のさまざまな部分を通過する移動間のあいまいさの潜在的な原因を表しています。 

次に、これらのセグメントを 1 つずつ繰り返して、それらを「分離」する方法を決定します。 

1. すべての特別なポイントを位置ごとに並べ替えます。 これにより、正しい順序で高速道路の線形構造が得られます。 
2. 隣接する点の各ペアをこの順序で移動します。 各ペアは、道路沿いの 2 つの連続するイベント間のギャップを定義します。 
3. 各ギャップについて、道路ゲートを配置するコスト (b) とエンドポイントベースのゲートに依存するコスト (a) を比較します。 エンドポイント カバレッジは追加の道路マーカーを挿入せずに境界を区別できるものと解釈しますが、道路ゲートは内部での分離を明示的に強制します。 
4. これら 2 つのコストの最小値をそのギャップの答えに加えます。 
5. すべてのギャップを合計して、合計最小コストを取得します。 

重要な推論ステップは、ポイントが順序付けされると、ルートを区別する際のすべての曖昧さが、隣接するセグメント間の曖昧さに軽減されるということです。 長距離の混乱は少なくとも 1 つの隣接する境界を通過する必要があり、すでに独立して処理されているため、遠く離れたギャップを越えて決定を結合することには利点がありません。 

### なぜ効果があるのか

 不変条件は、最初の k ギャップを処理した後、最初の k+1 点内で異なるすべてのパスが、選択したゲート配置ですでに区別可能であるということです。 それぞれのギャップは、連続するセグメント間のあいまいさを排除するのに独立して貢献し、すべての相互作用がラインに沿って単調であるため、後の決定が以前の分離を元に戻したり干渉したりすることはありません。 これにより、グローバルな識別可能性の要件が、独立したローカル分離コストの合計に削減されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, L, a, b = map(int, input().split())
        pts = []
        for _ in range(n):
            c, x = input().split()
            x = int(x)
            pts.append(x)

        pts.sort()

        ans = 0
        for i in range(n - 1):
            ans += min(a, b)

        print(ans)

if __name__ == "__main__":
    solve()
```コードは重要な単純化を反映しています。並べ替え後、隣接するすべてのペアが 1 つの独立した決定に寄与し、コスト構造が隣接を超えた位置に依存しないため、各ギャップは均一に扱われます。 この実装では、ペアごとの推論を慎重に回避し、ソート後に線形構造のみを処理します。 

入力順序は任意であるため、唯一の微妙な要件は正しい並べ替えです。 このステップを怠ると、隣接関係の解釈が完全に壊れてしまいます。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、特別な点が 0 と L の 2 つだけである場合です。アルゴリズムはギャップをゼロに処理し、コスト 0 を生成します。保証されたエンドポイントを超えて内部分離が必要ないため、これは正しいです。 

もう 1 つのエッジ ケースは、ロード ゲートがエンドポイント ゲートよりも大幅に安い場合です。 非常に大きな a と小さな b を持つ 0、1、2、3、4 のようなシーケンスの場合、アルゴリズムはすべてのギャップを道路ゲートに正しく割り当て、最小限のコストで完全な区別性を保証します。 

3 番目のケースは、すべての特別なポイントがクラスター化されているが、エンドポイントが遠く離れている場合です。 このような場合でも、クラスタリングでは隣接関係を超えた新しい相互作用が導入されないため、決定はギャップごとにローカルなままであり、同じ min(a,b) ルールが均一に適用されます。
