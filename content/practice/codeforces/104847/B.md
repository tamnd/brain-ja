 ## 解決策
 ## 問題の理解

 私たちは確率論的な富のプロセスを観察しています。$n$人々。 誰もが正確に 1 単位のお金から始めます。 その後、さらに多くのユニット転送が発生します。 各送金は、現在の資産に比例する確率で受取人を選択することによって生成されるため、より裕福な人はさらに裕福になる可能性が高くなります。 すべての移転が完了したら、富を株式に正規化します$p_i = \frac{s_i}{\sum s_i}$, したがって、シェアの合計は 1 になります。 

最終状態は確率単体上のランダムな点ですが、任意の方法で均一ではなく、優先的な接続プロセスから得られます。 これは、初期重みが等しい古典的なポーリャの壺です。これは、最終的な正規化ベクトルが、すべてのパラメーターが 1 に等しい対称ディリクレ分布と同じ分布を持つことを意味します。 

私たちは完全な構成を観察していません。 その代わりに、私たちは全人類の中で最も小さな割合だけを教えられています。$p_{(1)} = a$。 この条件の下で、最大シェアの期待値を計算するように求められます。$p_{(n)}$。 

重要な問題は、対称ディリクレ分布の順序統計量を条件付けすると、実行可能領域の幾何学形状が非常に自明ではない方法で変化することです。 素朴なアプローチでは、プロセスをシミュレートするか、すべての構成を明示的に統合しようとしますが、状態空間は連続的で高次元であるため、これは中程度のレベルの人でもすぐに手に負えなくなります。$n$。 

制約$n \le 2000$サブセットの列挙やシンプレックスの離散化を伴うものはすべて除外します。 値$a \le \frac{1}{n}$実現可能性と一致しています: 最小シェアが$a$、それでは少なくとも$n a \le 1$株式の合計は 1 になるため、保持する必要があります。 

微妙な問題は、イベントの「最小値が正確に等しい」ということです。$a$” は、暗黙的に 1 つの座標が正確に一致することを意味します。$a$他のすべては厳密に大きくなります。 連続分布では、同点の確率はゼロであるため、この解釈は安全ですが、構造をどのように分解するかが重要です。 

## アプローチ

 ブルートフォースメンタルモデルは、シンプレックス上の考えられるすべての最終的な富ベクトルを考慮し、最小座標が等しいものをフィルタリングすることです。$a$を計算し、最大座標を平均します。 計算を無視しても、ジオメトリは複雑です。順序統計によって定義された境界制約を使用して、単体のスライス領域を積分しています。 直接統合には処理が必要になります$n$- 次元の区分的領域はどの座標が最小であるかによって決定されますが、これは組み合わせ的に乱雑になります。 

構造上のブレークスルーは、分布を対称ディリクレとして認識することによってもたらされます。$(1,1,\dots,1)$、これはシンプレックス全体で均一です。 最小値が正確であるという条件$a$1 つの座標を強制的に境界に配置し、その最小値によって寄与される固定質量を除去した後、残りの座標は低次元の一様単体のように動作します。 

これにより、次のような問題が軽減されます。$n$-次元順序統計に関する質問$(n-1)$-一様単体に対する次元の期待に加えて、$a$。 

残りの成分は、一様なディリクレ ベクトルの予想される最大座標の既知の閉じた形式です。

 ## アルゴリズムのチュートリアル

 1. 最終的な正規化された資産ベクトルは、パラメーターがすべて 1 に等しい対称ディリクレ分布に従っていることを認識します。これは、ベクトルが確率単体上に均一に分布していることを意味します。 
2. イベントを「最小シェアが等しい」と解釈します。$a$” に等しい座標がちょうど 1 つ存在するものとして$a$、他のすべては厳密に大きくなります。 分布は連続的であるため、確率 0 で同点が発生するため、これは正当化されます。 
3. すべての座標から最小寄与分を減算します。 させて$p_i = a + x_i$。 ミニマルなコーディネートとしては、$x = 0$、他のすべては満足しますが、$x_i > 0$。 
4. 合計制約を変換します。 以来$\sum p_i = 1$、私たちは得ます$\sum x_i = 1 - n a$。 これにより、問題は総質量の単体に還元されます。$1 - n a$以上$n$変数の 1 つはゼロに固定されます。 
5. ゼロ座標を削除し、残りの座標に焦点を当てます。$n-1$正の変数。 による正規化後$1 - n a$、残りのベクトルは再び次元の単体に一様に分散されます。$n-1$。 
6. 最大シェアを表現します。 元の最大シェアは$a + \max(x_i)$、そしてそれ以来$x_i = (1 - n a) y_i$、 どこ$y$上で均一です$(n-1)$-シンプレックス、わかります$$p_{(n)} = a + (1 - n a)\cdot \max(y).$$7. 期待を線形に受け止めます。$$\mathbb{E}[p_{(n)} \mid p_{(1)} = a] = a + (1 - n a)\,\mathbb{E}[\max(y)].$$8. 次元の一様なディリクレ ベクトルの期待最大値として既知の閉じた形式を使用します。$k$:$$\mathbb{E}[\max] = \frac{H_k}{k},$$どこ$H_k$は高調波数です。 ここ$k = n-1$。 

### なぜ効果があるのか

 重要な不変条件は、対称ディリクレ分布の境界順序統計量で条件付けすると、固定座標を削除して繰り込みした後、縮小単体での均一性が維持されるということです。 ディリクレ分布は交換可能であり、このタイプの限界条件下で安定しているため、線形スケーリングを超える残りの座標の歪みが防止されます。 これにより、期待値を決定論的なシフトとスケーリングされた既知の期待値にきれいに組み込むことができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, a = input().split()
    n = int(n)
    a = float(a)

    if n == 1:
        print(1.0)
        return

    k = n - 1

    # harmonic number H_k
    H = 0.0
    for i in range(1, k + 1):
        H += 1.0 / i

    expected_max_simplex = H / k

    ans = a + (1.0 - n * a) * expected_max_simplex
    print(f"{ans:.12f}")

if __name__ == "__main__":
    solve()
```実装では、派生した分解が直接適用されます。 唯一の重要な計算は高調波数であり、次の線形時間で計算されます。$n$、これは十分に高速です$n \le 2000$。 最後の式は、決定論的な寄与を最小値および残りの単体のスケーリングされた期待値から慎重に分離します。 

よくある落とし穴は、スケール係数を忘れることです$1 - n a$。 これがないと、結果は最小座標を固定した後の減少した単体体積ではなく、残りの質量が 1 であると誤って仮定します。

 ## 特殊なケース

 いつ$a = \frac{1}{n}$、すべての質量はすでに最小制約レベルに集中しています。 この場合$1 - n a = 0$、したがって、残りの単体は消滅し、すべての座標は等しくなければなりません$a$。 スケーリング項により予想される最大寄与がキャンセルされるため、アルゴリズムはこれをきれいに処理します。 

いつ$a$は非常に小さいため、単体は完全なディリクレ分布とほとんど変わりません。 結果は、次元の一様単体の無条件に期待される最大値に近づきます。$n$、つまり$\frac{H_n}{n}$。 この方式では、式は滑らかに減少します。$1 - n a \approx 1$。 

いつ$n = 2$、「残りの単体」の次元は 1 で、最大値は決定的に 1 です。調和式は次のように正しく評価されます。$H_1/1 = 1$したがって、式は次のように折りたたまれます。$1 - a$、2 つの相補的なシェアの形状に一致します。
