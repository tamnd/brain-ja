 ## 問題の理解

 長さのすべてのバイナリ文字列を徹底的にテストする 2 つの方法を比較しています。$n$。 がある$2^n$考えられる秘密。 古典的なマシンは、1 件につき 1 つの候補者を正確にテストします。$a$秒なので、合計時間は次のようになります。$a \cdot 2^n$。 

量子マシンは異なる動作をします。 と$q$量子ビットまで処理可能$2^q$候補文字列を 1 つのバッチにまとめ、各バッチにかかる時間$b$秒。 あるので$2^n$候補の合計、量子マシンのニーズ$2^{n-q}$バッチなので、合計時間は$b \cdot 2^{n-q}$。 

タスクは、最小の非負の整数を見つけることです。$q$量子時間が古典時間よりも厳密に小さいか、そのような時間は存在しないと判断する$q$存在します。 

入力サイズは最大です$10^{18}$なので、次のようなべき乗を直接計算します。$2^n$不可能です。 どのような解決策でも、指数値を明示的に構築することを避け、代わりに不等式の代数的操作に依存する必要があります。 

重要なエッジケースは、量子マシンが、$q$。 たとえば、次の場合$a \le b$場合、無限バッチ処理の利点があっても、各バッチは従来の単一テストよりも安くないため、量子側は競争力がありません。 

もう一つの微妙なケースは次のような場合です。$n$小さいし、$a$大きいです。 たとえば、次の場合$n = 1, a = 100, b = 1$、それから小さなことでも$q$量子はすぐに優れたものになります。 不等式を正しく解かずに単調な動作を想定する単純なアプローチは、過大評価する可能性があります。$q$。 

## アプローチ

 直接シミュレーションでは、すべてのことを試します。$q$、古典的なランタイムと量子ランタイムを計算し、比較します。 古典的な時間は与えられた時間に固定されています$n, a$ただし、クォンタム時間はサイズのバッチの数によって異なります。$2^q$が必要です。 文字列のシミュレーションを避けたとしても、依然として次のような指数関数的な量に直面します。$2^n$、ブルートフォースが実行不可能になります。 

量子ランタイムは次のように指数関数的に減少するため、総当たり推論は原理的に機能します。$q$が増加します。 ただし、それぞれ確認してみると、$q$を含む式を評価する必要があります$2^n$、次の場合には表現できません。$n$大きいです。 これにより、実行時間が問題になる前にアプローチが破綻してしまいます。 

重要な観察は、両方のランタイムが閉じた指数形式で記述できることです。$$T_{\text{classical}} = a \cdot 2^n$$

$$T_{\text{quantum}} = b \cdot 2^{n-q}$$それらを比較します。$$b \cdot 2^{n-q} < a \cdot 2^n$$キャンセル$2^n$:$$b \cdot 2^{-q} < a$$並べ替え:$$\frac{b}{2^q} < a \quad \Rightarrow \quad b < a \cdot 2^q$$ここで問題は最小のものを見つけることになります$q$次のような:$$2^q > \frac{b}{a}$$もし$a \ge b$、その後は偶数$q = 0$満足する$b < a$したがって、量子はゼロ量子ビットですでに高速です。 

それ以外の場合は、最小の整数を計算します$q$そのような$2^q > b/a$、これは以下と同等です$q = \lfloor \log_2(b/a) \rfloor + 1$。 整数と大きな値のみを扱うため、2 倍化またはビット長ロジックを繰り返すことによってこれを計算します。

 ## アルゴリズムのチュートリアル

 条件を以下の比較に変換します。$a$、$b$、2の累乗。 

1. 比較する$a$そして$b$。 もし$a \ge b$、その後、$q = 0$、quantum はすべての文字列を処理するため、すでに厳密に優れています。$b$秒対$a$古典的には文字列ごとに秒数がかかるため、合計の比較がすぐに有利になります。 0を出力します。 
2. それ以外の場合は、増やす必要があります$q$バッチ処理の利点がバッチごとの時間の遅さを補うまで$b$。 最小のものを探します$q$そのような$a \cdot 2^q > b$。 
3. から始める$q = 0$そして値$2^q = 1$。 不等式が成立するまで2倍を繰り返します。 各倍増は増加に対応します$q$1までに。 
4. 停止するタイミング$a \cdot 2^q > b$。 現在$q$増加したため最小限です$q$ゼロから単調に。 

### なぜ効果があるのか

 この不等式により、元の指数比較が単調関数に縮小されます。$q$。 左側$a \cdot 2^q$厳密に次のように増加します$q$増加するため、最初に超える固有のしきい値が存在します。$b$。 ゼロから開始して増加させることで、そのしきい値に 1 回だけ到達することが保証され、最初の成功で停止することで最小性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, a, b = map(int, input().split())

# Compare directly first condition
if a >= b:
    print(0)
    sys.exit()

q = 0
power = 1  # represents 2^q

while a * power <= b:
    power *= 2
    q += 1

print(q)
```最初のブランチは、量子ビットを必要とせずに量子が直ちに競合するケースを処理します。 2 番目の部分では、次の明示的な表現が維持されます。$2^q$2 倍化を繰り返し使用し、大きなべき乗や対数を避けます。 

ループ条件は不等式を直接強制します。$a \cdot 2^q \le b$、それでは最初の$q$それが壊れる、それがまさに答えです。 各ステップで 2 による乗算を使用すると、べき乗の式によるオーバーフローの懸念が回避され、すべてが整数演算に保たれます。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n, a, b = map(int, input().split())
