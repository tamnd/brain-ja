 ## 解決策
 ## 問題の理解

 いくつかの独立したテスト ケースが与えられています。 各テスト ケースには、要素の「重さ」または「高さ」を表す整数値のコレクションと、しきい値が存在します。$k$。 

このコレクションから、要素のサブセットを破棄することができます。 その後、残りの要素を自由に並べ替えることができます。 目標は、最終シーケンス内の連続する要素の各ペアの差異が最大で異なるように、選択したサブセットを配置することです。$k$。 

課題は、そのような配置を可能にするために削除する要素の数を最小限に抑えることです。 

この要件を言い換えると、保持されている要素を並べ替えた後、連続する値の間で大きな「ジャンプ」が発生しないように順序付けできるようにする必要があると言い換えることができます。 任意に並べ替えることが許可されているため、実際に構築しようとしている構造は、各ステップが最大で移動するチェーンです。$k$ただし、ソートされた隣接関係の使用は強制されません。 必要なのは、何らかの順序付けの存在だけです。 

入力サイズの制約は合計で大きく、最大で$2 \cdot 10^5$すべてのテスト ケースにわたる要素。 これにより、すべてのサブセットまたはすべてのペアごとの遷移をチェックするなどの二次戦略は直ちに除外されます。 平$O(n \log n)$テスト ケースごとは、合計が全体的に線形対数のままである場合にのみ許容されます。これにより、組み合わせ選択ではなく並べ替えと貪欲なスキャンが行われます。 

微妙なエッジケースは、重複や値の間隔が広い場合に発生します。 すべての数値が同一の場合、どのサブセットも機能するため、答えは削除ゼロになります。 値が極端に分散している場合、$k$が小さい場合、有効なチェーン内で 2 つの要素が隣接することはできないため、多くの場合、できるのは 1 つの要素だけです。 

別の自明ではないケースは、値が、よりわずかに大きいギャップによって分離された複数の密なクラスターを形成する場合に発生します。$k$。 たとえば、$[1, 2, 3, 10, 11, 12]$と$k = 2$、両方のクラスターを完全に取得できますが、混合することはできません。 ソートされた順序で単一の連続セグメントを選択する必要があると想定する素朴なアプローチでは、構造が必ずしも 1 つの間隔ではなく、潜在的に複数の互換性のあるブロックであるため、誤って多すぎる要素が破棄されます。 

## アプローチ

 ブルートフォースソリューションでは、要素のすべてのサブセットを考慮し、各サブセットについて、隣接する差分が範囲内に収まるように順序付けできるかどうかを判断します。$k$。 枝刈りを行ったとしても、これは本質的に探索します$2^n$各サブセットを検証するには、少なくともソートまたは隣接関係の実現可能性をチェックする必要があり、次のような結果になります。$O(2^n \cdot n \log n)$。 これはたとえ$n = 30$、ましてや$2 \cdot 10^5$。 

重要な簡素化は、配列をソートすることで実現します。 要素がソートされると、「任意に並べ替えることができる」という制約は、順列に関するものではなく、ソートされた順序で連続して選択された値がそれほど離れていないサブシーケンスを選択することに関するものになります。 その理由は、選択した 2 つの要素がそれ以上異なる場合であるためです。$k$その場合、どのように並べ替えても、間に大きなギャップを導入しない限り、それらを有効なチェーン内で隣接させることはできません。 それらを橋渡しできる中間要素は、その中に存在する必要があります。$k$、同じソートされた領域から取得する必要があります。 

これにより、問題は、最大でサイズのステップで接続できる最大のサブセットを特定することになります。$k$ソートされた配列に沿って歩いているとき。 言い換えれば、ソートされた順序で連続して選択された要素が最大で異なる最大のチェーンが必要です。$k$, ただし、接続を維持している限り、要素をスキップすることができます。 

これをより正確に見る方法は、ソートされた配列をインデックス間のエッジを定義するものと考えることです。$i < j$もし$a[j] - a[i] \le k$。 これらのエッジを使用してパスに配置できる最大の頂点セットが必要です。 エッジは値空間内の順序を尊重するため、最適な構造は最も長い「間隔で接続された」コンポーネントを取得することになります。これはスライディング ウィンドウを使用して見つけることができます。 

並べ替えると、最適なサブセットはウィンドウでカバーできる最大の要素グループに対応します。ここで、最大値から最小値を引いた値は、最大でも以下の連鎖可能な構造になります。$k$。 貪欲な洞察とは、開始点を固定すれば、次の各ステップがその範囲内にあることを維持しながら、可能な限り拡張するということです。$k$これは、ソートされた順序で、有効な領域内をスキップしても何も得られないことを意味します。 

したがって、この問題は、ソートされた順序で走査し、連続して選択された要素を常に距離内に保つことができる最大のサブセットを見つけることと同等になります。$k$。 これは古典的な 2 ポインター展開です。

 ## アルゴリズムのチュートリアル

 1. 配列を降順でない順に並べ替えます。 任意の順列ではなく局所的な差異を使用して有効な隣接構造を推論できるようにするには、ソートが必要です。 
2. 2 ポインタ ウィンドウを使用します。左ポインタは候補セグメントの開始をマークし、右ポインタは前方に展開します。 
3. 左ポインタの位置ごとに、各ステップが有効なチェーンの一部であることを維持しながら、右ポインタをできるだけ遠くに移動します。 具体的には、選択したサブセット内の連続する要素の差異が最大で許容されることを確認します。$k$、ソートされた形式では、ブレークが表示されるまで継続的に展開できます。 
4. そのような有効なウィンドウの最大サイズを追跡します。 これは、削除せずに保持できる要素の最大数を表します。 
5. テスト ケースの答えは、要素の総数からこの達成可能な最大サイズを引いたものになります。 

これで十分な理由は、最良のウィンドウの外にあるすべての要素は、最適な配置では事実上「使用不可能」であるためです。$k$- ある隣接関係における差分制約。 

### なぜ効果があるのか

 重要な不変条件は、任意の候補ウィンドウ内で、ウィンドウの外側の要素を必要とせずに、すべての要素を有効なシーケンスに接続できることです。 配列はソートされているため、次の値を超えるギャップが発生するたびに、$k$、そのギャップはハード分離として機能します。左側の要素は、最大ウィンドウ内にすでに含まれている中間値を経由せずにギャップを越えて要素に直接接続することはできません。 したがって、各最大ウィンドウは、値の間に最大の距離でエッジが存在する、暗黙のグラフ内の独立した連結成分を定義します。$k$、最適な解決策は、最大のコンポーネントを保持することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        a = list(map(int, input().split()))
        
        a.sort()
        
        l = 0
        best = 1
        
        for r in range(n):
            while l < r and a[r] - a[l] > k:
                l += 1
            best = max(best, r - l + 1)
        
        print(n - best)

if __name__ == "__main__":
    solve()
```ソートのステップは、問題をグローバルな置換問題からローカルな隣接制約問題に変換するものです。 2 ポインター ループは、すべての要素が相互互換性を保つスライディング ウィンドウを維持します。$k$-ギャップルール。 

条件`a[r] - a[l] > k`セグメントの有効性が強制される唯一の場所です。 配列はソートされているため、特定の条件でこの条件が失敗すると、`l`、増加しています`r`動かないと修正できない`l`これは、左ポインタの貪欲な前進を正当化します。 

最後の引き算`n - best`「最大の有効なサブセットを維持する」定式化を、必要な「最小要素を削除する」出力に変換します。

 ## 特殊なケース

 すべての要素が同一の場合、すべての差がゼロになるため、ソートされたウィンドウが壊れることはありません。 アルゴリズムはウィンドウをフル サイズまで拡大し続けます。その結果、除去はゼロになります。これは、任意の順序付けが有効であるという事実と一致します。 

配列が厳密に増加しているが、ステップ サイズが常に超過している場合$k$、各要素は独自の独立したコンポーネントを形成します。 スライディング ウィンドウはサイズ 1 を超えて大きくなることはありません。`best = 1`そして答えは次のようになります$n-1$これは、単一の要素のみを保持できることを反映しています。 

より大きなギャップによって分離された 2 つの密なクラスターがある場合$k$、アルゴリズムはそれらを自然に別々のウィンドウに分割します。 各クラスターは独立して評価され、最大のクラスターのみが評価に寄与します。`best`これは、クラスタ間の隣接関係が不可能であるという事実と一致します。
