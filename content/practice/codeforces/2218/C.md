 ## 解決策
 ## 問題の理解

 タスクは長さの順列を構築することです$3n$どこに分割するか$n$それぞれ 3 つの要素からなる連続したブロックを作成し、各ブロックの中央値を取得します。 私たちの目標は、これらの中央値の合計を最大化することです。 ここでの順列とは、次のすべての整数を含むシーケンスを意味します。$1$に$3n$まさに一度。 

数値を与える$n$、順列には長さが必要です$3n$。 3 つの要素からなる各ブロックは、ブロックを並べ替えた後、中央の要素として中央値を持ちます。 中央値の合計をできるだけ大きくしたいため、最大の数値を中央値として戦略的に配置する必要があります。 中央値に影響を与えることなく、合計への寄与が少ない場所に小さい数値を配置できます。 

制約は高いです:$n$まで可能です$10^5$、およびすべての合計$3n$テストケース全体で次を超えない$3 \cdot 10^5$。 これにより、線形または線形に近いアルゴリズムに制限されます。 どれでも$O(n^2)$解決策は不可能です。 すべての順列を試すという単純なアプローチはまったく問題外です。 

考慮すべきエッジケースには以下が含まれます$n = 1$、ここでの順列は 3 つの数値のみであり、解は自明です。$n$非常に大きいため、数値の配置を誤ると中央値の合計が大幅に減少する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての順列を生成することです。$[1, 2, ..., 3n]$そして、それぞれの中央値の合計を計算します。 これは原理的には正しいですが、順列の階乗増加により、たとえ小さな値であっても不可能になります。$n$。 のために$n=10$、 がある$30!$順列は天文学的に大きい。 

最適解に対する重要な洞察は、3 要素ブロックの中央値が中央の数であるという観察から得られます。 中央値の合計を最大化したい場合は、各中央値をできるだけ大きくする必要があります。 したがって、すべての数値を次から並べ替えることができます。$1$に$3n$そして、最大の数値が各ブロックの中央位置を占めるようにそれらを割り当てます。 これにより、すべての順列を調査する必要がなく、中央値の合計が最大化されます。 

具体的には、ソートされた配列を視覚化すると、$3n$数値が大きい場合、中央値は 3 つのブロックのうち 2 番目に大きいブロックから最小のものまで選択する必要があります。 数値を逆の順序で貪欲に配置すると、中央値が必要以上に小さくならないようになります。 次に、各ブロック内の残りの 2 つの要素をより小さい数字で埋めることができます。 それらの配置は中央値の合計には影響しないため、どのような順序でも機能します。

 | --- | --- | --- | --- |
 | ブルートフォース | O((3n)!) | O(3n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取り、$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$。 コンピューティング$3n$順列の長さとして。 
3. 以下から数値のリストを作成します。$1$に$3n$。 
4. 中央値を最大化するには、逆方向に反復して、ブロックの中央値として最大の数値を配置します。 最大のものをスキップして開始します$n$これらはブロックの中央位置を占めるためです。 次に大きい数値を中央の位置に配置します。 
5. 残りの位置に利用可能な最小の数字を入力します。 これらの数値は中央値の合計には影響しないため、順序は重要ではありません。 
6. 順列を出力します。 

機能する理由: 不変条件は、各ブロックの中央値が残りの最大値から選択されることです。 中央値は各ブロック内の 3 つのうちの 2 番目に大きいため、降順で割り当てると、各中央値が局所的に最大化され、全体的な合計が最大化されます。 残りの数値はブロック内の最初または 3 番目の位置のみを占め、中央値の合計は減りません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    perm = [0] * (3 * n)
    # fill numbers 1..3n
    numbers = list(range(1, 3*n + 1))
    
    left = 0
    right = 3*n - 1
    res = []
    # pick the largest n numbers as medians
    # strategy: always pick from the middle of remaining numbers
    # middle index for next median
    idx = 3*n - 2
    for _ in range(n):
        res.append(numbers[idx])
        idx -= 2
    # remaining numbers
    remaining = set(numbers) - set(res)
    res_full = []
    r = list(remaining)
    j = 0
    for val in res:
        res_full.append(r[j])
        j += 1
        res_full.append(val)
        res_full.append(r[j])
        j += 1
    print(*res_full)
```このソリューションでは、まず、ソートされた配列の上半分から数値を選択することで、どの数値が中央値になるかを決定します。 次に、これらの中央値の周囲の残りの数値を埋めて、各ブロックに意図した中央値を持つ 3 つの要素が含まれるようにします。 インデックス作成では、重複することなく番号を正しく選択するように注意が払われます。

 ## 特殊なケース

 のために$n=1$、順列は 3 つの要素のみです。 アルゴリズムは中央の数値を中央値として選択し、残りの 2 つの数値をその周りに配置します。 入力`1`与える`[1,2,3]`、中央値の合計 = 2。 

連続大用$n$、例えば、$n=5$、アルゴリズムは上半分から中央値を正しく選択します。`[9,7,5,3,1]`周囲の数字を埋めて、衝突のない最大の合計を保証します。 選択戦略により、2 つの中央値が競合しないことが保証され、すべての数値が 1 回だけ使用されます。
