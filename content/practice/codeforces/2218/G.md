 ## 解決策
 ## 問題の理解

 私たちは次のラインを持っています`n`社会的ぎこちなさのレベルが未知の人々`a_i`。 座るプロセスは個別です。最初は、次のような症状を持つ人々が座ります。`a_i = 0`時間通りに座る`0`。 他の人は時間に合わせて座ります`t`少なくとも`a_i`人々はすでに時間前に厳密に座っています`t`そして少なくとも隣の人の一人はすでに座っています。 配列`b`は、各人がいつ座ったかを正確に教えてくれます。 私たちのタスクは配列の数を数える事です`a`このシーケンスを生成できた可能性があります。 

入力は最大 10,000 のテスト ケースで構成され、それぞれのテスト ケースは`n`200,000まで。 合計から`n`すべてのテスト ケースは 200,000 で制限されており、どのソリューションもほぼ線形である必要があります。`n`テストケースごとに。 すべての人々のペアを比較する二次検査は非常に遅すぎます。 

微妙なのは、人が座っている時間は、以前に座っていた人の数と隣接関係の両方に依存するということです。 エッジケースには、列の最後尾にいる人や、同時に連続して座っている人が含まれます。 単純な実装ではこれらの条件を見落とし、不可能な数が生成される可能性があります。`a_i`。 たとえば、隣り合う二人が同時に座ると、`0`、隣接するものの存在が他のものを制約することはできず、これを考慮に入れないと、考えられる配列のカウントを誤る可能性があります。 

## アプローチ

 ブルートフォース手法では、可能な限りすべての処理が繰り返されます。`a_i`各人に合わせた価値観を設定し、与えられたルールに照らして座り方のルールを検証します。`b`。 以来`a_i`と同じくらいの高さになる可能性があります`n-1`、これは O(n²) であり、遅すぎます。 

重要な洞察は、座るプロセスを逆転させることです。 の時代`b`各人の前に何人が座ったはずかを正確に教えてください。 時間に座っている人にとって`t > 0`、 彼らの`a_i`前に座っていた人の数と、隣からの制約を差し引いた前に座っていた人の総数の間の任意の値を指定できます。 より正式には、人が時間通りに座っている場合、`t`、 彼らの`a_i`少なくとも以前に座っていた人の数でなければなりません`t`、最大でその数に隣接する位置によって許可される可能なバリエーションの数を加えたものになります。 

有効な数を計算できます。`a_i`毎回独立して`t`すでに座っている人の数を維持することによって。 そして、一人ひとりの可能性の数を掛け合わせていきます。 これにより、テスト ケースあたりの解は O(n) に減りますが、制約を考慮すると許容範囲内です。

 ## アルゴリズムのチュートリアル

 1. セットのリストを初期化する`time_to_indices`毎回マッピングする`t`そこに座っている人々のインデックスに`t`。 これにより、座った時間の順に繰り返すことができます。 
2. 配列を作成する`sat_count`各時間単位の前にすでに何人の人が座っていたかを追跡します。 累計を初期化する`total_sit = 0`。 
3. 時間をかけて反復する`t = 0`に`m-1`。 毎回:

 1. しましょう`indices`時間に座っている人々になる`t`。 
2. ひとりひとりに`i`で`indices`、以前に何人の隣人が座っていたかを確認します`t`。 以前に隣の人が座っていなかった場合`t`そして`t > 0`、この構成は不可能です。 
3. 有効枚数`a_i`なぜなら、この人は座ることができたかもしれない隣人の数に、可能な範囲を乗じたものに等しいからです。`a_i`以前のシッターによって制限された値。 
4. これらすべてのカウントをモジュロ 676767677 で乗算します。 
5.アップデート`total_sit`一度に座った人の数を加算することで`t`。 
4. 最終積のモジュロ 676767677 を返します。 

**効果がある理由**: 人それぞれ`a_i`は前に座った人の数によって制限され、隣接性の制約により、隣の人なしでは座ることができません。 時間の増加順に処理し、可能性を個別に乗算することにより、構成を二重にカウントしたり欠落したりすることなく、すべての有効な配列を考慮します。 不変条件とは、`total_sit`時間を処理するときに、以前のすべての参加者を正しく表します`t`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 676767677

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        b = list(map(int, input().split()))
        
        time_to_indices = [[] for _ in range(m)]
        for idx, val in enumerate(b):
            time_to_indices[val].append(idx)
        
        result = 1
        total_sit = 0
        sat = [False] * n
        
        for t_unit in range(m):
            indices = time_to_indices[t_unit]
            if not indices:
                continue
            count_valid = 0
            for i in indices:
                neighbor_sit = 0
                if i > 0 and sat[i - 1]:
                    neighbor_sit += 1
                if i < n - 1 and sat[i + 1]:
                    neighbor_sit += 1
                if t_unit > 0 and neighbor_sit == 0:
                    result = 0
                    break
                options = total_sit if t_unit > 0 else 1
                count_valid += options
            result = (result * count_valid) % MOD
            for i in indices:
                sat[i] = True
            total_sit += len(indices)
        print(result)

if __name__ == "__main__":
    solve()
```このコードは入力を読み取り、座っている時間ごとに人々をグループ化し、すでに座っている人を追跡します。 時間単位ごとに、有効な選択肢の数をカウントします。`a_i`前のシッターと隣人に基づいて、これらのカウントを指定された素数を法として乗算します。 境界チェックはエッジ インデックスを正しく処理します。
