 ## 解決策
 ## 問題の理解

 この問題では、家をノード、インターネット ケーブルをエッジとした接続グラフとして表現された村が与えられます。 各エッジにはレイテンシがあり、ケーブルに沿ったデータ送信の遅延を表します。 一部の住宅にはインターネット アクセスが必要ですが、サーバーを設置できるのはせいぜい以下の場所です。`k`家、どこ`k`からの範囲が可能です`1`に`n`。 サーバーを配置すると、インターネットのある家はグラフ内のパスに沿ってサーバーに接続でき、その家が経験する遅延は、そのパスに沿ったエッジの中で最大の遅延になります。 

タスクは、考えられるサーバーの数ごとに決定することです。`k = 1..n`、インターネットを必要とするすべての住宅を合計した、達成可能な最小合計遅延。 各クエリには、最適なサーバーの配置と、サーバーからインターネットに必要な住宅までの最適なパスの計算が含まれます。 出力は、それぞれの最小合計のリストです。`k`。 

制約は、グラフが小さいことを示します: 最大 400 個のノードと 400 個のエッジ。 これにより、以下で実行されるアルゴリズムを使用できるようになります。`O(n^3)`すべてのペアの最短経路を計算するための Floyd-Warshall などの時間。`400^3 = 64,000,000`操作は 2 秒の制限時間内で受け付けられます。 

明らかではないエッジ ケースは、インターネットを必要とするすべての住宅が既に 1 つのノードに隣接しているため、1 つのサーバーを配置することで遅延を追加することなく完全に満足できる場合です。 もう 1 つの微妙なケースは、グラフにボトルネックを形成するレイテンシの高いエッジがある場合に発生します。 サーバーを単純に貪欲に配置すると、パスに沿った最大エッジ メトリックを無視した場合、真の最小合計レイテンシが過小評価される可能性があります。 

## アプローチ

 ブルートフォースアプローチは、次のすべての組み合わせを列挙することです。`k`サーバーを配置するためのハウスを作成し、組み合わせごとに、サーバーから必要なすべてのハウスまでのパスに沿った最大レイテンシを計算します。 これは正しいですが、組み合わせの数が次のとおりであるため、実行できません。`C(n, k)`中程度の場合はすぐに爆発します`n`そして`k`。 

重要な洞察は、最短パス (または最小の最大エッジ パス) の計算をサーバーの選択から分離することです。 メトリクスはパスに沿った最大エッジ レイテンシーであるため、パス コストが合計ではなくパスに沿った最大の重みとして定義される修正フロイド-ウォーシャル アルゴリズムを使用して、ハウスのペアごとに可能な最小の最大エッジを事前計算できます。 すべてのペア間の最小の最大エッジ パスの行列を取得したら、動的プログラミングを使用して、最大エッジ パスを選択できます。`k`サーバーの位置。 簡単バージョンの場合は、`k`と同じ大きさにすることができます`n`したがって、サーバーを追加しても総遅延が増加することはないため、インターネットを必要とする各家にサーバーを段階的に貪欲に配置することを単純に検討できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^k * n * m) | O(n^2) | 遅すぎる |
 | 最適 (最大エッジのフロイド-ウォーシャル + 貪欲な DP) | O(n^3 + n*p) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. を初期化します。`n x n`マトリックス`max_edge[i][j]`からの任意のパスに沿って可能な最小の最大エッジを保存します。`i`に`j`。 埋める`max_edge[i][j]`直接エッジの重みを使用する場合`i`そして`j`接続されている場合、それ以外の場合は無限大です。 
2. 最大エッジ メトリックに適合した Floyd-Warshall アルゴリズムを適用します。 各中間ノードについて`k`、 アップデート`max_edge[i][j] = min(max_edge[i][j], max(max_edge[i][k], max_edge[k][j]))`。 これにより、どのペアでも`(i, j)`、`max_edge[i][j]`には、それらを接続するパスに沿った最小最大のエッジが含まれます。 
3. 必要なハウスごとに、他のすべてのノードへの最小遅延のリストを作成します。`max_edge`マトリックス。 住宅のレイテンシー`s`のサーバーに`v`は`max_edge[s][v]`。 
4. 反復する`k`から`1`に`n`。 それぞれについて`k`、選択します`k`遅延の合計を最小限に抑えるサーバーの場所。 簡単バージョンでは、`k`と同じ大きさにすることができます`n`、すべての家にサーバーを順番に配置することを貪欲に検討できます。これにより、それぞれの合計レイテンシーが最小になります。`k`。 
5. それぞれの合計レイテンシを出力します。`k`。 

機能する理由: Floyd-Warshall ステップにより、インターネットを必要とするあらゆる家と候補サーバーについて、あらゆるパスに沿った最小最大遅延がわかることが保証されます。 すべてのハウスを潜在的なサーバーとして評価し、最小の遅延を累積することによって、すべてのパスとすべてのノードを考慮するため、他の組み合わせでは改善できない合計値が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, p = map(int, input().split())
        s = list(map(lambda x: int(x)-1, input().split()))
        INF = 10**18
        max_edge = [[INF]*n for _ in range(n)]
        for i in range(n):
            max_edge[i][i] = 0
        for _ in range(m):
            u, v, w = map(int, input().split())
            u -= 1
            v -= 1
            max_edge[u][v] = w
            max_edge[v][u] = w

        # Floyd-Warshall for minimal max-edge paths
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    max_edge[i][j] = min(max_edge[i][j], max(max_edge[i][k], max_edge[k][j]))

        # Compute minimal total latency for each number of servers
        latencies = [INF]*n
        # Start with no servers: all latency to nearest server
        # Greedy: start with server at each house one by one
        best_latency = [INF]*n
        # Initially, zero servers placed
        min_latency_per_house = [INF]*p

        result = []
        # Place servers one by one
        for k in range(1, n+1):
            # Choose the next best server to minimize sum
            best_improvement = -1
            best_house = -1
            for v in range(n):
                # compute improvement if placing server at v
                improvement = 0
                for idx, house in enumerate(s):
                    improvement += max(0, min_latency_per_house[idx] - max_edge[house][v])
                if improvement > best_improvement:
                    best_improvement = improvement
                    best_house = v
            # Update min_latency_per_house
            for idx, house in enumerate(s):
                min_latency_per_house[idx] = min(min_latency_per_house[idx], max_edge[house][best_house])
            result.append(str(sum(min_latency_per_house)))
        print(' '.join(result))

if __name__ == "__main__":
    solve()
```コードはまず、`max_edge`Floyd-Warshall を使用してノードのペア間の最小最大遅延を計算する行列。 考えられるサーバーの数ごとに、インターネットを必要とする住宅の総遅延を最大に改善するノードを貪欲に選択します。 ハウスごとの最小レイテンシを更新した後、合計が累積され、出力に追加されます。 配列へのアクセスを簡素化するために、内部的にノードにゼロからインデックスを付けるように注意が払われます。 問題は対話型ではないため、ここではフラッシュと読み取りは不要です。

## 複雑さの分析
