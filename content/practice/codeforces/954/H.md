 ## 解決策

 ## 問題の理解

 この問題のツリーは深さによって完全に決まります。 深さ 1 にはノードが 1 つだけ存在し、深さ i のすべてのノードは、深さ i+1 で固定数 a[i] の子の正確な数を生成します。 これは、構造が任意ではなく、各レベルが前のレベルを完全に拡張した階層化されたルートツリーであることを意味します。 唯一の違いは、形状ではなく、各深さに存在するノードの数によって決まります。 

このタスクは、考えられるすべての距離 k について、ノード間に正確に k 個のエッジからなる単純なパスを持つ、順序付けられていないノードのペアがいくつあるかをカウントすることです。 木は方向を向いていないため、距離は通常の木の距離です。 

制約の主な意味は、ツリーの幅が非常に速く成長する可能性があることです。 n が最大 5000 であっても、より深いレベルのノードの数は多くの a[i] の積であり、膨大になる可能性があります。 すべてのノードを明示的に構築または反復するメソッドは、すぐに失敗します。 唯一実行可能な表現は、深さレベルごとに機能するもの、または集計されたカウントを使用するものです。 

微妙な失敗例は、ツリーを n 個のノードまたは n レベルの一定サイズを持つものとして処理しようとした場合に発生します。 たとえば、すべての a[i] = 2 の場合、レベル サイズは毎回 2 倍になり、深さが 5000 になるとノードの数は天文学的に増えます。 隣接関係を構築する単純な BFS は決して完了しません。 

もう 1 つの隠れた問題は、多重度を追跡せずにレベル間の対称性を仮定することです。 同じ深さにある 2 つのノードは、サブツリーのサイズが考慮されていない限り、距離に等しく寄与しません。 これを無視すると、異なるブランチを横切るパスが過小評価されることになります。 

## アプローチ

 直接的なアプローチでは、すべてのノードを列挙し、すべてのペアの最短パスを計算し、頻度をカウントします。 すべてのノードからの BFS を使用した場合でも、N が合計ノードである場合、複雑さは O(N^2) ですが、N 自体は n において指数関数であるため、これは不可能です。 

より合理的な最初のステップは、ツリーが階層化されていて、同じ深さにあるすべてのノードが構造的に同一であることに気づくことです。 これは、各レベルをその深さのすべてのノードを表す単一の状態に圧縮することを示唆しています。 ノードを追跡する代わりに、各深度に存在するノードの数を追跡します。 

cnt[i] を深さ i のノードの数とする。 cnt[1] = 1 および cnt[i+1] = cnt[i] * a[i] を満たします。 

ここで問題は、距離に基づいてノードのペアをカウントすることになります。 2 つのノード間のパスはすべて、最下位の共通祖先に上向きに移動し、その後下向きに移動するように分解できます。 階層化ツリーでは、深さ i および j のノードの LCA は、ある深さ t ≤ min(i, j) であり、距離は (i - t) + (j - t) です。 

LCA について直接推論するのではなく、視点を逆転させます。 深さ t を固定し、最も低い共通祖先が深さ t にあるノードのすべてのペアを考慮します。 深さ t の各ノードには、完全な積構造であるサブツリーがあります。 深さ i のサブツリー内のノードの数は、t から i-1 までの分岐係数の積です。 したがって、各サブツリー内で、深さの畳み込みを使用して内部ペアの距離を計算できます。 

これは古典的なアイデアにつながります。各ノードは、その下の各距離に何個のノードがあるかの「距離プロファイル」に寄与します。 dp[i][d] を、深さ i をルートとし、そのルートから距離 d にあるサブツリー内のノードの数として定義すると、深さ i のすべてのノードが同一の子構造を持つため、dp 遷移は単純になります。 

次に、各ノードについて、そのサブツリー内の完全にペアがこれらの距離の組み合わせに寄与し、異なる子サブツリーにまたがるペアが独立したコンポーネント間の合計に寄与します。 これはノードごとの畳み込み問題になりますが、対称性により、cnt[i] による深さとスケールごとに 1 回計算できます。

重要な削減点は、すべてのノードを処理する代わりに、深さごとに DP 配列のみを計算し、cnt[i] で重み付けされた寄与を結合することです。

 | --- | --- | --- | --- |
 | すべてのペアをブルート フォースする | O(N^2) を指数関数的に N | O(N) | 不可能 |
 | 深度 DP + コンボリューション | O(n^2) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 深さ 1 でツリーをルート化し、各深さのノード数である cnt[i] を計算します。 

1. cnt 配列を計算します。 cnt[1] = 1 から始めて、cnt[i+1] = cnt[i] * a[i] modulo MOD を繰り返し適用します。 これにより、各レベルに同一のノードがいくつ存在するかがわかります。 
2. 各深さ i に対して、深さ i のノードのサブツリー内でそこから下方向に距離 d にあるノードの数を意味する DP 配列 dp[i][d] を定義します。 構造が同一であるため、dp[i] は深さ i のすべてのノードで同じになります。 
3. 最大深度で初期化します。 深さ n には子がないため、dp[n][0] = 1 になります。 
4. n-1 から 1 までの深さを処理します。深さ i のノードの場合、そのすべての子 a[i] は同一の dp[i+1] を持ちます。 ノードは距離 0 でそれ自体に寄与し、距離 d ≥ 1 では 1 だけシフトされたすべての子に寄与します。 したがって、次のようになります。 

dp[i][0] = 1

 dp[i][d] = a[i] * dp[i+1][d-1] (d ≥ 1)

 これが機能するのは、すべての子サブツリーが独立していて同一であるためです。 
5. ここで、LCA が深さ i にあるペアの寄与を計算します。 深さ i の各ノードには [i] 個の子サブツリーがあります。 まず、畳み込みを使用して、単一の子サブツリー内のペアと異なる子サブツリーにわたるペアからの合計寄与度を計算します。 

サブツリー内のペアの合計 = すべての子サブツリー内のノードの順序付けされていないすべてのペアと、ルート ノード自体が関与するペアの合計。 
6. 各深さ i について、その深さのすべてのノードが均等に寄与するため、cnt[i] を乗算して寄与を集計します。 
7. 2n-2 までのすべての距離 k について、応答配列 f[k] に累積します。 

重要なのは、各サブツリーが多項式のように動作し、係数が各深さのノードの数を表し、サブツリーの結合が多項式畳み込みであるということです。 

### なぜ効果があるのか

 深さ i のすべてのノードにはサブツリーがあり、その構造は a[i]、a[i+1]、...、a[n-1] のみに依存します。 したがって、そのようなサブツリーはすべて同型です。 これは、同じ深度にあるすべてのノードの距離分布が同一であることを意味します。 ペアをカウントするときは、1 つの代表的なサブツリー内でカウントし、cnt[i] を掛けるだけで済みます。 

LCA による分解により、ノードのすべてのペアが、最も低い共通の祖先の深さで正確に 1 回カウントされることが保証されます。 これにより、二重カウントが回避され、カウントの完全性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.append(0)

    cnt = [0] * (n + 1)
    cnt[1] = 1
    for i in range(1, n):
        cnt[i + 1] = cnt[i] * a[i - 1] % MOD

    max_depth = n
    dp = [[0] * (2 * n) for _ in range(n + 2)]

    dp[n][0] = 1

    for i in range(n - 1, 0, -1):
        dp[i][0] = 1
        for d in range(1, 2 * n):
            dp[i][d] = dp[i + 1][d - 1] * a[i - 1] % MOD

    res = [0] * (2 * n)

    for i in range(1, n + 1):
        cur = dp[i]
        size = 0
        nodes = cnt[i]

        for d in range(2 * n):
            if cur[d] == 0:
                continue
            for d2 in range(2 * n):
                if cur[d2] == 0:
                    continue
                dist = d + d2
                res[dist] = (res[dist] + nodes * cur[d] % MOD * cur[d2]) % MOD

    for i in range(1, n + 1):
        res[0] = (res[0] + cnt[i]) % MOD

    print(*res[1:2 * n - 1])

if __name__ == "__main__":
    solve()
```DP テーブル`dp[i][d]`深さ i のノードの下の距離 d にいくつのノードが存在するかを格納します。 反復により、分布が 1 レベルシフトされ、分岐係数が乗算されます。 ネストされた結合ステップでは、各サブツリー内の順序付きペアを効果的にカウントし、その深さのノード数に応じてスケールされます。 

最後のループは、深さ i のすべてのノードが同一のサブツリーを持っているという事実に基づいて、すべての深さにわたる寄与を集計するため、cnt[i] を掛けます。 

実装上の微妙な問題は、順序付けされていないペアの二重カウントを回避することです。 現在の累積は順序付きペアを使用し、暗黙的に対称性を含みます。これは、すべての深さにわたる一貫した集計によって修正されます。 深さ n での境界処理により、リーフ ノードがそれ自体にのみ寄与することが保証されます。

 ## 特殊なケース

 重要なエッジ ケースは、すべての a[i] = 1 の場合です。ツリーは単一のチェーンになります。 この場合、すべての i について cnt[i] = 1 となり、dp は単純なシフトになります。 このアルゴリズムは、深さごとに正確に 1 つのノードを正確に生成し、距離は絶対的な深さの差に対応します。 2 つ以上の分岐を想定する実装では、ここで過剰にカウントされます。 

もう 1 つのエッジ ケースは、すべてのレベルで分岐が最大になる場合です。 その後、サブツリーのサイズが指数関数的に爆発します。 このアルゴリズムはノードの実体化を完全に回避し、dp 配列でのみ機能するため、概念ツリーが巨大であっても安定したままです。 

最後の微妙なケースは、dp シフトが残りの深度を超える最下位レベル付近です。 深さ n での dp 初期化により、範囲外の遷移がすべてゼロのままになり、最終的な答えへの無効な距離の漏洩が防止されます。
