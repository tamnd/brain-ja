 ## 解決策

 ## 問題の理解

 ジャンクションと道路を表す無向接続グラフが与えられます。各道路は単位長さを持ちます。 任意の 2 つのジャンクション間の最短距離は、パス内のエッジの最小数として定義されます。 

2 つの特別なノード (開始ジャンクション) が強調表示されます。`s`そして目的地のジャンクション`t`。 まだ直接接続されていないノードのペアの間に、新しい道路を 1 つだけ追加できます。 ただし、この新しい道路は、次の道路間の経路距離が最短になるように選択する必要があります。`s`そして`t`減りません。 

タスクは、順序付けされていない隣接しないノードのペアが何ペアあるかを数えることです。`(u, v)`この条件を満たす: エッジを追加すると`(u, v)`、間の最短経路距離`s`そして`t`は変わらないままです。 

グラフのサイズは、ノードから幅優先検索を線形時間で実行できるほど十分小さいですが、考えられるすべての候補エッジを反復して最短パスを最初から再計算するには時間がかかりすぎるほど十分に大きいです。 可能なエッジの数は次のとおりです。`n^2`一方、エッジごとの最短パスを再計算すると、それに別の係数が乗算されます。`n`または`m`、これは不要です。 

重要な構造的観察は、重み付けされていないグラフ内の距離が、BFS レイヤーによって完全にキャプチャされていることです。`s`そしてから`t`。 短くなる可能性のあるエッジ`s`に`t`距離は、現在の最短パス長より厳密に短いルートを作成するノードを接続する必要があります。 

素朴なソリューションが次のことをチェックするだけである場合、微妙な失敗例が発生します。`(u, v)`ある最短経路上にあります。 最短パスの外側のエッジでもショートカットが作成される可能性があるため、これでは不十分です。 

もう 1 つのよくある落とし穴は、レイヤーに近いレイヤーを直接接続するエッジのみが存在すると仮定することです。`s`そして`t`案件。 実際には、どちらのエンドポイントも個別に最短パス上にない場合でも、新しいエッジは 2 つの部分ルートを結合して合計距離を短縮できます。 

## アプローチ

 ブルートフォース戦略では、すべてのペアが考慮されます。`(u, v)`それはすでにエッジではありません。 候補ごとに、それを一時的に追加し、BFS を実行します。`s`新しい最短距離を計算するには`t`。 距離が変わらない場合は、ペアを数えます。 

これが機能するのは、BFS が重み付けされていないグラフの最短パスを正しく計算するためです。 ただし、各 BFS にはコストがかかります`O(n + m)`、そして、あります`O(n^2)`候補エッジ。 最悪の場合、これは約`O(n^3)`限界をはるかに超えた操作`n = 1000`。 

重要な洞察は、候補エッジごとに最短パスを再計算する必要がないということです。 代わりに、2 つの距離配列を事前計算できます。`ds[x]`～からの最短距離です`s`に`x`、 そして`dt[x]`～からの最短距離です`t`に`x`、どちらも BFS によって計算されます。 

間の元の最短経路長を`s`そして`t`なれ`D = ds[t]`。 ここでエッジの追加を検討してください`(u, v)`。 からの任意のパス`s`に`t`この新しいエッジを使用するものは、`s`1 つのエンドポイントに到達し、新しいエッジを越えてから、`t`。 これにより、次の 2 つの形式が考えられます。 

パス`s → u → v → t`長さの`ds[u] + 1 + dt[v]`、および対称のもの`ds[v] + 1 + dt[u]`。 

したがって、新しい最短パスは次のようになります。`min(D, ds[u] + 1 + dt[v], ds[v] + 1 + dt[u])`。 

距離が減少しないという条件は単純な不等式チェックになります。両方のクロスパス候補は少なくとも`D`。 これにより、問題は、欠落している各エッジを一定時間内にチェックすることになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (エッジごとに BFS を再計算) | O(n²(n + m)) | O(n + m) | 遅すぎる |
 | BFS + チェックペアを事前計算する | O(n²) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.BFS を実行します。`s`計算する`ds[x]`すべてのノードに対して`x`。 これにより、スタート地点からすべてのジャンクションまでの最短距離が得られます。 
2.BFS を実行します。`t`計算する`dt[x]`。 これにより、目的地からすべてのジャンクションまでの最短距離が得られます。 
3. 既存のエッジをすべてハッシュ セットまたは隣接行列に保存して、O(1) で次のことを確認できるようにします。`(u, v)`すでに接続されています。 
4. コンピューティング`D = ds[t]`、間の現在の最短経路長`s`そして`t`。 
5. すべての順序付けされていないペアを反復処理します。`(u, v)`と`u < v`。 
6. 間にエッジがすでに存在する場合、そのペアをスキップします。`u`そして`v`、新しい道路の追加のみを考慮しているためです。 
7. 有効なペアごとに、2 つの潜在的な迂回を計算します。`ds[u] + 1 + dt[v]`そして`ds[v] + 1 + dt[u]`。 
8. 両方の値が以上の場合`D`、ペアを有効なものとしてカウントします。 

これが機能する理由は、重み付けされていないグラフ内の最短パスは最短のサブパスで構成されている必要があるためです。 追`s`そして`t`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n, m, s, t = map(int, input().split())
s -= 1
t -= 1

adj = [[] for _ in range(n)]
bad = [[False] * n for _ in range(n)]

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)
    bad[u][v] = bad[v][u] = True

def bfs(start):
    dist = [10**9] * n
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == 10**9:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

ds = bfs(s)
dt = bfs(t)
D = ds[t]

ans = 0

for u in range(n):
    for v in range(u + 1, n):
        if bad[u][v]:
            continue
        if min(ds[u] + 1 + dt[v], ds[v] + 1 + dt[u]) >= D:
            ans += 1

print(ans)
```実装は、BFS の隣接リストと定数時間のエッジ存在チェック用のブール隣接行列の両方を構築することから始まります。 BFS 関数は重み付けされていないグラフの標準であり、最短経路距離を線形時間で計算します。 

すべてのノード ペアにわたる二重ループにより、考えられるすべての新しい道路が 1 回だけ考慮されることが保証されます。 この条件では、導出された不等式を直接使用するため、グラフの変更をシミュレートする必要がありません。 

微妙な点は、入力調整後にグラフを一貫して 0 から始まるインデックスとして扱うことです。 もう 1 つは、接続されたグラフではすべてのノードに到達可能ですが、未訪問のノードが安全に処理されるように、距離に大きなセンチネル値を使用する方法です。 

## 実用的な例

 サンプル入力を使用します。 

入力:```
5 4 1 5
1 2
2 3
3 4
4 5
```BFS 後:

 | ノード | ds | dt |
 | --- | --- | --- |
 | 1 | 0 | 4 |
 | 2 | 1 | 3 |
 | 3 | 2 | 2 |
 | 4 | 3 | 1 |
 | 5 | 4 | 0 |

 ここ`D = 4`。 

次に、非エッジの候補を調べます。 グラフはすでにチェーンになっているため、次のような隣接しないペアはすべて`(1,3)`または`(2,4)`ショートカットが作成されます。 のために`(1,3)`、計算します`ds[1] + 1 + dt[3] = 0 + 1 + 2 = 3`より小さい`D`, したがって無効です。 このようなペアはすべて距離を縮めるので、答えは次のようになります。`0`。 

2 番目の例:

 入力:```
4 2 1 4
1 2
3 4
```距離:

 | ノード | ds | dt |
 | --- | --- | --- |
 | 1 | 0 | 2 |
 | 2 | 1 | 1 |
 | 3 | 2 | 1 |
 | 4 | 3 | 0 |

 ここ`D = 3`。 ペア`(2,3)`与える`min(1+1+1, 2+1+1) = 3`, したがって、それは有効です。 ペア`(1,3)`与える`0+1+1 = 2`、 無効。 これは、より短い複合パスを作成しないペアのみがどのようにカウントされるかを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n² + m) | 2 回の BFS 実行には O(n + m) かかり、すべてのペアのチェックには O(n²) かかります。 |
 | スペース | O(n + m) | 隣接リストと距離配列およびエッジ ルックアップ テーブル。 |

 これは制限内に問題なく収まります。`n ≤ 1000`作る`n²`約 100 万回の操作がありますが、Python では問題ありません。

    from collections import deque

    n, m, s, t = map(int, input().split())
    s -= 1
    t -= 1

    adj = [[] for _ in range(n)]
    bad = [[False] * n for _ in range(n)]

    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
        bad[u][v] = bad[v][u] = True

    def bfs(start):
        dist = [10**9] * n
        dist[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if dist[v] == 10**9:
                    dist[v] = dist[u] + 1
                    q.append(v)

    ds = bfs(s)
    dt = bfs(t)

    ans = 0

## 特殊なケース

 主なエッジケースは次のような場合です`s`そして`t`すでに非常に近いということは、`D = 1`または`D = 2`。 このような場合、追加されたエッジのほとんどはショートカットを作成します。 BFS ベースの不等式はこれを正しく処理します。これは、どの候補も長さのパスを生成するためです。`1`または`2`すぐにフィルタリングされます。 

もう 1 つのケースは、グラフがすでに密集している場合です。 カウントする前に既存のエッジを明示的にチェックするため、既存のエッジを候補として誤って考慮することを回避します。 

最後に、ノードが以下に関して対称に位置する場合、`s`そして`t`、両方向`u → v`そして`v → u`チェックする必要があります。 条件内の対称最小値により、逆方向に作成された有効な短いパスを見逃すことがなくなります。
