 ## 問題の理解

 長さの配列を構築する必要があります$n$、各要素は次のいずれかです$+1$または$-1$。 2 つの特別な位置は、プレフィックスの合計とサフィックスの合計に基づいて定義されます。 

プレフィックスについては、すべての部分和を調べます$S_i = a_1 + \dots + a_i$。 これらの合計の最大値を計算し、この最大値に達する最小のインデックスを選択します。 そのインデックスは正確に一致する必要があります$x$。 

接尾辞の場合は、すべての接尾辞の合計を調べます$T_i = a_i + \dots + a_n$。 それらの最大値を計算し、この最大値が達成される最大のインデックスを選択します。 そのインデックスは正確に一致する必要があります$y$。 

したがって、タスクは、最初のピークが次の位置になるようにプレフィックスサム プロファイルを整形することです。$x$、最後のピークが になるように接尾語合計プロファイルを個別に形成します。$y$、のみを使用している間$\pm1$。 

制約により許可されるのは、$n$まで$10^5$すべてのテスト ケースにわたって行われるため、すべてのソリューションはテスト ケースごとに線形である必要があります。 すべての部分配列のシミュレーションや合計の繰り返しの再計算を伴うものは遅すぎます。 

微妙な問題は、プレフィックス条件とサフィックス条件が任意の方法で独立していないことです。プレフィックス要件のみを満たす単純な構造では、サフィックス条件を簡単に破ってしまう可能性があります。 たとえば、すべてを次のように埋めます。$+1$位置まで$x$その後交互に実行すると、通常、パリティに応じてサフィックスの最大値が遅すぎるか早すぎます。

重要な観察は、接頭辞の合計と接尾辞の合計が、以下の条件下で非常に構造化された方法で単調に動作するということです。$\pm1$配列。 プレフィックスの合計は 1 増加または 1 減少するため、その最大値は正のドリフトの維持をどこで停止するかによって完全に制御されます。 

同じ考え方が接尾語の合計にも当てはまりますが、右側からです。

これは、セグメントを次の間に設定することで実現されます。$y$そして$x$みんなに$+1$、そして配置$-1$早期または後から多額の蓄積を防ぐ方法で外部に保管します。

 ## アルゴリズムのチュートリアル

 配列を直接構築します。 

1. 配列を初期化する$a$長さの$n$。 決定的に値を割り当てます。 
2. 場所$+1$セグメント全体で$[y, x]$。 これにより、プレフィックスとサフィックスの両方の最大値がこの間隔を強制的に通過する、保証された増加領域が作成されます。 
3. の左側のポジションについては、$y$、プレフィックスの合計が位置で達成される値を超えないように値を割り当てます。$x$。 これは、それらを次のように埋めることで行われます。$-1$、早期の蓄積を防ぎます。 
4. 右側のポジションの場合$x$、また割り当てます$-1$、右端から始まるサフィックスが次のサフィックスの最大値を超えることがないようにします。$y$。 
5. 結果の配列を出力します。 

重要な考え方は、セグメントが$[y, x]$プレフィックスとサフィックスの両方の合計がグローバル最大値に達する可能性がある一意の領域として機能します。 この領域の外では、すべての寄与は負であり、代替最大値が出現しないことが保証されます。 

### なぜ効果があるのか

 間隔の中で$[y, x]$、各ステップでプレフィックスとサフィックスの両方の合計が増加し、このセグメント内で最大値が達成されることが保証されます。 外部のすべての値は$-1$、その前で終わる任意の接頭辞$x$のプレフィックスよりも厳密に小さいです$x$、およびその後で始まる接尾辞$y$は接尾辞より厳密に小さいです$y$。 したがって、最大プレフィックス合計が最初に出現するのは正確に次のとおりです。$x$、最大サフィックス合計が最後に出現するのは正確に次のとおりです。$y$。 この構造は、両方の条件を同時に強制する最大累積和の単一のプラトーを分離します。 ∎

 ## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, x, y = map(int, input().split())

        a = [-1] * n

        for i in range(y - 1, x):
            a[i] = 1

        print(*a)

if __name__ == "__main__":
    solve()
```このソリューションはすべてを初期化します。$-1$、偶発的な初期最大値が発生しないようにします。 次に、割り当てます$+1$間隔で$[y, x]$、これはプレフィックスとサフィックスの両方の合計を増やすことができる唯一のリージョンです。 

よくある間違いは、プレフィックス制約とサフィックス制約を別々に適用しようとすることです。 どちらもグローバルな累積構造に依存しているため、これは壊れます。 ここでの正しさは、単一の連続した正のブロックに依存します。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

        a = [-1] * n

 ## 特殊なケース

 いつ$x = y + 1$、正のセグメントは 2 つの隣接する要素まで縮小します。 プレフィックスの最大値は右のエンドポイントで即座に強制され、サフィックスの最大値は左のエンドポイントで強制されます。競合するセグメントが存在しないため、構築は引き続き機能します。 

いつ$y = 1$、プレフィックス構造全体が最初から制御されるため、正のセグメントは最初の要素から始まります。 すべてのサフィックスには最大ブロックが含まれるため、サフィックス条件は自動的に満たされます。 

いつ$x = n$、正のセグメントは配列の最後まで拡張され、それ以降のプレフィックスが最終合計を超えることができないようにするため、最大プレフィックスは必然的に次のようになります。$n$。
