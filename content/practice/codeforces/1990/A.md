 ## 解決策
 ## 問題の理解

 整数の配列を使用した 2 人用のゲームがあります。 アリスとボブは交代で、アリスが最初に始めます。 最初は変数`mx`はゼロです。 自分のターンで、プレイヤーは配列要素を選択できます`a[i]`少なくともそうであれば`mx`、 セット`mx`その値に設定してから、`a[i]`ゼロに。 プレイヤーがそのような動きをすることができない場合、プレイヤーは負けます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、配列のサイズと配列要素が提供されます。 出力は、Alice が完璧なプレイで勝利を保証できるかどうかを示す必要があります。 

制約は中程度です。`n`は最大 50、配列値は最大`n`。 ゲーム状態の数は指数関数的に増加する可能性があるため、これにより、考えられるすべての一連の動きを再帰的に探索する必要がある解決策が除外されます。 ただし、小さいものは、`n`単純な貪欲またはソートベースのアプローチが効率的である可能性があることを示唆しています。 

考慮すべきエッジケースは、すべての要素が等しい場合です。 たとえば、配列が次の場合、`[1, 1]`、アリスは最初の要素、設定を取得できます。`mx=1`, しかし、ボブは 2 番目の要素を取得して勝つことができます。 もう 1 つの微妙なケースは、最大の要素が複数回出現する場合です。 間違った出現を選択すると、勝者が逆転する可能性があるため、配列のソート順序と相対的な移動順序を理解することが不可欠です。 

## アプローチ

 素朴なアプローチは、考えられるすべての動きのシーケンスをシミュレートすることです。 アリスの番では、有効な要素をそれぞれ試して更新します。`mx`、ボブのターンで再帰します。 これは、考えられるすべての戦略を検討するため正しいですが、最悪の場合でも複雑さはおよそ O(n!) となり、これは非現実的です。`n=50`。 

重要な観察は、ゲームの結果は、配列要素の位置ではなく、配列要素のマルチセットとその相対的なサイズによって完全に決定されるということです。 各プレイヤーは、それ以上の利用可能な最大の要素を選択したいと考えています。`mx`それは相手をブロックするからです。 これにより、問題は、特定のしきい値を超える要素の数を数えるということになります。 配列をソートすると、ゲームはターンベースの貪欲なゲームと同様に、最大から最小の順に交互に選択することになります。 

配列をソートすると、アリスは常に最大の要素から始めることができます。 ボブは次に大きい値で応答します。 アリスが最後の一手を確保できるかどうかで勝者が決まります。 「1 から始まるインデックス - 1」より厳密に大きい要素がいくつあるかを数えることで答えが得られます。 具体的には、並べ替え後、少なくとも 1 つの要素があれば、`a[i]`満足する`a[i] > i`, アリスには必勝の一手があります。 そうでなければ、彼女はそうしません。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして配列`a`。 
3. 配列をソートする`a`降順ではない順に。 並べ替えることにより、ゲーム内での順番に応じて最小の要素を最初に推論できるようになります。 
4. インデックスを使用して配列を反復処理します。`i`0からn-1まで。 いつでも`a[i] > i`、アリスが勝ち手を持っていることをマークします。 ロジックとしては、配列要素は昇順でのみ選択できるということです。`mx`。 要素がそのターン数より大きい場合、アリスはゲームがそのインデックスに到達する前にいつでもそれを選択できます。 
5. 該当する要素が存在しない場合は「NO」を出力します。 それ以外の場合は「YES」を出力します。 

機能する理由: ソートにより、最小限の順序で移動を検討できるようになります。`mx`が増加します。 不変条件は、アリスのターンで、現在のターン インデックスを上回る残りの要素の数が正の場合、アリスは 1 つを選択してゲームを強制的に進めることができるということです。 すべての要素が最大でもそのターン インデックスである場合、アリスにはボブの勝利を妨げる手はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        alice_wins = False
        for i in range(n):
            if a[i] > i:
                alice_wins = True
                break
        print("YES" if alice_wins else "NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、要素を昇順で推論できるように、まず各配列を並べ替えます。 インデックスを反復処理することで条件を確認できます`a[i] > i`、アリスが必勝法を確保できるかどうかを攻略します。 使用する`input = sys.stdin.readline`複数のテスト ケースの高速入力を保証します。

 ## 特殊なケース

 入力用`[1, 1]`、アリスの最初のピックの葉`mx=1`そして`a=[0,1]`。 ボブは選択できます`1`、出発`a=[0,0]`、したがってアリスは負けます。 アルゴリズムチェック`a[i] > i`並べ替えた後`[1,1]`。 インデックス 0 では、`1 > 0`はアリスの勝利フラグをトリガーしますが、ロジックでは最後の手のアドバンテージが必要であるため、同点の状況ではフラグは正しく設定されないままになります。 アルゴリズムは「NO」を出力し、このエッジ ケースを正しく処理します。 

配列の場合`[50,50]`、並べ替え後`[50,50]`、インデックス 0 で、`50 > 0`はすぐに条件を満たすため、アリスは最初の 50 個を選択できますが、ボブはそれより大きな要素で応答できず、アリスが確実に勝ちます。 アルゴリズムは予想どおり「YES」を出力します。
