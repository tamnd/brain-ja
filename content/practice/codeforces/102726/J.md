 ## 解決策
 # 問題の理解

 この問題では、グラフを相関のある確率変数のモデルとして見るように求められます。 各頂点は平均ゼロの確率変数を表します。 変数の分散はその頂点次数に等しく、隣接する変数には共分散があります。`-1`、隣接しない変数には共分散があります。`0`。 これらの変数の線形結合の係数を選択する必要があります。係数の二乗和は次のように固定されます。`1`、その組み合わせの標準偏差を最大化します。 

入力により、無向無重みグラフが得られます。 出力は、頂点に関連付けられた変数の正規化された線形結合の最大の標準偏差です。 

グラフには最大でも`100`頂点と`1600`エッジ。 これらの境界は十分に小さいため、すべてのエッジまたはすべての頂点にわたる繰り返しパスを含むアルゴリズムを実行できます。 ただし、これらはコンテスト環境で大量の汎用行列分解ルーチンを正当化できるほど大きくないため、グラフによって作成された行列の構造を活用する必要があります。 

重要な観察は、共分散行列がまさにグラフのラプラシアンであるということです。 すべての頂点について、対角線のエントリがその次数になります。 すべてのエッジについて、対応する 2 つの非対角エントリは次のとおりです。`-1`。 他のすべてのエントリはゼロです。 正規化された線形結合の最大分散は、この対称行列の最大固有値であり、答えはその平方根です。 

よくある間違いは、個々の変数間のみを検索することです。 たとえば、接続された 2 つの頂点を持つグラフの各変数分散は次のようになります。`1`、ただし、反対の符号と組み合わせると分散が生じます`4`、標準偏差を生成します`2`? 実際、共分散行列については、`[[1,-1],[-1,1]]`、最大の固有値は`2`、したがって、答えは次のとおりです`sqrt(2)`。 最大化の組み合わせでは両方の変数が一緒に使用されるため、頂点を個別にチェックすると失敗します。 

もう 1 つの特殊なケースは、接続されていないグラフです。 考慮する：```
3 1
0 1
```正しい出力はおよそ次のとおりです。```
1.4142135623730951
```孤立した頂点の固有値はゼロになります。 グラフが接続されている必要があると仮定したり、孤立した頂点を削除したりする不注意な実装では、行列が変更され、正しいスペクトルが失われる可能性があります。 

最後の微妙なケースは、すべての次数が等しいグラフです。 例えば：```
3 3
0 1
1 2
2 0
```共分散行列は三角グラフのラプラシアンです。 最大の固有値は次のとおりです。`3`、したがって、答えはおよそ`1.7320508075688772`。 度だけを見ると、すべての方向にばらつきがあると誤って示唆されてしまいます。`2`。 

## アプローチ

 直接的なアプローチは、共分散行列を構築し、一般固有値分解を実行することです。 答えは最大の固有値の平方根であるため、これは数学的に簡単です。 ただし、完全な固有値ソルバーを実装することは不必要であり、特に固有値が 1 つだけ必要な場合にはエラーが発生しやすくなります。 

より単純な強引なアイデアは、候補係数ベクトルを構築し、最大の分散を検索しようとすることです。 係数ベクトルの分散`a`は`a^T L a`、 どこ`L`ラプラシアンです。 係数空間には無限の方向があるため、候補を列挙することは不可能です。 係数をグリッドに制限する場合でも、指数関数的な数の可能性が必要になります。 

重要な構造は、`L`対称です。 対称行列の場合、行列を繰り返し乗算すると、ベクトルが最大の固有値の方向に押し出されます。 これがべき乗反復法です。 グラフ ラプラシアンでは、完全な行列を保存せずに乗算も可能です。 あらゆるエッジに`(u, v)`、ラプラシアン乗算が寄与します。`x[u] - x[v]`頂点へ`u`そして`x[v] - x[u]`頂点へ`v`。 

最適な方向は係数空間内に隠された連続固有ベクトルであるため、ブルート フォースは失敗します。 答えが対称行列の極端な固有値であるという観察により、検索をスパース行列とベクトルの乗算を繰り返すことで置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数的またはそれ以上 | 大 | 遅すぎる |
 | 完全な固有分解 | 実装によって異なりますが、通常は O(n³) | O(n²) | 不要 |
 | 累乗反復 | O(反復回数 × (n + m)) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフ表現を構築します。 ラプラシアンを乗算するにはエッジを訪問するだけで済み、すべてを保存する必要はないため、すべてのエッジを保存します。`n × n`マトリックスのエントリ。 
2. ゼロ以外の係数ベクトルから開始し、それを正規化します。 ベクトルには、最大の固有ベクトルの方向に何らかの成分がなければなりません。そうでない場合は、べき乗反復で検出できません。 
3. 現在のベクトルにラプラシアンを繰り返し乗算します。 エッジ接続用`u`そして`v`、 追加`x[u] - x[v]`での結果に`u`そして追加します`x[v] - x[u]`での結果に`v`。 
4. 各乗算後に結果のベクトルを正規化します。 正規化を行わないと、値は固有値とともに指数関数的に増加し、最終的には数値的に不安定になります。 
5. レイリー商を使用して固有値を推定します。$$\lambda = \frac{x^T Lx}{x^Tx}$$正規化されたベクトルの場合、これは単純に次のようになります。`x · (Lx)`。 

1. この問題では分散ではなく標準偏差が求められるため、推定された最大固有値の平方根を出力します。 

これが機能する理由は、ラプラシアンが実対称行列であるため、直交する固有基底があるためです。 乗算を繰り返すと、すべての固有ベクトル成分がその固有値によってスケーリングされます。 最大の固有値に属する成分が最も速く成長し、ベクトルがその固有ベクトルに向かって収束します。 その後、レイリー商は最大の固有値自体に収束します。 

## Python ソリューション```python
import sys
import math

input = sys.stdin.readline

def solve():
    line = input().split()
    if not line:
        return
    n, m = map(int, line)

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        edges.append((u, v))

    vec = [i + 1.0 for i in range(n)]
    norm = math.sqrt(sum(x * x for x in vec))
    vec = [x / norm for x in vec]

    for _ in range(10000):
        nxt = [0.0] * n
        for u, v in edges:
            d = vec[u] - vec[v]
            nxt[u] += d
            nxt[v] -= d

        norm = math.sqrt(sum(x * x for x in nxt))
        if norm == 0:
            print("0.0")
            return
        vec = [x / norm for x in nxt]

    lap_vec = [0.0] * n
    for u, v in edges:
        d = vec[u] - vec[v]
        lap_vec[u] += d
        lap_vec[v] -= d

    eigenvalue = sum(vec[i] * lap_vec[i] for i in range(n))
    print(math.sqrt(max(0.0, eigenvalue)))

if __name__ == "__main__":
    solve()
```入力セクションはグラフを読み取り、エッジのみを保存します。 ほとんどすべてのエントリがゼロであり、エッジベースの乗算の方が高速でメモリ使用量が少ないため、このアルゴリズムでは完全な共分散行列が作成されることはありません。 

初期ベクトルでは、すべて 1 ではなく、異なる値が使用されます。 すべて 1 のベクトルは常に固有値 0 を持つラプラシアンの固有ベクトルであるため、それから開始すると、有用な方向がすぐに失われます。 

乗算ループはべき乗反復を実行します。 各エッジの減算はまさにラプラシアン演算です。すべての頂点は、次数の寄与からその近傍の値を差し引いた値を受け取ります。 

収束後、コードはレイリー商を計算します。 の`max`この呼び出しは、平方根を求める前の小さな負の浮動小数点エラーから保護します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(k(n + m)) |`k`パワー反復、それぞれがすべての頂点とエッジを訪問します。 
| スペース | O(n + m) | エッジ リストといくつかのベクトルを格納します。 

ここ`k`固定の反復回数です。 だけで`100`頂点と`1600`エッジでは、繰り返される疎行列の乗算は簡単に制限内に収まります。 

## テストケース```python
import sys
import io
import math

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)

    data = sys.stdin.read().split()
    if not data:
        return ""

    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    edges = []
    for _ in range(m):
        edges.append((int(next(it)), int(next(it))))

    vec = [i + 1.0 for i in range(n)]
    norm = math.sqrt(sum(x * x for x in vec))
    vec = [x / norm for x in vec]

    for _ in range(10000):
        nxt = [0.0] * n
        for u, v in edges:
            d = vec[u] - vec[v]
            nxt[u] += d
            nxt[v] -= d
        norm = math.sqrt(sum(x * x for x in nxt))
        if norm == 0:
            return "0.0"
        vec = [x / norm for x in nxt]

    lap = [0.0] * n
    for u, v in edges:
        d = vec[u] - vec[v]
        lap[u] += d
        lap[v] -= d

    ans = math.sqrt(max(0.0, sum(vec[i] * lap[i] for i in range(n))))
    sys.stdin = old
    return str(ans)

 ## 特殊なケース

 1 つの孤立した頂点を持つグラフの場合:```
1 0
```ラプラシアンは 1 行 1 列のゼロ行列です。 べき乗反復は、乗算がゼロベクトルを生成することを検出し、戻り値を返します。`0`。 分散がないため、標準偏差は正確にゼロです。 

接続されていないコンポーネントの場合:```
4 2
0 1
2 3
```アルゴリズムには特別な処理は必要ありません。 ラプラシアン乗算は各コンポーネントで独立して機能します。 べき乗反復により、最大の固有値を含む成分が見つかります。これはまさにグローバル最大値が必要とするものです。 

通常のグラフの場合:```
3 3
0 1
1 2
2 0
```すべての頂点の分散は同じですが、その共通次数だけから答えが得られるわけではありません。 乗算を繰り返すことで共分散項間の相互作用が捕捉され、正しい最大固有値が得られます。`3`。 

小さなグラフの場合、浮動小数点精度が主なリスクになります。 このアルゴリズムは、乗算後にベクトル ノルムをチェックすることでほぼゼロによる除算を回避し、平方根を適用する前に小さな負の固有値推定値をクランプします。
