 ## 解決策
 ## 問題の理解

 桁の合計が指定された値になる、可能な限り最小の幸運な数字を構築する必要があります`n`。 

ラッキーナンバーには数字のみを含めることができます`4`そして`7`。 例えば、`447`すべての数字が次のいずれかであるため、これは有効です`4`または`7`、 その間`45`数字なので無効です`5`が表示されます。 

入力は単一の整数を与えます`n`、目的の桁の合計を表します。 出力は、数字の合計が正確に一致する、数値的に最小のラッキーナンバーでなければなりません。`n`。 そのような番号が存在しない場合は、印刷します`-1`。 

制約は次のとおりです`10^6`これにより、ラッキーナンバーを 1 つずつ生成することが直ちに除外されます。 たった20桁のラッキーナンバーだけでも、すでに膨大な数になります。 ほぼ直線的な時間、またはそれ以上の時間で実行できるものが必要です。 

重要な観察は、桁の合計は桁数にのみ依存するということです。`4`と`7`私たちが使っているのは。 使用する場合`a`数字のコピー`4`そして`b`数字のコピー`7`、 それから：$4a + 7b = n$したがって、問題は非負の整数を見つけることになります。`a`そして`b`この方程式を満たしながら、可能な限り最小の数を生成します。 

見落としやすいエッジケースがいくつかあります。 

もし`n = 1`、どちらでもないので解決策はありません`4`または`7`合計を寄付できる`1`。 正しい出力は次のとおりです。```
-1
```不注意な実装では、貪欲な減算を試行し、誤って無限ループに入ったり、空の文字列を出力したりする可能性があります。 

もう 1 つの注意が必要なケースは、複数の分解が存在する場合です。 例えば：```
n = 28
```次のように書くことができます:```
28 = 7 + 7 + 7 + 7
```それは与える`7777`、 または：```
28 = 4 + 4 + 4 + 4 + 4 + 4 + 4
```それは与える`4444444`。 

それでも`4444444`桁数が多いほど、桁数が異なる数値は数値的に小さくなります。桁値が異なると、桁数が少ない数値が常に小さくなるわけではないからです。 実際のルールはさらに微妙です。同じ長さの数字の中で、前の数字の方が重要です。 辞書編集的に最小の有効な数を慎重に構築する必要があります。 

もう 1 つの重要なエッジ ケースは、桁数が異なる場合に発生します。 考慮する：```
n = 11
```考えられる分解は次のとおりです。```
4 + 7
7 + 4
```有効なラッキーナンバーは次のとおりです。`47`そして`74`。 正しい答えは、`47`辞書編集的には小さいからです。 間違った順序で数字を追加する実装は、ここで失敗します。 

## アプローチ

 最も直接的な強引なアイデアは、幸運な数字を生成し、その数字の合計をテストすることです。 のみを含むすべての数値を再帰的に構築できます。`4`そして`7`、その桁の合計を計算し、有効な最小のものを追跡します。 

すべての幸運な数字は最終的に生成されるため、これは概念的に機能します。 問題はカウントの爆発です。 長さのある幸運な数字`k`もっている`2^k`可能性。 長さに関しても`20`、すでに候補者100万人を超えています。 以来`n`届くかもしれない`10^6`、必要な数値には数十万桁が含まれる可能性があり、ブルートフォースは完全に不可能になります。 

問題の構造は、はるかに単純な解釈を与えます。 実際の桁の順序は、桁数を決定した後にのみ重要になります。`4`と`7`を使用します。 私たちが選ぶなら`a`四つん這いと`b`7 の場合、合計条件は次のようになります。$4a + 7b = n$ここで必要なのは、有効なペアを検索することだけです`(a, b)`。 

次の問題は、結果の数値をできるだけ小さくする方法です。 

桁数の少ない数値は、両方の先頭にゼロがない場合、桁数の多い数値よりも常に小さくなります。 すべての数字が少なくとも寄与するため、`4`、合計桁数を最小限に抑えることが有益です。 2個交換`4`1つ付いています`7`次の理由により、桁数が減ります。```
4 + 4 = 8
7 = 7
```もっと使う`7`s は通常、桁数が少ないことを意味します。 

ただし、桁の順序も重要です。 合計桁数が決まったら、小さい桁を先に配置するほど数値が小さくなります。 したがって、カウントを選択した後、`(a, b)`、最適な配置は次のとおりです。```
444...4777...7
```みんなで`4`まず。 

これにより、検索スペースが非常に小さくなります。 可能な数だけ反復できます。`7`s. の各値に対して、`b`、残りの合計が次で割り切れるかどうかを確認します。`4`。 

すべての有効なペアの中で、合計桁数が最も小さいペアが優先されます。```
a + b
```複数のペアが同じ長さの場合、より長いペアが優先されます。`4`を最前面に置きます。これは最小化すると自然に起こります。`b`。

 | ブルートフォース | O(2^k) | O(k) | 遅すぎる |
 | 最適 | O(n) | O(1) 出力を除く | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数を読み取る`n`。 
2. 可能な桁数を繰り返します。`7`さあ、電話してください`b`、 から`0`まで`n // 7`。 
3. それぞれについて`b`、残りの合計を計算します。```
remaining = n - 7 * b
```1. かどうかを確認します。`remaining`で割り切れます`4`。 

で割り切れない場合`4`の場合、有効なカウントはありません`4`はこのために存在します`b`。 

1. 割り切れる場合は、次を計算します。```
a = remaining // 4
```これで有効な分解が得られました。$4a + 7b = n$1. 繰り返すので`b`小さい値から大きい値まで、最初の有効なペアが自動的に最小の数値を与えます。 

より小さい`b`より主導的な意味`4`s であり、通常はより好ましい辞書順です。 

1. 次の文字列を出力します。`a`のコピー`'4'`に続く`b`のコピー`'7'`。 
2. ループ後に有効なペアが存在しない場合は、次のように出力します。`-1`。 

### なぜ効果があるのか

 すべての有効なラッキーナンバーは何らかのペアに対応します`(a, b)`満足のいく：$4a + 7b = n$これらの数字から形成されるすべての数字の中で、すべての数字を配置すると、`4`何よりもまず`7`s は最小の配置を生成します。`4 < 7`。 

アルゴリズムは、可能なすべてのカウントをチェックします。`7`は昇順です。 最初の有効な解決策は、次の数を最小限に抑えます。`7`s. 交換してから`7`と一緒です`4`s は小さい数字を前面に押し出し、有効な最小のラッキーナンバーを生成します。 

有効な分解はスキップされないため、アルゴリズムは最適な答えを見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    for sevens in range(n // 7 + 1):
        remaining = n - 7 * sevens

        if remaining % 4 == 0:
            fours = remaining // 4
            print('4' * fours + '7' * sevens)
            return

    print(-1)

solve()
```ループは、可能なすべてのカウントを試行します。`7`最小から最大まで。 選択肢ごとに、残りの合計が完全に次の方法で形成できるかどうかを確認します。`4`s.

 有効な分解が見つかった瞬間に、すぐに答えを出力して停止します。 後のソリューションにはさらに多くのものが含まれるため、この早期の復帰が重要になります。`7`s を使用して、より大きな数を生成します。 

アウトプットの構造も重要です。 全て印刷いたします`4`何よりもまず`7`■ 桁のマルチセットが固定されると、辞書編集順によって小さい番号が決定されるためです。 

微妙な詳細の 1 つは、ループ バインドです。```
range(n // 7 + 1)
```なしで`+1`、合計が次のものだけで構成されている場合を見逃してしまいます。`7`s.

 もう 1 つの簡単な間違いは、減算する前に割り算をチェックすることです。`7`貢献。 割り算テストは、選択されたすべての値を計算した後の残りの値に適用する必要があります。`7`s.

# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())

    for sevens in range(n // 7 + 1):
        remaining = n - 7 * sevens

        if remaining % 4 == 0:
            fours = remaining // 4
            print('4' * fours + '7' * sevens)
            return

    print(-1)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
