 ## 解決策
 ## 問題の理解

 2 つの多項式が与えられます。 最初のものは線形多項式です$$f(x)=Ax+B$$2 番目にはゼロ以外の項が 2 つだけあります。$$g(x)=Cx^n+Dx^{n-1}.$$最小数の導関数が必要です。$k$、微分した後、$g(x)$その通り$k$を乗算すると、結果の多項式は次のように割ることができます。$f(x)$商のすべての係数を整数として保持します。 

テストケースの数は次のとおりです。$10^5$、すべての値は最大でも$2\cdot10^5$。 デリバティブをシミュレートするか、可能な限りすべてを試すソリューション$k$すべてのテストケースに対して遅すぎるでしょう。 と$10^5$場合によっては、前処理後にケースごとにほぼ一定の時間が必要になります。 

主なトラップは、割り算の定義に含まれる「整数」という単語によって引き起こされます。 有理数の割り算だけでは十分ではありません。 

例えば：```
1
2 4 1 3 3
```ここ$$f(x)=2x+4,\quad g(x)=x^3+3x^2.$$1 つの導関数の後:$$g'(x)=3x^2+6x=3x(x+2).$$線形部分は次のようになります。$2x+4$ただし、商には小数が含まれます。$$3x(x+2)=\frac{3}{2}x(2x+4).$$正しい答えはそうではありません$1$。 商が整数多項式になるまで続行する必要があります。 

もう 1 つのエッジ ケースは、多項式がゼロに達した場合です。 例えば：```
1
5 1 1 1 1
```十分な微分を行うと、多項式はゼロになります。 商は単にゼロになる可能性があるため、ゼロはすべての多項式で割り切れます。 答えには、この最後の可能性が含まれている必要があります。 

3 番目のエッジケースは、$k=0$。 元の多項式がすでに条件を満たしている可能性があります。 

## アプローチ

 直接的なアプローチは微分を繰り返すことです$g(x)$結果が次で割り切れるかどうかをテストします。$f(x)$。 これは、導関数ごとに次数が 1 ずつ減少するため、数学的に機能します。$n+1$導関数では多項式はゼロになります。 ただし、すべてのテスト ケースで考えられるすべての導関数をチェックするにはコストがかかります$O(n)$、与える$O(2\cdot10^{10})$限界をはるかに超えた最悪の場合でも動作します。 

重要な観察は、すべての導関数が同じ構造を維持しているということです。 後$k$デリバティブ、ここで$0\le k<n$、$$g^{(k)}(x)=
\frac{n!}{(n-k)!}C x^{n-k}
+
\frac{(n-1)!}{(n-1-k)!}D x^{n-1-k}.$$多項式は次のように書くことができます$$x^{n-1-k}(\alpha x+\beta).$$余分な力$x$で割り切れるかどうかは関係ありません$Ax+B$。 唯一関連する部分は線形係数です。 必要です$$\alpha x+\beta=q(Ax+B)$$ある整数に対して$q$。 

比率条件は次のようになります。$$\frac{\alpha}{\beta}=\frac{A}{B}.$$導関数係数を代入すると、次のようになります。$$\frac{nC}{(n-k)D}=\frac AB.$$並べ替え:$$nBC=AD(n-k).$$させて$$s=n-k.$$それから$s$は一意に決定されます。$$s=\frac{nBC}{AD}.$$これが次の範囲の整数でない場合は、$1$そして$n$、ゼロ以外の導関数は機能せず、答えは次のようになります。$n+1$。 存在する場合でも、商が整数であることを確認する必要があります。 残りの条件は、$$B \mid D\cdot \frac{(n-1)!}{(s-1)!}.$$必要なのは素指数だけです$B$。 以来$B\le 2\cdot10^5$、それを因数分解し、ルジャンドルの公式を使用して階乗素指数を計算できます。

 ## アルゴリズムのチュートリアル

 1. コンピューティング$$num=nBC,\qquad den=AD.$$比率の方程式は次のように述べています。$s=n-k=num/den$、したがって、導関数の数は完全性をチェックする前に決定されます。 

1. もし`num`で割り切れない`den`、ゼロ多項式の前に有効な導関数はありません。 戻る$n+1$。 
2. しましょう$s=num/den$。 もし$s\notin[1,n]$、 戻る$n+1$。 の値$s$を表します$n-k$したがって、既存の派生関数に対応する必要があります。 
3. かどうかを確認します。$$B \mid D\cdot s(s+1)\cdots(n-1).$$製品はまさに$(n-1)!/(s-1)!$、これは微分後の線形因子の定数係数に現れます。 

1. 割り算テストが成功した場合、答えは次のようになります。$k=n-s$。 それ以外の場合は戻る$n+1$。 

なぜ効果があるのか:

 考えられるすべての有用な導関数には線形係数があり、その係数比が一致する必要があります。$Ax+B$。 この比率により、可能な値が 1 つだけ強制されます。$n-k$。 残りの唯一の要件は、スカラー乗数が整数であることです。 素指数チェックはその条件を正確に検証するため、すべての戻り値が定義を満たしており、より小さな導関数はすべて強制値によってすでに除外されています。$k$。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MAXN = 200000

spf = list(range(MAXN + 1))
for i in range(2, int(MAXN ** 0.5) + 1):
    if spf[i] == i:
        for j in range(i * i, MAXN + 1, i):
            if spf[j] == j:
                spf[j] = i

def factor(x):
    res = []
    while x > 1:
        p = spf[x]
        c = 0
        while x % p == 0:
            x //= p
            c += 1
        res.append((p, c))
    return res

def fact_exp(n, p):
    ans = 0
    while n:
        n //= p
        ans += n
    return ans

def solve_case(A, B, C, D, n):
    num = B * n * C
    den = A * D

    if num % den:
        return n + 1

    s = num // den
    if s < 1 or s > n:
        return n + 1

    need = factor(B)

    for p, e in need:
        have = 0
        x = D
        while x % p == 0:
            have += 1
            x //= p
        have += fact_exp(n - 1, p) - fact_exp(s - 1, p)
        if have < e:
            return n + 1

    return n - s

def main():
    t = int(input())
    ans = []
    for _ in range(t):
        A, B, C, D, n = map(int, input().split())
        ans.append(str(solve_case(A, B, C, D, n)))
    print("\n".join(ans))

if __name__ == "__main__":
    main()
```コードはまず最小の素因数テーブルを構築します。$B$速いです。 すべての値は次のように制限されているため、$200000$、この前処理はすべてのテスト ケースで共有されます。 

比率の計算には Python の整数が使用されるため、オーバーフローの危険はありません。 値`s`回答に変換される前にチェックされるため、$k=n-s$場合にのみ意味をなす$s$有効な残りの学位です。 

可分性テストでは階乗積を直接構築することはありません。 代わりに、素数指数を比較します。 の素数の指数$m!$分割を繰り返すことで求められます$m$その素数によって計算されます。これがルジャンドルの公式です。

 ## 特殊なケース

 初期多項式がすでに正しく除算されている場合、比率方程式は次のようになります。$s=n$、したがって、答えは次のようになります$k=0$。 アルゴリズムはこれを処理します。$s$等しい$n$。 

比率条件は満たされるが、商が小数である場合、素数指数チェックにより候補が拒否されます。 たとえば、```
1
2 4 1 3 3
```唯一可能な非ゼロの候補は$k=1$、ただし、係数乗数には次の係数が含まれます。$3/2$。 アルゴリズムはそれを検出します$B=4$必要な係数を除算せず、後のゼロ多項式の答えを返します。 

ゼロ多項式の前に導関数が機能しない場合、戻り値は次のようになります。$n+1$。 その時点で$g^{(n+1)}(x)=0$、ゼロは商がゼロの線形多項式で割り切れます。
