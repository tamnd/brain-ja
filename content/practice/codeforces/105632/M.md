 ## 解決策
 ## 問題の理解

 1 から n までの要素の宇宙が与えられ、各要素 i には重み ai が割り当てられます。 目標は、独立したコイントスを使用して固定サイズ k のサブセットを生成し、その後無効な結果を拒否するランダム化手順を設計することです。 

このプロセスは、各インデックス i に確率 pi を割り当てることによって機能します。 1 つの試行では、各 i を確率 pi で個別に含めて、ランダムなサブセット T を生成します。結果のサブセットのサイズが正確に k である場合、それを受け入れます。 それ以外の場合は、トライアル全体を破棄し、成功するまで繰り返します。 すべての成功した結果の中で、k サイズのサブセット S にわたる分布が S のすべての要素にわたる ai の積に比例するようにしたいと考えています。 

出力はサブセット自体ではなく、包含確率 pi です。 これらの確率は合計が k になる必要があり、拒否サンプリングの後、必要な乗算重み構造に一致する k サブセット上の分布を誘導する必要があります。 

この制約により、n は最大 100000 まで許可され、サブセットの列挙やすべての k の組み合わせに対する動的プログラミングが含まれるものは即座に除外されます。 正しいアプローチでは、アレイ上の少数のパスで問題を線形時間またはほぼ線形時間に抑える必要があります。 

微妙な点は、分布がイベント |T| で条件付けされた後に定義されることです。 = k. その条件付けはすべての座標を結合するため、生成が独立しているとしても、最終的な確率 pi は単純な方法では ai の独立した関数ではありません。 

典型的な失敗モードは、pi が ai に比例する、または正規化だけで十分であると仮定することです。 たとえば、n = 3、k = 1、a = [1, 100, 100] の場合、ai に比例する pi を推測すると、条件付け構造を考慮しない確率が得られ、拒否後の誘導分布は重み付きシングルトン全体で均一ではありません。 

もう 1 つの微妙な落とし穴は、数値の安定性です。 pi は実数であり、グローバル制約を満たす必要があるため、正規化条件を通じて小さな誤差が蓄積され、合計制約に違反したり、比率が歪んだりする可能性があります。 

## アプローチ

 ブルートフォース解釈では、定義条件から直接 pi を解こうとします。 サイズ k のすべてのサブセット S を列挙し、拒絶サンプリングが S を出力する確率を pi で書き、任意の 2 つのサブセット間の比をそれらの重みの比と同等にすることを想像できます。 各サブセットの確率は pi と (1 - pi) の積に拡張されるため、これにより、指数関数的に多くの方程式からなるシステムが得られます。 完全な尤度を記述する場合でも、すべてのサイズのすべてのサブセットを合計する必要があり、これは O(2^n) になります。 これは、n が小さい場合でも実行不可能です。 

重要な構造的観察は、拒否ステップが固定カーディナリティを条件とすることであり、これは和制約を条件とするポアソン二項分布との関連を示唆しています。 棄却前の T の分布は完全に因数分解されますが、|T| で条件付けされた後は = k の場合、固定サイズの積形式分布が得られます。 

k サブセットにわたる必要なターゲット分布は ∏ ai に比例します。これは、各項目が重み ai を持つ場合に、k 個の項目を非置換でサンプリングすることで得られる分布とまったく同じです。 これは古典的な加重 k サブセット モデルであり、多変量ワレニウスまたはフィッシャーの非心超幾何構造としても知られています。 このようなモデルでは、既知の表現があります。各要素 i には、単一のスケーリング パラメーター λ に依存する「包含傾向」pi があり、正しい形式は次のとおりです。 

pi = 1 / (1 + λ / ai)

 一部の λ > 0 については、独立したサンプリングの下で T の期待サイズが k に等しくなるように選択されます。

この構造は、任意の 2 つの要素間の包含確率の比が、コンディショニング後の重みの比と一致する必要があるために出現します。 すべての k サブセットにわたって比例性を強制すると、1 パラメーターの解ファミリーが強制され、制約 ∑ pi = k が λ を一意に固定します。 

したがって、問題は、pi(λ) の合計が k に等しくなるような λ を見つけることに帰着します。 π は λ において単調減少するため、和も単調となり、二分探索を使用して λ を求めることができます。 合計の各評価は O(n) であり、完全な解は O(n 対数精度) になります。

 ## アルゴリズムのチュートリアル

 すべての確率を同時に制御する単一の正のパラメーター λ を導入します。 固定 λ の場合、各包含確率を pi(λ) = ai / (ai + λ) として定義します。 この形式が選択されるのは、重みを (0,1) の確率にマッピングしながら要素間の比例オッズを保存する唯一の滑らかな対称変換であるためです。 

1. λ の候補値を固定します。 この λ について、pi = ai / (ai + λ) を使用してすべての pi(λ) を計算します。 このステップでは、順序を維持する方法で重みを包含確率に変換します。つまり、ai が大きいほど、pi も常に大きくなります。 
2. 合計 S(λ) = ∑ pi(λ) を計算します。 この合計は、拒否される前のサンプル セットの予想サイズを表します。 拒否ステップでは pi は変化しないため、これは制御する正しい量です。 
3. λ → 0 の場合、すべての pi が 1 に近づくため、S(λ) が n に近づくことに注目してください。 λ → ∞ の場合、すべての pi が 0 に近づくため、S(λ) は 0 に近づきます。これにより、[1, n − 1] のすべてのターゲット k が達成可能であることが保証されます。 
4. λ に対して二分探索を使用して、S(λ) = k となる一意の値を見つけます。 各中間点で S(λ) を計算し、それを k と比較します。 S(λ) が大きすぎる場合、λ は小さすぎるため、大きくする必要があります。 それ以外の場合は、λ を小さくします。 
5. 収束後、最終的な λ を使用して各 i の pi を出力します。 

二分探索は、合計が十分に正確で、個々の pi 値が真の値と最大で 1e-6 異なる場合に終了します。 

### なぜ効果があるのか

 拒否後の分布は、要素間の相対的な包含確率のみに依存します。 形式 pi = ai / (ai + λ) は、これらのオッズを正確に保持します。 

pi / (1 − pi) = ai / λ。 

これは、包含の対数オッズが定数 λ だけシフトされた log(ai) に比例することを意味します。 正確に k 個の選択されたアイテムを条件とすることにより、期待されるカーディナリティが k に一致するように強制され、S(λ) の単調性により一意の解が保証されます。 したがって、この構築は、独立したベルヌーイ試行を固定サイズの加重サンプリング分布に合わせるための唯一の一貫した方法です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    def calc(lam):
        s = 0.0
        for x in a:
            s += x / (x + lam)
        return s

    lo, hi = 0.0, 1.0

    # expand hi until sum <= k
    while calc(hi) > k:
        hi *= 2.0

    for _ in range(80):
        mid = (lo + hi) / 2.0
        if calc(mid) > k:
            lo = mid
        else:
            hi = mid

    lam = hi
    res = [x / (x + lam) for x in a]
    print("\n".join(f"{v:.12f}" for v in res))

if __name__ == "__main__":
    solve()
```解決策は、関数 S(λ) を定義することから始まります。この関数は、指定されたパラメーターの予想されるサブセット サイズを計算します。 初期の上限は、予想されるサイズが k を下回るまで指数関数的に拡張され、バイナリ検索間隔が有効であることが保証されます。 

次に、二分探索が固定回数の反復で適用されます。 S(λ) の単調性により、方向更新の正確さが保証されます。 収束後、最終的な λ を使用して各 pi が直接計算されます。 

よくある実装の落とし穴は、浮動小数点精度には単純なイプシロン停止ではなく十分な反復が必要であることを忘れていることです。 倍精度を実現するには、80 などの固定反復回数を使用すれば十分です。

 ## 特殊なケース

 エッジケースの 1 つは、すべての AI が等しい場合です。 その場合、システムは一様な確率 pi = k / n に減らす必要があります。 S(λ) は対称であり、二分探索は等しい確率を生成する一意の λ に収束するため、アルゴリズムはこれを処理します。 

もう 1 つのエッジ ケースは、k = 1 など、k が非常に小さい場合です。その場合、T にはちょうど 1 つの要素が期待され、解は λ を大きく押し出すため、すべての確率が小さくなり、比率が ai と一致します。 この構造では、要素間の比例選択が自然に維持されます。 

最後のエッジ ケースは、1 つの ai が 1e9 で他の ai が 1 など、極端な重みの不一致です。単調な構造により、バイナリ検索が確実に収束します。pi = ai / (ai + λ) という形式の比により、ai が大きい場合でもすべての演算が浮動小数点で安定しているため、オーバーフローが防止されます。
