 ## 解決策
 ## 問題の理解

 このゲームでのランは次のシーケンスです。$n$すべて順番にクリアする必要があるレベル。 各レベルで、1 回の試行は確率で成功します。$1-p$または確率で失敗する$p$。 通常、失敗は厳しい結果をもたらします。プレーヤーは最初のレベルに戻され、すべてを最初からやり直す必要があります。 

ひねりを加えれば、$k$特別な「みかじめ料」。 通常、失敗によって再起動がトリガーされるたびに、1 チャージを消費してリセットを防ぐことができ、プレイヤーは同じレベルに留まって挑戦を続けることができます。 

プロセスはすべて完了するまで続行されます。$n$レベルは 1 つの中断のない進行で正常に完了します (リセットを防ぐ保護料金を法として)。 必要な量は、この完了が発生するまでに実行されるレベル試行の予想合計数です。 

入力はレベル数を与えます$n$、保護の数$k$、および失敗確率$p$。 出力は、予想されるレベル試行回数です。 

問題の規模がそれを自明ではないものにしている。 制約$n \le 10^5$に線形に依存する状態表現は直ちに除外されます。$n$二次遷移を伴う。 「現在のレベル × 残機」に関する単純なシミュレーションや完全なマルコフ連鎖は爆発するでしょう。 条件$np \le 20$は重要な構造上のヒントですが、$n$が大きい場合、完全に成功した実行で予想される失敗の数は少なくなります。つまり、失敗に対する分布の効果的なサポートは非​​常に限られています。 

主なエッジケースは次のような場合です。$k = 0$。 その後、失敗するたびに実行が再開され、プロセスは古典的な「取得までの予想時間」になります。$n$連続成功」の問題。$n = 5$、$p = 0.5$、正解は$62$、レベルを誤って独立して扱うソリューションでは、誤った出力が行われます。$5 / 0.5 = 10$。 

反対の極端な場合、$k$は非常に大きく、障害が発生しても実際には再起動が発生することはなく、プロセスはレベルごとに単純な幾何学的プロセスになります。 各レベルには予想される時間がかかります$1/(1-p)$試行回数の合計は次のようになります$n/(1-p)$。 正しい解は、明示的に「無限」に分岐することなく、この動作にスムーズに収束する必要があります。$k$”。

 ## アプローチ

 直接的な定式化により、実行の正確な状態、つまり現在のレベル、実行が再開されたかどうか、保護機能がいくつ残っているかが追跡されます。 各状態から、成功または失敗に応じて分岐します。 これは自然に動的計画法またはマルコフ連鎖システムにつながります。$O(nk)$州。 以来$k$と同じ大きさにすることができます$10^9$、これは不可能です。 

重要な観察は、全体的に重要なのは、実行が成功するまでに何回失敗が発生するかだけであるということです。 すべての障害は保護を消費するか、再起動をトリガーします。再起動は保護が使い果たされた場合にのみ発生します。 これは、プロセス全体の複雑さは、問題の「保護なし」バージョンにおける失敗の数の分布によって要約できることを意味します。 

いつ$k = 0$、このプロセスは十分に知られており、古典的な幾何学的実行に対応します。$n$連続成功。 これにより閉じた形式が得られます。 いつ$k > 0$、最初のものだけを気にします$k$障害が異なる動作をする。 それ以上の失敗は次のように動作します。$k = 0$追加の再起動が必要な場合。 なぜなら$np \le 20$、成功した実行中に約 20 を超える失敗が発生する確率質量は無視できるため、サイズが約 20 の切り捨てられた失敗空間について推論するだけで済みます。これにより、実効 DP 次元が から減少します。$k$最大でも20まで。 

次に、グローバル値に依存するレベルでの線形反復を維持しながら、「残りの保護」に対する階層化された DP を使用して期待値を計算します。$E[0]$。 これにより、保護層ごとに解決可能なシステムが生成されます。

 ## アルゴリズムのチュートリアル

 まず、有効な保護の数を次のように減らします。$K = \min(k, 20)$。 その理由は、成功した実行では、期待に意味のある影響を与える失敗の数が、次の式で暗示される定数によって制限されるためです。$np \le 20$。 

私たちは定義します$q = 1 - p$。 

私たちは保護の上に DP 層を維持します。 させて$E_j[i]$レベルを終了するために必要な予想試行回数を示します$i$いつ$j$保護は残っています。 

これらの層を次から計算します。$j = 0$上向きに。 

固定の場合$j$、私たちが表現したいのは、$E_j[i]$以下の観点から:

 1. 次のレベル$E_j[i+1]$試みが成功した場合。 
2. 同じレベル$E_j[i]$障害が発生したが、保護機能によって吸収された場合。 
3. すでに計算された前の層$E_{j-1}[i]$障害により保護が消費された場合。 

これにより再発が発生します。$$E_j[i] = 1 + qE_j[i+1] + p \cdot (\text{failure effect})$$のために$j = 0$、障害が発生すると完全な再起動が発生するため、次のようになります。$$E_0[i] = 1 + qE_0[i+1] + pE_0[0]$$のために$j \ge 1$、障害が発生すると、前の保護層に移行します。$$E_j[i] = 1 + qE_j[i+1] + pE_{j-1}[i]$$重要な構造的問題は、$E_j[i]$に依存します$E_j[0]$再起動 (または基本レベルの依存関係) が同じレイヤーにフィードバックされるためです。 各層を次の線形関数として表現することでこれを解消します。$X = E_j[0]$。 

固定の場合$j$では、次のように定義します。$$E_j[i] = A[i] + B[i] \cdot X$$私たちは計算します$A[i]$そして$B[i]$から後ろ向きに$i = n$に$0$。 

のために$j = 0$:$$A[i] = 1 + qA[i+1], \quad B[i] = qB[i+1] + p$$のために$j \ge 1$、前の層からの寄与は既知の定数配列です$C[i] = E_{j-1}[i]$:$$A[i] = 1 + qA[i+1] + pC[i], \quad B[i] = qB[i+1]$$計算後$A[0]$そして$B[0]$、次のように解決します。$$X = A[0] + B[0]X \Rightarrow X = \frac{A[0]}{1 - B[0]}$$これにより、$E_j[0]$、つまり全レイヤーです。 

これを全員に対して繰り返します$j \le K$、毎回前のレイヤーの完成した値を使用します。 

正確さは、各層の循環依存関係を線形固定小数点方程式に折りたたむことで得られます。 再発は未知の領域で難しい$E_j[0]$したがって、すべての状態はその単一の未知数の線形関数となり、反復収束なしでシステムを解決できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    p = float(input())
    q = 1.0 - p

    K = min(k, 20)

    # E_prev[i] = E_{j-1}[i]
    E_prev = [0.0] * (n + 1)

    for j in range(K + 1):
        A = [0.0] * (n + 1)
        B = [0.0] * (n + 1)

        A[n] = 0.0
        B[n] = 0.0

        if j == 0:
            for i in range(n - 1, -1, -1):
                A[i] = 1.0 + q * A[i + 1]
                B[i] = q * B[i + 1] + p
        else:
            for i in range(n - 1, -1, -1):
                A[i] = 1.0 + q * A[i + 1] + p * E_prev[i]
                B[i] = q * B[i + 1]

        if abs(1.0 - B[0]) < 1e-15:
            X = 0.0
        else:
            X = A[0] / (1.0 - B[0])

        E_curr = [0.0] * (n + 1)
        for i in range(n + 1):
            E_curr[i] = A[i] + B[i] * X

        E_prev = E_curr

    print(f"{E_prev[0]:.10f}")

if __name__ == "__main__":
    solve()
```このコードは、利用可能な保護の数に応じてソリューションを層ごとに構築します。 各層は、その層の未知の開始期待値に関して、各レベルからの期待コストの線形表現を構築します。 線形係数がわかったら、システムは 1 回の代入によって解決されます。 

確率構造により、高次の故障の影響が数値的許容範囲を超えて期待値に実質的な影響を与えないことが保証されるため、20 の保護への切り捨ては安全です。

 ## 特殊なケース

 いつ$k = 0$、失敗するたびに再起動が強制されます。 アルゴリズムは単一の DP 層に折りたたまれ、線形システムが完全な再起動フィードバックを取得します。$B[i]$係数。 たとえば、$n = 1$、$p = 0.5$、システムは次の結果をもたらします$E = 2$、幾何学的期待と一致します。 

いつ$k \ge 20$、切り捨ては、すべての意味のある障害の相互作用が保護された遷移として吸収されることを意味します。 DP は、あたかも再起動が、$np \le 20$。 このような場合、解はレベルごとの独立した期待値にスムーズに近づきます。$n/(1-p)$再起動のフィードバックは再発では残らないためです。 

いつ$n = 1$の場合、漸化式は、$k$失敗を拡大する再起動チェーンがないためです。
