 ## 解決策
 ## 問題の理解

 単一の整数が与えられます$n$ジェリーがコンテストに派遣している ICPC チームの数を表します。 各チームには 4,000 ドルの固定登録料が必要です。 このタスクは、すべてのチームを登録するために必要な合計金額を計算することです。 

入力にはこの 1 つのカウントを超える構造は含まれず、出力はチームごとの料金でスケーリングした後の合計コストのみです。 

制約$n \le 20$入力サイズが非常に小さいことを意味します。 これにより、効率に関する懸念がすぐに排除され、典型的な整数範囲でのオーバーフローも Python では問題になりません。また、固定幅整数言語でも最大値が制限されます。$20 \cdot 4000 = 80000$は些細なことです。 

注意すべき主なエッジケースは、可能な限り最小の入力です。 以来$n$は正の整数です。最小の場合は次のようになります。$n = 1$、4000 が生成されるはずです。$n$ゼロベースであるか、誤って追加の定数を追加すると、そのような場合にすぐに問題が発生します。 

## アプローチ

 ブルートフォース解釈では、文字通りチームごとに登録プロセスをシミュレートし、各チームに 4000 を追加します。 これは、合計をゼロに初期化してループするように見えます。$n$回、毎回 4000 ずつ増加します。 これは正しいです。各チームが独立した固定費を負担するため、累積は乗算と一致します。 

このアプローチは次のように実行されます。$O(n)$、これはすでに無視できます$n \le 20$。 ただし、問題の構造により、追加を繰り返す必要はありません。 和のすべての項が同一であるため、計算全体が直接乗算にまとめられます。$4000 \cdot n$。 変化する入力を処理するのではなく、一定のシーケンスを合計していることがわかります。そのため、反復を単一の算術演算に置き換えることができます。

 ## アルゴリズムのチュートリアル

 可能な限り最も直接的な方法で総コストを計算します。 

1. 整数を読み取る$n$入力から。 これは登録されているチームの数を表します。 
2. 総コストを次のように計算します。$n \times 4000$。 このステップでは、シミュレーションを行わずに、チームごとのコストの定義を直接適用します。 
3. 計算された値を最終的な答えとして出力します。 

### なぜ効果があるのか

 各チームは、他のチームとは独立して、ちょうど 4000 を寄付します。 したがって、総コストは次の合計となります。$n$同一の項。数学的には乗算と同じです。 条件付きルール、割引、チーム間のやり取りがないため、カウントのスケーリング以外に追加のロジックは必要ありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    print(n * 4000)

if __name__ == "__main__":
    solve()
```このソリューションは、単一の整数を読み取り、即座に 4000 を乗算します。`strip()`末尾の改行が整数の解析を妨げないようにします。 計算は単一の算術式であるため、ループや条件はなく、境界問題のリスクもありません。
