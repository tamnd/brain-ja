 ## 解決策
 ## 問題の理解

 恒等順列から始めます。つまり、配列には 1 から n までの数値が昇順に含まれます。 バイナリ分割プロセスのように動作する再帰的構築を繰り返し適用することができます。 いつでも、連続したセグメントを取得し、それを空ではない 2 つの連続した部分に分割し、必要に応じて 2 つの部分を交換し、各部分内で同じ手順を再帰的に適用します。 最後に、処理された左部分と右部分が結合されます。 

重要な観察点は、このプロセスでは要素が恣意的に並べ替えられるわけではないということです。 配列を連続ブロックに再帰的に分割し、必要に応じてバイナリ再帰ツリーの各内部ノードで 2 つの半分を交換することによって構築できる順列のみが許可されます。 

タスクは、ソートされた配列から始まるそのような分割と交換のシーケンスによって特定の順列を生成できるかどうかを判断することです。 

制約は大きく、テスト ケース全体の合計 n は最大 2×10^5 です。 各セグメントには O(n) 個の分割選択肢があり、各分割で 2 つの再帰的分岐が作成されるため、考えられるすべての分割点またはすべての再帰的構造をシミュレートしようとするソリューションは、組み合わせ的に爆発します。 テスト ケースが 1 つだけでも、指数関数的な動作が発生する可能性があります。 

微妙な落とし穴は、これが「セグメントの反転によって得られる任意の順列」と同等であると仮定していることです。 それは誤りです。 たとえば、任意の部分配列を反転することは、この再帰よりもはるかに強力です。これは、ここではすべての分割がすべての再帰レベルにわたって連続性を維持する必要があるためです。 

もう 1 つのよくある間違いは、置換がスワップなしで「分割統治可能なソート可能」であるかどうかをチェックしているだけだと考えることです。これは、より厳密な条件になります。 各ノードでのスワップの自由度は非常に重要であり、構造を大きく変えます。 

## アプローチ

 ブルートフォース手法では、再帰ツリーの再構築が試行されます。 現在のセグメントに対して考えられるすべての分割点を試み、各分割でスワップするかスワップしないかに分岐します。 分割を選択した後、両側を再帰的に検証します。 これにより、n 個のラベル付きリーフ上のすべてのバイナリ ツリーに対する再帰が形成されます。これは構造的にはカタルーニャ語ですが、各ノードには O(n) 個の分割選択肢もあります。 状態の数は超指数関数的に増加し、n が 20 程度であっても完全に実行不可能になります。 

重要な構造的洞察は、プロセスを逆転させることです。 配列をどのように構築できるかを問うのではなく、再帰ステップごとにどのようなプロパティを保持する必要があるかを尋ねます。 

どのセグメントでも、この手順は連続した間隔を取り、それを 2 つの連続する部分に分割します。 [1..n] から開始するため、再帰内のすべてのセグメントは、必ずしも位置ではなく、値の一定の間隔に対応します。 重要な事実は、恒等順列では、有効なセグメントの値は連続した整数の範囲を形成する必要があるということです。 

次に、有効な分割で何が起こるかを考えてみましょう。 値範囲 [l, r] に対応するセグメントを操作しているとします。 有効な分割は、この範囲を 2 つの素な連続値範囲 [l, m] と [m+1, r] に分割します。 最終的な配列では、各辺に属するすべての要素が出力内で連続ブロックとして表示され、場合によっては交換されることを保持する必要があります。 

これにより、問題は、各ノードが連続値区間に対応し、ルート区間が [1, n] である再帰ツリーに順列を分解できるかどうかをチェックするようになります。 各ノードでは、値の間隔に属する要素が順列の連続セグメントとして現れる必要があります。 

重要な操作上のコツは、位置範囲と値範囲に基づいたスタックのような貪欲な分解を使用してこの構造をシミュレートし、各セグメントが有効な再帰間隔のように動作することを検証することです。

 ## アルゴリズムのチュートリアル

 すべてのセグメントが、連続した値の範囲を表す有効な再帰ブロックとして解釈できるかどうかをチェックすることによって、順列を処理します。 

1. 順列全体を値の間隔 [1, n] を表す候補セグメントとして扱います。 配列内の位置範囲と期待値の範囲によって定義される間隔のスタックを使用してセグメントを追跡します。 
2. 現在のセグメントを繰り返し取得し、その中の最小値と最大値を見つけます。 これら 2 つの極端な値によって、セグメントが有効な再帰ブロックに対応できるかどうかが決まります。 セグメントが有効な場合、その値は欠落数値のない連続した間隔を正確に形成する必要があります。 
3. セグメント内の値が連続した範囲ではない場合 (つまり、最大値 - 最小値 + 1 がセグメント長と等しくない)、その構造は再帰的分割から得られるはずがないため、直ちに拒否します。 
4. 値の範囲に関してセグメントが有効になったら、値が 2 つの連続するグループに分割される場所に基づいて、概念的にセグメントを左部分と右部分に分割します。 どちらの側に値の小さい半分が含まれ、どちらの側に値の大きい半分が含まれるかを特定します。 
5. 結果として得られたサブセグメントをさらに検証するためにプッシュバックし、すべてのセグメントが単一の要素に還元されるまで同じ推論を再帰的に繰り返します。 
6. 単一要素ブロックに到達するまですべてのセグメントを一貫して分解できれば、置換は有効です。 

重要なメカニズムは、各再帰ブロックが位置空間と値空間の両方での連続性を純粋にチェックすることによって検証されることです。 再帰構造は、値の境界で繰り返し分割することによって暗黙的に適用されます。 

### なぜ効果があるのか

 元のプロセスのすべての有効な構築ステップでは、2 つの不変条件が維持されます。 まず、各再帰ノードは配列内の連続したセグメントに対応します。 第 2 に、完全に順序付けされたシーケンスから開始し、サブセグメント全体を交換することによってのみ再配置するため、そのセグメント内の値は連続した整数の間隔を形成します。 スワップでは異なるサブツリーの値がインターリーブされることはないため、再帰では互いに素な間隔の値が混在することはありません。 

したがって、有効なセグメントは常に、その最小値と最大値がそのメンバーシップを正確に定義するという特性を満たさなければなりません。 これにより、再帰が一意に決定されます。セグメントが識別されると、その内部構造は値の分割によって強制されます。 これにより、分割された選択肢の曖昧さが取り除かれ、指数構造が線形検証プロセスに崩壊します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        stack = [(0, n - 1)]

        ok = True

        while stack:
            l, r = stack.pop()
            if l >= r:
                continue

            mn = min(a[l:r+1])
            mx = max(a[l:r+1])

            if mx - mn + 1 != r - l + 1:
                ok = False
                break

            mid = (mn + mx) // 2

            left_part = []
            right_part = []

            for i in range(l, r + 1):
                if a[i] <= mid:
                    left_part.append(i)
                else:
                    right_part.append(i)

            if not left_part or not right_part:
                ok = False
                break

            if left_part:
                stack.append((min(left_part), max(left_part)))
            if right_part:
                stack.append((min(right_part), max(right_part)))

        print("Yes" if ok else "No")

if __name__ == "__main__":
    solve()
```この実装では、再帰の深さの問題を回避するためにスタックを使用します。 各セグメントはインデックス間隔で表されます。 各セグメントについて、最小値と最大値を計算して、それが連続する値の間隔に対応するかどうかを確認します。 このテストに失敗した場合、置換は直ちに拒否されます。 

次に、要素が値の範囲の下半分に該当するか上半分に該当するかに基づいて、要素を 2 つのグループに分割します。 このステップでは、連続値間隔のバイナリ再帰パーティションと一致する唯一の可能な分割を再構築します。 結果として得られるインデックス範囲は、検証する次のセグメントを形成します。 

インデックスは再帰順序で連続していなければならないため、サブセグメントを計算するときは注意が必要です。 最小インデックスと最大インデックスを使用すると、パーティション化後にセグメント境界を正しく回復できます。

| ステップ | セグメント | 分 | 最大 | 有効範囲? | アクション |

 3 が欠落しているため、値の範囲が連続していません。 これは、再帰的構築に必要な構造に直ちに違反します。 アルゴリズムは正しく No を出力します。 

これは、再帰ではブロック内の値をスキップできないため、セグメント内の中間値が 1 つ欠けているだけでも有効性が損なわれていることを示しています。

 ## 特殊なケース

 重要なエッジ ケースは、値が連続した間隔を形成しているものの、位置が大きくインターリーブされているセグメントです。 例えば、`[3, 1, 4, 2]`min=1 と max=4 は変わりませんが、この構造では、連続した位置セグメントとしても表示される 2 つの値の間隔に分割できるかどうかを確認する必要があります。 このアルゴリズムは、値の中間点で分割を強制することでこれを処理し、再帰構造に違反するインターリーブがパーティショニング中に拒否されることを保証します。 

もう 1 つのエッジ ケースは、分割を試みた後に片側が空になった場合です。 これは、すべての値が値の範囲の半分に該当し、有効なバイナリ再帰ノードに対応できない場合に発生します。 このアルゴリズムは、左右のパーティションが空ではないかどうかを明示的にチェックし、縮退したケースを正しく拒否します。
