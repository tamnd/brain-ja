 ## 解決策
 ## 問題の理解

 この問題では、単純なテキスト パターンを生成するように求められます。 印刷する必要がある行数を表す単一の整数 _n_ が与えられます。 最初の行には 1 つのアスタリスクが含まれ、2 行目には 2 つのアスタリスクが含まれるようになり、_n_ 行目に _n_ アスタリスクが含まれるまで続きます。 基本的に、出力は高さが _n_ の左揃えのアスタリスクの直角三角形です。 

入力制約は 1 ≤ _n_ ≤ 50 です。これは、_n_ が小さく、_n_ に対して線形または二次時間で実行される解はほぼ瞬時に実行されることを示しています。 ここではパフォーマンスの制限に達するリスクがないため、大きな入力サイズに対するアルゴリズムの最適化を考慮する必要はありません。 

微妙なエッジ ケースは、_n_ が 1 に等しい場合です。正しい出力は、アスタリスクが 1 つ付いた 1 行です。 ゼロから開始するループまたはオフバイワン ロジックを使用する不注意な解決策では、行がゼロになったり、単一のアスタリスクの出力に失敗したりする可能性があります。 同様に、_n_ = 50 が最大の入力であるため、最後の行には正確に 50 個のアスタリスクが含まれている必要があります。 ループ境界でカウントに誤りがあると、行が切り詰められたり、余分なアスタリスクが生成されたりする可能性があります。 

## アプローチ

 単純なアプローチは簡単です。1 から _n_ まで反復し、各反復 _i_ に対して _i_ アスタリスクを出力します。 これが機能するのは、各行が独立してそのインデックスのみに依存し、繰り返される文字の文字列の構築が Python の小さい _n_ に対する定数時間の操作であるためです。 ブルート フォース ソリューションの時間計算量は、合計 1 + 2 + … + _n_ (_n_(_n_+1)/2 に等しく) に比例します。 _n_ ≤ 50 の場合、これは最大でも 1275 文字の出力であり、これは現代のコンピューターでは取るに足らない量です。 

問題はすでに小規模であるため、これ以上の最適化は必要ありません。 重要な洞察は、各行の内容が 1 つの文字の単純な繰り返しであることを認識することです。これにより、文字列の乗算演算子を使用して Python でワンライナーが可能になります。 この問題にはデータ構造や再帰は必要ありません。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 承認済み |
 | 最適 | O(n^2) | O(n) | 承認済み |

 どちらのアプローチも同じ漸近的な複雑さを共有していますが、「最適な」バージョンでは文字列の繰り返しと直接出力を活用してコードを簡潔にしています。 

## アルゴリズムのチュートリアル

 1. 入力から整数 _n_ を読み取ります。 これは三角形の線の数を定義します。 
2. 1 から _n_ までの範囲で繰り返します。 ループ変数を _i_ とします。 
3. _i_ ごとに、_i_ アスタリスクで構成される文字列を生成します。 Python では、これは次のように行われます。`"*"`_i_ を掛けます。 
4. 生成された文字列を出力します。 各反復では 1 行が出力され、自動的に改行が追加されます。 

機能する理由: ループの不変条件は、反復 _i_ で正確に _i_ アスタリスクが出力されることです。 これにより、最後の反復の後、三角形が正しい形状になり、各行に 1 から始まるインデックスに対応する正確な数のアスタリスクが含まれることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

for i in range(1, n + 1):
    print('*' * i)
```コードは、高速 I/O を使用して入力を読み取ることから始まります。 入力文字列を整数に変換すると、ループが適切にバインドされることが保証されます。 の`for`ループは、1 から _n_ までの各行インデックスを反復し、正しい数のアスタリスクを含む文字列を生成し、それをすぐに出力します。 Python で文字列に整数を乗算すると、必要なパターンに一致する、文字が繰り返された新しい文字列が生成されます。 Off-by-one エラーは次の方法で回避できます。`range(1, n + 1)`の代わりに`range(n)`。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n^2) | 出力される文字の合計は 1 + 2 + … + n = n(n+1)/2、つまり O(n^2) です。 |
 | スペース | O(n) | 各行は、印刷する前に最大 n 文字を保存する必要があります。 |

 n ≤ 50 の場合、アルゴリズムは即座に実行され、使用されるメモリは無視できます。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    n = int(input())
    for i in range(1, n + 1):
        print('*' * i)
    return output.getvalue().strip()

# provided sample
assert run("3\n") == "*\n**\n***", "sample 1"

# custom cases
assert run("1\n") == "*", "minimum input"
assert run("50\n") == '\n'.join('*' * i for i in range(1, 51)), "maximum input"
assert run("2\n") == "*\n**", "small even number"
assert run("5\n") == "*\n**\n***\n****\n*****", "small odd number"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1 | * | 最小限の入力を処理します |
 | 50 | 1 行あたり 1 ～ 50 個のアスタリスク | 許可される最大行数を正しく印刷します。 
| 2 | *、** | 小さい偶数入力の正しい行数 |
 | 5 | *、**、***、****、***** | 小さい奇数入力の正しい行数 |

 ## 特殊なケース

 _n_ = 1 の場合、アルゴリズムは 1 回の反復を実行し、アスタリスクを 1 つだけ出力します。 これにより、コードが最小の入力を正しく処理していることが確認されます。 _n_ = 50 の場合、ループは 50 回実行され、各行には正しい数のアスタリスクが含まれます。 文字列にループ変数を乗算すると、off-by-one エラーは発生しません。 すべての行は、必要な順序を維持しながら順番に印刷されます。
