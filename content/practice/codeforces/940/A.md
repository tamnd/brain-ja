 ## 解決策
 ## 問題の理解

 数直線上に配置されたいくつかの点が与えられます。 各点は単なる単一の整数座標です。 残りのポイントの広がりが制御されるように、これらのポイントのサブセットを保持したいと考えています。具体的には、保持されている最大のポイントと最小のポイントの差が所定の制限を超えてはなりません。`d`。 

タスクは、サブセットを直接選択することではなく、残りの点が最大でもある長さの範囲内に収まるように、削除する必要がある点の最小数を決定することです。`d`。 

重要な観察は、残りのセットの左端と右端の点を決定すると、その間にあるすべてのものを並べ替えられた順序で保持できる可能性があるということです。 これにより、構造が本質的に 1 次元になり、順序付けが中心的なツールになります。 

制約は小さいです。`n ≤ 100`これにより、二次解も許容可能であり、ソートとその後のスキャンは容易に十分に高速であることがわかります。 指数関数的なサブセットなど、それを超えるものは不要ですが、入力サイズが小さいため、技術的にはまだ実現可能です。 

すべての点がすでに範囲 ≤ 内にある場合、微妙なエッジ ケースが発生します。`d`。 この場合、削除は必要ありません。 もう 1 つのエッジケースは次のような場合です`d = 0`。 この場合、同一の座標のみが一緒に残ることができます。これは、単一の値の最大頻度を効果的に探すことを意味します。 たとえば、入力`3 0`ポイント付き`1 2 1`2つを維持する必要があります`1`s を選択し、1 点を削除します。 

単純な間違いは、ソートせずに、またはすべての有効なウィンドウを考慮せずに、極端な点を貪欲に削除しようとすることです。 たとえば、現在の最小値または最大値を繰り返し削除すると失敗する可能性があります。これは、1 つの極端な値を削除すると、以前は有効だった別のウィンドウが最適化されなくなる可能性があるためです。 

## アプローチ

 この問題を考える強引な方法は、考えられる点のサブセットをすべて試して、その直径が最大以下であるかどうかを確認することです。`d`。 サブセットごとに、最小値と最大値を計算し、制約を検証します。 これはすべての可能性を検討するため正しいですが、次のような理由から計算上実行不可能です。`2^n`サブセット。 と`n = 100`、これは完全に爆発します。 

論点を整理すると、問題の構造は非常に単純になります。 ソート後、直径 ≤ の有効な点のセット`d`いくつかの要素を削除した後、このソートされた配列内の連続セグメントに対応する必要があります。 任意のサブセットを選択する代わりに、最大の連続ブロックを見つけるだけで済みます。`a[r] - a[l] ≤ d`。 これにより、問題は、古典的な 2 ポインタ パターンである差分制約を満たす最長のウィンドウを見つけることになります。 

制約を維持しながら、左ポインタをスライドさせ、右ポインタを可能な限り拡大します。 制約に違反するたびに、左ポインタを前方に移動します。 最大の有効なウィンドウが保持できる最大ポイント数を示します。答えは次のとおりです。`n - best_window_size`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | お(1) | 遅すぎる |
 | 並べ替え + 2 つのポインター | O(n log n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 点座標の配列を降順でない順に並べ替えます。 ソートにより、直径チェックを間隔の終点間の単純な差異に減らすことができるため、ソートは不可欠です。 
2. 2 つのポインタを初期化する`l = 0`そしてそれを繰り返す`r`左から右へ。 考え方は治療することです`r`候補有効セグメントの拡張エンドポイントとして。 
3. ポジションごとに`r`、現在のセグメントかどうかを確認します。`[l, r]`満足する`a[r] - a[l] ≤ d`。 これは、現在のサブセットの直径を直接表します。 
4. 条件に違反した場合は移動する`l`条件が再び有効になるまで前進します。 それぞれの増分`l`現在のウィンドウ内の最小の要素を削除します。これが、ソートされた配列の直径を縮小する唯一の方法です。 
5. 各ステップで、有効なウィンドウのサイズを計算します。`r - l + 1`そしてそのような最大サイズを追跡します。 これは、保持できる最大のサブセットを表します。 
6.すべての処理が完了したら`r`、答えを次のように計算します。`n - best_window_size`最適なウィンドウにないものはすべて削除する必要があるためです。 

### なぜ効果があるのか

 並べ替えにより、最小値と最大値を達成するサブセットが並べ替えられた順序で連続する範囲に対応することが保証されます。 2 ポインター プロセスでは、常に直径制約を満たすウィンドウが維持されます。 制約に違反した場合、有効性を回復する唯一の方法は、左側の境界を右に移動することです。これは、極値が変わらない限り、内部要素を削除しても最大値と最小値のギャップに影響を与えないためです。 これにより、最適な構成を見逃すことなく、すべての有効な候補ウィンドウが考慮されるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, d = map(int, input().split())
a = list(map(int, input().split()))

a.sort()

l = 0
best = 0

for r in range(n):
    while a[r] - a[l] > d:
        l += 1
    best = max(best, r - l + 1)

print(n - best)
```ソートのステップは、問題を単調シーケンス上のスライディング ウィンドウに変換するものです。 ソートを行わないと、直径条件は単純な左右差に対応せず、ツーポインタ法は失敗します。 

の`while`ループは、最良の回答を更新する前に、現在のウィンドウが常に有効であるという不変式を保証します。 重要なことは、`l`は前方にのみ移動するため、ポインタの移動の合計数は線形になります。 

## 実用的な例

 ### 例 1

 入力:```
3 1
2 1 4
```ソートされた配列:`[1, 2, 4]`| r | l | ウィンドウ | a[r] - a[l] | 有効 | 最高 |
 | --- | --- | --- | --- | --- | --- |
 | 0 | 0 | [1] | 0 | はい | 1 |
 | 1 | 0 | [1,2] | 1 | はい | 2 |
 | 2 | 1 | [2,4] | 2 | いいえ → l を調整します | 2 |

 いつ`r = 2`、窓`[1,2,4]`は無効です。`4 - 1 = 3 > 1`。 移動します`l`窓ができるまで`[2,4]`、これはまだ違反しているため、再び次のことに移ります。`[4]`。 

最終的な最適なウィンドウ サイズは`2`、したがって、答えは`3 - 2 = 1`。 

これは、最適解には必ずしも最小の要素が含まれるわけではないことを示しています。 これを削除すると、有効なより大きなセグメントのロックが解除される可能性があります。 

### 例 2

 入力:```
5 0
1 2 2 3 2
```ソートされた配列:`[1, 2, 2, 2, 3]`| r | l | ウィンドウ | a[r] - a[l] | 最高 |
 | --- | --- | --- | --- | --- |
 | 0 | 0 | [1] | 0 | 1 |
 | 1 | 1 | [2,2] | 0 | 2 |
 | 3 | 1 | [2,2,2] | 0 | 3 |
 | 4 | 2 | [2,3] | 1 > 0 → シフト l | 3 |

 最適な窓は、`3`、したがって、答えは`5 - 3 = 2`。 

これにより、`d = 0`case は、最も頻度の高い値を選択するように動作します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, d = map(int, input().split())
    a = list(map(int, input().split()))
    a.sort()

    l = 0
    best = 0

    for r in range(n):
        while a[r] - a[l] > d:
            l += 1
        best = max(best, r - l + 1)

    return str(n - best)

 ## 特殊なケース

 すべての点が同一の場合、ソートにより定数配列が生成され、ウィンドウは条件に関係なく常に条件を満たします。`d`。 このアルゴリズムはウィンドウをフル サイズに拡張し、ゼロの除去を正確に返します。 

いつ`d = 0`、等しい値のみが共存できます。 スライディング ウィンドウは自然に同じ番号のブロックに折りたたまれ、最大ウィンドウは任意の座標の最大周波数に正確に対応します。 

1 つの値が残りの値よりはるかに外側にある場合、並べ替えによってその値が一方の端に配置されます。 ウィンドウには一時的にそれが含まれますが、制約に違反するとすぐに縮小され、有効なセグメント内に収まらない限り確実に除外されます。
