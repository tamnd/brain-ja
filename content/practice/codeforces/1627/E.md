 ## 解決策
 ## 問題の理解

 建物は、各フロアが部屋の列である層状のグリッドとして見ることができます。 フロア内を水平方向に移動するには、歩いた距離に比例したコストとフロア固有のペナルティ係数がかかりますが、垂直方向の移動は、報酬も得られる可能性のある有向梯子を介してのみ可能です。 

このタスクは、1 階の左上の開始セルから最後の階の右下のセルまでの可能な限り最良の最終結果を計算することです。 床上のあらゆる水平方向の動き`i`費用`|j-k| * x_i`。 すべてのはしごは、下の階の部屋から上の階の別の部屋への有向エッジであり、利得に貢献します。`h_i`(したがって、総コストが効果的に削減されます)。 目標は、総コストを最小限に抑えること、または負の値が許可される場合は同等に利益を最大化することです。 一連の移動が目的地に到達しない場合、答えは「NO ESCAPE」です。 

この制約により、状態空間を完全なグリッド グラフとして扱うアプローチから遠ざかることになります。 全体にわたる直接最短経路モデル`(n * m)`両方の次元が到達できるため、ノードは不可能です`10^5`。 すべてのノードを保存することすら不可能です。 重要な観察は、垂直方向の移動は上方向にのみ行われるため、その構造は階層化された DAG であり、フロアを昇順に処理することを強く示唆しています。 

素朴な落とし穴は、あるフロアの部屋に到着したら、そこに到着した経緯とは関係なく、続行するための最善の方法があると思い込んでしまうことです。 これは誤りです。水平方向に移動するコストは移動を開始する場所によって異なるため、異なる「水平コンテキスト」で同じセルに到達すると、将来のコストが異なる可能性があります。 

もう 1 つの微妙なエッジ ケースは、独立した床です。 フロアに入ってくるはしごがなく、フロア 1 ではない場合、水平移動に関係なく、そのフロアには到達できません。 単純なグリッド緩和では、値が誤って割り当てられる可能性があります。 

最後に、大きな報酬を与えるはしごは、合計の答えがマイナスになる可能性があります。 これにより、コストは常に負ではないという前提が崩れ、負のエッジを慎重に処理しないとダイクストラが除外されます。 

## アプローチ

 ブルート フォース ビューは、すべてのセルが次のようなグラフを構築します。`(i, j)`ノードです。 各フロアが貢献`m`ノードと水平エッジは距離に比例した重みで同じフロア上のすべてのペアを接続しますが、はしごはエッジを上に向けます。 このグラフで最短経路アルゴリズムを実行するには、最大で次のことが必要になります。`n * m`ノードと`O(m^2)`明示的に実行すると、フロアごとのエッジが増加し、不可能なメモリと時間が必要になります。`10^10`。 

単一フロア内の構造は、簡素化の最初の重要な点です。 フロア上のいくつかのセルに到達するための最適なコストがすでにわかっている場合`i`、その後、同じフロア上の別のセルへの移行は、コスト関数が次のとおりであるため、2 つのスイープを使用して線形時間で処理できます。`|j-k| * x_i`に凸です`j`。 これは古典的な「直線上の距離変換」パターンです。 

2 番目の重要な洞察は、はしごは上向きにしか進まないということです。 これにより、フロアが順番に独立したものになります。つまり、フロアの処理が完了すると、その最もよく知られている値を後で再検討することなく上方に伝播することができます。 各フロアは DP のステージとなり、入ってくるラダーからの貢献をマージし、水平緩和を実行します。 

難しいのは、フロアが多くのはしごから値を受け取る可能性があるため、水平伝播を適用する前にそれらを効率的に結合する必要があることです。 これは、部屋ごとの最もよく知られているコストを維持し、フロアごとに一括して更新し、その後 2 パスのスイープを実行することで処理されます。

 | --- | --- | --- | --- |
 | ブルートフォースグリッドグラフ | O(nm + nm log(nm)) 以上 | O(nm) | 遅すぎる |
 | フロアごとに最適化されたレイヤード DP | O(アクティブなフロアごとに n + k + m) | O(m + k) | 承認済み |

 ## アルゴリズムのチュートリアル

 フロアを昇順に処理し、DP 配列を維持します`dp[j]`部屋に立つために最もよく知られているコストを表す`j`現在のフロアにあります。 

1. を除くすべての値を無限大に初期化します。`dp[1] = 0`1階にあります。 これは次から始まることを表します`(1,1)`費用はかかりません。 
2. 各フロアごと`i`、まず、このフロアで終わるすべてのはしごからの寄与を注入します。 はしごが到着したら`(i, d)`、改善に努めます`dp[d]`開始時から報酬を差し引いた最もよく知られているコストを使用する`h`。 このステップでは、水平方向の動きが考慮される前に、垂直方向の遷移が集約されます。 
3. すべてのラダー更新後、フロア内で水平伝播を実行します。 左から右方向にのみ移動する場合と、右から左方向に移動する場合は別々に、各部屋に到達するための最適なコストを計算します。 この 2 パス緩和により、コスト構造が正しく考慮されます。`|j-k| * x_i`なぜなら、段階的に進むと、まさに線形のペナルティが蓄積されるからです。 
4. 交換する`dp`水平緩和の結果、今から`dp[j]`フロアを完全に探索した後、可能な限り最高のコストを表します`i`。 
5.床まで繰り返します`n`。 答えは`dp[m]`それが有限である場合、そうでない場合、目的地に到達できません。 

水平ステップの正しさは、固定床では移動コストが線に沿ったスケーリングされたマンハッタン距離であるため、2 点間の最適なパスには単調な移動以外の中間迂回が必要ないという事実に依存します。 

### なぜ効果があるのか

 各フロアの境界で、`dp[j]`部屋に到達するための最低コストを表します`j`以前のすべてのフロアを完全に利用した後。 ラダーはフロア順序の非循環性を維持するため、フロアが処理されると、その後の操作でそのフロアに到達するためのより安価な方法を生成することはできません。 フロア内では、左右のジグザグを繰り返すと厳密にコストが増加するため、2 パス スイープにより、一連の水平移動が直接の最適な遷移に削減されます。 これにより、フロアによって圧縮された DAG にわたって一貫した最短パスの不変条件が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10**30

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        x = list(map(int, input().split()))
        
        ladders_in = [[] for _ in range(n)]
        for _ in range(k):
            a, b, c, d, h = map(int, input().split())
            a -= 1
            c -= 1
            b -= 1
            d -= 1
            ladders_in[c].append((a, b, d, h))
        
        dp = [INF] * m
        dp[0] = 0
        
        for i in range(n):
            new = dp[:]
            
            for a, b, d, h in ladders_in[i]:
                if dp[b] != INF:
                    val = dp[b] - h
                    if val < new[d]:
                        new[d] = val
            
            if i == 0:
                left = new[:]
            else:
                left = new[:]
                # left-to-right pass
                for j in range(1, m):
                    cost = left[j-1] + x[i] * 1
                    if cost < left[j]:
                        left[j] = cost
                
                # right-to-left pass
                for j in range(m-2, -1, -1):
                    cost = left[j+1] + x[i] * 1
                    if cost < left[j]:
                        left[j] = cost
            
            dp = left
        
        print("NO ESCAPE" if dp[m-1] == INF else dp[m-1])

if __name__ == "__main__":
    solve()
```DP 配列には、現在のフロアの部屋ごとの最もよく知られているコストが保存されます。 ラダー トランジションはフロア間をジャンプする唯一の方法であるため、最初に適用されます。 水平緩和では 2 つの線形スイープを使用し、それぞれの隣接位置をコストで更新します。`x[i]`、絶対値コストの単位距離拡張をエンコードします。 番兵`INF`到達不可能な状態が誤って遷移に寄与しないようにします。 

微妙な点は、すでに固定位置から開始しているため、はしごを適用する前に最初の床を水平に緩和する必要がないことです。 もう 1 つの重要な詳細は、リラックスする前に常に新しい配列にコピーすることで、ラダーの更新と水平方向の伝播が同じ反復で干渉するのを防ぎます。

    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    INF = 10**30
    t = int(input())
    out = []
    for _ in range(t):
        n, m, k = map(int, input().split())
        x = list(map(int, input().split()))
        ladders = [[] for _ in range(n)]
        for _ in range(k):
            a, b, c, d, h = map(int, input().split())
            a -= 1; b -= 1; c -= 1; d -= 1
            ladders[c].append((a, b, d, h))

        dp = [INF] * m
        dp[0] = 0

        for i in range(n):
            ndp = dp[:]
            for a, b, d, h in ladders[i]:
                if dp[b] != INF:
                    ndp[d] = min(ndp[d], dp[b] - h)

                left[j] = min(left[j], left[j+1] + x[i])

            dp = left

        res = dp[m-1]
        return "NO ESCAPE" if res == INF else str(res)

 ## 特殊なケース

 重大なエッジ ケースは、あるフロアにはしごを通ってのみ到達可能であるが、単一の柱を除いて以前は到達可能だった部屋から水平方向にアクセスできない場合です。 このような状況において、民進党ははしご緩和の前に時期尚早にコストを分散してはならない。 ラダーの更新が水平スイープの前に適用され、エントリ ポイントが伝播に確実に含まれるため、アルゴリズムはこれを処理します。 

もう 1 つのエッジ ケースは、はしごが非常に大きな報酬を提供するため、中間階がコストがかかるのではなく有益になる場合です。 DP では負の値が許容され、単調性が想定されていないため、これらの遷移は、許可された前方フロア順序内でのみ後方効果を正しく伝播します。 

最後に、到達不能なフロアはラダーフェーズと水平フェーズの両方を通じて INF のままとなり、後の計算への部分値の誤った漏洩を防ぎます。これは、「NO ESCAPE」を正しく生成するために不可欠です。
