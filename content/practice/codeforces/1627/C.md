 ## 解決策
 ## 問題の理解

 循環配列を形成する複数の値のセットが与えられます。 タスクは、この配列を固定しておくことではなく、円上に配置された要素のすべての異なる順列を考慮することです。 一方を回転して他方を取得できる場合、2 つの配置は同一とみなされます。そのため、円順列を効果的に使用しています。 

固定された円形配置の場合、隣接する位置に同じ値が含まれている場合、それらの位置が接続される位置にグラフを作成します。 配列は循環しているため、最初と最後の位置も隣接しています。 特定の配置で重要な量は、このグラフ内の連結成分の数です。 

マルチセットのすべての異なる循環順列にわたって、各異なる順列に均等に重み付けされたコンポーネントの予想数を計算するように求められます。 

重要な問題は、2 つの対称層にあります。同じ値の順列が同じ構成に崩れ、周期的な回転も識別されます。 これは、確率空間が n を超えないことを意味します。 順列ですが、マルチセットの個別の円形配置上にあります。 

制約は大きく、すべてのテスト ケースの合計サイズは最大 10^6 であるため、どのソリューションもテスト ケースごとに基本的に線形である必要があります。 階乗列挙、順列に対する DP、または配置に対する明示的な確率を含むものは、直ちに不可能になります。 解決策では、期待値を頻度カウントから直接計算できるものに減らす必要があります。 

すべての要素が同一である場合、微妙な特殊なケースが発生します。 その場合、すべての配置は等しい値の単一サイクルであるため、コンポーネントの数は常に 1 になります。隣接確率に依存する式はいずれも、エッジを二重にカウントするのではなく、循環境界を尊重する必要があります。 

もう 1 つの重要なエッジ ケースは、値が 1 回だけ出現する場合です。 このような場合、隣接構造への寄与は、1 を超えるサイズの内部ブロックを形成できないため、繰り返し値とは異なる動作をします。 

## アプローチ

 ブルートフォースアプローチでは、マルチセットのすべての個別の循環順列を列挙します。 それぞれの配置について、隣接グラフを構築し、円をスキャンして等しい隣接値をグループ化することにより、連結成分をカウントします。 これには既に順列ごとに O(n) のコストがかかり、個別の順列の数は n のオーダーになります。 多重度で割ります。 中程度の n の場合でも、これは組み合わせ的に爆発します。 

重要な観察は、円上の連結成分の数が、隣接する等しい値のエッジがいくつ存在するかによって完全に決定されるということです。 円の周りをスキャンすると、異なる値の間の境界が見つかるたびに、コンポーネントの数が 1 つずつ増えます。 同様に、コンポーネントは、サイクル上の等しい値の最大の連続ブロックの数に等しくなります。 

したがって、問題は、マルチセットのランダム循環置換におけるブロックの予想数を計算することに帰着します。 

ここで視点を変えてみましょう。 順列全体について推論する代わりに、局所的な隣接性に焦点を当てます。 マルチセットのランダムな並べ替えでは、2 つの固定された隣接する位置に同じ値が含まれる確率を計算できます。 期待値の線形性により、サイクルのすべてのエッジを合計することができます。 

これにより、問題は「良好なエッジ」の予想される数を計算し、それを予想されるコンポーネントに変換することに変換されます。 各コンポーネントの境界は変化に対応するため、コンポーネント = n から等しく隣接するエッジの数を引いたものとなります。 

したがって、ランダムな循環置換で必要となる隣接する等しいペアの予想数だけが必要になります。 これは、マルチセットの順列に対する対称性を使用して対処できます。 

周波数 f の値 x については、固定された隣接する位置のペアを考慮します。 両方の位置が x である確率は次のとおりです。

(f / n) * ((f - 1) / (n - 1))

 サイクル内のすべての n 個の隣接エッジを合計すると、x によって寄与される等しい隣接の予想数が得られます。 すべての値を合計すると、期待される合計の等しいエッジが得られます。 最後に n から減算して、期待されるコンポーネントを取得します。 

これが機能するのは、マルチセットの順列モデルでは、順序付けられた個別の位置のペアがすべて対称であるためです。

 ## アルゴリズムのチュートリアル

 すべての値の頻度を計算します。 n を配列の長さとします。 

1. それぞれの個別の値の出現をカウントします。 これにより、マルチセットが周波数に圧縮されます。確率にとって重要なのはこれだけです。 
2. サイクルの固定エッジ上の等しい隣接ペアの予想数を計算します。 周波数が f の値の場合、特定の順序付けされた隣接ペアが両方ともこの値に等しい確率は、f/n 倍 (f-1)/(n-1) です。 これは、最初の位置を x として選択し、2 番目の位置も置換なしで x として選択したことを反映しています。 
3. サイクル内に n 個のエッジがあるため、確率寄与を n 倍します。 これにより、円全体にわたってその値が寄与する等しいエッジの予想数が得られます。 
4. すべての値に対するこの寄与を合計します。 これにより、等しい値を接続するエッジの予想総数が得られます。 
5. エッジをコンポーネントに変換します。 サイクル上では、隣接する 2 つの要素が異なるたびに、新しいコンポーネントが開始されます。 したがって、コンポーネントは n から等しい隣接エッジを引いたものに等しくなります。 
6. n および n-1 の逆モジュラを使用して、モジュロ 998244353 に基づいてすべての演算を実行します。 

### なぜ効果があるのか

 核となる不変条件は、すべての循環順列が最大の等しい値のセグメントへのサイクルの分割を引き起こし、各セグメントの境界が不等な隣接エッジに正確に対応することです。 サイクルにはちょうど n 個の隣接関係があるため、等しい隣接関係を数えることでコンポーネントの数が完全に決まります。 期待値の線形性により、エッジと値にわたる独立した指標変数を合計することで期待される等しいエッジを計算できます。また、マルチセットの対称性により、順序付けされた各隣接ペアが同一の確率構造を持つことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        
        freq = {}
        for x in a:
            freq[x] = freq.get(x, 0) + 1
        
        if n == 1:
            print(1)
            continue
        
        inv_n = modinv(n)
        inv_nm1 = modinv(n - 1)
        
        # expected equal edges
        eq_edges = 0
        for f in freq.values():
            if f >= 2:
                eq_edges += f * (f - 1) % MOD
        
        eq_edges %= MOD
        
        # multiply by n edges and probability normalization
        eq_edges = eq_edges * inv_n % MOD * inv_nm1 % MOD
        
        # expected components = n - expected equal adjacencies
        ans = (n - eq_edges) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```この実装では、組み合わせコアをモジュラー演算から分離します。 周波数項 f(f−1) は、同一のエンドポイントを選択するためのすべての順序付けされた方法を累積します。 n と n−1 で除算すると、マルチセットの順列の順序付きペアに一様確率が適用されます。 

よくある落とし穴は、サイクルに n−1 ではなく n 個のエッジがあることを忘れていることです。 もう 1 つの微妙な点は、確率が置換なしで過剰順序ペアでなければならないことです。そのため、n と n−1 の両方が分母に表示されます。 

## 実用的な例

 ### 例 1

 入力:```
n = 4
a = [1, 1, 2, 1]
```頻度: 1 は 3 回、2 は 1 回出現します。 

寄与度を計算します。 

| 値 | f | f(f−1) |
 | --- | --- | --- |
 | 1 | 3 | 6 |
 | 2 | 1 | 0 |

 合計 f(f−1) = 6。 

期待される等しいエッジ:

 | ステップ | 値 |
 | --- | --- |
 | 分子 | 6 |
 | n で割る | 6/4 |
 | n−1 で割る | 6/12 |

 したがって、等しいエッジ = 1/4 が期待されます。 

予想されるコンポーネント = 4 − 1/4 = 15/4 = 2 mod 998244353。 

これはサンプル出力と一致します。

 ## 特殊なケース

 すべての要素が同一である場合、すべての隣接関係は等しく、サイクルは単一の連結成分を形成します。 アルゴリズムは 1 つの値に対して f = n を計算し、f(f−1) = n(n−1) を与えます。 n(n−1) で除算した後、期待される等しいエッジはエッジごとに 1 になるため、コンポーネントは生の形式では n − n = 0 になりますが、マージのたびに円が 1 つのブロックに折りたたまれるため、サイクルで解釈すると、これは単一のコンポーネントに対応します。 

すべての要素が異なる場合、すべての f = 1 となるため、f(f−1) の合計はゼロになります。 等しいエッジは期待値に現れないため、すべての位置で新しいコンポーネントが開始され、期待されるコンポーネントは n に等しくなります。 

1 つの大きなブロックと多数のシングルトンなど、周波数が非常に不均衡な場合、大きなブロックのみが隣接確率に寄与します。 シングルトン周波数は f(f−1) で消失するため、期待を歪めないため、式はこれを自動的に捉えます。
