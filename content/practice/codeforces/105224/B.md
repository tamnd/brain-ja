 ## 解決策
 ## 問題の理解

 私たちは時間の経過とともに変化する配列を維持しており、変更のたびに、配列を連続した部分に分割することに基づいて最適なスコアを計算するように求められる場合があります。 単一セグメントのスコアは、その最大値と最小値の差として定義され、完全なパーティションのスコアは、すべてのセグメントにわたるこれらの差の合計となります。 タスクは、この合計を最大化するパーティションを選択することです。 

操作は 2 つあります。 1 つの操作では範囲内のすべての要素に値を追加し、もう 1 つの操作ではその時点で可能な最適なパーティション値を求めます。 更新は潜在的に大きな連続セグメントを変更し、クエリはグローバルな最適化を要求するため、問題は基本的に、最適なセグメンテーションについて推論できるようにしながら、範囲のシフトに効率的に反応する構造を維持することです。 

制約は最大 100,000 要素と 100,000 操作に及ぶため、クエリごとに答えを最初から再計算するソリューションは遅すぎます。 クエリごとのリニア スキャンでも、最悪の場合は 10^10 の演算が発生します。 これにより、クエリごとにパーティション値を素朴に再計算するアプローチは即座に除外されます。 

微妙な点は、範囲はシフト値を更新しますが、更新された領域の外側の要素の相対的な順序を変更しないことです。 ただし、更新された範囲の境界内および境界を越えて、最適なパーティション構造は自明ではない方法で変化する可能性があります。 

いくつかの特殊なケースは見落とされがちです。 すべての要素が等しい場合、パーティションに関係なく、すべてのセグメントの値は 0 になるため、答えは常に 0 になります。 単純な欲張りセグメンテーションでは、更新後に消える局所的な変動に基づいて、誤って分割またはマージされる可能性があります。 もう 1 つの特殊なケースは、更新や分割に関係なく、答えが常に 0 になる単一要素の配列です。 最後に、負の値が問題となるのは、範囲の更新によって要素の値が相互に押し上げられるため、正数性や単調性に依存するメソッドは失敗するためです。 

## アプローチ

 直接的な総当たりアプローチは、配列の可能なすべてのパーティションを列挙し、各セグメントの最大値から最小値を引いた合計を計算することです。 これには、隣接する要素間にカット (2^(n-1) 個のパーティション) を配置するあらゆる方法を考慮する必要があります。 dp[i] をプレフィックス i の最良のスコアとして定義する動的プログラミングに限定したとしても、各遷移ではセグメントの最大値と最小値を計算するために以前のすべての j をスキャンする必要があり、単純に実行すると O(n^2) 個の遷移と遷移ごとに O(n) 回の作業が発生します。 これにより O(n^3) が得られ、最小値と最大値の範囲を維持するための最適化を行ったとしても、クエリごとに依然として O(n^2) のままです。 

重要な観察は、セグメントのスコアは最大値と最小値のエンドポイントのみに依存し、セグメントを分割しても合計スコアは増加するか、変化しないままに維持されるだけであるということです。 セグメント [l, r] を取得し、それを [l, k] と [k+1, r] に分割すると、合計スコアは (max1-min1)+(max2-min2) になります。 これは、極値を分離することで各セグメントの最小値と最大値を「リセット」できるため、範囲全体を 1 つのセグメントとして扱うよりも厳密に優れている可能性があります。 

これは、最適な分割が値のグループ化に関連しているため、極端な値ができるだけ早く分離されて有益であることを示唆しています。 問題を再解釈する有効な方法は、値で並べ替えるときに、隣接する要素間の差異が寄与するという観点から考えることです。連続する値間の大きなギャップはそれぞれセグメント境界になる可能性があり、合計スコアは、構造全体で利用できるそのようなギャップの数に密接に関係しています。

再構成後、問題は、値が配列に沿ってどのように分布するかを追跡し、範囲シフトをサポートする構造を維持することになります。 範囲更新では、セグメント内のすべての値が均等にシフトされ、そのセグメント内の内部差異は保持されますが、隣接するセグメントとの境界関係は変更されます。 これにより、各ブロックがその局所的な最大値と最小値に寄与するブロックのシーケンスとして配列の動的表現が維持され、ブロックの結合または分割は局所的な境界の比較のみに依存します。 

最適なソリューションでは、セグメント ツリーまたはバランスの取れた構造を使用して、各セグメントの最小値と最大値に加えて、最適な内部パーティショニングに関する追加情報を維持します。 範囲の更新は遅延伝播によって処理され、クエリはセグメント情報を結合してグローバルな最適値を再構築します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリごとに O(n · 2^n) または O(n^2) | O(n) | 遅すぎる |
 | 最適 (遅延伝播を使用したセグメント ツリー) | O(q log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各ノードがその間隔で最適なパーティション値を計算するのに十分な情報を保存するセグメント ツリーを構築します。 各ノードは、最適なパーティショニングを前提として、そのセグメント内の最小値、最大値、および達成可能な最良のスコアを維持します。 

1. 単一の要素に対応する各リーフ ノードについて、最小値と最大値を要素自体として初期化し、最良のスコアをゼロとして初期化します。 単一の要素セグメントは違いに寄与しないため、これは正しいです。 
2. 左と右の子を結合する内部ノードの場合、両方の子のグローバル最小値と最大値として最小値と最大値を計算します。 これが必要なのは、両方の子をカバーするセグメントは両方の半分にわたる極値を考慮する必要があるためです。 
3. 重要なステップは、結合されたセグメントの最良のスコアを計算することです。 2 つのケースを考えます。 左右の間をカットしません。その場合、スコアは単純に max(left+right) から min(left+right) を引いたものになります。 または、カットを許可します。その場合、スコアは最高(左) + 最高(右)になります。 これら 2 つの値の最大値を採用します。 これは、子間の境界が分割点として有益であるかどうかの決定を捕捉します。 
4. 範囲の更新には、遅延伝播を使用します。 セグメントに x を追加すると、最小値と最大値の両方が x ずつ増加しますが、セグメント内のすべての差異が保持されるため、内部の最高スコアは変化しません。 
5. クエリの場合、保留中の遅延更新がすべて適用された後、ルート ノードの最高スコアを返します。 これが機能するのは、ルートが完全な配列を表すためです。 

機能する理由: DP の構造により、考えられるすべてのパーティションがすべてのセグメント ツリー境界での二分決定に対応することが保証されます。 各ノードは、その境界で切断するかどうかをエンコードし、ツリー構造上の帰納法によって、すべての可能なセグメンテーションが表現されます。 遅延伝播が機能するのは、一様シフトが順序とすべての内部差異を保持するためです。そのため、セグメントの最適性は絶対値ではなく構造のみに依存します。 その結果、ノードを結合すると、達成可能な最大パーティション スコアの正確さが常に維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class Node:
    __slots__ = ("mn", "mx", "best")
    def __init__(self, mn=0, mx=0, best=0):
        self.mn = mn
        self.mx = mx
        self.best = best

class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.size = 4 * self.n
        self.mn = [0] * self.size
        self.mx = [0] * self.size
        self.best = [0] * self.size
        self.lazy = [0] * self.size
        self.build(1, 0, self.n - 1, arr)

    def pull(self, v):
        l, r = 2 * v, 2 * v + 1
        self.mn[v] = min(self.mn[l], self.mn[r])
        self.mx[v] = max(self.mx[l], self.mx[r])
        self.best[v] = max(self.best[l] + self.best[r],
                           self.mx[v] - self.mn[v])

    def apply(self, v, x):
        self.mn[v] += x
        self.mx[v] += x
        self.lazy[v] += x

    def push(self, v):
        if self.lazy[v] != 0:
            self.apply(2 * v, self.lazy[v])
            self.apply(2 * v + 1, self.lazy[v])
            self.lazy[v] = 0

    def build(self, v, l, r, arr):
        if l == r:
            self.mn[v] = self.mx[v] = arr[l]
            self.best[v] = 0
            return
        m = (l + r) // 2
        self.build(2 * v, l, m, arr)
        self.build(2 * v + 1, m + 1, r, arr)
        self.pull(v)

    def update(self, v, l, r, ql, qr, x):
        if ql <= l and r <= qr:
            self.apply(v, x)
            return
        self.push(v)
        m = (l + r) // 2
        if ql <= m:
            self.update(2 * v, l, m, ql, qr, x)
        if qr > m:
            self.update(2 * v + 1, m + 1, r, ql, qr, x)
        self.pull(v)

    def query(self):
        return self.best[1]

n, q = map(int, input().split())
a = list(map(int, input().split()))
st = SegTree(a)

for _ in range(q):
    tmp = list(map(int, input().split()))
    if tmp[0] == 1:
        l, r, x = tmp[1] - 1, tmp[2] - 1, tmp[3]
        st.update(1, 0, n - 1, l, r, x)
    else:
        print(st.query())
```The implementation keeps a segment tree where each node stores the minimum and maximum of its segment along with the best achievable partition value inside that segment. マージ ステップは重要な部分で、どちらがより良いスコアを与えるかに応じて、左右の間のカットを維持するか、単一のセグメントにマージします。 

遅延伝播により、範囲の増分が対数時間で適用されます。 重要な点は、定数シフトの追加は内部差には影響せず、絶対的な最小値と最大値のみに影響するため、更新の際に最良の値を最初から再計算する必要がないことです。 

## 実用的な例

 ### Example 1

 入力配列: [-1、3、-6、8]

 まずツリーを構築します。 

| ノード間隔 | 分 | 最大 | best |
 | --- | --- | --- | --- |
 | [0,0] | -1 | -1 | 0 |
 | [1,1] | 3 | 3 | 0 |
 | [2,2] | -6 | -6 | 0 |
 | [3,3] | 8 | 8 | 0 |
 | [0,3] | -6 | 8 | 計算された |

 フルセグメントの場合、分割するかどうかを決定します。 最適なパーティションは、最終的には強い値のギャップを中心に分割され、特に -6 と 8 が分離されます。 

After applying updates, range shifts move values uniformly, updating min and max while preserving internal structure.

 このトレースは、根本的な決定は、分割した方が 2 つの半分を結合するよりも多くの利点が得られるかどうかのみに依存していることを示しています。 

### 例 2

 配列 [1, 1, 1, 1] を考えてみましょう。 

すべてのノードは min = max = 1 であるため、すべてのセグメントは best = 0 になります。範囲に定数を追加する更新では、その範囲内の等価性が維持されるため、すべての最良の値はゼロのままになります。 ルートは、パーティショニングに関係なく常にゼロを返します。 

これにより、縮退した一様な場合の正しさが確認されます。

 ## 特殊なケース

 最大値と最小値の差を生成するための間隔の長さが存在しないため、単一要素の配列は常にゼロを生成します。 セグメント ツリーはリーフをゼロに等しい最適値で初期化します。最小値と最大値の両方が等しくシフトし、等価性が維持されるため、更新によってその事実が変更されることはありません。 

完全に均一な配列は、どのパーティションも有益ではないことを示しています。 すべてのノードの最小値と最大値は同一であるため、マージ ルールは常に、正のゲインが得られる場合にのみ分割を優先しますが、そのようなことは決して起こりません。 セグメント全体で均一なすべての更新の後、ルートはゼロのままです。 

以前の更新と重複する範囲の更新は、遅延伝播によって処理されます。 各更新は値をシフトするだけであるため、複数の更新を積み重ねると単純に遅延タグに蓄積され、プッシュにより、構造を最初から再計算することなく、子が一貫した変換を受け取ることが保証されます。
