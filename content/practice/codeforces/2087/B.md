 ## 解決策
 ## 問題の理解

 を含む競争力のあるゲームのショーマッチを企画するよう依頼されました。$2n$それぞれが独自のレーティングを持つ異なるプレーヤー。 重要な要件は、すべてのプレイヤーが自分のレーティングに最も近い別のプレイヤーとペアになることです。 より正確には、各プレーヤーには 1 人以上の「最高の対戦相手」がいます。これは、レーティングとの絶対的な差が最小限であるプレーヤーとして定義されます。 課題は、形成が可能かどうかを判断することです。$n$各ペアで両方の参加者がお互いの最良の対戦相手となるような、素のペア。 

入力は単純です: テスト ケースの数$t$、 に続く$t$テストケースブロック。 各テスト ケースが提供するのは、$n$とリスト$2n$評価。 最適な対戦相手の基準の下で完全なペアリングが存在する場合、出力は YES であり、それ以外の場合は NO です。 

制約は小さいです:$n$最大50まで上げることができるので、$2n \le 100$、評価は次のとおりです。$10^5$。 これは、たとえ$O(n^2)$アルゴリズムは制限時間内で快適に実行されますが、すべてをチェックするブルートフォースアプローチ$n!$可能なペアリングは実行不可能です。 

評価が分散され、最近傍がチェーンを形成するが、そのチェーンが完全に一致することができない場合、微妙なエッジ ケースが発生します。 たとえば、評価の場合`[1, 3, 5, 8]`、最も近いものをペアリングすると、`(1, 3)`そして`(5, 8)`。 ここで、3 の最良の相手は 1、5 の最良の相手は 3、8 の最良の相手は 5 です。 ペアリング`(1, 3)`そして`(5, 8)`動作しますが、試してみると`(1, 5)`そして`(3, 8)`、ペアリングに失敗します。 近接性によって要素を任意にペアにするだけの不注意なアプローチは、そのようなシーケンスでは失敗します。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのペアリング方法を生成します。$2n$プレーヤーを確認し、各ペアが相互に最適な対戦相手であるかどうかを確認します。 各ペアリングは完全一致として表すことができます。$(2n-1)!!$可能性。 のために$n = 50$、これは天文学的な大きさです。 ブルートフォースは概念的には正しさを保証するので機能しますが、組み合わせ爆発のため非現実的です。 

重要な洞察は、評価が並べ替えられるとき、最良の対戦相手の関係は局所的であるということです。 評価を並べ替えると、どのプレイヤーでも最も近い評価が隣接することが保証されます。 すべてのレーティングは個別であるため、すべてのプレイヤーには、絶対的な差を最小化する隣接するレーティングという最高の対戦相手が 1 人だけ存在します。 したがって、評価のリストを並べ替えて、隣接するプレーヤーをペアにするだけで十分です。 もし$2n$偶数であれば、プレーヤーをペアにすることができます`(a[0], a[1]), (a[2], a[3]), ..., (a[2n-2], a[2n-1])`。 このペアの各プレーヤーは、並べ替えられた順序で最も優れた対戦相手と隣接するため、相互性が保証されます。 隣接する評価間に最小限の違いがない場合、完全な一致は不可能です。 

この観察により、問題は隣接する差異の並べ替えとチェックに集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((2n)!/n!) | O(n) | 遅すぎる |
 | 並べ替え + 隣接ペアリング | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そしてのリスト$2n$明確な評価。 
3. 評価を昇順に並べ替えます。 並べ替えにより、最も近い評価が隣接することが保証されます。これは、評価の区別性によって保証されます。 
4. 隣接する評価のペアごとに`(ratings[2*i], ratings[2*i + 1])`、近隣との違いを確認してください。 もし`ratings[2*i+1] - ratings[2*i]`他のレーティングと比較して両方のプレーヤーにとって最小である場合、そのペアは有効です。 ソートによって隣接性が保証されるため、隣接するペアとの差分を確認するだけで済みます。 
5. すべての隣接するペアが最小差特性を満たしている場合、YES を出力します。 それ以外の場合は NO を出力します。 

機能する理由: 並べ替えにより、各プレーヤーの最近隣のプレーヤーがその直前または直後になることが保証されます。 並べ替えられたリスト内でプレーヤーを順番にペアリングすると、各プレーヤーが最も近い対戦相手と一致することが保証されます。 レーティングは個別であるため、各プレーヤーの最小の差は一意であり、隣接するレーティングで発生します。 この不変条件により、構築されたペアが相互の最良の対戦相手の要件を満たすことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()
        valid = True
        for i in range(0, 2*n, 2):
            # check if the left neighbor is closer than previous pair, or right neighbor
            left_diff = a[i+1] - a[i]
            if i > 0:
                prev_diff = a[i] - a[i-1]
                if prev_diff < left_diff:
                    valid = False
                    break
            if i + 2 < 2*n:
                next_diff = a[i+2] - a[i+1]
                if next_diff < left_diff:
                    valid = False
                    break
        print("YES" if valid else "NO")

if __name__ == "__main__":
    solve()
```このソリューションでは、まず、最も近い評価が隣接するように評価を並べ替えます。 次に、2 つのステップで反復して、各ペアとそのすぐ隣のペアの間の最小差分プロパティをチェックします。 これにより、各ペアが相互に最も優れた対戦相手で構成されることが保証されます。 境界チェックは、リストの末尾にある近隣にアクセスする際の範囲外エラーを防ぎます。
