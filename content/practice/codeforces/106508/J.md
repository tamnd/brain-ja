 ## 解決策
 ## 問題の理解

 整数のシーケンスが与えられ、その空でない部分シーケンスをすべて考慮するように求められます。 サブシーケンスごとに、その中のすべての要素の最大公約数とその中のすべての要素の最小公倍数という 2 つの値を計算します。 タスクは、これら 2 つの値が等しいという特性を持つサブシーケンスがいくつあるかを数えることです。 

この条件を解釈する便利な方法は、一連の数値が同一の gcd と lcm を持つことが何を意味するかを考えることです。 セットの gcd は常にセット内のすべての要素以下ですが、lcm は常にすべての要素以上です。 両方が一致するには、すべての要素が正確に同じ値にある必要があります。そうしないと、lcm が最小要素を厳密に超えるか、gcd が最大要素を下回ってしまうためです。 この観察により、問題は数理論的に重く見えるものから、等しい値をめぐる構造的な計数問題に変わります。 

入力は単純な整数の 1 つの配列であり、出力はこの条件下で有効なサブシーケンスの数です。 

制約の観点から見ると、重要な意味は、すべてのサブシーケンスに対して反復処理を行う余裕があるかどうかです。 約 10^5 までのサイズのシーケンスは、指数関数的な探索を即座に排除します。 複数のテスト ケースにわたって繰り返すと、最悪の場合、ペアの二次カウントでも速度が非常に遅くなります。 これにより、配列を周波数カウントに圧縮し、線形または線形に近い時間で動作するソリューションが実現します。 

gcd または lcm についてグローバルではなくローカルに推論しようとすると、微妙な失敗例が発生します。 たとえば、次のような配列では、`[2, 3, 4]`、素朴な試みでは、gcd と lcm が「たまたま一致した」場合、いくつかの混合部分列が機能する可能性があると考えるかもしれませんが、チェックすると次のことがわかります。 

後続`[2, 4]`gcd 2 と lcm 4 は等しくありません。`[2, 3, 4]`gcd 1 と lcm 12 があります。単一要素のサブシーケンスのみが機能します。 これは、異なる値が混合されると直ちに等価条件が破られることを裏付けています。 

もう 1 つのエッジ ケースは、すべての要素が同一である場合です。たとえば、`[5, 5, 5]`。 空でないすべてのサブシーケンスは機能するため、答えは次のようになります。$2^3 - 1 = 7$。 多重度をカウントすることを忘れたソリューションは、誤って 1 を返します。 

## アプローチ

 ブルートフォースアプローチは簡単に説明できます。 空ではないすべてのサブシーケンスを反復処理し、その要素を折り畳んで gcd と lcm を計算し、それらが一致するかどうかを確認します。 これは問題の定義に直接従うため、正しいです。 問題はサブシーケンスの数です。サイズの配列です。$n$もっている$2^n - 1$サブシーケンス、さらには$n = 40$これはすでに実行不可能になっていますが、$n = 10^5$完全に不可能にしてしまいます。 

重要な構造的洞察は、gcd と lcm が等しいと、サブシーケンス内のすべての要素が同一になるということです。 これが認識されると、問題は gcd や lcm の計算にまったく依存しなくなり、等しい値の各グループから空ではないサブセットを選択できる方法が何通りあるかを数えることになります。 値が表示された場合$f$場合によっては、それらの出現のサブセットが有効なサブシーケンスを形成し、$2^f - 1$選択肢。 

問題をサブシーケンスの列挙から頻度のカウントに削減します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n · n) | O(n) | 遅すぎる |
 | 周波数計数 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取り、それぞれの異なる数値が何回出現するかを数えます。 このステップでは、シーケンスを同一の値の同値クラスに圧縮します。これらのクラスが、有効なサブシーケンスを形成できる唯一の候補になります。 
2. 頻度のある個別の値ごとに$f$、その値のみを使用して空ではないサブシーケンスがいくつ形成できるかを計算します。 これは$2^f - 1$, 空の選択肢を除き、各出現箇所を含めることも除外することもできるためです。 
3. すべての個別の値にわたるこれらの寄与を合計します。 
4. 最終的な合計を答えとして返します。 

値ごとに独立して合計する理由は、2 つの異なる値を含むサブシーケンスは直ちに条件に違反するため、有効なサブシーケンスは値ごとにきれいに分割されるためです。 

### なぜ効果があるのか

 サブシーケンスは、そのすべての要素が同一である場合にのみ、gcd が lcm と等しいという条件を満たします。 2 つの要素が異なる場合は、次のようにします。$a < b$の場合、lcm は少なくとも$b$gcd が最大である間、$a$、したがって平等は不可能です$a = b$。 これにより、すべての有効なサブシーケンスが単一の値クラス内に完全に含まれるようになります。 このアルゴリズムは、これらのクラスを正確に列挙し、それぞれのクラス内の空でないサブセットをすべてカウントし、完全性を確保し、過剰カウントを防ぎます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    n = int(input().strip())
    arr = list(map(int, input().split()))
    
    freq = Counter(arr)
    
    ans = 0
    for v, f in freq.items():
        ans += (1 << f) - 1
    
    print(ans)

if __name__ == "__main__":
    solve()
```実装はその推論を直接反映しています。 頻度テーブルは配列を圧縮し、ビットシフトは`(1 << f)`効率的に計算する$2^f$。 1 を減算すると、空の部分列が削除されます。 構造引数によって混合値の部分列が完全に除去されるため、gcd または lcm の計算は必要ありません。 

実装の微妙な詳細は、代わりにビット シフトを使用することです。`pow(2, f)`これは浮動小数点のオーバーヘッドを回避し、整数のべき乗のための競技プログラミングの標準です。

 ## 特殊なケース

 すべての要素が同一の場合、次のようになります。`[10, 10, 10]`、アルゴリズムはすべてをカウントします$2^3 - 1$後続。 頻度マップは頻度 3 の単一エントリを生成し、計算により空ではないすべてのサブセットが正しく集計されます。 

すべての要素が異なる場合、たとえば、`[1, 2, 3, 4]`、各周波数は 1 であるため、それぞれが寄与します。$2^1 - 1 = 1$。 結果は 4 で、単一要素のサブシーケンスのみが有効であるという事実と一致します。 

支配的な値と多くの希少な値がある場合、`[5, 5, 5, 1, 2]`、アルゴリズムは寄与を値によって明確に分離し、無効な混合サブシーケンスが考慮されないようにします。
