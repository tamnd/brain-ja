 ## 解決策

 ## 問題の理解

 2 つの幾何学的図形が与えられ、それぞれが平面内の 4 つの隅の点によって記述されます。 それらの 1 つは軸に沿った正方形であり、その辺が座標軸に平行であることを意味します。 もう 1 つは、45 度回転した正方形です。これは、その辺が軸に沿って配置されておらず、グリッドに対してダイヤモンド型を形成していることを意味します。 

各正方形は、その 4 つの頂点のリストとして境界に沿って順番に提供されます。 順序は一貫しているため (時計回りまたは反時計回り)、エッジは連続するポイントを接続し、最後のポイントは最初のポイントに戻ります。 

タスクは、これら 2 つの正方形が少なくとも 1 つの点を共有しているかどうかを判断することです。つまり、1 つの点で接触している場合、または一方が他方の完全に内側にある場合、両方とも交差としてカウントされます。 

座標範囲は -100 ～ 100 と非常に小さく、オブジェクトは 2 つだけあり、それぞれに 4 つの頂点があります。 これは、多くの点にわたって 3 次複雑さ、さらには 2 次複雑度の高い解は不要であることを直ちに示唆しています。 定数因数幾何学的推論または直接セグメント交差チェックで十分です。 

微妙な点は、「交差」には境界接触が含まれることです。 頂点またはエッジに沿ってのみ接触する 2 つの正方形も、交差しているものとしてカウントされます。 厳密な内部オーバーラップのみをチェックする単純なアプローチでは、これらのケースが誤って拒否されてしまいます。 

もう 1 つのよくある落とし穴は、両方の正方形の軸の位置合わせに依存できると仮定していることです。 軸が揃っているのは 1 つの正方形だけです。 もう一方は 45 度の任意の向きを持つことができます。 両方の軸に長方形が整列していると仮定するメソッドは失敗します。 

一般的に誤ったソリューションを破壊するエッジケースには、次のようなものがあります。 

1 つの正方形がもう 1 つの正方形の中に完全に収まります。たとえば、軸が揃った正方形の内側の中心に回転した正方形です。 この場合、交差するエッジはありませんが、内側の正方形のすべての頂点が外側の正方形の内側にあります。 

回転した正方形の先端が軸に揃えられた正方形の側面に触れるなどの単一点タッチ。 この場合、セグメント内部は重なりません。 

頂点が他の正方形のエッジ上に正確に位置する、縮退したように見える状況。交差として扱う必要があります。 

## アプローチ

 ブルートフォース幾何学的アプローチは、各正方形を 4 つの線分のセットとして扱うことから始まります。 最初の正方形のすべてのセグメントと 2 番目の正方形のすべてのセグメントの交差をチェックできます。 各セグメント間のチェックは、方向テストを使用して一定時間行われます。 正方形ごとにエッジが 4 つしかないため、これはすでに制限内で機能しており、最大でも 16 セグメントの比較が可能です。 

ただし、このブルートフォースはすでに十分に効率的ですが、すぐに封じ込めには対応しません。 1 つの正方形がもう 1 つの正方形の内側に完全にある場合、どのエッジも交差しないため、ポイントの包含もチェックしない限り、アルゴリズムは誤って「いいえ」を返します。 これにより追加のレイヤーが追加されます。1 つの正方形の各頂点について、それが他の多角形の内側にあるかどうかをテストする必要があります。 

重要な観察は、両方の形状がちょうど 4 つの頂点を持つ凸多角形であるということです。 凸多角形の場合、交差するかどうかは、エッジが交差するかどうか、または一方の多角形にもう一方の多角形の頂点が含まれるかどうかという 2 つの条件をチェックすることによって完全に決定できます。 これが機能するのは、凸多角形がエッジ交差せずに重なる場合、一方が他方を完全に包含する必要があるためです。 

これにより、問題は一定の時間内で行われる少数の固定数の方向テストとセグメント テストに軽減されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |

 | ブルート フォース セグメント + ポイント チェック | お(1) | お(1) | 承認済み |
 | 最適な凸多角形の交差 | お(1) | お(1) | 承認済み |

実際には、ここでは両方とも漸近的に同じですが、構造化された凸多角形の推論により、包含ケースの欠落が回避されます。 

## アルゴリズムのチュートリアル

 1. 各正方形の 4 つの頂点を読み取り、順番に保存します。 この順序により、連続する点がエッジを定義することが保証されます。 
2. 関数を定義する`orient(a, b, c)`外積符号を計算して、点が次の点であるかどうかを判断します。`c`左、右、または有向線上にあります`ab`。 これは、すべての幾何学的推論の中核となるプリミティブです。 
3. 関数を定義する`on_segment(a, b, c)`ポイントかどうかを検出する`c`セグメント上に正確に位置します`ab`。 これにより、境界接触のケースが明示的に処理されます。 
4. 2 つのセグメント間のセグメント交差チェックを定義します。 2 つのセグメントは、それらの端点が互いの支持線の反対側にある場合、またはいずれかの端点がもう一方のセグメント上にある場合に交差します。 
5. 最初の正方形の 4 つの端すべてを 2 番目の正方形の 4 つの端すべてと比較して確認します。 いずれかのエッジのペアが交差する場合は、直ちに正方形が交差していると結論付けます。 
6. 交差するエッジがない場合は、凸多角形の一貫した方向チェックを使用して、最初の正方形の頂点が 2 番目の正方形の内側または境界上にあるかどうかをチェックします。 
7. 同じ包含チェックを反対方向に繰り返し、2 番目の正方形の頂点が最初の正方形の内側にあるかどうかをテストします。 
8. エッジの交差も包含も見つからない場合は、正方形は交差していないと結論付けます。 

各ステップが必要な理由は、凸多角形が正確に 3 つの方法で重なる可能性があるためです: エッジの交差、完全な包含、または交差せずに境界に接触する。 各ケースは、上記のチェックのいずれかによって捕捉されます。 

### なぜ効果があるのか

 両方の正方形は凸多角形です。 凸多角形の場合、その交差部分が空でない場合、境界が交差するか、一方の多角形がもう一方の多角形の完全に内側に位置します。 境界の交差はセグメント間チェックによってキャプチャされ、包含はポリゴン内の頂点チェックによってキャプチャされます。 すべての可能性がカバーされているため、両方の条件が満たされない場合は、セットが素であることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def orient(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def on_segment(ax, ay, bx, by, cx, cy):
    return min(ax, bx) <= cx <= max(ax, bx) and min(ay, by) <= cy <= max(ay, by) and orient(ax, ay, bx, by, cx, cy) == 0

def seg_inter(a, b, c, d):
    ax, ay = a
    bx, by = b
    cx, cy = c
    dx, dy = d

    o1 = orient(ax, ay, bx, by, cx, cy)
    o2 = orient(ax, ay, bx, by, dx, dy)
    o3 = orient(cx, cy, dx, dy, ax, ay)
    o4 = orient(cx, cy, dx, dy, bx, by)

    if o1 == 0 and on_segment(ax, ay, bx, by, cx, cy): return True
    if o2 == 0 and on_segment(ax, ay, bx, by, dx, dy): return True
    if o3 == 0 and on_segment(cx, cy, dx, dy, ax, ay): return True
    if o4 == 0 and on_segment(cx, cy, dx, dy, bx, by): return True

    return (o1 > 0) != (o2 > 0) and (o3 > 0) != (o4 > 0)

def inside(poly, p):
    x, y = p
    n = 4
    for i in range(n):
        x1, y1 = poly[i]
        x2, y2 = poly[(i + 1) % n]
        if orient(x1, y1, x2, y2, x, y) < 0:
            return False
    return True

sq1 = list(map(int, input().split()))
sq2 = list(map(int, input().split()))

poly1 = [(sq1[i], sq1[i+1]) for i in range(0, 8, 2)]
poly2 = [(sq2[i], sq2[i+1]) for i in range(0, 8, 2)]

for i in range(4):
    for j in range(4):
        if seg_inter(poly1[i], poly1[(i+1) % 4], poly2[j], poly2[(j+1) % 4]):
            print("YES")
            sys.exit()

for p in poly1:
    if inside(poly2, p):
        print("YES")
        sys.exit()

for p in poly2:
    if inside(poly1, p):
        print("YES")
        sys.exit()

print("NO")

包含チェックでは、凸多角形のすべてのエッジにわたって一貫した符号テストが使用されます。 頂点が順番に与えられるため、点が常にすべての有向エッジの同じ側にある場合、その点は多角形の内側にあります。 

有効な交差点であれば十分であるため、最初に検出された交差点での早めの退出は安全です。

 ## 特殊なケース

 One important case is full containment, where the rotated square lies entirely inside the axis-aligned square. In this situation, no edge intersections occur. たとえば、正方形`(0,0)-(5,0)-(5,5)-(0,5)`含まれています`(1,1)-(4,1)-(4,4)-(1,4)`。 このアルゴリズムはセグメント チェックに失敗し、内側の正方形の各頂点を外側の正方形と比較して評価します。 各方向テストはすべてのエッジに対して負ではない値を返すため、包含チェックは true を返し、最終的な答えは「YES」になります。 

2 番目のケースは、単一点タッチです。 一方の正方形の頂点がもう一方の正方形のエッジ上に正確に位置する場合、方向はゼロになり、`on_segment`トリガー。 This ensures that cases like`(0,0)-(2,0)-(2,2)-(0,2)`そして`(2,2)-(3,2)-(3,3)-(2,3)`重複する領域がない場合でも、正しく「YES」を返します。 

3 番目のケースは完全な分離です。 正方形が遠く離れている場合、すべての方向テストはすべてのエッジの符号に一貫性があり、セグメントの交差はトリガーされません。 少なくとも 1 つのエッジがテスト ポイントを間違った側に認識しているため、両方の包含チェックが失敗し、曖昧さのない「NO」が得られます。
