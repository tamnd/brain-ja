 ## 解決策
 ## 問題の理解

 配列としきい値が与えられます`x`。 可能なすべての整数に対して`k`から`0`に`n`、正確にいくつのサブ配列があるかを数える必要があります。`k`厳密に以下の要素`x`。 各サブ配列は正確に 1 つのサブ配列に寄与します`k`、その要素の数がしきい値を下回るかどうかに応じて異なります。 

このタスクについて考えるもう 1 つの方法は、考えられるすべてのセグメントをスライドさせることです。`[l, r]`そして、セグメントごとに 1 つの値、つまり、そのセグメント内で以下の要素の数を計算します。`x`。 出力は、すべての部分配列にわたるこの値の頻度分布です。 

制約`n ≤ 2 · 10^5`すべての部分配列を明示的に列挙するソリューションは直ちに除外されます。 くらいあります`n(n+1)/2`サブ配列、次数です`2 · 10^10`最悪の場合。 サブ配列ごとに 1 つのカウンターを計算するだけでも、2 秒の制限をはるかに超えてしまいます。 

問題の構造は、実際には次の値以上の要素の値を気にしないことを示唆しています。`x`, except in how they partition or shift counts. これは、配列を各要素が次のようなバイナリ シーケンスに圧縮できることを示す強力なヒントです。`1`もし`a[i] < x`そして`0`さもないと。 次に、問題は合計によって部分配列をカウントすることに帰着します。 

すべての要素が以下の値以上である場合、微妙なエッジケースが発生します。`x`。 その場合、すべてのサブ配列には`k = 0`したがって、答えは次のようになります。`n(n+1)/2`のために`k = 0`それ以外の場合はゼロ。 少なくとも 1 つの要素が以下のものであると仮定する単純な実装`x`周波数構造を構築するときに、この均一なケースを誤ってスキップする可能性があります。 

もう 1 つのエッジ ケースは、すべての要素が以下の場合です。`x`。 その後、すべてのサブ配列が貢献します`k = length of subarray`したがって、分布は三角形になります: 正確に`n - k + 1`それぞれのサブ配列`k`。 

## アプローチ

 ブルートフォース手法では、すべてのサブ配列が列挙されます。`[l, r]`、以下の要素の数を計算します。`x`セグメントをスキャンし、その値に応じてカウンターをインクリメントします。`k`。 これは定義に直接従うため、正しく機能します。 ただし、各サブアレイにはコストがかかります`O(n)`最悪の場合は時間がかかり、`O(n^3)`単純に実装した場合の全体的な複雑さ、または`O(n^2)`すべての部分配列を列挙するため、カウント用のプレフィックス合計を使用した場合でも。 

重要な観察は、配列をバイナリ配列に変換した後です。`b[i] = 1`もし`a[i] < x`そして`0`それ以外の場合、各部分配列の値は単にセグメントの合計になります。 したがって、タスクは、可能な合計がそれぞれいくつのサブ配列にあるかを数えるようになります。 

これは古典的な畳み込み問題です。 配列を定義すると`f`どこ`f[i] = 1`すべてのプレフィックスの合計値について、合計を持つサブ配列の数`k`はプレフィックス合計のペアの数です`(i, j)`そのような`pref[j] - pref[i] = k`。 これは、プレフィックス合計の周波数配列とそれ自体の反転バージョンの畳み込みとして書き直すことができます。 

畳み込みとして表現すると、FFT ベースの多項式乗算を使用してすべての周波数を同時に計算できます。`O(n log n)`時間。 The size of prefix sums is`n+1`なので、大まかに長さの配列を構築します`2n`畳み込み結果を安全に受け入れるため。

 ## アルゴリズムのチュートリアル

 1. 入力配列を、各要素が次のようなバイナリ配列に変換します。`1`厳密に以下の場合`x`、 さもないと`0`。 この変換により、すべての部分配列について関心のある量が正確に保存されます。 
2. このバイナリ配列に対してプレフィックスの合計を構築します。 各接頭辞の合計は、以下の要素の数を表します。`x`そのインデックスまで存在します。 
3. 周波数配列を構築する`cnt`どこ`cnt[v]`プレフィックス合計値の倍数です`v`が発生します。 プレフィックスの合計の範囲は次のとおりです。`0`に`n`。 
4. プレフィックスの合計のペアを数えることとして問題を解釈します`(i, j)`そのような`pref[j] - pref[i] = k`。 このような各ペアは、正確に次の部分配列に対応します。`k`より小さい要素`x`。 
5. このカウントを畳み込みとして再定式化します。`cnt`それを元の配列と畳み込み、結果として得られる配列は、プレフィックスの合計間のすべての差のカウントを示します。 
6. FFT ベースの多項式乗算を使用して、この畳み込みを効率的に計算します。`O(n log n)`時間。 
7. すべての結果を抽出する`k`から`0`に`n`、これはサブ配列の数に正確に対応します。`k`より小さい要素`x`。 

### なぜ効果があるのか

 各サブアレイ`[l, r]`プレフィックスインデックスのペアに一意に対応します`(l-1, r)`。 未満の要素の数`x`その部分配列には`pref[r] - pref[l-1]`。 したがって、すべての有効な部分配列は、その差が次の値に等しい、順序付けられたプレフィックス合計のペアを 1 つだけ提供します。`k`、そのようなペアはすべて、正確に 1 つの部分配列を定義します。 この 1 対 1 の対応により、プレフィックスの合計の差をカウントすることが、サブ配列をカウントすることと同等であることが保証されます。 

畳み込みステップは、すべてのプレフィックス合計にわたるそのようなすべてのペアごとの差を同時に集計するだけです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import numpy as np

def fft_convolve(a, b):
    fa = np.fft.rfft(a)
    fb = np.fft.rfft(b)
    fc = fa * fb
    res = np.fft.irfft(fc)
    return np.rint(res).astype(np.int64)

def solve():
    n, x = map(int, input().split())
    arr = list(map(int, input().split()))

    b = [1 if v < x else 0 for v in arr]

    pref = [0] * (n + 1)
    for i in range(n):
        pref[i + 1] = pref[i] + b[i]

    cnt = [0] * (n + 1)
    for v in pref:
        cnt[v] += 1

    rev = cnt[::-1]

    conv = fft_convolve(cnt, rev)

    # conv index shift: we want differences pref[j] - pref[i]
    # reverse convolution gives centered differences at offset n
    offset = n
    ans = [0] * (n + 1)

    for k in range(n + 1):
        ans[k] = int(conv[offset + k])

    print(*ans)

if __name__ == "__main__":
    solve()
```### コードの説明

 バイナリ変換により、各要素の関連する機能のみが分離されます。 次に、プレフィックス合計は、すべてのサブ配列カウントを 2 つのプレフィックス状態の差としてエンコードします。 

周波数配列`cnt`各プレフィックス合計が発生する頻度をカウントします。複数のインデックスが同じプレフィックス合計値を共有できるため、これは不可欠です。 この配列を反転すると、畳み込みでプレフィックス値間のすべての差異を自然に計算できるようになります。 

FFT 畳み込みはすべてのペアごとの積をまとめて計算し、インデックス シフトによって畳み込み出力が調整されるため、インデックスが`n + k`差分に相当する`k`。 

浮動小数点 FFT 出力を解釈するときは注意が必要です。 畳み込み結果には数値誤差が蓄積されるため、最も近い整数への丸めが必要です。

 ## 特殊なケース

 すべての要素が以上の場合`x`、バイナリ配列はすべて 0 になります。 プレフィックスの合計はゼロで一定であるため、`cnt[0] = n+1`。 次に、畳み込みにより単一の非ゼロ値が生成されます。`k = 0`、部分配列の数に等しい`n(n+1)/2`、期待される結果と一致します。 

すべての要素が未満の場合`x`、バイナリ配列はすべて 1 になります。 プレフィックスの合計は厳密に増加するシーケンスを形成し、畳み込みは考えられるすべての差にわたってカウントを均等に広げ、三角形構造を生成します。 それぞれ`k`正確に受け取ります`n-k+1`その合計を生成する長さの部分配列の数と一致する寄与。
