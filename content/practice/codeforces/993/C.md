 ## 解決策
 ## 問題の理解

 私たちには 2 組の敵船が与えられ、すべてが 2 本の垂直線上に横たわっています。1 つのグループは 2 つの位置に固定されています。$x=-100$、もう一方は$x=100$。 各船には整数があります$y$- 座標、複数の船が同じものを共有する場合があります$y$。 

垂直線上のどこにでも 2 隻の友軍艦を配置できます$x=0$、彼らの選択$y$- 自由に調整できます (整数である必要はありません)。 すべての敵の船は同時に 2 つのレーザー光線を発射します。1 つは最初の味方の船に、もう 1 つは 2 番目の味方の船に向けてです。 各レーザー光線は、敵艦から始まり、選択された味方位置を通過し、その先まで続く真っ直ぐな無限の半線です。 

レーザー光線がその位置を通過すると、船は破壊されます。 課題は 2 つのポジションを選択することです。$x=0$破壊された敵船の総数が最大化されるようにします。 

制約は小さく、片側あたり最大 60 隻です。 これにより、すべての幾何学的構成を徹底的に調べたり、継続的な最適化を試みたりするようなことは即座に排除されます。 任意の位置の光線交差をシミュレートしようとするソリューションは、構造を活用しないとすぐに複雑になりすぎます。 

重要な微妙な点は、破壊はどちらかの側に局所的に起こるものではないということです。 左側の船は、選択した点との共線性を通じて間接的に右側の船を破壊することができ、その逆も同様です。 この 2 つの側の結合により、単純な計算が壊れる傾向があります。 

いくつかの特殊なケースでは、典型的な間違いが明らかになります。 

片側のすべての船が同じものを共有している場合$y$そして、両方の味方の船を同じ場所に配置します$y$の場合、すべての光線が水平になり、カバレッジが最大になります。 それぞれの側を独立して扱う単純な解決策では、選択された両方の点が同じ光線のセットを通じて相互作用することを見逃してしまう可能性があります。 

もう 1 つの失敗例は、対称構成によって重複する線が作成される場合に発生します。 2 つの異なる左側の船が同じ右側の船に当たる光線を生成した場合でも、その右側の船は 1 回だけカウントされる必要があります。 ユニオンロジックが慎重に扱われない限り、船ごとの貪欲なカウントは結果を過大評価します。 

最後に、両方の味方の船が同じ場所に配置されている場合、$y$、問題は単一点構成にまで悪化します。 2 つの位置が異なると仮定した解決策では、この最適なケースを逃すことになります。 

## アプローチ

 強引な解釈は、2 隻の船の可能な配置をすべて試すことから始まります。$x=0$。 以来$y$は実数であり、これは連続的ですが、ジオメトリにより意味のあるイベントが特別な値に制限されます。右の船が左の船の光線に当たるのは、3 つの点が同一線上にある場合にのみであり、選択された値が強制されます。$y$次の形式の線形方程式を満たす値$$y = \frac{y_i + y_j}{2}.$$これは、有限数の候補位置のみが重要であることを示唆していますが、候補を離散化した後でも、位置のすべてのペアを試して幾何学的交差を最初から再計算すると、$O(C^2 \cdot n \cdot m)$このアプローチは、高度に最適化された場合にのみ許容されます。 

重要な構造的観察は、選択された各位置が独立して反対側の破壊された船のセットを決定するということです。 固定位置の場合$a$、左の船ごとに$(-100, y_i)$何もしないか、右側の 1 つだけをヒットする一意の行を定義します。$y$-座標、つまり$y_j = 2a - y_i$。 これは、各候補位置が、他の船から独立して、反対側に破壊された船の決定的なサブセットを生成することを意味します。 

これにより、問題は 2 つの候補を選択することになります。$a$そして$b$、そこではそれぞれが反対側の破壊された船のセットを提供し、私たちは連合を獲得します。 同じ推論が対称的に当てはまります。 

すべての候補位置が 2 つのビットマスク (左から右への効果と右から左への効果) に削減されると、すべてのペアをチェックし、ビット演算によって和集合をとることによって最終的な答えが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース連続ジオメトリ | 無限 / 未定義 | お(1) | 使用不可 |
 | 再計算によりすべてのペアを離散化 | O(C²・n・m) | お(1) | 遅すぎる |
 | 候補ごとの事前計算されたビットマスク | O(C² · (n + m)) | O(C · (n + m)) | 承認済み |

 ## アルゴリズムのチュートリアル

 問題を候補の有限セットに圧縮します$y$-味方の船の座標。 これらにはすべての入力が含まれます$y$- 値とすべての中間点$(y_i + y_j)/2$これは共線性条件から発生する可能性があります。 

候補者が決定したら、各候補者がどのように行動するかを事前計算します。 

1. 候補ポジションのリストを作成します。 これらにはすべてのオリジナルが含まれます$y$- 両側とすべての値からの座標$(y_i + y_j)/2$有効な幾何学的配置として表示される場合があります。 これにより、最適な配置が検索空間内に確実に表現されます。 
2. 各候補者について$c$、左側の船を使用して右側での効果を計算します。 左の船ごとに、$y_i$、暗黙の右側のヒット位置を計算します。$y_j = 2c - y_i$。 この値が正しい艦船に存在する場合、候補のビットマスクで破壊済みとしてマークします。$c$。 これにより、多対 1 マッピングが単一の共用体構造に圧縮されます。 
3. 同様に、各候補について計算します。$c$右側のシップを使用して左側にその効果を与え、再びビットマスクを構築します。 
4. 次に、順序付けされた候補のペアをすべて検討します。$(a, b)$。 破壊された右側の船の合計は、次の値に対応する 2 つのビットマスクを結合することによって取得されます。$a$そして$b$。 左側についても同じことが行われます。 
5. 最終的な答えは、破壊された左側と右側の船の合計のすべての候補ペアの最大値です。 

### なぜ効果があるのか

 各候補位置は決定論的な幾何学的制約を引き起こします。つまり、左の船は選択した点ごとに多くても 1 隻の右の船に衝突することができ、その関係は方程式によって完全に把握されます。$y_j = 2c - y_i$。 これは、候補者のすべての影響が、敵座標の離散的な集合に対する集合メンバーシップ問題に崩壊することを意味します。 

破壊は、船を通過する少なくとも 1 つの光線の存在として定義されるため、2 つの位置を結合することは、これらのセットを結合することに正確に対応します。 最終的なビットマスクのメンバーシップを超えて、個々の左船間の相互作用を追跡する必要はなく、情報を失うことなく正確さが保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    L = list(map(int, input().split()))
    R = list(map(int, input().split()))

    # compress right/left y-values into indices
    R_idx = {y: i for i, y in enumerate(R)}
    L_idx = {y: i for i, y in enumerate(L)}

    # candidate set: all original y-values + midpoints
    cand = set(L + R)
    for y1 in L:
        for y2 in L:
            cand.add((y1 + y2) / 2)
    for y1 in R:
        for y2 in R:
            cand.add((y1 + y2) / 2)

    cand = list(cand)

    # bitmasks
    RL = [0] * len(cand)  # left -> right
    LR = [0] * len(cand)  # right -> left

    # precompute effects
    for ci, c in enumerate(cand):
        # left to right
        for y in L:
            y_r = 2 * c - y
            if y_r in R_idx:
                RL[ci] |= 1 << R_idx[y_r]

        # right to left
        for y in R:
            y_l = 2 * c - y
            if y_l in L_idx:
                LR[ci] |= 1 << L_idx[y_l]

    best = 0
    C = len(cand)

    for i in range(C):
        for j in range(i, C):
            right_mask = RL[i] | RL[j]
            left_mask = LR[i] | LR[j]
            best = max(best, right_mask.bit_count() + left_mask.bit_count())

    print(best)

if __name__ == "__main__":
    solve()
```この実装では、まず幾何学的相互作用をビットマスクに圧縮して、各候補位置が事前計算された「破壊プロファイル」のように動作するようにします。 制約の下では候補数が少ないままであるため、候補に対するネストされたループは許容されます。 

最もデリケートな部分は中間の構造です。 これがなければ、最適な位置合わせは左から右または右から左の反射条件が満たされたときに正確に行われることが多いため、一部の最適な位置は決してテストされません。 

破壊は純粋にセットベースであるため、交差を再計算する代わりにビットマスク ユニオンが使用されます。船を通過する光線の数に関係なく、船が命中されるか否かのどちらかです。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    n, m = map(int, input().split())
    L = list(map(int, input().split()))
    R = list(map(int, input().split()))

    R_idx = {y: i for i, y in enumerate(R)}
    L_idx = {y: i for i, y in enumerate(L)}

    cand = set(L + R)
    for a in L:
        for b in L:
            cand.add((a + b) / 2)
    for a in R:
        for b in R:
            cand.add((a + b) / 2)

    cand = list(cand)

    RL = [0] * len(cand)
    LR = [0] * len(cand)

    for i, c in enumerate(cand):
        for y in L:
            if 2 * c - y in R_idx:
                RL[i] |= 1 << R_idx[2 * c - y]
        for y in R:
            if 2 * c - y in L_idx:
                LR[i] |= 1 << L_idx[2 * c - y]

    ans = 0
    for i in range(len(cand)):
        for j in range(i, len(cand)):
            ans = max(ans, (RL[i] | RL[j]).bit_count() + (LR[i] | LR[j]).bit_count())

    return str(ans)

 ## 特殊なケース

 すべての船が同じ位置にある場合、縮退ケースが発生します。$y$。 その状況では、すべての候補が同一のマスクを生成し、どのペアを選択しても同じ結果が得られます。 ビット単位の OR では人為的な重複が発生しないため、アルゴリズムはこれを自然に処理します。 

最適な位置合わせに入力に存在しない中点が必要な場合には、別のケースが発生します。 たとえば、左側の艦艇が 0 と 10 で、右側の艦艇が 5 の場合、有効な候補は次のようになります。$y=2.5$。 中点生成ステップにより、この値が確実に含まれるようになり、対応する共線性を検出できるようになります。 

最後の微妙なケースは、選択した両方の船が同一である場合です。 このアルゴリズムでは区別性が強制されず、ペア ループには当然のことながら次のものが含まれます。$i=j$これは、有効なポジションが 1 つだけ使用される状況を正確にモデル化します。
