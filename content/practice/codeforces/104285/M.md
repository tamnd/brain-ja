 ## 問題の理解

このステートメントには 2 つの構造上の制約が隠されています。 まず、真の整数$n$は 100 未満の素因数のみで構成されます。これは、次の因子空間の境界を定めます。$n$素数の固定有限集合に変換します。 2番、$k$の除数の数と等しくなければなりません$n$、これは完全に素因数分解の指数によって決まります。 課題は、どちらの値の正確な桁も分からず、それぞれが真実とちょうど 1 桁異なることだけがわかっていることです。

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Precompute primes under 100
def sieve(n=100):
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    for i in range(2, n):
        if is_prime[i]:
            for j in range(i*i, n, i):
                is_prime[j] = False
    return [i for i in range(2, n) if is_prime[i]]

PRIMES = sieve(100)

def factorize(num_str):
    # convert large string to integer via repeated division
    # since primes are small, we simulate division manually
    n = int(num_str)
    exps = {}
    for p in PRIMES:
        if p * p > n:
            break
        if n % p == 0:
            cnt = 0
            while n % p == 0:
                n //= p
                cnt += 1
            exps[p] = cnt
    if n > 1:
        exps[n] = exps.get(n, 0) + 1
    return exps

def divisor_count(exps):
    res = 1
    for e in exps.values():
        res *= (e + 1)
    return res

def mutate_all(s):
    res = set()
    s = list(s)
    for i in range(len(s)):
        original = s[i]
        for d in '0123456789':
            if i == 0 and d == '0':
                continue
            if d == original:
                continue
            s[i] = d
            res.add(''.join(s))
        s[i] = original
    return res

def mutate_k(s):
    res = set()
    s = list(s)
    for i in range(len(s)):
        original = s[i]
        for d in '0123456789':
            if i == 0 and d == '0':
                continue
            if d == original:
                continue
            s[i] = d
            res.add(''.join(s))
        s[i] = original
    return res

T = int(input())
for _ in range(T):
    n_str, k_str = input().split()

    n_cands = mutate_all(n_str)
    k_cands = mutate_k(k_str)
    k_set = set(k_cands)

    best_n = None
    best_k = None

    for ns in n_cands:
        exps = factorize(ns)
        k_val = divisor_count(exps)
        if str(k_val) in k_set:
            if best_n is None or int(ns) < int(best_n):
                best_n = ns
                best_k = str(k_val)

    print(best_n, best_k)
```この解決策では、まず、両方の可能性のあるすべての 1 桁の補正を構築します。$n'$そして$k'$。 次に、素因数分解から導出された約数と数の関係を強制することにより、候補をフィルタリングします。 

重要な実装の詳細は、ミューテーション中に数値を文字列として扱いますが、因数分解の場合にのみ整数に変換することです。 これにより、算術演算を単純に保ちながら、100 桁の数値の精度の問題が回避されます。 最小値の比較$n$Python の整数は任意の精度を処理するため、これは安全です。
