 ## 解決策
 ## 問題の理解

 私たちは、アルファベットの上に文字列として書かれた DNA 鎖を与えられています。`{A, T, C, G}`。 生物学は、相補鎖を構築するための正確な変換規則を与えてくれます。まず、2 本の鎖が反対方向に走るため、元の配列を逆にしてから、固定されたペアリング規則を使用して各ヌクレオチドを置き換えます。`A ↔ T`そして`C ↔ G`。 

タスクは、テスト ケースごとにその変換を正確にシミュレートすることです。 入力は複数の独立した DNA 文字列を提供し、それぞれに対して 5' 末端から 3' 末端に現れるのと同じ左から右の方向に相補鎖を出力する必要があります。 

制約は十分小さいため、テスト ケースごとの線形変換で十分です。 各文字列の長さは最大 100 で、テスト ケースは最大 2000 個あるため、ケースごとの単純な O(n) ソリューションでも制限内で快適に実行できます。 処理される文字の総数は最大 200,000 ですが、Python ではこれはわずかです。 

実装でつまずく可能性がある唯一の微妙な点は、逆転の手順を忘れることです。 元に戻さずに置換を適用するだけの単純な解決策では、有効に見える DNA 文字列が生成されますが、方向が間違っています。 

たとえば、次の場合`s = "ATCG"`を直接代入すると、`"TAGC"`ですが、正しい手順は最初に逆になります。`"GCTA"`次に、に置き換えます`"CGAT"`。 

もう 1 つの考えられる間違いは、置換後に取り消しを適用することです。 また、補完によって位置ではなくシンボルが変更されるため、演算の順序が固定されるため、誤った結果が得られます。 

## アプローチ

 ブルート フォース解釈では、逆文字列を明示的に構築し、マッピング ルールを適用して再度反復処理を行います。 これはすでに線形時間であり、変換が純粋にローカルであるため機能します。反転された文字列内の位置が判明すると、各文字は独立してマップされます。 

文字列を末尾から先頭まで直接反復してその場で結果を構築する場合、これを単一パスと考えることもできます。 これにより、明示的な反転コピーが不要になります。 

重要な観察は、変換がインデックスの順列 (逆順) と文字の置換という 2 つの独立したコンポーネントに分解されることです。 どちらも要素あたり O(1) であり、順序を超えて相互に依存しないため、それらを単一のパスに融合できます。 

ブルート フォース方式では、文字列ごとに 2 回の線形スキャンが実行されます。 最適化されたバージョンは 1 つを実行しますが、漸近的に両方とも O(n) になります。 改善点は主に定数係数の単純化です。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、文字列を読み取ります。`s`。 この文字列は、5' 末端から 3' 末端までの 1 本の DNA 鎖を表します。 
2. ヌクレオチド間のマッピングを準備します。`A → T`、`T → A`、`C → G`、`G → C`。 これは生物学的なペアリング ルールをエンコードし、各キャラクターに独立して適用されます。 
3. 文字列を最後の文字から最初の文字までたどります。 これにより、新しい反転文字列を構築せずに、反転ステップが暗黙的に実行されます。 
4. 逆方向のトラバーサル中に検出された各文字について、マッピングを使用して置換し、結果を出力バッファに追加します。 
5. すべての文字を処理した後、構築された文字列を出力します。 

明示的に逆にするのではなく、逆の順序で反復する理由は、正確さを維持しながら余分なメモリ割り当てを回避するためです。 反転後は各位置が独立しているため、変換のストリーミングは同等です。 

### なぜ効果があるのか

 DNA 変換は 2 つの機能の組み合わせです: 順列`P`インデックスと置換を逆にする`C`各文字をマッピングします。 なぜなら`C`点単位で動作し、近傍やグローバル構造、構成に依存しません。`C(P(s))`は、並べ替えられたインデックス順序に対する 1 回の走査で両方の操作を適用することで計算できます。 これにより、すべての文字が正しい最終位置に 1 回だけ変換されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    mp = {
        'A': 'T',
        'T': 'A',
        'C': 'G',
        'G': 'C'
    }

    out = []
    for _ in range(t):
        n = int(input())
        s = input().strip()

        res = []
        for i in range(n - 1, -1, -1):
            res.append(mp[s[i]])
        out.append("".join(res))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```このソリューションは、直接文字マッピングを構築し、各文字列を右から左に処理します。 ループオーバー`i = n-1 ... 0`暗黙的に反転を実行します。 各文字は、辞書検索 (O(1)) を使用して 1 回変換されます。 結果は効率化のためにリストに蓄積され、テスト ケースごとに 1 回結合されます。 

の使用`strip()`末尾の改行がインデックス作成を妨げないようにします。 繰り返しの書き込みを避けるために、出力はバッファリングされます。

 ## 特殊なケース

 次のような単一文字入力の場合`A`、アルゴリズムはインデックス 0 を読み取り、それを直接マッピングします。`T`、生成します`"T"`。 反転は単一の要素には影響を及ぼさないため、正しさは有効なままであるマッピング テーブルのみに依存します。 

のような入力の場合`ATCG`、走査順序は次のようになります。`G → C → T → A`。 各文字は独立してマッピングされ、`C → G`、`G → C`、`T → A`、`A → T`に連結されます`"CGAT"`。 これは、反転が反復方向によって暗黙的に処理され、別の配列を必要としないことを確認します。
