 ## 解決策
 ## 問題の理解

 入力は、以下で構成される三角格子を記述します。$n$層。 各レイヤーには小さな三角形領域の行が含まれており、すべての小さな三角形が 3 つの境界セグメントに寄与します。 これらのセグメントの一部はすでに「充電」状態ですが、他のセグメントはまだ充電されていません。 目標は、すべてのセグメントを有料にすることです。 

許可される唯一の操作は、エネルギー ルーンストーンを 1 つの小さな三角形に配置することです。 そうすることで、その三角形の 3 つの辺すべてが即座に充電されます。 各配置には 1 つのコストがかかり、複数の配置が適用範囲内で重複する場合があります。 

したがって、タスクは個々のエッジを直接切り替えることではなく、すべての非帯電セグメントがそれに付随する少なくとも 1 つの選択された三角形によってカバーされるように三角形のサブセットを選択することです。 答えは、選択する必要がある三角形の最小数です。 

構造が重要です。三角形は正三角形グリッドを形成し、各内部エッジはちょうど 2 つの三角形によって共有され、境界エッジはちょうど 1 つの三角形に属します。 この非対称性が、決断を迫られる主な原因となっています。 

制約$n \le 500$小さな三角形の総数が次のオーダーであることを意味します。$n^2$、 だいたい$250{,}000$。 より近い解決策はどれか$O(n^2)$または$O(n^2 \log n)$許容されますが、立方体的なものは何でも$n$それ以上の場合は直ちに実行不可能になります。 

微妙な問題が境界エッジに現れます。 境界セグメントが帯電していない場合、隣接する単一の三角形を選択することによってのみ修正できます。 この強制的な構造を無視すると、誤った過小カウントまたは過大カウントが発生します。 

多くの強制的な選択が重なった場合、別の重要なケースが発生します。 たとえば、1 つの三角形を強制すると複数の境界欠陥がカバーされる場合、単純に貪欲にカウントすると二重にカウントされたり、残りの問題構造が変化するという事実を見逃したりする可能性があります。 

## アプローチ

 この問題を直接考える方法は、各三角形を選択するかどうかという決定変数として扱うことです。 それぞれの非帯電エッジには、その入射三角形の少なくとも 1 つを選択する必要があるという制約が課されます。 これは古典的なカバー処方です。 

ブルートフォース手法では、三角形のすべてのサブセットを列挙し、すべての非帯電エッジがカバーされているかどうかをチェックします。 まで$250{,}000$三角形、これは$2^{250000}$、完全に不可能です。 

より構造化された観点は、これを、ノードが三角形であり、内部セグメントを共有する 2 つの三角形をエッジが接続するグラフ上の頂点カバー問題として扱うことです。 各内部エッジには、少なくとも 1 つの終点三角形を選択する必要があります。 境界エッジは、常に「覆われていない」ダミーの固定ノードに接続されたエッジのように動作し、隣接する三角形が強制的に選択されます。 

境界制約から強制選択を削除した後に残るのは、三角形の隣接グラフ上の頂点カバーの問題です。 重要な観察は、三角形が方向 (上向き三角形と下向き三角形) によって色付けされ、すべての隣接が反対方向を接続するため、このグラフが 2 部構成であるということです。 これにより、問題は 2 部頂点カバー問題に変わり、最大マッチングを使用して解決できます。 

したがって、この戦略は、まず境界制約に起因するすべての強制選択を解決し、その影響をグラフから除去してから、ケーニッヒの定理を使用して残りの 2 部グラフの最小頂点カバーを計算することです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | サブセットに対するブルート フォース |$O(2^{n^2})$|$O(n^2)$| 遅すぎる |
 | 二部マッチングの削減 |$O(VE)$または$O(E\sqrt V)$|$O(V+E)$| 承認済み |

 ## アルゴリズムのチュートリアル

 ### ステップ 1: グリッドをグラフとしてモデル化する

 それぞれの小さな三角形がノードになります。 2 つの三角形が内部セグメントを共有する場合、それらをエッジで接続します。 このエッジは制約を表します。少なくとも 1 つのエンドポイントを選択する必要があります。 

境界セグメントは他の三角形へのエッジを作成しません。 代わりに、単一ノードに対する制約のように動作します。 

### ステップ 2: プロセス境界制約

 帯電されていないすべての境界セグメントについて、隣接する三角形のみを選択する必要があります。 このような三角形を強制としてマークします。 

三角形が強制されると、そのエッジに関係するすべての制約が自動的に満たされるため、それらのエッジは後で無視できます。 

### ステップ 3: 満たされた制約を削除する

 強制三角形が選択されると、それらが接触するすべてのエッジが満たされたとみなされます。 検討から削除させていただきます。 残っているのは、残りのすべての制約に 2 つの強制されていない三角形が含まれる縮小されたグラフです。 

### ステップ 4: 二部構成を活用する

 残りの三角形の隣接グラフは、方向に基づいて 2 つのセットに色分けできます。 すべての隣接エッジは反対方向に接続するため、グラフは 2 部構成になります。 

これにより、問題は 2 部グラフの最小頂点カバーを見つけることに変換されます。 

### ステップ 5: 最大一致に変換する

 ケーニッヒの定理により、頂点カバーの最小サイズは、2 部グラフの最大一致サイズと等しくなります。 そこで、残りのグラフに対して 2 部マッチング アルゴリズムを実行します。 

### ステップ 6: 結果を結合する

 最終的な答えは、強制された三角形の数に、残りのグラフで計算された最小頂点カバーのサイズを加えたものになります。 

### なぜ効果があるのか

 非チャージの各エッジは、少なくとも 1 つの終点三角形の選択を必要とする制約になります。 境界拘束は強制的な頂点の包含に減ります。 強制された頂点を削除した後、残りの制約はすべて 2 値かつ 2 部構成になります。つまり、すべてのインタラクションが頂点カバーの定式化によって正確にキャプチャされます。 ケーニッヒの定理は、最大一致を解決すると選択された三角形の正確な最小数が得られることを保証するため、貪欲な選択や局所的な選択によって最適性が向上したり、最適性に違反したりすることはありません。

from collections import deque

class HopcroftKarp:
    def __init__(self, n_left, n_right, graph):
        self.n_left = n_left
        self.n_right = n_right
        self.graph = graph
        self.pair_u = [-1] * n_left
        self.pair_v = [-1] * n_right
        self.dist = [0] * n_left

    def bfs(self):
        q = deque()
        for u in range(self.n_left):
            if self.pair_u[u] == -1:
                self.dist[u] = 0
                q.append(u)
            else:
                self.dist[u] = -1

        found = False

        while q:
            u = q.popleft()
            for v in self.graph[u]:
                if self.pair_v[v] == -1:
                    found = True
                elif self.dist[self.pair_v[v]] == -1:
                    self.dist[self.pair_v[v]] = self.dist[u] + 1
                    q.append(self.pair_v[v])

        return found

    def dfs(self, u):
        for v in self.graph[u]:
            pu = self.pair_v[v]
            if pu == -1 or (self.dist[pu] == self.dist[u] + 1 and self.dfs(pu)):
                self.pair_u[u] = v
                self.pair_v[v] = u
                return True
        self.dist[u] = -1
        return False

    def max_matching(self):
        match = 0
        while self.bfs():
            for u in range(self.n_left):
                if self.pair_u[u] == -1 and self.dfs(u):
                    match += 1
        return match

 ## 特殊なケース

 クリティカルなエッジ ケースは、境界セグメントがチャージされておらず、その三角形が他の複数の制約にも隣接している場合です。 この状況では、内部構造に関係なく三角形を選択する必要があります。 アルゴリズムは、マッチングが実行される前にノードを強制することでこれを処理し、後のステップが要件と矛盾しないようにします。 

もう 1 つのケースは、強制が境界に沿って大きく伝播し、多くのエッジが削除され、グラフが切断されたコンポーネントに分割される可能性がある場合に発生します。 マッチングは残りのグラフに対して独立して計算されるため、各コンポーネントは相互作用することなく正しく処理されます。 

最後の微妙なケースは、グリッド全体に非帯電エッジがない場合です。 このシナリオでは、強制は発生せず、隣接グラフは空であるため、一致するサイズはゼロであり、答えは正しくゼロになります。
