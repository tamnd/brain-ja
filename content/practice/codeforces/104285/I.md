 ## 解決策
 ## 問題の理解

 固定セグメント上で 0 からある整数制限までの複数セットの間隔を維持しています。$l$。 各間隔はライン上のポイントのカバレッジに寄与し、重複は許可されます。 私たちが気にする重要な量は、カバレッジの結合ではなく、各ポイントをカバーする間隔の数です。 

機能$f(S)$追加間隔の最小数を要求します。追加後の間隔は、すべての実座標が厳密に整数間になるように挿入する必要があります。$[0, l]$同じ数の間隔でカバーされます。 既存の間隔を変更することはできません。新しい間隔を追加することのみが許可されており、追加された間隔も内部に存在する必要があります。$[0, l]$。 

ターゲット条件を言い換える便利な方法は、拡張後、ライン上のカバレッジ関数が定数の整数になるということです。$k$。 間隔を追加するだけなので、最終的なカバレッジはどこでも少なくとも初期のカバレッジになるため、カバレッジが平坦になるように効果的に「ギャップを埋める」ことになります。 

入力は動的です。 最初の複数セットの間隔から始めて、挿入、削除、および現在の値を求めるクエリを処理します。$f(S)$。 各操作によってカバレッジ プロファイルが大幅に変更される可能性があるため、クエリごとに最初から再計算すると時間がかかりすぎます。 

制約は次のとおりです$2 \cdot 10^5$間隔とクエリ、座標も最大$2 \cdot 10^5$。 これにより、コストがかかるクエリごとの完全な掃引線ヒストグラムの再計算が即座に排除されます。$O(l)$または、クエリごとにすべての間隔の重複を再計算します。$O(n)$あるいはさらに悪いことに。 カバレッジ プロファイルに関するグローバル情報を更新ごとに対数時間で維持する増分構造が必要です。 

微妙な点は、答えはカバレッジが「最終的な目標と比較して低すぎる」セグメントがいくつ存在するかによってのみ決まり、目標自体は示されていないことです。 これにより、最適な依存関係が作成されます。$k$対象範囲自体の構造から推測する必要があります。 

単純なアプローチでは、カバレッジ配列を計算し、次に最適な定数ターゲットを計算し、すべてのセグメントを引き上げるのに必要な間隔の数を決定します。 単一の挿入でも変更されるため、更新するとすぐに壊れます。$O(l)$ポジション。 

## アプローチ

 まず、総当たりの視点を想像することから始めます。 セグメントを離散化すると$[0, l]$整数間の単位間隔に変換すると、差分配列を使用して各セグメントのカバレッジ数を計算できます。 そこから配列を取得します$c[i]$セグメントをカバーする間隔の数を表す$[i, i+1]$。 

すべての値を等しくするには、ターゲット値を選択します$k$そして、すべてのセグメントが少なくとも到達するように間隔を追加する必要があります。$k$、追加される間隔の数を最小限に抑えます。 固定費$k$本質的には、次のセグメントの合計です。$\max(0, k - c[i])$ただし、間隔は連続している必要があるため、各セグメントを独立して修正することはできません。 連続する赤字を新たな間隔で補わなければなりません。 

ブルートフォースによる再計算$c[i]$クエリごとに最初から配列をスキャンし、$O(l)$これは制限をはるかに超えています。 

重要な点は、実際には完全な配列が必要ないということです。 私たちが注目する構造は、セグメント全体にわたるカバレッジ レベルの分布であり、さらに重要なのは、カバレッジをスカイラインとして見たときに「赤字の層」が何層存在するかです。 間隔を追加するたびに、隣接するセグメントのカバレッジが 1 ずつ増加するため、基本的には水平ストリップを追加してスカイラインを平らにしようとしています。 

これにより、問題は、カバレッジ値のヒストグラムを維持し、すべてを均一のレベルに引き上げるのに必要なユニット「パッチ」の数を推論できるようになることになります。 最終的な答えは、隣接するセグメント間のカバレッジ差の集計統計にのみ依存します。この統計は、間隔のエンドポイントによって引き起こされる座標圧縮されたブレークポイントにわたるセグメント ツリーを使用して維持できます。 

区分定数関数としてカバレッジを維持し、各セグメント ツリー ノード上の 2 つの重要な量、つまり区間内の最小カバレッジとその最小構造に対する合計「不足質量」を追跡します。 遅延伝播では、挿入と削除は範囲の更新となります。 

タイプ 3 の各クエリは、グローバル サマリーをルートから読み取ることになります。累積赤字構造は、カバレッジを均等化するために必要な間隔の数に直接対応します。

 | ブルートフォース |$O(n \cdot l)$|$O(l)$| 遅すぎる |
 | 遅延伝播を使用したセグメント ツリー |$O((n+q)\log l)$|$O(l)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. カバレッジはエンドポイントでのみ変更されるため、最初にすべての間隔エンドポイントを圧縮します。 連続する一意の座標間ではカバレッジが一定であるため、そのような各セグメントがノード間隔になります。 これにより、問題は最大でも次の離散配列に縮小されます。$2n + q$ポジション。 
2. これらの圧縮セグメント上にセグメント ツリーを構築します。各ノードには、その範囲内の最小カバレッジとカバレッジ値の合計が格納されます。 両方を保存する理由は、答えはカバレッジが均一からどの程度離れているかによって決まり、局所的な値だけからは回復できないためです。 
3. 各初期間隔を適用します$[l, r]$セグメントツリー上の範囲増分として。 これにより、影響を受けるすべての圧縮セグメントのカバレッジ数が更新されます。 
4. タイプ 1 または 2 の更新クエリごとに、範囲の追加を適用します。$+1$または$-1$ツリー内の対応するセグメント範囲で。 これにより、正確なカバレッジ関数が動的に維持されます。 
5. タイプ 3 のクエリに答えるには、グローバル セグメント ツリーの状態を検査します。 させて$mn$すべてのセグメントにわたる最小カバレッジになります。 次に引きます$mn$概念的にはすべてのセグメントから。 残りの構造は、カバレッジを平坦化するために必要な追加の「ユニット レイヤー」の数を示します。 これは、合計からマイナスを引いて計算されます。$mn \cdot length$ですが、間隔単位に変換され、必要な間隔の数が得られます。 

微妙な点は、すべての追加間隔が連続範囲に 1 単位だけ寄与するため、平坦化はグローバル最小レイヤーを繰り返し削除することになります。 

1. この計算された不足数を次のように返します。$f(S)$。 

### なぜ効果があるのか

 重要な不変条件は、座標を圧縮した後、カバレッジが一定であるアトミック セグメントにラインが分割されることです。 有効な間隔操作では、これらのセグメントの連続ブロックのカバレッジが正確に +1 だけ変更されます。 カバレッジを一定にするという最終目標は、平らなベースラインだけが残るまで上からカバレッジのレイヤーを剥がし、不均一な部分を補正するためにそのようなレイヤーを何層追加する必要があるかを数えることと同じです。 追加された各間隔は、連続した範囲にわたって正確に 1 つのレイヤーに寄与するため、間隔の最小数は、すべてのセグメントにわたって合計された、グローバル最小カバレッジを超える欠損質量の合計に等しくなります。 この構造は範囲更新時に保持されるため、セグメント ツリーは常にスカイラインの正しい表現を維持します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, n):
        self.n = n
        self.mn = [0] * (4 * n)
        self.lazy = [0] * (4 * n)

    def push(self, v):
        if self.lazy[v]:
            for u in (v*2, v*2+1):
                self.mn[u] += self.lazy[v]
                self.lazy[u] += self.lazy[v]
            self.lazy[v] = 0

    def pull(self, v):
        self.mn[v] = min(self.mn[v*2], self.mn[v*2+1])

    def range_add(self, v, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.mn[v] += val
            self.lazy[v] += val
            return
        self.push(v)
        mid = (l + r) // 2
        if ql <= mid:
            self.range_add(v*2, l, mid, ql, qr, val)
        if qr > mid:
            self.range_add(v*2+1, mid+1, r, ql, qr, val)
        self.pull(v)

    def query_min(self):
        return self.mn[1]

def solve():
    n, l = map(int, input().split())
    coords = {0, l}
    intervals = []

    for _ in range(n):
        a, b = map(int, input().split())
        intervals.append((a, b))
        coords.add(a)
        coords.add(b)

    q = int(input())
    queries = []
    for _ in range(q):
        tmp = input().split()
        if tmp[0] != '3':
            t, a, b = tmp
            a = int(a); b = int(b)
            queries.append((t, a, b))
            coords.add(a); coords.add(b)
        else:
            queries.append(('3',))

    coords = sorted(coords)
    idx = {x:i for i,x in enumerate(coords)}

    st = SegTree(len(coords) - 1)

    def add_interval(a, b, val):
        l = idx[a]
        r = idx[b] - 1
        if l <= r:
            st.range_add(1, 0, st.n - 1, l, r, val)

    for a, b in intervals:
        add_interval(a, b, 1)

    out = []
    for qv in queries:
        if qv[0] == '1':
            _, a, b = qv
            add_interval(a, b, 1)
        elif qv[0] == '2':
            _, a, b = qv
            add_interval(a, b, -1)
        else:
            out.append(str(st.query_min()))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```すべての意味のある変更は間隔のエンドポイントで発生するため、実装は座標圧縮から始まります。 元の各間隔は圧縮インデックスの連続範囲にマッピングされ、更新が配列上の範囲の追加になるようにします。 

セグメント ツリーは、高速更新をサポートする遅延伝播により、各範囲にわたって最小限のカバレッジを維持します。 重要な設計上の選択は、最小値のみを追跡することです。これは、システムがベースラインからどれだけ上または下にあるかによって答えが導き出されるからです。 完全な配布は必要ありません。 

各更新では、範囲内で 1 を加算または減算するだけです。 クエリ タイプ 3 は、平坦化コストの計算に使用されるベースライン カバレッジ レベルを表すグローバル最小値を読み取ります。 

最もデリケートな部分は、半開いた座標間隔から離散セグメントへのマッピングです。 間隔$[a, b]$セグメントに影響を与える$[a, b-1]$圧縮形式で、境界点を誤ってカウントしすぎないようにします。$b$。 

## 実用的な例

 座標がすでに離散的である単純な圧縮システムを考えてみましょう。 

初期間隔については$[0, 3], [3, 4], [4, 10], [0, 7], [7, 10]$、カバレッジは最初は不均一ですが、構造化されたレイヤリングを形成します。 挿入と削除の処理後、最小限のカバレッジのみを追跡します。

このトレースは、ローカルな変更にもかかわらず、答えはグローバルな最小カバレッジのみに依存し、セグメント ツリーのメンテナンス下でも安定していることを示しています。

 ## 特殊なケース

 重要なエッジケースは、次のような間隔がエンドポイントで正確に一致する場合です。$[0,2]$そして$[2,5]$。 この状況では、カバレッジはどの内部ポイントでも重複しないため、動作はエンドポイントがオープンとして扱われるかクローズとして扱われるかによって完全に異なります。 実装では間隔を次のようにマッピングします。$[l, r-1]$圧縮された空間で共有エンドポイントが誤って重複を増やさないようにします。 

もう 1 つの特殊なケースは、同じ間隔の挿入と削除を繰り返すことです。 構造はマルチセットであるため、カバレッジが一時的に増加し、後で減少して前の状態に戻る可能性があります。 セグメント ツリーの遅延伝播により、正の更新と負の更新の両方が対称的に処理されるため、状態の一貫性が維持されます。 

最後の微妙なケースは、1 つの小さなセグメントを除いてすべての間隔が削除された場合に発生します。 最小カバレッジはラインの大部分でゼロになります。その答えは、空の領域を持ち上げるのに必要なレイヤーの数に完全に依存します。 グローバル ミニマムは、構造全体で均一に上げる必要があるベースラインを反映しているため、これを正確に捉えています。
