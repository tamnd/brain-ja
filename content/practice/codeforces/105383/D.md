 ## 解決策
 ## 問題の理解

 としてモデル化された乗客の長方形の配置が与えられています。$n \times m$グリッド。 各セルは 1 つの座席を表し、確実に感染している乗客、明らかに健康な乗客、または確率的に独立して感染している不確かな乗客のいずれかを含みます。$1/2$。 

費用モデルは、地域での感染の広がり方によって異なります。 乗客が感染した場合、一定の隔離費用を負担する$d_0$。 少なくとも 1 人の感染した乗客の端に直接隣接する健康な乗客は感染の原因となります。$d_1$。 感染した乗客の端に隣接していないが、少なくとも 1 人の感染した乗客の角に隣接している健康な乗客は、感染に寄与します。$d_2$。 健康な乗客に感染した隣人がまったくいない場合（斜め方向であっても）、その乗客のコストはゼロです。 

タスクは、1 つの決定的な値を計算することではなく、未知のセルのすべてのランダムな割り当てに対する予想される総隔離コストを計算することです。 それぞれの「?」は独立して確率で感染するか感染しないか$1/2$。 答えは、この積分布の下での期待値として正確に計算され、大きな素数を法として出力される必要があります。 

制約$n, m \le 100$せいぜい暗示する$10^4$細胞。 すべてを列挙するアプローチ$2^{nm}$構成は不可能です。 隣接するセルのすべてのサブセットに対するセルごとの列挙も、それが残っている場合にのみ受け入れられます。$O(nm)$または$O(nm \cdot 8)$。 これは、解が局所的な寄与に分解され、離れたセル間の結合を回避する必要があることを強く示唆しています。 

微妙なエッジ ケースは、セルのコスト カテゴリが、感染した隣接セルの数ではなく、少なくとも 1 つの存在に依存する場合です。 この「少なくとも 1 つ」の条件により補数イベントが導入され、直接カウントするよりも簡単に処理できます。 

もう 1 つの重要なケースは、完全に未知のグリッドです。 たとえば、すべてのセルが「?」の場合、すべてのセルは対称ですが、隣接するセルが重なっているため、依存関係は依然として存在します。 セルごとの独立した確率を乗算する単純なアプローチでは、隣接する 2 つの両方が感染しているなどの重複イベントが誤って無視されます。 

## アプローチ

 ブルートフォース手法では、各「?」に次の値が割り当てられます。$\{0,1\}$、すべて列挙します$2^k$構成では、すべてのセルをスキャンして隣接セルをチェックすることによって各構成の合計コストを計算し、平均します。 これは正しいですが、たとえ$k=100$、 以来$2^{100}$天文学的に大きいです。 

重要な観察は、予想される総コストがセルごとの予想される寄与の合計に分解できるということです。 期待値が直線的であるため、ジョイント構成をグローバルに考慮する必要がなくなります。 各セルは期待値に独立して寄与しますが、その寄与はそれ自体とその近隣の局所的な感染確率に依存します。 

各セルについて、そのセルが感染しているかどうか、および 4 方向および斜め方向の隣接セルに感染しているかどうかだけを知る必要があります。 重要な単純化は、隣接するものの完全な結合分布が必要ないことです。 必要なのは、「セット内の少なくとも 1 つの感染した隣人」のようなイベントの確率だけです。 

これらは補数を使用して計算できます。独立したベルヌーイ近傍のセットの場合、どれも感染していない確率は、それらの「感染していない」確率の積になります。 これにより、セルごとの感染確率を事前に計算すると、各セルの予想される寄与を一定時間で計算できるようになります。 

したがって、問題はすべてのセルを反復して計算することになります。 

セルが感染している確率、および感染した 4 隣接セルまたは感染した対角隣接セルが存在しない確率、およびそれらを決定論的なコスト規則に従って組み合わせます。

 ## アルゴリズムのチュートリアル

 ### ステップ 1: 各細胞を感染確率に変換する

 私たちは定義します$p_{i,j}$細胞が感染する確率として。 「V」の場合は、$p_{i,j}=1$。 「。」の場合は、$p_{i,j}=0$。 「？」の場合は、$p_{i,j}=\frac{1}{2}$。 

また、$q_{i,j} = 1 - p_{i,j}$、細胞が感染していない確率。 この二重表現は、すべての近傍条件が「これらのセルのいずれも感染していない」に帰着するため便利です。 

### ステップ 2: モジュラー算術値を事前計算する

 答えは剰余が必要なので、$10^9+7$、私たちは代表します$1/2$これにより、すべての確率をモジュラー形式で正確に維持できます。 

### ステップ 3: 感染細胞の寄与を計算する

 各細胞が貢献します$d_0$感染する確率の何倍にもなります。 これを次のように答えに直接蓄積します$p_{i,j} \cdot d_0$。 

これが有効である理由は、期待の直線性です。各感染細胞は他の細胞とは独立して一定量を寄与します。 

### ステップ 4: 健康なセルに対するエッジ隣接の影響を計算する

 感染していない細胞の場合、$d_1$感染した 4 ネイバーが少なくとも 1 つある場合。 

このイベントを直接計算する代わりに、その補数を計算します。つまり、4 つの近傍はすべて感染していません。 

それで：$$P(\text{at least one infected 4-neighbor}) = 1 - \prod (1 - p_{\text{neighbor}})$$この確率を次のように乗算します。$q_{i,j} \cdot d_1$なぜなら、このルールは細胞自体が感染していない場合にのみ適用されるからです。 

### ステップ 5: 斜めに隣接する影響を計算する

 同様に、セルが感染しておらず、感染した 4 つの隣接セルが存在しない場合は、$d_2$少なくとも 1 つの斜めの隣が感染している場合。 

次のように計算します。$$P(\text{diagonal trigger}) = P(\text{no 4-neighbor infected}) \cdot (1 - \prod (1 - p_{\text{diag}}))$$次に乗算します$q_{i,j} \cdot d_2$。 

この条件付き構造により、4 近傍がすでに高いコストをトリガーしている場合に、対角線の影響を二重にカウントしないことが保証されます。 

### ステップ 6: すべてのセルを合計する

 各セルは期待値に独立して寄与するため、すべての寄与を合計します。 

### なぜ効果があるのか

 このアルゴリズムは 2 つのプロパティに依存します。 まず、期待値の線形性により、異なるセルの状態間の相関関係を気にすることなく、グローバル コストをセル全体の合計に分解できます。 第 2 に、各ローカル イベント (「少なくとも 1 つの感染した近隣イベント」) は独立したイベントの補数として表現でき、単純な積を使用して正確な確率計算が可能になります。 これら 2 つの事実により、相関関係のある隣接構成から生じるであろう指数関数的な依存関係が排除されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
INV2 = (MOD + 1) // 2

def mul(a, b):
    return (a * b) % MOD

def add(a, b):
    s = a + b
    return s % MOD

def solve():
    n, m, d0, d1, d2 = map(int, input().split())
    
    grid = [input().strip() for _ in range(n)]
    
    p = [[0] * m for _ in range(n)]
    q = [[0] * m for _ in range(n)]
    
    for i in range(n):
        for j in range(m):
            if grid[i][j] == 'V':
                p[i][j] = 1
            elif grid[i][j] == '.':
                p[i][j] = 0
            else:
                p[i][j] = INV2
            q[i][j] = (1 - p[i][j]) % MOD
    
    ans = 0
    
    dirs4 = [(1,0),(-1,0),(0,1),(0,-1)]
    dirs8 = [(dx,dy) for dx in (-1,0,1) for dy in (-1,0,1) if not (dx == 0 and dy == 0)]
    
    for i in range(n):
        for j in range(m):
            # infected contribution
            ans = (ans + p[i][j] * d0) % MOD
            
            # compute 4-neighbor infection probability
            prod4 = 1
            for dx, dy in dirs4:
                ni, nj = i + dx, j + dy
                if 0 <= ni < n and 0 <= nj < m:
                    prod4 = prod4 * (1 - p[ni][nj]) % MOD
            
            has4 = (1 - prod4) % MOD
            
            # compute diagonal (8-neighbors excluding 4-neighbors)
            prod8 = 1
            for dx, dy in dirs8:
                ni, nj = i + dx, j + dy
                if 0 <= ni < n and 0 <= nj < m:
                    prod8 = prod8 * (1 - p[ni][nj]) % MOD
            
            has_any = (1 - prod8) % MOD
            
            # ensure diagonal only applies if no 4-neighbor
            diag_only = (has_any - has4) % MOD
            
            ans = (ans + q[i][j] * d1 % MOD * has4) % MOD
            ans = (ans + q[i][j] * d2 % MOD * diag_only) % MOD
    
    print(ans % MOD)

if __name__ == "__main__":
    solve()
```実装はアルゴリズムの分解を反映します。 配列`p`そして`q`感染確率と非感染確率を保存します。 各セルについて、感染した寄与分が最初に追加されます。 

4 近傍の計算では補数の積を使用するため、重複する近傍依存関係の二重カウントが回避されます。 同じ考え方が 8 つの近傍すべてに拡張され、その違いによって純粋に対角線でトリガーされたケースが分離されます。 

引き算`diag_only = has_any - has4`これは、ルール階層を強制するため重要です。対角コストは、エッジ隣接感染が存在しない場合にのみ適用されます。 この分離がないと、端と斜めの両方に感染した隣接セルがあるセルが過剰にカウントされてしまいます。

 ## 特殊なケース

 重要なエッジ ケースは、セルにエッジ隣接と斜め隣接の両方の感染した隣接セルがある場合です。 例えば：```
V ?
? .
```中央のセルには両方のタイプの影響が表示されます。 このアルゴリズムでは、エッジ隣接感染が存在する場合に、対角線の寄与が減算されることによって確実に抑制されます。`has4`から`has_any`。 これにより、正しい階層のみが適用されることが保証されます。 

もう 1 つのエッジ ケースは境界セルです。この場合、欠落している隣接セルを確率ゼロの感染セルとして扱ってはなりません。 この実装では、確率を乗算する前に境界を明示的にチェックし、存在しない近傍が積に影響を与えないようにします。
