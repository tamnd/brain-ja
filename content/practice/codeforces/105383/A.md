 ## 解決策
 ## 問題の理解

 動物のコレクションが与えられ、それぞれが種名と影響力の数値によって説明されます。 これらの動物の中から任意のサブセットを選択して指導評議会を形成する必要がありますが、その選択はブタと呼ばれる単一の特別な種によって制約されます。 

評議会は 2 つの規則に従わなければなりません。 まず、評議会の一員になれる豚は最大でも1頭だ。 第二に、豚が含まれている場合、評議会の豚以外のすべての動物の影響力は、その豚よりも厳密に小さくなければなりません。 ブタが含まれていない場合、ブタに関する制約は適用されませんが、ブタが存在し、選択を支配する可能性があるため、このような評議会は決して最適ではありません。 

目的は、これらの制約の下で、選択したサブセットの影響値の合計を最大化することです。 

入力サイズは最大 100,000 匹の動物にすることができ、サブセットを列挙したり、考えられるすべての評議会をシミュレートしようとするソリューションは即座に除外されます。 10^10 の演算は 2 秒の制限をはるかに超えているため、n の二次関数であっても遅すぎます。 私たちは、通常は並べ替えやプレフィックス集計を伴う、ほぼ線形または n log n 時間でデータを処理する戦略を余儀なくされています。 

すべての動物が豚である場合、微妙な特殊なケースが発生します。 この場合、選択できる豚は最大 1 頭であるため、答えは合計ではなく、豚間の最大の影響力になります。 すべての豚を常に合計できると仮定する素朴なアプローチは、ここでは失敗します。 別のエッジ ケースは、最強のブタが非ブタの組み合わせと比較して非常に小さい場合に発生します。これは、制約により、両方のグループを個別にグローバルに最大化するのではなく、しきい値に基づいて非ブタをフィルタリングすることが強制されるためです。 

## アプローチ

 直接的な強引な解釈は、豚のあらゆる選択肢を検討し、互換性のあるすべての非豚を選択することです。 各豚について、その影響力を計算し、その影響力がその豚よりも厳密に小さい豚以外のすべてを追加することができます。 これは正しいです。なぜなら、ブタが固定されると、非ブタ自体には制限がないため、非ブタに対する最適な戦略は常に有効なものをすべて採用することになるからです。 

ただし、これには依然としてすべての豚についてすべての非豚をスキャンする必要があり、最悪の場合は O(n^2) の動作が発生します。 n が 10^5 までになると、これは完全に不可能になります。 

重要な観察は、豚に関して重要なのはその影響力の値だけだということです。 影響力 x を持つ豚を修正すると、値が x 未満の豚以外のすべてが自動的に適格となり、値がそれ以上のすべては除外されます。 これは、非ブタを影響力によってソートし、プレフィックスの合計を事前計算して、対数時間で「値 < x を持つすべての非ブタの合計」を答えることができることを示唆しています。 

次に、すべての豚に対して反復処理を行い、各豚を最大制約の候補として扱い、二分探索を使用してその値を豚以外の可能な限り最良の寄与と組み合わせます。 これにより、問題はソート、プレフィックス合計、バイナリ検索に集約されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | フルスキャンによるブルートフォースピッグチェック | O(n^2) | O(n) | 遅すぎる |
 | ソート + 接頭辞の合計 + 豚の二分探索 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. すべての動物を種に基づいて 2 つのグループ (ブタとブタ以外) に分類します。 これが必要なのは、ブタが閾値アンカーとして機能するのに対し、ブタ以外はその閾値によってのみ制約されるためです。 
2. 豚以外の影響値をリストに抽出し、昇順に並べ替えます。 すべての「x 未満」クエリがプレフィックスの問題になるように、並べ替えが必要です。 
3. ソートされた非ブタ影響に対してプレフィックス合計配列を構築します。 インデックス i の各接頭辞の合計は、そのインデックスまでのすべての非ブタの影響の合計を表します。 
4. 各豚を潜在的な最大制約として評価するため、豚の影響も並べ替えます。 
5. 影響力 x を持つ各ブタについて、ソートされた非ブタ配列に対して二分検索を実行して、影響力が厳密に x より小さい最後のインデックスを見つけます。 これは、どの非豚を含めることができるかを正確に定義します。 
6. ブタの影響 x をそのインデックスのプレフィックス合計に加算します。 これにより、この豚がリーダーに選ばれた場合の最高の評議会合計が得られます。 
7. すべての豚の最大値を追跡します。 最終的な答えは、達成可能な最大の合計です。 

二分探索ステップは、配列をスキャンせずに厳密な不等式制約を効率的に適用するため、重要です。 

### なぜ効果があるのか

 影響力 x を持つ固定豚の場合、有効な評議会にはその豚と、影響力が厳密に x より小さい非豚のみを含める必要があります。 非ブタのすべてのサブセットの中で、非ブタ間には内部制限がなく、すべての値が正であるため、それらをすべて取得することが常に最適です。 したがって、各ブタ候補の最適解はプレフィックス合計クエリに帰着します。 すべての有効な解決策は、一意のピッグ (または同等の支配的な制約) として何らかのピッグを選択する必要があるため、すべてのピッグを列挙することですべての可能性がカバーされ、これらの互いに素な最適部分問題の最大値を取得します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    
    pigs = []
    non_pigs = []
    
    for _ in range(n):
        sp, val = input().split()
        val = int(val)
        if sp == "pig":
            pigs.append(val)
        else:
            non_pigs.append(val)
    
    if not pigs:
        return print(0)
    
    pigs.sort()
    non_pigs.sort()
    
    prefix = [0]
    for v in non_pigs:
        prefix.append(prefix[-1] + v)
    
    import bisect
    
    ans = 0
    
    for x in pigs:
        idx = bisect.bisect_left(non_pigs, x) - 1
        total = x + (prefix[idx + 1] if idx >= 0 else 0)
        if total > ans:
            ans = total
    
    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず入力を分割して、豚と豚以外が独立して処理されるようにします。 非豚リストはソートされているため、特定の豚のしきい値の下でどの値が許可されるかを効率的に判断できます。 プレフィックス配列は、O(n) の前処理ステップの後に、繰り返される合計クエリを O(1) のルックアップに変換します。 

機能`bisect_left(non_pigs, x)`x より小さくない最初の要素を検索するため、1 を減算すると、厳密に x より小さい最後の有効なインデックスが得られます。 このインデックスは、適格な非豚の接頭辞の合計を直接決定します。 

実装によくある落とし穴は、厳密な不等式の要件を忘れることです。 使用する`bisect_right`代わりに、豚の影響に等しい値が誤って含まれ、制約に違反します。 

## 実用的な例

 ### 例 1

 入力:```
pig 10
horse 15
pig 5
cow 20
sheep 25
```ブタを次のように分けます`[10, 5]`そして豚以外のものとしては`[15, 20, 25]`。 

選別すると豚が得られる`[5, 10]`そして豚以外の`[15, 20, 25]`。 

非豚の接頭辞の合計は次のとおりです。```
index:   0   1   2   3
value:   0  15  35  60
```次に豚を評価します。 

豚 = 5 の場合、豚以外の豚には 5 未満はないため、合計は 5 になります。 

豚 = 10 の場合、やはり豚以外には 10 未満はないので、合計は 10 になります。 

最大は 10 です。 

| 豚 | しきい値 x | 上限インデックス | 豚以外の合計 | 合計 |
 | --- | --- | --- | --- | --- |
 | 5 | 5 | -1 | 0 | 5 |
 | 10 | 10 | -1 | 0 | 10 |

 これは、大型の非豚はすべて豚の閾値を超えているため使用できないことを示しています。

 ## 特殊なケース

 すべての動物がブタの場合でも、ブタ以外のリストは空であるため、アルゴリズムは機能します。 プレフィックス合計配列にはゼロのみが含まれるため、すべての豚候補はそれ自体の値と等しい合計を生成します。 入力の場合:```
3
pig 5
pig 7
pig 3
```各反復で豚自体に等しい合計が計算され、最大値は正しく 7 になります。 

すべての非ブタがすべてのブタよりも大きい場合、すべての二分検索は -1 を返します。これは、非ブタが適格でないことを意味します。 のために：```
pig 1
cow 10
horse 20
```プレフィックスの寄与は常にゼロであるため、両方の豚 (複数ある場合) は独自の値のみを生成します。 このアルゴリズムは、厳密な不等式が適用されるため、無効な非ブタが誤って含まれることを正しく回避します。`bisect_left`。 

ピッグ値が非ピッグ値とインターリーブする場合、正確さは正しいピッグしきい値の選択に依存します。 アルゴリズムは各豚を独立して評価するため、小さい豚ではより多くの非豚が許可され、大きい豚の値が優勢な場合でも、両方が明示的にテストされ、最大値が保持されます。
