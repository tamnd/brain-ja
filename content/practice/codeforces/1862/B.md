 ## 問題の理解

 考えられる元のシーケンスを再構築するように求められます`a`シーケンスが与えられた`b`これは、単純なフィルタリング ルールによって導出されました。 シーケンス`b`常に最初の要素から始まります`a`、そして次のすべての要素が含まれます`a`それは直前のバージョン以上のものです。 言い換えると、`b`スキャン時に最初の要素とすべての非減少「ピーク」を保持することによって形成されます`a`。 私たちの仕事は、固有の元のシーケンスを見つけることではなく、有効なシーケンスを見つけることです。`a`それは与えられたものを生み出すことができます`b`。 

制約により、最大で次のことが許可されます。`2 * 10^5`の要素`b`すべてのテストケースにわたって。 までの長さのシーケンスを出力できるため、`2n`それぞれに`b`、直線的な構造で十分です。 これにより、これよりも複雑なものは除外されます。`O(n)`テストケースごとに。 

微妙なのは、次の 2 つの連続する要素の間です。`b`、の要素`a`最初の非減少要素が次の要素に到達する限り、自由に下がったり上がったりすることがあります。`b`。 たとえば、次の場合`b = [4, 6, 3]`の間に任意のシーケンスを挿入できます。`4`そして`6`を超えないもの`6`前に`6`、との間`6`そして`3`で終わる減少シーケンスを持つことができます。`3`。 エッジケースが発生するのは次の場合です`b`要素が 1 つしかない場合、または連続する要素が等しい場合、同じ要素のシーケンスが 1 回以上繰り返されても機能します。 

## アプローチ

 ブルートフォースアプローチでは、長さ以下のすべてのシーケンスを列挙しようとします。`2n`どちらが減少するかを確認するには`b`、しかし可能性の数は指数関数的に増加し、実現不可能です。 

最適なアプローチは、連続する要素の間に中間要素を配置すれば十分であるという観察を活用します。`b`増加と減少の両方を許可します。 具体的には、`b[i]`そして`b[i+1]`、挿入できます`b[i]`またもしなら`b[i] > b[i+1]`次の値がドロップされるようにします。 これにより、フィルタリング ルールが依然として正確に結果を生成することが保証されます。`b`。 もし`b[i] <= b[i+1]`、単純に追加します`b[i+1]`直接。 このメソッドは、結果として得られるシーケンスが`a`せいぜい長さがある`2n`、フィルタリング ルールを尊重し、線形時間で実行されます。

 ## アルゴリズムのチュートリアル

 1. 空のリストを初期化する`a`。 
2. の最初の要素を追加します。`b`に`a`。 
3. 連続する要素の各ペアを反復処理します。`(b[i], b[i+1])`:

 1.追加`b[i+1]`に`a`。 
2. もし`b[i] > b[i+1]`、追加`b[i]`直前に`b[i+1]`フィルタリング ルールを維持しながら減少を許可します。 これにより、構築時に次のことが保証されます。`b`から`a`、非減少フィルターは挿入されたものをスキップします。`b[i]`必要に応じて。 
4. すべてのペアを処理した後、長さを出力します。`a`そしてシーケンスそのもの。 

なぜ効果があるのか​​: 挿入することで`b[i]`前に`b[i+1]`減少が必要な場合は常に、フィルタリング ルールによって正確な結果が得られることを保証します。`b`。 最初の要素は常に保持され、前の数値を繰り返すか、次の要素の減少を許可する方法で要素を配置するため、挿入された要素が非減少フィルターに違反することはありません。 長さは最大でも`2n`ペアごとに最大 1 つの要素を挿入するためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        b = list(map(int, input().split()))
        a = [b[0]]
        for i in range(1, n):
            if b[i-1] > b[i]:
                a.append(b[i-1])
            a.append(b[i])
        print(len(a))
        print(*a)

if __name__ == "__main__":
    solve()
```このソリューションは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`そしてシーケンスを構築します`a`直線的に。 前の要素を再度挿入することで連続する要素が減少するケースを処理するように注意が払われました。これは、フィルタリング ルールが正確な結果を得るために不可欠です。`b`。
