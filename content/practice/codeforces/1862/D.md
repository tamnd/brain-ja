 ## 解決策
 ## 問題の理解

 テマが正確に作るために購入する必要があるアイスクリームボールの最小数を決定するように求められます。`n`特徴的な 2 つのボールのアイス クリーム コーン。 各コーンは 2 つのボールで構成されており、それらは同じフレーバーのものである可能性があります。 2 つのコーンは、フレーバーの**マルチセット**が異なる場合、異なるものとみなされます。 たとえば、コーン`{1,2}`そして`{2,1}`同一ですが、`{1,1}`とは異なります`{1,2}`。 Tema は必要なだけフレーバーを購入でき、必要に応じて同じフレーバーのボールを複数使用できます。 

入力により提供されるのは、`t`テストケース。 各テスト ケースは単一の整数を与えます`n`、個別の 2 ボール コーンの必要な数。 各テスト ケースの出力は、必要なアイスクリーム ボールの最小合計数である必要があります。 

制約は大きいです:`n`まで高くすることができます`10^18`。 これにより、考えられるすべてのコーンを列挙しようとする強引なアプローチが即座に除外されます。 O(n) の解であっても、最大の入力に対しては実行不可能です。 対数的な解が必要です`n`または直接数学的推論を使用します。 エッジケースが発生するのは次の場合です`n`非常に小さいです、例えば`1`または`2`, なぜなら、単一のダブルフレーバーコーンを形成するのに十分なボールを確保する必要があるからです。 

たとえば、次の場合`n = 1`、最小のボールのセットは`[1,1]`- 1 つのフレーバー、2 つのボール - 1 つの異なるコーンを生成します。 もし`n = 3`、2 つのボールではそれを行うことはできません。これは、1 つの異なるコーンしか許可されないからです。 ボールが3つ必要です`[1,2,3]`3 つの異なる円錐を形成する`{1,2}`、`{1,3}`、 そして`{2,3}`。 

## アプローチ

 強引なアプローチでは、ボールをフレーバーに割り当て、結果として得られる 2 つのボール コーンを数えるすべての可能な方法を、正確に到達するまでシミュレートしようとします。`n`。 概念的には単純ですが、このアプローチは非常に時間がかかります。 組み合わせの数はボールの数に応じて二次関数的に増加します。`n`まで`10^18`、すべての組み合わせを計算することさえ不可能です。 

重要な観察は、次のことです。`k`それぞれのボールに独特の風味があると、ボールの魅力が最大限に発揮されます。 この数値は次の組み合わせ式で求められます。`C(k,2) = k*(k-1)/2`。 もし`n`は次の三角数より小さいため、正確に到達するには既存のフレーバーのボールを追加するのが最適かもしれません`n`コーン。 一般的な戦略は、最小の整数を見つけることです。`k`そのような`k*(k+1)/2 >= n`。 これにより、`k`ボール、少なくとも形成できます`n`異なる 2 ボール コーン。すべてがユニークなフレーバー、またはギャップを埋めるためにいくつかの繰り返しフレーバーが含まれています。 

効率的に見つけることができます`k`二次不等式から導出された閉形式の解法または二分探索のいずれかを使用します。 閉じた形式の解決策には、以下を解決することが含まれます。`k*(k+1)/2 >= n`のために`k`二次公式を使用し、最も近い整数に切り上げます。 このアプローチは、テスト ケースごとに一定の時間で結果を計算するため、非常に高速です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k^2) | O(k) | n > 10^5 では遅すぎます |
 | 最適 | テスト ケースごとに O(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、次の内容を読んでください。`n`、希望するアイスクリームの種類の数。 
2. 作成できる個別の 2 ボール コーンの最大数を観察します。`x`ボールがすべて一意である場合、`x*(x-1)/2`。 到達するには少なくともこれだけの数が必要です`n`。 
3. 不等式を解く`x*(x-1)/2 >= n`のために`x`。 これを二次方程式に書き直すと次のようになります。`x^2 - x - 2*n >= 0`。 
4. 二次公式を使用して次の値を求めます。`x = ceil((1 + sqrt(1 + 8*n))/2)`。 これが最低限必要なボール数です。 
5. 結果を印刷します。`x`テストケースごとに。 

なぜそれが機能するのか: 公式`x*(x-1)/2`異なるボールの考えられるすべてのペアをカウントします。 を解決することで、`x`、少なくとも生産するのに十分なボールを確保します。`n`個性的なアイスクリーム。 シーリングを使用すると、二次方程式で端数の結果が得られる場合でも、切り上げて整数のボールが得られるようになります。 ボールの数が少ないと、生成されるボールの数は厳密に次の数よりも少なくなります。`n`独特の円錐形。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n = int(input())
    # solve x*(x-1)/2 >= n => x^2 - x - 2n >= 0
    x = math.ceil((1 + math.sqrt(1 + 8*n)) / 2)
    print(x)
```ソリューションはテスト ケースの数を読み取り、それぞれのテスト ケースを読み取ります。`n`最小値を計算します`x`二次公式を使って。`math.sqrt`非常に大きなものでも安全です`n`Python では任意精度の整数のため、`math.ceil`不等式を満たす最小の整数を保証します。 これにより、整数の除算を使用した場合や手動で丸めようとした場合に発生する可能性のある、1 による誤差が回避されます。

 ## 特殊なケース

 のために`n = 1`、アルゴリズムは次のように計算します`x = ceil((1 + sqrt(1+8))/2) = 2`。 1 つのコーンを作るには同じフレーバーの 2 つのボールが必要なので、これは正しく 2 を出力します。 のために`n = 10^18`、`x`は約 1.34×10^9 であり、Python の整数演算はオーバーフローすることなくこれを処理します。 この式は本質的に、非常に小さいものと非常に大きいものの両方を処理します。`n`追加の境界チェックは必要ありません。
