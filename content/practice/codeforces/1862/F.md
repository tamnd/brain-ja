 ## 解決策
 ## 問題の理解

 魔術師のヴィカが一連のモンスターを倒すのに必要な最短時間を計算するように求められました。 モンスターにはそれぞれ強さがあり、ヴィカは水と火の2種類の魔法を持っています。 1秒以内に、彼女は一定量の水と火のマナを生成します。 モンスターを倒すには、いずれかのタイプの魔法を使用して、単一の呪文に少なくともモンスターの強さと同じ量のマナを費やす必要があります。 十分なマナが蓄積されていれば、彼女は 1 秒間に複数の呪文を唱えることができます。 この問題では、複数のテスト ケースについて、すべてのモンスターを倒すのに必要な最小秒数を見つけることが求められます。 

入力により、テスト ケースごとに、マナ生成率とモンスターの強さが得られます。 制約は小さく、テスト ケースあたりのモンスターの数は最大 100 で、すべてのテスト ケースの合計も最大 100 です。各モンスターの強さは最大でも 100 です。$10^4$、1秒あたりのマナ生成は非常に大きくなる可能性がありますが、$10^9$。 これは、モンスターの数を飛躍的に増加させる解決策を模索できることを示しています。$2^{100}$は大きすぎますが、合計強度 (最大でも) によって制限される合計に対するサブセットの合計または DP を賢く使用します。$100 \times 10^4 = 10^6$）は実現可能です。 

あるタイプのマナが他のタイプよりもはるかに大きい場合、エッジケースが発生します。 たとえば、ヴィカが毎秒 1 ユニットの水と 100 ユニットの火を生成でき、すべてのモンスターの強さが 50 である場合、彼女は火の呪文に集中する必要があります。 マナを常に均等に分割したり、モンスターの魔法タイプへの最適な割り当てを無視した不用意なアプローチは失敗します。 もう 1 つのエッジ ケースは、モンスターの強さの合計がマナ レートの倍数と正確に一致する場合、またはモンスターが 1 体しか存在しない場合です。 これらには、近似ではなく正確な計算が必要です。 

## アプローチ

 ブルートフォースソリューションでは、モンスターを水または火の呪文に割り当てるすべての可能性が考慮されます。 各モンスターには 2 つの選択肢があるため、$2^n$割り当ての合計。 割り当てごとに、必要な水と火のマナの合計を計算し、1 秒あたりに生成されるマナで割って (切り上げ)、最大値を取得します。 これにより、文字通り 2 つの魔法タイプ間でモンスターを分配するあらゆる方法がチェックされるため、正確さが保証されます。 ただし、$n$100まで、$2^{100}$可能性は不可能です。 

重要な観察は、これが古典的な 2 次元の部分集合和の問題であるということです。 火は自動的に決定されるため、水のマナ配分に集中できます。 必要な水マナの合計が$W$、その後、残りのモンスターが必要とする$F$マナ、最小時間は$\max(\lceil W / w \rceil, \lceil F / f \rceil)$。 すべてのモンスターの強さの合計は最大で$10^6$, そのため、達成可能な水の合計に対して動的計画法を実行できます。 具体的には、ブール値 DP 配列を維持します。`dp[s]`水の強さの合計が正確に一致するモンスターのサブセットが存在する場合は true$s$。 DP を取得したら、達成可能なすべての合計を反復処理します。`s`そして時間を次のように計算します$\max(\lceil s / w \rceil, \lceil (total - s) / f \rceil)$、最小限を維持します。 

これにより、問題は指数時間から擬似多項式時間に軽減されます。 最大DPサイズはすべてのモンスターの強さの合計であり、最大でも$10^6$、モンスターごとに、DP 配列を更新します。 と$n \le 100$、これは効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | サブセット合計の DP | O(n * S) ここで、S=強度の合計 | O(S) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. モンスターの強さの合計を計算します。 させて`total = sum(s_i)`。 
2. サイズのブール DP 配列を初期化します。`total + 1`、 と`dp[0] = True`モンスターがいない状態でも合計が 0 に達する可能性があるためです。 
3. モンスターの強さごとに`s_i`、からの DP 配列を逆方向に反復します。`total`まで`s_i`。 もし`dp[j - s_i]`True の場合は設定します`dp[j] = True`。 これにより、すべての達成可能な水の合計が更新されます。 
4.初期化`ans`無限のように。 すべてのインデックスを反復処理する`w_sum`DP 配列内。 それぞれについて`w_sum`それは達成可能です(`dp[w_sum] = True`)、残りの火災合計を計算します`f_sum = total - w_sum`。 マナを蓄積する時間を計算します。`time = max((w_sum + w - 1) // w, (f_sum + f - 1) // f)`。 アップデート`ans = min(ans, time)`。 
5. 出力`ans`必要な最小秒数として。 

それが機能する理由: DP は、水と火の間で可能なモンスターのあらゆる分割を考慮することを保証します。 それぞれ`w_sum`一部のモンスターの水魔法への有効な割り当てに対応します。 補完により、射撃の割り当てが自動的に行われます。 の計算`max(ceil(W/w), ceil(F/f))`両方のタイプの十分なマナを蓄積する時間を正確にモデル化します。 達成可能なすべての水の合計を反復することにより、最小全体時間が確実に見つかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        w, f = map(int, input().split())
        n = int(input())
        s = list(map(int, input().split()))
        total = sum(s)
        dp = [False] * (total + 1)
        dp[0] = True
        for strength in s:
            for j in range(total, strength - 1, -1):
                if dp[j - strength]:
                    dp[j] = True
        ans = float('inf')
        for w_sum in range(total + 1):
            if dp[w_sum]:
                f_sum = total - w_sum
                time = max((w_sum + w - 1) // w, (f_sum + f - 1) // f)
                if time < ans:
                    ans = time
        print(ans)

if __name__ == "__main__":
    solve()
```DP セクションは逆方向に反復して、同じサブセット内で単一のモンスターが複数回二重にカウントされるのを防ぎます。 計算`(w_sum + w - 1) // w`整数の除算を切り上げます。これは次と同等です。`ceil(w_sum / w)`これにより、部分的なマナの蓄積が完全に 1 秒としてカウントされるようになります。
