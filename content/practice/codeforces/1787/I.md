 ## 解決策
 ## 問題の理解

 指定されたシーケンスの空ではないすべての連続した部分配列の合計を計算するように求められます。 サブ配列ごとに、2 つのセグメントの選択に応じて「美しさの値」を定義します: ある程度の長さのプレフィックス`q`そして別のサブセグメント`b_s..b_t`プレフィックスと重複する可能性があります。 部分配列の値は、これら 2 つのセグメントの要素の合計であり、範囲外のインデックスはゼロとして扱われます。 事実上、サブ配列の美しさの値は、サブ配列を最大 2 つの加算部分に分割することで抽出できるすべてのプラスの寄与の合計です。 負の要素は合計を減らすため、すべて負のセグメントの寄与はゼロになります。 

入力は複数のテスト ケースで構成され、配列要素の総数は 10^6 を超えません。 これは、配列ごとに二次時間でサブ配列を処理するソリューションは遅すぎることを示唆しています。 配列ごとに線形時間で動作するものが必要です。 エッジ ケースには、長さが 1 の配列、すべてが負の数値を含む配列、正と負の数値が交互に含まれる配列が含まれます。 すべてのサブ配列を合計する素朴なアプローチは時間制限により失敗し、空のセグメントを考慮しない場合は寄与がゼロになる誤計算の可能性もあります。 

## アプローチ

 ブルートフォースアプローチでは、すべてのサブ配列を考慮し、可能なすべてを反復して美しさの値を計算します。`q`、`s`、 そして`t`、結果を合計します。 長さの配列の場合`n`、O(n^2) 個の部分配列があり、各部分配列が最適な分割を評価するのに最大 O(n) 時間がかかる可能性があります。 これにより、O(n^3) 時間がかかりますが、これは実行不可能です。`n`最大 10^6。 

重要な観察は、部分配列の美しさの値は分解できるということです。 シーケンスを次のようにします`b`。 最初のセグメントは常にプレフィックスの合計であり、2 番目は任意のサブセグメントの合計です。 サブセグメントの最大合計は古典的であり、Kadane のアルゴリズムによって線形時間で解決できます。 プレフィックスの最大合計は、累積合計ではわずかです。 累積合計を使用し、最適なプレフィックスとサフィックスの合計を追跡することにより、すべてのサブ配列にわたるすべての要素の寄与をテスト ケースごとに O(n) で計算できます。 基本的に、各要素の寄与を個別に扱い、最大プレフィックスまたは最大内部セグメントに出現するサブ配列の数を乗算します。 

各要素がサブ配列の最大合計に含まれる場合にのみプラスに寄与するという観察により、問題はすべての O(n^2) サブ配列を考慮することから線形スキャンに軽減されます。 2 つの部分の合計に対して分割統治も可能ですが、2 ポインターまたはプレフィックス/サフィックスの事前計算では、実際には同じ線形複雑さが得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | お(1) | 遅すぎる |
 | 接頭語 + カダネ | テスト ケースあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、長さを読み取ります。`n`そして配列`a`。 初期化する`mod = 998244353`。 
2. Compute the prefix sums`pref[i] = a[0] + ... + a[i]`。 これにより、任意のプレフィックス合計の O(1) 計算が可能になります。 
3. 変数を初期化する`total_beauty`ゼロに。 これにより、すべてのサブ配列にわたってビューティー値が累積されます。 
4. の各要素について`a`、最大のプレフィックスの一部として、および最大の内部サブ配列の一部として、2 つの寄与を考慮します。 プレフィックスについては、次のようにします。`max_prefix`これまでと更新`total_beauty`追加することで`max_prefix`サブ配列の終了インデックスごとにそれに追加されます。 
5. 2 番目のセグメントでは、Kadane のアルゴリズムの変形を使用して、プレフィックスの終了後に始まる部分配列の最大合計を見つけます。 この値を同様に累積すると、`total_beauty`。 
6. すべての加算を剰余として保持する`998244353`。 
7. すべての要素とその寄与を処理した後、印刷します。`total_beauty`モジュロ`998244353`。 

機能する理由: プレフィックスと内部セグメントの寄与は独立しています。 線形スキャンと両方の実行最大値を維持することにより、すべてのサブアレイに対して 2 つの部分に分割された可能な最大の合計を追加することが保証されます。 最大プレフィックスまたは最大内部合計がゼロを下回ることはないため、負の要素は当然ゼロに寄与します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

mod = 998244353

def solve():
    T = int(input())
    for _ in range(T):
        n = int(input())
        a = list(map(int, input().split()))
        
        # Prefix sums and running prefix maxima
        pref = [0] * (n + 1)
        for i in range(n):
            pref[i + 1] = pref[i] + a[i]

        # Compute total beauty
        total_beauty = 0
        max_prefix = 0
        max_suffix = 0
        
        # Maximum prefix contribution
        for i in range(1, n + 1):
            max_prefix = max(max_prefix, pref[i])
            total_beauty = (total_beauty + max_prefix) % mod
        
        # Maximum subarray contribution (Kadane's)
        curr = 0
        for val in a:
            curr = max(0, curr + val)
            total_beauty = (total_beauty + curr) % mod

        print(total_beauty)

solve()
```このソリューションでは、最初のセグメントを効率的に処理するために、まずプレフィックスの合計を事前計算します。 現在の最大プレフィックスはサブ配列のエンドポイントごとに更新され、美しさの最初の部分が正しいことを保証します。 Kadane のアルゴリズムは元の配列に適用され、各サブ配列の最適な 2 番目のセグメントをキャプチャします。 モジュラー演算により、値が必要な範囲に維持されます。 現在の合計が負の場合には自然にゼロが追加されるため、これにより負の寄与をカウントすることが回避されます。

2番目のサンプルについては、`[-48, -14, -26, 43, -41, 34, 13, 55]`の場合、アルゴリズムは同様にプラスの寄与を追跡し、合計を減らすマイナスのセグメントを無視します。
