 ## 解決策
 ## 問題の理解

 直線上の整数点に配置された人々のセットが与えられています。 各人は固定座標から開始し、最大で 1 歩左に移動するか、その場に留まるか、1 歩右に移動することが許可されます。 全員が選択を行った後、複数の人が同じ座標を使用することになる可能性がありますが、私たちが気にするのは、最終構成で占有される個別の座標の数だけです。 

タスクは、すべての有効な移動割り当ての 2 つの極端な値を決定することです。 まず、占有位置の可能な最小限の数。これは、移動ルールが許す限り密に人々をクラスター化することに対応します。 2 番目は、占有位置の最大可能数です。これは、「最大 1 つずつ移動」という制約に違反することなく、占有位置を可能な限り分散することに対応します。 

制約により、最大 200,000 人が許可されます。 このサイズでは、すべての動きの組み合わせを列挙したり、すべての割り当てをシミュレートしようとするソリューションは除外されます。各人には 3 つの選択肢があり、ブルート フォースが爆発的に爆発するためです。 二次時間で配列を繰り返しスキャンする貪欲な構築でさえ遅すぎるため、有効なアプローチはソート後に本質的に線形または線形に近いものでなければなりません。 

複数の人が同じポジションまたは連続したポジションからスタートする場合、微妙なエッジケースが発生します。 たとえば、全員が位置 2 にいる場合、位置 1、2、および 3 にしか分散できないため、n が大きい場合でも、最大個別カウントは 3 になります。 一方、[1、3、5] のように位置がすでに十分に離れている場合、重複する可能性は低いため、最小値はすでに最大値に近くなります。 

もう 1 つのコーナー状況は境界位置 1 と n で、移動によって人が 0 または n+1 に押し込まれる可能性があります。 これらの追加の位置は有効なエンドポイントであり、境界で利用可能なスラックを使用して衝突を回避したいという最大の場合にのみ重要です。 

## アプローチ

 ブルート フォースの見方は簡単です。各人に対して 3 つのポジションから 1 つを選択し、その結果のセット サイズを計算します。 これにより、解空間全体が正しく探索されますが、構成の数は 3^n であり、n が 200,000 までの場合はまったく実現不可能です。 20くらいのnでもボーダーラインになります。 

重要な観察は、構造が本質的に変位が制限された一次元の充填であるということです。 位置がソートされると、衝突と分離は隣接する値間の局所的な相互作用のみに依存します。 これにより、配列を順番に処理し、最終的な位置の割り当て方法をローカルで決定することが可能になります。 

最大の場合、重複を避けたいので、各人は一意の整数の位置を占有しようとします。 元の各位置 x_i では [x_i - 1, x_i + 1] の最終値が許可されるため、この間隔内にある最も左の可能な自由な位置を貪欲に割り当てることができます。 これは、ライン上で間隔をスケジュールするという古典的なアイデアです。各人が間隔を作成し、その中の個別の点を選択します。 

最小のケースでは、直感を逆にします。 分散するのではなく、できるだけ多くのポイントを統合したいと考えています。 問題は、できる限り少数の個別の「クラスター」を形成することに帰着します。各クラスターは、±1 の柔軟性により複数の点を吸収できる整数の連続セグメントに対応します。 ソートすると、現在のクラスターを可能な限り拡張することを貪欲に試みることができます。 次のポイントを吸収できない場合は、新しいクラスターを開始します。 

各要素が 1 回処理され、決定は最後に選択された位置またはクラスター境界のみに依存するため、ソート後はどちらの解も線形になります。

 ## アルゴリズムのチュートリアル

まず、近傍を一貫して推論できるように位置の配列を並べ替えます。 

### 占有住宅の最大数

 1. 変数を初期化する`last`最後に占有された位置を表す非常に小さな値に設定されます。 
2. ソートされた位置を反復処理します。 
3. ポジションごとに`x`、許容される間隔を考慮してください`[x-1, x+1]`。 
4. この間隔内で、厳密に次の値よりも大きい最小値を選択します。`last`。 これにより、前の人がすでに取得した座標を再利用することがなくなります。 
5. そのような値が存在する場合は、それを割り当てて更新します`last`。 それ以外の場合は、この人をスキップしてください。 

常に最小の実現可能な値を選択する理由は、スペースを早期に消費しても、将来のオプションに害を及ぼすだけだからです。 割り当てを遅らせても、後のポジションに割り当てられる余地が減るだけです。 

### 最小占有住宅数

 1. 変数を初期化する`last_used`非常に小さな値にします。 
2. カウンターを維持する`groups`0から始まります。 
3. ソートされた位置を反復処理します。 
4. それぞれについて`x`、次のことを確認して、現在のグループにマージできるかどうかを判断します。`x-1 <= last_used + 1`。 
5. 「はい」の場合、設定によって現在のグループを拡張します。`last_used = min(x+1, last_used + 1)`。 
6. それ以外の場合は、新しいグループを開始して増分します。`groups`、設定`last_used = x + 1`。 

各グループは、選択されたすべての最終位置が ±1 の柔軟性を介して重複できる最大の連続領域を表すという考えです。 

### なぜ効果があるのか

 最大の場合、すべての割り当ては、ソートされた各位置の周囲の単位間隔内に点を配置することと同等です。 貪欲ルールは常に最も早い利用可能なスロットを選択します。これにより、後の割り当てでは以前の有効な位置をスキップするメリットが得られないため、将来の実現可能性が最大限に維持されます。 

最小の場合、プロセスは最大の重複セグメントを構築します。 新しいポイントを現在のセグメントに吸収できない場合、順序と制限された変位により、有効な割り当てによって以前のポイントとマージすることはできません。 したがって、新しいグループの開始が強制されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    # maximum number of distinct positions
    last = -10**18
    max_ans = 0

    for x in a:
        # try to assign x-1, x, or x+1
        for p in (x - 1, x, x + 1):
            if p > last:
                last = p
                max_ans += 1
                break

    # minimum number of distinct positions
    groups = 0
    last_used = -10**18

    for x in a:
        if x - 1 > last_used:
            groups += 1
            last_used = x + 1
        else:
            last_used = min(last_used, x + 1)

    print(groups, max_ans)

if __name__ == "__main__":
    solve()
```最初のループでは、許可された範囲内で可能な限り早い自由座標を各人に貪欲に割り当てることで、最大値を構築します。 3 つのオプションにわたる内部ループは、常に左から右に試行し、将来のスペースの消費を最小限に抑えるため、安全です。 

2 番目のループでは、最小限のクラスターが構築されます。 次の位置が現在到達可能なセグメントと重なることができない場合は、新しいグループを開始する必要があります。 それ以外の場合、セグメントは拡張され、最も遠くに到達可能な結合点を追跡します。 

どちらの場合でも並べ替えは不可欠です。 それがなければ、隣接情報は無意味になり、貪欲な決定は失敗します。

 各人に明確なポジションが割り当てられ、4 を達成していることがわかります。 

#### 最小限の構築

 | ステップ | × | 最後に使用した | アクション | グループ |

これは、連続またはほぼ連続した値の周囲に密集したクラスターがどのように形成されるかを示しています。

 それらを次のように配置できます`[2,3,4,1,5]`割り当てを順序付けした後、5 つの異なる位置が得られます。

 ## 特殊なケース

 すべての値が同一の場合、最小値はすべてを 1 つのクラスターにまとめますが、最大値は ±1 の自由度を完全に使用してすべての点を分離します。 

値がすでに十分に分離されている場合、各ポイントは独自のクラスターを形成し、両方の答えが一致するため、アルゴリズムが独立したコンポーネントを人為的にマージしていないことが確認されます。 

値が 1 や n などの境界にある場合、0 または n+1 に移動できるため、最大のケースでも分離を維持できます。これは、許可された間隔をすべての位置で均一に扱うことで自然に処理されます。
