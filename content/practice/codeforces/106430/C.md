 ## 解決策
 ## 問題の理解

 整数の配列が与えられており、正確に K 回のスワップ操作を使用してそれを逆に変換できるかどうかを判断したいと考えています。 スワップ操作は、配列内の任意の 2 つの位置の値を交換します。 

自然な目標は、配列をその反転バージョンと同一にするために必要なスワップの最小数を理解し、正しい最終状態で終了しながら正確に K に一致するように操作の数を上方に調整できるかどうかを検討することです。 

重要な観察は、反転構造がインデックス i とインデックス n − 1 − i をペアにすることです。 スワップ後に配列が回文になるには、そのような各ペアの値が等しくなる必要があるため、問題はスワップを使用して不一致のミラーリングされたペアを修正することに帰着します。 

制約は明示的に提供されていませんが、このタイプの典型的な Codeforce の問題には、最大 10^5 要素の配列が関係します。 これは、スワップをシミュレートしたり、一連の操作を検索したりするソリューションは不可能であることを直ちに意味します。 解決策では、問題を配列に対する少数の算術演算またはカウント演算に減らす必要があります。 

いくつかの特殊なケースが構造的に重要です。 

たとえば、すべての要素がすでに対称である場合、`[1, 2, 3, 2, 1]`、スワップの最小数はゼロです。 スワップが必要であると常に想定する単純なアプローチでは、誤って過大評価されてしまいます。 

重複が存在する場合は、次のようになります。`[1, 1, 1, 1]`、対称位置を交換しても何も起こらない可能性があり、最小限必要な操作が変更されます。 

K が最小必要スワップより小さい場合、たとえ操作を任意に再配置できたとしても、答えは直ちに不可能になります。 

## アプローチ

 ブルートフォース解釈は、反転された配列への変換を明示的にシミュレートすることになります。 各位置 i をそのターゲット位置 n − 1 − i と一致させようとし、不一致が見つかるたびに貪欲に交換を実行することができます。 これにより、一連のスワップが正しく構築されますが、各スワップで正しい要素の検索が必要になる可能性があり、最悪の場合 O(n^2) の動作が発生するため、非効率的になります。 

重要な洞察は、実際にはスワップのシーケンスを構築する必要がないということです。 必要な情報は 2 つだけです。反転された構成に到達するために必要なスワップの最小数 X と、最終結果を変更せずに追加のスワップを挿入できるかどうかです。 

配列はミラーリングされたペア (i, n − 1 − i) に分解されます。 ペアにすでに同じ値が含まれている場合、そのペアを交換する必要はありません。 それ以外の場合は、必要な修正が 1 回行われたとみなします。 これにより、⌊in/2⌋ に近いベースライン X が得られ、対称ペアが一致する場合に下方に調整されます。 

X がわかったら、残りの問題は、正確に K 個のスワップに到達する方法です。 

アレイに重複がない場合、すべてのスワップが構成に目に見える影響を与えます。 最終状態を保存するには、追加のスワップを後で元に戻す必要があるため、追加の操作はペアで行われ、K − X が偶数になるように強制されます。 

重複が存在する場合は、配列をまったく変更せずに、等しい要素間の交換を実行できます。 これにより、X を超える追加のスワップを無制限に吸収することができます。

 ## アルゴリズムのチュートリアル

 ### 1. ミラーリングされたペアをカウントし、重複を検出します

 配列の両端から反復処理を行い、位置 i と n − 1 − i を比較します。 値が異なる場合、このペアはスワップの基本数 X に寄与します。同時に、値が複数回出現するかどうかを追跡します。これにより、余分なスワップを「隠す」ことができるかどうかが決定されるためです。 

このステップが機能するのは、各スワップが最適な構造で最大 1 つのミラーリングされた不一致を修正できるためです。 

### 2. 最小限必要なスワップ X を計算します。 

各ペアは潜在的な不一致に対応するため、X を ⌊in/2⌋ として初期化します。 すでに一致している対称ペアごとに、交換の必要がないため、X を 1 つ減らします。 

これにより、実際に修正が必要なペアの正確な数が得られます。 

### 3. 実現可能条件 K ≥ X を確認します。 

K が X より小さい場合、すぐにそれは不可能であると結論付けます。 最適なスワップであっても、不一致を修正するために必要な構造上の最小値を下回る操作数を減らすことはできません。 

### 4. 重複ケースと非重複ケースを処理する

 すべての要素が異なる場合、スワップのたびに構造が変更されるため、追加のスワップは相殺される必要があります。 各「実行と元に戻す」サイクルには 2 つのスワップがかかるため、K − X は偶数でなければなりません。 

重複が存在する場合、配列に影響を与えることなく、等しい値の間でスワップを自由に実行できます。つまり、追加のスワップ数は吸収できます。 

### なぜ効果があるのか

 このアルゴリズムは、不一致のミラーリングされたペアをすべて修正した後、同一の値の順列に至るまで配列が一意に決定されるという不変条件に依存しています。 すべての値が異なる場合、スワップによって順列状態が変更されるため、同じ構成に戻すにはペアリングのスワップが必要になります。 重複が存在する場合は、配列状態で操作なしとして機能する非同一性順列が存在し、操作の任意のパディングが可能になります。 これにより、問題が構造的な下限と値の繰り返しのみに依存する柔軟性条件に分離されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))
    
    x = n // 2
    
    for i in range(n // 2):
        if a[i] == a[n - 1 - i]:
            x -= 1
    
    # check duplicates
    seen = set()
    has_dup = False
    for v in a:
        if v in seen:
            has_dup = True
        seen.add(v)
    
    if k < x:
        print("NO")
        return
    
    if has_dup:
        print("YES")
    else:
        print("YES" if (k - x) % 2 == 0 else "NO")

if __name__ == "__main__":
    solve()
```実装はアルゴリズム構造に直接に従います。 ミラーリングされたペア ループは、n/2 の単純な上限を修正することによって、スワップの最小数を計算します。 重複検出はセットを使用して線形時間で行われます。必要なのはカウントではなくブール値のフラグだけであるため、これで十分です。 

最終的な決定は 2 つの概念的なケースに分かれます。重複の場合、余分なスワップは常に吸収可能です。 重複がない場合、パリティ制約により、偶数のスワップ数のみが有効になります。 

## 実用的な例

 ### 例 1

 入力:`n = 5, k = 2, a = [1, 2, 3, 2, 1]`| 私 | a[i] | a[n-1-i] | 不一致 | X |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 1 | いいえ | 2 |
 | 1 | 2 | 2 | いいえ | 2 |

 ここで X = 2 は最初は n//2 = 2 ですが、不一致がないためさらに小さくなり、X = 0 になります。 

重複も検出します (1 と 2 が複数回出現します)。 

k = 2 ≥ X = 0 で重複が存在するため、任意の K が機能します。 

出力: はい

 これは、重複によってパリティ制限が完全に削除される様子を示しています。 

### 例 2

 入力:`n = 4, k = 3, a = [1, 2, 3, 4]`| 私 | a[i] | a[n-1-i] | 不一致 | X |
 | --- | --- | --- | --- | --- |
 | 0 | 1 | 4 | はい | 2 |
 | 1 | 2 | 3 | はい | 2 |

 X = 2 であり、すべての要素は個別です。 

k ≥ 2 が必要であり、k − 2 は偶数でなければなりません。 ここで、k − x = 1 は奇数です。 

出力: いいえ

 これは、重複が存在しない場合のパリティ制限を示しています。

 ## 特殊なケース

 ### すべての要素が同一

 入力:`[7, 7, 7, 7]`すべてのミラーリングされたペアは一致するため、X = 0 になります。重複フラグは true であるため、任意の K が受け入れられます。 アルゴリズムは、実現可能性 K ≥ 0 が成立する限り、K に関係なく YES を正しく出力します。 

### 奇数の追加スワップを含む厳密に異なる配列

 入力:`[1, 2, 3, 4]`、K = 3

 X = 2 を計算します。重複がないため、K − X が偶数である必要があります。 ここでは 1 であるため、アルゴリズムは拒否します。 これにより、構造を維持しながら単一のスワップを「無駄にする」という無効な試みが回避されます。これは、ペアの構成を破壊して復元することなしには不可能です。 

### すでに反転回文

 入力:`[1, 3, 3, 1]`すべてのミラーリングされたペアが一致するため、X は 0 になります。 重複が存在する場合、どの K も有効です。 重複がない場合は、キャンセルするペアにスワップを追加する必要があるため、K のみが有効です。
