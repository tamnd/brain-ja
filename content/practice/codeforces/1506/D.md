 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、互いに異なる要素のペアを繰り返し削除できます。 私たちのタスクは、この操作を何度でも適用した後に配列が取り得る最小サイズを決定することです。 入力は複数のテスト ケースで構成され、それぞれが独自の配列を持ちます。 出力は、最適なペアの削除後の各配列の可能な最小限の長さです。 

制約を見ると、配列は 1 つのテスト ケースで 2×10^5 要素まで大きくなり、すべてのテスト ケースの合計は 2×10^5 に制限されます。 これにより、考えられるすべてのペアの削除を明示的にシミュレートしようとするソリューションは即座に除外されます。これは、最悪の場合、O(n^2) 操作が含まれる可能性があるためです。 テストケースごとに線形または線形に近いアプローチが必要です。 各要素の値は最大 10^9 と非常に大きくなる可能性があるため、値自体でインデックス付けされた周波数配列の作成に依存するソリューションは実行不可能です。 値の範囲ではなく、カウントを扱う必要があります。 

注意が必要なエッジケースには、すべての要素が等しい配列が含まれます。 例えば、`[1, 1, 1]`ペアを削除することはできないため、結果は 3 になります。もう 1 つの注意が必要なシナリオは、最も頻繁に出現する数値のカウントが配列を支配する場合です。 例えば、`[1, 1, 1, 2, 3]`2 つのペアのみを削除できます (`1-2`そして`1-3`)、1つを残す`1`後ろに。 カウントの分布を考慮しない場合、ペアを恣意的に削除する単純なアプローチでは、最適ではない最終サイズが生成される可能性があります。 

## アプローチ

 ブルートフォース手法では、2 つの異なる数値を繰り返し削除するシミュレーションを行います。 ペアを選択して削除し、ペアがなくなるまでこれを繰り返します。 これは、慎重に実装すれば正しい答えが得られることが保証されていますが、最悪の場合の複雑さは O(n^2) であり、n = 2×10^5 には遅すぎます。 

重要な洞察は、各数値の頻度を知る必要があるだけであるということです。 最も頻繁に出現する数値があると仮定します。`max_count`回と残りの要素の合計`rest_count = n - max_count`。 もし`rest_count`以上です`max_count`次に、最も頻繁に出現するすべての数値を別の要素と組み合わせて、パリティに応じて配列を 0 または 1 の要素に減らすことができます。 もし`rest_count`未満です`max_count`、他のすべての要素を最も頻繁に使用される要素と組み合わせた後でも、`max_count - rest_count`削除できない要素が残っています。 したがって、最小配列サイズは次のようになります。`max(1, max_count - rest_count)`もし`max_count > rest_count`そして`n % 2`さもないと。 

この観察により、周波数マップを使用して各テスト ケースを O(n) 時間で解決できるようになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2) | O(n) | 遅すぎる |
 | 周波数分析 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. テスト ケースごとに、配列の長さを読み取ります。`n`そして配列`a`。 
3. 配列内の各数値の出現を数えます。 これは辞書を使用するか、`collections.Counter`。 
4. 最大周波数を特定する`max_count`。 
5. 他のすべての周波数の合計を計算します。`rest_count = n - max_count`。 
6. もし`max_count`より大きい`rest_count`、最小配列サイズは次のとおりです。`max_count - rest_count`これらの要素は異なるものと組み合わせることができないためです。 
7. もし`max_count`以下である`rest_count`そうすると、0 または 1 個の要素が残るまでペアを最適に削除できるため、最小サイズは次のようになります。`n % 2`。 
8. 各テスト ケースの最小サイズを出力します。 

ここでの不変条件は、最大周波数要素が残りの要素の下限を決定するということです。 他の要素と組み合わせるのに十分な場合は、すべて削除できます。 そうしないと、余分な部分が残ります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

t = int(input())
for _ in range(t):
    n = int(input())
    a = list(map(int, input().split()))
    freq = Counter(a)
    max_count = max(freq.values())
    rest_count = n - max_count
    if max_count > rest_count:
        print(max_count - rest_count)
    else:
        print(n % 2)
```コードはまず、すべての入力を効率的に読み取ります。`Counter`頻度マップを作成することで、最も一般的な要素を迅速に決定できます。`max_count`そして`rest_count`最小配列サイズを決定するために必要な 2 つの重要な量を取得します。 次に、アルゴリズムからの推論を直接適用します。最も頻繁に使用される要素が優勢な場合は、超過分を出力します。 それ以外の場合は、最大ペアリング後の配列サイズのパリティを出力します。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | テスト ケースあたり O(n) | 頻度のカウントは線形であり、小さな辞書での最大値の検出は一意の要素で線形であり、合計 ≤ n です。 |
 | スペース | O(n) | 配列と周波数マップを保存します。 周波数マップには最大で n 個のキーがあります。 |

## テストケース```python
import sys, io
from collections import Counter

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = []
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        freq = Counter(a)
        max_count = max(freq.values())
        rest_count = n - max_count
        if max_count > rest_count:
            output.append(str(max_count - rest_count))
        else:
            output.append(str(n % 2))
    return "\n".join(output)

# provided samples
assert run("5\n6\n1 6 1 1 4 4\n2\n1 2\n2\n1 1\n5\n4 5 4 5 4\n6\n2 3 2 1 3 1\n") == "0\n0\n2\n1\n0"

# custom cases
assert run("1\n1\n42\n") == "1"  # single element
assert run("1\n4\n7 7 7 7\n") == "4"  # all equal
assert run("1\n5\n1 2 3 4 5\n") == "1"  # all unique odd
assert run("1\n6\n1 1 2 2 3 3\n") == "0"  # all paired perfectly
assert run("1\n7\n1 1 1 2 2 2 3\n") == "1"  # one excess
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`1\n1\n42`| 1 | 単一の要素をペアにすることはできません。 
|`1\n4\n7 7 7 7`| 4 | すべての要素が同一 |
 |`1\n5\n1 2 3 4 5`| 1 | すべての一意の奇数の要素 |
 |`1\n6\n1 1 2 2 3 3`| 0 | すべての要素を正確にペアにすることができます。 
|`1\n7\n1 1 1 2 2 2 3`| 1 | 最大限のペアリング後に過剰な要素が残る |

 ## 特殊なケース

 すべての要素が等しい配列の場合、アルゴリズムは次のように計算します。`max_count = n`、`rest_count = 0`、および出力`max_count - rest_count = n`。 例えば、`[7, 7, 7, 7]`正しく 4 を出力します。次のように、まったく 2 つの異なる要素が同じ数で出現する配列の場合、`[1, 1, 2, 2]`、`max_count = 2`、`rest_count = 2`、出力は`n % 2 = 4 % 2 = 0`、すべて削除できることを確認します。 このソリューションは、単一要素の配列、1 つの支配的な数値を持つ配列、および完全なペアリングの機会を持つ配列を正しく処理します。
