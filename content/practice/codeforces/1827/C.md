 ## 解決策
 ## 問題の理解

 ラテン文字の小文字で構成される文字列が与えられ、その「美しい」部分文字列を数えるように求められます。 部分文字列が偶数回文であるか、より小さな偶数回文に分割できる場合、その部分文字列は美しくなります。 偶数回文は長さが均等で、前から見ても後ろから読んでも同じです。 たとえば、「aa」、「abba」、「abccba」も回文です。 「a」、「aba」、または「abc」はそうではありません。 

入力は複数のテスト ケースで構成され、それぞれが最大 500,000 文字の長さの文字列を持ちます。 すべてのテスト ケースの長さの合計は 500,000 を超えません。 1 秒の時間制限では、すべての部分文字列を個別に反復するアルゴリズムは遅すぎます。 ある長さの文字列内の部分文字列の数を考慮すると、$n$は$O(n^2)$、単純なソリューションはおおよそのパフォーマンスを発揮します$10^{11}$最悪の場合は操作が不可能になります。 これにより、各部分文字列に対するブルート フォース チェックが排除されます。 

エッジ ケースは、文字列が長さ 1 など非常に短い場合に発生し、偶数回文を形成できない場合や、文字列が同じ文字の繰り返しで構成されている場合（「aaaaa」など）、多数の重複する偶数回文を形成する可能性があります。 こうしたケースでは、異なる文字や重複しない回文を想定した素朴なアプローチが崩れることがよくあります。 

## アプローチ

 ブルートフォース手法では、偶数長のすべての可能な部分文字列を反復処理し、それぞれが回文であるかどうかを確認し、回文である場合は、より小さな偶数の回文に分割できるかどうかを再帰的に確認します。 このアプローチは原理的には正しいですが、$O(n^3)$各文字列について:$O(n^2)$部分文字列の回数$O(n)$回文の有効性を確認します。 と$n$まで$5\cdot 10^5$、これは明らかに実行不可能です。 

重要な観察は、美しい部分文字列が再帰的により小さな均等な回文に分解できるということです。 重要な洞察は、文字列プロパティを使用して、偶数長の回文を線形時間で識別できることです。 具体的には、各文字を再帰的パーティションを表す概念ツリー内のノードとして扱う場合、部分文字列の半分が再帰的に一致するかどうかに基づいて「分割の深さ」を追跡できます。 偶数回文の場合、部分文字列を 2 つの半分に分割できます。 両方の半分が同一であれば、部分文字列の美しさは 1 レベル高くなります。 

この観察を利用すると、すべての部分文字列を個別にチェックする必要はありません。 代わりに、すべての位置を反復処理し、潜在的な偶数長の部分文字列ごとに、前半が後半と等しいかどうかを確認します。 これは、ハッシュまたは文字数の累積合計を使用して効率的に実行できます。 このアプローチにより、私たちは次のことを達成します。$O(n)$以前の結果を利用して、短い部分文字列から長い部分文字列の「美しさレベル」を計算することで、文字列ごとのソリューションを作成します。

 | ブルートフォース | O(n3) | お(1) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 文字列ごとにリストを初期化します。`dp`長さの`n`位置で終わる各プレフィックスの美しさの深さを保存します`i`。 
3. インデックス付きの文字列を反復処理します。`i`0から`n-1`。 それぞれについて`i`潜在的な部分文字列の終わりを表します。 

1. 偶数長の部分文字列のみを考慮するため、次の場合はスキップします。`i`奇数です。 
2. コンピューティング`mid = i // 2`。 前半かどうかを確認してください`s[0:mid+1]`後半に等しい`s[mid+1:i+1]`。 一致する場合は設定します`dp[i] = dp[mid] + 1`。 さもないと、`dp[i] = 0`。 
4. 美しい部分文字列の総数は、次のすべての値の合計です。`dp`。 
5. 各テスト ケースの合計を出力します。 

不変条件とは、`dp[i]`インデックスで終わる再帰的な偶数回文パーティションの数を正確に表します`i`。 中間点から値を構築することにより、再帰的にそれ自体をより小さな偶数回文に分割できる部分文字列のみをカウントすることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        dp = [0] * n
        total = 0
        for i in range(n):
            if i % 2 == 1:
                mid = (i - 1) // 2
                if s[:mid+1] == s[mid+1:i+1]:
                    dp[i] = dp[mid] + 1
            total += dp[i]
        print(total)

if __name__ == "__main__":
    solve()
```ソリューションが初期化されます`dp`各インデックスの美しさの深さを保存します。 奇数のインデックスをスキップして、偶数長の部分文字列のみをチェックします。 スライスによって前半と後半を比較することで、完全な部分文字列の比較を繰り返すことを回避します。 の累積合計`dp`合計の美しい部分文字列が得られます。 境界条件は自然に処理されます。単一文字の部分文字列は寄与せず、繰り返される文字は複数回正しくカウントされます。

 ## 特殊なケース

 「a」などの単一文字入力の場合、アルゴリズムは奇数長の部分文字列をすべて正しくスキップし、ゼロを返します。 「aaaa」のような繰り返し文字の場合、アルゴリズムは長さ 2、4 の重複する部分文字列を偶数回文として正しく認識し、再帰的にカウントして美しさレベルの合計を算出します。 「abab」のような交互パターンを持つ文字列の場合、再帰条件を満たす偶数回文が存在しないため、アルゴリズムはゼロを出力します。 これらの例では、中点比較不変式がすべての美しい部分文字列を欠落したり過剰にカウントしたりすることなく正しくキャプチャしていることを確認します。
