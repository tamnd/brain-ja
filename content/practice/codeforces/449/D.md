 ## 問題の理解

 の配列が与えられます`n`負ではない整数。 グループは、配列インデックスの空でないサブセットです。 選択したグループについて、それらのインデックスのすべての値のビット単位の AND を計算します。 

タスクは、以下に等しいビット単位の AND を持つ空ではないグループの数を数えることです。`0`。 答えはモジュロで報告する必要があります`1000000007`。 

重要な点は、値ではなくインデックスを選択しているということです。 同じ番号が複数回出現する場合、異なるインデックスの選択は異なるグループとしてカウントされます。 

制約によって、必要なソリューションの種類が完全に決まります。 配列の長さは次のように大きくできます。`10^6`これにより、サブセットを直接検査するものはすべて即座に除外されます。 がある`2^n - 1`空ではないグループ、天文学的な数。 

さらに興味深い制約は値の範囲です。 毎`a[i]`せいぜい`10^6`、これは次の理由により 20 ビット以内に収まります。$$2^{20} = 1048576$$これは、すべての数値を最大 20 ビットのマスクとして表示できることを意味します。 サイズの状態空間`2^20 ≈ 10^6`大きいですが扱いやすいです。 問題が大きくなるたびに`n`しかしビット幅が小さい場合、これは多くの場合、サブセット空間ではなくマスク空間で作業する必要があることを示しています。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

考慮する：```
1
0
```唯一空ではないグループは、`{0}`そしてその AND は以下に等しい`0`、したがって、答えは次のとおりです`1`。 適切なタイミングで空のサブセットを除外することを忘れたソリューションでは、間違ったカウントが生成される可能性があります。 

考慮する：```
2
1 1
```考えられるグループは次のとおりです。`{1}`、`{1}`、 そして`{1,1}`。 すべてのグループの AND は等しい`1`、 一度もない`0`、したがって、答えは次のとおりです`0`。 インデックスのサブセットの代わりにマスクをカウントすると、重複した値が誤ってマージされ、過小カウントまたは過大カウントされる可能性があります。 

考慮する：```
3
0 7 7
```ゼロ要素を含むグループは、次の AND と等しくなります。`0`。 このようなグループは 4 つあります。```
{0}
{0,7(first)}
{0,7(second)}
{0,7(first),7(second)}
```正しい答えは、`4`。 これは、インデックスの多重度が重要である理由を示しています。 

もう 1 つの微妙な状況は、個々の数値が 0 ではないが、組み合わせによっては 0 が生成される場合です。```
2
1 2
```シングルトン グループには AND 値があります`1`そして`2`、しかし、このペアには次のような特徴があります。```
1 & 2 = 0
```答えは`1`。 個体値だけを見るだけでは不十分です。 

## アプローチ

 最も直接的な解決策は、インデックスの空でないすべてのサブセットを列挙し、選択されたすべての数値の AND を計算し、結果がゼロになる数をカウントすることです。 

これは正しいグループの定義を正確にチェックするためです。 残念ながら、`2^n - 1`空ではないグループ。 たとえ`n = 50`、これはすでに実行不可能です。 と`n = 10^6`、アプローチは完全に不可能です。 

より良い解決策を見つけるには、サブセットの AND に特定のビットが含まれることが何を意味するかを考える必要があります。 

マスクを修正するとします`m`。 のすべてのビットが含まれる配列要素の数を数えてみましょう。`m`。 言い換えると：```
(a[i] & m) = m
```サブセットの AND に次のすべてのビットが含まれる場合、`m`の場合、そのサブセット内のすべての要素には、`m`。 

これにより、問題は、マスクのスーパーセットである数値から抽出されたサブセットをカウントするという問題に変換されます。 

させて：```
cnt[m]
```マスクが次のスーパーセットである配列要素の数になります。`m`。 

次に、AND に含まれる空でないサブセットの数`m`等しい:```
2^(cnt[m]) - 1
```なぜなら、それらの空でない選択は`cnt[m]`要素はあらゆるビットを保持します`m`。 

これで、典型的な包含と排除の状況が生じました。 

定義する：```
F(m) = number of non-empty subsets whose AND contains m
```私たちが望んでいるのは:```
G(0) = number of non-empty subsets whose AND is exactly 0
```サブセット格子でメビウス反転を使用する:```
G(0) = Σ (-1)^(popcount(m)) * F(m)
```ここで、合計はすべてのマスクに適用されます。 

残りの課題はコンピューティングです`cnt[m]`あらゆるマスクに。 これはまさに SOS DP (Sum Over Subsets DP) 問題です。 正確な値の頻度カウントから開始して、マスクごとに、値がそのマスクのスーパーセットである配列要素の数を計算します。 

ソリューション全体は次の組み合わせになります。 

1. マスクの頻度をカウントします。 
2. スーパーセット数を取得するための SOS DP。 
3. すべてのマスクに対する包含/除外。

 ## アルゴリズムのチュートリアル

 ### 1. すべての正確なマスクの出現をカウントします。 

配列を作成する`freq`サイズの`2^20`。 

入力番号ごとに`x`、増分:```
freq[x]
```これは、各正確なマスクが何回出現したかを記録します。 

### 2. SOS DP を使用してスーパーセット数を構築する

 作成:```
dp = freq
```最初は`dp[m]`以下に等しい要素をカウントします`m`。 

私たちが望んでいるのは:```
dp[m] = number of elements whose masks are supersets of m
```からの各ビットに対して`0`に`19`そしてすべてのマスクについて:

 マスクにビットが設定されていない場合は、そのビットをオンにしたマスクのカウントを加算します。 

正式には:```
dp[mask] += dp[mask | (1 << bit)]
```20回すべてパスした後、`dp[m]`は次を満たす配列要素の数になります。```
(value & m) = m
```### 3. 2 の累乗を事前計算する

 あらゆる人にとって`i`から`0`に`n`計算します:```
pow2[i] = 2^i mod MOD
```頻繁に次のものが必要になります。```
2^(dp[m]) - 1
```これは、それらの要素から形成された空でないサブセットの数です。 

### 4. 包含/除外を適用する

 すべてのマスクについて:```
ways = 2^(dp[mask]) - 1
```これは、AND に次のすべてのビットが含まれる空でないサブセットをカウントします。`mask`。 

マスクに偶数の設定ビットがある場合は、次を追加します。`ways`。 

マスクに奇数のセットビットがある場合は、減算します。`ways`。 

数学的に:```
answer += (-1)^(popcount(mask)) * ways
```すべての演算はモジュロで実行されます`1000000007`。 

### 5. 結果を正規化する

 計算中に包含除外和が負になる場合があります。 

戻る：```
(answer % MOD + MOD) % MOD
```### なぜ効果があるのか

 SOS DP の後、`dp[m]`マスクに次のすべてのビットが含まれる配列要素を正確にカウントします。`m`。 これらの要素から選択された空でないサブセットには、次のすべてのビットも含まれる AND があります。`m`、与える`2^(dp[m]) - 1`サブセット。 

AND が何らかのマスクに等しい各サブセット`A`あらゆることに貢献します`F(m)`どこ`m`のサブマスクです`A`。 ブール格子の包含-除外により、過剰カウントが削除され、AND が正確に 0 であるサブセットが分離されます。 これはまさにサブセット マスクのメビウス反転公式であり、最終的な合計が AND であるグループの数と等しいことを保証します。`0`。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1000000007
BITS = 20
MAX_MASK = 1 << BITS

def solve():
    n = int(input())
    arr = list(map(int, input().split()))

    freq = [0] * MAX_MASK
    for x in arr:
        freq[x] += 1

    dp = freq[:]

    for bit in range(BITS):
        for mask in range(MAX_MASK):
            if (mask & (1 << bit)) == 0:
                dp[mask] += dp[mask | (1 << bit)]

    pow2 = [1] * (n + 1)
    for i in range(1, n + 1):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = 0

    for mask in range(MAX_MASK):
        ways = pow2[dp[mask]] - 1

        if mask.bit_count() & 1:
            ans -= ways
        else:
            ans += ways

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```最初のセクションでは、正確なマスクの頻度テーブルを構築します。 値が超えることはありませんので、`10^6`、サイズの配列を割り当てる`2^20`実現可能です。 

SOS DP は、正確な周波数をスーパーセット周波数に変換します。 ビットを処理するとき、すべてのマスクは追加の必要なビットを 1 つ含むマスクからの寄与を受け取ります。 20 次元すべてが処理された後、各状態には、そのマスクのスーパーセットである配列要素の数が含まれます。 

電力テーブルを使用すると、次の定数時間の評価が可能になります。`2^k`。 以来`k`と同じ大きさにすることができます`n`、事前計算を 1 回行うと、累乗を繰り返すよりもはるかに高速になります。 

最後のループはメビウス反転を実行します。 偶数パリティ マスクはプラスに寄与し、奇数パリティ マスクはマイナスに寄与します。 結果として得られる合計は、AND が 0 に等しい空ではないグループの数となります。 

よくある実装上の間違いは、スーパーセット数ではなく正確な頻度で包含/除外を使用しようとすることです。 逆数式は、SOS DP 値を計算した後にのみ機能します。
