 ## 解決策
 ## 問題の理解

 最大数の友人がその選択に満足できるように、友人のグループがちょうど 2 枚のピザを選ぶのを手伝ってください。 各友人にはお気に入りの具材のセットがあり、選択した 2 枚のピザの少なくとも 1 つに自分の好きな具材がすべて含まれていれば、友人は満足します。 各ピザには一定の材料と価格が設定されています。 複数のピザのペアが同じ数の友人を満足させる場合、合計価格が最小となるペアを選択する必要があります。 出力は単純に 2 つのピザのインデックスです。 

友達の数、$n$、ピザの数、$m$、それぞれの大きさは次のようになります。$10^5$。 考えられる材料の総数は 9 つであるため、各友人とピザには最大 9 つの材料が含まれます。これらの境界により、すべての材料を明示的にチェックするソリューションは除外されます。$n \times m^2$に達する組み合わせ$10^{15}$最悪の場合の運用。 代わりに、少数の材料を活用し、どの友人がピザ 2 枚で満足しているかをすぐに確認できる表現を使用する必要があります。 

微妙なエッジケースは、複数のピザが一緒に友人に必要な材料をすべてカバーしているのに、1 枚のピザではカバーできない場合に発生します。 たとえば、友人が食材 {1,2} を好み、ピザが [{1}、{2}] である場合、ピザを 1 つだけ選択しても、この友人は満足できません。 ピザごとの満足度を個別に評価する単純なアプローチでは、この友人は不満足であると誤ってカウントされてしまいます。 別の特殊なケースは、複数のピザのペアが同じ数の友人を満足させる場合に発生します。合計コストが最小のペアを選択する必要があります。 

## アプローチ

 総当たりのアプローチは簡単です。すべてのピザのペアを反復処理し、それらの材料の結合を計算し、その結合にすべての材料が含まれている友人の数を数えます。 最小限の合計コストで関係を解消し、満足する友人の最大数を与えるペアを追跡します。 これは原理的には正しいですが、$O(m^2 \cdot n \cdot k)$複雑さ、どこで$k \le 9$友人ごとの材料の数です。 と$m = 10^5$そして$n = 10^5$、これは完全に非現実的です。 

重要な洞察は、成分が 9 つだけであるため、成分のセットを 9 ビット整数 (ビットマスク) として表すことができるということです。 友人の好みセットとピザの材料は、それぞれ長さ 9 のビットマスクとしてエンコードできます。ビット単位の演算を使用すると、友人の好みが 1 枚のピザまたはピザの組み合わせによって満たされるかどうかを迅速に判断できます。 しかないので、$2^9 = 512$可能な材料セットがあれば、各材料セットに対して最も安価なピザを前処理できます。 次に、すべてをチェックするのではなく、$m^2$ピザのペアを直接計算すると、512 個の可能なセットの中からペアを考慮するだけで済み、比較の数が大幅に減ります。$10^{10}$おおよそに$512^2 = 262144$、それは実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m^2) | お(1) | 遅すぎる |
 | ビットマスク圧縮 | O(n + 2^9 * 2^9) | O(2^9) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各友人の好きな食材のセットを 9 ビット整数としてエンコードします。 各ビットは、友人がその食材を好むかどうかを表します。 
2. 各ピザの材料を 9 ビット整数としてエンコードします。 各ピザにもコストがかかります。 
3. 各ビットマスクをその正確な材料セットを使用した最も安いピザのインデックスにマッピングする辞書を維持します。 複数のピザが同じビットマスクを共有する場合、最適なペアには同じ材料セットが 2 回含まれる可能性があるため、2 つのピザを最も安価なものにしてください。 
4. 考えられる友人マスクごとに (最大 512)、そのマスクを持っている友人の数を数えます。 これにより、2 つのピザ マスクの結合にフレンド マスクが含まれるかどうかを確認することで、満足度を迅速に計算できます。 
5. ピザ マスクのすべてのペアを繰り返します (そのタイプのピザが少なくとも 2 つある場合は、同じマスクを 2 回使用することを含みます)。 各ペアについて、2 つのマスクの結合を計算します。 各フレンド マスクについて、ビットごとの AND を使用して、それが共用体に完全に含まれているかどうかを確認します。 満足した友達の数を合計します。 
6. 満足した友人の合計を最大にするピザのペアを追跡します。 複数のペアが同じ最大値をもたらす場合は、合計コストが最小のものを選択します。 出力用のインデックスを保存します。 
7. 選択した 2 つのピザのインデックスを出力します。 

機能する理由: ビットマスクと小さな材料世界を使用することで、すべてのピザを個別に検討するのではなく、すべての意味のある材料の組み合わせを考慮するという問題を軽減します。 ピザ マスクの各結合は、これら 2 つのピザを選択することで得られる材料を正確に表します。 ビットごとのチェックで満足した友人をカウントすることで、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
friend_count = [0] * 512  # count of friends for each mask

for _ in range(n):
    parts = list(map(int, input().split()))
    fmask = 0
    for ing in parts[1:]:
        fmask |= 1 << (ing - 1)
    friend_count[fmask] += 1

pizza_masks = {}
pizza_prices = {}
pizza_indices = {}

for idx in range(1, m + 1):
    parts = list(map(int, input().split()))
    price = parts[0]
    pmask = 0
    for ing in parts[2:]:
        pmask |= 1 << (ing - 1)
    
    if pmask not in pizza_prices:
        pizza_prices[pmask] = [price]
        pizza_indices[pmask] = [idx]
    else:
        pizza_prices[pmask].append(price)
        pizza_indices[pmask].append(idx)
        # keep only two cheapest
        combined = sorted(zip(pizza_prices[pmask], pizza_indices[pmask]))
        pizza_prices[pmask], pizza_indices[pmask] = zip(*combined[:2])

best_count = -1
best_cost = None
best_pair = None

masks = list(pizza_prices.keys())
for i in range(len(masks)):
    for j in range(i, len(masks)):
        mask1, mask2 = masks[i], masks[j]
        cost1_list, cost2_list = pizza_prices[mask1], pizza_prices[mask2]
        idx1_list, idx2_list = pizza_indices[mask1], pizza_indices[mask2]

        if i == j and len(cost1_list) < 2:
            continue  # cannot pick same pizza twice if only one exists

        cost = cost1_list[0] + (cost2_list[0] if i != j else cost1_list[1])
        union_mask = mask1 | mask2
        count = 0
        for fmask in range(512):
            if friend_count[fmask] > 0 and (fmask & union_mask) == fmask:
                count += friend_count[fmask]

        if count > best_count or (count == best_count and cost < best_cost):
            best_count = count
            best_cost = cost
            if i != j:
                best_pair = (idx1_list[0], idx2_list[0])
            else:
                best_pair = (idx1_list[0], idx1_list[1])

print(best_pair[0], best_pair[1])
```コードはまず友達とピザをビットマスクとしてエンコードし、次にマスクごとに 2 つの最も安いピザを保存します。 マスク上のネストされたループにより、すべてを反復処理することなく、すべての実行可能なペアを考慮できるようになります。$m^2$ピザ。 ユニオンマスクとビット単位の AND 演算により、どの友達が満足しているかを効率的にチェックできます。
