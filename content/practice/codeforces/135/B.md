 ## 解決策
 ## 問題の理解

 平面上には 8 つの異なる点が与えられます。 タスクは、それらをそれぞれ 4 つの点からなる 2 つの互いに素なグループに分割することです。 

1 つのグループは正方形を形成する必要があります。 もう一方のグループは長方形を形成する必要があります。 長方形グループには正方形も許可されているため、2 番目の形状は長方形の条件を満たすだけで済みます。 

点は任意の順序で表示でき、形状は必ずしも軸に沿っているとは限りません。 回転された正方形と長方形は完全に有効です。 

出力では、そのようなパーティションが存在することを、対応するポイントのインデックスとともにレポートするか、有効なパーティションが存在しないことをレポートする必要があります。 

入力サイズが非常に小さいです。 ポイントは 8 つしかありません。つまり、サブセットに対するブルート フォースが完全に現実的であることを意味します。 あるのは$$\binom{8}{4} = 70$$正方形の 4 つの点を選択する方法。 これらが修正されると、残りの 4 つは自動的に長方形に属します。 

これは、本当の課題は最適化ではなく幾何学的検証であることを直ちに示唆しています。 

この問題の危険な部分は形状認識です。 実装を不注意にすると、無効な構成が有効な構成として誤って分類されやすくなります。 

次の点を考慮してください。```
0 0
1 0
2 0
3 0
```すべてのペアごとの距離は等しいわけではありませんが、誰かが「2 つの異なる距離」だけをチェックすると、この縮退した線が誤って通過する可能性があります。 正方形と長方形の両方に正の面積が必要です。 

もう 1 つのよくある間違いは、ポイントが循環的な順序で到着すると仮定することです。 例えば：```
0 0
1 1
0 1
1 0
```これらは正方形の頂点ですが、順序はシャッフルされています。 順列を考慮せずに隣接する辺を直接チェックするアルゴリズムは失敗します。 

回転した数字も重要です。 この四角形は有効です。```
0 0
2 1
3 3
1 2
```辺は軸に平行ではないため、x 座標と y 座標だけをチェックするのは正しくありません。 

最も安全なアプローチは、距離とベクトル ドット積を完全に操作することです。これらのプロパティは、回転や順序に関係なく有効なままであるためです。 

## アプローチ

 ブルーフォースのアイデアは単純明快です。 4 つの点のすべてのサブセットを正方形の候補として試します。 残りの4点が長方形の候補となります。 次に、選択したグループが本当に必要な形状を形成しているかどうかを個別に検証します。 

サブセットが 70 しかないため、高価な幾何学的チェックでも十分高速です。 

本当の問題は、正方形または長方形を確実に検証する方法です。 

素朴な幾何学的なアプローチは、点を中心の周りの角度で並べ替えてから、辺の長さと直角をテストすることです。 それは機能しますが、不必要に壊れやすいです。 浮動小数点の問題と順序付けの複雑さにより、実装が必要以上に難しくなります。 

より明確な観察は、正方形と長方形の両方が単純な対角特性を持っているということです。 

長方形の場合:

 1. 対角線の長さは等しい。 
2. 対角線は同じ中点を共有します。 
3. 面積がゼロではありません。 

正方形の場合、さらに次のものが必要です。 

1. 4 つの辺がすべて等しい。 
2. 対角線が等しい。 
3. 対角線が辺よりも長い。 

ポリゴンの順序を再構成する代わりに、ペアごとの距離を直接分析できます。 

4 つの点の場合、正確に 6 つのペアワイズ二乗距離が存在します。 

有効な正方形は以下を生成します。 

1. 4 つの等しい小さい距離、辺。 
2. 2 つの等しい大きい距離、対角線。 
3. 対角線の長さは、正方形の辺の長さの 2 倍に等しくなります。 

有効な四角形では次のものが生成されます。 

1. 辺の長さが等しい 2 つのペア。 
2. 2 つの等しい対角線。 
3. ポジティブエリア。 

さらにきれいな長方形チェックは順列から得られます。 4 点の順序は 24 個しかないため、考えられる循環順序をすべて試してテストすることができます。$$\overrightarrow{AB} \cdot \overrightarrow{BC} = 0$$そして$$|AB| > 0,\quad |BC| > 0$$反対側が等しいことが自動的に暗示されます。 

検索空間が小さいため、順列アプローチは完全に受け入れ可能であり、非常に信頼性があります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 幾何学的な再構築によるブルート フォース |$O(70 \cdot 24)$|$O(1)$| 承認済み |
 | 堅牢なチェックを備えた最適なサブセット ブルート フォース |$O(70 \cdot 24)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 8 つの点を読み取り、その座標を元のインデックスとともに保存します。 
2. 4 つのインデックスのすべてのサブセットを正方形の候補として列挙します。 
3. 長方形候補の 4 つのインデックスの相補的なサブセットを構築します。 
4. 最初のグループが正方形を形成しているかどうかを確認します。 

6 つのペアごとの二乗距離をすべて計算します。 

有効な正方形は、正確に 2 つの異なる正の値を生成する必要があります。$$\{s,s,s,s,d,d\}$$どこ$$d = 2s$$小さい値は辺を表し、大きい値は対角を表します。 
5. 2 番目のグループが長方形を形成しているかどうかを確認します。 

可能な巡回順序として 4 つの点のすべての順列を試します。 

ご注文の場合$A,B,C,D$、次のことを確認します。$$\overrightarrow{AB} \cdot \overrightarrow{BC} = 0$$これにより直角が保証されます。 

次に、次のことを確認します。$$|AB| = |CD|$$そして$$|BC| = |DA|$$正の辺の長さも合わせて。 
6. 両方のチェックが成功した場合は、印刷します。`"YES"`と対応する点のインデックス。 
7. すべてのサブセットをテストした後でパーティションが機能しない場合は、次のように出力します。`"NO"`。 

### なぜ効果があるのか

 このアルゴリズムは、8 つの点を 4 つずつ 2 つのグループに分割する可能性をすべて徹底的に試行します。 有効な回答はこの列挙から逃れることはできません。 

どの正方形にも必ず 4 つの等しい辺と 2 つの等しい対角線があり、ペアごとの距離が表示されるのはそれらだけであるため、正方形のテストは正しいです。 辺の長さは正でなければならないため、縮退構成は失敗します。 

すべての長方形には 4 つの直角があり、向かい合う辺が等しいため、長方形のテストは正しいです。 すべての順列を試すと、最終的には長方形の頂点の真の循環順序が得られることが保証されます。 

すべての候補パーティションは形状の数学的定義に対して正確にチェックされるため、アルゴリズムは無効な構成を受け入れたり、有効な構成を拒否したりすることはできません。 

## Python ソリューション```python
import sys
from itertools import combinations, permutations

input = sys.stdin.readline

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy

def is_square(points):
    dists = []

    for i in range(4):
        for j in range(i + 1, 4):
            dists.append(dist2(points[i], points[j]))

    dists.sort()

    if dists[0] == 0:
        return False

    return (
        dists[0] == dists[1] == dists[2] == dists[3]
        and dists[4] == dists[5]
        and dists[4] == 2 * dists[0]
    )

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def is_rectangle(points):
    for p in permutations(points):
        a, b, c, d = p

        abx = b[0] - a[0]
        aby = b[1] - a[1]

        bcx = c[0] - b[0]
        bcy = c[1] - b[1]

        cdx = d[0] - c[0]
        cdy = d[1] - c[1]

        dax = a[0] - d[0]
        day = a[1] - d[1]

        if dot(abx, aby, bcx, bcy) != 0:
            continue

        if dist2(a, b) == 0 or dist2(b, c) == 0:
            continue

        if dist2(a, b) != dist2(c, d):
            continue

        if dist2(b, c) != dist2(d, a):
            continue

        return True

    return False

def solve():
    pts = [tuple(map(int, input().split())) for _ in range(8)]

    indices = list(range(8))

    for square_ids in combinations(indices, 4):
        square_set = set(square_ids)

        rect_ids = [i for i in indices if i not in square_set]

        square_points = [pts[i] for i in square_ids]
        rect_points = [pts[i] for i in rect_ids]

        if is_square(square_points) and is_rectangle(rect_points):
            print("YES")
            print(*[i + 1 for i in square_ids])
            print(*[i + 1 for i in rect_ids])
            return

    print("NO")

solve()
```このソリューションには 2 つの独立したジオメトリ バリデーターがあります。 

スクエア チェッカーは、ペアワイズ距離の特性評価を使用します。 距離の二乗では平方根が回避されるため、すべての計算は整数のままになります。 これにより、浮動小数点の精度の問題が完全に解消されます。 

入力順序は任意であるため、長方形チェッカーは順列を使用します。 同じ 4 つの長方形の頂点は 24 の異なる順序で表示されますが、周囲を正しく歩くことに対応するのはそのうちの一部だけです。 

直角テストでは内積を使用します。$$\vec{u} \cdot \vec{v} = 0$$これは、標準的な整数セーフ直交性条件です。 

微妙な点の 1 つは、長さがゼロの辺を拒否することです。 このチェックを行わないと、反復ポイントまたは縮退ポイントが偶発的に等辺条件を満たしてしまう可能性があります。 この問題では、個別の入力点がグローバルに保証されますが、防御ジオメトリ コードでは依然として正の長さを明示的に検証する必要があります。 

もう 1 つの微妙な点は、実際のユークリッドの長さの代わりに二乗距離を使用していることです。 浮動小数点の平方根を直接比較するのは不必要であり、信頼性も低くなります。
