 ## 解決策
 ## 問題の理解

 バイナリグリッドが与えられます。 を含む細胞`'1'`使用可能なタイルを形成しながら、`'0'`細胞がブロックされます。 

私たちは完全に次のものから構成される最長のサイクルを望んでいます。`'1'`細胞。 サイクルはグリッド上の単純な閉曲線のように動作する必要があります。 サイクル上のすべてのセルは、隣接する他の 2 つのサイクル セルに正確に接触する必要があるため、形状が分岐したり自己交差したりすることはできません。 

もう 1 つ条件があり、これが難しい部分です。 毎`'1'`サイクル上にないセルは、囲まれた領域の外側になければなりません。 言い換えれば、サイクルは余分な要素を囲むことはできません。`'1'`細胞。 

答えは、そのようなサイクルに属するセルの最大数です。 

グリッドの大きさは次のとおりです。`1000 x 1000`、これは最大 100 万個のセルを意味します。 すべてのサブセット、すべての単純なサイクルを試行したり、セルごとに負荷の高いグラフ操作を実行したりするアルゴリズムは、すぐに失敗します。 線形時間に非常に近いものが必要です。 

最初の重要な観察は、有効な冷却サイクルが実際には接続されたコンポーネントの境界であるということです。`'1'`穴のないセル。 すべての境界セルはコンポーネント内にちょうど 2 次を持ち、コンポーネントには内部を含めることはできません。`'1'`境界条件から切り離されたセル。 

不注意な実装は、通常、枝や穴のある形状では失敗します。 

次のグリッドについて考えてみましょう。```
111
111
111
```外側のリングは長さのサイクルのように見えます`8`、ただし、中央のセルも`'1'`そして厳密にループの内側にあります。 正しい答えは、`0`。 

もう 1 つの危険なケースは、テールのあるコンポーネントです。```
1110
1011
1110
```左`3x3`リングは有効なサイクルですが、右側に接続されている余分なセルがサイクル頂点の 1 つの次数条件を破っています。 単純な境界計数ソリューションでは、誤ったレポートが生成されてしまいます。`8`。 

接続されていないコンポーネントも重要です。```
1110111
1010101
1110111
```長さは 2 つの別個のサイクルに分かれています`8`。 合計ではなく最大値を返す必要があります。 

最後に、細い廊下は自己接触構造を作成できます。```
1111
1001
1111
```これは有効です。なぜなら、すべてのサイクル セルにはサイクル内にちょうど 2 つの隣接セルがあり、隣接セルが 1 つも存在しないからです。`'1'`細胞が内部に閉じ込められています。 

## アプローチ

 強引なアイデアは、グリッドをグラフとして扱い、すべての単純なサイクルを列挙することです。 各サイクルについて、すべてのサイクル頂点に次数 2 があるかどうか、および他のすべての頂点に次数があるかどうかを検証できます。`'1'`細胞は外側にあります。 

定義がローカルであり、さらに封じ込め条件があるため、これは概念的に機能します。 残念ながら、グリッド グラフ内の単純なサイクルの数は指数関数的に増加します。 たとえ`20 x 20`グリッドには列挙するには多すぎるサイクルがすでに含まれています。 

したがって、冷却サイクルが実際に構造的にどのようなものであるかを理解する必要があります。 

の連結成分を取るとします。`'1'`細胞。 そのコンポーネント内のすべてのセルがコンポーネント内の次数がちょうど 2 である場合、そのコンポーネントは単純なサイクルを形成します。 すべての頂点が次数 2 を持つ接続されたグラフは、正確に 1 サイクルです。 

次に「インテリアなし」について考えてみましょう。`'1'`「セル」条件。コンポーネント自体が 1 つの単純なサイクルである場合、余分なサイクルはありません。`'1'`その中の細胞は、すべての`'1'`コンポーネントのセルはすでにサイクルに属しています。 閉じ込められたもの`'1'`セルは必ず同じ連結コンポーネントに属し、頂点次数が 2 を超えるように強制されます。 

これにより問題は完全に変わります。 幾何学的な推論や内部と外部のテストはもう必要ありません。 

接続されたコンポーネントを見つけるだけで済みます。`'1'`すべての頂点の次数がちょうど 2 であるセル。 

この等価性がわかると、解決策はグリッド上の単純なグラフ走査問題になります。 

グリッドをスキャンし、未訪問のすべてに対して DFS または BFS を実行します。`'1'`コンポーネントを調べ、そのサイズを数え、内部のすべてのセルにちょうど 2 つの隣接するセルがあることを確認します。`'1'`細胞。 

条件がコンポーネント全体に当てはまる場合、そのコンポーネントは 1 つの単純なサイクルであり、そのサイズが答えの候補となります。

 ## アルゴリズムのチュートリアル

 1. グリッドを読み取り、アクセスした配列を維持します。 
2. グリッド内のすべてのセルを繰り返し処理します。 
3. まだ訪れていないものに出会うたびに`'1'`セルにある場合は、そこから DFS または BFS を開始して、接続されているコンポーネントを調べます。 
4. 走査中に、コンポーネント内のセルの数を数えます。 
5. 訪問したセルごとに、隣接するセルの数を計算します。`'1'`。 重要なのは 4 つの基本的な方向のみです。 
6. コンポーネント内のいずれかのセルの隣接数が異なる場合`2`、コンポーネントを無効としてマークします。 
7. トラバースが終了したら、有効性フラグを確認します。 
8. コンポーネント全体が有効な場合は、コンポーネントのサイズを使用して回答を更新します。 
9. すべてのセルが処理されるまで続行します。 

### なぜ効果があるのか

 連結成分の内部で、次数がちょうど 2 であるすべてのセルは、成分グラフがサイクルであることを意味します。 グリッドの隣接性により単純な無向グラフが生成され、すべての頂点が次数 2 を持つ接続されたすべてのグラフが単一サイクルになります。 

コンポーネント自体には、到達可能なすべてのものが含まれています`'1'`細胞。 すべてのセルはサイクルに属しているため、別のセルが存在することはできません。`'1'`その中に閉じ込められた細胞。 これは冷却サイクルの定義と一致します。 

逆に、すべての冷却サイクルは、各頂点の次数がちょうど 2 である連結コンポーネントを形成します。 したがって、アルゴリズムは有効なサイクルを正確に受け入れ、それ以外はすべて拒否します。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]

    visited = [[False] * m for _ in range(n)]

    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    ans = 0

    for i in range(n):
        for j in range(m):
            if grid[i][j] == '1' and not visited[i][j]:
                q = deque()
                q.append((i, j))
                visited[i][j] = True

                size = 0
                ok = True

                while q:
                    x, y = q.popleft()
                    size += 1

                    deg = 0

                    for dx, dy in directions:
                        nx = x + dx
                        ny = y + dy

                        if 0 <= nx < n and 0 <= ny < m:
                            if grid[nx][ny] == '1':
                                deg += 1

                                if not visited[nx][ny]:
                                    visited[nx][ny] = True
                                    q.append((nx, ny))

                    if deg != 2:
                        ok = False

                if ok:
                    ans = max(ans, size)

    print(ans)

if __name__ == "__main__":
    solve()
```トラバーサルでは、グリッドを無向グラフとして扱います。 それぞれ`'1'`セルは頂点であり、辺の隣接によってエッジが作成されます。 

微妙な部分は次数の計算です。 トラバーサル ツリーからではなく、グリッドから直接近隣ノードをカウントします。 サイクルにはバック エッジが含まれるため、DFS ツリーのエッジ カウントは間違っています。 

もう 1 つの重要な詳細は、検出されたサイクル フラグメントだけでなく、接続されたコンポーネント全体を検証することです。 サイクルに追加のブランチが接続されているとします。 分岐上の一部のセルは局所的に次数 2 を持っている可能性がありますが、接続点の次数は 3 になるため、コンポーネントは全体として拒否する必要があります。 

このソリューションでは BFS とキューを使用しますが、DFS も同様に機能します。 BFS は、非常に大きなグリッドでの Python 再帰の深さの問題を回避します。 

訪問された配列により、各セルが正確に 1 回処理されることが保証され、複雑さが線形に保たれます。
