 ## 解決策
 ## 問題の理解

 正の整数の配列から始めます。 ちょうど 1 つの要素を別の値に変更する必要があります。`1`そして`10^9`。 その 1 回の置換の後、配列を降順でない順序で並べ替えます。 

タスクは、置換を 1 回だけ実行した後、辞書編集的に可能な限り最小のソート配列を生成することです。 

「各位置の最小可能値」に関する元のステートメントの文言は、辞書編集上の最小ソート配列を説明する別の方法です。 最初の位置をできるだけ小さくし、次に 2 番目というようにしていきます。 

制約`n ≤ 10^5`二次関数はすぐに除外されます。 シンプルなものでも、`O(n^2)`アルゴリズムには次のようなものが必要です`10^10`限界をはるかに超えた最悪の場合の操作。 ここでは仕分けが十分に安いので、`O(n log n)`のために`10^5`要素は Python で簡単に管理できます。 

難しいのは、実際にどのような置換によって最終的に最小のソート済み配列が生成されるかを理解することです。 

配列がすでにソートされていると仮定します。```
1 2 3 4 5
```最大値を置き換えると`5`と`1`、次のようになります。```
1 1 2 3 4
```数値を小さくすると、ソート順序ができるだけ早くなるのに役立つため、これは明らかに最適です。 

ここで、すべての要素がすでに配置されている配列を考えてみましょう。`1`:```
1 1 1
```ある要素を別のものに変更する必要があります。 交換することはできません`1`別の人と`1`。 最良のオプションは、要素を 1 つ最小限に増やすことです。```
1 1 2
```不注意な実装では、依然として何かを置き換えようとする可能性があります。`1`、変更されていない配列が生成されますが、これは不正です。 

もう 1 つの微妙なケースは、配列に複数の最小値だけでなく、より大きな数値も含まれる場合です。```
1 1 5
```正しい答えは次のとおりです。```
1 1 1
```交換します`5`と`1`。 単純な「常に 1 つの値を増やす」戦略では、配列全体をさらに小さくできることを見逃してしまいます。 

本当の違いは、配列が既に完全に構​​成されているかどうかです。`1`s`。 

## アプローチ

 ブルートフォースのアイデアは単純です。 すべての位置について、その要素を重要な可能性のあるすべての候補値で置き換えてみて、結果の配列を並べ替えて、辞書編集的に最小の答えを保持します。 

この問題は、可能な限り最小の最終的な並べ替えられた配列を直接要求するため、これは概念的に機能します。 有効な置換をすべて列挙すると、そのうちの 1 つが最適になるはずです。 

問題は可能性の数です。 たとえ置換値の候補の小さなセットだけを試したとしても、サイズの配列をソートすると`n`すべてのポジションにはすでにコストがかかります`O(n^2 log n)`。 と`n = 10^5`、これはまったく不可能です。 

重要な点は、可能な限り最小の置換値のみが重要であるということです。 

配列に より大きい値が含まれている場合、`1`、そのような値の 1 つを次のように置き換えます。`1`ソートされた配列を厳密に改善します。 すべての選択肢の中で、最大の要素を置き換えるのが最適です。これは、許容される最小の数値を追加しながら最大の数値を削除するためです。 

例えば：```
1 2 3 4 5
```は次のようになります:```
1 1 2 3 4
```交換後`5`と`1`。 

この戦略が失敗するのは、すべての要素が既に等しい場合だけです。`1`。 それでは何も置き換えることはできません`1`値が実際に変更される必要があるためです。 最小の有効な変更は、1 つを置き換えることです。`1`と`2`。 

したがって、最適な戦略は非常に小さくなります。 

1. 配列をソートします。 
2. すべての要素が`1`、最後のものを次のように変更します`2`。 
3. それ以外の場合は、最大の要素を次のように変更します。`1`。 
4. 必要に応じて再度並べ替えます。 

配列はすでにソートされているため、最終的な配置は即座に行われます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n² log n) 以上 | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(1) 追加 (並べ替えを除く) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 配列を読み取り、降順でない順に並べ替えます。 

ソートにより、辞書編集上の順序を直接推論することができます。 最小の要素が最初に表示されるため、初期の位置を改善することが明らかになります。 
2. 最大の要素が以下に等しいかどうかを確認します。`1`。 

配列はソートされているため、この条件はすべての要素がソートされていることを意味します。`1`。 
3. すべての要素が`1`、最後の要素を次のように置き換えます`2`。 

正確に 1 つの値を変更する必要があります。`2`は次とは異なる最小の有効な数値です`1`。 
4. それ以外の場合は、現在最大である最後の要素を次の要素に置き換えます。`1`。 

これにより、最大値が削除され、可能な限り最小の値が挿入され、辞書順に最小の並べ替えられた配列が生成されます。 
5. 必要に応じて配列を再度並べ替えるか、変更した並べ替え順序を単に出力します。 

最大の要素を次のように置き換えた後、`1`、新しい`1`フロントに属します。 別の並べ替えを実行するのは簡単ですが、それでも十分効率的です。 

### なぜ効果があるのか

 辞書編集上の順序は、最も古い異なる位置によって決定されます。 最終的にソートされた配列を最小化するには、最初にできるだけ多くの小さな値が必要です。 

配列にこれより大きい値が含まれている場合、`1`、そのような値の 1 つを次のように置き換えます。`1`最小要素の数を増やし、より多くの要素を削除します。 ソート後のプレフィックスは同一のままですが、後の位置は小さくなるため、最大値を置換することは、常に小さい値を置換することと少なくとも同等の効果があります。 

すべての要素がすでに存在する場合`1`、値を減らすことは不可能です。 最小の法的変更は、要素を 1 つだけ増やすことです。`2`、すべての有効な変更の中で可能な限り最小の並べ替え結果が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

a.sort()

if a[-1] == 1:
    a[-1] = 2
else:
    a[-1] = 1

a.sort()

print(*a)
```この解決策は、配列をソートすることから始まります。 これにより、最大の要素に簡単にアクセスできるようになります。`a[-1]`。 

条件`a[-1] == 1`すべての要素が正しいかどうかを判断するには十分です。`1`配列がソートされているためです。 最大値が`1`の場合、すべての値も次のようにする必要があります。`1`。 

すべての要素が揃っているとき、`1`、最後の要素を次のように置き換えます。`2`。 これより大きな数値を選択すると、辞書編集的に悪い配列が作成されます。 

それ以外の場合は、最大要素を次のように置き換えます。`1`。 これにより、既存の最大値が削除され、最小値が 1 つ追加されます。 

最後の並べ替えでは、降順ではない順序が復元されます。 分別するため、コストはまだ許容範囲内です`10^5`整数を 2 回指定することは簡単に制限内に収まります。 

よくある間違いは、置換によって実際に値が変更される必要があることを忘れることです。 すべて 1 の配列の場合、`1`別の人と`1`は無効です。 

もう 1 つの簡単なバグは、最大の要素ではなく最小の非 1 要素を置き換えることです。 これにより、配列内に大きな数値が残り、辞書編集上の結果が悪化します。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    a.sort()

    if a[-1] == 1:
        a[-1] = 2
    else:
        a[-1] = 1

    a.sort()

    print(*a)

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return out

# provided sample
assert run("5\n1 2 3 4 5\n") == "1 1 2 3 4\n", "sample 1"

# minimum size
assert run("1\n1\n") == "2\n", "single element equal to 1"

# single non-one element

# all equal values
assert run("4\n1 1 1 1\n") == "1 1 1 2\n", "all ones case"

# mixed values
assert run("5\n1 1 5 7 9\n") == "1 1 1 5 7\n", "replace largest value"

# already sorted but with duplicates
assert run("6\n2 2 2 2 2 2\n") == "1 2 2 2 2 2\n", "duplicate non-one values"
