## アプローチ

 直接的な総当り戦略では、ミミックのあらゆる配置を試し、可能な限りすべての方法で値を並べ替え、すべてをシミュレートすることで期待される報酬を計算します。$n$開始位置を決め、最小限の位置を取る。 ミミックの位置を修正しても残らない$O((n-k)!)$順列があり、$\binom{n}{k}$ミミックを選択する方法が異なるため、これは完全に不可能になります。 

重要な観察は、ミミックが固定されると、円が連続した通常のチェストのセグメントに分割されることです。 セグメントで開始したプレーヤーは、最後のミミックに到達するまで、そのセグメントのサフィックスを収集します。 これにより、円形プロセスが独立した直線セグメントに変換されます。 

長さのセグメント内$L$、値が$v_1, v_2, \dots, v_L$、次にその位置で開始$i$集める$v_i + v_{i+1} + \dots + v_L$。 それぞれの値$v_j$したがって、正確にカウントされます$j$そのセグメント内の開始位置。 これにより、各セグメントが加重合計に変換されます$\sum v_j \cdot j$。 

現在、グローバル構造はセグメントの長さだけに依存します。 長さのセグメントがある場合$L_1, L_2, \dots, L_t$、合計寄与率は、重みを含む独立した重み付き線形配列の合計です。$1, 2, \dots, L_i$各セグメントの内部。 残された唯一の自由は、ミミックを配置してセグメント パーティションを選択する方法です。 

重要な構造的事実は、重み関数が$\sum_{j=1}^{L} j$に凸です$L$。 通常のチェストの総数が固定されている場合、長さをより少ないセグメントに集中させると、総重量の合計が厳密に減少します。 これは、通常のチェストを複数のセグメントに分割することを可能な限り避けたいことを意味します。

 ## アルゴリズムのチュートリアル

 ### 1. 胸の値を並べ替える

 すべての値を降順でない順に並べ替えます。 これにより、小さな値を小さな位置重みと一致させる準備が整い、重みが増加する積の合計を最小化するのに最適です。 

### 2. ミミックによって引き起こされる構造を修正する

 与えられた$k$、最良の配置はすべてを配置することであることがわかります。$k$サークル上で連続して模倣します。 これにより、通常の長さのチェストの 1 つの連続したブロックが作成されます。$n-k$。 他の配置ではセグメンテーションが増加し、加重寄与の合計が増加します。 

### 3. 位置の重みを構築する

 通常のブロック内では、位置にラベルが付けられます$1$に$n-k$。 位置の値$j$まさに貢献する$j$その値をすべての開始位置の合計に掛けます。 

### 4. 合計貢献度を計算する

 私たちは計算します$$S_k = \sum_{j=1}^{n-k} a_j \cdot j$$どこ$a_j$はソートされた配列です。 

### 5. 期待に変換する

 各開始位置は次の中で等しい可能性があります。$n$部屋。 したがって、期待値は次のようになります。$$\frac{S_k}{n}$$の逆モジュラーを掛けます。$n$最終的な答えを得るために。 

### なぜ効果があるのか

 ミミックのすべての配置は、円のセグメントへの分割を定義し、各セグメントはその長さにわたって凸状の重み付き合計に寄与します。 凸性は、複数のセグメントに質量を分割すると、値の割り当てに関係なく、総重量の寄与が増加するだけであることを意味します。 したがって、最適な構造は、通常の胸部の単一の最大セグメントです。 この構造が修正されると、重み付き合計を最小化すると、標準的な並べ替え不等式になります。つまり、位置の昇順で、より小さな値をより大きな重みに割り当てます。

c.sort()

inv_n = modinv(n)

# We compute answers for all k by progressively removing largest elements
# k mimics => n-k regular elements used
# best uses smallest (n-k) elements
for k in range(1, n + 1):
    m = n - k
