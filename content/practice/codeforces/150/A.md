 ## 解決策
 ## 問題の理解

 数字から始めましょう`q`紙に書かれた。 各ターンで、プレイヤーは現在の数値を自明ではない約数の 1 つで置き換える必要があります。つまり、厳密に次の数の間の約数を意味します。`1`そして数字そのもの。 

プレイヤーが行動できない場合、そのプレイヤーは即座に勝ちます。 これは、動けないプレイヤーが負けとなる通常の通常プレイのゲームの慣例とは逆です。 

タスクは、最初のプレーヤーと 2 番目のプレーヤーが両方とも最適にプレイしたときに、どちらが勝つかを判断することです。 最初のプレーヤーが勝利戦略を持っている場合は、有効な最初の手を 1 つ出力する必要もあります。 

入力サイズの数は小さく、整数は 1 つだけですが、値自体は大きくなる可能性があります。`10^13`。 これにより、すべての約数を繰り返し列挙しようとしたり、コストのかかる再帰的なゲーム状態の探索を実行しようとしたりするものは排除されます。 おおよそまでの平方根因数分解`3 * 10^6`2 秒以内であれば完全に許容されます。`sqrt(10^13)`についてです`3.16 * 10^6`。 

難しいのはパフォーマンスではなく、珍しい勝利条件のためゲームロジックを正しく理解することです。 

非常によくある間違いは、「何も動かないことは負けを意味する」と思い込むことです。 多くの場合、それは正反対の答えを生み出します。 

次のことを考慮してください。 

入力:```
2
```番号`2`には自明でない約数はありません。 最初のプレイヤーは移動できないため、最初のプレイヤーがすぐに勝ちます。 正しい出力は次のとおりです。```
1
0
```標準の Sprague-Grundy の直感を使用した不注意な実装により、プレーヤーが誤って出力されてしまいます。`2`。 

もう 1 つの微妙なケースは、数値がちょうど 2 つの素数の積である場合です。 

入力：```
6
```唯一の合法的な動きは、`2`そして`3`。 どちらも素数なので、次のプレイヤーは何も動かず、すぐに勝ちます。 つまり、次の場所に移動するということです`2`または`3`現在のプレイヤーの負けとなります。 ～からのあらゆる可能な動き`6`悪いので、`6`それ自体が負けている。 

正しい出力は次のとおりです。```
2
```最終条件を慎重に元に戻さない単純な再帰的解決策は、多くの場合、これを逆方向に導きます。 

また、主力を巡る構造的なエッジケースも存在する。 

入力：```
8
```法的な動きは、`2`そして`4`。 

に引っ越したら`2`、相手は動けずにすぐに勝ってしまうので、その手は負けです。 

に引っ越したら`4`、相手は次の場所に移動する必要があります。`2`、それでは動けない、勝てない。 

それで`8`が勝っています。有効な最初の動きは次のとおりです。`4`。 

このケースは、現在の数字が合成であるかどうかだけでゲームが決まるわけではないことを示しています。 因数分解の構造が重要です。 

## アプローチ

 ブルートフォース ソリューションでは、到達可能なすべての数値をゲームの状態として扱い、勝ちか負けかを再帰的に判断します。 数字の場合`x`、自明でない約数をすべて列挙し、それらを再帰的に分析します。 

再帰自体は、すべての移動が厳密に数値を減少させるため管理可能ですが、高価な部分は除数の列挙です。 最悪の場合、最大でスキャンすることになります。`sqrt(x)`多くの州で繰り返し。 と`x`と同じくらい大きい`10^13`、それはすぐに無駄になってしまいます。 

さらに深刻な問題は、実際には完全なゲーム検索が必要ないということです。 すべての手が数字を適切な約数に置き換えるため、ゲームは非常に厳格な構造になっています。 

状態を注意深く分類しましょう。 

素数には法的な動きはありません。 動けないプレイヤーが勝ちなので、すべての素数が勝ちの状態になります。 

次に、可能性のある手が 1 つだけある数字を見てみましょう。`p^2`。 

例：```
9 -> 3
```動きはプライムに進み、次のプレイヤーが勝ちます。 それで`9`負けています。 

さあ見てください`p^3`。 

例：```
27 -> 9` or `3
```直接移動する`3`相手がすぐに勝つので悪いです。 しかし、に移動します`9`いいから`9`負けています。 それで`27`勝っている。 

この交互の動作は、純粋なプライムパワーに対して継続します。 

少なくとも 2 つの異なる素因数を持つ数値の場合、状況ははるかに単純になります。 ほとんどの場合、すぐに負け状態に移行する可能性があります。 

重要な観察は、唯一負ける状態は、多重度で数えた素因数の合計数が偶数である数値であるということです。 

させて：```
n = p1 * p2 * ... * pk
```ここで、繰り返される素数は繰り返しカウントされます。 定義する：```
Ω(n) = total count of prime factors with multiplicity
```例:```
Ω(12) = Ω(2^2 * 3) = 3
Ω(18) = Ω(2 * 3^2) = 3
Ω(36) = Ω(2^2 * 3^2) = 4
```すべての動きは少なくとも 1 つの素因数を削除するため、各動きは厳密に減少します。`Ω(n)`。 

プライムには`Ω = 1`そして勝っています。 

の数字`Ω = 2`すべての手が素数に達するため、負けています。 

の数字`Ω = 3`の状態に移動できるため、勝利しています。`Ω = 2`。 

帰納法により:

 - 奇数`Ω(n)`勝つことを意味します
 - 偶数`Ω(n)`負けるという意味

 問題全体は、数を因数分解し、素数の多重度を数えるということになります。 

カウントが偶数の場合、プレイヤーは`2`勝ちます。 

カウントが奇数の場合:

 - 法的措置がまったくない場合は、印刷します`0`- それ以外の場合は、偶数の因数を残す除数を出力します。 

最も簡単な方法は、1 つの素因数で割ることです。

 ## アルゴリズムのチュートリアル

 1. 数値を因数分解する`q`トライアル分割を使用して最大`sqrt(q)`。 

あらゆる約数について`d`、分割を繰り返します`q`による`d`可能な限り、削除された素因数の数を数えてください。 
2. 試行分割後の残りの値が より大きい場合`1`、それはより大きい素因数です`sqrt(original q)`なので、因子数をもう一度増やします。 
3. しましょう`cnt`多重度で数えた素因数の総数になります。 

例:```
12 = 2 * 2 * 3 -> cnt = 3
18 = 2 * 3 * 3 -> cnt = 3
36 = 2 * 2 * 3 * 3 -> cnt = 4
```4. もし`cnt`が偶数の場合は、次のように出力します。```
2
```現状は先手負けです。 
5. それ以外の場合は、最初のプレイヤーが勝ちます。 

印刷:```
1
```6. 偶数個の素因数を残す自明でない約数を見つけます。 

1 つの素因数で除算すると、常にカウントが 1 だけ減り、パリティが奇数から偶数に変更されます。 
7. 元の数が素数の場合、正当な手はありません。 印刷:```
0
```8. それ以外の場合は、次のように出力します。```
q / p
```どこ`p`のいずれかの素因数です`q`。 

### なぜ効果があるのか

 不変量は、素因数の総数のパリティです。 

すべての動きが置き換えられます`n`適切な約数を使用して。 これは、少なくとも 1 つの素因数が消えることを意味します。`Ω(n)`厳密に減少します。 

移動するとパリティが変わります`Ω(n)`なぜなら、正の数の素因数を削除すると、その数が奇数である場合にのみパリティが反転されるからです。 素因数で割ることによって常に正確に 1 つの素因数を削除できるため、すべての奇数状態は偶数状態に移行します。 

素数は`Ω = 1`現在のプレイヤーが移動できないため、勝利しています。 

誘導を使用する`Ω(n)`:

 - すべての奇数カウントが勝ちです
 - 偶数カウントはすべて負けています

 したがって、パリティがゲームの結果を完全に決定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    original = n

    cnt = 0
    first_prime = -1

    d = 2
    while d * d <= n:
        while n % d == 0:
            if first_prime == -1:
                first_prime = d
            cnt += 1
            n //= d

        if d == 2:
            d = 3
        else:
            d += 2

    if n > 1:
        if first_prime == -1:
            first_prime = n
        cnt += 1

    if cnt % 2 == 0:
        print(2)
    else:
        print(1)

        if cnt == 1:
            print(0)
        else:
            print(original // first_prime)

solve()
```最初の部分では、試行除算を使用して素因数分解を実行します。 ゲームは多重性に依存するため、一度係数を削除するのではなく、各係数で繰り返し除算します。 例えば、`12 = 2^2 * 3`貢献しなければならない`3`総要素ではなく、`2`。 

変数`first_prime`元の数値の素約数を 1 つ保存します。 その後、ポジションが勝っている場合、この素数で除算すると因数の数がちょうど 1 だけ減り、パリティが反転します。 

ループはチェック後に偶数をスキップします`2`これにより、パフォーマンスがわずかに向上します。 以来`sqrt(10^13)`周りだけです`3 * 10^6`、この実装は時間制限に簡単に適合します。 

条件`cnt == 1`素数を識別します。 素数には法的な非自明な約数がないため、最初のプレイヤーがすぐに勝ったとしても、必要な手の出力は次のようになります。`0`。 

よくある実装のバグは、ループ後の残りの素因数の処理を忘れることです。 例えばファクタリングの場合`10`で割った後、`2`私たちに残っているのは`5`。 以来`5 * 5 > 5`、ループが停止し、最後の素数を手動でカウントする必要があります。

def solve():
    input = sys.stdin.readline

    n = int(input())
    original = n

    cnt = 0
    first_prime = -1

    d = 2
    while d * d <= n:
        while n % d == 0:
            if first_prime == -1:
                first_prime = d
            cnt += 1
            n //= d

        if d == 2:
            d = 3
        else:
            d += 2

    if n > 1:
        if first_prime == -1:
            first_prime = n
        cnt += 1

    out = []

        out.append("2")
    else:
        out.append("1")

        if cnt == 1:
            out.append("0")
        else:

    return "\n".join(out)

    return solve()

 ## 特殊なケース

 素数の場合は、何も動かなかったプレイヤーが勝つため、最も直観に反するケースです。 

入力：```
2
```因数分解:```
2 = 2
```それで：```
cnt = 1
```奇数パリティは、最初のプレイヤーが勝つことを意味します。 自明でない約数がないため、正しい移動出力は次のようになります。```
0
```アルゴリズムは特殊なケースを通じてこれを処理します`cnt == 1`。 

次にセミプライムを考えてみましょう。 

入力：```
15
```因数分解:```
15 = 3 * 5
```それで：```
cnt = 2
```偶数パリティは負けを意味します。 

考えられる動き:```
15 -> 3
15 -> 5
```どちらのターゲットもプライムであり、次のプレイヤーが移動できないため、プライムは勝利状態になります。 アルゴリズムは正しく出力します。```
2
```次に、より高い素数パワーを考えてみましょう。 

入力：```
32
```因数分解:```
32 = 2^5
```それで：```
cnt = 5
```奇数パリティは勝ちを意味します。 

アルゴリズムは以下を選択します。```
32 / 2 = 16
```今：```
16 = 2^4
```これは偶数パリティを持ち、負けています。 

出力：```
1
16
```これにより、正確に 1 つの素因数を削除すると、ゲーム状態のパリティが常に正しく反転されることが確認されます。
