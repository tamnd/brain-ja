 ## 解決策
 ## 問題の理解

 一連の乗算演算を使用して 2 つの正の整数を等しくするように求められます。 メイプルはどちらかの数値を選択し、選択した正の整数を掛けることができます。 目標は、これを最小限の操作で実行することです。 各テスト ケースには 2 つの数値が与えられ、それぞれに対して最小限の操作を出力する必要があります。 

制約を考慮すると、両方の数値は 1 ～ 1000 であり、テスト ケースの数は最大 100 です。数値は乗算後に任意に大きくなる可能性があるため、計算の入力境界によって制限されません。 つまり、Python では整数オーバーフローを心配する必要はありませんが、単純な試行的な乗算は指数関数的になる可能性があるため、最適な戦略を検討する必要があります。 

微妙なエッジ ケースには、小さい数、等しい数、および一方が他方を割る数が含まれます。 たとえば、数値が等しい場合、操作は必要ありません。 一方の数値がもう一方の数値を割る場合、1 回の乗算で十分です。 常に両方の数値の乗算を試行する不注意な実装では、演算が過剰にカウントされたり、単純なケースを認識できなかったりする可能性があります。 たとえば、与えられた`a = 1`そして`b = 2`、乗算`a`by 2 は 1 回の操作で問題を即座に解決します。 

もう 1 つの特殊なケースは、数値間の比率が単純な整数ではない場合です。 例えば、`a = 10`そして`b = 3`公倍数に達するには、両方の数値を戦略的に乗算する必要があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての乗算シーケンスを検討して、`a`等しい`b`。 掛け算してみるのもいいかもしれません`a`1 からある範囲までのすべての整数ごとに再帰的にチェックします。`b`より少ない操作で一致させることができます。 これは原理的には正しいですが、数値が増加すると検索空間が指数関数的に増大し、たとえ小さい数値であっても数百もの可能性が生じる可能性があるため、明らかに非現実的です。 

重要な洞察は、あらゆる乗算が許可されるため、問題は 2 つの数値間の比に帰着するという観察から得られます。 させて`m = max(a, b)`そして`n = min(a, b)`。 作るには`n`に等しい`m`乗算を使用する場合、重要なのは比率だけです`r = m / n`。 私たちは変身したいのです`n`の中へ`m`積が次と等しくなるようにそれに整数を乗算します。`m`。 

任意の整数は 2、3、5 因数の積として表すことができ、その他の素因数は必要に応じて別の乗算が必要になることに注意してください。 以来`a, b ≤ 1000`、比率`r`は 2、3、5 のべき乗に因数分解できます (1 を掛けるのは冗長なので 1 は無視します)。 各乗算では、これらの素数の指数を少なくとも 1 増加させることができます。 この観察は、単純な貪欲な解決策につながります。つまり、比率を 1 になるまで 2、3、5 で割って、分割数を数えます。 これらのカウントの合計が最小操作数です。 2、3、5 を除いた後に因数が残った場合は、さらに 1 回の乗算で処理できます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、整数を読み取ります。`a`そして`b`。 もし`a`等しい`b`、0を出力して続行します。 操作は必要ありません。 
2. 2 つの数値のうち大きい方と小さい方を特定します。`m`そして`n`。 比率を計算する`r = m / n`。 もし`m`で割り切れない`n`、役割を交換するか、一方の数値を乗算してもう一方の数値を倍数にするという 2 つの演算を検討します。 
3. カウンタの初期化`ops`ゼロに。 これにより、必要な乗算の数が追跡されます。 
4. ながら`r`2で割り切れる、割る`r`2ずつ増加します`ops`by 1。これは、比率のすべての 2 のべき乗を処理します。 
5. 3 と 5 の割り算についても同じことを繰り返します。割り算ごとに、増分します。`ops`。 
6. 2、3、および 5 の要素をすべて削除した後、次の場合`r`が 1 ではない場合は、他の要因があることを意味します。 1 回の操作で任意の整数を乗算できるため、インクリメントします。`ops`1までに。 
7. 出力`ops`このテスト ケースの最小操作数として。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`r`常に均等化する残りの比率を表します`a`そして`b`。 それぞれの操作が減少します`r`素因数を取り除くことによって。 任意の整数を乗算できるため、貪欲な方法で各素因数を個別に処理することで、最小限の演算数が保証されます。 残りの因数が存在する場合、1 つの数値を直接乗算して他の数値と一致させることができるため、1 回の操作だけで済みます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def min_operations(a, b):
    if a == b:
        return 0
    m, n = max(a, b), min(a, b)
    r = m // n
    ops = 0
    for p in [2, 3, 5]:
        while r % p == 0:
            r //= p
            ops += 1
    if r != 1:
        ops += 1
    return ops

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(min_operations(a, b))
```機能`min_operations`最初にチェックするかどうか`a`そして`b`等しい場合は、すぐに 0 を返します。 次に、大きい数値と小さい数値の比率を計算します。 因数 2、3、および 5 を繰り返し除算することにより、必要な最小乗算回数がカウントされます。 残った因数は 1 回の追加の乗算で処理されます。 整数除算を使用すると、浮動小数点エラーは発生しません。
