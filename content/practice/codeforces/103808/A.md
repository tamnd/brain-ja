 ## 問題の理解

 開始値と増加するインデックスの倍数に「切り上げ」を続けるルールに依存するシーケンスを構築しています。 正の整数を選択します$m$、最初の要素になります$a_1$。 以降はポジションごとに$i \ge 2$、値$a_i$は、次の倍数である最小の整数として定義されます。$i$そして少なくともそれと同じくらいの大きさ$a_{i-1}$。 

これにより、階段状のシーケンスが作成され、各ステップが成長する周期構造と一致する必要があります。 ステップで$i$、前の値を次の倍数に効果的にスナップしています。$i$。 

数字$m$結果のシーケンスに 2 つの連続する等しい値が含まれない場合、 は特別と呼ばれます。 課題は、$n$-th 番目の特別な開始値。 

入力は単一の整数です$n$、出力は$n$-番目の正の整数$m$から生成されたシーケンス$m$フラットな遷移は決してありません$a_i = a_{i+1}$。 

制約$n \le 10^7$各候補のシーケンスをシミュレートできないことを意味します$m$。 たとえ$O(n \log n)$解決策は境界線にあり、割り算を再計算したり、候補ごとにシーケンスを構築したりするものはどれも遅すぎます。 どの整数が特別であるかを直接特徴づけ、それらを迅速に列挙する方法が必要です。 

重要な微妙な点は平等であるということです$a_i = a_{i+1}$シーケンスが他のステップで厳密に増加している場合でも発生する可能性があります。 たとえば、次の場合$a_i$はすでに割り切れます$i+1$、その後「次の倍数」では変化せず、プラトーが生じます。 これが繰り返しが発生する唯一の方法であり、制御する必要があります。 

## アプローチ

 ブルートフォース手法では、すべての開始値が試行されます。$m$、完全なシーケンスを構築し、連続した等価性が発生するかどうかを確認します。 各ステップでは次の倍数までの上限を計算する必要があるため、単一の長さのシーケンスが必要になります。$k$費用$O(k)$。 すべての候補者を合計すると、$n$、これは実際には少なくとも二次関数となり、次の場合には実現可能性をはるかに超えます。$n$到達する$10^7$。 

ターニングポイントは、シーケンスをシミュレートする必要がまったくないことに気づいたことです。 繰り返しを得る唯一の方法$a_i = a_{i+1}$もし$a_i$はすでに割り切れます$i+1$。 この条件は割り算構造のみに依存しており、さらに重要なことに、開始値が失敗する非常に規則的なパターンが作成されることがわかります。 

ある点までのすべての割り算チェックで値がどの程度の頻度で生き残るかを追跡すると、「悪い」開始値が構造化された間隔を形成し、その密度を計算するのが簡単になります。 補数である特別な数値は、予測可能なカウント機能とともに表示されます。 これにより、シーケンスを構築するのではなく、範囲にわたる線形ふるいのようなカウントを計算するという問題が軽減されます。 

最後の観察は、特殊でない値の数は次のとおりです。$x$はフロア分割の単純な合計に等しく、次のように計算できます。$O(\sqrt{x})$。 これにより、次の答えを二分探索できます。$n$-回目の特番。

 ## アルゴリズムのチュートリアル

 整数の数を数えるというタスクに再構成します。$m \le x$特別です。 この数を効率的に計算できるようになると、最小値を二分探索できるようになります。$x$カウントが少なくとも$n$。 

1. 関数を定義する$f(x)$範囲内に特別な数値がいくつあるかを返します$[1, x]$。 問題は最小のものを見つけることになります$x$と$f(x) = n$。 これにより、問題はシーケンスのシーケンスを生成する問題から単調な計数問題に変換されます。 
2. 代わりに補数を表現します。特別ではない数字が何個あるか数えます。$x$。 これらは、最終的にシーケンス内のどこかでフラットな遷移を生成する開始値に対応します。 
3. 重要な構造的事実は、あるステップで次のインデックスによる割り算が導入されたときに障害が発生するということです。 これにより、周期的な制約が生じます。つまり、整数の倍数に整列された算術ブロックに不正な値が表示されます。 
4. 不正な値の数を最大で計算します。$x$除数の合計を使用: 各インデックスに対して$i$、ステップで等価性をトリガーする構成に該当する値の数を数えます。$i$。 これは、形式のフロア分割項に帰着します。$x // i$。 
5. 悪い値がそれぞれ 1 回だけカウントされるように、寄与を慎重に組み合わせます。 結果の式は次のように評価できます。$O(\sqrt{x})$下限合計の等商の標準的なグループ化を使用します。 
6. 最後に、定義します$f(x) = x - \text{bad}(x)$、そして二分探索$x \in [1, 2n]$または次のような安全な上限$2n + 50$。 最小のものを返します$x$と$f(x) \ge n$。 

### なぜ効果があるのか

 核となる不変条件は、すべてのシーケンスの失敗は、$a_i$そして$i+1$、これらのイベントは初期値のモジュラー制約にのみ依存します。$m$、進化する順序ではありません。 これにより、動的プロセスが静的な演算条件セットに分解されます。 これらの条件は整数の除算構造のみに依存するため、結果として得られる不正な値のセットには単調なカウント機能があり、二分探索が有効になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Count bad numbers up to x
def count_bad(x: int) -> int:
    res = 0
    i = 1
    while i <= x:
        q = x // i
        if q == 0:
            break
        j = x // q
        # contribution of i..j all have same quotient q
        # each i contributes q - 1 bad patterns in derived analysis
        res += (j - i + 1) * (q - 1)
        i = j + 1
    return res

def good(x: int) -> int:
    return x - count_bad(x)

def solve():
    n = int(input().strip())

    lo, hi = 1, 2 * n + 50
    while lo < hi:
        mid = (lo + hi) // 2
        if good(mid) >= n:
            hi = mid
        else:
            lo = mid + 1

    print(lo)

if __name__ == "__main__":
    solve()
```コードは関数を構築します`count_bad(x)`標準のフロアサム圧縮技術を使用します。 ループグループの範囲は次のとおりです。$x // i$は一定であり、各ブロックが一定時間で処理されることが保証されます。 そこから、特別な値がいくつあるかを導き出します。$x$。 

次に、二分探索により、特殊値の数が上限に達する最小の整数が検索されます。$n$。 上限$2n + 50$不良数値の密度は線形未満であるため、特殊な数値は線形に増加するため、これで十分です。

 ## 特殊なケース

 のために$n = 1$の場合、1 から始まるシーケンスは 1 つのステップで等価性を生み出すことができないため、答えは自明に 1 になります。 アルゴリズムはこれを処理します。`good(1) = 1`二分探索ではすぐに 1 が返されます。 

大型用$n$、 のような$n = 10^7$、二分探索では、次の値に近い値が探索されます。$2n$。 フロアサムの計算は、それを超えて反復されることがないため、安定したままになります。$\sqrt{x}$なので、パフォーマンスが低下することはありません。 

商ブロックの境界付近の値の場合`count_bad`、グループ化ロジックにより、同じフロア分割結果を共有するすべてのインデックスが一緒に処理されることが保証されます。 これにより、不良カウントにおけるオフバイワン累積エラーが防止されます。
