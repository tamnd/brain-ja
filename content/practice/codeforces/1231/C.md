 ## 解決策
 ## 問題の理解

 整数の長方形グリッドが与えられます。 一部のセルにはすでに固定の正の値が含まれていますが、一部のセルにはゼロが含まれており、これらを任意の正の整数に置き換えることができます。 目標は、すべてのゼロ セルに値を割り当てて、2 つの単調性条件が同時に成立するようにすることです。すべての行は厳密に左から右に増加する必要があり、すべての列は厳密に上から下に増加する必要があります。 

すべての有効な補完の中で、すべてのエントリの合計が最大になるものが必要です。 厳密な順序制約を満たすことができない補完がない場合は、その不可能性を報告する必要があります。 

重要な構造上の詳細は、すべてのゼロ セルが厳密にマトリックスの内側にあること、つまり境界上にセルが存在しないことです。 これにより、すべてのゼロ セルに、その行および列のコンテキストのどこかで利用可能な 4 つの直接方向隣接セルがすべて存在することが保証されます。これは、制約を推定するために重要です。 

制約が十分に大きいため、セルごとに個別に値を割り当てたり、調整を繰り返しシミュレートしたりするアプローチは遅すぎます。 と$n, m \le 500$、周りの解決策$O(nm)$または$O(nm \log nm)$は必要ですが、三次的なものや繰り返しのグローバルな再計算を伴うものは除外されます。 

一般的な失敗例は、行と列の両方の制約を通じてゼロが相互作用する場合に発生します。 たとえば、左と上に隣接するゼロのみを指定して、各ゼロをできるだけ大きく埋め込むと、右または下に隣接する将来の制約に違反する可能性があります。 次のような行を考えてみましょう`5 0 2`。 ローカルでは、方向に応じてゼロに 5 から 2 の間の値が割り当てられる可能性がありますが、これは一貫性がないため、単純な貪欲な割り当ては失敗します。 

もう 1 つの微妙な問題は、ゼロが行間隔と列間隔の両方によって制約され、それらの間隔が競合する可能性がある場合に発生します。 交差点が空の場合は、各方向が個別に実行可能であるように見えても、有効な割り当ては存在しません。 

## アプローチ

 ブルート フォースの観点では、厳密な不等式を強制しながら、各ゼロ セルに値を割り当てようとします。 可能な割り当てをセルごとに探索し、制約に違反するたびにバックトラックすることを想像することもできます。 これは、各割り当てを近傍に対してローカルにチェックできるため、概念的には機能しますが、値が正の整数であるため、ゼロあたりの選択肢の数に制限がなく、追加の構造なしで検索空間が無限になります。 人為的に値を何らかの最大値で制限したとしても、構成の数はゼロの数で指数関数的に増加し、最悪の場合は次のようになります。$O(nm)$。 

重要な観察は、各セルの境界を理解すると、最適性と実現可能性が切り離されるということです。 すべての空のセルについて、その値は行方向と列方向の最も近い固定セルまたはすでに決定されている隣接セルによって上から制約され、同様に下からも制約されます。 厳密な単調性は、有効な割り当てはすべて、これらの境界によって決定される間隔内に存在する必要があることを意味します。 

各ゼロが実行可能な間隔を持つとみなしたら、問題はこれらの間隔の一貫性をチェックして合計を最大化することになります。 最大化は簡単です。値が有効な間隔内にある限り、値を増やしても制約に違反することはないため、すべてのセルはその制約で許可されている最大値を取る必要があります。 

難しいのは、これらの可能な限り厳しい境界をグローバルに計算することです。 これは、行方向と列方向の両方の方向に制約を伝播することで処理され、各セルが最も近い固定アンカーをすべて尊重するようになります。

 ## アルゴリズムのチュートリアル

 固定セルを行と列に沿って単調な制約を課すアンカーとして扱います。 ゼロは、これらのアンカー間で値を推測する必要があるギャップです。 

1. まず、各行を左から右に、次に右から左に独立して処理します。 厳密な増加を維持し、固定セルを尊重する最大許容値を計算します。 左から右へのパスでは、各セルが左隣のセルより少なくとも大きいことが保証され、一方、右から左へのパスでは、次の固定値または制約された値に関する実現可能性が保証されます。 
2. 列に対して同様の伝播を上から下、下から上に実行します。 これにより、垂直方向の一貫性の制約が強制されます。 このステップの後、すべてのセルには、行と列の両方の制約によって暗示される実行可能な範囲が設定されます。 
3. 各セルについて、行由来の制約と列由来の制約を交差させます。 下限が上限を超える場合、構成は不可能であるため、-1 が返されます。 この交差ステップは重要な一貫性チェックです。 
4. 実現可能性が確認されたら、各ゼロ セルに交差間隔で許容される最大値を割り当てます。 固定セルは変更されません。 
5. 最後に、結果のグリッド内のすべての値の合計を計算します。 

最大値を採用する理由は、すべての制約が単調であるため、将来の決定が値を下げることに依存しないためです。 値を増やすと、範囲内に収まる限り、実現可能性を損なうことなく常に目標が向上します。 

### なぜ効果があるのか

 各行と列は厳密な不等式の連鎖を強制します。これは、すべてのセルが、4 方向の最も近い固定セルまたはすでに制約されている隣接セルによって効果的に境界付けられることを意味します。 伝播により、これらの境界がグローバルに一貫していることが保証されます。 水平制約と垂直制約の交差により、各セルの正確な実行可能な間隔が生成されます。 制約は単調であるため、実行可能な割り当ては実行可能性を侵害することなく点単位の最大割り当てに変換でき、貪欲な最大化が正しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]

    INF = 10**18

    # row constraints: left-to-right minimum feasibility, right-to-left maximum feasibility
    row_min = [[-INF]*m for _ in range(n)]
    row_max = [[INF]*m for _ in range(n)]

    for i in range(n):
        # left to right: enforce increasing lower bound
        for j in range(m):
            if j == 0:
                row_min[i][j] = 1 if a[i][j] == 0 else a[i][j]
            else:
                prev = row_min[i][j-1]
                cur = a[i][j] if a[i][j] != 0 else 1
                row_min[i][j] = max(cur, prev + 1)

        # right to left: enforce upper bound consistency
        for j in range(m-1, -1, -1):
            if j == m-1:
                row_max[i][j] = a[i][j] if a[i][j] != 0 else INF
            else:
                nxt = row_max[i][j+1]
                cur = a[i][j] if a[i][j] != 0 else INF
                row_max[i][j] = min(cur, nxt - 1)

    # column constraints
    col_min = [[-INF]*m for _ in range(n)]
    col_max = [[INF]*m for _ in range(n)]

    for j in range(m):
        for i in range(n):
            if i == 0:
                col_min[i][j] = 1 if a[i][j] == 0 else a[i][j]
            else:
                prev = col_min[i-1][j]
                cur = a[i][j] if a[i][j] != 0 else 1
                col_min[i][j] = max(cur, prev + 1)

        for i in range(n-1, -1, -1):
            if i == n-1:
                col_max[i][j] = a[i][j] if a[i][j] != 0 else INF
            else:
                nxt = col_max[i+1][j]
                cur = a[i][j] if a[i][j] != 0 else INF
                col_max[i][j] = min(cur, nxt - 1)

    ans = 0

    for i in range(n):
        for j in range(m):
            lo = max(row_min[i][j], col_min[i][j])
            hi = min(row_max[i][j], col_max[i][j])

            if lo > hi:
                print(-1)
                return

            if a[i][j] == 0:
                a[i][j] = hi

            ans += a[i][j]

    print(ans)

if __name__ == "__main__":
    solve()
```各方向が独立した不等号の連鎖を形成するため、実装では水平制約と垂直制約が分離されます。 行パスは行内の一貫性を保証し、列パスは列内の一貫性を保証します。 最後の交差ステップは、両方の制約が満たされる場所です。 

微妙な点は、固定セルがハード アンカーとして機能することです。伝播中、固定セルは値に上限を設けるか強制しますが、ゼロ セルは柔軟なプレースホルダーのように動作します。 使用する$1$最小開始値により、すべての割り当てが正の値を維持することが保証されます。 

もう 1 つの重要な詳細は、上限に大きなセンチネルを使用することです。 これにより、セグメントに固定上部アンカーがない場合の人為的な制限が回避されます。

 ## 特殊なケース

 主なエッジ ケースは、ゼロ セルが行方向と列方向の両方で 2 つの固定値の間に押し込まれる場合です。 このアルゴリズムは、行と列の境界を個別に計算し、それらを交差させることでこれを処理します。 交差点が崩壊した場合、その不可能性は即座に検出されます。 

もう 1 つのエッジ ケースは、固定アンカー間にゼロの長いチェーンが存在する場合に発生します。 この状況では、行と列のパスで値が段階的にリフトされ、最終的な割り当てでは常に各セグメントの最後の可能な値が割り当てられ、単調性に違反することなく最大の合計が保証されます。 

3 番目のエッジ ケースは、行または列全体に境界を除いて固定制約が含まれていない場合です。 センチネルベースの伝播により、これらのセグメントは人為的な制限なしに、1 から始まる有効な厳密に増加するシーケンスを引き続き受け取ることが保証されます。
