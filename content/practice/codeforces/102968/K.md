 ## 解決策
 ## 問題の理解

 非常に大きなサイズの正方形のグリッドが与えられました。$N \times N$、 どこ$N$は常に 2 のべき乗です。 二次対角線より上のセルのみが関連します。つまり、すべてのセルが関係します。$(X, Y)$そのような$X + Y \le N$。 これにより、三角形の領域が形成されます。 

正方形のタイルを使用してこの領域を完全にカバーする必要があります。各タイルの辺の長さは 2 の累乗になります。 タイルはグリッドに合わせて配置する必要があり、重なったり、許可された領域の外に広がったりすることはできません。 すべての有効なセルをカバーする必要があり、すべての有効なカバーの中で使用するタイルの数を最小限に抑えたいと考えています。 

このような最適なタイリング (必ずしも一意である必要はない) を構築した後、複数のクエリが尋ねられます。 各クエリはセルを与えます$(X, Y)$そして、そのセルを覆うタイルの辺の長さを何らかの最適な構造で出力する必要があります。 複数の最適な構造が存在し、それらがそのセルに異なるタイル サイズを割り当てる場合は、次のように出力する必要があります。$-1$。 

この制約により、明示的な構築を回避する解決策が求められます。$N$と同じ大きさにすることができます$2 \cdot 10^{18}$, それでさえ$O(N)$または$O(N \log N)$クエリごとには不可能です。 代わりに、三角形領域の構造分解に依存する必要があります。 

重要な微妙なエッジ ケースは、クエリされたセルが 2 つの同等に最適な分解間の境界上に正確に存在する場合です。 たとえば、次のような小さな例では、$N = 4$、異なる再帰的分割により、対称位置に異なるタイル割り当てが生成される可能性があり、答えは 1 つのタイルに固執するのではなく、曖昧さを反映する必要があります。 

## アプローチ

 これを直接解決しようとすると、可能な限り大きな正方形のタイルを三角形の領域に配置することを考えざるを得なくなります。 当然の強引なアイデアは、構築をシミュレーションすることです。各ステップで、残りの覆われていない領域内に完全に収まる最大の 2 のべき乗の正方形を選択し、それを配置し、その領域を削除し、すべてが満たされるまで繰り返します。 この貪欲なパッキングは、四分木分解を思い出させます。 

しかし、これはすぐに実行不可能になります。 操作の数は必要なタイルの数によって異なり、最悪の場合、領域は多数の小さなカバーされていないフラグメントに縮退します。 それぞれの配置が効率的であっても、次の場合、すべてのセル、さらにはすべてのタイルを反復処理することは不可能です。$N$までです$10^{18}$。 

重要な観察は、グリッド サイズとタイル サイズの両方が 2 の累乗であるため、この領域には非常に厳格な自己相似構造があるということです。 最適なタイリングはこの構造を尊重する必要があります。意味のある分割のみが中間点で発生し、三角形はより小さな類似の三角形と長方形に再帰的に分解されます。 これは、分割統治のカバーリングやクワッドツリーのような構造に現れるのと同じメカニズムです。 

タイリングを構築する代わりに、問題を三角形領域の再帰的分割として再解釈します。 それぞれのスケールで$2^k$、領域は大きな正方形のタイルに完全に属しているか、一定数のサイズのサブ領域に分割されています。$2^{k-1}$。 これにより、高さが$O(\log N)$。 

曖昧性条件は、セルが複数の対称再帰的方法で解決できる境界上にあるときに発生します。 このような場合、複数の最適な分解が存在するため、答えは一意に決まりません。

 ## アルゴリズムのチュートリアル

 三角形の領域を再帰的に定義されたオブジェクトとして解釈します。 

あらゆる規模で$N = 2^k$、正方形をサイズの 4 つの象限に分割します。$2^{k-1}$。 二次対角線は予測可能な方法でこれらの象限を横切るため、許可された領域は次の組み合わせに分解されます。 

1 つの象限には小さな完全な三角形があり、他の象限には長方形または三角形の断片が含まれます。 

正方形のタイルの数を最小限に抑える構築では、常に、これらの象限の境界に合わせて可能な限り最大の正方形を使用することが優先されます。 これにより、境界線を除いて決定論的な分解パターンが得られます。 

### ステップ

 1. もし$N = 1$の場合、領域には 1 つのセルが含まれており、タイル サイズは 1 のみです。1 を返します。 
2. 2 つのスケールの最大のべき乗を見つけます$S = 2^k = N$そして、クエリ ポイントが大規模に解決できる領域にあるかどうかを検討します。$S/2$。 の位置を分類します。$(X, Y)$中間点を基準にして。 
3. 両方の場合$X$そして$Y$左上の象限にあります（つまり、$X \le S/2$そして$Y \le S/2$そして$X + Y \le S/2$) の場合、問題は同じクエリをより小さなサイズの三角形に縮小することができます。$S/2$。 再帰的に続けていきます。 
4. 点が他の象限の 1 つにある場合、それは、このスケールの単一の大きなタイルで完全に覆われた反射された三角形または長方形の領域に対応します。 その場合、現在のタイル サイズは$S/2$が答えです。 
5. 点が分解境界上に正確に存在する場合、つまり 2 つの等価な再帰的分岐に属することができる対称条件を満たすことを意味します。$-1$そのセルに異なるタイル サイズを割り当てる最適なタイリングが複数存在するためです。 
6. 特定のスケールでセルを解決するか、基本ケースに到達するまで繰り返します。 

### なぜ効果があるのか

 各レベルで、許可された領域の分解は 2 のべき乗ジオメトリによって強制されます。 より大きな正方形を配置したり、位置をずらして配置すると、境界に違反したり、タイル数が増加したりするため、最適なタイリングはこれらの中点に位置合わせする必要があります。 これにより、2 つの部分問題のコストが区別できない対称境界を除いて、独特の再帰的構造が誘発されます。 再帰では一意の分岐選択が強制されないため、これらの境界セルはあいまいなクエリに正確に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_one(n, x, y):
    if n == 1:
        return 1

    ans = None
    cur = n

    while cur > 1:
        half = cur // 2

        in_top_left = (x <= half and y <= half and x + y <= half)

        if in_top_left:
            cur = half
            continue

        # outside main triangle quadrant structure
        # determine if on boundary causing ambiguity
        # boundary occurs when symmetric wrt diagonal split
        if x <= half and y > half:
            return cur // 2
        if x > half and y <= half:
            return cur // 2

        # bottom-right region relative to current block
        # this region is fully covered at this level
        # but may be ambiguous if exactly on split line
        if x + y == cur + 1:
            return -1

        return cur // 2

    return 1

def main():
    q = int(input())
    out = []
    for _ in range(q):
        n, x, y = map(int, input().split())
        out.append(str(solve_one(n, x, y)))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```この実装では、現在の領域サイズが繰り返し半分になります。 変数`cur`クエリ点を含むアクティブな部分問題の現在の辺の長さを表します。 点が左上の再帰三角形の完全に内側にある場合は、下降を続けます。 

別の象限に交差する場合、このスケールでそれを覆うタイルのサイズが適切である必要があることがすぐに特定されます。`cur // 2`。 これは、再帰が拡張を停止する最初のレベルに対応します。 

条件`x + y == cur + 1`曖昧さ検出器として使用されます。 これは、二次対角線が再帰的分割と一致する正確な境界をキャプチャします。これは、2 つの対称タイリングが可能であることを意味します。 

このソリューションでは、明示的なグリッド構築を回避し、対数降下のみを使用します。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、クエリされたセルが再帰的な分割境界上に正確に存在する場合です。 たとえば、次のようなとき$X + Y = N + 1$、セルは現在の部分問題の二次対角線上に正確に位置します。 この状況では、そのレベルで 2 つの同等の方法で領域を分割できるため、2 つの対称分解が有効になり、異なるタイル割り当てが行われます。 

このような場合、アルゴリズムは曖昧性条件をトリガーし、次の値を返します。$-1$タイル サイズにこだわる代わりに。 これは、セルの被覆を一意に決定する単一の最適なタイリングがないという事実を反映しています。 

もう 1 つの微妙なケースは、クエリが左上の再帰三角形の奥深くにある場合に発生します。 アルゴリズムは繰り返し削減します$N$象限終了条件をトリガすることはありません。 これは、再帰ごとに問題のサイズが厳密に半分に減り、終了条件も厳密に減少するため、安全です。$N = 1$曖昧さのない最終的な解決を保証します。
