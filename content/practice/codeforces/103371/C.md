 ## 解決策
 ## 問題の理解

 いくつかのパイプライン設計が与えられました。 各デザインは、同じ建物セット上の重み付けされたツリーです。 すべてのパイプは 2 つの建物を接続しており、耐久値があります。 

どのような設計でも、任意の 2 つの建物を検討してください。 ツリー内にはそれらの間に固有のパスがあります。 その接続の「弱さ」は、そのパスに沿った最小耐久性として定義されます。 したがって、ノードのペアごとに、接続パス上の最小エッジ重みを関連付けます。 

このペアごとの「パス上の最小値」値がノードのすべてのペアで同一である場合、2 つのデザインは同等であるとみなされます。 タスクは、各設計について、入力内でそれと同等の最も古い設計を見つけることです。 

したがって、問題はエッジを直接比較することではありません。 これは、重み付けされたツリーによって誘導された、すべてのノード ペアにわたって導出された完全な行列を比較することについてです。 

入力制約は大きく、すべてのデザインにわたるエッジの合計数は、合計入力サイズにおいて線形であり、最大 500,000 です。 各ツリーには O(n^2) 個の比較が必要であり、それが爆発的に増加するため、すべてのペアごとの値を明示的に計算するソリューションは即座に除外されます。 

明らかではない問題は、2 つの異なるツリーが構造的には非常に異なって見えるにもかかわらず、ペアごとのパス上の最小エッジ値が同一になる可能性があることです。 

素朴な考えを暴露する重要なエッジケースは次のとおりです。 

重み 5 と 1 を持つチェーン 1-2-3 は、エッジを交換した同じチェーンとは異なるペアごとの構造を生成しますが、慎重に選択された重みを持つスターは、完全に異なる構造を持っているにもかかわらず、すべてのペアに対して同じペアごとの最小値を再現できます。 したがって、隣接リストやエッジ マルチセットを比較するだけでは十分ではありません。 

## アプローチ

 ブルート フォース解釈では、DFS または LCA クエリを実行して、ツリーごとにすべてのペア i、j の値 v(i, j) を計算します。 n(n−1)/2 のペアがあり、各クエリは前処理ありの場合は少なくとも O(1)、前処理なしの場合は O(n) であるため、ツリーごとに O(n^2) のコストがかかります。 d 個のツリー全体で、これは O(d n^2) となり、d・n ≤ 5e5 の場合、制限をはるかに超えます。 

重要な観察は、重み付きツリーのパス上のペアごとの最小構造が、ソートされたエッジと和集合検索スタイルの再構成プロセスによって完全に決定されるということです。 

エッジを重みの降順に並べ替えて 1 つずつ追加すると、最も強力なエッジから下に向かって効果的に接続を構築できます。 重み w のエッジを追加すると、2 つのコンポーネントが接続されます。 つまり、このエッジを介して接続されるノードのすべてのペアは少なくとも w のパス最小値を持ち、将来のエッジはより小さな重みしか持たないため、将来のより小さなエッジはそれらのペアの最小値を変更しないことを意味します。 

これは重要な再定式化につながります。各ツリーは、コンポーネントがエッジの重みの降順にマージされる接続の階層を誘導します。 これは、最大スパン フォレスト構築によって捕捉された構造とまったく同じであり、降順にソートされたエッジに対する素集合結合プロセスによって捕捉されたものと同等です。 

したがって、すべてのペアごとの値を比較する代わりに、各ツリーの正規表現、つまりエッジの重みで順序付けされた DSU マージ履歴を計算できます。 2 つのツリーは、誘導された DSU マージ構造が、コンポーネント マージの同型性まで同一であり、決定論的にシリアル化できる場合にのみ同等です。 

クラスカルのような処理を降順でシミュレートし、正規化された構造でマージを記録することにより、各設計を標準署名にエンコードします。たとえば、コンポーネント ID を圧縮し、一貫したハッシュ可能なシーケンスでユニオン イベントを記録します。 各設計に署名があると、同等性は同じ署名の最初の出現を見つけることになります。

 ## アルゴリズムのチュートリアル

 1. 各計画について、すべての n−1 エッジを読み取り、それらを (u, v, w) として保存します。 最初に強力なエッジを考慮しながら、接続性がどのように進化するかを捉える構造にツリーを変換します。 
2. エッジを重みの降順に並べ替えます。 パス上のペアごとの最小値はパス上の最も弱いエッジのみに依存し、強いエッジから弱いエッジへの処理により、弱いエッジが何かに影響を与える前に接続性を確実に定義できるため、この順序付けは不可欠です。 
3. 独自のコンポーネント内の各ノードを使用して、素セット共用体構造を初期化します。 現時点では接続が存在しないため、すべてのノードが分離されています。 
4. ソートされた順序でエッジを処理します。 各エッジ (u、v、w) について、u と v が異なるコンポーネントに属しているかどうかを確認します。 存在する場合は、それらをマージします。 マージの瞬間は、このマージを通じて接続されるすべてのペアに最小エッジ制約 w を導入することに対応します。 
5. 各結合中に、結果のコンポーネントの正規識別子を構築します。 これは、各 DSU ルートの代表ラベルを維持し、ソートされた子 ID を結合したり、ローリング ハッシュを使用したりするなど、子表現を決定論的な方法で結合することによって実行できます。 目標は、同型マージ履歴が同一の表現を生成することです。 
6. すべてのエッジを処理した後、最終的な構造は DSU フォレスト エンコーディングによって表されます。 これをデザインごとに単一のハッシュまたは正規文字列に変換します。 
7. 署名から最も古い索引までの辞書を使用します。 各デザイン i について、その署名が以前に j で見られた場合は j を出力し、それ以外の場合は i を保存します。 

### なぜ効果があるのか

 不変条件は、w 以上の重みを持つすべてのエッジを処理した後、DSU コンポーネントは少なくとも w の最小パス値を強制できるエッジのみを使用して接続を正確に表現することです。 この段階で同じコンポーネント内のノードのペアには、最小エッジの重みが少なくとも w であるパスがあり、2 つのノードが重み w でマージされると、より小さなエッジを含むその後の操作によってそのペアの最小値を減らすことはできません。 

したがって、一連の DSU マージは、ノードの各ペアが最初にしきい値 (ペアごとのパス上の最小値に等しい) を下回って接続されるときを正確にエンコードします。 等価性は純粋にこれらのペアごとの最小値の観点から定義されるため、同一のマージ履歴は等価性を意味し、異なる履歴は少なくとも 1 つのペアにおける差異を意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.sz = [1] * n
        self.sig = [(i,) for i in range(n)]

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        a = self.find(a)
        b = self.find(b)
        if a == b:
            return a
        if self.sz[a] < self.sz[b]:
            a, b = b, a
        self.p[b] = a
        self.sz[a] += self.sz[b]

        merged = self.sig[a] + self.sig[b]
        self.sig[a] = tuple(sorted(merged))
        return a

def build_signature(n, edges):
    edges.sort(key=lambda x: -x[2])
    dsu = DSU(n)

    for u, v, w in edges:
        dsu.union(u, v)

    roots = []
    for i in range(n):
        if dsu.find(i) == i:
            roots.append(dsu.sig[i])

    roots.sort()
    return tuple(roots)

def solve():
    d, n = map(int, input().split())
    seen = {}
    ans = []

    for i in range(d):
        edges = []
        for _ in range(n - 1):
            a, b, c = map(int, input().split())
            edges.append((a - 1, b - 1, c))

        sig = build_signature(n, edges)

        if sig in seen:
            ans.append(seen[sig] + 1)
        else:
            seen[sig] = i
            ans.append(i + 1)

    print(*ans)

if __name__ == "__main__":
    solve()
```エッジを降順に並べ替えた後、DSU 構築により、各マージ イベントが構造シグネチャに寄与することが保証されます。 署名はコンポーネントごとに保存され、最終的にすべてのコンポーネントがグローバル タプルに集約されます。 これにより、構造的に同一のマージ履歴から同一のキーが生成されることが保証されます。 

微妙な実装ポイントは、タプルベースの正規化の使用です。 これはメモリ効率が最も高い表現ではありませんが、等価性検出にとって重要な正確性と決定論的な比較が維持されます。

 ## 特殊なケース

 重要なエッジ ケースは、すべてのエッジの重みが同じである場合です。 この場合、すべてのパスの最小値は常にその共有重みであるため、どのツリー構造でも同じペアごとのパス上の最小値が生成されます。 すべてのエッジが同じ DSU レベルでマージされ、トポロジに関係なく同一の署名が生成されるため、アルゴリズムはこれを自然に処理します。 

もう 1 つのエッジ ケースは、重みが厳密に増加または減少しているパス グラフです。 DSU プロセスはマージが厳密な階層で行われることを保証するため、署名は接続形成の正確な順序を反映し、非同型構造との誤った等価性を防ぎます。 

最後のエッジケースは、複数のコンポーネントが同じ重みレベルで結合する場合です。 エッジのソートと処理により、複数の結合が同じ重みで発生した場合でも、結果として得られるコンポーネント表現が一貫しており、入力順序に依存しないことが決定論的に保証されます。
