 ## 問題の理解

 2 つのバイナリ行列があります。 シフト`(x, y)`その細胞を意味します`(i, j)`最初の行列のセルと比較されます`(i + x, j + y)`2番目の行列の。 

固定シフトの場合、オーバーラップ係数はオーバーラップするセルの積の合計です。 すべての値はどちらかであるため、`0`または`1`、製品が貢献する`1`重なっている両方のセルに次の内容が含まれている場合に正確に`1`。 

問題を捉えるもう 1 つの方法は、以下を含む位置のみを見ることです。`1`。 特定のシフトの場合、オーバーラップ係数は単に次のペアの数です。`1`各テーブルから 1 つずつ、シフトを適用した後に整列されるセル。 

この数を最大化するシフトを見つけなければなりません。 

両方の行列の次元は最大でも`50 × 50`。 つまり、各行列には最大でも次のものが含まれます。`2500`細胞。 考えられるすべてのシフトとすべてのセルのペアを検査するソリューションでは、数千万回の操作が実行されることになります。 これはそれほど大きなことではありませんが、意図した解決策に直接つながる、より明確な観察結果があります。 

行列には次のものしか含まれていないという事実`0`そして`1`重要な構造特性です。 を含むポジションのみ`1`案件。 各行列には少なくとも 1 つが含まれることが保証されているため、`1`、それらの位置に完全に集中できます。 

よくある間違いは、重複する領域についてのみ考えることです。 最適なシフトにより、一方の行列の大部分が他方の行列の外側に配置される可能性があります。 例えば：```
A:
1

B:
1
```シフトごとにオーバーラップ係数が生成されます。`1`または`0`。 シフト値自体は行列の次元によって制約されません。 

もう 1 つの簡単な間違いは、シフトを間違った方向に計算することです。 もし`1`最初の行列の位置は`(r1, c1)`そして`1`2 番目の行列の位置は`(r2, c2)`、それらを揃えるシフトは次のとおりです。```
x = r2 - r1
y = c2 - c1
```減算を逆にすると、逆のシフトが生じ、間違った位置合わせがカウントされます。 

最後の微妙なケースは、複数のシフトが同じ最大オーバーラップを達成する場合に発生します。 このステートメントではあらゆる最適な答えが許可されるため、最大数の 1 つのシフトを覚えておくだけで済みます。 

## アプローチ

 最も直接的な解決策は、可能な限りあらゆるシフトを試すことです。 行列は最大でも`50 × 50`、行シフトの範囲はおおよそ次のとおりです。`-49`に`49`, and the column shift does the same. シフトごとに、すべてのセルをスキャンし、重複する 1 のペアをカウントできます。 

このアプローチは、文字通りすべての候補シフトの重複係数を評価するため、正しいです。 The problem is efficiency. くらいあります`100 × 100 = 10,000`可能性のあるシフト、および各シフトには最大でスキャンが必要になる場合があります。`2500`細胞。 最悪の場合のコストは、細胞検査に約 2,500 万回かかります。 

重要な観察は、以下を含む細胞のみが存在することです。`1`オーバーラップ係数に寄与します。 

仮に`1`最初の行列の位置は次のとおりです。`(ra, ca)`そして`1`2 番目の行列の位置は`(rb, cb)`。 これら 2 つのセルは、正確に 1 つのシフトで整列されます。```
(rb - ra, cb - ca)
```多くの 1 のペアが同じシフトを生成する場合、それらすべてのペアはそのシフトの下で同時に整列されます。 

これにより、問題は計数の問題に変換されます。 から構成されるすべてのペアに対して、`1`最初の行列と`1`2 番目の行列から、それらを揃えるシフトを計算し、各シフトが何回出現するかを数えます。 

最大の周波数を持つシフトは、まさに、重複する 1 のペアの最大数を作成するシフトです。 

各行列には最大でも`2500`多くても 1 つです`2500 × 2500 = 6.25`百万ペア。 これは Python の制限内に問題なく収まります。

 ## アルゴリズムのチュートリアル

 1. 両方の行列を読み取ります。 
2. を含むすべてのセルの座標を抽出します。`1`最初のマトリックスで。 
3. を含むすべてのセルの座標を抽出します。`1`2番目のマトリックスで。 
4.シフトからハッシュマップを作成する`(x, y)`その周波数に。 
5. あらゆる人にとって`1`細胞`(ra, ca)`最初の行列とすべての行列で`1`細胞`(rb, cb)`2 番目の行列で次を計算します。```
x = rb - ra
y = cb - ca
```シフトの周波数を上げる`(x, y)`。 

このシフトは、これら 2 つのセルを揃える独自の変換です。 
6. 周波数が最大になるシフトを追跡します。 
7. そのシフトを出力します。 

### なぜ効果があるのか

 固定シフトを考慮する`(x, y)`。 

一対の`1`セルは、次の場合にのみ、このシフトの下でオーバーラップ係数に寄与します。```
rb = ra + x
cb = ca + y
```並べ替えると次のようになります。```
x = rb - ra
y = cb - ca
```したがって、寄与するすべてのペアは、シフトの 1 回の発生に正確に対応します。`(x, y)`私たちのカウントプロセスで。 

逆に、すべてのペアがシフトとしてカウントされます`(x, y)`そのシフトの下で連携し、貢献する`1`オーバーラップ係数に。 

したがって、シフト用に保存された周波数は、そのオーバーラップ係数と正確に等しくなります。 周波数を最大化すると、オーバーラップ係数が最大化され、正確さが証明されます。 

## Python ソリューション```python
import sys
from collections import defaultdict

input = sys.stdin.readline

def solve():
    na, ma = map(int, input().split())

    ones_a = []
    for i in range(na):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == '1':
                ones_a.append((i, j))

    nb, mb = map(int, input().split())

    ones_b = []
    for i in range(nb):
        row = input().strip()
        for j, ch in enumerate(row):
            if ch == '1':
                ones_b.append((i, j))

    cnt = defaultdict(int)

    best_shift = (0, 0)
    best_count = -1

    for ra, ca in ones_a:
        for rb, cb in ones_b:
            shift = (rb - ra, cb - ca)
            cnt[shift] += 1

            if cnt[shift] > best_count:
                best_count = cnt[shift]
                best_shift = shift

    print(best_shift[0], best_shift[1])

if __name__ == "__main__":
    solve()
```コードの最初の部分では、次の内容を含むすべての位置が抽出されます。`1`。 ゼロを含む積は重複係数に寄与しないため、1 つおきのセルは無関係です。 

ネストされたループは、次のすべてのペアを列挙します。`1`細胞。 ペアごとに、それらを揃える固有のシフトを計算します。 辞書は、各シフトに何組が投票したかをカウントします。 

シフトのカウントが現在の最大値を超えた瞬間に、それが最良の回答として保存されます。 このステートメントはあらゆる最適なシフトを受け入れるため、タイブレーク ロジックは必要ありません。 

1 ベースの座標の代わりに 0 ベースの座標を使用しても、計算されたシフトには影響しません。 減算の両方の終点は同じ定数だけシフトされるため、差は同一のままです。 

座標の差は最大でも約 1 程度であるため、オーバーフローの問題は発生しません。`50`規模的には。

 ## 特殊なケース

 それぞれが 1 つの行列を含む 2 つの行列を考えます。`1`:```
1 1
1
1 1
1
```1 の唯一のペアがシフトを生成します`(0,0)`。 そのシフトの頻度は`1`、したがってアルゴリズムは戻ります`(0,0)`。 重複領域の計算は必要ありません。 

最適なシフトにより、一方の行列のほとんどがもう一方の行列の外側に移動する場合を考えてみましょう。```
1 2
10
2 2
00
01
```1 の位置は次のとおりです。`(0,0)`そして`(1,1)`。 彼らのアライメントシフトは、`(1,1)`。 アルゴリズムはこのペアをカウントし、次の値を返します。`(1,1)`ほとんどのセルが重複領域の外側にある場合でも。 重複係数は位置合わせされたものにのみ依存するため、これは正しいです。 

複数の最適な答えを検討してください。```
1 2
11
1 2
11
```両方のシフト`(0,0)`他のいくつかは処理中にカウントを受け取る可能性がありますが、`(0,0)`の最大オーバーラップ係数を達成します。`2`。 別の例で別のシフトが最大値に結びついた場合、アルゴリズムは最初に最大値に達した方を返します。 このステートメントではあらゆる最適な答えが明示的に許可されているため、この動作は有効です。 

最後に、よくある記号の間違いについて考えてみましょう。 もし`1`に表示されます`(0,0)`最初の行列と`(1,1)`2 番目の行列では、位置合わせシフトは次のようになります。```
(1 - 0, 1 - 0) = (1,1)
```使用する`(0 - 1, 0 - 1)`生み出すだろう`(-1,-1)`これにより、2 番目の行列が間違った方向に移動します。 アルゴリズムは一貫して計算します`rb - ra`そして`cb - ca`、このエラーを回避します。
