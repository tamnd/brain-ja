[CF 228E - ベルランドへの道は善意で舗装されている](https://codeforces.com/problemset/problem/228/E)

 **評価:** 1900
 **タグ:** 2-sat、dfs および類似の、dsu、グラフ
 **解決時間:** 1 分 57 秒
 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 グラフがあります`n`によってつながる都市`m`方向のない道路。 各道路にはアスファルトが舗装されています（`1`) またはしません (`0`）。 国王は都市を選択することができ、労働者はその都市に至るすべての道路でアスファルトの状態を切り替えることができます。アスファルト舗装された道路が非アスファルト舗装になり、その逆も同様です。 目標は、すべての道路がアスファルト化される一連の都市選択を見つけることです。 各都市を 1 日に最大 1 回選択できます。`n`日々。 

各入力道路はトリプレットで表されます`(a, b, c)`、 どこ`a`そして`b`それが接続する都市は何ですか、そして`c`初期のアスファルト状態です。 出力は、すべての道路をアスファルト舗装するための切り替え順序を表す都市のシーケンス、またはそのようなシーケンスが存在しない場合は「不可能」のいずれかになります。 

重要な制約は、`n ≤ 10^5`そして`m ≤ 2*10^5`。 これは、以下よりも悪い解決策を意味します。`O(n + m)`または`O((n+m) log(n+m))`制限時間を超える可能性があります。 シーケンスの数が指数関数的に増加するため、都市トグルのすべての順列を試す単純な総当りアプローチは実行不可能です。`n`。 

道路が切断されたコンポーネントまたはサイクルを形成する場合、微妙なエッジ ケースが発生します。 たとえば、初期アスファルト状態の道路を持つ小さな三角形`[1, 0, 0]`トグル順序を慎重に選択する必要がある場合があります。 やみくもに都市を選択すると、3 つの都市すべてを切り替えた後でも 1 つの道路が未舗装のままになる可能性があります。 

もう 1 つの注意が必要なシナリオは、すべての道路が最初はアスファルトで舗装されているか、最初はすべて舗装されていない場合です。 アルゴリズムは、特定の初期構成を想定せずに、これらを均一に処理する必要があります。 

## アプローチ

 強引な方法は、都市の切り替えのすべてのシーケンスを試し、それぞれに切り替え操作を適用し、すべての道路がアスファルトで舗装されるかどうかを確認することです。 のために`n`都市、あります`2^n`可能なトグルの組み合わせ。 各組み合わせではすべてを検査する必要があります`m`道路。 これにより、およその操作数が得られます。`O(m * 2^n)`、これは完全に不可能です`n`まで`10^5`。 

重要な観察は、各道路が独立して切り替わり、道路を偶数回切り替えると元の状態のままになり、奇数回切り替えると反転することです。 アスファルトの状態を二値で表すと(`1`アスファルト舗装の場合、`0`それ以外の場合)、問題を GF(2) 上の線形方程式系に還元できます。 それぞれの道ごとに`(u, v)`、方程式は`x[u] XOR x[v] = 1 - c`、 どこ`c`が初期状態です。 未知のもの`x[i]`都市かどうかを示します`i`切り替わります (`1`） か否か （`0`）。 この系を解くことは、2-SAT 問題を解くこと、または方程式のグラフに対して DFS を実行することと同じです。 

グラフ内の各連結成分は独立して処理できます。 コンポーネントを任意のノードにルートし、そのトグル値を割り当てることができます。 次に、DFS を使用して値をツリーに沿って伝播し、すべてのエッジ方程式を満たすようにします。 矛盾が発生した場合 (方程式が満たされない場合)、コンポーネントには解決策がなく、問題全体が不可能になります。 それ以外の場合は、割り当てられたすべての都市を収集します`1`一連のトグル操作として。 これにより、これ以上のものは必要なくなります。`n`日々。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m * 2^n) | O(n + m) | 遅すぎる |
 | DFS + XOR 伝播 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 都市の隣接リストを作成し、各近隣都市と道路の初期アスファルト状態を保存します。 それぞれの道路は次の形式の方程式を導入します。`x[u] XOR x[v] = 1 - c`。 
2. すべての都市を次のように初期化します。`x[i] = -1`、未割り当てのトグル状態を表します。 
3. 未訪問の都市ごとに、DFS を実行して割り当てを伝達します。 任意に割り当てる`x[root] = 0`コンポーネントのルートの場合。 
4. DFS中、都市の場合`u`割り当てられた`x[u]`、それぞれの隣人を考慮します`v`道路状況あり`c`。 満足するために`x[u] XOR x[v] = 1 - c`、割り当てます`x[v] = x[u] XOR (1 - c)`未割り当ての場合。 
5. もし`v`すでに値がある場合は、方程式が成り立つかどうかを確認してください。 そうでない場合は、すぐに「不可能」と報告してください。 
6. すべてのコンポーネントを処理した後、すべての都市を収集します。`x[i] = 1`。 これは、任意の順序で切り替える都市のセットです。 
7. 切り替えられた都市の数とそのインデックスを出力します。 

機能する理由: 各道路は 2 つの終点からのみ影響を受けます。 DFS ごとにトグル値を割り当てると、各エッジ方程式が一貫して満たされることが保証されます。 XOR 伝播により、すべての道路のトグルのパリティがターゲットのアスファルトの状態と一致することが保証されます。 競合は即座に検出されるため、解決策は正確かつ完全になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 20)

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, c = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, c))
        adj[v].append((u, c))

    x = [-1] * n
    def dfs(u):
        for v, c in adj[u]:
            expected = x[u] ^ (1 - c)
            if x[v] == -1:
                x[v] = expected
                if not dfs(v):
                    return False
            elif x[v] != expected:
                return False
        return True

    for i in range(n):
        if x[i] == -1:
            x[i] = 0
            if not dfs(i):
                print("Impossible")
                return

    res = [i + 1 for i in range(n) if x[i] == 1]
    print(len(res))
    if res:
        print(*res)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず隣接関係グラフを構築します。 各 DFS 呼び出しは、ツリー構造に沿って XOR 式を伝播します。 設定`x[root] = 0`伝播を任意に単純化し、必要に応じてすべてのゼロを 1 に切り替えることで、任意の解をシフトできます。 競合は、以前に割り当てられた都市が方程式に違反した場合に検出されます。

import sys, io

def run(inp: str) -> str:

# Provided sample
assert run("4 4\n1 2 1\n2 4 0\n4 3 1\n3 2 0\n") in ["2\n2 3", "2\n3 2"], "sample 1"
