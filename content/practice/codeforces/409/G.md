 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、$n$浮動小数点座標を使用した 2D 平面上の点。 タスクは、すべての点が半平面 (平面を 2 つの部分に分割する直線) で確実にカバーできる、原点の周りの可能な最小の回転角度を見つけることです。 同様に、原点から光を当てることを想像すると、すべての点が光線の片側に位置するように回転させたいと考えます。目標は、それを達成するために回転する角度を最小限に抑えることです。 

入力には最大 1000 点があり、座標は -1000 ～ 1000 の間で、小数点以下 2 桁で指定されます。 これは、浮動小数点の精度が重要であることを意味しますが、非常に大きな数値や、倍精度浮動小数点が提供する精度を超える精度について心配する必要はありません。 1秒という制限時間は、$O(n^2 \log n)$解決策は実現可能ですが、$O(n^3)$解決策が遅すぎる可能性があります。 

複数の点が原点と同一線上にある場合、明らかではないエッジ ケースが発生します。 たとえば、すべての点が正の X 軸上にある場合、最小回転角度は 0 です。もう 1 つの注意が必要なシナリオは、点が原点を中心とした円内に均等に分布している場合です。 軸に沿った方向のみをチェックする単純な方法では、必要な角度が過小評価される可能性があります。 点が反対方向にクラスター化されている場合は、最小の半平面によって小さなクラスターが除外される可能性があるため、慎重に処理する必要があります。 

## アプローチ

 強引なアプローチは、考えられるすべての点のペアを試して、半平面の候補方向を定義することです。 候補となる方向ごとに、すべてのポイントをチェックして、それらをカバーするために必要な最小限の回転を計算します。 これは正しいです。なぜなら、半平面の最適な境界は少なくとも 1 つの点を通過する必要があるからです。 ただし、この方法には次のことが含まれます。$O(n^3)$最悪の場合の操作: それぞれについて$n^2$候補の方向性を確認します$n$ポイントは過剰です$n=1000$。 

重要な観察は、問題が原点に対する角度に帰着するということです。 各点は、次を使用して角度として表すことができます。`atan2(y, x)`。 最小の半平面は、すべての点をカバーする最小の角度間隔に対応します。 角度をソートすると、これを円間隔の問題として扱うことができます。ソートした角度を反復処理して、それぞれを半平面の潜在的な開始点として扱い、180 度のスイープ内に収まる最大角度を見つけることができます。 ソートには時間がかかるため、これにより複雑さが大幅に軽減されます。$O(n \log n)$スキャンは次の方法で実行できます$O(n)$二点アプローチで。 

ブルート フォースはすべてのポイント ペアを明示的に考慮するため機能しますが、次の場合には失敗します。$n$立方体成長により大きくなります。 原点の周りの各点の角度が十分であるという洞察により、モジュロ演算による角度の循環構造を利用して、並べ替えられた角度の配列に対する線形スキャンを使用して問題を解決できます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | O(n) | 遅すぎる |
 | 角度スイープ | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 以下を使用して、原点に対する各点の角度を計算します。`atan2(y, x)`。 これにより、各点が間の単一のスカラー角度に変換されます。$-π$そして$π$。 角度を使用すると、2D の幾何学的な問題が 1D の円形の問題に縮小されます。 
2. 角度の配列を昇順に並べ替えます。 並べ替えにより、すべての点をカバーする連続した角度間隔を効率的に見つけることができます。 
3. を追加して角度配列を複製します。$2π$を各角度に追加し、ソートされた配列の末尾に追加します。 これは円形のラップアラウンドを処理するので、交差する間隔を確認できます。$-π/π$特別なロジックなしで境界を設定します。 
4. 2 つのポインタを初期化します。`i`そして`j`、どちらも 0 から始まります。`i`は半平面の始点を表し、`j`前方にスキャンして、180 度の間隔内で最も遠い点を見つけます。`i`。 
5. それぞれについて`i`、 前進`j`角度が違う限り`angles[j] - angles[i]`π以下です。 最大の差は、次から始まる半平面によってカバーされる最大の間隔を示します。`angles[i]`。 
6. 補角を 360 度（または$2π$ラジアン)$2π - \text{max interval}$。 全体にわたって最小限の補完を追跡する`i`。 この最小補数は、すべての点が半平面内にあることを保証する最小の回転です。 

機能する理由: すべての点を含むすべての半平面は、単位円上の最大 π ラジアンの間隔として表すことができます。 角度を並べ替えると、2 ポインター手法によるスキャンで最大の間隔がキャプチャされることが保証されます。 補数を計算することで、必要な最小回転角度がわかります。 すべての点が単位円上にあり、最大の角度ギャップが最小の回転を決定するため、どのような点の構成でもより小さな回転を生成することはできません。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())
angles = []

for _ in range(n):
    x, y = map(float, input().split())
    angles.append(math.atan2(y, x))

angles.sort()
angles += [angle + 2 * math.pi for angle in angles]

ans = 0.0
j = 0

for i in range(n):
    while j < 2 * n and angles[j] - angles[i] <= math.pi + 1e-12:
        j += 1
    ans = max(ans, angles[j - 1] - angles[i])

print(f"{2 * math.pi - ans:.10f}")
```コードはまずすべての点を読み取り、それらを角度に変換します。 ソートでは、2 つのポインターを使用してスキャンできます。 配列を複製すると循環ラップアラウンドが処理されるため、-π/π 境界を越える間隔については特別なロジックは必要ありません。 の`1e-12`許容誤差により、正確な境界での浮動小数点エラーが防止されます。 最終的な答えは、最小回転を次のように出力します。$2π - \text{largest interval}$。

## テストケース```python
import sys, io
import math

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(input())
    angles = []
    for _ in range(n):
        x, y = map(float, input().split())
        angles.append(math.atan2(y, x))
    angles.sort()
    angles += [angle + 2 * math.pi for angle in angles]
    ans = 0.0
    j = 0
    for i in range(n):
        while j < 2 * n and angles[j] - angles[i] <= math.pi + 1e-12:
            j += 1
        ans = max(ans, angles[j - 1] - angles[i])
    return f"{2 * math.pi - ans:.10f}"

# provided sample
assert run("8\n-2.14 2.06\n-1.14 2.04\n-2.16 1.46\n-2.14 0.70\n-1.42 0.40\n-0.94 -0.48\n-1.42 -1.28\n-2.16 -1.62\n") == "5.4100117506"
