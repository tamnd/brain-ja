 ## 解決策
 ## 問題の理解

 いくつかの小文字の文字列が与えられます。 各文字列について、その文字列に出現するすべての文字を含む最小のアルファベットが必要です。 

アルファベットは常に英語のアルファベットの接頭辞になります。 サイズ 1 のアルファベットには次の内容のみが含まれます。`a`、サイズ 2 のアルファベットには次のものが含まれます。`a`そして`b`、 等々。 サイズ 26 のアルファベットにはすべての小文字が含まれます。 

質問は単純です。文字列で使用されているすべての文字を含むアルファベットの最小の接頭辞は何ですか?

 これを考えるのに役立つ方法は、存在する最大の文字に焦点を当てることです。 文字列に文字が含まれている場合`w`の場合、有効なアルファベットには以下のすべての文字が含まれている必要があります。`a`を通して`w`。 以来`w`が 23 番目の文字である場合、答えは少なくとも 23 である必要があります。他のすべての文字が 23 番目の文字より前の場合、`w`の場合、サイズ 23 のアルファベットですでに十分です。 

制約はわずかです。 各文字列の長さは最大 100 で、テスト ケースの数は最大 1000 です。 たとえ$O(n^2)$ここでの解決策は完全に問題ありません。 各文字列を 1 回スキャンするだけで済みます。 

最も起こりやすい間違いの 1 つは、最大の文字を見つけるのではなく、個別の文字を数えることです。 

考慮する：```
1
3
bcf
```特徴的な文字は、`{b,c,f}`、サイズは 3 です。不注意な解法では 3 が出力されます。正しい答えは 6 です。`f`6 番目の文字、および次の文字を含む任意のアルファベットです。`f`も含まれている必要があります`a`を通して`e`。 

もう 1 つの間違いは、文字列の長さを使用することです。 

考慮する：```
1
5
zzzzz
```文字列の長さは 5 ですが、答えは 26 です。`z`26通目の手紙です。 

3 番目の間違いは、文字を並べ替えて一意の文字数を使用することです。 

考慮する：```
1
4
down
```4 つの異なる文字がありますが、最大のものは`w`, したがって、答えは23です。 

## アプローチ

 ブルートフォース手法では、1 から 26 までのすべてのアルファベット サイズを試します。サイズごとに、文字列のすべての文字がそのアルファベットに属しているかどうかを確認します。 最初の有効なサイズが答えになります。 

これが機能するのは、可能なアルファベットのサイズが 26 個だけであるためです。 ある長さの文字列の場合$n$、複雑さは$O(26n)$。 

重要な観察は、答えが文字列内の最大の文字によって完全に決定されるということです。 最大の文字の場合`k`、その後、すべての小さな文字が、対応するサイズのアルファベットに自動的に含まれます。`k`。 これより小さいアルファベットは見逃されます`k`自体。 

これにより、問題は最大文字を見つけて、それをアルファベット内の位置に変換するだけになります。

 ## アルゴリズムのチュートリアル

 1. テスト ケースの数を読み取ります。 
2. 各テスト ケースについて、次の内容を読んでください。`n`そして文字列`s`。 
3. で最大の文字を見つけます。`s`。 
4. 以下を使用して、その文字をアルファベットの位置に変換します。`ord(max_char) - ord('a') + 1`5. 結果の値を出力します。 

これが機能する理由は、アルファベットのサイズが`x`からの文字が正確に含まれています`a`を通して`x`- 番目の手紙。 文字列内に現れる最大の文字が、このプレフィックスがどこまで拡張される必要があるかを決定する唯一の文字です。 

### なぜ効果があるのか

 しましょう`c`文字列内に現れる最大の文字になります。 

有効なアルファベットには次のものが含まれている必要があります。`c`したがって、そのサイズは少なくとも次のアルファベットの位置でなければなりません。`c`。 

サイズが次の位置と等しいアルファベット`c`～からのすべての文字が含まれています`a`を通して`c`。 文字列内にこれより大きい文字はないため、`c`、すべての文字が含まれます。 

有効なアルファベットの最小サイズは、最大文字の位置と同じです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())

for _ in range(t):
    n = int(input())
    s = input().strip()

    ans = ord(max(s)) - ord('a') + 1
    print(ans)
```実装はアルゴリズムからの観察に直接続きます。 

への呼び出し`max(s)`文字列内で辞書編集上最大の小文字を検索します。 ASCII テーブルでは小文字がアルファベット順に表示されるため、最大の文字はアルファベット順で最も新しい文字でもあります。 

表現```
ord(max(s)) - ord('a') + 1
```その文字を 1 から始まるアルファベットのインデックスに変換します。 例えば：```
ord('a') - ord('a') + 1 = 1
ord('f') - ord('a') + 1 = 6
ord('z') - ord('a') + 1 = 26
```すべての値が小さいため、オーバーフローの心配はありません。 唯一の微妙な点は、末尾の改行を次のように削除することです。`.strip()`文字列を処理する前に。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        s = input().strip()
        out.append(str(ord(max(s)) - ord('a') + 1))

    return "\n".join(out)

# provided sample
assert run(
    "5\n"
    "1\n"
    "a\n"
    "4\n"

    "10\n"

    "3\n"
    "bcf\n"
    "5\n"
    "zzzzz\n"
) == "1\n23\n19\n6\n26"

# minimum size
assert run("1\n1\na\n") == "1"

# largest possible letter
assert run("1\n1\nz\n") == "26"

# all characters identical
assert run("1\n5\nmmmmm\n") == "13"

# mixed letters
assert run("1\n6\nabczxy\n") == "26"
