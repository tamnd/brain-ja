 ## 問題の理解

 2 つの配列が与えられています。`a`そして`b`、それぞれの長さ`n`、間に要素がある`1`そして`n`。 3 番目の配列を選択する必要があります`c`同じ長さなので構築されたゲームはKoxiaが勝ちます。 ゲームは次のように進行します`n`ラウンドします。 ラウンド中`i`、コキシアはマルチセットを見る`{a_i, b_i, c_i}`1 つの要素を最適に削除します。 次に、まひるは残りの 2 つの要素から 1 つを選択します。 すべてのラウンドの後、アレイは`d`まひるの選択は以下の順列でなければなりません`1..n`コキアが勝つために。 

入力サイズは最大です`n = 10^5`テストケースごととすべての合計`n`も上限があります`10^5`。 これにより、考えられるすべてを列挙する強引なアプローチが排除されます。`c`配列の総数は`n^n`最悪の場合。 テスト ケースごとに線形または線形に近いソリューションが必要です。 

エッジケースには、次のような状況が含まれます。`a`そして`b`すでに、どうやっても順列を構築できないような繰り返し値を持っています。`c`は。 たとえば、ある数値の場合、`x`両方に2回登場します`a`そして`b`、選択肢はありません`c`有効な順列を生成できます。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての配列を試すことです`c`ラウンドごとにゲームをシミュレーションします。 各ラウンドで、Koxia は削除するのに最適な要素を選択し、Mahiru は残りの 2 つの要素から最適な要素を選択します。 施工後`d`、順列かどうかを確認します。 これは小規模な場合に機能します`n`、しかし、`n = 10^5`、配列の数`c`は`n^n`シミュレーションが遅すぎる可能性があります。 

重要な洞察は、**2 部マッチング** の観点から考えることです。 各ラウンドでは 3 つの値のマルチセットが得られます。 Koxia は 1 つを削除できるため、Mahiru には 2 つの選択肢が残されます。 Koxia が勝利を保証するには、各ラウンドでまひるの選択を整数に割り当てる必要があります。`1..n`衝突なしで。 つまり、からの各数値は、`1`に`n`まひるの最終配列に 1 回だけ出現する必要があります`d`。 

これを **有向グラフ** としてモデル化できます。各ラウンドはノードと数値です。`1..n`は別のノードです。 ラウンドから出現する可能性のある数字までエッジを描画します。`d_i`Koxiaの最適な除去に応じて。 その後、有効にカウントします`c`配列は、**このグラフ**内の有効な完全一致の数をカウントすることに帰着します。これは**関数グラフ**のサイクルに対応します。 

ラウンドごとに考えられる選択肢を慎重に分析した結果、この関数グラフ内の各連結成分が有効な選択肢の総数に 1 または 2 の係数を与えていることがわかります。`c`配列。 すべてのコンポーネントにわたる積、モジュロ`998244353`、答えが得られます。

 ## アルゴリズムのチュートリアル

 1. 周波数配列を初期化する`freq`サイズの`n + 1`まひるが選択した各数字を何ラウンドで出せるかを数えます。 未割り当ての番号のセットも維持します`unused`から`1`に`n`。 
2. ラウンドごとに`i`に応じて、まひるの可能な選択肢を決定します。`a[i]`そして`b[i]`。 もし`a[i] == b[i]`, Koxia は両方のコピーを削除できないため、Mahiru はその値を取得する必要があります。 それ以外の場合、Koxia が最適に 1 つを削除した後、まひるは残りの 2 つの番号のいずれかを選択できます。 
3. 各数値からマッピングを構築する`x`生成できるすべてのラウンドに`x`。 
4. 数値を反復処理する`1..n`。 数値が孤立している (1 つの可能なラウンドのみがその数値を生成する) 場合は、その数値をそこに割り当て、他のラウンド オプションから削除します。 数値が可能なラウンドのサイクルに属している場合、各サイクルが合計カウントに正確に 2 つの選択肢を与えることに注意してください。 
5. すべてのサイクルと個別の割り当てからの寄与を乗算します。 積の剰余を維持する`998244353`。 
6. 有効な数の合計を返します。`c`配列。 

機能する理由: ラウンドと考えられる値を 2 部マッチング問題としてモデル化することで、各数値が`1..n`に 1 回だけ表示されます`d`この関数グラフに完全な一致がある場合に限ります。 互いに素なサイクルまたは孤立したノード内の一致の数は、有効なサイクルの数と正確に一致します。`c`配列。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        graph = [0] * (n + 1)
        used = [False] * (n + 1)
        for i in range(n):
            if a[i] == b[i]:
                graph[i] = a[i]
            else:
                graph[i] = 0
        visited = [False] * n
        ans = 1
        for i in range(n):
            if visited[i] or graph[i]:
                continue
            cycle = 0
            j = i
            while not visited[j]:
                visited[j] = True
                if a[j] != b[j]:
                    cycle += 1
                    j = a[j] - 1 if not visited[a[j]-1] else b[j]-1
                else:
                    break
            if cycle > 0:
                ans = (ans * 2) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```ソリューションはラウンドを分割します。`a[i] == b[i]`(まひるの選択は固定) 2 つの異なるオプションがあるラウンドから。 サイクル検出により、独立したサイクルが合計カウントの 2 倍に寄与することが保証されます。 すべてを列挙することは避けます`c`直接配列するため、ソリューションは線形時間で実行されます。
