 ## 解決策
 ## 問題の理解

 各超高層ビルは、地面に位置する軸に沿った長方形です。 パラメータのある建物`(h, l, r)`すべてのポイントを占める`l ≤ x ≤ r`そして`0 ≤ y ≤ h`。 

地面から始まり、水平または垂直にのみ移動し、すべての建物を地面と一緒に囲むポリラインを構築する必要があります。 このようなすべてのポリラインの中で、最初に囲まれた領域を最小化します。 複数のポリラインが同じ最小面積を達成する場合、全長が最も短いポリラインが選択されます。 

幾何学的には、これはまさに長方形の結合の上のスカイラインです。 ポリラインは、より高い建物が建つたびに上昇し、目に見える高さが一定である間は平らになり、現在の最も高い建物が消えると下降します。 

この制約により、二次アプローチは即座に除外されます。 と`n ≤ 100000`、 平`O(n^2)`簡単な操作で`10^10`最悪の場合、制限時間を大幅に超えて作業が行われる可能性があります。 に近いものが必要です`O(n log n)`。 

建物は任意の方法で重なり合うことができます。 不用意にスカイラインを構築しようとすると、いくつかの微妙なケースが発生します。 

危険なケースの 1 つは、複数のイベントが同じ X 座標で発生する場合です。 

例：```
3
5 0 2
3 2 4
7 2 5
```で`x = 2`、1 つの建物が終了し、他の 2 つの建物が始まります。 スカイラインは高さから直接ジャンプする必要があります`5`高さまで`7`。 挿入前に削除を処理する単純なスイープでは、誤って中間ドロップが作成される可能性があります。`0`または`3`。 

もう 1 つの注意が必要なケースは、入れ子になった建物です。 

例：```
3
10 0 10
3 2 4
5 6 8
```小さな建物は高い建物の下に完全に隠れるため、輪郭に影響を与えることはありません。 すべての建物のセグメントを盲目的に出力する単純な実装では、冗長な頂点が生成され、最小長の要件を満たせなくなります。 

バラバラな建物も重要です。 

例：```
2
4 0 2
3 5 7
```正しいスカイラインは建物間の地上レベルに戻る必要があります。```
0 0
0 4
2 4
2 0
5 0
5 3
7 3
7 0
```別々のコンポーネントを誤ってマージすると、不必要な領域が囲まれてしまい、主要な最適化基準に違反することになります。 

最後に、同じ高さには注意が必要です。 

例：```
2
5 0 2
5 2 4
```正解は、高さにある 1 つの連続した水平セグメントです。`5`、不必要な垂直エッジを持つ 2 つの別個のプラトーではありません。`x = 2`。 

## アプローチ

 最も直接的なアイデアは、x 軸を離散化することです。 すべての個別の座標を収集し、平面を基本的な間隔に分割し、各間隔をカバーする建物の最大高さを計算できます。 高さプロファイルがわかれば、ポリラインの生成は簡単です。 

これは概念的に機能します。最適なポリラインは、各 X 座標での最大可視高さによって一意に決定されるからです。 曲線が低いと建物と交差し、曲線が高いと囲まれた領域が増加します。 

ブルート フォースの問題はカバレッジ テストです。 座標を次のように圧縮するとします。`m`間隔。 間隔ごとにすべての建物をチェックして最大の高さを見つけます。 最悪の場合、`m`は`2n`、これは次のようになります`O(nm) = O(n^2)`。 

と`100000`建物、つまり大まかに言うと`10^10`比較。 

重要な観察は、スカイラインが建物の境界でのみ変化するということです。 2 つの連続するイベント座標の間では、アクティブな建物のセットは決して変化しないため、そこで目に見える高さは一定です。 

これは当然スイープ ラインを示唆します。 データ構造内で最も高いアクティブな建物を維持しながら、すべての建物の開始イベントと終了イベントを左から右に処理します。 

建物の開始時に、その高さを挿入します。 

建物が完成したら、その高さを取り除きます。 

位置でのイベントの処理後`x`、アクティブな最大高さによって、すぐ右側のスカイラインが決まります。`x`。 

最大ヒープにより、現在最も高い建物に高速アクセスできます。 Python ヒープは最小ヒープであるため、負の高さを格納します。 ヒープから任意の高さを削除するのは不便なので、カウンター マップを使用した遅延削除を使用します。 

スイーププロセス`2n`イベント、および各挿入または削除のコスト`O(log n)`、全体的に複雑になります`O(n log n)`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての建物を 2 つのイベントに変換します。 

建物`(h, l, r)`は次のようになります:

 - イベント開始`(l, type=0, h)`- 終了イベント`(r, type=1, h)`同じ座標で終了イベントの前に開始イベントを処理します。 これにより、ある建物が別の建物の開始点とまったく同じ位置で終了する場合に、一時的に高さが低下することが回避されます。 
2. すべてのイベントを X 座標とイベント タイプで並べ替えます。 

並べ替えた後、左から右にスイープすると、どの建物が現在アクティブであるかが常にわかります。 
3. アクティブな高さの最大ヒープを維持します。 

Python は最小ヒープのみを提供するため、負の高さを格納します。 

最初にヒープには次のものが含まれます`0`、地面のレベルを表します。 
4. 遅延削除のために頻度マップを維持します。 

建物が終了すると、ヒープから直接削除するのではなく、その頻度を減らします。 

現在の最大値を読み取る前に、頻度がゼロになったヒープ要素を繰り返しポップします。 
5. 同じ X 座標を持つすべてのイベントをまとめて処理します。 

これは重要です。 スカイラインは、同じ X 座標で複数回変更することはできません。 

位置でのすべてのイベントについて`x`:

 - 開始イベントの高さを追加します
 - 終了イベントで削除されたマークの高さ
 6. 位置ですべてのイベントを処理した後`x`、ヒープをクリーンアップします。 

最上部がアクティブな高さに一致するまで、古いヒープ エントリを削除します。 
7. 新しい最大高さを以前のスカイラインの高さと比較します。 

高さが次から変わった場合`prev_h`に`cur_h`、スカイラインは次の方向に曲がらなければなりません`x`。 

2 つの頂点が追加されます。 

-`(x, prev_h)`-`(x, cur_h)`これにより、必要な垂直セグメントが作成されます。 
8. 冗長な連続した重複を削除します。 

トランジションによっては、繰り返しのポイントや不要な同一線上の頂点が作成される場合があります。 それらを圧縮すると、最小長のポリラインが保証されます。 
9. スイープ トランジションを通じて、最初と最後の接地点を自動的に追加します。 

### なぜ効果があるのか

 すべての x 座標で、ヒープには、x のすぐ右側の位置をカバーする建物の高さが正確に含まれます。 それらの最大値は、エンベロープの可能な最小の有効な高さです。これより小さい値は建物と交差するためです。 

スカイラインは、アクティブな最大高さが変更された場合にのみ変更されます。 これらの遷移点で頂点を正確に放出すると、固有の最小面積エンベロープが生成されます。 垂直または水平セグメントを追加すると、面積は変化せずに全長が増加するため、クリーン化されたポリラインもすべての最小面積ソリューションの中で最小の長さを持ちます。 

## Python ソリューション```python
import sys
import heapq
from collections import defaultdict

input = sys.stdin.readline

def solve():
    n = int(input())

    events = []

    for _ in range(n):
        h, l, r = map(int, input().split())

        # start before end at same x
        events.append((l, 0, h))
        events.append((r, 1, h))

    events.sort()

    heap = [0]
    cnt = defaultdict(int)
    cnt[0] = 1

    ans = []

    prev_h = 0

    i = 0
    m = len(events)

    while i < m:
        x = events[i][0]

        while i < m and events[i][0] == x:
            _, typ, h = events[i]

            if typ == 0:
                cnt[h] += 1
                heapq.heappush(heap, -h)
            else:
                cnt[h] -= 1

            i += 1

        while heap and cnt[-heap[0]] == 0:
            heapq.heappop(heap)

        cur_h = -heap[0]

        if cur_h != prev_h:
            ans.append((x, prev_h))
            ans.append((x, cur_h))
            prev_h = cur_h

    # remove redundant consecutive duplicates / collinear points
    res = []

    for p in ans:
        if res and res[-1] == p:
            continue

        while len(res) >= 2:
            x1, y1 = res[-2]
            x2, y2 = res[-1]
            x3, y3 = p

            if (x1 == x2 == x3) or (y1 == y2 == y3):
                res.pop()
            else:
                break

        res.append(p)

    print(len(res))
    for x, y in res:
        print(x, y)

solve()
```スイープ ラインは実装の中核です。 すべての建物は、1 つの挿入イベントと 1 つの削除イベントに寄与します。 イベントを並べ替えると、左から右への走査順序が決まります。 

ヒープには、現在スカイラインを定義している可能性のあるすべての高さの候補が格納されます。 ヒープから任意の要素を削除するとコストがかかるため、コードでは遅延削除を使用します。 高さは、頂点に達するまでヒープ内に残ります。 その時点で、周波数マップにそれらがまだアクティブであることが示されているかどうかを確認します。 

同じ x 座標にあるすべてのイベントをまとめて処理すると、中間遷移が正しく行われないことが回避されます。 ある高さが消えて、同じ座標にさらに高い別の高さが現れるとします。 一度に 1 つのイベントずつ変更を発行すると、誤って幅がゼロのジグザグが作成される可能性があります。 

最後のクリーンアップ ループは、同一線上にある冗長な頂点を削除します。 これがないと、同じ高さの台地や垂直方向の回転が繰り返されると、最小ではないポリラインが生成される可能性があります。 

すべての座標と高さは Python 整数に安全に収まるため、オーバーフローの問題は発生しません。

 ## 特殊なケース

 同じ境界を共有する建物を考えてみましょう。```
3
5 0 2
3 2 4
7 2 5
```で`x = 2`、 身長`5`高みになると消える`3`そして`7`現れる。 アルゴリズムはすべてのイベントを次の時点で処理します。`x = 2`新しい最大値を読む前に一緒に行ってください。 ヒープはから直接移行します。`5`に`7`、生産:```
0 0
0 5
2 5
2 7
5 7
5 0
```一時的なディップは発生しません。 

次に、ネストされた建物を考えてみましょう。```
3
10 0 10
3 2 4
5 6 8
```ヒープの最大値は残ります`10`スイープ全体を通して。 小さな建物はヒープに出入りしますが、最大になることはありません。そのため、内部のスカイラインが変わることはありません。`[0,10]`。 

均等に隣接する建物の場合:```
2
5 0 2
5 2 4
```最初の建物が終了し、2 番目の建物が始まるとき`x = 2`、処理前後の最大高さが残ります。`5`。 以来`cur_h == prev_h`、新しい頂点は生成されません。 結果は、1 つの連続した水平セグメントになります。 

最後に、ばらばらの建物:```
2
4 0 2
3 5 7
```加工後`x = 2`、ヒープの最大値は次のようになります。`0`、したがって、スカイラインは地面のレベルに戻ります。 で`x = 5`、再び上昇します`3`。 これにより、不必要な領域を囲むのではなく、建物間の空きスペースが適切に保存されます。
