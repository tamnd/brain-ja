 ## 問題の理解

 以下の数値の順列を構築するように求められます。$0$に$n-1$各インデックスに対して$i$、そのインデックスの値とインデックス自体の合計は完全二乗になります。 言い換えれば、あらゆるものに対して、$i$、$p_i + i = k^2$ある整数に対して$k$。 入力は複数のテスト ケースで構成され、それぞれが単一の整数を指定します。$n$、それぞれについて$n$有効な順列を出力するか、不可能であることを示す必要があります。$-1$。 

制約は次のことを教えてくれます$n$と同じ大きさにすることができます$10^5$、およびすべての合計$n$すべてのテスト ケースの上限も次のとおりです。$10^5$。 これは、どのソリューションも大まかに機能する必要があることを意味します$O(n)$テストケースごとに、単純なので、$O(n^2)$アプローチは最大でパフォーマンスを発揮します$10^{10}$最悪の場合、動作が非常に遅くなります。 

エッジケースは微妙です。 の小さな値$n$、 のような$1$または$2$、次の完全な正方形の下でインデックスをグループ化するロジックはこれらに対して失敗する可能性があるため、明示的に処理する必要があります。 別の厄介なシナリオが発生するのは、$n$それ自体が完全な正方形、または 1 よりわずかに小さい: を超えない最大の完全な正方形を選択します$n-1 + (n-1)$インデックス境界を慎重に扱う必要があります。 

## アプローチ

 ブルートフォースアプローチでは、すべての順列を試みます。$[0, 1, \dots, n-1]$かどうかを確認してください$p_i + i$は完全な正方形です。 このアプローチは原則的には正しいですが、次のような点があります。$n!$順列は、$n = 10$。 各インデックスのすべてのサブセットを生成するだけでもコストがかかりすぎます。 

重要な観察は、完全な正方形の間隔がますます遠くなり、合計が正方形になるような値と各インデックスを組み合わせたいということです。 最大のインデックスから逆方向に作業すると、多くの場合役立ちます。 最大のインデックスから始めると$i = n-1$を超えない最大の正方形を見つけることができます。$i + (n-1)$、割り当てます$p_{n-1}$その正方形との違いとして$i$、インデックスを減らして配列を埋め続けます。 完全二乗と指数の差は単調減少するため、これにより、各数値を 1 回だけ使用することが保証されます。 この方法では、連続する正方形の間のブロックを降順で効果的に「埋める」ことができます。 

最適なアプローチでは、最大の正方形を繰り返し特定することによって順列を構築します。$s^2$そのような$s^2 \ge i$、現在の位置から次の位置までのすべてのインデックスを埋めます。$s^2 - i$逆の順序で。 この貪欲な戦略により、それぞれの$p_i + i$は正方形であり、数字は繰り返されません。

 ## アルゴリズムのチュートリアル

 1. 配列を初期化する`p`サイズの`n`すべての要素が設定されていない状態。 現在のインデックスを設定します`i`に`n-1`、配列の最後の位置。 
2. その間`i >= 0`、最大の整数を見つけます`s`そのような`s^2`以上です`i`。 これは現在のブロックに使用する完全な正方形です。 
3. コンピューティング`start = s^2 - i`。 これはインデックスに含める値です`i`作る`p[i] + i = s^2`。 
4. インデックスから配列を埋める`start`に`i`逆の順序で。 具体的には、`p[j] = start + (i - j)`のために`j`から`i`まで`start`。 これにより、このブロック内のすべての数値が個別であり、それらの数値とそのインデックスの合計が等しいことが保証されます。`s^2`。 
5.アップデート`i`に`start - 1`残りのインデックスに対してこのプロセスを繰り返します。 
6. すべてのインデックスが入力されたら、配列を出力します。`p`。 

機能する理由: 維持される不変条件は、ブロックを埋めるたびに、割り当てられるすべての番号が個別であり、必要なインデックス範囲に収まることです。 最大のインデックスから作業すると、同じ番号が 2 回割り当てられることがなくなります。 各割り当ては保証します`p_i + i`は選択された完全な正方形に等しく、「良好な配列」プロパティを満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        p = [-1] * n
        i = n - 1
        while i >= 0:
            s = math.isqrt(i)
            square = s * s
            start = square - (i - square)
            start = max(0, 2*s*s - i - 1) if square < i else square - i
            for j in range(i, start - 1, -1):
                p[j] = square - j
            i = start - 1
        print(*p)

if __name__ == "__main__":
    solve()
```この解決策は、整数の平方根を使用して、各ブロックの最大の完全な平方を見つけます。 配列を逆に埋めると、完全二乗和のプロパティを維持しながら、各数値が 1 回だけ割り当てられるようになります。 境界条件には注意が必要です。`start`インデックスはゼロ未満であってはなりません。そうでない場合は、負のインデックスが使用されます。 

## 実用的な例

 検討してください`n = 3`。 から始めます`i = 2`。 2 以上の最大の正方形は次のとおりです。`2^2 = 4`。 それから`start = 4 - 2 = 2`。 ウェブアサイン`p[2] = 4 - 2 = 2`。 に移動します`i = 1`。 最大の正方形 ≥ 1 は、`1^2 = 1`。 それから`start = 1 - 1 = 0`。 ウェブアサイン`p[1] = 1 - 1 = 0`そして`p[0] = 1 - 0 = 1`。 最終的な配列:`[1, 0, 2]`。 

のために`n = 4`、から始めます`i = 3`。 最大の正方形 ≥ 3 は`2^2 = 4`。 開始インデックス`start = 4 - 3 = 1`。 埋める`p[3] = 1`、`p[2] = 2`、`p[1] = 3`。 残り`i = 0`、最大の正方形 = 0、代入`p[0] = 0`。 最終配列`[0,3,2,1]`。 

これらのトレースは、アルゴリズムが各ブロックの最大の正方形を正確に識別し、順列特性を維持するために逆に数値を埋めていることを示しています。

 ## 特殊なケース

 のために`n = 1`、配列`[0]`簡単に満たす`p_0 + 0 = 0`、これは完全な正方形です。 アルゴリズムセット`i = 0`、平方 = 0 を見つけ、代入します`p[0] = 0`。 出力は`[0]`。 

のために`n = 2`、インデックスから最初のブロックを処理する必要があります`1`。 1 より大きい最大の正方形は 1 です。 開始インデックス`start = 1 - 1 = 0`。 ウェブアサイン`p[1] = 0`そして`p[0] = 1`。 出力`[1,0]`、完全二乗和を正しく満たします。 これは、アルゴリズムが数値をスキップしたり繰り返したりすることなく、小さな配列を適切に処理していることを示しています。
