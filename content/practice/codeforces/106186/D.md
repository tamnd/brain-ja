 ## 解決策
 ## 問題の理解

 同じ長さの配列が 2 つあります。 各値は最大でも配列の長さです。 このタスクは、最大公約数が素数である、最初の配列の 1 つの要素と 2 番目の配列の 1 つの要素の順序付けされた選択肢を数えるというものです。 順序は重要です。`a[i]`と`b[j]`値が等しい場合でも、別のインデックス ペアを選択することは異なります。 

直接的なアプローチでは、2 つの配列間で考えられるすべてのペアを検査します。 配列に次のものが含まれている場合`n`要素、それが生み出すもの`n²`ペア。 合計から`n`到達できるすべてのテストケースにわたって`200000`、二次解法には約`4 * 10^10`これは 1 秒の制限をはるかに超えています。 値が次のように制限されているという事実を利用する必要があります。`n`要素の数だけではありません。 

扱いにくいケースのほとんどは、正確な gcd 値から割り算を区別することに関連しています。 たとえば、次のような場合です。```
1
2
2
```唯一のペアに gcd があります`2`、これは素数なので、答えは次のようになります。`1`。 重複する値を無視したり、両方の数値が素因数を共有するかどうかだけをチェックしたりするメソッドは、カウントに失敗する可能性があります。 

別の例は次のとおりです。```
2
4 6
2 3
```可能な gcd 値は次のとおりです。`2`、`1`、`2`、 そして`3`、したがって、答えは次のとおりです`3`。 両方の値を素数で割るすべてのペアをカウントする不注意な解決策は、そのペアをカウントする可能性があります。`(4, 2)`プライムを通して`2`そして、gcd 自体は 1 回しか貢献できないことを見逃しています。 必要なのは、共有される素約数の数ではなく、完全な gcd が素数に等しいペアの数です。 

主な違いは、正確な gcd 周波数を計算する必要があることです。 gcd を持つ順序ペアの数がわかったら`d`の素数値の周波数を加算するだけで済みます。`d`。 

## アプローチ

 ブルートフォースの方法は簡単です。 あらゆるインデックスに対して`i`最初の配列とすべてのインデックスで`j`2 番目の配列で計算します。`gcd(a[i], b[j])`そしてプライムかどうかを確認します。 すべての順序付きペアが 1 回だけ検査されるため、これは正しいです。 ただし、`n = 100000`、約 100 億 gcd の操作を実行しますが、これは遅すぎます。 

有用な観察は、小さな値の範囲から得られます。 個々のペアについて考える代わりに、可能な数で割り切れるペアの数を数えることができます。 両方の数が次で割り切れることがわかっている場合、`d`の場合、その gcd は次の倍数になります。`d`。 このようなペアの数は、すべての値の倍数を数えると簡単に取得できます。 

させて`cntA[d]`最初の配列の要素の数で割り切れる数になります。`d`、定義します`cntB[d]`同様に。 それから`cntA[d] * cntB[d]`gcd が次で割り切れるペアの数です。`d`。 

gcd とのペアなので、これではすぐには答えが得られません。`12`のカウントに含まれます`d = 1, 2, 3, 4, 6, 12`。 この重複を、複数の包含を使用して削除します。 値を大きいものから小さいものまで処理すると、すべての値と正確に等しい gcd を持つペアがいくつあるかを計算できます。`d`。 

その後、答えは単純に素数の正確な gcd カウントの合計になります。`d`。

 ## アルゴリズムのチュートリアル

 1. 最初の配列と 2 番目の配列に各値が出現する回数を数えます。 これらの周波数から、`cntA[d]`そして`cntB[d]`、各値は配列要素の数が次の倍数であることを格納します。`d`。 これにより、個々の割り算チェックが、約数に関するプレフィックス スタイル情報に変換されます。 
2. あらゆる人にとって`d`、計算します`pairs[d] = cntA[d] * cntB[d]`。 これは、gcd が次の値で割り切れる順序ペアの数です。`d`。 選択した両方の数値が次の値を含む場合、ペアはここに属します。`d`除数として。 
3. プロセス`d`から`n`まで`1`。 から始める`exact[d] = pairs[d]`、次に、より大きいすべての倍数のカウントを減算します。`d`これらはすでに正確な gcd 値として分類されています。 残りの値は、gcd が正確に一致するペアの数です。`d`。 
4. までの素数を生成します`n`ふるいで。 追加`exact[p]`すべての素数に対して`p`最終的な答えを得るために。 

なぜ効果があるのか:

 すべての数字について`d`、`pairs[d]`gcd に含まれるすべてのペアをカウントします。`d`除数として。 大きいものから小さいものへ処理する場合、より大きな gcd 値はすべてすでにから削除されています。`pairs[d]`。 残りのペアは、より大きな倍数の gcd を持つことはできません。`d`、そしてそれらはすべて次の式で割り切れます。`d`、したがって、それらの gcd は正確である必要があります`d`。 したがって`exact[d]`どれも正しいです`d`。 素数値の正確な数を合計すると、必要なペアが正確にカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    t = data[0]
    ptr = 1
    tests = []
    max_n = 0

    for _ in range(t):
        n = data[ptr]
        ptr += 1
        a = data[ptr:ptr + n]
        ptr += n
        b = data[ptr:ptr + n]
        ptr += n
        tests.append((n, a, b))
        max_n = max(max_n, n)

    is_prime = [True] * (max_n + 1)
    if max_n >= 0:
        is_prime[0] = False
    if max_n >= 1:
        is_prime[1] = False
    for i in range(2, int(max_n ** 0.5) + 1):
        if is_prime[i]:
            for j in range(i * i, max_n + 1, i):
                is_prime[j] = False

    ans = []

    for n, a, b in tests:
        freq_a = [0] * (n + 1)
        freq_b = [0] * (n + 1)

        for x in a:
            freq_a[x] += 1
        for x in b:
            freq_b[x] += 1

        cnt_a = [0] * (n + 1)
        cnt_b = [0] * (n + 1)

        for d in range(1, n + 1):
            for m in range(d, n + 1, d):
                cnt_a[d] += freq_a[m]
                cnt_b[d] += freq_b[m]

        exact = [0] * (n + 1)

        for d in range(n, 0, -1):
            cur = cnt_a[d] * cnt_b[d]
            for m in range(d * 2, n + 1, d):
                cur -= exact[m]
            exact[d] = cur

        total = 0
        for p in range(2, n + 1):
            if is_prime[p]:
                total += exact[p]

        ans.append(str(total))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```コードの最初の部分では、テスト ケースに出現する最大値に対してふるいを 1 回作成します。 このふるいを再利用すると、プライムチェックを繰り返す必要がなくなります。 

各テスト ケースについて、頻度配列には正確な値の出現が格納されます。 除数にわたる 2 つのネストされたループは、それらの正確な周波数を倍数のカウントに変換します。 倍数にわたるループでは、制限された値の範囲が使用され、高調波系列に複雑さが与えられます。 

下降ループは包含ステップです。 加工時`d`、 毎`exact[m]`のために`m`の倍数より大きいこと`d`はすでにわかっているため、これらの値を減算すると、次と等しい gcd 値のみが残ります。`d`。 

答えは、Python で 64 ビット整数を自動的に使用します。 これは、注文したペアの数が次の数に達する可能性があるため必要です。`n²`。
