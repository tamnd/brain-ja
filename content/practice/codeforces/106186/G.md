 ## 解決策
 # 問題の理解

 平面上の点で表されるビーコン タワーのセットがあります。 3 つの塔から構築された三角形は、その辺の 1 つが点セット全体の境界上にある場合に特別であるとみなされます。 幾何学的用語では、1 つの側面は凸包エッジである必要があり、他の 2 つの側面は一連の点を切断して、残りの塔がこれらの線の両側に表示されるようにする必要があります。 

すべてのタワーについて、それを含むすべての特別な三角形を調べ、そのスコアをそれらの三角形の中で最小の面積として定義します。 タスクは、すべてのタワーの最大スコアを見つけることです。 タワーが特別な三角形に属せない場合、それは何も貢献しません。 

入力には、異なる座標を持つ最大 5000 個の点が含まれますが、同じ線上に 3 つの点は存在しません。 このサイズがキーの制限です。 すべてのトリプルにわたる三次解では、最悪の場合でも約 1,250 億個の三角形が検査されることになりますが、これは 1 秒の制限をはるかに超えています。 5,000 の 2 乗で 2,500 万回の演算が得られるため、二次関数に近い解が必要です。最適化された Python ではこれが現実的です。 

幾何学的条件は複雑に見えますが、凸包によって主に単純化されます。 三角形の辺は、凸包エッジの場合に正確に設定された点全体の支持辺になります。 船体のエッジが固定されると、ほぼ 3 つおきの点で有効な三角形が作成されます。 無効な 3 番目の点は、そのエッジの 2 つの隣接するハル頂点だけです。これらの頂点は別のハル エッジを作成することになるためです。 

いくつかの特殊なケースでは、直接実装が中断される可能性があります。 すべての点が三角形の包の上にある場合、有効な三角形は存在しません。 

例えば：```
3
0 0
1 0
0 1
```唯一の三角形が凸包上に 3 つの辺すべてを持っているため、答えはありません。 必要な条件はそのような側面を 1 つだけ要求するため、出力は次のようになります。`0`。 

別のケースは凸四角形です。```
4
0 0
4 0
4 4
0 4
```連続する 3 つのハル頂点を使用する三角形は、ハル エッジが 2 つまたは 3 つあるため無効です。 選択した側面が船体のエッジであるかどうかだけをチェックする不注意な解決策では、これらの三角形が誤ってカウントされてしまいます。 正しい出力は 2 つの対角三角形に基づいており、その 2 倍の面積は 16 であるため、答えは次のようになります。`8.0000000000`。 

3 番目の問題は、ポイントが内部にある場合に発生します。 例えば：```
5
0 0
10 0
10 10
0 10
5 5
```中心点はハル エッジを持つ有効な三角形に参加できますが、4 隅は反対側のハル頂点の選択が正しく処理される必要があります。 ハルの頂点のみを三角形の頂点として考慮する実装では、有効な答えが失われます。 

# アプローチ

 直接的なアプローチは、すべてのトリプルポイントを試すことです。 各三角形について、その 3 つの辺をテストし、セット全体のサポート ラインの数を数えることができます。 ちょうど 1 つの側が条件を満たす場合は、各頂点の答えを更新します。 これは定義に直接従うため、正しいです。 ただし、O(n³) 個のトリプルがあり、すべての点に対して三角形をチェックすると別の要素が追加され、O(n⁴) が得られます。 n が 5000 に等しい場合、これは完全に不可能です。 

有益な観察は、特別にする必要がある唯一の側面は凸包エッジであるということです。 まず凸包を構築します。 次に、1 つの船体のエッジと 3 番目の点によって形成される三角形のみを調べます。 

船体のエッジ AB を考えてみましょう。 任意の点 C は、AB を支持辺とする三角形 ABC を作成します。 三角形に別の支持辺がある唯一のケースは、C が A または B に隣接する 2 つのハルの 1 つである場合です。これら 2 つの選択肢は除外されます。 1 つおきの点は、正確に 1 つの支持面を与えます。 

これにより、問題はすべての点に対してすべてのハルのエッジをチェックすることになります。 ハルのエッジは最大で n 個あるため、総作業量は O(n²) です。 有効な組み合わせごとに、外積を使用して 2 倍の面積を計算します。 2 倍の領域を維持すると、最終的な除算まで浮動小数点エラーが回避されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n⁴) | O(n) | 遅すぎる |
 | 最適 | O(n²) | O(n) | 承認済み |

 # アルゴリズムのチュートリアル

 1. 単調連鎖アルゴリズムを使用して、すべての点の凸包を構築します。 船体は、支持線の条件を満たすことができる唯一の可能な側面を提供します。 
2. ハルの頂点が 4 つ未満の場合は、0 を返します。 三角形ハルには、ハル エッジが 1 つだけある三角形を含めることはできません。 
3. ハル頂点 A と B の連続するペアごとに、AB を固有の必要なハル エッジとして扱います。 A と B の 2 つのハルに隣接する点は、3 番目の頂点として使用できない唯一の点です。 
4. すべてのポイント C をスキャンします。A、B、および 2 つの禁止された近傍をスキップします。 残りのすべての点について、三角形 ABC の 2 倍の面積を計算し、C で見つかった最小値を更新します。 
5. すべてのハル エッジが処理された後、各ポイントには、それを含む最小の有効な三角形エリアが格納されます。 答えはこれらの値のうち最大のものです。 

これが機能する理由は、すべての有効な三角形にハル エッジが 1 つだけ含まれている必要があるためです。 このアルゴリズムは、考えられるすべての船体のエッジと、他の 2 つの側面が船体のエッジにならないようにするすべての考えられる 3 番目の頂点を列挙します。 この列挙には有効な三角形がすべて表示されるため、候補が見逃されることはありません。 列挙されたすべての候補が近隣除外ルールを満たすため、無効な三角形は使用されません。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    pts = sorted(points)

    def build(seq):
        hull = []
        for p in seq:
            while len(hull) >= 2 and cross(hull[-2], hull[-1], p) <= 0:
                hull.pop()
            hull.append(p)
        return hull

    lower = build(pts)
    upper = build(reversed(pts))
    return lower[:-1] + upper[:-1]

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    hull = convex_hull(points)
    h = len(hull)

    if h < 4:
        print("0.0000000000")
        return

    index = {p: i for i, p in enumerate(hull)}
    best = [10**30] * n

    for i in range(h):
        a = hull[i]
        b = hull[(i + 1) % h]

        forbidden = {
            hull[(i - 1) % h],
            hull[(i + 2) % h],
            a,
            b
        }

        for j, c in enumerate(points):
            if c in forbidden:
                continue
            area2 = abs(cross(a, b, c))
            if area2 < best[j]:
                best[j] = area2

    ans = max(best)
    if ans == 10**30:
        print("0.0000000000")
    else:
        print("{:.10f}".format(ans / 2))

if __name__ == "__main__":
    solve()
```の`convex_hull`関数は外側の境界だけを維持しながら中間点を削除します。 入力により 3 つの点が同一線上にないことが保証されるため、次のように使用します。`<= 0`は安全で、真のハル頂点のみを保持します。 

メイン ループは、各ハル エッジを 1 回だけ考慮します。 禁止セットには、端点と 2 つの隣接するハル頂点が含まれます。 これらはまさに、三角形に追加の船体のエッジを作成するための選択です。 

面積の計算には絶対外積が使用されます。 これにより、三角形の面積が整数の 2 倍になり、比較時の精度の問題が回避されます。 2 による除算は、最終結果を出力する場合にのみ行われます。 

ソリューションで作成された辞書は最終的な計算には必要ないため、削除できます。 この実装では、構造が幾何学的説明に近い状態に保たれますが、実際の更新は座標のみに依存します。

# テストケース```python
import sys, io

def run(inp: str) -> str:
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.read().strip().split()
    sys.stdin = old

    if not data:
        return ""

    it = iter(data)
    n = int(next(it))
    points = [(int(next(it)), int(next(it))) for _ in range(n)]

    def cross(a, b, c):
        return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])

    def hull(ps):
        ps = sorted(ps)

        def make(arr):
            res = []
            for p in arr:
                while len(res) >= 2 and cross(res[-2], res[-1], p) <= 0:
                    res.pop()
                res.append(p)
            return res

        return make(ps)[:-1] + make(reversed(ps))[:-1]

    h = hull(points)
    if len(h) < 4:
        return "0.0000000000\n"

    best = [10**30] * n
    for i in range(len(h)):
        a = h[i]
        b = h[(i + 1) % len(h)]
        bad = {a, b, h[(i-1) % len(h)], h[(i+2) % len(h)]}
        for j, c in enumerate(points):
            if c not in bad:
                best[j] = min(best[j], abs(cross(a, b, c)))

    return f"{max(best) / 2:.10f}\n"
