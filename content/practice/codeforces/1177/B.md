 ## 解決策
 ## 問題の理解

 すべての正の整数を区切り文字なしで連続して記述することで形成される無限の文字列「1234567891011121314…」を考慮するように求められます。 立場を与えられて$k$、どの桁がその場所を占めるかを判断する必要があります。 入力は単一の整数です$k$まで$10^{12}$、出力は対応する数字になります。 

最初の観察は、シーケンスが数値の長さによって暗黙的に構造化されていることです。 1 桁の数字は 1 から 9 の位置を占めます。2 桁の数字は 10 から 189 の位置を占め、3 桁の数字は 190 から 2889 の位置を占めます。 この桁の長さによる階層化は効率化のために不可欠です。 以下までの文字列を構築する素朴なアプローチ$k$までの保管が必要になります$10^{12}$これはメモリ内で実行不可能であり、妥当な時間内に生成するには遅すぎます。 

重要なエッジケースは、桁の長さの境界付近で発生します。 たとえば、次の場合$k = 10$、その数字は最初の 2 桁の数字「10」に属します。 長さグループを考慮せずに桁を数える単純な実装では、数え間違えて間違った桁を選択する可能性があります。 

別の微妙なケースが発生する場合$k$たとえば、長さグループの最後の桁に正確に着地します。$k = 9$または$k = 189$。 これらの位置は、1 桁または 2 桁の数字の最後の桁に対応します。 境界を慎重に処理すると、off-by-one エラーが防止されます。 

## アプローチ

 ブルート フォースのアプローチは簡単です。1 から開始して、合計の長さに達するまで各数値を文字列として追加します。$k$。 その後、$k$-番目の文字。 これは正しいです。文字通りシーケンスをシミュレートしているからです。 問題はパフォーマンスに発生します。 のために$k$近く$10^{12}$、数字を 1 つずつ生成するには、少なくとも$10^{12}$1 秒の制限時間の実用的な制限をはるかに超えた操作。 

最適なソリューションを実現するための重要な洞察は、シーケンスが同じ桁長の数字のブロックで構造化されていることです。 数字と$d$数字は連続した長さのブロックを占めます$d \times 9 \times 10^{d-1}$。 これらのブロックの長さを累積的に計算することで、どのブロックに$k$- 番目の桁はシーケンス全体を生成せずに実行されます。 ブロックが識別されると、整数の除算とモジュロ演算により、その数値内の正確な数値と桁が特定されます。 これにより、線形の問題が軽減されます。$k$桁の長さの数が対数になるため、これは許容されます。$k$まで$10^{12}$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(k) | O(k) | 遅すぎる |
 | 最適 | O(log k) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 桁長カウンタを初期化する`d = 1`この長さの開始番号`start = 1`。 累積長カウンタを初期化する`count = 0`これまでに処理された合計桁数を追跡します。 
2. 現在のブロックの長さを計算します。`d`-桁数として`block_len = 9 * 10^(d-1) * d`。 追加する場合`block_len`に`count`保つ`count < k`、増分`d`そして更新します`count += block_len`。 を含むブロックまで繰り返します。`k`が見つかりました。 
3. 桁の長さが正しくなったら`d`が見つかったら、オフセットを計算します`k`ブロック内:`offset = k - count - 1`。 の`-1`位置をブロック内のゼロベースのインデックスに変換します。 
4. 整数除算を使用して、ブロック内のどの番号に目的の数字が含まれているかを判断します。`number_index = offset // d`。 実際の数値は`number = 10^(d-1) + number_index`。 
5. モジュロを使用して、この数値内のどの桁がターゲットであるかを決定します。`digit_index = offset % d`。 数値を文字列に変換し、インデックスを作成することで、数字を抽出します。`str(number)[digit_index]`。 
6. 数字を答えとして出力します。 

なぜ機能するのか: 各ステップで、次の不変条件を維持します。`count`すべての小さなブロックでカバーされる合計桁数を追跡します。 ブロック長を特定することで`d`含まれている`k`そして、整数の除算とモジュロを使用して、グローバルな位置を正確にマッピングします。`k`数値とその数値内の数字に変換します。 各ブロック内の数値は連続しており、サイズが均一であるため、あいまいさはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

k = int(input())

d = 1
count = 0

while True:
    block_len = 9 * (10 ** (d - 1)) * d
    if count + block_len >= k:
        break
    count += block_len
    d += 1

offset = k - count - 1
number_index = offset // d
digit_index = offset % d
number = 10 ** (d - 1) + number_index
print(str(number)[digit_index])
```コードはアルゴリズムに正確に従います。 の`while`ループは累積して正しい桁長のブロックを検索します。`count`。 ゼロベースのインデックス付け`offset = k - count - 1`整数の除算と剰余で数値と桁が正しく特定されるようにします。 数値は最大 12 桁であるため、文字列への変換は安全です (`k ≤ 10^12`) Python の整数に快適に適合します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    k = int(input())
    d = 1
    count = 0
    while True:
        block_len = 9 * (10 ** (d - 1)) * d
        if count + block_len >= k:
            break
        count += block_len
        d += 1
    offset = k - count - 1
    number_index = offset // d
    digit_index = offset % d
    number = 10 ** (d - 1) + number_index
    return str(number)[digit_index]
