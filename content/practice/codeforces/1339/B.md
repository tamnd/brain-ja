[CF 1339B - 隣接する差異の並べ替え](https://codeforces.com/problemset/problem/1339/B)

 **評価:** 1200
 **タグ:** 建設的アルゴリズム、並べ替え
 **解決時間:** 3 分 50 秒
 **確認済み:** いいえ

 ## 解決策
 ## 問題の理解

 いくつかの独立した配列が与えられており、それぞれの配列の要素を、左から右に移動しても隣接する要素間の絶対差が減少しないシーケンスに並べ替える必要があります。 言い換えれば、行に数字を配置し始めると、連続する数字の間のギャップは減少しないシーケンスを形成する必要があります。 

出力は、元の構造を保存するものではありません。 配列を任意に並べ替えることができ、隣接する差分に関するこの単調性条件を満たす有効な順序付けを 1 つ生成するだけで済みます。 

すべてのテスト ケースにわたる合計入力サイズに対する制約は、テスト ケースごとに線形以上または線形に近いソリューションは失敗することを意味します。 すべての順列を試したり、すべてのスワップのペアを繰り返しチェックしたりする単純な試みは、組み合わせまたは二次関数的に爆発的に発生します。 目的のソリューションでは、各配列をテスト ケースごとに O(n log n) または O(n) で処理する必要があります。 

局所構造から欲張って考えると微妙な故障モードが現れます。 最後に選択した要素に最も近い利用可能な数値を繰り返し追加してシーケンスを構築しようとすると、最初の小さな差によって後の大きなジャンプが強制され、単調性が崩れるという構成に簡単に陥る可能性があります。 たとえば、中間の値から開始して外側に向かって貪欲に拡張すると、後で近くに未使用の要素が残ったときにギャップが減少する可能性があります。 これは、ローカルの貪欲な隣接関係が信頼できないことを示しています。 この構造は世界的に適用する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、配列のすべての順列を試し、候補の順序付けが非減少隣接差分プロパティを満たすかどうかをチェックします。 単一の順列をチェックするだけでも O(n) のコストがかかり、n 個あります。 これは、n が約 10 の場合でも完全に実行不可能になります。 

2 番目の単純なアイデアは、シーケンスを生成し、条件を維持する位置に要素を繰り返し挿入することです。 ただし、各挿入では、差分の単調性を検証するためにシーケンス全体をスキャンする必要があり、以前の決定によって将来の挿入が無効にならないという保証はありません。 これにより、テスト ケースごとの動作が O(n²) 以上悪化します。 

重要な観察は、実際には差異の値を独立して制御しようとしているわけではないということです。 代わりに、中央値から外側に向かってシーケンスを構築することで、非常に構造化された差のパターンを強制できます。 配列を並べ替えると、当然のことながら、値が互いに近い場合は小さな差が生じますが、値が離れている場合は大きな差が生じます。 要素を中心から外側にインターリーブすると、初期の差は小さく、中央領域から遠ざかるにつれて後の差は大きくなります。 

標準的な構造では、配列をソートし、開始点として中央の要素を選択し、ソートされた順序の右側と左側に交互に拡張します。 これにより、最初に中央値付近の密なクラスター内を移動し、後で極値を導入するシーケンスが生成されます。これにより、絶対的な差が減少しないことが保証されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | お(ん!) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 配列を非降順で並べ替えます。 これにより、インデックスの近さが値の近さに対応するように値が整理されます。 差異の構造はインデックスの動きによって制御されます。 
2. ソートされた配列の中心近くの開始点を選択します。 両端までの初期距離が最小限に抑えられるため、中間のインデックスを選択するのが便利です。 
3. ソートされた配列内で右方向と左方向を交互に、この中心から外側に拡張して結果シーケンスを構築します。 これにより、増大する価値のギャップをバランスよく調査することができます。 
4. 選択した各要素を、参照した順序で結果に追加します。 最初の数ステップは狭い数値範囲内にとどまるため、差異は小さいままです。 
5. すべての要素が使用されるまで続行し、ソート順で中心から遠い要素がシーケンスの後半にのみ導入されるようにします。 

### なぜ効果があるのか

 この構造では、初期の隣接する差分がソート順で近い、したがって絶対値が小さい要素から得られることが保証されます。 トラバーサルが外側に拡大するにつれて、新しく導入されたすべての要素はソートされた順序で前の領域からさらに遠くに配置され、ギャップの大きさを維持または増加させることしかできません。 外側に移動した後、以前にスキップされた極値に戻ることは決してないので、必要な単調性を強制する、大きな差の後に小さな差を導入することを避けます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        l = (n - 1) // 2
        r = l + 1

        res = [a[l]]
        toggle = True

        while l > 0 or r < n:
            if toggle:
                if r < n:
                    res.append(a[r])
                    r += 1
                else:
                    l -= 1
                    res.append(a[l])
            else:
                if l > 0:
                    l -= 1
                    res.append(a[l])
                else:
                    res.append(a[r])
                    r += 1
            toggle = not toggle

        print(*res)

if __name__ == "__main__":
    solve()
```コードは、数値的な近さが構造的な隣接になるように各テスト ケースの配列を並べ替えることから開始します。 次に、中央のインデックスを選択し、交互の方向に外側に拡張します。 ポインタを交互に動かすことで、同じ極端な側から繰り返し値を取得することがなくなり、大きなジャンプの後に小さな差が生じる危険があります。 

重要な実装の詳細は、いずれかのポインタが配列の終端に到達したときの境界の慎重な処理です。 その時点で、アルゴリズムは残りの方向にのみ続行されます。 

## 実用的な例

 ### 例 1

 入力配列:`[5, -2, 4, 8, 6, 5]`ソートされた配列は次のようになります。`[-2, 4, 5, 5, 6, 8]`中間付近のインデックス 2 または 3 (0 から始まるインデックス) から開始します。 インデックス 2 を中心として使用:

 | ステップ | 左のインデックス | 右インデックス | 選ばれた | 結果 |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | 3 | 5 | [5] |
 | 2 | 2 | 4 | 5 | [5、5] |
 | 3 | 1 | 4 | 4 | [5、5、4] |
 | 4 | 1 | 5 | 6 | [5、5、4、6] |
 | 5 | 0 | 5 | -2 | [5、5、4、6、-2] |
 | 6 | 0 | 6 (終了) | 8 | [5、5、4、6、-2、8] |

 差は 0、1、2、8、10 であり、減少しません。 

このトレースは、小さな局所的な差が最初に密集した中間領域内で作成され、極値は後でのみ表示され、より大きなジャンプを生成する様子を示しています。 

### 例 2

 入力配列:`[8, 1, 4, 2]`ソートされた配列:`[1, 2, 4, 8]`インデックス 1 (値 2) から開始します。 

| ステップ | 左のインデックス | 右インデックス | 選ばれた | 結果 |
 | --- | --- | --- | --- | --- |
 | 1 | 1 | 2 | 2 | [2] |
 | 2 | 1 | 3 | 4 | [2、4] |
 | 3 | 0 | 3 | 1 | [2、4、1] |
 | 4 | 0 | 4 (終了) | 8 | [2、4、1、8] |

 差は２、３、３で減りません。 

この例は、交互に行うことで、極端な値の間をすぐに飛び移るのではなく、中心から外側に向かって徐々に拡張する方法を示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | 各テスト ケースでは並べ替えが優先されますが、構築は直線的です。 
| スペース | O(n) | ソートされた配列を保存し、順列を出力します。 

すべてのテスト ケースの n の合計は最大 10^5 であるため、各テスト ケースを個別に並べ替えても時間制限内に問題なく収まります。 線形再構成ステップにより、ソート以外の追加のオーバーヘッドが発生しません。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out_lines = []
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        a.sort()

        l = (n - 1) // 2
        r = l + 1

        res = [a[l]]
        toggle = True

        while l > 0 or r < n:
            if toggle:
                if r < n:
                    res.append(a[r]); r += 1
                else:
                    l -= 1; res.append(a[l])
            else:
                if l > 0:
                    l -= 1; res.append(a[l])
                else:
                    res.append(a[r]); r += 1
            toggle = not toggle

        out_lines.append(" ".join(map(str, res)))

    return "\n".join(out_lines)
