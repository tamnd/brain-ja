 ## 解決策
 ## 問題の理解

 ポリュカルプは、傭兵の集団から一部の傭兵を選択したいと考えています。`n`個人。 各傭兵には 2 つの制約があります。1 つは参加したいチームの最小サイズと最大サイズで、次の式で与えられます。`l_i`そして`r_i`。 さらに、傭兵の一部のペアはお互いを嫌っており、同じサブセットに一緒に登場することはできません。 タスクは、これらの傭兵ごとのサイズ制約を満たし、競合するペアを含まない空でないサブセットをすべてカウントすることです。 

入力は傭兵の数で構成されます`n`そしてヘイトペアの数`m`。 それぞれの傭兵に与えられるのは、`l_i`そして`r_i`そして、対立する傭兵のペアごとに、インデックスが与えられます。 出力は有効な空でないサブセットの数を法的に表したものです。`998244353`。 

制約は微妙です。`n`最大 300,000 になる可能性があり、すべてのサブセットを単純に列挙するアルゴリズムは除外されます。`2^n`操作。 ただし、ヘイトペアの数は`m`は最大でも 20 であり、非常に小さいです。 これは、傭兵の制約のほとんどは効率的に処理する必要がある一方で、紛争には指数関数的な手法を使用して対処できることを示唆しています。`m`制限時間を超えずに。 

エッジケースは単純な解決策を騙す可能性があります。 たとえば、すべての傭兵が`l_i = 1`そして`r_i = n`、矛盾がない場合、答えは次のようになります。`2^n - 1`。 不注意なアプローチでは、空のサブセットの除外を忘れたり、重複する境界を誤って処理したりする可能性があります。 すべての紛争に同じ傭兵が関与している場合、別の厄介なケースが発生します。 ヘイトペアに対する包含と除外では、サブセットを二重にカウントしてはなりません。 

## アプローチ

 ブルートフォースアプローチでは、空ではない傭兵のサブセットをすべて列挙します。 各サブセットについて、そのサイズが次の範囲内にあるかどうかを確認します。`[l_i, r_i]`サブセット内のすべての傭兵について、競合するペアがサブセットに含まれていないことを確認します。 これは、問題の定義が小規模な組み合わせであるため機能しますが、`n = 3*10^5`、すべてを列挙するので、これは明らかに実行不可能です`2^n`サブセットには以上が必要になります`10^90`操作。 

最適なアプローチは 2 つの重要な観察を活用します。 まず、ヘイト ペアは最大 20 個であるため、競合する傭兵を含む有効なサブセットは包含-除外を使用してカウントできます。 次に、サイズのサブセットの数を事前に計算できます。`k`プレフィックスの組み合わせの合計を使用して、すべての傭兵のサイズ制限を満たすもの。 これら 2 つの観察を組み合わせることで、すべてのサブセットを明示的に列挙することなく、すべての傭兵の境界を満たすサブセットを効率的に数え、競合を調整することができます。 具体的には、競合する傭兵のすべてのサブセット (最大で`2^m`可能性)、包含/除外を使用して、少なくとも 1 つの競合するペアを含む有効なサブセットの数を調整します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | 最適 | O(n + 2^m * n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. まず、考えられるサブセット サイズごとに傭兵を並べ替えるか、カウントするために前処理します。`k`、サイズのサブセットがいくつあるか`k`あらゆる傭兵の限界を満たす`[l_i, r_i]`。 これは、各傭兵のサイズの有効範囲をマークするプレフィックス合計または差分配列を使用して効率的に行うことができます。 
2. 傭兵のインデックスを使用して各ヘイト ペアを表します。 すべて生成`2^m`ヘイトペアのサブセット。 ヘイトペアのサブセットごとに、そのサブセットに含まれる傭兵のセットを計算し、これらの傭兵をすべて含み、サイズ制約を満たす傭兵のサブセットの数を数えます。 
3. これらのヘイトペアのサブセットに対して包含/除外を使用します。 サブセットに含まれる場合`t`ヘイトペア、その貢献度は`(-1)^t`関与するすべての傭兵を含む有効なスーパーセットの数の倍。 これにより、競合制約に違反するサブセットが適切に減算されることが保証されます。 
4. 包含-除外からのすべての寄与を合計し、結果を剰余として取得します。`998244353`。 これにより、有効な空でないサブセットの数が得られます。 

機能する理由: すべてのステップで、サイズ制約を満たすサブセットを正しく考慮するという不変条件を維持します。 包含-除外により、競合を含むサブセットが二重にカウントされたり見逃されたりすることがなくなります。これは、競合を含む各サブセットが、打ち消すのに正確な数の包含-除外用語に現れるためです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
MOD = 998244353

def solve():
    n, m = map(int, input().split())
    l, r = [], []
    for _ in range(n):
        li, ri = map(int, input().split())
        l.append(li)
        r.append(ri)

    hate = []
    for _ in range(m):
        a, b = map(int, input().split())
        hate.append((a-1, b-1))

    # Precompute factorials and inverses for nCr
    fact = [1] * (n + 1)
    inv_fact = [1] * (n + 1)
    for i in range(1, n+1):
        fact[i] = fact[i-1] * i % MOD
    inv_fact[n] = pow(fact[n], MOD-2, MOD)
    for i in range(n-1, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

    def comb(a, b):
        if b < 0 or b > a:
            return 0
        return fact[a] * inv_fact[b] % MOD * inv_fact[a-b] % MOD

    # Compute number of subsets of size k satisfying bounds
    valid_sizes = [0]*(n+2)
    for i in range(n):
        valid_sizes[l[i]] += 1
        if r[i]+1 <= n:
            valid_sizes[r[i]+1] -= 1
    for i in range(1, n+1):
        valid_sizes[i] += valid_sizes[i-1]

    # Count total valid subsets by size
    total = 0
    for size in range(1, n+1):
        if valid_sizes[size] == n:
            total = (total + comb(n, size)) % MOD

    # Inclusion-Exclusion over hate pairs
    from itertools import combinations
    for mask in range(1, 1 << m):
        bits = []
        involved = set()
        for j in range(m):
            if mask & (1 << j):
                involved.add(hate[j][0])
                involved.add(hate[j][1])
        k = len(involved)
        if k > n:
            continue
        ways = 0
        # Count subsets including all involved mercenaries
        for size in range(k, n+1):
            if valid_sizes[size] == n:
                ways = (ways + comb(n - k, size - k)) % MOD
        if bin(mask).count('1') % 2:
            total = (total - ways) % MOD
        else:
            total = (total + ways) % MOD

    print(total % MOD)

solve()
```コードは、入力を読み取り、傭兵の境界とヘイトのペアの配列を構築することから始まります。 階乗と逆モジュラーは事前に計算されており、高速な組み合わせ計算が可能です。 の`valid_sizes`配列は、サブセット サイズごとに、すべての傭兵がそのサイズを許可するかどうかをマークします。 包含と除外はヘイト ペアのすべてのサブセットに対して反復され、関与するすべての傭兵が含まれるサブセットの数を数え、それに応じて合計を調整します。 境界条件は、モジュラー演算と適切なサブセット サイズチェックを使用して慎重に処理されます。

 | 傭兵 | l_i | r_i | valid_sizes への貢献 |
