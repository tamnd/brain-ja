 ## 解決策
 ## 問題の理解

 この問題により、次のような無向グラフが得られます。$n$ノードと$m$結果として得られるサボテンにはブリッジがないという条件で、同じ数のノードとエッジを持つ「サボテン」グラフを構築するように求められます。 サボテンは、すべてのエッジが最大 1 つの単純なサイクルに属するグラフです。 言い換えれば、すべてのサイクルは分離されており、任意の 2 つのサイクルは最大 1 つの頂点を共有します。 ブリッジはエッジであり、その削除により接続されるコンポーネントの数が増加します。 すべてのエッジが何らかのサイクルの一部であるため、橋が存在しないサボテンを作成する必要があります。 

入力は 2 つの整数を提供します$n$そして$m$、ノードとエッジの数を表します。 出力は、制約を満たす構築されたサボテンのエッジのリストである必要があります。 サボテンのプロパティとブリッジなしの条件を超えると、特定の頂点ラベルやサイクルは必要ありません。 

制約により許可されるのは、$n$まで$10^5$そして$m$まで$2 \cdot 10^5$。 これは、ノードのすべてのペアを反復したり、すべてのスパニング ツリーを試行したりするソリューションは実行不可能であることを意味します。 次の点に関する線形または線形に近いアプローチ$n + m$が必要です。 

微妙なエッジケースが発生する場合$m < n$、ノードよりもエッジの少ない接続されたグラフには少なくとも 1 つのツリー エッジが必要なため、ブリッジを避けることは不可能です。 例えば、$n=4, m=3$木が必要であり、それには必ず橋が必要です。 不注意な実装では、各エッジのサイクルをやみくもに生成しようとし、切断されたグラフや無効なグラフが生成される可能性があります。 

もう 1 つのエッジケースは次のような場合です$m$まさに$n$これにより、すべてのノードをカバーする最も単純なサイクルが可能になります。 同様に、$m$非常に大きい（近づいている）$2n$)、ブリッジを導入せずにノードを共有する複数の小さなサイクルを作成する必要があります。 これらには、重複するサイクルを慎重に構築する必要があります。 

## アプローチ

 ブルートフォースアプローチは、サイクルとエッジのすべての組み合わせを試すことです。 各エッジについて、追加によってサボテンのプロパティが維持され、ブリッジが回避されるかどうかを確認します。 これが機能するのは、サボテンの定義がローカルであるためです。各エッジは最大 1 つのサイクルに属している必要があります。 ただし、このアプローチには次のことが必要です$O(\binom{n}{2})$最悪のケースでノードの各ペア間にエッジを追加するかどうかをチェックします。$5 \cdot 10^9$操作時の操作$n=10^5$が遅すぎます。 

重要な観察は、橋のないサボテンは体系的に構築できるということです。 少なくとも 3 つのノードからなる単純なサイクルにはブリッジが含まれません。 頂点を共有することでそのようなサイクルを連鎖させれば、橋を作ることなくより大きなサボテンを生み出すことができます。 また、エッジの総数は最大で$2n - 2$橋のないサボテンの中。 もし$m > 2n - 2$、建設は不可能です。 それ以外の場合は、単純な長さのサイクルから始めることができます。$n$次に、ノード間にコードを追加して到達します。$m$同じエッジを共有する複数のサイクルを慎重に避けてください。 

最適な構造には、スターアンドサイクルハイブリッドアプローチが使用されます。 中央ノード (ノード 1) がノード 2 に接続されていることから開始し、$n$。 これにより接続が確保されます。 次に、非中心ノード間にエッジを追加して、到達するまで繰り返しサイクルを形成します。$m$エッジ。 これが機能するのは、新しいエッジごとに新しいサイクルが 1 つだけ追加され、既存のエッジはサイクルの一部であるためブリッジにならないためです。

 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.次のことを確認します$m < n$または$m > 2n - 2$。 いずれかの条件が true の場合は、-1 を出力するか失敗します。接続されたブリッジのないサボテンには少なくとも$n$エッジとせいぜい$2n - 2$エッジ。 
2. 単純な長さのサイクルでグラフを初期化します。$n$: ノード 1 を 2、2 を 3、...、に接続します。$n-1$に$n$、 そして$n$1 に戻ります。これにより、$n$すべてのエッジがサイクルに属しているため、ブリッジがないことを保証します。 
3. 余分なエッジを追加するためのカウンターを保持します。 現在のエッジの数が$m$、ノードのすべてのペア (i, j) を反復処理します。$i < j$、すでに存在するエッジをスキップします。 
4. 候補エッジごとに、それをエッジ リストに追加します。 追加されたすべてのエッジは、既存のサイクル内の 2 つのノードを接続することによって、新しい単純なサイクルを作成します。 合計に達したらエッジの追加を停止します$m$。 すべてのエッジは少なくとも 1 つのサイクルの一部であるため、エッジはブリッジにはなりません。 
5. エッジリストを出力します。 

機能する理由: 最初のサイクルでは、ブリッジなしで完全な接続が保証されます。 新しいエッジはそれぞれ 1 つの追加サイクルを作成し、既存のサイクルを削除せず、ブリッジなしのプロパティを維持します。 不変条件は、グラフ内のすべてのエッジが各ステップで少なくとも 1 つのサイクルに属することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    if m < n or m > 2 * n - 2:
        print(-1)
        return
    
    edges = []
    # Step 2: create initial cycle
    for i in range(1, n):
        edges.append((i, i + 1))
    edges.append((n, 1))  # close the cycle
    
    extra_edges = m - n
    # Step 3: add extra edges between non-adjacent nodes
    for i in range(1, n + 1):
        for j in range(i + 2, n + 1):
            if i == 1 and j == n:
                continue  # skip edge that closes the main cycle again
            if extra_edges == 0:
                break
            edges.append((i, j))
            extra_edges -= 1
        if extra_edges == 0:
            break
    
    # Output
    for u, v in edges:
        print(u, v)

t = int(input())
for _ in range(t):
    solve()
```各セクションは、アルゴリズムのウォークスルーのステップに直接対応しています。 主な微妙な点は、重複サイクルが作成される 1 から n へのエッジを 2 回回避することです。 ネストされたループにより、サボテンのプロパティを壊すことなく体系的にコードを埋めていくことができます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 入れ子になったループ内に最初のサイクルを O(n) で生成し、最大でも O(m) 個の追加エッジを生成します。 
| スペース | O(n + m) | すべてのエッジを明示的に保存します。 

これは制約に適合します$n \le 10^5$、$m \le 2 \cdot 10^5$。 十分なエッジが追加されると中断されるため、ネストされたループは O(m) 反復を超えることはありません。
