 ## 解決策
 ## 問題の理解

 最大 20 個の頂点を持つ無向接続グラフが与えられます。 各頂点はサーバーを表し、エッジは直接の双方向通信リンクを表します。 

サーバーごとに$u$、隣接する頂点を 1 つだけ選択する必要があります$a(u)$。 これは、各ノードに隣接するノードの 1 つに 1 つの出力ポインタを割り当てると考えると、システム全体が、すべてのノードの出次数が正確に 1 になる有向グラフになります。 

ルーティングは再帰的に機能します。$u$に$v$、ノード$u$最初に直接接続されているかどうかを確認します$v$。 そうでない場合は、リクエストを委任します。$a(u)$、同じ手順が繰り返されます。 生成されるパスは、選択された補助エッジのチェーンと、その後に続く最後の直接エッジです。$v$。 

要件は非常に強力です: すべての順序ペアに対して$(u, v)$、このプロセスは最終的に成功し、有効なパスが生成される必要があります。 

主な問題点は、選択したポインターが隣接する頂点に決して到達しないサイクルを作成した場合、プロセスが永久にループする可能性があることです。$v$。 したがって、次の割り当ては$a(u)$すべての宛先が一致するようにグラフをグローバルに構造化する必要があります。$v$この委任プロセスを通じて、あらゆる開始点から「表示」されます。 

制約$n \le 20$最も重要な信号です。 一般的な構造に対する多項式グラフ アルゴリズムではなく、サブセットまたはハミルトニアン構造に対する指数関数的状態手法を強く示唆しています。 みたいなもの$O(2^n n^2)$任意の関数を列挙したものは何でも受け入れられます$a(u)$直接的には、$n^n$、無理です。 

スパニング ツリーを構築してすべてのノードをその親にポイントしようとすると、微妙な障害モードが発生します。 これにより、ルート付きのツリー構造が生成されますが、ターゲットが異なるため、一般にルーティングは不可能になります。$v$すべてのルート パス上にあることが保証されていない祖先を必要とします。 小さな反例は、いくつかの頂点がある木です。$v$葉の唯一の隣接葉は別の枝の奥深くにあります。 無関係なノードの祖先チェーンは、その近隣ノードと出会うことはありません。 

実際の制約はグローバルであり、すべてのペアにわたって対称的であり、ソースごとに分解することはできません。 

## アプローチ

 生の定義から開始します。各ノードが近傍ノードを選択するため、無向基本グラフ上の関数グラフが得られます。 すべてのノードには出力エッジが 1 つだけあるため、この有向グラフの各接続コンポーネントには 1 つの有向サイクルがあり、すべてのノードが最終的にそのサイクルに流入します。 

開始ノードを修正すると$u$、ルーティング プロセスは、同じ機能コンポーネント内のノードのみを訪問します。$u$。 これは、複数のコンポーネントがある場合、あるコンポーネントのノードが委任を通じて別のコンポーネントのノードに到達することはできないことを意味します。 

ここで、問題が固定された目的地に必要なものを考えてみましょう。$v$。 すべての開始ノードから$u$、から始まる委任チェーン$u$最終的には直接隣接するノードに到達する必要があります。$v$。 これは、すべてのコンポーネントにすべての頂点の近傍が少なくとも 1 つ含まれている必要があることを意味します。$v$。 2 つの異なるコンポーネントがある場合は、頂点を選択します$v$その近傍はそのうちの 1 つに完全には存在しませんが、これは接続された単純なグラフ構造では避けられません。 すべての人にとって矛盾を避ける唯一の方法$v$同時に、グラフ全体を単一の機能コンポーネントに強制することになります。 

すべてのノードが出次数 1 を持ち、コンポーネントが 1 つだけある関数グラフは、すべての頂点をカバーする 1 つの有向サイクルで構成されなければなりません。 いずれかのノードがサイクルの外側にある場合、最終的にはサイクル内に流入し、2 番目のコンポーネント構造の矛盾が生じます。 したがって、構造はすべての頂点を含む単一のサイクルに崩壊します。 

これにより、明確な特徴付けが得られます。元のグラフにはハミルトニアン サイクルが必要です。 このようなサイクルが存在すると、それを一貫して方向づけて設定します。$a(u)$サイクル上の次の頂点に移動します。 次に、任意の開始ノードから繰り返し委任がサイクル全体を実行するため、クロージャ内ですべてのノードに到達可能になります。 すべての頂点にはグラフ内のどこかに少なくとも 1 つの近傍があるため、すべてのターゲットは$v$このクロージャ内に隣接するクロージャが存在し、成功が保証されます。 

したがって、問題は次のグラフでハミルトニアン サイクルを見つけることになります。$n \le 20$、これは古典的なビットマスク動的計画問題です。

 ## アルゴリズムのチュートリアル

 問題を、与えられたグラフ内でハミルトニアン サイクルを構築することに縮小します。 

1. 開始頂点を修正します。$0$。 すべての頂点を正確に 1 回訪問してから元に戻るサイクルを検索します。$0$。 これにより、単一のグローバル サイクル構造が確保されます。 
2. DP 状態を定義する$dp[mask][v]$つまり、正確に頂点を訪問したことになります。`mask`から始まりました$0$、現在は頂点で終了しています$v$。 入力グラフのエッジに沿った遷移のみを許可します。 
3.初期化$dp[1 \ll 0][0] = true$。 これは、頂点 0 から開始し、その頂点のみを訪問することを表します。 
4. 州ごとに$(mask, v)$、任意の近隣に拡張してみてください$to$の$v$まだ入っていない`mask`、設定$dp[mask \cup \{to\}][to] = true$。 また、パスを再構築するために親ポインターも保存します。 
5. DP を埋めた後、すべての頂点が訪問され、エンドポイントからエンドポイントに戻るエッジがある状態を探します。$0$。 そのような状態が存在する場合、ハミルトニアン サイクルを再構築します。 
6. そのような状態が存在しない場合は、「No」を出力します。 
7. それ以外の場合は、サイクル注文を受け取ります$c_0, c_1, \dots, c_{n-1}$、定義します$a(c_i) = c_{i+1}$、 と$a(c_{n-1}) = c_0$。 

これが機能する理由は、以前の構造還元に由来しています。有効な解はすべての頂点にわたる単一の有向サイクルを形成する必要があり、ハミルトニアン サイクルは有効な割り当てを生成します。 DP は考えられるすべてのサイクル構造にわたって完全であるため、そのようなサイクルがグラフ内に存在する場合に限り、そのようなサイクルを見つけます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
g = [[False]*n for _ in range(n)]

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)
    g[u][v] = g[v][u] = True

if n == 1:
    print("No")
    sys.exit()

N = 1 << n
dp = [[False]*n for _ in range(N)]
par = [[-1]*n for _ in range(N)]

start = 0
dp[1 << start][start] = True

for mask in range(N):
    if not (mask & (1 << start)):
        continue
    for v in range(n):
        if not dp[mask][v]:
            continue
        for to in adj[v]:
            if mask & (1 << to):
                continue
            nmask = mask | (1 << to)
            if not dp[nmask][to]:
                dp[nmask][to] = True
                par[nmask][to] = v

full = (1 << n) - 1
end = -1

for v in range(n):
    if dp[full][v] and g[v][start]:
        end = v
        break

if end == -1:
    print("No")
    sys.exit()

cycle = []
mask, v = full, end

while v != -1:
    cycle.append(v)
    pv = par[mask][v]
    mask ^= (1 << v)
    v = pv

cycle.reverse()

pos = [0]*n
for i, x in enumerate(cycle):
    pos[x] = i

a = [0]*n
for i in range(n):
    a[i] = cycle[(pos[i] + 1) % n] + 1

print("Yes")
print(*a)
```コードはまず、高速サイクル クロージャ チェックのために隣接構造とブール エッジ マトリックスを構築します。 DP は、ノード 0 から始まるすべてのハミルトニアン パスを列挙します。有効な完了が見つかると、親ポインターが完全なサイクルを再構築します。 

重要な点は、最後の終点が最初に戻るように強制的に接続し、すべての頂点をカバーする単なるパスではなく、真にサイクルを形成するようにすることです。 

サイクルが回復したら、そのサイクル内で後続の各頂点を割り当て、無向ハミルトニアン サイクルを必要な関数グラフに変換します。 

## 実用的な例

 ### 例 1

 入力:```

2 3
3 1
```これはもう三角形ですね。

| ステップ | マスク | エンドポイント |

 サイクルを再構築します`[0,1,2]`そしてポインタを割り当てます`0→1, 1→2, 2→0`。 

これにより、完全なサイクル グラフでは解決策が即座に得られることが確認されます。
