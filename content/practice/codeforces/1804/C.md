 ## 解決策
 ## 問題の理解

 ルーレットホイールがあります`n`～から番号が付けられたセクター`0`に`n-1`。 ホイールはセクターを指す矢印から始まります`x`ハンドルを整数の力で引くと回転させることができます`f`間`1`そして`p`。 スピンは次のように動作します。最初の 1 秒でスピンが進みます。`f`セクター、次の瞬間に`f-1`セクター、その後`f-2`、まで`1`。 その後の全体の動き`f`秒は最初の合計です`f`正の整数、つまり`f*(f+1)/2`。 セクターはモジュロでラップアラウンドします`n`。 目的は、整数が存在するかどうかを確認することです`f`から`1`に`p`スピン後、矢印がセクターを指すようにする`0`。 

制約が教えてくれる`n`まで行くことができます`10^5`そして`p`まで`10^9`。 すべてのテストケースをまとめると、`n`を超えない`2*10^5`。 あらゆる手段を試す強引なアプローチ`f`から`1`に`p`実行不可能であるため`p`非常に大きくなる可能性があります。 すべての力を繰り返すよりも賢いものが必要です。 エッジケースには、矢印がすでに次の方向を向いている場合が含まれます。`0`、 いつ`p`に比べて非常に小さい`n`、またはいつ`x`ホイールの端近くにあり、スピンが複数回ラップアラウンドします。 

たとえば、次の場合`n = 5`、`x = 2`、`p = 1`、その場合、唯一のスピンは`f=1`、移動`1`セクタ。 矢印の終点は次のとおりです`3`、したがって、答えは「いいえ」です。 もし`p = 2`、選択できます`f=2`、移動`3`合計セクター数 (`2 + 1`）に着陸します`0`。 単純なアプローチでは大規模な問題には対処できません。`p`効率的に。 

## アプローチ

 ブルートフォースソリューションはあらゆる力を試します`f`から`1`に`p`、計算します`f*(f+1)/2`、追加します`x`、モジュロを取ります`n`届くかどうかを確認するために`0`。 これは原理的には機能しますが、最大で次のことが必要になる場合があります。`10^9`テスト ケースごとの反復回数は制限時間をはるかに超えています。 

重要な洞察は、方程式が次であるかどうかを確認するだけでよいということです。`(x + f*(f+1)/2) % n == 0`いくつかの解決策があります`1 <= f <= p`。 それを拡張したいのです`(f*(f+1)/2) % n == (-x) % n`。 左辺は二次方程式です`f`直接反転するのは難しいように見えますが、一度反転すると次のようになります。`f`を超える`n`、合計`f*(f+1)/2`モジュロ`n`追加するため、パターンの繰り返しが始まります`n`に`f`合計を次の倍数だけ増やします`n`。 つまり、確認するだけで十分です`f`まで`min(p, 2*n)`ずっとではなく`p`、その後はパターンがモジュロで循環するため`n`。 これにより、反復が削減されます。`10^9`せいぜい`2*10^5`テスト ケースごとに、制約を考慮すると管理可能です。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`x`、`p`。 
3. 目標値を計算する`target = (-x) % n`。 これは、到達するために前進する必要があるセクターの数です`0`。 
4. 反復する`f`から`1`に`min(p, 2*n)`。 に止まります`2*n`なぜなら`f*(f+1)/2`モジュロ`n`この時点を超えて繰り返しが始まります。 
5. それぞれについて`f`、合計の進歩を計算します`move = f*(f+1)//2`。 
6. もし`(move % n) == target`、「Yes」を出力してループを終了します。 
7. いいえの場合`f`条件を満たしている場合は、「いいえ」を出力します。 

なぜ機能するのか: 重要な特性は、最初の値の合計が`f`整数の剰余`n`限られた範囲内で繰り返します。 までチェックすることで、`2*n`、すべての個別の剰余モジュロに遭遇することが保証されています。`n`, したがって、解決策が存在する場合は、それを見つけます。 これにより、ずっと反復する必要がなくなります。`p`いつ`p`とても大きいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, x, p = map(int, input().split())
    target = (-x) % n
    found = False
    limit = min(p, 2*n)  # pattern repeats modulo n
    for f in range(1, limit + 1):
        move = f * (f + 1) // 2
        if move % n == target:
            found = True
            break
    print("Yes" if found else "No")
```私たちが使用するのは`sys.stdin.readline`最大で`10^4`テストケース。 の`min(p, 2*n)`トリックにより、最大の反復が防止されます`10^9`。 整数の除算`//`浮動小数点の問題を回避するために必要です。 モジュロ演算により、ホイールの円形の性質を確実に処理できます。
