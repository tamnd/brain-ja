 ## 解決策
 ## 問題の理解

 次のような接続された無向グラフが与えられます。$n$頂点と$m$エッジ。 各エッジには 1 から 1 までの番号が付けられます。$m$と処理を求められます。$q$クエリ。 各クエリは、さまざまな頂点インデックスを提供します。$[l, r]$、初期エッジの最小数を決定します。$k$その範囲内のすべての頂点は、エッジ 1 から 1 までのみを使用して相互に到達可能です。$k$。 

実践的な言葉で言い換えると、最初は空のグラフに、指定された順序に従ってエッジを 1 つずつ追加すると想像してください。 連続した頂点の特定のセットについて、頂点同士が接続されたコンポーネントを形成する瞬間を知りたいと考えています。 この範囲外の頂点への接続性は考慮せず、内部接続性のみを考慮します。 

制約が意味するのは、$n$まで可能です$10^5$そして$m, q$まで$2 \cdot 10^5$テスト ケースごとに、すべてのテスト ケースの合計が同様に制限されます。 これはアルゴリズムが複雑であることを意味します$O(n m q)$または$O(n^2)$不可能です。 線形または線形に近いものが必要です$m$そして$n$テストケースごとに。 

明らかではないエッジ ケースには、長さ 1 の範囲や次のようなクエリが含まれます。$l$そして$r$頂点の順序の両端にあります。 たとえば、次のようなクエリ$l=1, r=1$単一の頂点は自明にそれ自体に接続されるため、0 を返す必要があります。 常にエッジを処理する不注意な実装では、少なくとも 1 が返されます。 

## アプローチ

 素朴なアプローチは、エッジの追加を段階的にシミュレートし、クエリごとにクエリ範囲内の頂点が接続されているかどうかを確認することです。 これには、最初のサブグラフを維持する必要があります。$k$エッジとパフォーマンス$O(r-l+1)$クエリごとの接続チェック。 最悪の場合、こうなります$O(m q n)$が遅すぎます。 

重要な洞察は、この問題が任意のセットではなく、**連続する頂点範囲**の接続性を要求しているということです。 これにより、頂点ごとに計算できるようになります。$i$、最も早いエッジ$f[i]$どの頂点の後に$i$につながるようになる$i-1$。 エッジを順番に反復処理しながらこの情報を維持すると、問題は **範囲最大クエリ** に縮小されます。$[l, r]$、答えは$\max(f[l+1], f[l+2], ..., f[r])$。 これが機能するのは、範囲全体の接続には、連続するペアを接続する最大のエッジ インデックスが必要であるためです。 

効率的に計算するには$f[i]$では、Union-Find とも呼ばれる Disjoint Set Union (DSU) 構造を使用できます。 エッジを追加するときに、エッジの端点を含むセットをマージし、各コンポーネントの最大頂点を追跡します。 2 つのコンポーネントがマージされると、そのコンポーネント内の連続する頂点を接続する最初のエッジが更新されます。 このプロセスはほぼ直線的な時間で実行されます。 

これにより、クエリごとの作業がアレイ上の最大範囲のクエリに削減されます。$f$、クエリがオフラインの場合は、セグメント ツリーまたは単純なプレフィックス最大配列を使用して前処理できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(q \cdot n \cdot m)$|$O(n+m)$| 遅すぎる |
 | 最適 |$O((n+m) \cdot \alpha(n) + q)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. DSU 構造を初期化します。$n$頂点。 各頂点は独自のコンポーネントから始まります。 
2. 配列を初期化する$f[2..n]$ゼロ付き。$f[i]$頂点がその後に続く最小のエッジ インデックスを保存します。$i-1$そして$i$接続されています。 
3. エッジを順番に繰り返します$1..m$。 エッジ接続用$u$そして$v$:

 - のコンポーネントを見つける$u$そして$v$DSUを使用して。 
- すでに同じコンポーネント内にある場合はスキップします。 
- それ以外の場合は、2 つのコンポーネントをマージします。 マージ後、結合にまたがるすべての連続する頂点について、更新します。$f[i] = \text{current edge index}$それがゼロだったら。 
4. すべてのエッジを処理した後、プレフィックスの最大配列を計算します。$F$から$f$。 ここ$F[i] = \max(f[2..i])$。 これにより、$O(1)$取得して質問の回答を取得する$F[r]$または$F[r] - F[l]$インデックスによって異なります。 
5. 各クエリについて$[l, r]$：

- もし$l = r$、0を出力します。 
- それ以外の場合は出力$\max(f[l+1..r])$。 これは、範囲全体が接続される後の最も早いエッジに対応します。 

**機能する理由:** すべてのマージ ステップで、連続する 2 つの頂点を接続する最初のエッジが確実に記録されます。$f$。 すべての連続するペアが接続されている場合にのみ範囲が接続されるため、これらの値の最大値を取ると最小値が得られます。$k$必須。 DSU はマージを見逃さないことを保証し、ランクごとの結合ヒューリスティックにより効率を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

class DSU:
    def __init__(self, n):
        self.p = list(range(n))
        self.size = [1]*n
        self.left = list(range(n))
        self.right = list(range(n))

    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]

    def union(self, x, y, edge_idx, f):
        x = self.find(x)
        y = self.find(y)
        if x == y:
            return
        if self.size[x] < self.size[y]:
            x, y = y, x
        for i in range(self.left[y]+1, self.right[y]+1):
            if f[i] == 0:
                f[i] = edge_idx
        self.p[y] = x
        self.size[x] += self.size[y]
        self.left[x] = min(self.left[x], self.left[y])
        self.right[x] = max(self.right[x], self.right[y])

def solve():
    t = int(input())
    for _ in range(t):
        n, m, q = map(int, input().split())
        edges = [tuple(map(int, input().split())) for _ in range(m)]
        edges = [(u-1, v-1) for u,v in edges]
        f = [0]*(n+1)
        dsu = DSU(n)
        for idx, (u, v) in enumerate(edges, 1):
            dsu.union(u, v, idx, f)
        prefix_max = [0]*(n+1)
        for i in range(2, n+1):
            prefix_max[i] = max(prefix_max[i-1], f[i])
        for _ in range(q):
            l, r = map(int, input().split())
            if l == r:
                print(0, end=' ')
            else:
                print(prefix_max[r], end=' ')
        print()

if __name__ == "__main__":
    solve()
```DSU は、各コンポーネントの左端と右端の頂点を保存します。 2 つのコンポーネントをマージすると、マージされた間隔内のすべての連続する頂点を接続する最も古いエッジが更新されます。 プレフィックス最大配列は、連続するペアの値を高速なクエリ応答に変換します。 境界処理により、長さ 1 のクエリは必ず 0 を返します。
