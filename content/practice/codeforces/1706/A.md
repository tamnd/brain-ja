 ## 解決策
 ## 問題の理解

 長さの文字列を構築するように求められます`m`、最初は文字「B」で埋められます。`n`シーケンスによって定義された操作`a_1, a_2, ..., a_n`。 各要素`a_i`選択を表します:`i`- 番目の操作では、次のいずれかを設定できます。`a_i`- 番目の文字または`(m + 1 - a_i)`文字列の - 番目の文字を「A」にします。 複数の操作が同じ位置に影響を与える可能性がありますが、文字を「A」から「A」に変更しても効果はありません。 目標は、すべての操作の後に辞書編集上可能な限り最小の文字列を取得することです。 

境界を考えると、`n`そして`m`両方とも最大 50 の場合、すべての可能な選択肢の総当りシミュレーションは 1 つのテスト ケースでは実現可能ですが、最大 2000 のテスト ケースでは、テスト ケースごとに線形時間で機能するソリューションが必要になります。`O(n)`または`O(m)`。 入力サイズが小さいということは、単純な比較に基づく貪欲なアプローチが効率的に機能することも示唆しています。 

明らかではないエッジケースには、次のような選択肢が含まれます。`a_i`対称な位置を指します。 たとえば、次の場合`m = 5`そして`a_i = 2`、ポジション 2 または 4 を選択できます。常に選択する単純なアプローチ`a_i`辞書編集上最小の文字列を生成できない可能性があります。 もう 1 つのエッジ ケースは、複数の操作が同じ位置をターゲットとする場合です。 アルゴリズムは、最小の文字列を達成するために、より早い位置が優先されることを保証する必要があります。 

## アプローチ

 ブルート フォース アプローチでは、すべての選択肢のシーケンスを試行し、次のいずれかを設定します。`a_i`または`(m + 1 - a_i)`操作ごとに。 と`n`これにより、最大で`2^n`組み合わせ。 たとえ`n <= 50`、これは 2000 のテスト ケースでは明らかに実行不可能です。 

重要な点は、各演算において、辞書編集的により小さな選択は、可能な 2 つの位置のうち小さい方を「A」に設定することであるということです。 これにより、問題は単純な貪欲な選択に変換されます。 位置が「A」に設定されると、同じ位置に対する後続の操作によって結果が悪化することはないため、すべての要素を安全に反復できます。`a`、2 つの候補位置を計算し、更新する小さい方のインデックスを選択します。 

このアプローチは、配列に対して 1 回のパスを実行し、定数時間の更新を実行し、バックトラックせずに最終的な文字列を直接構築するため、効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(m) | 遅すぎる |
 | 貪欲に最適 | テスト ケースあたり O(n) | O(m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.文字列を初期化する`s`長さの`m`すべての文字が「B」です。 これは、操作前の開始状態を表します。 
2. 各要素を反復処理する`a_i`順番に`a`。 2 つの候補位置を計算します。`left = a_i - 1`そして`right = m - a_i`。 これらは、文字列内のゼロから始まるインデックスの位置です。 
3. 各操作について、2 つの位置のうち小さい方を選択します。`min(left, right)`、「A」に設定します。 これにより、常に左端の利用可能な位置が最初に変更されるようになり、辞書編集上の最小の文字列が得られます。 
4. その位置の文字列を「A」に更新します。 この位置がすでに「A」である場合、この位置をターゲットとする後続の操作は効果がありません。 
5. すべての操作が完了したら、結果の文字列を出力します。 

機能する理由: 貪欲な選択では、常に対称候補の間で利用可能な左端の位置が選択されます。 辞書編集上、以前の位置の方が重要です。 一度「A」に設定すると、位置を元に戻すことはできないため、文字列の最小性を維持します。 この不変式は各操作に適用され、正確性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))
        s = ['B'] * m
        for ai in a:
            left = ai - 1
            right = m - ai
            pos = min(left, right)
            s[pos] = 'A'
        print(''.join(s))

if __name__ == "__main__":
    solve()
```このソリューションは文字列を初期化し、各操作を個別に処理します。 選択する`min(left, right)`左端の文字が優先されることが保証されます。 ゼロベースのインデックス付けは慎重に処理されます。 の`print`各テスト ケースの最終文字列を出力します。 境界の問題がないので、`1 <= a_i <= m`。

 ## 特殊なケース

 アルゴリズムは常に左端を選択することにより、対称位置を正しく処理します。 例えば、`m = 4, a = [1,3]`最初の位置は 0 と 3、2 番目の位置は 2 と 1 になります。 貪欲な選択では位置 0 と 1 が選択され、`AABB`、これは辞書編集的に最小限です。 繰り返される選択、例えば`[1,1,1]`、結果を上書きしたり悪化させたりせず、正確さを保ちます。 最小長と最大長、およびエッジを対象とした操作はすべて、追加の分岐なしで同じロジックによって処理されます。
