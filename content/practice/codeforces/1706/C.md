 ## 解決策
 ## 問題の理解

 私たちは、それぞれが一定の階数を持つ建物の列を与えられています。 建物は、隣接する建物よりも厳密に高い場合に「クール」であると見なされます。 最初と最後の建物は、隣接する建物が 2 つもないため、クールになることはできません。 床を追加することで建物の高さを増やすことができます。目標は、追加する床の総数を最小限に抑えながら、クールな建物の数を最大化することです。 

入力は複数のテスト ケースで構成されます。 各テスト ケースでは、建物の数と現在の高さが提供されます。 各テスト ケースの出力は、クールな建物の数を最大化するために必要な最小フロア数です。 

この制約は、すべてのテスト ケースにわたる建物の数の合計が 200,000 を超えないことを示しています。 これにより、テスト ケースごとの建物の数が 2 次になるソリューションが除外されます。 各テスト ケースに対して、ほぼ線形時間で実行されるアルゴリズムが必要です。 

明らかではないエッジ ケースには、建物の高さがすでに交互になっているシーケンスや、複数の隣接する建物の高さが等しいシーケンスが含まれます。 たとえば、シーケンス`[1, 2, 1, 2, 1]`の位置 2 と 4 にはすでに最大限のクールな建物があるため、追加のフロアは必要ありません。 もう一つの厄介なケースは、`[3, 1, 4, 4, 2]`連続する 2 つの建物が等しい場合。 どの建物を増やすかの選択は、追加されるフロアの総数に影響を与える可能性があります。 

## アプローチ

 強引なアプローチとしては、各建物の内部を個別に冷却してみて、必要な階数を計算することです。 次に、建物のすべての組み合わせを試して、クールな建物の最大数と最小の追加フロアを見つけることができます。 ただし、`n`まで`10^5`、可能性の数は指数関数的に増加するため、すべての組み合わせを試すことは明らかに不可能です。 

重要な洞察は、すべての組み合わせを考慮する必要はないということです。 クールな建物を隣接させることはできません。連続する 2 つの建物を隣の建物よりも高くしようとすると、それらの高さが競合してしまうからです。 この観察により、問題は、すべての奇数インデックスの内部建物か、すべての偶数インデックスの内部建物のいずれかの独立した選択に帰着します。 これら 2 つのパターンに必要な下限を計算し、合計が小さい方を選択できます。 奇数長のシーケンスの場合は、重複するペアをチェックするハイブリッド アプローチを検討する必要がある場合がありますが、ほとんどの場合、奇数位置と偶数位置を比較するだけで十分です。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各テスト ケースについて、建物の数を読み取ります。`n`そして高さの配列`h`。 
2. もし`n`が奇数の場合は、2 つの合計を初期化します。1 つは奇数のインデックスが付いたすべての内部建物を涼しくするために必要な追加フロア用で、もう 1 つは偶数のインデックスが付いたすべての内部建物用です。 
3. インデックスの各内部建物について`i`(1 ベースなので、`2 ≤ i ≤ n-1`)、両方の隣接する階よりも高くするために必要な最小階数を計算します。`max(h[i-1], h[i+1]) + 1 - h[i]`。 結果が負の場合は、ゼロを使用します。 
4. 計算されたフロアを奇数または偶数の位置の合計に加算します。`i`。 
5. すべての内部建物を処理した後、次の場合`n`が奇数の場合は、2 つの合計の最小値を選択します。 もし`n`が偶数の場合、パターンはより複雑になるため、スライディング ウィンドウ アプローチを使用して、隣接しないクールな建物の合計を計算し、最小の合計を選択します。 
6. テスト ケースの最小合計フロアを出力します。 

機能する理由: 不変条件は、隣接する 2 つの建物が両方とも涼しいということはあり得ないため、最適なソリューションは隣接しない建物のサブセットを選択する必要があるということです。 このアルゴリズムでは、隣接しない 2 つの最大のサブセット (奇数と偶数) が考慮され、クールな建物の数を最大化するための最小合計が見つかることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        h = list(map(int, input().split()))
        if n % 2 == 1:
            total = 0
            for i in range(1, n-1, 2):
                total += max(0, max(h[i-1], h[i+1]) + 1 - h[i])
            print(total)
        else:
            # Sliding window for even length
            add = [0] * (n-2)
            for i in range(1, n-1):
                add[i-1] = max(0, max(h[i-1], h[i+1]) + 1 - h[i])
            prefix = [0] * (n-1)
            prefix[0] = add[0]
            for i in range(1, n-2):
                prefix[i] = prefix[i-1] + add[i]
            res = float('inf')
            for i in range((n-2)//2 + 1):
                left = prefix[i-1] if i > 0 else 0
                right = prefix[-1] - prefix[i + (n-2)//2 - 1] if i + (n-2)//2 - 1 < n-3 else 0
                middle = prefix[i + (n-2)//2 - 1] - prefix[i-1] if i > 0 else prefix[i + (n-2)//2 - 1]
                res = min(res, left + right + middle)
            print(res)

solve()
```コードはまず、他のすべての建物に必要な最小階数を合計することによって、奇数長のシーケンスを処理します。 偶数長のシーケンスの場合、すべての内部建物に必要なフロアを事前計算し、プレフィックス合計とスライディング ウィンドウを使用して、隣接しない建物の組み合わせを考慮します。 インデックス作成には、off-by-one エラーを避けるために特別な注意が払われます。 建物がすでに隣の建物よりも高い場合、フロアは必要ないため、負の値はゼロにクランプされます。
