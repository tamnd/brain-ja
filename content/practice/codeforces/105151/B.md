 ## 解決策
 ## 問題の理解

 私たちには、水平線上の点に落ちる雨粒のセットが与えられています。 各液滴は特定の座標に表示され、それぞれの落下時間が経過した後にのみ膨張を開始します。 液滴が着地すると、一定の速度で対称的に膨張します。$k$着地から数秒、中心からの間隔をカバー$x_i$距離的に両方向へ$k$。 したがって、各液滴は成長間隔を形成し、その半径は時間とともに直線的に増加しますが、それはその活性化時間の後でのみです。 

タスクは最も早い整数モーメントを決定することです$T$これらすべての拡張間隔の和集合が固定セグメントを完全にカバーするようにします。$[0, r]$。 カバレッジとは、内部のすべてのポイントを意味します。$[0, r]$一度に少なくとも 1 つの液滴の拡張間隔に含まれる$T$。 

制約は大きく、最大で$2 \cdot 10^6$液滴と座標まで$10^9$。 これにより、時間を段階的にシミュレートしたり、候補時間ごとにカバレッジを個別に再計算したりするアプローチは即座に排除されます。 どのソリューションでも、チェックごとにすべての液滴を繰り返し処理することは避けなければなりません。 私たちにも余裕がない$O(n \log n)$各チェックは線形時間に近い必要があるため、慎重な線形マージを行わずに単純な二分探索で時間ごとに評価します。 

この問題の微妙な側面は、液滴がすぐには寄与しないことです。 それらは、個々の立ち下がり時間の後にのみアクティブになります。 これにより、時間依存の一連の間隔が作成されますが、すべての液滴が時間ゼロからアクティブであると仮定すると、誤って処理されやすくなります。 

いくつかの特殊なケースでは、よくある間違いが明らかになります。 すべての液滴が候補時間の後に落ちる場合、たとえそれらの位置が密であっても、カバレッジは空になります。 例えば、$n=2, r=10$、での液滴$x=0, x=10$、両方とも$t_i=100$。 で$T=50$、カバレッジは存在せず、たとえ空間的にすべてが完璧だったとしても、答えは 50 にはなりません。 

別の失敗例は、液滴が正確な時間に落下した場合に発生します。$T$。 時間における半径$T$はゼロであるため、単一ポイントのみに寄与します。 これをゼロ以外の間隔に寄与すると誤解すると、誤った早期終了が発生します。 

最後に、時間ベースのアクティブ化を考慮せずに固定順序を仮定すると、貪欲なマージの失敗が発生します。 アクティブな間隔のセットは次のように変化します。$T$したがって、カバレッジは常に固定された候補時間と比較して評価する必要があります。 

## アプローチ

 直接的なアプローチは、次の時間をシミュレートすることです。$0$上向きに。 各整数時間で$T$、すでに落下したすべての液滴を計算し、そのような液滴ごとにその間隔を計算します。$[x_i - (T - t_i), x_i + (T - t_i)]$。 次に、これらの間隔をマージし、それらの間隔がカバーされているかどうかを確認します。$[0, r]$。 これは問題定義に直接従うため、正しいです。 

問題はパフォーマンスです。 最悪の場合、以下の検査が必要になる場合があります。$10^9$候補時間、および各チェックには最大で 1 回の処理が必要です。$2 \cdot 10^6$間隔。 これは実行可能な計算をはるかに超えています。 

重要な観察は、カバレッジ特性が時間に対して単調であるということです。 一定時間に1回$T$カバーするには十分です$[0, r]$、それ以上の時間$T'$すべての液滴はさらに拡大するだけなので、これも機能します。 これにより、バイナリ検索が可能になります$T$。 

特定の各実現可能性チェック$T$で行うことができます$O(n)$液滴のみに有効な間隔を構築することで、$t_i \le T$、それらをソートまたはスイープし、マージします。 ただし、小切手ごとに並べ替えるのは遅すぎます。 代わりに、液滴を位置によって 1 回分類するか、繰り返しの分類を避ける方法で処理します。 最も効率的な定式化は、ペアにすることです。$x_i$そして$t_i$、固定の場合$T$、オンザフライで間隔を計算し、左のエンドポイントで並べ替えた後に線形スキャンを実行します。 

したがって、解は二分探索になります。$T$、各チェックでは線形変換と線形マージが実行されます。

 ## アルゴリズムのチュートリアル

 1. 安定した処理に必要な場合にのみ液滴を位置で並べ替えますが、より重要なのは、固定値に基づいてカバレッジ間隔を計算することで、各チェックを独立して処理することです。$T$。 マージはチェックごとに行われるため、順序付けは本質的にグローバルには必要ありません。 
2. 関数を定義する`can(T)`すべてが次の点を指しているかどうかを決定します$[0, r]$時間でカバーされます$T$。 
3. 内部`can(T)`、すべての液滴を繰り返します。 各液滴に対して、$t_i \le T$、その半径を計算します$d = T - t_i$、したがってその間隔$[x_i - d, x_i + d]$。 飛沫を無視する$t_i > T$まだ登場していないので。 
4. このような間隔をすべて収集し、左端の昇順にマージします。 マージ中は、これまでにカバーした最も右側のポイントを維持します。 いずれかの時点で、現在のマージされたカバレッジと次の間隔の間にギャップがある場合、カバレッジは直ちに失敗します。 
5. すべての間隔をマージした後、最終的にカバーされたポイントが少なくとも次の点に達しているかどうかを確認します。$r$。 「はい」の場合、$T$で十分です。 
6. 二分探索オーバー$T$範囲内で$[0, \max t_i + r]$。 上限は、右端のカバレッジが遠くの液滴から伝播しなければならないという最悪のケースに基づいています。 
7. 二分探索の各中間値に対して、次を呼び出します。`can(mid)`それに応じて境界を調整して、有効な最小値を見つけます$T$。 

これが機能する理由は、カバレッジの単調性に基づいています。 間隔設定が完了したら$[0, r]$時に$T$、増加しています$T$すべてのアクティブな間隔を拡張するか、より多くの液滴をアクティブにするだけです。 これは、有効な時間のセットが整数タイムラインのサフィックスを形成することを意味します。これはまさに二分探索の正確さに必要な条件です。 マージのステップにより、カバレッジを過大評価することなく、重複する展開を正しく考慮し、ギャップを正確に検出できるようになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def can(T, x, t, r):
    intervals = []
    for i in range(len(x)):
        if t[i] <= T:
            d = T - t[i]
            l = x[i] - d
            rgt = x[i] + d
            intervals.append((l, rgt))

    if not intervals:
        return False

    intervals.sort()
    
    cur = 0
    for l, rgt in intervals:
        if l > cur:
            return False
        if rgt > cur:
            cur = rgt
        if cur >= r:
            return True
    return cur >= r

def solve():
    n, R = map(int, input().split())
    x = list(map(int, input().split()))
    t = list(map(int, input().split()))

    lo, hi = 0, R + max(t)
    ans = hi

    while lo <= hi:
        mid = (lo + hi) // 2
        if can(mid, x, t, R):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1

    print(ans)

if __name__ == "__main__":
    solve()
```実装の中核となるのは、`can`一定時間に有効カバレッジを再構築する機能。 各液滴は、それがアクティブな場合にのみ間隔に変換されます。 区間の拡張は時間差から直接計算されるため、幾何学的解釈の正確さが保証されます。 

マージプロセスでは単一の変数が維持されます。`cur`、これまでにカバーされた右端のポイントを追跡します。 以降に始まる任意の間隔`cur`ギャップを知らせ、候補時間を即座に無効にします。 

二分探索では、答えが上に制限されるという事実を利用します。$R + \max(t_i)$、最悪の場合、位置 0 の液滴は距離を超えて拡大する必要があるためです。$R$アクティブになった後。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def can(T, x, t, r):
        intervals = []
        for i in range(len(x)):
            if t[i] <= T:
                d = T - t[i]
                intervals.append((x[i] - d, x[i] + d))
        if not intervals:
            return False

            if l > cur:

            if can(mid, x, t, R):
                ans = mid
                hi = mid - 1
            else:
                lo = mid + 1

        print(ans)

    solve()
    return ""

 ## 特殊なケース

 重要なエッジケースは、候補時間にアクティブな液滴が存在しない場合です。 例えば、$T=0$みんなで$t_i > 0$空の間隔セットを生成します。 可能なカバレッジがないため、アルゴリズムは正しく false を即座に返します。 

もう 1 つのケースは、カバレッジがほぼ完全であるにもかかわらず、1 つのギャップで失敗する場合です。 たとえば、拡張後の間隔により、$[0, 2]$そして$[3, 5]$2 から 3 にギャップがあります。マージ ステップはこれを検出します。これは、次の間隔が後に開始されるためです。`cur`、関数は続行せずに false を返します。 

最後の微妙なケースは、液滴が候補時間に正確に活性化する場合です。 半径がゼロなので、その間隔は単一の点になります。 アルゴリズムには引き続きそれが含まれていますが、既存のカバレッジの境界に正確に存在しない限り、ギャップを埋めることはできません。これはマージ条件によって正しく処理されます。`l > cur`。
