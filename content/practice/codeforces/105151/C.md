ただし、ノードごとに、半径を増やしながらすべてのノードを繰り返し処理する場合があります。 密なグラフでは、各 BFS は接触することができます$O(n)$ノードと各 DP コスト$O(nk)$、与える$O(n^2 k)$開始ノードごとに、$O(n^3 k)$全体。 これは完全に失敗します$2 \cdot 10^5$。

 ## アルゴリズムのチュートリアル

 BFS を使用して各開始ノードを個別に処理します。 

1. 固定起動ノードの場合$s$、距離配列を初期化します$-1$そしてセット$dist[s] = 0$。 でキューを初期化します$s$。 
2. DP アレイを維持する`dp`サイズの$k$、 どこ`dp[r]`現在検出されているノード間でサブセットを形成できるかどうかを示します。$k$等しい$r$。 最初はすべての値が false です。 
3.セット`dp[c[s] % k] = True`。 これは、開始ノードのみをサブセットとして選択できることを反映しています。 
4. もし`dp[0]`すぐに true になり、その後、次のように応答します$s$は$d = 0$。 
5. BFS レベルをレベルごとに展開します。 ノードの場合$v$遠くで発見される$d$、トランジションを使用して DP を更新します。 

あらゆる残留物に対して$r$、 もし`dp[r]`それは本当です、それでは`(r + c[v]) % k`到達可能になります。 
6. 各 BFS レイヤーを処理した後、次のことを確認します。`dp[0]`それは本当です。 それが true になる最初の層が最小値を決定します。$d$。 
7. BFS が達成されずに終了した場合`dp[0]`、出力$-1$。 

重要な設計上の選択は、ノードが最初に検出されたときにのみ DP 更新が適用されることです。 これにより、各ノードが 1 回だけ貢献することが保証され、異なる BFS レベルにわたる過剰カウントが防止されます。 

### なぜ効果があるのか

 DP の不変条件は、最大でも距離内のすべてのノードを処理した後、$d$、`dp[r]`合計が一致するノードのサブセットが存在する場合にのみ true になります。$r \bmod k$。 BFS はレイヤーで次のことを保証します。$d$、半径内にノードのセットが正確にあります。$d$したがって、DP 状態は、許可された領域のサブセット空間と正確に一致します。 ノードの追加は利用可能なサブセットのセットを拡張するだけなので、残りが$0$到達可能になり、より大きなすべての者にとって到達可能な状態が維持されます$d$、最初に出現したものが最小有効半径になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

def solve():
    n, m, k = map(int, input().split())
    c = list(map(int, input().split()))
    
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    ans = [-1] * n

    for s in range(n):
        dist = [-1] * n
        dist[s] = 0
        q = deque([s])

        dp = [False] * k
        dp[c[s] % k] = True

        if dp[0]:
            ans[s] = 0
            continue

        current = 0
        while q:
            v = q.popleft()
            for to in g[v]:
                if dist[to] == -1:
                    dist[to] = dist[v] + 1
                    q.append(to)

                    newdp = dp[:]
                    for r in range(k):
                        if dp[r]:
                            newdp[(r + c[to]) % k] = True
                    dp = newdp

                    if dp[0]:
                        ans[s] = dist[to]
                        q.clear()
                        break
            if ans[s] != -1:
                break

    print(*ans)

if __name__ == "__main__":
    solve()
```BFS は、ノードが距離の増加順に検出されることを保証するため、最初に DP が有効になる時点が最小半径に対応します。 インプレースで更新すると、単一レイヤーの移行で同じノードが誤って複数回再利用される可能性があるため、DP コピーのステップは重要です。 

微妙な点は、ノードがデキューされたときではなく、ノードが最初に検出されたときに DP を更新することです。 これにより、増加する到達可能なセットに合わせて DP が維持されます。 剰余ゼロが見えた瞬間に、それ以上の拡張を無効にすることはできないため、早期に停止できます。

 ## 特殊なケース

 1 つのエッジ ケースは、コストが既に次の要素で割り切れる単一ノードです。$k$。 アルゴリズムが初期化されます`dp[c[s] % k]`したがって、これがゼロの場合、答えは BFS が開始される前に記録され、正しくゼロが返されます。
