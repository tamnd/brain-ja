 ## 解決策
 ## 問題の理解

 平面上に点のセットが与えられ、それぞれの点が収集可能なアイテムを 1 つだけ提供する店を表します。 重要な制限は幾何学的なもので、単一の直線上にある店舗からのみ商品を選ぶことが許可されています。 このようなラインを選択した後、そのライン上の店舗のサブセットを訪問することができますが、移動はそのラインに制限されるため、選択したすべての点が同一線上にある必要があります。 

報酬は集めたアイテムの数によって異なります。 集めたら$t$のうちのアイテム$n$店舗の合計に比例して割引を受けます$t$、そしてタスクは、少なくとも必要なしきい値を達成できるかどうかを判断することになります。これは事実上、少なくとも一定数の共線点が必要であることを意味します。 

条件を書き直すと、問題は次のようになります。少なくとも次の内容を含む行が存在するかどうかを調べます。$k$ポイント、どこ$k$パーセンテージ要件から導出されます。 そのようなセットが存在する場合は、同じ行にあるインデックスの有効なサブセットを出力する必要があります。 

入力サイズは大きく、最大 400,000 ポイントです。 これにより、ペアワイズが即座に除外されます。$O(n^2)$線または斜面の幾何学的列挙。 すべてのペアを保存することさえ、時間的にもメモリ的にも不可能です。 どのソリューションでも、すべての行を明示的に考慮することは避けなければなりません。 

微妙だが重要な問題は、ポイントの重複です。 複数のインデックスが同一の座標を共有する場合があり、それらのすべてがその位置を通過する任意の線と自明に同一直線上にあります。 単純な傾斜ベースのソリューションは、方向を正規化しない場合や一致点を正しく処理しない場合、簡単に壊れる可能性があります。 

別の失敗例は、多くの点が同一線上にあるにもかかわらず、ランダム サンプリングや部分的なグループ化によって検出されない場合に発生します。 たとえば、すべての点が垂直線上にある場合、無限の傾きを特別に処理しない傾きベースのハッシュでは、正しいグループを見逃してしまう可能性があります。 

## アプローチ

 強引なアイデアは、すべての点のペアを考慮し、それらを通過する線を計算し、その上に他の点がいくつあるかを数えるというものです。 各回線チェックにかかる費用$O(n)$、そして、あります$O(n^2)$ペア、につながる$O(n^3)$時間。 正規化された係数によって線をハッシュしても、依然として次のような問題に直面します。$O(n^2)$ペアと潜在的に大規模な衝突処理。 と$n = 4 \cdot 10^5$、これはまったく不可能です。 

重要な点は、すべての行を調べる必要はないということです。 少なくとも次の内容を含む 1 行を見つけるだけで済みます。$k$ポイント。 これは、ランダム化またはピボットベースの戦略を示唆しています。そのような線が存在する場合、その線からランダムな点を選択すると、他の多くの点がそれに一致する可能性が高くなります。 ただし、決定的な保証が必要です。 

より強力な洞察は、ラインにすべてのポイントの少なくとも固定部分が含まれている場合、データセットからランダムなポイントのペアを選択すると、そのライン内に到達する確率がかなり高いということです。 候補ペアを選択すると、それらが定義する線を検証し、線形時間ですべての共線点をカウントできます。 

したがって、解決策は、ランダムなペアを繰り返しサンプリングし、線を定義し、その上にある点の数を確認することになります。 十分に試行すれば、高い確率で有効なペアがヒットします。 見つかったら、その線上にあるすべての点を出力します。 

これにより、すべての行のグローバルな列挙が回避され、代わりにターゲット行の組み合わせ密度が活用されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (すべてのペア、フルカウント) |$O(n^3)$|$O(1)$または$O(n)$| 遅すぎる |
 | ランダム化されたライン サンプリング |$O(n \cdot T)$|$O(n)$| 承認済み |

 ここ$T$はランダムな試行の数で、通常は 30 ～ 60 のような小さな定数です。 

## アルゴリズムのチュートリアル

 十分な数の点を持つ線を見つけることを繰り返し試みます。 

1. 必要なしきい値を計算します$k = \lceil \frac{m}{100} \cdot n \rceil$。 これは必要な共線点の最小数です。 
2. 固定回数、たとえば 60 回繰り返します。 

1. 2 つの異なるインデックスをランダムに選択します$i$そして$j$。 
2. 点が同一の場合は、一意の方向が定義されていないため、この繰り返しをスキップします。 
3. 方向の正規化表現を使用して、これら 2 つの点を通過する線を定義します。 安定した方法は、方向ベクトルを計算することです。$(dx, dy)$それを gcd で削減し、一意性を確保するために符号も修正します。 
4. すべての点をスキャンし、外積条件を使用してこの線との共線性を満たす点の数を数えます。$(x - x_i) \cdot dy = (y - y_i) \cdot dx$。 
5. カウントが少なくとも$k$、この条件を満たすすべてのインデックスを収集し、すぐに出力します。 
3. 繰り返しで有効な行が見つからない場合は、「No」を出力します。 

各反復の正確性は、外積による正確な共線性チェックに依存しており、これにより浮動小数点精度の問題が回避されます。 

### なぜ効果があるのか

 有効な解決策が存在する場合、少なくとも次のセットが存在します。$k$単一の線上にある点。 このサブセットから選択されたペアは、まさにそのラインを定義します。 あるので$\binom{k}{2}$みんなの中で良いペア$\binom{n}{2}$ペアの場合、ランダム サンプリングではそのようなペアが選択される確率がゼロではありません。 十分な回数繰り返すと、実際には失敗する可能性が無視できます。 正しいラインがサンプリングされると、検証ステップでそのライン上のすべての点が決定的に検出され、正確さが保証されます。 

## Python ソリューション```python
import sys
import random
import math

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    k = (m * n + 99) // 100

    if k <= 1:
        print("Yes")
        print(1)
        print(1)
        return

    idx = list(range(n))

    for _ in range(70):
        i = random.randrange(n)
        j = random.randrange(n)
        if i == j:
            continue

        x1, y1 = pts[i]
        x2, y2 = pts[j]

        dx = x2 - x1
        dy = y2 - y1

        if dx == 0 and dy == 0:
            continue

        res = []
        for t in range(n):
            x, y = pts[t]
            if (x - x1) * dy == (y - y1) * dx:
                res.append(t + 1)

        if len(res) >= k:
            print("Yes")
            print(len(res))
            print(*sorted(res))
            return

    print("No")

if __name__ == "__main__":
    solve()
```この実装では、傾きの正規化を完全に回避し、共線性の外積条件に依存します。これは、大きな座標の下でより簡単かつ安全です。 並べ替えは、出力形式の最後にのみ適用されます。 

ランダム サンプリングは、ペアを定義する候補を選択するためにのみ使用されます。 正確性は、各候補行の完全な検証によって保証されます。 

よくある落とし穴は、浮動小数点除算または単純な分数を使用して勾配をハッシュしようとすることです。 このアプローチは、精度の制限や重複した処理の下では失敗します。 ここでは、整数演算により、この種の問題が完全に回避されます。

 ## 特殊なケース

 すべての点が同一の場合、どのペアも縮退しており、方向が定義されていないためスキップする必要があります。 その場合、すべてのポイントが共線性チェックを満たし、しきい値が許容する場合、アルゴリズムはすべてのインデックスを正しく返します。 

有効な線が垂直または水平の場合でも、除算が完全に回避されるため、外積公式は引き続き機能します。 縦線の場合は、$dx = 0$、そして条件は正しく x 座標の等しさに帰着します。 

複数のラインの密度が類似しているが十分ではない場合、ランダム サンプリングにより非生産的なペアが繰り返し選択される可能性があります。 密な線が存在すると、そこからペアをサンプリングする確率が高まり、予想される時間内で最終的に成功することが保証されるため、制限された反復回数は引き続き機能します。
