 ## 解決策
 ## 問題の理解

 次のような長方形のグリッドが与えられます。$n$行と$m$列。 このグリッド内のどこかに、敵は単一のセルを隠します。$(x, y)$。 私たちは、固定されたセットを「調査」することができます。$k$私たちが選んだ細胞。 選択したセルごとに、隠れたセルまでのマンハッタン距離を受け取ります。 

重要な制限事項は、これらを確認した後、$k$距離を考慮すると、考えられるあらゆる選択肢に対して隠れたセルを一意に決定できなければなりません。$(x, y)$。 目標は、この一意性を保証するために必要なプローブの最小数を見つけることです。 

問題は基本的に、すべてのグリッド セルがそれらの点までのマンハッタン距離の一意のベクトルを持つために必要な参照点の数に関するものです。 

制約$n, m \le 10^9$セルを列挙したり、距離パターンをシミュレートしたりするという考えが不要になります。 正しい解決策は、グリッドの明示的なサイズではなく、グリッドのジオメトリのみに依存する必要があります。 まであるので、$10^4$テスト ケースでは、解はケースごとに一定時間である必要があります。 

素朴な推論による微妙な失敗例は、プローブを「遠くに」配置すれば常に十分であると仮定した場合に現れます。 たとえば、$2 \times 3$グリッドでは、マンハッタン距離によって特定の対称性が維持されるため、反対側のコーナーを選択しても必ずしも対称的な位置が区別されるわけではありません。 これがまさに、問題が乱暴な配置ではなく構造にある理由です。 

## アプローチ

 ブルートフォースアプローチでは、次のことを選択しようとします。$k$セルをプローブし、隠れセルから距離ベクトルへのマッピングが単射的であるかどうかを確認します。 プローブを固定して選択した場合、すべてのプローブの距離ベクトルを計算します。$n \cdot m$セルを作成し、一意性を検証します。 1 つの構成だけをテストする場合でも、すでにコストがかかります$O(nm)$、次の場合は不可能です$n, m$到達できる$10^9$。 

すべてのプローブ セットを試すとさらに悪くなります。 探索空間は、$(nm)^k$、でも爆発的に成長します。$k = 2$。 したがって、ブルートフォースは完全に手の届かないところにあります。 

重要な観察は、マンハッタン距離は非常に厳格な構造を持っているということです。 ダイヤモンド型の輪郭上のすべての点は同じ距離を共有するため、単一のプローブでは一意のセルを決定することはできません。 追加の各プローブは、そのような輪郭の別のファミリーと効果的に交差します。 問題は、長方形内の 1 つの格子点を分離するには、そのような制約がいくつ必要かということです。 

1 つのプローブからの距離が 1 つあれば、対角線に沿って複数の候補が残ります。 2 つのプローブを使用すると、対角レベル セットの 2 つのファミリーが交差することを考えることができます。 ただし、グリッドに複数の行と複数の列がある場合は縮退が発生します。特定の構成では依然としてあいまいさが許容されます。 もう 1 つのプローブは、残りの対称性を壊すことでこの問題を解決します。 

重要な単純化は、答えはグリッドが線であるか真の 2 次元であるかによってのみ決まるということです。 どちらかの場合$n = 1$または$m = 1$、すべてのセルは単一の線上にあり、マンハッタンの距離は通常の絶対距離になります。 エンドポイントで慎重に選択された 1 つのプローブは、単一の値ですべての位置を一意に識別します。これは、エンドポイントに固定されている場合、線に沿った距離が単射的なためです。 

両方の次元が少なくとも 2 の場合、常に 2 つのプローブで十分であり、1 つでは十分ではありません。 1 つのプローブでは対称位置を区別できません。 縮退していない位置 (隣接するコーナーなど) に 2 つのプローブを配置すると、すべての対称性が崩れます。 

したがって、答えは次のとおりです。 

-$k = 1$もし$n = 1$または$m = 1$-$k = 2$それ以外の場合

 この二分法は問題を完全に特徴づけています。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数関数 /$O((nm)^k)$|$O(nm)$| 遅すぎる |
 | 最適 |$O(1)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り$n$そして$m$テストケースごとに。 これらはグリッドの形状を定義します。答えにとって重要なのはこれだけです。 
2. グリッドが単一行または単一列に縮退しているかどうかを確認します。 これは以下に対応します$n = 1$または$m = 1$。 この場合、すべての点は直線上にあるため、距離は 1D 絶対差のように動作します。 
3. グリッドが 1 次元の場合、出力 1。エンドポイントに配置された単一のプローブにより、他のすべての位置に明確な距離が設定されるため、あいまいさが残りません。 
4. それ以外の場合、両方の次元は少なくとも 2 です。この場合、出力 2。1 つのプローブは対称構成を区別できませんが、2 つのプローブは単一の距離値を維持するすべての可能な反射と変換を遮断します。 

### なぜ効果があるのか

 正確さは、距離情報が座標をどのように制約するかによって決まります。 1 つのプローブで、すべてのセルが満足する$|x - x_0| + |y - y_0| = d$はダイヤモンドを形成し、2D グリッドで 1 つのプローブのみが使用される場合、複数のセルは常に同じ距離パターンを共有します。 これにより、次の場合に非一意性が保証されます。$n, m \ge 2$。 

グリッドが線の場合、マンハッタン メトリックは 1 つの軸に沿った絶対差に減少し、エンドポイントにプローブを配置すると、すべてのセルにわたって厳密に増加または減少する距離値が生成され、すべての位置を一意に識別できるようになります。 2D で 2 つの独立した距離制約を使用すると、2 つのマンハッタン レベル セットの交差は最大でも 1 つのグリッド セルになり、曖昧さがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print(1)
    else:
        print(2)
```この実装は、グリッドの構造分類を直接反映します。 必要な唯一の決定は、グリッドが 1D ラインに折りたたまれるかどうかです。 答えは純粋に次元に依存するため、シミュレーションやジオメトリの構築は必要ありません。 

重要な点は、問題がエンドポイントを明示的に構築する必要がない場合でも、1D の場合、エンドポイントが暗黙的に最適なプローブ位置であることを認識していることです。 2D の場合、問題は最小数のみを要求するため、2 つのプローブを構築する必要もありません。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 or m == 1:
            out.append("1")
        else:
            out.append("2")
    return "\n".join(out)

# provided samples
assert run("2\n2 3\n3 1\n") == "2\n1"

# minimum size grid
assert run("1\n1 1\n") == "1"

# single row
assert run("1\n1 1000000000\n") == "1"

# square grid
assert run("1\n4 4\n") == "2"

# tall grid
assert run("1\n100 1\n") == "1"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 1×1 | 1 | 最小のグリッド |
 | 1×N | 1 | 1D 行の動作 |
 | N×1 | 1 | 1D 列の動作 |
 | 4×4 | 2 | 最小限の 2D ケース |

 ## 特殊なケース

 のために$1 \times 1$グリッド、アルゴリズムチェック$n = 1$または$m = 1$セルは 1 つだけ存在するため、あいまいさはなく、任意のプローブで十分です。 

のために$1 \times m$のようなグリッド$1 \times 5$、条件により再び 1D ケースがトリガーされます。 頭の中でシミュレーションすると、どんなプローブでも$(1, 1)$距離を生み出す$0, 1, 2, 3, 4$行全体ですべて異なるため、1 つのクエリで十分かつ最適です。 

のために$2 \times 2$グリッドでは、どちらの次元も 1 に等しくないため、アルゴリズムは 2 を出力します。プローブが 1 つだけの場合、次のような反対側のコーナーが発生します。$(1,1)$そして$(2,2)$距離パターンの内部推論に対称的な曖昧性が生じます。 これらの対称性を破り、出力を一致させるには 2 つのプローブが必要です。
