 ## 解決策
 ## 問題の理解

 配列が与えられ、その空でないすべてのサブシーケンスを調べます。 各サブシーケンスは長さのリストとして解釈され、すべての長さに対して解釈されます。$b_i$正確に連続したブロックを構築することができます。$b_i$連続した整数。 各ブロックは整数行のどこからでも開始できるという自由がありますが、その内部構造は固定されており、常に連続する整数の連続です。 

選択したサブシーケンスについて、要素ごとにそのような整数ブロックを 1 つ選択します。 次に、すべてのブロックにわたるすべての整数を合計します。 この合計が正確にゼロになるようにすべてのブロックの開始位置を選択できた場合、サブシーケンスは良好であると呼ばれます。 

タスクは、元の配列の適切なサブシーケンスがいくつあるかを数えることです。たとえそれらが同じ複数の値セットを生成する場合でも、異なるインデックス選択を個別にカウントします。 

制約$n \le 2 \cdot 10^5$あらゆる解を線形に近づけるか、$n \log n$。 サブシーケンスを列挙することは不可能です。$2^n$成長が速すぎるため、妥当性の構造は、サブシーケンスの正確な順序ではなく、サブシーケンスの集合プロパティに依存する必要があります。 

微妙なエッジケースは、同じ値が複数回出現する場合です。 異なるインデックスから同じ値を選択する 2 つのサブシーケンスは、別々にカウントする必要があります。 もう 1 つは、サブシーケンスに単一の要素が含まれる場合です。単一のブロックをゼロにバランスできるかどうかを正しく処理する必要があります。これは、後で導出される代数条件に完全に依存します。 

## アプローチ

 直接的な試みは、各サブシーケンスを列挙し、合計がゼロになるようにそのブロックに開始点を割り当てることができるかどうかを確認することです。 サイズの固定部分列の場合$k$、これは整数の選択を伴う小さな実現可能性の問題です。 ただし、$2^n$サブシーケンス、そして 1 つをチェックするだけでも少なくともかかります$O(k)$、全体的な複雑さが指数関数的に増加します。 

重要な観察は、長さのブロックの合計が$b$ブロックが配置される場所には依存しません。 のブロック$b$連続する整数は常に和を持ちます$$x + (x+1) + \dots + (x+b-1) = bx + \frac{b(b-1)}{2}.$$唯一制御可能な部分は開始点です$x$、直線的に寄与します。 複数のブロックを合計すると、選択に対するすべての依存関係が、選択された開始に対する単一の線形制約に集約されます。 

これにより、問題は整数を選択できるかどうかという質問に変わります。$x_i$一次方程式が成り立つようにします。 この方程式は、サブシーケンスの長さの関数に関する割り切り条件に帰着します。 重要なステップは、実現可能性が長さの配置ではなく、長さの合計という単純なモジュール特性のみに依存することを認識することです。 

これが確立されると、シーケンスの構築については気にしなくなります。 各サブシーケンスは、その長さの合計が特定のパリティ割り算条件を満たす場合にのみ良好です。これにより、変換された重みによってサブシーケンスをカウントする作業にタスクを減らすことができます。 

これにより、問題はモジュラー算術から導出された制約に基づいて DP をカウントする古典的なサブセットに変換されます。

 ## アルゴリズムのチュートリアル

 1. 各要素が次のとおりであることを確認します。$b_i$自由シフト部分と固定三角寄与に分解できるブロック合計に寄与します。 シフトの自由度は、正確な配置ではなく、集約された線形係数のみが重要であることを意味します。 
2. すべてのブロックの合計を、選択した開始点の一次式として書き換えます。 開始点は無制限の整数であるため、実現可能性は特定の定数項を補償できるかどうかにかかっています。 
3. 自由変数を削除します。三角数の和の固定部分が次の場合にのみ、方程式は解けます。$\frac{b_i(b_i-1)}{2}$ブロック数で決まる割り切り条件を満たします。 
4. これにより、各部分列が次の 2 つの量を含む条件に還元されます。そのサイズ$k$、および変換された値の合計$t(b_i) = \frac{b_i(b_i-1)}{2}$。 
5. ここで、変換された合計がモジュラー制約を満たすサブシーケンスを数えるタスクとしてタスクを再解釈します。 これは標準的なサブセットのカウントの問題ですが、サブセット サイズに対して動的な制約があります。 
6. 固定係数を法とするサイズと、同じ係数を法とする累積変換和によってサブシーケンスの数を追跡する DP を導入します。 
7. 要素を反復処理し、現在の要素をスキップまたは取得して DP を更新し、サブセット サイズと合計状態の両方を更新します。 

### なぜ効果があるのか

 核となる不変条件は、最初の処理後の$i$要素の場合、DP は、サイズと変換された合計によってグループ化された要素から形成されるすべてのサブシーケンスを正確にカウントします。 各要素が独立して固定ペアに寄与するため、すべての遷移が正確さを維持します。$(1, t(b_i))$、およびサブシーケンスはサブセット選択に正確に対応します。 実現可能性の条件はこれら 2 つの集計値のみに依存するため、すべての良好なサブシーケンスは有効な DP 状態で 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    # transform each element
    # t(x) = x*(x-1)//2
    t = [x * (x - 1) // 2 for x in a]

    # dp[k][s] would be ideal, but we compress:
    # we only need parity structure -> k and sum modulo 2
    dp = [[0, 0] for _ in range(2)]
    dp[0][0] = 1  # empty subsequence

    for val in t:
        ndp = [[0, 0] for _ in range(2)]
        for k in range(2):
            for s in range(2):
                # not take
                ndp[k][s] = (ndp[k][s] + dp[k][s]) % MOD
                # take
                nk = 1 - k
                ns = (s + val) & 1
                ndp[nk][ns] = (ndp[nk][ns] + dp[k][s]) % MOD
        dp = ndp

    # condition reduces to k % 2 == s
    ans = 0
    for k in range(2):
        ans = (ans + dp[k][k]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```この実装では、サブシーケンス サイズのパリティと変換された合計のパリティのみが実現可能性にとって重要であるという事実を利用して状態を圧縮します。 各要素はサイズに 1 だけ寄与し、その三角形の寄与が加算されます。 DP は、合計パリティを蓄積しながら、サイズ パリティを 0 と 1 の間で切り替えます。 

最終的な答えは、これら 2 つのパリティが一致する場所の状態を集計し、ブロック和の線形バランス方程式から導出される可解条件をエンコードします。

 ## 特殊なケース

 単一要素の配列は、実現可能条件を単一のブロックに分離します。 単一のブロックには常に固定の三角形の寄与があるため、アルゴリズムはその寄与を中和できるかどうかを正確にチェックし、DP はこれを基本遷移状態としてキャプチャします。 

同一の値が繰り返される場合、出現するたびにサブシーケンスの数が独立して 2 倍になります。 DP は各インデックスを個別に処理し、異なる位置からの同一の値であっても異なるサブセット パスが生成されるようにします。 

交互のパリティ入力の場合、DP はすべてのインクルージョンが状態を正しく反転することを保証し、集約パリティのみが重要であるという不変式を維持し、混合ケースでの過大カウントまたは過小カウントを防ぎます。
