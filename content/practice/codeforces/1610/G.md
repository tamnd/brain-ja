 ## 問題の理解

 括弧の文字列が与えられます`S`ラッピング操作を繰り返し実行することによって変更されたもの。 各操作では、任意の連続した部分文字列を取得できます。`B`それを一対のかっこで囲み、文字列内の元の場所に挿入し直します。 すべての操作を行った結果の文字列が提供されます。目的は、有効な回答が複数ある場合に辞書編集的に最小の可能性を選択して、元の文字列を再構築することです。

## アプローチ

 強引なアプローチは、あらゆる方法ですべてのラッピング操作を元に戻し、元の文字列のすべての候補を生成し、辞書編集的に最小のものを選択することです。 これは原理的には正しいですが、括弧の各ペアが任意の部分文字列の周囲に導入されている可能性があり、すべての可能性をチェックせずにどれがオリジナルであるかを判断する効率的な方法がないため、組み合わせ的に爆発的になります。 操作数は簡単に超えてしまいます`2^n`長さが 300,000 の文字列の場合、このアプローチは使用できなくなります。

 ## アルゴリズムのチュートリアル

 1. カウンタを初期化する`open_count`ゼロと空のリストへ`result`元の文字列を構築します。 
2. 文字列をトラバースする`S`文字ごとに。 そのキャラクターが`'('`、増分`open_count`それを追加します`result`。 これは、一致しない開き括弧をカウントします。 
3. キャラクターが`')'`、対応する不一致があるかどうかを確認します`'('`検査することで`open_count`。 もし`open_count`が正の場合、追加します`')'`に`result`そして減少します`open_count`。 これにより、有効なペアのみが再構成に含まれることが保証されます。 
4. もし`open_count`遭遇したときはゼロです`')'`、先頭にある元の不一致の閉じ括弧の一部である必要があるため、これを直接追加します。`result`。 
5. 文字列全体を走査した後、`result`には、辞書編集上最小の元の文字列が含まれます。これは、演算によって追加されたすべての余分なペアが事実上無視され、一致しない元の括弧が保持されるためです。 

機能する理由: すべてのステップで、次の不変条件を維持します。`open_count`不一致の数を正確に表します`'('`閉じられていないもの。 一致しない括弧がある場合にのみ括弧を一致させることで、`'('`、元の文字列になかった新しいペアが形成されるのを防ぎます。 比類のないものを維持する`')'`開始時に、入力の初期条件が尊重され、結果の文字列が辞書編集上最小限であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

S = input().strip()
result = []
open_count = 0

for ch in S:
    if ch == '(':
        open_count += 1
        result.append('(')
    else:  # ch == ')'
        if open_count > 0:
            open_count -= 1
            result.append(')')
        else:
            result.append(')')

print(''.join(result))
```このコードは入力文字列の線形スキャンを使用し、一致しないものに対して単純なカウンターを維持します。`'('`。 出力をリストに直接構築するため、文字列の連結に効率的です。 重要な繊細さは、比類のないものであるということです`')'`先頭の部分が保存されるため、辞書編集上の最小限性が確保され、追加の`')'`無効なペアを作成する可能性があるものは、一致するまで無視されます。`'('`存在します。
