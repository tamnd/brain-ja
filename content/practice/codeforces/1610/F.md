 ## 解決策
 ## 問題の理解

 各エッジの重みが 1 または 2 である無向重み付きグラフが与えられます。私たちのタスクは、各エッジに方向を割り当てて、出ていくエッジと入ってくるエッジの合計がちょうど 1 だけ異なる頂点の数を最大化することです。これらの特別な頂点は Oddysey 頂点と呼ばれます。 

入力は次のもので構成されます`n`頂点と`m`エッジ。それぞれは 2 つの端点とその重みによって定義されます。 出力には 2 つのことが必要です。1 つ目は、達成可能な Oddysey 頂点の最大数であり、2 つ目は、次のようにエンコードされた一連のエッジ方向です。`1`エッジがそこから出た場合`u_i`に`v_i`そして`2`さもないと。 

まで`10^5`頂点とエッジ、すべてを試す強引なアプローチ`2^m`可能なエッジ方向は明らかに実行不可能です。 次の点で線形または線形に近い解決策が必要です。`n + m`。 微妙な点の 1 つは、グラフが切断されているか、同じ頂点ペアの間に複数のエッジが含まれている可能性があるため、ソリューションでは接続された各コンポーネントを個別に処理する必要があることです。 もう 1 つの注意が必要な部分は、合計の差がゼロ以外ではなく、正確に 1 であることを確認することです。 エッジの向きを不注意にすると、差が 0 または 1 を超える状態になり、美しさが損なわれる可能性があります。 

明白でないエッジ ケースには、1 つの頂点のみが Oddysey になることができる重み 2 の単一エッジ、または差分 0 または 2 の頂点が残らないように特定の向きを強制するすべてのエッジの重み 1 を持つ三角形が含まれます。もう 1 つのコーナーは、接続されていないコンポーネントです。各コンポーネントの Oddysey 頂点を個別に最大化する必要があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべてのエッジ方向を試みて計算します。`d^+ - d^-`各頂点について、Odyssey 頂点の最大数を追跡します。 と`m`エッジ、これにより、`O(2^m)`操作は困難です。 

重要な観察は、各エッジを端点の合計にプラスまたはマイナスのいずれかに寄与するものとして扱うことができ、オディシー条件では差の絶対値が正確に 1 である必要があるため、頂点は差の法 2 のパリティのみを気にするだけであるということです。これにより、問題は、重み付けされた 2 部グラフまたは一般的なグラフで次数のバランスをとるのと同様のグラフ方向付けタスクに縮小されます。 具体的には、重み 1 のエッジは差を ±1 で調整するように方向付けすることができ、重み 2 のエッジは ±2 で調整することができます。 各頂点での累積差が正確な法 2 であるという不変条件を維持しながら、深さ優先の方法で向きを慎重に伝播することで、最適な構成を保証できます。 

実際には、これは各連結成分にわたる DFS となり、各頂点の「現在の差分」がターゲット パリティと一致するようにエッジの方向を設定します。 複数の入射エッジを持つ頂点の場合、不変条件を維持するために方向を順番に選択し、Oddysey プロパティを満たすために必要に応じてエッジを反転します。 DFS は各エッジに 1 回アクセスするため、アプローチは次のように線形です。`n + m`。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^m) | O(n + m) | 遅すぎる |
 | DFS バランシング | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力を解析し、出力用にエッジの重みとインデックスを含む隣接リストとしてグラフを保存します。 エッジの方向と頂点の違いを追跡するために配列を初期化します。 
2. 各頂点を反復処理します。 未訪問の場合は、DFS を開始します。 DFS 関数は、各頂点での現在の差分合計を維持します。 
3. 各エッジについて`(u, v)`DFS では、ネイバーが訪問されていない場合、再帰的に DFS を続行します。 バランスをとるエッジの方向を決める`d^+ - d^-`両方の頂点に対して。 重み 1 の場合、現在の頂点の差を 1 増やす方向を割り当てます。重み 2 の場合、±2 を考慮して同様に方向を設定します。 
4. すべてのエッジを訪問した後、DFS は接続コンポーネント内のすべての頂点について、合計の差が 0 または ±1 であることを保証します。 差±1の頂点はOddyseyです。 
5. Oddysey 頂点をカウントし、割り当てられたエッジ方向を順番に出力します。 

機能する理由: DFS を介して向きの決定を慎重に伝播することにより、Oddysey 条件法 2 に違反する差異が残る頂点がないという不変条件が維持されます。各エッジが正確に 1 回考慮され、入射エッジに従って各頂点が調整されるため、DFS は後戻りすることなく最大限の美しさを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(1 << 25)

def solve():
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        edges.append([u, v, w])
        adj[u].append((v, w, idx))
        adj[v].append((u, w, idx))
    
    visited = [False] * n
    dir_edge = [0] * m
    diff = [0] * n
    
    def dfs(u):
        visited[u] = True
        for v, w, idx in adj[u]:
            if dir_edge[idx] != 0:
                continue
            if not visited[v]:
                dfs(v)
            # Orient edge from u->v if current diff[u] even
            if (diff[u] % 2) == 0:
                dir_edge[idx] = 1 if edges[idx][0] == u else 2
                diff[u] += w
                diff[v] -= w
            else:
                dir_edge[idx] = 2 if edges[idx][0] == u else 1
                diff[u] -= w
                diff[v] += w
    
    for i in range(n):
        if not visited[i]:
            dfs(i)
    
    beauty = sum(1 for x in diff if abs(x) == 1)
    print(beauty)
    print(''.join(map(str, dir_edge)))

if __name__ == "__main__":
    solve()
```コードはまず隣接リストとしてグラフを構築し、訪問した頂点、エッジの方向、および差分合計の配列を初期化します。 DFS は各頂点を訪問し、各頂点の現在の差が ±1 に向かうようにエッジ方向を割り当て、Oddysey 頂点を正確にカウントします。 エッジの再訪を避け、元のエッジ インデックスへの正しいマッピングを維持するように注意が払われます。
