 ## 解決策
 ## 問題の理解

 一連の「グループ隣接性」制約の下で有効な歌手の順列がいくつあるかを数えるように求められます。 

各歌手はそれぞれ異なる要素を持っています。$1$に$n$。 それらをすべて一列に並べなければなりません。 各友人は私たちに興味のある歌手のサブセットを提供し、最終行でそのサブセットのすべての歌手が部外者が邪魔することなく隣り合って表示される場合にのみ満足します。 グループ内の順序は重要ではありません。 重要なのは、それらが連続したセグメントを占めているという事実だけです。 

出力はすべての順列の数です。$n$すべての友人の制約を同時に満たす歌手 (法を適用)$998244353$。 

制約のサイズは小さいです。両方とも$n$そして$m$せいぜい$100$, しかし、これで問題がすぐに単純化されるわけではありません。 階乗サイズの検索空間が存在します ($n! \approx 10^{158}$で$n=100$) なので、順列を直接構築しようとするアプローチは不可能です。 

重要なのは制約の構造です。 各サブセット要件は位置に対してローカルではなく、置換にグローバルな「間隔制約」を課します。 複数のサブセット間の相互作用により、歌手を分離不可能なグループに統合する依存関係が作成されます。 

いくつかの特殊なケースについては、覚えておく価値があります。 

セットが全員歌手である友人が 1 人いる場合、シーケンス全体が 1 つのブロックとして自明に連続しているため、すべての順列が有効になります。 たとえば、$n=5$そして、ある友人はすべての歌手が好きです、答えはこうです$5!$。 

すべての友人がシングルトンを好む場合、単一の要素は常に連続しているため、すべての順列が有効になります。 これにより、$n!$。 

より微妙なケースは、制約が矛盾して重なっている場合です。 たとえば、$n=3$、友人が望むなら$\{1,2\}$連続した別の欲求$\{2,3\}$連続した場合$1,2,3$3 つすべてを明示的に要求する友人がいない場合でも、すべてが 1 つのブロックに収まる必要があります。 制約を独立して扱う単純なアプローチでは、この強制的なマージを見逃してしまいます。 

重要な問題は、制約が重なりを介して伝播し、明示的に与えられた構造よりも大きな分離不可能な構造を形成することです。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列が試行されます。$n$シンガーを検索し、すべてのサブセットが連続したセグメントとして表示されるかどうかをチェックします。 単一の順列をチェックするには、各サブセットをスキャンし、その要素が連続範囲を占めているかどうかを確認する必要があります。これは、次のように実行できます。$O(nm)$。 総費用は次のようになります$O(n! \cdot nm)$、これは実現可能な限界をはるかに超えています。 

中心的な観察は、制約が独立して機能しないということです。 2 つのサブセットがインターリーブ防止を強制する方法でオーバーラップする場合、それらの要素は効果的に結合されてより大きな構造になります。 このアイデアを繰り返し適用すると、歌手の最大の「分離不可能なコンポーネント」が生成されます。そのようなコンポーネント内では、少なくとも 1 つの制約を破らなければ、要素を異なる位置に分割することはできません。 

これは、問題を、オーバーラップ誘発クロージャの下で繰り返しセットがマージされるものとして捉えることを示唆しています。 これらのコンポーネントが識別されると、グローバルな順列がこれらのコンポーネントの順序付けになり、各コンポーネントは同じルールによって再帰的に内部的に制約されます。 

構造は自然に再帰的になります。各コンポーネントは自明であるか、同じロジックを使用してさらに分解できます。 マージのたびにコンポーネントのサイズが厳密に増加するため、再帰は終了します。 

直接実装では、順列の明示的な列挙を回避し、代わりに拡張と再帰によってこれらのコンポーネントを構築し、構造の拡大を強制する場合にのみ各制約が適用されるようにします。

 ## アルゴリズムのチュートリアル

 最小限の分離不可能なブロックを繰り返し抽出することでソリューションを構築します。 

1. 歌手のフルセットから始めます。 まだブロックに割り当てられていない最小のインデックス付き歌手を選択します。 このアンカーにより、決定論的な分解が保証されます。 
2. ワーキングセットを初期化する$C$この歌手だけが入っています。 
3. すべての友人のサブセットを繰り返しスキャンします。 サブセットが交差する場合$C$完全には含まれていませんが、展開してください$C$そのサブセットのすべての要素を追加することによって。 このステップでは、友人のグループがブロック内に部分的に入ることができないというルールを強制します。 
4. まで拡張を続けます。$C$変化が止まります。 この時点で、$C$交差するすべてのサブセットが完全に含まれるという制約の下で閉じられます。 
5. 内部の問題を再帰的に解決する$C$、完全にその範囲内にある制約のみを扱います。$C$。 
6. 削除する$C$残りの歌手からブロックを取得し、同じ手順を繰り返して他のブロックを取得します。 
7. すべてのブロックが形成されたら、各ブロックの有効な内部配置の数を掛け、さらにこれらのブロックを並べる方法の数を掛けて答えを計算します。 

ブロック順序に対する最終的な乗算が存在するのは、2 つの異なるブロックにまたがる制約がないためであり、最終的な並べ替えではブロックは独立したセグメントになります。 

### なぜ効果があるのか

 展開ステップでは、ハイパーエッジがフレンド サブセットであるハイパーグラフの下の頂点の閉包を計算します。 有効な置換では、各ハイパーエッジを完全に連続セグメント内に配置する必要があります。 ハイパーエッジが候補ブロックと部分的に重なる場合、その要素は分割できず、ハイパーエッジ全体が強制的に含められます。 このクロージャーを繰り返すことで、残りのすべての制約が完全に内部または完全に外部になることが保証されます。 

これにより、生成された各ブロックが制約によって引き起こされる分離不可能性に関して最小であることが保証され、有効な置換は少なくとも 1 つの制約に違反せずにその要素を分離できません。 その後、再帰によって各ブロック内に同じロジックが適用され、分解の完全性が保証されます。 

## Python ソリューション```python
import sys
sys.setrecursionlimit(1000000)
input = sys.stdin.readline

MOD = 998244353

n, m = map(int, input().split())
sets = []
for _ in range(m):
    tmp = list(map(int, input().split()))
    k = tmp[0]
    s = set(tmp[1:])
    sets.append(s)

all_mask = (1 << n) - 1

# bit representation
set_bits = []
for s in sets:
    mask = 0
    for x in s:
        mask |= 1 << (x - 1)
    set_bits.append(mask)

from functools import lru_cache

@lru_cache(None)
def solve(mask):
    if mask == 0:
        return 1

    # pick smallest element in mask
    u = (mask & -mask).bit_length() - 1

    comp = (1 << u)

    changed = True
    while changed:
        changed = False
        for s in set_bits:
            if s & comp:
                new_comp = comp | s
                if new_comp != comp:
                    comp = new_comp
                    changed = True

    rest = mask & ~comp

    # recursively solve
    return (solve(comp) * solve(rest)) % MOD

print(solve(all_mask))

再帰的分割中に同じサブセット構造が複数回出現する可能性があるため、メモ化は不可欠です。 キャッシュがなければ、再帰によって同じ状態が繰り返し再計算されます。

 ## 特殊なケース

 制約のない最小限の例:$n=1$、再帰は空またはシングルトン マスクで停止し、マージは行われないため、すぐに 1 を返します。 

すべての歌手が 1 つのセットに登場する完全に制約された例では、最初のクロージャ ステップでマスク全体が即座に拡張されます。 再帰は 1 回の呼び出しで終了し、結果は次のようになります。$n!$、すべての順列が単一の連続する要件を満たすという事実と一致します。 

たとえば、連鎖オーバーラップの場合$\{1,2\}$そして$\{2,3\}$は、クロージャが中間要素を介してどのように伝播するかを示しています。 1 から開始して、最初のセットには 2 を含めることを強制し、2 番目のセットには 3 を含めることを強制します。最後のブロックはセット全体になり、再帰ではそれ以上の分割は見られません。 

次のような素の制約の場合$\{1,2\}$そして$\{3,4\}$閉鎖が行き過ぎていないことを示しています。 各ブロックは独立したままであり、最終的な答えは、2 つのグループが任意の順序で連続したセグメントとして現れる順列を正確にカウントします。
