 ## 問題の理解

 整数のリストが与えられたので、同じ長さの別のリストを割り当てることが可能かどうかを判断したいとします。$b_1, b_2, \dots, b_n$、与えられたすべての数値が$a_i$の 2 つの値の差として表すことができます。$b$。 差分に使用されるインデックスは、$i$、そして同じ$b$要素は任意に何度でも再利用できます。 

したがって、要件はそうではありません$a_i = b_{i} - b_{i+1}$またはそのように構造化されたもの。 その代わりに、それぞれ$a_i$すべてのペアごとの違いのマルチセットのどこかに出現する必要があるだけです$b_j - b_k$。 

再フレームしました。配置できるかどうかを尋ねています。$n$頂点上の数値と、指定された値ごとの数値$a_i$、ラベルが正確に異なる 2 つの頂点を見つけます。$a_i$。 

制約$n \le 10$がキー信号です。 の順列を含む代入を明示的に検索しようとするソリューション$b$、または構築しようとします$b$決定論的な方法で貪欲に行うと、厳格すぎる可能性があります。 むしろ、これは十分に小さい宇宙なので、構造の選択に対する指数関数的な探索が実行可能です。 

微妙な問題は、同じことです$a_i$は異なる表現で複数回使用される場合があります。 また、複数の$a_i$同じインデックスのペアにマッピングされる場合があります$b$、再利用が許可されているため。 

素朴な推論を打ち破るエッジケースは通常、固定構造を仮定することから生じます。$b$。 たとえば、すべてが$a_i$非ゼロで別個の場合、それらを並べ替えられた配列内の隣接する差分として配置しようとする場合があります。$b$, しかし、違いはローカルではなくグローバルであるため、これは失敗します。 

線形チェーンの推移性を仮定すると、別の失敗例が現れます。$b_1 - b_2 = x$そして$b_2 - b_3 = y$、その後自動的に$b_1 - b_3 = x + y$これにより、入力には存在しない不要な差異が生じる可能性があります。 どのような構築でも余分な差異を許容する必要がありますが、少なくとも必要な差異が存在することを保証する必要があります。

 ## アルゴリズムのチュートリアル

 部分集合和の解釈に焦点を当てます。 

1. テスト ケースごとに、配列を読み取ります。$a$。 すべての値がゼロかどうかに基づいてロジックを分離します。 すべての値がゼロの場合、すべての制約は自己ループとして実現できるため、答えはすぐに「はい」になります。$b_j - b_j = 0$。 
2. 以下のインデックスのすべてのサブセットを列挙します。$0$に$2^n - 1$。 各サブセットは、次の候補グループを表します。$a_i$一つのサイクルとして実現しようとする価値観。 
3. サブセットごとに、選択したサブセットの合計を計算します。$a_i$。 合計がゼロでない場合、このサブセットは一貫したサイクルを形成できず、破棄されます。 
4. サブセットの和がゼロで空でない場合は、常に使用できます。 単一のエッジ サイクルは自己ループ経由でのみ有効であるため、要素が 1 つだけ含まれる場合はゼロにする必要があります。 
5. 有効なサブセットが見つかった場合は、YES を出力します。 存在しない場合は NO を出力します。 

それが機能する理由は、制約が潜在的な差異にどのように変換されるかによって決まります。 あらゆる有効な構造$b$それぞれが次のようなグラフを生成します。$a_i$重み付きの有向エッジに対応します$a_i$。 どのようなサイクルにおいても、差が伸縮するため、合計は強制的にゼロになります。 逆に、合計がゼロであるエッジのセットを選択した場合、サイクルの周りに増分頂点ポテンシャルを割り当てることでそれらをサイクルとして認識し、残りのエッジをツリーとしてアタッチすることができます。これにより、サイクル制約が導入されません。 ツリーは一貫した潜在的な割り当てを常に許容するため、実現可能性は完全にゼロ和サブセットを見つけることになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        if all(x == 0 for x in a):
            print("YES")
            continue

        found = False

        for mask in range(1, 1 << n):
            s = 0
            cnt = 0
            for i in range(n):
                if mask >> i & 1:
                    s += a[i]
                    cnt += 1

            if s == 0:
                if cnt >= 2:
                    found = True
                    break
                if cnt == 1 and s == 0:
                    found = True
                    break

        print("YES" if found else "NO")

if __name__ == "__main__":
    solve()
```このソリューションは、インデックスのすべてのサブセットを反復処理し、有効なサイクルに必要な合計条件が維持されるかどうかを確認します。 すべてゼロの特殊なケースにより、不必要な列挙が回避されますが、厳密には必須ではありません。 

サブセット ループは、選択したグループの合計とサイズの両方を構築します。 サイズ チェックにより、値がゼロの場合にのみシングルトン サブセットが通過し、自己ループの解釈と一致することが保証されます。

 ## 特殊なケース

 ゼロを含む単一要素の配列は、すべてゼロのショートカットによって処理されます。 の選択に対応します$b_1 = 0$、唯一の違いは次のとおりです。$0$。 

1 つの変数を使用すると、単一の値の差がゼロ以外になることはないため、単一の非ゼロ要素は常に失敗します。 差異がある場合は、少なくとも 2 つの異なるインデックスが必要です。 

合計がゼロであるが、フルセットの合計がゼロになる以外のサブセットがない混合配列も、フルセット自体が有効なサイクル候補を形成するため、依然として有効です。 

サブセットの選択は要素の同一性ではなく合計のみに依存するため、値が繰り返される配列の動作は変わりません。
