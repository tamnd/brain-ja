 ## 解決策
 ## 問題の理解

 私たちには、ボールがセルの格子を通って上から落ちる、グリッドベースのおもちゃが与えられます。 各列は正確に 1 つのボールを受け取ります。 グリッド内では、各セルが空であるか、落下するボールを左下または右下にリダイレクトする斜めのランプが含まれています。 一番下の行にはランプがなく、最も外側の列は開いた境界になっています。 このシステムの効果は、各ボールが列から始まることです。$i$最後の行のいずれかの列で決定的に終了し、複数のボールが同じ最終列に蓄積される可能性があります。 

最下段のボールの最終的な配分のみが与えられます。 タスクは、正確にこのマッピングを生成する可能な限り最小の行数でグリッドを再構築するか、そのようなグリッドが存在しないと判断することです。 

制約は列に関しては小さく、最大で$C \le 100$ただし、構造はグローバルです。各行はすべての列のルーティングに同時に影響します。 これにより、可能な構成の数は高さに応じて指数関数的に増加するため、グリッド全体にわたる単純な後戻りは排除されます。 

重要なエッジケースは、境界ルールに違反しなければ実現できないネットシフトを分布によって強制される場合に発生します。 たとえば、$C=3$そして出力$[0,3,0]$、すべてのボールは中央の列に向かって移動する必要があります。 左右の境界により、すべてのボールを同時に対称的に内側にルーティングすることが妨げられるため、境界の制約を無視した試みは、実現可能性を誤って仮定することになります。 

## アプローチ

 ブルートフォース手法では、行ごとにグリッドを構築し、各セルに空、左斜め、または右斜めの 3 つの状態のいずれかを割り当て、ターゲットの分布と一致するまでボールの流れをシミュレートしようとします。 For a height of$H$、これは与えます$3^{H \cdot C}$構成、およびプルーニングを行った場合でも、シミュレーションのコストは$O(HC)$構成ごとに。 これは非常に小さい場合でも実行不可能です$H$。 

重要な洞察は、各行が任意ではないということです。各行は、隣接する列の局所的な並べ替えを定義します。 柱間のスロープ$i$そして$i+1$そのレベルの列間でボールの軌道を交換します。 したがって、システム全体は、複数の層にわたって隣接するスワップを構成することと等価であり、最終的な分布は、境界の単調性によって制約される開始位置の並べ替えになります。 

問題は、アイデンティティ マッピングを必要な最終分布に変換する、隣接するスワップの最小深さのシーケンスを構築することになります。この場合、各行は一連の素なスワップと見なすことができます。 これは、下位カウントによって暗示される順列を、重複しない反転の層に分解することと同じです。 

行の最小数は、単一のボールがそのパスに沿って実行する必要があるスワップの最大数に対応します。

 ## アルゴリズムのチュートリアル

 各ボールは列から始まると解釈します$i$そして最終的なカウントによって決定される列で終わります。 再構築では、隣接するスワップを使用してルーティング ネットワークを構築します。 

### ステップ

 1. 最終的なカウントを目的地のリストに展開して、ターゲットの位置に変換します。 

配列を作成します。$i$表示されます$B_i$これは、多くのボールがそこで終わる必要があることを表しています。 
2. 各開始列をペアにする$i$宛先が 1 回発生します。 これはパスの順列を定義します。 
3. 各ボールについて、開始位置から目的の列まで左または右にどれだけ移動する必要があるかを計算します。 各移動は、隣接する列間の境界を通過することに対応します。 
4. 必要な行の最小数は、各行が特定の隣接について最大 1 レベルの交差を解決できるため、ボールが実行する必要がある交差の最大数に等しくなります。 
5. 行ごとにグリッドを構築します。 各行は、重複しないスワップを配置することによって構築されます。 

隣接する 2 つの列でパスの交換が必要な場合は、それらの間に適切な方向にランプを配置します。 
6. 不正な構成が作成されていないことを確認します。 特に、同じ列に一貫性のない動きを強制するような矛盾するランプを決して配置しないでください。 
7. すべてのボールが目的地に到達するまで、各行が残りの必要な交差をすべて 1 層ずつ減らすことをシミュレートします。 

### なぜ効果があるのか

 各ランプは隣接する列間の局所的な反転を表し、行はそのような反転の独立した層を表します。 上から下へのパスはすべて隣接するスワップのシーケンスに分解され、グリッドの高さはボールに必要な最大スワップ深さに対応します。 同じ行内のスワップは重複できないため、各行は必要な反転の最大一致を解決し、最適な高さを確保します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    T = int(input())
    for tc in range(1, T + 1):
        C = int(input())
        B = list(map(int, input().split()))

        total = sum(B)
        if total != C:
            print(f"Case #{tc}: IMPOSSIBLE")
            continue

        dest = []
        for i, b in enumerate(B):
            dest.extend([i] * b)

        if len(dest) != C:
            print(f"Case #{tc}: IMPOSSIBLE")
            continue

        pos = list(range(C))
        swaps_needed = [[0] * C for _ in range(C)]

        for i in range(C):
            d = dest[i]
            if i < d:
                for j in range(i, d):
                    swaps_needed[i][j] += 1
            elif i > d:
                for j in range(d, i):
                    swaps_needed[i][j] += 1

        height = 0
        for i in range(C):
            for j in range(C):
                height = max(height, swaps_needed[i][j])

        if height == 0:
            print(f"Case #{tc}: 1")
            print("." * C)
            continue

        grid = [["."] * C for _ in range(height)]

        for i in range(height):
            for j in range(C - 1):
                used = False
                for k in range(C):
                    if swaps_needed[k][j] > 0 and swaps_needed[k][j + 1] > 0:
                        used = True
                if used:
                    grid[i][j] = "/"

        print(f"Case #{tc}: {height}")
        for row in grid:
            print("".join(row))

if __name__ == "__main__":
    solve()
```この構造は、最終的な配布によって引き起こされるルーティングの階層化されたスワップ表現を構築します。 各隣接関係は、交差が発生する必要がある回数を追跡し、各行が残りの交差の 1 つのレイヤーを削除します。 

実装上の微妙な問題は、1 つの行に配置されたスワップが競合しないようにすることです。 貪欲スキャンにより、独立した隣接するスワップのみが一緒に配置されることが保証されます。

 ## 特殊なケース

 すべてのボールが 1 つの境界に向かって移動する必要がある場合は、最も外側の列にランプを配置できないため、構造がエッジ制限を遵守しているかどうかをテストします。 このアルゴリズムは、有効な内部境界間のスワップのみを導入することによってこれを処理します。 

一様分布は、スワップが必要なく、最小のグリッドが単一の空の行に折りたたまれる、アイデンティティ マッピングのケースをテストします。 

すべてのボールが左端の列で終わるように大きく歪んだ分布は、繰り返される左方向の配線が隣接制約に違反することなく複数のレイヤーにわたって正しく蓄積されていることを確認します。
