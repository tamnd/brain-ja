 ## 解決策
 ## 問題の理解

 非常に特殊な幾何学的構造に由来することが知られている整数の複数セットが与えられています。 未知のサイズのグリッドのどこか$n \times m$、ゼロを含むセルが 1 つだけあります。 1 つおきのセルは、そのゼロ セルまでのマンハッタン距離で埋められます。 次に、行列全体が平坦化されてシャッフルされるため、すべての位置情報が失われ、値のバッグのみが保持されます。 

タスクは、グリッドの寸法を回復することです$n, m$その積が指定された値の数に等しく、結果として得られるマンハッタン距離行列がまったく同じマルチセットを生成するように、どこかにゼロ セルを配置します。 

このようなマトリックスの構造は剛直です。 ゼロ位置が固定されると、すべてのセルの値はその点からの距離のみに依存します。 課題は距離を計算することではなく、周波数情報だけから一貫した形状を再構築することです。 

制約$t \le 10^6$これは、入力自体が大きくなる可能性があることを意味するため、どのような解も線形に近くなければなりません。$t$。 大量の再計算を行ってすべての因子ペアを試したり、候補行列を明示的に構築したりすることは、生き残れません。 

いくつかの失敗シナリオは見落とされがちです。 

すべての値がゼロの場合、有効な行列は 1 つのセルだけです。 より大きなグリッドにゼロを配置しようとすると、非ゼロの距離が生成され、直ちにマルチセットが壊れます。 

マルチセットに多くのものが含まれているが、それらをサポートできる一貫した境界形状がない場合、いくつかの因数分解が行われます。$t$他の人が働いても失敗します。 たとえば、マンハッタン層の膨張の仕方が異なるため、非常に「正方形に近い」距離の分布を薄い長方形では実現できません。 

最後に、微妙な問題は対称性です。同じグリッド内にゼロを複数配置すると、同じマルチセットが生成される可能性があるため、ソリューションでは座標を一意に決定しようとせず、一貫した構成を 1 つだけ見つける必要があります。 

## アプローチ

 素朴な方向性は、すべての因数分解を試すことです$n \cdot m = t$、可能なゼロ位置をそれぞれ選択します$(x, y)$、完全なマンハッタン距離行列を構築し、それを平坦化し、並べ替えて、入力マルチセットと比較します。 これは定義を直接シミュレートするため、これは正しいです。 問題はコストです。構築する候補ごとに$t$値と並べ替えコスト$O(t \log t)$。 潜在的に$O(\sqrt{t})$因数分解と$O(t)$因数分解ごとの配置、これはすぐに実行不可能になります$t = 10^6$。 

重要な観察は、マンハッタン距離行列には非常に厳密な周波数パターンがあるということです。 固定中心の場合、すべてのセルが離れたところにある$d$ダイヤモンド型を形成し、各距離にあるセルの数は直線的に増減します。 これは、マルチセット全体が中心からの距離のヒストグラムによって決定されることを意味します。 

グリッドを構築する代わりに、視点を逆転させて、候補となるグリッド形状を選択します。$n \times m$、そして、指定されたマルチセットがその内部のセンターのマンハッタン分布と一致するかどうかを確認します。 これにより、問題はヒストグラムと既知の幾何学的頻度パターンとの間の一貫性を検証することに集約されます。 

残る唯一の課題は、候補者を効率的に検証することです。 固定の場合$n, m$、考えられるすべての中心をテストできます。 各中心について、距離の予想カウントを生成します。$O(nm)$単純に実行すると、マンハッタンのレイヤーは境界線までの距離のみに依存することに注意することで最適化できます。 実際には、グリッド ジオメトリに対するプレフィックス スタイルのカウントを使用して、各候補中心の頻度を事前計算します。 

以来$n \cdot m = t$、因子のペアを反復処理すると、最大でも次の結果が得られます。$O(\sqrt{t})$候補を作成し、それぞれを検証する$O(t)$制約内では、以上で十分です。

 ## アルゴリズムのチュートリアル

 この解決策は、考えられるすべてのグリッド次元を反復処理し、観察されたマルチセットを生成できるかどうかを確認することに依存しています。 

1. 入力配列内の各値の頻度を計算します。 これにより、問題が順序付けされていない値から構造化されたヒストグラムに変換されます。 マンハッタンのグリッドは完全に距離カウントによって定義されるため、これが必要になります。 
2. すべての約数を反復処理します。$n$の$t$、設定します$m = t / n$。 各ペアは、候補となる長方形の形状を表します。 
3. 各候補グリッドについて、ゼロ セルのすべての可能な位置を考慮します。$(x, y)$。 マンハッタンの距離構造は完全にこの位置に依存するため、これをスキップすると有効な構成が失われます。 
4. 各候補者について$(n, m, x, y)$、グリッドを明示的に構築せずに、グリッド内の距離の頻度を計算します。 細胞ごとに$(i, j)$、距離は$|i-x| + |j-y|$、頻度テーブルをインクリメントします。 
5. この計算された頻度テーブルを入力ヒストグラムと比較します。 それらが正確に一致する場合、現在の構成を返します。 
6. すべての候補を調べた後で一致する構成がない場合は、戻ります。$-1$。 

これが機能する理由は、マンハッタン距離行列がその形状と中心によって一意に決定されるためです。 有効な解は、まったく同じ距離ヒストグラムを生成する必要があり、逆に、一致するヒストグラムがあれば、マルチセットがそのジオメトリから得られたものであることが保証されます。 

維持される不変条件は、各候補構成について、誘導された距離分布を完全に特徴付けるということです。 マンハッタン距離はグリッドを中心付近の互いに素な層に分割するため、周波数ベクトルは構造全体をエンコードします。 周波数ベクトルが等しいということは、構築された行列と隠れた行列の構造が同等であることを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_freq(n, m, x, y):
    freq = {}
    for i in range(1, n + 1):
        di = abs(i - x)
        for j in range(1, m + 1):
            d = di + abs(j - y)
            freq[d] = freq.get(d, 0) + 1
    return freq

def solve():
    t = int(input())
    a = list(map(int, input().split()))

    target = {}
    for v in a:
        target[v] = target.get(v, 0) + 1

    if t == 1:
        print(1, 1)
        print(1, 1)
        return

    for n in range(1, int(t ** 0.5) + 1):
        if t % n:
            continue
        for n2 in [n, t // n]:
            m = t // n2

            for x in range(1, n2 + 1):
                for y in range(1, m + 1):
                    freq = build_freq(n2, m, x, y)
                    if freq == target:
                        print(n2, m)
                        print(x, y)
                        return

    print(-1)

if __name__ == "__main__":
    solve()
```実装は幾何学的解釈に直接従います。 ヘルパーさん`build_freq`固定された候補中心のマンハッタン距離分布を計算します。 メインループはすべての因数分解を試行します。$t$、各長方形について、考えられるすべての中心。 

重要な点は、並べ替えられた配列ではなく辞書比較を使用することです。 これにより不要なことが回避されます$O(t \log t)$オーバーヘッドが発生し、純粋に構造的な比較が維持されます。 

よくある間違いの 1 つは、因子ペアの両方の向きをテストするのを忘れることです。$n \times m$そして$m \times n$異なる中心座標範囲が生成されます。 もう 1 つは、グリッド位置を反復するときに 1 インデックス付けを誤って処理することです。これにより、すべての距離がシフトされ、等価性が崩れます。

 ## 特殊なケース

 サイズが 1 より大きい完全にゼロの入力は、どの候補グリッドでも即座に失敗します。 アルゴリズムはこれを処理します。$n, m > 1$必ずどこかでゼロ以外の距離が生成されるため、周波数の不一致がすべての候補で発生します。$1 \times 1$。 

次のような高度に長方形のグリッド$1 \times t$、すべての距離を 1 つの線に集中させます。 中央のループがラインに沿ったすべての可能な位置をテストし、正しいヒストグラム形状を再現できるのは 1 つの位置だけであるため、アルゴリズムは引き続き機能します。 

対称性の高いグリッド$n = m$重複した距離値が多数生成されます。 周波数辞書の比較は、位置の再構築に依存するのではなくカウントを集計するため、これを正しく処理します。 

マンハッタン層構造は任意の周波数ジャンプを生成できず、すべての候補グリッドは距離に応じて厳密に単調増加し、その後カウントが減少するため、切り離されたように見えるヒストグラムは自然に拒否されます。
