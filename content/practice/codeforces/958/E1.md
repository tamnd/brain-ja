 ## 問題の理解

 平面内に 2 つの小さな点セットが与えられ、1 つは反乱軍の船を表し、もう 1 つは基地を表します。 各船は正確に 1 つの基地に割り当てられる必要があり、各基地も正確に 1 つの船を受け取る必要があるため、割り当ては 2 つのセット間の全単射となります。 ペアを選択したら、一致するペア間に直線セグメントを描きます。これらのセグメントの 2 つが端点以外の場所で交差しないようにする必要があります。 

タスクは、そのような交差しない完全な一致が存在するかどうかを判断することです。 

重要な制約は、両方のセットのサイズが最大 10 であることです。これにより、幾何学的なフローや重い組み合わせ論のようなものはすぐに除外され、置換に対する指数関数的な検索が実行可能であることが強く示唆されます。 10 ポイントの場合、全単射の数は 10 です。 これは約 360 万であり、各候補の一致は O(n²) または O(n log n) でチェックでき、これはまだ実現可能です。 

幾何学的制約により、微妙な特殊なケースが発生します。 3 つの点が同一線上にないため、交差テストがあいまいになる縮退は回避されますが、それでもセグメントが端点を共有したり、セグメントの内部で交差したりするケースを処理する必要があります。 

素朴だが誘惑しやすい間違いは、x または y 座標によるソートと一致によって貪欲に平面性が維持されると想定することです。 ローカルな選択により後で横断が強制される場合、これは失敗します。 もう 1 つの間違った考え方は、最も近いものを一致させることです。これにより、非常に小さな構成でも簡単に交差が発生する可能性があります。 

たとえば、船と基地が交互に配置され、凸状の四角形を形成する 4 つの点を考えてみましょう。 最も近い距離による貪欲なペアリングでは、境界に沿って交差しないマッチングが存在する場合でも、交差する対角線が生成される可能性があります。 

## アプローチ

 強引なアイデアは、艦艇の基地への可能な限りの割り当てを試みることです。 船舶に割り当てられたベースの順列ごとに、線分のセットを構築し、2 つの線分が交差するかどうかを確認します。 有効な割り当てが 1 つでも見つかった場合は、Yes を返します。 

これは正しいです。すべての有効な解は塩基の順列であるため、網羅的な検索ではすべての可能性がカバーされます。 ボトルネックは階乗増加です。R = B = 10 の場合、最大 10 までテストします。 割り当てがあり、それぞれに O(n²) の交差チェックが必要で、およそ 360 万回 100 回のチェックが必要になります。これはボーダーラインですが、最適化された Python ではプルーニングが使用されている場合にのみ許容されます。 

ただし、構造は純粋に組み合わせ的なものであり、ジオメトリは交差を検証するためにのみ使用されることに注意することで、より良い結果を得ることができます。 グラフのサイズが小さいため、主な改善点は交差制約を段階的に統合することです。 完全な順列をチェックする代わりに、一致する船を一度に 1 隻ずつ建造し、交差が作成された場合は部分的な割り当てを即座に拒否します。 これにより、総当りの順列列挙が枝刈りによるバックトラッキングに変換されます。 

枝刈りが効果的である理由は、交差をローカルに検出できることです。新しいセグメントを追加するときは、すでに選択されているセグメントと照合するだけで済みます。

 ## アルゴリズムのチュートリアル

1. 船を順序が固定されたものとして扱い、順列生成を通じてベースを割り当てますが、事前に完全な順列を列挙するのではなく、段階的に割り当てを構築します。 これにより、早期の拒否が可能になります。 
2. すでに使用されているベースとこれまでに形成されたセグメントのリストを維持します。 各セグメントは、船をその割り当てられた基地に接続します。 
3. 次の船に基地を割り当てようとするときは、新しいセグメントが以前に作成されたセグメントと交差するかどうかを確認します。 
4. 2 つのセグメント (a、b) と (c、d) は、方向が標準のセグメント交差条件を満たしている場合にのみ交差します。 3 つの点が同一線上にないため、同一線上にある重複ケースを処理しなくても、厳密な方向テストで十分です。 
5. 新しいセグメントが既存のセグメントと交差しない場合は、再帰的に次のシップに進みます。 
6. すべての船が正常に割り当てられた場合は、すぐに成功を返します。 
7. 完全に有効な一致につながる割り当てがない場合は、失敗を返します。 

### なぜ効果があるのか

 再帰のどの段階でも、部分一致は交差しないセグメントのセットを表します。 新しいセグメントが既存のセグメントと交差する場合、セグメントは固定ジオメトリ オブジェクトであるため、この部分割り当てを拡張してもその交差を修正できません。 したがって、そのような状態を枝刈りしても有効な解決策を排除することはできません。 逆に、有効な完全一致は交差を作成せずに段階的に構築できるため、すべての枝刈りステップに耐えることができます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def orient(ax, ay, bx, by, cx, cy):
    return (bx - ax) * (cy - ay) - (by - ay) * (cx - ax)

def intersect(a, b, c, d):
    ax, ay = a
    bx, by = b
    cx, cy = c
    dx, dy = d

    o1 = orient(ax, ay, bx, by, cx, cy)
    o2 = orient(ax, ay, bx, by, dx, dy)
    o3 = orient(cx, cy, dx, dy, ax, ay)
    o4 = orient(cx, cy, dx, dy, bx, by)

    return (o1 * o2 < 0) and (o3 * o4 < 0)

def solve():
    R, B = map(int, input().split())
    ships = [tuple(map(int, input().split())) for _ in range(R)]
    bases = [tuple(map(int, input().split())) for _ in range(B)]

    if R != B:
        print("No")
        return

    n = R
    used = [False] * n
    match = [-1] * n

    sys.setrecursionlimit(1000000)

    def dfs(i, segs):
        if i == n:
            return True

        sx, sy = ships[i]

        for j in range(n):
            if used[j]:
                continue

            ok = True
            for (a, b) in segs:
                if intersect(ships[a], bases[b], (sx, sy), bases[j]):
                    ok = False
                    break

            if not ok:
                continue

            used[j] = True
            segs.append((i, j))

            if dfs(i + 1, segs):
                return True

            segs.pop()
            used[j] = False

        return False

    print("Yes" if dfs(0, []) else "No")

if __name__ == "__main__":
    solve()
```ソリューションの中核は、船舶インデックス上の DFS であり、各船舶に一意のベースを割り当てます。 の`used`配列により全単射が確実に維持されます。 

の`intersect`関数は、方向 (外積符号) を使用して標準セグメント交差テストをエンコードします。 入力では 3 つの共線点が保証されていないため、厳密な符号比較のみが必要です。 

再帰では、基数に基づいて辞書編集順に代入を調べます。 ベースを割り当てるたびに、以前に選択したすべてのセグメントに対して検証して、交差が発生しないことを確認します。 この増分検証により、実際には検索が小規模に保たれます。 

微妙な点は、セグメントが座標ではなくインデックス ペアとして保存されることです。これにより、座標の繰り返しコピーが回避され、現在の部分一致との交差チェックの一貫性が保たれます。
