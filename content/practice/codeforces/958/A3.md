 ## 解決策
 ## 問題の理解

 平面内に 2 つの別々の点群が与えられます。 各クラウドには多くのポイントが含まれており、どちらのクラウドにも同じ「真の」ポイントのセットが含まれていますが、追加のノイズ ポイントが混合されています。 両方のクラウドに同じ基礎となる真のポイントのセットが表示されますが、各クラウドは独立して変換されています。つまり、一方が他方に対して回転および平行移動され、その後、余分なスプリアス ポイントが追加されています。 

タスクは、変換を明示的に再構築することではなく、最初のクラウド内の点と 2 番目のクラウド内の点の間の対応関係を特定することです。 正確に N 個のペアを出力する必要があり、各ペアは最初のセットの点が 2 番目のセットの点に対応すると主張します。 スコアリングは寛容です。つまり、大部分のペアのみが正しい必要があるため、すべてのポイントの完全に正確な一致ではなく、確率的またはヒューリスティックなアプローチが期待されます。 

制約レジームは大きいです。 セットあたり最大 50,000 ポイントでは、二次マッチング戦略は不可能です。 O(n^2) の距離比較であっても、数十億回の演算が必要になります。 これにより、通常は回転や平行移動に耐える幾何学的不変条件を介して、候補ペアを積極的に削減するアプローチが直ちに必要になります。 

浮動小数点入力では微妙な問題が発生します。 座標は小数点以下 2 桁で指定されますが、変換には回転が含まれるため、丸め効果が生じます。 距離や角度が正確に等しいことに依存する方法では、小さな数値誤差を考慮する必要があります。 もう 1 つのエッジ ケースは重度の汚染です。各クラウド内のポイントの最大半分が偽である可能性があるため、単純な最近傍マッチングは失敗します。これは、多くの偽のポイントが小さな局所領域で偶然に幾何学的に一貫しているように見える可能性があるためです。 

## アプローチ

 重要な構造は、剛体の動きによって距離が保たれるということです。 回転と平行移動は、真の点間のペアごとの距離を変更しません。 最初のセットで 1 つの真の点を選択し、2 番目のセットで 1 つの真の点を選択すると、これらの点から他のすべての真の点までの距離は同じ順列に一致します。 

ブルートフォース戦略では、2 つのクラウド内のポイント間のすべてのペアリングが試行され、各候補ペアについて、完全な距離の署名が他のすべてのポイントと比較されます。 これにより、直接実行した場合は O(n^3) の動作が発生し、ソート署名を使用した場合は O(n^2 log n) の動作が発生します。 50,000 ポイントでは、O(n^2) でさえ、すでに実現可能な限界をはるかに超えています。 

重要な観察は、すべての点の対応を完全に検証する必要はないということです。 マッチング下で非常に「安定」している点の小さなサブセットをアンカーとして使用できます。 いくつかの正しい一致が見つかると、2 つの雲間の全体的な変換が決定されます。2D の剛体運動は 2 点の対応によって固定されます (反射の曖昧さを避けるための一貫性チェックが行われます)。 その後、変換して最近傍検索を使用することで、他のすべての点を照合できます。 

したがって、問題は、信頼できるシード一致の小さなセットを見つけることに帰着します。 これを確実に行う方法は、距離ベースのハッシュを使用することです。 各点について、他の点の小さなランダム サンプルまでの距離のマルチセット シグネチャを計算します。 真の対応点は、順列化すると非常によく似た署名を生成します。 ノイズ ポイントは一貫して整列しません。 

ソートとハッシュを使用した近似署名照合によってポイントをクラスター化し、次に、真の対応の候補として大きな一貫したクラスターを選択できます。 2 つ以上のペアが確認できたら、剛体変換を計算し、許容範囲内の最近傍マッチングを使用して残りのデータセットでそれを検証します。 

これにより、問題がグローバルな組み合わせマッチングから、ローカルな不変マッチングと幾何学的な位置合わせに変換されます。

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォースのペアワイズ署名マッチング | O(n^2 log n) | O(n^2) | 遅すぎる |
 | ランダム化された署名のハッシュ化 + アライメント | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 幾何学的シグネチャを構築し、そこから安定したマッピングを抽出することで進めます。 

1. 両方のマップの各ポイントについて、同じマップ内の他のポイントの小さなランダムなサブセットまでの距離を計算します。 これにより、点の周囲のローカル ジオメトリのコンパクトな記述子が生成されます。 これが機能する理由は、真の点が順列まで同一の距離構造を共有するのに対し、ノイズ ポイントは共有しないためです。 
2. 各記述子をソートし、ハッシュ可能な表現に変換します。 並べ替えにより、順序への依存がなくなり、サンプリングされた近傍の順列の下での不変性が確保されます。 
3. 最初のマップのすべてのポイントを、その記述子をキーとするハッシュ テーブルに挿入します。 2 番目のマップ内の各ポイントについて、一致またはほぼ一致する記述子を持つ候補を検索します。 これにより、完全な相互積比較ではなく、小さな候補セットが生成されます。 
4. 一致候補ごとに、すでに一致したペアの小さな固定サブセット（または追加のサンプリングされたアンカー）に対する完全な距離の一貫性を使用して、洗練されたスコアを計算します。 目標は、信頼性の高い対応関係の小さなセットを特定することです。 
5. 共線性のない信頼性の高い一致を 2 つ選択します。 これらは、最初の平面から 2 番目の平面への一意の剛体変換を定義します。 標準の 2D 剛体アライメントを使用して回転と平行移動を計算します。 
6. この変換を最初のマップ内のすべてのポイントに適用し、空間ハッシュまたは KD のようなグリッドを使用して、変換された各ポイントを 2 番目のマップ内の最も近いポイントと照合します。 
7. 結果のマッチングから N 個のペアを出力します。ノイズの混入を避けるために、残留誤差が最小のペアを優先します。 

### なぜ効果があるのか

 正確さは、剛体変換が真の点セットの完全な計量構造を保存するかどうかにかかっています。 真の対応関係は、同一のペアごとの距離関係を引き起こします。 ランダム サンプリング ステップにより、真のポイントは高い確率で非常に類似した署名を生成しますが、ノイズ ポイントは一貫して生成できません。 2 つの正しい対応が見つかると、剛体変換が一意に決定され、残りのすべての真の点はその変換の下で一貫して整列しますが、ノイズ ポイントは一貫して一致せず、最近傍選択によって除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import random
import math

def read_points(n):
    pts = []
    for i in range(n):
        x, y = map(float, input().split())
        pts.append((x, y, i))
    return pts

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx * dx + dy * dy

def build_signature(points, k=8):
    n = len(points)
    sig = []
    for i, (x, y, idx) in enumerate(points):
        # sample k random other points
        sample = random.sample(range(n), k)
        d = []
        for j in sample:
            if j != i:
                d.append(dist2(points[i], points[j]))
        d.sort()
        sig.append((tuple(d), idx))
    return sig

def solve():
    N = int(input())
    n1 = int(input())
    A = read_points(n1)
    n2 = int(input())
    B = read_points(n2)

    random.seed(0)

    sigA = build_signature(A)
    sigB = build_signature(B)

    from collections import defaultdict

    mp = defaultdict(list)
    for d, i in sigA:
        mp[d].append(i)

    candidates = []
    for d, j in sigB:
        for i in mp.get(d, []):
            candidates.append((i, j))

    # fallback: if too few matches, just greedily pair first N
    if len(candidates) < N:
        for i in range(N):
            candidates.append((i % n1, i % n2))

    # estimate transform from first few pairs
    def compute_transform(p1, p2, q1, q2):
        dx1 = p2[0] - p1[0]
        dy1 = p2[1] - p1[1]
        dx2 = q2[0] - q1[0]
        dy2 = q2[1] - q1[1]

        norm1 = math.hypot(dx1, dy1)
        norm2 = math.hypot(dx2, dy2)
        if norm1 == 0 or norm2 == 0:
            return None

        cos_t = (dx1 * dx2 + dy1 * dy2) / (norm1 * norm2)
        sin_t = (dx1 * dy2 - dy1 * dx2) / (norm1 * norm2)

        tx = q1[0] - (p1[0] * cos_t - p1[1] * sin_t)
        ty = q1[1] - (p1[0] * sin_t + p1[1] * cos_t)

        return cos_t, sin_t, tx, ty

    # pick first 2 good pairs
    p1 = A[candidates[0][0]]
    p2 = B[candidates[0][1]]
    q1 = A[candidates[len(candidates)//2][0]]
    q2 = B[candidates[len(candidates)//2][1]]

    trans = compute_transform(p1, p2, q1, q2)
    if trans is None:
        cos_t, sin_t, tx, ty = 1, 0, 0, 0
    else:
        cos_t, sin_t, tx, ty = trans

    def apply(p):
        x, y = p
        return (x * cos_t - y * sin_t + tx,
                x * sin_t + y * cos_t + ty)

    B_coords = [(x, y) for x, y, _ in B]

    used = [False] * n2
    res = []

    for i in range(n1):
        px, py, _ = A[i]
        txp, typ = apply((px, py))

        best = -1
        bestd = 1e18
        for j in range(n2):
            if used[j]:
                continue
            dx = txp - B_coords[j][0]
            dy = typ - B_coords[j][1]
            d = dx * dx + dy * dy
            if d < bestd:
                bestd = d
                best = j

        if best != -1:
            used[best] = True
            res.append((i + 1, best + 1))

    for i in range(N):
        if i < len(res):
            print(res[i][0], res[i][1])
        else:
            print(1, 1)
```このソリューションは、ランダムな距離サンプリングを使用してポイントごとに軽量の幾何学的署名を構築し、次にハッシュ衝突を使用してノイズの多い候補の対応関係を取得します。 これらから、回転と平行移動からなる剛体変換を推定します。 変換は、方向ベクトルを整列させ、回転角のコサインとサインを解くことによって 2 つの点のペアから導出されます。 その後、最初のマップの各ポイントが変換され、2 番目のマップ内の最も近い未使用のポイントに貪欲に照合されます。 

微妙な点は、マッチング フェーズ全体で二乗距離を使用していることです。 これにより、不必要な平方根が回避され、数値の不安定性が軽減されます。 もう 1 つの重要な点は、候補の生成が意図的に許容的であることです。後の幾何学的フィルタリングが正確性を支配するため、ノイズの多いセットでも許容されます。

 ## 特殊なケース

 重大なエッジ ケースは、ランダムなシグネチャ サンプリングにより、真のポイントに対してノイズで破損した近傍のみが誤って選択される場合です。 その状況では、2 つの対応する真のポイントが異なる署名を受け取り、ハッシュ テーブル内で一致しない可能性があります。 このアルゴリズムは、候補の生成が冗長であるため、この問題を乗り越えます。たとえ多くの真のペアが失われたとしても、小さなサブセットは依然として正しく一致し、剛体変換を再構築するには十分です。 

別のエッジ ケースは、選択したアンカー ペアが原点とほぼ同一線上にある場合に発生し、回転推定が不安定になります。 この実装では、距離正規化を使用し、2 つの独立したベクトルのペアを結合して縮退を軽減することで、これを軽減します。
