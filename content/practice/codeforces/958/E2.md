 ## 問題の理解

 私たちは、ハイジが一時的にハイパースペースを離れる瞬間の厳密に増加するシーケンスを与えられます。 これらの瞬間は、会議を開始または終了できる唯一の有効なエンドポイントです。 ハイジは正確に整理しなければなりません$K$独立した会議。各会議は 2 つのインデックスを選択することによって定義されます。$i < j$そして間隔を割り当てる$[t_i, t_j]$。 2 つの会議が時間的に重なってはならず、エンドポイントでの接触さえも禁止されているため、1 つの会議が次の時間に終了した場合、$t_i$、他の会議は次の時間に開始または終了することはできません。$t_i$。 

各会議には、その期間に等しい費用がかかります$t_j - t_i$、そして目的はペアリングすることです$2K$選択した時点のポイント$K$長さの合計が最小になるように、重複しない間隔を設定します。 

重要な構造は、ソートされた配列からペアを選択し、交差しないセグメントを形成し、可能な限り最小の差分の合計を求めるということです。 

制約は大きいです:$N$最大500000まで可能で、$K$これにより、すべてのペアリングを試行したり、すべてのエンドポイントに対して二次動的計画法を使用したりするソリューションは即座に除外されます。 平$O(NK)$定数によっては境界線になる場合もありますが、慎重に移行すれば許容できる場合がほとんどです。 関わるものなら何でも$O(N^2)$または、すべての間隔一致を列挙することは不可能です。 

微妙なエッジ ケースは、「共有エンドポイントなし」という制約から生じます。 これを忘れた場合、隣接する要素を貪欲にペアリングしようとする可能性がありますが、最適なペアリングでは要素がスキップされる可能性があるため、これは常に有効であるとは限りません。 もう 1 つの失敗例は、常にペアリングする必要があると想定していることです。$t_i$と$t_{i+1}$これはグローバル構造を無視します。場合によっては、far 要素を早期にペアにすることで、将来のギャップを小さくすることができます。

```貪欲な隣接ペアリングにより、$[1,2]$そして$[100,101]$、 料金$1 + 1 = 2$。 これは実際には最適ですが、次のように変更します。```
t = [1, 10, 11, 12, 20, 21]
```隣接する貪欲な与えます$[1,10], [11,12], [20,21]$K=3 の場合、コストが得られます$9+1+1=11$、しかしペアリング$[10,11], [12,20]$構造は、ペアリングの選択が残りのギャップに影響するため、貪欲は一般に安全ではないことを示しています。 

正しいソリューションでは、どのポイントが使用され、どのようにペアになるかをグローバルに決定する必要があります。 

## アプローチ

 ブルートフォースアプローチでは、選択しようとします$2K$からのポイント$N$そしてそれらを最適にペアリングします。 サブセットを修正したとしても、ソートされた順序で最適にペアにするのは簡単ですが、サブセット自体の選択は組み合わせになります。 選択する方法の数$2K$ポイントは$\binom{N}{2K}$、これは天文学的に大きいです$N = 500000$。 中程度の場合でも$K$、これは不可能です。 

点はすでにソートされており、間隔は重複できないという構造を利用する必要があります。 これは動的プログラミングの解釈を示唆しています。ペアを決定すると、問題が左右のセグメントの独立した部分問題に分割されます。 

重要な観察は、最適なソリューションでは、選択したエンドポイントを並べ替えると、ペアリングは常に、何らかの構造化された方法で連続した選択された要素間で行われるということです。 さらに重要なのは、すでに形成されている間隔の数を追跡しながら、新しい間隔を開始するか終了するかを決定して、左から右にソリューションを構築することを考えることができます。

重要な改良点は、問題を選択として再解釈することです。$2K$ポイントを取得し、それらを順番に貪欲にペアリングすることで、その誘導された構造内で一致するペア間の距離を合計するコストが削減されます。 これにより、DP を古典的な「エンドポイントの選択」最適化に変換することができ、次のペアを開始する前にスキップする要素の数だけを考慮する必要があります。 結果として生じる反復は、プレフィックス構造とローリング DP を使用して効率的に計算できます。

 ## アルゴリズムのチュートリアル

 ソートされた配列を左から右に処理し、正確にどのように形成するかを決定する動的プログラミング状態を維持します。$k$素のペア。 

1. 定義する$dp[k][i]$形成するための最低限のコストとして$k$最初のペアを使用する$i$タイムポイント。 これにより、プレフィックスの中からエンドポイントを選択する有効な方法がすべてキャプチャされます。 

間隔が交差できないため、順序付けは重要です。そのため、有効な構造はインデックスの順序を尊重する必要があります。 
2. 位置で$i$、私たちはどちらかを使用しません$t_i$、またはペアの右エンドポイントとして使用します。 これを使用しない場合は、以前の値を継承します。$dp[k][i] = dp[k][i-1]$。 
3. 弊社が利用することにした場合$t_i$エンドポイントとして、以前の未使用のポイントとペアにする必要があります$t_j$、 どこ$j < i$。 費用負担額は、$t_i - t_j$。 したがって、以前の有効なすべてを試します$j$それは第 2 のエンドポイントとして機能する可能性があります。$k$-番目のペア。 
4. すべてを明示的に繰り返す代わりに$j$、最適な候補構造を維持します。$i$、これまでのところ最適にポイントを選択していることを表す、最良の「オープン」エンドポイント状態を維持していると解釈できます。 これにより、状態ごとに償却定数時間で遷移を計算できるようになります。 
5. 繰り返します$k$1 から K まで、各位置に対して DP を昇順に更新します。$i$、トランジションが前のレイヤーにのみ依存するようにします$k-1$。 
6. 最終的な答えは次のとおりです。$dp[K][N]$、完全なシーケンスからすべてのペアを選択する最良の方法を表します。 

### なぜ効果があるのか

 重要な不変条件は、最適なソリューションはすべて、$2K$インデックスを作成し、ソートされた順序でそれらをペアにします。各ペアは、選択された点の誘導サブシーケンス内の連続セグメントに対応します。 コストを増加させることなく交差はいつでも削除できるため、最適なペアリングは非交差であると想定できます。 これにより、左から右に処理するときに、セグメントが閉じられた後に以前のペアリングの決定を再検討する必要がなくなることが保証されます。 したがって、DP は、構成を見逃すことなく、すべての最適な構造を完全にキャプチャします。

        # We maintain auxiliary array per k using running minimum

        # we rebuild DP with correct O(NK) formulation.

 ## 特殊なケース

 エッジ ケースの 1 つは、最適なペアリングで明らかな隣接する一致をスキップする必要がある場合に発生します。 入力の場合:```
