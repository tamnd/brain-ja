 ## 解決策

 ## 問題の理解

 各船は、最大 5 次元の空間にベクトルの小さなコレクションを提供します。 これらのベクトルからすべての線形結合を考慮するため、すべての船は部分空間、つまり、指定されたジェネレーターを組み合わせることで到達できるすべてのベクトルのセットを定義します。 

このタスクは、生成された部分空間が同一である場合に 2 つの船が正確に同じラベルを受け取るように、船にラベルを割り当てることです。 異なる入力セットが同じ部分空間を生成する可能性があるため、各生成セットをそれがまたがる部分空間の正規表現に正規化してから、同一のものをグループ化する必要があります。 

2 番目の要件は、単にグループ化するだけではなく、辞書編集上最小の有効なラベルを作成することです。 これは、新しい部分空間に遭遇したときに、以前の割り当てと一致する可能な限り最小のラベルを割り当てることを意味します。 

主な問題点は、部分空間を生のジェネレーターから直接比較できないことです。 2 つの異なるベクトルのセットは、実際には同じ空間に広がっているにもかかわらず、無関係に見える場合があります。 単純な試みでは、船舶の各ペア間の線形システムを解くことでスパンを比較することになりますが、船舶の数が最大 30,000 隻になる可能性があるため、これでは非常に時間がかかりすぎます。 

次元が最大 5 であることが重要な制約です。 これにより、シップごとに一定時間でガウス消去法を使用して、各部分空間の安定した正規基底を計算できます。 

船舶が冗長なベクトル、または他のベクトルの線形結合であるベクトルを提供する場合、微妙なエッジ ケースが発生します。 たとえば、次元 2 では、セットは`{(1,0), (2,0)}`そして`{(1,0)}`同じ部分空間を定義します。 正しいソリューションでは、冗長性を完全に排除する必要があります。 そうしないと、生の入力をハッシュすると、同等の部分空間が異なるものとして誤って扱われてしまいます。 

もう 1 つの問題は順序付けです。ハッシュ化するには、2 つの正規ベースがバイトごと (または座標ごと) に同一である必要があります。 同じ部分空間に対して異なる基底を選択した場合でもグループ化が崩れるため、表現は決定論的である必要があります。 

## アプローチ

 直接的なアプローチでは、スパンが等しいかどうかを確認することによって、すべてのペアの船舶を比較します。 2 つの部分空間が等しいことをテストするには、一方の各生成器がもう一方のスパン内にあるかどうかを確認します。これには、最大 5 サイズの線形システムを解く必要があります。 このテストは一定時間ですが、O(m²) 個のペアがあり、最悪の場合には約 4 億 5,000 万回の比較が行われることになり、これでは遅すぎます。 

より良い観点は、ベクトルの各セットをその部分空間の正準表現に変換することです。 次元が小さいため、各セットに対して個別にガウス消去法を実行して基底を抽出できます。 すべての部分空間が一意の縮小基底で表されると、等価性はこれらの基底の等価性になります。 

重要な観察は、固定次元でのガウス消去法が決定論的な縮小行階層形式を生成するということです。 ベクトルを並べ替えたり、一貫して処理したりすると、入力の冗長性や順序に関係なく、各部分空間は同じ標準基底に崩壊します。 

正規化後、各基底をハッシュし (たとえば、タプルのタプルに変換することによって)、辞書を使用して、辞書編集上の最初の出現順にグループ ID を割り当てることができます。

 ## アルゴリズムのチュートリアル

 私たちは最大 5 次元のベクトル空間で作業するため、すべての線形代数演算は一定サイズになります。 

1. 各船について、その k ベクトルを読み取り、それらを作業リストとして保存します。 目標は、このリストをそのスパンの基礎に変換することです。 
2. これらのベクトルに対してガウス消去法を実行し、漸進的に縮小基底を構築します。 私たちはリストを管理しています`basis`最初は空です。 
3. 船の入力内の各ベクトルについて、それを基底に挿入してみます。 既存の基底ベクトルを使用してベクトルを削減し、以前に選択したピボットに沿ったコンポーネントを削除します。 ゼロ以外になると、新しい独立した方向に寄与し、新しい基底ベクトルとして追加されます。 
4. すべてのベクトルを処理した後、結果の基底を正規化して、決定論的な形式になります。 標準的な選択は、ピボット位置が一貫しており、ベクトルが相互に縮小されていることを確認することです。 これにより、同一の部分空間が常に同一の塩基を生成することが保証されます。 
5. 基底をハッシュ可能な構造、たとえば、ピボット検出の順序を維持しながら、整数のタプルのタプルに変換します。 
6. この正規表現をグループ ID にマッピングする辞書を使用します。 このベースが以前に見られたことがある場合は、その ID を再利用します。 それ以外の場合は、新しいものを昇順に割り当てます。 
7. 割り当てられたidを入力順に出力します。 

この順序付け戦略が辞書編集上の最小限性を保証する理由は、最初に遭遇したときに常に利用可能な最小のラベルを割り当て、以前の船にラベルを付け直すことがないためです。 

### なぜ効果があるのか

 正しさは、ガウス消去法が固定の決定論的規則の下で実行されたときに各部分空間の正規基底を生成するという事実にかかっています。 追加されるすべてのベクトルはスパンを増やすか冗長であり、冗長なベクトルは完全に削除されます。 したがって、2 つのベクトルのセットは、それらの換算された基底が正確に一致する場合に限り、同じ部分空間を生成します。 基底構造は入力順序ではなくスパンのみに依存するため、同じ部分空間の異なる表現の下では不変です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def normalize(vectors, d):
    basis = []
    for v in vectors:
        v = v[:]  # copy
        for b in basis:
            # eliminate component along b
            # find pivot position
            for i in range(d):
                if b[i] != 0:
                    piv = i
                    break
            if v[piv] != 0:
                factor = v[piv] / b[piv]
                # avoid floats: integer elimination
                # scale subtraction
                for i in range(d):
                    v[i] = v[i] * b[piv] - b[i] * v[piv]
        if any(x != 0 for x in v):
            # normalize v
            # find pivot
            for i in range(d):
                if v[i] != 0:
                    piv = i
                    break
            # make pivot positive
            if v[piv] < 0:
                for i in range(d):
                    v[i] = -v[i]
            basis.append(v)
    # final cleanup: sort by pivot for determinism
    basis.sort(key=lambda x: next(i for i, val in enumerate(x) if val != 0))
    return tuple(tuple(row) for row in basis)

def solve():
    m, d = map(int, input().split())
    mp = {}
    res = []
    next_id = 1

    for _ in range(m):
        k = int(input())
        vecs = [list(map(int, input().split())) for _ in range(k)]
        key = normalize(vecs, d)
        if key not in mp:
            mp[key] = next_id
            next_id += 1
        res.append(mp[key])

    print(*res)

if __name__ == "__main__":
    solve()
```コードは各シップを個別に処理します。 の`normalize`関数は、ベクトルを段階的に挿入し、依存する方向を削除することによって基礎を構築します。 整数演算では、除算の際に除算ではなくスケーリングを行うことで、浮動小数点の不安定性を回避します。 

ピボットを選択すると、各基底ベクトルが明確に定義された先頭の非ゼロ座標を持つことが保証されます。 最後にソートすると、ハッシュ化に必要な基底ベクトルの一貫した順序が保証されます。 

辞書は正規表現を ID にマッピングし、最初に見た順序を自動的に保持するため、辞書編集的に最小限のラベル付けが行われます。

 ## 特殊なケース

 典型的な失敗例は、ベクトルがスケーリングだけが異なる場合です。 例えば`(1,0)`そして`(2,0)`正規化後は同一でなければなりません。 消去ステップによりこれが保証されます。`(2,0)`のスカラー倍数に減ります`(1,0)`and becomes redundant when inserted into the basis.

 Another issue arises when vectors are linearly dependent in non-obvious ways. 3次元では、`(1,0,0)`、`(0,1,0)`、`(1,1,0)`すべては最初の 2 つのベクトルと同じ平面にまたがります。 アルゴリズムは 3 番目のベクトルを削除します。これは、既存の基底への射影後に 0 になるため、最終的な表現は安定したままになります。 

3 番目の微妙なケースは、入力ベクトルの順序が一貫していないことです。 ガウス消去法は基底を増分的に構築しますが、ピボット位置によってソートするため、同じ生成セットの順列は同じ最終的な正規基底を生成し、異なる入力間で一貫したグループ化が保証されます。
