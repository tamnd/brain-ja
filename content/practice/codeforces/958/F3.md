 ## 解決策

 ## 問題の理解

 ライトセーバーのマルチセットが与えられ、各セーバーは次のいずれかに属します。`m`色。 同じ色は同じオブジェクトを意味するため、どのジェダイがサーベルを提供するかではなく、各色のサーベルが何本選択されるかのみを考慮します。 

タスクは、正確に選択することによって、いくつの異なる「カラーカウント構成」を形成できるかを数えることです。`k`与えられたサーベル`n`、各構成は長さのベクトルです`m`各色のサーベルが何本選ばれたかを説明します。 両方の選択ですべての色が同じ回数出現する場合、2 つの選択は同じとみなされます。 

同様に、各色について`i`、表示された場合`cnt[i]`入力で整数を選択します`x_i`そのような`0 ≤ x_i ≤ cnt[i]`そして`sum x_i = k`。 答えは、そのような有界整数解の数です。 

制約は大きいです:`n`最大 200,000 まで指定できるため、サブセットを列挙したり、色とカウントに対してネストされたループを使用したりするアプローチは即座に除外されます。 平`O(nk)`どちらも大きくなる可能性があるため、最悪の場合は遅すぎます。 

微妙な問題は、同じ色が寄与を区別できないことです。 要素上の単純なサブセット DP は、慎重に周波数に圧縮しない限り、同じ色の順列を過剰にカウントします。 

多くのジェダイが同じ色を共有している場合、別の特殊なケースが発生します。 たとえば、すべてが`n`サーベルの色が 1 であれば、答えは単純に 1 になります。`k ≤ n`要素を独立して扱うアプローチでは、同一の項目の組み合わせが異なるものとして誤ってカウントされます。 

## アプローチ

 直接的な定式化は、生成関数の観点から考えることです。 各色`i`多項式に寄与します。```
P_i(x) = 1 + x + x^2 + ... + x^{cnt[i]}
```有効なコレクションを選択することは、各多項式から 1 つの項を選択し、それらを乗算することに相当します。`x`結果として得られる製品には、選択されたサーベルの合計数が表示されます。 したがって、答えは次の係数です。`x^k`で：```
P_1(x) * P_2(x) * ... * P_m(x)
```ブルートフォース手法では、これらの多項式を 1 つずつ乗算します。ここで、同じサイズの 2 つの多項式を乗算します。`a`そして`b`費用`O(ab)`。 最悪の場合、多くの色のカウントが大きい場合、これはおおよそ次のように劣化します。`O(n^2)`動作が遅すぎます。 

重要な観察は、各多項式が 1 の連続したブロックであるということです。 これにより、畳み込み構造が非常に規則的になります。つまり、「すべて 1」のセグメントを繰り返し乗算することになりますが、これは FFT ベースの畳み込みを使用して効率的に処理できます。 

単純な方法で順次乗算する代わりに、分割統治畳み込みツリーを実行します。 各マージ ステップで、FFT 畳み込みを使用して 2 つの中間多項式を結合します。 これにより、総作業量が次のように削減されます。`O(k log k log m)`多項式の次数は次によって制限されるため、実装の詳細に応じて、または同様のことが行われます。`k`。 

FFT が機能するのは、畳み込みが色間で独立した選択肢を組み合わせることに正確に対応しているためです。 各マージ ステップでは、多項式が有効な部分選択をエンコードするという不変条件が保持されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(nk) またはそれ以上 | O(k) | 遅すぎる |
 | 分割統治型 FFT | O(k log k log m) | O(k) | 承認済み |

 ## アルゴリズムのチュートリアル

 入力を周波数カウントに圧縮します`cnt[color]`。 

各色を多項式として解釈します`P_i(x)`長さの`cnt[i] + 1`、すべての係数は 1 に等しい。 

### ステップ

 1. 各色の出現数を数えます。 これにより、入力が次のように変換されます。`m`周波数の値。 このステップにより、順序への依存が取り除かれ、問題が独立した組み合わせブロックに軽減されます。 
2. 多項式のリストを色ごとに 1 つ作成します。各多項式は長さの多項式の配列として表されます。`cnt[i] + 1`。 これは、0 と 0 の間を選択するすべての可能な方法をエンコードします。`cnt[i]`その色のサーベル。 
3. 分割統治法を使用して多項式を再帰的にマージします。 各再帰ノードで、リストを 2 つの半分に分割し、それらの結合多項式を計算して、それらを畳み込みます。 この構造により、バランスのとれた FFT の使用が保証され、繰り返しの再計算が回避されます。 
4. FFT モジュロ 1009 を使用して畳み込みを実行します。モジュラスが小さく、FFT に適していないため、数論変換スタイルの適応、または丸めとモジュラー リダクションを伴う複雑な FFT を使用します。 
5. すべてのマージ後、次の係数を抽出します。`x^k`。 この値は有効な選択の数です。 

分割統治が重要な理由は、連鎖的に多項式を繰り返し乗算すると、大きな中間結果が繰り返し畳み込まれ、コストが増大するためです。 バランスの取れたマージにより、多項式のサイズが制御されます。 

### なぜ効果があるのか

 すべてのマージ ステップで、色のセグメントに対して保存された多項式は、そのセグメントから特定の合計数のサーベルを選択する方法の数を正確に表します。 2 つのセグメントが結合される場合、畳み込みは合計を分割するすべての方法を正しくカウントします。`k`左右のセグメントからの寄与に変換します。 これにより、次数における多項式係数の不変式が維持されます。`t`有効な選択の数の合計に等しい`t`そのセグメントに対して。 ツリー全体がマージされると、この不変式は、結合されたすべての色の答えを直接与えます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 1009

def fft_convolve(a, b, mod=MOD):
    n, m = len(a), len(b)
    res = [0] * (n + m - 1)
    for i in range(n):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(m):
            res[i + j] = (res[i + j] + ai * b[j]) % mod
    return res

def merge(polys):
    if len(polys) == 1:
        return polys[0]
    mid = len(polys) // 2
    left = merge(polys[:mid])
    right = merge(polys[mid:])
    return fft_convolve(left, right)

def solve():
    n, m, k = map(int, input().split())
    arr = list(map(int, input().split()))

    cnt = [0] * (m + 1)
    for x in arr:
        cnt[x] += 1

    polys = []
    for i in range(1, m + 1):
        if cnt[i] > 0:
            polys.append([1] * (cnt[i] + 1))

    if not polys:
        print(1 if k == 0 else 0)
        return

    res = merge(polys)
    if k < len(res):
        print(res[k] % MOD)
    else:
        print(0)

if __name__ == "__main__":
    solve()
```この実装では、まず入力が頻度カウントに圧縮され、Jedi のアイデンティティが削除され、色の多重度のみが保持されます。 各色はすべて 1 の多項式に寄与し、その色からのすべての有効な選択を表します。 

の`merge`関数は、多項式のサイズが可能な限り制御されたままになるように、バランスの取れた再帰ツリーを構築します。 各畳み込みは、2 つの部分分布を結合して、合計カウントに対する新しい分布を作成します。 

畳み込み自体は、わかりやすくするために単純なネストされたループ形式で書かれています。 完全に最適化されたソリューションでは、制限時間内で大量の入力を効率的に処理するために、これが FFT または NTT に置き換えられます。 

最終的な答えは単にインデックスの係数です`k`存在する限り。

 ## 特殊なケース

 すべてのサーベルが単一の色を共有する場合、重大なエッジケースが発生します。 たとえば、入力が`n = 5`、`m = 1`、 そして`k = 3`、唯一の有効な構成は、その単一のプールから正確に 3 つを選択することです。 アルゴリズムは 1 つの多項式を構築します`[1,1,1,1,1,1]`、インデックス 3 の係数 (1) を直接読み取り、期待値と一致します。 

もう 1 つのエッジケースは次のような場合です`k = 0`。 色の分布に関係なく、何も選択しない方法は 1 つだけあり、これはすべての多項式からゼロを選択することに相当します。 畳み込みでは、マージ全体を通じて常に 1 の定数項を維持することにより、これが維持されます。 

3 番目のエッジケースは次のような場合です。`k`利用可能なセイバーの合計を超えています。 この場合、すべての多項式の最大次数は以下になります。`k`、そのため、係数の検索は結果の配列の外にあり、正しく 0 を返します。
