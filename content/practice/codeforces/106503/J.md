 ## 解決策
 ## 問題の理解

 次のサイズの長方形グリッドが与えられます。$n \times m$。 各セルは単位正方形として扱われ、各正方形には、グリッド上の 4 つの方向の 1 つに対応する 4 つの可能な方向のうちの 1 つが割り当てられます。 これらの方向は、正方形が選択した辺を介して隣接するセルにどのように「接続」するかを示します。 

すべてのセルの方向を選択することで、隣接するセル間でのみ隣接が許可されるグリッド上に有向構造を効果的に構築します。 方向の選択によっては、グリッド上の領域を囲む閉ループが形成されます。 各閉ループは境界領域に対応し、そのような領域の「面積」はそこに含まれる単位セルの数です。 

タスクは、すべての閉じた領域によって形成される合計囲まれた領域ができるだけ大きくなるように、すべてのセルに方向を割り当てることです。 閉領域を形成できない場合、答えはゼロです。 

制約は全体として厳しいです。テスト ケースは最大 1500 個まで存在できますが、すべてのテスト ケースの合計は$n \times m$それらを横切るのはせいぜい$10^6$。 これは、あらゆるソリューションがテスト ケースごとのグリッド サイズで線形であるか、最悪の場合でもすべてのテスト ケース全体で全体的に線形である必要があることを直ちに示唆します。 二次関数の何か$n \times m$遅すぎるでしょう。 

微妙な点は、単一のサイクルまたは単一の領域を見つけることが求められているのではなく、囲まれた領域の合計を最大化することが求められているということです。 これにより、問題はローカルなサイクル検出から、少なくとも 1 つの閉じた境界構造に参加するセルの数を最大化する構成のグローバルな構築へと移行します。 

いくつかの特殊なケースで動作が明確になります。 

いつ$n = 1$そして$m = 1$、セルは 1 つだけです。 自己ループなしに単一ノード内にサイクルが存在することはできず、グリッド構造ではそのような構築ができないため、答えは 0 でなければなりません。 

いつ$n = 1$そして$m = 2$、2 つのセルの行しかありません。 方向の割り当ては左または右のみを指すことができるため、必然的に閉ループではなくオープンエンドになります。 繰り返しますが、答えは 0 です。 

いつ$n = 2$そして$m = 2$、4 つのセルすべてが周囲にループを形成するように方向を配置することで、サイクルが可能になります。 これにより、エリア 4 の単一の囲まれた領域が生成されます。この例は、重要なしきい値がグリッドがサイクル構造をサポートできるかどうかであることを示しています。 

これらの例は、問題は、グリッドをカバーするサイクルを埋め込むことができるかどうか、埋め込むことができる場合はどのくらいの大きさにできるかを決定することに帰着することを示唆しています。 

## アプローチ

 直接的な総当たりアプローチでは、各セルに 4 つの方向のうちの 1 つを割り当て、結果として得られる有向グラフ構造をシミュレートし、すべてのサイクルを計算して、囲まれた領域の合計を測定します。 あるので$4^{n \cdot m}$構成では、これは非常に小さなグリッドであっても完全に実行不可能です。 単一の構成のチェックに限定したとしても、すべての囲まれた領域を検出するには、グリッド全体にわたるグラフの走査が必要です。$O(nm)$, そのため、すべての構成に対するブルートフォースは絶望的です。 

重要な観察は、グリッド構造が非常に規則的であるということであり、重要なのは、すべてのセルを 1 回だけ使用する単一のグローバルな循環構造にセルを配置できるかどうかだけです。 このような構造が存在する場合、すべてのセルが一貫した閉鎖システムの境界上に位置し、最大の密閉面積が達成されます。 

これにより、問題は古典的なグラフ構築の問題に帰着します。グリッド隣接グラフ内のすべてのセルを 1 回だけ訪問するサイクルを形成できるか? これは、グリッド グラフにハミルトニアン サイクルがあるかどうかを尋ねることと同じです。 

長方形グリッドのよく知られた特性は、両方の次元が 1 より大きい場合にのみハミルトニアン サイクルが存在するということです。どちらかの次元が 1 の場合、グリッドはパスに縮退し、サイクルを形成できません。 両方の次元が少なくとも 2 であれば、前後のパターンでグリッドを蛇行し、端を接続して完全なサイクルを形成できます。 

このようなサイクルが存在すると、すべてのセルが境界構造の一部となるため、最大囲まれた面積はセルの総数に等しくなります。$n \cdot m$。

 ## アルゴリズムのチュートリアル

 解決策は、グリッドの寸法に関する単純な構造チェックに帰着します。 

1.読む$n$そして$m$テストケースごとに。 

グリッド構造は追加の重みやラベルではなく、その形状に完全に依存するため、必要なのはこれら 2 つの値だけです。 
2. いずれかの次元が 1 であるかどうかを確認します。 

もし$n = 1$または$m = 1$、グリッドは単一の行または列であり、セルの線形チェーンを形成することを意味します。 直線チェーンは閉じたループを形成できないため、囲まれた領域を作成できません。 
3. 両方の場合$n > 1$そして$m > 1$、 戻る$n \cdot m$。 

この場合、グリッドには、すべてのセルをカバーするサイクルを埋め込むのに十分な接続が含まれています。 すべてのセルを 1 回だけ訪問し、グリッドの隣接構造を使用してループを閉じる、ヘビのようなトラバーサルを構築できます。 
4. 各テスト ケースの結果を出力します。 

### なぜ効果があるのか

 グリッドは、各セルが最大 4 つの隣接セルに接続する無向グラフとして見ることができます。 このグラフ構造では、閉領域がサイクルに対応します。 囲まれた領域を最大化するということは、サイクル内に存在する頂点の数を最大化することを意味します。 考えられる最良の状況は、すべての頂点が 1 つのサイクルの一部であるときです。 

長方形グリッドは、両方の次元が 1 を超える場合にハミルトニアン サイクルを正確にサポートします。その場合、すべての次元が 1 を超えます。$n \cdot m$頂点は 1 つのサイクルに含めることができます。これは、すべてのセルが囲まれた構造に寄与することを意味します。 １次元が１の場合には、周期が全く存在しないため、正の領域は形成できない。 

この構造的特性が答えを完全に決定します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, m = map(int, input().split())
    if n == 1 or m == 1:
        print(0)
    else:
        print(n * m)
```この実装では、上記で導出されたディメンション チェックが直接適用されます。 各テスト ケースは一定時間内に独立して処理されます。 

唯一の微妙な点は、複数のテスト ケースにわたって正しい解析を保証することです。 合計から$n \cdot m$によって制限されています$10^6$、単純な入力処理の下では、多数のテスト ケースでも依然として効率的です。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    t = int(input())
    out = []
    for _ in range(t):
        n, m = map(int, input().split())
        if n == 1 or m == 1:
            out.append("0")
        else:
            out.append(str(n * m))
    return "\n".join(out)

# provided samples (interpreted)
assert run("2\n2 5\n4 4\n") == "10\n16"

# minimum edge
assert run("1\n1 1\n") == "0"

# single row
assert run("1\n1 10\n") == "0"

# single column
assert run("1\n10 1\n") == "0"

# small cycle-capable grid
assert run("1\n2 2\n") == "4"

# larger rectangle
assert run("1\n3 7\n") == "21"
```| テスト入力 | 期待される出力 | 検証内容 |

 | k×1 | 0 | 対称縮退の場合 |

 ## 特殊なケース

 1 行 1 列のグリッドの場合、サイクル形成と囲まれた領域の両方に少なくとも 2 行 2 列の構造が必要なため、アルゴリズムはすぐに 0 を返します。 ループを閉じることができる隣接構造はありません。 

1 × m グリッドの場合、アルゴリズムは再び 0 を返します。複数のセルがある場合でも、すべてのパスは線形であり、それ自体で閉じることはできません。 同じ推論が n × 1 グリッドにも対称的に当てはまります。 

両方の次元が少なくとも 2 であるグリッドの場合、アルゴリズムは m の n 倍を返します。 暗黙的な構築は、そのようなグリッドが常にすべてのセルにわたるフルサイクルの走査を許可し、最大の囲まれた領域を確保するという事実に依存しています。
