 ## 問題の理解

 タスクは与えられた自然数を分割することです`N`いくつかの正の整数に変換します。 分割の各部分は、10 進数の合計がまったく同じである必要があります。 パーツの数は少なくとも 2 つである必要があります。`N`100 万を超えることはできません。 このような分割が存在する場合は、部品の量と部品自体を出力します。 それ以外の場合は印刷します`-1`。 

限界`N <= 10^18`可能なサマンドの試行やパーティションの検索を即座に除外します。 すべての値を反復処理しても、`N`入力には約 1 京の数値が含まれる可能性があるため、これは不可能です。 有用な観察は桁数のみに依存する必要があります。`N`10 進数は最大 19 桁です。

のために`N = 10`、10 進数の分解では加数が 1 つだけ得られます。`10`、これは無効です。 正しい出力は次のとおりです`2`に続く`5 5`、両方の加数が桁の合計を持っているため`5`。 10 進数のみをカウントする不用意な実装では、10 のべき乗をすべて見逃してしまいます。 

のために`N = 2`、数値のコピーへの分解は正しく機能します。`1 + 1`。 両方の数値には桁の合計があります`1`、加数の数は有効です。

 ## アルゴリズムのチュートリアル

 1. 次の 10 進数の合計を計算します。`N`。 これにより、単純な数字分解に 1 つまたは複数の加数が含まれるかどうかがわかります。 
2. もし`N`は`1`、印刷`-1`。 合計が次のような 2 つの正の数を作成する方法はありません。`1`。 
3. の桁の和が`N`は`1`を 2 部印刷します。`N / 2`。 そのような値は 10 の累乗のみであり、1 より大きい 10 の累乗はすべて偶数です。 それぞれの半分には桁の合計があります`5`。 
4. それ以外の場合は、次の 10 進数をスキャンします。`N`右から左へ。 すべての桁について`d`位置で`10^k`、 追加`d`のコピー`10^k`答えに。 

これが機能する理由は、生成された各値にはゼロ以外の桁が 1 つだけあるため、生成されたすべての値には桁の合計が含まれるためです。`1`。 コピーを追加すると、元の 10 進数が正確に再構築されます。 
5. 生成された加数の数と加数自体を出力します。 

この構築の背後にある不変条件は、生成されるすべての加数が同じ桁の合計を持つということです。 唯一の特殊なケースは、自然数分解に 1 つの加数が含まれる場合であり、これは正確に 10 の累乗で発生します。 これらの数値を個別に処理すると、少なくとも 2 つの部分を持つという要件を満たしながら、同じ不変条件が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def digit_sum(x):
    return sum(map(int, str(x)))

def solve():
    n = int(input())

    if n == 1:
        print(-1)
        return

    if digit_sum(n) == 1:
        print(2)
        print(n // 2, n // 2)
        return

    ans = []
    x = n
    power = 1

    while x > 0:
        digit = x % 10
        for _ in range(digit):
            ans.append(power)
        power *= 10
        x //= 10

    print(len(ans))
    print(*ans)

if __name__ == "__main__":
    solve()
```最初のブランチは、唯一不可能な入力を処理します。 条件は 10 のべき乗の場合の前にチェックされます。`1`も桁和は 1 ですが、これを 2 つの正の整数に分けることは不可能です。 

2 番目のブランチは、1 より大きい 10 の累乗をすべて処理します。 これらの数値は偶数であり、得られる半分の桁の合計が等しいため、除算は正確です。 

メインループは右から左に数字を抽出します。`power`常に現在の小数点以下の値を保存します。 現在の桁が`d`、追加`d`のコピー`power`元の数値に寄与した桁とまったく同じ金額を寄与します。 この入力範囲で可能な 10 進数の合計の最大値は次のとおりであるため、回答サイズは小さいままです。`171`。 

Python の整数はオーバーフローしないので、半分は`10^18`そしてすべての中間値は安全です。 また、ループは数値を数字のリストに変換することを回避し、実装を直接的に保ちます。

import sys
import io

def solve_case(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    def digit_sum(x):
        return sum(map(int, str(x)))

    n = int(sys.stdin.readline())

    if n == 1:
        return "-1"

    if digit_sum(n) == 1:
        return f"2\n{n // 2} {n // 2}"

    ans = []
    x = n
    power = 1
    while x > 0:
        d = x % 10
        for _ in range(d):
            ans.append(power)
        power *= 10
        x //= 10

    return str(len(ans)) + "\n" + " ".join(map(str, ans))

def check(inp):
    out = solve_case(inp)
    if out == "-1":
        return out

    lines = out.splitlines()
    m = int(lines[0])
    values = list(map(int, lines[1].split()))

    assert len(values) == m
    assert 2 <= m
    assert all(v > 0 for v in values)
    assert sum(values) == int(inp)
    assert len({sum(map(int, str(v))) for v in values}) == 1
    return out
