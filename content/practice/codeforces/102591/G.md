 # 問題の理解

 からのすべての数字が記入された長方形のボードが与えられます。`1`に`N*M`まさに一度。 ボードは、以下を含む単一のセルから作成されました。`1`新しい行または列を外側に繰り返し追加します。 行が追加されると、そのセルは左から右に、これまでに出現したことのない最小の数字で埋められます。 列を追加すると、そのセルは同じように上から下に入力されます。 

タスクは、ボードを作成した可能性のある一連の操作を回復することです。 出力は、それらの操作を時系列で説明する一連の文字です。 

制約により許可されるのは、`N`そして`M`まで`500`、ボードに次のものを含めることができます`250000`細胞。 考えられる操作オーダーの数が指数関数的に増加するため、多くの考えられる構築履歴を試すソリューションは不可能です。 意図したソリューションでは基板の検査を少数回のみ行う必要があるため、ほぼ線形の複雑さになります。 

主なトラップは、最大値が常に右下隅にあると想定しています。 そうではありません。 最後の操作では、任意の側から行または任意の側から列を追加できます。 もう 1 つのよくある間違いは、レイヤーを削除した後、次に大きい値は元のボードではなく、残りの長方形内でのみ検索する必要があることを忘れていることです。 

例えば：```
1 2
3 4
```不注意な解決策を使用すると、常に一番下の行が削除されて出力される可能性があります。`D`。 これはここでは有効ですが、次のことを考慮してください。```
3 1
4 2
```最大の 2 つの値は次のとおりであるため、最後の操作では左の列が追加されている必要があります。`3,4`垂直に。 間違った側を削除すると、構築順序が崩れます。 

もう 1 つの特殊なケースは単一行です。```
1 2 3 4
```可能な操作は列の追加のみです。 現在の寸法を確認せずに行と列を対称的に扱うと、無効な削除が作成される可能性があります。 

## アプローチ

 直接的なアプローチでは、プロセスを前向きに再構築しようとします。 から始まる`1`、考えられるすべての次の操作を試し、シミュレーションし、結果をターゲット ボードと比較することができます。 これは正しいです。なぜなら、すべての有効な履歴が調査された選択肢の中で表されるからです。 問題は、各状態が 4 つの選択肢に分岐する可能性があり、その構築には次のことが必要であることです。`N+M-2`操作。 検索スペースは約`4^(N+M)`これは、500 程度の次元で処理できる範囲をはるかに超えています。 

プロセスを逆から見ると、有益な観察が得られます。 あらゆる瞬間に、すでに配置されている数字はまさにシーケンスの接頭辞になります。`1,2,3,...`。 現在の長方形に面積がある場合`A`、その後、最後の操作で、で終わる数字を正確に含む辺が追加されました。`A`。 長さの列`k`以下を含める必要があります:```
A-k+1, A-k+2, ..., A
```左から右へ。 列には上から下まで同じシーケンスが含まれている必要があります。 

これにより、問題は履歴の発見から最終層の繰り返し剥離へと変わります。 各ステップで、残りの長方形の 4 つの境界線をチェックするだけで済みます。 境界線が必要な連続値に一致すると、最後の操作がわかり、それを削除できます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |`O(4^(N+M))`|`O(N*M)`| 遅すぎる |
 | 最適 |`O(N*M)`|`O(N*M)`| 承認済み |

 ## アルゴリズムのチュートリアル

 1. 現在残っている四角形を表す 4 つのポインターを保持します。`top`、`bottom`、`left`、 そして`right`。 最初はこれがボード全体です。 も保管してください`area`、現在四角形内のセルの数。 
2. 一番上の行に次の値が含まれているかどうかを確認します。`area - width + 1`に`area`昇順で。 存在する場合、最後の操作は次のとおりです。`U`, そのため、この行を削除し、行の長さだけ面積を減らします。 
3. 上の行が一致しない場合は、下の行も同様に確認します。 一致する場合、最後の操作は`D`。 
4. 同じルールを使用して、左右の列を確認します。 左の列が一致する場合は、最後の操作が`L`、右側の列が一致する場合は、最後の操作が`R`。 
5. 削除されたすべての操作を保存します。 削除は逆の時系列で行われるため、印刷する前に収集された操作を元に戻します。 

不変条件は、すべての除去の前に、残りの長方形が最後の構築ステップ前の基板の状態とまったく同じであるということです。 そのセルには正確に次の数値が含まれています。`1`に`area`したがって、最後に追加された側には、そのプレフィックスの最大数が含まれている必要があります。 アルゴリズムはこの特性を満たす辺のみを削除するため、すべての削除は有効な以前の操作に対応します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    a = [list(map(int, input().split())) for _ in range(n)]

    top, bottom = 0, n - 1
    left, right = 0, m - 1
    area = n * m
    ans = []

    while top < bottom or left < right:
        done = False

        width = right - left + 1
        need = list(range(area - width + 1, area + 1))

        if a[top][left:right + 1] == need:
            ans.append('U')
            top += 1
            area -= width
            done = True
        elif a[bottom][left:right + 1] == need:
            ans.append('D')
            bottom -= 1
            area -= width
            done = True
        else:
            height = bottom - top + 1
            need = list(range(area - height + 1, area + 1))

            col = [a[i][left] for i in range(top, bottom + 1)]
            if col == need:
                ans.append('L')
                left += 1
                area -= height
                done = True
            else:
                col = [a[i][right] for i in range(top, bottom + 1)]
                if col == need:
                    ans.append('R')
                    right -= 1
                    area -= height
                    done = True

        if not done:
            break

    print(''.join(reversed(ans)))

if __name__ == "__main__":
    solve()
```コードは、現在の四角形の境界とその中に残っているセルの数のみを保持します。 の`area`変数は、まだ存在しているはずの最大値です。これにより、最後に追加された境界線の期待値をすぐに計算できます。 

比較は、逆のプロセスと同じ順序で行われます。つまり、最初に最後の行が考えられ、次に最後の列が考えられます。 この問題は、すべての段階で少なくとも 1 つの側が有効であることを保証します。 辺が削除されると、次の反復の前に、対応する境界が内側に移動します。 

Python の整数は最大値のみであるため、ここでは特別な処理は必要ありません。`250000`。 主な実装の詳細は更新中です`area`次に予想されるシーケンスはそれに依存するため、削除されたセルの正確な数によって決まります。

 ## 特殊なケース

 単一セルの場合:```
1 1
1
```スターティングボードはすでにターゲットに等しい。 削除する境界線がないため、ループは実行されず、答えは空の文字列になります。 

1 列ボードの場合:```
1 4
1 2 3 4
```唯一の行を削除するとボードが残らないため、現在の長方形は行を失うことはありません。 アルゴリズムは列をチェックし、可能な唯一の構造と一致するものを 1 つずつ削除します。 

最終操作が下側または右側ではないボードの場合:```
2 2
3 1
4 2
```最大値は最初の列にあります。 アルゴリズムは 4 つの境界線すべてをチェックし、最後の連続値を含む左の列を見つけて、`L`固定された方向に依存するのではなく。 これにより、逆構築の不変条件が保存されます。
