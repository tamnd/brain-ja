 ## 解決策
 ## 問題の理解

 1 から 2 までの範囲からできるだけ多くの数字を選択するように求められます。$n$正確に合計するサブセットを作成せずに、$k$。 各テスト ケースは値を提供します$n$そして$k$、出力には、選択された数値のカウントとリスト自体の両方が必要です。 課題は、合計が以下になるサブセットを回避しながら、セットのサイズを最大化することです。$k$。 

制約は控えめです。$n$そして$k$最大 1000 個、最大 100 個のテスト ケースを含めることができます。 これにより、必要に応じて、テスト ケースごとに 2 次または 2 次の複雑さを持つアルゴリズムを検討することができます。 ただし、すべてのサブセットをブルートフォースで列挙すると、指数関数的になります。$n$そして実行不可能です、なぜなら$n=20$100 万を超えるサブセットが生成されます。 

微妙な点が生じるのは、$k$非常に小さい、たとえば$k=1$。 1 つを除くすべての数値を含めるという素朴なアプローチは、合計が等しい数値を誤って含めた場合に失敗する可能性があります。$k$。 たとえば、次の場合$n=1$そして$k=1$、数値 1 を含むはサブセットであるため無効です。$\{1\}$合計すると$k$。 同様に、$k$がすべての数値の合計に近い場合、セットを最大化するには、いくつかの特定の数値だけを避ける必要があります。 

## アプローチ

 ブルートフォースソリューションでは、考えられるすべてのサブセットが試行されます。$\{1, 2, \dots, n\}$、合計が等しいかどうかを確認します$k$。 これは正しいですが、明らかに実行不可能です。サブセットの数は$2^n$、指数関数的に増加します。 のために$n=1000$、これは許容時間をはるかに超えており、ブルートフォースは容認できません。 

重要な洞察は、すべての組み合わせを考慮する必要はないという観察から得られます。 合計が形成されないようにするには、$k$を合計すると、サブセットに含まれる可能性のある数値を体系的に除外できます。$k$。 シンプルで効果的な戦略の 1 つは、以下から数字を選択し始めることです。$n$1 まで下げて、残りの選択された数値の合計が正確に一致する数値をスキップします。$k$。 これが機能するのは、より大きな数値の合計がすぐに超過するためです。$k$、これらの大きな数の部分集合を合計することは不可能になります。$k$。 結果として、主に、禁止された合計を直接形成する可能性のある小さな数値を除外する必要があります。 

たとえば、より大きい数値を選択すると、$\frac{k}{2}$選択した 2 つ以上の数値の合計が一致しないことを保証します$k$。 残りの数字は以下の通り$\frac{k}{2}$その後、安全性を個別にチェックできます。 この貪欲なアプローチは問題の構造を利用し、最大限のアンチナップザックを効率的に構築できるようにします。

 ## アルゴリズムのチュートリアル

 1. 選択した番号を保存するために空のリストを初期化します。 
2. 反復処理$n$1 まで。各数字で$i$が含まれているかどうかを確認してください$i$任意のサブセットの合計を許可します$k$。 
3. チェックは簡略化できます: スキップ$i$もし$i$と全く同じです$k - \text{sum of already selected numbers below } i$。 貪欲なアプローチの場合、この条件は正確に回避することになります。$k$トップダウンで構築する場合。 
4. すべての安全な番号を選択リストに追加します。 
5. リストのサイズと数値自体を出力します。 

機能する理由: 最大値から最小値まで数値を選択すると、選択した数値の合計が常に超過します。$k$複数の数字が含まれる場合。 以下に等しい数値をスキップします$k$または直接形成できる数字$k$サブセットが禁止された合計に加算されないようにします。 維持される不変条件は、すべてのステップで、選択された数値のサブセットの合計が次の値にならないということです。$k$、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    n, k = map(int, input().split())
    result = []
    for i in range(n, 0, -1):
        if i < k:
            result.append(i)
            k -= i
    print(len(result))
    print(*result)
```このソリューションは複数のテスト ケースを読み取ります。 それぞれの場合、最大の番号から始まります$n$残りの数値より小さい数値$k$が結果に追加され、$k$それに応じて減額されます。 これにより、サブセットの合計が元の値と一致しないことが保証されます。$k$禁止されたサブセットを完成させる可能性のある数値をスキップするためです。 印刷では、unpack 演算子を使用して、任意の長さのリストを処理します。
