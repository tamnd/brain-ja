## Python ソリューション```python
import sys
input = sys.stdin.readline

def check(s, n, k):
    diff = [0] * (n + 2)
    cur = 0

    for i in range(n):
        cur ^= diff[i]

        if cur == 0:
            bit = s[i]
        else:
            bit = 1 - s[i]

        if bit == 0:
            if i + k > n:
                return False
            cur ^= 1
            diff[i + k] ^= 1

    return True

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        s = input().strip()
        arr = [1 if c == '1' else 0 for c in s]

        ans = 1
        for k in range(1, n + 1):
            if check(arr, n, k):
                ans = k
        print(ans)

if __name__ == "__main__":
    solve()

 ## 特殊なケース

 重要なエッジケースは、文字列がゼロで始まり、$k$大きいです。 例えば、`00000`と$k=5$。 最初の位置を固定する必要があるため、アルゴリズムはインデックス 0 ですぐに反転します。 これにより、文字列全体をカバーする完全な反転が生成され、その後、すべての位置が 1 になります。 貪欲ルールは、次の場合にのみ反転を許可するため、境界条件を正しく処理します。$i+k \le n$無効な操作が試行されないようにします。
