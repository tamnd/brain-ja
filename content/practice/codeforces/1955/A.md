 ## 解決策
 ## 問題の理解

 マキシムは正確に購入したいと考えています`n`ヨーグルト1個あたりの値段の店のヨーグルト`a`バールですが、ヨーグルト 2 個を提供するプロモーションがあります。`b`バール。 テストケースごとに、購入に費やすことができる最小金額を正確に計算する必要があります。`n`ヨーグルト。 入力では複数のテスト ケースを指定し、それぞれがヨーグルトの数を提供します。`n`、通常の単一価格`a`、および 2 対 1 のプロモーション価格`b`。 各テスト ケースの出力は、最小総コストを表す単一の整数です。 

制約は小さいです。`n`は 100 まで、価格は 30 までです。`10^4`テスト ケースでは、各テスト ケースを一定時間で処理する必要があります。 これにより、反復処理を行うアルゴリズムが排除されます。`n`各テスト ケースを複数回実行するか、複雑な検索を実行します。 

エッジケースには、ヨーグルトを 2 つ個別に購入した方がプロモーションよりも安い状況が含まれます。 たとえば、次の場合`a = 5`そして`b = 11`の場合、10 バールのヨーグルトを 2 つ別々に購入する方が、11 バールのプロモーションを利用するよりもお得です。もう 1 つの微妙なケースは次のような場合です。`n`奇数です。 できるだけ多くのペアを購入し、最後の 1 つのヨーグルトを別々に処理する必要があるかもしれません。 

## アプローチ

 ブルートフォースアプローチでは、合計が以下になる単一ペアとプロモーションペアのあらゆる可能な組み合わせを試みます。`n`ヨーグルトを抽出し、各組み合わせの合計コストを計算します。 これは 0 から 0 まで反復できるため機能します。`n//2`ペアの数ごとに、残りの単一ヨーグルトを追加して合計コストを計算します。 最大限に`n = 100`の場合、テスト ケースごとに最大 50 回の反復を実行します。 と`10^4`テスト ケースでは、最悪の場合 500,000 回の反復が発生しますが、これは実現可能ですが不要です。 

重要な洞察は、問題が単純な比較に帰着することです。ヨーグルトのペアごとに、プロモーション価格で 2 つ購入するという単純な比較です。`b`以下の場合にのみ価値があります`b`未満です`2 * a`。 それ以外の場合は、ヨーグルトを常に個別に購入する必要があります。 この観察により、単一の式で最小コストを計算できるようになります。ペアの数を計算します (`n // 2`) と残ったシングル (`n % 2`)、ペアの場合は、より安い方を使用します。`b`そして`2 * a`。 シングルはいつも`a`それぞれ。 これにより、ソリューションはテスト ケースごとの単純な算術に削減され、最適になります。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 それぞれを独立して処理していきます。 
2. 各テスト ケースについて、次の内容を読んでください。`n`、`a`、`b`。 これらは、購入するヨーグルトの合計、ヨーグルト 1 個の価格、およびヨーグルト 2 個のプロモーション価格を表します。 
3. 購入できるヨーグルトのペアの数を計算します。`n // 2`残りの単一ヨーグルトの数は次のようになります。`n % 2`。 
4. ペアについて、次の小さい方を使用してコストを計算します。`b`そして`2 * a`、ペアを購入する場合は、2 つを個別に購入するコストを決して超えてはいけないためです。 
5. ペアの数にペアのコストを掛け、残りの単一ヨーグルトに次の値を掛けます。`a`それらを合計して合計コストを取得します。 
6. テスト ケースの結果を印刷します。 

効果がある理由: 不変なのは、ヨーグルトを 2 つ購入する場合、プロモーションと 2 つの単品購入のうち、常に安い方のオプションを選択するということです。 すべてのヨーグルトを会計処理する必要があるため、残った単一のヨーグルトは個別に処理されます。 総コストを削減できる代替の組み合わせはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, a, b = map(int, input().split())
    pairs = n // 2
    singles = n % 2
    cost = pairs * min(2 * a, b) + singles * a
    print(cost)
```コードはテスト ケースの数を読み取り、それぞれを一定時間で処理します。 テスト ケースごとに、ペアと単一のヨーグルトの数を計算し、`min`ペアの安価なオプションを選択する機能。 このアプローチでは、残ったシングルを次のように処理することで、off-by-one エラーを回避します。`n % 2`。 計算は簡単で、不要なループを回避します。 

## 実用的な例

 サンプル入力 1 のトレース:

 入力:`2 5 9`変数:`n = 2`、`a = 5`、`b = 9`ペア:`2 // 2 = 1`シングル:`2 % 2 = 0`ペアのコスト:`min(2*5, 9) = 9`総費用:`1*9 + 0*5 = 9`入力：`3 5 11`変数:`n = 3`、`a = 5`、`b = 11`ペア:`3 // 2 = 1`シングル:`3 % 2 = 1`ペアのコスト:`min(2*5, 11) = 10`総費用:`1*10 + 1*5 = 15`これらのトレースは、アルゴリズムがペアの安価なオプションを正しく選択し、残ったシングルを処理していることを示しています。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    output = io.StringIO()
    sys.stdout = output
    t = int(input())
    for _ in range(t):
        n, a, b = map(int, input().split())
        pairs = n // 2
        singles = n % 2
        cost = pairs * min(2 * a, b) + singles * a
        print(cost)
    return output.getvalue().strip()

 ## 特殊なケース

 のために`n = 1`そしてどれでも`b`、アルゴリズムは正しく計算します`singles = 1`そしてプリント`a`、プロモーションを無視します。 奇数の場合`n`のように`n = 3`、`pairs = 1`そして`singles = 1`ヨーグルトは必ず1つずつ個別に購入してください。 プロモーションのとき`b`単体で2つ購入するよりも高価ですが、`min(2*a, b)`安い方を選ぶ`2*a`。 いつ`b`等しい`2*a`、それでも選択します`2*a`、それは正しいです。 これらの状況は、最小サイズ、奇数、境界のプロモーション価格シナリオが正しいことを確認します。
