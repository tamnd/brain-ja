 ## 解決策
 ## 問題の理解

 文字列のシーケンスが与えられます。 各文字列は正の整数を表しますが、一部の数字は次のように置き換えられています。`'?'`。 元のシーケンスは厳密に増加していました。 私たちの仕事は、すべてを置き換えることです`'?'`結果として得られるすべての数値が先行ゼロのない有効な正の整数となり、シーケンス全体が厳密に増加するように 10 進数を使用します。 

シーケンスの長さは次のとおりです$10^5$、すべての数字には最大 8 文字が含まれます。 個々の数字の長さが短いことが重要な観察点です。 多くの要素があっても、その長さが 8 を超えることはないため、各要素は小さな検索スペースに属します。文字列ごとに一定量の作業のみを実行するソリューションは、簡単に十分に高速です。 一方で、考えられるすべての代替品を試すことは不可能です。 完全に疑問符で構成される長さ 8 の文字列は、すでに次のことを表しています。$10^8$候補者たち。 

問題の最もデリケートな部分は、ローカルの選択が後の数値に影響を与えることです。 早期に不必要に大きな値を選択すると、将来のポジションが不可能になる可能性があります。 

考慮する：```
2
??
10
```最初の数値は 99 にすることができますが、2 番目の数値はそれを超えることはできません。 正しい選択は、前の要素より大きい最小の有効な数値です。つまり、シーケンスは厳密に増加する必要があるため、10 は不可能です。そのため、01 を選択します。 先行ゼロは許可されません。 実際の答えは次のとおりです。```
YES
9
10
```長さが異なる場合には、別の微妙なケースが発生します。```
2
??
???
```3 桁の数値は、2 桁の数値よりも大きくなります。 貪欲な戦略では、これを利用して、より大きな値を試す無駄な労力ではなく、有効な最小の 2 桁の数値を選択する必要があります。 

先頭のゼロも間違いのよくある原因です。```
1
?5
```答えは 15、25、...、95 になる可能性がありますが、05 になることはありません。最初の桁はゼロ以外でなければなりません。 

最後に、いくつかのインスタンスは不可能です。```
2
99
??
```2 桁の補完は最大 99 であるため、厳密にこれより大きな値は存在しません。 正しい出力は次のとおりです。```
NO
```課題は、すべてのポジションについて、以前に選択した数値より厳密に大きい、最小の有効な補完を見つけることです。 

## アプローチ

 ブルート フォース アプローチでは、各パターンの可能なすべての完成を生成し、厳密に増加するシーケンスを検索します。 長さ 8 の単一の文字列であっても、$10^8$候補者たち。 それに掛けると$10^5$ポジションは全く無理です。 

問題の構造は、別の視点を示唆しています。 前の値が固定されると、現在の位置に必要なのは 1 つだけです。それは、前の値より厳密に大きい、そのパターンに一致する最小の数値です。 実行可能な最小値を常に見つけることができれば、より大きな選択は後の制約を難しくするだけなので、将来のポジションを損なうことはありません。 

これにより、問題が繰り返される部分問題に変換されます。 

パターン文字列と下限が与えられた場合$L$、値がより大きいパターンに一致する最小数を見つけます。$L$。 

長さ制限が 8 なので、これがはるかに簡単になります。 候補となる数値はどれも標準の整数に収まります。 膨大な数値範囲を検索する代わりに、桁ごとに回答を構築できます。 

パターンの長さがパターンの桁数より小さいとします。$L+1$。 その場合、すべての候補の桁数が少なくなるため、解決策は存在しません。 

パターンの長さがもっと長いとします。 その後、すべての候補者が自動的に超過します$L$そして、パターンに一致する最小の有効な数値を単純に構築します。 

興味深いのは、両方の長さが等しい場合です。 辞書編集上最小の補完が必要です。$L+1$。 長さは最大 8 であるため、digit-DP スタイルの貪欲な構造を使用できます。 各位置で、バインドされたプレフィックスよりすでに大きいかどうかを追跡しながら、許可された数字を最小値から最大値まで試します。 存在する位置は 8 つだけであるため、単純な再帰検索でも事実上定数時間になります。 

これにより、シーケンス全体にわたる線形解が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 「?」の数が指数関数的になる | お(1) | 遅すぎる |
 | 最適 | O(n) | お(1) | 承認済み |

 隠れた定数は最大長 8 に由来し、固定されています。 

## アルゴリズムのチュートリアル

 ### 境界を超える最小の有効な完了を見つける

 パターン文字列の場合`s`と前の値`prev`、より大きい最小の一致する数値を見つける必要があります。`prev`。 

1. コンピューティング`target = prev + 1`。 
2. もし`len(s) < len(str(target))`、返品失敗。 

すべての補完は桁数が少なくなります。`target`, そのため、必要な値に達することができません。 
3. もし`len(s) > len(str(target))`、パターンに一致する最小の有効な数値を構築します。 

桁数が多い数値は自動的に次より大きくなります`prev`。 
4. 長さが等しい場合、少なくとも以下の辞書編集上最小の補完を構築します。`target`。 
5. 再帰を使用して、左から右に数字を処理します。 

すでに選択されているプレフィックスが、対応するプレフィックスよりも厳密に大きいかどうかを追跡します。`target`。 
6. 位置で`i`、パターンで許可されるすべての数字を列挙します。 

最初の位置が疑問符の場合、数字 0 は禁止されます。 
7. プレフィックスがまだターゲットのプレフィックスと等しい場合、この位置ではターゲットの数字より小さい数字は許可されません。 
8. 昇順に数字を試してください。 

最初に成功した継続により、最小の有効な数値が得られます。 
9. どの桁も機能しない場合は、失敗を返します。 
10. から始める`prev = 0`、シーケンスを左から右に処理します。 

選択した各値を保存し、次の下限として使用します。 
11. いずれかの位置が失敗した場合、出力`"NO"`。 
12. それ以外の場合は出力`"YES"`そして構築されたシーケンス。 

### なぜ効果があるのか

 加工後の位置`i`の場合、アルゴリズムは、そのパターンに一致し、かつ以前に選択された数値を超える可能な最小の値を保存します。 代替の有効な選択肢は、選択された選択肢以上になります。 

完全な解決策が存在すると仮定します。 選択した値をより大きな有効な値に置き換えても、以降の要素はすべて現在の要素より厳密に大きくなければならないため、将来の位置を簡単にすることはできません。 実行可能な最小の選択は常に、他のすべての実行可能な選択と少なくとも同じくらい優れています。 

桁の構成も最適です。 1 つの位置で複数の数字が可能な場合は常に、昇順に試して最初に成功した継続を受け入れると、辞書編集上最小の有効な補完が生成されます。 固定長の数値の場合、辞書編集順序と数値順序は一致します。 

シーケンスに対する帰納法により、解が存在する場合、アルゴリズムは不必要に大きな選択を行ってそれを削除することはありません。 アルゴリズムが失敗を報告した場合、その位置には有効な完了が存在しないため、グローバルな解決策は存在しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def smallest_any(pattern):
    res = []
    m = len(pattern)

    for i, ch in enumerate(pattern):
        if ch != '?':
            if i == 0 and ch == '0':
                return None
            res.append(ch)
        else:
            if i == 0:
                res.append('1')
            else:
                res.append('0')

    return ''.join(res)

def build_ge(pattern, target):
    m = len(pattern)
    t = str(target)

    if len(t) > m:
        return None

    if len(t) < m:
        return smallest_any(pattern)

    memo = {}

    def dfs(pos, greater):
        if pos == m:
            return ""

        key = (pos, greater)
        if key in memo:
            return memo[key]

        if pattern[pos] == '?':
            digits = range(10)
        else:
            digits = [int(pattern[pos])]

        for d in digits:
            if pos == 0 and d == 0:
                continue

            td = int(t[pos])

            if not greater and d < td:
                continue

            ngreater = greater or (d > td)

            suffix = dfs(pos + 1, ngreater)
            if suffix is not None:
                memo[key] = str(d) + suffix
                return memo[key]

        memo[key] = None
        return None

    return dfs(0, False)

def solve():
    n = int(input())
    patterns = [input().strip() for _ in range(n)]

    ans = []
    prev = 0

    for s in patterns:
        cur = build_ge(s, prev + 1)
        if cur is None:
            print("NO")
            return

        val = int(cur)
        ans.append(cur)
        prev = val

    print("YES")
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```ヘルパーさん`smallest_any`パターンの長さがすでに必要なバインドされた長さを超えている場合に使用されます。 その状況では、すべての有効な補完は自動的に増加条件を満たします。そのため、単純に最小の正当な数値を構築します。 

機能`build_ge`実際の作業を担当します。 長さが一致する場合、桁ごとに検索が実行されます。 状態は、現在の位置と、構築されたプレフィックスがターゲット プレフィックスよりもすでに大きいかどうかを示すブール値で構成されます。 ブール値の位置は最大 8 つで、可能な値は 2 つだけであるため、メモ化テーブルには最大 16 個の状態が含まれます。 

再帰的検索では、常に数字が昇順に試行されます。 最初に成功した分岐は、最小の有効な完了です。 これは、貪欲な選択を正しく実装するための重要な詳細です。 

メインループはシーケンスを左から右に処理します。 値を選択すると、それが次の位置の下限になります。 選択されたすべての値はすべての実行可能な選択肢の中で最小であるため、将来のポジションは可能な限り制約されないままになります。

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve_io(inp: str) -> str:
    input = io.StringIO(inp).readline

    def smallest_any(pattern):
        res = []
        for i, ch in enumerate(pattern):
            if ch != '?':
                if i == 0 and ch == '0':
                    return None
                res.append(ch)
            else:
                res.append('1' if i == 0 else '0')
        return ''.join(res)

    def build_ge(pattern, target):
        m = len(pattern)
        t = str(target)

        if len(t) > m:
            return None

        if len(t) < m:
            return smallest_any(pattern)

        memo = {}

        def dfs(pos, greater):
            if pos == m:
                return ""

            key = (pos, greater)
            if key in memo:
                return memo[key]

            digits = range(10) if pattern[pos] == '?' else [int(pattern[pos])]

            for d in digits:
                if pos == 0 and d == 0:
                    continue

                td = int(t[pos])

                if not greater and d < td:
                    continue

                suf = dfs(pos + 1, greater or d > td)
                if suf is not None:
                    memo[key] = str(d) + suf
                    return memo[key]

            memo[key] = None
            return None

        return dfs(0, False)

    n = int(input())
    prev = 0
    ans = []

    for _ in range(n):
        s = input().strip()
        cur = build_ge(s, prev + 1)
        if cur is None:
            return "NO\n"
        ans.append(cur)
        prev = int(cur)

    return "YES\n" + "\n".join(ans) + "\n"

def run(inp: str) -> str:
    return solve_io(inp)

# length increase
