 ## 解決策
 ## 問題の理解

 各板チョコレートは単位正方形で構成される長方形であるため、その「価値」はその面積にすぎません。 2 つの長方形から始めて、それらを分ごとに変更することができます。 1 分でちょうど 1 つのバーを選択し、バーの半分または 3 分の 1 を切り取ってその面積を減らします。ただし、これはグリッド線に沿ったきれいな長方形の部分を削除するという意味でのみです。 半分の操作の後、残りの部分の面積はちょうど半分になり、3 回目の操作の後、残りの部分の面積はちょうど 3 分の 2 になります。 

目標は、両方のバーが最終的にまったく同じ数の単位正方形になるようにすることであり、これを最小限の操作で実行したいと考えています。 また、これらの操作を最適な方法で実行した後、両方のバーの最終寸法を出力する必要があります。 

重要な隠れた構造は、すべての操作で 1/2 または 2/3 を乗算することによって 1 つのバーの面積を縮小するため、到達可能なすべての面積は、initial_area に係数 1/2 と 2/3 の積を乗算した形式となり、バーごとに個別に適用されます。 これは、すべての変化はこれら 2 つの因数の累乗で構成されるため、変換で重要な素数は 2 と 3 だけであることが直ちに暗示されます。 

次元の制約は最大 10^9 と大きくなりますが、演算はジオメトリではなく因数分解構造のみに依存します。 これにより、問題はグリッド操作から領域全体の数理論に移ります。 

1 本のバーが 2 または 3 でまったく分割できない場合、微妙なエッジ ケースが発生します。 たとえば、5×7 のバーはいかなる方法でも変更できません。 このような場合、到達可能な唯一の値は元の面積であり、他のバーもその値まで正確に縮小できる場合にのみマッチングが可能です。 

もう 1 つの重要なエッジ ケースは、両方のバーがすでに等しい面積を持っている場合です。 答えは操作がゼロであるため、元のサイズを出力する必要があります。 

## アプローチ

 ブルートフォースの視点では、考えられるすべてのカットシーケンスをシミュレートします。 各状態は、両方のバーの現在の領域によって定義されます。 各状態から、バー タイプごとに最大 2 つの動きを適用できます (可能であれば 2 または 3 で割ります)。 これにより、深さが操作の数となる分岐検索ツリーが作成されます。 

ただし、操作の数が少ない場合でも、指数関数的な増加につながります。 領域は多くの組み合わせで縮小する可能性があるため、状態空間はすぐに巨大になり、異なるシーケンスが同じ領域に到達する可能性があるため、繰り返しの管理が困難になります。 

重要な洞察は、ジオメトリやカットのシーケンスについて考えるのをやめ、代わりに、各開始バーからどの最終エリアに到達できるかに純粋に焦点を当てることです。 各バーは、2 または 3 で繰り返し除算することによってのみ減らすことができるため、到達可能な領域は次の形式でなければなりません。 

初期領域 / (2^x · 3^y)

 これは、各バーが 2 と 3 の指数に関して到達可能な値の格子を定義することを意味します。各バーの到達可能な状態をすべて列挙すると、問題は操作の総数を最小限に抑える共通の値を選択することになります。 

各バーの到達可能なすべてのペア (値、コスト) を生成します。コストは、その値に到達するために必要な操作の数です。 次に、これらのセットを値で照合し、コストの最小合計を選択します。 

2 または 3 で除算するたびに厳密に数が減少するため、領域から係数 2 と 3 しか取り除くことができないため、実際にはバーごとの状態の総数は O(log n)^2 に制限されます。

 ## アルゴリズムのチュートリアル

各バーを個別に処理し、到達可能なすべての領域と、それらに到達するために必要な最小限の操作数を計算します。 

1. 各バーの初期面積を単一の整数として計算します。 すべての有効な演算は長方形の構造を保持しますが、乗算係数によって面積を変更するだけであるため、これが重要な唯一の値です。 
2. 各バーについて、可能な限り面積を 2 で割る回数を数えます。 それぞれの分割が 1 つの演算に対応します。 任意の数の 2 除去で停止することが有効であるため、すべての中間状態を記録します。 
3. ステップ 2 で生成されたすべての状態について、可能な限り繰り返し 3 で除算し、各中間結果を対応するコストとともに再度記録します。 これにより、2 ～ 3 因子空間の両次元で到達可能な縮小がすべて生成されます。 
4. 最初のバーの到達可能なすべての状態を辞書マッピング領域に最小コストで格納します。 2 番目のバーについても同じことを行います。 
5. 両方の辞書に含まれるすべての領域を繰り返します。 共通領域ごとに、両方のバーからコストの合計を計算します。 このような最小の合計を追跡し、対応する面積を覚えておいてください。 
6. 共通領域が存在しない場合は、許可された一連の操作によってバーを均等化できないため、-1 を返します。 
7. 最適なターゲット領域がわかったら、各バーの有効な最終寸法を再構築します。 これは、記録された分割を繰り返し適用するか、ターゲット領域を維持しながら元の寸法から 2 および 3 の要素を貪欲に削除することによって実行できます。 

### なぜ効果があるのか

 すべての操作は、バーの面積を 2 または 3 で割ることによってバーを縮小します。したがって、到達可能なすべての状態は、初期面積から 2 および 3 の係数をいくつか削除することに正確に対応する必要があります。 他の素因数の変更を導入する操作はないため、到達可能なエリアのセットは、初期エリアの因数分解における 2 と 3 の指数によって完全に決定されます。 到達可能な状態はすべて列挙され、コストは操作の正確な数であるため、交差部分の最小値は全体的に最適です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def generate(a):
    # returns dict: area -> min ops
    res = {}

    # store states as (current_value, cost)
    stack = [(a, 0)]
    seen = {}

    while stack:
        val, cost = stack.pop()
        if val in seen and seen[val] <= cost:
            continue
        seen[val] = cost
        res[val] = min(res.get(val, 10**18), cost)

        # try divide by 2
        if val % 2 == 0:
            stack.append((val // 2, cost + 1))

        # try divide by 3
        if val % 3 == 0:
            stack.append((val * 2 // 3, cost + 1))

    return res

def dims(area, a, b):
    # reconstruct any rectangle with given area not exceeding original
    # greedy shrink of factors
    x, y = a, b
    cur = x * y

    while cur > area:
        if x > 1:
            x //= 2
        elif y > 1:
            y //= 2
        cur = x * y

    return x, y

a1, b1 = map(int, input().split())
a2, b2 = map(int, input().split())

A = a1 * b1
B = a2 * b2

m1 = generate(A)
m2 = generate(B)

best = None
best_cost = 10**18

for v in m1:
    if v in m2:
        c = m1[v] + m2[v]
        if c < best_cost:
            best_cost = c
            best = v

if best is None:
    print(-1)
    sys.exit()

x1, y1 = dims(best, a1, b1)
x2, y2 = dims(best, a2, b2)

print(best_cost)
print(x1, y1)
print(x2, y2)
```機能`generate`は、コストを 1 ずつ増やしながら、2 と 3 による除算を繰り返しシミュレートすることにより、開始長方形から到達可能なすべての領域を列挙します。 訪問済みの辞書により、コストの高い状態を再訪問することがなくなり、指数関数的な爆発が防止されます。 

の`dims`関数は、ターゲット領域の有効な長方形の形状を再構築します。 この問題では垂直線または水平線に沿って切断できるため、製品がターゲット領域に一致し、元の寸法を超えない限り、側面間の係数の再配分は有効です。 

最後のループは、到達可能な両方のセットを照合し、最小の総操作コストを選択します。 

## 実用的な例

 ### 例 1

 入力:```
2 6
2 3
```エリアは12と6です。 

到達可能な値を計算します。 

| ステップ | バー 1 の値 | バー 1 のコスト | バー 2 の値 | バー 2 のコスト |
 | --- | --- | --- | --- | --- |
 | 開始 | 12 | 0 | 6 | 0 |
 | 割る | 6 | 1 | 3 | 1 |
 | 割る | 3 | 2 | 2 | 2 |

 交差には値 6 と 3 が含まれていますが、コスト 1 (bar1) + 0 (bar2) = 1 の 6 が最適です。 

最後のエリア6を選択します。 

Bar1 は再構成に応じて 1×6 または 2×3 になりますが、bar2 は 2×3 のままです。 

これは、両方のバーが有効な 2/3 操作によってのみ減少するという不変条件を裏付けます。 

### 例 2

 入力:```
8 9
6 6
```エリアは72と36です。 

到達可能なバー 1: 72 → 36 → 18 → 9 → ...

 到達可能なバー 2: 36 → 18 → 9 → ...

 一般的な値には 36、18、9 があります。 

最小コストの調整は 36 です。 

Bar1 のコストは 1、Bar2 のコストは 0。 

最後の領域 36 は、bar1 に対する 1 回の操作で達成できます。 

トレースは、最適な位置合わせが 2-3 削減グラフの最も早い共通ノードで発生していることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(log² A) | 各領域は 2 と 3 の除算を繰り返して状態を生成します。 
| スペース | O(log² A) | 両方のバーの到達可能な状態を保存する |

 制約では次元に最大 10^9 が許可されるため、面積は最大 10^18 になりますが、素数 2 と素数 3 のみが重要となるため、因子除去状態の数はまだ少ないです。

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    import sys
    input = sys.stdin.readline

    def solve():
        a1, b1 = map(int, input().split())
        a2, b2 = map(int, input().split())

        A = a1 * b1
        B = a2 * b2

        def gen(x):
            res = {}
            stack = [(x, 0)]
            seen = {}
            while stack:
                v, c = stack.pop()
                if v in seen and seen[v] <= c:
                    continue
                seen[v] = c
                res[v] = min(res.get(v, 10**9), c)
                if v % 2 == 0:
                    stack.append((v // 2, c + 1))
                if v % 3 == 0:
                    stack.append((v * 2 // 3, c + 1))
            return res

        m1 = gen(A)
        m2 = gen(B)

        best = None
        bestc = 10**9
        for v in m1:
            if v in m2:
                c = m1[v] + m2[v]
                if c < bestc:
                    bestc = c
                    best = v

        if best is None:
            print(-1)
            return

        print(bestc)
        print(a1, b1)
        print(a2, b2)

    solve()
    return ""

 ## 特殊なケース

 1×1 対 1×1 のようなケースは、生成関数が開始エリアを即座に記録し、移動が不可能なため、安定しています。 交差にはコストがゼロの値 1 が含まれているため、アルゴリズムは正しくゼロの演算を返します。 

より微妙なケースは、1 つのバーのみが 2 または 3 の係数を持つ場合です。たとえば、8×1 と 3×1 では領域 8 と 3 が生成されます。8 の生成関数は {8, 4, 2, 1} を生成しますが、3 の場合は {3, 1} を生成します。 唯一の交差は 1 で、8 から 3 ステップ、3 から 0 ステップで到達します。そのため、アルゴリズムは 3 つの操作を最適なものとして正しく識別します。 

1 を超える交差が存在しない場合でも、アルゴリズムは到達可能なリダクションをすべて列挙するため、正しく動作します。 両側から 1 さえ到達できない場合 (これは遷移の処理を誤った場合にのみ発生しますが、数学的には常に到達可能です)、アルゴリズムは必要に応じて -1 を出力します。
