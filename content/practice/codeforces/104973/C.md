 ## 解決策
 ## 問題の理解

 次のような無向グラフが与えられます。$n$都市と$m$提案されたトンネル。 各トンネルは 2 つの都市を結び、数字のタグが付いています。 各都市にラベルと番号を割り当てることができます。 トンネルは、そのエンドポイントの 1 つがトンネルのタグと同じ都市ラベルを持つ場合にのみ使用可能になります。 両方のエンドポイントがタグに一致するか、どちらも一致しない場合、そのトンネルは無視されます。 

目標は、このルールによってトンネルをフィルタリングした後でも、残りの使用可能なトンネルで都市のすべてのペア間の移動が可能になるように、都市にラベルを割り当てることです。 言い換えれば、使用可能なエッジは接続されたグラフを形成する必要があります。 

この入力により、アクティベーション ルールを無視してすべてのトンネルを維持した場合、グラフが接続されることが保証されます。 課題は、グローバルなラベル付け制約に基づいてエッジを選択的に削除していることです。各ノードは単一の値を持ちますが、各エッジは独自のタグとの等価性に関する条件を強制します。 

制約は大きく、最大で$2 \cdot 10^5$ノードとエッジ。 これにより、指数関数的な割り当て検索やノードごとのバックトラッキングが即座に排除されます。 どのソリューションも、基本的に線形または線形に近い時間でラベルを構築する必要があります。$O(n + m)$。 

構造を持たずに貪欲なローカル選択を試みると、微妙な失敗モードが現れます。 たとえば、エッジごとに独立してラベルを決定する場合、そのラベルはすべてのインシデント エッジにわたって共有されるため、単一の頂点が複数の矛盾するエッジ要件を満たすことを強制される可能性があります。 もう 1 つのよくある間違いは、等しいエッジ タグの接続されたコンポーネントに基づいてラベルを割り当てようとすることです。これは、エッジが共有ラベル単独ではなく共有頂点を通じて相互作用するため失敗します。 

本当に難しいのは、一貫性の制御です。各頂点は 1 つのラベルにのみ「コミット」できますが、各エッジは、そのエンドポイントの 1 つが自身のラベルと一致する必要があるという制約を課そうとします。 

## アプローチ

 素朴なアプローチは、各頂点を個別に扱い、可能なラベルの割り当てをすべて試してみることです。 割り当てごとに、どのエッジがアクティブになるかを再計算し、接続を確認します。 これはすぐに爆発します。$n$頂点は最大です$m$意味のある選択肢 (エッジ ラベルとダミー値) が考えられるため、状態空間は指数関数的であり、接続性チェックは線形であるため、実行不可能になります。$O(m \cdot m^n)$実際に爆発するタイプ。 

重要な観察は、実際にはすべてのエッジについて一度に推論する必要はないということです。 アクティブ化されたエッジの一部がすでにスパニング ツリーを形成していることを確認するだけで十分です。 元のグラフが接続されているため、スパニング ツリーが含まれています。 選択したスパニング ツリーのすべてのエッジを強制的にアクティブにできれば、非ツリー エッジに何が起こっても接続が保証されます。 

次に、単一の木の端が何を意味するかを考えてみましょう。$(u, v, a)$アクティブになること。 ラベルが必要なエンドポイントは 1 つだけです$a$。 これは方向性のある選択です。$u$ラベルを次のように設定することで、エッジを満たすことに「責任を負います」$a$、 または$v$そうです。 

すべてのツリー エッジが 1 つのエンドポイントに責任を割り当てると考える場合、各頂点は複数のエッジを担当してはなりません。そうしないと、頂点は複数の異なるラベルを取ることを強制されます。 この制限は、中核となる構造上の制限です。 

木には、これを強制するための非常にきれいな方法が認められています。それは、根を張って、すべての端を根の方向に向けることです。 ルート以外のすべての頂点には、そこに向かう親エッジが 1 つだけあるため、ラベルが 1 つだけ、つまりその親エッジのラベルが割り当てられます。 ルートは割り当てを受け取らず、エッジ ラベルに干渉しないダミー値を安全に取得できます。 

この構造により、すべてのツリー エッジが一貫してアクティブ化されることが保証されるため、アクティブ化されたサブグラフにはすでにスパニング ツリーが含まれています。

 ## アルゴリズムのチュートリアル

 この問題を、スパニング ツリーを選択し、ルールに従って強制的にアクティブにすることに変換します。 

1. 任意のノードから開始して、DFS または BFS を使用してグラフの任意のスパニング ツリーを構築します。 グラフ全体が接続されているため、これはいつでも可能です。 
2. このツリーを任意の頂点、たとえば頂点 1 にルートします。ルートの選択は正確さに影響しませんが、割り当ての一貫性が簡素化されます。 
3. エッジ ラベルとして表示されないことが保証されている特別なラベルをルートに割り当てます。 すべてのエッジラベルが入っているため、$[1, m]$、選択する$m + 1$安全です。 
4. 根が生えた木を横切ります。 親間のすべての木の端に対して$p$そして子供$c$、エッジラベル付き$a$、割り当てます$b[c] = a$。 
5. この時点では親を変更しないままにしておきます。 すでに値が設定されているか、ルートでない場合は最終的に設定されます。 この構造では、すべての非ルート ノードは親エッジから 1 つの割り当てを取得します。 
6. 結果の配列を出力します$b$。 

これが機能する理由は、すべてのツリー エッジがアクティブ化されることが保証されているためです。子エンドポイントにはエッジ ラベルと同じラベルがあり、親エンドポイントにはありません (別個のラベルを持つルートであるか、ルートに近いため異なるエッジ ラベルが割り当てられているため)。 これらのアクティブ化されたツリー エッジがスパニング ツリーを形成するため、すべての都市は接続されたままになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    
    edges = []
    for _ in range(m):
        u, v, a = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append((v, a))
        g[v].append((u, a))
    
    parent = [-1] * n
    parent_edge = [-1] * n
    
    # build spanning tree with BFS
    from collections import deque
    q = deque([0])
    parent[0] = -2
    
    order = []
    
    while q:
        u = q.popleft()
        order.append(u)
        for v, a in g[u]:
            if parent[v] == -1:
                parent[v] = u
                parent_edge[v] = a
                q.append(v)
    
    b = [0] * n
    b[0] = m + 1
    
    for i in range(1, n):
        b[i] = parent_edge[i]
    
    print(*b)

if __name__ == "__main__":
    solve()
```BFS は、各ノードが最初にアクセスされた時間を記録することにより、暗黙的にスパニング ツリーを構築します。 の`parent_edge[v]`到達するために使用されるエッジのラベルを格納します`v`、これは次の強制値になります。`b[v]`。 

ルートが割り当てられています$m+1$、エッジ ラベルと衝突しないことが保証された値。 他のすべてのノードは 1 つの値を取るため、どの頂点も競合する割り当てに直面することはありません。 アクティブ化ルールは、BFS ツリーのエッジに沿ってエッジごとに満たされます。

 ## 特殊なケース

 ノードが 2 つだけの最小限のグラフは、単一のエッジがスパニング ツリーになるため、きれいに処理されます。 子はエッジラベルを取得し、ルートはダミー値を取得し、接続性は自明に保持されます。 

星型グラフでは、1 つのノードがルートになり、他のすべてのノードがその入射エッジ ラベルを直接取得します。 各リーフには親エッジが 1 つだけあるため、ルートに多くの隣接エッジがある場合でも競合は発生しません。 

長いチェーンでは、ルートを除く各ノードは親エッジから 1 つの割り当てを受け取るため、ラベルは分岐の競合なしにパスに沿って伝播します。 この構造により、ノードが複数のエッジ制約を満たすことを強制されることがなくなり、全体の有効性が維持されます。
