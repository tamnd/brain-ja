 ## 解決策
 ## 問題の理解

 私たちは持っています`n`2D 平面上の塔。 すべてのタワーは、2 人の将軍のうちの 1 人に属している必要があります。 各将軍に対して要求するコストは、彼に割り当てられた 2 つの塔の間のマンハッタンの最大距離です。 王は 2 つの費用のうち大きい方のみを支払います。 

タスクは、大きな内径ができるだけ小さくなるようにタワーを 2 つのグループに分割することです。 この最小可能値を見つけた後、それを達成する割り当ての数もカウントする必要があります。 

2 つのタワー間のマンハッタン距離は次のとおりです。$$|x_1 - x_2| + |y_1 - y_2|$$最初の課題は最適化です。 2 番目の課題は、すべての最適なパーティションをカウントすることです。 

この制約により、ブルートフォースパーティショニングが完全に排除されます。 がある`2^n`課題と`n`まで上がります`5000`。 すべてのサブセットをチェックしても、`n = 40`もう無理でしょう。 二次時間に近いものが必要です。 

非常に重要な観察は、マンハッタン距離が標準の座標変換後に適切に動作することです。$$u = x + y,\quad v = x - y$$マンハッタン距離の場合、$$dist(p_i, p_j) = \max(|u_i-u_j|, |v_i-v_j|)$$つまり、「距離は D を超えてはいけない」というすべての制約が 2 つの間隔制約になります。 

いくつかの微妙なエッジケースがあります。 

すべてのタワーがコストを伴う 1 つのグループに収まる場合`0`の場合、すべてのタワーの座標が同一である必要があります。 このステートメントは明確な点を保証するため、答えを得る唯一の方法です`0`各将軍に最大 1 つのタワーを割り当てます。 例えば：```
2
0 0
1 1
```最適な答えは`0`, 各将軍が 1 つの塔を取得するためです。 両方のグループが空でない必要があると仮定する不注意な解決策は、誤って返されます。`2`。 

多くのペアが制限を超える場合、別の危険なケースが発生します。 仮定する：```
4
0 0
10 0
0 10
10 10
```限界がある場合`10`、反対側のコーナーは同じグループに属することはできません。 これらの制約はグローバルに相互作用します。 局所的な選択がグラフ全体に伝播するため、貪欲な色付けは失敗する可能性があります。 

3 番目のトラップが重要です。 考慮する：```
3
0 0
1 0
100 0
```限界の場合`1`、遠いタワーは近いペアから分離する必要があります。 どの将軍が孤立したタワーを取得するかに応じて、有効な割り当ては 2 つあります。 連結成分を誤って数えると、簡単に二重に数えたり、対称的な割り当てを見逃したりする可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 最初の将軍の割り当てとして塔のすべてのサブセットを試し、2 番目の将軍として補足を試してください。 各パーティションについて、各グループ内の最大ペアごとのマンハッタン距離を計算し、2 つの大きい方を取ります。 

1 つのパーティションのチェックにかかる時間`O(n^2)`すべてのペアを検査する必要がある場合があるため、時間がかかります。 あるので`2^n`パーティションを分割すると、全体の複雑さは次のようになります。$$O(2^n n^2)$$それは絶望的だ`n = 5000`。 

重要な観察は、問題を逆転させることです。 答えを直接最小化する代わりに、候補値を固定するとします。`D`。 

ここで次のように尋ねてください。 

「同じグループ内のすべてのペアの距離が最大になるように、塔を 2 つのグループに分割できますか?」`D`？」

 同様に、距離が次を超えるすべてのペアは、`D`異なるグループに属している必要があります。 

それはすぐにグラフの問題になります。 

頂点が塔であるグラフを作成し、マンハッタン距離が より大きい場合は 2 つの塔を接続します。`D`。 有効なパーティションでは、すべてのエッジのエンドポイントを反対側のグループに配置する必要があります。 したがって、グラフは 2 部構成でなければなりません。 

これにより、ジオメトリがグラフの色付けに変換されます。 

次の洞察は幾何学的なものです。 変換された座標の下で$$u=x+y,\quad v=x-y$$マンハッタン距離は$$\max(|\Delta u|, |\Delta v|)$$したがって、エッジが存在するのは$$|u_i-u_j| > D \quad \text{or} \quad |v_i-v_j| > D$$制限に違反するペアは、ソート後に効率的に生成できます。 

最後に、実行可能な最小値を二分探索します。`D`。 各候補について、二部性をテストし、有効なカラーリングの数を数えます。 

接続された各 2 部構成要素は、その構成要素内で色を交換する可能性があるため、正確に 2 つの有効な色付けに寄与します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^nn^2) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2 log C) | O(n^2) | 承認済み |

 ここ`C`は座標範囲です。 

## アルゴリズムのチュートリアル

 1. すべてのタワーの座標を読み取ります。 
2. すべてのペアごとのマンハッタン距離を事前計算します。 

これにより、二分探索中の距離の再計算が回避されます。 

1. 最小値を二分探索する`D`禁止されたペアのグラフが二部になるようにします。 

2 つの塔の距離が 2 よりも大きい場合`D`、同じ将軍に属することはできません。 

1.固定の場合`D`、グラフを構築します。 

間にエッジを追加します`i`そして`j`いつでも$$dist(i,j) > D$$1. BFS または DFS の 2 部カラーリングを実行します。 

色の割り当て`0`そして`1`エッジに沿って交互に。 

エッジが同じ色の 2 つの頂点を接続している場合、グラフは 2 部ではなく、`D`不可能です。 

1. グラフの連結成分を数えます。 

接続されたすべての 2 部コンポーネントには、そのコンポーネント内のすべての色を反転することによって得られる、正確に 2 つの有効な色があります。 

あれば`k`連結成分、割り当ての数が等しい$$2^k$$1. 最初の実現可能性`D`二分探索で見つけたものが最適解です。 
2. この最適化について 2 部構成チェックを再実行します。`D`有効な割り当ての数を剰余として出力します`10^9+7`。 

### なぜ効果があるのか

 固定制限の場合`D`、より遠くにある塔のペア`D`同じグループに留まることはできません。 したがって、そのようなペアはすべて「異なっていなければならない」という制約を作成します。 

2 つの一般への分割は、まさにこの制約グラフの 2 色分けです。 グラフが 2 部に分かれていない場合、何らかの奇妙なサイクルにより矛盾が生じ、分割が不可能になります。 

逆に、すべての禁止されたペアがパーティション全体に存在するため、すべての 2 部カラーリングにより有効な割り当てが生成されます。 これにより、同じグループ内のすべてのペアが最大でも距離を持つことが保証されます`D`。 

したがって、実現可能性は二者構成と同等です。 

二分探索が機能するのは、実現可能性が単調であるためです。 値の場合`D`が実現可能であれば、制限に違反するペアの数が少ないため、より大きな値もすべて実現可能です。 

## Python ソリューション```python
import sys
from collections import deque

input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]

    dist = [[0] * n for _ in range(n)]
    mx = 0

    for i in range(n):
        x1, y1 = pts[i]
        for j in range(i + 1, n):
            x2, y2 = pts[j]
            d = abs(x1 - x2) + abs(y1 - y2)
            dist[i][j] = dist[j][i] = d
            mx = max(mx, d)

    def check(D):
        g = [[] for _ in range(n)]

        for i in range(n):
            row = dist[i]
            gi = g[i]
            for j in range(i + 1, n):
                if row[j] > D:
                    gi.append(j)
                    g[j].append(i)

        color = [-1] * n
        comps = 0

        for s in range(n):
            if color[s] != -1:
                continue

            comps += 1
            color[s] = 0
            q = deque([s])

            while q:
                v = q.popleft()

                for to in g[v]:
                    if color[to] == -1:
                        color[to] = color[v] ^ 1
                        q.append(to)
                    elif color[to] == color[v]:
                        return False, 0

        return True, pow(2, comps, MOD)

    lo, hi = -1, mx

    while hi - lo > 1:
        mid = (lo + hi) // 2

        ok, _ = check(mid)

        if ok:
            hi = mid
        else:
            lo = mid

    _, ways = check(hi)

    print(hi)
    print(ways)

solve()
```最初のセクションでは、すべてのペアごとのマンハッタン距離を事前計算します。 以来`n = 5000`、完全な行列の保存は大きくなりますが、整数を使用して慎重に実装すれば、Python で管理できます。 

の`check(D)`関数は非互換性グラフを作成します。 2 つのタワーは、同じグループに属せない場合に正確に接続されます。 

BFS カラーリングは標準的な 2 部テストです。 未訪問の頂点により、新しい接続コンポーネントが開始されます。 コンポーネントの色をグローバルに反転できるため、コンポーネントが成功すると、有効な割り当ての数が 2 倍になります。 

二分探索は単調性に依存します。 多少なら`D`グラフはエッジを失うだけなので、より大きな値でも機能します。 

微妙な詳細の 1 つは、孤立した頂点です。 それらはコンポーネントも形成し、次の要因に寄与します。`2`。 これは、他の者の制約を受けない塔はどちらの将軍のものでもよいという解釈と一致します。 

もう 1 つの微妙な点は、割り当てのカウントです。 この声明は、最初の将軍に与えられた正確なセットによって割り当てを区別します。 2 つの将軍を交換すると、異なる割り当てが作成されるため、すべてのコンポーネントが実際に 2 つの選択肢に貢献します。

        for i in range(n):
