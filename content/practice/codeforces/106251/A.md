 ## 解決策
 ## 問題の理解

 このタスクでは、内部に視覚的なパターンを構築する方法について説明します。$N \times N$グリッド。 すべてのセルには最初にドット文字が含まれており、その後、特定のセルがハッシュ文字で上書きされ、対称的な描画が形成されます。 

図面は 4 つの独立したコンポーネントで構成されます。 まず、左端の列全体がハッシュで埋められ、垂直線が形成されます。 次に、右端の列全体も塗りつぶされ、2 番目の垂直線が形成されます。 3 番目に、左上隅からグリッドの中心に向かって斜めの線が引かれ、中央の行インデックスで止まります。 最後に、右上隅から同じ中央の行に向かって別の対角線を引き、グリッドの中央付近で交わるミラーリングされたストローク パターンを作成します。 

出力は、これらすべてのマーキングを行った後の最終グリッドであり、行ごとに文字列として印刷されます。 

唯一の操作がグリッド内のセルを埋めることであるため、制約は事実上最小限です。 大型の場合でも$N$、この構築では、初期化中に各セルに最大 1 回タッチすることと、エッジと対角線に対して行ごとに一定の数の書き込みを行う必要があります。 これにより、複雑なデータ構造や配列の直接操作を超える最適化の必要性が即座に排除されます。 

主なエッジケースは幾何学的縮退です。$N$とても小さいです。 いつ$N = 1$、4 つのコンポーネントすべてが同じ 1 つのセルに折りたたまれるため、推論の重複を避けるために注意が必要ですが、最終結果は依然として 1 つのハッシュです。 いつ$N = 2$、対角線が境界線と大きく重なっており、切り離されたセグメントを想定した単純な実装では、インデックスが誤ってスキップされたり二重処理されたりする可能性があります。 もう 1 つの微妙なケースは、中点定義での整数の除算です。対角線は次の位置で止まります。$\lfloor N/2 \rfloor$、奇数の場合$N$の場合は中央の列が含まれますが、偶数の場合は$N$、対角線は下半分のすぐ上で終わります。 

## アプローチ

 ブルートフォースアプローチは、文字通り、一定のサイズのグリッドを構築することです。$N \times N$、すべてのセルをドットで初期化し、記述された各幾何学的コンポーネントを反復処理して、セルを 1 つずつマークします。 これが機能するのは、各操作が単純かつローカルであり、文字の上書き以外のセル間の相互作用がないためです。 操作の合計数は、グリッド内のセルの数にマークされた位置の数を加えたものに比例します。 

単純な実装は、組み合わせの爆発や依存関係の連鎖がないため、すでに問題の最適な構造と一致しています。 ただし、変換を繰り返し適用したり、セルごとにジオメトリを再計算したりするなど、より抽象的なシミュレーションを試みると、出力を変更せずに複雑さが不必要に増加します。 重要な観察は、各セルの最終値が独立して決定されることです。セルは、指定された 4 つの構造の少なくとも 1 つに存在する場合、ハッシュになります。 

したがって、問題は固定インデックス セットの直接マーキングに帰着します。 これにより、動的な更新や、座標を 1 回通過する以上の反復が必要なくなります。

 ## アルゴリズムのチュートリアル

 1.$N \times N$グリッド全体が文字「.」で埋められています。 これは、すべてのストロークが描画される基本状態を形成します。 
2. 列 0 のすべてのセルを「#」に設定して、左側の境界線を塗りつぶします。 これにより、左端に沿って連続的な垂直ストロークが保証されます。 
3. 列内のすべてのセルを設定して、右の境界線を塗りつぶします。$N-1$に '＃'。 これにより、左の境界線がミラーリングされ、フレームが完成します。 
4. 行 0 から行 0 までを繰り返して、最初の対角線を描画します。$\lfloor N/2 \rfloor$そして設定セル$(i, i)$に '＃'。 これにより、左上から中央に向かって下降する対角線が作成されます。 停止点により、ストロークが下半分に及ばず、意図した形状が維持されます。 
5. 行 0 から行 0 までを繰り返して 2 番目の対角線を描画します。$\lfloor N/2 \rfloor$そして設定セル$(i, N-1-i)$に '＃'。 これにより、右上から中心に向かって対称的な下降対角線が形成されます。 
6. グリッドの各行を文字列に変換して出力します。 

### なぜ効果があるのか

 各操作は、他の変換から独立した決定論的な座標セットに対応します。 セルは、定義された幾何学的セット (左境界線、右境界線、または 2 つの対角線のいずれか) の少なくとも 1 つに属する場合に正確にマークされます。 すべての操作は「.」からの単調な上書きであるため、 '#' に変更すると、後のステップで以前のマーキングを無効にすることはできません。 これにより、最終的なグリッドが正確にこれらの座標セットの結合であることが保証され、これはまさに意図した構造になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input().strip())
    grid = [['.'] * n for _ in range(n)]

    for i in range(n):
        grid[i][0] = '#'
        grid[i][n - 1] = '#'

    limit = n // 2
    for i in range(limit + 1):
        grid[i][i] = '#'
        grid[i][n - 1 - i] = '#'

    for row in grid:
        print(''.join(row))

if __name__ == "__main__":
    solve()
```この解決策は、セルごとに一定の時間で更新を適用できるように、完全な文字マトリックスを構築することから始まります。 左右の境界線は行を 1 回通過するだけで塗りつぶされ、直線的な作業が保証されます。$N$。 次に、対角線は、偶数と奇数の両方の値が得られるように、整数の除算を慎重に使用して、中間点のインデックスまでのみ描画されます。$N$正しく行動する。 最後に、各行が出力用の文字列に結合されます。 

実装の微妙な詳細は、すべての構造で同じグリッドを再利用することです。 これにより、'#' を複数回書くことは冪等であるため、対角線と境界線の間の重なりに特別な処理が必要なくなります。

 ## 特殊なケース

 のために$N = 1$、4 つのジオメトリ コンポーネントすべてが同じ単一セルに折りたたまれます。 グリッドは「.」で始まり、境界線の塗りつぶしによって「#」に上書きされ、両方の対角線も同じセルをターゲットとします。 「#」の書き込みは冪等であるため、最終結果は単一の「#」のままになります。 

のために$N = 2$、あらゆる構造が重なり合っています。 左右の境界線はすでにグリッド全体を埋めており、対角線は同じセルに繰り返し書き込まれます。 このアルゴリズムは、互いに素な領域を決して想定しないため、引き続き正しく動作します。 

奇数の場合$N$、対角線は中央のセルで正確に交わります$(\lfloor N/2 \rfloor, \lfloor N/2 \rfloor)$を含める必要があります。 ループ境界にはこのインデックスが明示的に含まれており、交差点が見逃されないことが保証されます。 

偶数の場合$N$、対角線は下半分の 1 行上で停止します。 これにより、意図しない領域への偶発的な拡張が防止され、厳密な中間点交差ではなくフロア分割を使用する定義と一致します。
