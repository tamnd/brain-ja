 ## 解決策
 ## 問題の理解

 正の整数が与えられます$X$ベースに書かれている$B$一連の数字として。 

タスクは、2 つの正の整数が存在するかどうかを判断することです。$Y$そして$Z$次のような:$$X + Y = Z$$そしてベースは-$B$の表現$Y$そして$Z$まったく同じ複数の数字セットが含まれています。 桁の順序は異なる場合がありますが、両方の数字ですべての桁が同じ回数出現する必要があります。 

そのような数値が存在する場合は、有効なペアを 1 つ出力する必要があります。 それ以外の場合は出力します`NO`。 

入力サイズが大きいです。 単一の数値には最大で次の数値を含めることができます。$10^5$桁数、すべてのテスト ケースの合計桁数は最大で$2 \cdot 10^5$。 値全体を組み込みの整数型に変換しようとする解決策は不可能です。 ベース上で直接動作するアルゴリズムが必要です。$B$数字表現であり、線形時間で実行されます。 

最も重要な観察は、桁の合計から得られます。 同じ複数の桁セットを持つ 2 つの数値は、まったく同じ桁の合計になります。 基地内$B$、$$N \equiv \text{sum of digits of } N \pmod{B-1}.$$以来$Y$そして$Z$同じ数字を使用し、$$Y \equiv Z \pmod{B-1}.$$使用する$Z-Y=X$、$$X \equiv 0 \pmod{B-1}.$$これは必須条件です。 

不注意な実装は、ここで停止して、割り算のみをテストする可能性があります。 より難しいのは、この条件も十分であることを証明し、有効な答えを構築することです。 

基本の小さな例を考えてみましょう$10$:```
X = 36
```桁の合計は$3+6=9$、 それで$X$で割り切れます$9$。 有効な答えは、```
Y = 105
Z = 150
```どちらも数字を使用します`{1,0,5}`、 そして$$150 - 105 = 45 \neq 36.$$同じ数字を持っているだけでは十分ではありません。 構築では、必要な差異を正確に生成する必要があります。 

もう 1 つのエッジケースは次のような場合です$X$桁は 1 つだけです。```
B = 2
X = 1
```以来$B-1=1$、すべての数値は次で割り切れます。$B-1$。 解決策はまだ存在しているはずです。 商が複数の桁であると仮定するアプローチは、ここでは失敗します。 

3 番目の微妙なケースは、除算後の商に先行ゼロが含まれる場合です。 例えば、```
B = 10
X = 18
```それから$X/(B-1)=2$。 商の表現は単純に`[2]`、 ない`[0,2]`。 長い除算では、先頭のゼロを正しく削除する必要があります。 

## アプローチ

 ブルートフォースのアイデアは、候補となる数字のマルチセットを生成し、すべての順列を構築することです。$Y$そして$Z$、どうかを確認してください。$Z-Y=X$。 順列の数は桁数に応じて階乗的に増加するため、これは非常に小さな入力に対してのみ機能します。 長さが 20 であっても、検索はすでに完全に不可能になります。 

重要な観察はモジュラー演算です。 

なぜなら$Y$そして$Z$同じ数字が含まれている場合、それらの数字の合計は同じになります。 基地内$B$、すべての数値はその桁和を法とするものと一致します。$B-1$。 したがって、$$Y \equiv Z \pmod{B-1}.$$以来$X=Z-Y$、$$X \equiv 0 \pmod{B-1}.$$これは直ちに必要条件を与えます。 

驚くべきことは、それが十分であるということです。 

させて$$K=\frac{X}{B-1}.$$ベースを仮定すると、$B$の桁$K$は$$d_1,d_2,\ldots,d_m.$$構築する$$Y = (1,0,d_1,d_2,\ldots,d_m)_B$$そして$$Z = (1,d_1,d_2,\ldots,d_m,0)_B.$$2 つの数字は明らかにまったく同じ数字を含んでいます。両方とも 1 桁を含んでいます。`1`、1桁`0`、およびすべての桁$K$。 

数値的には、$$Y = 1\cdot B^{m+1}+K,$$

$$Z = 1\cdot B^{m+1}+B\cdot K.$$減算すると、$$Z-Y=(B-1)K=X.$$だから、すべての$X$で割り切れる$B-1$解決策を認めます。 

問題全体は次のようになります。 

1. かどうかを確認します。$X$で割り切れます$B-1$。 
2.そうでない場合は出力`NO`。 
3. それ以外の場合は計算します$K=X/(B-1)$数字配列で長い除算を使用します。 
4. 上記の構築を出力します。

 ## アルゴリズムのチュートリアル

 1. ベースを読んでください。$B$の桁$X$。 
2. 桁和モジュロを計算します。$B-1$。 

以来$B \equiv 1 \pmod{B-1}$、数値は次で割り切れます。$B-1$ちょうどその桁の合計が次の値で割り切れるとき$B-1$。 
3. 剰余がゼロ以外の場合、出力`NO`。 

同じ桁のマルチセットを持つ 2 つの数値は合同モジュロであるため、有効なペアは存在できません。$B-1$。 
4. の桁配列を分割します。$X$による$B-1$ベースで標準の長い除算を使用する$B$。 

残りを維持します。 各桁ごとに更新します$$cur = remainder \cdot B + digit,$$発する$$cur // (B-1),$$そして保管してください$$cur \bmod (B-1).$$5. 商から先頭のゼロの数字を削除します。 残りの数字は基数です。$B$の表現$K$。 
6. 商の桁を次のようにします。$d_1,\ldots,d_m$。 
7. 出力$$Y=(1,0,d_1,\ldots,d_m)$$そして$$Z=(1,d_1,\ldots,d_m,0).$$### なぜ効果があるのか

 等しい桁のマルチセットは等しい桁の和を意味し、数値はその桁の和を法とするものと一致するため、割り算テストが必要です。$B-1$。 したがって、すべての有効な$X$満たさなければなりません$X \equiv 0 \pmod{B-1}$。 

この条件が成立する場合、次のように定義します。$K=X/(B-1)$。 この構造では、同じ数字が次のように配置されます。$Y$そして$Z$、単に立場を変えるだけです。 それらの先頭の数字は常に`1`, したがって、どちらの数字にも先頭にゼロはありません。 

数値的な違いは、$$(1\cdot B^{m+1}+BK) - (1\cdot B^{m+1}+K)
= (B-1)K
= X.$$したがって、この構造は両方の要求特性を満たしており、十分であることが証明されている。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
out = []

for _ in range(t):
    n, b = map(int, input().split())
    a = list(map(int, input().split()))

    mod = b - 1

    if sum(a) % mod != 0:
        out.append("NO")
        continue

    # Long division: X / (B - 1)
    q = []
    rem = 0

    for digit in a:
        cur = rem * b + digit
        q.append(cur // mod)
        rem = cur % mod

    idx = 0
    while idx < len(q) - 1 and q[idx] == 0:
        idx += 1
    q = q[idx:]

    m = len(q) + 2

    y = [1, 0] + q
    z = [1] + q + [0]

    out.append("YES")
    out.append(str(m))
    out.append(" ".join(map(str, y)))
    out.append(" ".join(map(str, z)))

sys.stdout.write("\n".join(out))
```最初の部分では、割り切れるかどうかをチェックします。$B-1$数字の合計ルールを使用します。 これにより、膨大な価値を再構築することがなくなります。$X$。 

長除算セクションは次のように計算します。$K=X/(B-1)$数字配列から直接。 すべての中間値は最大でも$$(B-2)\cdot B + (B-1) < B^2,$$これは標準の整数に簡単に適合します。 

除算後、先頭のゼロは削除されます。 商は正規形式で表現する必要があるため、これは重要です。 

最終的な施工がまさにその証拠です。 2 つの配列には同じ数字が含まれており、どちらもゼロで始まることはなく、その差は次のとおりです。$X$。

        out.append("YES")
        out.append(str(m))
        out.append(" ".join(map(str, y)))

 ## 特殊なケース

 次のことを考慮してください。```
1
1 10
5
```桁の合計は$5$。 以来$5 \not\equiv 0 \pmod 9$、アルゴリズムはすぐに出力します`NO`。 有効なペアには次のものが必要です$X\equiv0\pmod9$、したがって、拒否は正しいです。 

考慮する：```
1
1 2
1
```ここ$B-1=1$。 すべての整数は次で割り切れます$1$。 長い除算で得られるもの$K=1$。 建設が生み出すのは、```
Y = [1,0,1]
Z = [1,1,0]
```そして$$110_2 - 101_2 = 1.$$可能な限り最小の入力は自然に処理されます。 

考慮する：```
1
2 10
1 8
```我々は持っています$18/9=2$。 長除算では最初に商の桁が生成されます`[0,2]`。 先頭のゼロが削除されて残ります。`[2]`。 この構築では、次の正規表現が使用されます。$K$これにより、出力内の偶発的な先行ゼロが防止されます。
