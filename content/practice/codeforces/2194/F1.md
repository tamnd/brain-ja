 ## 問題の理解

 私たちに与えられた木は、`n`頂点。各頂点は負ではない整数を持ちます。`a_v`そこに書かれています。 のセットもプレゼントされます`k`個別の非負の整数`b_1, ..., b_k`。 タスクは、結果として得られる接続コンポーネントのそれぞれが、セットに属する頂点値のビットごとの XOR を持つように、エッジを削除する方法の数をカウントすることです。`b`。 

言い換えれば、削除するエッジのサブセットを選択した後、接続された各サブグラフは、許可されているものの 1 つである合計 XOR を持つ必要があります。`b_i`価値観。 出力は、そのようなすべてのエッジ サブセットのモジュロ数です。`10^9 + 7`。 

重要な制約は次のとおりです。`n`まで行くことができます`10^5`すべてのテストケースにわたって、`k`は最大 4 です。これは十分に小さいため、`b`値は実現可能です。 エッジのすべてのサブセットを試す単純なアプローチは指数関数的であり、明らかに不可能です。 さらに、XOR は線形演算であるため、サブツリーからの結果を効率的に組み合わせることができますが、最先端のエッジがツリーをどのように分割するかを慎重に考慮する必要があります。 

次の場合、微妙なエッジケースが発生します。`k = 1`そして許可される唯一の XOR はゼロです。 このような場合、すべてのエッジ除去では、コンポーネントがゼロ以外の XOR を持たないという制約を尊重する必要があり、すべてのサブセットが大幅に制限される可能性があります。 もう 1 つの注意が必要なシナリオは、リーフ ノードだけがコンポーネントを形成する場合です。 たとえば、木に頂点がある場合、`[1,2,3]`価値観を持って`[0,1,1]`そして`b = {1}`、エッジを削除して頂点 1 を分離すると、有効なコンポーネントが生成されます。 すべてのノードが接続されたままでなければならないと想定する単純な実装では、そのような解決策が欠けてしまいます。 

## アプローチ

 ブルート フォース アプローチでは、エッジのすべてのサブセットを試して削除し、結果として得られる各コンポーネントの XOR を計算し、すべてのコンポーネントの XOR が一致するかどうかを確認します。`b`。 がある`2^(n-1)`エッジサブセット、これは明らかに不可能です`n = 10^5`。 各コンポーネントを個別にチェックできるため総当たり攻撃は機能しますが、サブセットの数が指数関数的に増加するため失敗します。 

重要な洞察は、コンポーネントの XOR はそのサブツリーの XOR のみに依存するということです。 ツリーを任意にルート化し、各ノードで動的プログラミング手順を実行できます。 させて`dp[u][mask]`をルートとするサブツリーを分割する方法の数を表します。`u`次のような XOR`u`のサブツリーとカットを組み合わせたビットマスクに対応します。`b`価値観。 以来`k <= 4`、せいぜいあります`16`マスクを使用することで、この DP が実現可能になります。 

基本的に、ツリー構造により、各ノードを再帰的に処理できます。 各ノードで、ビットマスクの畳み込みを使用して、その子の DP 結果を結合します。 また、子へのエッジを切断する可能性も考慮する必要があります。これにより、その子で新しいコンポーネントが効果的に開始されます。 このアプローチは、指数関数的なエッジサブセット問題を、小さな定数係数 DP を使用した線形トラバーサルに変換します。

 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n * n) | O(n) | 遅すぎる |
 | DP + ビットマスク | O(n * 2^k * 2^k) | O(n * 2^k) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ツリーと値を読み取る`a_v`とセット`b`。 ノード 1 でツリーを任意にルートします。 
2. それぞれをマップする`b_i`ビットインデックスへ`0..k-1`検索辞書を保存します`b_to_idx`。 これにより、XOR の結果をビットマスクとして効率的に表現できるようになります。 
3. 各ノードについて`u`、DP 配列を維持します`dp[u][mask]`サイズの`2^k`。`dp[u][mask]`のサブツリーを分割する方法の数を数えます。`u`結果として得られる XOR は、`u`のサブツリーは次のように表されます。`mask`。 
4. ルートから DFS を実行します。 ノードごとに初期化します`dp[u][mask_u] = 1`どこ`mask_u`単一の値を表します`a_u`との XOR`b`セット。 
5. それぞれの子どもたちに対して`v`の`u`、再帰的に計算します`dp[v]`。 組み合わせる`dp[u]`そして`dp[v]`2 つの方法: まずエッジを仮定します`(u,v)`が維持され、マージされます`v`の中へ`u`のコンポーネント、2 番目はエッジがカットされていると仮定し、次の位置で新しいコンポーネントを開始します。`v`。 それに応じてマスクを更新します。 
6. すべての子を処理した後、`dp[root][full_mask]`ツリー全体の有効な分割の数を示します。 許可されている XOR 値に対応するすべてのマスクを合計します。`b`。 
7. 結果のモジュロを出力します。`10^9 + 7`。 

機能する理由: 各ノードで、`dp[u]`は、すべての子を独立して考慮し、エッジを切断または維持することを考慮しているため、サブツリーを分割するすべての方法を正しくカウントします。 ビットマスク終了`b`無効な XOR 値をカウントしないようにします。 ルートは再帰的にサブツリーからすべての組み合わせを収集するため、完全性が保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(200000)

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, k = map(int, input().split())
        edges = [[] for _ in range(n)]
        for _ in range(n-1):
            u, v = map(int, input().split())
            edges[u-1].append(v-1)
            edges[v-1].append(u-1)
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        b_to_idx = {val:i for i,val in enumerate(b)}
        
        def val_to_mask(x):
            mask = 0
            for i, val in enumerate(b):
                if x == val:
                    mask |= (1 << i)
            return mask
        
        dp = [None]*n
        visited = [False]*n
        
        def dfs(u):
            visited[u] = True
            mask_u = val_to_mask(a[u])
            dp_u = [0]*(1<<k)
            dp_u[mask_u] = 1
            for v in edges[u]:
                if visited[v]:
                    continue
                dfs(v)
                new_dp = [0]*(1<<k)
                for m1 in range(1<<k):
                    if dp_u[m1]==0:
                        continue
                    for m2 in range(1<<k):
                        if dp[v][m2]==0:
                            continue
                        # keep edge: merge masks
                        merged = m1 ^ m2
                        new_dp[merged] = (new_dp[merged] + dp_u[m1]*dp[v][m2]) % MOD
                        # cut edge: treat child as separate component if its mask valid
                        for i in range(k):
                            if m2 == (1<<i):
                                new_dp[m1] = (new_dp[m1] + dp_u[m1]*dp[v][m2]) % MOD
                dp_u = new_dp
            dp[u] = dp_u
        
        dfs(0)
        res = 0
        for mask in range(1<<k):
            for i in range(k):
                if mask == (1<<i):
                    res = (res + dp[0][mask]) % MOD
        print(res)

if __name__ == "__main__":
    solve()
```このソリューションでは、DFS 再帰を設定し、DP 配列を構築し、維持されたエッジとカットされたエッジのマスクを慎重にマージします。 の`val_to_mask`関数は、各頂点の値がビットマスクにマッピングされることを保証します。`b`。 マージのネストされたループはサブツリーのすべての組み合わせを処理し、最終的な合計は有効な XOR 値を表すマスクのみをカウントします。 よくある間違いは、各乗算または合計の後に mod を忘れることで、オーバーフローしてしまいます。
