 ## 解決策
 ## 問題の理解

 長方形のグリッドがあります。 すべてのセルには、正または負の整数値が含まれます。 

ミケランジェロは、左上隅から右下隅への道を選択します。 彼は右か下にしか動かないかもしれない。 パスのスコアは、そのパス上で訪問したすべてのセル値の合計であり、常に最大のスコアを持つパスを選択します。 

ラファエルはパスを選択する前に、正確に 1 つのセルを選択し、その符号を反転します。 値`x`になる`-x`。 

ラファエロは、ミケランジェロの最終的な最適スコアをできるだけ小さくしたいと考えています。 ミケランジェロは修正されたグリッドを見て、最善の道を選択します。 

テスト ケースごとに、Raphael が強制できる最小スコアを計算する必要があります。 

グリッドには最大でも次のものが含まれます`10^6`すべてのテスト ケースにわたるセル。 これにより、反転される可能性のあるすべてのセルに対して完全な動的プログラミング テーブルを再計算するアプローチは即座に排除されます。 シングル`O(nm)`DPでもいいけど、`O((nm)^2)`完全に不可能なときは`nm = 10^6`。 

難しいのは、セルが反転された後、ミケランジェロがまったく別のパスに切り替わる可能性があることです。 彼が以前と同じ最適なパスを使い続けるとは考えられません。 

小さな例を考えてみましょう。```
1 100
100 1
```元の最適パスは 3 つのセルを使用しており、値があります`102`。 

ラファエルがひっくり返すと、`100`右上隅では、ミケランジェロは単純にルートを変更し、別のルートを使用します。`100`。 

元の最適パスのみを検討するソリューションは、ここでは失敗します。 

見落としやすいもう 1 つのケースは、複数の異なる最適なパスが存在する場合です。```
0 0
0 0
```どの道にも価値がある`0`。 

セルを反転しても何も変わりません。 反転されたセルが 1 つの最適なパス上にある場合でも、ミケランジェロは同じスコアを持つ別のパスを選択できます。 「最適なパスを破壊すると最適なパスも破壊される」と仮定する解決策は間違っています。 

3 番目のコーナー ケースは、セルが 1 つだけ含まれる対角線上で発生します。```
5
```開始セルと終了セルは同じです。 どのパスもそこを通過する必要があります。 ひっくり返した後の答えは、`-5`。 

対角線に含まれるセルが 1 つだけの場合、その対角線上にパスで使用できる代替セルはありません。 

## アプローチ

 最も直接的なアイデアは、ラファエルの選択に従って、可能なすべてのセルを試してみることです。 

固定セルの場合は、その符号を反転し、標準グリッド DP を使用して最大パス合計を再計算します。 結果として得られる値がミケランジェロの応答です。 すべてのセルの最小値を取ると答えが得られます。 

これは文字通りゲームをシミュレートするものであるため、これは正しいです。 

問題はその複雑さです。 最大パス DP コスト`O(nm)`。 がある`nm`セルを反転する可能性があります。 全体の複雑さは次のようになります。`O((nm)^2)`に達する`10^12`最悪の場合の運用。 

単一セルの反転が最適なパスにどのような影響を与えるかを理解する必要があります。 

させて`f[i][j]`= 開始点から終了点までの最大パス合計`(i,j)`。 

させて`g[i][j]`= からの最大パス合計`(i,j)`最後まで。 

それから```
val(i,j) = f[i][j] + g[i][j] - a[i][j]
```通過するパスの最大スコアです`(i,j)`。 セル値は 2 回カウントされるため、1 回減算します。 

ここで、ラファエルがセルを反転したとします。`(i,j)`。 

ミケランジェロが今も通る道を選んだなら`(i,j)`、そのパスは正確に失われます`2 * a[i][j]`、貢献度が から変化するため、`a[i][j]`に`-a[i][j]`。 

したがって、そのセルを使用する最適なパスは次のようになります。```
val(i,j) - 2*a[i][j]
```残りの質問は、次のことを避ける最善の方法です。`(i,j)`。 

ここで重要な観察結果が現れます。 

からのすべての単調な道`(1,1)`に`(n,m)`各対角線上の 1 つのセルを正確に訪問します`i + j = constant`。 

セルを修正する`(i,j)`そしてさせてください`d = i + j`。 

あらゆるパスを回避`(i,j)`対角線上の他のセルを通過する必要があります`d`。 

あらゆる細胞に対して`(x,y)`同じ対角線上に、`val(x,y)`通過するすべてのパスの中で最高のパス スコアです`(x,y)`。 

したがって、回避する最適なパスは`(i,j)`単に最大値です`val`対角線上の他のすべてのセルの間で`d`。 

これにより、問題は、すべての反対角について、次の最大値と 2 番目に大きい値を維持するように変換されます。`val`。 

細胞の場合`(i,j)`:

 もしそれなら`val`は対角線上で最大ではないため、最適な回避パスは対角線上の最大値を使用します。 

もしそれなら`val`は一意に最大であるため、これを削除すると、2 番目に大きい値を使用する必要があります。 

その後、ミケランジェロの最適な反応は、```
max(
    path_using_flipped_cell,
    best_path_avoiding_flipped_cell
)
```そしてラファエルはすべてのセルの中から最小値を選択します。

 ## アルゴリズムのチュートリアル

 1. コンピューティング`f[i][j]`、開始点からすべてのセルまでの最大パス合計。 
2. コンピューティング`g[i][j]`、すべてのセルから宛先までの最大パス合計。 
3. すべてのセルの計算```
val = f[i][j] + g[i][j] - a[i][j]
```これは、そのセルを通過するすべてのパスの最大スコアです。 
4. 対角線でセルをグループ化する`d = i + j`。 
5. 各対角線について、最大値を保存します`mx1[d]`そして2番目に大きい値`mx2[d]`。 

複数のセルが最大値を共有する場合、`mx2[d]`と等しくなることが許される`mx1[d]`。 これにより、タイが自動的に正しく処理されます。 
6. すべてのセルを列挙する`(i,j)`ラファエロの反転独房のように。 
7. コンピューティング```
through = val - 2*a[i][j]
```これは、反転されたセルを引き続き使用する最良のパス スコアです。 
8. そのセルを回避する最適なパスを計算します。 

もし`val == mx1[d]`、 使用`mx2[d]`。 

それ以外の場合は使用します`mx1[d]`。 
9. ミケランジェロは、次の 2 つの選択肢のうち、より良い方を選択します。```
score = max(through, avoid)
```10. 最小化する`score`すべての細胞にわたって。 

### なぜ効果があるのか

 単調パスは、すべての対角線上で 1 つのセルを正確に訪問します。 反転したセルを修正する`(i,j)`対角線上に`d`。 

あらゆるパスを回避`(i,j)`同じ対角線の別のセルを通過する必要があります。 逆に、対角線の別のセルを通過するパスは、`d`自動的に回避します`(i,j)`なぜなら、パスはその対角線上の 1 つのセルのみを訪問できるからです。 

対角セルごとに`(x,y)`、`val(x,y)`is the best score among all paths passing through it. したがって、回避するパスの最高スコアは`(i,j)`まさに最大値です`val`対角線上の他のすべてのセルの間で`d`。 

反転されたセルを使用した最適なパスは正確に失われます`2*a[i][j]`。 ミケランジェロは「使用」と「回避」の選択肢のうち良い方を選択し、ラファエロはその結果を最小限に抑えるセルを選択します。 すべての可能性が 1 回だけ評価されるため、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

INF = 10 ** 30

t = int(input())

for _ in range(t):
    n, m = map(int, input().split())

    a = [list(map(int, input().split())) for _ in range(n)]

    f = [[-INF] * m for _ in range(n)]
    g = [[-INF] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            if i == 0 and j == 0:
                f[i][j] = a[i][j]
            else:
                best = -INF
                if i > 0:
                    best = max(best, f[i - 1][j])
                if j > 0:
                    best = max(best, f[i][j - 1])
                f[i][j] = best + a[i][j]

    for i in range(n - 1, -1, -1):
        for j in range(m - 1, -1, -1):
            if i == n - 1 and j == m - 1:
                g[i][j] = a[i][j]
            else:
                best = -INF
                if i + 1 < n:
                    best = max(best, g[i + 1][j])
                if j + 1 < m:
                    best = max(best, g[i][j + 1])
                g[i][j] = best + a[i][j]

    diag_cnt = n + m - 1
    mx1 = [-INF] * diag_cnt
    mx2 = [-INF] * diag_cnt

    val = [[0] * m for _ in range(n)]

    for i in range(n):
        for j in range(m):
            cur = f[i][j] + g[i][j] - a[i][j]
            val[i][j] = cur

            d = i + j

            if cur >= mx1[d]:
                mx2[d] = mx1[d]
                mx1[d] = cur
            elif cur > mx2[d]:
                mx2[d] = cur

    ans = INF

    for i in range(n):
        for j in range(m):
            d = i + j
            cur = val[i][j]

            through = cur - 2 * a[i][j]

            if cur == mx1[d]:
                avoid = mx2[d]
            else:
                avoid = mx1[d]

            score = max(through, avoid)
            ans = min(ans, score)

    print(ans)
```最初の DP は、すべてのセルで終わる最適なプレフィックスを計算します。 2 番目の DP は、すべてのセルから開始して最適なサフィックスを計算します。 

それらを組み合わせると、各セルを通過する最適なパスが得られます。 その量はソリューション全体で再利用されるため、反転されたセルを選択した後に DP を再実行する必要はありません。 

対角最大値は特に注意する必要があります。 新しい値が少なくとも現在の最大値である場合、それが新しい最大値となり、古い最大値が 2 番目の最大値になります。 私たちが使っているので、`>=`、等しい最大値は正しく保存されます。 2 つのセルの対角線上に同じ最適値がある場合、1 つを削除しても、もう 1 つのセルから使用できる同じ値が残ります。 

すべての計算では Python 整数が使用されます。 パスの合計はおよそに達する可能性があります`(n+m) * 10^9`したがって、64 ビット演算が必要です。

 ## 特殊なケース

 ### 単一セルグリッド

 入力:```
1
1 1
5
```可能な反転と可能なパスは 1 つだけです。`val = 5`。 

反転後:```
through = 5 - 2*5 = -5
```対角線上には代替セルがないため、結果は次のようになります。`-5`。 

その対角線上の 2 番目の最大値が負の無限大のままであるため、アルゴリズムはこれを処理します。`through`オプションが優勢です。 

### 複数の最適なパス

 入力:```
1
2 2
0 0
0 0
```すべてのパスにはスコアがあります`0`。 

すべての対角線について、最大値と 2 番目に大きい値の両方が次のようになります。`0`。 

セルが除外されると、同じ値を持つ別のセルが使用可能なままになります。 アルゴリズムは戻ります`0`、それは正しいです。 

### 反転されたセルは最終パスでは使用されていません

 入力:```
1
2 2
1 100
100 1
```どちらかを反転する`100`そのセルを通過する経路がさらに悪化します。 

アルゴリズムは以下を比較します。```
through = val - 200
```同じ対角線からの最良の代替値に対して。 

別のパスが勝利し、フリップを見た後にルートを変更するミケランジェロの能力と一致します。 

これがまさに、ソリューションが反転されたすべてのセルに対して「使用」ケースと「回避」ケースの両方を考慮する必要がある理由です。
