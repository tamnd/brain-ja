 ## 解決策
 ## 問題の理解

 私たちは直線道路に沿って位置 0 から位置 X まで移動し、秒速 1 メートルで正確に歩きます。 途中、固定座標に信号機が設置されています。 各信号機は、その位置、初期の色、および赤と緑が永久に切り替わる速度を制御する周期パラメーターによって記述されます。 

動きは連続的です。 信号に到達したとき、その時点で現在の色が赤であれば、待たなければならない可能性があります。 それ以外の場合は、すぐに通過します。 物理的な距離を超えて総移動時間を長くする唯一のことは、赤信号で待つことです。 

入力により n 個の信号機が与えられ、それぞれの信号機は位置 p、初期色 c (赤または緑)、およびサイクル長パラメーター t を持ちます。 信号は t 秒ごとに切り替わります。これは、その全サイクルが 2t 秒であることを意味します。 赤で始まる場合、赤は時間 0 から t まで続き、次に緑は t から 2t まで続きます。 緑色で始まる場合、フェーズが入れ替わります。 

歩行時間と待機時間の両方を考慮した、0 から開始して X に到達するまでの合計時間が必要です。 

制約は、ライトが 100,000 まで、距離が 100,000 までです。これにより、時間を少しずつ進めようとするシミュレーションは即座に除外されます。 唯一の実行可能なアプローチは、位置によって信号機を並べ替えた後、線形時間またはほぼ線形時間で各信号機を 1 回処理することです。 O(n log n) または O(n) より悪い解は遅すぎます。 

複数のライトが位置によってソートされていない場合、微妙な失敗のケースが発生します。 入力順に処理すると、空間的な順序から外れてライトをシミュレートし、間違ったタイミングで待機を計算する可能性があります。 待ち時間は通過する信号の数だけではなく、絶対的な到着時間に依存することを忘れると、別の問題が発生します。 

たとえば、次の 2 つのライトについて考えてみましょう。 

入力:```
2 10
R 5 5
G 2 3
```入力順序で処理される場合、位置 2 の前に位置 5 を処理する可能性がありますが、これは物理的に不可能であり、不正確なタイミングにつながります。 

正しい出力は、位置の昇順での処理に依存します。 

## アプローチ

 直接シミュレーションでは、0 から X まで 1 秒ずつ歩きます。 私たちは信号の上に立っているかどうか、信号によって待たされるかどうかを毎秒確認します。 これは実際のプロセスを正確に反映しているため、これは正しいです。 ただし、距離は最大 100,000 であり、待機によって時間が大幅に延びる可能性もあるため、このアプローチでは 1 秒あたりのシミュレーション ステップが O(X) に低下し、最悪の場合は遅くなりすぎる可能性があります。 

より良い方法は、位置と時間以外は継続的に変化するものは何もないことを認識することです。 信号の間では意思決定は行われません。 ある信号から次の信号に安全にジャンプでき、その距離を移動時間として追加できます。 唯一の重要な計算は、信号で待たなければならないかどうかを決定することです。これは、現在時刻の 2t を法とする値のみに依存します。 

この観察により、問題は位置によってライトを分類し、単一パスをシミュレートし、現在の時間を維持してライトごとに更新することに帰着します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ステップバイステップのシミュレーション | O(X + 待機中のイベント) | お(1) | 遅すぎる |
 | ソート + シングルパス シミュレーション | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての信号機を位置に従って昇順に並べ替えます。 これが必要なのは、時間は空間経路に沿って進化するため、物理的に到達した順序で光に遭遇する必要があるためです。 
2. 現在時刻を 0、現在位置を 0 に初期化します。時間は、待機時間も含めて歩いた時間を表します。 
3. ソートされた順序で各信号機を繰り返し処理します。 
4. 前の位置から現在の光の位置まで歩くのに必要な時間を追加します。 速度は秒速1メートルですから、単純に現在時刻に距離の差を足したものになります。 
5. current_time モジュロ (2t) を使用して、到着時の信号機の状態を計算します。 これにより、繰り返しサイクル内のフェーズが得られます。 
6. 初期色に応じて、現在のフェーズが赤または緑のどちらに対応するかを決定します。 到着時に信号が赤色の場合は、現在の時刻を次の緑色の間隔の開始位置まで進めます。 このジャンプは、それに応じて t または 2t から現在の位相を減算することによって計算されます。 
7. 現在位置を信号機の位置に更新して続行します。 
8. すべてのライトを処理した後、最後のライトからの最後のセグメントを X に追加します。 

重要な考え方は、秒ごとにシミュレーションを行わないということです。 信号である意味のあるイベントポイント間をジャンプするだけです。 

### なぜ効果があるのか

 連続する信号の間のシステムの状態は、現在時刻という 1 つの変数によって完全に決定されます。 道路セグメントには時間に依存するイベントは含まれません。 各信号機で待つか追い越すかの決定は、固定サイクル長を法とした現在時間のみに依存します。 この計算は正確であり、ライトを空間順序で処理するため、シミュレーションでは近似を行わずに真の連続時間の動作が保存されます。 不変条件は、current_time が常に、その時点までに必要な待機をすべて解決した後の現在の位置への正確な到着時間に等しいということです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, X = map(int, input().split())
    lights = []
    
    for _ in range(n):
        parts = input().split()
        c = parts[0]
        p = int(parts[1])
        t = int(parts[2])
        lights.append((p, c, t))
    
    lights.sort()
    
    cur_time = 0
    cur_pos = 0
    
    for p, c, t in lights:
        cur_time += (p - cur_pos)
        cur_pos = p
        
        cycle = 2 * t
        phase = cur_time % cycle
        
        if c == 'R':
            if phase < t:
                cur_time += (t - phase)
        else:
            if phase >= t:
                cur_time += (cycle - phase)
    
    cur_time += (X - cur_pos)
    print(cur_time)

if __name__ == "__main__":
    solve()
```実装はイベントベースのシミュレーションに正確に従います。 並べ替えにより、正しい空間順序が保証されます。 変数`cur_time`は常に、現在の時点に到着したときの絶対時間を表します。 モジュロ計算により、信号サイクル内のどこにいるのかが特定されます。 条件付き調整は、赤色の間隔中に到着した場合にのみ時間を進めます。 

よくある間違いは、次のセグメントを計算する前に位置を更新するのを忘れることで、距離の計算が中断されてしまいます。 もう 1 つの微妙な問題は、特にサイクルの後半が赤である青開始信号の場合に、赤と緑の間隔を誤って分類することです。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | ソート ライトが優先され、各ライトは 1 回処理されます。 
| スペース | O(n) | すべての信号機の保管 |

 制約により最大 100,000 個の信号機が許可されるため、並べ替えと線形シミュレーションは制限時間内に快適に収まります。 ループ内の各操作は定数時間算術であるため、ソート後の実行時間は実質的に線形になります。

 ## 特殊なケース

 エッジケースの 1 つは、ライトが赤と緑の境界で正確にトリガーされる場合です。 周期 t の赤スタート光の場合、位相 0 に正確に到達することは赤を意味し、位相 t に正確に到達することは緑を意味します。 実装では、位相 < t で厳密な不等式を使用するため、これが正しく処理されます。 

もう 1 つのエッジ ケースは、複数のライトが非常に接近している場合です。 各ライトは次の動作の前に現在時刻を更新するため、連続した待機は干渉することなく正確に加算されます。 

最後のケースは、X が信号機の位置に等しい場合です。 その状況では、ライトの処理後に最後のセグメントで追加される距離はゼロであるため、答えは単に最後のライトを解決した後の時間となり、これは交差点に正確に到着するという物理的な解釈と一致します。
