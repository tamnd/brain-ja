 ## 解決策

 ## 問題の理解

 整数の配列が与えられ、この配列の連続するセグメントごとに個別の分割タスクを想像します。 選択したセグメント内では、各グループ内で任意の 2 つの数値の積が完全二乗になるように、その要素を可能な限り最小の数のグループに分割する必要があります。 

グループ化条件は各グループ内でグローバルです。隣接する要素が適切に動作するだけでは十分ではなく、グループ内のすべてのペアが完全二乗積条件を満たさなければなりません。 すべての部分配列について、そのようなグループの最小数を計算し、最後に、考えられる各応答値を生成する部分配列の数を数えます。 

条件を解釈する直接的な方法は、素指数の観点から考えることです。 すべての素数の指数の合計が偶数である場合、積は完全平方になります。 これは、すべての二乗因数を取り除いた後の各数値の構造が、グループ内の互換性にとって重要であることを意味します。 

制約により、最大 5000 個の要素が許可されます。 サブ配列の二次数はすでに約 1,250 万セグメントに達しているため、およそ O(n²) の解は実現可能性の境界にありますが、三次関数やサブ配列ごとに大量の因数分解を伴うものは、高度に最適化しない限り遅すぎます。 これにより、各サブ配列が少額の償却更新で段階的に処理されるソリューションがすぐに得られます。 

すべての要素が 1、4、または 9 であるなど、すべての数値が同一の正方形である場合、微妙なエッジ ケースが発生します。このような場合、すべての要素は相互に互換性があるため、すべての部分配列の答えは 1 になります。同一の値を互換性がないものとして誤って扱う単純なアプローチでは、グループが誤って過大評価されてしまいます。 別のエッジ ケースは、数値が異なるが同じ平方のないコアを共有する場合に発生します。たとえば、2 と 8 は、平方係数を削除すると両方とも 2 になります。 これらはやはりグループ化する必要があります。 

## アプローチ

 ブルートフォース戦略では、すべてのサブ配列を個別に検査します。 各部分配列について、異なる正方形自由構造を持つ要素が同じグループ内に共存できないという制約の下で、効果的に分割をシミュレートしてグループを構築しようとします。 簡単に解釈すると、それぞれの異なる「自由平方型」が独自のグループを強制するため、部分配列の答えはその中にある個別の正規化された値の数になります。 

ただし、サブ配列ごとにこれらの個別の値を最初から再計算すると、O(n³) のプロセスが必要になります。O(n²) 個のサブ配列があり、最悪の場合、サブ配列の各スキャンのコストは O(n) になります。 これは、n が 5000 までの場合は遅すぎます。 

重要な観察は、グループ化条件が単純な分類問題に崩壊するということです。 すべての整数は、因数分解で奇数の指数で現れる素数の積である平方フリー カーネルに還元できます。 2 つの数値は、それらの平方フリー カーネルが同一である場合にのみ、同じグループ内に共存できます。これは、同一のパリティ パターンのみがそれらの積が完全な平方であることを保証するためです。 これにより、各部分配列内の問題は、異なる正方形のないカーネルがいくつ現れるかという単純な質問に変換されます。 

これを理解すると、タスクはすべての部分配列にわたって個別の要素をカウントするようになります。これは、頻度表を維持しながら左端点を固定し、右端点を拡張することで実行できます。

 ## アルゴリズムのチュートリアル

 ### 1. すべての数値を平方フリーのカーネルに正規化します。

各値を因数分解し、奇数回出現する素数のみを保持することで前処理します。 これにより、同一のグループ化動作を持つすべての数値が等しくなる正規表現が生成されます。 

このステップが必要なのは、グループ化条件が実際の大きさではなく、指数のパリティのみに依存するためです。 

### 2. 部分配列の左端点を修正する

 部分配列の可能なすべての開始インデックスを反復処理します。 各開始点について、右の終点を徐々に延長します。 

### 3. 右のエンドポイントを拡張しながら周波数マップを維持する

 部分配列を拡張するときに、正方形のないカーネルがそれぞれ何回出現するかを追跡します。 また、現在存在する個別のカーネルの数を示すカウンターも維持します。 

これにより、各拡張後に各部分配列の答えを O(1) 時間で更新できます。 

### 4. 拡張子ごとに、個別のカーネルの数を記録します。 

新しい正しいエンドポイントに拡張すると、現在の個別のカーネルの数がその部分配列の正確な答えになります。 

その値のグローバル回答バケットを増分します。 

### 5. すべての開始点にわたる結果を集計する

 左側のエンドポイントをすべて処理した後、考えられるすべての回答のカウントを取得します。 

### なぜ効果があるのか

 サブ配列内では、有効なグループ化により、各グループには同一の正方形フリー カーネルを持つ数値のみが含まれるようになります。 2 つの異なるカーネルを 1 つのグループ内に共存させることはできないため、それぞれの異なるカーネルには独自のグループが必要です。 逆に、すべての等しいカーネルは、それらのペアごとの積が完全二乗であるため、1 つのグループに配置できます。 これにより、グループの最小数は個別の正規化値の数と正確に等しくなり、スライディング ウィンドウは再計算せずにすべての部分配列に対してこれらのカウントを正しく列挙します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def build_spf(limit):
    spf = list(range(limit + 1))
    for i in range(2, int(limit ** 0.5) + 1):
        if spf[i] == i:
            step = i
            start = i * i
            for j in range(start, limit + 1, step):
                if spf[j] == j:
                    spf[j] = i
    return spf

def square_free(x, primes):
    x = abs(x)
    if x == 0:
        return 0
    res = 1
    for p in primes:
        if p * p > x:
            break
        cnt = 0
        while x % p == 0:
            x //= p
            cnt ^= 1
        if cnt:
            res *= p
    if x > 1:
        res *= x
    return res

def solve():
    n = int(input())
    a = list(map(int, input().split()))

    limit = 10000
    spf = build_spf(limit)
    primes = [i for i in range(2, limit + 1) if spf[i] == i]

    norm = [square_free(x, primes) for x in a]

    ans = [0] * (n + 1)

    for l in range(n):
        freq = {}
        distinct = 0
        for r in range(l, n):
            v = norm[r]
            if v not in freq:
                freq[v] = 0
            if freq[v] == 0:
                distinct += 1
            freq[v] += 1

            ans[distinct] += 1

    print(*ans[1:])

if __name__ == "__main__":
    solve()
```コードはまず、各整数を平方フリー カーネルに圧縮します。 これは数論が使用される唯一の部分であり、サブ配列の処理が開始される前にすべての構造的等価性が確実に解決されます。 

入れ子になったループは、O(n²) 内のすべての部分配列を列挙します。 左側のエンドポイントごとに、辞書`freq`現在のサフィックスに正規化された各値が何回出現するかを追跡します。 変数`distinct`は増分的に維持され、新しいカーネルがそのサブ配列に初めて出現したときにのみ増加します。 

配列`ans`個別のカーネル数によってグループ化されたサブ配列の数を累積します。これは、必要なグループの最小数に直接対応します。 

正規化には注意が必要です。符号は完全二乗条件に影響しないため、絶対値を使用すると負の数の問題が回避されます。 因数分解ループは次の時点で停止します。`p * p > x`、そして残り物`x > 1`はすでに主因数であり、直接寄与しています。

 ## 特殊なケース

 すべての要素が完全な正方形である場合は、システムの最も圧縮された動作を示します。 入力用`[9, 16, 25]`、すべての数値は次のようになります。`1`平方フリー正規化後は、すべての部分配列に 1 つのグループが存在します。 すべてのエントリが同じキーにマップされ、個別のカウンターが 1 を超えて増加することはないため、アルゴリズムはこれを処理します。 

対照的なケースは、すべての要素に固有の正方形のないカーネルがある場合です。`[2, 3, 5, 7]`。 サブ配列を拡張するたびに、サブ配列の長さと等しくなるまで個別カウントが 1 ずつ増加します。 頻度マップにより、各新しいカーネルが最初に出現したときに正確に 1 回カウントされ、再度カウントされることはありません。 

次のように、数値は異なっていても同じカーネルに正規化される場合、より微妙な状況が発生します。`2, 8, 18`。 生の値が大きく異なっていても、正規化ステップによりそれらの値は 1 つの代表値にまとめられます。 周波数構造では 1 つのキーのみが認識されるため、アルゴリズムは範囲全体を 1 つのグループを持つものとして正しく処理します。
