 # 問題の理解

 整数の配列が与えられます。 各整数は有効なビットのセットを表します。 あらゆる可能なマスクに対して`x`含む`k`ビットがある場合、値に欠落しているビットが少なくとも 1 つ含まれる最初の配列位置を見つける必要があります。`x`。 すべての配列値が次のサブマスクの場合`x`、その位置はゼロとみなされます。 タスクは、この値をすべてに追加することです。`2^k`可能なマスク。 

マスクの数は指数関数的に増加します`k`、 そして`k`すべてのマスクを直接反復するには、60 を超える値が必要になります。`10^18`そのため、ソリューションではマスクへのアクセスを完全に回避する必要があります。 配列の長さはわずか 100 です。つまり、演算は次のようになります。`n * k`簡単に手頃な価格ですが、何でも依存します`2^k`不可能です。 

厄介なケースは、決して出現しないビットや、同じ配列位置に初めて出現する複数のビットに起因します。 決して出現しないビットは値を無効にすることはできないため、偽の位置を提供してはなりません。 例えば：```
Input:
2 2
0 1
```最初の出現位置は位置 2 のビット 0 ですが、ビット 1 は出現しません。 ビット 0 のみが重要です。 欠落しているビットを位置 0 または位置 1 として扱うと、答えが誤って増加します。 

別のケースでは、最初の位置が繰り返されます。```
Input:
2 2
3 3
```両方のビットは最初に位置 1 に現れます。`x = 0`の場合、両方のビットが欠落しているため、答えは 1 になります。 のために`x = 1`、ビット 1 が欠落しており、答えは依然として 1 です。位置をソートし、盲目的に 2 の累乗を等しい値に個別に割り当てるソリューションでは、オーバーカウントになります。 同じ位置はグループ化する必要があります。 

# アプローチ

 ブルート フォース手法は定義に直接に従います。 あらゆるマスクに`x`から`0`に`2^k - 1`、サブマスクではない最初の値が見つかるまで、配列を左から右にスキャンします。`x`。 1 つの値の小切手は安いですが、`2^k`マスクとそれまで`n`それぞれのポジション。 と`k = 60`、このあたりです`100 * 2^60`利用可能な時間を大幅に超えています。 

重要な観察は、マスクが`x`含まれていないビットを通じてのみ興味深いものになります。 すべてのビットについて、そのビットが出現する最も古い配列位置を見つけます。 もし`x`少し見逃します`b`の場合、最初の無効な配列要素は、最初に出現するまでに出現する必要があります。`b`。 実際、その答えは、`x`欠落しているすべてのビットの中で最初に出現する最小値です。`x`。 

ここで問題は、すべてのマスクではなく、ビット位置に関するカウントの問題になります。 出現するすべてのビットの最初の出現がソートされていると仮定します。 値が最小の欠落オカレンスの場合、それより小さなオカレンスはすべて、その値に存在するビットに属している必要があります。`x`、選択されたオカレンスは、存在しないビットに属している必要があります。 残りの大きいビットは空きます。 等しい出現をグループ化すると、複数のビットが同時に候補になることが処理されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^k * n) | お(1) | 遅すぎる |
 | 最適 | O(nk + k log k) | O(k) | 承認済み |

 # アルゴリズムのチュートリアル

 1. からのすべてのビットに対して`0`に`k - 1`、このビットを含む最初の配列インデックスを見つけます。 決して出現しないビットは無視してください。マスクが失敗することは決してないからです。 
2. 既存の最初の位置をすべて収集し、並べ替えます。 複数のビットが同時に最初の欠落ビットになる可能性があるため、同じ位置はグループ化されたままにする必要があります。 
3. 等しい位置の各グループを処理します。 グループに次のものが含まれているとします。`cnt`ビット、あります`smaller`最初の位置が小さいビット、および`larger`最初の位置が大きいビット。 
4. このグループが答えを決定するには、全員が`smaller`ビットが存在する必要があります`x`。 現在のグループ内では、少なくとも 1 つのビットが存在していなければなりません。 このグループ内の選択肢の数は次のとおりです。`2^cnt - 1`、すべての大きなビットは制限されていないため、`2^larger`可能性。 
5.追加```
position * (2^cnt - 1) * 2^larger
```答えのモジュロ`998244353`。 

なぜ効果があるのか:

 すべてのマスク`x`欠落しているビットの中で最初に出現する一意の最小値があります。 このアルゴリズムは、最小欠落ビットが各グループに属するマスクを正確にカウントします。 より小さいグループを省略すると、より早い回答が作成されるため、省略することはできません。 現在のグループは完全に存在することはできません。そうなると貢献できなくなるからです。 グループが大きくても最小値には影響せず、自由に選択できます。 これらのケースでは、考えられるすべてのマスクが 1 回だけカバーされます。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    n, k = map(int, input().split())
    a = list(map(int, input().split()))

    first = [n + 1] * k

    for i, x in enumerate(a, 1):
        for b in range(k):
            if (x >> b) & 1 and first[b] == n + 1:
                first[b] = i

    vals = [x for x in first if x != n + 1]
    vals.sort()

    pow2 = [1] * (len(vals) + 1)
    for i in range(1, len(pow2)):
        pow2[i] = (pow2[i - 1] * 2) % MOD

    ans = 0
    i = 0
    m = len(vals)

    while i < m:
        j = i
        while j < m and vals[j] == vals[i]:
            j += 1

        cnt = j - i
        larger = m - j

        ways = (pow2[cnt] - 1) * pow2[larger] % MOD
        ans = (ans + vals[i] * ways) % MOD

        i = j

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```最初の配列には、各ビットの最も古い位置が格納されます。 必要な値は 0 から始まるオフセットではなく配列インデックスであるため、位置は 1 から始まります。 

リスト`vals`実際に発生するビットのみが含まれます。 これをソートすると、最小の欠落ビットを左から右に数えることができます。 

グループ化されたループが重要な部分です。 複数のビットが同じ最初の出現を共有する場合、アルゴリズムはそれらをまとめて処理します。 表現`2^cnt - 1`グループ内の少なくとも 1 つのビットが欠落しているすべての方法をカウントします。`2^larger`後で現れるビットを説明します。 

Python の整数はオーバーフローしませんが、すべての乗算は剰余化されます。`998244353`必要な出力形式と一致するようにします。

 # エッジケース

 ビットが決して出現しない場合、そのビットはソートされたリストに参加すべきではありません。 例えば：```
2 2
0 1
```ビット 0 のみ、位置 2 で最初に出現します。アルゴリズムはビット 1 を完全に無視し、2 を生成します。ビット 1 に偽の値を追加すると、マスクが正しくカウントされません。 

複数のビットが最初に一緒に出現した場合、それらは 1 つのグループとしてカウントされなければなりません。 のために：```
2 2
3 3
```両方のビットの最初の位置は 1 です。これらのビットの少なくとも 1 つが欠落しているマスクが 3 つあり、それらはすべて値 1 に寄与します。寄与は次のとおりです。`1 * (2^2 - 1) = 3`これらのマスクから、残りのマスクの寄与はゼロになります。 アルゴリズムのグループ化式はこれを直接捉えます。
