 ## 解決策
 ## 問題の理解

 無向グラフがあります。 すべてのエッジは、5 を法とする剰余のセットから 1 つの値を受け取る必要があります。つまり、可能な値は次のとおりです。`0, 1, 2, 3, 4`。 ラベル付けは、すべての頂点に合計が 5 で割り切れる入射エッジ値がある場合に有効です。 

タスクは、有効なエッジ ラベリングがいくつ存在するかをカウントすることです。 答えはモジュロで出力されます`998244353`。 

入力は複数のグラフ インスタンスで構成されます。 各インスタンスは頂点とエッジの数を示し、その後に各エッジで接続されている頂点のペアが示されます。 グラフは切り離される可能性があるため、接続された各コンポーネントを個別に処理する必要があります。 

制約により、線形またはほぼ線形の解決策が必要になります。 すべてのテスト ケースにわたる頂点とエッジの合計数には制限があるため、グラフの走査は手頃な価格で行えます。 各エッジには 5 つの選択肢があるため、割り当てを列挙しようとするアプローチにはチャンスがありません。`5^m`可能性。 適度なサイズのグラフであっても、これは天文学的に大きくなります。 

隠れた主な困難は、独立制約の数を理解することです。 よくある間違いは、すべての頂点条件によって 1 つの自由度が削除されると想定することです。 頂点方程式は常に独立しているわけではないため、これは誤りです。 ツリーと奇数サイクルは異なる動作をし、切断されたコンポーネントはその寄与を倍増します。 

たとえば、単一の孤立した頂点にはエッジがありません。```
1 0
```空の割り当ては 1 つだけなので、答えは次のようになります。`1`。 すべての接続コンポーネントがサイクル自由度に寄与すると仮定したソリューションでは、ここに誤って何かを追加することになります。 

三角形も重要なケースです。```
3 3
1 2
2 3
3 1
```答えは`1`。 サイクルが奇数であるため、3 つの頂点方程式はモジュロ 5 に対して独立しています。 すべてのサイクルを 1 つの自由変数を追加するものとして扱うと、誤って次の結果が生成されます。`5`。 

四角形は反対の動作を示します。```
4 4
1 2
2 3
3 4
4 1
```答えは`5`。 偶数サイクルで交互に代入すると、1 つの自由変数が作成されます。 グラフが奇数であるか偶数であるかをチェックせずに、グラフにサイクルが含まれているかどうかだけをチェックする方法では、これを見逃してしまいます。 

## アプローチ

 直接的な解決策では、エッジへの値の割り当てをすべて試し、頂点の合計をテストします。 これは正しいです。考えられるすべてのラベルが検査され、有効なものだけがカウントされるからです。 ただし、`m`これに必要なエッジ`5^m`課題。 何十万ものエッジを持つグラフの場合、これは不可能です。 

有益な観察は、問題をモジュロ 5 上の線形システムとして見ることから得られます。 各エッジは変数です。 各頂点は、隣接するエッジ変数の合計がゼロであることを必要とする方程式を与えます。 あれば`m`変数とシステムにはランクがあります`r`、解の数は次のようになります。`5^(m-r)`全体の問題は、グラフの出現率に似た行列のランクを見つけることになります。 

接続コンポーネントの場合、`n`頂点の場合、ランクはコンポーネントが 2 部構成であるかどうかによってのみ決まります。 コンポーネントが 2 部構成の場合、頂点方程式には 1 つの依存関係があるため、ランクは次のようになります。`n-1`。 コンポーネントが 2 部構成でない場合、奇数サイクルによってその依存関係が削除され、ランクは次のようになります。`n`。 

この総当たり法は、方程式が有効な代入を完全に記述しているため機能しますが、線形システムの構造を無視しているため失敗します。 ランクのみが重要であるという観察により、指数列挙をグラフ走査に置き換えることができます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(5^m · (n+m)) | O(n+m) | 遅すぎる |
 | 最適 | O(n+m) | O(n+m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 後で接続されたコンポーネントを走査して二部性をテストする必要があるため、各エッジは両方向に保存されます。 
2. すべての未訪問の頂点から幅優先検索または深さ優先検索を実行します。 走査中に、各頂点に 2 つの色のいずれかを割り当てます。 エッジが同じ色の 2 つの頂点を接続している場合、コンポーネントは 2 部構成ではありません。 
3. 現在の接続コンポーネント内の頂点とエッジの数を数えます。 コンポーネントが 2 部構成の場合は、次を追加します`vertices - 1`総合ランクに。 それ以外の場合は追加します`vertices`総合ランクに。 

エッジ数を直接使用する必要がない理由は、すべてのコンポーネントが頂点の数とパリティ構造に応じて寄与するためです。 エッジの数は指数の後半にのみ表示されます。 

1. すべてのコンポーネントを処理した後、次のように答えを計算します。`5^(total_edges - total_rank)`べき乗モジュラーを使用します。 

なぜ効果があるのか:

 グラフ方程式は、モジュロ 5 にわたる線形システムを形成します。 次のような均質線形システムの解の数。`m`変数とランク`r`まさに`5^(m-r)`なぜなら、すべての自由変数は独立して 5 つの値のうちの 1 つを取ることができるからです。 

接続された 2 部コンポーネントの場合、交互の符号を持つすべての頂点方程式の合計によりすべてのエッジがキャンセルされ、1 つの依存関係が作成されます。 したがって、ランクは頂点の数より 1 つ減ります。 非 2 部コンポーネントの場合、奇数サイクルによりその依存関係が防止されるため、ランクは頂点の数と等しくなります。 接続されたコンポーネントに関するこれらのランクを合計すると、システム全体のランクが得られ、最終的な指数が正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return

    it = iter(data)
    t = int(next(it))
    ans = []

    for _ in range(t):
        n = int(next(it))
        m = int(next(it))

        g = [[] for _ in range(n)]
        for _ in range(m):
            a = int(next(it)) - 1
            b = int(next(it)) - 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        rank = 0

        for start in range(n):
            if color[start] != -1:
                continue

            color[start] = 0
            stack = [start]
            vertices = 0
            bipartite = True

            while stack:
                v = stack.pop()
                vertices += 1

                for u in g[v]:
                    if color[u] == -1:
                        color[u] = color[v] ^ 1
                        stack.append(u)
                    elif color[u] == color[v]:
                        bipartite = False

            if bipartite:
                rank += vertices - 1
            else:
                rank += vertices

        ans.append(str(pow(5, m - rank, MOD)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```隣接リストの構築は、アルゴリズムの最初のステップに対応します。 すべてのエッジは 2 回表示されますが、これはトラバース時間にのみ影響し、数学的なカウントには影響しません。 

DFS スタックは、現在接続されているコンポーネントを維持します。 配列`color`2 色の試行を保存します。 以前に訪問した近傍が同じ色である場合、コンポーネントには奇数のサイクルが含まれるため、2 部構成ではありません。 

変数`rank`すべてのコンポーネントの合計ランク寄与を格納します。 最後の電話は`pow`Python のべき乗剰余演算を使用するため、巨大な値の構築が回避されます。`5^(m-rank)`直接。 

Python の整数は任意の精度であり、累乗剰余演算により中間値が制御されるため、オーバーフローの懸念はありません。 システムのランクはエッジ変数の数を超えることができないため、指数が負になることはありません。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

MOD = 998244353

def solution(inp):
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    t = int(input())
    res = []

    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n)]

        for _ in range(m):
            a, b = map(int, input().split())
            a -= 1
            b -= 1
            g[a].append(b)
            g[b].append(a)

        color = [-1] * n
        rank = 0

        for i in range(n):
            if color[i] != -1:
                continue

            stack = [i]
            color[i] = 0
            cnt = 0
            ok = True

            while stack:
                v = stack.pop()
                cnt += 1
                for u in g[v]:
                    if color[u] == -1:
                        color[u] = color[v] ^ 1
                        stack.append(u)
                    elif color[u] == color[v]:
                        ok = False

            rank += cnt - 1 if ok else cnt

        res.append(str(pow(5, m - rank, MOD)))

    return "\n".join(res)

 ## 特殊なケース

 孤立した頂点の場合:```
1 0
```コンポーネントには頂点が 1 つ含まれており、エッジは含まれていません。 二部構成であるため、その順位への貢献度は次のようになります。`1-1=0`。 指数は`0-0=0`、与える`1`。 このアルゴリズムは、存在しない自由度を誤って削除することはありません。 

木の場合:```
5 4
1 2
2 3
3 4
4 5
```グラフは 2 部構成になっています。 成分ランクは`5-1=4`、エッジの数と一致します。 指数はゼロであるため、すべてのエッジ値が強制され、すべてゼロの割り当てのみが残ります。 

奇数サイクルの場合:```
3 3
1 2
2 3
3 1
```色付けの試行では、最後のエッジが 2 つの同じ色の頂点を結合するときに競合が検出されます。 コンポーネントランクは、`3`の代わりに`2`。 指数はゼロになり、有効な割り当ては 1 つだけになります。 

偶数サイクルの場合:```
4 4
1 2
2 3
3 4
4 1
```色塗りは成功です。 ランク貢献度は`3`、フリーエッジ変数が 1 つ残ります。 指数は 1 であるため、コンポーネントは 5 つの解を提供します。 このアルゴリズムは、サイクルを明示的に構築することなく、追加の自由を獲得します。
