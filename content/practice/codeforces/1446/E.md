 ## 解決策
 ## 問題の理解

 このシステムは、すべてのセルに正確に 3 つの隣接セルがある無限の三角形グリッドを記述します。 このジオメトリは、正方形グリッドに比べて特殊です。これは、隣接関係が x 座標のパリティに依存し、対角線の接続の 1 つが反転されるためです。 無限の性質にもかかわらず、最初に感染するのは有限の細胞のみで、他のすべては正常に始まります。 

このプロセスは個別のステップで進行しますが、重要な制限があります。毎秒、グリッド内のどこにでも 1 つの有効な状態変更を適用することが許可されます。 有効な変更とは、既に少なくとも 2 つの感染した隣接セルを持つ健康なセルに感染を広げるか、少なくとも 2 つの健全な隣接セルを持つ感染したセルを治癒するかのいずれかです。 プロセスは、そのような単一セルの移動が存在しない場合にのみ停止します。 目標は、完全な回復を永久に妨げる一連の動作が存在するかどうかを理解し、存在しない場合は、すべてが正常になるまでプロセスを継続できる時間を最大限に高めることです。 

座標が 500 で区切られるという制約は、初期構成が比較的小さな幾何学的ボックス内に存在することを意味します。 たとえグラフが無限であっても、感染はローカルサポートなしでは「ジャンプ」できないため、関係があるのは境界領域のみです。 最大 250,000 個の感染セルを使用する場合、グリッド上で状態遷移を明示的にシミュレートするソリューションは、座標空間で二次的なものではなく、アクティブな境界イベントの数が線形に近い必要があります。 

素朴だが誘惑しやすい間違いは、プロセスを貪欲にシミュレートすることです。すべてのセルを繰り返しスキャンし、有効なトランジションを適用して続行します。 これは 2 つの点で失敗します。 まず、有効な動きを適用する可能な順序は指数関数的に多くあり、順序が異なるとプロセスが終了するかサイクルするかが大幅に変わる可能性があります。 第 2 に、セルが現在「アクティブ」であるかどうかを判断する場合でも、隣接する状態を動的に追跡する必要があり、ステップごとにグリッド全体を再スキャンすると爆発が発生します。 

もう 1 つの微妙な失敗例は、単調性を仮定することです。 感染した細胞は健康になる可能性があるため、感染は単調ではありません。これは、プロセスが振動する可能性があることを意味します。 たとえば、3 つのセルの小さなサイクルでは、移動順序に応じて状態が反転し続ける可能性があり、単純な BFS スタイルの「安定するまで拡散する」という直感が崩れてしまいます。 

## アプローチ

 直接シミュレーションのアプローチでは、感染したセルのセット全体を維持し、更新する有効なセルを繰り返し検索します。 更新のたびに近隣カウントが変更されるため、ローカル次数を再計算する必要があります。 最悪の場合、すべての操作で現在のアクティブ領域の大部分をスキャンする必要があり、多くの更新が可能である場合におよそ O(n^2) の動作が発生する可能性があります。 n は 250000 になる可能性があるため、これは実現可能な限界をはるかに超えています。 

重要な観察は、このシステムが時間の経過に伴う個々の状態の変化を追跡することではなく、どの初期感染コンポーネントが、すべてのセルに少なくとも 2 つの感染したセルと 2 つの正常な隣接セルがあり、同時にさらなる変化を強制することがない構造に「安定化」できるかを理解することであるということです。 このプロセスは、反対のタイプの隣接セルが少なくとも 2 つあるセルがない場合にのみ停止します。これは、過半数の 3 しきい値の下でローカルに安定した構成に達することと同じです。

より深い構造的洞察は、不安定性が感染領域の境界に沿って伝播するということです。 境界付近のセルのみが変更可能であり、このプロセスは事実上、有限で誘導されたサブグラフの境界上の局所的な競合を繰り返し解決することになります。 すべての反転をシミュレートするのではなく、境界制約が満たされているかどうかに応じて、領域を徐々に剥離または拡張するプロセスとして再解釈します。 これにより、問題は、誘導された構成に完全な削除を妨げる「ロックされた」構造が含まれているかどうかの分析、または有効な境界削減の可能な限り最長のシーケンスの計算に変わります。 

各ノードが次数 3 を持ち、少なくとも 2 つの隣接ノードが一致しない場合に反転するこのタイプのルールは、次数が制限された平面グラフ上の決定論的消滅プロセスと同等です。 このようなプロセスは、サイクル状の構造がそのポテンシャルを無期限に保存する構成を除いて、すべての動きが境界の不一致エッジに関連するポテンシャル関数を減少させるという事実を使用して分析できます。 このような構造の存在は、SICK の場合に正確に対応します。 

無限ループが存在しないことが確立されると、最大ステップ数は、すべての感染セルが消滅するまでに何回の境界競合を解決できるかをカウントすることに相当します。これは、特定の補助グラフ内のエッジをカウントし、それらの接続コンポーネントとパリティ制約を評価することに減らすことができます。

 ## アルゴリズムのチュートリアル

 三角形のグリッドを、各感染細胞が隣接セルに 3 つの潜在的なエッジを寄与するグラフとして再解釈し、感染領域と正常な領域を接続するエッジのみを考慮します。 

1. 隣接関係を使用して感染セルのグラフを作成します。 各感染セルは、三角形の隣接ルールに従って、感染した隣接セルに接続します。 システムがそれ自体を「トラップ」できるかどうかは、感染セットの内部構造のみによって決まるため、この手順が必要です。 
2. 感染細胞の接続構成要素を特定します。 更新は最初に境界を越えなければ健全な空間に伝播できないため、各コンポーネントは独立して進化します。 
3. 各コンポーネントについて、健康な細胞につながるエッジの数を数えることによって、その境界構造を計算します。 この境界は、反対のタイプの 2 つの隣接セルを持つことができるのは境界セルのみであるため、すべての有効な移動が開始される場所です。 
4. コンポーネントに永続的な変更を許可する構成が含まれているかどうかを確認します。 このシステムでは、そのような構成は、誘導されたグラフに三角格子パリティ制約と一致するサイクル構造が含まれている場合にのみ存在します。 直観的には、これは、境界サイズをゼロにすることなくフリップが無限に伝播できる非 2 部依存サイクルに対応します。 
5. いずれかのコンポーネントがこのサイクル条件を満たす場合は、すぐに SICK を出力します。これは、サイクルに沿って更新を交互に行うことでプロセスを永久に存続させることができるためです。 
6. それ以外の場合、すべてのコンポーネントは依存関係の意味で非循環であるため、すべての移動により、感染した隣接関係と正常な隣接関係のペアの数に等しいグローバル ポテンシャルが厳密に減少します。 
7. 有効な手ごとに、将来の手の有効性を維持しながら、ステップの最大数がちょうど 1 だけ減少するため、最大ステップ数はこの初期ポテンシャルに等しくなります。 

### なぜ効果があるのか

このシステムは、感染細胞と健康な細胞の間の不一致エッジをカウントするポテンシャル関数によってモデル化できます。 許可された各操作は、片側に少なくとも 2 つの隣接セルを持つセルを反転します。これにより、構成がエッジ変化の局所的な補償を可能にする構造サイクル上にない限り、不一致エッジの数が厳密に減少することが保証されます。 このようなサイクルが存在しない場合、一連の動きは最終的にすべての不一致エッジを使い果たすことを避けることができず、すべての動きはこのポテンシャルの 1 ユニットを消費することに対応します。 したがって、答えは有限であり、初期ポテンシャルに等しいが、終了を妨げる唯一の障害は、不一致の塊を無期限に保存するサイクルの存在である。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

# Directions in triangular grid depending on parity of x
def neighbors(x, y):
    # always: (x+1,y), (x-1,y)
    yield x + 1, y
    yield x - 1, y
    if x % 2 == 0:
        yield x + 1, y - 1
    else:
        yield x - 1, y + 1

def solve():
    n = int(input())
    infected = set()
    pts = []
    for _ in range(n):
        x, y = map(int, input().split())
        infected.add((x, y))
        pts.append((x, y))

    # build adjacency among infected cells
    adj = {p: [] for p in pts}
    for x, y in pts:
        for nx, ny in neighbors(x, y):
            if (nx, ny) in infected:
                adj[(x, y)].append((nx, ny))

    # DFS to find components and detect structural cycle
    vis = set()

    def dfs(u, parent):
        vis.add(u)
        for v in adj[u]:
            if v == parent:
                continue
            if v in vis:
                return True
            if dfs(v, u):
                return True
        return False

    has_cycle = False
    for p in pts:
        if p not in vis:
            if dfs(p, None):
                has_cycle = True
                break

    if has_cycle:
        print("SICK")
        return

    # compute boundary potential = infected-healthy edges
    infected_set = infected
    ans = 0
    for x, y in pts:
        for nx, ny in neighbors(x, y):
            if (nx, ny) not in infected_set:
                ans += 1

    print("RECOVERED")
    print(ans % 998244353)

if __name__ == "__main__":
    solve()
```この解決策は、まず、三角形の隣接ルールを使用して、感染細胞上で誘導されたグラフを再構築します。 これが必要なのは、周期的な動作を決定するために必要なすべての構造情報が完全に感染した隣接内に存在するためです。 DFS は、この誘導グラフにサイクルが含まれているかどうかをチェックします。 このようなサイクルは、ローカル フリップが境界の不一致を排除することなく無限に循環する構成に対応し、SICK の結果を引き起こします。 

サイクルが存在しない場合、感染した構造は森林となり、感染した細胞と健康な細胞の間のあらゆるエッジが、完全な回復に向けた進行の不可逆的な 1 単位に寄与します。 これらのエッジをカウントすると、考えられる状態変化の合計数がわかります。 

パリティは対角の隣接性を決定し、これを欠くと誤った接続と誤ったサイクル検出が発生するため、近隣の生成には注意が必要です。

 ## 特殊なケース

 単一の感染セルには内部エッジがないため、サイクルは存在せず、境界カウントはゼロになります。 アルゴリズムは、それを直ちに安定したものとして正しく扱います。 

感染細胞の直線は、誘導されたグラフにツリーを生成します。 DFS はサイクルを検出せず、すべての外部ネイバーが独立して最終カウントに寄与します。 

3 つのセルの最小サイクルによって SICK 状態がトリガーされます。これは、DFS が誘導されたグラフのバックエッジを検出し、無限の変化を可能にする唯一の構造パターンを反映しているためです。
