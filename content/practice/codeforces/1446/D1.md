 ## 解決策
 ## 問題の理解

 整数の配列が与えられ、最も頻繁に出現する値が一致する最も長く連続する部分配列を見つけるように求められます。これは、単一の支配的な要素が存在しないことを意味します。 つまり、最も頻繁に出現する要素が$f$部分配列内に少なくとも 1 つの他の個別の要素が出現する必要があります$f$回。 出力は単にこの部分配列の長さです。 そのような部分配列が存在しない場合は、ゼロを出力します。 

制約が重要です。 配列の長さ$n$最大 200,000 になる可能性があり、ナイーブであることはすぐに除外されます$O(n^2)$すべてのサブ配列を列挙するソリューション。これには最大で$4 \times 10^{10}$2 秒に収まる回数をはるかに超えた反復。 要素の値は次のように制限されます。$\min(n,100)$したがって、存在する個別の値は最大 100 個であり、これは、固定サイズの配列またはハッシュ マップを使用した頻度ベースのアプローチが実現可能であることを示唆しています。 

明らかではないエッジケースには、すべての値が同一である配列が含まれます。$[5,5,5,5]$、ここで、どのサブ配列も同点になることはできません。 別のエッジケースは次のような配列です$[1,2,1,2,3]$ここで、タイを持つ最長の部分配列では、周波数を等化するために一方の端の要素をスキップする必要がある場合があります。 全体的な頻度だけをカウントしたり、即時の繰り返しだけを調べたりする不用意なアプローチでは、これらのシナリオを見逃してしまいます。 

## アプローチ

 ブルートフォース手法は簡単です。すべてのサブ配列を列挙し、そのサブ配列内の各要素の頻度を計算し、最大頻度を決定し、複数の要素がその最大値に達するかどうかを確認します。 各サブ配列の周波数の計算には次の時間がかかります。$O(n)$時間がかかるため、全体的な複雑さは$O(n^3)$。 これは非常に小さな配列では機能しますが、次の場合は実行できません。$n$200,000まで。 

より高速なソリューションを実現するための重要な点は、個別の値のペアを調べるだけでよいということです。 2 つの値を選択すると$x$そして$y$、配列を次のシーケンスに変換できます。$+1$のために$x$、$-1$のために$y$、 そして$0$他のすべてのために。 次に、問題は、次の数が満たされる最長の部分配列を見つけることに帰着します。$x$の数に等しい$y$、その部分配列では次の周波数が存在するため、$x$そして$y$ネクタイ。 これは古典的なプレフィックス合計の問題です。つまり、現在までの合計を維持します。$+1$そして$-1$、各プレフィックス合計の最も早い出現を追跡します。 同じ接頭辞の合計が再び現れると、その間の部分配列のカウントは同じになります。$x$そして$y$。 

個別の値は最大 100 個あるため、チェックする必要があるペアは最大 4950 個になります ($100 \choose 2$）。 各ペアは次のように処理できます。$O(n)$プレフィックス合計アプローチを使用すると、全体的な複雑さはおよそ次のようになります。$5 \times 10^8$操作。 これは Python の境界線ですが、慎重に実装すれば実現可能です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^3) | O(n) | 遅すぎる |
 | ペアごとのプレフィックス合計 | O(n * V^2)、V ≤ 100 | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各要素の頻度をグローバルに計算します。 最も高い頻度を持つ要素を特定します。 複数の要素がすでにこの頻度で結合している場合、配列全体が有効であるため、出力$n$そして出ます。 これは、グローバル最大値が一意ではない配列の単純なショートカットを処理します。 
2. 異なる要素のペアごとに$x$そして$y$、各プレフィックス合計が発生する最も古いインデックスを格納する辞書を初期化します。 インデックス 0 から始まる部分配列を処理するには、インデックス -1 の合計 0 から開始します。 
3. 配列を走査します。 要素ごとに、プレフィックスの合計を 1 ずつ増分します。$x$の場合は 1 ずつ減ります。$y$、それ以外の場合は無視します。 
4. 各ステップで、このプレフィックス合計が以前に確認されたかどうかを確認します。 はいの場合、前の出現から現在のインデックスに 1 を加えた部分配列の長さを計算します。 この長さが大きい場合は、最大長を更新します。 
5. すべてのペアを処理した後、記録された最大長が答えとなります。 有効な部分配列が見つからなかった場合は、0 を出力します。 

これが機能するのは、prefix-sum によって、2 つの等しいプレフィックス合計間の部分配列について、$x$そして$y$は同一です。 すべてのペアを考慮すると、2 つの要素が最大周波数で結合する潜在的なサブ配列がすべてキャプチャされることが保証されます。 最大周波数で 1 つのペアのみを含むサブ配列で十分であるため、他の要素は無視されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    from collections import Counter
    
    freq = Counter(a)
    max_freq = max(freq.values())
    
    # Shortcut: if any frequency occurs more than once
    if list(freq.values()).count(max_freq) > 1:
        print(n)
        return
    
    vals = list(freq.keys())
    ans = 0
    
    for i in range(len(vals)):
        for j in range(i+1, len(vals)):
            x, y = vals[i], vals[j]
            prefix = {0: -1}
            s = 0
            for idx, val in enumerate(a):
                if val == x:
                    s += 1
                elif val == y:
                    s -= 1
                # ignore other values
                if s in prefix:
                    ans = max(ans, idx - prefix[s])
                else:
                    prefix[s] = idx
    print(ans)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず頻度辞書を計算し、同じ最大頻度を持つ複数の要素が配列に既に含まれているかどうかを確認します。 そうであれば、配列全体が適格になります。 ペアごとのプレフィックス合計アプローチでは、選択した 2 つの要素のみをインクリメントまたはデクリメントし、カウントを乱さないように他の要素を無視します。 最長の部分配列を迅速に計算するには、各プレフィックスの合計の最初の出現を保存することが重要です。 プレフィックス辞書を初期化する`{0: -1}`インデックス 0 から始まるサブ配列を正しく処理できるようになります。
