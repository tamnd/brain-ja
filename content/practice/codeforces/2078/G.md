 ## 解決策
 ## 問題の理解

 紙片の濃度レベルを表す整数の配列が与えられ、独特の操作が行われます。つまり、紙片を何度でも折り、1 つの位置に黒い染料を滴下し、その後広げることができます。 染料は、折り目の層を通過する経路に沿って暗さを増します。 機能$f(b)$シーケンス用に$b$正確に暗さレベルを達成するために必要なそのような操作の最小数をカウントします。$b$。 

この問題では配列を取得するように求められます$a$そして合計$f$すべての連続する部分配列にわたって$a$。 これは、間隔ごとに次のことを尋ねることと同じです。$[l, r]$で$a$、暗闇のパターンを達成するには何回の操作が必要ですか$a_l, \dots, a_r$?

 制約は厳しいです。 と$n$まで$2 \cdot 10^5$複数のテスト ケース、計算するあらゆるアプローチ$f(b)$すべての人のためにゼロから$\mathcal{O}(n^2)$部分配列は実行不可能です。 線形または線形に近い解決策が必要です。$n$テストケースごとに。 単純なアルゴリズムでは、すべてのサブアレイをチェックし、それぞれに対してフォールドと色素ドロップをシミュレートする必要がありますが、これは簡単に超えてしまう可能性があります。$10^{10}$操作。 

注意すべきエッジ ケースには、すべての要素が等しいサブ配列、長さ 1 のサブ配列、値が高い値と低い値の間で交互に現れるケースなどがあります。 たとえば、単一要素の部分配列は常に次のようになります。$f(b) = b_1$染料を落とすことができたら$b_1$回。 ピークが繰り返される配列は、各セルを個別に処理するのではなく、対称的に折りたたむことによって最適化できます。 

## アプローチ

 ブルートフォースアプローチでは次のように計算されます。$f(b)$すべてのサブ配列に対して独立して。 長さの部分配列の場合$m$、間隔内の最小値を再帰的に見つけ、すべての要素から最小値を減算して間隔を減らし、合計することができます。$1 + f(\text{left}) + f(\text{right})$。 これは、複数のセルを一度にカバーするために折りたたんだ後に各染料ドロップを適用できるため機能します。 正しいのですが、これを計算すると、$\mathcal{O}(n^2)$特にコンピューティング以降、間隔が遅すぎます。$f(b)$それ自体は$\mathcal{O}(m)$。 

重要な洞察は、操作がセグメントごとの貪欲な削減のように動作するということです。 任意の間隔の最小値は、間隔全体に適用できる「ベース染料ドロップ」を定義し、すべての値を同時に減少させます。 その後、値がこの最小値を超える部分を再帰的に解決できます。 これは当然、分割統治のアプローチにつながります。 反復は単調であり、ベースドロップは加算的であるため、スタックを使用して新しい色素ドロップが始まる高さを追跡する単一の左から右のスキャンですべてのサブアレイの寄与を計算できます。 基本的に、各位置で終了するサブ配列の演算の累計を維持します。 

同じ「現在の最小値からベースを引いたもの」を持つ連続したセグメントを単一のエントリに圧縮することができ、これにより冗長な計算が削減されます。 これにより、合計時間が短縮されます。$O(n^3)$または$O(n^2)$おおよそに$O(n)$単調性と増分集計を活用してテスト ケースごとに実行します。

 ## アルゴリズムのチュートリアル

 1. 現在のテスト ケースの合計を累積する変数を初期化します。 
2. 配列を左から右に繰り返します。 各位置について、各要素が次のペアであるスタックを維持します。`(height, count)`、最小高さが均一なセグメントを表します。 
3. 現在の要素について、前のベースを減算して、最後の最小値に対する超過を計算します。 一番上の高さが現在の余剰部分より小さくなるまで、スタックからポップします。 各ポップは、セグメントの完了とその寄与を合計に追加することを表します。 
4. 現在の超過値がゼロより大きい場合は、それが開始するサブアレイの数を表すカウントとともにスタックにプッシュします。 カウントと高さを使用して累積合計を更新します。 
5. すべての要素を処理した後、スタック内の残りのセグメントからの寄与を追加します。 
6. 各テスト ケースに対してこれを繰り返し、和の剰余を出力します。$998\,244\,353$。 

不変条件は、スタックが常に高さが減少するセグメントを維持しており、セグメントをポップするたびに、現在の位置で終了し、そのセグメントの高さによって制限されているすべてのサブ配列を正しくカウントしていることです。 各サブ配列の$f(b)$したがって、各セグメント レベルで適用される基本リダクションの合計として 1 回だけ計算されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

for _ in range(int(input())):
    n = int(input())
    a = list(map(int, input().split()))
    stack = []
    total = 0
    for val in a:
        count = 1
        while stack and stack[-1][0] >= val:
            h, c = stack.pop()
            total -= h * c
            count += c
        stack.append((val, count))
        total += val * count
    print(total % MOD)
```を使用して入力を効率的に読み取ります`sys.stdin.readline`。 テスト ケースごとに、スタックは高さの減少と各高さから始まるサブ配列の数を追跡します。 新しい要素が到着すると、それ以上の高さをすべてポップし、それに応じて合計を調整します。 次に、更新されたカウントで現在の値をプッシュします。 合計は、現在の要素で終わるすべてのサブ配列の寄与を累積します。 モジュロ演算により、結果が必要な制限内に収まることが保証されます。
