 ## 解決策
 ## 問題の理解

 2つのレーンがあります。 各レーンはちょうど 1 人から始まります。 

レベルの構成は次のとおりです。`n`ラウンドします。 各ラウンドには左ゲートと右ゲートがあります。 ゲートは、固定人数を追加するか、現在そのレーンにいる人の数を倍増します。 

重要な点は、ゲートが車線の人口を直接変更しないことです。 その代わりに、各ゲートはある程度の数の「新しい」人々を生み出します。 

ゲートがある場合`+ a`、それは正確に作成します`a`新しい人たち。 

ゲートがある場合`x a`、レーンには現在次のものが含まれています`k`人々、それが生み出すもの`(a - 1) * k`新しい人たち。 

ラウンドの両方のゲートで新しい人物が生成された後、新しく作成されたすべての人物が一緒にプールされます。 私たちはそれらの新しい人々を 2 つのレーンに好きなように分配することができます。 既存の人物は移動できません。新しく生成された人物のみが割り当て可能です。 

タスクは、すべてのラウンド後に両方のレーンの人数の合計を最大化することです。 

ラウンド数は多くても30ラウンドと少ないです。 挑戦は規模ではありません`n`、しかし、新しく作成された人々をレーン間に分配するための膨大な数の可能な方法。 すべての割り当てを直接検索すると、組み合わせが爆発的に増加します。 

微妙な点は、乗算ゲートはラウンド開始前にそのレーンにすでに存在していた人の数にのみ依存することです。 同じラウンド中に生成された人物は、その乗算効果を増加させることはできません。 割り当てと乗算を間違った順序で処理するソリューションでは、オーバーカウントが発生します。 

考慮する：```
1
1
x 3 x 3
```最初は両方のレーンに 1 人が入っています。 

2 つのゲートが生成する`2 + 2 = 4`新しい人たち。 この 4 人を好きなように分配することができますが、最終的な合計は常に次のようになります。`2 + 4 = 6`。 

不用意なアプローチは、生成された人々をレーンに配置すると、同じラウンド内の他の乗算をすぐに助けて、より大きな値を生み出すことができると考える可能性があります。 それは許されません。 

もう 1 つの簡単な間違いは、レーンのバランスが常に最適であると仮定することです。 

考慮する：```
1
2
+ 100 + 0
x 3 + 0
```生成された 100 人全員を左のレーンに配置する必要があります。そのレーンは後で乗算されるためです。 均等に分割すると価値が下がります。 今後のラウンドにより、現在の利益をどこに投資するかが決まります。 

最も難しいのは、将来のすべての乗算を考慮して、各ラウンドで新しく作成された人々がどこに行くべきかを決定することです。 

## アプローチ

 ブルート フォース ビューは、構造を理解するのに役立ちます。 

現在の人口がわかっていると仮定します`(l, r)`。 ラウンドは何らかの数値を生成します`g`新しい人々の。 任意の分割を選択できます。```
x people to the left
g - x people to the right
```すべての整数に対して`0 ≤ x ≤ g`。 

考えられるすべての割り当て戦略をチェックするため、そのようなすべての選択肢を再帰的に探索することは正しいことです。 問題はそれです`g`数回の乗算の後、巨大になる可能性があります。 ラウンドごとの選択肢の数を何らかの方法で制限したとしても、分岐係数は依然として指数関数的に増加します。`n`。 

重要な観察は、ゲームが完全に直線的であるということです。 

私たちがラウンドの前に立っていると想像してみてください`i`。 その時点以降で達成可能な最大の最終答えは次のように記述できると仮定します。```
A * l + B * r + C
```どこ`l`そして`r`は現在の車線人口です。 

ゲームの最後では、これは明らかに真実です。```
final = l + r
```だから最初は```
A = 1
B = 1
C = 0
```ここで、以前の 1 つのラウンドを考えてみましょう。 

させて`g`そのラウンドで新しく作成された人の総数になります。 私たちが送ったら`x`それらのうち左車線にある場合、将来の価値は次のようになります。```
A(l + x) + B(r + g - x) + C
```これを単純化すると```
Al + Br + C + Bg + (A - B)x
```唯一の変数は`x`。 

もし`A > B`、余分な人はすべて左レーンでより価値があるため、新しく生成されたすべての人は左に移動する必要があります。 

もし`B > A`、新しく生成されたすべての人は右に進む必要があります。 

それらが等しい場合、どの分割も最適です。 

これが画期的な点です。 部分分布を考慮する必要はありません。 各ラウンドで生成された人々は、将来係数がより大きい方のレーンに完全に投資されます。 

これが分かれば、丸めを逆方向に処理して係数を更新できます。`(A, B, C)`。 

乗算ゲートは現在のレーン人口に比例した値に寄与し、加算ゲートは定数に寄与するため、後方スイープ全体を通じて線形形式が維持されます。

 | 最適 | テスト ケースあたり O(n) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ラウンドのサフィックスの値関数を次のように定義します。```
F(l, r) = A * l + B * r + C
```どこ`(A, B, C)`将来の最適な見返りを説明します。 
2.最終ラウンド後の状態からスタートします。 

その時点で:```
F(l, r) = l + r
```それで初期化します:```
A = 1
B = 1
C = 0
```3. 右から左にラウンドを処理します。 
4. 次のようにしましょう。```
m = max(A, B)
```新しく生成された人物は係数付きのレーンに完全に割り当てられる必要があります`m`なぜなら、それが将来の貢献が最大になるからです。 
5. 各ゲートを線形寄与として表現します。 

門の場合`+ a`:```
gain = a
```これは以下に相当します:```
0 * lane + a
```門の場合`x a`:```
gain = (a - 1) * lane
```これは以下に相当します:```
(a - 1) * lane + 0
```6. 左側のゲートを貢献させる```
cL * l + dL
```そして正しいゲートが貢献します```
cR * r + dR
```生成された人の合計は、```
g = cL * l + cR * r + dL + dR
```7. 生成されたすべての人には価値があるので`m`将来的には、追加する`m * g`現在値関数に。 

これにより、以下が生成されます。```
A' = A + m * cL
B' = B + m * cR
C' = C + m * (dL + dR)
```8. 交換する`(A, B, C)`による`(A', B', C')`そして続けます。 
9. すべてのラウンドが処理されると、初期状態は次のようになります。`(1, 1)`。 

答えは次のとおりです。```
A + B + C
```### なぜ効果があるのか

 不変条件は、ラウンドのサフィックスを処理した後、その時点からの最適な最終答えは常に一次関数として表すことができるということです。```
A * l + B * r + C.
```最終的なスコアは単純であるため、基本ケースは true です。`l + r`。 

ラウンドに対して不変式が成り立つと仮定します`i + 1`。 ラウンド中`i`、唯一の決定は、新しく生成された人々をどのように分配するかです。 将来の価値は線形であるため、追加の各人はどちらかに貢献します。`A`または`B`それを受け取るレーンによって異なります。 より大きな係数を持つレーンに人を送り込むことは、他の選択肢と少なくとも同じくらい優れています。 したがって、生成されたすべての人間には価値がある`max(A, B)`。 

この値を現在の線形関数に加算すると、不変式を維持した別の線形関数が生成されます。 帰納法により、不変式はゲームの開始を含むすべてのラウンドで保持されます。 結果の値は、`(1, 1)`が最適な答えです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for _ in range(t):
        n = int(input())
        gates = []

        for _ in range(n):
            op1, a1, op2, a2 = input().split()
            gates.append((op1, int(a1), op2, int(a2)))

        A = 1
        B = 1
        C = 0

        for op1, a1, op2, a2 in reversed(gates):
            m = max(A, B)

            if op1 == '+':
                cL, dL = 0, a1
            else:
                cL, dL = a1 - 1, 0

            if op2 == '+':
                cR, dR = 0, a2
            else:
                cR, dR = a2 - 1, 0

            A = A + m * cL
            B = B + m * cR
            C = C + m * (dL + dR)

        print(A + B + C)

solve()
```変数`A`、`B`、 そして`C`すでに処理されたサフィックスの最適値関数の係数を保存します。 

すべてのラウンドで最初に計算します`m = max(A, B)`。 生成されたすべての人々はより収益性の高いレーンに投資される必要があるため、これは新たに生成された 1 人の将来の価値を表します。 

各ゲートは次の形式に変換されます。```
c * lane + d
```これにより、更新代数が簡単になります。 

更新では古い値を使用する必要があります。`m`。 再計算中`m`アップデート後`A`または`B`割り当ての決定は将来のラウンドではなく現在のラウンドに属するため、これは不正確です。 

Python の整数は自動的に任意のサイズに拡張されますが、これが必要なのは、乗算を繰り返すと答えが 64 ビットの制限をはるかに超えてしまう可能性があるためです。

 可能な最小レベルを考慮してください。```
1
1
+ 1 + 1
```逆方向初期化を行うと次のようになります。```
A = 1
B = 1
C = 0
```このラウンドではコンスタントに2名が貢献します。 以来`m = 1`:```
C = 2
```答えは次のようになります。```
1 + 1 + 2 = 4
```これは直接シミュレーションと一致します。 

次に、純粋な乗算ラウンドを考えてみましょう。```
1
1
x 3 x 3
```2 つのゲートにより次のものが生成されます。```
2 * l + 2 * r
```と`A = B = 1`、 我々は持っています`m = 1`、 それで：```
A = 3
B = 3
C = 0
```答えは次のとおりです。```
3 + 3 = 6
```これは、新しく生成された人々が同じラウンド内の乗算に影響を与えることを許可されていないことを確認します。

1
2

```逆方向処理により次の結果が得られます。```

```常にレーンのバランスを取る戦略はこの機会を逃し、より小さな答えを生み出すことになります。 係数に基づいた決定により、将来の乗算によって投資が最も収益性が高くなる場所が正確に特定されます。
