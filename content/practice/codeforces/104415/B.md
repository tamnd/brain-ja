 ## 解決策
 ## 問題の理解

 原点と平面内の追加の 2 点を通過することが知られている二次曲線が与えられます。 つまり、放物線は 3 つの点によって一意に決定され、そのうちの 1 つは (0, 0) に固定され、残りの 2 つは入力に与えられます。 これらの制約から、放物線の方程式を再構築し、その根を決定することが求められます。 

点の 1 つが原点であるため、2 次関数の定数項はすぐに消えます。 曲線は制限された形式で書くことができます$y = ax^2 + bx$。 タスクは係数を回復することになります。$a$そして$b$指定された 2 つの点から計算し、この二次方程式の x 切片を求めます。 

通常、入力は 2 つの非ゼロ点を提供します$(x_1, y_1)$そして$(x_2, y_2)$。 各テスト ケースは独立しており、出力は再構成された放物線の根に対応します。 

制約は、テスト ケースごとにすべてが定数時間になるように設計されています。 これは、範囲の反復や数値検索を伴う解決策は不要であり、精度の問題や非効率性のリスクが生じるだけであることを意味します。 意図した解決策は、直接の代数操作に依存する必要があります。 

素朴なアプローチでは、内挿ライブラリを使用して多項式を再構築するか、構造を利用せずに一般的な二次公式を介して多項式を解こうとする可能性があります。$c = 0$。 これでも数学的には機能しますが、不必要な浮動小数点演算が発生し、除算の安定性が脆弱になる特殊なケースが発生します。 

微妙な失敗例は、次のいずれかの場合に発生します。$x_1$または$x_2$不用意に扱うと、中間導出ではゼロになります。 コンピューティング時に別の問題が発生します$a$そして$b$浮動小数点演算を繰り返すと、分母が小さい場合に精度誤差が増幅される可能性があります。 

## アプローチ

 強引な考え方は、一般的な二次補間を使用して放物線を再構成することです。 完全なシステムを解決できるのは、$a$、$b$、 そして$c$次に、すべてを二次ルート ソルバーに接続します。 これは原理的には機能しますが、1 つの係数がすでにゼロであることがわかっていることを無視しているため、3 変数のフレームワークに不必要に埋め込まれた 2 変数システムを解くことになります。 

すべてが定数時間であるため、非効率性は漸近的な複雑さではなく、数値の不安定性と冗長な計算にあります。 追加の代数ステップごとに除算が発生し、浮動小数点誤差が増幅される可能性があります。 

重要な観察は、この構造によりシステムが 2 つの未知数における 2 つの線形方程式に崩壊するということです。 一度$c = 0$、両方の点が満たされます:$$ax_i^2 + bx_i = y_i$$これは線形システムです。$a$そして$b$。 これを直接解くと、一般的な二次機械への再帰を行わずに、安定した閉じた形式の式が得られます。 

一度$a$そして$b$は知られていますが、そのルーツは些細なものです。 ルートは常に 1 つです$x = 0$、もう 1 つは因数分解から得られます。$$ax^2 + bx = x(ax + b)$$したがって、2番目の根は$x = -\frac{b}{a}$と仮定すると$a \neq 0$。

 ## アルゴリズムのチュートリアル

 幾何学的制約を小さな代数系に変換し、根を直接抽出することで、この問題を解決します。 

1. 放物線が原点を通過するという事実から開始し、定数項を直ちにゼロに固定します。 これにより、方程式は次のように簡略化されます。$y = ax^2 + bx$、システムから未知のものを排除します。 
2. 最初の点を置き換えます$(x_1, y_1)$方程式に代入して、$a x_1^2 + b x_1 = y_1$。 これにより、次の間に線形関係が得られます。$a$そして$b$。 
3. 2 番目の点を置き換えます$(x_2, y_2)$、生産$a x_2^2 + b x_2 = y_2$。 これで、2 つの未知数を含む 2 つの線形方程式ができました。 
4. 通常、1 つの変数を削除します。$b$最初の方程式から次のように表すと、$b = \frac{y_1 - a x_1^2}{x_1}$。 このステップが選択されるのは、2 番目の方程式の置換の複雑さが軽減されるためです。 
5. この式を 2 番目の方程式に代入し、次の式を解きます。$a$。 これにより、すべての項が既知の入力のみに依存する閉じた形式の式が生成されます。 
6. 1回$a$既知である、計算する$b$先ほどの式を直接使用します。 この時点で、完全な二次方程式が再構築されます。 
7. 二次方程式を次のように因数分解します$x(ax + b)$、すぐに 1 つのルートが得られます。$x = 0$そして2番目のルートは$x = -\frac{b}{a}$と仮定すると$a$はゼロではありません。 

### なぜ効果があるのか

 正しさは、2 つの異なる非原点点が定数項がゼロの二次方程式を一意に決定するという事実から得られます。 連立方程式は未知の係数では線形です$a$そして$b$, したがって、それを解くと、近似なしで正確な係数が生成されます。 多項式が再構築されたら、因数分解します。$x$は代数的に正確であり、ルートが元の曲線の正確な解であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    out = []
    for _ in range(t):
        x1, y1 = map(float, input().split())
        x2, y2 = map(float, input().split())

        # Solve:
        # a x1^2 + b x1 = y1
        # a x2^2 + b x2 = y2

        denom = (x2 * x1 * x1 - x1 * x2 * x2)
        # rearranged from elimination
        a = (y2 * x1 - y1 * x2) / denom
        b = (y1 - a * x1 * x1) / x1

        # roots: x = 0 and x = -b/a
        if abs(a) < 1e-12:
            # degenerate linear case bx = 0
            root2 = 0.0
        else:
            root2 = -b / a

        # output both roots
        out.append(f"0 {root2}")

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```実装は、導出された代数構造に直接に従います。 係数の計算は消去ステップを反映しており、分母は 2 つの点によって形成される 2x2 系の行列式に対応します。 一度$a$が得られ、$b$は、システムを再計算することなく最初の方程式から回復されます。 

根の抽出には因数分解の洞察が使用されます。 非常に小さい場合の特別な取り扱い$a$曲線が事実上直線になる縮退ケースにおける除算の不安定性を回避します。

 ## 特殊なケース

 重要なエッジ ケースは、両方の非原点点が 2 次関数を縮退させ、事実上崩壊させる直線上にある場合に発生します。$a$ゼロに。 その状況では、2 番目の根の式には次の除算が含まれます。$a$したがって、単純な実装ではクラッシュしたり、無限が発生したりする可能性があります。 小切手$|a|$出力が安定した状態を維持し、因数分解された形式と一致するゼロの繰り返し根を返します。 

もう一つの微妙なケースは次のような場合です。$x_1$非常に小さいか負です。 の計算以来、$b$で割る$x_1$不注意な順序付けや整数キャストを行うと、すぐに正確性が損なわれてしまいます。 すべての値を浮動小数点として扱い、式の構造を保持することで、この不安定性を完全に回避できます。 

最後のケースは、行列式における数値的な相殺です。$x_2 x_1^2 - x_1 x_2^2$。 いつ$x_1$そして$x_2$が近いと、この値は小さくなり、精度の低下が大きくなる可能性があります。 この式は依然として数学的に正しいままですが、安定した評価は不必要な再計算を回避し、示されているように式を因数分解し続けるかどうかにかかっています。
