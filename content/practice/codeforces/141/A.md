 ## 解決策
 ## 問題の理解

 3 つの大文字の文字列が与えられます。 最初の 2 つの文字列はドアに書かれた名前で、3 番目の文字列は翌朝、誰かがすべてを混ぜ合わせた後に発見された手紙の山です。 

タスクは、3 番目の文字列に、最初の 2 つの文字列を結合したものとまったく同じ文字が含まれているかどうかを確認することです。 すべてのキャラクターは、登場回数も含めて重要です。 結合した名前に 3 つが含まれる場合`'A'`文字の場合、パイルにはちょうど 3 文字が含まれている必要があります`'A'`文字。 文字の欠落や余分な文字は許可されません。 

各文字列の最大長はわずか 100 であるため、かなり非効率な操作であっても完全に安全です。 二次解も即座に実行されます。 これにより、微細な最適化を気にすることなく、最も明確な実装を自由に選択できるようになります。 

主な危険は、キャラクターの存在だけではなく、キャラクターの頻度が重要であることを忘れることです。 不用意な解決策では、すべての個別の文字が山のどこかに出現するかどうかだけをチェックするだけになる可能性があります。 

次の入力を考えてみましょう。```
AAB
C
ABAC
```正しい出力は次のとおりです。```
YES
```結合された名前には 2 つが含まれます`'A'`、 1つ`'B'`、そして1つ`'C'`。 パイルにはまったく同じカウントが含まれています。 

次に、このケースを見てみましょう。```
AAB
C
ABC
```正しい出力は次のとおりです。```
NO
```必要な文字がすべて少なくとも 1 回出現するため、素朴な存在ベースのチェックではこれが誤って受け入れられてしまいます。 問題はそれです`'A'`が欠けています。 

もう 1 つの簡単な間違いは、余分な文字を拒否することを忘れることです。```
ABC
DEF
ABCDEFX
```正しい出力は次のとおりです。```
NO
```必要な文字はすべて揃っていますが、余分な文字は`'X'`パイルを無効にします。 

最後のエッジケースは、長さがすでに一致していない場合です。```
AB
CD
ABC
```正しい出力は次のとおりです。```
NO
```結合した名前には 4 文字が必要ですが、山には 3 文字しかありません。 正しいソリューションは、直ちに拒否するか、カウントを通じて不一致を検出する必要があります。 

## アプローチ

 この強引なアイデアは、結合された名前の可能なすべての順列を生成し、それらの 1 つがパイル文字列に等しいかどうかをチェックすることです。 これが機能するのは、問題が文字通り、山を元の文字に再配置できるかどうかを問うているからです。 

組み合わせた長さの場合、`n`、 がある`n!`順列。 たとえ`n = 20`、これは不可能なほど大きくなり、実際の制限は 200 文字に達する可能性があります。 階乗時間アルゴリズムはまったく実行不可能です。 

重要な点は、文字の順序はまったく重要ではないということです。 パイルは任意にシャッフルできます。 2 つの文字列は、すべての文字が両方に同じ回数出現する場合にのみ、任意の並べ替えの下で同等となります。 

これにより、問題は文字の頻度の比較に限定されます。 

これを行うには一般的な方法が 2 つあります。 1 つは、配列またはハッシュ マップを使用して文字をカウントする方法です。 もう 1 つは、両方の文字列をソートし、ソートされた結果を比較することです。 入力サイズが小さいため、どちらのアプローチも快適に受け入れられます。 

ソートベースのソリューションは特に簡潔です。 最初の 2 つの文字列を連結し、結果を並べ替え、パイル文字列を並べ替えて、それらを直接比較します。 ソートされたバージョンが一致する場合、文字マルチセットは同一です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース順列 | お(ん!) | O(n) | 遅すぎる |
 | 並べ替えと比較 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ゲスト名、ホスト名、パイルストリングを読み取ります。 
2. 最初の 2 つの文字列は、存在する必要があるすべての文字を表すため、これらを連結します。 
3. 連結された文字列を並べ替えます。 並べ替えると、同じ文字がグループ化され、頻度の比較が簡単になります。 
4. 同じ理由でパイルストリングを並べ替えます。 
5. ソートされた 2 つの文字列を比較します。 

それらが同一の場合、すべての文字は両方の文字列に同じ回数出現するため、次のように出力します。`"YES"`。 
6. それ以外の場合は、印刷します`"NO"`。 

### なぜ効果があるのか

 並べ替えにより、各文字列が正規形式に変換され、同一の文字マルチセットが同一の文字列になります。 2 つの文字列に同じ頻度でまったく同じ文字が含まれている場合、それらの並べ替えられたバージョンは文字ごとに一致する必要があります。 文字数が1つでも異なると、ソートされた文字列はどこかが異なります。 これにより、比較が必要かつ十分であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

guest = input().strip()
host = input().strip()
pile = input().strip()

combined = guest + host

if sorted(combined) == sorted(pile):
    print("YES")
else:
    print("NO")
```最初のステップでは、3 つの入力文字列を読み取り、末尾の改行文字を次のように削除します。`strip()`。 

変数`combined`誰も何も追加または削除しなかった場合に存在するはずのすべての文字を保存します。 

への呼び出し`sorted()`各文字列をソートされた文字リストに変換します。 Python はリストを辞書順に比較するため、両方のリストに同じカウントでまったく同じ文字が含まれている場合にのみ等価性が成功します。 

微妙な点の 1 つは、並べ替えだけでも長さの不一致がすでに自動的に処理されていることです。 1 つの文字列に余分な文字または欠落している文字がある場合、並べ替えられたリストは等しくなりません。 

Python の組み込みソート機能がすべての面倒な作業を効率的に処理するため、実装は短く済みます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n log n) | 並べ替えが実行時間を支配します。 
| スペース | O(n) | ソートされた文字リストには追加のメモリが必要です。 

ここ、`n`関係する文字の総数です。 可能な最大長はわずか 200 であるため、実行時間は制限に比べてわずかです。 このソリューションは、時間とメモリの両方の制約内に簡単に適合します。 

## テストケース```python
# helper: run solution on input string, return output string
import sys, io

def solve():
    input = sys.stdin.readline

    guest = input().strip()
    host = input().strip()
    pile = input().strip()

    combined = guest + host

    if sorted(combined) == sorted(pile):
        print("YES")
    else:
        print("NO")

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    output = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

    return output

# provided sample
assert run(
    "SANTACLAUS\nDEDMOROZ\nSANTAMOROZDEDCLAUS\n"
) == "YES\n", "sample 1"

# missing repeated character
assert run(
    "AAB\nC\nABC\n"
) == "NO\n", "missing repeated character"

# extra character
assert run(
    "ABC\nDEF\nABCDEFX\n"
) == "NO\n", "extra character"

# minimum size valid
assert run(
    "A\nB\nAB\n"
) == "YES\n", "minimum valid case"

# all characters equal
assert run(
    "AAA\nAAAA\nAAAAAAA\n"
) == "YES\n", "all equal characters"

# maximum-style boundary case
assert run(
    "A" * 100 + "\n" +
    "B" * 100 + "\n" +
    "A" * 100 + "B" * 100 + "\n"
) == "YES\n", "large boundary case"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`AAB / C / ABC`|`NO`| 欠落している重複文字を検出します。 
|`ABC / DEF / ABCDEFX`|`NO`| 余分な文字を拒否します |
 |`A / B / AB`|`YES`| 最小の有効な入力 |
 |`AAA / AAAA / AAAAAAA`|`YES`| 繰り返される同一文字を処理します。 
| 100`'A'`そして100`'B'`|`YES`| 境界サイズの入力 |
