 ## 解決策
 ## 問題の理解

 私たちは、石けり遊びのコートに投げられた石が厳密に正方形の内側に着地するかどうかを判断し、着地する場合はどの正方形であるかを特定するように求められます。 コートは一辺の長さの正方形から作られます`a`、1-1-2-1-2 の繰り返しパターンで行に配置されます。 各正方形には、下の行から左から右に順番に番号が付けられます。 座標`(x, y)`石が平面内のどこに着地するかを指定します。`(0, 0)`最初の正方形の左下隅にあります。 ストーンが境界線またはコートの外に着地した場合、出力は次のようになります。`-1`。 

制約が示すのは、`a`最大 100 までの小さいものですが、`x`そして`y`非常に大きくなる可能性があり、最大で`10^6`規模的には。 これにより、垂直方向の正方形の数が超過する可能性があるため、すべての潜在的な正方形を個別に反復するアプローチは除外されます。`10^4`最悪の場合。 

明らかではないエッジケースには、石が正方形の境界または列の間に正確に着地することが含まれます。 たとえば、`a = 1`、の石`(0, 0)`最初の正方形の角にあり、戻る必要があります`-1`。 同様に、2 つ並んだ 2 つの正方形の間の水平方向の隙間に正確に着地した石も戻ってくるはずです。`-1`。 単純に分割する単純な解決策`x`そして`y`による`a`厳格な封じ込めをチェックしないと、これらの国境症例では失敗します。 

## アプローチ

 ブルートフォースソリューションには、すべての正方形の座標を生成し、その境界ボックスを保存し、`(x, y)`は厳密に各ボックスの中にあります。 これは問題を直接モデル化するため機能しますが、正方形の数が直線的に増加するため、大きな座標に対しては遅すぎます。`y`そして交互の行の幅。 と`y`まで`10^6`そして`a`おそらく 1、最大まで調べる必要があります`10^6`各行には最大 2 つの正方形があり、最悪の場合は何百万もの小切手が発行されます。 

最適な解決策の重要な観察は、石けり遊びのコートが周期的であるということです。 一番下の行は 1 つの正方形、次の行は 1 つの正方形、その次は 2 つの正方形の行となり、この 1-2 パターンが繰り返されます。 垂直レイアウトにより、石がどの列にあるかを整数除算によって直接計算できます。`y`による`a`一方、水平レイアウトは、行の種類が決まれば扱いが簡単です。 また、石が正方形の境界上にないことを確認するなど、厳しい内部状態にも対応する必要があります。 これにより、問題は以下に基づく算術計算に縮小されます。`x`、`y`、 そして`a`これにより、すべての正方形を明示的に生成する必要がなくなります。

 ## アルゴリズムのチュートリアル

 1. まず、次のことを確認します。`x`はマイナスです。 そうであれば、ストーンはコートの外にあるので、出力`-1`。 
2. の整数除算によって行インデックスを計算します。`y`による`a`どの列に石が垂直に含まれているかを確認します。 これに電話してください`row`。 
3. 剰余を計算する`y % a`行内の位置を決定します。 余りが 0 または正確な場合`a`、石は水平境界上にあるので、出力`-1`。 
4. 行のタイプを決定します。最初の 2 行は 1 つの正方形で、次に 2 つの正方形の行とそれに続く 1 つの正方形の行でパターンが繰り返されます。 行インデックスを使用して、行に 1 つの正方形があるか 2 つの正方形があるかを識別します。 
5. 単一の正方形の行の場合は、`x`厳密に 0 から`a`。 そうでない場合は出力`-1`。 
6. 二重正方形の行については、`x`厳密に 0 から`2*a`。 もし`x`0との間にあります`a`、石は最初の正方形にあります。 間の場合`a`そして`2*a`、石は2番目の広場にあります。 もし`x`この範囲外の場合、出力`-1`。 
7. 以前のすべての行の正方形の数を合計し、現在の行内のローカル正方形インデックスを加算することによって、絶対平方数を計算します。 

機能する理由: アルゴリズムは直接マッピングします。`y`列に並んで、`x`1-2 交互パターンに従って、列に移動します。 厳密な不平等をチェックすることで、境界上の石が拒否されることを保証します。 周期的な列パターンにより、フルコートを生成することなく計算が可能になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

a, x, y = map(int, input().split())

if x < 0:
    print(-1)
    sys.exit()

row = y // a
row_pos = y % a

if row_pos == 0:
    print(-1)
    sys.exit()

# first two rows: 1 square each
if row == 0:
    if 0 < x < a:
        print(1)
    else:
        print(-1)
    sys.exit()
elif row == 1:
    if 0 < x < a:
        print(2)
    else:
        print(-1)
    sys.exit()

# pattern repeats starting from row 2
# rows: 2 -> 2+ pattern 1-2-1-2...
pattern_row = row - 2
# compute how many full cycles of 2 rows we have
cycle = pattern_row // 2
# determine type of row in cycle
row_in_cycle = pattern_row % 2  # 0 -> 1-square, 1 -> 2-squares

# base number of squares before this cycle
base_square = 2 + cycle * 3

if row_in_cycle == 0:  # single square row
    if 0 < x < a:
        print(base_square + 1)
    else:
        print(-1)
else:  # double square row
    if 0 < x < a:
        print(base_square + 1)
    elif a < x < 2*a:
        print(base_square + 2)
    else:
        print(-1)
```コードはまず、否定的な些細なケースを処理します。`x`そして最初の2行。 後続の行については、モジュラー算術と整数除算を使用して行のタイプを決定し、マップします。`x`正しい広場へ。 境界チェックは厳格で、端に石が存在しないようにします。
