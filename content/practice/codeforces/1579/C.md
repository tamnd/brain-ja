 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$n \times m$紙を表しており、一部のセルが黒くなっています（で示されています）`*`) その他は白 (`.`）。 カシミール氏は、黒細胞はダニを描くことによって生成されると主張している。 ティックサイズ$d$あるセルの中心にあり、斜め上、左上、右上に正確に伸びています$d$細胞。 ダニが中央細胞と 2 本の腕を覆い、その結果、$2d+1$黒い細胞。 すべてのティックには最小サイズがあります$k$。 複数の目盛りが重なることがあり、セルが黒になると黒のままになります。 

タスクは、指定された白黒グリッドが、少なくともサイズが指定されたティックの組み合わせによって生成されたかどうかを確認することです。$k$。 

制約は小さいです。$n$最大でも 10 であり、$m$これにより、タイムアウトを気にせずにグリッドを徹底的に処理できるようになります。 主な課題は効率ではなく、どの黒セルがどのサイズのティックに属するかを正確に識別することです。$\ge k$すべての黒セルが考慮されていることを確認します。 

エッジ ケースには、いくつかの黒いセルが孤立しているグリッドや、最小サイズの目盛りをサポートするには最上部の行に近すぎるグリッドが含まれます。 たとえば、次の場合$k=2$そして`*`最初の行に が表示されている場合、これを一番下のセルとしてサイズ 2 の目盛を形成する方法はありません。そのため、答えは次のようになります。`NO`。 

## アプローチ

 ブルートフォースアプローチでは、すべての可能な位置ですべての可能なティックを試し、それらがグリッドを正確にカバーできるかどうかを確認しようとします。 各潜在的中心について`(i, j)`、すべてのサイズを試してみます$d \ge k$それに応じてセルにマークを付けます。 これは小さなグリッドでは機能しますが、$n=10$そして$m=19$、重複する多くのティックを冗長に試行する可能性があり、カバレッジを繰り返し検証するのは面倒になります。 

最適化するための重要な観察は、目盛りが斜め上に伸びる必要があるということです。 したがって、目盛の中心はその行の下またはその行にある黒いセルのみを担当できるため、グリッドを下の行から上の行にスキャンできます。 それぞれについて`*`、上に向かう対角線を確認することで、そのセルを底とする最大目盛サイズを決定できます。 最大サイズが少なくとも$k$、対応するセルをカバー済みとしてマークします。 すべての潜在的なティックを処理した後、`*`覆われないままにしておくと、グリッドが無効になります。 

これにより、貪欲だが構造化されたアプローチが可能になります。つまり、各セルで終了する可能性のある目盛りの最大サイズを計算し、それに応じてセルにマークを付け、すべての黒いセルが含まれていることを確認します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n * m * min(n, m)^2) | O(n * m) | 遅すぎる/乱雑 |
 | 最適 | O(n * m) | O(n * m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力グリッドとパラメータを読み取ります。`n, m, k`。 グリッドをブール 2D 配列に変換します`grid`どこ`True`黒マスを表します。 
2. 2 つの補助 2D 配列を初期化する`left_diag`そして`right_diag`グリッドと同じサイズです。`left_diag[i][j]`で終わる、左斜め上にある連続する黒セルの長さを格納します。`(i,j)`。`right_diag[i][j]`で終わる連続する黒セルの長さを右斜め上に格納します。`(i,j)`。 
3. 埋める`left_diag`そして`right_diag`ボトムアップ方式で。 細胞の場合`(i,j)`と`*`、`left_diag[i][j]`は`1 + left_diag[i-1][j-1]`もし`i>0`そして`j>0`、それ以外の場合は 1。同様に、`right_diag[i][j]`は`1 + right_diag[i-1][j+1]`もし`i>0`そして`j<m-1`、それ以外の場合は 1。 
4. を初期化します。`covered`サイズの配列`n x m`みんなで`False`。 この配列は、どの黒セルがサイズ ≥ k の目盛りによって説明されるかを追跡します。 
5. 各セルをスキャンします`(i, j)`下から上へ。 もし`(i,j)`が黒の場合、最大ティック サイズを次のように計算します。`d = min(left_diag[i][j], right_diag[i][j]) - 1`。 もし`d >= k`、このティックのすべてのセルをマークします。`covered`配列: それぞれ`h`から`0`に`d`、 マーク`(i-h, j-h)`そして`(i-h, j+h)`として`True`。 
6. すべてのセルを処理した後、グリッド上で反復処理を行います。 任意のセルがあれば`(i,j)`元のグリッドでは黒ですが、カバーされているとマークされていない場合、印刷します`NO`。 それ以外の場合は、印刷します`YES`。 

機能する理由: ボトムアップ スキャンにより、潜在的なダニの腕がブロックされていないことが確認され、すべてのセルにダニのマークが付けられます。 黒いセルが覆われていないままの場合、そのセルはサイズ ≥ k のどのティックにも属すことはできません。 ボトムアップでスキャンすることにより、各ティックは可能な最大サイズで識別され、有効なティックが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m, k = map(int, input().split())
        grid = [list(input().strip()) for _ in range(n)]
        left_diag = [[0]*m for _ in range(n)]
        right_diag = [[0]*m for _ in range(n)]
        covered = [[False]*m for _ in range(n)]

        for i in range(n):
            for j in range(m):
                if grid[i][j] == '*':
                    left_diag[i][j] = 1 + (left_diag[i-1][j-1] if i>0 and j>0 else 0)
                    right_diag[i][j] = 1 + (right_diag[i-1][j+1] if i>0 and j<m-1 else 0)

        for i in reversed(range(n)):
            for j in range(m):
                if grid[i][j] == '*':
                    d = min(left_diag[i][j], right_diag[i][j]) - 1
                    if d >= k:
                        for h in range(d+1):
                            covered[i-h][j-h] = True
                            covered[i-h][j+h] = True

        ok = True
        for i in range(n):
            for j in range(m):
                if grid[i][j] == '*' and not covered[i][j]:
                    ok = False
                    break
            if not ok:
                break
        print("YES" if ok else "NO")

solve()
```の`left_diag`そして`right_diag`配列は、各セルの潜在的なティックの最大上向きアームを効率的に計算します。 ボトムアップ パスでは、可能な限り最大のティックを最初にキャプチャし、カバーされているすべてのセルにマークを付けることが保証されます。 最終チェックでは、原因不明の黒セルがないことが保証されます。 インデックスエラーを避けるために、配列の境界には注意する必要があります。 

## 実用的な例

 **例 1**

 入力グリッド (4x9、k=2):```
*.*.*...*
.*.*...*.
..*.*.*..
.....*...
```最下段のステップトレース`i=3`:

 | 私 | j | グリッド | 左ダイアグ | 右診断 | d | アクション |
 | --- | --- | --- | --- | --- | --- | --- |
 | 3 | 5 | * | 1 | 1 | 0 | d<k、スキップ |

 上に移動すると、目盛りの中心が次の位置になります。`(2,5)`と`d=2`すべてのセルにマークを付け、関連するセルをカバーします`*`。 アルゴリズムはすべてのティックを検出し、すべての黒いセルがカバーされていることを確認します。 出力：`YES`。 

**例 2**

 入力グリッド (2x3、k=1):```
*.*
...
```ボトムアップパス:

 | 私 | j | グリッド | 左ダイアグ | 右診断 | d | アクション |
 | --- | --- | --- | --- | --- | --- | --- |
 | 1 | 0 | 。 | 0 | 0 | - | スキップ |
 | 0 | 0 | * | 1 | 1 | 0 | d<k、スキップ |

 サイズ 1 以上の目盛りは説明できません`*`で`(0,0)`。 出力：`NO`。 

これらのトレースは、アルゴリズムが可能な最大目盛りサイズを正確に識別し、説明のつかない黒セルが残されていないことを確認していることを示しています。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n*m) | 各セルは一定の回数処理されます。つまり、対角線の計算が 1 回、ボトムアップのマーキングが 1 回です。 |
 | スペース | O(n*m) | のために`left_diag`、`right_diag`、 そして`covered`配列。 |

 入力境界が小さいため、この線形ソリューションは非常に効率的になります。
