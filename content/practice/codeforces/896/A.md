 ## アルゴリズムのチュートリアル

 まず、各文字列の構造を形式化します。 各レベル$f_i$以下で構成されます:

 1. 固定プレフィックス文字列$A =$「送りながら何してるの？」
 2. 全体$f_{i-1}$。 
3. 中央の固定弦$B =$「?忙しいですか?」を送ってください。 
4. 別のコピー$f_{i-1}$。 
5. 固定サフィックス$C =$「「？」。 

これらのコンポーネントの構造は直線的であるため、長さのみを追跡します。 

1. 長さを事前計算します。$f_i$から$i = 0$に$n$で成長が止まる$10^{18}$。 これにより、オーバーフローが回避され、大規模なデータを処理する際の比較が安全に保たれます。$k$。 
2. クエリごとに$(n, k)$、どうかを確認してください$k$～の全長を超える$f_n$。 その場合は、「.」を返します。 ポジションが存在しないためすぐに。 
3. それ以外の場合は、水平から始まる降下をシミュレートします。$n$。 各レベルで$i$、 比較する$k$5 つの構造部分の長さを順番に測定します。 
4. もし$k$固定セグメント内にある$A, B, C$、これらの文字列は定数であるため、対応する文字を直接返します。 
5. もし$k$～の最初または 2 番目のコピー内にある$f_{i-1}$、以前のすべてのセグメントのオフセットを減算し、レベルで再帰を続行します。$i-1$。 
6. 到達するまで繰り返します$f_0$、答えが直接得られます。 

これが機能する理由は、すべてのポジションが$f_i$正確に 1 つの互いに素なセグメント (固定テキストまたは 2 つの同一の再帰的部分構造のいずれか) に属します。 からのマッピング$f_i$に$f_{i-1}$相対的な順序が保持されるため、オフセットを減算すると、グローバル インデックスがローカル インデックスに正しく変換されます。 

不変条件は、すべての再帰ステップで、ペアが$(i, k)$常に概念文字列内の同じ文字を参照します$f_i$。 セグメンテーションにより文字列がすべてのレベルで完全に分割されるため、アルゴリズムは領域をスキップしたり複製したりすることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    base = "What are you doing at the end of the world? Are you busy? Will you save us?"
    A = "What are you doing while sending "
    B = "? Are you busy? Will you send \""
    C = "\"?"

    q = int(input().strip())
    queries = [tuple(map(int, input().split())) for _ in range(q)]

    MAX = 10**18

    # precompute lengths
    # f0
    f_len = [0] * (100005)
    f_len[0] = len(base)

    for i in range(1, 100005):
        val = len(A) + len(B) + len(C)
        if f_len[i - 1] > MAX:
            inner = MAX
        else:
            inner = f_len[i - 1]

        val += 2 * inner
        f_len[i] = min(MAX, val)

    def get_char(n, k):
        if n == 0:
            return base[k - 1] if 1 <= k <= len(base) else '.'

        A_len = len(A)
        B_len = len(B)
        C_len = len(C)
        inner = f_len[n - 1]

        if k <= A_len:
            return A[k - 1]

        k -= A_len

        if k <= inner:
            return get_char(n - 1, k)

        k -= inner

        if k <= B_len:
            return B[k - 1]

        k -= B_len

        if k <= inner:
            return get_char(n - 1, k)

        k -= inner

        if k <= C_len:
            return C[k - 1]

        return '.'

    for n, k in queries:
        print(get_char(n, k), end='')

if __name__ == "__main__":
    solve()

再帰関数`get_char`構造的な降下を実行します。 セグメントの長さを減算するたびに、座標系が正しいサブパーツにシフトされます。 の再帰コピーを入力するとき$f_{n-1}$、絶対位置を再計算せずに正確さを維持しながら、調整されたインデックスを直接渡します。
