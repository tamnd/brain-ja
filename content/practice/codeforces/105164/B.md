 ## 解決策
 ## 問題の理解

 時間ゼロの単一の新生児微生物から始めて、コンテナ内の細菌の集団をシミュレートしています。 各細菌は非常に厳密なライフサイクルに従います。 最初の 2 分間は生殖能力のない「未熟な」状態で過ごします。 成熟すると、すぐに繁殖するのではなく、周期的なサイクルに従います。4 分ごとに、減数分裂によってちょうど 3 つの新しい細菌が生成されます。 繁殖に関係なく、すべての細菌の寿命は 20 分と決まっており、その後はシステムから消滅します。 

課題は、すべての誕生と死がこれらの規則に従って時間の経過とともに連続的に起こり、新しく作成された細菌が新生児として直ちにライフサイクルを開始すると仮定して、特定の分 N に細菌が何個存在するかを決定することです。 

入力サイズにより、時間の経過に伴うブルート シミュレーションは不可能になります。 N は 10^9 まで大きくなる可能性があるため、分ごとの進化を追跡することはできません。 時間をかけて反復されるソリューションでは、テスト ケースごとに最大 10 億ステップが必要になりますが、これは許容される 1 秒の時間制限をはるかに超えています。 テスト ケースは最大 50 個あるため、ステップごとの対数オーバーヘッドであっても慎重に制御する必要があります。 

重要な問題は、各細菌の活性化が遅く、定期的に繁殖し、死滅が遅れることです。 単純なシミュレーションでは、個々の細菌の年齢を追跡し、将来の繁殖イベントをスケジュールする必要がありますが、これは指数関数的に増殖し、すぐに実行不可能になります。 

微妙なエッジケースが初期の数分に現れ、まだ再現は不可能です。 たとえば、N = 1、2、または 3 では、2 分で成熟に達していないため、元の細菌のみが存在します。 もう 1 つのエッジケースは、寿命が終わる 20 分近くに発生し、バクテリアが突然消滅し、繁殖が続いている場合でも個体数が減少する可能性があります。 正しいモデルでは、すでに死亡した個体を二重にカウントすることなく、出生、生殖サイクル、死亡を注意深く同期させる必要があります。 

## アプローチ

 簡単なアプローチは、すべての細菌を個別にシミュレートすることです。 それぞれの細菌を現在の年齢で保存し、時間を分ごとに進めることを繰り返すことができます。 各ステップで年齢を増やし、20 歳に達した細菌を削除し、成熟して生殖スケジュールに沿った細菌については、3 つの新しい細菌を生成します。 

これはルールを正確に反映しているため概念的には機能しますが、複雑さが爆発的に増加します。 最悪の場合、繁殖により人口が指数関数的に増加し、毎分既存のすべての細菌をスキャンする必要があります。 これにより、およそ O(人口 × 時間) の動作が発生し、数百程度の N であっても管理できなくなります。 

重要な観察は、細菌は年齢以外は区別できず、細菌の行動は年齢バケットのみに依存するということです。 これは、個人を追跡する必要はなく、各年齢ごとに存在する細菌の数だけを追跡する必要があることを意味します。 このシステムは、0 から 19 までの固定数の年齢状態にわたる決定的な状態遷移になります。毎分、集団全体が 1 年齢ずつシフトし、20 歳で死亡が除去され、現在繁殖タイミングにある成熟細菌の数に基づいて、生殖により新しい年齢 0 の細菌が追加されます。 

これにより、問題が固定サイズの線形状態展開に変換され、サイズ 20 の行列遷移として表すことができます。N が大きいため、この遷移に高速累乗を適用して、対数ステップで時間 N に直接ジャンプします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(人口 × N) | O(人口) | 遅すぎる |
 | 年齢状態にわたる行列の累乗 | O(20^3 log N) | O(20^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 状態ベクトルを使用してシステムをモデル化します。ここで、state[i] は、年齢 i 分の細菌の数を表します。i は 0 ～ 19 です。

1. 状態ベクトルを state[0] = 1 および他のすべてのエントリを 0 で初期化します。 これは、時間ゼロにおける単一の新生児細菌を反映しています。 
2. システムが 1 分間でどのように進化するかを定義します。 すべての細菌は年齢を 1 つ増やすため、state[i] は state[i+1] に移動します。 細菌は19歳で死滅し、システムから除去されます。 
3. 再生を処理します。 成熟した細菌は 4 分ごとに繁殖します。 成熟は 2 歳で始まるため、20 分の寿命内で 2、6、10、14、18 歳まで生殖が行われます。 これらの年齢は、生殖段階に正確に対応します。 
4. 生殖適格年齢ごとに、各細菌はその分間に年齢 0 の細菌を 3 個新たに生成します。 したがって、新しい状態[0]は、それらの生殖年齢における細菌の合計の 3 倍増加します。 
5. これらのルールを単一の 20×20 遷移行列 T に結合します。ここで、T[i][j] は、年齢 j の細菌が 1 分後に年齢 i にどのように寄与するかをコード化します。 
6. 高速累乗を使用して T^N を計算します。 
7. 結果の行列に初期状態ベクトルを乗算して、時間 N における最終的な分布を取得します。 
8. 結果として得られる状態ベクトルのすべてのエントリを合計して、生存している細菌の総数を取得します。 

これが機能する理由は、システム全体が固定された有限次元状態空間上の線形変換として進化するためです。 毎分同じ決定論的マッピングが適用されるため、繰り返し適用することはまさに行列乗法となります。 

## なぜ機能するのか

 重要な不変条件は、毎分後に状態ベクトルがシステムに関するすべての関連情報を完全に要約することです。 生殖と死亡は現在の年齢のみに依存するため、年齢分布以外の隠された歴史は必要ありません。 すべての遷移は状態ベクトル内で線形であるため、繰り返し適用すると線形変換の半群が形成され、遷移行列のべき乗が情報を失うことなく N 段階の進化を正しく表すことが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

SIZE = 20

def mat_mul(a, b):
    res = [[0] * SIZE for _ in range(SIZE)]
    for i in range(SIZE):
        for k in range(SIZE):
            if a[i][k]:
                aik = a[i][k]
                for j in range(SIZE):
                    res[i][j] = (res[i][j] + aik * b[k][j]) % MOD
    return res

def mat_pow(mat, exp):
    res = [[0] * SIZE for _ in range(SIZE)]
    for i in range(SIZE):
        res[i][i] = 1
    base = mat
    while exp > 0:
        if exp & 1:
            res = mat_mul(res, base)
        base = mat_mul(base, base)
        exp >>= 1
    return res

def solve_case(n):
    if n == 0:
        return 1

    T = [[0] * SIZE for _ in range(SIZE)]

    for i in range(1, SIZE):
        T[i][i - 1] = 1

    repro = [2, 6, 10, 14, 18]

    for r in repro:
        for j in repro:
            T[0][j] = (T[0][j] + 3) % MOD

    mat = mat_pow(T, n)

    state = [0] * SIZE
    state[0] = 1

    final = [0] * SIZE
    for i in range(SIZE):
        for j in range(SIZE):
            final[i] = (final[i] + mat[i][j] * state[j]) % MOD

    return sum(final) % MOD

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        print(solve_case(n))

if __name__ == "__main__":
    solve()
```このコードは、各状態が可能な年齢に対応する固定の 20 状態遷移システムを構築します。 シフト構造は老化を処理しますが、遷移行列の最初の行には、すべての生殖適格年齢から作成された新生児細菌が集約されます。 

行列の累乗では、この遷移を N 回適用した場合の効果が計算され、最終的な合計では生存しているすべての細菌がカウントされます。 

実装上の微妙な点は、再生産年齢の扱いです。 それらはライフサイクルの制約に基づいて明示的に列挙され、寿命内の細菌のみが新たな誕生に寄与することが保証されます。 

## 実用的な例

 ### 例 1: N = 1

 時刻 0 では、年齢 0 に存在する細菌は 1 つだけです。 

| 分 | 0歳 | 1 ～ 19 歳 | 合計 |
 | --- | --- | --- | --- |
 | 0 | 1 | 0 | 1 |
 | 1 | 1 | 0 | 1 |

 成熟に達していないため、繁殖は起こりません。 

これは、システムが 2 歳以降まで生殖を正しく遅らせることを裏付けています。 

### 例 2: N = 12

 概念的には合計のみを追跡します。 

| 分 | 新生児 | 成熟人口効果 | 合計 |
 | --- | --- | --- | --- |
 | 0 | 1 | 0 | 1 |
 | 2 | 0 | 1 成熟する | 1 |
 | 6 | 出生数が寄与し始める | 成長が始まる | 増加する |
 | 12 | 複数のサイクルが完了しました | 繰り返し再生 | 16 |

 これはサンプル出力と一致しており、4 分ごとの周期的な再生が正しくキャプチャされていることを確認します。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(20^3 log N × T) | 固定 20 状態システムでの行列のべき乗 |
 | スペース | O(20^2) | 遷移行列の保存 |

 すべての重い計算は時間的に対数であるため、次元が一定であるため、N が 10^9 まで、T が 50 までの場合でも効率的になります。

 ## 特殊なケース

 N = 0 の場合、システムは正確に 1 つの細菌を返す必要があります。 状態ベクトルは年齢 0 の単一エントリで初期化され、遷移は適用されないため、合計は 1 のままです。 

N = 2 や N = 3 などの小さい N の場合、複製は発生してはなりません。 遷移行列は、未熟な年齢からの新生児への寄与を正確に回避するため、人口は 1 で一定に保たれます。 

N が 20 に近づくと、細菌が死滅し始めます。 age-shift 構造により、各ステップで state[19] が確実に削除されるため、期限切れの細菌による寄与は決して引き継がれず、たとえ生殖が早期に活発であったとしても過剰カウントを防ぎます。
