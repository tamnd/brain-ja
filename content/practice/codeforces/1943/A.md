 ## 問題の理解

 非負の整数の配列を使用して 2 人用ゲームを分析するように求められます。 アリスは空の配列から始まります`c`そして、彼女の番では、最初の配列から任意の要素を取得します。`a`そしてそれを追加します`c`。 ボブは自分の番で、から要素をすべて削除します。`a`しかし、それを追加しません`c`。 ゲームは次の時点で終了します`a`は空です。 最終スコアは次の MEX です。`c`、これは、以下に存在しない最小の非負の整数です。`c`。 アリスはこのスコアを最大化したいと考えていますが、ボブは最小化したいと考えています。 この問題では、両方のプレイヤーが最適にプレイした場合の最終スコアを求めます。 

入力は複数のテスト ケースで構成されます。 各テスト ケースはサイズを提供します`n`配列と配列要素自体のすべてが より小さいことが保証されます`n`。 出力は、アリスの配列の最終 MEX を表すテスト ケースごとに 1 つの整数です。`c`。 

とすれば`n`最大 200,000 およびすべての合計`n`全体のテスト ケースは 200,000 に制限されているため、サイズが線形または線形に近いソリューションを目指す必要があります。`a`。 二次複雑度の解は 2 秒の制限時間内に完了しません。 

考慮すべきエッジ ケースには、0 から 0 までのすべての数値が既に含まれている配列が含まれます。`n-1`(低い MEX を強制する)、すべてが重複している配列 (最初のいくつかの整数が欠落している可能性がある)、要素が高い値または低い値に大きく偏っている配列。 例えば、`a = [1,1,1]`の MEX を出力する必要があります`0`、 その間`a = [0,1,2]`出力する必要があります`3`。 すべての動きの単純なシミュレーションはパフォーマンスに失敗する可能性がありますが、配列の構造のみが最適なプレイを決定するため、その必要はありません。 

## アプローチ

 ブルートフォースアプローチは、あらゆる可能なゲームをシミュレートします。 各ターンでアリスにとって最良の要素とボブにとって最悪の要素を繰り返し選択し、更新していました。`a`最後に MEX を計算します。 このアプローチは正しいのですが、遅すぎます。 最悪の場合、各ターンで残りの配列をスキャンして最適な要素を選択する必要があり、複雑さがおよそ O(n²) になる可能性があり、これは受け入れられません。`n = 2 * 10^5`。 

重要な点は、すべてのターンをシミュレーションする必要はないということです。 メキシコ合衆国`c`のどの数字によって決まりますか`0`ボブがそれらを取り除く前に、アリスは上向きに確保することができます。 したがって、問題は、各整数のコピーが何個存在するかを数えるということになります。`a`。 させて`count[x]`整数の出現数になります`x`で`a`。 アリスは各番号のコピーを 1 つだけ追加できます`c`、ボブは他の人を削除できます。 ゲームは以下から順番に進行していきます`0`上向きに。 MEX は最小の整数によって決定されます。`x`アリスが少なくとも 1 つのコピーを配置できないもの`c`ボブがすべて削除したか、利用できないためです。 

この洞察により、問題は発生のカウントとスキャンからのスキャンに帰着します。`0`上向きに。 これにより、カウントを保存するための O(n) スペースを持つテスト ケースごとに O(n) のソリューションが得られます。

 ## アルゴリズムのチュートリアル

 1. テスト ケースごとに、配列を読み取ります。`a`辞書または頻度配列内の各整数の頻度を計算します`count`。 
2. 変数を初期化する`mex`0にします。 
3. その間`count[mex]`存在し、肯定的な場合は、次の手順を実行します。 

- もし`count[mex] >= 2`、アリスは 1 回の出現を確保できますが、ボブは彼女が少なくとも 1 回出現するのを防ぐことができないため、値を減らします。`count[mex]`2 ずつ増分`mex`1までに。 
- もし`count[mex] == 1`、アリスはそれを受け取ることができますが、ボブは次のターンにそれを取り除くので、減らしてください。`count[mex]`1.増分`mex`1までに。 
- もし`count[mex] == 0`または存在しない場合は壊れます。 これ`mex`アリスが確保できない最小の非負の整数であり、次の MEX です。`c`。 
4. 出力`mex`。 

重要な不変条件は、各数値で`x`、アリスは最大 1 つのコピーを取得でき、ボブは 1 つのコピーを削除できます。つまり、合計数によってアリスが配置できるかどうかが決まります。`x`の中へ`c`使い果たされる前に。 一度`count[x]`足りなくなり、アリスは配置できません`x`で`c`、MEX を定義します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def mex_game(a):
    from collections import Counter
    count = Counter(a)
    mex = 0
    while True:
        if count[mex] >= 2:
            count[mex] -= 2
            mex += 1
        elif count[mex] == 1:
            count[mex] -= 1
            mex += 1
        else:
            break
    return mex

def main():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        print(mex_game(a))

if __name__ == "__main__":
    main()
```コードはまず、次を使用して各数値の出現をカウントします。`Counter`。 while ループは、0 から始まる各整数を段階的にチェックします。ループごとに 1 つまたは 2 つの出現を減算することで、アリスとボブの最適なプレイが考慮されます。 アリスが数字を配置できない場合、ループは中断され、正確性が保証されます。 使用するという選択`Counter`サイズの配列の必要性を回避します`n`、欠落している数値の特殊なケースの処理を簡素化します。
