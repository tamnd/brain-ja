 ## 解決策
 ## 問題の理解

 それぞれが正の整数の長さを持つ木の棒のセットが与えられています。 Vasya さんは、同じ長さの棒を積み上げて塔を建てたいと考えています。 各タワーは同じ長さのバーで構成されている必要がありますが、タワーが異なれば長さも異なります。 目標は、タワーの数を最小限に抑え、最も高いタワーの高さを報告しながら、すべてのバーをタワーに構築することです。 

入力はバーの数で構成されます$N$(1 ≤ N ≤ 1000) とその長さのリスト。 出力には、単一のタワーに積み重ねられたバーの最大数とタワーの合計数の 2 つの整数が必要です。 

制約は中程度です。$N$最大 1000 までの値を指定できるため、時間計算量が最大 1000 までのアルゴリズムが可能になります。$O(N^2)$快適に。 ただし、長さは 1000 で区切られた整数であるため、これを利用して、バーのすべてのペアを反復処理することなくカウントを効率的に計算できます。 これは、入れ子になったループ構造ではなく、頻度をカウントするアプローチを示唆しています。 

明らかではないエッジケースには次のようなものがあります。 

1. すべてのバーは固有の長さを持っています。 たとえば、入力`5\n1 2 3 4 5`それぞれ高さ 1 の 5 つの塔が作成されます。バーを「結合」しようとする不用意なアプローチは失敗します。 
2. すべてのバーは同じ長さです。 入力`4\n7 7 7 7`高さ 4 の単一の塔が生成されるはずです。 
3. 混合繰り返し。 入力`6\n1 2 2 3 3 3`は、高さ 1、2、および 3 の塔を生成し、最も高い塔の高さは 3 になります。数えずに単純に並べ替えると、塔の数を効率的に計算する方法がわかりにくくなる可能性があります。 

## アプローチ

 強引なアプローチは、塔の建設を明示的にシミュレートすることです。 各バーを反復処理して、同じ長さの既存のタワーに配置することも、新しいタワーを開始することもできます。 のために$N = 1000$、これにはすべてのバーについてすべての既存のタワーをチェックすることが含まれ、潜在的に次のような問題につながる可能性があります。$O(N^2)$操作。 これはここでは実現可能ですが、高さと数をより直接的に求めることができる場合、不必要に複雑になり、エラーが発生しやすくなります。 

重要な洞察は、最も高いタワーの高さはバーの長さの最大頻度によって決まり、タワーの総数は異なる長さの数によって決まるということです。 周波数をカウントすると、問題はデータの単純なパスに変わります。 各長さのバーが何本存在するかを保存することにより、最も高いタワーが単に最大数となり、タワーの数が一意の長さの数になります。 

「明示的な塔構造ではなく、カウントのみが必要である」という観察により、問題がシミュレーションからカウントの問題に変換され、複雑さが軽減されます。$O(N^2)$に$O(N)$。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(N^2) | O(N) | 機能しますがやりすぎです |
 | 最適 | O(N) | O(L) ただし、L ≤ 1000 | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 各小節の長さの頻度をカウントするために辞書 (またはサイズ 1001 の配列) を初期化します。 この構造は、各長さをその長さの小節の数にマッピングします。 
2. すべてのバーの長さを繰り返します。 長さごとに、頻度ディクショナリ内のカウントを増加させます。 このステップにより、バーの長さの完全な分布が得られます。 
3. 周波数辞書で最大値を見つけて、最も高い塔の高さを決定します。 同一のバーの最大数は、最も高いタワーに直接対応します。 
4. 辞書に存在する一意の長さの数を計算して、タワーの総数を数えます。 それぞれの固有の長さが正確に 1 つのタワーを形成します。 
5. 最も高いタワーの高さとタワーの総数を出力します。 

機能する理由: 各ポイントで、アルゴリズムは各小節の長さの完全なカウントを保持します。 最も高いタワーは、最も頻繁に使用される長さの数を超えることはできず、それぞれの異なる長さが少なくとも 1 つのタワーに寄与する必要があります。 情報が失われることはないので、最終的な答えは正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

N = int(input())
lengths = list(map(int, input().split()))

# count frequencies
freq = {}
for l in lengths:
    if l in freq:
        freq[l] += 1
    else:
        freq[l] = 1

max_height = max(freq.values())
num_towers = len(freq)

print(max_height, num_towers)
```このソリューションはまず、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`。 周波数辞書`freq`は各長さのカウントを保存し、最も高いタワーの最大値を直接計算します。 辞書内のキーの数によって、個別のタワーの数が決まります。 これにより、off-by-one エラーや不要なループが回避されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(N) | 入力の読み取りに 1 つのパス、ビルドに 1 つのパスがカウントされます。 |

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    N = int(input())
    lengths = list(map(int, input().split()))
    freq = {}
    for l in lengths:
        freq[l] = freq.get(l, 0) + 1
    return f"{max(freq.values())} {len(freq)}"

# provided sample
assert run("3\n1 2 3\n") == "1 3"

# all equal
assert run("4\n7 7 7 7\n") == "4 1"

# mixed repetitions
assert run("6\n1 2 2 3 3 3\n") == "3 3"

# minimum input
assert run("1\n5\n") == "1 1"

# maximum input with distinct values
assert run("1000\n" + " ".join(map(str, range(1,1001))) + "\n") == "1 1000"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | 4\n7 7 7 7 | 4 1 | すべてのバーは同一、単一タワー |
 | 6\n1 2 2 3 3 3 | 3 3 | 混合カウント、最も高いタワーの計算 |
 | 1\n5 | 1 1 | 最小サイズの入力 |
 | 1000\n1 2 3 ... 1000 | 1 1000 | 最大サイズの入力、すべて個別 |

 ## 特殊なケース

 入力用`4\n7 7 7 7`、周波数辞書は次のようになります。`{7:4}`。`max(freq.values())`最も高い塔の場合は 4 を正しく返します。`len(freq)`1 を返します。カウントを超えて個々のバーを反復する必要はありません。 

入力用`6\n1 2 2 3 3 3`、辞書`{1:1,2:2,3:3}`最も高いタワーの高さ 3、タワーの数 3 が生成されます。これにより、積み重ねのための追加ロジックなしで、アルゴリズムがさまざまな繰り返しを正しく処理していることが確認されます。
