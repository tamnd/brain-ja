 ## 解決策
 ## 問題の理解

 複数のテストケースが与えられます。 各テスト ケースは、2D 平面上の一連の点で構成されます。 すべての点には整数の座標と色のラベルがあります。 

このタスクは、それらの間のユークリッドの二乗距離を最大化する 2 つの点を見つけることです。ただし、選択された 2 つの点は異なる色でなければならないという 1 つの制限があります。 実際の距離を計算する代わりに、平方根を避けるために距離の 2 乗を使用しますが、ペアの順序は変わりません。 

幾何学的には、これはセット内で最も遠い点のペアを求めていますが、同じ色を共有する 2 つの点を選択することはできません。 色を完全に無視すると、答えは単純に点セットの直径になります。 問題は、直径の端点が同じ色を共有している可能性があるため、最適な代替ペアを探す必要があることです。 

制約は非常に大きいです。 すべてのテスト ケースの合計ポイント数は最大 10^6 であるため、テスト ケースごとの線形計算よりも劣る解は存続できません。 テスト ケースごとに O(n^2) であっても、最大 10^12 の距離計算が必要となるため、完全に不可能です。 これにより、ユークリッド空間の最も遠いペアは常に凸包上に発生するため、境界点のみが重要な幾何学的構造へと私たちは誘導されます。 

素朴なアプローチでは、すべてのポイントのペアをチェックし、同じ色のペアをスキップします。 これは二次関数の複雑さによりすぐに失敗します。 

より微妙な失敗例は、地球上で最も遠いペアが同じ色に属している場合に発生します。 たとえば、遠く離れた 2 つの点を除くすべての点が同じ色を共有している場合、真の答えは、単一の最適な幾何学的ペアに明らかに関連していない、はるかに小さいサブセットから得られる可能性があります。 単一の直径のみを計算して停止するアプローチは、正しくありません。 

## アプローチ

 色を無視する場合、古典的な解決策は、凸包を計算し、回転キャリパーを実行して直径を見つけることです。 正確さは、最も遠いペアが凸包上に存在する必要があり、回転ノギスが包上のすべての対蹠候補ペアを線形時間で列挙するという事実から得られます。 

ブルートフォース手法では、すべての n(n−1)/2 ペアを計算し、同じ色のペアをフィルタリングして除外し、最大距離を取得します。 すべてを明示的にチェックするため、これは正しいのですが、最悪の場合、制限をはるかに超える約 5×10^11 の演算が実行されます。 

重要な構造上の観察は、すべてのペアが必要ではないということです。 距離が極端に離れている可能性のあるペアのみを考慮する必要があります。 ユークリッド幾何学では、極端な距離は凸包上で発生し、より具体的には、回転キャリパー スイープの対蹠接触として現れるペアによって実現されます。 これにより、候補セットが O(n^2) ペアから O(h) に減ります。ここで、h はハル サイズです。 

色の制約により、これが少し複雑になります。最適な有効なペアは、絶対的な直径のペアではない可能性があります。 ただし、同じ幾何学的候補の生成に依拠することはできます。 すべての有効なペアについてグローバルに推論しようとする代わりに、制約のない問題で最適と思われるすべてのペアを生成し、色の制限を満たすものの中から最適なものを選択します。 残りの重要なステップは、各船体ポイントについて、最も遠いパートナーだけでなく、回転キャリパーが自然に露出する次善の幾何学的候補も取得できるようにすることです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | お(1) | 遅すぎる |
 | 凸包 + キャリパーの候補 | O(n log n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に解決します。

まず、標準的な単調チェーン構造を使用して、すべての点の凸包を計算します。 ハル上にないポイントは最大距離ペアの一部にはなり得ないため、このステップでは内部ポイントをフィルターで除外します。 

次に、凸包に対して回転キャリパー プロセスを実行して、対蹠関係を特定します。 各船体の頂点 i について、i から j までの距離が増加する間に船体の周囲を進むポインタ j を維持します。 これにより、その固定 i の距離を最大化する候補 j が得られます。 

第三に、各 i について、ハルに沿った j の隣接位置も考慮します。これは、キャリパー ポインターが移動するとき、最適な頂点の後の次の頂点が、最適に近い距離を生成できる唯一の他の意味のある幾何学的候補であるためです。 これにより、i ごとに最大 2 人のパートナー候補が得られます。 

4 番目に、すべての候補ペア (i, j) と (i, next(j)) をリストに収集します。 このリストは船体サイズに比例します。 

5 番目に、収集されたすべての候補ペアを反復処理し、それらの二乗距離を計算します。 このうち、端点の色が異なる最大のペアを選択します。 

### なぜ効果があるのか

 グローバルに最適な非拘束ペアは凸包上にあり、回転キャリパー スイープ中に対蹠ペアとして現れます。 そのペアがすでに異なる色を持っている場合、それは制約付き問題にも最適です。 

両方の端点が同じ色を共有しているためにそのペアが無効な場合、対蹠的な構成からの逸脱は船体の横断に沿って距離を単調に減少させるため、最適な有効なペアはキャリパーの順序付けにおいて幾何学的に近いペアの中に存在する必要があります。 キャリパー プロセスにより、ハル頂点間の局所的に最大の距離遷移がすべて、生成された候補ペアに含まれることが保証されるため、潜在的に最適な制約付きペアが見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dist2(a, b):
    dx = a[0] - b[0]
    dy = a[1] - b[1]
    return dx*dx + dy*dy

def convex_hull(points):
    points = sorted(points)
    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def solve():
    t = int(input())
    out = []

    for _ in range(t):
        n = int(input())
        pts = []
        for i in range(n):
            x, y, c = map(int, input().split())
            pts.append((x, y, c))

        if n == 2:
            (x1, y1, c1), (x2, y2, c2) = pts
            if c1 != c2:
                out.append(str(dist2((x1,y1),(x2,y2))))
            else:
                out.append("0")
            continue

        hull = convex_hull([(x, y, c) for x, y, c in pts])
        m = len(hull)

        if m == 1:
            out.append("0")
            continue

        best = 0

        def try_pair(i, j):
            nonlocal best
            if hull[i][2] != hull[j][2]:
                best = max(best, dist2(hull[i], hull[j]))

        j = 1
        for i in range(m):
            if j == i:
                j = (j + 1) % m

            while True:
                nj = (j + 1) % m
                if nj == i:
                    break
                if dist2(hull[i], hull[nj]) >= dist2(hull[i], hull[j]):
                    j = nj
                else:
                    break

            try_pair(i, j)
            try_pair(i, (j + 1) % m)
            try_pair(i, (j - 1 + m) % m)

        out.append(str(best))

    print("\n".join(out))

if __name__ == "__main__":
    solve()
```この解決策は、凸包を構築して内部点を排除することから始まります。 次に、回転キャリパー ループは、船体の頂点ごとに、循環順序で最も遠くに到達可能なパートナーを見つけます。 ヘルパーさん`try_pair`グローバル最大値を更新する前に色の制約を適用します。 

隣接するものに対する追加のチェック`j`色の等しいために正確な対蹠パートナーが無効な場合でも、近くの候補が評価されるようにします。 

## 実用的な例

 凸包が正方形で色が混合されている小さな構成を考えてみましょう。 船体点の順序が A、B、C、D で、最も遠い幾何学的ペアが A-C ですが、A と C は同じ色を共有しているとします。 

| 私 | j (最も遠い) | j+1 | 有効な A ～ B | 有効な A ～ C | これまでで最高 |
 | --- | --- | --- | --- | --- | --- |
 | あ | C | D | はい | いいえ | A-B候補 |
 | B | D | あ | はい | はい | B-D候補 |
 | C | あ | B | いいえ | いいえ | 変更なし |
 | D | B | C | はい | はい | 更新されました |

 この表は、色の制約により絶対直径のペアが無効な場合でも、アルゴリズムがどのように代替案を探索するかを示しています。 

ここで、最適な答えが全体の直径ではなく、依然として船体上にある場合を考えてみましょう。 キャリパー ポインタは、すべての頂点がその最適な幾何学的パートナーと確実にペアになるようにするため、たとえ世界的に最も遠いペアが失格となったとしても、次に最適な有効なペアがキャリパー一致の近隣に表示されます。

 ## 特殊なケース

 重要なエッジ ケースは、凸包のすべての極点が同じ色を共有する場合です。 このような構成では、グローバル直径は完全に無効になり、アルゴリズムはわずかに短いもののハルベースのペアにフォールバックする必要があります。 キャリパーの隣接チェックでは、隣接するハルの遷移が引き続き評価されることが保証されるため、アルゴリズムは単一の極値ペアだけに依存しません。 

別のエッジ ケースは、凸包が線分に崩壊するときに発生します。 この場合、ハルには 2 つの点しか含まれず、キャリパー ループは縮退します。 実装では、ペアを直接評価するか、不必要なポインタの移動をスキップすることでこれを処理し、無効なインデックスの移動が発生しないようにします。 

3 番目のエッジ ケースは、複数のポイントが同じ座標を共有しているが色が異なる場合に発生します。 この問題では、明確なトリプルが保証されますが、色間の等しい座標では依然として距離がゼロになり、アルゴリズムは色が異なる場合にのみそのようなペアを正しく許可します。
