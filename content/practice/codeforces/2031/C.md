 ## 解決策
 ## 問題の理解

 長さの配列内の各位置に値を割り当てるように求められます。$n$。 これらの値は、一列に並べられたバンズに配置された「フィリング」を表します。 同じ詰め物が複数回出現する場合がありますが、それは 2 つの厳密なルールに基づいてのみです。 

まず、詰め物が現れる場合、それは一度だけ現れるわけではありません。 使用するすべてのラベルは少なくとも 2 回出現する必要があります。 第 2 に、2 つの位置が同じラベルを共有する場合は常に、それらの位置間の距離は完全な正方形でなければなりません。 言い換えれば、各数値の出現により、すべてのペアごとの距離が平方数となる一連のインデックスが形成されます。 

したがって、タスクは配列を任意に「色付け」することではなく、インデックスをグループに分割することです。各グループのサイズは少なくとも 2 であり、グループ内のインデックス間のすべてのペアごとのギャップが完全な正方形になるように構造化されています。 

制約は大きいです:$n$まで上がります$2 \cdot 10^5$テストケース全体で。 ラベルを自由に割り当ててから各グループ内のすべてのペアを検証しようとするアプローチは、ペアごとの距離のチェックがグループ サイズの 2 次関数であり、$O(n^2)$。 

小さなサイズではキーエッジケースがすぐに現れます。 もし$n = 1$、単一の位置ではラベルが 1 回だけ出現することが強制されるため、これは不可能であり、これは禁止されています。 のために$n = 2$、1 つのラベルは 2 回しか使用できませんが、距離は$1$、これは完全な正方形なので、機能します。 本当に難しいのは、この構造を大規模に拡張する方法を理解することです。$n$。 

素朴なアイデアは、位置を 1、4、9 などの平方距離のペアに任意にグループ化してみることです。問題は、複数のペアが重なると一貫性が崩れることです。完全に位置が揃っていない限り、位置は 2 つの異なる正方形オフセット構造に属することはできません。 したがって、構造はグローバルであり、非常に規則的である必要があります。 

## アプローチ

 最初の本能は、ローカルに考えることです。各インデックスを一致させようとします。$i$いくつかの$i + k^2$。 貪欲に平方距離を選択してペアを形成すると、すぐに衝突に遭遇します。 複数の四角形ジャンプによって位置に到達できる場合があり、その位置を 1 つのペアに割り当てると別のペアがブロックされ、行き止まりにつながります。 逆戻りしてみても可能性は爆発的に増えます。 

重要な観察は、条件がグローバルで対称的であるということです。2 つの位置が必要な場合$i$そして$j$値を共有するには、その違いは正方形の集合内にある必要があります。 これは、エッジが接続されるインデックスの有向グラフの観点から考えることを示唆しています。$i$に$i + s^2$。 各値は、グループ内ですべてのノードの次数が少なくとも 1 である構造を形成するエッジのセットの選択に対応します。 

画期的な点は、任意の平方距離は必要なく、すべての値に対して機能する 1 つの一貫したパターンだけが必要であることに気づいたことです。 異なるスクエア ジャンプを混合する代わりに、アレイをタイル化する慎重に選択された単一のスクエア ステップ構造を使用して、固定ペアリング スキームを構築します。 

重要なアイデアは、整数ごとに増加する平方オフセットに基づいてチェーンを構築することです。$k$で区切られた位置を接続します。$k^2$ただし、すべてのポジションが制御された方法で正確に 2 回参加するように、これをレイヤーで行います。 これにより、インデックスが「正方形のはしご」にグループ化され、各はしごでは増加する正方形のギャップの連続セグメントが使用されます。 

この構造が認識されると、問題は、連続する奇数平方の合計から導出される既知の構成パターンに一致するサイズのブロックに配列を分割することになります。 これにより、各グループのサイズが自然に少なくとも 2 になることが保証され、すべてのペアごとの違いはチェックされるのではなく構築によって強制されます。

 ## アルゴリズムのチュートリアル

 1. 最大の整数を事前計算します$k$私たちが構築する全体的な構造が$k$を超えない$n$。 これは、構造が予測可能な階層的な方法で成長するという事実から来ています。 
2. ブロックをどこに置くかでブロックを構築します$k$サイズがあります$2k$。 2 倍にする理由は、各レイヤーですべてのラベルが少なくとも 2 回出現することを保証する必要があり、四角ジャンプ間の対称性によりペアでの使用が強制されるためです。 
3. これらのブロックにインデックスを順番に貪欲に割り当てます。 各ブロックは 1 つの異なるラベルに対応します。 
4. 各ブロック内で、対応する位置間の距離が一致するようにインデックスを対称パターンで配置します。$k^2$。 具体的には、ブロックの前半と後半を正確にずらして一致させます。$k^2$。 
5. すべての完全なブロックを構築した後に残りの位置が存在する場合、連続する位置は 1 だけ異なるため、最小の平方オフセット (1) を使用してそれらをペアで割り当てます。$1^2$。 
6. いずれかの時点で残りのポジションに対して少なくともペアを形成できない場合は、次のように出力します。$-1$。 

重要な構造上の決定は、各ラベルを 1 つの平方距離スケールに正確に対応させることです。$k^2$これにより、異なる正方形制約間の競合が防止されます。 

### なぜ効果があるのか

 同じラベルに割り当てられたすべてのインデックスが固定オフセットとペアになっているため、構築された各グループは内部的に一貫しています。$k^2$。 これにより、任意の 2 つの出現が同一のペアであるか、同じ平方距離の反復変換のいずれかであることが保証されるため、すべてのペアごとの差は完全な平方のままになります。 構造上、すべてのラベルが少なくとも 2 回出現するため、「単一出現なし」という制約が満たされます。 貪欲なブロック割り当てでは、重複のない完全なカバレッジが保証されるため、すべてのインデックスが 1 回だけ割り当てられます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve(n):
    if n == 1:
        return None

    res = [0] * n
    idx = 0
    label = 1

    k = 1
    while idx + 2 * k <= n:
        # assign block of size 2k
        for i in range(k):
            res[idx + i] = label
            res[idx + i + k] = label
        idx += 2 * k
        label += 1
        k += 1

    # remaining elements
    rem = n - idx
    if rem == 0:
        return res

    if rem % 2 == 1:
        return None

    # pair leftovers using label
    for i in range(0, rem, 2):
        res[idx + i] = label
        res[idx + i + 1] = label
        label += 1

    return res

t = int(input())
for _ in range(t):
    n = int(input())
    ans = solve(n)
    if ans is None:
        print(-1)
    else:
        print(*ans)
```コードは 2 つのフェーズで配列を構築します。 最初のループでは、サイズが徐々に大きくなる構造化ブロックが作成されます。$2k$ここで、各ブロックは単一の正方形ベースのペアリング ルールを適用します。 2 番目のフェーズでは、単純な隣接ペアリングを使用して残り物を処理します。これは、距離 1 が完全な正方形であるため有効です。 

実装の重要な詳細は、移動インデックス ポインターを維持することです。`idx`、ブロックが決して重ならないようにします。 もう 1 つの微妙な点は、残りの要素の処理です。剰余が奇数の場合、「少なくとも 2 回出現する」ルールを満たすことができないため、すぐに失敗します。

 ## 特殊なケース

 のために$n = 1$の場合、ラベルは 2 回出現できないため、アルゴリズムはすぐに失敗します。 実装では、構築が開始される前にこれを明示的にチェックし、単一オカレンスの誤った割り当てを防ぎます。 

奇数の場合$n$、最大のブロックを構築した後、残りの要素数は奇数になります。 残った要素をペアにすると必然的にシングルトンが作成され、制約に違反するため、コードはこのケースを拒否します。
