 ## 問題の理解

 特殊なカードを1枚入れたデッキで簡単な実験を繰り返し、$m-1$普通のカード。 各トライアルは、デッキを完全にランダム化し、一番上のカードを確認し、デッキの構成を変更せずにそれを元に戻すことから構成されます。 

すべてのシャッフルはすべての順列にわたって均一であるため、各試行の一番上のカードはすべてのカードの中で均一にランダムになります。$m$カード、およびさまざまなトライアルは独立しています。 ジョーカーは一回の試練で確率で出現する$p = \frac{1}{m}$したがって、確率変数は$x$は単純に成功した回数です$n$成功確率を伴う独立したベルヌーイ試行$1/m$。 

タスクは、次のような二項期待値を計算するだけではありません。$\mathbb{E}[x]$、しかし、$k$-乗モーメント$\mathbb{E}[x^k]$。 入力サイズにより、$n$そして$m$おおよそまで$10^9$、 その間$k$最大 5000 になる可能性があるため、すべての結果を拡張するメソッドはすべて$x$あるいは、試験のサブセット全体にわたって行うことは不可能です。 

素朴なアプローチでは、すべての結果を列挙しようとする可能性があります。$x$0から$n$、二項確率を計算し、合計します。$x^k \cdot P(x)$。 それはすでにコストがかかります$O(n)$、それは不可能です。 拡張しようとすると、より深い問題が表示されます$x^k$試行の指標変数の多項式として: 以上の合計が得られます。$k$-インデックスのタプル、つまり$O(n^k)$概念的にも完全に使用不可能です。 

さらに微妙な落とし穴は、二項変数のモーメントが次のような単純な式で直接表現できると仮定していることです。$(np)^k$。 それは次の場合にのみ当てはまります$k=1$、すでに失敗しています$k=2$差異の寄与によるもの。 

## アプローチ

 重要な単純化は、次の分布について考えるのをやめるということです。$x$それ自体を拡張する代わりに$x^k$試行にわたる基本的な対称構造の観点から。 

させて$I_i$ジョーカーが描かれたことを示す指標となる$i$- 回目の裁判。 それから$x = \sum_{i=1}^n I_i$、そしてすべて$I_i$確率を持つ独立したベルヌーイ変数です$p = 1/m$。 

拡大中$x^k$インジケーターの積の合計を生成します。$$x^k = \sum_{i_1,\dots,i_k} I_{i_1} I_{i_2} \cdots I_{i_k}.$$期待値は、タプル内に出現する個別のインデックスの数にのみ依存します。$(i_1,\dots,i_k)$。 まさに$r$明確なインデックスが表示されると、製品の期待値は次のようになります。$p^r$、そしてこの構造を実現するために多重度を割り当てる方法の数は、組み合わせ分割数の問題になります。 

これはまさに、第 2 種スターリング数が登場する場所です。 これらは、一連のパーティションを分割する方法の数を数えます。$k$ラベル付きの位置を$r$空ではないグループ。 各グループは 1 つの異なる試験インデックスに対応します。 選択した後$r$～からの明確な試練$n$を割り当てます。$k$これらのポジションに$r$試練。 

これにより次の ID が得られます。$$\mathbb{E}[x^k] = \sum_{r=0}^k S(k,r) \cdot (n)_r \cdot p^r,$$どこ$(n)_r = n(n-1)\cdots(n-r+1)$は下降階乗であり、$S(k,r)$は第 2 種スターリング数です。 

残りのタスクは純粋に代数的なものです。スターリング数を次まで計算します。$k=5000$、階乗のような積を事前計算し、合計を評価します。 

私たちは計算します$S(k,r)$標準的な繰り返しを使用すると、次のようになります。$$S(k,r) = S(k-1,r-1) + r \cdot S(k-1,r),$$どれが当てはまるか$O(k^2)$。 

このテーブルが作成されると、答えは単一の合計になります。$r$、累乗モジュラーは次の累乗によって暗黙的に処理されます。$n$との逆べき乗$m$。

 ## アルゴリズムのチュートリアル

 1. 通訳する$x$独立したベルヌーイ変数の合計として$I_i$。 この再定式化により、置換について確率論的にではなく代数的に推論できるようになります。 
2. モジュラー逆関数を事前計算します。$m$、ジョーカーの出現はすべて要因に寄与するため、$1/m$。 素数体を法として扱うには、除算を乗算の逆数に置き換える必要があります。 
3. スターリング数の DP テーブルを構築する$S(k,r)$まで$k$。 繰り返しでは、最後の要素が新しいグループを形成するか、既存の要素に結合するかに応じてパーティションが分割されます。 
4. 事前計算能力$n$および下降階乗項$(n)_r$。 下降階乗は次のように反復的に計算されます。$cur *= (n - r + 1)$これにより、製品を最初から再計算する必要がなくなります。 
5. それぞれについて$r$、貢献度を蓄積します。$$S(k,r) \cdot (n)_r \cdot m^{-r}.$$各用語は選択に対応します$r$個別のトライアルと割り当て$k$それらの間で発生する確率には、独立した成功による寄与が含まれます。 
6. すべての寄与を法的に合計する$998244353$。 

### なぜ効果があるのか

 の展開におけるすべての単項式$x^k$の選択に対応します$k$繰り返しを伴うトライアルインデックス。 同一のインデックスをグループ化すると、選択範囲が分割されます。$r$独特の試練。 スターリング数はこれらの分割を正確にカウントしますが、下降階乗は実際の試行の選択をカウントします。 独立性により、各グループが要因に貢献することが保証されます$1/m$, したがって、確率係数は次のようになります。$m^{-r}$。 個別のインデックスによるパーティション化はすべてのインデックス タプルの完全な分類であるため、用語の欠落や二重カウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

n, m, k = map(int, input().split())

# Stirling numbers S(k, r)
S = [[0] * (k + 1) for _ in range(k + 1)]
S[0][0] = 1

for i in range(1, k + 1):
    for j in range(1, i + 1):
        S[i][j] = (S[i - 1][j - 1] + j * S[i - 1][j]) % MOD

inv_m = modinv(m)

# falling factorial (n)_r
fall = 1

ans = 0

for r in range(0, k + 1):
    if r > n:
        break
    if r == 0:
        term = S[k][0]
    else:
        fall = fall * (n - r + 1) % MOD
        term = S[k][r] * fall % MOD * pow(inv_m, r, MOD) % MOD
    ans = (ans + term) % MOD

print(ans)
```実装は分解の後に直接続きます。 Stirling DP は、同一の試験インデックスをグループ化する組み合わせ論をエンコードします。 下降階乗は、反復せずに個別の試行を選択する方法が何通りあるかを追跡します。 モジュラーの逆$m$ジョーカーの出現が成功するたびに、乗算確率係数に変換します。 

微妙な点は、下降階乗が段階的に更新されることです。 それぞれを最初から再計算する$r$不必要なものを導入することになる$O(k)$要素。 もう 1 つの重要な点は、次の権限です。$1/m$項ごとの高速べき乗によって計算されます。これは、次の時点で許容されます。$k \le 5000$ですが、必要に応じて走力を維持することで最適化することもできます。

 ## 特殊なケース

 微妙なケースとしては、$m=1$。 すべての引き分けは常にジョーカーなので、$x=n$決定論的に。 式は次のようになります。$\sum_r S(k,r)(n)_r$、まさにその通りです$n^k$、決定的な値と一致します。 

もう一つのケースは、$k=0$、パラメータに関係なく、答えは 1 でなければなりません。 スターリング公式は自然に次のものだけを生成します。$r=0$期間は 1 に等しいため、$x^0 = 1$いつも。 

いつ$n < k$、より上位の下降階乗項は自動的に消滅します。$(n)_r = 0$のために$r>n$。 これにより、無効な過剰カウントが防止され、特別なケースを使用しなくても正確さが保証されます。
