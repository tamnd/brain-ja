 ## 解決策
 ## 問題の理解

 いくつかの独立した実験が与えられました。 各実験には参照整数があります$D$特定の猫の DNA を表すものと、整数で表される他の猫のリスト$a_i$。 各整数は遺伝的特性をビットとしてエンコードします。 

少なくとも 1 つのビット位置が存在する場合、猫は参照猫に関連していると見なされます。$a_i$そして$D$ビット単位の用語では、これは 2 つの数値のビット単位の AND が 0 以外であることを意味します。 タスクは、各テスト ケースでこの条件を満たす値の数を単純に数えることです。 

各テスト ケースには最大で次のものを含めることができます。$2 \cdot 10^5$数値、およびすべてのテスト ケースにわたって、$10^6$。 これにより、二次関数は即座に除外されます。$n$なぜなら、テスト ケースごとの線形スキャンでさえ、すでに唯一の実行可能な構造だからです。 要素ごとに実行する操作は定数時間である必要があります。 

微妙なエッジケースが現れるのは、$a_i = 0$。 以来$0 \& D = 0$、そのような要素は、$D$。 別のエッジケースが発生するのは次の場合です。$D = 0$。 その場合、どの番号もセットビットを共有することはできません。$D$したがって、たとえすべてが揃っていたとしても、答えは常にゼロになります。$a_i$はゼロではありません。 すべての正の数が自動的にビットを共有すると仮定すると、これらのケースは誤って処理されやすくなります。 

## アプローチ

 最も直接的なアプローチは、すべての猫を個別に検査することです。 それぞれについて$a_i$、計算する$a_i \& D$結果がゼロ以外の場合はカウンターをインクリメントします。 関連性の定義がまさにその条件であるため、これは正しいです。 

このアプローチのコストは、すべてのテスト ケースにわたる整数の合計数に比例します。 各ビット単位の AND は 32 ビットまたは 64 ビット整数の定数時間であるため、合計の複雑さは次のようになります。$O(\sum n)$、最大でも$10^6$。 これは、高速入力で実装された場合、Python で 1 秒の制限内で快適に高速です。 

各要素は独立しているため、利用できるより深い構造はありません。 条件は固定ビットマスクに依存するため、値を前処理またはグループ化しようとしても、作業がさらに削減されることはありません。$D$各値に個別に適用されます。 重要な認識は、問題がすでに最小限であるということです。つまり、ビット条件に対するストリーミング フィルターです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (要素ごとの AND チェック) | テスト ケースあたり O(n) | O(1) おまけ | 承認済み |
 | 最適 (同じ考え方、高速 I/O) | O(合計 n) | O(1) おまけ | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。 それぞれの場合の目標は、少なくとも 1 つのセット ビットを共有する値の数を数えることです。$D$。 

1.読む$n$そして$D$テストケース用。 これは、比較する固定ビットマスクを定義します。 
2. カウンタをゼロに初期化します。 これにより、条件を満たすすべての猫が蓄積されます。 
3. 各値を反復処理します。$a_i$リストにあります。 
4. コンピューティング$a_i \& D$。 結果がゼロでない場合は、カウンターをインクリメントします。 このチェックでは、2 つのビットマスクが交差するかどうかを直接エンコードします。 
5. すべての値を処理した後、カウンターを出力します。 

ある要素の結果を別の要素から推測する方法がないため、各ステップが必要です。 条件は各ペアに対して純粋にローカルです$(a_i, D)$。 

### なぜ効果があるのか

 正確さは、ビットごとの AND が共有設定ビットを分離するという事実に基づいています。 2 つの数値が少なくとも 1 つのビット位置を共有し、両方とも 1 を持つ場合、それらの AND はゼロ以外でなければなりません。 逆に、AND が 0 の場合、ビット位置は共有されず、問題の定義ではそれらが無関係であることを意味します。 すべての要素を正確に 1 回テストし、条件が必要かつ十分であるため、最終的なカウントは正確になります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, D = map(int, input().split())
        arr = list(map(int, input().split()))
        
        ans = 0
        for x in arr:
            if x & D:
                ans += 1
        
        print(ans)

if __name__ == "__main__":
    solve()
```このソリューションは、テスト ケースに対する単純なストリーミング ループとして構造化されています。 高速入力経由`sys.stdin.readline`整数の合計数は 100 万に達する可能性があるため、これは必須です。 表現`x & D`はコア操作です。 追加の計算を行わずに関係条件を直接エンコードします。 

現在のテスト ケースを超える追加の前処理やストレージは必要ないため、入力サイズに対してメモリ使用量が一定に保たれます。

## 特殊なケース

 重要なエッジケースの 1 つは次のような場合です。$D = 0$。 入力の場合:```
1
4 0
1 2 3 4
```アルゴリズムは計算します$x \& 0 = 0$あらゆる要素に対して。 ループは引き続きすべての要素に対して実行されますが、カウンターは増加しません。 出力は 0 で、ビットの重複はありえないため、定義と一致します。 

もう 1 つの特殊なケースは、すべてが$a_i = 0$:```

```各反復で評価されるのは、`0 & 5 = 0`したがって、カウンターは全体を通してゼロのままです。 アルゴリズムは、特別なケースを使用せずにこれを自然に処理します。 

最後の微妙なケースは次のような場合です。$D$たとえば、ビットが 1 つだけ設定されています$D = 1$。 奇数のみを数える必要があります。```
1
5 1
2 3 4 5 6
```最下位ビットが設定されているのは 3 と 5 のみであるため、アルゴリズムは 3 と 5 のみを正しくカウントします。
