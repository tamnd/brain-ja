 ## 解決策
 ## 問題の理解

 いくつかの有向グラフが与えられ、それぞれがノードと有向エッジによって記述されます。 あるノードから別のノードへの有向エッジは、その方向にのみ移動できることを意味します。 

各テスト ケースのタスクは、追加する必要がある追加の有向エッジの最小数を決定し、それらを追加した後、すべてのノードが有向エッジをたどることで他のすべてのノードに到達できるようにすることです。 グラフの観点から言えば、グラフが強く結びつくことを望みます。 

重要な考え方は、ここでは到達可能性が対称的ではないということです。 A から B へのパスが存在する場合でも、B から A へ戻るパスを意味するものではありません。目標は、追加するエッジの数を最小限に抑えてこの非対称性を修復することです。 

制約は大きく、すべてのテスト ケースにわたるノードとエッジの合計数は 100 万に達する可能性があります。 これにより、すべてのノードのペア間の到達可能性を直接チェックしようとするアプローチは除外されます。これは、単一のフロイド・ウォーシャル スタイルのアイデアでもすぐに制限を超えるためです。 すべてのノードから BFS/DFS を繰り返すと、最悪の場合 O(n(n + m)) になるため、遅すぎます。 

グラフがすでに強く接続されている場合、より微妙なエッジ ケースが表示されます。 その状況ではエッジは必要なく、答えはゼロでなければなりません。 もう 1 つの注意が必要な状況は、グラフがほぼ接続されているものの、チェーンを形成するコンポーネントに分割されている場合です。 単純なアプローチでは、エッジの最小数を実際に制御する構造を認識せずに、「コンポーネントを貪欲に接続」しようとする可能性があります。 

## アプローチ

 強引なアイデアは、グラフが強く接続されているかどうかを繰り返しチェックし、そうでない場合は、すべてのノードのペアの間にエッジを追加して再度テストすることです。 各接続性チェックには O(n + m) のコストがかかり、考慮すべきエッジは O(n²) 個あるため、これは完全に不可能です。 

重要な構造的洞察は、有向グラフの内部では、ノードが自然に強く接続されたコンポーネントを形成するということです。 このような各コンポーネント内では、すべてのノードが他のすべてのノードに到達できます。 各コンポーネントを 1 つのノードに圧縮すると、結果として得られる構造は有向非巡回グラフになります。 

グラフがこのコンポーネント グラフに縮小されると、元の問題ははるかに単純になります。個別のノードを扱うのではなく、原子単位のように動作する SCC を扱うようになります。 グラフ全体を強く接続する唯一の方法は、このコンポーネント グラフを確実にサイクルにすることです。これには、ソースとシンクを慎重に接続する必要があります。 

最後の観察は、2 種類のコンポーネントのみが重要であるということです。凝縮グラフに入力エッジがないコンポーネントと、出力エッジがないコンポーネントです。 追加された各エッジは 1 つのソースと 1 つのシンクの関係を同時に修正できるため、必要なエッジの最小数はこれらがいくつ存在するかによって決まります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | n の指数 | O(n + m) | 遅すぎる |
 | SCC 圧縮 + 次数カウント | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 各テストケースを個別に処理します。

1. まず、有向グラフの強連結成分をすべて計算します。 これにより、グループ内のすべてのノードが同じグループ内の他のすべてのノードに到達できるようにノードがグループ化されます。 コンポーネントの内部構造は答えに影響を与えないため、このステップが必要です。 
2. SCC を効率的に見つけるために、2 パス DFS アプローチ (Kosaraju のアルゴリズム) を実行します。 最初のパスでは、グラフを走査し、完了した順にノードを記録します。 この順序により、コンポーネント間の依存関係が把握されます。 
3. 次に、グラフ内のすべてのエッジを反転し、終了時間の降順にノードを処理します。 この 2 番目のパスの各 DFS トラバーサルでは、強く接続されたコンポーネントが 1 つだけ検出されます。 
4. すべてのノードにコンポーネント ID を割り当てた後、各コンポーネントを新しい圧縮グラフ内の単一のノードとして扱います。 
5. すべての元のエッジを反復処理します。 u から v までのすべてのエッジについて、u と v が異なるコンポーネントに属している場合、対応するコンポーネント間に有向エッジを追加します。 
6. 各コンポーネントについて、2 つの値を計算します。つまり、凝縮グラフに入るエッジの数と、そのコンポーネントから出るエッジの数です。 
7. 入力エッジがゼロのコンポーネントの数と、出力エッジがゼロのコンポーネントの数を数えます。 
8. コンポーネントが合計 1 つだけの場合、グラフはすでに強く結合されており、答えはゼロになります。 それ以外の場合、答えはソース コンポーネントとシンク コンポーネントの最大数になります。 

### なぜ効果があるのか

 凝縮グラフは常に有向非巡回グラフです。 このような構造では、強く接続された最終グラフは、新しい接続を導入してすべてのソースとシンクを削除する必要があります。 追加された各エッジは、最大 1 つの SCC テールを 1 つの SCC ヘッドに接続するため、ソースまたはシンクの数を最大 1 つの有効単位だけ減らすことができます。 したがって、2 つのカウントの最大値は、回避できないボトルネックを表します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        g = [[] for _ in range(n)]
        rg = [[] for _ in range(n)]

        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            rg[v].append(u)

        visited = [False] * n
        order = []

        sys.setrecursionlimit(10**7)

        def dfs1(u):
            stack = [(u, 0)]
            visited[u] = True
            while stack:
                node, i = stack[-1]
                if i < len(g[node]):
                    nxt = g[node][i]
                    stack[-1] = (node, i + 1)
                    if not visited[nxt]:
                        visited[nxt] = True
                        stack.append((nxt, 0))
                else:
                    order.append(node)
                    stack.pop()

        for i in range(n):
            if not visited[i]:
                dfs1(i)

        comp = [-1] * n
        cid = 0

        def dfs2(u):
            stack = [u]
            comp[u] = cid
            while stack:
                node = stack.pop()
                for nxt in rg[node]:
                    if comp[nxt] == -1:
                        comp[nxt] = cid
                        stack.append(nxt)

        for v in reversed(order):
            if comp[v] == -1:
                dfs2(v)
                cid += 1

        if cid == 1:
            print(0)
            continue

        indeg = [0] * cid
        outdeg = [0] * cid

        for u in range(n):
            for v in g[u]:
                if comp[u] != comp[v]:
                    outdeg[comp[u]] += 1
                    indeg[comp[v]] += 1

        sources = sum(1 for i in range(cid) if indeg[i] == 0)
        sinks = sum(1 for i in range(cid) if outdeg[i] == 0)

        print(max(sources, sinks))

if __name__ == "__main__":
    solve()
```解決策は、グラフとその逆の両方を構築することから始まります。 この二重構造は、コサラジュのアルゴリズムが強く接続されたコンポーネントを正しく識別するために必要です。 

最初の DFS は、明示的なスタックを使用することにより、再帰スタック深さの問題を発生させることなく、終了順に頂点を収集します。 2 番目の DFS は、反転したグラフを使用してコンポーネント ID を割り当てます。 コンポーネントが割り当てられると、凝縮グラフは隣接リストとして明示的に構築されません。 代わりに、元のエッジをスキャンしながら、入次数と出次数のカウントを直接計算します。 

単一コンポーネントの最後の条件チェックでは、すでに強く関連しているケースが処理されます。そうでないと、誤って正のカウントが生成されてしまいます。 

## 実用的な例

 ### 例 1

 入力グラフには、3 つのノードと 4 番目のノードへの追加の接続の間でサイクルを形成するエッジがあり、複数の SCC が作成されます。 

| ステップ | アクション | コンポーネント | 情報源 | シンク |
 | --- | --- | --- | --- | --- |
 | 1 | SCC を構築する | {サイクル}、{ノード4} | 1 | 1 |
 | 2 | 凝縮エッジを構築する | SCC 間の 1 エッジ | | |
 | 3 | カウント indeg/outdeg | SCC0 角度 0、SCC1 出力角度 0 | 1 | 1 |
 | 4 | 答えを計算する | 最大(1,1) = 1 | | |

 これは、2 つの SCC を強固に接続された構造に接続するには 1 つのエッジで十分であることを示しています。 

### 例 2

 グラフはすでにすべてのノードにわたって単一のサイクルを形成しています。 

| ステップ | アクション | コンポーネント | 情報源 | シンク |
 | --- | --- | --- | --- | --- |
 | 1 | SCC 分解 | 1 コンポーネント | 0 | 0 |
 | 2 | 早期終了 | cid = 1 | - | - |
 | 3 | 出力 | 0 | | |

 これにより、グラフがすでに強く接続されている場合に、アルゴリズムが不必要なエッジの追加を正しく回避していることが確認されます。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n + m) | 各ノードとエッジは、SCC 構築と次数カウントにわたって一定回数処理されます。 
| スペース | O(n + m) | 隣接リスト、逆グラフ、コンポーネント配列 |

 ## 特殊なケース

 完全強接続グラフは成分数が 1 個の場合は早期終了で扱われます。 その状況では、入次数および出力次数のロジックは必要なく、アルゴリズムは正しくゼロを出力します。 

エッジのないノードなど、完全に切断されたグラフでは、ノードごとに 1 つの SCC が生成されます。 凝縮グラフでは、すべてのノードがソースとシンクの両方になります。 このアルゴリズムはソースとシンクの数を同数カウントし、すべてのコンポーネントを単一の強く接続された構造に接続するために必要なエッジの数を正確に最大値で示します。 

ノードの線形チェーンは、凝縮グラフ ロジックが 1 つのソースと 1 つのシンクを正確に識別するかどうかをテストします。 このアルゴリズムは、チェーンの開始時に単一のソース SCC を生成し、最後に単一のシンク SCC を生成します。これは、単一のエッジでサイクルを終了できるという事実と一致し、答えは 1 になります。
