 ## 問題の理解

 花の種類のいくつかのコレクションが与えられます。各コレクション (花束と呼ばれます) は基本的に、最大 60 サイズのユニバースから抽出された許可された花のラベルのセットです。各テスト ケースに対して、オサマは 1 つの花束を正確に選択し、長さの庭園を構築します。$m$。 庭の各位置は、選択した花束から任意の花の種類を選ぶことで独立して埋められ、繰り返しが許可されています。 

したがって、花束に含まれている場合は、$k$異なる花の種類であれば、その花束を正確に生成できます$k^m$それぞれ異なる庭園があるため、$m$位置は次のいずれかになります$k$独立してタイプします。 

複雑なのは、すべての花束にわたって個別の庭園の数を求められることです。つまり、2 つの異なる花束が同じシーケンスを生成できる場合、そのシーケンスは 1 回だけカウントする必要があります。 これは、ブーケのタイプセットが重なっている場合に自然に発生します。 

制約によってソリューションの構造が決まります。 花束の数は最大でも 19 であり、これはすぐに次のような指数関数的な依存関係を示唆しています。$n$、 のような$2^n$、許容されます。 値$m$と同じ大きさにすることができます$10^9$したがって、庭の位置を反復するアプローチは不可能です。 ただし、それぞれの花束は形式の項に寄与するため、$|S|^m$、長さにわたる反復ではなく、高速なべき乗のみが必要です。 

最も重要な構造上の観察は、花の種類の世界のサイズが 60 のみであるため、各花束は 60 要素にわたるビットマスクとして表現できるということです。 これにより、交差点の操作が迅速かつ正確になります。 

微妙なエッジ ケースは、花束の異なるサブセットが同一の交差セットを生成する場合です。 たとえば、花束 A と花束 B が同じである場合、どちらも同じ貢献をします。$k^m$、単純な合計では二重にカウントされてしまいます。 もう 1 つの問題は、ブーケのサブセットに対して包含-除外を使用する必要があり、そうしないと重複を修正できないことです。 

素朴な考えによる小さな具体的な失敗例は次のとおりです。 

花束1の場合$\{1,2\}$そして花束2は$\{2,1\}$、 そして$m=2$、その後、両方とも同じシーケンスのセットを生成し、単純に追加します$2^2 + 2^2$数えすぎてしまうだろう。 正しい答えは、$4$、 ない$8$。 

## アプローチ

 強引なアイデアは、各花束を独立して扱い、すべてを列挙することです。$k^m$シーケンスを概念的に抽出し、ブーケ全体で重複排除を試みます。 次の場合、すべてのシーケンスを保存したり反復したりすることさえ不可能であるため、これはすぐに失敗します。$m$大きいです。 ブーケあたりのシーケンスの数は指数関数的に増加します。$m$したがって、明示的な構築は実行不可能です。 

重要な構造的洞察は、各ブーケがセットの完全なデカルト累乗を定義するということです。 これらの力の結合は、花束に対する包含と除外を使用して処理できます。 花束の任意のサブセットについて、それらの交差は、サブセット内のすべての花束に共通する花の種類のみを使用して形成できるシーケンスに対応します。 その交差点にサイズがある場合$x$、その場合、それは正確に貢献します$x^m$シーケンス。 

すべての空でないサブセットに対して包含-除外を使用すると、すべてのシーケンスが正確に 1 回カウントされることが保証されます。これは、すべての有効なシーケンスには、使用されているすべての花の種類を含む明確に定義された一連の花束があり、包含-除外により、その原因となっている最大交差が分離されるためです。 

以来$n \le 19$、すべてを反復します$2^n$サブセットは実現可能です。 各サブセットでは、マスクの交差を計算し、高速なべき乗剰余を評価する必要があります。

 ## アルゴリズムのチュートリアル

 1. 各花束を 60 ビット マスクとして表します。 各ビットは、その花束に花の種類が存在するかどうかを示します。 これにより、定数時間であるビットごとの AND を使用して交差を計算できるようになります。 
2. ビットマスクを使用して、ブーケの空でないすべてのサブセットを反復処理します。$1$に$(1 \ll n) - 1$。 各サブセットは、交差部分を分析する花束のグループを表します。 
3. サブセットごとに、サブセット内のすべてのブーケの AND 演算により交差マスクを計算します。 このマスクのサイズは、サブセット内のすべての花束に共通する花の種類の数です。 これは、これらすべてのブーケに対して同時に有効なシーケンス内に出現できる唯一のタイプのセットです。 
4. コンピューティング$x^m \bmod (10^9+7)$、 どこ$x$交差マスクのサイズです。 これは、まさにこれらの一般的なタイプを使用して形成できるシーケンスの数を表します。 
5. 包含/除外を適用します。サブセット サイズが奇数の場合は、この値を答えに加算し、そうでない場合は減算します。 この交互配置により、異なる花束グループ間の重複によって引き起こされる過剰カウントが修正されます。 
6. 最終累算結果のモジュロを返します。$10^9+7$。 

### なぜ効果があるのか

 有効な庭園はどれも長さがあります。$m$いくつかの花の種類のセットにわたるシーケンス。 そのセットは少なくとも 1 つの花束に含まれている必要がありますが、複数の花束に含まれていても構いません。 花束のサブセットに対する包含/除外により、選択したすべての花の種類を含む花束の最大のサブセットとして各シーケンスが 1 回カウントされることが保証されます。 交差サイズによって各サブセット内のシーケンスに使用できるアルファベットが一意に決定されるため、寄与度は$x^m$そのサブセットによってサポートされるすべてのシーケンスを正確にカウントし、交互の符号により、より大きな重複するサブセットからの過剰カウントが除去されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def modpow(a, e):
    res = 1
    a %= MOD
    while e > 0:
        if e & 1:
            res = res * a % MOD
        a = a * a % MOD
        e >>= 1
    return res

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        masks = []
        for _ in range(n):
            arr = list(map(int, input().split()))
            k = arr[0]
            vals = arr[1:]
            mask = 0
            for v in vals:
                mask |= 1 << (v - 1)
            masks.append(mask)

        ans = 0

        for s in range(1, 1 << n):
            inter = (1 << 60) - 1
            for i in range(n):
                if s >> i & 1:
                    inter &= masks[i]
                    if inter == 0:
                        break

            if inter == 0:
                continue

            cnt = inter.bit_count()
            val = modpow(cnt, m)

            if bin(s).count("1") % 2 == 1:
                ans = (ans + val) % MOD
            else:
                ans = (ans - val) % MOD

        print(ans % MOD)

if __name__ == "__main__":
    solve()
```実装はサブセット列挙に直接続きます。 各ブーケはビットマスクに圧縮されるため、交差は 1 つの AND 演算に減ります。 交差はすべての 60 ビット セットから開始され、一部のブーケがまばらな場合でも正確性が保証されます。 

累乗は 2 進累乗で処理されます。$m$と同じ大きさにすることができます$10^9$。 サブセット パリティによって、寄与が加算されるか減算されるかが決まり、必要に応じて包含と除外が正確に実装されます。 

細かいことですが重要な点は、交差点がゼロになったときに早期に停止することです。 共通の花の種類がなくなると、そのサブセットは何も寄与せず、それ以降の処理はスキップされます。

 ## 特殊なケース

 すべての花束が同一である場合、サブセットの寄与が重複することが強調されます。 すべての花束がどこにあるかを入力するため`{1,2,3}`そして$m=5$、すべてのサブセットは同じ交差サイズ 3 を持ちます。包含と除外の合計は次のようになります。$(1 - (n choose 1) + (n choose 2) - \dots) \cdot 3^5$、正確に評価されます$3^5$、重複が正しく折りたたまれることを確認します。 

空の交差部分があるケースは、花束に共通の要素がない場合に発生します。 例えば`{1}`、`{2}`、`{3}`どれでも$m$。 サイズが 2 以上のすべてのサブセットには交差ゼロがあり、何も寄与せず、シングルトンだけが残るため、結果は次のようになります。$1^m + 1^m + 1^m = 3$これは、各ブーケが 1 つの定数シーケンスのみを生成するという事実と一致します。 

より大きなオーバーラップ構造、たとえば、`{1,2}`、`{2,3}`、`{1,3}`、ペアごとのオーバーラップがトリプル交差によって修正されることをチェックします。 このアルゴリズムは、シングルトン要素 2、1、および 3 に重複することなく正しい重みを割り当てます。これは、それぞれが特定のサブセット ファミリの共通部分として現れるためです。
