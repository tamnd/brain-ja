 ## 解決策
 ## 問題の理解

 まさに`N`開き括弧と`N`閉じ括弧なので、すべての有効な答えは、長さの通常の括弧のシーケンスになります。`2N`。 このようなすべてのシーケンスのうち、ある長さの文字列を取得しても取得できないものだけをカウントする必要があります。`N`そして2回連続で書きます。 

文字列が呼び出されます`N`-前半と後半が同じ場合は定期的。 たとえば、`N = 2`、文字列`)()(`最初の 2 文字が周期的であるため、`)(`が繰り返される一方で、`)(()`そうではありません。 

タスクはシーケンスを構築することではありません。 必要なのはカウントモジュロだけです`10^9 + 7`。 

制約`N <= 1000`テストケースの数は最大でも`1000`それを教えてください`O(N)`または`O(N log N)`前処理アプローチで十分です。 通常の括弧シーケンスの数はカタルーニャ数であり、指数関数的に増加するため、括弧シーケンスを生成する解決策は不可能です。 適度に小さい場合でも`N`、列挙が大きくなりすぎます。 

主なエッジケースは、繰り返される部分の長さと括弧のペアの数を混同することから発生します。 のために`N = 1`、唯一の正規の括弧シーケンスは、`()`。 空でない 2 つの等しい半分に分割することはできないため、答えは次のようになります。`1`。 常に 1 つの周期シーケンスを減算する不注意な解決策では、誤った出力が発生します。`0`。 

もう 1 つの重要なケースは次のような場合です。`N`奇数です。 たとえば、入力の場合`N = 3`、通常の括弧シーケンスの総数は次のとおりです。`5`。 周期的なシーケンスには前半の長さが必要です`3`これには、同数の開き括弧と閉じ括弧が含まれます。 奇数の長さの文字列では両方の括弧の数を同じにすることはできないため、これは不可能です。 正しい答えは、`5`、あらゆることを想定した不用意なアプローチ`N`より小さなカタロニア語の減算が作成されるのは間違いです。 

最後の境界ケースは次のような場合です。`N`は均等です。 のために`N = 4`、規則的なシーケンスは次のようにカウントされます。`Catalan(4) = 14`。 周期的なものは、正確に、一定の長さの規則的なシーケンスを繰り返すことによって形成されるシーケンスです。`4`、与える`Catalan(2) = 2`無効なシーケンス。 答えは`12`。 繰り返される半分自体のバランスが取れている必要があることを忘れると、減算される文字列が多すぎます。 

## アプローチ

 直接的なアプローチは、すべての通常の括弧シーケンスを生成することです。`N`ペアを作成し、それが周期的であるかどうかを確認し、そうでないものを数えます。 これは、必要なセットを正確に検査するため、正しいです。 ただし、通常のブラケットシーケンスの数は`Catalan(N)`、これはほぼ指数関数的です。 のために`N = 1000`、回答空間を表すことさえ不可能なので、総当たりは機能しません。 

有益な観察は、周期的な規則的な括弧シーケンスがどのようなものであるかを調べることから得られます。 有効なシーケンスがあると仮定します`S`長さがある`2N`そしてそれは`N`-定期的。 すると、次のような形になります`T + T`、 どこ`T`長さがある`N`。 

シーケンス全体のバランスが取れているため、ブラケットの合計バランスは`T + T`ゼロでなければなりません。 したがって、最初のコピーの残高はある程度の価値があります`x`、2番目のコピーは別のコピーを提供します`x`、与える`2x = 0`。 したがって、`x = 0`これは、前半に同じ数の左括弧と右括弧がすでに含まれていることを意味します。 

次に、妥当性について考えてみましょう。 シーケンス全体のすべてのプレフィックスには、少なくとも閉じ括弧と同じ数の開き括弧が必要です。 最初のコピー`T`は完全な文字列の接頭辞であるため、その中のすべての接頭辞は`T`有効である必要があります。 以来`T`バランスゼロもありますが、`T`それ自体は通常の括弧シーケンスです。 

これにより、1 対 1 の関係が得られます。 毎`N`-periodic の通常の括弧シーケンスは、一定の長さの通常の括弧シーケンスに対応します。`N`、そしてそのようなシーケンスは次の場合にのみ存在します。`N`は均等です。 もし`N = 2k`、周期シーケンスの数は`Catalan(k)`。 

通常の括弧シーケンスの総数`N`ペアは`Catalan(N)`したがって、最終的な答えは次のようになります。`Catalan(N) - Catalan(N / 2)`いつ`N`は均等です。`Catalan(N)`いつ`N`奇数です。

 ## アルゴリズムのチュートリアル

 1. 階乗および逆階乗を最大で事前計算します。`1000`。 カタロニア語の数値は、次の組み合わせ式を使用して計算できます。`Catalan(n) = C(2n, n) - C(2n, n + 1)`これは以下と同等です:`Catalan(n) = (2n choose n) / (n + 1)`。 

これらの値を事前に計算すると、すべてのクエリに即座に答えることができます。 
2. 値を持つクエリごとに`N`、通常の括弧シーケンスの合計数から始めます。`Catalan(N)`。 

これにより、周期的なシーケンスを削除する前に、考えられるすべての有効なシーケンスがカウントされます。 
3. もし`N`偶数なので引きます`Catalan(N / 2)`。 

削除されるシーケンスは、前半自体が通常のブラケット シーケンスであるシーケンスだけです。 
4. もし`N`は奇数なので、何も減算しないでください。 

奇数の長さの半分には、同じ数の左括弧と右括弧を含めることはできないため、周期的な規則的なシーケンスは存在しません。 
5. 結果のモジュロ値を出力します。`10^9 + 7`。 

なぜ効果があるのか:

 解決策の背後にある不変条件は、すべての無効なシーケンスが固有の前半部分を持つということです。 周期的としてカウントされるシーケンスは、その半分の 2 つの同一のコピーである必要があります。 完全な文字列が正規であるためには、半分の残高がゼロであり、そのすべてのプレフィックスが有効である必要があります。 これらはまさに、半分が通常の括弧シーケンスになるための条件です。 したがって、周期シーケンスは小さい方のカタロニア数で正確にカウントされ、それらを減算することで不要なシーケンスのみが削除されます。 

## Python ソリューション```python
import sys

input = sys.stdin.readline

MOD = 10**9 + 7

MAX_N = 1000

fact = [1] * (2 * MAX_N + 5)
for i in range(1, len(fact)):
    fact[i] = fact[i - 1] * i % MOD

inv_fact = [1] * (2 * MAX_N + 5)
inv_fact[-1] = pow(fact[-1], MOD - 2, MOD)
for i in range(len(inv_fact) - 1, 0, -1):
    inv_fact[i - 1] = inv_fact[i] * i % MOD

def comb(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD

catalan = [0] * (MAX_N + 1)
for i in range(MAX_N + 1):
    catalan[i] = (comb(2 * i, i) - comb(2 * i, i + 1)) % MOD

def solve():
    t = int(input())
    ans = []
    for _ in range(t):
        n = int(input())
        cur = catalan[n]
        if n % 2 == 0:
            cur -= catalan[n // 2]
        ans.append(str(cur % MOD))
    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```前処理部分は階乗と逆階乗を構築するため、モジュロに基づいて組み合わせを一定時間で計算できます。 必要な最大のカタルーニャ語インデックスは次のとおりです。`1000`、しかし計算上`Catalan(1000)`必要`C(2000, 1000)`、階乗は次まで保存されます。`2000`。 

クエリ処理は数学的結果に直接従います。 まず、通常の括弧シーケンスの合計数を取得します。 いつ`N`が偶数の場合、繰り返される半分はカタロニア数で数えられます。`N / 2`ペアになり、削除されます。 

モジュロ減算は最後に次のように処理されます。`% MOD`周期シーケンスを削除すると中間値が負になる可能性があるためです。 

## 実用的な例

 のために`N = 2`、計算は次のようになります。 

| ステップ | N | カタルーニャ語合計 | 定期的なカウント | 答え |

 | 定期的な | を削除します。 2 | 2 | カタロニア語(1)=1 | 1 |

 2 つの規則的なシーケンスは次のとおりです。`(())`そして`()()`。 2 番目は次の繰り返し形式です。`()`, したがって、シーケンスは 1 つだけ残ります。 

のために`N = 4`、計算は次のようになります。 

| ステップ | N | カタルーニャ語合計 | 定期的なカウント | 答え |
 | --- | --- | --- | --- | --- |

 削除された 2 つのシーケンスは、2 つの括弧のペアを持つ 2 つの通常のシーケンスを取得し、それらを 2 回繰り返すことによって作成されます。 他のすべての有効なシーケンスは非周期的です。

 ## 特殊なケース

 のために`N = 1`、アルゴリズムは次のように計算します。`Catalan(1) = 1`。 以来`N`は奇数です。何も減算しません。 結果は`1`、唯一のシーケンスと一致する`()`。 

のために`N = 3`、有効なシーケンスの総数は次のとおりです。`Catalan(3) = 5`。 アルゴリズムはパリティをチェックし、次のことを確認します。`3`は奇数であるため、カウントは変更されません。 これは、長さ 3 の有効な前半が存在できない場合を処理します。 

のために`N = 4`、アルゴリズムは次から始まります`Catalan(4) = 14`。 長さが偶数なので引きます`Catalan(2) = 2`。 これら 2 つのシーケンスは、繰り返される可能性のあるすべての半分を表します。`12`非周期的な規則的な括弧シーケンス。 

次のような非常に大きな許容値の場合、`N = 1000`、アルゴリズム自体がシーケンスを構築することはありません。 事前に計算された組み合わせ値のみを使用するため、括弧文字列の実際の数が指数関数的に増加することを回避します。
