 ## 問題の理解

 長さの配列を扱っています$N$ですが、配列の値自体は無関係です。 重要なのは、1 から 1 までのインデックス行だけです。$N$。 この行では、次のようになります。$M$特別なセグメント$[l_i, r_i]$。 これらのセグメントは、サブ配列を「不良」にするものに関する制約を表します。 

サブアレイ$[a, b]$指定されたセグメントの少なくとも 1 つが完全に含まれている場合、つまり一定の間隔が存在する場合、不良とみなされます。$[l_i, r_i]$そのような$a \le l_i$そして$r_i \le b$。 優れたサブ配列とは、単に指定されたすべてのセグメントについてこの状態を回避するものです。 

したがって、タスクはペアの数を数えることです$(a, b)$と$1 \le a \le b \le N$禁止されたセグメントを完全にカバーしていない。 

制約$N \le 10^9$すべてのサブ配列、さらにはすべてのエンドポイントを直接反復するアプローチは直ちに除外されます。 部分配列の数は$\Theta(N^2)$、これは天文学的に大きいため、私たちは完全にその構造に依存する必要があります。$M$間隔。 重要な観察は、複雑さは次のものに依存する必要があるということです。$M$、オンではありません$N$、ただし、次の場合を除きます。$N$最終的な算術式に現れます。 

素朴なアプローチでは、すべてのサブ配列をチェックし、禁止されたセグメントが含まれているかどうかをテストします。 単一のサブ配列をチェックする場合でも、$O(M)$、合計は次のようになります$O(N^2 M)$、それは完全に不可能です。 

もう少し賢い単純なアプローチは、サブ配列を修正することです。$[a, b]$データ構造を維持して、内部に区間があるかどうかをテストします。 これにはまだすべてを反復する必要があります$\Theta(N^2)$ペアなので、すぐに失敗します。 

エンドポイントのみをチェックしようとすると、より微妙な障害モードが表示されます。$l_i, r_i$そしてローカルで理由づけします。 たとえば、境界が一部の配列と一致するサブ配列のみが存在すると誤って仮定する可能性があります。$l_i$または$r_i$これは重要ですが、これは、サブ配列がどこで開始および終了しても、セグメントを完全にカバーできることを無視しています。 

具体的な落とし穴:$N = 6$そしてセグメントがあります$[2, 3]$、サブ配列$[1, 4]$どちらのエンドポイントも 2 または 3 に正確に一致しないにもかかわらず、すでに不良です。 カバレッジ構造を考慮せずにエンドポイントを直接追跡するだけのアプローチは、そのようなケースを見逃してしまいます。 

問題は基本的にペアを数えるということです$(a, b)$これにより、2 次元の幾何学的条件である禁止区間が完全に含まれることがなくなります。 

## アプローチ

 有用な再定式化は、条件を反転することで得られます。 サブアレイ$[a, b]$少なくとも 1 つの間隔が含まれる場合は不良です$[l_i, r_i]$、これは以下と同等です$a \le l_i$そして$b \ge r_i$。 したがって、各間隔で不良ペアのセットが生成されます。$(a, b)$平面: 長方形内のすべての点$[1, l_i] \times [r_i, N]$、に限定されます$a \le b$。 

したがって、問題は、三角形グリッド内のこれらの長方形の結合を数えるということになります。 この和集合の補数が答えを与えます。 

ブルートフォースアプローチでは、すべてのペアを明示的に列挙します。$(a, b)$そしてそれらが長方形の中にあるかどうかをテストします。 つまり$O(N^2 M)$、それは不可能です。 

重要な構造観察は、左側の端点をスイープできることです。$a$。 固定の場合$a$、正しいエンドポイントがいくつあるか知りたいです$b$少なくとも 1 つの長方形で覆われています。 各インターバル$[l_i, r_i]$の取材に貢献する$b \ge r_i$いつでも$a \le l_i$。 これは次のことを意味します$a$減少すると、より多くの間隔がアクティブになり、それぞれが範囲に寄与します。$b$-軸。 

したがって、処理できます$a$降順で、間隔の動的な結合を維持します。$b$-軸。 の各固定セグメントに対して、$a$- アクティブ セットが変化しない値。寄与は単純に幅です。$a$カバーされる長さの回数$b$。 これにより、挿入中の間隔の結合を維持するという問題が軽減され、圧縮された座標上のセグメント ツリーで処理できます。

 ## アルゴリズムのチュートリアル

 次に、アクティブな間隔の幾何学に焦点を当てて、段階的にソリューションを構築します。 

### 1. 禁止されている各セグメントを四角形に変換します。 

各インターバル$[l, r]$すべての不良サブアレイを表します$[a, b]$そのような$a \le l$そして$b \ge r$。 これを長方形として解釈します。$(a, b)$空間。 

この変換は、組み合わせ条件を幾何学和集合問題に変換するため、不可欠です。 

### 2. 適切なエンドポイントを圧縮する

 いくつかの値として表示される値を追跡するだけで済みます。$r_i$プラス境界線$N$。 これらの値を圧縮して、セグメント ツリー内で維持できるようにします。 

正しいエンドポイント ディメンションが集計対象となるため、この手順が必要です。 

### 3. 左のエンドポイントで間隔を並べ替えます

 間隔を降順に処理します。$l_i$。 これは、左方向に移動すると、$a$、より多くの間隔がアクティブになります。 

### 4. から左端点をスイープします。$N$1まで下げる

 ポインタを維持します$a$。 それぞれに異なる$l_i$、その左側のエンドポイントですべての間隔をアクティブにします。 

2 つの連続するアクティベーション ポイントの間$L_{k}$そして$L_{k+1}$、アクティブ セットは変化しないため、カバレッジは$b$は一定です。 

### 5. 正しい軸の範囲を維持する

 過剰に圧縮されたセグメントツリーを維持します$b$-価値観。 各間隔は範囲の更新に寄与します$[r_i, N]$。 セグメント ツリーには、カバーされる合計の長さが格納されます。 

間隔を追加すると、その範囲にわたるカバレッジ数が増加します。 カバレッジ数が正の場合、そのセグメントは結合長に寄与します。 

### 6. セグメント全体にわたって貢献を蓄積する$a$各セグメントごとに、$a$-幅の値$w$に、次のように追加します。$$w \times (\text{covered length on } b)$$これにより、すべての四角形が寄与する不良サブ配列の合計数が得られます。 

### 7. サブ配列の合計から減算する

 サブ配列の合計は次のとおりです。$N(N+1)/2$。 計算された不良数を減算して、良好なサブ配列を取得します。 

### なぜ効果があるのか

 いつでも固定$a$、アクティブな間隔は正確に次のとおりです。$l_i \ge a$。 このような各間隔は、連続した範囲の無効な値に寄与します。$b$-価値観。 セグメント ツリーは、これらの範囲の結合を正確に維持します。 アクティブ セットは次の値でのみ変更されるため、$l_i$、それらのポイントでスイープを分割することで、中間状態を見逃すことなく正確さが保証されます。 すべての悪いペア$(a, b)$正確に 1 つのスイープ セグメントの一部として 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class SegTree:
    def __init__(self, vals):
        self.n = len(vals) - 1
        self.coords = vals
        self.tree = [0] * (4 * self.n)
        self.cnt = [0] * (4 * self.n)

    def _push_up(self, idx, l, r):
        if self.cnt[idx] > 0:
            self.tree[idx] = self.coords[r + 1] - self.coords[l]
        else:
            if l == r:
                self.tree[idx] = 0
            else:
                self.tree[idx] = self.tree[idx * 2] + self.tree[idx * 2 + 1]

    def update(self, idx, l, r, ql, qr, val):
        if ql <= l and r <= qr:
            self.cnt[idx] += val
            self._push_up(idx, l, r)
            return
        mid = (l + r) // 2
        if ql <= mid:
            self.update(idx * 2, l, mid, ql, qr, val)
        if qr > mid:
            self.update(idx * 2 + 1, mid + 1, r, ql, qr, val)
        self._push_up(idx, l, r)

def solve():
    N, M = map(int, input().split())
    segs = []
    ys = {1, N + 1}

    for _ in range(M):
        l, r = map(int, input().split())
        segs.append((l, r))
        ys.add(r)

    ys = sorted(ys)
    idx = {v: i for i, v in enumerate(ys)}

    segs.sort(reverse=True)
    st = SegTree(ys)

    active = 0
    ans_bad = 0
    i = 0

    while i < M:
        cur_l = segs[i][0]
        j = i
        while j < M and segs[j][0] == cur_l:
            l, r = segs[j]
            st.update(1, 0, len(ys) - 2, idx[r], len(ys) - 2, 1)
            j += 1

        next_l = segs[j][0] if j < M else 0
        width = cur_l - next_l
        ans_bad += width * st.tree[1]

        i = j

    total = N * (N + 1) // 2
    print(total - ans_bad)

if __name__ == "__main__":
    solve()
```実装はスイープオーバーを分離します$l$のカバレッジの維持から得られる値$r$-軸。 セグメント ツリーには、カバーされる結合長が格納されます。$b$-値、および各更新は、より小さいすべての値に関連する間隔のアクティブ化に対応します。$a$。 

重要な繊細さは範囲です$[r_i, N]$、これにはセンチネルを追加する必要があります$N+1$圧縮中にセグメント ツリー内で長さの計算が適切に機能するようにします。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、間隔がまったくない場合です。 この状況では、アルゴリズムはセグメントをアクティブにすることはなく、スイープによって不良サブ配列がゼロになり、最終的な答えは正しくなります。$N(N+1)/2$。 

もう 1 つのケースは、間隔が配列全体をカバーする場合です。たとえば、$[1, N]$。 これにより、可能なすべてをカバーする長方形が生成されます。$(a, b)$とペアにする$a \le b$したがって、すべてのサブ配列は不良です。 セグメント ツリーは最終的に全体をカバーします。$b$-軸、およびスイープは全領域を蓄積し、予想されるゼロ良好サブアレイと一致します。 

より微妙なケースは、次のような重複する間隔です。$[1, 3]$そして$[2, 3]$。 単純な合計では 2 倍にカウントされますが、セグメント ツリーは和集合の適用範囲を維持するため、重複は 1 回だけ寄与します。 これにより、重なりが激しい場合でも正確さが保たれます。
