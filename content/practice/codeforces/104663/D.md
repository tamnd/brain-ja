 ## 問題の理解

 以下の整数を含むセットから始めます。$1$に$N$。 毎日の構成は次のとおりです。$K$独立したランダムな描画。すべての描画で均一に値が選択されます。$1$に$N$。 描画された値がセット内にまだ存在する場合、それは削除されます。 そうでなければ何も起こりません。 このプロセスは、セットが空になるまで毎日続きます。 タスクは、モジュラー演算を使用して、これが発生するまでに必要な予想日数を計算することです。 

重要な点は、除去は数日にわたって持続するが、1 日以内に複数の成功したドローが同じ残りの要素に複数回ヒットする可能性があり、最初のヒットのみが重要であるということです。 

この制約により、シミュレーションやサブセットを明示的に追跡する状態空間が即座に除外されます。 と$N$まで$10^5$、 平$O(N^2)$移行は不可能であり、$O(NK)$慎重に構造化しない限り、州ごとのサイズは大きすぎます。 以来$K \le 7$、どのようなソリューションでも、毎日の描画数が非常に少ないという事実を利用する必要があります。これにより、1 日に発生する可能性のある組み合わせの複雑さが制限されます。 

微妙なエッジケースは次のような場合です$K$に比べて大きい$N$、しかしここでは$K$は小さいため、主な困難はステップごとのランダム性ではなく、1 日に削除される新しい要素の数の正確な分布を計算することです。 

単純な考えは、毎日シミュレーションしてランダムにサンプリングすることです。$K$セットが空になるまで値を繰り返し入力します。 これでは、モンテカルロ法を介してのみ正しい期待値が生成されますが、非常に時間がかかり、正確ではありません。 もう 1 つの誤った単純化は、残りの各要素を確率で独立して削除されたものとして扱うことです。$1 - (1 - 1/N)^K$。 これは失敗します。1 回のドローで 1 つの数値しかヒットできないため、1 日のさまざまな要素の削除には負の相関があるためです。

 ## アルゴリズムのチュートリアル

 私たちは定義します$f[m]$すべての要素を削除するのに必要な予想日数として、$m$要素は残ります。 

1.設定します$f[0] = 0$空のセットにはそれ以上の日数は必要ないためです。 
2. の状態から$m > 0$で構成される 1 日をシミュレーションします。$K$描く。 この日以降、正確に想像してください$t$以前に残っていた個別の要素が少なくとも 1 回ヒットします。 状態は次のように遷移します。$m - t$。 
3. 確率を計算します$P(m, t)$正確に削除する$t$1 日の中で異なる要素を。 これを行うには、まずどれを選択しますか$t$要素が関与しており、それが要因となります$\binom{m}{t}$。 次に、有効なシーケンスを数えます。$K$他のものに触れない描画$m - t$残りの要素を選択し、すべての要素を選択したことを確認します$t$少なくとも一度は現れます。 各抽選で利用可能なアルファベットは次のようになります。$N - (m - t)$、手つかずの残りの要素を禁止しているためです。 
4. すべてが選択されていることを強制する$t$少なくとも 1 回出現する場合、これらのサブセットに対して包含/除外を使用します。$t$要素。 サイズのサブセットの場合$j$、それらを避けるシーケンスを減算します。$j$要素、用語を与える$(-1)^j \binom{t}{j} (N - m + t - j)^K$。 まとめ$j$すべてが含まれるシーケンスの数を生成します。$t$少なくとも一度は現れます。 
5. で割る$N^K$確率が得られます$P(m, t)$。 私たちに必要なのは$t \le K$、せいぜい$K$明確な新しい要素が現れる可能性があります$K$描く。 
6. 計算する$f[m]$再発を利用して$$f[m] = 1 + \sum_{t=0}^{\min(m,K)} P(m,t)\, f[m-t].$$1. 評価する$f[m]$から$m=0$まで$N$、事前に計算されたべき乗と二項係数を使用します。 

核となる不変条件は次のとおりです$f[m]$は残りの要素の数のみに依存し、要素の同一性には依存しません。 遷移確率は、すべての有効なシーケンスが重複または省略されることなく、1 日に考えられるすべての結果を正確に考慮します。$K$描画は、少なくとも 1 回出現する残りの要素のサブセットによって一意に分類されます。 包含/排他により、そのような各シーケンスが適切な順序で正確に 1 回カウントされることが保証されます。$t$-class を使用して、DP が真のマルコフ過程と一致することを確認します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

N, K = map(int, input().split())

# Precompute powers
powK = [1] * (N + 1)
for i in range(N + 1):
    powK[i] = pow(i, K, MOD)

# Precompute factorials for nCk up to K
fact = [1] * (K + 1)
invfact = [1] * (K + 1)
for i in range(1, K + 1):
    fact[i] = fact[i - 1] * i % MOD
invfact[K] = modinv(fact[K])
for i in range(K, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    # n is large but r <= K
    res = 1
    for i in range(r):
        res = res * ((n - i) % MOD) % MOD
    return res * invfact[r] % MOD

inv_NK = modinv(pow(N, K, MOD))

f = [0] * (N + 1)

for m in range(1, N + 1):
    total = 1  # the "+1" in recurrence

    max_t = min(m, K)
    for t in range(0, max_t + 1):
        ways_choose = C(m, t)

        inner = 0
        for j in range(0, t + 1):
            sign = 1 if j % 2 == 0 else -1
            avail = N - m + t - j
            inner = (inner + sign * powK[avail]) % MOD

        prob = ways_choose * inner % MOD
        prob = prob * inv_NK % MOD

        total = (total + prob * f[m - t]) % MOD

    f[m] = total

print(f[N])
```この実装は DP を直接ミラーリングします。 配列`powK[x]`店舗$x^K$、これは長さのシーケンスの数です$K$アルファベット以上の大きさ$x$。 これは包含/除外式の内部で使用されます。 

機能`C(n, r)`小規模向けに最適化されています$r$、 以来$r \le K \le 7$、最大階乗事前計算を回避します。$N$。 これにより、メモリを小さく保ちながら、高速な二項計算が可能になります。 

変数`inner`固定の包含と除外の合計を計算します。$m, t$。 乗算`ways_choose`どちらを選択するためのアカウント$t$要素が削除され、乗算されます。`inv_NK`カウントを確率に変換します。 

ついに、`f[m]`ボトムアップで構築されるため、より小さな状態へのすべての遷移がすでに利用可能になります。

 ## 特殊なケース

 いつ$N = 1$、プロセスは、関係なくちょうど 1 日で終了します。$K$唯一の要素は少なくとも 1 回描画されるとすぐに削除されるためです。 DP はこれを処理します。$m=1$、唯一の有効な遷移は$t=1$、 そして$f[1] = 1 + f[0]$。 

いつ$K = 1$, 毎日 1 つのクーポンが抽選されます。 この移行は、1 日に 1 つの要素のみを削除できる標準のクーポン コレクター ステップに簡素化されます。 DP は、すべての項が一致するため、正しく減少します。$t > 1$消える。 

いつ$K$に比べて大きい$m$、 のような$m \le K$、遷移ではのみ考慮されるため、DP は依然として正しく動作します。$t \le m$。 許容される描画のアルファベットが次のように大幅に縮小された場合でも、包含/除外式は引き続き有効です。$m$が減少し、無効な過剰カウントが発生しないようにします。
