 ## 解決策
 ## 問題の理解

 次のような正の整数 (x) と (y) を見つける必要があります。 

[
 x^2-y^2=n、
 】

 ここで (0\le n\le 2^{60})、(x) と (y) は両方とも (2^{62}-1) 以下でなければなりません。 そのようなペアが存在する場合、それらのいずれかを出力してもよい。 それ以外の場合は印刷します`No`。 

重要なのは、式は二乗の差であるため、次のように因数分解できるということです。 

[
 (x-y)(x+y)=n。 
】

 (n>0) の場合、両方の因数は正であり、その合計は (2x) であるため、同じパリティを持ちます。 これにより、問題は 2 つの未知の整数の検索から (n) の適切な因数分解を見つけることに変わります。 

上限 (2^{60}) は、(n) まで値を 1 つずつ試行するアルゴリズムには大きすぎます。 (O(\sqrt n)) アルゴリズムでさえ、最悪の場合、約 (2^{30}) 回の反復を実行します。これは、低レベル言語ではすでに数億回の演算が行われており、この問題に対する適切な戦略ではありません。 代わりに代数構造を活用する必要があります。 Python の整数にも固定幅のオーバーフローの問題はありませんが、答えを作成する際には数学的な境界が依然として重要です。 

不注意な因数分解アプローチによって無効なペアが生成される可能性があるエッジケースがいくつかあります。 (n=0) の場合、問題には正の整数が必要であるため、(x=y=1) を選択すると機能しますが、(x=y=0) を選択するとその要件に違反します。 (n=1) の場合、明らかな因数分解 (1\cdot1) では (x=1) と (y=0) が得られますが、これは無効であるため、正しい答えは次のようになります。`No`。 (n=4) の場合、同じパリティの因数による唯一の正の因数分解は (2\cdot2) であり、やはり (y=0) が得られるため、正しい答えも次のようになります。`No`。 (n=2) の場合、因数分解 (1\cdot2) には異なるパリティの因数があるため、整数 (x) と (y) に対応できません。正解は次のとおりです。`No`。 

## アプローチ

 直接的なアプローチでは、(y) の可能な値を試し、(y^2+n) を計算し、それが完全な正方形であるかどうかを確認できます。 これは正しいです。すべての有効な解には何らかの正 (y) があり、すべての関連する値をチェックすると、最終的にその解に到達します。 ただし、検索が終了するまでに (\sqrt n) 個の候補が存在する可能性があります。 (n=2^{60}) の場合、これは約 (2^{30}) 回の反復となるため、最悪のケースではおよそ 10 億 7,000 万回の候補チェックになります。 これは、入力が 1 つの整数で構成される問題にとっては多大な作業です。 

役に立つ観察は因数分解です

 [
 x^2-y^2=(x-y)(x+y)。 
】

 (a=x-y) と (b=x+y) を仮定します。 そうすれば (ab=n)、回復できます

 [
 x=\frac{a+b}{2}、\qquad y=\frac{b-a}{2}。 
】

 これらを整数にするには、(a) と (b) が同じパリティを持っている必要があります。 (n) が奇数の場合、(n) のすべての因数は奇数なので、単純に (a=1) と (b=n) を選択できます。 これにより、

 [
 x=\frac{n+1}{2}、\qquad y=\frac{n-1}{2}。 
】

 これは奇数 (n\ge3) の場合に有効です。 (n=1) の場合は (y=0) を生成するため、個別に拒否する必要があります。 

(n) が (4) で割り切れる場合、(a=2) と (b=n/2) を選択できます。 どちらの因数も偶数であるため、結果の (x) と (y) は整数になります。 

[
 x=\frac{n/2+2}{2}=\frac n4+1、
 \qquad
 y=\frac{n/2-2}{2}=\frac n4-1。 
】

 (y>0) が必要です。つまり (n/4>1)、つまり (n\ge8) になります。 したがって、(8) から始まる (4) のすべての倍数には解があります。 特殊なケース (n=0) は (x=y=1) とは別に処理されます。 

残りの正の整数は、(1) と (4) とともに、(2\pmod4) に完全に合同な整数です。 2 つの正の平方の差として有効な表現はありません。

 ## アルゴリズムのチュートリアル

 1. (n=0) の場合、(x=1,y=1) を出力します。 それらの二乗は等しいため、その差はゼロであり、両方の数値は正です。 
2. (n=1) または (n=4) の場合、出力`No`。 (n=1) の場合、唯一の因数分解は (1\cdot1) であり、(n=4) の場合、機能する唯一の同一パリティ因数分解は (2\cdot2) です。 どちらの場合も、結果の (y) はゼロになります。 
3. (n) が奇数の場合は、(a=x-y=1) と (b=x+y=n) を選択します。 どちらも奇数であるため、再構成すると整数値が得られます。 
[
 x=(n+1)/2、\qquad y=(n-1)/2。 
】
 すべての奇数 (n\ge3) について、(y) は正になります。 
4. (n) が (4) で割り切れる場合は、(a=2) と (b=n/2) を選択します。 どちらの因数も偶数で、(n\ge8) については (b>a) が得られます。 
[
 x=n/4+1,\qquad y=n/4-1
 】
 は正の整数です。 
5. 上記のいずれのケースにも当てはまらない場合、出力`No`。 このような正の (n) は (2\pmod4) に一致するため、同じパリティを持つ 2 つの因数の積として書くことはできません。 

### なぜ効果があるのか

 正の解の場合、(a=x-y) および (b=x+y) を設定すると (ab=n) が得られ、(a) と (b) は同じパリティを持ちます。 (n) が奇数の場合、係数 (1) と (n) はこの要件を満たします。 (n) が (4) で割り切れる場合、因数 (2) と (n/2) は両方とも偶数です。 これらの構成は、構成された (y) が 0 である 2 つの小さなケース (n=1) と (n=4) を除いて、正の整数を直接生成します。 

逆に、(n\equiv2\pmod4) の場合、どの因数分解 (ab=n) にも 1 つの奇数因数と 1 つの偶数因数が含まれている必要があります。これは、その積に (2) の因数が 1 つだけ含まれるためです。 これら 2 つの量は常に同じパリティを持つため、このような係数は (x-y) と (x+y) に等しくなりません。 したがって、解決策は存在しません。 ケース (n=0) は個別に処理されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())

    if n == 0:
        print("Yes")
        print(1, 1)
        return

    if n == 1 or n == 4:
        print("No")
        return

    if n & 1:
        x = (n + 1) // 2
        y = (n - 1) // 2
        print("Yes")
        print(x, y)
        return

    if n % 4 == 0:
        x = n // 4 + 1
        y = n // 4 - 1
        print("Yes")
        print(x, y)
        return

    print("No")

if __name__ == "__main__":
    solve()
```最初の分岐は、因数分解ロジックの前に (n=0) を処理します。これは、因数分解の引数が正の因数を想定しているためです。一方、(0) には単純な正の解 (1^2-1^2=0) があります。 

(1) と (4) のチェックにより、数式で (y=0) が生成されなくなります。 (n=1) の場合、奇数の式は ((x,y)=(1,0)) を与えます。 (n=4) の場合、4 で割り切れる式は ((x,y)=(2,0)) を与えます。 どちらも (y\ge1) という要件に違反しています。 

表現`n & 1`(n) が奇数かどうかをチェックします。 整数の 2 による除算は、対応する分子が偶数であるため安全です。 4 で割り切れる分岐では、`n // 4`は正確であるため、構築された値は両方とも整数です。 

Python ではオーバーフローの問題はありません。 固定幅の 64 ビット実装でも、入力は最大でも (2^{60}) ですが、構築される値は (2^{62}-1) をはるかに下回ります。 奇数 (n) の場合は (x\le2^{59})、(n) が (4) で割り切れる場合は (x\le2^{58}+1) となります。 

## 実用的な例

 ### サンプル 1: (n=3)

 入力は奇数で (1) より大きいため、アルゴリズムは因数分解を使用します。 

[
 3=1\cdot3。 
】

 対応する値は (x=(1+3)/2=2) および (y=(3-1)/2=1) です。 

| ステップ | (n) | ケース | (x) | (y) | 結果 |
 | --- | --- | --- | --- | --- | --- |
 | 1 | 3 | (n\neq0) | | | 続ける |
 | 2 | 3 | (n\neq1,4) | | | 続ける |
 | 3 | 3 | 奇数 | 2 | 1 | 出力`Yes`|

 確かに、

 [
 2^2-1^2=4-1=3。 
】

 トレースは、奇数の構成が直接機能する理由を示しています。因数 (x-y=1) と (x+y=3) は必要な同じパリティを持っています。 

### サンプル 2: (n=2)

 数 (2) は正であり、(1) でも (4) でもなく、奇数ではなく、(4) で割り切れません。 したがって、それは不可能なケースに該当します。 

| ステップ | (n) | 奇数？ | 4で割り切れますか？ | 結果 |
 | --- | --- | --- | --- | --- |
 | 1 | 2 | いいえ | いいえ | 続ける |
 | 2 | 2 | いいえ | いいえ | 出力`No`|

 その理由は構造的なものです。 (2) の因数分解には因数 (1) と (2) があり、それらのパリティは異なります。 ただし、(x-y) と (x+y) は常に同じパリティを持つ必要があります。

 ## 特殊なケース

 ### (n=0)

 入力用```
0
```アルゴリズムはすぐに (x=y=1) を選択します。 方程式は次のようになります

 [
 1^2-1^2=0。 
】

 正 (n) の因数分解引数はゼロには適用されないため、特別な分岐が必要です。 不注意な実装では (0,0) が出力される可能性がありますが、ゼロは出力条件で許可される自然な正の値ではありません。 

### (n=1)

1
```奇妙な構造が選択するでしょう

 [
 x=\frac{1+1}{2}=1、\qquad y=\frac{1-1}{2}=0。 
】

 (1^2-0^2=1) であるため、方程式自体は正しいですが、(y=0) は禁止されています。 (1) には他に因数分解がないため、正しい結果は次のようになります。```
No
```### (n=4)

 のために```
4
```4 で割り切れる構造により、

 [
 x=4/4+1=2、\qquad y=4/4-1=0。 
】

 繰り返しますが、方程式は数値的には正しいですが、(y) は正ではありません。 因数分解 (4=2\cdot2) は (x-y=x+y=2) に正確に対応し、強制的に (y=0) になります。 したがって、正しい出力は次のようになります。`No`。 

### (n=2)

 のために```
2

### (n=8)

 これは、有効な解を持つ最初の 4 の正の倍数です。 構造が与えるもの

 [

 [
 3^2-1^2=9-1=8。

 最大入力は 4 で割り切れるので、

 [

 \qquad

 [
 (2^{58}+1)^2-(2^{58}-1)^2

】
