 ## 問題の理解

 私たちには番号が与えられています$N$それは素因数分解によって完全に説明されます。 すべての素数$p_i$同じ指数で現れる$m$、 それで$N = p_1^m p_2^m \cdots p_k^m$。 の任意の約数$N$は、素数ごとに、以下の指数を選択することによって表すことができます。$0$そして$m$、長さのベクトルを形成します$k$。 

除数の場合$y$、関数を定義します$f(y)$因数分解におけるすべての指数の合計として。 ベクトル形式では、これは単なる座標の合計です。 私たちは、指数の合計が正確に次のような約数に興味があります。$T$。 これらは「ターゲット」ノードです。 

それぞれが次から始まる複数のシーケンスを構築する必要があります。$1$そして終わる$N$ここで、各ステップは、割り算によって約数からより大きな約数に移動します。 指数的に言えば、各ステップは一部の座標を増加させますが、減少させることはありません。 したがって、有効なシーケンスは、$k$-次元グリッドから$(0,0,\dots,0)$に$(m,m,\dots,m)$。 

目標は、指数の合計が正確に一致するすべての約数が一致するように、そのようなパスをできるだけ少なく選択することです。$T$少なくとも 1 つの選択されたパスに表示されます。 

重要な制約は次のとおりです。$k \le 10^3$、$m \le 10^3$、 そして$T \le mk \le 10^6$。 これにより、すべての約数を明示的に列挙したり、完全な要素を構築したりするアプローチは除外されます。$k$-次元格子。 サイズの完全な DP テーブルを保存する場合でも$k \times T$境界線かもしれないし、立体的なものは何でも$k$または$T$すぐには無理です。 

素朴な推論を打ち破ることが多い微妙なケースは、単一のパスが複数のターゲット約数をカバーする可能性があるという仮定です。 たとえば、次のようなとき$k=2, m=2, T=2$、ターゲットには次のものが含まれます$(2,0)$、$(1,1)$、 そして$(0,2)$。 指数の合計が次の値に達すると、パスはこれらのうちの 1 つだけを通過できます。$2$、それ以上の動きは厳密に増加します。 したがって、パスに 2 つの異なるターゲットを含めることはできません。 これにより、純粋にカウントベースのソリューションが必要になります。 

もう 1 つのエッジケースは次のような場合です$T=0$。 唯一のターゲットはルート除数です$1$、したがって、答えは明らかです$1$。 その対極にあるとき、$T=mk$、唯一のターゲットは$N$、また答えます$1$。

 ## アルゴリズムのチュートリアル

 生成関数を次のように書き換えます。$$(1 + x + \cdots + x^m)^k = \left(\frac{1 - x^{m+1}}{1 - x}\right)^k$$これにより、境界のある部分が境界のない構成構造から分離されます。 

## ステップ 1

 展開する$(1 - x^{m+1})^k$二項定理を使って。 これにより合計が得られます$a$ここで、「カットオフ」項に寄与する素数の数を選択します。$x^{m+1}$。 

各用語は次のことに貢献します。$$\binom{k}{a} (-1)^a x^{a(m+1)}$$## ステップ 2

 展開する$(1 - x)^{-k}$、これは標準的な星と棒のシリーズです。$$(1 - x)^{-k} = \sum_{t \ge 0} \binom{t + k - 1}{k - 1} x^t$$これは、制約のない構成をカウントします。 

## ステップ 3

 両方の展開を乗算します。 の係数$x^T$全体の合計になります$a$:$$\sum_{a \ge 0} \binom{k}{a} (-1)^a \binom{T - a(m+1) + k - 1}{k - 1}$$ここで、負の引数を持つ項は無視されます。 

## ステップ 4

 階乗および逆階乗を最大で事前計算します。$T + k$。 各二項係数は次のようになります。$O(1)$。 

## ステップ 5

 反復処理$a$から$0$に$k$、貢献度を法的に累積します$998244353$。 

### なぜ効果があるのか

 変換により、制限された制約が自由な構成から分離されます。 包含/除外用語$(1 - x^{m+1})^k$座標が次の値を超えるすべての解を削除します。$m$からのオーバーカウントを修正します。$(1-x)^{-k}$。 「オーバーフロー座標」の各サブセットが交互の符号で修正されるため、すべての有効な指数ベクトルは 1 回だけカウントされます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 998244353

def modinv(x):
    return pow(x, MOD - 2, MOD)

def solve():
    m, k, T = map(int, input().split())
    primes = list(map(int, input().split()))  # not used

    max_n = T + k + 5

    fact = [1] * max_n
    invfact = [1] * max_n

    for i in range(1, max_n):
        fact[i] = fact[i - 1] * i % MOD

    invfact[max_n - 1] = modinv(fact[max_n - 1])
    for i in range(max_n - 2, -1, -1):
        invfact[i] = invfact[i + 1] * (i + 1) % MOD

    def C(n, r):
        if n < 0 or r < 0 or n < r:
            return 0
        return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

    ans = 0

    for a in range(k + 1):
        t = T - a * (m + 1)
        if t < 0:
            break
        ways = C(k, a) * C(t + k - 1, k - 1) % MOD
        if a % 2 == 1:
            ans = (ans - ways) % MOD
        else:
            ans = (ans + ways) % MOD

    print(ans % MOD)

if __name__ == "__main__":
    solve()
```実装では階乗を 1 回事前計算し、それをすべての二項評価に使用します。 ループオーバー$a$早めに止まるときは$T - a(m+1)$それ以上の項は何も寄与しないため、負になります。 指数空間で問題を再定式化した後は素数は無関係であるため、完全を期すためにのみ読み取られます。
