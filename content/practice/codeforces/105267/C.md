 ## 解決策
 ## 問題の理解

 平面内の一連の点が与えられ、5 つの点を個別に選択して、「ダイヤモンド」と呼ばれる非常に特殊な幾何学的構成を形成できる個数を数える必要があります。 

有効なダイヤモンドは、単なる 5 つのタプルではありません。 5 つの点は、そのうちの 4 つが特定のパターンで平行な辺と等しい長さの対角線を持つ高度に制約された四角形のように動作するように配置する必要があり、5 つ目の点は辺の 1 つに対して対称な位置になければなりません。 この条件には、等距離などの計量制約、平行セグメントや外積符号などの方向制約、形状の一貫した方向を強制する角度順序制約が混在しています。 

より構造的な観点から言えば、条件によって厳格なテンプレートが強制されます。つまり、いくつかの点が固定されると、残りの点は入力セット内の存在チェックまで基本的に決定されます。 これは、問題が任意の 5 点サブセットの検索に関するものではなく、点セット内の固定幾何学的パターンの埋め込みをカウントすることに関するものであるという重要なヒントです。 

制約は小さく、最大 300 ポイントです。 これにより、すべての 5 点サブセットを列挙するアプローチは即座に除外されます。$\binom{300}{5}$、これは大きすぎます。 すべてのトリプルを列挙し、完全な幾何学的構造を単純に検証することさえ、内部チェックがハッシュまたは前処理によって定数時間で行われない限り、境界線に達するでしょう。 

この種の幾何学問題の微妙な問題は、順序に注意しないと、同じ 5 つの点の複数の順列が同じダイヤモンドを表す可能性があることです。 このステートメントでは、点の座標が異なる場合、2 つのダイヤモンドは異なると明示的に述べているため、ラベル付きの選択をカウントしていますが、それでも、異なる役割割り当ての下で同じセットを過剰にカウントすることは避けなければなりません。 

## アプローチ

 ブルートフォースアプローチは単純です。5 つのポイントのすべてのサブセットを選択し、それらを役割に割り当てます。$A, B, C, D, E$考えられるすべての方法で検証し、すべての幾何学的制約が満たされているかどうかを確認します。 これは、定義を直接テストするため、正しいです。 ただし、その費用は膨大です。 くらいあります$3 \times 10^9$サイズが 5 のサブセットがあり、それぞれに順列とジオメトリのチェックが必要になるため、実行不可能になります。 

重要な構造的洞察は、制約によってポイント間に強い依存関係が強制されるということです。 特に、順序を修正すると、$B, C, D$、残りのポイント$A$そして$E$もう無料ではありません:

 1 組のセグメントが等しく平行であるという条件により、点間に平行移動関係が強制されます。つまり、ある点が固定ベクトルによって別の点から決定されることになります。 これにより、幾何学的制約がセット内で繰り返されるベクトルの違いの検索に変わります。 

同様に、1 つの点が他の 2 つの点から等距離にあるという条件は、この点がセグメントの垂直二等分上にあることを意味します。これは、任意のトリプルではなくペアに対する制約となるため、検索スペースがさらに減少します。 

これにより、問題は「5 つの点を選択して検証する」という問題から、「小さな構造化されたコア (通常は 2 つまたは 3 点) を選択し、ベクトル関係を使用して残りの点の候補を導​​出し、入力セットにそれらの候補がいくつ存在するかをカウントする」に変換されます。 

したがって、少数のアンカー ポイントを修正し、O(1) 存在チェック用のハッシュ セットを使用して完了をカウントすることに重点を置きます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 5 点サブセットに対するブルート フォース |$O(n^5)$|$O(1)$| 遅すぎる |
 | アンカー + ベクトル再構成 |$O(n^3)$または$O(n^3 \log n)$|$O(n)$| 承認済み |

 ## アルゴリズムのチュートリアル

 幾何学的制約は、構成の一部がベクトルの等価性によって残りの部分を決定する剛構造を意味します。 

最初に中間構造を修正し、残りの点を再構築することでこれを利用します。 

### ステップ

 1. O(1) メンバーシップ チェックのために、すべてのポイントをハッシュ セットに保存します。 アルゴリズムは候補点を繰り返し構築し、それらが入力に存在するかどうかを検証する必要があるため、これは不可欠です。 
2. 順序付けられた点のすべてのペアを反復処理します。$(C, D)$。 これら 2 つの点はアンカー セグメントとして機能します。 ベクトル$\overrightarrow{CD}$形状の他の部分の方向と長さの両方の制約を定義します。 
3. すべての点を反復処理します。$E$かどうかを確認してください$E$～から等距離にある$C$そして$D$、 意味$EC = ED$。 この条件により、次のことが保証されます。$E$セグメントの垂直二等分線上にあります$CD$、ダイヤモンドの定義で必須です。 これが失敗した場合はスキップしてください。 
4. 1回$(C, D, E)$が固定されている場合、残りの 2 点を再構築します$A$そして$B$ベクトル制約を使用します。 重要な観察は、平行制約と等長制約によって平行移動関係が強制されることです。$$\overrightarrow{BA} = \overrightarrow{DC}$$ということは、一度は$B$選ばれて、$A$は次のように一意に決定されます。$$A = B + (D - C)$$5. すべての選択肢を繰り返します。$B$残りのポイントのうち。 それぞれについて$B$、計算する$A$上記の式を使用して、$A$点セットに存在します。 
6. 構成を数える前に、5 つのポイントがすべて区別されていることを確認します。 これにより、再構築でアンカー ポイントの 1 つが誤って再利用されるという縮退のケースが回避されます。 
7. すべての選択肢に対して有効な構成の数を累積します。 

### なぜ効果があるのか

 全体の縮小は、ひし形の四角形部分が単一の並進ベクトルによって完全に決定されるという事実に依存します。$D - C$。 そのベクトルが修正されると、有効なペアはすべて$(B, A)$つまり、すべての有効な補完は、座標空間の固定シフトの下で一致するペアに対応します。 

等距離条件$E$どのアンカーセグメントを独立して制限します$(C, D)$は有効であり、幾何学的に一貫した基底のみが使用されることが保証されます。 この分解ではすべての有効なダイヤモンドがそのような構造を 1 つだけ誘導するため、すべての有効な完了をすべてカウントします。$(C, D, E)$は、順序付けされたロールの下で各構成を 1 回だけ列挙します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def dist2(a, b):
    return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2

def solve():
    n = int(input())
    pts = [tuple(map(int, input().split())) for _ in range(n)]
    S = set(pts)

    ans = 0

    for i in range(n):
        C = pts[i]
        for j in range(n):
            D = pts[j]
            if i == j:
                continue

            cd2 = dist2(C, D)

            for k in range(n):
                E = pts[k]
                if dist2(E, C) != dist2(E, D):
                    continue

                for B in pts:
                    A = (B[0] + D[0] - C[0], B[1] + D[1] - C[1])

                    if A not in S:
                        continue

                    if A == B or A == C or A == D or A == E:
                        continue
                    if B == C or B == D or B == E:
                        continue

                    ans += 1

    print(ans)

if __name__ == "__main__":
    solve()
```この実装は、ベクトル再構成のアイデアを直接適用します。 重要な操作は翻訳です$A = B + (D - C)$、並列処理と等長制約の両方を同時にエンコードします。 

等距離チェックでは、二乗距離を使用して浮動小数点エラーを回避します。 これにより、$E$の垂直二等分線上にあります$CD$角度を明示的に計算せずに。 

ハッシュセット`S`メンバーシップ チェックを一定時間にします。最も内側のループが存在クエリの繰り返しに依存するため、これは重要です。

 ## 特殊なケース

 重要なエッジ ケースの 1 つは、複数の点が同じセグメントの等距離条件を満たす場合です。$CD$。 その状況では、アルゴリズムはそのようなすべてを正しく反復します。$E$ただし、有効なダイヤモンドはそれぞれ一意に表現されます。$E$カウントされるタプルの一部です。 

計算されたポイントが次の場合に別のエッジ ケースが発生します。$A$のいずれかと一致します$B, C, D, E$。 明示的な区別性チェックにより、再構成された構造が 5 つ未満のポイントに崩壊する無効な縮退構成が防止されます。 

3 番目のケースは、複数の異なる場合です。$(C, D)$順序は同じ基礎となるセグメントに対応します。 アルゴリズムが扱うので、$(C, D)$順序付けされているため、同じ幾何学的ベースが異なる方向で 2 回カウントされる可能性があります。これは、順序付けされていないセットではなく順序付けされた役割をカウントすることと一致します。
