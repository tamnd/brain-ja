 ## 問題の理解

 私たちは 4 チームのサッカー グループの最終ラウンドをシミュレーションしています。 すでに3つの試合が判明している。中国はタイとすでに2試合を行っており、残るは中国対韓国、タイ対シンガポールの最終ラウンドのみとなっている。 唯一不明なのは、これら 2 つの試合の最終スコアであり、4 つの整数で与えられます。韓国のスコアは a、中国のスコアは b、タイのスコアは c、シンガポールのスコアは d です。 

これら 2 つの結果から、4 チームすべての最終グループ テーブルを再構築する必要があります。 各チームは標準的な方法でポイントを蓄積します。勝利の場合は 3、引き分けの場合は 1、負けの場合は 0 です。 ランキングは、最初に合計ポイント、次に得失点差、最後に合計得点によって決定されます。 その後もチームが同点の場合は、直接対決のサブランキングが適用されますが、この問題により、最終ステップ以上に進む必要がないことが保証されます。 

重要な問題は、中国とタイが以前の試合からの直接対決ですでに部分的に同点であり、両国間の最終順位を決定するには、詳細なタイブレークルールを通じて同点を解消する必要がある可能性があることである。 すべての計算の結果、中国がグループ内で上位 2 位に入るかどうかを判断する必要があります。 

制約は非常に小さく、すべてのスコアは 0 ～ 10 です。これにより、パフォーマンスの観点から最適化する必要がなくなります。 考えられるすべての結果に対する強引なシミュレーションさえも実現可能です。 本当の課題は、ランキング ロジックを正しく実装することであり、特に中国とタイのタイブレークは制限された試合のサブセットに依存します。 

中国とタイが勝ち点、得失点差、総得点で同点となり、直接比較を余儀なくされると、微妙なエッジケースが生じる。 そのシナリオでは、これら 2 つのチームが関与する試合のみが重要となり、その制限を無視すると、不正確なランキングにつながります。 

## アプローチ

 問題を解決する直接的な方法は、最終ラウンドの結果を適用した後、グループの順位を完全にシミュレートすることです。 既知の以前の結果と 2 つの決勝戦を使用して、4 つのチームすべての得点、得点、失点を計算します。 完全な統計が得られたら、ランキング ルールに従ってチームを並べ替えます。 

2 つ以上のチームがすべての主要基準で同点の場合、複雑な状況が発生します。 その場合、グローバルな統計に単純に依存することはできません。 同点のチーム間で行われた試合のみを考慮してミニテーブルを再計算する必要があります。 この問題において、中国の出場資格に影響を与える可能性がある唯一の重要な関係は、中国とタイの間である。 

ブルート フォース アプローチでは、すべての同点が解消されるまで同点チームをグループ化し、サブテーブル統計を再計算することを繰り返して、同点解消手順を明示的にシミュレートする場合があります。 チームが 4 つしかないため、計算的には簡単ですが、不必要に複雑になります。 

重要な観察は、完全な再帰的同点解決システムは必要ないということです。 We only need to correctly compute:

1. Global ranking for all four teams.
 2. 中国とタイが世界基準で同点である場合、両者のミニテーブルを比較してください。

 ## アルゴリズムのチュートリアル

 試合結果を明示的に再構築し、ランキングを評価することで進めます。 

1. 4 つのチームすべてを、勝ち点、得点、失点をゼロで初期化します。 This sets a clean baseline for aggregation.
 2. Add the known past results:

中国はタイと２試合あり、１勝２対１、１引き分け１対１となっている。 これらから、両チームのポイントとゴールの統計を更新します。 このステップは固定されており、入力には依存しません。 
3. 入力から最終ラウンドの結果を適用します。 

韓国対中国では、韓国が a ゴール、中国が b ゴールに貢献し、勝敗または引き分けに応じて両チームの得点、失点、およびポイントを更新します。 

タイ対シンガポールも同様に c と d に寄与します。 
4. 各チームについて計算します。 

総得点、得失点差、総得点。 これらは主なランキングキーです。 
5. これらのキーを使用して 4 つのチームを辞書順に並べ替えます。最初に得点、次に得失点差、次に得点の順です。 
6. このランキングから上位 2 チームを暫定予選チームとして決定します。 
7. 中国がすでに上位 2 位に入っている場合は、すぐに YES を出力します。 
8. そうでない場合は、中国とタイがすべての世界基準 (勝ち点、得失点差、得点) で同点かどうかを確認します。 同点でない場合はNOを出力します。 
9. 世界的に同点の場合、中国とタイの間には他に一致が存在しないため、既知の 2 つの結果 (2:1 と 1:1) に加えて他には何も使用せず、中国とタイの間の試合のみについて直接対決テーブルを作成します。 
10. 同じランキング ルールを使用して、このミニ表で中国とタイを比較します。 中国が上位にランクされている場合は、YES を出力します。 それ以外の場合は NO を出力します。 

正確性は、世界ランキングが中国とタイを区別するのに不十分であることを正確に検出し、制限された比較セットに切り替えるかどうかにかかっています。 

これが機能する理由は、FIFA スタイルのタイブレークが世界的な統計でチームを分離できない場合にのみ、直接対決の結果を分離する方法に基づいています。 この構成ではおそらく中国とタイだけがこの第 2 段階を必要とするため、そのペアを超えた任意のサブセットをシミュレートする必要はありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def add(team, gf, ga, pts, g, a):
    team["gf"] += gf
    team["ga"] += ga
    team["pts"] += pts

def result_points(x, y):
    if x > y:
        return 3, 0
    if x == y:
        return 1, 1
    return 0, 3

def key(t):
    return (t["pts"], t["gf"] - t["ga"], t["gf"])

def better(a, b):
    if key(a) != key(b):
        return key(a) > key(b)
    return False

china = {"pts": 0, "gf": 0, "ga": 0}
korea = {"pts": 0, "gf": 0, "ga": 0}
thailand = {"pts": 0, "gf": 0, "ga": 0}
singapore = {"pts": 0, "gf": 0, "ga": 0}

# known matches China vs Thailand
def apply(a, b, x, y):
    pa, pb = result_points(x, y)
    add(a, x, y, pa, 0, 0)
    add(b, y, x, pb, 0, 0)

apply(china, thailand, 2, 1)
apply(china, thailand, 1, 1)

a, b, c, d = map(int, input().split())

apply(korea, china, a, b)
apply(thailand, singapore, c, d)

teams = [china, korea, thailand, singapore]
teams.sort(key=lambda t: (t["pts"], t["gf"] - t["ga"], t["gf"]), reverse=True)

top2 = teams[:2]

if china in top2:
    print("YES")
    sys.exit()

def equal(a, b):
    return key(a) == key(b)

if not equal(china, thailand):
    print("NO")
    sys.exit()

apply_ct_pts = [(2, 1), (1, 1)]
c_pts = 0
t_pts = 0

for x, y in apply_ct_pts:
    if x > y:
        c_pts += 3
    elif x == y:
        c_pts += 1
        t_pts += 1
    else:
        t_pts += 3

if c_pts > t_pts:
    print("YES")
else:
    print("NO")
```この解決策は、チーム統計用の 4 つの辞書を維持することから始まります。 各試合では、得点、失点、ポイントが一貫して更新されます。 ヘルパーさん`result_points`得点ルールを直接エンコードし、勝ち、引き分け、負けの処理に曖昧さがなくなります。 

すべての試合を処理した後、チームは標準の辞書編集ランキング キーによって並べ替えられます。 中国が上位 2 位に入っているかどうかをすぐに確認します。これにより、追加の論理を必要とせずにほとんどのケースが解決されます。 

中国が上位 2 位に入っていない場合にのみ、同点シナリオを検討します。 機能`equal`グローバルランキングルールの下で中国とタイが区別できないかどうかを検出します。 そうでない場合、この構成ではタイブレークがタイブレークを超えて中国を押し上げることはできないため、答えは即座にノーになります。 

最後のブロックは、2 つの固定された過去の試合を使用して、中国とタイの間の直接対決の寄与のみを計算します。 これらの結果は一定であるため、ミニテーブル ポイントを直接再計算して比較します。
