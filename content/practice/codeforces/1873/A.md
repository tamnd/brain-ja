 ## 解決策
 ## 問題の理解

 ラベルが付いた 3 枚の異なるカードが与えられます。`a`、`b`、 そして`c`、いくつかの順序で並べられています。 私たちの目標は、2 枚のカードの最大 1 回の交換を使用して、行を順序付けられたシーケンスに変換できるかどうかを判断することです。`abc`。 各テスト ケースは、これら 3 つの文字を何らかの順列で正確に含む長さ 3 の文字列で構成されます。 それぞれの場合の出力は、順序付けられたシーケンスが取得できた場合は「YES」、取得できなかった場合は「NO」になります。 

要素が 3 つしかないため、順列の合計数は 6 になります。 これは、問題について徹底的に推論できることを意味しますが、単一のスワップで十分である正確な条件も理解する必要があります。 スワップは、間違って配置された 1 つのペアを修正するか、シーケンスがすでに存在する場合は不要です。`abc`。 制約はわずかです。テスト ケースが 6 つまでで、各テスト ケースに含まれるのは 3 文字だけなので、合理的なアプローチであれば無視できる時間で実行されます。 エッジケースには、すでにソートされているシーケンスが含まれます (`abc`)、1 回のスワップでは修正できないシーケンス (`bca`または`cab`)、および 1 つスワップ離れたシーケンス (`acb`、`bac`、`cba`）。 

単純な実装では、任意の 2 文字を交換すれば常に十分であると誤って想定される可能性があります。 例えば、`bca`なれない`abc`1回の交換で。 間違って配置された文字の数だけをチェックすると、ここで誤検知が発生します。 アルゴリズムは、ターゲットに対する各文字の位置を考慮する必要があります。`abc`。 

## アプローチ

 ブルートフォース手法では、可能なすべてのポジションのペアの交換を明示的に試み、結果が一致するかどうかを確認します。`abc`。 3 文字の場合、位置 0 と 1、位置 0 と 2、位置 1 と 2 の 3 つの交換が可能です。各交換の後、文字列を次と比較します。`abc`。 スワップによってターゲットが得られる場合は、「YES」を出力します。 それ以外の場合は「いいえ」。 これは正しいです。考えられるすべてのシングルスワップ操作をカバーしており、入力サイズが固定されていると一定時間で実行されます。 欠点は、このアプローチはより大きな配列に拡張できないことですが、ここでは許容されます。 

さらに単純化するための重要な観察は、3 つの文字の順列は、最大でも 1 回の交換で済むということです。`abc`すでにどちらかである場合に限り、`abc`または、最初と最後の文字が入れ替わっています (`acb`、`bac`、`cba`）。 シーケンス`bca`そして`cab`2 回のスワップが必要であり、1 回の操作では修正できません。 これらのパターンに対して文字列をチェックすることで、1 回の比較で答えを決定できます。これは、テスト ケースごとに実質的に O(1) になります。

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る`t`。 
2. 各テスト ケースについて、カード シーケンスを表す 3 文字の文字列を読み取ります。 
3. 文字列が正確であるかどうかを確認します`abc`。 その場合は、「YES」と出力して続行します。 
4. それ以外の場合は、文字列が次の 3 つの順列のいずれかに一致するかどうかを確認します。`abc`1 回の交換で:`acb`、`bac`、`cba`。 存在する場合は、「YES」を出力します。 
5. これらの条件がいずれも満たされない場合は、「NO」と出力します。 これらはシーケンスです`bca`そして`cab`、2 回のスワップが必要です。 
6. すべてのテスト ケースに対して手順 2 ～ 5 を繰り返します。 

機能する理由: 3 要素の置換の場合、文字列はすでにターゲットに一致しているか、正確に 2 つの要素を交換することで修正できるか、または複数の交換が必要です。 私たちがチェックする 3 つのパターンは、1 回のスワップで解決できるすべてのケースをカバーし、正確性を保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().strip()
    if s == "abc" or s in {"acb", "bac", "cba"}:
        print("YES")
    else:
        print("NO")
```コードは最初にテスト ケースの数を読み取ります。 テストケースごとに、文字列を読み取り、空白を取り除き、それをターゲットと比較します。`abc`。 文字列が一致する場合`abc`またはスワップが 1 つ離れています (`acb`、`bac`、`cba`)、「YES」を出力します。 それ以外の場合は、「NO」を出力します。 ワンスワップ パターンのセットを使用すると、効率的なメンバーシップ チェックが可能になります。

 ## 特殊なケース

 アルゴリズムは、すでにソートされたシーケンスのエッジケースを処理します`abc`まず明示的に等しいかどうかをチェックします。 のために`bca`そして`cab`の場合、アルゴリズムは単一のスワップではシーケンスを修正できないことを正しく識別し、「NO」を出力します。 のために`cba`、これが逆の場合、アルゴリズムはそれを 1 スワップの場合として検出し、「YES」を出力します。 ワンスワップ順列にセットを使用するという決定により、有効な構成を見逃すことなく、すべての解決可能な順列が確実にキャプチャされます。
