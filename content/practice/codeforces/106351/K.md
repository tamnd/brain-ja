 ## 問題の理解

 正の整数の配列があります。 インデックスのペアをカウントする必要があります`(i, j)`どこ`i < j`そして、選択された 2 つの値は、2 つの数理論条件を同時に満たします。 それらの最大公約数は少なくとも`x`、それらの最小公倍数を超えてはなりません`y`。 タスクは、そのようなペアの数を出力することです。 

重要な制限は、配列の長さとすべての値が最大でも次の値であることです。`100000`。 これにより、すべてのペアを直接チェックすることが除外されます。`10^10`ペア。 値自体が次の制限を受けているという事実を利用する必要があります。`100000`これにより、インデックスの代わりに値の範囲にわたる前処理が可能になります。 

より大きい値を含むペア`y`2 つの正の整数の lcm は常に少なくとも両方の整数であるため、有効になることはあり得ません。 したがって、次の値を超えるすべての配列値を無視できます。`y`最初から。 

微妙なケースは、多くの値が等しい場合です。 たとえば、次の入力を使用します。```
3 2 10
4 4 4
```答えは次のとおりです。```
3
```3 つのペアすべてに gcd があります`4`そしてlcm`4`。 異なる値のみをカウントするソリューションでは、これらのペアが見逃されます。 

もう 1 つの注意が必要なケースは、gcd 条件と lcm 条件が相互作用する場合です。 例えば：```
2 5 6
10 15
```gcd は`5`これは十分な大きさですが、lcm は`30`、大きすぎます。 正しい答えは次のとおりです。```
0
```gcd のみまたは lcm のみをチェックすると、このペアが誤ってカウントされます。 

## アプローチ

 簡単なアプローチは、インデックスのすべてのペアを試し、gcd と lcm を計算して、条件を確認することです。 考えられるすべてのペアが検査されるため、これは正しいです。 ただし、`n = 100000`、これは周りで実行されます`5 * 10^9`制限時間を大幅に超えるペアチェック。 

重要な観察は、可能な値が小さいということです。 位置について考える代わりに、考えられる lcm 値について考えることができます。 すべての有効なペアには lcm があります`L`と`L <= y`、ペアの両方の数値が約数である必要があります。`L`。 数の約数の数は次のとおりです。`100000`は小さいため、考えられる各 lcm について、小さい候補セットを検査するだけで済みます。 

固定の場合`L`のすべての約数を集めます。`L`配列内に表示されるもの。 これらの約数間の任意のペアには、除算する lcm があります。`L`。 実際の lcm が正確であるペアのみを保持します`L`、そしてその gcd が少なくとも`x`。 

インデックスに対する総当り攻撃は、最大の数の約数に対するはるかに小さな列挙になります。`y`。

 ## アルゴリズムのチュートリアル

 1. 配列内に各値が出現する回数を数えます。 より大きい値`y`有効なペアの一部にはならないため、無視されます。 
2. 次のすべての数値の約数のリストを事前計算します。`1`に`y`。 これにより、指定された lcm とのペアに参加できるすべての可能な値をすばやく見つけることができます。 
3. 考えられるすべての lcm 値に対して反復します。`L`から`1`に`y`。 このために`L`、除算する値のみ`L`lcm が次のペアに出現する可能性があります`L`。 
4. すべての約数のペアについて`(a, b)`の`L`、計算します`gcd(a, b)`そして`lcm(a, b)`。 gcd が少なくとも`x`lcm は正確に`L`、これらの値によって形成されるインデックス ペアの数を加算します。 
5. 除数列挙内で等しい値を個別に処理します。 もし`a == b`、貢献度は`freq[a] * (freq[a] - 1) / 2`。 それ以外の場合、貢献度は`freq[a] * freq[b]`。 

なぜ効果があるのか:

 すべての有効なペアには 1 つの一意の lcm 値があります。 その lcm の反復中に、両方の値がその除数内に出現する必要があるため、ペアは 1 回だけ考慮されます。 gcd と lcm のチェックは元の要件と一致します。これは、カウントされたすべてのペアが有効であることを意味します。 他の lcm 反復では同じペアをカウントできないため、二重にカウントされることはありません。 

## Python ソリューション```python
import sys
from math import gcd

input = sys.stdin.readline

def solve():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return

    n, x, y = data[0], data[1], data[2]
    arr = data[3:3 + n]

    freq = [0] * (y + 1)
    for v in arr:
        if v <= y:
            freq[v] += 1

    divisors = [[] for _ in range(y + 1)]
    for d in range(1, y + 1):
        for m in range(d, y + 1, d):
            divisors[m].append(d)

    ans = 0

    for l in range(1, y + 1):
        divs = divisors[l]
        m = len(divs)

        for i in range(m):
            a = divs[i]
            if freq[a] == 0:
                continue

            for j in range(i, m):
                b = divs[j]
                if freq[b] == 0:
                    continue

                if gcd(a, b) < x:
                    continue

                if a // gcd(a, b) * b != l:
                    continue

                if a == b:
                    ans += freq[a] * (freq[a] - 1) // 2
                else:
                    ans += freq[a] * freq[b]

    print(ans)

if __name__ == "__main__":
    solve()
```頻度配列には、回答に現れる可能性のある値のみが保存されます。 これにより、すでに lcm 制限に違反している数値に時間を浪費することがなくなります。 

除数リストは、ふるいのようなループを使用して構築されます。 すべての約数の候補について、そのすべての倍数にそれを追加します。 このステップの後、`divisors[l]`lcm とペアを形成する可能性のある値が正確に含まれています`l`。 

メインループ内で、ペアの列挙は次から始まります。`i`ペアは順序付けされていないため、ゼロではなく。 これにより数を数える必要がなくなります`(a, b)`そして`(b, a)`別に。 lcmチェックでは以下を使用します。`a // gcd(a, b) * b`の代わりに`a * b // gcd(a, b)`固定サイズの整数を使用する言語でのオーバーフローの可能性を減らすため。 

同じ値の 2 つの出現を選択すると、2 つの異なる頻度の積ではなく組み合わせが作成されるため、値が等しい場合には特別な処理が必要です。

## テストケース```python
import sys
import io
from math import gcd

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return ""

    n, x, y = data[0], data[1], data[2]
    arr = data[3:3 + n]

    freq = [0] * (y + 1)
    for v in arr:
        if v <= y:
            freq[v] += 1

    divs = [[] for _ in range(y + 1)]
    for i in range(1, y + 1):
        for j in range(i, y + 1, i):
            divs[j].append(i)

    ans = 0
    for l in range(1, y + 1):
        d = divs[l]
        for i in range(len(d)):
            for j in range(i, len(d)):
                a, b = d[i], d[j]
                if freq[a] == 0 or freq[b] == 0:
                    continue
                g = gcd(a, b)
                if g >= x and a // g * b == l:
                    if a == b:
                        ans += freq[a] * (freq[a] - 1) // 2
                    else:
                        ans += freq[a] * freq[b]
    return str(ans) + "\n"
