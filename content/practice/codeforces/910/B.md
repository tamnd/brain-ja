 ## 解決策
 ## 問題の理解

 Petya が _n_ の長さの均一な木製の棒を使用して 2 つの同一のドアフレームを構築したいというワークショップのシナリオがあります。 各ドア フレームは、長さ _a_ の 2 つの垂直側面と、長さ _b_ の水平上部 1 つの 3 つの側面で構成されます。 すべての面は連続した切れ目のない部分である必要があるため、1 つの面を複数の小さな部分に切断することは許可されません。 課題は、2 つのドアの 6 面すべてを切り出すのに必要な全長バーの最小数を把握することです。 

入力により、各バーの長さと、必要な垂直辺と水平辺の長さが与えられます。 出力は、要件を満たすことができるバーの最小整数です。 

制約は小さく、_n_ ≤ 1000 および _a_、_b_ ≤ _n_ です。 これにより、必要なバーの総数が制限され、いくつかのオプションを徹底的にチェックすることが可能になるため、バーを切断するあらゆる方法を考慮したアルゴリズムを使用することができます。 厄介な点は、それぞれの側が固体の部分を維持する必要があるという事実から来ており、単純な分割では不十分です。 不注意な解決策では、不可分性の要件を無視して、単純に必要な長さの合計を計算して _n_ で割る可能性があります。 たとえば、_n_ = 3、_a_ = 2、_b_ = 2 の場合、必要な全長は 6 で、これは 2 つのバーに収まるように見えますが、1 つのバーで長さ 2 の部分を 2 つ提供し、なおかつ反対側に十分な長さを残すことはできません。 正解は3小節です。 

## アプローチ

 強引なアプローチは、6 つの辺をいくつかのバーに分散するあらゆる方法を試し、それぞれの組み合わせをチェックしてピースが適合するかどうかを確認することです。 すべてのバーに 0 ～ 3 の辺を割り当て (最長の辺は _n_ までである可能性があるため)、バーの辺の長さの合計が _n_ を超えるかどうかを計算し、バーの合計をカウントします。 正しいとはいえ、このアプローチはこのような小さな問題には過剰であり、制約があるため機能するとしても実装が面倒になります。 

重要な洞察は、_a_ と _b_ という 2 つの異なる長さしかなく、ピースの数が非常に少ない (6) ということです。 これにより、長さ _a_ と長さ _b_ の辺の特定の数を各バーに貪欲に割り当て、最初のバーについて可能なすべての分割を試し、必要なバーの数を検討することができます。 最初の小節を割り当てたら、残りの辺をできるだけ少ない小節に詰めることができます。 _n_ ≤ 1000 で辺が 6 つしか存在しないため、最初のバーで _a_ の長さの辺の可能な数をすべて試し、残りのスペースを計算し、残りを貪欲に詰め込むことができます。 選択肢が非常に少ないため、これによりグローバル最小値が見つかることが保証されます。 基本的に、問題を実現可能な分割に関する小さな検索に縮小します。

 | 貪欲 / 小さな検索 | お(1) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 側面の合計数を計算します: 2 つのドアの場合、垂直側面 4 つと水平側面 2 つです。 させて`count_a = 4`そして`count_b = 2`。 
2. 変数を初期化する`min_bars`見つかった最小限のバーを保存する大きな数値に設定します。 
3. 考えられるすべての数の垂直辺を反復します。`x`最初のバーを 0 から min(`count_a`、 床（`n`/`a`））。 これにより、最初のバーに長さの辺がいくつ含まれるかが決まります。 それぞれについて`x`、使用されるスペースを計算します。`used_space = x * a`。 
4. 最初のバーの残りのスペースを、長さ _b_ のできるだけ多くの水平辺で埋めます。`y = min(count_b, floor((n - used_space) / b))`。 
5. 残りの辺の数を計算します。`remaining_a = count_a - x`、`remaining_b = count_b - y`。 
6. 残りの側面に必要な追加のバーの数を計算します。 各バーは最大まで収まります`floor(n / a)`垂直側面と`floor(n / b)`水平方向の側面。 上限のある整数除算を使用します。`ceil(remaining_a / floor(n / a)) + ceil(remaining_b / floor(n / b))`。 
7.アップデート`min_bars`と`1 + bars_for_remaining_sides`現在の値より小さい場合。 
8. できる限りのことを試した後`x`最初のバーで出力`min_bars`。 

機能する理由: 各バーは、垂直辺と水平辺の組み合わせを担っていると見なされます。 最初のバーのすべての可能性を列挙することで、残りの辺が最小限に抑えられ、効率的にパックされるようになります。 辺が 6 つしかなく、バーは少なくとも 1 つの辺を保持するのに十分な長さがあるため、この最初のバーの徹底的な割り当てにより、最小限の解決策が保証されます。 

## Python ソリューション```python
import sys
import math
input = sys.stdin.readline

n = int(input())
a = int(input())
b = int(input())

count_a = 4
count_b = 2

max_a_per_bar = n // a
max_b_per_bar = n // b

min_bars = 1000  # large initial value

for x in range(min(count_a, max_a_per_bar) + 1):
    used_space = x * a
    y = min(count_b, (n - used_space) // b)
    
    remaining_a = count_a - x
    remaining_b = count_b - y
    
    bars_for_remaining_a = (remaining_a + max_a_per_bar - 1) // max_a_per_bar if max_a_per_bar else remaining_a
    bars_for_remaining_b = (remaining_b + max_b_per_bar - 1) // max_b_per_bar if max_b_per_bar else remaining_b
    
    total_bars = 1 + bars_for_remaining_a + bars_for_remaining_b
    min_bars = min(min_bars, total_bars)

print(min_bars)
```このソリューションでは、最初に最初のバーに収まる垂直方向と水平方向の辺の数を計算します。 次に、天井分割を使用して、残りの辺に必要なバーの数を計算します。 の`if max_a_per_bar else remaining_a`辺がバーよりも長いというエッジ ケースを処理します。これは制約により発生しませんが、安全性が向上します。 すべてのオプションにわたってバーの最小数を追跡します。
