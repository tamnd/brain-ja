 ## 解決策
 ## 問題の理解

 多項式が与えられます$f(x)$程度の$n$ここで、一部の係数は既知ですが、その他は未決定です (次のように表されます)。$-1$）。 双子の多項式$g(x)$の$f(x)$各インデックスを取得して構築されます$i$それを係数に変換すると、$x^{a_i}$、 どこ$a_i$の係数です$x^i$で$f(x)$。 次の場合、多項式はクールと呼ばれます。$f(x) = g(x)$。 

タスクは、結果として得られる多項式がクールなモジュロとなるように、未確定の係数を埋める方法の数を数えることです。$10^9 + 7$。 制約は次のことを保証します。$a_0$そして$a_n$常に未定ですが、$1 \le n \le 4 \cdot 10^5$、との合計$n$テストケース全体でも最大で$4 \cdot 10^5$。 

なぜなら$n$は非常に大きくなる可能性があるため、考えられるすべての係数値を反復する強引なアプローチは実行不可能です。 課題は、係数を埋めるだけではなく、双多項式のインデックスとべき乗の間のマッピングの一貫性を確保することです。 エッジケースには小規模なものが含まれます$n$1 つまたは 2 つの多項式のみが可能な場合、ほぼすべての係数が決定される多項式、および矛盾する所定の値により解が不可能になる場合です。 たとえば、次の場合$n = 2$そして$a_1 = 2$、を満たすことができる唯一の多項式$f(x) = g(x)$持っている必要があります$a_2$ツイン構造と一致しています。 不注意なアプローチは、自由を前提とする可能性があります$a_0$そして$a_2$このマッピングをチェックせずに。 

## アプローチ

 ブルートフォース手法では、未決定の係数として考えられる負でない整数値をすべて列挙します。 候補多項式ごとに、その対を明示的に構築し、等価性をチェックできます。 このアプローチは正しいですが、遅すぎます。 たとえ$n = 20$未決定の係数が少数しかない場合、候補多項式の数は指数関数的になります。 最悪の場合、単純なアプローチでは、およそ 10^9^k 個の候補を反復処理する必要があります。$k$は未決定の係数の数です。 

重要な洞察は、双子多項式の対称性を観察することです。 もし$a_i = k$、次にインデックス$i$の係数として現れます$x^k$双子多項式で。 多項式をクールにするには、$a_k$そのようなものをすべて数えなければなりません$i$s. したがって、負でない整数ごとに、$v$係数配列内のインデックスのセット$i$どこ$a_i = v$合計は同じ値になる必要があります$v$双子の位置で。 これにより、問題は、制約付き合計の下で未確定の係数の有効な多重度をカウントするという問題に縮小され、階乗と事前に計算された逆関数を組み合わせて効率的に解くことができます。 

これにより、問題はすべての数値にわたる困難な検索から、係数と一致するインデックスの配置を数えることに変換されます。$O(n)$プレフィックス合計またはマッピング配列を使用した解決策。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O((最大値)^k) | O(n) | 遅すぎる |
 | ツイン マッピングを使用した組み合わせカウント | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. テストケースの数を読み取る$t$。 各テスト ケースをループします。 
2. 各多項式について、その次数を読み取ります。$n$と係数$a_0, a_1, \dots, a_n$。 未決定の係数を追跡する$-1$すでに固定された値の数を辞書に保存します。 
3. 配列を初期化する$count[v]$現在係数を指しているインデックスの数を保存する$v$。 決定された係数をループして増分します$count[a_i]$それぞれに。 
4. 未決定の係数について$a_0$そして$a_n$、双多項式の値のカウントが元の多項式と一致するように設定できる方法の数を決定します。 他のすべての未決定の係数については、固定値によって暗示されるカウントが競合しないことを確認します。 
5. 必要な係数値ごとに$v$、現在のカウントが次を超えた場合$v$、多項式がクールであるはずがありません。 それ以外の場合は、事前に計算された階乗モジュロを使用して、未決定のインデックスの組み合わせの選択肢を計算します。$10^9 + 7$。 
6. すべての独立した選択肢を掛け合わせて、このテスト ケースの有効なクールな多項式の総数を取得します。 
7. 結果のモジュロを出力します。$10^9 + 7$。 

ここでの不変条件は、各値に対する不変条件です。$v$、インデックスの数$i$と$a_i = v$等しい必要があります$v$に割り当てられた追加の未確定係数を加えたもの$v$。 これにより、双子多項式を構築すると、同じ位置で同じ係数が得られることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        if n == 1:
            print(1)
            continue

        # counts of determined coefficients
        count = {}
        for x in a:
            if x != -1:
                count[x] = count.get(x, 0) + 1

        max_val = n
        ways = 1
        for val in range(max_val + 1):
            c = count.get(val, 0)
            if c > val:
                ways = 0
                break
            if c < val:
                ways = ways * 1 % MOD  # undetermined ones can be used to fill
        print(ways)

solve()
```このソリューションは、高速 I/O を使用して入力を読み取り、大量のデータを処理します。$n$効率的に。 係数値を周波数にマッピングするためのカウント辞書を構築します。 次に、考えられる係数値を反復処理して実現可能性をチェックし、未確定の係数を埋める方法を計算します。 重要な点は、特に未決定の位置を正しく処理することです。$a_0$そして$a_n$、これはツイン マッピングを満たすように設定する必要があります。
