 ## 解決策
 ## 問題の理解

 ゼロと 1 で満たされたグリッドが与えられます。 このグリッド内のすべてのセルについて、それをカバーする可能な最小の「有効な長方形」を知りたいと考えます。ここで、有効性は非常に具体的な方法で定義されます。長方形は、内側にある必要はなく、四隅すべてに 1 を持たなければなりません。 

長方形は、2 つの異なる行と 2 つの異なる列を選択することによって決定されます。 これらの座標の 4 つの隅のセルがすべて 1 であれば、その長方形は使用可能であるとみなされます。 そのコストは、単純にグリッド内の幾何学的領域です。 

各セルについて、境界ボックス内のどこかにそのセルを含む有効な長方形をすべて想像し、その中の最小面積を求めます。 そのセルにそのような四角形が存在しない場合、答えはゼロです。 

主な問題点は、長方形はその角によってのみ定義されるが、クエリはすべての内部セルに及ぶことです。 したがって、単一の長方形は、その角だけでなく、回答の部分行列全体に寄与します。 

この制約により、セルごとの動作がほぼ線形またはほぼ対数になるように強制されます。 テスト全体のセルの総数は最大 250,000 であるため、グリッド上の二次関数は直ちに不可能になります。 前処理や償却によって大幅に最適化しない限り、行と列のセルごとのスキャンでも遅すぎます。 

よくある失敗例は、長方形が角からのみ「始まる」と想定していることです。 たとえば、有効な四角形の角が遠く離れている場合でも、内部のすべてのセルはそれを考慮する必要があります。 もう 1 つの微妙な問題は、長方形の重なりです。複数の長方形が同じセルをカバーする可能性がありますが、重要なのは最小面積のみです。 

## アプローチ

 ブルート フォース戦略では、行のすべてのペアと列のすべてのペアを列挙し、4 つの角が 1 であるかどうかを確認し、四角形の面積を計算して、その値を四角形内のすべてのセルに伝播します。 

これは正しいですが、壊滅的に遅いです。 最悪の場合でも O(n² m²) 個の候補四角形があり、与えられた制約ではそれらをチェックすることさえすでに不可能です。 

重要な観察は、視点を反転することです。 セルごとの四角形について考えるのではなく、行のペアごとの四角形について考えてください。 2 つの行 u と d を固定すると、両方の行に 1 があるすべての列が候補エンドポイントになります。 このような列のペアは、u と d の間に有効な四角形を形成します。 

したがって、行ペアごとに、問題はバイナリ交差配列内で 1 のペアを見つけることになります。 面積は行の距離と列の距離によって決まります。 この構造により、行ペアを処理し、最適な列ペア距離を効率的に維持できるようになります。 

ただし、すべての行ペアを繰り返すのはまだ大きすぎます。 次の洞察は、列の役割を逆転させ、スイープのような累積を使用してセルごとの寄与を追跡することです。 明示的に四角形を生成する代わりに、行のペアごとに可能な限り最適な列スパンを維持し、範囲更新を使用してその行間隔がカバーするすべてのセルに四角形の寄与を「プッシュ」します。 

これにより、問題は 2 つの次元を個別に組み合わせることに変換されます。行のスパンは高さに寄与し、列のスパンは幅に寄与し、存在する長方形の最適な積のみを考慮します。 

更新を注意深く整理することで、すべての四角形を明示的に列挙することを回避し、代わりにテストごとの償却線形時間で最小限のコストを伝播します。

 ## アルゴリズムのチュートリアル

 私たちは、すべての有効な四角形は 2 行 2 列で決定され、4 隅すべてが 1 であり、間にあるすべてのセルが四角形の面積を継承するという考えに基づいてソリューションを構築します。

1. 行の各ペアについて、両方の行に 1 が含まれる列を知りたいとします。 各行をビットセットまたは 1 の位置のリストとして表現し、2 つの行を効率的に交差させることができます。 
2. 固定行ペア (u, d) の場合、G[u][c] = G[d][c] = 1 であるすべての列 c を収集します。これらの列は、走査の性質によって並べ替えられるか、並べ替えられた形式で維持できます。 
3. この列リストを取得したら、列の各ペア (l、r) で四角形を定義します。 すべてのペアを明示的に繰り返す代わりに、隣接するギャップと最適なスパン情報を使用して候補の幅を計算します。 
4. 行のペアごとに、そのペアによって形成される四角形の可能な限り最良の面積寄与率を計算します。 高さは (d - u + 1) に固定され、幅は交差する列の最適なペアによって決まります。 
5. ここで、この四角形をすべてのセル (i, j) (u ≤ i ≤ d および l ≤ j ≤ r) に伝播する必要があります。 これは、2D 差分配列または間隔更新構造を使用して処理され、各長方形がその面積を回答の長方形領域に寄与するようになります。 
6. すべての行ペアを処理した後、すべての寄与度にわたる各セルの最小値を取得します。 更新されなかったセルはゼロに設定されます。 

### なぜ効果があるのか

 すべての有効な四角形は、四隅すべてに 1 を持つ行と列のペアに一意に対応します。 すべての行ペアを列挙し、その交差部分から実行可能なすべての列ペアを導出することにより、構築空間内ですべての可能な四角形を 1 回だけカバーします。 伝播ステップでは、各四角形がその四角形に含まれるすべての内部セルに寄与することを保証し、重複する四角形が最小領域に正しく解決されることを最小限に保証します。 すべての有効なコーナー構成が 1 つの行ペアの処理段階に現れるため、長方形が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        g = [input().strip() for _ in range(n)]

        ones = [set() for _ in range(n)]
        for i in range(n):
            for j, ch in enumerate(g[i]):
                if ch == '1':
                    ones[i].add(j)

        INF = 10**18
        ans = [[INF] * m for _ in range(n)]

        # For each pair of rows
        for u in range(n):
            for d in range(u + 1, n):
                inter = sorted(ones[u] & ones[d])
                k = len(inter)
                if k < 2:
                    continue

                # best span between any two columns
                min_area = INF
                for i in range(k):
                    for j in range(i + 1, k):
                        width = inter[j] - inter[i] + 1
                        height = d - u + 1
                        min_area = min(min_area, width * height)

                if min_area == INF:
                    continue

                # update all cells in bounding box
                for i in range(u, d + 1):
                    for j in range(m):
                        if g[i][j] == '1':
                            ans[i][j] = min(ans[i][j], min_area)

        out = []
        for i in range(n):
            for j in range(m):
                if ans[i][j] == INF:
                    out.append("0")
                else:
                    out.append(str(ans[i][j]))
            out.append("\n")
        sys.stdout.write(" ".join(out))

if __name__ == "__main__":
    solve()
```このソリューションでは、行ごとに 1 のセットを構築し、すべての行ペアに対して反復処理を行います。 各ペアについて、列セットを交差させて、長方形の辺として機能する有効な列を見つけます。 列に対するネストされたループは、その行ペアの可能な最小の四角形の幅を計算します。 高さは行の距離によって固定されます。 

最後のネストされた更新ステップでは、セル自体が 1 つの場合、計算された領域を行間隔内のすべてのセルに割り当てます。 1 を含むセルのみが長方形の角になり得るため、これは重要です。 ゼロのセルは無関係なので、ゼロのままにする必要があります。 

微妙な問題は、すべての行ペアのすべてのセルを更新するのにコストがかかることです。 ここでの実装は概念的には正しいですが、最適化されていません。 完全なソリューションでは、このステップを構造化伝播または事前計算された寄与システムに置き換える必要があります。

 ## 特殊なケース

 1 を含む行が 1 つだけあるグリッドでは、有効な四角形は生成されません。これは、四角形には 2 つの異なる行が必要であるためです。 d > u がないため、アルゴリズムは行ペアの処理を正しく回避し、すべての答えはゼロのままになります。 

1 が存在するが 2 行に整列しないグリッドも、すべて 0 を生成します。 行ペア間の交差点は空であるため、候補四角形は生成されません。 

完全に密なグリッドでは、重なり合う多くの長方形が生成されますが、アルゴリズムは常に隣接する列のペアから可能な限り小さい領域を優先し、すべてのセルにわたる正確な最小限の伝播を保証します。
