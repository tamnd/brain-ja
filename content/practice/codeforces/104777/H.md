 ## 問題の理解

 長さの配列を数えています`n`ここで、各要素は負ではない整数ですが、任意の配列ではありません。 2 つの制限によって、何が許可されるかが決まります。 まず、連続する値間の絶対差が最大以下であるという意味で、要素の隣接するすべてのペアが近くなければなりません。`k`。 これにより、配列は各ステップが最大で移動できるウォークのように動作するように強制されます。`k`ユニットを上下に動かします。 

次に、配列は特定の値範囲に「接触」する必要があります。少なくとも 1 つの要素がその範囲内に存在する必要があります。`[x, x + k - 1]`。 したがって、単に境界付きステップ ウォークをカウントしているのではなく、特定の値のウィンドウに少なくとも 1 回アクセスするウォークをカウントしています。 

難しさはサイズから来ます`n`そして`k`。 どちらも次のような大きさにすることができます`10^9`したがって、配列の位置を反復する解決策は不可能です。 値は時間の経過とともに際限なく変動する可能性があるため、素朴な DP の感覚で考えると、可能な値の範囲を保存することすら実現できません。 しかし、`x`は小さく、最大でも 40 です。これは、問題の構造が絶対値ではなく、このウィンドウの周囲の相対位置の追跡に依存していることを強く示唆しています。 

有効なステップバイステップの歩行をすべて数えてから、決して入力されなかった歩行を減算しようとすると、微妙な失敗のケースが発生します。`[x, x+k-1]`。 代わりに、制約なしですべての有効な歩行のみをカウントした場合でも、ステップ制限を尊重しながら値が任意に変動する可能性があるため、無限の状態空間に直面することになります。 もう 1 つの単純な間違いは、値を次のように制限しようとすることです。`[x-k*n, x+k*n]`これは技術的には正しいですが、大きすぎます。 

重要な課題は、値には制限がないにもかかわらず、制約が存在することです。`|ai - ai-1| ≤ k`構造を局所的にし、唯一の「重要な」領域は禁制帯の周囲にあります`[x, x+k-1]`。 

## アプローチ

 「必ず訪問する必要がある」を無視すると、`[x, x+k-1]`」状態の場合、問題は長さを数えることになります-`n`最大でもステップ差のあるシーケンス`k`。 状態空間は無限であるため、これはすでに自明ではありません。 ただし、遷移ルール​​は変換不変です。つまり、すべての値を定数でシフトしても有効性は変わりません。 これは、絶対値は無関係であり、差異のみが重要であることを示唆しています。 

ブルートフォースアプローチでは、到達可能なすべての値に対して動的プログラミングを実行しようとします。 開始値から、各ステップは最大で次のように分岐します。`2k+1`選択肢があるので、その後`n`ステップごとにパスの数は次のように増加します`(2k+1)^n`、小さいものでも天文学的な大きさです。`n`。 値は際限なく変動するため、状態を保存することさえ不可能です。 

重要な洞察は、値について考えるのをやめ、代わりに禁止された窓に関連した構造について考えることです。 正確な値を追跡する代わりに、歩行がすでにその間隔に入っているかどうかを追跡します。`[x, x+k-1]`。 これにより、問題は 2 層の計数問題に変わります。有効な歩行をすべて数えてから、間隔を完全に回避した歩行を減算します。

 ## アルゴリズムのチュートリアル

 すべての有効な歩行をカウントし、間隔に触れない歩行を減算するという問題を再定式化します。`[x, x+k-1]`。 

1. まず、有効な長さの配列をすべて数えます。`n`間隔内の訪問に制限はありません。 これは、最大ステップ サイズの整数に対する変換不変ウォークです。`k`。 このようなウォークの数は、前の値と比較して各ステップにどれだけの選択肢があるかによってのみ依存するため、これをステップ遷移にわたる線形反復として扱います。 
2. 次に、禁止された散歩、決して訪れてはいけない散歩を分類します。`[x, x+k-1]`。 このようなウォークはすべて、2 つの互いに素な領域 (すべての値) のいずれかに完全に存在する必要があります。`< x`またはすべての値`> x+k-1`。 歩行がこれらの領域のいずれかに入ると、回避条件に違反せずにその区間に入ることができなくなります。 
3. 厳密に以下にとどまるように制約された四球数を計算します。`x`。 これは、ハードシーリングで制限された歩行をカウントするのと同等になります。`x-1`。 トランジションでは最大でもジャンプが許可されるため、`k`、有効な状態は、境界までの距離で切り捨てられます。`k`意味のあるレベル。 
4. 同様に、厳密に上記を超えた歩数を計算します。`x+k-1`。 対称性により、これは前の計算と同じです。 
5. 合計カウントから 2 つの禁止カウントを差し引きます。 結果は、その間隔に少なくとも 1 回アクセスする有効な配列の数です。 

### なぜ効果があるのか

 正確さは、すべての有効なウォークの空間を 3 つの互いに素なクラスに分割することによって得られます。つまり、間隔より下に留まるクラス、間隔より上に留まるクラス、少なくとも 1 回間隔に触れるクラスです。 これらのクラスは互いに素であり、あらゆる可能性をカバーします。 最初の 2 つは対称であり、吸収境界を持つ制約付きウォークとして計算可能です。 分解により過剰カウントが発生しないことが保証され、ステップ ルールの変換不変性により、境界の配置がカウントに影響を与える唯一の要素であることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, x, k = map(int, input().split())

        # We only need the fact that the walk is translation invariant.
        # Count total walks: each step has (2k+1) choices relative to previous.
        # So total = (2k+1)^(n-1).
        #
        # Forbidden walks are those that never enter [x, x+k-1].
        # Because the interval has length k and step size is k,
        # such walks split into two symmetric classes:
        # entirely below or entirely above.
        #
        # Each class behaves like a walk with a hard boundary,
        # yielding the same count as total walks on a half-line,
        # which equals k^(n-1) in relative transitions.

        if n == 1:
            # Single element array: valid iff it lies in interval.
            # There are k choices inside [x, x+k-1].
            print(k % MOD)
            continue

        total = pow(2 * k + 1, n - 1, MOD)
        forbidden = (2 * pow(k, n - 1, MOD)) % MOD
        ans = (total - forbidden) % MOD
        print(ans)

if __name__ == "__main__":
    solve()
```実装は自明なケースを分離します`n = 1`ここで、答えは単に区間内の有効な値の数です。 大型の場合`n`の場合、計算はステップごとに利用可能な遷移の数の累乗に依存します。 合計数は、どの位置からでも正確に`2k+1`有効な次の値。 

減算項は、区間に入らないシーケンスを削除します。 上下に 2 つの対称的なケースがあり、それぞれ変換下で同じように動作し、係数は 2 になります。このような制限付きウォークはそれぞれフリー ウォークのように動作しますが、実効分岐係数が 2 に減少します。`k`、インターバルを横切ることは許可されていないためです。 

べき乗剰余演算の使用は不可欠です。`n`と同じ大きさにすることができます`10^9`、直接の反復は不可能です。
