 ## 問題の理解

 無限の整数グリッド上を移動する一般化されたナイトの駒が与えられています。 どの細胞からでも$(x,y)$、ベクトルを並べ替えて反転することで得られる 8 つの対称位置にジャンプできます。$(p,q)$そして$(q,p)$独立した符号の変化を伴います。 これは、各移動が固定ステップ形状の構造を維持しながら、平面内での完全な回転と反射が可能であることを意味します。

 タスクは、原点から開始するかどうかを判断することです。$(0,0)$、目標点に到達できます$(x,y)$このような動きをいくつでも使用できます。 

制約により、最大で$10^4$までの座標を含むクエリ$10^9$規模的には。 これは、あらゆる解法がテスト ケースごとに一定時間である必要があることを強く示唆しています。$O(\sqrt{|x|+|y|})$最悪の場合、クエリごとの推論が遅すぎる可能性があります。 

この問題の微妙な点は、到達可能性が移動ベクトルの算術構造に大きく依存することです。 最短経路や BFS 定式化とは異なり、グリッドは無限かつ対称であるため、答えは検索ではなく数論的な不変量によって完全に決定されます。 

主なエッジケースは、次のいずれかの場合に発生します。$p$または$q$がゼロの場合、または$p = q$、移動セットが対称的に縮退したり、方向が崩れたりするためです。 たとえば、次の場合$p = q = 0$、騎士は決して動かないので、$(0,0)$到達可能です。 もし$p = 0$、ナイトは軸に沿ったストライプに沿ってのみ移動し、パリティ制約が決定的になります。 

もう 1 つの重要なエッジ ケースはパリティ障害です。 たとえば、$(1,2)$-knight は、両方の座標が gcd のような構造で個別に割り切れる場合でも、すべての格子点に到達することはできません。これは、座標のパリティによって引き起こされるグリッドの色が移動しても保持されるためです。 

## アプローチ

 ブルートフォース解釈では、あらゆる可能性のあるウォークをシミュレートします。$(0,0)$、無限グリッド上で BFS を実行します。 各ノードは最大 8 つの隣接ノードに拡張されるため、$k$私たちが探求するステップ$8^k$最悪の場合は状態。 座標は次のように大きくできるため、$10^9$、意味のあるターゲットには膨大な数のステップが必要となる可能性があり、このアプローチは実行不可能になります。 

重要な観察は、移動セットがラティスを形成していることです。$\mathbb{Z}^2$。 すべての動きでセットからベクトルが追加されます$$(\pm p, \pm q), (\pm q, \pm p)$$したがって、到達可能な点は、これらのベクトルのすべての整数線形結合を形成します。 これにより、問題は次のことを確認するだけになります。$(x,y)$は、これらの動きによって生成された追加サブグループ内にあります。 

パスを探索する代わりに、この格子の不変条件を分析します。 2 つの独立した制約が現れます。 

まず、すべての動きは次のように割り切れます。$g = \gcd(p,q)$。 すべての動きの両方の座標は次の倍数です。$g$したがって、到達可能な点はいずれも満たす必要があります。$x \equiv 0 \pmod g$そして$y \equiv 0 \pmod g$。 

次に、すべてを次のように割った後、$g$、我々は互いに素のペアに還元します$(a,b)$と$\gcd(a,b)=1$。 この正規化されたシステムでは、構造はパリティと縮退のみに依存します。 

両方の場合$a$そして$b$がゼロでなく等しくない場合、生成される格子はすべて、パリティ条件が到達可能な組み合わせのパリティと一致する整数点になります。 実際、次のことを示すことができます。$(x',y')$到達可能な場合$(x'+y') \bmod 2 = 0$、各移動が制御された方法でパリティを変更するためです。 

いつ$a = b$、移動は斜め方向に折りたたまれ、到達可能なポイントが線に制限されます。$x' \pm y' = \text{constant}$。 

いずれかのとき$a,b$がゼロの場合、動きは軸に沿って整列し、到達可能性は軸に沿った独立した 1 次元の可分性をチェックすることになります。

 ## アルゴリズムのチュートリアル

 1. コンピューティング$g = \gcd(p,q)$。 両方の場合$p$そして$q$がゼロの場合、到達可能な点は原点だけです。 それ以外のクエリは不可能です。 
2. スケーリングによって問題を軽減します: set$p = p/g$、$q = q/g$、同様にそれを確認します$x$そして$y$で割り切れる必要があります$g$。 どちらかの座標が割り切れない場合は、「No」を返します。 これは、すべての移動が次の可算性を維持するためです。$g$。 
3. 座標の正規化: 定義$x' = x/g$、$y' = y/g$。 ここからは、共素系のみで推論します。 
4. もし$p = 0$、その後、騎士は垂直方向と水平方向にのみ次のステップで移動します。$q$。 これは、一方の座標が他方の方向のステップ構造を法として不変のままであることを意味します。 到達可能性は、次のことを確認することに帰着します。$x'$で割り切れます$q$そして$y'$で割り切れます$q$、動きは軸に沿って行われるため。 
5. もし$p = q$、すべての動きはフォームの斜めのステップに減ります$(\pm p, \pm p)$。 これにより、到達可能なポイントが満足のいくものに制限されます$x' \equiv y' \pmod{2p}$、これは要求を単純化します$x' \equiv y' \pmod 2$。 
6. どちらの縮退も成立しない場合は、完全な格子が生成されます。 この場合、パリティが唯一の障害になります。移動するたびに合計が変化します。$x+y$偶数ずつなので、$x' + y'$到達可能性のためには均等である必要があります。 
7. すべての条件が満たされている場合は「Yes」を返し、そうでない場合は「No」を返します。 

### なぜ効果があるのか

 到達可能なセットは、次の追加サブグループを形成します。$\mathbb{Z}^2$から導出された対称ベクトルによって生成される$(p,q)$。 このようなサブグループは、線形可分性制約とパリティ不変式によって完全に特徴付けられます。 gcd リダクションはスケーリングを分離しますが、残りの構造は、基底ベクトルが完全な整数格子に及ぶか、パリティまたは対角制限のある部分格子に及ぶかによって決まります。 すべての手がこれらの不変条件を保持し、それらを満たす任意の点は整数の組み合わせによって構築できるため、条件は必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from math import gcd

def solve():
    T = int(input())
    for _ in range(T):
        p, q, x, y = map(int, input().split())

        if p == 0 and q == 0:
            print("Yes" if x == 0 and y == 0 else "No")
            continue

        g = gcd(abs(p), abs(q))
        if x % g != 0 or y % g != 0:
            print("No")
            continue

        x //= g
        y //= g
        p //= g
        q //= g

        # normalize absolute structure
        p, q = abs(p), abs(q)

        if p == 0:
            # moves are (0, ±q) and (±q, 0)
            print("Yes" if x % q == 0 and y % q == 0 else "No")
        elif p == q:
            # diagonal lattice
            print("Yes" if (x - y) % 2 == 0 else "No")
        else:
            # general case: parity constraint
            print("Yes" if (x + y) % 2 == 0 else "No")

if __name__ == "__main__":
    solve()
```実装は、些細な不動のケースを処理することから始まります。 gcd リダクションは、グローバル スケーリング制約を早期に強制するため、座標がステップ ラティスと互換性がない場合の誤検知を防止します。 

ケース$p = 0$移動セットは軸に沿ったジャンプに折りたたまれ、到達可能性が純粋に割り算ベースになるため、別個に扱われます。 

いつ$p = q$、すべての動きは対角線上にあるため、不変式は正規化後の座標パリティの等価性になります。 

他のすべてのケースは、対称ムーブ セットが到達可能なポイントに単一のパリティ制約を持つフルランク ラティスにまたがるという事実に依存します。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from math import gcd

    def solve():
        T = int(input())
        out = []
        for _ in range(T):
            p, q, x, y = map(int, input().split())
            if p == 0 and q == 0:
                out.append("Yes" if x == 0 and y == 0 else "No")
                continue
            g = gcd(abs(p), abs(q))
            if x % g != 0 or y % g != 0:
                out.append("No")
                continue
            x2, y2 = x // g, y // g
            p2, q2 = abs(p // g), abs(q // g)
            if p2 == 0:
                out.append("Yes" if x2 % q2 == 0 and y2 % q2 == 0 else "No")
            elif p2 == q2:
                out.append("Yes" if (x2 - y2) % 2 == 0 else "No")
            else:
                out.append("Yes" if (x2 + y2) % 2 == 0 else "No")
        return "\n".join(out)

    return solve()

# provided samples

# custom cases
assert run("1\n0 0 1 1\n") == "No"
assert run("1\n1 0 2 3\n") == "No"
assert run("1\n2 2 4 4\n") == "Yes"
assert run("1\n1 2 3 5\n") in ["Yes", "No"]

 ## 特殊なケース

 いつ$p = q = 0$の場合、アルゴリズムは次の場合にのみすぐに「はい」を返します。$(0,0)$。 他の点では、移動がまったく不可能なため、すべての不変条件が失敗します。 

いつ$p = 0$、コードは軸に沿った分岐に入ります。 たとえば、入力の場合$(0,3)$、到達$(6,9)$両方の座標が 3 の倍数であるため成功しますが、$(5,9)$x が 3 で割り切れないため、すぐに失敗します。 

いつ$p = q$、 のような$(2,2)$、移動は対角線に制限されます。 みたいなポイント$(4,4)$以来経過$x-y=0$、 その間$(4,5)$正規化後にパリティの対称性が崩れるため、失敗します。 

一般的な場合、たとえば、$(1,3)$、パリティ チェックにより、到達不能なポイントがフィルタリングされます。 のために$(2,4)$、合計が偶数であるため合格しますが、$(1,2)$パリティ副格子の外側にあるため失敗します。
