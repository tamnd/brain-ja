 ## 問題の理解

 1 から 1 までのラベルが付いた人々のセットが与えられます。$n$、 しかし$n$は非常に大きくなる可能性があるため、すべての個人に対して明示的に構造を構築する余裕はありません。 代わりに、入力により次のことが得られます$m$圧縮された形式で友情を記述するルール: 各ルールは特定の人について述べます。$x$インターバル全体のすべての人と友達です$[L, R]$。 

友情は相互的なものであるため、各ルールは事実上、相互間に無向エッジを追加します。$x$そしてすべてのノード$[L, R]$。 これらすべてのエッジを想像すると、ネットワークは接続されたコンポーネントに分割されます。 ハリーはメッセージを受信する最初の人を何人か選ぶことができ、その後メッセージは接続されたコンポーネント全体に到達するまで友情エッジを介して広がります。 タスクは、最初の送信者の最小数を計算することです。これは、この暗黙的なグラフ内の接続コンポーネントの数と正確に一致します。 

主な難点は、$n$までです$10^{12}$したがって、ノードを明示的に表現したり、頂点に対して標準のグラフ走査を実行したりすることはできません。 この構造は完全にインターバル接続によって定義されるため、本当の課題は、オーバーラップするインターバルやポイントツーインターバル リンクによって引き起こされる接続を圧縮することです。 

制約に関する重要な洞察は次のとおりです。$m$までです$2 \cdot 10^5$。 これにより、すべてのノードを反復したり、間隔をエッジに拡張したりするアプローチは即座に除外されます。 有効な解決策はどれもおおよその範囲で機能する必要があります。$O(m \log m)$または$O(m)$、エンドポイントと間隔のインタラクションのみを使用して接続を表す必要があります。 

素朴な解釈では、それぞれを明示的に結び付けようとします。$x_i$すべてのノードに$[L_i, R_i]$、次に BFS/DSU を実行します。 これは両方とも失敗します。$10^{12}$最悪の場合はエッジが発生し、間隔を超えて反復することさえ不可能になるためです。 

各ルールを整数の独立した間隔として処理しようとすると、より微妙な失敗例が発生し、ポイントを考慮せずに貪欲に重複をマージします。$x_i$。 たとえば、間隔をマージするだけの場合、$[L, R]$、接続が常に特定のアンカー ノードを介して仲介されるという事実が失われます。$x_i$, そのため、間接的な接続が見逃される可能性があります。 

## アプローチ

 ブルート フォース ビューは、ルールごとにグラフを明示的に構築することから始まります。$(x, L, R)$、私たちは接続します$x$その範囲内のすべての整数に変換します。 グラフが構築されたら、DFS または DSU を使用して接続コンポーネントをカウントします。 

これは、説明されている友情を正確にモデル化しているため、原則的には正しいです。 失敗は計算上のものです: 単一の間隔が全範囲に及ぶ場合$1$に$10^{12}$、すでに紹介しています$10^{12}$1 つのノードからのエッジ。 すべてのエッジを反復処理することさえ不可能であり、ノードを保存することさえ不可能です。 

重要な観察は、実際には間隔内に個々のノードが必要ないということです。 重要なのは、異なる立場が共有アンカーを通じて接続されるかどうかです$x_i$。 各ルールは本質的に、ノードが$x_i$は連続セグメントに接続するハブとして機能するため、すべての構造は、これらの間隔がどのように重なり、これらのハブを介して接続を伝播するかによって決定されます。 

ソートされた順序で間隔を処理し、数直線のどの部分が以前に確認されたハブを介してすでに接続されているかを維持する場合、点を列挙することなく接続をシミュレートできます。 重要なトリックは、スキャン中に「到達可能なカバー領域」を維持し、すでにアクティブ化されているコンポーネントと重複する間隔をマージすることです。 新しいルールはそれぞれ、新しい分離されたコンポーネントを接続するか、既存のコンポーネントにマージします。これは、回答をインクリメントするかどうかに正確に対応します。 

これにより、問題は巨大な暗黙的なグラフから、ソートされた間隔のエンドポイントにわたるスイープに軽減されます。

 ## アルゴリズムのチュートリアル

 それぞれのルールを再解釈します$(x, L, R)$点と範囲の間の接続に寄与する間隔セグメントとして。 主なアイデアは、このようなすべてのセグメントを順番に処理し、それらがどのように接続されたコンポーネントにマージされるかを追跡することです。 

1. 各ルールを、次の点にアンカーされた正規化された間隔表現に変換します。$x$。 治療します$x$つながる「コネクター」として$[L, R]$。 これにより、個々のエッジではなくセグメントの観点から考えることができます。 
2. すべてのルールを左のエンドポイントで並べ替えます$L$。 接続性は範囲の重複によって決まり、重複検出は順序付けされた形式でのみ意味があるため、並べ替えが必要です。 
3. すでに接続されているコンポーネントを表すアクティブなマージされた間隔のセットを維持します。 各アクティブな間隔は、少なくとも 1 つの選択された開始ノードからすでに到達可能なインデックスの連続領域を表します。 
4. ソートされたルールを繰り返し処理します。 ルールごとに$(x, L, R)$、アクティブな間隔と交差するかどうかを確認します。 既存のコンポーネントと交差しない場合、このルールにより新しい切断された領域が導入されるため、答えが増加します。 
5. 1 つ以上のアクティブな間隔と交差する場合は、それらをすべての重複部分の和集合をカバーする単一の拡張された間隔にマージします。$[L, R]$。 これは、間隔内のいずれかのノードが接続されると、到達可能な領域全体が接続されるという事実をシミュレートします。$x$統一されます。 
6. アクティブ セット内の重複する間隔をマージされた間隔に置き換えます。 これにより、接続されたコンポーネントの素の表現が常に維持されます。 
7. すべてのルールを処理した後、維持されるコンポーネントの数が答えとなります。これは、それぞれが暗黙的なグラフ内の個別の接続コンポーネントに対応するためです。 

### なぜ効果があるのか

 このアルゴリズムは、アクティブな間隔が、すでに処理されたルールによって形成された連結コンポーネントを正確に表すという不変条件を維持します。 2 つのノードは、それらの位置が同じマージされた間隔内にある場合に限り、同じコンポーネント内にあります。 接続性は、これらの間隔によって引き起こされる到達可能性セットの重複によってのみ発生するため、各新しいルールは既存のコンポーネントに接続するか、または新しい分離されたコンポーネントを形成します。 元のグラフ内のすべての接続は何らかのルールによって仲介され、すべてのルールは間隔の重複によってのみ接続を拡張するため、隠れた接続が見逃されることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    m = 0
    n, m = map(int, input().split())
    
    segs = []
    for _ in range(m):
        x, l, r = map(int, input().split())
        # treat as segment [l, r] with anchor x implicitly connecting
        segs.append((l, r))
    
    segs.sort()
    
    merged = []
    ans = 0
    
    for l, r in segs:
        if not merged:
            merged.append([l, r])
            ans += 1
            continue
        
        # check last interval overlap (sufficient after sorting)
        if l > merged[-1][1]:
            merged.append([l, r])
            ans += 1
        else:
            # merge
            merged[-1][1] = max(merged[-1][1], r)
    
    print(ans)

if __name__ == "__main__":
    solve()
```このコードは、問題を区間マージに帰着させます。 各ルールは範囲に影響を与えます$[L, R]$そして、結合されていない結合範囲がいくつ存在するかを追跡します。 並べ替えでは、前のアクティブなセグメントと重複が存在することが保証されるため、最後の間隔のみをチェックする必要があります。 

実装に関する重要な決定事項は無視することです$x$合併中。 これは有効です。$x$は常にそのインターバルによって引き起こされる接続構造内にあり、接続性はインターバルがどのように重なり合い、共有カバレッジを通じて連鎖するかによって完全に決定されます。 

並べ替えには注意が必要です$L$ソートされていない処理では、連鎖した重複が見逃されるためです。 また、ソート後はすべての重複部分がアクティブな構造内で連続しているため、最後にマージされたセグメントのみを更新しても機能します。

 ## 特殊なケース

 主なエッジ ケースは、間隔が直接重なり合わず、一連の重なり合う範囲を介して接続される場合です。 例えば、$[1,3]$そして$[3,5]$重なり合う部分が 1 点であっても、接続されているものとして扱う必要があります。 並べ替えにより、接触している間隔がマージされることが保証されるため、アルゴリズムはこれを処理します。$l \leq$前の$r$。 

もう 1 つのケースは、多くの間隔が 1 つの点を共有しているものの、それ以外の点では互いに素である場合です。 例えば、$[1,1], [1,10], [10,10]$。 マージ プロセスにより、アクティブな間隔が次のように拡張されます。$[1,10]$、他のすべてを正しく吸収します。 

3 番目のケースは次の場合に発生します。$n$非常に大きいですが、$m$小さいです。 アルゴリズムは決して参照しないため、$n$入力の読み取りを除き、範囲が大きくてもパフォーマンスや正確さに影響しません。
