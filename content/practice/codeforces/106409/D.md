 ## 解決策
 ## 問題の理解

 最大で次のような単純な無向グラフが与えられます。$2 \cdot 10^5$頂点まで$3 \cdot 10^5$エッジ。 タスクは、4 つの異なる頂点のチェーンが存在するかどうかを判断することです。$a, b, c, d$チェーンに沿った連続する各ペアがエッジで接続され、長さ 3 の単純なパスが形成されます。 そのようなパスが存在する場合は、有効な 4 つの頂点を順番に出力する必要があります。 それ以外の場合は -1 を出力します。 

私たちが探している構造は、サイクルや一般的なサブグラフ パターンではなく、特に 3 つのエッジを持つ単純なパスです。 これは、頂点の繰り返しが禁止されているため、複数のエッジが存在する場合でもノードを再利用できないため重要です。 

この制約は、次のことを強く示唆しています。$O(N^2)$または$O(NM)$アプローチは不可能です。 と$N, M$数十万、さらには$10^8$操作は限界に達しており、立体的なものは完全に範囲外です。 どのソリューションも基本的に、線形または線形に近い時間でグラフをスキャンする必要があります。$O(N + M)$。 

グラフに多くの三角形または密集した近傍が含まれる場合、微妙な失敗のケースが発生します。 たとえば、サイズ 4 のクリークには有効な答えが含まれていますが、すべてのトリプルまたは近傍の近傍を試す単純なアプローチは組み合わせ論的に爆発します。 もう 1 つの特殊なケースは、グラフがスター、つまり中心が多くの葉に接続されている場合です。 エッジの数が多いにもかかわらず、そこには長さ 3 のパスは存在しないため、「エッジが多いとパスが長いことを意味する」と仮定するアルゴリズムは正しくありません。 

## アプローチ

 直接的な総当たりアプローチは、順序付けられたすべてのエッジのペアを試し、それらをパスに拡張することを試みることです。 具体的には、すべてのエッジに対して反復処理を行うことができます。$b\!-\!c$、次にすべての近隣を試します$a$の$b$そして隣人全員$d$の$c$かどうかを確認します$a, b, c, d$は区別されます。 This is correct because it enumerates every possible middle edge and tries to extend it on both sides.

 問題は、密集地域ではこれが非常に高価になることです。 完全なグラフの最悪の場合、各頂点には次数があります。$O(N)$したがって、エッジごとにすべての拡張子をチェックすると、$O(N^3)$行動。 と$3 \cdot 10^5$エッジ、これは不可能です。 

重要な点は、すべての拡張機能を調べる必要はないということです。 エッジの各エンドポイントに反対側のエンドポイント以外の隣接エンドポイントが少なくとも 1 つあるかどうかだけを知る必要があります。 有効な中間エッジを選択したら$b-c$、隣人なら誰でも$a \neq c$の$b$そして隣人も$d \neq b$の$c$すぐに有効なパスを形成します$a-b-c-d$。 したがって、問題は、反対側の端点を考慮から除外することによって引き起こされるグラフ内で、両方の端点の次数が少なくとも 2 であるエッジを見つけることになります。 

これを悪用するきれいな方法は、隣接リストと次数を前処理することです。 次に、エッジを反復処理して、貪欲にパスを構築しようとします。 両方の拡張を許可する最初のエッジは、有効な応答を即座に生成します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | すべての拡張子に対するブルート フォース |$O(N^3)$|$O(N + M)$| 遅すぎる |
 | 次数ベースの貪欲なエッジ拡張 |$O(N + M)$|$O(N + M)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成し、各頂点の次数を計算します。 これにより、近隣への常時アクセスと、拡張が可能かどうかの迅速なチェックが可能になります。 
2. すべてのエッジを反復処理します。$(b, c)$。 このエッジは、パスの中間となる可能性があります。 
3. 現在のエッジについて、近傍を検索します。$a$の$b$そのような$a \neq c$。 そのような隣接エッジが存在しない場合、このエッジは有効なパスの中間であるはずがないため、次に進みます。 
4. 同様に、近傍を検索します。$d$の$c$そのような$d \neq b$。 これも存在する場合、有効なパスがすぐに得られます。$a - b - c - d$と出力できます。 
5. ステップ 3 と 4 でエッジが成功しなかった場合は、有効な長さ 3 のパスがグラフに存在しないため、-1 を出力します。 

重要な考え方は、各側で複数の隣接候補を探索する必要がないということです。 エッジの両端の有効な延長が見つかるとすぐに停止します。 

### なぜ効果があるのか

 有効なソリューションには中間エッジが含まれている必要があります$(b, c)$。 パスの場合$a - b - c - d$存在する、ならば定義上$a$の隣人です$b$とは違う$c$、 そして$d$の隣人です$c$とは違う$b$。 したがって、エッジを調べると、$(b, c)$、正しいエンドポイント$a$そして$d$隣接リストに存在することが保証されます。 このアルゴリズムは、この存在条件を超える順序や構造に依存しないため、有効な構成を見逃すことはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]

    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    for b, c in edges:
        a = -1
        d = -1

        for x in adj[b]:
            if x != c:
                a = x
                break

        if a == -1:
            continue

        for x in adj[c]:
            if x != b:
                d = x
                break

        if d == -1:
            continue

        print(a)
        print(b)
        print(c)
        print(d)
        return

    print(-1)

if __name__ == "__main__":
    solve()
```このソリューションでは、隣接リストを一度作成してから、エッジをスキャンします。 内側のループは、最初の有効な候補が見つかるまで近傍をスキャンするだけなので、成功した試行ごとにその次数を超えて頂点が処理されることはありません。 重要な実装の詳細は、隣接するエンドポイントを選択するときに反対側のエンドポイントを再利用しないようにすることです。これは、区別性に違反するためです。 

このアルゴリズムは早期終了に依存しています。有効なパスが見つかるとすぐに、それ以降の作業を停止します。 

## 実用的な例

 ### 例 1

 入力:```
4 1
3 4
```エッジが 1 つだけあるため、次数が 2 以上の頂点はありません。アルゴリズムはエッジ (3, 4) をチェックし、どちらの端点にも代替の近傍を見つけず、-1 で終了します。 

### 例 2

 入力:```
6 7
1 3
1 5
2 3
2 5
2 6
4 5
4 6
```エッジごとにトレースします。 

| エッジ (b,c) | c を除く b の隣 | b を除いた c の近傍 | 結果 |
 | --- | --- | --- | --- |
 | (1,3) | 5 | 2 | 有効なパスが見つかりました |
 | 停止 | | | 出力 |

 エッジ (1, 3) の場合、頂点 1 には 3 のほかに隣接 5 があり、頂点 3 には 1 のほかに隣接 2 があります。これにより、パスが得られます。$5 - 1 - 3 - 2$。 アルゴリズムはそれをすぐに出力し、停止します。 

これは、成功したエッジが 1 つだけ必要であることを示しています。 グローバル構造の検索は必要ありません。

 ## 特殊なケース

 星形のグラフは、エッジは存在するが長さ 3 のパスの中間として機能できる頂点がない故障モードを示しています。 アルゴリズムがエッジを検査する場合、1 つのエンドポイントは常に次数 1 を持つため、近隣除外ステップはすぐに失敗し、アルゴリズムは正しく -1 を返します。 

追加の末尾エッジを持つ完全に接続された三角形は、密な局所構造がアルゴリズムを混乱させないことを示しています。 末尾のエッジを処理するとき、三角形に接続されているエンドポイントには代替の隣接点が残っているため、すべての三角形のエッジを探索する必要なく有効なパスを構築できます。 

純粋なパス グラフは、最もきれいな正のケースです。 すべての内部エッジは必要な構造を正確に備えており、アルゴリズムは中間エッジに遭遇するとすぐに成功し、早期終了によって有効な回答がスキップされないことが確認されます。
