 ## 解決策
 # 問題の理解

 この問題は、回線上に配置された複数のビーコンについて説明しています。 各ビーコンには位置と現在の電力があります。 通常のステップ中に、まだ拡張できるすべてのビーコンのパワーが 1 ずつ増加します。 力を持ったビーコン`p`からの間隔をカバーします`x - p`に`x + p`。 ビーコンは、そのカバーされた間隔が別のビーコンのカバーされた間隔に接触すると、独立して拡張できなくなるため、拡張を停止します。 

タスクは、この繰り返しのプロセスが終了した後、カバーされたポジションの最終的な合計量を見つけることです。 

入力により、ビーコンの数が得られ、その後に各ビーコンの座標と初期電力が続きます。 出力は、すべての可能な展開が行われた後にカバーされる整数の位置の数です。 

この制約により、直接シミュレーションを回避する必要があります。 あれば`n`ビーコンとそれぞれのビーコンは何度も拡張する可能性があるため、すべてのラウンドをシミュレートすると直線的な時間よりもはるかに長い時間がかかる可能性があります。 入力が大きい場合、すべてのビーコンを繰り返しスキャンするアプローチでは時間がかかりすぎます。これは、ラウンド数が座標距離だけでなく座標距離にも依存するためです。`n`。 

難しいのは、同時成長が重要であるということです。 1 回の部分的な更新後にブロックされたように見えるビーコンは、同じラウンド中に他のビーコンも成長するため、実際のプロセスでは依然として成長する可能性があります。 

たとえば、2 つのビーコン:```
2
0 1
5 1
```二人ともカバーを始める`[ -1, 1 ]`そして`[4, 6]`。 お互いが成長した後、彼らは最終的に出会います。 左側のビーコンのみを停止するまで成長させるシミュレーションでは、誤ってあまりにも早くフリーズしてしまいます。 

もう 1 つのエッジ ケースは、初期範囲が重複していることです。```
2
0 5
3 1
```最初のビーコンはすでに 2 番目のビーコンをカバーしています。 2 番目のビーコンを独立したものとして扱い、両方の範囲を別々に追加すると、位置が 2 回カウントされます。 

# アプローチ

 簡単な解決策は、全ステップをシミュレートすることです。 各ラウンドで、拡張できるすべてのビーコンを見つけてパワーを増加させ、変化が起こらなくなるまで繰り返します。 これはプロセスに正確に従っているため、これは正しいです。 問題は、ビーコンが別のビーコンに到達するまでに多くの拡張が必要になる可能性があることです。 座標が大きい場合、ラウンド数は座標の距離に比例する可能性があり、最悪の場合は許容範囲をはるかに超えます。 

有益な観察は、個々の展開の順序は重要ではないということです。 すべての拡張可能なビーコンを一緒に増やす代わりに、一度に 1 つのビーコンだけを 1 ユニットずつ拡張する小規模な操作を実行することを想像してください。 最終的な安定状態は同一です。 これにより、展開をカバーされた間隔間のマージとして処理できるようになります。 

位置によってビーコンを並べ替えた後、現在の分離されたカバーされたセグメントを維持します。 新しいセグメントが前のセグメントと重なる場合、その 2 つは同じ最終グループに属します。 それらの最大リーチは、マージされたセグメントのリーチになります。 元の各セグメントは一定数のマージのみに参加するため、ソート後の合計作業量は線形です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(ラウンド数 × n) | O(n) | 遅すぎる |
 | 最適 | O(n log n) | O(n) | 承認済み |

 # アルゴリズムのチュートリアル

 1. すべてのビーコンを位置に基づいて並べ替えます。 相互作用は隣接するカバーされた間隔間でのみ発生するため、左から右の順序で十分です。 
2. 現在の各グループをセグメントとして表現します。`[left, right]`その拡張力も相まって。 最初は、すべてのビーコンが独自のセグメントです。 
3. ビーコンをソート順に 1 つずつ追加します。 新しいセグメントを挿入した後、その前のセグメントと比較します。 
4. 2 つのセグメントが重ならない場合は、両方を保持します。 将来的に 1 つのグループ内で拡大しても、覆われていないギャップを飛び越えることはできないため、それらは永遠に分離されます。 
5. セグメントが重なっている場合は、セグメントを結合します。 新しいセグメントには、左側のセグメントの左側の境界と、マージされたカバレッジの右側の境界があります。 そのビーコンは最も遠くまで拡張し続けることができるため、その力は 2 つの力のうち大きい方です。 
6. 最新のセグメントが前のセグメントと重なる間、後方へのマージを続けます。 
7. すべてのマージが完了すると、残りのすべてのセグメントが最終的に接続されたカバーされたコンポーネントになります。 左端のセグメント`l`、右端点`r`、そしてパワー`p`貢献する`r - l + 2 * p + 1`ポジション。 

これが機能する理由: 不変条件は、格納されているすべてのセグメントが、もはや分離できないカバレッジの 1 つの接続されたコンポーネントを正確に表していることです。 2 つのコンポーネントが接触すると、コンポーネント内の最も遠くに到達するまでどちらの側からの拡張も継続できるため、以降のプロセスではそれらを 1 つとして扱います。 すべてのマージでは可能な最大のリーチが維持されるため、最終的なセグメントは、元の完全なステップを繰り返し適用することによって生成されるセグメントとまったく同じになります。 

# Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    beacons = []
    for _ in range(n):
        x, p = map(int, input().split())
        beacons.append((x, p))

    beacons.sort()

    stack = []

    for x, p in beacons:
        stack.append([x - p, x + p, p])

        while len(stack) >= 2:
            a = stack[-2]
            b = stack[-1]

            if a[1] < b[0]:
                break

            stack.pop()
            stack.pop()

            stack.append([
                a[0],
                max(a[1], b[1]),
                max(a[2], b[2])
            ])

    ans = 0
    for l, r, p in stack:
        ans += r - l + 2 * p + 1

    print(ans)

solve()
```マージ プロセスは隣接する間隔に依存するため、入力が最初に並べ替えられます。 スタックには、現在分離されている間隔のみが保存されます。 

マージ ループはアルゴリズムの中核です。 2 つの間隔が交差する場合、それらを分離しておくと、保存されているすべての間隔が互いに素であるという不変条件に違反します。 接続された後は、残っている最も強力な拡張能力のみが重要となるため、新しいパワーは元の 2 つのパワーの最大値となります。 

最後のループでは、各独立コンポーネントによってカバーされる位置をカウントします。 式には、初期間隔の長さと両側で利用可能な追加の増加が含まれます。 

Python の整数はオーバーフローしないため、実装では大きな応答に対して特別な処理を必要としません。

# テストケース```python
def run(inp: str) -> str:
    import sys, io
    old = sys.stdin
    sys.stdin = io.StringIO(inp)
    data = sys.stdin.readline
    n = int(data())
    a = []
    for _ in range(n):
        x, p = map(int, data().split())
        a.append((x, p))
    a.sort()
    st = []
    for x, p in a:
        st.append([x-p, x+p, p])
        while len(st) >= 2 and st[-2][1] >= st[-1][0]:
            b = st.pop()
            c = st.pop()
            st.append([c[0], max(c[1], b[1]), max(c[2], b[2])])
    ans = sum(r-l+2*p+1 for l, r, p in st)
    sys.stdin = old
    return str(ans) + "\n"

 # エッジケース

 単一ビーコンの場合:```
1
7 0
```スタックには 1 つの間隔が含まれます`[7,7]`。 マージは行われず、貢献度は次のようになります。`1`1 つの位置がカバーされているため、これは正しいです。 

最初に重複しているビーコンの場合:```
2
0 5
3 1
```最初のビーコンカバー`[-5,5]`そして2枚目のカバーは`[2,4]`。 間隔が重複しているため、アルゴリズムはこれらを直ちにマージします。 マージされた間隔ではより大きな電力が維持されるため、最終的なカバレッジは最初のビーコンのみによって決定され、二重カウントが回避されます。 

分離されたビーコンの場合:```
2
0 1
100 1
```間隔`[-1,1]`そして`[99,101]`決して交わらないでください。 スタックには 2 つのコンポーネントが保持され、答えは両方の長さの合計になります。 

重複のチェーンの場合:```
3
0 2
4 2
8 2
```最初の 2 つの間隔は接触しているため、結合されます。 結果のコンポーネントは 3 番目の間隔と重なるほど遠くまで達し、2 番目のマージが発生します。 マージのたびに新しい間隔が前のコンポーネントに対して再度チェックされるため、繰り返されるマージ ループはこのケースを処理します。
