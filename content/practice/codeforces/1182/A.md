 ## 解決策
 ## 問題の理解

 3 列のボードがあります。$n$列。 利用できるピースは同じサイズのドミノだけです$2 \times 1$、縦または横に配置できます。 タスクは、全体の異なる方法が何通りあるかを数えることです。$3 \times n$長方形は、重なり合うことなく、空のセルを残さずに覆うことができます。 

入力には、列数を表す単一の整数が含まれます。 出力は、そのボードの完全なタイリングの数です。 

バウンド$n \le 60$とても小さいです。 たとえ$O(n^2)$または$O(n^3)$解決策は簡単に十分に高速になります。 重要なのは、適切な再発を見つけることです。 すべてのタイリングを直接列挙しようとすると、可能性の数が指数関数的に増加するため、すぐに実行不可能になります。 

いくつかの特殊なケースは見落とされがちです。 

考慮する```
1
```ボードには 3 つのセルが含まれています。 すべてのドミノは 2 つのセルをカバーするため、奇数のセルをカバーすることは不可能です。 正しい答えは、```
0
```不用意に実装すると、繰り返しを盲目的に適用して正の値を生成しようとする可能性があります。 

別の例は```
2
```答えは```
1
```1 つのタイルに対して 1 つのタイリング パターンが存在します。$3\times2$矩形。 基本ケースが欠けていると、それ以降のすべての値が不正確になります。 

より大きな偶数の例は次のとおりです。```
4
```誰の答えは```
4
```偶数の幅のみが可能であるため、奇数の値を個別に処理することを忘れると、入力の半分で誤った答えが得られます。 

## アプローチ

 ブルートフォース手法では、最初の覆われていないセルにドミノを再帰的に配置し、ボードがいっぱいになるまで続けます。 配置ごとに複数の分岐が作成されるため、状態の数は指数関数的に増加します。 のために$n=60$、構成の数は膨大で、1 秒以内に調査できる範囲をはるかに超えています。 

ブルート フォースが概念的に機能する理由は、すべての完全なタイリングが 1 回だけ生成されるためです。 その弱点は、同等の部分ボードを繰り返し再計算することです。 

小さな値を見ると、強いパターンが明らかになります。 奇数の幅には常にゼロウェイがあります。 偶数幅の場合、シーケンスが始まります$$1,1,4,16,64,\dots$$幅用$$0,2,4,6,8,\dots$$2 つの列を追加するたびに、前のタイリングを拡張するための独立した選択肢が 2 つだけ存在します。 その結果、$$f(n)=2f(n-2)$$均等に$n$。 

この観察により、問題は小さな動的計画問題に変換されます。 から始まる$f(0)=1$、2 つの列が追加されるたびに 2 を繰り返し乗算します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース |$O(2^n)$|$O(n)$| 遅すぎる |
 | 最適 |$O(n)$|$O(1)$| 承認済み |

 ## アルゴリズムのチュートリアル

 1. の値を読み取ります。$n$。 
2. もし$n$は奇数です。すぐに 0 を出力します。$3\times n$ボードには含まれています$3n$セル、これは奇妙です。 ドミノは 2 つのセルをカバーするため、完璧なタイルは存在できません。 
3. 空のボードに対応して、答えを 1 として初期化します。$f(0)=1$。 
4. 幅を 2 ​​列ずつ繰り返し増やし、そのたびに答えに 2 を掛けます。 

この繰り返しは、列の追加ペアごとに 2 つの独立した拡張パターンが導入されるという事実から生じます。 

1. 結果の値を出力します。 

### なぜ効果があるのか

 不変条件は、処理後の幅です。$i$、変数`ans`のタイリング数に等しい$3\times i$矩形。 最初は、空のタイリングが 1 つあるため、これは幅 0 の場合に当てはまります。 列が 2 つ増えるたびに可能性の数が 2 倍になるため、不変式は有効なままになります。 幅の場合$n$に達し、`ans`希望するタイリング数と等しくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())

if n % 2 == 1:
    print(0)
else:
    ans = 1
    for _ in range(n // 2):
        ans *= 2
    print(ans)
```The first step checks whether the width is odd. セルの総数が奇数になるため、完全にカバーすることは不可能であるため、答えはすぐにゼロになります。 

For even widths, the variable`ans`現在処理されている幅のタイリングの数を保存します。 基本ケースから始まります$f(0)=1$。 各反復は 2 つの列の追加に対応し、そのような拡張ごとに有効なタイリングの数が 2 倍になります。 

Python の整数は自動的に任意のサイズに拡張されるため、$n=60$オーバーフローの心配なく安全にフィットします。 

ループは正確に実行されます`n // 2`回。 整数除算を使用すると、次の場合に 1 つずつずれたミスを回避できます。$n=0$または$n=2$。

## テストケース```python

import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    n = int(sys.stdin.readline())

    if n % 2 == 1:

    return str(ans) + "\n"
