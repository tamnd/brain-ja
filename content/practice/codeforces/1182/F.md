 ## 問題の理解

 正弦波のスケーリングされた角度に依存する整数に関する関数が与えられています。 任意の整数位置の場合$x$に比例する角度を計算します。$x$、 具体的には$\frac{p}{q}\pi x$、その正弦の絶対値を評価します。 タスクは最大値自体を計算することではなく、最小の整数を見つけることです。$x$セグメント内$[a, b]$ここで、この値はできるだけ大きくなります。 

幾何学的には、これは周期波形上の整数点に沿って歩くことと同等です。 正弦関数は次の間で滑らかに振動します。$-1$そして$1$絶対値を取得すると、マイナスの半分がプラス側に折り畳まれ、値のピークが繰り返し生成されます。$1$。 主な課題は、関数が単調ではなく、実空間に無限に多くの極大値があるにもかかわらず、有界区間内の整数点のみをサンプリングすることです。 

制約は大きく、$b$まで$10^9$最大 100 のテスト ケース。 これにより、すべての整数で関数を評価するアプローチは即座に除外されます。 最悪のケースでは、$10^{11}$評価。 

周期構造から微妙な問題が生じます。 最大値$1$正弦引数がヒットしたときに発生します$\frac{\pi}{2} + k\pi$。 ただし、サンプルは次の整数倍でのみ行うため、$\frac{p}{q}\pi$、最大値がヒットする位置は整数ではない可能性があります。 多くの場合、正確な値に到達することはできません$1$したがって、代わりに、正弦がこれらのピークに最も近い、最も近い整数点を見つける必要があります。 ここで、連続最大値に基づく単純な推論が失敗します。 

関数がセグメント上で単峰性であると仮定すると、別の失敗例が現れます。 そうではない。 たとえば、によっては$p/q$、関数は内部で何度も発振する可能性があります。$[a, b]$、最適な整数はどこにでも現れる可能性があり、必ずしもエンドポイントの近くにあるとは限りません。 

## アプローチ

 ブルートフォースメソッドは直接評価します$f(x)$すべての整数に対して$x$から$a$に$b$、最大値を追跡し、最小値を選択します$x$それを達成すること。 すべての候補を明示的にチェックするので、これは正しいです。 ただし、評価の数は次のとおりです。$10^9$テストケースごとに、これは実現可能な限界をはるかに超えています。 

関数の構造は分数回転によって駆動されます。$\frac{p}{q}x$。 正弦はこの値を法としてのみ依存します$2\pi$の周期性に対応します。$x$ピリオド付き$2q/p$合理的な言葉で言えば。 ただし、整数でのみ評価するため、動作はどのように評価するかを検討することになります。$px \bmod 2q$進化する。 

重要な観察は、次の値が$|\sin(\theta)|$最大化されるのは$\theta$の奇数倍に最も近い$\frac{\pi}{2}$、つまり、いつ$\frac{p}{q}x$に最も近い$\frac{1}{2} + k$。 スケーリング後、これは整数を求める数論の問題になります。$x$そのような$px \bmod (2q)$に最も近い$q/2$または$3q/2$、絶対正弦の下で対称ターゲットです。 

すべてをスキャンするのではなく、$x$では、問題をモジュール構造によって生成された候補点のみをチェックすることに縮小します。 これらの候補は、次の形式の線形合同を解くことで得られます。$px \equiv t \pmod{2q}$、 どこ$t$はピーク位置を表します。 各合同式は等差数列を生成します。必要なのは最初の有効な数列だけです。$x$範囲内で$[a, b]$。 

意味のあるターゲット残基は一定数しかないため、テスト ケースごとに少数の候補セットをチェックし、最小のインデックスで同点を破りながら最良の値を選択します。

 ## アルゴリズムのチュートリアル

 1. を考慮して式をモジュール角度問題として書き直す$px \bmod 2q$。 このステップでは、三角関数の評価を完全に削除し、離散算術構造に置き換えます。 
2. それを特定します$|\sin(\theta)|$最大化されるのは$\theta$に最も近い$\frac{\pi}{2}$モジュロ$\pi$。 スケーリング後、これは次の残基に対応します。$q/2$モジュロ$q$、モジュラスにリフトアップ$2q$。 これにより、連続的な最適化がターゲット残基の有限セットに限定されます。 
3. 各候補標的残基について$t$、合同を解きます$px \equiv t \pmod{2q}$。 これは線形合同であり、次の拡張 gcd を使用して解くことができます。$p$そして$2q$。 溶液は塩基を与えます$x_0$とステップサイズ$2q / \gcd(p, 2q)$。 
4. 各等差数列から最小値を計算します。$x \ge a$それはその中にあります。 これはシフトによって行われます$x_0$期間のステップで進みます。 
5. を超える候補を破棄する$b$。 すべての有効な候補の中から、次の正確な値を計算します。$f(x)$そして最良のものを追跡します。 値が同点の場合は、最小のものを選択します$x$。 

### なぜ効果があるのか

 関数は以下にのみ依存します$px \bmod 2q$したがって、すべての整数はこの剰余によって同値クラスに分割されます。 各クラス内の値は、$|\sin|$固定されています。 最適値は、その剰余が正弦ピーク剰余に最も近いクラスで発生する必要があります。 このようなピーク残基のモジュ​​ロは有限個しかないので、$2q$、到達可能なすべてのクラスをチェックすることで、少なくとも 1 つの最適なクラスが考慮され、最小の有効なクラスが選択されることが保証されます。$x$そのクラスではタイブレーク要件を満たします。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

from math import gcd
import math

def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = ext_gcd(b, a % b)
    return g, y, x - (a // b) * y

def mod_inv(a, mod):
    g, x, _ = ext_gcd(a, mod)
    if g != 1:
        return None
    return x % mod

def solve_case(a, b, p, q):
    m = 2 * q
    g = gcd(p, m)

    def get_x(t):
        if t % g != 0:
            return None
        p1, m1, t1 = p // g, m // g, t // g
        inv = mod_inv(p1 % m1, m1)
        if inv is None:
            return None
        x0 = (t1 * inv) % m1
        # lift to >= a
        if x0 < a % m1:
            x0 += ((a % m1 - x0 + m1 - 1) // m1) * m1
        else:
            x0 += ((a - x0 + m1 - 1) // m1) * m1
        return x0

    best_x = None
    best_val = -1.0

    targets = [q // 2, q + q // 2]

    for t in targets:
        for tt in [t, (t + q) % m]:
            x = get_x(tt)
            if x is None:
                continue
            if x > b:
                continue
            val = abs(math.sin(math.pi * p * x / q))
            if val > best_val or (abs(val - best_val) < 1e-18 and (best_x is None or x < best_x)):
                best_val = val
                best_x = x

    return best_x

t = int(input())
for _ in range(t):
    a, b, p, q = map(int, input().split())
    print(solve_case(a, b, p, q))
```解決策は、正弦条件をモジュラー演算に変換することから始まります。$2q$これは、このスケーリングされた剰余空間ではサインの周期性が線形になるためです。 拡張 gcd ルーチンは反転に使用されます。$p/g$モジュロ$(2q)/g$、各等差数列の基本解を生成します。 

各候補残基は、潜在的なピークのアラインメントに対応します。 基本ソリューションが見つかると、最初の有効なソリューションに前方にシフトされます。$x \ge a$。 これにより、間隔のスキャンが回避されます。 

最後のループでは、テスト ケースごとに一定数の候補のみを評価し、正弦値を直接比較して最適な候補を選択します。

 ## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    input = sys.stdin.readline

    import math
    from math import gcd

    def ext_gcd(a, b):
        if b == 0:
            return a, 1, 0
        g, x, y = ext_gcd(b, a % b)
        return g, y, x - (a // b) * y

    def mod_inv(a, mod):
        g, x, _ = ext_gcd(a, mod)
        if g != 1:
            return None
        return x % mod

    def solve(a, b, p, q):
        m = 2 * q
        g = gcd(p, m)

        def get_x(t):
            if t % g != 0:
                return None
            p1, m1, t1 = p // g, m // g, t // g
            inv = mod_inv(p1 % m1, m1)
            if inv is None:
                return None
            x0 = (t1 * inv) % m1
            if x0 < a % m1:
                x0 += ((a % m1 - x0 + m1 - 1) // m1) * m1
            else:
                x0 += ((a - x0 + m1 - 1) // m1) * m1
            return x0

        best_x = None
        best_v = -1.0

        for t in [q // 2, q + q // 2]:
            for tt in [t, (t + q) % (2 * q)]:
                x = get_x(tt)
                if x is None or x > b:
                    continue
                v = abs(math.sin(math.pi * p * x / q))
                if v > best_v or (abs(v - best_v) < 1e-18 and (best_x is None or x < best_x)):
                    best_v = v
                    best_x = x

        return best_x

    data = """2
0 3 1 3
17 86 389 995
"""
    return "\n".join(str(solve(*map(int, line.split()))) for line in data.splitlines() if line.strip().count(" ") == 3)

 ## 特殊なケース

 いつ$a = b$の場合でも、アルゴリズムは間隔を有効なものとして扱い、その単一の候補範囲のみを評価する必要があります。 その場合、等差数列ステップは 1 つのチェックに集約され、正しい出力は自明です。$a$。 

いつ$p$そして$2q$互いに素ではないため、複数の剰余が同じ算術クラスにマップされます。 モジュラー反転ステップでは、反転の前に方程式を縮小することでこれを処理します。 この縮小がないと、ソルバーは可逆性を誤って仮定し、有効な解を見逃してしまいます。 

When no candidate residue produces a valid$x$で$[a, b]$の場合でも、少なくとも 1 つの剰余クラスが常に整数と交差するため、アルゴリズムは値を返す必要があり、実現可能性が保証されます。
