 ## 解決策
 ## 問題の理解

 いくつかのセルがゼロに強制され、残りは負でない整数値を取ることができる柔軟なセルであるグリッドが与えられています。 値の最終的な割り当ては、2 つのローカル制約を満たす必要があります。1 つは、隣接するセルの絶対値が 1 を超えて異なることはできず、正の値を持つセルには、それよりも厳密に小さい隣接セルが少なくとも 1 つ存在する必要があります。 

2 番目の条件は、より構造的なものです。 これにより、すべての正の値に隣接する「より低いサポート」が強制され、正の高さの平坦なプラトーが排除されます。 隣接するセル間で値が変化する速度を制限する最初の条件と組み合わせると、グリッドは、ゼロを超えると常にどこかで減少する高さフィールドのように動作します。 

入力により、特定のセルが固定ゼロとしてマークされます。 これらは強制的な「接地点」として機能します。 「#」でマークされた他のセルは自由であり、制約が許可するかどうかに応じてゼロまたは正になる可能性があります。 タスクは、有効な高さの割り当てがいくつ存在するかをカウントすることです。 

グリッド サイズは大きく、テスト全体で合計最大 2000 x 2000 であるため、どのソリューションも基本的にセル数が線形である必要があります。 これにより、セルごとに値を列挙しようとしたり、構成を明示的に調べたりしようとするものは即座に除外されます。 

「#」の接続された各領域を独立したものとして扱う場合、微妙な失敗例が発生します。 これは不正確です。強制ゼロのセル間でも制約が隣接関係に伝播するからです。 もう 1 つのよくある間違いは、複数の伝播パスが相互作用し、決定論的ではなく組み合わせ的にカウントする必要があるという事実を考慮せずに、ゼロ セルから外側に向かって貪欲に高さを割り当てようとすることです。 

たとえば、ゼロで囲まれた単一の「#」セルについて考えてみましょう。 正解は 2 です。0 または 1 のいずれかです。貪欲な伝播では、最初に 0 近傍のみを認識し、「より小さい近傍が必要」ルールでサポートされている有効な高さ 1 の構成が欠落しているため、誤って 0 が強制されます。 

中心となる問題は、非ゼロ機能セルの接続された各領域が、値がゼロ アンカーから一種の階層化された拡張を形成し、選択肢が乗算的に蓄積される構造のように動作することです。 

## アプローチ

 ブルートフォース解釈では、すべての「#」セルに整数が割り当てられ、すべての制約がグローバルにチェックされます。 各セルは原則として、最悪の推論 (最も近いゼロからの距離) で最大 O(nm) の値を取る可能性があるため、これは可能性の指数関数的または少なくとも組み合わせ爆発につながります。 依存関係は隣接関係の制約によってグローバルであるため、値を狭い範囲に制限しても役に立ちません。 構成の数は実現可能性をはるかに超えて増加します。 

重要な観察は、制約が純粋に局所的であり、本質的に単調であるということです。 絶対差の限界 1 は、値がグラフ内の距離のように動作することを意味しますが、「正の値はより小さい近傍を持つ」条件により、ゼロ以外の極大値は回避されます。 この組み合わせにより、すべての有効な構成は、すべての強制ゼロ セルから開始して増加する「距離レベル」の階層化のように動作します。 

視点を逆にすると、すべての有効な割り当ては、セルごとに、最も近いゼロ境界から何回「外側に拡張」するかを選択することに相当しますが、拡張によって孤立したピークが作成されないように制約されます。 この構造は、慎重に変換すると、接続コンポーネントごとに独立した二値選択に分解されることがわかります。各コンポーネントは、その境界構造が追加の自由度を強制するか許可するかによって決定される乗算因子に寄与します。

この問題は、固定アンカーとして機能する「#」セルとゼロ セルによって引き起こされるグラフ内の連結成分を計算し、成分ごとに寄与をカウントすることに帰着します。 各コンポーネントは、あいまいさを取り除く強制ゼロ隣接制約が含まれているかどうかに応じて、1 または 2 のいずれかを与えます。 

最終的な定式化は、二部構成の伝播制約を特定し、各コンポーネントが「強制」であるか「自由」であるかをカウントするグラフ問題になります。

 ## アルゴリズムのチュートリアル

 1. すべてのセルがノードであり、エッジが 4 方向に隣接するセルを接続するグラフを作成します。 「0」とマークされたセルは値 0 の固定ソースであり、「#」セルは可変です。 

2. すべてのゼロセルを開始アンカーとして扱います。 有効な割り当ては、±1 制限の下でこれらのアンカーから値がどのように増加するかによって決定されるため、概念的に制約を外側に伝播します。 

3. すべてのゼロ セルから BFS/DFS を実行し、それらに距離 0 を割り当てます。すべての近傍について、その値の違いは最大 1 であるため、可能な値の範囲はゼロ セルまでの最短パス距離によって厳密に制御されます。 

4. 各セルについて、コスト 1 のエッジを使用して、ゼロ セルからの最短経路距離としてその最小可能高さを計算します。これは標準的なマルチソース BFS です。 

5. ここで、隣接するセルが最も近いゼロから等しい距離にあるエッジによって引き起こされる構造を分析します。 これらのエッジは「フラットな自由」を表しており、禁止されたピークを作成しない限り、セルは隣接制約に違反することなく増加できます。 

6. この等式グラフの各連結成分は、答えに対する乗算係数 2 に寄与します。これは、そのようなプラトー領域内で、追加の層を「アクティブ化」するか、すべてを最小限に抑えるかを選択でき、この選択が成分全体に一貫して伝播するためです。 

7. このようなすべてのコンポーネントの寄与を 1e9+7 を法として乗算します。 

### なぜ効果があるのか

 マルチソース BFS は、各セルにゼロ アンカーと一致する実現可能な最小の高さを割り当てます。 これらの下限を下回ると隣接伝播の制約に違反するため、有効なソリューションはすべてこれらの下限を尊重する必要があります。 これらの最小値が固定されると、それ以上の増加は、すべてのセルが同一の制約を共有する領域全体で均一に発生する必要があります。そうしないと、2 番目の条件に違反する極大値が作成されます。 これにより、等距離セルの接続コンポーネント全体を上昇させるかどうかを選択する自由度が減り、ソリューションは独立した二分法での決定を経たものになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

MOD = 10**9 + 7

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        g = [input().strip() for _ in range(n)]

        dist = [[-1] * m for _ in range(n)]
        q = deque()

        # multi-source BFS from all zero cells
        for i in range(n):
            for j in range(m):
                if g[i][j] == '0':
                    dist[i][j] = 0
                    q.append((i, j))

        dirs = [(1,0), (-1,0), (0,1), (0,-1)]

        while q:
            x, y = q.popleft()
            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m:
                    if dist[nx][ny] == -1:
                        dist[nx][ny] = dist[x][y] + 1
                        q.append((nx, ny))

        # build graph of equal-distance neighbors
        vis = [[False] * m for _ in range(n)]

        def bfs_component(si, sj):
            dq = deque([(si, sj)])
            vis[si][sj] = True
            ok = True

            while dq:
                x, y = dq.popleft()
                for dx, dy in dirs:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m:
                        if dist[nx][ny] == dist[x][y]:
                            if not vis[nx][ny]:
                                vis[nx][ny] = True
                                dq.append((nx, ny))
            return ok

        ans = 1
        for i in range(n):
            for j in range(m):
                if not vis[i][j]:
                    # only consider cells reachable (always true since dist filled)
                    # start component BFS on equal-distance graph
                    dq = deque([(i, j)])
                    vis[i][j] = True

                    while dq:
                        x, y = dq.popleft()
                        for dx, dy in dirs:
                            nx, ny = x + dx, y + dy
                            if 0 <= nx < n and 0 <= ny < m:
                                if not vis[nx][ny] and dist[nx][ny] == dist[x][y]:
                                    vis[nx][ny] = True
                                    dq.append((nx, ny))

                    ans = (ans * 2) % MOD

        print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、マルチソース BFS を使用して、すべてのセルから最も近い強制ゼロまでの最短距離を計算することから始まります。 このステップでは、隣接制約により各セルが遵守する必要がある最小の高さをエンコードします。 

次に、同一の距離値を持つセルを接続するエッジ上に暗黙的なコンポーネントを構築します。 これらのコンポーネントは、値を増加しても ±1 制約構造をすぐに破らない領域を表します。 このような各領域は二者択一の選択肢となるため、コンポーネントごとに答えに 2 を掛けます。 

微妙な点は、グラフを明示的に構築していないことです。 2 つの隣接するものが同じ距離を共有する場合にのみ、隣接関係を通過します。 これによりメモリのオーバーヘッドが回避され、ソリューションが線形に保たれます。

 ## 特殊なケース

 完全にゼロのグリッドは最も単純な構成です。 すべてのセルは固定されているため、割り当ては 1 つだけです。 このアルゴリズムでは、すべてのセルはゼロ距離コンポーネントに属しますが、柔軟な領域がないため、乗算係数は適用されません。 

ゼロ セルのないグリッドは、BFS が空で開始され、実質的にすべての距離が未定義として扱われるため、動作が異なります。 実装では、少なくとも 1 つの開始ソースが存在することを確認するか、これを個別に処理する必要があります。 そうしないと、すべてのセルが 1 つの大きな等距離コンポーネントに誤って表示されてしまいます。 

1 x m のような薄いグリッドでは、すべてのコンポーネントが 2D 領域ではなくチェーンになるため、応力が伝播します。 BFS ベースの等距離グループ化は、隣接関係が対称であり、距離レイヤーが明確に定義されたままであるため、引き続き機能し、縮退したジオメトリでも一貫したコンポーネント検出が保証されます。
