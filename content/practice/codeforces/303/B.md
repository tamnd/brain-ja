 ## 解決策
 ## 問題の理解

 次のサイズのグリッドに整列した長方形があります。`n × m`。 すべての有効な点の間には整数の座標があります。`(0, 0)`そして`(n, m)`。 

その中に軸が揃った別の長方形を選択する必要があります。 長方形は 4 つの整数で表されます`(x1, y1, x2, y2)`。 選択した長方形は 3 つの条件を満たさなければなりません。 

まず、指定されたポイントが含まれている必要があります`(x, y)`。 

第二に、辺の長さは正確な比率に従う必要があります。`a : b`。 長方形の幅が`W = x2 - x1`そして高さは`H = y2 - y1`、 それから：$\frac{W}{H}=\frac{a}{b}$すべての座標は整数なので、両方とも`W`そして`H`も整数でなければなりません。 

第三に、すべての有効な長方形の中で、最大の面積を持つ長方形が必要です。 複数の長方形の面積が同じ場合、間のユークリッド距離を最小化します。`(x, y)`そして長方形の中心。 まだ同点の場合は、辞書編集上最小の 4 倍数が選択されます。 

制約は非常に大きく、最大で`10^9`。 これにより、座標、次元、または候補四角形の反復を伴うものは即座に除外されます。 たとえ`O(sqrt(10^9))`次元ごとのループは、不用意に実行するとすでに疑わしいものになります。 意図した解決策は本質的に定数時間でなければなりません。 

重要な数学的観察は比率条件から得られます。 有効な長方形の寸法は次のようになっている必要があります。$W = k\cdot a,\quad H = k\cdot b$整数のスケーリング係数の場合`k`。 

したがって、問題全体は最大の整数を見つけることに帰着します`k`次のような:$k\cdot a \le n,\quad k\cdot b \le m$その後、長方形を配置するだけで済みます。`(x, y)`そして可能な限りその点を中心に配置されます。 

いくつかの特殊なケースは、誤って処理されやすいものです。 

スケーリングされた長方形がボード全体と正確に等しいと仮定します。 

入力：```
5 3 2 1 5 3
```唯一の有効な答えは次のとおりです。```
0 0 5 3
```を中心にしようとする不注意な実装`(2,1)`最初と次に独立してシフトすると、負の座標が生成されたり、境界を超えたりする可能性があります。 

点が境界近くにある場合、別の微妙なケースが発生します。 

入力：```
10 10 0 0 3 2
```長方形の最大サイズは`(9,6)`。 最適な配置は次のとおりです。```
0 0 9 6
```素朴に中心に置くと`(0,0)`、長方形の一部をグリッドの外側に配置しようとします。 

ネクタイの扱いも繊細です。 

入力：```
8 8 4 4 1 1
```最大平方は`8 × 8`、与える:```
0 0 8 8
```長方形が既にボード全体を占めているため、多くの場合中央に配置することは不可能です。 辞書編集上の順序は、面積を最大化し、中心距離を最小化した後にのみ重要になります。 

## アプローチ

 ブルートフォースソリューションでは、寸法が比率条件を満たすすべての長方形を列挙します。 有効な次元は次の倍数であるため、`(a,b)`可能なすべてのスケーリング係数を反復できます。`k`を含むすべてのプレースメントを生成します。`(x,y)`、エリアとタイブレーク ルールを評価します。 

すべての有効な四角形が列挙内に出現する必要があるため、このアプローチは数学的に正しいです。 問題は設置数です。 1 つの次元のペアであっても、`O(nm)`配置。 限界が近い`10^9`、これはまったく不可能です。 

この画期的な進歩は、比率を制限すると、意味のある選択肢が 1 つだけ、つまり実現可能な最大のスケール係数だけになるという認識から生まれました。 

長方形が寸法を使用する場合`(k·a, k·b)`の場合、その面積は次のようになります。$Area = (k\cdot a)(k\cdot b)=k^2ab$以来`a`そして`b`は固定されており、面積の最大化は最大化とまったく同じです。`k`。 

有効な最大スケールは次のとおりです。$k = \min\left(\left\lfloor\frac{n}{a}\right\rfloor,\left\lfloor\frac{m}{b}\right\rfloor\right)$最適な寸法を計算した後、残りのタスクは純粋に幾何学的配置です。 

間の距離を最小限にするには`(x,y)`長方形の中心、できるだけ中心に近い点が必要です。 1 つの軸に沿って、長方形の長さが`W`、理想的な間隔は次のとおりです。`x`:$\left[x-\frac{W}{2},\ x+\frac{W}{2}\right]$座標は整数である必要があり、長方形はボードの内側に留まる必要があるため、左の端点を有効な範囲内にクランプします。`[0, n-W]`。 

同じロジックが y 軸に独立して適用されます。

 ## アルゴリズムのチュートリアル

 1. 可能な最大のスケーリング係数を計算します。```
k = min(n // a, m // b)
```これにより、ボード内に収まる最大の長方形の寸法が得られます。 
2. 長方形の寸法を計算します。```
w = k * a
h = k * b
```最大面積を持つ有効な長方形はすべて、これらの寸法を正確に使用する必要があります。 
3. 長方形を水平に配置します。 

理想的な左枠は次のとおりです。```
x - w // 2
```これにより、ターゲット ポイントを中心に長方形が中央に配置されます。 
4. 左側の境界線を有効な範囲に固定します。 

長方形は次の条件を満たす必要があります。```
0 <= x1 <= n - w
```それで：```
x1 = max(0, min(x - w // 2, n - w))
```5. 以下を計算します。```
x2 = x1 + w
```6. 同じプロセスを垂直方向に繰り返します。```
y1 = max(0, min(y - h // 2, m - h))
y2 = y1 + h
```7. 出力`(x1, y1, x2, y2)`。 

なぜ効果があるのか:

 面積は倍率のみに依存します`k`したがって、最大面積の長方形は実現可能な最大のものを使用する必要があります。`k`。 寸法が固定されると、中心までの距離の最小化は x 軸と y 軸に沿って独立したものになります。 を中心に`(x,y)`が最適であり、クランプによって長方形が移動されるのは、境界によって強制された場合のみです。 さらにシフトすると、中心はさらに遠くに移動します。 複数の配置が同じ距離を与える場合、クランプ式は自然に可能な限り最小の座標を生成し、辞書編集的に最小の答えも得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n, m, x, y, a, b = map(int, input().split())

    k = min(n // a, m // b)

    w = k * a
    h = k * b

    x1 = x - w // 2
    y1 = y - h // 2

    x1 = max(0, min(x1, n - w))
    y1 = max(0, min(y1, m - h))

    x2 = x1 + w
    y2 = y1 + h

    print(x1, y1, x2, y2)

solve()
```最初の部分では、実現可能な最大スケール係数を計算します。 すべての有効な長方形の寸法は次の倍数でなければならないため、`(a,b)`、面積の最大化は最大化に帰着します。`k`。 

次のセクションでは、実際の長方形の幅と高さを計算します。 これらは適合することが保証されているため、`k`フロア区分から選ばれました。 

配置ロジックは微妙な部分です。 まず長方形を中心に配置しようとします`(x,y)`を使用して`x - w // 2`そして`y - h // 2`。 これにより、境界を考慮する前に、可能な限り最も近い中心が得られます。 

次に、開始座標をクランプします。 有効な範囲は、`x1`は`[0, n-w]`。 中央の配置がいずれかの境界を超える場合は、それを有効にするのに十分なだけシフトします。 これにより、可能な限り最小の中心距離が維持されます。 

順序が重要です。 最初に中心位置を計算してからクランプする必要があります。 中心に置く前に境界に直接スナップすると、タイブレークの場合は失敗します。 

すべての計算は 64 ビット整数に快適に収まります。 いずれにせよ、Python の整数には制限がないため、オーバーフローが問題になることはありません。

import io

def solve():
    input = sys.stdin.readline

    n, m, x, y, a, b = map(int, input().split())

    k = min(n // a, m // b)

    w = k * a
    h = k * b

    x1 = x - w // 2

def run(inp: str) -> str:
    backup_stdin = sys.stdin
    backup_stdout = sys.stdout

    sys.stdin = io.StringIO(inp)
    sys.stdout = io.StringIO()

    solve()

    out = sys.stdout.getvalue()

    sys.stdin = backup_stdin
    sys.stdout = backup_stdout

 ## 特殊なケース

 長方形がボード全体を埋める場合を考えてみましょう。 

入力：```
5 3 2 1 5 3
```スケール係数は次のとおりです。```
k = min(5 // 5, 3 // 3) = 1
```それで：```
w = 5
h = 3
```中心にある試みにより、次のことが得られます。```
x1 = 2 - 2 = 0
y1 = 1 - 1 = 0
```有効な範囲は次のとおりです。```
0 <= x1 <= 0
0 <= y1 <= 0
```したがって、長方形は次のように強制されます。```
0 0 5 3
```クランプ範囲は単一の値に集約されるため、アルゴリズムはこれを自然に処理します。 

次に、境界上の点を考えてみましょう。 

入力：```
10 10 0 0 3 2
```以下を取得します。```
k = 3
w = 9
h = 6
```中央に配置された長方形は次の位置から始まります。```
x1 = -4
y1 = -3
```これらの値は無効であるため、クランプにより値がゼロに上方にシフトされます。```
x1 = 0
y1 = 0
```最終的な長方形は次のようになります。```
0 0 9 6
```有効な長方形はボード内に完全に収まる必要があるため、これは可能な限り最も近い有効な配置です。 

最後に、奇数と偶数の長さが相互作用する場合を考えてみましょう。 

入力：```
8 8 4 4 3 2
```最大の規模は次のとおりです。```
k = 2
```与える：```

```ポイント`(4,4)`まさに中心にあります。 整数フロア除算は、特別な場合を除いてパリティの差を正しく処理します。
