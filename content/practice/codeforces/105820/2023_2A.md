 ## 解決策
 ## 問題の理解

 偶数長の配列が与えられます。 これを連続したサブ配列に分割したいと考えています。すべてのサブ配列の長さは奇数でなければならず、それらのサブ配列の中央値はすべてまったく同じでなければなりません。 

ここでの中央値は、奇数長の配列の通常の中央値、つまり並べ替え後の中央の要素です。 

入力は単一の配列で構成されます。 出力は、そのようなパーティションが存在するかどうかだけです。 

配列の長さは次のとおりです$2 \cdot 10^5$。 すべての奇数長の部分配列を明示的に検査するアプローチは直ちに除外されます。 がある$O(n^2)$サブ配列の場合、1 つのサブ配列の中央値を計算することさえ定数時間ではありません。 に近いものが必要です$O(n \log n)$。 

最初の微妙な点は、共通中央値が恣意的ではないということです。 

共通中央値が次のような有効なパーティションを考えます。$x$。 中央値を含む奇数長のすべてのセグメント$x$少なくとも含まれています$\lfloor len/2 \rfloor + 1$である要素$\le x$、そして少なくとも$\lfloor len/2 \rfloor + 1$である要素$\ge x$。 

このような奇数のセグメントをいくつか結合すると、これらの保証が加算されます。 結果として、すべてのセグメントが共有する中央値は、セグメントを結合して得られるコレクション全体の中央値でもある必要があります。 この観察は、問題の重要な構造的特性です。 

2 番目の見落としやすい詳細は、パリティに由来します。 全体の長さは偶数ですが、すべてのセグメントの長さは奇数です。 したがって、セグメントの数は偶数である必要があります。 

例えば：```
n = 2
a = [1, 2]
```可能な唯一のパーティションは、`[1] | [2]`。 中央値が異なるため、答えは次のようになります。`No`。 

別の役立つ例は次のとおりです。```
n = 6
a = [1, 2, 3, 3, 2, 1]
```に分割`[1,2,3]`そして`[3,2,1]`中央値を与える`2`両方のセグメントにあるため、答えは次のようになります。`Yes`。 

素朴な推論を打ち破るケースは次のとおりです。```
n = 6
a = [1, 2, 1, 3, 2, 3]
```値`2`ソート順の途中にあるにもかかわらず、有効なパーティションが存在しないため、有望に見えます。 答えは`No`。 

## アプローチ

 ブルート フォース ソリューションでは、すべての奇数の分割位置とすべての可能なパーティションを列挙し、結果として得られるすべてのセグメントの中央値を計算し、それらが一致するかどうかを確認します。 

すべてのパーティションを 2 つの奇数セグメントに分けて試行しただけだとしても、依然として多くの範囲に対する中央値クエリが必要になります。 各範囲をソートして中央値を計算するとコストがかかります$O(n \log n)$分割ごとに、おおよそ$O(n^2 \log n)$仕事。 

画期的な進歩は、有効なパーティションの構造を理解することから始まります。 

有効なパーティションが存在し、すべてのセグメントに中央値があると仮定します。$x$。 

セグメントの数は偶数であるため、最初のセグメントを 1 つのグループとして取り、残りのすべてのセグメントを 2 番目のグループにマージします。 2 番目のグループは、奇数の有効なセグメントをマージしたものであるため、中央値もあります。$x$。 最初のグループには明らかに中央値があります$x$。 

これは次のことを意味します。 

有効なパーティションは、奇数のインデックスが存在する場合にのみ存在します。$k$そのような```
median(a[1..k])     = x
median(a[k+1..n])   = x
```どこ$x$配列構造全体によって強制される中央値です。 

偶数長の配列の場合、その値はグローバルにソートされた配列の下側中央の要素、つまり位置の要素です。$n/2$1 から始まるインデックス付け。 これは、まさに受け入れられているソリューションで使用される値です。 

問題は次のように縮小されました。 

奇数の分割位置ごとに$k$、プレフィックスの中央値とサフィックスの中央値を決定します。 

これは範囲 k 次の統計問題になります。 座標圧縮と永続的なセグメント ツリーを使用すると、任意の範囲の中央値を取得できます。$O(\log n)$。 

あるのは$O(n)$候補が分割された位置なので、完全な複雑さは次のようになります。$O(n \log n)$。

### なぜ効果があるのか

 合計の長さが偶数であるため、すべての有効なパーティションには偶数個の奇数長のセグメントがあります。 

すべてのセグメントに中央値がある場合$X$、その後、奇数の連続する有効なセグメントを結合しても、中央値のセグメントが生成されます。$X$。 これを最初のセグメントを除くすべてのセグメントに適用すると、パーティションが正確に 2 つの奇数長の部分に分割され、両方とも中央値になります。$X$。 

逆は即時です。 中央値が両方とも 2 つの奇数長の部分に分割されている場合$X$、その分割自体はすでに有効なパーティションです。 

したがって、奇数の分割位置をすべてチェックすることは必要かつ十分です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

tmp = sorted(a)
target = tmp[n // 2 - 1]

vals = sorted(set(a))
comp = {v: i + 1 for i, v in enumerate(vals)}
m = len(vals)

left = [0]
right = [0]
cnt = [0]
roots = [0] * (n + 1)

def update(prev, l, r, pos):
    node = len(cnt)
    left.append(left[prev])
    right.append(right[prev])
    cnt.append(cnt[prev] + 1)

    if l != r:
        mid = (l + r) // 2
        if pos <= mid:
            left[node] = update(left[prev], l, mid, pos)
        else:
            right[node] = update(right[prev], mid + 1, r, pos)
    return node

for i in range(1, n + 1):
    roots[i] = update(roots[i - 1], 1, m, comp[a[i - 1]])

def kth(u, v, l, r, k):
    if l == r:
        return l

    mid = (l + r) // 2
    left_count = cnt[left[v]] - cnt[left[u]]

    if k <= left_count:
        return kth(left[u], left[v], l, mid, k)
    return kth(right[u], right[v], mid + 1, r, k - left_count)

def median_value(l, r):
    length = r - l + 1
    k = (length + 1) // 2
    idx = kth(roots[l - 1], roots[r], 1, m, k)
    return vals[idx - 1]

for split in range(1, n, 2):
    if median_value(1, split) == target and median_value(split + 1, n) == target:
        print("Yes")
        sys.exit()

print("No")
```座標圧縮ステップにより、永続セグメント ツリーがコンパクトな値範囲で機能できるようになります。 

ツリーの各バージョンはプレフィックスに対応します。 範囲内の周波数を取得するには、2 つのバージョンに保存されているカウントを減算します。 これは、範囲順序統計の標準的な永続セグメント ツリーのトリックです。 

中央値クエリでは次のことが求められます。$(len+1)/2$- 番目に小さい要素。これは、調査するすべての範囲の長さが奇数であるためです。 

よくある間違いの原因は、目標の中央値です。 配列全体の長さは偶数であるため、位置に対応する、グローバルにソートされた配列の下中央の要素を使用します。$n/2$1 から始まるインデックス付け。

import sys
import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    n = int(input())
    a = list(map(int, input().split()))

    tmp = sorted(a)
    target = tmp[n // 2 - 1]

    vals = sorted(set(a))
    comp = {v: i + 1 for i, v in enumerate(vals)}
    m = len(vals)

    left = [0]
    right = [0]
    cnt = [0]
    roots = [0] * (n + 1)

    def update(prev, l, r, pos):
        node = len(cnt)
        left.append(left[prev])
        right.append(right[prev])
        cnt.append(cnt[prev] + 1)

        if l != r:
            mid = (l + r) // 2
            if pos <= mid:
                left[node] = update(left[prev], l, mid, pos)
            else:
                right[node] = update(right[prev], mid + 1, r, pos)
        return node

    for i in range(1, n + 1):
        roots[i] = update(roots[i - 1], 1, m, comp[a[i - 1]])

    def kth(u, v, l, r, k):
        if l == r:
            return l
        mid = (l + r) // 2
        lc = cnt[left[v]] - cnt[left[u]]
        if k <= lc:
            return kth(left[u], left[v], l, mid, k)
        return kth(right[u], right[v], mid + 1, r, k - lc)

    def med(l, r):
        length = r - l + 1
        k = (length + 1) // 2
        idx = kth(roots[l - 1], roots[r], 1, m, k)
        return vals[idx - 1]

    for split in range(1, n, 2):
        if med(1, split) == target and med(split + 1, n) == target:
            return "Yes\n"

    return "No\n"
