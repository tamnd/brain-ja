 ## 解決策
 ## 問題の理解

 固定の小文字文字列と多くの範囲クエリが与えられます。 

お問い合わせの場合`[l, r]`、部分文字列を考慮します`t = s[l..r]`。 すべての部分文字列の中で、`t`、ほぼ回文ではない部分文字列の最大長が必要です。 

文字列を回文に再配置できる場合、その文字列はほぼ回文です。 小文字の場合、これは最大でも 1 文字が奇数の頻度を持つと言うのと同じです。 

したがって、すべてのクエリについて、内部で最も長い連続セグメントを探します。`t`その周波数パリティ マスクには少なくとも 2 つの奇数カウントが含まれています。 

文字列の長さとクエリの数は両方とも最大です。`2 · 10^5`。 クエリ範囲を 1 文字ずつスキャンするアプローチは、すぐに遅すぎます。 平`O(length of query)`クエリごとに次のようになります`O(nq)`最悪の場合、それは約`4 · 10^10`操作。 

ソリューションは、前処理後に一定時間または対数時間で各クエリに応答する必要があります。 

微妙なエッジ ケースは、完全に 1 つの文字で構成される範囲です。 

例えば：```
aaaaa
```すべての部分文字列も次のものだけで構成されます。`'a'`。 このような部分文字列には常に最大 1 つの奇数頻度が含まれるため、すべての部分文字列はほぼ回文になります。 答えは次のとおりです。```
0
```もう 1 つの重要なケースは、文字が交互に並ぶ範囲です。 

例えば：```
ababa
```文字列全体はほぼ回文であり、長さ 4 および長さ 3 のすべての部分文字列もほぼ回文です。 最も長い不正な部分文字列は次のとおりです。```
ab
```長さのある`2`。 

クエリ範囲全体の頻度カウントのみを調べるソリューションでは、これが見逃されます。 

## アプローチ

 ブルートフォースアプローチは簡単です。 

すべてのクエリについて、クエリ範囲のすべての部分文字列を列挙します。 部分文字列ごとに、文字の頻度をカウントし、複数の文字が奇数の頻度を持つかどうかを確認します。 

クエリの長​​さが`m`、 がある`O(m^2)`部分文字列。 プレフィックス周波数があっても、すべてをチェックするのはコストがかかりすぎます。 と`m = 2 · 10^5`、これはまったく不可能です。 

重要な観察は、答えは、クエリされた範囲のいくつかの構造的特性にのみ依存するということです。 

させて`t = s[l..r]`そしてさせてください`m = |t|`。 

根本的に異なる 3 つの状況があります。 

すべての文字が入っている場合、`t`は同じで、すべての部分文字列はほぼ回文であり、答えは次のようになります。`0`。 

それ以外の場合は、`t`自体がほとんど回文ではない場合、範囲全体がすでに要件を満たしています。 答えは単純です`m`。 

興味深いケースは次のような場合です。`t`は回文に近いです。 

この問題に対する古典的な観察によれば、交互の範囲のみが一般的な範囲とは異なる動作をします。 範囲が交互でない場合、つまり隣接する文字が等しいインデックスが存在する場合、適切なエンドポイントを 1 つ削除すると、次のような長さの非ほぼ回文の部分文字列が生成されます。`m - 1`。 

交互範囲の場合、すべての部分文字列は交互構造を継承します。 それらのパリティ動作は非常に制限されているため、別の式が必要になります。 

同等のケースを検討すると、答えは次のようになります。 

すべての文字が等しい場合に答えます`0`。 

範囲が交互の場合:```
m                  if t is not nearly palindromic
m - 1              if m is odd
m - 2              if m is even
```範囲が交互でない場合:```
m                  if t is not nearly palindromic
m - 1              otherwise
```これにより、すべてのクエリが 3 つのチェックに減ります。 

1. 範囲はすべて 1 文字ですか?
 2. 範囲は​​交互ですか?
 3. 範囲は​​回文に近いですか?

 3 つすべてに答えることができます`O(1)`前処理を使用します。 

パリティ条件は、26 ビットのプレフィックス XOR マスクで処理されます。 部分文字列は、そのマスクに含まれるセット ビットが 1 つ以下であれば、ほぼ回文です。 

他の 2 つの条件は、隣接する文字が異なる位置のプレフィックスの合計で答えられます。 

結果として得られるソリューションは、すべてのクエリに一定時間内に応答します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | クエリあたり O(m²) | お(1) | 遅すぎる |
 | 最適 | O(n + q) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. プレフィックス パリティ マスク配列を構築します。 

させて`pref[i]`位置で終わるプレフィックス内の文字ビットの xor になります。`i`。 

クエリ範囲のパリティ マスクは次のとおりです。```
mask = pref[r] xor pref[l - 1]
```2. アレイを構築する`diff1`。 

あらゆるポジションについて`i > 1`、次のいずれかを保存します。```
s[i] != s[i - 1]
```そのプレフィックスの合計により、範囲内のすべての文字が等しいかどうかを確認できます。 
3. アレイを構築する`diff2`。 

あらゆるポジションについて`i > 2`、次のいずれかを保存します。```
s[i] != s[i - 2]
```そのプレフィックスの合計により、範囲が交互になっているかどうかを確認できます。 
4. お問い合わせの場合`[l, r]`、 させて：```
m = r - l + 1
```5. すべての文字が等しいかどうかを確認します。 

範囲内に隣接する差分がない場合は戻ります。`0`。 
6. 範囲のパリティ マスクを計算し、その設定ビットをカウントします。 

ポップカウントが次より大きい場合`1`、範囲全体はすでに回文に近くないので、戻ります`m`。 
7. 範囲が交互になっているかどうかを確認します。 

すべての文字が 2 つ後の文字と等しい場合、範囲は交互になります。 
8. 範囲が交互の場合:

 もし`m`奇数です、戻ります`m - 1`。 

それ以外の場合は戻る`m - 2`。 
9. 範囲が交互でない場合は、戻ります。`m - 1`。 

### なぜ効果があるのか

 パリティ マスクは、文字列を回文に再配置できるかどうかを完全に特徴付けます。 パリティ マスクに最大 1 ビットが設定されている場合、文字列は回文に近いものになります。 

クエリされた範囲がすでに回文に近くない場合、その範囲内には部分文字列が存在しないため、答えはその全長になります。 

範囲が回文に近い場合は、少数の文字を削除して最長の不良部分文字列を取得する必要があります。 非交互範囲には、不正な長さの部分文字列を作成するのに十分なローカル反復が常に含まれます。`m - 1`。 交互範囲は唯一の例外であり、そのパリティ構造により、最長の不良部分文字列が強制的に次のようになります。`m - 1`奇数の長さの場合と`m - 2`均等な長さで。 

前処理配列を使用すると、これらのケースのどれが当てはまるかを正確に認識できます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
s = input().strip()

pref = [0] * (n + 1)
for i, ch in enumerate(s, 1):
    pref[i] = pref[i - 1] ^ (1 << (ord(ch) - ord('a')))

adj = [0] * (n + 1)
for i in range(2, n + 1):
    adj[i] = adj[i - 1] + (s[i - 1] != s[i - 2])

alt = [0] * (n + 1)
for i in range(3, n + 1):
    alt[i] = alt[i - 1] + (s[i - 1] != s[i - 3])
for i in range(1, 3):
    alt[i] = 0

q = int(input())

for _ in range(q):
    l, r = map(int, input().split())
    m = r - l + 1

    if adj[r] - adj[l] == 0:
        print(0)
        continue

    mask = pref[r] ^ pref[l - 1]

    if mask.bit_count() > 1:
        print(m)
        continue

    is_alternating = True
    if m >= 3:
        is_alternating = (alt[r] - alt[l + 1] == 0)

    if is_alternating:
        if m & 1:
            print(m - 1)
        else:
            print(m - 2)
    else:
        print(m - 1)
```プレフィックス xor 配列には、周波数パリティ情報が格納されます。 ビットは、その文字が表示されるたびに切り替わります。 2 つの接頭辞の xor により、任意の部分文字列のパリティ マスクが得られます。 

の`adj`prefix 配列は、隣接する文字が異なる位置をカウントします。 範囲にそのような位置が含まれていない場合、範囲内のすべての文字は同一になります。 

の`alt`プレフィックス配列は条件をチェックします`s[i] == s[i - 2]`。 この条件が範囲内のどこでも当てはまる場合、範囲は交互になります。 

チェックの順序が重要です。 すべて等しい場合を最初に処理する必要があります。そうしないと、長さ 1 または 2 の交互範囲が否定的な応答を生成するためです。

## テストケース```python
# helper: run solution on input string, return output string
import sys
import io

def run(inp: str) -> str:
    data = io.StringIO(inp)
    input = data.readline

    n = int(input())
    s = input().strip()

    pref = [0] * (n + 1)
    for i, ch in enumerate(s, 1):
        pref[i] = pref[i - 1] ^ (1 << (ord(ch) - ord('a')))

    adj = [0] * (n + 1)
    for i in range(2, n + 1):
        adj[i] = adj[i - 1] + (s[i - 1] != s[i - 2])

    alt = [0] * (n + 1)
    for i in range(3, n + 1):
        alt[i] = alt[i - 1] + (s[i - 1] != s[i - 3])

    q = int(input())
    out = []

    for _ in range(q):
        l, r = map(int, input().split())
        m = r - l + 1

        if adj[r] - adj[l] == 0:
            out.append("0")
            continue

        mask = pref[r] ^ pref[l - 1]

        if mask.bit_count() > 1:
            out.append(str(m))
            continue

        is_alt = True
        if m >= 3:
            is_alt = (alt[r] - alt[l + 1] == 0)

        if is_alt:
            out.append(str(m - 1 if m & 1 else m - 2))
        else:
            out.append(str(m - 1))

    return "\n".join(out)

# sample
assert run(
"""8
aabaaaba
3
3 7
1 8
4 4
"""
) == "4\n6\n0"

# all equal
assert run(
"""5
aaaaa
1
1 5
"""
) == "0"

# already not nearly palindromic
assert run(
"""3
abc
1
1 3
"""
) == "3"

# alternating odd length
assert run(
"""5
ababa
1
1 5
"""
) == "4"

# alternating even length
assert run(
"""6
ababab
1
1 6
"""
) == "4"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 |`aaaaa`|`0`| すべて等しい範囲 |
 |`abc`|`3`| 全範囲がすでに悪い |
 |`ababa`|`4`| 交互、奇数の長さ |

 ## 特殊なケース

 次のことを考慮してください。```
aaaa
```すべての部分文字列には、異なる文字が 1 つだけ含まれます。 パリティ マスクに複数の設定ビットを含めることはできません。 アルゴリズムは範囲内に隣接する差がないことを検出し、すぐに返します。`0`。 

考慮する：```
abc
```周波数は次のとおりです。`{1,1,1}`。 3 つの文字のカウントが奇数であるため、範囲自体は回文に近いものではありません。 パリティ マスクには 3 つの設定ビットが含まれており、アルゴリズムは全長を返します。`3`。 

考慮する：```
ababa
```この範囲は交互であり、ほぼ回文形式です。 アルゴリズムは交互分岐に到達し、戻ります。`m - 1 = 4`。 これはまさに、通常の回文に近い範囲とは別個の処理を必要とする特殊な構造です。 

考慮する：```
ababab
```範囲は均等な長さで交互に表示されます。 交互偶数式は次の結果を返します。`m - 2 = 4`、返品というよくある間違いを回避します`5`。
