 ## 解決策
 ## 問題の理解

 まず、ボード上に配置された 1 つの整数から始めます。 各ステップで、この数値は、一様にランダムに選択された約数の 1 つで置き換えられます。 この操作を正確に k 回繰り返すと、ボード上の値は整数にわたる確率変数になり、素数を法とするその期待値が求められます。 

このプロセスは、n から到達可能な約数にわたるマルコフ連鎖です。 各状態は数値 v であり、v から d(v) 上で等しい確率 1 でその約数のいずれかに遷移します。ここで、d(v) は v の約数の数です。問題は、n が 10^15 にもなる可能性があるため、構造なしで到達可能なすべての状態のすべての約数を単純に列挙することはできないことです。 ステップ数 k は最大 10^4 であり、ステップにわたる動的プログラミングを示唆していますが、状態空間を大幅に圧縮する必要があります。 

単純なアプローチでは、各ステップの後にすべての可能な値とその確率を明示的にシミュレートします。 n が中程度の場合でも、各約数が再び独自の約数に分岐するため、約数グラフは急速に成長する可能性があります。 2 × 3 × 5 × 7 × 11 のような数値の場合、除数グラフにはすでに数十の状態が含まれており、k ステップにわたって分岐を繰り返すと指数関数的に爆発します。 

n が 1 の場合、微妙なエッジ ケースが発生します。1 には約数が 1 つしかないため、プロセスはすぐに吸収されます。 少なくとも 2 つの約数を想定する誤った実装では、ゼロで除算するか、偽の遷移が発生します。 もう 1 つのエッジ ケースは、p^k のような素数べき乗です。この場合、除数構造は線形ですが、不用意な実装では依然として事前計算なしで除数を順序なしのセットとして扱い、除数リストの再計算が繰り返される可能性があります。 

重要な構造的観察は、プロセスが n の約数のみを訪問し、期待値は因数分解を超えた n の絶対サイズではなく、約数の関係のみに依存するということです。 

## アプローチ

 ブルート フォース シミュレーションでは、到達可能なすべての値にわたる確率分布が維持されます。 n から開始して、すべての約数を計算し、確率質量を均一に分配し、k ステップにわたって繰り返します。 各ステップでは、すべての現在の状態を反復し、確率をその約数に再分配する必要があります。 

マルコフ過程を直接モデル化しているため、正確性は簡単です。 失敗点は状態爆発です。 最悪の場合、n は約 10^4 の約数を持つ可能性があり、各約数は再び独自の約数を寄与するため、ステップごとにおよそ O(d(n)^2) の遷移が発生し、k 倍すると完全に実行不可能になります。 

重要な洞察は、視点を逆転させることです。 値に対する前方確率分布を追跡する代わりに、各約数がプロセスを通じて後方にどの程度寄与するかを追跡します。 各ステップは除数包含関係のみに依存し、値でソートすると、これらの関係は有向非循環構造を形成します。 n のすべての約数を事前計算し、それらの間の遷移を構築します。 k は大きいですが、除数セットは固定されており小さいため、この圧縮された状態空間のステップに対して動的プログラミングを実行します。 

これは、問題をサイズ d(n) のグラフにわたる k ステップ DP に変換します。ここで、遷移は中間ノードの除数の数に依存します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォースシミュレーション | O(k · d(n)^2) | O(d(n)) | 遅すぎる |
 | 状態に対する除数 DP | O(k · d(n)^2) | O(d(n)) | 承認済み |

 ## アルゴリズムのチュートリアル

 n の各約数を状態として扱います。

1. n を素因数分解します。 これにより、n まで反復することなく、すべての約数を効率的に生成できます。 n は 10^15 まで大きくなる可能性があるため、この手順が必要です。 
2. 素数指数からの再帰的構築を使用して、n のすべての約数を生成します。 それらをリストに保存し、並べ替えます。 これにより、サイズ m = d(n) の状態空間が得られます。 
3. 各約数 v について、完全な約数リストからフィルタリングすることによって、v のすべての約数を計算します。 これにより、移行の可能性が定義されます。 
4. 各状態 v の約数の数である d(v) を事前計算します。これは、遷移が約数にわたって均一であるため使用されます。 
5. dp[t][v] を、t ステップ後の状態 v から始まる期待値寄与として定義します。 完全な 2D を保存する代わりに、時間をかけて配列をロールします。 
6. すべての v ≠ n について、dp[0][n] = n および dp[0][v] = 0 を初期化します。 これにより、開始ディストリビューションがエンコードされます。 
7. 1 から k までの各ステップについて、各状態 v をそのすべての約数 u に均等に分配することによって dp を更新します。 各遷移は dp[t-1][v] / d(v) を dp[t][u] に寄与します。 確率ではなく期待値を直接蓄積します。 
8. k ステップの後、答えは dp[k][n] となり、すべてのパスに対する期待値として解釈されます。 

### なぜ効果があるのか

 このプロセスでは、n の除数状態にわたる有限マルコフ連鎖を定義します。 すべての遷移は除数の包含のみに依存し、均一な選択により期待値の線形性がきれいに適用されることが保証されます。 状態全体で期待される寄与を追跡することにより、確率で重み付けされたすべての可能なパスを暗黙的に合計します。 状態空間は遷移ルール​​の下で閉じられているため、システムから確率質量が流出することはなく、DP はすべてのステップで期待値全体を正確に保存します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

# compute all divisors via factorization
from collections import defaultdict
import math

def factorize(x):
    f = {}
    i = 2
    while i * i <= x:
        while x % i == 0:
            f[i] = f.get(i, 0) + 1
            x //= i
        i += 1
    if x > 1:
        f[x] = f.get(x, 0) + 1
    return f

def gen_divisors(primes, i=0, cur=1):
    if i == len(primes):
        return [cur]
    p, e = primes[i]
    res = []
    val = 1
    for _ in range(e + 1):
        res += gen_divisors(primes, i + 1, cur * val)
        val *= p
    return res

def get_divisors_from_list(divs):
    divs.sort()
    m = len(divs)
    idx = {v: i for i, v in enumerate(divs)}
    divisors = [[] for _ in range(m)]
    for i, v in enumerate(divs):
        for u in divs:
            if v % u == 0:
                divisors[i].append(idx[u])
    return divisors

def solve():
    n, k = map(int, input().split())
    
    if n == 1:
        print(1)
        return

    fac = factorize(n)
    primes = list(fac.items())
    divs = gen_divisors(primes)
    divs.sort()
    
    m = len(divs)
    idx = {v: i for i, v in enumerate(divs)}

    divisors = [[] for _ in range(m)]
    for i, v in enumerate(divs):
        for u in divs:
            if v % u == 0:
                divisors[i].append(idx[u])

    dp = [0] * m
    dp[idx[n]] = n

    inv = [0] * (max(len(divisors[i]) for i in range(m)) + 1)
    MOD = 10**9 + 7

    for step in range(k):
        ndp = [0] * m
        for i in range(m):
            if dp[i] == 0:
                continue
            v = dp[i]
            deg = len(divisors[i])
            inv_deg = pow(deg, MOD - 2, MOD)
            for j in divisors[i]:
                ndp[j] = (ndp[j] + v * inv_deg) % MOD
        dp = ndp

    print(dp[0] % MOD)

if __name__ == "__main__":
    solve()
```この実装では、最初に n の完全な除数格子が構築されます。 dp 配列には、各状態での値の予想される寄与が格納されます。 各ステップでは、除数の数による除算を表す逆モジュラーを使用して、ノードからそのすべての除数に値を均一に再分配します。 

微妙な点は、確率を個別に維持するのではなく、期待値を直接伝播することです。 これが機能するのは、期待値が線形であり、状態値と確率質量を乗算することで両方を 1 つの DP テーブルにマージできるためです。 

最終的な答えは、k 回の遷移後の状態 1 の期待値です。これは、すべてのパスが最終的に除数構造を通過し、期待値がルートに蓄積されるためです。 

## 実用的な例

 ### 例 1: n = 6、k = 1

 約数は [1、2、3、6] です。 6時に全ミサから始めます。 

| ステップ | 状態 | 値 | 約数 | 配布 |
 | --- | --- | --- | --- | --- |
 | 0 | 6 | 6 | 1、2、3、6 | すべての質量は 6 |
 | 1 | 1 | 1 | - | 1/4 |
 | 1 | 2 | 2 | - | 1/4 |
 | 1 | 3 | 3 | - | 1/4 |
 | 1 | 6 | 6 | - | 1/4 |

 期待値は (1 + 2 + 3 + 6) / 4 = 3 です。 

### 例 2: n = 6、k = 2

 最初のステップの後、分布は約数にわたって均一になります。 これらのそれぞれは、それぞれの約数に再び広がります。 追跡により、小さい約数は複数の数の約数として現れるため、時間の経過とともにより高い確率質量を獲得することがわかります。 

この例では、除数グラフの複数のレイヤーにわたって遷移が正しく蓄積されていることを確認します。

 ## 特殊なケース

 n が 1 の場合、遷移セットにはそれ自体のみが含まれるため、DP は状態を変更せず、k に関係なく出力は 1 のままになります。 除数の数をやみくもに計算して除算する実装では、誤ってゼロ除算が試行されたり、誤って質量が再分配されたりします。 

素数 n の場合、除数グラフには 1 と n の 2 つのノードがあります。 1 つのステップの後、プロセスは常に一律に 1 または n に到達します。 さらなるステップの後、n のすべての約数は 1 または n であるため、質量は 1 に向かって集中し、遷移の繰り返しによってこの構造が強化されます。 除数リストは最小限ですが完全であるため、DP はこれを正しく処理します。 

360 のような高度に合成された数の場合、複数の約数が重複する約数セットを共有します。 DP は、共有遷移が親状態ごとに独立してカウントされることを保証し、重複するパス全体にわたる確率質量の正しい累積を維持します。
