 ## 解決策
 ## 問題の理解

 2 つの文字列が与えられています。`s`長さの`n`そして`t`長さの`m`、 どこ`n`より厳密に小さいです`m`。 課題は、分割できる方法の数を数えることです`s`3 つの連続する部分文字列に分割`x`、`y`、`z`私たちが摂取するときのように`x`、 繰り返す`y`何度か (少なくとも 1 回) 追加してから`z`、文字列を正確に取得します`t`。 本質的には、`t`の「ポンプ」バージョンです`s`真ん中の部分を繰り返すことで`y`ある程度の回数。 

主な制約は次のとおりです。`n`そして`m`まで可能です`10^7`。 これにより、考えられるすべての分割を反復するアプローチは除外されます。`s`繰り返される連結を素朴にシミュレートします。 すべての部分文字列を考慮した総当たりアルゴリズム`x`、`y`、`z`関与するだろう`O(n^2 * m)`この限界には遅すぎる操作です。 

明らかではないエッジケースには、次のような状況が含まれます。`x`または`z`空の場合もあるし、`y`単一の文字が複数回繰り返されます。 たとえば、次の場合`s = "aa"`そして`t = "aaaaa"`、有効なトリプルが複数あります。`("", "a", "aa")`、`("a", "a", "a")`、 そして`("", "aa", "a")`。 空ではないことを前提とした不注意なアプローチ`x`または`z`または一致させようとします`t`注意して位置合わせせずに貪欲に実行すると、有効なトリプルが失われる可能性があります。 

## アプローチ

 ブルートフォース手法では、考えられるすべての分割点を反復処理します。`x`そして`y`で`s`、計算する`z`残りの部分文字列として、各候補トリプルについて繰り返しているかどうかを確認します。`y`生成する`t`正しく。 候補ごとに、これを繰り返すことが必要になる場合があります。`t`繰り返しを確認するためです。 すべての分割を考慮すると`(i, j)`のために`x`で終わる`i`そして`y`で終わる`j`、おおよそあります`O(n^2)`分割し、それぞれを検証するには最大で 2 時間かかる場合があります`O(m)`操作の全体的な複雑さは次のとおりです。`O(n^2 * m)`、これは不可能です`n, m ~ 10^7`。 

重要な観察点は、`y`何度か繰り返されると、～のセグメントと一致します`t`文字列ハッシュを使用すると効率的に実行できます。 ローリングハッシュを事前計算する`s`そして`t`。 次に、潜在的な分割ごとに、次のハッシュを比較するだけで済みます。`x`そして`z`対応するプレフィックスとサフィックスを付けたもの`t`。 のために`y`の部分を確認します。`t`繰り返しに対応する`y`の倍数です`len(y)`そして、繰り返されるすべてのブロックは同じハッシュを持ちます。`y`。 これにより、検証の繰り返しが軽減されます。`t`文字ごとに`O(1)`ブロックごとのハッシュ比較により、全体的な複雑さが線形になります。`n + m`。 

この観察により、実行不可能な総当たり攻撃が実行可能なローリング ハッシュ ベースのソリューションに変換されます。

 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * m) | お(1) | 遅すぎる |
 | ハッシュ + 分割列挙 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 両方のプレフィックス ハッシュを事前計算します。`s`そして`t`ローリング ハッシュを使用し、ハッシュ ベースの累乗を最大で計算します。`m`O(1) 部分文字列ハッシュ クエリを有効にします。 これにより、文字ごとではなくハッシュによって部分文字列を効率的に比較できるようになります。 
2. 可能なすべての分割点を反復処理します。`i`のために`x`で`s`から`0`に`n`。 それぞれについて`i`、可能な分割点を反復処理します。`j`のために`y`から始まる`i`に`n-1`。 それから`z`暗黙的に`s[j:]`。 
3.「中央部分」の長さを計算します。`t`繰り返しに対応する`y`：これは`m - len(x) - len(z)`。 この長さが次の倍数でない場合は、`len(y)`、この分割はスキップしてください。`y`整数以外の回数を繰り返すことはできません。 
4. のハッシュを比較します。`x`と`t[:len(x)]`そして`z`と`t[-len(z):]`。 これらが一致しない場合は、この分割をスキップします。 
5. 繰り返し回数を計算する`k = (m - len(x) - len(z)) // len(y)`。 のハッシュを比較します`y`あらゆる長さのブロックごとに`len(y)`真ん中に`t`事前に計算されたローリング ハッシュを使用します。 すべてのブロックが一致する場合`y`、このトリプルを有効なものとしてカウントします。 
6. すべての有効なトリプルを合計し、合計を出力します。 

機能する理由: アルゴリズムにより次のことが保証されます。`x`そして`z`のプレフィックスとサフィックスに正確に一致します`t`、そしてそれ`y`繰り返して真ん中を正確に埋めます。 ローリング ハッシュにより正確性が高い確率で保証され、すべての分割を反復処理することで有効なすべてがカバーされます。`(x, y, z)`構成。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9+7
BASE = 31

def compute_hashes(s):
    n = len(s)
    h = [0] * (n+1)
    power = [1] * (n+1)
    for i in range(n):
        h[i+1] = (h[i]*BASE + (ord(s[i]) - ord('a') + 1)) % MOD
        power[i+1] = (power[i]*BASE) % MOD
    return h, power

def get_hash(h, power, l, r):
    return (h[r] - h[l]*power[r-l] % MOD + MOD) % MOD

def main():
    n, m = map(int, input().split())
    s = input().strip()
    t = input().strip()
    
    hs, ps = compute_hashes(s)
    ht, pt = compute_hashes(t)
    
    ans = 0
    for i in range(n+1):  # x ends at i-1
        for j in range(i, n+1):  # y ends at j-1, z = s[j:]
            len_x = i
            len_y = j - i
            len_z = n - j
            
            if len_y == 0:
                continue
            
            middle_len = m - len_x - len_z
            if middle_len <= 0 or middle_len % len_y != 0:
                continue
            
            if get_hash(hs, ps, 0, len_x) != get_hash(ht, pt, 0, len_x):
                continue
            if get_hash(hs, ps, j, n) != get_hash(ht, pt, m - len_z, m):
                continue
            
            k = middle_len // len_y
            valid = True
            y_hash = get_hash(hs, ps, i, j)
            for t_start in range(len_x, len_x + k*len_y, len_y):
                if get_hash(ht, pt, t_start, t_start+len_y) != y_hash:
                    valid = False
                    break
            if valid:
                ans += 1
    print(ans)

if __name__ == "__main__":
    main()
```このソリューションはハッシュを事前計算して、定数時間の部分文字列比較を可能にします。 ネストされたループオーバー`i`そして`j`～の可能な分割を列挙する`x`そして`y`。 ここで分割をスキップします`y`の途中に整数回は収まりません`t`。 検証します`x`そして`z`のプレフィックスとサフィックスと一致します`t`、次に、繰り返しブロックが存在することを確認します。`y`の対応する部分と一致します`t`。 インクリメント`ans`有効なトリプルをそれぞれカウントします。
