 ## 問題の理解

 隠れたモジュラスプロセスによって生成された値を表すと考えられる非負の整数の配列が与えられます。 未知の正の整数が存在します$M$、配列は 2 のべき乗を剰余的に減算して形成されたシーケンスと一致することが期待されます。$M$。 言い換えると、最初の要素は次のように動作する必要があります。$2^0 \bmod M$、2番目のいいね！$2^1 \bmod M$、 等々。 

タスクは、機能する係数を見つけることではなく、正の整数が 1 つだけ存在するかどうかを判断することです。$M$これにより、シーケンス全体がこのルールと一致します。 そのような場合$M$一意に存在するのでそれを出力します。 それ以外の場合は、-1 を出力します。 

入力サイズは最大で$10^5$すべてのテスト ケースにわたって集計された、テスト ファイルごとの値。 これにより、次の候補値を試行するアプローチは即座に除外されます。$M$それぞれの完全なシーケンスをシミュレートします。 二次関数または偶数関数$O(n \sqrt{A_i})$スタイルのソリューションでは遅すぎるでしょう。 

微妙な点は、シーケンスが任意のモジュラー演算ではないことです。 これは厳密にはモジュロの下での決定論的な指数関数的進行であり、構造に大きな制約を与えます。 この構造が再建を可能にするのです。 

素朴な推論を誤解させることがよくある失敗例の 1 つは、すべての値が何らかの候補よりも小さい場合に次のように仮定することです。$M$、さらに大きいもの$M$works. たとえば、シーケンスが次の場合、$[1, 2, 4, 8]$、その後任意$M > 8$preserves equality, meaning there is no unique modulus. これは直接「-1」の場合につながります。 

Another edge case appears when wraparound occurs. For instance, if a value suddenly becomes 0 or repeats earlier values unexpectedly, it suggests that the modulus is small enough to force collisions, and multiple candidate moduli may exist or none at all.

 ## アプローチ

 ブルートフォースのアイデアは定義から始まります。 候補を試してみます$M$すべての用語が一致するかどうかを確認します$2^{i-1} \bmod M$。 それぞれについて$M$、これには配列全体をスキャンする必要があり、潜在的に多くの妥当な値が存在します。$M$。 候補者を次のような範囲に制限することさえ$\max(A_i) + 1$正確性の条件は、観測値との比較だけではなく、モジュールの動作に依存するため、依然として無制限の検索空間が残ります。 

この問題をより生産的に考える方法は、モジュール化プロセスを逆に考えることです。 テストの代わりに$M$、シーケンスがそれにどのような制約を課すかを尋ねます。 

定義から:$$A_{i+1} \equiv 2A_i \pmod{M}$$これは次のことを意味します:$$2A_i - A_{i+1} \equiv 0 \pmod{M}$$したがって、隣接するすべてのペアは、次の値で割り切れる数値を与えます。$M$。 つまり、$M$フォームのすべての値を除算する必要があります$2A_i - A_{i+1}$。 

これにより、問題はこれらの制約に対する最大公約数の計算に直ちに帰着します。 このようなすべての差がゼロの場合、シーケンスは 2 倍化と完全に一致し、ラップすることはありません。これは、次の場合に相当します。$M$には制限がなく、固有の解決策は存在しません。 

それ以外の場合、すべての制約の gcd が唯一の可能な候補係数を与えます。 この候補を計算したら、それが指定されたシーケンスを生成することを検証する必要があります。これは、gcd ベースの再構成では、完全なモジュラー ダイナミクスではなく、ペアごとの一貫性のみが強制されるためです。

 ## アルゴリズムのチュートリアル

 ### 1. 連続した項から制約を構築する

 隣接するペアごとに$(A_i, A_{i+1})$、次を計算します。$$D_i = 2A_i - A_{i+1}$$それぞれ$D_i$未知の係数で割り切れる必要があります$M$。 これにより、シーケンス制約が割り算システムに変換されます。 

### 2. すべての非ゼロ制約の gcd を計算します。 

全体的に実行中の gcd を維持する$D_i \neq 0$。 この gcd は、すべての制約を同時に分割できる最大の整数を表すため、制約の唯一の候補となります。$M$。 

もしすべてなら$D_i$がゼロの場合、限界を導き出すことはできません。$M$、無限に多くの値を意味します$M$は構造を満たしてしまうため、一意性は失われます。 

### 3.「すべての差分がゼロ」の場合を処理する

 すべての場合$D_i = 0$、順序は満たされます$A_{i+1} = 2A_i$その通り。 これは、シーケンスが何もモジュロをラップしないことを意味します。 十分に大きいもの$M$機能するため、固有の係数はありません。 すぐに -1 を返します。 

### 4. 候補係数を検証する

 しましょう$M$計算された gcd になります。 再発をシミュレートします。$$x_1 = A_1, \quad x_{i+1} = (2x_i) \bmod M$$指定された配列が正確に再現されるかどうかを確認します。 いずれかの時点で失敗した場合は、-1 を返します。 

### なぜ効果があるのか

 重要な不変条件は、有効な法はすべての式を除算する必要があるということです。$2A_i - A_{i+1}$。 これは、モジュール反復を書き直すことから直接得られます。 したがって、有効なすべての$M$はすべての制約の gcd の除数セット内にあり、gcd は可能な最大の候補です。 

gcd 候補が検証に失敗した場合、その候補のどの除数も成功することはありません。$M$モジュールのラッピングを強化するだけであり、初期の不整合が発生する可能性があります。 これにより、アルゴリズムが代替の有効な係数を見逃すことがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 1:
        return -1
    
    g = 0
    for i in range(n - 1):
        d = 2 * a[i] - a[i + 1]
        if d != 0:
            if g == 0:
                g = abs(d)
            else:
                import math
                g = math.gcd(g, abs(d))
    
    if g == 0:
        return -1
    
    # verify
    m = g
    cur = a[0]
    for i in range(1, n):
        cur = (2 * cur) % m
        if cur != a[i]:
            return -1
    
    return m

def main():
    t = int(input())
    out = []
    for _ in range(t):
        out.append(str(solve()))
    print("\n".join(out))

if __name__ == "__main__":
    main()
```コアの実装は、再帰を線形制約に変換し、gcd を使用してそれらを圧縮することに重点を置いています。 減算ステップ`2 * a[i] - a[i+1]`で割り切れる可能性を明らかにするために必要な唯一の変換です。$M$。 

gcd 集約はローカル制約の一貫性のみを保証するため、検証フェーズが必要です。 シミュレーションにより、最初の項以降のモジュール進化の全体的な正確性が保証されます。 

実装の微妙な詳細は、否定的な差異の処理です。 割り算は符号の影響を受けないため、gcd の前に絶対値を取得することが不可欠です。

 ## 特殊なケース

 ### すべての差はゼロです

 シーケンスがラップなしで正確に 2 倍になる場合、すべての$D_i = 0$。 アルゴリズムセット$g = 0$そしてすぐに -1 を返します。 これは、無限に多くのモジュライが有効であるため、一意性が侵害されるという事実を正しく捉えています。 

### 負の中間差異

 もし$2A_i < A_{i+1}$、計算された$D_i$マイナスになる。 絶対値を取得すると、割り算は大きさのみに依存するため、gcd 計算が有効なままになります。 

### 初期の不一致

 シーケンスがいずれかの時点でモジュラー ダブリングに違反すると、検証ループはすぐに失敗し、ローカルですべてのペアごとの制約を満たしている場合でも、間違った gcd 候補が拒否されます。
