 ## 問題の理解

 タスクは、次のセットを取得することです。$n^2$整数を並べて、$n \times n$すべての行、すべての列、および両方の対角線の合計が等しくなるような行列。 この合計は魔法定数と呼ばれます$s$。 そのような取り決めが存在することが保証されているため、不可能かどうかを確認する必要はありません。 入力は整数で構成されます$n$続いて$n^2$整数。 出力は次の値です。$s$その後に行列自体が続きます。 

制約は小さいです。$n \le 4$、これはせいぜい$16$数字。 これは、階乗または指数関数的な複雑さを持つアルゴリズムを可能にするため、非常に重要です。これは、大規模なアルゴリズムでは不可能です。$n$。 この問題によって解決策が存在することが保証されるため、解決不可能な構成を考慮する必要はありません。 

明らかではないエッジ ケースは、対角和を満たすために一部の数値が特定の位置を占有する必要がある重複した数値または配列から発生します。 たとえば、次の場合$n=3$そしてその数字は$2,2,2,2,2,2,2,2,2$、すべての合計が同一であるため、どのような配置も魔方陣を満たします。 不注意なアルゴリズムは、異なる数値を想定したり、不必要に一意性を強制しようとしたりする可能性があります。 もう 1 つの微妙なケースは、数値の大きさが大きく異なる場合に発生します。この場合、不適切な貪欲な配置により、行と列が正しいにもかかわらず、対角線上の魔法定数に違反する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、指定されたすべての順列を生成することです。$n^2$数値を行列に配置し、行、列、対角線の合計が等しいかどうかを確認します。 のために$n=3$、 がある$9! = 362{,}880$順列、および$n=4$、$16! \approx 2.1 \times 10^{13}$、これは明らかに実行不可能です。 段階的に合計をチェックして最適化したとしても、$n=4$純粋な総当たり力を使用するには大きすぎるままです。 

重要な洞察は、小さな入力サイズと魔方陣の既知の構造から得られます。 のために$n=3$、魔方陣は、最大値、最小値、および中央値の位置に固定パターンがある古典的な Lo Shu 正方形を反映する順序で数字を配置することで常に取得できます。 のために$n=4$、デューラー正方形パターンなど、4x4 の魔方陣の既知のテンプレートがあり、固定マスクに従って任意の複数セットの数字を配置できます。 したがって、問題は数値を並べ替えて、事前に計算された魔方陣テンプレートにマッピングすることになります。 このアプローチにより、合計が自動的に一致することが保証され、その複雑さは並べ替えによって支配されます。$O(n^2 \log n^2)$、これは些細なことです$n \le 4$。

 ## アルゴリズムのチュートリアル

 1. の入力値を読み取ります。$n$そしてのリスト$n^2$整数。 
2. 数値のリストを並べ替えます。 並べ替えは、魔方陣のプロパティを保持するテンプレートに数値を一貫してマッピングするのに役立ちます。 
3. 指定された魔方陣テンプレートを選択します。$n$。 のために$n=3$、位置に 0 ～ 8 のラベルが付いた古典的な Lo Shu 正方形テンプレートを使用します。$n=4$、位置 0 ～ 15 の固定 4x4 魔方陣テンプレート (デューラー正方形など) を使用します。 
4. ソートされた数値を昇順でテンプレートの位置にマッピングします。 テンプレートは、行、列、対角についてマジック サムが満たされることを保証します。 
5. マジックサムを計算する$s$塗りつぶされた行列の任意の行を合計することによって。 
6. 出力$s$次に行列を行ごとに表示します。 

機能する理由: ソートされた数値から既知の魔方陣テンプレートへのマッピングでは、増加する割り当ての魔方陣を満たす相対位置がテンプレートで定義されているため、合計が不変に保たれます。 並べ替えると、数値が一貫して位置を埋め、マジック サムが保証されます。 この問題によって解決策が存在することが保証されるため、このマッピングによって常に有効な魔方陣が生成されることがわかります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def main():
    n = int(input())
    a = list(map(int, input().split()))
    a.sort()

    if n == 3:
        # Lo Shu square template indices
        template = [
            [0, 1, 2],
            [3, 4, 5],
            [6, 7, 8]
        ]
    elif n == 4:
        # Durer 4x4 magic square template indices
        template = [
            [0, 15, 14, 1],
            [12, 7, 6, 9],
            [8, 11, 10, 5],
            [4, 3, 2, 13]
        ]
    else:
        template = [[i*n+j for j in range(n)] for i in range(n)]

    # Create empty matrix
    matrix = [[0]*n for _ in range(n)]
    flat_matrix = [0]*(n*n)
    
    # Assign numbers according to template
    for i in range(n):
        for j in range(n):
            idx = template[i][j]
            flat_matrix[idx] = a.pop(0)
    
    # Fill matrix from flat_matrix
    for i in range(n):
        for j in range(n):
            matrix[i][j] = flat_matrix[i*n + j]
    
    # Calculate magic sum
    s = sum(matrix[0])
    print(s)
    for row in matrix:
        print(" ".join(map(str, row)))

if __name__ == "__main__":
    main()
```コードは、入力を読み取り、数値を並べ替えることから始まります。 のために$n=3$そして$n=4$、事前に計算された魔方陣テンプレートを使用します。 テンプレートの位置に番号が順番に割り当てられ、最初の行からマジック サムが計算されます。 最後に、行列が行ごとに出力されます。 テンプレートを使用する場合、Python でのゼロベースのインデックス付けの処理には注意が必要です。
