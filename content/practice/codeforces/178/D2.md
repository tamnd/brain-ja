 ## 解決策
 ## 問題の理解

 を構築するように求められています。$n \times n$指定されたマルチセットを使用した魔方陣$n^2$整数。 魔方陣には、すべての行、すべての列、および両方の対角線の合計が等しいという特性があります。 入力により提供されるのは、$n$そして、次のフラットリスト$n^2$整数であり、出力はマジック サム プロパティを満たすこれらの数値を正方形に配置したものでなければなりません。 さらに、マジック サム自体を出力する必要があります。 

制約は小さいです。$n \le 4$。 のために$n=1$これは些細なことです。 のために$n=2$任意の整数に対して魔方陣は存在しない可能性がありますが、この問題は解決策を保証します。 のために$n=3$または$n=4$、可能な順列の総数$n^2$整数は最大でも$16! \approx 2 \times 10^{13}$、総当たり探索するには大きすぎます。 ただし、サイズが小さいため、枝刈りや組み合わせの最適化による再帰的なバックトラックが可能です。 

明らかではないエッジケースには、多くの数値が等しい状況が含まれます。 例えば、$n=3$すべての数値が 5 に等しい場合、すべてのエントリが 5 でマジック サムが 15 の正方形が生成されます。もう 1 つの注意が必要なケースは、整数の 1 つの配列のみが行、列、および対角の和を満たす場合です。そのため、アルゴリズムは正しくバックトラックし、途中で部分和を受け入れないようにする必要があります。 

## アプローチ

 単純なアプローチでは、数値のすべての順列を試し、それぞれのマジック サム プロパティをチェックします。 これは正しいです。行、列、および対角の和を満たす有効な順列はすべて解となるからです。 ただし、順列の階乗増加により、このアプローチは実行不可能になります。$n > 2$、 以来$9! = 362{,}880$そして$16! \approx 2 \times 10^{13}$2 秒以内に合理的な計算を超えます。 

重要な点は、すべての順列を盲目的に試す必要はないということです。 問題によって解決策が存在することが保証され、$n \le 4$。 したがって、再帰的なバックトラッキング アプローチがうまく機能します。行の合計、列の合計、対角の合計を追跡しながら、セルごとに正方形を埋めていきます。 各ステップで、数値を入力すると有効なマジック サムに到達できなくなるかどうかを確認します。 そうであれば、そのブランチをスキップします。 これにより、すべての順列を探索する場合と比較して、探索スペースが大幅に削減されます。 

のために$n=3$そして$n=4$、サイズが小さく、解の存在が保証されているため、バックトラッキングは十分に高速であり、数値の並べ替えや最初に中心/対角線を埋めるなどの追加の最適化により、バックトラッキングをさらに高速化できます。

 ## アルゴリズムのチュートリアル

 1.読む$n$そしてのリスト$n^2$整数。 すべての数値の合計を計算し、で割ります。$n$マジックサムを決定するには$s$。 これが機能するのは、魔方陣ではそれぞれの$n$行の合計は$s$したがって、合計は次のようになります。$n \cdot s$。 
2. を初期化します。$n \times n$グリッドはゼロで埋められます。 各行と列の現在の合計の配列と、主対角和と副対角和の 2 つの変数を維持します。 
3. 使用可能な数値のカウンタを作成します。これにより、現在のセルで未使用の数値を 1 回ずつ効率的に試すことができます。 
4. グリッドを埋めるための再帰関数を定義します。 各ステップで、行優先の順序で次の空のセルを選択します。 まだ利用可能な各数値について、それをセルに配置し、行、列、および対角の和を更新してみてください。 配置により合計が超過する場合$s$、すぐに後戻りしてください。 
5. 最後のセルに到達し、すべての行、列、および対角の合計が等しい場合$s$、有効な魔方陣が見つかり、再帰を停止できます。 
6. 出力$s$そして塗りつぶされたグリッド。 

機能する理由: 各再帰ステップで、アルゴリズムは、行、列、または対角の合計がマジック サムを超えないという不変条件を維持します。 解決策が保証されているため、バックトラッキングにより最終的には正しい配置が探索され、プルーニングにより不可能な配置を探索することがなくなります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import Counter

def solve():
    n = int(input())
    nums = list(map(int, input().split()))
    s = sum(nums) // n
    
    grid = [[0]*n for _ in range(n)]
    row_sum = [0]*n
    col_sum = [0]*n
    diag_main = 0
    diag_anti = 0
    
    count = Counter(nums)
    positions = [(i, j) for i in range(n) for j in range(n)]
    
    def backtrack(pos):
        nonlocal diag_main, diag_anti
        if pos == n*n:
            return True
        i, j = positions[pos]
        for x in list(count.keys()):
            if count[x] == 0:
                continue
            if row_sum[i]+x > s or col_sum[j]+x > s:
                continue
            if i == j and diag_main + x > s:
                continue
            if i + j == n-1 and diag_anti + x > s:
                continue
            # place x
            grid[i][j] = x
            row_sum[i] += x
            col_sum[j] += x
            if i == j:
                diag_main += x
            if i + j == n-1:
                diag_anti += x
            count[x] -= 1
            if backtrack(pos+1):
                return True
            # undo
            grid[i][j] = 0
            row_sum[i] -= x
            col_sum[j] -= x
            if i == j:
                diag_main -= x
            if i + j == n-1:
                diag_anti -= x
            count[x] += 1
        return False
    
    backtrack(0)
    print(s)
    for row in grid:
        print(' '.join(map(str, row)))

if __name__ == "__main__":
    solve()
```ソリューションはまずマジック サムを計算します。$s$すべての数値の合計から。 It then uses a recursive backtracking function to fill the grid, checking at each step that row, column, and diagonal sums do not exceed$s$。 カウンタは、各数値が指定された回数だけ使用されることを保証します。
