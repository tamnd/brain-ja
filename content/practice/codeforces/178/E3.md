 ## 解決策
 ## 問題の理解

 として表される正方形のモノクロ画像が与えられます。$n \times n$マトリックス。各要素は 0 (背景が白) または 1 (前景が黒) です。 この画像内には、正方形または円のいくつかの異なる幾何学的形状があります。 タスクは、円と四角がいくつ存在するかを判断することです。 形状は任意に回転でき、最大 20% のピクセルにノイズが発生し、色が反転する場合があります。 主な制約は、形状が十分に大きく (直径 15 ピクセル以上)、少なくとも 10 ピクセル離れていて、形状の総数が 50 を超えないことです。 

入力サイズ$n$これにより、ピクセルごとに重い演算を実行する場合、ピクセル数が 2 次またはそれより劣るアルゴリズムが即座に除外されます。 理想的には、ピクセル数に応じて線形またはほぼ線形にスケールするソリューションを設計する必要があります。$O(n^2)$最悪の場合、総ピクセル数は約$4 \times 10^6$。 

単に幾何学的テンプレートをあらゆる可能な位置に適合させようとする単純なアプローチは、ノイズと回転のために失敗します。 もう 1 つのエッジ ケースは、正方形が 45 度回転された場合です。その境界ボックスが辺の長さよりも大きくなるため、単純な軸合わせチェックでは誤って分類される可能性があります。 形状が小さいかノイズしきい値に近い場合、不注意なアルゴリズムにより同じ形状が複数回カウントされたり、完全に見逃されたりする可能性があります。 

たとえば、45 度回転した 20×20 ピクセルの正方形は、28×28 の境界ボックスを占める可能性があります。 単純に面積と周囲の比率をチェックすると、円として誤分類される可能性があります。 正しい取り扱いでは、回転と騒音を考慮する必要があります。 

## アプローチ

 ブルートフォース手法では、すべてのピクセルを反復処理し、黒ピクセルの接続されたコンポーネントを見つけて、各コンポーネントを正方形または円として分類しようとします。 これが機能するのは、形状が十分に分離されており、各コンポーネントが 1 つの形状に対応しているためです。 コンポーネントの検索は、BFS または DFS で実現できます。 コンポーネントを見つけた後、その境界ボックス、面積、周囲長、および次のような単純な円形度メトリックを計算できます。$\text{compactness} = \frac{4 \pi \cdot \text{area}}{\text{perimeter}^2}$。 円のコンパクトさは 1 に近く、正方形 (回転したものであっても) のコンパクトさはわずかに小さくなりますが、ノイズにより分散が生じます。 

課題はノイズと回転に対する堅牢性です。 1 つの洞察は、形状が大きく分離されているため、小さなノイズのあるピクセルは侵食/拡張などの形態学的操作で除去するか、主連結成分を数えるときに単純に無視できるということです。 もう 1 つは、回転した正方形の角が鋭く、コンパクトさが損なわれる一方、円は滑らかなままであることです。 BFS を使用してメインブロブを抽出し、形状の 2 次モーメント (ピクセル座標の共分散) を計算することで、偏心率と方向を推定できます。 円は x と y の分散がほぼ同じですが、正方形は回転するとわずかに異なる場合があります。 

したがって、最適なソリューションは、標準の連結成分のラベル付けと、形状タイプを分類するための堅牢なメトリックの組み合わせです。 BFS または DFS が実行される$O(n^2)$、形状分類はコンポーネントのピクセル数において線形です。 これは十分に高速です$n \le 2000$コンポーネント数は 50 未満です。

## アルゴリズムのチュートリアル

 1. を読んでください。$n \times n$ピクセルマトリックス。 処理を容易にするために、それをブール グリッドに変換します。 
2. どのピクセルがコンポーネントに割り当てられているかを追跡するために、同じサイズの訪問済み行列を初期化します。 
3. 各ピクセルを反復処理します。 ピクセルが黒 (1) で未訪問の場合は、BFS を開始して、接続されているすべての黒ピクセルを抽出します。 それらを現在のコンポーネントを表すリストに追加します。 
4. BFS が完了したら、コンポーネントの面積をピクセル数と境界ボックスの寸法 (x と y の最小値と最大値) として計算します。 
5.重心を計算する$(cx, cy)$そして二番目の瞬間$\text{var}_x, \text{var}_y, \text{cov}_{xy}$。 これらを使用して、形状の偏心と方向を推定します。 ほぼ円形のコンポーネントには、$\text{var}_x \approx \text{var}_y$そして低い偏心率。 正方形を回転すると、対角線に沿ってわずかに変化が現れます。 
6. コンパクトさの指標を計算する$C = \frac{4 \pi \cdot \text{area}}{\text{perimeter}^2}$。 サークルには、$C \approx 1$、正方形がわずかに少なくなります。 偏心率とコンパクトネスのしきい値を組み合わせて、形状を確実に分類します。 
7. 対応する円または四角のカウンターをインクリメントします。 すべてのピクセルが訪問されるまで繰り返します。 
8. 2 つのカウントを出力します。 

不変条件は、分離が保証されているため、各連結コンポーネントが正確に 1 つの形状に対応するということです。 BFS では、形状のすべてのピクセルが 1 回カウントされることが保証され、形状の最小サイズが大きいため、幾何学的メトリクスはノイズや回転に対して堅牢になります。 

## Python ソリューション```python
import sys
from collections import deque
import math
input = sys.stdin.readline

def main():
    n = int(input())
    grid = [list(map(int, input().split())) for _ in range(n)]
    visited = [[False]*n for _ in range(n)]

    circles = 0
    squares = 0

    dx = [0,0,1,-1,1,1,-1,-1]
    dy = [1,-1,0,0,1,-1,1,-1]

    def bfs(sx, sy):
        q = deque()
        q.append((sx, sy))
        visited[sx][sy] = True
        pixels = []
        while q:
            x, y = q.popleft()
            pixels.append((x, y))
            for d in range(8):
                nx, ny = x + dx[d], y + dy[d]
                if 0 <= nx < n and 0 <= ny < n and grid[nx][ny] and not visited[nx][ny]:
                    visited[nx][ny] = True
                    q.append((nx, ny))
        return pixels

    def classify(pixels):
        area = len(pixels)
        xs = [x for x,_ in pixels]
        ys = [y for _,y in pixels]
        cx, cy = sum(xs)/area, sum(ys)/area
        var_x = sum((x - cx)**2 for x in xs)/area
        var_y = sum((y - cy)**2 for y in ys)/area
        cov_xy = sum((x - cx)*(y - cy) for x,y in pixels)/area
        # Eccentricity estimate
        trace = var_x + var_y
        det = var_x*var_y - cov_xy**2
        if trace == 0:
            e = 0
        else:
            e = math.sqrt(max(trace**2 - 4*det, 0)) / trace
        if e < 0.25:
            return 'circle'
        return 'square'

    for i in range(n):
        for j in range(n):
            if grid[i][j] and not visited[i][j]:
                comp = bfs(i,j)
                shape = classify(comp)
                if shape == 'circle':
                    circles += 1
                else:
                    squares += 1

    print(circles, squares)

if __name__ == "__main__":
    main()
```BFS 関数は、形状のすべてのピクセルを収集します。 の`classify`関数は重心と共分散を使用して離心率を推定します。 円は x 方向と y 方向にほぼ均等に広がり、離心率が低くなります。 このメトリクスはノイズと回転を許容します。
