 ## 問題の理解

 指定されたセットを手配するように求められます。$n^2$整数を$n \times n$魔方陣を形成するようにマトリックスを作成します。 魔方陣は、すべての行、すべての列、および 2 つの主対角線の合計が同じ値になる行列として定義されます。$s$。 入力はサイズを提供します$n$そして、次のフラットリスト$n^2$整数。 出力は合計です$s$その後に行列自体が続き、入力からの各数値が指定された回数だけ出現します。 

制約の限界$n$満点の場合は最大 4 まで。 と$n \leq 4$、の順列の数$n^2$数字はせいぜい$16!$、大まかに言うと$2 \times 10^{13}$。 これは単純に調査するには大きすぎるため、総当たりで列挙することは不可能です。 小さいサブケースは、$n \leq 3$または、最大 9 個の異なる数字は、盲目的な検索に依存するのではなく、対称性と組み合わせパターンを活用できることを示唆しています。 

微妙な点は、数字が繰り返される可能性があるため、一意性を前提とした単純な配置は失敗する可能性があることです。 たとえば、入力が次の場合`2 2 2 2`のために$n = 2$、総当り順列ジェネレーターは 1 つの一意の配置のみを考慮しますが、4 つの位置すべてに以下が含まれている必要があります。`2`、および合計$s = 4$。 同様に、主対角線と副対角線が重なる場合があります（奇数の場合は中央）。$n$）のため、共有ポジションの取り扱いには注意が必要です。 

## アプローチ

 ブルートフォースアプローチでは、次のすべての順列が生成されます。$n^2$数値を入力し、正方形を埋めて、合計条件が満たされるかどうかを確認します。 これが機能するのは、問題によって解決策が存在することが保証され、最終的には解決策が見つかるからです。 ただし、順列の数は階乗的に増加するため、これは許容できません。$n = 4$あるいは$n = 3$if we are not exploiting duplicates.

 重要な観察は、正方形内の位置の数が少なく、魔方陣の構造が厳格であるということです。 のために$n = 3$、古典的な Lo Shu 正方形は、中心が常に数値の中央値になる固定パターンを示します。 大型の場合$n$、位置をコーナー、エッジ、中心として分類できます。 各クラスは行、列、対角の合計に同じ寄与を持ち、これらの対称クラスに従って数値を配置できます。 のために$n = 4$最大 9 つの異なる数値を使用する場合、ほとんどの配置が早期に合計制約に違反し、検索が枝刈りされるため、少数の一意の数値をバックトラックするのが効率的です。 

最適なアプローチとして、プルーニングを伴うバックトラッキングを使用します。 行、列、対角線の累計を維持しながら、正方形の位置に数字を順番に配置しようとします。 いずれかの時点で部分合計が目標合計を超える場合、またはすべての合計を満たすことが不可能になる場合は、後戻りします。 正方形の対称性により、共有位置を正しく処理できるようになり、不必要な分岐が減少します。

 ## アルゴリズムのチュートリアル

 1. それぞれの異なる数値の出現数を数えます。 これにより、複数の位置で同じ数値を不必要に繰り返し試行することを避けることができます。 
2. 埋めるポジションのリストを定義します。理想的には、最も制約の多いポジションが最初に配置される順序で行います。 コーナーと対角線はより多くの合計に参加するため、早めに実行する必要があります。 
3. 各行、列、および 2 つの対角線の累計を維持します。 これにより、早期の枝刈りが可能になります。数値を配置した結果、残りの数値では合計が達成できなくなった場合は、すぐに後戻りします。 
4. 使用可能なプールから現在の位置に数値を配置しようとする再帰関数を実装します。 配置後、その数のカウントをデクリメントします。 次の位置に戻ります。 再帰後、カウントを復元します (バックトラッキング)。 
5. すべての位置が埋まったら、すべての行、列、対角の合計が候補の合計と等しいかどうかを確認します。 「はい」の場合は、溶液を保管して戻ります。 この問題では解決が保証されているため、最初に見つかった有効な正方形を出力できます。 
6. 再帰の前に、目標の合計を推測してみます$s$制約から。 小型用$n$1 つのオプションは、数値を並べ替えて行合計の平均を計算することです。$s = \text{sum(numbers)} / n$。 これが機能するのは、各行と列の合計が同じになる必要があるためです。$s$、合計は正確に$n \cdot s$。 

### なぜ効果があるのか

 不変条件は、すべての再帰ステップで、配置されたすべての数値が行、列、および対角線の部分和を満たすということです。 この不変式に違反する枝を枝刈りすることで、見つかった完全な正方形が魔方陣の特性を満たすことが保証されます。 徹底的な探索は実行可能な配置のみを対象とするため、正確性は保たれます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    nums = list(map(int, input().split()))
    target_sum = sum(nums) // n
    from collections import Counter
    counts = Counter(nums)
    
    grid = [[0]*n for _ in range(n)]
    rows = [0]*n
    cols = [0]*n
    diag1 = 0
    diag2 = 0
    positions = [(i, j) for i in range(n) for j in range(n)]
    
    found = False
    
    def backtrack(idx):
        nonlocal found, diag1, diag2
        if found:
            return
        if idx == n*n:
            if all(r == target_sum for r in rows) and all(c == target_sum for c in cols) and diag1 == target_sum and diag2 == target_sum:
                print(target_sum)
                for row in grid:
                    print(' '.join(map(str, row)))
                found = True
            return
        i, j = positions[idx]
        for num in list(counts.keys()):
            if counts[num] == 0:
                continue
            # check feasibility
            rows[i] += num
            cols[j] += num
            if i == j:
                diag1 += num
            if i + j == n - 1:
                diag2 += num
            counts[num] -= 1
            
            if all(rows[k] <= target_sum for k in range(n)) and all(cols[k] <= target_sum for k in range(n)) and diag1 <= target_sum and diag2 <= target_sum:
                grid[i][j] = num
                backtrack(idx+1)
                grid[i][j] = 0
            
            rows[i] -= num
            cols[j] -= num
            if i == j:
                diag1 -= num
            if i + j == n - 1:
                diag2 -= num
            counts[num] += 1
    
    backtrack(0)

solve()
```このソリューションでは、最初に目標合計を計算し、次に再帰的にグリッドを埋めます。 カウンターにより、重複が効率的に処理されます。 早期に枝刈りを行うと、不可能な部分和の探索が回避されます。 位置は自然な行優先の順序で反復され、奇数の中心での重複を考慮して対角線が動的に更新されます。$n$。
