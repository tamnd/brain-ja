 ## 解決策
 ## 問題の理解

 として表される大きなバイナリ イメージが与えられます。$n \times n$グリッド。各セルは白または黒です。 黒いセルはいくつかの切り離された形状を形成し、それぞれの形状は円または正方形のいずれかであることが保証されており、任意に回転する可能性があります。 

タスクは、画像内にいくつの円といくつの四角形が存在するかを数えることです。 

重要な問題は、画像にノイズが多いことです。各ピクセルが確率 0.2 で独立して反転される可能性があるため、一部の白いピクセルが黒に見えたり、その逆の場合もあります。 それにもかかわらず、各オブジェクトは大きく、他のオブジェクトから十分に分離されているため、元の形状の幾何学的構造が目に見えるままになります。 

制約は非常に厳しいです。$n$最大 2000、つまり最大 400 万ピクセルになります。 ピクセルごとに線形または線形に近い処理以上の処理を行うソリューション、特にコンポーネントごとまたは形状ごとに 2 次のものは失敗します。 これにより、コンポーネントごとに多くの候補曲線または回転を試行する幾何学的フィッティング手法が即座に排除されます。 

もう 1 つの重要な構造的保証は分離です。 2 つの形状は少なくとも 10 ピクセル離れており、各形状のスケールは少なくとも 15 ピクセルです。 これにより、ノイズ下であっても、グリッド感覚で接続されたコンポーネントが個々のオブジェクトに厳密に対応することが保証されます。 

単純な間違いは、ノイズによって接続が切断されると想定することです。たとえば、次のようになります。 

入力フラグメント:```
000000
001100
001100
000000
```ノイズによって数ピクセルが反転した場合、不注意な BFS により、近くにある 2 つの形状がマージされたり、1 つの形状が複数のコンポーネントに分割されたりする可能性があります。 分離距離を確保することでオブジェクト間の結合は防止されますが、ノイズによって内部に穴やブリッジが発生する可能性があるため、きれいな輪郭に頼ることはできません。 

もう 1 つの微妙な失敗例は、バウンディング ボックスだけに依存している場合です。 回転した正方形と円は非常によく似た境界ボックスを共有する可能性があるため、幅と高さのみに基づく分類子は失敗します。```
a filled rotated square and a filled circle can both have nearly equal width and height
```したがって、ノイズや回転に対して安定した形状記述子が必要です。 

## アプローチ

 直接的な総当たりアプローチでは、各接続コンポーネントを抽出し、それを幾何学的モデルと比較することによって分類しようとします。 各コンポーネントについて、円のフィッティング (中心と半径の推定) または正方形のフィッティング (すべての方向を試してエッジの一貫性を検証) を試みることができます。 ただし、正方形の任意の回転をフィッティングするには、角度検索または PCA ベースの位置合わせとそれに続く境界チェックのいずれかが必要です。 各チェックには、コンポーネントごとに潜在的に数千のピクセルをスキャンし、複数の仮説を試すことが含まれます。 最大 50 の形状と最大 400 万ピクセルの場合、特に回転フィッティングで別の乗算係数が導入される場合、最悪の場合の作業は法外なものになります。 

重要な観察は、円と正方形は、重心からの動径分散という非常に安定した統計的特性において異なるということです。 円は中心からの距離が一定ですが、正方形は回転した場合でも境界までの距離が非常に不均一になります。 ノイズはピクセルを局所的に混乱させますが、このグローバルな分布を破壊することはありません。 したがって、ジオメトリを明示的にフィッティングする代わりに、各接続コンポーネントの重心を計算し、重心からの距離がどのように動作するかを測定できます。 

これにより、問題は接続コンポーネントとコンポーネントごとの定数時間分類に縮小されます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | 形状ごとのブルート フォース幾何学フィッティング |$O(k \cdot s \cdot t)$|$O(n^2)$| 遅すぎる |
 | 接続コンポーネント + 形状統計 |$O(n^2)$|$O(n^2)$| 承認済み |

 ここ$k \le 50$、$s$は形状サイズ、そして$t$ブルートフォースでの回転またはフィッティング試行の回数です。 

## アルゴリズムのチュートリアル

 1. グリッドをスキャンし、BFS または DFS を使用して黒ピクセルの連結成分を抽出します。 

未訪問の各黒ピクセルは新しいコンポーネントを開始し、画像内のピクセル接続によって暗示される隣接定義に応じて 4 方向または 8 方向にフラッドフィルします。 分離制約により、各 BFS が 1 つの形状だけを分離するようになります。 
2. コンポーネントを収集するときに、そのすべてのピクセル座標を保存し、その重心を計算します。 

重心は、コンポーネント内のすべてのピクセルの x 座標と y 座標の平均として計算されます。 これにより、適度なノイズ下でも安定した基準点が得られます。 
3. コンポーネント内の各ピクセルについて、重心までの二乗ユークリッド距離を計算します。 

二乗距離は十分であり、浮動小数点平方根を回避できるため、安定性と速度が向上します。 
4. これらの距離に関する 2 つの統計値、つまり平均距離と分散 (または最大距離と最小距離の比) を計算します。 

円は密に集中した距離を生み出します。 正方形は、コーナーがエッジの中点よりも重心から遠いため、より広い広がりを生成します。 
5. 分散対平均比のしきい値に基づいてコンポーネントを分類します。 

分散が小さい場合は円を示し、分散が大きい場合は正方形を示します。 形状の最小サイズが保証されているため、しきい値は堅牢です。 
6. 各クラスに分類されるコンポーネントの数を数え、最終的な合計を出力します。 

### なぜ効果があるのか

 各形状は、その重心からの距離の分布を引き起こします。 完全な円の場合、すべての境界点は中心から等距離にあるため、分散はゼロに近くなります。 正方形の場合、回転した場合でも、コーナー近くの点はエッジ近くの点よりも重心から大幅に離れており、特徴的な高分散パターンが生成されます。 ノイズは局所的な摂動を引き起こしますが、このグローバルな距離分布を体系的に歪めることはありません。 形状が大きく、十分に分離されているため、重心推定値は最大 20% のピクセル反転の下でも安定したままになります。 

重要な不変条件は、重心ベースの動径統計が、適度なランダム ノイズの下でも円と正方形の間の厳密な順序を維持することです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import deque

n = int(input())
grid = [list(map(int, input().split())) for _ in range(n)]

vis = [[False] * n for _ in range(n)]

dirs = [(1,0), (-1,0), (0,1), (0,-1)]

def bfs(i, j):
    q = deque()
    q.append((i, j))
    vis[i][j] = True
    cells = []

    while q:
        x, y = q.popleft()
        cells.append((x, y))
        for dx, dy in dirs:
            nx, ny = x + dx, y + dy
            if 0 <= nx < n and 0 <= ny < n:
                if not vis[nx][ny] and grid[nx][ny] == 1:
                    vis[nx][ny] = True
                    q.append((nx, ny))
    return cells

circles = 0
squares = 0

for i in range(n):
    for j in range(n):
        if grid[i][j] == 1 and not vis[i][j]:
            comp = bfs(i, j)
            k = len(comp)

            sx = sy = 0
            for x, y in comp:
                sx += x
                sy += y

            cx = sx / k
            cy = sy / k

            dist = []
            for x, y in comp:
                dx = x - cx
                dy = y - cy
                dist.append(dx * dx + dy * dy)

            mean = sum(dist) / k
            var = sum((d - mean) ** 2 for d in dist) / k

            if var < mean * 0.15:
                circles += 1
            else:
                squares += 1

print(circles, squares)
```コードは、接続されている各コンポーネントを分離するための BFS フラッドフィルで始まります。 最小限の分離により、ノイズが発生した後でもコンポーネントが接触しないことが保証されるため、これは安全です。 

各コンポーネントについて、整数の累算とそれに続く浮動小数点除算を使用して重心を計算します。 正規化せずにピクセル座標を直接使用すると、形状サイズが異なると分散が無意味になってしまうため、この手順は重要です。 

数値の不安定性を避けるために、距離は二乗距離として計算されます。 分散計算では、成分の数が少ないため、オンライン手法ではなく直接定義が使用されます。 

しきい値$0.15$は、問題の制約の下で円と四角形によって引き起こされる 2 つの分布の間の安定した分離子として選択されます。

def run(inp: str) -> str:

    import sys
    input = sys.stdin.readline

    n = int(input())
    grid = [list(map(int, input().split())) for _ in range(n)]
    vis = [[False]*n for _ in range(n)]
    from collections import deque
    dirs = [(1,0),(-1,0),(0,1),(0,-1)]

    def bfs(i,j):
        q=deque([(i,j)])
        vis[i][j]=True
        comp=[]
        while q:
            x,y=q.popleft()
            comp.append((x,y))
            for dx,dy in dirs:
                nx,ny=x+dx,y+dy
                if 0<=nx<n and 0<=ny<n and not vis[nx][ny] and grid[nx][ny]==1:
                    vis[nx][ny]=True
                    q.append((nx,ny))
        return comp

    circles=squares=0
    for i in range(n):
        for j in range(n):
            if grid[i][j]==1 and not vis[i][j]:
                comp=bfs(i,j)
                sx=sum(x for x,_ in comp)
                sy=sum(y for _,y in comp)

                var=sum((d-mean)**2 for d in dist)/len(dist)
                if var<mean*0.15:
                    circles+=1
                else:
                    squares+=1

    return f"{circles} {squares}"

 ## 特殊なケース

 クリティカル エッジ ケースは、ピクセルの反転により円に小さな「スパイク」が発生する非常にノイズの多い境界です。 分離保証により複数のコンポーネントへの断片化が防止されるため、BFS は依然としてそれを 1 つのコンポーネントとして扱います。 重心はわずかにシフトしますが、すべての距離値は一貫してシフトし、低い分散を維持します。 

もう 1 つのエッジ ケースは、角がひどく破損している回転した正方形です。 一部のコーナー ピクセルが白に反転された場合でも、残りの構造は依然として二峰性の距離分布を生成します。エッジ ピクセルはしっかりとクラスター化されますが、生き残ったコーナー ピクセルはかなり遠くに残ります。 分散は依然として十分に高いため、分類しきい値を上回っています。 

3 番目のエッジ ケースは、最小サイズの 15 ピクセルに近い非常に小さな形状です。 ここでも、分離保証により、意味のある重心推定に十分なサンプルが存在することが保証され、分散計算により、円状の均一性と正方形状の異方性が分離されます。
