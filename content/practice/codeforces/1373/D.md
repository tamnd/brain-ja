 ## 解決策

 ## 問題の理解

 いくつかの配列が与えられ、各配列に対して実行できる操作は最大 1 つだけです。つまり、連続セグメントを選択し、それを反転します。 このオプションの変更後は、偶数のインデックス、つまり位置 0、2、4 などにある要素のみを調べ、それらの合計ができるだけ大きくなるようにします。 

逆転がなければ、寄与は固定されます。偶数のインデックスにあるすべての要素が答えに寄与します。 この難しさは、セグメントを反転すると要素が偶数位置と奇数位置の間で移動するという事実から来ており、これによりパリティ全体でどの値が交換されるかに応じて合計が改善または悪化する可能性があります。 

制約は厳しく、すべてのテスト ケースの全長は最大 2 · 10^5 であるため、すべてのセグメントを試行したり反転をシミュレートしたりするソリューションは、すぐに遅すぎます。 テスト ケースごとの 2 次スキャンはすでに大きすぎるため、3 次スキャンは不可能です。 

何もしないのが最適な動きである場合、微妙なエッジケースが発生します。 たとえば、すべての要素が等しい場合、またはパリティを交換しても寄与が増加しない場合、セグメントを反転すると同一の値のみが再分配されるため、答えは元の偶数インデックスの合計と等しくなる必要があります。 もう 1 つの注意が必要なケースは、長さが 2 の非常に短いセグメントから最良の改善が得られる場合です。これは、2 つの隣接する要素を効果的に交換し、パリティの寄与を局所的に変更します。 長いセグメントのみを考慮するアプローチでは、この改善は見逃されます。 

## アプローチ

 開始点は、反転が偶数インデックスの合計に実際にどのような影響を与えるかを理解することです。 セグメント [l, r] を反転するとします。 このセグメント内では、位置が反転します。インデックス i にあった要素は、r - (i - l) に移動します。 これは、パリティの変更がセグメントの端からの距離のみに依存することを意味します。 セグメントの外側の要素は影響を受けません。 

ブルート フォース ソリューションでは、考えられるすべてのセグメントを試し、逆転をシミュレートし、偶数インデックスの合計を再計算します。 各シミュレーションのコストは O(n) で、セグメント数は O(n^2) なので、全体では O(n^3) となり、これは実現可能な限界をはるかに超えています。 

重要な点は、配列全体を再計算する必要がないということです。 パリティが反転したときに寄与がどのように変化するかを追跡する必要があるだけです。 セグメントが反転されると、セグメント内の位置のペアが偶数インデックスと奇数インデックスの間で役割を効果的に交換します。 これは、任意のセグメントの効果を一連のローカル ゲイン寄与に分解できることを示唆しています。 

標準的なトリックは、パリティに基づいて寄与を分離し、元は奇数のインデックスにあった要素を反転後に偶数のスロットと組み合わせることによってどれだけ得られるか、またはその逆を調べることです。 セグメントの左側の境界を固定すると、サブ配列の最大合計と同様の貪欲な拡張を使用して最適な右側の境界を決定できます。この拡張では、交互のパリティ差からゲインを蓄積します。 

具体的には、基本となる答え (偶数のインデックスの合計) を事前に計算します。 次に、反転が偶数インデックスで始まるか奇数インデックスで始まるかに応じて 2 つの独立したケースを検討します。 それぞれのケースについて、ペアリングの位置が次のいずれかに寄与する潜在的な利益の配列を構築します。`a[j] - a[j-1]`または`a[j-1] - a[j]`パリティアライメントに応じて異なります。 問題は、この変換された配列の最大サブ配列合計を見つけることに帰着します。これにより、セグメント反転の最良の改善が得られます。 

したがって、解決策は次のようになります。基本和を計算し、2 つの変換されたゲイン シーケンスを構築し、両方に対して Kadane のアルゴリズムを実行し、最良のプラスの改善を取得します。

 | 最適 (パリティ ゲイン + カダネ) | テストあたり O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 偶数のインデックスにあるすべての要素のベースライン合計を計算します。 何も元に戻さないことを選択した場合の答えはこれです。 これはすべての改善の基準点として機能します。 
2. 隣接する要素間のパリティ寄与の交換による潜在的なゲインを表す差分配列を構築します。 この考え方は、逆転によって要素がパリティ境界を越え、そのような交差がそれぞれ予測可能な変化に寄与するというものです。 
3. 偶数のインデックスから反転を開始することを検討します。 この場合、各ステップが反転セグメントを 1 要素ずつ拡張することで得られるメリットを表す実行配列を構築します。 
4. この配列に対して最大サブ配列合計の計算を実行します。 これにより、このパリティ アライメントの下で反転により最大のゲインが得られる最良の連続セグメントが特定されます。 
5. パリティの動作はセグメントの開始位置に応じて反転するため、奇数のインデックスから開始する反転についても同じ構築を繰り返します。 
6. 反転を完全にスキップできるため、両方のケースから最大ゲインを取得し、それが負でないことを確認します。 
7. このゲインをベースラインの偶数インデックス合計に加算し、結果を出力します。 

### なぜ効果があるのか

 すべての反転は、パリティの位置を切り替える要素間のペアごとの相互作用に分解できます。 寄与の変化は、パリティの変更を通じて見た場合、セグメント全体にわたる隣接する比較にのみ依存します。 これにより、反転のグローバル構造が、独立したローカル ゲインの線形累積に縮小されます。 Kadane のアルゴリズムは、これらのゲインの最適な連続セグメントを正確に識別します。これは、最適な反転に正確に対応します。 

重要な不変条件は、変換されたゲイン配列の任意の点で、現在の累計がその位置で終了するセグメントを反転した場合の純改善を表すということです。 すべての有効な反転は、このゲイン表現における 1 つの連続する区間に正確に対応するため、サブアレイの最大合計は最適な改善と等しくなる必要があります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))

        base = 0
        for i in range(n):
            if i % 2 == 0:
                base += a[i]

        # Case 1: start reversal affecting even-index structure
        best1 = 0
        cur = 0
        for i in range(1, n):
            val = a[i] - a[i - 1] if i % 2 == 1 else a[i - 1] - a[i]
            cur = max(0, cur + val)
            best1 = max(best1, cur)

        # Case 2: flipped parity interpretation
        best2 = 0
        cur = 0
        for i in range(1, n):
            val = a[i - 1] - a[i] if i % 2 == 1 else a[i] - a[i - 1]
            cur = max(0, cur + val)
            best2 = max(best2, cur)

        print(base + max(best1, best2))

if __name__ == "__main__":
    solve()
```コードはまず、偶数のインデックスからベースライン寄与を計算します。 次に、2 つの Kadane パスを構築します。それぞれは、異なるパリティ位置で反転が開始されたときにパリティが反転する方法の異なる配置を表します。 それぞれ`val`term は、反転セグメントを 1 ステップだけ拡張することによる限界ゲインをエンコードします。 の使用`max(0, cur + val)`有益なセグメントのみを確実に保持します。 

よくある落とし穴は、両方のパリティ アライメントを考慮する必要があることを忘れていることです。 もう 1 つは反転を明示的にシミュレートしようとするものですが、これは不必要かつ遅すぎます。 

## 実用的な例

 最初のサンプル配列をトレースします。`1 7 3 4 7 6 2 9`。 

偶数インデックスのベースライン合計は次のとおりです。`1 + 3 + 7 + 2 = 13`。 

最初の変換では、ゲインを計算します。 

| 私 | ペア (i-1, i) | 値 | カー | 最高 |
 | --- | --- | --- | --- | --- |
 | 1 | (1,7) | 6 | 6 | 6 |
 | 2 | (7,3) | 3 - 7 = -4 | 2 | 6 |
 | 3 | (3,4) | 4 - 3 = 1 | 3 | 6 |
 | 4 | (4,7) | 4 - 7 = -3 | 0 | 6 |
 | 5 | (7,6) | -1 | 0 | 6 |
 | 6 | (6,2) | -4 | 0 | 6 |
 | 7 | (2,9) | 7 | 7 | 7 |

 ここでの最良のゲインは 7 です。 

2 番目の変換では異なるアライメントが得られますが、セグメント構造に応じて同じ最大ゲインまたはより小さいゲインが生成されます。 この場合、最良は 7 のままです。 

したがって、最終的な答えは`13 + 7 = 20`。 

このトレースは、アルゴリズムが明示的に何も反転せずに、重要な反転効果をどのように取得するかを示しています。 各ステップは、ローカル スワップがグローバルな改善にどのように蓄積されるかを反映します。 

2 番目の例は、次のような単調増加配列です。`1 2 3 4`。 ベースラインは`1 + 3 = 4`、および可能なすべての反転は、パリティ構造を改善せずに値を再分配するだけであるため、両方の Kadane パスが正のゲインを蓄積することはありません。 これにより、アルゴリズムが正しく 4 を返すことが確認されます。

 ## 特殊なケース

 次のような長さ 1 の配列の場合、`[100]`、アルゴリズムはベースライン 100 を計算し、空の Kadane スキャンを実行しますが、ゲインは生成されません。 最終出力は 100 のままで、これは可能な唯一の構成と一致します。 

次のような 2 要素の配列の場合`[1, 100]`、ベースラインは 1 です。ゲイン配列は、パリティ アラインメントの 1 つで 99 という単一の正の寄与を生成するため、Kadane はそれを完全にキャプチャします。 これは、配列全体を反転し、100 を位置 0 に移動することに正確に対応します。 

モノトーン配列の場合`[1, 2, 3, 4, 5, 6]`、すべての局所的な差は、正のサブアレイの蓄積を防ぐ方法で符号が交互になるため、両方のゲインアレイは継続的にゼロにリセットされます。 出力はベースラインの偶数インデックス合計のままであり、アルゴリズムが強制反転を正しく回避していることが確認されます。
