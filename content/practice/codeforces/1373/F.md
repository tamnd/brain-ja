 ## 解決策
 ## 問題の理解

 中心首都を中心に一連の都市が円状に配置されており、各都市にはネットワーク カバレッジを必要とする多数の世帯があります。 隣接する都市のすべてのペアの間にネットワーク ステーションを設置でき、各ステーションにはサービスを提供できる最大世帯数があります。 このタスクは、各世帯が 2 つの隣接するステーションのいずれかに割り当てられているかどうかを、どのステーションもそのキャパシティを超えないように決定することです。 

入力は、各都市の世帯数を配列として提供します。`a`および配列としてのステーションの容量`b`。 各駅`i`市にサービスを提供する`i`そして街`(i + 1) % n`。 各テスト ケースについて、すべての世帯がステーションの容量内でカバーできる場合は YES を出力し、そうでない場合は NO を出力します。 

制約は厳しいです。 と`n`まで`10^6`と合計`n`すべてのテストケースにわたって以下を超えない`10^6`、二次複雑度のアルゴリズムを使用する余裕はありません。 テスト ケースごとの操作は、ほぼ線形である必要があります。`n`、したがって、`O(n)`または`O(n log n)`解決。 素朴なアプローチが失敗する可能性のあるエッジ ケースには、ある都市の世帯数が以前のステーションが提供できる世帯数よりも少なく、別の都市がカバーされないままになるシナリオが含まれます。 たとえば、ステーションに前の都市に必要な容量よりも多くの容量があり、次の都市には十分な容量が残っていない場合、常に前の都市に対してできるだけ多くの世帯にサービスを提供するという単純な欲張りは失敗する可能性があります。 

## アプローチ

 この強引なアプローチは、ステーションごとに世帯の可能な限りの分布を試行することです。 駅用`i`、都市間で世帯を割り当てるすべての方法を繰り返すことができます。`i`そして`(i+1)`、後続のステーションを再帰的にチェックします。 これは原理的には正しいですが、各都市には複数の割り当ての選択肢があるため、指数関数的な時間が必要になります。 メモ化しても分岐要素が高すぎる`n`まで`10^6`。 

重要な観察は、貪欲な方法で都市を順次処理できるということです。 各都市が独自のステーションを使用する前に、まず前のステーションの残り容量を使用するように修正するとします。 次に、現在のステーションが処理しなければならない最小世帯数は、前のステーションの寄与後に残っている世帯数によって決まります。 これにより、問題は都市ごとに次のことを確認するだけになります。`i`、ステーションの合計`i-1`の残り物とステーション`i`の収容力は少なくとも市内の世帯数です`i`。 いずれかの時点で、残りの要件が現在のステーションの容量を超える場合、それは不可能です。 これが機能するのは、各ステーションが 2 つの都市にのみサービスを提供でき、円形の性質により、残りの要件を円の周囲に伝播できるためです。

 ## アルゴリズムのチュートリアル

 1. 変数から始める`prev_excess`以前のステーションでサービスを受けられなかった世帯の数を追跡するため。 ゼロに初期化します。 
2. 各都市を反復処理する`i`0から`n-1`。 現在のステーションが処理しなければならない世帯の最小数を計算します。これは次のようになります。`max(a[i] - prev_excess, 0)`。 
3. この値が容量を超えた場合`b[i]`現在のステーションの場合は、NO を出力して、このテスト ケースを終了します。 それは、現在のステーションでは必要な世帯を処理できないことを意味します。 
4. それ以外の場合は更新します`prev_excess`に`b[i] - households_served_for_city_i`。 これは次の都市に貢献できる余力です。 
5. 都市は円を形成しているので、最後の都市の後の最初の都市を考慮して周回します。 ステーションのキャパシティを超過することなくアルゴリズムが完了した場合は、YES と出力します。 

ここでの不変条件は、`prev_excess`は常に、現在の都市に適用できる前のステーションからの残りの容量を表します。 以前の容量を消費した後に必要な最小世帯数を常にチェックすることで、過負荷のステーションがなく、すべての世帯が考慮されるようにします。 この不変式により正確さが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n = int(input())
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        
        # Find the minimal excess from the previous station
        min_start = 0
        for i in range(n):
            prev = (i - 1 + n) % n
            a[i] = max(a[i] - b[prev], 0)
        
        if sum(a) <= sum(b):
            print("YES")
        else:
            print("NO")

if __name__ == "__main__":
    solve()
```このソリューションはまず、各都市について、前のステーションの容量を差し引いた後、独自のステーションでサービスを提供する必要がある残りの世帯を計算します。 これらの残差の合計は、すべてのステーション容量の合計を超えてはなりません。超えない場合、計画は失敗します。 循環インデックス`(i-1+n)%n`最初の都市が最後のステーションの寄与を正しく考慮していることを確認します。 このアプローチは過剰カウントを回避し、最小限の容量でエッジケースをエレガントに処理します。
