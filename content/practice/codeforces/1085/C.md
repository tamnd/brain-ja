 ## 解決策
 ## 問題の理解

 無限グリッド上に 3 つの異なるセルが与えられ、それぞれが正方形の土地を表します。 最初はすべてがブロックされており、必要なセルを「クリア」できます。 目標は、一連のセルをクリアして、クリアされたセル上を 4 方向に移動して、指定された 3 つのセルが接続されるようにすることです。 接続性とは、3 つの特別なセルのいずれかから開始して、隣接するクリアされたセルのみを使用して、他の 2 つのセルに段階的に移動できることを意味します。 

タスクは、これが可能かどうかを判断するだけではなく、可能な限り最小のサイズでクリアされたセルの構成を構築することです。 言い換えれば、与えられた 3 つの点すべてを含むグリッド セルの最小の接続セットを探します。 

制約は小さく、座標は最大 1000、点は 3 つだけです。 これにより、大規模な状態に対する動的プログラミングや完全なグリッド上の最短パスのグラフのようなものは除外されます。これは、答えが検索問題ではなく幾何学的構造であるためです。 この構造は非常に厳格であるため、最短のマンハッタン接続がどのように動作するかを観察することで解決策を導き出す必要があります。 

単純なアプローチでは、各ポイントから BFS を実行し、何らかの方法で最短パスをマージしたり、接続構造の候補を列挙したりする可能性があります。 これでは、多くのグリッド セルが暗黙的に探索され、すぐに不必要な過剰操作になってしまいます。 主な問題は、2 点間に複数の最短パスが存在し、余分なセルを無駄にすることなく 3 点すべてが単一の接続された構造を共有するようにそれらを選択する必要があることです。 

素朴な直観が微妙に失敗するケースは、ペアを最短パスで個別に接続することが常に機能すると仮定することです。 たとえば、A から B および B から C をマンハッタンの最短パスで接続すると、特に「中間」点が適切に選択されていない場合、冗長な迂回が生じたり、重複を最小限に抑えられなかったりする可能性があります。 正しいソリューションでは、3 つの接続パス間で最大の重複を強制する必要があります。 

## アプローチ

 強引な考え方では、3 つの点を含むすべての可能な接続形状を考慮し、それらの結合のサイズを計算します。 しかし、ペア間のパスに限定しても、2 点間の可能な最短マンハッタン パスの数は、距離に応じて組み合わせ的に増加します。 3 ペアの接続のすべての組み合わせを探索することは、中程度の距離であっても実行不可能になります。これは、各ペアだけで、水平方向と垂直方向の順序の選択に関して指数関数的に多くの最短パスが存在する可能性があるためです。 

重要な構造的洞察は、マンハッタン幾何学では、複数の点間の最適な接続が、非常に特定の位置で分岐が発生するシュタイナー ツリーのように動作するということです。 3 つのターミナルの場合、すべてのパスが単一のグリッドに整列したジャンクションで交わる最適な構成が常に存在します。 これが受け入れられると、問題は正しい集合場所を見つけることになります。 

重要な観察は、軸に沿った距離の場合、最適な「接合部」によって 3 点までの距離の合計が x 次元と y 次元で独立して最小化されるということです。 これは、3 つの点の中から x 座標の中央値と y 座標の中央値を選択することによって実現されます。 この中心が固定されたら、単調な水平および垂直セグメントを使用して各点をこの中心に接続するのが最善の戦略です。 これにより、各セグメントがマンハッタン距離の最短パスとなり、共有中心を介してオーバーラップが自動的に最大化されるため、結合サイズの合計が最小になることが保証されます。

 ## アルゴリズムのチュートリアル

1. 指定された 3 つの点の x 座標と y 座標を抽出します。 
2. x 座標の中央値と y 座標の中央値を使用して、候補ミーティングポイントを計算します。 この選択は、各軸に沿った 3 点すべてへのマンハッタン距離の合計を個別に最小化するため、最適です。 
3. 3 つの点のそれぞれについて、最初に x が一致するまで水平に移動し、次に y が一致するまで垂直に移動して、集合点へのパスを構築します。 順序は重要ではありませんが、1 つの順序を固定すると、構築が単純かつ決定的に保たれます。 
4. 重複を避けるために、セット内のこれら 3 つのパスが訪問するすべてのセルにマークを付けます。 これにより、必要なすべてのクリアされたプロットの和集合を繰り返しなく出力できるようになります。 
5. セットのサイズを出力し、その後にすべての座標を任意の順序で出力します。 

### なぜ効果があるのか

 正しさは、マンハッタン ジオメトリの 3 点を接続するための最適解を、使用するセルの数を増やすことなく、すべてのパスが 1 つのグリッド ポイントで交差する解に変換できるという事実にかかっています。 このようなジャンクションが存在すると、合計経路長を最小化する最適なジャンクションは、まさに座標方向の中央値になります。 軸に合わせた最短パスを使用した構築により、不必要な迂回が決して導入されないことが保証され、パス間の重複は一意のセルの総数を減らすだけであり、最適化にとって有益です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def path(x1, y1, x2, y2):
    cells = []
    x, y = x1, y1

    dx = 1 if x2 > x else -1
    while x != x2:
        cells.append((x, y))
        x += dx
    cells.append((x, y))

    dy = 1 if y2 > y else -1
    while y != y2:
        if (x, y) not in cells:
            cells.append((x, y))
        y += dy
    cells.append((x, y))

    return cells

def solve():
    pts = [tuple(map(int, input().split())) for _ in range(3)]

    xs = sorted(p[0] for p in pts)
    ys = sorted(p[1] for p in pts)

    cx = xs[1]
    cy = ys[1]

    res = set()

    for x, y in pts:
        for cell in path(x, y, cx, cy):
            res.add(cell)

    print(len(res))
    for x, y in res:
        print(x, y)

if __name__ == "__main__":
    solve()
```このソリューションでは、まず 3 つの点を読み取り、両方の次元の中央値の座標を計算します。 その中央値は共有ジャンクションとして機能します。 次に、各ポイントは、単純な L 字型のマンハッタン パスを使用してこのジャンクションに接続されます。 

ヘルパー関数は、不要なセルを再度訪問することなく、単調なパスを構築します。 このセットにより、最適化に不可欠な重複セグメントによってカウントが増大しないことが保証されます。 最適な構造は共有セグメントに大きく依存しており、重複を削除する必要があるため、これは重要です。 

実装の微妙な詳細は、包括的なエンドポイントの処理です。 最終的な結合が 3 つの元の点すべてを含む接続された構造を正しく形成できるように、各パスには両方の端点が含まれている必要があります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    pts = [tuple(map(int, sys.stdin.readline().split())) for _ in range(3)]

    xs = sorted(p[0] for p in pts)
    ys = sorted(p[1] for p in pts)
    cx, cy = xs[1], ys[1]

    res = set()

    def path(x1, y1, x2, y2):
        x, y = x1, y1
        res_local = []
        dx = 1 if x2 > x else -1
        while x != x2:
            res_local.append((x, y))
            x += dx
        res_local.append((x, y))
        dy = 1 if y2 > y else -1
        while y != y2:
            res_local.append((x, y))
            y += dy
        return res_local

    for x, y in pts:
        for cell in path(x, y, cx, cy):
            res.add(cell)

    out = [str(len(res))]
    for x, y in res:
        out.append(f"{x} {y}")
    return "\n".join(out)

 ## 特殊なケース

 退化的ですが有益なケースは、3 つの点すべてが垂直直線上にある場合です (たとえば、(0,0)、(0,1)、(0,2))。 中央値構築では (0,1) が選択され、各ポイントは同じ列に沿って直接接続されます。 結合は正確に 3 つのセルであり、余分な分岐は表示されません。 すべてのパスが垂直セグメントに沿って完全に重なるため、アルゴリズムは自然に冗長構造を崩壊させます。 

もう 1 つのケースは、点が (0,0)、(0,2)、(2,1) のような直角パターンを形成する場合です。 中央値は (0,1) になります。 1 つのパスは自明であり、1 つは垂直方向の 1 ステップであり、もう 1 つは水平セグメントを形成してから垂直セグメントを形成します。 これをトレースすると、すべてのパスが選択した中心で交差しており、少なくとも 1 点からの距離を増やさずに結合をさらに縮小できる代替ジャンクションがないことが確認されます。
