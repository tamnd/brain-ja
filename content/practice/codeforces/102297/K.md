 ## 解決策
 ## 問題の理解

 各クエリに対して、正の整数 (X) と (N) が与えられます。 二項展開の (N+1) 項を考慮します。 

[
 (1+X)^N、
 】

 ここで、1 から始まるインデックスを使用したインデックス (i) の用語は次のようになります。 

[
 T_i=\binom{N}{i-1}X^{i-1}。 
】

 これらのインデックスのサブセットを選択することもできます。 対応する項の積は (2\pmod 4) に一致する必要があり、すべての有効なサブセットの中で、それらのインデックスの可能な最大の合計が必要です。 元のコンテスト ステートメントでは、(q\le 500) クエリと (X,N<2^{31}) が与えられます。 

限界 (N<2^{31}) が中心的な難易度です。 すべての (N+1) 語を直接スキャンするには、1 つのクエリに対して最大 (2^{31}) 回の反復が必要ですが、これはすでに通常のコンテストの制限時間をはるかに超えています。 クエリが 500 個もある場合、反復回数はおよそ (500\cdot2^{31})、つまり約 (1.07\times10^{12}) に達します。 解は、(N) 自体ではなく、(N) のビット数に依存する必要があります。 

直接実装すると、気付かれずに問題が発生する可能性があるエッジケースがいくつかあります。 (X) が 4 で割り切れる場合、(T_1=1) を除くすべての項は 4 で割り切れるため、積は (2\pmod4) にはなりません。 たとえば、```
1
4 5
```正しい出力は`0`を使用して`0`有効なサブセットが存在しないことを示します。 (T_1) のみを選択すると 1 が得られますが、他のすべての項は 4 で割り切れる係数に寄与します。 

(X\equiv2\pmod4) の場合、(k\ge2) の累乗 (X^k) はすべて 4 で割り切れます。 2 に一致する唯一の可能な因数は (T_2=NX) であり、これは (N) が奇数の場合にのみ発生します。 したがって```
1
2 3
```答えがあります`3`, (T_1=1) と (T_2=6\equiv2\pmod4) なので、インデックス 1 と 2 を選択できます。 

奇数 (X) の場合、(X) の累乗は 2 の因数に寄与しません。動作は完全に二項係数によって制御されます。 例えば、```
1
3 3
```係数は (1,3,3,1) で、すべて奇数であるため、すべての項は奇数であり、積が (2\pmod4) になることはありません。 答えは`0`。 十分に大きいすべての (N) に 2 モジュロ 4 に等しい係数が含まれると仮定する不注意な実装は、ここでは失敗します。 

最後に、2 で割り切れるが 4 では割り切れない係数と、4 で割り切れる係数の区別が重要です。 (X=3,N=5) の場合、係数は (1,5,10,10,5,1) です。 10 は両方とも (2\pmod4) であり、そのうちの 1 つだけを選択できます。 公開された例では、インデックス 3 ではなくインデックス 4 の用語が選択され、最大合計 (18) が得られます。 

## アプローチ

 ブルートフォース ソリューションでは、すべての項を明示的に生成し、それをモジュロ 4 で削減し、次にどのサブセットが 2 に合同な積を生成できるかを推論できます。 (N+1) 個の項と潜在的に (2^{N+1}) 個のサブセットがありますが、モジュラー構造によりサブセット検索を大幅に減らすことができます。 この削減後でも、すべての用語の検査にはクエリごとに (O(N)) のコストがかかります。 最悪の場合、これは 1 つのクエリに対して約 (2^{31}) 回の操作と、500 個のクエリに対して約 (1.07\times10^{12}) 個の用語検査に相当しますが、これは実行不可能です。 

重要な観察は、ちょうど 1 つの因子 (2\pmod4) を除いて、選択されたすべての因子が奇数である場合に、積が (2\pmod4) になるということです。 4 で割り切れる係数は選択できません。 

これにより、最適化問題が完全に変わります。 すべての奇数項は常に選択する必要があります。これは積モジュロ 4 を変更せず、インデックスの合計を増加させるためです。 2 モジュロ 4 に合同な項のうち、正確に 1 つを選択する必要があり、最大のインデックスを持つ項を選択する必要があります。 したがって、問題は、すべての (k=0,\ldots,N) を列挙することなく、2 の累乗に従ってすべての二項係数を分類することに帰着します。 

奇数 (X) の場合、

 [
 T_{k+1}=\binom NkX^k
 】

 は (\binom Nk) とまったく同じ 2 進評価を持ちます。 クンマーの定理は、2 を除算する指数 (\binom Nk) は、2 進数で (k) と (N-k) を加算するときのキャリーの数に等しいとしています。 同様に、これは、2 進数で (N) から (k) を減算するときに生成される借入の数に等しくなります。 

これにより、わずかな桁の DP が得られます。 (k) のビットを最下位から最上位に処理する間、現在の減算ボローとこれまでに確認されたボローの数を保持します。 借用の数が 0 であるか、正確に 1 であるか、少なくとも 2 であるかだけを考慮します。その結果、クエリ全体にかかる時間は (O(\log N)) のみになります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | モジュール削減後のクエリごとの (O(N)) | (O(1)) | 遅すぎる |
 | 最適 | (O(\log N)) クエリごと | (O(1)) | 承認済み |

 ## アルゴリズムのチュートリアル

1. まず (X\bmod4) を検査します。 (X\equiv0\pmod4) の場合、(i>1) のすべての (T_i) は 4 で割り切れるため、有効な積は存在せず、0 を出力します。 
2. (X\equiv2\pmod4) の場合、(X^k) は (k\ge2) ごとに 4 で割り切れます。 唯一可能な (2\pmod4) 項は (T_2=NX) です。 (N) が奇数の場合、正確には (2\pmod4) になります。 この場合、最適なサブセットは ({1,2}) であり、答え 3 が得られます。(N) が偶数の場合、有効なサブセットは存在しません。 
3. ここからは (X) が奇数であると仮定します。 次に、(X^k) は (k) ごとに奇数であるため、(T_{k+1}) の 2 のべき乗を法とする剰余クラスは完全に (\binom Nk) によって決定されます。 
4. すべての (k) について、(v_2\left(\binom Nk\right)) を係数の 2 の指数とします。 係数は、この値が 0 の場合は奇数、1 の場合は (2\pmod4)、2 以上の場合は 4 で割り切れます。 
5. 二項係数を計算せずに、二項減算を使用してこの評価を計算します。 (k) のビットを下位から上位に処理します。 各ビットで、(k_i=0) または (k_i=1) のいずれかを選択します。 受信した借用が与えられた場合、(k_i) と借用を (N) の対応するビットから減算します。 減算が負になると、次の状態のボローは 1 となり、二項係数で 2 の因数が 1 つ増えたことになります。 
6. DP 状態は、現在の借入と評価カテゴリ (v\in{0,1,2}) で構成されます。カテゴリ 2 は、少なくとも 2 つの借入を意味します。 カテゴリ 0 の場合、状態に到達する (k) 値の数とそれらの (k) 値の合計を保存します。 カテゴリ 1 の場合、最終的にはそのような用語が 1 つだけ選択されるため、最大値 (k) のみが必要になります。 
7. 31 ビットすべてを処理した後、最終的な減算ボローが 0 である状態を保持します。 このような状態は (0\le k\le N) に正確に対応します。 カテゴリ 0 の状態はすべての奇数の二項係数を表すため、そのインデックス (k+1) がすべて選択されます。 
8. カテゴリ 1 の状態がない場合、(2\pmod4) となる項はないため、答えは 0 になります。それ以外の場合は、カテゴリ 1 の最大値 (k) を取得し、そのインデックス (k+1) をカテゴリ 0 のすべてのインデックスの合計に加算します。 

これが機能する理由: 数字 DP の不変条件は、最初の (j) ビットを処理した後、各状態が記録された減算ボローと記録されたボロー数 (上限は 2) を持つ (k) の下位 (j) ビットの選択を正確に表すことです。 クンマーの定理は、その借入数を (v_2\left(\binom Nk\right)) に変換します。 最後に、最後のボロー ゼロは (k\le N) を意味するため、すべての有効な (k) は 1 回だけ表されます。 製品の状態では、評価が正確に 1 である 1 つの因子を除き、選択されたすべての因子が奇数である必要があります。 したがって、すべての評価ゼロの項を選択することは常に最適であり、最大のインデックスの評価-1 項を選択すると、可能な最大の合計が得られます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve_query(x, n):
    xm = x & 3

    # X is divisible by 4.
    if xm == 0:
        return 0

    # X is 2 modulo 4.
    if xm == 2:
        if n & 1:
            return 3
        return 0

    # X is odd.
    #
    # dp[(borrow, v)] = (count, sum_k, max_k)
    # v = 0: exactly zero borrows
    # v = 1: exactly one borrow
    # v = 2: at least two borrows
    #
    # max_k is only relevant for v = 1.
    dp = {
        (0, 0): (1, 0, -1)
    }

    for bit in range(31):
        ndp = {}
        nb_n = (n >> bit) & 1
        value = 1 << bit

        for (borrow, v), (cnt, sum_k, max_k) in dp.items():
            for kb in (0, 1):
                t = nb_n - kb - borrow
                new_borrow = 1 if t < 0 else 0
                new_v = min(2, v + new_borrow)

                key = (new_borrow, new_v)

                old_cnt, old_sum, old_max = ndp.get(key, (0, 0, -1))

                add_sum = sum_k + cnt * kb * value
                new_cnt = old_cnt + cnt
                new_sum = old_sum + add_sum

                candidate_max = max_k
                if new_v == 1:
                    if kb:
                        candidate_max = max(candidate_max, max_k + value)
                    else:
                        candidate_max = max(candidate_max, max_k)

                ndp[key] = (
                    new_cnt,
                    new_sum,
                    max(old_max, candidate_max)
                )

        dp = ndp

    # Final borrow must be zero, otherwise k > N.
    odd_cnt, odd_sum, _ = dp.get((0, 0), (0, 0, -1))
    _, _, max_one = dp.get((0, 1), (0, 0, -1))

    if max_one == -1:
        return 0

    # Each k corresponds to term index k + 1.
    return odd_sum + odd_cnt + max_one + 1

def solve():
    q = int(input())
    ans = []

    for _ in range(q):
        x, n = map(int, input().split())
        ans.append(str(solve_query(x, n)))

    sys.stdout.write("\n".join(ans))

if __name__ == "__main__":
    solve()
```最初の 2 つの分岐は偶数 (X) を直接処理します。 (X\equiv0\pmod4) の場合、ちょうど 2 のべき乗に寄与できる因数はありません。(X\equiv2\pmod4) の場合、問題となるのは指数 (k=1) だけであり、その係数は (N) であり、(N) が奇数の場合に正確に (2\pmod4) 項が得られます。 

残りのコードは奇数 (X) を処理します。 辞書`dp`2 つの可能な借入値と 3 つの評価カテゴリがあるため、一定数の状態のみが含まれます。 

ビットごとに、`kb`は、(k) の選択されたビットを表します。 表現`n_bit - kb - borrow`1 つのバイナリ減算ステップを実行します。 負の結果は、このビットが次の位置から借用する必要があることを意味します。 クンマーの定理によれば、そのような借用はそれぞれ、二項係数の 2 進評価に 1 つ寄与します。 

DP は、借入ゼロ カテゴリのすべて (k) 値の合計も追跡します。 対応する用語インデックスは (k+1) であるため、インデックスの合計は次のようになります。`odd_sum + odd_cnt`。 

1 回借用のカテゴリでは、最大のもの (k) のみを保持します。 このような用語を複数選択すると積が 4 で割り切れる可能性があるため、完全な合計を保存する理由はありません。最大 (k) は可能な最大の用語インデックスを与え、まさに必要なものとなります。 

制約により (N<2^{31}) が保証されるため、ループでは 31 ビットが使用されます。 余分な 1 ビットの処理も無害ですが、入力範囲内のすべての可能な (k) を表すには 31 ビットで十分です。 Python の整数には任意の精度があるため、累積されたインデックスの合計にオーバーフローの心配はありません。 

最終的な借入はゼロでなければなりません。 ゼロ以外の最終借入は、選択された 2 進数 (k) が (N) より大きいことを意味するため、有効な二項係数インデックスではありません。 

## 実用的な例

 公開されたステートメントの具体的な例では、(X=3,N=5) が使用されています。 その係数は (1,5,10,10,5,1) で、対応する項にはインデックス 1 ～ 6 があります。 

バイナリ DP の場合、(N=5) は次のようになります。`101`。

 このパスは (k=2) と (\binom52=10) を表し、2 の因数が 1 つだけあります。 

(N=5) に関連する (k) 値は次のとおりです。 

| (k) | (\binom5k) | (v_2) | 用語索引 |

この例では、2 の 1 つの因数と 2 の少なくとも 2 つの因数の区別を実行します。係数 4 は破棄する必要がありますが、6 は 2 を法とする 4 に一致する一意の因数を提供できます。

import io
import sys

def solve_query(x, n):
    xm = x & 3

    if xm == 0:
        return 0

    if xm == 2:
        return 3 if (n & 1) else 0

    dp = {
        (0, 0): (1, 0, -1)
    }

    for bit in range(31):
        ndp = {}
        nbit = (n >> bit) & 1
        value = 1 << bit

        for (borrow, v), (cnt, sum_k, max_k) in dp.items():
            for kb in (0, 1):
                t = nbit - kb - borrow
                new_borrow = 1 if t < 0 else 0
                new_v = min(2, v + new_borrow)
                key = (new_borrow, new_v)

                old_cnt, old_sum, old_max = ndp.get(key, (0, 0, -1))

                candidate_max = max_k
                if new_v == 1 and kb:
                    candidate_max = max(candidate_max, max_k + value)

                ndp[key] = (
                    old_cnt + cnt,
                    old_sum + sum_k + cnt * kb * value,
                    max(old_max, candidate_max)
                )

        dp = ndp

    odd_cnt, odd_sum, _ = dp.get((0, 0), (0, 0, -1))
    _, _, max_one = dp.get((0, 1), (0, 0, -1))

    if max_one == -1:
        return 0

    return odd_sum + odd_cnt + max_one + 1

def run(inp: str) -> str:
    data = io.StringIO(inp)
    q = int(data.readline())
    out = []

    for _ in range(q):
        x, n = map(int, data.readline().split())
        out.append(str(solve_query(x, n)))

    return "\n".join(out)

3 3
```二項係数は (1,3,3,1) であるため、すべての項は奇数になります。 DP には、(v_2=1) の係数が存在しないことに対応する、借入が 1 つだけある状態はありません。 このアルゴリズムは、積が奇数のままになる奇数項のみを誤って選択するのではなく、0 を返します。

```ゼロボロー係数は (k=0,1,4,5) に対応し、項インデックス 1、2、5、6 を与えます。それらの合計は 14 です。ワンボロー係数は (k=2,3) に対応し、インデックス 3 と 4 を与えます。より大きなインデックス 4 を選択すると 18 が得られます。もう 1 つの選択では 17 が得られるため、最大値が正しく取得されます。
