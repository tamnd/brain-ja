 ## 解決策
 ## 問題の理解

 私たちは神の「強さ」を表す整数を一列に並べて与えられます。 隣接する神のすべてのペアの間で、その強さがどのように異なるかを調べます。 配置全体の不安定性は、そのような隣接する最大の差として定義されます。 

このタスクでは 1 回の修正が可能です。配列内の位置を 1 つだけ選択し、その値を必要な整数に置き換えることができます。 その後、最大隣接差分を再計算します。 目標は、この最大値をできるだけ小さくし、変更した位置とそこに割り当てた値を出力することです。 

主な問題点は、1 つの要素を変更すると隣接する 2 つのエッジにのみ影響するが、それらのエッジはグローバル最大値に関与することです。 したがって、決定は変更に関してはローカルですが、評価に関してはグローバルです。 

5・10^5 までの制約 n は、すべての置換の二次シミュレーションを即座に除外します。 すべての位置を試して毎回最大値を再計算するアプローチでは O(n^2) が必要となり、これでは遅すぎます。 

最適な戦略が実際には何も改善しないことである場合、微妙なエッジケースが発生します。 現在の構成がすでに最適である場合、または 1 回の変更で改善できない場合は、配列を変更しないままにするなど、有効な変更を出力することができます。 

もう 1 つの注意が必要な状況は、最適な変更値が隣接する値の間になければならない場合です。 たとえば、位置 i を固定すると、2 つのエッジ (i−1, i) と (i, i+1) のみが変化します。 a_i の最適な選択は、a_{i−1} および a_{i+1} とのみ相互作用しますが、全体的な答えは、これによって現在の最大エッジが他の場所で削除されるかどうかによって異なります。 

## アプローチ

 ブルートフォースのアイデアは簡単です。インデックス i ごとに、a_i のすべての可能な値を試し、隣接する最大の差を再計算し、最良の結果を取得します。 これは定義に直接従うため、正しいです。 ただし、すべての整数置換を試行するのは無限であり、候補を賢く制限したとしても、再計算ごとに O(n) のコストがかかるため、依然として O(n^2) またはさらに悪い動作が発生します。 n が 5・10^5 までの場合、これは実行不可能です。 

重要な観察は、答えは隣接する差分の極大値のみに依存するということです。 d_i = |a_i − a_{i+1}| とします。 現在の答えは D = max d_i です。 位置 i を変更すると、d_{i−1} と d_i のみが影響を受けます。 他のすべてのエッジは変更されません。 したがって、D を減らす唯一の方法は、D に等しいすべてのエッジが変更されないか、変更によって「カバーされる」ことを確認することです。 

これにより、問題は、最大エッジの位置を基準にしてどこに変更を加えるかを考慮するだけになります。 適切な値を選択することで、その周囲の両方のエッジを同時に D 未満に低減できるような位置 i がある場合、その位置は最大値を除去できる可能性があります。 そうでない場合は、D を受け入れることを余儀なくされます。 

固定 i の場合、max(|a_{i−1} − x|, |x − a_{i+1}|) を最小化する x = a_i^* を選択します。 これは直線上の古典的なミニマックス問題であり、最適な x は 2 つの近傍の中点であり、整数が許可されているため任意に丸められます。 結果として得られる最小値は ceil(|a_{i−1} − a_{i+1}| / 2) になります。 

したがって、各 i について、i を変更した場合に可能な最良の極大値がいくらになるかを計算できます。 グローバルな答えは、次の範囲の最大値のすべての i にわたる最小値です。 

変更されていないエッジ (i を含むエッジを除くすべての d_j)、および i での新しい誘導エッジ。 

これを効率的に維持するために、d にわたるプレフィックスとサフィックスの最大値を事前計算します。 次に、各 i について、a_i を最適に置き換えた場合に達成可能な最良の値を計算し、それを O(1) の影響を受けない部分と組み合わせます。 

これにより、O(n) の解が得られます。

 ## アルゴリズムのチュートリアル

 1. 隣接する差分の配列 d_i = |a_i − a_{i+1}| を計算します。 1 から n−1 までのすべての i に対して。 これにより、現在の不安定性へのすべての寄与が捕捉されます。 この配列からグローバル最大値 D も計算します。 
2. d に対してプレフィックス最大配列 pref とサフィックス最大配列 suf を構築します。 これらにより、任意の間隔外の最大エッジ値を迅速にクエリできるようになります。 これが必要なのは、インデックス i を変更すると d_{i−1} と d_i の影響が除去されるためです。 
3. 各位置 i を潜在的な変更点として考慮します。 各 i について、a_i を置き換えた後、i に接する 2 つのエッジの可能な限り新しい寄与を計算したいと考えています。 
4. 固定 i の場合、L = a_{i−1} および R = a_{i+1} を定義します。 a_i の最適な置換値は、max(|L − x|, |x − R|) を最小化します。 最適な x は L と R の間にあり、その結果得られる最小可能最大エッジは ceil(|L − R| / 2) です。 この値は、両方のエッジ (i−1, i) と (i, i+1) を置き換えます。 
5. この i に対する答えの候補を、ステップ 4 で得られる最良の達成可能な局所値、pref を使用して i-1 の厳密に左側にある最大エッジ、および suf を使用して i の厳密に右側にある最大エッジの 3 つの量の最大値として計算します。 これにより、アレイの変更されていない部分が最適化されたローカル修復と結合されます。 
6. すべての i にわたって最小のそのような候補を追跡します。 最良のインデックスと、隣接するものの中間点として計算された、対応する選択値 x を保存します。 
7. 選択した位置および置換値とともに、達成可能な最小 D を出力します。 

### なぜ効果があるのか

 このアルゴリズムは、目的関数を独立したエッジ寄与に分解することに依存しています。 変更されたインデックスに触れていないすべてのエッジは操作下では不変であるため、プレフィックスとサフィックスの最大値を介して個別に考慮する必要があります。 唯一の自由度は 2 つの隣接するエッジから得られ、1 つの値を置き換えると、これら 2 つのエッジが線分上の 1 つの凸状の最適化問題に変換されます。 すべての相互作用は局所的であるため、すべてのエッジにわたって最大値を最小化すると、各候補を個別に評価して全体的な最小値を取得することになります。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    if n == 2:
        # only one possible modification point, or none useful
        best_x = (a[0] + a[1]) // 2
        D = abs(a[0] - a[1])
        print(D, 1, best_x)
        return

    d = [abs(a[i] - a[i+1]) for i in range(n-1)]
    D = max(d)

    pref = [0] * (n-1)
    suf = [0] * (n-1)

    pref[0] = d[0]
    for i in range(1, n-1):
        pref[i] = max(pref[i-1], d[i])

    suf[n-2] = d[n-2]
    for i in range(n-3, -1, -1):
        suf[i] = max(suf[i+1], d[i])

    ansD = D
    ans_i = 1
    ans_x = a[0]

    for i in range(n):
        # compute unaffected max
        left_max = pref[i-2] if i-2 >= 0 else 0
        right_max = suf[i+1] if i+1 < n-1 else 0
        base = max(left_max, right_max)

        if 0 < i < n-1:
            L, R = a[i-1], a[i+1]
            local = (abs(L - R) + 1) // 2
            x = (L + R) // 2
            cand = max(base, local)
        else:
            # endpoint: only one neighbor matters
            if i == 0:
                local = abs(a[1] - a[1])  # can set a[0] = a[1]
                x = a[1]
            else:
                local = abs(a[n-2] - a[n-2])
                x = a[n-2]
            cand = max(base, local)

        if cand < ansD:
            ansD = cand
            ans_i = i + 1
            ans_x = x

    print(ansD, ans_i, ans_x)

if __name__ == "__main__":
    solve()
```コードは、目的にとって重要な唯一の構造である隣接差分配列を構築することから始まります。 プレフィックスとサフィックスの最大値により、候補インデックスが変更されたときに影響を受けない領域の定数クエリが可能になります。 

i に対するループは、考えられる各修正点を個別に評価します。 内部位置の場合、最適な置換は 2 つの隣接位置にのみ依存します。 中間地点の構築`(L + R) // 2`最適なバランスを実現する有効な整数を与えます。 計算されたローカル寄与は、2 つの隣接するエッジの可能な限り最良の圧縮を反映します。 

境界ケースでは、エンドポイントは 2 つのエッジではなく 1 つのエッジのみを提供するため、エンドポイントを個別に処理します。 

## 実用的な例

 ### 例 1

 入力:```
5
4 1 3 5 4
```差を計算します。 

d = [3, 2, 2, 1]、つまり D = 3。 

それぞれの指標を評価していきます。 

| 私 | 隣人 (L,R) | ローカル | 基本最大値 | 缶 |
 | --- | --- | --- | --- | --- |
 | 1 | (1,3) | 1 | 2 | 2 |
 | 2 | (4,5) | 1 | 3 | 3 |
 | 3 | (1,4) | 2 | 3 | 3 |
 | 4 | (3,4) | 1 | 3 | 3 |

 最良の場合は、i = 2 で値 3 が得られます。 

ここでは D_min = 2 がグローバルに達成できないことを出力するため、最終的な最適値は位置 2 での変更を伴う 3 になります。 

これは、局所的な改善は、支配的なエッジをターゲットにしない限り、必ずしも全体的な最大値を減少させるわけではないことを示しています。 

### 例 2

 入力:```
4
1 2 1 1
```違い:

 d = [1, 1, 0]、D = 1。 

インデックス 2 または 3 を変更して配列をフラット化できます。 

インデックス 2 を 1 に設定すると、配列は [1,2,1,1] になり、D=1 は変わりません。 

ただし、インデックス 3 を 1 に設定すると、すでに近隣と一致します。 

達成可能な最良の値は、インデックス 2 の 1 つの変更によってすべてを等しく設定することにより 0 になります: [1,1,1,1]。 

これは、1 回の内部調整で隣接する両方のエッジを同時に除去できるという重要なアイデアを裏付けています。

 ## 特殊なケース

 [1, 100, 1, 100, 1] のような厳密に交互の配列の場合、最大の差はどこでも発生します。 アルゴリズムは各インデックスをチェックし、単一の位置を変更すると隣接する 2 つのエッジのみが削除され、他の大きなエッジはそのまま残ることを正しく評価します。 プレフィックスとサフィックスを分離することにより、これらの手つかずの最大値が依然として候補の回答を支配することが保証され、過度の楽観的な削減が防止されます。 

[5, 5, 5, 5] のような一様な配列の場合、すべてのエッジの差はゼロになります。 変更を加えると、最良の答えはゼロのままになります。 このアルゴリズムでは、改善は不可能であり、その場合は有効な出力が許可されるため、元の位置と値を返すことが正しく許可されます。
