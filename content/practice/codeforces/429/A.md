 ## 解決策
 ## 問題の理解

 私たちに与えられたのは、根を張った木です。`n`各ノードには 0 または 1 のラベルが付いています。各ノードには 0 と 1 のターゲット構成も与えられます。 許可される唯一の操作はノードを「選択」することです。これにより、その値とすべての第 2 レベルの子孫がツリーの下に反転されます。 具体的には、ノードが選択されると、その値が反転し、その子の値は変更されず、孫は反転し、ひ孫はそのまま残り、というようにレベルが交互に変化します。 

入力は、ノードを接続するエッジと、初期状態とターゲット状態を表す 2 つの配列を備えた標準ツリー記述です。 すべての操作後にツリーがターゲット配列と一致するように、出力は選択するノードの最小限のシーケンスである必要があります。 

以来`n`最大 100,000 で、時間が 1 秒しかない場合、すべてのノードを数回以上訪問したり、ノードのすべてのサブセットを試行したりするアルゴリズムは遅すぎます。 必要なのは`O(n)`トラバーサルベースのソリューション。 エッジ ケースには、ノードが 1 つだけのツリー、完全にバランスの取れたツリー、または慎重に扱わないと同じ枝に沿った複数のノードが互いに反転してしまう状況が含まれます。 単純なソリューションでは、ノードを任意の順序で貪欲に選択する可能性があり、これによりノードが過剰に反転され、最小限の操作よりも大きなセットが発生する可能性があります。 

## アプローチ

 ブルートフォースアプローチは、考えられるすべての順序ですべてのノードを選択し、適切なレベルを反転して、ターゲットに到達したかどうかを確認することです。 これは、操作が可逆的でツリーが有限であるため、原理的には機能しますが、シーケンスの数が指数関数的に増加するため、これは非現実的です。`n`最大 10^5。 

重要な洞察は、反転操作にはレベルに沿った予測可能なパターンがあるということです。偶数の深さで反転すると偶数の深さのノードに影響し、奇数の深さで反転すると奇数の深さのノードに影響します。 これは、ルートから深さ優先のトラバーサルを実行し、偶数および奇数の深さでパスに沿って適用された反転の数を追跡できることを意味します。 各ノードで、以前の反転の累積効果に基づいて反転するかどうかを決定します。 これにより、偶数と奇数の深さでのフリップを表す 2 つの整数のブックキーピングを備えた単一の DFS に問題が軽減され、`O(n)`解決。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^n) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 隣接リストを使用してツリーを構築します。 初期値と目標値を保存します。 
2. 2 つのカウンターを初期化します。`even_flips`そして`odd_flips`、偶数および奇数の深さのノードのパスに沿って適用された反転の数を追跡します。 
3. ルート (深さ 0) から DFS トラバーサルを開始します。 各ノードについて、その深さに沿ってフリップのパリティを適用することにより、その現在の実効値を計算します。 
4. 現在の実効値が目標と一致しない場合は、このノードを結果セットに追加し、その深さパリティに対応するフリップ カウンタをインクリメントします。 
5. 子に再帰し、更新されたフリップカウントを渡します。 
6. 子供たちを訪問した後、バックトラックします。子孫への累積的な影響のみを考慮しているため、フリップを元に戻す必要はありません。 

なぜ機能するのか: 各ノードで、次の不変条件が維持されます。`current_value ^ cumulative_flips = goal_value`その深さで。 ノードを反転する決定により、この不変式がすべての子孫に対して確実に保持されます。 DFS 順序でトラバースするため、すべてのノードは、自身を反転するかどうかを決定する前に、自分に影響を与えるすべての反転を確認します。 交互のフリップ パターンはパリティ ベースのトラッキングと一致し、最小限のフリップを保証します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

def solve():
    n = int(input())
    tree = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, input().split())
        tree[u].append(v)
        tree[v].append(u)
    
    init = [0] + list(map(int, input().split()))
    goal = [0] + list(map(int, input().split()))
    
    result = []
    
    def dfs(node, parent, depth, even_flips, odd_flips):
        if depth % 2 == 0:
            effective = init[node] ^ even_flips
        else:
            effective = init[node] ^ odd_flips
        
        if effective != goal[node]:
            result.append(node)
            if depth % 2 == 0:
                even_flips ^= 1
            else:
                odd_flips ^= 1
        
        for child in tree[node]:
            if child != parent:
                dfs(child, node, depth + 1, even_flips, odd_flips)
    
    dfs(1, 0, 0, 0, 0)
    
    print(len(result))
    for node in result:
        print(node)

solve()
```The adjacency list represents the tree efficiently. 私たちが使用するのは`sys.setrecursionlimit`深いツリーを使用しないと再帰がオーバーフローする可能性があるためです。`even_flips`そして`odd_flips`偶数および奇数の深さでノードの累積反転を追跡します。 DFS は、すべてのノードが 1 回アクセスされることを保証し、現在の有効な状態に基づいて決定を行います。 カウンタは深さ固有であり、値によって渡されるため、反転のバックトラックを避けるように注意が必要です。
