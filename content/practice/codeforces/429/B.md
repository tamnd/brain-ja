 ## 解決策
 ## 問題の理解

 サイズ _n_ × _m_ のグリッドとして表される 2 次元のジムがあります。 各セルには、その場所でのワークアウトによる消費カロリーを表す正の整数が含まれています。 イアフブとイアフビナの 2 人はそれぞれ反対側の角からスタートし、反対側に到達する必要があります。イアフブは左上からスタートして右下に進み、下または右のみに移動します。一方、イアフビナは左下からスタートして右上に進み、上または右にのみ移動します。 ちょうど 1 つのセルで、彼らは出会い、運動することなく停止します。 目標は、両方の経路で消費される総カロリーを最大化することです。 

重要な複雑さはグリッドのサイズから生じます。_n_ と _m_ はそれぞれ最大 1000 に達する可能性があります。考えられるすべてのミーティング ポイントとすべてのパスを試す単純なアプローチでは、指数関数的に遅くなります。 グリッドには最大 1,000,000 個のセルがあるため、O(n²·m²) の操作を実行するソリューションは制限時間を超えます。 安全のためには約 O(n・m) が必要です。 

明らかではないエッジ ケースには、境界近くで合流することで最大の利得が得られ、非直観的な方法でパスを強制的に曲げるシナリオが含まれます。 たとえば、中央のセルの値が最小である 3×3 グリッドについて考えてみましょう。 会議セルが中心である場合、各人は価値の高いセルを不必要に無駄にしないようにする必要があり、不用意に貪欲なアプローチを行うと、極大値を選択しても最適な合計を逃す可能性があります。 

## アプローチ

 ブルートフォースアプローチでは、考えられるすべての会議セルが考慮されます。 各セルについて、Iahub の場合は開始点からそのセルまで、Iahubina の場合は開始点からそのセルまでのすべての可能なパスに沿って収集された最大カロリーを計算します。 次に、各人の会議セルから終点までのパスも計算します。 これは原理的には正しいですが、n·m 個のセルに会うごとにパスの計算に O(n·m) かかる可能性があり、合計で O(n²·m²) 回の操作が必要になります。 n、m ≤ 1000 の場合、これは約 10¹² の操作となり、非常に遅すぎます。 

重要な洞察は、各人は 2 つの方向にのみ移動できるということです。イアフブは下または右、イアフビナは上または右です。 これは、動的プログラミングを使用して、任意のセルに収集される最大カロリーを事前に計算できることを意味します。 Specifically, we can compute four DP arrays:

 1.`dp1[i][j]`- 最大カロリーは左上から`(i, j)`(イアハブ開始)
 2.`dp2[i][j]`- 最大カロリーは右下から`(i, j)`(イアハブ終了)
 3.`dp3[i][j]`- 最大カロリーは左下から`(i, j)`(イアフビナスタート)
 4.`dp4[i][j]`- 右上から最大カロリーまで`(i, j)`(イアフビナ終了)

 これらが記入されると、会議の可能性のあるセルごとに`(i, j)`、会議セルの二重カウントを回避する 2 つの互いに素なパスの合計として合計ゲインを計算できます。 合計ゲインを最大化しながらそれらが出会う方法は 2 つあり、2 つの「交差」パターンに対応します。1 つは水平方向にエッジを共有せずに交差するパターン、もう 1 つは垂直方向です。 すべての内部セル (境界を除く) を反復処理し、これらの DP 配列から合計を計算すると O(n・m) となり、効率的です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²・m²) | O(n・m) | 遅すぎる |
 | DP 事前計算 | O(n・m) | O(n・m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 寸法を読む`n`、`m`そしてグリッド`a`。 4 つの方向に沿って最大ゲインを計算する必要があります。 
2. 4 つの DP 配列を初期化します。`dp1`、`dp2`、`dp3`、`dp4`。 各配列は、特定の開始からすべてのセルまでの最大カロリーを保存します。 各 DP 配列の開始セルを、対応するセルのカロリーで初期化します。 
3. 埋める`dp1`(イアハブ左上から右下)。 細胞ごとに`(i, j)`、それに到達するための最大カロリーは`a[i][j] + max(dp1[i-1][j], dp1[i][j-1])`。 最初の行と列は、前のセルが 1 つだけ存在するというエッジ ケースを処理します。 
4. 埋める`dp2`(Iahub 右下から左上)。 細胞ごとに`(i, j)`、`dp2[i][j] = a[i][j] + max(dp2[i+1][j], dp2[i][j+1])`。 右下から開始して後方に移動します。 
5. 埋める`dp3`(イアフビナ左下から右上)。 細胞ごとに`(i, j)`、`dp3[i][j] = a[i][j] + max(dp3[i+1][j], dp3[i][j-1])`。 左下から始めます。 
6. 埋める`dp4`(イアフビナ右上から左下)。 細胞ごとに`(i, j)`、`dp4[i][j] = a[i][j] + max(dp4[i-1][j], dp4[i][j+1])`。 右上から始めます。 
7. すべての内部セルを反復処理します。`(i, j)`どこ`1 ≤ i ≤ n-2`そして`1 ≤ j ≤ m-2`。 各セルについて、考えられる 2 つの交差合計を計算します。 

- パターン 1: イアフブが下に移動してから右に移動し、イアフビナが右に移動してから上に移動します。`total1 = dp1[i-1][j] + dp2[i+1][j] + dp3[i][j-1] + dp4[i][j+1]`・パターン2：イアフブは右→下、イアフビナは上→右。`total2 = dp1[i][j-1] + dp2[i][j+1] + dp3[i+1][j] + dp4[i-1][j]`最大値で回答を更新します`total1`そして`total2`。 
8. 最大合計ゲインを出力します。 

**機能する理由:** DP アレイは、どのセルでも、許可された方向に沿って最大のゲインが得られることを保証します。 4 つの方向すべてを事前に計算することにより、交差点を二重にカウントすることなく、内部セルごとに交差パターンを O(1) で組み合わせることができます。 すべての内部セルを考慮するため、最適なミーティング ポイントが確実に選択されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
a = [list(map(int, input().split())) for _ in range(n)]

dp1 = [[0]*m for _ in range(n)]
dp2 = [[0]*m for _ in range(n)]
dp3 = [[0]*m for _ in range(n)]
dp4 = [[0]*m for _ in range(n)]

# dp1: top-left to bottom-right
for i in range(n):
    for j in range(m):
        best = 0
        if i > 0:
            best = max(best, dp1[i-1][j])
        if j > 0:
            best = max(best, dp1[i][j-1])
        dp1[i][j] = a[i][j] + best

# dp2: bottom-right to top-left
for i in range(n-1, -1, -1):
    for j in range(m-1, -1, -1):
        best = 0
        if i < n-1:
            best = max(best, dp2[i+1][j])
        if j < m-1:
            best = max(best, dp2[i][j+1])
        dp2[i][j] = a[i][j] + best

# dp3: bottom-left to top-right
for i in range(n-1, -1, -1):
    for j in range(m):
        best = 0
        if i < n-1:
            best = max(best, dp3[i+1][j])
        if j > 0:
            best = max(best, dp3[i][j-1])
        dp3[i][j] = a[i][j] + best

# dp4: top-right to bottom-left
for i in range(n):
    for j in range(m-1, -1, -1):
        best = 0
        if i > 0:
            best = max(best, dp4[i-1][j])
        if j < m-1:
            best = max(best, dp4[i][j+1])
        dp4[i][j] = a[i][j] + best

ans = 0
for i in range(1, n-1):
    for j in range(1, m-1):
        total1 = dp1[i-1][j] + dp2[i+1][j] + dp3[i][j-1] + dp4[i][j+1]
        total2 = dp1[i][j-1] + dp2[i][j+1] + dp3[i+1][j] + dp4[i-1][j]
        ans = max(ans, total1, total2)

print(ans)
```最初の 4 つのブロックは、4 方向すべての DP テーブルを計算します。 ミーティングポイントではすべてのパスが継続できるようにする必要があるため、内部セルをループすることで境界線を確実に回避できます。 2 つの交差パターンは、カロリーを重複させることなくパスを組み合わせる可能な両方の方法を処理します。 オフ
