 ## 問題の理解

 から始めます`n`小石。 

どのような動きであっても、現在私たちが持っているのであれば、`x`小石、私たちはそれらを配置しなければなりません`a`同じ長さの行`b`、 どこ`a > 1`そして`x = a · b`。 行を作成した後、1 行だけを保持し、他の行はすべて破棄します。 小石の数は、`b`。 

小石カウントのシーケンスを次のように表すと、`c₁ = n, c₂, c₃, ..., cₖ = 1`その場合、次のすべての値は前の値の適切な約数でなければなりません。`cᵢ = a · cᵢ₊₁`と`a > 1`。 

ゲームのスコアは、このシーケンス内のすべての値の合計です。 その合計を最大化する必要があります。 

入力には単一の整数が含まれています`n`、 まで`10^9`。 このような制限により、次のすべての数値に対する動的計画法が即座に排除されます。`n`、また、大規模な状態空間の探索も除外されます。 おおよそのパフォーマンスを発揮するソリューション`O(√n)`作業は簡単に十分に高速ですが、それに近いものは`O(n)`そうではありません。 

最も重要な観察は、すべての移動が現在の数値を適切な約数の 1 つで置き換えることです。 選択が異なると、シーケンスの長さも異なり、合計も異なる場合があります。 

いくつかの特殊なケースは注目に値します。 

考慮する`n = 2`。 

唯一の法的取り決めは、`2 = 2 · 1`したがって、シーケンスは次のようになります。`2 → 1`答えは`3`。 

すべての数値に 1 より大きい非自明な約数があると仮定する不用意な実装は、ここで失敗します。 

考慮する`n = 8`。 

考えられるパスは次のとおりです。`8 → 4 → 2 → 1`、合計 = 15`8 → 2 → 1`、合計 = 11`8 → 1`、合計 = 9

 最善の策は、最大の削減ではありません。 すべての訪問数が合計に寄与するため、現在の値をできるだけ大きく保ちたいと考えています。 

考慮する`n = 13`。 

13 は素数なので、可能な唯一の動きは次のとおりです。`13 → 1`答えは`14`。 

複合因数分解ステップが常に存在すると仮定したソリューションでは、不正確な結果が生成されます。 

## アプローチ

 ブルートフォース ソリューションでは、すべての除数の選択が分岐の決定と見なされます。 現在値から`x`、すべての適切な約数を列挙できます`d < x`、から開始して最高のスコアを再帰的に計算します。`d`、最大値を取ります。 

すべての正当なゲームがこの再帰ツリーの 1 つのパスに対応するため、これは正しいです。 残念ながら、たとえ`n ≤ 10^9`、再帰では、多くの繰り返される状態と多くの可能な約数チェーンが調査されます。 状態空間はこの特定の制限では巨大ではありませんが、必要以上に複雑です。 

重要な観察は、動きが実際に何をするかを調べることから得られます。 

現在の番号が`x`。 因数分解を選択します`x = a · b`と`a > 1`、そして保管してください`b`。 

以来`b = x / a`、当面の貢献を最大化するということは、`a`できるだけ小さいもの。 可能な最小値`a`の最小の素因数です`x`。 

させて`p`～の最小の素因数となる`x`。 

次に、考えられる最大の次の状態は次のようになります。`x / p`。 

将来のスコアはすべて負ではないため、より大きな次の状態を選択しても問題はありません。 ある除数チェーンが別の除数チェーンよりも大きい値から開始されている場合、その除数チェーンはすぐに追加のスコアをすでに獲得しており、少なくとも同程度の将来の可能性もあります。 

つまり、最適な戦略は常に次のとおりです。 

から`x`を最小の素因数で割ります。 

素数の場合、自明でない約数は存在しないため、唯一の方法は直接次のようにすることです。`1`。 

ゲームは決定的になります。 最小の素因数で繰り返し除算し、訪問したすべての値を答えに加算します。 

これを実装するには、現在の数値の最小の素因数を繰り返し見つけるだけで済みます。 以来`n ≤ 10^9`、トライアル分割まで`√x`で十分です。

 ## アルゴリズムのチュートリアル

 1.読む`n`。 
2. 答えを次のように初期化します。`n`開始値は常にスコアに含まれるためです。 
3. 現在の値がより大きい間`1`、その最小の素因数を見つけます。 
4. 除算の試行中に約数が見つからない場合、現在の値は素数になります。 唯一の合法的な次の状態は、`1`。 追加`1`答えに戻って停止します。 
5. それ以外の場合は、現在の値を最小の素因数で除算します。 
6. 新しい値を答えに追加します。 
7. 値が次になるまで繰り返します。`1`。 

ステップ 5 が最適である理由は、最小の素因数で除算すると、可能な最大の適切な約数が生成されるためです。 将来の寄与はすべてプラスであるため、可能な限り最大の数値を維持すると、合計スコアが最大になります。 

### なぜ効果があるのか

 任意の現在値に対して`x`、あらゆる法的措置は要素を選択します`a > 1`そしてに移動します`x/a`。 

させて`p`～の最小の素因数となる`x`。 あらゆる有効な要素`a`満足する`a ≥ p`したがって、`x/a ≤ x/p`。 

それで`x/p`可能な最大の次の状態です。 

別の手がより小さな次の状態を選択すると仮定します。`y < x/p`。 当面の貢献度はすでに悪化しています。`y`より小さいです。 より大きな数字から開始すると、常に少なくとも同じ数の利用可能な手が残り、将来のスコアが減少することはないため、将来の貢献はこの損失を補うことはできません。 

したがって、あらゆる最適なソリューションは次のいずれかを選択する必要があります。`x/p`。 各移動の後に同じ引数を適用すると、最小の素因数で繰り返し除算することで独自の最適スコアが生成されることが証明されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def smallest_prime_factor(x):
    d = 2
    while d * d <= x:
        if x % d == 0:
            return d
        d += 1
    return x  # x is prime

def solve():
    n = int(input())

    ans = n
    cur = n

    while cur > 1:
        spf = smallest_prime_factor(cur)

        if spf == cur:
            ans += 1
            break

        cur //= spf
        ans += cur

    print(ans)

solve()
```ヘルパー関数は、試行除算を使用して最小の素因数を見つけます。 到達する前に約数が見つからない場合`√x`、数値は素数であり、関数は数値自体を返します。 

メインループは現在の小石の数を維持します。 各反復では、最小の素因数で除算することによって最適な移動が実行されます。 シーケンス内のすべての状態がスコアに寄与するため、結果の値が答えに追加されます。 

主要なケースには特別な処理が必要です。 現在の値が素数の場合、次の最終状態は次のようになります。`1`。 最後に追加します`1`そして終了します。 

すべての算術演算は 64 ビット整数に快適に収まります。 最大の答えは、多くの大きな中間値が蓄積されたときに発生しますが、依然として Python の制限をはるかに下回っています。

順序：`13 → 1`答え：`13 + 1 = 14`これにより、複合移動が利用できない数値が正しく処理されます。 

### 有効な最小入力
