 ## 解決策
 ## 問題の理解

 各頂点が温室、各エッジがヒート パイプであるグラフがあります。 すべての頂点は範囲内の整数の温度を受け取る必要があります`[a, b]`。 すべてのエッジについて、2 つの終点温度は正確に 1 だけ異なっていなければなりません。 同時に、あらゆる温度から`a`に`b`頂点間に少なくとも 1 回は出現する必要があります。 

頂点の数という点では制約は少ないです。 すべての合計`n`値はわずか 2000 なので、アルゴリズムは`O(n^2)`可能です。 エッジの数は 50000 に達する可能性があるため、グラフを効率的に処理し、考えられるすべての割り当てに対してコストのかかる作業を回避する必要があります。 

厄介なケースは、無効な奇数サイクルだけではありません。 グラフはエッジの違いをすべて満たすことができますが、十分な異なる温度を作成できないため失敗します。 例えば：```
1
3 3 1 3
1 2
2 3
1 3
```サイクルを一周すると、間違ったパリティで値を返す必要があるため、三角形に温度を割り当てることはできません。 正しい出力は次のとおりです`No`。 

別のケースは次のとおりです。```
1
3 0 1 3
```3 つの孤立した頂点と 3 つの必要な温度があります。 を代入することで答えが可能です`1 2 3`。 接続されたコンポーネントのみをチェックする不用意なソリューションでは、孤立した頂点が忘れられる可能性があります。 

最後の微妙なケースは、多くの頂点があるが、狭い温度範囲しかカバーしないコンポーネントです。 中心温度のある星`2`そして葉の温度`1`温度のみを提供します`1`そして`2`複数の頂点が含まれている場合でも。 到達可能な温度を個別にカウントする代わりに頂点をカウントすると、誤った結果が得られます。 

## アプローチ

 直接的な解決策では、すべての温室に温度を割り当て、制約が満たされているかどうかを確認します。 各頂点には最大で`b-a+1`したがって、検索空間は指数関数的であり、直ちに不可能になります。 

グラフ構造により、より強力な観察が得られます。 1 つの連結コンポーネント内では、1 つの頂点の温度を固定した後、他のすべての頂点が強制されます。 エッジを横切ると、次のいずれかによって温度が変化します。`+1`または`-1`。 2 つのトラバースが同じ頂点に矛盾する値を与える場合、コンポーネントは不可能になります。 

したがって、有効なコンポーネントは相対温度の固定形状を持ちます。 任意のルートからオフセットを計算する場合、すべてのオフセットに同じ定数を追加することでコンポーネント全体をシフトできます。 2 つの極値の間のパスはすべての中間値を通過する必要があるため、コンポーネントは最小オフセットと最大オフセットの間のすべての整数をカバーします。 

したがって、問題は、これらのコンポーネント間隔のシフトを選択して、それらの和集合がカバーされるようにすることになります。`[a,b]`。 

頂点の総数が少ないため、これは区間カバレッジで解決できます。 コンポーネントは内部のどこにでも配置可能`[a,b]`。 すでにカバーされているパーツの隣にコンポーネントを配置することで、可能な限り最大のカバーされたセグメントを貪欲に作成できます。 温度を再構築するには、選択したシフトを記憶する必要もあります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | 指数 | O(n) | 遅すぎる |
 | 最適 | O(n + m) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. グラフの隣接リストを作成します。 すべての接続コンポーネントに対して、各頂点のオフセットを保存しながら BFS を実行します。 最初の頂点はオフセットを受け取ります`0`。 2 つの頂点間のエッジの場合、2 番目の頂点のオフセットは最初の頂点より正確に 1 大きいか小さい必要があります。 以前に訪問した頂点が異なるオフセットを受け取った場合、コンポーネントは無効になります。 
2. 各コンポーネントについて、その頂点の最小オフセット、最大オフセット、および実際のオフセットを記録します。 コンポーネントの自然温度間隔には長さがあります`max_offset - min_offset + 1`。 
3. 各コンポーネントの間隔が内側に収まるようにずらします`[a,b]`。 コンポーネントは貪欲に処理されます。 すでに保証されている最も適切な温度を維持します。 コンポーネントの左側が現在の境界に触れるように移動すると、コンポーネントはこのカバレッジを拡張できます。 
4. すべてのコンポーネントを処理してもカバー範囲に達しない場合`b`、解決策はありません。 それ以外の場合は、保存されているシフトをすべての頂点に適用し、温度を出力します。 

なぜ効果があるのか:

 すべての有効なコンポーネントの自由度は 1 つだけです。つまり、すべての頂点に定数を追加します。 BFS オフセットは、そのコンポーネントのすべての可能な割り当てを記述します。 接続されたパスはステップごとに温度を 1 ずつ変化させるため、最小オフセットと最大オフセットの間のすべての値が表示されます。 必要よりも早くコンポーネントを配置すると、将来のカバーされない領域が減少するだけであるため、貪欲な配置によって拡張の可能性が無駄になることはありません。 したがって、到達`b`は、必要な温度がすべて生成されていることを意味し、その温度に到達しない場合は、同じ間隔の配置が全範囲をカバーできないことを意味します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    ans = []

    for _ in range(t):
        n, m, a, b = map(int, input().split())
        g = [[] for _ in range(n)]
        for _ in range(m):
            u, v = map(int, input().split())
            u -= 1
            v -= 1
            g[u].append(v)
            g[v].append(u)

        off = [None] * n
        comps = []
        ok = True

        for s in range(n):
            if off[s] is not None:
                continue

            off[s] = 0
            q = [s]
            comp = []
            head = 0

            while head < len(q):
                u = q[head]
                head += 1
                comp.append(u)

                for v in g[u]:
                    if off[v] is None:
                        off[v] = off[u] + 1
                        q.append(v)
                    elif abs(off[v] - off[u]) != 1:
                        ok = False

            mn = min(off[x] for x in comp)
            mx = max(off[x] for x in comp)
            comps.append((comp, mn, mx))

        if not ok:
            ans.append("No")
            continue

        comps.sort(key=lambda x: x[2] - x[1], reverse=True)

        cur = a - 1
        res = [0] * n

        for comp, mn, mx in comps:
            if cur >= b:
                break
            length = mx - mn + 1
            left = cur + 1
            if left + length - 1 <= b:
                shift = left - mn
                cur += length
            else:
                shift = b - mx
                cur = b

            for v in comp:
                res[v] = off[v] + shift

        if cur < b or any(x < a or x > b for x in res):
            ans.append("No")
        else:
            ans.append("Yes")
            ans.append(" ".join(map(str, res)))

    print("\n".join(ans))

if __name__ == "__main__":
    solve()
```BFS セクションはソリューションの中核です。 オフセット配列には、コンポーネントの唯一可能な相対配置が格納されます。 競合チェックでは次を使用します。`abs(off[v] - off[u]) != 1`、奇数のサイクルと一貫性のない制約の両方を捕捉します。 

コンポーネント リストには、頂点とそのオフセット範囲が保持されます。 ソートのステップは正確さを保つために厳密に必要なわけではありませんが、最初に大きな間隔を置くことで、貪欲なカバレッジ プロセスが簡素化されます。 

再構成ステップでは、保存されたシフトが使用されます。 よくある間違いは、コンポーネントのエンドポイントのみをシフトし、コンポーネント内のすべての頂点に同じ追加が必要であることを忘れることです。

## 特殊なケース

 奇数サイクルの場合、BFS はサイクル全体にオフセットを割り当てます。 3 番目のエッジは 1 の差を要求しますが、すでに割り当てられているオフセットではそれを満たすことができないため、無効な温度が生成される前に矛盾が検出されます。 

孤立した頂点の場合、すべての頂点は間隔の長さが 1 のコンポーネントになります。 貪欲な配置では、必要な範囲がカバーされるまで連続した温度が割り当てられます。 

星など、温度が繰り返されるコンポーネントの場合、アルゴリズムは頂点の数ではなくオフセット範囲を使用します。 これにより、コンポーネントが実際に提供できる異なる温度の数が正確に測定されます。
