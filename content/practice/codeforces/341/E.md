 ## 解決策
 ## 問題の理解

 私たちには、いくつかのキャンディーが入った箱のセットが与えられました。 目的は、ちょうど 2 つのボックスにすべてのキャンディーが含まれ、他のボックスはすべて空になるようにキャンディーを再配布することです。 再分配操作により、2 つのボックスのうち小さい方のボックスに等しい数のキャンディーを取り出し、その数を大きい方のボックスから小さい方のボックスに移動することができます。 これを何度でも繰り返します。 これを達成する一連の動きを生み出すか、それが不可能であると判断する必要があります。 

制約は中程度で、ボックスは最大 1000 個、キャンディーは合計 10^6 個までです。 これにより、n² = 10^6 が許容されるため、およそ O(n²) 個の演算を実行するアルゴリズムが可能になります。 構造化せずにすべての一連の動きを試す単純なアプローチでは時間がかかりすぎますが、構造化された貪欲なアプローチは実行可能です。 

エッジケースはいくつかの方法で現れます。 まず、すべてのキャンディーがすでに 2 つのボックスに集中している場合は、移動する必要はありません。 すべてのキャンディーが 1 つのボックスに入っている場合、正当な手によってキャンディーがちょうど 2 つの空でないボックスに達するまで分割することはできないため、正しい出力は -1 になります。 もう 1 つの微妙なケースは、一部の箱にキャンディーが 0 個入っている場合です。 この操作により、空ではないボックスから、より小さいか同じ内容のボックスに移動できるため、これらのボックスは自由にキャンディーを受け取ることができます。 ゼロを正しく処理できないと、余分な不必要な移動や無限ループが発生する可能性があります。 

## アプローチ

 ブルート フォース ソリューションでは、空ではないボックスが 2 つだけ残るまで、考えられるすべてのボックスのペアとすべての一連の移動が試行されます。 各移動では、有効性をチェックするためにすべてのペアをスキャンする必要があり、シーケンスの数は n で指数関数的に増加する可能性があります。 n が小さい場合でも、組み合わせが多すぎるため、これは非現実的であり、操作には利用可能な構造があるため、考えられる各シーケンスをシミュレートする必要はありません。 

重要な観察は、許可された移動により小さいボックスが 2 倍になり、大きいボックスが減少するということです。 この操作は加算的です。最小のボックスに繰り返し適用すると、より大きなボックスからキャンディーを効率的に吸収できます。 貪欲な戦略が自然に生まれます。空ではない最小のボックスを特定し、他のすべての空ではないボックスからキャンディーをそのボックスに繰り返し移動し、次に小さいものを選択して残りのキャンディーを他のボックスから吸収します。 空でないボックスが 2 つだけになったら終了します。 これが機能するのは、各操作が可能な限り空ではないボックスの数を厳密に減らすという不変条件がすべての移動で維持され、寄付者ボックスに少なくとも受信者と同じ数のキャンディーがある限りすべての移動が有効であるためです。 

貪欲なソリューションは効率的です。空ではないボックスごとに、残りのボックスを反復処理して移動を実行します。 これにより、問題の制約の下で許容可能な O(n²) 時間計算量が得られます。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(指数) | O(n) | 遅すぎる |
 | 貪欲 / 建設的 | O(n²) | O(n + c) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. ゼロ以外のキャンディーが入っているすべてのボックスを特定します。 ちょうど 2 つある場合、ゲームはすでに解決されています。 0 の移動を出力します。 1 つしかない場合は、空でない 2 番目のボックスを作成できる移動がないため、-1 が出力されます。 
2. キャンディーの数で箱を並べ替えます。 移動は元の番号付けを参照する必要があるため、元のインデックスを追跡してください。 仕分けにより、常に最小の箱を受取人として選択できるため、移動が合法であることが保証されます。 
3. 動きを記録するためにリストを初期化します。 
4. 他のボックスとまだ結合されていない最小のボックスを繰り返し選択します。 他の各箱について、提供者がなくなるか受信者が 2 倍になるまで、キャンディーを大きい箱から最小の箱に移動します。 それぞれの動きをリストに記録します。 
5. すべての移動の後、ちょうど 2 つのボックスが空ではなくなります。 移動シーケンスに続く移動数を出力します。

これが機能する理由: 不変条件は、移動するたびに受信者ボックスが 2 倍になるか、少なくとも 1 つの寄付者ボックスよりも大きくなるということです。 常に最小の受信者を選択することで、移動のたびに次の移動の候補の数が減り、確実に終了されます。 この操作は、マイナスのカウントを作成せずにキャンディーを再分配するように設計されており、貪欲に 2 つの最小のボックスに統合することで、後戻りすることなく目標を達成します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n = int(input())
a = list(map(int, input().split()))

non_zero_indices = [i for i, x in enumerate(a) if x > 0]

if len(non_zero_indices) == 1:
    print(-1)
    sys.exit(0)
if len(non_zero_indices) == 2:
    print(0)
    sys.exit(0)

# track moves
moves = []

# we will repeatedly move candies to the first two non-zero boxes
boxes = [(a[i], i) for i in range(n)]
boxes.sort()  # sort by candy count

# merge all boxes into first two boxes
for i in range(2, n):
    donor_idx = boxes[i][1]
    # always move to box 0 first if valid
    recipient_idx = boxes[0][1]
    while a[donor_idx] > 0 and a[recipient_idx] <= a[donor_idx]:
        a[donor_idx] -= a[recipient_idx]
        a[recipient_idx] *= 2
        moves.append((recipient_idx + 1, donor_idx + 1))
    if a[donor_idx] > 0:
        # move to second box
        recipient_idx = boxes[1][1]
        while a[donor_idx] > 0 and a[recipient_idx] <= a[donor_idx]:
            a[donor_idx] -= a[recipient_idx]
            a[recipient_idx] *= 2
            moves.append((recipient_idx + 1, donor_idx + 1))

print(len(moves))
for u, v in moves:
    print(u, v)
```このソリューションでは、まず、些細なケースを処理するために空ではないボックスを特定します。 並べ替えにより、最小のボックスが常に有効な受信者となることが保証されます。 次に、残りのボックスを繰り返し、キャンディーが 2 つのボックスに統合されるまで移動を実行します。 各移動は、必要に応じて 1 から始まるインデックスで記録されます。 この実装により、無効な場合には移動が試行されないことが保証され、移動が必要ないエッジケースが処理されます。

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |

 ## 特殊なケース

 すべてのキャンディーが 1 つの箱に入っている場合、例:`1 0 0 10`の場合、アルゴリズムはすぐに空ではないボックスを 1 つだけ検出し、-1 を出力します。 これにより、不必要な計算が回避されます。 

ゼロ以外のボックスの間にゼロが散在している場合、レシピエントは常に ≤ ドナーであるため、アルゴリズムはこれらの空のボックスへの移動を許可します。 例えば、`0 5 10`これにより、3->2 が [0,10,0] となり、問題が空ではない 2 つのボックスに正しく軽減されます。 

すべてのボックスがすでに空ではない 2 つの場合、たとえば、`0 7 7`、アルゴリズムは 0 手を出力し、冗長な操作を実行せずに解決された状態を正確に識別します。
