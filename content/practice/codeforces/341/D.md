 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$行列は最初はゼロで埋められます。 この問題では、2 種類の演算を効率的に処理することが求められます。1 つは部分行列内のすべての要素の xor を計算するもの、もう 1 つは部分行列のすべての要素に指定された値を xor するものです。 各演算では部分行列の左上と右下の座標を指定し、更新の場合は xor する値を指定します。 

入力境界は重要です。$n$最大 1000 まで増加できるため、要素の合計数は最大$10^6$、および操作の数$m$まで高くすることができます$10^5$。 クエリまたは更新ごとに部分行列のすべてのセルを反復処理する単純なソリューションでは、最大で 2 時間かかります。$10^5 \cdot 10^6 = 10^{11}$最悪の場合、1 秒の制限で処理できる範囲をはるかに超えた操作が行われます。 これは、操作ごとに各要素を個別に操作できないことを意味します。 範囲の更新と範囲のクエリの両方を効率的に実行できるデータ構造が必要です。 

注意すべきエッジケースには、単一要素の部分行列、行列全体をカバーする部分行列、同じ要素に対する複数の更新などがあります。 たとえば、同じ値を 2 回 xor 演算すると、それが打ち消されるはずです。 範囲更新を正しく処理しない単純な prefix-xor アプローチでは、更新が重なったときに誤った結果が生じる可能性があります。 

## アプローチ

 ブルートフォースアプローチは簡単です。 更新ごとに、指定された部分行列内のすべての要素をループし、指定された値との XOR を実行します。 クエリごとに、部分行列をループし、すべての値の XOR を実行します。 このアプローチは正しいですが、時間がかかります。$n \times n$行列$m$それぞれの操作が潜在的に行列全体に影響を与える可能性があるため、最大で$m \cdot n^2 = 10^5 \cdot 10^6 = 10^{11}$実行不可能な操作。 

重要な洞察は、xor がそれ自体の逆演算であるため、加算演算と減算演算の両方で適切に動作するということです。 このプロパティにより、各セルが xor 寄与を格納する 2D フェンウィック ツリー (バイナリ インデックス付きツリー) を使用できるようになります。 標準の 2D フェンウィック ツリーは、ポイントの更新と四角形のクエリをサポートしていますが、包含-除外の原則を使用して四角形の更新をサポートするように拡張できます。 アイデアは、4 つの角を適切に更新することで値を四角形に XOR できる構造を維持し、四角形に対するクエリはこれらの角の XOR 和を使用して表現できるようにすることです。 これにより、各操作が次のように削減されます。$O(\log^2 n)$これは、指定された制約に対して十分な速度です。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n^2 * m) | O(n^2) | 遅すぎる |
 | 2D BIT (長方形の更新 + クエリ) | O(m * log^2 n) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 2D バイナリ インデックス付きツリーを初期化する`bit`寸法付き$n+1 \times n+1$1 から始まるインデックスを簡単に処理できるようになります。 
2. ヘルパー関数を定義する`xor_update(x, y, val)`標準の BIT 更新を実行します: xor`val`座標の影響を受ける BIT 内のすべての位置に`(x, y)`。 これが核となる構成要素です。 
3. 値を XOR する`v`長方形の上に`(x0, y0)`に`(x1, y1)`、包含と除外を適用します。 

-xor`v`で`(x0, y0)`-xor`v`で`(x0, y1 + 1)`-xor`v`で`(x1 + 1, y0)`-xor`v`で`(x1 + 1, y1 + 1)`これにより、任意のセルまでのプレフィックス xor を計算するときに、`(x, y)`、重なり合う長方形からの寄与が正しく結合されます。 
4. ヘルパー関数を定義する`prefix_xor(x, y)`から部分行列の xor を計算します。`(1,1)`に`(x, y)`標準の 2D BIT クエリ トラバーサルを使用します。 
5. 任意の部分行列の xor を計算するには`(x0, y0, x1, y1)`、プレフィックス xor 値を使用して包含/除外を適用します。 

- 結果 =`prefix_xor(x1, y1) ^ prefix_xor(x0-1, y1) ^ prefix_xor(x1, y0-1) ^ prefix_xor(x0-1, y0-1)`6. 入力内の各操作を処理します。 更新の場合は、四角形更新ルーチンを呼び出します。 クエリの場合は、部分行列プレフィックス xors を使用して xor を計算し、結果を出力します。 

機能する理由: 包含/除外を備えた 2D BIT は、すべての更新の XOR 寄与を維持します。 各プレフィックス クエリは、指定された四角形に影響を与えるすべての更新の xor を正確に取得します。 xor は結合的で自己反転であるため、重複する更新は正しくキャンセルされ、二重カウントは発生しません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

class BIT2D:
    def __init__(self, n):
        self.n = n
        self.bit = [[0] * (n + 2) for _ in range(n + 2)]

    def update(self, x, y, val):
        i = x
        while i <= self.n:
            j = y
            while j <= self.n:
                self.bit[i][j] ^= val
                j += j & -j
            i += i & -i

    def rectangle_update(self, x0, y0, x1, y1, val):
        self.update(x0, y0, val)
        self.update(x0, y1 + 1, val)
        self.update(x1 + 1, y0, val)
        self.update(x1 + 1, y1 + 1, val)

    def prefix_xor(self, x, y):
        res = 0
        i = x
        while i > 0:
            j = y
            while j > 0:
                res ^= self.bit[i][j]
                j -= j & -j
            i -= i & -i
        return res

    def query(self, x0, y0, x1, y1):
        return (self.prefix_xor(x1, y1) ^ self.prefix_xor(x0 - 1, y1) ^
                self.prefix_xor(x1, y0 - 1) ^ self.prefix_xor(x0 - 1, y0 - 1))

n, m = map(int, input().split())
bit2d = BIT2D(n)

for _ in range(m):
    cmd = list(map(int, input().split()))
    if cmd[0] == 1:
        x0, y0, x1, y1 = cmd[1:]
        print(bit2d.query(x0, y0, x1, y1))
    else:
        x0, y0, x1, y1, v = cmd[1:]
        bit2d.rectangle_update(x0, y0, x1, y1, v)
```の`BIT2D`クラスはすべての BIT ロジックをカプセル化します。 の`update`メソッドは 1 つのセルとそのすべての祖先を変更します。`rectangle_update`xor を四隅に適用します。 の`query`このメソッドは、包含-排他を使用して部分行列の正確な xor を取得します。 

境界の扱いは微妙です。 必要です`n+2`インデックスのオーバーフローを回避するための内部配列の場合`x1+1`または`y1+1`等しい`n+1`。 1 から始まるインデックスを使用すると、BIT トラバーサルとの混乱を避けることができます。
