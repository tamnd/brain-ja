 ## 解決策
 ## 問題の理解

 夏の間、毎日の降水量の系列が与えられているので、最も早く「雨が降っていない」日を見つける必要があります。 前の日と比べて、その日はそれほど雨が降っていないとみなされます。`x`何日も、そして次の日も`y`（夏の期間内で）日中は、どの地域よりも降水量が厳密に少なくなっています。 入力は次のもので構成されます`n`日々、と`x`振り返りの日々と`y`先読みの日々、そしてその後`n`降雨量を表す個別の整数。 出力は、この条件を満たす最初の日のインデックスです。 

なぜなら`n`最大 100,000 人で、国民は前後 7 日間しか視聴しない場合、毎日を他のすべての日と大きなウィンドウで比較するソリューションは非効率的です。 単純な総当り攻撃では、次のような結果が得られます。`x + y`結果として、最悪の場合、最大 100,000 * 14 = 1,400,000 回の操作が発生します。 これは最新の CPU にとっては十分小さいため、単純な解決策でも機能する可能性があります。 主な微妙な点は、境界を適切に処理することにあります。`x`日が経つと確認できません`x`数日前。 最後に`y`日が経つと確認できません`y`数日後。 また、すべての雨の量は個別であるため、厳密な不平等は安全であり、ネクタイを処理する必要はありません。 

不用意にアプローチすると、範囲を制限することを忘れる可能性があります`1`に`n`。 たとえば、次の場合`x = 2`そして私たちはその日を検討しています`1`、私たちは日を見ることができません`-1`または`0`。 If implemented naively, accessing negative indices could produce incorrect results or runtime errors. もう 1 つの微妙な点は、最も早い日を返さなければならないため、複数の日が条件を満たす場合は、インデックスが最も小さい日を選択する必要があることです。 

## アプローチ

 The brute-force approach is straightforward: iterate over each day, check the rainfall for the`x`前日と`y`次の日を調べて、現在の日がこのウィンドウ内のすべての近傍よりも厳密に小さいかどうかを判断します。 「それほど雨が降っていない」の定義を直接実装しているため、これは正しいですが、次の場合には非効率になる可能性があります。`x`そして`y`大きかった。 ここ、`x`そして`y`は 7 で区切られているため、直接比較することもできます。 

もう少しクリーンなアプローチに関する重要な洞察は次のとおりです。`x`そして`y`非常に小さいため、セグメント ツリーや両端キューなどの高度なデータ構造は必要ありません。 一日から単純に繰り返すことができます`1`今日`n`そして毎日、左右の小さな窓をチェックしてください。 すべての隣人がより優れた日を見つけたら、すぐにその日を元に戻すことができます。 これは、「最も早い日」基準により線形スキャンが許可されるという事実を利用します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルート フォース (近隣のチェック) | O(n * (x + y)) | O(n) | 承認済み |
 | 最適化済み (同じロジック、早期終了) | O(n * (x + y)) | O(n) | 承認済み |

 実際には、小さいことを考慮すると、どちらも許容されます。`x`そして`y`。 

## アルゴリズムのチュートリアル

 1.読む`n`、`x`、 そして`y`、配列を読み取ります`a`降水量のこと。 
2. 毎日のインデックスを反復処理する`d`から`1`に`n`。 
3. 毎日について`d`、からの過去のすべての日を確認してください`max(1, d - x)`まで`d - 1`。 これらのいずれかに以下の雨が降った場合、`a[d]`、その日`d`あまり雨が降らないはずがないので、次の日にスキップします。 
4.次の日をすべて確認します`d + 1`まで`min(n, d + y)`。 これらのいずれかに以下の雨が降った場合、`a[d]`、その日`d`失格です。 
5. 両方のチェックに合格した場合は、印刷します。`d`雨が降っていない日の中で一番早いので終了します。 

機能する理由: このアルゴリズムは、境界を尊重しながら、現在の日と国民が関心を持っている正確な日を明示的に比較します。 すべての値は個別であるため、厳密な比較によって条件が正しく評価されることが保証されます。 線形反復により、最初の有効な日が返されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, x, y = map(int, input().split())
a = list(map(int, input().split()))

for i in range(n):
    is_valid = True
    for j in range(max(0, i - x), i):
        if a[j] <= a[i]:
            is_valid = False
            break
    if not is_valid:
        continue
    for j in range(i + 1, min(n, i + y + 1)):
        if a[j] <= a[i]:
            is_valid = False
            break
    if is_valid:
        print(i + 1)
        break
```コードは最初の日から最後の日まで繰り返されます。 毎日、次を使用して左右のウィンドウをチェックします。`max`そして`min`限界を超えないようにするためです。 両方のチェックに合格した最初の日が印刷されます。 の`+1`問題ステートメント内の 1 から始まるインデックス付けを説明します。
