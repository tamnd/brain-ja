 ## 解決策
 ## 問題の理解

 スイレンはまっすぐな茎で湖の底に取り付けられています。 当初、茎は完全に垂直であるため、花は湖底の根元の真上にあります。 花は既知の高さだけ水面上に浮かんでいます\(H\)。 

次に、花が水面に沿って一定距離だけ水平に引っ張られたときに何が起こるかをシミュレーションします。\(L\)。 ステムは真っ直ぐで硬いままであるため、底点に固定された単一のセグメントとして回転します。 問題に記載されている瞬間、花はちょうど水面に到達したところです。 

タスクは、茎の取り付け点での湖の深さを決定することです。 

幾何学的には、これは直角三角形の問題になります。 茎は斜辺であり、その長さは固定されており、湖の底と花を結びます。 最初は、底から花までの垂直距離は、茎の全長から水深を引いたものになります。 花を水平方向にドラッグした後、\(L\)、花は水面に出ているので、垂直の高さはまさに湖の深さになります。 

制約\(1 \le H < L \le 10^6\)これは、すべてが浮動小数点演算に快適に適合し、オーバーフローや極端な大きさによる数値の不安定性を心配することなく、標準の倍精度を安全に信頼できることを示しています。 

素朴な推論を混乱させる可能性がある微妙な問題は、どのセグメントがステムの長さに対応するかを混同することです。 ステムは単純ではありません\(H + \text{depth}\); これは初期の垂直構成にのみ当てはまります。 回転後、ジオメトリは変化し、ステムの不変の長さと、水平方向の変位と垂直方向の落下によって形成される直角三角形の組み合わせから正しい関係が得られます。 

## アプローチ

 純粋に代数的に考えると、未知数を導入することができます。 湖の深さを次のようにします\(D\)。 そのときのステムの長さは、\(D + H\)、なぜなら、最初の花は\(H\)表面より上。 引きずった後、花は水面にあるので、茎の垂直方向の突起が正確になります。\(D\)、水平方向の変位は\(L\)。 これは、斜辺が次の位置にある直角三角形を形成します。\(D + H\)、片足は\(D\)、そしてもう一つは\(L\)。 

ピタゴラスの定理から次のことが得られます。$$
(D + H)^2 = D^2 + L^2
$$拡張および単純化により削除\(D^2\)両側から:$$
D^2 + 2DH + H^2 = D^2 + L^2
$$
$$
2DH + H^2 = L^2
$$
$$
D = \frac{L^2 - H^2}{2H}
$$ブルートフォースアプローチは、深さを推測して毎回ジオメトリをシミュレートし、結果として得られるステムの長さが一貫性制約に一致するかどうかをチェックすることです。 これには、考えられるすべての深さまで反復する必要があります。\(10^6\)、関係が代数的で直接的なため、これは不必要で無駄です。 

重要な観察は、システムが単一の二次方程式によって完全に決定されるということです。 幾何学的拘束が正しく変換されると、解決策はすぐに得られます。

 ## アルゴリズムのチュートリアル

 1. 整数の読み取り\(H\)そして\(L\)。 これらは、水上の初期の高さとドラッグ後の水平変位を定義します。 

2. ジオメトリを、ステムの長さが一定で等しい直角三角形の関係に変換します。\(D + H\)。 このステップでは、物理的なセットアップを代数に変換します。 

3. ピタゴラスの定理を適用します。$$
   (D + H)^2 = D^2 + L^2
   $$これは、不変ステムの長さと回転後の直交分解をキャプチャします。 

4. 未知の部分を分離するために、両側の同一の用語を展開およびキャンセルします。\(D\)。 この単純化により、対称性により二次項がきれいに削除されます。 

5. 得られた一次方程式を次のように解きます。\(D\):$$
   D = \frac{L^2 - H^2}{2H}
   $$6. 出力\(D\)十分な精度を持つ浮動小数点数として。 

### なぜ効果があるのか

 構造全体は、固定長の剛体セグメントに依存しています。 この固定長は回転しても変化しないため、ステムの端点の有効な構成は、湖の底点を中心とする半径の円上にのみ存在します。\(D + H\)。 最終的な位置は直角三角形を形成します。その斜辺はその半径であり、その脚は水平変位です。\(L\)そして垂直方向の奥行き\(D\)。 この幾何学的制約は三角形を一意に決定するため、計算された式は次のようになります。\(D\)これは、初期構成と最終構成の両方と一致する唯一の値です。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

H, L = map(int, input().split())

D = (L * L - H * H) / (2 * H)
print(D)
```このソリューションは、派生した閉じた形式の公式を直接実装します。 必要な精度は Python 浮動小数点除算のみであるため、使用するだけで十分です。\(10^{-6}\)、中間値は最大でも\(10^{12}\)、このコンテキストでは倍精度で正確に表現できる範囲内に十分にあります。 

引き算\(L^2 - H^2\)変換前は両方の値が 64 ビット整数に収まるため、安全です。 による除算\(2H\)浮動小数点で実行され、最終結果が必要に応じて実数になるようにします。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    H, L = map(int, sys.stdin.readline().split())
    D = (L * L - H * H) / (2 * H)
    return str(D)

# provided sample
assert abs(float(run("1 2\n")) - 1.5) < 1e-9

# minimum values
assert abs(float(run("1 2\n")) - 1.5) < 1e-9

# simple geometric check
assert abs(float(run("2 6\n")) - 8.0) < 1e-9

# equal difference case
assert abs(float(run("3 5\n")) - ((25 - 9) / 6)) < 1e-9

# large values
assert run("1000000 1000000\n")  # just ensures no crash
```| テスト入力 | 期待される出力 | 検証内容 |

 | 1 2 | 1.5 | 基本的な正しさ |

 ## 特殊なケース

 いつ\(H\)たとえば、最小限です\(H = 1\)そして\(L = 2\), the computation reduces to a small integer arithmetic expression and confirms that the formula does not depend on scaling. The algorithm directly computes \(D = (4 - 1)/2 = 1.5\), which matches the expected geometric configuration.

 いつ\(L\)よりわずかに大きいだけです\(H\)、分子\(L^2 - H^2\)プラスのままですが小さいため、浅い湖が形成されます。 減算ステップは両方の平方が 64 ビット整数内に収まるため安全であり、除算では安定した浮動小数点の結果が生成されます。 

いつ\(L\)に比べて非常に大きい\(H\)、深さは二次関数的に増加します。\(L\)。 Python の整数は浮動小数点に変換する前に大きな中間値を正確に処理し、整数段階でのオーバーフローや精度の損失が発生しないため、数式は引き続き正しく動作します。
