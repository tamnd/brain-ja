 ## 解決策
 ## 問題の理解

 ループや複数のエッジのない、接続された重み付き無向グラフが与えられます。 各エッジには正の重みがあります。 このタスクは、各エッジがすべての最小スパニング ツリーに属するか、少なくとも 1 つの最小スパニング ツリーに属するか、または最小スパニング ツリーにまったく属さないかに応じて分類することです。 言い換えれば、すべてのエッジについて、それが MST の構築に不可欠なのか、オプションなのか、または MST に含めることが不可能なのかを知りたいのです。 

グラフには最大 100,000 個の頂点と 100,000 個のエッジを含めることができ、各エッジの重みは最大 1,000,000 です。 これらの制限があるため、O(m log n) よりも複雑なアルゴリズムは遅すぎる可能性があります。 すべての MST を明示的に構築するか、エッジを削除して MST の重みが増加するかどうかを確認しようとする強引なアプローチでは、O(m^2) 以上の操作が必要になりますが、これは実行不可能です。 

自明ではないエッジ ケースには、同じ重み形成サイクルを持つ複数のエッジが含まれます。 たとえば、頂点 1、2、3 とエッジ (1-2、重み 1)、(2-3、重み 1)、(3-1、重み 1) を持つ三角形グラフを考えてみましょう。 任意の 2 つのエッジが MST を形成します。 このような場合、すべてのエッジは「少なくとも 1 つ」であり、「任意」ではなく、「なし」ではありません。 もう 1 つのエッジ ケースは、単一のエッジが 2 つのコンポーネントを接続する最小の重みを持つ場合に発生します。そのエッジはすべての MST に存在する必要がありますが、等重みサイクルを無視する不注意なアルゴリズムにより誤って分類される可能性があります。 

## アプローチ

 ブルート フォースのアプローチは簡単です。エッジごとに、それを一時的に削除し、MST を再計算します。 MST の重みが増加すると、エッジはすべての MST に存在します。 MST の重みが同じで、エッジが 1 つの可能な MST に含まれている場合、そのエッジは少なくとも 1 つの MST に属します。 これを含めると常に MST の重みが増加する場合は、MST なしになります。 これは原理的には機能しますが、各 MST 計算は O(m log n) であるため、O(m * (m log n)) となります。 m が 100,000 までの場合、これは 100 億回の演算となり、遅すぎます。 

重要な観察は、Kruskal のアルゴリズムのように、エッジを重みでソートし、昇順でエッジを処理することによって、MST を効率的に分析できることです。 Union-Find (DSU) 構造は、接続されたコンポーネントを追跡します。 エッジが 2 つの別個のコンポーネントを接続している場合、それは MST の一部である可能性があります。 同じ重みの複数のエッジが同じコンポーネントを接続する場合、どれがオプションであるかを慎重に決定する必要があります。 これを行うには、エッジを重みでグループ化し、グループ内の各エッジの接続性を確認し、エッジを削除すると接続性が失われるかどうかを判断します。 これにより、MST を最初から再計算する必要がなくなり、ランクとパス圧縮による結合を備えた DSU を使用してエッジを O(m log n) で分類できるようになります。 

最後のアプローチは、修正されたクラスカルです。エッジを並べ替え、同じ重みを持つエッジをまとめて処理し、グループごとに、コンポーネント間の唯一の接続であるエッジを「任意」としてマークし、コンポーネントを接続しているが代替手段があるエッジを「少なくとも 1 つ」としてマークし、サイクルを形成するエッジを「なし」としてマークします。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(m^2 log n) | O(n) | 遅すぎる |
 | 修正されたクラスカル + DSU | O(m log n) | O(n + m) | 承認済み |

 ## アルゴリズムのチュートリアル

1. 出力順序を維持できるように、グラフのエッジを読み取り、入力インデックスとともに保存します。 すべてのエッジを重みで昇順に並べ替えます。 ソートにより、クラスカルの MST アルゴリズムと同様に、最小のエッジが最初に処理されることが保証されます。 
2. 頂点ごとに 1 つのコンポーネントを使用して素集合共用体 (DSU) 構造を初期化します。 各コンポーネントは、これまでに接続された頂点のセットを表します。 
3. エッジを重みに基づいてグループに分けて処理します。 等しい重みを持つエッジのグループごとに、次の操作を実行します。 
4. グループ内の各エッジについて、そのエンドポイントが現在の DSU 内の同じコンポーネントに属しているかどうかを確認します。 それらが同じコンポーネント内にある場合、エッジはサイクルを形成し、どの MST にも属せないため、「なし」としてマークします。 
5. エンドポイントが異なるコンポーネント内にある場合は、エッジを暫定的に「少なくとも 1 つ」としてマークします。 これらのエッジは MST に含まれる可能性があります。 
6. この重みグループで「少なくとも 1 つ」とマークされているすべてのエッジについて、ノードが DSU コンポーネント、エッジがさまざまなコンポーネントを接続する現在の重みエッジである一時グラフを作成します。 DFS または Union-find チェックを実行して、この一時グラフ内のどのエッジがブリッジであるかを検出します。 ブリッジであるエッジは、これらのコンポーネントを接続するすべての MST に含まれている必要があるため、そのマークを「any」に更新します。 非ブリッジエッジは「少なくとも 1 つ」のままです。 
7. グループ内のすべてのエッジを分類した後、それらのコンポーネントをメイン DSU にマージします。 これにより、次の重みグループが更新された接続を確認できるようになります。 
8. すべてのエッジが処理されるまで繰り返します。 最後に、元の入力順序で分類を出力します。 

機能する理由: どの段階でも、個別のコンポーネントを接続するエッジが MST 内に存在する可能性があります。 同じ重みのエッジをグループ化することで、複数のエッジが互いに置き換えられる状況を正しく処理します。 ブリッジを識別すると、接続に不可欠なエッジが「任意」としてマークされ、サイクルを形成するエッジは除外されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
from collections import defaultdict

sys.setrecursionlimit(1 << 25)

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0]*n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True

n, m = map(int, input().split())
edges = []
for i in range(m):
    a, b, w = map(int, input().split())
    edges.append((w, a-1, b-1, i))

edges.sort()
res = [None]*m
dsu = DSU(n)
i = 0

while i < m:
    j = i
    group = []
    while j < m and edges[j][0] == edges[i][0]:
        group.append(edges[j])
        j += 1

    temp_graph = defaultdict(list)
    temp_edges = []
    for w, u, v, idx in group:
        u_root = dsu.find(u)
        v_root = dsu.find(v)
        if u_root == v_root:
            res[idx] = "none"
        else:
            res[idx] = "at least one"
            temp_graph[u_root].append((v_root, idx))
            temp_graph[v_root].append((u_root, idx))
            temp_edges.append((u_root, v_root, idx))

    visited = {}
    low = {}
    tin = {}
    timer = [0]

    def dfs(u, parent):
        visited[u] = True
        timer[0] += 1
        tin[u] = low[u] = timer[0]
        for v, idx in temp_graph[u]:
            if v == parent:
                continue
            if v in visited:
                low[u] = min(low[u], tin[v])
            else:
                dfs(v, u)
                low[u] = min(low[u], low[v])
                if low[v] > tin[u]:
                    res[idx] = "any"

    for node in temp_graph:
        if node not in visited:
            dfs(node, -1)

    for w, u, v, idx in group:
        dsu.union(u, v)
    i = j

for r in res:
    print(r)
```このソリューションでは、最初にエッジを並べ替え、DSU を初期化し、重みによってエッジを処理します。 サイクルを形成するエッジを「なし」として分類し、重みグループごとに一時的なグラフを使用して「任意」とマークされたブリッジを検出します。 処理後の DSU マージにより、次のグループの接続が確実に更新されます。
