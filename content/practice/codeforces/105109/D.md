 ## 解決策
 ## 問題の理解

 シーケンスの最初のいくつかの値が与えられます$f(1), f(2), \dots, f(n)$、シーケンスは、以前のすべての値に乗算的に依存する方法で再帰的に定義されます。 いつの日も$x > n$、値$f(x)$前の値から計算されます$n$前の各項を以前の既知の値に応じて累乗した積を使用して値を計算します。 

タスクは計算することです$f(k)$潜在的に巨大なインデックスの場合$k$、 どこ$k$と同じ大きさにすることができます$10^{18}$したがって、シーケンスを直接シミュレートすることはできないことは明らかです。 

それぞれ$f(x)$固定ウィンドウ サイズの乗法反復によって定義されます$n$。 この構造は、シーケンスが任意ではなく、決定論的な線形変換に従って、加法空間ではなく乗法空間で進化することを示唆しています。 

モジュラスは$10^9 + 7$、素数、モジュラー演算による指数操作、および変換された空間での行列のべき乗が関連します。 

主な問題点は、再発が直線的ではないことです。$f(x)$、ただし、対数を法とした後は線形になります。$10^9 + 7$なぜなら、積は和になり、累乗はスカラー倍になるからです。 

重要な制約は、$n \leq 50$、これにより、$O(n^3 \log k)$または$O(n^2 \log k)$行列のべき乗を使用した解。 大きな値$k$これにより、固定次元状態に対する対数時間べき乗アプローチが強制されます。 

微妙なエッジケースが現れるのは、$n = 1$。 その場合、漸化式は自己べき乗方程式に崩壊し、単純な実装は指数の増加とモジュラー指数の入れ子によって失敗することがよくあります。 もう 1 つの特殊なケースは、0 に等しい値を処理することです。 ただし、すべて$f(i) \geq 1$、複雑さがゼロになることを回避し、対数変換を簡素化します。 

## アプローチ

 再帰計算の直接解釈$f(x)$それぞれに$x$まで$k$。 新しいポジションごとに、次のように乗算します。$n$各乗算には整数の指数による累乗が含まれるため、高速な累乗であっても各ステップにコストがかかります$O(n \log M)$、 どこ$M$は係数です。 以上$k$これは不可能な手順です$k$到達する$10^{18}$。 

漸化式を指数空間で書き直すと、構造がより明確になります。 定義しましょう$g(x) = \log f(x)$。 次に、反復は線形反復になります。$$g(x) = \sum_{i=1}^{n} f(i)\, g(x-i)$$ここで重要な点がわかります。再帰係数は固定されており、初期値によって与えられます。$f(i)$。 これにより、問題は次の計算に変わります。$k$順序の線形漸化式の - 番目の項$n$、これは行列のべき乗を使用して解くことができます。 

サイズのベクトルをシフトするコンパニオン行列を構築します$n$、最初の行は係数をエンコードします。$f(i)$、残りの行はシフトを実装します。 この行列をべき乗すると$k-n$計算できるようになります$g(k)$対数時間で。 取得したら$g(k)$、モジュラー算術でべき乗して回復します。$f(k)$。 

重要な洞察は、元の漸化式は乗算的で非線形であるにもかかわらず、指数は線形に進化し、固定次元の線形漸化式はまさに行列のべき乗が効率的に処理できるように設計されているということです。

 ## アルゴリズムのチュートリアル

 漸化式が線形になる指数空間で作業します。 

1.読む$n$、$k$、および初期配列$f(1 \dots n)$。 これらの値は、将来のすべての項がそれらに直接依存するため、システムの遷移係数を定義します。 
2. もし$k \leq n$、 戻る$f(k)$直接。 値はすでに与えられているため、再帰拡張は必要ありません。 
3. サイズの状態ベクトルを構築します$n$最後を代表する$n$変換されたシーケンスの値。 
4. を構築する$n \times n$遷移マトリックス。 最初の行は$[f(1), f(2), \dots, f(n)]$、前の各状態が次の項にどのように寄与するかを指数形式でエンコードします。 下対角は、状態ウィンドウのシフトを実行するための 1 で埋められます。 
5. この行列をべき乗します$k-n$高速累乗を使用します。 このステップでは、繰り返しを繰り返し適用する効果を 1 つの変換に圧縮します。 
6. 結果の行列に初期状態ベクトルを乗算して、次の値に対応する変換値を取得します。$g(k)$。 
7. べき乗モジュラーロジックを使用して指数空間から逆変換し、$f(k) \bmod (10^9+7)$。 

### なぜ効果があるのか

 重要な不変条件は、行列乗算の各ステップの後、結果として得られるベクトルが前のベクトルの正しい線形結合を表すということです。$n$変形した状態。 再発は直線的です$g(x)$したがって、遷移行列のすべてのアプリケーションは、シーケンス進化の 1 つのステップを正確にシミュレートします。 行列のべき乗は、構造を失うことなく同一の線形変換を構成するため、繰り返し適用してもこの正確性が維持されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(A, B):
    n = len(A)
    res = [[0]*n for _ in range(n)]
    for i in range(n):
        for k in range(n):
            if A[i][k]:
                aik = A[i][k]
                for j in range(n):
                    res[i][j] = (res[i][j] + aik * B[k][j]) % MOD
    return res

def mat_pow(M, p):
    n = len(M)
    res = [[0]*n for _ in range(n)]
    for i in range(n):
        res[i][i] = 1
    while p > 0:
        if p & 1:
            res = mat_mul(res, M)
        M = mat_mul(M, M)
        p >>= 1
    return res

def solve():
    n, k = map(int, input().split())
    f = list(map(int, input().split()))

    if k <= n:
        print(f[k-1] % MOD)
        return

    M = [[0]*n for _ in range(n)]
    for j in range(n):
        M[0][j] = f[j] % MOD

    for i in range(1, n):
        M[i][i-1] = 1

    P = mat_pow(M, k - n)

    state = [f[n-1-i] % MOD for i in range(n)]
    ans = 0
    for i in range(n):
        ans = (ans + P[0][i] * state[i]) % MOD

    print(ans)

if __name__ == "__main__":
    solve()
```実装は、線形化された反復と一致する方法で遷移行列を構築します。 最初の行は、次の項が前の項にどのように依存するかをエンコードします。$n$一方、下対角線は状態をシフトして、古い値がベクトルの下に移動するようにします。 

べき乗ステップにより、次からの遷移の実効数が減少します。$k$に$\log k$。 最終的なドット積は、初期状態の寄与を抽出します。$k$-第3期。 

よくある実装上の間違いは、行列の向きと矛盾して状態ベクトルを反転してしまうことです。 インデックスの順序は、遷移行列の定義方法と正確に一致する必要があります。そうでない場合、反復は間違った位置に適用されます。

 ## 特殊なケース

 のために$n = 1$、状態の値が 1 つだけであるため、漸化式は縮退します。そのため、遷移行列は次のようになります。$1 \times 1$。 このアルゴリズムは同じ値の累乗を繰り返すことに帰着し、行列累乗はそれを正しく処理します。これは、行列累乗が単なるスカラー累乗であるためです。 変化する曖昧性がないため、状態ベクトルは一貫したままになります。 

大型用$k$に近い$10^{18}$、べき乗ループは、次のことのみを保証します。$\log k$乗算が実行されます。 アルゴリズムは決して線形に反復しません。$k$したがって、極端な入力であっても、行列二乗ステップの数を除いて小さな入力と同じように動作します。
