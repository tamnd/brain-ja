 ## 解決策
 ## 問題の理解

 小文字の文字列が与えられ、その文字列内で少なくとも 2 回出現する最長の部分文字列の長さを見つけることが課題となります。 繰り返される現象は重複する場合があります。 入力は最大 100 文字の単一の文字列です。 出力は、そのような繰り返し部分文字列の最大長を表す単一の整数です。 

文字列の長さが最大 ​​100 までと小さいため、文字列の長さが 2 次であるアルゴリズムを使用できます。 これにより、部分文字列のすべてのペアを比較するアプローチが実現可能になります。 問題のエッジケースは、部分文字列が繰り返されない、すべての文字が同じ、または部分文字列が正確に重複する状況です。 たとえば、次の文字列`aaaa`長さ 3 の最も長く繰り返される部分文字列があります (`aaa`)、位置 0 ～ 2 および 1 ～ 3 は重複して発生する可能性があります。 単純なアプローチでは、重複しない位置のみを考慮すると、この重複を正しく処理できない可能性があります。 

もう 1 つの微妙なケースは、次のような完全に一意の文字を含む文字列です。`abcd`。 ここで、正解は、`0`部分文字列が繰り返されることはなく、単一の文字も繰り返されないためです。 

## アプローチ

 最も単純なアプローチはブルートフォースです。 入力の考えられるすべての部分文字列を生成し、それぞれが何回出現するかをカウントできます。 各部分文字列について、文字列上でウィンドウをスライドさせ、同じ長さの部分文字列を比較します。 少なくとも 2 回出現する部分文字列が見つかった場合は、その長さを記録し、最大値を更新します。 この方法は、候補となるすべての部分文字列を明示的に検査するので正しいですが、その複雑さは最悪の場合でも O(n³) です。つまり、すべての部分文字列の生成に O(n²)、出現のチェックに O(n) かかります。 n = 100 の場合、これは約 1,000,000 回の操作に相当し、最新の CPU 速度を考慮すると許容範囲内ですが、低速側にあるため、最適化することができます。 

重要な洞察は、すべての部分文字列を個別にチェックする必要がないということです。 代わりに、考えられる長さを降順で反復し、その長さの部分文字列が繰り返されるかどうかを確認できます。 適切な長さが見つかったら、停止できます。 固定長のすべての部分文字列のチェックは、検出された部分文字列を追跡するセットまたは辞書を使用して O(n²) 時間で実行できます。 これにより、全体の複雑さは最悪の場合 O(n³) に軽減されますが、実際には、最も長く繰り返される部分文字列が見つかったらすぐに停止するため、処理速度が速くなります。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n3) | お(1) | n ≤ 100 の場合は受け入れられます |
 | 長さベースのセットチェック | O(n³) 最悪の場合、平均でより高速 | O(n²) | 受け入れられ、実装が簡単になります |

 ## アルゴリズムのチュートリアル

 1. 入力文字列の長さを決定します。`n`。 変数を初期化する`max_len`これにより、これまでに見つかった最長の繰り返し部分文字列の長さが保存されます。 
2. 候補部分文字列の長さのループ`l`1から`n-1`。 長さを確認する必要がありません`n`長さの部分文字列なので`n`は一度しか出現できません。 
3.長さごとに`l`、空のセットを初期化します`seen`。 これは、次の長さのすべての部分文字列を追跡します。`l`私たちは遭遇します。 
4. 一定の長さのウィンドウをスライドさせます`l`文字列をインデックス 0 から`n-l`。 各位置の部分文字列を抽出します。 
5. 部分文字列がすでに存在する場合`seen`、 アップデート`max_len`に`l`もし`l`現在より大きい`max_len`。 この長さの繰り返し部分文字列がすでに見つかっているため、この内側のループから抜け出します。 
6. 部分文字列が含まれていない場合`seen`、セットに追加して続行します。 
7. すべての長さを確認したら、出力します。`max_len`。 

機能する理由: アルゴリズムは、次の不変条件を維持します。`max_len`繰り返される部分文字列が見つかった最大の長さです。 最初に短い部分文字列をチェックすることで、有効な長い部分文字列が見逃されないようにします。 セットを使用すると、重複した部分文字列が効率的に検出されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

s = input().strip()
n = len(s)
max_len = 0

for l in range(1, n):
    seen = set()
    for i in range(n - l + 1):
        sub = s[i:i+l]
        if sub in seen:
            max_len = l
            break
        seen.add(sub)

print(max_len)
```ソリューションは文字列を読み取り、可能な部分文字列の長さを反復します。 内側のループは、スライスを使用して各部分文字列を構築します。 セットを使用すると、チェックごとに平均 O(1) 時間で重複が検出されます。 繰り返される部分文字列が見つかったら内側のループを中断すると、不必要な作業が回避されます。 

## 実用的な例

 のために`abcd`:

 | l | チェックされた部分文字列 | 見たセット | 最大長 |
 | --- | --- | --- | --- |
 | 1 | 'a'、'b'、'c'、'd' | {'a'、'b'、'c'、'd'} | 0 |
 | 2 | 'ab'、'bc'、'cd' | {'ab','bc','cd'} | 0 |
 | 3 | 'abc','bcd' | {'abc','bcd'} | 0 |

 部分文字列の繰り返しがないため、出力は次のようになります。`0`。 

のために`aaaa`:

 | l | チェックされた部分文字列 | 見たセット | 最大長 |
 | --- | --- | --- | --- |
 | 1 | 'a'、'a' | {'a'} | 1 |
 | 2 | 'ああ'、'ああ' | {'ああ'} | 2 |
 | 3 | 'ああ'、'ああ' | {'ああ'} | 3 |

 ここで、最も長く繰り返される部分文字列は次のとおりです。`aaa`重複した出現により、`max_len = 3`。 

## 複雑さの分析

 | 測定 | 複雑さ | 説明 |
 | --- | --- | --- |
 | 時間 | O(n³) 最悪の場合 | 外側のループは長さ O(n)、内側のループは位置 O(n)、部分文字列のスライスは O(n) |
 | スペース | O(n²) | Set は、最悪の場合、長さ n の部分文字列を最大 n 個格納します。 

n ≤ 100 の場合、このソリューションは最大 1,000,000 個の部分文字列チェックを実行し、2 秒の制限内に十分収まります。 メモリ使用量は最小限のままです。 

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    s = input().strip()
    n = len(s)
    max_len = 0
    for l in range(1, n):
        seen = set()
        for i in range(n - l + 1):
            sub = s[i:i+l]
            if sub in seen:
                max_len = l
                break
            seen.add(sub)
    return str(max_len)

# provided samples
assert run("abcd\n") == "0", "sample 1"
assert run("aaaa\n") == "3", "overlapping repeats"

# custom cases
assert run("abcabc\n") == "3", "entire repeated sequence"
assert run("a\n") == "0", "single character string"
assert run("ababab\n") == "4", "overlapping pattern abab"
assert run("abcdefg\n") == "0", "all unique letters"
assert run("aaaaa\n") == "4", "all same letters, max overlap"
```| テスト入力 | 期待される出力 | 検証内容 |
 | --- | --- | --- |
 | ABC | 3 | 文字列の半分に等しい繰り返し部分文字列 |
 | | 0 | 最小入力サイズ |
 | アババブ | 4 | 重複する繰り返し |
 | abcdefg | 0 | 繰り返しはありません |
 | ああああ | 4 | 最大オーバーラップ |

 ## 特殊なケース

 次のような単一文字列`a`生成する`0`部分文字列は繰り返すことができないためです。 このアルゴリズムは、1 から始まる長さを正しく反復し、重複する部分文字列を検出しません。 

のような文字列の場合`aaaaa`、アルゴリズムは、長さが増加する部分文字列をチェックすることにより、重複する繰り返しを見つけます。 正しく検出してくれる`aaaa`最も長く繰り返される部分文字列として、`aaaa`位置 0 ～ 3 および 1 ～ 4 で発生します。 このセットにより、重複が確実に検出され、繰り返しが見つかったらループを中断することで、より長い部分文字列の欠落を回避できます。
