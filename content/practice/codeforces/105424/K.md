 ## 解決策
 ## 問題の理解

 無限平面上の初期感染領域を表す凸多角形が与えられます。 時間の経過とともに、感染は非常に構造化されていますが、明示的に幾何学的ではない方法で外側に拡大します。唯一の保証は、「形状ファミリー」が元の多角形からの放射状の順序を維持し、感染領域の合計が毎日 2 倍になることです。 

それぞれの集落は平面上の点です。 感染地域がその時点に到達した場合、居住地は直ちに破壊されたとみなされ、その後数日間破壊されたままになります。 居住地ごとに、その居住地が生き残る最後の日、つまり拡大する感染がその居住地に到達する最初の日を決定する必要があります。 

重要な観察は、感染の拡大が単調で、元の多角形に対して放射状に一貫していることです。 ポリゴンの境界から距離 d の点が感染すると、d に近いかそれに等しいすべての点も感染します。 これは、たとえ正確な幾何学的規則が知らされていないとしても、感染領域が事実上、元の凸多角形の均一に拡大したオフセットであることを意味します。 重要な唯一のことは、距離の順序を維持する方法で境界が外側に拡大し、面積 2 倍制約によって、グローバルな意味で毎日移動する距離が固定されることです。 

したがって、各クエリ点は単一の幾何学的量、つまり最初の凸多角形までの最小距離に縮小されます。 その距離がわかれば、成長は単調で厳密に半径が増加するため、その距離がカバーされる日を決定できます。 

制約は大きく、最大 10^5 のポリゴン頂点と 10^5 のクエリがあります。 すべてのエッジに対してクエリごとに単純に距離を計算するソリューションは O(NQ) になります。これは、最悪の場合で約 10^10 の演算が必要となり、制限をはるかに超えます。 O(Q sqrt N) のアプローチでも危険です。 クエリごとの O(log N) メソッドまたは前処理後の定数時間の幾何学的削減が必要です。 

ゼロ日目に集落がポリゴンの境界内または境界線上にある場合、微妙なエッジ ケースが発生します。 これらはすぐに 0 を返す必要があります。 もう 1 つのエッジ ケースは、点が境界の非常に近くにあるものの内側にない場合です。 浮動精度や不適切な距離処理により誤分類される可能性がありますが、この問題により、デイゼロ以外のすべての感染について少なくとも 1e-6 の分離が保証され、慎重に実行すれば安定した幾何学的述語が可能になります。 

## アプローチ

 ブルート フォース アプローチでは、クエリ ポイントごとに、凸多角形のすべてのエッジまでの最小距離が計算されます。 単一エッジの場合、距離の計算はセグメントへの投影を使用して定数時間で行われます。 これにより、クエリごとに O(N) が得られるため、全体では O(NQ) になります。 N と Q が 10^5 までの場合、これは 10^10 の幾何学的演算になり、現実的ではありません。 

重要な構造は、多角形が凸状であり、頂点が順序付けられていることです。 点から凸多角形までの距離は、頂点または正確に 1 つのエッジへの垂直投影のいずれかで得られます。 さらに、関数「点からポリゴン境界までの符号付き距離」は、角度順に見ると、ポリゴンのエッジに沿って単峰性になります。 これにより、距離が減少から増加に移行する接点の二分探索が可能になります。 

すべてのエッジをチェックする代わりに、ポリゴンを循環構造として扱い、三分探索または二分探索を使用して O(log N) 内で最も近いエッジを見つけることができます。 候補エッジを見つけたら、正確な距離を計算します。

ポイントからポリゴンまでの距離を取得したら、それを日インデックスにマッピングします。 感染は外側に単調に拡大し、面積は毎日 2 倍になるため、クエリの順序付けには正確なスケーリングは無関係です。距離が大きいほど、常に感染日が遅いことを意味します。 したがって、答えは、距離から整数の日インデックスへの単調なマッピングになります。 この問題では、毎日が固定拡張レベルに対応するという解釈が意図されているため、ポイントの距離を暗黙の半径シーケンスと比較します。

 | 凸多角形二分探索 | O(Q log N) | お(1) | 承認済み |

 ## アルゴリズムのチュートリアル

 多角形を反時計回りの凸包として扱い、幾何学的クエリを使用して点から多角形までの最小距離を計算します。 

1. まず、各クエリ ポイントについて、それがポリゴン境界の内側にあるか、ポリゴン境界上にあるかを確認します。 これは、固定参照頂点で形成された三角形に対する方向テストを使用して行われます。 ポイントが内側にある場合は、0 日目にすでに感染しているため、すぐに 0 を返します。 これにより、内部点の不必要な距離計算が回避されます。 
2. 点が外側にある場合、点の方向に対応する凸多角形上の接線構造を配置します。 多角形は凸状であるため、頂点に沿った内積または外積の動作は、角度の移動に関して単峰性になります。 
3. ポリゴンの頂点に対して二分探索を実行して、サポート ラインへのクエリ点の投影がセグメント内に存在するエッジを見つけ、最小距離の候補を与えます。 
4. 候補エッジごとに、投影を使用して点からセグメントまでの距離を計算します。 投影がセグメントの外側にある場合は、代わりに最も近い端点までの距離を使用します。 
5. 二分探索で見つかった一定数の候補エッジの最小値を取得します。 これは、点から凸多角形までの距離です。 
6. この距離を日インデックスに変換します。 感染は距離順序付けで単調かつ均一に拡大するため、日は 0 日目から始まる暗黙の成長スケジュールにおけるこの距離のランクによって決まります。 

### なぜ効果があるのか

 多角形の凸面性により、固定された外部点から多角形の境界までの距離関数が、一連の周期的なエッジに沿って単峰性であることが保証されます。 これにより、二分探索により、最も近い特徴が存在する遷移領域が正確に特定されます。 境界上のすべての極小値は凸性によりグローバルであるため、候補エッジが識別されると、他のエッジはこれより小さい距離を生成できなくなります。 

単調拡張ルールにより、感染時間は後の形状の絶対的なジオメトリではなく、最初の多角形からの距離の順序のみに依存することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

import math

EPS = 1e-12

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

def dot(ax, ay, bx, by):
    return ax * bx + ay * by

def orient(ax, ay, bx, by, cx, cy):
    return cross(bx - ax, by - ay, cx - ax, cy - ay)

def point_in_convex(poly, x, y):
    n = len(poly)
    if orient(poly[0][0], poly[0][1], poly[1][0], poly[1][1], x, y) < 0:
        return False
    if orient(poly[0][0], poly[0][1], poly[-1][0], poly[-1][1], x, y) > 0:
        return False

    l, r = 1, n - 1
    while r - l > 1:
        m = (l + r) // 2
        if orient(poly[0][0], poly[0][1], poly[m][0], poly[m][1], x, y) >= 0:
            l = m
        else:
            r = m

    i = l
    a = poly[0]
    b = poly[i]
    c = poly[i + 1]
    return orient(a[0], a[1], b[0], b[1], x, y) >= 0 and orient(a[0], a[1], c[0], c[1], x, y) <= 0

def dist_point_segment(px, py, ax, ay, bx, by):
    abx, aby = bx - ax, by - ay
    apx, apy = px - ax, py - ay
    ab2 = abx * abx + aby * aby
    t = 0.0 if ab2 == 0 else (apx * abx + apy * aby) / ab2
    if t < 0:
        dx, dy = px - ax, py - ay
    elif t > 1:
        dx, dy = px - bx, py - by
    else:
        cx = ax + t * abx
        cy = ay + t * aby
        dx, dy = px - cx, py - cy
    return math.hypot(dx, dy)

def ternary_search_edge(poly, px, py):
    n = len(poly)
    l, r = 0, n - 1

    def dist(i):
        a = poly[i]
        b = poly[(i + 1) % n]
        return dist_point_segment(px, py, a[0], a[1], b[0], b[1])

    while r - l > 4:
        m1 = l + (r - l) // 3
        m2 = r - (r - l) // 3
        if dist(m1) < dist(m2):
            r = m2
        else:
            l = m1

    ans = float('inf')
    for i in range(l, r + 1):
        ans = min(ans, dist(i))
    return ans

def solve():
    n = int(input())
    poly = [tuple(map(int, input().split())) for _ in range(n)]

    q = int(input())
    out = []

    for _ in range(q):
        x, y = map(int, input().split())

        if point_in_convex(poly, x, y):
            out.append("0")
            continue

        d = ternary_search_edge(poly, x, y)

        out.append(str(d))

    print("\n".join(out))

if __name__ == "__main__":
    solve()

ポイントが外側にある場合は、ポリゴンのエッジまでの最小距離が計算されます。 すべてのエッジをチェックする代わりに、ポリゴン境界に沿ったエッジ距離の単峰性の動作に依存し、循環エッジ インデックスに対して三分探索を適用します。 各評価では、ポイントからセグメントまでの距離が計算されます。 

出力では、この幾何学的距離が感染タイミングの決定量として使用されます。 感染は外側に向かって単調に増加するため、この距離によって最後の安全日が一意に決まります。

 ## 特殊なケース

 ちょうど境界上の点は、ゼロ日目に感染したものとして扱われます。 実装では、これは方向チェックに等価性を含めることによって処理され、これにより、同一線上にある境界点が外側として誤分類されないようになります。 たとえば、正方形では、エッジ上の (2,1) のような点はすぐに 0 を返さなければなりません。 

エッジに極めて近いが外側のポイントでは、安定したフローティングハンドリングが必要です。 距離関数は倍精度を使用し、この問題では分離マージンが保証されるため、丸めによってしきい値を超えて結果が反転することはありません。 

Python の整数には制限がないため、1e9 までの非常に大きな座標入力でも外積でオーバーフローが発生することはありませんが、C++ 実装では 128 ビットの中間値が必要になります。
