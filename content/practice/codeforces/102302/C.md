 ## 解決策
 ## 問題の理解

 座標平面上には最大 2000 個の異なる点があります。 有効な長方形は、これらの点のうち 4 つをその角として使用する必要があり、その辺は水平または垂直である必要があり、長方形の内部または 4 つの辺の 1 つに他の指定された点があってはなりません。 

タスクは、これらの条件を満たすすべての個別の長方形をカウントすることです。 実際の座標値は (10^9) まで大きくなる可能性がありますが、その絶対サイズは無関係です。 重要なのは、どの座標が等しいか、どの座標が他の座標の間にあるかということです。 

(N \le 2000) では、(O(N^2)) 解が自然なターゲットになります。 順序付けされていないポイントのペアは約 200 万あるため、一定の作業量で各ペアを処理することは可能です。 (O(N^3)) の解では、最悪の場合でもすでに約 (4\cdot10^9) 個の操作が必要になる可能性がありますが、これは 1 秒の制限には多すぎます。 4 点の組み合わせを完全に (O(N^4)) 列挙することはさらに困難です。 (10^9) の座標境界は、元の座標によって直接インデックス付けされたグリッドを割り当てることができないことも意味します。 

最初のエッジ ケースは、ポイントが 4 つ未満であることです。 たとえば、入力`1 / 5 7`には点が 1 つしか含まれていないため、答えは 0 です。すべてのペアが最終的に長方形を定義できると仮定した解決策では、誤って存在しない角にアクセスしようとする可能性があります。 

もう 1 つの特殊なケースは、1 本の垂直線または水平線上に多数の点がある場合です。 例えば4つのポイント`(0,0)`、`(0,1)`、`(0,2)`、`(0,3)`長方形を形成できないため、答えは 0 です。4 つの座標が独立して発生するかどうかを確認するだけでは十分ではありません。4 つの角には 2 つの異なる x 座標と 2 つの異なる y 座標が必要だからです。 

空の状態が微妙な部分です。 考慮する`(0,0)`、`(2,0)`、`(0,2)`、`(2,2)`、`(1,1)`。 4 つの角点は存在しますが、答えは 0 です。`(1,1)`長方形の中にあります。 四隅の存在のみをチェックするソリューションでは、四隅が誤ってカウントされてしまいます。 

境界上の点でも同じ問題が発生します。 と`(0,0)`、`(2,0)`、`(0,2)`、`(2,2)`、`(1,0)`、四隅は存在しますが、答えは再び 0 になります。`(1,0)`下端にあります。 長方形は、閉じた境界ボックス内にその 4 つの隅の点を正確に含む必要があります。 

## アプローチ

 直接的なアプローチは、すべての点のペアを左下隅と右上隅の可能性があると考えることです。 それらの x 座標と y 座標が両方とも異なる場合は、他の 2 つの角がハッシュ セットに存在するかどうかを確認できます。 次に、すべて (N 個) の点をスキャンして、候補の四角形の内側または境界上に点があるかどうかを確認します。 各候補ペアは (O(N)) で処理され、(O(N^3)) 時間がかかります。 (N=2000) の場合、(\binom{2000}{2}=1,999,000) 個のペアがあり、各ペアで 2000 ポイントをスキャンすると、約 (3,998,000,000) ポイントの検査が行われます。 このアプローチは論理的には正しいですが、遅すぎます。 

長方形は左下隅と右上隅によって一意に決定されるため、総当り攻撃が機能します。 コストがかかる部分は、角を特定することではなく、特定の軸に沿った長方形の中に指定された点がいくつあるかを繰り返し尋ねることです。 

重要な観察は、その質問に対する答えが事前に計算できるということです。 座標の相対的な順序のみが重要であるため、すべての個別の x 座標を (1,\ldots,X) に圧縮し、すべての個別の y 座標を (1,\ldots,Y) に圧縮します。 どちらのタイプの異なる座標も最大 (N) 個しかないため、結果として得られるグリッドには最大 (N^2) 個のセルが含まれます。 

占有された圧縮座標ごとに 1 を置き、2 次元のプレフィックスの合計を構築します。 このテーブルが存在すると、標準の包含/除外式を使用して、閉じた四角形内の点の数を (O(1)) 時間で取得できます。 

これで、すべてのポイントのペアを検査できるようになりました。 x 座標で並べ替えた後、y 座標が増加するペアのみが左下隅と右上隅を表すことができます。 他のコーナーが存在するかどうかを確認します。 4 つの角がすべて存在する場合、長方形全体のプレフィックスの合計は正確に 4 でなければなりません。既知の 4 つの角はすでに 4 つの点に寄与しているため、合計が 4 より大きい場合は、追加の点がエッジの内側またはエッジ上にあることを意味します。 

これにより、候補ごとに (N) ポイントをスキャンするという高価な部分が、定数時間のプレフィックス合計クエリに削減されます。 この問題に対する公開参照実装では、同じ座標圧縮と 2 次元のプレフィックス合計戦略を使用します。

 | 最適 | (O(N^2)) | (O(N^2)) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. すべての点を読み取り、それらの個別の X 座標と Y 座標を収集します。 両方の座標リストをソートし、各座標に 1 から始まる圧縮インデックスを割り当てます。圧縮では順序が保持されるため、圧縮前の点は、圧縮された座標が対応する圧縮長方形の内側にあるときと同じように、長方形の内側にあります。 
2. 圧縮された (Y\times X) グリッドを作成し、占有されているすべてのセルに 1 を置きます。 元の座標が近いか (10^9) ほど大きいかに関係なく、グリッドの寸法は最大 (2000\times2000) です。 
3. グリッドを 2 次元のプレフィックスサム配列に変換します。 すべての圧縮セル ((x,y)) について、そのプレフィックス値には、圧縮された座標が最大でも (x) および (y) である入力ポイントの数が格納されます。 角 ((x_1,y_1)) と ((x_2,y_2)) を持つ閉じた長方形内の点の合計は次のようになります。

[
 P(x_2,y_2)-P(x_1-1,y_2)-P(x_2,y_1-1)+P(x_1-1,y_1-1)。 
】
 4. すべての圧縮ポイントをハッシュ セットに保存します。 これにより、必要なコーナーが存在するかどうかを一定の平均時間でチェックできます。 
5. 圧縮されたポイントを x 座標で並べ替え、次に y 座標で並べ替えます。 この順序で点のすべてのペアを検討します。 x 座標が等しいペアを長方形の対角の隅にすることはできません。また、y 座標が増加しないペアを左下隅と右上隅にすることはできません。 
6. 残りのペア ((x_1,y_1))、((x_2,y_2)) について、((x_1,y_2)) が存在するかどうかを確認します。 点 ((x_2,y_1)) はすでに選択された点の 1 つであるため、選択された 2 つの点と ((x_1,y_2)) を合わせると、4 つの角がすべて存在します。 
7. 完全な閉じた長方形のプレフィックスの合計を照会します。 結果が 4 の場合は、長方形を正確に数えます。四隅は 4 つのポイントを提供することが保証されているため、値が大きいほど、内側またはエッジ上に不要なポイントがあることを意味します。 
8. 累積カウントを出力します。 すべての有効な長方形には左下と右上のペアが 1 つだけあるため、それは 1 回だけとみなされます。 

### なぜ効果があるのか

 不変条件は、アルゴリズムによって受け入れられるすべての候補が、その閉じた境界ボックス内に正確に 4 つの指定された点を持ち、それらの 4 つの点が必要な角を形成するということです。 コーナーの存在チェックにより、4 つの頂点が存在することが保証されます。 prefix-sum クエリでは、長方形の内側とその境界上のすべての点がカウントされるため、値がちょうど 4 ということは、そこに 5 番目の点が存在しないことを証明します。 逆に、すべての有効な長方形には、一意の左下隅と右上隅のペアがあります。 このペアが処理されると、他の 2 つの角が検出され、プレフィックスの合計がちょうど 4 になるため、長方形がカウントされます。 したがって、すべての有効な四角形は 1 回カウントされ、無効な四角形はカウントされません。 

## Python ソリューション```python
import sys
from array import array

input = sys.stdin.readline

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    if n < 4:
        print(0)
        return

    xs = sorted({x for x, _ in points})
    ys = sorted({y for _, y in points})

    x_id = {x: i + 1 for i, x in enumerate(xs)}
    y_id = {y: i + 1 for i, y in enumerate(ys)}

    nx = len(xs)
    ny = len(ys)
    width = nx + 1

    # Unsigned short is enough because every prefix sum is at most N <= 2000.
    pref = array('H', [0]) * ((ny + 1) * width)

    compressed = []
    present = set()

    for x, y in points:
        cx = x_id[x]
        cy = y_id[y]
        compressed.append((cx, cy))
        present.add((cx, cy))
        pref[cy * width + cx] = 1

    # Build the 2D prefix sum in-place.
    for y in range(1, ny + 1):
        base = y * width
        previous = base - width
        row_sum = 0

        for x in range(1, nx + 1):
            idx = base + x
            row_sum += pref[idx]
            pref[idx] = pref[previous + x] + row_sum

    compressed.sort()

    answer = 0

    for i in range(n):
        x1, y1 = compressed[i]

        for j in range(i + 1, n):
            x2, y2 = compressed[j]

            # Sorting gives x1 <= x2. Equal x cannot form a rectangle.
            if x1 == x2:
                continue

            # We need the first point to be the bottom-left corner.
            if y1 >= y2:
                continue

            # The missing fourth corner is (x1, y2).
            if (x1, y2) not in present:
                continue

            # Count all points in the closed rectangle.
            total = (
                pref[y2 * width + x2]
                - pref[(y1 - 1) * width + x2]
                - pref[y2 * width + (x1 - 1)]
                + pref[(y1 - 1) * width + (x1 - 1)]
            )

            if total == 4:
                answer += 1

    print(answer)

if __name__ == "__main__":
    solve()
```初期の`n < 4`check は、データ構造を構築せずに最小の入力を処理します。 これは正確さを保つために必須ではありませんが、不必要な作業を回避します。 

座標マップは、元の各座標をコンパクトな整数インデックスに変換します。 x と y を個別に圧縮すると、元の座標範囲を使用するのではなく、接頭辞合計グリッドが最大 (2001\times2001) セルに保持されます。 

プレフィックス配列が使用するのは、`array('H')`Python 整数の代わりに。 プレフィックス値は (N) (最大 2000) を超えることはできないため、符号なしの 16 ビット値で十分です。 これにより、グリッドは最大サイズで約 8 MB に保たれ、メモリ制限の 256 MB を余裕で下回ります。 

プレフィックスの合計は行ごとに構築されます。`row_sum`は、現在の行でこれまでに確認されたポイントの数を表します。`pref[previous + x]`前のすべての行からの寄与が含まれます。 これら 2 つの値を加算すると、標準的な 2 次元のプレフィックスの繰り返しが得られます。 

点は圧縮された x 座標によって並べ替えられます。 すべてのペアについて、等しい x 座標は拒否されます。これは、それらが軸に揃えられた長方形の対角になることができないためです。 の`y1 >= y2`check は方向を 1 つだけ選択するため、同じ四角形が右上と左下のペアから逆に数えられることはありません。 

ハッシュ セットには圧縮された座標ペアが含まれているため、欠けている角をチェックすることで、元の (10^9) スケールの座標への変換を回避できます。 4 つの角がすべて判明すると、プレフィックスの合計にはそれらの 4 つの点が自動的に含まれます。 テスト`total == 4`したがって、内部制限と境界制限の両方を強制するには十分です。 

Python の整数には制限がないため、答えがオーバーフローする危険はありません。 長方形の最大数も最大 (\binom{2000}{4}) であり、これは安全に表現可能です。 

## 実用的な例

 最初のサンプルでは、圧縮後、ポイントはすでに次のように配置されています。`(1,1), (1,2), (2,1), (2,2), (3,1), (3,2)`。

from array import array

def solve_data(inp: str) -> str:
    it = iter(inp.split())
    n = int(next(it))

    points = [(int(next(it)), int(next(it))) for _ in range(n)]

    if n < 4:
        return "0\n"

    xs = sorted({x for x, _ in points})
    ys = sorted({y for _, y in points})

    x_id = {x: i + 1 for i, x in enumerate(xs)}
    y_id = {y: i + 1 for i, y in enumerate(ys)}

    nx = len(xs)
    ny = len(ys)
    width = nx + 1

    pref = array('H', [0]) * ((ny + 1) * width)

    compressed = []
    present = set()

    for x, y in points:
        cx = x_id[x]
        cy = y_id[y]
        compressed.append((cx, cy))
        present.add((cx, cy))
        pref[cy * width + cx] = 1

    for y in range(1, ny + 1):
        base = y * width
        previous = base - width
        row_sum = 0

        for x in range(1, nx + 1):
            idx = base + x
            row_sum += pref[idx]
            pref[idx] = pref[previous + x] + row_sum

    compressed.sort()

    answer = 0

    for i in range(n):
        x1, y1 = compressed[i]

        for j in range(i + 1, n):
            x2, y2 = compressed[j]

            if x1 == x2 or y1 >= y2:
                continue

            if (x1, y2) not in present:
                continue

            total = (
                pref[y2 * width + x2]
                - pref[(y1 - 1) * width + x2]
                - pref[y2 * width + x1 - 1]
                + pref[(y1 - 1) * width + x1 - 1]
            )

            if total == 4:
                answer += 1

    return f"{answer}\n"
