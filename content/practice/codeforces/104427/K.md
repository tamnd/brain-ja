 ## 解決策
 ## 問題の理解

 いくつかのテストケースが与えられています。 各テスト ケースでは、一連の点が水平線上に左から右の順序で配置されます。 各ポイントには色があります。 点のペアを接続する線の上に曲線を描くことができますが、次の 3 つの制約があります。曲線は 2 つの異なる色を接続しなければならない、曲線は内部で交差することは許可されない、曲線は端点で接触することはできますが、内部の点を共有することはできません。 

タスクは、描画できる曲線の数を計算するだけでなく、可能な最大数の曲線を実現する 1 つの有効な構成を明示的に出力することでもあります。 

幾何学的制約は、インデックスのペアがどのように相互作用できるかについての構造的制約に変換されます。 各曲線は 2 つのインデックス間の間隔に対応します。 2 つの曲線は、端点がインターリーブするときに正確にその内部で交差します。つまり、エッジ (i, k) と (j, l) を持つ i < j < k < l のようなパターンを形成するペアを選択することはできません。 ただし、ネストされた間隔が交差しないため、ネストしても問題ありません。 

色に関する制約により、同じ色のすべてのペアが考慮から除外されます。 目標は、有効な非交差間隔の可能な最大のセットを選択することです。 

この制約により、すべてのテスト ケースにわたって最大 200,000 ポイントが許可されます。 すべてのペアをチェックしようとするソリューションは二次的であり、すぐに失敗します。 これにより、各ポイントが一定量の作業のみに参加する、線形または線形に近い構造が求められます。 

微妙な点は、曲線が端点を共有できることです。 これは、単一の点を多くの曲線で使用できることを意味するため、マッチングの問題を解決しているわけではありません。 この区別により、一般的な非交差マッチングよりもはるかに高密度の構造が可能になるため、重要です。 

よくある失敗例は、これを最大一致問題として扱おうとしたことに起因します。 たとえば、1 2 1 2 のようなシーケンスでは、一致するビューは 2 つのペアのみが可能であることを示唆しているかもしれませんが、実際には、交差することなく 4 つの曲線をサイクル状の構造で描くことができます。 主な違いは、使用時に頂点が消費されないことです。 

## アプローチ

 ブルートフォース解釈では、異なる色のすべてのペア (i, j) を考慮し、新しい曲線が以前に追加された曲線と交差するかどうかを確認しながら、それらを貪欲に追加しようとします。 これには、間隔の動的な構造を維持し、すべての候補ペアの互換性をチェックする必要があります。 効率的な間隔チェックを行ったとしても、最悪の場合、考えられるペアは Θ(N^2) 個あり、これは大きすぎます。 

重要な観察は、最適な図面の構造が非常に厳格であるということです。 点が直線上に配置され、交差が禁止されると、最大構成は配列の自然な順序と一致する傾向があります。 特に、有用な曲線は、ほとんどの場合、ローカル隣接関係または単一のグローバル ラップアラウンド接続に対応します。 

任意のペアを選択する代わりに、連続した点の間のエッジに注目を限定することができます。 i と i+1 の間の曲線は、直線上の互いに素なセグメントを占めるため、他の連続する曲線と常に交差しません。 これにより、安全なベースライン構造が即座に得られます。 

すべての有効な連続接続を構築した後も、構造全体が、端におそらく未使用の電位を持つ単一の外側境界を形成していることが観察されます。 最初と最後の点の色が異なる場合は、すべての中間点を囲む大きな外側の円弧でそれらを安全に接続できます。 この外側の円弧は、厳密にすべての円弧の上に位置し、構造全体を囲んでいるため、内部の連続する円弧とは交差しません。 

これにより、問題は、隣接する要素間の純粋にローカルなチェックと 1 つのオプションのグローバル接続に集約されます。

 ## アルゴリズムのチュートリアル

 1. 配列を左から右にトラバースし、点 i と i+1 の隣接する各ペアを検討します。 色が異なる場合は、それらの間に曲線を描きます。 このような各曲線は線上の独自の間隔を占め、別の隣接する間隔の内部と重なることができないため、これは常に安全です。 
2. これらすべての隣接関係ベースの曲線を、答えの基本セットとして保存します。 この段階では、すべての曲線は線分の最小セグメントに対応しており、間隔がばらばらであるため、どの曲線も交差することはできません。 
3. 最初の点と最後の点の色が異なるかどうかを確認します。 存在する場合は、インデックス 1 とインデックス N を接続する追加の曲線を 1 つ追加します。この曲線はすべての中間点の上にあり、区間全体にまたがっているため、以前に追加した隣接する曲線のいずれとも交差しません。 
4. 収集されたすべての曲線を出力します。 

### なぜ効果があるのか

 すべての隣接エッジは、ラインの互いに素なサブセグメントに対応するため、内部交差のない平面構造を形成します。 最初の点から最後の点にまたがる追加の曲線は構成全体を囲むため、内部隣接セグメントを横切ることはできません。 すべての禁止された相互作用は区間の交差であり、私たちの構築では互いに素な区間、または他のすべてを含む単一の外側区間のいずれかのみが作成されるため、幾何学的制約の違反は発生しません。 

最大性は、異なる色のすべての隣接するペアが最適解で使用可能でなければならないという事実から得られます。そのようなペアをスキップすると、他の場所で厳密に優れた非交差構造のための余地を作ることはできません。これらのエンドポイントを含む代替接続は、同じローカル セグメントを再利用するか、隣接するセグメントとの交差を作成することになるからです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        a = list(map(int, input().split()))

        res = []

        # take all adjacent differing-color edges
        for i in range(n - 1):
            if a[i] != a[i + 1]:
                res.append((i + 1, i + 2))

        # optional outer edge
        if a[0] != a[-1]:
            res.append((1, n))

        print(len(res))
        for u, v in res:
            print(u, v)

if __name__ == "__main__":
    solve()
```このソリューションは、テスト ケースごとに 1 回配列をスキャンし、隣接するすべてのペアを異なる色で記録します。 これらのエッジは、安全な非交差ローカル アークに正確に対応します。 その後、エンドポイントをチェックし、場合によっては両端を接続する単一のグローバル アークを追加します。 

すべてのローカル アークが固定された後に外側のアークを追加する必要があるため、操作の順序が重要になります。これにより、構築中にインターリーブされるのではなく、概念的にローカル アークを包み込むようになります。

## テストケース```python
import sys, io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)
    from collections import deque

    input = sys.stdin.readline

    def solve():
        t = int(input())
        out = []
        for _ in range(t):
            n, m = map(int, input().split())
            a = list(map(int, input().split()))
            res = []
            for i in range(n - 1):
                if a[i] != a[i + 1]:
                    res.append((i + 1, i + 2))
            if a[0] != a[-1]:
                res.append((1, n))
            out.append(str(len(res)))
            for u, v in res:
                out.append(f"{u} {v}")
        return "\n".join(out)

    return solve()

 ## 特殊なケース

 重要なエッジ ケースは、すべての隣接するポイントが同じ色を共有する場合です。 この状況では、端点も同じ色を共有するため、隣接エッジは生成されず、外側のエッジも追加されません。 このアルゴリズムはゼロ曲線を正しく出力し、すべての潜在的なペアが無効であるという事実と一致します。 

シーケンスで色が交互になる場合、別の特殊なケースが発生します。 ここでは、すべての隣接するペアが有効であり、構造は最大限に密になります。 オプションの外側エッジも追加され、すべての内部セグメントを包み込むため、交差のない可能な限り最大の構成が生成されます。 

最後の構造上のエッジ ケースは、端点のみが色が異なり、内部は一定である場合です。 この場合、2 つのブロック間の境界に隣接エッジが 1 つだけ表示され、端点が同じ色を共有するため、外側のエッジは追加されず、長い円弧が追加されることはありません。
