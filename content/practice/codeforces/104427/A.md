 ## 解決策
 ## 問題の理解

 サイズのグリッドが与えられています$N \times M$ここで、各セルは黒または白です。 私たちが見るグリッドは必ずしも元の構成であるとは限りません。 代わりに、特殊な操作を複数回適用することによってグリッドが変換された可能性があります。 

操作は次のように行われます。セルを選択すると、その選択したセルと現在同じ色のセルの連結コンポーネント全体が反転されます。 接続性は、標準的な 4 方向、つまり上、下、左、右で定義されます。 

このタスクは、この操作を何度も実行した後に、異なる初期グリッドがいくつあるかを数えることです。各操作では、現在のグリッド内の単色の連結成分全体が反転されます。 答えはモジュロで計算されます$10^9 + 7$。 

主な問題点は、操作がコンポーネント上でグローバルであり、セル上ではローカルではないことです。 ワンタッチで大きな領域を反転でき、その後の操作でコンポーネントを動的に結合または分割できます。 これにより、コンポーネントは反転するたびに進化するため、変換履歴がわかりにくくなります。 

制約$N, M \le 2000$までを暗示$4 \cdot 10^6$したがって、どのような解も線形時間に近いものでなければなりません。 セルまたはコンポーネントのすべてのペアに対する 2 次またはそれより悪いアプローチは不可能です。 

グリッドが均一である場合、微妙なエッジケースが発生します。 たとえば、グリッドがすべて黒の場合、有効な初期状態の数は自明に 1 ではありません。安定しているように見えても、反転操作により多くの代替履歴が作成される可能性があり、これらはさまざまな初期構成に対応します。 もう 1 つのエッジ ケースは、すべてのセルが独自のコンポーネント内で分離されているチェッカー盤のようなグリッドであり、大きな均一領域と比較してフリップの動作が大きく異なります。 

## アプローチ

 ブルートフォース解釈では、考えられるすべての初期グリッドをシミュレートし、それらがターゲット グリッドに変換できるかどうかを確認しようとします。 それは明らかに実行不可能です。$2^{NM}$考えられる初期状態。 対称性や局所的な制約による枝刈りも役に立ちません。これは、この操作が進化するグリッドに依存する接続コンポーネント全体に作用するためです。 

より構造化されたビューが必要です。 初期状態から前向きに考えるのではなく、プロセスを逆にします。 重要な観察は、最終的なグリッドが平面を同じ色の接続されたコンポーネントに分割していることです。 このような各コンポーネントは、ある意味では独立して反転できるユニットのように動作しますが、相互作用はコンポーネント間の境界に沿ってのみ発生します。 

最終的なグリッドをコンポーネントのグラフとして考えてみましょう。 すべての最大単色領域はノードであり、反対色の隣接する領域の間にエッジが存在します。 この操作によりノード全体が反転され、ノードの色が切り替わり、中間状態の隣接ノードとマージされる可能性があります。 ただし、重要な洞察は、可逆構造は、内部の配置ではなく、最終的なグリッド内のコンポーネント間の隣接関係のみに依存するということです。 

各コンポーネントを頂点として見る場合、問題は、このコンポーネント グラフ上の 2 部反転システムの下で有効な割り当てをカウントすることに帰着します。 この操作により、このグラフ内の接続された領域を効果的に切り替えることができ、初期状態の数は、最終的に到達可能な構成空間と一致する初期色を割り当てる方法の数に対応します。 

構造はさらに単純化されます。コンポーネント グラフは、最終状態では常​​に反対の色が隣接しているという意味で 2 部構成になっています。 このグラフの各連結成分は、二部一貫性がある場合、正確に 2 つの自由度に寄与しますが、より一般的には、構造にパリティ制約の矛盾が含まれているかどうかに応じて係数に寄与します。 

最終的な結果は、隣接関係グラフ内の接続コンポーネントをカウントし、コンポーネントごとの寄与を乗算することになります。 各接続コンポーネントは次のいずれかに寄与します。$2$または$1$パリティを固定するエッジ制約サイクルが少なくとも 1 つ含まれているかどうかに応じて異なります。 この問題では、隣接グラフのすべての接続コンポーネントが正確に次の係数に寄与します。$2$、および分離された均一なグリッドがそれに応じて寄与し、コンポーネントのきれいな累乗につながります。 

したがって、答えは次のようになります$2^k \bmod (10^9+7)$、 どこ$k$最終的なグリッド内の同じ色の領域を結合することによって形成される隣接グラフ内の連結コンポーネントの数です。 

これらのコンポーネントは、グリッド上で標準の BFS または DFS を使用して計算され、各セルをノードとして扱いますが、異なる色領域間の遷移は 1 回のみカウントされるようにします。

 ## アルゴリズムのチュートリアル

 1. グリッドを、各セルがその 4 つの隣接セルに接続するグラフとして扱います。 目標は、同じ色のセルの接続されたコンポーネントを識別することです。 
2. グリッド上でフラッド フィル (BFS または DFS) を実行し、各単色の接続コンポーネントを単一ユニットとしてマークします。 この圧縮ステップが必要なのは、操作が個々のセルではなくコンポーネントに作用するためです。 
3. トラバース中に異なる色の間の境界を観察することにより、これらのコンポーネント間に暗黙の隣接構造を構築します。 異なるコンポーネントの 2 つのセルが接触すると、それらのコンポーネントはコンポーネント グラフ内で隣接しているとみなされます。 
4. コンポーネント グラフをスキャンし、この上位レベルのグラフに存在する接続コンポーネントの数を数えます。 これには、コンポーネント代表上に別の BFS/DFS が必要です。 
5. このグラフの各連結成分は、次の乗算係数に寄与します。$2$。 これらの寄与を剰余で乗算します$10^9+7$。 
6. 最終成果物を出力します。 

コンポーネントの接続性に限定する理由は、反転操作では、単色領域間の隣接性によってのみ到達可能性の制約が維持されるためです。 領域内では、すべてのセルはどのような一連の操作でも同じように動作するため、個々のセルを区別する必要はありません。 

### なぜ効果があるのか

 それぞれの単色の接続領域は剛体オブジェクトとして機能します。すべての操作で完全に反転するため、内部構成の違いを個別に観察したり保存したりすることはできません。 組み合わせの自由度の唯一の源は、領域が隣接する領域と比較して「偶数回または奇数回反転される」かどうかによって決まります。 そのパリティの自由度は隣接グラフ全体に伝播し、このグラフの各接続コンポーネントは 1 つの独立した 2 値の選択に寄与します。 操作がコンポーネントに部分的に影響を与えることがないため、この不変条件は安定しており、局所的にパリティ制約が破られることはありません。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**7)

MOD = 10**9 + 7

def solve():
    n, m = map(int, input().split())
    g = [list(input().strip()) for _ in range(n)]

    comp = [[-1] * m for _ in range(n)]
    comps = 0

    from collections import deque

    # Step 1: build monochromatic components
    for i in range(n):
        for j in range(m):
            if comp[i][j] != -1:
                continue
            comps += 1
            q = deque()
            q.append((i, j))
            comp[i][j] = comps - 1
            col = g[i][j]

            while q:
                x, y = q.popleft()
                for dx, dy in ((1,0), (-1,0), (0,1), (0,-1)):
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m:
                        if comp[nx][ny] == -1 and g[nx][ny] == col:
                            comp[nx][ny] = comps - 1
                            q.append((nx, ny))

    # Step 2: build adjacency between components
    adj = [[] for _ in range(comps)]
    seen_edges = set()

    for i in range(n):
        for j in range(m):
            for dx, dy in ((1,0), (0,1)):
                ni, nj = i + dx, j + dy
                if 0 <= ni < n and 0 <= nj < m:
                    a = comp[i][j]
                    b = comp[ni][nj]
                    if a != b:
                        if (a, b) not in seen_edges:
                            adj[a].append(b)
                            adj[b].append(a)
                            seen_edges.add((a, b))
                            seen_edges.add((b, a))

    # Step 3: count connected components in component graph
    vis = [False] * comps
    ans = 1

    for i in range(comps):
        if not vis[i]:
            ans = (ans * 2) % MOD
            q = deque([i])
            vis[i] = True
            while q:
                v = q.popleft()
                for to in adj[v]:
                    if not vis[to]:
                        vis[to] = True
                        q.append(to)

    print(ans)

if __name__ == "__main__":
    solve()
```この解決策は、グリッドを最大の同色の領域に圧縮することから始まります。 これにより、操作は常に接続されたブロック全体に適用されるため、各セルを個別に処理する必要がなくなります。 BFS ラベル付けにより、すべてのセルが正確に 1 つのコンポーネントに属することが保証されます。 

その後、グリッド内で接触する異なるコンポーネント間でのみ隣接関係が構築されます。 セット`seen_edges`グリッドの境界線が複数回スキャンされるため、これは重要なエッジの重複を防ぎます。 

最後に、コンポーネント グラフ上の BFS は、接続されたコンポーネントがいくつ存在するかをカウントします。 新しいコンポーネントに遭遇するたびに、接続された構造ごとの二項自由度を反映して、答えに 2 を掛けます。 

微妙な点は、すべてのセル隣接関係の完全なグラフを明示的に構築する必要がないことです。 コンポーネント間の境界エッジのみが重要であるため、ソリューションは線形に保たれます。

 ## 特殊なケース

 1x1 グリッドには単一のコンポーネントが含まれるため、コンポーネント グラフにはノードが 1 つだけあり、係数 2 に寄与します。アルゴリズムは正しく初期化されます。`comps = 1`、エッジを構築せず、連結成分を 1 つカウントし、次の結果が得られます。$2$。 

次のような完全に均一なグリッドで```
WWWW
WWWW
```すべてのセルが 1 つのコンポーネントに結合されます。 BFS はすべてのセルに同じコンポーネント ID を割り当て、隣接エッジは作成されません。 グラフには 1 つのノードがあり、答え 2 が生成されます。これは、単一の接続された構造が 1 つの 2 値自由度に寄与するという不変条件と一致します。 

市松模様のようなパターンで、```
WB
BW
```すべてのセルが独自のコンポーネントになります。 すべてのセルが反対色の隣接セルと接触するため、隣接グラフはそれらを単一の接続された構造に接続します。 コンポーネント上の BFS では依然として 1 つの接続コンポーネントが生成されるため、答えは 2 のままで、セル レベルでの断片化が上位レベルの接続数に影響を与えないことを示しています。
