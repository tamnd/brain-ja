 ## 問題の理解

 いくつかの独立した石の山が与えられます。 各山は正の数の石から始まり、2 人のプレイヤーが交互に動きます。 ターンでは、プレーヤーはちょうど 1 つの山を選択し、その山のサイズ内に収まる最大の正方形に応じたルールに従ってそこから石を取り除きます。 

パイルがある場合$m$石、計算します$s = \lfloor \sqrt{m} \rfloor$、これは最大の辺の長さです$s \times s$中に収まる正方形$m$。 ルールでは、概念的にこの正方形の構造を残りの石から分離し、プレーヤーがその正方形の一定数の完全な列を削除できるようにすることが説明されています。 移動後、杭は正方形の部分が空になり、削除された列の数に応じて、より小さな正方形の構造のみが残る場合があります。 

すべての山のすべての石が取り除かれるとゲームは終了し、最後の石を取り除いたプレイヤーが勝ちとなります。 タスクは、両方のプレーヤーが最適にプレーしたと仮定して勝者を決定することです。 

制約から得られる重要な観察は、各杭サイズは選択に関して独立しており、杭間の結合は交代によってのみ行われるということです。 これは、ばらばらのコンポーネントよりも Sprague-Grundy 配合を強く示唆しています。 以来$n$あたりまで可能です$10^5$そしてそれぞれ$a_i$と同じ大きさにすることができます$10^9$、動きを明示的にシミュレートしたり、パイルごとにゲームグラフを構築したりするアプローチは不可能です。 パイルごとに手を列挙するだけでもすでに大きすぎます。$m$までを暗示することができます$O(\sqrt{m})$構造的な選択。 

素朴な考えによる微妙な失敗例は、ステートメント内の式に基づいて移動を任意の減算として解釈し、それぞれのステートメントから到達可能なすべての状態をシミュレートしようとすることです。$m$。 たとえば、$m = 10^9$、たとえ単一の山であっても、巨大な遷移グラフが生成されます。 もう 1 つのよくある間違った方向は、ゲームを標準の Nim ヒープとして扱い、各移動が任意の正の整数を削除することです。 これは、二乗分解によって課せられた強力な構造を無視し、不正確なグランディ値をもたらします。 

## アプローチ

 直接的なブルート フォース アプローチでは、各パイルをゲーム グラフ内の状態として扱い、すべての有効な手を列挙することによってそのグランディ値を計算しようとします。 サイズの山の場合$m$、計算するでしょう$s = \lfloor \sqrt{m} \rfloor$、次に、削除する行数について考えられるすべての選択肢を検討し、結果の状態を再帰的に計算します。 スプラーグ・グランディ理論が適用されるため、これは理論的には正しいですが、すぐに実行不可能になります。 各州は次のように分岐する可能性があります。$O(s)$次の州、そしてそれ以来$s$は$O(\sqrt{m})$の場合、すべてのパイルにわたる合計作業量は、中程度の入力であっても爆発的に増加します。 

重要な単純化は、最大の正方形の外側にある山の詳細な残りが将来の決定に影響しないことに気づくことから来ています。 サイズの正方形を分離したら$s \times s$、すべての移動は、行全体を削除することによって有効な正方形のサイズを変更するだけです。 これは、パイルのゲーム状態は次の要素のみに依存することを意味します。$s = \lfloor \sqrt{m} \rfloor$の正確な値ではありません$m$。 

この縮小が行われると、各パイルは事実上、状態が整数であるパイルと等価になります。$s$、そして移動が変形します$s$さらに小さいものに$t < s$行を削除することによって。 これにより、ゲームは非常に単純なテイクダウン構造に崩壊します。$s$、すべての州$0, 1, \dots, s-1$到達可能です。 

これにより、問題は古典的な選択肢減少ゲームのグランディ数の計算に変わり、直接閉じた形式が生成されます。

 ## アルゴリズムのチュートリアル

 各パイルを 1 つの整数に圧縮します。$s = \lfloor \sqrt{a_i} \rfloor$、そのようなそれぞれのグランディ値を計算します。$s$。 

1. 各パイルについて、計算します。$s = \lfloor \sqrt{a_i} \rfloor$。 すべての操作は完全な正方形の行が何行存在するかに依存するため、これは将来の動きに影響を与える山の一部のみをキャプチャします。 
2. 概念的な状態を定義する$G(s)$有効な正方形の辺の長さが次のような杭を表します$s$。 この状態から、移動すると任意の番号を選択できるようになります$k$行の数を減らし、正方形の辺を$s$に$s-k$、 どこ$k \ge 1$。 
3. すべての状態を観察します。$t$と$0 \le t < s$を選択すると、まさに 1 回の移動で到達できます。$k = s - t$。 これにより、トランジションセットが次のようになります。$s$すべての小さい整数に等しい。 
4. グランディ値をボトムアップで計算します。$G(0) = 0$。 それぞれについて$s \ge 1$、到達可能な Grundy 値のセットは正確に$\{G(0), G(1), \dots, G(s-1)\}$。 
5. セットのメキシコ$\{0, 1, \dots, s-1\}$は$s$、 それで$G(s) = s$。 
6. したがって、各山のグランディ値は単純に次のようになります。$s = \lfloor \sqrt{a_i} \rfloor$。 
7. すべての XOR を計算します。$s$価値観。 結果がゼロ以外の場合、最初のプレーヤーが勝利戦略を持っています。 それ以外の場合は、2 番目のプレーヤーが勝ちます。 

核となる不変条件は、縮小後、各パイルがその平方根に等しいサイズを持つ独立した Nim ヒープとして動作することです。 すべての移動がこの値を厳密に減少させ、すべてのより小さい値に到達できるようにするため、Grundy シーケンスは厳密に次のようになります。$G(s)=s$これにより、パイル間の XOR 合成が結果を完全に決定することが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline
import math

def solve():
    n = int(input())
    a = list(map(int, input().split()))
    
    x = 0
    for v in a:
        s = math.isqrt(v)
        x ^= s
    
    if x:
        print("First")
    else:
        print("Second")

if __name__ == "__main__":
    solve()
```実装では、派生したリダクションを直接適用します。 唯一の重要な手順は、整数の平方根を使用することです。これにより、浮動小数点の精度の問題が回避されます。 各パイルは一定時間でそのグランディ寄与に変換され、最終的な XOR によってスプレイグ グランディ理論に従って勝者が決定されます。 

## 実用的な例

 パイルのある入力を考えてみましょう$[3, 8, 15]$。 

それぞれの値について計算します$s = \lfloor \sqrt{a_i} \rfloor$、与える$[1, 2, 3]$。 XOR は段階的に計算されます。 

| パイル | 価値$a_i$|$s = \lfloor \sqrt{a_i} \rfloor$| これまでの XOR |
 | --- | --- | --- | --- |
 | 1 | 3 | 1 | 1 |
 | 2 | 8 | 2 | 3 |
 | 3 | 15 | 3 | 0 |

 最終的な XOR はゼロなので、2 番目のプレーヤーが勝ちます。 これは、最適なプレイの下で杭が完全にバランスしているという直観と一致します。 

ここで考えてみましょう$[1, 4, 9]$。 平方根は$[1, 2, 3]$繰り返しますが、構造を削除すると、各杭がすでに完全な正方形であることがわかり、それぞれが完全に寄与しています。 

| パイル | 価値$a_i$|$s$| これまでの XOR |
 | --- | --- | --- | --- |
 | 1 | 1 | 1 | 1 |
 | 2 | 4 | 2 | 3 |
 | 3 | 9 | 3 | 0 |

 ここでも結果は最初のプレイヤーの負けであり、生の山のサイズではなくグランディ値の対称性が結果を決定することを示しています。

import sys, io

 ## 特殊なケース

 主なエッジケースは、杭がすでに完全な正方形である場合です。 例えば、$m = 16$与える$s = 4$。 この状況では、ゲーム状態は、Nim のような減少選択形式のサイズ 4 の標準ヒープとまったく同じように動作します。 アルゴリズムは引き続き Grundy 値 4 を割り当てるため、特別な分岐を行わずに一貫して処理されます。 

もう一つのエッジケースは、$m = 1$。 ここ$s = 1$、そして唯一の動きは0につながり、孤立した場合は次のプレイヤーにとって負けのポジションになります。 計算によりグランディ値 1 が生成され、これは勝ち位置を正確に反映します。 

大きな値$m = 10^9$また、アルゴリズムは整数の平方根のみを計算するため、安全です。 この構造により、オーバーフローや深い再帰が発生せず、各パイルは一定時間で独立して処理されます。
