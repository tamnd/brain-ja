 ## 解決策
 ## 問題の理解

 スペースで区切られたいくつかの小文字の単語を含む 1 行が与えられます。 Petya の言語のすべての有効な単語は、厳密に 1 つの文法カテゴリと厳密に 1 つの性別に属し、接尾辞によって完全に決定されます。 

法的な接尾辞は 6 つだけです。 

-`lios`男性的な形容詞の場合
 -`liala`女性形容詞の場合
 -`etr`男性名詞の場合
 -`etra`女性名詞の場合
 -`initis`男性動詞の場合
 -`inites`女性動詞の場合

 有効な文は非常に厳格な構造を持っています。 以下が含まれる場合があります:

 - 0 個以上の形容詞、
 - 後に名詞が 1 つだけ続く、
 - 0 個以上の動詞が続きます。 

すべての単語は同じ性別でなければなりません。 

タスクは、入力行全体が正確に 1 つの有効な文を形成しているかどうかを判断することです。 

合計入力サイズは最大でも$10^5$したがって、ソリューションは文字列を線形時間で処理する必要があります。 接頭語を繰り返しスキャンしたり、同じ単語の分類を再計算したりするアプローチは、実際にはおそらく合格するでしょうが、左から右への 1 回のパス以外には何も必要ありません。 きれいな$O(n)$解決策で十分です。 

難しいのはパフォーマンスではなく、文法検証を正確に行うことです。 

簡単な間違いの 1 つは、複数の名詞を含む入力を受け入れることです。 文には名詞が 1 つだけ含まれている必要があります。 

例えば：```
etr etr
```正しい出力は次のとおりです。```
NO
```接尾辞の有効性と性別の一貫性をチェックするだけの不注意な実装は、それを誤って受け入れてしまいます。 

もう 1 つの微妙なケースは注文です。 形容詞は名詞の前に、動詞は名詞の後に来なければなりません。 

例：```
initis etr
```正しい出力は次のとおりです。```
NO
```どちらの単語も男性語であり、単独で有効ですが、動詞は名詞の前に表示されます。 

男女混合も直ちに拒否されなければなりません。 

例：```
lios etra
```形容詞は男性形、名詞は女性形なので、答えは次のようになります。```
NO
```最後のエッジケースは、その単語がその言語に属している限り、単一の単語自体が有効な文であるということです。 

例：```
inites
```これは有効です。なぜなら、動詞が 1 つだけでも文法に適合するからです。形容詞も名詞もゼロですか? いいえ。ステートメントには名詞が 1 つだけ必要ですが、この問題では、文が有効な言語の単語を 1 つだけ使用できることもわかります。 以来`inites`は有効な単語です。答えは次のとおりです。```
YES
```この特別なルールは見落とされがちです。 

## アプローチ

 最も直接的な強引なアプローチは、すべての単語を分類し、名詞として考えられるすべての位置を試すことです。 候補となる名詞の位置ごとに、前の単語がすべて形容詞であり、後の単語がすべて動詞であり、すべての単語が同じ性別であることを検証します。 

あれば$n$つまり、これには以下のことを確認する必要があります$n$名詞の位置を確認し、チェックするたびに文全体を再度スキャンする場合があります。 全体の複雑さは次のようになります。$O(n^2)$。 

と$10^5$文字数が多くても、単語数が多くなる場合もあります。 入力に短い単語が多数含まれている場合、二次関数の動作は不要であり、Python でタイミングの問題が発生する危険性があります。 

重要な観察は、文法が 3 つの品詞間の厳密な順序を定義していることです。```
adjective < noun < verb
```有効な文には名詞が 1 つだけ含まれている必要があり、型の順序が決して減少してはなりません。 

各単語が次のように分類されると、

 - 性別、
 - 文法タイプ、

 問題は単純な線形スキャンになります。 

3 つの条件を同時にチェックしながら、単語を左から右に処理します。 

- すべての単語は言語に属し、
 - すべての性別が一致します。 
- 文法タイプは降順ではなく、名詞を 1 つだけ含みます。 

これにより問題は次のように縮小されます$O(n)$一定の追加メモリを備えた時間。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(n²) | O(n) | 遅すぎる |
 | 最適 | O(n) | O(n) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. 入力行を単語に分割します。 

接尾辞によって言語内での役割が完全に決まるため、各単語を個別に分析する必要があります。 
2. すべての単語について、6 つの法的な接尾辞のいずれかに一致するかどうかを判断します。 

一致する接尾辞がない場合、文全体が直ちに無効になります。 
3. すべての単語を 2 つのプロパティに変換します。 

- 性別: 男性または女性、
 - タイプ: 形容詞、名詞、または動詞。 

型を数値的にエンコードできます。 

- 形容詞 = 0
 - 名詞 = 1
 - 動詞 = 2

 これにより、注文の確認が非常に簡単になります。 
4. 文に単語が 1 つだけ含まれており、その単語が有効な場合は、`"YES"`。 

この問題では、名詞であるかどうかに関係なく、単一の有効な単語が完全な文になることを明示的に許可します。 
5. それ以外の場合は、すべての単語が同じ性別を共有していることを確認します。 

単語が 1 つでも異なる場合は印刷します`"NO"`。 
6. 出現する名詞の数を数えます。 

複数語のステートメントには、名詞を 1 つだけ含める必要があります。 
7. 一連の文法タイプを左から右にスキャンします。 

種類は決して減ってはいけません。 言い換えれば:

 - 形容詞の後には形容詞または名詞が続く場合があります。 
- 名詞の後に動詞が続く場合があります。 
- 動詞の後には動詞のみが続きます。 

小さい型が大きい型の後に出現すると、文法順序が崩れます。 
8. すべてのチェックに合格したら、印刷します。`"YES"`。 

### なぜ効果があるのか

 言語内のすべての有効なステートメントは、まさに次の構造を持っています。```
(adjectives) noun (verbs)
```形容詞、名詞、動詞を次のようにエンコードします`0`、`1`、 そして`2`文法規則を単調条件に変換します。 有効な文は、1 つの名詞を含む非減少シーケンスに正確に対応します。 

性別ルールは独立したグローバルなものであるため、すべての単語が同じ性別を共有していることを確認するだけで十分です。 

文法では、名詞がなくても、個々の有効な単語で文を形成できるため、単一単語の例外は個別に処理されます。 

考えられるすべての無効性がこれらのチェックの 1 つによって検出されるため、アルゴリズムは正しいです。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

def solve():
    words = input().split()

    suffixes = [
        ("lios", "M", 0),
        ("liala", "F", 0),
        ("etr", "M", 1),
        ("etra", "F", 1),
        ("initis", "M", 2),
        ("inites", "F", 2),
    ]

    parsed = []

    for word in words:
        found = False

        for suf, gender, typ in suffixes:
            if word.endswith(suf):
                parsed.append((gender, typ))
                found = True
                break

        if not found:
            print("NO")
            return

    if len(words) == 1:
        print("YES")
        return

    genders = [g for g, _ in parsed]
    types = [t for _, t in parsed]

    if len(set(genders)) != 1:
        print("NO")
        return

    if types.count(1) != 1:
        print("NO")
        return

    for i in range(1, len(types)):
        if types[i] < types[i - 1]:
            print("NO")
            return

    print("YES")

solve()
```実装の最初の部分では、どの接尾辞で終わるかをチェックしてすべての単語を分類します。 サフィックス リストは小さくて固定されているため、単純なループで十分です。 

の`parsed`配列には次のペアが格納されます`(gender, type)`それぞれの言葉ごとに。 型に整数を使用すると、後の順序チェックが簡単になります。 

単一単語の特殊ケースは、名詞の数の検証の前に指定する必要があります。 そうでなければ、次のような言葉`inites`または`lios`名詞ではないため、誤って失敗します。 

性別チェックはセットを使用します。 異なる性別が複数存在する場合、その文は無効になります。 

複数語のステートメントの場合、名詞の数は正確に 1 つである必要があります。 これは、名詞が 2 つある場合や名詞がない場合などを検出します。 

最後に、型シーケンスが決して減少しないことを確認することにより、順序付け条件が検証されます。 これにより、文を形容詞、名詞、動詞のセグメントに明示的に分割することなく、文法構造がコンパクトに適用されます。

import io

def run(inp: str) -> str:
    sys.stdin = io.StringIO(inp)

    input = sys.stdin.readline

    def solve():
        words = input().split()

        suffixes = [
            ("lios", "M", 0),
            ("liala", "F", 0),
            ("etr", "M", 1),
            ("etra", "F", 1),
            ("initis", "M", 2),

                    parsed.append((gender, typ))
                    found = True
                    break

                return "NO"

        if len(words) == 1:

        types = [t for _, t in parsed]

        if len(set(genders)) != 1:
            return "NO"

        if types.count(1) != 1:
            return "NO"

        for i in range(1, len(types)):
            if types[i] < types[i - 1]:
                return "NO"

        return "YES"

    return solve()
