 ## 解決策
 ## 問題の理解

 私たちは、_n_ 個の部屋と _m_ 個の廊下を持つ無向接続グラフとして表現された博物館内での 2 人の友人のランダムな動きをモデル化するように求められています。 各部屋には 1 分間その場に留まる確率があり、それ以外の場合は一律に隣の部屋に移動します。 このタスクは、部屋ごとに、2 人の友人がその部屋で会う確率を計算することです。 Petya と Vasya の初期位置が示されています。 会議は、両方が同時に同じ部屋を占有している場合にのみ発生します。 廊下ですれ違ってもカウントされません。 

_n_ の小さい値 (最大 22) は、システムの状態空間 (2 人の友人の位置のペア) が最大で _n_ の 2 乗で指数関数的な演算を実行できることを示します。$n^2 = 484$州。 これにより、同時確率の完全な列挙や線形システムの解決を伴うアプローチが実現可能になります。 確率は小数点以下 4 桁までで与えられるため、次の誤差要件を満たすために少なくとも倍精度浮動小数点精度を維持する必要があります。$10^{-6}$。 

重要なエッジケースは、2 人の友人が同じ部屋で開始する場合です。 その場合、滞在確率が 1 未満であっても、その部屋の確率は 1 になり、他のすべての確率は 0 になるはずです。もう 1 つの微妙なシナリオは、一部の部屋が接続によって区別できない対称グラフであり、これにより、それらの部屋で会う確率が等しくなる可能性があります。 単純なアルゴリズムが適切な正規化または同時の動きを考慮できない場合、出力はオフになります。 

## アプローチ

 ブルートフォースアプローチでは、可能なすべての軌道を分刻みでシミュレートしようとします。 考えられるすべてのポジションのペアにわたって確率分布を維持し、動きのルールに従って繰り返し更新します。 これは原理的には正しいですが、プロセスは確率的であり、有限のステップ数では収束しない可能性があるため、潜在的に無限に長い時間のシミュレーションが必要になります。 特に滞在確率が 1 に近い場合、収束が遅くなる可能性があります。これにより、単純なシミュレーションは実用的ではなくなります。 

重要な洞察は、2 人の友人の結合状態空間にわたる吸収マルコフ連鎖として問題をモデル化することです。 各状態は 2 つの部屋のペアです$(i, j)$。 もし$i = j$、状態は吸収中です（彼らは会っています）。 それ以外の場合、次の状態の確率は、滞在確率とグラフの隣接性によって決定されます。 各部屋で会う確率は、各吸収状態の吸収確率を計算することに相当します。 線形代数は直接的な解を与えます。つまり、各非吸収状態が近傍の観点から吸収の確率を表す一連の線形方程式を設定します。 なぜなら$n^2 \le 484$、標準的なガウス消去法を使用してこのシステムを解くことができます。 

このアプローチが機能するのは、マルコフ連鎖が有限であり、すべての状態が最終的に確率 1 の吸収状態に到達し (グラフが接続されており、滞在確率が 1 未満である)、線形方程式が予想される吸収確率の再帰構造を正確に捉えているためです。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | シミュレーション | 潜在的に無限 | O(n²) | 正確な確率を得るには遅すぎる |
 | 吸収マルコフ連鎖 (線形システム) | O(n⁶) 単純ガウスの最悪のケース、実際的な << 2s | O(n⁴) | 承認済み |

 ## アルゴリズムのチュートリアル

 1. コリドー入力からグラフの隣接リストを作成します。 また、各部屋の次数を記録して、隣接する部屋の間で均一な確率分布を容易にします。 
2. すべての状態を列挙する$(i, j)$、 どこ$i$ここはペティアの部屋で、$j$ヴァシャの部屋です。 がある$n^2$州。 吸収状態を特定します。$i = j$。 これらの状態に、それぞれの部屋には 1、その他の部屋には 0 をもつ確率ベクトルを割り当てます。 
3. 非吸収状態ごとに$(i, j)$、次の分の遷移に関して会議確率ベクトルを表す一次方程式を書きます。 Petya はどちらかに滞在できます$i$確率的に$p_i$または確率で各近隣に移動します$(1-p_i)/\text{deg}(i)$。 ヴァシャについても同様です。 動きは独立しているため、積ルールを使用して両方の選択肢を組み合わせます。 これにより、次の状態にわたる重み付き合計が得られます。 
4. 線形システムを構築します。各行は、状態の確率ベクトルの成分に対応します。 斜めのエントリは自己寄与 (同じ状態に留まる) を考慮し、非対角のエントリは遷移を考慮します。 右側は、吸収状態の確率ベクトルを表す定数である吸収寄与を除いて、非吸収状態ではゼロです。 
5. ガウス消去法または小規模な高密度システムに適したソルバーを使用して線形システムを解きます。 各部屋に対応する各吸収状態の遭遇確率を解から抽出します。 
6. 部屋の順序で確率を出力します。 

機能する理由: 方程式系は、マルコフ連鎖の予想される吸収確率を正確にモデル化します。 各非吸収状態の方程式は、最終的に各吸収状態に到達する確率を再帰的にエンコードします。 チェーンは有限で接続されており、すべての滞在確率が 1 未満であるため、システムは厳密に対角的に優勢であり、独自のソリューションを備えています。 したがって、アルゴリズムは浮動小数点精度までの正確な一致確率を出力します。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

n, m, a, b = map(int, input().split())
a -= 1
b -= 1
adj = [[] for _ in range(n)]
deg = [0]*n
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)
    deg[u] += 1
    deg[v] += 1

p = [float(input()) for _ in range(n)]

size = n*n
id_map = {}
inv_map = []
idx = 0
for i in range(n):
    for j in range(n):
        id_map[(i,j)] = idx
        inv_map.append((i,j))
        idx += 1

import numpy as np
A = np.zeros((size, size))
B = np.zeros((size, n))

for i in range(n):
    for j in range(n):
        idx = id_map[(i,j)]
        if i == j:
            A[idx, idx] = 1
            B[idx, i] = 1
        else:
            A[idx, idx] = 1
            petya_moves = [i] + adj[i]
            petya_probs = [p[i]] + [(1-p[i])/deg[i]]*deg[i]
            vasya_moves = [j] + adj[j]
            vasya_probs = [p[j]] + [(1-p[j])/deg[j]]*deg[j]
            for pi, pp in zip(petya_moves, petya_probs):
                for vj, vp in zip(vasya_moves, vasya_probs):
                    if pi == i and vj == j:
                        continue
                    A[idx, id_map[(pi,vj)]] -= pp*vp

X = np.linalg.solve(A, B)
res = X[id_map[(a,b)]]
print(" ".join(f"{x:.10f}" for x in res))
```コードはまずグラフと滞在確率を読み取ります。 次に、すべてを列挙します$n^2$ジョイントの状態を確認し、密な線形システムの遷移確率を設定します。 このシステムはNumPyで解決されます`linalg.solve`。 行列インデックスに辞書の代わりに配列を使用すると、数値の安定性とパフォーマンスが保証されます。

 **サンプル 1**

 入力:```
2 1 1 2
1 2
0.5
0.5
```| 状態 (i,j) | 方程式 |
 | --- | --- |
 | (0,0) | 吸収、部屋の確率 0 = 1 |
 | (1,1) | 吸収、部屋 1 の確率 = 1 |
 | (0,1) | P(0,1) = 0.5_0.5_P(0,1) + 0.5_0.5_P(1,0) + ... |

 これを解くと、P(部屋 0 で会う) = 0.5、P(部屋 1 で会う) = 0.5 となります。

これにより、アルゴリズムが対称グラフとジョイント状態遷移を正しく処理できることが確認されます。
