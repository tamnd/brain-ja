 ## 解決策
 ## 問題の理解

 私たちに与えられているのは、$n \times n$グリッド。各セルは削除可能または削除できない場合があります。 入力では、削除可能なセルを 1 で指定し、削除不可能なセルを 0 で指定します。タスクは正確に削除することです。$(n-k+1)^2$配列が存在しないようなセル$k$残りのセルは厳密に増加する対角パターンを形成します。 各ステップで行インデックスと列インデックスの両方が増加する場合、シーケンスは厳密に増加しています。 

各テスト ケースは次のように指定します$n$、グリッド、および整数$k$。 出力では、削除が適用された有効なグリッド構成が提供されるか、構成が存在しない場合は「NO」がレポートされる必要があります。 

制約は厳しいです。$n^2$すべてのテストケースで次を超えない$10^6$、 そして$n$それ自体は 1000 に達する可能性があります。これは、$O(n^3)$解決が遅すぎますが、$O(n^2)$テストケースごとに許容されます。 エッジ ケースには、対角線が削除できないシナリオが含まれます。たとえば、次のような場合です。$k = n$主対角線に沿ったすべてのセルは 0 であり、その対角線上のセルは削除できず、長さが厳密に増加するシーケンスになります。$n$常に存在します。 

別の微妙なシナリオが発生するのは、$k=2$: 欠失パターンでは、単一の 2 長さ増加ペアがどこにでも作成されることを回避する必要があるため、対角線または反対角線に沿った欠失の分布が重要になります。 を尊重しない不注意な実装$(n-k+1)^2$削除数を増やしたり、間違った順序で貪欲な削除を試みたりすると失敗します。 

## アプローチ

 ブルート フォース アプローチでは、次のサイズの削除可能なセルのすべてのサブセットが試行されます。$(n-k+1)^2$禁止されている長さの増加シーケンスを確認します$k$。 シーケンスをチェックするには、残りのセルのすべての組み合わせを反復する必要があり、これは指数関数的です。$k$そして$n$。 これは明らかに不可能になります$n \ge 10$。 

重要な観察は、長さが厳密に増加するシーケンスであるということです。$k$十分な長さの対角線に沿ってのみ存在できます。 各セルは次の特徴を持つ対角線上にあります。$i+j$。 左上隅から開始して連続する対角線のブロックに沿ってセルを削除することで、一連の長さの増加を防ぐことができます。$k$。 具体的には、左上の部分を削除すると、$(n-k+1) \times (n-k+1)$正方形の場合、残りのシーケンスはすべてブロックされます。この削除されたブロックで始まる候補シーケンスはすべて無効であり、外側のシーケンスは短すぎて長さに達しません。$k$。 

したがって、次のことを実装できます。$O(n^2)$貪欲な構築。 左上隅から昇順に対角線を繰り返します。$i+j$許可されており、削除が残っている場合はセルを削除します。 まさにそれまで続けます$(n-k+1)^2$削除が行われます。 最終的に削除数が足りない場合は問題は発生しません。 それ以外の場合は、結果のグリッドを出力します。 

| アプローチ | 時間計算量 | 空間の複雑さ | 評決 |
 | --- | --- | --- | --- |
 | ブルートフォース | O(2^(n^2) * n^k) | O(n^2) | 遅すぎる |
 | 最適 | O(n^2) | O(n^2) | 承認済み |

 ## アルゴリズムのチュートリアル

 1.読む$t$、テストケースの数。 
2. 各テスト ケースについて、次の内容を読んでください。$n$そして$k$、次にグリッドを整数の 2D 配列に読み取ります。 
3.初期化`remaining_deletions = (n-k+1)^2`。 
4. すべての対角線を次の順序で繰り返します。$i+j$0から$2n-2$。 対角線ごとに、すべてのセルを反復処理します。`(i, j)`満足のいく`i+j = diag_index`。 
5. もし`remaining_deletions > 0`そして細胞`(i,j)`削除可能 (値 1) の場合は削除し (0 に設定)、デクリメントします`remaining_deletions`。 
6. すべての対角線を処理した後、次のことを確認します。`remaining_deletions == 0`。 そうでない場合は、「NO」を出力します。 
7. 成功した場合は、「YES」を出力し、結果のグリッドを各行の 0 と 1 の文字列として出力します。 

これが機能する理由は、長さが厳密に増加するシーケンスはすべて、$k$少なくとも必要です$k$対角線。 左上を削除すると$(n-k+1)^2$セルでは、長さのすべての対角線をブロックします$k$それ以上になると、禁止されたシーケンスを見つけることができなくなります。 対角的に反復することで、削除を効率的に使用し、必要な数のセルを正確に削除するという不変条件が維持されることが保証されます。 

## Python ソリューション```python
import sys
input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, k = map(int, input().split())
    grid = [list(map(int, list(input().strip()))) for _ in range(n)]
    
    to_delete = (n - k + 1) ** 2
    deleted = 0
    
    for diag in range(2 * n - 1):
        for i in range(n):
            j = diag - i
            if 0 <= j < n and grid[i][j] == 1 and deleted < to_delete:
                grid[i][j] = 0
                deleted += 1
    
    if deleted < to_delete:
        print("NO")
    else:
        print("YES")
        for row in grid:
            print("".join(map(str, row)))
```コードは、次を使用して入力を効率的に読み取ります。`sys.stdin.readline`そして整数リストのリストとしてグリッドを構築します。 削除ループは斜めに反復され、セルが許可され、まだ削除が必要な場合にのみ削除されます。 境界チェック`0 <= j < n`これにより、各対角線に沿った有効なセルのみにアクセスできるようになります。 削除パスの後、正確な削除数が適用されたかどうかを確認します。 最終出力では、グリッドが必要な形式で印刷されます。
