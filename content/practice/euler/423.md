[プロジェクト オイラー問題 423](https://projecteuler.net/problem=423)

 ## 解決策

 **答え:**`653972374`させて$$C(n)=\#\{\text{length-}n\text{ die sequences with }c\le \pi(n)\},$$どこ$c$隣接する等しいペアの数です。 

計算しなければなりません$$S(50\,000\,000)=\sum_{n=1}^{50\,000\,000} C(n) \pmod{1\,000\,000\,007}.$$---

 #1. 数学的分析

 ## 正確にシーケンスをカウントする$k$等しい隣接関係

 長さのシーケンス$n$もっている$n-1$隣接するギャップ。 

正確に仮定してください$k$それらのギャップは等しい。 

- を選択してください$k$等間隔:$$\binom{n-1}{k}.$$- 最初のサイコロの値を選択します。$$6.$$- 不均等なギャップはすべて変化を強制し、$5$それぞれの選択肢。 

がある$n-1-k$そういったギャップ。 

したがって、次のようになります。$$\boxed{ N(n,k)=6\binom{n-1}{k}5^{\,n-1-k} }$$したがって$$\boxed{ C(n)=6\sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k} }$$これにより、次のことがすぐに確認されます。$$C(4)=6\left(5^3+3\cdot 5^2+3\cdot 5\right)=1290.$$---

 #2. 早い再発

 定義する$$D(n)=\frac{C(n)}{6} = \sum_{k=0}^{\pi(n)} \binom{n-1}{k}5^{\,n-1-k}.$$また定義します$$p=\pi(n), \qquad B_n=\binom{n-1}{p}5^{\,n-1-p}.$$---

 ## 複合トランジション

 もし$n+1$複合である場合、$\pi(n+1)=p$。 

パスカルの使用:$$\binom{n}{k}=\binom{n-1}{k}+\binom{n-1}{k-1}.$$それから$$D(n+1) = 6D(n)-B_n.$$したがって$$\boxed{ C(n+1)=6C(n)-6B_n }$$---

 ## プライム移行

 もし$n+1$が素数であれば、$\pi(n+1)=p+1$。 

新しい合計の上限により、追加の項が 1 つ追加されます。$$D(n+1) = 6D(n) + \binom{n-1}{p+1}5^{\,n-1-p}.$$使用する$$\binom{n-1}{p+1} = \binom{n-1}{p}\frac{n-1-p}{p+1},$$私たちは得る$$\boxed{ C(n+1) = 6C(n) + 6B_n\frac{n-1-p}{p+1} }$$---

 #3. アップデートする$B_n$再発も必要です$B_n$。 

- -

＃＃ もし$n+1$複合です

 それから$p$固定されたままです:$$B_{n+1} = \binom{n}{p}5^{n-p} = B_n\cdot \frac{5n}{n-p}.$$それで$$\boxed{ B_{n+1}=B_n\frac{5n}{n-p} }$$- -

＃＃ もし$n+1$プライムです

 それから$p\to p+1$:$$B_{n+1} = \binom{n}{p+1}5^{\,n-1-p} = B_n\frac{n}{p+1}.$$したがって、$$\boxed{ B_{n+1}=B_n\frac{n}{p+1} }$$---

 #4. 複雑さ

 すべてが$O(L)$ステップごとに一定の作業のみを行うループ。 

素数をふるいにかけます$50\,000\,000$、モジュラー逆行列を事前計算し、1 回反復します。 

これは、最適化された C++ で数秒以内に簡単に実行されます。 

---

 #5. Pythonの実装```python
MOD = 1_000_000_007
L = 50_000_000

# ---------- sieve ----------
is_prime = bytearray(b"\x01") * (L + 1)
is_prime[0] = is_prime[1] = 0

p = 2
while p * p <= L:
    if is_prime[p]:
        step = p
        start = p * p
        is_prime[start:L + 1:step] = b"\x00" * (((L - start) // step) + 1)
    p += 1

# ---------- modular inverses ----------
inv = [0] * (L + 1)
inv[1] = 1

for i in range(2, L + 1):
    inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

# ---------- recurrence ----------
# C(1) = 6
C = 6

# B_1 = binom(0,0) * 5^0 = 1
B = 1

S = 6
pi_n = 0

for n in range(1, L):

    if is_prime[n + 1]:
        # prime transition

        extra = (
            6
            * B
            % MOD
            * (n - 1 - pi_n)
            % MOD
            * inv[pi_n + 1]
        ) % MOD

        C = (6 * C + extra) % MOD

        pi_n += 1

        B = B * n % MOD * inv[pi_n] % MOD

    else:
        # composite transition

        C = (6 * C - 6 * B) % MOD

        B = (
            B
            * 5
            % MOD
            * n
            % MOD
            * inv[n - pi_n]
        ) % MOD

    S += C
    S %= MOD

print(S)
```---

 #6. コードのチュートリアル

 ### プライムふるい

 以下のすべての整数の素数を計算します。$50\,000\,000$。 

これにより、次のことがわかります。$\pi(n)$ステップごとに増加します。 

---

 ### モジュラーインバース

 漸化式は次のような数値で除算されます。$p+1$そして$n-p$。 

使用方法:$$\text{inv}[i] = -(M//i)\cdot \text{inv}[M\bmod i] \pmod M$$すべての逆数を線形時間で事前計算します。 

---

 ### メインループ

 私たちは以下を維持します:

 -`C = C(n)`-`B = B_n`-`pi_n = π(n)`各ステップで:

 - もし$n+1$素数です:

 素数再帰を使用し、
 - それ以外の場合:

 複合反復を使用します。 

に蓄積します`S`。
