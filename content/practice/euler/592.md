[プロジェクト オイラー問題 592](https://projecteuler.net/problem=592)

 ## 解決策

 **答え:**`13415DF2BE9C`させて$$M = 20! = 2432902008176640000.$$次の 16 進数の最後の 12 桁が必要です$M!$末尾の 16 進数のゼロの前。 

末尾の 16 進数のゼロは、次の係数に対応します。$16=2^4$。 

それで、もし$$v_2(M!)=\sum_{k\ge1}\left\lfloor \frac{M}{2^k}\right\rfloor,$$この場合、末尾の 16 進数のゼロの数は次のようになります。$$\left\lfloor \frac{v_2(M!)}{4}\right\rfloor.$$したがって、計算します$$\frac{M!}{16^{\lfloor v_2(M!)/4\rfloor}} \pmod{16^{12}}.$$同等の作業モジュロ$$16^{12}=2^{48},$$すべての要素を取り除きます$2$階乗積から残りの奇数部分を剰余として保持します$2^{48}$、最後に残った電力を回復します$2^{v_2(M!)\bmod 4}$。 

これを効率的に行う方法は、2 の累乗を法とする標準的な再帰的奇階乗アルゴリズムです。$$G(n)=\frac{n!}{2^{v_2(n!)}},$$再帰あり$$G(n)=G\!\left(\left\lfloor \frac n2\right\rfloor\right)\cdot \prod_{\substack{1\le k\le n\\ k\text{ odd}}}k \pmod{2^{48}}.$$奇数剰余の周期性を法として使用する$2^{48}$、これは減少します$O(\log n)$再帰の深さ。 

クリーンな Python 実装は次のとおりです。```python
from functools import cache
from math import factorial

MOD = 1 << 48
N = factorial(20)

def v2_factorial(n):
    s = 0
    while n:
        n //= 2
        s += n
    return s

@cache
def odd_fact(n):
    if n == 0:
        return 1

    # recursive odd-part reduction
    res = odd_fact(n // 2)

    # multiply odd terms
    p = 1
    for k in range(1, n + 1, 2):
        p = (p * k) % MOD

    return (res * p) % MOD

v2 = v2_factorial(N)

# odd part
g = odd_fact(N)

# restore remaining twos after removing hexadecimal zeros
g = (g * pow(2, v2 % 4, MOD)) % MOD

answer = f"{g:012X}"
print(answer)
```サンプルの場合:```python
20! = 21C3677C82B40000 (hex)
```末尾の 4 つの 16 進数のゼロを削除すると、次のようになります。```python
21C3677C82B4
```これはステートメントと一致します。
