[プロジェクト オイラー問題 473](https://projecteuler.net/problem=473)

 ## 解決策

 **答え:**`35856681704365`させて$$\varphi=\frac{1+\sqrt5}{2},\qquad \varphi^2=\varphi+1.$$すべての正の整数は、次の累乗を使用した一意の有限表現を持ちます。$\varphi$連続した指数は使用されません。 

回文フィジタル表現の場合、数字列は次の条件を満たす必要があります。$$d_i=d_{-i-1}.$$したがって、すべての回文値は次の形式になります。$$N=\sum_{i\ge0} d_i\left(\varphi^i+\varphi^{-i-1}\right).$$定義する$$T_i=\varphi^i+\varphi^{-i-1}.$$標準アイデンティティの使用$$\varphi^n=\frac{L_n+F_n\sqrt5}{2},$$（どこ$F_n$そして$L_n$はフィボナッチ数とルーカス数です)、次のことがわかります。 

-$T_1=2$はすでに整数です、
 - のために$k\ge1$、$$T_{2k}=\frac{a_k+b_k\sqrt5}{2},\qquad T_{2k+3}=\frac{c_k-b_k\sqrt5}{2},$$したがって、不合理な部分はペアの **のみ** キャンセルされます$$T_{2k}+T_{2k+3}.$$これらの整数ブロックは、$$14,36,94,246,644,\dots$$そして回帰式を満たす$$B_n=3B_{n-1}-B_{n-2},$$と$B_1=14,\ B_2=36$。 

元の表現では連続する指数が禁止されているため、これらのブロックを隣接させることはできません。 実際、選択したブロックは少なくとも 2 つの未使用ブロックで区切られている必要があります。 

したがって、すべての回文フィジタル整数は次から得られます。 

- オプションで分離された値を追加します$2$、
 - 競合しないブロックの合計を加えたもの$B_n$。 

小さなケース（$\le1000$) を与えます$$1,2,14,36,38,94,96,246,248,260,644,646,658,680,682$$確かにその合計は何ですか$$4345.$$---

 ## Pythonの実装```python
LIMIT = 10**10

# Generate the integer blocks:
# 14, 36, 94, 246, ...
blocks = [14, 36]
while True:
    nxt = 3 * blocks[-1] - blocks[-2]
    if nxt > LIMIT:
        break
    blocks.append(nxt)

# Generate all valid sums of blocks.
# If block i is used, then i+1 and i+2 are forbidden.
base_sums = set()

def dfs(start, total):
    base_sums.add(total)

    for i in range(start, len(blocks)):
        dfs(i + 3, total + blocks[i])

dfs(0, 0)

# Build the final set of palindromic phigital integers.
vals = set(base_sums)

# Optional isolated value 2.
# It conflicts only with the first block (14),
# so we only combine it with sums generated from blocks[1:].
with_two = set()

def dfs_two(start, total):
    with_two.add(total)

    for i in range(start, len(blocks)):
        dfs_two(i + 3, total + blocks[i])

dfs_two(1, 2)

vals |= with_two

# The special one-digit palindrome "1"
vals.add(1)

answer = sum(v for v in vals if v <= LIMIT)

print(answer)
```---
