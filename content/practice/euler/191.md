 ## 解決策

 **答え:**`1918080160`有効な (「賞品」) 出席文字列の長さを指定します。$n$を満たす：

 - 3回連続不可$A$さんの、
 - 多くても 1 つ$L$。 

このような文字列を数えなければなりません$n=30$。

 # ステップ 1 — 問題を再定式化する

 毎日は次のようになります。 

-$O$= 時間通りに、
 -$A$= 欠席、
 -$L$=遅い。 

制約は次のとおりです。 

1. 部分文字列なし$AAA$、
 2. 最大 1 つ$L$。 

これは古典的な有限状態動的計画法の問題です。 

それを解決するきれいな方法は次のとおりです。 

- 最初に **no を含む文字列をカウントします$L$**、
 - 次に、正確に 1 つを挿入します$L$。 

---

 # ステップ 2 — なしの文字列を数える$L$定義する：$$f(n)=\text{number of length-}n\text{ strings using only }O,A$$3連続なし$A$さんの。 

漸化式を導き出します。 

有効な長さの文字列$n$次のいずれかで終わる必要があります:

 -$O$、
 -$AO$、
 -$AAO$、
 - またはおそらくすべて$A$十分に短い場合は。 

より体系的に:

 文字列が次で終わる場合:

 -$O$: 前の部分が貢献します$f(n-1)$、
 -$AO$: 前の部分が貢献します$f(n-2)$、
 -$AAO$: 前の部分が貢献します$f(n-3)$。 

したがって、$n\ge3$、$$f(n)=f(n-1)+f(n-2)+f(n-3).$$これがトリボナッチ回帰です。 

初期値:$$f(0)=1$$(空の文字列)$$f(1)=2$$($O,A$)$$f(2)=4$$($OO,OA,AO,AA$）

それで：$$f(3)=4+2+1=7.$$確かに、無効な長さ 3 の文字列は次のとおりです。$AAA$。 

---

 # ステップ 3 — シングルの紹介$L$賞品の文字列を最大 1 つまでカウントするようになりました$L$。 

2 つのケース:

 ---

 ## ケース 1: いいえ$L$単純に次のようなものがあります。$$f(30)$$そのような文字列。 

---

 ## ケース 2: 1 つだけ$L$を配置します。$L$位置で$k$($1\le k\le 30$）。 

次に:

 - 左側には長さがあります$k-1$、
 - 右側には長さがあります$30-k$、

 そして両側は独立して有効です。$L$文字列。 

したがって、カウントは次のようになります。$$\sum_{k=1}^{30} f(k-1)f(30-k).$$したがって、賞品文字列の総数は次のようになります。$$P(30)=f(30)+\sum_{k=1}^{30} f(k-1)f(30-k).$$同様に:$$P(30)=f(30)+\sum_{i=0}^{29} f(i)f(29-i).$$---

 # ステップ 4 — Python の実装```python
def prize_strings(n):
    # f[i] = number of valid strings of length i
    # using only O and A, with no AAA
    f = [0] * (n + 1)

    # Base cases
    f[0] = 1
    if n >= 1:
        f[1] = 2
    if n >= 2:
        f[2] = 4

    # Tribonacci recurrence
    for i in range(3, n + 1):
        f[i] = f[i - 1] + f[i - 2] + f[i - 3]

    # Case 1: no L
    total = f[n]

    # Case 2: exactly one L
    for i in range(n):
        total += f[i] * f[n - 1 - i]

    return total

# Verify the example in the problem
print(prize_strings(4))   # should be 43

# Compute the required answer
print(prize_strings(30))
```---
