[プロジェクト オイラー問題 160](https://projecteuler.net/problem=160)

 ## 解決策

 **答え:**`16576`次のゼロ以外の最後の 5 桁を探します。$$N! \quad \text{with } N=10^{12}.$$定義する$f(N)$末尾のゼロの前の最後の 5 桁として$N!$。 

The problem is therefore:$$f(10^{12}).$$---

 #1. 数学的分析

 Trailing zeroes come from factors of$10=2\cdot5$。 

階乗には 5 よりも 2 が多く含まれるため、末尾のゼロの数は正確に 5 の指数になります。$N!$:$$v_5(N!)=\sum_{k\ge1}\left\lfloor \frac{N}{5^k}\right\rfloor.$$すべての要素を取り除いてみると、$10$、残るのは$$\frac{N!}{10^{v_5(N!)}} = \frac{N!}{2^{v_5(N!)}5^{v_5(N!)}} = 2^{v_2(N!)-v_5(N!)} \cdot \prod_{m\le N,\;5\nmid m} m.$$このモジュロだけが必要です$10^5=100000$。 

2 のべき乗は可逆剰余ではないため$10^5$、モジュロで動作するのが標準です$$2^5=32 \qquad\text{and}\qquad 5^5=3125,$$その後、CRT 経由で結合します。 

---

 ## ステップ 1: 各用語からすべての 2 と 5 を削除します

 定義する$$g(n)=\prod_{k=1}^n \frac{k}{2^{v_2(k)}5^{v_5(k)}},$$つまり、2 と 5 をすべて取り除いた後の「縮小」部分の積です。 

それから$$f(n)\equiv g(n)\cdot 2^{v_2(n!)-v_5(n!)} \pmod{100000}.$$したがって、問題はコンピューティングになります。 

1. 2 の余剰電力、
 2. 還元された製品$g(n)$。 

---

 # 2. モジュロ構造体$10^5$重要な観察点は周期性です。 

10 を法とする数値を考慮します$10^5$。 

それらはサイズの乗法的なグループを形成します$$\varphi(100000)=40000.$$係数 2 と 5 を削除すると、数値が 5 のブロックごとに自然にグループ化されるため、削減された積は再帰的に動作します。 

古典的な導出では次の結果が得られます。$$g(n) = g\!\left(\left\lfloor\frac n5\right\rfloor\right) \cdot G(n\bmod 100000) \cdot (-1)^{\lfloor n/100000\rfloor} \pmod{100000},$$どこ$G(m)$までの還元残基の累積積です。$m$。 

再帰の深さはわずか約です$$\log_5(10^{12}) \approx 18.$$したがって、計算全体が非常に高速になります。 

---

 #3. 効率的な計算

 事前に計算します$0\le k<100000$:$$R(k)=\text{reduced part of }k$$(2 と 5 の要素をすべて削除)、

 およびプレフィックス製品$$P(m)=\prod_{k=1}^m R(k)\pmod{100000}.$$次に、再帰的に計算します。$$g(n)= g\!\left(\left\lfloor n/5\right\rfloor\right) \cdot P(n\bmod 100000) \cdot P(99999)^{\lfloor n/100000\rfloor} \pmod{100000}.$$最後に残りの 2 の累乗を掛けます。$$2^{v_2(n!)-v_5(n!)}.$$---

 #4. Pythonの実装```python
MOD = 100000

# ---------------------------------------------------------
# Compute exponent of prime p in n!
# ---------------------------------------------------------
def vp_factorial(n, p):
    s = 0
    while n:
        n //= p
        s += n
    return s

# ---------------------------------------------------------
# Remove all factors of 2 and 5 from x
# ---------------------------------------------------------
def reduce_25(x):
    while x % 2 == 0:
        x //= 2
    while x % 5 == 0:
        x //= 5
    return x % MOD

# ---------------------------------------------------------
# Precompute prefix products of reduced numbers
# ---------------------------------------------------------
prefix = [1] * MOD

for i in range(1, MOD):
    prefix[i] = (prefix[i - 1] * reduce_25(i)) % MOD

block_product = prefix[-1]

# ---------------------------------------------------------
# Recursive computation of reduced factorial product
# ---------------------------------------------------------
def g(n):
    if n == 0:
        return 1

    q, r = divmod(n, MOD)

    # contribution from full blocks
    ans = pow(block_product, q, MOD)

    # contribution from partial block
    ans = (ans * prefix[r]) % MOD

    # recurse on division by 5
    ans = (ans * g(n // 5)) % MOD

    return ans

# ---------------------------------------------------------
# Main computation
# ---------------------------------------------------------
N = 10**12

# excess powers of 2 after cancelling 5s
e2 = vp_factorial(N, 2)
e5 = vp_factorial(N, 5)

extra_twos = e2 - e5

# reduced product
ans = g(N)

# restore leftover powers of 2
ans = (ans * pow(2, extra_twos, MOD)) % MOD

print(ans)
```---
