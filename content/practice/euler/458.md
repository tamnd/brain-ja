[プロジェクト オイラー問題 458](https://projecteuler.net/problem=458)

 ## 解決策

 **答え:**`423341841`アルファベットを **project** の 7 つの異なる文字とします。$$A=\{c,e,j,o,p,r,t\}$$禁止された部分文字列は、**「プロジェクト」の任意の順列**、つまり、**すべての 7 文字を 1 回だけ含む** 長さ 7 のブロックです。 

## 1. 数学的分析

 ### 主な所見

 アルファベット自体は正確に 7 文字であるため、**7 文字すべてが異なる場合**、長さ 7 の部分文字列は禁止されます。 

したがって、問題は次のようになります。 

> 長さの文字列を数える$n$**長さ 7 の連続したブロックがすべて異なる文字を持たない**ように、7 文字のアルファベット上で。 

---

 ### 状態圧縮

 文字を追加すると禁止されたブロックが作成されるかどうかを判断するために必要な情報は次のとおりです。 

> **異なる連続文字**の最長の接尾辞の長さ。 

状態の定義$k$($0\le k\le 6$） として：

-$k=0$: 空の文字列、
 -$k\ge1$: 現在の文字列は接尾辞で終わります。$k$はっきりとした文字。 

状態 7 は、禁止された順列が出現することを意味するため、決して許可しません。 

#### 移行ルール

 私たちが州にいると仮定してください$k\ge1$、接尾辞付き$$x_1x_2\cdots x_k$$（すべて別個です）。 

以下を追加すると、

 - **接尾辞にない新しい文字**:

 接尾辞の長さは次のようになります$k+1$、 と$7-k$選択肢。 
- 既存の接尾辞文字の 1 つ$x_i$:

 新しい個別のサフィックスは次のようになります$$x_{i+1}\cdots x_kx_i$$その長さは$$k-i+1.$$したがって状態から$k$:

 - 各状態への遷移は 1 つだけ$1,2,\dots,k$、
- そして$7-k$状態への遷移$k+1$（もし$k<6$）。 

州$6$に移行できません$7$禁止された部分文字列が作成されてしまうためです。 

これにより、$7\times7$遷移行列なので、$$T(n)$$の高速行列累乗を使用して計算できます。$$O(7^3\log n).$$簡単な確認:$$T(7)=7^7-7!=818503,$$問題文と一致します。

 ## 2. Python の実装```python
MOD = 10**9
SIZE = 7

# Build transition matrix
M = [[0] * SIZE for _ in range(SIZE)]

for k in range(SIZE):
    if k == 0:
        # First character: 7 choices -> state 1
        M[1][0] = 7
    else:
        # Repeating one of the suffix letters
        for new_len in range(1, k + 1):
            M[new_len][k] += 1

        # Add a new distinct letter
        if k < 6:
            M[k + 1][k] += (7 - k)

def mat_mul(A, B):
    """Matrix multiplication mod MOD."""
    n = len(A)
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                a = A[i][k]
                for j in range(n):
                    if B[k][j]:
                        C[i][j] = (C[i][j] + a * B[k][j]) % MOD

    return C

def mat_pow(M, exp):
    """Binary exponentiation of matrix."""
    n = len(M)
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while exp:
        if exp & 1:
            R = mat_mul(R, M)
        M = mat_mul(M, M)
        exp >>= 1

    return R

def T(n):
    # Initial vector: empty string in state 0
    v = [0] * SIZE
    v[0] = 1

    P = mat_pow(M, n)

    result = [0] * SIZE
    for i in range(SIZE):
        total = 0
        for j in range(SIZE):
            total += P[i][j] * v[j]
        result[i] = total % MOD

    return sum(result) % MOD

# Verification
print(T(7))          # 818503
print(T(10**12))     # final answer
```---

 ## 3. コードのチュートリアル

 1. **移行マトリックスの作成**

 文字を追加した後に個別のサフィックスの長さがどのように変化するかをエンコードします。 
2. **行列乗算 (`mat_mul`)**

 行列の剰余を乗算します$10^9$、最後の 9 桁のみが必要なためです。 
3. **高速累乗 (`mat_pow`)**

 計算します$$M^n$$対数時間で。 

1. **初期ベクトル**

 状態 0 (空の文字列) で開始します。 
2. **最終合計額**

 有効な終了状態をすべて合計して取得します$T(n)$。 

### 小さな例のチェック

 のために$n=7$:```python
T(7) = 818503
```一致するもの:$$7^7 - 7! = 823543 - 5040 = 818503.$$したがって、オートマトンは正しく動作しています。

 ## 4. 最終確認

 - 7 つの状態のみを追跡するため、行列のべき乗は正確かつ効率的です。 
-$n=7$健全性チェックは完全に一致します。 
- モジュロ$10^9$最後の 9 桁のみが要求されるため、算術演算は有効です。
