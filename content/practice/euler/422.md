[プロジェクト オイラー問題 422](https://projecteuler.net/problem=422)

 ## 解決策

 **答え:**`92060460`させて$$Q(x,y)=12x^2+7xy-12y^2.$$双曲線は$$H:\quad Q(x,y)=625,$$そして$X=(7,1)\in H$。 

私たちは定義します$P_n$幾何学的条件によって再帰的に：

 -$P_1=(13,\tfrac{61}{4})$、
 -$P_2=(-\tfrac{43}{6},-4)$、
- のために$n>2$、$P_n$の 2 番目の交差点です$H$ラインスルーで$P_{n-1}$と平行して$XP_{n-2}$。 

計算しなければなりません$P_n$のために$$n=11^{14}$$そして戻る$$(a+b+c+d)\bmod 1{,}000{,}000{,}007$$どこ$$P_n=\left(\frac ab,\frac cd\right)$$最低の言葉で。 

---

 ## 1. 数学的分析

 ### ステップ 1: 双曲線をパラメータ化します。$X$線を引きます$X=(7,1)$傾斜あり$u$:$$(x,y)=(7+t,1+ut).$$に置き換えます$Q(x,y)=625$:$$12(7+t)^2+7(7+t)(1+ut)-12(1+ut)^2=625.$$因数分解すると次のようになります。$$t\left(12tu^2-7tu-12t-25u-175\right)=0.$$一つの根は、$t=0$(ポイント$X$); 2つ目の交差点は$$t=\frac{25u+175}{12u^2-7u-12}.$$したがって、すべての点$H$(漸近方向を除く) パラメータに対応$u$。 

二次分母因数は次のとおりです。$$12u^2-7u-12 = 12\left(u-\frac43\right)\left(u+\frac34\right).$$これは置換を示唆しています$$z = \frac{u-\frac43}{u+\frac34}.$$を解決する$u$、$$u=\frac{\frac43+\frac34 z}{1-z}.$$点の座標を代入すると、美しく単純化されます。$$x=3z+\frac4z, \qquad y=\frac{16}{3z}-\frac94 z.$$---

 ### ステップ 2: 再発箇所を見つける$z_n$させて$z_n$に対応する$P_n$。 

条件は「$P_nP_{n-1}$と平行して$XP_{n-2}$」は代数的に翻訳できます。 

置換と単純化の後、漸化式は次のようになります。$$z_n=\frac{4z_{n-2}}{3z_{n-1}}.$$初期値:$$z_1=\frac13, \qquad z_2=-\frac89.$$チェック中：$$z_3 = \frac{4(1/3)}{3(-8/9)} = -\frac12,$$

$$z_4 = \frac{4(-8/9)}{3(-1/2)} = \frac{64}{27},$$問題のデータと一致します。 

---

 ### ステップ 3: 素数指数形式

 すべては力として始まるので、$2$そして$3$、 書く$$z_n=\pm 2^{A_n}3^{B_n}.$$反復により次のことが得られます。$$A_n=A_{n-2}-A_{n-1}+2,$$

$$B_n=B_{n-2}-B_{n-1}-1,$$と$$A_1=0,\ A_2=3,$$

$$B_1=-1,\ B_2=-2.$$のために$n=11^{14}$:

 -$n$奇妙です、
 -$n\equiv 1\pmod 3$、

それで$z_n>0$、および大きな奇数の場合$n$、$$A_n<0,\qquad B_n>0.$$したがって$$z_n=\frac{3^{B_n}}{2^{-A_n}}.$$させて$$p=3^{B_n}, \qquad q=2^{-A_n}.$$それから$$z_n=\frac pq.$$座標は次のようになります。$$x=\frac{3p^2+4q^2}{pq},$$

$$y=\frac{64q^2-27p^2}{12pq}.$$奇数の場合$n$ここでは、両方の分数がすでに約定されています。 

---

 ### ステップ 4: 剰余指数の計算

 最終和のモジュロだけが必要です$$M=1{,}000{,}000{,}007.$$以来$M$は素数、指数は剰余です$M-1$。 

アフィン反復での高速行列累乗は次のようになります。$$A_n \equiv 852174610 \pmod{M-1},$$

$$B_n \equiv 218412851 \pmod{M-1}.$$以来$A_n<0$、$$-A_n \equiv 147825396 \pmod{M-1}.$$したがって、$$p\equiv 3^{218412851}\pmod M,$$

$$q\equiv 2^{147825396}\pmod M.$$それから：$$a=3p^2+4q^2,$$

$$b=pq,$$

$$c=64q^2-27p^2,$$

$$d=12pq.$$ついに：$$(a+b+c+d)\bmod M = 92060460.$$---

 ## 2. Python の実装```python
MOD = 1_000_000_007
PHI = MOD - 1

n = 11**14

def matrix_mul(A, B, mod):
    """Multiply two 3x3 matrices modulo mod."""
    return [
        [
            sum(A[i][k] * B[k][j] for k in range(3)) % mod
            for j in range(3)
        ]
        for i in range(3)
    ]

def recurrence_mod(n, x1, x2, c):
    """
    Solve:
        x_n = x_{n-2} - x_{n-1} + c
    modulo PHI.
    """
    if n == 1:
        return x1 % PHI
    if n == 2:
        return x2 % PHI

    # State vector:
    # [x_n, x_{n-1}, 1]
    M = [
        [-1 % PHI, 1, c % PHI],
        [1, 0, 0],
        [0, 0, 1]
    ]

    # Fast exponentiation
    power = n - 2
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while power:
        if power & 1:
            result = matrix_mul(result, M, PHI)
        M = matrix_mul(M, M, PHI)
        power >>= 1

    vec = [x2 % PHI, x1 % PHI, 1]

    xn = sum(result[0][i] * vec[i] for i in range(3)) % PHI
    return xn

# Compute exponent residues
A_mod = recurrence_mod(n, 0, 3, 2)
B_mod = recurrence_mod(n, -1, -2, -1)

# Since A_n is negative for this n
exp2 = (-A_mod) % PHI
exp3 = B_mod

p = pow(3, exp3, MOD)
q = pow(2, exp2, MOD)

# Coordinates modulo MOD
a = (3 * p * p + 4 * q * q) % MOD
b = (p * q) % MOD

c = (64 * q * q - 27 * p * p) % MOD
d = (12 * p * q) % MOD

answer = (a + b + c + d) % MOD

print(answer)
```---
