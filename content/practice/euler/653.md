[プロジェクト オイラー問題 653](https://projecteuler.net/problem=653)

 ## 解決策

 **答え:**`1130658687`大理石の直径を次のようにします。$D=20$。 

で表します$x_i(t)$の中心$i$- 番目の大理石 (最初は西から数えて)。 

最初はビー玉が満足する$$x_{i+1}(0)-x_i(0)\ge D.$$主な困難は衝突の処理です。 標準的な「同一の粒子」トリックは、重要な洞察です。 

#1. 衝突の等価性

 完全な弾性衝突による等しい質量の場合、衝突する 2 つのビー玉は単純に速度を交換します。 

したがって:

 - アイデンティティを無視すると、ビー玉は相互に通過する粒子とまったく同じように動作します。 
- 衝突の唯一の影響は、アイデンティティが交換されることです。 

したがって、決して衝突しない**ゴースト粒子**を研究できるかもしれません。 

---

 # 2. 直径制約の削除

 変換された座標を定義する$$y_i = x_i - Di.$$隣接するセンターは常に少なくとも$D$別に、引き算する$Di$ハードコアの除外を完全に削除します。 

最初に:$$x_i = 10 + \sum_{k=1}^i g_k + D(i-1),$$どこ$$g_k = (r_k \bmod 1000)+1.$$したがって、$$y_i = \sum_{k=1}^i g_k - 10.$$したがって、変換された位置は次のものから独立しています。$D$。 

---

 #3. 反射壁トリック

 西側の壁で反射する西方向に移動する粒子は、西側の壁で反射し始めた粒子と等価です。$-y_i$そして常に東に移動しました。 

このように定義します$$s_i = \begin{cases} +y_i,& r_i\le 10^7 \quad (\text{east})\\ -y_i,& r_i>10^7 \quad (\text{west}) \end{cases}$$そして今、すべてのゴースト粒子は単位速度で東に移動するだけです。 

---

 #4. 退場時間

 変換された座標では、東口の境界は次のとおりです。$$L-D.$$したがって、大理石から発生するゴースト粒子は$i$時間通りに退出する$$t_i^{(\text{ghost})} = (L-D)-s_i.$$並べ替える$s_i$降順で:$$s_{(1)} \ge s_{(2)} \ge \cdots \ge s_{(N)}.$$次に、対応するゴースト終了時間が昇順に発生します。 

本物の大理石は秩序を保っているので、$j$- 番目の大理石の出口は、$j$- 番目の終了イベント。 

先に出たビー玉はそれぞれ、占有チューブを正確に短くします。$D$したがって、実際の終了時間は次のように短縮されます。$$D(j-1)-D = D(j-2).$$したがって$$\boxed{ d(L,N,j)=L+20-20j-s_{(j)} }$$どこ$s_{(j)}$です$j$- の中で 2 番目に大きい値$s_i$。 

---

 #5. 例の検証

 のために$(L,N,j)=(5000,3,2)$:$$s=\{107,-539,-712\}.$$2番目に大きい値は、$-539$。 

したがって、$$d=5000+20-40-(-539)=5519.$$正しい。 

のために$(10000,11,6)$、式は次のようになります。$$11780.$$正しい。 

のために$(100000,101,51)$、式は次のようになります。$$114101.$$正しい。

 #6. Pythonの実装```python
import heapq

MOD = 32745673

def d(L, N, j):
    r = 6563116

    gap_sum = 0
    signed_positions = []

    for _ in range(N):
        gap = (r % 1000) + 1
        gap_sum += gap

        # y_i = sum(gaps) - 10
        y = gap_sum - 10

        # east => +y, west => -y
        if r <= 10_000_000:
            signed_positions.append(y)
        else:
            signed_positions.append(-y)

        r = (r * r) % MOD

    # j-th largest signed position
    s_j = heapq.nlargest(j, signed_positions)[-1]

    return L + 20 - 20 * j - s_j

print(d(5000, 3, 2))         # 5519
print(d(10000, 11, 6))       # 11780
print(d(100000, 101, 51))    # 114101

print(d(1_000_000_000, 1_000_001, 500_001))
```---
