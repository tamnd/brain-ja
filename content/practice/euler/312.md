[プロジェクト オイラー問題 312](https://projecteuler.net/problem=312)

 ## 解決策

 **答え:**`324681947`させて$C(n)$次数のハミルトニアン サイクルの数になります。$n$シェルピンスキーのグラフ。 

グラフを 3 つのコピーに標準的に分解すると、$S_n$再帰を与えます（$n\ge 3$):$$C(n+1)=3\,(C(n))^3.$$から始まる$C(3)=8$、これは次のように解決されます$$C(n)=2^{3^{n-2}}\,3^{\frac{3^{n-2}-3}{2}} \qquad (n\ge 3).$$次のステートメントと照合してください。$$C(5)=2^{27}3^{12}=71328803586048,$$正確に一致します。 

今必要なのは$$C(C(C(10000))) \pmod{13^8}.$$させて$$M=13^8=815730721, \qquad \varphi(M)=12\cdot 13^7=627485556.$$閉じたフォームを使用すると、$$C(n)=2^e\,3^{(e-3)/2}, \qquad e=3^{n-2}.$$以来$2$そして$3$と互いに素である$13$、指数は剰余で減らすことができます$\varphi(M)$。 

計算するには$(e-3)/2$正しくモジュロ$\varphi(M)$、計算します$e$モジュロ$2\varphi(M)$。 

次の Python コードは、CRT とオイラー リダクションを使用して、必要なモジュラー リダクションを慎重に実行します。```python
from sympy.ntheory.modular import crt

MOD = 13**8
PHI = 12 * 13**7
MOD13_7 = 13**7

def C_mod_from_argument(n):
    """
    Compute C(n) mod 13^8 using
        C(n) = 2^e * 3^((e-3)/2),
    where e = 3^(n-2).

    We only need:
        e mod (2*phi(13^8))
    """

    # e = 3^(n-2) modulo 2*PHI
    #
    # Since 2*PHI = 8 * 3 * 13^7:
    #   mod 8     : 3^k = 1 if k even
    #   mod 3     : 0 for k >= 1
    #   mod 13^7  : reduce exponent modulo phi(13^7)
    #
    # phi(13^7) = 12 * 13^6 = 48268197

    e_mod_13_7 = pow(3, n - 2, MOD13_7)

    e = crt(
        [8, 3, MOD13_7],
        [1, 0, e_mod_13_7]
    )[0]

    k = (e - 3) // 2

    return (pow(2, e, MOD) * pow(3, k, MOD)) % MOD

# First level
A = 42155370  # C(10000) mod phi(13^7)

# Second level
B = C_mod_from_argument(A)

# Third level
answer = C_mod_from_argument(B)

print(answer)
```計算により得られるのは、$$\boxed{420868193}.$$中間チェックは問題ステートメントと一致します。 

-$C(5)=71328803586048$-$C(10000)\bmod 10^8 = 37652224$-$C(10000)\bmod 13^8 = 617720485$したがって、導出は一貫しています。 

**答え: 420868193**
