 ## 解決策

 **答え:**`1884161251122450`させて$$A=pqr$$そして推測してください$$\frac1A=\frac1p+\frac1q+\frac1r.$$私たちが求めているのは、$150000^\text{th}$正の整数$A$この条件を満たしていること。 

---

 # ステップ 1 — 代数変換

 から始まる$$\frac1{pqr}=\frac1p+\frac1q+\frac1r,$$両辺に次の値を掛けます$pqr$:$$1=qr+pr+pq.$$したがって、アレクサンドリア整数は、次を満たす整数の 3 倍に対応します。$$pq+pr+qr=1.$$ここで、すべてのソリューションをパラメータ化します。 

---

 # ステップ 2 — 有用なパラメータ化を導出する

 を解決する$r$:$$r(p+q) = 1-pq$$それで$$r=\frac{1-pq}{p+q}.$$整数解が必要です。 

標準的な Project Euler アプローチに従って、次のようにします。$$p=a,\qquad q=-(a+d),$$どこ$a>0$そして$d>0$。 

それから$$p+q=a-(a+d)=-d,$$そして$$1-pq =1-a(-(a+d)) =1+a(a+d) =a^2+ad+1.$$したがって$$r=\frac{a^2+ad+1}{-d} =-\left(a+\frac{a^2+1}{d}\right).$$したがって$r$が整数であるとき、$$d \mid (a^2+1).$$アレクサンドリア整数は次のようになります。$$A = pqr = a(a+d)\left(a+\frac{a^2+1}{d}\right).$$したがって、次のようになります。 

> すべての正の整数に対して$a$そしてすべての約数$d\mid (a^2+1)$、
 >
 >
 >
 >
 >$$A=a(a+d)\left(a+\frac{a^2+1}{d}\right)$$>
 >
 >
 >
 > はアレクサンドリア整数です。 

これにより、すべての正のアレクサンドリア整数が生成されます。 

---

 # ステップ 3 — 例の確認

 テイク$a=5$。 

それから$$a^2+1=26.$$除数を選択してください$d=2$。 

それから$$p=5,\qquad q=-(5+2)=-7,$$そして$$r=-\left(5+\frac{26}{2}\right)=-18.$$したがって$$A=5\cdot(-7)\cdot(-18)=630,$$問題文と一致します。

 # ステップ 4 — 効率的なアルゴリズム

 私たちはそれを見つけなければなりません$150000^\text{th}$最小の個別値。 

アルゴリズム:

 1. ループオーバー$a=1,2,3,\dots$2. コンピューティング$n=a^2+1$3. すべての約数を列挙します$d\mid n$4. 生成する$$A=a(a+d)\left(a+\frac{n}{d}\right)$$5. セットに挿入する
 6. 生成されたすべての値を並べ替える
 7.$150000^\text{th}$境界線$a=150000$で十分です。

 # Pythonの実装```python
import math

LIMIT = 150000

# ------------------------------------------------------------
# Sieve of primes for fast factorization
# ------------------------------------------------------------
def prime_sieve(n):
    sieve = bytearray(b'\x01') * (n + 1)
    sieve[0:2] = b'\x00\x00'

    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            sieve[i*i:n+1:i] = b'\x00' * (((n - i*i) // i) + 1)

    return [i for i, v in enumerate(sieve) if v]

primes = prime_sieve(500000)

# ------------------------------------------------------------
# Generate all divisors of n
# ------------------------------------------------------------
def divisors(n):
    factors = []
    temp = n

    for p in primes:
        if p * p > temp:
            break

        if temp % p == 0:
            e = 0
            while temp % p == 0:
                temp //= p
                e += 1
            factors.append((p, e))

    if temp > 1:
        factors.append((temp, 1))

    divs = [1]

    for p, e in factors:
        current = divs[:]
        mult = 1

        for _ in range(e):
            mult *= p
            for d in current:
                divs.append(d * mult)

    return divs

# ------------------------------------------------------------
# Generate Alexandrian integers
# ------------------------------------------------------------
alex = set()

MAX_A = 150000

for a in range(1, MAX_A + 1):
    n = a * a + 1

    for d in divisors(n):
        A = a * (a + d) * (a + n // d)
        alex.add(A)

# ------------------------------------------------------------
# Extract answer
# ------------------------------------------------------------
alex = sorted(alex)

print(alex[LIMIT - 1])
```---
