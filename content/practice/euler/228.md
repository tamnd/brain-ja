[プロジェクト オイラー問題 228](https://projecteuler.net/problem=228)

 ## 解決策

 **答え:**`86226`ポリゴンのエッジの外側の法線方向によってその辺が決まるようにします。 

凸多角形のミンコフスキー和に関する標準的な事実は次のとおりです。 

> 一連のエッジ方向 (外向きの法線方向と同等)
 >
 >$P+Q$のエッジ方向の和集合です。$P$そして$Q$。 

したがって、問題は、複数のエッジ間に現れる明確なエッジ方向を数えることに帰着します。$$S_{1864},S_{1865},\dots,S_{1909}.$$---

 #1. 幾何学形状$S_n$の頂点$S_n$は$$v_k=\left(\cos\frac{(2k-1)\pi}{n},\, \sin\frac{(2k-1)\pi}{n}\right).$$これらは単位円の周囲に等間隔に配置され、次の角度で回転されます。$\pi/n$。 

隣接する頂点は角度を持っています$$\frac{(2k-1)\pi}{n},\qquad \frac{(2k+1)\pi}{n}.$$それらの間のエッジには中点の方向があります$$\frac{2k\pi}{n}.$$したがって、外向きの法線方向は、$n$側面はまさに$$\frac{2k\pi}{n},\qquad k=0,1,\dots,n-1.$$それで$S_n$指示に貢献します$$\left\{\frac{k}{n}\pmod 1\right\}.$$---

 # 2. ミンコフスキー和の異なる方向

 2 つの方向が一致する場合$$\frac{k_1}{n_1}\equiv \frac{k_2}{n_2}\pmod 1.$$最下位項に換算した後、すべての方向が換算された分数に一意に対応します$$\frac{a}{d},\qquad \gcd(a,d)=1.$$そういう方向性が見えてくるのは$d\mid n$少なくとも1人にとっては$n\in[1864,1909]$。 

分母ごとに$d$、まさにあります$\varphi(d)$その分母で分数を切り捨てます。 

したがって:

 \boxed{ \text{# 面} = \sum_{\substack{d\ge1\\ d\mid n\text{ 一部の場合 }1864\le n\le1909}} \varphi(d) }

 どこで$\varphi$はオイラーのトーティエント関数です。 

---

 #3. Pythonの実装```python
from math import gcd

# Euler totient
def phi(n):
    result = n
    p = 2
    m = n

    while p * p <= m:
        if m % p == 0:
            while m % p == 0:
                m //= p
            result -= result // p
        p += 1

    if m > 1:
        result -= result // m

    return result

# Collect every divisor of numbers 1864..1909
divisors = set()

for n in range(1864, 1910):
    for d in range(1, int(n**0.5) + 1):
        if n % d == 0:
            divisors.add(d)
            divisors.add(n // d)

# Sum Euler totients
answer = sum(phi(d) for d in divisors)

print(answer)
```これは次のように出力します:```python
86226
```---
