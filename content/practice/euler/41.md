 ## 解決策

 **答え:**`7652413`## 1. 数学的分析

 **最大のパンデジタル素数**が必要です。$n$-桁のパンデジタル番号は各桁を使用します$1$に$n$まさに一度。 

例えば：$$2143$$は$4$-桁パンデジタルとプライム。 

素朴な考えは次のとおりです。 

- すべてのパンデジタル番号を生成します。 
- 素数性をチェックし、
 - 最大値を取る。 

しかし、数論を使用すると、はるかに優れた結果を得ることができます。 

### 重要な洞察 1: 3 で割り切れる

 数値は次で割り切れます$3$その桁の合計が次で割り切れる場合$3$。 

のために$n$-桁のパンデジタル番号、桁の合計は次のとおりです。$$1+2+\cdots+n=\frac{n(n+1)}{2}$$の値を確認してみましょう$n$:$$n=9:\quad \frac{9\cdot10}{2}=45$$で割り切れる$3$, したがって、**9 桁のパンデジタル数はすべて 3 で割り切れます** → 素数になることは不可能です。$$n=8:\quad \frac{8\cdot9}{2}=36$$また、次のように割り切れます。$3$→ **すべての 8 桁のパンデジタル番号は複合です**。$$n=7:\quad \frac{7\cdot8}{2}=28$$で割り切れない$3$, so a 7-digit pandigital prime **might exist**.

 したがって、最大のパンデジタル素数は **7 桁以下**でなければなりません。 

We only need to search among permutations of:$$1,2,3,4,5,6,7$$### 重要な洞察 2: 降順で検索する

 このような**最大**の素数が必要です。 

すべてのパンデジタル数を生成して最大値を取得する代わりに、**辞書編集順**で順列を生成し、最初に見つかった素数で停止します。 

これにより最適性が保証されます。 

### 重要な洞察 3: 高速素数性テスト

 数値かどうかをテストするには$n$素数です:

 - 拒否する$n < 2$、
 - 偶数を拒否します。 
- 次の値までの約数のみを試してください。$$\sqrt{n}$$なぜなら、もし$n = ab$、要素は最大でも 1 つでなければなりません$\sqrt{n}$。 

したがって、各候補について、次の範囲までの奇数整数で割り切れるかどうかをテストします。$$\lfloor \sqrt{n} \rfloor$$以下のものしかないので、$$7! = 5040$$7 桁の順列、ブルートフォースはごくわずかです。

 ## 2. Python の実装```python
from itertools import permutations
import math

def is_prime(n):
    """Return True if n is prime, otherwise False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))

    # Check odd divisors only
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False

    return True

def largest_pandigital_prime():
    # Try n from largest to smallest
    for n in range(9, 0, -1):

        # Skip digit lengths whose digit sum is divisible by 3
        digit_sum = n * (n + 1) // 2
        if digit_sum % 3 == 0:
            continue

        digits = ''.join(str(i) for i in range(n, 0, -1))

        # Generate permutations in descending order
        for perm in permutations(digits):
            number = int(''.join(perm))

            if is_prime(number):
                return number

answer = largest_pandigital_prime()
print(answer)
```---
