[プロジェクト オイラー問題 288](https://projecteuler.net/problem=288)

 ## 解決策

 **答え:**`605857431263981935`させて$$N(p,q)=\sum_{n=0}^{q} T_n p^n,$$どこ$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093,\qquad T_n=S_n\bmod p.$$私たちが欲しいのは$$\operatorname{NF}(p,q)=v_p(N(p,q)!),$$素数の指数$p$で$N(p,q)!$。 

この問題については:$$p=61,\qquad q=10^7,$$そして私たちには必要です$$\operatorname{NF}(61,10^7)\bmod 61^{10}.$$---

 #1. 数学的分析

 重要な事実は **ルジャンドルの公式**です:$$v_p(n!)=\sum_{k\ge1}\left\lfloor \frac{n}{p^k}\right\rfloor.$$ベースから派生した標準アイデンティティ$p$桁の合計は$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$どこ$s_p(n)$の桁の合計です$n$基地内で$p$。 

---

 ## ステップ 1: ベース-$p$の表現$N(p,q)$それぞれだから$$0\le T_n < p,$$番号$$N(p,q)=\sum_{n=0}^{q}T_n p^n$$すでにベースになっています-$p$の拡大$N$。 

したがって、$$s_p(N)=\sum_{n=0}^{q}T_n.$$したがって、$$\operatorname{NF}(p,q) = \frac{N-\sum T_n}{p-1}.$$の定義を代入します。$N$:$$\operatorname{NF}(p,q) = \frac{\sum_{n=0}^{q}T_n p^n-\sum_{n=0}^{q}T_n}{p-1}.$$項ごとに因数分解する:$$\operatorname{NF}(p,q) = \sum_{n=0}^{q} T_n\frac{p^n-1}{p-1}.$$定義する$$R_n=\frac{p^n-1}{p-1}=1+p+p^2+\cdots+p^{n-1}.$$それで$$\boxed{ \operatorname{NF}(p,q)=\sum_{n=0}^{q}T_nR_n }.$$---

 ## ステップ 2: モジュロを削減する$p^{10}$モジュロだけが必要です$61^{10}$。 

観察する：$$R_n = 1+p+\cdots+p^{n-1}.$$どれについても$n\ge 10$、$$R_n \equiv 1+p+\cdots+p^9 \pmod{p^{10}},$$なぜなら、高次の累乗はすべて次のように割り切れるためです。$p^{10}$。 

させて$$R=1+p+\cdots+p^9.$$それから$$\operatorname{NF}(p,q) \equiv \sum_{n=0}^{9}T_nR_n + R\sum_{n=10}^{q}T_n \pmod{p^{10}}.$$これが重要な単純化です。私たちは決して巨大な権限を必要としません。$p$、最初の10個だけ。 

---

 #2. Pythonの実装```python
def solve():
    p = 61
    q = 10_000_000
    mod = p ** 10

    # Random generator seed
    S = 290797

    # R = 1 + p + p^2 + ... + p^9  (mod p^10)
    R = sum(p ** i for i in range(10)) % mod

    # Store first 10 T_n values separately
    first_terms = []

    # Sum of all T_n for n >= 10
    tail_sum = 0

    # Generate T_n values
    for n in range(q + 1):
        T = S % p

        if n < 10:
            first_terms.append(T)
        else:
            tail_sum += T

        S = (S * S) % 50515093

    # Compute contribution of first 10 terms exactly
    ans = 0

    for n in range(10):
        # R_n = 1 + p + ... + p^(n-1)
        Rn = sum(p ** i for i in range(n))
        ans += first_terms[n] * Rn

    # Contribution from all remaining terms
    ans += R * tail_sum

    ans %= mod

    return ans

print(solve())
```---
