[プロジェクト オイラー問題 550](https://projecteuler.net/problem=550)

 ## 解決策

 **答え:**`328104836`させて$g(n)$サイズの単一の山のスプラーグ・グランディ値を示します$n$。 

とのポジション$k$の xor があればパイルは勝ちます$k$パイルのグランディ値がゼロ以外です。 

したがって、問題は次のようになります。 

1. すべての整数のグランディ値を計算します。$2\le n\le 10^7$。 
2. 各グランディ値を持つ数値がいくつあるか数えます。 
3. 何個数えるか$k$-タプルには XOR があります$=0$xor 畳み込み / ウォルシュ アダマール変換を使用します。 
4. タプルの総数から減算します。 

---

 #1. 数学的分析

 ## 1.1 許可される動き

 サイズの山から$n$、動きは2つの適切な約数を選択します$a,b$の$n$満足のいく$$1<a<n,\qquad 1<b<n.$$結果として得られるゲーム位置は 2 つの独立したパイルであるため、そのグランディ値は次のようになります。$$g(a)\oplus g(b).$$したがって$$g(n)=\operatorname{mex}\{g(a)\oplus g(b)\}.$$---

 # 1.2 重要な所見:$g(n)$のみに依存する$\Omega(n)$させて$$\Omega(n)=\text{total number of prime factors of }n$$(多重度でカウントされます)。 

例:$$\Omega(12)=\Omega(2^2\cdot3)=3, \qquad \Omega(72)=\Omega(2^3\cdot3^2)=5.$$仮定する$\Omega(n)=m$。 

のすべての適切な約数$n$間の素因数の数があります$1$そして$m-1$、その間隔内のすべての値が達成可能です。 

確かに、もし$$n=p_1p_2\cdots p_m$$(繰り返しは許可されます)、その後、任意の値を取得します。$t$これらの素因数の約数は次のようになります。$\Omega=t$。 

したがって、移動セットは以下にのみ依存します。$m$。 

定義する$$G(m)=g(n)\quad\text{whenever }\Omega(n)=m.$$それから$$G(1)=0$$(素数には移動がありません)、および$m\ge2$、$$G(m)=\operatorname{mex} \left( \{\,G(i)\oplus G(j)\;:\;1\le i,j<m\,\} \right).$$再帰的に計算すると次のようになります。$$\begin{aligned} G(1)&=0\\ G(2)&=1\\ G(3)&=2\\ G(4)&=4\\ G(5)&=7\\ G(6)&=8\\ &\dots \end{aligned}$$のために$n\le10^7$、$$\Omega(n)\le23$$なぜなら$$2^{24}>10^7.$$したがって、最初の 23 個の Grundy 値のみが必要になります。 

---

 # 1.3 xor-zero タプルのカウント

 しましょう$$c_x=\#\{n\in[2,10^7]:g(n)=x\}.$$私たちが選ぶなら$k$独立して積み上げた場合、xor が 0 であるタプルの数は$k$-fold xor 畳み込みはゼロで評価されます。 

標準ツールは、高速ウォルシュ アダマール変換 (FWHT) です。 

もし$A$は周波数ベクトルです$(c_x)$、その後:

 1. FWHT変換$A$、
 2. 変換された各コンポーネントを$k$-乗、
 3. 逆変換。 

インデックスでの結果の係数$0$は、まさに xor-zero タプルの数です。 

ついに、$$f(n,k)=n^k-(\text{xor-zero tuples}).$$ここ$n=10^7-1$可能なパイルサイズ ($2$を通して$10^7$）。 

すべてはモジュロで計算されます$$987654321.$$---

 #2. Pythonの実装```python
MOD = 987654321
N = 10_000_000
K = 10**12

# ------------------------------------------------------------
# Step 1: compute Omega(n) for all n <= N using a linear sieve
# ------------------------------------------------------------

omega = [0] * (N + 1)
primes = []

for i in range(2, N + 1):
    if omega[i] == 0:
        omega[i] = 1
        primes.append(i)

    for p in primes:
        v = i * p
        if v > N:
            break

        omega[v] = omega[i] + 1

        if i % p == 0:
            break

# ------------------------------------------------------------
# Step 2: compute Grundy values G(m)
# Only m <= 23 is needed
# ------------------------------------------------------------

MAX_OMEGA = max(omega)

G = [0] * (MAX_OMEGA + 1)

grundy_values_so_far = []

for m in range(1, MAX_OMEGA + 1):

    reachable = set()

    for a in grundy_values_so_far:
        for b in grundy_values_so_far:
            reachable.add(a ^ b)

    g = 0
    while g in reachable:
        g += 1

    G[m] = g
    grundy_values_so_far.append(g)

# ------------------------------------------------------------
# Step 3: count how many numbers have each Grundy value
# ------------------------------------------------------------

MAX_G = max(G)

SIZE = 1
while SIZE <= MAX_G:
    SIZE <<= 1

freq = [0] * SIZE

for n in range(2, N + 1):
    freq[G[omega[n]]] += 1

# ------------------------------------------------------------
# Step 4: FWHT for xor convolution
# ------------------------------------------------------------

def fwht(a, inverse=False):
    n = len(a)
    h = 1

    while h < n:
        for i in range(0, n, h * 2):
            for j in range(i, i + h):
                x = a[j]
                y = a[j + h]

                a[j] = (x + y) % MOD
                a[j + h] = (x - y) % MOD

        h <<= 1

    if inverse:
        inv_n = pow(n, -1, MOD)
        for i in range(n):
            a[i] = (a[i] * inv_n) % MOD

# transform
fwht(freq)

# raise pointwise to K
for i in range(SIZE):
    freq[i] = pow(freq[i], K, MOD)

# inverse transform
fwht(freq, inverse=True)

xor_zero = freq[0] % MOD

# total tuples
total = pow(N - 1, K, MOD)

answer = (total - xor_zero) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## リニアふるい```python
omega[v] = omega[i] + 1
```を乗算するときに素因数を 1 つ追加します。$p$。 

したがって、計算します$\Omega(n)$あらゆる人にとって$n\le10^7$線形時間で。 

---

 ## グランディな再帰

 再帰:```python
reachable.add(a ^ b)
```実装する$$G(m)=\operatorname{mex}\{G(i)\oplus G(j)\}.$$州は 23 しか存在しないため、この部分は小さいです。 

---

 ## 度数表```python
freq[G[omega[n]]] += 1
```各グランディ値を生成するパイル サイズの数をカウントします。 

---

 ## FWHT

 Walsh-Hadamard 変換は、xor 畳み込みを対角化します。 

変換後:```python
freq[i] = pow(freq[i], K, MOD)
```を計算します$K$-周波数空間での xor 畳み込みを折ります。 

逆変換によりタプル数が回復されます。`freq[0]`xor-zero の位置の数になります。
