[プロジェクト オイラー問題 329](https://projecteuler.net/problem=329)

 ## 解決策

 **答え:**`199740353/29386561536000`観察された鳴き声シーケンスを次のようにします$$S=\texttt{PPPPNNPPPNPPNPN}$$長さの$15$。 

カエルがこのシーケンスを生成する正確な確率を計算する必要があります。 

---

 # 数学的分析

 カエルは整数の上を動きます$1,\dots,500$。 

- 広場にて$1$にジャンプする必要があります$2$。 
- 広場にて$500$にジャンプする必要があります$499$。 
- Otherwise it jumps left/right with probability$1/2$。 

ジャンプする前に、次のように鳴きます。 

- 素正方形の場合:

 -$P$確率的に$2/3$、
 -$N$確率的に$1/3$。 
- 非プライムスクエアの場合:

 -$P$確率的に$1/3$、
 -$N$確率的に$2/3$。 

初期位置はすべてに均一に分布します。$500$正方形。 

---

 ## ステップ 1: 放出確率

 定義する$$e(x,c)= \begin{cases} \frac23,& \text{if }x\text{ is prime and }c=P,\\[4pt] \frac13,& \text{if }x\text{ is prime and }c=N,\\[4pt] \frac13,& \text{if }x\text{ is nonprime and }c=P,\\[4pt] \frac23,& \text{if }x\text{ is nonprime and }c=N. \end{cases}$$カエルが現在正方形にいる場合$x$、そして次に聞こえる鳴き声は$c$の場合、確率寄与は次のようになります。$e(x,c)$。 

---

 ## ステップ 2: 動的プログラミング

 しましょう$$dp_k(x)$$最初の処理後の確率は$k$鳴く、カエルが四角いところにいる$x$。 

最初に:$$dp_0(x)=\frac1{500}.$$キャラクターごとに$c_k$シーケンス内:

 1. 鳴く確率を掛ける$e(x,c_k)$、
 2. その後、ジャンプルールに従って移動します。 

遷移:

 - から$1$に$2$確率的に$1$、
- から$500$に$499$確率的に$1$、
 - それ以外の場合は、左右に均等に分割します。 

結局$15$すべての状態を合計すると、望ましい確率が得られます。 

すべての遷移と放出の確率は有理であるため、最終的な答えは正確な分数になります。 

---

 # Pythonの実装```python
from fractions import Fraction

# ---------------------------------------------------------
# Problem data
# ---------------------------------------------------------

N = 500
sequence = "PPPPNNPPPNPPNPN"

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------

is_prime = [False] * (N + 1)

prime = [True] * (N + 1)
prime[0] = prime[1] = False

for p in range(2, int(N**0.5) + 1):
    if prime[p]:
        for multiple in range(p * p, N + 1, p):
            prime[multiple] = False

for i in range(2, N + 1):
    is_prime[i] = prime[i]

# ---------------------------------------------------------
# Initial distribution
# ---------------------------------------------------------

dp = {x: Fraction(1, N) for x in range(1, N + 1)}

# ---------------------------------------------------------
# Process croaks one by one
# ---------------------------------------------------------

for step, ch in enumerate(sequence):

    next_dp = {}

    for pos, prob in dp.items():

        # Probability of hearing this croak at this position
        if is_prime[pos]:
            emit = Fraction(2, 3) if ch == 'P' else Fraction(1, 3)
        else:
            emit = Fraction(1, 3) if ch == 'P' else Fraction(2, 3)

        prob *= emit

        # Last croak: no need to move afterward
        if step == len(sequence) - 1:
            next_dp[pos] = next_dp.get(pos, Fraction(0)) + prob
            continue

        # Movement
        if pos == 1:
            next_dp[2] = next_dp.get(2, Fraction(0)) + prob

        elif pos == N:
            next_dp[N - 1] = next_dp.get(N - 1, Fraction(0)) + prob

        else:
            next_dp[pos - 1] = (
                next_dp.get(pos - 1, Fraction(0))
                + prob / 2
            )

            next_dp[pos + 1] = (
                next_dp.get(pos + 1, Fraction(0))
                + prob / 2
            )

    dp = next_dp

# ---------------------------------------------------------
# Final probability
# ---------------------------------------------------------

answer = sum(dp.values())

print(answer)
print(answer.numerator)
print(answer.denominator)
```---

 # コードのチュートリアル

 ### プライムふるい

 まず、どの整数が次から得られるかを計算します。$1$に$500$プライムです。 

### 初期状態```python
dp = {x: Fraction(1, N) for x in range(1, N + 1)}
```カエルは均一にランダムに開始します。 

### それぞれの鳴き声を処理する

 現在の位置ごとに次のようになります。 

1. そこで観察された鳴き声が聞こえる確率を掛けます。 
2. 確率質量を隣接する正方形に分配します。 

内部の広場では:```python
prob / 2
```左右に行きます。 

エンドポイントで:```python
1 -> 2
500 -> 499
```確率的に$1$。 

### 正確な算術演算

 使用する`Fraction`浮動小数点エラーがないことを保証します。

 # 最終確認

 分母には次の累乗が含まれている必要があります。 

-$500$初期配布から、
 -$3^{15}$鳴き声の確率から、
 -$2^{14}$ジャンプから。 

確かに、$$29386561536000 = 500 \cdot 3^{15} \cdot 2^{14},$$これはまさに予想通りの構造です。 

得られた還元分率は、$$\frac{199740353}{29386561536000}.$$したがって、計算は内部的に一貫しています。

 **答え: 199740353/29386561536000**
