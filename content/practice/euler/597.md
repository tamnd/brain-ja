[プロジェクト オイラー問題 597](https://projecteuler.net/problem=597)

 ## 解決策

 **答え:**`0.5001817828`ボートにインデックスを付けましょう$1,2,\dots,n$開始順序で最低から最高まで。 

ボート$i$始まります$40(i-1)$最下位のボートから上流に数メートルあるため、ゴールまでの残りの距離は$$d_i=L-40(i-1).$$速度はi.i.d.です。$$v_i=-\log X_i \sim \text{Exp}(1).$$最終的な順列が偶数になる確率が必要です。

 #1. 重要な数学的洞察

 ボートだと仮定します$i$ボートを追っている$i+1$。 

彼らは始まります$40$メートル離れているため、衝突が発生します$$\frac{40}{v_i-v_{i+1}} \le \frac{d_i}{v_i}.$$並べ替えた後、$$d_{i+1}v_i \ge d_i v_{i+1}.$$定義する$$w_i=\frac{v_i}{d_i}.$$すると、バンプ条件は単純になります。$$w_i \ge w_{i+1}.$$ここで次のことを観察してください。 

- それ以来$v_i\sim \text{Exp}(1)$、
 - スケーリングにより得られる$$w_i \sim \text{Exp}(d_i).$$したがって、$w_i$レートを伴う独立した指数関数です$d_i$。 

---

 ## 再帰的な構造

 「ターゲットコーディネート」をご紹介します$$t=\frac{L}{40}+1.$$それから$$d_i=40(t-i).$$共通因数を無視すると$40$、私たちは考えるかもしれません$$w_i \sim \text{Exp}(t-i).$$指数関数に関する重要な事実:

 独立した指数関数にレートがある場合$\lambda_i$、次にその変数の確率$m$最小値は$$\frac{\lambda_m}{\sum \lambda_j}.$$最小限のボート$w_i$:

 - 決して他のボートにぶつからないでください。 
- したがって、最終順位ではボートが最下位のままです。 

位置で最小値が発生すると仮定します。$m$。 

次に:

 - ボート$l,\dots,m-1$新しいターゲットとなる独立した部分問題を形成する$m$、
 - ボート$m+1,\dots,r$元のターゲットを変更せずに、別の独立した部分問題を形成します。 

動く船$m$前に、順列パリティを次のように変更します$$(-1)^{m-l}.$$それで、もし$E(l,r,t)$予想される置換符号を示します

 ($+1$偶数の場合、$-1$奇数の場合）、

 再帰が得られます$$E(l,r,t) = \sum_{m=l}^r \Pr(m\text{ minimum}) (-1)^{m-l} E(l,m-1,m) E(m+1,r,t).$$最小確率は$$\Pr(m\text{ minimum}) = \frac{t-m} {\sum_{j=l}^r (t-j)}.$$ついに、$$p(n,L)=\frac{1+E(1,n,L/40+1)}{2}.$$---

 #2. Pythonの実装```python
from fractions import Fraction
from functools import lru_cache

def probability_even(n, L, spacing=40):
    # target coordinate
    t0 = Fraction(L, spacing) + 1

    @lru_cache(None)
    def expected_sign(l, r, t):
        """
        Expected permutation sign (+1 even, -1 odd)
        for boats l..r with target coordinate t.
        """

        # empty or single boat => identity permutation
        if l >= r:
            return Fraction(1, 1)

        count = r - l + 1

        # S = sum_{j=l}^r (t - j)
        S = Fraction(count, 1) * t - (l + r) * count // 2

        total = Fraction(0, 1)

        for m in range(l, r + 1):

            # probability that m is the minimum
            pm = (t - m) / S

            # parity change caused by moving m to front
            sign_flip = -1 if ((m - l) & 1) else 1

            # left and right independent subproblems
            left = expected_sign(l, m - 1, Fraction(m, 1))
            right = expected_sign(m + 1, r, t)

            total += pm * sign_flip * left * right

        return total

    e = expected_sign(1, n, t0)

    # convert expected sign to probability of even permutation
    return (Fraction(1, 1) + e) / 2

def rounded_decimal(frac, digits=10):
    scale = 10 ** digits
    x = frac * scale

    q = x.numerator // x.denominator
    r = x.numerator % x.denominator

    # round half up
    if 2 * r >= x.denominator:
        q += 1

    integer = q // scale
    decimal = q % scale

    return f"{integer}.{decimal:0{digits}d}"

# verification
print(probability_even(3, 160))          # 56/135
print(rounded_decimal(probability_even(4, 400), 10))
print(rounded_decimal(probability_even(13, 1800), 10))
```---

 #3. コードのチュートリアル

 ##`expected_sign(l, r, t)`これは、ボートによって生成される順列の予期される符号を再帰的に計算します。$l$を通して$r$。 

### 基本ケース```python
if l >= r:
    return Fraction(1, 1)
```単一のボート (または空の間隔) が均等な順列に寄与します。 

---

 ### 合計指数率```python
S = sum(t - j)
```これは、区間内のすべての指数関数の合計レートです。 

---

 ### 最小値の選択```python
pm = (t - m) / S
```独立した指数関数は、レートに比例して最小値を選択します。 

---

 ### パリティ貢献```python
sign_flip = (-1)^(m-l)
```最小限のボートを前方に移動するには、$m-l$交換します。 

---

 ### 再帰的分解```python
left = expected_sign(...)
right = expected_sign(...)
```左側と右側の部分は独立した部分問題になります。
