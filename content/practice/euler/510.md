 #1. 数学的分析

 接線を配置します$L$として$x$-軸。 

次に:

 - サークル$A$中心がある$(0,a)$、
- 丸$B$中心がある$(2\sqrt{ab},\,b)$、

 同じ線に接し、互いに接する 2 つの円は次の条件を満たすためです。$$(\Delta x)^2=(a+b)^2-(a-b)^2=4ab.$$今度は円を配置します$C$センター付き$(x,c)$。 

以来$C$に接している$A$、$$x^2=(a+c)^2-(a-c)^2=4ac,$$したがって$$x=2\sqrt{ac}.$$同様に、$B$与える$$(2\sqrt{ab}-x)^2=4bc.$$代わりの$x=2\sqrt{ac}$:$$(2\sqrt{ab}-2\sqrt{ac})^2=4bc.$$で割る$4$:$$(\sqrt{ab}-\sqrt{ac})^2=bc.$$幾何学的構成で平方根を取ると、次の結果が得られます。$$\sqrt{ab}=\sqrt{ac}+\sqrt{bc}.$$因数分解$\sqrt c$:$$\sqrt{ab}=\sqrt c(\sqrt a+\sqrt b).$$したがって$$\boxed{\sqrt c=\frac{\sqrt{ab}}{\sqrt a+\sqrt b}}$$そして$$\boxed{c=\frac{ab}{(\sqrt a+\sqrt b)^2}}.$$---

 ## 整数のパラメータ化

 のために$c$積分であるためには、次のように書きます$$a=dx^2,\qquad b=dy^2,$$どこ$x,y$は互いに素である。 

それから$$c=\frac{d^2x^2y^2}{d(x+y)^2} =\frac{dx^2y^2}{(x+y)^2}.$$以来$$\gcd(x+y,xy)=1$$素数のため$x,y$、私たちは持っている必要があります$$(x+y)^2\mid d.$$それで、しましょう$$d=k(x+y)^2.$$そうすると、あらゆる解決策は、$$\boxed{ \begin{aligned} a&=k\,x^2(x+y)^2,\\ b&=k\,y^2(x+y)^2,\\ c&=k\,x^2y^2, \end{aligned}}$$と$$\gcd(x,y)=1,\qquad x\le y,\qquad k\ge1.$$---

 ## への貢献$S(n)$以来$b\le n$、$$k\,y^2(x+y)^2\le n.$$定義する$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$固定共素の場合$x,y$、有効な値は次のとおりです。$k=1,\dots,M$。 

今$$a+b+c = k\Big((x+y)^2(x^2+y^2)+x^2y^2\Big).$$したがって、合計貢献度は次のようになります。$$\Big((x+y)^2(x^2+y^2)+x^2y^2\Big) \sum_{k=1}^{M}k.$$使用する$$\sum_{k=1}^{M}k=\frac{M(M+1)}2,$$私たちは得る$$\boxed{ S(n)= \sum_{\substack{x\le y\\ \gcd(x,y)=1}} \left((x+y)^2(x^2+y^2)+x^2y^2\right) \frac{M(M+1)}2 }$$どこ$$M=\left\lfloor \frac{n}{y^2(x+y)^2}\right\rfloor.$$これは効率的であるため、$$y^2(x+y)^2\le n$$についてだけを意味します$O(\sqrt n)$関連するペア。 

---

 #2. Pythonの実装```python
from math import gcd, isqrt

def S(n):
    total = 0

    # y^2 (x+y)^2 <= n
    # so y is at most sqrt(n)
    limit = isqrt(n)

    for y in range(1, limit + 1):
        for x in range(1, y + 1):

            # primitive pairs only
            if gcd(x, y) != 1:
                continue

            denom = y * y * (x + y) * (x + y)

            if denom > n:
                break

            M = n // denom

            base = (x + y) * (x + y) * (x * x + y * y)
            base += x * x * y * y

            total += base * M * (M + 1) // 2

    return total

print(S(5))       # 9
print(S(100))     # 3072
print(S(10**9))
```---
