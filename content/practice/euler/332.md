[プロジェクト オイラー問題 332](https://projecteuler.net/problem=332)

 ## 解決策

 **答え:**`2717.751525`球面三角形の3つの頂点を球面上に置く$x^2+y^2+z^2=r^2$整数ベクトルであること$$\mathbf a,\mathbf b,\mathbf c \in \mathbb Z^3, \qquad \|\mathbf a\|=\|\mathbf b\|=\|\mathbf c\|=r.$$私たちはあらゆるものを見つけなければなりません$1\le r\le 50$、最小の非縮退球面三角形領域を求め、それらを合計します。 

---

 #1. 数学的分析

 半径の球上の球面三角形$r$面積がある$$A = r^2 E,$$どこ$E$は球面の余剰です。 

単位ベクトルの場合$\mathbf u,\mathbf v,\mathbf w$、標準的なアイデンティティは次のようになります。$$E = 2\arctan\!\left( \frac{|\mathbf u\cdot(\mathbf v\times\mathbf w)|} {1+\mathbf u\cdot\mathbf v+\mathbf v\cdot\mathbf w+\mathbf w\cdot\mathbf u} \right).$$私たちのポイントは半径上にあるので$r$、$$\mathbf u=\frac{\mathbf a}{r}, \quad \mathbf v=\frac{\mathbf b}{r}, \quad \mathbf w=\frac{\mathbf c}{r}.$$式に代入します。$$\mathbf u\cdot(\mathbf v\times\mathbf w) = \frac{\det(\mathbf a,\mathbf b,\mathbf c)}{r^3},$$そして$$1+\mathbf u\cdot\mathbf v+\mathbf v\cdot\mathbf w+\mathbf w\cdot\mathbf u = \frac{ r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a }{r^2}.$$したがって$$E = 2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right).$$したがって、球面面積は、$$\boxed{ A = 2r^2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right) }.$$三角形はまさに次の場合に縮退します。$$\det(\mathbf a,\mathbf b,\mathbf c)=0,$$なぜなら、その 3 つの点は同じ大円上にあるからです。 

したがって、アルゴリズムは次のようになります。 

1. 球上のすべての整数点を生成します$x^2+y^2+z^2=r^2$。 
2. トリプルを列挙します。 
3. 行列式を無視する$0$。 
4. 上記の面積式を計算します。 
5. 最低限のものを守る。 

---

 #2. Pythonの実装```python
import numpy as np
from math import isqrt

# ------------------------------------------------------------
# Generate all lattice points on x^2 + y^2 + z^2 = r^2
# ------------------------------------------------------------
points_by_r = {}

for r in range(1, 51):
    pts = []
    r2 = r * r

    for x in range(-r, r + 1):
        xx = x * x

        for y in range(-r, r + 1):
            zz = r2 - xx - y * y

            if zz < 0:
                continue

            z = isqrt(zz)

            if z * z == zz:
                pts.append((x, y, z))

                if z != 0:
                    pts.append((x, y, -z))

    points_by_r[r] = np.array(pts, dtype=np.int64)

# ------------------------------------------------------------
# Compute the minimum spherical triangle area for radius r
# ------------------------------------------------------------
def minimum_area(r):
    P = points_by_r[r]
    n = len(P)

    rr = r * r
    best = float("inf")

    # dot-product matrix
    D = P @ P.T

    for i in range(n - 2):

        A = P[i]

        # Cross products with all later points
        crosses = np.cross(A, P[i + 1:])

        for offset, c in enumerate(crosses, start=i + 1):

            # determinants with remaining points
            dets = np.abs(P[offset + 1:] @ c)

            mask = dets != 0
            if not mask.any():
                continue

            dets = dets[mask]

            # denominator term
            S = (
                D[i, offset]
                + D[offset, offset + 1:]
                + D[offset + 1:, i]
            )

            S = S[mask]

            denom = r * (rr + S)

            # area formula
            areas = 2 * rr * np.arctan2(dets, denom)

            m = areas.min()

            if m < best:
                best = float(m)

    return best

# ------------------------------------------------------------
# Sum A(r)
# ------------------------------------------------------------
total = 0.0

for r in range(1, 51):
    total += minimum_area(r)

print(f"{total:.6f}")
```---

 #3. コードのチュートリアル

 ### 格子点の生成

 それぞれについて$r$:```python
x^2 + y^2 + z^2 = r^2
```徹底的にチェックされています。 

いつでも$z^2$が完全な正方形である場合、対応する点を追加します。 

---

 ### 縮退テスト

 ベクターの場合$\mathbf a,\mathbf b,\mathbf c$、```python
det = abs(c · (a × b))
```これがゼロの場合、点は 1 つの大円上にあるため、三角形は除外されます。 

---

 ### 面積計算

 実装された式は正確に$$A = 2r^2\arctan\!\left( \frac{ |\det(\mathbf a,\mathbf b,\mathbf c)| }{ r\left(r^2+\mathbf a\cdot\mathbf b+\mathbf b\cdot\mathbf c+\mathbf c\cdot\mathbf a\right) } \right).$$---

 ### チェック例

 のために$r=14$、プログラムは与えます$$A(14)=3.294040110677\ldots$$これは問題のステートメントと一致します。$$3.294040$$小数点以下 6 桁まで。

 結果は、最小の三角形が比較的大きくなる可能性がある、非常に少数の格子点 (たとえば 2 の累乗) を持つ球によって支配されます。 計算された値はすべて正であり、ジオメトリと一致しています。
