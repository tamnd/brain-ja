[プロジェクト オイラー問題 269](https://projecteuler.net/problem=269)

 ## 解決策

 **答え:**`1311109198529286`させて$$P_n(x)=a_mx^m+a_{m-1}x^{m-1}+\cdots+a_0$$どこ$a_ma_{m-1}\cdots a_0$は次の 10 進数です$n$。 

私たちは求めています$$Z(10^{16})$$= 正の整数の数$n\le 10^{16}$そのような$P_n(x)$**少なくとも 1 つの整数ルート**があります。 

---

 ## 1. 数学的分析

 ### ステップ 1: 可能な整数根を制限する

 係数は数字なので$0,\dots,9$、すべての係数は負ではなく、先頭の係数は正です。 

もし$r>0$、 それから$$P_n(r)>0$$すべての項が非負であり、先頭の項が正であるためです。 

したがって、**正のルートは不可能**です。 

整根定理により、整数根は定数項 (最後の桁) を除算する必要があるため、整数根は次の位置になければなりません。$$\{0,-1,-2,\dots,-9\}.$$したがって、ルート候補は **10 個**しかありません。 

---

 ### ステップ 2: 多項式評価を再定式化する

 次の 10 進数を仮定します。$n$は$$d_1d_2\cdots d_L.$$それから$$P_n(r) = (((d_1r+d_2)r+d_3)\cdots)r+d_L.$$ホーナー再発です。 

私たちが望んでいるのは:$$P_n(r)=0.$$固定ルートの場合$r$、状態を逆方向に定義します。 

接尾辞の後に値が必要な場合$t$、その後、前の状態$p$満たさなければなりません$$pr+d=t.$$したがって$$p=\frac{t-d}{r}.$$各桁ごとに$d\in\{0,\dots,9\}$、この先行者は一意に決定されるか、不可能です。 

これにより、動的プログラミングが非常に効率的になります。 

---

 ### ステップ 3: 包含と除外

 多項式に**少なくとも1つ**の整数根を持つ数値が必要です。$$R=\{0,-1,-2,\dots,-9\}.$$任意のサブセットに対して$S\subseteq R$、 させて$N(S)$多項式が**根ごとに消える整数の数になります。$S$。 

次に、包含と除外によって次のようになります。$$Z = \sum_{\emptyset\neq S\subseteq R} (-1)^{|S|+1}N(S).$$あるのは$$2^{10}-1=1023$$空ではないサブセットなので、これは実現可能です。

 ## 2. Python の実装```python
from functools import lru_cache

# Candidate integer roots:
# index 0 -> root 0
# index i -> root -i for i=1..9
ROOTS = [0] + [-i for i in range(1, 10)]

cache = {}

def count_subset(mask, length):
    """
    Count length-digit numbers whose polynomial
    vanishes at every root specified by 'mask'.
    """

    key = (mask, length)
    if key in cache:
        return cache[key]

    # Root 0 means last digit must be 0
    need_zero_root = (mask & 1) != 0

    # Negative roots included in this subset
    roots = [-i for i in range(1, 10) if (mask >> i) & 1]

    @lru_cache(None)
    def dp(rem_digits, targets):
        """
        rem_digits = number of digits still to place
        targets = tuple of required evaluation states
                  for each root
        """
        if rem_digits == 0:
            return 1 if all(t == 0 for t in targets) else 0

        total = 0

        for d in range(10):

            # Leading digit cannot be zero
            if rem_digits == 1 and d == 0:
                continue

            # Root 0 condition: LSD must be zero
            if need_zero_root and rem_digits == length and d != 0:
                continue

            prev_states = []
            ok = True

            # Backward transition:
            # p * r + d = target
            for r, t in zip(roots, targets):
                numerator = t - d

                if numerator % r != 0:
                    ok = False
                    break

                prev_states.append(numerator // r)

            if ok:
                total += dp(rem_digits - 1, tuple(prev_states))

        return total

    result = dp(length, tuple([0] * len(roots)))
    cache[key] = result
    return result

def compute_Z(limit_power):
    total = 0

    # Count numbers < 10^limit_power
    for length in range(1, limit_power + 1):
        union_count = 0

        for mask in range(1, 1 << 10):
            c = count_subset(mask, length)

            # Inclusion–exclusion
            if mask.bit_count() % 2 == 1:
                union_count += c
            else:
                union_count -= c

        total += union_count

    # Add 10^16 itself
    # P_{10^16}(x) = x^16, root x=0
    total += 1

    return total

print(compute_Z(16))

 ## 3. コードのチュートリアル

 ### 候補ルート

 私たちはテストするだけです$$0,-1,-2,\dots,-9$$他の整数根はあり得ないからです。 

###`count_subset(mask, length)`これは重要です$L$- **サブセット内のすべての根**で多項式が消える桁の数値。 

ビットマスクはサブセットをエンコードします。 

例:

 - ビット0 → ルート$0$- ビット 1 → ルート$-1$- ビット 2 → ルート$-2$など

 ### 動的プログラミング

 **最下位桁から逆方向に**数値を構築します。 

現在次のものが必要だとします。$$P(r)=t.$$桁の選択$d$前の状態を強制します。$$p=\frac{t-d}{r}.$$割り切れない場合、その桁は不可能です。 

メモ化により、繰り返される状態が非常に高速になります。 

### 包含と除外

 空でないすべてのサブセットを合計します。$$\sum (-1)^{|S|+1}N(S).$$これにより、**少なくとも 1 つ**の整数根を持つ数値が正しくカウントされます。
