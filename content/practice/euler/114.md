[プロジェクト オイラー問題 114](https://projecteuler.net/problem=114)

 ## 解決策

 **答え:**`16475640049`させて$F(n)$ある長さの行を埋める方法の数を示します$n$使用:

 - 灰色の長さの正方形$1$、
 - 少なくとも長さの赤いブロック$3$、
 - 2 つの赤いブロックの間に少なくとも 1 つの灰色の正方形がある。 

計算するように求められます$F(50)$。 

---

 # 数学的分析

 第一原理から漸化式を導き出します。 

## ステップ 1: 構造を理解する

 長さの行の左端の位置を考慮します$n$。 

次の 2 つの可能性があります。 

### ケース 1 — 最初の四角形は灰色です

 それから残りは$n-1$ポジションを埋めることができます$F(n-1)$方法。 

貢献：$$F(n-1)$$---

 ### ケース 2 — 最初のピースは赤いブロックです

 最初の赤いブロックに長さがあると仮定します。$k$、 どこ$$k \ge 3$$2 つのサブケースがあります。 

#### サブケース A: ブロックが最後に到達する

 もし$k=n$、これはちょうど 1 つの配置に貢献します。 

#### サブケース B: ブロックの後にスペースが残る

 もし$k<n$、その場合、次の正方形は灰色 (セパレータ) でなければならず、1 つの余分な単位を消費します。 

したがって、配置した後:

 - 長さの赤いブロック$k$、
 - 必須の灰色の四角形 1 つ、

 残りの長さは$$n-k-1$$記入できるもの$$F(n-k-1)$$方法。 

したがって、固定の場合$k<n$、貢献度は次のとおりです。$$F(n-k-1)$$---

 ## ステップ 2: 繰り返しを構築する

 すべてのケースを組み合わせると、次のようになります。$$F(n) = F(n-1) + 1 + \sum_{k=3}^{n-1} F(n-k-1)$$の$+1$ちょうど同じ長さの赤いブロックが配置された配置に対応します$n$行を埋めます。 

---

 ## ステップ 3: 初期条件

 行の長さが以下の場合$3$、赤いブロックは入りません。 

したがって、すべて灰色の配置のみが存在します。$$F(0)=F(1)=F(2)=1$$問題文には次のように書かれています$n=7$がある$17$方法があるので、それを使って検証できます。 

---

 # Pythonの実装```python
def count_ways(n):
    # F[i] = number of valid fillings for length i
    F = [0] * (n + 1)

    # Base cases
    F[0] = 1
    if n >= 1:
        F[1] = 1
    if n >= 2:
        F[2] = 1

    # Compute values bottom-up
    for length in range(3, n + 1):

        # Case 1: first square is grey
        total = F[length - 1]

        # Case 2: first block is red
        for block_len in range(3, length + 1):

            if block_len == length:
                # Red block fills the entire row
                total += 1
            else:
                # Need one grey separator after the block
                total += F[length - block_len - 1]

        F[length] = total

    return F[n]

# Verify small example
print(count_ways(7))   # should be 17

# Compute required answer
print(count_ways(50))
```---
