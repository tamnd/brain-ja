 ## 解決策

 **答え:**`336785000760344621`すべての非負の整数を多項式として解釈します。$\mathbb F_2$バイナリ展開を係数として読み取ることによって。 

例えば$$13 = 1101_2 \longleftrightarrow x^3+x^2+1.$$この通信では次のようになります。 

- XOR は多項式加算になります$\mathbb F_2$、
 - XOR積$\otimes$通常の多項式乗算になります$\mathbb F_2$。 

つまり、問題は実際に内部で起こっているのです$\mathbb F_2[x]$。 

---

 #1. 方程式を書き直す

 しましょう$$A(x)\leftrightarrow a,\qquad B(x)\leftrightarrow b.$$方程式$$(a\otimes a)\oplus (2\otimes a\otimes b)\oplus (b\otimes b)=5$$になる$$A^2+xAB+B^2=x^2+1.$$(ここでは整数$2$多項式に対応します$x$、 そして$5=101_2$に対応する$x^2+1$。）

 したがって、解決しなければなりません$$A^2+xAB+B^2=x^2+1. \tag{1}$$---

 # 2. 二次拡張の導入

 しましょう$u$満足する$$u^2+xu+1=0.$$次に共役を定義します$$\bar u = x+u.$$確かに、$$u+\bar u=x,\qquad u\bar u=1.$$ここで考えてみましょう$$z=A+Bu.$$その標準は$$N(z)=z\bar z=(A+Bu)(A+B\bar u).$$特徴の拡大$2$、$$N(z)=A^2+xAB+B^2.$$したがって、式 (1) は正確に次のようになります。$$N(z)=x^2+1=(x+1)^2. \tag{2}$$---

 #3. すべてのソリューションを生成する

 なぜなら$$N(u)=u\bar u=1,$$任意の解に次のべき乗を乗算します。$u$規範を守ります。 

基本的な解決策は、$$(A,B)=(0,x+1),$$なぜなら$$0^2+0+(x+1)^2=x^2+1.$$整数ではこれは$(a,b)=(0,3)$。 

ここで繰り返し乗算します$u$。 

仮定する$$A_n+B_nu=(x+1)u^n.$$それから$$(A_{n+1},B_{n+1})$$を乗算することで得られます$u$:$$(A_n+B_nu)u = B_n + (A_n+xB_n)u.$$したがって、$$A_{n+1}=B_n, \qquad B_{n+1}=A_n+xB_n.$$整数に戻すと、次のようになります。 

- の乗算$x$1ビット左シフト、
 - 加算は XOR です。 

したがって$$a_{n+1}=b_n, \qquad b_{n+1}=a_n\oplus (2b_n). \tag{3}$$から始まる$$(a_0,b_0)=(0,3),$$私たちは得る$$\begin{aligned} (0,3),\\ (3,6),\\ (6,15),\\ (15,24),\\ (24,63),\ldots \end{aligned}$$まさに例と一致します。 

この二次拡張における独自の因数分解から、**すべて** の解がこのようにして得られることがわかります。 

したがって$X(N)$は単にすべての XOR です$b_n\le N$。 

---

 #4. 効率的な計算

 再発は次のとおりです。$$(a,b)\mapsto (b,\ a\oplus (b\ll 1)).$$くらいしかありません$60$以下の条件$10^{18}$したがって、直接の反復は簡単です。 

---

 #5. Pythonの実装```python
def compute_X(N):
    # Initial solution
    a, b = 0, 3

    ans = 0

    while b <= N:
        ans ^= b

        # Next solution:
        # a' = b
        # b' = a XOR (b << 1)
        a, b = b, a ^ (b << 1)

    return ans

# Verification of the small example
print(compute_X(10))      # should be 5

# Final answer
print(compute_X(10**18))
```---
