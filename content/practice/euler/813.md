 ## 解決策

 **答え:**`14063639`させて$$a \otimes b$$は XOR 積を示します。 

重要な観察は、XOR 積が体上の 2 進多項式の正確な乗算であるということです。$\mathbb F_2$。 

---

 #1. 数学的分析

 整数をバイナリで書き込みます。$$n=\sum n_i2^i,\qquad n_i\in\{0,1\}$$それに多項式を関連付けます$$f_n(x)=\sum n_i x^i$$以上$\mathbb F_2$。 
基数での通常のlong乗算$2$加算を XOR で置き換えたもので、正確には多項式乗算のモジュロです。$2$。 したがって：$$f_{a\otimes b}(x)=f_a(x)f_b(x).$$---

 ## ステップ 1: に対応する多項式$11$

$$11_{10}=1011_2$$それで$$f(x)=x^3+x+1.$$したがって$$P(n)=11^{\otimes n}$$に対応する$$f(x)^n.$$---

 #2. 指数構造の活用

 必要です$$P(8^{12}\cdot 12^8).$$指数を因数分解します。$$8^{12}\cdot 12^8 =(2^3)^{12}(2^2\cdot 3)^8 =2^{36} \cdot 2^{16}\cdot 3^8 =2^{52}3^8.$$したがって、$$P(8^{12}12^8) =f(x)^{2^{52}3^8}.$$---

 ## ステップ 2: フロベニウス マップ$\mathbb F_2$特徴的には$2$、$$(a+b)^2=a^2+b^2.$$したがって、任意の多項式に対して$g(x)$、$$g(x)^{2^k}=g(x^{2^k}).$$それで：$$f(x)^{2^{52}3^8} = \left(f(x)^{3^8}\right)^{2^{52}} = f(x^{2^{52}})^{3^8}.$$させて$$f(x)^{3^8}=\sum_i c_i x^i, \qquad c_i\in\{0,1\}.$$それから$$f(x)^{2^{52}3^8} = \sum_i c_i x^{i2^{52}}.$$最後に、整数に戻すということは、次のように評価することを意味します。$x=2$:$$P(8^{12}12^8) = \sum_i c_i 2^{i2^{52}}.$$モジュロ$M=10^9+7$、 定義する$$r=2^{2^{52}} \pmod M.$$それから$$P(8^{12}12^8)\equiv \sum_i c_i r^i \pmod M.$$したがって、タスクは次のようになります。 

1. コンピューティング$f(x)^{6561}$以上$\mathbb F_2$、
 2. で評価します。$r$。

 #3. Pythonの実装```python
MOD = 10**9 + 7

# Polynomial for 11 = 1011_2 = x^3 + x + 1
# Bit i = coefficient of x^i
f = (1 << 0) | (1 << 1) | (1 << 3)

# XOR-polynomial multiplication over GF(2)
def mul(a, b):
    res = 0
    shift = 0

    while b:
        if b & 1:
            res ^= (a << shift)
        shift += 1
        b >>= 1

    return res

# Fast exponentiation of polynomials over GF(2)
def poly_pow(a, n):
    res = 1

    while n:
        if n & 1:
            res = mul(res, a)

        a = mul(a, a)
        n >>= 1

    return res

# Compute f(x)^(3^8)
g = poly_pow(f, 3**8)

# r = 2^(2^52) mod MOD
r = pow(2, 2**52, MOD)

# Evaluate polynomial g at r modulo MOD
ans = 0
power = 1

while g:
    if g & 1:
        ans = (ans + power) % MOD

    power = (power * r) % MOD
    g >>= 1

print(ans)
```---
