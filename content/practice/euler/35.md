[プロジェクト オイラー問題 35](https://projecteuler.net/problem=35)

 ## 解決策

 **答え:**`55`## 1. 数学的分析

 **循環素数**は、**その数字のすべての循環回転も素数**となるような素数です。 

例えば：$$197 \to 971 \to 719$$3つとも素数なので、$197$円形です。 

すべての円周素数を数えたい**以下$10^6$**。 

### 重要な洞察 1: ローテーション

 数字に桁がある場合$d_1d_2\dots d_k$、その後、その回転は、先頭の数字を最後に移動することによって形成されます。 

例えば：$$197 \to 971 \to 719$$アルゴリズム的に:

 - 数値を文字列に変換します。 
- 回転:

 -`"197"`→`"971"`-`"971"`→`"719"`- 整数に変換し直します。 

**すべての回転が素数**である場合、数値は円周素数です。 

---

 ### 重要な洞察 2: 数字の削除

 2 桁以上の数字の場合:

 任意の数字が次の場合:$$0,2,4,5,6,8$$その場合、回転が偶数桁で終了するか、$5$、それを複合化します。 

例：$$23 \to 32$$

$32$偶数→素数ではない。 

例：$$157 \to 571 \to 715$$

$715$で終わる$5$→合成。 

したがって、 **1 桁の素数を除く$2$そして$5$**、すべての円周素数は数字のみを使用する必要があります。$$\{1,3,7,9\}$$これにより、検索スペースが大幅に減少します。 

---

 ### 重要な洞察 3: 高速素数性テスト

 多くのプライムチェックが必要なので、**エラトステネスのふるい**が最適な方法です。 

100 万未満のすべての素数を生成します。 

- 素数のブール配列を作成します。 
- 各素数の倍数を合成としてマークします。 
- プライムルックアップは次のようになります。$O(1)$。 

時間計算量:$$O(n \log\log n)$$ふるいの場合は、後で安価な回転チェックを行います。 

---

 ### アルゴリズム

 1. 最大のプライムふるいを構築します。$10^6$。 
2. 各素数について:

 - すべての桁の回転を生成します。 
- すべての回転が素数であるかどうかを確認します。 
3. 有効な数を数えます。 

最適化:

 - 禁止されている数字を含む番号をスキップする$0,2,4,5,6,8$（を除外する$2,5$）。 

---

 ## 2. Python の実装```python
def count_circular_primes(limit):
    # Build sieve of Eratosthenes
    sieve = [True] * limit
    sieve[0] = sieve[1] = False

    for i in range(2, int(limit ** 0.5) + 1):
        if sieve[i]:
            # Mark multiples as composite
            for j in range(i * i, limit, i):
                sieve[j] = False

    def rotations(n):
        """Generate all cyclic rotations of n."""
        s = str(n)
        return [int(s[i:] + s[:i]) for i in range(len(s))]

    circular_count = 0

    for n in range(2, limit):
        if not sieve[n]:
            continue

        # Skip impossible candidates
        if n > 10 and any(d in "024568" for d in str(n)):
            continue

        # Check all rotations
        if all(sieve[r] for r in rotations(n)):
            circular_count += 1

    return circular_count

# Compute answer
print(count_circular_primes(1_000_000))
```---
