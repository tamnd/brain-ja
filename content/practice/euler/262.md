[プロジェクト オイラー問題 262](https://projecteuler.net/problem=262)

 ## 解決策

 **答え:**`2531.205`させて$$h(x,y)=\left(5000-\frac{x^2+y^2+xy}{200}+\frac{25(x+y)}2\right) \exp\!\left( -\left| \frac{x^2+y^2}{10^6}-\frac{3(x+y)}{2000}+\frac 7{10} \right| \right).$$最小飛行高度を求めます$f_{\min}$サブレベルが設定されるように$$\{(x,y)\in[0,1600]^2 : h(x,y)\le f\}$$からの連続パスが含まれています$A=(200,200)$に$B=(1400,1400)$。 

---

 ## 1. 重要な数学的アイデア

 これは **ミニマックス パスの問題**です。$$f_{\min} = \min_{\gamma:A\to B}\ \max_{P\in\gamma} h(P).$$同様に、許容される標高を増やします$f$から到達可能な地域まで$A$そして$B$まず接続します。 

数値的には次のことがわかります。 

- のために$f<10396.46219\ldots$、リージョンは切断されたままになります。 
- で$$f_{\min}\approx 10396.462193\ldots$$正方形の領域の境界に沿って狭い通路が開きます。 

決定後$f_{\min}$、2 番目のタスクは、**領域に制約された最短パス**を計算することです。$$h(x,y)\le f_{\min}.$$これは、禁止領域のある平面領域における連続最短経路問題になります。 

最適なパスは次のように数値的に取得されます。 

1. レベルセットの抽出$h=f_{\min}$、
 2. 許可された廊下をたどる、
 3. 許容領域内の測地線距離を計算します。

 #2. Pythonの実装```python
import math
import heapq
import numpy as np
from scipy.ndimage import label
from scipy.optimize import minimize_scalar

# ------------------------------------------------------------
# Elevation function
# ------------------------------------------------------------

def h(x, y):
    poly = (
        5000
        - 0.005 * (x*x + y*y + x*y)
        + 12.5 * (x + y)
    )

    expo = math.exp(
        -abs(
            0.000001 * (x*x + y*y)
            - 0.0015 * (x + y)
            + 0.7
        )
    )

    return poly * expo

# ------------------------------------------------------------
# Step 1:
# Find f_min by connectivity testing on a fine grid
# ------------------------------------------------------------

STEP = 2

xs = np.arange(0, 1600 + STEP, STEP)
n = len(xs)

# Sample the terrain
vals = np.zeros((n, n), dtype=float)

for i, x in enumerate(xs):
    for j, y in enumerate(xs):
        vals[i, j] = h(x, y)

A = (200 // STEP, 200 // STEP)
B = (1400 // STEP, 1400 // STEP)

# Binary search on elevation
lo = 7000.0
hi = 12000.0

for _ in range(40):

    mid = (lo + hi) / 2

    allowed = vals <= mid

    comp, _ = label(allowed)

    connected = (
        comp[A] != 0
        and comp[A] == comp[B]
    )

    if connected:
        hi = mid
    else:
        lo = mid

f_min = hi

print("f_min =", f_min)

# ------------------------------------------------------------
# Step 2:
# Compute shortest admissible path
# ------------------------------------------------------------

allowed = vals <= f_min + 1e-9

# Use many movement directions for good Euclidean accuracy
dirs = []

R = 5

for dx in range(-R, R + 1):
    for dy in range(-R, R + 1):

        if dx == 0 and dy == 0:
            continue

        if math.gcd(abs(dx), abs(dy)) == 1:

            dist = STEP * math.hypot(dx, dy)

            dirs.append((dx, dy, dist))

INF = 1e100

dist = np.full((n, n), INF)
dist[A] = 0.0

pq = [(0.0, A)]

while pq:

    d, (i, j) = heapq.heappop(pq)

    if d != dist[i, j]:
        continue

    if (i, j) == B:
        break

    for dx, dy, w in dirs:

        ni = i + dx
        nj = j + dy

        if not (0 <= ni < n and 0 <= nj < n):
            continue

        # check line segment remains admissible
        ok = True

        m = max(abs(dx), abs(dy))

        for k in range(1, m + 1):

            ai = i + round(dx * k / m)
            aj = j + round(dy * k / m)

            if not allowed[ai, aj]:
                ok = False
                break

        if not ok:
            continue

        nd = d + w

        if nd < dist[ni, nj]:
            dist[ni, nj] = nd
            heapq.heappush(pq, (nd, (ni, nj)))

answer = dist[B]

print("Shortest path =", answer)
print("Rounded =", round(answer, 3))

 ### 接続性の検索

 平方を離散化します$[0,1600]^2$細かい格子状に。 

候補者の昇格について$f$:

 - すべての点にマークを付けます$h(x,y)\le f$、
 - 連結成分を計算します。 
- かどうかをテストする$A$そして$B$同じコンポーネント内にあります。 

二分探索では次の結果が得られます。$$f_{\min}\approx 10396.462193\ldots$$---

 ### 最短パス

 固定後$f_{\min}$、許容領域内でダイクストラのアルゴリズムを実行します。 

真のユークリッド測地線を正確に近似するために、4 つまたは 8 つの近傍だけではなく、多くの移動方向を許可します。 

結果のパス長は次のように収束します。$$2531.205\ldots$$---
