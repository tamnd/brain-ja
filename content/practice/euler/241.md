 ## 解決策

 **答え:**`482316491800641154`させて$$p(n)=\frac{\sigma(n)}{n}, \qquad \sigma(n)=\sum_{d\mid n} d.$$全部欲しいです$n\le 10^{18}$そのような$$p(n)=k+\frac12$$ある整数に対して$k$。 同様に、$$\frac{\sigma(n)}{n}=\frac{2k+1}{2},$$したがって、分母を減らすと$p(n)$まさにそうでなければなりません$2$。 

---

 #1. 数学的分析

 書く$$n=\prod p_i^{a_i}.$$の乗法を使用する$\sigma$、$$\frac{\sigma(n)}{n} = \prod_i \frac{p_i^{a_i+1}-1}{p_i^{a_i}(p_i-1)}.$$定義する$$R(n)=\frac{\sigma(n)}{n}.$$以下の短縮形が必要です$R(n)$分母を持つこと$2$。 

---

 ## 重要な再帰的なアイデア

 ある段階で、$$\frac{\sigma(n)}{n}=\frac{A}{B}$$最低の言葉で。 

最終的には欲しい$B=2$。 

構築する代わりに$R(n)$直接的には、半整数に到達するために必要な「欠損係数」を再帰的に追跡します。 

させて$$\frac{rn}{rs}$$次のような縮小分数になります。$$R(n)\cdot \frac{rn}{rs}$$は依然として半整数の候補です。 

最初に、ターゲットの半整数が$$\frac{x}{2} \qquad (x \text{ odd}),$$それから始めましょう$$(rn,rs)=(x,2).$$さて、掛け算をしてみましょう$n$による$p^e$。 それから$$R(np^e) = R(n)\cdot \frac{p^{e+1}-1}{p^e(p-1)}.$$それで更新します$$rn \leftarrow rn\cdot p^e,$$

$$rs \leftarrow rs\cdot \frac{p^{e+1}-1}{p-1},$$そしてgcdで削減します。 

最終的には$$rn=rs=1,$$その場合、必要な残りの要素は$1$, したがって、有効な半整数完全商を達成しました。 

---

 ## 再帰が有限である理由

 すべてのステップで:

 - 最小の素約数を選択します$rs$、
 - 素数を強制的に因数分解します$n$、
 - そして分母構造は急速に崩壊します。 

これにより、非常に小さな検索ツリーが作成されます。 実際、以下に有効な数字は **22** のみです$10^{18}$。 

それらの合計が必要な答えです。

 #2. Pythonの実装```python
from math import gcd

LIMIT = 10**18

def smallest_prime_factor(n):
    """Return the smallest prime factor of n."""
    if n % 2 == 0:
        return 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return d
        d += 2

    return n

solutions = []

def dfs(n, rn, rs):
    """
    Recursive search.

    n  = current integer being built
    rn/rs = remaining correction factor
    """

    # Prune: even the minimal remaining multiplier is too large
    if n * rs > LIMIT:
        return

    # Success condition
    if rn == 1 and rs == 1:
        solutions.append(n)

    # Nothing more to do
    if rs == 1:
        return

    # Force the smallest prime dividing rs
    p = smallest_prime_factor(rs)

    # p must not already divide n
    if gcd(p, n) != 1:
        return

    # exponent of p inside rs
    e = 1
    while rs % (p ** (e + 1)) == 0:
        e += 1

    power = p ** e

    # Try larger exponents as well
    for exp in range(e, 60):

        new_n = n * power

        if new_n > LIMIT:
            break

        # Multiply correction fraction appropriately
        new_rn = rn * power

        sigma_part = (power * p - 1) // (p - 1)

        new_rs = rs * sigma_part

        g = gcd(new_rn, new_rs)

        dfs(new_n, new_rn // g, new_rs // g)

        power *= p

# The target numerator must be odd.
# Small odd starting values are sufficient.
for odd in range(3, 13, 2):
    dfs(1, odd, 2)

answer = sum(solutions)

print(sorted(solutions))
print(answer)
```---

 #4. 小さな例の検証

 のために$n=24$、$$24=2^3\cdot 3.$$それから$$\sigma(24)=1+2+3+4+6+8+12+24=60.$$それで$$\frac{\sigma(24)}{24} = \frac{60}{24} = \frac52 = 2+\frac12.$$それで$24$有効です。 

プログラムにはそれが正しく含まれています。
