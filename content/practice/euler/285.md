[プロジェクト オイラー問題 285](https://projecteuler.net/problem=285)

 ## 解決策

 **答え:**`157055.80999`させて$$x = ka+1,\qquad y = kb+1,$$どこ$a,b\sim U[0,1]$。 

それから$(x,y)$正方形に均一に分布しています$$[1,k+1]\times[1,k+1],$$誰のエリアですか$k^2$。 

アルバートの得点$k$正確にいつを指しますか$$k-\tfrac12 \le \sqrt{x^2+y^2} < k+\tfrac12.$$したがって、円環の内側にある正方形の部分の面積が必要です$$(k-\tfrac12)^2 \le x^2+y^2 < (k+\tfrac12)^2.$$---

 #1. 幾何学的確率

 定義する$$A(R)=\text{area}\left(\{(x,y)\in[1,\infty)^2:x^2+y^2\le R^2\}\right).$$のために$R>1$、円は線と交差します$y=1$で$$x=\sqrt{R^2-1}.$$したがって、$$A(R)=\int_1^{\sqrt{R^2-1}} \left(\sqrt{R^2-x^2}-1\right)\,dx.$$使用する$$\int \sqrt{R^2-x^2}\,dx = \frac12\left( x\sqrt{R^2-x^2} + R^2\arcsin\frac{x}{R} \right),$$簡略化すると次のようになります。$$A(R) = 1-\sqrt{R^2-1} + R^2\left( \frac{\pi}{4}-\arcsin\frac1R \right).$$したがって、固定の望ましい確率は$k$は$$P_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k^2}.$$ターンからの予想スコア貢献度$k$したがって$$E_k = kP_k = \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$したがって、総期待値は次のようになります。$$E = \sum_{k=1}^{10^5} \frac{ A(k+\tfrac12)-A(k-\tfrac12) }{k}.$$---

 #2. Pythonの実装```python
import math

def A(R):
    # For R <= 1 the region is empty
    if R <= 1.0:
        return 0.0

    return (
        1.0
        - math.sqrt(R * R - 1.0)
        + R * R * (math.pi / 4.0 - math.asin(1.0 / R))
    )

def expected_value(n):
    total = 0.0

    for k in range(1, n + 1):
        outer = A(k + 0.5)
        inner = A(k - 0.5)

        total += (outer - inner) / k

    return total

# Check the example from the problem
print(round(expected_value(10), 5))

# Compute the required answer
ans = expected_value(100000)

print(f"{ans:.5f}")
```---
