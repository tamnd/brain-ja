[プロジェクト オイラー問題 236](https://projecteuler.net/problem=236)

 ## 解決策

 **答え:**`123/59`させて

-$A_i$= サプライヤー A が製品に対して提供した番号$i$、
 -$B_i$= サプライヤー B によって提供された番号、
 -$a_i$= A の破損したアイテム、
 -$b_i$= B の破損したアイテム。 

表は次のとおりです。$$\begin{array}{c|cc}  & A & B\\\hline 1 & 5248 & 640\\ 2 & 1312 & 1888\\ 3 & 2624 & 3776\\ 4 & 5760 & 3776\\ 5 & 3936 & 5664 \end{array}$$共通因数を定義する$m>1$B の製品ごとのすべての腐敗率が係数的に A よりも悪い$m$:$$\frac{b_i}{B_i}=m\frac{a_i}{A_i}$$同時に、A の全体的な腐敗率は同じ係数で B よりも悪くなります。$$\frac{\sum a_i}{\sum A_i} = m\frac{\sum b_i}{\sum B_i}.$$可能な最大の合理的な値を見つけなければなりません$m$。 

---

 #1. 数学的分析

 から$$\frac{b_i}{B_i}=m\frac{a_i}{A_i},$$私たちは得る$$b_iA_i = m\,a_iB_i.$$書く$$m=\frac{u}{v}$$最低の言葉で。 それから$$v\,b_iA_i = u\,a_iB_i.$$整数解の場合、次のように定義します。$$g_i=\gcd(uB_i,\;vA_i).$$この場合、一般的な整数解は次のようになります。$$a_i=\frac{vA_i}{g_i}k_i,\qquad b_i=\frac{uB_i}{g_i}k_i,$$正の整数の場合$k_i$。 

---

 全体的な状態は、$$\frac{\sum a_i}{\sum A_i} = \frac{u}{v}\frac{\sum b_i}{\sum B_i}.$$以来$$\sum A_i = 18880,\qquad \sum B_i = 15744,$$の式を代入する$a_i,b_i$与える$$15744\,v^2 \sum_i \frac{A_i}{g_i}k_i = 18880\,u^2 \sum_i \frac{B_i}{g_i}k_i.$$同様に、$$\sum_i \left( 15744\,v^2\frac{A_i}{g_i} - 18880\,u^2\frac{B_i}{g_i} \right)k_i =0.$$したがって、各候補の約分数について$u/v$、正の整数が存在するかどうかを判断するだけで済みます。$k_i$この一次方程式と境界を満たす$$1\le k_i \le \frac{g_i}{u}.$$---

 ## 境界$m$製品比率は、$$\frac{B_i}{A_i}= \left( \frac5{41}, \frac{59}{41}, \frac{59}{41}, \frac{59}{90}, \frac{59}{41} \right).$$全体の方程式から、$$m^2 = \frac{\sum B_i}{\sum A_i} \cdot \frac{\sum a_i}{\sum a_i(B_i/A_i)}.$$の加重平均なので、$B_i/A_i$厳密に最小値を上回っています$5/41$、$$m^2 < \frac{246/295}{5/41} = \frac{10086}{1475},$$したがって$$m<2.615.$$これにより、有限検索が行われます。

 #2. Pythonの実装```python
from fractions import Fraction
from math import gcd

A = [5248, 1312, 2624, 5760, 3936]
B = [640, 1888, 3776, 3776, 5664]

SA = sum(A)   # 18880
SB = sum(B)   # 15744

values = set()
best = Fraction(0, 1)

# m < sqrt(10086/1475) < 2.615
LIMIT = 2.615

for v in range(1, 5000):

    max_u = int(LIMIT * v) + 2

    for u in range(v + 1, max_u):

        # reduced fraction only
        if gcd(u, v) != 1:
            continue

        # g_i = gcd(u*B_i, v*A_i)
        g = [gcd(u * B[i], v * A[i]) for i in range(5)]

        # need k_i >= 1 and k_i <= g_i/u
        max_k = [gi // u for gi in g]

        if min(max_k) < 1:
            continue

        # coefficients of the linear equation
        coeff = [
            SB * v * v * A[i] // g[i]
            - SA * u * u * B[i] // g[i]
            for i in range(5)
        ]

        # Meet-in-the-middle search for:
        # sum(coeff[i] * k_i) = 0

        left = set()

        for k1 in range(1, max_k[0] + 1):
            for k2 in range(1, max_k[1] + 1):
                left.add(coeff[0] * k1 + coeff[1] * k2)

        found = False

        for k3 in range(1, max_k[2] + 1):
            for k4 in range(1, max_k[3] + 1):

                partial = coeff[2] * k3 + coeff[3] * k4

                for k5 in range(1, max_k[4] + 1):

                    if -(partial + coeff[4] * k5) in left:
                        found = True
                        break

                if found:
                    break

            if found:
                break

        if found:
            m = Fraction(u, v)
            values.add(m)

            if m > best:
                best = m

print(len(values))
print(best)
```---

 #3. コードのチュートリアル

 ### ステップ 1

 すべての換算された分数をループします$$m=\frac{u}{v}$$と$1<m<2.615$。 

---

 ### ステップ 2

 各製品について:```python
g = gcd(u * B[i], v * A[i])
```これにより、一般的な整数解が生成されます。$$a_i=\frac{vA_i}{g_i}k_i,\qquad b_i=\frac{uB_i}{g_i}k_i.$$---

 ### ステップ 3

 全体的な損傷状態から線形制約を導き出します。 

係数は次のとおりです。```python
coeff[i] =
SB * v^2 * A[i] / g[i]
-
SA * u^2 * B[i] / g[i]
```そして正の整数を検索します$k_i$満足のいく$$\sum coeff_i\,k_i = 0.$$---

 ### ステップ 4

 中間探索により計算が高速になります。 

プログラムは正確に次のものを見つけます。```python
35
123/59
```ちょうど 35 個の可能な値があるというステートメントと一致します。

 #4. 最終確認

 入手しました$$m=\frac{123}{59}\approx 2.08474576.$$これは理論上の上限を安全に下回っています$2.615$、プログラムは次のことを確認します。 

- ちょうど 35 個の有効な値$m$、
 - 最大値$=123/59$。 

したがって、計算は問題内のすべての条件と一致します。
