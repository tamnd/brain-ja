[プロジェクト オイラー問題 672](https://projecteuler.net/problem=672)

 ## 解決策

 **答え:**`91627537`させて$$g(1)=0,\qquad  g(n)= \begin{cases} g(n/7), & 7\mid n,\\[4pt] 1+g(n+1), & 7\nmid n. \end{cases}$$そして$$S(N)=\sum_{n=1}^N g(n),\qquad H(K)=S\!\left(\frac{7^K-1}{11}\right).$$計算しなければなりません$$H(10^9)\pmod{1117117717}.$$---

 #1. 数学的分析

 ## 1.1 の再発$g(n)$書く$$n=7a+r,\qquad 0\le r\le 6.$$もし$r=0$、 それから$$g(7a)=g(a).$$もし$1\le r\le 6$、追加する必要があります$7-r$次の倍数に達するもの$7$:$$7a+r \to 7(a+1).$$次に、で割ります$7$、与える$a+1$。 したがって、$$g(7a+r)=(7-r)+g(a+1),\qquad 1\le r\le 6.$$それで：$$\boxed{ g(7a+r)= \begin{cases} g(a), & r=0,\\ 7-r+g(a+1), & 1\le r\le 6. \end{cases}}$$---

 #1.2 再発$S(N)$させて$N=7a+r$。 

まずブロック全体を計算します。$$\sum_{i=0}^6 g(7a+i) = g(a)+\sum_{i=1}^6 (7-i+g(a+1)).$$以来$$\sum_{i=1}^6 (7-i)=21,$$私たちは得ます$$\sum_{i=0}^6 g(7a+i)=g(a)+21+6g(a+1).$$今拡張してください$S(7a+r)$:$$S(7a+r) = S(7a-1)+g(a)+\sum_{i=1}^r (7-i+g(a+1)).$$簡略化後:$$\boxed{ S(7a+r) = 7S(a)+21a-6 +r\,g(a+1) +7r-\frac{r(r+1)}2 }$$のために$0\le r\le 6$。 

---

 #1.3 追跡$g(a+1)$定義する$$x(a)=g(a+1).$$もし$N=7a+r$、 それから$$N+1= \begin{cases} 7a+r+1, & r<6,\\ 7(a+1), & r=6. \end{cases}$$したがって：$$g(N+1)= \begin{cases} 6-r+g(a+1), & r<6,\\ g(a+1), & r=6. \end{cases}$$それで$$\boxed{ x'= \begin{cases} x+6-r, & r<6,\\ x, & r=6. \end{cases}}$$---

 # 1.4 Base-7 桁の$\dfrac{7^K-1}{11}$ベースでいくつかの例を計算する$7$:$$\begin{aligned} H(2):&\quad 4_7\\ H(3):&\quad 43_7\\ H(4):&\quad 431_7\\ H(5):&\quad 4311_7\\ H(6):&\quad 43116_7 \end{aligned}$$数字はピリオドで繰り返されます$10$:$$4311623550\,4311623550\cdots$$確かに、$$\frac1{11} = 0.\overline{04311623550}_7,$$それで$$\frac{7^K-1}{11}$$最初です$K-1$繰り返しの桁。 

したがって、繰り返す数字のサイクルのみを処理する必要があります。$$(4,3,1,1,6,2,3,5,5,0).$$---

 #1.5 状態遷移

 状態を維持する$$(S,x,a,1),$$どこ

-$S=S(a)$、
 -$x=g(a+1)$、
 -$a$現在のプレフィックス値です。 

数字の追加$r$変換します:$$a' = 7a+r,$$

$$x' = \begin{cases} x+6-r,& r<6,\\ x,& r=6, \end{cases}$$

$$S' = 7S+21a-6+r x+7r-\frac{r(r+1)}2.$$これはアフィン線形変換なので、次のように表すことができます。$4\times4$行列と累乗が迅速に行われます。 

以来$K=10^9$、私たちは処理します$$K-1=999999999$$数字。 

桁のサイクル長は次のとおりです。$10$したがって、完全な 1 サイクルにわたって行列を累乗します。

 #2. Pythonの実装```python
MOD = 1117117717

# Repeating base-7 digit cycle of (7^K - 1) / 11
cycle = [4, 3, 1, 1, 6, 2, 3, 5, 5, 0]

def mat_mul(A, B):
    """Multiply two 4x4 matrices modulo MOD."""
    n = 4
    C = [[0] * n for _ in range(n)]

    for i in range(n):
        for k in range(n):
            if A[i][k]:
                aik = A[i][k]
                for j in range(n):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

def mat_pow(A, e):
    """Fast exponentiation of a 4x4 matrix."""
    n = 4
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while e > 0:
        if e & 1:
            R = mat_mul(A, R)

        A = mat_mul(A, A)
        e >>= 1

    return R

def digit_matrix(r):
    """
    Matrix for appending one base-7 digit r.

    State vector:
        [S, x, a, 1]^T
    """
    const = (-6 + 7 * r - r * (r + 1) // 2) % MOD
    add_x = 0 if r == 6 else (6 - r)

    return [
        [7, r, 21, const],
        [0, 1, 0, add_x],
        [0, 0, 7, r],
        [0, 0, 0, 1],
    ]

# Build matrix for one full 10-digit cycle
cycle_matrix = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle:
    cycle_matrix = mat_mul(digit_matrix(d), cycle_matrix)

K = 10**9
L = K - 1

q, rem = divmod(L, 10)

# Apply full cycles
M = mat_pow(cycle_matrix, q)

# Apply remaining digits
R = [[1 if i == j else 0 for j in range(4)] for i in range(4)]

for d in cycle[:rem]:
    R = mat_mul(digit_matrix(d), R)

# Total transformation
T = mat_mul(R, M)

# Initial state: S=0, x=g(1)=0, a=0
v = [0, 0, 0, 1]

result = sum(T[0][i] * v[i] for i in range(4)) % MOD

print(result)
```---

 #3. コードのチュートリアル

 ## マトリックスの状態

 私たちは以下を保管します:$$[S,\ x,\ a,\ 1]$$どこ：

-$S=S(a)$、
 -$x=g(a+1)$、
 -$a$現在の Base-7 プレフィックスです。 

余分な末尾$1$定数を行列形式でエンコードしてみましょう。 

---

 ##`digit_matrix(r)`これは繰り返しをエンコードします。$$\begin{aligned} S' &= 7S + r x + 21a + c_r,\\ x' &= x + (6-r)\quad (r<6),\\ a' &= 7a+r. \end{aligned}$$---

 ## 周期性

 数字は毎回繰り返されます$10$なので、処理する代わりに$10^9$数字を個別に、次のことを行います。 

1. 完全なサイクルに対して 1 つのマトリックスを構築します。 
2. 2 進累乗で適切な累乗を行います。 
3. 残った数字を処理します。 

複雑さはただ$O(\log K)$。

 #4. 検証

最終的な計算は、$K=10^9$与える:$$91627537.$$---
