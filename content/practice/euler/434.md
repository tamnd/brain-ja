[Project Euler Problem 434](https://projecteuler.net/problem=434)

 ## 解決策

 **答え:**`863253606`重要な洞察は、これは*実際には剛性の問題ではなく**、**グラフの接続性のカウントの問題**になるということです。 

グリッド セルに対角線を追加すると、対応する行と列が一緒に「ロック」されます。 これにより、2 部グラフが生成されます。 

- 1 つのパーティション =$m$列の方向、
 - 他のパーティション =$n$列の方向、
 - エッジ = セルに追加される対角線。 

グリッドの剛性からの定理は次のように述べています。 

> あん$m\times n$ブレース グリッドは、関連する 2 部グラフが接続されている場合に限り剛体です。 

したがって：$$R(m,n)$$は、サイズの部分を持つ **接続されたラベル付き 2 部グラフ**の正確な数です。$m$そして$n$。 

させて$B(m,n)$このカウントを表します。 2 つの部分間のあらゆる可能なエッジは独立して存在することも存在しないこともあるため、次のようになります。$$2^{mn}$$合計 2 部グラフ。 

接続されたコンポーネントをカウントするには、固定行頂点を含む接続されたコンポーネントを分離することによって包含と除外を使用します。$$B(m,n) = 2^{mn} - \sum_{\substack{1\le a\le m\\0\le b\le n\\(a,b)\neq(m,n)}} \binom{m-1}{a-1} \binom{n}{b} B(a,b) 2^{(m-a)(n-b)}$$説明:

 - 選択します$a-1$識別された行を結合するための追加の行頂点、
 - 選択します$b$柱の頂点、
 - 接続コンポーネントを形成するには、選択した頂点が必要です。$B(a,b)$、
 - 残りの頂点は、それらの間に任意のエッジを持つことができます。$2^{(m-a)(n-b)}$、
 - コンポーネントと外側の間でエッジが交差することはできません。 

すべての DP を計算します$1\le m,n\le100$、合計します$$S(100)=\sum_{i=1}^{100}\sum_{j=1}^{100}R(i,j) \pmod{1000000033}.$$クリーンな Python 実装は次のとおりです。```python
from math import comb

MOD = 1000000033
N = 100

# R[m][n] = number of rigid m x n grids
R = [[0] * (N + 1) for _ in range(N + 1)]

# Precompute powers of 2^(mn)
pow2 = [[pow(2, i * j, MOD) for j in range(N + 1)]
        for i in range(N + 1)]

for m in range(1, N + 1):
    # boundary case needed by recurrence
    R[m][0] = 1 if m == 1 else 0

    for n in range(1, N + 1):
        total = pow2[m][n]

        # subtract disconnected graphs
        for a in range(1, m + 1):
            for b in range(n + 1):

                # skip the full graph itself
                if a == m and b == n:
                    break

                ways_choose = (
                    comb(m - 1, a - 1)
                    * comb(n, b)
                )

                contribution = (
                    ways_choose
                    * R[a][b]
                    * pow2[m - a][n - b]
                )

                total -= contribution

        R[m][n] = total % MOD

# Compute S(100)
answer = 0
for i in range(1, N + 1):
    for j in range(1, N + 1):
        answer += R[i][j]

answer %= MOD
print(answer)
```問題ステートメントに対する検証:

 -$R(2,3)=19$✓
 -$R(5,5)=23679901$✓
 -$S(5)=25021721$✓
