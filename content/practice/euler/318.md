[プロジェクト オイラー問題 318](https://projecteuler.net/problem=318)

 ## 解決策

 **答え:**`709313889`させて$$\alpha=\sqrt p+\sqrt q,\qquad \beta=\sqrt q-\sqrt p$$と$p<q$、$p,q\in \mathbb Z_{>0}$。 

私たちは勉強しています$$\alpha^{2n}.$$重要な観察は次のとおりです$\alpha\beta=q-p$、 そして$$(\sqrt p+\sqrt q)^{2n}+(\sqrt q-\sqrt p)^{2n}$$は常に整数です。 

実際、奇妙な無理項は二項展開で相殺されるため、$$A_n=\alpha^{2n}+\beta^{2n}\in \mathbb Z.$$したがって$$\alpha^{2n}=A_n-\beta^{2n}.$$以来$0<\beta<1$(この条件が重要になります)、小数部分は$$\{\alpha^{2n}\}=1-\beta^{2n}.$$したがって、小数部分は近づきます$1$もし$$\beta<1.$$なぜなら$\beta=\sqrt q-\sqrt p$、許容されるペアはまさに満足のいくペアです。$$\sqrt q-\sqrt p<1.$$---

 私たちが欲しいのは$C(p,q,n)\ge 2011$、つまり、小数点以下が少なくとも 2011 年連続する 9 です。 

つまり、$$1-\beta^{2n}$$とは異なっていなければなりません$1$せいぜい$10^{-2011}$:$$\beta^{2n}\le 10^{-2011}.$$ログの取得:$$2n\ln\beta \le -2011\ln 10.$$以来$\ln\beta<0$、$$n \ge \frac{2011\ln 10}{-2\ln \beta}.$$したがって$$N(p,q) = \left\lceil \frac{2011\ln 10} {-2\ln(\sqrt q-\sqrt p)} \right\rceil.$$これをすべて合計します$$p<q,\qquad p+q\le 2011,\qquad \sqrt q-\sqrt p<1.$$---

 ### Python の実装```python
from math import sqrt, log, ceil

LIMIT = 2011
K = 2011
LN10 = log(10)

total = 0

for p in range(1, LIMIT):
    # q must satisfy p < q and p + q <= LIMIT
    for q in range(p + 1, LIMIT - p + 1):

        beta = sqrt(q) - sqrt(p)

        # Only these pairs have fractional part -> 1
        if beta < 1:
            n = ceil(K * LN10 / (-2 * log(beta)))
            total += n

print(total)
```### コードのチュートリアル

 - すべての整数ペアをループします$(p,q)$と$p<q$そして$p+q\le 2011$。 
- コンピューティング$$\beta=\sqrt q-\sqrt p.$$- 保管のみ$\beta<1$、そうでないので$\beta^{2n}$傾向がない$0$、したがって小数部分は近づきません$1$。 
- コンピューティング$$N(p,q)= \left\lceil \frac{2011\ln 10} {-2\ln \beta} \right\rceil.$$- すべての値を追加します。
