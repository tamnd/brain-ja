[プロジェクト オイラー問題 355](https://projecteuler.net/problem=355)

 ## 解決策

 **答え:**`1726545007`させて$$\operatorname{Co}(n)$$のサブセットの可能な最大合計になります。$\{1,2,\dots,n\}$その要素は**対で互いに素**です。 

重要な観察は、ペアごとに互いに素であるということは、次のことを意味するということです。 

> 選択した複数の数値に素因数が出現することはできません。 

したがって、実際の問題は、選択した整数に素数を割り当てることです。 

### ステップ 1: 自然なベースライン

 すべての素数について$p \le n$を使用すると、$p$まったく、単独での最高の貢献は、**最大の力です。$p$** を超えないこと$n$:$$M(p)=\max\{p^k\le n\}.$$異なる素数の素数べき乗は相互に素であるため、有効なベースラインセットは次のようになります。$$\{1\}\cup \{M(p): p\le n\},$$合計付き$$B = 1 + \sum_{p\le n} M(p).$$例$n=10$:$$M(2)=8,\quad M(3)=9,\quad M(5)=5,\quad M(7)=7$$与える$$1+8+9+5+7=30,$$これが最適です。 

ただし、素数を 1 つの合成物に結合すると、別個の素数累乗よりも優れた場合があります。 

例 （$n=30$）：

- 別：$16+25=41$素数用$2,5$、
 - 結合:$27?$不可能（のみが含まれます）$3$）、
- しかし$2\cdot 13=26$勝つかもしれない$16+13=29$? いいえ。 

一般に、任意の平方素数集合に対して、$S$、 定義する：$$V(S)=\max\{x\le n:\text{ prime factors of }x\text{ are exactly }S\}.$$個別の主力を次のように置き換えます。$V(S)$スコアを変える$$\Delta(S) = V(S)-\sum_{p\in S} M(p).$$とのセットのみ$\Delta(S)>0$案件。 

最適化は次のようになります。 

> 素数集合を選択する$S$総合的な改善を最大化する$\sum \Delta(S)$。 

これは **重み付けセットパッキング/バイナリ整数最適化** 問題です。 

- 変数$x_S\in\{0,1\}$、
 - 各素数は最大 1 つの選択されたセットに出現する可能性があります。 
- トータルゲインを最大化します。 

以来$n=200000$、収益性の高いセットの数は控えめ (約 25,000) ですが、最新の MILP は即座にそれを解決します。 

### Python の実装```python
from sympy import primerange
from scipy.optimize import milp, LinearConstraint, Bounds
import scipy.sparse as sp
import numpy as np

def Co(n):
    primes = list(primerange(2, n + 1))

    # Largest prime power <= n for each prime
    M = {}
    for p in primes:
        x = p
        while x * p <= n:
            x *= p
        M[p] = x

    baseline = 1 + sum(M.values())

    # Smallest prime factor sieve
    spf = list(range(n + 1))
    for i in range(2, int(n**0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, n + 1, i):
                if spf[j] == j:
                    spf[j] = i

    # For each prime set, keep the largest number <= n using exactly those primes
    best = {}

    for x in range(2, n + 1):
        y = x
        prime_set = []

        while y > 1:
            p = spf[y]
            prime_set.append(p)
            while y % p == 0:
                y //= p

        prime_set = tuple(prime_set)

        if x > best.get(prime_set, 0):
            best[prime_set] = x

    # Keep only profitable replacements
    candidates = []

    for prime_set, x in best.items():
        gain = x - sum(M[p] for p in prime_set)

        if gain > 0 and len(prime_set) >= 2:
            candidates.append((gain, prime_set))

    # Build sparse constraint matrix:
    # each prime may be used at most once
    p_index = {p: i for i, p in enumerate(primes)}

    rows, cols, data = [], [], []

    for j, (_, prime_set) in enumerate(candidates):
        for p in prime_set:
            rows.append(p_index[p])
            cols.append(j)
            data.append(1)

    A = sp.coo_matrix(
        (data, (rows, cols)),
        shape=(len(primes), len(candidates))
    ).tocsr()

    # MILP:
    # maximize gains == minimize negative gains
    c = -np.array([gain for gain, _ in candidates], dtype=float)

    constraints = LinearConstraint(
        A,
        -np.inf * np.ones(len(primes)),
        np.ones(len(primes))
    )

    integrality = np.ones(len(candidates), dtype=int)
    bounds = Bounds(
        np.zeros(len(candidates)),
        np.ones(len(candidates))
    )

    result = milp(
        c=c,
        constraints=constraints,
        integrality=integrality,
        bounds=bounds
    )

    return int(round(baseline - result.fun))

# Verification
print(Co(30))   # 193
print(Co(100))  # 1356

# Final answer
print(Co(200000))
```### コードのチュートリアル

2. **すべての整数を因数分解する$x\le n$**

 最小素因数ふるいを使用して、次の異なる素因数を決定します。$x$。 
3. **各素数セットの最良の代表を記録**

 素数サブセットの場合$S$、正確に使用して最大の数値のみを保持します$S$。 
4. **ゲインの計算**

 個別の素数パワーを合成パワーに置き換えることで合計が増加する場合は、正のゲインを記録します。 
5. **MILP の最適化**

 置換候補ごとのバイナリ変数。 制約により、各素数が最大 1 回出現することが強制されます。
