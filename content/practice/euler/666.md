[プロジェクト オイラー問題 666](https://projecteuler.net/problem=666)

 ## 解決策

 **答え:**`0.48023168`これは、古典的な **マルチタイプのゴルトン-ワトソン分岐プロセス**です。 

させて$$x_i=\Pr(\text{eventual extinction}\mid \text{start with one bacterium of type }\alpha_i).$$必要な答えは、$P_{500,10}=x_0$。 

分岐プロセスの場合、消滅確率は子孫生成関数の **最小非負固定点** です。 

種類ごとに$i$、 定義する$$f_i(x_0,\dots,x_{k-1})$$あるタイプの単一の細菌の 1 分間の進化に対応する生成関数として$\alpha_i$。 

なぜなら、それぞれの選択が$j\in[0,m-1]$確率も同じなので、平均すると、$m$考えられるルール。 

与えられた$q=r_{im+j}\bmod 5$:

 -$q=0$：死

 貢献$=1$-$q=1$: 自身のクローンを作成します

 子孫：2人$\alpha_i$貢献$=x_i^2$-$q=2$: に変異する$\alpha_{2i\bmod k}$貢献$=x_{2i\bmod k}$-$q=3$: 3つに分割$\alpha_{i^2+1\bmod k}$貢献$=x_{i^2+1\bmod k}^3$-$q=4$: それ自体を維持してスポーンします$\alpha_{i+1\bmod k}$貢献$=x_i x_{i+1\bmod k}$したがって、$$x_i=f_i(x)$$と$$f_i(x)=\frac1m\sum_{j=0}^{m-1} g_{i,j}(x),$$どこ$g_{i,j}$は上記の対応する貢献です。 

ゼロベクトルから開始して反復する$$x^{(n+1)} = f(x^{(n)})$$は最小固定点に単調に収束します。これはまさに消滅確率ベクトルです。

 ## Pythonの実装```python
from math import *

def extinction_probability(k, m):
    MOD = 10007

    # Generate q-values
    r = 306
    qs = []
    for _ in range(k * m):
        qs.append(r % 5)
        r = (r * r) % MOD

    # qs for each type i
    rules = [qs[i*m:(i+1)*m] for i in range(k)]

    # Fixed-point iteration
    x = [0.0] * k

    for _ in range(1000):
        nx = [0.0] * k

        for i in range(k):
            s = 0.0

            for q in rules[i]:

                if q == 0:
                    # death
                    s += 1.0

                elif q == 1:
                    # two copies of type i
                    s += x[i] ** 2

                elif q == 2:
                    # mutate
                    s += x[(2 * i) % k]

                elif q == 3:
                    # split into three
                    t = (i * i + 1) % k
                    s += x[t] ** 3

                else:  # q == 4
                    # keep itself and spawn one new bacterium
                    s += x[i] * x[(i + 1) % k]

            nx[i] = s / m

        # convergence check
        diff = max(abs(nx[i] - x[i]) for i in range(k))
        x = nx

        if diff < 1e-16:
            break

    return x[0]

# Verification on the examples
print(round(extinction_probability(2, 2), 8))
print(round(extinction_probability(4, 3), 8))
print(round(extinction_probability(10, 5), 8))

# Required value
ans = extinction_probability(500, 10)
print(round(ans, 8))
```---

 ## コードのチュートリアル

 ### 1. 擬似乱数シーケンスを生成する```python
r = 306
r = (r * r) % 10007
```これによりシーケンスが生成されます$r_n$、各ルールは次を使用します$$q = r_n \bmod 5.$$---

 ### 2. ルールテーブルを構築する```python
rules = [qs[i*m:(i+1)*m] for i in range(k)]
```種類ごとに$i$、私たちはそれを保管します$m$可能な変換。 

---

 ### 3. 固定小数点の反復

 まずは```python
x = [0.0] * k
```それはどこにも「確実な生存」に相当しません。 

母関数を繰り返し適用すると、最小の固定点、つまり消滅確率ベクトルに収束します。 

---

 ### 4. 各ルールの貢献度

 例:```python
s += x[i] ** 2
```型の 2 つの独立した子孫を生成することに対応します。$i$, したがって、両方の系統は滅びなければなりません。 

同様に、```python
s += x[t] ** 3
```3人の独立した子孫を意味します。
