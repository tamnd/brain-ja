[プロジェクト オイラー問題 684](https://projecteuler.net/problem=684)

 ## 解決策

 **答え:**`922058210`させて$s(n)$桁の合計が次のような最小の正の整数であること$n$。 

例えば：

-$s(1)=1$-$s(10)=19$-$s(20)=299$私たちは定義します$$S(k)=\sum_{n=1}^k s(n).$$計算しなければなりません$$\sum_{i=2}^{90} S(f_i) \pmod{1\,000\,000\,007},$$どこ$f_i$フィボナッチ数です。 

---

 #1. 数学的分析

 ## ステップ 1: の式$s(n)$桁の合計で最小の数を作るには$n$、私たちが望むのは：

 - できるだけ少ない桁数、
 - 大きい数字は右に移動します。 

書く$$n = 9q + r,\qquad 0 \le r \le 8.$$この場合、最適な数は次のようになります。 

- 先頭の 1 桁$r$（もし$r>0$）、
- に続く$q$次の桁に等しい$9$。 

例:

 -$10 = 9\cdot1+1 \Rightarrow s(10)=19$-$20 = 9\cdot2+2 \Rightarrow s(20)=299$したがって、$$s(n)=r\cdot 10^q + (10^q-1).$$それで：$$\boxed{s(n)=(r+1)10^q-1}$$と$n=9q+r$。 

---

 # ステップ 2: の式を導き出す$S(k)$させて$$k=9q+r,\qquad 0\le r\le 8.$$9 項の完全なブロックを合計します。 

固定の場合$a\ge0$、$$s(9a+t)=(t+1)10^a-1,\qquad 1\le t\le8,$$そして$$s(9a+9)=10^{a+1}-1.$$したがって：$$\sum_{t=1}^{9} s(9a+t) = \sum_{t=1}^{8}\big((t+1)10^a-1\big) + (10^{a+1}-1).$$計算:$$\sum_{t=1}^{8}(t+1)=44,$$それで$$=44\cdot10^a-8+10^{a+1}-1 =54\cdot10^a-9.$$したがって、各完全なブロックは貢献します$$54\cdot10^a-9.$$合計する$a=0,\dots,q-1$:$$\sum_{a=0}^{q-1}(54\cdot10^a-9) = 54\frac{10^q-1}{9}-9q.$$したがって、フルブロックの寄与は次のようになります。$$6(10^q-1)-9q.$$残りを追加します$r$条項：$$\sum_{t=1}^{r}\big((t+1)10^q-1\big).$$以来$$\sum_{t=1}^{r}(t+1)=\frac{r(r+3)}2,$$これはこうなる$$\frac{r(r+3)}2\,10^q-r.$$組み合わせる:$$S(k) = 6(10^q-1)-9q + \frac{r(r+3)}2\,10^q-r.$$したがって$$\boxed{ S(k)=\left(\frac{r(r+3)}2+6\right)10^q-9q-r-6 }$$どこ$k=9q+r$。

 #2. Pythonの実装```python
MOD = 1_000_000_007

def S(k):
    """
    Compute S(k) modulo MOD using the closed formula.
    """
    q, r = divmod(k, 9)

    # Closed form:
    # S(k) = ((r(r+3))/2 + 6) * 10^q - 9q - r - 6
    value = (
        ((r * (r + 3)) // 2 + 6) * pow(10, q, MOD)
        - 9 * q
        - r
        - 6
    )

    return value % MOD

# Fibonacci iteration
f0, f1 = 0, 1

answer = 0

for _ in range(2, 91):
    f0, f1 = f1, f0 + f1
    answer = (answer + S(f1)) % MOD

print(answer)
```---
