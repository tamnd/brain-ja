[プロジェクト オイラー問題 808](https://projecteuler.net/problem=808)

 ## 解決策

 **答え:**`3807504276997394`させて$n$可逆素二乗 (RPS) である必要があります。 定義により:

 1.$n$回文ではありませんが、
 2.$n=p^2$いくつかのプライムのために$p$、
 3.$\operatorname{rev}(n)=q^2$いくつかのプライムのために$q$。 

例えば：$$169 = 13^2,\qquad 961 = 31^2,\qquad 961=\operatorname{rev}(169)$$だから両方とも$169$そして$961$可逆な素平方です。 

このような数値の **最初の 50 個の合計** が必要です。 

---

 # 数学的分析

 仮定してください$$n=p^2$$どこ$p$プライムです。 

次のように計算します。$$r = \operatorname{rev}(n)$$そして、次のことを確認してください。 

-$r \neq n$(回文ではありません)、
 -$r$は完全な正方形であり、
 -$\sqrt r$プライムです。 

数字の特徴を説明するにはこれで十分です。 

---

 ## 主な所見

 ### 1. 反転により桁数が保持されます。 

もし$n$末尾がゼロの場合、反転すると先頭のゼロが削除されます。 

しかし、素平方はとにかくゼロで終わることはできません。$10$で終わる数字への平方$00$。 

したがって、特別な処理は必要ありません。 

---

 ### 2. 真二乗検定

 与えられた$r$、テストします:$$s = \lfloor \sqrt r \rfloor$$それから：$$r \text{ is a square } \iff s^2=r$$その後は、次のことをテストするだけです。$s$プライムです。 

---

 ### 3. 効率的な発電

 すべての整数をテストする代わりに、素数のみを生成します$p$、次に計算します$p^2$。 

これにより、検索スペースが大幅に減少します。 

最初の 50 RPS 値は以下の素数に対して発生します。$5\times 10^7$, ザルを使うと簡単です。 

---

 # Pythonの実装```python
from math import isqrt

def sieve(limit):
    """
    Classic sieve of Eratosthenes.
    Returns a boolean array where prime[p] is True iff p is prime.
    """
    prime = bytearray(b'\x01') * (limit + 1)
    prime[0] = prime[1] = 0

    for i in range(2, isqrt(limit) + 1):
        if prime[i]:
            start = i * i
            step = i
            prime[start:limit + 1:step] = (
                b'\x00' * (((limit - start) // step) + 1)
            )

    return prime

LIMIT = 50_000_000
prime = sieve(LIMIT)

reversible_prime_squares = []

for p, is_p in enumerate(prime):
    if not is_p:
        continue

    square = p * p

    # Reverse decimal digits
    rev_square = int(str(square)[::-1])

    # Must not be a palindrome
    if rev_square == square:
        continue

    # Check whether reversed value is also a square
    q = isqrt(rev_square)

    if q * q != rev_square:
        continue

    # Check whether sqrt(rev_square) is prime
    if q <= LIMIT and prime[q]:
        reversible_prime_squares.append(square)

# Remove duplicates and sort
reversible_prime_squares = sorted(set(reversible_prime_squares))

answer = sum(reversible_prime_squares[:50])

print(answer)
```---
