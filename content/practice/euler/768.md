[プロジェクト オイラー問題 768](https://projecteuler.net/problem=768)

 ## 解決策

 360 個のキャンドルホルダーを統一の 360 番目の根に対応させます。 

選択されたルートのベクトルの合計がゼロであれば、構成は完全にバランスが取れています。 

選択したセットを、単一の個別の 360 乗根の消失和として書き込みます。 

なぜなら$$360 = 2^3\cdot 3^2\cdot 5$$そしてキャンドルの数は$20$、これは **3 で割り切れません**、消失和の Lam-Leung 分類は、すべてのバランスのとれた構成が以下の素な和集合に分解する必要があることを意味します。 

- 対蹠ペア（サイズ$2$)、および/または
 - 正五角形（サイズ$5$）。 

他の基本的な消失構成は発生しません。 

---

 正五角形を定義する$$P_r=\{r,r+72,r+144,r+216,r+288\} \qquad (0\le r<72).$$知らせ：

-$P_r$そして$P_{r+36}$向かい合った五角形です。 
- これらは一緒になって、10 個の頂点を含む「十角形ブロック」を形成します。 
- 1 つのブロック内にはちょうど 5 つの対蹠ペアがあります。 

したがって、360 個の頂点は次のように分割されます。$36$独立したブロック。 

---

 1 つのブロックについて、可能なバランスのとれた選択は次のとおりです。 

- 選択します$k$対蹠ペア ($0\le k\le 4$):$$\binom{5}{k}x^{2k}$$- 五角形を 1 つ選択します:$$2x^5$$- 十角形全体を選択します。$$x^{10}$$(5 つの対蹠ペアをすべて選択すると、反対側の五角形を両方選択した場合と同じセットが得られるため、これは 1 回だけカウントする必要があります。)

 したがって、1 つのブロックの生成多項式は次のようになります。$$F(x)=1+5x^2+10x^4+2x^5+10x^6+5x^8+x^{10}.$$36個のブロックは独立しているので、$$f(360,20)=[x^{20}]F(x)^{36}.$$---

 Python コード:```python
from collections import defaultdict

# generating polynomial for one 10-vertex block
F = {
    0: 1,
    2: 5,
    4: 10,
    5: 2,
    6: 10,
    8: 5,
    10: 1
}

# DP for coefficient extraction
dp = {0: 1}

for _ in range(36):
    nd = defaultdict(int)

    for a, va in dp.items():
        for b, vb in F.items():
            if a + b <= 20:
                nd[a + b] += va * vb

    dp = nd

print(dp[20])
```これにより、$$7631085872322540.$$チェック:

 - のために$f(12,4)$、同じ方法で得られます$15$。 
- のために$f(36,6)$、それは与えます$876$。 

どちらも問題文と一致します。 

したがって、

 **答え: 7631085872322540**
