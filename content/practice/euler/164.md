[プロジェクト オイラー問題 164](https://projecteuler.net/problem=164)

 ## 解決策

 **答え:**`378158756814587`次のような 20 桁の整数を数えたいとします。 

- 最初の桁がゼロ以外の場合、
 - 連続する 3 桁ごとに、その合計は最大 9 になります。 

数字を次のようにします$$d_1 d_2 \cdots d_{20},$$と$d_1 \neq 0$、そしてすべてについて$i$、$$d_i + d_{i+1} + d_{i+2} \le 9.$$これは古典的な有限状態動的計画法の問題です。 

---

 # 数学的分析

 条件は前の 2 桁のみに依存します。 

下 2 桁がすでに分かっている場合$(a,b)$、次の桁$c$であれば許可されます$$a+b+c \le 9.$$したがって：$$c \in \{0,1,\dots,9-a-b\}.$$したがって、プロセス全体は、最後の 2 桁で構成される状態間の遷移としてモデル化できます。 

---

 ## DP の定義

 しましょう$$DP(k,a,b)$$有効な数になります$k$-数字で終わる数字シーケンス$a,b$、すべてのトリプルの条件を満たします。 

移行は次のとおりです。$$DP(k+1,b,c) += DP(k,a,b)$$あらゆる人にとって$c$そのような$$a+b+c \le 9.$$---

 ## 初期化

 2 桁のプレフィックスの場合:

 - 最初の桁$a \in \{1,\dots,9\}$、
 - 2 桁目$b \in \{0,\dots,9\}$。 

トリプルはまだ存在しないため、そのようなペアはすべて最初は有効です。 

したがって：$$DP(2,a,b)=1.$$---

 ## 状態数

 状態空間は非常に小さいです。 

-$a,b \in \{0,\dots,9\}$、
- のみ$100$州。 

各州ごとに、最大でも$10$遷移が存在します。 

したがって、計算は簡単です。 

---

 # Pythonの実装```python
from collections import defaultdict

# dp[(a,b)] = number of valid sequences ending with digits a,b
dp = defaultdict(int)

# Initialize all valid 2-digit beginnings
for a in range(1, 10):      # first digit cannot be zero
    for b in range(10):
        dp[(a, b)] = 1

# Extend sequences until length 20
for length in range(2, 20):
    new_dp = defaultdict(int)

    for (a, b), count in dp.items():

        # Next digit c must satisfy a+b+c <= 9
        max_c = 9 - a - b

        for c in range(max_c + 1):
            new_dp[(b, c)] += count

    dp = new_dp

# Total number of valid 20-digit numbers
answer = sum(dp.values())

print(answer)
```---
