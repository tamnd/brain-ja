[プロジェクト オイラー問題 183](https://projecteuler.net/problem=183)

 ## 解決策

 **答え:**`48861552`私たちは求めています$$\sum_{N=5}^{10000} D(N),$$どこ$D(N)=N$製品を最大化する場合$M(N)$は終端のない小数であり、$D(N)=-N$さもないと。 

重要なのは、それぞれについて判断することです。$N$、最適な製品かどうか$$M(N)=\left(\frac Nk\right)^k$$終了しているかどうか。 

#1. 数学的分析

 固定用$N$、 定義する$$f(k)=\left(\frac Nk\right)^k.$$これを正の整数で最大化します$k$。 

ログの取得:$$\log f(k)=k(\log N-\log k).$$扱う$k$実数として微分します:$$\frac{d}{dk}\bigl(k(\log N-\log k)\bigr) =\log N-\log k-1.$$これをゼロに設定すると、次のようになります。$$\log\frac Nk=1 \quad\Longrightarrow\quad \frac Nk=e \quad\Longrightarrow\quad k=\frac Ne.$$したがって、最大化する整数は$k$は最も近い整数です$N/e$。 

より正確には:

 - させてください$$k_1=\left\lfloor \frac Ne \right\rfloor,$$- 次に比較します$f(k_1)$そして$f(k_1+1)$。 

この問題の標準的な事実は、最大化する整数は常に次のいずれかであるということです。$$\left\lfloor \frac Ne \right\rfloor \quad\text{or}\quad \left\lfloor \frac Ne \right\rfloor+1.$$---

 ## いつですか$M(N)$終了しますか？ 

最大化すると仮定します$k$が選ばれます。 

それから$$M(N)=\left(\frac Nk\right)^k.$$分数を減らす：$$\frac Nk=\frac ab$$最低の言葉で。 

それから$$M(N)=\left(\frac ab\right)^k.$$有理数の分母に以下の素因数がない場合、有理数には終端小数があります。$2$そして$5$。 

したがって、分母が減少したかどうかを知る必要があるだけです。$b$他に素数が含まれています$2,5$。 

しかし$$b=\frac{k}{\gcd(N,k)}.$$したがって:

 - 計算する$$d=\frac{k}{\gcd(N,k)};$$- 要素の分割を繰り返します。$2$そして$5$;
 - 結果が次の場合$1$、 それから$M(N)$終了します。 
- それ以外の場合はそうではありません。 

したがって：$$D(N)= \begin{cases} -N & \text{if } d \text{ has only factors }2,5,\\ +N & \text{otherwise.} \end{cases}$$---

 #2. 最適な値を決定する$k$比較します$$\left(\frac N{k}\right)^k$$連続する整数の場合。 

巨大な累乗の代わりに、対数を比較します。$$k\log\frac Nk.$$定義する$$g(k)=k\log\frac Nk.$$この場合、最大化する整数は次のようになります。```python
k = floor(N/e)
if g(k+1) > g(k):
    k += 1
```---

 #3. Pythonの実装```python
import math
from math import gcd

def optimal_k(N):
    """
    Return the integer k maximizing (N/k)^k.
    """
    k = int(N / math.e)

    # Compare logarithms to avoid huge numbers
    g1 = k * math.log(N / k)
    g2 = (k + 1) * math.log(N / (k + 1))

    if g2 > g1:
        k += 1

    return k

def terminating_decimal(N):
    """
    Return True iff M(N) is a terminating decimal.
    """
    k = optimal_k(N)

    # Reduced denominator of N/k
    d = k // gcd(N, k)

    # Remove all factors of 2
    while d % 2 == 0:
        d //= 2

    # Remove all factors of 5
    while d % 5 == 0:
        d //= 5

    return d == 1

def compute(limit):
    total = 0

    for N in range(5, limit + 1):
        if terminating_decimal(N):
            total -= N
        else:
            total += N

    return total

# Verify the example
print(compute(100))      # should be 2438

# Final answer
print(compute(10000))
```---

 ## チェックの例

 ###$N=11$最適$k=4$。$$M(11)=\left(\frac{11}{4}\right)^4.$$削減された分母は$4=2^2$、ということで終了。 

したがって、$$D(11)=-11.$$---

 ###$N=8$最適$k=3$。$$M(8)=\left(\frac83\right)^3=\frac{512}{27}.$$分母に因数が含まれています$3$、つまり非終了です。 

したがって、$$D(8)=+8.$$---
