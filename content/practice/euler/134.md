 ## 解決策

 **答え:**`18613426663617118`連続する素数を次のようにします$p_1$そして$p_2$、 と$p_2 > p_1$。 

最小の整数を求めます$S$次のような:

 1.$S \equiv p_1 \pmod{10^d}$、 どこ$d$は小数点以下の桁数です$p_1$、
 2.$S \equiv 0 \pmod{p_2}$。 

たとえば、$p_1=19$、$p_2=23$:$$1219 \equiv 19 \pmod{100}, \qquad 1219 \equiv 0 \pmod{23}.$$計算しなければなりません$$\sum S$$連続するすべての素数ペアにわたって$$5 \le p_1 \le 10^6.$$---

 # 数学的分析

 仮定してください$d$の桁数です$p_1$、定義します$$m = 10^d.$$次の数字で終わる任意の数字$p_1$次のように書くことができます$$S = m k + p_1$$ある整数に対して$k \ge 0$。 

必要です$S$で割り切れる$p_2$:$$mk + p_1 \equiv 0 \pmod{p_2}.$$したがって、$$mk \equiv -p_1 \pmod{p_2}.$$なぜなら$p_2$プライムであり、$p_2 \ne 2,5$、 我々は持っています$$\gcd(m,p_2)=1,$$それで$m$モジュラー逆モジュロを持っています$p_2$。 したがって、$$k \equiv -p_1 \cdot m^{-1} \pmod{p_2}.$$最小の非負の解は次のとおりです。$$k = (-p_1)\,m^{-1} \bmod p_2.$$それから$$S = mk + p_1.$$したがって、問題全体は逆モジュールの繰り返しに帰着します。

 ## 逆モジュラーの計算

 以来$p_2$プライムです、$$m^{-1} \equiv m^{p_2-2} \pmod{p_2}$$フェルマーの小定理による。 

Python はこれを直接提供します。```python
pow(m, -1, p2)
```これにより逆モジュラーが効率的に計算されます。

 # アルゴリズム

 1. わずかに上までのすべての素数を生成する$10^6$。 
2. 連続するペアごとに$(p_1,p_2)$:

 - スキップ$p_1 < 5$、
 - 一度停止します$p_1 > 10^6$、
- させて$m = 10^{\text{digits}(p_1)}$、
 - 計算します:$$k = (-p_1)\cdot m^{-1} \bmod p_2,$$- 計算します:$$S = mk + p_1,$$- 合計に追加します。 
3. 合計を出力します。 

複雑さはふるいによって支配されます。$$O(n \log\log n)$$これは十分に高速です$10^6$。 

---

 # Pythonの実装```python
from math import isqrt

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def sieve(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(limit) + 1):
        if is_prime[i]:
            step = i
            start = i * i
            is_prime[start:limit + 1:step] = [False] * (
                ((limit - start) // step) + 1
            )

    return [i for i, v in enumerate(is_prime) if v]

# We need primes slightly beyond 1,000,000
LIMIT = 1_100_000
primes = sieve(LIMIT)

total = 0

for i in range(len(primes) - 1):
    p1 = primes[i]
    p2 = primes[i + 1]

    if p1 < 5:
        continue

    if p1 > 1_000_000:
        break

    # 10^d where d = number of digits of p1
    m = 10 ** len(str(p1))

    # Solve m*k + p1 ≡ 0 (mod p2)
    inv = pow(m, -1, p2)

    k = (-p1 * inv) % p2

    S = m * k + p1

    total += S

print(total)
```---
