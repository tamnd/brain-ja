 ## 解決策

 **答え:**`71`**5000 以上の異なる方法**で素数の合計として記述できる最初の整数を求められます。 

これは古典的な **整数分割** の問題ですが、許可される部分が素数のみである点が異なります。 

---

 # 数学的分析

 しましょう$f(n)$書き方の数を表す$n$素数の合計として、順序は**重要ではありません**。 

たとえば、$10$:$$\begin{aligned} 10 &= 7+3\\ &=5+5\\ &=5+3+2\\ &=3+3+2+2\\ &=2+2+2+2+2 \end{aligned}$$それで$f(10)=5$。 

---

 ## 重要な洞察: コインチェンジ動的プログラミング

 この問題は構造的には古典的な「コインチェンジ」問題と同じです。 

利用可能な素数が次のとおりであるとします。$$2,3,5,7,11,\dots$$生成する非順序和の数が必要です$n$。 

定義する：$$dp[k]$$合計を形成する方法の数として$k$。 

最初に:$$dp[0]=1$$なぜなら、ゼロを作る方法はただ 1 つしかないからです。それは、何も選択しないことです。 

次に、各素数について$p$、 アップデート：$$dp[k] \mathrel{+}= dp[k-p]$$みんなのために$k\ge p$。 

なぜこれが機能するのでしょうか?

 - 素数処理時$p$、
 - あらゆる作り方$k-p$- を作る方法になります$k$1つ追加することで$p$。 

素数は昇順に処理されるため、配置に関係なく、各組み合わせは 1 回だけカウントされます。

 ## 素数の生成

 比較的小さな数だけが必要なので、単純な素数テストで十分です。 

数字$n$整数がない場合は素数です$d \le \sqrt n$それを分割します。

 ## 戦略

 インクリメントします$n$小さい値から順に:

 1. すべての素数を生成する$\le n$2. 素数パーティションの数を計算します。$n$3. カウントを超えたら停止します$5000$---

 # Pythonの実装```python
from math import isqrt

# Check whether a number is prime
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, isqrt(n) + 1):
        if n % d == 0:
            return False
    return True

# Generate all primes up to limit
def primes_up_to(limit):
    return [x for x in range(2, limit + 1) if is_prime(x)]

target = 5000
n = 2

while True:
    primes = primes_up_to(n)

    # dp[k] = number of ways to write k as a sum of primes
    dp = [0] * (n + 1)
    dp[0] = 1

    # Coin-change style dynamic programming
    for p in primes:
        for k in range(p, n + 1):
            dp[k] += dp[k - p]

    # Check whether we've exceeded the target
    if dp[n] > target:
        print(n)
        break

    n += 1
```---
