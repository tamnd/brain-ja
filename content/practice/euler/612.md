 ## 解決策

 **答え:**`819963842`させて$$N=10^{18}$$すべての整数を考慮します$$1 \le x < N.$$2 つの数値は、10 進表現が少なくとも 1 桁を共有する場合、**友達**です。 

私たちが欲しいのは$$f(N)=\#\{(p,q):1\le p<q<N,\; p,q\text{ are friends}\}$$モジュロ$1000267129$。 

## 1. 数学的分析

 友達のペアを直接カウントする代わりに、補数をカウントします。 

> **非友人ペア** = **互いに素な数字セット**を持つペア。 

それから$$f(N)=\binom{N-1}{2}-\text{(non-friend pairs)}.$$以来$N=10^{18}$、以下のすべての正の整数$N$10 進数は最大 18 桁です。 

### ステップ 1: 数字セットごとに数値を分類する

 数字の場合$x$、 定義する$D(x)\subseteq \{0,\dots,9\}$に現れる数字のセットとして$x$。 

させて$$F(S)=\#\{x:1\le x<10^{18},\ D(x)=S\}$$サブセットごとに$S\subseteq \{0,\dots,9\}$。 

それからペア$(p,q)$友達じゃないなら$$D(p)\cap D(q)=\varnothing.$$したがって、$$\text{non-friend pairs} = \frac12 \sum_{\substack{A,B\\A\cap B=\varnothing}} F(A)F(B).$$要因$1/2$二重カウントを削除します。 

---

 ### ステップ 2: セットの数字のみを使用して数を数える

 定義する$$G(T)$$正の整数の数として$<10^{18}$数字がすべて入っているのは$T$。 

仮定する$T$contains:

 -$k=|T|$合計桁数、
 -$nz$ゼロ以外の数字 (先頭の数字を 0 にすることはできません)。 

長さに関しては$L$:

 - 最初の桁:$nz$選択肢、
 - 残り$L-1$:$k$それぞれの選択肢。 

それで$$G(T) = \sum_{L=1}^{18} nz\cdot k^{L-1}.$$これは、桁セットが ** に含まれる数字を数えます **$T$。 

---

 ### ステップ 3: 包含と排除 (メビウスの反転)

 **正確な**数字セットが必要です。 

以来$$G(T)=\sum_{S\subseteq T}F(S),$$私たちは回復します$F$部分集合メビウス反転による：$$F(S) = \sum_{T\subseteq S} (-1)^{|S|-|T|} G(T).$$あるのは$2^{10}=1024$サブセットなので、これは計算的には小さいです。

 ## 2. Python の実装```python
MOD = 1000267129

def solve():
    LIMIT = 10**18
    MAX_LEN = 18
    FULL_MASK = (1 << 10) - 1  # digits 0..9

    # G[mask] = count of numbers using only digits in mask
    G = [0] * 1024

    for mask in range(1, 1024):
        k = mask.bit_count()
        has_zero = mask & 1
        nonzero_digits = k - (1 if has_zero else 0)

        # Cannot start with zero
        if nonzero_digits == 0:
            continue

        total = 0
        for length in range(1, MAX_LEN + 1):
            total += nonzero_digits * (k ** (length - 1))

        G[mask] = total

    # Möbius inversion to get exact digit-set counts
    F = G[:]

    for bit in range(10):
        for mask in range(1024):
            if mask & (1 << bit):
                F[mask] -= F[mask ^ (1 << bit)]

    # Total unordered pairs
    M = LIMIT - 1
    total_pairs = M * (M - 1) // 2

    # Count non-friend pairs (disjoint digit sets)
    non_friend = 0

    for A in range(1, 1024):
        fa = F[A]
        if fa == 0:
            continue

        complement = FULL_MASK ^ A
        B = complement

        while B:
            non_friend += fa * F[B]
            B = (B - 1) & complement

    # Each unordered pair counted twice
    non_friend //= 2

    friend_pairs = total_pairs - non_friend

    return friend_pairs % MOD

print(solve())
```---

 ## 3. コードのチュートリアル

 ### ビルド`G`すべての桁のサブセットに対して (`mask`):

 - 含まれる桁数を数えます (`k`）
 - ゼロ以外のものがいくつあるか数えます (`nonzero_digits`）
 - 各長さについて$1$に$18$、$$\text{count} = \text{nonzero\_digits}\cdot k^{L-1}$$それらを一緒に追加します。 

---

 ### メビウス反転`F`として始まります`G`。 

各ビット (桁) について、より小さいサブセットを減算します。```python
F[mask] -= F[mask ^ (1 << bit)]
```この後、```python
F[S]
```桁セットが**正確に**である数値を数えます`S`。 

---

 ### 素のペアを数える

 すべてのサブセットについて`A`、サブセットを列挙する`B`その補数の:```python
complement = FULL_MASK ^ A
```それから`A`そして`B`バラバラです。 

蓄積:```python
F[A] * F[B]
```順序のないペアは 2 回カウントされるため、2 で割ります。
