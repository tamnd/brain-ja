-$F_0=A$-$F_1=B$-$F_n=F_{n-1}F_{n-2}$のために$n\ge2$ここで、並列とは連結を意味します。 

このフィボナッチのような単語システム内で数字を計算するように求められます。 

2 つの 100 桁の文字列は次のとおりです。$$A= 14159265358979323846264338327950288419716939937510 58209749445923078164062862089986280348253421170679$$

$$B= 82148086513282306647093844609550582231725359408128 48111745028410270193852110555964462294895493038196$$評価しなければなりません$$\sum_{n=0}^{17}10^n\,D_{A,B}((127+19n)7^n)$$どこ$D_{A,B}(m)$です$m$- 位置を含むのに十分な長さの最初のフィボナッチ ワードの 桁目$m$。 

---

 #1. 数学的分析

 ## フィボナッチ語長

 しましょう$L_n=|F_n|$、の長さ$n$-番目の単語。 

連結すると長さが増すので、$$L_n=L_{n-1}+L_{n-2}$$と$$L_0=L_1=100$$したがって$$L_n=100F_{n+1}$$どこ$F_k$は通常のフィボナッチ数です。 

したがって、長さは急速に伸びます。 

---

 ## 再帰的に数字を検索する

 が欲しいとします。$m$- 番目の桁。 

最小のものを選択してください$k$そのような$$L_k \ge m.$$なぜなら$$F_k = F_{k-1}F_{k-2},$$最初$L_{k-1}$数字の由来は$F_{k-1}$、残りの数字は次のとおりです。$F_{k-2}$。 

したがって:

 - もし$m \le L_{k-1}$、数字は内側にあります$F_{k-1}$;
 - それ以外の場合は内部にあります$F_{k-2}$位置で$$m-L_{k-1}.$$これにより、再帰的な削減が行われます。$$(k,m)\to \begin{cases} (k-1,m), & m\le L_{k-1}\\[4pt] (k-2,m-L_{k-1}), & m>L_{k-1} \end{cases}$$最終的には次のようになります。 

-$k=0$: 数字が入っています$A$、
 -$k=1$: 数字が入っています$B$。 

これにより、巨大な文字列の構築が回避されます。

 #2. Pythonの実装```python
A = (
    "14159265358979323846264338327950288419716939937510"
    "58209749445923078164062862089986280348253421170679"
)

B = (
    "82148086513282306647093844609550582231725359408128"
    "48111745028410270193852110555964462294895493038196"
)

# ---------------------------------------------------------
# Precompute Fibonacci-word lengths
# ---------------------------------------------------------

lengths = [100, 100]

while lengths[-1] < 10**18:
    lengths.append(lengths[-1] + lengths[-2])

# ---------------------------------------------------------
# Compute D_A,B(n)
# ---------------------------------------------------------

def D(n):
    """
    Return the nth digit (1-indexed) in the first Fibonacci
    word whose length is at least n.
    """

    # Find smallest k with lengths[k] >= n
    k = 0
    while lengths[k] < n:
        k += 1

    # Reduce recursively without building strings
    while k > 1:

        # F_k = F_{k-1} + F_{k-2}

        if n <= lengths[k - 2]:
            k -= 2
        else:
            n -= lengths[k - 2]
            k -= 1

    # Base cases
    if k == 0:
        return int(A[n - 1])
    else:
        return int(B[n - 1])

# ---------------------------------------------------------
# Evaluate the required sum
# ---------------------------------------------------------

answer = 0

for n in range(18):
    N = (127 + 19 * n) * (7 ** n)
    answer += (10 ** n) * D(N)

print(answer)
```---
