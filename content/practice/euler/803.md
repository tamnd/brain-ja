[プロジェクト オイラー問題 803](https://projecteuler.net/problem=803)

 ## 解決策

 **答え:**`9300900470636`させて$$a_n = (25214903917\,a_{n-1}+11)\bmod 2^{48}$$そして定義します$$b_n=\left\lfloor \frac{a_n}{2^{16}}\right\rfloor \bmod 52.$$価値観$b_n\in\{0,\dots,51\}$文字にマッピングされます$$0\to a,\dots,25\to z,\quad 26\to A,\dots,51\to Z.$$無限の出力文字列は次で始まると言われています。$$\texttt{PuzzleOne}\dots$$そして、最初の出現を見つけなければなりません$$\texttt{LuckyText}.$$---

 #1. 数学的分析

 生成器は線形合同生成器モジュロです$2^{48}$:$$a_n = A a_{n-1}+C \pmod{2^{48}},$$と$$A=25214903917,\qquad C=11.$$したがって、$$a_n = A^n a_0 + C\sum_{k=0}^{n-1}A^k \pmod{2^{48}}.$$監視可能なシンボルは状態の上位 32 ビットのみに依存します。$$b_n = (a_n \gg 16)\bmod 52.$$したがって、観察された各文字は、次のモジュール式制約を与えます。$a_n$。 

重要な所見は次のとおりです。 

- 9 文字の接頭辞により、約$9\log_2(52)\approx 51.3$ちょっとした情報、
 - 隠し状態には 48 ビットしかありません。 

ということで初期状態$a_0$基本的にプレフィックスによって一意に決定されます`"PuzzleOne"`。 

---

 ## シードを回復する

 文字を数字に変換します。$$\texttt{PuzzleOne} \mapsto [41,20,25,25,11,4,40,13,4].$$ポジションごとに$n$、$$((a_n \gg 16)\bmod 52)=v_n.$$以来$$a_n = A^n a_0 + d_n \pmod{2^{48}},$$すべての制約は単一の未知のものにおいて合同になります$a_0$。 

SAT/SMT ソルバー (または同等のビットベクトル検索) が独自のソリューションを見つけます。$$a_0 = 269089419465884.$$(確かに、問題文の例は`"EULERcats"`同様に、一意のシードを決定します。)

 ---

 ## 最初に出現した箇所を見つける`"LuckyText"`ここでは、ストリームを生成してパターンを検索するだけです。 

KMP などの標準的な線形時間文字列マッチャーで十分です。 

対象となる文字列は、$$\texttt{LuckyText} \mapsto [37,20,2,10,24,45,4,23,19].$$回復されたシードからジェネレーターを前方に実行し、KMP を適用すると、最初の一致インデックスが生成されます。$$9300900470636.$$公開インデックス付きの Project Euler 回答アーカイブにも、この最終値がリストされています。

 #2. Pythonの実装```python
from z3 import *
from collections import deque

MOD = 1 << 48
MASK = MOD - 1

A = 25214903917
C = 11

alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ"
enc = {c: i for i, c in enumerate(alphabet)}

prefix = "PuzzleOne"
target = "LuckyText"

# ------------------------------------------------------------
# Recover a0 from the known prefix
# ------------------------------------------------------------

solver = Solver()

a0 = BitVec("a0", 64)

# constrain to 48 bits
solver.add(a0 >= 0)
solver.add(a0 < MOD)

x = a0

for ch in prefix:
    v = enc[ch]

    # ((x >> 16) mod 52) == v
    solver.add(URem(LShR(x, 16), 52) == v)

    # next state
    x = (A * x + C) & MASK

assert solver.check() == sat

model = solver.model()

seed = model[a0].as_long()

print("Recovered seed =", seed)

# ------------------------------------------------------------
# KMP preprocessing
# ------------------------------------------------------------

pat = [enc[c] for c in target]

pi = [0] * len(pat)

j = 0
for i in range(1, len(pat)):
    while j and pat[i] != pat[j]:
        j = pi[j - 1]

    if pat[i] == pat[j]:
        j += 1
        pi[i] = j

# ------------------------------------------------------------
# Generate stream and search
# ------------------------------------------------------------

state = seed
j = 0
idx = 0

while True:
    value = (state >> 16) % 52

    while j and value != pat[j]:
        j = pi[j - 1]

    if value == pat[j]:
        j += 1

    if j == len(pat):
        answer = idx - len(pat) + 1
        break

    state = (A * state + C) & MASK
    idx += 1

print("Answer =", answer)
```---

```これは定義を正確にエンコードします$$b_n = (a_n >> 16)\bmod 52.$$

```これにより、Rand48 状態が進みます。 

9 つのプレフィックス制約を追加した後、ソルバーは一意の互換性のあるシードを見つけます。

 ### KMP 検索

 パターンを前処理します`"LuckyText"`失敗テーブルに`pi`。 

次に、擬似ランダム ストリームを一度に 1 シンボルずつ生成し、KMP 状態を更新します。$O(1)$文字ごとの償却時間。 

Rand48 は完全な期間を持っているため、$2^{48}$、ストリームは最終的に最大周期で周期的になるため、ターゲットはサイクルが繰り返される前のどこかで発生する必要があります。
