[プロジェクト オイラー問題 192](https://projecteuler.net/problem=192)

 ## 解決策

 **答え:**`57060635927998347`無理数の場合$x$、連分数の理論では、すべての **最良近似** (問題文の意味で) は次のいずれかであることがわかります。 

- の連分数の収束$x$、または
 - 中間部分（半収束とも呼ばれます）。 

次のような二次無理数の場合$\sqrt n$、連分数展開は周期的であり、収束は非常に効率的に生成できます。 

---

 #1. 数学的分析

 しましょう$$x = [a_0;a_1,a_2,a_3,\dots]$$～の継続分数となる$x$。 

その収束者は、$$\frac{p_k}{q_k},$$によって生成される$$p_k=a_k p_{k-1}+p_{k-2},\qquad q_k=a_k q_{k-1}+q_{k-2},$$初期値あり$$p_{-2}=0,\; p_{-1}=1,\qquad q_{-2}=1,\; q_{-1}=0.$$---

 ## の継続分数$\sqrt n$非正方形の場合$n$、$$\sqrt n = [a_0;\overline{a_1,a_2,\dots,a_t}]$$定期的です。 

標準的な繰り返しは次のとおりです。$$m_{k+1}=d_k a_k-m_k,$$

$$d_{k+1}=\frac{n-m_{k+1}^2}{d_k},$$

$$a_{k+1}=\left\lfloor\frac{a_0+m_{k+1}}{d_{k+1}}\right\rfloor.$$---

 ## 分母を制限した最良近似$D$連続した収束があると仮定します$$\frac{p_{k-1}}{q_{k-1}}, \qquad \frac{p_k}{q_k}, \qquad \frac{p_{k+1}}{q_{k+1}},$$そして$$q_k \le D < q_{k+1}.$$次に、分母を使用してすべての候補の最良近似を計算します。$\le D$次のいずれかでなければなりません:

 1. 収束するもの$\frac{p_k}{q_k}$、または
 2. 許容可能な最大の半収束$$\frac{t p_k+p_{k-1}}{t q_k+q_{k-1}},$$どこ$$t=\left\lfloor\frac{D-q_{k-1}}{q_k}\right\rfloor.$$したがって、**2 つの候補** のみをチェックする必要があります。 

- -

＃＃ 例：$\sqrt{13}$連分数は$$\sqrt{13}=[3;\overline{1,1,1,1,6}].$$収束者:$$3,\ \frac41,\ \frac72,\ \frac{11}3,\ \frac{18}5,\ \frac{119}{33},\dots$$のために$D=20$:

 -$5 \le 20 < 33$- 半収束の最大の分母は$18$候補者は次のとおりです。$$\frac{18}5,\qquad \frac{65}{18}.$$数値的には、$$\left|\sqrt{13}-\frac{18}5\right| < \left|\sqrt{13}-\frac{65}{18}\right|,$$だから答えは$\frac{18}5$。 

のために$D=30$、最大の半収束は次のようになります。$$\frac{101}{28},$$より近いのは$\frac{18}5$。

 #2. Pythonの実装```python
from math import isqrt
from decimal import Decimal, getcontext

# We need very high precision because denominators go up to 10^12
getcontext().prec = 80

LIMIT = 10**12

def best_denominator_sqrt(n, D):
    """
    Returns the denominator of the best approximation to sqrt(n)
    with denominator bound D.
    """

    a0 = isqrt(n)

    # Ignore perfect squares
    if a0 * a0 == n:
        return 0

    x = Decimal(n).sqrt()

    # Continued fraction state
    m = 0
    d = 1
    a = a0

    # Convergents:
    # p[-2]=0, p[-1]=1
    # q[-2]=1, q[-1]=0
    p0, p1 = 1, a
    q0, q1 = 0, 1

    while True:

        # Generate next continued-fraction term
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d

        # Next convergent
        p2 = a * p1 + p0
        q2 = a * q1 + q0

        # Stop when next denominator exceeds D
        if q2 > D:

            # Largest admissible semiconvergent
            t = (D - q0) // q1

            # Candidate 1: convergent
            cand1_p, cand1_q = p1, q1

            # Candidate 2: semiconvergent
            cand2_p = t * p1 + p0
            cand2_q = t * q1 + q0

            # Compare distances to sqrt(n)
            err1 = abs(Decimal(cand1_p) / cand1_q - x)
            err2 = abs(Decimal(cand2_p) / cand2_q - x)

            if err1 <= err2:
                return cand1_q
            else:
                return cand2_q

        # Advance
        p0, p1 = p1, p2
        q0, q1 = q1, q2

def solve():
    total = 0

    for n in range(2, 100001):
        r = isqrt(n)

        # Skip perfect squares
        if r * r == n:
            continue

        total += best_denominator_sqrt(n, LIMIT)

    return total

print(solve())
