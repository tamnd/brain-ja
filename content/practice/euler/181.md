[プロジェクト オイラー問題 181](https://projecteuler.net/problem=181)

 ## 解決策

 **答え:**`83735848679360680`**グループ**は、そこに含まれる白黒のオブジェクトの数によってのみ説明されます。 

したがって、グループタイプはペアです$$(b,w)\neq(0,0)$$グループに含まれることを意味します$b$黒い物体と$w$白い物体。 

そのようなグループのマルチセットの数を数えなければなりません。その合計は$$(60,40).$$たとえば、$3$黒と$1$白い物体、7 つの可能性はまさに 7 つのペアのマルチセットを合計したものです。$(3,1)$。 

---

 #1. 数学的分析

 これは 2 次元分割の問題です。 

---

 ## 関数の生成

 考えられるすべてのグループ タイプについて$(b,w)\neq(0,0)$、その型を使用できます。 

- ゼロ回、
 - 1回、
 - 2回、
 -など

 したがって、母関数への寄与は次のようになります。$$1+x^b y^w+x^{2b}y^{2w}+\cdots = \frac1{1-x^b y^w}.$$考えられるすべての非ゼロのペアを乗算すると、次のようになります。$$F(x,y) = \prod_{(b,w)\neq(0,0)} \frac1{1-x^b y^w}.$$必要な答えは次の係数です。$$x^{60}y^{40}.$$---

 ## 動的プログラミングの解釈

 これは、各「コイン」が 2 つの座標を持つことを除いて、古典的な整数パーティション DP (「コイン チェンジ」) とまったく同じです。 

定義する$$dp[i][j]$$合計を計算する方法の数になります$(i,j)$。 

最初に:$$dp[0][0]=1.$$グループタイプごとに$(b,w)\neq(0,0)$、 アップデート：$$dp[i+b][j+w] += dp[i][j].$$グループ タイプを任意に何度も再利用できるように、ループは **前方**に進む必要があります。 

までの合計だけが必要なので、$(60,40)$、私たちはただ考慮します$$0\le b\le 60,\qquad 0\le w\le 40,$$除く$(0,0)$。 

複雑さは簡単に管理できます。 

---

 #2. Pythonの実装```python
# Project Euler 181
# Count ways to group 60 black objects and 40 white objects.

B = 60
W = 40

# dp[i][j] = number of ways to form i black and j white objects
dp = [[0] * (W + 1) for _ in range(B + 1)]

# Empty grouping
dp[0][0] = 1

# Process every possible nonempty group type (b, w)
for b in range(B + 1):
    for w in range(W + 1):

        # Skip the empty group
        if b == 0 and w == 0:
            continue

        # Forward iteration => unlimited reuse allowed
        for i in range(B - b + 1):
            for j in range(W - w + 1):
                dp[i + b][j + w] += dp[i][j]

print(dp[B][W])
```---

 #3. コードのチュートリアル

 ### ステップ 1 — DP テーブルを作成する```python
dp = [[0] * (W + 1) for _ in range(B + 1)]
```

`dp[i][j]`以下を正確に使用して、有効なグループ化の数を格納します。 

-`i`黒い物体、
 -`j`白い物体。 

---

 ### ステップ 2 — 基本ケース```python
dp[0][0] = 1
```何もグループ化しない方法が 1 つあります。それは、グループを使用しないことです。 

---

 ### ステップ 3 — すべてのグループ タイプを反復処理する```python
for b in range(B + 1):
    for w in range(W + 1):
```各ペア`(b,w)`は、考えられるグループ構成の 1 つを表します。 

除外します`(0,0)`空のグループは許可されないためです。 

---

 ### ステップ 4 — 移行```python
dp[i + b][j + w] += dp[i][j]
```形にできれば`(i,j)`、さらにグループを 1 つ追加します`(b,w)`私たちは形成することができます`(i+b,j+w)`。 

ループは次のように進みます。```python
for i in range(B - b + 1):
    for j in range(W - w + 1):
```これにより、同じグループ タイプを無制限に再利用できます。

 ## サンプルでの検証

 同じアルゴリズムを実行すると、$B=3$、$W=1$与える:$$7$$問題文と正確に一致します。
