[プロジェクト オイラー問題 174](https://projecteuler.net/problem=174)

 ## 解決策

 **答え:**`209566`外側の正方形に辺の長さを持たせる$a$内側の正方形 (「穴」) は辺の長さを持ちます$b$、 どこ：

-$a>b$、
 - 両方の正方形が中央に配置され、
 - 境界線の太さは整数です。 

それは強制する$a$そして$b$同じパリティを持つこと。 

層内のタイルの数は、$$t=a^2-b^2.$$それぞれを数えたい$t\le 10^6$、いくつの異なる薄層がそれを生成するか$t$。 

If exactly$n$明確な薄層が生成する$t$、 それから$t$タイプです$L(n)$。 

私たちは求められています$$\sum_{n=1}^{10} N(n),$$どこ$N(n)$何個数えますか$t\le 10^6$タイプです$L(n)$。 

---

 # 数学的分析

 ## 1. タイルの式を書き直す

 以来$a$そして$b$同じパリティを持っている場合は、書き込みます$$a=b+2k, \qquad k\ge1.$$それから$$t=a^2-b^2=(a-b)(a+b).$$代わりの$a-b=2k$:$$t=(2k)(2b+2k)=4k(b+k).$$もう 1 つの非常に便利な形式は、直接展開することで得られます。$$t = 4m(m+d),$$しかし、最もクリーンな数え方の解釈は次のとおりです。$$t=(a-b)(a+b),$$両方の因子が等しい場合。 

定義する$$u=\frac{a-b}{2}, \qquad v=\frac{a+b}{2}.$$それから$$t=4uv,$$整数の場合$$u\ge1,\qquad v>u.$$したがって、すべての層は因数分解に正確に対応します$$\frac{t}{4}=uv$$と$u<v$。 

したがって、個別の層の数は$t$の因子ペアの数に等しい$t/4$。 

---

 ## 2. 直接的な建設的なカウント

 よりアルゴリズム的なアプローチは、よりシンプルかつ高速です。 

外側の長さを固定する$a$。 

考えられる内側の正方形は次のとおりです。$$b=a-2,\ a-4,\ a-6,\dots,\ge1.$$各ペアについて:$$t=a^2-b^2.$$それぞれ何回か数えます$t\le10^6$が発生します。 

### 検索の境界を設定する

 外寸の中で最も薄いラミナ$a$使用します:$$a^2-(a-2)^2 = 4a-4.$$必要とする$$4a-4\le10^6$$それで$$a\le250001.$$生成される薄片の総数は管理可能です (約数百万)。 

---

 # Pythonの実装```python
LIMIT = 1_000_000

# ways[t] = number of distinct laminae using exactly t tiles
ways = [0] * (LIMIT + 1)

# Outer square side length
outer = 3

while True:
    # Smallest lamina for this outer size
    smallest = outer * outer - (outer - 2) * (outer - 2)

    if smallest > LIMIT:
        break

    # Try all valid inner squares
    inner = outer - 2

    while inner >= 1:
        tiles = outer * outer - inner * inner

        if tiles > LIMIT:
            break

        ways[tiles] += 1
        inner -= 2

    outer += 1

# Count t whose type is L(1) through L(10)
answer = sum(1 for t in range(LIMIT + 1) if 1 <= ways[t] <= 10)

print(answer)
```---

 # コードのチュートリアル

 ## 初期化```python
LIMIT = 1_000_000
ways = [0] * (LIMIT + 1)
```タイル数ごとに保存します$t$、いくつの異なる薄層がそれを生成するか。 

---

 ## 外側の四角いループ```python
outer = 3
```可能な最小の外側の正方形は次のとおりです。$3\times3$、少なくとも$1\times1$穴。 

---

 ## 停止条件```python
smallest = outer * outer - (outer - 2) * (outer - 2)
```これは最も細い境界線です (幅$1$）。 

これでも制限を超えると、より大きな外側の正方形は機能しなくなります。 

---

 ## 内側の四角いループ```python
inner = outer - 2
```内側と外側は同じパリティでなければならないため、ステップごとに 2 ずつ減少します。 

---

 ## タイル数```python
tiles = outer * outer - inner * inner
```まさに境界タイルの数です。 

---

 ## 1 つのラミナを記録する```python
ways[tiles] += 1
```それぞれ有効$(outer, inner)$ペアは 1 つの異なる薄層を与えます。 

---

 ## 最終的なカウント```python
answer = sum(1 for t in range(LIMIT + 1) if 1 <= ways[t] <= 10)
```これがすべてを意味します$t$それはタイプです$L(1)$を通して$L(10)$。

 # 例を確認する

 ## 例:$t=8$

$$3^2-1^2=9-1=8.$$ラミナは 1 つだけ存在します。 

それで$8$タイプです$L(1)$。 

正しい。 

- -

＃＃ 例：$t=32$2 つの表現:$$6^2-2^2 = 36-4 = 32,$$そして$$5^2-1^2 = 25-1 = 24$$おっと — 32 ではありません。正しい 2 番目のものは$$9^2-7^2 = 81-49 = 32.$$したがって、正確に 2 つの層があります$32$、それを型にします$L(2)$。 

正しい。
