[プロジェクト オイラー問題 347](https://projecteuler.net/problem=347)

 ## 解決策

 **答え:**`11109800204052`計算する必要があります$$S(N)=\sum_{\substack{p<q\\ p,q\text{ primes}}} M(p,q,N),$$どこ$M(p,q,N)$は最大の整数です$\le N$その素数は _ まさに _ です$p$そして$q$。 

例えば、$$M(2,3,100)=96=2^5\cdot 3,$$

$$M(3,5,100)=75=3\cdot 5^2.$$私たちは求められています$$S(10^7).$$---

 # 数学的分析

 A number counted by$M(p,q,N)$形を持っています$$p^a q^b,$$と$$a\ge1,\qquad b\ge1,$$他に素因数はありません。 

したがって、固定された個別の素数の場合$p,q$、$$M(p,q,N)=\max \{p^a q^b \le N\}.$$そのような番号が存在しない場合は、$M=0$。 

---

 ## 重要な所見

 仮定してください$p q > N$。 

次に、両方で割り切れる最小の数でも、$p$そして$q$を超える$N$、 それで$$M(p,q,N)=0.$$したがって、次を満たす素数ペアのみが必要です。$$pq \le N.$$のために$N=10^7$、これは管理可能です。 

---

 ## の効率的な計算$M(p,q,N)$固定用$p,q$、私たちが欲しいのは$$\max p^a q^b \le N.$$パワーは指数関数的に増大するため、すべての指数に対するブルート フォースは十分に高速です。 

アルゴリズム:

 - すべてのパワーを生成します$p$:$$p,p^2,p^3,\dots$$まで$N$。 
- すべてのパワーを生成します$q$:$$q,q^2,q^3,\dots$$まで$N$。 
- すべての製品をチェックしてください$p^a q^b\le N$、最大値を維持します。 

べき乗の数はごくわずかです:$$\log_2(10^7)\approx 23.$$したがって、各ペアにかかる操作は数百回だけです。 

---

 ## 素数ペアの数

 以下までのすべての素数が必要です$N$、ただし、とペアリングするだけです$$pq\le N.$$素数ごとに$p$、 有効$q$満足する$$q\le \frac{N}{p}.$$これにより、およそ数十万のペアが生成され、完全に実現可能です。 

---

 # Pythonの実装```python
from math import isqrt

N = 10_000_000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
def prime_sieve(limit):
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"

    for i in range(2, isqrt(limit) + 1):
        if sieve[i]:
            step = i
            start = i * i
            sieve[start:limit + 1:step] = b"\x00" * (((limit - start) // step) + 1)

    return [i for i in range(limit + 1) if sieve[i]]

primes = prime_sieve(N // 2)

# ------------------------------------------------------------
# Compute M(p,q,N)
# ------------------------------------------------------------
def M(p, q, N):
    best = 0

    # Generate powers of p
    pp = p
    p_powers = []
    while pp <= N:
        p_powers.append(pp)
        pp *= p

    # Generate powers of q
    qq = q
    q_powers = []
    while qq <= N:
        q_powers.append(qq)
        qq *= q

    # Try all products
    for a in p_powers:
        for b in q_powers:
            val = a * b
            if val <= N:
                if val > best:
                    best = val

    return best

# ------------------------------------------------------------
# Compute S(N)
# ------------------------------------------------------------
total = 0

L = len(primes)

for i in range(L):
    p = primes[i]

    if p * p > N:
        break

    for j in range(i + 1, L):
        q = primes[j]

        if p * q > N:
            break

        total += M(p, q, N)

print(total)
```---
