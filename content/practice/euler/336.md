 #1. 数学的分析

 ## サイモンの戦略

 サイモンは列車を左から右に修正します。 

キャリッジを修理しているとします。$A_i$所定の位置に$i$。 

次の 2 つのケースがあります。 

1. もし$A_i$はすでに終了しているため、1 回反転するだけで十分です。$$R_i$$2. それ以外の場合は、サイモンが最初に送信します$A_i$最後まで移動してから、最終位置まで移動します。$$R_j,\quad R_i$$どこ$j$の現在の位置です$A_i$。 

したがって:

 - 各ステージで最大 2 回のリバーサルが使用されます。 
- 最終ステージを除き、1 つだけ使用できます。 

だから、$n$キャリッジの最大反転可能回数は$$2(n-2)+1=2n-3.$$これを達成する順列は **maximix 配置**と呼ばれます。 

---

 ## maximix 配置の再帰構造

 文字に最大の配置があると仮定します。$$B,C,D,\dots$$そしてそれを呼びます$q$。 

今挿入します$A$。 

Simon が最大移動数を必要とする場合:

 -$A$最初でも最後でもありません。 

順列を次のように書きます$$P\,A\,S$$両方とも$P,S\neq\emptyset$。 

サイモンは次のことを実行します。 

1. で始まる逆サフィックス$A$:$$P\,A\,S \to P\,S^R\,A$$2. 列車全体を逆転させます。$$P\,S^R\,A \to A\,S\,P^R$$固定後$A$、残りのサフィックス自体は maximax 配列である必要があります。 したがって：$$q = S\,P^R.$$したがって、すべての最大ミックス配置は、次のようにして小さい配置から取得されます。$$P\,A\,S$$どこ$q=S\,P^R$。 

もし$q$長さがある$m=n-1$、分割ポイントを選択します$k$と$$1 \le k \le m-1.$$それから：

-$S=q[:k]$-$P^R=q[k:]$-$P=(q[k:])^R$与える$$p=(q[k:])^R + A + q[:k].$$これにより、**すべて**のマキシミックス配置が再帰的に生成されます。 

カウントは次の条件を満たします。$$M_n=(n-2)M_{n-1}, \qquad M_2=1,$$それで$$M_n=(n-2)!.$$のために$n=11$:$$M_{11}=9!=362880,$$直接生成できるほど小さい。

 #2. Pythonの実装```python
def maximix(chars):
    n = len(chars)

    # Base case: for two letters, only the reversed order is maximix
    if n == 2:
        return [chars[1] + chars[0]]

    first = chars[0]
    result = []

    # Generate all maximix arrangements of the remaining letters
    for q in maximix(chars[1:]):

        m = n - 1

        # Split q into S + P^R
        for k in range(1, m):

            # Reconstruct P A S
            p = q[k:][::-1] + first + q[:k]

            result.append(p)

    return sorted(result)

arrangements = maximix("ABCDEFGHIJK")

answer = arrangements[2010]   # 2011th lexicographic (1-indexed)

print(answer)
```---
