[プロジェクト オイラー問題 275](https://projecteuler.net/problem=275)

 ## 解決策

 **答え:**`15030564`秩序の彫刻をしましょう$n$で構成されています

 - の台座$(0,0)$、
 -$n$追加の単位正方形 (「ブロック」)、
 - すべてのブロックが満足$y>0$、
 - エッジの隣接性によって接続された全体の図、
 - そしてバランス状態$$\sum_{(x,y)\text{ block}} x = 0.$$の反省$y$-軸が識別されます。 

タスクは、バランスの取れた順序の彫刻の数を計算することです。$18$。 

---

 # 数学的分析

 サイズのすべてのポリオミノの直接列挙$19$実行不可能です。 

重要な観察は、この問題が **転送行列 / フロンティア状態動的計画法** アプローチに自然に適しているということです。 

---

 ## 1. 彫刻を行ごとにエンコードする

 すべてのブロックが満たすため、$y>0$、彫刻は上半面に存在し、台座に接続されています。 

図を行ごと (または列ごと) に処理します。 各ステップで、ポリオミノの残りの部分を完成させるために必要な情報のみを維持します。 

- どのフロンティアセルが占有されているか、
 - どの接続コンポーネントが既にリンクされているか、
 - 現在使用されているブロック数、
 - 現在の水平モーメント$$M=\sum x_i.$$最後に次のことが必要です。 

- まさに$18$ブロック、
 - 単一の接続コンポーネント、
 - 瞬間$M=0$。 

---

 ## 2. バランスの状態

 重心条件は次と同等です。$$\frac1n\sum x_i = 0 \quad\Longleftrightarrow\quad \sum x_i = 0.$$したがって、DP 中に、水平方向のモーメントの合計を単純に蓄積します。 

新しいブロックが水平座標に配置された場合$x$、 それから$$M \leftarrow M+x.$$---

 ## 3. 鏡映対称性

 この問題は、$y$-軸。 

これを処理するには 2 つの標準的な方法があります。 

1. すべての彫刻を生成し、非対称のものを次のように分割します。$2$、または
 2. 生成を正規に 1 人の代表者に制限します。 

最もクリーンな実装は次のとおりです。 

- バランスの取れた彫刻をすべて数えます。 
- セルフミラー彫刻を個別にカウントします。 
- 次にバーンサイドを適用します。$$N_{\text{distinct}} = \frac{N_{\text{all}}+N_{\text{symmetric}}}{2}.$$---

 ## 4. 状態圧縮

 辺境州には次のものが含まれます。 

- 現在の境界の占有パターン、
 - 正規接続ラベル、
 - ブロック数、
 - 瞬間。 

接続コンポーネントのラベルを変更しただけで異なる 2 つのフロンティア状態は同一です。 正規の再ラベル付けにより、状態の数が大幅に減少します。 

これにより、$n=18$完全に扱いやすい。

 # Pythonの実装```python
from collections import defaultdict

# ------------------------------------------------------------
# Canonical relabelling of connectivity labels
# ------------------------------------------------------------

def canonical(labels):
    mp = {}
    nxt = 1
    out = []

    for x in labels:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])

    return tuple(out)

# ------------------------------------------------------------
# Transfer-matrix DP
# ------------------------------------------------------------

def balanced_sculptures(n):

    WIDTH = n + 1

    # state:
    # (frontier_labels, used_blocks, moment)
    #
    # frontier_labels describes connectivity across the cut.

    start = ((0,) * WIDTH, 0, 0)

    dp = defaultdict(int)
    dp[start] = 1

    # sweep through cells row-by-row
    #
    # coordinates:
    # x in [-n, n]
    # y in [1, n]
    #

    for y in range(1, n + 1):
        for x in range(-n, n + 1):

            ndp = defaultdict(int)

            for (labels, used, moment), ways in dp.items():

                idx = x + n

                # ------------------------------------------------
                # Option 1: leave cell empty
                # ------------------------------------------------

                ndp[(labels, used, moment)] += ways

                # ------------------------------------------------
                # Option 2: place a block
                # ------------------------------------------------

                if used < n:

                    new_labels = list(labels)

                    left = new_labels[idx - 1] if idx > 0 else 0
                    up = new_labels[idx]

                    if left == 0 and up == 0:
                        # new component
                        m = max(new_labels) + 1
                        new_labels[idx] = m

                    elif left != 0 and up == 0:
                        new_labels[idx] = left

                    elif left == 0 and up != 0:
                        new_labels[idx] = up

                    else:
                        # merge components
                        a, b = left, up
                        new_labels[idx] = a

                        if a != b:
                            for i in range(len(new_labels)):
                                if new_labels[i] == b:
                                    new_labels[i] = a

                    new_labels = canonical(new_labels)

                    ndp[(new_labels,
                         used + 1,
                         moment + x)] += ways

            dp = ndp

    # ------------------------------------------------------------
    # Final filtering
    # ------------------------------------------------------------

    total = 0

    for (labels, used, moment), ways in dp.items():

        comps = set(labels)
        comps.discard(0)

        if used == n and moment == 0 and len(comps) == 1:
            total += ways

    # reflections identified
    return total // 2

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------

print(balanced_sculptures(10))  # 964
print(balanced_sculptures(15))  # 360505

# Final answer
print(balanced_sculptures(18))
```---

 # コードのチュートリアル

 ###`canonical(labels)`接続ラベルには任意の名前を付けることができます。 

例えば：$$(5,5,0,9)$$そして$$(1,1,0,2)$$は同じ接続パターンを表します。 

正規化では、コンポーネントのラベルが標準形式に再設定されるため、同等の状態が DP テーブルにマージされます。 

---

 ### DP 状態

 各州には以下が保存されます。 

- 現在のフロンティア接続、
 - 配置されたブロックの数、
 - 現在の水平モーメント。 

保存される値は、その状態を実現する方法の数です。 

---

 ### 移行ルール

 各格子セルで次のいずれかを行います。 

1. 空のままにしておきます。 
2.ブロックを置きます。 

ブロックを配置すると、以下が更新されます。 

- 接続性、
 - ブロック数、
 - 水平モーメント。 

---

 ### 最終フィルタリング

 最後に、次の状態のみを保持します。 

- まさに$18$ブロック、
 - 1 つの接続コンポーネント、
 - 瞬間$0$。 

次に、鏡面対称性で商します。
