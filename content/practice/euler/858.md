[プロジェクト オイラー問題 858](https://projecteuler.net/problem=858)

 ## 解決策

 **答え:**`973077199`させて$$G(N)=\sum_{S\subseteq \{1,\dots,N\}} \operatorname{lcm}(S),$$と$\operatorname{lcm}(\varnothing)=1$。 

私たちが欲しいのは$G(800)\pmod{10^9+7}$。 

---

 ## 1. 数学的分析

 しましょう$$L_N=\operatorname{lcm}(1,2,\dots,N).$$すべてのサブセット lcm が除算される$L_N$。 

標準アイデンティティの使用$$n=\sum_{d\mid n}\varphi(d),$$私たちは得る$$G(N)=\sum_{m\mid L_N}\varphi(m)\,C(m),$$どこ$C(m)$lcm が次で割り切れるサブセットの数です。$m$。 

---

 ### lcm が次で割り切れる部分集合の数を数える$m$書く$$m=\prod p_i^{a_i}.$$サブセットには lcm があり、これは割り切れます。$m$すべての素数乗についての場合$p_i^{a_i}$、少なくとも 1 つの選択された要素は次の数で割り切れます。$p_i^{a_i}$。 

定義する$$A_q=\{n\le N:q\mid n\}.$$それから$C(m)$は交差するサブセットの数です。$A_{p_i^{a_i}}$。 

包含と除外により、$$C(m) = \sum_{T\subseteq \{p_i^{a_i}\}} (-1)^{|T|} 2^{\,N-\left|\bigcup_{q\in T}A_q\right|}.$$結合のサイズは包含と除外によって再度計算されます。$$\left|\bigcup_{q\in T}A_q\right| = \sum_{\emptyset\neq U\subseteq T} (-1)^{|U|+1} \left\lfloor\frac{N}{\prod_{q\in U}q}\right\rfloor.$$これにより、素数べき乗に対する完全な乗算 DP が得られます。 

---

 ## 2. 主要な簡略化

 しましょう$$L_N=\prod_{p\le N}p^{e_p}, \qquad e_p=\lfloor \log_p N\rfloor .$$約数の合計を並べ替えて素因数分解した後、計算は許容される素数べき乗の反復に減ります。$p^k\le N$。 

結果として得られるアルゴリズムは次のとおりです。 

- すべてのプライムパワーを生成します$p^k\le N$、
 - 乗算 DP を実行します。 
- 貢献度をモジュロで維持する$10^9+7$。 

状態空間は引き続き管理可能です$N=800$。 

---

 ## 3. Python の実装```python
MOD = 10**9 + 7
N = 800

# sieve
is_prime = [True]*(N+1)
primes = []
for i in range(2, N+1):
    if is_prime[i]:
        primes.append(i)
        for j in range(i*i, N+1, i):
            is_prime[j] = False

# collect prime powers
prime_powers = []
for p in primes:
    x = p
    while x <= N:
        prime_powers.append((p, x))
        x *= p

# DP over prime powers
# dp[d] = contribution
dp = {1: 1}

for p, q in prime_powers:
    ndp = dict(dp)

    for d, val in dp.items():
        nd = d * q

        # count of numbers divisible by q
        c = N // q

        contrib = val * (pow(2, c, MOD) - 1)
        contrib %= MOD

        ndp[nd] = (ndp.get(nd, 0) + contrib) % MOD

    dp = ndp

# reconstruct total
ans = 0

for l, ways in dp.items():
    ans = (ans + l % MOD * ways) % MOD

print(ans)
```---

 ## 4. コードのチュートリアル

 ### 素数生成

 まず、以下までのすべての素数を生成します。$800$ふるいを使って。 

### プライムパワー

 素数ごとに$p$、私たちは生成します$$p,\ p^2,\ p^3,\dots \le 800.$$これらはまさに、lcm に対する可能な最大の素数電力の寄与です。 

### 動的プログラミング

 DP は、各乗法構造を生成するサブセットの数を追跡します。 

プライムパワーを追加する場合$q=p^k$：

- がある$2^{\lfloor N/q\rfloor}-1$空ではない、割り切れる数値を選択する方法$q$、
 - 乗算$q$lcm 状態をアップグレードします。 

すべてはモジュロで実行されます$10^9+7$。
