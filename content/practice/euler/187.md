[プロジェクト オイラー問題 187](https://projecteuler.net/problem=187)

 ## 解決策

 **答え:**`17427258`私たちは整数を数えています$$n < 10^8$$**ちょうど 2 つの素因数**を持ち、多重度で数えられます。 

このような数は**半素数**と呼ばれます。 

例:

 -$15 = 3\cdot 5$-$9 = 3^2$-$12 = 2^2\cdot 3$→ 許可されません（多重度を数える 3 つの素因数）

 したがって、フォームのすべての数値が必要です$$n = pq$$どこ$p,q$は素数であり、$p \le q$。 

---

 # 数学的分析

 素数のペアを数える必要があります$(p,q)$そのような$$pq < 10^8.$$二重カウントを避けるために、強制的に$$p \le q.$$したがって、各素数に対して$p$、素数を数えます$q$満足のいく$$q \ge p,\qquad q < \frac{10^8}{p}.$$---

 ## 重要な所見

 もし$p > \sqrt{10^8} = 10^4$、 それから$$p^2 > 10^8,$$だから無効です$q \ge p$存在します。 

したがって、必要なのは素数だけです$$p \le 10^4.$$そのような素数ごとに$p$:

 1. しましょう$$M = \left\lfloor \frac{10^8-1}{p} \right\rfloor.$$2. 素数を数える$q$と$$p \le q \le M.$$もし$\pi(x)$素数の数を表します$\le x$、そしてもし$p$です$i$-番目の素数 (0 から始まる)、許容される数$q$は$$\pi(M) - i.$$有効なすべての合計$p$答えを出します。 

---

 # 効率的なアルゴリズム

 必要なものは次のとおりです。 

1. 以下のすべての素数$10^8 / 2 = 5\times10^7$。 
2.素数計数の高速化$\pi(x)$。 

エラトステネスのふるい$5\times10^7$最適化された Python/PyPy で実現可能ですが、概念的にはこの方法は簡単です。 

疑似プロセス:

 - までのすべての素数を生成します$5\times10^7$。 
- 素数ごとに$p \le 10^4$:

 - 素数がいくつあるかを調べます$\le (10^8-1)/p$。 
- のインデックスを減算します。$p$強制する$q \ge p$。 

複雑さはふるいによって支配されます。 

---

 # Pythonの実装```python
from bisect import bisect_right
from math import isqrt

LIMIT = 10**8

# We only need primes up to LIMIT // 2
MAXP = LIMIT // 2

# Sieve of Eratosthenes
sieve = bytearray(b"\x01") * (MAXP + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(MAXP) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:MAXP + 1:step] = b"\x00" * (((MAXP - start) // step) + 1)

# Extract primes
primes = [i for i in range(2, MAXP + 1) if sieve[i]]

answer = 0

# Only need p <= sqrt(LIMIT)
root = isqrt(LIMIT)

for i, p in enumerate(primes):
    if p > root:
        break

    max_q = (LIMIT - 1) // p

    # Number of primes <= max_q
    count = bisect_right(primes, max_q)

    # Enforce q >= p
    answer += count - i

print(answer)
```---
