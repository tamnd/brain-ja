 ## 解決策

 **答え:**`1922364685`すべての整数を求めます$0<n<64\,000\,000$そのような$$\sigma_2(n)=\sum_{d\mid n} d^2$$は完全な平方であり、そのようなものをすべて合計します$n$。 

---

 # 数学的分析

 ## 1. の乗法性$\sigma_2$任意の正の整数の場合$n$素因数分解あり$$n=\prod p_i^{a_i},$$除数二乗和関数は乗法です。$$\sigma_2(n)=\prod \left(1+p_i^2+p_i^4+\cdots+p_i^{2a_i}\right).$$のすべての約数が次のとおりです。$n$第一次権力から独立して形成される。 

プライムパワーの場合:$$\sigma_2(p^a)=1+p^2+p^4+\cdots+p^{2a} =\frac{p^{2(a+1)}-1}{p^2-1}.$$それで、計算できれば$\sigma_2(n)$すべての人にとって効率的に$n<64\cdot10^6$、結果が完全な正方形であるかどうかをテストするだけです。 

---

 ## 2. 効率的なふるいの計算

 までのすべての数値の直接因数分解$64$百万は Python では遅すぎるでしょう。 

代わりに、除数ふるいを使用します。 

観察する：$$\sigma_2(n)=\sum_{d\mid n} d^2.$$したがって、配列を初期化することができます。$$S[n]=0$$そしてすべての約数について$d$、 追加$d^2$すべての倍数に$d$。 

擬似構造:```python
for d in range(1, LIMIT):
    d2 = d*d
    for multiple in range(d, LIMIT, d):
        S[multiple] += d2
```これはエラトステネスのふるいに似ており、およそ$$N\log N$$時間。 

のために$N=64\,000\,000$、これは大規模ですが、最適化された実装 (特に PyPy / 低レベル言語) で実現可能です。 

---

 ## 3. 完全二乗検定

 それぞれについて$n$、計算後$\sigma_2(n)$、それが正方形であるかどうかをテストします。 

整数の平方根を使用する:$$r = \lfloor \sqrt{\sigma_2(n)} \rfloor$$そしてチェック:$$r^2 = \sigma_2(n).$$Python の場合:```python
r = isqrt(value)
if r*r == value:
    ...
```の`math.isqrt`関数は正確であり、浮動小数点エラーを回避します。 

---

 # Pythonの実装```python
from math import isqrt

LIMIT = 64_000_000

# sigma2[n] will contain σ₂(n)
sigma2 = [0] * LIMIT

# Divisor sieve:
# add d² to every multiple of d
for d in range(1, LIMIT):
    d2 = d * d
    for multiple in range(d, LIMIT, d):
        sigma2[multiple] += d2

# Sum all n for which σ₂(n) is a perfect square
answer = 0

for n in range(1, LIMIT):
    s = sigma2[n]
    r = isqrt(s)
    if r * r == s:
        answer += n

print(answer)
```---

 # 小規模な例の検証

 のために$n=10$:

 約数は次のとおりです。$$1,2,5,10$$そして$$\sigma_2(10)=1^2+2^2+5^2+10^2 =1+4+25+100 =130.$$以来$130$は正方形ではないので、10はカウントされません。 

のために$n=1$:$$\sigma_2(1)=1,$$これは完全な正方形なので、1 が含まれます。 

ふるいはこれらを正しく計算します。
