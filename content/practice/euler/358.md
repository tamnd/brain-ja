[プロジェクト オイラー問題 358](https://projecteuler.net/problem=358)

 ## 解決策

 **答え:**`3284144505`させて$N$巡回数になります。 巡回数に関する古典的な事実は次のとおりです。 

- すべての巡回数は、次の繰り返し小数から来ています。$1/p$、 どこ$p$は素数です$10$原始根モジュロです$p$(**完全なreptendプライム**)。 
- 巡回数は次の繰り返しです。$1/p$:$$N=\frac{10^{p-1}-1}{p}$$まさに$p-1$数字。 

例えば：$$\frac{1}{7}=0.\overline{142857}$$巡回数を与える$142857$。 

---

 ### ステップ 1: 左端の数字を使用する

 小数展開が始まることがわかります。$$0.00000000137\cdots$$したがって$$\frac{1}{p} \in \left[ 1.37\times 10^{-9}, 1.38\times 10^{-9} \right)$$それで$$\frac{10^{11}}{138} < p \le \frac{10^{11}}{137}.$$これにより、次のようになります。$$724\,637\,681 < p < 729\,927\,007.$$---

 ### ステップ 2: 最後の 5 桁を使用します

 巡回番号の末尾は$56789$。 

以来$$pN = 10^{p-1}-1,$$モジュロがあります$100000$:$$p\cdot 56789 \equiv -1 \pmod{100000}.$$モジュラーの逆$56789$モジュロ$100000$与える:$$p \equiv 9891 \pmod{100000}.$$上記の間隔を検索すると、候補が 3 つだけ表示されます。$$725509891,\quad 726509891,\quad 729809891.$$ここで、完全な reptend 条件を課します (つまり、$10$秩序がある$p-1$モッド$p$):

 -$725509891$: 周期的ではない
 -$726509891$: 周期的ではない
 -$729809891$: 循環 ✓

 したがって、$$p = 729809891.$$---

 ### ステップ 3: 桁の合計

 完全なRependプライムの場合$p$、繰り返しには長さがあります$p-1$、ミディの定理によれば、後半は前半の 9 の補数になります。 したがって、各ペアの数字の合計は次のようになります。$9$。 

したがって、桁の合計は次のようになります$$9\cdot \frac{p-1}{2}.$$代わりの$p=729809891$:$$9\cdot \frac{729809890}{2} = 9\cdot 364904945 = 3284144505.$$### Python の実装```python
from sympy import primerange, factorint

# Interval forced by leading digits 00000000137
lo = int(10**11 / 138) + 1
hi = int(10**11 / 137)

def is_full_reptend_prime(p):
    """Check whether 10 is a primitive root mod p."""
    factors = factorint(p - 1)
    return all(pow(10, (p - 1) // q, p) != 1 for q in factors)

def last_five_digits_match(p):
    """Check that repetend ends in 56789."""
    # N = (10^(p-1) - 1) / p
    mod = p * 100000
    n_mod = (pow(10, p - 1, mod) - 1) // p
    return n_mod % 100000 == 56789

candidate = None

for p in primerange(lo, hi + 1):
    # congruence from last five digits
    if p % 100000 != 9891:
        continue

    # first 11 digits must be 00000000137
    if 10**11 // p != 137:
        continue

    if last_five_digits_match(p) and is_full_reptend_prime(p):
        candidate = p
        break

# digit sum of cyclic number
answer = 9 * (candidate - 1) // 2
print(answer)
```### コードのチュートリアル

 - **範囲の絞り込み**: の間隔を計算します。$p$プレフィックスを使用して`00000000137`。 
- **合同フィルター**: 満足する素数のみを保持します$$p\cdot 56789\equiv -1 \pmod{100000}.$$- **プレフィックス テスト**: 最初の 11 桁が正確であることを検証します。`00000000137`。 
- **周期テスト**: をチェックします。$10$プリミティブルートMODです$p$、小数展開が循環的であることを保証します。 
- **桁合計**: 巡回数の補数プロパティを使用して計算します。$$9\cdot\frac{p-1}{2}.$$最終的な健全性チェック:

 -$p$必要な間隔内にある ✓
 - 繰り返しは次で終了します`56789`✓
 - 完全な周期特性が保持されます ✓
 - 桁の合計の式は既知の例と一致します ($1/7\to27$、$1/17\to72$) ✓
