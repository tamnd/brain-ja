[プロジェクト オイラー問題 649](https://projecteuler.net/problem=649)

 ## 解決策

 **答え:**`924668016`ボード座標を次のようにします$0,\dots,n-1$コインを使って各方向に$(x,y)$。 移動すると、**ちょうど 1 つの座標**が次の 1 つだけ減少します。$\{2,3,5,7\}$、したがって、ゲームは公平な通常プレイ ゲームであり、独立したサブゲームに分解されます。 

## 1. 数学的分析

 ### ステップ 1: グランディな価値観を 1 次元で表現する

 定義する$g(k)$座標上の線上のトークンのグランディ数として$k$。 

再発というのは、$$g(k)=\operatorname{mex}\{g(k-2),g(k-3),g(k-5),g(k-7)\},$$ここには、有効な先行者のみが含まれます。 

最初の項の計算:$$0,0,1,1,2,2,3,3,4,0,0,1,1,2,2,3,3,4,\dots$$これは周期的です$9$:$$(0,0,1,1,2,2,3,3,4).$$したがって、各座標は次のいずれかに寄与します。$\{0,1,2,3,4\}$。 

のために$$n=10{,}000{,}019,$$我々は持っています$$10{,}000{,}019 = 9\cdot 1{,}111{,}113 + 2.$$したがって、座標のグランディ数は次のようになります。$$\#(0)=2q+2,\quad \#(1)=2q,\quad \#(2)=2q,\quad \#(3)=2q,\quad \#(4)=q,$$と$q=1{,}111{,}113$、つまり$$(2222228,\ 2222226,\ 2222226,\ 2222226,\ 1111113).$$### ステップ 2: 正方形のグランディ値

 水平移動と垂直移動が独立しているため、$$G(x,y)=g(x)\oplus g(y).$$xor 値によってすべてのボードの正方形をカウントすると、次のようになります。$$v = \bigl( 20987734567981,\, 19753162469208,\, 19753162469208,\, 19753162469208,\, 4938292839528,\, 4938288395076,\, 4938288395076,\, 4938288395076 \bigr),$$グランディな価値観のために$0,\dots,7$。 

### ステップ 3:$100$識別可能なコイン

 合計ポジション Grundy は、すべてのコイン Grundy の xor です。 

xor がゼロ以外の場合、アリスが勝ちます。 

コインは区別可能であり、重複する可能性があるため、xor を使用した構成の数は$0$です$100$-xor 畳み込み係数を倍します$0$。 

ウォルシュ – アダマール変換を使用すると、次のようになります。$$L = \frac{1}{8} \sum_{k=0}^{7} \widehat v(k)^{100},$$どこ$$\widehat v = ( 100000380000361,\, 1234576543225,\, 1234576543225,\, 1234576543225,\, 60494063950849,\, 1234567654321,\, 1234567654321,\, 1234567654321 ).$$アレンジメントの総数は、$$T=(n^2)^{100}.$$したがって、$$M(n,100)=T-L.$$最後を取る$9$数字は次のようになります。$$M(10{,}000{,}019,100)\equiv 924668016 \pmod{10^9}.$$## 2. Python の実装```python
from collections import Counter

MOD = 10**9
n = 10_000_019
c = 100

# 1D Grundy pattern (period 9)
pattern = [0, 0, 1, 1, 2, 2, 3, 3, 4]

# Count coordinate Grundy frequencies
q, r = divmod(n, 9)

coord_count = [0] * 5
for g in pattern:
    coord_count[g] += q
for g in pattern[:r]:
    coord_count[g] += 1

# Count board-square Grundy values G(x,y)=gx xor gy
board_count = [0] * 8
for gx, cx in enumerate(coord_count):
    for gy, cy in enumerate(coord_count):
        board_count[gx ^ gy] += cx * cy

# Walsh-Hadamard transform values
transform = []
for mask in range(8):
    s = 0
    for x, v in enumerate(board_count):
        if bin(mask & x).count("1") % 2:
            s -= v
        else:
            s += v
    transform.append(s)

# Number of losing positions (xor = 0)
losing = sum(pow(x, c) for x in transform) // 8

# Total arrangements
total = pow(sum(board_count), c)

answer = (total - losing) % MOD
print(answer)
```## 3. 例の検証

- 変換方法は正確であり、xor の独立性を利用しています。 
- 小さな症例は完全に一致し、再発と周期性が確認されます。
