[プロジェクト オイラー問題 178](https://projecteuler.net/problem=178)

 ## 解決策

 **答え:**`126461847755`以下の**パンデジタルステップ番号**の数を求めます。$10^{40}$。 

**ステップ番号**は、隣接する桁が正確に異なる番号です。$1$。 

例:

 -$45656$はステップ番号です。$$|4-5|=|5-6|=|6-5|=|5-6|=1.$$- 数値自体に先行ゼロを使用することはできません。 

すべての桁の場合、数値は **パンデジタル** です$0,1,\dots,9$少なくとも 1 回は表示されます。 

すべてのパンデジタル ステップ番号を最大でもカウントする必要があります。$40$数字。 

---

 # 数学的分析

 ステップ番号の定義プロパティは完全にローカルです。 

- 数字から$d$、次の桁は次のとおりです。$d-1$または$d+1$。 

これは当然 **動的プログラミング** を示唆しています。 

追加のパンデジタル条件は、これまでに出現した数字を追​​跡する必要があることを意味します。 

---

 ## 1. 状態の表現

 ステップ番号を 1 桁ずつ構築しているとします。 

いつでも次のことを知る必要があります。 

1. 現在の最後の桁、
 2. すでに表示されている数字。 

使用される数字のセットを 10 ビット マスクでエンコードします。$$\text{mask} \in [0,2^{10}-1].$$少し$k$は$1$桁が違う場合$k$が現れた。 

たとえば:

 - マスク$= 0000000011_2$数字を意味します$0,1$現れた、
 - マスク$=1111111111_2 = 1023$すべての数字が表示されたことを意味します。 

定義する$$dp[\ell][d][m]$$ステップ番号の数として:

 - 長さの$\ell$、
 - 数字で終わる$d$、
 - 数字セットを使用している$m$。 

---

 ## 2. 初期条件

 有効な数値をゼロで始めることはできません。 

それで長さに関しては$1$:$$dp[1][d][1\ll d]=1 \quad\text{for } d=1,\dots,9.$$---

 ## 3. 移行

 現在の最後の桁が$d$の場合、次の数字は次のようになります。 

-$d-1$もし$d>0$、
 -$d+1$もし$d<9$。 

数字まで拡張するとします$nd$。 それから：$$\text{newmask}=m\cup\{nd\} = m \,|\, (1\ll nd).$$したがって、次のようになります。$$dp[\ell+1][nd][newmask] \;+=\; dp[\ell][d][m].$$---

 ## 4. パンデジタル数字を数える

 すべての数字が表示される場合、その数字はパンデジタルです。$$m = 2^{10}-1 = 1023.$$したがって、それぞれの長さに対して$\ell$、$$\text{count}(\ell) = \sum_{d=0}^{9} dp[\ell][d][1023].$$すべての長さが必要です$1$を通して$40$。 

---

 # 複雑さ

 以下のものがあります:

 -$40$長さ、
 -$10$可能な終了数字、
 -$2^{10}=1024$マスク。 

したがって、状態の合計は次のようになります。$$40 \times 10 \times 1024 \approx 4\times 10^5,$$それは小さいです。 

---

 # Pythonの実装```python
from collections import defaultdict

FULL = (1 << 10) - 1   # 1023, all digits used

# dp[digit][mask] = count
dp = defaultdict(int)

# Initialize 1-digit numbers (no leading zero)
for d in range(1, 10):
    dp[(d, 1 << d)] = 1

answer = 0

# Build lengths from 1 up to 40
for length in range(1, 41):

    # Count pandigital numbers of this length
    for (digit, mask), cnt in dp.items():
        if mask == FULL:
            answer += cnt

    # Build next layer
    new_dp = defaultdict(int)

    for (digit, mask), cnt in dp.items():

        # Move to digit-1
        if digit > 0:
            nd = digit - 1
            new_mask = mask | (1 << nd)
            new_dp[(nd, new_mask)] += cnt

        # Move to digit+1
        if digit < 9:
            nd = digit + 1
            new_mask = mask | (1 << nd)
            new_dp[(nd, new_mask)] += cnt

    dp = new_dp

print(answer)
```---
