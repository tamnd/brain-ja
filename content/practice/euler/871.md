[プロジェクト オイラー問題 871](https://projecteuler.net/problem=871)

 ## 解決策

 **答え:**`2848790`条件を注意深く書き直してみましょう。 

最大のサブセットが必要です$A\subseteq S$そのような$$|A\cup f(A)|=2|A|.$$いつもから$|f(A)|\le |A|$、平等は次の場合にのみ起こります。 

1.$f$**は単射的です$A$** （それで$|f(A)|=|A|$）、
 2.$A\cap f(A)=\varnothing$(したがって、結合サイズが追加されます)。 

したがって、ドリフトサブセットはまさにセットです$A$ここで:

 - の 2 つの要素はありません$A$同じ画像にマッピングします。 
- の要素はありません$A$の別の要素にマップします$A$。 

同様に、1 つのエッジを持つ無向グラフを描くと、$\{x,f(x)\}$それぞれに$x$(自己ループを無視して)、次に選択します$x\in A$エッジを選択することを意味します$x\to f(x)$、条件は次のようになります。 

> 選択したエッジはペアごとに頂点が共通でなければなりません。 

それで$D(f)$は、このグラフの **最大一致サイズ** です。 

のために$$f_n(x)=x^3+x+1 \pmod n,$$グラフには頂点ごとに 1 つの出力エッジがあるため、すべての接続されたコンポーネントは関数グラフ (ツリーがそこに入力される有向サイクル) になります。 このようなグラフ上の最大マッチングは、ツリー DP とサイクル DP を介してコンポーネントごとに線形時間で解決できます。 

ルート化されたツリー上の動的プログラミングの状態は次のとおりです。 

-$A(v)$: サブツリー内で最も一致する場合$v$**その親と一致しません**、
 -$B(v)$: サブツリー内で最も一致する場合$v$**はその親**と一致します。 

トランジション:$$B(v)=\sum A(c),$$子供たち以上に$c$、

そして$$A(v) = \sum A(c) + \max\!\left(0,\max_c\bigl(1+B(c)-A(c)\bigr)\right),$$なぜなら$v$最大 1 人の子供とマッチングできます。 

次に、サイクルごとに、サイクル全体で小さな DP を実行します (ケース分割: 最初のサイクル エッジが使用されるか使用されないか)。 

正しい Python 実装は次のとおりです。```python
from collections import deque

def D(n):
    # Build function graph
    f = [(x*x*x + x + 1) % n for x in range(n)]

    rev = [[] for _ in range(n)]
    indeg = [0] * n

    for x, y in enumerate(f):
        rev[y].append(x)
        indeg[y] += 1

    # Peel trees away to identify cycle vertices
    q = deque(i for i in range(n) if indeg[i] == 0)
    removed = [False] * n
    order = []

    while q:
        v = q.popleft()
        removed[v] = True
        order.append(v)

        y = f[v]
        indeg[y] -= 1
        if indeg[y] == 0:
            q.append(y)

    # Tree DP
    A = [0] * n
    B = [0] * n

    for v in order:
        base = 0
        gain = 0

        for ch in rev[v]:
            if removed[ch]:
                base += A[ch]
                gain = max(gain, 1 + B[ch] - A[ch])

        B[v] = base
        A[v] = base + gain

    # Path matching DP
    def solve_path(AA, BB):
        free = 0
        matched = -10**18

        m = len(AA)

        for i in range(m):
            new_free = -10**18
            new_matched = -10**18

            # v unmatched to next
            new_free = max(new_free, free + AA[i])

            # v matched to next
            if i < m - 1:
                new_matched = max(
                    new_matched,
                    free + 1 + BB[i]
                )

            # v already matched to previous
            new_free = max(new_free, matched + BB[i])

            free, matched = new_free, new_matched

        return max(free, matched)

    # Process cycle components
    vis = [False] * n
    ans = 0

    for s in range(n):
        if not removed[s] and not vis[s]:
            cyc = []
            v = s

            while not vis[v]:
                vis[v] = True
                cyc.append(v)
                v = f[v]

            AA = []
            BB = []

            for v in cyc:
                base = 0
                gain = 0

                for ch in rev[v]:
                    if removed[ch]:
                        base += A[ch]
                        gain = max(gain, 1 + B[ch] - A[ch])

                BB.append(base)
                AA.append(base + gain)

            k = len(cyc)

            # Case 1: first-last cycle edge NOT used
            best = solve_path(AA, BB)

            # Case 2: first-last cycle edge used
            if k >= 2:
                val = 1 + BB[0] + BB[-1]

                if k > 2:
                    val += solve_path(AA[1:-1], BB[1:-1])

                best = max(best, val)

            ans += best

    return ans

total = sum(D(100000 + i) for i in range(1, 101))
print(total)
