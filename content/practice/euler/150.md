[プロジェクト オイラー問題 150](https://projecteuler.net/problem=150)

 ## 解決策

 **答え:**`-271248680`## 1. 数学的分析

 次の三角配列が与えられます。$1000$疑似乱数の整数で埋められた行$s_k$そして、**部分三角形の最小可能合計**を見つける必要があります。 

部分三角形は次のように決定されます。 

- 上部の頂点$(r,c)$、
 - そして高さ$h$、

 次の内容が含まれるようにします。 

- 1 number in the first row,
 - 次の 2、
 - 次の 3、
 -など

 強引なアプローチは不可能です。$$\frac{n(n+1)(n+2)}{6}$$サブトライアングルの可能性があります。 

のために$n=1000$、$$\frac{1000 \cdot 1001 \cdot 1002}{6} \approx 1.67\times10^8$$三角形はすでに巨大であり、それぞれの合計を単純に計算することははるかに悪いことになります。 

もっと賢い方法が必要です。 

### ステップ 1: 三角配列を生成する

 この問題は線形合同生成器を定義します。$$t_0 = 0$$

$$t_k = (615949t_{k-1}+797807)\bmod 2^{20}$$

$$s_k = t_k - 2^{19}$$これら$500500$値は行ごとに三角形に配置されます。 

---

 ### ステップ 2: 各行内のプレフィックスの合計

 行を仮定します$r$は：$$[a_0,a_1,a_2,\dots]$$行プレフィックスの合計を定義します。$$P[j] = \sum_{i=0}^{j-1} a_i$$この場合、連続するセグメントの合計は次のようになります。$$a_c + a_{c+1} + \cdots + a_d = P[d+1]-P[c]$$これにより、**O(1)** 時間で行セグメントを取得できます。 

---

 ### ステップ 3: 効率的なサブトライアングルの累積

 **上の行**を修正$r$。 

可能な開始列ごとに$c$、 維持する：$$\text{acc}[c]$$三角形と頂点の合計を格納します$(r,c)$下に向かって拡大していきます。 

次に、三角形を行ごとに拡張します。 

現在の一番下の行が$b$の場合、三角形の幅は次のようになります。$$h=b-r+1$$新しく追加された行セグメントは次のとおりです。$$\text{rowSum} = P_b[c+h]-P_b[c]$$それで：$$\text{acc}[c] \leftarrow \text{acc}[c] + \text{rowSum}$$更新するたびに、次のことを確認してください。$$\text{acc}[c]$$これまでに確認された最小の金額です。 

### 複雑さ

 上の各行について$r$、その下のすべての行とすべての有効な列を処理します。$$O(n^3)$$のために$n=1000$、これは最適化された Python では十分に高速です。 

---

 ## 2. Python の実装```python
def solve():
    n = 1000

    # -------------------------------
    # Generate the triangular array
    # -------------------------------
    t = 0
    triangle = []

    for r in range(1, n + 1):
        row = [0] * r
        for c in range(r):
            t = (615949 * t + 797807) & ((1 << 20) - 1)
            row[c] = t - (1 << 19)
        triangle.append(row)

    # -----------------------------------------
    # Row prefix sums for O(1) segment queries
    # -----------------------------------------
    prefix = []

    for row in triangle:
        p = [0]
        running = 0

        for x in row:
            running += x
            p.append(running)

        prefix.append(p)

    # -----------------------------------------
    # Find minimum sub-triangle sum
    # -----------------------------------------
    best = float('inf')

    for top in range(n):

        # acc[c] stores triangle sum with apex at (top, c)
        acc = [0] * (top + 1)

        for bottom in range(top, n):

            height = bottom - top + 1
            p = prefix[bottom]

            for c in range(top + 1):

                # Sum of the newly added row segment
                segment_sum = p[c + height] - p[c]

                acc[c] += segment_sum

                if acc[c] < best:
                    best = acc[c]

    return best

print(solve())
```---

 ## 3. コードのチュートリアル

 ### 三角形の生成```python
t = (615949 * t + 797807) & ((1 << 20) - 1)
```これは次のように計算します。$$t \bmod 2^{20}$$ビットマスクを使用する（より高速）`%`）。 

それから：```python
row[c] = t - (1 << 19)
```実装します:$$s_k=t_k-2^{19}$$---

 ### プレフィックスの合計

 各行について:```python
p.append(running)
```ビルド:$$P[j] = \sum_{i<j} a_i$$許可する:```python
p[right] - p[left]
```連続した行の合計を即座に取得します。 

---

 ### サブトライアングルの展開

 固定用`top`:```python
acc = [0] * (top + 1)
```その行のすべての頂点の三角和を保存します。 

一番下の行を下に移動すると、次のようになります。```python
height = bottom - top + 1
```三角形が 1 つ広がります。 

新たに含まれるストリップは次のとおりです。```python
segment_sum = p[c + height] - p[c]
```それを既存の三角和に追加します。```python
acc[c] += segment_sum
```そしてグローバル最小値を更新します。 

---

 ### 小さな例の検証

 問題のおもちゃの例の最小サブトライアングル和は次のとおりです。$$-42$$このアルゴリズムは、合計の再計算を回避しながら、すべての有効なサブトライアングルを明示的にチェックするため、その値を再現します。
