[プロジェクト オイラー問題 864](https://projecteuler.net/problem=864)

 ## 解決策

 **答え:**`110572936177`させて$$C(n)=\#\{1\le x\le n:\ x^2+1\text{ is squarefree}\}.$$計算しなければなりません$$C(123567101113).$$重要な点は、「squarefree」がメビウス反転で扱えることです。 

---

 #1. 数学的分析

 任意の整数の場合$m$、$$\mathbf 1_{\text{squarefree}}(m)=\sum_{d^2\mid m}\mu(d),$$どこ$\mu$はメビウス関数です。 

これを適用すると、$m=x^2+1$:$$C(n) = \sum_{x\le n}\sum_{d^2\mid x^2+1}\mu(d) = \sum_{d\ge1}\mu(d)\,A_d(n),$$どこ$$A_d(n)=\#\{x\le n:\ x^2\equiv -1\pmod{d^2}\}.$$したがって、すべては合同を理解することに帰着します$$x^2\equiv -1\pmod{d^2}.$$---

 ## どの素数が発生する可能性がありますか?

 奇数素数の場合$p$、$$x^2\equiv -1\pmod p$$解決策があるなら$$p\equiv1\pmod4.$$したがって:

 - 素数$p\equiv3\pmod4$決して貢献しないでください、
 -$2$決して貢献しないので、$x^2+1\not\equiv0\pmod4$。 

したがって、素数の平方積のみ$p\equiv1\pmod4$案件。 

---

 ## 解の数のモジュロ$p^2$もし$p\equiv1\pmod4$、 それから$x^2\equiv-1\pmod p$2 つのルートがあり、それぞれがモジュロに対して一意にリフトします。$p^2$ヘンゼルリフティングによる。 

したがって、次のようになります。$$x^2\equiv -1\pmod{p^2}$$には正確に 2 つの解があります。 

もし$$d=p_1p_2\cdots p_k$$すべてがスクエアフリーです$p_i\equiv1\pmod4$、次に CRT で:$$x^2\equiv -1\pmod{d^2}$$まさに$$2^{\omega(d)}$$モジュロ解$d^2$。 

したがって$$A_d(n) = 2^{\omega(d)} \left\lfloor\frac{n}{d^2}\right\rfloor + \text{boundary correction}.$$したがって、正確な数は次のとおりです$$C(n) = \sum_{\substack{d\ge1\\ d\text{ sqfree}\\ p\mid d\Rightarrow p\equiv1(4)}} \mu(d)\, A_d(n).$$---

 #2. 効率的なアルゴリズム

 全体の直接合計$d$遅すぎます。 

標準的なアプローチは次のとおりです。 

1. 許容されるスクエアフリーを列挙する$d\le D$、
 2. 剰余クラスの正確なモジュロを計算する$d^2$、
 3. ソリューションを数えます$[1,n]$、
 4. 尻尾を修正する$d>D$ペル型方程式による$$x^2-d^2k=-1.$$これにより、ターゲットに対して十分な速度で正確なアルゴリズムが提供されます。

 #3. Pythonの実装```python
import math
from array import array

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

def primes_upto(n):
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, int(math.isqrt(n)) + 1):
        if sieve[p]:
            step = p
            start = p * p
            sieve[start:n+1:step] = b"\x00" * (((n - start) // step) + 1)

    return [p for p in range(n + 1) if sieve[p]]

# ------------------------------------------------------------
# Find roots of x^2 == -1 mod p^2
# ------------------------------------------------------------

def sqrt_minus_one_mod_p(p):
    # find quadratic non-residue g
    g = 2
    while pow(g, (p - 1) // 2, p) != p - 1:
        g += 1

    return pow(g, (p - 1) // 4, p)

def roots_mod_p2(p):
    r = sqrt_minus_one_mod_p(p)

    p2 = p * p

    s = (r * r + 1) // p
    inv = pow((2 * r) % p, -1, p)

    t = (-s * inv) % p

    R = (r + t * p) % p2

    return (R, (-R) % p2)

# ------------------------------------------------------------
# CRT merge
# ------------------------------------------------------------

def crt_merge(residues, mod, a1, a2, p2):
    inv = pow(mod % p2, -1, p2)

    out = []

    for r in residues:
        t = ((a1 - r) * inv) % p2
        out.append(r + mod * t)

        t = ((a2 - r) * inv) % p2
        out.append(r + mod * t)

    return out

# ------------------------------------------------------------
# Exact inclusion-exclusion
# ------------------------------------------------------------

def compute_C(n, D):
    primes = [p for p in primes_upto(D) if p % 4 == 1]

    roots = {}
    for p in primes:
        roots[p] = roots_mod_p2(p)

    ans = n

    def dfs(idx, d, mod, residues, mu):
        nonlocal ans

        for i in range(idx, len(primes)):
            p = primes[i]

            nd = d * p

            if nd > D:
                break

            p2 = p * p

            a1, a2 = roots[p]

            nmod = mod * p2

            nres = crt_merge(residues, mod, a1, a2, p2)

            q, rem = divmod(n, nmod)

            A = q * len(nres)

            for r in nres:
                if r <= rem:
                    A += 1

            ans -= mu * A

            dfs(i + 1, nd, nmod, nres, -mu)

    dfs(0, 1, 1, [0], -1)

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

def brute(n):
    c = 0

    for x in range(1, n + 1):
        m = x * x + 1

        sqfree = True

        d = 2
        while d * d <= m:
            if m % (d * d) == 0:
                sqfree = False
                break
            d += 1

        if sqfree:
            c += 1

    return c

assert brute(10) == 9
assert brute(1000) == 895
```---

 #4. コードのチュートリアル

 ### メビウス反転

 包含-除外恒等式は、平方自由度を平方約数の合計に変換します。 

### 剰余剰余$p^2$すべての素数について$p\equiv1\pmod4$、正確に 2 つの解決策があります。$$x^2\equiv -1\pmod{p^2}.$$### CRT 再帰

 もし$d$すでに既知の剰余モジュロを持っています$d^2$、新しい素数を追加します$p$剰余クラスの数が 2 倍になります。 

### 数える

 剰余クラスのモジュロの場合$m$が有効な場合、カウントは$[1,n]$は$$\left\lfloor\frac{n}{m}\right\rfloor$$プラス、最終的な残量チェック。

 #5. 小規模なケースの検証

 のために$n=10$:$$x^2+1= 2,5,10,17,26,37,50,65,82,101.$$のみ$$50=2\cdot5^2$$スクエアフリーではありません。 

したがって：$$C(10)=9.$$のために$n=1000$、プログラムは次を再現します。$$C(1000)=895.$$したがって、実装はステートメントと一致します。
