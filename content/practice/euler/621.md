[プロジェクト オイラー問題 621](https://projecteuler.net/problem=621)

 ## 解決策

 **答え:**`11429712`させて$$T_m=\frac{m(m+1)}2$$になる$m$-番目の三角数。 

計算するように求められます$$G(N),\qquad N=17526\cdot 10^9.$$---

 # ステップ 1 — 三角数を平方数に変換する

 古典的なアイデンティティとは、$$8T_m+1=(2m+1)^2.$$仮定する$$N=T_a+T_b+T_c.$$それから$$8N+3=(2a+1)^2+(2b+1)^2+(2c+1)^2.$$逆に言えば、あらゆる表現は、$8N+3$3 つの奇数平方の合計として、次の表現に一意に対応します。$N$3 つの三角数の合計として。 

奇数の整数の符号を変更しても三角数は変わらないため、すべての三角表現は正確に対応します。$2^3=8$署名された正方形の表現。 

したがって、次のようになります。$$G(N)=\frac{r_3(8N+3)}8,$$どこ$r_3(m)$は順序付けされた整数解の数です$$x^2+y^2+z^2=m.$$---

 # ステップ 2 — ガウスの 3 平方クラス数公式を使用する

 しましょう$$M=8N+3.$$整数の場合$M\equiv 3\pmod 8$、

 ガウスは次のように証明しました。$$r_3(M)=24\,H(M),$$どこ$H(M)$はハーヴィッツのクラス番号です。 

したがって$$G(N)=3H(M).$$今すぐ計算してください$M$:$$M=8(17526\cdot 10^9)+3 =140208000000003.$$因数分解:$$140208000000003 =3^8\cdot 13\cdot 3527\cdot 466073.$$させて$$D_0=-(13\cdot3527\cdot466073)=-21369913123.$$これは基本的な判別式です。 

以来$$M=|D_0|\cdot 3^8,$$ハーヴィッツのクラス番号は$$H(M)=\sum_{d^2\mid M} h\!\left(-\frac{M}{d^2}\right),$$そして二乗の約数は$$1,3^2,3^4,3^6,3^8.$$したがって、関連する判別式は次のようになります。$$D_0,\quad D_0\cdot 3^2,\quad D_0\cdot 3^4,\quad D_0\cdot 3^6,\quad D_0\cdot 3^8.$$---

 # ステップ 3 — 非基本次数のクラス番号

 車掌のご注文について$f$判別式の二次体で$D_0$、$$h(D_0f^2) = h(D_0)\,f\prod_{p\mid f}\left(1-\frac{\chi_{D_0}(p)}p\right).$$ここ$f=3^k$、 そして$$\chi_{D_0}(3)=\left(\frac{D_0}{3}\right)=-1.$$したがって、$$h(D_0 3^{2k}) = h(D_0)\cdot 3^k\left(1+\frac13\right) = 4\cdot 3^{k-1}h(D_0) \qquad (k\ge1).$$それで：$$\begin{aligned} H(M) &= h(D_0) +4h(D_0) +12h(D_0) +36h(D_0) +108h(D_0)\\ &=161\,h(D_0). \end{aligned}$$したがって$$G(N)=3H(M)=483\,h(D_0).$$---

 # ステップ 4 — 基本クラス番号を計算する

 基本的な判別式は$$D_0=-21369913123.$$縮小バイナリ二次形式 (または同等のクラス番号アルゴリズム) を使用すると、次のことがわかります。$$h(D_0)=23664.$$したがって$$G(N)=483\cdot 23664=11429712.$$---

 # Pythonの実装```python
from math import gcd, isqrt
from sympy.ntheory import factorint
from sympy.ntheory.residue_ntheory import sqrt_mod

# ------------------------------------------------------------
# Count reduced primitive binary quadratic forms of
# discriminant D < 0.
#
# For a fundamental discriminant D, this equals h(D).
# ------------------------------------------------------------

def class_number_fundamental(D):
    assert D < 0
    assert D % 4 in (0, 1)

    h = 0
    limit = isqrt(abs(D) // 3) + 1

    for a in range(1, limit + 1):

        modulus = 4 * a
        rhs = D % modulus

        # Solve b^2 ≡ D (mod 4a)
        roots = sqrt_mod(rhs, modulus, all_roots=True)

        for r in roots:

            # Convert to representatives in [-a, a]
            candidates = set()

            for b in (r, r - modulus):
                if -a <= b <= a:
                    candidates.add(b)

            for b in candidates:

                if (b * b - D) % (4 * a):
                    continue

                c = (b * b - D) // (4 * a)

                # Reduced form conditions
                if a > c:
                    continue

                if (abs(b) == a or a == c) and b < 0:
                    continue

                # Primitive
                if gcd(gcd(a, b), c) != 1:
                    continue

                h += 1

    return h

# ------------------------------------------------------------
# Main computation
# ------------------------------------------------------------

N = 17526 * 10**9
M = 8 * N + 3

# Factor M
factors = factorint(M)
print("Factorization:", factors)

# Fundamental discriminant
D0 = -(13 * 3527 * 466073)

# Fundamental class number
h0 = class_number_fundamental(D0)

# Hurwitz multiplier:
# H(M) = 161 * h0
# G(N) = 3 * H(M)
answer = 3 * 161 * h0

print("h(D0) =", h0)
print("G(N) =", answer)
```---

ガウスは、基本的な判別式について次のことを証明しました。$D<0$、そのような縮小形式の数はクラス番号に等しい$h(D)$。 

ループ:```python

```縮小形式の考えられる主要係数を列挙します。 

私たちは次のことを解決します:$$b^2 \equiv D \pmod{4a}$$を使用して`sqrt_mod`。 

それから：$$c=\frac{b^2-D}{4a}$$は縮小形式の不等式を満たさなければなりません。 

最後に、原始的な形式のみをカウントします。$$\gcd(a,b,c)=1.$$私たちの判別式では、次の結果が得られます。$$h(D_0)=23664.$$残りの算術演算は、上記で導出された指揮者/フルヴィッツの公式です。
