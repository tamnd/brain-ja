[プロジェクト オイラー問題 151](https://projecteuler.net/problem=151)

 ## 解決策

 **答え:**`0.464399`封筒の状態を次のようにします$$(a_2,a_3,a_4,a_5)$$どこ$a_k$サイズの枚数です$A_k$現在封筒の中に入っています。 

最初のバッチ (月曜日の朝) の後、最初の$A1$シートを得るために何度も切り取られました$A5$印刷用のシートです。 封筒に戻される未使用のシートは次のとおりです。$$\{A2,A3,A4\}$$したがって、初期状態は$$(1,1,1,0).$$最初と最後のバッチを除いて、バッチが開始される前に封筒にちょうど 1 枚のシートが含まれると予想される回数を計算する必要があります。 

---

 #1. 状態遷移

 現在の状態が$$(a_2,a_3,a_4,a_5).$$総枚数は、$$N=a_2+a_3+a_4+a_5.$$シートは均一にランダムに選択されます。 

---

 ## の場合$A5$選択されています

 確率:$$\frac{a_5}{N}.$$これは単純に使用されるため、次のようになります。$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4,a_5-1).$$---

 ## の場合$A4$選択されています

 確率:$$\frac{a_4}{N}.$$アン$A4$二つに切られている$A5$シート。 1つ$A5$が使用されると、もう一方が返されます。 

正味の効果:

 - 1 つを削除します$A4$- 1 つ追加$A5$それで：$$(a_2,a_3,a_4,a_5)\to(a_2,a_3,a_4-1,a_5+1).$$---

 ## の場合$A3$選択されています

 確率:$$\frac{a_3}{N}.$$切断プロセス:$$A3 \to 2A4,\quad A4 \to 2A5,$$1つ$A5$が使用されます。 

返却されたシート:

 - 1つ$A4$- 1つ$A5$したがって：$$(a_2,a_3,a_4,a_5)\to(a_2,a_3-1,a_4+1,a_5+1).$$---

 ## の場合$A2$選択されています

 確率:$$\frac{a_2}{N}.$$同様に:

 返却されたシート:

 - 1つ$A3$- 1つ$A4$- 1つ$A5$したがって：$$(a_2,a_3,a_4,a_5)\to(a_2-1,a_3+1,a_4+1,a_5+1).$$---

 # 2. どの州が重要ですか?

 封筒にちょうど 1 枚のシートが入っている朝を数えます。 

考えられる単一シートの状態は次のとおりです。$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0),\quad (0,0,0,1).$$ただし:

 - 一番最初のバッチは除外されます。 
- 最後のバッチは除外されます。 

最終状態$(0,0,0,1)$は最後のバッチに対応するため、カウントする必要はありません**。 

したがって、カウントされるシングルトン状態は次のとおりです。$$(1,0,0,0),\quad (0,1,0,0),\quad (0,0,1,0).$$したがって、期待値は$$E = P(1,0,0,0) + P(0,1,0,0) + P(0,0,1,0),$$ここで、これらの確率は、バッチが開始される前にそれらの状態に到達する確率です。 

---

 #3. 正確な確率の計算

 到達可能なすべての状態を通じて確率を伝播します。 

開始状態:$$(1,1,1,0)$$確率的に$1$。 

シートの総数はバッチごとにちょうど 1 つずつ減少するため、プロセスは有限であり、正確な合理的計算には十分小さいものです。 

---

 #4. Pythonの実装```python
from fractions import Fraction
from collections import defaultdict

# ------------------------------------------------------------
# Transition function
# ------------------------------------------------------------

def transitions(state):
    a2, a3, a4, a5 = state
    total = a2 + a3 + a4 + a5

    result = []

    # choose A2
    if a2:
        p = Fraction(a2, total)
        nxt = (a2 - 1, a3 + 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A3
    if a3:
        p = Fraction(a3, total)
        nxt = (a2, a3 - 1, a4 + 1, a5 + 1)
        result.append((p, nxt))

    # choose A4
    if a4:
        p = Fraction(a4, total)
        nxt = (a2, a3, a4 - 1, a5 + 1)
        result.append((p, nxt))

    # choose A5
    if a5:
        p = Fraction(a5, total)
        nxt = (a2, a3, a4, a5 - 1)
        result.append((p, nxt))

    return result

# ------------------------------------------------------------
# Dynamic probability propagation
# ------------------------------------------------------------

start = (1, 1, 1, 0)

dist = defaultdict(Fraction)
dist[start] = Fraction(1, 1)

expected = Fraction(0, 1)

while dist:
    new_dist = defaultdict(Fraction)

    for state, prob in dist.items():

        total_sheets = sum(state)

        # Count singleton states excluding final A5 state
        if total_sheets == 1 and state != (0, 0, 0, 1):
            expected += prob

        # Continue transitions unless terminal
        if state == (0, 0, 0, 0):
            continue

        for p, nxt in transitions(state):
            new_dist[nxt] += prob * p

    dist = new_dist

# ------------------------------------------------------------
# Output
# ------------------------------------------------------------

value = float(expected)

print(expected)
print(f"{value:.6f}")
```---

 #5. コードのチュートリアル

 ## 遷移ジェネレーター

 機能:```python
transitions(state)
```考えられるすべてのランダムなシート選択を列挙し、次を返します。```python
(probability, next_state)
```ペア。 

例えば：```python
(a2,a3,a4,a5)
```を選択する$A3$与える:```python
(a2, a3-1, a4+1, a5+1)
```を切るので$A3$残りが1つ生成されます$A4$そして残り1つ$A5$。 

---

 ## 確率の伝播

 到達可能なすべての状態にわたる確率分布を維持します。```python
dist[state] = probability
```各ステップで次のことを行います。 

1. シングルトン状態の確率を期待値に追加します。 
2. 確率質量を後続の状態に伝播します。 

すべてのバッチで最終的な結果が 1 つだけ削除されるため、$A5$、プロセスは自然に終了します。

 #6. 検証

 最後のバッチの前に発生する可能性のあるシングルトン状態は次のとおりです。 

-のみ$A2$、
- のみ$A3$、
- のみ$A4$。 

これらはかなりまれなイベントであるため、期待ははるかに低いはずです$1$、これは最終的な値と一致します。$$0.464399\ldots$$これはまさに既知のプロジェクト オイラーの結果です。
