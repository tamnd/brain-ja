[プロジェクト オイラー問題 613](https://projecteuler.net/problem=613)

 ## 解決策

 **答え:**`0.3916721504`直角三角形に頂点があるようにします

 -$A=(0,0)$、
 -$B=(30,0)$、
 -$C=(0,40)$、

 したがって、最長の辺は斜辺です$BC$長さの$50$。 

ポイントとしては$P=(x,y)$三角形の内側で、アリが一様にランダムな方向を選択した場合、アリが側面から出る確率$BC$衝突する方向の角度幅に等しい$BC$、で割る$2\pi$。 

その角度幅は正確にセグメントによって定められる角度です$BC$で$P$:$$p(P)=\frac{\angle BPC}{2\pi}.$$したがって、望ましい確率は、三角形全体にわたるこの量の平均です。$$\Pr(BC) = \frac{1}{\text{Area}(\triangle)} \iint_{\triangle} \frac{\angle BPC}{2\pi} \,dA.$$三角地帯は、$$\frac{30\cdot 40}{2}=600.$$のために$P=(x,y)$、$$\angle BPC = \cos^{-1} \!\left( \frac{(B-P)\cdot(C-P)} {|B-P||C-P|} \right).$$明示的に:$$B-P=(30-x,-y), \qquad C-P=(-x,40-y).$$そこで数値的に評価してみます$$\frac{1}{600} \int_0^{30} \int_0^{40-\frac43x} \frac{ \cos^{-1} \left( \frac{(30-x)(-x)+(-y)(40-y)} {\sqrt{(30-x)^2+y^2}\sqrt{x^2+(40-y)^2}} \right) }{2\pi} \,dy\,dx.$$### Python の実装```python
import mpmath as mp

# High precision
mp.mp.dps = 50

def subtended_angle(x, y):
    # vectors from P=(x,y) to B and C
    bx, by = 30 - x, -y
    cx, cy = -x, 40 - y

    # dot product
    dot = bx * cx + by * cy

    # magnitudes
    norm_b = mp.sqrt(bx * bx + by * by)
    norm_c = mp.sqrt(cx * cx + cy * cy)

    # angle BPC
    cos_theta = dot / (norm_b * norm_c)
    return mp.acos(cos_theta)

def integrand(y, x):
    # probability from point (x,y)
    return subtended_angle(x, y) / (2 * mp.pi)

# upper boundary of the triangle:
# y = 40 - (4/3)x
def integrate_x(x):
    ymax = 40 - (4 * x / 3)
    return mp.quad(lambda y: integrand(y, x), [0, ymax])

# integrate over triangle and divide by area
area = 600
result = mp.quad(lambda x: integrate_x(x), [0, 30]) / area

print(result)
print(round(result, 10))
```### コードのチュートリアル

 1.**`subtended_angle(x, y)`**

 角度を計算します$\angle BPC$ドット積公式を使用すると、次のようになります。$$\cos\theta = \frac{u\cdot v}{|u||v|}.$$2.**`integrand(y, x)`**

 角度を で割って確率に変換します。$2\pi$。 
3. **三角形の境界**

 斜辺は$$y = 40-\frac43x,$$だからそれぞれに$x\in[0,30]$、$$0\le y\le 40-\frac43x.$$4. **二重統合**

 三角形を数値的に積分し、面積で割ります。$600$すべての開始位置の平均を求めます。
