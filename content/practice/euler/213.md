[プロジェクト オイラー問題 213](https://projecteuler.net/problem=213)

 ## 解決策

 **答え:**`330.721154`させて$E$は、50 回のランダムなジャンプ後の空の正方形の予想数を示します。 

重要な観察は、ノミが**独立して**動くということです。 

すべてを追跡するのではなく、$900$ノミを結合して (直接は不可能)、各正方形について計算します$s$:$$\Pr(s \text{ is empty after 50 steps})$$そしてすべての正方形を合計します。 

---

 #1. 数学的分析

 固定ターゲット正方形を考える$s$。 

開始マスごとに$i$、 させて$$p_{i\to s}^{(50)}$$ノミが次から始まる確率は$i$にあります$s$50回ジャンプした後。 

ノミは独自に行動するので、$$\Pr(s \text{ empty}) = \prod_{i=1}^{900} \left(1-p_{i\to s}^{(50)}\right)$$それぞれのノミが独立して回避するため、$s$。 

したがって、$$E = \sum_{s} \Pr(s \text{ empty}) = \sum_{s} \prod_{i=1}^{900} \left(1-p_{i\to s}^{(50)}\right)$$したがって、問題は、すべての 50 ステップの遷移確率を計算することに帰着します。$30\times30$グリッド。 

---

 ## マルコフ連鎖構造

 ノミはグリッド上をランダムに歩きます。 

正方形に次数がある場合$d\in\{2,3,4\}$、その後、ノミはその正方形から確率で隣の正方形の 1 つに均一に移動します。$1/d$。 

状態空間には、$900$したがって、確率を動的に進化させることができます。 

1 つの開始正方形の場合:

 - 確率を初期化する$1$初めに、
 - 50 ステップの間、確率マスを近傍に繰り返し分配します。 

これですべてが得られます$p_{i\to s}^{(50)}$。 

これをすべての人に対して素朴に行うと、$900$おおよその費用がかかります$$900 \times 50 \times 900$$操作は完全に実行可能です。 

---

 #2. Pythonの実装```python
from math import prod

N = 30
STEPS = 50

# ------------------------------------------------------------
# Build neighbor lists for every square
# ------------------------------------------------------------

neighbors = {}

for r in range(N):
    for c in range(N):
        adj = []

        if r > 0:
            adj.append((r - 1, c))
        if r < N - 1:
            adj.append((r + 1, c))
        if c > 0:
            adj.append((r, c - 1))
        if c < N - 1:
            adj.append((r, c + 1))

        neighbors[(r, c)] = adj

# ------------------------------------------------------------
# empty_prob[r][c] will accumulate:
#   product over fleas of (1 - probability flea ends here)
# ------------------------------------------------------------

empty_prob = [[1.0 for _ in range(N)] for _ in range(N)]

# ------------------------------------------------------------
# Process each flea independently
# ------------------------------------------------------------

for sr in range(N):
    for sc in range(N):

        # Current probability distribution
        cur = [[0.0 for _ in range(N)] for _ in range(N)]
        cur[sr][sc] = 1.0

        # Perform 50 random-walk steps
        for _ in range(STEPS):

            nxt = [[0.0 for _ in range(N)] for _ in range(N)]

            for r in range(N):
                for c in range(N):

                    p = cur[r][c]

                    if p == 0.0:
                        continue

                    adj = neighbors[(r, c)]
                    share = p / len(adj)

                    for nr, nc in adj:
                        nxt[nr][nc] += share

            cur = nxt

        # Multiply contribution into empty probabilities
        for r in range(N):
            for c in range(N):
                empty_prob[r][c] *= (1.0 - cur[r][c])

# ------------------------------------------------------------
# Expected number of empty squares
# ------------------------------------------------------------

answer = 0.0

for r in range(N):
    for c in range(N):
        answer += empty_prob[r][c]

print(f"{answer:.6f}")
```---

 #3. コードのチュートリアル

 ## 近隣の建物を構築する```python
neighbors[(r, c)]
```すべての合法的な隣接する正方形を保存します。 

- コーナーには 2 つの隣接コーナーがあります。 
- エッジは 3 つあり、
 - 内部の正方形は 4 つあります。 

---

 ## 空の二乗確率

 私たちは以下を維持します:```python
empty_prob[r][c]
```最初はどのマスも確率的に確実に空です$1$ノミについて考える前に。 

ノミごとに次の値を掛けます。$$1 - p_{i\to s}^{(50)}$$なぜなら、そのノミは広場を避けなければならないからです。 

---

 ## 1 匹のノミをシミュレートする```python
cur[sr][sc] = 1.0
```ノミは最初のマス目から開始します。 

各ステップでは、近傍間で確率を均等に分配します。 

これはまさにマルコフ遷移則です。 

50 回の反復後:```python
cur[r][c]
```ノミが終わる確率に等しい$(r,c)$。 

---

 ## 最終的な期待値

 各正方形について:```python
answer += empty_prob[r][c]
```実装するもの$$E = \sum_s \Pr(s \text{ empty})$$期待値の直線性による。

 #4. 検証

 いくつかの健全性チェック:

 - 最初は空のマスはありません。 
- ノミがランダム化すると、衝突が発生します。 
- したがって、予想される空のマスの数はかなり多くなりますが、900 未満にとどまります。 
- 前後の値$300$–$350$わずか 50 ステップでは分布が多少混合されますが、完全には均一ではないため、これは妥当です。 

プログラムを実行すると、次の結果が得られます。$$330.721154\ldots$$それは期待に応えます。
