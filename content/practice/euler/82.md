 ## 解決策

 **答え:**`260324`## 1. 数学的分析

 私たちに与えられているのは、$80\times 80$行列を作成し、**左列の任意のセル**から**右列の任意のセル**までの**最小パス合計**を求めます。移動のみ:

 - **そうです**
 - **上**
 - **下**

 垂直方向の動きが両方向に許可されるため、これは問題 81 よりも困難です。 

### ステップ 1: 最短経路問題として再定式化する

 各行列エントリは、その値に等しいコストを持つノードと考えてください。 

あるセルから別のセルへの移動は、次の場合に許可されます。 

- そう、
 - アップ、
 -またはダウン。 

列内の任意の場所から始まる最小コストのパスが必要です$0$そして最後の列のどこかで終わります。 

可能性の数が爆発的に増加するため、パスを総当たりで検索することは絶望的です。 

---

 ### ステップ 2: 列による動的プログラミング

 重要な洞察は次のとおりです。 

移動は **決して左にならない**ため、パスは左から右に単調に進みます。 

列内のすべてのセルに到達するための最小コストがすでにわかっているとします。$c-1$。 カラムのコストを最小限に抑えたい$c$。 

させて：$$dp[r]$$行に到達するための最小コストを示します$r$現在の列の。 

右の動きのみが許可されている場合:$$dp[r] = \text{prev}[r] + M[r][c]$$ただし、入力後に **列内で上下に移動**することもできます。 

したがって、各列については次のようになります。 

1. **Initial right move**:$$dp[r] = \text{prev}[r] + M[r][c]$$2. **下方向への動きをリラックス**:

 列から来られるなら$r-1$:$$dp[r] = \min(dp[r],\, dp[r-1] + M[r][c])$$1. **上向きの動きをリラックス**:

 列から来られるなら$r+1$:$$dp[r] = \min(dp[r],\, dp[r+1] + M[r][c])$$なぜこれが機能するのでしょうか?

 列に入る最小パスは垂直方向に何度でも小刻みに動くことができますが、コストはすべて正であるため、1 つの列内の最適なパスは単純に単調な垂直セグメント (入力後は上向きのみ、または下向きのみ) になります。 したがって:

 - 1回の下向きスイープ、
 - 1回の上向きスイープ

 すべての最適値を伝播するには十分です。 

これにより、アルゴリズムが複雑になります。$$O(n^2)$$のために$n\times n$マトリックス。 

のために$n=80$、これは非常に高速です。

 ## 2. Python の実装```python
def minimal_path_sum(matrix):
    n = len(matrix)

    # Base case:
    # cost to reach left column is just the cell itself
    dp = [matrix[r][0] for r in range(n)]

    # Process one column at a time
    for c in range(1, n):

        # Step 1: move right into this column
        new_dp = [dp[r] + matrix[r][c] for r in range(n)]

        # Step 2: relax downward paths
        for r in range(1, n):
            new_dp[r] = min(
                new_dp[r],
                new_dp[r - 1] + matrix[r][c]
            )

        # Step 3: relax upward paths
        for r in range(n - 2, -1, -1):
            new_dp[r] = min(
                new_dp[r],
                new_dp[r + 1] + matrix[r][c]
            )

        dp = new_dp

    # End in any row of the rightmost column
    return min(dp)

# Read the matrix file
with open("0082_matrix.txt") as f:
    matrix = [
        list(map(int, line.strip().split(",")))
        for line in f
    ]

answer = minimal_path_sum(matrix)
print(answer)
```---
