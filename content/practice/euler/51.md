[プロジェクト オイラー問題 51](https://projecteuler.net/problem=51)

 ## 解決策

 **答え:**`121313`### 1. 数学的分析

 数字の一部を **同じ数字**で置き換えることによって形成される **8 素数ファミリー**に属する **最小の素数**が必要です。 

例えば：

-`*3`6 つの素数が得られます。$$13,23,43,53,73,83$$-`56**3`7 つの素数を与えます。$$56003,56113,56333,56443,56663,56773,56993$$**10 個の置換** から 8 個の素数を生成する **最初の素数** を探します。 

---

 #### 重要な観察 1: 等しい数字のみを置換します

 独立して位置を置き換えるとします。 その後、検索は組み合わせ的に爆発的に行われます。 

しかし、問題文には次のように書かれていることに注目してください。 

> 数字の一部を **同じ数字**に置き換えます

 したがって、ポジションを選択すると$i_1, i_2, \dots$、それらはすべて 1 つの共通の数字に置き換える必要があります$d\in\{0,\dots,9\}$。 

自然な戦略:

 1. 素数を生成します。 
2. 素数ごとに、桁位置のサブセットを選択します。 
3. これらの位置を同時に数字に置き換えます$0$–$9$。 
4. 素数の結果がいくつあるか数えます。 
5. サイズ 8 の最初のファミリーで停止します。 

---

 #### 重要な観察 2: 置換された位置には、元の同じ数字が含まれている必要があります

 異なる数字を含む位置を置き換えるとします。 

例：`12345`、位置を交換します`(1,3)`。 

家族は次のようになります。$$10305,11315,\dots$$しかし、これによって構造が維持されたり、作業が重複したりすることはほとんどありません。 

代わりに、**同じ数字**が既に含まれている位置のマスクのみを考慮します。 ようなプライムの場合`56003`、2つを交換することを検討します`0`s.

 これにより、検索スペースが大幅に削減され、目的のファミリーが捕捉されます。 

---

 #### 重要な観察 3: 3 による割り算の制限

 これは巧妙な数学的トリックです。 

置き換えるとします$k$桁数$d$。 

桁の合計は直線的に変化します。$$S(d)=S_0+k d$$もし$k \not\equiv 0 \pmod 3$、その後、$d$0 から 9 まで実行されます。$$S(d)\pmod 3$$すべての残基を循環します。 したがって、**少なくとも 3 つの値** は 3 で割り切れます。 

ただし、**8 つの素数**が必要です。これは、最大で **2 つの合成**を意味します。 

それで：$$k \equiv 0 \pmod 3$$必要です。 

したがって、置換される桁数は通常次のようになります。$$3,6,\dots$$これにより、検索が大幅に削減されます。 

---

 #### アルゴリズム

 素数ごとに$p$:

 1. 文字列に変換します。 
2. インデックスを数字ごとにグループ化します (`0`–`9`）。 
3. 各数字グループについて:

 - 3 で割り切れるサイズのサブセットを考慮します。 
4. それらの位置を数字に置き換えます`0..9`。 
5. 先行ゼロの結果をスキップします。 
6.族内の素数を数えます。 
7. count = 8 の場合、その族内の最小の素数を返します。 

素数を昇順にスキャンするため、最初に見つかった有効な素数が自動的に答えになります。

 ### 2. Python の実装```python
from itertools import combinations
from math import isqrt

def sieve(limit):
    """Return boolean prime table and list of primes."""
    is_prime = [True] * limit
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(limit) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            is_prime[start:limit:step] = [False] * (
                (limit - start - 1) // step + 1
            )

    primes = [i for i, flag in enumerate(is_prime) if flag]
    return is_prime, primes

def find_smallest_prime_in_family(target_family_size=8):
    # Large enough upper bound for Problem 51
    LIMIT = 1_000_000

    is_prime, primes = sieve(LIMIT)

    for p in primes:
        if p < 10:
            continue

        s = str(p)
        n = len(s)

        # Group positions by digit
        digit_positions = {}
        for i, ch in enumerate(s):
            digit_positions.setdefault(ch, []).append(i)

        # Try replacement masks
        for digit, positions in digit_positions.items():

            # Replace counts divisible by 3
            for r in range(1, len(positions) + 1):
                if r % 3 != 0:
                    continue

                for mask in combinations(positions, r):

                    family = []

                    for replacement_digit in "0123456789":
                        chars = list(s)

                        for idx in mask:
                            chars[idx] = replacement_digit

                        # No leading zero
                        if chars[0] == "0":
                            continue

                        candidate = int("".join(chars))

                        if is_prime[candidate]:
                            family.append(candidate)

                    if len(family) == target_family_size:
                        return min(family)

    return None

answer = find_smallest_prime_in_family()
print(answer)
```---
