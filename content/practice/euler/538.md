[プロジェクト オイラー問題 538](https://projecteuler.net/problem=538)

 ## 解決策

 **答え:**`22472871503401097`選択した 4 つの辺の長さを次のようにします。$a \le b \le c \le d$。 

辺の長さが固定されている場合、面積が最大の四角形は周期的であるため、ブラーマグプタの公式により次のようになります。$$A^2=(s-a)(s-b)(s-c)(s-d), \qquad s=\frac{a+b+c+d}{2}.$$同様に、$$16A^2= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$定義する$$F(a,b,c,d)= (a+b+c-d) (a+b-c+d) (a-b+c+d) (-a+b+c+d).$$面積の最大化は最大化と同じです$F$、境界線によって関係が切れます$P=a+b+c+d$。 

---

 #1. 主要な構造観察

 利用可能な長さの複数セットがソートされていると仮定します。 

最適な 4 倍数が 2 つの選択された値の間で利用可能な値をスキップした場合、選択された小さい値をスキップされた大きい値で置き換えると、すべての係数が増加します。$F$、したがって面積が増加します。 

したがって:

 > **最適な 4 要素は常に、ソートされたマルチセット内の 4 つの連続する要素です。**

 したがって、ソートされたシーケンスに新しい値を挿入した後は、その新しい値を含む最大 4 つの連続ウィンドウのみが最適値を改善できる可能性があります。 

これにより、問題は「すべての 4 回転」から 1 つのみに減ります。$O(1)$挿入ごとの候補。 

---

 #2. シーケンスの生成$$u_n = 2^{B(3n)} + 3^{B(2n)} + B(n+1),$$どこ$B(k)$はバイナリのポップカウントです。 

のために$n \le 3\,000\,000$、の異なる値は 1614 個しかありません。$u_n$したがって、それらを調整圧縮し、フェンウィック ツリー (バイナリ インデックス付きツリー) を使用して順序付けされたマルチセットを維持します。 

フェンウィック ツリーは以下をサポートしています。 

- 挿入、
 - ランククエリ、
 -$k$-番目の要素のクエリ、

 全部入り$O(\log M)$、 どこ$M=1614$。 

したがって、計算全体は本質的に線形です。

 #3. Pythonの実装```python
from bisect import bisect_left

N = 3_000_000

# ---------- generate all u_n ----------
pow3 = [3 ** k for k in range(30)]

vals = []
distinct = set()

for n in range(1, N + 1):
    v = (1 << ((3 * n).bit_count())) \
        + pow3[(2 * n).bit_count()] \
        + (n + 1).bit_count()

    vals.append(v)
    distinct.add(v)

# ---------- coordinate compression ----------
coord = sorted(distinct)
idx = {v: i + 1 for i, v in enumerate(coord)}
M = len(coord)

# ---------- Fenwick tree ----------
bit = [0] * (M + 1)

def add(i, delta):
    while i <= M:
        bit[i] += delta
        i += i & -i

def prefix_sum(i):
    s = 0
    while i:
        s += bit[i]
        i -= i & -i
    return s

def kth(k):
    """
    Smallest index i such that prefix_sum(i) >= k
    """
    i = 0
    step = 1 << (M.bit_length() - 1)

    while step:
        ni = i + step
        if ni <= M and bit[ni] < k:
            k -= bit[ni]
            i = ni
        step >>= 1

    return i + 1

def value_at_rank(r):
    return coord[kth(r) - 1]

# ---------- Brahmagupta comparison quantity ----------
def score(q):
    a, b, c, d = q

    x1 = a + b + c - d
    if x1 <= 0:
        return -1

    return (
        x1
        * (a + b - c + d)
        * (a - b + c + d)
        * (-a + b + c + d)
    )

best_F = -1
best_P = 0

answer = 0
total = 0

# ---------- process U_n incrementally ----------
for n, v in enumerate(vals, start=1):

    i = idx[v]

    # rank of inserted element
    rank = prefix_sum(i) + 1

    add(i, 1)
    total += 1

    # only windows containing the new element matter
    start_lo = max(1, rank - 3)
    start_hi = min(rank, total - 3)

    for s in range(start_lo, start_hi + 1):

        q = [
            value_at_rank(s),
            value_at_rank(s + 1),
            value_at_rank(s + 2),
            value_at_rank(s + 3),
        ]

        F = score(q)
        P = sum(q)

        if F > best_F or (F == best_F and P > best_P):
            best_F = F
            best_P = P

    if n >= 4:
        answer += best_P

print(answer)
```---

 #4. コードのチュートリアル

 ### シーケンスの生成```python
v = (1 << ((3 * n).bit_count())) \
    + pow3[(2 * n).bit_count()] \
    + (n + 1).bit_count()
```の定義を直接実装します。$u_n$。 

---

 ### フェンウィックの木

 各圧縮値のカウントを維持します。 

-`add(i,1)`オカレンスを 1 つ挿入します。 
-`prefix_sum(i)`要素がいくつあるかを数えます$\le i$、
 -`kth(k)`を取得します$k$- 番目に小さい要素。 

---

 ### 連続したウィンドウ

 挿入された要素にソートランクがある場合`rank`の場合、次のウィンドウのみが変更される可能性があります。$$[rank-3, rank],\ [rank-2, rank+1],\ [rank-1, rank+2],\ [rank, rank+3].$$したがって、最大 4 つの候補クワドルプルのみがチェックされます。 

---

 ### エリア比較

 浮動小数点領域の代わりに、次のように比較します。$$F = 16A^2,$$これは整数値であり、正確です。 

タイブレークではペリメーターを使用します。
