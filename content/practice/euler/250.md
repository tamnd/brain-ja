[プロジェクト オイラー問題 250](https://projecteuler.net/problem=250)

 ## 解決策

 **答え:**`1425480602091519`させて$$a_n = n^n \pmod{250}$$のために$n=1,2,\dots,250250$。 

**空ではないサブセット**の数が必要です。$$\{1^1,2^2,3^3,\dots,250250^{250250}\}$$その合計が次で割り切れる$250$。 同様に、合計が以下に一致するサブセットの数を求めます。$0 \pmod{250}$。 

で割り切れるだけなので、$250$問題は、すべての数値を剰余として減らすことができることです$250$。 

---

 ## 1. 数学的分析

 これはサブセット合計のモジュロを計算する問題です$250$。 

定義する：$$r_n = n^n \bmod 250.$$次のようなサブセットを数える必要があります。$$\sum r_n \equiv 0 \pmod{250}.$$ブルートフォース検索$2^{250250}$サブセットは不可能なので、**250 を法とする剰余に対して動的計画法**を使用します。 

### 動的プログラミングのアイデア

 しましょう$$dp[k]$$和が一致するサブセットの数になります。$k \pmod{250}$。 

まず、要素を選択する前に、次のようにします。$$dp[0]=1$$(空のサブセット)、その他すべてのエントリは$0$。 

次に各残余を処理します$r_n$。 

既存の残基ごとに$s$:

 - **除外**$r_n$: 残留物に残る$s$、
- **含む**$r_n$: 残基に移動$$(s+r_n)\bmod 250.$$したがって：$$dp_{\text{new}}[(s+r_n)\bmod 250] \;+=\; dp[s].$$結局$250250$用語が処理されます:

 -$dp[0]$合計で割り切れるすべてのサブセットをカウントします。$250$、
 - 空のサブセットを含む。 

したがって、最終的な答えは、$$dp[0]-1.$$---

 ### これが実現可能な理由

 すべてのサブセット合計ではなく、**250 州**のみを追跡します。 

複雑さ:

 -$250250$数字、
 -$250$残留物。 

総作業量:$$250250 \times 250 \approx 6.25\times 10^7$$簡単な操作なので実用的です。 

**右端の 16 桁**のみが必要なので、剰余を計算します。$$10^{16}$$全体を通して。

 ## 2. Python の実装```python
MOD = 10**16
M = 250

# dp[r] = number of subsets with sum ≡ r (mod 250)
dp = [0] * M
dp[0] = 1  # empty subset

# Process n^n for n = 1..250250
for n in range(1, 250251):
    residue = pow(n, n, M)

    # Copy current DP state
    new_dp = dp[:]

    # Include current element in existing subsets
    for r in range(M):
        new_dp[(r + residue) % M] = (
            new_dp[(r + residue) % M] + dp[r]
        ) % MOD

    dp = new_dp

# Exclude the empty subset
answer = (dp[0] - 1) % MOD

print(answer)
```---

 ### DP 移行```python

```まず、古い数 (現在の数を除く) をコピーします。 

それから：```python
for r in range(250):
    new_dp[(r + residue) % 250] += dp[r]
```これにより、新しい要素を**含む**ことによって形成されたすべてのサブセットが追加されます。 

モジュロを削減します$10^{16}$数字を小さく保つためにあらゆるステップを実行します。
