 # 数学的分析

 ストレートにはちょうど 10 個の可能なランク パターンがあります。$$A2345,\ 23456,\ 34567,\ \dots,\ TJQKA$$これらの窓口に電話してください$W_0,\dots,W_9$。 

ストレートは、5 つのランクごとに 1 つのスートを選択することで得られますが、5 枚のカードは **すべて同じスートではない**という制限があります。 

したがって、単一のストレートの場合は次のようになります。$$4^5 - 4 = 1024 - 4 = 1020$$そして$$10 \cdot 1020 = 10200$$ステートメントと一致します。 

---

 # ステップ 1 — 多重度ベクトル

 8 つのストレートの中で次のように仮定します。 

-$p_0$使用$A2345$、
 -$p_1$使用$23456$、
 - …
 -$p_9$使用$TJQKA$。 

それから：$$p_0+p_1+\cdots+p_9=8$$各ランクに存在するカードは最大 4 枚 (スートごとに 1 枚) であるため、特定のランクを使用するストレートの合計数は 4 を超えることはできません。 

これにより、有効なベクトルが大幅に制限されます$p$。 

固定多重度ベクトルの場合:

 - ウィンドウへの 8 つのラベル付きストレートの順序付けられた割り当ての数は、$$\frac{8!}{\prod p_i!}$$---

 # ステップ 2 — スーツの割り当てを数える

 ウィンドウの固定順序構成の場合:

 - すべてのストレートにはランクごとに 1 つのスーツが必要です。 
- カードは繰り返すことができません。 
- ストレートはストレート フラッシュではありません。 

「すべてが同じではない訴訟」を強制するきれいな方法は、包含と排除です。 

---

 ## 包含と除外

 サブセットにしましょう$T$ストレートの一部は強制的にストレート フラッシュになります。 

ストレートが単色の場合、そのすべてのランクは同じスーツを使用します。 

単一のランクを調べてください$r$。 

仮定する：

-$c_r$合計ストレート使用ランク$r$、
 -$k_r$そのうちの$T$。 

の$k_r$単色ストレートはすでに消費しています$k_r$そのランクの独特のスーツ。 

残り$c_r-k_r$ストレートは、残りのスートの間で任意の単射代入を使用できます。$$P(4-k_r,\ c_r-k_r) = \frac{(4-k_r)!}{(4-c_r)!}$$13 ランクすべてを乗算すると、そのサブセットの完了数が得られます。$T$。 

残っている唯一のタスクは、単色のストレートの有効なカラーリングを数えることです。 

ランクが重複する 2 つの単色ストレートは、同じスートを共有することはできません。 

したがって、区間重複グラフ上のグラフ色付け問題が得られます。 

ストレートは合計 8 つしかないため、すべてのサブセットに対する総当たり攻撃$T\subseteq\{1,\dots,8\}$完全に実現可能です。

 # Pythonの実装```python
from functools import lru_cache
from math import factorial

# ------------------------------------------------------------
# Build the 10 straight windows
# ------------------------------------------------------------

windows = []

# A2345
windows.append([12, 0, 1, 2, 3])

# 23456 ... TJQKA
for s in range(1, 10):
    windows.append(list(range(s - 1, s + 4)))

# ------------------------------------------------------------
# Overlap graph between straight windows
# ------------------------------------------------------------

overlap = [[False] * 10 for _ in range(10)]

for i in range(10):
    for j in range(10):
        overlap[i][j] = bool(set(windows[i]) & set(windows[j]))

# ------------------------------------------------------------
# Generate all valid multiplicity vectors p
# satisfying:
#
#   sum p_i = 8
#   every rank used at most 4 times
# ------------------------------------------------------------

vectors = []

def gen(i, rem, p, rank_count):
    if i == 10:
        if rem == 0:
            vectors.append(tuple(p))
        return

    for x in range(rem + 1):

        new_count = rank_count[:]
        ok = True

        for r in windows[i]:
            new_count[r] += x
            if new_count[r] > 4:
                ok = False
                break

        if ok:
            p.append(x)
            gen(i + 1, rem - x, p, new_count)
            p.pop()

gen(0, 8, [], [0] * 13)

# ------------------------------------------------------------
# Count suit assignments for a fixed multiplicity vector
# using inclusion-exclusion
# ------------------------------------------------------------

@lru_cache(None)
def count_vector(p):

    p = list(p)

    # Expand into individual labeled straights
    copies = []

    for w, cnt in enumerate(p):
        copies += [w] * cnt

    m = len(copies)

    # Total usage count of each rank
    total_rank_use = [0] * 13

    for w in copies:
        for r in windows[w]:
            total_rank_use[r] += 1

    answer = 0

    # Inclusion-exclusion over monochromatic straights
    for mask in range(1 << m):

        chosen = [i for i in range(m) if (mask >> i) & 1]

        # k_r
        mono_use = [0] * 13

        for i in chosen:
            for r in windows[copies[i]]:
                mono_use[r] += 1

        # Count remaining injective assignments
        ways = 1
        ok = True

        for r in range(13):

            a = 4 - mono_use[r]
            b = total_rank_use[r] - mono_use[r]

            if b > a:
                ok = False
                break

            # falling factorial P(a,b)
            for t in range(a - b + 1, a + 1):
                ways *= t

        if not ok:
            continue

        # Count proper colorings of monochromatic straights
        color_count = 0
        colors = {}

        order = chosen

        def dfs(idx):
            nonlocal color_count

            if idx == len(order):
                color_count += 1
                return

            i = order[idx]

            forbidden = set()

            for j, c in colors.items():
                if overlap[copies[i]][copies[j]]:
                    forbidden.add(c)

            for c in range(4):
                if c not in forbidden:
                    colors[i] = c
                    dfs(idx + 1)
                    del colors[i]

        dfs(0)

        answer += ((-1) ** len(chosen)) * ways * color_count

    return answer

# ------------------------------------------------------------
# Total count
# ------------------------------------------------------------

total = 0

for p in vectors:

    mult = factorial(8)

    for x in p:
        mult //= factorial(x)

    total += count_vector(p) * mult

# unordered straights
total //= factorial(8)

print(total)
```---
