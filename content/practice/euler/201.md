[プロジェクト オイラー問題 201](https://projecteuler.net/problem=201)

 ## 解決策

 **答え:**`115039000`させて$$S=\{1^2,2^2,\dots,100^2\}.$$**ちょうど 1** の合計として現れるすべての整数の合計を見つけなければなりません$50$-要素のサブセット$S$。 

---

 # 数学的分析

 一意性条件の下でサブセットの合計を扱っています。 

セットの場合$A$、 定義する$$U(A,k)=\left\{x : x \text{ is the sum of exactly one } k\text{-element subset of }A\right\}.$$必要です$$\sum U(S,50).$$---

 ## 1. 動的プログラミングの観点

 の各要素$S$次のいずれかが可能です:

 - サブセットから除外される、または
 - 含まれること。 

可能な限りすべてを数えたいと思います。 

- サブセットのサイズ$j$、
 - サブセットの合計$t$、

 そのペアを達成するサブセットの数は何ですか$(j,t)$。 

---

 ## 2. 重要な観察

 サブセットの正確な数は、それを超えると**必要ありません**$1$。 

なぜ？ 

なぜなら、この問題は合計が次のとおりであるかどうかを問うだけだからです。 

- 達成$0$回、
 - 正確に達成されました$1$時間、
 - または複数回達成しました。 

したがって、すべてのカウントに上限を設けることができます。$2$。 

これにより、複雑さが大幅に軽減されます。 

---

 ## 3. DP の定義

 定義:$$dp[j][t]$$意味:

 -$0$： 不可能、
-$1$: まさに一方向、
 -$2$: 少なくとも 2 つの方法。 

最初に:$$dp[0][0]=1$$空のサブセットにはサイズがあるため$0$そして合計$0$。 

正方形ごとに$a=i^2$、逆方向に更新します。$$dp[j+1][t+a] = \min\left(2,\; dp[j+1][t+a]+dp[j][t]\right).$$逆方向反復により、同じ正方形を複数回再利用することができなくなります。 

---

 ## 4. 可能な最大合計額

 最大の$50$-サブセットの合計は$$51^2+52^2+\cdots+100^2.$$使用する$$\sum_{i=1}^{100} i^2 = \frac{100\cdot101\cdot201}{6}=338350,$$そして$$\sum_{i=1}^{50} i^2 = 42925,$$私たちは得ます$$338350-42925=295425.$$したがって、DP テーブルには次の合計のみが必要です。$295425$。 

---

 # Pythonの実装```python
import numpy as np

# We need 50-element subset sums of squares 1^2 ... 100^2
N = 100
K = 50

squares = [i * i for i in range(1, N + 1)]

# Maximum possible 50-element sum
MAX_SUM = sum(i * i for i in range(51, 101))

# dp[j][s]:
#   0 = impossible
#   1 = exactly one way
#   2 = two or more ways
dp = np.zeros((K + 1, MAX_SUM + 1), dtype=np.uint8)

# Empty subset
dp[0][0] = 1

# Process each square
for a in squares:

    # Go backwards so each value is used once
    for j in range(K - 1, -1, -1):

        # Existing states for size j
        src = dp[j, :MAX_SUM + 1 - a]

        # Destination states for size j+1
        dst = dp[j + 1, a:]

        # Add counts, capped at 2
        total = dst.astype(np.uint16) + src.astype(np.uint16)
        total[total > 2] = 2

        dp[j + 1, a:] = total.astype(np.uint8)

# Sum all uniquely representable sums
answer = np.where(dp[K] == 1)[0].sum()

print(answer)
```---

 # 小さな例での検証

 のために$$B=\{1,3,6,8,10,11\},$$ユニークな$3$-サブセットの合計は$$\{10,12,14,18,21,25,27,29\}.$$それらの合計は$$10+12+14+18+21+25+27+29=156,$$ステートメントと一致します。
