[プロジェクト オイラー問題 470](https://projecteuler.net/problem=470)

 ## 解決策

 **答え:**`147668794`現在表示されているダイ面のセットを次のようにします。$V\subseteq \{1,\dots,d\}$、 と$|V|=k$。 

### 1. Ramvok分析

 固定金型状態の場合$V$、 定義する$H_t(V)$最大でも期待される**賞品** (コストを除く) として最適な金額$t$ターンは許可されます。 

我々は持っています：

-$H_0(V)=0$-$H_1(V)=\frac1k\sum_{x\in V}x$- のために$t\ge 1$、$$H_{t+1}(V) = \frac1k\sum_{x\in V}\max(x,H_t(V))$$ロールを見た後だから$x$、私たちは立ち止まって取るかのどちらかです$x$、または値を続行します$H_t(V)$。 

初期費用がかかる場合は、$ct$の場合、期待される**利益**は次のようになります。$$R_t(V,c)=H_t(V)-ct$$そして$$R(V,c)=\max_{t\ge0} R_t(V,c).$$のために$c=0$、最適な戦略は、表示される最大の顔が表示されるまで永遠に待つことです。そのため、次のようになります。$$R(V,0)=\max(V).$$のために$c>0$、わずかな改善$$H_{t+1}(V)-H_t(V)$$単調減少するので、それを下回るまで繰り返します$c$。 

例を確認すると:$$R(\{1,2,3,4\},0.2)=2.65$$これはステートメントと一致します。 

---

 ### 2. スーパー Ramvok 分析

 状態をサブセットとする$V$目に見える顔の。 

各 Ramvok ゲームの後、1 つの均一にランダムな面が切り替わります (表示 ↔ 空白)。 すべての面が空白になった場合、プロセスは終了します。 

させて$S(V,c)$状態から出発して将来の最適な予想利益になる$V$。 それから：$$S(\varnothing,c)=0$$そしてのために$V\neq\varnothing$、$$S(V,c) = R(V,c) + \frac1d \sum_{i=1}^{d} S(V\triangle \{i\},c)$$どこ$\triangle$は面を切り替えることを示します。 

超立方体ウォークの対称性により、ハミング重みに条件付けすると、同じサイズのすべてのサブセットの可能性が等しくなります。 したがって：$$S(d,c) = \sum_{k=1}^{d} N_{d,k}\, \overline{R}_{d,k}(c)$$どこ：

-$N_{d,k}$=体重までの予想来院回数-$k$空集合での吸収前の状態、
 -$\overline{R}_{d,k}(c)$= 全体の Ramvok の平均利益$k$-のサブセット$\{1,\dots,d\}$。 

の$N_{d,k}$値は重みの誕生と死亡の連鎖から得られます。$$k \to k-1 \text{ with prob } \frac{k}{d}, \qquad k \to k+1 \text{ with prob } \frac{d-k}{d}.$$この一時的なマルコフ システムを解くと、予想される訪問数が得られます。 

この例では正しく検証されています。$$S(6,1)=208.3$$問題文と一致します。 

### 3. Python の実装```python
import math
import itertools
import numpy as np

def expected_visits(d):
    """
    Expected number of visits to each weight k=1..d
    before absorption at 0, starting from weight d.
    """
    A = np.zeros((d, d))

    for k in range(1, d + 1):
        i = k - 1
        A[i, i] = 1.0

        # Transition to k-1
        if k > 1:
            A[i, k - 2] -= k / d

        # Transition to k+1
        if k < d:
            A[i, k] -= (d - k) / d

    # Fundamental matrix row for starting state d
    N = np.linalg.inv(A)
    return N[d - 1]

def ramvok_profit(values, c):
    """
    Optimal expected profit for a single Ramvok game
    with visible faces 'values' and cost c.
    """
    values = tuple(sorted(values))

    # c = 0 -> wait forever for max value
    if c == 0:
        return values[-1]

    k = len(values)
    H = 0.0
    best = 0.0
    turns = 0

    while True:
        turns += 1

        # H_{t+1} = E[max(x, H_t)]
        new_H = sum(max(x, H) for x in values) / k

        profit = new_H - c * turns
        best = max(best, profit)

        marginal_gain = new_H - H

        # Further turns can no longer improve value
        if marginal_gain < c:
            break

        H = new_H

    return best

def super_ramvok(d, c):
    visits = expected_visits(d)

    total = 0.0

    for k in range(1, d + 1):
        subset_sum = 0.0

        for subset in itertools.combinations(range(1, d + 1), k):
            subset_sum += ramvok_profit(subset, c)

        avg_profit = subset_sum / math.comb(d, k)
        total += visits[k - 1] * avg_profit

    return total

def F(n):
    total = 0.0

    for d in range(4, n + 1):
        for c in range(n + 1):
            total += super_ramvok(d, c)

    return round(total)

print(super_ramvok(6, 1))  # 208.3
print(F(20))
```### 4. 検証
