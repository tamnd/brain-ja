[プロジェクト オイラー問題 398](https://projecteuler.net/problem=398)

 ## 解決策

 **答え:**`2010.59096`セグメントの長さを次のようにします$$X_1,\dots,X_m \in \mathbb Z_{>0}, \qquad X_1+\cdots+X_m=n.$$選択する$m-1$点を均等にカットします。$n-1$内部格子点は、次の構成を選択することと同等です。$n$の中へ$m$ポジティブな部分を均一にランダムに配置します。 

このような作品の総数は、$$\binom{n-1}{m-1}.$$させて$Y$2 番目に小さいセグメント長になります。 

正の整数確率変数には標準のテールサム恒等式を使用します。$$\mathbb E[Y] = \sum_{k\ge1}\Pr(Y\ge k).$$したがって、全体の問題は、2 番目に小さい部分が少なくとも$k$。 

---

 #1. 数を数える$\Pr(Y\ge k)$条件$Y\ge k$意味:

 - **すべて**のセグメントが少なくとも$k$、
 - または **ちょうど 1 つ** セグメントが$<k$、他のすべては少なくとも$k$。 

---

 ## ケース A: すべてのセグメント$\ge k$書く$$X_i = k + Z_i, \qquad Z_i\ge0.$$それから$$Z_1+\cdots+Z_m = n-mk.$$ソリューションの数:$$A_k = \binom{n-mk+m-1}{m-1}.$$---

 ## ケース B: セグメントが 1 つだけ$<k$どのセグメントが小さいかを選択します。$m$選択肢。 

小さなセグメントに値があると仮定します$t\in\{1,\dots,k-1\}$。 

残りについては$m-1$セグメント書き込み$$X_i = k + Z_i,\qquad Z_i\ge0.$$それから$$\sum Z_i = n-t-(m-1)k.$$したがって、可能性の数は、$$\binom{n-t-(m-1)k+m-2}{m-2}.$$まとめ$t=1,\dots,k-1$ホッケースティックのアイデンティティを使用すると、$$B_k = \binom{n-(m-1)(k-1)-1}{m-1} - \binom{n-m(k-1)-1}{m-1}.$$したがって、好ましい組成物の数は、$$N_k = A_k + mB_k.$$簡略化後:$$N_k = m\binom{n-(m-1)(k-1)-1}{m-1} - (m-1)\binom{n-m(k-1)-1}{m-1}.$$したがって$$\Pr(Y\ge k) = \frac{ m\binom{n-(m-1)(k-1)-1}{m-1} - (m-1)\binom{n-m(k-1)-1}{m-1} }{ \binom{n-1}{m-1} }.$$ついに、$$E(n,m) = \sum_{k\ge1}\Pr(Y\ge k).$$---

 #2. Pythonの実装```python
from math import comb

def E(n, m):
    total = comb(n - 1, m - 1)

    ans = 0.0
    k = 1

    while True:
        a_top = n - m * (k - 1) - 1
        b_top = n - (m - 1) * (k - 1) - 1

        if a_top < m - 1 and b_top < m - 1:
            break

        A = comb(a_top, m - 1) if a_top >= m - 1 else 0
        B = comb(b_top, m - 1) if b_top >= m - 1 else 0

        favorable = m * B - (m - 1) * A

        ans += favorable / total
        k += 1

    return ans

# sanity checks
print(E(3, 2))   # 2.0
print(E(8, 3))   # 16/7 = 2.285714285714...

# target
value = E(10**7, 100)
print(f"{value:.5f}")
```---

 #3. コードのチュートリアル

 -`total`は作曲の総数です。$$\binom{n-1}{m-1}.$$- それぞれについて$k$、次のように計算します。 

-`A`= すべてのパートが少なくとも含まれるコンポジションの数$k$、
 -`B`= 補助ホッケースティック用語、
 -`favorable = m*B - (m-1)*A`。 
- で割る`total`与える$\Pr(Y\ge k)$。 
- 全体をまとめる$k$期待をもたらします。 

チェック項目:$$E(3,2)=2$$そして$$E(8,3)=\frac{16}{7}$$ステートメントと正確に一致します。

 #4. 最終検証

 のために$n=10^7$そして$m=100$:

 - 平均セグメント長は$10^5$、
 - 最小値と 2 番目の最小値ははるかに小さい必要があります。 
- 周囲の値$2000$2 番目に小さい次数の統計としては完全に合理的です。 

計算により得られるのは、$$E(10^7,100)=2010.590959579\ldots$$小数点第 5 位に四捨五入:
