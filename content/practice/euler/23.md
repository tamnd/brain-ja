[プロジェクト オイラー問題 23](https://projecteuler.net/problem=23)

 ## 解決策

 **答え:**`4179871`私たちは、2 つの豊富な数値の合計として**書くことができない**すべての正の整数を求めます。 

適切な約数の合計がその数自体を超える場合、その数は**豊富**です。 

この問題により、キーのバインドが得られます。 

- 以下のすべての整数$28123$は 2 つの豊富な数の和として書くことができます。 

したがって、タスクは次のとおりです。 

1. までの豊富な数をすべて生成します。$28123$。 
2. 2 つの豊富な数値の合計として表現できるすべての数値にマークを付けます。 
3. 以下のすべての整数を合計します。$1$に$28123$**マークされていない**。 

除数和ふるいを使用すると、これが効率的に行われます。 

Python コード:```python
LIMIT = 28123

# Sum of proper divisors for each number
div_sum = [0] * (LIMIT + 1)

for i in range(1, LIMIT // 2 + 1):
    for j in range(i * 2, LIMIT + 1, i):
        div_sum[j] += i

# Collect abundant numbers
abundant = [n for n in range(1, LIMIT + 1) if div_sum[n] > n]

# Mark numbers expressible as sum of two abundant numbers
can_be_written = [False] * (LIMIT + 1)

for i in range(len(abundant)):
    for j in range(i, len(abundant)):
        s = abundant[i] + abundant[j]
        if s <= LIMIT:
            can_be_written[s] = True
        else:
            break

# Sum numbers that cannot be expressed this way
answer = sum(n for n in range(1, LIMIT + 1) if not can_be_written[n])

print(answer)
```ロジックをトレースすると、次のようになります。 

-$12$最初の豊富な数です。 
-$24 = 12 + 12$は最初に表現可能な合計です。 
- ふるいは除数の合計を正しく計算します。 
- ネストされたループは、すべての豊富なペアの合計を制限まで列挙します。 
- 最終的な累積は、既知のプロジェクト オイラーの結果と一致します。 

**答え: 4179871**
