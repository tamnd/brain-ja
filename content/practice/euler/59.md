[プロジェクト オイラー問題 59](https://projecteuler.net/problem=59)

 ## 解決策

 **答え:**`129448`### 1. 数学的分析

 **長さ 3 の繰り返し XOR キー**を使用して暗号化された暗号文が与えられます。各キー文字は英小文字 (`a`–`z`）。 

次の場合:

 - 平文バイト =$p_i$- キーバイト =$k_i$- 暗号文バイト =$c_i$この場合、暗号化は次のようになります。$$c_i = p_i \oplus k_{i \bmod 3}$$どこ$\oplus$はXORを表します。 

XOR はそれ自体の逆なので、次のようになります。$$p_i = c_i \oplus k_{i \bmod 3}$$したがって、**キーがわかっていれば**、復号化は簡単です。 

課題は、未知の 3 文字のキーを見つけることです。 

---

 #### 重要な観察: ブルート フォースは小さなものである

 各キー文字は小文字です。$$26^3 = 17576$$可能なキー。 

これは小さいので、すべてのキーを試すことができます。 

各候補キーについて:

 1. 暗号文を周期的に XOR 復号化します。 
2. 結果が英語のテキストと似ているかどうかを確認します。 

英語のテキストには次のような一般的な単語が含まれています。 

-`" the "`-`" and "`-`" of "`-`" to "`ほとんどが印刷可能な ASCII 文字です。 

読みやすい英語が見つかったら、次を計算します。$$\sum \text{ASCII values of plaintext}$$その合計が必要な答えです。 

---

 ### 2. Python の実装```python
from itertools import product
import requests

# Download the cipher text
url = "https://projecteuler.net/resources/documents/0059_cipher.txt"
cipher = list(map(int, requests.get(url).text.strip().split(",")))

best_score = -1
best_sum = None
best_text = None
best_key = None

# Try all 3-letter lowercase keys
for key_chars in product(range(ord('a'), ord('z') + 1), repeat=3):
    # Decrypt
    plaintext = [
        c ^ key_chars[i % 3]
        for i, c in enumerate(cipher)
    ]

    # Convert to text
    text = ''.join(map(chr, plaintext))

    # Reject obviously bad plaintext
    if not all(32 <= x <= 126 or x in (10, 13) for x in plaintext):
        continue

    # Score based on common English words
    score = (
        text.count(" the ") * 10 +
        text.count(" and ") * 5 +
        text.count(" of ") * 3 +
        text.count(" to ") * 2 +
        text.count(" in ")
    )

    # Keep best candidate
    if score > best_score:
        best_score = score
        best_sum = sum(plaintext)
        best_text = text
        best_key = ''.join(map(chr, key_chars))

print("Key:", best_key)
print("ASCII sum:", best_sum)
print(best_text[:300])
```---
