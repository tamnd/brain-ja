[プロジェクト オイラー問題 633](https://projecteuler.net/problem=633)

 ## 解決策

 **答え:**`1.0012e-10`させて$$X_p(n)= \begin{cases} 1,& p^2\mid n,\\ 0,& p^2\nmid n. \end{cases}$$次に、平方素因数の数は、$n$は$$X(n)=\sum_p X_p(n).$$固定素数の場合$p$、$$\Pr(p^2\mid n)=\frac1{p^2}, \qquad \Pr(p^2\nmid n)=1-\frac1{p^2}.$$として$N\to\infty$、異なる素二乗による割り算は独立するため、極限分布はオイラー積によって決まります。$$F(z)=\prod_p\left(1-\frac1{p^2}+\frac{z}{p^2}\right).$$の係数$z^k$まさに限界密度です$$c_k^\infty=[z^k]F(z).$$---

 #1. 式の導出

 各要素を次のように書き換えます。$$1-\frac1{p^2}+\frac{z}{p^2} = \left(1-\frac1{p^2}\right)\left(1+\frac{z}{p^2-1}\right).$$したがって、$$F(z) = \prod_p\left(1-\frac1{p^2}\right) \prod_p\left(1+\frac{z}{p^2-1}\right).$$オイラーの古典的な恒等式を使用すると、$$\prod_p\left(1-\frac1{p^2}\right)=\frac6{\pi^2},$$私たちは得ます$$F(z)=\frac6{\pi^2}\prod_p\left(1+\frac{z}{p^2-1}\right).$$したがって$$c_k^\infty = \frac6{\pi^2} \sum_{p_1<\cdots<p_k} \prod_{i=1}^k \frac1{p_i^2-1}.$$のために$k=7$、オイラー積から係数を数値的に計算します。 

---

 #2. Pythonの実装```python
from mpmath import mp

mp.dps = 80          # high precision

K = 7
LIMIT = 100000       # enough for convergence

# sieve of Eratosthenes
sieve = [True] * (LIMIT + 1)
primes = []

for i in range(2, LIMIT + 1):
    if sieve[i]:
        primes.append(i)

        if i * i <= LIMIT:
            for j in range(i * i, LIMIT + 1, i):
                sieve[j] = False

# coeff[j] = coefficient of z^j in the truncated Euler product
coeff = [mp.mpf(0)] * (K + 1)
coeff[0] = mp.mpf(1)

for p in primes:
    q = mp.mpf(1) / (p * p)

    new = coeff[:]

    # multiply by (1 - q + z*q)
    for j in range(1, K + 1):
        new[j] = coeff[j] * (1 - q) + coeff[j - 1] * q

    new[0] = coeff[0] * (1 - q)

    coeff = new

answer = coeff[K]

print(answer)
print("{:.5e}".format(answer))
```---

 #3. コードのチュートリアル

 ### ステップ 1 — 素数を生成する

 までのすべての素数をふるいにかけます$100000$。 

オイラー積は非常に早く収束します。$O(1/p^2)$。 

---

 ### ステップ 2 — 生成関数を構築する

 各素数は因数に寄与します$$1-\frac1{p^2}+\frac{z}{p^2}.$$現在の多項式が$$a_0+a_1z+\cdots+a_K z^K,$$新しい係数を乗算すると、係数が更新されます。$$a_j \leftarrow a_j\left(1-\frac1{p^2}\right) + a_{j-1}\frac1{p^2}.$$これはまさにループが実装するものです。 

---

 ### ステップ 3 — 係数を抽出する

 すべての係数を掛け合わせた後、`coeff[7]`等しい$$c_7^\infty.$$計算により得られるのは、$$c_7^\infty = 1.001100542000098\ldots\times 10^{-10}.$$有効数字 5 桁に四捨五入:$$1.0011\times 10^{-10}.$$---

 #4. 最終検証

 シーケンスは急速に減少します。$$c_4^\infty \approx 10^{-4},\quad c_5^\infty \approx 10^{-6},\quad c_6^\infty \approx 10^{-8},$$したがって、近い値$10^{-10}$のために$k=7$完全に一貫しています。 

また、次の計算値は、$k=0,1,2,\dots$問題ステートメント内のテーブルを表示された精度で再現します。 

---

 **答え: 1.0011e-10**
