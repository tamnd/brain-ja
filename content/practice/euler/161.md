[プロジェクト オイラー問題 161](https://projecteuler.net/problem=161)

 ## 解決策

 **答え:**`20574308184277971`ボードをそのままにしておきます$9\times 12$、あります。$108$セルの合計。 

各トリオミノが正確にカバーするため、$3$セル、すべてのタイリングは正確に使用します$$108/3 = 36$$トリオミノ。 

重要な問題は、トリオミノが行境界を越えて拡張できるため、単純な行ごとの DP では不十分であることです。 標準的なソリューションは、**壊れたプロファイル動的プログラミング** アプローチです。 

---

 #1. 数学的分析

 トリオミノには 6 つの方向があります。 

- 2 つのストレート トロミノ:

 - 水平$1\times 3$- 垂直$3\times 1$- 4 つの L 字型トロミノ。 

ボードを行優先の順序でセルごとに処理します。 

---

 ## フロンティアの表現

 どの時点でも、将来のセルの一部は、以前に開始された部分によってすでに占有されています。 

垂直トリオミノは下方向に最大 2 列まで拡張できるため、次の占有を覚えておくだけで十分です。 

- 現在の行
 - 次の行
 - 次の行に続きます

 幅用$9$、これは当然ビットマスクによって表されます。 

一般的な最適化は次のとおりです。 

- 一度に 1 つのセルを処理します。 
- 現在の位置を基準にして次の 2 行の占有を維持します。 

同等の配合物が存在します。 最もクリーンな再帰的なものは次のとおりです。$$F(pos, mask_0, mask_1, mask_2)$$どこ：

-$pos$= 現在の行インデックス、
 -$mask_0$= 現在の行の占有率、
 -$mask_1$= 次の行の占有率、
 -$mask_2$= 次の行の占有率。 

各マスクには 9 ビットがあります。 

現在の行がいっぱいになった場合:$$mask_0 = 2^9 - 1 = 511$$私たちは前進します:$$(mask_0,mask_1,mask_2)\to(mask_1,mask_2,0)$$次の行に移動します。 

---

 ## 最初の空のセルを埋める

 各段階で:

 1. 左端の空のビットを見つけます。$mask_0$。 
2. そのセルをカバーするすべてのトリオミノの向きを試します。 
3. マスクを適宜更新します。 

これにより次のことが保証されます。 

- 重複なし、
 - 省略なし、
 - すべてのタイリングは正確に 1 回カウントされます。 

---

 ## これが機能する理由

 これは、古典的な転送 DP / プロファイル DP 引数です。 

未来は、処理されたセルと未処理のセルの境界にのみ依存します。 

トリオミノの高さは最大 3 であるため、状態に必要な情報は 3 行だけです。 

到達可能な状態の数は管理可能 (最大で数十万) であり、メモ化により検索が高速になります。

 #2. Pythonの実装```python
from functools import lru_cache

W = 9
H = 12
FULL = (1 << W) - 1

# ---------------------------------------------------------
# Helper routines
# ---------------------------------------------------------

def bit(mask, c):
    return (mask >> c) & 1

def setbit(mask, c):
    return mask | (1 << c)

# ---------------------------------------------------------
# Recursive profile DP
# ---------------------------------------------------------

@lru_cache(None)
def solve(row, m0, m1, m2):
    """
    row = current row index

    m0 = occupancy mask for current row
    m1 = occupancy mask for next row
    m2 = occupancy mask for row+2
    """

    # Finished all rows
    if row == H:
        return 1 if (m0, m1, m2) == (0, 0, 0) else 0

    # If current row is completely filled,
    # advance frontier downward
    if m0 == FULL:
        return solve(row + 1, m1, m2, 0)

    # Find first empty column
    c = 0
    while bit(m0, c):
        c += 1

    ans = 0

    # -------------------------------------------------
    # Try all 6 triomino orientations
    # -------------------------------------------------

    # 1) Horizontal 1x3
    if c + 2 < W:
        if (not bit(m0, c + 1)
                and not bit(m0, c + 2)):
            ans += solve(
                row,
                setbit(setbit(setbit(m0, c), c + 1), c + 2),
                m1,
                m2
            )

    # 2) Vertical 3x1
    if row + 2 < H:
        if (not bit(m1, c)
                and not bit(m2, c)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(m1, c),
                setbit(m2, c)
            )

    # 3) L-shape: cells
    # (r,c), (r+1,c), (r,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m0, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    # 4) L-shape:
    # (r,c), (r+1,c), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m1, c)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(m0, c),
                setbit(setbit(m1, c), c + 1),
                m2
            )

    # 5) L-shape:
    # (r,c), (r,c+1), (r+1,c+1)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c + 1)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c + 1),
                m2
            )

    # 6) L-shape:
    # (r,c), (r,c+1), (r+1,c)
    if c + 1 < W and row + 1 < H:
        if (not bit(m0, c + 1)
                and not bit(m1, c)):
            ans += solve(
                row,
                setbit(setbit(m0, c), c + 1),
                setbit(m1, c),
                m2
            )

    return ans

print(solve(0, 0, 0, 0))

 #3. コードのチュートリアル

 ## 定数```python
W = 9
H = 12
FULL = (1 << W) - 1
```

`FULL = 511`行内のすべてのセルが占有されていることを意味します。 

---

 ## 状態の定義```python
solve(row, m0, m1, m2)
```連続する 3 行の占有をエンコードします。 

---

 ## 行送り```python
if m0 == FULL:
    return solve(row + 1, m1, m2, 0)
```現在の行が完了したら:

 - 次の行が現在の行になります。 
- 3 行目が次になります。 
- 新しい空の行が追加されます。 

---

 ## 最初の空のセル```python
c = 0
while bit(m0, c):
    c += 1
```正規化は重要です。 

常に最初に左端の空のセルを入力します。 

これにより、重複したカウントが防止されます。

 ## ピースの配置

 各方向のチェック:

 - 境界、
 - 重複制約。 

次に、対応するビットが設定されます。 

例: 垂直トロミノ```python
if row + 2 < H:
    if (not bit(m1, c)
            and not bit(m2, c)):
```次の 2 行の同じ列が空である必要があります。
