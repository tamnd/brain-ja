[プロジェクト オイラー問題 216](https://projecteuler.net/problem=216)

 ## 解決策

 **答え:**`5437849`次の形式の素数を数えなければなりません$$t(n)=2n^2-1,\qquad 1<n\le 50\,000\,000.$$問題は次のように述べています$n\le 10\,000$、 その通り$2202$値は素数です。 までのカウントが必要です$5\times 10^7$。 

---

 # 数学的分析

 の数を求めます$n$そのような$$2n^2-1$$プライムです。 

すべての直接の素数テスト$50$代数構造を利用しない限り、100 万値を処理するのは遅すぎます。 

---

 ## 1. 合同構造

 素数を仮定します$p$分割する$2n^2-1$。 それから$$2n^2 \equiv 1 \pmod p$$それは意味します$$n^2 \equiv \frac12 \pmod p.$$同様に、$$(2n)^2 \equiv 2 \pmod p.$$したがって$2$二次剰余モジュロでなければなりません$p$。 二次相反性により、$$\left(\frac{2}{p}\right)=1 \iff p\equiv 1,7 \pmod 8.$$したがって、すべての奇数の素約数は、$2n^2-1$満足する$$p\equiv 1 \text{ or } 7 \pmod 8.$$そのような素数ごとに$p$、合同$$2n^2\equiv 1 \pmod p$$厳密に 2 つの解を法とする$p$。 

つまり、すべての複合値をプライムふるいのように正確にふるいにかけられるということです。 

---

 ## 2. ふるい戦略

 定義する$$f(n)=2n^2-1.$$最初は次のように仮定します$f(n)$プライムです。 

すべての素数について$p\equiv1,7\pmod8$:

 1.解決する$$2n^2\equiv1\pmod p.$$2. 2 つの根を次のようにします。$r_1,r_2$。 
3. 毎$$n\equiv r_1,r_2\pmod p$$与える$p\mid f(n)$。 

私たちはそのようなものすべてにマークを付けます$n$。 

ただし、$f(n)=p$それ自体を複合としてマークすることは_しない_必要があります。 

それが起こるのは次のときだけです$$2n^2-1=p.$$したがって、ふるい分け中に、いつであるかをマークするだけです$$2n^2-1>p.$$これは、通常のふるいを開始するのとまったく同じです。$p^2$。 

---

 ## 3. ルートの計算

 解決策が必要です$$2n^2\equiv1\pmod p.$$の逆数を乗算します$2$:$$n^2\equiv 2^{-1}\pmod p.$$同様に、$$(2n)^2\equiv2\pmod p.$$したがって、もし$s^2\equiv2\pmod p$、 それから$$n\equiv s\cdot 2^{-1}\pmod p.$$したがって、必要なのはモジュラー平方根だけです$2$モジュロ$p$、トネリ・シャンクス経由で入手可能。 

---

 ## 4. 複雑さ

 ふるいにかけます$N=50\,000\,000$インデックス。 

素数にわたる高調波密度は、総仕事量をおよそ与えます。$$N\sum_{p}\frac{2}{p} \sim 2N\log\log N,$$これは最適化されたコードで実現可能です。 

これは、このオイラー問題の標準的に受け入れられている解法です。 

---

 # Pythonの実装```python
from array import array
from math import isqrt

LIMIT = 50_000_000

# ------------------------------------------------------------
# Ordinary prime sieve up to sqrt(2)*LIMIT
# Any composite t(n)=2n^2-1 has a prime divisor <= sqrt(t(n))
# ------------------------------------------------------------

P = isqrt(2 * LIMIT * LIMIT - 1) + 1

is_prime = bytearray(b"\x01") * (P + 1)
is_prime[0] = is_prime[1] = 0

for i in range(2, isqrt(P) + 1):
    if is_prime[i]:
        step = i
        start = i * i
        is_prime[start:P + 1:step] = b"\x00" * ((P - start) // step + 1)

primes = [p for p in range(2, P + 1) if is_prime[p]]

# ------------------------------------------------------------
# Tonelli-Shanks modular square root
# Finds x such that x^2 = n (mod p)
# ------------------------------------------------------------

def tonelli(n, p):
    assert pow(n, (p - 1) // 2, p) == 1

    if p % 4 == 3:
        return pow(n, (p + 1) // 4, p)

    # write p-1 = q * 2^s with q odd
    q = p - 1
    s = 0
    while q % 2 == 0:
        s += 1
        q //= 2

    # find quadratic nonresidue z
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = pow(z, q, p)
    x = pow(n, (q + 1) // 2, p)
    t = pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        temp = (t * t) % p
        while temp != 1:
            temp = (temp * temp) % p
            i += 1

        b = pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ------------------------------------------------------------
# Candidate array:
# 1 means "possibly prime"
# ------------------------------------------------------------

cand = bytearray(b"\x01") * (LIMIT + 1)
cand[0] = cand[1] = 0

# ------------------------------------------------------------
# Sieve using prime divisors
# ------------------------------------------------------------

for p in primes:
    if p == 2:
        continue

    # 2 must be quadratic residue mod p
    if p % 8 not in (1, 7):
        continue

    # sqrt(2) mod p
    s = tonelli(2, p)

    inv2 = (p + 1) // 2

    r1 = (s * inv2) % p
    r2 = (-r1) % p

    for r in (r1, r2):
        if r == 0:
            start = p
        else:
            start = r

        # ensure 2*n^2 - 1 > p
        while 2 * start * start - 1 <= p:
            start += p

        for n in range(start, LIMIT + 1, p):
            cand[n] = 0

# ------------------------------------------------------------
# Count survivors
# ------------------------------------------------------------

answer = sum(cand)

print(answer)
```---
