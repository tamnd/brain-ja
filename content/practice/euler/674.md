[プロジェクト オイラー問題 674](https://projecteuler.net/problem=674)

 ## 解決策

 **答え:**`416678753`させて$$\mathcal I(x,y)=(1+x+y)^2+y-x.$$重要な観察は、$\mathcal I$非負整数の順序付きペアの単射エンコーディングです。 

確かに、書いてください$$s=1+x+y.$$それから$$\mathcal I(x,y)=s^2+(y-x).$$以来$0\le y-x\le s-1$絶対値では、すべての値は正方形の周囲の一意の間隔内にあります。$s^2$。 したがって、から$n=\mathcal I(x,y)$一意に復元できます。 

-$s=\lfloor \sqrt n\rfloor$、
 -$d=n-s^2=y-x$、
 -そしてそれゆえに$$x=\frac{s-1-d}{2},\qquad y=\frac{s-1+d}{2}.$$それで：$$\mathcal I(a,b)=\mathcal I(c,d)\iff a=c\text{ and }b=d.$$つまり、$\mathcal I$は、一次項統合のコンストラクター シンボルとまったく同じように動作します。 

---

 #1. 問題を統合に変換する

 すべての式は次のいずれかです。 

- 変数、または
 -$\mathcal I(A,B)$。 

したがって解決$$e_1=e_2$$再帰的に次のように削減されます。$$\mathcal I(A,B)=\mathcal I(C,D) \iff A=C \text{ and } B=D.$$これは標準的なロビンソン統合です。 

例:

 -$A=\mathcal I(x,\mathcal I(z,t))$-$B=\mathcal I(\mathcal I(y,z),y)$引数を一致させると次が得られます。$$x=\mathcal I(y,z), \qquad \mathcal I(z,t)=y.$$代入:$$x=\mathcal I(\mathcal I(z,t),z).$$自由変数を最小限に設定する ($z=t=0$) は次のようになります:$$y=\mathcal I(0,0)=1,$$

$$x=\mathcal I(1,0)=3,$$したがって$$A=B=\mathcal I(3,1)=23.$$まさに記載どおりです。

 # 2. すべての自由変数が次の場合に最小値が発生する理由$0$非負の整数の場合、$$\mathcal I(x+1,y)-\mathcal I(x,y)=2(1+x+y)>0,$$

$$\mathcal I(x,y+1)-\mathcal I(x,y)=2(2+x+y)>0.$$それで$\mathcal I$各引数で厳密に増加しています。 

統合後、制約によって強制されない変数は自由な非負の整数になります。 式はすべての変数で単調であるため、残りの自由変数をすべて に設定することによって最小同時値が得られます。$0$。 

したがって、アルゴリズムは次のようになります。 

1. 式をツリーに解析します。 
2. 統合を試みます。 
3.無理なら→貢献$0$。 
4. それ以外の場合は、残りのすべての変数を使用して統合式を評価します。$0$。 

最後だけ$9$数字が必要なため、計算は剰余で行われます$10^9$。

 #3. Pythonの実装```python
from __future__ import annotations
import sys

MOD = 10**9

# -------------------------------------------------
# Term representation
# -------------------------------------------------

class Var:
    __slots__ = ("name",)

    def __init__(self, name: str):
        self.name = sys.intern(name)

class INode:
    __slots__ = ("a", "b")

    def __init__(self, a, b):
        self.a = a
        self.b = b

# -------------------------------------------------
# Parsing
# -------------------------------------------------

def parse_expr(s: str):
    i = 0
    n = len(s)

    def parse():
        nonlocal i

        if s[i] == "I":
            i += 2  # skip "I("

            left = parse()

            i += 1  # skip ','

            right = parse()

            i += 1  # skip ')'

            return INode(left, right)

        start = i
        while i < n and s[i].isalpha():
            i += 1

        return Var(s[start:i])

    return parse()

# -------------------------------------------------
# Unification
# -------------------------------------------------

def unify(t1, t2):
    subs = {}
    occurs_cache = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            nxt = subs[t.name]

            # path compression
            if isinstance(nxt, Var) and nxt.name in subs:
                subs[t.name] = subs[nxt.name]

            t = nxt

        return t

    def occurs(vname, t):
        t = deref(t)

        key = (vname, id(t))
        if key in occurs_cache:
            return occurs_cache[key]

        stack = [t]
        seen = set()

        while stack:
            cur = deref(stack.pop())

            if isinstance(cur, Var):
                if cur.name == vname:
                    occurs_cache[key] = True
                    return True
            else:
                nid = id(cur)

                if nid in seen:
                    continue

                seen.add(nid)

                stack.append(cur.a)
                stack.append(cur.b)

        occurs_cache[key] = False
        return False

    stack = [(t1, t2)]

    while stack:
        a, b = stack.pop()

        a = deref(a)
        b = deref(b)

        if a is b:
            continue

        if isinstance(a, Var) and isinstance(b, Var):
            if a.name == b.name:
                continue

        if isinstance(a, Var):
            if occurs(a.name, b):
                return None

            subs[a.name] = b
            continue

        if isinstance(b, Var):
            if occurs(b.name, a):
                return None

            subs[b.name] = a
            continue

        if isinstance(a, INode) and isinstance(b, INode):
            stack.append((a.a, b.a))
            stack.append((a.b, b.b))
            continue

        return None

    return subs

# -------------------------------------------------
# Evaluation
# -------------------------------------------------

def i_op(x, y):
    s = (1 + x + y) % MOD
    return (s * s + y - x) % MOD

def evaluate(root, subs):
    memo = {}

    def deref(t):
        while isinstance(t, Var) and t.name in subs:
            t = subs[t.name]
        return t

    def rec(t):
        t = deref(t)

        if isinstance(t, Var):
            return 0

        tid = id(t)

        if tid in memo:
            return memo[tid]

        x = rec(t.a)
        y = rec(t.b)

        val = i_op(x, y)

        memo[tid] = val
        return val

    return rec(root)

# -------------------------------------------------
# Solve
# -------------------------------------------------

def least_simultaneous_value(e1, e2):
    subs = unify(e1, e2)

    if subs is None:
        return 0

    return evaluate(e1, subs)

def main():
    with open("I-expressions.txt") as f:
        terms = [parse_expr(line.strip())
                 for line in f if line.strip()]

    total = 0

    n = len(terms)

    for i in range(n):
        for j in range(i + 1, n):
            total += least_simultaneous_value(
                terms[i], terms[j]
            )

    print(total % MOD)

if __name__ == "__main__":
    main()
```---

 - コンパウンドとコンパウンド。 

発生チェックにより、次のような循環置換が防止されます。$$x = I(x,y).$$統合が失敗した場合、否定的でない解決策はありません。
