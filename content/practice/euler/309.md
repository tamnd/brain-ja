[プロジェクト オイラー問題 309](https://projecteuler.net/problem=309)

 ## 解決策

 **答え:**`210139`道路幅を次のようにします$w$。 はしごには長さがあるとします$x<y$、高所で反対側の壁に接触する$a$そして$b$、 それぞれ。 

ピタゴラスの定理によると、$$a^2+w^2=x^2,\qquad b^2+w^2=y^2$$それで$a,b$整数でなければなりません。 交差点の高さ$h$標準の交差はしご関係を満たします。$$\frac1h=\frac1a+\frac1b$$再配置すると$$h=\frac{ab}{a+b}$$したがって、整数の場合、$h$、次のものが必要です。$$a+b \mid ab$$したがって、問題は次のようになります。 

1. 共通の脚を持つすべての整数直角三角形を見つけます$w$:$$x^2=w^2+a^2,\qquad y^2=w^2+b^2$$2. 同じものを共有するすべてのペアについて$w$, が付いているものを数えます$$\frac{ab}{a+b}\in \mathbb Z$$重要な観察は、有効なすべての$(w,a,x)$はピタゴラストリプルです。 Euclid の公式を使用して、このようなトリプルをすべて効率的に生成できます。$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$と$\gcd(m,n)=1$逆パリティ、その後スケールアップ$k$。 

幅ごとに$w$、可能なすべてのラダー構成を収集します$(a,x)$次に、すべてのペアをテストします。$$h=\frac{ab}{a+b}$$もし$h$が整数である場合は、3 つの要素を数えます$(x,y,h)$。

 ### Python の実装```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 1_000_000

# width -> list of (height, ladder_length)
by_width = defaultdict(list)

# Generate all Pythagorean triples
m_max = isqrt(LIMIT) + 2

for m in range(2, m_max):
    for n in range(1, m):
        # Primitive triple conditions
        if gcd(m, n) != 1 or (m - n) % 2 == 0:
            continue

        a = m * m - n * n
        b = 2 * m * n
        c = m * m + n * n

        k = 1
        while k * c < LIMIT:
            aa = k * a
            bb = k * b
            cc = k * c

            # Either leg can be the street width
            if aa < LIMIT:
                by_width[aa].append((bb, cc))
            if bb < LIMIT:
                by_width[bb].append((aa, cc))

            k += 1

count = 0

# For each common width, test pairs
for w, configs in by_width.items():
    L = len(configs)

    for i in range(L):
        a, x = configs[i]

        for j in range(i + 1, L):
            b, y = configs[j]

            # Need x < y (avoid duplicates)
            if x == y:
                continue

            # h = ab / (a + b) must be integer
            if (a * b) % (a + b) == 0:
                count += 1

print(count)
```---

 ### コードのチュートリアル

 - **ピタゴラス トリプルを生成**

 - Euclid の公式は、すべての原始直角三角形を生成します。 
- 乗算$k$すべての非プリミティブなものを取得します。 
- 共通の幅でキー化されたすべての可能性を保存します$w$。 
- **同じ幅を共有するペアのはしご**

 ●各幅ごとにあらゆる収納物がはしご可能です。 
- すべてのペアを比較します。 
- **整数交差の高さを確認してください**

 - 使用する$$h=\frac{ab}{a+b}$$- 割り切れる場合のみカウントします。
