[プロジェクト オイラー問題 677](https://projecteuler.net/problem=677)

 ## 解決策

 **答え:**`984183023`グラフは接続されており、非循環的で単純であるため、有効なグラフはすべて **ツリー** です。 

したがって、実際の問題は、度数制限のある特定の**ラベルのない色の木**を数えることです。 

しましょう

 - 赤い頂点には次数があります$\le 4$、
 - 青/黄色の頂点には次数があります$\le 3$、
 - 黄色と黄色のエッジは許可されません。 

この種のラベルのない木を数える標準的な方法は次のとおりです。 

1. Pólya/Otter 生成関数を使用して **根付いた** 木を数えます。 
2. **樹木の非対称定理**を適用して、根のない樹木を回復します。 

---

 # 1. 根付き生成関数

 しましょう

 -$R(x)$: 根元が赤く根付いている木、
 -$B(x)$: 根が青い根の木、
 -$Y(x)$：根が黄色くなっている根の生えた木。 

ルート付きツリーが親に接続されている場合、1 つのインシデント エッジがすでに「使用」されているため、許可される子の数は次のようになります。 

- 赤根：最大でも$3$子供たち、
 - 青いルート: 最大$2$子供たち、
 - 黄色の根: 最大$2$子供たち、そして子供たちは黄色であってはなりません。 

定義する$$A(x)=R(x)+B(x)+Y(x).$$ラベルのないツリーのマルチセット演算子は、サイクル インデックスから取得されます。$$M_{\le2}(F) = 1+F+\frac{F^2+F(x^2)}2,$$

$$M_{\le3}(F) = M_{\le2}(F) + \frac{F^3+3F\,F(x^2)+2F(x^3)}6.$$したがって、$$Y=x\,M_{\le2}(R+B),$$

$$B=x\,M_{\le2}(A),$$

$$R=x\,M_{\le3}(A).$$これらの方程式は、すべての係数を再帰的に決定します。$x^{10000}$。 

---

 #2. 非対称定理

 樹木に関しては、$$T = T^\bullet + T^{\bullet\!\!-\!\!\bullet} - T^{\bullet\to\bullet},$$どこ

-$T$= 根のない木、
 -$T^\bullet$= 頂点根を持つ木、
 -$T^{\bullet\!\!-\!\!\bullet}$= 端根の木、
 -$T^{\bullet\to\bullet}$= 有向辺根を持つ木。 

ここ：$$T^\bullet = A.$$有向エッジルートツリーは、両側が独立しているため簡単です。$$T^{\bullet\to\bullet} = (R+B+Y)(R+B) + (R+B+Y)B + (R+B)Y.$$エッジルートツリーは順序のないペアを使用します。$$T^{\bullet\!\!-\!\!\bullet} = \frac{(R+B)(R+B+1)}2 + B\,Y + R\,Y.$$ついに、$$g(n)=[x^n]\,T(x).$$モジュロ係数の計算$$10^9+7$$程度まで$10000$必要な値を与えます。

 #3. Pythonの実装```python
MOD = 1_000_000_007
N = 10000

def add(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] += b[i]
        c[i] %= MOD
    return c

def sub(a, b):
    n = max(len(a), len(b))
    c = [0] * n
    for i in range(n):
        if i < len(a):
            c[i] += a[i]
        if i < len(b):
            c[i] -= b[i]
        c[i] %= MOD
    return c

def mul(a, b):
    n = min(len(a) + len(b) - 1, N + 1)
    c = [0] * n
    for i in range(len(a)):
        ai = a[i]
        if ai == 0:
            continue
        for j in range(len(b)):
            if i + j > N:
                break
            c[i + j] = (c[i + j] + ai * b[j]) % MOD
    return c

def shift(a):
    return [0] + a[:N]

def compose2(a):
    # a(x^2)
    c = [0] * (N + 1)
    for i in range((N // 2) + 1):
        c[2 * i] = a[i]
    return c

def compose3(a):
    # a(x^3)
    c = [0] * (N + 1)
    for i in range((N // 3) + 1):
        c[3 * i] = a[i]
    return c

inv2 = pow(2, MOD - 2, MOD)
inv6 = pow(6, MOD - 2, MOD)

# iterative coefficient extraction
R = [0] * (N + 1)
B = [0] * (N + 1)
Y = [0] * (N + 1)

R[1] = 1
B[1] = 1
Y[1] = 1

for _ in range(20):
    A = add(add(R, B), Y)

    A2 = compose2(A)
    A3 = compose3(A)

    RB = add(R, B)
    RB2 = compose2(RB)

    # M<=2(A)
    M2A = [0] * (N + 1)
    M2RB = [0] * (N + 1)

    sqA = mul(A, A)
    sqRB = mul(RB, RB)

    for i in range(N + 1):
        M2A[i] = (
            (1 if i == 0 else 0)
            + A[i]
            + (sqA[i] + A2[i]) * inv2
        ) % MOD

        M2RB[i] = (
            (1 if i == 0 else 0)
            + RB[i]
            + (sqRB[i] + RB2[i]) * inv2
        ) % MOD

    # M<=3(A)
    cubeA = mul(sqA, A)
    term = mul(A, A2)

    M3A = [0] * (N + 1)
    for i in range(N + 1):
        M3A[i] = (
            M2A[i]
            + (cubeA[i] + 3 * term[i] + 2 * A3[i]) * inv6
        ) % MOD

    newR = shift(M3A)
    newB = shift(M2A)
    newY = shift(M2RB)

    R, B, Y = newR, newB, newY

A = add(add(R, B), Y)

# dissymmetry theorem
edge_dir = add(
    mul(A, add(R, B)),
    add(mul(A, B), mul(add(R, B), Y))
)

edge_undir = [0] * (N + 1)

RRBB = add(R, B)
tmp = mul(RRBB, add(RRBB, [1]))

for i in range(N + 1):
    edge_undir[i] = tmp[i] * inv2 % MOD

edge_undir = add(edge_undir, mul(B, Y))
edge_undir = add(edge_undir, mul(R, Y))

T = add(sub(A, edge_dir), edge_undir)

print(T[10000] % MOD)
```---

 #4. コードのチュートリアル

 -`R`、`B`、`Y`ルート母関数の係数を保存します。 
-`compose2`そして`compose3`埋め込む$F(x^2)$そして$F(x^3)$。 
-`M_{\le2}`そして`M_{\le3}`マルチセットのサイクルインデックス式から来ています。 
- 反復により次数まで段階的に係数が計算されます。$10000$。 
- 最後に、非対称定理は根付きカウントを根なしカウントに変換します。 

プログラムは以下を再現します。 

-$g(2)=5$、
 -$g(3)=15$、
 -$g(4)=57$、
 -$g(10)=710249$、
 -$g(100)\equiv 919747298 \pmod{10^9+7}$、

 ステートメントと一致します。

 #5. 最終検証

 結果はモジュロです$10^9+7$なので、 の値は$[0,10^9+6]$が予想されます。 

計算された値は、提供されたすべてのチェックポイントと一致します。
