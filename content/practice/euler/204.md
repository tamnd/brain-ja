 ## 解決策

 **答え:**`2944730`### 1. 数学的分析

 **を超えないタイプ 100 の一般化ハミング数** をカウントしたいと考えています。$10^9$。 

数値は、次のタイプの一般化されたハミング数です。$n$**すべての素因数が次の場合$\le n$**。 

タイプについて$100$、許可される素数は次のとおりです。$$2,3,5,7,11,\dots,97$$つまり、**すべての素数$\le 100$**。 

次の形式の整数を数える必要があります。$$m = \prod_{p\le 100} p^{e_p}$$そのような$$m \le 10^9, \qquad e_p \ge 0.$$---

 #### 重要な洞察: プライムパワーによる再帰的生成

 最大の整数に対する総当たり検索$10^9$絶望的だろう。 

代わりに、すべての有効な数値に **一意の素因数分解**があることに注目して、すべての可能性を再帰的に構築できます。 

素数が次のとおりであるとします。$$p_1,p_2,\dots,p_k$$素数ごとに$p_i$、指数を選択してもよい$$e_i = 0,1,2,\dots$$制限を下回ることが条件となります。 

各再帰ステップで:

 - 現在の素数の累乗を選択します。 
- それを現在の積に乗算します。 
- 次の素数まで再帰します。 

素因数分解は一意であるため、次のようになります。 

- **すべての有効な数値は 1 回だけ生成されます**、そして
 - **無効な番号は生成されません**。 

これは本質的に、指数ベクトルの深さ優先列挙です。 

たとえば、タイプを使用すると、$5$、許可される素数は次のとおりです。$$2,3,5$$そしてフォームの数を生成します$$2^a3^b5^c \le N.$$のために$N=10^8$の場合、カウントは **1105** となり、問題のステートメントと一致するはずです。

 ### 2. Python の実装```python
from sympy import primerange

LIMIT = 10**9

# All allowed prime factors (primes <= 100)
primes = list(primerange(1, 101))

def count_hamming(index, current):
    """
    Recursively count generalised Hamming numbers.

    index   : which prime we are currently processing
    current : current product formed so far
    """
    # If all primes processed, we found one valid number
    if index == len(primes):
        return 1

    total = 0
    p = primes[index]

    # Try all powers of p that keep us <= LIMIT
    value = current
    while value <= LIMIT:
        total += count_hamming(index + 1, value)
        value *= p

    return total

answer = count_hamming(0, 1)
print(answer)
```---
