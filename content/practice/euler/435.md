[プロジェクト オイラー問題 435](https://projecteuler.net/problem=435)

 ## 解決策

 **答え:**`252541322550`させて$$F_n(x)=\sum_{i=0}^n f_i x^i,$$どこ$f_0=0,\ f_1=1,\ f_n=f_{n-1}+f_{n-2}$、そして私たちが望むのは$$\sum_{x=0}^{100} F_n(x) \quad \text{for } n=10^{15}$$モジュロ$$15! = 1{,}307{,}674{,}368{,}000.$$重要な観察は、固定された$x$、$F_n(x)$**線形漸化式**を満たすため、次のように計算できます。$O(\log n)$行列のべき乗を使用した時間。 

それぞれについて$x$、 定義する：$$g_k=f_k x^k,\qquad h_k=f_{k+1}x^k.$$それから：$$g_{k+1}=x h_k,$$

$$h_{k+1}=x(g_k+h_k),$$そして$$F_{k+1}=F_k+g_{k+1}.$$これにより、行列の漸化式が得られます。$$\begin{bmatrix} g_{k+1}\\ h_{k+1}\\ F_{k+1} \end{bmatrix} = \begin{bmatrix} 0 & x & 0\\ x & x & 0\\ 0 & x & 1 \end{bmatrix} \begin{bmatrix} g_k\\ h_k\\ F_k \end{bmatrix},$$初期状態で$$(g_0,h_0,F_0)=(0,1,0).$$したがって、それぞれについて$x\in[0,100]$、計算する$M_x^n$モジュロ$15!$、 抽出する$F_n(x)$、すべての結果をモジュロで合計します$15!$。 

Python の実装:```python
MOD = 1307674368000  # 15!
N = 10**15

def mat_mul(A, B, mod):
    """Multiply two 3x3 matrices modulo mod."""
    return [
        [
            sum(A[i][k] * B[k][j] for k in range(3)) % mod
            for j in range(3)
        ]
        for i in range(3)
    ]

def F_mod(n, x, mod):
    """Compute F_n(x) modulo mod using matrix exponentiation."""
    M = [
        [0, x % mod, 0],
        [x % mod, x % mod, 0],
        [0, x % mod, 1]
    ]

    # State vector: [g_0, h_0, F_0] = [0,1,0]
    vec = [0, 1, 0]

    while n:
        if n & 1:
            vec = [
                sum(M[i][j] * vec[j] for j in range(3)) % mod
                for i in range(3)
            ]
        M = mat_mul(M, M, mod)
        n >>= 1

    return vec[2]

answer = 0
for x in range(101):
    answer = (answer + F_mod(N, x, MOD)) % MOD

print(answer)
```例に対する健全性チェック:
