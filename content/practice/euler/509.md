[プロジェクト オイラー問題 509](https://projecteuler.net/problem=509)

 ## 解決策

 **答え:**`151725678`させて$g(n)$サイズの山の Sprague-Grundy 値になる$n$。 

移動は適切な約数を選択することで構成されます$d\mid n$、$d<n$、と置き換えます$n$による$n-d$。 

3 つの山の場合、位置は$(a,b,c)$負けてるなら$$g(a)\oplus g(b)\oplus g(c)=0,$$どこ$\oplus$ビット単位の XOR です。 

したがって、問題全体は理解に帰着します$g(n)$。 

---

 #1. 数学的分析

 ## ステップ 1: グランディ値を計算する

 しましょう$v_2(n)$の指数を表します$2$で$n$、つまり$$n = 2^{v_2(n)} \cdot m \quad (m \text{ odd}).$$私たちは次のように主張します:$$g(n)=v_2(n).$$私たちはこれを証明します。 

---

 ## ステップ 2: 動きの構造

 仮定してください$$n = 2^k m,\qquad m\text{ odd}.$$すべての適切な約数$d$の$n$次のように書くことができます$$d=2^t u,$$どこ$0\le t\le k$、$u\mid m$。 

新しいパイルのサイズは$$n-d.$$2 進数の評価のみを考慮します。 

---

 ### より小さいグランディ値の到達可能性

 どれでも取ってください$t<k$。 

選ぶ$$d = 2^t m.$$以来$t<k$、これはの適切な約数です$n$。 

それから$$n-d =2^k m-2^t m =2^t m(2^{k-t}-1).$$なぜなら$2^{k-t}-1$奇妙です、$$v_2(n-d)=t.$$それで、評価額の山から$k$、小さい評価ごとに$0,1,\dots,k-1$到達可能です。 

---

 ### 移動しないと評価が維持される$k$書く$$n=2^k m,\qquad d=2^t u.$$もし$t<k$、 それから$$n-d=2^t(\text{odd}),$$したがって、評価は正確に$t<k$。 

もし$t=k$、 それから$$d=2^k u,$$と$u\mid m$。 以来$u<m$適切な約数を求めるには、$$n-d = 2^k(m-u),$$そして$m-u$は偶数（奇数マイナス奇数）なので、$$v_2(n-d)\ge k+1.$$それで評価$k$それ自体は決して到達できません。 

したがって、到達可能なグランディ値は正確に次のようになります。$$\{0,1,\dots,k-1\}.$$したがって$$g(n)=\operatorname{mex}\{0,1,\dots,k-1\}=k.$$したがって、$$\boxed{g(n)=v_2(n)}.$$---

 #2. 負けポジションを数える

 定義する$$c_k = \#\{1\le x\le n : v_2(x)=k\}.$$これらは次で割り切れる整数です$2^k$しかし、それによってではありません$2^{k+1}$:$$c_k = \left\lfloor \frac{n}{2^k}\right\rfloor - \left\lfloor \frac{n}{2^{k+1}}\right\rfloor.$$トリプルは負けます$$v_2(a)\oplus v_2(b)\oplus v_2(c)=0.$$したがって、負けたトリプルの数は$$L = \sum_{i,j\ge0} c_i c_j c_{i\oplus j}.$$したがって$$S(n)=n^3-L.$$---

 #3. Pythonの実装```python
def S(n):
    # c[k] = count of numbers with v2(x) = k
    c = []
    k = 0

    while (1 << k) <= n:
        ck = n // (1 << k) - n // (1 << (k + 1))
        c.append(ck)
        k += 1

    # Count losing triples:
    # v2(a) xor v2(b) xor v2(c) = 0
    losing = 0

    for i, a in enumerate(c):
        for j, b in enumerate(c):
            x = i ^ j
            if x < len(c):
                losing += a * b * c[x]

    return n**3 - losing

# Check the examples
print(S(10))    # 692
print(S(100))   # 735494

# Required value
MOD = 1234567890
n = 123456787654321

print(S(n) % MOD)
```---

 #4. コードのチュートリアル

 ### カウントを構築する```python
ck = n // (1 << k) - n // (1 << (k + 1))
```正確な 2 進評価で整数をカウントします$k$。 

例:

 - で割り切れる$2^k$- しかし、それによってではありません$2^{k+1}$---

 ### 負けたトリプルを数える

 もし$$i \oplus j \oplus k = 0,$$それから$$k=i\oplus j.$$したがって、各ペアについて$(i,j)$、必要な 3 番目の評価は一意に決定されます。 

これらの評価額のトリプルの数は次のとおりです。$$c_i c_j c_{i\oplus j}.$$合計するとすべての負けポジションが得られます。 

---

 ### 最終結果

 すべてのトリプル:$$n^3.$$トリプル勝ち:$$S(n)=n^3-L.$$---

 #5. 検証

$$S(100)=735494.$$したがって、導出は一貫しています。
