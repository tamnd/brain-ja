 ## 解決策

 **答え:**`872187`すべての整数を求めます$n < 10^6$次のような:

 1.$n$は 10 進数の回文です。 
2. のバイナリ表現$n$も回文です。 
3. どちらの表現でも先頭のゼロは許可されません。 

次に、そのような数値をすべて合計します。 

---

 # 数学的分析

 回文は前から読んでも後ろから読んでも同じです。 

例えば：

-$585$10進数では次のようになります。$$585$$これは回文です。 
- バイナリの場合:$$585 = 1001001001_2$$これも回文です。 

100 万未満のそのような数値をすべて見つけなければなりません。 

## 主な所見

 ### 1. 10 進回文はまれです

 すべての数値をチェックするのではなく、$1$に$999999$、10 進回文のみを生成する方がはるかに高速です。 

6 桁の回文は次の形式になります。$$abc|cba$$5 桁の回文の形式は次のとおりです。$$ab|c|ba$$100 万未満の 10 進回文の数は少ないです。 

- 1桁：$9$- 2桁:$9$- 3桁:$90$- 4桁:$90$- 5桁:$900$- 6桁:$900$合計：$$9+9+90+90+900+900 = 1998$$したがって、100 万件の数値をチェックする代わりに、約 2,000 件のみをチェックします。 

---

 ### 2. 2 進回文は 0 で終わることはできません

 バイナリ回文の先頭にゼロを付けることはできません。 

2 進数が次で終わる場合$0$、そして、対称性により、それはまた次のように始まります。$0$、 不可能。 

したがって、すべての 2 進回文は奇数になります。 

したがって、有効な数値はすべて奇数でなければなりません。 

これにより、偶数 10 進回文がすべて即座に削除されます。 

---

 ### 3. 効率的な回文テスト

 文字列$s$次の場合は回文です。$$s = s[::-1]$$それで:

 - 10 進回文:```python
str(n) == str(n)[::-1]
```- バイナリ回文:```python
b = bin(n)[2:]
b == b[::-1]
```---

 # Pythonの実装```python
def is_palindrome(s):
    """Return True if string s is a palindrome."""
    return s == s[::-1]

total = 0

# Check every odd number below one million
for n in range(1, 1_000_000, 2):

    # Check decimal palindrome
    if is_palindrome(str(n)):

        # Convert to binary without '0b'
        b = bin(n)[2:]

        # Check binary palindrome
        if is_palindrome(b):
            total += n

print(total)
```---
