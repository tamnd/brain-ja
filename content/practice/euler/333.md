[プロジェクト オイラー問題 333](https://projecteuler.net/problem=333)

 ## 解決策

 **答え:**`3053105`項を指数ペアで表すとします$$(i,j)\quad\leftrightarrow\quad 2^i3^j.$$パーティションは、他の用語を分割する用語がない場合に有効です。 

2期分$$2^a3^b,\qquad 2^c3^d,$$我々は持っています$$2^a3^b \mid 2^c3^d \iff a\le c \text{ and } b\le d.$$したがって、有効なパーティションは、座標的に一致しない指数ペアのセットに正確に対応します。$\le$別の。 

同様に:

 - もし$i$-指数が増加し、
 - それから$j$-指数は厳密に減少する必要があります。 

したがって、すべての有効なパーティションをチェーンとして書き込むことができます。$$(i_1,j_1),(i_2,j_2),\dots,(i_k,j_k)$$と$$i_1<i_2<\cdots<i_k,\qquad j_1>j_2>\cdots>j_k.$$これにより、問題が構造化された組み合わせ検索に変換されます。 

---

 #1. 数学的分析

 必要なものは次のとおりです。$$\sum_{\substack{q<10^6\\ q\text{ prime}\\ P(q)=1}} q.$$---

 ## 指数の範囲

 以来$2^i3^j<10^6$、

 -$i\le 19$なぜなら$2^{20}>10^6$、
 -$j\le 12$なぜなら$3^{13}>10^6$。 

したがって、可能な基本用語はほとんどありません。 

---

 ## 動的プログラミングのアイデア

 ～の力を処理する$3$大きいものから$j$小さなものまで$j$。 

それぞれに$j$、私たちは次のことを行うことができます：

 - それは飛ばしてください$j$、または
 - 正確に 1 つ選択してください$i$以前に選択したすべてよりも大きい$i$。 

これにより、以下が自動的に適用されます。$$i_1<i_2<\cdots,\qquad j_1>j_2>\cdots,$$したがって、有効性。 

状態を維持します。$$(\text{largest chosen } i,\ \text{sum})$$そして、それぞれの合計が何通り起こるかを数えます。 

最後に:

 - 計算する$P(n)$、
 - ふるい素数、
 - すべての素数を合計します$P(q)=1$。

 #2. Pythonの実装```python
from collections import defaultdict

LIMIT = 10**6

# ------------------------------------------------------------
# Generate powers of 2 and 3
# ------------------------------------------------------------

pow2 = [1]
while pow2[-1] * 2 < LIMIT:
    pow2.append(pow2[-1] * 2)

pow3 = [1]
while pow3[-1] * 3 < LIMIT:
    pow3.append(pow3[-1] * 3)

I = len(pow2)
J = len(pow3)

# ------------------------------------------------------------
# DP states:
#
# states[k] is a dictionary:
#   sum -> number of valid partitions
#
# where the largest chosen i-exponent equals (k-1).
#
# k = 0 represents "no exponent chosen yet", i.e. last_i = -1.
# ------------------------------------------------------------

states = [defaultdict(int) for _ in range(I + 1)]
states[0][0] = 1

# Process j from large to small
for j in range(J - 1, -1, -1):

    new_states = [defaultdict(int) for _ in range(I + 1)]

    for idx, d in enumerate(states):

        last_i = idx - 1

        for current_sum, ways in d.items():

            # Option 1: skip this j
            new_states[idx][current_sum] += ways

            # Option 2: choose an i > last_i
            for new_i in range(last_i + 1, I):

                value = pow2[new_i] * pow3[j]
                new_sum = current_sum + value

                if new_sum < LIMIT:
                    new_states[new_i + 1][new_sum] += ways

    states = new_states

# ------------------------------------------------------------
# Collect P(n)
# ------------------------------------------------------------

P = [0] * LIMIT

for d in states:
    for s, cnt in d.items():
        P[s] += cnt

# Remove empty partition
P[0] -= 1

# ------------------------------------------------------------
# Prime sieve
# ------------------------------------------------------------

is_prime = bytearray(b"\x01") * LIMIT
is_prime[0:2] = b"\x00\x00"

for p in range(2, int(LIMIT**0.5) + 1):
    if is_prime[p]:
        is_prime[p*p:LIMIT:p] = b"\x00" * (
            ((LIMIT - 1 - p*p) // p) + 1
        )

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = sum(
    n for n in range(LIMIT)
    if is_prime[n] and P[n] == 1
)

print(answer)
```---

 ## DP 構造```python
states[k][s]
```意味:

 - 私たちは合計を形成しました$s$、
 - 使用される最大の指数$i$等しい$k-1$。 

処理$j$降順で将来の選択を保証します$j$の方が小さいです。 

選ぶだけ$i > \text{last}_i$保証が増える$i$さんの。 

したがって、可分性は発生しません。 

- -

＃＃ 遷移```python
# skip this j
new_states[idx][current_sum] += ways
```または```python
value = pow2[new_i] * pow3[j]
new_sum = current_sum + value
```用語を含めるには。 

- -

＃＃ 建物$P(n)$結局$j$が処理されます:```python
P[s] += cnt
```の有効なパーティションの数をカウントします。$s$。
