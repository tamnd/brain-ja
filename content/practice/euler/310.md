[プロジェクト オイラー問題 310](https://projecteuler.net/problem=310)

 ## 解決策

 **答え:**`2586528661783`させて$G(n)$ヒープのサイズの Sprague-Grundy (数値) 値になります。$n$**ニムスクエア**では、移動は石の平方数を取り除くことで構成されます。 

ポジション$(a,b,c)$負けてるなら$$G(a)\oplus G(b)\oplus G(c)=0,$$どこ$\oplus$はビット単位の XOR を示します。 

## 1. 数学的分析

 減算ゲーム (平方数の削除など) の場合、グランディ数は次の条件を満たします。$$G(0)=0,$$そしてのために$n\ge1$、$$G(n)=\operatorname{mex} \left( \{G(n-k^2)\mid k^2\le n\} \right),$$ここで、**mex** は、セットにない最小の非負の整数を意味します。 

そこで計算します$G(n)$みんなのために$0\le n\le100000$。 
### 重要な観察: 数値の頻度によるカウント
 しましょう$$f(x)=\#\{n\in[0,N]\mid G(n)=x\}.$$次に、**順序付けられた**トリプルの合計数$(a,b,c)$XORゼロを使用すると、$$T = \sum_{x,y} f(x)f(y)f(x\oplus y),$$なぜなら一度$G(a)=x$そして$G(b)=y$、3 番目の番号は次でなければなりません。$$G(c)=x\oplus y.$$しかし、問題はトリプルのみを必要とします$$a\le b\le c.$$順序付けられたトリプルをソートされたトリプルに変換します。 

させて：

-$E$= すべて等しいトリプル$(x,x,x)$-$P$= 正確に 2 つ等しい順序付きトリプル
 -$D$= すべてが異なる順序付けされたトリプル

 それから$$T=D+P+E.$$ソートされたトリプルは次のことに貢献します。 

-$6$順序付けされた順列がすべて異なる場合、
 -$3$正確に 2 つが等しい場合、
 -$1$すべてが等しい場合。 

したがって、ソートされた負けポジションの数は次のようになります。$$L = \frac{D}{6} + \frac{P}{3} + E.$$並べ替え:$$L = \frac{T+P+5E}{6}.$$### コンピューティング$P$そして$E$すべてが平等であるために：$$x\oplus x\oplus x=x,$$したがって、すべてが等しいトリプルで負けるのは数値の山だけです$0$:$$E=f(0).$$正確に 2 が等しい場合:$$x\oplus x\oplus y=y,$$したがって、シングルトンヒープには数値が必要です$0$。 

もし$M=N+1$がヒープ サイズの数である場合、次のようになります。$$P = 3\,f(0)(M-1),$$(因数 3 は、どの位置がシングルトンであるかを説明します)。 

例でメソッドを検証します$N=29$、取得:$$1160,$$問題文と一致します。 

## 2. Python の実装```python
import math

def nim_square_losing_positions(N):
    # All square moves
    squares = [i * i for i in range(1, int(math.isqrt(N)) + 1)]

    # Compute Grundy values
    grundy = [0] * (N + 1)
    max_g = 0

    for n in range(1, N + 1):
        seen = 0

        # Collect reachable Grundy values
        for s in squares:
            if s > n:
                break
            seen |= 1 << grundy[n - s]

        # mex(seen)
        mex = 0
        while (seen >> mex) & 1:
            mex += 1

        grundy[n] = mex
        max_g = max(max_g, mex)

    # Frequency of each Grundy value
    freq = [0] * (max_g + 1)
    for g in grundy:
        freq[g] += 1

    # Count ordered losing triples
    ordered_total = 0
    for x, fx in enumerate(freq):
        for y, fy in enumerate(freq):
            z = x ^ y
            if z <= max_g:
                ordered_total += fx * fy * freq[z]

    f0 = freq[0]
    M = N + 1

    # Exactly two equal
    P = 3 * f0 * (M - 1)

    # All equal
    E = f0

    # Convert ordered -> sorted
    losing_positions = (ordered_total + P + 5 * E) // 6

    return losing_positions

# Check the example
print(nim_square_losing_positions(29))      # 1160

# Solve the problem
print(nim_square_losing_positions(100000))
