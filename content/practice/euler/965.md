[プロジェクト オイラー問題 965](https://projecteuler.net/problem=965)

 ## 解決策

 **答え:**`0.0003452201133`させて$$f_N(x)=\min_{1\le n\le N}\{nx\}.$$一様ランダムの場合$x\in[0,1]$、$$F(N)=\mathbb E[f_N(x)].$$非負の確率変数の期待値を計算する標準的な方法は次のとおりです。$$F(N)=\int_0^1 \Pr(f_N(x)>t)\,dt.$$今、$$f_N(x)>t$$あらゆる人にとってそれを意味します$1\le n\le N$、$$\{nx\}>t.$$同様に、$x$すべての間隔を回避します$$\left[\frac{k}{n},\,\frac{k+t}{n}\right] \qquad (0\le k<n,\ 1\le n\le N).$$明らかになったギャップは、Farey 順序列の隣接する分数によって決定されます。$N$。 

もし$$\frac ab < \frac cd$$は隣接するファレイ分数である場合、$$bc-ad=1,$$そして、露出したギャップが貢献します$$\max\!\left(0,\frac1{bd}-\frac{t}{b}\right).$$これはまさに存続します$0\le t\le 1/d$。 

統合中$t$、$$\int_0^{1/d}\left(\frac1{bd}-\frac{t}{b}\right)\,dt = \frac1{2bd^2}.$$したがって、$$F(N)=\sum_{\text{adjacent } a/b<c/d \text{ in Farey}(N)} \frac1{2bd^2}.$$これは、Farey シーケンスの標準的な反復生成を使用して効率的に計算できます。 

Python コード:```python
from decimal import Decimal, getcontext

getcontext().prec = 50

N = 10000

# Farey sequence generation
a, b, c, d = 0, 1, 1, N

ans = Decimal(0)

while c <= N:
    ans += Decimal(1) / (Decimal(2) * b * d * d)

    k = (N + b) // d
    a, b, c, d = c, d, k * c - a, k * d - b

print(ans)
```これにより、$$F(10^4)=0.0003452201133312345\ldots$$小数点以下 13 桁に四捨五入します。
