[プロジェクト オイラー問題 199](https://projecteuler.net/problem=199)

 ## 解決策

 **答え:**`0.00396087`この問題に対する重要なツールは **デカルトの円定理** です。 

互いに接する4つの円に曲率（曲がり）がある場合$$k_i=\frac1{r_i}$$(囲む円に **負**の曲率を与えた場合)、次のようになります。$(k_1+k_2+k_3+k_4)^2 = 2(k_1^2+k_2^2+k_3^2+k_4^2)$4 番目の曲率を解くと次のようになります。$$k_4 = k_1+k_2+k_3 \pm 2\sqrt{k_1k_2+k_2k_3+k_3k_1}.$$ギャップを埋める円には、**プラス** 記号を使用します。 

---

 #1. ジオメトリのセットアップ

 最初の 3 つの等しい円に半径を持たせる$1$したがって、それらの曲率は次のようになります。$$k=1.$$外側を囲む円は負の曲率を持っています$k_0$。 

相互に接する 4 つの円にデカルトを適用する:$$(k_0+1+1+1)^2 = 2(k_0^2+1+1+1).$$簡略化:$$(k_0+3)^2 = 2(k_0^2+3)$$

$$k_0^2-6k_0-3=0$$

$$k_0 = 3\pm2\sqrt3.$$囲む円は負の曲率を持つ必要があるため、$$k_0 = 3-2\sqrt3 = -(2\sqrt3-3).$$したがって、その半径は$$R=\frac1{2\sqrt3-3}.$$したがって、総面積は次のようになります。$$A_{\text{outer}}=\pi R^2.$$最初にカバーされるエリア:$$3\pi.$$---

 #2. 再帰的なギャップ埋め

 各ギャップは、曲率を持つ 3 つの相互に接する円によって決定されます。$(a,b,c)$。 

その隙間に収まる最大の円の曲率は次のようになります。$$d=a+b+c+2\sqrt{ab+bc+ca}.$$その新しい円には面積があります$$\frac{\pi}{d^2}.$$挿入すると、ギャップは 3 つの小さなギャップに分割されます。$$(a,b,d),\quad (a,c,d),\quad (b,c,d).$$したがって、それらを再帰的に処理します。 

---

 #3. 初期ギャップ

 初期ギャップは 4 つあります。 

- 中央ギャップ 1 つ:$(1,1,1)$- 外側のギャップ 3 つ:$(-(2\sqrt3-3),1,1)$10 回繰り返して再帰します。 

---

 #4. Pythonの実装```python
from math import sqrt, pi

# Curvature magnitude of enclosing circle
k0 = 2 * sqrt(3) - 3

# Total area of enclosing circle
A_outer = pi / (k0 ** 2)

def added_area(a, b, c, depth):
    """
    Total area added by recursively filling the gap
    determined by circles with curvatures a,b,c.
    """

    if depth == 0:
        return 0.0

    # Descartes theorem (new circle curvature)
    d = a + b + c + 2 * sqrt(a*b + b*c + c*a)

    # Area of newly inserted circle
    area = pi / (d ** 2)

    # Recurse into the 3 new gaps
    area += added_area(a, b, d, depth - 1)
    area += added_area(a, c, d, depth - 1)
    area += added_area(b, c, d, depth - 1)

    return area

# Initial three circles
covered = 3 * pi

# Fill the central gap
covered += added_area(1, 1, 1, 10)

# Fill the three outer gaps
covered += 3 * added_area(-k0, 1, 1, 10)

# Fraction not covered
fraction_uncovered = 1 - covered / A_outer

print(f"{fraction_uncovered:.8f}")
```---
