[プロジェクト オイラー問題 377](https://projecteuler.net/problem=377)

 ## 解決策

 **答え:**`732385277`させて

-$c(n)$= ゼロ桁を含まない正の整数の数と桁の合計$n$、
 -$f(n)$= そのような整数すべての合計。 

私たちは求められています$$\sum_{i=1}^{17} f(13^i) \pmod{10^9}.$$---

 #1. 数学的分析

 ゼロ桁と桁の合計を含まない数値$n$は正確に次の数字のシーケンスです$\{1,\dots,9\}$合計は誰の$n$。 

したがって、問題は基本的に次の構成に関するものです。$n$パーツを使って$1$–$9$。 

---

 ## シーケンスのカウント: の繰り返し$c(n)$桁の合計に有効なすべての数値$n$何らかの数字で終わる$d\in\{1,\dots,9\}$。 

最後の桁を削除すると、有効な桁数の合計が残ります。$n-d$。 

したがって、$$c(n)=\sum_{d=1}^{9} c(n-d),$$初期条件あり$$c(0)=1,\qquad c(n)=0\text{ for }n<0.$$小さい値の場合:$$c(1)=1,\; c(2)=2,\; c(3)=4,\; c(4)=8,\; c(5)=16,$$これは、次のステートメントと一致します。$16$桁の和のような数値$5$。 

---

 ## の繰り返し$f(n)$仮定する$x$桁の合計を持つ有効な数値です$n-d$。 

数字の追加$d$生成する$$10x+d.$$すべての可能性を合計すると、次のようになります。$$f(n)=\sum_{d=1}^{9} \left( 10f(n-d)+d\,c(n-d) \right).$$並べ替え:$$f(n) = 10\sum_{d=1}^{9} f(n-d) + \sum_{d=1}^{9} d\,c(n-d).$$させる$k=n-d$、$$f(n) = 10\sum_{k=n-9}^{n-1} f(k) + \sum_{k=n-9}^{n-1} (n-k)c(k).$$これは順序の線形回帰です$9$。 

---

 ## 例の検証$n=5$繰り返しを使用すると、次のようになります。$$f(5) = 10(f(4)+f(3)+f(2)+f(1)+f(0)) + (1c(4)+2c(3)+3c(2)+4c(1)+5c(0)).$$使用する$$f(0)=0,\quad f(1)=1,\quad f(2)=13,\quad f(3)=147,\quad f(4)=1625,$$そして$$c(0)=1,\; c(1)=1,\; c(2)=2,\; c(3)=4,\; c(4)=8,$$私たちは得ます$$f(5)=17891,$$まさに与えられたとおりです。 

---

 #2. マトリックスの定式化

 なぜなら$13^{17}$が巨大なため、直接DPは不可能です。 

行列のべき乗を使用します。 

状態ベクトルを定義する$$V(n)= \begin{bmatrix} f(n)\\ f(n-1)\\ \vdots\\ f(n-8)\\ c(n)\\ c(n-1)\\ \vdots\\ c(n-8) \end{bmatrix}.$$これは$18$-次元ベクトル。 

再発は線形であるため、$18\times18$マトリックス$M$そのような$$V(n+1)=MV(n).$$それから$$V(N)=M^{N-8}V(8).$$2進累乗はこれを計算します$O(\log N)$。 

すべての計算はモジュロで実行されます$10^9$。 

---

 #3. Pythonの実装```python
MOD = 10**9

# ------------------------------------------------------------
# Build initial values c(n), f(n) for n = 0..8
# ------------------------------------------------------------

c = [0] * 9
f = [0] * 9

c[0] = 1

# c(n) recurrence
for n in range(1, 9):
    c[n] = sum(c[max(0, n - 9):n])

# f(n) recurrence
for n in range(1, 9):
    total = 0

    for d in range(1, 10):
        if n - d >= 0:
            total += 10 * f[n - d] + d * c[n - d]

    f[n] = total

# ------------------------------------------------------------
# Build the 18x18 transition matrix
# ------------------------------------------------------------

SIZE = 18

M = [[0] * SIZE for _ in range(SIZE)]

# First row: recurrence for f(n+1)
for j in range(9):
    M[0][j] = 10
    M[0][9 + j] = 9 - j

# Shift rows for f
for i in range(1, 9):
    M[i][i - 1] = 1

# Recurrence for c(n+1)
for j in range(9):
    M[9][9 + j] = 1

# Shift rows for c
for i in range(10, 18):
    M[i][i - 1] = 1

# ------------------------------------------------------------
# Matrix multiplication
# ------------------------------------------------------------

def mat_mul(A, B):
    C = [[0] * SIZE for _ in range(SIZE)]

    for i in range(SIZE):
        for k in range(SIZE):
            if A[i][k]:
                aik = A[i][k]

                for j in range(SIZE):
                    C[i][j] = (C[i][j] + aik * B[k][j]) % MOD

    return C

# ------------------------------------------------------------
# Matrix exponentiation
# ------------------------------------------------------------

def mat_pow(M, e):
    # Identity matrix
    R = [[0] * SIZE for _ in range(SIZE)]

    for i in range(SIZE):
        R[i][i] = 1

    A = M

    while e > 0:
        if e & 1:
            R = mat_mul(R, A)

        A = mat_mul(A, A)
        e >>= 1

    return R

# ------------------------------------------------------------
# Multiply matrix by vector
# ------------------------------------------------------------

def mat_vec_mul(A, v):
    out = [0] * SIZE

    for i in range(SIZE):
        s = 0

        for j in range(SIZE):
            s += A[i][j] * v[j]

        out[i] = s % MOD

    return out

# ------------------------------------------------------------
# Initial state V(8)
# ------------------------------------------------------------

state = (
    f[8::-1] +   # f(8),...,f(0)
    c[8::-1]     # c(8),...,c(0)
)

# ------------------------------------------------------------
# Compute f(N)
# ------------------------------------------------------------

def F(N):
    if N <= 8:
        return f[N]

    P = mat_pow(M, N - 8)
    result = mat_vec_mul(P, state)

    return result[0]

# ------------------------------------------------------------
# Final summation
# ------------------------------------------------------------

answer = 0

for i in range(1, 18):
    answer = (answer + F(13**i)) % MOD

print(answer)
```---
