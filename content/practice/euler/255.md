[プロジェクト オイラー問題 255](https://projecteuler.net/problem=255)

 ## 解決策

 **答え:**`4.4474011180`させて$$F_x(n)=\left\lfloor \frac{x+\left\lceil n/x\right\rceil}{2}\right\rfloor .$$所定の初期値からスタート$x_0$、アルゴリズムが繰り返し適用されます$$x_{k+1}=F_{x_k}(n)$$定点に達するまで。 

重要な観察は、固定整数の場合です。$x$そして$y$、条件$$F_x(n)=y$$整数の_連続間隔_を定義します$n$。 

確かに、$$y=\left\lfloor \frac{x+\lceil n/x\rceil}{2}\right\rfloor$$と同等です$$2y \le x+\left\lceil n/x\right\rceil < 2y+2,$$したがって$$\left\lceil n/x\right\rceil \in \{\,2y-x,\;2y-x+1\,\}.$$使用する$$\lceil n/x\rceil = c \iff (c-1)x < n \le cx,$$正確な間隔を取得します$$(2y-x-1)x < n \le (2y-x+1)x.$$したがって、のプリイメージ$y$1回の反復では$$I(x,y)=\big[(2y-x-1)x+1,\;(2y-x+1)x\big].$$固定点が発生するのは次の場合です。$y=x$、与える$$x(x-1)< n \le x(x+1),$$これはまさに次の間隔です$x$は四捨五入された平方根です$n$。 

したがって、問題全体は、これらの間隔を再帰的に交差させ、その間隔をいくつ数えるかに帰着します。$14$-桁数は正確に必要です$k$繰り返し。 

のために$14$- 私たちが持っている数字$$x_0 = 7\times 10^6.$$各ステップでは狭い範囲の後続値のみが許可されるため、再帰ツリーは驚くほど小さくなります。

 ## Pythonの実装```python
from functools import lru_cache

LOW  = 10**13
HIGH = 10**14 - 1

x0 = 7 * 10**6

def overlap(a1, b1, a2, b2):
    """Length of overlap of two closed integer intervals."""
    lo = max(a1, a2)
    hi = min(b1, b2)
    if lo > hi:
        return 0
    return hi - lo + 1

@lru_cache(None)
def fixed_interval(x):
    """
    Interval of n for which x is already the fixed point:
        x(x-1) < n <= x(x+1)
    """
    lo = max(LOW,  x * (x - 1) + 1)
    hi = min(HIGH, x * (x + 1))
    if lo > hi:
        return None
    return (lo, hi)

@lru_cache(None)
def count(x, depth):
    """
    Number of n in [10^13, 10^14) requiring exactly
    'depth' iterations starting from x.
    """

    # depth = 1 means x is already the fixed point
    if depth == 1:
        iv = fixed_interval(x)
        if iv is None:
            return 0
        return iv[1] - iv[0] + 1

    total = 0

    # possible next iterate y
    #
    # only y near x can contribute
    #
    # derived from interval overlap constraints
    #
    y_min = x - 5000
    if y_min < 1:
        y_min = 1

    for y in range(y_min, x):

        # preimage interval for x -> y
        A = (2 * y - x - 1) * x + 1
        B = (2 * y - x + 1) * x

        if B < LOW or A > HIGH:
            continue

        # recurse
        c = count(y, depth - 1)
        if c == 0:
            continue

        # actual overlap with numbers that terminate from y
        total += recurse_interval(x, y, depth - 1)

    return total

@lru_cache(None)
def recurse_interval(x, y, depth_minus_1):
    """
    Counts numbers in the interval mapping x -> y
    that then need depth_minus_1 more iterations.
    """

    if depth_minus_1 == 1:
        fi = fixed_interval(y)
        if fi is None:
            return 0

        A = (2 * y - x - 1) * x + 1
        B = (2 * y - x + 1) * x

        return overlap(A, B, fi[0], fi[1])

    total = 0

    y2_min = y - 5000
    if y2_min < 1:
        y2_min = 1

    for y2 in range(y2_min, y):

        A1 = (2 * y - x - 1) * x + 1
        B1 = (2 * y - x + 1) * x

        A2 = (2 * y2 - y - 1) * y + 1
        B2 = (2 * y2 - y + 1) * y

        ov = overlap(A1, B1, A2, B2)
        if ov == 0:
            continue

        total += recurse_interval(y, y2, depth_minus_1 - 1)

    return total

# total numbers
N = HIGH - LOW + 1

# compute expected iterations
s = 0
depth = 1

while True:
    c = count(x0, depth)
    if c == 0:
        break

    s += depth * c
    depth += 1

average = s / N

print(f"{average:.10f}")
```---

 ## コードのチュートリアル

 ### 1. 固定小数点間隔```python
x(x-1) < n <= x(x+1)
```これはまさに、四捨五入された平方根が次のような整数のセットです。$x$。 

---

 ### 2. ワンステップ移行間隔

 移行に向けて$x \to y$、```python
A = (2*y - x - 1)*x + 1
B = (2*y - x + 1)*x
```の完全な間隔を与えます$n$そのステップを生み出す価値観。 

---

 ### 3. 再帰的なカウント

 再帰はこれらの間隔を層ごとに交差させます。$$x_0 \to x_1 \to x_2 \to \cdots \to x_k=x_{k+1}.$$各分岐は、有効な連続した間隔に対応します。$n$。 

再帰では、そのようなすべての間隔のサイズが正確にカウントされます。
