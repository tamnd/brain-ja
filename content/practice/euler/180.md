 ## 解決策

 **答え:**`285196020571078987`私たちはすべての有理トリプルを求めます$(x,y,z)$と$$0<x,y,z<1,\qquad x,y,z\in \left\{\frac ab:0<a<b\le 35\right\},$$ある整数に対して$n$、$$f_n(x,y,z)=0.$$重要なのは、代数構造を単純化することです。$f_n$。 

---

 #1. 数学的分析

 私たちは与えられています$$\begin{aligned} f_{1,n}&=x^{n+1}+y^{n+1}-z^{n+1},\\ f_{2,n}&=(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1}),\\ f_{3,n}&=xyz(x^{n-2}+y^{n-2}-z^{n-2}), \end{aligned}$$そして$$f_n=f_{1,n}+f_{2,n}-f_{3,n}.$$まずこの式を因数分解します。 

## 1.1 展開$f_n$拡大する：$$\begin{aligned} f_n &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +(xy+yz+zx)(x^{n-1}+y^{n-1}-z^{n-1})\\ &\quad -xyz(x^{n-2}+y^{n-2}-z^{n-2}). \end{aligned}$$次の権限を含むグループ用語$x$:$$x^{n-1}(x^2+xy+xz-yz).$$しかし$$x^2+xy+xz-yz=(x+y)(x+z)-2yz.$$より明確な方法は、それを直接確認することです。$$f_n=(x+y-z)(x^n+y^n-z^n).$$確かに、$$\begin{aligned} (x+y-z)(x^n+y^n-z^n) &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy^n+yx^n-xz^n-zx^n\\ &\quad +xz^n+zy^n-zx^n-zy^n\\ &=x^{n+1}+y^{n+1}-z^{n+1}\\ &\quad +xy(x^{n-1}+y^{n-1})\\ &\quad +xz(x^{n-1}-z^{n-1})\\ &\quad +yz(y^{n-1}-z^{n-1}), \end{aligned}$$これは再グループ化後に正確に一致します。 

したがって、$$\boxed{f_n(x,y,z)=(x+y-z)(x^n+y^n-z^n).}$$したがって、ゴールデントリプルは次のいずれかを満たします

 1.$x+y=z$、または
 2.$x^n+y^n=z^n$。 

ある整数に対して$n$。 

---

 # 1.2 どの指数が重要ですか?

 なぜなら$0<x,y,z<1$合理的です:

 - のために$n=1$:$$x+y=z.$$- のために$n=2$:$$x^2+y^2=z^2.$$有理ピタゴラス三重が発生します。 
- のために$n\ge 3$:

 フェルマーの最終定理によれば、ゼロ以外の有理解は存在しません。 
- のために$n=0$:$$x^0+y^0=z^0 \implies 1+1=1,$$不可能。 
- のために$n=-1$:$$\frac1x+\frac1y=\frac1z.$$同様に、$$z=\frac{xy}{x+y}.$$- のために$n=-2$:$$\frac1{x^2}+\frac1{y^2}=\frac1{z^2},$$別のピタゴラス型の状態。 
- のために$n\le -3$:

 書き換えると得られる$$\left(\frac1x\right)^m+\left(\frac1y\right)^m =\left(\frac1z\right)^m,$$これもFLTでは不可能です。 

したがって、存在するケースは 4 つだけです。$$n\in\{1,2,-1,-2\}.$$---

 # 1.3 有効なトリプルをすべて列挙する

 しましょう$$S=\left\{\frac ab:0<a<b\le 35,\ \gcd(a,b)=1\right\}.$$すべての個別の値が必要です$$s=x+y+z$$次のいずれかを満たしているトリプルから来ています:

 1.$x+y=z$2.$x^2+y^2=z^2$3.$1/x+1/y=1/z$4.$1/x^2+1/y^2=1/z^2$と$x,y,z\in S$。 

最後にすべての個別の値を合計します$s$。 

---

 # 1.4 合理的なパラメータ化

 2 つの二次方程式は、有理ピタゴラス 3 倍体によってパラメータ化されます。 

もし$$a^2+b^2=c^2,$$それから$$(a,b,c)=k(m^2-n^2,2mn,m^2+n^2).$$したがって:

 - ケース$n=2$:

 内部の有理ピタゴラス トリプルを選択する$(0,1)$。 
- 場合$n=-2$:

 このようなトリプルの逆数。 

計算は有限であり、分母を使用したフェレイ分数に対する総当たり攻撃に十分な小ささです。$\le 35$。

 #2. Pythonの実装```python
from fractions import Fraction
from math import gcd, isqrt

K = 35

# ------------------------------------------------------------
# Generate all reduced fractions a/b with 0 < a < b <= K
# ------------------------------------------------------------

vals = set()

for b in range(2, K + 1):
    for a in range(1, b):
        if gcd(a, b) == 1:
            vals.add(Fraction(a, b))

vals = sorted(vals)

# ------------------------------------------------------------
# Collect all distinct sums s = x + y + z
# ------------------------------------------------------------

sums = set()

for x in vals:
    for y in vals:

        # ----------------------------------------------------
        # Case n = 1 : x + y = z
        # ----------------------------------------------------
        z = x + y
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -1 : 1/x + 1/y = 1/z
        # z = xy / (x + y)
        # ----------------------------------------------------
        z = x * y / (x + y)
        if z in vals:
            sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = 2 : x^2 + y^2 = z^2
        # ----------------------------------------------------
        z2 = x * x + y * y

        num = z2.numerator
        den = z2.denominator

        sn = isqrt(num)
        sd = isqrt(den)

        if sn * sn == num and sd * sd == den:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

        # ----------------------------------------------------
        # Case n = -2 :
        # 1/x^2 + 1/y^2 = 1/z^2
        # ----------------------------------------------------
        inv2 = Fraction(1, x * x) + Fraction(1, y * y)

        num = inv2.numerator
        den = inv2.denominator

        sn = isqrt(den)
        sd = isqrt(num)

        if sn * sn == den and sd * sd == num:
            z = Fraction(sn, sd)
            if z in vals:
                sums.add(x + y + z)

# ------------------------------------------------------------
# Sum all distinct s-values
# ------------------------------------------------------------

total = sum(sums, Fraction(0, 1))

print(total)
print(total.numerator + total.denominator)
```---
