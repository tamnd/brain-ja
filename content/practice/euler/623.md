[プロジェクト オイラー問題 623](https://projecteuler.net/problem=623)

 ## 解決策

 **答え:**`3679796`させて$T_m(n)$の数になります$\alpha$-**正確**サイズのラムダ項の同値クラス$n$その自由変数は$m$利用可能なバインダー。 

すると、必要な量は、$$\Lambda(n)=\sum_{k\le n} T_0(k).$$重要な観察は、モジュロを数えることです。$\alpha$-equivalence は、**de Bruijn インデックス作成** とまったく同じです。実際の変数名ではなく、_バインディング構造_ のみが重要です。 

---

 #1. 数学的分析

 ## サイズモデル

 例から:

 - 変数$x$サイズがあります$1$。 
- 応用$(MN)$2 つの括弧を追加します。$$|(MN)| = |M|+|N|+2.$$- 抽象化$(\lambda x.M)$貢献します:
 - 左括弧
 -$\lambda$- 変数
 - ドット
 - 右括弧

 それで$$|(\lambda x.M)| = |M|+5.$$チェック：$$|(\lambda x.x)| = 5+1 = 6,$$ステートメントと一致します。 

---

 ## 再帰的分解

 によって数えられる用語$T_m(n)$次のいずれかです:

 ### 1. 変数

 まさにあります$m$可能な自由変数。 

それで：$$T_m(1)=m.$$---

 ### 2. アプリケーション

 用語$(AB)$サイズがあります$$|A|+|B|+2=n.$$したがって、次のようになります。$$\sum_{i=1}^{n-3} T_m(i)\,T_m(n-2-i).$$---

 ### 3. 抽象化

 用語$(\lambda x.M)$サイズがあります$$|M|+5=n.$$抽象化の内部では、利用可能な変数がもう 1 つ得られるため、次のようになります。$$T_{m+1}(n-5).$$---

 すべてを組み合わせると:$$\boxed{ T_m(n)= \begin{cases} m,& n=1,\\[1ex] T_{m+1}(n-5)+ \displaystyle\sum_{i=1}^{n-3}T_m(i)T_m(n-2-i), & n\ge2. \end{cases} }$$ついに、$$\boxed{ \Lambda(N)=\sum_{n=0}^{N} T_0(n). }$$---

 #2. Pythonの実装```python
MOD = 1_000_000_007
N = 2000

# Maximum possible abstraction depth.
# Every abstraction costs 5 symbols.
MAX_M = N // 5 + 5

# dp[m][n] = number of alpha-equivalence classes
# of exact size n with free variables among m binders
dp = [[0] * (N + 1) for _ in range(MAX_M + 2)]

# Compute from large m downward because dp[m]
# depends on dp[m+1]
for m in range(MAX_M, -1, -1):

    # Variable terms
    dp[m][1] = m

    # Larger sizes
    for n in range(2, N + 1):

        total = 0

        # Abstraction contribution
        if n >= 5:
            total += dp[m + 1][n - 5]

        # Application contribution
        # (A B) has size |A| + |B| + 2
        for left_size in range(1, n - 2):
            right_size = n - 2 - left_size
            total += dp[m][left_size] * dp[m][right_size]

        dp[m][n] = total % MOD

# Lambda(N) = cumulative count of closed terms
answer = sum(dp[0][:N + 1]) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## テーブル定義```python
dp[m][n]
```正確なサイズの項の数を格納します$n$せいぜい$m$アクセス可能なバインダー。 

---

 ## 変数の場合```python
dp[m][1] = m
```変数は次のいずれかになります。$m$バインドされた変数。 

---

 ## 抽象化の場合```python
total += dp[m + 1][n - 5]
```抽象化は 5 つのシンボルを消費し、追加のバインダーが 1 つ導入されます。 

---

 ## アプリケーションケース```python
for left_size in range(1, n - 2):
```アプリケーションは括弧を 2 つ提供するため、$$|A|+|B| = n-2.$$各ペアが貢献します$$T_m(|A|)\cdot T_m(|B|).$$---

 ## 最終累積```python
answer = sum(dp[0][:N + 1]) % MOD
```閉じた項は、まさに最初に利用可能な自由変数を持たない項です。$m=0$。
