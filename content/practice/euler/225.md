[プロジェクト オイラー問題 225](https://projecteuler.net/problem=225)

 ## 解決策

 **答え:**`2009`させて$$T_1=T_2=T_3=1,\qquad  T_n=T_{n-1}+T_{n-2}+T_{n-3}.$$これはトリボナッチ数列です。$$1,1,1,3,5,9,17,31,57,105,\dots$$私たちが求めているのは、$124^\text{th}$奇数の整数$m$数列の**どの項**も次の条件で割り切れないようにします。$m$。 

---

 #1. 数学的分析

 シーケンスのモジュロのみを考慮します$m$。 

状態ベクトルを定義する$$S_n=(T_n,T_{n+1},T_{n+2}) \pmod m.$$なぜなら$$T_{n+3}=T_{n+2}+T_{n+1}+T_n,$$次の状態は現在の状態によって完全に決定されます。$$(a,b,c)\mapsto (b,c,a+b+c \bmod m).$$したがって、シーケンスモジュロ$m$は決定論的な有限状態プロセスです。 

しかないので、$m^3$可能なトリプルモジュロ$m$、最終的にはシーケンスを繰り返す必要があります。 実際、変換は可逆モジュロであるため、$m$、シーケンスは純粋に周期的です。 

したがって:

 - いくつかの用語はいずれかになります$0 \pmod m$、
 - または、ヒットすることなくシーケンスが永遠に循環します$0$。 

したがって、候補の奇数をテストするには$m$、単純にトリボナッチ値を法的に生成します。$m$その状態が繰り返されるまで。 

反復の前にゼロ項に遭遇すると、$m$トリボナッチ数を除算します。 

ゼロが表示されずにサイクルが終了した場合、$m$は希望する数値の 1 つです。 

問題文からは次のことがわかります。$$27$$は、このプロパティの最初の奇数です。 

が見つかるまでこのプロセスを続けます。$124^\text{th}$そんな奇数。

 #2. Pythonの実装```python
def tribonacci_has_zero_mod(m):
    """
    Return True if some Tribonacci number is divisible by m.
    Return False otherwise.
    """

    # Initial Tribonacci values modulo m
    a = b = c = 1 % m

    seen = set()

    while (a, b, c) not in seen:

        # If any current term is 0 mod m,
        # then m divides a Tribonacci number
        if a == 0 or b == 0 or c == 0:
            return True

        seen.add((a, b, c))

        # Advance recurrence:
        # T_{n+3} = T_n + T_{n+1} + T_{n+2}
        a, b, c = b, c, (a + b + c) % m

    # Cycle closed without seeing 0
    return False

target = 124
count = 0
n = 1

while True:

    if n % 2 == 1:  # odd numbers only

        if not tribonacci_has_zero_mod(n):
            count += 1

            if count == target:
                print(n)
                break

    n += 2
```---
