[プロジェクト オイラー問題 407](https://projecteuler.net/problem=407)

 ## 解決策

 **答え:**`39782849136421`整数の場合$a$、合同$$a^2 \equiv a \pmod n$$手段$$a(a-1)\equiv 0 \pmod n.$$重要な観察は次のとおりです$a$そして$a-1$は互いに素であるため、次のすべての素数べき約数は$n$そのうちの**ちょうど1つ**を分割する必要があります。 

---

 #1. 数学的分析

 私たちは求めています$$M(n)=\max\{a<n : a^2\equiv a \pmod n\}.$$計算しなければなりません$$\sum_{n=1}^{10^7} M(n).$$---

 ## ステップ 1 — すべてのソリューションの構造

 しましょう$$n=\prod_{i=1}^k p_i^{e_i}.$$なぜなら$$a(a-1)\equiv 0 \pmod{p_i^{e_i}},$$そして$\gcd(a,a-1)=1$、各素数パワーに対して次のものが必要です。$$a\equiv 0 \pmod{p_i^{e_i}} \quad\text{or}\quad a\equiv 1 \pmod{p_i^{e_i}}.$$したがって、すべてのソリューションは、各素力率に対して独立して、次のいずれかを選択することに対応します。$0$または$1$。 

中国の剰余定理によれば、正確には次のとおりです。$$2^{\omega(n)}$$解決策、どこで$\omega(n)$は個別の素因数の数です。 

---

 ## ステップ 2 — 素因数で書き直す

 ～の主権を分割する$n$2 つの互いに素な部分に分割します。$$n = uv,\qquad \gcd(u,v)=1.$$次に、対応する冪等は満たされます。$$a\equiv 0\pmod u, \qquad a\equiv 1\pmod v.$$書く$a=uk$。 それから$$uk\equiv 1\pmod v.$$それで$$k\equiv u^{-1}\pmod v.$$したがって、一意の解モジュロ$n$は$$a=u\cdot u^{-1}\pmod v.$$すべての冪等はこのようにして生じます。 

したがって$$M(n)=\max_{uv=n,\ \gcd(u,v)=1} \left(u\cdot u^{-1}\pmod v\right).$$---

 ## ステップ 3 — 効率的な計算

 すべてに対するブルートフォース因数分解$n\le10^7$遅すぎます。 

代わりに:

 1. 最小の素因数ふるいを作成します。 
2. それぞれの異なる素因数を回復する$n$。 
3. 個別の素数べき乗のすべてのサブセットを生成します。 
4. 各共素分割について$n=uv$:

 - モジュラー逆関数を計算します$u^{-1}\pmod v$、
 - 冪等を構築し、
 - 最大化します。 

なぜなら$10^7$異なる素因数が最大 8 つあるため、サブセットの列挙は小さいです。 

全体の複雑さは本質的に線形ふるいスケールです。

 #2. Pythonの実装```python
from math import prod

LIMIT = 10_000_000

# ---------------------------------------------------------
# Smallest prime factor sieve
# ---------------------------------------------------------
spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ---------------------------------------------------------
# Extended Euclidean algorithm
# ---------------------------------------------------------
def invmod(a, m):
    """Return inverse of a modulo m."""
    x0, x1 = 1, 0
    b = m

    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1

    return x0 % m

# ---------------------------------------------------------
# Factorization into prime powers
# Example:
#   12 -> [4, 3]
#   72 -> [8, 9]
# ---------------------------------------------------------
def prime_powers(n):
    res = []

    while n > 1:
        p = spf[n]
        pp = 1

        while n % p == 0:
            n //= p
            pp *= p

        res.append(pp)

    return res

# ---------------------------------------------------------
# Compute M(n)
# ---------------------------------------------------------
def M(n):
    if n == 1:
        return 0

    pp = prime_powers(n)
    k = len(pp)

    best = 1

    # Enumerate all subset products u
    for mask in range(1 << k):
        u = 1

        for i in range(k):
            if mask & (1 << i):
                u *= pp[i]

        v = n // u

        # trivial solutions 0 and 1
        if v == 1 or u == 1:
            continue

        # Solve:
        #   a ≡ 0 (mod u)
        #   a ≡ 1 (mod v)
        inv = invmod(u % v, v)

        a = u * inv

        if a > best:
            best = a

    return best

# ---------------------------------------------------------
# Main summation
# ---------------------------------------------------------
ans = 0

for n in range(1, LIMIT + 1):
    ans += M(n)

print(ans)
```---

 ## CRT 選択肢の列挙

 各主要パワーは次のいずれかに属することができます。 

- 除算係数$a$、
 - または除算係数$a-1$。 

したがって、すべてのサブセット製品を列挙します$u$。 

それから：$$v = n/u.$$以来$u$そして$v$互いに素である、私たちは解決します$$a \equiv 0 \pmod u, \qquad a \equiv 1 \pmod v.$$書き込み$a=uk$:$$uk \equiv 1 \pmod v$$それで$$k = u^{-1}\pmod v.$$したがって```python
a = u * invmod(u % v, v)
```それが CRT ソリューションです。

 #4. 小さな例の検証

 のために$n=6$:

 主な権限は次のとおりです。$$6=2\cdot3.$$考えられる CRT の選択肢:

 |$a \bmod 2$|$a \bmod 3$| ソリューション |
 | --- | --- | --- |
 | 0 | 0 | 0 |
 | 1 | 1 | 1 |
 | 0 | 1 | 4 |
 | 1 | 0 | 3 |

 最大のものは次のとおりです。$$M(6)=4.$$ステートメントと一致します。

 #5. 最終検証

 -$M(p)=1$素数用$p$、だけなので$0,1$は素数を法として冪等である。 
- 複数の異なる素因数を持つ合成数は、多くの場合、次のような大きな非自明な冪等を持ちます。$n$。 
- したがって、合計額は次のようになります。$10^7 \times 10^7 = 10^{14}$、計算結果の大きさと一致します。 

計算により次の結果が得られます。$$\sum_{n=1}^{10^7} M(n) = 39782849136421.$$**答え: 39782849136421**
