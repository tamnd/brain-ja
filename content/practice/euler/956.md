[プロジェクト オイラー問題 956](https://projecteuler.net/problem=956)

 ## 解決策

 **答え:**`882086212`させて$$F(n,m)=D(n,m)=\sum_{\substack{d\mid n\\ m\mid \Omega(d)}} d.$$のために$$n=\prod p_i^{e_i},$$生成関数$$\prod_i (1+p_i x+p_i^2x^2+\cdots+p_i^{e_i}x^{e_i})$$の係数があります$x^k$約数の合計に等しい$d\mid n$と$\Omega(d)=k$。 

したがって、$D(n,m)$インデックスが次で割り切れる係数の合計です。$m$。 

統一根フィルターを使用すると、$$D(n,m)=\frac1m\sum_{j=0}^{m-1} \prod_i\left(\sum_{k=0}^{e_i}(p_i\omega^j)^k\right),$$どこ$\omega$原始的です$m$単位モジュロの - 乗根$999999001$。 

---

 超高性能の場合:$$n\bigstar=\prod_{t=1}^n t^{\binom{n-t+2}{2}},$$したがって、素数の指数$p$は$$e_p=\sum_{a\ge1}\sum_{\substack{t\le n\\ p^a\mid t}} \binom{n-t+2}{2}.$$のために$n=1000$、すべてを計算します$e_p$、次に、単位根の公式をモジュロで評価します。$$999999001.$$Python の実装:```python
from sympy import primerange, primitive_root

MOD = 999_999_001
m = 1000
n = 1000

# prime exponents in n★
E = {}
for p in primerange(1, n + 1):
    e = 0
    pk = p
    while pk <= n:
        for t in range(pk, n + 1, pk):
            e += (n - t + 1) * (n - t + 2) // 2
        pk *= p
    E[p] = e

g = primitive_root(MOD)
w = pow(g, (MOD - 1) // m, MOD)
inv_m = pow(m, MOD - 2, MOD)

ans = 0

for j in range(m):
    omega = pow(w, j, MOD)
    prod = 1

    for p, e in E.items():
        r = p * omega % MOD

        if r == 1:
            s = e + 1
        else:
            s = (pow(r, e + 1, MOD) - 1) * pow(r - 1, MOD - 2, MOD)

        prod = (prod * s) % MOD

    ans = (ans + prod) % MOD

ans = (ans * inv_m) % MOD
print(ans)
```これは次のように評価されます。
