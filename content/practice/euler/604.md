[プロジェクト オイラー問題 604](https://projecteuler.net/problem=604)

 ## 解決策

 **答え:**`1398582231101`グラフに格子点を通過させる$$P_0,P_1,\dots,P_m$$厳密に増加すると$x$-座標と$y$-コーディネート。 

ステップベクトルを定義する$$v_i=P_i-P_{i-1}=(a_i,b_i),\qquad a_i,b_i\in \mathbb Z_{>0}.$$厳密に凸状の増加関数の場合、傾きは次の条件を満たす必要があります。$$\frac{b_1}{a_1}<\frac{b_2}{a_2}<\cdots<\frac{b_m}{a_m}.$$したがって、すべての傾きは最大 1 回だけ発生する可能性があるため、すべてのベクトルはプリミティブとみなされる可能性があります。$$\gcd(a_i,b_i)=1.$$また、$$\sum a_i\le N,\qquad \sum b_i\le N.$$したがって、問題は次のようになります。 

> 厳密に増加する傾きを持つ、できるだけ多くのプリミティブ正格子ベクトルを選択します。 
>
 >
 >
 >
 >$$\sum a_i\le N,\qquad \sum b_i\le N.$$---

 #1. 注文方法$a+b$プリミティブベクトルの場合$(a,b)$、その「コスト」を定義します$$c=a+b.$$ベクトルの数を最大化するには、明らかに、可能な限り最小の値を持つベクトルを選択します。$a+b$。 

固定の場合$s$、プリミティブ ベクトル$a+b=s$は$$(a,s-a),\qquad 1\le a<s,\quad \gcd(a,s)=1.$$まさにあります$$\varphi(s)$$そういったベクトル。 

---

 # 2. 完全なシェルのコスト

 **すべて**のプリミティブ ベクトルを使用することを検討してください。$a+b=s$。 

セットは以下で対称であるため、$a\leftrightarrow b$、$$\sum a=\sum b=\frac{s\varphi(s)}2$$（のために$s=2$、これは等しい$1$）。 

したがって、すべての貝殻を取ると、$2,3,\dots,m$、 それから$$X(m)=Y(m)=\frac12\sum_{s=2}^m s\varphi(s).$$使用されるベクトルの数は、$$V(m)=\sum_{s=2}^m \varphi(s).$$したがって、格子点の数は次のようになります。$$F=V(m)+1.$$---

 # 3. 部分的な最終シェル

 しましょう$m$そのように最大になる$$X(m)\le N.$$残りの容量を定義する$$R=N-X(m).$$ここで、次のシェルからさらにベクトルを取得できるようになりました。$s=m+1$。 

このようなベクトルにはそれぞれ総コストがあります$s$したがって、追加されたすべてのベクトルは正確に消費されます$s$合計予算からの単位$$(\sum a_i)+(\sum b_i)\le 2N.$$残りの合計予算は、$2R$したがって、最大の追加ベクトルは次のようになります。$$\left\lfloor \frac{2R}{s}\right\rfloor .$$したがって$$\boxed{ F(N)=1+\sum_{k=2}^m\varphi(k) +\left\lfloor \frac{2\left(N-\frac12\sum_{k=2}^m k\varphi(k)\right)} {m+1} \right\rfloor }$$どこ$m$は最大です$$\frac12\sum_{k=2}^m k\varphi(k)\le N.$$これにより、指定されたすべての値が再現されます。 

-$F(3)=3$-$F(9)=6$-$F(11)=7$-$F(100)=30$-$F(50000)=1898$---

 #4. Pythonの実装```python
from array import array

N = 10**18

# ---------------------------------------------------------
# Compute Euler phi up to a sufficient limit.
# The required m is about (pi^2 N)^(1/3) ~ 2.15e6.
# ---------------------------------------------------------

LIMIT = 3_000_000

phi = array('Q', range(LIMIT + 1))

for p in range(2, LIMIT + 1):
    if phi[p] == p:                 # p is prime
        for k in range(p, LIMIT + 1, p):
            phi[k] -= phi[k] // p

# ---------------------------------------------------------
# Accumulate complete shells
# ---------------------------------------------------------

used = 0          # X(m)
count = 1         # initial lattice point
s = 2

while True:

    # contribution of the complete shell a+b=s
    add = (s * phi[s]) // 2

    if used + add > N:
        break

    used += add
    count += phi[s]
    s += 1

# ---------------------------------------------------------
# Partial next shell
# ---------------------------------------------------------

remaining = N - used
extra = (2 * remaining) // s

answer = count + extra

print(answer)
```---

 #5. コードのチュートリアル

 ### トーティエントふるい```python
phi = array('Q', range(LIMIT + 1))
```初期化します$\phi(n)=n$。 

すべての素数について$p$、```python
phi[k] -= phi[k] // p
```オイラーの積公式を実装します$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$---

 ### 完全なシェルの構築

 シェル用$s$、```python
add = (s * phi[s]) // 2
```両方に加算される金額です$x$- そして$y$-合計。 

予算が許す限り、殻ごと採り続けます。 

加算されるベクトルの数は```python
count += phi[s]
```シェルだから$s$正確に含まれています$\varphi(s)$プリミティブベクトル。 

---

 ### 部分的な最終シェル

 最後の完全なシェルの後:```python
remaining = N - used
extra = (2 * remaining) // s
```次のシェルからできるだけ多くのベクトルを追加します。 

ついに、```python
answer = count + extra
```格子点の総数を与えます。
