[プロジェクト オイラー問題 651](https://projecteuler.net/problem=651)

 ## 解決策

 **答え:**`448233151`ステッカーを形にしてみましょう$a\times b$長方形のグリッドを円柱に巻き付ける：

 -$a$= 軸に沿った周期、
 -$b$= number of stickers around the circumference.

 パターンは両方向に周期的であるため、表面は実質的に$a\times b$トーラス。 

**正確に**を使用して色を数える必要があります$m$によって生成されたすべての幾何学的対称を法とする色

 - 軸に沿った平行移動、
 - シリンダー周りの回転、
 - 反省。 

したがって、対称群は次のようになります。$$G \cong D_a \times D_b,$$サイズ付き$$|G| = 4ab.$$問題は **バーンサイドの補題** を直接適用することです。 

---

 #1. バーンサイドの補題

 グループ要素の場合$g$、 させて$c(g)$は、上で誘発された順列のサイクル数になります。$ab$ステッカーの位置。 

によって修正されたカラーリング$g$は各サイクルで一定でなければなりません。$k$利用可能な色があります$$k^{c(g)}$$固定されたカラーリング。 

**正確に**の使用を強制するには$m$色、包含-除外を使用:$$E_m(c) = \sum_{j=0}^{m} (-1)^{m-j} \binom{m}{j} j^c.$$これは等しい$m!\,S(c,m)$、 どこ$S(c,m)$は第 2 種スターリング数です。 

したがって、$$f(m,a,b) = \frac1{4ab} \sum_{g\in G} E_m(c(g)).$$したがって、タスク全体はサイクル数を計算することになります。$c(g)$。 

---

 #2. サイクル構造

 二面体要素は次のいずれかです。 

- 回転、
 - または反省。 

ローテーションの場合$r$長さのサイクルに沿って$n$:$$\gcd(n,r)$$サイクルが発生し、それぞれの長さ$n/\gcd(n,r)$。 

反省について:

 - もし$n$奇数です:

 - 1 つの固定点、
 -$(n-1)/2$移調;
 - もし$n$偶数です:

 - 反射の半分には 2 つの固定点があります。 
- 半数は何も持っていません。 

製品アクションの場合、1 つの要素に長さのサイクルがある場合$p_i$もう一方は長さがあります$q_j$の場合、積の順列が寄与します。$$\sum_{i,j}\gcd(p_i,q_j)$$サイクル。 

これにより、効率的な除数和の公式が得られ、計算が実用的になります。$$(F_{39},F_{40})=(63245986,102334155).$$---

 #3. Pythonの実装```python
from math import gcd, isqrt, comb

MOD = 1_000_000_007

# ------------------------------------------------------------
# Euler phi
# ------------------------------------------------------------

phi_cache = {1: 1}

def phi(n):
    if n in phi_cache:
        return phi_cache[n]

    x = n
    result = n
    p = 2

    while p * p <= x:
        if x % p == 0:
            while x % p == 0:
                x //= p
            result -= result // p
        p += 1

    if x > 1:
        result -= result // x

    phi_cache[n] = result
    return result

# ------------------------------------------------------------
# Divisors
# ------------------------------------------------------------

def divisors(n):
    ds = []
    for d in range(1, isqrt(n) + 1):
        if n % d == 0:
            ds.append(d)
            if d * d != n:
                ds.append(n // d)
    return ds

# ------------------------------------------------------------
# Number of surjections onto exactly m colours
# ------------------------------------------------------------

def exact_colourings(cycles, m):
    total = 0

    for j in range(m + 1):
        total += (
            (-1) ** (m - j)
            * comb(m, j)
            * pow(j, cycles, MOD)
        )

    return total % MOD

# ------------------------------------------------------------
# Burnside count
# ------------------------------------------------------------

def f(m, a, b):

    total = 0

    # --------------------------------------------------------
    # rotation / rotation
    # --------------------------------------------------------

    for d1 in divisors(a):
        for d2 in divisors(b):

            count = phi(a // d1) * phi(b // d2)
            cycles = d1 * d2

            total += count * exact_colourings(cycles, m)

    # --------------------------------------------------------
    # rotation / reflection
    # --------------------------------------------------------

    for d1 in divisors(a):

        A = a // d1
        count = phi(A)

        if b % 2 == 1:

            cycles = d1 * (
                1 + ((b - 1) // 2) * gcd(A, 2)
            )

            total += b * count * exact_colourings(cycles, m)

        else:

            cycles_even = d1 * (b // 2 + 1)
            cycles_odd  = d1 * (b // 2)

            total += (
                (b // 2)
                * count
                * (
                    exact_colourings(cycles_even, m)
                    + exact_colourings(cycles_odd, m)
                )
            )

    # --------------------------------------------------------
    # reflection / rotation
    # --------------------------------------------------------

    for d2 in divisors(b):

        B = b // d2
        count = phi(B)

        if a % 2 == 1:

            cycles = d2 * (
                1 + ((a - 1) // 2) * gcd(B, 2)
            )

            total += a * count * exact_colourings(cycles, m)

        else:

            cycles_even = d2 * (a // 2 + 1)
            cycles_odd  = d2 * (a // 2)

            total += (
                (a // 2)
                * count
                * (
                    exact_colourings(cycles_even, m)
                    + exact_colourings(cycles_odd, m)
                )
            )

    # --------------------------------------------------------
    # reflection / reflection
    # --------------------------------------------------------

    def reflection_types(n):

        if n % 2 == 1:
            # (fixed points, transpositions), multiplicity
            return [((1, (n - 1) // 2), n)]

        return [
            ((2, (n - 2) // 2), n // 2),
            ((0, n // 2),       n // 2),
        ]

    for (f1, t1), mult1 in reflection_types(a):
        for (f2, t2), mult2 in reflection_types(b):

            cycles = (
                f1 * f2
                + f1 * t2
                + f2 * t1
                + 2 * t1 * t2
            )

            total += (
                mult1
                * mult2
                * exact_colourings(cycles, m)
            )

    total %= MOD

    return total * pow(4 * a * b, MOD - 2, MOD) % MOD

# ------------------------------------------------------------
# Fibonacci numbers
# ------------------------------------------------------------

F = [0, 1]

for _ in range(2, 41):
    F.append(F[-1] + F[-2])

# ------------------------------------------------------------
# Required sum
# ------------------------------------------------------------

ans = 0

for i in range(4, 41):
    ans += f(i, F[i - 1], F[i])

ans %= MOD

print(ans)
```---
