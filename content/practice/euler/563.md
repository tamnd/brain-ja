 ## 解決策

 **答え:**`27186308211734760`構築可能な長方形に辺の長さを持たせる$a$そして$b$。 

各溶接ステップには時間がかかります$k$同一の長方形 ($2 \le k \le 25$) を一方のエッジに沿って溶接し、一方の辺の長さに正確に を乗算します。$k$。 

したがって、構成可能なすべての辺の長さは数値の積になります。$\le 25$、つまり、素因数がすべて以下の範囲に収まる数値です。$$2,3,5,7,11,13,17,19,23.$$したがって、構成可能な辺の長さは、正確に **23 平滑数 ** となります。

 # 数学的分析

 建設可能なエリアごとにカウントする必要があります$A$、因数分解の数$$A = xy$$そのような

 -$x,y$23-滑らかです、
 -$x \le y$、
 -$y \le 1.1x$。 

その数が「バリアント」の数です。 

以下を定義します。$$M(n)=\text{smallest constructible area with exactly } n \text{ variants}.$$私たちには次のものが与えられます:$$M(3)=889200.$$確かに、$$889200 =900\cdot 988 =912\cdot 975 =936\cdot 950,$$各辺の長さは 23-smooth です。

 ## すべての構築可能な領域を生成する

 すべての構築可能な領域も 23-smooth です。$$A = xy$$両方とも$x$そして$y$23-スムーズ。 

したがって、すべての関連領域は素数によって生成されます。$$\{2,3,5,7,11,13,17,19,23\}.$$標準的なヒープベースの「ハミング数」生成アルゴリズムは、そのような数値をすべて昇順に列挙します。 

---

 ## 1 つの領域のバリアントをカウントする

 現在のエリアが$A$。 

考えられるすべての短辺を検索します$x$満足のいく$$x \le \sqrt{A}.$$それから$$y=\frac{A}{x}.$$10％の条件は、$$\frac{y}{x}\le \frac{11}{10}$$または同等の$$10y \le 11x.$$つまり、23 スムーズごとに$x$近く$\sqrt{A}$、次のことを確認します。 

1.$x \mid A$、
 2.$10(A/x)\le 11x$。 

成功したチェックの数がバリアントの数になります。 

全員まで続けます$M(2),M(3),\dots,M(100)$が見つかります。

 # Pythonの実装```python
import heapq
import math
from bisect import bisect_right

# Allowed primes (all primes <= 25)
PRIMES = [2, 3, 5, 7, 11, 13, 17, 19, 23]

# Upper bound known to exceed M(100)
LIMIT = 2300000000000000

# solutions[n] = M(n)
solutions = [0] * 101

# Number of distinct M(n) already found
found = 1  # M(1) is irrelevant

# Final sum
answer = 0

# Min-heap generating all 23-smooth numbers
heap = [1]

# All generated smooth numbers that can serve as side lengths
sides = []

while found < 100:

    current = heapq.heappop(heap)

    # Store as a possible side length
    if current * current <= LIMIT:
        sides.append(current)

    # Generate larger smooth numbers
    for p in reversed(PRIMES):
        nxt = current * p

        if nxt <= LIMIT:
            heapq.heappush(heap, nxt)

        # Avoid duplicates
        if current % p == 0:
            break

    # Small optimisations observed experimentally
    if found >= 56:
        if current % 800 != 0:
            continue
    elif found >= 8:
        if current % 80 != 0:
            continue
    else:
        if current % 40 != 0:
            continue

    # Count variants
    count = 0

    # Largest possible short side
    idx = bisect_right(sides, int(math.isqrt(current))) - 1

    while idx > 0:
        short_side = sides[idx]
        idx -= 1

        long_side = current // short_side

        # Ratio exceeded 10%
        if long_side * 10 > short_side * 11:
            break

        # Exact divisor?
        if long_side * short_side == current:
            count += 1

    # We only care about 2..100
    if not (2 <= count <= 100):
        continue

    # First occurrence => minimal area
    if solutions[count] == 0:
        solutions[count] = current
        answer += current
        found += 1

print(answer)
```---

 ## 有効な長方形の数を数える

 エリア用`current`:```python
short_side <= sqrt(current)
```そして```python
long_side = current // short_side
```私たちは以下を強制します:```python
long_side * 10 <= short_side * 11
```まさに「10％以内」の条件です。 

追加でしたら```python
long_side * short_side == current
```その後、有効なバリアントが見つかりました。
