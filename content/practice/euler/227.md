[プロジェクト オイラー問題 227](https://projecteuler.net/problem=227)

 ## 解決策

 **答え:**`3780.618622`2 つのサイコロを区別できるようにし、円周上のサイコロ間の **距離** だけを追跡します。 

テーブルには 100 人のプレーヤーが周期的に配置されているため、関連する状態は次のようになります。 

-$d =$2 つのサイコロ ホルダー間の最小円周距離、
 - それで$d \in \{0,1,2,\dots,50\}$。 

州$d=0$夢中になれる: 1 人のプレイヤーが両方のサイコロを持っているので、ゲームは終了します。 

最初はサイコロが向かい合っているので、$$d_0 = 50.$$---

 #1. 数学的分析

 各ダイスはターン中に次のように独立して動作します。 

- 確率で左に移動します$1/6$、
 - 確率で右に移動します$1/6$、
 - 確率的にその場に留まる$4/6$。 

現在の距離が$d$。 

最初のダイスを次のように動かします。$X\in\{-1,0,+1\}$、

 そして2番目は$Y\in\{-1,0,+1\}$。 

次に、指向性分離は次のように変化します。$$d \mapsto d + (Y-X).$$数量$Y-X$可能性があるのは次のとおりです:$$-2,-1,0,+1,+2$$畳み込みによって得られる確率:$$\begin{aligned} P(\pm2) &= \frac1{36},\\ P(\pm1) &= \frac{8}{36}=\frac29,\\ P(0) &= \frac{18}{36}=\frac12. \end{aligned}$$したがって、内部状態については、$2\le d\le 48$、$$E_d = 1 +\frac1{36}E_{d-2} +\frac29E_{d-1} +\frac12E_d +\frac29E_{d+1} +\frac1{36}E_{d+2},$$どこ$E_d$距離から始まる予想される残りの継続時間です$d$。 

並べ替え:$$\frac12E_d -\frac29E_{d-1} -\frac29E_{d+1} -\frac1{36}E_{d-2} -\frac1{36}E_{d+2} =1.$$---

 ## 境界動作

 ### 吸収状態$$E_0 = 0.$$＃＃＃ 州$d=1$の移行$-1$または$-2$どちらも円の周りに折りたたんだ後に吸収され、次の結果が得られます。$$E_1 = 1 +\frac{19}{36}E_1 +\frac29E_2 +\frac1{36}E_3.$$＃＃＃ 州$d=50$反対の位置では、どちらの側からでも「近づく」と同じ距離が得られます。$$E_{50} = 1 +\frac12E_{50} +\frac49E_{49} +\frac1{18}E_{48}.$$これにより、未知数の 50 個の方程式からなる線形システムが生成されます。$$E_1,E_2,\dots,E_{50}.$$これを解くと、望ましい期待値が得られます。$$E_{50}\approx 3780.61862178446.$$有効数字 10 桁に四捨五入:$$3780.618622.$$---

 #2. Pythonの実装```python
import numpy as np
from collections import defaultdict

N = 100
MAX_D = N // 2   # 50

def transitions(d):
    """
    Return transition probabilities from distance d.
    States are folded using circular symmetry.
    """
    probs = defaultdict(float)

    # Possible moves of one die:
    # -1 with prob 1/6
    #  0 with prob 4/6
    # +1 with prob 1/6
    moves = [(-1, 1/6), (0, 4/6), (1, 1/6)]

    for a, pa in moves:
        for b, pb in moves:

            # new oriented separation
            nd = (d + b - a) % N

            # fold to minimal circular distance
            nd = min(nd, N - nd)

            probs[nd] += pa * pb

    return probs

# Build linear system A x = b
# x[i] = expected time starting from distance i+1
A = np.zeros((MAX_D, MAX_D))
b = np.ones(MAX_D)

for d in range(1, MAX_D + 1):

    row = d - 1

    # E_d coefficient
    A[row, row] = 1.0

    # Move all transition terms to left side
    for nd, p in transitions(d).items():

        # E_0 = 0, so omit absorbing state
        if nd == 0:
            continue

        A[row, nd - 1] -= p

# Solve system
E = np.linalg.solve(A, b)

answer = E[MAX_D - 1]

print(f"{answer:.12f}")
```---

 ## 距離を更新しています```python
nd = (d + b - a) % N
```1 つの死が移動した場合$a$そしてもう一つは$b$、

 それらの相対的な距離は次のように変化します$b-a$。 

プレイヤーは輪になって座るので、モジュロ 100 を減らします。

 ## 折り畳み対称性```python
nd = min(nd, N - nd)
```距離$d$そして$100-d$円上では等価です。 

したがって、状態空間は 100 状態からわずか 51 状態に減少します。

 期待方程式は常に次の形式になります。$$E_d = 1 + \sum p_{d\to k} E_k.$$行列形式に並べ替えます。$$(I-P)E = 1.$$---

 #4. 最終検証

 結果はもっともらしいです:

 - このプロセスは非常に遅いランダム ウォークです。 
- サイコロは通常静止しています ($4/6$それぞれ）。 
- 相対運動には分散のみがあります$2/3$ターンごとに。
