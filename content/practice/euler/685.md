[プロジェクト オイラー問題 685](https://projecteuler.net/problem=685)

 ## 解決策

 **答え:**`662878999`させて$$f(n,m)=\text{the }m^{\text{th}}\text{ positive integer whose digit sum is }n.$$私たちが欲しいのは$$S(k)=\sum_{n=1}^k f(n^3,n^4), \qquad S(10000)\pmod{1\,000\,000\,007}.$$---

 #1. 数学的分析

 ## 1.1 「9からの赤字」による数字の書き換え

 桁の合計を修正する$s$。 

で数字を書きます$L$としての数字$$d_0d_1\dots d_{L-1},$$と$d_0\neq0$。 

**赤字**を定義する$$c_i = 9-d_i.$$それから$$d_i = 9-c_i,$$そして$$\sum d_i = 9L-\sum c_i.$$したがって、桁の合計が必要です$s$と同等です$$\sum c_i = 9L-s.$$また：

-$0\le c_i\le 9$、
 - 先頭の数字の場合、$c_0\le 8$。 

ここで定義します$$D = 9L-s.$$すると数字自体は$$N = \sum_{i=0}^{L-1}(9-c_i)10^{L-1-i} = 10^L-1-\sum_{i=0}^{L-1} c_i10^{L-1-i}.$$したがって、問題は次のようになります。 

> すべての赤字ベクトルを列挙する$(c_0,\dots,c_{L-1})$合計で$D$、辞書編集上の降順で。 

この順序は、元の数値の昇順と正確に一致します。 

---

 # 1.2 どの長さが重要ですか?

 書く$$s=9q+r,\qquad 0\le r<9.$$可能な限り短い長さは、$$L_{\min}=q+[r>0].$$この長さの場合、$$D=9L_{\min}-s= \begin{cases} 0 & r=0,\\ 9-r & r>0. \end{cases}$$さて、私たちの問題は次のとおりです。$$s=n^3,\qquad m=n^4.$$立方体剰余なので$9$だけです$0,\pm1$、$$r\in\{0,1,8\}.$$したがって:

 - もし$r=1$、 それから$D=8$、
- もし$r=0$、 それから$D=0$、
- もし$r=8$、 それから$D=1$。 

固定の不足ベクトルの数$D$多項式のように成長します$q$程度の$D$。 

これが重要な漸近事実です。 

-$D=8$すでに約を与えています$q^8$、
 -$D=9$について与える$q^9$、
 -$D=10$について与える$q^{10}$。 

しかし$m=n^4$、 その間$q\sim n^3$。 

したがって、次のようになります。 

- のために$r=1$、答えは次のとおりです。$D=8$層、
 - のために$r=0$、一意の最小数をスキップして、次の場所に到達します。$D=9$、
- のために$r=8$、省略します。$D=1$レイヤーと着地$D=10$。 

だからそれだけ$D\in\{8,9,10\}$実際の計算には常に必要になります。 

それが中心的な単純化です。 

---

 # 1.3 赤字ベクトルを数える

 しましょう$$F(p,d)$$長さの数値になります-$p$エントリを持つベクトル$[0,9]$合計すると$d$。 

必要なのは$d\le10$、包含と除外は非常に小さいです。$$F(p,d) = \binom{p+d-1}{d} - p\binom{p+d-11}{d-10}.$$(第 2 項は次の場合にのみ重要です)$d=10$。）

 ---

 #1.4 ランキング解除

 を見つけるには、$m$-th ベクトル (辞書順):

 各ポジションで赤字を試す$$c=8,7,\dots,0$$(最初の桁について)、その後$$9,8,\dots,0$$その後。 

候補者ごとに$c$、可能なサフィックスの数を数えます。$$F(\text{remaining positions},\text{remaining deficit}).$$そのブロックが以下より小さい場合$m$、スキップしてください。 それ以外の場合は、その数字を選択して続行します。 

総赤字はせいぜい$10$, the recursion depth is tiny.

 ---

 #2. Pythonの実装```python
from math import comb

MOD = 1_000_000_007

def F(p, d):
    """
    Number of vectors of length p with entries in [0,9]
    summing to d.
    Only d <= 10 is ever needed.
    """
    if d < 0:
        return 0

    # unrestricted weak compositions
    ans = comb(p + d - 1, d)

    # inclusion-exclusion for a digit >= 10
    if d >= 10:
        ans -= p * comb(p + d - 11, d - 10)

    return ans

def kth_number_with_digit_sum(s, m):
    """
    Return f(s,m) modulo MOD.
    """

    q, r = divmod(s, 9)

    # determine which deficit layer contains the answer
    if r == 1:
        L = q + 1
        D = 8

    elif r == 0:
        # skip the unique all-9 number
        m -= 1
        L = q + 1
        D = 9

    else:  # r == 8
        # skip the D=1 layer
        m -= (q + 1)
        L = q + 2
        D = 10

    rem = D
    ans = 0

    for pos in range(L):

        if pos == 0:
            upper = min(8, rem)
        else:
            upper = min(9, rem)

        chosen = None

        for c in range(upper, -1, -1):

            cnt = F(L - pos - 1, rem - c)

            if m > cnt:
                m -= cnt
            else:
                chosen = c
                break

        digit = 9 - chosen
        ans = (ans * 10 + digit) % MOD
        rem -= chosen

    return ans

def solve(limit=10000):
    total = 0

    for n in range(1, limit + 1):
        s = n ** 3
        m = n ** 4

        total += kth_number_with_digit_sum(s, m)
        total %= MOD

    return total

print(solve())
```---

 #3. コードのチュートリアル

 ##`F(p,d)`長さの不足ベクトルをカウントします$p$合計すると$d$。 

桁のキャップなし:$$\binom{p+d-1}{d}$$(星とバーを使用)。 

のために$d=10$、1 桁が不正になる可能性があります。$10$, したがって、包含-除外はそれらを差し引きます。 

---

 ##`kth_number_with_digit_sum`まず、どの欠損層に答えが含まれているかを判断します。 

-$r=1\Rightarrow D=8$、
 -$r=0\Rightarrow D=9$、
 -$r=8\Rightarrow D=10$。 

次に、貪欲に赤字ベクトルを構築します。 

各位置で:

 - 最初に赤字を大きくしてみてください。 
- 存在するサフィックスの数を数えます。 
- 正しいブロックに到達するまでブロック全体をスキップします。 

最後に赤字を数値に変換します。$$d_i=9-c_i.$$---
