 ## 解決策

 **答え:**`20444710234716473`させて$s(n)$は 10 進数の合計を示します$n$。 

整数の数を求めます$$0 \le n < 10^{18}$$そのような$$s(n)=s(137n).$$---

 # 数学的分析

 しましょう$$n=\sum_{i=0}^{17} d_i 10^i, \qquad 0\le d_i\le 9.$$乗算を処理します$137$最下位から最上位まで 1 桁ずつ。 

---

 ## 1. 桁上げ時の桁和の動作

 あるステップで計算するとします。$$137d_i + c_i,$$どこ$c_i$は受信キャリーです。 

書く$$137d_i+c_i = 10c_{i+1}+e_i,$$と$e_i$の出力桁$137n$。 

それから：$$e_i = (137d_i+c_i)\bmod 10, \qquad c_{i+1}=\left\lfloor \frac{137d_i+c_i}{10}\right\rfloor.$$桁合計の差への寄与は次のとおりです。$$d_i-e_i.$$18 桁すべてが処理された後、一部のキャリーが残ります。 その 10 進数も、次の桁の合計に影響します。$137n$。 

したがって、$$s(n)-s(137n) = \sum_{i=0}^{17}(d_i-e_i) - s(c_{18}),$$どこ$s(c_{18})$は最終桁上げの桁の合計です。 

したがって、私たちが必要とするのは、$$\sum_{i=0}^{17}(d_i-e_i)=s(c_{18}).$$これは数字の DP に最適です。 

---

 ## 2. 状態圧縮

 各ポジションで必要なのは以下だけです。 

- 現在のキャリー、
 - 累積差額$$\Delta=\sum(d_i-e_i).$$したがって、次のように定義します。$$\text{DP}(pos, carry, \Delta)$$= 位置から数字を埋める方法の数`pos`これからも。 

最後に （`pos = 18`）、場合に応じて受け入れます$$\Delta = s(carry).$$キャリーは小さいままです:$$137\cdot 9 + \text{carry} < 1400,$$したがって状態空間は小さいです。 

---

 # Pythonの実装```python
from functools import lru_cache

LENGTH = 18
MULTIPLIER = 137

@lru_cache(None)
def dp(pos, carry, diff):
    """
    pos   : current digit position (0 = least significant)
    carry : carry entering this position
    diff  : accumulated value of sum(d_i - e_i)
    """

    # All 18 digits processed
    if pos == LENGTH:

        # Remaining carry contributes digits to 137n
        carry_digit_sum = 0
        c = carry

        while c > 0:
            carry_digit_sum += c % 10
            c //= 10

        # Need total digit sums to match
        return 1 if diff == carry_digit_sum else 0

    total = 0

    # Choose next digit of n
    for d in range(10):

        value = MULTIPLIER * d + carry

        # Output digit of 137n
        out_digit = value % 10

        # Next carry
        next_carry = value // 10

        # Update digit-sum difference
        next_diff = diff + d - out_digit

        total += dp(pos + 1, next_carry, next_diff)

    return total

answer = dp(0, 0, 0)

print(answer)
```---

 # 小規模な健全性チェック

 テイク$n=1$:$$137n = 137.$$桁の合計:$$s(1)=1,\qquad s(137)=1+3+7=11.$$平等ではありません。 

私たちの DP は、累積された差が最後の桁上げ桁によってバランスが取れていないため、これを拒否します。
