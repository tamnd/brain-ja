[プロジェクト オイラー問題 663](https://projecteuler.net/problem=663)

 ## 解決策

 **答え:**`1884138010064752`重要な観察は、これが**点更新における動的最大部分配列問題**であるということです。 

させて$$A_n = (A[0],A[1],\dots,A[n-1])$$そしてステップの後$i$、$$M_n(i)=\max_{0\le p\le q<n}\sum_{j=p}^q A[j]$$(連続する部分配列の最大合計、つまり Kadane の問題)。 

各ステップで **1 つの位置のみが変更**されるため、再計算$M_n(i)$最初から$O(n)$には不可能です$$n=10{,}000{,}003,\qquad l=10{,}200{,}000.$$効率的な解決策は次のとおりです。 

1. トリボナッチ値の剰余を生成する$n$段階的に。 
2. メンテナンス$A_n$ポイント更新付き。 
3. **セグメント ツリー**を使用して、グローバル最大サブ配列合計を維持します。 

セグメントごとに 4 つの数量を保存します。$$(\text{sum},\text{pref},\text{suff},\text{best})$$どこ：

-`sum`= セグメントの合計
 -`pref`= 最大プレフィックス合計
 -`suff`= 最大サフィックス合計
 -`best`= 部分配列の合計の最大値

 2 つの子セグメント$L,R$組み合わせる$O(1)$:$$\text{sum}=L_s+R_s$$

$$\text{pref}=\max(L_p,L_s+R_p)$$

$$\text{suff}=\max(R_u,R_s+L_u)$$

$$\text{best}= \max(L_b,R_b,L_u+R_p)$$メモリ効率の高い実装では **ブロック分解** を使用します: 完全な配列を保持します$A$コンパクトな 64 ビット配列で、個々の要素ではなくブロックにわたるセグメント ツリーを維持します。 問題はただ求めるだけなので、$$S(n,10{,}200{,}000)-S(n,10{,}000{,}000),$$私たちに必要なのはただ$M_n(i)$最後に$200{,}000$ステップ。 それで:

 - 最初のものを適用します$10^7$直接更新し、
 - 構造を一度構築すると、
 - 最終処理$200{,}000$蓄積しながら更新$M_n(i)$。 

正しい Python 実装は次のとおりです。```python
from array import array

NEG_INF = -(10**18)

def block_summary(A, start, end):
    r = 0
    max_pref = NEG_INF
    min_pref_best = 0
    best = NEG_INF
    min_pref_suff = 0
    last = end - 1

    for k in range(start, end):
        r += A[k]

        max_pref = max(max_pref, r)
        best = max(best, r - min_pref_best)
        min_pref_best = min(min_pref_best, r)

        if k != last:
            min_pref_suff = min(min_pref_suff, r)

    total = r
    max_suff = total - min_pref_suff
    return total, max_pref, max_suff, best

def build_block_tree(A, n, B):
    m = (n + B - 1) // B
    size = 1
    while size < m:
        size <<= 1

    total = array("q", [0]) * (2 * size)
    pref  = array("q", [NEG_INF]) * (2 * size)
    suff  = array("q", [NEG_INF]) * (2 * size)
    best  = array("q", [NEG_INF]) * (2 * size)

    # Leaves
    for b in range(m):
        s = b * B
        e = min(n, s + B)
        ts, tp, tu, tb = block_summary(A, s, e)

        pos = size + b
        total[pos] = ts
        pref[pos] = tp
        suff[pos] = tu
        best[pos] = tb

    # Internal nodes
    for pos in range(size - 1, 0, -1):
        l = pos * 2
        r = l + 1

        total[pos] = total[l] + total[r]
        pref[pos] = max(pref[l], total[l] + pref[r])
        suff[pos] = max(suff[r], total[r] + suff[l])
        best[pos] = max(best[l], best[r],
                         suff[l] + pref[r])

    return (m, size, total, pref, suff, best)

def update_block(tree, A, n, B, b):
    m, size, total, pref, suff, best = tree

    s = b * B
    e = min(n, s + B)

    ts, tp, tu, tb = block_summary(A, s, e)

    pos = size + b
    total[pos] = ts
    pref[pos] = tp
    suff[pos] = tu
    best[pos] = tb

    pos //= 2

    while pos:
        l = pos * 2
        r = l + 1

        total[pos] = total[l] + total[r]
        pref[pos] = max(pref[l], total[l] + pref[r])
        suff[pos] = max(suff[r], total[r] + suff[l])
        best[pos] = max(best[l], best[r],
                         suff[l] + pref[r])

        pos //= 2

def solve():
    n = 10_000_003
    start = 10_000_000
    end = 10_200_000
    B = 256

    A = array("q", [0]) * n

    # tribonacci window modulo n
    u0, u1, u2 = 0, 0, 1 % n

    tree = None
    ans = 0

    for i in range(1, end + 1):
        idx = u0
        delta = (u1 << 1) - n + 1
        A[idx] += delta

        if i == start:
            tree = build_block_tree(A, n, B)

        elif i > start:
            update_block(tree, A, n, B, idx // B)
            ans += tree[5][1]   # root maximum subarray sum

        # advance tribonacci by 2 steps
        t3 = u0 + u1 + u2
        if t3 >= n:
            t3 -= n
        if t3 >= n:
            t3 -= n

        t4 = u1 + u2 + t3
        if t4 >= n:
            t4 -= n
        if t4 >= n:
            t4 -= n

        u0, u1, u2 = u2, t3, t4

    return ans

print(solve())
