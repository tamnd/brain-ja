[プロジェクト オイラー問題 582](https://projecteuler.net/problem=582)

 ## 解決策

 **答え:**`19903`の三角形の場合、$120^\circ$反対側の角度$c$、余弦の法則は次のようになります。$$c^2=a^2+b^2+ab.$$整数解を数えるように求められます。$$a\le b\le c,\qquad b-a\le 100.$$定義する$$d=b-a \quad (1\le d\le 100).$$それから$b=a+d$、 それで$$c^2=a^2+(a+d)^2+a(a+d) =3a^2+3ad+d^2.$$乗算する$4$:$$4c^2=12a^2+12ad+4d^2 =3(2a+d)^2+d^2.$$させて$$x=2a+d.$$それから$$4c^2-3x^2=d^2,$$または同等の$y^2-3x^2=d^2\quad (y=2c)$これはペル型方程式です。 

---

 #1. すべての原始解のパラメータ化

 アイゼンシュタインのトリプルの古典的なパラメータ化は次のとおりです。$$a=m^2-n^2,\qquad b=2mn+n^2,\qquad c=m^2+mn+n^2,$$と$$m>n>0,\qquad \gcd(m,n)=1,\qquad m\not\equiv n\pmod 3.$$次に差を計算します。$$b-a = 2mn+n^2-(m^2-n^2) = 2n^2+2mn-m^2.$$させて$$x=m-n.$$それから$m=x+n$、 そして$$b-a = 3n^2-x^2.$$したがって、$$x^2-3n^2=\pm d, \qquad 1\le d\le100.$$したがって、すべての原始三角形はペル型方程式の原始解に対応します。$$x^2-3n^2=\pm d.$$---

 #2. ペルの再発

 もし$$x^2-3n^2=\pm d,$$次に基本単位を掛けます$$2+\sqrt3$$別の解決策を生成します。$$(x+n\sqrt3)(2+\sqrt3) = (2x+3n)+(x+2n)\sqrt3.$$したがって、再発は、$$x' = 2x+3n, \qquad n' = x+2n.$$すべてのプリミティブ ソリューションは、最小限のシードの有限セットから生成されます。 

プリミティブ三角形ごとに、以下の条件を満たすすべての非プリミティブ倍数が許可されます。$$k(b-a)\le100.$$したがって、各プリミティブトリプルが貢献します$$\min\!\left(\left\lfloor\frac{10^{100}}{c}\right\rfloor, \left\lfloor\frac{100}{b-a}\right\rfloor\right)$$三角形。

 #3. Pythonの実装```python
from math import gcd

LIMIT = 10**100

# ------------------------------------------------------------
# Generate minimal Pell seeds
# ------------------------------------------------------------

seeds = []

for x in range(1, 500):
    for n in range(1, 500):

        d = abs(x*x - 3*n*n)

        # difference must satisfy 1 <= d <= 100
        if d == 0 or d > 100:
            continue

        # primitive conditions
        if gcd(x, n) != 1:
            continue

        # equivalent to m != n (mod 3)
        if x % 3 == 0:
            continue

        # test whether this is a minimal seed
        xb = 2*x - 3*n
        nb = 2*n - x

        # if backward step is not positive,
        # this is the start of an orbit
        if xb <= 0 or nb <= 0:
            seeds.append((x, n))

# ------------------------------------------------------------
# Generate all primitive triangles with c <= LIMIT
# ------------------------------------------------------------

primitive = set()

for x, n in seeds:

    while True:

        m = x + n

        a = m*m - n*n
        b = 2*m*n + n*n
        c = m*m + m*n + n*n

        if c > LIMIT:
            break

        a, b = sorted((a, b))

        primitive.add((a, b, c))

        # Pell recurrence
        x, n = 2*x + 3*n, x + 2*n

# ------------------------------------------------------------
# Count all multiples
# ------------------------------------------------------------

total = 0

for a, b, c in primitive:

    d = b - a

    total += min(LIMIT // c, 100 // d)

print(total)
```---

 #4. コードのチュートリアル

 ### シード生成

 のすべての原始的な最小解を検索します。$$x^2-3n^2=\pm d,\qquad d\le100.$$条件```python
gcd(x, n) == 1
x % 3 != 0
```まさにエイゼンシュタインのトリプルの原始的な条件です。 

後方ペルステップ```python
xb = 2*x - 3*n
nb = 2*n - x
```解が軌道上で最小であるかどうかを検出します。 

---

 ### ペルの再発```python
x, n = 2*x + 3*n, x + 2*n
```乗算します$2+\sqrt3$、より大きなソリューションをすべて生成します。 

---

 ### 三角形の回復

 から$m=x+n$、$$a=m^2-n^2,\quad b=2mn+n^2,\quad c=m^2+mn+n^2.$$次に、有効なスカラー倍数をすべて数えます。
