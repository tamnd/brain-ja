[プロジェクト オイラー問題 412](https://projecteuler.net/problem=412)

 ## 解決策

 **答え:**`38788800`させて$a=m-n$。 

形状$L(m,n)$です$m\times m$右上の四角形$n\times n$四角が削除されました。 

図を回転すると、$180^\circ$、条件

 - すべてのエントリは、その下および左側のエントリよりも小さくなります。 

標準的なヤングタブロー状態になります

 - エントリは右下に増加します。 

それで$\operatorname{LC}(m,n)$パーティションの標準的なヤング タブローの正確な数です$$\lambda=(\underbrace{m,\dots,m}_{a\text{ rows}}, \underbrace{a,\dots,a}_{n\text{ rows}}).$$セルの総数は、$$|\lambda|=m^2-n^2.$$したがって、通常のフック長の公式を使用できます。$$f^\lambda=\frac{(|\lambda|)!}{\prod_{c\in\lambda} h(c)}.$$---

 #1. フックの長さ

 図を 3 つの領域に分割します。 

行と列を次から開始します$1$。 

## 地域 A:$1\le i\le a,\ 1\le j\le a$これらのセルは左上にあります$a\times a$ブロック。 

フックの長さは$$h(i,j)=2m-i-j+1.$$固定用$i$、$$\prod_{j=1}^{a} h(i,j) = \frac{(2m-i)!}{(m+n-i)!}.$$---

 ## 地域 B:$1\le i\le a,\ a<j\le m$これらは右上の長方形のセルです。 

フックの長さは$$h(i,j)=2m-n-i-j+1.$$固定用$i$、$$\prod_{j=a+1}^{m} h(i,j) = \frac{(m-i)!}{(a-i)!}.$$---

 ## 地域 C:$a<i\le m,\ 1\le j\le a$これらは左下のセルです。 

彼らのフックの長さは再び$$h(i,j)=2m-n-i-j+1.$$書き込み$i=a+k$($1\le k\le n$）、$$\prod_{j=1}^{a} h(i,j) = \frac{(m-k)!}{(n-k)!}.$$---

 すべてを組み合わせると:$$\boxed{ \operatorname{LC}(m,n) = \frac{(m^2-n^2)!}{ \left( \prod_{i=1}^{a} \frac{(2m-i)!}{(m+n-i)!} \frac{(m-i)!}{(a-i)!} \right) \left( \prod_{k=1}^{n} \frac{(m-k)!}{(n-k)!} \right) } }$$と$a=m-n$。 

---

 # 2. モジュラー算術トリック

 必要です$$\operatorname{LC}(10000,5000)\pmod{76543217}.$$させて$$p=76543217.$$判明しました$p$プライムです。 

また、$$10000^2-5000^2=75\,000\,000 < p.$$したがって、すべての分母項は可逆剰余です$p$。 

唯一の大きな階乗は$$75\,000\,000!.$$ウィルソンの定理を使用すると、次のようになります。$$(p-1)! \equiv -1 \pmod p.$$したがって、$$N! \equiv -\left(\prod_{k=N+1}^{p-1} k\right)^{-1} \pmod p,$$どこ$$N=75\,000\,000.$$尻尾の長さはたったの$$p-1-N = 1\,543\,216,$$これは非常に管理しやすいものです。 

---

 #3. Pythonの実装```python
MOD = 76543217

m = 10000
n = 5000
a = m - n

# Total number of cells
N = m * m - n * n

# ------------------------------------------------------------
# Compute N! mod MOD using Wilson's theorem
#
# (MOD-1)! = -1 (mod MOD)
#
# Therefore:
# N! = -1 / product(N+1 ... MOD-1)
# ------------------------------------------------------------

tail = 1
for x in range(N + 1, MOD):
    tail = (tail * x) % MOD

num = (-pow(tail, MOD - 2, MOD)) % MOD

# ------------------------------------------------------------
# Precompute factorials up to 2m
# ------------------------------------------------------------

limit = 2 * m

fac = [1] * (limit + 1)
for i in range(1, limit + 1):
    fac[i] = fac[i - 1] * i % MOD

invfac = [1] * (limit + 1)
invfac[limit] = pow(fac[limit], MOD - 2, MOD)

for i in range(limit, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

# ------------------------------------------------------------
# Compute hook product denominator
# ------------------------------------------------------------

den = 1

# Region A and Region B
for i in range(1, a + 1):

    # (2m-i)! / (m+n-i)!
    den = den * fac[2 * m - i] % MOD
    den = den * invfac[m + n - i] % MOD

    # (m-i)! / (a-i)!
    den = den * fac[m - i] % MOD
    den = den * invfac[a - i] % MOD

# Region C
for k in range(1, n + 1):

    # (m-k)! / (n-k)!
    den = den * fac[m - k] % MOD
    den = den * invfac[n - k] % MOD

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

answer = num * pow(den, MOD - 2, MOD) % MOD

print(answer)
```---
