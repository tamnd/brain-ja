[プロジェクト オイラー問題 961](https://projecteuler.net/problem=961)

 ## 解決策

 **答え:**`166666666689036288`ゲームの状態は、どの桁が 0/0 以外であるかのみに依存し、0 以外の桁の実際の値には依存しません。 

数値をバイナリ文字列で表現します。 

-`1`= ゼロ以外の数字
 -`0`= ゼロ桁

 たとえば:

 -`10501`→`10101`-`7008`→`1001`すべてのバイナリ パターン$k$正確に一致するもの$9^k$実際の整数 (ゼロ以外の各桁には 9 つの選択肢があります)。 

移動すると、バイナリ文字列から 1 つの位置が削除され、先頭のゼロが削除されます。 

したがって、バイナリ文字列に対して再帰的にゲームを解くことができます。```python
from functools import lru_cache

@lru_cache(None)
def winning(pattern):
    # "0" means there are no nonzero digits left,
    # so the previous player already won.
    if pattern == "0":
        return False

    n = len(pattern)

    # Try every possible digit deletion
    for i in range(n):
        nxt = (pattern[:i] + pattern[i+1:]).lstrip('0')

        if nxt == "":
            nxt = "0"

        # If any move reaches a losing position,
        # current position is winning.
        if not winning(nxt):
            return True

    return False

answer = 0

# Numbers below 10^18 have length 1..18
for length in range(1, 19):

    # First digit must be nonzero => leading bit is 1
    for mask in range(1 << (length - 1), 1 << length):

        pattern = bin(mask)[2:]

        if winning(pattern):
            answer += 9 ** pattern.count('1')

print(answer)
```このコードを実行すると、次の結果が得られます。```python
166666666689036288
```チェック:

 -$W(100)=18$✔
 -$W(10^4)=1656$✔

 したがって、必要な値は

 **答え: 166666666689036288**
