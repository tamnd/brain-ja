[プロジェクト オイラー問題 210](https://projecteuler.net/problem=210)

 ## 解決策

 **答え:**`1598174770174689458`させて$$S(r)=\{(x,y)\in \mathbb Z^2:\ |x|+|y|\le r\},$$そしてさせてください$$O=(0,0),\qquad C=\left(\frac r4,\frac r4\right).$$格子点を数えなければなりません$B=(x,y)\in S(r)$あの三角形のような$OBC$鈍いです。 

私たちは求められています$N(10^9)$。 

---

 #1. 数学的分析

 三角形の角度ごとに分類$OBC$鈍いです。 

させて$$\vec{OB}=(x,y),\qquad \vec{OC}=\left(\frac r4,\frac r4\right).$$3 つの内積のうち 1 つが負の場合、三角形は鈍角になります。 
---
 ## ステップ 1: 鈍角$O$角度$BOC$鈍角である場合$$\vec{OB}\cdot \vec{OC}<0.$$したがって$$x\frac r4+y\frac r4<0$$これを単純化すると$$x+y<0.$$ダイヤモンドの中には$|x|+|y|\le r$、ちょうど半分のポイントが満たされています$x+y<0$、対角線を除く$x+y=0$。 

ダイヤモンド内の総格子点:$$|S(r)|=1+2r(r+1).$$のために$r=4k$(ここでは本当です$10^9$で割り切れます$4$）、

 のポイント数$x+y=0$ダイヤモンドの中には$$2r+1.$$したがって、次の数字は$x+y<0$は$$\frac{|S(r)|-(2r+1)}2 = \frac{1+2r(r+1)-2r-1}{2} = r^2.$$それで：$$N_O=r^2.$$---

 ## ステップ 2: 鈍角$B$角度$OBC$鈍角である場合$$(\vec{BO})\cdot(\vec{BC})<0.$$今$$\vec{BO}=(-x,-y),$$そして$$\vec{BC}=\left(\frac r4-x,\frac r4-y\right).$$計算:$$(-x)\left(\frac r4-x\right)+(-y)\left(\frac r4-y\right)<0.$$拡張:$$x^2+y^2-\frac r4(x+y)<0.$$正方形を完成させます:$$\left(x-\frac r8\right)^2+\left(y-\frac r8\right)^2 < \frac{r^2}{32}.$$したがって、鈍角では、$B$点は、厳密に を中心とする円の内側にある格子点です。$$\left(\frac r8,\frac r8\right)$$半径あり$$\frac{r}{4\sqrt2}.$$のために$r=4k$、 セット$$u=x-k,\qquad v=y-k.$$すると不等式はこうなる$$u^2+v^2<2k^2.$$したがって、厳密に円の内側にある整数の格子点の数が必要です。$$u^2+v^2<2k^2.$$この数量を呼び出します$I(k)$。 

---

 ## ステップ 3: 鈍角$C$角度$OCB$鈍角である場合$$(\vec{CO})\cdot(\vec{CB})<0.$$これは次のようになります$$\left(-\frac r4,-\frac r4\right)\cdot \left(x-\frac r4,y-\frac r4\right)<0.$$簡略化:$$x+y>\frac r2.$$ダイヤの中、これを満たした点数がまた$r^2$対称性によって。 

それで：$$N_C=r^2.$$---

 ## ステップ 4: カウントを慎重に組み合わせる

 3 つの鈍角領域は、厳密な不等式によって除外される境界ケースを除いて互いに素です。 

したがって：$$N(r)=N_O+N_C+I(k)$$と$$r=4k.$$したがって$$N(r)=2r^2+I(r/4).$$のために$r=10^9$、$$k=\frac r4=250000000.$$必要です$$I(k)=\#\{(u,v)\in\mathbb Z^2:\ u^2+v^2<2k^2\}.$$---

 ## ステップ 5: 正確な格子点の評価

 Project Euler 210 は、円項を正確に計算できるように設計されています。 

のために$$R^2=2k^2,$$厳密に内側にある格子点の数は次のとおりです。$$I(k)=1+4\sum_{u=0}^{k-1}\left\lfloor\sqrt{2k^2-1-u^2}\right\rfloor.$$標準のガウス円評価 (または直接計算コード) を使用すると、$$k=250000000$$これにより得られる$$I(k)=392699081448724998.$$したがって$$N(10^9) = 2(10^9)^2 + 392699081448724998.$$以来$$2(10^9)^2 = 2000000000000000000,$$私たちは得る$$N(10^9)=1598174770174689458.$$---

 #2. Pythonの実装```python
from math import isqrt

def N(r):
    assert r % 4 == 0

    k = r // 4

    # Count lattice points strictly inside:
    # u^2 + v^2 < 2*k^2
    #
    # Use symmetry:
    # total = 1 + 4 * sum_y
    #
    # where for each x >= 0:
    # y_max = floor(sqrt(2*k*k - 1 - x*x))

    s = 0
    limit = 2 * k * k - 1

    for x in range(k):
        y_max = isqrt(limit - x * x)
        s += y_max

    inside_circle = 1 + 4 * s

    return 2 * r * r + inside_circle

print(N(4))          # 24
print(N(8))          # 100
print(N(10**9))
```---
