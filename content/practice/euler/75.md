[プロジェクト オイラー問題 75](https://projecteuler.net/problem=75)

 ## 解決策

 **答え:**`161667`この問題の鍵は、すべての整数直角三角形の構造です。 

ピタゴラス三重$(a,b,c)$満足する$$a^2+b^2=c^2$$そしてその周囲は$$L=a+b+c.$$何個か数える必要があります$L \le 1{,}500{,}000$**ちょうど 1 つ**の整数直角三角形に対応します。 

---

 # 数学的分析

 すべての原始ピタゴラス トリプルは、ユークリッドの公式によって一意に生成できます。$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$どこ

-$m>n>0$、
 -$\gcd(m,n)=1$、
 - のうちの 1 つ$m,n$は偶数、もう一方は奇数です。 

すると周長は$$L=a+b+c.$$代わりの：$$L=(m^2-n^2)+(2mn)+(m^2+n^2)$$これを単純化すると$$L=2m(m+n).$$プリミティブ以外のトリプルはすべて単なる倍数です。$$(k a,\; k b,\; k c)$$周囲付き$$kL.$$したがって、戦略は次のとおりです。 

1. すべてのプリミティブ境界を生成する$$p=2m(m+n)\le1{,}500{,}000.$$2. 倍数ごとに$kp$、カウンターをインクリメントします。 
3. 正確に 1 回当たった境界の数を数えます。 

---

 ## 境界あり$m$以来$$2m(m+n)\le N$$そして$n\ge1$、$$2m(m+1)\le N.$$したがって、およそ$$m \lesssim \sqrt{N/2}.$$のために$N=1{,}500{,}000$、$$m \lesssim 866.$$有効性を超えたブルートフォース$(m,n)$ペアは非常に実現可能です。 

---

 # Pythonの実装```python
from math import gcd

LIMIT = 1_500_000

# counts[L] = number of different right triangles with perimeter L
counts = [0] * (LIMIT + 1)

m = 2

# Generate primitive triples using Euclid's formula
while 2 * m * (m + 1) <= LIMIT:

    for n in range(1, m):

        # Primitive triple conditions:
        # 1. m and n coprime
        # 2. opposite parity
        if ((m - n) % 2 == 1) and gcd(m, n) == 1:

            primitive_perimeter = 2 * m * (m + n)

            # Add all multiples of this primitive perimeter
            for p in range(primitive_perimeter, LIMIT + 1, primitive_perimeter):
                counts[p] += 1

    m += 1

# Count perimeters with exactly one representation
answer = sum(1 for x in counts if x == 1)

print(answer)
```---
