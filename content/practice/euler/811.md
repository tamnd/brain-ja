[プロジェクト オイラー問題 811](https://projecteuler.net/problem=811)

 ## 解決策

 **答え:**`327287526`重要な観察は、再帰が 1 ビット間のゼロランのパターンのみに依存するということです。$n$。 

のために$$n=(2^t+1)^r,$$いつ$t$十分に大きい（そしてここでは$t=10^{14}+31$)、二項展開から得られる二進ブロック$$(1+2^t)^r=\sum_{k=0}^r \binom{r}{k}2^{kt}$$重ならないようにしてください。 したがって、次の 1 ビット位置は$n$は、二項係数の二進展開から直接取得されます。 

結果として得られる閉じた形式の評価を使用して、$A(n)$、計算できます$$H(10^{14}+31,62)\pmod{1\,000\,062\,031}.$$次の Python プログラムはこれを効率的に評価します。```python
MOD = 1_000_062_031

def b(n):
    return n & -n

def max_binom_bitlen(r):
    c = 1
    mx = 1
    for k in range(r + 1):
        mx = max(mx, c.bit_length())
        if k < r:
            c = c * (r - k) // (k + 1)
    return mx

def one_positions_via_binom(t, r):
    pos = []
    c = 1
    for k in range(r + 1):
        x = c
        while x:
            lsb = x & -x
            bit = lsb.bit_length() - 1
            pos.append(k * t + bit)
            x -= lsb
        if k < r:
            c = c * (r - k) // (k + 1)
    return pos

def A_from_positions(pos, mod):
    m = len(pos)

    v = [0] * m
    v[0] = 1
    for k in range(1, m):
        v[k] = (5 * v[k - 1] + 3) % mod

    ans = 1
    desc = pos[::-1]

    for i in range(m - 1):
        gap = desc[i] - desc[i + 1] - 1
        if gap > 0:
            ans = ans * pow(v[i + 1], gap, mod) % mod

    return ans

def H(t, r, mod):
    pos = one_positions_via_binom(t, r)
    return A_from_positions(pos, mod)

print(H(10**14 + 31, 62, MOD))
```サンプルに対する検証:$$H(3,2)=A(81)=636056,$$プログラムは正しく再現します。
