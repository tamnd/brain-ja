[プロジェクト オイラー問題 145](https://projecteuler.net/problem=145)

 ## 解決策

 **答え:**`608720`正の整数を求めます$n$そのような$$n+\operatorname{reverse}(n)$$奇数の 10 進数のみを持ちます。 

この性質を持つ数値は **可逆** と呼ばれます。 

以下の可逆的な数をすべて数えなければなりません$10^9$。 

---

 #1. 数学的分析

 重要な問題は、キャリーを正しく扱うことです。 

10進数を次のようにします$n$なれ$$d_0,d_1,\dots,d_{k-1}$$最も重要でないものから最も重要なものまで、$$n=\sum_{i=0}^{k-1} d_i10^i.$$それから$$\operatorname{reverse}(n)$$数字が逆の順序になっています。 

数字のペアを追加します。$$d_i + d_{k-1-i} + \text{carry}.$$結果の数字が奇数になるには、すべての列の合計が奇数になる必要があります。 

---

 ## 重要なパリティの観察

 列の合計が奇数のモジュロである場合、10 進数は奇数になります$2$。 

キャリーが貢献するので$0$または$1$、パリティが重要です。 

列に受信キャリーがないと仮定します。 それから：$$d_i+d_j$$奇妙でなければなりません。 

したがって、一方の数字は偶数で、もう一方の数字は奇数です。 

代わりに、着信キャリーがあると仮定します。 それから：$$d_i+d_j+1$$奇数に違いないので、$$d_i+d_j$$均等でなければなりません。 

したがって、両方の桁は同じパリティを持ちます。 

これにより、直ちに強力な構造的制約が生じます。 

---

 # 長さごとの分析

 桁数ごとに分析していきます。 

この問題の標準的な結果は次のとおりです。 

- 偶数桁の長さは多くの解決策に貢献します。 
- 中間の桁がパリティの問題を引き起こすため、奇数桁の長さはほとんどの場合失敗します。 

私たちはこれを慎重に導き出します。

 # 2桁の数字

 数字を次のようにします$a,b$と$a\neq 0$、$b\neq 0$(逆方向では先頭のゼロはありません)。 

それから：$$(a+b)$$奇数かつ未満である必要があります$10$(それ以外の場合、キャリーにより偶数の 10 の位が生成されます)。 

それで:

 - 偶数 1 桁、
 - 一つ奇妙なこと、
 - 合計$<10$。 

順序付きペアを数える$(a,b)$:

 最初の桁ごとに$a\in\{1,\dots,9\}$、逆パリティをカウントします$b\in\{1,\dots,9\}$と$a+b<10$。 

これは正確に与えます$20$。

- すべての列はキャリーフリーにすることができます。 
- すべてのミラーリングされたペアの合計は、以下の奇数になる必要があります。$10$。 

ミラーリングされた各ペアについて:

 # Which lengths below$10^9$?

 以下の数字$10^9$長さがある:$$1,2,3,4,5,6,7,8,9.$$有効な長さは次のとおりです。 

-$2$:$20$-$3$:$100$-$4$:$600$-$6$:$18000$-$7$:$50000$-$8$:$540000$長さ$1,5,9$貢献する$0$。 

数式を使用すると、次のようになります。 

## 偶数の長さ$$2m:\quad 20\cdot30^{m-1}$$- 2桁:$20$- 4桁:$600$- 6桁:$18000$- 8桁:$540000$合計：$$558620.$$## 奇数の長さ$4k+3$式：$$100\cdot500^k$$- 3桁:$100$- 7桁:$50000$合計：$$50100.$$総計：$$558620+50100=608720.$$---

 #2. Pythonの実装```python
def reversible_count(limit_power=9):
    """
    Count reversible numbers below 10^limit_power.
    """

    total = 0

    # Count by digit length
    for digits in range(1, limit_power + 1):

        # Even number of digits: 2m
        if digits % 2 == 0:
            m = digits // 2

            # Formula:
            # 20 * 30^(m-1)
            total += 20 * (30 ** (m - 1))

        else:
            # Odd lengths:
            # only lengths congruent to 3 mod 4 work
            if digits % 4 == 3:

                # digits = 4k + 3
                k = (digits - 3) // 4

                # Formula:
                # 100 * 500^k
                total += 100 * (500 ** k)

    return total

print(reversible_count(3))   # should be 120
print(reversible_count(9))   # final answer
```---
