[プロジェクト オイラー問題 314](https://projecteuler.net/problem=314)

 ## 解決策

 **答え:**`132.52756426`正方形の中心を原点に置くと、利用可能な領域は次のようになります。$$-250 \le x,y \le 250.$$最適な壁は両軸に対して対称で凸状であるため、第 1 象限円弧結合を検討するだけで十分です。$$(0,250)\quad\text{to}\quad(250,0).$$この四半期境界に面積寄与がある場合$A_q$そして長さ$L_q$、完全な図は次のようになります。$$A = 4A_q,\qquad L = 4L_q,$$とても最大化しています$A/L$を最大化するのと同じです$$\frac{A_q}{L_q}.$$---

 #1. 数学的分析

 モノトーンの多角形チェーンの場合$$P_0=(0,250),\,P_1,\dots,P_k=(250,0),$$増加するにつれて$x$-座標と減少$y$-座標:

 - 4分の1の面積は台形から取得されます。$$A_q = \sum_i \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i),$$- 四分の一の周囲は$$L_q = \sum_i \sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$最大化したい$$\frac{A_q}{L_q}.$$---

 ## ディンケルバッハ変換

 部分最適化の標準的なトリックは次のとおりです。 

最大化する$$\frac{A_q}{L_q}$$最適値の場合は$r^{*}$、$$\max (A_q-r^{*}L_q)=0.$$したがって、固定の場合$r$、エッジの重みを定義します$$w(P_i,P_{i+1}) = \frac{y_i+y_{i+1}}2 (x_{i+1}-x_i) - r\sqrt{(x_{i+1}-x_i)^2+(y_{i+1}-y_i)^2}.$$ここで問題は、第 1 象限の格子点の DAG 上の最長パス動的プログラムになります。 

二分探索$r$:

 - の最良の値の場合$A_q-rL_q$がポジティブであれば、$r$小さすぎる、
 - 否定的な場合、$r$大きすぎます。 

固有のルートが最適な比率です。

 #2. Pythonの実装```python
from math import hypot

N = 250

# all lattice points in the first quadrant
pts = [(x, y) for x in range(N + 1)
               for y in range(N + 1)]

# monotone ordering
pts.sort()

# ------------------------------------------------------------
# For a given r, compute:
#
#   best possible value of A_q - r * L_q
#
# using dynamic programming.
# ------------------------------------------------------------
def best_value(r):

    # dp[(x,y)] = best score reaching (x,y)
    dp = {(0, 250): 0.0}

    for x2 in range(N + 1):
        for y2 in range(N + 1):

            if (x2, y2) == (0, 250):
                continue

            best = -1e100

            # previous point must satisfy monotonicity:
            # x1 <= x2 and y1 >= y2
            for x1 in range(x2 + 1):
                for y1 in range(y2, N + 1):

                    if (x1, y1) not in dp:
                        continue

                    if x1 == x2 and y1 == y2:
                        continue

                    dx = x2 - x1
                    dy = y1 - y2

                    if dx < 0 or dy < 0:
                        continue

                    area = (y1 + y2) * dx / 2.0
                    length = hypot(dx, dy)

                    val = dp[(x1, y1)] + area - r * length

                    if val > best:
                        best = val

            if best > -1e90:
                dp[(x2, y2)] = best

    return dp[(250, 0)]

# ------------------------------------------------------------
# Binary search for the optimal ratio
# ------------------------------------------------------------
lo, hi = 100.0, 150.0

for _ in range(60):
    mid = (lo + hi) / 2.0

    if best_value(mid) > 0:
        lo = mid
    else:
        hi = mid

answer = (lo + hi) / 2.0

print("{:.8f}".format(answer))
```---

 ### 移行

 すべての有効な先行者に対して$(x_1,y_1)\to(x_2,y_2)$:```python

length = hypot(dx, dy)
```これは次のように計算します。 

- 台形面積の寄与、
 - ユークリッド辺の長さ。 

それから：```python
val = previous + area - r * length
```変換された最適化目標を実装します。

 ### 二分探索

 最適な比率$r^{*}$満足する$$\max(A_q-r^{*}L_q)=0.$$そこでルートを二分探索します。
