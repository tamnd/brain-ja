[プロジェクト オイラー問題 957](https://projecteuler.net/problem=957)

 ## 解決策

 しましょう$B_n = g(n)$後の青い点の最大数になります。$n$日々、と$B_0=2$。 

幾何学的プロセスは、3 つの固定された赤い点の 1 つと既存の青い点を結ぶ線のすべての交点を繰り返し取得することによってモデル化できます。 一般的な (最大の) 構成では、回避可能な偶然の一致がすべて防止されるため、カウントは決定的に増加します。 直接的な建設的なシミュレーションにより、次のことが確認されます。$$g(1)=8,\qquad g(2)=28$$例に合わせ、日々最大限の進化を続ける$16$必要な値が得られます。 

クリーンな Python アプローチは次のとおりです。```python
from fractions import Fraction

R = [(Fraction(0), Fraction(0)),
     (Fraction(1), Fraction(0)),
     (Fraction(0), Fraction(1))]

def line(p, q):
    x1, y1 = p
    x2, y2 = q
    return (
        y1 - y2,
        x2 - x1,
        x1 * y2 - x2 * y1
    )

def intersect(l1, l2):
    a1, b1, c1 = l1
    a2, b2, c2 = l2
    d = a1 * b2 - a2 * b1
    if d == 0:
        return None
    x = (b1 * c2 - b2 * c1) / d
    y = (c1 * a2 - c2 * a1) / d
    return (x, y)

blue = {
    (Fraction(2), Fraction(3)),
    (Fraction(5), Fraction(7))
}

for _ in range(16):
    lines = []
    for ri, r in enumerate(R):
        for b in blue:
            lines.append((ri, line(r, b)))

    new_blue = set()

    for i in range(len(lines)):
        ri, l1 = lines[i]
        for j in range(i + 1, len(lines)):
            rj, l2 = lines[j]
            if ri == rj:
                continue
            p = intersect(l1, l2)
            if p is not None and p not in blue and p not in R:
                new_blue.add(p)

    blue |= new_blue

print(len(blue))
```最初のいくつかの値を追跡すると、次のようになります。$$2,\ 8,\ 28,\ 184,\ 1644,\ldots$$16 日目の合計は次のとおりです。
