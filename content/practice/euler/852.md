[プロジェクト オイラー問題 852](https://projecteuler.net/problem=852)

 ## 解決策

 **答え:**`130.313496`させて$V(f,u)$が存在する場合に最適な将来の予想スコアを示します。$f$公正なコインと$u$不公平なコインがボックスに残っています。 

公正なコインには、$$P(H)=\tfrac12,$$一方、不公平なコインは$$P(H)=\tfrac34.$$選択されたコインが不公平であるという現在の事後確率が$q$、その後:

 - 「不公平」を推測すると、期待される報酬が得られます$$20q-50(1-q)=70q-50,$$- 「公平」と推測すると期待される報酬が得られます$$20(1-q)-50q=20-70q.$$したがって、最適な即時停止の見返りは次のとおりです。$$G(q)=\max(70q-50,\;20-70q).$$---

 ## ベイズ更新

 しましょう$$r=\frac{q}{1-q}$$コインが不公平であるというオッズ比になります。 

当初は、$$r_0=\frac{u}{f}.$$観察後:

 - 頭: 尤度比を乗算します。$\frac{3/4}{1/2}=\frac32$、
 - テール: 尤度比を乗算します。$\frac{1/4}{1/2}=\frac12$。 

したがって、次のようになります。$$r \to \frac32 r \quad (\text{head}), \qquad r \to \frac12 r \quad (\text{tail}).$$表の予測確率は$$P(H)=\frac34 q+\frac12(1-q) =\frac{2+3r}{4(1+r)}.$$---

 ## 動的プログラミングがワンコインで

 このラウンドの後、継続値が次のように異なると仮定します。$$A = V(f,u-1)-V(f-1,u).$$じゃあすぐ後ろで止めたら$q$、このラウンド以降の合計期待値は、$$\max\Big(q(70+A)-50,\; q(A-70)+20\Big).$$させて$F(r)$オッズ比から始まる最適な期待値になる$r$。 それから$$F(r)=\max\left( S(r), -1 + P(H)F\!\left(\tfrac32 r\right)      + P(T)F\!\left(\tfrac12 r\right) \right),$$どこ$S(r)$上記の停止値です。 

ついに、$$V(f,u)=V(f-1,u)+F\!\left(\frac{u}{f}\right).$$境界条件:$$V(0,u)=20u,\qquad V(f,0)=20f,$$なぜなら、残りのコインがすべてわかれば、将来の推測はすべて正しくなり、投げる必要がなくなるからです。

 ## Pythonの実装```python
from math import *

def solve(N, depth=160):
    V = [[0.0]*(N+1) for _ in range(N+1)]

    pow2 = [1.0]
    pow3 = [1.0]

    for _ in range(depth + 2):
        pow2.append(pow2[-1] * 2.0)
        pow3.append(pow3[-1] * 3.0)

    for total in range(1, 2*N + 1):

        lo = max(0, total - N)
        hi = min(N, total)

        for f in range(lo, hi + 1):

            u = total - f

            if f == 0:
                V[f][u] = 20.0 * u
                continue

            if u == 0:
                V[f][u] = 20.0 * f
                continue

            A = V[f][u-1] - V[f-1][u]

            r0 = u / f

            # H[a][b]:
            # after b tosses with a heads
            H = [[0.0]*(depth+2) for _ in range(depth+2)]

            for b in range(depth, -1, -1):

                for a in range(b, -1, -1):

                    r = r0 * pow3[a] / pow2[b]
                    q = r / (1.0 + r)

                    stop = max(
                        q*(70.0 + A) - 50.0,
                        q*(A - 70.0) + 20.0
                    )

                    if b < depth:

                        pH = (2.0 + 3.0*r) / (4.0*(1.0 + r))

                        cont = (
                            -1.0
                            + pH * H[a+1][b+1]
                            + (1.0-pH) * H[a][b+1]
                        )

                        stop = max(stop, cont)

                    H[a][b] = stop

            V[f][u] = V[f-1][u] + H[0][0]

    return V[N][N]

ans = solve(50)
print(f"{ans:.6f}")
```切り捨ての深さが増加すると、計算は急速に収束します。
