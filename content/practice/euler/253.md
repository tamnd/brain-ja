[プロジェクト オイラー問題 253](https://projecteuler.net/problem=253)

 ## 解決策

 **答え:**`11.492847`毛虫に持たせてください$n$位置に配置されたピース$1,2,\dots,n$。 

ピースを均一にランダムな順序で配置します。 

すべての段階で、占有された位置がいくつかの連続したブロック (「セグメント」) を形成します。 

私たちは興味があります$$M = \max(\text{number of segments seen during the process}).$$のために$n=40$、計算しなければなりません$$\mathbb E[M].$$---

 #1. 数学的分析

 ## セグメントダイナミクス

 位置にピースを配置するとします$x$。 

可能性は 3 つだけです。 

- どちらの隣も占有されていません$\Rightarrow$新しいセグメントが作成されます$\Rightarrow \Delta S = +1$- ちょうど 1 つの隣人が占有されています$\Rightarrow$既存のセグメントが拡張される$\Rightarrow \Delta S = 0$- 両方の隣が占有されています$\Rightarrow$2 つのセグメントが結合する$\Rightarrow \Delta S = -1$したがって、プロセスは空のギャップのパターンによって完全に決定されます。 

---

 ## ギャップの表現

 占有位置を保存する代わりに、_空のギャップ_を保存します。 

ギャップは次のように表されます。$$(g,L,R)$$どこ：

-$g$= ギャップ内の空のセルの数
 -$L \in \{0,1\}$: 左側の境界は占有されていますか?
 -$R \in \{0,1\}$: 右側の境界は占有されていますか?

 最初に:$$[(40,0,0)]$$(完全に空の間隔が 1 つ)。 

ギャップの中にピースを配置すると、ギャップは 2 つの小さなギャップに分割されます。 

これにより、クリーンな再帰 DP が得られます。 

---

 ## 確率 DP

 定義する$$F(state,s,m)$$以下から始まる確率として:

 - 電流ギャップ構成 =`state`- 現在のセグメント数 =$s$私たちは決して超えることはありません$m$将来のセグメント。 

次に:

 - もし$s>m$、 戻る$0$- ギャップが残っていない場合は、戻ります$1$それ以外の場合は、すべての可能な配置の平均を計算します。 

ついに、$$P(M \le m)=F(\text{initial},0,m).$$アイデンティティの使用$$\mathbb E[M] = \sum_{k\ge1} P(M\ge k) = \sum_{k\ge1} \left(1-P(M\le k-1)\right),$$期待を正確に得ます。

 #2. Pythonの実装```python
from functools import cache
from collections import defaultdict

N = 40

@cache
def transitions(state, segs):
    """
    Generate all transitions from a given state.

    state = tuple of gaps (g, L, R)
    segs  = current number of segments
    """

    total_empty = sum(g for g, _, _ in state)

    out = defaultdict(int)

    for idx, (g, L, R) in enumerate(state):

        others = list(state[:idx] + state[idx + 1:])

        for pos in range(1, g + 1):

            # Number of occupied neighbours
            c = 0
            if pos == 1 and L:
                c += 1
            if pos == g and R:
                c += 1

            # Segment count change
            if c == 0:
                new_segs = segs + 1
            elif c == 1:
                new_segs = segs
            else:
                new_segs = segs - 1

            new_state = others[:]

            left_len = pos - 1
            right_len = g - pos

            if left_len > 0:
                new_state.append((left_len, L, 1))

            if right_len > 0:
                new_state.append((right_len, 1, R))

            new_state = tuple(sorted(new_state))

            out[(new_state, new_segs)] += 1

    return total_empty, list(out.items())

def probability_max_at_most(m):

    @cache
    def F(state, segs):

        if segs > m:
            return 0.0

        if not state:
            return 1.0

        total_empty, trans = transitions(state, segs)

        ans = 0.0

        for (new_state, new_segs), count in trans:
            ans += count * F(new_state, new_segs)

        return ans / total_empty

    return F(((N, 0, 0),), 0)

# Compute expectation
expectation = 0.0

for k in range(1, N + 1):
    p_le = probability_max_at_most(k - 1)
    expectation += 1.0 - p_le

print(f"{expectation:.6f}")
```---

 #3. コードのチュートリアル

 ##`transitions(state, segs)`すべてのギャップのすべての空の位置について:

 - どれだけ多くの占有近隣に接触しているかを決定します
 - セグメント数を更新します
 - ギャップを左/右のサブギャップに分割します
 - 結果として得られる同一の状態を集約する

 これにより、状態空間が大幅に減少します。 

---

 ##`F(state, segs)`再帰的なメモ化された確率:$$F = \Pr(\text{never exceed } m)$$基本的なケース:

 - すでに超えています$m$

$\Rightarrow 0$- 空のセルは残らない$\Rightarrow 1$それ以外の場合は、次に考えられるすべての配置の平均をとります。 

---

 ## 最終的な期待値

 私たちが使用するのは$$\mathbb E[M] = \sum_{k=1}^{N} \left(1-P(M\le k-1)\right).$$---
