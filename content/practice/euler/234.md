[プロジェクト オイラー問題 234](https://projecteuler.net/problem=234)

 ## 解決策

 **答え:**`1259187438574927161`させて$p<q$連続する素数であること。 

すべての整数に対して$n$と$$p^2 < n < q^2,$$我々は持っています$$\operatorname{lps}(n)=p,\qquad \operatorname{ups}(n)=q,$$厳密にはその間に素数が存在しないため、$p$そして$q$。 

だからその間隔の中で$(p^2,q^2)$、次の場合、数値は正確に半割り可能です。 

- それは次で割り切れます$p$xor で割り切れる$q$、
 - つまり、そのうちの 1 つで割り切れます。 

これにより、問題はすぐに連続する素数ペアの合計に変わります。 

---

 #1. 数学的分析

 連続する素数の場合$p<q$、 定義する$$I_{p,q}=\{n : p^2<n<q^2\}.$$この間隔内では次のようになります。 

- 割り切れる半割り数$p$:$$p\cdot k,\qquad k=p+1,\dots,\left\lfloor\frac{q^2-1}{p}\right\rfloor$$- 割り切れる半割り数$q$:$$q\cdot k,\qquad k=\left\lfloor\frac{p^2}{q}\right\rfloor+1,\dots,q-1$$しかし両方で割り切れる数$p$そして$q$の倍数です$pq$、そして両方の素平方根がそれらを割るので、これらは**半分割可能ではありません**。 

したがって、各素数ペアに対して包含と除外を使用します。$$S(p,q) = \sum_{\substack{p^2<n<q^2\\ p\mid n}} n + \sum_{\substack{p^2<n<q^2\\ q\mid n}} n - 2\sum_{\substack{p^2<n<q^2\\ pq\mid n}} n.$$要因$2$二重にカウントされた倍数を削除します$pq$全体的に。 

---

 ## 効率的に倍数を合計する

 の倍数の合計$m$間隔の中で$[A,B]$は：$$m\sum_{k=\lceil A/m\rceil}^{\lfloor B/m\rfloor} k.$$等差級数公式を使用すると、$$\sum_{k=L}^{R} k = \frac{(L+R)(R-L+1)}{2}.$$それで：$$\operatorname{sumMultiples}(m,A,B) = m\cdot \frac{(L+R)(R-L+1)}{2},$$どこ$$L=\left\lceil\frac{A}{m}\right\rceil,\qquad R=\left\lfloor\frac{B}{m}\right\rfloor.$$---

 #2. Pythonの実装```python
from math import isqrt

LIMIT = 999966663333

# ------------------------------------------------------------
# Generate all primes up to sqrt(LIMIT)
# ------------------------------------------------------------

max_prime = isqrt(LIMIT) + 1000

sieve = bytearray(b'\x01') * (max_prime + 1)
sieve[0] = sieve[1] = 0

for i in range(2, isqrt(max_prime) + 1):
    if sieve[i]:
        sieve[i * i : max_prime + 1 : i] = (
            b'\x00' * (((max_prime - i * i) // i) + 1)
        )

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# Sum of multiples of m inside [A, B]
# ------------------------------------------------------------

def sum_multiples(m, A, B):
    L = (A + m - 1) // m
    R = B // m

    if L > R:
        return 0

    count = R - L + 1
    return m * (L + R) * count // 2

# ------------------------------------------------------------
# Main computation
# ------------------------------------------------------------

total = 0

for p, q in zip(primes, primes[1:]):

    # numbers with lps = p and ups = q
    A = p * p + 1
    B = min(q * q - 1, LIMIT)

    if A > B:
        break

    total += (
        sum_multiples(p, A, B)
        + sum_multiples(q, A, B)
        - 2 * sum_multiples(p * q, A, B)
    )

print(total)
```---

 #5. 最終検証

 アルゴリズムは数学的に正確です。 

- 毎$n\ge4$ちょうど 1 つの間隔に属します$(p^2,q^2)$、
 - 半割り可能性は、ちょうど次の 1 つだけ割り可能になります。$p,q$、
 - 包含と除外により、禁止されている倍数が削除されます。$pq$。 

計算された値は次のとおりです。$$1259187438574927161$$これは予想される大きさです ($\sim 10^{18}$) 限界に近い場合$10^{12}$。
