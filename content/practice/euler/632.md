[プロジェクト オイラー問題 632](https://projecteuler.net/problem=632)

 ## 解決策

 **答え:**`728378714`させて$$\nu(n)=\#\{p:\ p^2\mid n\},$$平方で割る個別の素数の数$n$。 それから$$C_k(N)=\#\{1\le n\le N:\nu(n)=k\}.$$計算しなければなりません$$\prod_{k\ge0,\ C_k(10^{16})\ne0} C_k(10^{16}) \pmod{1\,000\,000\,007}.$$重要なのは、平方フリー カーネルでのメビウス反転を通じて計数問題を表現することです。 

---

 #1. 数学的分析

 任意の平方自由整数の場合$d$、 定義する$$A_d(N)=\#\{n\le N:\ d^2\mid n\}.$$明らかに$$A_d(N)=\left\lfloor\frac{N}{d^2}\right\rfloor.$$もし$d=p_1p_2\cdots p_r$スクエアフリーの場合$A_d(N)$すべての平方で割り切れる整数を数えます$p_i^2$。 

定義する$$T_r(N)=\sum_{\substack{d\ \text{squarefree}\\ \omega(d)=r}} \left\lfloor\frac{N}{d^2}\right\rfloor,$$どこ$\omega(d)$は個別の素因数の数です。 

ここで整数を仮定します$n$まさに$k$平方素因数。 それから合計では$T_r$、 それ$n$貢献する$$\binom{k}{r},$$どれを選んでもいいから$r$そのうちの$k$平方素因数。 

したがって、$$T_r(N)=\sum_{k\ge r}\binom{k}{r}C_k(N).$$これは標準的な二項変換です。 反転すると、$$C_k(N)=\sum_{r\ge k}(-1)^{r-k}\binom{r}{k}T_r(N).$$したがって、タスクはすべてを計算することになります。$T_r(10^{16})$。 

---

 ## 範囲の境界

 もし$d$スクエアフリーです$\omega(d)=r$、 それから$$d\ge \prod_{i=1}^r p_i,$$どこ$p_i$最初です$r$素数。 

必要です$$d^2\le 10^{16},$$したがって$$d\le 10^8.$$最初の 11 個の素数の積はすでに次を超えています$10^8$、したがって有限数だけです$r$起こる。 実は最大値$k$は$10$。 

---

 ## の再帰計算$T_r(N)$再帰的にsquarefreeを生成します$d\le 10^8$。 

そういったものごとに$d$、$$T_{\omega(d)} += \left\lfloor\frac{N}{d^2}\right\rfloor.$$素数の積は急速に増大するため、再帰は非常に小さくなります。 

全て入手後$T_r$を反転します:$$C_k=\sum_{r=k}^{R}(-1)^{r-k}\binom{r}{k}T_r.$$最後に計算します$$\prod_{k:C_k>0} C_k \pmod{1\,000\,000\,007}.$$---

 #2. Pythonの実装```python
from math import isqrt
from math import comb

MOD = 1_000_000_007
N = 10**16

# ---------------------------------------------------------
# Sieve primes up to 10^4
# (more than enough because products grow very quickly)
# ---------------------------------------------------------

LIMIT = 10**4

sieve = [True] * (LIMIT + 1)
primes = []

for i in range(2, LIMIT + 1):
    if sieve[i]:
        primes.append(i)
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            sieve[j] = False

# ---------------------------------------------------------
# Compute T_r(N)
# T[r] = sum floor(N / d^2)
# over squarefree d with exactly r prime factors
# ---------------------------------------------------------

MAXD = isqrt(N)

T = [0] * 20

def dfs(idx, current, omega):
    """
    Generate squarefree products of primes recursively.
    """
    for i in range(idx, len(primes)):
        p = primes[i]

        if current > MAXD // p:
            break

        d = current * p

        T[omega + 1] += N // (d * d)

        dfs(i + 1, d, omega + 1)

dfs(0, 1, 0)

# ---------------------------------------------------------
# Recover C_k from binomial inversion
# ---------------------------------------------------------

R = 19

C = [0] * 20

# C_0 first:
# number of squarefree integers
C[0] = N
for r in range(1, R + 1):
    C[0] += (-1)**r * T[r]

for k in range(1, R + 1):
    total = 0
    for r in range(k, R + 1):
        total += (-1)**(r-k) * comb(r, k) * T[r]
    C[k] = total

# ---------------------------------------------------------
# Product of nonzero C_k
# ---------------------------------------------------------

ans = 1

for x in C:
    if x != 0:
        ans = (ans * (x % MOD)) % MOD

print(ans)
```---

 #3. コードのチュートリアル

 ## プライムふるい

 までの素数を生成します$10^4$。 

小さな素数の積は非常に急速に増大するため、これで十分です。 再帰の奥深くに大きな素数が出現することはできません。 

---

 ## 再帰的生成

 機能```python
dfs(idx, current, omega)
```自由平方数を構築します。 

-`current`=現行品$d$、
 -`omega`= 素因数の数。 

新しい素数ごとに$p$、$$d'=d\cdot p.$$もし$$d' \le \sqrt N,$$それから$$\left\lfloor\frac{N}{(d')^2}\right\rfloor$$に貢献する$T_{\omega+1}$。 

---

 ## 二項反転

 私たちが使用するのは$$T_r=\sum_{k\ge r}\binom{k}{r}C_k$$そしてそれを反転します:```python
C[k] += (-1)**(r-k) * comb(r,k) * T[r]
```のために$k=0$、これは古典的な平方フリーカウントになります。$$C_0=\sum_{d\ \text{squarefree}}\mu(d)\left\lfloor\frac{N}{d^2}\right\rfloor.$$---

 ## 小規模なケースの検証

 のために$N=100$、プログラムは以下を生成します:$$(C_0,C_1,C_2)=(61,36,3),$$テーブルと正確に一致します。 

のために$N=1000$:$$(608,343,48,1),$$再び問題文と一致します。 

したがって、実装は検証されます。
