[プロジェクト オイラー問題 311](https://projecteuler.net/problem=311)

 ## 解決策

 **答え:**`2466018557`双斜積分四角形は中点を使用して再解釈できます。$O$対角線の$BD$。 

させて

-$x = BO = DO = \tfrac{BD}{2}$、
 -$y = AO = CO$、

と$y \le x$、両方とも整数です。 

各辺は辺のある三角形から生じます$(x,y,\text{edge})$。 コサインの法則と中点幾何学により、すべてのエッジの長さは、2 つの平方の和として同じ整数を表現することでパラメータ化できます。 鍵となるアイデンティティは次のとおりです。$$AB^2+BC^2+CD^2+AD^2 = 4(x^2+y^2)$$したがって、制約は次のようになります。$$x^2+y^2 \le \frac{N}{4}.$$この問題は、厳密な不等式を条件として、同じ 2 つの平方和の表現の互換性のある順序ペアを数えることに帰着します。$$AB < BC < CD < AD.$$効率的なソリューションはすべての分解を列挙します$$k = u^2 + v^2$$そしてそれらを間隔に変換します$(u-v,\;u+v)$。 有効な双斜四辺形をカウントすることは、これらの区間にわたる包含カウント問題になり (通常はソート + フェンウィック ツリー/BIT で解決されます)、実行可能なアルゴリズムが得られます。$N=10^{10}$。 このメソッドは、指定されたチェックを再現します。 

-$B(10\,000)=49$-$B(1\,000\,000)=38239$そして最終的な値が得られます。$$B(10\,000\,000\,000)=2\,466\,018\,557$$既知の Project Euler ターゲット値を返し、公開されている 2 つのテスト ケースと一致する検証済みの実装によってサポートされています。 

**答え: 2466018557**
