[プロジェクト オイラー問題 431](https://projecteuler.net/problem=431)

 ## 解決策

 **答え:**`23.386029052`サイロに半径を持たせる$R$、ポイントから穀物を注ぐようにしてください。$(x,0)$シリンダーの上部にあります。 

安息角がある場合$\alpha$、その後、粒子の自由表面が傾斜を作ります$$\tan\alpha$$水平で。 

どの点でも$(u,v)$したがって、円形断面では、粒子上の垂直方向の空の高さは次のようになります。$$h(u,v)=\tan\alpha\;\sqrt{(u-x)^2+v^2}.$$したがって、無駄な体積は次のようになります。$$V(x)=\tan\alpha\iint_D \sqrt{(u-x)^2+v^2}\,dA,$$どこ$D$ディスクです$u^2+v^2\le R^2$。 

---

 #1. 積分値の変換

 流出点を中心とする極座標を使用します。$$u=x+r\cos\theta,\qquad v=r\sin\theta.$$方向に沿って$\theta$、レイは次のときにサイロから出ます。$$(x+r\cos\theta)^2+(r\sin\theta)^2=R^2.$$を解決する$r$、$$r_{\max}(\theta) = -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta}.$$被積分関数は単純なので、$r$、$$V(x) = \tan\alpha \int_0^{2\pi}\int_0^{r_{\max}(\theta)} r\cdot r\,dr\,d\theta.$$したがって$$\boxed{ V(x)= \frac{\tan\alpha}{3} \int_0^{2\pi} \left( -x\cos\theta+\sqrt{R^2-x^2\sin^2\theta} \right)^3 d\theta }.$$---

 #2. 例の確認

 ステートメントの最初の例では、次のものが使用されます。 

- 直径$6\Rightarrow R=3$、
 -$\alpha=30^\circ$、
 -$x=0$。 

それから$$V(0) = \frac{\tan30^\circ}{3} \int_0^{2\pi} 3^3\,d\theta = 18\pi\tan30^\circ = 6\pi\sqrt3 \approx 32.648388556,$$これは問題のステートメントと正確に一致します。 

したがって、式は正しいです。 

---

 #3. 実際の問題データ

 今すぐ使用してください:$$R=6,\qquad \alpha=40^\circ.$$私たちはすべてを求めます$x\in[0,6]$そのような$V(x)$は完全な正方形です。 

以来$V(x)$厳密に増加しています$x$、各正方形には最大でも 1 つの解決策があります。 

範囲を計算します。$$V(0)\approx 379.60, \qquad V(6)\approx 644.43.$$したがって、可能な完全正方形は次のとおりです。$$20^2,21^2,22^2,23^2,24^2,25^2.$$数値的に解く$V(x)=n^2$それぞれに$n=20,\dots,25$与える:$$\begin{aligned} x_{20}&\approx1.6097585009208716,\\ x_{21}&\approx2.8060119465435142,\\ x_{22}&\approx3.6783279154320040,\\ x_{23}&\approx4.4264032917821366,\\ x_{24}&\approx5.1094202074447333,\\ x_{25}&\approx5.7561071894994169. \end{aligned}$$合計:$$\sum x = 23.386029051622676\ldots$$四捨五入して$9$小数点以下の桁数:$$\boxed{23.386029052}$$---

 #4. Pythonの実装```python
import mpmath as mp

mp.mp.dps = 50

R = mp.mpf(6)
alpha = mp.radians(40)
T = mp.tan(alpha)

# Volume function
def V(x):
    def integrand(theta):
        return (
            -x * mp.cos(theta)
            + mp.sqrt(R*R - x*x * mp.sin(theta)**2)
        ) ** 3

    return (T / 3) * mp.quad(integrand, [0, 2 * mp.pi])

# Solve V(x) = n^2 by bisection
def solve_for_square(n):
    target = n * n

    lo = mp.mpf(0)
    hi = R

    for _ in range(100):
        mid = (lo + hi) / 2

        if V(mid) < target:
            lo = mid
        else:
            hi = mid

    return (lo + hi) / 2

roots = []

for n in range(20, 26):
    x = solve_for_square(n)
    roots.append(x)
    print(n, x)

answer = mp.fsum(roots)

print("Sum =", answer)
print("Rounded =", mp.nstr(answer, 12))
```---

 #5. コードのチュートリアル

 -`V(x)`上記で導出された正確な積分公式を実装します。 
- 角度ごとに`theta`、円盤内の光線の長さは```python
-x*cos(theta) + sqrt(R^2 - x^2*sin(theta)^2)
```- 内半径積分は係数に寄与します$r^3/3$。 
- 数値的に積分します$[0,2\pi]$。 
- 以来$V(x)$単調で、二等分は安全に解決されます$$V(x)=n^2.$$- からの正方形のみ$20^2$に$25^2$達成可能な範囲内にあります。
