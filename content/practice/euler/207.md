 ## 解決策

 **答え:**`44043947822`させて$$4^t = 2^t + k.$$正の整数について質問されます$k$そのようなパーティションが存在するもの、およびその中で、$t\in\mathbb Z$(「完璧な」パーティション)。 

私たちは最小のものを望んでいます$m$そのような$$P(m) < \frac1{12345},$$どこ$P(m)$を含むパーティションの割合です。$k\le m$それは完璧です。 

---

 # ステップ 1: 方程式を書き直す

 セット$$x = 2^t.$$それから$$4^t = (2^t)^2 = x^2,$$したがって、定義式は次のようになります$$x^2 = x + k.$$したがって、$$k = x^2 - x = x(x-1).$$以来$k$整数でなければなりません、$x$同様に整数でなければなりません (なぜなら、$x$モニック多項式を満たす$x^2-x-k=0$; 整数ルート条件は次のようになります$x\in\mathbb Z$）。 

したがって、すべてのパーティションは整数に正確に対応します$$x=n\ge2,$$と$$k=n(n-1).$$したがって、許容されるのは$k$はまさに$$2,6,12,20,30,\dots$$例と一致します。 

---

 # ステップ 2: 完璧なパーティションの特徴を明らかにする

 パーティションは次のような場合に最適です。$t$は整数です。 

しかし$x=2^t$。 したがって：

-$t\in\mathbb Z$- もしも$x$は 2 の累乗です。 

したがって、完璧なパーティションは次のようになります。$$x=2^a \quad (a\ge1),$$与える$$k = 2^a(2^a-1).$$---

 # ステップ 3: パーティションを次まで数えます$m$すべてのパーティションは整数によってインデックス付けされます$n\ge2$と$$k=n(n-1)\le m.$$そのような最大のものを仮定します$n$は$N$。 それから$$N(N-1)\le m < (N+1)N.$$したがって、パーティションの総数は次のようになります。$m$は$$N-1$$（以来$n=2,3,\dots,N$）。 

次に、完全なパーティションを数えます。 

完全なパーティションは次の場合に発生します。$n$は 2 のべき乗です:$$n=2,4,8,\dots,2^A\le N.$$したがって、完全な分割の数は次のようになります。$$A,$$どこ$$A=\lfloor \log_2 N\rfloor.$$したがって$$P(m)=\frac{\lfloor \log_2 N\rfloor}{N-1}.$$---

 # ステップ 4: 不等式を解く

 必要です$$\frac{\lfloor \log_2 N\rfloor}{N-1}<\frac1{12345}.$$させて$$a=\lfloor \log_2 N\rfloor.$$それから$$2^a \le N < 2^{a+1}.$$不平等はこうなる$$12345a < N-1,$$または$$N > 12345a+1.$$最小限に抑えるには$m$を最小限に抑えます$N$。 したがって、それぞれについて$a$、最小の候補は$$N = 12345a+2.$$でもこれ$N$満たさなければなりません$$\lfloor \log_2 N\rfloor = a,$$つまり$$2^a \le 12345a+2 < 2^{a+1}.$$の値をテストします$a$。 

-$a=16$:$$12345\cdot16+2=197522,$$しかし$$2^{16}=65536,\qquad 2^{17}=131072.$$大きすぎます。 

-$a=17$:$$12345\cdot17+2=209867,$$そして$$2^{17}=131072,\qquad 2^{18}=262144.$$これは機能します。 

したがって、有効な最小値は$N$は$$N=209867.$$次に、対応する最小の$m$まさにこれの最小値です$N$、つまり$$m=N(N-1).$$それで$$m=209867\cdot209866.$$計算:$$209867^2 = 44\,044\,151\,689,$$したがって$$m=209867^2-209867 =44\,044\,151\,689-209\,867 =44\,043\,941\,822.$$---

 # Pythonの実装```python
import math

TARGET = 12345

a = 1

while True:
    # smallest N satisfying:
    # a / (N - 1) < 1 / TARGET
    N = TARGET * a + 2

    # check whether floor(log2(N)) == a
    if (1 << a) <= N < (1 << (a + 1)):
        m = N * (N - 1)
        print(m)
        break

    a += 1
```---
