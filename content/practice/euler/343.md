私たちは定義します$f(k)$プロセスが最初に分母を取得したときに到達する整数になります。$1$。 

例えば：$$\frac1{20}\to\frac2{19}\to\frac3{18}=\frac16\to\cdots\to\frac61=6$$それで$f(20)=6$。 

計算しなければなりません$$\sum_{k=1}^{2\cdot10^6} f(k^3).$$---

 #1. 数学的分析

 ## ステップ 1: 非還元シーケンスを記述する

 削減はしばらく無視してください。 

から始まる$$\frac1k,$$各ステップが追加します$1$分子に代入して減算します$1$分母からなので、その後$m-1$得られるステップ$$\frac{m}{k+1-m}.$$リダクションでは、分子と分母を gcd で割るだけです。 

したがって、実際の換算分数は次のようになります。$$\frac{m/g}{(k+1-m)/g}, \qquad g=\gcd(m,k+1-m).$$しかし$$\gcd(m,k+1-m)=\gcd(m,k+1).$$したがって、削減後の分母は次のようになります。$$\frac{k+1-m}{\gcd(m,k+1)}.$$これが等しい場合、シーケンスは停止します。$1$、つまり$$k+1-m \mid m.$$以来$k+1-m\mid (k+1)$自動的に、停止条件は次のようになります。$$d:=k+1-m$$の約数でなければなりません$k+1$。 

それから$$m=k+1-d,$$結果の整数は$$\frac{m}{d} = \frac{k+1-d}{d} = \frac{k+1}{d}-1.$$---

 ## ステップ 2: どの除数が最初に発生しますか?

 プロセスが実行されると、分母は$$d=k+1-m$$から減少します$k$まで$1$。 

したがって、_最初_に停止するときは、**最小の約数に相当します。$d>1$** の$k+1$、つまり最小の素因数:$$d=\operatorname{spf}(k+1).$$したがって、$$f(k) = \frac{k+1}{\operatorname{spf}(k+1)}-1.$$しかし$$\frac{k+1}{\operatorname{spf}(k+1)}$$はまさに**最大の素因数**です$k+1$いつ$k+1$ここで関連する因数分解構造では平方自由です。 より一般的には、量は最小の素因数を削除した後の最大の余因子に等しくなります。 より明確な同等のアイデンティティは次のとおりです。$$f(k)=\operatorname{lpf}(k+1)-1,$$どこ$\operatorname{lpf}(n)$は最大の素因数を表します$n$。 

チェック：

-$k=20$:$$21=3\cdot7,\quad \operatorname{lpf}(21)=7,$$それで$$f(20)=7-1=6.$$-$k=12$:$$13\text{ prime},$$それで$$f(12)=13-1=12.$$正しい。

 #2. 適用先$k^3$必要です$$f(k^3)=\operatorname{lpf}(k^3+1)-1.$$ここで次のことを考慮します。$$k^3+1=(k+1)(k^2-k+1).$$したがって、問題はこれらの数値の最大の素因数を計算することになります。$$1\le k\le 2\cdot10^6.$$二次項は次の条件を満たします$$k^2-k+1 \le 4\cdot10^{12},$$その平方根は$2\cdot10^6$。 したがって、次までのすべての素数による除算を試行します。$2\cdot10^6$で十分です。そのような素因数をすべて削除した後、残りの因数はそれ自体が素数でなければなりません。

 #3. 効率的なアルゴリズム

 素数をふるいにかけます$2\cdot10^6$。 

それぞれについて$k$:

 - 初期化する$$r_k=k^2-k+1.$$素数ごとに$p$：

- 解決する$$k^2-k+1\equiv0\pmod p.$$この合同式には次のような特徴があります。 

- 1 つのルート$p=3$、
 - 2つのルートの場合$p\equiv1\pmod3$、
 - それ以外の場合は根がありません。 

すべてのソリューションクラスのモジュロに対して$p$、等差数列をたどり、次のすべてのべき乗を分割します。$p$。 

見つかった最大の素因数を追跡します。 

最後に次の最大の素因数と比較します。$k+1$。 

複雑さは本質的に線形対数的であり、Python では簡単に十分に高速です。

 #4. Pythonの実装```python
from array import array
import sympy as sp

N = 2_000_000

# ---------------------------------------------------------
# Sieve primes up to N
# ---------------------------------------------------------
is_prime = bytearray(b"\x01") * (N + 1)
is_prime[0] = is_prime[1] = 0

primes = []

for i in range(2, N + 1):
    if is_prime[i]:
        primes.append(i)

        if i * i <= N:
            is_prime[i * i : N + 1 : i] = (
                b"\x00" * (((N - i * i) // i) + 1)
            )

# ---------------------------------------------------------
# largest prime factor of k+1
# ---------------------------------------------------------
lpf_small = array('I', (0 for _ in range(N + 2)))

for p in primes:
    for m in range(p, N + 2, p):
        lpf_small[m] = p

# ---------------------------------------------------------
# values[k-1] = k^2 - k + 1
# mx[k-1] = largest prime factor found so far
# ---------------------------------------------------------
values = array('Q', (k * k - k + 1 for k in range(1, N + 1)))
mx = array('Q', (0 for _ in range(N)))

# ---------------------------------------------------------
# Factor k^2 - k + 1 using modular roots
# ---------------------------------------------------------
for p in primes:

    # Roots of x^2 - x + 1 mod p

    if p == 3:
        roots = [2]

    elif p % 3 != 1:
        continue

    else:
        # (2x - 1)^2 ≡ -3 (mod p)
        r = sp.sqrt_mod(-3, p, all_roots=False)

        inv2 = pow(2, -1, p)

        roots = [
            ((1 + r) * inv2) % p,
            ((1 - r) * inv2) % p
        ]

    for r in roots:

        if r == 0:
            r = p

        for k in range(r, N + 1, p):

            idx = k - 1

            while values[idx] % p == 0:
                values[idx] //= p

            mx[idx] = p

# ---------------------------------------------------------
# Remaining values > 1 are prime
# ---------------------------------------------------------
total = 0

for k in range(1, N + 1):

    remaining = values[k - 1]

    largest = max(
        mx[k - 1],
        remaining,
        lpf_small[k + 1]
    )

    total += largest - 1

print(total)
```---
