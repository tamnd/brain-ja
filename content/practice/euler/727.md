[プロジェクト オイラー問題 727](https://projecteuler.net/problem=727)

 ## 解決策

 **答え:**`3.64039141`互いに接している 3 つの円に中心があるとします。$A,B,C$と半径$a,b,c$それぞれ。 

次のように円を座標に配置します。 

-$A=(0,0)$-$B=(a+b,0)$-$C=(x,y)$円は外接しているので、$$|AC|=a+c,\qquad |BC|=b+c.$$それで$$x=\frac{(a+c)^2+(a+b)^2-(b+c)^2}{2(a+b)},$$

$$y=\sqrt{(a+c)^2-x^2}.$$接点は次のとおりです。 

- の間$A,B$:$$P_{ab}=(a,0)$$- 間$A,C$:$$P_{ac}=\frac{a}{a+c}C$$- 間$B,C$:$$P_{bc}=B+\frac{b}{b+c}(C-B).$$外心$D$三角形の外心です$(P_{ab},P_{ac},P_{bc})$。 

ソディ円の内側の半径は、デカルトの定理によって与えられます。$$k_4=k_1+k_2+k_3+2\sqrt{k_1k_2+k_2k_3+k_3k_1},$$どこ$k_i=1/r_i$、したがって$$r=\frac1{k_4}.$$その中心$E$満足する$$|EA|=a+r,\quad |EB|=b+r.$$ついに、$$d=|DE|.$$私たちは平均します$d$すべての共素トリプルにわたって$$1\le a<b<c\le100.$$使用したPythonコード:```python
from math import sqrt, gcd

def dist(p, q):
    return ((p[0]-q[0])**2 + (p[1]-q[1])**2) ** 0.5

def circumcenter(p1, p2, p3):
    ax, ay = p1
    bx, by = p2
    cx, cy = p3

    d = 2 * (ax*(by-cy) + bx*(cy-ay) + cx*(ay-by))

    ux = (
        (ax*ax + ay*ay)*(by-cy)
        + (bx*bx + by*by)*(cy-ay)
        + (cx*cx + cy*cy)*(ay-by)
    ) / d

    uy = (
        (ax*ax + ay*ay)*(cx-bx)
        + (bx*bx + by*by)*(ax-cx)
        + (cx*cx + cy*cy)*(bx-ax)
    ) / d

    return (ux, uy)

def compute(a, b, c):
    A = (0.0, 0.0)
    B = (a + b, 0.0)

    x = ((a+c)**2 + (a+b)**2 - (b+c)**2) / (2*(a+b))
    y = sqrt((a+c)**2 - x*x)

    C = (x, y)

    Pab = (a, 0.0)

    Pac = (
        a*x/(a+c),
        a*y/(a+c)
    )

    Pbc = (
        B[0] + b*(x-B[0])/(b+c),
        b*y/(b+c)
    )

    D = circumcenter(Pab, Pac, Pbc)

    k1, k2, k3 = 1/a, 1/b, 1/c

    k4 = (
        k1 + k2 + k3
        + 2*sqrt(k1*k2 + k2*k3 + k3*k1)
    )

    r = 1 / k4

    ex = (
        (a+r)**2 - (b+r)**2 + (a+b)**2
    ) / (2*(a+b))

    ey = sqrt((a+r)**2 - ex*ex)

    E = (ex, ey)

    return dist(D, E)

total = 0.0
count = 0

for a in range(1, 101):
    for b in range(a+1, 101):
        for c in range(b+1, 101):
            if gcd(gcd(a, b), c) == 1:
                total += compute(a, b, c)
                count += 1

answer = total / count
print(answer)
```これにより、$$3.640391406429808$$これは次のように小数点以下 8 桁に四捨五入されます。 

**答え: 3.64039141**
