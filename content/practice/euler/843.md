[プロジェクト オイラー問題 843](https://projecteuler.net/problem=843)

 ## 解決策

 **答え:**`2816775424692`円上の数字を次のようにします$a_0,a_1,\dots,a_{n-1}$、インデックス付きモジュロ$n$。 

プロセスの 1 つのステップで置き換えられます。$$a_i \longmapsto |a_{i-1}-a_{i+1}|.$$重要な事実は、起こり得る最終的な期間のセットは完全に法で決定されるということです。$2$。 

モジュロ$2$、$$|x-y|\equiv x+y \pmod 2,$$もう終わった$\mathbb F_2$マップは線形変換になります$$T(a_i)=a_{i-1}+a_{i+1}.$$これは古典的な Rule-90 セル オートマトンです。 

---

 #1. 代数的定式化

 状態を多項式で表す$$A(x)=\sum_{i=0}^{n-1} a_i x^i$$リングの中で$$R_n=\mathbb F_2[x]/(x^n-1).$$次に、1回の反復は単純に$$A(x)\mapsto (x+x^{-1})A(x).$$以来$x^{-1}=x^{n-1}$商のリングでは、$$T(A)=(x+x^{n-1})A.$$したがって、ダイナミクスは有限リングの固定要素による乗算です。$R_n$。 

---

 #2. 期間の構造

 書く$$n=2^s m,\qquad m\ \text{odd}.$$以上$\mathbb F_2$、$$x^n-1=(x^m-1)^{2^s}.$$要素$x^m-1$還元不可能なものに：$$x^m-1=\prod_i f_i(x).$$各要素はダイナミクスの独立したコンポーネントを与えます。 

還元不可能な要因としては$f$、 させて$\alpha$～の根になる$f$。 

そのコンポーネントでは、マップは次の乗算によって機能します。$$\beta=\alpha+\alpha^{-1}.$$そのコンポーネントによって寄与される期間は、次の乗算次数です。$\beta$によって生成される有限場の中で$\alpha$。 

もし$n$要因がある$2^s$、因数が繰り返されると、追加の 2 のべき乗乗数が導入されます。$2^b$と$0\le b\le s$。 

したがって:

 - 各既約因数は基本的な奇数周期に寄与します$o$、
 - 可能な期間は、構成要素期間の最小公倍数を取得することによって取得されます。 
- 繰り返された因数から得られる 2 の累乗を掛けます。 

労働組合をすべてを掌握する$3\le n\le N$合計が次のような集合を与えます$S(N)$。 

---

 #3. 例の検証

 のために$3\le n\le 6$:

 -$n=3$: ピリオド$\{1\}$-$n=4$: ピリオド$\{1\}$-$n=5$: ピリオド$\{1,3\}$-$n=6$: ピリオド$\{1,2\}$連合：$$\{1,2,3\}$$それで$$S(6)=1+2+3=6,$$ステートメントと一致します。 

のために$N=30$、計算により正確に得られます$$S(30)=20381,$$再び問題文と一致します。

 #4. Pythonの実装```python
import math
import sympy as sp

x = sp.symbols('x')

# convert a GF(2) polynomial to bit representation
def poly_to_int(poly):
    v = 0
    for (e,), c in poly.terms():
        if int(c) & 1:
            v |= (1 << e)
    return v

# multiplication in GF(2)[x]/(modpoly)
def mul(a, b, modpoly, deg):
    r = 0
    while b:
        if b & 1:
            r ^= a
        b >>= 1
        a <<= 1
        if a >> deg:
            a ^= modpoly
    return r

def powmod(a, e, modpoly, deg):
    r = 1
    while e:
        if e & 1:
            r = mul(r, a, modpoly, deg)
        a = mul(a, a, modpoly, deg)
        e >>= 1
    return r

# multiplicative order in the finite field
def order(a, modpoly, deg):
    group_order = (1 << deg) - 1
    ans = group_order

    for p, e in sp.factorint(group_order).items():
        for _ in range(e):
            if powmod(a, ans // p, modpoly, deg) == 1:
                ans //= p
            else:
                break

    return ans

def periods_for_n(n):
    # n = 2^s * m  with m odd
    s = 0
    m = n
    while m % 2 == 0:
        s += 1
        m //= 2

    poly = sp.Poly(x**m - 1, x, modulus=2)
    factors = sp.factor_list(poly, modulus=2)[1]

    component_choices = []

    for f, _ in factors:

        # ignore x+1 (gives only the trivial fixed point)
        if f.degree() == 1:
            continue

        deg = f.degree()
        modpoly = poly_to_int(f)

        alpha = 2                      # polynomial x
        alpha_inv = powmod(alpha, m - 1, modpoly, deg)

        beta = alpha ^ alpha_inv       # alpha + alpha^{-1} over GF(2)

        odd_period = order(beta, modpoly, deg)

        choices = [1]
        for b in range(s + 1):
            choices.append(odd_period * (1 << b))

        component_choices.append(choices)

    periods = {1}

    for choices in component_choices:
        new_periods = set()
        for a in periods:
            for b in choices:
                new_periods.add(math.lcm(a, b))
        periods = new_periods

    return periods

def S(N):
    all_periods = set()

    for n in range(3, N + 1):
        all_periods |= periods_for_n(n)

    return sum(all_periods)

print(S(30))   # 20381
print(S(100))
