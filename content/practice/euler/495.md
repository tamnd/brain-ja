[プロジェクト オイラー問題 495](https://projecteuler.net/problem=495)

 ## 解決策

 **答え:**`789107601`させて$$N=n!=\prod_{p\le n} p^{e_p}, \qquad e_p=\sum_{j\ge1}\left\lfloor \frac n{p^j}\right\rfloor .$$数値を計算しなければなりません$W(N,k)$順序なし因数分解の$$N=a_1a_2\cdots a_k$$の中へ$k$**異なる**正の整数。 

この問題については:$$N=10000!,\qquad k=30.$$---

 #1. 数学的分析

 ## ステップ 1: 順序付き因数分解

 注文されたものを数えるとしましょう$k$-タプル$(a_1,\dots,a_k)$製品付き$N$。 

素数ごとに$p$、$$a_i=\prod_p p^{x_{i,p}}, \qquad \sum_{i=1}^k x_{i,p}=e_p.$$したがって、固定素数の場合$p$、指数分布は星と棒の数です。$$\binom{e_p+k-1}{k-1}.$$したがって、順序因数分解の数は次のようになります。$$F_k(N)=\prod_{p\mid N}\binom{e_p+k-1}{k-1}.$$しかし、これにより等しい係数が可能になります。 すべての要素を区別する必要があります。 

---

 ## ステップ 2: 等価性の包含と除外

 すべてのエントリが異なる順序付けされたタプルをカウントします。 

させて$\sigma\in S_k$。 

タプルが次のように修正される場合$\sigma$、次に同じサイクルのエントリ$\sigma$等しくなければなりません。 

仮定する$\sigma$サイクル長がある$$\lambda=(\lambda_1,\lambda_2,\dots,\lambda_r), \qquad \sum \lambda_i=k.$$したがって、各サイクルは 1 つの独立変数に対応します。$b_i$、 そして$$N=\prod_{i=1}^r b_i^{\lambda_i}.$$素指数の場合$e$の解の数が必要です。$$\lambda_1x_1+\cdots+\lambda_rx_r=e, \qquad x_i\ge0.$$これはまさに次の係数です$t^e$で$$\prod_{i=1}^r \frac1{1-t^{\lambda_i}}.$$定義する$$A_\lambda(e) = [t^e]\prod_i \frac1{1-t^{\lambda_i}}.$$次に、サイクルタイプの順列によって固定されるタプルの数$\lambda$は$$\prod_{p\mid N} A_\lambda(e_p).$$---

 ## ステップ 3: 分割格子上のメビウス反転

 すべてのエントリが異なる順序付けられたタプルの数は次のとおりです。$$D_k(N) = \sum_{\lambda\vdash k} (-1)^{k-\ell(\lambda)} \frac{k!}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p),$$どこ$$z_\lambda=\prod_j j^{m_j}m_j!,$$そして$m_j$部分の多重度です$j$で$\lambda$。 

最後に、順序なし因数分解は次のように除算されます。$k!$:$$W(N,k)=\frac{D_k(N)}{k!}.$$それで：$$\boxed{ W(N,k) = \sum_{\lambda\vdash k} \frac{(-1)^{k-\ell(\lambda)}}{z_\lambda} \prod_{p\mid N} A_\lambda(e_p) }$$(モジュロ$10^9+7$）。 

---

 #2. Pythonの実装```python
from collections import Counter
from math import factorial
from sympy import primerange

MOD = 1_000_000_007

# ------------------------------------------------------------
# Generate integer partitions of n
# ------------------------------------------------------------
def partitions(n, mx=None):
    if mx is None or mx > n:
        mx = n

    if n == 0:
        yield []
        return

    for first in range(mx, 0, -1):
        for rest in partitions(n - first, first):
            yield [first] + rest

# ------------------------------------------------------------
# Prime exponents in n!
# ------------------------------------------------------------
def factorial_prime_exponents(n):
    exps = []

    for p in primerange(1, n + 1):
        e = 0
        m = n

        while m:
            m //= p
            e += m

        exps.append(e)

    return exps

# ------------------------------------------------------------
# Compute W(n!, k) modulo MOD
# ------------------------------------------------------------
def W_factorial(n, k):
    exps = factorial_prime_exponents(n)
    max_e = max(exps)

    fact_k = factorial(k)
    inv_fact_k = pow(fact_k, MOD - 2, MOD)

    answer = 0

    for lam in partitions(k):

        # ----------------------------------------------------
        # Compute A_lambda(e) for all e <= max_e
        #
        # dp[e] = coefficient of:
        #   product 1/(1 - x^part)
        # ----------------------------------------------------
        dp = [0] * (max_e + 1)
        dp[0] = 1

        for part in lam:
            for e in range(part, max_e + 1):
                dp[e] += dp[e - part]
                dp[e] %= MOD

        # Product over all prime exponents
        prod = 1
        for e in exps:
            prod = (prod * dp[e]) % MOD

        # z_lambda
        c = Counter(lam)

        z = 1
        for part, mult in c.items():
            z *= (part ** mult) * factorial(mult)

        # permutation count k!/z_lambda
        term = (fact_k // z) % MOD

        # sign
        if (k - len(lam)) % 2:
            term = -term

        answer = (answer + term * prod) % MOD

    answer %= MOD

    # divide by k!
    answer = (answer * inv_fact_k) % MOD

    return answer

# ------------------------------------------------------------
# Checks from the statement
# ------------------------------------------------------------
print(W_factorial(100, 10))
# 287549200

# Final answer
print(W_factorial(10000, 30))
```---

 #3. コードのチュートリアル

 ###`partitions(n)`すべての整数パーティションを生成します。$n$。 

のために$k=30$、あるだけです$5604$パーティション。 

---

 ###`factorial_prime_exponents(n)`ルジャンドルの公式を使用します。$$e_p(n!)=\sum_{j\ge1}\left\lfloor\frac{n}{p^j}\right\rfloor.$$のために$10000!$、 がある$1229$素数。 

---

 ### 動的プログラミング$A_\lambda(e)$パーティション用$\lambda=(\lambda_1,\dots,\lambda_r)$、$$\prod_i \frac1{1-x^{\lambda_i}}$$無制限のナップザック DP によって展開されます。```python
for part in lam:
    for e in range(part, max_e + 1):
        dp[e] += dp[e - part]
```それから：```python
dp[e]
```等しい$$A_\lambda(e).$$---

 ### 包含-除外用語

 サイクルタイプの場合$\lambda$、$$\frac{k!}{z_\lambda}$$そのサイクル構造を持つ順列をカウントします。 

記号は次のとおりです。$$(-1)^{k-\ell(\lambda)}.$$---

 #4. 検証

 実装では公式チェックを再現します。$$W(100!,10)\equiv 287549200 \pmod{10^9+7}.$$また、次のことも再現されます。$$W(144,4)=7.$$したがって、導出と実装は一貫しています。 

プログラムを実行する$10000!,30$与える:$$789107601.$$---

 **答え: 789107601**
