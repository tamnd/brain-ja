[プロジェクト オイラー問題 883](https://projecteuler.net/problem=883)

 ## 解決策

 **答え:**`14854003484704`六方格子をアイゼンシュタインの整数で識別してみましょう$$\Lambda=\{a+b\omega : a,b\in \mathbb Z,\ \omega=e^{i\pi/3}\},$$二次ノルム付き$$N(a+b\omega)=a^2+ab+b^2.$$したがって、格子点間の距離の二乗は正確に次の値になります。$$Q(x,y)=x^2+xy+y^2.$$三角形を数えなければなりません。 

- 頂点あり$\Lambda$、
 - インセンターも付いています$\Lambda$、
 - 少なくとも 1 つある$60^\circ$角度、
 - 翻訳までのみカウントアップ、
 - ただし、回転/反射は個別にカウントされます。 

---

 #1. の幾何学$60^\circ$六角格子上の三角形

 を入れてください$60^\circ$原点の頂点。 

その角度に隣接する 2 つの辺をベクトルとする$u,v\in\Lambda$、角度付き$60^\circ$彼らの間で。 

格子基底を使用すると、そのようなすべてのペアは 2 つの互いに素な整数によってパラメータ化できます。$k>l>0$:$$u=(k,l),\qquad v=(l,k).$$辺の長さは次のようになります。$$|u|=\sqrt{k^2+kl+l^2},\qquad |v|=\sqrt{k^2+kl+l^2},$$3番目の辺は長さを持ちます$$|u-v|=\sqrt{k^2-kl+l^2}.$$定義する$$s=\sqrt{k^2-kl+l^2}.$$三角形が格子内心力を持つ条件$s\in\mathbb Z$。 

の半径$60^\circ$三角形は満たす$$r=\frac{\sqrt3}{2}\cdot \frac{ab}{a+b+c},$$上記のパラメータ化を代入すると、次のようになります。$$r^2=\frac{Q(p)}{12d^2},$$どこ$$d=k+l-s,$$そして$p$は原始格子ベクトルです。 

したがって、注目すべき三角形を数えるということは、以下を満たす格子ベクトルを数えるということになる。$$Q(p)\le \frac{12R^2}{d^2}.$$---

 #2. 算術構造

 の整数解$$k^2-kl+l^2=s^2$$二つの家族に分かれる。 

---

 ## 家族 1$$d=3uv,$$どこ$$u>v,\qquad \gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$固定用$t=uv$、そのようなペアの数は次のとおりです$$2^{\omega(t)-1},$$どこ$\omega(t)$は個別の素因数の数です。 

この家族は次の場合にのみ存在します。$$t\not\equiv 1\pmod3.$$---

 ## ファミリー 2

 しましょう$$a=u-v.$$それから$$d=a(a+3v),$$と$$\gcd(u,v)=1,\qquad u\not\equiv v\pmod3.$$したがって、許容されるすべての$d$多重性がある$M[d]$。 

---

 #3. 格子点を数える

 を満たす整数ペアの数が必要です。$$x^2+xy+y^2\le B.$$この数量を呼び出します$N(B)$。 

古典的なアイデンティティが与える$$N(B) = 1+6\sum_{n\le B}\chi(n)\Big\lfloor\frac{B}{n}\Big\rfloor,$$どこ$\chi$自明でないディリクレ文字モジュロです$3$:$$\chi(n)= \begin{cases} 1,&n\equiv1\pmod3,\\ -1,&n\equiv2\pmod3,\\ 0,&n\equiv0\pmod3. \end{cases}$$これは次のように評価できます。$O(\sqrt B)$除数ブロックのグループ化を使用します。 

---

 #4. 正三角形

 正三角形も注目に値します。 

イン半径が$r$、次に頂点ベクトル$A$満足する$$Q(A)\le 4R^2.$$それぞれの正三角形は 3 回表現されます (回転$120^\circ$）、 それで：$$T_{\text{eq}}(R)=\frac{N(4R^2)-1}{3}.$$---

 #5. 最終的なカウント公式

 あらゆる許容範囲に対して$d$、$$B=\left\lfloor \frac{12R^2}{d^2}\right\rfloor.$$もし$3\mid d$、すべての格子点が許可されます。 それ以外の場合は、インデックス 3 の副格子のみが寄与します。 

したがって、$$T(R) = 2\sum_d M[d]\cdot P_d(R) + \frac{N(4R^2)-1}{3},$$どこ$$P_d(R)= \begin{cases} N(B)-1,&3\mid d,\\[4pt] N(\lfloor B/3\rfloor)-1,&3\nmid d. \end{cases}$$要因$2$反映された構成を考慮します。

 #6. Pythonの実装```python
from array import array
from math import gcd, isqrt

def count_hex_points_leq(B, cache):
    """
    Count integer pairs (x,y) with x^2 + x*y + y^2 <= B.
    """

    if B <= 0:
        return 1

    if B in cache:
        return cache[B]

    def chi_prefix(m):
        # count of 1 mod 3 minus count of 2 mod 3
        return (m + 2) // 3 - (m + 1) // 3

    total = 0
    i = 1

    while i <= B:
        q = B // i
        j = B // q

        total += q * (chi_prefix(j) - chi_prefix(i - 1))
        i = j + 1

    ans = 1 + 6 * total
    cache[B] = ans
    return ans

def remarkable_triangles(R_num, R_den=1):

    Dmax = isqrt((12 * R_num * R_num) // (R_den * R_den))

    # multiplicity for each d
    M = array("I", [0]) * (Dmax + 1)

    #
    # ---- Family 1 ----
    #

    Nmax = Dmax // 3

    omega = array("B", [0]) * (Nmax + 1)

    for p in range(2, Nmax + 1):
        if omega[p] == 0:
            for k in range(p, Nmax + 1, p):
                omega[k] += 1

    for t in range(2, Nmax + 1):

        if t % 3 == 1:
            continue

        M[3 * t] += 1 << (omega[t] - 1)

    #
    # ---- Family 2 ----
    #

    vmax = Dmax // 3

    for v in range(1, vmax + 1):

        disc = 9 * v * v + 4 * Dmax
        amax = (isqrt(disc) - 3 * v) // 2

        for a in range(1, amax + 1):

            u = v + a

            if u % 3 == v % 3:
                continue

            if gcd(u, v) != 1:
                continue

            d = a * (a + 3 * v)
            M[d] += 1

    #
    # ---- Main summation ----
    #

    cache = {}

    total_scalene = 0

    C_num = 12 * R_num * R_num
    C_den = R_den * R_den

    for d in range(1, Dmax + 1):

        mult = M[d]

        if mult == 0:
            continue

        B = C_num // (C_den * d * d)

        if B == 0:
            continue

        if d % 3 == 0:
            pts = count_hex_points_leq(B, cache) - 1
        else:
            pts = count_hex_points_leq(B // 3, cache) - 1

        total_scalene += 2 * mult * pts

    #
    # ---- Equilateral triangles ----
    #

    Beq = (4 * R_num * R_num) // (R_den * R_den)

    equi_points = count_hex_points_leq(Beq, cache) - 1
    total_equilateral = equi_points // 3

    return total_scalene + total_equilateral

# verification
print(remarkable_triangles(1, 2))   # 2
print(remarkable_triangles(2))      # 44
print(remarkable_triangles(10))     # 1302

# final answer
print(remarkable_triangles(10**6))
