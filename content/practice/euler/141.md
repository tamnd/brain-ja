[プロジェクト オイラー問題 141](https://projecteuler.net/problem=141)

 ## 解決策

 **答え:**`878454337159`させて$$n = dq + r,\qquad 0 \le r < d$$そして推測してください$d,q,r$等比数列の連続した項 (ある順序で) です。 

私たちはそのようなものすべてを望んでいます$n$これも完全正方形です。$$n < 10^{12}.$$---

 #1. 数学的分析

 まず等比数列をパラメータ化することから始めます。 

3 つの項が次のようになっているとします。$$a,\quad ar,\quad ar^2$$ある合理的な比率で$r$。 

以来$d,q,r$が整数の場合、比率を最小値で次のように書きます。$$\frac{u}{v}, \qquad \gcd(u,v)=1.$$次に、連続する GP 用語は次のように書くことができます。$$kv^2,\quad kuv,\quad ku^2$$正の整数の場合$k,u,v$と$\gcd(u,v)=1$。 

商が剰余よりも大きいため、可能な順序は次のとおりです。$$r = kv^2,\qquad d = kuv,\qquad q = ku^2,$$そうでなければ$r\ge d$、 不可能。 

ここで次のように置き換えます$$n = dq + r.$$取得します$$n = (kuv)(ku^2) + kv^2$$それで$$n = k^2u^3v + kv^2.$$要素：$$n = kv(ku^2 + v).$$したがって、すべての累進数は次の形式になります。$$\boxed{n = kv(ku^3 + v)}.$$---

 ## 平方条件の強制

 今必要なのは$n$完全な正方形になるように。 

重要な洞察は、四角形のないパーツを分離することです。 

させて$$k = a b^2,$$どこ$a$スクエアフリーです。 

それから$$n = ab^2v(ab^2u^3 + v).$$なぜなら$\gcd(u,v)=1$、示すことができます$$\gcd(v,\,ab^2u^3+v)=1.$$したがって、2つの要因$$v,\qquad ab^2u^3+v$$は互いに素である。 

製品時代から$a$が正方形である場合、各共素コンポーネントは正方形のない部分を適切に吸収する必要があります。 

セット$$v = ac^2,$$それから$$ab^2u^3 + v = ad^2.$$代わりの$v=ac^2$:$$ab^2u^3 + ac^2 = ad^2.$$で割る$a$:$$b^2u^3 + c^2 = d^2.$$したがって$$d^2 - c^2 = b^2u^3.$$要素：$$(d-c)(d+c)=b^2u^3.$$この時点で、総当たり検索が可能になります。 

---

 # より実用的なパラメータ化

 標準の簡略化は次から直接取得されます。$$n = kv(ku^3+v).$$なぜなら$\gcd(v,ku^3)=1$、私たちも持っています$$\gcd(v,ku^3+v)=1.$$もし$n$が平方である場合、2 つの互いに素な因数はそれぞれ共通の平方自由因数までの平方でなければなりません。 

それで、しましょう$$v = as^2,\qquad ku^3+v = at^2,$$と$a$スクエアフリー。 

減算:$$ku^3 = a(t^2-s^2)=a(t-s)(t+s).$$これにより、必然的に効率的な列挙が可能になります。 

ただし、ほとんどの高速ソリューションで使用されるさらにクリーンなルートがあります。 

---

 # 主要な代数的還元

 書く$$k = m^2 n, \qquad v = n r^2,$$と$n$スクエアフリー。 

それから$$N = kv(ku^3+v)$$になる$$N = m^2 n^2 r^2(m^2u^3+r^2).$$したがって$N$正方形であれば$$m^2u^3+r^2$$は正方形です。 

させて$$m^2u^3+r^2=s^2.$$それから$$(s-r)(s+r)=m^2u^3.$$設定しました$$s-r=a,\qquad s+r=b,$$それで$$ab=m^2u^3.$$以来$a,b$同じパリティを持ち、$$r=\frac{b-a}{2}, \qquad s=\frac{a+b}{2}.$$これにより、完全なパラメータ化が行われます。 

---

 # 効率的な列挙

 計算上より便利な定式化は恒等式から得られます。$$n = x^2 y^3 z^2 + xyz^2$$と$$\gcd(x,y)=1.$$検索範囲は十分に小さいため、$$x^2 y^3 z^2 < 10^{12}.$$以下を列挙できます。 

-$y$くらいまで$10^4$、
 -$x$まで$\sqrt{10^{12}/y^3}$、
 -$z$同様に有界です。 

見つかったすべての正方形を重複除去します。 

---

 #2. Pythonの実装```python
from math import isqrt, gcd

LIMIT = 10**12

# Use a set to avoid duplicates
progressive_squares = set()

# From:
# n = k*v*(k*u^3 + v)
#
# Let:
#   k = a*b^2
#   v = a*c^2
#
# Then:
#   n = a^2 * b^2 * c^2 * (a*b^2*u^3 + c^2)
#
# Therefore n is square iff:
#   a*b^2*u^3 + c^2
# is a square.
#
# We enumerate:
#   u, a, b, c
# under the size bound.

max_u = int(LIMIT ** (1/3)) + 2

for u in range(1, max_u):

    u3 = u**3

    # minimal contribution already grows like a^2*b^2*c^2*u^3
    # so a,b,c ranges are small.

    max_ab = isqrt(LIMIT // u3) + 1

    for a in range(1, max_ab + 1):

        # c must remain manageable
        for b in range(1, max_ab + 1):

            base = a * b * b * u3

            if base >= LIMIT:
                break

            # derive c bound from:
            # n = a^2*b^2*c^2*(base + c^2) < LIMIT

            max_c = isqrt(LIMIT // (a*a*b*b)) + 1

            for c in range(1, max_c + 1):

                # coprimality condition inherited from GP structure
                if gcd(u, c) != 1:
                    continue

                t = base + c*c
                s = isqrt(t)

                if s*s != t:
                    continue

                n = a*a*b*b*c*c*t

                if n >= LIMIT:
                    break

                root = isqrt(n)
                if root * root == n:
                    progressive_squares.add(n)

answer = sum(progressive_squares)

print(answer)
```---
