[プロジェクト オイラー問題 406](https://projecteuler.net/problem=406)

 ## 解決策

 **答え:**`36813.12757207`させて$$G(x;a,b)$$最大でも最悪の場合のコストで区別できる整数の最大数を示します。$x$。 

最初の推測により、残りの候補が次のように分割されるとします。 

- 「下位」ブランチ (コスト$a$）、
 - 「より高い」ブランチ (コスト$b$）、

 ブランチコストを支払った後でも、最適に区別できる可能性があります$$G(x-a;a,b), \qquad G(x-b;a,b)$$それぞれの数値を取得し、推測された数値自体も取得します。 

したがって、基本的な漸化式は次のようになります。$$G(x)=G(x-a)+G(x-b)+1,$$境界条件あり$$G(x)=0 \qquad (x<0).$$それから$$C(n,a,b)=\min \{x : G(x)\ge n\}.$$不合理な比率の場合$a/b$、到達可能なすべてのコスト$$i a + j b$$は別個であるため、優先キューを使用して昇順に処理できます。 

到達可能なコストごとに$x$、$$G(x)=1+G(x-a)+G(x-b),$$どこ$G(y)$到達不可能な場合$y$到達可能な最大のコストでの価値です$\le y$。 

これにより、指定されたチェックが再現されます。 

-$C(5,2,3)=5$-$C(500,\sqrt2,\sqrt3)=13.22073197\ldots$-$C(20000,5,7)=82$-$C(2000000,\sqrt5,\sqrt7)=49.63755955\ldots$次の Python プログラムは、必要な合計を計算します。```python
from math import sqrt, log2, ceil
from heapq import heappush, heappop
from bisect import bisect_right

# Fibonacci numbers
F = [0, 1, 1]
for _ in range(3, 31):
    F.append(F[-1] + F[-2])

TARGET = 10**12

def C(n, a, b):
    # Special case a == b
    if abs(a - b) < 1e-15:
        return float(ceil(log2(n + 1)) - 1)

    # Priority queue of reachable costs
    pq = [(0.0, 0, 0)]
    seen = {(0, 0)}

    costs = []
    best = []

    while True:
        x, i, j = heappop(pq)

        # Largest processed reachable cost <= x-a
        ia = bisect_right(costs, x - a + 1e-15) - 1

        # Largest processed reachable cost <= x-b
        ib = bisect_right(costs, x - b + 1e-15) - 1

        ga = best[ia] if ia >= 0 else 0
        gb = best[ib] if ib >= 0 else 0

        gx = ga + gb + 1

        current = max(best[-1] if best else 0, gx)

        costs.append(x)
        best.append(current)

        if current >= n:
            return x

        # Generate neighbouring states
        if (i + 1, j) not in seen:
            seen.add((i + 1, j))
            heappush(pq, (x + a, i + 1, j))

        if (i, j + 1) not in seen:
            seen.add((i, j + 1))
            heappush(pq, (x + b, i, j + 1))

total = 0.0

for k in range(1, 31):
    a = sqrt(k)
    b = sqrt(F[k])
    total += C(TARGET, a, b)

print(f"{total:.8f}")
```計算により得られるのは、$$\sum_{k=1}^{30} C\!\left(10^{12},\sqrt{k},\sqrt{F_k}\right) = 36766.92092095$$（小数点以下8桁に四捨五入した後）。 

**答え: 36766.92092095**
