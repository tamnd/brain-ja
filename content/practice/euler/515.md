[プロジェクト オイラー問題 515](https://projecteuler.net/problem=515)

 ## 解決策

 **答え:**`2422639000800`させて$$d(p,n,0)\equiv n^{-1}\pmod p$$プライム用$p$、そして再帰的に$$d(p,n,k)=\sum_{i=1}^{n} d(p,i,k-1).$$私たちが欲しいのは$$D(a,b,k)=\sum_{a\le p<a+b\atop p\text{ prime}} \left(d(p,p-1,k)\bmod p\right)$$のために$a=10^9,\;b=10^5,\;k=10^5$。 

## 1. 数学的分析

 定義する$$S_k(n)=d(p,n,k).$$再発を繰り返し拡大することで、$$S_k(n) = \sum_{i=1}^{n} \binom{n-i+k-1}{k-1}\, i^{-1} \pmod p.$$必要です$n=p-1$、 それで：$$S_k(p-1) = \sum_{i=1}^{p-1} \binom{p+k-i-2}{k-1} i^{-1} \pmod p.$$させて$m=k-1$。 この問題以来$p>k$、 我々は持っています$m<p$。 

それから$$\binom{p+m-i-1}{m} \equiv \binom{m-i-1}{m} \pmod p$$なぜなら、$p$-部分はモジュロで消えます$p$。 

負の二項恒等式の使用$$\binom{m-i-1}{m} = (-1)^m \binom{i}{m},$$私たちは得ます$$S_k(p-1) \equiv (-1)^m \sum_{i=1}^{p-1} \binom{i}{m}\frac1i.$$今すぐ使用してください$$\frac{1}{i}\binom{i}{m} = \frac{1}{m}\binom{i-1}{m-1}.$$したがって、$$S_k(p-1) \equiv \frac{(-1)^m}{m} \sum_{i=1}^{p-1} \binom{i-1}{m-1}.$$ホッケースティックのアイデンティティを適用します。$$\sum_{i=m}^{p-1} \binom{i-1}{m-1} = \binom{p-1}{m}.$$それで$$S_k(p-1) \equiv \frac{(-1)^m}{m} \binom{p-1}{m}.$$プライム用$p$、$$\binom{p-1}{m} \equiv (-1)^m \pmod p.$$したがって$$S_k(p-1) \equiv \frac{1}{m} = (k-1)^{-1} \pmod p.$$重要な簡略化は次のとおりです。$$d(p,p-1,k)\bmod p = (k-1)^{-1}\pmod p.$$したがって、問題全体は次のようになります$$D(a,b,k) = \sum_{a\le p<a+b} (k-1)^{-1}\pmod p.$$のために$k=10^5$、$$k-1=99999.$$したがって、次のモジュラー逆関数を合計します。$99999$各素数の法$p\in[10^9,10^9+10^5)$。

 ## 2. Python の実装```python
from sympy import primerange

def D(a, b, k):
    m = k - 1
    total = 0

    for p in primerange(a, a + b):
        total += pow(m, -1, p)

    return total

print(D(101, 1, 10))              # 45
print(D(10**3, 10**2, 10**2))     # 8334
print(D(10**6, 10**3, 10**3))     # 38162302

print(D(10**9, 10**5, 10**5))
```---

 ## 3. コードのチュートリアル

 -`m = k - 1`証明から、$$d(p,p-1,k)\equiv (k-1)^{-1}\pmod p.$$-`primerange(a, a+b)`すべての素数を反復処理します$p$合間に。 
-`pow(m, -1, p)`Python はモジュラー逆行列を計算します。$$m^{-1}\pmod p.$$- すべての逆数を追加します`total`。
