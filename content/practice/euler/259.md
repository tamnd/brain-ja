[プロジェクト オイラー問題 259](https://projecteuler.net/problem=259)

 ## 解決策

 **答え:**`20101196798`数字を文字列にします$$123456789$$そして、連続する数字のブロックから取得できるすべての値を再帰的に構築するとします。 

重要な所見は次のとおりです。 

> 数字のブロック上の有効な式は、ある位置で左の部分式と右の部分式に分割し、1 つの二項演算で結合する必要があります。 

これにより、完全な再帰構造が得られます。 

---

 #1. 数学的分析

 数字を使わなければなりません$1,2,\dots,9$正確に 1 回、順番に。 

許可される:

 - 連結、
 -$+$、$-$、$\times$、$/$、
 - 任意の括弧。 

許可されないもの:

 - 単項マイナス。 

We must find every **positive integer** obtainable and sum them.

 ---

 ## 1.1 部分問題の表現

 定義する$$F(i,j)$$連続した数字を使用して取得できるすべての有理数のセットになる$$(i+1)(i+2)\cdots j$$例えば：

-$F(0,1)=\{1\}$-$F(1,3)$数字を使う$23$-$F(0,9)$が完全な問題です。 

すべてのブロックは次のいずれかを行うことができます。 

1. 連結された 1 つの整数として使用されます。 
2. あるいはいつか分裂する$k$:$$[i,k) \quad\text{and}\quad [k,j)$$1 つの二項演算によって結合されます。 

したがって：$$F(i,j)=\{\text{concatenated integer}\} \cup \bigcup_{k=i+1}^{j-1} \left\{ a+b,\ a-b,\ a\times b,\ a/b \right\}$$みんなのために$$a\in F(i,k),\quad b\in F(k,j),$$除算を使用する場合のみ$b\neq0$。 

---

 ## 1.2 有理数が必要な理由

 中間式は整数であってはなりません。 

ステートメントの例:$$(1/23)\times((4\times5)-6)\times(78-9)=42$$したがって、正確な有理計算を維持する必要があります。 

浮動小数点を使用すると、精度エラーが発生し、個別の値が誤って結合されます。 

したがって、Python の正確な有理型を使用します。$$\texttt{Fraction}$$---

 ## 1.3 複雑さ

 あるのは次のとおりです。$$\frac{9\cdot10}{2}=45$$桁間隔。 

各間隔は、より小さい間隔を再帰的に組み合わせます。 

メモ化により計算が完全に実行可能になります。

 #2. Pythonの実装```python
from fractions import Fraction
from functools import lru_cache

digits = "123456789"

@lru_cache(None)
def values(i, j):
    """
    Returns the set of all rational values obtainable
    from digits[i:j].
    """

    result = set()

    # Option 1: concatenate all digits into one integer
    result.add(Fraction(int(digits[i:j]), 1))

    # Option 2: split into two parts
    for k in range(i + 1, j):

        left_values = values(i, k)
        right_values = values(k, j)

        for a in left_values:
            for b in right_values:

                result.add(a + b)
                result.add(a - b)
                result.add(a * b)

                if b != 0:
                    result.add(a / b)

    return result

# Compute all values using digits 1..9
all_values = values(0, 9)

# Keep only positive integers
reachable = {
    x.numerator
    for x in all_values
    if x.denominator == 1 and x > 0
}

answer = sum(reachable)

print(answer)
```---
