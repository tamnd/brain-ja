[プロジェクト オイラー問題 84](https://projecteuler.net/problem=84)

 ## 解決策

 **答え:**`101524`モノポリーボードのマス目に番号を付けましょう$0$–$39$：

- 行く$=0$- 刑務所$=10$- G2J$=30$- CC で$2,17,33$- チャット$7,22,36$**2 つの 4 面サイコロ**を使用する場合、次のようなマルコフ過程の定常分布を計算する必要があります。 

1.通常の動き、
 2. ダブルスのトリプル$\to$刑務所、
 3. CC/CHカードの効果、
 4.G2J、
 5. CC に着地する「3 マス戻る」などの再帰的効果。 

必要な答えは、最も可能性の高い 3 つの最終正方形を連結したものです。 

---

 # 数学的分析

 これを解決するきれいな方法は、モノポリーを **マルコフ連鎖** としてモデル化することです。 

状態には以下が含まれている必要があります。 

- 現在のボードの位置$p\in\{0,\dots,39\}$、
 - 連続ダブルスの数$d\in\{0,1,2\}$。 

したがって、次のとおりです。$$40 \times 3 = 120$$州。 

---

 ## 1. サイコロの確率

 4 面ダイスが 2 つあり、それぞれのダイスは次のようになります。$1,2,3,4$。 

がある$16$同様に起こり得る結果。 

合計は次の確率で発生します。 

| 合計 | 方法 |
 | --- | --- |
 | 2 | 1 |
 | 3 | 2 |
 | 4 | 3 |
 | 5 | 4 |
 | 6 | 3 |
 | 7 | 2 |
 | 8 | 1 |

 ダブルスは次のとおりです。$$(1,1),(2,2),(3,3),(4,4)$$それで：$$P(\text{double})=\frac{4}{16}=\frac14$$プレーヤーがすでに 2 連続のダブルを持っていて、さらにダブルを出した場合、プレーヤーは移動せずに直接刑務所に送られます。 

---

 #2. 共同募金

 CC スクエアの場合:

 - 14 枚のカードでは何も起こりません。 
- カード1枚$\to$ゴー、
 - カード1枚$\to$刑務所。 

したがって：$$P(\text{GO})=\frac1{16},\quad P(\text{JAIL})=\frac1{16},\quad P(\text{stay})=\frac{14}{16}$$---

 #3. チャンスカード

 CH スクエアの場合:

 10 枚のカードがプレイヤーを動かします:

 - 行く
 - 刑務所
 -C1
 - E3
 - H2
 -R1
 - 次のR
 - 次のR
 - 次のU
 - 3マス戻る

 そして6枚のカードは何もしません。 

したがって、リストされた各動きには確率があります$1/16$ただし、以下を除きます。 

- 次の R が 2 回表示されます$\Rightarrow 2/16$。 

---

 #4. 再帰的な動きの処理

 微妙な点は次のとおりです。 

・「3マス戻る」はCCマスに着地可能。 
- その CC マスはプレイヤーを再び移動させることができます。 

例：$$36 \xrightarrow{\text{back 3}} 33$$そして$33$CCです。 

したがって、移動の解決は、終端の正方形に到達するまで再帰的に行う必要があります。 

---

 #5. 遷移行列

 定義:$$T_{ij}=P(\text{state }i\to \text{state }j)$$これは$120\times120$確率行列。 

定常分布$\pi$を満たす:$$\pi T = \pi$$乗算を繰り返すことで数値的に取得できます。$$\pi_{n+1}=\pi_n T$$収束するまで。 

最後に、各ボードの正方形の 3 つのダブルカウント状態を合計します。$$P(p)=\sum_{d=0}^2 \pi(p,d)$$次に、確率を並べ替えます。 

---

 # Pythonの実装```python
from collections import defaultdict

# ------------------------------------------------------------
# Board constants
# ------------------------------------------------------------

GO = 0
JAIL = 10
G2J = 30

CC = {2, 17, 33}
CH = {7, 22, 36}

RAILWAYS = [5, 15, 25, 35]
UTILITIES = [12, 28]

# ------------------------------------------------------------
# Helpers for Chance cards
# ------------------------------------------------------------

def next_railway(pos):
    for r in RAILWAYS:
        if r > pos:
            return r
    return RAILWAYS[0]

def next_utility(pos):
    for u in UTILITIES:
        if u > pos:
            return u
    return UTILITIES[0]

# ------------------------------------------------------------
# Resolve all special square effects recursively.
#
# Returns a dictionary:
#   final_position -> probability
# ------------------------------------------------------------

def resolve_square(pos):

    # Go To Jail
    if pos == G2J:
        return {JAIL: 1.0}

    # Community Chest
    if pos in CC:
        out = defaultdict(float)

        out[GO] += 1/16
        out[JAIL] += 1/16
        out[pos] += 14/16

        return dict(out)

    # Chance
    if pos in CH:
        out = defaultdict(float)

        # 6 cards do nothing
        out[pos] += 6/16

        # Direct movement cards
        out[GO] += 1/16
        out[JAIL] += 1/16
        out[11] += 1/16      # C1
        out[24] += 1/16      # E3
        out[39] += 1/16      # H2
        out[5] += 1/16       # R1

        # Next railway (2 cards)
        out[next_railway(pos)] += 2/16

        # Next utility
        out[next_utility(pos)] += 1/16

        # Back 3 squares
        back = (pos - 3) % 40

        # Must recursively resolve
        for p, prob in resolve_square(back).items():
            out[p] += prob * (1/16)

        return dict(out)

    # Ordinary square
    return {pos: 1.0}

# ------------------------------------------------------------
# Build state indexing
# state = (position, consecutive_doubles)
# ------------------------------------------------------------

states = []
index = {}

for p in range(40):
    for d in range(3):
        index[(p, d)] = len(states)
        states.append((p, d))

N = len(states)

# ------------------------------------------------------------
# Transition matrix
# ------------------------------------------------------------

T = [[0.0] * N for _ in range(N)]

# Enumerate all dice outcomes
dice = []

for a in range(1, 5):
    for b in range(1, 5):
        dice.append((a, b))

for i, (pos, doubles_count) in enumerate(states):

    for a, b in dice:

        prob = 1 / 16
        is_double = (a == b)

        # Third consecutive double -> jail
        if is_double and doubles_count == 2:
            j = index[(JAIL, 0)]
            T[i][j] += prob
            continue

        # New doubles count
        new_doubles = doubles_count + 1 if is_double else 0

        # Move normally
        new_pos = (pos + a + b) % 40

        # Resolve square effects
        outcomes = resolve_square(new_pos)

        for final_pos, p2 in outcomes.items():

            # After movement effects, doubles count persists
            # unless sent to jail
            if final_pos == JAIL:
                nd = 0
            else:
                nd = new_doubles

            j = index[(final_pos, nd)]
            T[i][j] += prob * p2

# ------------------------------------------------------------
# Power iteration for stationary distribution
# ------------------------------------------------------------

dist = [0.0] * N
dist[index[(GO, 0)]] = 1.0

for _ in range(500):
    new_dist = [0.0] * N

    for i in range(N):
        for j in range(N):
            new_dist[j] += dist[i] * T[i][j]

    dist = new_dist

# ------------------------------------------------------------
# Combine probabilities by board square
# ------------------------------------------------------------

square_probs = [0.0] * 40

for (pos, d), idx in index.items():
    square_probs[pos] += dist[idx]

# Sort descending
ranking = sorted(
    range(40),
    key=lambda x: square_probs[x],
    reverse=True
)

top3 = ranking[:3]

answer = "".join(f"{x:02d}" for x in top3)

print(answer)
```---
