 **答え:**`748317`## 1. 数学的分析

 次の**たった 11 個の素数**を探します。 

- 自分自身を呼び起こし、
 - **左から右**に数字を繰り返し切り捨てるときは素数のままであり、
 - **右から左**に数字を繰り返し切り捨てる場合は素数のままです。 

例：$$3797 \to 797 \to 97 \to 7$$そして$$3797 \to 379 \to 37 \to 3$$すべてプライムのままです。 

を除くすべてのそのような素数の**合計**を見つけなければなりません。$2,3,5,7$。 

### 主な所見

 #### 観察 1: 桁の制限

 複数桁の切り捨て可能な素数の場合:

 - **最後の数字**は次のようにする必要があります$3$または$7$、素数以来$>5$偶数桁または 5 で終わることはできません。 
- 内部数字は偶数または 5 にすることはできません。そうしないと、一部の切り捨てが合成になります。 

したがって、候補者は次の数字のみを使用します。$$\{1,3,7,9\}$$(場合によっては先頭の数字を除く)。 

これにより、検索スペースが大幅に削減されます。

 #### 観察 3: 11 個しかありません

 ### 効率的な素数性テスト

 当社では、トライアル分割を次の目的で使用します。$$\sqrt{n}$$もしもから$n = ab$、少なくとも 1 つの要素が最大です$\sqrt n$。 

アルゴリズム:

 - 拒否$n<2$、
 - 偶数を素早く処理し、
 - 奇数の約数を最大でテストします$\sqrt n$。 

有効な数値は 11 個だけであるため、複雑さはわずかです。

 ## 2. Python の実装```python
import math

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    limit = int(math.sqrt(n))
    for d in range(3, limit + 1, 2):
        if n % d == 0:
            return False
    return True

def is_truncatable_prime(n):
    """Check if n is truncatable from both directions."""
    s = str(n)

    # Exclude single-digit primes
    if len(s) == 1:
        return False

    # Left-to-right truncations
    for i in range(len(s)):
        if not is_prime(int(s[i:])):
            return False

    # Right-to-left truncations
    for i in range(len(s), 0, -1):
        if not is_prime(int(s[:i])):
            return False

    return True

found = []
n = 11  # smallest possible multi-digit prime

while len(found) < 11:
    if is_prime(n) and is_truncatable_prime(n):
        found.append(n)
    n += 2  # skip even numbers

answer = sum(found)

print(found)
print(answer)
```---
