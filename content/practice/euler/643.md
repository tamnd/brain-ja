[プロジェクト オイラー問題 643](https://projecteuler.net/problem=643)

 ## 解決策

 **答え:**`968274154`させて$$f(n)=\#\{(p,q):1\le p<q\le n,\ \gcd(p,q)=2^t,\ t>0\}.$$必要です$f(10^{11}) \bmod 1\,000\,000\,007$。 

## 1. 数学的分析

 もし$\gcd(p,q)=2^t$と$t>0$、 書く$$p=2^t a,\qquad q=2^t b,$$どこ$\gcd(a,b)=1$。 

以来$p<q\le n$、$$1\le a<b\le \left\lfloor \frac{n}{2^t}\right\rfloor.$$したがって、それぞれについて$t\ge 1$、有効なペアの数は互いに素なペアの数と等しい$(a,b)$と$a<b\le m$、 どこ$$m=\left\lfloor \frac{n}{2^t}\right\rfloor.$$### 互いに素のペアを数える

 固定用$b$、の数$a<b$と$\gcd(a,b)=1$はオイラーの解です:$$\varphi(b).$$したがって、$$C(m)=\sum_{b=2}^{m}\varphi(b).$$合計関数を定義する$$\Phi(m)=\sum_{k=1}^{m}\varphi(k).$$それから$$C(m)=\Phi(m)-1.$$したがって、$$f(n) = \sum_{t\ge 1} \left( \Phi\!\left(\left\lfloor \frac{n}{2^t}\right\rfloor\right)-1 \right).$$以来$2^t>n$結局のところ、ただ$O(\log n)$用語が存在します。 

---

 ### 高速計算$\Phi(n)$古典的なアイデンティティを使用する$$\sum_{d\le n}\varphi(d)\left\lfloor \frac{n}{d}\right\rfloor = \frac{n(n+1)}{2}.$$並べ替え:$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right).$$重要な最適化は、等しい値をグループ化することです。$\lfloor n/d\rfloor$：

もし$$v=\left\lfloor \frac{n}{d}\right\rfloor,$$それから全部$d\in[l,r]$同じものを共有する$v$、 どこ$$r=\left\lfloor \frac{n}{v}\right\rfloor.$$これにより、複雑さが大まかに軽減されます$O(n^{2/3})$-スタイルのメモ化された分割統治、十分に高速$10^{11}$。

 ## 2. Python の実装```python
MOD = 1_000_000_007
LIMIT = 5_000_000

# Sieve Euler phi up to LIMIT
phi = list(range(LIMIT + 1))

for i in range(2, LIMIT + 1):
    if phi[i] == i:  # i is prime
        for j in range(i, LIMIT + 1, i):
            phi[j] -= phi[j] // i

# Prefix sums of phi
phi_prefix = [0] * (LIMIT + 1)

running = 0
for i in range(LIMIT + 1):
    running += phi[i]
    phi_prefix[i] = running

# Memoized summatory totient
memo = {0: 0}

def Phi(n):
    """Return sum_{k<=n} phi(k)."""
    if n <= LIMIT:
        return phi_prefix[n]

    if n in memo:
        return memo[n]

    result = n * (n + 1) // 2

    l = 2
    while l <= n:
        v = n // l
        r = n // v

        result -= (r - l + 1) * Phi(v)
        l = r + 1

    memo[n] = result
    return result

def f(n):
    total = 0
    t = 1

    while True:
        m = n >> t  # floor(n / 2^t)

        if m == 0:
            break

        total += Phi(m) - 1
        total %= MOD

        t += 1

    return total

print(f(10**11))
```---

 ### ステップ 1: トーチエントふるい

 すべてを計算します$\varphi(k)$カットオフまで (`LIMIT = 5_000_000`) 標準のオイラーふるいを使用します。 

### ステップ 2: プレフィックスの合計

 私たちは構築します$$\Phi(n)=\sum_{k\le n}\varphi(k)$$小さなすべての人にとって$n$。 

### ステップ 3: 再帰的要約トピック

 大型用$n$、私たちは使用します$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{d=2}^{n} \Phi\!\left(\left\lfloor \frac{n}{d}\right\rfloor\right),$$同一の商をグループ化して効率化します。 

### ステップ 4: 計算する$f(n)$合計します$$\Phi\!\left(\left\lfloor n/2^t\right\rfloor\right)-1$$のために$t=1,2,\dots$。
