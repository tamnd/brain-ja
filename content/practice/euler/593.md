[プロジェクト オイラー問題 593](https://projecteuler.net/problem=593)

 ## 解決策

 **答え:**`96632320042.0`させて$$S(k)=p_k^k \bmod 10007,$$どこ$p_k$です$k$-番目の素数、および$$S_2(k)=S(k)+S\!\left(\left\lfloor \frac{k}{10000}\right\rfloor+1\right).$$長さのウィンドウごとに$k$、中央値を取得し、それらを合計します。$$F(n,k)=\sum_{i=1}^{n-k+1} M(i,i+k-1).$$必要なものは次のとおりです。$$F(10^7,10^5).$$---

 # 数学的分析

 ブルートフォースアプローチは不可能です。 

-$10^7$用語、
 - 適切なサイズの窓$10^5$、
 - 単純に中央値を再計算するとコストがかかりすぎます。 

主な観察結果は次のとおりです。 

---

 ## 1. 値が小さい

 なぜなら$$S(k)=p_k^k \bmod 10007,$$私たちはいつも持っています$$0 \le S(k)\le 10006.$$したがって$$0 \le S_2(k)\le 20012.$$したがって、すべての要素は次のドメインのみに属します。$20013$可能な値。 

つまり、バランスのとれたツリー/ヒープの代わりに **周波数配列** を維持できるということです。 

---

 ## 2. スライディングウィンドウ中央値

 ある程度のサイズの窓の場合$10^5$、中央値は 2 つの中間統計量によって決定されます。 

ドメインは小さいため、次の点を維持してください。$$\text{count}[v] = \text{frequency of value } v$$のために$0\le v\le 20012$。 

ウィンドウがスライドすると:

 - 値を 1 つ削除します。 
- 値を 1 つ追加します。 
- 現在の中央値ポインタをローカルで調整します。 

これにより、各アップデートは基本的に$O(1)$償却された。 

---

 ## 3. 高速モジュラー電源

 直接コンピューティング$$p_k^k \bmod 10007$$通常の累乗で1000万倍は高価です。 

以来$10007$は素数、乗法群の剰余$10007$サイズがあります$$10006.$$プリミティブルートの使用$g$、ゼロ以外のすべての剰余は次のように書くことができます。$$g^a.$$事前計算:

 - 離散対数、
 - 指数テーブル。 

それから$$x^e \bmod 10007$$単一のテーブル検索になります。$$x^e = g^{(\log_g x)\,e \bmod 10006}.$$これは劇的に速くなります。

 # Pythonの実装```python
from __future__ import annotations
import math

MOD = 10007
PHI = MOD - 1
MAX_S2 = 2 * (MOD - 1)
DOMAIN_SIZE = MAX_S2 + 1

def nth_prime_upper_bound(n: int) -> int:
    if n < 6:
        return 15
    x = float(n)
    return int(x * (math.log(x) + math.log(math.log(x))) + 10)

def sieve_primes_upto(limit: int):
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"

    r = int(math.isqrt(limit))
    for p in range(2, r + 1):
        if sieve[p]:
            start = p * p
            sieve[start:limit + 1:p] = b"\x00" * (((limit - start) // p) + 1)

    return [i for i in range(2, limit + 1) if sieve[i]]

def factorize(n):
    out = []
    d = 2
    while d * d <= n:
        if n % d == 0:
            out.append(d)
            while n % d == 0:
                n //= d
        d += 1
    if n > 1:
        out.append(n)
    return out

def build_tables(mod):
    phi = mod - 1
    factors = factorize(phi)

    primitive_root = None

    for g in range(2, mod):
        ok = True
        for q in factors:
            if pow(g, phi // q, mod) == 1:
                ok = False
                break
        if ok:
            primitive_root = g
            break

    exp_table = [0] * phi
    log_table = [-1] * mod

    x = 1
    for i in range(phi):
        exp_table[i] = x
        log_table[x] = i
        x = (x * primitive_root) % mod

    return log_table, exp_table

LOG_TABLE, EXP_TABLE = build_tables(MOD)

def fast_pow_mod(a, e):
    if a == 0:
        return 0
    return EXP_TABLE[(LOG_TABLE[a] * e) % PHI]

def compute_F2(n, k):
    """
    Returns 2 * F(n, k)
    """

    counts = [0] * DOMAIN_SIZE
    window = [0] * k

    even = (k % 2 == 0)
    rank = k // 2 if even else (k + 1) // 2

    m1 = 0
    below = 0
    pos = 0
    filled = 0

    total2 = 0

    def init_median():
        nonlocal m1, below

        s = 0
        v = 0

        while s + counts[v] < rank:
            s += counts[v]
            v += 1

        m1 = v
        below = s

    def adjust():
        nonlocal m1, below

        while below >= rank:
            m1 -= 1
            below -= counts[m1]

        while below + counts[m1] < rank:
            below += counts[m1]
            m1 += 1

    def median2():
        if not even:
            return 2 * m1

        pos_in_bucket = rank - below

        if pos_in_bucket < counts[m1]:
            return 2 * m1

        m2 = m1 + 1
        while counts[m2] == 0:
            m2 += 1

        return m1 + m2

    limit = nth_prime_upper_bound(n)

    root = int(math.isqrt(limit))
    base_primes = sieve_primes_upto(root)

    odd_primes = [p for p in base_primes if p > 2]
    odd_squares = [p * p for p in odd_primes]

    offsets = [0] * 1002

    e = 1
    t = 1
    next_t = 10000

    idx = 1

    s = 2
    offsets[1] = s

    v = s + s

    window[0] = v
    counts[v] += 1
    filled = 1

    seg_odds = 1 << 20
    low = 3

    while low <= limit:

        high = min(low + 2 * seg_odds, limit + 1)

        seg_len = (high - low) // 2
        seg = bytearray(b"\x01") * seg_len

        for p, sq in zip(odd_primes, odd_squares):

            if sq >= high:
                break

            start = sq

            if start < low:
                rem = low % p
                start = low if rem == 0 else low + (p - rem)

            if start % 2 == 0:
                start += p

            j = (start - low) // 2

            seg[j::p] = b"\x00" * (((seg_len - j - 1) // p) + 1)

        find = seg.find
        i = find(1)

        while i != -1:

            prime = low + 2 * i

            idx += 1

            e += 1
            if e == PHI:
                e = 0

            if idx == next_t:
                t += 1
                next_t += 10000

            pm = prime % MOD

            s = fast_pow_mod(pm, e)

            if idx <= 1001:
                offsets[idx] = s

            v = s + offsets[t]

            if filled < k:

                window[filled] = v
                counts[v] += 1
                filled += 1

                if filled == k:
                    init_median()
                    total2 += median2()

            else:

                out = window[pos]

                if out != v:

                    counts[out] -= 1

                    if out < m1:
                        below -= 1

                    window[pos] = v
                    counts[v] += 1

                    if v < m1:
                        below += 1

                    adjust()

                pos += 1
                if pos == k:
                    pos = 0

                total2 += median2()

            if idx == n:
                return total2

            i = find(1, i + 1)

        low = high | 1

ans2 = compute_F2(10**7, 10**5)

if ans2 % 2:
    print(f"{ans2 // 2}.5")
else:
    print(f"{ans2 // 2}.0")

 # コードのチュートリアル

 このアルゴリズムには 4 つの主要なコンポーネントがあります。 

### 1. 素数の生成

 セグメント化されたふるいが最初の$10^7$効率的にプライミングします。 

### 2. 高速モジュラー電源

 離散ログモジュロの使用$10007$、べき乗剰余演算はテーブル検索になります。 

### 3. スライディング頻度テーブル

 すべての価値観が入っているので、$[0,20012]$、中央値はヒープではなくカウントによって維持されます。 

### 4. 中央値の維持

 ポインタ`m1`現在の下位中央値を追跡します。 

ウィンドウが変わるときは移動するだけです`m1`わずかに左/右。 

これにより、合計実行時間はほぼ線形になります。
