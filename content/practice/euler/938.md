[プロジェクト オイラー問題 938](https://projecteuler.net/problem=938)

 ## 解決策

 **答え:**`0.2928967987`させて$P(R,B)$は、最後に残った色が黒である確率を示します。 

ある状態で$(R,B)$、2枚のカードが引かれます:

 - 確率付きRR$\dfrac{R(R-1)}{(R+B)(R+B-1)}$、につながる$(R-2,B)$- 確率付きBB$\dfrac{B(B-1)}{(R+B)(R+B-1)}$、同じ状態に戻ります
 - 確率付きRB$\dfrac{2RB}{(R+B)(R+B-1)}$、につながる$(R,B-1)$したがって、$$P(R,B)= \frac{R(R-1)}{N(N-1)}P(R-2,B) +\frac{B(B-1)}{N(N-1)}P(R,B) +\frac{2RB}{N(N-1)}P(R,B-1),$$どこ$N=R+B$。 

並べ替えると、$$P(R,B)= \frac{R-1}{R+2B-1}P(R-2,B) + \frac{2B}{R+2B-1}P(R,B-1).$$境界条件:$$P(0,B)=1,\qquad P(R,0)=0 \text{ for } R>0.$$以来$R=24690=2\cdot12345$、 定義する$$f(k,b)=P(2k,b).$$それから$$f(k,b)= \frac{2k-1}{2k+2b-1}f(k-1,b) + \frac{2b}{2k+2b-1}f(k,b-1).$$シンプルな$O(KB)$動的プログラムが答えを計算します。 

Python コード:```python
K = 12345
B = 12345

# dp[b] = current row values
dp = [1.0] * (B + 1)   # k = 0 => P(0,b)=1

for k in range(1, K + 1):
    dp[0] = 0.0        # P(2k,0)=0

    for b in range(1, B + 1):
        dp[b] = (
            (2*k - 1) * dp[b]
            + 2*b * dp[b - 1]
        ) / (2*k + 2*b - 1)

print(f"{dp[B]:.10f}")
```これにより、指定されたチェックが再現されます。 

-$P(2,2)=0.4666666667$-$P(10,9)=0.4118903397$-$P(34,25)=0.3665688069$そして収量$$P(24690,12345)=0.2928967987\ldots$$**答え: 0.2928967987**
