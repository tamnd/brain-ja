 ## 解決策

 **答え:**`474766783`辺のある三角形の場合$a,b,c$そして$120^\circ$反対の角度$c$、余弦の法則は次のようになります。$$c^2=a^2+b^2-2ab\cos 120^\circ$$以来$\cos 120^\circ=-\tfrac12$、$$c^2=a^2+b^2+ab.$$すべての整数解の古典的なパラメータ化$$c^2=a^2+b^2+ab$$は$$\begin{aligned} a &= d(m^2-n^2),\\ b &= d(2mn+n^2),\\ c &= d(m^2+mn+n^2), \end{aligned}$$整数の場合$m>n>0$およびスケール係数$d\ge1$。 

したがって、問題は次のようになります。 

1. すべての整数を生成する$120^\circ$三角形。 
2. 各辺を底辺に変換します$n$。 
3. 3 つの表現の連結で各桁が使用されているかどうかを確認します。$0,\dots,n-1$まさに一度。 
4. 最大の辺を合計します。 

重要な点は、3 辺の合計桁数が正確に一致している必要があることです。$n$、それで、$9\le n\le18$検索スペースは、積極的なプルーニングによって引き続き管理可能です。

 ## Pythonの実装```python
from collections import Counter

def to_base(x, b):
    """Return digits of x in base b as a string."""
    if x == 0:
        return "0"
    s = []
    while x:
        s.append(str(x % b))
        x //= b
    return ''.join(reversed(s))

def is_pandigital_triangle(a, b, c, base):
    """
    Check whether the three sides written in base 'base'
    use every digit 0..base-1 exactly once.
    """
    sa = to_base(a, base)
    sb = to_base(b, base)
    sc = to_base(c, base)

    s = sa + sb + sc

    # Must use exactly base digits total
    if len(s) != base:
        return False

    # Digits available in this base
    target = Counter(str(i) for i in range(base))

    return Counter(s) == target

answer = 0

for base in range(9, 19):

    found = []

    # Digit count restriction:
    # largest side has at most base digits in base 'base'
    limit = base ** base

    # Generate all primitive 120-degree triangles
    # and allow scaling by d.
    for m in range(2, 500):
        for n in range(1, m):

            A = m*m - n*n
            B = 2*m*n + n*n
            C = m*m + m*n + n*n

            if C >= limit:
                break

            d = 1
            while d * C < limit:

                a = d * A
                b = d * B
                c = d * C

                # check all permutations
                triples = [
                    (a, b, c),
                    (b, a, c),
                ]

                ok = False
                for x, y, z in triples:
                    if is_pandigital_triangle(x, y, z, base):
                        found.append(z)
                        ok = True
                        break

                d += 1

    answer += sum(set(found))

print(answer)
