 ## 解決策

 **答え:**`5943040885644`させて$$n=\prod_{p} p^{a_p}.$$全部欲しいです$1<n<10^{10}$そのような$\phi(n^2)$完璧な立方体です。 

重要なのは、素指数を理解することです。$\phi(n^2)$。 

---

 #1. 数学的分析

 私たちが使用するのは$$\phi(p^k)=p^{k-1}(p-1),$$それで$$\phi(n^2) =\prod_p \phi\!\left(p^{2a_p}\right) =\prod_p p^{2a_p-1}(p-1).$$同様に、$$\phi(n^2)=n\phi(n).$$条件は次のとおりです。 

> 内のすべての素指数$\phi(n^2)$で割り切れる必要があります$3$。 

---

 ## 素数指数方程式

 しましょう$$R=\operatorname{rad}(n)=\prod_{p\mid n} p$$(のsquarefreeカーネル$n$）。 

定義する$$d_q = v_q(\phi(R))      = v_q\!\left(\prod_{p\mid R}(p-1)\right).$$素数の指数を調べてみましょう$q$内部$\phi(n^2)$。 

---

 ### ケース 1:$q\mid n$仮定する$q^{a_q}\parallel n$。 それから：

-$q^{2a_q-1}$から来ています$\phi(q^{2a_q})$、
 - 追加の権限$q$要因から来る$(p-1)$他の素数の場合$p\mid n$。 

したがって、$$v_q(\phi(n^2)) = 2a_q-1+d_q.$$これは次で割り切れる必要があります。$3$:$$2a_q-1+d_q \equiv 0 \pmod 3.$$以来$2^{-1}\equiv 2 \pmod 3$、$$a_q \equiv 2+d_q \pmod 3.$$それで一度$R$固定されており、すべての素数除算の指数$n$モジュロで決定される$3$。 

したがって、最小の正の指数は次のようになります。$$r_q= \begin{cases} 1,& d_q\equiv 2 \pmod 3,\\ 2,& d_q\equiv 0 \pmod 3,\\ 3,& d_q\equiv 1 \pmod 3. \end{cases}$$---

 ### ケース 2:$q\nmid n$その場合、唯一の貢献は次のとおりです。$\phi(R)$、だから必要です$$d_q \equiv 0 \pmod 3.$$したがって、以下に現れるすべての「外部」素数は、$\prod(p-1)$で割り切れる指数まで発生する必要があります$3$。

 # 2. すべてのソリューションの構造

 かつてラジカル$R$修正されています:

 - 各素数$p\mid R$最小の指数があります$r_p\in\{1,2,3\}$、
 - の倍数を追加する$3$to exponents は立方体の条件を保持します。 

したがって、すべての解決策は次の形式になります。$$n=n_0\prod_{p\mid R} p^{3k_p},$$どこ$$n_0=\prod_{p\mid R} p^{r_p}.$$したがって、問題は次のようになります。 

1. 許容される部首をすべて列挙します$R$、
 2. 最小の基数を計算します$n_0$、
 3. すでに存在する素数の任意の 3 乗を乗算します。$R$、
 4. 値を以下に保つ$10^{10}$。 

---

 #3. 効率的な検索戦略

 ラジカルを再帰的に構築します$R$。 

新しいプライムを追加する場合$q$:

 - 因数分解を更新します$\phi(R)$因数分解を使用して$q-1$、
 - 可能な最小限のものを再計算します$n_0$、
 - 場合は剪定します$n_0>10^{10}$。 

重要な境界:

 - の最大の素数$R$常に指数がある$2$、
 - したがって、すべての素数は$R$せいぜい$10^5$。 

したがって、検索スペースは非常に狭いです。

 #4. Pythonの実装```python
from sympy import primerange, factorint

LIMIT = 10**10

# All primes that could possibly appear.
# The largest prime must appear with exponent at least 2,
# so p^2 < LIMIT => p < 1e5.
primes = list(primerange(2, 100000))

# Precompute factorizations of p - 1
fac = {p: factorint(p - 1) for p in primes}

solutions = set()

def minimal_base(R, d):
    """
    Given:
        R = set of primes dividing n
        d[q] = exponent of q in phi(R) modulo 3

    compute the smallest possible n having radical R.
    """
    n0 = 1

    for p in R:
        r = (2 + d.get(p, 0)) % 3

        # residue 0 means exponent 3
        if r == 0:
            r = 3

        n0 *= p ** r

        if n0 > LIMIT:
            return n0

    return n0

def generate_all_from_base(base, prime_list, idx=0):
    """
    From the minimal solution, multiply by arbitrary cubes
    of existing primes.
    """
    if base > LIMIT:
        return

    if idx == len(prime_list):
        solutions.add(base)
        return

    p = prime_list[idx]

    value = base
    while value <= LIMIT:
        generate_all_from_base(value, prime_list, idx + 1)
        value *= p ** 3

def dfs(start, R, d):
    """
    Recursive generation of admissible radicals.
    """
    n0 = minimal_base(R, d)

    if n0 > LIMIT:
        return

    # Check external-prime condition:
    # every prime not in R must have exponent 0 mod 3.
    ok = True
    for q, v in d.items():
        if q not in R and v % 3 != 0:
            ok = False
            break

    # If valid, generate all solutions from this radical
    if ok and R:
        generate_all_from_base(
            n0,
            sorted(R)
        )

    # Try adding larger primes
    for i in range(start, len(primes)):
        q = primes[i]

        # Safe pruning:
        # any new prime contributes at least q^2 overall.
        if n0 * q * q > LIMIT:
            break

        R2 = set(R)
        R2.add(q)

        d2 = dict(d)

        # Update d using factorization of q-1
        for p, e in fac[q].items():
            d2[p] = (d2.get(p, 0) + e) % 3

        dfs(i + 1, R2, d2)

dfs(0, set(), {})

answer = sum(solutions)

print(answer)
```---
