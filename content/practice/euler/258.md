[プロジェクト オイラー問題 258](https://projecteuler.net/problem=258)

 ## 解決策

 **答え:**`12747994`させて$$g_k = \begin{cases} 1,&0\le k\le 1999,\\[4pt] g_{k-2000}+g_{k-1999},&k\ge 2000. \end{cases}$$計算しなければなりません$$g_{10^{18}} \pmod{20092010}.$$---

 #1. 数学的分析

 これは順序の線形回帰です$2000$。 

特性関係を定義します。$$g_n-g_{n-1999}-g_{n-2000}=0.$$したがって、特性多項式は次のようになります。$$P(x)=x^{2000}-x-1.$$線形反復の重要な事実は次のとおりです。 

> 毎学期$g_n$最初の線形結合として表現できます。$2000$条項。 

すべての初期値は$$g_0=g_1=\cdots=g_{1999}=1,$$の係数を計算できれば$x^n$特性多項式を法とする$P(x)$の場合、答えは単にそれらの係数の合計になります。 

---

 ## 多項式の観点

 商リングの内側$$\mathbb Z_m[x]/(x^{2000}-x-1),$$削減ルールがあります$$x^{2000}\equiv x+1.$$したがって、どんな力でも$x^n$次数の多項式に還元できる$<2000$:$$x^n \equiv \sum_{i=0}^{1999} c_i x^i.$$それから$$g_n=\sum_{i=0}^{1999} c_i g_i.$$しかし、すべての$g_i=1$、 それで$$g_n=\sum_{i=0}^{1999} c_i.$$したがって、タスクは次のようになります。 

1. コンピューティング$x^{10^{18}} \bmod (x^{2000}-x-1)$。 
2. 係数を法として合計します。$20092010$。 

---

 #2. 効率的なアルゴリズム

 多項式に対して 2 進累乗を使用します。 

2 つの多項式を乗算すると、次数は次のようになります。$3998$。 

学期ごとに$x^d$と$d\ge 2000$と表示される場合は、使用量を減らしてください$$x^{2000}\equiv x+1.$$したがって$$x^d = x^{d-2000}x^{2000} \equiv x^{d-1999}+x^{d-2000}.$$これにより、$O(K^2\log n)$アルゴリズムを使用した$K=2000$これは簡単に十分に高速です。 

---

 #3. Pythonの実装```python
MOD = 20092010
K = 2000
N = 10**18

def combine(a, b):
    """
    Multiply two polynomials modulo:
        x^2000 - x - 1
    Result has degree < 2000.
    """
    tmp = [0] * (2 * K - 1)

    # Ordinary polynomial multiplication
    for i, ai in enumerate(a):
        if ai:
            for j, bj in enumerate(b):
                if bj:
                    tmp[i + j] = (tmp[i + j] + ai * bj) % MOD

    # Reduce high-degree terms using:
    # x^2000 = x + 1
    for d in range(2 * K - 2, K - 1, -1):
        v = tmp[d]
        if v:
            tmp[d - K] = (tmp[d - K] + v) % MOD
            tmp[d - K + 1] = (tmp[d - K + 1] + v) % MOD

    return tmp[:K]

def power_x(n):
    """
    Compute x^n modulo the characteristic polynomial.
    Return coefficients of degree < 2000 polynomial.
    """

    # res = 1
    res = [1] + [0] * (K - 1)

    # base = x
    base = [0, 1] + [0] * (K - 2)

    while n > 0:
        if n & 1:
            res = combine(res, base)

        base = combine(base, base)
        n >>= 1

    return res

# coefficients for x^N
coeffs = power_x(N)

# since g_0 ... g_1999 are all 1,
# g_N is the sum of coefficients
answer = sum(coeffs) % MOD

print(answer)
```---

tmp[d - K + 1]
