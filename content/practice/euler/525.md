[プロジェクト オイラー問題 525](https://projecteuler.net/problem=525)

 ## 解決策

 **答え:**`44.69921807`楕円とします$$\frac{x^2}{a^2}+\frac{(y-b)^2}{b^2}=1$$したがって、身体座標（楕円の中心を中心とする）では、境界は次のようになります。$$r(t)=(a\cos t,\; b\sin t), \qquad -\frac{\pi}{2}\le t\le \frac{3\pi}{2}.$$で$t=-\pi/2$、一番下の点が地面に接触します。 

## 1. 数学的分析

 楕円が滑らずに転がると、その境界を境に接触点が連続的に変化します。 

### ステップ 1: 接触形状

 ポイントとしては$r(t)$、接線ベクトルは$$r'(t)=(-a\sin t,\; b\cos t),$$その大きさは$$q(t)=\sqrt{a^2\sin^2 t+b^2\cos^2 t}.$$これは極小の円弧長係数です。$$ds=q(t)\,dt.$$パラメータでの楕円の外側の法線$t$に比例する$$\left(\frac{\cos t}{a},\frac{\sin t}{b}\right).$$水平線上で回転するということは、この法線がワールド座標で垂直下を指すことを意味します。 したがって、楕円の回転角度は$\phi(t)$満足する$$\phi(t) = -\frac{\pi}{2} -\operatorname{atan2} \!\left(\frac{\sin t}{b},\frac{\cos t}{a}\right).$$回転を 1 回転にわたって連続させるには、楕円が回転するようにこの角度をアンラップします。$2\pi$。 

### ステップ 2: 中心座標

 滑りがないため、接地点は境界円弧の長さだけ進みます。$$x_{\text{contact}}(t) = \int q(t)\,dt.$$ワールド座標で回転した接触点が$$R_{\phi(t)}r(t) = (x_r(t),y_r(t)),$$すると、楕円の中心は$$X(t)=x_{\text{contact}}(t)-x_r(t), \qquad Y(t)=-y_r(t).$$したがって、経路長は次のようになります。$$C(a,b) = \int \sqrt{ \left(\frac{dX}{dt}\right)^2 + \left(\frac{dY}{dt}\right)^2 }\,dt.$$完全 1 回転にわたる数値積分により、目的の値が得られます。 

チェックとして、評価する$C(2,4)$問題のステートメントを再現します。$$C(2,4)\approx 21.38816906.$$---

 ## 2. Python の実装```python
import mpmath as mp

mp.mp.dps = 50  # high precision

def C(a, b):
    # Rotation angle of ellipse so tangent is horizontal
    def phi_raw(t):
        return -mp.pi / 2 - mp.atan2(mp.sin(t) / b,
                                      mp.cos(t) / a)

    # Unwrap angle to make one continuous full turn
    def phi(t):
        p = phi_raw(t)
        if t > -mp.pi / 2:
            while p > 0:
                p -= 2 * mp.pi
        return p

    # Arc-length factor of ellipse boundary
    def q(t):
        return mp.sqrt(a*a * mp.sin(t)**2 +
                       b*b * mp.cos(t)**2)

    # Rotated boundary point in world coordinates
    def x_rel(t):
        p = phi(t)
        x = a * mp.cos(t)
        y = b * mp.sin(t)
        return x * mp.cos(p) - y * mp.sin(p)

    def y_rel(t):
        p = phi(t)
        x = a * mp.cos(t)
        y = b * mp.sin(t)
        return x * mp.sin(p) + y * mp.cos(p)

    # Speed of ellipse center
    def integrand(t):
        dx = q(t) - mp.diff(x_rel, t)
        dy = -mp.diff(y_rel, t)
        return mp.sqrt(dx*dx + dy*dy)

    return mp.quad(integrand,
                   [-mp.pi/2, 3*mp.pi/2])

# Verify sample
print(C(2, 4))

# Required quantity
ans = C(1, 4) + C(3, 4)
print(ans)
print(f"{ans:.8f}")
```---

 ## 3. コードのチュートリアル

 -`phi_raw(t)`接触点の接線が水平になるように必要な回転角度を計算します。 
-`phi(t)`角度をアンラップして、連続的な完全回転を保証します。 
-`q(t)`差動弧長を計算します$ds/dt$楕円の境界線。 
-`x_rel(t), y_rel(t)`回転後の接触点の位置を計算します。 
- 中心位置は次のことから得られます。 

- 境界円弧の長さだけ前進します (滑りなし)、
 - 回転された接触点オフセットを減算します。 
-`integrand(t)`中心の瞬間速度を計算します。 
- 境界を 1 回完全に横断する数値積分により次の結果が得られます。$C(a,b)$。
