 ## 解決策

 **答え:**`2406376.3623`させて

-$T$= 1 つの 4 面ダイスの結果、
 -$C$= の合計$T$独立した6面ダイス、
 -$O$= の合計$C$独立した8面ダイス、
 -$D$= の合計$O$独立した12面ダイス、
 -$I$= の合計$D$独立した20面体のサイコロ。 

私たちは求められています$\mathrm{Var}(I)$。 

重要なツールは、**総期待の法則**と**総分散の法則**です。 

フェアに向けて$n$-サイドダイス取得値$1,\dots,n$、$$\mathbb E[X] = \frac{n+1}{2}, \qquad \mathrm{Var}(X)=\frac{n^2-1}{12}.$$次の事実を繰り返し使用します。 

もし$S_N$の合計です$N$iid 確率変数$X_i$、 どこ$N$それ自体はランダムであり、$X_i$、 それから$$\mathbb E[S_N] = \mathbb E[N]\mathbb E[X],$$そして$$\mathrm{Var}(S_N) = \mathbb E[N]\mathrm{Var}(X) + \mathrm{Var}(N)\bigl(\mathbb E[X]\bigr)^2.$$そのアイデンティティは直接由来します$$\mathrm{Var}(S_N) = \mathbb E[\mathrm{Var}(S_N\mid N)] + \mathrm{Var}(\mathbb E[S_N\mid N]).$$---

 # ステップ 1: 各ダイの分布パラメータ

 のために$k$-サイドダイ:$$\mu_k = \frac{k+1}{2}, \qquad \sigma_k^2 = \frac{k^2-1}{12}.$$したがって:

 | 死ぬ | 平均 | 分散 |
 | --- | --- | --- |
 | d4 |$5/2$|$5/4$|
 | d6 |$7/2$|$35/12$|
 | d8 |$9/2$|$21/4$|
 | d12 |$13/2$|$143/12$|
 | d20 |$21/2$|$133/4$|

 # ステップ 2: 計算する$C$条件付き$T=t$、$$C = \sum_{i=1}^t X_i,$$どこ$X_i$IID D6 ロールです。 

したがって、$$\mathbb E[C] = \mathbb E[T]\mu_6 = \frac52\cdot\frac72 = \frac{35}{4}.$$合計分散を使用する:$$\mathrm{Var}(C) = \mathbb E[T]\sigma_6^2 + \mathrm{Var}(T)\mu_6^2.$$それで$$\mathrm{Var}(C) = \frac52\cdot\frac{35}{12} + \frac54\cdot\left(\frac72\right)^2.$$計算:$$= \frac{175}{24} + \frac{245}{16} = \frac{595}{24}.$$---

 # ステップ 3: 計算する$O$

$O$の合計です$C$iid d8 ロール。 

平均：$$\mathbb E[O] = \mathbb E[C]\mu_8 = \frac{35}{4}\cdot\frac92 = \frac{315}{8}.$$分散：$$\mathrm{Var}(O) = \mathbb E[C]\sigma_8^2 + \mathrm{Var}(C)\mu_8^2.$$したがって$$= \frac{35}{4}\cdot\frac{21}{4} + \frac{595}{24}\cdot\left(\frac92\right)^2.$$

$$= \frac{735}{16} + \frac{16065}{96} = \frac{20475}{96} = \frac{6825}{32}.$$---

 # ステップ 4: 計算する$D$

$D$の合計です$O$IID D12 ロール。 

平均：$$\mathbb E[D] = \frac{315}{8}\cdot\frac{13}{2} = \frac{4095}{16}.$$分散：$$\mathrm{Var}(D) = \mathbb E[O]\sigma_{12}^2 + \mathrm{Var}(O)\mu_{12}^2.$$それで$$= \frac{315}{8}\cdot\frac{143}{12} + \frac{6825}{32}\cdot\left(\frac{13}{2}\right)^2.$$

$$= \frac{45045}{96} + \frac{1153425}{128}.$$共通点$384$:$$= \frac{180180 + 3460275}{384} = \frac{3640455}{384}.$$---

 # ステップ 5: 計算する$I$

$I$の合計です$D$iid d20 ロール。 

必要なのは分散だけです。$$\mathrm{Var}(I) = \mathbb E[D]\sigma_{20}^2 + \mathrm{Var}(D)\mu_{20}^2.$$代替値:$$= \frac{4095}{16}\cdot\frac{133}{4} + \frac{3640455}{384}\cdot\left(\frac{21}{2}\right)^2.$$最初の学期:$$\frac{4095\cdot133}{64} = \frac{544635}{64}.$$第二期：$$\frac{3640455}{384}\cdot\frac{441}{4} = \frac{1603440655}{1536}.$$最初の項を分母に変換します$1536$:$$\frac{544635}{64} = \frac{13071240}{1536}.$$したがって、$$\mathrm{Var}(I) = \frac{1616511895}{1536}.$$10 進数値:$$\mathrm{Var}(I) = 1052416.5983072916\ldots$$小数点第 4 位に四捨五入:$$1052416.5983$$---

 # Pythonの実装```python
from fractions import Fraction

def die_stats(sides):
    """
    Return (mean, variance) for a fair die with values 1..sides.
    """
    mean = Fraction(sides + 1, 2)
    var = Fraction(sides * sides - 1, 12)
    return mean, var

def compound_sum(mean_n, var_n, mean_x, var_x):
    """
    If S is the sum of N iid X variables:

        S = X1 + X2 + ... + XN

    where N is random and independent of the Xi, then

        E[S]   = E[N] E[X]
        Var[S] = E[N] Var[X] + Var[N] (E[X])^2

    Returns (mean_S, var_S).
    """
    mean_s = mean_n * mean_x
    var_s = mean_n * var_x + var_n * mean_x * mean_x
    return mean_s, var_s

# Start with T: one d4
mean_T, var_T = die_stats(4)

# C: sum of T d6
mean_d6, var_d6 = die_stats(6)
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)

# O: sum of C d8
mean_d8, var_d8 = die_stats(8)
mean_O, var_O = compound_sum(mean_C, var_C, mean_d8, var_d8)

# D: sum of O d12
mean_d12, var_d12 = die_stats(12)
mean_D, var_D = compound_sum(mean_O, var_O, mean_d12, var_d12)

# I: sum of D d20
mean_d20, var_d20 = die_stats(20)
mean_I, var_I = compound_sum(mean_D, var_D, mean_d20, var_d20)

print("Exact variance:", var_I)
print("Decimal:", float(var_I))
print("Rounded:", round(float(var_I), 4))
```---

 # コードのチュートリアル

 ###`die_stats`公平なサイコロの平均と分散を計算します。$$\mu=\frac{n+1}{2},\qquad \sigma^2=\frac{n^2-1}{12}.$$使用する`Fraction`すべてを正確に保ちます。 

---

 ###`compound_sum`基本的な式を実装します。$$E[S]=E[N]E[X]$$そして$$\mathrm{Var}(S) = E[N]\mathrm{Var}(X) + \mathrm{Var}(N)(E[X])^2.$$これはチェーンを通じて繰り返し適用されます。$$T \to C \to O \to D \to I.$$---

 ### 再帰的計算

 各ステージは、次のステージで振られるサイコロのランダムな数になります。 

例えば：```python
mean_C, var_C = compound_sum(mean_T, var_T, mean_d6, var_d6)
```の合計の統計を計算します。$T$6面サイコロ。

 # 最終確認

 各層では、前の層からの期待カウントと不確実性の両方が乗算されるため、分散は非常に急速に増加します。 

最終的な値は約$1.05\times10^6$、d20 ロールの予想数を考えると、これは合理的です。$$E[D] = \frac{4095}{16} \approx 256.$$約 256 個の d20 ダイスの合計にはすでにばらつきがあります。$$256 \cdot \frac{133}{4} \approx 8500,$$そして、サイコロを振った数のランダム性がさらに大きく寄与し、その差異は 100 万を超えます。
