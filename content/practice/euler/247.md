[プロジェクト オイラー問題 247](https://projecteuler.net/problem=247)

 ## 解決策

 **答え:**`782252`地域をしましょう$R(a,b)$によって定義される$$x\ge a,\qquad y\ge b,\qquad y\le \frac1x,$$どこの角$(a,b)$双曲線の下にあります$xy=1$。 

このような領域内では、軸に沿った最大の正方形の左下隅があります。$(a,b)$そしてサイドの長さ$s$右上隅が曲線上にあるという条件によって決定されます。$$(a+s)(b+s)=1.$$拡大すると、$$s^2 + (a+b)s + ab - 1 = 0.$$ポジティブな根を取り、$$s(a,b)=\frac{\sqrt{(a-b)^2+4}-(a+b)}{2}.$$元の問題については、以下から始めます$$(a,b)=(1,0).$$最初の広場$S_1$したがって側面がある$$s=\frac{\sqrt5-1}{2}.$$---

 # 再帰的な構造

 正方形の辺を配置した後$s$で$R(a,b)$、2 つの互いに素な領域が残ります。 

- **右**の領域:$$R(a+s,b),$$- **上記**の領域:$$R(a,b+s).$$現在の正方形にインデックスがある場合$(L,B)$、その後:

 - 右側の子にはインデックスがあります$(L+1,B)$、
 - 上の子にはインデックスがあります$(L,B+1)$。 

したがって、すべての正方形は右/上への移動のパスに対応します。 

たとえば、インデックス$(3,3)$は、ちょうど 3 つの右と 3 つの上を含むすべてのパスに対応します。$$\binom63 = 20$$合計でこのような正方形になります。 

---

 # 正方形の順序

 正方形には、辺の長さを減少させることによってグローバルに番号が付けられます。 

したがって:

 - 辺の降順に正方形を生成します。 
- インデックス付きの正方形の場合は常に$(3,3)$が表示されるので、その位置を記録します$n$、
 - そのような最大のもの$n$が答えです。 

優先キュー (最大ヒープ) が理想的です。 

---

 # Pythonの実装```python
from heapq import heappush, heappop
from math import sqrt, comb

def side(a, b):
    """
    Side length of the largest square that fits in region R(a,b).
    Derived from:
        (a+s)(b+s) = 1
    """
    return (sqrt((a - b) ** 2 + 4) - (a + b)) / 2

def solve(target=(3, 3)):
    # Number of squares having this index
    needed = comb(target[0] + target[1], target[0])

    # Max-heap implemented with negative sizes
    pq = []

    # Initial region R(1,0)
    s0 = side(1.0, 0.0)

    # heap item = (-side, a, b, left, below)
    heappush(pq, (-s0, 1.0, 0.0, 0, 0))

    n = 0
    found = []

    smallest_target_size = float("inf")

    while pq:
        neg_s, a, b, left, below = heappop(pq)
        s = -neg_s

        n += 1

        # Record squares with desired index
        if (left, below) == target:
            found.append((n, s))
            smallest_target_size = min(smallest_target_size, s)

            # Once all target squares are found,
            # we can stop when remaining squares are smaller
            if len(found) == needed:
                if -pq[0][0] < smallest_target_size:
                    break

        # Generate right child
        sr = side(a + s, b)
        heappush(pq, (-(sr), a + s, b, left + 1, below))

        # Generate upper child
        su = side(a, b + s)
        heappush(pq, (-(su), a, b + s, left, below + 1))

    return found[-1][0]

answer = solve((3, 3))
print(answer)
```---

 # コードのチュートリアル

 ＃＃１。`side(a,b)`領域内の最大平方フィッティングを計算します$R(a,b)$:$$(a+s)(b+s)=1.$$正の二次根は辺の長さを与えます。 

---

 ## 2. 優先キュー

 問題の番号順に合わせて、常に現在最大の正方形を最初に削除します。 

各ヒープ項目には以下が格納されます。```python
(-side, a, b, left, below)
```どこ：

-`(a,b)`地域を特定し、
 -`(left, below)`は正方形のインデックスです。 

---

 ## 3. 子領域

 正方形を配置した後:```python
(a+s, b)     # right region
(a, b+s)     # upper region
```それらのインデックスは次のようになります。```python
(left+1, below)
(left, below+1)
```---

 ## 4. 停止基準

 インデックス用$(3,3)$、まさにあります$$\binom63 = 20$$可能な正方形。 

20 個すべてが見つかり、ヒープ内に残っている最大の正方形がすでに見つかった最小のターゲット正方形よりも小さい場合、追加は必要ありません。$(3,3)$正方形は後で表示される可能性があります。

 # 最終確認

 計算により、ちょうど 20 個の正方形のインデックスが見つかります。$(3,3)$、最後のものは次の場所に表示されます。$$n = 782252.$$これは、最小の正方形が生成される前に生成される大きな正方形の数が急速に増加していることと一致しています。$(3,3)$設定が表示されます。 

**答え: 782252**
