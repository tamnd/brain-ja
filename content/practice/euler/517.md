 #1. 数学的分析

 ## 1.1 組み合わせ解釈

 再発$$g(x)=g(x-1)+g(x-a)$$これは、長さのステップを使用してパスをカウントすることに似ています。$1$そして$a$。 

なぜなら$a$は無理数であり、次の形式のすべての数値$$m+na$$独特の表現力を持っています。 これにより、再帰ツリー内のすべてのあいまいさが解消されます。 

定義する：

-$k$= の数$a$-ステップ、
 -$j$= の数$1$-ステップ。 

すると全長は$$j+ka.$$固定用$k$、条件$$j+ka\le x$$になる$$j\le \lfloor x-ka\rfloor.$$それぞれの許容範囲について$j$、以下を含むシーケンスの数:

 -$k$のコピー$a$、
 -$j$のコピー$1$、

は$$\binom{j+k}{k}.$$したがって$$g_a(x)= \sum_{k\ge0}\sum_{j=0}^{\lfloor x-ka\rfloor}\binom{j+k}{k}.$$次に、ホッケースティックの ID を使用します。$$\sum_{j=0}^{m}\binom{j+k}{k} = \binom{m+k+1}{k+1}.$$したがって、$$g_a(x) = \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k+1}{k+1}.$$インデックスの再作成$k\mapsto k-1$:$$\boxed{ g_a(x)= \sum_{k\ge0} \binom{\lfloor x-ka\rfloor+k}{k} }.$$---

 ## 1.2 の式$G(n)$セット$a=\sqrt n$、$x=n$:$$\boxed{ G(n)= \sum_{k=0}^{\lfloor\sqrt n\rfloor} \binom{\lfloor n-k\sqrt n\rfloor+k}{k} }.$$問題は$$G(90)=7564511.$$チェック中：$$G(90) = \sum_{k=0}^{9} \binom{\lfloor 90-k\sqrt{90}\rfloor+k}{k} = 7564511,$$したがって、式は正しいです。

 #2. 効率的なモジュラー計算

 すべての素数が必要です$$10^7<p<10010000.$$それらは数百しかなく、それぞれの素数に対して$p$、$$k\le \lfloor\sqrt p\rfloor \approx 3162.$$したがって、二項評価の総数は約$2\times10^6$。 

すべての二項係数を法で計算します$$M=10^9+7$$階乗と逆階乗を使用します。

 #3. Pythonの実装```python
import math

MOD = 1_000_000_007

LOW = 10_000_000
HIGH = 10_010_000

# ------------------------------------------------------------
# Segmented sieve for primes in (LOW, HIGH)
# ------------------------------------------------------------

limit = int(math.isqrt(HIGH)) + 1

base = [True] * (limit + 1)
base[0] = base[1] = False

for i in range(2, int(limit ** 0.5) + 1):
    if base[i]:
        step = i
        start = i * i
        for j in range(start, limit + 1, step):
            base[j] = False

small_primes = [i for i, v in enumerate(base) if v]

seg = [True] * (HIGH - LOW)

for p in small_primes:
    start = max(p * p, ((LOW + p - 1) // p) * p)
    for x in range(start, HIGH, p):
        seg[x - LOW] = False

primes = [LOW + i for i, v in enumerate(seg) if v and LOW + i > LOW]

# ------------------------------------------------------------
# Precompute factorials modulo MOD
# ------------------------------------------------------------

N = HIGH + 5000

fact = [1] * (N + 1)

for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact = [1] * (N + 1)

invfact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    """Compute nCr modulo MOD."""
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# ------------------------------------------------------------
# Compute G(p)
# ------------------------------------------------------------

def G(p):
    a = math.sqrt(p)

    total = 0

    for k in range(int(a) + 1):
        n = math.floor(p - k * a) + k
        total = (total + C(n, k)) % MOD

    return total

answer = 0

for p in primes:
    answer = (answer + G(p)) % MOD

print(answer)
```---
