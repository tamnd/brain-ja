 ## 解決策

 **答え:**`1517926517777556`させて$$a = 1504170715041707,\qquad m = 4503599627370517.$$私たちはその順序を研究します$$E_n = an \pmod m.$$オイラーコインは、以前のすべての用語よりも厳密に小さい用語です。 

すべてのオイラーコインの合計を計算する必要があります。

 #1. 数学的分析

 順序は$$E_n = an - m\left\lfloor \frac{an}{m}\right\rfloor.$$なぜなら$\gcd(a,m)=1$、シーケンスは整数の順列です。$1,\dots,m-1$。 

重要な観察は、オイラーコインがまさにこのモジュラーシーケンスの連続した最小値であるということです。 

最初のいくつかの用語は次のとおりです。$$\begin{aligned} E_1 &= 1504170715041707,\\ E_2 &= 3008341430083414,\\ E_3 &= 8912517754604. \end{aligned}$$以来$$8912517754604 < 1504170715041707,$$3 番目の項は 2 番目のオイラーコインです。 

---

 ## コア数理論の洞察

 直接シミュレーションは不可能です。$m \approx 4.5\times10^{15}$。 

画期的な進歩はモジュラーインバースから生まれます。 

以来$\gcd(a,m)=1$、存在します$a^{-1}$そのような$$aa^{-1}\equiv 1\pmod m.$$拡張ユークリッド アルゴリズムを使用すると、次のようになります。$$a^{-1} \equiv 3451657199285664 \pmod m.$$これはつまり：$$n \equiv a^{-1}E_n \pmod m.$$---

 ## 2 つの補完的な検索

 オイラーコインは自然に 2 つのフェーズに分かれます。 

### フェーズ 1: 大型オイラーコイン

 シーケンスを順方向に生成します。$$E_n = (E_{n-1}+a)\bmod m,$$新しい最小値のみを維持します。 

これらの最小値は急速に減少します。 

比較的少ない反復の後、オイラーコインは小さくなります。 

---

 ### フェーズ 2: 小規模オイラーコイン

 仮定してください$x$オイラーコインです。 

その場合、そのインデックスは$$n_x \equiv a^{-1}x \pmod m.$$数字$x$対応するインデックスがあればオイラーコインです$n_x$は、すでにチェックされているすべての小さな正の整数のインデックスよりも小さいです。 

したがって、小さい場合は$x$、次のことをテストできます。$$n_x = (a^{-1}x)\bmod m.$$このインデックスがこれまでに確認された最小値である場合、$x$オイラーコインです。 

この 2 番目の方法では、非常に迅速に小さなオイラーコインが見つかります。 

---

 ## これが機能する理由

 仮定してください$x<y$。 

もし$$n_x < n_y,$$それから$x$シーケンス内でより前に表示されます$y$、 それで$y$以下の最小値が最初に出現することはできません$x$。 

したがって、オイラーコインは、モジュラー逆指数が新しい最小値である値に正確に対応します。 

これにより、困難な前方モジュラー スキャンが、小さな整数に対する非常に安価な検索に変換されます。

 #2. Pythonの実装```python
from math import gcd

A = 1504170715041707
M = 4503599627370517

# ------------------------------------------------------------
# Extended Euclidean algorithm
# ------------------------------------------------------------

def egcd(a, b):
    if b == 0:
        return (a, 1, 0)
    g, x1, y1 = egcd(b, a % b)
    return (g, y1, x1 - (a // b) * y1)

# modular inverse of A mod M
g, x, y = egcd(A, M)
A_INV = x % M

# ------------------------------------------------------------
# Phase 1: generate large Eulercoins directly
# ------------------------------------------------------------

coins = []

current = A
minimum = A

coins.append(A)

while current > 10_000_000:
    current = (current + A) % M

    if current < minimum:
        minimum = current
        coins.append(current)

# ------------------------------------------------------------
# Phase 2: generate small Eulercoins using inverse mapping
# ------------------------------------------------------------

best_index = M

for x in range(1, minimum):
    idx = (A_INV * x) % M

    if idx < best_index:
        best_index = idx
        coins.append(x)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

answer = sum(coins)

print(answer)
```---
