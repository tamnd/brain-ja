 ## 解決策

 **答え:**`834171904`させて$$H(n)=\#\{S\subset \mathbb Z_{>0}:\operatorname{lcm}(S)=n\}$$どこ$S$は **セット** (繰り返しなし) であり、$$L(n)=\operatorname{lcm}(1,2,\dots,n).$$私たちは求めています$$HL(50000)=H(L(50000)) \pmod{10^9}.$$---

 ## 1. 数学的分析

 ### ステップ 1: 有効なセットの特徴付け

 もし$\operatorname{lcm}(S)=n$、のすべての要素$S$分けなければなりません$n$。 したがって、すべての有効なセットは、次の除数セットのサブセットです。$n$。 

させて$D(n)$～の約数の集合となる$n$、サイズ付き$$\tau(n)=\#D(n).$$空でないすべてのサブセット$D(n)$ある程度の lcm 分割がある$n$。 したがって：$$2^{\tau(n)}-1 = \sum_{d\mid n} H(d).$$これは約和の関係であるため、メビウス反転すると次のようになります。$$H(n) = \sum_{d\mid n} \mu(d)\,2^{\tau(n/d)}.$$以来$\mu(d)=0$ない限り$d$は平方フリーなので、素因数のサブセットのみが問題になります。 

---

 ### ステップ 2: プライムパワー形式

 仮定してください$$n=\prod_{i=1}^{r} p_i^{a_i}.$$平方自由除数の場合$d$、プライムを選択$p_i$で$d$要素を置き換えます$a_i+1$による$a_i$内部$\tau(n/d)$。 したがって、$$\tau(n/d) = \prod_{p_i\nmid d}(a_i+1) \prod_{p_i\mid d}a_i.$$したがって$$H(n) = \sum_{S\subseteq \{1,\dots,r\}} (-1)^{|S|} 2^{ \left( \prod_{i\notin S}(a_i+1) \prod_{i\in S}a_i \right) }.$$---

 ### ステップ 3: の構造$L(50000)$定義上、$$L(50000) = \prod_{p\le 50000} p^{\lfloor \log_p(50000)\rfloor}.$$したがって、指数は$a_i$は:

 | 指数$a$| カウント |
 | --- | --- |
 | 15 | 1 |
 | 9 | 1 |
 | 6 | 1 |
 | 5 | 1 |
 | 4 | 2 |
 | 3 | 5 |
 | 2 | 37 |
 | 1 | 5085 |

 膨大な数の指数 1 素数が計算上の主な課題です。 

---

 ### ステップ 4: モジュラー削減のトリック

 答えのモジュロだけが必要です$$10^9 = 2^9\cdot 5^9.$$すべての指数は巨大です ($>9$）、 それで$$2^k\equiv 0 \pmod{2^9}.$$のために$5^9$部分的に、オイラー/カーマイケル周期性は次のようになります。$$2^k \pmod{5^9}$$のみに依存する$$k \bmod \lambda(5^9) = 4\cdot 5^8 = 1{,}562{,}500.$$したがって、必要なのは巨大な指数モジュロだけです$1{,}562{,}500$、計算が可能になります。

 ## 2. Python の実装```python
from collections import Counter
import sympy as sp
import numpy as np

MOD = 10**9
EXP_MOD = 1_562_500  # Carmichael modulus for 5^9

def HL(n):
    # Count exponent frequencies in L(n)
    exponent_counts = Counter()

    for p in sp.primerange(1, n + 1):
        a = 0
        power = p
        while power <= n:
            a += 1
            power *= p
        exponent_counts[a] += 1

    # Use the largest multiplicity (a=1 here) as a vectorized dimension
    dominant_a = max(exponent_counts, key=lambda x: exponent_counts[x])
    dominant_count = exponent_counts.pop(dominant_a)

    # Binomial coefficients with alternating signs
    coeffs = [1]
    current = 1
    for k in range(1, dominant_count + 1):
        current = current * (dominant_count - k + 1) // k
        coeffs.append(current % MOD)

    coeffs = np.array(coeffs, dtype=np.int64)

    signs = np.array(
        [1 if k % 2 == 0 else MOD - 1
         for k in range(dominant_count + 1)],
        dtype=np.int64
    )

    coeffs = (coeffs * signs) % MOD

    # Contribution from the dominant exponent type
    dominant_factors = np.array([
        (pow(dominant_a, k, EXP_MOD) *
         pow(dominant_a + 1,
             dominant_count - k,
             EXP_MOD)) % EXP_MOD
        for k in range(dominant_count + 1)
    ], dtype=np.int64)

    # Precompute powers of 2 modulo 1e9
    power2 = np.array([
        pow(2, r, MOD)
        for r in range(EXP_MOD)
    ], dtype=np.int64)

    # Enumerate remaining exponent groups recursively
    remaining = list(exponent_counts.items())
    states = []

    def dfs(i, product_mod, coefficient):
        if i == len(remaining):
            states.append((product_mod % EXP_MOD,
                           coefficient % MOD))
            return

        a, count = remaining[i]

        comb = 1
        pow_a = 1
        pow_b = (a + 1) ** count

        for k in range(count + 1):
            sign = comb if k % 2 == 0 else -comb

            dfs(
                i + 1,
                product_mod * pow_a * pow_b,
                coefficient * sign
            )

            if k < count:
                comb = comb * (count - k) // (k + 1)
                pow_a *= a
                pow_b //= (a + 1)

    dfs(0, 1, 1)

    # Final accumulation
    answer = 0

    for base, coeff in states:
        residues = (base * dominant_factors) % EXP_MOD
        values = power2[residues]

        subtotal = int(np.dot(coeffs, values) % MOD)
        answer = (answer + coeff * subtotal) % MOD

    return answer % MOD

print(HL(4))      # 44
print(HL(50000))  # target

 ## 3. コードのチュートリアル

 ### 素数指数の抽出

 素数ごとに$p\le n$、計算します$$a=\lfloor \log_p(n)\rfloor$$繰り返し乗算することで$p$。 

これにより、次の素数べき乗分解が構築されます。$L(n)$。 

---

 ### 同一の指数のグループ化

 全てを治療するのではなく、$5133$素数を個別に、指数ごとにグループ化します$a$。 

指数の場合$a$登場する$c$選択するよりも合計することが多い$k$包含-除外サブセット内のこれらの素数:$$\binom{c}{k}(-1)^k.$$これにより、検索スペースが大幅に減少します。

 ### 剰余指数の削減

 以来$$2^e \pmod{10^9}$$問題は減らします$e$モジュロ$$1{,}562{,}500.$$これにより、天文学的に大きな指数を直接処理することが回避されます。

 のために$n=4$:$$L(4)=12.$$プログラムは以下を返します:$$HL(4)=44,$$問題文と正確に一致します。
