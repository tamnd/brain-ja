[プロジェクト オイラー問題 49](https://projecteuler.net/problem=49)

 ## 解決策

 **答え:**`296962999629`次のような 2 番目の 4 桁の素数の等差数列を求めます。 

1. 3 つの項はすべて素数です。 
2. それらは等差数列を形成します。 
3. 3 つの数字は互いに順列です。 
4. とは異なります$1487,4817,8147$。 

---

 # 数学的分析

 3つの項を次のようにします$$a,\quad a+d,\quad a+2d$$ここで、すべては 4 桁の素数です。 

順列条件は、3 つの数値すべてに、異なる順序でまったく同じ数字が含まれていることを意味します。 有益な結果は次のとおりです。 

- 数値の順列はすべて同じ桁の合計になります。 
- したがって、3 つの数値はすべて合同モジュロです。$9$。 

したがって、次のようになります。$$(a+d)-a=d$$で割り切れる必要があります$9$。 

関係する素数はすべて奇数であるため (2 より大きい 4 桁の素数)、公差も偶数でなければなりません。 

したがって：$$d \text{ is divisible by } 18.$$これにより、検索スペースが大幅に減少します。 

自然なアルゴリズムは次のとおりです。 

1. 4 桁の素数をすべて生成します。 
2. ソートされた数字に基づいて素数をグループ化します。 

- 例：$$1487 \to "1478"$$

$$4817 \to "1478"$$3. 各順列グループ内で、3 項の等差数列を検索します。 
4. 既知の例は無視してください。 
5. 3 つの数値を連結します。

 # Pythonの実装```python
from collections import defaultdict
from itertools import combinations

# ------------------------------------------------------------
# Sieve of Eratosthenes to generate primes up to 9999
# ------------------------------------------------------------
limit = 10000
is_prime = [True] * limit
is_prime[0] = is_prime[1] = False

for i in range(2, int(limit ** 0.5) + 1):
    if is_prime[i]:
        for j in range(i * i, limit, i):
            is_prime[j] = False

# Keep only 4-digit primes
primes = [p for p in range(1000, 10000) if is_prime[p]]

# ------------------------------------------------------------
# Group primes by sorted digit signature
# Example: 4817 -> "1478"
# ------------------------------------------------------------
groups = defaultdict(list)

for p in primes:
    key = ''.join(sorted(str(p)))
    groups[key].append(p)

# ------------------------------------------------------------
# Search each group for arithmetic sequences
# ------------------------------------------------------------
for group in groups.values():

    # Need at least 3 numbers to form a sequence
    if len(group) < 3:
        continue

    group.sort()
    group_set = set(group)

    # Try every pair as potential first two terms
    for a, b in combinations(group, 2):
        d = b - a
        c = b + d

        # Check if third term exists
        if c in group_set:

            # Ignore the known sequence
            if (a, b, c) != (1487, 4817, 8147):

                result = f"{a}{b}{c}"
                print(result)
```---
