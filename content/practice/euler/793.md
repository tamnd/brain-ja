[プロジェクト オイラー問題 793](https://projecteuler.net/problem=793)

 ## 解決策

 **答え:**`475808650131120`させて$$S_0=290797,\qquad S_{i+1}=S_i^2 \bmod 50515093$$そして定義します$$P(n)=\{S_iS_j \mid 0\le i<j<n\}.$$がある$$N=\binom n2$$ペア商品。 以来$N$にとっては奇妙だ$n=1{,}000{,}003$、中央値は正確に一致する一意の要素です。$N//2$その下の商品。 

私たちは求められています$$M(1{,}000{,}003).$$---

 #1. 数学的分析

 ## ステップ 1: シーケンスの生成と並べ替え

 擬似乱数ジェネレーターは、以下の正の整数を生成します。$50515093$。 

させて$$A = \text{sorted}(S_0,S_1,\dots,S_{n-1}).$$仕分けは、製品を効率的に数えるために非常に重要です。 

---

 ## ステップ 2: 中央値問題を計数問題に変換する

 定義する$$f(x)=\#\{(i,j): i<j,\ A_iA_j\le x\}.$$それから$f(x)$単調増加です。 

計算できれば$f(x)$すぐに中央値が最小になります$x$そのような$$f(x)\ge \frac{N+1}{2}.$$のために$$N=\binom{1{,}000{,}003}{2}=500002500003,$$目標ランクは$$K=\frac{N+1}{2}=250001250002.$$したがって、最小の整数を求めます$x$と$$f(x)\ge K.$$---

 ## ステップ 3: 2 ポインタのカウント

 なぜなら$A$がソートされている場合、線形時間でペアをカウントできます。 

修理$i$。 私たちは最大のものを望んでいます$j>i$満足のいく$$A_iA_j\le x.$$として$i$増加すると、この最大値は$j$決して増加しないため、減少するポインタを使用します。 

アルゴリズム:

 - 開始$j=n-1$。 
- それぞれについて$i$：

- その間$A_iA_j>x$、デクリメント$j$。 
- 次に、すべてのインデックス$i+1,\dots,j$仕事。 
- 追加$j-i$カウントに。 

これは計算します$f(x)$で$O(n)$。 

---

 ## ステップ 4: 二分探索

 製品範囲は以下の通りです$$0 \le A_iA_j \le A_{n-1}A_{n-2}.$$以来$f(x)$は単調です。検索範囲が以下であるため、バイナリ検索は約 51 回の反復で中央値を見つけます。$2^{52}$。 

全体的な複雑さ:

 - 並べ替え:$O(n\log n)$- 各カウント:$O(n)$- 二分探索:$O(n\log V)$これは十分に高速です$n=1{,}000{,}003$。 

---

 #2. Pythonの実装```python
MOD = 50515093
N = 1_000_003

# ------------------------------------------------------------
# Generate the sequence
# ------------------------------------------------------------
S = [0] * N

x = 290797
for i in range(N):
    S[i] = x
    x = (x * x) % MOD

# ------------------------------------------------------------
# Sort values
# ------------------------------------------------------------
A = sorted(S)

# Number of pairwise products
total_pairs = N * (N - 1) // 2

# We want the lower/true median rank (1-based)
target = total_pairs // 2 + 1

# ------------------------------------------------------------
# Count how many pairs have product <= value
# ------------------------------------------------------------
def count_leq(value):
    count = 0
    j = N - 1

    for i, a in enumerate(A):

        while i < j and a * A[j] > value:
            j -= 1

        if j <= i:
            break

        count += (j - i)

    return count

# ------------------------------------------------------------
# Binary search for the median product
# ------------------------------------------------------------
lo = 0
hi = A[-1] * A[-2]

while lo < hi:
    mid = (lo + hi) // 2

    if count_leq(mid) >= target:
        hi = mid
    else:
        lo = mid + 1

print(lo)
```---
