[プロジェクト オイラー問題 421](https://projecteuler.net/problem=421)

 ## 解決策

 **答え:**`2304215802083466198`させて$$S=\sum_{n=1}^{10^{11}} s(n,10^8),$$どこ$s(n,m)$**異なる**素因数の合計です$p\le m$の$n^{15}+1$。 

重要なのは、合計の順序を逆にすることです。 

---

 ## 1. 合計を書き換える

 素数$p$に貢献する$s(n,10^8)$もし$$p\mid n^{15}+1,$$つまり$$n^{15}\equiv -1 \pmod p.$$したがって、$$S=\sum_{p\le 10^8} p\cdot \#\{1\le n\le 10^{11}: n^{15}\equiv -1 \pmod p\}.$$したがって、各素数について$p$、剰余クラスを剰余としてカウントするだけで済みます。$p$満足のいく$$x^{15}\equiv -1 \pmod p.$$---

 #2. ソリューションの構造

 奇数素数の場合$p$、乗法群$$(\mathbb Z/p\mathbb Z)^\times$$秩序は循環する$p-1$。 

観察する：$$x^{15}\equiv -1 \iff (-x)^{15}\equiv 1.$$したがって、解は 1 の 15 乗根に正確に対応します。 

したがって、解の数は次のようになります。$$d=\gcd(15,p-1),$$したがって$d\in\{1,3,5,15\}$。 

素数の場合$p>5$、これはのみに依存します$p\bmod 30$:

 |$p\bmod 30$|$d$|
 | --- | --- |
 |$1$|$15$|
 |$11$|$5$|
 |$7,13,19$|$3$|
 |$17,23,29$|$1$|

 ---

 # 3. までの発生をカウントする$10^{11}$素数を修正する$p$。 

書く$$10^{11}=qp+t,\qquad 0\le t<p.$$各有効な剰余クラスのモジュロ$p$表示されます:

 - まさに$q$間で回$1,\dots,10^{11}$、
 - 残余が次の場合はさらに 1 つの追加オカレンスが追加されます。$\le t$。 

したがって、有効な残基が$r_1,\dots,r_d$、 それから$$\#\{n\le 10^{11}: p\mid n^{15}+1\} = dq+\#\{i:r_i\le t\}.$$したがって、計算は完全にモジュール化されています。 

---

 #4. 根の効率的な生成

 もし$u^{15}\equiv1$、 それから$n\equiv -u\pmod p$合同を解きます。 

そこで、15 乗根の部分群を生成します。 

次数の部分群の生成子を取得するには$d$、計算します$$g=a^{(p-1)/d}\pmod p$$小規模トライアルベース用$a$。 

それから$$1,g,g^2,\dots,g^{d-1}$$まさに統一の 15 番目の根です。 

対応する解決策は次のとおりです$$n\equiv -1,-g,-g^2,\dots \pmod p.$$---

 #5. Pythonの実装```python
from math import isqrt

# ---------------------------------------------------------
# Odd-only sieve of Eratosthenes
# ---------------------------------------------------------
def iter_odd_primes_upto(limit):
    size = (limit + 1) // 2
    sieve = bytearray(b"\x01") * size
    sieve[0] = 0

    r = isqrt(limit)

    for i in range(1, (r // 2) + 1):
        if sieve[i]:
            p = 2 * i + 1
            start = (p * p) // 2
            sieve[start::p] = b"\x00" * (((size - start - 1) // p) + 1)

    idx = sieve.find(1, 1)

    while idx != -1:
        yield 2 * idx + 1
        idx = sieve.find(1, idx + 1)

# ---------------------------------------------------------
# Test whether g has exact order 15 mod p
# ---------------------------------------------------------
def is_order_15(g, p):
    return (
        g != 1 and
        pow(g, 3, p) != 1 and
        pow(g, 5, p) != 1
    )

# ---------------------------------------------------------
# Find generator of subgroup of order d
# ---------------------------------------------------------
def find_generator(p, d):
    exp = (p - 1) // d

    for a in range(2, 100):
        g = pow(a, exp, p)

        if d in (3, 5):
            if g != 1:
                return g

        else:  # d == 15
            if is_order_15(g, p):
                return g

    raise RuntimeError("generator not found")

# ---------------------------------------------------------
# Main solver
# ---------------------------------------------------------
def solve(L=10**11, M=10**8):

    # d = gcd(15, p-1) determined by p mod 30
    d_table = [1] * 30
    d_table[1] = 15
    d_table[11] = 5
    d_table[7] = d_table[13] = d_table[19] = 3

    ans = 0

    # prime 2
    ans += 2 * ((L + 1) // 2)

    for p in iter_odd_primes_upto(M):

        d = d_table[p % 30]

        q, t = divmod(L, p)

        # only residue is -1 mod p
        if d == 1:
            cnt = q + (1 if t == p - 1 else 0)
            ans += p * cnt
            continue

        # subgroup generator
        g = find_generator(p, d)

        threshold = p - t

        u = 1
        extra = 0

        for _ in range(d):
            if u >= threshold:
                extra += 1
            u = (u * g) % p

        cnt = d * q + extra

        ans += p * cnt

    return ans

print(solve())

 #6. 例に対する検証

 プログラムはステートメントの例を再現します。 

-$2^{15}+1 = 3^2\cdot11\cdot331$それで$$s(2,10)=3,\qquad s(2,1000)=345.$$また、$$10^{15}+1 = 7\cdot11\cdot13\cdot211\cdot241\cdot2161\cdot9091,$$したがって$$s(10,100)=31,\qquad s(10,1000)=483.$$すべてのチェックに合格します。
