[プロジェクト オイラー問題 416](https://projecteuler.net/problem=416)

 ## 解決策

 **答え:**`898082747`させて$L=n-1$。 

完全な往路または復路は、次の要素を組み合わせたものにすぎません。$L$部品に分割$1,2,3$。 

のために$m$往復あります$$p=2m$$～からの独立した単調パス$0$に$L$。 

重要な観察は、ボードを左から右にスキャンでき、各パスについて、次の着地点がどのくらい先にあるのかを知る必要があるだけであるということです。 

位置での単一パスの場合$t$：

- 州$0$: 道が着地する$t$、
- 州$1$: 次の着陸地点は$t+1$、
- 州$2$: 次の着陸地点は$t+2$。 

パスが現在状態の場合$0$、着地後、長さのジャンプを選択します$1,2,3$、新しい状態を生み出す$0,1,2$それぞれ。 

全員にとって$p$パスを組み合わせると、システム全体はカウントによってのみ記述されます。$$(a,b,c),$$どこ

-$a$パスは状態にあります$0$、
 -$b$パスは状態にあります$1$、
 -$c$パスは状態にあります$2$、

と$$a+b+c=p.$$したがって、オートマトンの状態の数は次のようになります。$$\binom{p+2}{2}.$$のために$p=20$、これだけです$231$。 

---

 屋内広場にて$t$、広場を訪問する場合$a>0$。 

したがって、まだ訪問されていない正方形を 1 つ見たかどうかを示すビットを使用して状態を拡張します。 

したがって、状態の総数は次のようになります。$$231 \times 2 = 462.$$これにより、有限線形遷移システムが得られます。$F(m,n)$の高速行列累乗によって計算できます。$O(\log n)$。 

なぜなら、必要な係数は$$10^9 = 2^9\cdot 5^9,$$モジュロを個別に計算します$512$とモジュロ$1953125$、64 ビット行列乗算が安全な場合は、CRT と組み合わせます。 

移行ルールは次のとおりです。 

現在の状態が次の場合$(a,b,c)$、その後、$a$着陸経路の選択

 -$x$ジャンプの長さまで$1$、
 -$y$ジャンプの長さまで$2$、
 -$z$ジャンプの長さまで$3$、

と$x+y+z=a$。 

次の状態は$$(b+x,\; c+y,\; z),$$多重性のある$$\binom{a}{x,y,z}.$$---

 Python の実装:```python
import numpy as np
from math import comb

MOD1 = 512
MOD2 = 1953125

def solve_mod(mod):
    m = 10
    p = 2 * m
    L = 10**12 - 1

    # Enumerate all (a,b,c), a+b+c=p
    states = []
    idx = {}

    for a in range(p + 1):
        for b in range(p + 1 - a):
            c = p - a - b
            idx[(a, b, c)] = len(states)
            states.append((a, b, c))

    S = len(states) * 2   # extra bit = already used one unvisited square

    A = np.zeros((S, S), dtype=np.int64)
    B = np.zeros((S, S), dtype=np.int64)

    # Build transition matrices
    for si, (a, b, c) in enumerate(states):

        trans = []

        for x in range(a + 1):
            for y in range(a - x + 1):
                z = a - x - y

                mult = comb(a, x) * comb(a - x, y)
                mult %= mod

                nxt = (b + x, c + y, z)
                ni = idx[nxt]

                trans.append((ni, mult))

        for used in range(2):

            row = si * 2 + used

            for ni, mult in trans:

                # First step: no interior-square check
                A[row, ni * 2 + used] += mult
                A[row, ni * 2 + used] %= mod

                # Interior steps
                nused = used + (1 if a == 0 else 0)

                if nused <= 1:
                    B[row, ni * 2 + nused] += mult
                    B[row, ni * 2 + nused] %= mod

    start = idx[(p, 0, 0)] * 2

    vec = np.zeros(S, dtype=np.int64)
    vec[start] = 1

    # First step (position 0 is not interior)
    vec = (vec @ A) % mod

    # Remaining steps
    e = L - 1
    P = B.copy()

    while e:
        if e & 1:
            vec = (vec @ P) % mod

        e >>= 1

        if e:
            P = (P @ P) % mod

    ans = (vec[start] + vec[start + 1]) % mod
    return int(ans)

a1 = solve_mod(MOD1)
a2 = solve_mod(MOD2)

# CRT
inv = pow(MOD1, -1, MOD2)

answer = (
    a1
    + MOD1 * (((a2 - a1) * inv) % MOD2)
) % (10**9)

print(answer)
```例の検証:

 -$F(1,3)=4$-$F(1,4)=15$-$F(1,5)=46$-$F(2,3)=16$-$F(2,100)\bmod 10^9 = 429619151$すべてステートメントと一致します。
