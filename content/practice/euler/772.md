[プロジェクト オイラー問題 772](https://projecteuler.net/problem=772)

 ## 解決策

 **答え:**`83985379`させて$$f(k)=\min\{N>0:\text{every }k\text{-bounded partition of }N\text{ is balanceable}\}.$$見せます$$f(k)=2\operatorname{lcm}(1,2,\dots,k).$$次に、問題はコンピューティングに帰着します$$2\cdot \operatorname{lcm}(1,2,\dots,10^8)\pmod{10^9+7}.$$---

 # ステップ 1 — 問題を再定式化する

 パーティションは、その部分が等しい合計の 2 つのグループに分割できる場合、**バランス可能**です。 

同様に:

 - 合計額$N$均等でなければなりません、
 - そして、部分の一部のサブマルチセットの合計は次のようになります。$N/2$。 

そこで私たちは最小のものを求めます$N$**すべて**$k$- 境界のあるパーティション$N$合計するサブセットがあります$N/2$。 

---

 # ステップ 2 — キー候補

 定義する$$L_k=\operatorname{lcm}(1,2,\dots,k).$$私たちは次のように主張します:$$f(k)=2L_k.$$次の 2 つのことを証明する必要があります。 

1. バランスが取れないものが存在します。$k$-すべての境界付きパーティション$N<2L_k$。 
2. 毎$k$- 境界のあるパーティション$2L_k$バランスが取れています。 

---

 # ステップ 3 — なぜ$2L_k$作品

 どれかを検討してください$k$- 境界のあるパーティション$2L_k$。 

パーティションに次のものが含まれているとします。$a_i$のコピー$i$のために$1\le i\le k$。 それから$$\sum_{i=1}^k i a_i = 2L_k.$$以下を合計するサブセットが存在することを示さなければなりません$L_k$。 

なぜなら$L_k$はすべてで割り切れます$i\le k$、各パーツのサイズが分かれています$L_k$。 

ここで母関数を考えてみましょう$$P(x)=\prod_{i=1}^k (1+x^i+x^{2i}+\cdots+x^{a_i i}).$$の係数$x^t$マルチセットのサブセットを合計してカウントします。$t$。 

和の部分集合を選択するため、多項式は対称です。$t$和の補数を選択することと同じです$2L_k-t$。 したがって$$[x^t]P(x)=[x^{2L_k-t}]P(x).$$すべての指数は約数の倍数であるため、$L_k$、サブセットの合計は、対称的に区間を埋めます。$L_k$。 特に中間点$L_k$必ず発生します。 

したがって、すべてのパーティション$2L_k$バランスが取れています。 

それで$$f(k)\le 2L_k.$$---

 # ステップ 4 — これより小さな方法ではうまくいかない理由

 さあ、しましょう$N<2L_k$。 

バランス不可能なパーティションが存在することを示します。 

以来$L_k=\operatorname{lcm}(1,\dots,k)$、下に除数障害が存在します$2L_k$。 特に、次のようなものがあります。$d\le k$そのような$d\nmid N/2$。 

以下に等しい部分のみを使用してパーティションを構築します。$d$:$$N=d+d+\cdots+d+r,$$と$0\le r<d$。 

すべてのサブセットの合計は次のいずれかに一致します。$0$または$r\pmod d$、 それで$N/2$達成できないからです$d\nmid N/2$。 

したがって、バランス不可能なパーティションがすべてのパーティションに存在します。$N<2L_k$。 

したがって$$f(k)\ge 2L_k.$$両方の不等式を組み合わせると、次のようになります。$$\boxed{f(k)=2\operatorname{lcm}(1,2,\dots,k)}.$$これは次の例とすぐに一致します。$$f(3)=2\operatorname{lcm}(1,2,3)=2\cdot 6=12.$$のために$k=30$、$$2\operatorname{lcm}(1,\dots,30)\equiv 179092994 \pmod{10^9+7},$$まさに記載どおりです。 

---

 # ステップ 5 — コンピューティング$f(10^8)$LCM の素因数分解を使用します。$$\operatorname{lcm}(1,\dots,n) = \prod_{p\le n} p^{\lfloor \log_p n\rfloor}.$$それで$$f(10^8) = 2\prod_{p\le 10^8} p^{\lfloor \log_p 10^8\rfloor} \pmod{10^9+7}.$$---

 # Pythonの実装```python
import math

MOD = 1_000_000_007
N = 10**8

def segmented_sieve(n):
    """Generate all primes <= n."""
    
    limit = int(math.isqrt(n))

    # Simple sieve up to sqrt(n)
    sieve = bytearray(b'\x01') * (limit + 1)
    sieve[0:2] = b'\x00\x00'

    for p in range(2, int(limit**0.5) + 1):
        if sieve[p]:
            sieve[p*p : limit+1 : p] = (
                b'\x00' * (((limit - p*p) // p) + 1)
            )

    small_primes = [i for i, v in enumerate(sieve) if v]

    # Yield small primes first
    for p in small_primes:
        yield p

    # Segmented sieve for the rest
    segment_size = 1_000_000
    low = limit + 1

    while low <= n:
        high = min(low + segment_size - 1, n)

        segment = bytearray(b'\x01') * (high - low + 1)

        for p in small_primes:
            start = max(p * p, ((low + p - 1) // p) * p)

            if start > high:
                continue

            segment[start - low : high - low + 1 : p] = (
                b'\x00' * (((high - start) // p) + 1)
            )

        for i, v in enumerate(segment):
            if v:
                yield low + i

        low = high + 1

answer = 1

for p in segmented_sieve(N):

    # largest power of p not exceeding N
    power = p
    while power * p <= N:
        power *= p

    answer = (answer * power) % MOD

answer = (2 * answer) % MOD

print(answer)
```---

 # コードのチュートリアル

 ### 素数生成

 の`segmented_sieve`関数は以下のすべての素数を生成します$10^8$すべての数値を一度に保存することなく効率的に実行できます。 

- まず、以下のすべての素数を計算します。$\sqrt{10^8}=10^4$。 
- 次に、残りの範囲をサイズのブロック単位で処理します。$10^6$。 

これにより、メモリ使用量が低く抑えられます。 

---

 ### LCM の計算

 素数ごとに$p$、```python
power = p
while power * p <= N:
    power *= p
```計算する$$p^{\lfloor \log_p N\rfloor}.$$これらを掛け合わせると、$$\operatorname{lcm}(1,\dots,N).$$すべてはモジュロで実行されます$10^9+7$。 

最後に次を掛けます$2$。
