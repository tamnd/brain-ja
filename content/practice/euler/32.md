[プロジェクト オイラー問題 32](https://projecteuler.net/problem=32)

 ## 解決策

 **答え:**`45228`私たちはあらゆるアイデンティティを求めます$$a \times b = c$$の 10 進数のとき、$a$、$b$、 そして$c$を連結すると、$1$-を通して-$9$パンデジタル番号: すべての桁$1,2,\dots,9$は 1 回だけ表示されます。 

すべての個別の積を合計する必要があります$c$。 

---

 # 数学的分析

 しましょう:

 - 被乗数$= a$- 乗数$= b$- 製品$= c$の連結$a,b,c$合計 9 桁を使用します。 

## ステップ 1 — 可能な桁の長さを決定する

 次のように仮定します。 

-$a$もっている$m$数字
 -$b$もっている$n$数字
 -$c$もっている$p$数字

 次に:$$m+n+p=9$$また、乗算はおおよそ次の条件を満たします。$$p \approx m+n \quad \text{or} \quad m+n-1$$なぜなら、$m$-桁の数字$n$-桁の数値は、次のいずれかを生成します。$(m+n)$-数字または$(m+n-1)$-桁の数字。 

Substitute into the digit condition:$$m+n+p=9$$もし$p=m+n$、 それから：$$2(m+n)=9$$不可能。 

したがって必然的に次のようになります。$$p=m+n-1$$それで：$$m+n+(m+n-1)=9$$

$$2(m+n)=10$$

$$m+n=5$$したがって:$$p=4$$したがって、積は 4 桁の数値である必要があり、被乗数は合わせて 5 桁を使用します。 

考えられる分割:

 -$1$-桁×$4$-桁$=4$-桁
 -$2$-桁×$3$-桁$=4$-桁

 他のケースでは機能しません。 

---

 # ステップ 2 — ブルートフォース検索戦略

 あらゆる可能性を直接テストできます。 

すべての候補ペアについて$(a,b)$:

 1. 以下を計算します。$$c=a\times b$$2. 文字列を形成します。$$s = \text{str}(a)+\text{str}(b)+\text{str}(c)$$3. 以下を確認します。 

- 長さは9です
 - 数字は正確です$1,\dots,9$- ゼロは表示されません
 - 数字の繰り返しはありません

 重複した製品を複数回カウントしないようにするには、有効な製品をセットに保存します。 

最後に計算します:$$\sum \text{(distinct products)}$$---

 # Pythonの実装```python
def is_pandigital(a, b, c):
    """
    Return True if concatenating a, b, c produces
    a 1-through-9 pandigital number.
    """
    s = str(a) + str(b) + str(c)

    # Must use exactly 9 digits
    if len(s) != 9:
        return False

    # Digits must be exactly 1..9
    return set(s) == set("123456789")

products = set()

# Case 1:
# 1-digit × 4-digit = 4-digit
for a in range(1, 10):
    for b in range(1000, 10000):
        c = a * b

        if is_pandigital(a, b, c):
            products.add(c)

# Case 2:
# 2-digit × 3-digit = 4-digit
for a in range(10, 100):
    for b in range(100, 1000):
        c = a * b

        if is_pandigital(a, b, c):
            products.add(c)

# Sum all distinct products
answer = sum(products)

print(answer)
```---
