[プロジェクト オイラー問題 198](https://projecteuler.net/problem=198)

 ## 解決策

 **答え:**`52374425`有理数が_曖昧_である場合を正確に特徴付けてみましょう。 

2 つの換算された分数があるとします。$$\frac ab < \frac cd$$連続する Farey 隣接関数、つまり$$bc-ad=1.$$古典的な定理では、分母を持つそれらの間のすべての有理数は次のようになります$< b+d$端点の 1 つよりも間隔内のどの点からも遠いです。 特に、2 つの端点が等しく近い固有の点は、中央間隔の中点です。$$x=\frac{\frac ab+\frac cd}{2}.$$番号$x$正確に言うと曖昧です$\frac ab$そして$\frac cd$は連続するファレー分数であり、分母の境界は次のとおりです。$b+d-1$。 この場合、両方のエンドポイントが最良近似になります。 

ここで、曖昧な有理数の正確な形式を導き出します。 

---

 #1. 数学的分析

 しましょう$$\frac ab < \frac cd,\qquad bc-ad=1.$$中間点は$$x=\frac12\left(\frac ab+\frac cd\right)   =\frac{ad+bc}{2bd}.$$使用する$bc-ad=1$、$$ad+bc = 2ad+1.$$したがって、$$x=\frac{2ad+1}{2bd}.$$次に gcd を計算します。$$\gcd(2ad+1,\,2bd).$$以来$2ad+1$は奇数であるため、公約数は除算する必要があります$bd$。 しかし$$2ad+1 \equiv 1 \pmod d,$$そして$$2ad+1 \equiv 1 \pmod b,$$なぜなら$bc-ad=1\Rightarrow ad\equiv -1\pmod b$、など。したがって、gcd は$1$。 つまり、曖昧な数字はすべて分母が減ります$$q=2bd.$$逆に、すべての Fare 隣接ペアはあいまいな数値を生成します。 

したがって、問題は次のようになります。 

フェアリー隣接ペアをカウントする$(a,b),(c,d)$そのような$$bc-ad=1,$$

$$0<\frac{2ad+1}{2bd}<\frac1{100},$$

$$2bd\le 10^8.$$不等式を単純化します。 

以来$$\frac{2ad+1}{2bd}<\frac1{100},$$以下を乗算します:$$100(2ad+1)<2bd.$$使用する$bc-ad=1\Rightarrow ad=bc-1$、$$100(2bc-1)<2bd.$$再配置:$$200bc-100<2bd,$$

$$100c+\frac{-50}{b}<d.$$以来$b,d,c$は整数であり、$b>0$、$$d>100c.$$したがって、条件はまさに$$d>100c.$$行列式条件は次のようになります。$$bc-ad=1.$$固定共素の場合$b,d$、解決策は正確に 1 つあります$a,c$と$$0<c<b,$$つまり$$cd\equiv 1\pmod b.$$したがって$c$の逆モジュラーです$d$モッド$b$。 

したがって、互いに素のペアを数えなければなりません$(b,d)$そのような$$2bd\le 10^8,$$そしてもし$c=d^{-1}\pmod b$と$1\le c<b$、 それから$$d>100c.$$---

 ## キーの対称性のトリック

 書く$$d = kb + r,\qquad 1\le r<b,\qquad \gcd(r,b)=1.$$それから$$c \equiv r^{-1}\pmod b.$$条件はこうなります$$kb+r > 100c.$$大型用$k$, this is automatically true.

 驚くべき単純化は全単射から来ています$$r \leftrightarrow c=r^{-1}\pmod b.$$として$r$残基削減モジュールを実行します$b$、それもそうです$c$。 したがって、固定用$b$、許容されるもののうち、$d$'つまり、満足のいく割合です$d>100c$漸近的です$1/100$。 

しかし、正確な数が必要です。 

効率的なソリューションで使用されるより直接的な導出は次のとおりです。 

各共素ペアについて$(b,c)$、すべて有効です$d$満足のいく数字か$$d \equiv c^{-1}\pmod b,$$

$$d>100c,$$

$$d\le \frac{10^8}{2b}.$$書く$$d=d_0+tb,$$どこ$d_0$の最小の正の逆数です$c$モジュロ$b$。 次に、有効な数$d$は$$\max\left( 0,\; \left\lfloor \frac{10^8/(2b)-d_0}{b} \right\rfloor - \left\lfloor \frac{100c-d_0}{b} \right\rfloor \right).$$すべての共素を直接合計する$(b,c)$まで$b\le \sqrt{5\times10^7}\approx 7071$実現可能です。

 #2. Pythonの実装```python
from math import gcd

LIMIT = 10**8
ans = 0

# Since 2*b*d <= LIMIT and d > b,
# we only need b up to sqrt(LIMIT/2)
BMAX = int((LIMIT // 2) ** 0.5) + 1

for b in range(1, BMAX + 1):

    max_d = LIMIT // (2 * b)

    for c in range(1, b):

        if gcd(b, c) != 1:
            continue

        # d0 = inverse of c modulo b
        d0 = pow(c, -1, b)

        # smallest d congruent to d0 mod b
        # and strictly greater than 100*c
        if d0 > 100 * c:
            first = d0
        else:
            t = (100 * c - d0) // b + 1
            first = d0 + t * b

        if first <= max_d:
            ans += (max_d - first) // b + 1

print(ans)
```---
