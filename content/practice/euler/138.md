[プロジェクト オイラー問題 138](https://projecteuler.net/problem=138)

 ## 解決策

 **答え:**`1118049290473932`二等辺三角形には次のものがあるとします。 

- ベース$b$、
 - 等しい辺$L$、
- 身長$h$、

 条件付きで$$h=b\pm1.$$高度が底辺を二等分するので、足のある直角三角形が得られます。$h$そして$b/2$、斜辺$L$:$$L^2=h^2+\left(\frac b2\right)^2.$$整数を使用してすべての整数解を求めます$b,L$。 

---

 #1. 数学的分析

 セット$$b=2x,$$底面が均一でなければならないからです。 それから$$L^2=h^2+x^2.$$条件$h=b\pm1$になる$$h=2x\pm1.$$代わりの：$$L^2 = x^2 + (2x\pm1)^2.$$展開すると得られる$$L^2 = x^2 + 4x^2 \pm 4x +1      = 5x^2 \pm 4x +1.$$したがって、解決しなければなりません$$L^2 = 5x^2 \pm 4x +1.$$---

 ## ペル方程式への変換

 乗算する$5$:$$5L^2 = 25x^2 \pm 20x +5.$$知らせ$$(5x\pm2)^2 = 25x^2 \pm 20x +4.$$したがって、$$5L^2 = (5x\pm2)^2 +1,$$それで$$(5x\pm2)^2 - 5L^2 = -1.$$定義する$$y = 5x\pm2.$$次に、ペル方程式を取得します。$$y^2 - 5L^2 = -1.$$これが重要な洞察です。 

---

 ## ソリューションの構造

 根本的な解決策は、$$y^2-5L^2=-1$$は$$(2,1).$$すべての解は次のべき乗から再帰的に生成されます。$$9+4\sqrt5,$$または漸化関係による等価。 

最初の数個$(y,L)$解決策は次のとおりです。$$(2,1), (38,17), (682,305), (12238,5473), \dots$$些細なことを捨てる$L=1$、問題で説明されている三角形が正確に得られます。 

-$L=17$、
 -$L=305$、
 -など

 ---

 ## 単純な繰り返し

 の$L$-値が満たされる$$L_n = 18L_{n-1} - L_{n-2}.$$から始まる$$L_1=1,\qquad L_2=17.$$12 の非自明な解は、この反復によって迅速に生成されます。 

---

 #2. Pythonの実装```python
# Project Euler 138
# Sum of the first 12 isosceles triangle side lengths L
# satisfying h = b ± 1.

def solve():
    # Recurrence for Pell-generated solutions
    # L_n = 18*L_(n-1) - L_(n-2)

    L_prev = 1
    L_curr = 17

    total = 0
    count = 0

    while count < 12:
        total += L_curr

        # Generate next solution
        L_next = 18 * L_curr - L_prev
        L_prev, L_curr = L_curr, L_next

        count += 1

    return total

print(solve())
```---
