[プロジェクト オイラー問題 629](https://projecteuler.net/problem=629)

 ## 解決策

 **答え:**`626616617`単一の山のサイズの Sprague-Grundy 値を考えます$n$なれ$G_k(n)$ゲームパラメータに関しては$k$。 

杭で構成されるポジションの場合$a_1,\dots,a_m$、SG 値は$$G_k(a_1)\oplus G_k(a_2)\oplus\cdots\oplus G_k(a_m),$$したがって、この xor が存在する場合、ポジションは失われます。$0$。 

したがって、タスクは次のとおりです。 

1. コンピューティング$G_k(n)$みんなのために$n\le 200$、
 2. パーティションを数える$200$xor は誰のものですか$0$、
 3. それを勝利数に変換します。 

---

 # 1. SG 値の計算

 単一の山のサイズの場合$n$、移動はそれを分割することで構成されます。$$n=b_1+\cdots+b_p,\qquad 2\le p\le k,$$みんなで$b_i\ge1$。 

したがって$$G_k(n)=\operatorname{mex}\Bigl\{ G_k(b_1)\oplus\cdots\oplus G_k(b_p) \Bigr\}.$$これらを次から再帰的に計算します。$1$上向きに。 

- -

＃＃ 場合$k=2$バイナリ分割のみが許可されます。 

SG 値は次のようになります。$$0,1,0,1,0,1,\dots$$つまり$$G_2(n)= (n-1)\bmod 2.$$- -

＃＃ 場合$k\ge4$重要な現象が発生します。$$G_k(n)=n-1 \qquad (k\ge4).$$実際、4 方向の分割が利用可能になると、すべての値が$0,1,\dots,n-2$到達可能になるため、mex は$n-1$。 

したがって、すべて$k\ge4$は同一です。 

したがって、必要なのは次のものだけです。 

-$k=2$、
 -$k=3$、
 - 代表者1名$k=4$みんなのために$k\ge4$。 

したがって、$$g(200)=f(200,2)+f(200,3)+197\,f(200,4).$$---

 # 2. 失われたパーティションを数える

 しましょう$sg[a]$サイズの積み重ねのSG値を示します$a$。 

パーティションを数えます$N=200$xor は誰のものですか$0$。 

動的プログラミング:$$dp[s][x]$$= 合計のパーティション数$s$xor は誰のものですか$x$。 

パーツサイズを追加する場合$a$その通り$m$回:

 - 合計への貢献:$m a$、
 - xor への貢献:

 -$0$もし$m$平、
-$sg[a]$もし$m$奇数。 

これにより、標準のパーティション スタイルの DP が得られます。 

もし$L_k$は負けポジションの数です。$$f(200,k)=p(200)-L_k,$$どこ$p(200)$はパーティション番号です。

 #3. Pythonの実装```python
from functools import lru_cache

N = 200
MOD = 10**9 + 7

# ------------------------------------------------------------
# Partition numbers p(n)
# ------------------------------------------------------------

p = [0] * (N + 1)
p[0] = 1

for a in range(1, N + 1):
    for s in range(a, N + 1):
        p[s] += p[s - a]

P200 = p[200]

# ------------------------------------------------------------
# Compute SG values for fixed k
# ------------------------------------------------------------

def compute_sg(k, N):
    sg = [0] * (N + 1)

    for n in range(1, N + 1):

        reachable = set()

        # Generate all splits into p parts
        for parts in range(2, min(k, n) + 1):

            arr = [0] * parts

            def gen(rem, idx, mx, xr):
                if idx == parts - 1:
                    if 1 <= rem <= mx:
                        reachable.add(xr ^ sg[rem])
                    return

                upper = min(mx, rem - (parts - idx - 1))

                for v in range(upper, 0, -1):
                    gen(rem - v, idx + 1, v, xr ^ sg[v])

            gen(n, 0, n - 1, 0)

        g = 0
        while g in reachable:
            g += 1

        sg[n] = g

    return sg

# k = 2 and k = 3 explicitly
sg2 = compute_sg(2, N)
sg3 = compute_sg(3, N)

# For all k >= 4:
# G_k(n) = n - 1
sg4 = [i - 1 for i in range(N + 1)]

# ------------------------------------------------------------
# Count losing partitions using xor DP
# ------------------------------------------------------------

def losing_count(sg):

    MAXX = 512

    dp = [[0] * MAXX for _ in range(N + 1)]
    dp[0][0] = 1

    for a in range(1, N + 1):

        ndp = [[0] * MAXX for _ in range(N + 1)]

        for s in range(N + 1):
            for x, val in enumerate(dp[s]):

                if val == 0:
                    continue

                # choose multiplicity m of part size a
                for m in range((N - s) // a + 1):

                    nx = x
                    if m % 2 == 1:
                        nx ^= sg[a]

                    ndp[s + m * a][nx] += val

        dp = ndp

    return dp[N][0]

L2 = losing_count(sg2)
L3 = losing_count(sg3)
L4 = losing_count(sg4)

f2 = P200 - L2
f3 = P200 - L3
f4 = P200 - L4

answer = (f2 + f3 + 197 * f4) % MOD

print(answer)
```---

 #4. コードのチュートリアル

 ### パーティション番号```python
p[s] += p[s-a]
```これは古典的なパーティション DP コンピューティングです$p(n)$。 

---

 ### SG の計算

 それぞれについて$n$:

 - あらゆる法的分割を生成し、
 - 子パイルの SG 値の xor、
 -メキシコを連れて行きます。 

再帰`gen(...)`増加しないパーティションを列挙するため、各分割は 1 回カウントされます。 

---

 ### 負けポジション DP

 パイルサイズごとに$a$:

 - 多重度を選択します$m$、
- 追加$m a$合計額に、
 - xor による`sg[a]`もし$m$奇数です。 

最後に：```python
dp[200][0]
```負けポジションの数です。
