[プロジェクト オイラー問題 276](https://projecteuler.net/problem=276)

 ## 解決策

 **答え:**`5777137137739632912`させて$$T(N)=\#\{(a,b,c): a\le b\le c,\ a+b>c,\ a+b+c\le N\}$$周囲長が最大のすべての整数辺三角形の数になります。$N$、そしてさせてください$$P(N)$$**プリミティブ**の数になります (つまり、$\gcd(a,b,c)=1$）。 

私たちが欲しいのは$P(10^7)$。 

---

 ## 1. 数学的分析

 ### ステップ 1: 外周のすべての整数三角形を数える$n$させて$t(n)$周囲を正確に持つ整数の三角形の数である$n$。 

古典的な結果は次のようになります。$$t(n)=\operatorname{round}\!\left(\frac{n^2}{12}\right) -\left\lfloor \frac n4 \right\rfloor \left\lfloor \frac{n+2}{4}\right\rfloor.$$小さな例で検証できます。 

-$n=3$： のみ$(1,1,1)$、 それで$t(3)=1$-$n=5$： のみ$(1,2,2)$、 それで$t(5)=1$-$n=6$:$(1,2,3)$三角不等式は失敗しますが、$(2,2,2)$、$(1,2,3)$無効、$(1,1,4)$無効なので、$(2,2,2)$そして$(1,2,3)$除く ⇒$t(6)=1$公式は一致します。 

累積数を定義します。$$A(N)=\sum_{n\le N} t(n).$$以来$t(n)$周期的な補正を伴う二次関数 (周期 12)、$A(N)$は3次準多項式になります。 書き込み$$N=12q+r,\qquad 0\le r<12,$$正確な結果が得られます$O(1)$の公式$A(N)$。 例えば：$$A(12q)=6q^2(2q+1),$$他の 11 残基クラスについても同様です。 

---

 ### ステップ 2: メビウス反転による原始三角形

 すべての三角形$(a,b,c)$固有の gcd を持っています$d$:$$(a,b,c)=d(a',b',c')$$と$(a',b',c')$原生的。 

したがって：$$A(N)=\sum_{d\le N} P\!\left(\left\lfloor \frac Nd\right\rfloor\right).$$これは除数の畳み込みです。 

メビウス反転を適用する:$$P(N) = \sum_{d\le N} \mu(d)\, A\!\left(\left\lfloor \frac Nd\right\rfloor\right),$$どこ$\mu$はメビウス関数です。 

したがって、タスクは次のようになります。 

1. コンピューティング$\mu(d)$まで$10^7$直線ふるいを使用します。 
2. Mertens プレフィックスの合計を計算します。$$M(n)=\sum_{k\le n}\mu(k).$$1. 等しい値をグループ化する$\lfloor N/d\rfloor$:$$P(N) = \sum A(v)\, \bigl(M(r)-M(l-1)\bigr),$$どこ$v=\lfloor N/l\rfloor$そして$r=\lfloor N/v\rfloor$。 

これにより、合計は次のようになります。$O(\sqrt N)$。

 ## 2. Python の実装```python
from array import array

N = 10_000_000

def cumulative_triangles(n):
    """
    A(n) = number of integer-sided triangles
    with perimeter <= n.
    Exact O(1) quasipolynomial formula.
    """
    q, r = divmod(n, 12)

    if r == 0:
        return 6 * q * q * (2 * q + 1)
    elif r == 1:
        return q * (12 * q * q + 9 * q + 2)
    elif r == 2:
        return 3 * q * (2 * q + 1) ** 2
    elif r == 3:
        return 12 * q**3 + 15 * q**2 + 6 * q + 1
    elif r == 4:
        return (2 * q + 1) * (6 * q**2 + 6 * q + 1)
    elif r == 5:
        return 12 * q**3 + 21 * q**2 + 12 * q + 2
    elif r == 6:
        return 3 * (q + 1) * (2 * q + 1) ** 2
    elif r == 7:
        return (q + 1) * (12 * q**2 + 15 * q + 5)
    elif r == 8:
        return 6 * (q + 1) ** 2 * (2 * q + 1)
    elif r == 9:
        return 3 * (q + 1) ** 2 * (4 * q + 3)
    elif r == 10:
        return (q + 1) * (12 * q**2 + 24 * q + 11)
    else:  # r == 11
        return 3 * (q + 1) ** 2 * (4 * q + 5)

# ----- Linear sieve for Möbius function -----

mu = array('b', [0]) * (N + 1)
lp = array('I', [0]) * (N + 1)
primes = array('I')

mu[1] = 1

for i in range(2, N + 1):
    if lp[i] == 0:
        lp[i] = i
        primes.append(i)
        mu[i] = -1

    li = lp[i]

    for p in primes:
        v = i * p
        if v > N or p > li:
            break

        lp[v] = p

        if p == li:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# ----- Prefix sums of Möbius -----

M = array('i', [0]) * (N + 1)

running = 0
for i in range(1, N + 1):
    running += mu[i]
    M[i] = running

# ----- Möbius inversion with floor-division grouping -----

answer = 0
l = 1

while l <= N:
    v = N // l
    r = N // v

    answer += cumulative_triangles(v) * (M[r] - M[l - 1])

    l = r + 1

print(answer)
```---

 ## 3. コードのチュートリアル

 ###`cumulative_triangles(n)`計算します$$A(n)=\sum_{k\le n} t(k)$$12 を法とする正確な剰余クラスの式を使用して定数時間で計算します。 

これにより、次の時点までのすべての三角形のカウントを保存することがなくなります。$10^7$。 

---

 ### リニアシーブ

 メビウス関数を計算します。$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$を使用して$O(N)$リニアふるい。 

---

 ### プレフィックス メルテンス関数

 私たちは以下を保管します:$$M(n)=\sum_{k\le n}\mu(k)$$高速範囲合計を可能にするには:$$\sum_{d=l}^r \mu(d)=M(r)-M(l-1).$$---

 ### ハーモニックグループ化のトリック

 以来$$\left\lfloor \frac Nd\right\rfloor$$だけかかります$O(\sqrt N)$個別の値の場合、一定である間隔を処理します。 

これにより、最終的な合計が次のように減ります。$10^7$おおよその反復回数$2\sqrt N$。
