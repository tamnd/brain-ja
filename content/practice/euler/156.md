[プロジェクト オイラー問題 156](https://projecteuler.net/problem=156)

 ## 解決策

 **答え:**`21295121502550`させて$$f(n,d)=\text{number of occurrences of digit }d\text{ in }1,2,\dots,n.$$計算しなければなりません$$\sum_{d=1}^9 s(d), \qquad s(d)=\sum_{n:\,f(n,d)=n} n.$$主な難点は、ソリューションが膨大であることです（最大約$10^{11}$–$10^{13}$）なので、総当たりは不可能です。 

---

 #1. 数学的分析

 固定桁の場合$d$、 定義する$$g_d(n)=f(n,d)-n.$$すべてのゼロを求めます$g_d(n)$。 

---

 ## 数字の出現を効率的にカウントする

 小数点以下の位置の場合$10^k$、 させて

-`higher`= 現在位置の左の桁、
 -`current`= 現在の位置の数字、
 -`lower`= 現在の位置の右の桁。 

そして、このポジションの貢献は、$f(n,d)$は：$$\begin{cases} (higher+1)\cdot 10^k, & current>d,\\[4pt] higher\cdot 10^k + lower +1, & current=d,\\[4pt] higher\cdot 10^k, & current<d. \end{cases}$$すべての小数点以下の桁を合計すると、次のようになります。$f(n,d)$で$O(\log n)$。 

---

 ## の構造$g_d(n)$観察する：$$g_d(n+1)-g_d(n) = (\text{number of }d\text{'s in }n+1)-1.$$したがって、次のようになります。 

- 関数はゆっくりと変化します。 
- 連続する整数の間では、最大で減少する可能性があります$1$。 

これにより、重要な間隔枝刈りルールが得られます。 

区間を調べてみるとします$[a,b]$。 

もし$$g_d(a) > b-a,$$さらに、可能な最大量だけ減少します ($-1$ステップごと)、関数は到達できません$0$間隔の中。 

同様に、$$g_d(b) < a-b,$$その後、関数は元に戻ることはできません$0$。 

したがって、そのような区間には解が含まれません。 

これにより、広大な範囲にわたる分割統治探索が可能になります。

 #2. Pythonの実装```python
from functools import lru_cache

def count_digit(n, d):
    """Count occurrences of digit d in 1..n."""
    if n <= 0:
        return 0

    count = 0
    factor = 1

    while factor <= n:
        higher = n // (factor * 10)
        current = (n // factor) % 10
        lower = n % factor

        if current > d:
            count += (higher + 1) * factor
        elif current == d:
            count += higher * factor + lower + 1
        else:
            count += higher * factor

        factor *= 10

    return count

@lru_cache(None)
def g(n, d):
    return count_digit(n, d) - n

def solve_digit(d, limit=10**13):
    """
    Find all n such that f(n,d)=n.
    Uses recursive interval pruning.
    """
    solutions = []

    def search(a, b):
        ga = g(a, d)
        gb = g(b, d)

        # Impossible to hit zero inside interval
        if ga > (b - a):
            return

        if gb < (a - b):
            return

        # Small interval: check directly
        if b - a <= 1:
            if ga == 0:
                solutions.append(a)

            if b != a and gb == 0:
                solutions.append(b)

            return

        mid = (a + b) // 2

        search(a, mid)
        search(mid + 1, b)

    search(0, limit)

    return sorted(set(solutions))

total = 0

for d in range(1, 10):
    sols = solve_digit(d)
    sd = sum(sols)

    print(f"d={d}")
    print("solutions:", sols[:10], "...")
    print("s(d) =", sd)
    print()

    total += sd

print("FINAL =", total)
```---

 #3. コードのチュートリアル

 ##`count_digit`これは計算します$f(n,d)$digit-position by digit-position.

 例$n=12,d=1$:

 数字:$$1,10,11,12$$含む$1+1+2+1=5$つまり、$$f(12,1)=5.$$この関数はまさにこれを返します。 

---

 ##`g(n,d)`私たちは定義します$$g(n,d)=f(n,d)-n.$$解決策はまさに次の場合に発生します。$$g(n,d)=0.$$---

 ## 再帰的な間隔検索

 インターバルごとに$[a,b]$：

- 評価する$g(a)$そして$g(b)$、
 - 不可能な間隔を切り詰めます。 
- それ以外の場合は半分に分割します。 

剪定が非常に強力であるため、実際に探索する必要があるのは広大な範囲のほんの一部だけです。
