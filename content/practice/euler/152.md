[プロジェクト オイラー問題 152](https://projecteuler.net/problem=152)

 ## 解決策

 **答え:**`301`すべてのサブセットに対する直接的なブルート フォース検索$\{2,3,\dots,80\}$不可能です:$$2^{79} \approx 6\times 10^{23}.$$この問題を解決する鍵は、分母とモジュラーの可分性から生じる強力な算術制約を利用することです。 

---

 # 数学的分析

 すべてのサブセットを探します$S \subseteq \{2,\dots,80\}$そのような$$\sum_{n\in S}\frac1{n^2}=\frac12.$$定義する$$f(n)=\frac1{n^2}.$$中心的な観察は、素因数の割り算の制約のため、ほとんどの整数は決して有効な解に参加できないということです。 

---

 ## 1. 素数べき除算フィルタリング

 素数を仮定します$p$分母項が 1 つだけ出現し、最大値が得られます。$p$-アディックパワー。 

例: もし$n$で割り切れます$p^k$選択された他の分母には以下が含まれない$p^k$、分母をクリアした後、その項によって寄与される分子は非ゼロモジュロになります。$p$、他のものはすべてモジュロで消えます$p$。 そのためキャンセルは不可となります。 

これにより、非常に強力な制限が生じます。 

---

 ### 例: 素数$79$で割り切れる唯一の分母$79$は$79$自体。 

もし$1/79^2$が現れ、共通分母を乗算すると、ゼロ以外の剰余モジュロが得られます。$79$、キャンセル不可。 

したがって、次のようになります。$$79 \notin S.$$同じ引数で多くの数値が削除されます。 

---

 ## 2. 許容セットの構築

 標準的な再帰的削除では、整数のみが残ります。$$\{2,3,4,5,6,7,8,9,10,12,14,15,18,20,21,24,28,30,35,36,40,42,45,56,60,63,70,72\}.$$すべての有効なソリューションがこのセットに含まれている必要があります。 

これにより、検索スペースが大幅に削減されます。$$2^{28}\approx 2.68\times10^8,$$まだ大きいですが、中間者と正確な有理演算を使用することで実現可能になりました。 

---

 ## 3. 正確な整数表現

 しましょう$$L=\operatorname{lcm}(n^2 : n\in A),$$どこ$A$は許容されるセットです。 

それから$$\frac1{n^2} = \frac{L/n^2}{L}.$$したがって、方程式は次のようになります$$\sum_{n\in S} \frac{L}{n^2} = \frac{L}{2}.$$これで、すべてが整数のサブセットの合計になります。 

定義する$$a_n = \frac{L}{n^2},\qquad T=\frac{L}{2}.$$サブセットを数えなければなりません$$\sum a_n = T.$$---

 ## 4. 中間者会議

 許容セットを 2 つに分割します。 

- 左半分$A_1$- 右半分$A_2$それぞれの半分のすべてのサブセットの合計を列挙します。 

もし$$x+y=T,$$と$x$左からと$y$右から順に並べると、それらが一緒になって有効なソリューションを形成します。 

複雑さは大まかになります$$2^{14}+2^{14},$$それは小さいです。 

---

 # Pythonの実装```python
from math import gcd
from functools import reduce
from collections import Counter

# ------------------------------------------------------------
# Utility: least common multiple
# ------------------------------------------------------------

def lcm(a, b):
    return a * b // gcd(a, b)

# ------------------------------------------------------------
# Step 1:
# After modular/divisibility elimination, only these numbers
# can possibly appear in a solution.
# ------------------------------------------------------------

allowed = [
    2, 3, 4, 5, 6, 7, 8, 9, 10,
    12, 14, 15, 18, 20, 21, 24,
    28, 30, 35, 36, 40, 42, 45,
    56, 60, 63, 70, 72
]

# ------------------------------------------------------------
# Step 2:
# Convert the reciprocal-square equation into an integer
# subset-sum equation.
# ------------------------------------------------------------

# L = lcm of all n^2
L = reduce(lcm, (n * n for n in allowed))

# Integer weights
weights = [L // (n * n) for n in allowed]

# Target sum
TARGET = L // 2

# ------------------------------------------------------------
# Step 3:
# Meet-in-the-middle
# ------------------------------------------------------------

mid = len(weights) // 2

left = weights[:mid]
right = weights[mid:]

def subset_sums(arr):
    """
    Return Counter mapping:
        subset_sum -> number_of_ways
    """
    m = len(arr)
    sums = Counter()

    for mask in range(1 << m):
        s = 0
        for i in range(m):
            if mask & (1 << i):
                s += arr[i]
        sums[s] += 1

    return sums

left_sums = subset_sums(left)
right_sums = subset_sums(right)

# ------------------------------------------------------------
# Step 4:
# Count complementary pairs
# ------------------------------------------------------------

answer = 0

for s_left, count_left in left_sums.items():
    needed = TARGET - s_left

    if needed in right_sums:
        answer += count_left * right_sums[needed]

print(answer)
```---
