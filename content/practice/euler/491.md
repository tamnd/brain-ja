 ## 解決策

 **答え:**`194505988824000`20桁の数字を次のようにします$$d_1d_2\dots d_{20}$$ここで、各桁は$0,1,\dots,9$ちょうど 2 回出現し、$d_1\neq 0$。 

このような数値の次の数が必要です。$11$。 

標準的な可分性テストでは次のようになります。$$(d_1+d_3+\cdots+d_{19})-(d_2+d_4+\cdots+d_{20}) \equiv 0 \pmod{11}.$$すべての数字が 2 回出現するため、すべての数字の合計は次のようになります。$$2(0+1+\cdots+9)=2\cdot 45=90.$$させたら

 -$S_{\text{odd}}$= 奇数桁の数字の合計、
 -$S_{\text{even}}$= 偶数桁の合計、

 それから$$S_{\text{odd}}+S_{\text{even}}=90,$$で割り切れる$11$必要$$S_{\text{odd}}-S_{\text{even}}\equiv 0\pmod{11}.$$2 つの方程式を追加すると、次のようになります。$$2S_{\text{odd}} \equiv 90 \pmod{11}.$$以来$90\equiv 2\pmod{11}$、$$2S_{\text{odd}}\equiv 2 \pmod{11}.$$の逆数を掛ける$2$モジュロ$11$(つまり$6$):$$S_{\text{odd}}\equiv 1\pmod{11}.$$しかし$S_{\text{odd}}$マルチセットから選択された 10 桁の合計です$$\{0,0,1,1,\dots,9,9\}.$$可能な範囲の合計は約$45$、そして合計は$90$、合同を満たす唯一の実現可能な値は、$$S_{\text{odd}}=45.$$したがって:

 > 奇数桁の 10 桁の合計は正確に 45 になる必要があります。

 # 1. 有効な奇数/偶数選択の特徴付け

 各桁ごとに$k\in\{0,\dots,9\}$、 させて$x_k$数字のコピーの数になります$k$変な位置に置かれています。 

各数字が 2 回出現するため、次のようになります。$$x_k\in\{0,1,2\}.$$必要なものは次のとおりです。$$\sum_{k=0}^9 x_k = 10$$(奇数の位置が 10 個あるため)

 そして$$\sum_{k=0}^9 kx_k = 45.$$ここで次のことを観察してください。$$\sum_{k=0}^9 k = 45.$$定義する$$y_k = x_k-1.$$それから$y_k\in\{-1,0,1\}$、 そして$$\sum y_k = 0,$$

$$\sum ky_k = 0.$$これは次のことを意味します。 

- を含む数字$x_k=2$と数字$x_k=0$合計が等しい必要があります。 

同様に:

 > サブセットを選択する$A$奇数の位置に重複する数字とそのサブセット$B$奇妙な位置にいない場合、
 >
 >
 >
 >
 >$$\sum A = \sum B.$$残りの数字はすべて奇数の位置に 1 回表示されます。

 #2. 固定分布の計数の取り決め

 ベクトルを修正したとします。$(x_0,\dots,x_9)$。 

次に:

 - 奇数の位置には以下が含まれます$x_k$数字のコピー$k$、
 - 偶数の位置には以下が含まれます$2-x_k$コピー。 

がある：$$\frac{10!}{\prod x_k!}$$奇数の位置を配置する方法、および$$\frac{10!}{\prod (2-x_k)!}$$均等な位置に配置する方法。 

しかし、これらは等しいので、$x_k!$そして$(2-x_k)!$も同じです$x_k=0,1,2$。 

させて

-$t$= の桁数$x_k=2$。 

それからまた$t$数字には$x_k=0$、 そして$10-2t$数字には$x_k=1$。 

したがって、$$\prod x_k! = 2^t.$$したがって、この配布の全体的な手配は次のようになります。$$\left(\frac{10!}{2^t}\right)^2.$$---

 #3. 先行ゼロ補正

 ## ケース A:$x_0=0$奇数の位置にはゼロが存在しないため、最初の桁をゼロにすることはできません。 

修正は必要ありません。 

貢献：$$\left(\frac{10!}{2^t}\right)^2.$$---

 ## ケース B:$x_0=1$奇数の位置にゼロが 1 回出現します。 

あらゆる奇数配置の中でも、まさに$1/10$ゼロから始めます。 

したがって、有効な奇数の配置は次のようになります。$$\frac{9}{10}\cdot \frac{10!}{2^t}.$$アレンジメントも変更なし:$$\frac{10!}{2^t}.$$貢献：$$\frac{9}{10}\left(\frac{10!}{2^t}\right)^2.$$---

 ## ケース C:$x_0=2$両方のゼロが奇数の位置にあります。 

ゼロを同一のものとして扱うと、ゼロで始まる小数は次のようになります。$2/10=1/5$。 

したがって、有効な奇数の配置は次のとおりです。$$\frac45\cdot \frac{10!}{2^t}.$$貢献：$$\frac45\left(\frac{10!}{2^t}\right)^2.$$---

 # 4. 有効な分布を列挙する

 すべてのベクトルを数えます$(x_0,\dots,x_9)$制約を満たしていること。 

コンパクトな方法は強引な方法です$3^{10}=59049$可能性。 

---

 # Pythonの実装```python
from itertools import product
from math import factorial

# Precompute 10!
F = factorial(10)

answer = 0

# x_k = number of copies of digit k in odd positions
# each x_k is 0,1,2
for xs in product((0, 1, 2), repeat=10):

    # Need exactly 10 digits in odd positions
    if sum(xs) != 10:
        continue

    # Need odd-position digit sum = 45
    if sum(d * xs[d] for d in range(10)) != 45:
        continue

    # t = number of digits appearing twice in odd positions
    t = sum(1 for x in xs if x == 2)

    base = (F // (2 ** t)) ** 2

    x0 = xs[0]

    # Leading-zero correction
    if x0 == 0:
        contribution = base

    elif x0 == 1:
        contribution = base * 9 // 10

    else:  # x0 == 2
        contribution = base * 4 // 5

    answer += contribution

print(answer)
```---
