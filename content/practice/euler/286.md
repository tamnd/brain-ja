[プロジェクト オイラー問題 286](https://projecteuler.net/problem=286)

 ## 解決策

 **答え:**`52.6494571953`させて$$p_x = 1 - \frac{x}{q}$$バーバラが遠距離から得点する確率$x$、 どこ$x=1,2,\dots,50$。 

50 回のショットで **ちょうど 20 点**を獲得する確率は、正確に$2\%$:$$\Pr(\text{exactly 20 successes}) = 0.02.$$私たちは決めなければなりません$q>50$。 

---

 # 数学的分析

 ショットごとに$x$:

 - 成功確率:$$p_x = 1-\frac{x}{q}$$- ミス確率:$$1-p_x = \frac{x}{q}.$$ショットは独立していますが、確率はショットごとに異なるため、これは標準の二項分布ではありません**。 

したがって、動的プログラミングを使用します。 

---

 ## DP 配合

 定義する$$dp[k][s]$$最初のことを考慮した後の確率として$k$シュート、バーバラは正確にゴールを決めた$s$ポイント。 

初期状態:$$dp[0][0]=1$$ショットを行う前は、0 回成功する確率は 1 であるためです。 

ショット用$k$:

 - 確率的に$p_k$、スコアが 1 増加します。 
- 確率的に$1-p_k$、それは同じままです。 

したがって、$$dp[k][s] = dp[k-1][s-1]\cdot p_k + dp[k-1][s]\cdot (1-p_k).$$50 ショットすべてを処理した後:$$P(q)=dp[50][20].$$解決しなければなりません$$P(q)=0.02.$$---

 # 単調性

 として$q$増加します:$$p_x = 1-\frac{x}{q}$$ショットごとに増加します。 

したがって、期待される成功数が増加します。つまり、ちょうど 20 回の成功が得られる確率が最終的に減少します (平均が 20 を超えるため)。 

数値的に:

 -$P(52)\approx 0.0240$-$P(55)\approx 0.0101$したがって、解は 52 と 55 の間にあります。 

したがって、二分探索を使用できます。 

---

 # Pythonの実装```python
from math import *

def probability(q):
    # dp[s] = probability of exactly s successes so far
    dp = [0.0] * 21
    dp[0] = 1.0

    # shots from x = 1..50
    for x in range(1, 51):
        p = 1.0 - x / q

        new_dp = [0.0] * 21

        # zero successes case
        new_dp[0] = dp[0] * (1 - p)

        for s in range(1, 21):
            # make shot x
            make = dp[s - 1] * p

            # miss shot x
            miss = dp[s] * (1 - p)

            new_dp[s] = make + miss

        dp = new_dp

    return dp[20]

# Binary search for q
lo = 50.0
hi = 60.0

for _ in range(100):
    mid = (lo + hi) / 2

    if probability(mid) > 0.02:
        lo = mid
    else:
        hi = mid

q = (lo + hi) / 2

print("{:.10f}".format(q))
```---

 ### 二分探索

 私たちはユニークなものを探します$q$満足のいく$$P(q)=0.02.$$もし：```python
probability(mid) > 0.02
```それから$q$は小さすぎるため、下限を上に移動します。 

100 回の反復後、値ははるかに正確になります。$10^{-10}$。
