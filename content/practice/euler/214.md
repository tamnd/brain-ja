[プロジェクト オイラー問題 214](https://projecteuler.net/problem=214)

 ## 解決策

 **答え:**`1677366278943`させて$L(n)$から始まる反復トーティエントチェーンの長さを示します。$n$、両方のエンドポイントをカウントします。 したがって$$5 \to 4 \to 2 \to 1$$長さがある$4$。 

計算するように求められます$$\sum_{\substack{p<40\,000\,000\\ p\text{ prime}\\ L(p)=25}} p.$$---

 # 数学的分析

 ## 1. トーティエントチェーン

 オイラーのトーティエント関数は満たされます$$\phi(n) < n \quad (n>1),$$繰り返し適用すると必ず到達します$1$。 

再帰的に定義します。$$L(1)=1, \qquad L(n)=1+L(\phi(n)).$$例えば：$$L(5)=1+L(4) =1+(1+L(2)) =1+1+(1+L(1)) =4.$$---

 ## 2. 素数の特別な動作

 もし$p$が素数であれば、$$\phi(p)=p-1.$$したがって、$$L(p)=1+L(p-1).$$したがって、鎖の長さで素数を見つけるには$25$までの整数の連鎖の長さを知る必要があるだけです。$40\,000\,000$。 

---

 ## 3. の効率的な計算$\phi(n)$コンピューティング$\phi(n)$それぞれに対して独立して$n$遅すぎるでしょう。 

代わりに、古典的な sieve ID を使用します。 

初期化する$$\phi(n)=n.$$素数ごとに$p$、$$\phi(k)\leftarrow \phi(k)\left(1-\frac1p\right)$$倍数ごとに$k$の$p$。 

これにより、次の値までのすべての合計が計算されます。$N$およそで$$O(N\log\log N).$$---

 ## 4. チェーンの長さの動的プログラミング

 以来$$\phi(n) < n,$$チェーンの長さを昇順に計算できます。$$L(n)=1+L(\phi(n)).$$なぜなら$\phi(n)$はすでに知られており、より小さい$n$、各値は 1 回計算されます。 

---

 ## 5. 必要な素数の検出

 素数$p$貢献する場合$$L(p)=25.$$使用する$$L(p)=1+L(p-1),$$同等に必要です$$L(p-1)=24.$$したがって、素数をふるいにかけながら、これをすぐにテストできます。 

---

 # Pythonの実装```python
LIMIT = 40_000_000

# ---------------------------------------------------------
# Step 1: Compute Euler's totient function for all n
# ---------------------------------------------------------

phi = list(range(LIMIT + 1))
is_prime = bytearray(b"\x01") * (LIMIT + 1)

is_prime[0] = is_prime[1] = 0

for p in range(2, LIMIT + 1):
    if is_prime[p]:
        # p is prime

        # Apply phi formula to all multiples
        for k in range(p, LIMIT + 1, p):
            phi[k] -= phi[k] // p

        # Mark composite numbers
        step = p
        start = p * 2
        for k in range(start, LIMIT + 1, step):
            is_prime[k] = 0

# ---------------------------------------------------------
# Step 2: Compute totient-chain lengths
# ---------------------------------------------------------

chain_len = [0] * (LIMIT + 1)
chain_len[1] = 1

for n in range(2, LIMIT + 1):
    chain_len[n] = chain_len[phi[n]] + 1

# ---------------------------------------------------------
# Step 3: Sum primes with chain length 25
# ---------------------------------------------------------

answer = 0

for p in range(2, LIMIT):
    if is_prime[p] and chain_len[p] == 25:
        answer += p

print(answer)
```---
