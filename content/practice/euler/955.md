[プロジェクト オイラー問題 955](https://projecteuler.net/problem=955)

 ## 解決策

 **答え:**`6795261671274`三角形の数字を次のようにします$$T_m=\frac{m(m+1)}2.$$仮定する$a_r=T_m$はシーケンス内に出現するトライアングル番号であり、次に出現するトライアングル番号は$a_{r+k}=T_n$。 

2 つの三角数の間の漸化式は次のようになります。$$a_{j+1}-a_j=(a_j-a_{j-1})+1,$$三角番号の直後に、差は にリセットされます。$1$。 

したがって、連続する増分は次のようになります。$$1,2,3,\dots,k,$$それで$$T_n-T_m = 1+2+\cdots+k = T_k.$$したがって$$T_n=T_m+T_k.$$使用する$T_x=\frac{x(x+1)}2$、$$n(n+1)=m(m+1)+k(k+1).$$再配置:$$(2n+1)^2=(2m+1)^2+(2k+1)^2-1.$$標準的な因数分解のトリックでは、$$m(m+1)=uv,$$と$$u=\frac{2n+1-(2k+1)}2,\qquad v=\frac{2n+1+(2k+1)}2.$$それから$$2k+1=v-u,\qquad 2n+1=u+v.$$したがって、当然のことながら$m$、シーケンス内の _next_ 三角形の番号を取得するには、因子のペアを選択する必要があります$$uv=m(m+1)$$最小の奇数差で$v-u>1$。 それから$$k=\frac{v-u-1}{2},\qquad n=\frac{u+v-1}{2}.$$から始まる$m=2$（以来$a_0=3=T_2$)、このルールを 69 回繰り返し、対応する値を累積します。$k$-values (インデックスがジャンプします)。 

クリーンな Python 実装は次のとおりです。```python
from math import isqrt
from sympy import divisors

def next_triangle(m):
    N = m * (m + 1)

    best = None
    for u in divisors(N):
        if u * u > N:
            break
        v = N // u
        d = v - u

        # need smallest odd difference > 1
        if d > 1 and d % 2 == 1:
            best = (u, v)

    u, v = best

    k = (v - u - 1) // 2
    n = (u + v - 1) // 2

    return n, k

m = 2          # T_2 = 3
index = 0      # a_0

for _ in range(69):   # move to the 70th triangle number
    m, jump = next_triangle(m)
    index += jump

print(index)
```これにより、$$6795261671274.$$**答え: 6795261671274**
