[プロジェクト オイラー問題 265](https://projecteuler.net/problem=265)

 ## 解決策

 **答え:**`209110240768`長さのすべてのバイナリ循環シーケンスを探します。$2^N$長さのすべてのバイナリ ワードが$N$時計回りの連続したサブシーケンスとして 1 回だけ表示されます。 

これらはまさに、秩序のバイナリ **de Bruijn サイクル ** です。$N$。 

のために$N=5$、問題ステートメントで説明されているすべての個別のエンコーディングの合計を計算する必要があります。 

---

 # 数学的分析

 秩序のバイナリ de Bruijn サイクル$N$は、可能なすべての要素が含まれる循環バイナリ シーケンスです。$N$-bit 文字列は 1 回だけ出現します。 

がある$2^N$このような部分文字列なので、サイクル長は次のようにする必要があります。$2^N$。 

---

 ## 1. グラフの解釈

 有向グラフを定義します。 

- 頂点 = 長さのすべてのバイナリ文字列$N-1$- 有向エッジ = 長さのすべてのバイナリ文字列$N$エッジ$$b_1b_2\dots b_N$$から行く$$b_1b_2\dots b_{N-1}$$に$$b_2b_3\dots b_N$$各頂点には次のものがあります。 

- 出次数$2$- 度数$2$de Bruijn サイクルは、このグラフのオイラー サイクルに正確に対応します。 

---

 ## 2. 正規表現

 この問題では、シーケンスを最初から開始する必要があるため、回転の重複が削除されます。$$00000$$したがって、開始ノードをすべて 0 に固定し、そこから始まるすべてのオイラー サイクルを生成できます。 

生成された巡回系列が$$a_0a_1\dots a_{31}$$エンコードされた整数は次のようになります$$\sum_{i=0}^{31} a_i 2^{31-i}$$---

 ## 3. DFSの構築

 保守:

 - 現在$(N-1)$-ビット接尾辞
 - 訪問者のセット$N$-ビット文字列

 最初に:

 - 訪問した内容$00000$- シーケンスは 5 つのゼロで始まります

 各ステップで:

 - 追加ビット$0$または$1$- 次の形を作る$N$-ビットワード
 - その単語が以前に出現していない場合にのみ続行します

 いつすべて$2^N$単語が訪問された場合、1 つの有効なサイクルが得られます。 

のために$N=5$、この検索は完全に実行可能です。 

---

 # Pythonの実装```python
from collections import defaultdict

def debruijn_sum(n):
    target = 1 << n                 # total N-bit strings
    mask = (1 << (n - 1)) - 1      # keeps last N-1 bits

    visited = {0}                  # start with 000...0 already used
    seq = [0] * n                  # initial sequence = N zeros

    total = 0

    def dfs(node):
        nonlocal total

        # If every N-bit word has appeared exactly once,
        # we have a complete de Bruijn cycle.
        if len(visited) == target:
            bits = seq[:target]
            value = int("".join(map(str, bits)), 2)
            total += value
            return

        suffix = node & mask

        # Try appending 0 or 1
        for bit in (0, 1):
            nxt = (suffix << 1) | bit

            if nxt not in visited:
                visited.add(nxt)
                seq.append(bit)

                dfs(nxt)

                seq.pop()
                visited.remove(nxt)

    dfs(0)
    return total

# Verify the example
print(debruijn_sum(3))   # should be 52

# Solve the problem
print(debruijn_sum(5))
```---

 # DFS ステップ

 現在のサフィックスが$(N-1)$-ビット数`suffix`。 

追加ビット`bit`作成します:```python
nxt = (suffix << 1) | bit
```次はどれですか$N$-ビットワード。 

まだ表示されていない場合は、再帰的に続行します。
