 #1. 数学的分析

 ## ステップ 1: 重要な置き換え

 定義する$$b_n = 6a_n+5.$$それから$$\begin{aligned} b_{n+1} &=6a_{n+1}+5 \\ &=6(6a_n^2+10a_n+3)+5 \\ &=36a_n^2+60a_n+23. \end{aligned}$$しかし$$(6a_n+5)^2-2 =36a_n^2+60a_n+25-2 =36a_n^2+60a_n+23.$$したがって、$$\boxed{b_{n+1}=b_n^2-2}$$と$$b_1=6\cdot1+5=11.$$したがって、再発は次のようになります$$11,\ 119,\ 14159,\dots$$二乗マイナス 2 を繰り返すことによって生成されます。 

---

 ## ステップ 2: クローズドフォーム

 検討してください$$\alpha=\frac{11+3\sqrt{13}}2.$$その共役は$$\alpha^{-1}=\frac{11-3\sqrt{13}}2$$なぜなら$$\alpha\alpha^{-1} =\frac{121-117}{4}=1.$$また、$$\alpha+\alpha^{-1}=11=b_1.$$ここで定義します$$u_n=\alpha^{2^{n-1}}+\alpha^{-2^{n-1}}.$$それから$$u_{n+1} =(u_n)^2-2$$なぜなら$$(x+x^{-1})^2-2=x^2+x^{-2}.$$以来$u_1=11=b_1$、独自性が与える$$\boxed{b_n=\alpha^{2^{n-1}}+\alpha^{-2^{n-1}}}.$$したがって$$\boxed{ a_n=\frac{ \alpha^{2^{n-1}}+\alpha^{-2^{n-1}}-5 }{6}. }$$---

 ## ステップ 3: 素数を法として扱う

 プライムの場合$p\neq 13$、私たちは二次フィールドで作業します$\mathbb F_p(\sqrt{13})$。 

要素$\alpha$規範がある$1$、したがって、その乗算順序は除算されます$$p-\left(\frac{13}{p}\right),$$どこ$\left(\frac{13}{p}\right)$ルジャンドル記号です。 

したがって$$\alpha^{2^{n-1}}$$のみに依存する$$2^{n-1}\bmod \left(p-\left(\frac{13}{p}\right)\right).$$したがって、各素数について$p$:

 1. コンピューティング$$m=p-\left(\frac{13}{p}\right).$$1. コンピューティング$$e=2^{n-1}\bmod m.$$1. コンピューティング$\alpha^e$二次拡張で。 
2.回復する$$a_n=\frac{(\alpha^e+\alpha^{-e})-5}{6}\pmod p.$$以来$m\sim 10^9$、べき乗は小さい (約 30 ビット)。

 #2. Pythonの実装```python
from sympy import primerange

N = 10**15

def value_mod_p(p, n):
    """
    Compute a_n mod p using the closed form.
    """

    # Legendre symbol (13/p)
    ls = 1 if pow(13, (p - 1) // 2, p) == 1 else -1

    # Order divisor
    m = p - ls

    # exponent = 2^(n-1) mod m
    e = pow(2, n - 1, m)

    inv2 = (p + 1) // 2
    inv6 = pow(6, p - 2, p)

    # alpha = (11 + 3*sqrt(13))/2
    # represented as pair (a,b) meaning a + b*sqrt(13)
    a = 11 * inv2 % p
    b = 3 * inv2 % p

    # Fast exponentiation in F_p(sqrt(13))
    ra, rb = 1, 0
    ba, bb = a, b

    while e:
        if e & 1:
            ra, rb = (
                (ra * ba + 13 * rb * bb) % p,
                (ra * bb + rb * ba) % p
            )

        ba, bb = (
            (ba * ba + 13 * bb * bb) % p,
            (2 * ba * bb) % p
        )

        e >>= 1

    # Since alpha has norm 1:
    # alpha^{-e} = conjugate(alpha^e)
    # so alpha^e + alpha^{-e} = 2 * real_part
    b_n = (2 * ra) % p

    # a_n = (b_n - 5)/6
    return ((b_n - 5) * inv6) % p

def B(x, y, n):
    total = 0

    for p in primerange(x, x + y + 1):
        total += value_mod_p(p, n)

    return total

# Verification examples
print(B(10**9, 10**3, 10**3))
print(B(10**9, 10**3, 10**15))

# Final answer
print(B(10**9, 10**7, 10**15))
```---
