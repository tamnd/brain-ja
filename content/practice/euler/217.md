[プロジェクト オイラー問題 217](https://projecteuler.net/problem=217)

 ## 解決策

 **答え:**`6273134`させて$$t(n)=2n^2-1$$おっと — 問題のコンテキストが間違っています。 

代わりに、Project Euler 217 の数量が必要です。$$T(n)=\sum_{\substack{0\le x<10^n\\ x\text{ balanced}}} x$$ここで、最初の値の合計が数値の**バランス**である場合、$\lceil k/2\rceil$桁は最後の合計に等しい$\lceil k/2\rceil$数字。 

私たちは求めています$$T(47)\bmod 3^{15}.$$---

 #1. 数学的分析

 ## 1.1 バランス状態の理解

 ある数字があるとします。$k$数字。 

---

 ### 偶数の長さ:$k=2m$番号を次のように書きます$$N = L\cdot 10^m + R$$どこ：

-$L$最初です$m$数字、
 -$R$最後です$m$数字。 

バランス条件は次のとおりです。$$\text{digitSum}(L)=\text{digitSum}(R).$$---

 ### 奇数の長さ:$k=2m+1$番号を次のように書きます$$N = L\cdot 10^{m+1} + c\cdot 10^m + R$$どこ$c$中桁です。 

定義は最初のものを比較します。$m+1$数字と最後の$m+1$数字:$$\text{digitSum}(L)+c = c+\text{digitSum}(R).$$中央の数字はキャンセルされるので、再度次のようにします。$$\text{digitSum}(L)=\text{digitSum}(R).$$したがって、偶数と奇数の長さの両方が同じコア状態に減少します。 

---

 # 1.2 桁の合計の DP

 定義:$$A(m,s)=\#\{\text{length-}m\text{ digit strings with digit sum }s\}$$先行ゼロを許可します。 

以下も定義します。$$B(m,s)=\sum (\text{all such }m\text{-digit numbers}).$$これらは次の遷移を満たします。$$A(m+1,s+d) += A(m,s)$$そして$$B(m+1,s+d) += 10B(m,s)+dA(m,s).$$なぜ？ 

数字の追加$d$すべての古い数字を変換します$x$の中へ$$10x+d.$$そういったものをすべてまとめると、$x$:$$\sum (10x+d) = 10\sum x + d\cdot(\#\text{numbers}).$$---

 # 1.3 偶数長さの貢献

 のために$2m$-桁のバランスのとれた数値:

 - 左半分$L$先行ゼロは必要ありません。 
- 右半分$R$先頭にゼロが付く場合がありますが、
 - 両方の桁の合計が等しい必要があります$s$。 

させて：

-$C_L(s)$= 有効な左半分の数、
 -$S_L(s)$= 有効な左半分の合計。 

すると、貢献度の合計は、$$\sum_s \left( S_L(s)\cdot 10^m \cdot A(m,s) + C_L(s)\cdot B(m,s) \right).$$最初の項は、上位桁に配置された左半分を説明します。 2 番目は右半分を表します。 

---

 # 1.4 奇数長の貢献

 のために$2m+1$-桁のバランスのとれた数値:$$N=L\cdot10^{m+1}+c\cdot10^m+R.$$固定用$(L,R)$、合計します$c=0,\dots,9$:$$\sum_c N = 10(L\cdot10^{m+1}+R) + 45\cdot10^m.$$したがって：$$\sum_s \left[ 10\left( S_L(s)\cdot10^{m+1}\cdot A(m,s) + C_L(s)\cdot B(m,s) \right) + 45\cdot10^m\cdot C_L(s)\cdot A(m,s) \right].$$---

 #2. Pythonの実装```python
MOD = 3**15
N = 47

# Maximum half-length needed:
# floor(47/2) = 23, but we use 24 safely.
MAXM = 24
MAXS = 9 * MAXM

# A[m][s] = count of m-digit strings with digit sum s
# B[m][s] = sum of all such m-digit numbers
A = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]
B = [[0] * (MAXS + 1) for _ in range(MAXM + 1)]

A[0][0] = 1

# Precompute powers of 10
pow10 = [1]
for _ in range(60):
    pow10.append(pow10[-1] * 10)

# Build DP tables
for m in range(MAXM):
    for s in range(9 * m + 1):

        count = A[m][s]
        total = B[m][s]

        if count == 0 and total == 0:
            continue

        for d in range(10):

            A[m + 1][s + d] += count

            # Appending digit d:
            # new_number = old_number * 10 + d
            B[m + 1][s + d] += total * 10 + count * d

def left_tables(m, s):
    """
    Count/sum of m-digit numbers with no leading zero
    and digit sum s.
    """

    count = 0
    total = 0

    for first in range(1, 10):

        if s - first < 0 or s - first > 9 * (m - 1):
            continue

        cnt = A[m - 1][s - first]

        # Numbers formed as:
        # first * 10^(m-1) + tail
        sm = B[m - 1][s - first] + cnt * first * pow10[m - 1]

        count += cnt
        total += sm

    return count, total

def balanced_sum_length(length):

    # One-digit case
    if length == 1:
        return 45

    # -------------------------------------------------
    # EVEN LENGTH = 2m
    # -------------------------------------------------
    if length % 2 == 0:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            ans += (
                left_sum * pow10[m] * A[m][s]
                + left_count * B[m][s]
            )

        return ans

    # -------------------------------------------------
    # ODD LENGTH = 2m+1
    # -------------------------------------------------
    else:

        m = length // 2
        ans = 0

        for s in range(9 * m + 1):

            left_count, left_sum = left_tables(m, s)

            pair_count = left_count * A[m][s]

            ans += (
                10 * (
                    left_sum * pow10[m + 1] * A[m][s]
                    + left_count * B[m][s]
                )
                + 45 * pow10[m] * pair_count
            )

        return ans

# Compute T(47)
answer = sum(
    balanced_sum_length(k)
    for k in range(1, N + 1)
) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## DP 構築

 数字を追加してすべての数字列を構築します$0\ldots9$。`A[m][s]`長さの文字列の数を保存します`m`桁の合計がある`s`。`B[m][s]`整数として解釈されたすべての文字列の合計を格納します。 

---

 ##`left_tables(m, s)`これは以下を計算します:

 - 有効な左半分の数、
 - 有効な左半分の合計、

 ただし、最初の桁がゼロ以外であるという制限があります。 

先頭の数字を明示的に選択します$1\ldots9$。 

---

 ##`balanced_sum_length(length)`個別に処理します:

 - 均等な長さ、
 - 奇数の長さ。 

上記で導出された式を使用します。 

---
