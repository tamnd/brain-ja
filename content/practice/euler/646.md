[プロジェクト オイラー問題 646](https://projecteuler.net/problem=646)

 ## 解決策

 **答え:**`845218467`させて$$n=\prod_{i=1}^k p_i^{\alpha_i}, \qquad \lambda(n)=(-1)^{\sum \alpha_i}.$$私たちが欲しいのは$$S(n,L,H)=\sum_{\substack{d\mid n\\L\le d\le H}}\lambda(d)\,d.$$この問題については:$$S(70!,10^{20},10^{60}) \pmod{1\,000\,000\,007}.$$## 1. 数学的分析

 もし$$d=\prod_i p_i^{\beta_i}, \qquad 0\le \beta_i\le \alpha_i,$$それから$$\lambda(d) = (-1)^{\sum_i \beta_i}.$$したがって$$\lambda(d)d = \prod_i (-p_i)^{\beta_i}.$$したがって、すべての約数は乗算の符号付き重みに寄与します。 

課題は、$70!$膨大な数の約数があります:$$\tau(70!) = \prod_i (\alpha_i+1) = 3\,543\,845\,437\,440,$$したがって強引な行為は不可能です。 

### 中間者会議

 素数を分割する$70!$2つのグループに分けて$A,B$。 

グループ内の各部分約数について$A$、次を計算します。 

- その価値$a$、
 - 署名された寄稿文$t_A=\lambda(a)a$。 

グループでも同様に$B$:

 - 約数$b$、
 - 署名された寄稿$t_B=\lambda(b)b$。 

次に、のすべての約数$70!$は一意です:$$d=a\cdot b,$$そして貢献する$$\lambda(d)d = t_A t_B.$$固定の場合$a$、 有効$b$満足する$$\frac{L}{a}\le b\le \frac{H}{a}.$$もしすべてなら$b$-値はソートされており、間隔をバイナリ検索して、次のプレフィックスの合計を使用できます。$t_B$取得するため：$$\sum_{\frac{L}{a}\le b\le \frac{H}{a}} t_B$$で$O(\log N)$。 

したがって、全体の複雑さはおおよそ次のようになります。$$O(N\log N),$$それぞれの半分には約$1.88\times 10^6$状態 — 完全に実現可能です。 

## 2. Python の実装```python
from math import factorial
from bisect import bisect_left, bisect_right
from sympy import factorint

MOD = 1_000_000_007

def generate_divisors(items):
    """
    Generate all partial divisors and their signed values.

    Returns list of tuples:
        (d, lambda(d) * d)
    """
    arr = [(1, 1)]

    for p, a in items:
        powers = []

        value = 1
        sign = 1

        for _ in range(a + 1):
            powers.append((value, sign * value))
            value *= p
            sign *= -1

        new_arr = []

        for d, t in arr:
            for v, tv in powers:
                new_arr.append((d * v, t * tv))

        arr = new_arr

    return arr

def S(n, L, H):
    # Prime factorization of n!
    fac = factorint(factorial(n))
    items = list(fac.items())

    # Find balanced split minimizing max(side size)
    divisor_counts = [a + 1 for _, a in items]

    total_divisors = 1
    for c in divisor_counts:
        total_divisors *= c

    best_mask = None
    best_size = float("inf")

    m = len(items)

    for mask in range(1 << m):
        left_size = 1

        for i in range(m):
            if (mask >> i) & 1:
                left_size *= divisor_counts[i]

        right_size = total_divisors // left_size
        worst = max(left_size, right_size)

        if worst < best_size:
            best_size = worst
            best_mask = mask

    A = [items[i] for i in range(m)
         if (best_mask >> i) & 1]

    B = [items[i] for i in range(m)
         if not ((best_mask >> i) & 1)]

    # Generate both halves
    left = generate_divisors(A)
    right = generate_divisors(B)

    # Sort right side by divisor value
    right.sort(key=lambda x: x[0])

    right_divs = [d for d, _ in right]

    # Prefix sums of signed contributions
    prefix = [0]
    running = 0

    for _, t in right:
        running += t
        prefix.append(running)

    total = 0

    for a, ta in left:
        lo = (L + a - 1) // a
        hi = H // a

        i = bisect_left(right_divs, lo)
        j = bisect_right(right_divs, hi)

        total += ta * (prefix[j] - prefix[i])

    return total

# Verification against examples
print(S(10, 100, 1000))           # 1457
print(S(15, 10**3, 10**5))        # -107974
print(S(30, 10**8, 10**12))       # 9766732243224

# Final computation
ans = S(70, 10**20, 10**60)
print(ans % MOD)
```## 3. コードのチュートリアル

 -`factorint(factorial(n))`の素指数を計算します$n!$。 
-`generate_divisors()`すべての部分除数を再帰的に列挙し、格納します。$$(d,\lambda(d)d).$$- 素数を 2 つのバランスの取れたグループに分割し、各側が約$1.88$百万の州。 
- 右半分は除数のサイズでソートされます。 
- プレフィックス合計により、二分探索後の一定時間での間隔合計が可能になります。 
- 左の約数ごとに$a$、すべて互換性があることがわかります$b$満足のいく：$$L \le ab \le H.$$- すべての署名された貢献を合計します。

## 4. 最終確認

 すべての約数にわたる無制限の合計$70!$次のように乗算的に因数分解します。$$\sum_{d\mid 70!}\lambda(d)d = \prod_p (1-p+p^2-\cdots),$$大幅なキャンセルが予想されますので、 結果のモジュロ$10^9+7$剰余範囲の中央にあることは完全にもっともらしいです。
