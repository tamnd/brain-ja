[プロジェクト オイラー問題 675](https://projecteuler.net/problem=675)

 ## 解決策

 **答え:**`416146418`させて$$S(n)=\sum_{d\mid n}2^{\omega(d)}$$どこ$\omega(d)$は、次の異なる素約数の数です。$d$。 

必要です$$F(n)=\sum_{i=2}^n S(i!)$$のために$n=10^7$、モジュロ$$M=1\,000\,000\,087.$$---

 # ステップ 1 — 閉じた形式を導出する$S(n)$書く$$n=\prod_{p} p^{e_p}.$$すべての約数$d\mid n$形を持っています$$d=\prod_p p^{a_p}, \qquad 0\le a_p\le e_p.$$固定素数の場合$p$：

- もし$a_p=0$、何の貢献もしない$\omega(d)$、
- もし$a_p>0$、貢献します$1$。 

したがって、プライムからの貢献は$p$は：

-$1$重みで選ぶ$2^0=1$、
 -$e_p$重みのある選択$2^1=2$。 

したがって、ローカル要因は次のようになります。$$1+2e_p.$$したがって$$S(n)=\prod_p (2e_p+1).$$たとえば、次のようになります。$$6=2^1\cdot 3^1$$与える$$S(6)=(2\cdot1+1)(2\cdot1+1)=3\cdot3=9,$$これはステートメントと一致します。 

---

 # ステップ 2 — これを階乗に適用します

 しましょう$$i! = \prod_p p^{E_p(i)}.$$それから$$S(i!)=\prod_p (2E_p(i)+1).$$すでに知っていると仮定してください$S((i-1)!)$。 

乗算する場合$i$、$$i=\prod_p p^{c_p},$$関連する各素数の指数は次のように増加します。$c_p$:$$E_p \to E_p+c_p.$$したがって、係数は次から変化します$$2E_p+1$$に$$2(E_p+c_p)+1.$$したがって$$S(i!) = S((i-1)!) \prod_{p^ {c_p}\parallel i} \frac{2(E_p+c_p)+1}{2E_p+1}.$$これにより、基本的に増分更新が可能になります$O(\omega(i))$。 

---

 # ステップ 3 — 効率的な因数分解

 最大のすべての数値の最小素因数 (SPF) を前処理します。$10^7$直線ふるいを使用します。 

それから毎回$i$すぐに因数分解できる。 

また、次のことも維持します。 

-`exp[p] = E_p(i!)`- 現在の値$$cur = S(i!)$$モジュロ$M$。 

除算モジュロなので$M$モジュラー逆数を乗算することを意味します。すべての奇数の逆数を事前に計算します。$$(2k+1)^{-1}\pmod M.$$---

 # Pythonの実装```python
from array import array

MOD = 1_000_000_087
N = 10_000_000

# ------------------------------------------------------------
# Linear sieve for smallest prime factor
# ------------------------------------------------------------

spf = array('I', [0]) * (N + 1)
primes = []

for i in range(2, N + 1):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)

    for p in primes:
        v = p * i
        if v > N:
            break
        spf[v] = p
        if p == spf[i]:
            break

# ------------------------------------------------------------
# Precompute inverses of all odd numbers:
# inv[k] = inverse of (2k+1) modulo MOD
# ------------------------------------------------------------

inv = array('I', [0]) * (N + 1)

# inverse of 1
inv[0] = 1

for k in range(1, N + 1):
    a = 2 * k + 1
    inv[k] = MOD - (MOD // a) * inv[(MOD % a) // 2] % MOD

# ------------------------------------------------------------
# exp[p] = exponent of prime p in current factorial
# cur    = S(i!)
# ans    = running sum of S(i!)
# ------------------------------------------------------------

exp = array('I', [0]) * (N + 1)

cur = 1
ans = 0

for n in range(2, N + 1):

    x = n

    # factorize n using SPF
    while x > 1:

        p = spf[x]
        c = 0

        while x % p == 0:
            x //= p
            c += 1

        old_e = exp[p]
        new_e = old_e + c
        exp[p] = new_e

        # multiply by (2*new_e+1)/(2*old_e+1)
        cur = (
            cur
            * (2 * new_e + 1)
            % MOD
            * inv[old_e]
            % MOD
        )

    ans += cur
    ans %= MOD

print(ans)
```---

 # コードのチュートリアル

 ### 1. リニアシーブ```python
spf[i]
```～の最小素因数を格納します`i`。 

これにより、すべての数値を非常に迅速に因数分解することができます。 

---

 ### 2. 逆表

 次の形式の数値の逆モジュールが必要です。$$2e+1.$$再発$$a^{-1}\equiv -\left\lfloor \frac{M}{a}\right\rfloor (M\bmod a)^{-1} \pmod M$$線形時間で逆数を計算します。 

---

 ### 3. アップデート$S(i!)$素数とする$p$指数がありました$e$を乗算した後、$i$それはなる$e+c$。 

それから```python
cur *= (2*new_e+1) / (2*old_e+1)
```モジュロ$M$。 

したがって、素因数ごとに一定時間で更新します。

 # 最終確認

 アルゴリズムは基本的に線形時間で実行されます。 

- ふるい：$O(N)$、
 - 因数分解/更新: 約$O(N\log\log N)$。
