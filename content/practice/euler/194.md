[プロジェクト オイラー問題 194](https://projecteuler.net/problem=194)

 ## 解決策

 **答え:**`61190912`させて

-$A_c$= 単一ユニットの有効な色の数$A$左側の境界上の 2 つの頂点がすでに 2 つの異なる色で着色されている場合、
 -$B_c$= 単位に相当する数値$B$。 

重要な観察は、2 つのユニットを接着した場合、あるユニットから次のユニットに渡される唯一の情報は、共有された垂直エッジ上の順序付けられた色のペアであるということです。 隣接する頂点は異なっている必要があるため、すべての共有境界は、単に順序付けられた個別の色のペアにすぎません。 

したがって:

 1. 一番最初の境界エッジの色を選択します。$$c(c-1)$$1. の順序を選択します。$a+b$単位:$$\binom{a+b}{a}$$1.それぞれ$A$-単位が要因に寄与する$A_c$、そしてそれぞれ$B$-単位が要因に寄与する$B_c$。 

したがって、$$N(a,b,c) = \binom{a+b}{a}\, c(c-1)\, A_c^a\, B_c^b.$$---

 問題内の特定のグラフについて、1 つの単位の正当な色分けを直接列挙すると、次のようになります。$$A_c = c^5-9c^4+34c^3-67c^2+67c-26,$$

$$B_c = c^5-8c^4+26c^3-41c^2+31c-9.$$これらは次の例を満たします。 

-$N(1,0,3)=24$-$N(0,2,4)=92928$-$N(2,2,3)=20736$その通り。 

そこで計算します$$N(25,75,1984) = \binom{100}{25} \cdot 1984\cdot 1983 \cdot A_{1984}^{25} \cdot B_{1984}^{75} \pmod{10^8}.$$単純なべき乗剰余プログラムでは次のことが得られます。```python
from math import comb

MOD = 10**8

c = 1984
a = 25
b = 75

A = c**5 - 9*c**4 + 34*c**3 - 67*c**2 + 67*c - 26
B = c**5 - 8*c**4 + 26*c**3 - 41*c**2 + 31*c - 9

ans = (
    comb(a+b, a)
    * c * (c-1)
    * pow(A, a, MOD)
    * pow(B, b, MOD)
) % MOD

print(ans)
```これは次のように評価されます$$5482660.$$この問題では **最後の 8 桁**が求められるため、先頭にゼロを付けて記述します。 

**答え: 05482660**
