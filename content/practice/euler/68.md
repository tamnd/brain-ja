[プロジェクト オイラー問題 68](https://projecteuler.net/problem=68)

 ## 解決策

 **答え:**`6531031914842725`## 1. 数学的分析

 **魔法の 5 ゴン リング** を数値を使用して説明する **最大 16 桁の文字列**が必要です$1$を通して$10$。 

5 角リングには次のような特徴があります。 

- **5 つの外部ノード**
 - **5 つの内部ノード**

 各行には次の内容が含まれます。$$(\text{external}, \text{internal}_i, \text{internal}_{i+1})$$そして 5 行すべての合計が同じになる必要があります。 

しましょう:

 - 外部ノード:$e_1,\dots,e_5$- 内部ノード:$i_1,\dots,i_5$この場合、すべての行は次の条件を満たします。$$e_k + i_k + i_{k+1} = S$$(5 を法とするインデックス)。 

---

 ### 重要な観察 1: なぜ 16 桁だけなのでしょうか?

 各数値は 1 回表示されますが、内部ノードは連結内で **2 回**表示されます (それぞれが 2 つの行に属しているため)。 

番号$10$**2 桁** を提供します。 

もし$10$**内部ノード**であるため、2 回出現します。 → 文字列の合計長は **17 桁**になります。 

**16 桁** の文字列が必要なので、次のようになります。$$10 \text{ must be external.}$$---

 ### 重要な観察 2: 正規表現

 この問題は回転対称性を取り除きます。 

- **外部ノードが最小**のグループから開始
 - **時計回り**で読んでください

 したがって、すべての有効な配置には一意のエンコーディングがあります。 

---

 ### 重要な観察 3: 数値を最大化する

 文字列は順番に連結されるため、**可能な限り最大の先頭桁**が必要です。 

ただし、最初のグループは **最小の外部ノード** から開始する必要があります。 

したがって、文字列の合計を最大化するには、次のようにします。 

- 最小の外部ノードはできるだけ大きくする必要があります。 
- 外装の中で最小限でありながら。 

以来$10$外部に配置する必要がある場合、**最大の数値を外部に配置する**ことが最善の戦略です。 

自然な候補は次のとおりです。$$\{6,7,8,9,10\}$$外部ノードとして、残す$$\{1,2,3,4,5\}$$内部。 

次に、すべての有効なマジック リングを検索し、最大有効な 16 桁の文字列を取得します。

 ## 2. Python の実装```python
from itertools import permutations

def solve():
    nums = set(range(1, 11))
    best = 0

    # Choose the 5 internal nodes and arrange them cyclically
    for inner in permutations(range(1, 11), 5):
        inner_set = set(inner)
        outer_nums = nums - inner_set

        # Try all permutations of outer nodes
        for outer in permutations(outer_nums):
            # Enforce canonical form:
            # first outer node must be the smallest
            if outer[0] != min(outer):
                continue

            # Compute target sum using first line
            target = outer[0] + inner[0] + inner[1]

            valid = True
            groups = []

            for i in range(5):
                a = outer[i]
                b = inner[i]
                c = inner[(i + 1) % 5]

                if a + b + c != target:
                    valid = False
                    break

                groups.append(f"{a}{b}{c}")

            if not valid:
                continue

            candidate = int("".join(groups))

            # Only keep 16-digit strings
            if len(str(candidate)) == 16:
                best = max(best, candidate)

    return best

print(solve())
```---
