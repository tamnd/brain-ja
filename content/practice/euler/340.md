[プロジェクト オイラー問題 340](https://projecteuler.net/problem=340)

 ## 解決策

 **答え:**`291504964`させて$$F(n)= \begin{cases} n-c & n>b\\[4pt] F(a+F(a+F(a+F(a+n)))) & n\le b \end{cases}$$そして$$S(a,b,c)=\sum_{n=0}^{b}F(n).$$必要なものは次のとおりです。$$S(21^7,7^{21},12^7)$$モジュロ$10^9$。 

## 1. 数学的分析

 定義する$$d=a-c.$$以来$a>c$、 我々は持っています$d>0$。 

のために$n>b$、$$F(n)=n-c=n-d-a+a.$$重要なのは、何が起こるかを理解することです$n\le b$。 

### ステップ 1: パーティション$n$ブロックに分割

 しましょう$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$これはつまり$n$にあります$k$上から - 番目のブロック:$$b-(k+1)a < n \le b-ka.$$私たちは次のように主張します:$$F(n)=n+D_k$$ブロック依存の定数の場合$D_k$。 

---

 ### ステップ 2: 基本ケース ($k=0$）

もし$b-a<n\le b$、 それから$a+n>b$、 それで：$$F(a+n)=a+n-c=n+d.$$その後、残りのネストされた引数はすべてすでに$>b$したがって、外側のアプリケーションごとに別のアプリケーションが減算されます。$c$:$$F(n) = n+d+d+d+d = n+4(a-c).$$したがって$$D_0=4a-4c.$$---

 ### ステップ 3: 再発$D_k$仮定する$n$ブロック内にあります$k\ge1$。 それから$a+n$ブロックの中にあります$k-1$したがって、帰納法により、次のようになります。$$F(a+n) = (a+n)+D_{k-1}.$$その後、残りの 3 つの外側のアプリケーションはすべて$>b$それぞれの政権が貢献している$+d$。 したがって、次のようになります。$$D_k = a+D_{k-1}+3d.$$以来$d=a-c$、$$D_k = D_{k-1}+4a-3c.$$と$$D_0=4a-4c,$$これは次のように解決されます。$$D_k = (k+1)(4a-3c)-c.$$したがって：$$\boxed{ F(n) = n+(k+1)(4a-3c)-c }$$どこ$$k=\left\lfloor \frac{b-n}{a}\right\rfloor.$$---

 ### ステップ 4: 合計する

 しましょう$$b=qa+r, \qquad 0\le r<a.$$次に:

 - ブロック$k=0,\dots,q-1$それぞれに正確に含まれています$a$価値観、
 - ブロック$k=q$含まれています$r+1$価値観。 

また、$$\sum_{n=0}^{b} n = \frac{b(b+1)}{2}.$$させて$$T=4a-3c.$$以来$$D_k=(k+1)T-c,$$合計オフセットは$$a\sum_{k=0}^{q-1}\big((k+1)T-c\big) + (r+1)\big((q+1)T-c\big).$$使用する$$\sum_{j=1}^{q}j=\frac{q(q+1)}{2},$$私たちは得ます$$S(a,b,c) = \frac{b(b+1)}{2} + a\left( T\frac{q(q+1)}{2} -cq \right) + (r+1)\big((q+1)T-c\big).$$---

 ## 2. Python の実装```python
def crazy_sum(a, b, c):
    # Divide b into full blocks of size a
    q, r = divmod(b, a)

    # Constant increment per block
    T = 4 * a - 3 * c

    # Sum of n from 0 to b
    total = b * (b + 1) // 2

    # Contribution from full blocks
    full_blocks = a * (
        T * q * (q + 1) // 2 - c * q
    )

    # Contribution from the final partial block
    final_block = (r + 1) * (
        (q + 1) * T - c
    )

    return total + full_blocks + final_block

# Example check
print(crazy_sum(50, 2000, 40))
# 5204240

# Required problem
a = 21 ** 7
b = 7 ** 21
c = 12 ** 7

answer = crazy_sum(a, b, c) % (10 ** 9)
print(answer)
```---

 ## 3. コードのチュートリアル

 ###`divmod(b, a)`スプリット$b$の中へ：$$b=qa+r$$したがって、幅の完全なブロックの数がわかります$a$存在する。 

###`T = 4*a - 3*c`これは、ブロック オフセットの等差数列におけるステップ サイズです。$$D_k=(k+1)T-c.$$###`total`基本寄与を追加します$$\sum n=\frac{b(b+1)}{2}.$$###`full_blocks`すべての完全なブロックのオフセットを合計します。$$a\sum_{k=0}^{q-1}D_k.$$###`final_block`サイズの残りの部分ブロックを追加します$r+1$。 

---

 ### サンプルでの検証

 のために$$(a,b,c)=(50,2000,40)$$コードは以下を返します:$$5204240$$これは問題のステートメントと正確に一致します。
