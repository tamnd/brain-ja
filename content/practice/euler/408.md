[プロジェクト オイラー問題 408](https://projecteuler.net/problem=408)

 ## 解決策

 **答え:**`299742733`させて$$T(n)=\binom{2n}{n}$$からの単調格子パスの総数になります。$(0,0)$に$(n,n)$。 

**許容できない**点を通過するパスを除外する必要があります。 

---

 #1. 数学的分析

 A lattice point$(x,y)$以下の場合は認められません

 -$x$は正の平方であり、
 -$y$は正の平方であり、
 -$x+y$も正の正方形です。 

したがって、整数が存在します$a,b,c>0$そのような$$x=a^2,\qquad y=b^2,\qquad a^2+b^2=c^2.$$したがって、許容できない点はピタゴラスの 3 倍に正確に対応します。 

のために$n=10^7$、$$a,b \le \sqrt{10^7}=3162.$$したがって、許容されないポイントの数は非常に少ないです (わずか 7,850 ポイント)。 

---

 ## 格子点を通るパスを数える

 からの単調な北/東パスの数$(x_1,y_1)$に$(x_2,y_2)$は$$\binom{(x_2-x_1)+(y_2-y_1)}{x_2-x_1}.$$すべての許容されないポイントを次のように並べ替えると、$(x+y,x)$の場合、点の許容されるすべての先行部分が以前に表示されます。 

定義する：$$F(P)=\text{number of admissible paths from }(0,0)\text{ to }P.$$ポイントとしては$P=(x,y)$、$$F(P) = \binom{x+y}{x} - \sum_{Q\le P} F(Q)\binom{(x-x_Q)+(y-y_Q)}{x-x_Q},$$合計が以前の許容できないポイントを超える場合$Q=(x_Q,y_Q)$満足のいく$$x_Q\le x,\qquad y_Q\le y.$$これは、DAG の標準の包含-除外 / DP です。 

ついに、$$P(n) = \binom{2n}{n} - \sum_Q F(Q) \binom{(n-x_Q)+(n-y_Q)}{n-x_Q}.$$すべての計算はモジュロです$$M=1\,000\,000\,007.$$以来$M$プライムであり、$2n< M$、通常の階乗/二項算術剰余$M$直接的に働きます。 

---

 #2. Pythonの実装```python
from math import isqrt
from array import array

MOD = 1_000_000_007
N = 10_000_000

# ------------------------------------------------------------
# Precompute factorials and inverse factorials modulo MOD
# ------------------------------------------------------------

MAXF = 2 * N

fact = array('I', [0]) * (MAXF + 1)
invfact = array('I', [0]) * (MAXF + 1)

fact[0] = 1
for i in range(1, MAXF + 1):
    fact[i] = (fact[i - 1] * i) % MOD

invfact[MAXF] = pow(fact[MAXF], MOD - 2, MOD)

for i in range(MAXF, 0, -1):
    invfact[i - 1] = (invfact[i] * i) % MOD

def C(n, r):
    """Binomial coefficient modulo MOD."""
    if r < 0 or r > n:
        return 0
    return (fact[n] * invfact[r] * invfact[n - r]) % MOD

# ------------------------------------------------------------
# Generate inadmissible points
# ------------------------------------------------------------

limit = isqrt(N)

points = set()

for a in range(1, limit + 1):
    aa = a * a

    for b in range(a + 1, limit + 1):
        bb = b * b

        c2 = aa + bb
        c = isqrt(c2)

        if c * c == c2:
            points.add((aa, bb))
            points.add((bb, aa))

points = sorted(points, key=lambda p: (p[0] + p[1], p[0]))

# ------------------------------------------------------------
# DP over inadmissible points
# ------------------------------------------------------------

k = len(points)

xs = [p[0] for p in points]
ys = [p[1] for p in points]

F = [0] * k

for i in range(k):

    x, y = xs[i], ys[i]

    # Total paths to (x,y)
    val = C(x + y, x)

    # Remove paths already passing through earlier inadmissible points
    for j in range(i):

        xj, yj = xs[j], ys[j]

        if xj <= x and yj <= y:

            ways = C((x - xj) + (y - yj), x - xj)

            val -= F[j] * ways

    F[i] = val % MOD

# ------------------------------------------------------------
# Count admissible paths to (N,N)
# ------------------------------------------------------------

answer = C(2 * N, N)

for j in range(k):

    xj, yj = xs[j], ys[j]

    ways = C((N - xj) + (N - yj), N - xj)

    answer -= F[j] * ways

answer %= MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## 階乗

 事前計算します$$n! \pmod M$$フェルマーを使用した逆階乗：$$a^{-1}\equiv a^{M-2}\pmod M.$$それから$$\binom{n}{r} = \frac{n!}{r!(n-r)!} \pmod M.$$---

 ## 許容できないポイントの生成

 全部列挙します$$a,b\le \sqrt{N}$$かどうかをテストします$$a^2+b^2$$は正方形です。 

そのたびに挿入します$$(a^2,b^2)$$そして対称点。 

のために$N=10^7$、そのようなポイントは 7850 個しかありません。 

---

 ## DP

 認められないポイントごとに$P$:

 1. すべてのパスから開始します。$P$、
 2. 以前に許容されないポイントをすでに通過させられたものを差し引きます。 

したがって$F(P)$**最初の許容できないポイント**が正確に一致するパスをカウントします$P$。 

最後に、からすべてのパスを減算します。$(0,0)$に$(N,N)$許容できない点を通過するもの。
