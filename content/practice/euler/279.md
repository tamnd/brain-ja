[プロジェクト オイラー問題 279](https://projecteuler.net/problem=279)

 ## 解決策

 **答え:**`416577688`三角形の辺が整数になるようにします$a,b,c$、1 つの角度が整数の度であると仮定します。 

余弦の法則により、$$\cos \theta = \frac{a^2+b^2-c^2}{2ab},$$それで$\cos\theta$合理的です。 

ニーブンの古典的な定理は次のように述べています。 

> もし$\theta/\pi$合理的であり、$\cos\theta$それは合理的です、それでは
 >
 >
 >
 >
 >$$\cos\theta \in \left\{0,\pm \frac12,\pm1\right\}.$$非縮退三角形の場合、これにより次だけが残ります。 

-$60^\circ$、
 -$90^\circ$、
 -$120^\circ$。 

したがって、問題は、これら 3 つのタイプのすべての整数三角形を周囲長で数えることに帰着します。$\le 10^8$。 

---

 #1. 直角三角形 ($90^\circ$）

 原始ピタゴラス トリプルは次のようにパラメータ化されます。$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2,$$と$$m>n,\quad \gcd(m,n)=1,\quad m-n\text{ odd}.$$彼らの周囲は$$p=2m(m+n).$$すべての非プリミティブ トリプルはプリミティブ トリプルの倍数であるため、提供される数は次のようになります。$$\sum \left\lfloor \frac{N}{2m(m+n)} \right\rfloor .$$---

 ＃2。$120^\circ$三角形

 仮に、$120^\circ$角度は反対側です$c$。 それから$$c^2=a^2+b^2+ab.$$原始解は次のようにパラメータ化されます。$$a=m^2-n^2,$$

$$b=2mn+n^2,$$

$$c=m^2+mn+n^2,$$と$$m>n,\qquad \gcd(m,n)=1,\qquad m\not\equiv n\pmod 3.$$外周は$$p=2m^2+3mn+n^2.$$したがって、貢献度は$$\sum \left\lfloor \frac{N}{2m^2+3mn+n^2} \right\rfloor .$$---

 ＃3。$60^\circ$三角形

 正三角形以外にも、あらゆるプリミティブ$60^\circ$三角形はプリミティブから生じます$120^\circ$三角形。 

プリミティブから始める$120^\circ$三角形$(a,b,c)$、$$(a,c,a+b) \quad\text{and}\quad (b,c,a+b)$$原始的です$60^\circ$三角形。 

それらの原始的な境界線は次のようになります。$$p_1 = 3m(m+n),$$

$$p_2 = (2m+n)(m+2n).$$さらに、正三角形も貢献します$$\left\lfloor \frac{N}{3}\right\rfloor .$$したがって、合計数は、$60^\circ$三角形は$$\left\lfloor \frac{N}{3}\right\rfloor + \sum \left\lfloor \frac{N}{3m(m+n)} \right\rfloor + \sum \left\lfloor \frac{N}{(2m+n)(m+2n)} \right\rfloor .$$---

 # Pythonの実装```python
from math import gcd, isqrt

N = 10**8

# ------------------------------------------------------------
# Count 90-degree triangles
# ------------------------------------------------------------
def count_90(limit):
    total = 0

    for m in range(2, isqrt(limit // 2) + 2):
        for n in range(1, m):

            # Primitive Pythagorean conditions
            if gcd(m, n) != 1:
                continue

            if (m - n) % 2 == 0:
                continue

            perimeter = 2 * m * (m + n)

            if perimeter > limit:
                break

            total += limit // perimeter

    return total

# ------------------------------------------------------------
# Count 120-degree triangles
# ------------------------------------------------------------
def count_120(limit):
    total = 0

    for m in range(2, isqrt(limit) + 2):
        for n in range(1, m):

            # Primitive conditions
            if gcd(m, n) != 1:
                continue

            if (m - n) % 3 == 0:
                continue

            perimeter = 2 * m * m + 3 * m * n + n * n

            if perimeter > limit:
                break

            total += limit // perimeter

    return total

# ------------------------------------------------------------
# Count 60-degree triangles
# ------------------------------------------------------------
def count_60(limit):

    # Equilateral triangles
    total = limit // 3

    for m in range(2, isqrt(limit) + 2):
        for n in range(1, m):

            if gcd(m, n) != 1:
                continue

            if (m - n) % 3 == 0:
                continue

            p1 = 3 * m * (m + n)
            p2 = (2 * m + n) * (m + 2 * n)

            if p1 <= limit:
                total += limit // p1

            if p2 <= limit:
                total += limit // p2

    return total

c90 = count_90(N)
c120 = count_120(N)
c60 = count_60(N)

answer = c90 + c120 + c60

print(answer)
```---

 # コードのチュートリアル

 ###`count_90`原始ピタゴラス トリプルに対するユークリッドの公式を実装します。 

-`gcd(m,n)==1`原始性を保証します。 
-`(m-n)%2==1`逆パリティを保証します。 
- すべての倍数は以下を使用してカウントされます。$$\left\lfloor \frac{N}{p} \right\rfloor .$$---

 ###`count_120`プリミティブパラメータ化を使用します。$120^\circ$三角形。 

条件$$m\not\equiv n \pmod 3$$非プリミティブの重複を削除します。 
---
 ###`count_60`カウント:

 1.正三角形、
 2. 二人$60^\circ$各プリミティブから生成されたファミリー$120^\circ$三角形。

 # ちょっとした検証

 のために$N=100$、プログラムは次のようになります:

 -$17$直角三角形、
 -$14$ $120^\circ$三角形、
 -$53$ $60^\circ$三角形、

 合計で$$17+14+53=84.$$直接的なブルートフォースによってこれが正確に確認されます。

 # 最終確認

 最終的な数は数億のオーダーですが、これは次の理由から妥当です。 

- プリミティブ ファミリは 2 パラメータの格子です。 
- 各原始三角形は多くの倍数に寄与します。 
- 境界境界が非常に大きい ($10^8$）。 

計算は高速であり、$O(\sqrt N)$-スケールループ。
