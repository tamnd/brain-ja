[プロジェクト オイラー問題 66](https://projecteuler.net/problem=66)

 ## 解決策

 **答え:**`661`ペル方程式の場合$$x^2 - Dy^2 = 1,$$と$D$正の非平方整数の場合、次の値を求めます。$D \le 1000$誰の_minimal_ソリューション$x$できるだけ大きいです。 

重要な事実は、ペル方程式の最小解は、次の連分数展開から生成されるということです。$\sqrt D$。 

---

 # 数学的分析

 整数解が必要です$$x^2 - Dy^2 = 1.$$これがペルの方程式です。 

正方形用$D$、自明でない整数解はありません。$$x^2 - Dy^2=(x-\sqrt D\,y)(x+\sqrt D\,y),$$そして$\sqrt D$合理的です。 したがって、非正方形のみを考慮します。 

---

 ## 連分数とペル方程式

 古典的な定理は次のように述べています。 

> 最小限の解決策$(x,y)$の
 >
 >
 >
 >
 >$$x^2-Dy^2=1$$>
 >
 >
 >
 > の周期連分数展開の収束から得られます。$\sqrt D$。 

の連分数$\sqrt D$形を持っています$$\sqrt D = [a_0;\overline{a_1,a_2,\dots,a_k}],$$ここでブロックは定期的に繰り返されます。 

収束は分数です$$\frac{p_n}{q_n},$$によって再帰的に生成される$$p_n = a_n p_{n-1} + p_{n-2},$$

$$q_n = a_n q_{n-1} + q_{n-2}.$$収束物がペルの方程式を正確に満たすのは、次の場合です。$$p_n^2 - D q_n^2 = 1.$$最初のこのような収束は最小の解を与えます。 

---

 ## の連分数を計算する$\sqrt D$非正方形の場合$D$、 定義する$$a_0 = \lfloor \sqrt D \rfloor.$$それから反復します$$m_{n+1} = d_n a_n - m_n,$$

$$d_{n+1} = \frac{D - m_{n+1}^2}{d_n},$$

$$a_{n+1} = \left\lfloor \frac{a_0 + m_{n+1}}{d_{n+1}} \right\rfloor.$$から始まる$$m_0=0,\quad d_0=1,\quad a_0=\lfloor\sqrt D\rfloor.$$各ステップで、ペルの方程式が満たされるまで収束を構築します。 

---

 # Pythonの実装```python
import math

def minimal_pell_solution_x(D):
    """
    Return the minimal x satisfying:
        x^2 - D*y^2 = 1
    for a non-square D.
    """

    a0 = int(math.isqrt(D))

    # Ignore perfect squares
    if a0 * a0 == D:
        return None

    # Continued fraction variables
    m = 0
    d = 1
    a = a0

    # Convergent recurrence:
    # p/q are convergents
    p_minus2, p_minus1 = 0, 1
    q_minus2, q_minus1 = 1, 0

    while True:
        # Current convergent
        p = a * p_minus1 + p_minus2
        q = a * q_minus1 + q_minus2

        # Check Pell equation
        if p * p - D * q * q == 1:
            return p

        # Advance continued fraction
        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        # Shift recurrence variables
        p_minus2, p_minus1 = p_minus1, p
        q_minus2, q_minus1 = q_minus1, q

max_x = 0
answer_D = 0

for D in range(2, 1001):
    x = minimal_pell_solution_x(D)

    if x is not None and x > max_x:
        max_x = x
        answer_D = D

print(answer_D)
```---

 # 小さな例の検証

 のために$D=13$、コードは次を見つけます:$$649^2 - 13 \cdot 180^2 = 1.$$確かに、$$649^2 = 421201,$$

$$13 \cdot 180^2 = 13 \cdot 32400 = 421200,$$違い$=1$。 

これは問題文と一致します。 

のために$D \le 7$、最小限の$x$-値は次のとおりです。 

|$D$| 最小限の$x$|
 | --- | --- |
 | 2 | 3 |
 | 3 | 2 |
 | 5 | 9 |
 | 6 | 5 |
 | 7 | 8 |

 最大のものは$9$で$D=5$、再びプロンプトと一致します。
