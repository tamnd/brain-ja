[プロジェクト オイラー問題 96](https://projecteuler.net/problem=96)

 ## 解決策

 **答え:**`24702`この問題の鍵は、深い整数理論ではなく、数独パズルを解くための信頼性が高く効率的な完全一致検索アルゴリズムを設計することです。 

Sudoku グリッドは **制約満足問題** です。 

- 各行には数字が含まれている必要があります$1$–$9$まさに一度。 
- 各列には数字が含まれている必要があります$1$–$9$まさに一度。 
- それぞれ$3\times3$ボックスには数字が含まれている必要があります$1$–$9$まさに一度。 

Project Euler タスクには 50 個のパズルがあり、それぞれに固有の解決策があります。 解けたパズルごとに、上の行の最初の 3 桁で構成される 3 桁の数字を抽出し、それらを合計します。 

---

 # 数学的分析

 セルが空であると仮定します。 

させて：

-$R$= その行ですでに使用されている数字、
 -$C$= その列ですでに使用されている数字、
 -$B$= すでにその中で使用されている数字$3\times3$箱。 

次に、許可される候補は次のとおりです。$$\{1,\dots,9\}\setminus (R\cup C\cup B).$$すべてのセルに値が 1 つだけあれば、パズルは解けます。 

---

 ## バックトラッキング検索

 一般に、純粋な論理的演繹だけでは十分ではないため、再帰的検索を使用します。 

### 戦略

 1. **候補数が最も少ない**空のセルを見つけます。 
2. 各候補を試してください。 
3. 再発する。 
4. 矛盾が生じた場合は、後戻りします。 

この「残りの最小値」ヒューリスティックは、検索ツリーを大幅に枝刈りするため、非常に重要です。 

---

 # 効率的な表現

 セットを使用して制約を表すことができます。 

各行、列、およびボックスについて、すでに使用されている数字を維持します。 

細胞の場合$(r,c)$:$$\text{box}(r,c)=3\left\lfloor \frac r3 \right\rfloor+\left\lfloor \frac c3 \right\rfloor.$$候補桁は集合の差から迅速に計算されます。

 # Pythonの実装```python
from urllib.request import urlopen

# Download the Sudoku file
url = "https://projecteuler.net/project/resources/p096_sudoku.txt"
data = urlopen(url).read().decode().strip().splitlines()

# Parse puzzles
puzzles = []
for i in range(0, len(data), 10):
    grid = [list(map(int, data[i + j + 1])) for j in range(9)]
    puzzles.append(grid)

DIGITS = set(range(1, 10))

def solve(grid):
    """
    Solve a Sudoku puzzle using recursive backtracking
    with minimum-candidate heuristic.
    """

    # Track used digits
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]

    # Initialize constraint sets
    for r in range(9):
        for c in range(9):
            v = grid[r][c]
            if v:
                rows[r].add(v)
                cols[c].add(v)
                boxes[(r // 3) * 3 + (c // 3)].add(v)

    def backtrack():
        best = None
        best_candidates = None

        # Find empty cell with fewest candidates
        for r in range(9):
            for c in range(9):
                if grid[r][c] == 0:
                    b = (r // 3) * 3 + (c // 3)

                    candidates = (
                        DIGITS
                        - rows[r]
                        - cols[c]
                        - boxes[b]
                    )

                    if len(candidates) == 0:
                        return False

                    if best is None or len(candidates) < len(best_candidates):
                        best = (r, c, b)
                        best_candidates = candidates

        # No empty cells => solved
        if best is None:
            return True

        r, c, b = best

        # Try each candidate
        for v in best_candidates:
            grid[r][c] = v
            rows[r].add(v)
            cols[c].add(v)
            boxes[b].add(v)

            if backtrack():
                return True

            # Undo move
            grid[r][c] = 0
            rows[r].remove(v)
            cols[c].remove(v)
            boxes[b].remove(v)

        return False

    backtrack()
    return grid

total = 0

for puzzle in puzzles:
    solved = solve(puzzle)

    # Extract top-left 3-digit number
    value = (
        solved[0][0] * 100
        + solved[0][1] * 10
        + solved[0][2]
    )

    total += value

print(total)
```---

一度に 10 行のブロックを処理します。```python
for i in range(0, len(data), 10):
```そして行を整数リストに変換します。

 ## 制約の追跡

 私たちは以下を維持します:```python
rows = [set() for _ in range(9)]
cols = [set() for _ in range(9)]
boxes = [set() for _ in range(9)]
```これらは、どの数字がすでに使用されているかを保存します。 

ボックスのインデックスは次のとおりです。```python
(r // 3) * 3 + (c // 3)
```価値を与える$0$を通して$8$。 

---

 ## 候補の計算

 空のセルの場合:```python
candidates = DIGITS - rows[r] - cols[c] - boxes[b]
```これは、Sudoku の合法性の制約を直接実装します。 

---

 ## 最小候補ヒューリスティック

 最初に最も硬いセルを検索します。```python
if best is None or len(candidates) < len(best_candidates):
```これにより、分岐が大幅に減少します。 

---

 ## 再帰的バックトラッキング

 各候補者について:```python
grid[r][c] = v
```制約を更新し、再帰し、必要に応じて元に戻します。 

あらゆる法的可能性が体系的に検討されるため、これにより正確な解決策が保証されます。
