[プロジェクト オイラー問題 301](https://projecteuler.net/problem=301)

 ## 解決策

 **答え:**`2178309`通常プレイの Nim の場合、勝敗条件は **nim-sum** (ヒープ サイズのビットごとの XOR) によって完全に特徴付けられます。 

ポジション$(n_1,n_2,n_3)$負けてるなら$$n_1 \oplus n_2 \oplus n_3 = 0.$$したがって、正の整数の数が必要です$n \le 2^{30}$そのような$$n \oplus 2n \oplus 3n = 0.$$重要なのは、このビットごとの条件を単純化することです。 

---

 ## 1. 数学的分析

 Nim の損失条件は次のようになります。$$X(n,2n,3n)=0 \iff n\oplus 2n\oplus 3n = 0.$$ここで次のことを観察してください。$$3n = n + 2n.$$有用なビットごとの ID は次のとおりです。$$a+b = (a\oplus b) + 2(a\&b).$$したがって：$$a\oplus b = a+b \quad\Longleftrightarrow\quad a\&b = 0.$$これを適用すると、$a=n$、$b=2n$。 

もし$$n\oplus 2n = 3n,$$それから$$n\oplus 2n\oplus 3n = 0.$$以来$3n=n+2n$、これは、バイナリ加算に**桁上げがない**場合に正確に発生します。$n+2n$、つまり$$n\&2n = 0.$$ただし、2 を掛けることは単なる左シフトです。$$2n = n \ll 1.$$したがって：$$n \& (n\ll1)=0.$$これは次のことを意味します。 

> **隣接する 2 ビットはありません$n$両方とも 1.** になる可能性があります

 したがって、問題は次のようになります。 

> 整数を数える$1\le n\le 2^{30}$そのバイナリ表現には連続する 1 が含まれません。 

---

 ### フィボナッチ構造

 しましょう$f(k)$長さのバイナリ文字列の数になります$k$隣接する 1 はありません。 

最初のビットで分割します。 

- 0 から始まります:$f(k-1)$- 10 から始まります:$f(k-2)$したがって、次のようになります。$$f(k)=f(k-1)+f(k-2),$$フィボナッチ回帰。 

と：$$f(0)=1,\qquad f(1)=2$$得られるもの:$$f(k)=F_{k+2},$$どこ$F_1=1,F_2=1$。 

次に数字を考えてみましょう$0\le n<2^{30}$。 これらは長さが最大 ​​30 のバイナリ文字列に正確に対応するため、カウントは次のようになります。$$F_{32}.$$しかし、私たちの範囲は$$1\le n\le 2^{30}.$$知らせ：

-$n=0$に含まれています$F_{32}$カウントされますが、除外する必要があります。 
-$n=2^{30}$（バイナリ$1000\ldots0$) は有効であり、含める必要があります。 

これらは正確にキャンセルされます。 

したがって、最終的なカウントは残ります。$$F_{32}.$$計算:$$F_{32}=2178309.$$---

 ## 2. Python の実装```python
def solve(limit_power=30):
    # We need F_(limit_power + 2)
    # Fibonacci with F1 = 1, F2 = 1

    a, b = 1, 1  # F1, F2

    # Compute F32 for limit_power = 30
    target = limit_power + 2

    for _ in range(3, target + 1):
        a, b = b, a + b

    return b

print(solve())
```---

### 小規模な健全性チェック

 ステートメントの例:$$(1,2,3)$$Binary:

 -$1=001$-$2=010$-$3=011$XOR:$$1\oplus2\oplus3=0$$それで$X(1,2,3)=0$、問題文と一致します。 

いくつか確認してください$n$:

 -$n=1$: バイナリ`1`→有効
 -$n=2$: バイナリ`10`→有効
 -$n=3$: バイナリ`11`→無効（隣接するもの）
 -$n=5$: バイナリ`101`→有効
 -$n=6$: バイナリ`110`→無効

 まさに「1が連続しない」ルールです。

 ## 4. 最終確認

 答えはフィボナッチの成長にあるはずです。$$F_{32}\approx 2.1\times10^6,$$があることを考えると、それはもっともらしいです$2^{30}\approx10^9$連続する 1 のない候補と有効なビット文字列は指数関数的に疎になります。 

除外の解除$0$そしてそれを含めて$2^{30}$これは重要なエッジケースであり、カウントが正確に残っていることを確認します$F_{32}$。
