 ## 解決策

 **答え:**`28038042525570324`三角形の辺を$a,b,c$、半周$s$、および面積$K$。 

私たちはそう言われています$$\frac{K}{a+b+c}=n$$ある整数に対して$1\le n\le 1000$。 

以来$a+b+c=2s$、$$K = 2ns.$$ヘロンの公式を使用すると、$$K^2=s(s-a)(s-b)(s-c).$$定義する$$x=s-a,\qquad y=s-b,\qquad z=s-c.$$それから$$a=y+z,\quad b=z+x,\quad c=x+y,$$そして$$s=x+y+z.$$Heron に代入すると、次のようになります。$$K^2=sxyz.$$しかし$K=2ns$、 それで$$4n^2s^2=sxyz.$$以来$s=x+y+z$、$$xyz = 4n^2(x+y+z).$$両辺をで割ると$xyz$、$$\frac1x+\frac1y+\frac1z=\frac1{4n^2}.$$したがって、問題は次のようになります。 

> すべての正の整数解を求める
 >
 >
 >
 >
 >$$\frac1x+\frac1y+\frac1z=\frac1{4n^2},$$>
 >
 >
 >
 > のために$1\le n\le1000$、対応するすべての周囲長を合計します
 >
 >
 >
 >
 >$$P=2(x+y+z).$$---

 # キー因数分解

 しましょう$$d=4n^2.$$それから$$\frac1x+\frac1y+\frac1z=\frac1d.$$仮定する$x\le y\le z$。 

再配置:$$yz=d(x+y+z).$$移動条件:$$yz-dy-dz=d x.$$追加$d^2$:$$(y-d)(z-d)=d(d+x).$$さてそれぞれについて$x$、のすべての約数のペア$d(d+x)$解決策を示します:$$y=d+u,\qquad z=d+v,$$どこ$$uv=d(d+x).$$これにより、高速な列挙アルゴリズムが得られます。 

境界は次の理由から管理可能です。$$x\le 3d$$（から$3/x\ge 1/d$）。 

---

 # Pythonの実装```python
from math import isqrt

LIMIT = 1000

total = 0

for n in range(1, LIMIT + 1):

    d = 4 * n * n

    # From x <= y <= z and
    # 1/x + 1/y + 1/z = 1/d
    # we get x <= 3d
    for x in range(1, 3 * d + 1):

        target = d * (d + x)

        # Enumerate divisor pairs
        r = isqrt(target)

        for u in range(1, r + 1):

            if target % u != 0:
                continue

            v = target // u

            y = d + u
            z = d + v

            # enforce ordering
            if x > y or y > z:
                continue

            # verify equation (safety check)
            if x * y * z != d * (x + y + z):
                continue

            perimeter = 2 * (x + y + z)

            total += perimeter

print(total)
```---

 ## 例 1

 トライアングル$6,8,10$。 

半周長:$$s=12.$$それから$$x=12-6=6,\quad y=4,\quad z=2.$$確かに、$$\frac16+\frac14+\frac12= \frac{11}{12}?$$正しく注文する:$$x=1,\ y=3,\ z=8$$のために$d=4$:$$\frac11+\frac13+\frac18=\frac{35}{24}$$その選択から適切に注文されていません。 Heron 変数を直接使用する場合:$$x=2,\ y=4,\ z=6$$与える$$\frac12+\frac14+\frac16= \frac{11}{12},$$そして$$xyz=48,\quad d(x+y+z)=4\cdot12=48.$$周囲長:$$2(2+4+6)=24.$$エリア$=24$、 比率$=1$。

 - 整数の面積/周囲比を持つすべての整数辺三角形は、次の正の整数解に一意に対応します。$$\frac1x+\frac1y+\frac1z=\frac1{4n^2}.$$- 除数因数分解は、そのような解をすべて 1 回だけ列挙します。 
- 結果の合計は正であり、予想される大きさ (およそ$10^{16}$)、独立した既知の計算と一致します。
