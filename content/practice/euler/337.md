[プロジェクト オイラー問題 337](https://projecteuler.net/problem=337)

 ## 解決策

 **答え:**`85068035`有向遷移を定義しましょう$a_i \to a_{i+1}$いつでも$$\phi(a_i) < \phi(a_{i+1}) < a_i < a_{i+1}.$$この場合、有効なシーケンスはすべて、次から始まるこの DAG 内の単なるパスになります。$6$、 そして$S(N)$最終ノードが次のようなパスをすべてカウントします。$\le N$。 

## 1. 数学的分析

 しましょう$dp(n)$で終わる有効なシーケンスの数になります。$n$。 

すべてのシーケンスは次から始まるので、$6$、$$dp(6)=1.$$のために$n>6$、$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<\phi(n)<x}} dp(x).$$条件$$\phi(x)<\phi(n)<x$$は以下と同等です:

 -$x > \phi(n)$、
 -$\phi(x) < \phi(n)$。 

それで、もし$t=\phi(n)$、$$dp(n) = \sum_{\substack{x<n\\ \phi(x)<t}} dp(x) - \sum_{\substack{x\le t\\ \phi(x)<t}} dp(x).$$ここで重要な簡略化を観察してください。 

あらゆる人にとって$x>1$、$$\phi(x)<x.$$したがって、いつでも$x\le t$、$$\phi(x)<x\le t \quad\Rightarrow\quad \phi(x)<t$$自動的に。 

したがって、2 番目の和は単純に次のようになります。$$\sum_{x\le t} dp(x).$$定義する：$$P(k)=\sum_{x\le k}dp(x)$$(プレフィックスの合計$dp$）。 

また、合計値を格納することでインデックス付けされたフェンウィック ツリーも維持します。$$\sum_{\phi(x)\le v} dp(x).$$それから：$$dp(n) = \text{FenwickQuery}(\phi(n)-1) - P(\phi(n)).$$すべてはモジュロです$10^8$。 

### 複雑さ

 - ふるいにかけた合計:$O(N\log\log N)$- それぞれ$n$1 つの Fenwick クエリと更新を実行します。$O(\log N)$合計：$$O(N\log N)$$実現可能なのは$N=20{,}000{,}000$。

 ## 2. Python の実装```python
MOD = 100_000_000
N = 20_000_000

def solve():
    # Compute Euler totients
    phi = list(range(N + 1))

    for i in range(2, N + 1):
        if phi[i] == i:  # prime
            for j in range(i, N + 1, i):
                phi[j] -= phi[j] // i

    # Fenwick tree for sums indexed by phi value
    bit = [0] * (N + 2)

    def add(i, v):
        """Add v at index i in Fenwick tree."""
        i += 1
        while i <= N + 1:
            bit[i] += v
            bit[i] %= MOD
            i += i & -i

    def query(i):
        """Prefix sum [0..i]."""
        s = 0
        i += 1
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s % MOD

    # Prefix sums of dp
    prefix = [0] * (N + 1)

    # Base case: sequence [6]
    prefix[6] = 1
    add(phi[6], 1)

    for n in range(7, N + 1):
        t = phi[n]

        # dp[n]
        val = query(t - 1) - prefix[t]
        val %= MOD

        # Add to structures
        add(t, val)
        prefix[n] = (prefix[n - 1] + val) % MOD

    return prefix[N]

print(solve())
```---

 ## 3. コードのチュートリアル

 ### トーティエントふるい

 初期化する```python
phi[i] = i
```そして各素数に対して$p$、$$\phi(k) \leftarrow \phi(k)\left(1-\frac1p\right)$$複数の場合$k$の$p$。

 ### フェンウィックの木

 合計値ごとに保存します$v$、$$\sum_{\phi(x)=v} dp(x).$$それから：```python
query(t - 1)
```返品$$\sum_{\phi(x)<t} dp(x).$$---

 ### プレフィックスの修正

 すべてを排除しなければなりません$x \le t$、ルールでは次のことが求められるため、$$t < x.$$以来$\phi(x)<x$、そのようなすべて$x$自動的に満たされる$\phi(x)<t$なので、以下を減算します。```python
prefix[t]
```等しい$$\sum_{x\le t} dp(x).$$したがって：```python
val = query(t - 1) - prefix[t]
```まさに再帰を実装します。
