 ## 解決策

 **答え:**`2906969179`## 1. 数学的分析

 すべての数字が欲しい$N < 10^8$次のような:

 1.$N$は 10 進数の回文です。 
2.$N$**連続する正の整数の二乗**の合計として書くことができます。$$N = a^2 + (a+1)^2 + \cdots + b^2$$と$a \ge 1$そして$b>a$(問題では些細な問題が除外されるため、少なくとも 2 つの項が必要です)$1=0^2+1^2$）。 

目標は、そのような数値すべての合計を計算することです。 

### 重要な観察: 効率的な連続二乗和

 素朴なアプローチでは、合計を繰り返し再計算します。$$a^2 + (a+1)^2 + \cdots + b^2$$代わりに、プレフィックスの合計を定義します。$$S(n)=1^2+2^2+\cdots+n^2$$それから：$$a^2+(a+1)^2+\cdots+b^2 = S(b)-S(a-1)$$これにより、すべての連続二乗和が次のようになります。$O(1)$前処理後の操作。 

閉じた形式を使用することもできます。$$S(n)=\frac{n(n+1)(2n+1)}{6}$$ただし、プレフィックスの合計を保存する方が簡単で効率的です。 

### 検索の境界を設定する

 限界があるので、$10^8$、$$1^2+2^2+\cdots+n^2 \approx \frac{n^3}{3}$$それで：$$\frac{n^3}{3}\lesssim 10^8 \quad\Rightarrow\quad n\approx 670$$したがって、必要なのはおおよそ以下の正方形だけです$\sqrt{10^8}=10^4$ですが、実際には制限があるため、ループははるかに早く終了します。 

### 重複を避ける

 回文は、連続した平方和として複数の方法で表現できる場合があります。 この問題では、表現ではなく、**すべての数値**の合計が求められます。 

したがって、有効な回文を`set`。 

### 回文テスト

 次の場合、数値は回文です。$$\text{str}(n)=\text{reverse(str}(n))$$これは検索サイズに対して十分な速度です。

 ## 2. Python の実装```python
LIMIT = 10**8

# Build prefix sums of squares:
# prefix[n] = 1^2 + 2^2 + ... + n^2
prefix = [0]
n = 1

while True:
    next_sum = prefix[-1] + n * n

    # Stop when even the cumulative sum exceeds the limit
    # (future sums only get larger)
    if next_sum >= LIMIT:
        prefix.append(next_sum)
        break

    prefix.append(next_sum)
    n += 1

# Store unique palindromes
palindromes = set()

# Try every consecutive range of at least two squares
for start in range(len(prefix)):
    for end in range(start + 2, len(prefix)):

        # Sum of squares from (start+1)^2 to end^2
        total = prefix[end] - prefix[start]

        # Stop early if we exceed the limit
        if total >= LIMIT:
            break

        # Check palindrome
        s = str(total)
        if s == s[::-1]:
            palindromes.add(total)

# Final answer
answer = sum(palindromes)
print(answer)
```---
