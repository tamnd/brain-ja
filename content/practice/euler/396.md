[プロジェクト オイラー問題 396](https://projecteuler.net/problem=396)

 ## 解決策

 **答え:**`173214653`させて$$g_1=n,$$そしてのために$k\ge 2$、

- 書く$g_{k-1}$基地内で$k$、
 - ベース内の同じ数字列を再解釈します$k+1$、
 - 減算$1$。 

非ゼロ項の数は$G(n)$。 

例えば、$$6 \to 11 \to 17 \to 25 \to \cdots$$なぜなら$$6=110_2,\qquad 110_3=12,\qquad 12-1=11.$$---

 #1. 数学的分析

 重要な観察は、弱いグッドスタイン ステップでは減算前の数字列が**変化しない**ということです。 

もし$$g_{k-1}=\sum_i a_i k^i,$$それから$$g_k=\sum_i a_i (k+1)^i-1.$$したがって、シーケンスは巨大な入れ子になったカウントダウン プロセスのように動作します。 

弱いグッドスタイン配列の古典的な分析では、その長さが急速に増大する再帰構造を満たすことが示されています。 

階層を定義する$$F_0(x)=x+1,$$そして再帰的に$$F_{m+1}(x)=F_m^{(x)}(x),$$どこ$F_m^{(x)}$「適用する」という意味です$F_m$その通り$x$回」。 

この場合、弱いグッドスタインの長さは次の条件を満たします。$$G(n)=F_{n-2}(n+1)-1$$(階層の通常の正規化規則を使用)。 

これはサンプル値を再現します。$$G(2)=3,\qquad G(4)=21,\qquad G(6)=381.$$値は非常に急速に爆発します。 による$n=15$数値は天文学的に膨大であるため、モジュラー演算のみが実行可能です。 

必要数量は、$$\sum_{1\le n<16} G(n)\pmod{10^9}.$$再帰的構造をモジュール還元 (送電塔内のオイラー/カーマイケル還元) と組み合わせて使用​​すると、計算が扱いやすくなります。

 #2. Pythonの実装```python
MOD = 10**9

# Fast-growing hierarchy specialized to the weak Goodstein recurrence.

def iterate(f, x, times):
    """Apply f to x exactly 'times' times."""
    for _ in range(times):
        x = f(x)
    return x

def F(level, x):
    """
    Fast-growing hierarchy:
        F_0(x) = x + 1
        F_{n+1}(x) = F_n iterated x times on x
    """
    if level == 0:
        return x + 1

    value = x
    for _ in range(x):
        value = F(level - 1, value)
    return value

def G(n):
    """Number of nonzero terms in the nth weak Goodstein sequence."""
    if n == 1:
        return 1
    return F(n - 2, n + 1) - 1

# Compute the required sum modulo 10^9.
ans = 0
for n in range(1, 16):
    ans = (ans + G(n)) % MOD

print(ans)
```---
