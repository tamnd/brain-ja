[プロジェクト オイラー問題 175](https://projecteuler.net/problem=175)

 ## 解決策

 **答え:**`1137174208`させて$$F(x)=\prod_{k\ge 0}(1+x^{2^k}+x^{2^{k+1}})$$の係数が$x^n$まさに$f(n)$、書き方の数$n$べき乗の合計として$2$各電力は最大 2 回使用されます。 

私たちは最小のものを追求します$n$そのような$$\frac{f(n)}{f(n-1)}=\frac{123456789}{987654321}.$$---

 #1. 再発$f(n)$パリティに従って分割します。 

## 奇数の引数

 もし$n=2m+1$、その後、$2^0$用語は 1 回だけ出現する必要があります。 それを削除して除算すると、$2$～の表現を含む全単射を与える$m$。 したがって、$$f(2m+1)=f(m).$$## 偶数引数

 もし$n=2m$、次に、の数$1$はどちらかです$0$または$2$。 

- ある場合$0$すべてを次で割ります$2$:$f(m)$可能性。 
- ある場合$2$それらを削除して割ります$2$:$f(m-1)$可能性。 

したがって$$f(2m)=f(m)+f(m-1).$$---

 #2. 比率とバイナリ構造

 定義する$$R(n)=\frac{f(n)}{f(n-1)}.$$繰り返しを使用すると、次のようになります。 

## もし$n=2m$

$$R(2m)=\frac{f(m)+f(m-1)}{f(m)}       =1+\frac{1}{R(m)}.$$＃＃ もし$n=2m+1$

$$R(2m+1)=\frac{f(m)}{f(m)+f(m-1)}        =\frac{R(m)}{R(m)+1}.$$これらは、2 進数の追加に正確に対応します。 

- 追加$0$:$x \mapsto 1+\frac1x$- 追加$1$:$x \mapsto \frac{x}{x+1}$から始まる$R(1)=1$、すべての正の有理数は、Stern-Brocot/Calkin-Wilf ツリー内のパスによって一意に到達します。 

したがって、最小値を回復するには、$n$端数から$p/q$、逆方向に作業します。 

- もし$p<q$、最後の部分は$1$、そして私たちは置き換えます$$\frac pq \mapsto \frac p{q-p};$$- もし$p>q$、最後の部分は$0$、そして私たちは置き換えます$$\frac pq \mapsto \frac{p-q}q.$$これは単なるユークリッド アルゴリズムです。 

---

 # 3. 指定された分数に適用する

 最初に削減します:$$\frac{123456789}{987654321} = \frac{13717421}{109739369}.$$次に、ユークリッド処理を実行します。 

以来$$109739369 = 8\cdot 13717421 + 1,$$引き算します$13717421$8回：$$\frac{13717421}{109739369} \to \frac{13717421}{1}.$$これは 8 つの末尾に寄与します$1$-ビット。 

次、$$13717421 = 13717420\cdot 1 + 1,$$それで引き算します$1$合計$13717420$回:$$\frac{13717421}{1} \to \frac11.$$これは貢献します$13717420$後続$0$-ビット。 

ついに根元に到着$1/1$、先頭の 2 進数に対応$1$。 

したがって、バイナリ展開は次のようになります。$$1\underbrace{00\cdots0}_{13717420} \underbrace{11\cdots1}_{8}.$$したがって、その短縮されたバイナリ展開は次のようになります。$$1,13717420,8.$$---

 #4. Pythonの実装```python
from math import gcd

p = 123456789
q = 987654321

# Reduce fraction
g = gcd(p, q)
p //= g
q //= g

runs_reversed = []

while not (p == 1 and q == 1):

    if p < q:
        # We are undoing an appended '1'
        k = (q - 1) // p
        q -= k * p
        runs_reversed.append(("1", k))

    else:
        # We are undoing an appended '0'
        k = (p - 1) // q
        p -= k * q
        runs_reversed.append(("0", k))

# Reconstruct binary string
binary = "1"
for bit, count in reversed(runs_reversed):
    binary += bit * count

# Convert to shortened binary expansion
sbe = []
count = 1

for i in range(1, len(binary) + 1):
    if i < len(binary) and binary[i] == binary[i - 1]:
        count += 1
    else:
        sbe.append(count)
        count = 1

print(",".join(map(str, sbe)))
```---

 #5. コードのチュートリアル

 - 最初にターゲットの割合を減らします。 
- ユークリッド アルゴリズムを使用して逆方向に作業します。 
- 繰り返される減算の各ブロックは、繰り返される同一の 2 進数に対応します。 
- それらの実行からバイナリ展開を再構築します。 
- 連続する等しいビットを短縮されたバイナリ展開に圧縮します。 

サンプルについて$13/17$:

 -$17 = 1\cdot 13 + 4$→ 後続の 1 つ$1$-$13 = 3\cdot 4 + 1$→ 3 つの後続$0$さんの
 -$4 = 3\cdot 1 + 1$→ 3 つの後続$1$さんの

 バイナリを与える$$11110001_2 = 241,$$その短縮形は$$4,3,1,$$まさに記載どおりです。

 #6. 最終検証

 ユークリッド アルゴリズムは次の時点で終了します。$(1,1)$、最小限性を保証します。 

バイナリ パターンは次のもので構成されます。 

- 先頭の 1 つ$1$、
 -$13717420$ゼロ、
 -$8$もの、

 したがって、短縮されたバイナリ展開は一貫性があり、完全です。 

**答え: 1,13717420,8**
