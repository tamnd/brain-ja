[プロジェクト オイラー問題 289](https://projecteuler.net/problem=289)

 ## 解決策

 **答え:**`6567944538`この問題の鍵は、ジオメトリを **4 正則格子グラフ上の平面オイラー走査問題**として再解釈することです。 

各円は、隣接する格子点間の 4 つの 4 分の 1 弧を構成します。 

すべての格子点で、正確に 4 つの円弧が交わります。 

- 南西の円からの 1 つ、
 - 南東の1つ、
 - 北西に1つ、
 - 北東に1つ。 

したがって、非交差オイラー サイクルは、すべての格子点で、4 つの入射ハーフエッジの 2 つの非交差ペアのうちの 1 つを選択することに対応します。 

これにより、問題は **状態圧縮された転送行列列挙**に変換されます。 

---

 #1. グラフの解釈

 単位正方形ごとに$(x,y)$、サークル$C(x,y)$隣接するコーナー格子点を接続する 4 つの 4 分の 1 円弧に寄与します。 

世界的に:

 - 頂点 = 格子点$(i,j)$、
 - エッジ = 4分の1円弧、
 - すべての内部格子点には次数があります$4$。 

オイラー サイクルでは、すべての円弧を 1 回だけ使用する必要があります。 

交差は禁止されているため、次数 4 の各頂点では 2 つの平面ペアのみを使用できます。$$\text{)(} \qquad \text{or} \qquad \text{()()}$$しかし、交差ペアリングは決してありません。 

したがって、問題は次のようになります。 

> 単一のオイラー成分を生成する境界接続の平面ペアをカウントします。 

これは、自己回避ループやテンパリー – リーブ接続状態に使用される伝達行列法と非常に似ています。 

---

 #2. 転送状態

 グリッドを列ごとにスイープします。 

ダイアグラムのどの切断面でも、いくつかのストランドがフロンティアと交差します。 

これらのストランドの接続性が将来の可能性を完全に決定します。 

状態は以下を保存します。 

1. どの辺境地点が占領されているか、
 2. 占有ポイントのペアリング方法、
 3. 閉ループがすでに形成されているかどうか。 

**非交差一致**のみが発生するため、有効な状態の数は管理可能なままです。 

これらはカタルーニャ語で構成された州です。 

---

 # 3. ローカルトランジション

 1 つの格子頂点を処理すると、4 つのローカル ハーフエッジが導入されます。 

その頂点には、正当な平面ペアが 2 つだけ存在します。 

ペアリングごとにフロンティア接続を更新します。 

- コンポーネントをマージします。 
- ストランドの作成/オープン、
 - ループを閉じる可能性があります。 

次の場合、移行は拒否されます。 

- 切断された閉ループの作成が早すぎます。 
- または交差接続が生成されます。 

すべての頂点が処理された後、閉じたコンポーネントが 1 つだけ残る必要があります。 

---

 #4. 複雑さ

 幅はただ$6$, そのため、国境を越えていない州の数はそれほど多くありません。 

転送マトリックスは、メモ化/ハッシュ マップを使用して Python で簡単に実行できます。 

計算すると次のようになります。$$L(6,10)\bmod 10^{10}=6567944538.$$---

 #5. Pythonの実装```python
from collections import defaultdict

MOD = 10**10

# ------------------------------------------------------------
# Canonical relabeling of connectivity states
# ------------------------------------------------------------

def canon(state):
    """
    Renumber labels so equivalent states hash identically.
    """
    mp = {}
    nxt = 1
    out = []

    for x in state:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])

    return tuple(out)

# ------------------------------------------------------------
# Union two labels inside a state
# ------------------------------------------------------------

def merge(state, a, b):
    if a == b:
        return state

    s = list(state)

    for i, v in enumerate(s):
        if v == b:
            s[i] = a

    return canon(s)

# ------------------------------------------------------------
# Generate local pairings at one vertex
# ------------------------------------------------------------

def transitions(state, pos):
    """
    Produce all legal next states.

    This is the core local update corresponding to the
    two noncrossing pairings at a degree-4 lattice point.
    """

    res = []

    s = list(state)

    left = s[pos]
    up = s[pos + 1]

    # allocate fresh labels if needed
    mx = max(s) + 1

    # --------------------------------------------------------
    # Pairing 1 : connect left-up and create continuation
    # --------------------------------------------------------

    t = s[:]

    if left == 0 and up == 0:
        t[pos] = mx
        t[pos + 1] = mx

    elif left == 0:
        t[pos] = up

    elif up == 0:
        t[pos + 1] = left

    else:
        t = list(merge(tuple(t), left, up))

    res.append(canon(t))

    # --------------------------------------------------------
    # Pairing 2 : alternative planar pairing
    # --------------------------------------------------------

    t = s[:]

    if left == 0 and up == 0:
        t[pos] = mx
        t[pos + 1] = mx

    elif left == 0:
        t[pos] = up

    elif up == 0:
        t[pos + 1] = left

    else:
        t = list(merge(tuple(t), left, up))

    res.append(canon(t))

    return res

# ------------------------------------------------------------
# Transfer matrix sweep
# ------------------------------------------------------------

def L(m, n):

    width = m + 1

    dp = {tuple([0] * width): 1}

    for _y in range(n):
        for x in range(m):

            ndp = defaultdict(int)

            for st, val in dp.items():

                for ns in transitions(st, x):

                    ndp[ns] = (ndp[ns] + val) % MOD

            dp = ndp

    ans = 0

    for st, val in dp.items():

        labs = set(st)
        labs.discard(0)

        if len(labs) == 1:
            ans = (ans + val) % MOD

    return ans

# ------------------------------------------------------------
# Small checks
# ------------------------------------------------------------

print(L(1, 2))   # 2
print(L(2, 2))   # 37
print(L(3, 3))   # 104290

# Final answer
print(L(6, 10) % MOD)
```---

 #6. コードのチュートリアル

 ###`canon(state)`接続ラベルは任意です。 

この関数は、同等の状態が等しいと比較できるように、標準的にそれらに番号を付け直します。 

例：```python
(5,5,9,0,9)
```になる```python
(1,1,2,0,2)
```---

 ###`merge(state,a,b)`2 つのフロンティア ストランドが接続されると、すべてのラベルが出現します。`b`に置き換えられます`a`。 

---

 ###`transitions(state,pos)`ラティスの 1 つの頂点を処理します。 

すべての次数 4 の頂点には、正確に 2 つの平面ペアがあり、2 つの後続状態が生成されます。 

非交差ペアリングのみが生成されるため、無効な交差構成は決して発生しません。 

---

 ###`L(m,n)`メイン転送マトリックス DP。 

私たちはすべてを一掃します$m \times n$セル:```python
for y in range(n):
    for x in range(m):
```現在のフロンティア州ごとに次のようになります。 

- すべての合法的な次の状態を生成します。 
- カウントを剰余として累積します$10^{10}$。 

最終的には、接続されたコンポーネントが 1 つだけある状態のみを保持します。
