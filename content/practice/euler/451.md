[プロジェクト オイラー問題 451](https://projecteuler.net/problem=451)

 ## 解決策

 **答え:**`153651073760956`すべての整数が必要です$m$そのような$$m^2 \equiv 1 \pmod n,$$なぜなら、要素はそれ自体のモジュラーインバースであるためです。$m^{-1}\equiv m\pmod n$。 

問題の定義$I(n)$その最大のものとして$m<n-1$。 

---

 #1. 数学的分析

 解決しなければなりません$$x^2 \equiv 1 \pmod n.$$同様に、$$(x-1)(x+1)\equiv 0 \pmod n.$$主要な構造は中国の剰余定理から来ています。 

---

 ## ステップ 1: 素数べき乗を法とする解

 奇数の素数パワーの場合$p^k$:$$x^2\equiv 1 \pmod{p^k}$$正確に 2 つの解決策があります。$$x\equiv \pm 1 \pmod{p^k}.$$の権限については、$2$:

 - モジュロ$2$: 1 つの解決策
 - モジュロ$4$: 2 つの解決策
 - モジュロ$2^k$のために$k\ge 3$: 4 つの解決策$$x\equiv \pm1,\quad \pm(1+2^{k-1}) \pmod{2^k}.$$---

 ## ステップ 2: CRT の分解

 もし$$n=\prod p_i^{a_i},$$次に、すべての解のモジュロ$n$は、各素数べき乗を法とする 1 つの解を独立して選択し、それらを CRT と組み合わせることで得られます。 

したがって、自明でない解は、いくつかの素数べき乗因数を剰余に割り当てることによって得られます。$+1$その他の残留物$-1$。 

---

 ## ステップ 3: 最大のソリューションの特徴付け

 仮定してください$$n=ab,\qquad \gcd(a,b)=1.$$CRT システムを使用してください$$x\equiv -1 \pmod a,\qquad x\equiv 1 \pmod b.$$CRT は独自の解モジュロを提供します$n$。 

あらゆる重要な巻き込みは、このような分割から生じます。 

もし$x$が解決策であるなら、それも解決策です$n-x$。 

したがって、以下の最大の解決策は$n-1$は、最小の非自明な解から得られます。 

それで定義します$$s(n)=\min\{x>1 : x^2\equiv1\pmod n\},$$それから$$I(n)=n-s(n).$$---

 ## ステップ 4: 効率的な計算

 までは直接検索できません。$2\times10^7$。 

代わりに:

 1. 最小の素因数をふるいにかけます。 
2. それぞれを因数分解する$n$。 
3. 素数べき乗分解からすべての CRT インボリューションを生成します。 
4. 自明ではない最小の解決策を維持する$s(n)$。 
5.追加$n-s(n)$。 

個別の素因数の数が少ないため、インボリューションの数はわずかです。 

合計実行時間は、最適化された Python/PyPy で簡単に実現可能です。

 #2. Pythonの実装```python
from math import prod

LIMIT = 20_000_000

# ------------------------------------------------------------
# Smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(LIMIT + 1))

for i in range(2, int(LIMIT ** 0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, LIMIT + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Extended Euclid modular inverse
# ------------------------------------------------------------

def inv_mod(a, m):
    x0, x1 = 1, 0
    b = m
    while b:
        q = a // b
        a, b = b, a % b
        x0, x1 = x1, x0 - q * x1
    return x0 % m

# ------------------------------------------------------------
# CRT merge:
# x ≡ r1 (mod m1)
# x ≡ r2 (mod m2)
# gcd(m1,m2)=1
# ------------------------------------------------------------

def crt(r1, m1, r2, m2):
    t = ((r2 - r1) * inv_mod(m1, m2)) % m2
    return r1 + m1 * t

# ------------------------------------------------------------
# Generate prime powers
# ------------------------------------------------------------

def factorize(n):
    out = []
    while n > 1:
        p = spf[n]
        e = 0
        pp = 1
        while n % p == 0:
            n //= p
            e += 1
            pp *= p
        out.append((p, e, pp))
    return out

# ------------------------------------------------------------
# Solutions modulo p^k
# ------------------------------------------------------------

def local_roots(p, e, pe):
    if p == 2:
        if e == 1:
            return [1]
        elif e == 2:
            return [1, 3]
        else:
            h = 1 << (e - 1)
            return [1, pe - 1, 1 + h, h - 1]
    else:
        return [1, pe - 1]

# ------------------------------------------------------------
# Main
# ------------------------------------------------------------

answer = 0

for n in range(3, LIMIT + 1):

    fac = factorize(n)

    roots = [(0, 1)]

    # build all CRT combinations
    for p, e, pe in fac:
        local = local_roots(p, e, pe)

        new_roots = []

        for r, mod in roots:
            for t in local:
                nr = crt(r, mod, t, pe)
                new_roots.append((nr, mod * pe))

        roots = new_roots

    best = 1

    for r, _ in roots:
        r %= n
        if r != n - 1:
            best = max(best, r)

    answer += best

print(answer)
```---

 #3. コードのチュートリアル

 ### SPFふるい

 までのすべての数値の最小の素因数を事前計算します。$2\times10^7$。 

これにより、ほぼ一定の償却時間で因数分解が可能になります。 

---

 ###`factorize(n)`生産する$$n=\prod p_i^{e_i}$$実際の主要な権限と一緒に$p_i^{e_i}$。 

---

 ###`local_roots`すべての解を返します$$x^2\equiv1\pmod{p^e}.$$奇数素数の場合: のみ$\pm1$。 

2 の累乗の場合 ($e\ge3$):$$1,\ -1,\ 1+2^{e-1},\ -1+2^{e-1}.$$---

 ### CRT組み合わせ

 ローカル解をモジュロでグローバル解に再帰的に結合します$n$。 

異なる素因数の数が少ないため、根の総数は非常に少なくなります。 

---

 ### 抽出中$I(n)$あらゆる根の中でも、$n-1$は常に存在します（簡単な解決策）$-1$）。 

より厳密に小さい最大のルートを選択します。$n-1$。 

---

 #4. 小さな例での検証

 ##$n=15$ルーツは$$1,4,11,14.$$以下最大$14$は$$I(15)=11.$$正しい。 

---

 ##$n=100$ルーツは$$1, 49, 51, 99.$$以下最大$99$は$$I(100)=51.$$正しい。 

---

 ##$n=7$根のみ:$$1,6.$$以来$6=n-1$は除外されます:$$I(7)=1.$$正しい。

 #5. 最終検証

 合計は次のとおりです$$\sum_{n\le 2\times10^7} O(n),$$それで結果は$10^{14}$–$10^{15}$合理的です。 

計算は完全に決定論的であり、モジュロのインボリューションの完全な分類に基づいています。$n$。
