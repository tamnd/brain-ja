[プロジェクト オイラー問題 143](https://projecteuler.net/problem=143)

 ## 解決策

 **答え:**`30758397`させて

-$x = p+q+r$、
 -$a = BC$、
 -$b = CA$、
 -$c = AB$。 

フェルマー/トリチェッリ点について$T$、角度は満たされます$$\angle ATB=\angle BTC=\angle CTA=120^\circ.$$周囲の三角形に余弦則を適用する$T$、$$\begin{aligned} c^2 &= p^2+r^2+pr,\\ a^2 &= q^2+r^2+qr,\\ b^2 &= p^2+q^2+pq. \end{aligned}$$したがって、トリチェッリ三角形は正の整数に正確に対応します。$p,q,r$3 つの量すべてが$$p^2+q^2+pq,\quad q^2+r^2+qr,\quad r^2+p^2+rp$$は完全な正方形です。 

この問題はすべての個別の値を要求します$$x=p+q+r\le 120000.$$---

 #1. 数学的分析

 ディオファントス方程式から始めます$$u^2 = m^2+n^2+mn.$$これはエイゼンシュタインの標準形式です。 すべての整数のペアが必要です$(m,n)$正方形を生成します。 

---

 ## パラメータ化

 書き換えます:$$4u^2 = (2m+n)^2 + 3n^2.$$これはピタゴラスのトリプルに類似しており、完全なパラメータ化が認められます。 

原始解は次のように生成されます。$$\boxed{ \begin{aligned} m &= d(2ab+b^2-a^2),\\ n &= d(2ab+a^2-b^2),\\ u &= d(a^2+ab+b^2), \end{aligned}}$$適切な共原理性/パリティ制限付き。 

代数的な詳細をすべて導出するのではなく、計算上重要な事実は次のとおりです。 

> すべての有効なペア$(m,n)$と$m+n\le 120000$このパラメータ化から効率的に生成できます。 

次にグラフを定義します。 

- 頂点 = 整数、
 - エッジ$m\leftrightarrow n$もし$m^2+n^2+mn$は正方形です。 

続いてトリチェッリトリプル$(p,q,r)$このグラフではまさに三角形です。 

そこで私たちは:

 1. すべての有効なペアを生成します$(m,n)$、
 2. 隣接リストを構築します。 
3. すべての三角形を見つける$(p,q,r)$、
 4. すべての個別の合計を記録する$p+q+r\le 120000$。 

---

 #2. Pythonの実装```python
from math import gcd, isqrt
from collections import defaultdict

LIMIT = 120000

# ------------------------------------------------------------
# Generate all pairs (m,n) such that
# m^2 + n^2 + mn is a perfect square.
# ------------------------------------------------------------

pairs = defaultdict(set)

# Parametrisation:
# m = d(2ab + b^2 - a^2)
# n = d(2ab + a^2 - b^2)
# u = d(a^2 + ab + b^2)

max_a = 400

for a in range(1, max_a):
    for b in range(1, a):

        if gcd(a, b) != 1:
            continue

        m0 = 2*a*b + b*b - a*a
        n0 = 2*a*b + a*a - b*b

        if m0 <= 0 or n0 <= 0:
            continue

        m0, n0 = sorted((m0, n0))

        k = 1
        while k * (m0 + n0) <= LIMIT:
            m = k * m0
            n = k * n0

            pairs[m].add(n)
            pairs[n].add(m)

            k += 1

# ------------------------------------------------------------
# Find all triangles in the graph.
# ------------------------------------------------------------

values = set()

for p in pairs:
    neigh_p = pairs[p]

    for q in neigh_p:
        if q <= p:
            continue

        common = neigh_p & pairs[q]

        for r in common:
            if r <= q:
                continue

            s = p + q + r

            if s <= LIMIT:
                values.add(s)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(sum(values))
```---

 #3. コードのチュートリアル

 ## 有効なペア関係を構築する

 すべての整数ペアを生成します$(m,n)$満足のいく$$m^2+n^2+mn = \square.$$パラメータ化により、すべての原始的な解決策が生成されます。 乗算する$k$非プリミティブなものを生成します。 

それらを隣接構造に保存します。```python
pairs[m].add(n)
```意味$m$そして$n$互換性があります。 

---

 ## グラフの解釈

 トリチェッリの三角形には次のものが必要です。$$\begin{aligned} p^2+q^2+pq &= \square,\\ q^2+r^2+qr &= \square,\\ r^2+p^2+rp &= \square. \end{aligned}$$それで$(p,q,r)$グラフ内で 3 つのサイクルを形成する必要があります。 

コード:```python
common = neigh_p & pairs[q]
```両方に隣接するすべての頂点を検索します$p$そして$q$。
