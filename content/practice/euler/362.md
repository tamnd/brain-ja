[プロジェクト オイラー問題 362](https://projecteuler.net/problem=362)

 ## 解決策

 **答え:**`457895958010`**自由平方因数分解**してみましょう$n$整数への順序なし因数分解を意味します$>1$、ここですべての因子は平方自由です。 

以下を定義します。$$\operatorname{Fsf}(n)$$そのような因数分解の数として、そして$$S(N)=\sum_{k=2}^{N}\operatorname{Fsf}(k).$$私たちには次のものが与えられます:$$S(100)=193.$$以下を計算する必要があります。$$S(10^{10}).$$---

 ## 1. 数学的分析

 ### 再解釈$S(N)$合計する代わりに$n$、すべての有効な自由平方分解を直接カウントします。 

それぞれの貢献度$\operatorname{Fsf}(n)$自由平方整数の順序のない複数集合です$>1$誰の製品ですか$n$。 

したがって：$$S(N)$$はまさに自由平方整数の順序付けされていない複数集合の数です$>1$誰の製品がせいぜい$N$。 

---

 ### 正規の順序付け

 過剰カウントを避けるために、因子に非減少順序を課します。$$q_1 \le q_2 \le \cdots \le q_r,$$どこでも$q_i$スクエアフリーです。 

定義する：$$A(N,m)$$少なくともすべての因数を含む因数分解の数になります。$m$、および製品$\le N$。 

それから：$$S(N)=A(N,2).$$---

 ### 再帰式

 最小の係数を選択してください$q$、これは正方形でなく、以下を満たす必要があります。$$m \le q \le N.$$選択した後$q$:

 - 以下のみからなる有効な因数分解が 1 つ得られます。$q$、
 - または、残りの境界の因数分解を続行します$N/q$、係数を維持する$\ge q$。 

したがって：$$A(N,m) = \sum_{\substack{q\ \text{squarefree}\\ q\ge m\\ q\le N}} \Bigl(1+A(\lfloor N/q\rfloor,q)\Bigr).$$ここで次のことを観察してください。 

もし$$q>\sqrt N,$$それから$$\lfloor N/q\rfloor<q,$$したがって再帰は不可能です。 

したがって、次のようになります。$$A(N,m) = Q(N)-Q(m-1) + \sum_{\substack{m\le q\le \sqrt N\\ q\ \text{squarefree}}} A(\lfloor N/q\rfloor,q),$$どこ$Q(x)$自由平方整数を数えます$>1$まで$x$。 

---

 ### 自由平方整数の数を数える

 メビウス反転の使用:$$Q(x) = \sum_{d\le \sqrt x}\mu(d) \left\lfloor \frac{x}{d^2}\right\rfloor -1.$$($-1$数字を除きます$1$。）

以来：$$\sqrt{10^{10}}=100000,$$以下のメビウス値のみが必要です。$10^5$。 

再帰をメモ化すると計算が可能になります。 

---

 ## 2. Python の実装```python
from math import isqrt
from bisect import bisect_right
from functools import lru_cache

N = 10_000_000_000
LIMIT = isqrt(N)

# -------------------------------
# Möbius function (linear sieve)
# -------------------------------
mu = [0] * (LIMIT + 1)
mu[1] = 1

primes = []
composite = [False] * (LIMIT + 1)

for i in range(2, LIMIT + 1):
    if not composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        v = i * p
        if v > LIMIT:
            break

        composite[v] = True

        if i % p == 0:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# --------------------------------
# List of squarefree numbers <= LIMIT
# --------------------------------
squarefree = [x for x in range(2, LIMIT + 1) if mu[x] != 0]

# Prefix count of squarefree numbers (>1)
prefix_sf = [0] * (LIMIT + 1)
count = 0

for i in range(LIMIT + 1):
    if i >= 2 and mu[i] != 0:
        count += 1
    prefix_sf[i] = count

# --------------------------------
# Count squarefree numbers <= x
# --------------------------------
@lru_cache(None)
def Q(x):
    if x <= LIMIT:
        return prefix_sf[x]

    r = isqrt(x)
    total = 0

    for d in range(1, r + 1):
        if mu[d] != 0:
            total += mu[d] * (x // (d * d))

    return total - 1   # exclude 1

# --------------------------------
# Recursive counting
# --------------------------------
@lru_cache(None)
def A(n, idx):
    """
    Count squarefree factorizations
    using factors >= squarefree[idx].
    """
    m = squarefree[idx]

    # Count one-factor factorizations
    total = Q(n) - Q(m - 1)

    # Recursive part only needed up to sqrt(n)
    limit = isqrt(n)
    end = bisect_right(squarefree, limit)

    for j in range(idx, end):
        q = squarefree[j]
        total += A(n // q, j)

    return total

answer = A(N, 0)
print(answer)
```---

 私たちは計算します$\mu(n)$まで$100000$直線ふるいを使用します。 

これにより、以下の効率的な評価が可能になります。$$Q(x) = \sum \mu(d)\left\lfloor x/d^2\right\rfloor - 1.$$---

 ### ステップ 2: 自由平方数を生成する

 次の場合、数値は平方フリーです。$$\mu(n)\neq 0.$$すべての平方自由整数を次の値まで保存します。$100000$。 

---

 ### ステップ 3: 再帰的なカウント`A(n, idx)`最小因数が少なくとも次のとおりであるすべての有効な因数分解をカウントします。```python
squarefree[idx]
```用語：```python
Q(n) - Q(m - 1)
```すべての単一要素の選択肢をカウントします。 

次に、以下についてのみ再帰します。$$q \le \sqrt n,$$大きいので$q$他の要因を後に続けることはできません。 

メモ化により再計算が回避されます。
