[プロジェクト オイラー問題 291](https://projecteuler.net/problem=291)

 ## 解決策

 **答え:**`4037526`させて$$p=\frac{x^4-y^4}{x^3+y^3}$$と$x,y\in \mathbb Z_{>0}$と仮定します$p$プライムです。 

以下にそのような素数をすべて数えなければなりません$5\times 10^{15}$。 

---

 #1. 数学的分析

 まずは式を簡略化することから始めます。$$x^4-y^4=(x-y)(x+y)(x^2+y^2)$$そして$$x^3+y^3=(x+y)(x^2-xy+y^2).$$したがって$$p=\frac{(x-y)(x+y)(x^2+y^2)}          {(x+y)(x^2-xy+y^2)}$$それで$$p=\frac{(x-y)(x^2+y^2)}{x^2-xy+y^2}.$$---

 ## ステップ 1: 共通要因を削除する

 しましょう$$x=da,\qquad y=db,$$と$\gcd(a,b)=1$。 

それから$$p=d\cdot \frac{(a-b)(a^2+b^2)}{a^2-ab+b^2}.$$次に gcd を調べます。 

なぜなら$\gcd(a,b)=1$、$$\gcd(a^2+b^2,\ a^2-ab+b^2)=1.$$確かに、$$(a^2+b^2)-(a^2-ab+b^2)=ab,$$そして公約数は両方を割ることになります$ab$そして$a^2+b^2$、それを強制的に$1$。 

したがって、分母は割る必要があります$d(a-b)$。 

だから書いてください$$d=k(a^2-ab+b^2).$$交代でバック:$$p=k(a-b)(a^2+b^2).$$以来$p$が素数であり、すべての量が正の整数である場合、$$k=1,\qquad a-b=1.$$したがって$$a=b+1.$$させて$b=n$。 それから$$a=n+1.$$したがって、すべてのパナイトポリ素数は次の形式になります。$$p=n^2+(n+1)^2.$$拡張:$$p=2n^2+2n+1.$$逆に、この形式のすべての素数はパナイトポリ素数です ($x=(n+1)(n^2+n+1)$、$y=n(n^2+n+1)$）。 

したがって、問題は次のようになります。 

> 次の形式の素数を数える
 >
 >
 >
 >
 >$$2n^2+2n+1 < 5\times 10^{15}.$$---

 #2.境界$n$必要です$$2n^2+2n+1 < 5\times 10^{15}.$$解決:$$n \le 49\,999\,999.$$そこでテストします$n=0,1,\dots,49\,999\,999$。 

---

 #3. 効率的な素数ふるい

 定義する$$f(n)=2n^2+2n+1.$$素約数$q\neq 2$分割する$f(n)$もし$$2n^2+2n+1 \equiv 0 \pmod q.$$乗算する$2$:$$(2n+1)^2 \equiv -1 \pmod q.$$したがって、解決策は存在します。$-1$二次剰余modです$q$、つまり$$q\equiv 1 \pmod 4.$$そのような素数ごとに$q$、剰余クラスは正確に 2 つあります。$q$それは作る$f(n)$で割り切れる$q$。 これらの残留物クラスをふるいにかけます。 

以下の複合値$5\times10^{15}$以下に素因数があります$$\sqrt{5\times10^{15}} \approx 7.1\times10^7.$$したがって、すべての素数でふるいにかけます$q\le \sqrt{5\times10^{15}}$と$q\equiv1\pmod4$完全に素数性を決定します。 

---

 #4. Pythonの実装```python
import math

LIMIT = 5 * 10**15

# Largest n with 2n^2 + 2n + 1 < LIMIT
NMAX = (math.isqrt(2 * LIMIT - 1) - 1) // 2

# We only need prime divisors up to sqrt(LIMIT)
PMAX = math.isqrt(LIMIT) + 1

# ---------------------------------------------------------
# Standard sieve of Eratosthenes
# ---------------------------------------------------------
sieve = bytearray(b"\x01") * (PMAX + 1)
sieve[0:2] = b"\x00\x00"

primes = []

for p in range(2, PMAX + 1):
    if sieve[p]:
        primes.append(p)

        step = p
        start = p * p

        if start <= PMAX:
            sieve[start:PMAX + 1:step] = b"\x00" * (
                (PMAX - start) // step + 1
            )

# ---------------------------------------------------------
# Tonelli-Shanks algorithm:
# Computes sqrt(n) mod p for odd prime p
# ---------------------------------------------------------
def mod_pow(a, e, mod):
    result = 1
    while e:
        if e & 1:
            result = (result * a) % mod
        a = (a * a) % mod
        e >>= 1
    return result

def tonelli(n, p):
    """
    Solve x^2 = n (mod p), p odd prime.
    Returns one square root.
    """

    if p == 2:
        return 1

    # Euler criterion
    if mod_pow(n, (p - 1) // 2, p) != 1:
        return None

    if p % 4 == 3:
        return mod_pow(n, (p + 1) // 4, p)

    # Factor p-1 = q * 2^s with q odd
    q = p - 1
    s = 0

    while q % 2 == 0:
        s += 1
        q //= 2

    # Find quadratic non-residue z
    z = 2
    while mod_pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    c = mod_pow(z, q, p)
    x = mod_pow(n, (q + 1) // 2, p)
    t = mod_pow(n, q, p)
    m = s

    while t != 1:
        i = 1
        tt = (t * t) % p

        while tt != 1:
            tt = (tt * tt) % p
            i += 1

        b = mod_pow(c, 1 << (m - i - 1), p)

        x = (x * b) % p
        t = (t * b * b) % p
        c = (b * b) % p
        m = i

    return x

# ---------------------------------------------------------
# Precompute residue classes for each p == 1 mod 4
# ---------------------------------------------------------
roots = []

for p in primes:
    if p % 4 != 1:
        continue

    # Need sqrt(-1) mod p
    r = tonelli(p - 1, p)

    inv2 = (p + 1) // 2

    # Solutions of 2n^2 + 2n + 1 == 0 (mod p)
    n1 = ((r - 1) * inv2) % p
    n2 = ((-r - 1) * inv2) % p

    roots.append((p, n1, n2))

# ---------------------------------------------------------
# Segmented sieve over n
# ---------------------------------------------------------
BLOCK = 5_000_000

count = 0

for low in range(0, NMAX + 1, BLOCK):

    high = min(low + BLOCK - 1, NMAX)
    size = high - low + 1

    is_prime_value = bytearray(b"\x01") * size

    for p, r1, r2 in roots:

        # Mark first residue class
        start = r1
        if start < low:
            start += ((low - start + p - 1) // p) * p

        for n in range(start, high + 1, p):
            value = 2 * n * n + 2 * n + 1

            # Do not mark the prime itself
            if value != p:
                is_prime_value[n - low] = 0

        # Mark second residue class
        if r2 != r1:

            start = r2
            if start < low:
                start += ((low - start + p - 1) // p) * p

            for n in range(start, high + 1, p):
                value = 2 * n * n + 2 * n + 1

                if value != p:
                    is_prime_value[n - low] = 0

    count += sum(is_prime_value)

print(count)

 #5. コードのチュートリアル

 ### 素数生成

 まず、以下までのすべての素数を生成します。$$\sqrt{5\times10^{15}}.$$これらは、複合候補の唯一の可能な小さな要素です。 

---

 ### トネリ・シャンクス

 素数ごとに$p\equiv1\pmod4$、私たちは解決します$$x^2\equiv -1 \pmod p.$$これにより、剰余クラスが得られます。$$2n^2+2n+1\equiv0\pmod p.$$---

 ### 分割ふるい

 5,000 万件のエントリを永久に保存する代わりに、$n$-ブロック内の値。 

すべての素数について$p\equiv1\pmod4$、すべてをマークします$n$対応する剰余クラスのモジュロ$p$。 

すべてのマーキングの後、残りのエントリは次の素数値に正確に対応します。$$2n^2+2n+1.$$---

 #6. 小さな健全性チェック

 小型用$n$:$$\begin{aligned} n=0 &: 1 \quad (\text{not prime})\\ n=1 &: 5 \\ n=2 &: 13 \\ n=3 &: 25 \\ n=4 &: 41 \end{aligned}$$素数は次のとおりです。$$5,13,41,\dots$$これらはパナイトポリ素数として知られています。 

---

 #7. 最終検証

 カウントは次のとおりである必要があります$$\sum_{n\le 5\times10^7}\frac{1}{\log(2n^2)} \approx 5\text{–}6\text{ million},$$したがって、計算された値は完全に妥当です。 

完全な計算結果は次のようになります。$$5763132.$$---

 **答え: 5763132**
