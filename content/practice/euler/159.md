[プロジェクト オイラー問題 159](https://projecteuler.net/problem=159)

 ## 解決策

 **答え:**`14489159`させて$drs(n)$のデジタルルートを示します$n$。 

便利な閉じた形式は次のとおりです。$$drs(n)= \begin{cases} 0 & n=0\\ 1+((n-1)\bmod 9) & n>0 \end{cases}$$したがって、すべての正の整数について、$drs(n)\in\{1,\dots,9\}$、 そして：

-$drs(24)=2+4=6$-$drs(467)=4+6+7=17\to1+7=8$以下を定義します。$$mdrs(n)=\max\{\text{digital root sums over all factorizations of } n\}$$些細な因数分解も含めて$n$自体。 

例えば：$$24 = 3\times 8$$与える$$drs(3)+drs(8)=3+8=11$$そして、どの因数分解もより良い結果をもたらすので、次のようになります。$$mdrs(24)=11$$---

 # 重要な洞察

 分割したとしましょう$n$として：$$n=d\cdot \frac{n}{d}$$次に、次の最適な因数分解を行います。$n$次のように表示できます。 

- 約数を 1 つ選択する$d\ge2$、
 - 次に最適に因数分解します$n/d$。 

したがって：$$mdrs(n)=\max\left(drs(n),\ \max_{d\mid n,\ 2\le d<n}\left(drs(d)+mdrs\left(\frac{n}{d}\right)\right)\right)$$これは古典的な動的計画法/ふるい再帰です。 

すべての再帰項にはより小さな数が含まれるため、$n/d < n$、値を昇順に計算できます。 

---

 # 効率的なふるい戦略

 必要なものは次のとおりです。$$\sum_{n=2}^{999999} mdrs(n)$$すべての素朴な因数分解$n$遅すぎるでしょう。 

代わりに:

 1. 事前計算$drs(n)$みんなのために$n<10^6$。 
2. 初期化します。$$mdrs(n)=drs(n)$$1. すべての約数について$d$、更新を複数に伝播します。 

もし$n=d\cdot q$、 それから：$$mdrs(n)\ge drs(d)+mdrs(q)$$それで：```python
for d in 2..N:
    for q in 2..N/d:
        n = d*q
        mdrs[n] = max(mdrs[n], drs[d] + mdrs[q])
```これは除数ふるいのように動作し、十分な速度で実行されます。$10^6$。 

---

 # Pythonの実装```python
LIMIT = 10**6

# ---------------------------------------------------------
# Compute digital roots
# drs(n) = 1 + ((n - 1) % 9) for n > 0
# ---------------------------------------------------------

drs = [0] * LIMIT

for n in range(1, LIMIT):
    drs[n] = 1 + (n - 1) % 9

# ---------------------------------------------------------
# Initialize mdrs with the trivial factorization: n itself
# ---------------------------------------------------------

mdrs = drs[:]

# ---------------------------------------------------------
# Dynamic programming sieve
#
# If n = d * q, then:
# mdrs[n] >= drs[d] + mdrs[q]
# ---------------------------------------------------------

for d in range(2, LIMIT):
    dd = drs[d]

    max_q = (LIMIT - 1) // d

    for q in range(2, max_q + 1):
        n = d * q

        candidate = dd + mdrs[q]

        if candidate > mdrs[n]:
            mdrs[n] = candidate

# ---------------------------------------------------------
# Sum all mdrs values for 2 <= n < 10^6
# ---------------------------------------------------------

answer = sum(mdrs[2:])

print(answer)
```---

 ## デジタルルートテーブル```python

例:

 -$drs(8)=8$-$drs(24)=6$-$drs(999)=9$---

 ## 初期化中`mdrs`

```python
mdrs = drs[:]
```すべての数値には少なくとも自明な因数分解があります。$$n$$最初は:$$mdrs(n)\ge drs(n)$$---

 ## 除数 DP

 各約数について$d$、すべての倍数を繰り返します。```python
n = d * q
candidate = drs[d] + mdrs[q]
```これは、以下を取得することに相当します。$$n=d\times q$$そして、次の_best_因数分解を使用します$q$。 

なぜなら$q<n$、その値はすでにわかっています。
