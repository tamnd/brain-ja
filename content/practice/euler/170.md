 ## 解決策

 **答え:**`9857164023`整数乗数を次のようにします。$m$、他の整数を次のようにします。$a_1,a_2,\dots,a_k$と$k\ge2$。 

私たちは次のことを要求します:

 1. 入力の連結$$m\,a_1\,a_2\cdots a_k$$です$0$-に-$9$パンデジタルの 10 桁の番号。 
2. 製品の連結$$(m a_1)(m a_2)\cdots(m a_k)$$もです$0$-に-$9$パンデジタルの 10 桁の番号。 

私たちは可能な限り**最大**の連結積を求めます。 

---

 # 数学的分析

 積を連結して形成される、辞書編集上最大の 10 桁のパンデジタル番号が必要です。 

結果は数字を使ったパンデジタルなので$0$–$9$理想的には、最初の桁はできるだけ大きくする必要があります。$9$。 

ブルートフォース検索の空間は巨大に見えますが、いくつかの構造的な観察により、その空間は大幅に縮小されます。 

---

 ## 1. 連結製品の構造

 次のように仮定します。$$P = \text{concat}(m a_1, m a_2,\dots,m a_k)$$はターゲットのパンデジタル番号です。 

すべての数字なので、$0$–$9$に 1 回だけ表示されます$P$、合計桁数はちょうど 10 です。 

同様に、$$I = \text{concat}(m,a_1,\dots,a_k)$$10 桁のパンデジタルである必要もあります。 

したがって、からのすべての数字は、$0$に$9$入力中に 1 回だけ出現します。 

---

 ## 2. 重要な観察: 桁の分割

 数字の並べ替えを選択した場合$0$–$9$、それをいくつかの部分に分割することができます。$$m,\ a_1,\ a_2,\dots,a_k$$次に、次のように計算します。$$m a_1,\ m a_2,\dots,m a_k$$そしてそれらの連結が別のパンデジタル順列であるかどうかをテストします。 

これは、以下を検索することを提案します。 

- 数字の並べ替え、
 - ブロックに分割します。 

しかし$10! = 3,628,800$, そのため、剪定が必要になります。 

---

 ## 3. 出力の最大化

 連結された積は数値的に、つまり辞書順に比較されます。 

したがって:

 - 候補出力を降順で生成する必要があります。 
- 最初の有効な値で停止します。 

最初に入力を生成するのではなく、降順で _output_ 順列を生成する方がはるかに賢明です。 

---

 ## 4. 乗算器の再構築

 連結された積が次のようになると仮定します。$$P = p_1p_2\dots p_{10}$$仕切る$P$チャンクに分割:$$b_1,b_2,\dots,b_k$$それぞれどこで$b_i = m a_i$。 

それから$m$すべてのチャンクを分割する必要があります。 

したがって、次のようになります。$$m = \gcd(b_1,b_2,\dots,b_k)$$または少なくともその gcd の約数。 

これは非常に制限的なものになります。 

---

 ## 5. 効率的な検索戦略

 次のように進めます。 

1. 10 桁のパンデジタル番号を降順に列挙します。 
2. すべてのパーティションを少なくとも 2 つのチャンクに分割してみます。 
3. チャンクの gcd を計算します。 
4. 約数を列挙する$m>1$そのgcdの。 
5. 回復:$$a_i = b_i/m$$6. 連結しているかどうかを確認する$$m,a_1,\dots,a_k$$0 ～ 9 のパンデジタル文字列が生成されます。 

最初に見つかった有効な出力が最大値です。

 # Pythonの実装```python
from math import gcd
from itertools import permutations

DIGITS = "9876543210"

def is_pandigital_0_9(s):
    """Check whether s contains digits 0-9 exactly once."""
    return len(s) == 10 and set(s) == set("0123456789")

def divisors(n):
    """Return all divisors of n greater than 1."""
    ds = set()
    d = 2
    while d * d <= n:
        if n % d == 0:
            ds.add(d)
            ds.add(n // d)
        d += 1
    ds.add(n)
    return sorted(ds, reverse=True)

# Generate pandigital outputs in descending order
for perm in permutations(DIGITS):
    s = ''.join(perm)

    # Try all ways to partition into >=2 pieces
    # There are 2^9 possible cut patterns
    for mask in range(1, 1 << 9):

        parts = []
        start = 0

        for i in range(9):
            if mask & (1 << i):
                parts.append(int(s[start:i+1]))
                start = i + 1

        parts.append(int(s[start:]))

        # Need at least two multiplicands
        if len(parts) < 2:
            continue

        # Compute gcd of all chunks
        g = parts[0]
        for x in parts[1:]:
            g = gcd(g, x)

        if g <= 1:
            continue

        # Try divisors of gcd as multiplier
        for m in divisors(g):

            inputs = []
            ok = True

            for x in parts:
                if x % m != 0:
                    ok = False
                    break
                inputs.append(str(x // m))

            if not ok:
                continue

            candidate = str(m) + ''.join(inputs)

            if is_pandigital_0_9(candidate):
                print(s)
                raise SystemExit
```---
