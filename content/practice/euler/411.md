[プロジェクト オイラー問題 411](https://projecteuler.net/problem=411)

 ## 解決策

 **答え:**`9936352`させて$$P_i = \left(2^i \bmod n,\; 3^i \bmod n\right), \qquad 0 \le i \le 2n.$$重複を削除すると、これらが「ステーション」になります。 

からの最長パスが必要です$(0,0)$に$(n,n)$その座標は決して減少しません。 

同様に、すべての測点の中で、両方の座標が減少しないように順序付けできる最大のサブセットが必要です。 

---

 # 重要な数学的洞察

 すべての異なる駅を昇順で並べ替えるとします。$x$-座標 (そして次によって)$y$-座標）。 

この場合、有効な上り坂パスは、そのサブシーケンスに正確に対応します。$y$- 座標は減少しません。 

したがって：$$S(n)=\text{length of the Longest Nondecreasing Subsequence (LNDS)}$$の$y$-ステーションを並べ替えた後の値$x$。 

したがって、問題は次のようになります。 

1. すべての個別のポイントを生成する$$(2^i \bmod n,\; 3^i \bmod n).$$2. 辞書順に並べ替えます。 
3. のLANDを計算します。$y$-コーディネート。 

標準的な忍耐力ソート LIS アルゴリズムは、これを次のように計算します。$O(m\log m)$、 どこ$m$は個別のステーションの数です。 

平等だから$y$- 値は許可されます (減少ではなく、厳密には増加ではありません)。使用する必要があります。`upper_bound`、 ない`lower_bound`。 

---

 # Pythonの実装```python
from bisect import bisect_right

def S(n):
    # Generate all distinct stations
    seen = set()
    points = []

    x = 1 % n
    y = 1 % n

    while (x, y) not in seen:
        seen.add((x, y))
        points.append((x, y))

        x = (2 * x) % n
        y = (3 * y) % n

    # Sort by x, then y
    points.sort()

    # Longest nondecreasing subsequence on y
    lis = []

    for _, yy in points:
        pos = bisect_right(lis, yy)

        if pos == len(lis):
            lis.append(yy)
        else:
            lis[pos] = yy

    return len(lis)

total = 0

for k in range(1, 31):
    total += S(k ** 5)

print(total)
```---

 # コードのチュートリアル

 ### ステーションの生成```python
x = 1 % n
y = 1 % n
```これらは以下に対応します$i=0$:$$(2^0 \bmod n,\;3^0 \bmod n)=(1,1).$$各反復では 2 および 3 のモジュロを乗算します。$n$:```python
x = (2 * x) % n
y = (3 * y) % n
```シーケンスは周期的であるため、ペアが繰り返されると停止します。 

---

 ### ポイントの整理```python
points.sort()
```これは辞書順に並べ替えます$x$、 それから$y$。 

上り坂の道はすべてこの順序を尊重する必要があります。 

---

 ### 最長の非減少サブシーケンス

 ここで必要なのは、最長の非減少シーケンスだけです。$y$-価値観。 

忍耐力を分類するテクニックでは、次のことが維持されます。```python
lis[i]
```= 長さが減少しない部分列の可能な最小の末尾$i+1$。 

私たちは以下を使用します:```python
bisect_right
```等しいから$y$-値は許可されます。
