[プロジェクト オイラー問題 115](https://projecteuler.net/problem=115)

 ## 解決策

 **答え:**`168`させて$F(m,n)$ある長さの行を埋める方法の数を示します$n$使用:

 - 長さの黒い正方形$1$、
 - 少なくとも長さの赤いブロック$m$、
 - 任意の 2 つの赤いブロックが少なくとも 1 つの黒い四角形で区切られているという制限付き。 

私たちは最小限のものを求めます$n$そのような$$F(50,n) > 10^6.$$---

 # 数学的分析

 の漸化式を導出します。$F(m,n)$。 

定義する：$$F(n) := F(m,n)$$固定用$m$。 

---

 ## ステップ 1: 最初の四角形で具材を分類する

 ある長さの行を考えてみましょう$n$。 

### ケース 1 — 最初の正方形は黒です

 それから残りは$n-1$正方形は有効な方法で塗りつぶすことができます。$$F(n-1)$$可能性。 

---

 ### ケース 2 — 最初のブロックは赤です

 最初の赤いブロックに長さがあると仮定します。$k$、 どこ$$k \ge m.$$2 つのサブケースが発生します。 

---

 ### サブケース 2a — 赤いブロックが最後に到達

 これは次のような場合に起こります。$k=n$。 

それぞれの配列に対して 1 つの配列が存在します。$k$。 

---

 ### サブケース 2b — 残りのスペースがあります

 赤いブロックが行を終了しない場合は、その後に少なくとも 1 つの黒い四角形が続く必要があります。 

したがって、配置した後:

 - 一定の長さの赤いブロック$k$、
 - 必須の黒い四角形 1 つ、

 私たちは持っています$$n-k-1$$残りの正方形。 

それらは記入できます$F(n-k-1)$方法。 

したがって、それぞれについて$k$、$$F(n-k-1)$$貢献。 

---

 ## ステップ 2: 完全な再発

 完全に黒の配置を含めると、次の結果が得られます。$$F(n) = F(n-1) + \sum_{k=m}^{n} 1 + \sum_{k=m}^{n-1} F(n-k-1).$$「赤いブロックが最後まで到達」の場合を均一に処理することで、よりクリーンな配合が得られます。 

セット：$$F(t)=1 \quad \text{for } t<0.$$それから：$$F(n) = F(n-1) + \sum_{k=m}^{n} F(n-k-1).$$同様に、$$\boxed{ F(n)=F(n-1)+\sum_{j=0}^{n-m} F(j-1) }$$基本値付き$$F(0)=1.$$---

 ## ステップ 3: 動的プログラミングのアプローチ

 最初のものだけが必要なので、$n$どこ$F(50,n)>10^6$、動的プログラミングが理想的です。 

値を段階的に計算します。 

- から始める$F(0)=1$、
 - 値が 100 万を超えるまで上向きに構築します。 

The growth is fast enough that only modest$n$が必要です。 

---

 # Pythonの実装```python
def fill_count(m, limit):
    """
    Return the smallest n such that F(m, n) > limit.
    """

    # dp[n] = F(m, n)
    dp = [1]  # F(0) = 1

    n = 0

    while True:
        n += 1

        # Case 1: first square is black
        total = dp[n - 1]

        # Case 2: first block is red
        for k in range(m, n + 1):

            remaining = n - k - 1

            if remaining >= 0:
                total += dp[remaining]
            else:
                # red block reaches the end
                total += 1

        dp.append(total)

        if total > limit:
            return n

answer = fill_count(50, 1_000_000)
print(answer)
```---

 # サンプルの検証

 のために$m=3$:

 -$F(3,29)=673135$-$F(3,30)=1089155$だから少なくとも$n$100万を超える場合は次のとおりです。$$n=30.$$のために$m=10$:

 -$F(10,56)=880711$-$F(10,57)=1148904$だから少なくとも$n$は：$$n=57.$$再帰では両方の値が正確に再現されます。 

同じアルゴリズムを実行すると、$m=50$与える:$$F(50,168)=1053389 > 10^6,$$その間$$F(50,167)=978181 < 10^6.$$したがって、最も有効ではない$n$は$168$。
