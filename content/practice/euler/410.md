 ## 解決策

 **答え:**`799999783589946560`ラインを通します$P(a,b)$そして$Q(-a,c)$に接する$$x^2+y^2=r^2.$$すべての整数の 4 倍を数えたい$(r,a,b,c)$と$$0<r\le R,\qquad 0<a\le X.$$最終的に必要な値は、$$F(10^8,10^9)+F(10^9,10^8).$$---

 # 1. 幾何学的および数論的分析

 通るライン$P(a,b)$そして$Q(-a,c)$方程式があります$$(c-b)x+2ay-a(b+c)=0.$$一行$Ax+By+C=0$円に接しています$x^2+y^2=r^2$原点からの距離が等しい場合$r$:$$\frac{|C|}{\sqrt{A^2+B^2}}=r.$$代入:$$\frac{|a(b+c)|}{\sqrt{(c-b)^2+4a^2}}=r.$$二乗：$$a^2(b+c)^2=r^2\big((c-b)^2+4a^2\big).$$導入$$u=b+c,\qquad v=c-b.$$それから：$$a^2u^2=r^2(v^2+4a^2).$$させて$$g=\gcd(a,r),\qquad a=gA,\quad r=gR,\quad \gcd(A,R)=1.$$で割った後$g^2$、$$A^2u^2=R^2(v^2+4g^2A^2).$$なぜなら$\gcd(A,R)=1$、私たちは持っている必要があります$R\mid u$。 書く$$u=Rk.$$それから$$A^2k^2=v^2+4g^2A^2.$$また$\gcd(A,R)=1$暗示する$A\mid v$。 書く$$v=A\ell.$$今：$$k^2-\ell^2=4g^2.$$要素：$$(k-\ell)(k+\ell)=4g^2.$$させて$$k-\ell=2s,\qquad k+\ell=2t,$$となることによって$$st=g^2.$$すべての順序付き因数分解$g^2=st$解決策を生み出します。 

パリティ制約により、次の場合にカウントがわずかに減少します。$a$そして$r$異なる 2 進数の評価を持ちます。 

パリティケースを処理した後、固定ペアの解の数は$(r,a)$は$$N(r,a)= \begin{cases} 2\,\tau(g^2), & v_2(r)=v_2(a),\\[1ex] 2\,\tau\!\left(\left(\dfrac g2\right)^2\right), & v_2(r)\ne v_2(a),\ g\text{ even},\\[2ex] 2\,\tau(g^2), & g\text{ odd}, \end{cases}$$どこ$g=\gcd(r,a)$、$\tau(n)$は除数をカウントする関数であり、$v_2$は 2 の指数です。 

これにより、非常にコンパクトな要約形式に簡略化されます。$$F(R,X) = 2\sum_{n\le \min(R,X)} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor,$$どこ$\omega(n)$は、次の異なる素因数の数です。$n$。 

算術関数$$f(n)=2^{\omega(n)}$$乗法的でふるい分けが簡単です。 

---

 #2. 効率的なアルゴリズム

 計算しなければなりません$$\sum_{n\le N} 2^{\omega(n)} \left\lfloor \frac{R}{n}\right\rfloor \left\lfloor \frac{X}{n}\right\rfloor$$のために$N=\min(R,X)$。 

標準的な除数合計のトリックを使用します。 

- の値$\lfloor R/n\rfloor$そして$\lfloor X/n\rfloor$間隔を一定に保ち、
 - プレフィックスの合計を事前計算します$2^{\omega(n)}$、
 - プロセス間隔$O(\sqrt N)$。 

---

 #3. Pythonの実装```python
from math import isqrt

def solve(R, X):
    N = min(R, X)

    # sieve for omega(n)
    omega = [0] * (N + 1)

    for p in range(2, N + 1):
        if omega[p] == 0:          # prime
            for k in range(p, N + 1, p):
                omega[k] += 1

    # f(n) = 2^omega(n)
    f = [1] * (N + 1)
    for n in range(1, N + 1):
        f[n] = 1 << omega[n]

    # prefix sums
    pref = [0] * (N + 1)
    for i in range(1, N + 1):
        pref[i] = pref[i - 1] + f[i]

    ans = 0
    i = 1

    while i <= N:
        vr = R // i
        vx = X // i

        j = min(R // vr, X // vx, N)

        block = pref[j] - pref[i - 1]

        ans += block * vr * vx

        i = j + 1

    return 2 * ans

answer = solve(10**8, 10**9) + solve(10**9, 10**8)

print(answer)
```---

 #4. コードのチュートリアル

 ### ふるい部```python
omega = [0] * (N + 1)
```各整数の異なる素因数の数を格納します。 

すべての素数について$p$、すべての倍数を増分します。```python
for k in range(p, N + 1, p):
    omega[k] += 1
```それから：```python
f[n] = 1 << omega[n]
```計算する$$f(n)=2^{\omega(n)}.$$---

 ### プレフィックスの合計```python
pref[i] = pref[i - 1] + f[i]
```高速範囲合計が可能$f(n)$。 

---

 ### 双曲線法

 価値観$$\left\lfloor \frac{R}{n}\right\rfloor, \qquad \left\lfloor \frac{X}{n}\right\rfloor$$長い間隔で一定を保ちます。 

したがって、すべてを繰り返すのではなく、$n$、ブロックを処理します。```python
j = min(R // vr, X // vx, N)
```そしてブロック全体の寄与を一度に追加します。
