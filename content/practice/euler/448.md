[プロジェクト オイラー問題 448](https://projecteuler.net/problem=448)

 ## 解決策

 **答え:**`106467648`させて$$A(n)=\frac1n\sum_{i=1}^n \operatorname{lcm}(n,i), \qquad S(n)=\sum_{k=1}^n A(k).$$必要です$$S(99999999019)\pmod{999999017}.$$---

 #1. 数学的分析

 アイデンティティから始める$$\operatorname{lcm}(a,b)=\frac{ab}{\gcd(a,b)}.$$したがって$$A(n) = \frac1n \sum_{i=1}^n \frac{ni}{\gcd(n,i)} = \sum_{i=1}^n \frac{i}{\gcd(n,i)}.$$---

 ## ステップ 1: gcd によるグループ化

 しましょう$$d=\gcd(n,i).$$書く$$i=d m,\qquad n=d t,$$と$\gcd(m,t)=1$。 

それから$$\frac{i}{\gcd(n,i)}=\frac{dm}{d}=m.$$したがって、$$A(n) = \sum_{d\mid n} \sum_{\substack{1\le m\le n/d\\ \gcd(m,n/d)=1}} m.$$させて$t=n/d$。 それから$$A(n) = \sum_{t\mid n} \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$---

 ## ステップ 2: 還元された残基の合計

 古典的な結果:

 のために$t>1$、$$\sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m = \frac{t\varphi(t)}2.$$(残基はペアで存在します$m$そして$t-m$。）

のために$t=1$、合計は$1$。 

定義する$$f(t)= \sum_{\substack{1\le m\le t\\ \gcd(m,t)=1}} m.$$それから$$f(1)=1,\qquad f(t)=\frac{t\varphi(t)}2 \quad (t>1).$$それで$$A(n)=\sum_{d\mid n} f(d).$$したがって$$S(N) = \sum_{n\le N}\sum_{d\mid n} f(d).$$順序を入れ替えます:$$S(N) = \sum_{d\le N} f(d)\left\lfloor \frac{N}{d}\right\rfloor.$$代わりの$f(d)$:$$S(N) = 1\cdot N + \frac12 \sum_{d=2}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$同様に、$$S(N) = \frac12 \left( N+ \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor \right).$$したがって、問題全体はコンピューティングに帰着します$$F(N)=\sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$---

 #2. 高速な合計

 必要です$$H(n)=\sum_{k\le n} k\varphi(k).$$そうすれば評価できる$F(N)$除数のグループ化を使用する:$$F(N) = \sum_{d=1}^N d\varphi(d)\left\lfloor \frac{N}{d}\right\rfloor.$$の値$\left\lfloor N/d\right\rfloor$間隔は一定です:$$\left\lfloor \frac{N}{d}\right\rfloor = q$$のために$$d\in[L,R].$$したがって、$$F(N) = \sum q\,(H(R)-H(L-1)).$$これにより、$O(\sqrt N)$アルゴリズム。 

---

 ## ステップ 3: コンピューティング$H(n)$アイデンティティを利用する$$\sum_{d\mid n}\varphi(d)=n.$$乗算$n$、$$\sum_{d\mid n} d\varphi(d)$$は再帰化につながるディリクレ畳み込み構造を持っています$$H(n) = \sum_{k=1}^n k^2 - \sum_{l=2}^n \left(\sum_{i=l}^r i\right) H\!\left(\left\lfloor\frac nl\right\rfloor\right).$$等しい商をグループ化すると、$O(\sqrt n)$メモ化された再帰。 

---

 #3. Pythonの実装```python
MOD = 999999017
N = 99999999019

INV2 = pow(2, MOD - 2, MOD)
INV6 = pow(6, MOD - 2, MOD)

# Sieve limit
M = 20_000_000

# ------------------------------------------------------------
# Euler phi sieve
# ------------------------------------------------------------

phi = list(range(M + 1))

for p in range(2, M + 1):
    if phi[p] == p:          # p is prime
        for k in range(p, M + 1, p):
            phi[k] -= phi[k] // p

# ------------------------------------------------------------
# Prefix sums:
# H(n) = sum_{k<=n} k * phi(k)
# ------------------------------------------------------------

prefix = [0] * (M + 1)

for i in range(1, M + 1):
    prefix[i] = (prefix[i - 1] + i * phi[i]) % MOD

# ------------------------------------------------------------
# Sum of squares:
# 1^2 + 2^2 + ... + n^2
# ------------------------------------------------------------

def sum_sq(n):
    n %= MOD
    return n * (n + 1) % MOD * (2 * n + 1) % MOD * INV6 % MOD

# ------------------------------------------------------------
# Memoized computation of H(n)
# ------------------------------------------------------------

memo = {}

def H(n):
    if n <= M:
        return prefix[n]

    if n in memo:
        return memo[n]

    ans = sum_sq(n)

    l = 2
    while l <= n:
        q = n // l
        r = n // q

        # sum_{i=l}^r i
        block_sum = (l + r) % MOD
        block_sum = block_sum * ((r - l + 1) % MOD) % MOD
        block_sum = block_sum * INV2 % MOD

        ans -= block_sum * H(q)
        ans %= MOD

        l = r + 1

    memo[n] = ans
    return ans

# ------------------------------------------------------------
# Compute:
# F(N) = sum d*phi(d)*floor(N/d)
# using quotient grouping
# ------------------------------------------------------------

def solve(N):
    total = 0

    l = 1
    while l <= N:
        q = N // l
        r = N // q

        total += q * (H(r) - H(l - 1))
        total %= MOD

        l = r + 1

    # S(N) = (N + F(N)) / 2
    return ((total + N) % MOD) * INV2 % MOD

print(solve(N))
```---

 #4. コードのチュートリアル

 ### ファイふるい```python
phi = list(range(M + 1))
```初期化します$\varphi(n)=n$。 

すべての素数について$p$、```python
phi[k] -= phi[k] // p
```当てはまる$$\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).$$---

 ### プレフィックスの合計```python
prefix[i] = prefix[i - 1] + i * phi[i]
```店舗$$H(i)=\sum_{k\le i} k\varphi(k).$$---

 ### 再帰的$H(n)$再帰では、次の大きな値が計算されます。$H(n)$およそで$O(\sqrt n)$商グループ化を使用した時間。 

メモ化により再計算が回避されます。 

---

 ### Final summation

 The loop```python
q = N // l
r = N // q
```同じ商を持つすべてのインデックスをグループ化します。 

これにより、複雑さが軽減されます。$O(N)$おおよそに$O(\sqrt N)$。
