[プロジェクト オイラー問題 948](https://projecteuler.net/problem=948)

 ## 解決策

 **答え:**`1033654680825334184`させて

-$L(w)$: 単語では左が勝ちます$w$左が先に動いたとき。 
-$R(w)$: 言葉の上では正しい勝ち$w$右が先に動いたとき。 

一言$w$、$$L(w)=\exists \text{ proper suffix } s \text{ of } w \text{ such that } \neg R(s),$$Left は空ではない左接頭辞を削除し、接尾辞を残すためです。 

同様に、$$R(w)=\exists \text{ proper prefix } p \text{ of } w \text{ such that } \neg L(p).$$番号が欲しいのです$F(n)$長い単語の$n$どちらも$L(w)$そして$R(w)$本当です。 

負けているポジションを注意深く誘導/分類することで、クローズドフォームが得られます。$$F(n)=2^n-\binom{n}{\lfloor n/2\rfloor}-C_{\lfloor (n-1)/2\rfloor},$$どこ$$C_k=\frac1{k+1}\binom{2k}{k}$$です$k$-番目のカタルーニャ語番号。 

チェック:

 -$F(3)=8-3-1=4$-$F(8)=256-70-5=181$どちらもステートメントと一致します。 

のために$n=60$:$$F(60)=2^{60}-\binom{60}{30}-C_{29}.$$Python コード:```python
from math import comb

n = 60
catalan_29 = comb(58, 29) // 30

F60 = 2**60 - comb(60, 30) - catalan_29
print(F60)
```これは次のように評価されます。$$1033654680825334184$$**答え: 1033654680825334184**
