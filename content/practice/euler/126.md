[プロジェクト オイラー問題 126](https://projecteuler.net/problem=126)

 ## 解決策

 **答え:**`18522`直方体の寸法を次のようにします$a \times b \times c$と$a \ge b \ge c \ge 1$、そしてさせてください$L_k(a,b,c)$内の立方体の数を示します。$k$直方体を囲む第 層。 

私たちは最小限のものを見つけるように求められています$n$まさにそのようなこと$1000$個別の直方体/レイヤーの使用$n$立方体。 

---

 #1. 数学的分析

 ## 最初の層

 直方体の場合$a\times b\times c$、最初のレイヤーは目に見えるすべての面をカバーします。 

固体直方体には表面積があります$$2(ab+bc+ca)$$したがって、最初の層には次のことが必要です$$L_1 = 2(ab+bc+ca)$$立方体。 

例：$$3\times2\times1$$与える$$2(3\cdot2+2\cdot1+3\cdot1)=2(6+2+3)=22$$問題文と一致します。 

---

 ## 上位層

 別のレイヤーを追加すると、次のようになります。 

- 露出したすべての顔が拡大し、
 - エッジは直線的な成長に貢献し、
 - コーナーは追加の立方体に貢献します。 

標準的な導出では次のようになります。$$L_k(a,b,c) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$のために$k\ge1$。 

---

 ## 式を検証する

 のために$3\times2\times1$:

 ### 最初の層 ($k=1$）$$22$$### 2 番目の層 ($k=2$）$$22 + 4(1)(3+2+1)+4(1)(0) =22+24 =46$$### 第 3 層 ($k=3$）$$22+4(2)(6)+4(2)(1) =22+48+8 =78$$### 第 4 層 ($k=4$）$$22+4(3)(6)+4(3)(2) =22+72+24 =118$$すべて問題文と一致します。 

---

 # 表現のカウント

 私たちは定義します$$C(n)$$トリプルの数として$(a,b,c,k)$正確に生産する$n$立方体:$$n = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$最小のものを見つけなければなりません$n$そのような$$C(n)=1000.$$---

 # 検索の境界を設定する

 以下について体系的に検索します。 

-$a \ge b \ge c \ge 1$- レイヤー番号$k\ge1$十分に大きな制限まで、考えられるすべてのレイヤー サイズを計算します。 

プロジェクト オイラーの問題 126 には、以下のような答えがあることが知られています。$30000$、したがって、制限は次のとおりです$50000$安全以上です。 

可能な最小のレイヤーがすでに制限を超えたら、ループを停止します。 

---

 #2. Pythonの実装```python
from collections import defaultdict

LIMIT = 50000

# count[n] = number of cuboids/layers producing n cubes
count = defaultdict(int)

# Enumerate cuboid dimensions with a >= b >= c >= 1
for a in range(1, LIMIT):
    
    # Minimum layer for b=c=1
    if 2 * (a + 1 + a) > LIMIT:
        break

    for b in range(1, a + 1):

        # Minimum layer for c=1
        first = 2 * (a*b + a + b)
        if first > LIMIT:
            break

        for c in range(1, b + 1):

            # First layer
            base = 2 * (a*b + a*c + b*c)

            if base > LIMIT:
                break

            k = 1

            while True:
                n = (
                    base
                    + 4*(k-1)*(a+b+c)
                    + 4*(k-1)*(k-2)
                )

                if n > LIMIT:
                    break

                count[n] += 1
                k += 1

# Find smallest n with exactly 1000 representations
answer = min(n for n in count if count[n] == 1000)

print(answer)
```---

 #3. コードのチュートリアル

 ## データ構造```python
count = defaultdict(int)
```この店舗は$C(n)$、レイヤーサイズを取得する方法の数$n$。 

---

 ## 次元の列挙```python
for a in range(1, LIMIT):
```直方体の次元を非増加順に反復処理します。$$a \ge b \ge c$$直方体の重複を避けるため。 

---

 ## 最初のレイヤーのバインド```python
first = 2 * (a*b + a + b)
```これは固定の可能な最小のレイヤーです$a,b$いつ$c=1$。 

それを超えた場合はさらに大きく$c$もします。 

---

 ## レイヤーの式```python
n = (
    base
    + 4*(k-1)*(a+b+c)
    + 4*(k-1)*(k-2)
)
```これは直接実装します$$L_k(a,b,c) = 2(ab+bc+ca) + 4(k-1)(a+b+c) + 4(k-1)(k-2)$$---

 ## 出現回数をカウントする```python
count[n] += 1
```それぞれ有効$(a,b,c,k)$1 つの表現に貢献します。 

---

 ## 最終抽出```python
answer = min(n for n in count if count[n] == 1000)
```最小のものを探します$n$まさに$1000$表現。
