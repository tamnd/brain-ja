 ## 解決策

 **答え:**`21417`計算する必要があります$E(10000)$整数のとき$1 \le n \le 100000$次の基準で並べ替えられます:

 1.増加$\operatorname{rad}(n)$、
 2. 増やすことで関係を断ち切る$n$。 

根号は、次の _distinct_ 素因数の積として定義されます。$n$。 

例えば：

-$504 = 2^3 \cdot 3^2 \cdot 7$、
- それで$$\operatorname{rad}(504)=2\cdot3\cdot7=42.$$---

 # 数学的分析

 直接的な定義では、次の 2 つのタスクが示唆されます。 

1. コンピューティング$\operatorname{rad}(n)$すべての人にとって効率的に$n \le 100000$、
 2. ペアを並べ替える$(\operatorname{rad}(n), n)$。 

すべての数値を個別に単純に因数分解することもできますが、ふるいのようなアプローチを使用すると、はるかに優れた結果を得ることができます。 

## 重要な所見

 もし$p$が素数の場合、次のすべての倍数$p$もっている$p$明確な素因数として。 

したがって、次のように初期化できます。$$\operatorname{rad}(n)=1$$みんなのために$n$、そしてすべての素数に対して$p$:

 - 乗算する$\operatorname{rad}(k)$による$p$倍数ごとに$k$の$p$。 

これはエラトステネスのふるいに似ています。 

---

 ## 例

 以下から始めます:$$\operatorname{rad}(1)=\operatorname{rad}(2)=\cdots=1.$$プロセスプライム$2$:

 - 2 の倍数をすべて 2 で乗算します。 

今:$$\operatorname{rad}(2)=2,\quad \operatorname{rad}(4)=2,\quad \operatorname{rad}(6)=2,\dots$$プロセスプライム$3$:

 - multiply all multiples of 3 by 3.

 次に:$$\operatorname{rad}(6)=2\cdot3=6,$$

$$\operatorname{rad}(9)=3.$$等々。 

複雑さは本質的に次のとおりです。$$O(n \log\log n),$$これは非常に高速です$100000$。 

---

 # Pythonの実装```python
LIMIT = 100000

# rad[n] will store rad(n)
rad = [1] * (LIMIT + 1)

# Sieve to compute radicals
for p in range(2, LIMIT + 1):
    # If rad[p] is still 1, then p is prime
    if rad[p] == 1:
        # Multiply p into every multiple of p
        for multiple in range(p, LIMIT + 1, p):
            rad[multiple] *= p

# Build list of (rad(n), n)
values = [(rad[n], n) for n in range(1, LIMIT + 1)]

# Sort by rad(n), then by n automatically
values.sort()

# E(10000) is the 10000th element (1-indexed)
answer = values[9999][1]

print(answer)
```---

 ## ステップ 3: 素数をすべての倍数に乗算します```python

    rad[multiple] *= p
```各素数はすべての倍数に 1 回だけ寄与します。これがまさに根号の定義です。 

例:

 - いつ$p=2$、$12$2を掛けて、
 - いつ$p=3$、$12$3を掛けて、

したがって、次のようになります。$$\operatorname{rad}(12)=2\cdot3=6.$$---
