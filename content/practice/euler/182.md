[プロジェクト オイラー問題 182](https://projecteuler.net/problem=182)

 ## 解決策

 **答え:**`399788195976`させて$$n=pq,\qquad p=1009,\quad q=3643,$$それで$$\phi=(p-1)(q-1)=1008\cdot 3642.$$すべての有効な RSA 指数を求めます$e$そのような$$1<e<\phi,\qquad \gcd(e,\phi)=1,$$隠蔽されていないメッセージの数は最小限です。 

---

 #1. 数学的分析

 メッセージ$m$隠蔽されていないとき$$m^e \equiv m \pmod n.$$以来$n=pq$中国の剰余定理により、これは別個の素数を持つものと等価です。$$m^e \equiv m \pmod p, \qquad m^e \equiv m \pmod q.$$として書き換えます$$m(m^{e-1}-1)\equiv 0 \pmod p.$$フィールドを越えて$\mathbb F_p$:

 -$m=0$それは常に解決策であり、
 - のために$m\neq0$、必要です$$m^{e-1}\equiv1\pmod p.$$乗法群モジュロ$p$秩序がある$p-1$、したがって、解の数は$$\gcd(e-1,p-1).$$含む$m=0$、解の総数の剰余$p$は$$1+\gcd(e-1,p-1).$$同様にモジュロ$q$、番号は$$1+\gcd(e-1,q-1).$$したがって、隠蔽されていないメッセージの総数を法的に計算します。$n$は$$U(e)=\bigl(1+\gcd(e-1,p-1)\bigr)       \bigl(1+\gcd(e-1,q-1)\bigr).$$したがって、素数については次のようになります。$$U(e)=\bigl(1+\gcd(e-1,1008)\bigr)       \bigl(1+\gcd(e-1,3642)\bigr).$$---

 ## 隠蔽されていないメッセージの数を最小限に抑える

 以来$e$満たさなければなりません$\gcd(e,\phi)=1$、$e$奇妙だから$\phi$は均等です。 

したがって、$e-1$は偶数なので、$$\gcd(e-1,1008)\ge2, \qquad \gcd(e-1,3642)\ge2.$$したがって、可能な最小値は$U(e)$は$$(1+2)(1+2)=9.$$だから必要なのです$$\gcd(e-1,1008)=2, \qquad \gcd(e-1,3642)=2.$$係数を因数分解します。$$1008=2^4\cdot 3^2\cdot 7,$$

$$3642=2\cdot 3\cdot 607.$$したがって$e-1$必須:

 - で割り切れる$2$、
 - で割り切れない$3$、
 - で割り切れない$7$、
 - で割り切れない$607$。 

また$e$と互いに素でなければならない$$\phi=1008\cdot3642 =2^5\cdot3^4\cdot7\cdot607.$$したがって$e$さらに次で割り切れない必要があります$3,7,607$。 

以来$e$奇数です、自動的に$e-1$～の因子がちょうど 1 つあります$2$と共通して$3642$奇数の共通因数が発生しない場合に限ります。 

したがって、有効な$e$まさに互いに素な関係です$\phi$誰のために$$e\not\equiv1\pmod3, \qquad e\not\equiv1\pmod7, \qquad e\not\equiv1\pmod{607}.$$なぜ？ 

なぜなら：

-$3\mid(e-1)\iff e\equiv1\pmod3$、
 -$7\mid(e-1)\iff e\equiv1\pmod7$、
 -$607\mid(e-1)\iff e\equiv1\pmod{607}$。 

しかし$e$すでにありえない$0$これらの素数を法として計算します。$\gcd(e,\phi)=1$。 

したがって、各素因数について$r\in\{3,7,607\}$、と互いに素な残基間で$r$、残留物を除外する必要があります$1$。 

つまり、次のようになります。 

- モジュロ$3$:$1$許容残留物、
 - モジュロ$7$:$5$許容される残留物、
 - モジュロ$607$:$605$許容される残留物。 

の力$2$すべての奇数剰余をモジュロに寄与します$32$、つまり$16$選択肢。 

したがって、最小化指数の数は次のようになります。$$16\cdot1\cdot5\cdot605=48400.$$ここで、そのようなすべての**合計**が必要になります$e$。 

---

 #2. 合計の計算

 有効な指数はモジュロ対称サブセットを形成します$$\phi=3671136.$$有効なすべての$e$、番号$$\phi-e$$も有効です:

 - それは奇妙です、
 - と互いに素である$\phi$、
 - そして禁止された合同を保存します。 

したがって、合計する有効な指数のペアは$\phi$。 

あるので$48400$このような指数の合計は、$$\frac{48400}{2}\phi = 24200\cdot 3671136.$$計算:$$3671136\cdot24200 = 88854291200.$$---

 #3. Pythonの実装```python
from math import gcd

p = 1009
q = 3643

phi = (p - 1) * (q - 1)

best = None
total = 0

for e in range(2, phi):
    # RSA validity condition
    if gcd(e, phi) != 1:
        continue

    # number of unconcealed messages
    u = (1 + gcd(e - 1, p - 1)) * \
        (1 + gcd(e - 1, q - 1))

    if best is None or u < best:
        best = u
        total = e
    elif u == best:
        total += e

print(best)
print(total)
```---

 ## 小規模な例の検証

 ステートメントの例の場合:$$p=19,\quad q=37,\quad e=181.$$得ます$$\gcd(180,18)=18, \qquad \gcd(180,36)=36.$$したがって、$$U(181)=(1+18)(1+36)=19\cdot37=703.$$これはすべてのメッセージを法的に表したものに等しい$703$、まさに説明どおりです。
