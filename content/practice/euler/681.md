[プロジェクト オイラー問題 681](https://projecteuler.net/problem=681)

 ## 解決策

 **答え:**`2611227421428`一辺の長さがある四角形の場合$a,b,c,d$、最大の可能な面積は、周期的な四辺形によって達成されます。 ブラフマグプタの公式によれば、$$K^2=(s-a)(s-b)(s-c)(s-d), \qquad s=\frac{a+b+c+d}{2}.$$したがって、問題はこの式の整数解を調べることになります。 

定義する$$U=s-a,\quad V=s-b,\quad W=s-c,\quad T=s-d.$$それから$$U\ge V\ge W\ge T>0$$なぜなら$a\le b\le c\le d$、 そして$$a=s-U,\ b=s-V,\ c=s-W,\ d=s-T.$$また、$$U+V+W+T=2s=a+b+c+d.$$最大面積は次のようになります。$K^2=UVWT$したがって、$K$整数である場合$UVWT$は完全な正方形です。 

辺の長さは整数です。$U,V,W,T$すべて同じパリティを持ち、同等です$$U+V+W+T \equiv 0 \pmod 2.$$ついに、$a>0$与える$$s-U>0 \iff U<V+W+T.$$したがって、順序付けられた 4 倍数をすべて列挙する必要があります$$U\ge V\ge W\ge T>0$$そのような

 1.$UVWT=k^2$一部の人にとっては$1\le k\le n$、
 2.$U<V+W+T$、
 3.$U+V+W+T$は均等です。 

有効なクアドルプルごとに、$SP(n)$は$$U+V+W+T.$$---

 ## 効率的な列挙

 修正$k\le n$。 約数を列挙します$k^2$。 

させて$$UVWT=k^2.$$選ぶ$T\mid k^2$、 それから$W\mid k^2/T$、定義します$$R=\frac{k^2}{TW}=UV.$$今$V$分けなければなりません$R$、 そして$$U=\frac{R}{V}.$$注文条件$U\ge V$暗示する$$V\le \sqrt R.$$陽性条件はこうなる$$\frac{R}{V}<V+W+T.$$これにより、下限が与えられます$V$、検索を大幅に削減します。 

結果として得られるアルゴリズムは、快適に高速に実行されます。$n=10^6$。

 # Pythonの実装```python
from math import isqrt
from bisect import bisect_left

def build_spf(limit):
    """Smallest prime factor sieve."""
    spf = list(range(limit + 1))

    for i in range(2, isqrt(limit) + 1):
        if spf[i] == i:
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i

    return spf

def factorize(n, spf):
    """Prime factorization of n."""
    out = []

    while n > 1:
        p = spf[n]
        e = 0

        while n % p == 0:
            n //= p
            e += 1

        out.append((p, e))

    return out

def divisors_of_k2_upto_k(k, fac):
    """
    Generate all divisors d of k^2 with d <= k.
    """

    divs = [1]

    for p, e in fac:
        current = divs[:]

        pe = 1
        for _ in range(2 * e):
            pe *= p

            for d in current:
                v = d * pe
                if v <= k:
                    divs.append(v)

    divs.sort()
    return divs

def SP(n):
    spf = build_spf(n)

    total = 0

    for k in range(1, n + 1):

        k2 = k * k

        fac = factorize(k, spf)

        divs = divisors_of_k2_upto_k(k, fac)

        dlen = len(divs)

        for ti, T in enumerate(divs):

            k2_div_T = k2 // T

            for wi in range(ti, dlen):

                W = divs[wi]

                if W > k2_div_T:
                    break

                if k2_div_T % W:
                    continue

                R = k2_div_T // W   # R = U*V

                vmax = isqrt(R)

                if vmax < W:
                    continue

                S = W + T

                # Need:
                # R/V < V + S
                #
                # Solve:
                # V^2 + S*V - R > 0

                disc = S * S + 4 * R
                root = isqrt(disc)

                vmin = (root - S) // 2 + 1

                if vmin < W:
                    vmin = W

                if vmin > vmax:
                    continue

                lo = bisect_left(divs, vmin)

                for vi in range(lo, dlen):

                    V = divs[vi]

                    if V > vmax:
                        break

                    if R % V:
                        continue

                    U = R // V

                    # positivity condition
                    if U >= V + S:
                        continue

                    perimeter = U + V + S

                    # all U,V,W,T same parity
                    if perimeter % 2 == 0:
                        total += perimeter

    return total

# verification
assert SP(10) == 186
assert SP(100) == 23238

print(SP(1_000_000))
```---

 # コードのチュートリアル

 ### 1. 幾何学問題を算術問題に変換する

 Brahmagupta の公式を使用して、辺を次のように置き換えます。$$(U,V,W,T)=(s-a,s-b,s-c,s-d).$$次に:

 - エリア条件は$UVWT=k^2$、
 ・ご注文は$U\ge V\ge W\ge T$、
 - サイドポジティブになる$U<V+W+T$、
 - 一体性は全周均等になります。 

---

 ### 2. 約数を列挙する

 それぞれについて$k\le n$、因数分解します$k$最小の素因数ふるいを使用します。 

因数分解から$k$のすべての約数を生成します。$k^2$まで$k$。 

---

 ### 3. 構築する$(U,V,W,T)$私たちは以下を選択します:

 -$T$、
 -$W$、
- それから$V$、

 そして計算する$$U=\frac{k^2}{VWT}.$$不等式から導出される境界$$U<V+W+T$$検索スペースを大幅に削減します。 

---
