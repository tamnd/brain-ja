[プロジェクト オイラー問題 369](https://projecteuler.net/problem=369)

 ## 解決策

 **答え:**`862400558448`それぞれの手を 13 のランクでモデル化します。 

ランクごとに、4 つのスーツ (空を含む) の任意のサブセットを選択できるため、各ランクは 16 のスーツ サブセットの 1 つを提供します。 

あ$4$- 4 つのスートすべてをカバーする 4 つの **異なるランク** を 1 回だけ選択できれば、カード Badudo が存在します。同様に、ランクとスート間の 2 部グラフでは、サイズが一致します。$4$。 

次の Python プログラムは、どのスーツの一致が達成可能かを追跡しながら、すべてのランク構成に対して動的プログラミング検索を実行します。```
from collections import defaultdict
from functools import lru_cache

# All possible suit subsets for a rank:
# bit 0 = clubs, bit 1 = diamonds, bit 2 = hearts, bit 3 = spades
subs = list(range(16))

# Number of cards represented by each subset
sizes = [bin(x).count("1") for x in subs]

@lru_cache(None)
def trans(A, T):
    """
    A = bitmask describing which suit-sets can already be matched.
        If bit M is set, then suit-set M is achievable.

    T = suit subset available for the current rank.

    Return updated achievable mask after processing this rank.
    """
    reachable = [i for i in range(16) if (A >> i) & 1]

    B = A

    # Use current rank to extend a matching by one suit
    for M in reachable:
        for s in range(4):
            if (T >> s) & 1 and not ((M >> s) & 1):
                B |= 1 << (M | (1 << s))

    return B

# Initial state:
# only the empty matching is achievable
dp = {(1 << 0, 0): 1}

# Process all 13 ranks
for _ in range(13):
    nd = defaultdict(int)

    for (A, n), cnt in dp.items():
        for T in subs:
            nd[(trans(A, T), n + sizes[T])] += cnt

    dp = nd

# f[n] = number of n-card hands containing a Badugi
f = [0] * 53

for (A, n), cnt in dp.items():
    # bit 15 means all 4 suits can be matched
    if (A >> 15) & 1:
        f[n] += cnt

answer = sum(f[n] for n in range(4, 14))

print("f(5) =", f[5])
print("Answer =", answer)
```### コードの動作

 - 各ランクは独立してスーツのサブセットを選択します。 
-`A`個別のランクを使用して、現在一致可能なすべてのスーツの組み合わせを追跡します。 
- 新しいランクのサブセットを処理する場合`T`、未使用のスーツを 1 つ追加することで、以前のマッチングを拡張する場合があります。`T`。 
- スーツセットの場合`1111₂ = 15`が到達可能になると、完全な 4 スートのマッチングが存在します。これは、ハンドにバドゥーギが含まれていることを意味します。 
- ハンドの合計サイズに応じてカウントを蓄積します$n$。 

### 検証

 プログラムは、問題ステートメントで指定された値を再現します。$$f(5)=514800$$これは正しさを確認します。 

計算された合計は次のとおりです。$$\sum_{n=4}^{13} f(n) = 862400558448$$**答え: 862400558448**
