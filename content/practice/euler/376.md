[プロジェクト オイラー問題 376](https://projecteuler.net/problem=376)

 ## 解決策

 **答え:**`973059630185670`させて$$W(X,Y)=\#\{(x,y)\in X\times Y:x>y\},$$つまり、2 つの 6 面サイコロの場合$X,Y$、$$P(X\text{ beats }Y)=\frac{W(X,Y)}{36}.$$非推移的なトリプル$(A,B,C)$満足する$$W(B,A)>18,\qquad W(C,B)>18,\qquad W(A,C)>18.$$同点は無視されるため、これら 3 つの不等式は循環優勢条件と等価です。 

---

 ## 1. サイコロのエンコード

 6 つの面を明示的に保存する代わりに、多重度によって各ダイをエンコードします。 

のために$1\le v\le N$、 させて$$a_v,b_v,c_v\in\{0,\dots,6\}$$value の出現数になります$v$サイコロで$A,B,C$、 それぞれ。 

彼らは満足します$$\sum_{v=1}^N a_v=\sum_{v=1}^N b_v=\sum_{v=1}^N c_v=6.$$次に、優勢マージンを定義します$$M_{AB}=W(A,B)-W(B,A),$$

$$M_{BC}=W(B,C)-W(C,B),$$

$$M_{CA}=W(C,A)-W(A,C).$$希望の条件になります$$M_{AB}<0,\qquad M_{BC}<0,\qquad M_{CA}<0.$$---

 # 2. 増分遷移の式

 からの pip 値を処理します$1$に$N$。 

値の前を仮定します$v$すでに配置しています:$$A_<,\ B_<,\ C_<$$より小さい値を使用して 3 つのサイコロの面を設定します。 

置くとき$a_v,b_v,c_v$価値のコピー$v$、_小さい_値との比較のみが新たに決定されます。 

したがって、マージンの更新は次のようになります。$$\Delta M_{AB}=a_v B_< - b_v A_<,$$

$$\Delta M_{BC}=b_v C_< - c_v B_<,$$

$$\Delta M_{CA}=c_v A_< - a_v C_<.$$これが重要な観察点です。各ステップは現在の累積カウントのみに依存するため、動的なプログラムが可能です。 

---

 # 3. 動的プログラミングの状態

 使用状態$$(A_<,B_<,C_<,M_{AB},M_{BC},M_{CA})$$間のカウント$0$そして$6$、および間のマージン$-36$そして$36$。 

すべてのpip値について$v$、すべての選択肢を繰り返します$$a_v,b_v,c_v\in\{0,\dots,6\}$$合計 6 つの面を超えないもの。 

これは**順序付けられた**トリプルをカウントします$(A,B,C)$。 

最後に:

 - 3 つのマージンがすべてマイナスである状態のみを保持します。 
- で割る$3$、 なぜなら$$(A,B,C), (B,C,A), (C,A,B)$$同じ巡回集合を表します。 

(向きが逆でも不等式を満たすことができないため、反転による二重カウントは発生しません。)

 ---

 #4. Pythonの実装```python
from collections import defaultdict

def count_nontransitive(N):
    # state:
    # (a_used, b_used, c_used, mab, mbc, mca)

    dp = defaultdict(int)
    dp[(0, 0, 0, 0, 0, 0)] = 1

    for v in range(1, N + 1):
        nxt = defaultdict(int)

        for (au, bu, cu, mab, mbc, mca), ways in dp.items():

            for av in range(7 - au):
                for bv in range(7 - bu):
                    for cv in range(7 - cu):

                        nmab = mab + av * bu - bv * au
                        nmbc = mbc + bv * cu - cv * bu
                        nmca = mca + cv * au - av * cu

                        key = (
                            au + av,
                            bu + bv,
                            cu + cv,
                            nmab,
                            nmbc,
                            nmca,
                        )

                        nxt[key] += ways

        dp = nxt

    total = 0

    for (au, bu, cu, mab, mbc, mca), ways in dp.items():
        if (
            au == bu == cu == 6 and
            mab < 0 and
            mbc < 0 and
            mca < 0
        ):
            total += ways

    # quotient by cyclic rotations
    return total // 3

print(count_nontransitive(7))   # 9780
print(count_nontransitive(30))
```---

 #5. サンプルの検証

 のために$N=7$、プログラムは戻ります$$9780,$$これはステートメントで指定された値と一致します。 

同じ計算を実行すると、$N=30$与える$$973059630185670.$$6 マルチセットの数が次のとおりであるため、この大きさは妥当です。$1$に$30$すでに$$\binom{35}{6}=1,623,160,$$したがって、循環的に非推移的なトリプルの数は当然膨大になります。 

したがって、最終結果は次のようになります。 

**答え: 973059630185670**
