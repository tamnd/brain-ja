[プロジェクト オイラー問題 300](https://projecteuler.net/problem=300)

 ## 解決策

 **答え:**`8.0540771484375`長さのあるタンパク質を作る$n$バイナリ文字列にする$\{H,P\}$。 

折り畳みとは、正方形の格子上を自己回避的に歩くことです。 

固定されたフォールディングと固定されたタンパク質配列の場合、エネルギーは隣接するタンパク質の数です。$H\!-\!H$連絡先。 

重要な点:

 - 隣接$H$- **チェーン自体に沿った要素**も接触点としてカウントされます。 
- 2 つの非連続の場合、追加の接触が発生します。$H$は格子上の隣人になります。 

のために$n=8$、問題ステートメントは平均を示します$850/256 = 3.3203125$。 

確かに、$$\mathbb E[\text{sequential HH contacts}] = \frac{7}{4}=1.75,$$したがって、非連続的な格子接触からの平均寄与は次のようになります。$$3.3203125 - 1.75 = 1.5703125,$$これは自己回避歩行の計算と一致します。

 #1. 数学的分析

 以下を計算する必要があります。$$\frac1{2^{15}} \sum_{\text{all sequences }S} \max_{\text{foldings }F} C(S,F),$$どこ$C(S,F)$の合計数です$H\!-\!H$連絡先。 

---

 ## ステップ 1: 避けられない連絡先を分離する

 チェーン内の隣接するペアごとに次のようになります。$$(i,i+1),$$両方ある場合$H$、フォールディングに関係なく 1 つの接触に貢献します。 

がある$14$隣接するペア、それぞれ同時に$H$確率的に$1/4$。 したがって、次のようになります。$$\mathbb E[\text{chain contacts}] = 14\cdot \frac14 = 3.5.$$したがって、実際の作業は、折り畳むことによって生成される **余分**な接触の最適な数を計算することです。 

---

 ## ステップ 2: すべての折り畳みを列挙する

 フォールディングとは、自分自身を避けて長さを歩くことです$14$正方格子の上に。 

修正します:

 - 最初のモノマー$(0,0)$、
 - 2番目に$(1,0)$、

 回転対称性を取り除きます。 

すべての自己回避歩行について、集合を計算します$$E_F=\{(i,j)\mid |i-j|>1,\ \text{positions }i,j\text{ adjacent on lattice}\}.$$これらは非連続的な接触の機会です。 

異なるウォークでは同じコンタクト グラフが生成される可能性があるため、重複を排除します。 

のために$n=15$、これは正確に次のようになります:$$12495$$明確な接触グラフ。

 ## ステップ 3: すべてのタンパク質配列を評価する

 それぞれについて、$2^{15}=32768$シーケンス:

 - どのインデックスが該当するかを決定する$H$、
 - 接触グラフごとに$E_F$、

 両方の端点を持つエッジをカウントします。$H$、
 - 最大値を維持します。 

すべてのシーケンスを合計すると、次のようになります。$$149228$$最適な **非連続** 接触。 

したがって、平均追加貢献度は次のようになります。$$\frac{149228}{32768} = 4.5540771484375.$$避けられない連鎖寄与を追加すると、次のようになります。$$4.5540771484375 + 3.5 = 8.0540771484375.$$---

 #2. Pythonの実装```python
from collections import defaultdict

N = 15

# Directions on the square lattice
DIRS = [(1,0), (-1,0), (0,1), (0,-1)]

# Enumerate all self-avoiding walks with first step fixed
visited = {(0,0), (1,0)}
path = [(0,0), (1,0)]

contact_graphs = set()

def contact_graph(path):
    """
    Return the set of non-consecutive lattice-adjacent pairs.
    """
    edges = []

    for i in range(N):
        xi, yi = path[i]

        for j in range(i + 2, N):
            xj, yj = path[j]

            if abs(xi - xj) + abs(yi - yj) == 1:
                edges.append((i, j))

    return tuple(sorted(edges))

def dfs(x, y, step):
    if step == N - 1:
        contact_graphs.add(contact_graph(path))
        return

    for dx, dy in DIRS:
        nx, ny = x + dx, y + dy

        if (nx, ny) not in visited:
            visited.add((nx, ny))
            path.append((nx, ny))

            dfs(nx, ny, step + 1)

            path.pop()
            visited.remove((nx, ny))

dfs(1, 0, 1)

graphs = list(contact_graphs)

# best_extra[s] = maximum non-consecutive contacts
best_extra = [0] * (1 << N)

for s in range(1 << N):

    best = 0

    for g in graphs:

        score = 0

        for i, j in g:
            if ((s >> i) & 1) and ((s >> j) & 1):
                score += 1

        if score > best:
            best = score

    best_extra[s] = best

total_extra = sum(best_extra)

# Sequential HH contacts:
# each adjacent pair contributes with probability 1/4
sequential_average = (N - 1) / 4

answer = sequential_average + total_extra / (1 << N)

print(answer)
```---
