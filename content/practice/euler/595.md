[プロジェクト オイラー問題 595](https://projecteuler.net/problem=595)

 ## 解決策

 **答え:**`54.17529329`させて$S(n)$は、一様にランダムな順列から開始する場合に必要となる予想されるシャッフル数を示します。$n$カード。 

## 1. 数学的分析

 ### ステップ 1: プロセスを再定式化する

 どの段階でも、既に連続昇順になっているカードは **バンドルに追加**されます。 

例：$$4123756 \to (4)(123)(7)(56)$$重要な観察:

 > カードがバンドルされると、**バンドルの相対的な順序**のみが重要になります。 

あれば$k$束を空中に投げて拾い上げると、**一様にランダムな順列が得られます。$k$バンドル**。 

したがって、状態は以下にのみ依存します。$$k = \text{number of bundles}$$させて：$$E_k = \text{expected additional shuffles needed from a random arrangement of } k \text{ bundles}.$$私たちが望んでいるのは:$$S(n)=E_n.$$---

 ### ステップ 2: 遷移確率

 現在あると仮定します$k$バンドル。 

2 つの連続するバンドルが正しい順序で隣接して表示されると、バンドルの境界は消えます。 

定義する：$$r = \text{number of successful adjacencies}$$そして検査後：$$j = k-r$$バンドルが残っています。 

確率が必要です$p_{k,j}$のランダムな並べ替え$k$オブジェクトが正確に生成する$j$バンドル。 

同様に、順列を正確に数えます。$r=k-j$隣接する順序ペア:$$(i,i+1)$$のために$i=1,\dots,k-1$。 

包含と除外の使用:$$N_{k,r} = \sum_{s=r}^{k-1} (-1)^{s-r} \binom{s}{r} \binom{k-1}{s} (k-s)!$$どこ$N_{k,r}$は正確な順列の数です$r$成功した隣接関係。 

したがって、$$p_{k,j} = \frac{N_{k,k-j}}{k!}.$$---

 ### ステップ 3: 期待に対する再発

 順列がすでにソートされている場合、シャッフルは必要ありません。 

それは次の場合にのみ発生します$j=1$、確率的に$1/k!$。 

それ以外の場合は、ちょうど **1 回のシャッフル**が発生し、新しいバンドル数から続行されます。 

したがって：$$E_k = \left(1-\frac1{k!}\right) + \sum_{j=2}^{k} p_{k,j}E_j.$$任期以来$j=k$含まれています$E_k$自体：$$E_k(1-p_{k,k}) = \left(1-\frac1{k!}\right) + \sum_{j=2}^{k-1} p_{k,j}E_j.$$したがって：$$E_k = \frac{ 1-\frac1{k!} + \sum_{j=2}^{k-1} p_{k,j}E_j }{ 1-p_{k,k} }.$$基本ケース:$$E_1=0.$$---

 ## 2. Python の実装```python
from math import comb, factorial

def expected_shuffles(n):
    # E[k] = expected shuffles for k bundles
    E = [0.0] * (n + 1)

    # Precompute factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i

    # Build E[k] iteratively
    for k in range(2, n + 1):

        rhs = 1.0 - 1.0 / fact[k]

        # Contributions from smaller states
        for j in range(2, k):
            r = k - j

            # Inclusion-exclusion count N_{k,r}
            count = 0
            for s in range(r, k):
                count += (
                    (-1) ** (s - r)
                    * comb(s, r)
                    * comb(k - 1, s)
                    * fact[k - s]
                )

            p_kj = count / fact[k]
            rhs += p_kj * E[j]

        # Probability of staying at k bundles
        count_same = 0
        for s in range(k):
            count_same += (
                (-1) ** s
                * comb(k - 1, s)
                * fact[k - s]
            )

        p_kk = count_same / fact[k]

        E[k] = rhs / (1.0 - p_kk)

    return E[n]

# Check given examples
print(expected_shuffles(2))  # 1
print(expected_shuffles(5))  # 4213/871 ≈ 4.836969001148105

# Required answer
ans = expected_shuffles(52)
print(f"{ans:.8f}")
```---
