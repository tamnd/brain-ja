[プロジェクト オイラー問題 868](https://projecteuler.net/problem=868)

 ## 解決策

 **答え:**`3832914911887589`この問題は、鐘を鳴らすルールによって生成される順列順序のランキング問題です。 重要なのは、この手順がまさに **Steinhaus–Johnson–Trotter (SJT)** 順列順序 (「単純な変更」とも呼ばれます) であることを認識することです。 

最初のアルファベット順から特定の順列に到達するために必要なスワップの数を求められます。 すべてのステップで **正確に 1 つの隣接スワップ**が実行されるため、スワップの数は SJT 順序付けのターゲット順列の **0 から始まるインデックス ** と等しくなります。 

---

 ## 1. 数学的分析

 しましょう$R(P)$順列に達するまでに必要なスワップの数になります$P$。 

私たちが望んでいるのは:$$R(\texttt{NOWPICKBELFRYMATHS})$$アルファベット順に文字から始めます。 

### SJT オーダーの再帰構造

 あるとします。$n$最大の文字を$L$。 

SJT世代$n$文字は次の順序から再帰的に構築されます。$n-1$文字:

 - 小さい方の順列をそれぞれ取り出します。$n-1$手紙。 
- 入れる$L$可能なすべての位置に。 
- 挿入方向が交互になります。 

小さい順列のインデックスが **偶数**の場合、移動します$L$**右から左**へ。 

小さい順列に **奇数のインデックス**がある場合、移動します$L$**左から右**へ。 

例$ABC$:

 の順列から$AB$:

 -$AB$(インデックス 0、偶数): 挿入$C$右→左$$ABC,\ ACB,\ CAB$$-$BA$(インデックス 1、奇数): 挿入$C$左→右$$CBA,\ BCA,\ BAC$$問題文にあるとおりです。 

---

 ### 再発の導出

 しましょう:

 -$n$= 文字数
 -$L$= 最大の文字
 -$p$= の位置$L$(左から0インデックス)
 -$r$= 削除後の順列のランク$L$次に:

 - もし$r$**偶数**、$L$右→左に移動するため、ブロック オフセットは次のようになります。$$(n-1)-p$$- もし$r$**奇妙です**、$L$は左→右に移動するため、ブロック オフセットは次のようになります。$$p$$したがって：$$R(P)=n\cdot r + b$$どこ$$b= \begin{cases} (n-1)-p & \text{if } r \text{ even}\\[4pt] p & \text{if } r \text{ odd} \end{cases}$$これにより、$O(n^2)$再帰的なランキングアルゴリズム。

 ## 2. Python の実装```python
def sjt_rank(word):
    """
    Return the 0-based index of `word`
    in Steinhaus-Johnson-Trotter order.
    """

    def rank_recursive(letters):
        n = len(letters)

        # Base case
        if n <= 1:
            return 0

        # Largest letter
        largest = max(letters)

        # Position of largest letter
        pos = letters.index(largest)

        # Remove largest letter
        reduced = [x for x in letters if x != largest]

        # Rank of reduced permutation
        r = rank_recursive(reduced)

        # Offset within this block
        if r % 2 == 0:
            offset = (n - 1) - pos
        else:
            offset = pos

        return n * r + offset

    return rank_recursive(list(word))

# Verify examples
print(sjt_rank("CBA"))      # 3
print(sjt_rank("BELFRY"))   # 59

# Compute Project Euler answer
target = "NOWPICKBELFRYMATHS"
print(sjt_rank(target))
```---
