[プロジェクト オイラー問題 710](https://projecteuler.net/problem=710)

 ## 解決策

 **答え:**`1275000`させて

-$P(n)$= 合計する回文タプルの数$n$、
 -$a(n)$= 合計する回文タプルの数$n$**含まれない**$2$、
 -$t(n)$= 二人の仲間の数。 

それから$$t(n)=P(n)-a(n).$$回文構成の場合、左半分がタプル全体を決定するため、$$P(n)=2^{\lfloor n/2 \rfloor}.$$シーケンス$a(n)$回帰を満たす$$a(n)=a(n-2)+a(n-3),$$初期値あり$$a(1)=1,\quad a(2)=1,\quad a(3)=2.$$したがって、$$t(n)=2^{\lfloor n/2 \rfloor}-a(n).$$今計算します$t(n)\bmod 10^6$なるまで$0$初めて一緒に$n>42$。```python
MOD = 10**6

# a[n] = number of palindromic sums of n with no element equal to 2
a = [0, 1, 1, 2]   # indices 0..3

n = 3

while True:
    n += 1

    # recurrence: a(n) = a(n-2) + a(n-3)
    a.append((a[n - 2] + a[n - 3]) % MOD)

    # total palindromic sums = 2^(floor(n/2))
    total = pow(2, n // 2, MOD)

    # twopals
    t = (total - a[n]) % MOD

    if n > 42 and t == 0:
        print(n)
        break
```### ウォークスルー

 -`a[n]`数値 2 を避けた回文合計の数を格納します。 
- モジュロ値のみを保持します$10^6$100 万で割り切れるかどうかだけが重要だからです。 
-`pow(2, n // 2, MOD)`計算する$2^{\lfloor n/2\rfloor}\bmod 10^6$。 
- それぞれをテストします$n>42$それまで$t(n)\equiv 0 \pmod{10^6}$。 

### 検証

 この式は、問題で指定された値を再現します。 

-$t(20)=824$-$t(42)=1999923$そして最初の$n>42$と$$t(n)\equiv 0 \pmod{10^6}$$は:

 **答え: 1275000**
