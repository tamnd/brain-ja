[プロジェクト オイラー問題 603](https://projecteuler.net/problem=603)

 ## 解決策

 **答え:**`879476477`数値/文字列の 10 進数を次のようにします。$d_1,d_2,\dots,d_N$。 

計算しなければなりません$$S(n)=\sum_{\text{all contiguous substrings}} \text{(substring value)}.$$問題については:

 -$P(n)$= 最初の連結$n$素数、
 -$C(n,k)$=$P(n)$繰り返された$k$回、
 - 必須:$$S(C(10^6,10^{12})) \pmod{10^9+7}.$$---

 #1. 数学的分析

 ## 1.1 1 桁の寄与

 数字を修正する$d_i$位置にある$i$(左から 1 のインデックスが付けられます)。 

部分文字列がある位置から始まると仮定します。$\le i$そしてで終わります$j\ge i$。 

その部分文字列内では、$d_i$貢献する$$d_i \cdot 10^{j-i}.$$出発点の選択肢は何通りありますか?

 その通り$i$選択肢。 

したがって、貢献度の合計は、$d_i$は$$d_i \cdot i \sum_{j=i}^{N} 10^{j-i}.$$させて$t=j-i$。 それから$$\sum_{t=0}^{N-i}10^t = \frac{10^{N-i+1}-1}{9}.$$したがって$$S = \sum_{i=1}^{N} d_i\, i \,\frac{10^{N-i+1}-1}{9}.$$それで$$S = \frac1{9} \left( 10^{N+1}\sum_{i=1}^{N} d_i i 10^{-i} - \sum_{i=1}^{N} d_i i \right).$$すべてが重み付けされた数字の合計に還元されます。 

---

 # 1.2 繰り返しブロック

 の数字列を$P(n)$長さがある$L$、数字付き$$a_1,a_2,\dots,a_L.$$このブロックを繰り返します$k$回。 

コピー内の数字$r$（どこ$0\le r<k$) と内部位置$i$世界的な地位を持っている$$rL+i.$$定義する$$q=10^{-1}\pmod M, \qquad M=10^9+7.$$それから$$10^{- (rL+i)} = q^{rL+i}.$$必要です$$T = \sum_{r=0}^{k-1}\sum_{i=1}^{L} a_i(rL+i)q^{rL+i}.$$要素：$$T = \sum_{r=0}^{k-1} q^{rL} \left( rL \sum_i a_i q^i + \sum_i a_i i q^i \right).$$定義する$$B=\sum_i a_i q^i, \qquad C=\sum_i a_i i q^i.$$それから$$T = BL\sum_{r=0}^{k-1} r x^r + C\sum_{r=0}^{k-1} x^r,$$どこ$$x=q^L.$$私たちにも必要です$$U=\sum d_i i = kE + DL\frac{k(k-1)}2,$$どこ$$D=\sum_i a_i, \qquad E=\sum_i a_i i.$$したがって$$S = \frac{ 10^{N+1}T-U }{9}, \qquad N=Lk.$$---

 #1.3 幾何和

 私たちが使用するのは$$G_0=\sum_{r=0}^{k-1}x^r = \frac{1-x^k}{1-x},$$そして$$G_1=\sum_{r=0}^{k-1} r x^r = \frac{x(1-kx^{k-1}+(k-1)x^k)}{(1-x)^2}.$$それで$$T = BLG_1 + CG_0.$$すべてをモジュロで計算できるようになりました$M$。

 #2. Pythonの実装```python
MOD = 10**9 + 7

INV9 = pow(9, MOD - 2, MOD)
INV10 = pow(10, MOD - 2, MOD)
INV2 = pow(2, MOD - 2, MOD)

N_PRIMES = 10**6
K = 10**12

# ------------------------------------------------------------
# Sieve for first 1,000,000 primes
# ------------------------------------------------------------

import math

# Standard upper bound for nth prime
LIMIT = int(
    N_PRIMES * (
        math.log(N_PRIMES) +
        math.log(math.log(N_PRIMES))
    )
) + 100

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0] = sieve[1] = 0

for p in range(2, int(math.isqrt(LIMIT)) + 1):
    if sieve[p]:
        start = p * p
        sieve[start:LIMIT + 1:p] = b"\x00" * (
            ((LIMIT - start) // p) + 1
        )

# ------------------------------------------------------------
# Build digit statistics for P(10^6)
# ------------------------------------------------------------

L = 0

B = 0
C = 0
D = 0
E = 0

qpow = 1
count = 0

for p in range(2, LIMIT + 1):
    if sieve[p]:
        count += 1

        for ch in str(p):
            d = ord(ch) - 48

            L += 1

            # q^L
            qpow = (qpow * INV10) % MOD

            B = (B + d * qpow) % MOD
            C = (C + d * L * qpow) % MOD

            D = (D + d) % MOD
            E = (E + d * L) % MOD

        if count == N_PRIMES:
            break

# ------------------------------------------------------------
# Geometric sums
# ------------------------------------------------------------

x = pow(INV10, L, MOD)

den = (1 - x) % MOD
den_inv = pow(den, MOD - 2, MOD)

G0 = (1 - pow(x, K, MOD)) * den_inv
G0 %= MOD

G1 = (
    x *
    (1 - K * pow(x, K - 1, MOD) + (K - 1) * pow(x, K, MOD))
)

G1 %= MOD

G1 = (G1 * den_inv * den_inv) % MOD

# ------------------------------------------------------------
# Assemble formula
# ------------------------------------------------------------

T = (B * L % MOD) * G1
T += C * G0
T %= MOD

U = (
    (K % MOD) * E
    + D * (L % MOD) % MOD
      * ((K - 1) % MOD) % MOD
      * (K % MOD) % MOD
      * INV2
)
U %= MOD

# exponent reduced modulo MOD-1 by Fermat
N_mod = (L % (MOD - 1)) * (K % (MOD - 1))
N_mod %= (MOD - 1)

answer = (
    (pow(10, N_mod + 1, MOD) * T - U)
    * INV9
) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## ふるいセクション

 標準的な bytearray sieve を使用して最初の 100 万個の素数を生成します。 

100万番目の素数は$15{,}485{,}863$、したがって、上限に近い$1.65\times10^7$で十分です。 

---

 ## 桁統計の構築

 素数を桁ごとに連結すると、次のことが維持されます。 

-$L$: 合計桁数、
 -$B=\sum a_i q^i$、
 -$C=\sum a_i i q^i$、
 -$D=\sum a_i$、
 -$E=\sum a_i i$。 

私たちは巨大な数そのものを構築することはありません。 

---

 ## 幾何和

 なぜなら$C(n,k)$が繰り返しブロックである場合、すべての繰り返しコピー効果は次のように折りたたまれます。$$G_0=\sum x^r, \qquad G_1=\sum r x^r.$$両方とも計算されます$O(\log k)$べき乗剰余を使用した時間。 

---

 ## 最終アセンブリ

 私たちは計算します$$S=\frac{10^{N+1}T-U}{9}\pmod M.$$以来$N=Lk$が膨大なので、指数モジュロを減らします$M-1$フェルマーの定理を使って。
