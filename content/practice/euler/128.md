[プロジェクト オイラー問題 128](https://projecteuler.net/problem=128)

 ## 解決策

 **答え:**`14516824220`タイルを同心の六角形のリングに配置します。 

指輪$r$（と$r\ge 1$) が含まれています$6r$タイルとリングの最後のタイル$r$は$$1+\sum_{k=1}^{r}6k =1+3r(r+1).$$問題を解決する鍵は、ほとんどすべてのタイルに隣接する複合差分が多すぎて達成できないことです。$\operatorname{PD}(n)=3$。 実際、リングごとに機能できるタイルは 2 つだけであることが証明されています。 

---

 #1. 数学的分析

 タイルの場合$n$、 定義する$\operatorname{PD}(n)$間の 6 つの絶対差の中の素数値の数として$n$そしてその隣人たち。 

この問題では、可能な最大値は$3$。 

注目すべき観察は次のとおりです。 

- もし$\operatorname{PD}(n)=3$、 それから$n$特別な角の位置になければなりません。 
・具体的にはリング上の候補者は以下の2名のみ$r$働くことができます:$$A_r = 3r(r-1)+2$$(リングの最初のタイル$r$）

そして$$B_r = 3r(r+1)+1$$(リングの最後のタイル$r$）。 

ここで、これらの主条件を導出します。 

---

 ## 候補 1: リングの最初のタイル

 検討してください$$A_r = 3r(r-1)+2.$$その 6 つの隣接差分は次のように単純化されます。$$1,\quad 6r-1,\quad 6r+1,\quad 12r-7,$$さらに 2 つの明らかな複合値/非素数値。 

したがって$$\operatorname{PD}(A_r)=3$$3 つの数字すべてが一致する場合$$6r-1,\qquad 6r+1,\qquad 12r-7$$プライムです。 

---

 ## 候補 2: リングの最後のタイル

 ここで考えてみましょう$$B_r = 3r(r+1)+1.$$関連する近隣の差異は次のようになります。$$6r-1,\quad 6r+5,\quad 12r+5.$$したがって、$$\operatorname{PD}(B_r)=3$$もし$$6r-1,\qquad 6r+5,\qquad 12r+5$$はすべてプライムです。 

---

 ## シーケンスの生成

 したがって、シーケンスは以下で構成されます。 

-$1$、
- 全て$A_r$最初の素数トリプルを満たし、
 - すべて$B_r$2 番目の素数トリプルを満たします。 

第 10 項は次のように与えられます。$271$、便利なチェックを提供します。 

必要なのは 2000 番目の項だけであるため、高速素数テストによるリングの直接検索で十分です。 

---

 #2. Pythonの実装```python
from math import isqrt

def is_prime(n):
    """Deterministic primality test for positive integers."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    limit = isqrt(n)
    f = 5
    step = 2

    while f <= limit:
        if n % f == 0:
            return False
        f += step
        step = 6 - step

    return True

def solve(target):
    # The sequence starts with tile 1
    values = [1]

    r = 1

    while len(values) < target:

        # First tile in ring r
        a = 3 * r * (r - 1) + 2

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 1)
            and is_prime(12 * r - 7)
        ):
            values.append(a)

        # Last tile in ring r
        b = 3 * r * (r + 1) + 1

        if (
            is_prime(6 * r - 1)
            and is_prime(6 * r + 5)
            and is_prime(12 * r + 5)
        ):
            values.append(b)

        r += 1

    values.sort()
    return values[target - 1]

answer = solve(2000)
print(answer)
```---
