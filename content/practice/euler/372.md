 **答え:**`301450082318807027`させて$$R(M,N)=\#\left\{(x,y): M<x\le N,\; M<y\le N,\; \left\lfloor \frac{y^2}{x^2}\right\rfloor \text{ is odd} \right\}.$$私たちが欲しいのは$$R(2\cdot 10^6,10^9).$$---

 ## 1. 数学的分析

 を満たす格子点を数えなければなりません$$\left\lfloor \frac{y^2}{x^2}\right\rfloor = 2k+1$$ある整数に対して$k\ge0$。 

同様に、$$2k+1 \le \frac{y^2}{x^2} < 2k+2,$$したがって$$x\sqrt{2k+1}\le y < x\sqrt{2k+2}.$$したがって、固定の場合$x$、有効な$y$はばらばらの間隔で存在する$$[x\sqrt{1},x\sqrt{2}), [x\sqrt{3},x\sqrt{4}), [x\sqrt{5},x\sqrt{6}), \ldots$$に限定される$M<y\le N$。 

固定奇数の場合$n$、 定義する$$I_n(x)=\#\{y: n x^2\le y^2<(n+1)x^2,\; M<y\le N\}.$$それから$$R(M,N)=\sum_{\substack{n\ge1\\ n\text{ odd}}} \sum_{x=M+1}^{N} I_n(x).$$---

 ### 間隔を正確にカウントする

 奇数の場合$n$、$$y \in \left[ \left\lceil x\sqrt n\right\rceil, \left\lceil x\sqrt{n+1}\right\rceil-1 \right].$$以来$n+1$は偶数であり、決して正方形ではないため、上限の終点は常に無理数となるため、$$\left\lceil x\sqrt{n+1}\right\rceil-1 = \left\lfloor x\sqrt{n+1}\right\rfloor.$$したがって、寄与分は下限合計の差になります。$$I_n(x) = \left\lfloor x\sqrt{n+1}\right\rfloor - \left\lfloor x\sqrt n\right\rfloor + \varepsilon_n(x),$$どこ$\varepsilon_n(x)=1$そのときだけ$n$奇数平方である (下限点が整数であるため)、それ以外の場合$0$。 

したがって、問題は、フォームの巨額の評価に帰着します。$$\sum_{x\le X}\lfloor x\sqrt d\rfloor.$$これらは古典的なビーティ数列/二次無理数の下限和であり、次のように評価できます。$O(\log X)$再帰的な相補的な Beatty 関係を使用した時間。 

該当する奇数の合計数$n$小さいです:$$n \le \left(\frac{N}{M+1}\right)^2 < 250000,$$したがって、計算全体が実行可能です。

 ## 2. Python の実装```python
from math import isqrt

# Sum_{k=1}^n floor(k * sqrt(d))
# Uses recursive Beatty-style reduction.
def beatty_sqrt_sum(d, n):
    if n <= 0:
        return 0

    a = isqrt(d)
    if a * a == d:
        # perfect square
        return a * n * (n + 1) // 2

    # alpha = sqrt(d)
    # beta = alpha / (alpha - floor(alpha))
    m = int((isqrt(d * n * n) + a * n) // (d - a * a))

    # Recursive complementary Beatty identity
    return (
        n * m
        + n * (n + 1) // 2 * a
        - m * (m + 1) // 2
        - beatty_sqrt_sum(d, m)
    )

def F(d, L, R):
    # Sum_{x=L}^R floor(x * sqrt(d))
    if R < L:
        return 0
    return beatty_sqrt_sum(d, R) - beatty_sqrt_sum(d, L - 1)

def R(M, N):
    ans = 0

    max_n = (N // (M + 1)) ** 2

    for n in range(1, max_n + 1, 2):

        # largest x with x*sqrt(n) <= N
        x2 = N // isqrt(n)

        # largest x with x*sqrt(n+1) <= N
        x1 = N // isqrt(n + 1)

        L = M + 1

        # region where upper bound is floor(x*sqrt(n+1))
        if x1 >= L:
            ans += (
                F(n + 1, L, x1)
                - F(n, L, x1)
            )

        # region where upper bound saturates at N
        A = max(L, x1 + 1)
        if x2 >= A:
            cnt = x2 - A + 1
            ans += cnt * N - F(n, A, x2)

        # correction when n is an odd square
        s = isqrt(n)
        if s * s == n:
            ans += max(0, x2 - L + 1)

    return ans

print(R(0, 100))       # 3019
print(R(100, 10000))  # 29750422

print(R(2_000_000, 1_000_000_000))
```---
