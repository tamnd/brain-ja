[プロジェクト オイラー問題 426](https://projecteuler.net/problem=426)

 ## 解決策

 **答え:**`31591886008`占有されているボックスを次のように表すとします。`1`そして空箱は`0`。 

したがって、構成は次で始まり次で終わる有限のバイナリ文字列です。`1`。 

ボックス ボール システム (BBS) の場合、可積分システムに関する重要な事実は次のとおりです。 

> 最終的なソリトン サイズ (「最終状態」) は、隣接するソリトンの繰り返し除去によって得られるパーティションの行の長さとまったく同じです。`10`ペア。 

同様に:

 - 1 回のエリミネーション ラウンドで、隣接するすべてのエリミネーション ラウンドを除去します。`10`。 
- 削除されたペアの数を数えます。 
- いいえになるまで繰り返します`1`残っています。 

連続ラウンドで削除されたペアの数が$$c_1,c_2,c_3,\dots,$$最終状態は正確に$$[c_1,c_2,c_3,\dots].$$さらに、一致したペアが別のペアの中にネストされている場合、そのネストの深さによって、そのペアがどの消去ラウンドで消えるかが決まります。 

---

 #1. 数学的構造

 最初の交互ランレングス エンコーディングが次のようになっていると仮定します。$$(a_1,b_1,a_2,b_2,\dots,a_n),$$どこ：

-$a_i$= 連続して占有されたボックス、
 -$b_i$= 連続した空のボックス。 

この問題については、$$a_i=t_{2i},\qquad b_i=t_{2i+1},$$と$$t_k=(s_k\bmod 64)+1.$$BBS 不変式は、ターンをシミュレートせずに計算できます。 

---

 ## 括弧の解釈

 通訳する

 -`1`として "（"
-`0`として "）"。 

左から右にスキャン:

 - 毎`1`スタックにプッシュします。 
- 毎`0`最新のものと一致します 一致しないもの`1`。 

一致したペアのネストの深さは、そのペアが消えるエリミネーション ラウンドと同じになります。 

したがって、次のようになります。$$c_d = \#\{\text{pairs with depth } d\}.$$最終状態のソリトンの長さは、まさに次の数列です。$$[c_1,c_2,c_3,\dots].$$したがって、必要な答えは次のとおりです$$\sum_d c_d^2.$$---

 #2. 効率的な計算

 ビットの総数は膨大です。$$\sum t_i \approx 3.25\times 10^8,$$したがって、完全なバイナリ文字列を展開するのは無駄です。 

ただし、各ランの長さは最大でも$64$したがって、実行を直接処理します。 

保守:

 - 現在のスタック高さ$h$、
 - カウント`cnt[d]`。 

実行のために`1`長さのs$a$:

 - 深みが増す$h+1,h+2,\dots,h+a$、
 - 彼らを押してください。 

実行のために`0`長さのs$b$:

 - 最新の不一致と一致します`1`さん、
 - ポップされた深さは$h,h-1,\dots,h-b+1$、
 - 対応するカウンターをインクリメントします。 

全体的な複雑さは実行数に比例します。$$O(10^7),$$それは簡単に実現可能です。 

---

 #3. Pythonの実装```python
from collections import defaultdict

MOD = 50515093

# Generate t_k
def generate_t(n):
    s = 290797
    for _ in range(n + 1):
        yield (s % 64) + 1
        s = (s * s) % MOD

def solve(N):
    # We need t_0 ... t_N
    t = generate_t(N)

    # stack height
    h = 0

    # cnt[d] = number of matched pairs at depth d
    cnt = defaultdict(int)

    runs = list(t)

    # occupied runs are even indices
    # empty runs are odd indices
    for i, x in enumerate(runs):

        if i % 2 == 0:
            # run of 1s
            h += x

        else:
            # run of 0s
            for d in range(h, h - x, -1):
                cnt[d] += 1
            h -= x

    # final-state entries are cnt[d]
    ans = sum(v * v for v in cnt.values())
    return ans

print(solve(10))
print(solve(10_000_000))
```---

 #4. コードのチュートリアル

 ## PRNG```python
s = (s * s) % 50515093
t_k = (s % 64) + 1
```これは、問題で定義されたシーケンスを正確に再現します。 

---

 ## スタックの高さ```python
h += x
```占有されたボックスの実行により、比類のない追加が行われます`1`s.

 ---

 ## ゼロの一致```python
for d in range(h, h - x, -1):
    cnt[d] += 1
```それぞれ`0`最新のものと一致します 一致しないもの`1`。 

一致したペアのネストの深さは、現在のスタックの高さとまったく同じです。 

したがって、各エリミネーションラウンドで何ペアが消えるかを数えます。 

---

 ## 最終不変式```python
sum(v * v for v in cnt.values())
```のマルチセット`cnt[d]`値は最終状態です。 

それらの二乗和が必要です。
