[プロジェクト オイラー問題 287](https://projecteuler.net/problem=287)

 ## 解決策

 **答え:**`313135496`画像サイズを次のようにします$2^N\times 2^N$、定義します$$C = 2^{N-1},\qquad R^2 = 2^{2N-2}.$$ピクセル$(x,y)$黒なら$$(x-C)^2+(y-C)^2 \le R^2.$$それで$D_N$単に半径の離散円盤です$2^{N-1}$を中心に$(C,C)$。 

---

 #1. 数学的分析

 四分木ノードは軸に沿った正方形の領域を表します$$[x_0,x_0+s-1]\times [y_0,y_0+s-1]$$辺の長さで$s=2^k$。 

エンコーディングの場合:

 - 単色領域のコストは **2 ビット**

 -`10`黒用
 -`11`白用
 - 分割費用

 -`0`加えて 4 つの子のエンコーディングも追加します。 

したがって、リージョンが混在している場合、そのコストは次のようになります。$$1+\sum_{\text{4 children}} \text{cost(child)}.$$したがって、問題は次のようになります。 

> 正方形が完全に円の内側にあるのか、完全に外側にあるのか、または混合されているのかを判断します。 

---

 ## 重要な幾何学的観察

 正方形の領域の場合:

 ### 完全に黒

 中心から**最も遠い**ピクセルがまだ円の内側にある場合、正方形全体は黒です。 

二乗距離は凸であるため、正方形の最も遠い点は常に 4 隅の 1 つになります。 

したがって、定義します$$d_{\max}=\max_{\text{corners}} (x-C)^2+(y-C)^2.$$もし$$d_{\max}\le R^2,$$領域全体が黒です。 

---

 ### 全体的に白

 中心に**最も近い**ピクセルが円の外側にある場合、正方形全体が白になります。 

最も近い点は、中心座標を正方形の間隔に固定することによって取得されます。$$x_n = \min(\max(C,x_0),\,x_0+s-1),$$

$$y_n = \min(\max(C,y_0),\,y_0+s-1).$$それから$$d_{\min}=(x_n-C)^2+(y_n-C)^2.$$もし$$d_{\min}>R^2,$$広場全体が白です。 

---

 ### それ以外の場合: 混合

 どちらの条件も当てはまらない場合は、円の境界が正方形を横切るため、4 つの象限に分割されます。 

---

 #2. 再帰式

 しましょう$$F(x_0,y_0,s)$$その正方形の最小エンコード長になります。 

それから：$$F= \begin{cases} 2 & \text{if entirely black or entirely white},\\[4mm] 1+\displaystyle\sum_{i=1}^4 F_i & \text{otherwise}. \end{cases}$$再帰の深さは$N=24$、境界に接する領域のみが拡大されます。 

---

 #3. Pythonの実装```python
from functools import lru_cache

N = 24

CENTER = 1 << (N - 1)
R2 = 1 << (2 * N - 2)

@lru_cache(None)
def solve(x0, y0, size):
    """
    Return the minimal quadtree encoding length
    for the square:
        x in [x0, x0 + size - 1]
        y in [y0, y0 + size - 1]
    """

    x1 = x0 + size - 1
    y1 = y0 + size - 1

    # ---------------------------------------------------------
    # Test whether the whole square is black.
    # The farthest point from the center is one of the corners.
    # ---------------------------------------------------------

    max_d2 = max(
        (x - CENTER) ** 2 + (y - CENTER) ** 2
        for x in (x0, x1)
        for y in (y0, y1)
    )

    if max_d2 <= R2:
        return 2  # "10"

    # ---------------------------------------------------------
    # Test whether the whole square is white.
    # Find the nearest point in the square to the center.
    # ---------------------------------------------------------

    nearest_x = min(max(CENTER, x0), x1)
    nearest_y = min(max(CENTER, y0), y1)

    min_d2 = (
        (nearest_x - CENTER) ** 2 +
        (nearest_y - CENTER) ** 2
    )

    if min_d2 > R2:
        return 2  # "11"

    # ---------------------------------------------------------
    # Mixed region: split into four quadrants.
    # ---------------------------------------------------------

    half = size // 2

    return (
        1 +  # leading split bit "0"
        solve(x0,         y0 + half, half) +  # top-left
        solve(x0 + half,  y0 + half, half) +  # top-right
        solve(x0,         y0,        half) +  # bottom-left
        solve(x0 + half,  y0,        half)    # bottom-right
    )

answer = solve(0, 0, 1 << N)

print(answer)
```---

```長方形の中心から最も遠い点は角になります。

 ## 完全に白いテスト```python

その最も近い点がすでに円の外側にある場合、すべてのピクセルは白になります。

 小型用$N$、再帰は期待どおりに動作します。 

- 大きな単色ブロックは 2 ビットに圧縮されます。 
- 円形の境界と交差する領域のみがさらに細分化されます。 

合計サイズは、円の周長と再帰の深さの積にほぼ比例して大きくなり、これは最終的な大きさ (~$3\times10^8$）。
