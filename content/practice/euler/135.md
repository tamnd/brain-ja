[プロジェクト オイラー問題 135](https://projecteuler.net/problem=135)

 ## 解決策

 **答え:**`4989`等差数列の連続する 3 つの項を次のようにします。$$x = a+d,\qquad y=a,\qquad z=a-d,$$どこ$a>d>0$。 

整数がいくつあるかを数えるように求められます$n<10^6$満足する$$x^2-y^2-z^2=n$$ちょうど 10 通りの方法で。 

---

 # ステップ 1 — 代数的単純化

 等差数列形式を代入します。$$(a+d)^2-a^2-(a-d)^2.$$拡大する：$$(a^2+2ad+d^2)-a^2-(a^2-2ad+d^2).$$簡略化:$$= a^2+2ad+d^2-a^2-a^2+2ad-d^2$$

$$=4ad-a^2.$$したがって$$n=4ad-a^2.$$要素：$$n=a(4d-a).$$定義する$$k=4d-a.$$それから$$n=ak.$$以来$d=\frac{a+k}{4}$、次のことが必要です。 

1.$a+k\equiv 0\pmod 4$、
 2.$k>0$（なぜなら$n>0$）、
 3.$a>d$。 

から$a>d$:$$a>\frac{a+k}{4}$$

$$4a>a+k$$

$$3a>k.$$したがって、すべての解は因数分解に対応します$$n=ak$$と$$0<k<3a, \qquad a+k\equiv 0\pmod 4.$$有効な各ペア$(a,k)$正確に 1 つの等差数列解を与えます。 

したがって、タスクは次のようになります。 

> 何個数えますか$n<10^6$ちょうど 10 個の約数のペアがある$(a,k)$それらの制約を満たすこと。 

---

 # ステップ 2 — 効率的な計数戦略

 可能な限りすべてのことを繰り返します$a$そして$k$。 

以来$$n=ak<10^6,$$それぞれに$a$、$$k<\frac{10^6}{a}.$$また、必要です$$k<3a.$$したがって、$$k < \min\left(3a,\frac{10^6}{a}\right).$$そして最後に$$a+k\equiv0\pmod4.$$配列を維持します`count[n]`有効な表現をそれぞれいくつ保存するか$n$もっている。 

---

 # ステップ 3 — Python の実装```python
LIMIT = 1_000_000

# count[n] = number of valid solutions producing n
count = [0] * LIMIT

# Iterate over a
for a in range(1, LIMIT):

    # k must satisfy:
    #   k < 3a
    #   a*k < LIMIT
    k_max = min(3 * a, (LIMIT - 1) // a)

    # We need a + k ≡ 0 (mod 4)
    # so k ≡ -a (mod 4)
    start = (4 - (a % 4)) % 4
    if start == 0:
        start = 4

    for k in range(start, k_max + 1, 4):
        n = a * k
        count[n] += 1

# Count how many n have exactly 10 solutions
answer = sum(1 for n in range(1, LIMIT) if count[n] == 10)

print(answer)
```---
