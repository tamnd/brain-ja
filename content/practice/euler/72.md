[プロジェクト オイラー問題 72](https://projecteuler.net/problem=72)

 ## 解決策

 **答え:**`303963552391`## 1. 数学的分析

 **換算された固有分数**の数が必要です$$\frac{n}{d}$$次のような:

 -$n < d$、
 -$\gcd(n,d)=1$、
 -$d \le 1{,}000{,}000$。 

---

 ### ステップ 1: 固定分母の約分数を数える

 分母を固定する$d$。 

有効な分子$n$は整数です:$$1 \le n < d$$と互いに素である$d$。 

このような整数の数は、まさにオイラーの十関数です。$$\varphi(d)$$なぜなら$\varphi(d)$未満の正の整数をカウントします$d$と互いに素である$d$。 

例えば：

-$d=8$: 分子が互いに素である$1,3,5,7$、 それで$\varphi(8)=4$。 
-$d=7$： 全て$1,2,3,4,5,6$仕事、だから$\varphi(7)=6$。 

したがって、換算された固有分数の総数は、$d \le N$は：$$\sum_{d=2}^{N} \varphi(d)$$この問題については:$$\sum_{d=2}^{1{,}000{,}000} \varphi(d)$$---

 ### ステップ 2: トーティエントを効率的に計算する

 すべてのペアの直接 gcd チェック$(n,d)$ありえないほど遅いでしょう:$$O(N^2)$$代わりに、次までのすべての合計を計算します。$N$ふるいを使用します（エラトステネスのふるいに似ています）。 

重要な事実:

 もし$p$が素数の場合、次の倍数になります$p$、$$\varphi(n) = n\left(1-\frac1p\right)$$初期化します:$$\varphi(n)=n$$次に、各素数について$p$、すべての倍数を更新します。$$\varphi(k) \leftarrow \varphi(k)-\frac{\varphi(k)}{p}$$これにより、次の値までのすべての合計が計算されます。$10^6$おおよそ：$$O(N\log\log N)$$これは十分に速いです。 

---

 ## 2. Python の実装```python
def count_reduced_proper_fractions(limit):
    # Initialize phi[n] = n
    phi = list(range(limit + 1))

    # Sieve to compute Euler's totient for every number
    for p in range(2, limit + 1):
        # If phi[p] == p, then p is prime
        if phi[p] == p:
            # Update all multiples of p
            for multiple in range(p, limit + 1, p):
                phi[multiple] -= phi[multiple] // p

    # Sum φ(d) for d >= 2
    return sum(phi[2:])

# Problem limit
N = 1_000_000

answer = count_reduced_proper_fractions(N)
print(answer)
```---

 ## 4. 最終確認

 漸近推定値は次のとおりです。$$\sum_{n\le N}\varphi(n) \approx \frac{3}{\pi^2}N^2$$のために$N=10^6$:$$\frac{3}{\pi^2}(10^{12}) \approx 3.04\times10^{11}$$したがって、およそ数千億という答えが予想されますが、これは適切な規模です。
