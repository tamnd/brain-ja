[プロジェクト オイラー問題 686](https://projecteuler.net/problem=686)

 ## 解決策

 **答え:**`193060223`させて$$x_j = j\log_{10}2.$$それから$$2^j = 10^{x_j}.$$書く$$x_j = k + f_j,$$どこ$k=\lfloor x_j\rfloor$そして$f_j\in[0,1)$小数部分です。 

それから$$2^j = 10^k\cdot 10^{f_j},$$したがって、の先頭の数字は$2^j$によって完全に決定されます$10^{f_j}$。 

次の小数展開が必要です$2^j$まず始めに$L=123$。 

---

 #1. 数学的分析

 数字は数字で始まります$123$それが間隔内にある場合$$[123\cdot 10^m,\;124\cdot 10^m)$$ある整数に対して$m$。 

したがって$2^j$から始まる$123$もし$$123 \le 10^{f_j} < 124.$$で割る$100$、$$1.23 \le 10^{f_j} < 1.24.$$取る$\log_{10}$、$$\log_{10}(1.23)\le f_j < \log_{10}(1.24).$$定義する$$a=\log_{10}(1.23),\qquad b=\log_{10}(1.24).$$それなら必要です$$\{j\log_{10}2\}\in[a,b).$$したがって、問題は次のようになります。 

> を見つけます$678910$-番目の整数$j$小数部分が
 >
 >
 >
 >
 >$$j\alpha,\qquad \alpha=\log_{10}2$$>
 >
 >
 >
 > 間隔の中にあります$[a,b)$。 

なぜなら$\alpha$不合理な順序です$$\{j\alpha\}$$は等分布法 1 です。 

間隔の長さは$$b-a = \log_{10}(1.24)-\log_{10}(1.23) = \log_{10}\!\left(\frac{124}{123}\right) \approx 0.003516.$$つまり、およそ 1 人に 1 人$$\frac1{0.003516}\approx 284$$力が働きます。 

したがって、答えは近くにあると予想されます$$678910\times 284 \approx 1.93\times 10^8.$$これは、実際の答えの既知のスケールと一致します。 

---

 #2. 効率的なアルゴリズム

 直接のブルート フォース スキャンは、実際には Python で十分高速です。$2\times10^8$反復が必要であり、各反復は 1 を法とする 1 つの浮動小数点加算にすぎません。 

以下を繰り返します。$$f_{j+1} = (f_j+\alpha)\bmod 1.$$いつでも$$a\le f_j < b,$$カウンタをインクリメントします。 

カウンターが到達したら$678910$、 現在$j$が答えです。 

---

 #3. Pythonの実装```python
import math

# Constants
alpha = math.log10(2)

# Interval corresponding to leading digits 123
a = math.log10(1.23)
b = math.log10(1.24)

target = 678910

count = 0
frac = 0.0
j = 0

while True:
    j += 1

    # fractional part of j * log10(2)
    frac += alpha
    frac -= math.floor(frac)

    # check whether leading digits are 123
    if a <= frac < b:
        count += 1

        if count == target:
            print(j)
            break
```---
