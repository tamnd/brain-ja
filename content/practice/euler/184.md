 ## 解決策

 **答え:**`1725323624056`させて$S_r$厳密に円の内側にあるゼロ以外の格子点のセットであること$$x^2+y^2<r^2 .$$頂点を持つ三角形を数えなければなりません$S_{105}$厳密にその内部に起源を含んでいます。 

---

 #1. 数学的分析

 ## ステップ 1 — 原点条件のジオメトリ

 3 つの非ゼロ点を取得し、その極角を調べます。$$0 \le \theta_1 < \theta_2 < \theta_3 < 2\pi.$$3 つの点が**閉じた半円に含まれていない**場合、三角形には原点が含まれます。 

同様に:$$\theta_3-\theta_1 > \pi.$$代わりに$$\theta_3-\theta_1 \le \pi,$$この場合、3 点すべてが半円内にあるため、原点は外側 (または境界上) になります。 

したがって、問題は次のようになります。 

> 角度スパンが**厳密に大きい**格子点のトリプルをすべて数えます。$\pi$。 

---

 ## ステップ 2 — 方向別にポイントをグループ化する

 多くの格子点が原点からの同じ光線上にあります。 

例えば：$$(1,1), (2,2), (3,3), \dots$$どれも同じ角度です。 

原点を含む三角形は、同じ光線上の 2 つの点を使用することはできません。その場合、原点は厳密に三角形の内側に存在することができないからです。 

したがって、**プリミティブ方向**によってポイントを圧縮します。 

それぞれのポイントについて$(x,y)$、 定義する$$g=\gcd(|x|,|y|), \qquad \left(\frac{x}{g},\frac{y}{g}\right)$$それがその原始的な方向です。 

方向ごとに$d_i$、 させて：$$c_i = \text{number of lattice points on that ray}.$$すべてのプリミティブ方向を角度ごとに分類します。 

---

 ## ステップ 3 — 不正なトリプルを数える

 3 方向すべてが閉じた半円の内側に収まる場合、トリプルは「不良」です。 

開始方向を修正する$i$。 

後は指示を厳守してください$i$でも角度の範囲内で$\pi$窓になります。 

そのウィンドウ内のポイントの総数が次のようになると仮定します。$$W_i.$$ただし、**異なる方向**から点を選択する必要があります。そうしないと、三角形が縮退してしまいます。 

ウィンドウ内の多重度が$c_j$の場合、異なる方向からの順序のない点のペアの数は次のようになります。$$\frac{W_i^2-\sum c_j^2}{2}.$$乗算$c_i$(最初の方向の選択肢) は、最小角度方向が次のような不良トリプルの数を示します。$i$。 

全体をまとめると$i$すべての不良トリプルを正確に 1 回カウントします。 

---

 ## ステップ 4 — 個別方向トリプルの合計

 しましょう$$N=\sum_i c_i$$は非ゼロの格子点の総数になります。 

すべてのトリプル:$$\binom{N}{3}.$$ただし、同じ方向を 2 回 (または 3 回) 使用してトリプルを削除する必要があります。 

多重性のある方向の場合$c_i$:

 - その光線上のちょうど 2 つの点で 3 倍になります。$$\binom{c_i}{2}(N-c_i)$$- そのレイ上の 3 つすべてでトリプルします。$$\binom{c_i}{3}$$これらをから引くと、$\binom{N}{3}$異なる方向を使用してトリプルの数を与えます。 

ついに：$$\text{good}= \text{distinct-direction triples} - \text{bad triples}.$$---

 #2. Pythonの実装```python
from math import gcd, atan2, pi, comb
from collections import Counter

R = 105

# Count how many lattice points lie on each primitive direction
direction_count = Counter()

for x in range(-(R - 1), R):
    for y in range(-(R - 1), R):

        if x == 0 and y == 0:
            continue

        if x * x + y * y < R * R:

            g = gcd(abs(x), abs(y))
            dx = x // g
            dy = y // g

            direction_count[(dx, dy)] += 1

# Sort primitive directions by polar angle
dirs = sorted(
    (atan2(y, x) % (2 * pi), cnt)
    for (x, y), cnt in direction_count.items()
)

angles = [a for a, c in dirs]
counts = [c for a, c in dirs]

m = len(dirs)

# Duplicate arrays for circular two-pointer sweep
angles2 = angles + [a + 2 * pi for a in angles]
counts2 = counts + counts

# Prefix sums of counts and counts^2
pref = [0]
pref_sq = [0]

for v in counts2:
    pref.append(pref[-1] + v)
    pref_sq.append(pref_sq[-1] + v * v)

# Total number of lattice points (excluding origin)
N = sum(counts)

# Total triples
total = comb(N, 3)

# Remove triples using repeated directions
duplicate_direction_triples = 0

for c in counts:
    duplicate_direction_triples += comb(c, 2) * (N - c)
    duplicate_direction_triples += comb(c, 3)

distinct_direction_triples = total - duplicate_direction_triples

# Count bad triples (contained in a semicircle)
bad = 0

j = 0

for i in range(m):

    if j < i + 1:
        j = i + 1

    while j < i + m and angles2[j] <= angles[i] + pi + 1e-15:
        j += 1

    # Window excludes i itself
    W = pref[j] - pref[i + 1]
    SQ = pref_sq[j] - pref_sq[i + 1]

    # Number of unordered pairs from distinct directions
    pairs = (W * W - SQ) // 2

    bad += counts[i] * pairs

answer = distinct_direction_triples - bad

print(answer)
```---

したがって、すべての方向に$$[i+1,\; j-1]$$半円の中に収まる$i$。

 ## 異なる方向からのペアを数える

 カウントが次の場合$a_1,a_2,\dots$、 それから$$\sum_{u<v} a_u a_v = \frac{ \left(\sum a_u\right)^2 - \sum a_u^2 }{2}.$$それはまさに次のとおりです。```python
pairs = (W * W - SQ) // 2
```---
