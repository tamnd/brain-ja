[プロジェクト オイラー問題 698](https://projecteuler.net/problem=698)

 ## 解決策

 **答え:**`57808202`させて$S$123 個の数字すべてのセットになります。 

10 進数が属する$S$もし:

 1. すべての数字が入っています$\{1,2,3\}$、そして
 2. 表示される各数字の頻度も次のとおりです。$S$。 

例えば：

-$33\in S$数字だから$3$表示されます$2$回と$2\in S$。 
-$1112\in S$なぜなら、カウントは次のとおりです。 

- 数字$1$:$3$回、
 - 数字$2$:$1$時間、

 そして両方とも$1,3\in S$。 

私たちは求めています$$F(111111111111222333),$$の$111111111111222333$-rd 123 - 昇順の番号。 

---

 #1. 数学的分析

 ## 重要な再帰的観察

 数値に次のような特徴がある場合:

 -$a$数字のコピー$1$、
 -$b$数字のコピー$2$、
 -$c$数字のコピー$3$、

 次の場合、その番号は有効です$$a,b,c \in \{0\}\cup S.$$固定トリプルの場合$(a,b,c)$、有効な文字列の数は単に多項カウントです。$$\binom{a+b+c}{a,b,c} = \frac{(a+b+c)!}{a!b!c!}.$$したがって、問題全体は次のようになります。 

1. 許容されるカウントトリプルを列挙します。 
2. 合計の長さごとに有効な文字列がいくつ存在するかを数えます。 
3. 辞書順にランクを外します。 

---

 ## どのカウント値が重要でしょうか?

 ターゲットインデックスは約$10^{17}$, したがって、回答の長さはそれほど長くありません。 

長さ別に累積数を計算すると、次のようになります。 

- すべての有効な長さの数値$\le 37$合計$$85\,645\,659\,280\,376\,850,$$長さも含めて$38$目標を上回ります。 

したがって、答えには長さがあります$38$。 

ここで次のことを観察してください。 

- 許容されるカウント自体は 123 の数値でなければなりません$\le 38$、
 - そのような値は次のとおりです。$$1,2,3,11,12,13,21,22,23,31,32,33.$$したがって、必要なのはこれら 12 個の値 (プラス 0) だけです。 

---

 ## 有効な長さ 38 の数値をすべてカウントする

 すべてのトリプルを考慮します$$(a,b,c)$$と$$a+b+c=38$$そして各コンポーネントの$$\{0,1,2,3,11,12,13,21,22,23,31,32,33\}.$$トリプルごとに、次を追加します。$$\frac{38!}{a!b!c!}.$$これにより、$$84\,604\,808\,105\,550\,180$$有効な 123 桁の長さ$38$。 

希望するインデックス内側の長さ$38$したがって$$111111111111222333 - 85645659280376850 = 25465451830845483.$$---

 ## 辞書編集上のランク付け解除

 固定長の数値は辞書順に並べられます。 

答えを一桁ずつ組み立てていきます。 

各位置で:

 - 置いてみる$1$、
 - 完了がいくつ存在するかを数えます。 
- ターゲットインデックスがその数を超えている場合は、減算して試行します$2$、
 - それ以外の場合はそのままにしておきます$1$and continue.

 プレフィックスを選択した後の完了数は、残りの桁頻度を使用した多項カウントになります。 

これにより、次のようなユニークな結果が得られます。$$13312122322122222113311233331213131323.$$最後にモジュロを計算します$123123123$:$$13312122322122222113311233331213131323 \equiv 57808202 \pmod{123123123}.$$---

 #2. Pythonの実装```python
from math import comb
from functools import lru_cache

TARGET = 111_111_111_111_222_333
MOD = 123_123_123

# All 123-numbers <= 38
VALID = [0, 1, 2, 3, 11, 12, 13, 21, 22, 23, 31, 32, 33]

@lru_cache(None)
def multinomial(a, b, c):
    """
    Number of strings containing:
        a copies of '1'
        b copies of '2'
        c copies of '3'
    """
    n = a + b + c
    return comb(n, a) * comb(n - a, b)

def count_length(L):
    """
    Count all 123-numbers of total length L.
    """
    total = 0

    for a in VALID:
        for b in VALID:
            c = L - a - b

            if c in VALID:
                total += multinomial(a, b, c)

    return total

# ------------------------------------------------------------
# Step 1: determine the answer length
# ------------------------------------------------------------

cumulative = 0
length = 0

while True:
    length += 1
    cnt = count_length(length)

    if cumulative + cnt >= TARGET:
        break

    cumulative += cnt

# Index inside this length block
k = TARGET - cumulative

# ------------------------------------------------------------
# Step 2: enumerate all admissible count triples
# ------------------------------------------------------------

triples = []

for a in VALID:
    for b in VALID:
        c = length - a - b

        if c in VALID:
            triples.append((a, b, c))

# ------------------------------------------------------------
# Step 3: lexicographic unranking
# ------------------------------------------------------------

answer_digits = []

for _ in range(length):

    for digit in "123":

        total = 0
        next_triples = []

        for a, b, c in triples:

            aa, bb, cc = a, b, c

            if digit == "1":
                if aa == 0:
                    continue
                aa -= 1

            elif digit == "2":
                if bb == 0:
                    continue
                bb -= 1

            else:
                if cc == 0:
                    continue
                cc -= 1

            total += multinomial(aa, bb, cc)
            next_triples.append((aa, bb, cc))

        if k > total:
            k -= total
        else:
            answer_digits.append(digit)
            triples = next_triples
            break

answer = int("".join(answer_digits))

print("F(n) =", answer)
print("Modulo =", answer % MOD)
```---
