 ## 解決策

 **答え:**`1097343`以下の整数が必要です$50{,}000{,}000$それは次のように書くことができます$$n = p_2^2 + p_3^3 + p_4^4$$どこ$p_2,p_3,p_4$素数です。 

複数の素数トリプルが同じ合計を生成する可能性があるため、主な課題は **個別の値をカウントする**ことです。 

## 1. 数学的分析

 限界にしましょう$$L = 50{,}000{,}000.$$すべての数字が必要です$$p^2 + q^3 + r^4 < L$$と$p,q,r$プライム。 

### ステップ 1: 検索を限定する

 すべての項は正であるため、各素数は特定の最大値まで生成するだけで済みます。 

4 乗の場合:$$r^4 < L \Rightarrow r < L^{1/4}.$$以来$$50{,}000{,}000^{1/4} \approx 84,$$必要なのは 83 までの素数だけです。 

キューブの場合:$$q^3 < L \Rightarrow q < L^{1/3}.$$以来$$50{,}000{,}000^{1/3} \approx 368,$$必要なのは 367 までの素数だけです。 

正方形の場合:$$p^2 < L \Rightarrow p < \sqrt{L}.$$以来$$\sqrt{50{,}000{,}000}\approx 7071,$$必要なのは 7071 までの素数だけです。 

したがって、検索スペースは実際には非常に小さいです。 

- 素数平方：約900個の素数、
 - 素数キューブ: 約70個の素数、
 - 素数の 4 乗: 約 20 個の素数。 

合計の組み合わせはおおよそ$$900 \times 70 \times 20 \approx 1.26\times10^6,$$これは計算上は簡単なことです。 

### ステップ 2: 重複を避ける

 異なるトリプルが同じ合計を生成する場合があります。 

例：$$p_1^2 + q_1^3 + r_1^4 = p_2^2 + q_2^3 + r_2^4.$$数を数えるのは一度だけです。 

セットは自動的に重複を削除するため、最もクリーンなアプローチは、すべての有効な合計を **セット** に保存することです。 

### ステップ 3: 効率的な生成

 事前計算:

 - 以下のすべての素数正方形$L$、
 - 以下のすべての素数キューブ$L$、
 - 以下のすべての素数 4 乗$L$。 

次にループします:$$s = a+b+c$$そしていつでもセットに挿入します$$s < L.$$リストはソートされているため、早期にプルーニングできます。 

- もし$a+b \ge L$、内部ループを停止し、
 - もし$a+b+c \ge L$、最も深いループを停止します。

 ## 2. Python の実装```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes <= n using Sieve of Eratosthenes."""
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            for multiple in range(p * p, n + 1, p):
                is_prime[multiple] = False

    return [i for i, prime in enumerate(is_prime) if prime]

# Generate primes only up to the needed maximum
max_prime = isqrt(LIMIT)
primes = sieve(max_prime)

# Precompute prime powers under LIMIT
prime_squares = [p**2 for p in primes if p**2 < LIMIT]
prime_cubes = [p**3 for p in primes if p**3 < LIMIT]
prime_fourths = [p**4 for p in primes if p**4 < LIMIT]

# Store distinct representable numbers
values = set()

for square in prime_squares:
    for cube in prime_cubes:
        partial = square + cube

        if partial >= LIMIT:
            break

        for fourth in prime_fourths:
            total = partial + fourth

            if total >= LIMIT:
                break

            values.add(total)

print(len(values))
```---
