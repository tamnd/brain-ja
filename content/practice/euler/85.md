[プロジェクト オイラー問題 85](https://projecteuler.net/problem=85)

 ## 解決策

 **答え:**`2772`グリッドに幅を持たせる$m$と高さ$n$、単位正方形で測定されます。 

グリッド内に形成できる異なる長方形の数を数えたいとします。 

# ステップ 1: 内の四角形を数える$m \times n$グリッド

 長方形は以下を選択することによって決定されます。 

- 2 本の異なる垂直グリッド線、
 - 2 本の異なる水平グリッド線。 

アン$m \times n$グリッドには次のものがあります。 

-$m+1$垂直グリッド線、
 -$n+1$水平グリッド線。 

したがって、長方形の数は$$\binom{m+1}{2}\binom{n+1}{2}.$$使用する$$\binom{k}{2}=\frac{k(k-1)}2,$$私たちは得ます$$R(m,n) = \frac{m(m+1)}2 \cdot \frac{n(n+1)}2.$$それで$$R(m,n)=\frac{m(m+1)n(n+1)}4.$$対象は次のとおりです。$$R(m,n)\approx 2{,}000{,}000.$$グリッドエリアを尋ねられます$$A=mn$$その四角形の数は 200 万に最も近いです。 

---

 # ステップ 2: 小さな例を検証する

 のために$3\times2$グリッド：$$R(3,2) = \frac{3\cdot4}{2}\cdot\frac{2\cdot3}{2} = 6\cdot3 = 18.$$これは問題文と一致します。 

---

 # ステップ 3: 戦略

 長方形の数はおおよそ次のように増加します$$\frac{m^2n^2}{4},$$したがって、ターゲットに近い値の次元は数十程度になります。 

妥当な範囲にわたるブルートフォース検索は完全に実行可能です。 

各ペアごとに$(m,n)$:

 1. 長方形の数を計算します。 
2. からの差を計算します$2{,}000{,}000$、
 3. 最適なグリッドを維持します。 

---

 # Pythonの実装```python
TARGET = 2_000_000

best_diff = float('inf')
best_area = None
best_dims = None

# Search reasonable grid sizes.
# 100 is safely large enough.
for m in range(1, 101):
    for n in range(1, 101):

        # Number of rectangles in an m x n grid
        rectangles = (m * (m + 1) * n * (n + 1)) // 4

        diff = abs(rectangles - TARGET)

        # Update best solution if closer
        if diff < best_diff:
            best_diff = diff
            best_area = m * n
            best_dims = (m, n)

print("Best dimensions:", best_dims)
print("Area:", best_area)
print("Rectangle count:",
      (best_dims[0] * (best_dims[0] + 1) *
       best_dims[1] * (best_dims[1] + 1)) // 4)
print("Difference:", best_diff)
```---

 # 最終検証

 - 長方形の数が非常に近い$2{,}000{,}000$。 
- 面積の大きさは周囲の寸法に対して妥当です$40$-$80$。 
- 対称性チェック:$36\times77$そして$77\times36$同じ結果が得られます。
