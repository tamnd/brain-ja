[プロジェクト オイラー問題 47](https://projecteuler.net/problem=47)

 ## 解決策

 **答え:**`134043`それぞれが正確に **4 つの異なる素因数**を持つ **4 つの連続する整数**の最初の実行を求めます。 

させて$\omega(n)$の異なる素因数の数を表す$n$。 

私たちは最小のものを望んでいます$n$そのような$$\omega(n)=\omega(n+1)=\omega(n+2)=\omega(n+3)=4.$$---

 # 数学的分析

 素因数分解に 4 つの異なる素数が含まれる場合、指数のサイズに関係なく、数値には 4 つの異なる素因数があります。 

例えば：$$644 = 2^2 \cdot 7 \cdot 23$$明確な素数がある$\{2,7,23\}$、つまり、まさに$3$異なる素因数。 

ブルートフォース戦略は次のようになります。 

1. すべての整数を因数分解します。 
2. 異なる素約数を数えます。 
3. 条件を満たす連続する 4 つの整数を検索します。 

ただし、単純に因数分解を繰り返すと時間がかかります。 

---

 ## 効率的なアイデア: 改良されたふるい

 各数値を個別に因数分解する代わりに、ふるいのようなアプローチを使用できます。 

配列を作成します。$$\text{count}[n]$$どこ`count[n]`の異なる素因数の数を保存します$n$。 

最初はすべてのエントリが$0$。 

整数を反復処理します$p$：

- もし`count[p] == 0`、 それから$p$プライムです。 
- の倍数ごとに$p$、そのカウントを増分します$1$。 

これが機能するのは、すべての素数がそれぞれの倍数に 1 回だけ寄与するためです。 

例:

 - プライム$2$すべての偶数をインクリメントします。 
- プライム$3$すべての倍数を増分します$3$。 
-など

 ふるいが終わったら:$$\text{count}[n] = \omega(n)$$あらゆる人にとって$n$。 

次に、次の値に等しい 4 つの連続するエントリをスキャンします。$4$。 

これは非常に効率的で、古典的なエラトステネスのふるいを反映しています。

 # Pythonの実装```python
def first_consecutive_integers(target_factors=4, consecutive=4, limit=200000):
    """
    Find the first integer in the first run of `consecutive`
    consecutive integers each having exactly `target_factors`
    distinct prime factors.
    """

    # count[n] will store the number of distinct prime factors of n
    count = [0] * (limit + 1)

    # Modified sieve
    for p in range(2, limit + 1):

        # If count[p] == 0, then p is prime
        if count[p] == 0:

            # Add this prime factor to all multiples of p
            for multiple in range(p, limit + 1, p):
                count[multiple] += 1

    # Search for consecutive integers
    streak = 0

    for n in range(2, limit + 1):

        if count[n] == target_factors:
            streak += 1

            if streak == consecutive:
                return n - consecutive + 1
        else:
            streak = 0

    return None

# Compute the Project Euler answer
answer = first_consecutive_integers()

print(answer)
```---
