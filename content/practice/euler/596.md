[プロジェクト オイラー問題 596](https://projecteuler.net/problem=596)

 ## 解決策

 **答え:**`734582049`させて$$T(r)=\#\{(x,y,z,t)\in \mathbb Z^4:\ x^2+y^2+z^2+t^2\le r^2\}.$$重要な観察は、これが 4 つの正方形の合計としての表現の累積数であるということです。 もし$r_4(n)$は次を満たす整数の 4 倍の数を示します。$$x^2+y^2+z^2+t^2=n,$$それから$$T(r)=\sum_{n=0}^{r^2} r_4(n).$$ヤコビの古典的な 4 平方定理により、$$r_4(n)=8\sum_{\substack{d\mid n\\4\nmid d}} d$$これは次のように書き換えることができます$$r_4(n)=8\sigma(n)-32\sigma(n/4),$$どこ$\sigma(n)$は除数の合計であり、$\sigma(n/4)=0$ない限り$4\mid n$。 

したがって、$N=r^2$、$$T(r) = 1 + 8\sum_{n\le N}\sigma(n) - 32\sum_{n\le N/4}\sigma(n).$$総和除数関数を定義する$$S(N)=\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac{N}{d}\right\rfloor.$$除数のグループ化を使用する (つまり、$\lfloor N/d\rfloor$は間隔で一定です)、これはおおよそ次のように計算できます。$O(\sqrt N)$時間：```python
MOD = 1_000_000_007

def summatory_sigma_mod(N):
    res = 0
    i = 1
    while i <= N:
        q = N // i
        j = N // q

        # sum of integers from i to j
        segment_sum = (i + j) * (j - i + 1) // 2

        res = (res + (q % MOD) * (segment_sum % MOD)) % MOD
        i = j + 1

    return res

def T_mod(r):
    N = r * r
    s1 = summatory_sigma_mod(N)
    s2 = summatory_sigma_mod(N // 4)

    return (1 + 8 * s1 - 32 * s2) % MOD

# Verification
print(T_mod(2))      # 89
print(T_mod(5))      # 3121
print(T_mod(100))    # 493490641
print(T_mod(10**4))  # 49348022079085897 mod MOD
print(T_mod(10**8))
```この導出により、指定されたチェックが正確に再現されます。 

-$T(2)=89$-$T(5)=3121$-$T(100)=493490641$-$T(10^4)=49348022079085897$問題文と一致します。 

したがって、

 **答え: 734582049**
