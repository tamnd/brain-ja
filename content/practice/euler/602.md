[プロジェクト オイラー問題 602](https://projecteuler.net/problem=602)

 ## 解決策

 **答え:**`269496760`させて$q=1-p$表の確率になります。 

係数を求めます$c(n,k)$の$p^k$多項式で$e(n,p)$。 

# ステップ 1: 期待値を導き出す

 アリスが持っていると仮定します$n$友達。 

ゲームは周期的に進行します。 

- アリスが投げる、
 - その後、各友達が 1 回ずつ投げます。 
- アリスが頭を得るまで繰り返します。 

アリスが最初の頭を取得したと仮定します。$m$以前の失敗。 

次に:

 - アリスプロデュース$m$尾の後に頭が 1 つ続き、
 - このイベントの確率:$$p^m q.$$その間$m$失敗したラウンド、各友達は正確にトスした$m$独立して回ります。 

どんな友人にも$i$、$$X_i \sim \text{Binomial}(m,q),$$それで$$\mathbb E[X_i]=mq.$$友達は独立しているので、$$\mathbb E\!\left[\prod_{i=1}^n X_i \,\middle|\, m\right] = (mq)^n.$$したがって$$e(n,p) = \sum_{m\ge0} p^m q (mq)^n = q^{n+1}\sum_{m\ge0} m^n p^m.$$なぜなら$q=1-p$、$$e(n,p) = (1-p)^{n+1}\sum_{m\ge0} m^n p^m.$$---

 # ステップ 2: オイラー多項式

 古典的なアイデンティティでは次のように述べられています。$$\sum_{m\ge0} m^n x^m = \frac{A_n(x)}{(1-x)^{n+1}},$$どこ$A_n(x)$はオイラー多項式です。 

したがって、$$e(n,p)=A_n(p).$$したがって、係数は$c(n,k)$は正確にはオイラー数です:$$c(n,k)=\left\langle {n \atop k} \right\rangle .$$標準的な明示的な式は次のとおりです。$$\boxed{ c(n,k) = \sum_{i=0}^{k} (-1)^i \binom{n+1}{i} (k-i)^n }.$$私たちは求められています$$c(10^7,4\cdot10^6)\pmod{10^9+7}.$$---

 # ステップ 3: 効率的なモジュラー計算

 以来$$10^9+7$$プライムであり、$n+1 < 10^9+7$、すべての二項係数を法を反復して計算できます。$M=10^9+7$。 

計算は次のとおりです。```python
MOD = 10**9 + 7

n = 10_000_000
k = 4_000_000

# modular inverses up to k+1
inv = [0] * (k + 2)
inv[1] = 1
for i in range(2, k + 2):
    inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

ans = 0
binom = 1   # C(n+1, 0)

for i in range(k + 1):

    term = pow(k - i, n, MOD)

    if i & 1:
        ans -= binom * term
    else:
        ans += binom * term

    ans %= MOD

    # Update:
    # C(n+1, i+1) from C(n+1, i)
    binom = (
        binom
        * (n + 1 - i)
        % MOD
        * inv[i + 1]
        % MOD
    )

print(ans % MOD)
```---

 # ステップ 4: 小さな例での検証

 のために$n=3$、$$e(3,p)=p^3+4p^2+p.$$私たちの式は次のようになります。$$c(3,1)=1,\qquad c(3,2)=4,\qquad c(3,3)=1,$$ステートメントと完全に一致します。
