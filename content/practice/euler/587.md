[プロジェクト オイラー問題 587](https://projecteuler.net/problem=587)

 ## 解決策

 **答え:**`2240`すべての円に半径を持たせる$1$。 

長方形の左下隅が下になるように配置します。$(0,0)$、幅あり$2n$と高さ$2$。 

ラインは次から始まります$(0,0)$に$(2n,2)$したがって、その方程式は次のようになります。$$y=\frac{x}{n}.$$最初の円の中心は次のとおりです$(1,1)$、方程式付き$$(x-1)^2+(y-1)^2=1.$$「凹型三角形」は、以下によって境界が定められた領域です。 

- ライン$y=x/n$、
 - 四分の一円弧、
 - および左端/下端。 

重要な観察は、最初の円のみが重要であるということです。 ラインは 2 番目の円に到達する前に最初の円を出るため、その後の円はすべて無関係です。 

---

 # 1. L 断面の面積

 L 断面は、単位正方形から 4 分の 1 円を引いたものです。 

したがって、その面積は$$A_L = 1-\frac{\pi}{4}.$$私たちはそう言われています$n=1$、凹型三角形はちょうどこの半分であり、これは一貫しています。 

---

 #2. 直線と円の交点

 同時に解決します$$y=\frac{x}{n}$$そして$$(x-1)^2+(y-1)^2=1.$$代わりの$y=x/n$:$$(x-1)^2+\left(\frac{x}{n}-1\right)^2=1.$$拡大する：$$x^2-2x+1+\frac{x^2}{n^2}-\frac{2x}{n}+1=1.$$それで$$x^2\left(1+\frac1{n^2}\right)-2x\left(1+\frac1n\right)+1=0.$$乗算$n^2$:$$(n^2+1)x^2-2n(n+1)x+n^2=0.$$関連するルートは$$x=\frac{n(n+1)-n\sqrt{2n}}{n^2+1}.$$より明確な方法は、線の傾きを使用してパラメータ化することです。 

交点を$(x_0,y_0)$、 どこ$y_0=x_0/n$。 

解くと得られるもの$$x_0=\frac{n(n+1-\sqrt{2n})}{n^2+1}, \qquad y_0=\frac{n+1-\sqrt{2n}}{n^2+1}.$$---

 #3. 凹型三角形の面積

 凹型三角形は次のもので構成されます。 

1. の線の下の三角形$0$に$x_0$、
 2. 円弧と弦の間の円セグメントを差し引きます。 

より便利な定式化:$$A(n) = \int_0^{x_0} \frac{x}{n}\,dx + \int_{x_0}^{1} \left( 1-\sqrt{1-(x-1)^2} \right)\,dx.$$最初の積分は$$\frac{x_0^2}{2n}.$$2番目に代入します$u=x-1$:$$\int_{x_0}^{1} \left(1-\sqrt{1-(x-1)^2}\right)\,dx = (1-x_0) - \int_{x_0-1}^{0}\sqrt{1-u^2}\,du.$$使用する$$\int \sqrt{1-u^2}\,du = \frac12\left(u\sqrt{1-u^2}+\arcsin u\right),$$簡略化すると、ほとんどのソリューションで使用されるコンパクトな式が得られます。$$A(n) = \frac12\left( \arcsin(1-y_0) + (1-y_0)\sqrt{2y_0-y_0^2} \right) + \frac{x_0^2}{2n} - x_0.$$ただし、数値的には、整数形式が最も簡単で安全です。 

私たちは最小限のものを求めます$n$そのような$$\frac{A(n)}{A_L}<0.001.$$---

 #4. Pythonの実装```python
import math

# Area of the L-section
L = 1 - math.pi / 4

def concave_area(n):
    # Intersection point between line and circle
    x = (n * (n + 1 - math.sqrt(2 * n))) / (n * n + 1)

    # Area under the line from 0 to x
    tri = x * x / (2 * n)

    # Integral of lower quarter-circle boundary
    u = x - 1

    # Integral of sqrt(1-u^2)
    F = 0.5 * (u * math.sqrt(1 - u * u) + math.asin(u))

    # Area between curve and top edge
    curved = (1 - x) + F

    return tri + curved

n = 1

while True:
    ratio = concave_area(n) / L

    if ratio < 0.001:
        print(n)
        break

    n += 1
```---
