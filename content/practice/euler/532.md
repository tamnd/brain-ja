[プロジェクト オイラー問題 532](https://projecteuler.net/problem=532)

 ## 解決策

 **答え:**`827306.56`球に半径を持たせる$1$ボットを最初は緯度円上に配置します。$$x^2+y^2 = 0.999^2,$$したがって、彼らの共通の寛容さは$$\theta_0=\arcsin(0.999).$$あれば$n$ボットの場合、隣接するボット間の経度の間隔は次のとおりです。$$\alpha=\frac{2\pi}{n}.$$対称性により、動作中、ボットは縮小する緯度円上に等間隔に配置されます。 

位置上の 1 つのボットの場合$P$、次のボットを追いかけます$Q$、瞬間速度は、大圏測地線に沿った単位接線ベクトルです。$P$に$Q$。 

標準的な球面幾何学計算により、進化方程式が得られます。$$\frac{d\theta}{dt} = -\frac{\cos\theta\,\sin(\alpha/2)} {\sqrt{1-\sin^2(\alpha/2)\sin^2\theta}}.$$どのボットも高速で移動するため、$1$、1 つのボットによって描画される長さは、$\theta=0$:$$L_n = \int_0^{\theta_0} \frac{\sqrt{1-\sin^2(\alpha/2)\sin^2\theta}} {\sin(\alpha/2)\cos\theta} \,d\theta .$$ここで最小値を計算します$n$そのような$L_n>1000$。 

Using high-precision numerical integration:```python
from mpmath import mp

mp.dps = 50

theta0 = mp.asin(mp.mpf('0.999'))

def length_per_bot(n):
    k = mp.sin(mp.pi / n)

    f = lambda th: (
        mp.sqrt(1 - k*k * mp.sin(th)**2)
        / (k * mp.cos(th))
    )

    return mp.quad(f, [0, theta0])

n = 1
while True:
    n += 1
    L = length_per_bot(n)
    if L > 1000:
        break

total = n * L

print(n)
print(L)
print(total)
```これにより、次の結果が得られます。 

-$n=827$- ボットごとの長さ$=1000.370689492285\ldots$- 全長$=827306.5602101203\ldots$のために$n=826$、ボットあたりの長さは$999.1610\ldots$、 それで$827$確かに最小限です。 

したがって、必要な全長は、小数点第 2 位に四捨五入して次のようになります。 

**答え: 827306.56**
