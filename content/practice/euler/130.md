[プロジェクト オイラー問題 130](https://projecteuler.net/problem=130)

 ## 解決策

 **答え:**`149253`させて$R(k)$再現ユニットを示します$$R(k)=\frac{10^k-1}{9}=111\ldots1$$（と$k$もの）。 任意の整数の場合$n$と互いに素である$10$、いくつか存在します$k$そのような$$R(k)\equiv 0 \pmod n.$$定義する$A(n)$そのような_最小_になる$k$。 

私たちは最初のものを求めます$25$**合成**整数$n$そのような$$A(n)\mid (n-1),$$そして$\gcd(n,10)=1$。 次に、それらを合計する必要があります。 

---

 #1. 数学的分析

 重要な所見は次のとおりです。$$R(k)\equiv 0 \pmod n \iff \frac{10^k-1}{9}\equiv 0 \pmod n.$$以来$\gcd(n,10)=1$、これは次と同等です$$10^k \equiv 1 \pmod{9n}$$（要因を除く）$3$、しかし使用$9n$一様に正しく動作します）。 

したがって$A(n)$は次の乗算順序です$10$モジュロ$9n$:$$A(n)=\operatorname{ord}_{9n}(10).$$コンポジットを探しています$n$満足のいく$$n-1 \equiv 0 \pmod{A(n)}.$$---

 ## 素数の重要な性質

 素数の場合$p>5$、$$A(p)\mid p-1$$乗算順序がグループ サイズを分割するため、フェルマーの小定理によって計算されます。 

この問題では、同じ性質を持つ稀な合成数が求められます。 

これらは、擬似素数のような動作に関連しています。 

---

 #2. 効率的なアルゴリズム

 整数をテストします$n$昇順で。 

条件:

 1.$n$複合材
 2.$\gcd(n,10)=1$3.$(n-1)\bmod A(n)=0$計算上の課題は評価です$A(n)$。 

---

 ## コンピューティング$A(n)$乗算順序を直接計算できます。 

から始める$$x = 10 \bmod (9n)$$そして繰り返し乗算します$10$:$$x \leftarrow (10x)\bmod (9n)$$それまで$x=1$。 

ステップ数は$A(n)$。 

必要な数が比較的少ないため、これは十分効率的です。

 #3. Pythonの実装```python
from math import gcd

# Simple primality test
def is_prime(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

# Compute A(n):
# the smallest k such that R(k) is divisible by n
def A(n):
    # modulus used for multiplicative order
    mod = 9 * n

    x = 10 % mod
    k = 1

    while x != 1:
        x = (x * 10) % mod
        k += 1

    return k

count = 0
total = 0
n = 1

while count < 25:
    n += 1

    # must be coprime to 10
    if gcd(n, 10) != 1:
        continue

    # only composite numbers
    if is_prime(n):
        continue

    an = A(n)

    if (n - 1) % an == 0:
        count += 1
        total += n
        print(count, n)

print("Answer =", total)
```---
