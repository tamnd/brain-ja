[プロジェクト オイラー問題 107](https://projecteuler.net/problem=107)

 ## 解決策

 **答え:**`259679`この問題は、古典的な **最小スパニング ツリー** 問題です。 

接続された重み付き無向グラフが与えられます。 

グラフの接続を維持しながら、できるだけ多くの冗長なエッジを削除したいと考えています。 

重要な事実は次のとおりです。 

> 接続されたすべてのサブグラフの中で、合計の重みが最小のものは **最小スパニング ツリー (MST)** です。 

したがって：$$\text{maximum saving} = \text{(total weight of original graph)} - \text{(weight of MST)}$$---

 # 数学的分析

 グラフに次のものがあるとします。 

-$V$頂点
 -$E$重み付けされた無向エッジ

 スパニングツリー:

 - すべての頂点を接続します。 
- サイクルが含まれていない、
 - 常に正確に$V-1$エッジ。 

接続が維持されている場合、これを超える余分なエッジは冗長です。 

したがって、次のように計算する必要があります。 

1. 元のネットワークの総重量
 2. 最小スパニングツリーの重み

 次に引き算します。 

---

 ## クラスカルのアルゴリズム

 標準の MST アルゴリズムは **Kruskal のアルゴリズム** です。 

### 原則

 1. すべてのエッジを重みを増加させて並べ替えます。 
2. サイクルを作成しない**最小のエッジを繰り返し追加します。 
3. 選択後停止$V-1$エッジ。 

サイクルを効率的に検出するために、**Disjoint Set Union (Union-Find)** 構造を使用します。 

---

 # 問題の小さな例

 元のグラフの重みは次のとおりです。$$243$$最適な接続ネットワークには重みがあります。$$93$$したがって、節約は次のようになります。$$243 - 93 = 150$$これはステートメントと一致します。

 # Pythonの実装```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        # Path compression
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a, b):
        ra = self.find(a)
        rb = self.find(b)

        if ra == rb:
            return False

        # Union by rank
        if self.rank[ra] < self.rank[rb]:
            self.parent[ra] = rb
        elif self.rank[ra] > self.rank[rb]:
            self.parent[rb] = ra
        else:
            self.parent[rb] = ra
            self.rank[ra] += 1

        return True

# Read the matrix
with open("network.txt") as f:
    rows = [line.strip().split(",") for line in f]

n = len(rows)

edges = []
total_weight = 0

# Extract undirected edges once (i < j)
for i in range(n):
    for j in range(i + 1, n):
        if rows[i][j] != "-":
            w = int(rows[i][j])
            edges.append((w, i, j))
            total_weight += w

# Kruskal's algorithm
edges.sort()

dsu = DSU(n)
mst_weight = 0

for w, u, v in edges:
    if dsu.union(u, v):
        mst_weight += w

saving = total_weight - mst_weight

print(saving)
```---
