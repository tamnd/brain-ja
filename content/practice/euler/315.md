[プロジェクト オイラー問題 315](https://projecteuler.net/problem=315)

 ## 解決策

 **答え:**`13625242`各 10 進数字を 7 セグメントのビットマスクで表します。 

数値のデジタルルートチェーン$n$は$$n \to s(n) \to s(s(n)) \to \cdots$$どこ$s(n)$は 10 進数の合計です$n$、一桁の数字に達するまで。 

例えば：$$137 \to 11 \to 2$$重要な点は、両方の時計の違いは、連続する表示間での遷移方法のみであるということです。 

---

 #1. 数学的分析

 ## 7 セグメント表現

 各数字を 7 ビット マスクとしてエンコードします。 

セグメント番号付けの使用$$\begin{matrix}  &0& \\ 1&&2\\  &3& \\ 4&&5\\  &6& \end{matrix}$$マスクは次のとおりです。 

| 数字 | マスク | セグメントが点灯 |
 | --- | --- | --- |
 | 0 | 0x77 | 6 |
 | 1 | 0x24 | 2 |
 | 2 | 0x5D | 5 |
 | 3 | 0x6D | 5 |
 | 4 | 0x2E | 4 |
 | 5 | 0x6B | 5 |
 | 6 | 0x7B | 6 |
 | 7 | 0x27 | 4 |
 | 8 | 0x7F | 7 |
 | 9 | 0x6F | 6 |

 点灯セグメント数は単純にポップカウント（設定ビット数）となります。 

---

 #サムの時計

 サムはいつもこう言います。 

1. 数値全体をオンにします。 
2. その後、番号全体をオフにします。 

したがって、表示された数値が$x$用途$L(x)$点灯セグメント、サムが費やす$$2L(x)$$そのディスプレイ上のトランジション。 

したがって、デジタルルートチェーンの場合$$x_0,x_1,\dots,x_k$$サムが使う$$S = 2\sum_{i=0}^k L(x_i)$$---

 #マックスの時計

 Max は、連続する表示間で異なるセグメントのみを変更します。 

もし$M(a)$そして$M(b)$が 2 つのディスプレイのビットマスクである場合、必要なトランジションの数は次のようになります。$$\operatorname{popcount}(M(a)\oplus M(b))$$XOR は状態が変化するセグメントを正確にマークするためです。 

したがって、マックスの合計は次のようになります。 

- 最初の番号をオンにします。 
- 連続する数値間の XOR 遷移、
 - 最終番号をオフにします。 

それで：$$T = L(x_0) + \sum_{i=0}^{k-1} \operatorname{popcount}(M(x_i)\oplus M(x_{i+1})) + L(x_k)$$---

 # 素数範囲

 すべての素数についてこれを評価する必要があります$$10^7 \le p < 2\cdot 10^7$$エラトステネスのふるいは簡単に十分に速いです。

 #2. Pythonの実装```python
from math import isqrt

# Seven-segment bitmasks
SEG = {
    0: 0x77,
    1: 0x24,
    2: 0x5D,
    3: 0x6D,
    4: 0x2E,
    5: 0x6B,
    6: 0x7B,
    7: 0x27,
    8: 0x7F,
    9: 0x6F,
}

def digit_sum(n):
    """Sum of decimal digits."""
    s = 0
    while n:
        s += n % 10
        n //= 10
    return s

def segments_of_number(n):
    """
    Pack the seven-segment masks of all digits into one integer.
    Each digit gets 8 bits.
    """
    result = 0
    shift = 0

    while n > 0:
        result |= SEG[n % 10] << shift
        n //= 10
        shift += 8

    return result

def sam_cost(n):
    """Transitions used by Sam."""
    segs = segments_of_number(n)
    cost = 2 * segs.bit_count()

    if n > 9:
        cost += sam_cost(digit_sum(n))

    return cost

def max_cost(n, previous=0):
    """Transitions used by Max."""
    segs = segments_of_number(n)

    # Only changed segments toggle
    cost = (segs ^ previous).bit_count()

    if n > 9:
        cost += max_cost(digit_sum(n), segs)
    else:
        # Turn final display off
        cost += segs.bit_count()

    return cost

def sieve(limit):
    """Return list of primes <= limit."""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    for p in range(2, isqrt(limit) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            for k in range(start, limit + 1, step):
                is_prime[k] = False

    return is_prime

A = 10_000_000
B = 20_000_000

prime = sieve(B)

answer = 0

for p in range(A, B + 1):
    if prime[p]:
        answer += sam_cost(p) - max_cost(p)

print(answer)
```---

 #3. コードのチュートリアル

 ##`segments_of_number`各桁は 1 つの 7 ビット マスクに寄与します。 

例えば：$$137$$になる$$M(7)\ |\ (M(3)\ll 8)\ |\ (M(1)\ll 16)$$これにより、表示全体を 1 つの XOR で比較できるようになります。 

---

 ##`sam_cost`表示される各値について:```python
2 * segs.bit_count()
```すべてのセグメントのオンとオフをカウントします。 

次に、桁の和を再帰的に計算します。 

のために$137$:

 -$137$:$2(2+5+4)=22$-$11$:$2(2+2)=8$-$2$:$2(5)=10$合計：$$40$$---

 ##`max_cost`ディスプレイ間の遷移回数は次のとおりです。```python
(segs ^ previous).bit_count()
```XOR は変更されたセグメントを正確に検出するためです。 

のために$137$：

- 空の$\to 137$：11
 -$137 \to 11$：7
 -$11 \to 2$：7
 -$2 \to$空: 5

 合計:$$30$$問題文と一致します。
