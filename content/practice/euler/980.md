 # 数学的分析

 タイトルが重要なヒントです: これは四元数グループです$Q_8$。 

地図$$x \mapsto i,\qquad y \mapsto j,\qquad z \mapsto k$$クォータニオン関係を使用する$$i^2=j^2=k^2=-1,\qquad ij=k,\quad jk=i,\quad ki=j,$$

$$ji=-k,\quad kj=-i,\quad ik=-j.$$---

 ## ステップ 1 — 許可される動きを解釈する

 ### 移動 A: 挿入$xx,yy,zz$例：$$xx \mapsto i^2=-1.$$したがって、これはクォータニオン値を次のように乗算します。$-1$。 

---

 ### 移動 B: 置き換える$$x\to yz,\qquad y\to zx,\qquad z\to xy$$なぜなら$$jk=i,\qquad ki=j,\qquad ij=k.$$したがって、四元数の値は変更されません。 

---

 ### Move C: 隣接する個別の文字を交換する

 例:$$xy \leftrightarrow yx.$$しかし$$ij=k,\qquad ji=-k.$$隣接する異なる文字を交換すると、値が次のように乗算されます。$-1$。 

---

 ## ステップ 2 — パリティ不変式

 各演算では、クォータニオン値の符号が 1 回だけ反転されます。 

- 挿入$aa$: を掛ける$-1$、
 - 置換: 値は変更されませんが、ステップパリティが変更されます。 
- スワップ: 乗算$-1$。 

値を含む空の文字列から開始する$1$、後:

 - 偶数のステップ数 → 値$1$、
 - 奇数のステップ数 → 値$-1$。 

したがって:

 > 四元数の積が次の場合、文字列は中立です。$1$。 

それは完全に中立性を特徴づけます。 

---

 # ステップ 3 — コンピューティング$F(N)$各ブロック$c(i)$長さがある$50$。 

クォータニオン値を定義します。$$q_i \in Q_8.$$それから$$c(i)c(j)\text{ is neutral} \iff q_i q_j = 1 \iff q_j = q_i^{-1}.$$したがって、各四元数要素に評価されるブロックの数を数えるだけで済みます。 

---

 # ステップ 4 — クォータニオン乗算テーブル

 8つの要素とは、$$1,-1,i,-i,j,-j,k,-k.$$それらの逆数は次のとおりです。$$1^{-1}=1,\quad (-1)^{-1}=-1,$$

$$i^{-1}=-i,\quad (-i)^{-1}=i,$$

$$j^{-1}=-j,\quad (-j)^{-1}=j,$$

$$k^{-1}=-k,\quad (-k)^{-1}=k.$$もし$cnt[g]$値を持つブロックの数です$g$、 それから$$F(N)=\sum_{g\in Q_8} cnt[g]\cdot cnt[g^{-1}].$$---

 # Pythonの実装```python
MOD = 888_888_883
A = 88_888_888
MULT = 8888

# Quaternion elements:
# 0:  1
# 1: -1
# 2:  i
# 3: -i
# 4:  j
# 5: -j
# 6:  k
# 7: -k

# Multiplication table
mul = [[0] * 8 for _ in range(8)]

names = ["1", "-1", "i", "-i", "j", "-j", "k", "-k"]
idx = {v: i for i, v in enumerate(names)}

base = {
    ("1", "1"): "1",
    ("1", "i"): "i",
    ("1", "j"): "j",
    ("1", "k"): "k",

    ("i", "1"): "i",
    ("j", "1"): "j",
    ("k", "1"): "k",

    ("i", "i"): "-1",
    ("j", "j"): "-1",
    ("k", "k"): "-1",

    ("i", "j"): "k",
    ("j", "k"): "i",
    ("k", "i"): "j",

    ("j", "i"): "-k",
    ("k", "j"): "-i",
    ("i", "k"): "-j",
}

def qmul(a, b):
    sa = -1 if a.startswith("-") else 1
    sb = -1 if b.startswith("-") else 1

    aa = a[1:] if a.startswith("-") else a
    bb = b[1:] if b.startswith("-") else b

    r = base[(aa, bb)]

    sr = -1 if r.startswith("-") else 1
    rr = r[1:] if r.startswith("-") else r

    sign = sa * sb * sr

    if rr == "1":
        return "1" if sign == 1 else "-1"

    return rr if sign == 1 else "-" + rr

# Build numeric multiplication table
for i, a in enumerate(names):
    for j, b in enumerate(names):
        mul[i][j] = idx[qmul(a, b)]

# map:
# x -> i
# y -> j
# z -> k
letter_map = [2, 4, 6]

N = 10**6

counts = [0] * 8
a = A

for _ in range(N):

    q = 0  # quaternion value starts at 1

    for _ in range(50):
        b = a % 3
        q = mul[q][letter_map[b]]
        a = (MULT * a) % MOD

    counts[q] += 1

inverse = [0, 1, 3, 2, 5, 4, 7, 6]

answer = 0
for g in range(8):
    answer += counts[g] * counts[inverse[g]]

print(answer)
```---

 ## 最終的なカウント

 ペアは次の場合に寄与します。$$q_i q_j = 1.$$したがって：```python

```すべてのグループ要素に対して$g$。
