[プロジェクト オイラー問題 815](https://projecteuler.net/problem=815)

 ## 解決策

 **答え:**`54.12691621`プロセスの状態を次のように記述します。 

-$u$: まだ見られていない値の数、
 -$a$: サイズの積み重ね数$1$、
 -$b$: サイズの積み重ね数$2$、
 -$c$: サイズの積み重ね数$3$。 

すると、現在の空ではない山の数は次のようになります。$$s=a+b+c.$$当初の状態は、$$(u,a,b,c)=(n,0,0,0).$$サイズに達すると山は消えます$4$。 

---

 #1. 数学的分析

 状態で$(u,a,b,c)$、残りのカードは$$4u+3a+2b+c.$$確かに:

 - それぞれの目に見えない価値が貢献します$4$カード、
 - サイズ 1 の各パイルが貢献します$3$残りのカード、
 - サイズ 2 の各パイルが貢献します$2$、
 - サイズ 3 の各パイルが貢献します$1$。 

遷移は次のとおりです。 

### 新しい値を描画する

 確率$$\frac{4u}{4u+3a+2b+c}.$$状態の変化:$$(u,a,b,c)\to(u-1,a+1,b,c).$$杭の数は次のように増加します$1$。 

---

 ### サイズ 1 のパイルを拡張する

 確率$$\frac{3a}{4u+3a+2b+c}.$$遷移：$$(u,a,b,c)\to(u,a-1,b+1,c).$$杭の数は変わりません。 

---

 ### サイズ 2 の杭を拡張する

 確率$$\frac{2b}{4u+3a+2b+c}.$$遷移：$$(u,a,b,c)\to(u,a,b-1,c+1).$$杭の数は変わりません。 

---

 ### サイズ 3 の山を完成させる

 確率$$\frac{c}{4u+3a+2b+c}.$$遷移：$$(u,a,b,c)\to(u,a,b,c-1).$$杭の数は次のように減少します$1$。 

---

 プロセス全体で予想される同時杭の最大数を計算する必要があります。 

最もクリーンなアプローチは、次の動的プログラミングです。$$(u,a,b,c,m),$$どこ$m$これまでに確認された杭の最大数です。 

すべてを通じて確率を伝播します$4n$カードを引く。 

最終的にはすべての状態が$(0,0,0,0,m)$、 それで$$E(n)=\sum_m m\Pr(M=m).$$---

 #2. Pythonの実装```python
from collections import defaultdict

def expected_max_piles(n):
    # state = (u, a, b, c, m)
    # u = unseen values
    # a = piles of size 1
    # b = piles of size 2
    # c = piles of size 3
    # m = maximum number of piles seen so far

    dp = {(n, 0, 0, 0, 0): 1.0}

    # There are exactly 4n card draws
    for _ in range(4 * n):

        nxt = defaultdict(float)

        for (u, a, b, c, m), prob in dp.items():

            remaining = 4*u + 3*a + 2*b + c
            piles = a + b + c

            # Draw a new value
            if u:
                new_piles = piles + 1
                nxt[(u-1, a+1, b, c,
                     max(m, new_piles))] += prob * (4*u / remaining)

            # Extend a size-1 pile
            if a:
                nxt[(u, a-1, b+1, c, m)] += prob * (3*a / remaining)

            # Extend a size-2 pile
            if b:
                nxt[(u, a, b-1, c+1, m)] += prob * (2*b / remaining)

            # Complete a size-3 pile
            if c:
                nxt[(u, a, b, c-1, m)] += prob * (c / remaining)

        dp = nxt

    # Expected value of the maximum
    ans = 0.0

    for (u, a, b, c, m), prob in dp.items():
        ans += m * prob

    return ans

# Check the example
print(f"{expected_max_piles(2):.8f}")

# Compute E(60)
print(f"{expected_max_piles(60):.8f}")
```---

 #3. コードのチュートリアル

 ## 初期化```python
dp = {(n, 0, 0, 0, 0): 1.0}
```最初に:

 - すべて$n$価値観は目に見えないものであり、
 - 杭は存在しません。 
- これまでの最大パイル数は$0$。 

---

 ## 状態遷移

 状態ごとに次のように計算します。```python
remaining = 4*u + 3*a + 2*b + c
```それはデッキに残っているカードの数です。 

次に、考えられる 4 つのカード タイプに従って確率質量を分配します。 

---

 ## 最大値を追跡する

 新しい杭が作成されるとき:```python
new_piles = piles + 1
max(m, new_piles)
```実行最大値を更新します。 

---

 ## 最終的な期待値

 結局のところ$4n$カードが処理され、すべてのパスが終了します。 

次のように計算します。```python
ans += m * prob
```それはまさに$$E(M)=\sum_m m\,P(M=m).$$---

 #4. 検証

 のために$n=2$、プログラムは与えます$$E(2)=1.97142857,$$問題ステートメントで指定された値と一致します。 

のために$n=60$、計算は安定しており、それをわずかに下回る値が生成されます。$60$、予想通り。
