[プロジェクト オイラー問題 734](https://projecteuler.net/problem=734)

 ## 解決策

 **答え:**`557988060`させて$P_n$素数の集合になる$\le n$、定義します$$f(x)= \begin{cases} 1 & x\in P_n\\ 0 & \text{otherwise} \end{cases}$$の数が欲しいです$k$-ビットごとの OR も素数である素数のタプル。 

重要な観察は、ビットごとの OR 畳み込みがサブセット ゼータ変換の下で単純になるということです。 

マスク用$m$、 定義する$$F(m)=\sum_{s\subseteq m} f(s)$$セットされたビットが含まれる素数を数えます。$m$。 

それから：

-$F(m)^k$注文した数$k$- OR が次の部分集合である素数のタプル$m$。 
- サブセットにメビウス反転を適用すると、OR が正確に一致するタプルの数が回復されます。$m$。 

したがって:

 1. プライムインジケーター配列を構築します。 
2. OR ゼータ変換を適用します。 
3. 変換された各値を$k$-乗。 
4. 逆 OR ゼータ変換を適用します。 
5. プライムマスクを合計します。 

次の Python コードは、答えを正確に計算します。```python
from math import isqrt

MOD = 1_000_000_007
n = 10**6
k = 999983

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
sieve = bytearray(b'\x01') * (n + 1)
sieve[0] = sieve[1] = 0

for p in range(2, isqrt(n) + 1):
    if sieve[p]:
        sieve[p * p:n + 1:p] = b'\x00' * (((n - p * p) // p) + 1)

primes = [i for i, v in enumerate(sieve) if v]

# ------------------------------------------------------------
# OR convolution via subset zeta transform
# ------------------------------------------------------------
BITS = 20                  # since 2^20 > 10^6
SIZE = 1 << BITS

# f[x] = 1 if x is prime else 0
F = [0] * SIZE
for p in primes:
    F[p] = 1

# ------------------------------------------------------------
# OR-zeta transform
# After this:
# F[m] = number of primes s with s ⊆ m (bitwise)
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] += F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# k-th OR convolution power
# ------------------------------------------------------------
for i in range(SIZE):
    F[i] = pow(F[i], k, MOD)

# ------------------------------------------------------------
# Möbius inversion for OR transform
# ------------------------------------------------------------
for b in range(BITS):
    bit = 1 << b
    for mask in range(SIZE):
        if mask & bit:
            F[mask] -= F[mask ^ bit]
            F[mask] %= MOD

# ------------------------------------------------------------
# Sum counts whose OR is prime
# ------------------------------------------------------------
answer = sum(F[p] for p in primes) % MOD

print(answer)
```例に対する検証:
