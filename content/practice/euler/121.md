[プロジェクト オイラー問題 121](https://projecteuler.net/problem=121)

 ## 解決策

 **答え:**`2269`ゲームを長続きさせましょう$n=15$曲がる。 

ターン中$k$(から始まる$k=1$):

 - 描画する前に、バッグには次のものが含まれています$1$ブルーディスクと$k$赤いディスク、
 - したがって、青を引く確率は次のようになります。$$\frac{1}{k+1},$$赤を引く確率は$$\frac{k}{k+1}.$$青のドローの数が赤のドローの数よりも厳密に大きい場合、プレーヤーの勝ちです。 

のために$15$つまり、少なくとも$8$青いディスク。 

---

 # 数学的分析

 定義:

 -$B_k$: 順番に青を描く$k$、
 -$R_k$: 順番に赤を描く$k$。 

特定の結果シーケンスが発生する確率は、各ターンの確率の積です。 

重要な簡素化は、共通の分母を取り除くことで得られます。$$\prod_{k=1}^{15} (k+1)=16!.$$実際、すべての結果の確率には分母があります。$16!$。 

セットなら$S\subseteq\{1,\dots,15\}$は青が描画されるターンを表し、次のようになります。 

- 青は分子に寄与します$1$、
 - ターン中は赤$k$分子に寄与する$k$。 

したがって、次のようになります。$$P(S)=\frac{\prod_{k\notin S} k}{16!}.$$以来$$\prod_{k=1}^{15} k = 15!,$$書き換えることができます:$$P(S)=\frac{15!}{16!\prod_{k\in S}k} =\frac{1}{16\prod_{k\in S}k}.$$したがって、合計の当選確率は次のようになります。$$P(\text{win}) = \sum_{\substack{S\subseteq\{1,\dots,15\}\\ |S|\ge 8}} \frac{1}{16\prod_{k\in S}k}.$$ただし、動的計画法を使用してこれを計算する方が計算的には簡単です。 

---

 # 賞金の資金条件

 銀行家が賞金の資金を割り当てたとします。$F$ポンド。 

- プレーヤーはプレイするために £1 を支払います。 
- 支払い$F$返された£1が含まれます。 

予想される支払い額:$$F\cdot P(\text{win}).$$予想される損失を回避するには:$$F\cdot P(\text{win}) \le 1.$$したがって、最大許容整数賞金資金は次のようになります。$$\left\lfloor \frac{1}{P(\text{win})} \right\rfloor.$$したがって、私たちのタスクは正確な勝利確率を計算することになります。 

---

 # 動的プログラミングのアプローチ

 しましょう:$$dp[j]$$正確に持つ確率の合計を表します$j$青はいくつかのターンを処理した後に描画します。 

最初に:$$dp[0]=1.$$順番に$k$:

 - 青の確率$= \frac1{k+1}$、
 - 赤の確率$= \frac{k}{k+1}$。 

逆方向に更新します。$$dp[j] = dp[j]\cdot \frac{k}{k+1} + dp[j-1]\cdot \frac1{k+1}.$$15 ターン後、次の確率を合計します。$j\ge 8$。 

---

 # Pythonの実装```python
from fractions import Fraction

# Number of turns
N = 15

# dp[j] = probability of getting exactly j blue discs
dp = [Fraction(0, 1) for _ in range(N + 1)]
dp[0] = Fraction(1, 1)

# Process each turn
for k in range(1, N + 1):

    p_blue = Fraction(1, k + 1)
    p_red = Fraction(k, k + 1)

    # Update backwards to avoid overwriting needed values
    for j in range(k, 0, -1):
        dp[j] = dp[j] * p_red + dp[j - 1] * p_blue

    dp[0] *= p_red

# Need strictly more blue than red
# For 15 turns, that means at least 8 blues
win_probability = sum(dp[8:])

# Maximum prize fund
prize_fund = int(Fraction(1, 1) / win_probability)

print(win_probability)
print(prize_fund)
```---

 # 4ターン例での検証

 のために$N=4$、同じコードは次のようになります:$$P(\text{win})=\frac{11}{120},$$問題文と一致します。 

それから：$$\left\lfloor \frac{120}{11} \right\rfloor = 10,$$例とも一致します。 

したがって、メソッドは検証されます。

 # 最終計算

 のために$N=15$、正確な当選確率は$$\frac{9219406943}{20922789888000}.$$したがって：$$\left\lfloor \frac{20922789888000}{9219406943} \right\rfloor = 2269.$$これは合理的です:

 - 当選確率は約$0.0004406$、
 - したがって、逆数は近似されます$2269.4$、
 - したがって、最大の安全な整数の支払いは次のようになります。$2269$。
