[プロジェクト オイラー問題 940](https://projecteuler.net/problem=940)

 ## 解決策

 **答え:**`969134784`させて$$A(m,n)=\alpha\, r_1^m s_1^n+\beta\, r_2^m s_2^n$$ここで、反復によって定数と基数が決まります。 

から$$A(m+1,n)=A(m,n+1)+A(m,n)$$私たちは得ます$$r=s+1.$$から$$A(m+1,n+1)=2A(m+1,n)+A(m,n)$$私たちは得ます$$rs=2r+1.$$置き換える$r=s+1$:$$s(s+1)=2(s+1)+1$$

$$s^2-s-3=0.$$したがって、$$s_{1,2}=\frac{1\pm\sqrt{13}}2, \qquad r_{1,2}=1+s_{1,2}=\frac{3\pm\sqrt{13}}2.$$使用する$A(0,0)=0$そして$A(0,1)=1$、$$A(m,n)=\frac{r_1^m s_1^n-r_2^m s_2^n}{\sqrt{13}}.$$したがって$$S(k) = \sum_{i=2}^k\sum_{j=2}^k A(f_i,f_j) = \frac{ \left(\sum r_1^{f_i}\right)\left(\sum s_1^{f_j}\right) - \left(\sum r_2^{f_i}\right)\left(\sum s_2^{f_j}\right) }{\sqrt{13}}.$$すべてをモジュロで計算します$$M=1123581313$$二次環の内側$\mathbb Z_M[\sqrt{13}]$、数値をペアとして表します$$a+b\sqrt{13}.$$共役減算では、正確に次の係数が残ります。$\sqrt{13}$。 

Python コード:```python
MOD = 1123581313

# arithmetic in Z_MOD[sqrt(13)]
def add(x, y):
    return ((x[0] + y[0]) % MOD,
            (x[1] + y[1]) % MOD)

def mul(x, y):
    a, b = x
    c, d = y
    return ((a * c + 13 * b * d) % MOD,
            (a * d + b * c) % MOD)

def power(x, n):
    r = (1, 0)
    while n:
        if n & 1:
            r = mul(r, x)
        x = mul(x, x)
        n >>= 1
    return r

inv2 = pow(2, -1, MOD)

# s1 = (1 + sqrt(13))/2
# r1 = (3 + sqrt(13))/2
s1 = ((1 * inv2) % MOD, inv2)
r1 = ((3 * inv2) % MOD, inv2)

# Fibonacci numbers
fib = [0, 1]
for _ in range(2, 51):
    fib.append(fib[-1] + fib[-2])

T = (0, 0)
U = (0, 0)

for i in range(2, 51):
    T = add(T, power(r1, fib[i]))
    U = add(U, power(s1, fib[i]))

E = mul(T, U)

# If E = a + b*sqrt(13),
# then (E - conjugate(E))/sqrt(13) = 2b
answer = (2 * E[1]) % MOD

print(answer)
```検証:
