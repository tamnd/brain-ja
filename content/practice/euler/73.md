 ## 解決策

 **答え:**`7295372`## 1. 数学的分析

 **換算された固有分数**の数が必要です$$\frac{n}{d}$$そのような$$\frac13 < \frac nd < \frac12 \quad\text{and}\quad \gcd(n,d)=1,$$すべての分母に対して$$d \le 12000.$$### ステップ 1: 各分母の分子範囲を見つける

 分母を固定する$d$。 必要なものは次のとおりです。$$\frac13 < \frac nd < \frac12.$$を乗算する$d$:$$\frac d3 < n < \frac d2.$$したがって、有効な分子は整数です$$\left(\left\lfloor \frac d3 \right\rfloor + 1\right) \le n \le \left\lceil \frac d2 \right\rceil - 1.$$しかし、次のことも要求する必要があります。$$\gcd(n,d)=1.$$したがって、各分母について$d$、整数を数えます$n$この区間では互いに素である$d$。 

---

 ### ステップ 2: 直接計数アプローチ

 簡単なアルゴリズムは次のとおりです。 

分母ごとに$d=2,3,\dots,12000$:

 1. 可能な最小の分子を計算します。$$n_{\min}=\left\lfloor \frac d3 \right\rfloor +1$$2. 可能な最大の分子を計算します。$$n_{\max}=\left\lfloor \frac{d-1}{2}\right\rfloor$$3. すべての整数について$n\in[n_{\min},n_{\max}]$:

 - かどうかを確認してください$$\gcd(n,d)=1.$$- 「はい」の場合は、数えてください。 

検索スペースは次の理由から管理可能です。 

-$d \le 12000$- 平均間隔の長さは約$d/6$総作業量はおよそ数千万回の gcd チェックですが、Python はこれを快適に処理します。 

より洗練された数論的ソリューションでは **フェアリー数列** またはメビウス反転カウントが使用されますが、総当たりの gcd アプローチはすでに十分に高速です。

 ## 2. Python の実装```python
from math import gcd

def count_fractions(limit):
    total = 0

    # Check every denominator
    for d in range(2, limit + 1):

        # Numerators strictly between 1/3 and 1/2
        n_min = d // 3 + 1
        n_max = (d - 1) // 2

        # Count reduced fractions
        for n in range(n_min, n_max + 1):
            if gcd(n, d) == 1:
                total += 1

    return total

# Problem answer
result = count_fractions(12000)
print(result)
```---
