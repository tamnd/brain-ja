 ## 解決策

 **答え:**`44680`各桁を使用して形成される素数の_セット_の数を数えなければなりません$1,\dots,9$まさに一度。 

例えば、$$\{2,5,47,89,631\}$$は次の理由から有効です。 

- すべての要素が素数である、
 - 数字$1$を通して$9$全体で 1 回だけ使用され、
 - これは**セット**であるため、順序は関係ありません。 

課題は、このような個別のセットをすべて数えることです。

 # 数学的分析

 ## 1. 素数に関する観察

 数字を連結して整数を形成します。 

個別の数字から形成された数値は、次の場合にのみ素数になります。 

- 偶数桁で終わることは**ありません**、
 - では終わりません**$5$、
 - それは割り切れません$3$。 

3 で割り切れる観察は特に重要です。 

任意の整数の割り算$3$桁の合計に依存します。 

数字$1$を通して$9$合計して$$1+2+\cdots+9 = 45.$$以来$45\equiv 0 \pmod 3$、_ 連結全体 _ は次の数で割り切れます。$3$。 

したがって、すべての数字を 1 つの素数に入れることはできません。 

より一般的には:

 - 桁の合計が以下で割り切れる桁のサブセット$3$素数を形成することはできません（数値を除く）$3$自体）。 

これにより、検索スペースが大幅に削減されます。

 #4. セットの重複を避ける

 素数を再帰的に選択するとします。 

恣意的な順序を許可すると、$$\{2,5,47\}$$は次のようにカウントされます:

 -$2,5,47$-$2,47,5$-$5,2,47$-など

 これを防ぐために、素数を昇順に選択する必要があります。 

したがって、各セットは 1 回だけ生成されます。

 # Pythonの実装```python
from itertools import permutations
from math import isqrt

# ------------------------------------------------------------
# Primality test
# ------------------------------------------------------------

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    if n % 3 == 0:
        return n == 3

    r = isqrt(n)
    f = 5
    while f <= r:
        if n % f == 0 or n % (f + 2) == 0:
            return False
        f += 6
    return True

# ------------------------------------------------------------
# Generate all usable primes
# ------------------------------------------------------------

digits = '123456789'

# primes_by_mask[mask] = list of primes using exactly those digits
primes = []

for length in range(1, 10):
    for perm in permutations(digits, length):

        # quick divisibility-by-3 pruning
        digit_sum = sum(ord(c) - ord('0') for c in perm)
        if digit_sum % 3 == 0:
            # only possible prime is 3 itself
            if not (length == 1 and perm[0] == '3'):
                continue

        # last digit cannot be even or 5
        if perm[-1] in '24568':
            if not (length == 1 and perm[0] in '25'):
                continue

        n = int(''.join(perm))

        if is_prime(n):

            # build bitmask
            mask = 0
            for ch in perm:
                mask |= 1 << (ord(ch) - ord('1'))

            primes.append((n, mask))

# ------------------------------------------------------------
# Sort primes so recursive generation is canonical
# ------------------------------------------------------------

primes.sort()

FULL_MASK = (1 << 9) - 1

answer = 0

# ------------------------------------------------------------
# Backtracking search
# ------------------------------------------------------------

def search(start_index, used_mask):
    """
    Choose increasing primes whose digit masks are disjoint
    until all digits are used.
    """
    global answer

    if used_mask == FULL_MASK:
        answer += 1
        return

    for i in range(start_index, len(primes)):
        p, mask = primes[i]

        # disjoint digit sets only
        if used_mask & mask:
            continue

        search(i + 1, used_mask | mask)

search(0, 0)

print(answer)
```---
