[プロジェクト オイラー問題 86](https://projecteuler.net/problem=86)

 ## 解決策

 **答え:**`1818`直方体の辺の長さを整数にします$$a \le b \le c.$$サーフェスに沿った、一方の角から反対側の角までの最短パスが整数の長さになるようにします。 

重要な観察は、直方体を展開すると、最短パスの候補が次の 3 つになるということです。$$\sqrt{(a+b)^2+c^2},\qquad \sqrt{(a+c)^2+b^2},\qquad \sqrt{(b+c)^2+a^2}.$$以来$a \le b \le c$、 我々は持っています$$a+b \le a+c \le b+c,$$したがって、最も短い候補は常に$$\sqrt{(a+b)^2+c^2}.$$したがって、次の整数解が必要です。$$(a+b)^2 + c^2 = k^2$$ある整数に対して$k$。 

---

 #1. 数学的分析

 定義する$$s = a+b.$$それからピタゴラスの三倍数を求めます$$s^2 + c^2 = k^2,$$制約付き$$1 \le a \le b \le c.$$固定最大辺長の場合$M$、すべての直方体を次のように数えます。$$c \le M.$$したがって、それぞれについて$c$、すべての値をカウントします$s$そのような$$s^2 + c^2$$は完全な正方形です。 

次にペアの数を数えます$(a,b)$満足する$$a+b=s,\qquad 1\le a\le b\le c.$$---

 ## カウント中$(a,b)$ペア

 固定用$s$そして$c$:$$a+b=s,\qquad a\le b,\qquad b\le c.$$なぜなら$b=s-a$、$$a \le s-a \quad\Rightarrow\quad a \le \frac{s}{2}.$$また、$$s-a \le c \quad\Rightarrow\quad a \ge s-c.$$したがって、$$\max(1,s-c)\le a \le \left\lfloor \frac{s}{2}\right\rfloor.$$したがって、有効なペアの数は次のようになります。$$\left\lfloor \frac{s}{2}\right\rfloor-\max(1,s-c)+1.$$これは、標準的なコンパクト形式に簡略化されます。 

- もし$s\le c$:$$\#=\left\lfloor \frac{s}{2}\right\rfloor.$$- もし$s>c$:$$\#=\left\lfloor \frac{s}{2}\right\rfloor-(s-c)+1.$$---

 #2. 効率的なアルゴリズム

 インクリメントします$M=c$一度に一つずつ。 

新しいものごとに$c$:

 1. ループスルー$$s=2,3,\dots,2c$$なぜなら$a,b\le c$。 
2. かどうかを確認します。$$s^2+c^2$$は完全な正方形です。 
3. 「はい」の場合、有効な数を追加します。$(a,b)$ペア。 

累計を超えたら終了$1,000,000$。 

複雑さはおおよそ次のとおりです$$O(M^2),$$答えはすぐ近くにあるので、これは十分速いです$1800$。 

---

 #3. Pythonの実装```python
from math import isqrt

TARGET = 1_000_000

count = 0
M = 0

while count <= TARGET:
    M += 1

    # s = a + b
    for s in range(2, 2 * M + 1):

        # Check whether s^2 + M^2 is a perfect square
        n = s * s + M * M
        r = isqrt(n)

        if r * r == n:

            # Count valid (a,b) pairs
            if s <= M:
                count += s // 2
            else:
                count += (s // 2) - (s - M) + 1

print(M)
```---
