[プロジェクト オイラー問題 487](https://projecteuler.net/problem=487)

 ## 解決策

 **答え:**`106650212746`させて$$f_k(n)=\sum_{i=1}^n i^k, \qquad S_k(n)=\sum_{i=1}^n f_k(i).$$必要です$$\sum_{p} \left(S_{10000}(10^{12}) \bmod p\right),$$どこ$p$内のすべての素数を実行します$$2\cdot 10^9 < p < 2\cdot 10^9+2000.$$このような素数は 100 個あります。 

---

 #1. 数学的分析

 ## ステップ 1: 書き換える$S_k(n)$定義を展開します。$$S_k(n)=\sum_{i=1}^n \sum_{j=1}^i j^k.$$合計の順序を入れ替えます。$$S_k(n)=\sum_{j=1}^n (n-j+1)j^k.$$したがって、$$S_k(n) = (n+1)\sum_{j=1}^n j^k-\sum_{j=1}^n j^{k+1}.$$それで：$$S_k(n)=(n+1)f_k(n)-f_{k+1}(n).$$これはすぐに次のことを示します$S_k(n)$は多項式です$n$程度の$k+2$。 

のために$k=10000$、程度は$10002$。 

---

 ## ステップ 2: 素数を法とする多項式補間

 固定素数の場合$p$、 定義する$$P(n)=S_{10000}(n)\pmod p.$$以来$P(n)$次数の多項式です$10002$、その値を知っている$$0,1,2,\dots,10002$$完全にモジュロで決定します$p$。 

ここのすべての素数は満たすので、$$p > 2\cdot 10^9 \gg 10002,$$ラグランジュ補間のすべての階乗分母は可逆剰余です$p$。 

したがって、評価できます$P(10^{12})$モジュロ$p$連続した点に標準のラグランジュ補間を使用します。 

---

 ## ステップ 3: 補間テーブルを構築する

 We compute sequentially:$$f(i)=f(i-1)+i^{10000},$$その後$$S(i)=S(i-1)+f(i).$$店$$y_i=S(i)\pmod p$$のために$0\le i\le10002$。 

次に、次の多項式を評価します。$x=10^{12}\bmod p$。 

素数ごとの複雑さ:

 -$10002$べき乗モジュラー、
 -$O(10002)$補間。 

素数が 100 個しかないので、これは簡単に実現可能です。 

---

 #2. Pythonの実装```python
from sympy import primerange

K = 10000
N = 10**12
D = K + 2   # degree of S_k(n)

# ------------------------------------------------------------
# Lagrange interpolation on points x = 0,1,2,...,D
# y[i] = polynomial value at i
# Evaluates polynomial at x modulo mod.
# ------------------------------------------------------------
def lagrange(y, x, mod):
    n = len(y) - 1

    # If x is already one of the known points
    if x <= n:
        return y[x] % mod

    # factorials
    fact = [1] * (n + 1)
    for i in range(1, n + 1):
        fact[i] = fact[i - 1] * i % mod

    # inverse factorials
    ifact = [1] * (n + 1)
    ifact[n] = pow(fact[n], mod - 2, mod)

    for i in range(n, 0, -1):
        ifact[i - 1] = ifact[i] * i % mod

    # prefix products:
    # pre[i] = (x)(x-1)...(x-(i-1))
    pre = [1] * (n + 2)
    for i in range(n + 1):
        pre[i + 1] = pre[i] * (x - i) % mod

    # suffix products:
    # suf[i] = (x-i)(x-(i+1))...(x-n)
    suf = [1] * (n + 2)
    for i in range(n, -1, -1):
        suf[i] = suf[i + 1] * (x - i) % mod

    ans = 0

    for i, yi in enumerate(y):
        # numerator product excluding (x-i)
        num = pre[i] * suf[i + 1] % mod

        # denominator inverse
        den = ifact[i] * ifact[n - i] % mod

        # sign from (-1)^(n-i)
        if (n - i) & 1:
            den = mod - den

        ans = (ans + yi * num % mod * den) % mod

    return ans

def compute():
    total = 0

    # primes in (2e9, 2e9+2000)
    primes = list(primerange(2_000_000_000, 2_000_002_000))

    for p in primes:

        # y[i] = S_K(i) mod p
        y = [0] * (D + 1)

        fk = 0
        sk = 0

        for i in range(1, D + 1):
            fk = (fk + pow(i, K, p)) % p
            sk = (sk + fk) % p
            y[i] = sk

        value = lagrange(y, N % p, p)

        total += value

    return total

print(compute())

 ## 多項式値の構築```python
fk = (fk + pow(i, K, p)) % p
```維持します$$f_K(i)=\sum_{j=1}^i j^K \pmod p.$$それから```python
sk = (sk + fk) % p
```維持する$$S_K(i)=\sum_{t=1}^i f_K(t)\pmod p.$$これらの値は補間のために保存されます。 

---

 ## ラグランジュ補間

 なぜなら多項式の次数は$10002$、の値$$0,1,\dots,10002$$一意に決めます。 

補間式は$$P(x)=\sum_{i=0}^{n} y_i \prod_{j\ne i} \frac{x-j}{i-j}.$$階乗および接頭辞/接尾辞積を使用すると、評価が線形時間に短縮されます。
