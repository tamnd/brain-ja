[プロジェクト オイラー問題 162](https://projecteuler.net/problem=162)

 ## 解決策

 **答え:**`3D58725572C62302`最大でも長さを 16 進数で数えます$16$それぞれの数字が含まれる$0$、$1$、 そして$\mathrm A$少なくとも 1 回、先頭のゼロは付けません。 

重要な考え方は **包含と排除** です。 

させて：

-$S_n$= 有効なセット$n$-桁の 16 進数 (最初の桁はゼロ以外)、
 - すべてを含む数字が必要です$\{0,1,\mathrm A\}$。 

直接数えるのではなく、これらの数字のサブセットを_避ける_ように数を数えます。 

禁断のセットに$F\subseteq\{0,1,\mathrm A\}$：

- がある$16-|F|$全体的に 16 進数が許可されます。 
- 最初の桁は指定できません$0$。 

したがって、最初の桁は$$(16-|F|)-[0\notin F]$$選択肢、どこで$[0\notin F]$は$1$ゼロが許可されている場合 (先頭の位置からゼロを除外する必要があるため)。 

残り$n-1$それぞれが持つポジション$16-|F|$選択肢。 

したがって、次のようになります。$$f(n,F) = \text{first}\times (16-|F|)^{n-1}$$次に、包含と除外を適用します。$$\#(\text{contains }0,1,A) = \sum_{F\subseteq\{0,1,A\}} (-1)^{|F|} f(n,F)$$これを合計します$n=1,\dots,16$。 

---

 提供されている Python コードは、まさにこれを実装しています。```python
def f(n, fb):  # n-digit hex numbers avoiding digits in fb set
    a = 16 - len(fb)
    first = a - (0 not in fb)
    return (first * a**(n-1)) if first > 0 and a > 0 else 0

ans = 0
for n in range(1, 17):
    for mask in range(8):
        fb = {[0,1,10][i] for i in range(3) if mask>>i&1}
        ans += ((-1)**bin(mask).count('1')) * f(n, fb)

print(hex(ans)[2:].upper())
```## コードのチュートリアル

 ### 関数`f(n, fb)`

```python
a = 16 - len(fb)
```もし`fb`禁止された数字が含まれている場合、`a`許可される 16 進数の桁数です。 

例:

 - 禁止する`{0,1}`→$16-2=14$許可される数字。 

---```python
first = a - (0 not in fb)
```ゼロが許可される場合は、先頭の数字からゼロを除外する必要があります。 

それで:

 - もし`0`禁止されていない場合は 1 を引いて、
 - それ以外の場合はすべて`a`最初の位置には数字が有効です。 

---```python
return (first * a**(n-1))
```選択してください:

 - の最初の桁`first`方法、
 - 残りの桁は独立して`a`方法。
