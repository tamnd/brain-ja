[プロジェクト オイラー問題 594](https://projecteuler.net/problem=594)

 ## 解決策

 **答え:**`47067598`させて$$O_{a,b}$$辺の長さが交互に変化する等しい角度の凸八角形であること。$a$そして$b$。 

計算しなければなりません$$t(O_{4,2}),$$単位正方形と単位菱形によるタイリング数（角度付き）$45^\circ/135^\circ$）。 

これらのタイリング問題に対処する標準的な方法は、それらを交差しない格子パスのファミリーに変換し、リンドストローム・ゲッセル・ヴィエノット (LGV) 行列定理を適用することです。 

---

 #1. 数学的分析

 八角形$$(a,b,c,d,a,b,c,d)$$等しい角度で$135^\circ$de Bruijn の線表現を認めます。すべてのタイルは単調なパスの集合に一意に対応します。 

この族について、エルニツキーの決定的な列挙式は次のようになります。$$T_{a,b,c,d} = \sum_{X,Y} \left( \prod_{u=1}^{d+1}\det M^{(u)} \right) \left( \prod_{v=1}^{b+1}\det P^{(v)} \right),$$どこ：

-$X=(x_{k,\ell})$モノトーンです$b\times d$エントリを含む行列$[0,a]$、
 -$Y=(y_{k,\ell})$逆モノトーンです$b\times d$エントリを含む行列$[0,c]$、
 - 行列式は、LGV を介して交差しないパス ファミリをカウントします。 

プロジェクト オイラー ポリゴンの場合、$$O_{a,b}=(a,b,a,b,a,b,a,b),$$それで私たちは設定しました$$(a,b,c,d)=(a,b,a,b).$$行列は次のとおりです。$$M^{(u)}_{ij} = \binom{ (x_{j,u}-x_{i,u-1})+(y_{j,u}-y_{i,u-1}) }{ (x_{j,u}-x_{i,u-1})+(j-i) },$$そして$$P^{(v)}_{ij} = \binom{ (x_{v,j}-x_{v-1,i})+(y_{v-1,i}-y_{v,j}) }{ (x_{v,j}-x_{v-1,i})+(j-i) }.$$タイリングの総数は、許容されるすべての単調配列にわたるこれらの行列式の積を合計することによって得られます。$X,Y$。

 #2. Pythonの実装```python
from math import comb

def gen_monotone_matrices(rows, cols, max_value):
    """
    Generate all matrices M such that:
        M[i][j] >= M[i-1][j]
        M[i][j] >= M[i][j-1]
    with entries in [0, max_value].
    """
    m = [[0] * cols for _ in range(rows)]

    def rec(pos):
        if pos == rows * cols:
            yield tuple(tuple(r) for r in m)
            return

        i, j = divmod(pos, cols)

        lo = 0
        if i > 0:
            lo = max(lo, m[i - 1][j])
        if j > 0:
            lo = max(lo, m[i][j - 1])

        for v in range(lo, max_value + 1):
            m[i][j] = v
            yield from rec(pos + 1)

    yield from rec(0)

def det_bareiss(mat):
    """
    Exact determinant using the Bareiss algorithm.
    """
    n = len(mat)

    if n == 0:
        return 1

    a = [row[:] for row in mat]
    sign = 1
    prev = 1

    for k in range(n - 1):

        if a[k][k] == 0:
            for i in range(k + 1, n):
                if a[i][k]:
                    a[k], a[i] = a[i], a[k]
                    sign = -sign
                    break
            else:
                return 0

        pivot = a[k][k]

        for i in range(k + 1, n):
            for j in range(k + 1, n):
                a[i][j] = (
                    a[i][j] * pivot
                    - a[i][k] * a[k][j]
                ) // prev

        prev = pivot

    return sign * a[-1][-1]

def count_tilings_octagon(a, b, c, d):

    X = list(gen_monotone_matrices(b, d, a))

    Y = []
    for y_rev in gen_monotone_matrices(b, d, c):
        y = tuple(
            tuple(y_rev[b - 1 - i][j] for j in range(d))
            for i in range(b)
        )
        Y.append(y)

    total = 0

    for x in X:

        x_full = [[0] * (d + 2) for _ in range(b + 2)]

        for k in range(1, b + 1):
            for l in range(1, d + 1):
                x_full[k][l] = x[k - 1][l - 1]

        for k in range(1, b + 1):
            x_full[k][d + 1] = a

        for l in range(d + 2):
            x_full[b + 1][l] = a

        for y in Y:

            y_full = [[0] * (d + 2) for _ in range(b + 2)]

            for k in range(1, b + 1):
                for l in range(1, d + 1):
                    y_full[k][l] = y[k - 1][l - 1]

            for k in range(1, b + 1):
                y_full[k][d + 1] = c

            for l in range(d + 2):
                y_full[0][l] = c

            prod = 1

            # Product of det(M^(u))
            for u in range(1, d + 2):

                M = []

                for i in range(1, b + 1):

                    row = []

                    for j in range(1, b + 1):

                        A = (
                            x_full[j][u] - x_full[i][u - 1]
                            + y_full[j][u] - y_full[i][u - 1]
                        )

                        B = (
                            x_full[j][u] - x_full[i][u - 1]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    M.append(row)

                prod *= det_bareiss(M)

                if prod == 0:
                    break

            if prod == 0:
                continue

            # Product of det(P^(v))
            for v in range(1, b + 2):

                P = []

                for i in range(1, d + 1):

                    row = []

                    for j in range(1, d + 1):

                        A = (
                            x_full[v][j] - x_full[v - 1][i]
                            + y_full[v - 1][i] - y_full[v][j]
                        )

                        B = (
                            x_full[v][j] - x_full[v - 1][i]
                            + (j - i)
                        )

                        row.append(comb(A, B) if 0 <= B <= A else 0)

                    P.append(row)

                prod *= det_bareiss(P)

                if prod == 0:
                    break

            total += prod

    return total

def t_O_ab(a, b):
    return count_tilings_octagon(a, b, a, b)

# Verify given examples
print(t_O_ab(1, 1))  # 8
print(t_O_ab(2, 1))  # 76
print(t_O_ab(3, 2))  # 456572

# Required value
print(t_O_ab(4, 2))

 #3. コードのチュートリアル

 -`gen_monotone_matrices(...)`すべてのモノトーン配列を生成します$X$そして$Y$。 
-`det_bareiss(...)`分数のない Bareiss アルゴリズムを使用して行列式を正確に計算します。 
-`count_tilings_octagon(...)`決定式を直接実装します。 
-`t_O_ab(a,b)`一般的な八角形をプロジェクト オイラー形状に特殊化します。 

検証出力は次のとおりです。$$t(O_{1,1})=8, \qquad t(O_{2,1})=76, \qquad t(O_{3,2})=456572,$$問題文と正確に一致します。 

最後に、計算により次のようになります。$$t(O_{4,2}) = 47067598.$$---
