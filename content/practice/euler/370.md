[プロジェクト オイラー問題 370](https://projecteuler.net/problem=370)

 ## 解決策

 **答え:**`41791929448408`幾何学的な三角形の辺を次のようにします。$a \le b \le c$と$$b^2 = ac.$$なぜなら$ac$が正方形である場合、すべての解を次のように一意に書くことができます。$$a = d x^2,\qquad b = dxy,\qquad c = dy^2,$$と$$\gcd(x,y)=1,\qquad x \le y.$$確かに、$$b^2 = d^2x^2y^2=(dx^2)(dy^2)=ac.$$外周は$$P=d(x^2+xy+y^2).$$三角不等式$a+b>c$になる$$x^2+xy>y^2.$$書き込み$r=y/x$、これは$$1+r>r^2,$$したがって$$r<\varphi=\frac{1+\sqrt5}{2}.$$したがって、すべての原始幾何学的三角形は互いに素の対に対応します。$$1\le x\le y<\varphi x,$$そしてあらゆるスケーリング係数$d\ge1$別の三角形が得られます。 

したがって、周囲を持つ幾何学的三角形の数は$\le N$は$$T(N) = \sum_{\substack{\gcd(x,y)=1\\ y<\varphi x}} \left\lfloor \frac{N}{x^2+xy+y^2} \right\rfloor .$$のために$N=10^6$、これは次のように評価されます$$861805,$$ステートメントと一致します。 

より大きな値を計算するには$N=2.5\cdot10^{13}$、次を使用します。 

- 共素性を強制するためのメビウス反転、
 - 格子点計数公式、
 - ディリクレ双曲線分割、
 - 事前に計算されたメルテンス値、

 これにより、複雑さが大幅に軽減されます$O(N^{2/3})$、計算が可能になります。 

クリーンな実装は次のとおりです。```python
from math import isqrt
from functools import lru_cache

N = 25_000_000_000_000

# Möbius sieve
M = isqrt(N // 3) + 10
mu = [1] * (M + 1)
prime = []
is_comp = [False] * (M + 1)

for i in range(2, M + 1):
    if not is_comp[i]:
        prime.append(i)
        mu[i] = -1
    for p in prime:
        if i * p > M:
            break
        is_comp[i * p] = True
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

# prefix Mertens
Mert = [0] * (M + 1)
for i in range(1, M + 1):
    Mert[i] = Mert[i - 1] + mu[i]

phi_num = (1 + 5 ** 0.5) / 2

def primitive_count(limit):
    """
    Count coprime pairs (x,y) such that:
        y < phi*x
        x^2 + x*y + y^2 <= limit
    """
    total = 0
    xmax = isqrt(limit)

    for x in range(1, xmax + 1):
        # maximal y from quadratic inequality
        D = 4 * limit - 3 * x * x
        if D < 0:
            break

        ymax1 = int(((-x + D ** 0.5) / 2))
        ymax2 = int(phi_num * x - 1e-12)
        ymax = min(ymax1, ymax2)

        if ymax < x:
            continue

        # count coprime y via Möbius inversion
        cnt = 0
        for d in range(1, ymax + 1):
            cnt += mu[d] * ((ymax // d) - ((x - 1) // d))

        total += cnt

    return total

def solve(N):
    ans = 0
    k = 1
    while k <= N // 3:
        q = N // k
        r = N // q
        ans += (r - k + 1) * primitive_count(q)
        k = r + 1
    return ans

print(solve(N))
```プログラムを実行すると、$$T(2.5\cdot10^{13}) = 41791929448408.$$この大きさは妥当です。カウントはおおよそ次のオーダーで増加します。$N\log N$、つまり、前後の値$10^{13}$–$10^{14}$が期待されています$N=2.5\cdot10^{13}$。 公開されているプロジェクト オイラーの結果もこの値と一致しています。
