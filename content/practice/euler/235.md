[プロジェクト オイラー問題 235](https://projecteuler.net/problem=235)

 ## 解決策

 **答え:**`1.002322108633`等差幾何数列が与えられています。$$u(k)=(900-3k)r^{k-1},$$そして$$s(n)=\sum_{k=1}^n u(k).$$の値を見つけなければなりません$r$そのような$$s(5000)=-600000000000.$$答えは次のように四捨五入する必要があります$12$小数点以下の桁。 

---

 # 数学的分析

 解決したい$$\sum_{k=1}^{5000}(900-3k)r^{k-1}=-6\times10^{11}.$$定義する$$S(r)=\sum_{k=1}^{5000}(900-3k)r^{k-1}.$$私たちはその根源を探ります$$F(r)=S(r)+6\times10^{11}=0.$$---

 ## 二分探索が機能する理由

 観察してください:

 - で$r=1$、$$S(1)=\sum_{k=1}^{5000}(900-3k),$$これは有限であり、以下に比べて比較的小さい$6\times10^{11}$。 

- として$r$上に増加します$1$の場合、次の理由により、後の否定項が優勢になります。 

- 結局のところ$900-3k<0$、
- そして$r^{k-1}$指数関数的に成長します。 

したがって、$S(r)$急速かつ継続的に減少します。 

したがって、次のような区間には一意の解が存在します。$[1,2]$、二分探索が理想的になります。 

---

 # 数値戦略

 私たちは計算します$$S(r)=\sum_{k=1}^{5000}(900-3k)r^{k-1}$$浮動小数点演算を直接使用します。 

次に:

 - もし$S(r)>-6\times10^{11}$、もっと大きなものが必要です$r$、
 - それ以外の場合は、より小さいものが必要です$r$。 

までの区間を繰り返し二等分していきます。$$|r_{\text{high}}-r_{\text{low}}|<10^{-15}.$$最後に丸めます$12$小数点以下の桁。 

---

 # Pythonの実装```python
TARGET = -600000000000.0

def S(r):
    total = 0.0
    power = 1.0  # r^(k-1)

    for k in range(1, 5001):
        total += (900 - 3 * k) * power
        power *= r

    return total

# Binary search interval
low = 1.0
high = 2.0

# Perform binary search
while high - low > 1e-15:
    mid = (low + high) / 2.0

    if S(mid) > TARGET:
        low = mid
    else:
        high = mid

r = (low + high) / 2.0

print(f"{r:.12f}")
```---
