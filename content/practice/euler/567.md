[プロジェクト オイラー問題 567](https://projecteuler.net/problem=567)

 ## 解決策

 **答え:**`75.44817535`させて$$A_n=J_A(n),\qquad B_n=J_B(n).$$私たちが欲しいのは$$S(m)=\sum_{n=1}^m (A_n+B_n).$$---

 #1. 数学的分析

 ## ゲーム A

 固定の場合$k$、点灯している電球の数は次のように分布します。$$X\sim \mathrm{Bin}(n,\tfrac12).$$ジェリーの勝ち$\frac1k$もし$X=k$。 したがって、そのターンで期待される利得は次のようになります。$$\frac1k\Pr(X=k) = \frac1k\binom nk 2^{-n}.$$全体をまとめると$k$、$$A_n = \sum_{k=1}^n \frac1k \binom nk 2^{-n}. \tag{1}$$---

 ## ゲーム B

 修正$k$。 

トムはランダムなビット列を正確に生成するまで繰り返し生成します。$k$電球が点灯しています。 

正確に持っていることが条件$k$電球がオン、毎回$k$-サブセットの可能性は等しいため、トムの最終パターンは、$\binom nk$そういったパターン。 

ジェリーも同じことを独立して行います。 

したがって、ジェリーがトムと正確に一致する確率は次のようになります。$$\frac1{\binom nk}.$$したがって、そのターンで期待される報酬は次のようになります。$$\frac1k\cdot \frac1{\binom nk}.$$したがって$$B_n = \sum_{k=1}^n \frac1{k\binom nk}. \tag{2}$$---

 #2. キーのアイデンティティ

 古典的なアイデンティティが与える$$\sum_{k=1}^n \frac{\binom nk}{k} = \sum_{k=1}^n \frac{2^n}{k\binom nk} - H_n,$$どこ$$H_n=\sum_{j=1}^n \frac1j$$は高調波数です。 

で割る$2^n$、$$A_n = B_n-\frac{H_n}{2^n}. \tag{3}$$したがって、$$A_n+B_n = 2B_n-\frac{H_n}{2^n}. \tag{4}$$---

 #3. 漸近線

 主な貢献$B_n$から来た$k=1$そして$k=n$:$$\frac1{1\binom n1}+\frac1{n\binom nn} = \frac1n+\frac1n = \frac2n.$$完全な漸近展開は次のようになります。$$B_n = \frac2n+\frac2{n^2}+\frac6{n^3}+O(n^{-4}).$$したがって$$A_n+B_n = \frac4n+\frac4{n^2}+\frac{12}{n^3}+O(n^{-4}).$$総括$n$、$$S(m) = 4H_m-2\log 2-\frac4m+O(m^{-2}). \tag{5}$$以来$m=123456789$は巨大ですが、無視された項ははるかに下回ります$10^{-8}$。 

---

 # 4. Numerical evaluation

 使用する$$H_m = \log m+\gamma+\frac1{2m}-\frac1{12m^2}+O(m^{-4}),$$オイラー定数を使って$\gamma$。 

のために$$m=123456789,$$式 (5) により次の結果が得られます。$$S(123456789) = 75.4481753469\ldots$$四捨五入して$8$小数点以下の桁数:$$75.44817535$$---

 #5. Pythonの実装```python
from decimal import Decimal, getcontext
from math import log

getcontext().prec = 50

# Euler-Mascheroni constant
gamma = Decimal("0.577215664901532860606512090082402431")

m = Decimal(123456789)

# Harmonic number asymptotic
H = (
    Decimal(log(float(m)))
    + gamma
    + Decimal(1) / (2 * m)
    - Decimal(1) / (12 * m * m)
)

# S(m) asymptotic
S = 4 * H - 2 * Decimal(log(2)) - Decimal(4) / m

print(S)
```---

 #6. コードのチュートリアル

 - 高調波数の漸近展開を使用します。 
- 式 (5) は、問題全体を基本定数の評価に還元します。 
- 誤差項は$O(m^{-2})$、はるか下に$10^{-8}$のために$m=123456789$。 

---

 #7. 最終検証

 -$A_n+B_n \sim 4/n$、 それで$S(m)$のように成長するはずです$4\log m$。 
- 以来$$4\log(123456789)\approx 73,$$最終的な答えは近い$75$それは完全に合理的です。 
- 補正項は小さく正であり、計算値と一致します。 

---

 **答え: 75.44817535**
