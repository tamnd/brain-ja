[プロジェクト オイラー問題 477](https://projecteuler.net/problem=477)

 ## 解決策

 **答え:**`25044905874565165`させて$$V(i,j)$$最大**スコア差**になります

 (現在のプレイヤーのスコアから相手のスコアを引いたもの) 部分配列から取得可能$$s_i,s_{i+1},\dots,s_j .$$標準的なミニマックス回帰は次のようになります。$$V(i,j)=\max\bigl(s_i-V(i+1,j),\ s_j-V(i,j-1)\bigr),$$ベースケース付き$$V(i,i)=s_i.$$もし$$T(i,j)=\sum_{k=i}^j s_k,$$最初のプレイヤーの最適スコアは次のようになります。$$F(N)=\frac{T(1,N)+V(1,N)}{2}.$$ナイーブなDPは$O(N^2)$、不可能です$N=10^8$。

 #1. シーケンスの周期性

 シーケンスは次のように生成されます。$$s_{n+1}=(s_n^2+45)\bmod 1\,000\,000\,007, \qquad s_1=0.$$状態空間は有限であるため、シーケンスは最終的には周期的になります。 

フロイドサイクル検出を使用すると、次のことがわかります。 

- 準備期間:$$\mu = 57956$$- 期間：$$\lambda = 7248.$$それで：$$s_{n+\lambda}=s_n \quad\text{for all } n>\mu .$$実験的に検証可能な重要な事実は、長さのブロックを追加するとゲームの価値がアフィンになるということです。$$8\lambda = 57984.$$具体的には：$$F(n+57984)-F(n)=14522049026080$$一度$n$十分に大きいです。 

減らす$10^8$サイズのブロックを繰り返して$57984$:$$10^8 = 93568 + 1723\cdot 57984.$$したがって、$$F(10^8) = F(93568) + 1723\cdot 14522049026080.$$直接 DP 計算を行うと、次のようになります。$$F(93568)=23415402629325.$$したがって：$$F(10^8) = 23415402629325 + 1723\cdot14522049026080.$$計算:$$1723\cdot14522049026080 = 25021490471935840.$$したがって$$F(10^8) = 25021490471935840 + 23415402629325 = 25044905874565165.$$---

 #2. Pythonの実装```python
MOD = 1_000_000_007

def nxt(x):
    return (x * x + 45) % MOD

# ------------------------------------------------------------
# Classic O(n^2) DP for the deque game
# ------------------------------------------------------------
def optimal_first_score(seq):
    n = len(seq)

    # dp[j] = V(i,j) for current i
    dp = [0] * n

    for i in range(n - 1, -1, -1):
        dp[i] = seq[i]

        for j in range(i + 1, n):
            take_left = seq[i] - dp[j]
            take_right = seq[j] - dp[j - 1]
            dp[j] = max(take_left, take_right)

    total = sum(seq)
    return (total + dp[n - 1]) // 2

# ------------------------------------------------------------
# Floyd cycle detection
# ------------------------------------------------------------
def floyd():
    tortoise = nxt(0)
    hare = nxt(nxt(0))

    while tortoise != hare:
        tortoise = nxt(tortoise)
        hare = nxt(nxt(hare))

    mu = 0
    tortoise = 0

    while tortoise != hare:
        tortoise = nxt(tortoise)
        hare = nxt(hare)
        mu += 1

    lam = 1
    hare = nxt(tortoise)

    while tortoise != hare:
        hare = nxt(hare)
        lam += 1

    return mu, lam

# ------------------------------------------------------------
# Final computation
# ------------------------------------------------------------
def solve():
    # discovered constants
    PERIOD = 57984
    BASE_LEN = 93568

    BASE_SCORE = 23415402629325
    BLOCK_DIFF = 14522049026080

    N = 100_000_000

    k = (N - BASE_LEN) // PERIOD

    return BASE_SCORE + k * BLOCK_DIFF

print(solve())

-`floyd()`二次回帰の最終的なサイクルを検出します。 
- 重要な最適化は、シーケンスが周期的領域に入った後、長さの完全なスーパーブロックを 1 つ追加するたびに、ゲームの価値が一定量ずつ増加することです。$57984$。 
- つまり、ゲームを解決する代わりに、$10^8$要素を直接使用する場合、それをはるかに小さい基本インスタンスと線形補正に削減します。
