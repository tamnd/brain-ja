[プロジェクト オイラー問題 348](https://projecteuler.net/problem=348)

 ## 解決策

 **答え:**`1004195061`数字を入れてみましょう$N$～のように表現できる$$N = a^2 + b^3$$と$a>1$そして$b>1$。 

この形式の **正確に 4 つの異なる表現**を許容する **5 つの最小の回文数**を求めます。 

---

 # 数学的分析

 次の 3 つのアイデアを組み合わせる必要があります。 

1. 回文を効率的に生成します。 
2. 回文が正方形と立方体を加えたものとして書けるかどうかをテストします。 
3. 表現を正確に数えます。 

---

 ## 1. なぜ回文を直接生成するのでしょうか?

 回文はまばらであるため、すべての整数をチェックするのは無駄です。 

回文は前半で完全に決まります。 

例:

 - 均等な長さ:$$123321$$ミラーリングから来ています$123$。 
- 奇数の長さ:$$12321$$の最後の桁を除くすべてをミラーリングすることで得られます。$123$。 

したがって、非常に安価に昇順の回文を生成できます。 

---

 ## 2. 表現のカウント

 固定回文の場合$N$、すべてのペアが必要です$$(a,b), \qquad a>1,\; b>1$$そのような$$a^2 + b^3 = N.$$再配置:$$a^2 = N - b^3.$$したがって、すべての立方体について$b^3 < N$:

 1. コンピューティング$$r = N - b^3.$$2. かどうかを確認します。$r$は完全な正方形です。 

高速な完全二乗テストは次のとおりです。$$a = \lfloor \sqrt{r} \rfloor,$$それから確認してください$$a^2 = r.$$チェックが成功するたびに 1 つの表現が与えられます。 

---

 ## 3. 複雑さ

 仮定してください$N$周りにいる$10^9$。 

それから：$$b^3 \le N \quad\Rightarrow\quad b \le N^{1/3} \approx 1000.$$したがって、各回文に必要なのは約$1000$キューブチェック — 非常に管理しやすい。 

回文はまばらであるため、この強引な方法が実用的になります。 

---

 # Pythonの実装```python
from math import isqrt

def generate_palindromes(limit):
    """
    Generate palindromes in increasing order up to 'limit'.
    """

    length = 1

    while True:
        # Number of digits used to build the first half
        start = 10 ** ((length - 1) // 2)
        end = 10 ** ((length + 1) // 2)

        for half in range(start, end):
            s = str(half)

            # Odd length palindrome
            if length % 2 == 1:
                p = int(s + s[-2::-1])

            # Even length palindrome
            else:
                p = int(s + s[::-1])

            if p > limit:
                return

            yield p

        length += 1

def count_representations(n):
    """
    Count representations of n as:
        n = a^2 + b^3
    with a > 1 and b > 1.
    """

    count = 0
    b = 2

    while b ** 3 < n - 4:
        cube = b ** 3
        remainder = n - cube

        a = isqrt(remainder)

        if a > 1 and a * a == remainder:
            count += 1

        b += 1

    return count

# Search for the first five palindromes
# having exactly four representations.

found = []

LIMIT = 2_000_000_000

for p in generate_palindromes(LIMIT):

    if count_representations(p) == 4:
        found.append(p)

        print("Found:", p)

        if len(found) == 5:
            break

answer = sum(found)

print("Sum =", answer)
```---
