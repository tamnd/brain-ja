 #1. 数学的分析

 ## ステップ 1: ベースの構造$12$基地――$12$パンデジタル番号にはすべての数字が含まれている必要があります$$0,1,2,\dots,11$$少なくとも一度は。 

このような「最小」の数値では、次の理由から、明らかに各桁が 1 回だけ使用されます。 

- 任意の数字を 2 回使用すると、表現が長くなります。 
- 長い表現は自動的に大きくなります。 

したがって、最小の解の中のすべての候補は、12 塩基の順列になります。$12$数字:$$(0,1,2,\dots,11)$$先頭の数字がゼロ以外の場合。 

したがって、すべての候補者は正確に 12 塩基を持っています。$12$数字。 

したがって、$$11 \cdot 11! = 39,916,800$$考えられる候補者。 

これは大掛かりに聞こえますが、最適化された検索を使用すれば完全に管理可能です。

 ## ステップ 2: パンデジタル性を効率的にテストする

 各候補整数について$N$、および各塩基$b\in\{2,\dots,11\}$:

 1. 除算を繰り返します$b$、
 2. ビットマスクを使用して、検出された数字を記録します。 
3. すべての桁が正しいことを確認します$0,\dots,b-1$現れた。 

最終的なビットマスクが次の場合$$(1 \ll b)-1,$$その場合、数値は基数がパンデジタルになります$b$。 

候補を数値の昇順（辞書編集上の塩基の順序）で生成するため、$12$桁)、最初に見つかった 10 個の有効な数値は、正確に最小の 10 個です。$12$-スーパーパンデジタル数字。

 #2. Pythonの実装```python
from itertools import permutations

# ---------------------------------------------------------
# Check whether n is pandigital in base b
# ---------------------------------------------------------
def is_pandigital(n, b):
    seen = 0

    while n > 0:
        digit = n % b
        seen |= (1 << digit)
        n //= b

    # all digits 0..b-1 must appear
    return seen == (1 << b) - 1

# ---------------------------------------------------------
# Search for the 10 smallest 12-super-pandigital numbers
# ---------------------------------------------------------
found = []
total = 0

digits = range(12)

for perm in permutations(digits):

    # leading digit cannot be zero
    if perm[0] == 0:
        continue

    # interpret permutation as a base-12 number
    n = 0
    for d in perm:
        n = n * 12 + d

    # test bases 11 down to 2
    ok = True
    for b in range(11, 1, -1):
        if not is_pandigital(n, b):
            ok = False
            break

    if ok:
        found.append(n)
        total += n

        if len(found) == 10:
            break

print(found)
print(total)
```---
