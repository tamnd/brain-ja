 ## 解決策

 **答え:**`542934735751917735`ターゲットの 10 進数文字列を次のようにします$w=w_1w_2\dots w_m$、 どこ$m$の桁数です$n$。 

最初に出現するまでランダムな数字ストリームをスキャンします。$w$。 

これは古典的な「ランダム ストリームでのパターン マッチング」問題であり、オートマトン/KMP オーバーラップ構造を使用して解決されます。 

#1. 数学的分析

 一言$w$、**border** を空ではない文字列として定義し、同時に次のことを行います。 

- の接頭辞$w$、
 - と接尾辞$w$。 

ボーダーに長さがある場合$b$、パターンが部分的に一致して失敗した後、その重複を再利用できます。 

オートマトン/更新理論の標準的な結果は次のようになります。$$E(w)=\sum_{b \in B(w)} 10^b,$$どこ：

-$E(w)$パターンが完成するまでに必要となる予想される桁数です。 
-$B(w)$全長を含む境界線の長さのセットです$m$。 

ただし、問題の定義は、$g(n)$予想される**開始位置**として$k$、フィニッシュポジションではありません。 

試合がその位置で終了した場合$t$、 それから$$k=t-m+1.$$したがって、$$g(n)=E(w)-m+1.$$したがって：$$\boxed{ g(n)=\sum_{b \in B(w)} 10^b - m + 1 }$$どこ$w$は 10 進展開です$n$。 

- -

＃＃ 例：$n=535$の国境`"535"`:

 -`"5"`（長さ$1$）
 -`"535"`（長さ$3$）

したがって$$g(535)=10^1+10^3-3+1 =10+1000-2 =1008.$$これはステートメントと一致します。

 #2. 効率的な計算

 評価しなければなりません$$\sum_{n=2}^{999999} g\!\left(\left\lfloor\frac{10^{16}}{n}\right\rfloor\right).$$それぞれの値について:

 1. 10 進数の文字列に変換します。 
2. KMP プレフィックス関数を使用して、すべての境界線の長さを計算します。 
3.合計$10^b$あらゆる国境を越えて。 
4. 減算$m-1$。 

各文字列は最大 16 桁なので、合計の作業はわずかです。

 #3. Pythonの実装```python
def g_value(x):
    s = str(x)
    m = len(s)

    # KMP prefix function
    pi = [0] * m

    for i in range(1, m):
        j = pi[i - 1]

        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]

        if s[i] == s[j]:
            j += 1

        pi[i] = j

    # Full word always contributes 10^m
    ans = 10 ** m - m + 1

    # Add contributions from proper borders
    j = pi[-1]

    while j > 0:
        ans += 10 ** j
        j = pi[j - 1]

    return ans

total = 0

for n in range(2, 1_000_000):
    total += g_value(10 ** 16 // n)

print(total)
```---

- 追加$10^b$適切な境界線の長さごとに$b$、
 - 減算$m-1$。
