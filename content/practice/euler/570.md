 ## 解決策

 **答え:**`271197444`させて

-$A(n)$= ちょうど 1 層の厚さの単位三角形の数、
 -$B(n)$= ちょうど 3 層の厚さの単位三角形の数、
 -$G(n)=\gcd(A(n),B(n))$。 

私たちは求められています$$\sum_{n=3}^{10^7} G(n).$$---

 #1. 数学的分析

 重要なステップは、次の閉じた形式を導き出すことです。$A(n)$そして$B(n)$。 

再帰的オーバーレイ操作が順序からどのように増加するかを分析することによって$n-1$注文する$n$、線形回帰が得られます。$$A(n)=4A(n-1)+2\cdot 3^{n-2},$$

$$B(n)=4B(n-1)+24(n-2)4^{n-3}-6\cdot 3^{n-2},$$初期値は小さな雪片から取得されます。 

これらの漸化式を解くと、明示的な公式が得られます。$$A(n)=3\cdot 4^{n-1}-2\cdot 3^{n-1},$$そして$$B(n)=18(n-2)4^{n-2}+(4n+26)3^{n-1}-138\cdot 4^{n-2}.$$これらを単純化すると、$$B(n)= (18n-138)4^{n-2} + (4n+26)3^{n-1}.$$次に gcd を計算します。 

要素$A(n)$:$$A(n)=3\left(4^{n-1}-2\cdot 3^{n-2}\right).$$間の代数消去後$A(n)$そして$B(n)$、見つけます$$G(n) = 6\cdot \gcd\!\left( 2\cdot 4^{n-2}-3^{n-2}, \, 7n+3 \right).$$それが重要な単純化です。 

---

 ## さらなるモジュールの簡素化

 しましょう$$m=7n+3.$$もし$3\nmid n$、 それから$\gcd(3,m)=1$、 それで$3^{n-2}$可逆モジュロです$m$。 

定義する$$b \equiv 4\cdot 3^{-1} \pmod m.$$それから$$2\cdot 4^{n-2}-3^{n-2} \equiv 3^{n-2}\left(2b^{n-2}-1\right) \pmod m.$$以来$3^{n-2}$可逆モジュロです$m$、$$\gcd\!\left(2\cdot 4^{n-2}-3^{n-2},m\right) = \gcd\!\left(2b^{n-2}-1,m\right).$$したがって、各項はべき乗剰余演算のみを使用して計算できます。 

複雑さは本質的には$$O\!\left(N\log N\right),$$これは十分に高速です$N=10^7$。

 #2. Pythonの実装```python
from math import gcd

def A(n):
    return 3 * pow(4, n - 1) - 2 * pow(3, n - 1)

def B(n):
    p4 = pow(4, n - 2)
    p3 = pow(3, n - 1)
    return (18 * n - 138) * p4 + (4 * n + 26) * p3

def G(n):
    m = 7 * n + 3

    # If gcd(3, m) = 1, cancel 3^(n-2) modulo m
    if n % 3 != 0:

        # modular inverse of 3 modulo m
        if m % 3 == 1:
            inv3 = (2 * m + 1) // 3
        else:
            inv3 = (m + 1) // 3

        b = (4 * inv3) % m

        t = pow(b, n - 2, m)

        return 6 * gcd((2 * t - 1) % m, m)

    # Otherwise compute directly
    x = (2 * pow(4, n - 2, m) - pow(3, n - 2, m)) % m

    return 6 * gcd(x, m)

def solve(N):
    total = 0

    for n in range(3, N + 1):
        total += G(n)

    return total

# Verification against the statement
assert A(3) == 30
assert B(3) == 6
assert G(3) == 6

assert A(11) == 3027630
assert B(11) == 19862070
assert G(11) == 30

assert G(500) == 186
assert solve(500) == 5124

print(solve(10_000_000))
```---
