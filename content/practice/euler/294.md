[プロジェクト オイラー問題 294](https://projecteuler.net/problem=294)

 ## 解決策

 **答え:**`789184709`を小数展開してみましょう$k$なれ$$k=\sum_{i=0}^{n-1} a_i 10^i, \qquad 0\le a_i\le 9.$$私たちは数字を数えたいのです$k<10^n$そのような

 1.$k\equiv 0 \pmod{23}$、
 2.$\sum a_i = 23$。 

このカウントを次のように表します$S(n)$。 

---

 #1. 数学的分析

 ## 1.1 条件のエンコード

 桁の和の条件は次のとおりです。$$\sum_{i=0}^{n-1} a_i = 23.$$割り切れる条件は、$$\sum_{i=0}^{n-1} a_i 10^i \equiv 0 \pmod{23}.$$したがって、すべての数字が同時に寄与します。 

-$+a_i$桁の合計に、
 -$+a_i 10^i$モジュロ$23$。 

これは、生成関数アプローチを強く示唆しています。 

---

 ## 1.2 二変量生成関数

 固定位置の場合$i$、数字$d\in\{0,\dots,9\}$貢献する$$x^d y^{d10^i}.$$したがって、位置$i$多項式に寄与する$$P_i(x,y)=\sum_{d=0}^9 x^d y^{d10^i}.$$すべての位置で乗算する:$$F_n(x,y)=\prod_{i=0}^{n-1} P_i(x,y).$$次に:

 - の指数$x$桁の合計を記録し、
 - の指数$y$剰余剰余を記録する$23$。 

したがって、$$S(n)= [x^{23}y^0]\,F_n(x,y),$$ここで、の指数は$y$モジュロで解釈される$23$。 

---

 ## 1.3 周期性のモジュロ 23

 重要な観察:$$10^{22}\equiv 1 \pmod{23},$$なぜなら$23$プライムであり、$10$は原始要素モジュロです$23$。 

したがって、シーケンスは$10^i \pmod{23}$期間あり$22$。 

したがって、因子は毎回繰り返されます$22$ポジション。 

させて$$n = 22q + r,\qquad 0\le r<22.$$次に、各残基クラスの位置は次のいずれかになります。 

-$q$回、または
 -$q+1$回。 

具体的には、$j=0,\dots,21$、$$P_j(x,y)=\sum_{d=0}^9 x^d y^{d10^j},$$そして$$F_n(x,y) = \prod_{j=0}^{21} P_j(x,y)^{\,q+\mathbf 1_{j<r}}.$$---

 ## 1.4 切り捨ての奇跡

 係数だけを気にする$x^{23}$。 

したがって、すべての乗算中、次数のすべての項を破棄できます。$>23$。 

したがって、計算全体は小さな有限代数の中で行われます。 

-$x$-程度：$0\ldots 23$、
 - 剰余モジュロ$23$:$0\ldots 22$。 

合計状態:$$24\times 23 = 552.$$べき乗が非常に高速になります。

 #2. Pythonの実装```python
MOD = 10**9

# --------------------------------------------------------------------
# Polynomial representation:
# dictionary mapping (digit_sum, residue_mod_23) -> coefficient
# --------------------------------------------------------------------

def multiply(A, B):
    """
    Multiply two truncated polynomials.

    State:
        (s, r)
    means:
        x^s y^r

    We truncate all terms with s > 23.
    """
    C = {}

    for (s1, r1), v1 in A.items():
        for (s2, r2), v2 in B.items():

            s = s1 + s2

            # We only need digit sum <= 23
            if s <= 23:
                r = (r1 + r2) % 23

                key = (s, r)

                C[key] = (C.get(key, 0) + v1 * v2) % MOD

    return C

def power(P, e):
    """
    Fast exponentiation of a polynomial.
    """
    R = {(0, 0): 1}

    while e > 0:

        if e & 1:
            R = multiply(R, P)

        P = multiply(P, P)

        e >>= 1

    return R

def S(n):
    """
    Compute S(n) mod 1e9.
    """

    q, r = divmod(n, 22)

    # Start with multiplicative identity
    ans = {(0, 0): 1}

    # Build the 22 periodic factors
    for j in range(22):

        w = pow(10, j, 23)

        # P_j(x,y)
        P = {}

        for d in range(10):
            key = (d, (d * w) % 23)
            P[key] = P.get(key, 0) + 1

        exponent = q + (1 if j < r else 0)

        ans = multiply(ans, power(P, exponent))

    return ans.get((23, 0), 0)

# --------------------------------------------------------------------
# Verification on given examples
# --------------------------------------------------------------------

print(S(9))      # 263626
print(S(42))     # 878570056  (matches the last 9 digits)

# Final computation
N = 11**12

print(S(N))
```---

 #3. コードのチュートリアル

 ##`multiply(A, B)`各多項式はまばらに保存されます。 

用語```python
(s, r): value
```手段：$$\text{value}\cdot x^s y^r.$$乗算する場合:$$x^{s_1}y^{r_1}\cdot x^{s_2}y^{r_2} = x^{s_1+s_2}y^{r_1+r_2}.$$剰余はモジュロで換算されます$23$。 

桁の合計を含むすべての項を破棄します$>23$。 

---

 ##`power(P, e)`標準の 2 進累乗。 

これは次のように計算します。$$P^e$$で$O(\log e)$掛け算。 

以来$11^{12}\approx 3.1\times 10^{12}$、ちょうど約$42$直角化の手順が必要です。 

---

 ##`S(n)`周期性を使用します。$$10^{22}\equiv 1 \pmod{23}.$$したがって、あるのは$22$異なる位置タイプ。 

もし$$n=22q+r,$$次に因数分解します$P_j$表示されます:$$q+\mathbf 1_{j<r}$$回。 

最後に係数を抽出します。```python
ans[(23, 0)]
```これは次のものに正確に対応します。 

- 桁の合計$23$、
 - 残留物$0\pmod{23}$。

したがって、このメソッドは提供されたチェックと一致しています。
