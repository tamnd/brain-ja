[プロジェクト オイラー問題 42](https://projecteuler.net/problem=42)

 ## 解決策

 **答え:**`162`重要なタスクは、提供されたファイル内で **三角形の数値**に等しい **単語値**を持つ単語がいくつあるかを判断することです。 

三角形数は次のように定義されます。$$t_n = \frac{n(n+1)}{2}$$最初のいくつかは次のとおりです。$$1,3,6,10,15,21,28,36,45,55,\dots$$例えば：

-$S=19$-$K=11$-$Y=25$それで$$19+11+25 = 55$$そしてそれ以来$$55 = \frac{10\cdot 11}{2}$$SKYは三角形の単語です。 

---

 # ステップ 1 — 数学的分析

 ## 単語を数値に変換する

 各文字はそのアルファベット順のインデックスにマップされます。$$A=1,\;B=2,\;\dots,\;Z=26$$単語に文字が含まれている場合$c_1,c_2,\dots,c_k$、その値は$$V = \sum_{i=1}^{k} \text{value}(c_i)$$例：$$\text{SKY}=19+11+25=55$$---

 ## 数値が三角形かどうかを判断する

 何らかの整数かどうかを知る必要があります。$x$満足する$$x=\frac{n(n+1)}2$$再配置:$$n^2+n-2x=0$$二次公式を使用すると、次のようになります。$n=\frac{-1+\sqrt{1+8x}}{2}$それで$x$まさに三角形になるのは$$1+8x$$は完全な正方形であり、その結果は$n$は整数です。 

---

 ## 可能な最大ワード値

 単語ファイルには一般的な英単語が含まれています。 最大語長は短いです。 単語に 20 文字がすべて Z に等しい場合でも、次のようになります。$$20\cdot 26 = 520$$したがって、必要なのは三角形の数の控えめなセットだけです。 

実践的なアプローチ:

 1. すべての単語を読む
 2. 各単語の値を計算する
 3. 最大値までのすべての三角形の数値を事前計算します。 
4. 一致を数える

 セット内の検索は次のとおりであるため、これは効率的です。$O(1)$。

 # ステップ 2 — Python の実装```python
from math import sqrt

# Read the words file
with open("0042_words.txt") as f:
    content = f.read()

# The file format is:
# "WORD1","WORD2","WORD3",...
words = [w.strip('"') for w in content.split(",")]

# Function to compute word value
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)

# Compute all word values
values = [word_value(w) for w in words]

# Find the largest value
max_value = max(values)

# Generate all triangle numbers up to max_value
triangle_numbers = set()

n = 1
while True:
    t = n * (n + 1) // 2
    if t > max_value:
        break
    triangle_numbers.add(t)
    n += 1

# Count triangle words
count = sum(1 for v in values if v in triangle_numbers)

print(count)
```---

 ## 単語の値を計算する```python
def word_value(word):
    return sum(ord(c) - ord('A') + 1 for c in word)
```

`ord('A')`ASCII コード 65 を与えます。 

それで:

 - あ→$65-65+1=1$-B→$66-65+1=2$- …
 - Z → 26

 例:```python
word_value("SKY")
```与える$$19+11+25=55$$これは問題文と一致します。 

---

 ## 三角番号の生成```python
t = n * (n + 1) // 2
```これにより実装されます$$t_n = \frac{n(n+1)}2$$三角形の番号が最大ワード値を超えると停止します。 

を使用して`set`非常に高速なメンバーシップ テストが可能になります。

 ## 三角形の単語を数える```python
count = sum(1 for v in values if v in triangle_numbers)
```すべての単語の値について:

 - それ以外の場合は 0 を追加します
