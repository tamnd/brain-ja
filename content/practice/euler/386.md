 ## 解決策

 **答え:**`528755790`の素因数分解を書く$n$として$$n=\prod_{i=1}^k p_i^{a_i}.$$のすべての約数$n$ベクトルに対応する$$(e_1,\dots,e_k), \qquad 0\le e_i\le a_i,$$経由$$d=\prod p_i^{e_i}.$$割り算関係は製品半オーダーとなります$$(e_1,\dots,e_k)\le(f_1,\dots,f_k) \iff e_i\le f_i \text{ for all } i.$$それで$S(n)$除数格子です$$[0,a_1]\times\cdots\times[0,a_k].$$鎖の積に関するシュペルナー理論の標準定理は次のように述べています。 

> 最大のアンチチェーンは最大のランク レベルと同じです。 

約数の位数は、$$e_1+\cdots+e_k.$$したがって、$N(n)$の最大の係数です$$\prod_{i=1}^k (1+x+\cdots+x^{a_i}).$$例えば：

-$30=2^1 3^1 5^1$- 生成多項式:$$(1+x)^3=1+3x+3x^2+x^3$$- 最大係数$=3$- したがって$N(30)=3$。

 # 主要な計算上のアイデア

 値$N(n)$指数の複数セットに**のみ**依存します$$(a_1,\dots,a_k),$$実際の素数ではありません。 

そこで私たちは:

 1. 考えられるすべての指数パターンを列挙します。$n\le10^8$。 
2. 各パターンについて:

 - 最大係数を計算します。 
- 正確にその指数パターンを持つ整数がいくつあるかを数えます。 
- 掛け算と累積。 

以下の指数パターンの数$10^8$小さい (わずか数百) ため、これは高速です。

 # Pythonの実装```python
from collections import Counter
from functools import lru_cache
from math import comb
from sympy import primerange

LIMIT = 10**8

# ------------------------------------------------------------
# Generate all exponent patterns
# exponents are stored in nonincreasing order
# ------------------------------------------------------------

patterns = []

small_primes = list(primerange(2, 100))

def generate_patterns(last_exp, prime_index, current_value, current):
    if current:
        patterns.append(tuple(current))

    p = small_primes[prime_index]
    value = 1

    for e in range(1, last_exp + 1):
        value *= p
        if current_value * value > LIMIT:
            break

        current.append(e)
        generate_patterns(e, prime_index + 1,
                          current_value * value,
                          current)
        current.pop()

generate_patterns(60, 0, 1, [])

# ------------------------------------------------------------
# Compute N(pattern)
# largest coefficient of:
#    ∏ (1 + x + ... + x^a)
# ------------------------------------------------------------

@lru_cache(None)
def antichain_size(pattern):
    poly = [1]

    for a in pattern:
        nxt = [0] * (len(poly) + a)

        for i, v in enumerate(poly):
            for j in range(a + 1):
                nxt[i + j] += v

        poly = nxt

    return max(poly)

# ------------------------------------------------------------
# Count numbers with a given exponent pattern
# ------------------------------------------------------------

primes = list(primerange(2, LIMIT + 1))

@lru_cache(None)
def count_pattern(pattern, start_index=0, limit=LIMIT):
    pattern = tuple(pattern)

    if not pattern:
        return 1

    a = pattern[0]
    total = 0

    for i in range(start_index, len(primes)):
        p = primes[i]

        pe = p ** a
        if pe > limit:
            break

        total += count_pattern(
            pattern[1:],
            i + 1,
            limit // pe
        )

    return total

# ------------------------------------------------------------
# Main summation
# ------------------------------------------------------------

answer = 1   # N(1)=1

for pat in patterns:
    c = count_pattern(pat)
    n = antichain_size(pat)
    answer += c * n

print(answer)
```---

 # コードのチュートリアル

 ### 1. 指数パターンを生成する

 すべての指数タプルを再帰的に生成します$$(a_1\ge a_2\ge \cdots \ge a_k\ge1)$$そのような$$2^{a_1}3^{a_2}5^{a_3}\cdots \le 10^8.$$これにより、実現可能なすべての因数分解タイプが含まれることが保証されます。 

---

 ### 2. コンピューティング$N(n)$指数パターンの場合$(a_1,\dots,a_k)$、$$P(x)=\prod (1+x+\cdots+x^{a_i}).$$の係数$x^r$順位の約数を数える$r$。 

最大係数はアンチチェーンの最大サイズと等しくなります。 

単純な多項式 DP によって係数を計算します。 

---

 ### 3. そのパターンで整数を数えます

 例:$$(2,1,1)$$数字に対応する$$p^2 q r$$異なる素数を持つ$p,q,r$。 

再帰では、重複を避けるために増加する素数が選択されます。
