[プロジェクト オイラー問題 379](https://projecteuler.net/problem=379)

 ## 解決策

 **答え:**`132314136838185`させて$$f(n)=\#\{(x,y):x,y\in \mathbb Z_{>0},\ x\le y,\ \operatorname{lcm}(x,y)=n\}.$$私たちが欲しいのは$$g(N)=\sum_{n\le N} f(n),$$そして具体的には$g(10^{12})$。 

---

 ## ステップ 1: 固定 LCM を使用してペアをカウントする

 最初の **順序付き** ペアのカウント$(x,y)$そのような$$\operatorname{lcm}(x,y)=n.$$書く$$n=\prod p_i^{a_i}.$$素数ごとに$p^a$の指数の場合、$p$で$x,y$は$(u,v)$、それでは必要です$$\max(u,v)=a.$$指数ペアの数は$$(a+1)^2-a^2 = 2a+1.$$したがって、順序ペアの数は次のようになります。$$\prod (2a_i+1)=d(n^2),$$どこ$d(m)$は除数をカウントする関数です。 

次に、次の順序なしペアに変換します。$x\le y$。 

唯一の対称順序ペアは、$(n,n)$、 それで：$$f(n)=\frac{d(n^2)+1}{2}.$$したがって、$$g(N)=\sum_{n\le N}\frac{d(n^2)+1}{2} =\frac12\sum_{n\le N}d(n^2)+\frac N2.$$したがって、問題はコンピューティングに帰着します$$S(N)=\sum_{n\le N} d(n^2).$$---

 ## ステップ 2: 有用な ID$d(n^2)$標準的なアイデンティティは$$d(n^2)=\sum_{d\mid n}2^{\omega(d)},$$どこ$\omega(d)$は、次の異なる素因数の数です。$d$。 

確かに、$n=p^a$、$$d(p^{2a})=2a+1,$$その間$$\sum_{k=0}^{a}2^{\omega(p^k)} =1+2a.$$したがって$$S(N)=\sum_{n\le N}\sum_{d\mid n}2^{\omega(d)} =\sum_{d\le N}2^{\omega(d)}\Bigl\lfloor\frac Nd\Bigr\rfloor.$$これが重要な要約フォームです。 

---

 ## ステップ 3: より迅速な評価

 ディリクレ級数の使用$$\sum_{n\ge1}\frac{d(n^2)}{n^s} =\frac{\zeta(s)^3}{\zeta(2s)},$$畳み込み恒等式を導き出す$$d(n^2)=\sum_{k^2\mid n}\mu(k)\,d_3\!\left(\frac{n}{k^2}\right),$$どこ：

-$\mu$はメビウス関数、
 -$d_3(m)$カウント表現$abc=m$。 

したがって$$S(N) = \sum_{k\le \sqrt N} \mu(k)\, \sum_{m\le N/k^2} d_3(m).$$の総和関数$d_3$で評価できます$O(N^{2/3})$双曲線分解を使用したスタイルの複雑さ。 

それにより、$N=10^{12}$計算的には実現可能。 

---

 ## Pythonの実装```python
import math
from sympy import mobius

N = 10**12

def D3_sum(n):
    """
    Returns:
        sum_{k <= n} d3(k)

    using a 3-dimensional hyperbola decomposition.
    """

    total = 0
    c = int(round(n ** (1/3)))

    while (c + 1) ** 3 <= n:
        c += 1
    while c ** 3 > n:
        c -= 1

    for a in range(1, c + 1):
        s = math.isqrt(n // a)

        total += n // (a * a)

        total += 2 * sum((n // (a * b)) for b in range(a + 1, s + 1))

        total -= s * s

    total += c ** 3

    return total

S = 0

root = math.isqrt(N)

for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))

g = (S + N) // 2

print(g)
```---

 ## コードのチュートリアル

 ###`D3_sum(n)`計算します$$\sum_{m\le n} d_3(m).$$以来$d_3(m)$トリプルを数える$(a,b,c)$と$abc=m$、集計関数は次の条件を満たすトリプルをカウントします。$$abc\le n.$$コードでは、対称双曲線分解を使用して、これらを効率的にカウントします。 

---

 ### メビウス反転ループ```python
for k in range(1, root + 1):
    S += mobius(k) * D3_sum(N // (k * k))
```これは実装します$$S(N)=\sum_{k\le \sqrt N}\mu(k)\sum_{m\le N/k^2} d_3(m).$$---

 ### 最終ステップ

 以来$$g(N)=\frac{S(N)+N}{2},$$最終的な答えは次のとおりです。```python
g = (S + N) // 2
```---
