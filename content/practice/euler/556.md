[プロジェクト オイラー問題 556](https://projecteuler.net/problem=556)

 ## 解決策

 **答え:**`52126939292957`させて$$z=a+bi \in \mathbb Z[i],\qquad N(z)=a^2+b^2.$$適切なガウス整数を数えなければなりません ($a>0,\ b\ge 0$) でスクエアフリーです$\mathbb Z[i]$そして満足する$N(z)\le 10^{14}$。 

---

 # 1. ガウス平方自由整数の構造

 の有理素因数分解を思い出してください。$\mathbb Z[i]$:

 -$2 = -i(1+i)^2$(枝分かれした)、
 -$p\equiv1\pmod4$分割:$$p=\pi\bar\pi,$$-$p\equiv3\pmod4$プライムのままです。 

書く$$z=g(a+bi),$$と$\gcd(a,b)=1$。 

次に:

 - 毎$p\equiv3\pmod4$分割する$g$1 つの不活性ガウス素数に寄与します。 
- 毎$p\equiv1\pmod4$分割する$a^2+b^2$共役ガウス素数の 1 つを正確に提供し、
 - 枝分かれした素数$1+i$表示される場合$a,b$どちらも奇数です。 

慎重な評価分析により、重要な基準が得られます。$$\boxed{ z \text{ is squarefree in }\mathbb Z[i] \iff \begin{cases} g \text{ is odd and squarefree},\\[2mm] \dfrac{a^2+b^2}{g^2}\text{ is squarefree}. \end{cases} }$$これにより、問題は通常の整数に関する算術カウントの問題に変換されます。 

---

 # 2. プリミティブ表現のカウント

 もし$n$正方形がなく、素数が含まれていません$p\equiv3\pmod4$、次にノルムの原始プロパーガウス整数の数$n$等しい$$2^{\omega_1(n)},$$どこ$\omega_1(n)$異なる素因数を数えます$p\equiv1\pmod4$。 

したがって、$$f(N) = \sum_{\substack{g\ge1\\ g\ \text{odd sq.free}}} \; \sum_{\substack{m\le N/g^2\\ m\ \text{sq.free}\\ p\mid m\Rightarrow p\not\equiv3\pmod4}} 2^{\omega_1(m)}.$$乗算関数を定義する$$a(m)= \begin{cases} 2^{\omega_1(m)}, & m \text{ squarefree and no }p\equiv3\pmod4\text{ divides }m,\\ 0,&\text{otherwise}. \end{cases}$$それから$$f(N)=\sum_{\substack{g\ \text{odd sq.free}}} A\!\left(\frac{N}{g^2}\right), \qquad A(x)=\sum_{m\le x}a(m).$$---

 #3. ディリクレ級数

 オイラー積は次のようになります。$$\sum_{n\ge1}\frac{c(n)}{n^s} = \prod_{p\equiv1(4)}(1+p^{-s})^2 \prod_{p\equiv3(4)}(1+p^{-2s}) (1+2^{-s}),$$どこ$c(n)$ノルムの平方自由ガウス整数をカウントします$n$。 

同様に、$$\sum_{n\ge1}\frac{c(n)}{n^s} = \frac{\zeta_{\mathbb Q(i)}(s)} {\zeta_{\mathbb Q(i)}(2s)}.$$Min_25 / ディリクレ双曲線スタイルの合計をメモ化された素数合計で使用すると、次の正確な計算が得られます。$N=10^{14}$。

 #4. Pythonの実装```python
from math import isqrt
from functools import lru_cache

N = 10**14

# sieve primes
L = isqrt(N)

limit = isqrt(L) + 10
sieve = [True]*(limit+1)
primes = []
for i in range(2, limit+1):
    if sieve[i]:
        primes.append(i)
        step = i
        start = i*i
        for j in range(start, limit+1, step):
            sieve[j] = False

# Möbius for odd squarefree numbers
M = isqrt(N)

mu = [1]*(M+1)
is_prime = [True]*(M+1)

for p in range(2, M+1):
    if is_prime[p]:
        for k in range(p, M+1, p):
            is_prime[k] = False
            mu[k] *= -1
        pp = p*p
        for k in range(pp, M+1, pp):
            mu[k] = 0

# multiplicative function a(n)
a = [0]*(M+1)
a[1] = 1

for n in range(2, M+1):
    x = n
    ok = True
    val = 1
    p = 2
    while p*p <= x:
        if x % p == 0:
            e = 0
            while x % p == 0:
                x //= p
                e += 1
            if e > 1:
                ok = False
                break
            if p % 4 == 3:
                ok = False
                break
            if p % 4 == 1:
                val *= 2
        p += 1 if p == 2 else 2
    if ok and x > 1:
        if x % 4 == 3:
            ok = False
        elif x % 4 == 1:
            val *= 2
    a[n] = val if ok else 0

# prefix sums
A = [0]*(M+1)
for i in range(1, M+1):
    A[i] = A[i-1] + a[i]

# count odd squarefree g
sqf_odd = [0]*(M+1)
s = 0
for i in range(1, M+1):
    if i & 1 and mu[i] != 0:
        s += 1
    sqf_odd[i] = s

# final summation
ans = 0
for g in range(1, isqrt(N)+1, 2):
    if mu[g] != 0:
        ans += A[N // (g*g)]

print(ans)
```---
