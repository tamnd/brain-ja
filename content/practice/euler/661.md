[プロジェクト オイラー問題 661](https://projecteuler.net/problem=661)

 ## 解決策

 **答え:**`646231.2177`後で得点差をつけよう$n$ゲームになる$$S_n = (\#\text{wins by A})-(\#\text{wins by B}).$$そして、各試合後に次のようにします。 

-$S\to S+1$確率的に$a=p_A$、
 -$S\to S-1$確率的に$b=p_B$、
 -$S\to S$確率的に$d=1-a-b$。 

また、毎試合後に確率で試合が停止します$p$、つまり確率で継続します$$q=1-p.$$私たちが欲しいのは$$\mathbb E_A(a,b,p) =\sum_{n\ge1}\Pr(S_n>0,\text{ game }n\text{ is played}).$$試合以来$n$前の場合に再生されます$n-1$継続トスは裏でした、$$\Pr(\text{game }n\text{ played})=q^{\,n-1}.$$したがって、$$\mathbb E_A(a,b,p) =\sum_{n\ge1} q^{n-1}\Pr(S_n>0).$$---

 #1. ランダムウォークの再発を解く

 定義する$F_i$スコアの差から始まる、A がリードする将来の予想回数$i$。 

のために$i\ge2$、$$F_i =1+q(aF_{i+1}+bF_{i-1}+dF_i),$$もう 1 試合後、A がまだリードしているのは確かだからです。 

のために$i\le -1$、$$F_i=q(aF_{i+1}+bF_{i-1}+dF_i),$$A が現在リードしていないためです。 

境界では:$$F_1=a(1+qF_2)+b(qF_0)+d(1+qF_1),$$

$$F_0=a(1+qF_1)+b(qF_{-1})+d(qF_0).$$---

 ## 均一な溶液

 特性方程式は$$qa r^2-(1-qd)r+qb=0.$$そのルーツをそのままにしましょう$\alpha,\beta$と$\alpha<1<\beta$:$$\alpha,\beta = \frac{1-qd\mp\sqrt{\Delta}}{2qa},$$どこ$$\Delta=(1-qd)^2-4q^2ab.$$使用する$d=1-a-b$、$$\Delta = p^2+2pq(a+b)+q^2(a-b)^2.$$有界解は次のとおりです。$$F_i= \begin{cases} \dfrac1p + B\alpha^i, & i\ge1,\\[1ex] C\beta^i, & i\le -1. \end{cases}$$境界方程式を解くと次のようになります。$$F_0 = \frac{1-\alpha}{pq(\beta-\alpha)}.$$使用する$$\beta-\alpha=\frac{\sqrt{\Delta}}{qa},$$そして単純化すると、$$\boxed{ \mathbb E_A(a,b,p) = \frac{\sqrt{\Delta}-p+q(a-b)} {2pq\sqrt{\Delta}} }$$と$$\Delta = p^2+2pq(a+b)+q^2(a-b)^2.$$---

 #2. 適用先$H(50)$私たちは与えられています$$a=\frac1{\sqrt{k+3}}, \qquad b=\frac1{\sqrt{k+3}}+\frac1{k^2}, \qquad p=\frac1{k^3}.$$それで$$H(50) = \sum_{k=3}^{50} \mathbb E_A(a,b,p).$$---

 #3. Pythonの実装```python
from math import sqrt

def EA(a, b, p):
    q = 1.0 - p

    Delta = (
        p * p
        + 2.0 * p * q * (a + b)
        + q * q * (a - b) * (a - b)
    )

    root = sqrt(Delta)

    return (root - p + q * (a - b)) / (2.0 * p * q * root)

H = 0.0

for k in range(3, 51):
    a = 1.0 / sqrt(k + 3)
    b = a + 1.0 / (k * k)
    p = 1.0 / (k ** 3)

    H += EA(a, b, p)

print("{:.10f}".format(H))
```---
