 ## 解決策

 **答え:**`333082500`最大の余りを求めます$$r = (a-1)^n + (a+1)^n \pmod{a^2}$$各整数に対して$3 \le a \le 1000$、そして計算します$$\sum_{a=3}^{1000} r_{\max}.$$重要なのは、式を単純化することです。$a^2$。 

---

 # ステップ 1 — 二項定理による展開

 検討してください$$(a+1)^n.$$二項定理を使用すると、$$(a+1)^n = \sum_{k=0}^n \binom{n}{k} a^k.$$モジュロ$a^2$を含むすべての用語$a^2$以上は消滅するため、最初の 2 つの項のみが重要になります。$$(a+1)^n \equiv 1 + na \pmod{a^2}.$$同様に、$$(a-1)^n = \sum_{k=0}^n \binom{n}{k} a^k (-1)^{n-k}.$$ここでも以下の用語のみを保持します$a^2$、$$(a-1)^n \equiv (-1)^n + n(-1)^{n-1}a \pmod{a^2}.$$ここで 2 つの式を追加します。$$r \equiv \left[1 + na\right] + \left[(-1)^n + n(-1)^{n-1}a\right] \pmod{a^2}.$$パリティによってケースを分けます$n$。 

---

 # ステップ 2 — 偶数と奇数$n$## ケース 1:$n$さえ

 それから$$(-1)^n = 1, \qquad (-1)^{n-1} = -1.$$それで$$r \equiv (1+na)+(1-na)=2 \pmod{a^2}.$$したがって、偶数ごとに$n$与える$$r=2.$$---

 ## ケース 2:$n$奇妙な

 それから$$(-1)^n=-1, \qquad (-1)^{n-1}=1.$$したがって、$$r \equiv (1+na)+(-1+na)=2na \pmod{a^2}.$$それで、奇数については$n$、$$r \equiv 2an \pmod{a^2}.$$したがって、問題は最大化に帰着します$$2an \bmod a^2.$$因数分解$a$:$$r = a(2n \bmod a).$$したがって、可能な限り最大の倍数が必要です$a$下に$a^2$。 

なぜなら$2n$が偶数の場合、達成可能な最大の剰余は次のパリティに依存します。$a$。 

---

 # ステップ 3 — 決定する$r_{\max}$＃＃ もし$a$奇妙です

 それから$a-1$は偶数なので選択できます$$2n \equiv a-1 \pmod a.$$これにより、$$r_{\max}=a(a-1).$$- -

＃＃ もし$a$均等です

 次に、以下の最大の偶数剰余$a$は$a-2$、 それで$$r_{\max}=a(a-2).$$---

 両方のケースをきれいに組み合わせることができます。$$r_{\max} = \begin{cases} a(a-1), & a \text{ odd},\\ a(a-2), & a \text{ even}. \end{cases}$$---

 # ステップ 4 — 合計を計算する

 今評価します$$\sum_{a=3}^{1000} r_{\max}.$$---

 # Pythonの実装```python
total = 0

for a in range(3, 1001):

    # If a is odd:
    # r_max = a(a - 1)
    if a % 2 == 1:
        r_max = a * (a - 1)

    # If a is even:
    # r_max = a(a - 2)
    else:
        r_max = a * (a - 2)

    total += r_max

print(total)
```---
