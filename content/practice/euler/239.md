[プロジェクト オイラー問題 239](https://projecteuler.net/problem=239)

 ## 解決策

 **答え:**`0.001887854841`がある$100$ディスクのうちの素数は、$1,\dots,100$は：$$2,3,5,7,11,\dots,97$$素数の数$\le 100$は$$\pi(100)=25.$$**まさに次の確率が必要です$22$素数のディスクは本来の位置にありません**。 

同様に:

 - その中で$25$プライムディスク、
 - まさに$3$固定されており、
 - もう一方$22$移動されます。 

非プライムディスクには制限がありません。 

---

 # ステップ 1 — 計数問題を再定式化する

 しましょう:

 -$P$= 素数位置のセット、$|P|=25$、
 -$C$= 複合/非プライム位置のセット、$|C|=75$。 

私たちが求めているのは：$$\Pr(\text{exactly 3 prime disks fixed})$$全体$100!$順列。 

どちらを選択してください$3$プライムディスクは固定されたままです:$$\binom{25}{3}.$$これで残りは$22$プライムディスクは修正してはなりません**。 

制限はありません。$75$非プライムディスク。 

したがって、それらを修正した後、$3$素数がある場合、残りの素数の順列を数えなければなりません$97$指定された要素$22$プライムディスクは独自の位置を回避します。 

これは標準的な包含/除外問題です。 

---

 # ステップ 2 — 包含と除外

 残りはしましょう$22$プライムディスクは区別されます。 

このようなディスクごとに$i$、イベントを定義します。$$A_i = \{\text{disk } i \text{ is fixed}\}.$$すべてを避ける順列が必要です$A_i$。 

残りの順列の合計$97$オブジェクト:$$97!.$$特定のサブセットを強制すると、$k$そのうちの$22$修復するディスクの場合、次のようになります。$$(97-k)!$$順列は残ります。 

したがって、包含と除外によって次のようになります。$$N = \sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)!.$$の選択も含めて、$3$固定素数:$$\#(\text{desired permutations}) = \binom{25}{3} \sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)!.$$したがって、確率は次のようになります。$$\boxed{ \frac{ \binom{25}{3} \displaystyle\sum_{k=0}^{22} (-1)^k \binom{22}{k} (97-k)! }{ 100! } }.$$---

 # ステップ 3 — Python の実装```python
from math import comb, factorial
from decimal import Decimal, getcontext

# use high precision
getcontext().prec = 50

total = factorial(100)

# inclusion-exclusion sum
s = 0
for k in range(23):
    s += (-1)**k * comb(22, k) * factorial(97 - k)

count = comb(25, 3) * s

prob = Decimal(count) / Decimal(total)

print(prob)
print(round(prob, 12))
```---
