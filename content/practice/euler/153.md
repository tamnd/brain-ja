[プロジェクト オイラー問題 153](https://projecteuler.net/problem=153)

 ## 解決策

 **答え:**`17971254122360635`させて$$S(N)=\sum_{n=1}^N s(n),$$どこ$s(n)$すべてのガウス整数約数の合計です。$n$その実部は正です。 

私たちには次のものが与えられます:$$S(10^5)=17924657155.$$私たちが求めているのは：$$S(10^8).$$---

 # 数学的分析

 ガウス整数は$$a+bi,\qquad a,b\in\mathbb Z.$$その標準は$$N(a+bi)=a^2+b^2.$$ガウス整数$a+bi$有理数を除算します$n$もし$$\frac{n}{a+bi}$$もガウス整数です。 

---

 ## 1. 有理数 ($b=0$)

 これらは単なる通常の正の約数です。$n$。 

彼らの貢献度の合計は、$$\sum_{n\le N}\sigma(n),$$どこ$\sigma(n)$は通常の除数和関数です。 

標準の除数切り替え ID を使用すると、次のようになります。$$\sum_{n\le N}\sigma(n) = \sum_{d\le N} d\left\lfloor \frac Nd\right\rfloor.$$---

 ## 2. 非実数ガウス約数

 仮定してください$$z=a+bi,\qquad b\neq 0.$$それから$$\frac{n}{a+bi} = \frac{n(a-bi)}{a^2+b^2}.$$これをガウス積分するには、両方とも$$\frac{na}{a^2+b^2}, \qquad \frac{nb}{a^2+b^2}$$整数でなければなりません。 

書く$$a=ga',\qquad b=gb', \qquad \gcd(a',b')=1.$$それから$$a^2+b^2=g^2(a'^2+b'^2).$$以来$$\gcd(a',a'^2+b'^2)=1, \qquad \gcd(b',a'^2+b'^2)=1,$$割り切れる条件は次のようになります$$g(a'^2+b'^2)\mid n.$$したがって、すべてのガウス約数は次から得られます。 

- プリミティブペア$(a',b')$と$\gcd(a',b')=1$、
 - スケーリング基準$g$。 

---

 ## 3. 共役ペアの寄与

 もし$a+bi$分割する$n$、それならそうなります$a-bi$。 

それらの合計は$$(a+bi)+(a-bi)=2a.$$したがって、虚数部は完全にキャンセルされます。 

したがって、すべてのプリミティブ ペアは実数値のみを提供します。 

させて$$m=a'^2+b'^2.$$スケールごとに$g$、除数のペアが寄与します$$2ga'$$の倍数ごとに$gm$。 

したがって、合計貢献度は、$$\sum_{\substack{a',b'>0\\ \gcd(a',b')=1}} 2a' \sum_{g\le N/m} g\left\lfloor\frac{N}{gm}\right\rfloor.$$しかし$$\sum_{g\le M} g\left\lfloor\frac{M}{g}\right\rfloor = \sum_{k\le M}\sigma(k).$$したがって：$$S(N) = \sum_{d\le N} d\left\lfloor\frac Nd\right\rfloor + 2\sum_{\substack{a,b>0\\ \gcd(a,b)=1}} a\, \Sigma\!\left(\left\lfloor\frac{N}{a^2+b^2}\right\rfloor\right),$$どこ$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$これが重要な公式です。 

---

 # 効率的なアルゴリズム

 必要なものは次のとおりです。 

1. 高速計算$$\Sigma(x)=\sum_{n\le x}\sigma(n).$$除数のグループ化を使用する:$$\Sigma(x) = \sum_{d\le x} d\left\lfloor\frac xd\right\rfloor.$$これは次のように評価できます。$O(\sqrt x)$。 

1. プリミティブ格子点を列挙する$$a^2+b^2\le N.$$問題となるのは互いに素のペアだけです。 

結果として得られるアルゴリズムは、PyPy で快適に高速に実行されます。$N=10^8$。 

---

 # Pythonの実装```python
from math import gcd, isqrt

N = 10**8

# Summatory sigma:
#   S(n) = sum_{k<=n} sigma(k)
#
# Using:
#   sum sigma(k) = sum d * floor(n/d)
#
# Computed in O(sqrt(n)) using divisor grouping.
def sigma_sum(n):
    total = 0
    d = 1

    while d <= n:
        q = n // d
        r = n // q

        # sum of integers d..r
        block = (d + r) * (r - d + 1) // 2

        total += q * block
        d = r + 1

    return total

# Memoize sigma_sum values because many repeats occur.
memo = {}

def Sigma(n):
    if n not in memo:
        memo[n] = sigma_sum(n)
    return memo[n]

# ----------------------------------------------------
# Rational integer divisors contribution
# ----------------------------------------------------

answer = Sigma(N)

# ----------------------------------------------------
# Non-real Gaussian divisors
# ----------------------------------------------------

limit = isqrt(N)

for a in range(1, limit + 1):

    max_b = isqrt(N - a * a)

    for b in range(1, max_b + 1):

        if gcd(a, b) != 1:
            continue

        m = a * a + b * b

        answer += 2 * a * Sigma(N // m)

print(answer)
```---

 # コードのチュートリアル

 ##`sigma_sum(n)`計算します$$\sum_{k\le n}\sigma(k).$$使用する$$\sum_{k\le n}\sigma(k) = \sum_{d\le n} d\left\lfloor\frac nd\right\rfloor.$$の値$\lfloor n/d\rfloor$間隔が一定であるため、それらをグループ化します。$O(\sqrt n)$。 

---

 ## 有理数の寄与```python
answer = Sigma(N)
```これはすべての通常の正の約数を説明します。 

---

 ## 原始ガウス約数

 互いに素のペアをループします。```python
if gcd(a, b) != 1:
    continue
```と```python
m = a*a + b*b
```このようなすべての原始ガウス約数が寄与します$$2a\cdot \Sigma\!\left(\left\lfloor\frac{N}{m}\right\rfloor\right).$$それで：```python
answer += 2 * a * Sigma(N // m)
```---
