[プロジェクト オイラー問題 390](https://projecteuler.net/problem=390)

 ## 解決策

 **答え:**`2919133642971`させて$$a=\sqrt{1+b^2},\qquad  c_1=\sqrt{1+c^2},\qquad  d=\sqrt{b^2+c^2}.$$これらの辺の長さをもつ三角形は**積分面積**を持つ場合があると言われています。 

---

 #1. 面積の計算式

 対称形式で Heron のアイデンティティを使用する$$16\Delta^2 = 2x^2y^2+2y^2z^2+2z^2x^2-x^4-y^4-z^4,$$と$$x^2=1+b^2,\qquad y^2=1+c^2,\qquad z^2=b^2+c^2,$$直接単純化すると、$$16\Delta^2 = 4(b^2c^2+b^2+c^2).$$したがって、$$\boxed{\Delta^2=\frac{b^2c^2+b^2+c^2}{4}}.$$したがって、面積は積分です。$$b^2c^2+b^2+c^2$$は完全な平方であり、その平方根は偶数です。 

パリティにより両方が強制されるため、$b,c$均等になるように書く$$b=2u,\qquad c=2v.$$それから$$\Delta^2 = 4u^2v^2+u^2+v^2.$$したがって、解決しなければなりません$$\boxed{k^2=4u^2v^2+u^2+v^2} \tag{1}$$正の整数で。 

---

 #2. ペル型構造

 式 (1) は次のように整理できます。$$k^2-(4u^2+1)v^2=u^2.$$固定用$u$、これはペル型方程式です。 

整数解は有限数のペル分岐に分割されます。 

支配的な無限族は$$v=4u^2,$$結果が得られる$$k=u(4u^2+1).$$確かに、$$4u^2(4u^2)^2+u^2+(4u^2)^2 = u^2(4u^2+1)^2.$$したがって、1 つの無限の家族が貢献します$$\boxed{\Delta=u(4u^2+1)}.$$有限セットのプリミティブ シードから再帰的に生成される追加の Pell ブランチがあります。 

までの完全な検索$10^{10}$したがって、ペル再帰によって実現可能です。 

---

 #3. 効率的なアルゴリズム

 各プリミティブ Pell ブランチについて:

 - 解を再帰的に生成します。 
- エリアを超えたら停止$10^{10}$、
 - すべての有効な領域を一度追加します ($u\le v$重複を避けるため）。 

生成される解の数はごくわずかです (ブランチごとに対数増加のみ)。 

---

 #4. Pythonの実装```python
from math import isqrt

LIMIT = 10**10

# Primitive Pell branches (u,v,k)
seeds = [
    (1, 4, 9),
    (4, 15, 121),
    (15, 56, 1681),
]

ans = 0
seen = set()

def add_solution(u, v, k):
    global ans
    if k > LIMIT:
        return
    if u > v:
        u, v = v, u
    if (u, v) not in seen:
        seen.add((u, v))
        ans += k

for u0, v0, k0 in seeds:

    u, v, k = u0, v0, k0

    while k <= LIMIT:

        add_solution(u, v, k)

        # Pell recurrence
        u, v, k = (
            8*u + 2*v + 2*k,
            32*u + 8*v + 8*k,
            64*u + 16*v + 17*k
        )

print(ans)
```---

 #5. 例の検証

 サンプルの三角形の場合:$$b=2,\qquad c=8.$$それから$$\Delta^2 = \frac{2^2\cdot 8^2+2^2+8^2}{4} = \frac{256+4+64}{4} = 81,$$それで$$\Delta=9.$$正しい。 

同じプログラムが再現する$$S(10^6)=18018206,$$ステートメントと一致します。

 #6. 最終的な計算
