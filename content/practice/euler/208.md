[プロジェクト オイラー問題 208](https://projecteuler.net/problem=208)

 ## 解決策

 **答え:**`331951449665644800`ロボットの進行方向を 5 つの方向のいずれかにします$$0,1,2,3,4 \pmod 5$$で区切られた角度に対応する$72^\circ$。 

あらゆる動きにおいて：

 - ロボットが横断する$72^\circ$円弧、
 - 時計回りまたは反時計回りのいずれかに回転する必要があります。 
- したがって、その見出しは次のように変更されます。$\pm 1 \pmod 5$。 

次のような長さ 70 の歩行をすべてカウントする必要があります。 

1. 北を向き始めます。 
2.開始位置で終了、
 3. アークを再利用できます。 
4. 正確に 70 個の円弧で構成されます。 

---

 #1. 重要な数学的洞察

 重要な観察は次のとおりです。 

> ロボットの最終的な位置は、5 つの見出しがそれぞれ何回使用されたかによってのみ決まります。 

---

 ## 1 つの移動による変位

 ロボットが現在ある方向を向いていると仮定します。$d$。 

時計回りまたは反時計回りの円弧は、同じ基本ベクトルの回転コピーである変位ベクトルを生成します。 5 つの方向すべてにわたって、これらのベクトルは正五角形の 5 つの回転になります。 

させて$v_d$機首方位に関連付けられた変位になります$d$。 

円周上に5つの方向が等間隔に配置されているため、$$v_0+v_1+v_2+v_3+v_4=0.$$それらの間の唯一の線形関係はこれです。 

したがって、総変位が消えるには、すべての係数が$v_d$等しくなければなりません。 

それで、もし$c_d$方向を向いている間に行われた移動の数です$d$、閉鎖が必要です$$c_0=c_1=c_2=c_3=c_4.$$全部で70手あるので、$$c_d = \frac{70}{5}=14.$$したがって:

 > 各方向が正確に 14 回使用された場合、パスは閉じられます。 

これにより、問題からジオメトリが完全に削除されます。 

---

 #2. 純粋な計数問題として再定式化する

 ここでは、次のような左/右折のシーケンスをカウントするだけで済みます。 

- 見出しは次から始まります$0$、
 - 移動するたびに見出しが変わります$\pm1 \pmod5$、
 - 各見出しは正確に 14 回使用されます。 
- 70 移動後、見出しは に戻ります。$0$。 

---

 #3. 動的プログラミング

 DP 状態を定義します。$$(a,b,c,d,e,\text{dir})$$どこ

-$a,b,c,d,e$見出しの回数は何回ですか$0,1,2,3,4$使用されてきました、
 -`dir`は現在の見出しです。 

見出しから`dir`私たち：

 1. その見出しのカウントをインクリメントします。 
2. 左または右に曲がります:$$\text{dir}\to \text{dir}\pm1 \pmod5.$$再帰は、70 の手がすべて使用されると終了します。 

---

 #4. Pythonの実装```python
from functools import lru_cache

TOTAL = 70
PER = 14   # each of the 5 directions must be used 14 times

@lru_cache(None)
def dp(a, b, c, d, e, direction):
    """
    Counts the number of valid continuations from this state.

    a,b,c,d,e = number of times directions 0..4
                have already been used
    direction = current heading
    """

    counts = [a, b, c, d, e]

    # impossible state
    if any(x > PER for x in counts):
        return 0

    steps_used = sum(counts)

    # all 70 moves completed
    if steps_used == TOTAL:
        return (
            1
            if direction == 0 and all(x == PER for x in counts)
            else 0
        )

    # current move uses the current heading
    counts[direction] += 1

    na, nb, nc, nd, ne = counts

    # next heading is left or right
    return (
        dp(na, nb, nc, nd, ne, (direction + 1) % 5)
        +
        dp(na, nb, nc, nd, ne, (direction - 1) % 5)
    )

answer = dp(0, 0, 0, 0, 0, 0)

print(answer)
```---

 #5. コードのチュートリアル

 ## メモ化```python
@lru_cache(None)
```すべての状態をキャッシュして、計算が 1 回だけ行われるようにします。 

メモ化がなければ再帰は指数関数的になります。 

---

 ## 状態変数```python
dp(a, b, c, d, e, direction)
```トラック:

 - 各見出しが何回使用されたか、
 - 現在の見出し。 

クロージャーは見出し数のみに依存するため、これで十分です。 

---

 ## 不可能な状態```python
if any(x > PER for x in counts):
    return 0
```どの見出しも 14 回を超えて使用することはできません。 

---

 ## 完了テスト```python
if steps_used == TOTAL:
```有効なクローズド ウォークは次の条件を満たす必要があります。```python
direction == 0
```そして```python
all(x == PER for x in counts)
```意味:

 - 元の見出しに戻りました。 
- どの方向も同様に頻繁に使用されました。 

- -

＃＃ 遷移```python

```現在のステップでは、現在の見出しが使用されます。 

次に分岐します。```python

(direction - 1) % 5
```反時計回りまたは時計回りの回転に対応します。
