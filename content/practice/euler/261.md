[プロジェクト オイラー問題 261](https://projecteuler.net/problem=261)

 ## 解決策

 **答え:**`238890850232021`させて$$S(a,b)=a^2+(a+1)^2+\cdots+b^2$$そして推測してください$k$スクエアピボットです。 次に、整数が存在します$m>0$そして$n\ge k$そのような$$(k-m)^2+\cdots+k^2=(n+1)^2+\cdots+(n+m)^2.$$そのようなすべての異なるものの合計を見つけなければなりません$k\le 10^{10}$。 

---

 #1. 数学的分析

 二乗和の公式は、$$\sum_{i=1}^{t} i^2=\frac{t(t+1)(2t+1)}6.$$したがって$$S(k-m,k)=S(n+1,n+m).$$これを接頭辞の合計を使って単純化して書くと、次のようになります。$$k^2(m+1)-km(m+1)-mn(m+n+1)=0.$$で割る$m(m+1)$より対称的な形状になります$$\frac{k^2}{m}-k-n-\frac{n^2}{m+1}=0. \tag{1}$$---

 ## 境界$m$以来$n\ge k$、$$\frac{k^2}{m}-2k-\frac{k^2}{m+1}\ge0.$$簡略化後:$$k\ge 2m(m+1).$$したがって、$k\le N=10^{10}$、$$2m(m+1)\le N.$$それで$$m \le \frac{-1+\sqrt{1+2N}}2 \approx 70710.$$したがって、約だけ$7\times 10^4$の値$m$チェックする必要があります。 

---

 # 2. ペル方程式への変換

 整数を導入する$x,t$による$$\begin{cases} 2k = m(x+1)+t,\\ 2n = (m+1)(x-1)+t. \end{cases}$$(1)に代入して収量を単純化すると$$m(m+1)(x^2-1)=t^2. \tag{2}$$今書いてください$$m=r p^2,\qquad m+1=s q^2,$$どこ$r,s$スクエアフリーです。 

連続する整数は互いに素であるため、$r,s$も共素です。 

式(2)は次のようになります。$$r s p^2 q^2 (x^2-1)=t^2.$$したがって、$rpsq\mid t$。 させて$$t=rpsq\,y.$$それから$$x^2-rs\,y^2=1. \tag{3}$$これはペル方程式です。 

したがって、それぞれについて$m$、私たちは：

 1. 四角形部分を計算します。$r,s$の$m,m+1$。 
2. ペル方程式を解く$$x^2-Dy^2=1, \qquad D=rs.$$3. すべての Pell ソリューションを生成します。 
4.回復する$$k=\frac{m(x+1)+t}{2}, \qquad t=rpsq\,y.$$5. すべてを区別する$k\le 10^{10}$。 

---

 #3. Pythonの実装```python
from math import isqrt

N = 10**10

# ---------------------------------------------------------
# Compute squarefree part and square part of every integer
# n = sf[n] * sq[n]^2
# ---------------------------------------------------------

M = (-1 + isqrt(1 + 2 * N)) // 2

sf = [0] * (M + 3)   # squarefree part
sq = [0] * (M + 3)   # square root of square part

for n in range(1, M + 3):

    x = 1
    y = 1
    t = n

    d = 2
    while d * d <= t:

        if t % d == 0:

            e = 0
            while t % d == 0:
                t //= d
                e += 1

            # odd exponent contributes to squarefree part
            if e & 1:
                x *= d

            # floor(e/2) contributes to square part
            y *= d ** (e >> 1)

        d += 1 if d == 2 else 2

    if t > 1:
        x *= t

    sf[n] = x
    sq[n] = y

# ---------------------------------------------------------
# Fundamental Pell solution x^2 - D y^2 = 1
# via continued fractions
# ---------------------------------------------------------

def pell_fundamental(D):

    a0 = isqrt(D)

    if a0 * a0 == D:
        return None

    m = 0
    d = 1
    a = a0

    num_prev, num = 1, a
    den_prev, den = 0, 1

    while num * num - D * den * den != 1:

        m = d * a - m
        d = (D - m * m) // d
        a = (a0 + m) // d

        num_prev, num = num, num_prev + a * num
        den_prev, den = den, den_prev + a * den

    return num, den

# ---------------------------------------------------------
# Enumerate all square-pivots
# ---------------------------------------------------------

ans_set = set()

for m in range(1, M + 1):

    D = sf[m] * sf[m + 1]

    x1, y1 = pell_fundamental(D)

    # Generate all Pell solutions
    x, y = x1, y1

    # t = sf[m]*sf[m+1]*sq[m]*sq[m+1]*y
    mult = sf[m] * sf[m + 1] * sq[m] * sq[m + 1]

    while True:

        t = mult * y

        kk = m * (x + 1) + t

        if kk > 2 * N:
            break

        nn = (m + 1) * (x - 1) + t

        # parity checks + n >= k
        if kk % 2 == 0 and nn % 2 == 0 and nn >= kk:
            ans_set.add(kk // 2)

        # Next Pell solution
        x, y = (
            x1 * x + D * y1 * y,
            x1 * y + y1 * x
        )

answer = sum(ans_set)

print(answer)
```---

 #4. コードのチュートリアル

 ## ステップ 1 — 検索を限定する```python
M = (-1 + isqrt(1 + 2 * N)) // 2
```から$$2m(m+1)\le N,$$これにより可能な限りの最大値が得られます$m$。 

---

 ## ステップ 2 — 整数を分解する

 すべての整数に対して$n$、$$n = \text{squarefree}(n)\times (\text{square part})^2.$$私たちは以下を保管します:

 -`sf[n]`= 正方形のない部分
 -`sq[n]`= 平方根の平方根

 これらはペル判別式を形成するために必要です。 

---

 ## ステップ 3 — ペル方程式を解く

 それぞれについて$m$、$$D = \operatorname{sf}(m)\operatorname{sf}(m+1).$$私たちが解決します$$x^2 - D y^2 = 1.$$機能`pell_fundamental`連分数を使用して基本解を計算します。 

---

 ## ステップ 4 — すべてのソリューションを生成する

 すべての Pell ソリューションは、次の基本単位の累乗から得られます。$$x+y\sqrt D=(x_1+y_1\sqrt D)^n.$$再発```python
x, y = (
    x1 * x + D * y1 * y,
    x1 * y + y1 * x
)
```それらを連続的に生成します。 

---

 ## ステップ 5 — 回復する$k$使用する$$k=\frac{m(x+1)+t}{2},$$と$$t=\operatorname{sf}(m)\operatorname{sf}(m+1)    \operatorname{sq}(m)\operatorname{sq}(m+1)\,y.$$パリティを検証し、$n\ge k$、次に個別に保存します$k$。
