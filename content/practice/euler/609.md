[プロジェクト オイラー問題 609](https://projecteuler.net/problem=609)

 ## 解決策

 **答え:**`172023848`させて$$\pi(n)=\#\{p\le n : p \text{ prime}\}.$$あ$\pi$-sequence は有限シーケンスです$$u=(u_0,u_1,\dots,u_m)$$と$m\ge1$、$u_{i+1}=\pi(u_i)$、すべての項が肯定的です。 

シーケンスごとに$u$、 させて$c(u)$の非素数要素の数になります。$u$。 

以下を定義します。$$p(n,k)=\#\{u : u_0\le n,\ c(u)=k\},$$そして$$P(n)=\prod_{k:\,p(n,k)>0} p(n,k).$$私たちは次のことを求められます。$$P(10^8)\pmod{1\,000\,000\,007}.$$---

 #1. 数学的分析

 ## 1.1 の構造$\pi$-シーケンス

 から始まる$x=u_0$、シーケンスは強制されます:$$x,\ \pi(x),\ \pi(\pi(x)),\ \dots$$届くまで$1$、 なぜなら$\pi(1)=0$そしてシーケンスは正のままでなければなりません。 

したがって、すべての開始値$x\ge2$正確に 1 つの最大チェーンを生成します。 

例：$$10\to4\to2\to1.$$有効な$\pi$-シーケンスはすべて少なくとも長さのプレフィックスです$2$:$$(10,4),\quad (10,4,2),\quad (10,4,2,1).$$---

 ## 1.2 再帰的記述

 定義する$V(x)$すべての値の複数セットになる$c(u)$で始まるシーケンスの場合$x$。 

もし$x>1$、 させて$$y=\pi(x).$$させて$$b(x)= \begin{cases} 0,&x\text{ prime}\\ 1,&x\text{ non-prime} \end{cases}$$次に:

 - 最も短いシーケンス$(x,y)$貢献する$$b(x)+b(y),$$- すべての長いシーケンスは先頭に追加することによって取得されます$x$からのシーケンスへ$y$、追加$b(x)$非素数カウントに。 

したがって：$$V(x)=\{b(x)+b(y)\}\cup\{b(x)+t:t\in V(y)\}.$$これにより、再帰の深さが非常に小さくなります。$\pi$非常に早く数を減らします。 

のために$10^8$:$$10^8\to5761455\to412849\to\cdots\to1$$したがって、最大深度は非常に小さいです (16 未満)。 

---

 ## 1.3 均等によるグループ化$\pi(x)$重要な観察:$$\pi(x)=y$$すべての人に当てはまります$$x\in[p_y,\ p_{y+1}-1],$$どこ$p_y$です$y$-番目の素数。 

この間隔内では次のようになります。 

- ちょうど 1 つの数値が素数です ($p_y$）、
 - 残りは複合です。 

したがって、すべての数字は同じです$\pi(x)$次の 2 つのタイプにのみ分類されます。 

1.プライム$p_y$、
 2.間の複合物$p_y$そして$p_{y+1}$。 

したがって、計算するだけで済みます$V(y)$それぞれに1回ずつ$y\le \pi(10^8)$。 

以来$$\pi(10^8)=5\,761\,455,$$これは完全に実現可能です。 

---

 #2. 効率的なアルゴリズム

 までのすべての素数をふるいにかけます$10^8$。 

それから、それぞれについて$y\le\pi(10^8)$:

 1. 計算する$V(y)$再帰から、
 2. 以下からの貢献を追加します。 

- プライム$p_y$、
 - との合成数$\pi(x)=y$。 

再帰の深さが小さいため、カウントの短いベクトルのみを保存します。 

複雑さ:

 - ふるい：$O(n\log\log n)$、
 - DP: 本質的に直線的$\pi(n)$。 

---

 #3. Pythonの実装```python
MOD = 1_000_000_007
N = 10**8
K = 16                      # safely larger than maximum depth

# ------------------------------------------------------------
# Odd-only sieve
# ------------------------------------------------------------

size = N // 2
sieve = bytearray(b'\x01') * size
sieve[0] = 0

limit = int(N**0.5)

for i in range(3, limit + 1, 2):
    if sieve[i // 2]:
        start = i * i // 2
        sieve[start::i] = b'\x00' * (((size - start - 1) // i) + 1)

primes = [2] + [2 * i + 1 for i in range(1, size) if sieve[i]]

m = len(primes)             # pi(10^8)

# ------------------------------------------------------------
# primality up to m
# ------------------------------------------------------------

is_prime_small = bytearray(m + 1)

for p in primes:
    if p <= m:
        is_prime_small[p] = 1

# ------------------------------------------------------------
# pi(x) for x <= m
# ------------------------------------------------------------

pi_small = [0] * (m + 1)

c = 0
for i in range(1, m + 1):
    c += is_prime_small[i]
    pi_small[i] = c

# ------------------------------------------------------------
# DP storage
#
# C[y][k] = number of sequences starting at y
#            having exactly k non-primes
# ------------------------------------------------------------

C = [[0] * K for _ in range(m + 1)]

# final p(n,k)
P = [0] * K

for y in range(1, m + 1):

    # build V(y)
    if y > 1:
        z = pi_small[y]

        by = 0 if is_prime_small[y] else 1
        bz = 0 if is_prime_small[z] else 1

        # shortest sequence (y, z)
        C[y][by + bz] += 1

        # longer sequences
        for k in range(K - by):
            C[y][by + k] += C[z][k]

    # --------------------------------------------------------
    # Contributions from x with pi(x)=y
    # --------------------------------------------------------

    bz = 0 if is_prime_small[y] else 1

    # prime x = p_y
    P[bz] += 1
    for k in range(K):
        P[k] += C[y][k]

    # composite x with pi(x)=y
    if y < m:
        gap = primes[y] - primes[y - 1] - 1
    else:
        gap = N - primes[-1]

    P[1 + bz] += gap

    for k in range(K - 1):
        P[k + 1] += gap * C[y][k]

# ------------------------------------------------------------
# Final product
# ------------------------------------------------------------

ans = 1

for v in P:
    if v:
        ans = (ans * (v % MOD)) % MOD

print(ans)
```---

 #4. コードのチュートリアル

 ## ふるい

 奇数のみのふるいを使用します。 

- インデックス$i$数字を表します$2i+1$、
 - メモリは、たとえ$10^8$。 

これにより、以下のすべての素数が生成されます。$10^8$。 

---

 ## コンピューティング$V(y)$それぞれについて$y$:```python
z = pi_small[y]
```それから：```python
C[y][by + bz] += 1
```最短のシーケンスを追加します$(y,z)$。 

次：```python
C[y][by + k] += C[z][k]
```からのすべてのシーケンスを拡張します$z$。 

---

 ## グループ化されたカウント

 すべての数字に$\pi(x)=y$一緒に扱われます。 

次のものがあります:

 - プライム 1 つ$x=p_y$、
 - 連続した素数間の複合が多数ある。 

これにより作業が大幅に軽減されます。
