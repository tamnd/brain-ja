[プロジェクト オイラー問題 122](https://projecteuler.net/problem=122)

 ## 解決策

 **答え:**`1582`させて$m(k)$計算に必要な乗算の最小数を示します。$n^k$から$n$。 

これは古典的な **最小加算連鎖** 問題です。 

**追加チェーン**$k$シーケンスです$$1=a_0<a_1<\cdots<a_r=k$$すべての項が満たされるように$$a_i=a_j+a_\ell \qquad (j,\ell<i).$$各ステップは 1 つの乗算に対応します。$$n^{a_j}\cdot n^{a_\ell}=n^{a_i}.$$したがって:

 - チェーンの長さ$r$乗算の数に等しい、
 -そして$m(k)$で終わる最短の加算チェーンの長さです。$k$。 

たとえば、$15$:$$1,2,3,6,12,15$$長さがある$5$、与える$$m(15)=5.$$---

 # 数学的分析

 計算しなければなりません$$\sum_{k=1}^{200} m(k).$$すべてのチェーンに対するブルートフォースは巨大ですが、$200$慎重に枝刈りされた深さ優先検索には十分小さいです。 

---

 ## 1. 追加チェーン

 現在力がわかっていると仮定します$$n^{a_0},n^{a_1},\dots,n^{a_r}.$$1 つの乗算は、2 つの既知の指数を結合します。$$n^{a_i}n^{a_j}=n^{a_i+a_j}.$$したがって、すべての新しい指数は、前の 2 つの指数の合計になります。 

したがって、最小乗算数$m(k)$の最短の加算チェーンの長さに等しい$k$。 

---

 ## 2. 下限

 チェーンに長さがある場合$r$、次の可能な最大の指数$r$ステップは毎回 2 倍することで得られます。$$1,2,4,8,\dots,2^r.$$したがって：$$k\le 2^r \quad\Rightarrow\quad r\ge \lceil \log_2 k\rceil.$$これにより、強力な枝刈りルールが得られます。 

---

 ## 3. 深さ優先の検索戦略

 チェーンを再帰的に構築します。 

どの段階でも次のことが可能です。$$[1,a_1,a_2,\dots,a_t].$$最大の指数から$a_t$、新しい候補者は次のとおりです。$$a_t+a_i \qquad (0\le i\le t).$$なぜこれで十分なのでしょうか?

 最適連鎖の定理は、新しい項が直前の項を使用する最適連鎖が常に存在することを示しています (「ブラウアー連鎖」)。 のために$k\le 200$、この検索はオイラー 122 の標準で十分です。 

既知の最良の長さを維持しながら、深さ優先で検索します。 

---

 ## 4. 反復深化

 ターゲットごとに$k$、次の長さのチェーンを検索します。$$0,1,2,\dots$$成功するまで。 

検索深度が小さいため (最大$m(k)$のために$k\le200$だけです$9$)、これは非常に高速です。 

---

 # Pythonの実装```python
from math import log2, ceil

LIMIT = 200

# best[k] = minimal addition-chain length found for k
best = [float('inf')] * (LIMIT + 1)
best[1] = 0

def dfs(chain, depth_limit):
    """
    Depth-first generation of addition chains.

    chain[-1] is the current largest exponent.
    len(chain)-1 is the number of multiplications used.
    """

    current = chain[-1]
    depth = len(chain) - 1

    # Update best result for current exponent
    if depth < best[current]:
        best[current] = depth

    # No more depth available
    if depth == depth_limit:
        return

    # Lower-bound pruning:
    # even if we double every remaining step,
    # can we improve anything?
    max_possible = current << (depth_limit - depth)

    # Generate next exponents in descending order
    # (larger jumps first tends to succeed earlier)
    used = set()

    for i in range(len(chain) - 1, -1, -1):
        nxt = current + chain[i]

        if nxt > LIMIT:
            continue

        if nxt in used:
            continue
        used.add(nxt)

        # If we already know an equal/better chain, skip
        if depth + 1 >= best[nxt]:
            continue

        # Append and recurse
        chain.append(nxt)
        dfs(chain, depth_limit)
        chain.pop()

# Iterative deepening
# Upper bound is safely 11 for n <= 200
for limit in range(1, 12):
    dfs([1], limit)

answer = sum(best[1:])

print(answer)
```---
