[プロジェクト オイラー問題 327](https://projecteuler.net/problem=327)

 ## 解決策

 **答え:**`34315549139516`させて$M(C,R)$通過するために必要なカードの最小枚数であること$R$最大でも持ち運べる部屋$C$カード。 

重要なのは、**1 つのドア**を通ってカードを移動する繰り返しを導き出すことです。 

### ステップ 1: 1 つのドアを通してカードを搬送する

 必要だとします$x$カードは隣の部屋で入手可能です。 

ドアを通って**往復**:

 - から始める$C$カード、
 - 1枚のカードを使用して入場し、
 - できるだけ多くを隣の部屋に残してください。 
- 返却にはカードを 1 枚使用します。 

この預金は最大でも$C-2$カードを次の部屋に送ります。 

**最後の片道旅行**:

 - から始める$y+1$カード、
 - 入力するには 1 つを使用します。 
- 次の部屋で終了$y$カード。 

それで、もし$$x=t(C-2)+y,\qquad 1\le y\le C-1,$$それから：

-$t$往復のデポジット$t(C-2)$、
 - 最後の旅行デポジット 1 回$y$。 

現在の部屋で必要なカードの合計:$$g_C(x)=tC+(y+1).$$この量を最小化する分解を選択します。 

### ステップ 2: 再帰的構造

 渡るには$R$部屋、あります$R+1$ドア（出口ドアを含む）。 

させて$f_k$事前に必要な最低限のカードであること$k$残った扉。 

基本ケース:$$f_0=0.$$再発：$$f_{k+1}=g_C(f_k).$$それから：$$M(C,R)=f_{R+1}.$$これは例を再現します。 

-$M(3,6)=123$、
 -$M(4,6)=23$、
 -$\sum_{C=3}^{10}M(C,10)=10382$。

 ## Pythonの実装```python
def transport_cost(C, x):
    """
    Minimum cards needed in the current room
    to end up in the next room with x cards.
    """
    # One trip is enough
    if x <= C - 1:
        return x + 1

    best = float("inf")

    # Try all possible sizes of the final trip
    for y in range(1, C):
        remaining = x - y

        # Must be exactly covered by round trips
        if remaining % (C - 2) == 0:
            t = remaining // (C - 2)
            cost = t * C + (y + 1)
            best = min(best, cost)

    return best

def M(C, R):
    """
    Minimum cards needed to traverse R rooms.
    """
    f = 0  # no doors remaining

    # R rooms => R+1 doors (including exit)
    for _ in range(R + 1):
        f = transport_cost(C, f)

    return f

# Compute the required sum
answer = sum(M(C, 30) for C in range(3, 41))

print(answer)
```### コードのチュートリアル

 -`transport_cost(C, x)`移動に必要な最小限のカードを計算します$x$カードは 1 つのドアから通過できます。 

- もし$x \le C-1$、1回の旅行で十分なので、コストは`x + 1`。 
- それ以外の場合は、可能な限りの最終旅行サイズを試してください。$y\in[1,C-1]$。 
- 残りのカードは、完全な往復の入金で得られたものでなければなりません$C-2$それぞれのカード。 
-`M(C, R)`このトランスポート ルールを繰り返し適用します。 

- がある`R + 1`ドアの合計。 
- から始める`f = 0`(最後の終了後は何も必要ありません)。
