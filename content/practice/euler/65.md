[プロジェクト オイラー問題 65](https://projecteuler.net/problem=65)

 ## 解決策

 **答え:**`272`の継続分数については、$e$、$$e=[2;1,2,1,1,4,1,1,6,1,\dots]$$係数は単純なパターンに従います。$$a_0=2,$$そしてのために$n\ge1$、$$a_n= \begin{cases} 2k & \text{if } n=3k-1,\\ 1 & \text{otherwise}. \end{cases}$$の分子が必要です。$100^\text{th}$収束してからその桁の合計。 

---

 # 数学的分析

 連分数$$[a_0;a_1,a_2,\dots,a_n]$$収束要素があります$\frac{p_n}{q_n}$以下によって再帰的に生成されます。$$p_n=a_n p_{n-1}+p_{n-2}$$

$$q_n=a_n q_{n-1}+q_{n-2}$$初期値あり$$p_{-2}=0,\quad p_{-1}=1$$

$$q_{-2}=1,\quad q_{-1}=0.$$これらの反復は、継続分数を左から右に繰り返し評価することによって直接得られます。 

- -

のために$e$、条件は次のとおりです。$$2,\ 1,\ 2,\ 1,\ 1,\ 4,\ 1,\ 1,\ 6,\ 1,\dots$$最初のいくつかの分子は次のとおりです。 

-$2$-$3$-$8$-$11$-$19$問題文と一致します。 

したがって、アルゴリズムは次のようになります。 

1. 最初の 100 個の係数を生成します。 
2. 収束には反復を使用します。 
3. 100 番目の収束の分子を取得します。 
4. その数字を合計します。 

---

 # Pythonの実装```python
# Generate the first 100 coefficients for e's continued fraction

terms = [2]

k = 1
while len(terms) < 100:
    terms.extend([1, 2 * k, 1])
    k += 1

terms = terms[:100]

# Recurrence for convergents
# p = numerator, q = denominator

p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0

for a in terms:
    p = a * p_minus1 + p_minus2
    q = a * q_minus1 + q_minus2

    p_minus2, p_minus1 = p_minus1, p
    q_minus2, q_minus1 = q_minus1, q

# Numerator of the 100th convergent
numerator = p_minus1

# Sum of digits
digit_sum = sum(int(d) for d in str(numerator))

print(digit_sum)
```---

 # コードのチュートリアル

 ## 連分数項を構築する```python
terms = [2]
```連分数は次から始まります$2$。```python
terms.extend([1, 2 * k, 1])
```これにより、繰り返しパターンが生成されます$$1,\ 2k,\ 1$$与える：$$1,2,1,1,4,1,1,6,1,\dots$$100期になるまで。 

---

 ## 収束再発

 以前の分子と分母を保存します。```python
p_minus2, p_minus1 = 0, 1
q_minus2, q_minus1 = 1, 0
```次に、各係数について$a$:```python
p = a * p_minus1 + p_minus2
q = a * q_minus1 + q_minus2
```これは以下を実装します:$$p_n=a_n p_{n-1}+p_{n-2}$$

$$q_n=a_n q_{n-1}+q_{n-2}$$---

 ## 小規模な例の検証

 最初のいくつかの用語を使用すると、次のようになります。$$[2] = \frac21$$

$$[2;1] = 3$$

$$[2;1,2] = \frac83$$

$$[2;1,2,1] = \frac{11}{4}$$これらは問題ステートメントで指定された値と正確に一致しており、再発が正しいことが確認されます。

 # 最終確認

 100 番目の収束の分子は非常に大きな整数であるため、桁の合計が数百程度になるのが妥当です。 計算では正確な整数演算のみが使用されるため、浮動小数点エラーは発生しません。 

計算を実行すると、次のようになります。$$272$$**答え: 272**
