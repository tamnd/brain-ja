[プロジェクト オイラー問題 795](https://projecteuler.net/problem=795)

 ## 解決策

 **答え:**`955892601606483`させて$$g(n)=\sum_{i=1}^{n}(-1)^i\gcd(n,i^2).$$私たちは求めています$$G(N)=\sum_{n=1}^N g(n), \qquad G(12345678).$$---

 #1. 数学的分析

 ## ステップ 1: オイラーの全体恒等式を使用して gcd を展開する

 標準的なアイデンティティは$$\gcd(a,b)=\sum_{d\mid \gcd(a,b)}\varphi(d).$$したがって、$$g(n) = \sum_{i=1}^n (-1)^i \sum_{\substack{d\mid n\\ d\mid i^2}} \varphi(d).$$合計の順序を入れ替えます。$$g(n) = \sum_{d\mid n}\varphi(d) \sum_{\substack{1\le i\le n\\ d\mid i^2}} (-1)^i.$$定義する$$S(n,d)=\sum_{\substack{1\le i\le n\\ d\mid i^2}}(-1)^i.$$それから$$g(n)=\sum_{d\mid n}\varphi(d)\,S(n,d).$$---

 ## ステップ 2: 状態を特徴付ける$d\mid i^2$書く$$d=\prod p^{a_p}.$$それから$d\mid i^2$もし$$p^{a_p}\mid i^2 \iff p^{\lceil a_p/2\rceil}\mid i.$$したがって、条件は次と同等です。$$q(d)\mid i,$$どこ$$q(d)=\prod p^{\lceil a_p/2\rceil}.$$したがって、有効な$i$はまさに次の倍数です$q(d)$。 

---

 ## ステップ 3: 交互の合計を評価する

 ### ケース A:$q(d)$奇妙な

 次に、の倍数$q(d)$代替パリティ。 

- もし$n$が偶数である場合、偶数と奇数の倍数は同じ数だけ存在します。$$S(n,d)=0.$$- もし$n$が奇数である場合、余分な奇数項が 1 つあります。$$S(n,d)=-1.$$したがって、奇数の場合$n$、$$g(n) = -\sum_{d\mid n}\varphi(d) = -n.$$(使用して$\sum_{d\mid n}\varphi(d)=n$）。 

---

 ### ケース B:$q(d)$さえ

 次に、次の倍数ごとに、$q(d)$は偶数であるため、すべての項が寄与します$+1$。 

倍数の数は、$$\frac{n}{q(d)}$$（なぜなら$q(d)\mid n$いつでも$d\mid n$）。 

したがって、$$S(n,d)=\frac{n}{q(d)}.$$これは偶数の場合にのみ発生します$d$。 

したがって、偶数については、$n$、$$g(n) = \sum_{\substack{d\mid n\\ d\text{ even}}} \varphi(d)\frac{n}{q(d)}.$$---

 #2. 合計して取得する$G(N)$奇数と偶数を分割する$n$。 

奇数の場合$n$、$$g(n)=-n.$$までの奇数$N$合計する$$1+3+5+\cdots+(2m-1)=m^2, \quad m=\left\lfloor\frac{N+1}{2}\right\rfloor.$$したがって、奇妙な貢献度は$$-\left\lfloor\frac{N+1}{2}\right\rfloor^2.$$偶数でも処理できるようになりました$n$:$$\sum_{\substack{n\le N\\ n\text{ even}}}g(n) = \sum_{d\text{ even}\le N} \varphi(d) \sum_{\substack{n\le N\\ d\mid n}} \frac{n}{q(d)}.$$書く$n=dk$。 それから$$= \sum_{d\text{ even}\le N} \frac{\varphi(d)d}{q(d)} \sum_{k\le N/d}k.$$以来$$\sum_{k\le m}k=\frac{m(m+1)}2,$$私たちは得ます$$G(N) = -\left\lfloor\frac{N+1}{2}\right\rfloor^2 + \sum_{d\text{ even}\le N} \frac{\varphi(d)d}{q(d)} \cdot \frac{m(m+1)}2,$$どこ$$m=\left\lfloor\frac{N}{d}\right\rfloor.$$---

 #3. 乗算係数

 定義する$$f(d)=\frac{\varphi(d)d}{q(d)}.$$これは乗算です。 

プライムパワーのために$p^e$、$$q(p^e)=p^{\lceil e/2\rceil},$$それで$$f(p^e) = (p-1)p^{e-1} \cdot p^{e-\lceil e/2\rceil} = (p-1)p^{2e-1-\lceil e/2\rceil}.$$これにより、線形ふるい計算が可能になります。$O(N)$。 

---

 #4. Pythonの実装```python
from array import array

N = 12345678

# f(n) = phi(n) * n / q(n)
# where q(p^e) = p^ceil(e/2)

f = array('Q', [0]) * (N + 1)
exp = array('B', [0]) * (N + 1)
pp  = array('I', [0]) * (N + 1)

primes = []
f[1] = 1

def local_value(p, e):
    # f(p^e) = (p-1) * p^(2e-1-ceil(e/2))
    return (p - 1) * (p ** (2 * e - 1 - ((e + 1) // 2)))

# Linear sieve
for i in range(2, N + 1):

    if pp[i] == 0:
        primes.append(i)
        pp[i] = i
        exp[i] = 1
        f[i] = local_value(i, 1)

    for p in primes:
        v = i * p

        if v > N:
            break

        if i % p == 0:
            # extend prime power
            pp[v] = pp[i] * p
            exp[v] = exp[i] + 1

            e = exp[v]

            new_local = local_value(p, e)
            old_local = local_value(p, e - 1)

            f[v] = (f[i] // old_local) * new_local
            break

        else:
            # new prime factor
            pp[v] = p
            exp[v] = 1
            f[v] = f[i] * local_value(p, 1)

# Odd contribution
m = (N + 1) // 2
G = -m * m

# Even divisor contribution
for d in range(2, N + 1, 2):
    t = N // d
    G += f[d] * t * (t + 1) // 2

print(G)
```---

 #5. コードのチュートリアル

 ### 配列

 -`f[n]`店$$f(n)=\frac{\varphi(n)n}{q(n)}.$$-`exp[n]`最小の素因数の指数を格納します。 
-`pp[n]`対応する素数パワーを格納します。 

リニアシーブの標準的な構造です。 

---

 ###`local_value(p,e)`器具$$f(p^e)=(p-1)p^{2e-1-\lceil e/2\rceil}.$$なぜなら$f$は乗法であるため、すべての値は素数べき乗から構築できます。 

---

 ### 最終合計

 実装された式は正確に$$G(N) = -\left\lfloor\frac{N+1}{2}\right\rfloor^2 + \sum_{d\text{ even}\le N} f(d)\cdot \frac{\lfloor N/d\rfloor(\lfloor N/d\rfloor+1)}2.$$---
