[プロジェクト オイラー問題 24](https://projecteuler.net/problem=24)

 ## 解決策

 **答え:**`2783915460`辞書編集上の数字の 100 万番目の並べ替えを見つけるには`0–9`、すべてを生成するのではなく、**階乗数体系**を使用します。`10! = 3,628,800`順列。 

**1,000,000 番目**の順列が必要ですが、インデックス付けは次のとおりです。`0`計算が簡単になります:$$999,999$$各ステップで、階乗ブロックを使用して次の位置にどの桁が属するかを決定します。 

-$9! = 362880$:$999999 \div 362880 = 2$残り$274239$→ 3 桁目を選択してください:`2`残りの桁:`0,1,3,4,5,6,7,8,9`-$8! = 40320$:$274239 \div 40320 = 6$残り$32319$→選ぶ`7`残り：`0,1,3,4,5,6,8,9`-$7! = 5040$:$32319 \div 5040 = 6$残り$2079$→選ぶ`8`このプロセスを続けると、次の結果が得られます。`2783915460`### クリーンな Python コード```python
from math import factorial

digits = list("0123456789")
n = 999999  # zero-based index

result = []

for i in range(9, -1, -1):
    f = factorial(i)
    index = n // f
    result.append(digits.pop(index))
    n %= f

answer = "".join(result)
print(answer)
```階乗選択を追跡すると、順列が確認されます。`2783915460`**答え: 2783915460**
