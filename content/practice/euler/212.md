[プロジェクト オイラー問題 212](https://projecteuler.net/problem=212)

 ## 解決策

 **答え:**`328968937309`直方体を **半分開いた箱** として解釈しましょう$$[x_0,x_0+dx)\times [y_0,y_0+dy)\times [z_0,z_0+dz)$$これは、ステートメント内の閉じたバージョンと同じボリュームを持ちますが、境界の重複の曖昧さを回避します。 

タスクは、次の和集合の体積を計算することです。$50{,}000$軸が揃った直方体。 

---

 # 数学的分析

 直接的な包含と排除のアプローチは不可能です。直方体が多すぎるからです。 

軸に揃えられたボックスの結合体積を計算する標準的な方法は、**スイープ ライン アルゴリズム**です。 

---

 ## 1. スイープイン$x$-方向

 各直方体は次のことに貢献します。 

- **入場イベント**$x=x_0$- **退職イベント**$x=x_0+dx$連続する 2 つの間$x$-座標、直方体のアクティブなセットは変更されません。 

したがって、アクティブな四角形の結合領域が$yz$-飛行機は$A(x)$、 それから$$V = \sum (\Delta x)\cdot A(x)$$この問題では、すべての座標は整数であり、$$0 \le x < 10400$$なぜなら：

-$x_0 < 10000$-$dx \le 399$したがって、処理する必要があるのは$10400$整数スラブ。 

---

 ## 2. の共用体領域を計算します。$yz$-平面

 現在アクティブな直方体の場合は、それらを$yz$-飛行機。 

それぞれが長方形になります$$[y_1,y_2)\times[z_1,z_2)$$ここでもスイープラインを使用します。 

- 一掃する$y$- カバーされた長さを維持します$z$各長方形について:

 - イベントを追加$(y_1, z_1,z_2,+1)$- イベントを追加$(y_2, z_1,z_2,-1)$セグメントツリー$z$-axis ストア:

 - カバレッジ数
 - カバーされた全長

 ノードのカウントが正の場合、その間隔全体がカバーされます。 

したがって、結合領域は次のように累積されます。$$\text{area} += (y_i-y_{i-1}) \times (\text{covered z-length})$$---

 # Pythonの実装```python
from collections import defaultdict

# ------------------------------------------------------------
# Lagged Fibonacci Generator
# ------------------------------------------------------------

S = [0] * 300001

for k in range(1, 56):
    S[k] = (100003 - 200003 * k + 300007 * k * k * k) % 1000000

for k in range(56, 300001):
    S[k] = (S[k - 24] + S[k - 55]) % 1000000

# ------------------------------------------------------------
# Build cuboids and x-events
# ------------------------------------------------------------

ADD = defaultdict(list)
REMOVE = defaultdict(list)

for n in range(1, 50001):

    x0 = S[6 * n - 5] % 10000
    y0 = S[6 * n - 4] % 10000
    z0 = S[6 * n - 3] % 10000

    dx = 1 + (S[6 * n - 2] % 399)
    dy = 1 + (S[6 * n - 1] % 399)
    dz = 1 + (S[6 * n] % 399)

    cuboid = (y0, y0 + dy, z0, z0 + dz)

    ADD[x0].append(cuboid)
    REMOVE[x0 + dx].append(cuboid)

# ------------------------------------------------------------
# Segment tree for union length on z-axis
# ------------------------------------------------------------

ZMAX = 10400

class SegmentTree:

    def __init__(self, n):
        self.n = n
        self.count = [0] * (4 * n)
        self.length = [0] * (4 * n)

    def update(self, node, left, right, ql, qr, val):

        if qr <= left or right <= ql:
            return

        if ql <= left and right <= qr:
            self.count[node] += val
        else:
            mid = (left + right) // 2

            self.update(node * 2, left, mid, ql, qr, val)
            self.update(node * 2 + 1, mid, right, ql, qr, val)

        if self.count[node] > 0:
            self.length[node] = right - left
        else:
            if right - left == 1:
                self.length[node] = 0
            else:
                self.length[node] = (
                    self.length[node * 2]
                    + self.length[node * 2 + 1]
                )

# ------------------------------------------------------------
# Main sweep in x
# ------------------------------------------------------------

active = []
volume = 0

for x in range(10400):

    # add cuboids starting here
    active.extend(ADD[x])

    # remove cuboids ending here
    for r in REMOVE[x]:
        active.remove(r)

    # build y-events
    events = []

    for y1, y2, z1, z2 in active:
        events.append((y1, z1, z2, +1))
        events.append((y2, z1, z2, -1))

    events.sort()

    # sweep in y
    seg = SegmentTree(ZMAX)

    area = 0
    prev_y = 0
    i = 0

    while i < len(events):

        y = events[i][0]

        area += (y - prev_y) * seg.length[1]

        while i < len(events) and events[i][0] == y:
            _, z1, z2, typ = events[i]
            seg.update(1, 0, ZMAX, z1, z2, typ)
            i += 1

        prev_y = y

    volume += area

print(volume)
```---

 # コードのチュートリアル

 ## 直方体の生成

 遅延フィボナッチ ジェネレーターは次のことを生成します。$300000$数字。 

6 つの数値ごとに 1 つの直方体が定義されます。$$(x_0,y_0,z_0,dx,dy,dz)$$ステートメントと正確に一致します。 

---

 ## イベント構築

 各直方体について:

 - に追加します$x_0$- で削除します$x_0+dx$これにより、スイープイン中にアクティブ セットを維持できます。$x$。 

---

 ## セグメントツリー

 セグメント ツリーは、結合の長さを維持します。$z$-軸。 

各ノードには以下が保存されます。 

-`count[node]`= そのノードを完全にカバーする間隔の数
 -`length[node]`= カバーされた全長

 カバレッジ数が正の場合、間隔は完全にカバーされます。 

それ以外の場合、補償は子供たちから行われます。 

---

 ## 内部スイープイン$y$アクティブな長方形の場合:

 - イベントに参加する$y_1$- 退出イベント$y_2$連続した間$y$- 値、対象範囲$z$-長さは一定です。 

それで：$$\Delta \text{area} = (\Delta y)\times(\text{covered z length})$$---

 # 検証

 問題には次のように書かれています。 

> 最初の 100 個の直方体の合計体積は 723581599 です。 

最初の 100 個の直方体に対してのみ同じアルゴリズムを実行すると、以下が正確に再現されます。$$723581599$$したがって、実装は検証されます。 

最終巻は約$3.29\times 10^{11}$、これは合理的です:

 - 境界ボックスの合計ボリュームはおおよそ次のとおりです。$10^4{}^3 = 10^{12}$- 重複する部分がたくさんあります
 - 各直方体は比較的小さい

 したがって、大きさは一定です。
