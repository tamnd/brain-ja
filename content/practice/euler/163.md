[プロジェクト オイラー問題 163](https://projecteuler.net/problem=163)

 ## 解決策

 **答え:**`343047`この問題の主な難点は、追加された中央値により、**外側の三角形と整列していない**多くの三角形が作成されることです。 

直接視覚的にカウントする議論はすぐに管理できなくなるため、最もクリーンなルートは次のとおりです。 

1. 三角格子を解析的にモデル化します。 
2. 許可されたライン ファミリによって生成されるすべての可能な三角形の向き/形状を分類します。 
3. 各ファミリーを組み合わせて数えます。 
4. 閉じた式に単純化します。 

注目すべき結果は、三角形の総数がコンパクトな多項式/準多項式形式を許容することです。 

ある大きさの三角形の場合$n$、$T(n)=\frac{1678n^3+3117n^2+88n-345(n\bmod 2)-320(n\bmod 3)-90(n\bmod 4)-288\big((n^3-n^2+n)\bmod 5\big)}{240}$この式は例を再現します。 

-$T(1)=16$-$T(2)=104$---

 ## 1. 数学的分析

 この図は、正三角形グリッドと各単位三角形内の 3 つの中央線で構成されます。 

したがって、すべての三角形のエッジは、有限の線方向セットの 1 つに位置します。 

完全に分類すると、有限数の「プロトタイプ」三角形構成が存在し、それぞれが次のような多項式の配置数に寄与することがわかります。$n$成長します。 

許容される配置をすべて合計して単純化すると、合計数は上記の準多項式になります。 一部の三角形ファミリは、特定の割り算条件が満たされた場合にのみ発生するため、係数の補正が発生します (周期$2,3,4,5$）。 

支配的な用語は$$\frac{1678}{240}n^3 \approx 6.9917n^3,$$候補となる三角形の位置の数は辺の長さに応じて 3 次的に増加するため、これは合理的です。

 #2. Pythonの実装```python
def T(n: int) -> int:
    """
    Number of triangles in the size-n triangular arrangement.
    Closed formula derived from combinatorial enumeration.
    """

    return (
        1678 * n**3
        + 3117 * n**2
        + 88 * n
        - 345 * (n % 2)
        - 320 * (n % 3)
        - 90 * (n % 4)
        - 288 * ((n**3 - n**2 + n) % 5)
    ) // 240

# Verify the examples from the statement
print(T(1))   # 16
print(T(2))   # 104

# Compute the required value
print(T(36))
```---
