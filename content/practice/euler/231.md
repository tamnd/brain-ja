[プロジェクト オイラー問題 231](https://projecteuler.net/problem=231)

 ## 解決策

 **答え:**`7526965179680`次の素因数 (多重度付き) の合計が必要です。$$\binom{20\,000\,000}{15\,000\,000}.$$同様に、もし$$\binom{n}{k}=\prod_p p^{e_p},$$私たちは求めています$$\sum_p p\,e_p.$$小さな例としては、$$\binom{10}{3}=120=2^3\cdot3\cdot5,$$したがって、必要な合計は$$2\cdot3+3\cdot1+5\cdot1=14.$$---

 #1. 数学的分析

 重要なアイデアは、ルジャンドルの公式を使用して階乗内の各素数の指数を計算することです。 

プライムの場合$p$、$$v_p(n!)=\sum_{i\ge1}\left\lfloor \frac{n}{p^i}\right\rfloor.$$したがって、$$v_p\!\left(\binom{n}{k}\right) = v_p(n!) - v_p(k!) - v_p((n-k)!).$$この問題については:$$n=20\,000\,000,\qquad k=15\,000\,000,\qquad n-k=5\,000\,000.$$したがって、$$e_p = \sum_{i\ge1} \left( \left\lfloor \frac{20\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{15\,000\,000}{p^i}\right\rfloor - \left\lfloor \frac{5\,000\,000}{p^i}\right\rfloor \right).$$望ましい答えは、$$\sum_{p\le 20\,000\,000} p\,e_p.$$したがって、アルゴリズムは次のようになります。 

1. 以下のすべての素数を生成します。$20\,000\,000$ふるいを使って。 
2. 各素数について$p$:

 - コンピューティング$e_p$ルジャンドルの公式で。 
- 追加$p\cdot e_p$合計に。 

これは次の理由から効率的です。 

- 程度しかありません$1.27$百万素数まで$20$百万、
 - そして各素数はのみ寄与します$O(\log_p n)$条項。

 #2. Pythonの実装```python
from math import isqrt

N = 20_000_000
K = 15_000_000

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------
# Generate all primes <= N
sieve = bytearray(b"\x01") * (N + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(N) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# ---------------------------------------------------------
# Legendre exponent for p in n!
# ---------------------------------------------------------
def vp_factorial(n, p):
    total = 0
    while n:
        n //= p
        total += n
    return total

# ---------------------------------------------------------
# Compute the required sum
# ---------------------------------------------------------
answer = 0

for p in primes:
    exponent = (
        vp_factorial(N, p)
        - vp_factorial(K, p)
        - vp_factorial(N - K, p)
    )

    answer += p * exponent

print(answer)
```---

 #4. 小さな例の検証

 テイク$$\binom{10}{3}=120.$$素数指数:

 -$v_2(10!)=5+2+1=8$-$v_2(3!)=1$-$v_2(7!)=3+1=4$したがって、2の指数は次のようになります。$$8-1-4=3.$$同様に:

 - 3の指数は$1$、
 - 5の指数は$1$。 

したがって$$2\cdot3 + 3\cdot1 + 5\cdot1 = 6+3+5 = 14,$$ステートメントと一致します。
