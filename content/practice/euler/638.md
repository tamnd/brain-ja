[プロジェクト オイラー問題 638](https://projecteuler.net/problem=638)

 ## 解決策

 **答え:**`18423394`パスを次のもので構成します。$a$正しいステップと$b$アップステップ。 

右ステップが発生する高さによってパスをエンコードすると、パスの下の領域は正確にそれらの高さの合計になります。 

重要な観察は、これは ** であるということです。$q$-二項係数** (ガウス二項係数)。 

パスの場合$P_{a,b}$、$$C(a,b,k) = \sum_{P_{a,b}} k^{A(P)}$$は、面積によって重み付けされた格子パスの生成関数です。 これが古典的なアイデンティティです。$$C(a,b,k) = \binom{a+b}{a}_k = \prod_{i=1}^{a} \frac{k^{b+i}-1}{k^i-1}.$$これは、単調格子パス上の面積統計が反転計数/フェラス図の面積に対応し、その生成関数がガウス二項であるためです。 

のために$k=1$の場合、式は通常の二項係数になります。$$C(a,b,1)=\binom{a+b}{a},$$これは指定された例と一致します。$$C(10,10,1)=\binom{20}{10}=184756.$$別のサンプルを検証できます。$$C(15,10,3) = \prod_{i=1}^{15} \frac{3^{10+i}-1}{3^i-1} \equiv 880419838 \pmod{10^9+7},$$ステートメントと一致します。 

### 効率的なアルゴリズム

 必要です$$\sum_{k=1}^{7} C(10^k+k,10^k+k,k) \pmod{10^9+7}.$$以来$$C(n,n,k) = \prod_{i=1}^{n} \frac{k^{n+i}-1}{k^i-1},$$積をモジュロで反復的に評価します$$M=1\,000\,000\,007.$$なぜなら$M$が素数の場合、除算は逆モジュラーを使用して行われます。$$x^{-1}\equiv x^{M-2}\pmod M.$$Python の実装:```python
MOD = 1_000_000_007

def C(a, b, k):
    # Special case q = 1:
    # ordinary binomial coefficient C(a+b, a)
    if k == 1:
        res = 1
        for i in range(1, a + 1):
            res = res * (b + i) % MOD
            res = res * pow(i, MOD - 2, MOD) % MOD
        return res

    q = k % MOD
    q_to_b = pow(k, b, MOD)

    res = 1
    q_pow_i = 1

    # Product:
    # ∏_{i=1}^{a} (k^(b+i)-1)/(k^i-1)
    for i in range(1, a + 1):
        q_pow_i = q_pow_i * q % MOD

        numerator = (q_to_b * q_pow_i - 1) % MOD
        denominator = (q_pow_i - 1) % MOD

        res = (
            res
            * numerator
            % MOD
            * pow(denominator, MOD - 2, MOD)
            % MOD
        )

    return res

answer = 0

for k in range(1, 8):
    n = 10**k + k
    answer = (answer + C(n, n, k)) % MOD

print(answer)
```### コードのチュートリアル

 -`C(a, b, k)`重み付けされた格子パスの合計を計算します。 
- もし`k == 1`、通常の二項係数を計算します$\binom{a+b}{a}$。 
- それ以外の場合は、ガウス二項積公式を使用します。 
-`q_pow_i`店$k^i$段階的に。 
- それぞれの要因$$\frac{k^{b+i}-1}{k^i-1}$$乗算されたモジュロです$10^9+7$、フェルマー逆関数を使用します。 

健全性チェック:

 -`C(2,2,1) = 6`-`C(2,2,2) = 35`-`C(10,10,1) = 184756`-`C(15,10,3) ≡ 880419838 (mod 10^9+7)`-`C(10000,10000,4) ≡ 395913804 (mod 10^9+7)`すべて問題文と一致します。 

の計算値$k=1,\dots,7$合計すると:$$18\,423\,394 \pmod{1\,000\,000\,007}.$$**答え: 18423394**
