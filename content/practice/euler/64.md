[プロジェクト オイラー問題 64](https://projecteuler.net/problem=64)

 ## 解決策

 **答え:**`1322`非平方整数の場合$N$、の連分数展開$\sqrt N$定期的です。 連分数を生成するための標準アルゴリズムは次のとおりです。$$a_0=\lfloor \sqrt N \rfloor$$そして再帰的に$$m_{k+1}=d_k a_k-m_k$$

$$d_{k+1}=\frac{N-m_{k+1}^2}{d_k}$$

$$a_{k+1}=\left\lfloor \frac{a_0+m_{k+1}}{d_{k+1}} \right\rfloor$$初期値あり$$m_0=0,\qquad d_0=1,\qquad a_0=\lfloor\sqrt N\rfloor.$$のシーケンス$a_k$結局繰り返します。 平方根の場合、古典的な定理によれば、期間は正確に次の時点で終了します。$$a_k = 2a_0.$$したがって、非正方形ごとに$N$までの項を生成できます。$a_k=2a_0$、発生した歩数をカウントします。 そのカウントが周期の長さになります。 

何個か数える必要があります$N \le 10000$**奇数**の期間の長さを持っています。 

---

 ## 数学的導出

 連分数アルゴリズムは、次の形式の式を繰り返し有理化することから生まれます。$$\frac1{\sqrt N - m}.$$あるステップで次のようになったとします。$$\frac{\sqrt N + m_k}{d_k}.$$整数部分を区切ります。$$a_k = \left\lfloor \frac{a_0+m_k}{d_k}\right\rfloor,$$そして書き換えます:$$\frac{\sqrt N + m_k}{d_k} = a_k + \frac{\sqrt N - m_{k+1}}{d_{k+1}},$$これにより、上記の漸化式が得られます。 

次のような二次無理数の場合$\sqrt N$、状態ペア$(m_k,d_k)$最終的には繰り返す必要があるため、継続分数は周期的になります。 

平方根に特有の便利なプロパティは次のとおりです。$$\text{period ends when } a_k = 2a_0.$$したがって、期間の計算は簡単です。

 ## Pythonの実装```python
import math

def continued_fraction_period(n):
    """
    Return the period length of the continued fraction
    expansion of sqrt(n).
    """
    
    a0 = int(math.isqrt(n))
    
    # Perfect squares have no periodic continued fraction
    if a0 * a0 == n:
        return 0
    
    m = 0
    d = 1
    a = a0
    
    period = 0
    
    while True:
        # Recurrence relations
        m = d * a - m
        d = (n - m * m) // d
        a = (a0 + m) // d
        
        period += 1
        
        # For square roots, the period completes at 2*a0
        if a == 2 * a0:
            break
    
    return period

count = 0

for n in range(2, 10001):
    if continued_fraction_period(n) % 2 == 1:
        count += 1

print(count)
```---

 ## コードのチュートリアル

 ### 機能の設定```python
a0 = int(math.isqrt(n))
```の整数部分を計算します$\sqrt n$。 

---

 ### 真四角チェック```python
if a0 * a0 == n:
    return 0
```完全正方形には終端展開があり、周期的な無理数展開はありません。 

---

 ### 初期状態```python
m = 0
d = 1
a = a0
```これらは繰り返しの標準的な初期値です。 

---

 ### 主な再発```python
m = d * a - m
d = (n - m * m) // d
a = (a0 + m) // d
```これにより、次の連分数項が生成されます。 

---

 ### 期間のカウント```python
period += 1
```反復ごとに、繰り返しブロックに 1 つの項が追加されます。 

---

 ### 完了の検出```python
if a == 2 * a0:
    break
```平方根の場合、これは 1 つの完全な期間の終了を示します。
