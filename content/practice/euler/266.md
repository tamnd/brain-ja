[プロジェクト オイラー問題 266](https://projecteuler.net/problem=266)

 ## 解決策

 **答え:**`1096883702440585`させて$$p=\prod_{\substack{q\text{ prime}\\ q<190}} q.$$の最大約数を求めます$p$を超えない$\sqrt p$。 以来$p$平方フリーです。すべての約数は、以下の素数の部分集合を選択することに対応します。$190$。 

したがって、問題は次のようになります。 

> 以下の素数のサブセットを選択してください$190$残りの製品ができるだけ大きいもの$\le \sqrt p$。 

同様に、対数をとると次のようになります。$$\log d=\sum_{q\in S}\log q$$できるだけ近くでなければなりません$$\frac12 \log p.$$これは古典的な **バランスの取れたサブセット積/ナップザック** 問題であり、正しいアプローチは **中間者探索**です。 

---

 #1. 数学的分析

 以下の素数$190$は$$2,3,5,7,\dots,181.$$がある$42$このような素数なので、すべてのサブセットに対するブルートフォースのチェックが必要になります。$$2^{42}\approx 4.4\times 10^{12}$$サブセット — 直接的には不可能です。 

---

 ## 再定式化

 しましょう$$p=\prod_{i=1}^{42} p_i.$$のすべての約数$p$形を持っています$$d=\prod_{i\in S} p_i$$一部のサブセットに対して$S$。 

私たちが欲しいのは$$d\le \sqrt p$$そして$d$最大の。 

ログの取得:$$\log d=\sum_{i\in S}\log p_i.$$以来$$\log \sqrt p=\frac12\sum_{i=1}^{42}\log p_i,$$対数のサブセットの合計を、合計の半分を超えずにできるだけ近い値にしたいとします。 

---

 #2. 中間者会議

 素数を 2 つに分割します。 

- 左半分$L$- 右半分$R$それぞれの半分には約$21$素数。 

のサブセットごとに、$L$、次を計算します。 

- その対数和
 - まさにその製品

 同様に$R$。 

それぞれの側には、$$2^{21}=2,097,152$$サブセットなので管理可能です。 

---

 ## 重要なアイデア

 左のサブセットに対数和があると仮定します。$x$。 

次に、適切なサブセットは次の条件を満たす必要があります。$$y \le T-x$$どこ$$T=\frac12\log p.$$したがって、左側のサブセットごとに、右側のサブセットをバイナリ検索して、実現可能な最大のものを探します。$y$。 

対応する正確な積が乗算され、最大の有効な積が保持されます。

 #3. Pythonの実装```python
from math import log
from bisect import bisect_right

# Generate primes below 190
def primes_below(n):
    sieve = [True] * n
    sieve[0] = sieve[1] = False

    for i in range(2, int(n**0.5) + 1):
        if sieve[i]:
            for j in range(i * i, n, i):
                sieve[j] = False

    return [i for i, v in enumerate(sieve) if v]

primes = primes_below(190)

# Total logarithmic target
total_log = sum(log(p) for p in primes)
target = total_log / 2

# Split primes into two halves
mid = len(primes) // 2
A = primes[:mid]
B = primes[mid:]

# Enumerate all subset products and log sums
def subset_data(arr):
    n = len(arr)
    out = []

    for mask in range(1 << n):
        prod = 1
        s = 0.0

        for i in range(n):
            if mask & (1 << i):
                prod *= arr[i]
                s += log(arr[i])

        out.append((s, prod))

    return out

left = subset_data(A)
right = subset_data(B)

# Sort right subsets by logarithmic sum
right.sort()

right_logs = [x[0] for x in right]

best = 0

# For each left subset, binary search best compatible right subset
for ls, lp in left:

    remain = target - ls

    idx = bisect_right(right_logs, remain) - 1

    if idx >= 0:
        rp = right[idx][1]
        candidate = lp * rp

        if candidate > best:
            best = candidate

# Required modulo
answer = best % (10**16)

print(answer)
```---
