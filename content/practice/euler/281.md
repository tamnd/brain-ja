[プロジェクト オイラー問題 281](https://projecteuler.net/problem=281)

 ## 解決策

 **答え:**`1485776387445623`させて$N = mn$。 

の円形配置を数えなければなりません$N$ピザのスライスを使って$m$トッピング、それぞれが正確に表示されます$n$回。 

回転が識別され、反射が明確になります。 

以下を定義します。 

f(m,n)=\text{それぞれ } m \text{ のトッピングを使用した } mn \text{ スライスの円形配置を } n \text{ 回}使用しました。 

私たちは求めています$$\sum_{f(m,n)\le 10^{15}} f(m,n).$$---

 #1. 数学的分析

 これは、循環回転に対する **バーンサイドの補題** の古典的な応用です。 

循環グループにしましょう$C_{mn}$ローテーションで取り決めに基づいて行動します。 

---

 ## ステップ 1: バーンサイドの補題

 バーンサイドは次のように与えます:$$f(m,n)=\frac1{mn}\sum_{r=0}^{mn-1} \mathrm{Fix}(r),$$どこ$\mathrm{Fix}(r)$回転によって変化しない配列の数です。$r$スライス。 

---

 ## ステップ 2: ローテーションの構造

 ローテーションの場合$r$、 させて$$g=\gcd(r,mn).$$次に、回転によって分解されます。$mn$位置:

 -$g$サイクル、
 - それぞれの長さ$$L=\frac{mn}{g}.$$アレンジメントを固定するには、サイクル内のすべてのポジションで同じトッピングを使用する必要があります。 

したがって、それぞれのトッピングが重要になります$n$周期の長さで割り切れる必要があります$L$:$$L \mid n.$$したがって、約数だけ$L$の$n$貢献する。 

---

 ## ステップ 3: 固定配置のカウント

 仮定してください$L\mid n$、定義します$$d=\frac{n}{L}.$$次に、各トッピングが正確に収まります$d$サイクル。 

あるので$$g=\frac{mn}{L}=md$$合計サイクル数、トッピングにサイクルを割り当てる方法の数は次のとおりです。$$\frac{(md)!}{(d!)^m}.$$---

 ## ステップ 4: サイクル長は何回転か$L$?

 回転には周期長があります$L$まさにいつ$$\frac{mn}{\gcd(r,mn)}=L.$$このような回転の数はオイラーの合計です。$$\varphi(L).$$したがってバーンサイドは$$f(m,n) = \frac1{mn} \sum_{L\mid n} \varphi(L)\, \frac{(mn/L)!}{((n/L)!)^m}.$$置き換える$d=n/L$:$f(m,n)=\frac{1}{mn}\sum_{d\mid n}\varphi\!\left(\frac{n}{d}\right)\frac{(md)!}{(d!)^m}$これが私たちが計算する式です。 

---

 # 2. 検索の境界を設定する

 値は非常に急速に増加します。 

のために$n=1$、$$f(m,1)=(m-1)!.$$以来$$18! / 18 = 17! = 355687428096000 \le 10^{15},$$しかし$$19! / 19 = 18! > 10^{15},$$私たちに必要なのはただ$m\le 18$。 

同様に、固定ごとに$m$、$f(m,n)$で急速に成長します$n$、したがって、小さな有限のペアのセットだけが生き残ります。 

実際には、有効なペアは 74 個だけです$(m,n)$。 

---

 #3. Pythonの実装```python
from math import factorial
from sympy import divisors, totient

LIMIT = 10**15

def f(m, n):
    """
    Compute:
        f(m,n) = number of circular arrangements
    using Burnside's lemma.
    """
    total = 0

    for d in divisors(n):
        total += (
            totient(n // d)
            * factorial(m * d)
            // (factorial(d) ** m)
        )

    return total // (m * n)

answer = 0

m = 2

while True:

    # Minimal value for this m occurs at n = 1
    if f(m, 1) > LIMIT:
        break

    n = 1

    while True:
        value = f(m, n)

        if value > LIMIT:
            break

        answer += value
        n += 1

    m += 1

print(answer)
```---
