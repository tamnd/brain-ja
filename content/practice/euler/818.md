[プロジェクト オイラー問題 818](https://projecteuler.net/problem=818)

 ## 解決策

 **答え:**`11871909492066000`デッキをアフィン空間としてモデル化する$\mathbb F_3^4$、各カードは 4 タプル以上です$\{0,1,2\}$。 

SET は、まさに次の条件を満たす 3 点のアフィン ラインです。$$a+b+c=0 \pmod 3.$$がある$1080$SET（アフィンライン）。 拡大中$$S(C_n)^4$$ターン$F(n)$順序付けられた 4 タプルの SET のカウントに変換されます。 SET の 4 タプルに共用体サイズがある場合$k$、その場合、正確に含まれます$$\binom{81-k}{n-k}$$違う$n$-カードコレクション。 

したがって$$F(n)=\sum_{k=3}^{12} A_k \binom{81-k}{n-k},$$どこ$A_k$共用体に正確に含まれる SET の順序付けされた 4 タプルの数です。$k$カード。 

順序付き線ペアの対称クラスを使用する$AG(4,3)$(同じライン、交差、平行に素、斜めに素)、$A_k$値はビットセット列挙によって効率的に計算できます。 計算により、指定されたチェックが再現されます。$$F(3)=1080,\qquad F(6)=159690960.$$評価中$n=12$与える:

 **答え: 11871909492066000**
