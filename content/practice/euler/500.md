[プロジェクト オイラー問題 500](https://projecteuler.net/problem=500)

 ## 解決策

 **答え:**`35407281`させて$d(n)$は正の約数の数を示します$n$。 

この問題では**最小**の整数が求められます$N$そのような$$d(N)=2^{500500}.$$計算しなければなりません$N \bmod 500500507$。 

---

 #1. 数学的分析

 もし$$N=\prod_{i=1}^k p_i^{a_i},$$除数カウントの式は次のようになります。$$d(N)=\prod_{i=1}^k (a_i+1).$$これを純粋な 2 のべき乗と等しくしたいとします。$$\prod (a_i+1)=2^{500500}.$$したがって、あらゆる要因$a_i+1$それ自体は 2 の累乗でなければなりません。$$a_i = 2^{b_i}-1.$$したがって、指数は次の形式でなければなりません$$1,3,7,15,31,\dots$$そして$$\sum b_i = 500500.$$したがって$$N=\prod p_i^{\,2^{b_i}-1}.$$質問は次のようになります。 

> 「予算」をどう配分するか$500500$最小化する素数の間$N$?

 ---

 ## 重要な貪欲な洞察

 現在指数ブロックを使用しているとします。$b$プライムで$p$。 

増加中$b$による$1$から指数を変更します$$2^b-1 \quad\to\quad 2^{b+1}-1.$$したがって、指数は正確に増加します$2^b$。 

それは倍増します$N$による$$p^{2^b}.$$したがって、除数と指数の予算が追加されるたびに、乗算係数がかかります。$$p^{2^b}.$$最小限に抑えるには$N$、すべてのステップで、**利用可能な最小の乗数**を選択する必要があります。 

---

 # 再定式化

 最初は、すべての素数が次の 1 つの因数に寄与する可能性があります。$2$指数を使用して除数のカウントを計算します$1$。 

それには次のコストがかかります$p$。 

後で指数をアップグレードする場合$$1 \to 3,$$を掛けます$p^2$。 

それから$$3 \to 7$$コストの乗算$p^4$、など。 

したがって、候補コストは次のようになります。$$2,3,5,7,11,\dots$$(初登場)

 それから$$2^2,3^2,5^2,\dots$$それから$$2^4,3^4,\dots$$等々。 

正確に選択する必要があります$500500$そのようなコストは常に次の利用可能な最小のオプションを採用します。 

これは、古典的な優先キュー/ヒープ プロセスです。 

---

 # 貪欲な戦略が正しい理由

 2 つの選択肢があるとします。 

- を掛ける$a$、
 - を掛ける$b$、

と$a<b$。 

将来の乗数はすべて独立して正であるため、$a$最初に選択した場合よりも常に小さな総積が得られます。$b$初め。 

したがって、利用可能な最小の乗数を繰り返し取得することが全体的に最適です。 

---

 #2. 効率的なアルゴリズム

 各素数に対して次に利用可能な乗数を含む最小ヒープを維持します。 

プライムの場合$p$:

 - 最初の乗数は$p$、
 - 服用後$p^{2^k}$、次の乗数は次のようになります。$$p^{2^{k+1}}=(p^{2^k})^2.$$したがって、値をポップするたびに、$x$、私たちは押し返します$$x^2.$$ただし、必要なのはヒープの順序付けのための値だけであり、正確な巨大な整数ではありません。 

それでも、ヒープ サイズは約$500500$。 

答えのモジュロも維持します$500500507$。 

---

 #3. Pythonの実装```python
import heapq

MOD = 500500507
TARGET = 500500

# ------------------------------------------------------------
# Generate enough primes using a sieve
# ------------------------------------------------------------

# We need roughly the first 500500 primes.
# The 500500th prime is below 8,000,000.
LIMIT = 8000000

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, int(LIMIT ** 0.5) + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start: LIMIT + 1: step] = b"\x00" * (
            (LIMIT - start) // step + 1
        )

primes = [i for i, is_prime in enumerate(sieve) if is_prime]

# ------------------------------------------------------------
# Greedy heap process
# ------------------------------------------------------------

heap = []

# Initially each prime contributes multiplier p
for p in primes[:TARGET]:
    heapq.heappush(heap, (p, p))

answer = 1

for _ in range(TARGET):
    value, prime = heapq.heappop(heap)

    # Multiply into answer modulo MOD
    answer = (answer * (value % MOD)) % MOD

    # Next upgrade cost for this prime:
    # p^(2^k) -> p^(2^(k+1)) by squaring
    next_value = value * value

    heapq.heappush(heap, (next_value, prime))

print(answer)
```---
