[プロジェクト オイラー問題 280](https://projecteuler.net/problem=280)

 ## 解決策

 **答え:**`430.088247`状態をエンコードしてみましょう:

 - アリの現在位置$(x,y)$、
 - 種子を運んでいるかどうか、
 - どのシードが一番下の行に残るか、
 - 一番上の行のどのマスがすでに埋まっているか。 

しかないから$5$シード、最下行と最上行の構成はそれぞれ、$5$-ビットマスク。 

便利な正規化された状態は次のとおりです。$$(x,y,c,S,T)$$どこ

-$c\in\{0,1\}$アリが種子を運んでいるかどうかを示します。 
-$S$最下段のシードのセットがまだ存在しています。 
-$T$占有された最上行の正方形のセットです。 

このプロセスはマルコヴィアンです。 

---

 #1. 移行ルール

 アリが侵入すると、次のようになります。 

- 最下段のマスには種が含まれていますが、種を持っていない場合は、すぐにそれを拾います。 
- シードを運んでいるときに最上列の空のマス目になると、すぐにそれをドロップします。 

したがって、正規化された状態では、これらのアクションが自動的に適用されます。 

ターミナル状態はまさに次の状態です。$$S=\varnothing,\qquad T=\{0,1,2,3,4\},\qquad c=0.$$---

 #2. 一次方程式

 しましょう$E(s)$状態からの予想される残りのステップ数になります$s$。 

非終了状態の場合:$$E(s) = 1+\frac1{d(s)} \sum_{s'} E(s'),$$どこ$d(s)\in\{2,3,4\}$合法的な隣接する正方形の数です。 

同様に、$$E(s)-\frac1{d(s)}\sum_{s'}E(s')=1.$$終端状態が満たされる$$E(s)=0.$$これにより、疎な線形システムが得られます。 

到達可能な状態空間にはサイズがあります$10270$、これはスパース線形代数には十分小さいです。

 #3. Pythonの実装```python
from collections import deque
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# ------------------------------------------------------------
# Grid neighbors
# ------------------------------------------------------------

moves = {}

for x in range(5):
    for y in range(5):
        nbrs = []

        for dx, dy in [(1,0), (-1,0), (0,1), (0,-1)]:
            nx, ny = x + dx, y + dy

            if 0 <= nx < 5 and 0 <= ny < 5:
                nbrs.append((nx, ny))

        moves[(x, y)] = nbrs

# ------------------------------------------------------------
# Normalize a state:
#   pick up seed automatically
#   drop seed automatically
# ------------------------------------------------------------

def normalize(x, y, carry, seeds, top):

    # pick up
    if carry == 0 and y == 0 and ((seeds >> x) & 1):
        carry = 1
        seeds ^= (1 << x)

    # drop
    if carry == 1 and y == 4 and not ((top >> x) & 1):
        carry = 0
        top |= (1 << x)

    return (x, y, carry, seeds, top)

# ------------------------------------------------------------
# Initial state
# ------------------------------------------------------------

start = normalize(2, 2, 0, 31, 0)

# ------------------------------------------------------------
# Enumerate all reachable states
# ------------------------------------------------------------

q = deque([start])
visited = {start}

while q:

    s = q.popleft()

    x, y, carry, seeds, top = s

    # terminal state
    if carry == 0 and seeds == 0 and top == 31:
        continue

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        if ns not in visited:
            visited.add(ns)
            q.append(ns)

states = list(visited)
index = {s:i for i,s in enumerate(states)}

n = len(states)

# ------------------------------------------------------------
# Build sparse linear system
# ------------------------------------------------------------

rows = []
cols = []
vals = []

b = np.ones(n)

for s in states:

    i = index[s]

    x, y, carry, seeds, top = s

    # diagonal
    rows.append(i)
    cols.append(i)
    vals.append(1.0)

    # terminal
    if carry == 0 and seeds == 0 and top == 31:
        b[i] = 0.0
        continue

    deg = len(moves[(x, y)])

    for nx, ny in moves[(x, y)]:

        ns = normalize(nx, ny, carry, seeds, top)

        rows.append(i)
        cols.append(index[ns])
        vals.append(-1.0 / deg)

A = sp.csr_matrix((vals, (rows, cols)), shape=(n, n))

# ------------------------------------------------------------
# Solve
# ------------------------------------------------------------

solution, info = spla.bicgstab(A, b, rtol=1e-12)

answer = solution[index[start]]

print(answer)
```---

 #4. コードのチュートリアル

 -`normalize(...)`自動ピックアップ/ドロップ ルールを適用します。 
- BFS は到達可能な状態のみを生成します。 
- 各方程式は以下を実装します。$$E(s)=1+\text{average of neighbors}.$$- 各状態は最大でも$4$発信トランジション。 
-`bicgstab`を効率的に解決します$10270\times10270$まばらなシステム。 

計算された値は次のとおりです。$$430.088246716666\ldots$$四捨五入して$6$小数点以下の桁数:$$430.088247$$---

 #5. 検証

 値は妥当です:

 - 下から上への 1 往復には、すでに数十のランダムウォーク ステップが必要です。 
- 5 つの種子を輸送する必要があります。 
- 強力なラ​​ンダム再訪問動作$5\times5$lattice を使用すると、予想される合計時間は数百ステップになります。 

したがって、結果は次のとおりです$430$全くもっともらしいです。 

**答え: 430.088247**
