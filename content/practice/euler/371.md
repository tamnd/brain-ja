[プロジェクト オイラー問題 371](https://projecteuler.net/problem=371)

 ## 解決策

 **答え:**`40.66368097`ナンバープレートの 3 桁の部分を確率変数とする$X\in\{000,\dots,999\}$。 

セスは、数字の合計が次の 2 つのプレートを見るとすぐに勝ちます。$1000$。 

重要な点は次のとおりです。 

-$000$決して勝利に参加することはできません（勝利には参加する必要があります）$1000$、それは不可能です）。 
-$500$は特別です: それ自体とペアになるため、Seth は **2** の出現を確認する必要があります。$500$。 

したがって、これは標準的なクーポン コレクターの問題ではありません**。 

---

 # 数学的分析

 以下のものがあります:

 -$499$相補的なペア$$(1,999),(2,998),\dots,(499,501)$$- 1 つのセルフペア:$$(500,500)$$状態を使用してプロセスを追跡します。 

---

 ## 状態の説明

 しましょう

 -$k$= セスが**ちょうど 1** メンバーを確認した相補ペアの数。 
-$h\in\{0,1\}$:

 -$h=0$: セスはまだ見ていません$500$、
 -$h=1$: セスはまさに 1 つを見ました$500$。 

定義する$$E(k,h)$$この状態から勝つために必要な追加のプレートの予想数として。 

最初に:$$E(0,0)$$は私たちが望む量です。 

---

 # 遷移確率

 州から$(k,h)$:

 ## 1. 即時勝利

 次の場合に勝利となります。 

- セスは、次のいずれかの補数を参照します。$k$アクティブなペア、
 - または (場合$h=1$）彼は別のものを見ます$500$。 

したがって$$p_{\text{win}}=\frac{k+h}{1000}.$$---

 ## 2. 新しいアクティブなペアを作成します

 あります$499-k$それぞれが 2 つの目に見えない数値に寄与する、手付かずの相補ペア。 

したがって、次のようになります。$$p_{\text{new}}=\frac{2(499-k)}{1000}.$$これは次のように移動します。$$(k+1,h).$$---

 ＃＃３．初登場$500$もし$h=0$、見る$500$状態をに変更します$(k,1)$:$$p_{500}=\frac{1}{1000}.$$もし$h=1$、 別の$500$すでに勝利としてカウントされます。 

---

 ## 4. その他すべて

 残りのすべての結果は状態を変更しません。 

---

 # 期待値の計算式

 次のプレートの状態:$$E(k,h) = 1 + p_{\text{stay}}E(k,h) + p_{\text{new}}E(k+1,h) + p_{500}E(k,1).$$再配置:$$E(k,h) = \frac{ 1 + p_{\text{new}}E(k+1,h) + p_{500}E(k,1) }{ 1-p_{\text{stay}} }.$$しかし$$1-p_{\text{stay}} = p_{\text{win}}+p_{\text{new}}+p_{500}.$$これにより、単純な後方再帰が行われます。 

---

 # Pythonの実装```python
from functools import cache

@cache
def E(k, h):
    """
    Expected remaining plates needed to win.

    k = number of complementary pairs where exactly one member
        has been seen.
    h = 0 or 1 depending on whether one '500' has been seen.
    """

    # Probability of immediate win
    p_win = (k + h) / 1000.0

    # Probability of creating a new active pair
    p_new = 2 * (499 - k) / 1000.0

    # Probability of seeing the first 500
    p_500 = 0.0 if h else 1 / 1000.0

    # Probability of staying in same state
    p_stay = 1.0 - p_win - p_new - p_500

    # Recursive expectation equation
    value = 1.0

    if k < 499:
        value += p_new * E(k + 1, h)

    if h == 0:
        value += p_500 * E(k, 1)

    return value / (1.0 - p_stay)

answer = E(0, 0)

print("{:.8f}".format(answer))
```---
