[Project Euler Problem 226](https://projecteuler.net/problem=226)

 ## 解決策

 **答え:**`0.11316017`させて$$B(x)=\sum_{n=0}^{\infty}\frac{s(2^n x)}{2^n}, \qquad s(x)=\text{distance from }x\text{ to the nearest integer}.$$これは **ブラマンジェ関数** (または高木関数) です。 

同時に囲まれた領域を求めます。 

- ブラマンジェ曲線の下$y=B(x)$、
 -そしてサークルの中$$\left(x-\frac14\right)^2+\left(y-\frac12\right)^2=\left(\frac14\right)^2.$$必要な領域は、下の半円とブランマンジェ曲線で囲まれた小さな「スクープ」です。 

---

 #1. 数学的分析

 ## ステップ 1 — 円の方程式

 円の下半分は、$$y_c(x)=\frac12-\sqrt{\frac1{16}-\left(x-\frac14\right)^2}.$$交点が必要です$x_0$満足のいく$$B(x_0)=y_c(x_0).$$ブランマンジェ曲線の対称性により、$$B(x)=B(1-x),$$関連する囲まれた領域はから始まります$x_0$に$1/2$。 

したがって、希望する領域は、$$A=\int_{x_0}^{1/2}\left(B(x)-y_c(x)\right)\,dx.$$---

 ## ステップ 2 — の効率的な評価$B(x)$各項は次のように除算されるため、定義は非常に急速に収束します。$2^n$。 

数値計算の場合:$$B(x)\approx \sum_{n=0}^{N-1}\frac{s(2^n x)}{2^n},$$と$N=50$すでに非常に高い精度を実現しています。 

本当のことについては$t$、$$s(t)=|t-\operatorname{round}(t)|.$$---

 ## ステップ 3 — 交差点を見つける

 定義する$$f(x)=B(x)-y_c(x).$$区間での二等分を使用する$(0,0.5)$を取得します。$$x_0 \approx 0.07890778796534.$$---

 ## ステップ 4 — 数値積分

 私たちは計算します$$A=\int_{x_0}^{1/2}(B(x)-y_c(x))\,dx$$細かい細分化を伴うシンプソンの法則を使用します。 

数値は次のように収束します$$A \approx 0.11316016345\ldots$$小数点以下 8 桁に四捨五入すると、$$0.11316017.$$---

 #2. Pythonの実装```python
from math import sqrt

# Distance to nearest integer
def s(x):
    return abs(x - round(x))

# Blancmange function
def B(x, terms=60):
    total = 0.0
    scale = 1.0

    for n in range(terms):
        total += s(scale * x) / scale
        scale *= 2.0

    return total

# Lower semicircle
def circle_lower(x):
    return 0.5 - sqrt(0.0625 - (x - 0.25) ** 2)

# Difference between curves
def f(x):
    return B(x) - circle_lower(x)

# Bisection to find intersection point
a, b = 0.0, 0.5

for _ in range(100):
    m = (a + b) / 2

    if f(m) > 0:
        b = m
    else:
        a = m

x0 = (a + b) / 2

# Simpson integration
def simpson(g, a, b, n=20000):
    if n % 2 == 1:
        n += 1

    h = (b - a) / n
    total = g(a) + g(b)

    for i in range(1, n):
        coeff = 4 if i % 2 == 1 else 2
        total += coeff * g(a + i * h)

    return total * h / 3

area = simpson(
    lambda x: B(x) - circle_lower(x),
    x0,
    0.5,
    20000
)

print(f"{area:.8f}")
```---
