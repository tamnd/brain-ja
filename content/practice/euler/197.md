[プロジェクト オイラー問題 197](https://projecteuler.net/problem=197)

 ## 解決策

 **答え:**`1.710637717`させて$$f(x)=\left\lfloor 2^{30.403243784-x^2}\right\rfloor \cdot 10^{-9}, \qquad u_{n+1}=f(u_n),\qquad u_0=-1.$$計算しなければなりません$$u_{10^{12}}+u_{10^{12}+1}$$小数点以下9桁まで。 

重要な観察は、数列が単一の固定点に収束しない**ということです。 代わりに、非常に急速に **2 サイクル**に収束します。$$u_{2k}\to a,\qquad u_{2k+1}\to b,$$と$$a=f(b),\qquad b=f(a).$$したがって、膨大な量の$n$、$$u_n+u_{n+1}\approx a+b.$$したがって、交互項が安定するまで繰り返すだけで済みます。 

---

 # 数学的分析

 定義する$$u_{n+1}=f(u_n).$$固定点は満足するでしょう$$u=f(u),$$しかし、数値的には、反復は 2 つの近い値の間で変動します。 

したがって、代わりに 2 サイクルを求めます。$$a=f(b),\qquad b=f(a).$$同様に、$$f(f(a))=a.$$フロア操作によりリミット サイクル付近でマップが強く収縮するため、収束が非常に速くなります。 

問題ステートメントで提案されている停止基準は次のとおりです。$$|u_{n+2}-u_n|<10^{-12}.$$これが起こると、シーケンスは効果的に交互ペアに落ち着きます。 

---

 # Pythonの実装```python
from decimal import Decimal, getcontext, ROUND_FLOOR

# Use high precision
getcontext().prec = 50

TEN_NEG_9 = Decimal('1e-9')
C = Decimal('30.403243784')
TWO = Decimal(2)

def f(x):
    """
    Compute:
        floor(2^(30.403243784 - x^2)) * 1e-9
    using Decimal arithmetic.
    """
    exponent = C - x * x

    # Decimal power
    value = TWO ** exponent

    # floor(value)
    floored = value.to_integral_value(rounding=ROUND_FLOOR)

    return floored * TEN_NEG_9

# Initial value
u0 = Decimal(-1)

u_prev2 = u0
u_prev1 = f(u_prev2)

while True:
    u = f(u_prev1)

    # Check convergence to a 2-cycle
    if abs(u - u_prev2) < Decimal('1e-12'):
        break

    u_prev2, u_prev1 = u_prev1, u

# The 2-cycle values
a = u_prev2
b = u_prev1

answer = a + b

# Print with exactly 9 digits after decimal
print(format(answer, '.9f'))
```---
