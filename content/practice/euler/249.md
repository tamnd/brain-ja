 ## 解決策

 **答え:**`9275262564250418`させて$$S=\{2,3,5,\dots,4999\}$$以下のすべての素数の集合であること$5000$。 の部分集合を数えなければなりません$S$その要素合計はそれ自体が素数であり、最後の要素合計を返します。$16$数字。 

---

 # 数学的分析

 指定された合計プロパティを持つサブセットをカウントしているため、これは基本的に **サブセット合計カウント** の問題です。 

---

 ## 1. 問題を再定式化する

 すべてのサブセットについて$A\subseteq S$、 定義する$$\sigma(A)=\sum_{p\in A} p.$$次のようなサブセットの数が必要です。$\sigma(A)$プライムです。 

定義すると$$f(n)=\#\{A\subseteq S:\sigma(A)=n\},$$その場合、希望の量は$$\sum_{\substack{n\text{ prime}}} f(n).$$したがって、実際のタスクは次のとおりです。 

> 可能なすべての合計を達成するサブセットの数を計算します。 

---

 ## 2. 生成関数の観点

 それぞれの素数$p\in S$次のいずれかを行うことができます:

 - サブセットから除外される、
 - または、正確に 1 回含まれます。 

したがって、各素数は因数に寄与します$$(1+x^p).$$したがって、生成関数は次のようになります。$$F(x)=\prod_{p<5000}(1+x^p).$$この製品を拡張すると、次のようになります。$$F(x)=\sum_{n\ge0} f(n)x^n,$$どこ$f(n)$は、正確に合計したサブセットの数です$n$。 

したがって、係数抽出の問題は次のようになります。$$\text{Answer}=\sum_{\substack{n\text{ prime}}}[x^n]F(x).$$---

 ## 3. 動的計画法の導出

 多項式を記号的に展開しません。 代わりに、係数を繰り返し計算します。 

させて$$dp[s]$$合計が次の値に等しい、処理された素数のサブセットの数を示します。$s$。 

最初に:$$dp[0]=1$$空のサブセットには合計があるため$0$。 

新しい素数を処理します$p$。 

すべての古いサブセット合計$s$新しいサブセット合計を作成します$s+p$。 

したがって、次のようになります。$$dp[s+p] \mathrel{+}= dp[s].$$同じ素数を複数回再利用することを避けるために、合計を **下方向**に繰り返します。```python
for s from MAX-p down to 0:
    dp[s+p] += dp[s]
```これは標準の 0/1 サブセット DP です。 

---

 ## 4. サイズ境界

 あります$669$以下の素数$5000$。 

可能な最大のサブセット合計は次のとおりです。$$\sum_{p<5000} p = 1,548,136.$$したがって、DP 配列に必要なサイズは約$1.55\times10^6$、これは完全に実現可能です。 

サブセットの数は天文学的です ($2^{669}$)、ただし最後のものだけが必要です$16$桁数なので、計算全体を通じて剰余を削減します。$$10^{16}.$$---

 # Pythonの実装```python
import math
import numpy as np

MOD = 10**16

# ------------------------------------------------------------
# Step 1: Generate all primes below 5000
# ------------------------------------------------------------

n = 5000

is_prime = np.ones(n, dtype=bool)
is_prime[:2] = False

for i in range(2, math.isqrt(n - 1) + 1):
    if is_prime[i]:
        is_prime[i * i:n:i] = False

primes = np.nonzero(is_prime)[0]

# ------------------------------------------------------------
# Step 2: Subset-sum DP
# dp[s] = number of subsets with sum s
# ------------------------------------------------------------

max_sum = int(primes.sum())

dp = np.zeros(max_sum + 1, dtype=np.int64)
dp[0] = 1

MOD64 = np.int64(MOD)

for p in primes:
    p = int(p)

    # Vectorized backward-style update:
    # dp[p:] += dp[:-p]
    dp[p:] = (dp[p:] + dp[:-p]) % MOD64

# ------------------------------------------------------------
# Step 3: Sieve primes up to max_sum
# ------------------------------------------------------------

prime_sum = np.ones(max_sum + 1, dtype=bool)
prime_sum[:2] = False

for i in range(2, math.isqrt(max_sum) + 1):
    if prime_sum[i]:
        prime_sum[i * i:max_sum + 1:i] = False

# ------------------------------------------------------------
# Step 4: Add counts for prime sums
# ------------------------------------------------------------

answer = int(dp[prime_sum].sum() % MOD)

print(answer)
```---

```このベクトル化された操作は以下を実装します。$$dp[s+p] \leftarrow dp[s+p] + dp[s]$$あらゆる人にとって$s$。 

概念的には:

 - 既存のサブセットは残ります。 
- 既存のサブセットはすべて、以下を含めることで拡張できます。$p$。
