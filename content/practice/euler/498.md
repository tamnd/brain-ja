[プロジェクト オイラー問題 498](https://projecteuler.net/problem=498)

 ## 解決策

 **答え:**`472294837`させて$$F_n(x)=x^n,\qquad G_m(x)=(x-1)^m.$$私たちは定義します$R_{n,m}(x)$ときの余りになります$x^n$で割られる$(x-1)^m$。 約数には度数があるので$m$、残りは最大でも次数を持ちます$m-1$。 

の係数の絶対値を求めます。$x^d$で$R_{n,m}(x)$:$$C(n,m,d).$$計算するように求められます$$C(10^{13},10^{12},10^4)\pmod{999999937}.$$---

 #1. 数学的分析

 要点を中心に取り組んでいきます$x=1$。 

定義する$$y=x-1 \quad\Longrightarrow\quad x=1+y.$$それから$$x^n=(1+y)^n.$$モジュロ$y^m$、最初だけ$m$二項展開の項は存続します。$$R_{n,m}(x) = \sum_{k=0}^{m-1}\binom{n}{k}(x-1)^k.$$したがって、次の係数は$x^d$は$$a_d = \sum_{k=d}^{m-1}\binom{n}{k}[x^d](x-1)^k.$$次に展開します。$$(x-1)^k = \sum_{j=0}^k \binom{k}{j}x^j(-1)^{k-j}.$$したがって、$$[x^d](x-1)^k = (-1)^{k-d}\binom{k}{d}.$$したがって$$a_d = \sum_{k=d}^{m-1} (-1)^{k-d}\binom{n}{k}\binom{k}{d}.$$---

 ## 合計を単純化する

 アイデンティティを利用する$$\binom{n}{k}\binom{k}{d} = \binom{n}{d}\binom{n-d}{k-d}.$$させて$j=k-d$。 それから$$a_d = \binom{n}{d} \sum_{j=0}^{m-1-d} (-1)^j \binom{n-d}{j}.$$次に、交互二項恒等式を適用します。$$\sum_{j=0}^{r}(-1)^j\binom{N}{j} = (-1)^r\binom{N-1}{r}.$$と$$N=n-d,\qquad r=m-1-d,$$私たちは得ます$$a_d = (-1)^{m-1-d} \binom{n}{d} \binom{n-d-1}{m-d-1}.$$以来$C(n,m,d)$は絶対値です、$$\boxed{ C(n,m,d) = \binom{n}{d} \binom{n-d-1}{m-d-1}. }$$---

 ## 例と照らし合わせて確認してください

 ### 例 1$$C(6,3,1) = \binom61\binom41 = 6\cdot4 = 24.$$正しい。 

---

 ### 例 2$$C(100,10,4) = \binom{100}{4}\binom{95}{5}.$$これは等しい$$227197811615775,$$問題文と一致します。 

---

 #2. モジュラー計算

 必要です$$\binom{10^{13}}{10^4} \binom{10^{13}-10^4-1}{10^{12}-10^4-1} \pmod p,$$どこ$$p=999999937.$$以来$p$が素数である場合、ルーカスの定理を使用します。 

---

 ## ルーカス分解

 基数に数字を書きます$p$。 

### 最初の要素$$10^{13}=10000\cdot p + 630000,$$それで$$\binom{10^{13}}{10^4} \equiv \binom{10000}{0} \binom{630000}{10000} \pmod p.$$したがって$$\binom{10^{13}}{10^4} \equiv \binom{630000}{10000}.$$---

 ### 2番目の要素$$10^{13}-10^4-1 = 10000\cdot p + 619999,$$そして$$10^{12}-10^4-1 = 1000\cdot p + 52999.$$したがって、$$\binom{10^{13}-10^4-1}{10^{12}-10^4-1} \equiv \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$したがって$$C \equiv \binom{630000}{10000} \binom{10000}{1000} \binom{619999}{52999} \pmod p.$$以下はすべて通常の組み合わせです$p$、階乗とフェルマー逆関数で計算可能。 

---

 #3. Pythonの実装```python
MOD = 999999937

def mod_comb(n, r, mod):
    """Compute C(n,r) mod prime mod."""
    if r < 0 or r > n:
        return 0

    r = min(r, n - r)

    numerator = 1
    denominator = 1

    for i in range(1, r + 1):
        numerator = (numerator * (n - r + i)) % mod
        denominator = (denominator * i) % mod

    return numerator * pow(denominator, mod - 2, mod) % mod

# Problem values
n = 10**13
m = 10**12
d = 10**4

# Lucas reductions already derived mathematically
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)

answer = (a * b % MOD) * c % MOD

print(answer)
```---

 #4. コードのチュートリアル

 ##`mod_comb`これは計算します$$\binom{n}{r}\pmod p$$使用して$$\binom{n}{r} = \frac{n(n-1)\cdots(n-r+1)}{r!}.$$なぜなら$p$が素数なので、剰余を割ります$p$フェルマーの定理を使用すると、次のようになります。$$a^{-1}\equiv a^{p-2}\pmod p.$$---

 ## 主な計算

 上記で導出された Lucas 削減を使用します。```python
a = mod_comb(630000, 10000, MOD)
b = mod_comb(10000, 1000, MOD)
c = mod_comb(619999, 52999, MOD)
```それから```python
answer = (a * b % MOD) * c % MOD
```希望の値を与えます。

 #5. 最終検証

 - 派生した閉じた形式は、両方の例を正確に再現します。 
- 係数が素数であるため、ルーカスの定理が適用されます。 
- すべての換算二項パラメータは厳密に係数を下回ります。 
- 最終剰余が有効範囲内にある$[0,p-1]$。 

したがって、計算は一貫しています。
