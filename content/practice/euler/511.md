[プロジェクト オイラー問題 511](https://projecteuler.net/problem=511)

 ## 解決策

 **答え:**`935247012`させて$$D(n)=\{d : d\mid n\}$$の正の約数の集合となる$n$。 

シーケンスを数えなければなりません$$(a_1,a_2,\dots,a_n),\qquad a_i\mid n$$そのような$$n+a_1+\cdots+a_n\equiv 0\pmod{k}.$$同様に、$$a_1+\cdots+a_n\equiv -n\pmod{k}.$$したがって、問題は次のようになります。 

> カウントの長さ -$n$～の約数の列$n$その合計が所定の剰余モジュロである$k$。 

---

 #1. 数学的分析

 リング内の多項式を定義する$$R=\mathbb Z[x]/(x^k-1)$$による$$P(x)=\sum_{d\mid n} x^{d}.$$除数の各選択はその剰余モジュロに寄与します$k$。 

多項式を剰余で乗算するとき$x^k-1$、指数はモジュロを加算します$k$。 したがって：$$P(x)^n$$すべての長さをエンコードします -$n$約数の列。 

より正確には:$$[x^r]P(x)^n$$約数の合計が一致するシーケンスの数に等しい$r\pmod{k}$。 

したがって、$$Seq(n,k)=[x^{-n\bmod k}]P(x)^n.$$したがって、問題全体は次のようになります。 

1.長さを構築します-$k$ベクター$v$どこ$$v[r]=\#\{d\mid n : d\equiv r\pmod{k}\}.$$1. を計算します。$n$-巡回畳み込みパワーの倍数$v$。 
2. 残留物を抽出する$(-n)\bmod k$。 

---

 ## なぜ巡回畳み込みを行うのでしょうか?

 ベクトルの場合$A,B$残差カウントを表すと、$$(A*B)[t] = \sum_{i+j\equiv t\pmod{k}} A[i]B[j].$$これはまさに乗算の剰余です$x^k-1$。 

したがって、二乗による累乗は自然に機能します。 

---

 #2. 因数分解$n$次の約数が必要です$$n=1234567898765.$$因数分解:$$1234567898765 = 5\cdot 41\cdot 25343\cdot 237631.$$すべての指数は$1$、あります。$$2^4=16$$約数の合計。 

---

 #3. 効率的な計算

 単純な巡回畳み込みのコスト$O(k^2)$、二乗を繰り返すには遅すぎます。 

代わりに以下を使用します。 

- 数論変換 (NTT)
 - NTT に優しい 3 つのプライム
 - 中国剰余定理 (CRT)

 これにより、高速で正確な畳み込みが得られます。 

ベクトルの長さは$$k=4321,$$したがって、畳み込みは非常に管理しやすくなります。

 #4. Pythonの実装```python
from math import prod
from sympy import divisors

MOD = 10**9

# ------------------------------------------------------------
# NTT utilities
# ------------------------------------------------------------

PRIMES = [998244353, 1004535809, 469762049]
ROOTS  = [3, 3, 3]

CRT_MOD = prod(PRIMES)

Mi = [CRT_MOD // p for p in PRIMES]
INV = [pow(Mi[i], -1, PRIMES[i]) for i in range(3)]

def ntt(a, mod, primitive_root, invert=False):
    """
    Iterative in-place Number Theoretic Transform.
    """
    n = len(a)

    # Bit-reversal permutation
    j = 0
    for i in range(1, n):
        bit = n >> 1
        while j & bit:
            j ^= bit
            bit >>= 1
        j ^= bit

        if i < j:
            a[i], a[j] = a[j], a[i]

    length = 2

    while length <= n:

        wlen = pow(primitive_root, (mod - 1) // length, mod)

        if invert:
            wlen = pow(wlen, mod - 2, mod)

        half = length // 2

        for start in range(0, n, length):

            w = 1

            for i in range(start, start + half):

                u = a[i]
                v = a[i + half] * w % mod

                a[i] = (u + v) % mod
                a[i + half] = (u - v) % mod

                w = w * wlen % mod

        length *= 2

    if invert:
        inv_n = pow(n, mod - 2, mod)

        for i in range(n):
            a[i] = a[i] * inv_n % mod

# ------------------------------------------------------------
# Main solver
# ------------------------------------------------------------

def solve(n, k):

    # Build residue vector of divisors
    base = [0] * k

    for d in divisors(n):
        base[d % k] += 1

    # FFT size
    N = 1
    while N < 2 * k:
        N *= 2

    def cyclic_convolution(a, b):
        """
        Cyclic convolution modulo x^k - 1.
        """
        residue_results = []

        for mod, root in zip(PRIMES, ROOTS):

            fa = (a + [0] * (N - len(a))).copy()
            fb = (b + [0] * (N - len(b))).copy()

            fa = [x % mod for x in fa]
            fb = [x % mod for x in fb]

            ntt(fa, mod, root)
            ntt(fb, mod, root)

            for i in range(N):
                fa[i] = fa[i] * fb[i] % mod

            ntt(fa, mod, root, invert=True)

            # Fold coefficients modulo x^k - 1
            c = [0] * k

            for i, val in enumerate(fa[:2 * k - 1]):
                c[i % k] = (c[i % k] + val) % mod

            residue_results.append(c)

        # CRT reconstruction
        result = [0] * k

        for i in range(k):

            x = 0

            for j in range(3):
                x += residue_results[j][i] * Mi[j] * INV[j]

            result[i] = x % CRT_MOD % MOD

        return result

    # Fast exponentiation
    result = [0] * k
    result[0] = 1

    exponent = n

    while exponent:

        if exponent & 1:
            result = cyclic_convolution(result, base)

        base = cyclic_convolution(base, base)

        exponent >>= 1

    target = (-n) % k

    return result[target]

# ------------------------------------------------------------
# Verification on examples
# ------------------------------------------------------------

print(solve(3, 4))          # 4
print(solve(4, 11))         # 8
print(solve(1111, 24))      # 840643584

# Final problem
print(solve(1234567898765, 4321))
```---
