[プロジェクト オイラー問題 381](https://projecteuler.net/problem=381)

 ## 解決策

 **答え:**`139602943319822`素数の場合$p \ge 5$、 定義する$$S(p)=\sum_{k=1}^{5}(p-k)! \pmod p.$$計算しなければなりません$$\sum_{5\le p<10^8} S(p),$$ここで、和は素数を超えます。 

---

 #1. 数学的分析

 重要なアイデアは、ウィルソンの定理を使用することです。$$(p-1)! \equiv -1 \pmod p$$すべての素数に対して$p$。 

「逆除算」を繰り返して、他の階乗を次のように表現します。$(p-1)!$。 

---

 ## ステップ 1: 各階乗モジュロを表現する$p$以来$$(p-1)!=(p-1)(p-2)!,$$そして$p-1\equiv -1 \pmod p$、$$- (p-2)! \equiv -1 \pmod p,$$それで$$(p-2)! \equiv 1 \pmod p.$$次、$$(p-2)!=(p-2)(p-3)! \equiv (-2)(p-3)!,$$したがって$$(p-3)! \equiv -\frac12 \pmod p.$$同様に、$$(p-4)! \equiv \frac16 \pmod p,$$そして$$(p-5)! \equiv -\frac1{24} \pmod p.$$したがって、$$S(p)\equiv -1+1-\frac12+\frac16-\frac1{24}.$$最初の 2 つの項はキャンセルされます。$$S(p)\equiv -\frac12+\frac16-\frac1{24}.$$分母の使用$24$、$$S(p)\equiv \frac{-12+4-1}{24} = -\frac9{24} = -\frac38 \pmod p.$$したがって、問題全体は次のようになります。$$\boxed{S(p)\equiv -3\cdot 8^{-1}\pmod p}.$$これが重要な単純化です。 

---

 ## ステップ 2: 効率的な計算

 階乗の代わりに必要なのは逆モジュラーだけです。```python
S(p) = (-3 * pow(8, -1, p)) % p
```素数ごとに$p$。 

その後、複雑さは素数生成によって支配されます。$10^8$。 

くらいあります$5.76\times10^6$以下の素数$10^8$, したがって、エラトステネスのふるいは完全に実現可能です。 

---

 #2. Pythonの実装```python
from math import isqrt

LIMIT = 10**8

# Sieve of Eratosthenes (odd numbers only)
n = LIMIT
sieve = bytearray(b"\x01") * (n // 2)
sieve[0] = 0  # 1 is not prime

for i in range(3, isqrt(n) + 1, 2):
    if sieve[i // 2]:
        start = i * i
        step = 2 * i
        sieve[start // 2 :: i] = b"\x00" * (((n - start - 1) // step) + 1)

total = 0

# Iterate over odd primes
for p in range(5, n, 2):
    if sieve[p // 2]:
        total += (-3 * pow(8, -1, p)) % p

print(total)
```---

 ## 例の検証

 のために$p=7$:$$8^{-1}\equiv 1 \pmod 7,$$それで$$S(7)\equiv -3\equiv 4 \pmod 7,$$ステートメントと一致します。 

また、```python
sum(S(p) for 5 <= p < 100) = 480
```これは問題のチェック値と一致します。
