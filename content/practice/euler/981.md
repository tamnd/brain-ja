 プロジェクト オイラー問題 981、**「クォータニオン グループ II」**:

 > 空の文字列から始めて、文字を含む文字列を構築したい`"x"`、`"y"`、`"z"`。 各ステップで、次の操作のいずれかが実行されます。 
>
 >
 >
 >
 > - 連続する 2 つの同じ文字を挿入します`"xx"`、`"yy"`または`"zz"`文字列内の任意の場所。 
> - 規則に従って、文字列内の 1 つの文字を連続する 2 つの文字に置き換えます。 
>
 >`"x" → "yz"`、`"y" → "zx"`、`"z" → "xy"`;
 > - 文字列内の 2 つの連続する異なる文字を交換します。 
>
 >
 >
 >
 > 偶数のステップを経て空の文字列から文字列を生成できる場合、その文字列はニュートラルと呼ばれます。 
>
 >
 >
 >
 > しましょう$N(X,Y,Z)$を含むニュートラル文字列の数になります。 
>
 >$X$のコピー`"x"`、$Y$のコピー`"y"`、 そして$Z$のコピー`"z"`。 
>
 >
 >
 >
 > たとえば:
 >
 >
 >
 >
 >$$N(2,2,2)=42,\qquad N(8,8,8)=4732773210.$$>
 >
 >
 >
 > 探す
 >
 >
 >
 >
 >$$\sum_{0\le i,j,k<88} N(i^3,j^3,k^3)$$>
 >
 >
 >
 > モジュロ$888{,}888{,}883$。 

---

 # 数学的分析

 文字を四元数単位として解釈します。$$x=i,\qquad y=j,\qquad z=k.$$クォータニオンの関係を思い出してください。$$i^2=j^2=k^2=-1,\qquad ij=k,\quad jk=i,\quad ki=j,$$順序を逆にすると符号が変わります。$$ji=-k,\quad kj=-i,\quad ik=-j.$$---

 ## 1. 重要な不変式

 一言$w$、 定義する$Q(w)$その文字の四元積として。 

最初は、空の文字列には積が含まれています$$Q(\emptyset)=1.$$次に、許可されている各操作を検査します。 

---

 ### 操作 A: 挿入`"xx"`（または`"yy"`、`"zz"`）

以来$i^2=j^2=k^2=-1$、$$Q \mapsto -Q.$$それで記号が反転します。 

---

 ### 操作 B: 交換`"x"`による`"yz"`なぜなら$$yz=jk=i=x,$$四元数の積は変わりません。 

ただし歩数は増えます$1$。 

同様に、クォータニオン値は固定されたままですが、パリティは反転します。 

---

 ### 操作 C: 隣接する個別の文字を交換する

 例:$$xy=ij=k,\qquad yx=ji=-k.$$隣接する個別の文字を交換すると、積が次のように乗算されます。$-1$。 

ここでも、1 ステップでパリティが変更され、符号が反転します。 

---

 したがって:

 > すべての操作は乗算されます$Q(w)$による$-1$。 

から始まる$Q=1$、 後$t$手順:$$Q(w)=(-1)^t.$$したがって、次のようになります。 

- 偶数のステップ数$\iff Q(w)=1$、
 - 奇数のステップ数$\iff Q(w)=-1$。 

それで：$$\boxed{\text{A word is neutral iff }Q(w)=1.}$$---

 # 2. 単語の四元数値

 修正数$X,Y,Z$。 

正規の順序付けられた単語を考えてみましょう。$$x^X y^Y z^Z.$$その四元数の値は$$i^X j^Y k^Z.$$他の配置は隣接するスワップによって異なります。 

各スワップには要因が導入されます$-1$。 

したがって：$$Q(w)=(-1)^{\operatorname{inv}(w)} i^X j^Y k^Z,$$どこ$\operatorname{inv}(w)$は反転カウントのモジュロです$2$。 

---

 #3. いつできるか$Q(w)=1$?

 最初の計算$$C=i^X j^Y k^Z.$$パリティパターンが$(X,Y,Z)$ちょうど 1 つまたはちょうど 2 つの奇数が含まれている場合、$C\in\{\pm i,\pm j,\pm k\}$、 それで$Q(w)\neq1$すべての言葉に対して。 

したがって、次のようになります。$$N(X,Y,Z)=0$$3 つのパリティがすべて等しい場合を除きます。 

---

 ## ケース A: すべて偶数

 書く$$X=2a,\quad Y=2b,\quad Z=2c.$$それから$$C=(-1)^{a+b+c}.$$したがって、中立的な言葉は次のとおりです。 

- 場合によっては逆転も$a+b+c$さえ、
 - 奇数反転の場合$a+b+c$奇数。 

---

 ## ケース B: すべて奇数

 書く$$X=2a+1,\quad Y=2b+1,\quad Z=2c+1.$$それから$$C=(-1)^{a+b+c}ijk =(-1)^{a+b+c+1}.$$同じパリティ ルールが適用されます。 

---

 # 4. 偶数/奇数のマルチセットの順列を数える

 しましょう$$T=\binom{X+Y+Z}{X,Y,Z}$$総単語数になります。 

させて$$D=(\#\text{even inversions})-(\#\text{odd inversions}).$$それから$$\#\text{even}=\frac{T+D}{2},\qquad \#\text{odd}=\frac{T-D}{2}.$$標準$q$-多項評価で$q=-1$与える:$$D= \begin{cases} \displaystyle \binom{\lfloor X/2\rfloor+\lfloor Y/2\rfloor+\lfloor Z/2\rfloor} {\lfloor X/2\rfloor,\lfloor Y/2\rfloor,\lfloor Z/2\rfloor}, & \text{if at most one of }X,Y,Z\text{ is odd},\\[2ex] 0,& \text{otherwise}. \end{cases}$$例えば：$$D(2,2,2)=\binom311=6.$$以来$$T(2,2,2)=\frac{6!}{2!2!2!}=90,$$そして正準四元数は$-1$、奇数の反転が必要です。$$N(2,2,2)=\frac{90-6}{2}=42,$$ステートメントと一致します。 

---

 # Pythonの実装```python
MOD = 888_888_883
INV2 = (MOD + 1) // 2

# cube values
vals = [i ** 3 for i in range(88)]

# largest factorial needed
MAXN = 3 * vals[-1]

# factorials modulo MOD
fac = [1] * (MAXN + 1)
for i in range(1, MAXN + 1):
    fac[i] = fac[i - 1] * i % MOD

# inverse factorials
invfac = [1] * (MAXN + 1)
invfac[MAXN] = pow(fac[MAXN], MOD - 2, MOD)

for i in range(MAXN, 0, -1):
    invfac[i - 1] = invfac[i] * i % MOD

def multinomial(a, b, c):
    s = a + b + c
    return (
        fac[s]
        * invfac[a] % MOD
        * invfac[b] % MOD
        * invfac[c] % MOD
    )

def N(X, Y, Z):
    odd = (X & 1) + (Y & 1) + (Z & 1)

    # impossible to get quaternion value 1
    if odd in (1, 2):
        return 0

    T = multinomial(X, Y, Z)

    # parity difference D
    if odd >= 2:
        D = 0
    else:
        D = multinomial(X // 2, Y // 2, Z // 2)

    # sign of canonical product
    if odd == 0:
        sign_parity = ((X + Y + Z) // 2) & 1
    else:
        sign_parity = ((X + Y + Z + 1) // 2) & 1

    # sign_parity = 0 means canonical product = +1
    if sign_parity == 0:
        return (T + D) * INV2 % MOD
    else:
        return (T - D) * INV2 % MOD

ans = 0

for X in vals:
    for Y in vals:
        for Z in vals:
            ans = (ans + N(X, Y, Z)) % MOD

print(ans)
```---

 # コードのチュートリアル

 - 階乗および素数を法とする逆階乗を事前計算します$888{,}888{,}883$。 
-`multinomial(a,b,c)`計算する$$\frac{(a+b+c)!}{a!\,b!\,c!}.$$-`odd`の数を数えます$X,Y,Z$奇数です。 
- 1 つまたは 2 つだけが奇数の場合、四元数の積は決して等しくなりません。$1$、だから戻ってください$0$。 
-`T`総単語数です。 
-`D`偶数マイナス奇数の差です。 
- 正準四元数積の符号に応じて、次のいずれかを選択します。$$\frac{T+D}{2} \quad\text{or}\quad \frac{T-D}{2}.$$最後にすべての立方体を合計します$i^3,j^3,k^3$のために$0\le i,j,k<88$。

 # 最終確認

 式は以下を再現します。$$N(2,2,2)=42.$$また、次のことも得られます。$$N(8,8,8)=4732773210,$$問題文と一致します。
