[プロジェクト オイラー問題 21](https://projecteuler.net/problem=21)

 ## 解決策

 **答え:**`31626`以下のすべての友好的な番号が必要です$10000$。 

定義する$d(n)$の適切な約数の合計として$n$。 

2 つの数字$a,b$次の場合に友好的なペアを形成します。$$d(a)=b,\qquad d(b)=a,\qquad a\ne b$$例：$$d(220)=284,\qquad d(284)=220$$したがって、220 と 284 の両方が含まれます。 

直接的なアプローチ:

 1. コンピューティング$d(n)$あらゆる人にとって$n<10000$。 
2. それぞれについて$a$：

- させて$b=d(a)$- もし$b\neq a$そして$d(b)=a$、 それから$a$友好的です。 
3. これらをすべて合計します$a$。 

効率的な除数の合計は、除数を最大で反復することで実行できます。$\sqrt n$。 

Python コード:```python
def divisor_sum(n):
    if n == 1:
        return 0

    total = 1
    p = 2

    while p * p <= n:
        if n % p == 0:
            total += p
            q = n // p
            if q != p:
                total += q
        p += 1

    return total

LIMIT = 10000

d = [0] * LIMIT
for i in range(1, LIMIT):
    d[i] = divisor_sum(i)

answer = 0

for a in range(1, LIMIT):
    b = d[a]

    if b != a and b > 0:
        if b < LIMIT:
            if d[b] == a:
                answer += a
        else:
            if divisor_sum(b) == a:
                answer += a

print(answer)
```既知の友好的なペア$10000$:$$(220,284),\ (1184,1210),\ (2620,2924),\ (5020,5564),\ (6232,6368)$$すべての数値を合計すると、次のようになります。$$220+284+1184+1210+2620+2924+5020+5564+6232+6368 = 31626$$**答え: 31626**
