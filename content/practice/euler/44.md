 ## 解決策

 **答え:**`5482660`私たちは五角形の数を求めます$$P_n=\frac{n(3n-1)}2$$あるペアについては$(j,k)$、

 -$P_j+P_k$五角形であり、
 -$|P_k-P_j|$五角形であり、

 そしてその違い$$D=|P_k-P_j|$$できるだけ小さいです。 

---

 # 数学的分析

 五角形の数は次のように生成されます。$$P_n=\frac{n(3n-1)}2.$$最初のいくつかは次のとおりです。$$1,5,12,22,35,51,70,92,\dots$$五角形の数字が 2 つ必要です$P_j,P_k$2 つの条件を同時に満たす:$$P_j+P_k \text{ is pentagonal}$$そして$$|P_k-P_j| \text{ is pentagonal}.$$総当たり検索は可能ですが、数値が五角形であるかどうかをテストする効率的な方法が必要です。 

---

 ## 1. 五角形テストの導出

 仮定してください$x$五角形です。 次に、ある整数について$n$、$$x=\frac{n(3n-1)}2.$$2 を掛ける:$$2x=3n^2-n.$$再配置:$$3n^2-n-2x=0.$$これは二次方程式です$n$。 二次公式を使用すると、$$n=\frac{1\pm\sqrt{1+24x}}6.$$のために$n$正の整数になるようにするには:

 1.$1+24x$完全な正方形でなければなりません、
 2. 平方根は分子を 6 で割り切れなければなりません。 

したがって:$$x \text{ is pentagonal} \iff \sqrt{24x+1}\in\mathbb Z \quad\text{and}\quad (1+\sqrt{24x+1})\equiv0\pmod 6.$$これにより、メンバーシップ テストが非常に高速になります。 

---

 ## 2. 検索戦略

 五角形の数値を昇順に生成します。 

各ペアごとに$j<k$:$$P_j=\frac{j(3j-1)}2,\qquad P_k=\frac{k(3k-1)}2.$$計算:$$S=P_j+P_k, \qquad D=P_k-P_j.$$両方あるかどうかを確認してください$S$そして$D$は五角形です。 

最小値で見つかった最初の有効なペア$D$必要な解決策です。 

五角形の数は二次関数的に増加するため、検索はかなり早く収束します。 

---

 # Pythonの実装```python
import math

# Generate nth pentagonal number
def pentagonal(n):
    return n * (3 * n - 1) // 2

# Test whether x is pentagonal
def is_pentagonal(x):
    # Solve n = (1 + sqrt(1 + 24x)) / 6
    d = 24 * x + 1
    s = int(math.isqrt(d))

    # Must be a perfect square
    if s * s != d:
        return False

    # Must give integer n
    return (1 + s) % 6 == 0

best_D = None

# Search over pairs of pentagonal numbers
for k in range(1, 5000):
    Pk = pentagonal(k)

    for j in range(1, k):
        Pj = pentagonal(j)

        D = Pk - Pj
        S = Pk + Pj

        # Check both conditions
        if is_pentagonal(D) and is_pentagonal(S):
            best_D = D
            print("Found:", Pj, Pk, "Difference =", D)
            break

    if best_D is not None:
        break

print("Answer =", best_D)
```---

 # 小さな例の検証

 問題文は次のようになります。$$P_4=22,\qquad P_7=70.$$それらの合計:$$22+70=92=P_8,$$それは五角形です。 

彼らの違い:$$70-22=48.$$チェック：$$24(48)+1=1153,$$そして$1153$は完全な正方形ではないので、$48$五角形ではありません。 

私たちのテストでは正しく拒否されました。
