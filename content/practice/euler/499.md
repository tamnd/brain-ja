 ## 1. 数学的分析

 **破滅確率**を定義する$$q_m(s)=1-p_m(s),$$ギャンブラーが最終的にお金を使い果たす確率。 

のために$s<m$、$$q_m(s)=1.$$のために$s\ge m$、最初のゲームでのコンディショニングにより、$$q_m(s) = \sum_{k=0}^{\infty} 2^{-(k+1)} q_m(s-m+2^k).$$私たちは指数関数的な解決策を探しています$$q_m(s)=r^{\,s-m+1} \qquad (0<r<1).$$代入:$$r^{s-m+1} = \sum_{k=0}^{\infty} 2^{-(k+1)} r^{s-m+1-m+2^k}.$$共通因数をキャンセルする$r^{s-m+1}$:$$1 = r^{-m} \sum_{k=0}^{\infty} 2^{-(k+1)}r^{2^k}.$$同様に、$$r^m = \sum_{k=0}^{\infty} \frac{r^{2^k}}{2^{k+1}}.$$これには独特のルーツがあります$r\in(0,1)$。 

漸化条件と境界条件によって解が一意に決定され、次のようになります。$$q_m(s)=r^{s-m+1},$$したがって$$p_m(s)=1-r^{s-m+1}.$$### 例に対する健全性チェック

 のために$m=2$、解決します$$r^2=\sum_{k\ge0}\frac{r^{2^k}}{2^{k+1}}$$与える$$r\approx 0.74779150275.$$それから：$$p_2(2)=1-r\approx 0.2522,$$

$$p_2(5)=1-r^4\approx 0.6873,$$問題文と一致します。 

のために$m=6$、$$p_6(10000)\approx 0.9952,$$再び指定された値と一致します。

 ## 2. Python の実装```python
import mpmath as mp

mp.mp.dps = 50  # high precision

def survival_probability(m, s):
    # Equation:
    # r^m = sum_{k>=0} r^(2^k) / 2^(k+1)
    def equation(r):
        total = mp.nsum(
            lambda k: r ** (2 ** k) / (2 ** (k + 1)),
            [0, mp.inf]
        )
        return total - r ** m

    # Root in (0, 1)
    r = mp.findroot(
        equation,
        (mp.mpf('0.99999999'),
         mp.mpf('0.999999999'))
    )

    # p_m(s) = 1 - r^(s-m+1)
    return 1 - r ** (s - m + 1)

ans = survival_probability(15, 10**9)

print(ans)
print(f"{ans:.7f}")
```---
