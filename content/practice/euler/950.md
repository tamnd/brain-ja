[プロジェクト オイラー問題 950](https://projecteuler.net/problem=950)

 ## 解決策

 **答え:**`429162542`重要な観察は、同じくらい血に飢えているということです。$p=\frac1{\sqrt{C}}$、海賊の決定ルールは、以下の間のしきい値比較になります。 

- その後追加の板歩きで生き残る（価値がある）$p\cdot \Delta w$）、
 - 今すぐコインの賄賂を受け取るのではなく。 

不合理なために$p$、同点は決して発生しないため、均衡は決定的になります。 

させて$L$上級海賊が生き残る海賊カウントになる。 このような「リセット」ポイントの間に、新しい上級海賊はすべて運命にあり、次のような長い決定的な死の連鎖を生み出します。 

-$w(n)$直線的に増加し、
 -$c(n)$一定のままで、
 - 次の生存点は、以下を含む整数実現可能性不等式から導出できます。$$\left\lceil \frac{d}{\sqrt{C}} \right\rceil,$$どこ$d$次のリセットまでの距離です。 

これにより問題が不可能から軽減されます$O(N)$シミュレーション（$N=10^{16}$) おおよそ$O(\sqrt{C}\log N)$リセット状態間をジャンプすることによる動作。 

次の Python は正確な値を計算し、提供されたすべてのチェックを再現します。```python
from math import isqrt

MOD = 10**9

def floor_div_sqrt(d, D):
    if d <= 0:
        return 0
    dd = d * d
    t = isqrt(dd // D)

    while (t + 1) * (t + 1) * D <= dd:
        t += 1
    while t * t * D > dd:
        t -= 1

    return t

def ceil_div_sqrt(d, D):
    if d <= 0:
        return 0
    return floor_div_sqrt(d, D) + 1

def initial_prefix_sum(N, C):
    M = min(N, 2 * C)

    if M <= 0:
        return 0

    m = M // 2
    total = 2 * (m * C - (m * (m - 1)) // 2)

    if M % 2 == 1:
        total += C - m

    return total

def next_reset(L, C, D):
    if C == 0:
        return 2 * L

    t = 1
    while t <= C:
        y = C // t
        x = 2 * L - 2 * y
        d = x - L

        if d > 0:
            s = ceil_div_sqrt(d, D)
            if C // s == y:
                return x

        t = (C // y) + 1

    return 2 * L

def T(N, C, D):
    start_reset = 2 * C + 2

    if N <= start_reset:
        return initial_prefix_sum(N, C)

    total = initial_prefix_sum(start_reset, C)

    L = start_reset
    cL = 0

    while L < N:
        x = next_reset(L, C, D)

        if x > N:
            d = N - L + 1
            total += (d - 1) * cL + (d - 1) * d // 2
            break

        d = x - L

        if d > 1:
            total += (d - 1) * cL + (d - 1) * d // 2

        required_votes = (x + 1) // 2
        free_votes = d
        need_bribes = max(required_votes - free_votes, 0)

        s = ceil_div_sqrt(d, D)
        cost = need_bribes * s

        cL = C - cost
        total += cL

        L = x

    return total

# Verification
assert T(30, 3, 3) == 190
assert T(50, 3, 31) == 385
assert T(10**3, 101, 101) == 142427

N = 10**16
ans = 0

for k in range(1, 7):
    C = 10**k + 1
    ans += T(N, C, C)

ans %= 10**9
print(ans)
```計算により次の結果が得られます。
