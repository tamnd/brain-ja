[プロジェクト オイラー問題 61](https://projecteuler.net/problem=61)

 ## 解決策

 **答え:**`28684`**各タイプから 1 つずつ、6 つの異なる 4 桁の多角形数値の循環セット**を求めます。 

- 三角形$P_{3,n}$- 四角$P_{4,n}$- 五角形$P_{5,n}$- 六角形$P_{6,n}$- 七角形$P_{7,n}$- 八角形$P_{8,n}$次のような:

 1. すべての数字は**4桁**です。 
2. セットは**循環**です:$$\text{last two digits of } a_i = \text{first two digits of } a_{i+1}$$そして最後のリンクは最初のリンクに戻ります。 
3. 各多角形タイプは **1 回だけ**表示されます。 

---

 ## 1. 数学的分析

 ### ステップ 1: 多角形の数値を生成する

 式は次のとおりです。$$P_{3,n}=\frac{n(n+1)}{2}$$

$$P_{4,n}=n^2$$

$$P_{5,n}=\frac{n(3n-1)}{2}$$

$$P_{6,n}=n(2n-1)$$

$$P_{7,n}=\frac{n(5n-3)}{2}$$

$$P_{8,n}=n(3n-2)$$**4 桁の値**のみを考慮します。つまり、$$1000 \le P_{k,n} \le 9999$$---

 ### ステップ 2: グラフの問題としてモデル化する

 のような数字$8128$最初の 2 桁が等しい別の番号に接続できます$28$。 

例：$$8128 \to 2882$$なぜなら：$$8128 \mod 100 = 28$$そして$$\left\lfloor \frac{2882}{100} \right\rfloor = 28$$したがって、各数値は以下の間の有向エッジのように動作します。 

- プレフィックス = 最初の 2 桁
 - サフィックス = 最後の 2 桁

 **長さ 6 のサイクル**を検索します。ここで:

 - 各多角形タイプは 1 回使用されます。 
- 数字は明確です。 
- 隣接ルールが保持されます。 
- サイクルが終了します。 

これは、多角形タイプの順列に対する **深さ優先検索 (DFS)** によって自然に解決されます。 

---

 ### ステップ 3: 無効なトランジションを制限する

 有益な観察:

 接尾辞が 10 未満の場合、4 桁の数字の最初の 2 桁にすることはできません。 

例：$$8120$$で終わる$20$、 有効。 

しかし$$8105$$で終わる$05$, 「05」で始まる4桁の数字がないので不可能です。 

したがって、最後の 2 桁が 10 以上である数値のみを保持します。

 ## 2. Python の実装```python
from collections import defaultdict

# Polygonal formulas
def polygonal(s, n):
    if s == 3:
        return n * (n + 1) // 2
    elif s == 4:
        return n * n
    elif s == 5:
        return n * (3 * n - 1) // 2
    elif s == 6:
        return n * (2 * n - 1)
    elif s == 7:
        return n * (5 * n - 3) // 2
    elif s == 8:
        return n * (3 * n - 2)

# Generate all valid 4-digit polygonal numbers
poly = {}

for s in range(3, 9):
    nums = []
    n = 1

    while True:
        x = polygonal(s, n)

        if x >= 10000:
            break

        # Keep only valid 4-digit cyclic candidates
        if 1000 <= x <= 9999 and x % 100 >= 10:
            nums.append(x)

        n += 1

    poly[s] = nums

def dfs(path, used_types):
    # If we have 6 numbers, check cyclic closure
    if len(path) == 6:
        return path if path[-1] % 100 == path[0] // 100 else None

    suffix = path[-1] % 100

    # Try unused polygonal types
    for s in range(3, 9):
        if s not in used_types:
            for num in poly[s]:
                if num // 100 == suffix:
                    result = dfs(
                        path + [num],
                        used_types | {s}
                    )
                    if result:
                        return result

    return None

# Start search from octagonal numbers
# (any type works, but this reduces symmetry)
answer_cycle = None

for start in poly[8]:
    result = dfs([start], {8})
    if result:
        answer_cycle = result
        break

print(answer_cycle)
print(sum(answer_cycle))
```---

 ## 3. コードのチュートリアル

 ### 多角形数値の生成

 の 6 つの公式を実装します。`polygonal(s, n)`。 

各タイプについて:```python
for s in range(3, 9):
```9999 を超えるまで値を生成します。 

当社は以下のみを保持します:```python
1000 <= x <= 9999
```そして```python
x % 100 >= 10
```最後の 2 桁が別の 4 桁の数値の最初の 2 桁を形成できるようにするためです。 

---

 ### DFS 検索

 再帰関数:```python
dfs(path, used_types)
```維持します:

 -`path`→ 現在の数字の連鎖
 -`used_types`→ 多角形のカテゴリはすでに選択されています

 各ステップで:```python
suffix = path[-1] % 100
```未使用の多角形タイプをすべて試し、次のコマンドを使用して数値を検索します。```python
num // 100 == suffix
```最初の 2 桁が一致することを意味します。 

6 つの数字が集まった場合:```python
len(path) == 6
```サイクルが終了することを確認します。```python
path[-1] % 100 == path[0] // 100
```---

 ### 例の検証

 問題の例:$$8128, 2882, 8281$$機能する理由:

 -$8128 \to 2882$28経由
 -$2882 \to 8281$82経由
 -$8281 \to 8128$81経由

 数字はそれぞれ三角形、五角形、正方形です。 

DFS ロジックは、6 つのタイプに対してこの動作を正確に再現します。

 ## 4. 最終確認

 プログラムを実行すると、一意の循環セットが見つかります。$$1281,\ 8128,\ 2882,\ 8256,\ 5625,\ 2512$$(各ポリゴン ファミリの 1 つの数値を 1 回だけ使用します)。 

それらの合計は次のとおりです。$$1281+8128+2882+8256+5625+2512=28684$$大きさは妥当です (6 つの 4 桁の数字の合計は約$6\times 5000\approx 30000$) 問題の一意性条件と一致します。 

**答え: 28684**
