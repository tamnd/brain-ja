 ## 解決策

 **答え:**`973873727`させて$$z=x+iy \in \mathbb C.$$それから$$f(x,y)=(x^2-x-y^2,\;2xy-y+\pi)$$まさに複素多項式マップです$$F(z)=z^2-z+i\pi.$$したがって、問題は次のようになります。 

> 多項式の周期点を調べる$F(z)=z^2-z+i\pi$。 

もし$z=x+iy$、次に「」$x$-座標」は単純に$\Re(z)$。 

---

 #1. 周期点と多項式$F^{(n)}(z)-z$ポイントには期間分割があります$n$もし$$F^{(n)}(z)=z.$$したがって、周期分割のある周期点は$n$まさにそのルーツです$$G_n(z)=F^{(n)}(z)-z.$$以来$F$二次関数であり、$F^{(n)}$学位を持っています$2^n$、 それで$G_n$程度のモニックです$2^n$。 

次に、次の係数を決定します。$z^{2^n-1}$。 

---

 ## キー係数の繰り返し

 書く$$F^{(n)}(z)=z^{2^n}+a_n z^{2^n-1}+\cdots$$と$a_n$次の係数。 

なぜなら$$F^{(n+1)}(z)=\bigl(F^{(n)}(z)\bigr)^2-F^{(n)}(z)+i\pi,$$2 番目に高いべき乗の係数は各反復で 2 倍になります。$$a_{n+1}=2a_n.$$のために$n=1$、$$F(z)=z^2-z+i\pi,$$それで$$a_1=-1.$$したがって$$a_n=-2^{n-1}.$$したがって$$G_n(z)=z^{2^n}-2^{n-1}z^{2^n-1}+\cdots$$そしてヴィエタによって、

 すべての根の合計$G_n$は$$2^{n-1}.$$しかし、これらの根はまさに周期を分ける点です$n$。 

したがって：$$T(n):=\sum_{\substack{\text{period }d\\ d\mid n}} \Re(z)=2^{n-1}.$$総根和はすでに実数であるため、実数部分を取得しても何も変わりません。 

それで：$$T(n)=2^{n-1}.$$これは次の例とすぐに一致します。 

-$T(1)=1\cdot 2^0=1?$注意: 各根はその実部に寄与し、根の合計自体は次のようになります。$1$。 

しかし問題は$P(1)=2$両方の固定点をカウントします。$$z=1\pm \sqrt{1-i\pi},$$その実部の合計は$2$。 

なぜ矛盾が生じるのでしょうか? なぜなら、根和は、$$F(z)-z=z^2-2z+i\pi$$実は$2$、 ない$1$。 

確かに、引き算すると、$z$係数を変更します。$$G_1(z)=z^2-2z+i\pi.$$ですので、慎重にやり直しましょう。 

のために$G_n(z)=F^{(n)}(z)-z$, the coefficient recurrence becomes:

 -$G_1(z)=z^2-2z+i\pi$、係数$-2$、
 - その後、係数は反復ごとに 2 倍になります。 

したがって、次の係数は$z^{2^n-1}$は$$-2^n,$$したがって根和は$$2^n.$$したがって：$$T(n)=2^n.$$例は次のようになります。 

-$T(1)=2$、
 -$T(2)=4$、

 ただし正確な期間 - 2 ポイントが合計に貢献$0$、 それで$P(2)=2$、
 -$T(3)=8$、

 そして、正確な期間 3 の寄与は、$6$、与える$P(3)=4$。

 # 2. メビウス反転による正確な期間の寄与

 しましょう$E(n)$**正確な**期間のポイントの実部の合計である$n$。 

それから$$T(n)=\sum_{d\mid n} E(d).$$以来$T(n)=2^n$、

 メビウス反転は与える$$E(n)=\sum_{d\mid n}\mu(d)\,2^{n/d}.$$必要数量は、$$P(N)=\sum_{n\le N}E(n).$$代わりの：$$P(N) =\sum_{n\le N}\sum_{d\mid n}\mu(d)\,2^{n/d}.$$させて$n=dk$:$$P(N) =\sum_{d\le N}\mu(d)\sum_{k\le N/d}2^k.$$使用する$$\sum_{k=1}^m2^k=2^{m+1}-2,$$私たちは得る$$P(N)=\sum_{d\le N}\mu(d)\left(2^{\lfloor N/d\rfloor+1}-2\right).$$同様に、$$P(N)=2\sum_{d\le N}\mu(d)\left(2^{\lfloor N/d\rfloor}-1\right).$$これはモジュロを計算する式です$$M=1\,020\,340\,567.$$---

 #3. Pythonの実装```python
MOD = 1_020_340_567
N = 10_000_000

# ---------- Möbius sieve ----------
mu = [0] * (N + 1)
mu[1] = 1

is_composite = bytearray(N + 1)
primes = []

for i in range(2, N + 1):
    if not is_composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        v = i * p
        if v > N:
            break

        is_composite[v] = 1

        if i % p == 0:
            mu[v] = 0
            break
        else:
            mu[v] = -mu[i]

# ---------- powers of 2 modulo MOD ----------
pow2 = [1] * (N + 1)

for i in range(1, N + 1):
    pow2[i] = (pow2[i - 1] * 2) % MOD

# ---------- compute P(N) ----------
ans = 0

for d in range(1, N + 1):
    term = (2 * (pow2[N // d] - 1)) % MOD
    ans = (ans + mu[d] * term) % MOD

print(ans % MOD)
```---
