 ## 解決策

 **答え:**`999998760323313995`させて$$T(m,n)=\#\left\{\, i \mid n\le i<m,\ 10\mid \binom{i}{n}\right\}.$$私たちは与えられています$$T(10^9,10^7-10)=989697000$$そして計算しなければなりません$$T(10^{18},10^{12}-10).$$---

 #1. 数学的分析

 二項係数が次で割り切れるときを数える必要があります。$10$、つまり両方によって$2$そして$5$。 

したがって、次のように定義します。 

-$A_2$: の数$i$そのような$\binom{i}{n}$は ** で割り切れません$2$**。 
-$A_5$: の数$i$そのような$\binom{i}{n}$は ** で割り切れません$5$**。 
-$A_{10}$: の数$i$そのような$\binom{i}{n}$どちらでも割り切れない$2$または$5$。 

次に、包含と除外により、$$T(m,n) = (m-n)-A_2-A_5+A_{10}.$$したがって、問題はこれら 3 つの量を計算することに帰着します。 

---

 ## ルーカス/クンマーの定理

 プライムの場合$p$、$$\binom{i}{n}\not\equiv 0 \pmod p$$すべてのベースがあれば-$p$の桁$n$は最大でも次の対応する桁です$i$。 

同様に、もし$i=n+x$、次に追加します$n$そして$x$基地内で$p$**キャリーなし**。 

---

 # コンピューティング$A_2$させて$$n=10^{12}-10.$$バイナリでは、$\binom{i}{n}$バイナリの 1 ビットごとに奇数になる$n$も 1 ビットです$i$。 

基数 2 の数字 DP は次のようになります。$$A_2 = 238418395136.$$---

 # コンピューティング$A_5$基数 5 では、Lucas は同様の条件を与えています。 

基数 5 桁の DP は次のようになります。$$A_5 = 1258291200.$$---

 # コンピューティング$A_{10}$ここで、両方の条件を同時に満たす数値が必要になります。 

書く$$i=n+x.$$次に:

 - 2塁ではキャリーなし$\iff x\& n =0$、
 - ベース 5 ではキャリーなし$\iff$5 進数のすべての桁$x$によって制限されています$4-d_k(n)$。 

の進数 5 展開$n=10^{12}-10$は$$(1,1,2,3,4,0,4,4,4,4,4,4,4,4,4,4,3,0)_5$$(高値から低値まで読みます)。 

ほとんどの桁は$4$の対応する数字を強制的に入力します。$x$なる$0$。 

のみ$4800$低い部分の可能性が残っています。 

させて$$5^{18}=3814697265625.$$許容されるすべての$x$次のように一意に書くことができます$$x=y\cdot 5^{18}+z,$$どこ：

-$0\le y<262144$、
 -$z$そのうちの1つです$4800$admissible low parts.

 バイナリ条件の確認$(x\& n)=0$このようなすべてのペアで得られるのは、$$A_{10}=321.$$---

 # 最終計算

 次に、包含と除外を適用します。$$\begin{aligned} T &=(10^{18}-(10^{12}-10))  -238418395136  -1258291200  +321 \\ &=999999000000000010  -238418395136  -1258291200  +321 \\ &=999998760323313995. \end{aligned}$$---

 #2. Pythonの実装```python
from functools import lru_cache
from itertools import product
import numpy as np

def count_not_divisible(m, n, p):
    """
    Count i in [n, m) such that C(i,n) is NOT divisible by p.
    Lucas theorem:
    every base-p digit of n must be <= corresponding digit of i.
    """

    # digits of n
    nd = []
    x = n
    while x:
        nd.append(x % p)
        x //= p

    # digits of m-1
    md = []
    x = m - 1
    while x:
        md.append(x % p)
        x //= p

    L = max(len(nd), len(md))
    nd += [0] * (L - len(nd))
    md += [0] * (L - len(md))

    @lru_cache(None)
    def dp(pos, tight):
        if pos < 0:
            return 1

        limit = md[pos] if tight else (p - 1)

        total = 0
        for d in range(nd[pos], limit + 1):
            total += dp(pos - 1, tight and d == limit)

        return total

    return dp(L - 1, True)

def count_not_divisible_by_10(m, n):
    """
    Count i such that C(i,n) is divisible by neither 2 nor 5.
    """

    L = m - n

    # base-5 digits of n
    digits = []
    x = n
    while x:
        digits.append(x % 5)
        x //= 5

    # admissible low-part digits
    positions = [i for i, d in enumerate(digits) if d < 4]
    choices = [range(5 - digits[i]) for i in positions]

    zs = []

    for tup in product(*choices):
        z = 0
        for v, k in zip(tup, positions):
            z += v * (5 ** k)
        zs.append(z)

    zs = np.array(zs, dtype=np.uint64)

    p5 = 5 ** len(digits)

    Y = (L - 1) // p5 + 1

    ys = np.arange(Y, dtype=np.uint64) * np.uint64(p5)

    total = 0

    for z in zs:
        total += np.count_nonzero(((ys + z) & np.uint64(n)) == 0)

    return int(total)

def solve():
    m = 10 ** 18
    n = 10 ** 12 - 10

    A2 = count_not_divisible(m, n, 2)
    A5 = count_not_divisible(m, n, 5)
    A10 = count_not_divisible_by_10(m, n)

    T = (m - n) - A2 - A5 + A10

    return T

print(solve())

各拠点ごとに、$p$桁位置:

 - の桁$i$少なくとも次の桁でなければなりません$n$、
 - の桁を超えてはなりません$m-1$。 

DP カウントはすべて有効です$i<m$。

基数 5 の条件は、下位桁を大幅に制限します。$x=i-n$、残すのみ$4800$可能性。 

次に、より高いブロック係数を列挙します。$y$、次を使用してバイナリのキャリーなし条件をテストします。```python
((ys + z) & n) == 0
```これは、「1 ビットが重複しない」ことを正確にエンコードします。
