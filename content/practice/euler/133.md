 ## 解決策

 **答え:**`453647705`させて$$R(k)=\frac{10^k-1}{9}$$で再現ユニットを示します$k$もの。 

すべての素数の合計を求めるように求められます$p<100000$そのような$$p \nmid R(10^n) \quad\text{for every } n\ge 0.$$---

 #1. 数学的分析

 ## ステップ 1: 素数がレパユニットを割るのはいつですか?

 素数の場合$p\neq 2,5$、$$p \mid R(k) \iff p \mid \frac{10^k-1}{9} \iff 10^k \equiv 1 \pmod p.$$したがって、重要なオブジェクトは次の**乗算順序**です。$10 \pmod p$。 

定義する：$$\operatorname{ord}_p(10)=\min\{d>0 : 10^d\equiv 1 \pmod p\}.$$それから：$$p \mid R(k) \iff \operatorname{ord}_p(10)\mid k.$$---

 ## ステップ 2: に特化する$R(10^n)$現在、次のことが必要です。$$p \mid R(10^n) \iff \operatorname{ord}_p(10)\mid 10^n.$$しかし$$10^n = 2^n5^n,$$したがって、その唯一の素因数は$2$そして$5$。 

したがって：$$\operatorname{ord}_p(10)\mid 10^n$$一部の人にとっては$n$**ただし** 順序に次の素因数が含まれていない場合に限ります$2$そして$5$。 

同様に:$$\operatorname{ord}_p(10)=2^a5^b$$いくつかの整数の場合$a,b\ge0$。 

したがって、次のようになります。 

- 注文に他の素因数がある場合 (例:$3,7,11,\dots$）、 それから$p$**決して**分割しません$R(10^n)$。 
- そうしないと、最終的にはそうなります。 

---

 ## ステップ 3: ステートメントの例

 ### プライム$17$

$$\operatorname{ord}_{17}(10)=16=2^4.$$以来$16\mid 10^4$、$$17 \mid R(10^4).$$それで$17$はいくつかの有効な約数です$R(10^n)$。 

---

 ### プライム$19$

$$\operatorname{ord}_{19}(10)=18=2\cdot 3^2.$$要因のせいで$3$、$18\nmid 10^n$あらゆる人にとって$n$。 

したがって、$19$決して分けません$R(10^n)$。

 #2. Pythonの実装```python
from sympy import primerange

def multiplicative_order_10(p):
    """
    Compute the multiplicative order of 10 modulo p.
    Assumes gcd(p, 10) = 1.
    """
    order = 1
    value = 10 % p

    while value != 1:
        value = (value * 10) % p
        order += 1

    return order

total = 0

for p in primerange(2, 100000):

    # 2 and 5 can never divide repunits
    if p in (2, 5):
        total += p
        continue

    order = multiplicative_order_10(p)

    # Remove all factors of 2
    while order % 2 == 0:
        order //= 2

    # Remove all factors of 5
    while order % 5 == 0:
        order //= 5

    # If anything remains, order had another prime factor
    # so p can never divide R(10^n)
    if order != 1:
        total += p

print(total)
```---
