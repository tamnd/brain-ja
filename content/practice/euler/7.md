 ## 解決策

 を見つけるには、$10{,}001^\text{st}$prime では、素数を順番に生成し、ターゲットのインデックスに達するまでカウントします。 

標準的なアプローチは次のとおりです。 

- から始める$2$- 試行除算を使用して各候補の素数性をテストします。$\sqrt{n}$- 見つかった素数を数えます
 - カウントに達したら停止します$10{,}001$クリーンな Python コードは次のとおりです。```python
def is_prime(n):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    d = 3
    while d * d <= n:
        if n % d == 0:
            return False
        d += 2

    return True

count = 0
num = 1

while count < 10001:
    num += 1
    if is_prime(num):
        count += 1

print(num)
```ロジックをトレースすると、次のようになります。 

- 素数は次のように始まります。$2,3,5,7,11,13,\dots$- カウンタは素数が見つかった場合にのみ増加します。
