[プロジェクト オイラー問題 168](https://projecteuler.net/problem=168)

 ## 解決策

 **答え:**`59206`させて$$n = 10a+b$$10 進数表記では、$b$は最後の桁です。 

右回転$n$動く$b$前へ:$$R(n)=b\cdot 10^{k-1}+a$$どこ$k$の桁数です$n$。 

私たちはそう言われています$$R(n)=m n$$整数乗算の場合$m$。 

私たちはすべてを求めます$n$と$$10<n<10^{100}$$この特性を満たしており、最後のものを求めます。$5$それらの合計の桁数。 

---

 # 数学的分析

 仮定してください$n$もっている$k$数字。 

書く$$n=10a+b,$$どこ：

-$b\in\{1,\dots,9\}$(最後の桁は指定できません)$0$、そうでない場合は、回転により 1 桁が失われます)、
 -$0\le a<10^{k-1}$。 

回転させた数字は、$$R(n)=b\cdot 10^{k-1}+a.$$条件は$$b\cdot 10^{k-1}+a = m(10a+b).$$再配置:$$b\cdot 10^{k-1}+a = 10ma+mb,$$それで$$b(10^{k-1}-m)=a(10m-1).$$したがって、$$a=\frac{b(10^{k-1}-m)}{10m-1}.$$それから$$n=10a+b$$になる$$n =10\cdot \frac{b(10^{k-1}-m)}{10m-1}+b.$$用語を組み合わせる:$$n = \frac{10b(10^{k-1}-m)+b(10m-1)}{10m-1}.$$の$-10bm$そして$+10bm$キャンセル：$$n = \frac{b(10^k-1)}{10m-1}.$$したがって、すべてのソリューションは次の形式を持つ必要があります。$$\boxed{ n=\frac{b(10^k-1)}{10m-1} }$$と：

-$1\le b\le 9$、
 -$1\le m\le 9$、
 - 分母を分子で割る。 

---

 ## キーの分割条件

 必要です$$10m-1 \mid b(10^k-1).$$以来$$10m-1 \in \{9,19,29,39,49,59,69,79,89\},$$の乗法次数を分析できます。$10$これらの数値を法として計算します。 

それぞれについて$m$、 定義する$$d=10m-1.$$もし$$10^k\equiv 1 \pmod d,$$それから$d\mid (10^k-1)$、およびすべての桁$b$動作します。 

それ以外の場合は一部のみ$b$欠けている要素を補うことができるかもしれません。 

なぜなら$k<100$、すべてをブルートフォースできます。 

-$k=2,\dots,99$、
 -$m=1,\dots,9$、
 -$b=1,\dots,9$、

 そして可分性をテストします。 

合計の検索スペースは非常に小さいです。$$98\times 9\times 9 = 7938.$$---

 # Pythonの実装```python
MOD = 100000

total = 0

# k = number of digits
for k in range(2, 100):

    ten_k_minus_1 = pow(10, k) - 1

    # multiplier m
    for m in range(1, 10):

        d = 10 * m - 1

        # final digit b
        for b in range(1, 10):

            numerator = b * ten_k_minus_1

            # n must be integer
            if numerator % d == 0:

                n = numerator // d

                # verify the property directly
                s = str(n)

                rotated = int(s[-1] + s[:-1])

                if rotated == m * n:
                    total = (total + n) % MOD

print(total)
```---
