[プロジェクト オイラー問題 307](https://projecteuler.net/problem=307)

 ## 解決策

 **答え:**`0.7311720251`させて

-$n = 1{,}000{,}000$チップス、
 -$k = 20{,}000$欠陥、

 各欠陥は独立して均一にいずれかの欠陥に割り当てられます。$n$チップス。 

私たちが欲しいのは$$p(k,n)=\Pr(\text{some chip has at least }3\text{ defects}).$$同様に、$$p(k,n)=1-\Pr(\text{every chip has at most 2 defects}).$$主な課題は、大きなパラメータに対してこの確率を正確に計算することです。 

---

 #1. 数学的分析

 配布します$k$欠陥をラベル付けして$n$ラベルが付いたチップス。 

割り当ての合計:$$n^k.$$ここで、どのチップにも 2 つ以上の欠陥が発生しない割り当てをカウントします。 

仮定する：

-$a$チップには正確に 2 つの欠陥があり、
 -$b$チップには正確に 1 つの欠陥が発生します。 

それから$$2a+b=k.$$したがって、$$b=k-2a.$$占有チップ数は$$a+b=k-a.$$---

 ## 有効な構成のカウント

 固定の場合$a$:

 ### ステップ 1: チップを選択する

 選択してください:

 -$a$2 つの欠陥を含むチップ、
 -$b=k-2a$1 つの欠陥を含むチップ。 

方法の数:$$\binom{n}{a}\binom{n-a}{k-2a}.$$---

 ### ステップ 2: 欠陥を配布する

 私たちは持っています$k$ラベル付きの欠陥。 

それらを次のように分割する必要があります。 

-$a$順序のないペア、
 -$k-2a$シングルトン。 

方法の数:$$\frac{k!}{(2!)^a}.$$ただし、ペアになったグループ自体は順序付けされていないため、次のように除算します。$a!$:$$\frac{k!}{2^a a!}.$$シングルトン グループはチップによって自動的に区別されます。 

したがって、固定の有効な割り当ての合計は$a$:$$\binom{n}{a} \binom{n-a}{k-2a} \frac{k!}{2^a}.$$で割る$n^k$:$$\Pr(\text{no chip has } \ge 3) = \sum_{a=0}^{\lfloor k/2\rfloor} \frac{ \binom{n}{a} \binom{n-a}{k-2a} k! }{ 2^a n^k }.$$これはうまく単純化されます。 

---

 ## 簡略化された式

 下降階乗を使用する:$$\binom{n}{a}\binom{n-a}{k-2a} = \frac{n!}{a!(k-2a)!(n-k+a)!}.$$したがって、$$P_{\le2} = \sum_{a=0}^{\lfloor k/2\rfloor} \frac{ n! \, k! }{ a!(k-2a)!(n-k+a)!2^a n^k }.$$したがって$$p(k,n)=1-P_{\le2}.$$---

 #2. 数値的に安定した計算

 直接階乗は不可能です。 

代わりに、各項を対数的に計算します。 

定義する$$T_a = \frac{ n! \, k! }{ a!(k-2a)!(n-k+a)!2^a n^k }.$$それから$$\log T_a = \log(n!) +\log(k!) -\log(a!) -\log((k-2a)!) -\log((n-k+a)!) -a\log 2 -k\log n.$$対数ガンマの使用:$$\log(m!)=\ln\Gamma(m+1).$$最後に、log-sum-exp 安定化を使用して合計を計算します。 

---

 #3. Pythonの実装```python
import math

def p(k, n):
    """
    Probability that some chip receives at least 3 defects.
    """

    log_terms = []

    log_n_fact = math.lgamma(n + 1)
    log_k_fact = math.lgamma(k + 1)
    k_log_n = k * math.log(n)

    # Sum over number of double-occupied chips
    for a in range(k // 2 + 1):

        log_term = (
            log_n_fact
            + log_k_fact
            - math.lgamma(a + 1)
            - math.lgamma(k - 2 * a + 1)
            - math.lgamma(n - k + a + 1)
            - a * math.log(2)
            - k_log_n
        )

        log_terms.append(log_term)

    # Stable log-sum-exp
    m = max(log_terms)

    s = sum(math.exp(x - m) for x in log_terms)

    p_le_2 = math.exp(m) * s

    return 1.0 - p_le_2

# Example from problem statement
print(p(3, 7))

# Required value
ans = p(20000, 1000000)

print("{:.10f}".format(ans))
```---
