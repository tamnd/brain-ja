[プロジェクト オイラー問題 788](https://projecteuler.net/problem=788)

 ## 解決策

 **答え:**`471745499`長さを数値にしましょう$n$ある数字が厳密に次の値を超えて出現する場合は、_支配的_になります$n/2$回。 

計算しなければなりません$$D(2022)\pmod{1\,000\,000\,007}.$$重要なのは有効なものをカウントすることです$n$-数字の組み合わせ。 

---

 #1. 数学的分析

 固定長の場合$n$、定義:

 A(n)=\text{支配する# } n\text{-桁の数字}。 

それから$$D(N)=\sum_{n=1}^{N} A(n).$$したがって、私たちが必要とするのは、$A(n)$。 

---

 ## ステップ 1: 支配的な数字は一意です

 数値に 2 つの異なる桁があり、それぞれが 2 桁以上出現するとします。$n/2$回。 

その場合、合計桁数は次の値を超えます$n$、 不可能。 

したがって、すべての支配的な数字には、**固有**の支配的な数字があります。 

したがって、次のようにすることができます。 

1. 支配的な数字を選択します$d$、
 2. 出現回数を選択します。 
3. 残りの数字を配置します。 

---

 # ステップ 2: 数を数える$n$- 桁の数字、ここでの桁は$d$表示されます$k$回

 必要です$$k>\frac n2.$$以下のものを個別に扱う必要があります。 

-$d\neq 0$、
 -$d=0$、

 先頭のゼロは禁止されているためです。 

---

 # ケース A: 支配的な数字$d\neq 0$次のいずれかを選択してください$9$ゼロ以外の数字。 

仮定する$d$正確に表示されます$k$回。 

私たちは数えます$n$-数字の文字列:

 - 最初の桁がゼロ以外、
 - まさに$k$のコピー$d$、
 - 残りの数字は次のものを除きます。$d$。 

最初の桁が以下であるかどうかに応じて分割します。$d$。 

---

 ## A1. 最初の桁は$d$それから残りの中で$n-1$私たちが必要とするポジション:

 -$k-1$の追加コピー$d$、
 - もう一方$n-k$位置は次のいずれかになります$9$数字 (を除くすべて)$d$）。 

カウント：$$\binom{n-1}{k-1}9^{\,n-k}.$$---

 ## A2. 最初の桁はそうではありません$d$最初の桁:

 - ありえません$0$、
 - ありえません$d$、

 だからあります$8$選択肢。 

残っている中で$n-1$ポジション:

 - 選択します$k$のポジション$d$、
 - もう一方$n-1-k$ポジションは$9$それぞれの選択肢。 

カウント：$$8\binom{n-1}{k}9^{\,n-1-k}.$$---

 したがって、固定非ゼロの場合$d$、$$\binom{n-1}{k-1}9^{n-k} + 8\binom{n-1}{k}9^{n-1-k}.$$乗算する$9$の選択肢$d$:$$9\binom{n-1}{k-1}9^{n-k} + 72\binom{n-1}{k}9^{n-1-k}.$$---

 # ケース B: 支配的な数字$d=0$先頭の数字にゼロを使用することはできません。 

それで:

 - 最初の桁:$9$選択肢、
 - 残りの中で$n-1$ポジションを選択する$k$ゼロ、
 - 他のすべてのポジション:$9$選択肢。 

したがって：$$9\binom{n-1}{k}9^{n-1-k}.$$---

 # ステップ 3: 結合する

 固定の合計$n,k$:$$9\binom{n-1}{k-1}9^{n-k} + 81\binom{n-1}{k}9^{n-1-k}.$$パスカルを使用します。$$\binom{n}{k} = \binom{n-1}{k-1}+\binom{n-1}{k}.$$要素：$$9^{n-k+1} \left( \binom{n-1}{k-1}+\binom{n-1}{k} \right) = 9^{n-k+1}\binom{n}{k}.$$それで：$$A(n)= \sum_{k=\lfloor n/2\rfloor+1}^{n} \binom{n}{k}9^{n-k+1}.$$したがって$$D(N) = \sum_{n=1}^{N} \sum_{k=\lfloor n/2\rfloor+1}^{n} \binom{n}{k}9^{n-k+1}.$$モジュロを計算します$$M=1\,000\,000\,007.$$---

 #2. Pythonの実装```python
MOD = 1_000_000_007
N = 2022

# Precompute factorials and inverse factorials
fact = [1] * (N + 1)
for i in range(1, N + 1):
    fact[i] = fact[i - 1] * i % MOD

invfact = [1] * (N + 1)
invfact[N] = pow(fact[N], MOD - 2, MOD)

for i in range(N, 0, -1):
    invfact[i - 1] = invfact[i] * i % MOD

def C(n, r):
    if r < 0 or r > n:
        return 0
    return fact[n] * invfact[r] % MOD * invfact[n - r] % MOD

# powers of 9
pow9 = [1] * (N + 2)
for i in range(1, N + 2):
    pow9[i] = pow9[i - 1] * 9 % MOD

ans = 0

for n in range(1, N + 1):
    start = n // 2 + 1

    for k in range(start, n + 1):
        ans += C(n, k) * pow9[n - k + 1]
        ans %= MOD

print(ans)
```---
