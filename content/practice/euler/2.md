[プロジェクト オイラー問題 2](https://projecteuler.net/problem=2)

 ## 解決策

 以下の偶数フィボナッチ数の合計が必要です$4{,}000{,}000$。 

フィボナッチ数列は次のように始まります。$$1,2,3,5,8,13,21,34,\dots$$偶数値の項は次のとおりです。$$2,8,34,144,\dots$$直接的なアプローチは、最大でフィボナッチ数を生成することです。$4{,}000{,}000$そして偶数のものを積み上げます。 

Python コード:```python
a, b = 1, 2
total = 0

while a <= 4_000_000:
    if a % 2 == 0:
        total += a
    a, b = b, a + b

print(total)
```計算を追跡すると、偶数フィボナッチ項が得られます。$$2 + 8 + 34 + 144 + 610 + 2584 + 10946 + 46368 + 196418 + 832040 + 3524578$$それらの合計は次のとおりです。$$4613732$$**答え: 4613732**
