[プロジェクト オイラー問題 409](https://projecteuler.net/problem=409)

 ## 解決策

 **答え:**`253223948`させて$$q = 2^n.$$注文数を数えています$n$-タプル$$(x_1,x_2,\dots,x_n)$$次のような:

 - それぞれ$x_i\in\{1,2,\dots,q-1\}$、
- 全て$x_i$明確であり、
 - ポジションは nim で **勝利** です。つまり、$$x_1\oplus x_2\oplus \cdots \oplus x_n \ne 0.$$定義する：

-$A_k$: 順序付けられた個別の非ゼロの数$k$-タプル、
 -$L_k$: 順序付けられた個別の非ゼロの数$k$-xor を使用したタプル$0$、
 -$W_k=A_k-L_k$。 

最終的に必要なのは$W_n$のために$q=2^n$。 

---

 #1. 数学的分析

 ## タプルの総数

 順序付けられた個別の非ゼロの総数$k$-タプルは単純に$$A_k=(q-1)(q-2)\cdots(q-k)$$(下降階乗表記を使用$A_k=(q-1)_k$）。 

特に、$$A_n=(2^n-1)(2^n-2)\cdots(2^n-n).$$---

 # 負けポジションを数える

 ここで、次の漸化式を導出します。$L_k$。 

負けを考慮する$k$-タプル:$$x_1\oplus x_2\oplus\cdots\oplus x_k=0.$$次に、最後の要素が強制されます。$$x_k=x_1\oplus x_2\oplus\cdots\oplus x_{k-1}.$$したがって、順序付けられた個別の非ゼロから始めます$(k-1)$-tuple を実行し、強制された値がいつ有効であるかを尋ねます。 

がある$A_{k-1}$可能$(k-1)$-タプル。 

2 つの悪いケースを除外する必要があります。 

---

 ## 悪いケース 1: xor は$0$それから$x_k=0$、 禁断。 

これはまさに最初のときに起こります。$k-1$エントリはすでに XOR されています$0$。 

カウント：$$L_{k-1}.$$---

 ## 悪いケース 2: xor が既存のエントリと等しい

 仮定してください$$x_1\oplus\cdots\oplus x_{k-1}=x_i.$$その後、削除します$x_i$を残します$(k-2)$-xor が次のタプル$0$。 

逆に:

 - 負けを選ぶ$(k-2)$-タプル、
 - ポジションを選択してください$i$($k-1$選択肢）、
 - 選択します$x_i$まだ使用されていないゼロ以外の値にする必要があります。 

の$(k-2)$-タプルはすでに使用しています$k-2$明確なゼロ以外の値があるため、$$(q-1)-(k-2)=q-k+1$$～の選択肢$x_i$。 

したがって、悪いケース 2 のタプルの数は次のようになります。$$(k-1)(q-k+1)L_{k-2}.$$---

 # 再発

 したがって、次のようになります。$$\boxed{ L_k = A_{k-1} - L_{k-1} - (k-1)(q-k+1)L_{k-2} }$$初期条件あり$$L_0=1,\qquad L_1=0.$$ついに、$$W_n=A_n-L_n.$$この繰り返しは線形時間であり、十分に高速です。$n=10^7$。 

---

 #2. Pythonの実装```python
MOD = 1_000_000_007

def solve(n):
    q = pow(2, n, MOD)

    # n = 1 is trivial
    if n == 1:
        return 1

    # A1 = q - 1
    A_prev = (q - 1) % MOD

    # L0 = 1, L1 = 0
    L_prev2 = 1
    L_prev1 = 0

    # Build up to Ln
    for k in range(2, n + 1):

        # Recurrence:
        # Lk = A_{k-1}
        #      - L_{k-1}
        #      - (k-1)(q-k+1)L_{k-2}
        Lk = (
            A_prev
            - L_prev1
            - ((k - 1) * (q - k + 1) % MOD) * L_prev2
        ) % MOD

        # Update A_k from A_{k-1}
        A_curr = (A_prev * (q - k)) % MOD

        # Shift states
        A_prev = A_curr
        L_prev2, L_prev1 = L_prev1, Lk

    # Wn = An - Ln
    return (A_prev - L_prev1) % MOD

print(solve(5))      # 19764360
print(solve(100))    # 384777056
print(solve(10_000_000))
```---

 ## ステップ 2```python

```店舗$$A_1=q-1.$$---

 ## ステップ 3```python
L_prev2 = 1
L_prev1 = 0
```初期化:$$L_0=1,\qquad L_1=0.$$---

 ## ステップ 4

 ループ内:```python
Lk = (
    A_prev
    - L_prev1
    - ((k - 1) * (q - k + 1) % MOD) * L_prev2

```実装する$$L_k=A_{k-1}-L_{k-1}-(k-1)(q-k+1)L_{k-2}.$$---

 ## ステップ 5```python
A_curr = (A_prev * (q - k)) % MOD
```アップデート$$A_k=A_{k-1}(q-k).$$---

 ## ステップ 6

 最後に:```python
(A_prev - L_prev1) % MOD
```返品$$W_n=A_n-L_n.$$---
