[プロジェクト オイラー問題 668](https://projecteuler.net/problem=668)

 ## 解決策

 **答え:**`2811077773`させて$P(n)$の最大の素因数を示します$n$（と$P(1)$未定義ですが、$1$定義により平滑平方根と宣言されます)。 

数字$n$すべての素因数が厳密に次の値より小さい場合、平方根は滑らかです$\sqrt n$。 

同様に、$$P(n)<\sqrt n$$または$$P(n)^2<n.$$整数の数が必要です$n\le 10^{10}$これを満足させます。 

---

 #1. 数学的分析

 ## ステップ 1: 補体の特徴付け

 **平滑平方根ではない**数値を数える方が簡単です。 

数字$n>1$平方根は**滑らかではありません**$$P(n)\ge \sqrt n.$$書く$$n = pk,$$どこ$p=P(n)$が最大の素因数です。 

それから$$p \ge \sqrt n \quad\Longrightarrow\quad p^2 \ge n = pk \quad\Longrightarrow\quad p \ge k.$$したがって、すべての非滑らかな数値は固有の表現を持ちます。$$n = pk$$と：

-$p$プライム、
 -$k \le p$、
 -$pk \le x$。 

逆に、そのようなペアはすべて非滑らかな数値を生成します。$p$は主因数であり、$$p \ge k \;\Rightarrow\; p^2 \ge pk=n \;\Rightarrow\; p\ge \sqrt n.$$したがって、非滑らかな数値はペアで全単射になります。$$(p,k)$$そのような$$p \text{ prime},\qquad k\le p,\qquad pk\le x.$$---

 ## ステップ 2: 補数を数える

 修正$k$。 

それから$p$満たさなければなりません$$k \le p \le \frac{x}{k}.$$したがって、有効な素数の数は次のようになります。$$\pi\!\left(\frac{x}{k}\right)-\pi(k-1),$$どこ$\pi(n)$は素数カウント関数です。 

また、必然的に$k\le \sqrt x$、 さもないと$k^2>x$。 

したがって、非滑らかな整数の数は次のようになります。$$N(x) = \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right).$$したがって、必要なカウントは次のようになります。$$S(x)=x-N(x).$$それで：$$\boxed{ S(x) = x- \sum_{k\le \sqrt x} \left( \pi\!\left(\frac{x}{k}\right)-\pi(k-1) \right) }$$と$x=10^{10}$。 

---

 ## ステップ 3: 例を確認する$x=100$式を使用すると、次のようになります。$$N(100) = \sum_{k=1}^{10} \left( \pi(100/k)-\pi(k-1) \right) =71.$$したがって、$$S(100)=100-71=29,$$問題文と一致します。

 #2. Pythonの実装```python
from functools import lru_cache
from math import isqrt

# ------------------------------------------------------------
# Sieve for small primes
# ------------------------------------------------------------

LIMIT = 5_000_000

sieve = bytearray(b"\x01") * (LIMIT + 1)
sieve[0:2] = b"\x00\x00"

for i in range(2, isqrt(LIMIT) + 1):
    if sieve[i]:
        sieve[i * i : LIMIT + 1 : i] = b"\x00" * (
            ((LIMIT - i * i) // i) + 1
        )

primes = [i for i, v in enumerate(sieve) if v]

# pi_small[n] = number of primes <= n
pi_small = [0] * (LIMIT + 1)

count = 0
for i in range(LIMIT + 1):
    if sieve[i]:
        count += 1
    pi_small[i] = count

# ------------------------------------------------------------
# Lehmer prime counting function
# Computes pi(n) quickly for large n
# ------------------------------------------------------------

@lru_cache(None)
def phi(x, s):
    """Count integers <= x not divisible by first s primes."""
    if s == 0:
        return x
    return phi(x, s - 1) - phi(x // primes[s - 1], s - 1)

@lru_cache(None)
def pi(n):
    """Lehmer prime counting function."""
    if n <= LIMIT:
        return pi_small[n]

    a = pi(int(n ** 0.25))
    b = pi(isqrt(n))
    c = pi(int(n ** (1 / 3)))

    # Main Lehmer formula
    result = phi(n, a) + ((b + a - 2) * (b - a + 1)) // 2

    for i in range(a + 1, b + 1):
        p = primes[i - 1]
        w = n // p

        result -= pi(w)

        if i <= c:
            bi = pi(isqrt(w))

            for j in range(i, bi + 1):
                result -= pi(w // primes[j - 1]) - (j - 1)

    return result

# ------------------------------------------------------------
# Count square-root smooth numbers
# ------------------------------------------------------------

def square_root_smooth_count(x):
    root = isqrt(x)

    non_smooth = 0

    for k in range(1, root + 1):
        non_smooth += pi(x // k) - pi(k - 1)

    return x - non_smooth

# ------------------------------------------------------------
# Compute the Project Euler answer
# ------------------------------------------------------------

x = 10_000_000_000

answer = square_root_smooth_count(x)

print(answer)
```---
