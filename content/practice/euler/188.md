 # 数学的分析

 私たちが欲しいのは$$1777 \uparrow\uparrow 1855 \pmod{10^8}.$$させて$$T_n = 1777 \uparrow\uparrow n.$$それから$$T_{n+1} = 1777^{T_n}.$$だから必要なのです$$T_{1855} \bmod 10^8.$$---

 ## ステップ 1: オイラーの定理

 以来$$10^8 = 2^8 \cdot 5^8,$$そして$1777$と互いに素である$10^8$、オイラーの定理が適用されます。$$a^{\phi(m)} \equiv 1 \pmod m \quad\text{if}\quad \gcd(a,m)=1.$$したがって、指数は剰余で減らすことができます$\phi(m)$。 

のために$m=10^8$、$$\phi(10^8) =10^8\left(1-\frac12\right)\left(1-\frac15\right) =10^8\cdot \frac12\cdot \frac45 =40\,000\,000.$$したがって、$$1777^k \pmod{10^8}$$のみに依存する$$k \pmod{40\,000\,000}.$$しかし、指数自体は別のテトレーションなので、再帰的に考えます。 

---

 ## ステップ 2: 再帰的なモジュラー削減

 再帰関数を定義する$$f(h,m)=1777\uparrow\uparrow h \pmod m.$$それから$$f(1,m)=1777\bmod m,$$そしてのために$h>1$、$$f(h,m) = 1777^{\,f(h-1,\phi(m))} \pmod m.$$なぜこれが機能するのでしょうか?

 なぜなら、計算するとき、$$1777^E \pmod m,$$指数$E$モジュロのみが重要$\phi(m)$。 

したがって、巨大な指数を正確に計算する代わりに、それを法で計算します。$\phi(m)$、そして再び再帰します。 

チェーンは次のようになります。$$10^8 \to \phi(10^8)=40\,000\,000 \to \phi(40\,000\,000)=16\,000\,000 \to \cdots$$最終的には、係数が十分に小さくなり、再帰がすぐに安定します。 

---

 ## ステップ 3: 効率的なべき乗剰余演算

 Python は以下を提供します。```python
pow(base, exponent, modulus)
```対数時間で二乗を繰り返してモジュラーべき乗を効率的に計算します。 

したがって、各再帰層は高速です。 

---

 # Pythonの実装```python
from math import gcd

def phi(n):
    """Compute Euler's totient function."""
    result = n
    p = 2

    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1

    if n > 1:
        result -= result // n

    return result

def tetration_mod(a, height, mod):
    """
    Compute a ↑↑ height (tetration) modulo mod.
    """

    # Base case
    if mod == 1:
        return 0

    if height == 1:
        return a % mod

    # Recursively compute exponent modulo phi(mod)
    exponent = tetration_mod(a, height - 1, phi(mod))

    # Euler reduction
    return pow(a, exponent, mod)

answer = tetration_mod(1777, 1855, 10**8)

print(answer)
```---
