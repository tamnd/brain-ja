[プロジェクト オイラー問題 546](https://projecteuler.net/problem=546)

 ## 解決策

 **答え:**`215656873`させて$$f_k(n)=\sum_{i=0}^{n} f_k\!\left(\left\lfloor \frac{i}{k}\right\rfloor\right), \qquad f_k(0)=1.$$計算するように求められます$$\sum_{k=2}^{10} f_k(10^{14}) \pmod{10^9+7}.$$---

 ## 1. 数学的分析

 定義する$$F_k(x)=\sum_{n\ge 0} f_k(n)x^n.$$再発から、$$f_k(n)-f_k(n-1)=f_k\!\left(\left\lfloor \frac nk\right\rfloor\right) \quad (n\ge1).$$乗算$x^n$そして合計すると$$(1-x)F_k(x) = \sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n.$$サイズのブロックごとに項をグループ化します$k$:$$\sum_{n\ge0} f_k\!\left(\left\lfloor \frac nk\right\rfloor\right)x^n = (1+x+\cdots+x^{k-1})F_k(x^k).$$したがって、$$(1-x)F_k(x) = \frac{1-x^k}{1-x}F_k(x^k),$$それで$$F_k(x)=\frac{1-x^k}{(1-x)^2}F_k(x^k).$$反復収量$$F_k(x) = \frac1{(1-x)^2} \prod_{j\ge1}\frac1{1-x^{k^j}}.$$したがって$f_k(n)$累積です$k$-ary パーティション関数。 

分割統治の高速反復はブロック構造から得られます。 

もし$$n=km+r,\qquad 0\le r<k,$$それから$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$両方にメモ化された再帰を使用する$f_k(n)$そのプレフィックスの合計は、$O(\log n)$-深度アルゴリズム。

 ## 2. Python の実装```python
MOD = 10**9 + 7

from functools import lru_cache

def solve_k(k, N):

    @lru_cache(None)
    def F(n):
        # returns f_k(n) mod MOD
        if n == 0:
            return 1

        m, r = divmod(n, k)

        return (k * S(m - 1) + (r + 1) * F(m)) % MOD

    @lru_cache(None)
    def S(n):
        # prefix sum: sum_{i=0}^n F(i)
        if n < 0:
            return 0
        if n == 0:
            return 1

        m, r = divmod(n, k)

        # sum over complete blocks
        total = 0

        for t in range(m):
            base = (k * S(t - 1) + F(t)) % MOD
            block = (k * base + (k * (k - 1) // 2) * F(t)) % MOD
            total += block

        total %= MOD

        # partial block
        base = (k * S(m - 1) + F(m)) % MOD

        partial = (
            (r + 1) * base
            + (r * (r + 1) // 2) * F(m)
        ) % MOD

        return (total + partial) % MOD

    return F(N)

N = 10**14

ans = 0
for k in range(2, 11):
    ans = (ans + solve_k(k, N)) % MOD

print(ans)
```---

 ## 3. コードのチュートリアル

 ###`F(n)`計算します$f_k(n)$。 

もし$n=km+r$、$$f_k(n) = k\sum_{i=0}^{m-1} f_k(i) + (r+1)f_k(m).$$プレフィックスの合計は次によって提供されます。`S(m-1)`。 

---

 ###`S(n)`計算します$$S(n)=\sum_{i=0}^{n} f_k(i).$$間隔はサイズのブロックに分解されます$k$:$$[k t,\; kt+k-1].$$1ブロックの中に、$$f_k(kt+j)=A_t+jf_k(t),$$どこ$$A_t=kS(t-1)+f_k(t).$$これにより、各ブロックの合計が閉じた形式で計算可能になります。
