[プロジェクト オイラー問題 856](https://projecteuler.net/problem=856)

 ## 解決策

 **答え:**`17.09661501`させて$T$連続する 2 枚のカードが初めて同じランクになるまで、または山札がなくなるまでに引かれるカードの数です。 

私たちが欲しいのは$$\mathbb E[T].$$---

 #1. 重要な確率論的な考え方

 非負の整数値の確率変数の標準的な恒等式は次のとおりです。$$\mathbb E[T] = \sum_{n\ge0}\Pr(T>n).$$ここ、$T>n$意味:

 >最初のあと$n$引き分けの場合、連続するカードが同じランクを共有することはありません。 

デッキのカード枚数は52枚のみなので、$$\mathbb E[T] = \sum_{n=0}^{51} q_n,$$どこ$$q_n=\Pr(\text{no adjacent equal ranks among first }n\text{ cards}).$$明らかに、$$q_0=q_1=1.$$したがって、問題全体は確率の計算に帰着します。$q_n$。 

---

 #2. 状態の圧縮

 すべてのデッキオーダーを直接強引に支配することは不可能です。 

代わりに、次のことを観察します。 

いかなる時点においても、未来はただ、

 - 現在、0、1、2、3、4 枚のカードがすでに使用されているランクはいくつですか、
 - そして、_最後に描かれたランク_のカードが既に使用されている枚数。 

状態を定義する$$(c_0,c_1,c_2,c_3,c_4;\ell),$$どこ

-$c_i$= 正確にそのランクの数$i$カードが引かれました、
 -$\ell\in\{1,2,3,4\}$= 最後に引いたランクのカードが何枚使用されたか。 

最初に、カードを 1 枚引いた後、次のようになります。$$(12,1,0,0,0;1).$$---

 #3. 移行ルール

 私たちが州にいると仮定してください$$(c_0,c_1,c_2,c_3,c_4;\ell)$$後$n$描く。 

がある$52-n$残りのカード。 

ペアの作成を避けるために、次のカードは前のカードと同じランクを持つことはできません。 

現在使用されているランクを選択すると$j$回:

 - あります$4-j$そのランクのカードが残っており、
 -そして、あります$$c_j - \mathbf 1_{\{\ell=j\}}$$そのタイプの利用可能なランク (前のランク自体を除く)。 

したがって、遷移確率は次のようになります。$$\frac{ \left(c_j-\mathbf 1_{\{\ell=j\}}\right)(4-j) }{ 52-n }.$$このようなランクを選択した後:

 - クラスから 1 ランク移動します$j$クラスへ$j+1$、
 - 新しい最終ランク数は次のようになります。$j+1$。 

これにより、小さな DP 状態空間が与えられ、すべての値が計算されます。$q_n$その通り。 

---

 #4. Pythonの実装```python
from collections import defaultdict

# dist[state] = probability of being in that state
# after n draws with no adjacent equal ranks
#
# state = (c0, c1, c2, c3, c4, lastk)

dist = {
    (12, 1, 0, 0, 0, 1): 1.0
}

# q[n] = probability that first n draws contain no adjacent equal ranks
q = [1.0, 1.0]

# We already handled n = 1.
# Build q[2] ... q[51].
for draws in range(1, 51):

    next_dist = defaultdict(float)
    survive_prob = 0.0

    remaining = 52 - draws

    for state, prob in dist.items():

        c = list(state[:5])
        lastk = state[5]

        # Choose a new rank type j = 0,1,2,3
        for j in range(4):

            # Number of usable ranks with j used cards,
            # excluding the previous rank if necessary
            usable_ranks = c[j] - (1 if lastk == j else 0)

            if usable_ranks <= 0:
                continue

            ways = usable_ranks * (4 - j)

            p = prob * ways / remaining

            # Update occupancy counts
            nc = c.copy()
            nc[j] -= 1
            nc[j + 1] += 1

            new_state = tuple(nc + [j + 1])

            next_dist[new_state] += p
            survive_prob += p

    dist = next_dist
    q.append(survive_prob)

# Expected value
E = sum(q)

print("{:.12f}".format(E))
```---

 #5. コードのチュートリアル

 ### 初期化```python
dist = {(12,1,0,0,0,1): 1.0}
```最初のカードの後:

 - 12 ランクの使用カードは 0 枚、
 - 1ランクには使用済みカードが1枚あり、
 - 最終ランクには現在 1 枚の使用済みカードがあります。 

---

 ### メインループ```python
for draws in range(1, 51):
```ステップで`draws`、これだけ多くの描画を行った後のすべての安全な状態はすでにわかっています。 

もう 1 回安全に引き分けた後に分布を計算します。 

---

 ### 安全な選択肢を数える```python
usable_ranks = c[j] - (1 if lastk == j else 0)
```前のランクもクラスにある場合$j$、それを除外する必要があります。 

使用可能な各ランクが貢献します$4-j$残りのカード。 

---

 ### 状態の更新```python
nc[j] -= 1
nc[j + 1] += 1
```ランク$j$使用済みカードはランク付きになります$j+1$使用済みのカード。 

---

 ### 期待値```python
E = sum(q)
```使用して$$\mathbb E[T] = \sum_{n=0}^{51} q_n.$$---

 #6. 健全性チェック

 - 最初の 2 枚のカードがペアを形成する確率は$$\frac{3}{51}=\frac1{17},$$ステートメントと一致します。 

- 引き分けが確率と独立している場合$1/13$以前のランクと一致すると、期待値はおおよそ次のようになります。$13$。 

カードは_置き換えなしで_引かれるため、早い段階ではリピートの可能性が低くなり、実際の期待値は多少大きくなるはずです。 

取得値：$$17.09661501\ldots$$それはまったく合理的です。

 **答え: 17.09661501**
