[プロジェクト オイラー問題 456](https://projecteuler.net/problem=456)

 ## 解決策

 **答え:**`333333208685971546`ポイントを$$P_n=\{(x_k,y_k)\}_{k=1}^n,$$どこ$$x_k=(1248^k \bmod 32323)-16161,\qquad y_k=(8421^k \bmod 30103)-15051.$$これらの点によって形成され、厳密に内部に原点を含む三角形の数を数えなければなりません。 

---

 #1. 数学的分析

 古典的な幾何学的事実が鍵となります。 

> 3 つの点で形成される三角形$A,B,C$3 つの点が**原点を中心とする開いた半円にすべて含まれていない**場合、原点が含まれます。 

したがって、「良い」三角形を直接数えるのではなく、半円の内側に収まる「悪い」トリプルを数えます。 

---

 ## ステップ 1: 極角で並べ替える

 For each point$$p_i=(x_i,y_i),$$極角を計算します$$\theta_i=\operatorname{atan2}(y_i,x_i).$$すべての点を原点の周りの角度で並べ替えます。 

次に、角度順に円の周りを歩くことを想像してください。 

---

 ## ステップ 2: 半円内のトリプルを数える

 点を修正する$p_i$。 

させて$m_i$との角度差がある後の点の数になります。$p_i$厳密に以下です$\pi$。 

そして、それらの中のすべてのペア$m_i$ポイントは一緒に悪い三角形を形成します$p_i$3 つの頂点すべてが 1 つの開いた半円の内側にあるためです。 

したがって、不良三角形の数は、$p_i$は$$\binom{m_i}{2}.$$全体をまとめると$i$、$$\text{Bad}=\sum_i \binom{m_i}{2}.$$ついに、$$C(n)=\binom{n}{3}-\text{Bad}.$$---

 ## ステップ 3: 2 ポインタ スイープ

 点は角度ごとに周期的に並べ替えられるため、すべての点を計算できます。$m_i$回転ポインタを使用して線形時間で。 

それぞれについて$i$、アドバンスポインタ$j$一方、角度の差は$<\pi$。 

浮動小数点の角度減算を使用する代わりに、外積を使用します。 

ベクターの場合$a=(a_x,a_y)$そして$b=(b_x,b_y)$、$$a\times b = a_xb_y-a_yb_x.$$それから：

-$a\times b>0$からの CCW 角度を意味します$a$に$b$いる$(0,\pi)$、
 -$a\times b=0$そして$a\cdot b>0$同じ方向という意味ですが、
 - 反対方向 ($\pi$）は除きます。 

これにより、精度の問題が回避されます。 

全体の複雑さは次のとおりです。 

- ポイントの生成:$O(n)$、
 - 並べ替え:$O(n\log n)$、
 - スイープ:$O(n)$。 

これは十分に高速です$n=2{,}000{,}000$。

 #2. Pythonの実装```python
import math

def count_triangles(n):
    # Generate points
    x = 1
    y = 1
    pts = []

    for _ in range(n):
        x = (x * 1248) % 32323
        y = (y * 8421) % 30103
        pts.append((x - 16161, y - 15051))

    # Sort by polar angle
    pts.sort(key=lambda p: math.atan2(p[1], p[0]))

    # Duplicate list for circular sweep
    ext = pts + pts

    bad = 0
    j = 1

    for i in range(n):
        if j < i + 1:
            j = i + 1

        ax, ay = ext[i]

        # Advance while angular difference < pi
        while j < i + n:
            bx, by = ext[j]

            cross = ax * by - ay * bx
            dot   = ax * bx + ay * by

            # angle in [0, pi)
            if cross > 0 or (cross == 0 and dot > 0):
                j += 1
            else:
                break

        m = j - i - 1
        bad += m * (m - 1) // 2

    total = math.comb(n, 3)

    return total - bad

# Verification
print(count_triangles(8))      # 20
print(count_triangles(600))    # 8950634
print(count_triangles(40000))  # 2666610948988

# Final answer
print(count_triangles(2000000))
```---
