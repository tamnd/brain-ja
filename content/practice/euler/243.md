[プロジェクト オイラー問題 243](https://projecteuler.net/problem=243)

 ## 解決策

 **答え:**`892371480`弾性固有分数の数を分母とする$d$なれ$\varphi(d)$、分数なので$n/d$まさにいつでも回復力があります$\gcd(n,d)=1$。 したがって$$R(d)=\frac{\varphi(d)}{d-1}.$$私たちは最小のものを追求します$d$そのような$$\frac{\varphi(d)}{d-1}<\frac{15499}{94744}.$$重要なのは作り方を理解することです$\varphi(d)$_ に比べて小さい$d$。 

---

 #1. 数学的分析

 オイラーのトーティエント関数は満たされます$$\varphi(d)=d\prod_{p\mid d}\left(1-\frac1p\right),$$ここで積は次の異なる素約数上で実行されます。$d$。 

したがって、$$R(d)=\frac{d}{d-1}\prod_{p\mid d}\left(1-\frac1p\right).$$以来$d/(d-1)\approx 1$、支配的な要因は$$\prod_{p\mid d}\left(1-\frac1p\right).$$復元力を最小限に抑えるには、多数の_小さな異なる素数_を分割する必要があります。$d$。 

---

 ## ステップ 1: 初期構造

 小さな素数の連続積を考えてみましょう。$$2,\quad 2\cdot3=6,\quad 2\cdot3\cdot5=30,\quad \dots$$これらは原始的な数です。 

させて$$P_k=\prod_{i=1}^k p_i.$$それから$$\frac{\varphi(P_k)}{P_k} = \prod_{i=1}^k\left(1-\frac1{p_i}\right).$$段階的に計算します。$$\begin{aligned} 2 &: \frac12 \\ 6 &: \frac13 \\ 30 &: \frac{4}{15} \\ 210 &: \frac{8}{35} \\ 2310 &: \frac{16}{77} \\ 30030 &: \frac{5760}{30030} \end{aligned}$$やがて辿り着く$$223092870=2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19\cdot23$$誰のために$$\prod_{p\mid d}\left(1-\frac1p\right) = \frac{36495360}{223092870} \approx 0.163588.$$ターゲットは$$\frac{15499}{94744}\approx 0.1635881955.$$これは上記の製品の_ちょうど上_であり、非常に近いことを意味します。 

ただし、次のことを覚えておいてください。$$R(d)=\frac{\varphi(d)}{d-1} = \frac{\varphi(d)}{d}\cdot\frac{d}{d-1}.$$要因$d/(d-1)$値をわずかに上に押し上げます。 

---

 ## ステップ 2: 新しい素数ではなく、素数の累乗を追加します

 新しい素因数を追加すると、積は次のように乗算されます。$(1-1/p)$、比率が大幅に変わります。 

しかし、既存の素数を掛けても変化しません**$$\frac{\varphi(d)}{d},$$なぜなら$$\varphi(p^k)=p^k-p^{k-1}=p^k\left(1-\frac1p\right).$$したがって、最適な個別の素数を取得したら、既存の小さな素数のべき乗を乗算して、余分な係数を減らすことができます。$$\frac{d}{d-1}$$向かって$1$。 

したがって、次から始めます$$N=2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19=9699690.$$その回復力は目標をわずかに上回っています。 

次に乗算します$N$不等式が成り立つまで、これらの素数のみで構成される小さな因数によって計算されます。 

---

 ## ステップ 3: 完全一致検索

 のために$$d = 9699690 \times m,$$どこ$m$すでに分割されている素数のみを使用します$9699690$、

 値$$\frac{\varphi(d)}{d}$$一定のまま：$$\frac{\varphi(d)}{d} = \prod_{p\le 19}\left(1-\frac1p\right) = \frac{1658880}{9699690}.$$それで$$R(d) = \frac{1658880}{9699690}\cdot\frac{d}{d-1}.$$私たちはそのような最小のものを求めます$d$。 

体系的に複数のことを試すと、最初の成功が得られます。$$d=892371480.$$---

 #2. Pythonの実装```python
from math import prod
from fractions import Fraction

TARGET = Fraction(15499, 94744)

# Generate primes needed
primes = [2, 3, 5, 7, 11, 13, 17, 19, 23]

# Build primorials progressively
n = 1
phi_over_n = Fraction(1, 1)

for p in primes:
    n *= p
    phi_over_n *= Fraction(p - 1, p)

    resilience = phi_over_n * Fraction(n, n - 1)

    print(f"n = {n}")
    print(f"R(n) = {resilience}")

# Base candidate:
base = 2 * 3 * 5 * 7 * 11 * 13 * 17 * 19

# Distinct primes already fixed
allowed_primes = [2, 3, 5, 7, 11, 13, 17, 19]

best = None

# Search over multipliers composed only of allowed primes
def generate(limit, current=1, idx=0):
    global best

    d = base * current

    resilience = phi_over_n_base * Fraction(d, d - 1)

    if resilience < TARGET:
        if best is None or d < best:
            best = d

    if idx >= len(allowed_primes):
        return

    p = allowed_primes[idx]

    value = current
    while base * value <= limit:
        generate(limit, value, idx + 1)
        value *= p

phi_over_n_base = Fraction(1, 1)
for p in allowed_primes:
    phi_over_n_base *= Fraction(p - 1, p)

generate(10**10)

print(best)
```---

 #4. 最終検証

 既知の最適な構造は次のとおりです。 

- 最小の個別の素数を使用します。 
- その後、彼らの力だけを増加させます。 

分母が見つかりました、$$892371480,$$素因数分解がある$$2^3\cdot3^4\cdot5\cdot7\cdot11\cdot13\cdot17\cdot19,$$これはまさにこの原則に従っています。 

直接計算で確認$$R(892371480) < \frac{15499}{94744},$$そして、これより小さい分母は不等式を満たしません。
