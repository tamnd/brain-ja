[プロジェクト オイラー問題 873](https://projecteuler.net/problem=873)

 ## 解決策

 **答え:**`735131856`有効な単語を以下から形成しましょう$p$として、$q$Bさん、そして$r$C の条件:

 > すべての A は、少なくとも 2 つの C によってすべての B から分離されています。 

私たちが欲しいのは$$W(10^6,10^7,10^8)\pmod{1\,000\,000\,007}.$$## 1. 数学的分析

 ### ステップ 1: 問題を A/B の実行に絞り込む

 C を一時的に無視して、A と B の順序だけを見てください。 

A/B スケルトンが連続して実行されると仮定します。$$AAA\;BB\;A\;BBBB\;\cdots$$させて：

-$a$= A ランの数、
 -$b$= B ランの数。 

次に:

 - 合計実行数 =$a+b$、
 - A と B の間の遷移 =$a+b-1$。 

各遷移 (A→B または B→A) **少なくとも 2 つの C が含まれている必要があります**。そうしないと、一部の A と B が近づきすぎます。 

それで、もし$$k = a+b-1$$が遷移の数である場合、予約する必要があります$$2k$$C は必須の区切り文字です。 

残り$$r-2k$$C は自由に配布できます。$p+q+1$ギャップ（文字の前、文字の間、文字の後）。 

星と棒で表すと:$$\#\text{ways to place remaining C's} = \binom{(r-2k)+(p+q)}{p+q}.$$---

 ### ステップ 2: A/B スケルトンを数える

 あれば$a$Aランと$b$B が実行されると、次のようになります。 

- 分割$p$Aさんは夢中です$a$ポジティブブロック:$$\binom{p-1}{a-1}$$- スプリット$q$Bがハマる$b$ポジティブブロック:$$\binom{q-1}{b-1}$$実行は交互に行う必要があるため、次のことのみを行ってください。$$|a-b|\le 1$$可能です。 

また:

 - もし$a=b$、開始方法は 2 つあります (A または B)。 
- それ以外の場合は 1 のみ。 

したがって:$$W(p,q,r) = \sum_{\substack{a,b\ge 1\\|a-b|\le 1}} c(a,b) \binom{p-1}{a-1} \binom{q-1}{b-1} \binom{r-2(a+b-1)+p+q}{p+q}$$どこ$$c(a,b)= \begin{cases} 2 & a=b\\ 1 & |a-b|=1 \end{cases}$$---

 ### ステップ 3: 例と照らし合わせて確認する

 この式は次のようになります。$$W(2,2,4)=32$$そして$$W(4,4,44)=13908607644,$$問題文と一致します。

 ## 2. Python の実装```python
MOD = 1_000_000_007

def W(p, q, r):
    n = p + q
    M = n + r

    # We only need inverses in the range [M - 4p - 5, M]
    low = M - 4 * p - 5
    size = M - low + 1

    # Batch inversion for a contiguous interval using one modular inverse
    prefix = [1] * size
    prod = 1

    for i in range(size):
        x = low + i
        prod = (prod * x) % MOD
        prefix[i] = prod

    inv_total = pow(prod, MOD - 2, MOD)

    inv_high = [0] * size
    for i in range(size - 1, -1, -1):
        x = low + i
        before = prefix[i - 1] if i > 0 else 1
        inv_high[i] = (inv_total * before) % MOD
        inv_total = (inv_total * x) % MOD

    def inv_big(x):
        return inv_high[x - low]

    # Small inverses up to n
    inv = [0] * (n + 1)
    inv[1] = 1
    for i in range(2, n + 1):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # Initial binomial:
    # C(r+n, n)
    T = 1
    for i in range(1, n + 1):
        T = T * (r + i) % MOD
        T = T * inv[i] % MOD

    ans = 0

    # A0 = C(p-1, m-1)
    # B0 = C(q-1, m-1)
    A0 = 1
    B0 = 1

    k = 0
    Tcur = T

    for m in range(1, p + 1):

        # Move to k = 2m - 1
        while k < 2 * m - 1:
            N = M - 2 * k
            Tcur = (
                Tcur
                * (N - n)
                * (N - n - 1)
                % MOD
                * inv_big(N)
                % MOD
                * inv_big(N - 1)
                % MOD
            )
            k += 1

        # Case a = b = m
        ans = (ans + 2 * A0 * B0 * Tcur) % MOD

        # Next binomial coefficients
        A1 = A0 * (p - m) % MOD * inv[m] % MOD if m < p else 0
        B1 = B0 * (q - m) % MOD * inv[m] % MOD if m < q else 0

        # Move to k = 2m
        if k < 2 * m:
            N = M - 2 * k
            Tcur = (
                Tcur
                * (N - n)
                * (N - n - 1)
                % MOD
                * inv_big(N)
                % MOD
                * inv_big(N - 1)
                % MOD
            )
            k += 1

        # Cases (m+1, m) and (m, m+1)
        ans = (
            ans
            + (A1 * B0 + A0 * B1) % MOD * Tcur
        ) % MOD

        A0, B0 = A1, B1

    return ans

print(W(10**6, 10**7, 10**8))
```---

 ## 3. コードのチュートリアル

 - 可能な実行回数を繰り返します。$a,b$。 
- 以来$|a-b|\le1$、 のみ$O(p)$ケースが存在します。 
- 実行パーティションの二項係数は乗算的に更新されます。$$\binom{n}{k+1} = \binom{n}{k} \frac{n-k}{k+1}$$- 大きな星と棒の用語$$\binom{r-2k+p+q}{p+q}$$また、以下を使用して段階的に更新されます。$$\binom{N-2}{n} = \binom{N}{n} \frac{(N-n)(N-n-1)}{N(N-1)}$$これにより、巨大な階乗表が回避されます。 

テスト:

 -$W(2,2,4)=32$✓
 -$W(4,4,44)=13908607644$✓
