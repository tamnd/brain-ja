 ## 解決策

 **答え:**`271204031455541309`サークルを通しましょう$(0,0),(N,0),(0,N),(N,N)$分析される。 

その中心は$(N/2,N/2)$、半径は$N/\sqrt2$。 したがって、方程式は次のようになります。$$\left(x-\frac N2\right)^2+\left(y-\frac N2\right)^2=\frac{N^2}{2}.$$乗算$4$、$$(2x-N)^2+(2y-N)^2=2N^2.$$定義する$$X=2x-N,\qquad Y=2y-N.$$次に、円上の整数格子点は、次の整数解に全単射的に対応します。$$X^2+Y^2=2N^2.$$したがって、$$f(N)=r_2(2N^2),$$どこ$r_2(m)$は次の表現の数です$m$2 つの平方の和として。 

古典的な定理を使用すると、次のようになります。 

もし$$m = 2^a \prod p_i^{\alpha_i}\prod q_j^{2\beta_j}$$どこ$p_i\equiv1\pmod4$そして$q_j\equiv3\pmod4$、 それから$$r_2(m)=4\prod (\alpha_i+1).$$以来$$2N^2$$因数を除いて偶数の指数のみを持ちます$2$、 毎$3\bmod4$素数は自動的に偶数の指数を持つため、$$f(N)=4\prod_{p\equiv1(4)}(2e_p+1),$$どこ$e_p$の指数です$p$で$N$。 

必要です$$f(N)=420.$$したがって$$\prod (2e_p+1)=105=3\cdot5\cdot7.$$唯一の指数パターンは次のとおりです。$$[52],\ [17,1],\ [10,2],\ [7,3],\ [3,2,1]$$(順列まで)。 

任意の素数$\equiv 3 \pmod 4$(そしてプライム$2$) は変更せずに任意の指数で表示される可能性があります$f(N)$。 

効率的なアルゴリズムは次のとおりです。 

1. 生成するすべての指数パターンを列挙します。$105$。 
2. それらを個別の素数に割り当てます$p\equiv1\pmod4$。 
3. 必要なベースを形成します$B$。 
4. のみで構成される任意の数値を掛けます。$2$と素数$3\bmod4$、 提供された$Bk\le10^{11}$。 
5. これらをすべて合計します$N$。 

正しい Python 実装は次のとおりです。```python
from bisect import bisect_right
from itertools import permutations
from math import isqrt

LIMIT = 10**11

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(n) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False

    return [i for i, ok in enumerate(is_prime) if ok]

# Generate primes
primes = sieve(10**6)

# p ≡ 1 mod 4 primes
p1 = [p for p in primes if p % 4 == 1]

# Allowed "neutral" primes:
# 2 and primes ≡ 3 mod 4
neutral = [2] + [p for p in primes if p % 4 == 3]

# Exponent patterns giving product 105
patterns = [
    [52],
    [17, 1],
    [10, 2],
    [7, 3],
    [3, 2, 1]
]

# Smallest base comes from [3,2,1]
min_base = 5**3 * 13**2 * 17
max_k = LIMIT // min_base

# Generate all numbers composed only of neutral primes
vals = []

def generate_neutral(start, current):
    vals.append(current)

    for i in range(start, len(neutral)):
        p = neutral[i]

        if current > max_k // p:
            break

        x = current * p

        while x <= max_k:
            generate_neutral(i + 1, x)

            if x > max_k // p:
                break

            x *= p

generate_neutral(0, 1)

vals = sorted(set(vals))

# Prefix sums for fast range summation
prefix = [0]
for v in vals:
    prefix.append(prefix[-1] + v)

def neutral_sum(limit):
    idx = bisect_right(vals, limit)
    return prefix[idx]

answer = 0

for pattern in patterns:
    # Distinct permutations of exponent assignments
    for exponents in set(permutations(pattern)):

        def recurse(i, start, base):
            global answer

            if i == len(exponents):
                answer += base * neutral_sum(LIMIT // base)
                return

            e = exponents[i]

            for j in range(start, len(p1)):
                p = p1[j]

                new_base = base * (p ** e)

                if new_base > LIMIT:
                    break

                recurse(i + 1, j + 1, new_base)

        recurse(0, 0, 1)

print(answer)
