[プロジェクト オイラー問題 779](https://projecteuler.net/problem=779)

 ## 解決策

 **答え:**`0.547326103833`させて$$f_K(n)=\frac{\alpha(n)-1}{p(n)^K},$$どこ$p(n)$の最小の素約数です$n$、 そして$\alpha(n)$の指数です$p(n)$で$n$。 

私たちは求めています$$S:=\sum_{K=1}^{\infty}\overline{f_K}, \qquad \overline{f_K} = \lim_{N\to\infty}\frac1N\sum_{n=2}^N f_K(n).$$---

 # ステップ 1: 指定された整数の密度$p(n)$そして$\alpha(n)$素数を修正する$p$と整数$a\ge1$。 

整数$n$と

-$p(n)=p$、
 -$\alpha(n)=a$、

 まさに次の形式のものです$$n=p^a m,$$どこ：

-$m$で割り切れない$p$、
 - プライムなし$q<p$分割する$m$。 

したがって、自然密度は次のようになります。$$\left(\frac1{p^a}-\frac1{p^{a+1}}\right) \prod_{q<p}\left(1-\frac1q\right).$$したがって、$$\overline{f_K} = \sum_p \sum_{a\ge1} \frac{a-1}{p^K} \left(\frac1{p^a}-\frac1{p^{a+1}}\right) \prod_{q<p}\left(1-\frac1q\right).$$項を独立して因数分解します$a$:$$\overline{f_K} = \sum_p \frac{p-1}{p^{K+1}} \prod_{q<p}\left(1-\frac1q\right) \sum_{a\ge1}\frac{a-1}{p^a}.$$今すぐ計算してください$$\sum_{a\ge1}(a-1)x^a = \frac{x^2}{(1-x)^2},$$と$x=1/p$:$$\sum_{a\ge1}\frac{a-1}{p^a} = \frac{1}{(p-1)^2}.$$それで$$\overline{f_K} = \sum_p \frac1{p^K\,p(p-1)} \prod_{q<p}\left(1-\frac1q\right).$$---

 # ステップ 2: 合計$K$今$$S = \sum_{K\ge1}\overline{f_K} = \sum_p \frac1{p(p-1)} \prod_{q<p}\left(1-\frac1q\right) \sum_{K\ge1}\frac1{p^K}.$$以来$$\sum_{K\ge1}\frac1{p^K} = \frac1{p-1},$$私たちは得る$$S = \sum_p \frac1{p(p-1)^2} \prod_{q<p}\left(1-\frac1q\right).$$使用する$$\prod_{q\le p}\left(1-\frac1q\right) = \left(1-\frac1p\right) \prod_{q<p}\left(1-\frac1q\right),$$これを単純化すると、$$S = \sum_p \frac1{p^2} \prod_{q<p}\left(1-\frac1q\right).$$これは急速に収束します。 

---

 # Pythonの実装```python
from sympy import primerange
from decimal import Decimal, getcontext

# high precision
getcontext().prec = 40

LIMIT = 20_000_000

prod_term = Decimal(1)
S = Decimal(0)

for p in primerange(2, LIMIT + 1):
    pD = Decimal(p)

    # add current term
    S += prod_term / (pD * pD)

    # update Euler product
    prod_term *= (Decimal(1) - Decimal(1) / pD)

print(S)
```---

 # コードのチュートリアル

 -`prod_term`店$$\prod_{q<p}\left(1-\frac1q\right).$$- 素数ごとに$p$、追加します$$\frac1{p^2} \prod_{q<p}\left(1-\frac1q\right).$$- 次に、次の値を乗算して積を更新します。$$1-\frac1p.$$項が漸近的に近似するため、級数は非常に早く収束します。$$\frac{e^{-\gamma}}{p^2\log p}.$$---
