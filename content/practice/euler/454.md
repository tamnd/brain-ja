[プロジェクト オイラー問題 454](https://projecteuler.net/problem=454)

 ## 解決策

 **答え:**`5435004633092`させて$$\frac1x+\frac1y=\frac1n, \qquad x<y\le L,$$と$x,y,n\in \mathbb Z_{>0}$。 

私たちが欲しいのは$F(L)$、そのようなペアの数$(x,y)$。 

---

 #1. 数学的分析

 から開始$$\frac1x+\frac1y=\frac1n.$$を乗算する$xyn$、$$n(x+y)=xy.$$## ステップ 1: gcd を抽出する

 しましょう$$x=gu,\qquad y=gv,$$と$$\gcd(u,v)=1,\qquad u<v.$$代わりの：$$n(g u + g v)=g^2uv.$$で割る$g$:$$n(u+v)=g uv.$$なぜなら$\gcd(u,v)=1$、$$\gcd(u,u+v)=\gcd(v,u+v)=1.$$したがって、$u\mid n$そして$v\mid n$。 以来$u,v$互いに素であり、$$uv\mid n.$$だから書いてください$$n=tuv$$何らかの正の整数の場合$t$。 

元に戻す:$$tuv(u+v)=g uv.$$キャンセル$uv$:$$g=t(u+v).$$したがって、すべての解決策は次の形式になります。$$x=t\,u(u+v),$$

$$y=t\,v(u+v),$$と$$u<v,\qquad \gcd(u,v)=1.$$逆に、このようなトリプルはすべて機能します。 

したがって、ソリューションを数えるということは、数えるということに帰着します。$$t\,v(u+v)\le L.$$固定共素の場合$u<v$、$$t \le \frac{L}{v(u+v)}.$$したがって、$$F(L)= \sum_{\substack{u<v\\ \gcd(u,v)=1}} \left\lfloor \frac{L}{v(u+v)} \right\rfloor.$$---

 #2. メビウスの反転

 紹介する$s=u+v$。 それから$v<s<2v$、 そして$$\gcd(v,s)=1.$$それで$$F(L) = \sum_{v=1}^{\sqrt L} \sum_{\substack{v<s<2v\\ \gcd(v,s)=1}} \left\lfloor \frac{L}{vs}\right\rfloor.$$標準の ID を使用する$$[\gcd(v,s)=1] = \sum_{d\mid \gcd(v,s)} \mu(d),$$どこ$\mu$はメビウス関数です。 

これにより、共素条件が除数の和に変換され、調和除算技術を使用して内部和を約 1 回で評価できるようになります。$O(L^{3/4})$、これは十分に高速です$L=10^{12}$。

 #3. Pythonの実装```python
import math

# ------------------------------------------------------------
# Mobius sieve
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

# ------------------------------------------------------------
# Fast computation of
#    sum_{k=a}^{b} floor(n / k)
# ------------------------------------------------------------

def floor_sum_range(n, a, b):
    if a > b:
        return 0

    s = 0
    k = a

    while k <= b:
        q = n // k
        r = min(b, n // q)
        s += q * (r - k + 1)
        k = r + 1

    return s

# ------------------------------------------------------------
# Main function
# ------------------------------------------------------------

def F(L):
    root = int(math.isqrt(L))

    mu = mobius_sieve(root)

    ans = 0

    for v in range(2, root + 1):

        # divisors of v
        divisors = []

        d = 1
        while d * d <= v:
            if v % d == 0:
                divisors.append(d)
                if d * d != v:
                    divisors.append(v // d)
            d += 1

        for d in divisors:
            if mu[d] == 0:
                continue

            vv = v // d

            left = vv + 1
            right = (2 * v - 1) // d

            n = L // (v * d)

            contribution = floor_sum_range(n, left, right)

            ans += mu[d] * contribution

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(F(15))      # 4
print(F(1000))    # 1069

# Final answer
print(F(10**12))
```---

 #4. コードのチュートリアル

 ##`mobius_sieve`メビウス関数を計算します$\mu(n)$みんなのために$n\le \sqrt L$。 

想起：

-$\mu(n)=0$もし$n$二乗素因数が含まれており、
 - それ以外の場合$\mu(n)=(-1)^k$、 どこ$k$は個別の素因数の数です。 

これはメビウス反転に必要です。 

---

 ##`floor_sum_range`効率的に計算する$$\sum_{k=a}^{b} \left\lfloor \frac{n}{k}\right\rfloor.$$商が変わるだけ$O(\sqrt n)$倍になるため、間隔を等しい商でグループ化します。 

---

 ## メインループ

 それぞれについて$v$:

 - 約数を列挙する$d\mid v$、
 - メビウス反転を適用し、
 - 高調波フロア合計を評価します。 
- 寄付を蓄積します。 

これにより、すべての共素ペアを直接反復処理することが回避されます。
