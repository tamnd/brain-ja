[プロジェクト オイラー問題 874](https://projecteuler.net/problem=874)

 ## 解決策

 **答え:**`4992775389`させて$$p(t)=\text{the }(t+1)\text{th prime},$$それで$$p(0)=2,\quad p(1)=3,\quad \dots$$計算しなければなりません$$M(7000,p(7000)).$$---

 #1. 数学的分析

 私たちには次のものが与えられます:

 -$k=7000$、
 -$n=p(7000)$。 

以来$p(t)$です$(t+1)$-番目の素数、$$n=p(7000)=\text{7001st prime}=70663.$$また、$$p(6999)=70657.$$私たちは最大限の価値を追求します。$$\sum_{i=1}^n p(a_i)$$対象となるもの:

 -$0\le a_i<7000$、
 -$\sum a_i\equiv 0\pmod{7000}$。 

---

 ## ステップ 1: 明らかな最大値から開始する

 可算条件がなければ、最良の選択は次のとおりです。$$a_i=6999 \quad \forall i,$$スコアを与える$$70663\cdot 70657.$$しかしその後$$\sum a_i = 70663\cdot 6999.$$以来$6999\equiv -1\pmod{7000}$、$$70663\cdot 6999 \equiv -70663 \equiv 6337 \pmod{7000}.$$したがって、次の条件に一致する量だけ合計を減らさなければなりません。$6337\pmod{7000}$。 

---

 # ステップ 2: 最小化問題に変換する

 赤字の定義$$d_i = 6999-a_i.$$それから$d_i\ge 0$、 そして$$\sum d_i \equiv 6337 \pmod{7000}.$$スコアはこうなります$$\sum p(a_i) = n\,p(6999)-\sum \bigl(p(6999)-p(6999-d_i)\bigr).$$ペナルティ関数を定義する$$f(d)=p(6999)-p(6999-d).$$この場合、スコアを最大化することは最小化することと同じです。$$\sum f(d_i)$$の対象となる$$\sum d_i \equiv 6337 \pmod{7000}.$$なぜなら、すべての素数ギャップは少なくとも$2$、$$f(d)\ge 2d.$$別のフルを追加する$7000$赤字にすれば少なくともペナルティは増える​​だろう$14000$したがって、最適な総赤字は許容可能な最小値となります。$$\sum d_i = 6337.$$したがって、必要なのは次のものだけです。 

> 最小化$\sum f(d_i)$の対象となる$\sum d_i=6337$。 

---

 # ステップ 3: 小さなペナルティを計算する

 上部付近の関連する素数は次のとおりです。$$\begin{aligned} p(6999)&=70657,\\ p(6998)&=70639,\\ p(6997)&=70627,\\ p(6996)&=70621,\\ p(6995)&=70619. \end{aligned}$$したがって、次のようになります。$$\begin{aligned} f(1)&=18,\\ f(2)&=30,\\ f(3)&=36,\\ f(4)&=38. \end{aligned}$$重要な所見は次のとおりです。$$\frac{f(4)}4=\frac{38}4=9.5$$は単位赤字あたりの最良の平均コストです。 

コンピューターによる全員チェック$1\le d<7000$ショー:$$f(d)\ge \frac{19d}{2},$$平等である場合にのみ$d$の倍数です$4$。 

以来$$6337\equiv 1\pmod 4,$$私たちだけでは使えません$4$'は。 
最高の残留物 -$1$オプションは$$f(9)=86,$$なぜなら$$86-\frac{19\cdot 9}{2}=0.5$$すべての中で最小限です$d\equiv 1\pmod 4$。 

したがって、最適な分解は次のようになります。$$6337 = 1582\cdot 4 + 9.$$合計ペナルティ:$$1582\cdot 38 + 86 = 60116+86 = 60202.$$---

 # ステップ 4: 最終スコア

 したがって、$$M = 70663\cdot 70657 - 60202.$$計算:$$70663\cdot 70657 = 4992835591.$$したがって、$$M = 4992835591 - 60202 = 4992775389.$$---

 #2. Pythonの実装```python
# Project Euler 874

def sieve(limit):
    """Return list of all primes <= limit."""
    is_prime = [True] * (limit + 1)
    is_prime[0] = is_prime[1] = False

    p = 2
    while p * p <= limit:
        if is_prime[p]:
            for x in range(p * p, limit + 1, p):
                is_prime[x] = False
        p += 1

    return [i for i, v in enumerate(is_prime) if v]

# We need primes up to around the 7001st prime (~70663)
primes = sieve(80000)

# p(t) = (t+1)th prime
def p(t):
    return primes[t]

k = 7000
n = p(7000)       # 7001st prime
top = p(6999)     # largest allowed prime score term

# Required deficit
D = (-n) % k

# Penalty function
# f(d) = p(6999) - p(6999-d)
f = [0] * (k)

for d in range(1, k):
    f[d] = top - p(6999 - d)

# Unbounded knapsack DP:
# dp[s] = minimum penalty to obtain total deficit s
INF = 10**18
dp = [INF] * (D + 1)
dp[0] = 0

for s in range(1, D + 1):
    best = INF
    for d in range(1, s + 1):
        best = min(best, dp[s - d] + f[d])
    dp[s] = best

penalty = dp[D]

answer = n * top - penalty

print(answer)
```---
