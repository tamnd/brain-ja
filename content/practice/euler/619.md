[プロジェクト オイラー問題 619](https://projecteuler.net/problem=619)

 ## 解決策

 **答え:**`857810883`させて$$S=\{a,a+1,\dots,b\}$$そして各整数に対して$n$、その素因数分解を次のように書きます$$n=\prod p_i^{e_i}.$$数値の積は、積全体のすべての素指数が偶数であれば完全二乗になります。 

次の **平方自由パリティ ベクトル** を定義します。$n$以上$\mathbb F_2$:$$v(n)=(e_i \bmod 2).$$次にサブセットについて$T\subseteq S$、$$\prod_{x\in T} x \text{ is a square} \iff \sum_{x\in T} v(x)=0 \quad (\text{over }\mathbb F_2).$$したがって、問題は次のようになります。 

> ベクトルの合計が 0 になる空でないサブセットをカウントします。 

---

 #1. 線形代数の定式化

 あると仮定します$$N=b-a+1$$数値の合計とベクトル$v(x)$ランクのベクトル空間にまたがる$r$。 

地図$$\phi:\mathbb F_2^N \to \mathbb F_2^m$$サブセット インジケーター ベクトルをパリティ合計に送信するにはカーネル サイズがあります$$2^{N-r}.$$These are exactly the subsets whose product is a square, including the empty subset.

 したがって$$C(a,b)=2^{N-r}-1.$$したがって、問題全体はランクの計算に帰着します。$r$以上$\mathbb F_2$。 

---

 #2. ベクトルの計算

 それぞれの番号について$n$:

 - factor it,
 - 奇数の指数を持つ素数のみを保持します。 
- その素数のセットがパリティ ベクトルです。 

例：$$72=2^3\cdot 3^2$$パリティベクトルあり$$\{2\}$$の指数だけなので、$2$奇数です。 

---

 #3. スパースガウス消去法終了$\mathbb F_2$各ベクトルはスパース (奇数の素因数がほとんどない) なので、素数のセットとして保存します。 

ガウス消去法:

 - ベクトル内の最大の素数をピボットとして選択します。 
- 既存の基底ベクトルに対して削除します。 
- ゼロ以外が残っている場合は、基底に挿入します。 

これによりランクが効率的に計算されます。 

---

 #4. Pythonの実装```python
from math import isqrt

MOD = 1_000_000_007

def compute_C(a, b):
    N = b - a + 1

    # ------------------------------------------------------------
    # Smallest prime factor sieve
    # ------------------------------------------------------------
    spf = list(range(b + 1))

    for p in range(2, isqrt(b) + 1):
        if spf[p] == p:  # p is prime
            for x in range(p * p, b + 1, p):
                if spf[x] == x:
                    spf[x] = p

    # ------------------------------------------------------------
    # Sparse Gaussian elimination over F2
    # basis[pivot_prime] = set representing basis vector
    # ------------------------------------------------------------
    basis = {}
    rank = 0

    for value in range(a, b + 1):

        n = value
        vec = set()

        # Build squarefree parity vector
        while n > 1:
            p = spf[n]
            parity = 0

            while n % p == 0:
                n //= p
                parity ^= 1

            if parity:
                vec.symmetric_difference_update({p})

        # Eliminate using existing basis
        while vec:
            pivot = max(vec)

            if pivot in basis:
                vec ^= basis[pivot]
            else:
                basis[pivot] = vec
                rank += 1
                break

    # Number of square-product subsets
    return (pow(2, N - rank, MOD) - 1) % MOD

# ------------------------------------------------------------
# Checks from the problem statement
# ------------------------------------------------------------
print(compute_C(40, 55))       # 15
print(compute_C(1000, 1234))   # 975523611

# ------------------------------------------------------------
# Required answer
# ------------------------------------------------------------
print(compute_C(1_000_000, 1_234_567))
```---

 #5. コードのチュートリアル

 ### SPFふるい```python
spf = list(range(b + 1))
```最初はすべての数値が素数であると仮定します。 

それから：```python
if spf[x] == x:
    spf[x] = p
```すべての合成数の最小の素因数を格納します。 

これにより素早い因数分解が可能になります。 

---

 ### パリティ ベクトルの構築

 各番号について:```python
while n % p == 0:
    n //= p
    parity ^= 1
```指数パリティのみを追跡します。 

パリティが奇数の場合、素数はベクトルに属します。 

---

 ### ガウス消去法

 各ベクトルは既存のピボットに対して削減されます。```python
vec ^= basis[pivot]
```追加が終わったので$\mathbb F_2$は XOR / 対称差です。 

ゼロ以外のベクトルが残っている場合、それは新しい独立次元に寄与します。

 #6. 与えられた例の検証
