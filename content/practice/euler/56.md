[プロジェクト オイラー問題 56](https://projecteuler.net/problem=56)

 ## 解決策

 **答え:**`972`次の形式の数値の桁の合計の最大値を求めます。$$a^b, \qquad a,b<100.$$つまり、すべての整数累乗を調べなければなりません$a^b$と$1 \le a \le 99$そして$1 \le b \le 99$、各値の桁の合計を計算し、最大値を見つけます。 

---

 # 数学的分析

 桁合計関数は次のとおりです。$$s(n)=\text{sum of the decimal digits of } n.$$例えば：$$2^{15}=32768,$$それで$$s(2^{15}) = 3+2+7+6+8 = 26.$$問題が求めているのは、$$\max_{1\le a,b<100} s(a^b).$$10 進数で桁上げすると桁の動作が非常に不規則になるため、最大桁合計を求める単純な閉じた形式の公式はありません。 ただし、いくつかの観察が役に立ちます。 

---

 ## 1. サイズの増加

 の桁数$a^b$およそです$$\lfloor b\log_{10}(a)\rfloor + 1.$$大きい$a$そして大きい$b$より多くの桁が生成される傾向があるため、桁の合計が大きくなる可能性があります。 

可能な最大桁合計は$d$-桁の数字は$9d$、大きい数が好まれます。 

例えば：$$99^{99}$$およそ$$99\log_{10}(99)\approx 197.56$$したがって、理論上の最大桁合計はおおよそ次のようになります。$$9\times198 = 1782.$$数字がすべてではないため、実際の答えはさらに小さくなります。$9$さんの。 

---

 ## 2. ブルートフォースは実行可能です

 あるのは$$99\times99 = 9801$$ペア$(a,b)$。 

最新の任意精度の整数は、これらの値を即座に計算できます。 

アルゴリズム:

 1. ループスルー$a=1,\dots,99$2. ループスルー$b=1,\dots,99$3. コンピューティング$n=a^b$4. 桁の合計を計算します。$$s(n)=\sum \text{digits of } n$$5. 最大値を追跡します。 

これは計算的には簡単です。 

---

 # Pythonの実装```python
# Project Euler Problem 56
# Maximum digital sum of a^b for a,b < 100

def digit_sum(n):
    """Return the sum of the decimal digits of n."""
    return sum(int(d) for d in str(n))

max_sum = 0
best_pair = None

# Check all powers a^b with 1 <= a,b < 100
for a in range(1, 100):
    for b in range(1, 100):
        value = a ** b
        s = digit_sum(value)

        # Update maximum if necessary
        if s > max_sum:
            max_sum = s
            best_pair = (a, b)

print("Maximum digital sum:", max_sum)
print("Produced by:", best_pair)
```---
