[プロジェクト オイラー問題 382](https://projecteuler.net/problem=382)

 ## 解決策

 **答え:**`697003956`させて$$s_1=1,\qquad s_2=2,\qquad s_3=3,\qquad s_n=s_{n-1}+s_{n-3}\ (n>3).$$サブセットの場合$A\subseteq U_n=\{s_1,\dots,s_n\}$、ますますソートされ、ポリゴンの状態は正確に$$\max(A)<\sum_{x\in A\setminus\{\max(A)\}}x.$$ずっと$s_i$それぞれが個別で増加しており、すべてのサブセットには固有の最大要素があります。 

---

 #1. 数学的分析

 定義:$$g(n)=\#\{\text{subsets of }U_{n-1}\text{ with sum }\le s_n\}.$$のサブセットの場合、$U_n$最大の要素を持つ$s_n$、残りの選択された要素の合計があればポリゴンを生成します。$>s_n$。 

がある$2^{n-1}$最大の要素が次のようなサブセット$s_n$したがって、$$f(n)=\sum_{k=1}^n \left(2^{k-1}-g(k)\right).$$したがって、問題はコンピューティングに帰着します$g(k)$。 

---

 ## 最初の値を計算する

 シーケンスが始まります$$1,2,3,4,6,9,13,19,28,41,\dots$$結果のポリゴン数は次のようになります。$$\begin{aligned} f(1)&=0\\ f(2)&=0\\ f(3)&=0\\ f(4)&=2\\ f(5)&=7\\ f(6)&=19\\ f(7)&=47\\ f(8)&=108\\ f(9)&=236\\ f(10)&=501. \end{aligned}$$ステートメントと一致します。 

---

 ## 重要な構造的事実

 なぜなら$s_n=s_{n-1}+s_{n-3}$、カウントシーケンス$f(n)$最終的には線形再帰的になります (C 有限シーケンスに対するサブセットカウント問題の標準的な結果)。 

最初のいくつかの正確な値と Berlekamp-Massey を使用すると、最小の再発が得られます。$$\boxed{ f(n)= 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5) +2f(n-7)-5f(n-8)+2f(n-9) }$$のために$n\ge 10$。 

特徴的な多項式因数は次のようになります。$$(x-2)(x-1)^2(x^3-x-1)(x^3+x-1).$$それで計算できます$f(10^{18})$モジュロ$10^9$高速な線形再帰累乗を使用する$O(r^2\log n)$と$r=9$。

 #2. Pythonの実装```python
MOD = 10**9

# Initial values f(1)..f(9)
init = [
    0,   # f(1)
    0,   # f(2)
    0,   # f(3)
    2,   # f(4)
    7,   # f(5)
    19,  # f(6)
    47,  # f(7)
    108, # f(8)
    236  # f(9)
]

# Recurrence:
# f(n) =
# 4f(n-1)-5f(n-2)+4f(n-3)-7f(n-4)+6f(n-5)
# +2f(n-7)-5f(n-8)+2f(n-9)

rec = [4, -5, 4, -7, 6, 0, 2, -5, 2]

def combine(a, b, rec):
    """
    Multiply two polynomials modulo the recurrence.
    """
    m = len(rec)
    tmp = [0] * (2 * m)

    for i in range(m):
        for j in range(m):
            tmp[i + j] = (tmp[i + j] + a[i] * b[j]) % MOD

    # Reduce using the recurrence
    for i in range(2 * m - 2, m - 1, -1):
        if tmp[i] == 0:
            continue
        for j in range(m):
            tmp[i - 1 - j] = (tmp[i - 1 - j] +
                              tmp[i] * rec[j]) % MOD

    return tmp[:m]

def linear_recurrence(n, init, rec):
    """
    Returns f(n) where indexing is:
        init[0] = f(1)
    """

    m = len(rec)

    if n <= m:
        return init[n - 1] % MOD

    # Binary exponentiation on the companion polynomial
    pol = [1] + [0] * (m - 1)
    e = [0, 1] + [0] * (m - 2)

    k = n - 1

    while k:
        if k & 1:
            pol = combine(pol, e, rec)
        e = combine(e, e, rec)
        k >>= 1

    ans = 0
    for i in range(m):
        ans = (ans + pol[i] * init[i]) % MOD

    return ans

N = 10**18
print(linear_recurrence(N, init, rec))
```---

 #3. コードのチュートリアル

 ### 初期値

 最初の 9 つの値はポリゴン条件から直接計算されます。$$0,0,0,2,7,19,47,108,236.$$これらは再発の種となります。 

---

 ### 漸化係数```python
rec = [4, -5, 4, -7, 6, 0, 2, -5, 2]
```代表する$$f(n)=\sum_{i=1}^{9} rec[i-1]\cdot f(n-i).$$---

 ###`combine`これは、特性多項式を法とする高速累乗とまったく同じように、2 つの多項式を乗算し、漸化式を法として減少させます。 

---

 ###`linear_recurrence`2 進累乗を使用して計算します。$n$対数時間の - 番目の項。 

複雑：$$O(r^2\log n)$$と$r=9$, それでさえ$10^{18}$些細なことだ。
