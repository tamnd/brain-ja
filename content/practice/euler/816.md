[プロジェクト オイラー問題 816](https://projecteuler.net/problem=816)

 ## 解決策

 **答え:**`20.880613018`これを効率的に解決するには、$k = 2{,}000{,}000$、強引な$O(n^2)$比較は不可能です($\sim 2\times10^{12}$ペア）。 

正しいアプローチは、古典的な **最も近い点のペア** スイープ ライン アルゴリズムです。 

- 指定された擬似乱数シーケンスを使用してすべての点を生成します。 
- ポイントの並べ替え$x$-座標。 
- 順序付けされたアクティブ セットを維持します。$y$-座標。 
- 現在の最適距離内のポイントのみを比較します。 

アルゴリズムは以下で実行されます$O(n \log n)$。 

使用される Python 実装:```python
from math import sqrt
import bisect
import math

MOD = 50515093
n = 2000000

# Generate points
pts = [None] * n
s = 290797

vals = [0] * (2 * n)
for i in range(2 * n):
    vals[i] = s
    s = (s * s) % MOD

for i in range(n):
    pts[i] = (vals[2 * i], vals[2 * i + 1])

# Sort by x-coordinate
pts.sort()

best2 = float('inf')

# Active set sorted by y-coordinate: (y, x)
active = []
left = 0

for x, y in pts:

    d = math.sqrt(best2) if best2 < float('inf') else float('inf')

    # Remove points too far in x-direction
    while x - pts[left][0] > d:
        xx, yy = pts[left]
        idx = bisect.bisect_left(active, (yy, xx))
        active.pop(idx)
        left += 1

    # Candidate points within y-range
    lo = bisect.bisect_left(active, (y - d, -10**18))
    hi = bisect.bisect_right(active, (y + d, 10**18))

    for yy, xx in active[lo:hi]:
        dx = x - xx
        dy = y - yy
        ds = dx * dx + dy * dy

        if ds < best2:
            best2 = ds
            d = math.sqrt(best2)

    bisect.insort(active, (y, x))

answer = math.sqrt(best2)
print(f"{answer:.12f}")
