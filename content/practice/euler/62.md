[プロジェクト オイラー問題 62](https://projecteuler.net/problem=62)

 ## 解決策

 **答え:**`127035954683`**その数字のちょうど 5 つの順列も立方体となる **最小の立方体**を探します。 

重要な観察は、桁の置換によって複数の桁のセットが保存されるということです。 したがって、キューブをペアごとに比較する代わりに、標準的な「数字の署名」によってキューブを分類できます。 

自然な署名は次のとおりです。 

- 立方体の数字を並べ替えます。 
- 相互に並べ替えられた 2 つの数値は、同じ並べ替えられた数字の文字列を共有します。 

例えば：$$345^3 = 41063625$$数字の並べ替え:$$41063625 \to 01234566$$今：$$384^3 = 56623104 \to 01234566$$

$$405^3 = 66430125 \to 01234566$$したがって、3 つのキューブはすべて同じ署名クラスに属します。 

---

 # 数学的分析

 次のように仮定します。$$n^3 = c$$署名を定義します。$$\sigma(c) = \text{sorted digits of } c$$それから：$$\sigma(a^3)=\sigma(b^3)$$もし、そしてその場合に限り$a^3$そして$b^3$は互いの順列です。 

したがって、問題は次のようになります。 

> シグネチャ クラスに正確に 5 つのキューブが含まれる最小のキューブを見つけます。 

---

 ## 効率的な戦略

 すべてのキューブ間のブルートフォース比較はコストがかかります。 

代わりに:

 1. キューブを順番に生成します。 
2. 各キューブの数字の署名を計算します。 
3. シグネチャごとにグループ化されたキューブを辞書に保存します。 
4. 署名が 5 つのキューブに達したら、それを記録します。 
5. クラスに **ちょうど** 5 つのキューブ (それ以上ではない) があることを確認します。 

微妙な問題:

 - 5 つの立方体に到達したときにすぐに停止すると、後の立方体が 6 番目の順列を作成する可能性があります。 

これを回避するには、桁の長さによってグループ化されたキューブを処理します。 

なぜ？ 

- どの順列も同じ桁数になります。 
- より多くの桁を持つ立方体に移行すると、それ以上の立方体は以前の桁長クラスに属することができなくなります。 

したがって:

 - すべてのキューブを次のように処理します$d$数字。 
- その桁の長さを終了した後、グループを検査します。 
- ちょうど 5 つのキューブを持つグループが確定されます。 

---

 # Pythonの実装```python
from collections import defaultdict

# Dictionary:
# key   -> sorted digit signature
# value -> list of cubes having that signature
groups = defaultdict(list)

n = 1
current_length = 1

while True:
    cube = n ** 3

    # Number of digits in the cube
    length = len(str(cube))

    # When digit length changes, previous groups are complete
    if length > current_length:

        # Check all groups from the previous digit length
        candidates = [
            cubes for cubes in groups.values()
            if len(cubes) == 5
        ]

        # If any valid group exists, return the smallest cube
        if candidates:
            answer = min(min(cubes) for cubes in candidates)
            print(answer)
            break

        # Reset for the next digit length
        groups.clear()
        current_length = length

    # Create canonical digit signature
    signature = ''.join(sorted(str(cube)))

    # Store cube in its group
    groups[signature].append(cube)

    n += 1
```---
