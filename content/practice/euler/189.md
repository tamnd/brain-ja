[プロジェクト オイラー問題 189](https://projecteuler.net/problem=189)

 ## 解決策

 **答え:**`10834893628237824`大きな正三角形の一辺の長さを$8$。 

に細分化されています$$1+3+5+\cdots+15 = 8^2 = 64$$小さな三角形。 

適切な数を数えなければなりません$3$-これらのカラーリング$64$三角形。隣接する三角形 (エッジを共有する) は異なる色を受け取ります。

 #1. 数学的分析

 ## 1.1 グラフの解釈

 それぞれの小さな三角形をグラフの頂点として扱います。 

- 対応する三角形がエッジを共有している場合、2 つの頂点は接続されます。 
- 色を使用してこのグラフの適切な着色の数が必要です$\{R,G,B\}$。 

したがって、これはグラフの色分けの計数問題になります。 

グラフには次の内容があります。 

-$64$頂点、
 - 最大度$3$、
 - 非常に規則的な層状構造。 

直接のブルートフォース検索にはチェックが必要です$$3^{64} \approx 3.4\times10^{30}$$任務、それは不可能です。 

そこで、動的プログラミングが必要になります。 

---

 # 1.2 重要な洞察: フロンティアの幅が狭い

 三角形を行ごとに (より正確には、適切な幾何学的順序で) 処理すると、現時点では、少数のすでに色付けされた三角形だけが今後の三角形と相互作用することができます。 

このセットは**フロンティア**と呼ばれます。 

サイドの三角格子の場合$8$、フロンティアはサイズを超えることはありません$8$。 

したがって:

 - 以前の色をすべて記憶するのではなく、
 - 私たちは辺境の色だけを覚えています。 

各フロンティア頂点には$3$可能な色、状態の数は最大で$$3^8 = 6561,$$それは小さいです。 

これにより、正確な計算が可能になります。 

---

 # 1.3 動的プログラミングの状態

 三角形を固定の順序で処理するとします。$$T_0,T_1,\dots,T_{63}.$$ステップで$i$:

 - 以前に処理された三角形の中には、まだ処理されていない隣接三角形がまだあるものがあります。 
- これらの三角形がフロンティアを形成します。 

DP の状態は次のとおりです。$$(\text{frontier colouring}) \mapsto \text{count}.$$次の三角形を処理するとき:

 1. すでに色付けされている隣接色によって禁止されている色を決定します。 
2. 残りの色を試してください。 
3. フロンティアを更新します。 

すべての三角形には最大でも次数があるため、$3$、それぞれの遷移は非常に小さいです。

 #2. Pythonの実装```python
from collections import defaultdict

# ------------------------------------------------------------
# Build the triangular grid graph
# ------------------------------------------------------------

def build_graph(n):
    """
    Build the adjacency graph of the n^2 little triangles.

    Each small triangle is represented by its three lattice vertices.
    Two triangles are adjacent iff they share an edge
    (i.e. two common vertices).
    """

    triangles = []

    # Upward-pointing triangles
    for i in range(n):
        for j in range(n - i):
            tri = ((i, j), (i + 1, j), (i, j + 1))
            triangles.append(tri)

    # Downward-pointing triangles
    for i in range(n - 1):
        for j in range(n - 1 - i):
            tri = ((i + 1, j), (i, j + 1), (i + 1, j + 1))
            triangles.append(tri)

    m = len(triangles)

    # Build adjacency
    adj = [set() for _ in range(m)]

    for a in range(m):
        A = set(triangles[a])

        for b in range(a + 1, m):
            B = set(triangles[b])

            # Sharing an edge means sharing exactly two vertices
            if len(A & B) == 2:
                adj[a].add(b)
                adj[b].add(a)

    return triangles, adj

# ------------------------------------------------------------
# Choose a geometric processing order
# ------------------------------------------------------------

def triangle_centroid(tri):
    x = sum(v[0] for v in tri) / 3
    y = sum(v[1] for v in tri) / 3
    return (y, x)

# ------------------------------------------------------------
# Count proper 3-colourings using frontier DP
# ------------------------------------------------------------

def count_colourings(n=8):

    triangles, adj = build_graph(n)

    m = len(triangles)

    # Process triangles from top to bottom
    order = sorted(range(m),
                   key=lambda t: triangle_centroid(triangles[t]))

    pos = {v: i for i, v in enumerate(order)}

    # Past neighbours of each vertex
    past = {
        v: [u for u in adj[v] if pos[u] < pos[v]]
        for v in range(m)
    }

    # DP:
    # state = tuple of frontier colours
    # value = number of ways
    states = {(): 1}

    for i, v in enumerate(order):

        # Current active frontier
        active = sorted(
            {
                u for u in order[:i]
                if any(pos[w] >= i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        # Frontier after processing v
        next_active = sorted(
            {
                u for u in order[:i + 1]
                if any(pos[w] > i for w in adj[u])
            },
            key=lambda x: pos[x]
        )

        new_states = defaultdict(int)

        for key, count in states.items():

            colouring = dict(zip(active, key))

            # Colours forbidden by already-coloured neighbours
            forbidden = {
                colouring[u]
                for u in past[v]
                if u in colouring
            }

            for colour in range(3):

                if colour in forbidden:
                    continue

                new_colouring = colouring.copy()

                # Keep v only if it still has future neighbours
                if any(pos[w] > i for w in adj[v]):
                    new_colouring[v] = colour

                new_key = tuple(new_colouring[u]
                                for u in next_active)

                new_states[new_key] += count

        states = new_states

    return sum(states.values())

# ------------------------------------------------------------
# Compute the answer
# ------------------------------------------------------------

answer = count_colourings(8)

print(answer)

 #3. コードのチュートリアル

 ## グラフの構築

 それぞれの小さな三角形は、その 3 つの格子頂点によってエンコードされます。 

上向き三角形の例:$$((i,j),(i+1,j),(i,j+1)).$$下向き三角形の例:$$((i+1,j),(i,j+1),(i+1,j+1)).$$2 つの三角形は、2 つの頂点を共有する場合、正確に隣接します。 

---

 ## 注文

 重心座標を使用して三角形を上から下に処理します。 

これによりフロンティアが小さく保たれます。

 状態は以下を保存します。 

- どのフロンティアトライアングルが存在するか、
 - そしてその色。

 - 辺境の三角形 #1 の色は 0、
 - フロンティアトライアングル #2 の色は 2、
 -など
