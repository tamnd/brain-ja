 ## 解決策

 私たちは満足のいくピタゴラスの三重項を求めます$a^2+b^2=c^2⟦PROTECT_2⟧b⟦PROTECT_3⟧a^2 + b^2 = c^2 \approx 225.00 + 225.00 = 450.00$a と b を調整すると、三角形と c.abc の派生値が更新されます。 

と$$a+b+c=1000.$$代わりの$c = 1000-a-b$ピタゴラス方程式に代入すると、次のようになります。$$a^2+b^2=(1000-a-b)^2.$$拡張と簡略化:$$a^2+b^2=1000000+a^2+b^2+2ab-2000a-2000b,$$それで$$0=1000000+2ab-2000a-2000b.$$で割る$2$:$$ab-1000a-1000b=-500000.$$再配置:$$(a-1000)(b-1000)=500000.$$因子ペアを検索すると、次の結果が得られます。$$a=200,\quad b=375,\quad c=425.$$チェック：$$200^2+375^2=40000+140625=180625=425^2.$$そして：$$200+375+425=1000.$$したがって、$$abc = 200 \times 375 \times 425 = 31875000.$$Python コード:```python
for a in range(1, 1000):
    for b in range(a + 1, 1000):
        c = 1000 - a - b
        if a*a + b*b == c*c:
            print(a * b * c)
```ロジックを追跡すると、一意のトリプレットが見つかります$(200,375,425)$、生産:```python
31875000
```**答え: 31875000**
