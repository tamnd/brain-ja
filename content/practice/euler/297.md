[プロジェクト オイラー問題 297](https://projecteuler.net/problem=297)

 ## 解決策

 **答え:**`2252639041804718029`させて$$F_1=1,\quad F_2=2,\quad F_n=F_{n-1}+F_{n-2}$$したがって、フィボナッチ数列は$$1,2,3,5,8,13,\dots$$すべての正の整数は、この数列 (ゼッケンドルフの定理) からの **非連続** フィボナッチ数の合計として一意の表現を持ちます。 

定義する$z(n)$のゼッケンドルフ表現におけるフィボナッチ項の数になります。$n$。 

計算しなければなりません$$\sum_{0<n<10^{17}} z(n).$$---

 # 数学的分析

 定義する$$S(N)=\sum_{0<n<N} z(n).$$私たちは求めています$S(10^{17})$。 

---

 ## 1. Zeckendorf 表現の構造

 以下のすべての数値を考慮します$F_k$。 

すべての数字$n<F_k$次の 2 つのグループのいずれかに分類されます。 

1.$0\le n<F_{k-1}$2.$F_{k-1}\le n<F_k$2 番目のグループについては、次のように書きます。$$n=F_{k-1}+m,$$必然的にどこで$$0\le m<F_{k-2},$$ゼッケンドルフ表現では連続したフィボナッチ数を使用できないためです。 

したがって$$z(n)=1+z(m).$$それで間隔は$[F_{k-1},F_k)$貢献します:

 - 数値ごとに 1 つの追加のフィボナッチ項、
 - 全員からの貢献に加えて$m<F_{k-2}$。 

したがって、次のようになります。$$S(F_k)=S(F_{k-1})+S(F_{k-2})+F_{k-2}.$$（用語$F_{k-2}$余分な「+1」を正確にカウントします$F_{k-2}$値。)

 ---

 ## 2. 正確なフィボナッチ境界の再帰

 定義する$$A_k=S(F_k).$$それから：$$A_k=A_{k-1}+A_{k-2}+F_{k-2}.$$基本的なケース:$$A_1=S(1)=0,$$

$$A_2=S(2)=z(1)=1.$$これにより、すべてを計算できるようになります$A_k$とても早く。 

---

 ## 3. 任意の一般的な再帰$N$させて$F_k$最大のフィボナッチ数になる$$F_k\le N.$$範囲を分割する$0<n<N$の中へ：

-$0<n<F_k$-$F_k\le n<N$最初の貢献は次のとおりです。$$A_k.$$2 番目の場合、すべての数値は次の形式になります。$$F_k+m,\qquad 0\le m<N-F_k,$$したがって$$z(F_k+m)=1+z(m).$$それで：$$S(N)=A_k+(N-F_k)+S(N-F_k).$$この再帰により、$N$最大のフィボナッチ加数によって各ステップが計算され、ゼッケンドルフ分解を正確に反映します。 

---

 # Pythonの実装```python
from functools import lru_cache

LIMIT = 10**17

# ------------------------------------------------------------
# Build Fibonacci numbers:
# F1 = 1, F2 = 2
# ------------------------------------------------------------

fib = [1, 2]

while fib[-1] < LIMIT:
    fib.append(fib[-1] + fib[-2])

# ------------------------------------------------------------
# A[k] = S(F_k)
# where S(N) = sum_{0 < n < N} z(n)
#
# Recurrence:
# A[k] = A[k-1] + A[k-2] + F[k-2]
# ------------------------------------------------------------

A = [0] * len(fib)

A[0] = 0          # S(1)
A[1] = 1          # S(2)

for k in range(2, len(fib)):
    A[k] = A[k-1] + A[k-2] + fib[k-2]

# ------------------------------------------------------------
# Recursive computation of S(N)
# ------------------------------------------------------------

@lru_cache(None)
def S(N):
    if N <= 1:
        return 0

    # largest Fibonacci number <= N
    k = 0
    while k + 1 < len(fib) and fib[k + 1] <= N:
        k += 1

    # exact boundary
    if fib[k] == N:
        return A[k]

    # recursive decomposition
    return A[k] + (N - fib[k]) + S(N - fib[k])

# ------------------------------------------------------------
# Compute answer
# ------------------------------------------------------------

answer = S(10**17)

print(answer)
```---

```python

```これにより、以前に導出された繰り返しが実装されます。

 ## 再帰的計算```python
return A[k] + (N - fib[k]) + S(N - fib[k])
```これは次のものに正確に対応します。$$S(N)=S(F_k)+(N-F_k)+S(N-F_k).$$Zeckendorf 分解は短いため、再帰の深さはわずかです。
