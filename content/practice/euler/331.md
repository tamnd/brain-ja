[プロジェクト オイラー問題 331](https://projecteuler.net/problem=331)

 ## 解決策

 **答え:**`467178235146843549`させて$b_{x,y}\in\{0,1\}$はディスクの初期状態を示します。$(x,y)$、 どこ$1$黒を意味し、$0$白を意味します。 

位置を反転すると$(i,j)$、次に行内のすべてのディスク$i$そしてコラム$j$で切り替わります。$(i,j)$全体で 1 回だけ切り替えられます。 

私たちは畑の上で働きます$\mathbb F_2$(XOR 演算)。 

---

 #1. 線形代数の定式化

 しましょう$$f_{i,j}\in\{0,1\}$$で移動を実行するかどうかを示します$(i,j)$。 

定義する$$R_i=\bigoplus_k f_{i,k}, \qquad C_j=\bigoplus_k f_{k,j},$$移動行列の行/列 XOR パリティ。 

細胞$(i,j)$反転されます:

 - での移動によって 1 回$(i,j)$、
 - 行内の移動ごとに 1 回$i$、
 - 列内で移動するたびに 1 回$j$。 

したがって、最終的なパリティ条件は次のようになります。$$R_i \oplus C_j \oplus f_{i,j}=b_{i,j}.$$したがって$$f_{i,j}=b_{i,j}\oplus R_i\oplus C_j.$$---

 ＃2.偶数$N$偶数の場合$N$、行にわたる方程式を合計すると、次のようになります。$$R_i = \bigoplus_j b_{i,j} \oplus \bigoplus_j C_j.$$させて$$r_i=\bigoplus_j b_{i,j}$$行のパリティになる$i$。 

対称的な構成により、$$r_i=c_i,$$そして、グローバルなパリティの自由を排除した後、独自の解決策が得られます。$$f_{i,j}=b_{i,j}\oplus r_i\oplus r_j.$$したがって、移動の数は次の数に等しくなります。$1$この行列には が含まれています。 

---

 #3. 奇妙な$N$奇数の場合$N$、すべての行パリティが等しい場合、システムは解決可能です。 

アニュラス構成の場合$C_N$、これは次の場合にのみ発生します。$N=5$に現れるすべての奇数値の中で$$2^i-i.$$したがって、次のようになります。$$T(5)=3, \qquad T(N)=0 \text{ for all other odd } N \text{ in the sum}.$$したがって、偶数の値のみが寄与します。 

---

 #4. 環状部の形状

 セルは黒い場合$$(N-1)^2 \le x^2+y^2 < N^2.$$固定用$x$、黒のセルは 1 つの連続した間隔を形成します。$y$:$$y_{\min}(x)\le y\le y_{\max}(x),$$どこ$$y_{\max}(x)=\left\lfloor\sqrt{N^2-1-x^2}\right\rfloor,$$

$$y_{\min}(x)= \left\lfloor\sqrt{N^2-2N-x^2}\right\rfloor+1.$$したがって、行にある黒マスの数は$x$は$$L(x)=y_{\max}(x)-y_{\min}(x)+1.$$そのパリティは$$r_x=L(x)\bmod 2.$$したがって、移動行列は次のようになります。$$f_{x,y}=b_{x,y}\oplus r_x\oplus r_y.$$の合計数を計算できます。$1$が入っています$O(N)$プレフィックス合計を使用した時間。

 #5. Pythonの実装```python
import math

def T(N):
    # Odd N: only N=5 is solvable in our range
    if N & 1:
        return 3 if N == 5 else 0

    n2 = N * N

    # r[x] = parity of black cells in row x
    r = [0] * N

    y_outer = [0] * N
    y_inner = [0] * N

    total_black = 0
    A = 0  # number of rows with odd parity

    # Compute row intervals
    for x in range(N):
        x2 = x * x

        # outer boundary
        yout = math.isqrt(n2 - 1 - x2)
        y_outer[x] = yout

        # inner boundary
        if x == N - 1:
            yin = -1
        else:
            v = n2 - 2 * N - x2
            yin = math.isqrt(v) if v >= 0 else -1

        y_inner[x] = yin

        L = yout - yin

        total_black += L

        r[x] = L & 1
        A += r[x]

    # Prefix sums of row parities
    pref = [0] * (N + 1)

    for i in range(N):
        pref[i + 1] = pref[i] + r[i]

    # Count black cells with r[x] XOR r[y] = 1
    Bxor1 = 0

    for x in range(N):
        y0 = y_inner[x] + 1
        y1 = y_outer[x]

        if y0 > y1:
            continue

        ones = pref[y1 + 1] - pref[y0]
        length = y1 - y0 + 1

        if r[x] == 0:
            Bxor1 += ones
        else:
            Bxor1 += length - ones

    # Total number of 1's in solution matrix
    return 2 * A * (N - A) + total_black - 2 * Bxor1

ans = sum(T((1 << i) - i) for i in range(3, 32))

print(ans)
```---
