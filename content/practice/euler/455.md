[プロジェクト オイラー問題 455](https://projecteuler.net/problem=455)

 ## 解決策

 **答え:**`450186511399999`私たちは機能を追求します$$f(n)=\max\{x<10^9 : n^x \equiv x \pmod{10^9}\},$$と$f(n)=0$そうでない場合$x$存在します。 

計算しなければなりません$$\sum_{n=2}^{10^6} f(n).$$---

 #1. 数学的分析

 合同式を解いています$$n^x \equiv x \pmod{10^9}.$$以来$10^9 = 2^9 5^9$、これは合成係数を法とする固定小数点問題です。 

重要な観察点は、地図が$$T(x)=n^x \pmod{10^9}$$反復すると、非常に急速に固定点に収束します。 

---

 ## 固定小数点の反復

 定義するとします$$x_{k+1}=n^{x_k}\pmod{10^9}, \qquad x_0=1.$$経験的に（そして次のように説明可能）$2$-アディックと$5$-adiclifting)、このシーケンスは非常に早く安定します。$$x_{k+1}=x_k.$$安定したら、$$x=n^x \pmod{10^9},$$それで$x$まさに有効な解決策です。 

さらに、この係数の場合、反復は以下の_最大_固定点に収束します。$10^9$。 

---

 ## 10 で割り切れる数字がゼロになるのはなぜですか

 もし$10\mid n$十分に大きな指数の場合、$$n^x \equiv 0 \pmod{2^9} \quad\text{and}\quad n^x \equiv 0 \pmod{5^9}.$$したがって、$$n^x \equiv 0 \pmod{10^9}.$$固定点には次のことが必要です$$x\equiv 0 \pmod{10^9},$$しかし$0\le x<10^9$、したがって、唯一の可能性は次のとおりです。$x=0$、問題では正の整数が要求されるため、これは除外されます。 したがって：$$f(n)=0 \qquad (10\mid n).$$---

 ## 例の検証

 ### 例 1:$n=4$反復:$$1 \to 4 \to 256 \to 719156736 \to \cdots \to 411728896.$$最終的に：$$4^{411728896}\equiv 411728896 \pmod{10^9}.$$したがって$$f(4)=411728896.$$---

 ### 例 2:$n=157$反復は次のように収束します$$743757,$$そして確かに$$157^{743757}\equiv 743757 \pmod{10^9}.$$それで$$f(157)=743757.$$---

 #2. Pythonの実装```python
MOD = 10**9

def f(n):
    """
    Compute the largest x < 10^9 such that
        n^x ≡ x (mod 10^9)
    using fixed-point iteration.
    """

    # Numbers divisible by 10 have no positive solution
    if n % 10 == 0:
        return 0

    x = 1

    while True:
        nx = pow(n, x, MOD)

        if nx == x:
            return x

        x = nx

def solve(limit=10**6):
    total = 0

    for n in range(2, limit + 1):
        total += f(n)

    return total

# Verification against the example in the statement
check = sum(f(n) for n in range(2, 1001))
print(check)   # 442530011399

# Final answer
print(solve())
```---
