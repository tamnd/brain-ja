[プロジェクト オイラー問題 334](https://projecteuler.net/problem=334)

 ## 解決策

 **答え:**`150320021261690835`ボウルに整数でインデックスを付け、次のようにします。$a_i$ボウルの中の豆の数を示します$i$。 

私たちはその移動を許可されています$$(\ldots,a_{i-1},a_i,a_{i+1},\ldots) \to (\ldots,a_{i-1}+1,a_i-2,a_{i+1}+1,\ldots)$$いつでも$a_i\ge 2$。 

重要なのは、何十億もの動きをシミュレートしないようにすることです。 

## 1. 数学的分析

 ### ステップ 1: 不変条件を特定する

 それぞれの移動により以下が保持されます。 

#### Bean の総数$$N=\sum_i a_i$$2 つの豆を削除して 2 つの豆を追加するためです。 

#### 第一モーメント (重心)$$M=\sum_i i\,a_i$$以来$$(i-1)+(i+1)-2i=0.$$したがって両方とも$N$そして$M$は不変です。 

---

 ### ステップ 2: 予測どおりに変化する量を見つける

 二次モーメントを考えてみましょう$$Q=\sum_i i^2 a_i.$$ポジションでの 1 つの移動$i$変化$Q$による$$(i-1)^2+(i+1)^2-2i^2.$$拡張:$$(i^2-2i+1)+(i^2+2i+1)-2i^2=2.$$したがって **すべての動きが増加します$Q$ちょうど 2** までに。 

したがって、次のようになります。$$\boxed{ \text{moves} = \frac{Q_{\text{final}}-Q_{\text{initial}}}{2} }$$したがって、必要なのは最終的な安定した構成のみです。 

---

 ### ステップ 3: 最終的な安定状態の特徴付け

 安定した状態では、ボウルごとに豆が 0 個または 1 個しかありません。 

固定されたすべての安定状態の中で$N$そして$M$、到達可能なものは、最小限に抑える独自の配置です。$$\sum x_i^2$$対象となるもの:

 -$N$占領された位置、
 - 個別の整数、
 - 合計額$M$。 

二乗関数は凸関数であるため、占有されたボウルは**可能な限り連続している**必要があります。 

したがって、最終的な位置は次のようになります。$$a,\ a+1,\ \ldots,\ a+N-1$$最大のものを除いて$r$位置は次のようにシフトされます$+1$。 

させて$$T=\frac{N(N-1)}{2}.$$それから書きます$$M-T = aN + r, \qquad 0\le r < N.$$最終的な占有位置は次のとおりです。$$a,\ a+1,\ldots,a+N-r-1,$$そして$$a+N-r+1,\ldots,a+N.$$これで計算できるようになります$Q_{\text{final}}$直接。 

---

 ### ステップ 4: シーケンスを生成する

 私たちには次のものが与えられます:$$t_0=123456$$そして$$t_i= \begin{cases} t_{i-1}/2 & \text{if even}\\ \lfloor t_{i-1}/2\rfloor \oplus 926252 & \text{if odd} \end{cases}$$と$$b_i=(t_i\bmod 2^{11})+1.$$最初の用語は次のとおりです。$$b_1=289,\qquad b_2=145$$ステートメントと一致します。 

ボウルが 2 つだけの例では、式は正確に次のようになります。$$3419100$$動き、正確さを検証します。

 ## 2. Python の実装```python
def generate_b(n=1500):
    t = 123456
    b = []

    for _ in range(n):
        if t % 2 == 0:
            t //= 2
        else:
            t = (t // 2) ^ 926252

        b.append((t % (2 ** 11)) + 1)

    return b

def sum_squares_arithmetic(start, length):
    """
    Sum of:
        start^2 + (start+1)^2 + ... + (start+length-1)^2
    """
    if length <= 0:
        return 0

    n = length
    return (
        n * start * start
        + 2 * start * (n * (n - 1) // 2)
        + (n - 1) * n * (2 * n - 1) // 6
    )

# Generate the 1500 bowls
b = generate_b(1500)

# Invariants
N = sum(b)
M = sum(i * x for i, x in enumerate(b))

# Initial quadratic moment
Q_initial = sum(i * i * x for i, x in enumerate(b))

# Determine final stable configuration
T = N * (N - 1) // 2
a = (M - T) // N
r = (M - T) % N

# Final occupied bowls:
# a, a+1, ..., a+N-r-1
# a+N-r+1, ..., a+N
left_count = N - r

Q_final = (
    sum_squares_arithmetic(a, left_count)
    + sum_squares_arithmetic(a + left_count + 1, r)
)

# Each move increases Q by exactly 2
moves = (Q_final - Q_initial) // 2

print(moves)
```---
