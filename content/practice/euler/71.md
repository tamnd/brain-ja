[プロジェクト オイラー問題 71](https://projecteuler.net/problem=71)

 ## 解決策

 **答え:**`428570`のすぐ左側にある縮小された固有分数を求めます。$$\frac37$$分母を持つすべての分数の間で$d \le 1{,}000{,}000$。 

この問題は基本的に **フェアリー数列** と有理近似に関するものです。 

---

 # 数学的分析

 最大の縮小分数が必要です$$\frac nd < \frac37$$と$$d \le 1{,}000{,}000.$$同様に、次の値に最も近い分数が必要です。$\frac37$下から。 

---

 ## ステップ 1: 分数がどのくらい離れているかを測定する$3/7$考慮する：$$\frac37 - \frac nd.$$計算:$$\frac37 - \frac nd = \frac{3d-7n}{7d}.$$以来$\frac nd < \frac37$、$$3d - 7n > 0.$$したがって、距離を最小化することは、正の整数を最小化することと同じです。$$3d - 7n.$$可能な最小の正の値は次のとおりです。$$3d - 7n = 1.$$したがって、最適な分数は次の条件を満たす必要があります。$$3d - 7n = 1.$$再配置:$$7n = 3d - 1,$$それで$$n = \frac{3d-1}{7}.$$したがって$3d-1$で割り切れる必要があります$7$。 

---

 ## ステップ 2: 合同式を解く

 必要なものは次のとおりです。$$3d \equiv 1 \pmod 7.$$の逆$3 \pmod 7$は$5$、 なぜなら：$$3 \cdot 5 = 15 \equiv 1 \pmod 7.$$したがって、次のようになります。$$d \equiv 5 \pmod 7.$$**最大**の分母が必要です$d \le 1{,}000{,}000$これを満足させます。 

計算:$$1{,}000{,}000 \bmod 7 = 1.$$それで最大の$d \equiv 5 \pmod 7$100 万未満は次のとおりです。$$999{,}997.$$---

 ## ステップ 3: 分子を計算する

 使用する$$n = \frac{3d-1}{7},$$得られるもの:$$n = \frac{3(999{,}997)-1}{7} = \frac{2{,}999{,}991-1}{7} = \frac{2{,}999{,}990}{7} = 428{,}570.$$したがって、分数は次のようになります。$$\frac{428570}{999997}.$$チェック：$$3(999997)-7(428570)=2999991-2999990=1,$$実際、それはすぐ左にあります$\frac37$。 

---

 # Pythonの実装```python
from math import gcd

LIMIT = 1_000_000

best_n = 0
best_d = 1

# For each denominator d, choose the largest n such that n/d < 3/7
for d in range(2, LIMIT + 1):

    # Largest integer strictly less than 3d/7
    n = (3 * d - 1) // 7

    # Fraction must be reduced
    if gcd(n, d) == 1:

        # Compare n/d with current best using cross multiplication
        if n * best_d > best_n * d:
            best_n = n
            best_d = d

print(best_n)
```---

 私たちの候補者は次のとおりです。$$\frac{428570}{999997}.$$近接性を確認します:$$\frac37 - \frac{428570}{999997} = \frac{1}{7 \cdot 999997},$$これは非常に小さいため最適です。
