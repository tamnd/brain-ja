[プロジェクト オイラー問題 506](https://projecteuler.net/problem=506)

 ## 解決策

 **答え:**`18934502`無限桁ストリームを次のようにします。$$123432123432123432\cdots$$それを連続する整数に分割します$v_n$したがって、次の桁の合計は$v_n$等しい$n$。 

最初の用語は次のとおりです。$$1,2,3,4,32,123,43,2123,432,1234,32123,\dots$$私たちが欲しいのは$$S(n)=\sum_{k=1}^{n} v_k$$そして具体的には$$S(10^{14}) \bmod 123454321.$$---

 ## 1. 数学的分析

 ### ステップ 1: 周期構造を観察する

 繰り返しブロックは$$123432$$その桁の合計は$$1+2+3+4+3+2 = 15.$$これが重要な洞察です。 

繰り返しブロックの合計は 15 になるため、ターゲット桁の合計を 15 増や​​すと、単純に 1 サイクルの桁が追加されます。 

たとえば:

 |$n$|$v_n$|
 | --- | --- |
 | 1 | 1 |
 | 16 | 1234321 |
 | 31 | 1234321234321 |

 同様に:

 |$n$|$v_n$|
 | --- | --- |
 | 5 | 32 |
 | 20 | 32123432 |
 | 35 | 32123432123432 |

 したがって、固定剰余の場合$r=n\bmod 15$、$$n=15q+r$$番号$v_n$の形式は次のとおりです。$$v_{15q+r} = \underbrace{C_rC_r\cdots C_r}_{q\text{ copies}}\,B_r$$どこ：

-$B_r=v_r$(基本パターン)、
 -$C_r$6桁の巡回ブロックです。 

例えば：$$B_5=32,\qquad C_5=321234$$それで$$v_{20}=32123432.$$---

 ### ステップ 2: 10 進数値の式

 もし$L_r$の桁の長さです$B_r$、 それから$$v_{15q+r} = \left( C_r\sum_{i=0}^{q-1}10^{6i} \right)10^{L_r} + B_r.$$幾何学的な部分は、$$R_q = \sum_{i=0}^{q-1}10^{6i} = \frac{10^{6q}-1}{10^6-1}.$$したがって$$v_{15q+r} = C_r\,10^{L_r}R_q+B_r.$$---

 ### ステップ 3: 全体をまとめる$q$固定残基の場合$r$、 させて$$m_r = \left\lfloor\frac{N-r}{15}\right\rfloor+1$$項の数になります。 

それから$$S_r = \sum_{q=0}^{m_r-1} v_{15q+r}.$$次の式を代入します。$$S_r = m_rB_r + C_r10^{L_r} \sum_{q=0}^{m_r-1}R_q.$$今$$\sum_{q=0}^{m-1}R_q = \frac{ \sum_{q=0}^{m-1}10^{6q}-m }{ 10^6-1 }$$そして$$\sum_{q=0}^{m-1}10^{6q} = \frac{10^{6m}-1}{10^6-1}.$$すべてはモジュロで計算できます$$M=123454321$$モジュラーインバースを使用します。 

なぜなら$$\gcd(999999,M)=1,$$除算モジュロ$M$有効です。

 ## 2. Python の実装```python
MOD = 123454321
BASE = 10**6
D = BASE - 1  # 999999

# First 15 base values v_r
B = [
    None,
    "1", "2", "3", "4", "32",
    "123", "43", "2123", "432",
    "1234", "32123", "43212",
    "34321", "23432", "123432"
]

# Corresponding repeating 6-digit blocks
C = [
    None,
    "123432", "234321", "343212", "432123",
    "321234", "123432", "432123", "212343",
    "432123", "123432", "321234", "432123",
    "343212", "234321", "123432"
]

def solve(N):
    inv_D = pow(D, -1, MOD)
    inv_geom = pow(BASE - 1, -1, MOD)

    total = 0

    for r in range(1, 16):
        if r > N:
            break

        # number of q-values
        m = (N - r) // 15 + 1

        b = int(B[r])
        c = int(C[r])
        L = len(B[r])

        # geometric sum:
        # sum_{q=0}^{m-1} 10^(6q)
        geom = (
            (pow(BASE, m, MOD) - 1)
            * inv_geom
        ) % MOD

        # sum of R_q
        sum_R = ((geom - m) % MOD) * inv_D % MOD

        contribution = (
            (m % MOD) * (b % MOD)
            + c * pow(10, L, MOD) * sum_R
        ) % MOD

        total = (total + contribution) % MOD

    return total

# Checks
print(solve(11))    # 36120
print(solve(1000))  # 18232686

# Final answer
print(solve(10**14))
```---

 ## 3. コードのチュートリアル

 -`B[r]`基本パターンを保存します$v_r$。 
-`C[r]`剰余の繰り返しの 6 桁のサイクルを保存します$r$。 
- 剰余クラスごとに$r=1,\dots,15$:

 - 出現する用語の数を数えます$N$、
 - 等比級数のモジュロを計算します$M$、
 - その剰余クラスの合計寄与を計算します。 
- 答えに追加します。 

### 検証

 プログラムは例を再現します。$$S(11)=36120$$そして$$S(1000)\bmod 123454321=18232686.$$どちらも問題文と正確に一致します。
