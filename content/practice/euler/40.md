[プロジェクト オイラー問題 40](https://projecteuler.net/problem=40)

 ## 解決策

 **答え:**`210`無理数を作成します$$0.12345678910111213141516\cdots$$正の整数を順番に連結します。 

させて$d_n$を示します$n$-小数点以下の桁。 

計算しなければなりません$$d_1 d_{10} d_{100} d_{1000} d_{10000} d_{100000} d_{1000000}.$$---

 #1. 数学的分析

 重要な考え方は、どの整数に次の値が含まれるかを特定することです。$n$- 番目の桁。 

整数を桁数でグループ化します。 

## ステップ 1: 各ブロックが提供する桁数をカウントする

 ### 1桁の数字

 数字:$$1,2,\dots,9$$がある$9$それぞれが寄与する数値$1$桁。 

合計桁数:$$9 \times 1 = 9$$---

 ### 2桁の数字

 数字:$$10,11,\dots,99$$がある$$90$$それぞれが寄与する数値$2$数字。 

合計桁数:$$90 \times 2 = 180$$累計:$$9 + 180 = 189$$---

 ### 3桁の数字$$100 \text{ to } 999$$カウント：$$900$$貢献した数字:$$900 \times 3 = 2700$$累計:$$2889$$- -

一般的に：

-$k$-桁の数字が寄与する$$9 \cdot 10^{k-1} \cdot k$$数字。 

---

 # 検索$d_n$決定するには$d_n$:

 1. どの桁長のブロックに位置が含まれるかを決定します$n$。 
2. そのブロック内の正確な番号を特定します。 
3. その数字の何桁かを判断します。 

- -

＃ 例：$d_{12}$最初の 9 桁の由来は、$1$-桁の数字。 

だから位置$12$の間にあります$2$-桁の数字。 

2 桁のブロック内の相対位置:$$12 - 9 = 3$$各数値は 2 桁を構成します。$$(3-1)//2 = 1$$したがって、10 の後の 2 番目の 2 桁の数字になります。$$11$$数字のインデックス:$$(3-1)\bmod 2 = 0$$の最初の桁は何ですか$11$、つまり:$$1$$それで$d_{12}=1$、ステートメントと一致します。 

---

 # 必要な数字を計算します

 ここで、次のように決定します。$$d_1,d_{10},d_{100},d_{1000},d_{10000},d_{100000},d_{1000000}$$結果の数字は次のとおりです。$$1,\ 1,\ 5,\ 3,\ 7,\ 2,\ 1$$したがって、製品は$$1 \times 1 \times 5 \times 3 \times 7 \times 2 \times 1$$

$$= 210$$---

 #2. Pythonの実装```python
def champernowne_digit(n):
    """
    Return the nth digit of Champernowne's constant:
    0.123456789101112...
    """

    digit_length = 1
    count = 9
    start = 1

    # Find which block contains the nth digit
    while n > digit_length * count:
        n -= digit_length * count
        digit_length += 1
        count *= 10
        start *= 10

    # Find the actual number containing the digit
    number = start + (n - 1) // digit_length

    # Find the digit inside that number
    digit_index = (n - 1) % digit_length

    return int(str(number)[digit_index])

# Required positions
positions = [1, 10, 100, 1000, 10000, 100000, 1000000]

product = 1

for p in positions:
    product *= champernowne_digit(p)

print(product)
```---

 #4. 最終検証

 見つかった数字は次のとおりです。$$d_1=1,\quad d_{10}=1,\quad d_{100}=5,\quad d_{1000}=3,\quad d_{10000}=7,\quad d_{100000}=2,\quad d_{1000000}=1$$彼らの製品:$$1 \cdot 1 \cdot 5 \cdot 3 \cdot 7 \cdot 2 \cdot 1 = 210$$抽出された多くの桁が小さいため、値は小さく妥当です。
