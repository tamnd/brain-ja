[プロジェクト オイラー問題 165](https://projecteuler.net/problem=165)

 ## 解決策

 **答え:**`2868868`Blum-Blum-Shub シーケンスから 5000 の線分を生成し、すべての線分ペア間で **明確な真の交点**の数を数えなければなりません。 

主な問題点は次のとおりです。 

1. 2 つの線分が両方の線分の **単一の内部点** で交差するかどうかを正しく検出します。 
2. エンドポイントの接触と同一線上のオーバーラップを回避します。 
3. **異なる**交差点を正確に数えます。これには、浮動小数点ではなく有理演算が必要です。 

---

 # 数学的分析

 ## 1. セグメントの生成

 私たちは与えられています$$s_0 = 290797,\qquad s_{n+1} = s_n^2 \pmod{50515093}$$そして$$t_n = s_n \bmod 500.$$連続する 4 つの値ごとに 1 つのセグメントが定義されます。$$(x_1,y_1)=(t_{4k+1},t_{4k+2}), \qquad (x_2,y_2)=(t_{4k+3},t_{4k+4}).$$5000 セグメントが必要なので、$20000$価値観$t_n$。 

---

 #2. セグメント交差の形状

 2 つのセグメントを考えてみましょう$$A=(x_1,y_1),\quad B=(x_2,y_2),$$

$$C=(x_3,y_3),\quad D=(x_4,y_4).$$ベクトルを定義する$$\mathbf r = B-A, \qquad \mathbf s = D-C.$$2 本の無限直線が交差する場合$$\mathbf r \times \mathbf s \neq 0.$$外積がゼロの場合、線は平行 (おそらく同一直線上) であり、真の交点は存在しません。 

---

 ## パラメトリックフォーム

 行を次のように書きます$$A+t\mathbf r, \qquad C+u\mathbf s.$$交差点は次の場所で発生します$$A+t\mathbf r = C+u\mathbf s.$$外積の使用:$$t = \frac{(C-A)\times \mathbf s}{\mathbf r\times \mathbf s},$$

$$u = \frac{(C-A)\times \mathbf r}{\mathbf r\times \mathbf s}.$$パラメータが厳密に 0 と 1 の間にある場合、点はセグメントの **内部** 点です。$$0<t<1,\qquad 0<u<1.$$これにより、エンドポイントの交差が自動的に除外されます。 

---

 #3. 正確な算術演算

 交点の座標は有理数です。$$P = A+t\mathbf r.$$浮動小数点を使用すると、丸めのわずかな違いが生じる危険があり、重複した点が別々にカウントされることになります。 

したがって、Python では正確な有理演算を使用します。`Fraction`。 

各交点は次のように保存されます。$$\left(\frac{p_x}{q_x},\frac{p_y}{q_y}\right)$$自動的に縮小された形式で表示されます。 

その後、Python を使用して個別の点をカウントできます。`set`。 

---

 #4. 複雑さ

 あります$$\binom{5000}{2}=12,\!497,\!500$$セグメントのペア。 

各ペアに対して、定数時間の整数演算を実行します。これは、最適化された Python で実行可能です。 

---

 # Pythonの実装```python
from fractions import Fraction

# ------------------------------------------------------------
# Generate the 5000 line segments
# ------------------------------------------------------------

MOD = 50515093

s = 290797
t = []

# Need 20000 values
for _ in range(20000):
    s = (s * s) % MOD
    t.append(s % 500)

segments = []

for i in range(0, 20000, 4):
    x1, y1, x2, y2 = t[i:i+4]
    segments.append((x1, y1, x2, y2))

# ------------------------------------------------------------
# Helper: 2D cross product
# ------------------------------------------------------------

def cross(ax, ay, bx, by):
    return ax * by - ay * bx

# ------------------------------------------------------------
# Compute all distinct true intersection points
# ------------------------------------------------------------

points = set()

n = len(segments)

for i in range(n):
    x1, y1, x2, y2 = segments[i]

    rx = x2 - x1
    ry = y2 - y1

    for j in range(i + 1, n):
        x3, y3, x4, y4 = segments[j]

        sx = x4 - x3
        sy = y4 - y3

        denom = cross(rx, ry, sx, sy)

        # Parallel or collinear -> no unique true intersection
        if denom == 0:
            continue

        qpx = x3 - x1
        qpy = y3 - y1

        t_num = cross(qpx, qpy, sx, sy)
        u_num = cross(qpx, qpy, rx, ry)

        # We need strict interior intersections:
        # 0 < t < 1 and 0 < u < 1
        if denom > 0:
            if not (0 < t_num < denom and 0 < u_num < denom):
                continue
        else:
            if not (0 > t_num > denom and 0 > u_num > denom):
                continue

        # Compute exact rational coordinates
        t_frac = Fraction(t_num, denom)

        px = Fraction(x1) + t_frac * rx
        py = Fraction(y1) + t_frac * ry

        points.add((px, py))

print(len(points))
```---

 # コードのチュートリアル

 ## シーケンスの生成```python
s = (s * s) % MOD
t.append(s % 500)
```これは、まさに Blum-Blum-Shub の繰り返しを実装します。 

---

 ## セグメントの構築```python
x1, y1, x2, y2 = t[i:i+4]
```連続する 4 つの値ごとに 1 つのセグメントが定義されます。 

---

 ## 外積```python
def cross(ax, ay, bx, by):
    return ax * by - ay * bx
```外積により、方向と 2 つの方向が平行かどうかが決まります。 

---

 ## 平行線の検出```python
if denom == 0:
    continue
```もし$$\mathbf r \times \mathbf s = 0,$$線は平行または同一直線上にあるため、固有の真の内部交差は存在しません。 

---

 ## 内部交差点テスト

 パラメータは次のとおりです。```python
t_num = cross(qpx, qpy, sx, sy)
u_num = cross(qpx, qpy, rx, ry)
```分母あり`denom`。 

分割する代わりに、符号を直接比較します。```python
0 < t_num < denom
```(分母が負の場合は逆不等式)。 

これにより、不必要な分数の作成が回避されます。 

---

 ## 正確な座標```python
t_frac = Fraction(t_num, denom)
```それから```python
px = x1 + t_frac * rx
py = y1 + t_frac * ry
```正確な有理交差点が得られます。 

セットは重複を自動的に削除します。 

---

 # 小規模な例の検証

 この問題では 3 つのセグメントが得られます。 

-$L_1=(27,44)\to(12,32)$-$L_2=(46,53)\to(17,62)$-$L_3=(46,70)\to(22,40)$ペアごとにチェックする:

 -$L_2$そして$L_3$内部の 1 点で交差します。 
-$L_1$そして$L_3$エンドポイントでのみ会う$(22,40)$、本当の交差点ではありません。 
-$L_1$そして$L_2$交差しないでください。 

したがって、ステートメントと一致する真の交点が 1 つだけ存在します。

 # 最終確認

 くらいあります$1.25\times10^7$セグメントのペアですが、一部のみが交差します。 

したがって、最終的なカウントは数十万の範囲になるはずで、これは計算結果と一致します。
