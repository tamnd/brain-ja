[プロジェクト オイラー問題 401](https://projecteuler.net/problem=401)

 ## 解決策

 **答え:**`281632621`計算したい$$\operatorname{SIGMA}_2(n)=\sum_{k=1}^n \sigma_2(k),$$どこ$$\sigma_2(k)=\sum_{d\mid k} d^2.$$ターゲットは$$\operatorname{SIGMA}_2(10^{15}) \pmod{10^9}.$$---

 # 数学的分析

 重要な点は、合計の順序を逆にすることです。 

定義上、$$\operatorname{SIGMA}_2(n) =\sum_{k=1}^n \sum_{d\mid k} d^2.$$数値を合計する代わりに$k$、約数の合計$d$。 

もし$d$分割する$k$、 それから$k=dm$。 

固定除数の場合$d$、の倍数$d$まで$n$は$$d,2d,3d,\dots,\left\lfloor \frac nd \right\rfloor d.$$それで$d^2$まさに貢献する$$\left\lfloor \frac nd \right\rfloor$$回。 

したがって、$$\boxed{ \operatorname{SIGMA}_2(n) = \sum_{d=1}^n d^2\left\lfloor \frac nd \right\rfloor }$$これが重要な変革です。 

---

 ## 単純な方法が不可能な理由

 のために$n=10^{15}$を反復して、$10^{15}$不可能です。 

私たちはこの事実を利用する必要があります。$$\left\lfloor \frac nd \right\rfloor$$ほんの約だけかかります$2\sqrt n$明確な価値観。 

---

 # 等商をグループ化する

 仮定してください$$q=\left\lfloor \frac nd \right\rfloor.$$それから全部$d$合間に$$\left[ \left\lfloor \frac n{q+1}\right\rfloor+1, \left\lfloor \frac nq\right\rfloor \right]$$同じ商を共有する$q$。 

したがって、範囲全体を一度に処理できます。 

公式が必要です$$\sum_{k=1}^m k^2 = \frac{m(m+1)(2m+1)}6.$$定義する$$S(m)=\frac{m(m+1)(2m+1)}6.$$それから$$\sum_{k=a}^b k^2 = S(b)-S(a-1).$$---

 # 複雑さの軽減

 しましょう$$r=\lfloor \sqrt n \rfloor.$$計算を 2 つの部分に分割します。 

1. 小さな約数を直接処理する$d\le r$2. 商ごとにグループ化された範囲で大きな約数を処理する

 これにより、$O(\sqrt n)$アルゴリズム。 

のために$n=10^{15}$、$$\sqrt n \approx 3.16\times 10^7,$$これは最適化された Python で実現可能です。 

---

 # Pythonの実装```python
from math import isqrt

MOD = 10**9
N = 10**15

def sum_squares(m):
    """Return 1^2 + 2^2 + ... + m^2."""
    return m * (m + 1) * (2 * m + 1) // 6

def sigma2_summatory(n):
    r = isqrt(n)
    ans = 0

    # Part 1:
    # Directly sum d^2 * floor(n/d) for d <= sqrt(n)
    for d in range(1, r + 1):
        ans += d * d * (n // d)
        ans %= MOD

    # Part 2:
    # Group all large d by equal quotient q = floor(n/d)
    for q in range(1, r + 1):

        # d values satisfying floor(n/d) = q
        lo = n // (q + 1) + 1
        hi = n // q

        # We only want d > sqrt(n),
        # since smaller ones were already counted.
        lo = max(lo, r + 1)

        if lo <= hi:
            block_sum = sum_squares(hi) - sum_squares(lo - 1)
            ans += q * block_sum
            ans %= MOD

    return ans % MOD

print(sigma2_summatory(N))
```---

 # コードのチュートリアル

 ##`sum_squares(m)`閉じた式を使用します$$1^2+2^2+\cdots+m^2 = \frac{m(m+1)(2m+1)}6.$$これにより、一定時間内の間隔合計が可能になります。 

---

 ## 最初のループ```python
for d in range(1, r + 1):
    ans += d * d * (n // d)
```計算します$$\sum_{d=1}^{\sqrt n} d^2\left\lfloor \frac nd\right\rfloor.$$---

 ## 2 番目のループ

 商ごとに$q$の完全な間隔を決定します。$d$そのような$$\left\lfloor \frac nd \right\rfloor=q.$$それらの間隔は次のとおりです。```python
lo = n // (q + 1) + 1
hi = n // q
```次に、その区間内のすべての正方形を一度に合計します。```python
block_sum = sum_squares(hi) - sum_squares(lo - 1)
```そして追加します$$q \times \sum d^2.$$---

 # 小さい値の検証

 のために$n=6$:$$\sigma_2(1)=1$$

$$\sigma_2(2)=1+4=5$$

$$\sigma_2(3)=1+9=10$$

$$\sigma_2(4)=1+4+16=21$$

$$\sigma_2(5)=1+25=26$$

$$\sigma_2(6)=1+4+9+36=50$$合計:$$1+5+10+21+26+50=113,$$問題文と一致します。
