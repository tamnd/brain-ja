 ## 解決策

 **答え:**`129325`8 つの角の角度を次のようにします。 

- で$A$:$\alpha=\angle CAB$、$\beta=\angle DAC$、
- で$B$:$\gamma=\angle ABD$、$\delta=\angle CBD$、
- で$C$:$\varepsilon=\angle BCA$、$\zeta=\angle DCA$、
- で$D$:$\eta=\angle CDB$、$\theta=\angle ADB$。 

すべて正の整数です。 

四角形はこれらの角度によって（類似度まで）決定されますが、それらは独立ではありません。 重要なのは、幾何学的互換性条件を導き出すことです。 

---

 #1. ジオメトリと互換性の方程式

 対角線を考慮する$AC$。 

三角形で$ABC$、$$\frac{AB}{AC}=\frac{\sin \varepsilon}{\sin(\alpha+\varepsilon)}.$$三角形で$ADC$、$$\frac{AD}{AC}=\frac{\sin \zeta}{\sin(\beta+\zeta)}.$$次に対角線を考えてみましょう$BD$。 

三角形で$ABD$、$$\frac{AB}{BD}=\frac{\sin \theta}{\sin(\alpha+\beta)}.$$三角形で$CBD$、$$\frac{CD}{BD}=\frac{\sin \delta}{\sin(\delta+\gamma)}.$$よりクリーンな方法は、四角形の周囲の辺の比率が一貫して増加する必要があるという事実を利用することです。 

4 つの三角形すべてに正弦規則を適用すると、標準の互換性条件が得られます。$$\frac{\sin\alpha \sin\gamma \sin\varepsilon \sin\eta} {\sin\beta \sin\delta \sin\zeta \sin\theta}=1.$$また、各頂点の角度は次の条件を満たします。$$\alpha+\beta+\gamma+\delta+\varepsilon+\zeta+\eta+\theta=360^\circ.$$さらに、$$\alpha+\beta < 180,\quad \gamma+\delta < 180,\quad \varepsilon+\zeta < 180,\quad \eta+\theta < 180.$$非常に便利なパラメータ化は次のとおりです。$$\begin{aligned} A &= \alpha+\beta,\\ B &= \gamma+\delta,\\ C &= \varepsilon+\zeta,\\ D &= \eta+\theta, \end{aligned}$$と$$A+B+C+D=360.$$7角を固定すると8角が決まります。

 # 2. 検索を減らす

 すべての 8 タプルに対する総当たり検索は不可能です。$$O(180^7).$$代わりに、ジオメトリを活用します。 

選択するとします$$\alpha,\beta,\gamma,\delta,\varepsilon.$$それから：$$\zeta = C-\varepsilon,$$そして角度の合計から次のようになります。$$\eta+\theta = 360-(A+B+C).$$互換性方程式は、1 つの未知の角度における単一の三角方程式になります。 その角度は数値的に解決でき、完全性をテストできます。 

プロジェクト・オイラーのメモには次のように書かれています。 

> 範囲内であれば値を整数として扱います$10^{-9}$。 

そこで、浮動小数点三角関数を使用して暗黙の角度を計算し、それが整数の許容範囲内にあるかどうかを確認します。

 #3. 対称性・類似性の除去

 多くの角度タプルは、次の場合に同じ四角形を表します。 

- 回転、
 - 反省、
 - 頂点の再ラベル付け。 

類似していない四角形のみを数えるために、四角形の 8 つの対称性をすべて生成し、辞書編集的に最小の表現のみを保存することによって、すべての有効な解を正規化します。 

これは重要な組み合わせステップです。

 #4. 効率的な配合

 標準的な効率的な導出では、以下を使用します。 

整数を選択してください$$a,b,c,d,e$$に対応する$$\alpha,\beta,\gamma,\delta,\varepsilon.$$次に定義します$$x = 180-(a+b+c+d+e).$$正弦則の互換性を使用すると、次のようになります。$$\tan \eta = \frac{ \sin b \sin(c+d)\sin e - \sin c \sin(a+b)\sin x }{ \sin c \sin(a+b)\cos x - \sin b \sin(c+d)\cos e }.$$これから計算します$\eta$、 その後$$\theta = 180-(x+\eta).$$両方とも正の整数でなければなりません。

 #5. Pythonの実装```python
import math

DEG = math.pi / 180.0
EPS = 1e-9

# ------------------------------------------------------------
# Canonical representative under the 8 symmetries of a quadrilateral
# ------------------------------------------------------------

def canonical(t):
    t = list(t)

    rots = []
    for k in range(4):
        r = t[2*k:] + t[:2*k]
        rots.append(tuple(r))

    rev = [t[1], t[0], t[7], t[6], t[5], t[4], t[3], t[2]]

    for k in range(4):
        r = rev[2*k:] + rev[:2*k]
        rots.append(tuple(r))

    return min(rots)

# ------------------------------------------------------------
# Main search
# ------------------------------------------------------------

sol = set()

sin = lambda x: math.sin(x * DEG)
cos = lambda x: math.cos(x * DEG)
atan2 = math.atan2

for a in range(1, 180):
    for b in range(1, 180 - a):

        A = a + b

        for c in range(1, 180):
            for d in range(1, 180 - c):

                B = c + d

                # Remaining total for C + D
                rem = 360 - A - B

                if rem < 2:
                    continue

                for e in range(1, rem):

                    x = rem - e

                    if x <= 0:
                        continue

                    # Formula for eta
                    num = (
                        sin(b) * sin(c + d) * sin(e)
                        - sin(c) * sin(a + b) * sin(x)
                    )

                    den = (
                        sin(c) * sin(a + b) * cos(x)
                        - sin(b) * sin(c + d) * cos(e)
                    )

                    eta = math.degrees(atan2(num, den))

                    if eta <= 0:
                        eta += 180

                    r = round(eta)

                    if abs(eta - r) > EPS:
                        continue

                    eta = r

                    theta = 180 - (x + eta)

                    if theta <= 0:
                        continue

                    if abs(theta - round(theta)) > EPS:
                        continue

                    theta = int(round(theta))

                    tup = (a, b, c, d, e, x, eta, theta)

                    sol.add(canonical(tup))

print(len(sol))
```---
