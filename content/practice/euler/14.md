[プロジェクト オイラー問題 14](https://projecteuler.net/problem=14)

 ## 解決策

 **答え:**`837799`開始番号を探します$n < 1{,}000{,}000$最長のコラッツ チェーンを生成します。 

各整数について:

 - もし$n$は偶数です:$n \to n/2$- もし$n$奇数です:$n \to 3n+1$重要な最適化は **メモ化** です。数値の連鎖の長さがわかったら、シーケンス全体を繰り返し再計算するのではなく、それを再利用します。 

例えば：$$13 \to 40 \to 20 \to 10 \to 5 \to 16 \to 8 \to 4 \to 2 \to 1$$もっている$10$条項。 

クリーンな Python ソリューション:```python
def collatz_length(n, cache):
    if n in cache:
        return cache[n]

    if n % 2 == 0:
        length = 1 + collatz_length(n // 2, cache)
    else:
        length = 1 + collatz_length(3 * n + 1, cache)

    cache[n] = length
    return length

cache = {1: 1}

best_n = 1
best_len = 1

for n in range(1, 1_000_000):
    length = collatz_length(n, cache)

    if length > best_len:
        best_len = length
        best_n = n

print(best_n)
```既知の結果を追跡する:

 -$13$長さを与える$10$- 検索が進むにつれて、より大きなレコードが表示されます
 - 100 万未満の最大チェーンは次の場所で発生します。$$837799$$チェーンの長さは$525$。 

**答え: 837799**
