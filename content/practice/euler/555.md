 ## 解決策

 **答え:**`208517717451208352`させて$$M(n)=M_{m,k,s}(n)= \begin{cases} n-s & (n>m),\\ M(M(n+k)) & (0\le n\le m). \end{cases}$$計算しなければなりません$$S(p,m)=\sum_{1\le s<k\le p} SF(m,k,s),$$どこ$SF(m,k,s)$はすべての不動点の合計です$M_{m,k,s}$。 

私たちは求められています$$S(10^6,10^6).$$---

 # ステップ 1 — 再帰を理解する

 機能を構造的に分析します。 

のために$n\le m$、 もし$n+k>m$の場合、最初の再帰呼び出しはすぐに再帰を終了します。$$M(n+k)=n+k-s.$$定義する$$d=k-s.$$それから$$M(n+k)=n+d.$$だから、$m-k<n\le m$、$$M(n)=M(n+d).$$ここで、追加を繰り返した場合に何が起こるかを考えてみましょう。$d$。 

やがて上を越えていきます$m$、その後、関数は減算して戻ります$s$。 

重要な所見は次のとおりです。 

- もし$d\nmid s$、プロセスは剰余クラスを循環し、固定点は存在しません。 
- もし$d\mid s$の場合、不動点は存在します。 

書く$$s=cd,\qquad k=(c+1)d.$$そうすれば、不動点は正確に$$m-s+1,\; m-s+2,\;\dots,\; m-s+d.$$それで:

 - 固定点の数 =$d$、
 - それらの合計は$$SF(m,k,s) = \sum_{i=1}^{d}(m-s+i).$$この合計を計算します。$$SF(m,k,s) = d(m-s)+\frac{d(d+1)}2.$$以来$s=cd$、$$SF = d(m-cd)+\frac{d(d+1)}2.$$---

 # ステップ 2 — 合計を再パラメータ化する

 なぜなら$$k=(c+1)d,$$すべての有効なペア$(k,s)$固定小数点は次のものに一意に対応します。 

-$d\ge1$、
 -$c\ge1$、
 -$(c+1)d\le p$。 

同様に、定義します$$t=c+1,$$それで$t\ge2$そして$$k=td,\qquad s=(t-1)d.$$それから$$SF = d\left(m-(t-1)d\right)+\frac{d(d+1)}2.$$簡略化:$$SF = \frac d2\Bigl(2m-(2t-3)d+1\Bigr).$$したがって$$S(p,m) = \sum_{d=1}^{p} \sum_{t=2}^{\lfloor p/d\rfloor} \frac d2\Bigl(2m-(2t-3)d+1\Bigr).$$---

 # ステップ 3 — 閉じた形式の内総和

 しましょう$$N=\left\lfloor\frac pd\right\rfloor.$$それから$$S(p,m) = \sum_{d=1}^{p} \left[ \frac{d(N-1)(2m+1+3d)}2 - d^2\left(\frac{N(N+1)}2-1\right) \right].$$これだけです$O(p)$、十分に速い$p=10^6$。 

---

 # ステップ 4 — Python の実装```python
def S(p, m):
    total = 0

    for d in range(1, p + 1):
        N = p // d
        cnt = N - 1

        total += (
            d * cnt * (2 * m + 1 + 3 * d) // 2
            - d * d * (N * (N + 1) // 2 - 1)
        )

    return total

# Verify the examples
print(S(10, 10))         # 225
print(S(1000, 1000))     # 208724467

# Required answer
print(S(10**6, 10**6))
```---
