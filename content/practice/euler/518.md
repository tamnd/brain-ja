[プロジェクト オイラー問題 518](https://projecteuler.net/problem=518)

 ## 解決策

 **答え:**`100315739184392`させて$$x=a+1,\qquad y=b+1,\qquad z=c+1.$$条件はこう言っています$x,y,z$等比数列を形成する：$$y^2=xz.$$以来$a,b,c$素数です、$$x,y,z>1.$$計算しなければなりません$$S(n)=\sum (a+b+c)$$すべての素数トリプルにわたって$(a,b,c)$満足のいく$$a<b<c<n,\qquad (a+1,b+1,c+1)\text{ geometric}.$$---

 #1. 数学的分析

 から始めます$$(b+1)^2=(a+1)(c+1).$$整数等比数列の標準パラメータ化は、比を最小項で記述することによって得られます。 

仮定する$$\frac{b+1}{a+1}=\frac{p}{q}$$と$\gcd(p,q)=1$、$p>q$。 

それから$$a+1=kq^2,\qquad b+1=kpq,\qquad c+1=kp^2$$ある整数に対して$k\ge1$。 

確かに、$$(kq^2)(kp^2)=(kpq)^2.$$したがって、有効なトリプルはすべて次の形式になります。$$a=kq^2-1,$$

$$b=kpq-1,$$

$$c=kp^2-1,$$と$$p>q,\qquad \gcd(p,q)=1.$$逆に、そのような構造はすべて自動的に幾何学的条件を満たします。 

したがって、問題は次のようになります。 

すべてのトリプルを検索する$$(kq^2-1,\;kpq-1,\;kp^2-1)$$それらはすべて素数以下です$n$。 

---

 ## 検索の境界を設定する

 以来$$c=kp^2-1<n,$$私たちは必要です$$kp^2<n.$$したがって、それぞれについて$p$、$$1\le k<\frac{n}{p^2}.$$また$1\le q<p$。 

これにより、検索の複雑さがおおよそわかります$$\sum_{p\le \sqrt n}\frac{n}{p^2}\cdot p = n\sum_{p\le \sqrt n}\frac1p = O(n\log\log n),$$それは簡単に実現可能です$10^8$速いふるいで。 

---

 #2. 効率的な素数性テスト

 以下のすべての素数を生成します$10^8$エラトステネスのふるいを使って。 

すると、素数検査は次のようになります。$O(1)$。 

それぞれについて$(p,q,k)$:

 1. コンピューティング$$A=kq^2-1,\quad B=kpq-1,\quad C=kp^2-1.$$2. 3 つすべてが素数であるかどうかを確認します。 
3.追加$$A+B+C$$現在の合計に。 

---

 #3. Pythonの実装```python
from math import gcd, isqrt

LIMIT = 10**8

# ---------------------------------------------------------
# Sieve of Eratosthenes
# ---------------------------------------------------------
is_prime = bytearray(b"\x01") * LIMIT
is_prime[0] = is_prime[1] = 0

for p in range(2, isqrt(LIMIT) + 1):
    if is_prime[p]:
        start = p * p
        step = p
        is_prime[start:LIMIT:step] = b"\x00" * (
            (LIMIT - 1 - start) // step + 1
        )

# ---------------------------------------------------------
# Enumerate all geometric-progressions
# ---------------------------------------------------------
total = 0

# p corresponds to the larger coprime parameter
for p in range(2, isqrt(LIMIT) + 1):

    max_k = (LIMIT - 1) // (p * p)

    for q in range(1, p):

        # ratio must be reduced
        if gcd(p, q) != 1:
            continue

        qq = q * q
        pq = p * q
        pp = p * p

        for k in range(1, max_k + 1):

            a = k * qq - 1
            b = k * pq - 1
            c = k * pp - 1

            # ordering automatically holds:
            # q^2 < pq < p^2 because p > q

            if is_prime[a] and is_prime[b] and is_prime[c]:
                total += a + b + c

print(total)
```---

```ブール素数テーブルを作成します。 

次に、標準ふるいによって複合材料が除去されます。 

前処理後:```python

```かどうか即座にわかります$x$プライムです。

 ## パラメータのトリプルを列挙する

 ループします:```python
for p in range(2, sqrt(LIMIT)):
```なぜなら$kp^2 < LIMIT$。 

それから：```python
for q in range(1, p):
```と```python
gcd(p, q) == 1
```比率を確実に下げるためです。 

各ペアごとに$(p,q)$、許容されるすべてを繰り返します$k$。 

---

 ## 素数の構築

 私たちは計算します```python
a = k*q*q - 1
b = k*p*q - 1
c = k*p*p - 1
```これにより、すべての幾何学的シーケンスが正確にパラメータ化されます。 

すべてが素数の場合、次を追加します。```python
total += a + b + c
```---

 #6. 最終検証

 次の理由により、検索ではすべての等比数列が独自にカバーされます。 

- すべての有理比は互いに素の整数に帰着します$p/q$、
 - すべての幾何学的トリプルには形があります$$(kq^2,\;kpq,\;kp^2),$$- 共正性により重複を防ぎます。
