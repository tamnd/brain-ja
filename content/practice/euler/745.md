[プロジェクト オイラー問題 745](https://projecteuler.net/problem=745)

 ## 解決策

 **答え:**`94586478`させて$$g(n)=\text{largest perfect square dividing } n.$$すべての正の整数は次のように一意に書くことができます。$$n = s\,t^2$$と$s$スクエアフリー。 したがって、$$g(n)=t^2.$$したがって、$$S(N)=\sum_{n\le N} g(n)      =\sum_{t\le \sqrt N} t^2 \cdot Q\!\left(\left\lfloor\frac N{t^2}\right\rfloor\right),$$どこ$Q(x)$自由平方整数を数えます$\le x$。 

メビウス反転を利用すると、$$Q(x)=\sum_{d^2\le x}\mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor.$$置換して並べ替えると、$$S(N) =\sum_{k\le \sqrt N} \left\lfloor \frac N{k^2}\right\rfloor \sum_{d\mid k} d^2\mu(k/d).$$内和はジョルダン合計関数です$J_2(k)$:$$J_2(k)=k^2\prod_{p\mid k}\left(1-\frac1{p^2}\right).$$したがって、問題は次のようになります$$S(N)=\sum_{k\le \sqrt N} J_2(k)\left\lfloor \frac N{k^2}\right\rfloor.$$私たちは計算します$J_2(k)$みんなのために$k\le 10^7$直線ふるいを使って。```python
from array import array

MOD = 1_000_000_007
N = 10**14
V = int(N**0.5)

# Linear sieve for Jordan totient J2(n)
J2 = array('Q', [0]) * (V + 1)
J2[1] = 1

primes = array('I')
is_comp = bytearray(V + 1)

for i in range(2, V + 1):

    if not is_comp[i]:
        primes.append(i)
        J2[i] = i * i - 1

    for p in primes:
        x = i * p
        if x > V:
            break

        is_comp[x] = 1

        if i % p == 0:
            # J2(ip) = J2(i) * p^2 when p divides i
            J2[x] = J2[i] * p * p
            break
        else:
            # multiplicative step
            J2[x] = J2[i] * (p * p - 1)

# Compute S(N)
ans = 0

for k in range(1, V + 1):
    ans += (N // (k * k)) * J2[k]
    ans %= MOD

print(ans)
```### ウォークスルー

 -`J2[n]`ジョーダン トーティメントを保管します$J_2(n)$。 
- 線形ふるいは、次の値までのすべての値を計算します。$10^7$。 
- 最後に評価します$$\sum_{k\le 10^7} J_2(k)\left\lfloor\frac{10^{14}}{k^2}\right\rfloor \pmod{1\,000\,000\,007}.$$### 小さな小切手

 のために$N=10$:$$S(10)=24$$のために$N=100$:$$S(100)=767$$問題文と一致します。
