[プロジェクト オイラー問題 357](https://projecteuler.net/problem=357)

 ## 解決策

 **答え:**`1739023853137`すべての正の整数を求めます$n \le 10^8$そのような$$d + \frac{n}{d}$$**すべての約数**の素数です$d$の$n$。 

計算しなければなりません$$\sum n.$$## 1. 数学的分析

 強い制約を導出してみましょう。 

### 主要な条件

 あらゆる約数について$d \mid n$、$$d + \frac{n}{d}$$プライムでなければなりません。 

約数は相補的なペアで提供されるため、次の値までの約数をテストするだけで済みます。$\sqrt n$。 

---

 ### 最初の観察:$d = n$取る$d=n$、$$n + \frac{n}{n} = n+1$$プライムでなければなりません。 

それで：

-$n+1$プライムです、
 - したがって$n$すべての人にとって平等です$n>1$。 

---

 ### 2 番目の観察:$d=1$取る$d=1$、$$1+n$$も素数でなければなりません - 同じ条件です。 

したがって、すべての有効な$n>1$を満たす:$$n+1 \text{ is prime}.$$これはすでに大幅な削減です。 

---

 ### 3 番目の観察:$d=p$素約数の場合

 仮定してください$p\mid n$。 

それから$$p + \frac{n}{p}$$プライムでなければなりません。 

ここで次の可能性を考えてみましょう$p^2 \mid n$。 

させて$$n = p^2m.$$除数を選択してください$$d = pm.$$それから$$d+\frac{n}{d} = pm+p = p(m+1).$$以来$n>1$、等しくない限り、これは複合です$p$、 不可能。 

したがって、次のようになります。 

### 重要な結果$$\boxed{n \text{ must be squarefree}}$$（を除外する$n=1$）。 

---

 ### 4 番目の観察:$d = p$もし$p\mid n$、$$p+\frac{n}{p}$$プライムでなければなりません。 

特に$p=2$、$$2+\frac n2$$プライムでなければなりません。 

これは非常に効果的な初期フィルターになります。 

---

 ### 戦略

 までの総当たり除数テスト$10^8$不可能です。 

私たちは観察結果を活用します。 

1.$n+1$プライムでなければなりません

 ⇒ 候補番号は$n=p-1$どこ$p$プライムです。 
2.$n$スクエアフリーである必要があります。 
3. すべての約数について$d$、

 かどうかをテストする$$d+\frac nd$$プライムです。 

以来$n$は正方形がなく、フィルタリング後はほとんどスパースであるため、これは実現可能になります。 

---

 ### 効率的な素数検索

 素数を次のようにふるいにかけます。$$10^8+1$$なぜなら、チェックされる最大値は$$d+\frac nd \le n+1.$$ブールふるいで得られるのは、$O(1)$素数性テスト。 

---

 ## 2. Python の実装```python
from math import isqrt

LIMIT = 100_000_000

def prime_sieve(n):
    """Boolean sieve: is_prime[x] tells whether x is prime."""
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            start = p * p
            sieve[start:n + 1:p] = b"\x00" * ((n - start) // p + 1)

    return sieve

# Build primality table up to LIMIT + 1
is_prime = prime_sieve(LIMIT + 1)

total = 0

# n = 1 works:
# divisors = {1}, and 1 + 1 = 2 is prime
total += 1

# Since n + 1 must be prime, candidates are p - 1
for p in range(3, LIMIT + 2, 2):
    if not is_prime[p]:
        continue

    n = p - 1

    # n must be squarefree and satisfy condition
    valid = True

    # Check every divisor d <= sqrt(n)
    root = isqrt(n)

    for d in range(2, root + 1):
        if n % d == 0:
            q = n // d

            # d + n/d must be prime
            if not is_prime[d + q]:
                valid = False
                break

            # squarefree test:
            if q % d == 0:
                valid = False
                break

    if valid:
        total += n

print(total)
```---
