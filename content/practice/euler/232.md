 ## 解決策

 **答え:**`0.83648556`させて

-$P(a,b)$= **プレイヤー 1 のターン**になったときにプレイヤー 2 が最終的に勝つ確率 (スコア付き)$$\text{Player 1}=a,\qquad \text{Player 2}=b.$$-$Q(a,b)$= **プレイヤー 2 の番**になったときに、プレイヤー 2 が最終的に勝つ確率。 

どちらかのプレイヤーが到達した場合、ゲームは直ちに終了します$100$ポイント:$$P(a,b)=Q(a,b)=0 \quad (a\ge 100),$$

$$P(a,b)=Q(a,b)=1 \quad (b\ge 100).$$私たちは求めています$$P(0,0).$$---

 #1. 数学的分析

 ## プレイヤー 1 の動き

 プレイヤー 1 は公正なコインを 1 枚投げます。 

- ヘッド ($\frac12$): プレイヤー 1 は 1 ポイントを獲得します。 
- テイルズ ($\frac12$）：意味がありません。 

その後、プレイヤー 2 の番になります。 

したがって$$P(a,b)=\frac12\,Q(a+1,b)+\frac12\,Q(a,b).$$---

 ## プレイヤー 2 の動き

 プレイヤー 2 は整数を選択します$T\ge1$。 

彼はコインを投げます$T$回。 

- 全表の確率:$$2^{-T}.$$- 成功すれば、彼は利益を得ます$$2^{T-1}$$ポイント。 
- そうでなければ、彼は何も得られません。 

プレイヤー 2 が移動すると、再びプレイヤー 1 の番になります。 

したがって、固定の場合、$T$、$$Q_T(a,b) = 2^{-T} P(a,b+2^{T-1}) + (1-2^{-T})P(a,b).$$プレイヤー 2 は常に最適なプレイを行うため、$$Q(a,b)=\max_{T\ge1} Q_T(a,b).$$---

 # 相互再帰の排除

 代役$$P(a,b)=\frac12Q(a+1,b)+\frac12Q(a,b)$$の式に$Q_T$。 

させて$$p=2^{-T},\qquad g=2^{T-1}.$$それから$$Q_T(a,b) = p\,P(a,b+g)+(1-p)P(a,b).$$また、$$P(a,b) = \frac12Q(a+1,b)+\frac12Q(a,b).$$代入:$$Q_T(a,b) = p\,P(a,b+g) + (1-p)\left(\frac12Q(a+1,b)+\frac12Q_T(a,b)\right).$$を解決する$Q_T(a,b)$:$$Q_T(a,b)\left(1-\frac12(1-p)\right) = p\,P(a,b+g)+\frac12(1-p)Q(a+1,b).$$したがって$$Q_T(a,b) = \frac{ p\,P(a,b+g)+\frac12(1-p)Q(a+1,b) }{ 1-\frac12(1-p) }.$$これをすべての状態に対して動的に計算します。 

---

 # なぜ小さいだけなのか$T$価値観が重要

 最大の有用な報酬は、すぐにゲームに勝つことができる最初の報酬です。 

ターゲットなので、$100$、$$2^{T-1}\ge100$$成功すればすでに勝利が保証されています。 

そのような最小のもの$T$は$8$なぜなら$$2^7=128.$$それでチェック中$T=1,\dots,8$で十分です。

 #2. Pythonの実装```python
N = 100

# P[a][b] = probability Player 2 wins
#           when it is Player 1's turn
#
# Q[a][b] = probability Player 2 wins
#           when it is Player 2's turn

P = [[0.0 for _ in range(N + 129)] for _ in range(N + 1)]
Q = [[0.0 for _ in range(N + 129)] for _ in range(N + 1)]

# Terminal states:
# If Player 2 already has >=100 points, he has won.
for a in range(N + 1):
    for b in range(100, N + 129):
        P[a][b] = 1.0
        Q[a][b] = 1.0

# Fill tables backwards
for a in range(99, -1, -1):
    for b in range(99, -1, -1):

        # Q(a+1,b), unless Player 1 already wins
        if a + 1 >= 100:
            next_q = 0.0
        else:
            next_q = Q[a + 1][b]

        best = 0.0

        # Try all meaningful T values
        for T in range(1, 9):

            p = 2.0 ** (-T)
            gain = 2 ** (T - 1)

            # P(a,b+gain)
            if b + gain >= 100:
                success_value = 1.0
            else:
                success_value = P[a][b + gain]

            # Derived closed-form recurrence
            numerator = (
                p * success_value
                + 0.5 * (1 - p) * next_q
            )

            denominator = 1 - 0.5 * (1 - p)

            value = numerator / denominator

            best = max(best, value)

        Q[a][b] = best

        # Player 1 turn recurrence
        P[a][b] = 0.5 * next_q + 0.5 * Q[a][b]

print("{:.8f}".format(P[0][0]))
```---
