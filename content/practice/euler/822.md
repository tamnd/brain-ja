[プロジェクト オイラー問題 822](https://projecteuler.net/problem=822)

 ## 解決策

 **答え:**`950591530`させて$$x_i(k)=i^{2^k}$$初期数値から得られる値とする$i$二乗した後$k$回。 

すべてのステップで、最小の現在値を選択し、それをもう一度 2 乗します。 

計算しなければなりません$$S(10^4,10^{16}) \pmod{1234567891}.$$---

 #1. 数学的分析

 それぞれについて$i$、 定義する$$L_i(k)=\log_2(\log x_i(k)).$$以来$$x_i(k)=i^{2^k},$$我々は持っています$$\log x_i(k)=2^k\log i,$$したがって$$L_i(k) =\log_2(2^k\log i) = k+\log_2(\log i).$$定義する$$c_i=\log_2(\log i).$$その後$k_i$二乗、「優先値」$i$単純に$$k_i+c_i.$$現在の最小値を二乗すると、優先度がちょうど 2 倍になります。$1$。 

したがって、プロセス全体は次のようになります。 

- 数字から始める$c_i$。 
- 各操作では最小の現在値が選択されます。 
- 値に置き換えます$+1$。 

これは古典的なバランス調整/注水プロセスです。 

---

 ## 最終カウントの構造

 すべての操作が完了した後、数値を計算するとします。$i$二乗された$k_i$回。 

次に、シーケンスから使用される値$i$は：$$c_i,\ c_i+1,\ c_i+2,\ \dots,\ c_i+k_i-1.$$アルゴリズムはグローバルに、$m$これらすべての等差数列の中で最小の要素。 

書く$$c_i=q_i+f_i,$$どこ$$q_i=\lfloor c_i\rfloor,\qquad 0\le f_i<1.$$十分な大きさの場合$Y$、$$k_i = Y-q_i$$すべてのユーザーに対して、さらに一部のインデックスに対して追加の操作が 1 つ追加される可能性があります。 

確かに、$$\sum_i (Y-q_i) = (n-1)Y-\sum_i q_i.$$させて$$B(Y)=(n-1)Y-\sum_i q_i.$$最大のものを選択してください$Y$そのような$$B(Y)\le m.$$次に定義します$$d=m-B(Y).$$その通り$d$インデックスはさらに 1 つの二乗、つまり最小の小数部分を持つインデックスを受け取ります。$f_i$。 

したがって：$$k_i= Y-q_i+\varepsilon_i,$$どこ$\varepsilon_i\in\{0,1\}$、 そして$\varepsilon_i=1$のために$d$最小$f_i$。

 #2. モジュール評価

 必要です$$\sum_{i=2}^{10000} i^{2^{k_i}} \pmod{1234567891}.$$させて$$M=1234567891.$$以来$M$プライムであり、$i<M$、

 フェルマーが与える$$i^{a\bmod (M-1)} \equiv i^a \pmod M.$$したがって、次のように計算します。$$e_i = 2^{k_i}\bmod (M-1),$$それから$$i^{e_i}\bmod M.$$---

 #3. Pythonの実装```python
from math import log, log2, floor

MOD = 1234567891

def solve(n, m):
    data = []
    sum_q = 0

    # Compute c_i = log2(log(i))
    for i in range(2, n + 1):
        c = log2(log(i))

        q = floor(c)
        f = c - q

        data.append((f, i, q))
        sum_q += q

    N = n - 1

    # Largest Y with base_count <= m
    Y = (m + sum_q) // N

    base_count = N * Y - sum_q
    extra = m - base_count

    # Smallest fractional parts get one extra operation
    data.sort()

    extra_indices = set(i for _, i, _ in data[:extra])

    ans = 0

    for f, i, q in data:
        k = Y - q

        if i in extra_indices:
            k += 1

        # exponent = 2^k mod (MOD-1)
        exponent = pow(2, k, MOD - 1)

        ans = (ans + pow(i, exponent, MOD)) % MOD

    return ans

# Checks from the statement
print(solve(5, 3))      # 34
print(solve(10, 100))   # 845339386

# Final problem
print(solve(10_000, 10**16))
```---
