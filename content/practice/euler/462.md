[プロジェクト オイラー問題 462](https://projecteuler.net/problem=462)

 ## 解決策

 **答え:**`5.5350769703e1512`させてください$3$-滑らかな数値は次のように書くことができます$$2^a3^b \qquad (a,b\ge 0).$$固定用$N$、 定義する$$\mathcal P_N=\{(a,b)\in \mathbb Z_{\ge0}^2 : 2^a3^b\le N\}.$$割り切れる関係は次のようになります。$$2^{a_1}3^{b_1}\mid 2^{a_2}3^{b_2} \iff a_1\le a_2 \text{ and } b_1\le b_2.$$それで$F(N)$は正確にポセットの線形拡張の数です$(\mathcal P_N,\le)$コンポーネントごとの順序で。 

---

 #1. フェラーズ図への変換

 それぞれについて$b$、 定義する$$\lambda_b = \left\lfloor \log_2\!\left(\frac{N}{3^b}\right)\right\rfloor + 1.$$それから漕ぎます$b$細胞が含まれています$$(a,b),\qquad 0\le a<\lambda_b.$$したがって、形状はフェラーズ図になります。$$\lambda=(\lambda_0,\lambda_1,\ldots).$$例：$N=20$。$$\lambda=(5,3,2),$$に対応する$$1,2,4,8,16;\quad 3,6,12;\quad 9,18.$$ポセットの順序は、まさにヤング図の順序です。 

したがって：$$F(N)=f^\lambda,$$形状の標準的な若いタブローの数$\lambda$。 

---

 #2. フック長の計算式

 フェラーズ形状の場合$\lambda$と$n$細胞、$$f^\lambda=\frac{n!}{\prod_{c\in\lambda} h(c)},$$どこ$h(c)$セルのフックの長さです$c$。 

したがって、$$F(N)=\frac{n!}{\prod h(c)}.$$---

 #3. 小さな例を検証する

 のために$N=20$、$$\lambda=(5,3,2), \qquad n=10.$$フックの長さは、$$\begin{matrix} 7&6&4&2&1\\ 4&3&1\\ 2&1 \end{matrix}$$誰の製品ですか$$7\cdot6\cdot4\cdot2\cdot1\cdot4\cdot3\cdot1\cdot2\cdot1=8064.$$したがって$$F(20)=\frac{10!}{8064}=450,$$ステートメントと一致します。 

のために$N=1000$、計算により次のことが得られます。$$F(1000)\approx 8.8521816557\times 10^{21},$$再び問題と一致します。

 #4. Pythonの実装```python
from math import log, floor, lgamma

def F_scientific(N):
    # Build the Ferrers shape
    rows = []
    b = 0
    p3 = 1

    while p3 <= N:
        rows.append(int(floor(log(N / p3, 2))) + 1)
        p3 *= 3
        b += 1

    # Total number of cells
    n = sum(rows)

    # Compute log10(product of hook lengths)
    hook_log10 = 0.0

    for r, length in enumerate(rows):
        for c in range(length):

            # cells to the right
            right = length - c - 1

            # cells below
            below = 0
            for rr in range(r + 1, len(rows)):
                if rows[rr] > c:
                    below += 1

            hook = right + below + 1
            hook_log10 += log(hook, 10)

    # log10(n!)
    log10_fact = lgamma(n + 1) / log(10)

    # log10(F)
    log10_F = log10_fact - hook_log10

    exponent = int(floor(log10_F))
    mantissa = 10 ** (log10_F - exponent)

    return mantissa, exponent

m, e = F_scientific(10**18)
print(f"{m:.10f}e{e}")
```---

 #5. コードのチュートリアル

 ### 形状の構築```python
rows.append(int(floor(log(N / p3, 2))) + 1)
```固定用$b$、これは有効な指数を数えます$a$そのような$$2^a3^b \le N.$$したがって、各行の長さは、許容される累乗の数と正確に一致します。$2$。 

---

 ### フックの長さ

 すべてのセルについて:```python
right = length - c - 1
below = number of later rows extending past column c
hook = right + below + 1
```これは標準的なヤングタブローフックの長さです。 

---

 ### 数値安定性

 数値は膨大なので、対数を計算します。$$\log_{10} F = \log_{10}(n!) - \sum \log_{10}(h).$$

`lgamma(n+1)`計算する$\log(n!)$正確に。
