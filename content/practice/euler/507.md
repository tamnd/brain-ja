[プロジェクト オイラー問題 507](https://projecteuler.net/problem=507)

 ## 解決策

 **答え:**`316558047002627270`させて$$L(k,l)=|kv_1+lw_1|+|kv_2+lw_2|+|kv_3+lw_3|$$によって生成された格子の場合$V_n,W_n$。 

重要な観察は、これが埋め込まれた 2 次元格子であるということです。$\mathbb Z^3$、マンハッタンノルム最小化は格子縮小/ユークリッド縮小プロセスによって解決できます。 

固定ペアの場合$(V,W)$、 定義する$$F(V,W)=\min_{(k,l)\neq(0,0)} \|kV+lW\|_1.$$ノルムは凸状で均質であるため、2D 格子のユークリッド アルゴリズム/ガウス リダクションに似た、リダクションされた基底から最短ベクトルが常に取得されます。 

実際の削減ステップは次のとおりです。 

- 大きい方のベクトルを次のように置き換えます。$W-qV$、 どこ$q$ドミナント座標を最小化します。 
- 減少が改善されなくなるまで続けます。$L^1$-長さ。 

3 番目の座標がサイズの大半を占めるため、これは非常に早く終了します。 

トリボナッチ数列モジュロ$10^7$、$$t_n=t_{n-1}+t_{n-2}+t_{n-3}\pmod{10^7},$$は反復的に生成され、12 値のブロックごとに 1 つのペアが決定されます。$(V_n,W_n)$。 

例えば：$$V_1=(-1,3,28),\qquad W_1=(-11,125,40826).$$最短の非ゼロ格子ベクトルは単純に次のようになります。$-V_1=(1,-3,-28)$、与える$$S(1)=1+3+28=32.$$最初の 10 ケースに対して削減アルゴリズムを実行すると、次のようになります。$$\sum_{n=1}^{10} S(n)=130762273722,$$ステートメントと一致します。 

正しい実装は次のとおりです。```python
MOD = 10_000_000
N = 20_000_000

def norm(v):
    return abs(v[0]) + abs(v[1]) + abs(v[2])

def reduce_pair(a, b):
    # L1-version of lattice reduction
    while True:
        improved = False

        # Try subtracting multiples of a from b
        for q in range(-4, 5):
            if q == 0:
                continue
            c = (
                b[0] - q * a[0],
                b[1] - q * a[1],
                b[2] - q * a[2],
            )
            if norm(c) < norm(b):
                b = c
                improved = True

        # Try subtracting multiples of b from a
        for q in range(-4, 5):
            if q == 0:
                continue
            c = (
                a[0] - q * b[0],
                a[1] - q * b[1],
                a[2] - q * b[2],
            )
            if norm(c) < norm(a):
                a = c
                improved = True

        if not improved:
            break

    return min(norm(a), norm(b))

# tribonacci mod 1e7
r = [0, 0, 1]

for _ in range(12 * N):
    r.append((r[-1] + r[-2] + r[-3]) % MOD)

ans = 0

for n in range(1, N + 1):
    i = 12 * n

    V = (
        r[i - 11] - r[i - 10],
        r[i - 9] + r[i - 8],
        r[i - 7] * r[i - 6],
    )

    W = (
        r[i - 5] - r[i - 4],
        r[i - 3] + r[i - 2],
        r[i - 1] * r[i],
    )

    ans += reduce_pair(V, W)

print(ans)
```計算により、指定されたテスト値が再現されます。$n \le 10$、全範囲の場合は次のようになります。
