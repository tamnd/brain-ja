[プロジェクト オイラー問題 298](https://projecteuler.net/problem=298)

 ## 解決策

 **答え:**`1.76882294`させて

-$L$= ラリーのスコア、
 -$R$= ロビンのスコア。 

計算しなければなりません$$\mathbb E(|L-R|)$$50ターン後。 

重要な点は、ゲームが **有限状態** であるということです。 

---

 #1. 数学的分析

 あらゆる場面で:

 - からの乱数$1,\dots,10$均一に描かれており、
 - 各プレイヤーは次のいずれかを行います。 

- 番号がすでに記憶されている場合はポイントを獲得します。または
 - 番号を挿入し、場合によっては古い番号を 1 つ削除します。 

プロセスを続行するために必要な唯一の情報は次のとおりです。 

1. ラリーの記憶状態、
 2. ロビンの記憶状態、
 3. 現在のスコア差$d=L-R$、
 4. ターン番号。 

---

 ## ラリーの戦略 (LRU)

 ラリーは、最近使用されていない番号を削除します。 

したがって、ラリーの記憶は順序付けられたタプルで表すことができます$$(a_1,a_2,\dots,a_k)$$最も新しいものから最も新しいものまで。 

番号がすでに存在する場合、その番号は末尾に移動されます。 

---

 ## ロビンの戦略 (FIFO)

 ロビンはメモリ内に最も長く保存されている番号を削除します。 

つまり、ロビンの記憶は、古いものから新しいものへ順番に並べられた単なるキューです。 

ヒットによって順序は**変更されません**。 

---

 # 状態圧縮

 実際のラベル$1,\dots,10$は無関係です。 

平等構造だけが重要です。 

たとえば、数字を含む州$$(3,7,9)$$そして$$(1,4,6)$$は同等です。 

したがって、遷移のたびに、正規にシンボルのラベルを付け直します。 

- 最初に出現するシンボル$\to 0$- 次の新しいシンボル$\to 1$-など

 これにより、状態空間が大幅に削減されます。 

---

 # 動的プログラミングの繰り返し

 定義する$$F(t,S_L,S_R,d)$$最終的な期待値として$|L-R|$ターン 50 以降の場合:

 - 回してください$t$、
 - ラリー状態$S_L$、
 - ロビンの状態$S_R$、
 - 現在のスコア差$d$。 

基本ケース:$$F(50,\cdot,\cdot,d)=|d|.$$遷移:

 次の可能な数字ごとに$x\in\{1,\dots,10\}$、

 - ラリーの記憶を更新し、
 - ロビンのメモリを更新します。 
- スコアの差を更新$$d' = d + (\text{Larry hit}) - (\text{Robin hit}),$$次に、同じ確率の 10 回の引き分けの平均を求めます。 

したがって、$$F=\frac1{10}\sum_x F(\text{next state}).$$メモ化は、到達可能なすべての状態を正確に計算します。 

---

 #2. Pythonの実装```python
from functools import cache

N = 50          # number of turns
NUMS = 10       # numbers 1..10
CAP = 5         # memory size

def canonicalize(lru, fifo):
    """
    Renumber symbols canonically so equivalent states merge.
    """
    mp = {}
    nxt = 0

    def conv(seq):
        nonlocal nxt
        out = []
        for x in seq:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])
        return tuple(out)

    return conv(lru), conv(fifo)

@cache
def dp(turn, lru, fifo, diff):
    """
    Expected final |L-R| from this state.
    """

    # after 50 turns
    if turn == N:
        return abs(diff)

    lru = list(lru)
    fifo = list(fifo)

    # currently used canonical symbols
    used = max([-1] + lru + fifo) + 1

    total = 0.0

    # existing symbols each represent one actual number
    choices = [(i, 1) for i in range(used)]

    # all unseen numbers are equivalent
    unseen = NUMS - used
    if unseen > 0:
        choices.append(("new", unseen))

    for x, weight in choices:

        value = used if x == "new" else x

        # ----- Larry (LRU) -----
        nlru = lru.copy()

        if value in nlru:
            l_hit = 1
            nlru.remove(value)
            nlru.append(value)
        else:
            l_hit = 0
            if len(nlru) == CAP:
                nlru.pop(0)
            nlru.append(value)

        # ----- Robin (FIFO) -----
        nfifo = fifo.copy()

        if value in nfifo:
            r_hit = 1
        else:
            r_hit = 0
            if len(nfifo) == CAP:
                nfifo.pop(0)
            nfifo.append(value)

        ndiff = diff + l_hit - r_hit

        clru, cfifo = canonicalize(tuple(nlru), tuple(nfifo))

        total += weight * dp(turn + 1, clru, cfifo, ndiff)

    return total / NUMS

answer = dp(0, (), (), 0)

print(f"{answer:.8f}")
```---

 #3. コードのチュートリアル

 ## 正規化```python
canonicalize(lru, fifo)
```シンボルの番号を一貫して付け直します。 

- 最初に見たシンボルは 0 になります。 
- 次は 1 になり、
 -など

 これにより、同等の状態がマージされ、DP が実行可能になります。 

---

 ## DP 状態```python
dp(turn, lru, fifo, diff)
```将来の期待値を格納します。 

パラメータ:

 -`turn`= 現在のラウンド、
 -`lru`= ラリーの記憶順序、
 -`fifo`= ロビンの記憶順序、
 -`diff = L - R`。 

---

 ## 既存の数字とまだ見ぬ数字

 現在、4 つの異なるラベルのみが表示されているとします。 

次に:

 - 既存の各ラベルは 1 つの実数に正確に対応します。 
- すべての目に見えない数字は同じように動作します。 

したがって、10 個の数値すべてを個別に分岐するのではなく、目に見えない数値を多重度のある 1 つの遷移に集約します。 

これにより、計算量が大幅に削減されます。 

---

 ## ラリーを更新しています

 ヒット時:```python
nlru.remove(value)
nlru.append(value)
```その番号は最後に使用されたものになるためです。 

失敗した場合:

 - いっぱいの場合は、最も最近使用されていないものを削除します。 
- 新しい番号を追加します。 

---

 ## ロビンを更新しています

 FIFO の動作:

 - ヒットしても何も起こりません。 
- 追加ミス、
 - いっぱいの場合は、最も古いものを削除します。

 #4. 検証

 期待は以下を満たさなければなりません:$$0 \le \mathbb E(|L-R|) \le 50.$$両方の戦略はかなり似ているため、予想される違いは小さいはずです。 

計算された値:$$1.76882294$$それはまったく合理的です。
