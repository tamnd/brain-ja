[プロジェクト オイラー問題 944](https://projecteuler.net/problem=944)

 ## 解決策

 **答え:**`1228599511`させて$E \subseteq \{1,2,\dots,n\}$。 要素$x\in E$に貢献する$\operatorname{sev}(E)$**別の**要素がある場合$E$で割り切れます$x$。 

固定用$x$、 させて$$m=\left\lfloor \frac{n}{x}\right\rfloor$$だからあります$m-1$他の倍数$x$で$\{1,\dots,n\}$。 

サブセットの数$E$どこ$x$エレベーターは次のとおりです。 

- 含む$x$、
 - 少なくとも 1 つを含める$m-1$他の倍数、
 - 残りの要素はすべて任意です。 

したがって、次のようになります。$$N_x = 2^{\,n-m}\left(2^{m-1}-1\right) = 2^{n-1}-2^{n-m}$$それで$$S(n) = \sum_{x=1}^{n} x\left(2^{n-1}-2^{n-\lfloor n/x\rfloor}\right)$$並べ替えると、はるかに高速に合計が得られます。$$S(n) = \sum_{d=2}^{n} 2^{n-d}\cdot \frac{\lfloor n/d\rfloor(\lfloor n/d\rfloor+1)}{2}$$これは次のように評価できます。$O(\sqrt n)$標準的なフロア分割間隔トリックを使用します。 

の値$\lfloor n/d\rfloor$間隔は一定です。 

クリーンな Python 実装:```python
import math

MOD = 1234567891
INV2 = (MOD + 1) // 2

def solve(n):
    D = math.isqrt(n)
    res = 0

    # Small d: direct
    p = pow(2, (n - 2) % (MOD - 1), MOD)

    for d in range(2, D + 1):
        q = n // d
        tri = (q * (q + 1) // 2) % MOD
        res += p * tri
        p = (p * INV2) % MOD

    res %= MOD

    # Large d grouped by equal floor(n/d)
    cache = {1: INV2}

    cur = D + 1
    pcur = pow(2, (n - cur) % (MOD - 1), MOD)

    for q in range(D - 1, 0, -1):
        R = n // q
        if R < cur:
            continue

        length = R - cur + 1

        if length not in cache:
            cache[length] = pow(INV2, length, MOD)

        ip = cache[length]

        tri = (q * (q + 1) // 2) % MOD
        interval_sum = (2 * pcur * (1 - ip)) % MOD

        res += interval_sum * tri
        pcur = (pcur * ip) % MOD
        cur = R + 1

    return res % MOD

print(solve(10**14))
```サンプルの確認:$$S(10)=4927$$これは問題文と一致します。 

のために$n=10^{14}$:

 **答え: 1228599511**
