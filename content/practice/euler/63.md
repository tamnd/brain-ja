[プロジェクト オイラー問題 63](https://projecteuler.net/problem=63)

 ## 解決策

 **答え:**`49`同時に次の条件を満たすすべての正の整数を求めます。 

-$n$-桁の数字、および
 -$n$力。 
つまり、次の形式の数値です。$$k^n$$そのような$k^n$まさに$n$数字。 

---

 # 数学的分析

 正の整数$x$まさに$n$桁が違う場合$$10^{n-1} \le x < 10^n.$$代わりの$x = k^n$:$$10^{n-1} \le k^n < 10^n.$$10 を底とする対数を計算します。$$n-1 \le n\log_{10} k < n.$$正しい不等式は常に次の場合に当てはまります$k<10$、そのときだから$\log_{10} k < 1$。 

左の不等式が重要です。$$n-1 \le n\log_{10} k.$$再配置:$$1 - \frac1n \le \log_{10} k.$$同様に、$$n(1-\log_{10} k)\le 1.$$したがって、固定ベースの場合$k$、許容される指数は次の条件を満たします$$n \le \frac{1}{1-\log_{10} k}.$$---

 ## どの塩基が考えられますか?

 もし$k \ge 10$、 それから$k^n$以上のものを持っています$n$数字なので無理です。 

もし$k=1$、 それから$1^n=1$、これは 1 桁しかないので、$n=1$動作します。 

したがって、必要なのは$$k = 1,2,\dots,9.$$それぞれについて$k\in\{1,\dots,9\}$、正の整数が何個あるか数えます$n$満足する$$10^{n-1}\le k^n.$$導出された不等式を使用すると、次のようになります。$$n \le \frac{1}{1-\log_{10} k}.$$したがって、有効な数は、$n$与えられた値に対する$k$は$$\left\lfloor \frac{1}{1-\log_{10} k} \right\rfloor.$$ここで次を計算します。 

|$k$| カウント |
 | --- | --- |
 | 1 | 1 |
 | 2 | 1 |
 | 3 | 1 |
 | 4 | 2 |
 | 5 | 3 |
 | 6 | 4 |
 | 7 | 6 |
 | 8 | 10 |
 | 9 | 21 |

 合計：$$1+1+1+2+3+4+6+10+21 = 49.$$---

 # Pythonの実装```python
import math

count = 0

# Bases only need to go from 1 to 9
for k in range(1, 10):

    # Maximum n satisfying:
    # n <= 1 / (1 - log10(k))
    max_n = int(1 / (1 - math.log10(k)))

    count += max_n

print(count)
```---

 # 例による検証

 問題は次のようになります。$$7^5 = 16807$$これは 5 桁の 5 乗です。 

また：$$8^9 = 134217728$$これは 9 桁の 9 乗です。 

上記の不等式には両方が含まれます。 

最終的な合計$49$塩基だけなので合理的です$1$–$9$機能し、ベース近くでカウントが急速に増加します$9$。
