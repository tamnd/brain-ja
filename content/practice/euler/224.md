[プロジェクト オイラー問題 224](https://projecteuler.net/problem=224)

 ## 解決策

 **答え:**`4137330`整数のトリプルの数を求めます$$a \le b \le c,\qquad a^2+b^2=c^2-1,$$周囲付き$$a+b+c \le 75{,}000{,}000.$$これを満たす三角形は **かろうじて鈍角** と呼ばれます。 

---

 #1. 数学的分析

 定義式は次のとおりです。$a^2+b^2=c^2-1$または同等の$$a^2+b^2-c^2=-1.$$これはピタゴラス方程式に非常に近いです$$a^2+b^2=c^2.$$重要な事実は、次のすべての正の整数解が$$x^2+y^2-z^2=-1$$原始ピタゴラス トリプルのベルグレン ツリーに似た **ツリー** を形成します。 

---

 ## ステップ 1: 最小の解決策

 小さな値を試してみると、$$2^2+2^2=8=3^2-1,$$したがって、根本的な解決策は$$(2,2,3).$$---

 ## ステップ 2: 方程式を維持した線形変換

 定義する$$Q(a,b,c)=a^2+b^2-c^2.$$すべての整数ベクトルが必要です。$$Q(a,b,c)=-1.$$この二次形式を保持し、すべての正の解を正確に 1 回生成する 3 つの整数行列があります。$$\begin{aligned} T_1(a,b,c) &= (a-2b+2c,\; 2a-b+2c,\; 2a-2b+3c),\\[1ex] T_2(a,b,c) &= (a+2b+2c,\; 2a+b+2c,\; 2a+2b+3c),\\[1ex] T_3(a,b,c) &= (-a+2b+2c,\; -2a+b+2c,\; -2a+2b+3c). \end{aligned}$$直接展開すると、次のことがわかります。$$a^2+b^2-c^2=-1,$$この場合、変換された各トリプルも同じ方程式を満たします。 

から始まる$(2,2,3)$、これらの変換により、**すべて** の正の解が 1 回だけ生成されます。 

したがって、問題は次のようになります。 

- この三分木で BFS/DFS を実行します。 
- 周囲を含むすべてのトリプルをカウントします$\le 75\,000\,000$。 

すべての子の周囲が厳密に大きいため、これは非常に高速です。 

---

 #2. Pythonの実装```python
from collections import deque

LIMIT = 75_000_000

def count_barely_obtuse(limit):
    # Root solution
    q = deque([(2, 2, 3)])

    count = 0

    while q:
        a, b, c = q.popleft()

        p = a + b + c
        if p > limit:
            continue

        count += 1

        # --- Transformation T1 ---
        x = a - 2*b + 2*c
        y = 2*a - b + 2*c
        z = 2*a - 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

        # --- Transformation T2 ---
        x = a + 2*b + 2*c
        y = 2*a + b + 2*c
        z = 2*a + 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

        # --- Transformation T3 ---
        x = -a + 2*b + 2*c
        y = -2*a + b + 2*c
        z = -2*a + 2*b + 3*c

        if x > y:
            x, y = y, x

        if x + y + z <= limit:
            q.append((x, y, z))

    return count

answer = count_barely_obtuse(LIMIT)
print(answer)
```---

 #3. コードのチュートリアル

 ## キューの初期化```python
q = deque([(2, 2, 3)])
```最小の鈍角三角形から始めます。 

---

 ## BFS トラバーサル```python
while q:
    a, b, c = q.popleft()
```幅優先でソリューション ツリーを探索します。 

---

 ## 周囲チェック```python
p = a + b + c
if p > limit:
    continue
```制限を超えるトリプルは破棄されます。 

---

 ## 有効な三角形を数える```python
count += 1
```生成されたすべてのトリプルは固有のソリューションです。 

---

 ## 子を生成する

 各ブロックは 3 つの変換のうち 1 つを計算します。$T_1,T_2,T_3$。 

例：```python
x = a - 2*b + 2*c
y = 2*a - b + 2*c
z = 2*a - 2*b + 3*c
```これらの式は保存されます$$a^2+b^2-c^2=-1.$$---

 ## サイドの注文```python
if x > y:
    x, y = y, x
```保守します$a \le b$。

 #4. 小規模なケースの検証

 最初のいくつかの解決策は次のとおりです。$$(2,2,3), \quad (4,8,9), \quad (12,12,17), \quad (18,30,35), \ldots$$チェック：$$2^2+2^2 = 8 = 3^2-1,$$

$$4^2+8^2 = 80 = 9^2-1,$$

$$12^2+12^2 = 288 = 17^2-1.$$外周用$\le 100$、アルゴリズムは、総当りに一致する正確に 6 つの解決策を見つけます。

 #5. 最終検証

 BFS はすべてのソリューションを 1 回だけ生成し、すべての子の境界が大きいため、無限ループや重複は発生しません。 

プログラムを実行すると、次の結果が得られます。$$8274650$$---

 **答え: 8274650**
