[プロジェクト オイラー問題 547](https://projecteuler.net/problem=547)

 ## 解決策

 **答え:**`11730879.0023`させて$$E(R)=\frac1{\operatorname{area}(R)^2}\iint_{R\times R} \|P-Q\|\,dP\,dQ$$領域内の 2 つの均一にランダムな点の間の予想される距離$R$。 

中空の正方形の層の場合、領域は次のようになります。$$L = O\setminus H,$$どこ

-$O$外側です$n\times n$四角、
-$H$削除されたものです$x\times y$矩形。 

計算しなければなりません$$S(n)=\sum_{\text{all laminae}} E(L).$$のために$n=40$, 閉じた形式の長方形積分を導出しない限り、強引な幾何積分は不可能です。 

---

 #1. 数学的分析

 ## ステップ 1 — 長方形ペアの積分

 定義する$$I(A,B)=\iint_{A\times B}\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}\,dA\,dB.$$それから$$E(R)=\frac{I(R,R)}{\operatorname{area}(R)^2}.$$それでラミナについては$L=O\setminus H$、$$I(L,L) = I(O,O)-2I(O,H)+I(H,H).$$したがって、すべては評価に帰着します$I$軸に揃えられた長方形の場合。 

---

 ## ステップ 2 — 逆誘導体

 しましょう$$r=\sqrt{x^2+y^2}.$$有用なアイデンティティとは、$$\frac{\partial^2}{\partial x\,\partial y} \left( \frac{xyr}{3} +\frac{x^3}{6}\operatorname{asinh}\frac{y}{x} +\frac{y^3}{6}\operatorname{asinh}\frac{x}{y} \right) =r.$$両方の変数をもう一度積分すると、4 次のプリミティブが得られます。$$Q(x,y)= \frac{x^4y}{24}\operatorname{asinh}\frac{y}{x} +\frac{xy^4}{24}\operatorname{asinh}\frac{x}{y} -\frac{x^4r}{60} +\frac{x^2y^2r}{20} -\frac{y^4r}{60}.$$そして、包含と除外を繰り返すことで、

 長方形の場合$$R_1=[a,b]\times[c,d], \qquad R_2=[e,f]\times[g,h],$$私たちは得る$$I(R_1,R_2) = \sum (-1)^{i+j+k+l} Q(x_i-u_j,\; y_k-v_l),$$どこ$$x_i\in\{a,b\}, \quad u_j\in\{e,f\}, \quad y_k\in\{c,d\}, \quad v_l\in\{g,h\}.$$これにより、評価数が 16 のみの正確な閉じた形式が得られます。 

---

 ## ステップ 3 — すべての層の列挙

 固定用$n$:

 - 穴の幅$x$:$1\le x\le n-2$、
 - 穴の高さ$y$:$1\le y\le n-2$、
 - 左オフセット$a$:$1\le a\le n-x-1$、
 - 下部オフセット$b$:$1\le b\le n-y-1$。 

各配置は、記載どおりの回転/反射を含めて個別にカウントされます。 

各層について:$$E(L) = \frac{ I(O,O)-2I(O,H)+I(H,H) }{ (n^2-xy)^2 }.$$これらすべての値を合計すると、次のようになります。$S(n)$。

 #2. Pythonの実装```python
import math

# Fourth-order primitive
def Q(x, y):
    x = abs(x)
    y = abs(y)

    r = math.hypot(x, y)

    val = 0.0

    if x > 0:
        val += x**4 * y * math.asinh(y / x) / 24.0

    if y > 0:
        val += x * y**4 * math.asinh(x / y) / 24.0

    val += (
        -x**4 * r / 60.0
        + x**2 * y**2 * r / 20.0
        - y**4 * r / 60.0
    )

    return val

# Rectangle pair integral
# rectangle format: (x1, x2, y1, y2)
def rect_pair_integral(R1, R2):

    a, b, c, d = R1
    e, f, g, h = R2

    xs = [a, b]
    us = [e, f]
    ys = [c, d]
    vs = [g, h]

    total = 0.0

    for i, X in enumerate(xs):
        for j, U in enumerate(us):
            for k, Y in enumerate(ys):
                for l, V in enumerate(vs):

                    total += (
                        (-1) ** (i + j + k + l)
                        * Q(X - U, Y - V)
                    )

    return total

def S(n):

    outer = (0, n, 0, n)

    # Cache repeated rectangle computations
    cache = {}

    def RP(A, B):
        key = (A, B)

        if key not in cache:
            cache[key] = rect_pair_integral(A, B)

        return cache[key]

    outer_outer = RP(outer, outer)

    total = 0.0

    for x in range(1, n - 1):
        for y in range(1, n - 1):

            # self-integral of hole depends only on x,y
            HH = RP((0, x, 0, y), (0, x, 0, y))

            area = n * n - x * y

            for a in range(1, n - x):
                if a + x > n - 1:
                    continue

                for b in range(1, n - y):
                    if b + y > n - 1:
                        continue

                    hole = (a, a + x, b, b + y)

                    I = (
                        outer_outer
                        - 2 * RP(outer, hole)
                        + HH
                    )

                    total += I / (area * area)

    return total

print(round(S(3), 4))
print(round(S(4), 4))
print(round(S(40), 4))

 ###`rect_pair_integral`16 コーナーの包含/除外式を使用します。$$\sum (-1)^{i+j+k+l}Q(\cdots).$$これはまさに評価します$$I(R_1,R_2).$$---

 ###`S(n)`すべての有効な内側の四角形の配置を列挙します。 

各層について:

 1. 計算する$I(O,O)$、
 2. 減算$2I(O,H)$、
 3.追加$I(H,H)$、
 4. 面積の二乗で割ります。 

次に、すべての層を合計します。
