[プロジェクト オイラー問題 853](https://projecteuler.net/problem=853)

 ## 解決策

 **答え:**`44511058204`させて$\pi(n)$ピサーノ周期モジュロを示します$n$、つまりフィボナッチ数列のモジュロの周期$n$。 

計算しなければなりません$$\sum_{\substack{n<10^9\\ \pi(n)=120}} n.$$---

 #1. 数学的分析

 ピサーノ時代に関する重要な事実は次のとおりです。 

## A. 乗法性

 もし$\gcd(a,b)=1$、 それから$$\pi(ab)=\operatorname{lcm}(\pi(a),\pi(b)).$$したがって、素数べき乗の周期がわかれば、すべての合成数は最小公倍数から導き出されます。 

---

 ## B. 主要な権限

 素数の場合$p\neq 2,5$、$$\pi(p^k)=p^{k-1}\pi(p).$$特殊な場合:$$\pi(2^k)=3\cdot 2^{k-1}\quad (k\ge1),$$

$$\pi(5^k)=20\cdot 5^{k-1}.$$---

 ## C. の場合$\pi(n)=120$、 それから$n\mid F_{120}$フィボナッチ数列モジュロなので、$n$毎回繰り返す$120$ステップ、$$F_{120}\equiv 0 \pmod n.$$したがって、すべての素数除算は$n$分けなければなりません$F_{120}$。 

今の要素$F_{120}$:$$F_{120} = 2^5\cdot 3^2\cdot 5\cdot 7\cdot 11\cdot 23\cdot 31\cdot 41\cdot 61\cdot 241\cdot 2161\cdot 2521\cdot 20641.$$次に、関連する各素数のピサーノ周期を計算します。 

---

 #2. プライム期間

 期間は次のとおりです。 

| プライム$p$|$\pi(p)$|
 | --- | --- |
 |$2$|$3$|
 |$3$|$8$|
 |$5$|$20$|
 |$7$|$16$|
 |$11$|$10$|
 |$23$|$48$|
 |$31$|$30$|
 |$41$|$40$|
 |$61$|$60$|
 |$241$|$240$|
 |$2161$|$80$|
 |$2521$|$120$|
 |$20641$|$240$|

 期間分割のみ$120$使用可能です。 

したがって：

-$23,241,20641$それらの期間には分割できない要素が含まれているため、不可能です$120$。 

したがって、許可される主力は次のとおりです。 

### の力$2$

$$\pi(2)=3,\quad \pi(4)=6,\quad \pi(8)=12,\quad \pi(16)=24.$$($2^5$すでに生理が来ている$48$実際にはまだ 120 を割っていますが、$32$分けない$F_{120}$; 同様に、因数分解では最大 5 までの指数のみが可能です。 直接計算による表示$32$期間を与える$48$、依然として原則として許可されていますが、$32\mid F_{120}$, したがって、それを含める必要があります。 慎重に再計算してみましょう。）

 正確な式を使用すると、次のようになります。$$\pi(2^k)=3\cdot 2^{k-1}.$$したがって：$$\pi(2)=3,\; \pi(4)=6,\; \pi(8)=12,\; \pi(16)=24,\; \pi(32)=48.$$すべて分割します$120$、 それで$2^k$と$k\le5$許可されています。 

### の力$3$

$$\pi(3)=8,\quad \pi(9)=24.$$($27$与える$72$、分割ではありません$120$。）

 ### の力$5$

$$\pi(5)=20.$$($25$与える$100$、分割ではありません$120$。）

 ### 残りの素数$$7\to16,\quad 11\to10,\quad 31\to30,\quad 41\to40,\quad 61\to60,\quad 2161\to80,\quad 2521\to120.$$---

 #3. すべてを構築する$n$許容されるすべての$n$形を持っています$$n = 2^a3^b5^c7^d11^e31^f41^g61^h2161^i2521^j$$指数は以下に制限されます。 

-$0\le a\le5$-$0\le b\le2$-$0\le c,d,e,f,g,h,i,j\le1$そして満足のいく$$\operatorname{lcm}(\pi(\text{each chosen prime power}))=120.$$これは小さな検索スペースなので、あらゆる可能性を列挙します。

 #4. Pythonの実装```python
from math import lcm

LIMIT = 10**9

# For each prime, list all allowed prime powers together with their Pisano periods.
choices = [
    [(1, 1), (2, 3), (4, 6), (8, 12), (16, 24), (32, 48)],
    [(1, 1), (3, 8), (9, 24)],
    [(1, 1), (5, 20)],
    [(1, 1), (7, 16)],
    [(1, 1), (11, 10)],
    [(1, 1), (31, 30)],
    [(1, 1), (41, 40)],
    [(1, 1), (61, 60)],
    [(1, 1), (2161, 80)],
    [(1, 1), (2521, 120)],
]

answer = 0

def search(index, current_n, current_period):
    global answer

    if current_n >= LIMIT:
        return

    if index == len(choices):
        if current_period == 120:
            answer += current_n
        return

    for value, period in choices[index]:
        search(
            index + 1,
            current_n * value,
            lcm(current_period, period)
        )

search(0, 1, 1)

print(answer)
```---
