[プロジェクト オイラー問題 345](https://projecteuler.net/problem=345)

 ## 解決策

 **答え:**`13938`これは古典的な **代入問題**です。 

- 各行から正確に 1 つの数字を選択する必要があります。 
- 選択した 2 つの数字が同じ列から来ることはできません。 
- **可能な最大額**が必要です。 

数学的に、行列が$A=(a_{ij})$、私たちは求めています$$\max_{\sigma \in S_n} \sum_{i=1}^{n} a_{i,\sigma(i)}$$どこ$S_n$の順列の集合です$\{0,1,\dots,n-1\}$。 

のために$15\times 15$マトリックス、全体的にブルートフォース$15!$順列は不可能です:$$15! \approx 1.3\times 10^{12}$$そこで、動的プログラミングが必要になります。 

---

 # 数学的分析

 しましょう:

 -$n = 15$-$dp(mask)$= によって表される列のセットにいくつかの行を割り当てた後に達成可能な最大合計`mask`。 

長さ 15 のビットマスクは、どの列がすでに使用されているかを表します。 

もし`mask`もっている$k$ビットが設定されている場合、すでに行が割り当てられています$0,1,\dots,k-1$。 

遷移:

 未使用の列ごとに$j$、$$dp(mask \cup \{j\}) = \max\left( dp(mask \cup \{j\}), \; dp(mask)+a_{k,j} \right)$$どこ$$k = \text{number of set bits in } mask$$状態の総数は次のとおりです。$$2^{15} = 32768$$各状態は最大 15 個の遷移を試行するため、複雑さはおよそ次のようになります。$$15 \cdot 2^{15} \approx 5\times 10^5$$それは小さいです。

n = len(matrix)

# dp[mask] = best sum achievable using columns in mask
dp = [-1] * (1 << n)
dp[0] = 0

for mask in range(1 << n):

    # Number of rows already assigned
    row = bin(mask).count("1")

    # If all rows assigned, skip transitions
    if row == n:
        continue

    # Try assigning current row to any unused column
    for col in range(n):

        # If column not used yet
        if not (mask & (1 << col)):

            new_mask = mask | (1 << col)

            dp[new_mask] = max(
                dp[new_mask],
                dp[mask] + matrix[row][col]
            )

answer = dp[(1 << n) - 1]

print(answer)
