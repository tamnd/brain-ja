 ## 解決策

 **答え:**`997651`## 1. 数学的分析

 以下の素数が必要です$10^6$これは **最も連続する素数の合計** として書くことができます。 

例えば：$$41 = 2+3+5+7+11+13$$これは 6 つの連続する素数を使用します。 

ブルートフォースアプローチは次のようになります。 

- 100 万未満のすべての素数を生成します。 
- 連続するすべてのサブシーケンスを試します。 
- 合計が素数かどうかを確認します。 

しかし、素朴にこれは遅すぎます。なぜなら、以下に数万の素数があるからです。$10^6$。 

### ステップ 1: すべての素数を効率的に生成する

 **エラトステネスのふるい**を使用して、100 万未満のすべての素数を生成します。 

あるのは次のとおりです。$$\pi(10^6)=78498$$素数は 100 万未満ですが、これは管理可能です。 

また、**セット**に保管します。$O(1)$素数検索。 

---

 ### ステップ 2: プレフィックス合計を使用した連続合計

 素数が次のとおりであるとします。$$p_0,p_1,p_2,\dots$$プレフィックス合計配列を定義します。$$S_k = \sum_{i=0}^{k-1} p_i$$と：$$S_0=0$$この場合、連続する素数和は次のようになります。$$p_i+p_{i+1}+\cdots+p_{j-1} = S_j-S_i$$これが重要な最適化です。 

合計を繰り返し再計算する代わりに、一定時間内に任意の間隔合計を取得できます。 

---

 ### ステップ 3: 最長の有効なチェーンを検索する

 **最大の長さ**を追求します$L$次のような:$$S_j - S_i$$は:

 1.未満$10^6$2.プライム

 一部の人にとっては$j-i=L$。 

最適化のアイデア:

 #### (a) 現在の最良のものよりも長いシーケンスのみをチェックする

 長さ 100 のシーケンスがすでに見つかっている場合は、100 未満の長さをチェックしても意味がありません。 

#### (b) 合計が 100 万を超えたら停止

 素数は増加しているため、合計が制限を超えると、間隔を延長しても増加するだけです。 

これにより、検索の効率が維持されます。 

---

 ## 2. Python の実装```python
LIMIT = 1_000_000

# -----------------------------
# Sieve of Eratosthenes
# -----------------------------
is_prime = [True] * LIMIT
is_prime[0] = is_prime[1] = False

for i in range(2, int(LIMIT ** 0.5) + 1):
    if is_prime[i]:
        for multiple in range(i * i, LIMIT, i):
            is_prime[multiple] = False

# List of primes
primes = [i for i, prime in enumerate(is_prime) if prime]

# Fast primality lookup
prime_set = set(primes)

# -----------------------------
# Prefix sums
# prefix[i] = sum of first i primes
# -----------------------------
prefix = [0]

for p in primes:
    prefix.append(prefix[-1] + p)

# -----------------------------
# Find longest consecutive sum
# -----------------------------
best_length = 0
best_prime = 0

n = len(primes)

for start in range(n):
    # No need to check lengths shorter than current best
    for end in range(start + best_length + 1, n + 1):

        current_sum = prefix[end] - prefix[start]

        # Stop if over limit
        if current_sum >= LIMIT:
            break

        # Check if prime
        if current_sum in prime_set:
            best_length = end - start
            best_prime = current_sum

print(best_prime)
```---
