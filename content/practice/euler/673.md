[プロジェクト オイラー問題 673](https://projecteuler.net/problem=673)

 ## 解決策

 **答え:**`700325380`させて$B$ベッドの配置を説明する巻き込みであり、$D$机の配置を説明するインボリューション。 

- 学生の場合$a,b$ルームメイトです、それでは$B(a)=b$そして$B(b)=a$。 
- 学生の場合$a$個室があるので、$B(a)=a$。 

デスクの場合も同様に、$D$。 

新しい割り当ては順列です$\sigma$。 

条件

 > 「ルームメイトはルームメイトのまま」

 意味:$$B(\sigma(k))=\sigma(B(k))$$あらゆる人にとって$k$、つまり$$\sigma B = B\sigma.$$同様に、デスクパートナーが一緒にいると、$$\sigma D = D\sigma.$$したがって、2 つのインボリューションと同時に通い合う順列をカウントする必要があります。$B,D$。 

---

 #1. グラフの構造

 各頂点が次のようなスチューデントのグラフを考えてみましょう。 

- 1 つの「ベッドエッジ」 (おそらくループ)、
 - 1 つの「デスクエッジ」 (おそらくループ)。 

なぜなら両方とも$B$そして$D$はインボリューションであり、すべての接続コンポーネントは次の 2 つのタイプのいずれかになります。 

## タイプ A — 交互サイクル

 ループは発生しません。 

エッジが交互になります$B,D,B,D,\dots$、つまり、コンポーネントの長さは偶数サイクルです$2m$。 

例：$$1 \xleftrightarrow{B} 2 \xleftrightarrow{D} 3 \xleftrightarrow{B} 4 \xleftrightarrow{D} 1.$$自己同型グループのサイズ:$$2m$$(エッジの色を維持する回転)。 

---

 ## タイプ B — 交互パス

 少なくとも 1 つのループが発生します。 

コンポーネントは、エッジの色が交互になるパスになります。 

エンドポイントの色に応じて次のようになります。 

- 反射は許可される場合と許可されない場合があります。 
- 自己同型群のサイズは次のいずれかです$1$または$2$。 

より正確には:

 - 奇数長のパス: 自己同型カウント$=1$、
 - エンドポイントの色が一致する偶数長のパス: 自己同型カウント$=2$。 

---

 # 2. すべての通勤順列を数える

 有効な置換:

 1. 同型接続コンポーネント全体を並べ替えることができます。 
2. 各コンポーネント内で、その自己同型性の 1 つを適用できます。 

したがって、コンポーネントタイプの場合、$T$- が発生する$m_T$回、
 - 自己同型カウントあり$a_T$、

 その場合、その貢献度は$$a_T^{m_T}\cdot m_T!.$$したがって：$$\boxed{ \prod_T a_T^{m_T}\,m_T! }$$モジュロ$999999937$。 

---

 #3. Pythonの実装```python
from collections import defaultdict

MOD = 999_999_937

def parse_pairs(filename):
    pairs = []
    with open(filename) as f:
        for line in f:
            line = line.strip()
            if line:
                a, b = map(int, line.split(","))
                pairs.append((a, b))
    return pairs

def count_permutations(n, bed_pairs, desk_pairs):
    # Build involutions
    B = list(range(n + 1))
    D = list(range(n + 1))

    for a, b in bed_pairs:
        B[a] = b
        B[b] = a

    for a, b in desk_pairs:
        D[a] = b
        D[b] = a

    visited = [False] * (n + 1)

    # Count component types
    type_count = defaultdict(int)
    type_aut = {}

    for start in range(1, n + 1):
        if visited[start]:
            continue

        # DFS component
        stack = [start]
        visited[start] = True
        comp = []

        while stack:
            v = stack.pop()
            comp.append(v)

            for u in (B[v], D[v]):
                if not visited[u]:
                    visited[u] = True
                    stack.append(u)

        k = len(comp)

        # Does component contain a loop?
        has_loop = any(B[v] == v or D[v] == v for v in comp)

        if not has_loop:
            # alternating cycle
            key = ("C", k)
            aut = k
        else:
            # alternating path
            if k % 2 == 1:
                # asymmetric
                key = ("P", k, "odd")
                aut = 1
            else:
                # possible reflection symmetry
                endpoint_type = "mixed"

                for v in comp:
                    if B[v] == v and D[v] != v:
                        endpoint_type = "B"
                        break
                    if D[v] == v and B[v] != v:
                        endpoint_type = "D"
                        break

                key = ("P", k, endpoint_type)
                aut = 2

        type_count[key] += 1
        type_aut[key] = aut

    # factorials
    fact = [1] * (n + 1)
    for i in range(2, n + 1):
        fact[i] = fact[i - 1] * i % MOD

    ans = 1

    for key, m in type_count.items():
        ans = ans * pow(type_aut[key], m, MOD) % MOD
        ans = ans * fact[m] % MOD

    return ans

# -------------------------
# Verification examples
# -------------------------

# n = 4 example
beds = [(2, 3)]
desks = [(1, 3), (2, 4)]
print(count_permutations(4, beds, desks))
# 2

# n = 6 example
beds = [(1, 2), (3, 4), (5, 6)]
desks = [(3, 6), (4, 5)]
print(count_permutations(6, beds, desks))
# 8
```---

 #4. コードのチュートリアル

 ## インボリューションの構築```python
B = list(range(n + 1))
D = list(range(n + 1))
```最初は、すべての生徒が自分自身 (個室/単一の机) にマップされます。 

次に、リストされた各ペアが交換されます。```python
B[a] = b
B[b] = a
```---

 ## 接続されたコンポーネントの検索

 によって生成されたグラフ$B$-エッジと$D$-edges は DFS で調査されます。 

各連結成分は 1 つの独立した対称係数を決定します。 

---

 ## コンポーネントの種類の検出```python
has_loop = any(B[v] == v or D[v] == v for v in comp)
```- ループなし$\Rightarrow$交互のサイクル、
 - それ以外の場合は代替パス。 

---

 ## 自己同型のカウント

 長さの周期$k$:$$a_T = k.$$対称パス:$$a_T = 2.$$非対称パス:$$a_T = 1.$$---

 ## 同一のコンポーネントを並べ替える

 コンポーネントタイプが発生した場合$m$場合によっては、それらを任意に並べ替えることもできます。$$m!$$それが答えに乗算されます。
