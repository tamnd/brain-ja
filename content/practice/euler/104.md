[プロジェクト オイラー問題 104](https://projecteuler.net/problem=104)

 ## 解決策

 **答え:**`329468`最初のフィボナッチ指数を求めます$k$次のような:

 - **最初の 9 桁**$F_k$パンデジタルです$1\text{-}9$、
 - および **最後の 9 桁**$F_k$パンデジタルもある$1\text{-}9$。 

9 桁の数字は、各桁が含まれていればパンデジタルです。$1,\dots,9$まさに一度。 

---

 # 数学的分析

 フィボナッチ数は次の条件を満たします$$F_n = F_{n-1}+F_{n-2}, \qquad F_1=F_2=1.$$関連する項には数十万の桁があるため、完全なフィボナッチ数を計算する単純なアプローチは実行不可能です。 したがって、**先頭**と**末尾**の数字を別々に扱います。 

---

 ## 1. 末尾の 9 桁

 最後の 9 桁を追跡するには、モジュラー演算を使用します。 

以来$$F_n \equiv F_{n-1}+F_{n-2}\pmod{10^9},$$私たちは以下のものだけを保管します：$$F_n \bmod 10^9.$$これにより、すべての計算が小さく高速に保たれます。 

各ステップで、最後の 9 桁がパンデジタルかどうかをテストします。```python
set(str(b).zfill(9)) == set('123456789')
```の`zfill(9)`先行ゼロが確実に保持されるようにします。 ゼロがあると、パンデジタル テストは自動的に不合格になります。 

---

 ## 2. 対数による先頭の数字

 重要な正体はビネーの公式です。$$F_n = \frac{\phi^n-\psi^n}{\sqrt5},$$どこ$$\phi=\frac{1+\sqrt5}{2}, \qquad \psi=\frac{1-\sqrt5}{2}.$$なぜなら$|\psi|<1$、大きい場合$n$、$$F_n \approx \frac{\phi^n}{\sqrt5}.$$10 を底とする対数を計算します。$$\log_{10}(F_n) \approx n\log_{10}(\phi)-\log_{10}(\sqrt5).$$これを次のように書きます$$\log_{10}(F_n)=I+f,$$どこ：

-$I$は整数部分、
 -$f\in[0,1)$小数部分です。 

それから$$F_n = 10^{I+f}=10^I\cdot 10^f.$$したがって、最初の 9 桁は次のようになります。$$\left\lfloor 10^{f+8}\right\rfloor.$$したがって、次のように計算します。```python
log_fk = k * log_phi - log_sqrt5
frac = log_fk - int(log_fk)
first9 = int(10**(frac + 8))
```かどうかをテストします`first9`パンデジタルです。 

これにより、巨大なフィボナッチ数自体を計算する必要がなくなります。 

---

 # Pythonの実装```python
from math import log10, sqrt

# Constants from Binet's formula
phi = (1 + sqrt(5)) / 2
log_phi = log10(phi)
log_sqrt5 = log10(sqrt(5))

# Target pandigital digit set
pan = set('123456789')

# Fibonacci values modulo 10^9
a, b = 1, 1
k = 2

while True:
    # Advance Fibonacci sequence modulo 10^9
    a, b = b, (a + b) % 10**9
    k += 1

    # Check trailing 9 digits
    if set(str(b).zfill(9)) == pan:

        # Approximate leading digits using logarithms
        log_fk = k * log_phi - log_sqrt5
        frac = log_fk - int(log_fk)

        # Extract first 9 digits
        first9 = int(10**(frac + 8))

        # Check leading 9 digits
        if set(str(first9)) == pan:
            print(k)
            break
```---

 # 最終確認

 このアルゴリズムは次の理由から非常に効率的です。 

- 末尾の数字はモジュラー演算を使用します。 
- 先頭の数字には対数が使用されます。 
- 巨大なフィボナッチ数は保存されません。 

問題ステートメントの既知のチェックポイントは一貫しています。 

-$F_{541}$：最初のパンデジタルテール、
 -$F_{2749}$：初のパンデジタルヘッド。 

アルゴリズムを実行すると、**両方**の条件を満たす最初のインデックスが生成されます。
