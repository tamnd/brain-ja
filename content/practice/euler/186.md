[プロジェクト オイラー問題 186](https://projecteuler.net/problem=186)

 ## 解決策

 **答え:**`2325629`ユーザーをグラフの頂点にします。$10^6$ノード。 

電話が成功するたびに、2 人のユーザー間に無向のエッジが追加されます。 

質問は次のように尋ねます。 

> 何回の呼び出しが成功した後、首相 (PM) を含む接続コンポーネントは番号を返します。$524287$、最初に少なくとも含めます$99\%$全ユーザーのうち？ 

あるので$10^6$ユーザーの皆様、PM の接続コンポーネントが少なくともサイズを持つ最初の瞬間を探します。$$0.99 \times 10^6 = 990000.$$したがって、自然なデータ構造は **素集合の共用構造** (Union–Find) になります。 

---

 #1. 数学的分析

 シーケンスは遅延フィボナッチ ジェネレーターによって生成されます。 

のために$1 \le k \le 55$、$$S_k = (100003 - 200003k + 300007k^3)\bmod 1000000.$$のために$k \ge 56$、$$S_k = (S_{k-24} + S_{k-55}) \bmod 1000000.$$それぞれの通話記録は、$$\operatorname{Caller}(n)=S_{2n-1}, \qquad \operatorname{Called}(n)=S_{2n}.$$発信者 = 着信済み (ミスダイヤル) の場合、通話は無視されます。 

それ以外の場合は、これら 2 人のユーザーの間にエッジを追加します。 

したがって、プロセスは次のとおりです。 

- ペアを生成する$(a,b)$、
 - 次の場合は無視します$a=b$、
 - 接続されたコンポーネントを結合します$a$そして$b$、
 - PM のコンポーネントのサイズを追跡します。 
- 到達したら停止します$990000$。 

---

 ## Union-Find が機能する理由

 各ユーザーが接続コンポーネントに属しているとします。 

間の通話が成功したとき$a$そして$b$:

 - すでに接続されている場合は何も変わりません。 
- それ以外の場合、2 つのコンポーネントがマージされます。 

Union-Find は以下をサポートします。 

-`find(x)`= を含むコンポーネントの代表$x$、
 -`union(x,y)`= コンポーネントをマージします。 
- コンポーネント サイズの追跡。 

パス圧縮とサイズ/ランクによる結合により、各操作は事実上一定時間になります。$$O(\alpha(n)),$$どこ$\alpha$は逆アッカーマン関数です。 

これは何百万もの操作に最適です。

 #2. Pythonの実装```python
MOD = 1000000
PM = 524287
TARGET = 990000

# ------------------------------------------------------------
# Lagged Fibonacci Generator
# ------------------------------------------------------------

S = [0] * 56  # use indices 1..55

for k in range(1, 56):
    S[k] = (100003 - 200003 * k + 300007 * k * k * k) % MOD

idx = 1

def next_S():
    global idx

    # First 55 values
    if idx <= 55:
        val = S[idx]
    else:
        # recurrence
        val = (S[(idx - 24 - 1) % 55 + 1] +
               S[(idx - 55 - 1) % 55 + 1]) % MOD

        # overwrite cyclic buffer
        S[(idx - 1) % 55 + 1] = val

    idx += 1
    return val

# ------------------------------------------------------------
# Union-Find
# ------------------------------------------------------------

parent = list(range(MOD))
size = [1] * MOD

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x

def union(a, b):
    ra = find(a)
    rb = find(b)

    if ra == rb:
        return

    # union by size
    if size[ra] < size[rb]:
        ra, rb = rb, ra

    parent[rb] = ra
    size[ra] += size[rb]

# ------------------------------------------------------------
# Main simulation
# ------------------------------------------------------------

successful_calls = 0

while True:

    caller = next_S()
    called = next_S()

    # misdial
    if caller == called:
        continue

    successful_calls += 1

    union(caller, called)

    pm_root = find(PM)

    if size[pm_root] >= TARGET:
        print(successful_calls)
        break
```---
