[プロジェクト オイラー問題 804](https://projecteuler.net/problem=804)

 ## 解決策

 **答え:**`4921370551019052`させて$$Q(x,y)=x^2+xy+41y^2.$$以来$g(n)$整数のペアの数を数えます$(x,y)$と$Q(x,y)=n$、 我々は持っています$$T(N)=\sum_{n=1}^N g(n)$$これはまさに、次を満たす整数格子点の数です。$$x^2+xy+41y^2 \le N,$$除く$(0,0)$（以来$n\ge 1$）。 

二次形式を書き換えます。$$4Q=(2x+y)^2+163y^2.$$したがって、整数のペアを数えます$(x,y)$そのような$$(2x+y)^2+163y^2\le 4N.$$固定の場合$y$、 させて$$r=\left\lfloor \sqrt{4N-163y^2}\right\rfloor.$$それから$t=2x+y$満たさなければなりません$|t|\le r$と同じパリティを持ちます$y$。 そのような数$t$は$$r + \mathbf{1}_{r\equiv y \pmod 2}.$$有効なすべての合計$y$を与える$O(\sqrt N)$アルゴリズム：```python
from math import isqrt

def T(N):
    M = 4 * N
    ymax = isqrt(M // 163)

    total = -1  # exclude (0,0)

    for y in range(ymax + 1):
        r = isqrt(M - 163 * y * y)
        count = r + ((r & 1) == (y & 1))

        total += count if y == 0 else 2 * count

    return total

print(T(10**3))   # 474
print(T(10**6))   # 492128
print(T(10**16))
```これにより、指定されたチェックが再現されます。 

-$T(10^3)=474$-$T(10^6)=492128$そして以下を計算します:$$T(10^{16}) = 4921370551019052.$$**答え: 4921370551019052**
