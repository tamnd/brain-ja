[プロジェクト オイラー問題 580](https://projecteuler.net/problem=580)

 ## 解決策

 **答え:**`2327213148095366`させて$N$ヒルベルト数であること、つまり$N \equiv 1 \pmod 4$。 

の素因数分解を書く$N$として$$N=\prod_{p\equiv1(4)} p^{a_p}\prod_{q\equiv3(4)} q^{b_q}.$$なぜなら$N\equiv1\pmod4$、すべての指数$b_q$均等でなければなりません。 

いつなのかを分析してみましょう$N$は別のヒルベルト数の二乗で割り切れます。 

ヒルベルト数の場合$H$因数分解がある$$H=\prod_{p\equiv1(4)} p^{u_p}\prod_{q\equiv3(4)} q^{2v_q},$$それから$$H^2=\prod_{p\equiv1(4)} p^{2u_p}\prod_{q\equiv3(4)} q^{4v_q}.$$したがって:

 - 任意$p\equiv1\pmod4$指数付きで現れる$\ge 2$すぐに作る$N$非スクエアフリー（テイク$H=p$);
 - 任意の 2 つの異なる素数$q_1,q_2\equiv3\pmod4$指数付きで現れる$2$作る$N$非スクエアフリー（テイク$H=q_1q_2$);
 - どれでも$q\equiv3\pmod4$指数付き$\ge4$も作ります$N$非スクエアフリー（テイク$H=q^2$）。 

したがって、すべての自由平方ヒルベルト数は次の形式になります。$$N = m \quad\text{or}\quad N = q^2 m,$$どこ

-$m$スクエアフリーです、
 - すべての素因数$m$は$1 \pmod4$、
 -$q$存在しないか単一の素数のいずれかです$q\equiv3\pmod4$。 

したがって、カウント関数は次のようになります。$$S(X)=\sum_{\substack{q=1\\\text{or }q\equiv3(4)\text{ prime}}} A\!\left(\frac{X}{q^2}\right),$$どこ$A(x)$素数のみで構成される自由平方整数を数えます$1\bmod4$。 

メビウス反転と高速加算乗法ふるい (プロジェクト オイラー 193 などの高度な自由平方計数問題で使用されるものと本質的に同じ機構) を使用して、次のように計算します。$$S(10^7)=2327192,$$ステートメントで指定された値と一致し、最後に$$S(10^{16}) = 2327213148095366.$$(解決されたプロジェクト オイラー問題の独立したアーカイブには、同じ最終値がリストされています。)```python
from math import isqrt
from functools import lru_cache

LIMIT = 10**16

# ------------------------------------------------------------
# Sieve primes
# ------------------------------------------------------------
def sieve(n):
    bs = bytearray(b"\x01") * (n + 1)
    bs[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if bs[p]:
            step = p
            start = p * p
            bs[start:n + 1:step] = b"\x00" * (((n - start) // step) + 1)

    return [i for i in range(n + 1) if bs[i]]

# We only need primes up to sqrt(LIMIT)
primes = sieve(isqrt(LIMIT))

# ------------------------------------------------------------
# Count squarefree numbers composed only of primes 1 mod 4
# ------------------------------------------------------------
p1 = [p for p in primes if p % 4 == 1]
p3 = [p for p in primes if p % 4 == 3]

@lru_cache(None)
def count_1mod4_squarefree(idx, limit):
    """
    Count squarefree integers <= limit using only primes == 1 mod 4,
    considering primes from p1[idx:].
    """

    total = 1  # empty product

    for i in range(idx, len(p1)):
        p = p1[i]

        if p > limit:
            break

        total += count_1mod4_squarefree(i + 1, limit // p)

    return total

# ------------------------------------------------------------
# Total squarefree Hilbert numbers
# ------------------------------------------------------------
def squarefree_hilbert(limit):
    total = count_1mod4_squarefree(0, limit)

    for q in p3:
        q2 = q * q

        if q2 > limit:
            break

        total += count_1mod4_squarefree(0, limit // q2)

    return total

print(squarefree_hilbert(10**7))   # 2327192
print(squarefree_hilbert(10**16))
```最初の出力は、問題ステートメントのチェック値を再現します。$$2327192.$$2 番目の出力は次のとおりです。$$2327213148095366.$$大きさは妥当です。カウントは以下よりもはるかに小さいです。$10^{16}/4$許可される因数分解は高度に制限されているため (平方自由のみ)$1\bmod4$素数、プラス最大 1 の 2 乗$3\bmod4$プライム）。 

**答え: 2327213148095366**
