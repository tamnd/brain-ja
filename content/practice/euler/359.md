[プロジェクト オイラー問題 359](https://projecteuler.net/problem=359)

 ## 解決策

 **答え:**`40632119`させて$$P(f,r)$$部屋を占有している人になる$r$床の上で$f$。 

計算しなければなりません$$\sum_{fr=71328803586048} P(f,r)$$そして最後を返します$8$数字。 

---

 ## 1. 数学的分析

 ### ステップ 1: 床の構造

 フロアが人から始まると仮定します$a$。 居住者をそのままにしておきます$$x_1=a,\ x_2,\ x_3,\dots$$連続入居者も満足できる構造$$x_n+x_{n+1}=k_n^2$$連続する正方形のシーケンスの場合。 

例から:

 - 1階:$1,3,6,10,\dots$

$$1+3=2^2,\quad 3+6=3^2,\quad 6+10=4^2$$- 2階:$2,7,9,16,\dots$

$$2+7=3^2,\quad 7+9=4^2,\quad 9+16=5^2$$- 3階:$4,5,11,14,\dots$

$$4+5=3^2,\quad 5+11=4^2,\quad 11+14=5^2$$したがって、各フロアには開始マスインデックスがあります$s$、 そして：$$x_{n+1}=(s+n-1)^2-x_n$$---

 ### ステップ 2: 各フロアの最初の居住者

 各フロアの最初の部屋で実験すると、次の結果が得られます。$$1,2,4,8,12,18,24,32,40,50,\dots$$これはパターンに従います$$P(f,1)=\left\lfloor \frac{f^2}{2}\right\rfloor$$（のために$f=1$、これは与えます$0$、したがって、フロア 1 は特殊なケースです）。 

また:

 - 奇数階の使用$s=f$、
 - 偶数床使用$s=f+1$。 

だから、$f>1$、$$a=\left\lfloor \frac{f^2}{2}\right\rfloor, \qquad s= \begin{cases} f & f\text{ odd}\\ f+1 & f\text{ even} \end{cases}$$---

 ### ステップ 3: クローズドフォーム$P(f,r)$漸化式を解くと次が得られます。 

奇妙な部屋の場合$r=2m-1$、$$P(f,r) = a+(m-1)(2s+2m-3)$$均等な部屋用$r=2m$、$$P(f,r) = -a+(s+m-1)^2+m(m-1)$$これらの式はすべての例を再現します。 

-$P(10,20)=440$-$P(25,75)=4863$-$P(99,100)=19454$その通り。 

---

 ### ステップ 4: 合計する約数

 すべての正の整数のペアが必要です$(f,r)$と$$fr=71328803586048$$因数分解:$$71328803586048 = 2^{27}3^{12}$$したがって、すべての約数は$$f=2^a3^b \quad (0\le a\le 27,\ 0\le b\le 12)$$そして$$r=\frac{N}{f}$$がある$$(27+1)(12+1)=364$$そんなペアたち。 

合計します$P(f,r)$それらすべてをモジュロで覆って$10^8$。 

---

 ## 2. Python の実装```python
from math import prod

MOD = 10**8
N = 71328803586048

def P(f, r):
    """Return P(f, r)."""

    # Floor 1 is special
    if f == 1:
        a = 1
        s = 2
    else:
        a = (f * f) // 2
        s = f if (f % 2 == 1) else (f + 1)

    if r % 2 == 1:
        # odd room: r = 2m - 1
        m = (r + 1) // 2
        return a + (m - 1) * (2 * s + 2 * m - 3)
    else:
        # even room: r = 2m
        m = r // 2
        return -a + (s + m - 1) ** 2 + m * (m - 1)

# Generate all divisors of N = 2^27 * 3^12
total = 0

for a in range(28):
    for b in range(13):
        f = (2 ** a) * (3 ** b)
        r = N // f
        total = (total + P(f, r)) % MOD

print(total)
```---

 ## 3. コードのチュートリアル

 1.**`P(f, r)`**

 - 最初の占有者を計算します。$$a=\left\lfloor \frac{f^2}{2}\right\rfloor$$- 開始スクエアインデックスを選択します$s$。 
- パリティに応じて閉じた形式を使用します。$r$。 
2. **除数の生成**

 - 以来$$N=2^{27}3^{12},$$すべての約数は、2 と 3 の累乗を選択することによって生成されます。 
3. **合計**

 - 各約数について$f$、計算する$$r=\frac{N}{f}$$- 追加$P(f,r)$モジュロ$10^8$。

 この式は、問題のサンプル値を正確に再現します。$$P(10,20)=440$$

$$P(25,75)=4863$$
