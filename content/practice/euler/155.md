[プロジェクト オイラー問題 155](https://projecteuler.net/problem=155)

 ## 解決策

 **答え:**`3857447`すべてのコンデンサに静電容量を持たせる$C$。 

結果として得られる静電容量はすべて次の有理数倍であるため、$C$、設定によって正規化します$C=1$。 

したがって、達成可能なすべての静電容量は正確な有理数になります。 

以下を定義します。$$S_n = \{\text{all capacitances achievable using exactly } n \text{ capacitors}\}$$そして$$D(n)=\left|\bigcup_{k=1}^n S_k\right|$$問題が求めているのは、$D(18)$。 

---

 # 数学的分析

 2 つのサブ回路に静電容量がある場合$x$そして$y$、その後:

 ## 並列接続

 静電容量は直接加算されます。$$C_{\text{parallel}} = x+y$$## 直列接続$$\frac1{C_{\text{series}}}=\frac1x+\frac1y$$それで$$C_{\text{series}}=\frac{xy}{x+y}$$したがって、すべての回路は以下から構築されます。$n$コンデンサは、コンデンサをサイズの空でない 2 つのグループに分割することで形成できます。$k$そして$n-k$、各グループから 1 つのサブ回路を構築し、それらを直列または並列に組み合わせます。 

したがって：$$S_n = \bigcup_{k=1}^{n-1} \left\{ x+y,\ \frac{xy}{x+y} \;\middle|\; x\in S_k,\ y\in S_{n-k} \right\}$$基本ケース:$$S_1=\{1\}$$すべての値は有理数であるため、分数を使用して正確に表します。 

---

 # 動的プログラミング戦略

 私たちは計算します$S_1,S_2,\dots,S_{18}$。 

それぞれについて$n$:

 - すべての分割を反復処理します$k$そして$n-k$、
 - すべてのペアを組み合わせる$x\in S_k$、$y\in S_{n-k}$、
- 入れる：

-$x+y$-$\dfrac{xy}{x+y}$セットに追加します (重複を自動的に削除するため)。 

便利な最適化:

 組み合わせるから$S_k$と$S_{n-k}$は対称なので、必要なのは以下だけです。$$k \le \frac n2$$これにより、作業が約半分に減ります。 

---

 # Pythonの実装```python
from math import gcd

N = 18

# S[n] = set of capacitances using exactly n capacitors
# Each capacitance stored as a reduced fraction (num, den)
S = [set() for _ in range(N + 1)]

# Base case: one capacitor => capacitance 1
S[1] = {(1, 1)}

# Global set of all distinct capacitances
all_values = {(1, 1)}

for n in range(2, N + 1):

    current = set()

    # Only need k <= n//2 because of symmetry
    for k in range(1, n // 2 + 1):

        other = n - k

        for a, b in S[k]:
            for c, d in S[other]:

                # -------------------------
                # Parallel:
                # a/b + c/d
                # -------------------------
                num = a * d + b * c
                den = b * d

                g = gcd(num, den)
                current.add((num // g, den // g))

                # -------------------------
                # Series:
                # (a/b * c/d) / (a/b + c/d)
                # = ac / (ad + bc)
                # -------------------------
                num = a * c
                den = a * d + b * c

                g = gcd(num, den)
                current.add((num // g, den // g))

    S[n] = current
    all_values |= current

print(len(all_values))
```---
