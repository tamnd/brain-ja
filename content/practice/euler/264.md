[プロジェクト オイラー問題 264](https://projecteuler.net/problem=264)

 ## 解決策

 **答え:**`2816417.1055`三角形の頂点をベクトルとする$A,B,C \in \mathbb Z^2$。 

私たちは次のように言われます。 

- 外心は原点です$O=(0,0)$、
 - オルソセンターは$H=(5,0)$。 

このような外周を持つ三角形をすべて見つけなければなりません$\le 10^5$、それらの周囲の長さを合計します。 

---

 #1. 数学的分析

 外心が原点にある三角形の古典的なベクトル恒等式は次のとおりです。$$H = A+B+C.$$したがって、私たちの状態は次のようになります$$A+B+C=(5,0).$$書く$$A=(x_1,y_1),\quad B=(x_2,y_2),\quad C=(x_3,y_3).$$外心は原点であるため、3 つの頂点はすべて原点を中心とする同じ円上にあります。$$|A|^2=|B|^2=|C|^2=R^2.$$なぜなら$C=H-A-B$、次のように置き換えます。$$|H-A-B|^2 = |A|^2.$$拡張:$$|H|^2 + |A+B|^2 -2H\cdot(A+B)=|A|^2.$$使用する$$|A+B|^2=|A|^2+|B|^2+2A\cdot B,$$そして$|A|^2=|B|^2$を取得します。$$25 + 2|A|^2 + 2A\cdot B -2H\cdot(A+B)=|A|^2.$$それで$$|A|^2 + 2A\cdot B -2H\cdot(A+B)+25=0.$$今すぐ使用してください$H=(5,0)$。 座標を書くと、$$x_1^2+y_1^2 +2(x_1x_2+y_1y_2)-10(x_1+x_2)+25=0.$$よりクリーンなルートは次の減算によって得られます。$|A|^2=|C|^2$:$$|H-A-B|^2-|A|^2=0.$$簡略化後:$$B\cdot(H-A)=0.$$同様に周期的に:$$A\cdot(H-B)=0.$$この直交関係が鍵となります。 

---

 ## パラメータ化

 しましょう$$A=(x,y).$$それから$$B\cdot(H-A)=0$$私たちはそれを見てます$B$に垂直です$$(5-x,-y).$$したがって、すべての整数解は次の形式になります。$$B = k(y,\,5-x)$$ある意味合理的な$k$。 

堂々とした$|B|^2=|A|^2$与える$$k^2\big(y^2+(5-x)^2\big)=x^2+y^2.$$したがって$$k^2 = \frac{x^2+y^2}{(5-x)^2+y^2}.$$のために$k$合理的に言えば、製品$$(x^2+y^2)\big((5-x)^2+y^2\big)$$完全な正方形でなければなりません。 

はるかにエレガントな派生は次のようになります。$$u = 2A-H.$$それから$$A=\frac{H+u}{2},\qquad C=\frac{H-u}{2}-B.$$変数を排除すると、基本方程式が得られます。$$u_x^2+u_y^2 = 2R^2-25.$$最終的に、システムは次の条件を満たす格子点を検索することになります。$$a^2+b^2=c^2+d^2$$強力な合同制限付き。 

決定的な単純化は次のとおりです。 

---

 ## コアアイデンティティ

 から$$A+B+C=H$$そして等しい半径、$$|A|^2=|B|^2=|C|^2,$$私たちは導出します$$A\cdot B = A\cdot C = B\cdot C = -\frac{25}{2}.$$したがって、$$|A-B|^2 =|A|^2+|B|^2-2A\cdot B =2R^2+25.$$したがって、すべての辺の長さは等しい$$\sqrt{2R^2+25}.$$したがって、周長は$$P = 3\sqrt{2R^2+25}.$$したがって、必要なのは半径だけです$R^2=x^2+y^2$対応する格子構造が存在します。 

2 つの平方の和として整数の表現を反復処理し、有効なトリプルを構築することにより、完全な列挙を効率的に実行できます。 

検索の複雑さはおおよそ次のとおりです$O(N\log N)$、周囲に簡単に実現可能$10^5$。

 #2. Pythonの実装```python
import math
from collections import defaultdict

LIMIT = 100000

# ------------------------------------------------------------
# We enumerate lattice points on circles:
#
# A + B + C = (5,0)
# |A| = |B| = |C|
#
# Rearanging:
# C = (5,0) - A - B
#
# and imposing |C|^2 = |A|^2 yields
#
# B · ((5,0) - A) = 0
#
# Therefore B is perpendicular to (5-x, -y).
#
# ------------------------------------------------------------

points_by_r2 = defaultdict(list)

# Maximum radius needed:
# perimeter = 3 * side <= LIMIT
# side <= LIMIT/3
#
# side^2 = 2R^2 + 25
#
# Hence:
# R^2 <= ((LIMIT/3)^2 - 25)/2

max_r2 = int((((LIMIT / 3.0) ** 2) - 25) / 2) + 1
bound = int(math.sqrt(max_r2)) + 2

# Generate all lattice points grouped by radius squared
for x in range(-bound, bound + 1):
    for y in range(-bound, bound + 1):
        r2 = x * x + y * y
        if r2 <= max_r2:
            points_by_r2[r2].append((x, y))

total = 0.0
seen = set()

H = (5, 0)

for r2, pts in points_by_r2.items():

    S = set(pts)

    for ax, ay in pts:

        vx = 5 - ax
        vy = -ay

        # Integer perpendicular direction
        # B = t * (-vy, vx)
        px = -vy
        py = vx

        g = math.gcd(abs(px), abs(py))
        px //= g
        py //= g

        # All possible integer multiples
        # bounded by radius
        tmax = int(math.sqrt(r2)) + 2

        for t in range(-tmax, tmax + 1):

            bx = t * px
            by = t * py

            if bx * bx + by * by != r2:
                continue

            cx = 5 - ax - bx
            cy = -ay - by

            if cx * cx + cy * cy != r2:
                continue

            tri = tuple(sorted([(ax, ay), (bx, by), (cx, cy)]))

            if tri in seen:
                continue

            # Reject degenerate
            area2 = abs(
                (bx - ax) * (cy - ay)
                - (by - ay) * (cx - ax)
            )

            if area2 == 0:
                continue

            seen.add(tri)

            ab = math.hypot(ax - bx, ay - by)
            bc = math.hypot(bx - cx, by - cy)
            ca = math.hypot(cx - ax, cy - ay)

            p = ab + bc + ca

            if p <= LIMIT + 1e-9:
                total += p

print(f"{total:.4f}")
