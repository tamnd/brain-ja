[プロジェクト オイラー問題 45](https://projecteuler.net/problem=45)

 ## 解決策

 **答え:**`1533776805`3 つの図形数列が与えられます。$$T_n=\frac{n(n+1)}2,\qquad P_n=\frac{n(3n-1)}2,\qquad H_n=n(2n-1)$$そして私たちは次のことを知っています:$$T_{285}=P_{165}=H_{143}=40755$$私たちは同時に三角形、五角形、六角形である **次の** 数を見つけなければなりません。 

---

 #1. 数学的分析

 ## ステップ 1 — 六角数と三角数の関係

 観察してください:$$H_n=n(2n-1)$$次に三角数と比較します。$$T_m=\frac{m(m+1)}2$$次のように設定すると、$$m=2n-1$$それから$$T_{2n-1} = \frac{(2n-1)(2n)}2 = n(2n-1) = H_n$$したがって、**すべての六角形の数は自動的に三角形になります**。 

したがって、3 つの条件をすべてチェックするのではなく、五角形でもある六角形の数を見つけるだけで済みます。 

---

 ## ステップ 2 — 五角形テスト

 数字を考えてみましょう$x$は五角形です:$$x=\frac{k(3k-1)}2$$両辺に次の値を掛けます$24$:$$24x = 12k(3k-1)$$1を追加:$$24x+1 = 36k^2-12k+1 = (6k-1)^2$$したがって：$$x \text{ is pentagonal} \iff 24x+1 \text{ is a perfect square}$$そして具体的には:$$\sqrt{24x+1}\equiv 5 \pmod 6$$したがって、それぞれの六角形の数について$H_n$、次のことをテストできます。$$24H_n+1$$は完全な正方形です。 

---

 ## ステップ 3 — 既知の解決策を検索する

 私たちは次のように言われます。$$H_{143}=40755$$したがって、次からチェックを開始します。$$n=144$$計算:$$H_n=n(2n-1)$$そしてそれが五角形であるかどうかをテストします。 

40755 の後の最初の一致は次のとおりです。$$1533776805$$---

 #2. Pythonの実装```python
import math

def is_pentagonal(x):
    """
    Check whether x is pentagonal.

    A number x is pentagonal iff:
        24*x + 1
    is a perfect square and congruent to 5 mod 6.
    """
    d = 24 * x + 1
    s = math.isqrt(d)

    return s * s == d and (1 + s) % 6 == 0

n = 144  # Start just after H_143

while True:
    # Hexagonal number
    h = n * (2 * n - 1)

    # Since every hexagonal number is triangular,
    # only test pentagonality.
    if is_pentagonal(h):
        print(h)
        break

    n += 1
```---
