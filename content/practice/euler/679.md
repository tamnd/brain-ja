 ## 解決策

 **答え:**`644997092988678`させて

-$S=\{\texttt{A},\texttt{E},\texttt{F},\texttt{R}\}$、
 - キーワードは$$\texttt{FREE},\quad \texttt{FARE},\quad \texttt{AREA},\quad \texttt{REEF}.$$番号を求めます$f(30)$長さ - 30 ワード以上$S$**各**キーワードが**1回だけ**含まれています。 

---

 #1. 数学的分析

 この問題は、古典的な有限状態動的計画法の問題です。 

主な観察結果は次のとおりです。 

1. すべてのキーワードには長さがある$4$。 
2. 新しい文字を追加してキーワードが作成されるかどうかは、最後の文字にのみ依存します。$3$すでに書かれた文字。 
3. 次の理由から、どのキーワードがすでに出現しているかを追跡する必要があります。 

- 各キーワードは少なくとも 1 回出現する必要があります。 
- どのキーワードも複数回出現することはできません。 

したがって、単語の歴史全体は次のように圧縮できます。 

- 最大でも現在の長さの接尾辞$3$、
 - 4 つのキーワードのうち、すでに出現しているものはどれですか。 

---

 ## 状態の表現

 次のようにして DP 状態を定義します。$$(\text{suffix}, b)$$どこ

-`suffix`最後の最大 3 文字です。 
-$b$出現したキーワードを4ビットマスクで記録したものです。 

たとえば:

 - ビット 0 = FREE が発生、
 - ビット 1 = FARE が発生しました。 
- ビット 2 = AREA が発生しました。 
- ビット 3 = REEF が発生しました。 

あるのは$$1+4+4^2+4^3 = 85$$可能なサフィックス、およびのみ$2^4=16$マスク。 

したがって、状態空間の合計は非常に小さいです。$$85 \times 16 = 1360.$$---

 ## 移行ルール

 私たちが州にいると仮定してください$$(\text{suffix}, b)$$そして文字を追加します$c\in S$。 

させて$$t = \text{suffix}+c.$$今:

 - もし$t$キーワードの 1 つで終わる場合、それを検出します。 
- そのキーワードが以前にすでに表示されていた場合、この遷移は無効です。 
- それ以外の場合は、対応するビットを設定します$b$。 

新しいサフィックスは、次の最後の 3 文字になります。$t$。 

---

 ## これが機能する理由

 キーワードの長さは 4 であるため、新しい文字を追加する場合、新しく作成できるキーワードは、新しい位置で終わる長さ 4 のサフィックスのみです。 

したがって、単語の古い部分を検査する必要はありません。 

これはまさに、部分文字列カウント問題に使用される標準的なオートマトン手法です。

 #2. Pythonの実装```python
from collections import defaultdict

# The four keywords
keywords = ["FREE", "FARE", "AREA", "REEF"]

# Alphabet
letters = "AEFR"

def transition(suffix, ch):
    """
    Append character ch to the current suffix.
    Return:
        (new_suffix, list_of_keywords_completed)
    """
    t = suffix + ch

    found = []

    for i, k in enumerate(keywords):
        if t.endswith(k):
            found.append(i)

    # Keep only the last 3 characters
    new_suffix = t[-3:]

    return new_suffix, found

# DP[state] = number of ways
# state = (suffix, mask)
dp = defaultdict(int)

# Start with empty word
dp[("", 0)] = 1

N = 30

for _ in range(N):

    ndp = defaultdict(int)

    for (suffix, mask), ways in dp.items():

        for ch in letters:

            new_suffix, found = transition(suffix, ch)

            new_mask = mask
            valid = True

            # Every keyword must occur at most once
            for idx in found:

                bit = 1 << idx

                # keyword already used -> invalid
                if new_mask & bit:
                    valid = False
                    break

                new_mask |= bit

            if valid:
                ndp[(new_suffix, new_mask)] += ways

    dp = ndp

# all four keywords seen exactly once
FULL = (1 << 4) - 1

answer = sum(
    ways
    for (suffix, mask), ways in dp.items()
    if mask == FULL
)

print(answer)
```---
