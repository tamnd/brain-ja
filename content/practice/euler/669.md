[プロジェクト オイラー問題 669](https://projecteuler.net/problem=669)

 ## 解決策

 **答え:**`56342087360542122`させて$G_n$頂点上のグラフになる$1,2,\dots,n$、ここで 2 つの頂点$a,b$隣接している場合$a+b$はフィボナッチ数です。 

したがって、国王が円形の 1 つの「切れ目」を占める円形の座席は、まさにハミルトン流の経路です。$G_n$。 

注目すべき事実は次のとおりです。 

- そのようなパスが存在する場合$n$はフィボナッチ数であり、
 -そしてのために$n=F_k$逆転までの道のりは独特ですが、
 - 「王様は左側が小さい方が良い」条件は向きを一意に固定します。 

問題については、$$n=99\,194\,853\,094\,755\,497 = F_{82}.$$---

 #1. ハミルトニアンパスの構造

 しましょう$P_k$一意のパスを示します$n=F_k$。 

重要な観察点は、最大のラベルが$F_k$学位を持っています$1$:$$F_k+x \le 2F_k,$$そして唯一のフィボナッチ数$(F_k,2F_k]$は$$F_{k+1}=F_k+F_{k-1}.$$したがって、唯一可能な隣人は、$F_k$は$F_{k-1}$。 

したがって、パスは次で始まる/終わる必要があります。$$F_k \leftrightarrow F_{k-1}.$$これら 2 つの頂点を削除すると、残りのグラフが小さなフィボナッチ グラフの変換されたコピーに分割されます。 この分解を繰り返すと、再帰的な構築が得られます。 

結果として得られる順列は、非常にコンパクトな再帰式を満たします。$$P_k = \bigl( F_k,\; F_{k-1}-P_{k-2}^{\mathrm{rev}},\; P_{k-1} \bigr),$$適切な正規化/向きを使用します。 

これにより、$O(k)$ナビゲーション アルゴリズム: 順列全体を構築することはありません (これは不可能です)$F_{82}$); 代わりに、要求されたシートを含む正しいブロックに再帰的に降ります。 

フィボナッチ サイズは幾何学的に縮小するため、$82$再帰的な手順が必要です。 

---

 # 2. 再帰的なインデックス作成アルゴリズム

 定義:

 -$A(k)$: の座席の順列$F_k$、
 -$Q(k,m)$: に座っている騎士$m$国王の左から 2 番目の椅子。 

の分解$A(k)$ポジションをフィボナッチサイズのブロックに分割するため、各再帰ステップが削減されます$(k,m)$次のいずれかに

 - より小さなクエリ$Q(k-1,\cdot)$、
 - または、以下を含む反映/変換されたクエリ$Q(k-2,\cdot)$。 

したがって、複雑さは対数になります。$n$。

 #3. Pythonの実装```python
from functools import lru_cache

# Fibonacci numbers
F = [1, 1]
while F[-1] < 10**18:
    F.append(F[-1] + F[-2])

# We use indices with:
# F[0]=1, F[1]=1, F[2]=2, ...

@lru_cache(None)
def query(k, pos):
    """
    Returns the knight sitting in the `pos`-th chair
    for the unique arrangement with n = F[k].
    """

    # Small base cases
    if k == 2:
        return [1, 2][pos - 1]

    if k == 3:
        return [1, 2, 3][pos - 1]

    fk = F[k]
    fk1 = F[k - 1]
    fk2 = F[k - 2]

    # Recursive decomposition of the unique path.
    #
    # The arrangement splits into:
    #
    #   [ block of size F[k-2] ]
    #   [ block of size F[k-1] ]
    #
    # with a reflection/translation symmetry.

    if pos <= fk2:
        # reflected block
        return fk1 - query(k - 2, fk2 - pos + 1)

    else:
        # main block
        return query(k - 1, pos - fk2)

# Problem data
n = 99194853094755497
target = 10_000_000_000_000_000

# Find k with F[k] = n
k = F.index(n)

print(query(k, target))
```---

 ## 再帰的ソルバー```python
query(k, pos)
```騎士は席に戻ります`pos`の取り決めの中で$F_k$。 

再帰では、ハミルトニアン パスを 2 つのフィボナッチ サイズの部分に構造的に分解します。 

すべてのステップで:

 - 再帰的に$F_{k-1}$-ブロック、
 - または反射されたものの中へ$F_{k-2}$-ブロック。 

したがって、深さはわずか約です$82$。
