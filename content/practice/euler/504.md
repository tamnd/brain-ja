[プロジェクト オイラー問題 504](https://projecteuler.net/problem=504)

 ## 解決策

 **答え:**`694687`ピックの定理を使用することが重要な観察です。 

頂点のある四角形の場合$$A(a,0),\quad B(0,b),\quad C(-c,0),\quad D(0,-d),$$その地域は$$\text{Area}=\frac{ab+bc+cd+da}{2}.$$境界上の格子点の数は$$B=\gcd(a,b)+\gcd(b,c)+\gcd(c,d)+\gcd(d,a).$$ピックの定理により、$$\text{Area} = I + \frac{B}{2} - 1,$$したがって、厳密に内部の格子点の数は次のようになります。$$I = \frac{ ab+bc+cd+da - \gcd(a,b)-\gcd(b,c)-\gcd(c,d)-\gcd(d,a) }{2} +1.$$次に、すべての 4 回転を数えます$(a,b,c,d)$と$1\le a,b,c,d\le 100$誰のために$I$は完全な正方形です。 

直接的な総当たり攻撃$100^4$このような場合は、最適化/事前計算を行うことで実現可能です。 

Python の検証:```python
from collections import Counter
from math import gcd

def solve(m):
    t = [[0]*(m+1) for _ in range(m+1)]

    for a in range(1, m+1):
        for b in range(1, m+1):
            t[a][b] = a*b - gcd(a, b)

    # Possible targets:
    # I = total/2 + 1 must be a square
    squares = set(i*i for i in range(150))
    targets = set(2*(s-1) for s in squares)

    # Precompute distributions
    X = [[None]*(m+1) for _ in range(m+1)]
    Y = [[None]*(m+1) for _ in range(m+1)]

    for b in range(1, m+1):
        for d in range(1, m+1):

            cx = Counter()
            cy = Counter()

            for a in range(1, m+1):
                cx[t[a][b] + t[d][a]] += 1

            for c in range(1, m+1):
                cy[t[b][c] + t[c][d]] += 1

            X[b][d] = cx
            Y[b][d] = cy

    ans = 0

    for b in range(1, m+1):
        for d in range(1, m+1):
            cx = X[b][d]
            cy = Y[b][d]

            for s, v in cx.items():
                for target in targets:
                    ans += v * cy.get(target - s, 0)

    return ans

print(solve(4))    # 42
print(solve(100))
```これにより、指定されたチェックが再現されます。$$m=4 \Rightarrow 42$$そしてのために$m=100$与える:$$694687$$**答え: 694687**
