[プロジェクト オイラー問題 321](https://projecteuler.net/problem=321)

 ## 解決策

 **答え:**`2470433131948040`させて$M(n)$赤と青のカウンターを交換するために必要な最小移動数になります。 

## 1. 数学的分析

 これは古典的な「カウンター交換」（またはカエルとヒキガエル）パズルです。 

のために$n$両側にカウンターがある場合、最小移動数は次のとおりです。$$M(n)=n(n+2)$$これは次の例で確認できます。$$M(3)=3(3+2)=15$$これは問題文と一致します。 

私たちはそれらを求めています$n$そのような$M(n)$は三角数です。 

三角数の形式は次のとおりです。$$T_k=\frac{k(k+1)}{2}$$したがって、必要です$$n(n+2)=\frac{k(k+1)}{2}$$2 を掛けると:$$2n(n+2)=k(k+1)$$拡大する：$$2n^2+4n=k^2+k$$### ペル方程式に変換する

 しましょう$$x=2k+1,\qquad y=n+1$$それから$$x^2=(2k+1)^2=4k^2+4k+1$$そして$$8y^2=8(n+1)^2=8n^2+16n+8$$減算:$$x^2-8y^2 = (4k^2+4k+1)-(8n^2+16n+8)$$使用する$$k^2+k=2n^2+4n$$私たちは得ます$$x^2-8y^2=-7$$したがって、次の正の整数解が必要です。$$x^2-8y^2=-7$$と$$n=y-1.$$最初の関連ソリューションは次のとおりです。$$(5,2)\Rightarrow n=1$$

$$(11,4)\Rightarrow n=3$$それ以降のすべての解は、基本ペル単位を乗算することによって生成されます。$$3+\sqrt 8.$$もし$$x+y\sqrt8$$解決策です、次は$$(3+\sqrt8)(x+y\sqrt8)$$これにより、次の繰り返しが得られます。$$x' = 3x+8y$$

$$y' = x+3y$$2 つの開始ブランチの使用$(5,2)$そして$(11,4)$、結果をマージして並べ替えます。$n=y-1$価値観。 

シーケンスは次のように始まります。$$1,\ 3,\ 10,\ 22,\ 63,\dots$$問題文と一致します。

 ## 2. Python の実装```python
def generate_branch(x, y, count):
    """Generate n-values from one Pell branch."""
    values = []

    for _ in range(count):
        values.append(y - 1)  # n = y - 1

        # Pell recurrence
        x, y = 3 * x + 8 * y, x + 3 * y

    return values

# Generate sufficiently many terms from both branches
branch1 = generate_branch(5, 2, 50)
branch2 = generate_branch(11, 4, 50)

# Merge, deduplicate, and sort
sequence = sorted(set(branch1 + branch2))

# Sum first 40 terms
answer = sum(sequence[:40])

print(answer)
```---

 ###`generate_branch(x, y, count)`これにより、次の解決策が生成されます。$$x^2 - 8y^2 = -7$$最初の解決策から始めます。 

-`values.append(y - 1)`Pell 変数を変換して戻します。$$n=y-1$$- 再発```python

```による乗算を適用します$3+\sqrt8$、次の解決策を生み出します。

```各ブランチから多くの用語を生成し、それらをマージし、重複を削除して並べ替えます。

 最初に生成される 5 つの値は次のとおりです。$$1,\ 3,\ 10,\ 22,\ 63$$合計は誰の$$99$$まさに与えられたとおりです。
