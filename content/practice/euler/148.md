重要なツールは **ルーカスの定理** です。 

---

 #1. 数学的分析

 ## ステップ 1 — ルーカスの定理

 プライムの場合$p$、$$\binom{n}{k} \not\equiv 0 \pmod p$$すべてのベースがあれば-$p$の桁$k$は最大でも次の対応する桁です$n$。 

書く$$n = n_r n_{r-1}\dots n_0 \quad \text{(base }7\text{)}.$$次に、行内の係数の数$n$で割り切れない$7$は$$\prod_{i=0}^{r}(n_i+1).$$なぜ？ 

各桁位置について$i$、数字$k_i$任意の整数を指定できます$$0 \le k_i \le n_i,$$正確に与える$n_i+1$独立した選択。 

したがって：$$f(n)=\#\{\text{entries in row }n\text{ not divisible by }7\} =\prod (n_i+1).$$---

 ## ステップ 2 — 小さな例

 テイク$n=6$。 

基地内$7$、$$6 = (6)_7.$$それで$$f(6)=6+1=7.$$実際、行 6 は次のとおりです。$$1,\ 6,\ 15,\ 20,\ 15,\ 6,\ 1$$そして7で割り切れるものはありません。 

---

 テイク$n=8$。$$8=(11)_7.$$したがって$$f(8)=(1+1)(1+1)=4.$$実際、行 8 には 7 で割り切れないエントリが 4 つだけあります。

 #2. 効率的に合計する

 必要です$$S(N)=\sum_{n=0}^{N-1} f(n),$$と$N=10^9$。 

---

 ## ステップ 3 — フルブロック

 すべての数値を最大でも次のように考慮します。$m$基本 7 桁:$$0 \le n < 7^m.$$それから$$S(7^m) = \sum_{n_0=0}^{6}\cdots\sum_{n_{m-1}=0}^{6} \prod (n_i+1).$$製品が分離するため:$$S(7^m) = \left(\sum_{d=0}^{6}(d+1)\right)^m.$$しかし$$1+2+3+4+5+6+7 = 28.$$したがって、$$S(7^m)=28^m.$$これが重要な単純化です。 

---

 #3. 再帰的数字 DP

 今書いてください$N$進数7。 

数字は最上位から最下位の順に処理されます。 

現在の数字が$d$、そして私たちはすでに乗法接頭辞を蓄積しました$P$。 

先頭の数字が小さい場合$x<d$:

 - 残りのポジション数:$$28^{\text{remaining digits}}$$- 現在の桁からの寄与:$$(x+1)$$- 前の数字からの寄与:$$P$$そこで追加します$$P \cdot (1+2+\cdots+d)\cdot 28^r.$$次に、次のように続けます。$$P \leftarrow P(d+1).$$---

 #5. Pythonの実装```python
def count_not_divisible(N, p=7):
    """
    Returns the number of entries not divisible by p
    in the first N rows of Pascal's triangle.
    """

    # Convert N to base p digits
    digits = []
    x = N
    while x > 0:
        digits.append(x % p)
        x //= p

    digits.reverse()

    # Precompute powers of 28
    # because sum_{d=0}^{6} (d+1) = 28
    powers = [1]
    for _ in range(len(digits)):
        powers.append(powers[-1] * 28)

    ans = 0
    prefix_product = 1
    m = len(digits)

    for i, d in enumerate(digits):
        remaining = m - i - 1

        # Sum of (x+1) for x = 0..d-1
        # = d(d+1)/2
        smaller_sum = d * (d + 1) // 2

        ans += (
            prefix_product
            * smaller_sum
            * powers[remaining]
        )

        # Extend prefix with actual digit
        prefix_product *= (d + 1)

    return ans

print(count_not_divisible(10**9))
```---

 ## メインループ

 各桁で:```python
smaller_sum = d * (d + 1) // 2
```なぜなら$$1+2+\cdots+d=\frac{d(d+1)}{2}.$$それから：```python
ans += prefix_product * smaller_sum * powers[remaining]
```この位置にある小さい桁のすべての数値をカウントします。 

ついに：```python
prefix_product *= (d + 1)
```有効なプレフィックスを拡張します。
