[プロジェクト オイラー問題 223](https://projecteuler.net/problem=223)

 ## 解決策

 **答え:**`61614848`させて$$a^2+b^2=c^2+1, \qquad a\le b\le c$$周囲付き$$a+b+c\le 25{,}000{,}000.$$すべての整数辺の「かろうじて鋭角な」三角形を数えたいと考えています。 

## 1. 数学的分析

 定義式を並べ替えます。$$a^2+b^2=c^2+1$$として$$a^2-1=c^2-b^2=(c-b)(c+b).$$定義する$$x=c-b,\qquad y=c+b.$$それから$$xy=a^2-1.$$以来$$b=\frac{y-x}{2},\qquad c=\frac{y+x}{2},$$私たちは以下を要求します：

 1.$x,y$同じパリティを持っています（つまり、$b,c$は整数です)、
 2.$x>0$、
 3.$a\le b$、つまり$$a \le \frac{y-x}{2}$$になる$$y-x\ge 2a.$$また、外周条件は次のようになります。$$a+b+c=a+y\le N,$$どこ$N=25{,}000{,}000$。 

したがって、それぞれの固定に対して$a$、約数を数えています$x\mid(a^2-1)$そのような$$x\le y=\frac{a^2-1}{x},$$

$$\frac{a^2-1}{x}-x\ge 2a,$$そして$$a+\frac{a^2-1}{x}\le N.$$なぜなら$y=(a^2-1)/x$の場合、制約は次のようになります。 

### 上限$x$から$y-x\ge 2a$:$$\frac{a^2-1}{x}-x\ge 2a.$$乗算する$x$:$$a^2-1\ge x^2+2ax.$$再配置:$$(x+a)^2\le 2a^2-1.$$したがって、$$x\le \sqrt{2a^2-1}-a.$$### 下限$x$周囲から:$$a+\frac{a^2-1}{x}\le N$$それで$$x\ge \frac{a^2-1}{N-a}.$$したがって、それぞれについて$a$、約数を数えます$x$の$a^2-1$狭間に横たわっている$$\left\lceil \frac{a^2-1}{N-a} \right\rceil \le x\le \left\lfloor \sqrt{2a^2-1}-a \right\rfloor,$$パリティ条件あり$x+y$平。 

### 特殊なケース$a=1$もし$a=1$、$$1+b^2=c^2+1 \Rightarrow b=c.$$したがって、すべての三角形$(1,b,b)$提供した作品$$1+2b\le N.$$それは貢献します$$\left\lfloor\frac{N-1}{2}\right\rfloor$$ソリューション。

 ## 2. Python の実装```python
from math import isqrt

N = 25_000_000
A_MAX = N // 3 + 1

def build_spf(limit):
    """Smallest prime factor sieve."""
    spf = list(range(limit + 1))

    for i in range(2, isqrt(limit) + 1):
        if spf[i] == i:  # i is prime
            for j in range(i * i, limit + 1, i):
                if spf[j] == j:
                    spf[j] = i

    return spf

spf = build_spf(A_MAX + 1)

# Special case a = 1
count = (N - 1) // 2

for a in range(2, A_MAX + 1):
    n = a * a - 1

    # Bounds on divisor x
    lower = (n + (N - a) - 1) // (N - a)
    upper = isqrt(2 * a * a - 1) - a

    # Factorise (a-1)(a+1)
    factors = {}

    for z in (a - 1, a + 1):
        while z > 1:
            p = spf[z]
            e = 0

            while z % p == 0:
                z //= p
                e += 1

            factors[p] = factors.get(p, 0) + e

    factor_items = list(factors.items())

    # Enumerate divisors <= upper
    stack = [(0, 1)]

    while stack:
        idx, cur = stack.pop()

        if idx == len(factor_items):
            if cur >= lower:
                y = n // cur

                # Same parity condition
                if ((cur + y) & 1) == 0:
                    count += 1
        else:
            p, e = factor_items[idx]
            value = 1

            for _ in range(e + 1):
                nxt = cur * value

                if nxt <= upper:
                    stack.append((idx + 1, nxt))
                else:
                    break

                value *= p

print(count)

 ## 3. コードのチュートリアル

 ### SPFふるい

 以下のすべての整数について**最小の素因数**を事前計算します。$$\frac{N}{3}$$以来$a \le N/3$。 

これにより、非常に高速な因数分解が可能になります。$a-1$そして$a+1$。 

### ループオーバー$a$それぞれについて$a$:

 - 計算する$$n=a^2-1$$- 有効な除数間隔を導出する$[L,U]$、
- 要素$$n=(a-1)(a+1),$$- 約数を生成する$x$の$n$まで$U$、
 - パリティと境界制約をチェックします。 

有効な各約数は、正確に 1 つの三角形に対応します。 

### 小規模な健全性チェック

 外周用$\le 100$、メソッドは次を含む 72 個の三角形を見つけます。$$(4,7,8), \quad (5,5,7), \quad (8,9,12), \quad (29,29,41),$$そして無限の家族$$(1,b,b).$$これは総当たり列挙に一致します。
