[プロジェクト オイラー問題 57](https://projecteuler.net/problem=57)

 ## 解決策

 **答え:**`153`の継続分数展開$\sqrt2$は$$\sqrt2 = 1 + \cfrac1{2+\cfrac1{2+\cfrac1{2+\cdots}}}.$$私たちは次のように尋ねられます。 

> 最初の 1000 個の収束 (展開) のうち、分子の桁数が分母より多い分数はいくつありますか?

 ---

 # 数学的分析

 収束者は次のとおりです。$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29},\dots$$それらを生成する体系的な方法が必要です。 

## 1. 再発の導出

 させてください$n$- 番目の収束値$$\frac{p_n}{q_n}.$$パターンを観察してください。$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29}.$$連分数構造は次のようになります。$$x_{n+1} = 1 + \frac1{1+x_n}.$$しかし、分子と分母については、さらに明確な再帰が直接行われます。 

から始まる$$\frac{p_n}{q_n},$$次の展開は$$1+\frac1{1+\frac{p_n}{q_n}} = 1+\frac{q_n}{p_n+q_n} = \frac{p_n+2q_n}{p_n+q_n}.$$したがって、$$p_{n+1}=p_n+2q_n,$$

$$q_{n+1}=p_n+q_n.$$初期値:$$p_1=3,\qquad q_1=2.$$---

 ＃＃２．再発の確認

 から$\frac32$:$$p_2 = 3 + 2\cdot2 = 7,$$

$$q_2 = 3+2 = 5.$$それで、私たちは得ます$\frac75$。 

次：$$p_3 = 7 + 2\cdot5 = 17,$$

$$q_3 = 7+5 = 12.$$もう一度修正します。 

---

 ## 3. 桁の比較

 何回数えなければなりません$$\text{digits}(p_n) > \text{digits}(q_n).$$正の整数の桁数$x$は$$\lfloor \log_{10}(x)\rfloor + 1,$$しかし、Python では単純に比較できます。```python
len(str(p)) > len(str(q))
```反復回数は 1000 回のみなので、これは完全に効率的です。 

---

 # Pythonの実装```python
# Project Euler Problem 57

# Initial convergent of sqrt(2)
p = 3  # numerator
q = 2  # denominator

count = 0

# Check the first 1000 expansions
for _ in range(1000):

    # Count cases where numerator has more digits
    if len(str(p)) > len(str(q)):
        count += 1

    # Generate next convergent:
    # p_{n+1} = p_n + 2*q_n
    # q_{n+1} = p_n + q_n
    p, q = p + 2*q, p + q

print(count)
```---

 # 小規模なケースの検証

 生成される最初のいくつかの収束は次のとおりです。$$\frac32,\ \frac75,\ \frac{17}{12},\ \frac{41}{29}, \frac{99}{70},\ \frac{239}{169},\ \frac{577}{408},\ \frac{1393}{985}.$$8 番目の収束は、分子の桁が分母の桁を超える最初の収束です。 

-$1393$：4桁
 -$985$：3桁

 したがって、再発は正しいです。 

1000 回の拡張に対して完全な計算を実行すると、次のようになります。$$153$$---

 結果は妥当です。このような桁オーバーフローは時折発生しますが、非常にまれではありません。 

**答え: 153**
