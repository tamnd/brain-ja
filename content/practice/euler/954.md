[プロジェクト オイラー問題 954](https://projecteuler.net/problem=954)

 ## 解決策

 **答え:**`736463823`数字を入れてみましょう$n$数字がある$d_i$小数点以下の位置$i$(最下位桁 = 位置$0$）。 数字を交換するとします$d_i=a$そして$d_j=b$。 新しい番号は次のようになります$$n' = n + (b-a)(10^i - 10^j).$$私たちが欲しいのは$n'$**決して**で割り切れない$7$、 その間$n$それ自体も次で割り切れません$7$。 

作業モジュロ$7$、 以来$10^k \bmod 7$周期性があり周期的である$6$、$$10^k \equiv (1,3,2,6,4,5,\ldots)\pmod 7.$$固定目標残余の場合$r=n\bmod 7\neq 0$、残基との位置間の交換$x=10^i\bmod 7$そして$y=10^j\bmod 7$場合は禁止されています$$r + (b-a)(x-y)\equiv 0 \pmod 7,$$同等に$$b \equiv a - r(y-x)^{-1}\pmod 7.$$したがって、各最終剰余について$r\in\{1,\dots,6\}$、数字 DP を構築できます。 

- 数字を左から右に処理します。 
- 現在の残りのモッドを追跡します$7$、
 - どの桁の剰余modを追跡する$7$6 つの位置の残基クラスのそれぞれにすでに出現しています。 
- スワップを生成して割り切れる数字を拒否します。$7$、
 - 「交換後に先頭にゼロを付けない」ルールを強制します。 

この DP はチェックを再現します。 

-$C(100)=74$-$C(10^4)=3737$必要に応じて。 

クリーンな Python 実装:```python
from functools import lru_cache

mods = [pow(10, i, 7) for i in range(13)]

def count_length(L):
    posmods = list(reversed(mods[:L]))  # MSD -> LSD
    total = 0

    for r in range(1, 7):

        # forbidden digit residues lookup
        block = [[None] * 7 for _ in range(7)]

        for x in range(1, 7):
            for y in range(1, 7):
                arr = [0] * 128

                diff = (y - x) % 7
                single = [0] * 7

                if diff:
                    inv = pow(diff, -1, 7)
                    k = (-r * inv) % 7
                    for m in range(7):
                        single[m] = 1 << ((m + k) % 7)

                for mask in range(128):
                    b = 0
                    mm = mask
                    while mm:
                        lsb = mm & -mm
                        m = lsb.bit_length() - 1
                        b |= single[m]
                        mm ^= lsb
                    arr[mask] = b

                block[x][y] = arr

        x0 = posmods[0]

        @lru_cache(None)
        def dp(i, rem, masks, msd_res):
            if i == L:
                return rem == r

            x = posmods[i]

            forbidden = 0
            tmp = masks

            for y in range(1, 7):
                forbidden |= block[x][y][tmp & 127]
                tmp >>= 7

            msd_forbidden = 0
            if i > 0 and (x0 - x) % 7:
                diff = (x0 - x) % 7
                inv = pow(diff, -1, 7)
                k = (-r * inv) % 7
                msd_forbidden = 1 << ((msd_res + k) % 7)

            ans = 0

            for d in range(10):
                if i == 0 and d == 0:
                    continue

                f = forbidden
                if i > 0 and d != 0:
                    f |= msd_forbidden

                dr = d % 7
                if (f >> dr) & 1:
                    continue

                nmasks = masks
                if i > 0:
                    shift = (x - 1) * 7
                    nmasks |= (1 << dr) << shift

                ans += dp(i + 1, (rem * 10 + d) % 7,
                          nmasks, msd_res)

            return ans

        for first_digit in range(1, 10):
            total += dp(1, first_digit % 7, 0,
                        first_digit % 7)

    return total

answer = sum(count_length(L) for L in range(1, 14))
print(answer)
```計算すると次のようになります。$$C(10^{13}) = 736463823.$$**答え: 736463823**
