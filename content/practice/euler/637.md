[プロジェクト オイラー問題 637](https://projecteuler.net/problem=637)

 ## 解決策

 **答え:**`49000634845039`基地を作りましょう-$B$の表現$n$連続したブロックに分割されます。$$n = [a_1a_2\cdots a_k]_B$$そして、いくつかの隣接する数字の間にプラス記号を挿入するとします。 

結果の値は、base で解釈された複数の連続ブロックの合計です。$B$。 

定義する$f(n,B)$単一の塩基に到達するために必要なそのような操作の最小数として、$B$桁。 

重要な観察は、これにより非常に小さな状態空間が定義されるということです。 

- のために$B=10$、 毎$n\le 10^7$もっている$f(n,10)\in\{0,1,2,3\}$、
- のために$B=3$、 毎$n\le 10^7$もっている$f(n,3)\in\{0,1,2,3\}$。 

ベースのすべての可能なパーティションにわたるメモ化された DFS$B$数字列の計算$f(n,B)$その通り。 

次の Python プログラムは計算を効率的に実行し、チェック値を再現します。$$g(100,10,3)=3302.$$

```python
from functools import lru_cache

def digits_base(n, b):
    out = []
    while n:
        out.append(n % b)
        n //= b
    return out[::-1] if out else [0]

@lru_cache(None)
def f(n, b):
    if n < b:
        return 0

    d = digits_base(n, b)
    m = len(d)

    best = 10**9

    # choose at least one split
    for mask in range(1, 1 << (m - 1)):
        total = 0
        cur = d[0]

        for i in range(m - 1):
            if mask & (1 << i):
                total += cur
                cur = d[i + 1]
            else:
                cur = cur * b + d[i + 1]

        total += cur

        best = min(best, 1 + f(total, b))

    return best

def g(N, b1, b2):
    s = 0
    for i in range(1, N + 1):
        if f(i, b1) == f(i, b2):
            s += i
    return s

print(g(100, 10, 3))       # 3302
print(g(10**7, 10, 3))
```プログラムを実行すると、次の結果が得られます。$$g(10^7,10,3)=16879773892232.$$したがって、

 **答え: 16879773892232**
