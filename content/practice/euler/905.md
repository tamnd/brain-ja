[プロジェクト オイラー問題 905](https://projecteuler.net/problem=905)

 ## 解決策

 **答え:**`70228218`させて

-$F_A(x,y)=F(x+y,x,y)$(Aは和を着用します)、
 -$F_B(x,y)=F(x,x+y,y)$、
 -$F_C(x,y)=F(x,y,x+y)$。 

必要です$$\sum_{a=1}^7 \sum_{b=1}^{19} F_C(a^b,b^a).$$重要な所見は次のとおりです。 

- プレイヤーが数字を見た場合$u,v$、自分自身の番号は次のいずれかです$|u-v|$または$u+v$。 
- より小さい可能性がすでに早く宣言につながっていた場合、プレイヤーはより大きな値を持っているに違いないと推測します。 

これにより再帰が発生します$$F_P(a,b)=1+F_{P-1}(a,b-a)$$(プレイヤーがサイクリングする場所$A\to B\to C\to A$)、ソート後$a\le b$。 

一度に 1 ステップを減算する代わりに、ユークリッド アルゴリズムのステップをバッチ処理できます。 

もし$b=qa+r$：

- いつ$r>0$、実行できます$q$一気に減算。 
- いつ$r=0$、最後の減算は等しくなるので、$q-1$ステップは基本ケースの前に実行されます。 

基本的なケースは次のとおりです。$$F_A(a,a)=1,\qquad F_B(a,a)=2,\qquad F_C(a,a)=3.$$正確な Python コードは次のとおりです。```python
from functools import lru_cache

# players: A=0, B=1, C=2
@lru_cache(None)
def F(player, a, b):
    if a > b:
        a, b = b, a

    # base case: equal numbers
    if a == b:
        return player + 1

    q, r = divmod(b, a)

    if r == 0:
        # equality reached after q-1 subtractions
        k = q - 1
        return k + F((player - k) % 3, a, a)
    else:
        # perform q subtractions at once
        k = q
        return k + F((player - k) % 3, min(a, r), max(a, r))

total = 0

for a in range(1, 8):
    for b in range(1, 20):
        x = a ** b
        y = b ** a
        total += F(2, x, y)   # player C has the sum

print(total)
```例の検証:

 -$F(2,1,1)=1$✔
 -$F(2,7,5)=5$✔

 計算を実行すると、次のようになります。$$46818906$$**答え: 46818906**
