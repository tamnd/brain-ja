[プロジェクト オイラー問題 697](https://projecteuler.net/problem=697)

 ## 解決策

 **答え:**`4343871.06`させて$$X_n = c\prod_{k=1}^n U_k,$$どこで$U_k$私は 一様確率変数$(0,1)$。 

私たちが欲しいのは$c$そのような$$\Pr(X_n<1)=0.25$$のために$n=10\,000\,000$。 

---

 # ステップ 1: 積を合計に変換する

 対数を取る：$$\ln X_n=\ln c+\sum_{k=1}^n \ln U_k.$$以来$0<U_k<1$、 定義する$$Y_k=-\ln U_k.$$標準的な事実は次のとおりです。$$Y_k \sim \text{Exp}(1),$$なぜなら$$\Pr(Y_k\le y)=\Pr(-\ln U_k\le y) =\Pr(U_k\ge e^{-y}) =1-e^{-y}.$$したがって$$-\sum_{k=1}^n \ln U_k = \sum_{k=1}^n Y_k.$$したがって、定義すると$$S_n=\sum_{k=1}^n Y_k,$$それから$$S_n \sim \Gamma(n,1),$$意地悪で$n$と分散$n$。 

また、$$X_n<1 \iff \ln c - S_n <0 \iff S_n>\ln c.$$したがって、条件は次のようになります$$\Pr(S_n>\ln c)=0.25.$$同様に、$$\Pr(S_n\le \ln c)=0.75.$$したがって、$\ln c$分布の 75 パーセンタイルです$\Gamma(n,1)$。 

---

 # ステップ 2: ガンマ分位数を近似する

 非常に大きい場合$n$、$$\Gamma(n,1)\approx N(n,n)$$中心極限定理による。 

させて$$z=\Phi^{-1}(0.75)=0.674489750196\ldots$$次に、Cornish-Fisher 展開により、75 パーセンタイルの正確な近似値が得られます。$$q \approx n + z\sqrt n + \frac{z^2-1}{3}.$$と$$n=10\,000\,000, \qquad \sqrt n = 3162.277660\ldots$$私たちは得ます$$q \approx 10\,000\,000 + 0.674489750196(3162.277660) + \frac{0.674489750196^2-1}{3}.$$数値的には、$$q \approx 10\,000\,002.411477.$$以来$q=\ln c$、$$\log_{10} c = \frac{\ln c}{\ln 10} = \frac{q}{\ln 10}.$$したがって$$\log_{10} c \approx 4343871.057176\ldots$$四捨五入すると$$4343871.06.$$---

 # Pythonの実装```python
import math
from statistics import NormalDist

# Problem parameter
n = 10_000_000

# 75th percentile of the standard normal distribution
z = NormalDist().inv_cdf(0.75)

# Cornish-Fisher approximation for Gamma(n,1) quantile
q = n + z * math.sqrt(n) + (z*z - 1) / 3

# Convert ln(c) to log10(c)
answer = q / math.log(10)

print(round(answer, 2))
```---

```これは、ガンマ分布の正規近似に対するコーニッシュ フィッシャー補正です。 

---

 ### 3. 10 を底とする対数に変換します```python

```なぜなら$$\log_{10} c = \frac{\ln c}{\ln 10}.$$---

 # 検証

 より小さな例としては$n=100$、$$\log_{10} c \approx 46.27,$$問題内のステートメントと一致します。 

のために$n=10^7$、結果は近いはずです$$\frac{10^7}{\ln 10}\approx 4.3429448\times10^6,$$そして私たちの答えは、予想される変動サイズによってのみ異なります$O(\sqrt n)$なので、大きさは正しいです。
