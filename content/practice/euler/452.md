[プロジェクト オイラー問題 452](https://projecteuler.net/problem=452)

 ## 解決策

 **答え:**`345558983`させて$$F(m,n)=\#\{(a_1,\dots,a_n)\in \mathbb Z_{>0}^n:\ a_1a_2\cdots a_n\le m\}.$$私たちは求められています$$F(10^9,10^9)\pmod{1234567891}.$$---

 ## 1. 数学的分析

 固定整数の場合$t$、 定義する$$d_n(t)=\#\{(a_1,\dots,a_n)\in \mathbb Z_{>0}^n:\ a_1a_2\cdots a_n=t\}.$$それから明らかに$$F(m,n)=\sum_{t\le m} d_n(t).$$---

 ### ステップ 1: 解釈する$d_n(t)$仮定する$$t=\prod p_i^{e_i}.$$注文されたものを形成するには$n$-タプルの積は$t$、指数を分配します$e_i$それぞれの素数の$p_i$の間で$n$ポジション。 

配布方法の数$e_i$同一のオブジェクトを$n$ボックスは$$\binom{n+e_i-1}{e_i}.$$したがって$$d_n(t)=\prod_i \binom{n+e_i-1}{e_i}.$$これは一般化された除数関数です。 

---

 ## ステップ 2: 1 を削除する

 はるかに役立つ視点は次のとおりです。 

- 正確に選択してください$k$であるポジション$>1$、
 - 残りのポジションはすべて$1$。 

させて$T_k(m)$注文した数を示します$k$- 整数のタプル$>1$誰の製品ですか$\le m$。 

それから$$F(m,n)=\sum_{k\ge0}\binom{n}{k}T_k(m).$$なぜ？ 

- を選択してください$k$1 以外の位置:$\binom nk$、
 - 有効な注文内容を入力します$k$-タプルのカウント数$T_k(m)$。 

すべての要素は少なくとも$2$、$$2^k\le m.$$のために$m=10^9$、$$k\le \lfloor \log_2(10^9)\rfloor = 29.$$したがって、必要な用語は 30 語だけです。 

---

 ## ステップ 3: 繰り返し$T_k(m)$定義する$$T_0(m)=1.$$のために$k\ge1$、$$T_k(m)=\sum_{a=2}^{m} T_{k-1}\!\left(\left\lfloor \frac{m}{a}\right\rfloor\right).$$これは、最初の要素がどのようなものであってもよいためです。$a\ge2$、そして残りの$k-1$因数には最大でも積が必要です$m/a$。 

---

 ## ステップ 4: 双曲線の最適化

 の値$$\left\lfloor \frac{m}{a}\right\rfloor$$変更のみ$O(\sqrt m)$回。 

もし$$q=\left\lfloor \frac{m}{a}\right\rfloor,$$それから全部$a$間隔の中で$[i,j]$同じ商を与える$q$。 

そこで計算します$$T_k(m)=\sum_{\text{blocks }[i,j]} (j-i+1)\,T_{k-1}(q).$$メモ化を使用すると、これが非常に高速になります。 

---

 #2. Pythonの実装```python
import math
from functools import lru_cache

MOD = 1234567891
N = 10**9
M = 10**9

@lru_cache(maxsize=None)
def T(k, x):
    """
    Number of ordered k-tuples of integers > 1
    whose product is <= x, modulo MOD.
    """

    if k == 0:
        return 1

    # minimum possible product is 2^k
    if x < (1 << k):
        return 0

    total = 0

    i = 2
    while i <= x:
        q = x // i
        j = x // q

        # all a in [i, j] give floor(x/a) = q
        total += (j - i + 1) * T(k - 1, q)
        total %= MOD

        i = j + 1

    return total

def solve():
    ans = 0

    # only k <= floor(log2(M)) matter
    for k in range(30):
        ans += math.comb(N, k) % MOD * T(k, M)
        ans %= MOD

    return ans

print(solve())
```---

 #4. 検証

 同じプログラムでは次のようになります。$$F(10,10)=571,$$ステートメントと一致します。 

また、次のことも得られます。$$F(10^6,10^6)\bmod 1234567891 = 252903833,$$再び問題文と一致します。 

したがって、メソッドは検証されます。 

ターゲットケースの計算値は次のとおりです。$$F(10^9,10^9)\bmod 1234567891 = 345558983.$$---
