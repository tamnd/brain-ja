 # 数学的分析

 しましょう$$S=\{ax+by:x,y\ge0\}$$によって生成される数値半群になります。$a,b$。 

カエル$m$カエルを攻撃する$n>m$もし$$n-m\in S.$$したがって、カエル間の許容される差異はすべて、**表現不可能**でなければなりません。$ax+by$。 

---

 ## 1. 表現できない数値

 共素の場合$a,b$、表現できない正の整数はすべて固有の形式を持ちます。$$ab-ai-bj$$と$$1\le i\le b-1,\qquad 1\le j\le a-1,$$そして$$ai+bj<ab.$$したがって、表現できない数値はそれぞれ格子点に対応します$(i,j)$。 

のために$(a,b)=(3,5)$、非代表者は$$7,4,2,1.$$確かに：$$7=15-3-5,\quad 4=15-6-5,\quad 2=15-3-10,\quad 1=15-9-5.$$---

 ＃＃２．２つのカエルに互換性があるのはいつですか？ 

2 つの非代表者がいるとします。$$u=ab-ai_1-bj_1,$$

$$v=ab-ai_2-bj_2.$$それから$$u-v=a(i_2-i_1)+b(j_2-j_1).$$両方の座標の差が負でない場合、この差は表現可能です。$$i_2\ge i_1,\qquad j_2\ge j_1.$$したがって、2 つのカエルは、その格子点が積順序で比較できない場合に正確に互換性があります。 

したがって、有効なフロッグ構成は、正確にポーズセット内の**アンチチェーン**です。$$(i,j)\le(i',j') \iff i\le i',\ j\le j'.$$---

 # 動的計画法定式化

 行ごとに$j$、 定義する$$L_j=\left\lfloor\frac{ab-bj-1}{a}\right\rfloor.$$それから漕ぎます$j$細胞が含まれています$$1\le i\le L_j.$$アンチチェーンには各行から最大 1 つのセルを含めることができ、選択されたセルは$i$-値は次のように厳密に減少する必要があります$j$が増加します。 

行に対して DP を実行します。 

- 行から何も選択しません。 
- または、$i$以前に選択したものよりも小さいです。 

選択された各セルが重みに寄与します$$ab-ai-bj.$$---

 # Pythonの実装```python
from functools import cache

def F(a, b):
    # L[j-1] = maximum i allowed in row j
    L = [(a*b - b*j - 1) // a for j in range(1, a)]

    @cache
    def dp(j, prev_i):
        """
        Returns:
            (count, total_sum)

        considering rows j..a-1,
        where future chosen i-values must be < prev_i.
        """

        # no more rows
        if j == a:
            return (1, 0)

        total_count, total_sum = dp(j + 1, prev_i)

        max_i = min(prev_i - 1, L[j - 1])

        for i in range(1, max_i + 1):
            count2, sum2 = dp(j + 1, i)

            weight = a*b - a*i - b*j

            total_count += count2
            total_sum += sum2 + count2 * weight

        return total_count, total_sum

    return dp(1, b)[1]

print(F(3, 5))    # 23
print(F(5, 13))   # 16336
print(F(19, 53))
```---

 # コードのチュートリアル

 再帰的な状態は次のとおりです。$$dp(j,\text{prev}_i)$$意味:

 - 行を処理中です$j$、
 - 選択された将来$i$満たさなければなりません$$i<\text{prev}_i.$$これにより、比類のないことが保証されます。 

各行には 2 つの選択肢があります。 

1. 行をスキップします。 
2. 許可されたセルを 1 つ選択します。 

選ぶなら$(i,j)$、対応する表現できない数値を追加します$$ab-ai-bj.$$再帰は累積します。 

- 構成の数、
 - すべての構成にわたるカエルの位置の合計。
