[プロジェクト オイラー問題 568](https://projecteuler.net/problem=568)

 ## 解決策

 **答え:**`4228020`させて$$D(n)=J_B(n)-J_A(n).$$問題が非常に単純な同一性に崩壊することを示します$$\boxed{D(n)=\frac{H_n}{2^n}}$$どこ$$H_n=\sum_{k=1}^n \frac1k$$です$n$-次高調波番号。 

次に、必要なのは先頭の数字だけです$$\frac{H_{123456789}}{2^{123456789}}.$$---

 #1. 数学的分析

 ## ゲーム A

 1 ターンで:

 - 数字$k\in\{1,\dots,n\}$一律に選ばれるので、
 - ジェリーが勝ちます$\frac1k$まさに$k$電球が点灯しています。 

固定用$k$、$$\Pr(\text{exactly }k\text{ bulbs on}) =\frac{\binom nk}{2^n}.$$したがって、そのターンで期待される利得は次のようになります。$$\frac1k\cdot \frac{\binom nk}{2^n}.$$それぞれなので$k$確率で選ばれる$1/n$、ターンごとに期待される利得は次のとおりです。$$\frac1n\sum_{k=1}^n \frac1k\frac{\binom nk}{2^n}.$$ゲームには、$n$回りますので、$$J_A(n) = n\cdot \frac1n \sum_{k=1}^n \frac{\binom nk}{k2^n} = \sum_{k=1}^n \frac{\binom nk}{k2^n}.$$したがって$$\boxed{ J_A(n)=\frac1{2^n}\sum_{k=1}^n \frac{\binom nk}{k} }.$$---

 ## ゲーム B

 修正$k$。 

トムはランダムなパターンを正確に生成するまで繰り返し生成します。$k$電球が点灯しています。 

「まさに」という条件付き$k$電球が点灯しています」、すべての$k$-subset の可能性も同様です。 がある$\binom nk$そのようなサブセット。 

ジェリーも独立して同じことを行います。 

したがって、ジェリーがトムとまったく同じサブセットを取得する確率は次のようになります。$$\frac1{\binom nk}.$$見返りは$\frac1k$、固定のため$k$期待される見返りは$$\frac1k\cdot \frac1{\binom nk}.$$一様に選択された値の平均$k$と乗算する$n$ターン:$$J_B(n) = \sum_{k=1}^n \frac1{k\binom nk}.$$それで$$\boxed{ J_B(n)=\sum_{k=1}^n \frac1{k\binom nk} }.$$---

 #2. 単純化する$D(n)$必要です$$D(n) = \sum_{k=1}^n \left( \frac1{k\binom nk} - \frac{\binom nk}{k2^n} \right).$$鍵となるアイデンティティは、$$\boxed{ \frac1{k\binom nk} = \frac1n\cdot \frac1{\binom{n-1}{k-1}} }$$なぜなら$$\binom nk = \frac nk\binom{n-1}{k-1}.$$したがって$$J_B(n) = \frac1n \sum_{k=1}^n \frac1{\binom{n-1}{k-1}} = \frac1n \sum_{j=0}^{n-1} \frac1{\binom{n-1}{j}}.$$今では古典的なアイデンティティを使用します$$\boxed{ \sum_{k=1}^n \frac{\binom nk}{k} = \sum_{m=1}^n \frac{2^m-1}{m} }$$(これは積分によって続きます)$(1+x)^n-1$で割る$x$）。 

したがって、$$J_A(n) = \frac1{2^n} \sum_{m=1}^n \frac{2^m-1}{m}.$$美しいキャンセルが発生します。$$\boxed{ D(n)=\frac{H_n}{2^n} }$$どこ$$H_n=\sum_{m=1}^n \frac1m.$$チェックしてください$n=6$:$$H_6=1+\frac12+\frac13+\frac14+\frac15+\frac16 =\frac{49}{20}.$$したがって$$D(6)=\frac{49}{20\cdot 64} =\frac{49}{1280} =0.03828125,$$まさに記載どおりです。 

---

 #3. の漸近線$n=123456789$最初のものが必要です$7$の有効数字$$D(n)=\frac{H_n}{2^n}.$$大型用$n$、$$H_n = \log n+\gamma+\frac1{2n}-\frac1{12n^2}+O(n^{-4}),$$どこ$\gamma$はオイラー定数です。 

のために$n=123456789$、$$H_n \approx 19.210680695\dots$$私たちは計算します$$\log_{10} D(n) = \log_{10}(H_n)-n\log_{10}2.$$高精度演算を使用すると、次のようになります。$$\log_{10} D(n) = -37164195.3738629342333\dots$$小数部は$$0.6261370657666\dots$$したがって$$D(n) = 10^{-37164195}\times 10^{0.6261370657\dots} = 10^{-37164195}\times 4.228020318\dots$$したがって、最初の有効数字 7 桁は次のようになります。$$4228020.$$---

 #4. Pythonの実装```python
from mpmath import mp

# required precision
mp.dps = 80

n = 123456789

# harmonic number asymptotic
gamma = mp.euler
H = mp.log(n) + gamma + 1/(2*n) - 1/(12*n**2)

# log10(D(n)) where D(n) = H_n / 2^n
x = mp.log10(H) - n * mp.log10(2)

# fractional part determines leading digits
frac = x - mp.floor(x)

# mantissa
mantissa = 10 ** frac

# first 7 significant digits
answer = int(mp.floor(mantissa * 10**6))

print(answer)
```---

 #5. コードのチュートリアル

 -`mp.dps = 80`高精度の演算を設定します。 
- 漸近展開を使用します$$H_n \approx \log n+\gamma+\frac1{2n}-\frac1{12n^2}$$これは必要以上に正確です。 
- 以来$$D(n)=H_n2^{-n},$$私たちは計算します$$\log_{10} D(n).$$- 対数の小数部によって先頭の桁が決まります。 
- もし$$D = m\times 10^e,\qquad 1\le m<10,$$それから$m=10^{\{\log_{10} D\}}$。 
- 掛け算$m$による$10^6$そして、発言権を獲得すると、最初の結果が得られます$7$有効数字。

 #6. 最終検証

 サンプルの場合:$$D(6)=\frac{H_6}{2^6} =\frac{49/20}{64} =0.03828125,$$これはステートメントと正確に一致します。 

計算された仮数$n=123456789$は$$4.228020318\dots$$したがって、最初の有効数字 7 桁は確かに$$4228020.$$**答え: 4228020**
