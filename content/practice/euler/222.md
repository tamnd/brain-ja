[プロジェクト オイラー問題 222](https://projecteuler.net/problem=222)

 ## 解決策

 **答え:**`1590933`パイプに内径を持たせる$$R=50\text{ mm}.$$配置する必要があります$21$半径のボール$$30,31,\dots,50 \text{ mm}$$パイプの全長が最小限になるようにシリンダー内に配置します。 

#1. 幾何学的分析

 半径のある 2 つの連続したボールを考えます。$r$そして$s$。 

最適な梱包では:

 - 各ボールがシリンダーの壁に触れます。 
- 連続したボールが互いに接触し、
 - それらの中心は、シリンダーの一方の側からもう一方の側に交互に配置されます。 

断面図からは次のことがわかります。 

- 円柱の軸から半径のボールの中心までの距離$r$:$$R-r$$- 2 つの中心間の横方向の分離:$$(R-r)+(R-s)=2R-r-s.$$ボール同士が接触しているので、中心距離は$$r+s.$$したがって、もし$d(r,s)$中心間の軸方向の距離、$$d(r,s)^2 + (2R-r-s)^2 = (r+s)^2.$$したがって、$$d(r,s) = \sqrt{(r+s)^2-(2R-r-s)^2}.$$と$R=50$、$$d(r,s) = \sqrt{(r+s)^2-(100-r-s)^2}.$$要素：$$d(r,s) = \sqrt{100(2r+2s-100)} = 10\sqrt{2(r+s)-100}.$$したがって、距離は次のもののみに依存します。$r+s$。 

---

 ## パイプの全長

 最初と最後のボールに半径がある場合$a$そして$b$の場合、パイプの長さは次のようになります。$$L = a+b+\sum d(r_i,r_{i+1}).$$したがって、隣接する間隔の合計を最小化する必要があります。 

なぜなら$d(r,s)$で増加しています$r+s$、隣接する合計をできるだけ小さくする必要があります。 

最適な順序は次のとおりです。$$50,48,46,\dots,32,30,31,33,35,\dots,47,49.$$つまり:

 - 偶数の減少、
 - その後、オッズが増加します。 

これにより、チェーン全体で隣接する合計が非常に小さく保たれます。

 #2. Pythonの実装```python
from math import sqrt

# Ball radii
balls = list(range(30, 51))

# Optimal ordering
order = (
    list(range(50, 29, -2)) +   # 50,48,...,30
    list(range(31, 50, 2))      # 31,33,...,49
)

def axial_distance(r, s):
    """
    Axial separation between centers of two touching balls
    inside a cylinder of radius 50 mm.
    """
    return sqrt((r + s)**2 - (100 - r - s)**2)

# Total pipe length in mm
length_mm = order[0] + order[-1]

for i in range(len(order) - 1):
    length_mm += axial_distance(order[i], order[i + 1])

# Convert mm -> micrometres
length_um = round(length_mm * 1000)

print(length_mm)
print(length_um)
```---

 #3. コードのチュートリアル

 ### 順序付けの構築```python
order = (
    list(range(50, 29, -2)) +
    list(range(31, 50, 2))
)
```作成します$$[50,48,46,\dots,30,31,33,\dots,49].$$---

 ### 軸方向距離の計算式```python
sqrt((r + s)**2 - (100 - r - s)**2)
```実装する$$d(r,s)=\sqrt{(r+s)^2-(100-r-s)^2}.$$---

 ### 全長```python
length_mm = order[0] + order[-1]
```エンドクリアランスを追加します。 

次に、ループはすべての中心間の軸方向の分離を追加します。 

ついに：```python
length_um = round(length_mm * 1000)
```ミリメートルをマイクロメートルに変換します。

 #4. 最終検証

 計算された長さは$$1590.933116\ldots \text{ mm}$$等しい$$1\,590\,933.116\ldots \text{ micrometres}.$$最も近い整数に四捨五入します。$$1\,590\,933.$$この大きさは妥当です。 

- 21個のボールはそれぞれ直径が異なります。$60$–$100$mm、
 - ただし、軸方向の重なりが大きいため、合計は約$1.59$メートル。
