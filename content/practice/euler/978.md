 # 数学的分析

 独立したランダムな符号を定義する$\varepsilon_t\in\{-1,+1\}$のために$t\ge2$、それぞれ確率付き$1/2$。 

プロセスは$$X_t = X_{t-1} + \varepsilon_t |X_{t-2}|.$$歪度が必要です。$$\text{Skew}(X_n) = \frac{\mathbb E[(X_n-\mu)^3]}{\sigma^3}.$$したがって、次のものが必要です。 

- 平均$\mu_n=\mathbb E[X_n]$、
 - 差異、
 - 3番目の中心モーメント。 

---

 ## ステップ 1: 平均値

 過去を条件づけて、$$\mathbb E[\varepsilon_t]=0,$$したがって$$\mathbb E[X_t] = \mathbb E[X_{t-1}] + \mathbb E[\varepsilon_t |X_{t-2}|] = \mathbb E[X_{t-1}].$$以来$X_1=1$、$$\boxed{\mathbb E[X_t]=1 \quad \forall t\ge1.}$$したがって、平均値は常に$1$。 

---

 # ステップ 2: 2 番目の瞬間

 しましょう$$a_t=\mathbb E[X_t^2].$$拡大する：$$X_t^2 = X_{t-1}^2 + X_{t-2}^2 + 2\varepsilon_t X_{t-1}|X_{t-2}|.$$期待を受け入れるとクロスタームが無効になります。$$a_t=a_{t-1}+a_{t-2}.$$初期値:$$a_0=0,\qquad a_1=1.$$したがって$a_t$はまさにフィボナッチ数列です:$$\boxed{a_t=F_t}.$$したがって$$\operatorname{Var}(X_t)=F_t-1.$$のために$t=50$、$$F_{50}=12586269025.$$したがって、$$\sigma^2 = 12586269024.$$---

 # ステップ 3: 第三の瞬間

 しましょう$$b_t=\mathbb E[X_t^3].$$拡大する：$$(X_{t-1}+\varepsilon_t|X_{t-2}|)^3.$$奇妙な力$\varepsilon_t$期待の中で消える、与える$$b_t = b_{t-1} + 3\mathbb E[X_{t-1}X_{t-2}^2].$$ここで定義します$$c_t=\mathbb E[X_tX_{t-1}^2].$$使用する$$X_t=X_{t-1}+\varepsilon_t|X_{t-2}|,$$私たちは得ます$$c_t = \mathbb E[X_{t-1}^3] + \mathbb E[\varepsilon_t|X_{t-2}|X_{t-1}^2].$$また第二項が消えてしまうので、$$c_t=b_{t-1}.$$したがって$$\boxed{b_t=b_{t-1}+3b_{t-2}}.$$初期条件:$$b_0=0,\qquad b_1=1.$$順方向に計算すると次のようになります。$$b_{50}=359426118413557441.$$---

 # ステップ 4: 第三中心モーメント

 平均値は$1$、$$\mu_3 = \mathbb E[(X_{50}-1)^3].$$使用する$$\mathbb E[(X-1)^3] = \mathbb E[X^3]-3\mathbb E[X^2]+3\mathbb E[X]-1,$$そして$\mathbb E[X]=1$、$$\mu_3 = b_{50}-3F_{50}+2.$$代替値:$$\mu_3 = 359426118413557441 - 3(12586269025) + 2 = 359426080654750368.$$---

 # ステップ 5: 歪度$$\text{Skew}(X_{50}) = \frac{359426080654750368}{(12586269024)^{3/2}}.$$数値的には、$$\boxed{ \text{Skew}(X_{50}) \approx 254.54470756901193 }$$8 桁に四捨五入:$$\boxed{254.54470757}$$---

 # Pythonの実装```python
from math import sqrt

N = 50

# Second moments: a[n] = E[X_n^2]
a = [0] * (N + 1)
a[0] = 0
a[1] = 1

for n in range(2, N + 1):
    a[n] = a[n - 1] + a[n - 2]

# Third moments: b[n] = E[X_n^3]
b = [0] * (N + 1)
b[0] = 0
b[1] = 1

for n in range(2, N + 1):
    b[n] = b[n - 1] + 3 * b[n - 2]

mean = 1
variance = a[N] - 1
sigma = sqrt(variance)

third_central = b[N] - 3 * a[N] + 2

skewness = third_central / (sigma ** 3)

print(f"{skewness:.8f}")
```---

 # コードのチュートリアル

 -`a[n]`店$\mathbb E[X_n^2]$。 
- 再発$$a_n=a_{n-1}+a_{n-2}$$フィボナッチ数を生成します。 
-`b[n]`店$\mathbb E[X_n^3]$。 
- 再発$$b_n=b_{n-1}+3b_{n-2}$$三次展開から来ています。 
- 差異は$$\sigma^2=a_n-1.$$- 3番目の中心モーメントは$$b_n-3a_n+2.$$- ついに：$$\text{Skew}=\mu_3/\sigma^3.$$このコードは、指定されたチェック値も再現します。$$\text{Skew}(X_{10})\approx2.50997097.$$したがって、導出は一貫しています。
