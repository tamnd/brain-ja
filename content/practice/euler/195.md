[プロジェクト オイラー問題 195](https://projecteuler.net/problem=195)

 ## 解決策

 **答え:**`75085391`三角形の辺を$a,b,c$と仮定します。$60^\circ$角度は反対側です$c$。 

余弦の法則により、$$c^2=a^2+b^2-ab.$$すべての整数解を 1 つだけ数えなければなりません$60^\circ$角度と半径$r\le n$。 

---

 #1. 数学的分析

 ## ステップ 1: すべてのパラメータ化$60^\circ$-三角形

 二次形式$$a^2-ab+b^2$$はエイゼンシュタイン整数の標準形式、および の原始解です。$$c^2=a^2-ab+b^2$$互いに素な整数によってパラメータ化されます$m>n>0$。 

標準的なパラメータ化は次のとおりです。$$\begin{aligned} a &= d(m^2-n^2),\\ b &= d(2mn-n^2),\\ c &= d(m^2-mn+n^2), \end{aligned}$$と$\gcd(m,n)=1$。 

ただし:

 - もし$m+n\not\equiv0\pmod3$、このトリプルは原始的です。 
- もし$m+n\equiv0\pmod3$、すべての辺は次のように割り切れます。$3$で割った後、$3$別の原始的な家族が得られます。 

同じ三角形を 2 回数えることを避けるため (置換するため)$n$による$m-n$同じ三角形を与えます)、私たちは課します$$m>2n.$$---

 ## ステップ 2: 半径の公式

 夾角を含む三角形の面積$60^\circ$は$$\Delta=\frac{\sqrt3}{4}ab.$$イン半径は満たす$$\Delta = rs,$$どこ$s$は半周です。 

パラメータ化を置き換えて単純化すると、次のようになります。 

### 家族 A:$m+n\not\equiv0\pmod3$

$$r=\frac{\sqrt3}{2}d\,n(m-n).$$したがって$$d\le \frac{2N}{\sqrt3\,n(m-n)}.$$貢献：$$\left\lfloor \frac{2N}{\sqrt3\,n(m-n)} \right\rfloor.$$---

 ### 家族 B:$m+n\equiv0\pmod3$プリミティブトリプルを次のように除算した後、$3$、$$r=\frac{\sqrt3}{6}d\,n(m-n).$$したがって$$d\le \frac{6N}{\sqrt3\,n(m-n)} = \frac{2\sqrt3\,N}{n(m-n)}.$$貢献：$$\left\lfloor \frac{2\sqrt3\,N}{n(m-n)} \right\rfloor.$$---

 ## ステップ 3: 最終的なカウント式

 したがって、$$T(N)= \sum_{\substack{m>2n\\ \gcd(m,n)=1}} \begin{cases} \left\lfloor\dfrac{2N}{\sqrt3\,n(m-n)}\right\rfloor, & m+n\not\equiv0\pmod3,\\[1.5ex] \left\lfloor\dfrac{2\sqrt3\,N}{n(m-n)}\right\rfloor, & m+n\equiv0\pmod3. \end{cases}$$これは非常に高速に実行されます。$$n(m-n)\le 2\sqrt3\,N.$$---

 #2. Pythonの実装```python
from math import gcd, sqrt

def T(N):
    # Bounds appearing in the counting formulas
    limit1 = 2 * N / sqrt(3)
    limit2 = 2 * sqrt(3) * N

    max_k = int(limit2)

    total = 0

    # We need:
    #   k = n(m-n) <= max_k
    #
    # Since m > 2n, we iterate efficiently.

    for n in range(1, max_k + 1):

        # From n(m-n) <= max_k:
        #     m <= max_k/n + n
        m_max = max_k // n + n

        # m > 2n avoids duplicate triangles
        for m in range(2 * n + 1, m_max + 1):

            if gcd(m, n) != 1:
                continue

            k = n * (m - n)

            if k > max_k:
                break

            # Family B
            if (m + n) % 3 == 0:
                total += int(limit2 // k)

            # Family A
            else:
                total += int(limit1 // k)

    return total

# Verification against the problem statement
print(T(100))     # 1234
print(T(1000))    # 22767
print(T(10000))   # 359912

# Required answer
print(T(1053779))
```---
