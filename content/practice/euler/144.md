[プロジェクト オイラー問題 144](https://projecteuler.net/problem=144)

 ## 解決策

 **答え:**`354`レーザービームを、楕円の内側で反射する一連の直線セグメントとしてモデル化します。$$4x^2+y^2=100.$$ビームが上部の小さな開口部から出る前に、ビームが内部表面に何回当たったかを数えるように求められます。$$-0.01 \le x \le 0.01,\qquad y>0.$$ビームは屋外で開始します$(0,10.1)$そして最初に楕円を打ちます$$(1.4,-9.6).$$---

 # 数学的分析

 ## 1. 反射の幾何学

 楕円の場合$$4x^2+y^2=100,$$陰的な微分により接線の傾きが得られます。$$8x+2y\frac{dy}{dx}=0$$それで$$\frac{dy}{dx}=-\frac{4x}{y}.$$したがって、ある時点で$(x,y)$:

 - 接線ベクトルは次のように取得できます。$$T=(1,-4x/y),$$- 法線ベクトルはこれに垂直です。 

よりクリーンなアプローチは、楕円の勾配を使用することです。$$F(x,y)=4x^2+y^2.$$それから$$\nabla F=(8x,2y)$$は楕円に垂直です。 

それでインパクトポイントで$P=(x,y)$、法線ベクトルは$$N=(4x,y).$$---

 ## 2. ベクトル反射公式

 入ってくる方向ベクトルが次であると仮定します。$v$。 

法線全体の反射$N$は：$$v_{\text{out}} = v - 2\frac{v\cdot N}{N\cdot N}N.$$これにより、三角法が完全に回避され、数値的に安定します。 

---

 ## 3. 次の交差点を見つける

 ビームが点から離れると仮定します$P=(x_0,y_0)$方向性あり$v=(d_x,d_y)$。 

パラメトリックラインは$$(x,y)=(x_0,y_0)+t(d_x,d_y).$$楕円方程式に代入します。$$4(x_0+t d_x)^2+(y_0+t d_y)^2=100.$$なぜなら$P$すでに楕円上にあり、根の 1 つは$t=0$。 

2 番目のルートは次のインパクト ポイントを与えます。 

拡張:$$4(x_0^2+2x_0d_xt+t^2d_x^2) +y_0^2+2y_0d_yt+t^2d_y^2 =100.$$使用する$4x_0^2+y_0^2=100$、$$t(8x_0d_x+2y_0d_y) +t^2(4d_x^2+d_y^2)=0.$$したがって、非ゼロの根は次のようになります。$$t = -\frac{8x_0d_x+2y_0d_y} {4d_x^2+d_y^2}.$$それから$$P_{\text{next}}=P+t\,v.$$---

 # Pythonの実装```python
import math

# Starting point outside the ellipse
x_prev, y_prev = 0.0, 10.1

# First impact point
x, y = 1.4, -9.6

# Count reflections on the internal surface
count = 0

while True:

    # Check whether beam exits through the hole
    if abs(x) <= 0.01 and y > 0:
        break

    # Incoming direction vector
    vx = x - x_prev
    vy = y - y_prev

    # Normal vector to ellipse at (x, y)
    nx = 4 * x
    ny = y

    # Reflect v across the normal
    dot = vx * nx + vy * ny
    norm_sq = nx * nx + ny * ny

    rx = vx - 2 * dot / norm_sq * nx
    ry = vy - 2 * dot / norm_sq * ny

    # Find next intersection with ellipse
    t = -(8 * x * rx + 2 * y * ry) / (4 * rx * rx + ry * ry)

    x_next = x + t * rx
    y_next = y + t * ry

    # Advance
    x_prev, y_prev = x, y
    x, y = x_next, y_next

    count += 1

print(count)
```---

 # コードのチュートリアル

 ## 初期条件```python
x_prev, y_prev = 0.0, 10.1
x, y = 1.4, -9.6
```ビームは楕円の外側から始まり、最初に当たります。$(1.4,-9.6)$。 

---

 ## 終了条件```python
if abs(x) <= 0.01 and y > 0:
    break
```ビームは上部近くの小さな開口部からのみ漏れます。 

---

 ## 入ってくる方向```python
vx = x - x_prev
vy = y - y_prev
```これは、前のポイントから現在のポイントへの方向です。 

---

 ## 表面法線```python
nx = 4 * x
ny = y
```なぜなら、楕円は、$$4x^2+y^2=100,$$勾配$(8x,2y)$それは正常です。 スケーリング$1/2$与える$(4x,y)$。 

---

 ## リフレクションステップ```python
dot = vx * nx + vy * ny
norm_sq = nx * nx + ny * ny

rx = vx - 2 * dot / norm_sq * nx
ry = vy - 2 * dot / norm_sq * ny
```これはベクトル反射公式を実​​装します。 

---

 ## 次の交差点```python
t = -(8 * x * rx + 2 * y * ry) / (4 * rx * rx + ry * ry)
```これにより、楕円との非ゼロ交差パラメータが計算されます。 

それから：```python
x_next = x + t * rx
y_next = y + t * ry
```次のバウンスポイントを与えます。 

---

 # 小規模な健全性チェック

 数値的に計算される最初の反射はおよそ$$(-3.9906,-6.025)$$これは、この問題の既知の軌跡とステートメントに示されているアニメーションと一致します。 

楕円は軌道を効率的に集束させるため、ビームは何度も反射しても捕捉されたままになります。

 # 最終確認

 浮動小数点演算を使用してシミュレーションを慎重に実行すると、次の結果が得られます。$$354$$ビームが開口部から出る前の内部反射。 

この大きさは妥当です。ビームは最終的に逃げるまでに数百回の反射を経験します。 

**答え: 354**
