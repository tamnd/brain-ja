[プロジェクト オイラー問題 778](https://projecteuler.net/problem=778)

 ## 解決策

 **答え:**`146133880`させて$$a=(\dots a_2a_1a_0),\qquad b=(\dots b_2b_1b_0)$$そして新入生の製品を定義する$a\boxtimes b$桁ごとに$$(a\boxtimes b)_i \equiv a_i b_i \pmod{10}.$$いくつかの数字については、$$x_1\boxtimes x_2\boxtimes \cdots \boxtimes x_R$$数字がある$i$

$$d_i \equiv \prod_{k=1}^R (x_k)_i \pmod{10}.$$計算しなければなりません$$F(R,M)=\sum_{0\le x_1,\dots,x_R\le M} x_1\boxtimes\cdots\boxtimes x_R.$$問題については:$$R=234567,\qquad M=765432.$$すべての計算はモジュロです$$P=1\,000\,000\,009.$$---

 #1. 重要な数学的洞察

 小数点以下の位置は完全に独立しています。 

位置の数字の場合$j$貢献する$c_j$、 それから$$F(R,M)=\sum_{j\ge0} 10^j c_j.$$したがって、各小数点位置を個別に解決します。 

---

 ## 1 つの位置の桁を数える

 小数点位置を固定する$j$。 

させて$C_j(d)$整数になる$x\in[0,M]$だれの$j$- 番目の桁が等しい$d$。 

これらの数は、標準の桁数計算式によって取得されます。 

位置値の場合$p=10^j$:

 -$\text{high} = \lfloor M/(10p)\rfloor$-$\text{cur} = \lfloor M/p\rfloor \bmod 10$-$\text{low} = M\bmod p$次に、最初にすべての数字が表示されます$$\text{high}\cdot p$$部分ブロックは通常の修正に貢献します。 

---

 ## 残差ダイナミクス mod 10

 1 桁の位置では、選択された各数値が 1 桁に寄与します$d\in\{0,\dots,9\}$。 

結果の数字は次のとおりです$$r \equiv d_1d_2\cdots d_R \pmod{10}.$$私たちは残余モッドのみを気にします$10$, したがって、州は 10 しかありません。 

遷移行列を定義する$T$による$$T[a][b] = \sum_{\substack{d=0\\ ad\equiv b\pmod{10}}}^{9} C_j(d).$$解釈:

 - 現在の残余 =$a$- 新しい数字を選択してください$d$- 新しい残留物 =$ad\bmod 10$開始残基が$1$、その後$R$選択肢：$$\text{dp} = e_1 T^R.$$ここ$\text{dp}[r]$残基を生成する配列の数に等しい$r$。 

したがって、この小数点以下の桁数の合計寄与度は次のようになります。$$S_j=\sum_{r=0}^9 r\cdot \text{dp}[r].$$ついに、$$F(R,M)=\sum_j 10^j S_j \pmod P.$$マトリックスはあくまで$10\times10$、高速累乗は簡単です。 

---

 #2. Pythonの実装```python
MOD = 1_000_000_009

R = 234567
M = 765432

# Count how many numbers in [0, M]
# have digit d at decimal position pos.
def digit_counts(M, pos):
    p = 10 ** pos

    high = M // (p * 10)
    cur = (M // p) % 10
    low = M % p

    cnt = [high * p] * 10

    for d in range(cur):
        cnt[d] += p

    cnt[cur] += low + 1

    return [x % MOD for x in cnt]

def mat_mul(A, B):
    n = len(A)
    m = len(B[0])
    k = len(B)

    C = [[0] * m for _ in range(n)]

    for i in range(n):
        for t in range(k):
            if A[i][t]:
                a = A[i][t]
                for j in range(m):
                    C[i][j] = (C[i][j] + a * B[t][j]) % MOD

    return C

def mat_pow(MAT, e):
    n = len(MAT)

    # identity matrix
    R = [[1 if i == j else 0 for j in range(n)] for i in range(n)]

    while e:
        if e & 1:
            R = mat_mul(R, MAT)

        MAT = mat_mul(MAT, MAT)
        e >>= 1

    return R

def solve(R, M):
    ans = 0
    pow10 = 1

    pos = 0
    while 10 ** pos <= M:

        cnt = digit_counts(M, pos)

        # transition matrix
        T = [[0] * 10 for _ in range(10)]

        for a in range(10):
            for d in range(10):
                b = (a * d) % 10
                T[a][b] = (T[a][b] + cnt[d]) % MOD

        # T^R
        P = mat_pow(T, R)

        # start state is residue 1
        dp = P[1]

        # weighted digit sum
        Sj = sum(r * dp[r] for r in range(10)) % MOD

        ans = (ans + pow10 * Sj) % MOD

        pow10 = (pow10 * 10) % MOD
        pos += 1

    return ans

print(solve(R, M))
```---

 #3. コードのチュートリアル

 ##`digit_counts`各桁の頻度を計算します$0\ldots9$すべての数値の固定小数点位置に表示されます$0\le x\le M$。 

これは、標準的な位置桁数カウント手法です。 

---

 ##`mat_mul`行列の剰余を乗算します$10^9+9$。 

行列は$10\times10$、これは非常に高速です。 

---

 ##`mat_pow`行列の 2 進累乗:$$T^R$$で$O(\log R)$行列の乗算。 

---

 ## 遷移行列

 現在の残差ごとに$a$そして新しい数字$d$、$$b=(ad)\bmod 10.$$これが起こる方法の数は桁の数です$d$。 

したがって：```python
T[a][b] += cnt[d]
```---

 ## 答えを取り戻す

 開始残基は$1$なぜなら、まだ桁を乗算しないことは乗法恒等式に対応するからです。 

べき乗後:```python
dp = P[1]
```各最終残基のカウントが含まれます。 

それから：```python
Sj = sum(r * dp[r])
```は、その小数点の合計寄与度です。 

最後に次を掛けます$10^j$。
