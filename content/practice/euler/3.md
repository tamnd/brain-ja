[プロジェクト オイラー問題 3](https://projecteuler.net/problem=3)

 ## 解決策

 次の最大の素因数が必要です$$600851475143$$標準的なアプローチは、試行分割を繰り返すことです。 

- 最小の素数による除算を開始します$2$。 
- 約数のときはいつでも$d$分割する$n$、 分ける$n$による$d$繰り返し。 
- 増加$d$そしてそれまで続ける$d^2 > n$。 
- 残りの値$n$したがって、 が最大の素因数になります。 

これが機能するのは、すべての複合因子にすでにテスト済みの小さい因子があるためです。 

Python コード:```python
n = 600851475143
factor = 2
largest = 1

while factor * factor <= n:
    while n % factor == 0:
        largest = factor
        n //= factor
    factor += 1

if n > 1:
    largest = n

print(largest)
```因数分解を追跡する:$$600851475143 = 71 \times 839 \times 1471 \times 6857$$これらはすべて素数であるため、最大の素因数は次のようになります。 

**答え: 6857**
