[プロジェクト オイラー問題 402](https://projecteuler.net/problem=402)

 ## 解決策

 **答え:**`356019862`させて$$P(n)=n^4+an^3+bn^2+cn.$$最大の整数を求めます$m$そのような$P(n)\equiv 0\pmod m$**すべて**の整数の場合$n$。 

---

 #1. 数学的分析

 ## ステップ 1: 特徴付け$M(a,b,c)$整数値多項式に関する標準的な事実は次のとおりです。 

> 整数にわたる多項式のすべての値の gcd は、次の場合の前方差分の gcd と等しくなります。$0$。 

の前方差分を計算します$P(n)$:$$\Delta P(0)=1+a+b+c,$$

$$\Delta^2 P(0)=14+6a+2b,$$

$$\Delta^3 P(0)=36+6a,$$

$$\Delta^4 P(0)=24.$$したがって$$M(a,b,c)=\gcd(1+a+b+c,\ 14+6a+2b,\ 36+6a,\ 24).$$それで$M(a,b,c)$常に分裂する$24$。 

したがって、$M$のみに依存する$a,b,c \pmod{24}$。 

---

 ## ステップ 2: 周期性$M$剰余だけなので$24$案件、$$M(a+24,b,c)=M(a,b,c)$$(そして同様に$b,c$）。 

したがって$S(N)$は周期を持つ三次準多項式です$24$。 

書く$$N=24q+r,\qquad 0\le r<24.$$各残基クラスについて$t\in\{1,\dots,24\}$、整数の数$\le N$に一致する$t\pmod{24}$どちらかです$q$または$q+1$。 

剰余クラスの合計は次のようになります$$S(N)=Aq^3+B_r q^2+C_r q+D_r,$$ここで、定数は次から決定されます。$24^3$残留キューブ。 

全期間の合計は$$A=\sum_{1\le a,b,c\le 24} M(a,b,c)=27984.$$これによりチェックが再現されます。$$S(10)=1972,$$

$$S(10000)=2024258331114.$$---

 ## ステップ 3: フィボナッチ入力

 必要です$$\sum_{k=2}^{1234567890123} S(F_k)\pmod{10^9}.$$フィボナッチ数の剰余なので$24$ピサーノ時代がある$24$、$$F_{k+24}\equiv F_k\pmod{24},$$係数$B_r,C_r,D_r$ピリオドを付けて繰り返す$24$。 

したがって$S(F_k)$の線形結合になります$$1,\quad F_k,\quad F_k^2,\quad F_k^3$$係数周期モジュロあり$24$。 

These sequences satisfy linear recurrences, so the whole sequence can be evaluated with matrix exponentiation in$O(\log n)$。

 #2. Pythonの実装```python
from math import gcd
import numpy as np

MOD = 10**9
BIGMOD = 288 * MOD

# ------------------------------------------------------------
# Compute M(a,b,c)
# ------------------------------------------------------------

def M(a, b, c):
    return gcd(
        gcd(
            gcd(1 + a + b + c,
                14 + 6*a + 2*b),
            36 + 6*a),
        24
    )

# ------------------------------------------------------------
# Precompute the 24x24x24 residue cube
# ------------------------------------------------------------

cube = np.zeros((25, 25, 25), dtype=object)

for a in range(1, 25):
    for b in range(1, 25):
        for c in range(1, 25):
            cube[a, b, c] = M(a, b, c)

# 3D prefix sums
pref = cube.cumsum(0).cumsum(1).cumsum(2)

# ------------------------------------------------------------
# S(N)
# ------------------------------------------------------------

def S(N):
    q, r = divmod(N, 24)

    return (
        q**3 * pref[24,24,24]
        + q*q * (
            pref[r,24,24]
            + pref[24,r,24]
            + pref[24,24,r]
        )
        + q * (
            pref[r,r,24]
            + pref[r,24,r]
            + pref[24,r,r]
        )
        + pref[r,r,r]
    )

# ------------------------------------------------------------
# Verify examples
# ------------------------------------------------------------

assert S(10) == 1972
assert S(10000) == 2024258331114

# ------------------------------------------------------------
# Fibonacci residues mod 24
# ------------------------------------------------------------

fib24 = [0, 1]
for _ in range(22):
    fib24.append((fib24[-1] + fib24[-2]) % 24)

# ------------------------------------------------------------
# Build polynomial coefficients
# We work with 288*S(F_n) to avoid fractions.
# ------------------------------------------------------------

import sympy as sp

q = sp.Symbol('q')
x = sp.Symbol('x')

# Recover cubic polynomials for each residue
poly_by_r = {}

for r in range(24):
    vals = [S(24*k + r) for k in range(4)]
    poly = sp.interpolate(
        [(k, vals[k]) for k in range(4)],
        q
    )
    poly_by_r[r] = sp.expand(poly)

coeffs = []

for r in range(24):
    expr = sp.expand(
        288 * poly_by_r[r].subs(q, (x-r)/24)
    )
    P = sp.Poly(expr, x)

    # const, x, x^2, x^3
    coeffs.append([
        int(P.nth(0)),
        int(P.nth(1)),
        int(P.nth(2)),
        int(P.nth(3)),
    ])

# ------------------------------------------------------------
# State vector:
#
# [F_n^3,
#  F_n^2 F_{n+1},
#  F_n F_{n+1}^2,
#  F_{n+1}^3,
#  F_n^2,
#  F_n F_{n+1},
#  F_{n+1}^2,
#  F_n,
#  F_{n+1},
#  1,
#  accumulated_sum]
# ------------------------------------------------------------

mons = [
    (3,0),(2,1),(1,2),(0,3),
    (2,0),(1,1),(0,2),
    (1,0),(0,1),(0,0)
]

idx = {m:i for i,m in enumerate(mons)}

T = np.zeros((10,10), dtype=object)

# Fibonacci transition:
# (x,y) -> (y, x+y)

from math import comb

for j, (a,b) in enumerate(mons):
    for k in range(b+1):
        coef = comb(b, k)
        mon = (k, a+b-k)
        i = idx[mon]
        T[i,j] += coef

# ------------------------------------------------------------
# Phase-dependent matrices
# ------------------------------------------------------------

def make_matrix(t):
    A = np.zeros((11,11), dtype=object)

    A[:10,:10] = T
    A[10,10] = 1

    c = coeffs[(t+1) % 24]

    # depends only on F_{n+1}
    A[10,3] = c[3]
    A[10,6] = c[2]
    A[10,8] = c[1]
    A[10,9] = c[0]

    return A % BIGMOD

phase = [make_matrix(t) for t in range(24)]

# ------------------------------------------------------------
# Multiply matrices
# ------------------------------------------------------------

def matmul(A, B):
    return (A.dot(B)) % BIGMOD

# 24-step block
B = np.identity(11, dtype=object)

for t in range(24):
    B = matmul(phase[t], B)

# ------------------------------------------------------------
# Fast exponentiation
# ------------------------------------------------------------

def mpow(M, n):
    R = np.identity(11, dtype=object)

    while n:
        if n & 1:
            R = matmul(M, R)

        M = matmul(M, M)
        n >>= 1

    return R

# ------------------------------------------------------------
# Initial state at n=0
# ------------------------------------------------------------

state0 = np.array([
    0,0,0,1,
    0,0,1,
    0,1,
    1,
    0
], dtype=object)

K = 1234567890123

blocks, rem = divmod(K, 24)

state = mpow(B, blocks).dot(state0) % BIGMOD

for t in range(rem):
    state = phase[t].dot(state) % BIGMOD

# state[10] = 288 * sum_{k=1}^K S(F_k)

answer = ((state[10] // 288) - 2) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ### コンピューティング$M(a,b,c)$有限差分特性評価を使用します。```python
gcd(1+a+b+c,
    14+6a+2b,
    36+6a,
    24)
```これは直ちに周期性モジュロを意味します$24$。 

---

 ### コンピューティング$S(N)$以来$M$残基modのみに依存する$24$、全体を事前計算します$24^3$キューブを一度。 

それから$$N=24q+r,$$各残基が何回出現するかを数えます。 

これにより、問題全体が 3 次準多項式の評価に集約されます。 

---

 ### フィボナッチ加速

 への依存$F_k$は3次なので、すべての単項式を次数まで追跡します$3$:$$F_k^3,\quad F_k^2F_{k+1},\quad \dots$$フィボナッチ遷移$$(F_k,F_{k+1})\to(F_{k+1},F_k+F_{k+1})$$これらの単項式に線形変換を引き起こします。 

次に、高速行列累乗を使用して、次の値に直接ジャンプします。$$k=1234567890123.$$---
