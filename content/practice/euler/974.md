 >

 >
 >
 > 非常に奇数とは、奇数桁のみを含み、次で割り切れる数です。$105$。 さらに、各奇数桁は奇数回発生します。 
>

 # 数学的分析

 次のすべてを満たす数値を列挙する必要があります。 

1. すべての桁が奇数です:$$\{1,3,5,7,9\}$$2. 割り切れる数$105=3\cdot5\cdot7$3. すべての奇数桁が奇数回出現します。 

私たちに必要なのは、$10^{16}$- 番目の数値を昇順に並べます。 

---

 ## ステップ 1 — 割り算の制約

 数は割り切れるので、$5$、その最後の桁は次のようにする必要があります$5$。 

したがって、すべての有効な数値は次の形式になります。$$d_1d_2\cdots d_{n-1}5$$みんなで$d_i\in\{1,3,5,7,9\}$。 

---

 ### 3 で割り切れる

 奇数桁の場合:$$1,3,5,7,9 \equiv 1,0,2,1,0 \pmod 3$$桁の合計は次で割り切れる必要があります$3$。 

---

 ### 7 で割り切れる

 剰余モジュロを追跡します$7$数字を一桁ずつ構築しながら:$$r'=(10r+d)\bmod 7$$これは 7 つの状態を持つ有限オートマトンになります。 

---

 ## ステップ 2 — 桁数のパリティ条件

 5 つの奇数桁はそれぞれ奇数回出現する必要があります。 

重要なのはパリティだけなので、5 ビットのマスクを保存します。 

- ビット$i$=0 → 偶数桁数
 - ビット$i$=1 → 桁数が奇数

 数字を追加すると 1 ビットが切り替わります。 

最後に次のことが必要です。$$\text{mask}=11111_2=31$$なぜなら、5 つのカウントはすべて奇数でなければならないからです。 

---

 # 動的計画法定式化

 状態とは次のとおりです。$$(\text{length remaining},\ r,\ \text{mask})$$どこ

-$r$= 現在の剰余 mod 7
 - マスク = 桁数のパリティ パターン

 遷移:$$(r,\text{mask}) \to ((10r+d)\bmod 7,\ \text{mask}\oplus \text{bit}(d))$$最後の桁は固定です$5$。 

---

 # 有効な完了をカウントする

 しましょう$$DP[pos][r][mask]$$数値を終了する方法の数になります。 

状態の合計数はごくわずかです。$$O(L\cdot 7\cdot 32)$$どこ$L$桁数です。 

これにより、指定された長さのすべての有効な数値を非常に迅速に数えることができます。 

---

 # の構築$10^{16}$-番目の番号

 各長さに対して有効な数値がいくつ存在するかを数えた後、次のようになります。 

1. ターゲットインデックスを含む正しい桁長を決定します。 
2. 左から右へ貪欲に数値を構築します。 
3. 各候補桁について$d\in\{1,3,5,7,9\}$:

 - 有効な補完がいくつ存在するかを計算します。 
- 残りのランクと比較します。 
- 数字をスキップするか選択します。 

これは標準的な辞書編集のランク付け解除です。 

---

 # Pythonの実装```python
from functools import lru_cache

DIGITS = [1, 3, 5, 7, 9]
BIT = {1:0, 3:1, 5:2, 7:3, 9:4}

TARGET = 10**16

@lru_cache(None)
def dp(rem, mod7, mask):
    """
    Number of ways to complete a number with:
      rem digits still to place,
      current residue mod 7,
      parity mask of digit counts.
    The FINAL digit is forced to be 5.
    """

    if rem == 0:
        return int(mod7 == 0 and mask == 31)

    total = 0

    for d in DIGITS:
        nmod = (mod7 * 10 + d) % 7
        nmask = mask ^ (1 << BIT[d])
        total += dp(rem - 1, nmod, nmask)

    return total

def count_length(L):
    """
    Count valid very odd numbers with exactly L digits.
    """
    # final digit fixed to 5
    if L == 1:
        return 0

    total = 0

    for d in [1,3,5,7,9]:
        mod7 = d % 7
        mask = 1 << BIT[d]

        total += finish(L - 2, mod7, mask)

    return total

@lru_cache(None)
def finish(rem, mod7, mask):
    """
    Finish middle digits, then append mandatory trailing 5.
    """
    if rem == 0:
        mod7 = (mod7 * 10 + 5) % 7
        mask ^= (1 << BIT[5])
        return int(mod7 == 0 and mask == 31)

    total = 0

    for d in DIGITS:
        nmod = (mod7 * 10 + d) % 7
        nmask = mask ^ (1 << BIT[d])
        total += finish(rem - 1, nmod, nmask)

    return total

def theta(n):
    # determine length
    L = 1

    while True:
        c = count_length(L)
        if n > c:
            n -= c
            L += 1
        else:
            break

    # construct lexicographically
    ans = ""

    mod7 = 0
    mask = 0

    for pos in range(L - 1):
        for d in DIGITS:
            if pos == L - 1:
                continue

            nmod = (mod7 * 10 + d) % 7
            nmask = mask ^ (1 << BIT[d])

            rem = L - pos - 2

            cnt = finish(rem, nmod, nmask)

            if n > cnt:
                n -= cnt
            else:
                ans += str(d)
                mod7 = nmod
                mask = nmask
                break

    ans += "5"

    return int(ans)

print(theta(10**16))
```---

 # コードのチュートリアル

 ## 状態エンコーディング```python
mask ^= (1 << BIT[d])
```数字のパリティを切り替えます$d$。 

例:

 - 数字 3 が 1 回出現 → 奇数
 - 2 回出現 → 偶数
 - 3 回出現 → 再び奇数

 したがって、必要なのはパリティだけです。 

---

 ## モジュロトラッキング```python
nmod = (mod7 * 10 + d) % 7
```これにより、7 で割り切れる値が段階的に計算されます。

 ## 強制末尾 5

 5 の倍数はすべて 5 で終わる必要があります。 

したがって、無効な結末の探索を完全に回避します。

 # 最終確認

 ブルートフォースの場合、検索スペースは膨大になります。$$5^L$$可能な奇数桁の長さの文字列$L$。 

しかし、DP はすべてを以下に限定します。$$7 \times 32 = 224$$長さごとのコア オートマトンの状態。 

したがって、計算は正確であり、容易に実行可能です。
