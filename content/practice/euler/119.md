 # 数学的分析

 数字を考えてみましょう$N$条件を満たしています。 

させて$$s = s(N)$$その桁の合計になります。 それから$$N = s^k$$ある整数に対して$k \ge 2$。 

したがって、すべての有効な数値は完全累乗であり、その底はその数値の合計と等しくなります。 

強引なアイデアは次のようになります。 

1. 多くの塩基を試す$s$。 
2. 電力を生成する$s^k$。 
3. の桁の合計が正しいかどうかを確認します。$s^k$等しい$s$。 

これが機能する理由は次のとおりです。 

- 桁の合計はゆっくりと増加します。 
- 権力は急速に成長し、
 - 条件を満たす数はごくわずかです。 

---

 ## 検索の境界を設定する

 もし$N$もっている$d$数字、その後$$s(N) \le 9d.$$しかし$N = s^k$、固定のため$s$、権力は最終的に巨大になります。 

経験的には、最初の 30 項を捕捉するには、数百までの基数と 15 ～ 20 程度までの指数を検索するだけで十分です。

 # Pythonの実装```python
def digit_sum(n):
    """Return the sum of decimal digits of n."""
    return sum(int(c) for c in str(n))

values = set()

# Try possible digit sums (bases)
for s in range(2, 200):

    # Generate powers s^k
    power = s * s  # start with k = 2

    for k in range(2, 20):

        # Check the defining property
        if digit_sum(power) == s:
            # Must contain at least two digits
            if power >= 10:
                values.add(power)

        power *= s

# Sort the sequence
sequence = sorted(values)

# Display first several terms
for i, v in enumerate(sequence[:30], start=1):
    print(i, v)

print("a_30 =", sequence[29])
```---
