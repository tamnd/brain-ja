 ## 解決策

 **答え:**`238518915714422000`させて$$a_n=n^2+k^2.$$**連続する 2 つの項**を分割する**最大の素数**が必要です$a_n$そして$a_{n+1}$。 

プライムなら$p$両方を割ると、$$n^2+k^2 \equiv 0 \pmod p$$そして$$(n+1)^2+k^2 \equiv 0 \pmod p.$$減算すると$$(n+1)^2-n^2 = 2n+1 \equiv 0 \pmod p.$$それで$$2n\equiv -1 \pmod p.$$二乗：$$4n^2 \equiv 1 \pmod p.$$から$n^2+k^2\equiv 0$、$$4n^2+4k^2\equiv 0 \pmod p.$$代わりの$4n^2\equiv 1$:$$1+4k^2\equiv 0 \pmod p.$$したがって、そのようなすべての素約数は次の条件を満たします。$$p \mid (4k^2+1).$$逆に、任意の素約数$p\mid (4k^2+1)$の解決策を可能にします$n$経由$$2n+1\equiv 0\pmod p,$$したがって、問題は次のようになります。 

>$P(k)$**の最大の素因数です**$4k^2+1$。 

したがって、私たちが必要とするのは、$$\sum_{k=1}^{10^7} P(k) \pmod{10^{18}}.$$ふるいは効率的に機能します。 

- 初期化$f[k]=4k^2+1$。 
- それぞれの最大の素因数を追跡します$k$。 
- プライムの場合$p\mid 4k^2+1$、次にモジュラールートによって次のようになります。$$p \mid 4(tp\pm k)^2+1,$$進行に沿ってふるいにかけてください$tp\pm k$。 

実装は公開されたチェックを再現します。 

-$\sum_{k\le 10^3}P(k)=299015732$-$\sum_{k\le 10^4}P(k)=223215627804$-$\sum_{k\le 10^5}P(k)=178688812032788$完全な計算を実行する$10^7$最後の 18 桁を返します。
