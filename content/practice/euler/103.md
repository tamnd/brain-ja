 #1. 数学的分析

 セット$A$2 つの空ではない素のサブセットの場合、それは **特別な合計セット**です$B,C\subseteq A$:

 1.$S(B)\neq S(C)$2. もし$|B|>|C|$、 それから$S(B)>S(C)$合計金額が最小の特別な金額セットが必要です。 

---

 ## 主要な構造特性

 仮定してください$$a_1<a_2<\cdots<a_n.$$条件(2)は効率よく確認できます。 

ソートされた正の数値の場合、条件 (2) に違反する最悪のケースは次のとおりです。 

- 最小の$k+1$要素

 対
 - 最大の$k$要素。 

したがって、必要なのは次のものだけです。$$a_1+a_2+\cdots+a_{k+1} > a_n+a_{n-1}+\cdots+a_{n-k+1}$$関連するすべての人にとって$k$。 

のために$n=7$、これは次のようになります。$$a_1+a_2 > a_7$$

$$a_1+a_2+a_3 > a_7+a_6$$

$$a_1+a_2+a_3+a_4 > a_7+a_6+a_5$$これらの不平等により、検索は大幅に削減されます。 

---

 ## 最適に近い構造

 問題ステートメントでは次のヒューリスティックが得られます。 

もし$$A=\{a_1,\dots,a_n\}$$が最適である場合、最適に近いサイズのセット$n+1$は$$B=\{b,a_1+b,\dots,a_n+b\},$$どこ$b$の中間要素です$A$。 

最適なものを使用する$n=6$セット$$\{11,18,19,20,22,25\},$$ヒューリスティックは以下を与えます:$$\{20,31,38,39,40,42,45\}.$$これは真の最適値に非常に近いので、近くを検索するだけで済みます。

 ## 条件 (1): 個別のサブセットの合計

 セットサイズの場合$7$、あるだけです$$2^7-1=127$$空ではないサブセット。 

すべてのサブセットの合計を計算し、互いに素な 2 つのサブセットの合計が等しいことがないことを確認できます。 

標準的なビットマスクのアプローチはうまく機能します。 

- 各サブセットをビットマスクで表します。 
- その合計を計算します。 
- 2 つのサブセットが同じ合計と素のマスクを持つ場合、そのセットを拒否します。 

---

 ## 検索戦略

 ヒューリスティックセンターを探索します。$$(20,31,38,39,40,42,45).$$最適なセットは緊密にクラスター化されているため、限定された DFS/バックトラッキング検索により最小の有効なセットがすぐに見つかります。 

既知の最適値は次のようになります。$$\{20,31,38,39,40,42,45\}.$$その合計は$$20+31+38+39+40+42+45=255.$$したがって、必要な設定文字列は次のようになります。$$20313839404245.$$---

 #2. Pythonの実装```python
from itertools import combinations

def satisfies_rule_two(arr):
    """
    Check:
    If |B| > |C| then S(B) > S(C)

    For sorted positive arrays, it is enough to verify:
    sum(first k+1) > sum(last k)
    """
    n = len(arr)

    for k in range(1, n // 2 + 1):
        if sum(arr[:k + 1]) <= sum(arr[-k:]):
            return False

    return True

def satisfies_rule_one(arr):
    """
    Check:
    No two disjoint non-empty subsets have equal sums.
    """

    n = len(arr)

    # map: subset_sum -> list of masks producing that sum
    sums = {}

    for mask in range(1, 1 << n):

        s = 0
        for i in range(n):
            if mask & (1 << i):
                s += arr[i]

        if s not in sums:
            sums[s] = [mask]
        else:
            # equal sum found; ensure subsets are not disjoint
            for other in sums[s]:
                if (other & mask) == 0:
                    return False

            sums[s].append(mask)

    return True

def is_special_sum_set(arr):
    return (
        satisfies_rule_two(arr)
        and satisfies_rule_one(arr)
    )

best = None
best_sum = float('inf')

# Near-optimum template from the problem statement
base = [20, 31, 38, 39, 40, 42, 45]

# Search nearby
def search(pos, current):
    global best, best_sum

    n = len(base)

    if pos == n:

        if sum(current) >= best_sum:
            return

        if is_special_sum_set(current):
            best = current[:]
            best_sum = sum(current)

        return

    # small perturbations around the heuristic set
    for delta in range(-3, 4):

        val = base[pos] + delta

        if current and val <= current[-1]:
            continue

        current.append(val)

        # early pruning using rule two
        if satisfies_rule_two(current):
            search(pos + 1, current)

        current.pop()

search(0, [])

print(best)
print("set string =", "".join(str(x) for x in best))
```---
