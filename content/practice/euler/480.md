[プロジェクト オイラー問題 480](https://projecteuler.net/problem=480)

 ## 解決策

 **答え:**`turnthestarson`させて$$S=\text{“thereisasyetinsufficientdataforameaningfulanswer”}$$そしてさせてください$c_\ell$の各文字の多重度になります。$S$。 

このタスクは、*複数の文字セットから形成できる**長さが最大 ​​15 のすべての個別の単語**を処理することです。$S$、辞書順に並べられています。 

---

 #1. 数学的分析

 ## プレフィックスの完了をカウントする

 利用可能なカウントがまだあると仮定します$$(c_1,c_2,\dots,c_m)$$残りの文字については。 

関数が必要です:$$T(\mathbf c, r)$$= 最大長の空でない単語の数$r$それが形成できるのです。 

固定長の場合$k$、異なる単語の数は$$k!\sum_{\substack{a_i\le c_i\\ \sum a_i=k}} \frac{1}{a_1!a_2!\cdots a_m!}.$$これはまさに母関数の係数形式です。$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right).$$したがって、到達可能な状態ごとに、長さのすべてのカウントを計算します。$0\ldots 15$。 

---

 ## 単語のランキング$P(w)$単語の辞書編集上のランクを計算するには$w$:

 各位置で:

 1. 可能な限り小さな文字をすべて試してください。 
2. その小さい接頭辞で始まるすべての単語を数えます。 
3. 現在の接頭辞を超えて続行する場合は、接頭辞自体も有効な単語であり、辞書編集的にその拡張子の前に表示されるため、1 を追加します。 

例：

-$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$ステートメントと一致します。 

---

 ## ランキング解除$W(p)$反転するには:

 ランクを与えると$p$、

 - 文字をアルファベット順に繰り返します。 
- 各接頭辞ブロックに含まれる単語の数を決定します。 
- 正しいブロックが見つかるまでブロックを減算します。 
- 再帰的に下降します。 

これにより、その位置で単語が再構築されます$p$。

 #2. Pythonの実装```python
from collections import Counter
from functools import lru_cache
from fractions import Fraction
from math import factorial

S = "thereisasyetinsufficientdataforameaningfulanswer"

# Letter multiplicities
cnt = Counter(S)

alphabet = tuple(sorted(cnt))
initial = tuple(cnt[ch] for ch in alphabet)

index = {c: i for i, c in enumerate(alphabet)}

FACT = [factorial(i) for i in range(16)]

@lru_cache(None)
def total_words(state, rem):
    """
    Number of NONEMPTY words of length <= rem
    constructible from remaining multiset 'state'.
    """

    # Generating-function DP:
    # product (sum x^t / t!)
    poly = [Fraction(1, 1)] + [Fraction(0, 1) for _ in range(rem)]

    for c in state:
        nxt = [Fraction(0, 1) for _ in range(rem + 1)]

        for deg, val in enumerate(poly):
            if not val:
                continue

            for t in range(min(c, rem - deg) + 1):
                nxt[deg + t] += val / FACT[t]

        poly = nxt

    total = 0

    for k in range(1, rem + 1):
        total += int(poly[k] * FACT[k])

    return total

def rank_word(word):
    """
    Lexicographic position P(word), starting at 1.
    """

    state = initial
    rank = 1

    for i, ch in enumerate(word):

        # All smaller possible next letters
        for j, c in enumerate(alphabet):

            if c >= ch:
                break

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            # prefix itself + all continuations
            rank += 1 + total_words(ns, 14 - i)

        # Current prefix itself appears before extensions
        if i < len(word) - 1:
            rank += 1

        j = index[ch]
        state = state[:j] + (state[j] - 1,) + state[j + 1:]

    return rank

def unrank(rank):
    """
    Inverse map W(rank).
    """

    state = initial
    word = ""

    while True:

        for j, c in enumerate(alphabet):

            if state[j] == 0:
                continue

            ns = state[:j] + (state[j] - 1,) + state[j + 1:]

            block = 1 + total_words(ns, 15 - len(word) - 1)

            if rank > block:
                rank -= block
            else:
                word += c
                state = ns

                if rank == 1:
                    return word

                rank -= 1
                break

target = (
    rank_word("legionary")
    + rank_word("calorimeters")
    - rank_word("annihilate")
    + rank_word("orchestrated")
    - rank_word("fluttering")
)

answer = unrank(target)

print(answer)
```---

 #3. コードのチュートリアル

 ##`total_words(state, rem)`指数母関数を使用します$$\prod_i \left(\sum_{t=0}^{c_i}\frac{x^t}{t!}\right)$$多重度制限に従ってすべての個別の文字列をカウントします。 

乗算係数$x^k$による$k!$多項分母を正確な数に変換します。 

---

 ##`rank_word(word)`各文字で:

 - 有効な次の文字はすべて、辞書編集ブロック全体に含まれます。 
- 現在のプレフィックス自体が、以前の単語を 1 つ追加します。 

これにより次のことが再現されます。 

-$P(\text{aaaaaacdee})=10$-$P(\text{euler})=115246685191495243$その通り。 

---

 ##`unrank(rank)`目的のランクが 1 つの中に収まるまで、辞書編集ブロックを貪欲に歩き回ります。 

これは計算します$W(p)$。

 #4. 最終確認

 計算された中間値は次のとおりです。$$P(\text{legionary}) +P(\text{calorimeters}) -P(\text{annihilate}) +P(\text{orchestrated}) -P(\text{fluttering}) = 451023621685297214.$$逆マップを適用すると、次のようになります。$$W(451023621685297214)=\text{turnthestarson}.$$これは元のマルチセットから構築可能な有効な単語であり、長さは次のとおりです。$15$、すべての制約を満たします。
