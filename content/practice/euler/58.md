[プロジェクト オイラー問題 58](https://projecteuler.net/problem=58)

 ## 解決策

 **答え:**`26241`この問題の鍵は、スパイラルが成長するにつれて対角線の数字がどのように変化するかを理解することです。 

辺の長さの螺旋の場合$n$（どこ$n$は奇数です)、外側の層はちょうど 4 つの新しいコーナー番号に寄与します。 

たとえば:

 - 辺の長さ$1$： ただ$1$- 辺の長さ$3$: コーナーは$3,5,7,9$- 辺の長さ$5$: コーナーは$13,17,21,25$- 辺の長さ$7$: コーナーは$31,37,43,49$素数である対角数の数を追跡し、その比率が最初に下回った時点を判断する必要があります。$10\%$。 

---

 # 数学的分析

 ## 1. コーナー番号の計算式

 辺の長さが奇数の正方形の螺旋を考えてみましょう$n$。 

レイヤー内の最大の数値は常に右下隅になります。$$n^2$$隣接するコーナー間のステップ サイズは次のとおりです。$$n-1$$したがって、四隅は次のようになります。$$\begin{aligned} c_1 &= n^2 \\ c_2 &= n^2-(n-1) \\ c_3 &= n^2-2(n-1) \\ c_4 &= n^2-3(n-1) \end{aligned}$$例$n=7$:$$49,\ 43,\ 37,\ 31$$これは図と一致します。 

---

 ## 2. 対角エントリの数

 新しいレイヤーごとに、4 つの対角線の数字が追加されます。 

辺の長さについて$n$:$$\text{total diagonal numbers} = 2n-1$$チェック：

-$n=1$:$1$-$n=3$:$5$-$n=5$:$9$-$n=7$:$13$正しい。 

---

 ## 3.素数比

 各層で:

 1. 4 隅の番号を生成します。 
2. それぞれの素数性をテストします。 
3. 更新:$$\text{ratio} = \frac{\text{prime diagonal count}} {\text{total diagonal count}}$$私たちは最初のものを求めます$n$次のような:$$\frac{\text{primes}}{2n-1} < 0.10$$---

 # Pythonの実装```python
import math

def is_prime(n):
    """Return True if n is prime, else False."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = int(math.isqrt(n))
    d = 3

    while d <= limit:
        if n % d == 0:
            return False
        d += 2

    return True

prime_count = 0
diagonal_count = 1   # starts with center value 1
side_length = 1

while True:
    side_length += 2

    square = side_length * side_length
    step = side_length - 1

    # The four corner values
    corners = [
        square,
        square - step,
        square - 2 * step,
        square - 3 * step
    ]

    # Count primes among the corners
    for c in corners:
        if is_prime(c):
            prime_count += 1

    diagonal_count += 4

    # Check ratio
    if prime_count / diagonal_count < 0.10:
        print(side_length)
        break
```---
