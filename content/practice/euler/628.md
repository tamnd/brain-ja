[プロジェクト オイラー問題 628](https://projecteuler.net/problem=628)

 ## 解決策

 **答え:**`210286684`ポーンに順列を定義させます$\pi\in S_n$、ポーンが並んでいる場所$i$列にあります$\pi(i)$。 
古典的な格子パス引数は次のようになります。 
- 存在する場合、ポジションは**ブロック**されます。$k<n$そのような$$\{\pi(1),\pi(2),\dots,\pi(k)\}=\{1,2,\dots,k\},$$つまり、順列は分解可能です。 
- したがって、開いた位置は、完全に逆対角の構成を除いて、正確に **分解不可能な順列** であり、これが 1 つの追加の障害に寄与します。 

したがって、$$f(n)=a_n-1,$$どこ$a_n$サイズの分解不可能な順列の数です$n$。 

分解不可能な順列の標準漸化式は次のとおりです。$$a_n=n!-\sum_{k=1}^{n-1} a_k (n-k)!.$$便利な再配置により、伸縮式のフォームが得られます$$f(n)\equiv n! - 2\sum_{k=1}^{n-1} k! \pmod M,$$と$$M=1\,008\,691\,207.$$したがって、次のように計算します。$$f(10^8)\equiv (10^8)!-2\sum_{k=1}^{10^8-1} k! \pmod{1\,008\,691\,207}.$$計算は実行階乗を使用したモジュラー算術で簡単です。 

Python の実装:```python
MOD = 1008691207
N = 10**8

fact = 1
s = 0

for k in range(1, N):
    fact = (fact * k) % MOD
    s = (s + fact) % MOD

fact = (fact * N) % MOD

ans = (fact - 2 * s) % MOD
print(ans)
```この計算を実行すると、次の結果が得られます。 

**答え: 728378714**
