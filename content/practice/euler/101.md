 ## 解決策

 **答え:**`37076114526`させて$$u_n = 1-n+n^2-n^3+\cdots-n^9+n^{10}.$$次数の最適多項式 (OP) から得られる FIT (「最初に誤った項」) の合計を計算するように求められます。$k-1$最初のフィッティング$k$数列の項、つまり$k=1,\dots,10$。 

---

 # ステップ 1 — 数学を理解する

 シーケンスは 10 次の多項式によって生成されます$$u(n)=\sum_{i=0}^{10}(-1)^i n^i.$$私たちに最初に与えられたのは、$k$価値観$$u(1),u(2),\dots,u(k),$$固有の多項式を構築します$P_k(n)$せいぜい程度の$k-1$それらを補間します。 

この多項式は「最適多項式」と呼ばれます。$$\operatorname{OP}(k,n)=P_k(n).$$真の母関数には次数があるため$10$：

- のために$k<11$、$P_k(n)\neq u(n)$、
 - したがって、最初の不一致は次の時点で発生します。$n=k+1$、
 - FIT は$$P_k(k+1).$$計算しなければなりません$$\sum_{k=1}^{10} P_k(k+1).$$---

 # ステップ 2 — シーケンス値を計算する

 最初の評価$u(n)$のために$n=1,\dots,11$。 

便利な単純化は、有限等比級数恒等式です。$$1-n+n^2-\cdots+n^{10} = \frac{1+n^{11}}{1+n}.$$確かに、$$\sum_{i=0}^{10}(-n)^i = \frac{1-(-n)^{11}}{1-(-n)} = \frac{1+n^{11}}{1+n}.$$それで：$$u(n)=\frac{n^{11}+1}{n+1}.$$最初の値は次のとおりです。$$\begin{aligned} u(1)&=1\\ u(2)&=683\\ u(3)&=44287\\ u(4)&=838861\\ u(5)&=8138021\\ u(6)&=51828151\\ u(7)&=247165843\\ u(8)&=954437177\\ u(9)&=3138105961\\ u(10)&=9090909091. \end{aligned}$$---

 # ステップ 3 — 補間のアイデア

 それぞれについて$k$、次数の多項式を補間します$k-1$最初を通して$k$ポイント:$$(1,u_1),\dots,(k,u_k).$$最もきれいな公式はラグランジュ補間です。$$P_k(x)= \sum_{i=1}^{k} u_i \prod_{\substack{1\le j\le k\\j\ne i}} \frac{x-j}{i-j}.$$するとFITは$$P_k(k+1).$$これらを合計すると、$k=1,\dots,10$。 

---

 # ステップ 4 — Python の実装```python
from fractions import Fraction

# True generating function
def u(n):
    return sum(((-1) ** i) * (n ** i) for i in range(11))

# Lagrange interpolation evaluated at x
def interpolate(xs, ys, x):
    total = Fraction(0, 1)

    for i in range(len(xs)):
        term = Fraction(ys[i], 1)

        for j in range(len(xs)):
            if i != j:
                term *= Fraction(x - xs[j], xs[i] - xs[j])

        total += term

    return total

answer = 0

# Compute FITs for k = 1..10
for k in range(1, 11):

    xs = list(range(1, k + 1))
    ys = [u(n) for n in xs]

    # First incorrect term occurs at n = k+1
    fit = interpolate(xs, ys, k + 1)

    answer += fit

print(answer)
```---

 ##`interpolate(xs, ys, x)`正確な有理算術を使用します (`Fraction`) 浮動小数点エラーを避けるため。 

各補間基底多項式について:```python
term *= Fraction(x - xs[j], xs[i] - xs[j])
```これは構築します$$\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}.$$すべての基底項を合計すると、次のように評価される固有の補間多項式が得られます。$x$。
