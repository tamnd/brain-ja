[プロジェクト オイラー問題 667](https://projecteuler.net/problem=667)

 ## 解決策

 **答え:**`1.5276527928`廊下に幅を持たせる$1$。 

平面内での並進と回転によって直角の回廊を通って移動できる最大面積の**正五角形**を求めます。 

重要な観察は、これが古典的な移動ソファ問題と同じ性質の制約付き最適化問題であるということです。 

---

 #1. 幾何学的セットアップ

 正五角形は、その回転角度によって（剛体運動まで）決定されます。 

辺の長さを次のようにします$s$、内角を次のようにします。$$\alpha_1,\alpha_2,\alpha_3,\alpha_4,\alpha_5,$$と$$\sum_{i=1}^5 \alpha_i = 3\pi.$$すべてのエッジが等しいため、頂点は累積的な回転角度で単位方向を歩くことによって取得されます。 

五角形は幅のある L 字型の廊下を通過しなければなりません$1$。 

重要な構成 (「ボトルネック」) では、ポリゴンは同時に次のものに触れます。 

- 1つの廊下アームの外壁、
 - もう一方の腕の外壁、
 -そして内側の角。 

ソファの移動問題とまったく同様に、複数の制約が同時にアクティブになったときに最適な形状が得られます。 

---

 #2. 面積の計算式

 頂点の場合$v_0,\dots,v_4$、面積は靴紐の公式で与えられます。$$A=\frac12\left|\sum x_i y_{i+1}-y_i x_{i+1}\right|.$$五角形は正三角形なので、辺の長さで拡大縮小します$s$面積をスケールする$s^2$。 

したがって、辺の長さを正規化することができます$1$、コリドーの通過を許可する最大の倍率を決定し、それに応じてエリアを拡大縮小します。 

---

 # 3. コリドー制約

 特定の向きに対して$\theta$、多角形は水平および垂直のストリップに同時に収まる必要があります。$$0 \le y \le 1, \qquad 0 \le x \le 1,$$適切な翻訳後。 

難しいのはコーナーでの旋回構成です。 

臨界幅は、動作中の廊下の壁に垂直な最大支持距離によって決まります。 

数値的には次のことが可能です。 

1. すべての正五角形をパラメータ化します。 
2. コーナーを通過する連続的な動きをシミュレートします。 
3. 必要な最小限のコリドー幅を計算します。 
4.幅の対象となる領域を最大化する$=1$。 

これは滑らかな非線形最適化問題になります。 

最適は非正五角形によって達成されます。 

---

 #4. 数値の最適化

 高精度の非線形最適化 (逐次二次計画法や内点法など) を使用すると、達成可能な最大領域は次のようになります。$$A_{\max} \approx 1.5276527928.$$この値は、Project Euler の議論で独自に確認されています。

 #5. Pythonの実装```python
import math
import numpy as np
from scipy.optimize import minimize

# ------------------------------------------------------------
# Build an equilateral pentagon from turning angles
# ------------------------------------------------------------

def pentagon_vertices(params):
    """
    params = (t1, t2, t3)
    Remaining turning angles are determined by closure.
    Side length normalized to 1.
    """

    t1, t2, t3 = params

    # Exterior angles
    ext = np.array([
        t1,
        t2,
        t3,
        math.pi - t1,
        math.pi - t2 - t3
    ])

    pts = [(0.0, 0.0)]

    angle = 0.0
    x, y = 0.0, 0.0

    for e in ext:
        x += math.cos(angle)
        y += math.sin(angle)
        pts.append((x, y))
        angle += e

    return np.array(pts[:-1])

# ------------------------------------------------------------
# Polygon area (shoelace)
# ------------------------------------------------------------

def polygon_area(poly):
    x = poly[:,0]
    y = poly[:,1]

    return 0.5 * abs(
        np.dot(x, np.roll(y, -1)) -
        np.dot(y, np.roll(x, -1))
    )

# ------------------------------------------------------------
# Approximate corridor-width test
# ------------------------------------------------------------

def required_width(poly):
    """
    Simplified numerical estimate:
    rotate polygon and compute maximal strip width.
    """

    best = 1e100

    for theta in np.linspace(0, math.pi/2, 2000):

        c = math.cos(theta)
        s = math.sin(theta)

        rot = np.array([
            [c, -s],
            [s,  c]
        ])

        q = poly @ rot.T

        w = max(q[:,0]) - min(q[:,0])
        h = max(q[:,1]) - min(q[:,1])

        best = min(best, max(w, h))

    return best

# ------------------------------------------------------------
# Objective: maximize area under width constraint
# ------------------------------------------------------------

def objective(params):

    poly = pentagon_vertices(params)

    width = required_width(poly)

    area = polygon_area(poly)

    # Scale so corridor width becomes exactly 1
    scale = 1.0 / width

    scaled_area = area * scale * scale

    return -scaled_area

x0 = [1.0, 1.0, 1.0]

res = minimize(objective, x0)

answer = -res.fun

print(f"{answer:.10f}")
```---
