[プロジェクト オイラー問題 129](https://projecteuler.net/problem=129)

 ## 解決策

 **答え:**`1000023`させて$$R(k)=\underbrace{111\ldots 1}_{k\text{ digits}}$$長さの繰り返しになる$k$。 以来$$R(k)=1+10+10^2+\cdots+10^{k-1}$$クローズドフォームがあります$$R(k)=\frac{10^k-1}{9}.$$私たちは定義します$A(n)$最小になる$k$そのような$R(k)\equiv 0\pmod n$と仮定すると$\gcd(n,10)=1$。 

この問題は最低限のものを求めます$n$そのような$$A(n)>1{,}000{,}000.$$---

 #1. 数学的分析

 私たちは最低限のものを望んでいます$n$最小レピュユニット倍数の長さが 100 万を超える場合。 

---

 ## ステップ 1: 割り算条件を再定式化する

 必要です$$R(k)\equiv 0 \pmod n.$$使用する$$R(k)=\frac{10^k-1}{9},$$私たちは得ます$$\frac{10^k-1}{9}\equiv 0 \pmod n.$$もし$\gcd(n,9)=1$、これは次と同等です$$10^k\equiv 1 \pmod n.$$より一般的には、$A(n)$は次の乗算順序です$10$モジュロ$9n$(またはモジュロ$n$いつ$9\nmid n$）。 

ただし、計算には高度な数論は必要ありません。 計算できる$A(n)$モジュラー反復を直接使用します。 

---

 ## ステップ 2: コンピューティング$A(n)$効率的に

 膨大な反復を構築する代わりに、反復を定義する$$r_k = R(k)\bmod n.$$それから$$R(k+1)=10R(k)+1,$$それで$$r_{k+1}=(10r_k+1)\bmod n.$$まずは以下から始めます:$$r_1=1\bmod n.$$最初$k$そのような$r_k=0$まさに$A(n)$。 

これにはモジュラー演算のみが必要であり、次のように実行されます。$O(A(n))$時間。 

---

 ## ステップ 3: 重要な所見

 以来$A(n)\le n$素数用$n$10 を除算しない (順序が除算するため)$\varphi(n)=n-1$）、すぐに次のことがわかります。 

- もし$A(n)>10^6$、そうすると必然的に$n>10^6$。 

そこで、100 万を少し超えるところで検索を開始します。 

また:

 - 割り切れる数$2$または$5$レプユニットを分割することはできません。 
- したがって、そのようなものはスキップします$n$。 

---

 ## ステップ 4: 戦略

 整数をテストします$n>10^6$と$\gcd(n,10)=1$:

 1. コンピューティング$A(n)$反復的なモジュール再帰によって。 
2. 最初のところで停止$n$と$A(n)>10^6$。 

そのような最初の$n$が答えです。 

---

 #2. Pythonの実装```python
from math import gcd

LIMIT = 1_000_000

def A(n):
    """
    Compute the least k such that R(k) is divisible by n,
    where R(k) = 111...1 (k ones).
    Assumes gcd(n, 10) = 1.
    """
    remainder = 1 % n
    k = 1

    while remainder != 0:
        remainder = (remainder * 10 + 1) % n
        k += 1

    return k

n = LIMIT + 1

while True:

    # Repunits can only be divisible by numbers coprime to 10
    if gcd(n, 10) == 1:

        if A(n) > LIMIT:
            print(n)
            break

    n += 1
```---

 #4. 小さな例の検証

 問題には次のように書かれています。$$A(7)=6.$$確かに：$$111111 = 7 \times 15873.$$繰り返しを実行します。 

-$1 \bmod 7 = 1$-$11 \bmod 7 = 4$-$111 \bmod 7 = 6$-$1111 \bmod 7 = 5$-$11111 \bmod 7 = 2$-$111111 \bmod 7 = 0$それで$A(7)=6$。 

また：$$A(17)=16>10,$$これは、17 が最初であるというステートメントと一致します。$n$と$A(n)>10$。

 #5. 最終検証

 答えは次のとおりです。 

- よりわずかに大きい$10^6$、
 - 10と互いに素である、
 - 10 という非常に大きな乗法次数を持っています。 

計算により次の結果が得られます。$$n = 1{,}000{,}023.$$これは確かに 100 万をわずかに超えており、満足です$$A(1{,}000{,}023) > 1{,}000{,}000.$$**答え: 1000023**
