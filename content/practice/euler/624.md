[プロジェクト オイラー問題 624](https://projecteuler.net/problem=624)

 ## 解決策

 **答え:**`984524441`させて$M$2 つの連続した表が最初に出現したときのトス インデックスになります (つまり、トスは$M-1,M$HHです）。 私たちは求めています$$P(n)=\Pr(n\mid M)$$のために$n=10^{18}$、次に計算します$$Q(P(n),p) \quad\text{with}\quad p=1{,}000{,}000{,}009.$$---

 ## 1. 数学的分析

 ### ステップ 1: の配布$M$持つこと$M=m$、シーケンス:

 - HH で終わる必要があります。 
- **以前の HH** を含める必要はありません。 

有効な長さのバイナリ文字列の数$m$最初の HH で終わるのはフィボナッチ数です。 

させて$A_m$toss で終わる有効なシーケンスの数になります。$m$。 

最初のHHがトスで発生した場合$m$、そしてトスします$m-1$そして$m$H、H、そして最初の$m-2$トスは連続した表を避け、T で終わる必要があります。 

これにより、次のようになります。$$A_m = F_{m-1}$$どこ$F_k$はフィボナッチ数列 ($F_0=0,F_1=1$）。 

したがって、$$\Pr(M=m)=\frac{F_{m-1}}{2^m}.$$それで$$P(n) = \sum_{k\ge1} \frac{F_{kn-1}}{2^{kn}}.$$---

 ### ステップ 2: クローズドフォームに変換する

 ビネーの公式を使用すると、次のようになります。$$F_m=\frac{\phi^m-\psi^m}{\sqrt5},$$どこ$$\phi=\frac{1+\sqrt5}{2}, \qquad \psi=\frac{1-\sqrt5}{2}.$$それから$$F_{kn-1} = \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$合計に代入します。$$P(n) = \sum_{k\ge1} \frac{1}{2^{kn}} \cdot \frac{\phi^{kn-1}-\psi^{kn-1}}{\sqrt5}.$$各部分は幾何学的であるため、合計して単純化すると次のようになります。$$P(n) = \frac{ 2^nF_{n-1}-(-1)^n }{ 4^n-2^nL_n+(-1)^n },$$どこ$L_n$はルーカス番号です:$$L_n = F_{n-1}+F_{n+1}.$$例を確認してください。 

のために$n=2$:$$P(2)=\frac{4\cdot1-1}{16-4\cdot3+1} =\frac35.$$のために$n=3$:$$P(3)=\frac{8\cdot1-(-1)}{64-8\cdot4-1} = \frac{9}{31}.$$どちらもステートメントと一致します。 

---

 ### ステップ 3: モジュールの解釈

 必要です$$Q\!\left(P(n),p\right)$$ユニークな残基はどれですか$q$満足のいく$$a \equiv bq \pmod p$$のために$P(n)=a/b$。 

したがって$$Q(P(n),p) = a\,b^{-1}\pmod p.$$したがって、必要なのは分子と分母のモジュロだけです$p$。 

のために$n=10^{18}$、次を計算します。 

-$F_{n-1}\pmod p$、
 -$F_{n+1}\pmod p$、
 -$L_n=F_{n-1}+F_{n+1}\pmod p$、
 -$2^n\pmod p$、
 -$4^n\pmod p$、

 **高速ダブリングフィボナッチ**を使用して$O(\log n)$。

 ## 2. Python の実装```python
MOD = 1_000_000_009
N = 10**18

def fib(n, mod):
    """Fast doubling Fibonacci.
    Returns (F_n, F_{n+1}) modulo mod.
    """
    if n == 0:
        return (0, 1)

    a, b = fib(n >> 1, mod)

    # F(2k)
    c = (a * ((2 * b - a) % mod)) % mod

    # F(2k+1)
    d = (a * a + b * b) % mod

    if n & 1:
        return d, (c + d) % mod
    return c, d

# Fibonacci values
Fn_minus_1 = fib(N - 1, MOD)[0]
Fn, Fn_plus_1 = fib(N, MOD)

# Lucas number: L_n = F_{n-1} + F_{n+1}
Ln = (Fn_minus_1 + Fn_plus_1) % MOD

# Powers
pow2 = pow(2, N, MOD)
pow4 = pow(4, N, MOD)

# Since N = 10^18 is even, (-1)^N = 1
sign = 1

# Numerator and denominator modulo MOD
numerator = (pow2 * Fn_minus_1 - sign) % MOD
denominator = (pow4 - pow2 * Ln + sign) % MOD

# Modular division
answer = numerator * pow(denominator, MOD - 2, MOD) % MOD

print(answer)
```---

 ## 3. コードのチュートリアル

 ### 高速倍増

 アイデンティティ:$$F_{2k}=F_k(2F_{k+1}-F_k),$$

$$F_{2k+1}=F_k^2+F_{k+1}^2$$フィボナッチ計算を許可します$O(\log n)$。 

関数は以下を返します:$$(F_n,F_{n+1})$$必要なものをすべて回復できるようにします。 

### ルーカス番号

 私たちは以下を使用します:$$L_n = F_{n-1}+F_{n+1}.$$### 確率の公式

 以来$N$は偶数です:$$(-1)^N=1.$$したがって：$$a = 2^N F_{N-1}-1,$$

$$b = 4^N - 2^N L_N + 1.$$ついに：$$Q(P(N),p)=a\,b^{-1}\pmod p.$$### 小規模な例の検証

 のために$n=2$:$$P(2)=\frac35$$とモジュロ$109$:$$5^{-1}\cdot3 \equiv 66.$$のために$n=3$:$$P(3)=\frac9{31}$$とモジュロ$109$:$$31^{-1}\cdot9 \equiv 46.$$どちらも問題の声明に同意します。
