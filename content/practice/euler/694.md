[プロジェクト オイラー問題 694](https://projecteuler.net/problem=694)

 ## 解決策

 **答え:**`1339784153569958487`させて$C$立方体いっぱいの数値のセットになります。 以来$s(n)$の立方体全体の約数を数えます$n$、$$S(N)=\sum_{n\le N}s(n)$$除数によってインデックスを再作成できます。$$S(N) = \sum_{d\in C,\ d\le N} \left\lfloor \frac{N}{d}\right\rfloor$$それぞれのキューブがいっぱいなので$d$貢献する$1$の倍数ごとに$d$。 

したがって、タスクはすべての立方体全体の数値を列挙することになります。$d\le 10^{18}$そして合計$\lfloor N/d\rfloor$。 

立方体フル数には少なくともすべての素指数が含まれます$3$したがって、素数べき乗を乗算することで再帰的にそれらを一意に生成できます。$p^e$と$e\ge 3$。 

使用される Python 実装:```python
from math import isqrt

def sieve(n):
    bs = bytearray(b'\x01') * (n + 1)
    bs[:2] = b'\x00\x00'
    for i in range(2, isqrt(n) + 1):
        if bs[i]:
            bs[i * i:n + 1:i] = b'\x00' * (((n - i * i) // i) + 1)
    return [i for i, b in enumerate(bs) if b]

primes = sieve(10**6)  # cube root of 10^18

def S(N):
    total = N  # contribution from d = 1

    def dfs(start_index, current):
        nonlocal total
        remaining = N // current

        for j in range(start_index, len(primes)):
            p = primes[j]
            p3 = p * p * p
            if p3 > remaining:
                break

            pe = p3
            while pe <= remaining:
                v = current * pe
                total += N // v
                dfs(j + 1, v)
                pe *= p

    dfs(0, 1)
    return total

print(S(16))      # 19
print(S(100))     # 126
print(S(10000))   # 13344
print(S(10**18))
```検証：

-$S(16)=19$✓
 -$S(100)=126$✓
 -$S(10000)=13344$✓
