[プロジェクト オイラー問題 92](https://projecteuler.net/problem=92)

 ## 解決策

 **答え:**`8581146`させて$f(n)$は、次の桁の二乗の和を示します。$n$。 

例えば、$$f(44)=4^2+4^2=32.$$繰り返し適用する$f$チェーンを生成します:$$44 \to 32 \to 13 \to 10 \to 1,$$

$$85 \to 89 \to 145 \to 42 \to \cdots \to 89.$$問題は次のように尋ねます。 

> 開始番号はいくつですか$1 \le n < 10^7$最終的に到着する$89$?

 ---

 # 数学的分析

 ## 1. 重要な観察: チェーンは急速に縮小する

 仮定してください$n < 10^7$。 それから$n$多くても$7$数字。 

平方和の最大値は次の場合に発生します。$$9,999,999$$その桁の二乗和は$$7 \cdot 9^2 = 7 \cdot 81 = 567.$$したがって、**1 ステップ** の後、1,000 万未満のすべての数値が範囲にマッピングされます。$$1 \le f(n) \le 567.$$これが重要な洞察です。 

1,000 万の長いチェーンを個別に研究する代わりに、値ごとに決定するだけで済みます。$1,\dots,567$、最終的に以下に達するかどうか。 

-$1$、 または
-$89$。 

その後、それより大きな数字はすべて、最初の桁の 2 乗和の運命を引き継ぎます。 

---

 ## 2. 終末期サイクル

 実験的には (そしてそれは証明されていますが)、すべてのチェーンは次の 2 つのサイクルのいずれかで終了します。$$1 \to 1$$または$$89 \to 145 \to 42 \to 20 \to 4 \to 16 \to 37 \to 58 \to 89.$$したがって、すべての開始番号は最終的にどちらかになります。$1$または$89$。 

---

 ## 3. 動的プログラミング/メモ化

 定義:$$g(x)= \begin{cases} 1 & \text{if the chain reaches }1,\\ 89 & \text{if the chain reaches }89. \end{cases}$$私たちは計算します$g(x)$みんなのために$x \le 567$メモ化を使用します。 

次に、それぞれの数字について$n < 10^7$:

 1. コンピューティング$s=f(n)$。 
2. かどうかを調べます。$s$で終わる$89$。 

これにより、$O(10^7)$これは Python で完全に実現可能です。 

---

 # Pythonの実装```python
def digit_square_sum(n):
    """Return the sum of the squares of the digits of n."""
    total = 0
    while n > 0:
        digit = n % 10
        total += digit * digit
        n //= 10
    return total

# Memo table:
# memo[x] = True  if x eventually reaches 89
# memo[x] = False if x eventually reaches 1
memo = {1: False, 89: True}

def arrives_at_89(n):
    """
    Determine whether n eventually reaches 89.
    Uses memoization to avoid recomputation.
    """
    chain = []

    while n not in memo:
        chain.append(n)
        n = digit_square_sum(n)

    result = memo[n]

    # Store results for all numbers seen in the chain
    for x in chain:
        memo[x] = result

    return result

LIMIT = 10_000_000

count = 0

for n in range(1, LIMIT):
    if arrives_at_89(digit_square_sum(n)):
        count += 1

print(count)
```---
