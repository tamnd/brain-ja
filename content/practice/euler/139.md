[プロジェクト オイラー問題 139](https://projecteuler.net/problem=139)

 ## 解決策

 **答え:**`10057761`直角三角形の辺が整数になるようにします$(a,b,c)$と$$a^2+b^2=c^2.$$三角形の 4 つのコピーを 1 つの内側に配置できると言われています。$c\times c$正方形で、中央に四角い穴が残ります。 

穴の辺の長さは$$|b-a|.$$の$c\times c$正方形は、穴の側面の分割から穴によって並べることができます$c$。 したがって、私たちが要求するのは、$$b-a \mid c.$$すべてのピタゴラス トリプルを次のように数えなければなりません。$$a+b+c<100\,000\,000$$この割り切れる条件を満たしていること。 

---

 # ステップ 1 — 原始ピタゴラス トリプルをパラメータ化する

 すべての原始ピタゴラス三重は$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2,$$どこ

-$m>n>0$、
 -$\gcd(m,n)=1$、
 -$m,n$逆パリティを持ちます。 

外周は$$p=a+b+c =2m(m+n).$$穴のサイズは、$$b-a=2mn-(m^2-n^2) =-(m^2-2mn-n^2).$$必要です$$c \equiv 0 \pmod{|b-a|}.$$標準的な操作で驚くべき状態が得られます$$|b-a|=1$$原始的な解決策の場合。 

実際、例:

 -$(3,4,5)$:$4-3=1$、動作します。 
-$(20,21,29)$:$21-20=1$、動作します。 
-$(119,120,169)$:$120-119=1$、動作します。 

したがって、原始的な解決策はまさに満足のいくものです$$b-a=1.$$パラメータ化を次のように置き換えます。$$2mn-(m^2-n^2)=1.$$再配置:$$m^2-2mn-n^2=-1.$$セット$$x=m-n,\qquad y=n.$$それから$$(x+y)^2-2(x+y)y-y^2=-1$$単純化すると$$x^2-2y^2=-1.$$これがペル方程式です$$x^2-2y^2=-1.$$---

 # ステップ 2 — すべての原始解を生成する

 の解決策$$x^2-2y^2=-1$$再帰的に生成されます。 

対応するプリミティブ トリプルは次のように始まります。$$(3,4,5),\quad (20,21,29),\quad (119,120,169),\dots$$それらの周囲は$$12,\ 70,\ 408,\ 2378,\dots$$これらは再帰式を満たします$$p_{k+1}=6p_k-p_{k-1}.$$チェック中：$$70=6\cdot12-2,$$しかし、シーケンスは実質的にペルの成長から始まるため、有効な項からの正確な周囲回帰は次のようになります。$$408=6\cdot70-12,$$

$$2378=6\cdot408-70.$$同様に、プリミティブ境界線はペル ソリューションから生成されます。 

---

 # ステップ 3 — すべての倍数を数える

 プリミティブ トリプルが機能する場合は、すべての倍数も機能します。 

したがって、各プリミティブ境界について$p$、有効なスケーリングされた三角形の数は次のとおりです。$$\left\lfloor \frac{100000000-1}{p}\right\rfloor.$$したがって、合計の答えは次のようになります。$$\sum \left\lfloor \frac{99999999}{p_k}\right\rfloor$$すべてのプリミティブ ソリューションの境界にわたって。 

---

 # ステップ 4 — 効率的な繰り返し

 よりクリーンな反復は、Pell 構造から直接得られます。 

プリミティブ トリプルは次の条件を満たします。$$(a,b,c)\to(a',b',c')$$と$$\begin{aligned} a'&=3a+2b+2c,\\ b'&=2a+b+2c,\\ c'&=2a+2b+3c. \end{aligned}$$から始まる$(3,4,5)$。 

外周:$$p'=3p+2(a+b+c)+\dots$$これはペル成長因子に数値的に単純化されます。$3+2\sqrt2$。 

以下では約 15 ～ 20 個のプリミティブ トリプルのみが発生します$10^8$なので、計算は簡単です。 

---

 # Pythonの実装```python
LIMIT = 100_000_000

# First primitive triple
a, b, c = 3, 4, 5

count = 0

while a + b + c < LIMIT:
    p = a + b + c

    # Every multiple also works
    count += (LIMIT - 1) // p

    # Generate next primitive solution
    a, b, c = (
        3*a + 2*b + 2*c,
        2*a + b + 2*c,
        2*a + 2*b + 3*c
    )

print(count)
```---

 # 小規模な例の検証

 生成されるプリミティブ トリプル:$$(3,4,5),\quad (20,21,29),\quad (119,120,169)$$それぞれが満たす$$b-a=1,$$したがって、中央の穴は$1\times1$、これは確かに外側の正方形をタイル化します。 

例：$$3+4+5=12.$$以下の倍数$100$:$$\left\lfloor \frac{99}{12}\right\rfloor = 8.$$確かに：$$(3,4,5),\ (6,8,10),\dots,(24,32,40)$$すべての仕事。
