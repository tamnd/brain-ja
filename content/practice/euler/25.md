[プロジェクト オイラー問題 25](https://projecteuler.net/problem=25)

 ## 解決策

 **答え:**`4782`インデックスを探します$n$最初のフィボナッチ数と$1000$数字。 

フィボナッチ数列は次の条件を満たします。$$F_n = F_{n-1}+F_{n-2}, \qquad F_1=1,\;F_2=1$$数字には$1000$次の場合の桁数:$$F_n \ge 10^{999}$$ビネーの公式からの近似を使用すると、次のようになります。$F_n\approx \frac{\varphi^n}{\sqrt{5}}$どこ$\varphi = \frac{1+\sqrt5}{2}$。 

私たちは次のことを解決します:$$\frac{\varphi^n}{\sqrt5} \ge 10^{999}$$対数を取る：$$n\log_{10}(\varphi)-\log_{10}(\sqrt5)\ge 999$$

$$n \ge \frac{999+\log_{10}(\sqrt5)} {\log_{10}(\varphi)}$$評価すると次のようになります。$$n \ge 4781.859\ldots$$したがって、最初の有効なインデックスは次のようになります。$$n = 4782$$### Python コード```python
a, b = 1, 1
index = 2

while len(str(b)) < 1000:
    a, b = b, a + b
    index += 1

print(index)
```精神的に追跡する:

 -$F_{12}=144$確かに最初の 3 桁のフィボナッチ数です (例と一致します)。 
- ループは、最初の項が 1000 桁に達するまで増分されます。 
- 計算されたインデックスは **4782** です。 

**答え: 4782**
