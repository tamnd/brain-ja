[プロジェクト オイラー問題 800](https://projecteuler.net/problem=800)

 ## 解決策

 **答え:**`1412403576`させて$$H(p,q)=p^q q^p$$異なる素数を持つ$p\neq q$。 順序のない素数ペアの数を数えなければなりません$(p,q)$そのような$$p^q q^p \le 800800^{800800}.$$定義する$$L = \log\left(800800^{800800}\right)=800800\log(800800).$$対数を取ると、不等式は次のように変換されます。$$q\log p + p\log q \le L.$$したがって、問題は次のようになります。 

> 素数ペアを数える$p<q$満足のいく
 >
 >
 >
 >
 >$$q\log p + p\log q \le L.$$---

 #1. 数学的分析

 ## ステップ 1 — 対数を使用して書き直す

 対数は厳密に増加しているので、$$p^q q^p \le N \iff q\log p + p\log q \le \log N.$$目標値については、$$N = 800800^{800800},$$それで$$L = 800800\log(800800).$$---

 ## ステップ 2 — 単調性

 固定用$p$、 定義する$$f_p(q)=q\log p + p\log q.$$のために$q>1$、$$f_p'(q)=\log p + \frac{p}{q}>0,$$それで$f_p(q)$厳密に増加しています$q$。 

したがって、各素数に対して、$p$、最大の素数があります$q$不等式を満たします。 これにより、2 ポインタ アプローチが可能になります。 

---

 ## ステップ 3 — プライムバウンド

 可能な限り最大の$q$発生するとき$p=2$:$$q\log 2 + 2\log q \le L.$$したがって、およそ$$q \lesssim \frac{L}{\log 2}.$$数字的にはこれくらいです$1.57\times 10^7$、これはエラトステネスの篩では完全に実現可能です。 

---

 ## ステップ 4 — 2 ポインタのカウント

 素数を$$p_0<p_1<\cdots<p_{m-1}.$$ポインタを維持します$j$最大の素数インデックスから開始します。 

それぞれについて$i$：

- 減少$j$その間$$p_j\log p_i + p_i\log p_j > L,$$- 次に、インデックス間のすべての素数$i+1$そして$j$動作します。 

追加$$j-i$$カウントに。 

なぜなら$j$下方向にのみ移動するため、ふるい分け後のアルゴリズムは線形です。 

---

 #2. Pythonの実装```python
from math import log, isqrt

def hybrid_count(base, exponent):
    # L = log(base^exponent)
    L = exponent * log(base)

    # Maximum possible q occurs roughly when p = 2
    limit = int(L / log(2)) + 10

    # Sieve of Eratosthenes
    sieve = bytearray(b'\x01') * (limit + 1)
    sieve[0:2] = b'\x00\x00'

    for p in range(2, isqrt(limit) + 1):
        if sieve[p]:
            start = p * p
            sieve[start:limit + 1:p] = (
                b'\x00' * (((limit - start) // p) + 1)
            )

    primes = [i for i, v in enumerate(sieve) if v]
    logs = [log(p) for p in primes]

    # Two-pointer counting
    total = 0
    j = len(primes) - 1

    for i, p in enumerate(primes):

        while j > i and primes[j] * logs[i] + p * logs[j] > L:
            j -= 1

        if j <= i:
            break

        total += (j - i)

    return total

# Checks from the problem statement
print(hybrid_count(800, 1))      # C(800)
print(hybrid_count(800, 800))    # C(800^800)

# Final answer
print(hybrid_count(800800, 800800))
```---

 #3. コードのチュートリアル

 ## コンピューティング$L$

```python
L = exponent * log(base)
```以来$$\log(base^{exponent}) = exponent \log(base),$$これにより、巨大な整数が完全に回避されます。 

---

 ## 素数の生成

 すべての素数を約次までふるいにかけます$$\frac{L}{\log 2}.$$これには、考えられるすべての候補が安全に含まれます。$q$。 

---

 ## ツーポインタセクション```python
while j > i and primes[j] * logs[i] + p * logs[j] > L:
    j -= 1
```これにより、不等式が成立するまで上限が縮小されます。 

次に、インデックスからのすべての素数$i+1$を通して$j$有効です。
