 ## 解決策

 **答え:**`1105985795684653500`させて$$D(n)=\text{number of greedy cube-subtractions needed to reduce }n\text{ to }0.$$例えば、$$100\to 36\to 9\to 1\to 0$$それで$D(100)=4$。 

計算しなければなりません$$S(N)=\sum_{1\le n<N} D(n)$$のために$$N=10^{17}.$$---

 #1. 数学的分析

 ## コア観察

 仮定してください$$m^3 \le n < (m+1)^3.$$次に、貪欲なアルゴリズムが最初に減算します。$m^3$、 それで$$D(n)=1+D(n-m^3).$$書く$$n=m^3+r,\qquad 0\le r<(m+1)^3-m^3.$$それから$$D(m^3+r)=1+D(r).$$これが重要な再帰構造です。 

---

 # 繰り返し$S(N)$させて$$N=m^3+r,\qquad 0\le r<(m+1)^3-m^3.$$それから$$S(N) = \sum_{n=1}^{m^3-1}D(n) + \sum_{t=0}^{r-1}D(m^3+t).$$使用する$D(m^3+t)=1+D(t)$、$$\sum_{t=0}^{r-1}D(m^3+t) = \sum_{t=0}^{r-1}(1+D(t)) = r+S(r),$$なぜなら$D(0)=0$。 

定義する$$C(m):=S(m^3).$$次に、取得します$$\boxed{S(m^3+r)=C(m)+r+S(r)}.$$それで一度$C(m)$既知である、評価する$S(N)$非常に速くなります。 

---

 # 繰り返し$C(m)$ブロック全体の寄与を計算します$$[m^3,(m+1)^3).$$その長さは$$L=(m+1)^3-m^3=3m^2+3m+1.$$このブロック内のすべての数字について、$$D(m^3+t)=1+D(t).$$したがって、$$\sum_{n=m^3}^{(m+1)^3-1}D(n) = L+S(L).$$したがって$$C(m+1)-C(m)=L+S(L),$$つまり$$\boxed{ C(m+1)=C(m)+(3m^2+3m+1)+S(3m^2+3m+1) }.$$基本ケース:$$C(1)=S(1)=0.$$---

 # 複雑さ

 のために$N=10^{17}$、$$\lfloor \sqrt[3]{10^{17}}\rfloor \approx 464158.$$したがって、必要なのは約だけです$4.6\times10^5$事前に計算された値。 

再帰の深さは、$S(N)$再帰呼び出しごとに置き換えられるため、小さいです$N$およそ$3N^{2/3}$。 

これは Python で 1 秒以内に簡単に実行できます。 

---

 #2. Pythonの実装```python
from functools import cache

# ------------------------------------------------------------
# Integer cube root:
# returns floor(n^(1/3))
# ------------------------------------------------------------
def icbrt(n: int) -> int:
    lo, hi = 0, int(n ** (1 / 3)) + 3

    while lo < hi:
        mid = (lo + hi + 1) // 2

        if mid ** 3 <= n:
            lo = mid
        else:
            hi = mid - 1

    return lo

TARGET = 10**17

# Maximum cube root needed
MAX_M = icbrt(TARGET - 1) + 1

# ------------------------------------------------------------
# C[m] = S(m^3)
# ------------------------------------------------------------
C = [0] * (MAX_M + 1)

# ------------------------------------------------------------
# Recursive computation of S(N)
# ------------------------------------------------------------
@cache
def S(N: int) -> int:
    if N <= 1:
        return 0

    m = icbrt(N - 1)
    cube = m ** 3

    # Exact cube boundary
    if N == cube:
        return C[m]

    r = N - cube

    # S(m^3 + r) = C(m) + r + S(r)
    return C[m] + r + S(r)

# ------------------------------------------------------------
# Build C iteratively
# ------------------------------------------------------------
# C(1) = 0 already

for m in range(2, MAX_M + 1):

    mm = m - 1

    # Length of interval [mm^3, m^3)
    L = 3 * mm * mm + 3 * mm + 1

    # C(m) = C(m-1) + L + S(L)
    C[m] = C[mm] + L + S(L)

# Final answer
print(S(TARGET))
```---
