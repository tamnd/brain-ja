[プロジェクト オイラー問題 475](https://projecteuler.net/problem=475)

 ## 解決策

 **答え:**`75780067`させてください$12n$ミュージシャンは次のように分けられます$3n$1日目からの固定カルテット:$$Q_1,Q_2,\dots,Q_{3n}, \qquad |Q_i|=4.$$2 日目には、すべてのミュージシャンを次のように分割する必要があります。$4n$**同じカルテットのメンバーが 2 人含まれるトリオがない**ような、順序のないトリオ。 

私たちは求めています$$f(12n).$$---

 #1. 数学的分析

 ## ステップ 1: すべての Trio パーティションから開始する

 分割方法の数$12n$人々にレッテルを貼る$4n$順序のないトリオは$$\frac{(12n)!}{(3!)^{4n}(4n)!} = \frac{(12n)!}{6^{4n}(4n)!}.$$次に、制限を課します。 

---

 ## ステップ 2: 包含と除外

 それぞれのカルテットの中には、$$\binom{4}{2}=6$$禁断のペア。 

イベントをしましょう$E_{ab}$意味：

 > ミュージシャン$a,b$（同じカルテットから）同じトリオで出演します。 

すべての禁止されたペアに対して包含と除外を適用します。 

---

 # ステップ 3: 禁止されたペアのどのサブセットが実現可能ですか?

 頂点を含む 1 つのカルテットを修正する$\{1,2,3,4\}$。 

サブセットを選択します$S$6つのエッジのうち。 

選択されたエッジは、そのペアが共通のトリオ内に存在する必要があることを意味します。 

トリオのサイズは 3 なので、グラフのすべての連結成分は$(\{1,2,3,4\},S)$サイズは最大 3 でなければなりません。 

実行可能なグラフの種類は次のとおりです。 

| タイプ | カウント | サイン | 効果 |
 | --- | --- | --- | --- |
 | 空 | 1 |$+$| 何も |
 | 片端 | 6 |$-$| 1 つの強制ペア |
 | 2 つの互いに素なエッジ | 3 |$+$| 2 つの強制ペア |
 | 2 つのエッジを持つ接続された 3 頂点グラフ | 12 |$+$| 強制トリプル 1 つ |
 | 三角形 | 4 |$-$| 強制トリプル 1 つ |

 最後の 2 つは両方とも同じことを強制します。つまり、3 つの頂点すべてが 1 つのトリオ内に存在する必要があります。 

したがって、1 つのカルテットの純寄与は次のようになります。$$P(x,y)=1-6x+3x^2+8y,$$どこ

-$x$強制ペアコンポーネントをカウントします。 
-$y$強制的なトリプルコンポーネントをカウントします。 

カルテットは独立しているので、全員にとって$3n$カルテット:$$P(x,y)^{3n}.$$させて$$[x^a y^b]P(x,y)^{3n}=c_{a,b}.$$それから：

-$a$= 強制ペアの数、
 -$b$= 強制されたトリプルの数。 

---

 # ステップ 4: 固定の完了数を数える$(a,b)$強制トリプルはすでに 1 つのトリオを占めています。 

強制ペアは、さらに 1 つのシングルトンによって完了する必要があります。 

修正後:

 -$a$ペアコンポーネント、
 -$b$トリプルコンポーネント、

 残りの空きシングルトン数は$$12n-2a-3b.$$個別のシングルトン パートナーを選択する必要があります。$a$ペア:$$\frac{(12n-2a-3b)!}{(12n-3a-3b)!}.$$残り$$12n-3a-3b = 3(4n-a-b)$$シングルトンは次のように分割されます$$4n-a-b$$順序のないトリオ:$$\frac{(12n-3a-3b)!}{6^{4n-a-b}(4n-a-b)!}.$$乗算:$$\frac{(12n-2a-3b)!}{6^{4n-a-b}(4n-a-b)!}.$$したがって$$\boxed{ f(12n)= \sum_{a,b} c_{a,b} \frac{(12n-2a-3b)!} {6^{\,4n-a-b}(4n-a-b)!} }$$どこ$$c_{a,b}=[x^a y^b](1-6x+3x^2+8y)^{3n}.$$---

 #2. Pythonの実装```python
MOD = 1_000_000_007

def solve(n):
    # DP for coefficients of:
    # (1 - 6x + 3x^2 + 8y)^(3n)

    from collections import defaultdict

    dp = {(0, 0): 1}

    for _ in range(3 * n):
        ndp = defaultdict(int)

        for (a, b), v in dp.items():

            # 1
            ndp[(a, b)] = (ndp[(a, b)] + v) % MOD

            # -6x
            ndp[(a + 1, b)] = (ndp[(a + 1, b)] - 6 * v) % MOD

            # +3x^2
            ndp[(a + 2, b)] = (ndp[(a + 2, b)] + 3 * v) % MOD

            # +8y
            ndp[(a, b + 1)] = (ndp[(a, b + 1)] + 8 * v) % MOD

        dp = ndp

    # factorials
    N = 12 * n

    fact = [1] * (N + 1)
    for i in range(1, N + 1):
        fact[i] = fact[i - 1] * i % MOD

    invfact = [1] * (4 * n + 1)

    invfact[4 * n] = pow(fact[4 * n], MOD - 2, MOD)

    for i in range(4 * n, 0, -1):
        invfact[i - 1] = invfact[i] * i % MOD

    inv6 = pow(6, MOD - 2, MOD)

    pow_inv6 = [1] * (4 * n + 1)
    for i in range(1, 4 * n + 1):
        pow_inv6[i] = pow_inv6[i - 1] * inv6 % MOD

    ans = 0

    for (a, b), c in dp.items():

        m = 12 * n - 2 * a - 3 * b
        k = 4 * n - a - b

        if m < 0 or k < 0:
            continue

        term = c
        term %= MOD

        term *= fact[m]
        term %= MOD

        term *= pow_inv6[k]
        term %= MOD

        term *= invfact[k]
        term %= MOD

        ans += term
        ans %= MOD

    return ans % MOD

# Checks from the problem statement
print(solve(1))   # 576
print(solve(2))   # 509089824

# Required answer
print(solve(50))
```---

 #3. コードのチュートリアル

 ### 多項式 DP

 の係数を構築します$$(1-6x+3x^2+8y)^{3n}$$動的プログラミングを使用します。 

各カルテットは 1 つの要素に貢献します。 

州:```python
dp[(a,b)]
```の係数を格納します$x^a y^b$。 

---

 ### 階乗

 形式の条件が必要です$$\frac{m!}{6^k k!}.$$モジュロ演算ではフェルマー逆関数が使用されます。$$10^9+7$$プライムです。 

---

 ### 最終合計

 すべての係数について$c_{a,b}$、追加します$$c_{a,b} \cdot \frac{(12n-2a-3b)!} {6^{4n-a-b}(4n-a-b)!}.$$---

 #4. 検証

 プログラムは、指定された両方の値を再現します。$$f(12)=576$$そして$$f(24)\bmod 10^9+7 = 509089824.$$したがって、導出は一貫しています。 

計算を実行する$n=50$与える:$$f(600)\bmod 1\,000\,000\,007 = 75780067.$$---

 **答え: 75780067**
