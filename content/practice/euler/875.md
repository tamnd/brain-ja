[プロジェクト オイラー問題 875](https://projecteuler.net/problem=875)

 ## 解決策

 **答え:**`79645946`させて$$R_n(t)=\#\{(x_1,x_2,x_3,x_4)\in (\mathbb Z/n\mathbb Z)^4: x_1^2+x_2^2+x_3^2+x_4^2\equiv t\pmod n\}.$$それから$$q(n)=\sum_{t \bmod n} R_n(t)^2,$$なぜなら、同じ二次和を持つ 2 つの 4 タプルを選択することが、まさに問題の条件だからです。 

計算しなければなりません$$Q(N)=\sum_{n\le N} q(n), \qquad N=12345678,$$モジュロ$1001961001$。 

---

 #1. 数学的分析

 ## ステップ 1: フーリエ展開

 追加文字を使用して、$$R_n(t)=\frac1n\sum_{h\bmod n} \left(\sum_{x\bmod n} e^{2\pi i h x^2/n}\right)^4 e^{-2\pi i ht/n}.$$二次ガウス和を定義する$$G_n(h)=\sum_{x\bmod n} e^{2\pi i h x^2/n}.$$それから$$R_n(t)=\frac1n\sum_{h\bmod n} G_n(h)^4 e^{-2\pi i ht/n}.$$したがって$$q(n) =\sum_t R_n(t)^2 =\frac1n\sum_{h\bmod n}|G_n(h)|^8.$$したがって、問題は完全に二次ガウス和の評価に帰着します。 

---

 # ステップ 2: 奇数の素数累乗

 奇数の場合$n$、古典的なガウス和恒等式は次のようになります。$$|G_n(h)|^2=n\gcd(h,n).$$したがって、$$|G_n(h)|^8=n^4\gcd(h,n)^4,$$したがって$$q(n)=n^3\sum_{h\bmod n}\gcd(h,n)^4.$$ここで用語をグループ化します$d=\gcd(h,n)$。 

の数$h$と$\gcd(h,n)=d$は$\varphi(n/d)$。 したがって$$q(n)=n^3\sum_{d\mid n} d^4\varphi(n/d).$$これは乗算です。 

奇数の素数パワーの場合$p^k$、$$q(p^k) =p^{3k}\sum_{i=0}^k p^{4i}\varphi(p^{k-i}).$$以来$$\varphi(p^m)= \begin{cases} p^m-p^{m-1}, & m\ge1,\\ 1,&m=0, \end{cases}$$私たちは得る$$q(p^k) = p^{7k} +(p-1)\sum_{i=0}^{k-1} p^{4k-1+3i}.$$同様に、再発$$q(p^k)=p^7 q(p^{k-1})+(p-1)p^{4k-1}.$$のために$k=1$、$$q(p)=p^7+(p-1)p^3.$$例：$$q(3)=3^7+2\cdot 3^3=2187+54=2241.$$正しい。 

---

 # ステップ 3: 2 の累乗

 2 進数のガウス和は異なる動作をします。 

直接評価すると、$$q(2^k)=\frac{2^{7k+3}-2^{4k}}7.$$同様に、$$q(2^k)=128\,q(2^{k-1})+2^{4k+3}.$$チェック：$$q(4)=\frac{2^{17}-2^8}{7} =\frac{131072-256}{7} =18432,$$ステートメントと一致します。 

---

 # ステップ 4: 乗法性

 この式はガウス和と CRT 因数分解に基づいているため、$$q(ab)=q(a)q(b)\qquad (\gcd(a,b)=1).$$したがって$q$乗算的です。 

したがって、次の値までのすべての値を計算できます。$N$直線ふるいを使用します。 

---

 #2. Pythonの実装```python
from array import array

MOD = 1001961001
N = 12345678

# q[n]      = q(n) mod MOD
# pp[n]     = highest prime power dividing n
# g[n]      = q(pp[n]) mod MOD

q = array('I', [0]) * (N + 1)
pp = array('I', [0]) * (N + 1)
g = array('I', [0]) * (N + 1)

primes = array('I')

q[1] = 1
g[1] = 1

answer = 1

for n in range(2, N + 1):

    # n is prime
    if pp[n] == 0:
        primes.append(n)
        pp[n] = n

        if n == 2:
            gn = 128
        else:
            gn = (pow(n, 7, MOD) + (n - 1) * pow(n, 3, MOD)) % MOD

        g[n] = gn
        q[n] = gn

    qn = q[n]

    # Euler linear sieve transitions
    for p in primes:
        m = n * p
        if m > N:
            break

        if n % p != 0:
            # new prime factor
            pp[m] = p

            if p == 2:
                gp = 128
            else:
                gp = (pow(p, 7, MOD) +
                      (p - 1) * pow(p, 3, MOD)) % MOD

            g[m] = gp
            q[m] = (qn * gp) % MOD

        else:
            # extending prime power
            pp_new = pp[n] * p
            pp[m] = pp_new

            old_g = g[n]

            if p == 2:
                # q(2^k)=128*q(2^(k-1))+2^(4k+3)
                new_g = (
                    128 * old_g
                    + 8 * pow(pp_new, 4, MOD)
                ) % MOD

            else:
                # q(p^k)=p^7*q(p^(k-1))+(p-1)p^(4k-1)
                term = (
                    (p - 1)
                    * (pow(pp_new, 4, MOD) * pow(p, -1, MOD) % MOD)
                ) % MOD

                new_g = (
                    pow(p, 7, MOD) * old_g + term
                ) % MOD

            g[m] = new_g

            # multiplicativity:
            # n = (n // pp[n]) * pp[n]
            q[m] = (q[n // pp[n]] * new_g) % MOD

            break

    answer += q[n]
    answer %= MOD

print(answer)
```---

 #3. コードのチュートリアル

 ### 配列

 -`q[n]`店$q(n)\pmod{M}$。 
-`pp[n]`繰り返される最小の素数の最高累乗を格納します。 
-`g[n]`プライムパワーの寄与を保存します$q(p^k)$。 

これは、乗算関数線形ふるいの標準的な構造です。 

---

 ### 主要なケース

 奇数素数の場合$p$、$$q(p)=p^7+(p-1)p^3.$$のために$p=2$、$$q(2)=128.$$これらはふるいを初期化します。 

---

 ### Coprime 拡張機能

 もし$p\nmid n$、次に乗法により、$$q(np)=q(n)q(p).$$---

 ### プライムパワー拡張

 もし$p\mid n$、それから拡張します$p^k\to p^{k+1}$。 

奇数の場合$p$、$$q(p^k)=p^7q(p^{k-1})+(p-1)p^{4k-1}.$$のために$p=2$、$$q(2^k)=128q(2^{k-1})+2^{4k+3}.$$---

 ### サンプルでの検証

 プログラムを実行する$N=10$与える$$Q(10)=18573381,$$問題文と正確に一致します。
