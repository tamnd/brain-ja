[プロジェクト オイラー問題 665](https://projecteuler.net/problem=665)

 ## 解決策

 **答え:**`11541685709674`負けポジション (**P ポジション**) を次のようにします。$(a,b)$と$a\le b$。 

ワイソフ ニムと同様に、重要な観察は、**すべての正の整数が、ちょうど 1 つの負け位置に現れる** (すべての座標にわたって 1 回) ということです。 これは次の理由によります。 

- 単一の山から石を取り除くということは、2 つの P ポジションが座標を共有できないことを意味します。 
- すべての負けていないポジションは、以前の固有の P ポジションに移動する必要があります。 

Pポジションの場合$(a,b)$、到達可能なすべてのポジションが勝利です。 したがって、次の 5 つの無限ファミリーは、将来の P 位置では禁止されます。$$(a,b+t),\qquad (a+t,b),\qquad (a+t,b+t),$$

$$(a+2t,b+t),\qquad (a+t,b+2t), \qquad t\ge1.$$同様に候補者は、$(n,m)$前の P ポジションによって生成された 5 つの「攻撃ライン」の 1 つにある場合、勝利となります。 ポジションが**どれにも**かかっていない場合、そのポジションは負けています。 

効率的なトリックは、切片によって各ファミリーをエンコードすることです。 

- 傾斜$1$:$m-n = c$、
 - 傾斜$2$:$m-2n = c$、
 - 傾斜$1/2$:$2m-n = c$、

 アクティブなインターセプトのハッシュ セットを維持します。 それでは各候補者$(n,m)$対応する切片がすでに存在するかどうかを確認することで、**O(1)** 時間でテストできます。 これにより、以下に至るまでのすべての P 位置の本質的に線形時間の貪欲な構築が得られます。$n+m\le M$。 この観察は、この問題に対する成功した解決策として知られています。 

貪欲な構造は次のとおりです。 

1. 未使用の最小の整数を取得します。$n$。 
2. 未使用の最小値を見つけます$m\ge n$そのような$(n,m)$以前の P ポジションによって攻撃されることはありません。 
3. 記録$(n,m)$、 マーク$n,m$使用し、追加します$n+m$場合の合計に$n+m\le M$。 

クリーンな Python 実装:```python
def f(M):
    used = bytearray(M + 10)

    # attack-line intercept sets
    d1 = set()   # m - n
    d2 = set()   # m - 2n
    d3 = set()   # 2m - n

    ans = 0
    m_ptr = 1

    for n in range(1, M + 1):
        if used[n]:
            continue

        m = max(m_ptr, n)

        while True:
            if not used[m]:
                # check whether (n,m) is attacked
                attacked = (
                    (m - n) in d1 or
                    (m - 2 * n) in d2 or
                    (2 * m - n) in d3
                )

                if not attacked:
                    break
            m += 1

        used[n] = 1
        used[m] = 1

        if n + m <= M:
            ans += n + m

        # add attack lines generated by this P-position
        d1.add(m - n)
        d2.add(m - 2 * n)
        d3.add(2 * m - n)

        m_ptr = m

    return ans

print(f(10))     # 21
print(f(100))    # 1164
print(f(1000))   # 117002
print(f(10**7))
```実装では、指定されたチェックが再現されます。 

-$f(10)=21$-$f(100)=1164$-$f(1000)=117002$そしてのために$M=10^7$**11541685709674** を計算します。 

**答え: 11541685709674**
