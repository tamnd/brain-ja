[プロジェクト オイラー問題 90](https://projecteuler.net/problem=90)

 ## 解決策

 **答え:**`1217`以下の 2 桁の平方数をすべて表示できる 6 桁の立方体の順序のないペアを数えなければなりません$100$:$$01,\ 04,\ 09,\ 16,\ 25,\ 36,\ 49,\ 64,\ 81$$という追加ルールを加えて、$6$そして$9$回転により交換可能です。 

---

 # 数学的分析

 立方体は、その面に書かれた数字のセットによってのみ決定されます。 

各立方体には、次から選択された正確に 6 つの異なる数字が含まれています。$\{0,1,\dots,9\}$。 

中心的な観察は次のとおりです。 

- 2桁の数字を表示するには$ab$、1 つのキューブには次のものを含める必要があります。$a$もう一方には次のものが含まれている必要があります$b$。 
- キューブは左右に入れ替えることができるので、次のいずれかになります。$$a \in A,\ b \in B$$または$$a \in B,\ b \in A$$---

 ## ステップ 1:$6/9$対称性

 なぜなら、$6$として行動できます$9$逆も同様で、それらを交換可能なものとして扱います。 

したがって:

 - キューブに含まれる場合$6$、効果的にも含まれています$9$、
 - 含まれている場合$9$、効果的にも含まれています$6$。 

したがって、テスト目的で、次のいずれかを含むセットを拡大してもよいでしょう。$\{6,9\}$両方を含むようにします。 

---

 ## ステップ 2: 必要な正方形のペア

 平方数には、次の桁ペアの制約が課されます。 

| スクエア | 必要なペア |
 | --- | --- |
 |$01$|$(0,1)$|
 |$04$|$(0,4)$|
 |$09$|$(0,6)$なぜなら$9 \leftrightarrow 6$|
 |$16$|$(1,6)$|
 |$25$|$(2,5)$|
 |$36$|$(3,6)$|
 |$49$|$(4,6)$|
 |$64$|$(6,4)$|
 |$81$|$(8,1)$|

 知らせ$49$そして$64$どちらも必要に応じて減少します$4$そして$6$反対側の立方体に。 

---

 ## ステップ 3: すべてのキューブを列挙する

 立方体は、10 桁の任意の 6 要素のサブセットです。$$\binom{10}{6} = 210$$だから、あるのは$210$可能な立方体。 

すべての順序付けされていないペアをブルート フォースすることができます。$$\binom{210+1}{2} = 22155$$それは小さいです。 

---

 ## ステップ 4: 妥当性テスト

 キューブの各ペアについて$(A,B)$:

 1. 各立方体を拡張します。 

- もし$6\in A$または$9\in A$、両方を追加します$6,9$、
 - 同様に$B$。 
2. 必要なペアごとに$(x,y)$、 確認する：$$(x\in A \land y\in B)\quad \text{or}\quad (x\in B \land y\in A)$$3. すべての平方制約を満たす、順序付けされていないペアをすべて数えます。 

---

 # Pythonの実装```python
from itertools import combinations

# All required square digit pairs
# 9 is replaced by 6 because 6/9 are interchangeable
required = [
    (0, 1),
    (0, 4),
    (0, 6),  # represents 09
    (1, 6),  # represents 16
    (2, 5),
    (3, 6),  # represents 36
    (4, 6),  # represents 49
    (6, 4),  # represents 64
    (8, 1),
]

digits = range(10)

# Generate all possible cubes (6 distinct digits)
cubes = list(combinations(digits, 6))

def extend(cube):
    """
    If a cube contains 6 or 9, add both,
    because they are interchangeable.
    """
    s = set(cube)

    if 6 in s or 9 in s:
        s.add(6)
        s.add(9)

    return s

def valid(c1, c2):
    """
    Check whether cubes c1 and c2
    can display all required square numbers.
    """
    a = extend(c1)
    b = extend(c2)

    for x, y in required:
        ok = ((x in a and y in b) or
              (x in b and y in a))

        if not ok:
            return False

    return True

count = 0

# Only unordered pairs
for i in range(len(cubes)):
    for j in range(i, len(cubes)):
        if valid(cubes[i], cubes[j]):
            count += 1

print(count)
```---
