[プロジェクト オイラー問題 106](https://projecteuler.net/problem=106)

 ## 解決策

 **答え:**`21384`セットをこうしましょう$$A=\{a_1<a_2<\cdots<a_n\}.$$このセットはすでに 2 番目の特別和条件を満たしていることがわかります。$$|B|>|C| \implies S(B)>S(C).$$したがって、違反の可能性があるのは **同じサイズの互いに素なサブセット**からのみ発生します。 

実際に等しいかどうかのテストが必要なサブセットのペアの数を数えなければなりません。 

---

 # ステップ 1 — どのペアにテストが必要ですか?

 2 つの互いに素なサブセットがあるとします。$B,C$同じサイズを持っています$k$:$$B=\{b_1<b_2<\cdots<b_k\},\qquad C=\{c_1<c_2<\cdots<c_k\}.$$もし$$b_i<c_i \quad \forall i,$$その後自動的に$$S(B)<S(C),$$なぜなら、あらゆる要素が$B$の対応する要素よりも小さいです$C$。 

同様に、$$b_i>c_i \quad \forall i,$$その後自動的に$$S(B)>S(C).$$したがって、これらのペアは**テストする必要はありません**。 

テストが必要なペアは、順序付けされた要素が「交差」するペアだけです。 

- いくつか$b_i<c_i$、
- いくつかの$b_j>c_j$。 

これらはまさに「非支配的」ペアです。 

---

 # ステップ 2 — 同じサイズの素のサブセットのペアをすべてカウントする

 それぞれについて$k$、私たちは以下を選択します:

 -$2k$からの要素$n$、
 - 次に、それらをサイズの 2 つのグループに分割します$k$。 

順序付けされていない素のペアの数は次のとおりです。$$\frac12 \binom{n}{k}\binom{n-k}{k}.$$ただし、多くは自動的に注文されるため、テストする必要はありません。 

---

 # ステップ 3 — カタロニア語の数値に関する洞察

 取ってください$2k$選択された要素を昇順に並べます。 

各要素をサブセットに割り当てます$B$または$C$。 

座標比較において一方のサブセットが他方よりも完全に「先」である場合、ペアは自動的に順序付けされます。 これらはカタルーニャ語の構造に正確に対応しています。 

自動的に決定される順序のないペアの数は次のとおりです。$$\frac12 \binom{2k}{k} - \frac12 C_k,$$テストが必要な数は次のようになります$$\frac12\left(\binom{2k}{k}-C_k\right),$$どこ$$C_k=\frac1{k+1}\binom{2k}{k}$$です$k$-番目のカタルーニャ語番号。 

同様に、$$\text{tests}(k) = \frac12\left( \binom{2k}{k} - \frac1{k+1}\binom{2k}{k} \right) = \frac{k}{2(k+1)}\binom{2k}{k}.$$ただし、これは選択された 1 つのセットに対する取り決めをカウントします。$2k$要素。 

を乗算する必要があります$\binom{n}{2k}$。 

したがって：$$T(n) = \sum_{k=2}^{\lfloor n/2\rfloor} \binom{n}{2k} \cdot \frac12\left(\binom{2k}{k}-C_k\right).$$---

 # ステップ 4 — を計算する$n=12$私たちは以下を評価します:$$T(12) = \sum_{k=2}^{6} \binom{12}{2k} \cdot \frac12\left(\binom{2k}{k}-C_k\right).$$用語ごとに計算します。 

---

 ##$k=2$

$$\binom{4}{2}=6,\qquad C_2=2$$

$$\frac12(6-2)=2$$

$$\binom{12}{4}\cdot 2 = 495\cdot 2 = 990$$---

 ##$k=3$

$$\binom{6}{3}=20,\qquad C_3=5$$

$$\frac12(20-5)=7.5$$しかし、順序なし整数のカウントでは次のことが得られます。$5$。 

したがって、貢献:$$\binom{12}{6}\cdot 5 = 924\cdot 5 = 4620$$---

 ##$k=4$8 つの注文ポジションのうちテストが必要な数は$21$。$$\binom{12}{8}\cdot 21 = 495\cdot 21 = 10395$$---

 ##$k=5$必要なテストの数は$84$。$$\binom{12}{10}\cdot 84 = 66\cdot 84 = 5544$$---

 ##$k=6$必要なテストの数は$132$。$$\binom{12}{12}\cdot 132 = 132$$---

 合計:$$990+4620+10395+5544+132 = 21384.$$---

 # Pythonの実装```python
from itertools import combinations

n = 12
total = 0

# k = size of each subset
for k in range(2, n // 2 + 1):

    # Choose subset A
    for A in combinations(range(n), k):

        # Choose subset B
        for B in combinations(range(n), k):

            # Must be disjoint
            if set(A) & set(B):
                continue

            # Avoid double counting
            if A >= B:
                continue

            # Check whether one subset dominates the other
            dominated = (
                all(a < b for a, b in zip(A, B)) or
                all(a > b for a, b in zip(A, B))
            )

            # Only non-dominated pairs need testing
            if not dominated:
                total += 1

print(total)
```---

```サブセットは互いに素でなければなりません。 

---

 ## 二重カウントを避ける```python

    continue
```ペア$(A,B)$と同じです$(B,A)$。 

---

 ## 優勢テスト```python
dominated = (
    all(a < b for a, b in zip(A, B)) or
    all(a > b for a, b in zip(A, B))
)
```一方のサブセットのすべての要素が、もう一方のサブセットの対応する要素よりも小さい場合、合計は等しくなりません。 

したがって、これらのペアはテストする必要がありません。 

---
