[プロジェクト オイラー問題 544](https://projecteuler.net/problem=544)

 ## 解決策

 **答え:**`640432376`させて$$F(r,c,n)$$の適切な色の数になります。$r\times c$の色を使用したグリッド グラフ$\{1,\dots,n\}$ここで、隣接とはエッジを共有することを意味します。 

私たちは求められています$$S(r,c,n)=\sum_{k=1}^{n}F(r,c,k)$$そして具体的には$$S(9,10,1112131415)\pmod{10^9+7}.$$---

 #1. 数学的分析

 重要な所見は次のとおりです。 

>$F(r,c,n)$はまさに次の色多項式です。$r\times c$グリッド グラフの評価時期$n$。 

グラフの場合$N=rc$頂点、色多項式には次数があります$N$。 

したがって：

-$F(9,10,n)$は多項式です$n$程度の$90$。 
- したがって$$S(9,10,n)=\sum_{k=1}^{n}F(9,10,k)$$は多項式です$n$程度の$91$。 

したがって、戦略は次のとおりです。 

1. 色彩多項式を計算する$P(q)=F(9,10,q)$。 
2. 十分小さな整数で評価します。 
3. ラグランジュ補間を使用して評価する$S(9,10,1112131415)$。 

難しいのはステップ1です。 

---

 ## フロンティア/転送-DP

 グリッドをセルごとに処理します。 

いかなる瞬間においても、重要なのは現在の「フロンティア」だけです。 

グリッドの場合$r=9$、フロンティアはサイズ9です。 

実際の色を保存する代わりに、等価構造のみを保存します。 

例：```python
[5,7,5,9]
```正規的には次のように表されます```python
[0,1,0,2]
```平等な関係だけが重要だからです。 

これにより、状態空間が大幅に圧縮されます。 

---

 ## 多項式 DP

 現在のフロンティアに次のものがあるとします。$m$独特の色。 

次のセルに色を付ける場合:

 - 既存のフロンティアカラーの再利用は係数に寄与します$1$、
 - 新色の導入が要因$$(q-m),$$あるから$q-m$現在フロンティアにない色です。 

したがって、すべての DP 値は次の多項式になります。$q$。 

すべてのセルが処理された後、完全な色彩多項式が得られます。 

---

 ## 補間が機能する理由

 以来$S(n)$学位を持っています$91$、その値を知っている$$n=0,1,2,\dots,91$$一意に決定します。 

これらの値をモジュロで計算します$$M=10^9+7$$そして多項式を次のように評価します。$$1112131415$$有限体上で標準的なラグランジュ補間を使用します。

 #2. Pythonの実装```python
MOD = 1_000_000_007
EMPTY = -1

def poly_eval(coeffs, x, mod=MOD):
    """Evaluate polynomial sum coeffs[i] * x^i."""
    x %= mod
    res = 0
    p = 1
    for a in coeffs:
        res = (res + a * p) % mod
        p = (p * x) % mod
    return res

def lagrange_eval(values, x, mod=MOD):
    """
    Given values[i] = f(i) for i=0..n
    where deg(f) <= n,
    evaluate f(x) modulo mod.
    """
    n = len(values) - 1

    if 0 <= x <= n:
        return values[x] % mod

    x %= mod

    fac = [1] * (n + 1)
    for i in range(1, n + 1):
        fac[i] = fac[i - 1] * i % mod

    invfac = [1] * (n + 1)
    invfac[n] = pow(fac[n], mod - 2, mod)

    for i in range(n, 0, -1):
        invfac[i - 1] = invfac[i] * i % mod

    pre = [1] * (n + 2)
    suf = [1] * (n + 2)

    for i in range(n + 1):
        pre[i + 1] = pre[i] * (x - i) % mod

    for i in range(n, -1, -1):
        suf[i] = suf[i + 1] * (x - i) % mod

    ans = 0

    for i in range(n + 1):
        num = pre[i] * suf[i + 1] % mod

        den = invfac[i] * invfac[n - i] % mod
        if (n - i) & 1:
            den = (-den) % mod

        ans = (ans + values[i] * num % mod * den) % mod

    return ans % mod

def chromatic_poly_grid(r, c, mod=MOD):
    """
    Compute chromatic polynomial of an r x c grid graph.
    Returns coefficients in power basis.
    """

    canon_cache = {}

    def canon(state):
        """Canonical relabelling of colours."""
        if state in canon_cache:
            return canon_cache[state]

        mp = {}
        nxt = 0
        out = []

        for x in state:
            if x == EMPTY:
                out.append(EMPTY)
            else:
                if x not in mp:
                    mp[x] = nxt
                    nxt += 1
                out.append(mp[x])

        res = tuple(out)
        canon_cache[state] = res
        return res

    trans_cache = {}

    def trans(st, i):
        """
        Set frontier position i to every possible label.
        """
        key = (st, i)

        if key in trans_cache:
            return trans_cache[key]

        mx = max(st)
        m = 0 if mx == EMPTY else mx + 1

        base = list(st)

        nexts = [None] * (m + 1)

        for lab in range(m + 1):
            base[i] = lab
            nexts[lab] = canon(tuple(base))

        base[i] = st[i]

        res = (m, nexts)
        trans_cache[key] = res
        return res

    forget_cache = {}

    def forget(st, i):
        key = (st, i)

        if key in forget_cache:
            return forget_cache[key]

        base = list(st)
        base[i] = EMPTY

        res = canon(tuple(base))
        forget_cache[key] = res

        return res

    def add_poly(tgt, poly):
        if len(tgt) < len(poly):
            tgt.extend([0] * (len(poly) - len(tgt)))

        for j, v in enumerate(poly):
            tgt[j] = (tgt[j] + v) % mod

    def add_q_minus_m_mul(tgt, poly, m):
        """
        tgt += (q - m) * poly
        """
        need = len(poly) + 1

        if len(tgt) < need:
            tgt.extend([0] * (need - len(tgt)))

        mm = m % mod

        for j, v in enumerate(poly):
            tgt[j] = (tgt[j] - mm * v) % mod
            tgt[j + 1] = (tgt[j + 1] + v) % mod

    start = tuple([EMPTY] * r)

    dp = {start: [1]}

    for col in range(c):
        for row in range(r):

            i = row

            has_up = row > 0
            has_left = col > 0

            ndp = {}

            for st, poly in dp.items():

                m, nexts = trans(st, i)

                up = st[i - 1] if has_up else -2
                left = st[i] if has_left else -2

                # reuse existing frontier colour
                for lab in range(m):

                    if lab == up or lab == left:
                        continue

                    ns = nexts[lab]

                    tgt = ndp.setdefault(ns, [])
                    add_poly(tgt, poly)

                # introduce new colour
                ns = nexts[m]

                tgt = ndp.setdefault(ns, [])
                add_q_minus_m_mul(tgt, poly, m)

            dp = ndp

    # forget remaining frontier
    for i in range(r):

        ndp = {}

        for st, poly in dp.items():

            ns = forget(st, i)

            tgt = ndp.setdefault(ns, [])
            add_poly(tgt, poly)

        dp = ndp

    return dp[start]

def solve():

    # sanity checks from problem statement

    p22 = chromatic_poly_grid(2, 2)

    assert poly_eval(p22, 3) == 18
    assert poly_eval(p22, 20) == 130340

    p34 = chromatic_poly_grid(3, 4)

    assert poly_eval(p34, 6) == 102923670

    p44 = chromatic_poly_grid(4, 4)

    s44 = sum(poly_eval(p44, k) for k in range(1, 16)) % MOD

    assert s44 == 325951319

    # target
    r, c, n = 9, 10, 1112131415

    p = chromatic_poly_grid(r, c)

    # S(n) has degree 91
    prefix = [0] * 92

    acc = 0

    for k in range(1, 92):
        acc = (acc + poly_eval(p, k)) % MOD
        prefix[k] = acc

    ans = lagrange_eval(prefix, n)

    print(ans)

solve()

 ##`canon(state)`任意のカラー ラベルを標準ラベルに置き換えます。```python
[7,3,7,9] -> [0,1,0,2]
```これにより、無関係な対称性が削除されます。

 ##`dp`

`dp[state]`多項式を格納します$q$。 

係数リストは以下を表します。$$a_0 + a_1 q + a_2 q^2 + \cdots$$---

 ## 色の再利用

 既存のフロンティアカラーを再利用する場合、選択肢の数は固定されているため、多項式をコピーするだけです。 

---

 ## 新色

 現在ある場合$m$フロンティアでアクティブなカラーを使用し、新しいカラーを導入すると、次のような効果が得られます。$$(q-m)$$したがって、次のようになります。```python
add_q_minus_m_mul(...)
```による乗算を実装します$(q-m)$。

 ## 補間

 以来$S(n)$学位を持っています$91$、の値$0..91$一意に決めます。`lagrange_eval()`その多項式を次のように評価します。$$n = 1112131415$$モジュロ$10^9+7$。
