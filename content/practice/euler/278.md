[プロジェクト オイラー問題 278](https://projecteuler.net/problem=278)

 ## 解決策

 **答え:**`1228215747273908452`させて$$a_1=pq,\qquad a_2=pr,\qquad a_3=qr$$異なる素数の場合$p<q<r$。 

必要です$$\sum_{p<q<r<5000} f(pq,pr,qr).$$重要なのは、次の閉じた公式を導き出すことです。$f(pq,pr,qr)$。 

---

 ## 1. 数学的分析

 **不可能な最大の非負の整数の組み合わせ**を探しています。$$x(pq)+y(pr)+z(qr)=b, \qquad x,y,z\ge 0.$$これはフロベニウス型の問題です。 

### ステップ 1: ペアごとの gcd 構造を観察する

 のために$$a=pq,\quad b=pr,\quad c=qr,$$我々は持っています$$\gcd(a,b)=p,\qquad \gcd(a,c)=q,\qquad \gcd(b,c)=r,$$そして$$\gcd(a,b,c)=1.$$これらのトリプルは特別な数値半群を形成します。 

次の形式のトリプルの古典的な結果$$(ab,ac,bc)$$ペアごとの互いに素な$a,b,c$フロベニウス数を与える：$$f(ab,ac,bc)=2abc-ab-ac-bc.$$ここで、ペアごとの互いに素なパラメータは正確に次のようになります。$p,q,r$、 それで：$$f(pq,pr,qr) = 2pqr-pq-pr-qr.$$### ステップ 2: 例に対して検証する

 #### 例 1$$(6,10,15)=(2\cdot3,\ 2\cdot5,\ 3\cdot5)$$式は次のようになります。$$2(2)(3)(5)-6-10-15 = 60-31 = 29.$$問題文と一致します。 

#### 例 2$$(14,22,77)=(2\cdot7,\ 2\cdot11,\ 7\cdot11)$$

$$2(2)(7)(11)-14-22-77 = 308-113 = 195.$$またまた一致します。 

したがって、合計は次のようになります$$S = \sum_{p<q<r<5000} \left(2pqr-pq-pr-qr\right).$$---

 ## 2. Python の実装```python
from sympy import primerange

# Generate all primes < 5000
primes = list(primerange(2, 5000))

# Prefix sums of primes for fast summation
prefix_sum = [0]
for p in primes:
    prefix_sum.append(prefix_sum[-1] + p)

total = 0

# O(n^2) summation over q,r
for k in range(2, len(primes)):
    r = primes[k]

    for j in range(1, k):
        q = primes[j]

        # Sum of p for p < q
        sum_p = prefix_sum[j]
        count_p = j

        # Sum over all p < q:
        # Σ (2pqr - pq - pr - qr)
        total += (
            (2 * q * r - q - r) * sum_p
            - q * r * count_p
        )

print(total)
```---

 ### 主な合計

 固定用$q,r$、$$\sum_{p<q} (2pqr-pq-pr-qr)$$になる$$(2qr-q-r)\sum_{p<q}p - qr\cdot \#\{p<q\}.$$これにより、複雑さが軽減されます。$O(n^3)$に$O(n^2)$。
