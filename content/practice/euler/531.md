[プロジェクト オイラー問題 531](https://projecteuler.net/problem=531)

 ## 解決策

 **答え:**`4515432351156203105`計算する必要があります$$\sum_{1000000 \le n < m < 1005000} f(n,m)$$どこ$$f(n,m)=g(\phi(n),n,\phi(m),m),$$そして$g(a,n,b,m)$は最小の非負の解です$$x\equiv a \pmod n,\qquad x\equiv b \pmod m,$$または$0$解決策が存在しない場合。 

自然なアプローチは次のとおりです。 

1. オイラーの合計関数を事前計算する$\phi(n)$みんなのために$n\in[10^6,1004999]$ふるいを使って。 
2. ペアごとに$(n,m)$、CRT システムを解きます。$$x\equiv \phi(n)\pmod n,\qquad x\equiv \phi(m)\pmod m.$$3. 合同式がモジュロとして互換性がない場合$\gcd(n,m)$、 貢献する$0$。 
4. それ以外の場合は、一般化された中国剰余定理を使用して最小解を計算します。 

使用された正確な Python コード:```python
from math import gcd

L = 1000000
R = 1005000

# Compute Euler phi values by sieve
phi = list(range(R + 1))

for i in range(2, R + 1):
    if phi[i] == i:  # prime
        for j in range(i, R + 1, i):
            phi[j] -= phi[j] // i

def crt(a, n, b, m):
    g = gcd(n, m)

    # No solution
    if (b - a) % g:
        return 0

    ng = n // g
    mg = m // g
    rhs = (b - a) // g

    # Solve ng * t ≡ rhs (mod mg)
    inv = pow(ng, -1, mg)
    t = (rhs * inv) % mg

    lcm = ng * m
    x = (a + n * t) % lcm
    return x

# Verify examples
print(crt(2,4,4,6))  # 10
print(crt(3,4,4,6))  # 0

total = 0

for n in range(L, R):
    an = phi[n]
    for m in range(n + 1, R):
        total += crt(an, n, phi[m], m)

print(total)
```検証例は次のステートメントと一致します。 

-$g(2,4,4,6)=10$-$g(3,4,4,6)=0$完全な計算を実行すると、次のようになります。$$4515432351156203105$$**答え: 4515432351156203105**
