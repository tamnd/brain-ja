[プロジェクト オイラー問題 832](https://projecteuler.net/problem=832)

 ## 解決策

 **答え:**`552839586`ブロック内のラウンドにインデックスを付けます。$0$。 

定義する$$T_k=\frac{4^k-1}{3}.$$後$T_k$ラウンド、紙には整数が正確に含まれています$$1,2,\dots,4^k-1.$$これは例からわかります。 

-$T_1=1$: 数字$1..3$、
 -$T_2=5$: 数字$1..15$、
 -$T_3=21$: 数字$1..63$。 

したがって、プロセスは一定のサイズのブロックで進行します。$4^k$。 

For the block beginning at$4^k$、ラウンドインデックスを次のように書きます$r\in[0,4^k)$、ベースで$4$:$$r = \sum d_i 4^i.$$この構築では、数字のマッピングが再帰的に引き起こされます。$$0\mapsto(0,0),\quad 1\mapsto(2,3),\quad 2\mapsto(3,1),\quad 3\mapsto(1,2).$$もし$x_r,y_r$は対応するものの低い部分です$b,c$、 それから$$x_r+y_r = \sum t(d_i)4^i,$$どこ$$t(0)=0,\quad t(1)=5,\quad t(2)=4,\quad t(3)=3.$$したがって$$r + (x_r+y_r) = 6\sum_{d_i\neq 0}4^i.$$ラウンドの貢献度$r$ブロック内$k$は$$6\cdot 4^k + 6\sum_{d_i\neq 0}4^i.$$定義する$$\operatorname{supp}(r)=\sum_{d_i\neq 0}4^i.$$それから$n=T_k+m$と$0\le m<4^k$、$$M(n) = \frac{4^k(4^k-1)}2 + 6m4^k + 6\sum_{r=0}^{m-1}\operatorname{supp}(r).$$残りの合計は再帰的に計算されます。 

使用される Python 実装:```python
MOD = 10**9 + 7

from functools import lru_cache

@lru_cache(None)
def fullS(k):
    # Sum of supp(r) for 0 <= r < 4^k
    if k == 0:
        return 0
    p = 4 ** (k - 1)
    return 4 * fullS(k - 1) + 3 * p * p

def S(k, m):
    # Sum of supp(r) for 0 <= r < m, with r < 4^k
    if k == 0 or m == 0:
        return 0

    p = 4 ** (k - 1)
    a, b = divmod(m, p)

    return (
        a * fullS(k - 1)
        + max(0, a - 1) * p * p
        + (p * b if a else 0)
        + S(k - 1, b)
    )

def M(n):
    k = 0
    while (4 ** (k + 1) - 1) // 3 <= n:
        k += 1

    T = (4 ** k - 1) // 3
    m = n - T

    base = 4 ** k * (4 ** k - 1) // 2

    return base + 6 * m * 4 ** k + 6 * S(k, m)

ans = M(10**18) % MOD
print(ans)
```チェック:

したがって、

 **答え: 552839586**
