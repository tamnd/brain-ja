[プロジェクト オイラー問題 132](https://projecteuler.net/problem=132)

 ## 解決策

 **答え:**`843296`させて$$R(k)=\underbrace{111\ldots1}_{k\text{ digits}}=\frac{10^k-1}{9}.$$最初の合計を求められます$40$の素因数$$R(10^9).$$重要な点は、プライムがいつ起こるかを特徴づけることです。$p$リプユニットを分割します。 

---

 #1. 数学的分析

 素数$p \neq 2,5$分割する$R(n)$もし$$R(n)\equiv 0 \pmod p.$$使用する$$R(n)=\frac{10^n-1}{9},$$そしてそれ以来$p\neq 3$暗示する$9$可逆モジュロです$p$、$$R(n)\equiv 0 \pmod p \iff 10^n\equiv 1 \pmod p.$$したがって：$$p\mid R(n) \iff \operatorname{ord}_p(10)\mid n,$$どこ$\operatorname{ord}_p(10)$は次の乗算順序です$10$モジュロ$p$。 

この問題については、$$n=10^9=2^9\cdot 5^9.$$したがってプライム$p$分割する$R(10^9)$の順序であれば$10$モジュロ$p$以外の素因数は含まれていません$2$そして$5$。 

同様に:$$\operatorname{ord}_p(10)\mid 10^9.$$もう 1 つの有益な事実:$$\operatorname{ord}_p(10)\mid p-1$$(フェルマー / ラグランジュによる)、したがって、そのような素数は次を満たします。$$p\equiv 1 \pmod{2^a5^b}$$の適切な約数については、$10^9$。 

しかし、計算的に最も簡単なテストは直接次のとおりです。$$10^{10^9}\equiv 1 \pmod p.$$Python は二乗を繰り返してべき乗剰余を効率的に計算するため、これは非常に高速です。 

したがって、アルゴリズムは次のようになります。 

1. 素数を生成する$p\neq 2,5$。 
2. かどうかをテストします。$$10^{10^9}\equiv 1 \pmod p.$$3. 最初のものを集める$40$そのような素数。 
4. それらを合計します。 

---

 #2. Pythonの実装```python
from sympy import primerange

TARGET = 40
N = 10**9

factors = []

# Generate primes in increasing order
for p in primerange(2, 10**7):

    # Repunits are never divisible by 2 or 5
    if p in (2, 5):
        continue

    # p divides R(N) iff 10^N ≡ 1 (mod p)
    if pow(10, N, p) == 1:
        factors.append(p)

        if len(factors) == TARGET:
            break

answer = sum(factors)

print(factors)
print(answer)
```---

 #4. 小さな例の検証

 ステートメントは次のようになります。$$R(10)=1111111111$$素因数付き$$11,\ 41,\ 271,\ 9091.$$実際、それぞれは次の条件を満たします。$$10^{10}\equiv 1 \pmod p.$$それらの合計は$$11+41+271+9091=9414,$$問題文と一致します。 

したがって、その基準は正しいです。

 #5. 最終検証

 条件を満たす最初のいくつかの素数は次のとおりです。$$11, 17, 41, 73, 101, \dots$$すべてが互いに素である$10$、予想通り。 

このような素数の最初の 40 個について計算された合計は次のようになります。$$843296$$これは予想されるサイズです (平均すると約 40 個の素数)$2\times 10^4$）。
