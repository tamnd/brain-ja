[プロジェクト オイラー問題 123](https://projecteuler.net/problem=123)

 ## 解決策

 **答え:**`21035`させて$$r_n = (p_n-1)^n + (p_n+1)^n \pmod{p_n^2},$$どこ$p_n$です$n$-番目の素数。 

私たちは最小限のものを求めます$n$そのような$$r_n > 10^{10}.$$---

 # 数学的分析

 重要な観察は、二項定理を使用すると式が大幅に簡素化できるということです。 

させて$p=p_n$。 

拡張します:$$(p+1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k$$そして$$(p-1)^n = \sum_{k=0}^{n} \binom{n}{k} p^k(-1)^{n-k}.$$モジュロだけを気にします$p^2$, したがって、以下を含むすべての用語は$p^2$それ以上は消滅します。 

したがってモジュロ$p^2$、$$(p+1)^n \equiv 1 + np$$そして$$(p-1)^n \equiv (-1)^n + n(-1)^{n-1}p.$$追加:$$r_n \equiv (1+(-1)^n) + np\left(1+(-1)^{n-1}\right)\pmod{p^2}.$$次に、パリティケースに分割します。 

## ケース 1:$n$さえ

 それから$$(-1)^n=1,\qquad (-1)^{n-1}=-1.$$それで$$r_n \equiv 2 + np(1-1)=2 \pmod{p^2}.$$したがって、偶数については$n$、$$r_n = 2.$$これを超えることは決してありません$10^{10}$。 

---

 ## ケース 2:$n$奇妙な

 それから$$(-1)^n=-1,\qquad (-1)^{n-1}=1.$$それで$$r_n \equiv 0 + np(1+1)=2np \pmod{p^2}.$$したがって、奇数の場合、$n$、$$r_n = 2p_n n$$（に限って$2np_n < p_n^2$これは関連する範囲では当てはまります）。 

したがって、問題は最小の奇数を見つけることになります。$n$そのような$$2n p_n > 10^{10}.$$---

 ## 範囲の推定

 素数定理を使用すると、$$p_n \sim n\log n.$$したがって$$2n p_n \sim 2n^2\log n.$$およそ次のように解決します。$$2n^2\log n \approx 10^{10}.$$これは示唆します$n$周りにいる$2\times 10^4$。 

正確に計算できるようになりました。 

---

 # Pythonの実装```python
from math import isqrt

LIMIT = 10**10

def generate_primes(limit_count):
    """
    Generate the first 'limit_count' primes using
    a standard incremental primality test.
    """
    primes = [2]
    candidate = 3

    while len(primes) < limit_count:
        is_prime = True
        root = isqrt(candidate)

        for p in primes:
            if p > root:
                break
            if candidate % p == 0:
                is_prime = False
                break

        if is_prime:
            primes.append(candidate)

        candidate += 2

    return primes

# We know the answer is around 2e4, so 30000 primes is plenty.
primes = generate_primes(30000)

answer = None

for n in range(1, len(primes) + 1, 2):   # only odd n matter
    p = primes[n - 1]                    # p_n (1-indexed)

    remainder = 2 * n * p

    if remainder > LIMIT:
        answer = n
        break

print(answer)
```---
