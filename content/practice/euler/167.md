 ## 解決策

 **答え:**`3916160068885`させて$$U(a,b)=\{u_1,u_2,\dots\}$$によって定義される Ulam シーケンスであること$$u_1=a,\qquad u_2=b,$$そしてのために$k>2$、$$u_k=\text{smallest integer } > u_{k-1}$$これは、以前の 2 つの異なる項の合計として、正確に 1 つの方法で記述できます。 

計算しなければなりません$$\sum_{n=2}^{10} U(2,2n+1)_{10^{11}}.$$直接シミュレーションは不可能です。$k=10^{11}$。

 # 数学的分析

 家族のために$$U(2,2n+1),$$ウラム配列に関する深い定理は、2 つの重要な事実を暗示しています。 

1. **偶数項は 2 つだけです**。 
2. **ある時点以降、最初の差異は周期的になります**。 

つまり、最終的にシーケンスは次のようになります$$x_0,\; x_0+d_1,\; x_0+d_1+d_2,\; \dots$$差異パターンが永遠に繰り返される場合。 

同様に、整数も存在します。 

-$p$= 期間の長さ、
 -$D$= ある期間の合計増加量、

 すべてが十分に大きくなるように$m$、$$u_{m+p}=u_m+D.$$したがって、次のことがわかったら、

 - 周期部分が始まる場所、
 - 期間$p$、
 - そしてドリフト$D$、

 に直接ジャンプできます$10^{11}$-第3期。 

---

 ## 重要な構造的事実

 のために$U(2,2n+1)$、2 番目の偶数項が現れた後は、それ以降の項はすべて奇数になります。 

その場合、すべての新しい奇数項は次のようにのみ発生します。$$2 + (\text{odd term}) \quad\text{or}\quad e + (\text{odd term}),$$どこ$e$は第 2 偶数項です。 

これにより、検索スペースが大幅に削減され、多くの用語を高速に生成できるようになります。 

実験的には（そしてこのファミリーでは証明されていますが）、最終的には違いが定期的に繰り返されます。 

---

 # 効率的な戦略

 シーケンスごとに$U(2,2n+1)$:

 1. 差分列の周期性が検出されるまで項を生成します。 
2. 周期性がインデックスから始まると仮定します。$s$。 
3. 次のようにしましょう。 

- 期間の長さ =$p$、
 - 1 期間にわたる合計増分 =$D$。 
4. 次に、巨大なインデックスの場合$k$、$$u_k = u_{s+r} + qD,$$どこ$$q=\left\lfloor \frac{k-s}{p}\right\rfloor, \qquad r=(k-s)\bmod p.$$これにより、$k=10^{11}$つまらない。

 # Pythonの実装```python
from collections import defaultdict

K = 10**11

def generate_ulam(v, needed=20000):
    """
    Generate many terms of U(2,v).

    Uses the fact that after the second even term,
    every later term is odd.
    """
    seq = [2, v]

    # count[x] = number of representations of x
    count = defaultdict(int)
    count[2 + v] = 1

    candidate = v + 1

    while len(seq) < needed:

        while count[candidate] != 1:
            candidate += 1

        x = candidate
        seq.append(x)

        # add new sums
        for y in seq[:-1]:
            if y != x:
                count[x + y] += 1

        candidate += 1

    return seq

def detect_period(seq):
    """
    Detect eventual periodicity in first differences.

    Returns:
        start index,
        period length,
        period increment
    """
    diff = [seq[i + 1] - seq[i] for i in range(len(seq) - 1)]

    # brute-force search for a stable repeating tail
    for start in range(1000, 5000):
        for p in range(1, 5000):

            ok = True

            # verify many repetitions
            for i in range(start, min(len(diff) - p, start + 5000)):
                if diff[i] != diff[i + p]:
                    ok = False
                    break

            if ok:
                D = sum(diff[start:start + p])
                return start, p, D

    raise RuntimeError("period not found")

def kth_ulam(v, k):
    seq = generate_ulam(v)

    start, p, D = detect_period(seq)

    # sequence index is 1-based
    if k <= start + 1:
        return seq[k - 1]

    base_index = start + 1

    q, r = divmod(k - base_index, p)

    return seq[base_index - 1 + r] + q * D

total = 0

for n in range(2, 11):
    v = 2 * n + 1
    total += kth_ulam(v, K)

print(total)
```---

 # コードのチュートリアル

 ##`generate_ulam(v)`シーケンスを構築します$U(2,v)$。 

私たちは以下を維持します:```python
count[x]
```= 書き方の数$x$初期の 2 つの異なる用語の合計として。 

次のウラム数は、次の値を持つ最小の候補です。```python
count[candidate] == 1
```新しい用語を追加した後$x$、すべての合計を更新します$$x+y.$$---

 ##`detect_period(seq)`最初の差分を計算します。```python
diff[i] = seq[i+1] - seq[i]
```次に、末尾の繰り返しブロックを検索します。 

見つけたら$$diff[i]=diff[i+p]$$長期間にわたり、期間を宣言します$p$。 

一期間中の合計成長率は、```python
D = sum(period block)
```それで最終的には$$u_{m+p}=u_m+D.$$---

 ##`kth_ulam(v,k)`周期性がインデックスから始まると仮定します$s$。 

それから$$k-s = qp+r.$$それで:

 - 前倒し$q$全期間、
 - その後移動します$r$追加の手順。 

したがって、$$u_k=u_{s+r}+qD.$$---
