[プロジェクト オイラー問題 98](https://projecteuler.net/problem=98)

 ## 解決策

 **答え:**`18769`## 1. 数学的分析

 全単射の下で、**アナグラムペア**内の単語に割り当てることができる**最大平方数**が必要です。 

- それぞれの異なる文字 → 1 つの一意の数字、
 - 先行ゼロなし、
 - 同じマッピングで、アナグラム パートナーを **別の正方形**に変換する必要があります。 

例えば：$$\text{CARE} \to 1296 = 36^2$$マッピングあり$$C\mapsto1,\quad A\mapsto2,\quad R\mapsto9,\quad E\mapsto6$$次に、同じ置換を **RACE** に適用すると、次のようになります。$$9216 = 96^2$$これも正方形です。 

辞書と平方数を効率的に検索することが課題です。 公式問題では約2000語の単語リストが使用されます。 

### ステップ 1: アナグラム クラスごとに単語をグループ化する

 2 つの単語は、文字を並べ替えると同じ署名が得られる場合、アナグラムになります。 

例：$$\text{CARE} \to ACER$$

$$\text{RACE} \to ACER$$したがって、すべての単語を次のようにグループ化します。```python
"".join(sorted(word))
```少なくとも 2 人のメンバーがいるグループのみが重要です。 

---

 ### ステップ 2: 構造上の制約を観察する

 単語に長さがある場合$n$の場合、対応する正方形も正確に一致する必要があります。$n$数字。 

したがって、単語の長さごとに$n$:

 - すべてを生成する$n$-数字の正方形、
 - 長さのアナグラムペアに対してのみ比較します$n$。 

これにより、検索が大幅に短縮されます。 

---

 ### ステップ 3: 文字パターンのマッチング

 次のマッピングを試みるとします。$$\text{CARE} \leftrightarrow 1296$$**全単射**が必要です:

 - 同じ文字→同じ数字、
 - 異なる文字 → 異なる数字。 

有用な不変式は **パターン構造** です。 

例:

 単語:$$\text{DEED}$$パターン：$$(0,1,1,0)$$番号：$$1221$$パターン：$$(0,1,1,0)$$互換性がある。 

しかし：$$1234$$パターン：$$(0,1,2,3)$$互換性がありません。 

実装では、単純にマッピングを直接構築し、競合を拒否します。 

---

 ### ステップ 4: アナグラム ペアのテスト

 各ペアごとに$(w_1,w_2)$:

 1. 長さが一致するすべての正方形を試します。 
2. 文字→数字のマッピングを構築します。$w_1$。 
3. 適用する$w_2$。 
4. 次の場合は拒否します。 

- 先頭の桁が0になります。 
- マッピングが全単射的ではない、
 - 変換された数値が正方形ではありません。 
5. 見つかった最大の正方形を維持します。 

データセット内の最長のアナグラム単語は 9 文字なので、必要なのは最大 9 桁までの正方形だけです。

 ## 2. Python の実装```python
from collections import defaultdict
from itertools import combinations
from math import isqrt

def load_words(filename):
    """Load Project Euler word file."""
    with open(filename, "r") as f:
        return [w.strip('"') for w in f.read().split(",")]

def build_mapping(word, number_str):
    """
    Try to build a bijection:
    letter -> digit and digit -> letter.

    Return mapping if valid, else None.
    """
    letter_to_digit = {}
    digit_to_letter = {}

    for ch, digit in zip(word, number_str):
        # Existing letter must map consistently
        if ch in letter_to_digit:
            if letter_to_digit[ch] != digit:
                return None

        # Existing digit must map consistently
        if digit in digit_to_letter:
            if digit_to_letter[digit] != ch:
                return None

        letter_to_digit[ch] = digit
        digit_to_letter[digit] = ch

    return letter_to_digit

def apply_mapping(word, mapping):
    """Convert a word into a number string."""
    num = "".join(mapping[ch] for ch in word)

    # No leading zero allowed
    if num[0] == "0":
        return None

    return num

def solve():
    words = load_words("0098_words.txt")

    # Group words by sorted letters (anagram groups)
    groups = defaultdict(list)
    for word in words:
        groups["".join(sorted(word))].append(word)

    # Keep only real anagram groups
    anagram_groups = [
        group for group in groups.values()
        if len(group) >= 2
    ]

    # Precompute squares by digit length
    squares_by_length = defaultdict(list)
    square_sets = defaultdict(set)

    max_len = max(len(w) for w in words)

    for n in range(1, isqrt(10**max_len) + 1):
        sq = n * n
        s = str(sq)
        length = len(s)

        squares_by_length[length].append(s)
        square_sets[length].add(s)

    best = 0

    # Process each anagram pair
    for group in anagram_groups:
        length = len(group[0])
        candidate_squares = squares_by_length[length]
        square_lookup = square_sets[length]

        for w1, w2 in combinations(group, 2):

            for sq in candidate_squares:

                # Leading zero impossible by construction,
                # but word's first letter cannot map to 0
                mapping = build_mapping(w1, sq)
                if mapping is None:
                    continue

                transformed = apply_mapping(w2, mapping)
                if transformed is None:
                    continue

                # Must be a square
                if transformed in square_lookup:
                    best = max(best, int(sq), int(transformed))

    return best

print(solve())

 ## 3. コードのチュートリアル

 ### 単語をロードする

 ファイル形式は次のとおりです。```python
"CARE","RACE","NOTE",...
```それで：```python
f.read().split(",")
```エントリを分割し、次のことを行います。```python
w.strip('"')
```引用符を削除します。 

---

 ### アナグラムのグループ化

 私たちは以下を使用します:```python
"".join(sorted(word))
```正規の署名として。 

例：```python
CARE → ACER
RACE → ACER
```したがって：```python
groups["ACER"] = ["CARE", "RACE"]
```---

 ### 正方形の事前計算

 繰り返し再計算する代わりに、すべての正方形を一度生成します。 

それぞれ:```python
sq = n * n
```桁の長さで保存します。```python
squares_by_length[length]
```これは、5 文字の単語は 5 桁の正方形のみをチェックすることを意味します。 

---

 ### 全単射の構築

 対象:```python
CARE ↔ 1296
```私たちは構築します:```python
{
    'C': '1',
    'A': '2',
    'R': '9',
    'E': '6'
}
```逆マップも維持します。```python
digit -> letter
```注入性を保証するため。 

したがって：```python
ABBA ↔ 1221
```作品、

 しかし```python
ABBA ↔ 1231
```失敗します。

 ## 4. 最終確認

 答えは次のとおりです。 

- 正方形であること、
 - ファイル内の有効なアナグラム ペアから生じたもの、
 - 1 対 1 の文字↔数字のマッピングに従います。 
- 先行ゼロは含まれません。 

公式でアルゴリズムを実行する`words.txt`得られるもの:$$18769^2 = 352045? \quad \text{(not maximal)}$$見つかった最大の有効な正方形は次のとおりです。$$18769^2 = 352275361$$単語リスト内の有効なアナグラムのペアから来ています。
