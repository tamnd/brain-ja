 ## 解決策

 **答え:**`64564225042`各コードワードを二分木の葉に対応させます。 

- を摂取する`0`エッジコスト`1`- を摂取する`1`エッジコスト`4`したがって、コードワードのコストは、ルートからの加重パス長になります。 

プレフィックスのないコードは、まさにそのようなツリーの葉のセットです。 

私たちは、可能な限り最小の総リーフコストを求めます。$n$葉。 

---

 #1. 数学的分析

 現在コストのリーフがあるとします。$x$。 

これを 2 つの子に展開すると、次のようになります。 

- 左の子の費用 =$x+1$- 右の子のコスト =$x+4$葉の数が増えます$1$、合計コストは次のように変化します。$$(x+1)+(x+4)-x = x+5.$$したがって:

 > できるだけ安くリーフの数を増やすには、常に現在最も安いリーフを拡張する必要があります。 

この貪欲な戦略は、拡張ごとに新しいリーフが 1 つだけ追加され、増分が追加されるため、最適です。$x+5$利用可能な最小のものを選択することで最小化されます$x$。 

---

 ## 拡張プロセス

 コストの 1 つの空のコードワードから開始します$0$。 

コストの葉を広げる$c$:$$c \to (c+1,\ c+4)$$させて$t_c$コストのリーフの回数になります$c$拡張されます。 

コストのノード$c$以下からのみ生じます。 

- 費用 -$(c-1)$経由ノード`0`エッジ
 - 費用 -$(c-4)$経由ノード`1`エッジ

 したがって、次のようになります。$$t_c = t_{c-1} + t_{c-4},$$と$$t_0=1,\qquad t_c=0 \text{ for } c<0.$$シーケンスは次のように始まります。$$1,1,1,1,2,3,4,5,7,10,14,19,\dots$$---

 ## これを葉の数に関連付ける

 拡張するたびに葉の数が増加します$1$。 

すべての費用を完全に処理した後$<k$、葉の数は$$1+\sum_{i=0}^{k-1} t_i.$$累計コストは$$\sum_{i=0}^{k-1} t_i(i+5),$$それぞれの拡張にはコストがかかるため、$i$総コストが増加する$i+5$。 

まだ必要なら$r$追加の拡張には費用がかかります$k$、 それから$$\text{Cost}(n) = \sum_{i=0}^{k-1} t_i(i+5) + r(k+5),$$どこ$$r = n-\left(1+\sum_{i=0}^{k-1} t_i\right).$$---

 #2. Pythonの実装```python
def cost(n):
    # t[c] = number of leaves of cost c that get expanded
    t = [1]   # t_0 = 1

    leaves = 1   # current number of leaves
    total = 0
    c = 0

    while True:
        # extend recurrence if needed
        if c >= len(t):
            val = t[c - 1]
            if c >= 4:
                val += t[c - 4]
            t.append(val)

        # If processing all nodes of cost c would reach/exceed n,
        # finish partially here.
        if leaves + t[c] >= n:
            remaining = n - leaves
            return total + remaining * (c + 5)

        # fully process all nodes of cost c
        leaves += t[c]
        total += t[c] * (c + 5)

        c += 1

print(cost(6))        # 35
print(cost(10**9))    # final answer
```---
