[プロジェクト オイラー問題 926](https://projecteuler.net/problem=926)

 ## 解決策

 **答え:**`40410219`数字の場合$n$、底面の丸み$b$が最大です$k$そのような$b^k \mid n$。 

したがって、次のようになります。$$R(n)=\sum_{b\ge2} v_b(n)$$どこ$v_b(n)$の指数です$b$分割する$n$。 

ここで次のことを観察してください。$$v_b(n)=\sum_{k\ge1} [b^k\mid n]$$それで$$R(n)=\sum_{k\ge1} \#\{b\ge2 : b^k\mid n\}.$$もし$$n=\prod p_i^{a_i},$$それから$b^k\mid n$のすべての素指数がある場合$b$せいぜい$\left\lfloor a_i/k\right\rfloor$。 

したがって、そのような数は、$b$は$$\prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1,$$(「」$-1$”を除く$b=1$）。 

それで：$$R(n)=\sum_{k\ge1} \left( \prod_i \left(\left\lfloor \frac{a_i}{k}\right\rfloor+1\right)-1 \right).$$のために$n=N!$、指数は$$a_p=v_p(N!)=\sum_{j\ge1}\left\lfloor \frac{N}{p^j}\right\rfloor.$$次の Python コードは、値を効率的に計算します。```python
MOD = 10**9 + 7
N = 10_000_000

# exponent of 2 in N! gives the maximum possible k
a2 = 0
t = N
while t:
    t //= 2
    a2 += t

# D[k] = product over primes p of (floor(v_p(N!)/k) + 1)
D = [1] * (a2 + 1)

# sieve of Eratosthenes
sieve = bytearray(b"\x01") * (N + 1)
sieve[0] = sieve[1] = 0

limit = int(N**0.5)
for i in range(2, limit + 1):
    if sieve[i]:
        step = i
        start = i * i
        sieve[start:N + 1:step] = b"\x00" * (((N - start) // step) + 1)

primes = [i for i in range(2, N + 1) if sieve[i]]

# process each prime exponent in N!
for p in primes:
    a = 0
    t = N
    while t:
        t //= p
        a += t

    for k in range(1, a + 1):
        D[k] = (D[k] * (a // k + 1)) % MOD

answer = sum(x - 1 for x in D) % MOD
print(answer)
```サンプルの検証:

 -$R(20)=6$-$R(10!)=312$どちらもステートメントと一致します。
