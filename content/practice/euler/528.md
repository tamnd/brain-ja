[プロジェクト オイラー問題 528](https://projecteuler.net/problem=528)

 ## 解決策

 **答え:**`779027989`させて$$S(n,k,b)=\#\left\{(x_1,\dots,x_k)\in \mathbb Z_{\ge 0}^k: x_1+\cdots+x_k\le n,\;\;0\le x_m\le b^m \right\}.$$必要です$$\left(\sum_{10\le k\le 15} S(10^k,k,k)\right)\bmod 1{,}000{,}000{,}007.$$## 1. 数学的分析

 有界整数解を数えたいのですが、$$x_1+\cdots+x_k\le n$$と$$0\le x_m\le b^m.$$標準的なトリックは、不等式を平等に変換します。 

スラック変数を導入する$$x_{k+1}=n-(x_1+\cdots+x_k)\ge 0.$$次に、解決策を数えます$$x_1+\cdots+x_k\le n$$の非負の解を数えることと同じです$$x_1+\cdots+x_k+x_{k+1}=n$$上限のみあり$x_1,\dots,x_k$。 

### ステップ 1: 無制限のカウント

 上限がない場合、非負の解の数は$$x_1+\cdots+x_{k+1}=n$$これは古典的な星と棒の結果です。$$\binom{n+k}{k}.$$### ステップ 2: 包含と除外

 強制しなければなりません$$x_m\le b^m.$$させて$$u_m=b^m.$$サブセットの場合$A\subseteq \{1,\dots,k\}$のすべての変数を仮定します。$A$その限界に違反しています:$$x_i\ge u_i+1 \qquad (i\in A).$$セット$$y_i=x_i-(u_i+1)$$のために$i\in A$。 すると方程式は次のようになります$$\sum y_i + \sum_{i\notin A}x_i + x_{k+1} = n-\sum_{i\in A}(u_i+1).$$したがって、そのような解の数は次のようになります。$$\binom{ n-\sum_{i\in A}(u_i+1)+k }{k},$$と解釈される$0$最高値が$<k$。 

包含と除外により、次のようになります。$$S(n,k,b) = \sum_{A\subseteq \{1,\dots,k\}} (-1)^{|A|} \binom{ n-\sum_{i\in A}(b^i+1)+k }{k}.$$以来$k\le 15$、 のみ$2^{15}=32768$サブセットが必要なため、これが非常に高速になります。

 ## 2. Python の実装```python
from math import comb

MOD = 1_000_000_007

def S(n, k, b):
    # Upper bounds u_i = b^i
    bounds = [b ** i for i in range(1, k + 1)]

    total = 0

    # Inclusion-exclusion over subsets
    for mask in range(1 << k):
        shift = 0
        bits = 0

        for i in range(k):
            if (mask >> i) & 1:
                shift += bounds[i] + 1
                bits += 1

        top = n - shift + k

        # Binomial coefficient contributes only if top >= k
        ways = comb(top, k) if top >= k else 0

        if bits % 2:
            total -= ways
        else:
            total += ways

    return total

# Verify examples
print(S(14, 3, 2))                  # 135
print(S(200, 5, 3))                 # 12949440
print(S(1000, 10, 5) % MOD)         # 624839075

# Compute Euler 528 answer
answer = sum(S(10**k, k, k) for k in range(10, 16)) % MOD

print(answer)
```---

 ## 3. コードのチュートリアル

 ###`bounds = [b ** i for i in range(1, k + 1)]`作成するもの:$$[b^1,b^2,\dots,b^k].$$これらは各変数の上限です。 

###`for mask in range(1 << k)`ビットマスクを使用して変数のすべてのサブセットを反復処理します。 

各サブセットは、上限に違反する変数を表します。 

###`shift += bounds[i] + 1`可変の場合$x_i$制限を超えることを強制された場合は、以下を差し引きます。$$b^i+1$$私たちが代用するから$$x_i = y_i + (b^i+1).$$###`top = n - shift + k`シフト後の残りの方程式は、$$k+1$$負でない変数を合計すると合計が小さくなります。 

星とバーは次のようになります。$$\binom{\text{top}}{k}.$$### 包含-除外記号

 奇数サイズのサブセットは減算されます。 偶数サイズのサブセットは以下を追加します。```python
if bits % 2:
    total -= ways
else:
    total += ways
```---
