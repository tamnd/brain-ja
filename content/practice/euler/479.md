[プロジェクト オイラー問題 479](https://projecteuler.net/problem=479)

 ## 解決策

 **答え:**`191541795`させて$$\frac1x=\left(\frac{k}{x}\right)^2(k+x^2)-kx.$$私たちはそう言われています$a_k,b_k,c_k$はこの方程式の 3 つの根であり、次のように定義されます。$$S(n)=\sum_{p=1}^n\sum_{k=1}^n (a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p.$$計算しなければなりません$S(10^6)\bmod 1\,000\,000\,007$。 

---

 # ステップ 1: 方程式を多項式に変換する

 から始まる$$\frac1x=\frac{k^2}{x^2}(k+x^2)-kx,$$拡大する：$$\frac1x=\frac{k^3}{x^2}+k^2-kx.$$を乗算する$x^2$:$$x=k^3+k^2x^2-kx^3.$$再配置:$$kx^3-k^2x^2+x-k^3=0.$$したがって$a_k,b_k,c_k$のルーツです$$kx^3-k^2x^2+x-k^3=0.$$で割る$k$:$$x^3-kx^2+\frac1k x-k^2=0.$$モニックキュービックについては$$x^3-s_1x^2+s_2x-s_3,$$ビエタが与える$$s_1=a+b+c=k,$$

$$s_2=ab+ac+bc=\frac1k,$$

$$s_3=abc=k^2.$$---

 # ステップ 2: 式を簡略化する

 必要です$$(a+b)(b+c)(c+a).$$標準の対称アイデンティティは次のとおりです。$$(a+b)(b+c)(c+a) =(a+b+c)(ab+ac+bc)-abc.$$したがって$$(a+b)(b+c)(c+a) =s_1s_2-s_3.$$Vieta の値を次のように置き換えます。$$=k\cdot \frac1k-k^2 =1-k^2.$$したがって、$$(a_k+b_k)^p(b_k+c_k)^p(c_k+a_k)^p =(1-k^2)^p.$$それで$$S(n)=\sum_{k=1}^n\sum_{p=1}^n(1-k^2)^p.$$---

 # ステップ 3: 等比級数を評価する

 固定用$k$、$$\sum_{p=1}^n r^p =\frac{r(r^n-1)}{r-1}, \quad r=1-k^2.$$したがって$$S(n)=\sum_{k=1}^n \frac{(1-k^2)\big((1-k^2)^n-1\big)}{-k^2}.$$このモジュロだけが必要です$$M=1\,000\,000\,007.$$以来$M$が素数、除算$k^2$は逆モジュラーによる乗算です。 

複雑さは$O(n\log M)$、簡単に十分に高速です$n=10^6$。 

---

 # ステップ 4: Python の実装```python
MOD = 1_000_000_007
n = 10**6

ans = 0

for k in range(1, n + 1):
    r = (1 - k * k) % MOD

    # Sum_{p=1}^n r^p
    # = r * (r^n - 1) / (r - 1)

    numerator = r * (pow(r, n, MOD) - 1)
    denominator = (r - 1) % MOD

    geom = numerator * pow(denominator, MOD - 2, MOD)
    ans = (ans + geom) % MOD

print(ans % MOD)
```---
