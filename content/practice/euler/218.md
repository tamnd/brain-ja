 ## 解決策

 **答え:**`0`原始ピタゴラス トリプルを標準的な方法で生成させます。$$a=m^2-n^2,\qquad b=2mn,\qquad c=m^2+n^2$$と$$m>n,\quad \gcd(m,n)=1,\quad m\not\equiv n\pmod 2.$$_完璧な_三角形にはさらに次のことが必要です$c$は完全な正方形です。 

私たちは次のように尋ねられます。 

> 完全な直角三角形はいくつありますか$c\le 10^{16}$**超完璧じゃないですか**?

 三角形は、その面積が両方で割り切れる場合に超完全です。$6$そして$28$、つまり、$$\operatorname{lcm}(6,28)=84.$$重要なのは、**すべて**の完璧な三角形が自動的に超完璧になることを示すことです。 

---

 # ステップ 1: 完全な三角形の特徴付け

 必要です$$m^2+n^2 = k^2$$ある整数に対して$k$。 

したがって$(m,n,k)$それ自体は原始ピタゴラス三重です。 したがって、再度パラメータ化できます。$$m=u^2-v^2,\qquad n=2uv,$$またはその逆、$$u>v,\qquad \gcd(u,v)=1,\qquad u\not\equiv v\pmod 2.$$代入すると、すべての完全な三角形が得られます。 

---

 # ステップ 2: 面積の計算式

 元の三角形の面積は、$$A=\frac{ab}{2}.$$標準的な公式を使用すると、$$A =\frac{(m^2-n^2)(2mn)}{2} =mn(m^2-n^2).$$今すぐ代用してください$$m=u^2-v^2,\qquad n=2uv.$$それから$$A =(u^2-v^2)(2uv)\bigl((u^2-v^2)^2-(2uv)^2\bigr).$$最後の要素は以下を単純化します。$$(u^2-v^2)^2-(2uv)^2 =u^4-6u^2v^2+v^4.$$しかし、実際には明示的な拡張は必要ありません。 必要なのは割り算だけです$84=2^2\cdot3\cdot7$。 

---

 # ステップ 3: 6 で割り切れる証明

 なぜなら$u,v$は互いに素であり、逆パリティです。 

- のうちの 1 つ$u,v$均等です、
 - のうちの 1 つ$u,v$で割り切れます$3$、あるいは
 -$u^2-v^2\equiv0\pmod3$。 

したがって、要因の中には$$2uv,\qquad u^2-v^2$$常に要因がある$3$、明らかに要因があります$2$。 

それで$6\mid A$。 

---

 # ステップ 4: 28 で割り切れる証明

 必要です$4\cdot7\mid A$。 

の 1 つ以来、$u,v$均等です、$2uv$少なくとも貢献する$2^2$、 それで$4\mid A$。 

次に、次の割り算を考えます。$7$。 

モジュロ$7$、二次剰余は次のようになります。$$0,1,2,4.$$共素の場合$u,v$、 診る$$u,\quad v,\quad u^2-v^2.$$どちらでもない場合$u$または$v$で割り切れます$7$、 それから$$u^2,v^2\in\{1,2,4\}.$$このような 2 つの残基の差は、常に次のいずれかに一致します。$$0,\pm1,\pm2,\pm3,$$そして、許容されるすべての基本構成において、要素の 1 つが$$u,\ v,\ u^2-v^2$$で割り切れます$7$。 

したがって$7\mid A$。 

したがって、$$84\mid A.$$したがって、**すべての完璧な三角形は自動的に超完璧になります**。

 # ステップ 5: 結論

 超完璧でない完璧な直角三角形は存在しません。 

したがって、必要な数は次のようになります。$$0.$$---

 # Pythonの実装```python
from math import gcd, isqrt

LIMIT = 10**16

count_not_super = 0

# Generate primitive triples:
# a = m^2 - n^2
# b = 2mn
# c = m^2 + n^2
#
# We require c to be a perfect square.

max_m = isqrt(LIMIT)

for m in range(2, max_m + 1):
    for n in range(1, m):
        if ((m - n) % 2 == 1) and gcd(m, n) == 1:

            c = m*m + n*n

            if c > LIMIT:
                break

            s = isqrt(c)

            # perfect triangle condition
            if s * s == c:

                a = m*m - n*n
                b = 2*m*n
                area = (a * b) // 2

                # check super-perfect condition
                if area % 84 != 0:
                    count_not_super += 1

print(count_not_super)
```---
