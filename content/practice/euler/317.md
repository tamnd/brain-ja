[プロジェクト オイラー問題 317](https://projecteuler.net/problem=317)

 ## 解決策

 **答え:**`1856532.8455`高所で爆発を起こさせる$h=100$地上 m、すべての破片が高速で発射される$$v_0 = 20 \text{ m/s}$$重力の下で$$g = 9.81 \text{ m/s}^2.$$少なくとも 1 つの破片が地面に衝突する前に到達する、空間内のすべての点の体積が必要です。 

---

 #1. 数学的分析

 速度コンポーネントで起動されたフラグメント$(v_x,v_y,v_z)$満足する$$v_x^2+v_y^2+v_z^2=v_0^2.$$問題は垂直軸を中心に回転対称であるため、円筒座標を使用します。 

-$r=\sqrt{x^2+y^2}$-$z$垂直の高さ。 

させて：

-$u$= 水平速度、
 -$w$= 垂直速度、

 それで$$u^2+w^2=v_0^2.$$発射体の方程式は次のとおりです。$$r = ut,$$

$$z = h + wt - \frac12 gt^2.$$なくす$u$を使用して$u=r/t$:$$\left(\frac{r}{t}\right)^2 + w^2 = v_0^2.$$また、$$w=\frac{z-h+\frac12 gt^2}{t}.$$代わりの：$$\frac{r^2}{t^2} + \left(\frac{z-h+\frac12 gt^2}{t}\right)^2 = v_0^2.$$乗算する$t^2$:$$r^2 + \left(z-h+\frac12 gt^2\right)^2 = v_0^2 t^2.$$私たちはそれぞれに求めます$(r,z)$が存在するかどうか。$t>0$これを満足させます。 

---

 ## 到達可能なポイントのエンベロープ

 定義する$$A=z-h.$$それから$$r^2 + \left(A+\frac12 gt^2\right)^2 = v_0^2 t^2.$$拡大する：$$r^2 + A^2 + Ag t^2 + \frac14 g^2 t^4 = v_0^2 t^2.$$させて$s=t^2$:$$\frac14 g^2 s^2 + (Ag-v_0^2)s + (A^2+r^2)=0.$$到達可能性には真のソリューションが必要です$s\ge0$。 したがって、判別式は満たさなければなりません$$(Ag-v_0^2)^2 - g^2(A^2+r^2)\ge0.$$拡大する：$$A^2g^2 - 2Agv_0^2 + v_0^4 - g^2A^2 - g^2r^2 \ge 0.$$の$A^2g^2$条件のキャンセル:$$v_0^4 - 2Agv_0^2 - g^2r^2 \ge 0.$$想起$A=z-h$:$$g^2r^2 \le v_0^4 - 2g v_0^2(z-h).$$を解決します$z$:$$z \le h + \frac{v_0^2}{2g} - \frac{g r^2}{2v_0^2}.$$これは放物面です。 

したがって、到達可能な領域全体が下の固体になります。$$z(r)=H-\alpha r^2$$どこ$$H=h+\frac{v_0^2}{2g}, \qquad \alpha=\frac{g}{2v_0^2}.$$地域はここで終わります$z=0$:$$0=H-\alpha R^2$$それで$$R^2=\frac{H}{\alpha}.$$---

 #2. 体積の計算

 回転体の体積は、$$V=\int_0^R \pi r^2\,dz$$またはもっと直接的に$$V=2\pi\int_0^R r(H-\alpha r^2)\,dr.$$計算:$$V = 2\pi \left[ \frac{H r^2}{2} - \frac{\alpha r^4}{4} \right]_0^R.$$使用する$R^2=H/\alpha$、$$V = 2\pi \left( \frac{H(H/\alpha)}{2} - \frac{\alpha(H/\alpha)^2}{4} \right).$$簡略化:$$V = 2\pi \left( \frac{H^2}{2\alpha} - \frac{H^2}{4\alpha} \right) = \frac{\pi H^2}{2\alpha}.$$以来$$\alpha=\frac{g}{2v_0^2},$$私たちは得る$$V = \pi H^2\frac{v_0^2}{g}.$$次に、値をプラグインします。$$H = 100+\frac{20^2}{2\cdot 9.81} = 100+\frac{400}{19.62} = 120.3873598369\ldots$$したがって$$V = \pi \cdot H^2 \cdot \frac{400}{9.81}.$$---

 #3. Pythonの実装```python
import math

# Given constants
h = 100.0
v0 = 20.0
g = 9.81

# Maximum height of the envelope paraboloid
H = h + v0**2 / (2 * g)

# Volume formula derived analytically
V = math.pi * H**2 * (v0**2 / g)

# Print rounded to 4 decimal places
print(f"{V:.4f}")
```---
