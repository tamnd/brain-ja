[プロジェクト オイラー問題 277](https://projecteuler.net/problem=277)

 ## 解決策

 **答え:**`1125977393124310`必要なステップ文字列を次のようにします$$S=\texttt{UDDDUdddDDUDDddDdDddDDUDDdUUDd}$$最小の整数を求めます$a_1>10^{15}$その修正されたコラッツ軌道は、まさにこれらのステップから始まります。 

---

 #1. 数学的分析

 ルールは次のとおりです。 

-$D:\quad a_{n+1}=\dfrac{a_n}{3}$、次の場合に有効です。$a_n\equiv0\pmod3$-$U:\quad a_{n+1}=\dfrac{4a_n+2}{3}$、次の場合に有効です。$a_n\equiv1\pmod3$-$d:\quad a_{n+1}=\dfrac{2a_n-1}{3}$、次の場合に有効です。$a_n\equiv2\pmod3$重要な所見は次のとおりです。 

> 各ステップはアフィン線形変換です。 

したがって、一連のステップ全体の後、開始値は終了値のアフィン関数になります。 

---

 ## 逆算して作業する

 すべてのステップの後、ある整数で終了すると仮定します。$x$。 

各演算を逆にします。 

### の逆$D$

$$a_n = 3a_{n+1}$$### の逆$U$

$$a_{n+1}=\frac{4a_n+2}{3}$$それで$$a_n=\frac{3a_{n+1}-2}{4}$$### の逆$d$

$$a_{n+1}=\frac{2a_n-1}{3}$$それで$$a_n=\frac{3a_{n+1}+1}{2}$$---

 次に、必要な文字列を逆方向に処理します。 

すべてのステップの後の最終値を次のようにします。$x$。 

すべての逆写像を記号的に構成した後、次の結果が得られます。$$a_1 = \frac{205891132094649\,x+21110037246199}{2^{22}}$$したがって$a_1$整数である場合$$205891132094649\,x+21110037246199 \equiv 0 \pmod{2^{22}}$$以来$2^{22}=4194304$、係数を法的に削減します$4194304$:$$686265x+356599\equiv0\pmod{4194304}$$なぜなら$$\gcd(686265,4194304)=1,$$固有の解モジュロがあります$4194304$。 

解くと得られるもの$$x\equiv 1966289 \pmod{4194304}.$$だから書いてください$$x=1966289+4194304k.$$をアフィン式に代入します。$a_1$:$$a_1 = 96521732651065 + 205891132094649\,k.$$ここでは最小のものを選択します$k$そのような$$a_1>10^{15}.$$つまり、$$96521732651065+205891132094649\,k>10^{15}.$$これにより、$$k=5.$$したがって、$$a_1 = 96521732651065 + 5\cdot205891132094649 = 1125977393124310.$$---

 #2. Pythonの実装```python
from math import gcd

# Required step sequence
s = "UDDDUdddDDUDDddDdDddDDUDDdUUDd"

# We derive:
# a1 = (A*x + B) / M
# where x is the value AFTER all steps.

A = 1
B = 0
M = 1

# Process inverses in reverse order
for ch in reversed(s):

    if ch == 'D':
        # x -> 3x
        A *= 3
        B *= 3

    elif ch == 'U':
        # x -> (3x - 2)/4
        A *= 3
        B = 3 * B - 2
        M *= 4

    elif ch == 'd':
        # x -> (3x + 1)/2
        A *= 3
        B = 3 * B + 1
        M *= 2

# Need:
# A*x + B ≡ 0 (mod M)

a = A % M
b = B % M

# modular inverse since gcd(a, M)=1
inv = pow(a, -1, M)

x0 = (-b * inv) % M

# General solution:
# x = x0 + M*k
#
# Then:
# a1 = (A*x + B)/M
#
# = base + A*k

base = (A * x0 + B) // M
step = A

LIMIT = 10**15

k = (LIMIT - base + step) // step

answer = base + step * k

print(answer)
```---

 #3. コードのチュートリアル

 ### アフィンフォームの構築

 逆数式は単純な線形マップであるため、シーケンスを逆方向に処理します。 

私たちは以下を維持します:$$a_1 = \frac{A x + B}{M}$$どこ$x$シーケンス全体の後の未知のエンドポイントです。 

各逆ステップが更新されます$A,B,M$。 

---

 ### 整合性の解決

 のために$a_1$整数になるには:$$A x + B \equiv 0 \pmod M.$$これは線形合同です。 

なぜなら$A$可逆モジュロです$M$、剰余クラスのモジュロがちょうど 1 つあります。$M$。 

---

 ### すべてのソリューションの生成

 すべての有効な解決策は次のとおりです。$$x=x_0+Mk.$$アフィン公式に代入すると、次のようになります。$$a_1=\text{base}+A k.$$したがって、有効な開始値は等差数列を形成します。 

を超える最小のものを選択します$10^{15}$。
