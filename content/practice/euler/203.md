[プロジェクト オイラー問題 203](https://projecteuler.net/problem=203)

 ## 解決策

 **答え:**`34029210557338`重要なタスクは、行に現れるすべての**個別の平方自由二項係数**を計算することです。$0$を通して$50$パスカルの三角形の値を求め、それらを合計します。 

数値を分割する素の平方がない場合、その数値は **自由平方** です。 

例:

 -$6 = 2 \cdot 3$スクエアフリーです。 
-$12 = 2^2 \cdot 3$そうではありません。 
-$20 = 2^2 \cdot 5$そうではありません。 

この問題は、ブルート フォース プログラムが動作することを明示的に示しています。 なぜそれが機能するのか、そしてそれがどのような結果を生み出すのかを正確に分析します。 

---

 # 数学的分析

 パスカルの三角形にはエントリが含まれています$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$行用$n = 0,1,2,\dots$。 

必要なものは次のとおりです。 

1. 間に現れるすべての個別の値$$\binom{n}{k}, \quad 0 \le n \le 50$$2. 四角いものだけを残します。 
3. それらを合計します。 

---

 ## スクエアフリーテスト

 数字$m$**整数がない**場合、squarefree です$d \ge 2$そのような$$d^2 \mid m$$提供された関数はこれを直接チェックします。```python
def is_squarefree(n):
    if n <= 1: return n == 1
    d = 2
    while d * d <= n:
        if n % (d*d) == 0: return False
        d += 1
    return True
```これが機能する理由は次のとおりです。 

- 正方形が分割されている場合$n$、
 - それからいくつかの正方形$d^2$と$d \le \sqrt n$それを分割します。 

それですべてをチェックしてください$d$まで$\sqrt n$で十分です。

 # Pythonの実装

 この問題では、次のコードを実行することが明示的に求められます。```python
from math import comb, isqrt

def is_squarefree(n):
    if n <= 1:
        return n == 1

    d = 2
    while d * d <= n:
        if n % (d * d) == 0:
            return False
        d += 1

    return True

seen = set()

for n in range(51):
    for k in range(n + 1):
        c = comb(n, k)

        if c not in seen and is_squarefree(c):
            seen.add(c)

print(sum(seen))
```---
