[プロジェクト オイラー問題 942](https://projecteuler.net/problem=942)

 ## 解決策

 **答え:**`557539756`させて$$p = 2^q-1$$と$q=74\,207\,281$、 そして$p$プライム。 

私たちは、最小限のポジティブな解決策を模索します。$$x^2 \equiv q \pmod p.$$メルセンヌ素数の場合、$2$秩序がある$q$モジュロ$p$、それで、$q$統一の根元$\mathbb F_p$は$$1,2,2^2,\dots,2^{q-1}.$$古典的な 2 次ガウス和恒等式は次のように与えます。$q\equiv1\pmod4$、$$G=\sum_{a=0}^{q-1}\left(\frac aq\right)2^a$$満足のいく$$G^2=q.$$以来$$\left(\frac 0q\right)=0, \qquad \left(\frac aq\right)= \begin{cases} 1 & a \text{ quadratic residue mod } q,\\ -1 & \text{otherwise}, \end{cases}$$書き換えることができます:$$G = 1+2\sum_{r\in QR(q)}2^r \pmod p,$$どこ$QR(q)$非ゼロ二次剰余のセットです。$q$。 

のために$q\equiv1\pmod8$(ここでは true)、このガウス和は_大きい_平方根なので、$$R(q)=p-G.$$したがって$$R(q) = 2^{q+1}-3 - 2\sum_{r\in QR(q)}2^r.$$このモジュロだけが必要です$M=10^9+7$したがって、すべての計算はモジュロで実行されます。$M$。 

直接$O(q)$計算は可能です。 

Python コード:```python
q = 74207281
MOD = 10**9 + 7

# mark quadratic residues mod q
qr = bytearray(q)
half = (q - 1) // 2

for i in range(1, half + 1):
    qr[(i * i) % q] = 1

s = 0
p2 = 2

for r in range(1, q):
    if qr[r]:
        s = (s + p2) % MOD
    p2 = (p2 * 2) % MOD

# p2 == 2^q mod MOD
ans = (2 * p2 - 3 - 2 * s) % MOD

print(ans)
```これは次のように評価されます。
