[プロジェクト オイラー問題 127](https://projecteuler.net/problem=127)

 ## 解決策

 **答え:**`18407904`させて$R(n)=\operatorname{rad}(n)$、次の異なる素因数の積$n$。 

私たちはすべてのトリプルを求めます$(a,b,c)$そのような$$a+b=c,\qquad a<b,\qquad \gcd(a,b)=\gcd(a,c)=\gcd(b,c)=1,$$そして$$R(abc)<c.$$計算しなければなりません$$\sum c \quad\text{for all abc-hits with } c<120000.$$---

 #1. 数学的分析

 直接的な力ずくのアプローチは絶望的です。 

-$c<120000$- それぞれについて$c$、潜在的に$O(c)$分割$a+b=c$それは何十億もの小切手になるでしょう。 

私たちはこの根本的な状況を利用する必要があります。 

---

 ## ステップ 1: gcd 条件の簡略化

 以来$$a+b=c,$$標準的な ID があります。$$\gcd(a,b)=1 \implies \gcd(a,c)=\gcd(b,c)=1.$$確かに、$$\gcd(a,c)=\gcd(a,a+b)=\gcd(a,b),$$そして同様に$\gcd(b,c)$。 

したがって、必要とするだけで十分です$$\gcd(a,b)=1.$$---

 ## ステップ 2: 根号を乗算的に使用する

 なぜなら$a,b,c$はペアごとに互いに素であり、$$R(abc)=R(a)R(b)R(c).$$したがって、abc-hit 条件は次のようになります。$$R(a)R(b)R(c)<c.$$同様に、$$R(a)R(b)<\frac{c}{R(c)}.$$これは非常に制限的なものです。 

---

 ## ステップ 3: 根号の事前計算

 私たちは計算します$R(n)$みんなのために$n<120000$ふるいを使って。 

最初に:$$R(n)=1.$$素数ごとに$p$、次の倍数ごとに乗算します。$p$による$p$。 

複雑：$$O(n\log\log n).$$---

 ## ステップ 4: キーの最適化

 仮定してください$c$固定されています。 

必要なものは次のとおりです。$$R(a)R(b)R(c)<c.$$以来$b=c-a$、$$R(a)R(c-a)<\frac{c}{R(c)}.$$ここで注意してください:

 - もし$R(c)$大きい場合は$c/R(c)$小さいです。 
- ほとんど$c$したがって動作できません。 

ループします:$$1\le a < \frac c2, \qquad b=c-a.$$しかし、そうでない限り、私たちはすぐに拒否します$$R(a)R(b) < \frac{c}{R(c)}.$$以下も必要です。$$\gcd(a,b)=1.$$---

 ## ステップ 5: 複雑さの推定

 意外とヒット数が少ない。 

最適化された検索は、Python では次の理由からすぐに終了します。 

- 根号は小さな整数です。 
- ほとんどのペアはすぐに失敗します。 
- gcd チェックは安いです。

 #2. Pythonの実装```python
from math import gcd

LIMIT = 120000

# ---------------------------------------------------------
# Compute rad(n) for all n < LIMIT using a sieve
# ---------------------------------------------------------

rad = [1] * LIMIT

for p in range(2, LIMIT):
    # p is prime iff rad[p] == 1
    if rad[p] == 1:
        for multiple in range(p, LIMIT, p):
            rad[multiple] *= p

# ---------------------------------------------------------
# Search for abc-hits
# ---------------------------------------------------------

total = 0

for c in range(3, LIMIT):

    rc = rad[c]

    # We need:
    # rad(a) * rad(b) * rad(c) < c
    #
    # so:
    # rad(a) * rad(b) < c / rad(c)

    threshold = c // rc

    # If threshold == 1, impossible
    if threshold <= 1:
        continue

    # Only need a < b
    for a in range(1, c // 2 + 1):

        b = c - a

        # Fast radical rejection
        if rad[a] * rad[b] >= threshold:
            continue

        # Need coprime
        if gcd(a, b) != 1:
            continue

        total += c

print(total)
```---
