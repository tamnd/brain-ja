 # 数学的分析

 最大でも全長の有効な方程式をすべて数えなければなりません$50$。 

A typical equation looks like$$a_1+a_2+\cdots+a_p = b_1+b_2+\cdots+b_q$$と$$a_1+\cdots+a_p=b_1+\cdots+b_q$$すべての数値は、先行ゼロのない正の 10 進整数です。 

---

 ## 1. 視点の反転: 桁-列 DP

 整数全体について考える代わりに、**最下位桁から列ごとに**方程式を処理します。 

任意の 10 進数列:

 - 一部の数値はまだ「生きています」(より高い桁まで継続します)、
 - 一部の数値はこの列で終了します (その最上位桁がここにあります)。 

仮定する：

-$p$左側の番号はまだ有効です。 
-$q$右側の番号はまだ有効です。 

アクティブな番号ごとに:

 - 上向きに続く場合、この数字は次の可能性があります。$0\ldots9$、
 - ここで終了する場合、この数字は次のようになります。$1\ldots9$。 

これは、「先行ゼロなし」ルールを正確に適用します。 

---

 ## 2. キャリー方程式

 しましょう

 -$S_L$= この列の左の数字の合計、
 -$S_R$= 右の数字の合計、
 -$c$= 入ってくるキャリー。 

それなら必要です$$S_L - S_R + c = 10c'$$外出用のキャリー用$c'$。 

したがって、問題全体は次のような有限状態の動的プログラムになります。$$(p,q,c)$$どこ：

-$p,q$数字が終わるにつれて減少し、
 -$c$は小数桁上げです。 

---

 ## 3. 長さの計算

 番号がある場合$d$数字、それは次のことに貢献します。 

-$d$数字文字、
 - 全体として 1 つのセパレーターの貢献。 

次の方程式の場合$m=p+q$合計数:

 - あります$m-2$プラス記号、
 - 1 つの等号、

 したがって、区切り文字の数は$$m-1.$$したがって全長は$$(\text{total digits}) + (m-1).$$DP は数字列を個別に追跡し、初期化時に区切り記号の寄与を追加します。 

---

 ## 4. 遷移のカウント

 その中にあると仮定します$p$アクティブな左側の番号:

 -$p'$続く、
-$p-p'$ここで終了します。 

右側についても同様に:

 -$q'$続く、
-$q-q'$終了します。 

数字生成セットは次のとおりです。 

- 継続番号: 桁$0\ldots9$、
 - 終端番号: 桁$1\ldots9$。 

特定の列の差を生み出すすべての桁の割り当てをカウントします。$$S_L-S_R.$$そしてキャリー条件により次のキャリーが一意に決まります。 

全長はわずかなので、$50$、状態空間はメモ化された再帰にとって十分に小さいです。

 # Pythonの実装```
from functools import lru_cache
from collections import defaultdict
from math import comb

MOD = 10**9 + 7
N = 50
MAX_TERMS = 25   # worst case: 1-digit numbers separated by symbols

# ------------------------------------------------------------
# dist(p, pp)
#
# p  = active numbers
# pp = numbers that continue upward
#
# Returns:
#   dictionary {digit_sum : count}
#
# Continuing numbers contribute digits 0..9.
# Terminating numbers contribute digits 1..9.
# ------------------------------------------------------------

@lru_cache(None)
def dist(p, pp):

    ways = {0: 1}

    # continuing numbers
    for _ in range(pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(10):
                nxt[s + d] += v
        ways = nxt

    # terminating numbers
    for _ in range(p - pp):
        nxt = defaultdict(int)
        for s, v in ways.items():
            for d in range(1, 10):
                nxt[s + d] += v
        ways = nxt

    # choose which numbers continue
    choose = comb(p, pp)

    return {k: v * choose for k, v in ways.items()}

# ------------------------------------------------------------
# trans(p, q, pp, qq)
#
# Returns all possible values of:
#
#   (left digit sum) - (right digit sum)
#
# together with their multiplicities.
# ------------------------------------------------------------

@lru_cache(None)
def trans(p, q, pp, qq):

    A = dist(p, pp)
    B = dist(q, qq)

    out = defaultdict(int)

    for a, va in A.items():
        for b, vb in B.items():
            out[a - b] += va * vb

    return list(out.items())

# ------------------------------------------------------------
# F(rem, p, q, carry)
#
# rem   = remaining digit-character budget
# p,q   = active numbers on each side
# carry = incoming carry
#
# Returns number of ways.
# ------------------------------------------------------------

@lru_cache(None)
def F(rem, p, q, carry):

    # success state
    if rem == 0:
        return 1 if p == 0 and q == 0 and carry == 0 else 0

    # impossible
    if p == 0 and q == 0:
        return 0

    column_cost = p + q

    if column_cost > rem:
        return 0

    ans = 0

    # choose survivors
    for pp in range(p + 1):
        for qq in range(q + 1):

            for diff, cnt in trans(p, q, pp, qq):

                t = diff + carry

                # must be divisible by 10
                if t % 10 != 0:
                    continue

                next_carry = t // 10

                ans += (
                    cnt *
                    F(rem - column_cost, pp, qq, next_carry)
                )

    return ans % MOD

# ------------------------------------------------------------
# Build A(n)
# ------------------------------------------------------------

exact = [0] * (N + 1)

for total_len in range(N + 1):

    value = 0

    # p left terms, q right terms
    for p in range(1, MAX_TERMS + 1):
        for q in range(1, MAX_TERMS + 1):

            separator_cost = p + q - 1

            if separator_cost > total_len:
                break

            digit_budget = total_len - separator_cost

            value += F(digit_budget, p, q, 0)

    exact[total_len] = value % MOD

# cumulative A(n)
A = [0] * (N + 1)

running = 0
for i in range(N + 1):
    running = (running + exact[i]) % MOD
    A[i] = running

print(A[3])   # 9
print(A[5])   # 171
print(A[7])   # 4878
print(A[50])
```---

 # コードのチュートリアル

 ##`dist(p, pp)`単一の 10 進数列の片側について考えられるすべての桁の合計を計算します。 

例：

-$p=3$、
 -$pp=1$、

 意味:

 - 1 つの数字が続く、
 - 2 つの番号はここで終了します。 

したがって、数字は次のとおりです。 

- から 1 桁$0..9$、
 - からの 2 桁$1..9$。 

可能なすべての桁の合計を数えます。 

---

 ##`trans(...)`左桁と右桁の分布を結合します。 

左の場合は合計が寄与します$a$そして右は合計に貢献します$b$、このコラムは次のように貢献しています。$$a-b.$$多重度を保存します。 

---

 ##`F(rem,p,q,carry)`コアメモ化DP。 

状態の意味:

 -`rem`残りの数字文字の予算、
 -`p,q`アクティブな番号、
 -`carry`小数桁上げ。 

各ステップで:

 1. 続く数字を選択します。 
2. すべての列の違いを列挙します。 
3. 割り算を強制する$10$、
 4. 再帰する。
