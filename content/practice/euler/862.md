[プロジェクト オイラー問題 862](https://projecteuler.net/problem=862)

 ## 解決策

 **答え:**`6111397420935766740`a の複数の桁の集合を$k$-桁の数字$n$修正されます。 数字と仮定します$d$表示されます$c_d$回、どこで$$\sum_{d=0}^9 c_d = k.$$この桁マルチ​​セットを使用して、すべての数値の寄与を計算したいと考えています。$S(k)$。 

## 1. 数学的分析

 特定の複数の数字セットに対して、次を定義します。$$P(c_0,\dots,c_9)$$**有効な数になります$k$- 形成可能な整数** (先頭のゼロなし)。 

### ステップ 1: 有効な順列を数える

 先行ゼロの制限を無視すると、個別の置換の数は次のようになります。$$\frac{k!}{\prod_{d=0}^9 c_d!}.$$もし$c_0>0$, いくつかのアレンジメントはゼロから始まります。 先頭のゼロを固定し、残りを並べ替えます$k-1$数字:$$\frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$したがって、$$P = \frac{k!}{\prod c_d!} - \frac{(k-1)!}{(c_0-1)!\prod_{d=1}^9 c_d!}.$$因数分解すると$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$---

 ### ステップ 2: 合計$T(n)$1桁以上のマルチセット

 すべての有効な置換を昇順にリストします。$$a_1 < a_2 < \cdots < a_P.$$のために$i$- 番目の番号、$$T(a_i)=P-i,$$正確には後の数字の方が大きいからです。 

したがって、このマルチセットの合計寄与度は次のようになります。$$\sum_{i=1}^{P}(P-i) = 0+1+\cdots+(P-1) = \frac{P(P-1)}{2}.$$したがって$$S(k) = \sum_{\substack{c_0+\cdots+c_9=k\\ c_d\ge 0}} \frac{P(P-1)}{2},$$どこ$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}.$$桁数ベクトルの数は$$\binom{k+9}{9},$$どちらのための$k=12$は$$\binom{21}{9}=293930,$$直接列挙できるほど小さい。

 ## 2. Python の実装```python
from math import factorial

def S(k):
    # Precompute factorials
    fact = [factorial(i) for i in range(k + 1)]

    counts = [0] * 10
    total = 0

    def dfs(digit, remaining):
        nonlocal total

        # Last digit count is forced
        if digit == 9:
            counts[9] = remaining

            # Compute denominator: product(c_i!)
            denom = 1
            for c in counts:
                denom *= fact[c]

            # Number of valid k-digit permutations
            P = (k - counts[0]) * fact[k - 1] // denom

            # Contribution of this multiset
            total += P * (P - 1) // 2
            return

        # Try all counts for this digit
        for c in range(remaining + 1):
            counts[digit] = c
            dfs(digit + 1, remaining - c)

    dfs(0, k)
    return total

# Check given example
print(S(3))   # 1701

# Required answer
print(S(12))
```---

 ## 3. コードのチュートリアル

 -`factorial(i)`値は、繰り返しの作業を避けるために事前に計算されます。 
- すべての桁数ベクトルを再帰的に列挙します$(c_0,\dots,c_9)$合計で$k$。 
- 各ベクトルについて:

 - 計算する$$\prod c_d!$$- 評価する$$P = \frac{(k-c_0)(k-1)!}{\prod c_d!}$$- 追加$$\frac{P(P-1)}{2}$$合計に。 

### 検証

 プログラムは指定された値を再現します。$$S(3)=1701.$$例としては$2302$:

 - 桁数:$c_0=1,c_2=2,c_3=1$- 有効な順列:$$P = \frac{(4-1)\cdot 3!}{1!\,2!\,1!} = 9$$したがって、このマルチセットの合計寄与度は次のようになります。$$\frac{9\cdot 8}{2}=36.$$実際、ソートされたリストにはランクがあり、$$8+7+\cdots+0=36.$$以来$2302$5番目の項目ですが、$T(2302)=4$、ステートメントと一致します。
