 ## 解決策

 **答え:**`806844323190414`させて$W(w,h)$幅の亀裂のない壁の数を示します$w$と高さ$h$。 

計算しなければなりません$W(32,10)$。 

重要な所見は次のとおりです。 

- 列は内部の垂直亀裂の位置によって完全に決まります。 
- 亀裂位置を共有しない場合、2 つの列は互換性があります。 
- したがって、問題は次のようになります。 

1. 幅の有効な行をすべて生成します。$32$、
 2. 互換性グラフを作成します。 
3. そのグラフ内の長さ 10 のパスを数えます。 

---

 # ステップ 1 — 行を表す

 レンガは$2\times1$そして$3\times1$、水平に配置されます。 

幅の列$w$の任意の構成です$w$2と3を使用します。 

幅の例$9$:

 -$2+2+2+3$-$3+3+3$-$2+3+2+2$など

 列ごとに、レンガ間の亀裂の位置を記録します。 

例：$$2+3+2+2$$累積合計がある$$2,5,7,9$$壁のエッジを無視する$9$、クラックセットは$$\{2,5,7\}$$亀裂セットが互いに素であれば、2 つの行は互換性があります。 

---

 # ステップ 2 — 可能な行数

 しましょう$R(w)$幅の行数になります$w$。 

それから$$R(w)=R(w-2)+R(w-3)$$と：$$R(0)=1,\quad R(1)=0,\quad R(2)=1,\quad R(3)=1$$のために$w=32$、これにより次の結果が得られます。$$R(32)=3329$$したがって、行タイプは 3329 個のみであり、グラフ メソッドとしては十分な小ささです。 

---

 # ステップ 3 — 互換性グラフ

 グラフを作成します。 

- 各ノード = 1 つの行パターン、
 - 亀裂が揃っていない場合はノード間のエッジ。 

行の場合$i$行と互換性があります$j$、その後、連続して積み重ねることができます。 

ここで、高さ 10 のスタックの数が必要になります。 

これは、長さの歩行を数えるのと同じです$9$互換性グラフで。 

---

 # ステップ 4 — 動的プログラミング

 しましょう:$$dp_k(i)$$亀裂のない高さの壁の数になります$k$行で終わる$i$。 

初期化:$$dp_1(i)=1$$それから：$$dp_{k+1}(j)=\sum_{i\sim j} dp_k(i)$$どこ$i\sim j$互換性があるという意味です。 

ついに：$$W(32,10)=\sum_i dp_{10}(i)$$---

 # Pythonの実装```python
from collections import defaultdict

WIDTH = 32
HEIGHT = 10

# ---------------------------------------------------------
# Generate all possible rows
# Each row is represented by a tuple of crack positions
# ---------------------------------------------------------

rows = []

def build(pos, cracks):
    """
    Recursively build rows of total width WIDTH.

    pos     = current filled width
    cracks  = crack positions so far
    """
    if pos == WIDTH:
        rows.append(tuple(cracks))
        return

    # place a 2-brick
    if pos + 2 <= WIDTH:
        new_pos = pos + 2
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

    # place a 3-brick
    if pos + 3 <= WIDTH:
        new_pos = pos + 3
        build(
            new_pos,
            cracks + ([new_pos] if new_pos < WIDTH else [])
        )

build(0, [])

# ---------------------------------------------------------
# Build compatibility graph
# Two rows are compatible if they share no cracks
# ---------------------------------------------------------

n = len(rows)

compat = [[] for _ in range(n)]

crack_sets = [set(r) for r in rows]

for i in range(n):
    for j in range(i + 1, n):
        if crack_sets[i].isdisjoint(crack_sets[j]):
            compat[i].append(j)
            compat[j].append(i)

# ---------------------------------------------------------
# DP over wall height
# dp[i] = number of ways ending with row i
# ---------------------------------------------------------

dp = [1] * n   # height = 1

for _ in range(HEIGHT - 1):
    new_dp = [0] * n

    for i in range(n):
        for j in compat[i]:
            new_dp[j] += dp[i]

    dp = new_dp

answer = sum(dp)

print(answer)
```---

 ## 動的プログラミング

 最初はすべての行を最初のレイヤーにすることができます。```python
dp = [1] * n
```追加の各レイヤーについて:```python

```いつでも行$i$そして$j$互換性があります。 

10 層を重ねた後、すべての可能性を合計すると答えが得られます。
