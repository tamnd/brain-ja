 ## 解決策

 **答え:**`810834388`楕円をその中心を中心とする座標で記述することにします。 

与えられたデータは、

 -$M=(-2000,1500)$-$G=(8000,1500)$- 円の半径$r=15000$間の距離$M$そして$G$は$$|MG|=10000.$$---

 #1. 楕円の導出

 ポイントとしては$P$、円までの距離は$$PM-r.$$楕円は次のように定義されます。$$PG = PM-r.$$したがって、$$PG+ r = PM.$$したがって、2 つの焦点までの距離の合計は一定です。$$PG+PM = 15000.$$したがって、楕円は次のようになります。$$2a=15000 \quad\Rightarrow\quad a=7500.$$焦点距離は$$2c=10000 \quad\Rightarrow\quad c=5000.$$したがって$$b^2=a^2-c^2 =7500^2-5000^2 =56\,250\,000-25\,000\,000 =31\,250\,000.$$中心は$$\left(\frac{-2000+8000}{2},1500\right)=(3000,1500).$$シフトされた座標の使用$$x=X-3000,\qquad y=Y-1500,$$楕円方程式は次のようになります$$\frac{x^2}{56\,250\,000}+\frac{y^2}{31\,250\,000}=1.$$---

 #2. 外部点からの接線

 外側の点を考慮する$P=(x_0,y_0)$。 

通る線$P$傾斜あり$m$は$$y=m(x-x_0)+y_0.$$として書くと$$y=mx+c, \qquad c=y_0-mx_0,$$この線は楕円に接します (ただし、$$c^2=a^2m^2+b^2.$$置き換える$c=y_0-mx_0$:$$(y_0-mx_0)^2=a^2m^2+b^2.$$これにより、接線の傾きに関する二次方程式が得られます。$$(x_0^2-a^2)m^2-2x_0y_0m+(y_0^2-b^2)=0.$$2 つの接線の傾きを次のようにします。$m_1,m_2$。 

角度$\theta=\angle RPS$接線間が満たされる$$\tan\theta = \left| \frac{m_1-m_2}{1+m_1m_2} \right|.$$Vieta の公式を使用して単純化すると、$$\tan^2\theta = \frac{ 4\left(b^2x_0^2+a^2y_0^2-a^2b^2\right) }{ \left(a^2+b^2-x_0^2-y_0^2\right)^2 }.$$必要です$$\theta>45^\circ \quad\Longleftrightarrow\quad \tan^2\theta>1.$$したがって$$4(b^2x^2+a^2y^2-a^2b^2) > (a^2+b^2-x^2-y^2)^2.$$置き換える$$a^2=56\,250\,000, \qquad b^2=31\,250\,000,$$そして簡略化すると：$$x^4+2x^2y^2+y^4 -300\,000\,000x^2 -400\,000\,000y^2 +14\,687\,500\,000\,000\,000 <0.$$この不等式を満たし、楕円の外側にある格子点を数えなければなりません$$\frac{x^2}{56\,250\,000} + \frac{y^2}{31\,250\,000} >1.$$---

 #3. 効率的な計数

 固定用$x$、不等式は 2 次です。$y^2$。 

させて$z=y^2$。 それから$$z^2+(2x^2-400000000)z + x^4-300000000x^2+14687500000000000 <0.$$それで$z$は厳密に 2 つのルートの間にあります。$$z_\pm = 200000000-x^2 \pm 10000\sqrt{253125000-x^2}.$$したがって、各整数に対して$x$、有効な整数$y$満足する$$z_-<y^2<z_+,$$楕円の外側の条件と合わせて。

 #4. Pythonの実装```python
import math

# Ellipse parameters
a2 = 56_250_000
b2 = 31_250_000

def valid(x, y):
    x2 = x * x
    y2 = y * y

    # angle > 45 degrees
    lhs = 4 * (b2 * x2 + a2 * y2 - a2 * b2)
    rhs = (a2 + b2 - x2 - y2) ** 2

    # outside ellipse
    outside = (x2 / a2 + y2 / b2) > 1

    return lhs > rhs and outside

total = 0

# x-range comes from discriminant >= 0
for x in range(0, 15911):

    x2 = x * x
    d = 253_125_000 - x2

    if d <= 0:
        continue

    A = 200_000_000 - x2
    B = 10_000 * math.sqrt(d)

    low = A - B
    high = A + B

    if high <= 0:
        continue

    # approximate y-range
    ymin = max(0, int(math.sqrt(max(low, 0))) - 5)

    # move upward until valid
    while True:
        y2 = ymin * ymin
        if y2 > low and (5 * x2 + 9 * y2 > 281_250_000):
            break
        ymin += 1

    ymax = int(math.sqrt(high)) + 5

    # move downward until valid
    while ymax >= ymin and not valid(x, ymax):
        ymax -= 1

    count = max(0, ymax - ymin + 1)

    # symmetry in all four quadrants
    if x == 0:
        total += 2 * count
    else:
        total += 4 * count

print(total)
