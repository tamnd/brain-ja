 # ステップ 1 — 条件グラフを理論的に解釈する

 64 の状態に関する有向グラフを次のように定義します。$$x\to T(x).$$以来$T$可逆的 (線形フィードバック シフト レジスタ タイプの変換です)、すべてのノードに次数があります。$1$と出次数$1$。 したがって、グラフは互いに素な有向サイクルに分解されます。 

各エッジについて$x\to T(x)$、条件には次のように書かれています。$$(\tau(x),\tau(T(x)))\neq (1,1).$$したがって、サイクルごとに次のことを割り当てる必要があります。$0/1$隣接する頂点の両方が存在しないようなラベル$1$。 

したがって:

 - 各サイクルは独立して貢献し、
 - そして一定の長さのサイクルについて$n$、有効な代入の数は、長さのバイナリ循環文字列の数です。$n$隣接しない$1$さんの。 

その量はよく知られています。$$N(n)=F_{n-1}+F_{n+1},$$どこ$F_n$フィボナッチ数です。 

(同様に、これはルーカス番号です)$L_n$。）

 したがって、問題は次のようになります。 

1. のサイクル分解を求めます。$T$、
 2. 対応するルーカス数を掛けます。

 # ステップ 3 — 循環棚卸計算式が正しい理由

 一定の長さのサイクルの場合$n$、バイナリラベルを次のようにします$$x_1,x_2,\dots,x_n,$$インデックス巡回モジュロ付き$n$。 

制約は$$x_i x_{i+1}=0.$$連続を避けるバイナリ循環文字列の数$1$に等しい$$F_{n-1}+F_{n+1}.$$簡単な導出:

 - 長さの線形文字列$m$隣接しない$1$は次のように数えられます$F_{m+2}$、
 - 循環文字列の場合:

 - どちらかの最初のビットは$0$:$F_{n+1}$、
 - または最初のビットは$1$: 隣人が強制的に$0$、出発$F_{n-1}$、
 - 与える$$F_{n+1}+F_{n-1}.$$---

 # ステップ 4 — Python の実装```python
from collections import defaultdict

# ---------------------------------------------------------
# Transformation T on 6-bit states
# ---------------------------------------------------------

def T(x):
    """
    x is an integer from 0..63 representing bits abcdef.
    Returns T(x).
    """

    # Extract bits
    a = (x >> 5) & 1
    b = (x >> 4) & 1
    c = (x >> 3) & 1
    d = (x >> 2) & 1
    e = (x >> 1) & 1
    f = x & 1

    # New last bit
    g = a ^ (b & c)

    # Shift left
    y = (b << 5) | (c << 4) | (d << 3) | (e << 2) | (f << 1) | g

    return y

# ---------------------------------------------------------
# Find cycle decomposition
# ---------------------------------------------------------

visited = [False] * 64
cycle_lengths = []

for start in range(64):

    if visited[start]:
        continue

    cur = start
    cycle = []

    while not visited[cur]:
        visited[cur] = True
        cycle.append(cur)
        cur = T(cur)

    cycle_lengths.append(len(cycle))

print(sorted(cycle_lengths))

# ---------------------------------------------------------
# Fibonacci / Lucas
# ---------------------------------------------------------

def fibonacci(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

def lucas(n):
    return fibonacci(n - 1) + fibonacci(n + 1)

# ---------------------------------------------------------
# Compute total count
# ---------------------------------------------------------

answer = 1

for n in cycle_lengths:
    answer *= lucas(n)

print(answer)
```---
