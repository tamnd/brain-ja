[プロジェクト オイラー問題 131](https://projecteuler.net/problem=131)

 ## 解決策

 **答え:**`173`私たちは素数を求めます$p$正の整数が存在するように$n$と$$n^3+n^2p$$完璧な立方体であること。 

私たちはそう言われています$p=19$、$$8^3+8^2\cdot 19=12^3.$$このような素数がいくつあるか数えなければなりません$p<10^6$。 

---

 # ステップ 1 — 代数解析

 整数が必要です$n,m>0$満足のいく$$n^3+n^2p=m^3.$$左辺を因数分解します。$$n^2(n+p)=m^3.$$それで$$m^3=n^2(n+p).$$次に、この方程式の構造を分析します。 

---

 ## キーの置換

 しましょう$$m = nk$$ある意味合理的な$k$。 代入:$$n^3k^3=n^2(n+p).$$キャンセル$n^2$:$$nk^3=n+p.$$したがって、$$p=n(k^3-1).$$以来$p$が素数であるため、これは非常に制限的です。 

要素：$$k^3-1=(k-1)(k^2+k+1).$$したがって$$p=n(k-1)(k^2+k+1).$$なぜなら$p$プライムであり、$n\ge1$、1 つを除くすべての要素が等しくなければなりません$1$。 

したがって必然的に:$$n=k-1=1.$$ただし、共素性を使用して導出する方がクリーンです。 

---

 # ステップ 2 — 標準導出

 書く$$m^3-n^3=n^2p.$$立方体の差を因数分解する：$$(m-n)(m^2+mn+n^2)=n^2p.$$さあ、みましょう$$m-n=d.$$それから$m=n+d$。 2 番目の要素に代入します。$$m^2+mn+n^2 =(n+d)^2+n(n+d)+n^2.$$拡張:$$=3n^2+3nd+d^2.$$したがって$$d(3n^2+3nd+d^2)=n^2p.$$重要な観察:$$\gcd(d,n)=1.$$確かに、数値が両方を割る場合、$d=m-n$そして$n$、それは分割します$m$したがって、の両側を分割します$$m^3-n^3=n^2p,$$gcd が一致しない限り、矛盾を強制します。$1$。 

以来$d\mid n^2p$そして$\gcd(d,n)=1$、私たちは持っている必要があります$$d\mid p.$$なぜなら$p$プライムであり、$d>0$、$$d=1 \quad \text{or} \quad d=p.$$もし$d=p$、 それから$$p(3n^2+3np+p^2)=n^2p,$$それは意味します$$3n^2+3np+p^2=n^2,$$不可能。 

したがって、$$d=1.$$それで$$m=n+1.$$交代でバック:$$(n+1)^3-n^3=n^2p.$$拡大する：$$3n^2+3n+1=n^2p.$$しかし、意図した再配置は、元の方程式から直接行う方が簡単です。$$n^3+n^2p=(n+1)^3.$$したがって$$n^2p=(n+1)^3-n^3.$$差を計算します。$$(n+1)^3-n^3=3n^2+3n+1.$$したがって$$p=\frac{3n^2+3n+1}{n^2}.$$これは一般に整数ではないと思われるため、より明確なパラメータ化が必要です。 

---

 # ステップ 3 — 正しいパラメータ化

 しましょう$$m=n+k.$$それから$$m^3-n^3 =3n^2k+3nk^2+k^3.$$これは等しいので、$n^2p$、$$n^2p = k(3n^2+3nk+k^2).$$また$\gcd(n,k)=1$、 それで$k\mid p$。 以来$p$プライムです、$$k=p.$$それから$$n^2 = 3n^2+3np+p^2,$$代わりにそうしない限り不可能$$k=1.$$したがって$$m=n+1.$$ここで慎重に置き換えます。$$(n+1)^3=n^3+n^2p.$$拡大する：$$n^3+3n^2+3n+1=n^3+n^2p.$$したがって、$$p=\frac{3n^2+3n+1}{n^2}.$$これもまた間違っているように見えます。$p=19$で動作します$n=8$。 確認してみましょう:$$\frac{3(64)+24+1}{64}=\frac{217}{64}.$$したがって、私たちの仮定は$m=n+1$は誤りです。 

きれいに再起動しましょう。 

---

 # ステップ 4 — エレガントな因数分解

 から$$n^3+n^2p=m^3,$$で割る$n^3$:$$1+\frac{p}{n}=\left(\frac{m}{n}\right)^3.$$させて$$\frac{m}{n}=\frac{a}{b}$$最低の言葉で。 それから$$1+\frac{p}{n}=\frac{a^3}{b^3}.$$再配置:$$\frac{p}{n}=\frac{a^3-b^3}{b^3}.$$したがって$$pb^3=n(a^3-b^3).$$以来$a,b$互いに素であり、$$a^3-b^3=(a-b)(a^2+ab+b^2).$$のために$p$素数になる唯一の可能性は$$a-b=1.$$セット$$a=b+1.$$それから$$a^3-b^3 =(b+1)^3-b^3 =3b^2+3b+1.$$したがって$$p=3b^2+3b+1.$$これが重要な結果です。 

確かに、$b=2$:$$p=3(4)+6+1=19.$$そして、例は次のようになります$$n=b^3=8,\qquad m=a^3=27 \Rightarrow m=12,$$完璧に一致して以来$$8^3+8^2\cdot19=12^3.$$したがって、問題は次のようになります。

 # ステップ 5 — バインド$b$必要です$$3b^2+3b+1<10^6.$$近似：$$3b^2<10^6 \Rightarrow b<577.35.$$したがって、テストするだけです$b=1,\dots,576$。

 # Pythonの実装```python
from math import isqrt

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    
    limit = isqrt(n)
    d = 3
    
    while d <= limit:
        if n % d == 0:
            return False
        d += 2
    
    return True

count = 0
values = []

b = 1

while True:
    p = 3*b*b + 3*b + 1
    
    if p >= 1_000_000:
        break
    
    if is_prime(p):
        count += 1
        values.append(p)
    
    b += 1

print(count)
```---
