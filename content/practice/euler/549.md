[プロジェクト オイラー問題 549](https://projecteuler.net/problem=549)

 ## 解決策

 **答え:**`476001479068717`正の整数の場合$n$、 定義する$s(n)$最小の整数として$m$そのような$$n \mid m!.$$計算しなければなりません$$S(10^8)=\sum_{n=2}^{10^8} s(n).$$重要なのは理解することです$s(n)$素因数分解を通じて。 

---

 #1. 数学的分析

 仮定してください$$n=\prod p_i^{a_i}.$$それから$n\mid m!$すべての素数乗についての場合$p_i^{a_i}$、$$v_{p_i}(m!)\ge a_i,$$どこ$v_p(x)$の指数です$p$で$x$。 

したがって：$$s(n)=\max_i s(p_i^{a_i}),$$したがって、問題全体は素数累乗に帰着します。 

---

 ## プライムパワー

 固定素数の場合$p$、 定義する：$$f(p,a)=s(p^a).$$最小のものが必要です$m$そのような$$v_p(m!)\ge a.$$ルジャンドルの公式によると、$v_p(m!)=\sum_{k\ge1}\left\lfloor\frac{m}{p^k}\right\rfloor$それで$f(p,a)$最小限です$m$この不等式を満たすこと。 

例:

 -$f(5,1)=5$-$f(5,2)=10$なぜなら$10!$ちょうど 2 つの要素が含まれています$5$---

 ## すべてを計算する$s(n)$あらゆるプライムパワーに対して$q=p^a\le N$:

 1. コンピューティング$m=f(p,a)$2. の倍数ごと$q$満たさなければなりません$s(k)\ge m$したがって、次のようにふるいにかけることはできます。$$s(k)=\max(s(k),\,f(p,a)) \quad\text{for all }k\equiv0\pmod{p^a}.$$これはプライムシーブと非常によく似ています。 

全体の複雑さはおよそ$$N\sum_{p^a\le N}\frac1{p^a},$$これは十分に速いです$N=10^8$最適化されたコードで。 

---

 #2. Pythonの実装```python
from math import isqrt

N = 10**8

# ------------------------------------------------------------
# Legendre valuation: exponent of prime p inside m!
# ------------------------------------------------------------
def vp_fact(m, p):
    s = 0
    while m:
        m //= p
        s += m
    return s

# ------------------------------------------------------------
# Smallest m such that v_p(m!) >= a
# ------------------------------------------------------------
def min_m(p, a):
    lo, hi = 1, p * a

    while lo < hi:
        mid = (lo + hi) // 2

        if vp_fact(mid, p) >= a:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# Sieve primes up to N
# ------------------------------------------------------------
is_comp = bytearray(N + 1)
primes = []

for i in range(2, N + 1):
    if not is_comp[i]:
        primes.append(i)

        if i <= isqrt(N):
            step = i
            start = i * i
            for j in range(start, N + 1, step):
                is_comp[j] = 1

# ------------------------------------------------------------
# Compute s(n) for all n <= N
# ------------------------------------------------------------
s = [0] * (N + 1)

for p in primes:

    power = p
    a = 1

    while power <= N:

        m = min_m(p, a)

        # every multiple of p^a needs at least m
        for k in range(power, N + 1, power):
            if s[k] < m:
                s[k] = m

        if power > N // p:
            break

        power *= p
        a += 1

# ------------------------------------------------------------
# Sum all values
# ------------------------------------------------------------
answer = sum(s[2:])
print(answer)
```---
