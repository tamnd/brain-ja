[プロジェクト オイラー問題 658](https://projecteuler.net/problem=658)

 ## 解決策

 **答え:**`958280177`させて$$I(\alpha,n)=\#\{\text{incomplete words over an alphabet of size }\alpha\text{ with length }\le n\}.$$私たちが欲しいのは$$S(k,n)=\sum_{\alpha=1}^k I(\alpha,n)$$のために$k=10^7,\ n=10^{12}$、モジュロ$M=10^9+7$。 

---

 ## 1. 不完全な単語を数える

 サイズのアルファベットを修正する$\alpha$。 

固定長の場合$m$、総単語数は$\alpha^m$。 

すべての文字が少なくとも 1 回出現すれば、単語は完成します。 包含と除外により、$$\#\{\text{complete words of length }m\} = \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$したがって、長さの不完全な単語の数は$m$は$$\alpha^m- \sum_{j=0}^{\alpha}(-1)^j\binom{\alpha}{j}(\alpha-j)^m.$$簡略化した後、$$\#\{\text{incomplete words of length }m\} = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$したがって、$$I(\alpha,n) = \sum_{m=0}^{n} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}j^m.$$合計を交換します。$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j} \sum_{m=0}^{n}j^m.$$定義する$$G_n(j)=\sum_{m=0}^{n}j^m.$$それから$$I(\alpha,n) = \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$---

 ## 2. すべてのアルファベットのサイズを合計する

 合計してください$\alpha\le k$:$$S(k,n) = \sum_{\alpha=1}^{k} \sum_{j=0}^{\alpha-1} (-1)^{\alpha-j+1}\binom{\alpha}{j}G_n(j).$$もう一度順序を入れ替えます。$$S(k,n) = \sum_{j=0}^{k-1} G_n(j) \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$定義する$$c_{k,j} = \sum_{\alpha=j+1}^{k} (-1)^{\alpha-j+1}\binom{\alpha}{j}.$$生成関数を使用すると、次のようになります。$$\sum_{j\ge0} c_{k,j}x^j = \frac{1+(-1)^{k+1}(1-x)^{k+2}} {(1-x)(2-x)}.$$これにより、係数の線形再帰が得られます。$c_{k,j}$ですべての係数を生成できるようになります。$O(k)$。 

また、$$G_n(j)= \begin{cases} n+1,& j=1,\\[4pt] \dfrac{j^{n+1}-1}{j-1},& j\ne1. \end{cases}$$以来$n=10^{12}$、各べき乗は高速べき乗剰余演算で計算されます。 

完全なアルゴリズムは以下で実行されます。$O(k\log n)$、実現可能$k=10^7$。 

---

 ## 3. Python の実装```python
MOD = 10**9 + 7

def solve(k, n):
    inv = [1] * (k + 3)
    inv[1] = 1
    for i in range(2, k + 3):
        inv[i] = MOD - (MOD // i) * inv[MOD % i] % MOD

    # coefficients c_j generated from
    # (2 - x)C(x) = 1 + (-1)^(k+1)(1-x)^(k+2)

    c = [0] * (k + 1)

    sign = -1 if (k + 1) & 1 else 1

    # constant term
    rhs0 = 1 + sign
    c[0] = rhs0 * inv[2] % MOD

    # recurrence:
    # 2*c_j - c_{j-1} = sign * (-1)^j * C(k+2, j)

    comb = 1

    for j in range(1, k):
        comb = comb * (k + 3 - j) % MOD
        comb = comb * inv[j] % MOD

        rhs = comb
        if (j & 1):
            rhs = MOD - rhs

        if sign == -1:
            rhs = MOD - rhs

        c[j] = (c[j - 1] + rhs) * inv[2] % MOD

    ans = 0

    for j in range(k):
        coeff = c[j]

        if j == 0:
            g = 1
        elif j == 1:
            g = (n + 1) % MOD
        else:
            g = (pow(j, n + 1, MOD) - 1) % MOD
            g = g * inv[j - 1] % MOD

        ans = (ans + coeff * g) % MOD

    return ans

print(solve(10**7, 10**12))
```---
