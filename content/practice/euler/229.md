 ## 解決策

 **答え:**`11325263`させて$$\begin{aligned} n&=x_1^2+y_1^2\\ n&=x_2^2+2y_2^2\\ n&=x_3^2+3y_3^2\\ n&=x_7^2+7y_7^2 \end{aligned}$$すべての変数は正の整数です。 

整数の数を求めます$n\le 2\cdot 10^9$**4 つすべて**の条件を満たしていること。 

---

 #1. 数学的分析

 重要なのは、2 進二次形式で表される素数の古典的な特性評価を使用することです。 

プライムの場合$p\nmid 42$:

 -$p=x^2+y^2\iff p\equiv 1\pmod 4$-$p=x^2+2y^2\iff p\equiv 1,3\pmod 8$-$p=x^2+3y^2\iff p\equiv 1\pmod 3$-$p=x^2+7y^2\iff \left(\frac{-7}{p}\right)=1$すべての合同条件を組み合わせると、正確に 3 つの剰余クラスが得られます。$$\operatorname{lcm}(4,8,3,7)=168:$$

$$p\equiv 1,\ 25,\ 121 \pmod{168}.$$したがって、奇数の指数に現れる可能性がある唯一の奇数素数は、それらの剰余クラスの素数です。 

同様に、もし$$n=\prod p_i^{e_i},$$次に、集合の外側のすべての素数$$\mathcal P=\{p:\ p\equiv 1,25,121\pmod{168}\}$$偶数の指数で発生する必要があります。 

Hence every admissible$n$次のように一意に書くことができます$$n=d\,m^2,$$どこ$d$は自由平方根とすべての素数除算です$d$にある$\mathcal P$。 

したがって、計数の問題は次のようになります$$\sum_{\substack{d\le N\\ d\text{ squarefree}\\ p\mid d\Rightarrow p\in\mathcal P}} \left\lfloor \sqrt{\frac{N}{d}} \right\rfloor .$$残りの作業は純粋に計算です。

 #2. Pythonの実装```python
from math import isqrt
from sympy import primerange

LIMIT = 2_000_000_000

# primes allowed to occur to odd exponent
good_primes = [
    p for p in primerange(2, LIMIT + 1)
    if p % 168 in (1, 25, 121)
]

# generate all squarefree products of good primes <= LIMIT
squarefree = []

def dfs(start, current):
    squarefree.append(current)

    for i in range(start, len(good_primes)):
        p = good_primes[i]

        if current * p > LIMIT:
            break

        dfs(i + 1, current * p)

dfs(0, 1)

# count all numbers n = d * m^2
answer = 0

for d in squarefree:
    answer += isqrt(LIMIT // d)

# remove d = 1 (pure squares with no allowed odd prime factor)
answer -= isqrt(LIMIT)

print(answer)
```---
