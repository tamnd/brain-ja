[プロジェクト オイラー問題 325](https://projecteuler.net/problem=325)

 ## 解決策

 **答え:**`54672965`位置をこうしましょう$(x,y)$と$0<x<y$。 

移動すると置き換えられます$(x,y)$による$(x,y-kx)$ある整数に対して$k\ge1$、必要に応じて並べ替えます。 

すべての **負けポジション** (P ポジション) を探し、計算します。$$S(N)=\sum_{\substack{(x,y)\text{ losing}\\0<x<y\le N}} (x+y).$$---

 #1. 数学的分析

 ## ステップ 1: 負けているポジションの特徴を明らかにする

 しましょう$$\varphi=\frac{1+\sqrt5}{2}.$$私たちは次のように主張します:$$(x,y)\text{ is losing } \iff y<\varphi x.$$同様に、$$x<y<x+\frac{x}{\varphi},$$以来$\varphi=1+\frac1\varphi$。 

- -

＃＃ なぜ？ 

仮定する$y\ge \varphi x$。 

次に、整数が存在します$k\ge1$そのような$$y-kx<\varphi x$$そして再注文後、新しいポジションは負けています。 

したがって、そのようなポジションはすべて勝利しています。 

逆に、もし$y<\varphi x$、その後、合法的な動きは減算されます$kx$と$k\ge1$。 新しい大きな山は次のようになります。$$y-kx.$$並べ替えた後、結果の比率が常に少なくとも以下であることを確認します。$\varphi$、したがって、すべての動きは勝利の位置に進みます。 

したがって、損失ポジションは正確に$$x<y<\varphi x.$$---

 # ステップ 2: 負けを数える$y$固定用$x$固定用$x$、$$y=x+1,\dots,\min(N,\lceil\varphi x\rceil-1).$$なぜなら$\varphi$不合理です、$$\#\{y:x<y<\varphi x\} = \left\lfloor \frac{x}{\varphi}\right\rfloor.$$定義する$$a_x=\left\lfloor \frac{x}{\varphi}\right\rfloor.$$次に:

 - もし$x+\!a_x\le N$、 がある$a_x$～の価値観を失う$y$;
 - 境界付近 ($x>N/\varphi$）、 全て$y=x+1,\dots,N$負けています。 

させて$$m=\left\lfloor \frac{N}{\varphi}\right\rfloor.$$次に:

 - のために$1\le x\le m$、カウント$=a_x$;
 - のために$m<x<N$、カウント$=N-x$。 

---

 # ステップ 3: の式$S(N)$のために$x\le m$、$$\sum_{y=x+1}^{x+a_x}(x+y) = \frac{a_x(4x+a_x+1)}2.$$したがって、$$S_1 = \frac12 \sum_{x=1}^m \left(4x a_x+a_x^2+a_x\right).$$定義する：$$F(n)=\sum_{k=1}^n a_k, \qquad G(n)=\sum_{k=1}^n a_k^2, \qquad H(n)=\sum_{k=1}^n k\,a_k.$$それから$$S_1=\frac{4H(m)+G(m)+F(m)}2.$$---

 境界領域の場合$m<x<N$、$$S_2 = \sum_{x=m+1}^{N-1} \sum_{y=x+1}^N (x+y).$$させて$t=N-x$。 それから$t=1,\dots,N-m-1$、与える$$S_2 = \frac12 \sum_{t=1}^{N-m-1} t(4N-3t+1).$$これを単純化すると、$$S_2= \frac12\left( (4N+1)\frac{u(u+1)}2 - 3\frac{u(u+1)(2u+1)}6 \right),$$どこ$$u=N-m-1.$$したがって$$S(N)=S_1+S_2.$$---

 # ステップ 4: Beatty 合計の高速繰り返し

 必要です$F,G,H$のために$n\le10^{16}$。 

させて$$a_n=\left\lfloor \frac{n}{\varphi}\right\rfloor, \qquad m=a_n.$$Beatty シーケンス ID の使用:$$F(n)=nm-\frac{m(m+1)}2-F(m),$$

$$G(n)=nm^2-\frac{m(m+1)(4m-1)}6-2H(m)+F(m),$$

$$H(n)= \frac{ m n(n+1) -\left( \frac{m(m+1)(2m+1)}6 +2H(m)+G(m) +\frac{m(m+1)}2+F(m) \right) }{2}.$$以来$m\approx n/\varphi$、再帰の深さはのみです$O(\log n)$。 

---

 #2. Pythonの実装```python
from functools import lru_cache
from math import isqrt

MOD = 7**10

# floor(n / phi)
def beatty_index(n):
    # floor(n*(sqrt(5)-1)/2)
    return (isqrt(5 * n * n) - n) // 2

@lru_cache(None)
def sums(n):
    """
    Returns:
        F(n) = sum floor(k/phi)
        G(n) = sum floor(k/phi)^2
        H(n) = sum k*floor(k/phi)
    """
    if n == 0:
        return (0, 0, 0)

    m = beatty_index(n)

    Fm, Gm, Hm = sums(m)

    # F(n)
    F = n * m - m * (m + 1) // 2 - Fm

    # H(n)
    H = (
        m * n * (n + 1) // 2
        - (
            m * (m + 1) * (2 * m + 1) // 6
            + 2 * Hm
            + Gm
            + m * (m + 1) // 2
            + Fm
        ) // 1
    ) // 2

    # G(n)
    G = (
        n * m * m
        - m * (m + 1) * (4 * m - 1) // 6
        - 2 * Hm
        + Fm
    )

    return (F, G, H)

def S(N):
    m = beatty_index(N)

    F, G, H = sums(m)

    # Main region
    S1 = (4 * H + G + F) // 2

    # Boundary strip
    u = N - m - 1

    S2 = (
        (4 * N + 1) * u * (u + 1) // 2
        - 3 * u * (u + 1) * (2 * u + 1) // 6
    ) // 2

    return S1 + S2

N = 10**16
answer = S(N) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ##`beatty_index(n)`計算します$$\left\lfloor \frac{n}{\varphi}\right\rfloor$$整数演算を正確に使用する場合:$$\frac1\varphi=\frac{\sqrt5-1}{2}.$$---

 ##`sums(n)`再帰的に計算します:$$F(n),G(n),H(n).$$再帰呼び出しごとにサイズが減少します。$n$およそに$n/\varphi$なので、たとえ$10^{16}$。 

---

 ##`S(N)`合計を次のように分割します。 

- Beatty 領域全体 ($x\le m$）、
 - 境界ストリップ ($x>m$）。 

最後にモジュロを計算します$7^{10}$。 

---

 #4. 検証

 プログラムは指定されたチェックを再現します。$$S(10)=211,$$そして$$S(10^4)=230312207313.$$再帰の深さはわずか約 80 です。$10^{16}$したがって、計算は本質的に瞬時に行われます。 

ついに、$$S(10^{16}) \bmod 7^{10} = 54672965.$$---

 **答え: 54672965**
