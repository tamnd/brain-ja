[プロジェクト オイラー問題 352](https://projecteuler.net/problem=352)

 ## 解決策

 **答え:**`378563.260589`させて$p$を各羊の感染確率とし、$$q = 1-p.$$最適な予想されるテスト数を計算する必要があります$T(s,p)$のために$s=10000$、合計$$p=0.01,0.02,\dots,0.50.$$重要な問題は、プールされた検査で陽性反応が出た後、情報が得られることです。つまり、そのプール内の**少なくとも 1 頭**の羊が感染していることがわかっているということです。 

この条件情報により、最適な継続戦略が変わります。 

---

 #1. 数学的分析

 2 つの DP 関数を定義します。 

---

 ## A.$T(n)$

$T(n)$= 完全に分類するために必要なテストの予想最小数$n$各羊が確率で独立して感染する場合$p$。 

---

 ## B.$C(n)$

$C(n)$= 分類に必要な**追加**テストの予想最小数$n$羊 **少なくとも 1 頭が感染していることがすでにわかっていることを前提としています**。 

明らかに、$$C(1)=0$$なぜなら、一頭の羊が陽性プールに属していることがわかっている場合、その羊は感染しているはずだからです。 

また、$$T(0)=0,\qquad T(1)=1.$$---

 #2. 再発$T(n)$最初のアクションが次のとおりであるとします。 

- サイズのグループを選択します$m$、
 - それらに対してプールされたテストを 1 つ実行します$m$羊。 

### ケース 1: プールされた検査陰性

 確率:$$q^m.$$それから全部$m$羊はきれいですが、まだ残っている羊を処理する必要があります$n-m$羊：$$T(n-m).$$### ケース 2: プールされた検査陽性

 確率:$$1-q^m.$$今、私たちはそれらを完全に解決しなければなりません$m$少なくとも1頭が感染していることを知っている羊:$$C(m),$$そして残りを処理します$n-m$:$$T(n-m).$$プールされたテスト自体を含む:$$T(n) = \min_{1\le m\le n} \left[ 1 + T(n-m) + (1-q^m)C(m) \right].$$---

 #3. 再発$C(n)$ここで次のように仮定します。 

- 私たちはすでにこれらのことを知っています$n$羊、
 - 少なくとも 1 人が感染しています。 

サイズのサブグループを分割します$m$そしてそれをテストしてください。 

---

 ## 条件付き確率

 グループ全体が陽性であるのに、テストされたサブグループが陰性である確率:$$\frac{q^m-q^n}{1-q^n}.$$なぜ？ 

- サブグループ陰性:$q^m$、
- 全て$n$ネガティブ：$q^n$、
 - 不可能なオーバーラップを減算します。 

同様に、サブグループ検定が陽性である確率は次のようになります。$$\frac{1-q^m}{1-q^n}.$$---

 ## サブグループが負の場合

 次に:

 - サブグループは完全に解決されています。 
- 残り$n-m$羊にはまだ少なくとも 1 頭の感染した羊が含まれています。 

料金：$$C(n-m).$$---

 ## サブグループが陽性の場合

 次に:

 - サブグループに必要なもの$C(m)$、
 - 残りの羊は再び無条件になり、コストがかかります$T(n-m)$。 

---

 テスト自体も含めて:$$C(n) = \min_{1\le m<n} \left[ 1 + \frac{q^m-q^n}{1-q^n}C(n-m) + \frac{1-q^m}{1-q^n}\left(C(m)+T(n-m)\right) \right].$$これら 2 つの反復により、最適なものが完全に決まります。 

---

 #4. Pythonの実装```python
from math import inf

def optimal_tests(p, nmax):
    q = 1.0 - p

    # T[n] = optimal expected tests for n sheep
    T = [0.0] * (nmax + 1)

    # C[n] = optimal expected additional tests
    #        given at least one infected among n sheep
    C = [0.0] * (nmax + 1)

    T[1] = 1.0
    C[1] = 0.0

    # Empirically the optimal split sizes stay small.
    # This bound is safely above all optimal values needed.
    LIMIT = min(nmax, int(2 / p) + 50)

    for n in range(2, nmax + 1):

        # ---- Compute C[n] ----
        denom = 1.0 - q ** n
        best = inf

        upper = min(n - 1, LIMIT)

        for m in range(1, upper + 1):

            prob_negative = (q ** m - q ** n) / denom
            prob_positive = (1.0 - q ** m) / denom

            value = (
                1.0
                + prob_negative * C[n - m]
                + prob_positive * (C[m] + T[n - m])
            )

            if value < best:
                best = value

        C[n] = best

        # ---- Compute T[n] ----
        best = inf
        upper = min(n, LIMIT)

        for m in range(1, upper + 1):

            value = (
                1.0
                + T[n - m]
                + (1.0 - q ** m) * C[m]
            )

            if value < best:
                best = value

        T[n] = best

    return T[nmax]

# Verify examples
print(round(optimal_tests(0.02, 25), 6))
print(round(optimal_tests(0.10, 25), 6))

# Final computation
answer = 0.0

for k in range(1, 51):
    p = k / 100.0
    answer += optimal_tests(p, 10000)

print(f"{answer:.6f}")
```---

 #5. コードのチュートリアル

 ### 配列```python
T = [0.0] * (nmax + 1)
C = [0.0] * (nmax + 1)
```DP 値を保存します。 

---

 ### コンピューティング$C[n]$

```python
prob_negative = (q ** m - q ** n) / denom
prob_positive = (1.0 - q ** m) / denom
```これらは、グループ全体にすでに感染症が含まれていると仮定した場合の条件付き確率です。 

---

 ### コンピューティング$T[n]$

```python
value = (
    1.0
    + T[n - m]
    + (1.0 - q ** m) * C[m]
)
```これは正確に以下を実装します:$$1 + T(n-m) + (1-q^m)C(m).$$---
