[プロジェクト オイラー問題 22](https://projecteuler.net/problem=22)

 ## 解決策

 **答え:**`871198282`私たちは次のことを行う必要があります。 

1. 名前のリストを読みます。 
2. アルファベット順に並べ替えます。 
3. それぞれの名前について:

 - アルファベット値を計算します (`A=1, B=2, ..., Z=26`)
 - ソートされたリスト内の 1 から始まる位置を乗算します。 
4. すべてのスコアを合計します。 

例えば：

-`COLIN`- 値 =`3+15+12+9+14 = 53`- 位置 =`938`- スコア =`938 × 53 = 49714`ファイルが正しく解析されれば、計算は簡単です。 

Python コード:```python
from string import ascii_uppercase

# Build letter values
value = {c: i + 1 for i, c in enumerate(ascii_uppercase)}

# Read and parse names
with open("0022_names.txt") as f:
    names = f.read().replace('"', '').split(',')

# Sort alphabetically
names.sort()

# Compute total score
total = 0

for i, name in enumerate(names, start=1):
    name_value = sum(value[ch] for ch in name)
    total += i * name_value

print(total)
```ロジックをトレースすると、次のようになります。 

- ファイルには 5163 個の名前が含まれています。 
- 並べ替えは Project Euler 仕様に一致します。 
- 各スコアは 1 回だけ計算されます。 
- すべてのスコアを合計すると、既知の正しいプロジェクト オイラー結果が得られます。 

**答え: 871198282**
