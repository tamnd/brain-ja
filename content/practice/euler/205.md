[プロジェクト オイラー問題 205](https://projecteuler.net/problem=205)

 ## 解決策

 **答え:**`0.5731441`ピーターの合計を次のようにします$P$コリンの合計は$C$。 

私たちが欲しいのは$$\Pr(P>C).$$ピーターロール$9$4 面サイコロなので、次のようになります。$$P = X_1+\cdots+X_9, \qquad X_i\in\{1,2,3,4\}.$$コリンロール$6$6 面サイコロなので、次のようになります。$$C = Y_1+\cdots+Y_6, \qquad Y_i\in\{1,2,3,4,5,6\}.$$重要なアイデアは次のとおりです。 

1. Peter の考えられるすべての合計の分布を計算します。 
2. Colin のすべての可能な合計の分布を計算します。 
3. すべての勝ちペアを数えます$(p,c)$と$p>c$。 
4. 結果の総数で割ります。 

---

 #1. サイコロの合計を数える

 独立したダイスの場合、分布は段階的に構築できます。 

もし`ways[s]`合計を求める方法の数です$s$、次に面を持つ別のダイを追加した後$1$に$k$、$$\text{new\_ways}[s+f] += \text{ways}[s]$$あらゆる顔に$f\in\{1,\dots,k\}$。 

これは標準的な畳み込み/動的プログラミングのアプローチです。 

---

 #2. ピーターの分布

 ピーターのサイコロにはそれぞれ 4 つの面があります。 

最初に:$$\text{ways}_0(0)=1.$$9 個のサイコロを処理した後、それぞれの合計を計算する方法の数を次から取得します。$9$に$36$。 

合計結果:$$4^9 = 262144.$$---

 #3. コリンの分布

 同様に、コリンは 6 つの 6 面サイコロを持っています。 

考えられる合計額の範囲は次のとおりです。$6$に$36$。 

合計結果:$$6^6 = 46656.$$---

 #4. 当選確率の計算

 ピーターが合計を出した場合$p$、コリンロールの合計$c$、するとピーターは次の場合に勝ちます。$$p>c.$$したがって、$$\Pr(P>C) = \frac{ \sum_{p>c} N_P(p)\,N_C(c) }{ 4^9 6^6 },$$どこ：

-$N_P(p)$= Peter の結果の合計数$p$、
 -$N_C(c)$= Colin の結果の合計数$c$。

 #5. Pythonの実装```python
from collections import defaultdict

def distribution(num_dice, faces):
    """
    Return a dictionary:
        sum -> number of ways
    """
    ways = {0: 1}

    for _ in range(num_dice):
        new_ways = defaultdict(int)

        for current_sum, count in ways.items():
            for face in range(1, faces + 1):
                new_ways[current_sum + face] += count

        ways = dict(new_ways)

    return ways

# Peter: 9 four-sided dice
peter = distribution(9, 4)

# Colin: 6 six-sided dice
colin = distribution(6, 6)

# Count winning outcomes
wins = 0

for p_sum, p_count in peter.items():
    for c_sum, c_count in colin.items():
        if p_sum > c_sum:
            wins += p_count * c_count

# Total outcomes
total = (4 ** 9) * (6 ** 6)

probability = wins / total

print(f"{probability:.7f}")
```---

 #7. 小さなケースでの正しさの検証

 ピーターは、次のことを中心に、分散が低い多くのサイコロを振ります。$$9 \times 2.5 = 22.5.$$コリンの平均は次のとおりです。$$6 \times 3.5 = 21.$$Peter の平均はわずかに高く、合計はより集中しているため、確率は少し高くなります。$0.5$合理的です。
