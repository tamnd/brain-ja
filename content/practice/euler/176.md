[プロジェクト オイラー問題 176](https://projecteuler.net/problem=176)

 ## 解決策

 **答え:**`96818198400000`させて$N(n)$は、以下に等しい 1 つのカテーテルを持つ整数辺直角三角形の数を示します。$n$。 

私たちは最小のものを求められます$n$そのような$$N(n)=47547.$$重要なのは、除数関数の公式を導き出すことです。$N(n)$。 

---

 #1. 数学的分析

 直角三角形に足があるとします。$n,b$と斜辺$c$。 それから$$n^2+b^2=c^2.$$再配置:$$c^2-b^2=n^2$$それで$$(c-b)(c+b)=n^2.$$定義する$$u=c-b,\qquad v=c+b.$$それから$$uv=n^2,$$そして$$c=\frac{u+v}{2},\qquad b=\frac{v-u}{2}.$$したがって$u,v$同じパリティを持つ必要があります。 

---

 ## 奇妙なケース

 もし$n$それは奇妙です、それでは$n^2$は奇数なので、すべての約数のペア$(u,v)$自動的に奇数になります。 

それぞれの因数分解$$uv=n^2,\quad u<v$$三角形を 1 つ与えます。 

したがって、次のようになります。$$N(n)=\frac{d(n^2)-1}{2},$$どこ$d(m)$は約数の数です$m$。 

---

 ## 偶数の場合

 書く$$n=2^a m,$$と$m$奇数。 

標準的な導出では次のようになります。$$N(n)=\frac{(2a-1)d(m^2)-1}{2}.$$同様に、もし$$n=2^{a_0}\prod p_i^{a_i},$$それから$$N(n)=\frac{\left(2a_0-1\right)\prod (2a_i+1)-1}{2}.$$これが重要な公式です。 

---

 #2. 条件を変換する

 必要です$$N(n)=47547.$$したがって$$\left(2a_0-1\right)\prod (2a_i+1) = 2\cdot 47547+1.$$計算:$$2\cdot47547+1=95095.$$要素：$$95095 = 5\cdot 7\cdot 11\cdot 13\cdot 19.$$だから必要なのです$$(2a_0-1)\prod (2a_i+1)=95095.$$最小限に抑えるには$n$では、標準的な最適化原則を使用します。 

- より大きな指数はより小さな素数になります。 
- 指数は因子から次のように決定されます。$$2a_i+1=f_i.$$したがって$$a_i=\frac{f_i-1}{2}.$$最大のものを割り当てる必要があります$f_i$最小の素数ベースまで。 

要因は次のとおりです。$$19,\ 13,\ 11,\ 7,\ 5.$$対応する指数:$$9,\ 6,\ 5,\ 3,\ 2.$$次に、どの係数が次の累乗に対応するかを決定する必要があります。$2$。 

のために$2$-私たちが使用する部分$$2a_0-1=f \quad\Rightarrow\quad a_0=\frac{f+1}{2}.$$最大の要素を試す$19$:$$a_0=10.$$次に、残りの指数は次のようになります。$$6,5,3,2$$素数について$3,5,7,11$。 

したがって、$$n=2^{10}3^6 5^5 7^3 11^2.$$これは、単調性の議論 (最小の素数に対する最大の指数) によって最小になります。 

---

 #3. Pythonの実装```python
from math import prod

# Target number of triangles
target = 47547

# We need:
# (2*a0 - 1) * Π(2*ai + 1) = 2*target + 1
M = 2 * target + 1

# Prime factorization of 95095:
factors = [19, 13, 11, 7, 5]

# Assign the largest factor to the power of 2:
# 2*a0 - 1 = 19  => a0 = 10
a0 = (19 + 1) // 2

# Remaining exponents:
# ai = (factor - 1)//2
odd_exponents = [
    (13 - 1) // 2,  # 6
    (11 - 1) // 2,  # 5
    (7  - 1) // 2,  # 3
    (5  - 1) // 2   # 2
]

# Corresponding odd primes
primes = [3, 5, 7, 11]

# Construct n
n = 2**a0
for p, e in zip(primes, odd_exponents):
    n *= p**e

print(n)
```---

 #5. 小さな例の検証

 のために$n=12$:$$12 = 2^2\cdot 3.$$式は次のようになります。$$N(12) = \frac{(2\cdot2-1)(2\cdot1+1)-1}{2} = \frac{3\cdot3-1}{2} = 4.$$問題文と完全に一致します。
