 ## 解決策

 **答え:**`33626723890930`させて$$p=5k-4 \qquad\Longrightarrow\qquad k=\frac{p+4}{5},$$それで$$k-1=\frac{p-1}{5}.$$定義する$$d=\frac{p-1}{5}.$$ゼロ以外の場合$x\in\mathbb F_p$、$$f_p(x)=x^k+x=x\left(x^{k-1}+1\right)=x\left(x^d+1\right).$$今$x^d$は常に 1 の 5 乗根です$\mathbb F_p$、 以来$$(x^d)^5=x^{p-1}=1.$$したがって、非ゼロ要素は、次の値によって決定される 5 つの剰余類に分割されます。$x^d$。 

固定5乗根の場合$r$、$$x^d=r$$暗示する$$f_p(x)=x(1+r).$$したがって、5 つの剰余類に対する誘発されたアクションはマップによって完全に決定されます。$$r \mapsto r(1+r)^d.$$周期剰余類のすべての要素は周期的であり、非周期剰余類のすべての要素は最終的には永久に残ります。 したがって:

 - 各周期剰余類は正確に寄与します$d=(p-1)/5$ポイント、
 -$x=0$常に固定されています。 

それで、もし$c$は 5 つの非ゼロ剰余類のうちの周期剰余類の数です。$$C(p)=1+c\cdot \frac{p-1}{5}.$$次の Python プログラムはこれを効率的に計算します。```python
import math

def S(N):
    # odd-only sieve
    sieve = bytearray(b'\x01') * (N // 2)

    limit = int(math.isqrt(N))
    for i in range(3, limit + 1, 2):
        if sieve[i // 2]:
            start = i * i // 2
            sieve[start::i] = b'\x00' * (((N // 2 - 1 - start) // i) + 1)

    total = 0

    # only primes p == 1 (mod 5) matter
    for p in range(11, N + 1, 10):
        if not sieve[p // 2]:
            continue

        d = (p - 1) // 5

        # find a primitive 5th root of unity
        a = 2
        while True:
            t = pow(a, d, p)
            if t != 1:
                break
            a += 1

        t2 = (t * t) % p
        t3 = (t2 * t) % p
        t4 = (t2 * t2) % p

        roots = (1, t, t2, t3, t4)
        idx = {roots[i]: i for i in range(5)}

        # induced map on the 5 cosets
        T = [0] * 5
        for i, r in enumerate(roots):
            nxt = (r * pow(1 + r, d, p)) % p
            T[i] = idx[nxt]

        # count periodic states in the 5-state graph
        periodic = 0
        for i in range(5):
            j = i
            seen = 0
            while not ((seen >> j) & 1):
                seen |= 1 << j
                j = T[j]
            if j == i:
                periodic += 1

        total += 1 + periodic * d

    return total

print(S(100))      # 127
print(S(10**8))
```プログラムは次の例を再現します。$$S(100)=127.$$実行する目的$10^8$与える:$$S(10^8)=33626723890930.$$**答え: 33626723890930**
