 ## 解決策

 **答え:**`2209`許容できる数値にしましょう$N$異なる素因数が次から始まる連続する素数である偶数の整数であること。$2$。 したがって、許容されるすべての数値は次の形式になります。$$N = 2^{a_1}3^{a_2}5^{a_3}\cdots p_k^{a_k}, \qquad a_i\ge 1 \text{ for } i<k,\ a_k\ge 0,$$スキップされた素数はありません。 

私たちはすべてが許容されるものであることを考慮しなければなりません$N<10^9$、最小値を計算します$M>1$そのような$$N+M$$が素数であり、そのような_distinct_をすべて合計します$M$。 

---

 # ステップ 1 — 許容される数値の構造

 重要な所見は次のとおりです。 

- 許容される数値は、次から始まる連続する素数からのみ構築されます。$2$、
 - 指数は異なる場合があります。 
- 連続する素数の積は非常に急速に増大するため、実際の検索空間は非常に小さいです。 

例えば：$$2\cdot3\cdot5\cdot7\cdot11\cdot13\cdot17 = 510510,$$さらに素数を追加すると急速に$10^9$。 

したがって、許容されるすべての数値を再帰的に生成できます。 

---

 # ステップ 2 — 疑似幸運の数字

 それぞれの許容範囲について$N$、擬似幸運数を定義します。$M$最小の整数として$>1$そのような$$N+M$$プライムです。 

許容される数値はすべて偶数であるため、$N+M$素数になるためには奇数でなければなりません (ただし、$2$、ここでは不可能です。$N\ge2$）。 したがって：

-$M$常に奇数でなければなりません。 

したがって、許容されるそれぞれの$N$、単純にテストします$$M=3,5,7,9,\dots$$それまで$N+M$プライムです。 

私たちはそのようなすべての異なるものを集めます$M$。 

---

 # ステップ 3 — 再帰的生成

 連続する素数を使用して再帰的に数値を構築します。 

私たちが最盛期にあると仮定します$p_i$。 次のべき乗を繰り返します。$p_i$:$$N,\ Np_i,\ Np_i^2,\dots$$値が以下に留まる限り$10^9$。 

次に、次の連続する素数まで再帰します。 

これにより、許容されるすべての数値が 1 回だけ生成されます。 

---

 # Pythonの実装```python
from sympy import primerange, isprime

LIMIT = 10**9

# Generate enough consecutive primes
primes = list(primerange(2, 100))

# Store all admissible numbers
admissible = set()

def generate(idx, current):
    """
    Recursively generate all admissible numbers.

    idx      = index of next prime to use
    current  = current admissible number
    """

    if current >= LIMIT:
        return

    # Exclude 1
    if current > 1:
        admissible.add(current)

    p = primes[idx]

    # Multiply by increasing powers of p
    x = current
    while x * p < LIMIT:
        x *= p
        generate(idx + 1, x)

# Start recursion
generate(0, 1)

# Compute all distinct pseudo-Fortunate numbers
pseudo_fortunate = set()

for n in admissible:

    # M must be odd because n is even
    m = 3

    while not isprime(n + m):
        m += 2

    pseudo_fortunate.add(m)

# Final answer
answer = sum(pseudo_fortunate)

print(answer)
```---

 ## 再帰的な許容数値の生成```python

```-`idx`は、次にどの連続した素数が来るかを教えてくれます。 
-`current`現在許容される数値です。 

素数ごとに$p$を繰り返し乗算します。```python
x *= p
```次に連続する素数まで再帰します。 

これにより、次のことが保証されます。 

- スキップされた素数はありません。 
- 任意の正の指数、
 - 重複はありません。

 ## 疑似幸運の数字を見つける

 それぞれの許容範囲について$n$:```python
m = 3
while not isprime(n + m):
    m += 2
```奇数のみをテストします$m$、 以来$n$は均等です。 

最初に成功したのは$m$擬似幸運の数です。

 # 小さな小切手

 問題には次のように書かれています。 

-$16$疑似幸運の数を持っています$3$。 

確かに：$$16+3=19$$それがプライムです。 

また：

-$630$疑似幸運の数を持っています$11$、

なぜなら$$630+11=641$$は素数ですが、それより小さい奇数オフセットは失敗します。 

プログラムはこれらを正しく再現します。
