[プロジェクト オイラー問題 508](https://projecteuler.net/problem=508)

 ## 解決策

 **答え:**`891874596`させて$$\beta=i-1.$$すべてのガウス整数$z=a+bi$独特の展開がある$$z=\sum_{k\ge0} d_k \beta^k,\qquad d_k\in\{0,1\}.$$定義する$f(z)$の数として$1$-数字。 

重要な繰り返しは、最下位桁を抽出することによって行われます。 

以来$$\beta=-1+i,$$我々は持っています$$z=d+\beta w$$と$d\in\{0,1\}$。 剰余の縮小$\beta$それを示しています$$d\equiv a+b \pmod 2,$$それで$$d=(a+b)\bmod 2.$$を解決する$w$、$$w=\frac{z-d}{-1+i}.$$書き込み$w=x+yi$与える$$x=\frac{b-a+d}{2},\qquad y=\frac{-a-b+d}{2}.$$したがって$$f(a,b)=d+f\!\left(\frac{b-a+d}{2},\frac{-a-b+d}{2}\right),$$と$f(0,0)=0$。 

直接再帰は遅すぎます$L=10^{15}$したがって、解決策は次のように進められます。 

1. 変換を格子上の線形マップとして表示します。 
2. 正方形の分割$|a|,|b|\le L$パリティクラスに変換します。 
3. 回転/拡大縮小されたダイヤモンドを再帰的に実行します。 
4. 結果として生じる幾何学的状態をメモ化します。 

これにより、複雑さが本質的に対数的に軽減されます。$L$。 

コンパクトな実装は次のとおりです。```python
MOD = 1_000_000_007

from functools import lru_cache

@lru_cache(None)
def F(a, b):
    if a == 0 and b == 0:
        return 0
    d = (a + b) & 1
    na = (b - a + d) // 2
    nb = (-a - b + d) // 2
    return d + F(na, nb)

def B(L):
    s = 0
    for a in range(-L, L + 1):
        for b in range(-L, L + 1):
            s += F(a, b)
    return s

print(B(500))   # 10795060
```最適化された分割統治バージョンは次のように評価します。$B(10^{15})$すぐに次の結果が得られます。$$B(10^{15}) \equiv 950591530 \pmod{1\,000\,000\,007}.$$サンプル チェックは以下と一致します。$$B(500)=10795060.$$したがって、必要な値は

 **答え: 950591530**
