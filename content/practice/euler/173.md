[プロジェクト オイラー問題 173](https://projecteuler.net/problem=173)

 ## 解決策

 **答え:**`1572729`外側の正方形に辺の長さを持たせる$n$、内側の正方形 (「穴」) は辺の長さを持ちます。$m$。 

ラミナは対称的な正方形の境界線であるため、次のようになります。 

-$n > m$-$n$そして$m$同じパリティを持たなければなりません（そうでない場合、境界線の太さは整数ではありません）
 - 使用されるタイルの数は$$n^2 - m^2$$私たちが望んでいるのは:$$n^2 - m^2 \le 10^6$$そして有効なペアをすべて数えなければなりません$(n,m)$。 

---

 # 数学的分析

 ## 1. タイル数の書き換え

 要因:$$n^2 - m^2 = (n-m)(n+m)$$以来$n,m$同じパリティを持ち、両方の要素は偶数です。 

させて$$n-m = 2k$$どこ$k \ge 1$境界線の太さです。 

それから：$$m = n-2k$$代わりの：$$n^2 - (n-2k)^2$$拡大する：$$= n^2 - (n^2 - 4kn + 4k^2)$$

$$= 4k(n-k)$$したがって、すべての層は整数に一意に対応します。 

-$k \ge 1$-$n > 2k$タイル数あり$$T = 4k(n-k)$$そして私たちが必要とするのは$$4k(n-k) \le 10^6$$---

 ## 2. 可能性を数える

 枠線の太さを固定する$k$。 

それから：$$n-k \le \frac{10^6}{4k}$$それで$$n \le \frac{10^6}{4k} + k$$また、次のものも必要です。$$n \ge 2k+1$$内穴側の長さは$$m=n-2k \ge 1$$したがって、それぞれについて$k$、有効な$n$値は次のとおりです。$$2k+1 \le n \le \left\lfloor \frac{10^6}{4k} + k \right\rfloor$$したがって、一定の層の数は$k$は$$\left\lfloor \frac{10^6}{4k} + k \right\rfloor - (2k+1) + 1$$これを単純化すると$$\left\lfloor \frac{10^6}{4k} \right\rfloor - k$$この量が正の場合。 

したがって、合計数は$$\sum_{k\ge1} \max\left(0,\left\lfloor \frac{10^6}{4k}\right\rfloor-k\right)$$---

 # Pythonの実装```python
LIMIT = 1_000_000

count = 0
k = 1

while True:
    # Number of valid outer sizes for this thickness
    ways = LIMIT // (4 * k) - k

    # Once non-positive, no larger k can work
    if ways <= 0:
        break

    count += ways
    k += 1

print(count)
```---

 # コードのチュートリアル```python
LIMIT = 1_000_000
```許可されるタイルの最大数。 

---```python
count = 0
k = 1
```-`count`層の総数を保存します。 
-`k`境界線の太さです。 

---```python
ways = LIMIT // (4 * k) - k
```導出から:$$\text{ways} = \left\lfloor \frac{LIMIT}{4k}\right\rfloor - k$$これは、厚さとして有効な外側の正方形のサイズをすべてカウントします。$k$。 

---```python
if ways <= 0:
    break
```として$k$増加すると量は単調減少します。 

一度非陽性になると、それ以上の層は形成できません。 

---```python
count += ways
```厚さの層をすべて追加します$k$。 

---```python
k += 1
```次の枠線の太さに移動します。 

---```python
print(count)
```個別の正方形の層の最終的な数を出力します。

 # 最終確認

 カウントは次のようになります。 

- よりもはるかに大きい$10^5$, 細い枠線がたくさんある可能性があるので、
 - しかし、それよりもはるかに小さい$10^7$許容される厚さはおおよそ までしかないためです。$$k^2 < \frac{10^6}{4} \Rightarrow k < 500$$結果の値は予想範囲内にあり、既知のプロジェクト オイラーの結果と一致します。
