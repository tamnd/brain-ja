[プロジェクト オイラー問題 206](https://projecteuler.net/problem=206)

 ## 解決策

 **答え:**`1389019170`一意の正の整数を求めます$n$そのような$$n^2 = 1\_2\_3\_4\_5\_6\_7\_8\_9\_0$$ここで、各アンダースコアは任意の数字です。 

つまり、正方形には小数点パターンが必要です$$1x2x3x4x5x6x7x8x9x0$$数字の場合$x\in\{0,\dots,9\}$。 

---

 # ステップ 1 — 構造を理解する

 番号の終わりは$0$、 それで：$$n^2 \equiv 0 \pmod{10}$$したがって、$n$で終わる必要があります$0$。 

書く$$n = 10m$$それから$$n^2 = 100m^2$$正方形のパターンから最後の 2 つのゼロを削除すると、次のようになります。$$m^2 = 1\_2\_3\_4\_5\_6\_7\_8\_9$$さらに重要なのは、元の正方形が次で終わっているためです。$900$、$$n^2 \equiv 900 \pmod{1000}$$したがって$$n^2 \equiv 9 \pmod{10}$$それで$n/10$で終わる必要があります$3$または$7$、 なぜなら：$$3^2 \equiv 9 \pmod{10},\qquad 7^2 \equiv 9 \pmod{10}$$したがって：$$n \text{ ends in } 30 \text{ or } 70$$これにより、検索スペースがすでに大幅に削減されます。 

---

 # ステップ 2 — 数値範囲を決定する

 可能な最小の正方形は$$1020304050607080900$$そして最大のものは$$1929394959697989990$$それで：$$\sqrt{1020304050607080900} \le n \le \sqrt{1929394959697989990}$$およその計算:$$1010101010 \lesssim n \lesssim 1389026623$$以来$n$で終わる必要があります$30$または$70$、それらの候補者のみをテストします。 

---

 # ステップ 3 — 効率的なパターンチェック

 繰り返し文字列に変換する代わりに、数字を直接検査できます。 

仮定する$$s = n^2$$必要なものは次のとおりです。 

- 単位桁 = 0
 - 百の位 = 9
 - 1万の位 = 8
 -など

 同様に、右から左に読むと次のようになります。$$0,9,8,7,6,5,4,3,2,1$$必要な各桁の間に任意の 1 桁を入れます。 

便利な方法は文字列マッチングです。```python
str(s)[::2] == "1234567890"
```必要な数字が 1 つおきの位置を占めるためです。 

---

 # ステップ 4 — Python の実装```python
import math

# Lower and upper bounds for the square root
low = int(math.isqrt(1020304050607080900))
high = int(math.isqrt(1929394959697989990)) + 1

# Force the search to numbers ending in 30 or 70
for n in range(low, high, 10):

    # Only numbers ending in 30 or 70 are possible
    if n % 100 not in (30, 70):
        continue

    sq = n * n

    # Check the required pattern
    if str(sq)[::2] == "1234567890":
        print(n)
        break
```---
