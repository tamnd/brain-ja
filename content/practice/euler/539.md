 #1. 数学的分析

 ## ステップ 1: 繰り返し$P(n)$最初の左から右へのパスの後$1,2,\dots,n$:

 - すべての奇数が削除されます。 
- 残りのリストは$$2,4,6,\dots,2\left\lfloor \frac n2 \right\rfloor$$すべてを次の値で割ります$2$。 残りの問題は同じ消去プロセスになりますが、逆の方向から始まります。 

生存者を次のように表すと、$P(n)$の場合、古典的なエリミネーション ゲームの繰り返しは次のようになります。$$P(n)=2\left(1+\left\lfloor\frac n2\right\rfloor-P\!\left(\left\lfloor\frac n2\right\rfloor\right)\right)$$ベースケース付き$$P(1)=1.$$同様に、$n\ge1$、$$P(2n)=P(2n+1)=2(n+1-P(n)).$$これは、連続する奇数/偶数のペアが等しい値を持つ理由をすぐに説明します。 

---

 ## ステップ 2: の繰り返しを導出する$S(n)$定義する$$A(n)=\sum_{k=1}^n P(2k).$$繰り返しを使用すると、次のようになります。$$P(2k)=2(k+1-P(k)),$$それで$$A(n) =\sum_{k=1}^n 2(k+1-P(k)).$$したがって$$A(n) =2\sum_{k=1}^n k + 2n -2S(n).$$以来$$\sum_{k=1}^n k=\frac{n(n+1)}2,$$私たちは得ます$$A(n)=n(n+1)+2n-2S(n) =n^2+3n-2S(n).$$---

 ## ステップ 3: エクスプレス$S(2n)$そして$S(2n+1)$なぜなら$$P(2k-1)=P(2k),$$我々は持っています$$S(2n) =1+2\sum_{k=1}^{n-1}P(2k)+P(2n).$$つまり、$$S(2n)=1+2A(n)-P(2n).$$次の式を代入します。$$A(n)=n^2+3n-2S(n),$$そして$$P(2n)=2(n+1-P(n)).$$簡略化後:$$\boxed{ S(2n)=2n^2+4n-1-2S(n)-2S(n-1) }$$同様に、$$S(2n+1)=S(2n)+P(2n+1).$$以来$P(2n+1)=P(2n)$、$$S(2n+1)=1+2A(n),$$したがって$$\boxed{ S(2n+1)=2n^2+6n+1-4S(n) }$$これらの繰り返しにより、毎回引数が半分になるため、複雑さはわずかになります。$O(\log n)$。 

---

 #2. Pythonの実装```python
from functools import lru_cache

MOD = 987654321

@lru_cache(None)
def S(n):
    # Base cases
    if n <= 0:
        return 0
    if n == 1:
        return 1

    # Even case: n = 2m
    if n % 2 == 0:
        m = n // 2
        return (
            2 * m * m
            + 4 * m
            - 1
            - 2 * S(m)
            - 2 * S(m - 1)
        ) % MOD

    # Odd case: n = 2m + 1
    else:
        m = n // 2
        return (
            2 * m * m
            + 6 * m
            + 1
            - 4 * S(m)
        ) % MOD

answer = S(10**18)
print(answer)
```---
