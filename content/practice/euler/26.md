[プロジェクト オイラー問題 26](https://projecteuler.net/problem=26)

 ## 解決策

 **答え:**`983`分数の場合$1/d$、10 進数展開での繰り返しサイクルの長さは、次の乗算順序によって決まります。$10 \pmod d$の要因を除去した後、$2$そして$5$(これらは終了小数点にのみ寄与するため)。 

プライム用$d$(以外の$2,5$)、繰り返しの周期の長さで割ります。$d-1$。 サイクルを最大化するには$1000$を検索します。$d<1000$最大の期間で。 

きれいな方法は、長い除算をシミュレートすることです。これまでに確認された剰余を追跡します。 剰余が繰り返されると、小数点の循環が始まり、循環長は出現間の距離になります。 

### Python コード```python
def cycle_length(d):
    seen = {}
    remainder = 1 % d
    position = 0

    while remainder != 0 and remainder not in seen:
        seen[remainder] = position
        remainder = (remainder * 10) % d
        position += 1

    if remainder == 0:
        return 0  # terminating decimal
    return position - seen[remainder]

best_d = 0
max_cycle = 0

for d in range(2, 1000):
    length = cycle_length(d)
    if length > max_cycle:
        max_cycle = length
        best_d = d

print(best_d)
```### メンタルトレース/正当性チェック

 - 小さなケース:

 -$1/3 = 0.(3)$→ 周期の長さ$1$-$1/7 = 0.(142857)$→ 周期の長さ$6$- アルゴリズムは繰り返しの剰余を正確に検出し、サイクル長を測定します。 
- 近くの値を確認する$1000$、最大の繰り返しサイクルは次の時点で発生します。$d=983$、サイクル長は$982$(完全なreptendプライム)。 

**答え: 983**
