[プロジェクト オイラー問題 292](https://projecteuler.net/problem=292)

 ## 解決策

 **答え:**`3600060866`多角形のエッジをベクトルとする$$v_i=(x_i,y_i)\in \mathbb Z^2, \qquad |v_i| \in \mathbb Z.$$ポリゴンは凸状であり、連続する 3 つの頂点が同一線上にないため、エッジの方向はポリゴンの周囲で厳密に増加しています。 

したがって、ピタゴラス多角形は、合計が 0 である整数長の格子ベクトルの巡回順序シーケンスによって (平行移動まで) 完全に決定されます。 

重要な所見は次のとおりです。 

> 許容されるすべてのエッジ ベクトルは、(おそらくスケーリングされた) 原始ピタゴラス ベクトルです。 
>
 >
 >
 >
 >$$(a,b)=k(m^2-n^2,\,2mn)$$>
 >
 >
 >
 > 符号の変更と座標の交換を伴う。 

外周用$\le 120$、可能なエッジ ベクトルの総数は、事前計算できるほど十分に小さいです。 

---

 #1. 数学的定式化

 極角を増加させることによってポリゴン エッジが順序付けされていると仮定します。$$v_1,v_2,\dots,v_r.$$凸性 + 「3 つ揃っていない」ということは、次のことを意味します。 

- すべての方向が明確であり、
 - 角度の順序は厳密です。 
- ポリゴンは次の場合に閉じます$$\sum_{i=1}^r v_i = (0,0).$$外周条件は、$$\sum_{i=1}^r |v_i| \le 120.$$したがって、問題は次のようになります。 

> ベクトルの合計が 0 で、ユークリッドの合計の長さが最大以下である整数長の格子ベクトルの角度増加シーケンスを厳密にカウントします。$120$。 

循環オーバーカウントを回避するには:

 - 角度が最小のエッジを最初のエッジとして選択します。 
- その後、後のすべてのエッジの角度が大きくなります。 

これにより、各ポリゴンが 1 回だけ与えられます。 

---

 #2. 動的プログラミングのアイデア

 整数の長さを持つすべての有向格子ベクトルを生成します$\le 120$。 

各ベクトル ストアについて:$$(x,y,\ell,\theta).$$角度ごとに並べ替えます。 

次に、状態に対して DFS / メモ化された DP を実行します。$$(\text{last index},\; s_x,\; s_y,\; p)$$意味:

 - 最後に選択したエッジには角度インデックスがあります`last`、
 - 現在のベクトルの合計は$(s_x,s_y)$、
 - 現在の境界線は$p$。 

トランジションでは、より大きな角度を持つ新しいベクトルが追加されます。 

必要な終了ベクトルが必要なときはいつでも$$(-s_x,-s_y)$$より大きな角度と周囲長でも存在します$\le 120$、ポリゴンを 1 つ取得します。 

なぜなら$120$が小さい場合、到達可能な状態はメモ化で管理可能です。

 #3. Pythonの実装```python
from math import gcd, isqrt, atan2
from functools import lru_cache

LIMIT = 120

# ------------------------------------------------------------
# Generate all integer-length lattice vectors with length <= 120
# ------------------------------------------------------------

vectors = []

for x in range(-LIMIT, LIMIT + 1):
    for y in range(-LIMIT, LIMIT + 1):

        if x == 0 and y == 0:
            continue

        s = x * x + y * y
        r = isqrt(s)

        if r * r == s and r <= LIMIT:
            ang = atan2(y, x)
            if ang < 0:
                ang += 2.0 * 3.141592653589793

            vectors.append((ang, x, y, r))

# sort by polar angle
vectors.sort()

M = len(vectors)

# map vector -> (index,length)
lookup = {}

for i, (_, x, y, r) in enumerate(vectors):
    lookup[(x, y)] = (i, r)

# ------------------------------------------------------------
# DFS with memoization
# ------------------------------------------------------------

@lru_cache(None)
def dfs(last, sx, sy, perim, edges):

    total = 0

    # Can we close the polygon?
    need = (-sx, -sy)

    if edges >= 2 and need in lookup:
        idx, r = lookup[need]

        if idx > last and perim + r <= LIMIT:
            total += 1

    # Try extending with another edge
    for nxt in range(last + 1, M):

        _, x, y, r = vectors[nxt]

        if perim + r > LIMIT:
            continue

        total += dfs(
            nxt,
            sx + x,
            sy + y,
            perim + r,
            edges + 1
        )

    return total

# ------------------------------------------------------------
# Start from each possible first edge
# ------------------------------------------------------------

answer = 0

for i, (_, x, y, r) in enumerate(vectors):
    answer += dfs(i, x, y, r, 1)

print(answer)
```---

 #4. コードのチュートリアル

 ### ベクトルの生成

 すべての格子ベクトルを列挙します$(x,y)$そのような$$x^2+y^2$$は完全な正方形です。 

これらはまさに整数のユークリッド長を持つベクトルです。 

---

 ### 角度による並べ替え

 凸多角形は、極角の厳密に増加する順序で取得されたベクトルに対応します。 

一度ソートすると、凸性を自動的に適用できます。 

---

 ### DFS 状態

 メモ化された状態には以下が保存されます。 

- 最後に使用された角度インデックス、
 - 現在のベクトルの合計、
 - 現在の周囲、
 - すでに選択されているエッジの数。 

---

 ### 終了条件

 必要な残りのベクトルがあれば、ポリゴンは閉じます。$$(-s_x,-s_y).$$そのベクトルが存在し、前のエッジよりも角度が大きい場合は、有効な凸多角形となります。
