[プロジェクト オイラー問題 94](https://projecteuler.net/problem=94)

 ## 解決策

 **答え:**`518408346`ほぼ正三角形に辺があるとします。 

-$(a,a,a+1)$、 または
-$(a,a,a-1)$、

どこ$a$は整数です。 私たちが望んでいるのは:

 1. 整数辺の長さ、
 2. 整数領域、
 3. 外周$\le 10^9$。 

重要なのは、エリア条件をペル方程式に変換することです。 

---

 #1. 数学的分析

 辺が等しい二等辺三角形の場合$a$そしてベース$b$、高さは$$h=\sqrt{a^2-\left(\frac b2\right)^2}.$$エリアは$$A=\frac12 bh.$$必要です$A$整数になるようにします。 

以来$b=a\pm1$、 書く：$$A=\frac b2\sqrt{a^2-\frac{b^2}{4}} =\frac b4\sqrt{4a^2-b^2}.$$したがって、私たちが要求するのは、$$4a^2-b^2$$完全な正方形になるように。 

させて$$b=a\pm1.$$それから$$4a^2-(a\pm1)^2 =3a^2\mp2a-1.$$だから必要なのです$$3a^2\mp2a-1 = k^2.$$---

 ## ケース 1:$(a,a,a+1)$得ます$$k^2=3a^2-2a-1.$$3 を掛ける:$$3k^2 = 9a^2-6a-3.$$1を追加:$$3k^2+1 = (3a-1)^2.$$したがって、$$(3a-1)^2-3k^2=1.$$させて$$x=3a-1,\qquad y=k.$$それから$$x^2-3y^2=1.$$これがペルの方程式です。 

また：$$a=\frac{x+1}{3}.$$必要です$x\equiv2\pmod3$。 

外周は$$P=3a+1=x+2.$$---

 ## ケース 2:$(a,a,a-1)$同様に、$$k^2=3a^2+2a-1.$$3 を掛けて 1 を加算します。$$(3a+1)^2-3k^2=1.$$させて$$x=3a+1.$$また：$$x^2-3y^2=1.$$今$$a=\frac{x-1}{3},$$と周囲:$$P=3a-1=x-2.$$---

 ## ペル方程式の構造

 解決策を列挙する必要があります$x^2-3y^2=1$根本的な解決策は、$$(2,1),$$すべての解決策は次から生まれます$$x_n+y_n\sqrt3=(2+\sqrt3)^n.$$有効な三角形を生成するものだけを保持します。$$P\le10^9.$$ペル解の反復は次のとおりです。$$x_{n+1}=2x_n+3y_n,$$

$$y_{n+1}=x_n+2y_n.$$最初のいくつかをテストします:

 |$a$| トライアングル | 周囲 |
 | --- | --- | --- |
 | 5 | 5-5-6 | 16 |
 | 17 | 17-17-16 | 50 |
 | 65 | 65-65-66 | 196 |
 | 241 | 241-241-240 | 722 |

 これらは既知の例と一致しており、交互に続きます。 

以下の有効な周囲長をすべて合計します。$10^9$。

 #2. Pythonの実装```python
LIMIT = 1_000_000_000

total = 0

# Fundamental Pell solution
x, y = 2, 1

while True:
    added = False

    # Case: (a, a, a+1)
    if (x + 1) % 3 == 0:
        a = (x + 1) // 3
        p = 3 * a + 1

        # Check triangle validity
        if p <= LIMIT and 2 * a > a + 1:
            total += p
            added = True

    # Case: (a, a, a-1)
    if (x - 1) % 3 == 0:
        a = (x - 1) // 3
        p = 3 * a - 1

        # Check triangle validity
        if p <= LIMIT and a > 1:
            total += p
            added = True

    # Generate next Pell solution
    x, y = 2 * x + 3 * y, x + 2 * y

    # Stop once both possible perimeters exceed limit
    if x - 2 > LIMIT and x + 2 > LIMIT:
        break

print(total)
```---

 ### 両方の三角形フォームをテストする

 各 Pell ソリューションについて:```python
if (x + 1) % 3 == 0:
```これは以下に対応します$$x=3a-1$$三角形用$(a,a,a+1)$。 

回復します:$$a=\frac{x+1}{3}$$と周囲$$P=3a+1.$$同様に:```python
if (x - 1) % 3 == 0:
```ハンドル$$x=3a+1$$三角形用$(a,a,a-1)$。

 ### ペルの再発```python
x, y = 2 * x + 3 * y, x + 2 * y
```これにより、次のすべてのソリューションが生成されます。$$x^2-3y^2=1.$$シーケンスは指数関数的に急速に増加するため、必要な反復は数十回だけです。
