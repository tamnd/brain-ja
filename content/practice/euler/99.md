[プロジェクト オイラー問題 99](https://projecteuler.net/problem=99)

 ## 解決策

 **答え:**`709`## 1. 数学的分析

 ファイルのどの行に次の **最大値** が含まれているかを判断したいと考えています。$$a^b$$ここで、各行には基数と指数のペアが含まれます$(a,b)$。 

などの数字があるため、直接比較することは不可能です。$$632382^{518061}$$何百万もの数字が含まれています。 

重要な観察は、**対数は順序を維持する**ということです。 

もし$$x > y,$$それから$$\log(x) > \log(y).$$だから比較するのではなく$$a^b \quad \text{and} \quad c^d,$$それらの対数を比較します。$$\log(a^b) = b\log(a)$$そして$$\log(c^d) = d\log(c).$$したがって、$$a^b > c^d \iff b\log(a) > d\log(c).$$これにより、不可能な巨大な整数の比較が、通常の浮動小数点数の比較に変換されます。 

### 問題の例

 比較してください:$$632382^{518061} \quad \text{vs} \quad 519432^{525806}$$比較します:$$518061\log(632382)$$そして$$525806\log(519432).$$より大きな対数スコアは、より大きな指数値に対応します。 これにより、膨大な数自体を計算する必要がなくなります。

 ## 2. Python の実装```python
from math import log

# Read the file
with open("base_exp.txt") as f:
    lines = f.readlines()

max_value = float("-inf")
max_line = 0

# Enumerate starting at 1 because Project Euler line numbers are 1-based
for line_number, line in enumerate(lines, start=1):
    base, exponent = map(int, line.strip().split(","))

    # Compare exponent * log(base)
    value = exponent * log(base)

    if value > max_value:
        max_value = value
        max_line = line_number

print(max_line)
```---
