 ## 解決策

 **答え:**`1966666166408794329`させて$$S_n=\sum_{k=1}^n k a_k.$$再発というのは、$$a_n=S_{n-1}\pmod n.$$私たちが欲しいのは$$f(N,M)=\#\{(p,q):1\le p\le q\le N,\ \sum_{i=p}^q a_i\equiv0\pmod M\}.$$標準的な接頭辞合計トリックは、これを計数問題に変換します。 

定義する$$B_n=\sum_{i=1}^n a_i,\qquad B_0=0.$$それから$$\sum_{i=p}^q a_i = B_q-B_{p-1},$$それで条件は$$B_q\equiv B_{p-1}\pmod M.$$したがって、残留物の場合$r$発生する$c_r$間で回$$B_0,B_1,\dots,B_N \pmod M,$$それなら貢献する$\binom{c_r}{2}$有効なペア。 したがって$$f(N,M)=\sum_{r=0}^{M-1}\binom{c_r}{2}.$$したがって、問題全体はシーケンスを理解することに帰着します$a_n$。

 #1. の構造を導き出す$a_n$いくつかの項を計算します。$$1,1,0,3,0,3,5,4,1,9,1,6,9,7,2,15,\dots$$強い$6$-term パターンが表示されます。 

私たちは次のように主張します:$$\boxed{ \begin{aligned} a_{6m+1}&=4m+1,\\ a_{6m+2}&=3m+1,\\ a_{6m+3}&=m,\\ a_{6m+4}&=6m+3,\\ a_{6m+5}&=m,\\ a_{6m+6}&=3m+3. \end{aligned}}$$これは、定義再発からの帰納によって証明できます。

 ## プレフィックスの合計を計算する$B_n$1 つの完全なブロックを合計すると、次のようになります。$$(4m+1)+(3m+1)+m+(6m+3)+m+(3m+3)=18m+8.$$したがって$$B_{6m} =\sum_{j=0}^{m-1}(18j+8) =9m^2-m.$$ブロック内:$$\boxed{ \begin{aligned} B_{6m} &= 9m^2-m,\\ B_{6m+1} &= 9m^2+3m+1,\\ B_{6m+2} &= 9m^2+6m+2,\\ B_{6m+3} &= 9m^2+7m+2,\\ B_{6m+4} &= 9m^2+13m+5,\\ B_{6m+5} &= 9m^2+14m+5. \end{aligned}}$$これらの式は正確です。

 # 2. 周期性モジュロ$M$リデュースモジュロ$M$。 

のために$m\mapsto m+M$、$$9(m+M)^2-(m+M)\equiv 9m^2-m \pmod M,$$6 つの残基クラスすべてについても同様です。 

したがって：$$B_{n+6M}\equiv B_n\pmod M.$$それでシーケンスは$B_n\bmod M$期間あり$6M$。 

この問題については:$$M=10^6,\qquad P=6M=6\cdot10^6.$$---

 #3. 残基を数える

 しましょう$$N=qP+r.$$それから最初の$q$全期間は均等に寄与するため、追加の部分ブロックが 1 つだけ必要になります。 

残基ごとに$x\in[0,M-1]$、 させて$c_x$の合計頻度になります。$$B_0,B_1,\dots,B_N.$$ついに：$$f(N,M)=\sum_x \frac{c_x(c_x-1)}2.$$---

 #4. Pythonの実装```python
from collections import defaultdict

def F(N, M):
    P = 6 * M

    # Count residues in one full period
    period_count = [0] * M

    for m in range(M):
        base = (9 * m * m - m) % M

        vals = [
            base,
            (base + 4 * m + 1) % M,
            (base + 7 * m + 2) % M,
            (base + 8 * m + 2) % M,
            (base + 14 * m + 5) % M,
            (base + 15 * m + 5) % M,
        ]

        for v in vals:
            period_count[v] += 1

    q, r = divmod(N, P)

    # Total counts
    total = [q * c for c in period_count]

    # Add the remaining prefix terms
    full_blocks = r // 6
    rem = r % 6

    for m in range(full_blocks + 1):
        base = (9 * m * m - m) % M

        vals = [
            base,
            (base + 4 * m + 1) % M,
            (base + 7 * m + 2) % M,
            (base + 8 * m + 2) % M,
            (base + 14 * m + 5) % M,
            (base + 15 * m + 5) % M,
        ]

        limit = 6 if m < full_blocks else rem + 1

        for i in range(limit):
            total[vals[i]] += 1

    # Count equal pairs
    ans = 0
    for c in total:
        ans += c * (c - 1) // 2

    return ans

print(F(10, 10))         # 4
print(F(10**4, 10**3))   # 97158
print(F(10**12, 10**6))
```---
