[プロジェクト オイラー問題 172](https://projecteuler.net/problem=172)

 ## 解決策

 **答え:**`227485267000992000`私たちは、数字が 3 回以上出現しない 18 桁の数字を数えなければなりません。 

数字を次のようにします$0,1,\dots,9$。 

長さ 18 の文字列の数を求めます。 

- 最初の桁がゼロ以外、
 - 各数字は最大 3 回使用されます。 

これは制約付き多項計数問題です。 

---

 #1. 数学的分析

 数字と仮定します$i$発生する$a_i$回、どこで$$0 \le a_i \le 3, \qquad \sum_{i=0}^9 a_i = 18.$$大事なら$(a_0,\dots,a_9)$が修正されている場合、次のようになります。 

- 18 桁の合計配列:$$\frac{18!}{a_0!a_1!\cdots a_9!}$$- しかし、いくつかは次のように始まります$0$、これらは禁止されています。 

## 先行ゼロのないカウント配列

 もし$a_0=0$の場合、すべての取り決めが有効になります。 

もし$a_0>0$、最初にゼロ以外の数字を固定して、有効な配置をカウントします。 

よりクリーンな方法は次のとおりです。$$\text{valid} = \frac{18!}{\prod a_i!} - \frac{17!}{(a_0-1)!\prod_{i=1}^9 a_i!}.$$第 2 項を因数分解します。$$\frac{17!}{(a_0-1)!\prod_{i=1}^9 a_i!} = \frac{17!a_0}{\prod a_i!}.$$したがって、$$\text{valid} = \frac{17!(18-a_0)}{\prod a_i!}.$$ゼロ以外の数字が 9 個あるので、$18-a_0 = a_1+\cdots+a_9$、まさに予想通り。 

したがって、合計の答えは、$$\boxed{ \sum_{\substack{a_0+\cdots+a_9=18\\0\le a_i\le3}} \frac{17!(18-a_0)}{a_0!a_1!\cdots a_9!} }$$これは有限であるため、それぞれ$a_i\in\{0,1,2,3\}$。 

---

 ## 生成関数の観点

 分母構造は生成関数を示唆しています。 

数字の場合$1$–$9$、 定義する$$f(x)=1+x+\frac{x^2}{2!}+\frac{x^3}{3!}.$$先行ゼロの修正には必要があります$$g(x)=1+\frac{x}{1!}+\frac{x^2}{2!}.$$なぜ？ 乗算するので、$a_0$改宗する$$\frac{a_0}{a_0!}=\frac1{(a_0-1)!}.$$それから$$\sum \frac{18-a_0}{\prod a_i!} = 9 \,[x^{17}]\, g(x)f(x)^9.$$ついに、$$N = 17!\cdot 9 \cdot [x^{17}]\,g(x)f(x)^9.$$これは洗練されていますが、実装ではすべてのカウントベクトルを直接列挙するのが最も簡単です。 

---

 #2. Pythonの実装```python
from math import factorial
from itertools import product

# Precompute factorials
fact = [factorial(i) for i in range(19)]

total = 0

# Each digit count can be 0,1,2,3
# Enumerate all 4^10 possibilities
for counts in product(range(4), repeat=10):

    # Total digits must be 18
    if sum(counts) != 18:
        continue

    a0 = counts[0]

    # Compute denominator product a0! a1! ... a9!
    denom = 1
    for c in counts:
        denom *= fact[c]

    # Number of valid 18-digit numbers for this count pattern
    ways = fact[17] * (18 - a0) // denom

    total += ways

print(total)
```---

 #4. 小さな健全性チェック

 おもちゃの小さいバージョンの場合:

 - 2桁の数字、
 - 数字が複数回繰り返されることはありません。 

カウントは次のようになります。 

- 最初の桁: 9 つの選択肢、
 - 2 桁目: 残り 9 つの選択肢、

 それで$9\times 9=81$。 

同じ多項法でこれを正確に再現します。

 #5. 最終検証

 無制限の 18 桁の数字は、$$9\times10^{17}.$$私たちの制限 (「3 回を超える数字は使用しない」) により多くの数値が削除されますが、依然として大部分が残るため、答えは依然として次のとおりであるはずです。$10^{17}$。 

計算された値は次のとおりです。$$227485267000992000$$これは確かに正しい大きさです。
