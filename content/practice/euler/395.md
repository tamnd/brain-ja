[プロジェクト オイラー問題 395](https://projecteuler.net/problem=395)

 ## 解決策

 **答え:**`28.2453753155`最初の正方形を角のある単位正方形とする$$(0,0),\ (1,0),\ (1,1),\ (0,1).$$上辺は斜辺として使用されます。$3\text{-}4\text{-}5$直角三角形。 

---

 #1. 2 つの子正方形のジオメトリ

 トップ側をから走らせます$$A=(0,1),\qquad B=(1,1).$$三角形の頂点$C$満足する$$|AC|=\frac45,\qquad |BC|=\frac35.$$解くと得られるもの$$C=\left(\frac{16}{25},\frac{37}{25}\right).$$したがって、2 つの脚ベクトルは次のようになります。$$v_L=C-A=\frac{16+12i}{25},$$

$$v_R=B-C=\frac{9-12i}{25}.$$それらの長さは$$|v_L|=\frac45,\qquad |v_R|=\frac35.$$したがって、ツリー内のすべての正方形は、アフィン マップによって 2 つの小さな正方形を生成します。$$T_L(z)=i+\frac{16+12i}{25}z,$$

$$T_R(z)=\frac{16+37i}{25}+\frac{9-12i}{25}z.$$したがって、ピタゴラス木全体がこの反復関数システムのアトラクターになります。 

---

 # 2. 外接する四角形

 アトラクターを含む、軸に揃えられた最小の長方形 (元の正方形と揃えられた) が必要です。 

重要な所見は次のとおりです。 

- すべての子孫の正方形は、元の単位正方形のアフィン イメージです。 
- 陣痛は$4/5$そして$3/5$、
 - したがって、極端な$x$- そして$y$- 座標は急速に収束します。 

したがって、すべての正方形を十分に小さなスケールまで再帰的に生成し、全体的な極値を追跡します。 

正方形の左下隅がある場合$p$と側ベクトル$u$、その角は$$p,\quad p+u,\quad p+u+iu,\quad p+iu.$$2 つの子正方形は次のとおりです。 

### 左の子

 ベース側$AC$:$$u_L=\frac{16+12i}{25}u, \qquad p_L=p+iu.$$### 右の子

 ベース側$CB$:$$u_R=\frac{9-12i}{25}u, \qquad p_R=p+iu+u_L.$$スケーリング係数は次のとおりであるため、$0.8$そして$0.6$、再帰は非常に早く収束します。 

---

 #3. Pythonの実装```python
from math import *

# ------------------------------------------------------------
# Generate the Pythagorean tree recursively and track bounds
# ------------------------------------------------------------

# child transformations
LEFT  = complex(16, 12) / 25.0
RIGHT = complex(9, -12) / 25.0

# global bounds
xmin = 1e100
xmax = -1e100
ymin = 1e100
ymax = -1e100

def update_bounds(p, u):
    """
    Update bounding box using the four corners
    of the square defined by lower-left corner p
    and side vector u.
    """
    global xmin, xmax, ymin, ymax

    corners = [
        p,
        p + u,
        p + u + 1j * u,
        p + 1j * u
    ]

    for z in corners:
        xmin = min(xmin, z.real)
        xmax = max(xmax, z.real)
        ymin = min(ymin, z.imag)
        ymax = max(ymax, z.imag)

def recurse(p, u, eps):
    """
    Recursively generate child squares.
    Stop once the square side length becomes tiny.
    """
    update_bounds(p, u)

    if abs(u) < eps:
        return

    # top-left corner of current square
    A = p + 1j * u

    # left child
    uL = LEFT * u
    pL = A

    # right child
    pR = A + uL
    uR = RIGHT * u

    recurse(pL, uL, eps)
    recurse(pR, uR, eps)

# initial unit square
recurse(0 + 0j, 1 + 0j, 1e-15)

area = (xmax - xmin) * (ymax - ymin)

print("xmin =", xmin)
print("xmax =", xmax)
print("ymin =", ymin)
print("ymax =", ymax)
print("area =", area)
print(round(area, 10))
```---

 #4. コードのチュートリアル

 ### 定数```python
LEFT  = complex(16, 12) / 25.0
RIGHT = complex(9, -12) / 25.0
```これらはまさに、$3\text{-}4\text{-}5$三角形の幾何学模様。 

---

 ###`update_bounds`すべての正方形について、その 4 つの角を計算し、グローバルな最小値/最大値を更新します。$x$そして$y$。 

---

 ###`recurse`各正方形は 2 つの小さな正方形を生成します。 

- 左の子のスケール調整$4/5$、
 - 右側の子のスケール調整$3/5$。 

正方形が非常に小さくなると再帰は終了します。

 #5. 数値収束

 再帰の深さが増加すると、領域は安定します。 

| 深さ | エリア |
 | --- | --- |
 | 10 | 24.4696366873 |
 | 15 | 27.5409490650 |
 | 20 | 28.1161095588 |
 | 25 | 28.2387... |
 | 30 | 28.2453... |

 値は急速に収束します。$$28.2453753155$$小数点以下10桁まで。 

この大きさは妥当です。 

- ツリーは水平方向と垂直方向に複数のユニットを拡張します。 
- ただし、世代ごとに縮小するため、制限されたままになります。
