 ## 解決策

 **答え:**`840`私たちは境界を求めます$p \le 1000$**整数直角三角形の解の最大数**が得られます。$(a,b,c)$満足のいく$$a^2+b^2=c^2,\qquad a+b+c=p$$どこ$a,b,c$は正の整数です。 

## 1. 数学的分析

 辺の長さが整数の直角三角形は **ピタゴラス トリプル**です。$$a^2+b^2=c^2$$各境界線にトリプルがいくつ存在するかを数えたいとします。$p\le 1000$。 

順序は重要ではないので、次のように仮定します。$$a \le b < c$$それから：$$a+b+c=p$$代わりの：$$c = p-a-b$$ピタゴラス方程式に代入すると、次のようになります。$$a^2+b^2=(p-a-b)^2$$拡張:$$a^2+b^2 = p^2+a^2+b^2-2pa-2pb+2ab$$キャンセル$a^2+b^2$:$$0=p^2-2p(a+b)+2ab$$再配置:$$2ab = 2p(a+b)-p^2$$固定周囲の場合$p$の整数値を効率的に列挙できます。$a,b$かどうかを確認してください$$c=\sqrt{a^2+b^2}$$は積分であるかどうか$$a+b+c=p.$$### 検索範囲

 以来$a \le b < c$、$$a < \frac{p}{3}$$そして$$b < \frac{p-a}{2}$$これにより、検索スペースが大幅に減少します。 

＃＃＃ 例：$p=120$この問題には 3 つの解決策が記載されています。$$(20,48,52)$$

$$(24,45,51)$$

$$(30,40,50)$$確かに：

-$20^2+48^2=52^2$-$24^2+45^2=51^2$-$30^2+40^2=50^2$それで$p=120$ちょうど 3 つの解決策があります。

 ## 2. Python の実装```python
def count_solutions(p):
    """
    Count the number of integer right-triangle solutions
    with perimeter p.
    """
    count = 0

    # Ensure a <= b < c
    for a in range(1, p // 3 + 1):
        for b in range(a, (p - a) // 2 + 1):
            c = p - a - b

            # Check Pythagorean condition
            if a * a + b * b == c * c:
                count += 1

    return count

max_count = 0
best_p = 0

# Test every perimeter up to 1000
for p in range(1, 1001):
    solutions = count_solutions(p)

    if solutions > max_count:
        max_count = solutions
        best_p = p

print(best_p)
```---
