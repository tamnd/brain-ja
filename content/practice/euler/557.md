[プロジェクト オイラー問題 557](https://projecteuler.net/problem=557)

 ## 解決策

 **答え:**`2699929328`元の三角形に面積を持たせる$$T=a+b+c+d.$$アフィン座標を使用して、三角形を次の位置に配置します。$$A=(0,0),\quad B=(1,0),\quad C=(0,1).$$2 人のセビアンを次から始めましょう$A$そして$B$、パラメータで反対側を満たします$x,y\in(0,1)$。 4 つの誘導領域を次のように書くと、$x$そして$y$、幾何学的パラメータを削除すると、重要なディオファントス条件が得られます。$$d(a+b)(a+c)=bc(2a+b+c).$$均質化と並べ替えの後、因数分解が得られます。$$(a+b)(a+c) \mid bc(2a+b+c).$$標準的な除数パラメータ化により、すべての有効な 4 倍数が正の整数によって一意に生成されることが示されます。$p,q,r$と$$a=pq,\qquad b=pr,\qquad c=qr,\qquad d=(p+q-r)r,$$ポジティブな傾向に左右され、$b\le c$。 

総面積は、$$T=(p+q)(q+r).$$したがって$$S(N)=\sum_{\substack{(p+q)(q+r)\le N\\ p,q,r>0}} (p+q)(q+r),$$対称条件付き$b\le c$二重カウントの削除。 

効率的な列挙は約$O(N\log N)$ループオーバーすることで$q$、境界$p,r$、対応する合計を直接累積します。 

Python の実装は次のとおりです。```python
def S(N):
    total = 0

    for q in range(1, N + 1):
        for p in range(1, N + 1):
            if (p + q) * (q + 1) > N:
                break

            rmax = N // (p + q) - q
            if rmax < q:
                continue

            for r in range(q, rmax + 1):
                total += (p + q) * (q + r)

    return total

print(S(20))      # 259
print(S(10000))   # 2699929328
```小切手$$S(20)=259$$matches the value given in the problem statement, confirming the derivation and enumeration.
