[プロジェクト オイラー問題 584](https://projecteuler.net/problem=584)

 ## 解決策

 **答え:**`32.83822408`させて$T$円形の 365 日カレンダーで **7 日以内に 4 人の誕生日**を最初に取得したとき、部屋にいる人の数になります。 

重要な所見は次のとおりです。 

- 「互いに 7 日以内」とは、4 人の誕生日がすべて、あるブロック内にあることを意味します。$8$連続した暦日。 
- 年末に誕生日が重なるため、カレンダーは循環します。 

定義する$$S_n=\Pr(T>n),$$その後の確率$n$人々、**ブロックはありません**$8$連続した日数が含まれる$4$またはそれ以上の誕生日。 

それから$$\mathbb E[T]=\sum_{n\ge0} S_n.$$したがって、問題は、禁止されたパターンを回避して誕生日の構成をカウントすることに帰着します。 

---

 # 1. 有効な構成を数える

 しましょう$c_i$その日の誕生日の数になります$i$、 どこ$i=1,\dots,365$。 

「7日以内に誕生日が4人いない」という条件はまさに$$c_i+c_{i+1}+\cdots+c_{i+7}\le 3$$連続 8 日間の周期ブロックごとに。 

固定占有ベクトルの場合$(c_1,\dots,c_{365})$合計で$n$、$$\sum_i c_i=n,$$それが認識されているラベル付き誕生日割り当ての数$$\frac{n!}{\prod_i c_i!}.$$したがって、$$S_n = \frac{n!}{365^n} \sum_{\substack{(c_i)\\ \text{all 8-block sums }\le3\\ \sum c_i=n}} \frac1{\prod_i c_i!}.$$---

 # 2. 状態遷移動的計画法

 8 日間の制約を適用するには、カレンダーを毎日調べます。 

状態は過去 7 日間の占有率を保存します。$$(c_{i-6},\dots,c_i).$$占有日を新たに追加する場合$x$、私たちは必要とします$$x+c_{i-6}+\cdots+c_i \le 3.$$したがって、状態の総数は少なくなります。$$\binom{7+3}{7}=120.$$で重み付けされた状態間の伝達グラフを構築します。$$\frac{z^x}{x!}.$$カレンダーは周期的であるため、有効な年間構成は長さの閉じた散歩に対応します。$365$。 

の係数を抽出すると、$z^n$の加重カウントを与えます$S_n$。 

ついに、$$\mathbb E[T] = \sum_{n\ge0} S_n.$$---

 #3. Pythonの実装```python
from math import factorial
import numpy as np

DAYS = 365
GROUP = 4
WINDOW = 7
MAX_N = 100   # far beyond where probabilities become negligible

def generate_states(length, limit):
    """
    Generate all tuples of given length whose entries are
    nonnegative integers with total sum < limit.
    """
    states = []

    def dfs(pos, remaining, cur):
        if pos == length:
            states.append(tuple(cur))
            return

        for x in range(remaining):
            cur.append(x)
            dfs(pos + 1, remaining - x, cur)
            cur.pop()

    dfs(0, limit, [])
    return states

# State length = WINDOW = 7 previous days
states = generate_states(WINDOW, GROUP)

index = {s: i for i, s in enumerate(states)}
S = len(states)

# Build transitions
transitions = [[] for _ in range(S)]

for s in states:
    i = index[s]
    current_sum = sum(s)

    # occupancy on next day
    for x in range(GROUP - current_sum):

        next_state = s[1:] + (x,)
        j = index[next_state]

        weight = 1.0 / factorial(x)

        transitions[i].append((j, x, weight))

# dp[start_state, current_state, n]
dp = np.zeros((S, S, MAX_N + 1), dtype=np.float64)

for i in range(S):
    dp[i, i, 0] = 1.0

# advance through all 365 days
for _ in range(DAYS):

    ndp = np.zeros_like(dp)

    for s in range(S):

        arr = dp[:, s, :]

        for ns, x, w in transitions[s]:

            ndp[:, ns, x:] += arr[:, :MAX_N + 1 - x] * w

    dp = ndp

# closed walks give cyclic configurations
A = np.zeros(MAX_N + 1)

for i in range(S):
    A += dp[i, i, :]

# survival probabilities
survival = np.zeros(MAX_N + 1)

for n in range(MAX_N + 1):
    survival[n] = factorial(n) * A[n] / (DAYS ** n)

expected_value = survival.sum()

print(expected_value)
print(round(expected_value, 8))
```---
