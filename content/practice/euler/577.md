 ## 解決策

 **答え:**`265695031399260211`三角格子を基底ベクトルによって生成させます。$$e_1=(1,0), \qquad e_2=\left(\tfrac12,\tfrac{\sqrt3}{2}\right).$$一辺の長さの大きな正三角形$n$すべての格子点で構成されます$$(i,j)\qquad (i\ge0,\ j\ge0,\ i+j\le n).$$頂点が格子点である正六角形をすべて数えなければなりません。 

---

 #1. 数学的分析

 ## ステップ 1: すべての格子の正六角形を記述する

 六角形の 1 つの辺ベクトルをとります。$$u=a e_1+b e_2, \qquad a,b\ge0, \qquad (a,b)\ne(0,0).$$回転$60^\circ$次の辺ベクトルを与える$$v=-b e_1+(a+b)e_2.$$正六角形は辺ベクトルを持って歩き回ることで得られます$$u,\ v,\ v-u,\ -u,\ -v,\ u-v.$$したがって、すべての格子正六角形は整数によって決定されます。$a,b\ge0$、どちらもゼロではありません。 

させて$$t=a+b.$$ここで、配置可能な数を決定します。 

---

 ## ステップ 2: 含まれる三角形のサイズ

 1 つの頂点が原点に来るように六角形を移動します。 

その頂点は次のようになります。$$(0,0),\quad (a,b),\quad (a-b,a+2b),\quad (-b,a+b),\quad (-a-b,b),\quad (-a,-b).$$すべての座標を非負にするようにシフトすると、六角形は辺の長さの最小の正三角形の内側に正確に収まります。$$3(a+b)=3t.$$したがって:

 - 六角形のタイプ$t$側面の大きな三角形の内側のどこにでも配置できます$n$、
 - 辺の三角形を提供$3t$その中に収まります。 

配置の数は、側面の格子の平行移動の数に等しくなります。$3t$辺の内側の三角形 -$n$三角形：$$\frac{(n-3t+1)(n-3t+2)}2.$$---

 ## ステップ 3: 固定されたさまざまな形状を数える$t$固定用$$t=a+b,$$可能性は$$(a,b)=(0,t),(1,t-1),\dots,(t-1,1),$$その通り$t$明確な方向/形状。 

したがって、$$H(n)=\sum_{t=1}^{\lfloor n/3\rfloor} t\cdot \frac{(n-3t+1)(n-3t+2)}2.$$したがって、最後のタスクは$$\sum_{n=3}^{12345} H(n).$$---

 ## ステップ 4: 例に対して検証する

 ###$n=3$のみ$t=1$:$$H(3)=1\cdot \frac{1\cdot2}{2}=1.$$正しい。 

---

 ###$n=6$

$$H(6) = 1\cdot \frac{4\cdot5}{2} + 2\cdot \frac{1\cdot2}{2} = 10+2=12.$$正しい。 

---

 ###$n=20$

$$H(20) = \sum_{t=1}^{6} t\cdot \frac{(20-3t+1)(20-3t+2)}2 =966.$$正しい。 

---

 #2. Pythonの実装```python
def H(n):
    total = 0

    # t = a + b
    for t in range(1, n // 3 + 1):

        # Number of placements of a side-(3t) triangle
        placements = (n - 3 * t + 1) * (n - 3 * t + 2) // 2

        # There are exactly t distinct hexagon shapes
        total += t * placements

    return total

# Compute the required sum
answer = sum(H(n) for n in range(3, 12346))

print(answer)
```---
