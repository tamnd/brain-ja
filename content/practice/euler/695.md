[プロジェクト オイラー問題 695](https://projecteuler.net/problem=695)

 ## 解決策

 **答え:**`0.1017786859`3つのポイントとしましょう$$P_i=(x_i,y_i)\qquad (i=1,2,3),$$すべての座標が独立して均一になる$[0,1]$。 

各ペアごとに$i<j$、長方形は$\overline{P_iP_j}$対角線には面積があるので$$A_{ij}=|x_i-x_j|\,|y_i-y_j|.$$次の中で**2番目に大きい**の期待値が必要です。$$A_{12},A_{13},A_{23}.$$---

 #1. 数学的分析

 ## ステップ 1: 座標を並べ替える

 並べ替える$x$-座標:$$x_{(1)}<x_{(2)}<x_{(3)}.$$ギャップを定義する$$a=x_{(2)}-x_{(1)},\qquad b=x_{(3)}-x_{(2)}.$$それから 3 人がペアで$x$-距離は$$a,\quad b,\quad a+b.$$同様に並べ替えた後、$y$-座標、$$u=y_{(2)}-y_{(1)},\qquad v=y_{(3)}-y_{(2)},$$そしてペアごとに$y$-距離は$$u,\quad v,\quad u+v.$$内のラベルの相対的な順序は、$y$-direction は次のいずれかになります。$6$順列はすべて同じ確率で起こります。 

---

 ## ステップ 2: ジオメトリを正規化する

 紹介する$$r=a+b,\qquad s=u+v,$$そして$$x=\frac{a}{a+b},\qquad y=\frac{u}{u+v}.$$それから$$a=rx,\qquad b=r(1-x),$$

$$u=sy,\qquad v=s(1-y).$$標準的なヤコビアン計算では次のことがわかります。 

-$r$そして$s$密度に依存しない$$f(r)=6r(1-r),\qquad 0<r<1,$$-$x,y$は独立した一様確率変数です$[0,1]$、
 - そして 4 つの変数はすべて独立しています。 

また、$$\mathbb E[r]=\mathbb E[s]=\frac12, \qquad \mathbb E[rs]=\frac14.$$したがって、問題は純粋な 2D 積分に帰着します。$(x,y)$。 

---

 # 2. 2 つの置換タイプ

 本質的に異なるケースは 2 つだけです。 

---

 ## ケース A: 同じ順序$x$そして$y$これが起こるのは、$2$の$6$順列。 

正規化された領域は、$$xy,\qquad (1-x)(1-y),\qquad 1.$$以来$1$は常に最大であり、2 番目に大きいのは$$M_1=\max\!\big(xy,(1-x)(1-y)\big).$$今$$xy>(1-x)(1-y) \iff x+y>1.$$したがって$$\begin{aligned} I_1 &=\iint_{[0,1]^2} M_1\,dx\,dy \\ &=2\int_0^1\int_{1-x}^1 xy\,dy\,dx \\ &=\frac{5}{12}. \end{aligned}$$---

 ## ケース B: 交差順序付け

 これは他の人にも起こります$4$順列。 

正規化された領域は次のようになります。$$x,\qquad y,\qquad (1-x)(1-y).$$したがって、2 番目に大きい値は、これら 3 つの数値の中央値です。$$M_2=\operatorname{med}\big(x,y,(1-x)(1-y)\big).$$対称性の使用$x\leftrightarrow y$、以上でのみ積分します$x\le y$。 

定義する$$z=(1-x)(1-y).$$固定用$x\le y$：

- もし$z\ge y$、中央値$=y$、
- もし$x\le z\le y$、中央値$=z$、
- もし$z\le x$、中央値$=x$。 

遷移曲線は次のとおりです。$$y=\frac{1-x}{2-x}, \qquad y=\frac{1-2x}{1-x}.$$区分積分を実行した後、$$I_2 = -\frac{23}{12} +\ln\!\left(\frac{1+\sqrt5}{2(\sqrt5-1)}\right) +\frac{11\sqrt5}{12}.$$数値的には、$$I_2\approx 0.40233878226740216.$$---

 #3. ケースを組み合わせる

 望ましい期待は、$$\mathbb E[A] = \mathbb E[rs] \left( \frac13 I_1+\frac23 I_2 \right).$$以来$\mathbb E[rs]=\frac14$、$$\boxed{ \mathbb E[A] = \frac14\left(\frac13\cdot\frac5{12}+\frac23 I_2\right) }.$$置き換える$I_2$そして簡略化すると：$$\boxed{ \mathbb E[A] = -\frac{41}{144} -\frac{\ln 2}{3} +\frac{\ln(3+\sqrt5)}{6} +\frac{11\sqrt5}{72} }.$$数値的には、$$\mathbb E[A] \approx 0.1017786859334559123.$$小数点以下 10 桁に四捨五入:$$0.1017786859.$$---

 #4. Pythonの実装```python
from decimal import Decimal, getcontext
import math

# use high precision
getcontext().prec = 50

sqrt5 = Decimal(5).sqrt()

# Expected value formula:
# E =
# -41/144
# - ln(2)/3
# + ln(3+sqrt(5))/6
# + 11*sqrt(5)/72

E = (
    Decimal(-41) / Decimal(144)
    - Decimal(math.log(2)) / Decimal(3)
    + Decimal(math.log(float(3 + sqrt5))) / Decimal(6)
    + Decimal(11) * sqrt5 / Decimal(72)
)

print(E)
print(round(E, 10))
```---
