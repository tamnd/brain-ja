 ## 解決策

 **答え:**`756872327473`条件の整数解を求めます$$P(\text{BB})=\frac12$$ボックスに含まれるもの$b$ブルーディスクと$r$赤いディスク、合計$$n=b+r.$$交換なしで青いディスクを 2 枚引く確率は、$$\frac{b}{n}\cdot\frac{b-1}{n-1}=\frac12.$$したがって、解決しなければなりません$$\frac{b(b-1)}{n(n-1)}=\frac12.$$同様に、$$2b(b-1)=n(n-1).$$最初の解決策を求められます。$$n>10^{12}.$$---

 # ステップ 1 — 方程式を変換する

 から開始$$2b(b-1)=n(n-1).$$拡大する：$$2b^2-2b=n^2-n.$$乗算する$4$:$$8b^2-8b=4n^2-4n.$$正方形を完成させます。$$8b^2-8b+2=4n^2-4n+1.$$したがって$$2(2b-1)^2=(2n-1)^2+1.$$再配置:$$(2n-1)^2-2(2b-1)^2=-1.$$定義する$$x=2n-1,\qquad y=2b-1.$$次に、ペル方程式を取得します。$$x^2-2y^2=-1.$$---

 # ステップ 2 — ペル方程式の漸化式

 負のペル方程式$$x^2-2y^2=-1$$再帰的に生成される無限に多くの解があります。 

最初のいくつかは次のとおりです。$$(1,1),\ (7,5),\ (41,29),\ (239,169),\dots$$これらは以下に対応します。$$n=\frac{x+1}{2},\qquad b=\frac{y+1}{2}.$$例えば：

-$x=239,\ y=169$与える$$n=120,\qquad b=85,$$これは問題文と一致します。 

解の標準的な反復は次のとおりです。$$x_{k+1}=3x_k+4y_k,$$

$$y_{k+1}=2x_k+3y_k.$$に戻す$(n,b)$、次のようになります。$$n_{k+1}=3n_k+4b_k-3,$$

$$b_{k+1}=2n_k+3b_k-2.$$既知の解決策から始める$$(n,b)=(21,15),$$まで、より大きなソリューションを繰り返し生成します。$n>10^{12}$。

 # ステップ 3 — Python の実装```python
# Project Euler Problem 100

LIMIT = 10**12

# Initial known solution:
# total discs = 21
# blue discs  = 15
n = 21
b = 15

# Generate larger solutions using the Pell recurrence
while n <= LIMIT:
    n, b = (
        3 * n + 4 * b - 3,
        2 * n + 3 * b - 2
    )

print(b)
```---

 # ステップ 5 — 小規模なケースを確認する

 から始まる$(n,b)=(21,15)$:

 次回の反復では次が得られます。$$n=120,\qquad b=85.$$チェック：$$\frac{85}{120}\cdot\frac{84}{119} = \frac{7140}{14280} = \frac12.$$正しい。 

繰り返しを続けると、最終的に次の結果が得られます。$$n=1\,070\,379\,110\,497,$$

$$b=756\,872\,327\,473.$$確かに、$$n > 10^{12}.$$---

 # 最終確認

- 結果の合計が次を超える$10^{12}$。
