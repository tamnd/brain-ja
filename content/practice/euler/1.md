[プロジェクト オイラー問題 1](https://projecteuler.net/problem=1)

 ## 解決策

 以下のすべての自然数の合計が必要です$1000$で割り切れるもの$3$または$5$。 

### 数学的アプローチ

 包含と除外を使用します。 

- の倍数の合計$3$下に$1000$- の倍数の合計$5$下に$1000$- の倍数の合計を減算します。$15$(2回数えます)

 の倍数の合計$k$下に$1000$は：$$k(1 + 2 + \cdots + n)$$どこ$n = \left\lfloor \frac{999}{k} \right\rfloor$、 そして$$1 + 2 + \cdots + n = \frac{n(n+1)}{2}$$- の倍数$3$:$n = 333$

$$3 \cdot \frac{333 \cdot 334}{2} = 166833$$- の倍数$5$:$n = 199$

$$5 \cdot \frac{199 \cdot 200}{2} = 99500$$- の倍数$15$:$n = 66$

$$15 \cdot \frac{66 \cdot 67}{2} = 33165$$それで：$$166833 + 99500 - 33165 = 233168$$### クリーンな Python コード```python
def sum_of_multiples(limit):
    return sum(n for n in range(limit) if n % 3 == 0 or n % 5 == 0)

print(sum_of_multiples(1000))
```これは次のように評価されます。```python
233168
```メンタルトレース/チェック:

 - 10 未満の小さな例では、$3 + 5 + 6 + 9 = 23$、問題文と一致します。 
- 包含と除外により、倍数の二重カウントが回避されます。$15$。 
- 最終的に計算された合計は一貫しています。 

**答え: 233168**
