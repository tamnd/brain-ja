[プロジェクト オイラー問題 610](https://projecteuler.net/problem=610)

 ## 解決策

 **答え:**`319.30207833`させて$E(s)$現在書き込まれている文字列がローマ数字の接頭辞である場合に期待される最終値を示します$s$。 

重要な所見は次のとおりです。 

- 文字を追加しても文字列が _minimal_ ローマ数字の有効な接頭辞に保たれる場合は、新しい状態に移行します。 
- それ以外の場合、その文字は無視されます。 
- いつ`#`出現（確率）$0.02$）、すぐに停止します。 

最小限の形式のローマ数字は標準的な分解を持っています$$M^a \cdot H \cdot T \cdot O$$どこ：

-$a \ge 0$、
 -$H \in \{ "", C, CC, CCC, CD, D, DC, DCC, DCCC, CM \}$、
 -$T \in \{ "", X, XX, XXX, XL, L, LX, LXX, LXXX, XC \}$、
 -$O \in \{ "", I, II, III, IV, V, VI, VII, VIII, IX \}$。 

したがって、有効な数値の言語全体は、境界のない先頭を除いて、有限の接頭辞オートマトンです。$M$さんの。 

---

 #1. 再発

 ある状態を仮定します$s$価値がある$v(s)$、 そして$k$有効な次の文字。 

それから$$E(s) = 0.02\,v(s) + 0.14\sum_{t} E(t) + (0.98-0.14k)E(s)$$ここで、合計はすべての有効な次の状態にわたって実行されます。$t$。 

並べ替え:$$(0.02+0.14k)E(s) = 0.02\,v(s)+0.14\sum_t E(t)$$で割る$0.02$、$$(1+7k)E(s) = v(s)+7\sum_t E(t).$$したがって$$\boxed{ E(s)=\frac{v(s)+7\sum_t E(t)}{1+7k} }$$空でないすべてのサフィックス状態に対して。 

---

 #2. 無限の処理$M$-チェーン

 現在の数字を次のようにします$$M^a s$$どこ$s$含まれていません$M$。 

書く$$E(M^a s)=1000a+F(s).$$再帰式に代入すると、次の依存関係がわかります。$a$完全にキャンセルされ、接尾辞の状態に有限系が残ります。$s$。 

空のサフィックス状態の場合:$$F(\varepsilon) = \frac{7000+7\sum F(t)}{43}$$合計が 6 つの 1 文字で始まる部分を超えているところ$$I,V,X,L,C,D.$$他のすべての状態は、上記の有限反復を満たします。

 #3. Pythonの実装```python
from functools import lru_cache

# Minimal Roman blocks
ones = ["", "I", "II", "III", "IV",
        "V", "VI", "VII", "VIII", "IX"]

tens = ["", "X", "XX", "XXX", "XL",
        "L", "LX", "LXX", "LXXX", "XC"]

hundreds = ["", "C", "CC", "CCC", "CD",
            "D", "DC", "DCC", "DCCC", "CM"]

# All minimal numerals from 0..999
nums = [
    hundreds[h] + tens[t] + ones[o]
    for h in range(10)
    for t in range(10)
    for o in range(10)
]

# Value of each suffix numeral
value = {}
prefixes = {""}

for n, s in enumerate(nums):
    value[s] = n
    for i in range(len(s) + 1):
        prefixes.add(s[:i])

letters = "IVXLCD"

# Valid transitions
trans = {}

for p in prefixes:
    nxt = []
    for ch in letters:
        q = p + ch
        if q in prefixes:
            nxt.append(q)
    trans[p] = nxt

# Solve backwards by decreasing length
states = sorted(prefixes, key=len, reverse=True)

F = {}

for s in states:
    if s == "":
        continue

    k = len(trans[s])

    F[s] = (
        value[s]
        + 7 * sum(F[t] for t in trans[s])
    ) / (1 + 7 * k)

# Empty state:
# one transition to another M,
# six transitions to I,V,X,L,C,D
F0 = (
    7000
    + 7 * sum(F[t] for t in trans[""])
) / 43

print("{:.8f}".format(F0))
```---

 #4. コードのチュートリアル

 - 最小限のローマ数字をすべて作成します。$0$に$999$。 
- 有効なプレフィックスをすべて収集します。 
- プレフィックス間の遷移グラフを構築します。 
- 遷移ごとに文字列の長さが増加するため、期待方程式を逆方向に解きます。 
- 先頭の無限連鎖を処理する$M$分析的には。 
- 期待値を小数点以下 8 桁まで出力します。

```---

 #5. 最終検証

 結果は妥当です:

 - 予想されるリード$M$が大まかに貢献します$$1000 \cdot \frac{0.14}{0.86} \approx 162.79$$- 残りのローマ字接尾辞は別の要素に寄与します$\sim 140$。 

合計約$300$、計算された値と一致します。
