[プロジェクト オイラー問題 828](https://projecteuler.net/problem=828)

 ## 解決策

 **答え:**`148693670`利用可能な数値の複数セットを次のようにします。$A$、定義します$F(A)$以下から取得できるすべての正の整数のセットとして$A$使用:

 - 各数字は最大 1 回、
 - 操作$+,-,\times,\div$、
 - 中間結果は正の整数のみ。 

重要な観察は、すべての有効な式が 2 つの互いに素な部分式をルートで結合したバイナリ ツリーに対応しているということです。 したがって：$$F(A)=\bigcup_{B\subset A,\ B\neq \emptyset,\ B\neq A} \{x\circ y : x\in F(B),\ y\in F(A\setminus B)\}$$どこ$\circ\in\{+,-,\times,\div\}$、以下の対象となります。 

-$x-y>0$、
 -$x\equiv 0\pmod y$分割のため。 

開始数値が 6 つしかないため、サブセットごとに達成可能なすべての値をメモ化できます。 

それぞれの課題について:

 1. 6 つの数値の空でない部分集合をすべて列挙します。 
2. そのサブセットに対して達成可能なすべての正の整数を計算します。 
3. 目標が達成可能な場合、スコアは目標を生成するすべてのサブセットのうちの最小サブセット合計になります。 
4. それ以外の場合、スコアは$0$。 

最後に計算します$$\sum_{n=1}^{200} 3^n s_n \pmod{1005075251}.$$例:$$211:(2,3,4,6,7,25)$$最低スコアは$$(25-2)(6+3)+4 = 211$$スコア付き$$25+2+6+3+4=40.$$それで$s_1=40$。 

クリーンな Python 実装は次のとおりです。```python
from functools import lru_cache

MOD = 1005075251

def reachable(nums):
    nums = tuple(sorted(nums))

    @lru_cache(None)
    def solve(state):
        state = tuple(state)

        if len(state) == 1:
            return {state[0]}

        out = set()
        n = len(state)

        # partition into two nonempty parts
        for mask in range(1, (1 << n) - 1):
            A = [state[i] for i in range(n) if mask & (1 << i)]
            B = [state[i] for i in range(n) if not (mask & (1 << i))]

            # avoid symmetric duplicates
            if len(A) > len(B):
                continue

            SA = solve(tuple(A))
            SB = solve(tuple(B))

            for x in SA:
                for y in SB:
                    out.add(x + y)
                    out.add(x * y)

                    if x > y:
                        out.add(x - y)
                        if x % y == 0:
                            out.add(x // y)

                    elif y > x:
                        out.add(y - x)
                        if y % x == 0:
                            out.add(y // x)

        return out

    return solve(nums)

def min_score(target, nums):
    best = None

    for mask in range(1, 1 << len(nums)):
        subset = [nums[i] for i in range(len(nums)) if mask & (1 << i)]

        if target in reachable(tuple(subset)):
            s = sum(subset)
            if best is None or s < best:
                best = s

    return best or 0

# read the 200 challenges
ans = 0
pow3 = 1

with open("number-challenges.txt") as f:
    for i, line in enumerate(f, start=1):
        target, rest = line.strip().split(":")
        target = int(target)
        nums = list(map(int, rest.split(",")))

        s = min_score(target, nums)

        pow3 = (pow3 * 3) % MOD
        ans = (ans + pow3 * s) % MOD

print(ans)
```メモ化は重要な最適化です。 

- あるだけです$2^6-1=63$空ではないサブセット、
 - 各サブセットは 1 回解決されます。 
- 取得可能なすべての値が繰り返し再利用されます。 

これは、200 の問題すべてに対して快適に高速に実行されます。
