[プロジェクト オイラー問題 755](https://projecteuler.net/problem=755)

 ## 解決策

 **答え:**`2877071595975576960`させて$$F=\{1,2,3,5,8,\dots\}$$そしてさせてください$f(n)$の部分集合の数になります$F$その要素の合計は$n$。 

それから$$S(N)=\sum_{k=0}^N f(k)$$**合計が最大以下であるフィボナッチ数のすべてのサブセットをカウントします$N$**。 

したがって、タスクは次のとおりです。 

> 合計を使用して個別のフィボナッチ数の部分集合を数える$\le 10^{13}$。 

非常に効率的な再帰が機能します。 

利用可能なフィボナッチ数が$F_0,\dots,F_i$、その後:

 - どちらも**使用しません**$F_i$、
 - または**使用**$F_i$。 

したがって、次のようになります。$$C(i,x)=C(i-1,x)+C(i-1,x-F_i).$$また、重要なショートカットも使用します。 

もし$$x \ge \sum_{k=0}^i F_k,$$その場合、すべてのサブセットが許可されるため、$$C(i,x)=2^{i+1}.$$これにより、状態の数が大幅に減少します。 

Python コード:```python
from functools import lru_cache

N = 10**13

# Build Fibonacci numbers: 1,2,3,5,...
fibs = [1, 2]
while fibs[-1] + fibs[-2] <= N:
    fibs.append(fibs[-1] + fibs[-2])

# Prefix sums
prefix = []
s = 0
for x in fibs:
    s += x
    prefix.append(s)

@lru_cache(None)
def count_subsets(i, limit):
    # Number of subsets using fibs[0..i] with sum <= limit

    if limit < 0:
        return 0

    if i < 0:
        return 1  # empty subset

    # If limit already exceeds total possible sum,
    # every subset is valid.
    if limit >= prefix[i]:
        return 1 << (i + 1)

    # Can't use fibs[i]
    if fibs[i] > limit:
        return count_subsets(i - 1, limit)

    # Exclude or include fibs[i]
    return (
        count_subsets(i - 1, limit)
        + count_subsets(i - 1, limit - fibs[i])
    )

answer = count_subsets(len(fibs) - 1, N)

print(answer)
```与えられた例の検証:
