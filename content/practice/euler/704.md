 ## 解決策

 **答え:**`501985601490518144`クンマーの定理を使用すると、次のようになります。$$g(n,m)=v_2\!\binom{n}{m}$$加算時のキャリー数に等しい$m$そして$n-m$バイナリで。 

可能な最大のキャリー数は、可能な限り最長の 1 のサフィックスを介してキャリーを強制するときに発生します。$n$。 これにより、$$F(n)=\lfloor \log_2 n \rfloor - v_2(n+1) + \mathbf 1_{\,n+1\text{ is a power of }2}.$$同様に:

 - もし$n\neq 2^k-1$、$$F(n)=\lfloor \log_2 n \rfloor-v_2(n+1),$$- そして$F(2^k-1)=0$。 

したがって$$S(N)=\sum_{n=1}^N \lfloor \log_2 n \rfloor -\sum_{n=1}^N v_2(n+1) +\#\{k:2^k-1\le N\}.$$次に各項を計算します。 

---

 ### 1. 床対数の合計

 しましょう$L=\lfloor \log_2 N\rfloor$。$$\sum_{n=1}^N \lfloor \log_2 n \rfloor = \sum_{k=0}^{L-1} k\,2^k +L(N-2^L+1).$$使用する$$\sum_{k=0}^{L-1} k2^k=(L-2)2^L+2,$$私たちは得ます$$A=(L-2)2^L+2+L(N-2^L+1).$$---

 ### 2. 以下の合計$v_2(n+1)$

$$\sum_{n=1}^N v_2(n+1) = \sum_{m=2}^{N+1} v_2(m) = v_2((N+1)!).$$ルジャンドルの公式によれば、$$v_2((N+1)!)=(N+1)-s_2(N+1),$$どこ$s_2(x)$は 2 進数の合計です。 

それで$$B=(N+1)-s_2(N+1).$$---

 ### 3. メルセンヌ数の数$$C=\left\lfloor \log_2(N+1)\right\rfloor.$$- -

のために$N=10^{16}$:

 -$L=\lfloor \log_2(10^{16})\rfloor=53$、
 -$s_2(10^{16}+1)=27$。 

代入:$$S(10^{16}) = 501985601490518144.$$コンパクトな Python 実装は次のとおりです。```python
def S(N):
    L = N.bit_length() - 1

    A = ((L - 2) << L) + 2 + L * (N - (1 << L) + 1)
    B = (N + 1) - bin(N + 1).count("1")
    C = (N + 1).bit_length() - 1

    return A - B + C

print(S(10**16))
```これにより、指定されたチェックも再現されます。 

-$S(100)=389$-$S(10^7)=203222840$したがって、導出は一貫しています。
