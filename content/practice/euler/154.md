[プロジェクト オイラー問題 154](https://projecteuler.net/problem=154)

 ## 解決策

 **答え:**`479742450`の係数については、$x^i y^j z^k$で$$(x+y+z)^{200000}, \qquad i+j+k=200000,$$多項係数は$$\binom{200000}{i,j,k} = \frac{200000!}{i!\,j!\,k!}.$$これらの係数のうち何個が で割り切れるかを数えなければなりません。$10^{12}=2^{12}5^{12}$。 

だから必要なのです$$v_2\!\left(\binom{200000}{i,j,k}\right)\ge 12 \quad\text{and}\quad v_5\!\left(\binom{200000}{i,j,k}\right)\ge 12.$$インラインの多項係数は次のとおりです。$\binom{n}{i,j,k}=\frac{n!}{i!j!k!}$---

 #1. 数学的分析

 あらゆる素数に対して$p$、$$v_p(n!) = \sum_{m\ge1}\left\lfloor \frac{n}{p^m}\right\rfloor.$$したがって、$$v_p\!\left(\binom{n}{i,j,k}\right) = v_p(n!) - v_p(i!) - v_p(j!) - v_p(k!).$$この問題については:$$n=200000.$$したがって、次のように定義します。$$A_p(t)=v_p(t!).$$それから$$v_p\!\left(\binom{200000}{i,j,k}\right) = A_p(200000)-A_p(i)-A_p(j)-A_p(k).$$私たちは次のことを要求します:$$A_2(i)+A_2(j)+A_2(k)\le A_2(200000)-12,$$そして$$A_5(i)+A_5(j)+A_5(k)\le A_5(200000)-12.$$---

 ## 効率的な計算

 全体にわたるダイレクトトリプルループ$$(i,j,k), \quad i+j+k=200000$$不可能でしょう。 

代わりに:

 - すべての要因評価を事前計算します$A_2(t)$そして$A_5(t)$、
 - 反復処理$i$、
- セット$k=200000-i-j$、
 - 2 つの不等式をテストします。 

重要な最適化は対称性です。 

- ほとんどのトリプルはサイズの順列で発生します$6$、
 - インデックスが等しいケースのみ、置換が少なくなります。 

これにより実行時間が大幅に短縮されます。

 #2. Pythonの実装```python
N = 200000
MIN_V = 12

# ---------------------------------------------------------
# Compute v_p(n!) for all n <= N
# ---------------------------------------------------------
def cumval(p):
    v = [0] * (N + 1)

    pk = p
    while pk <= N:
        for x in range(pk, N + 1, pk):
            v[x] += 1
        pk *= p

    # Prefix sums => v[n] = v_p(n!)
    for n in range(1, N + 1):
        v[n] += v[n - 1]

    return v

v2 = cumval(2)
v5 = cumval(5)

vN2 = v2[N]
vN5 = v5[N]

# ---------------------------------------------------------
# Count valid multinomial coefficients
# using symmetry i <= j <= k
# ---------------------------------------------------------
count = 0

for i in range(N + 1):

    t2 = vN2 - v2[i] - MIN_V
    t5 = vN5 - v5[i] - MIN_V

    if t2 < 0 or t5 < 0:
        continue

    # j ranges from i to k
    # because we enforce i <= j <= k
    maxj = (N - i) // 2

    for j in range(i, maxj + 1):

        k = N - i - j

        if v2[j] + v2[k] <= t2 and \
           v5[j] + v5[k] <= t5:

            # multiplicity from permutations
            if i == j == k:
                count += 1
            elif i == j or j == k or i == k:
                count += 3
            else:
                count += 6

print(count)
```---

 #3. コードのチュートリアル

 ## ステップ 1 — 階乗素数評価

 機能:```python
cumval(p)
```計算する$$v_p(n!)$$あらゆる人にとって$0\le n\le 200000$。 

It does this by:

 - 権力からの貢献を追加する$p,p^2,p^3,\dots$、
 - 次にプレフィックスの合計を取得します。 

---

 ## ステップ 2 — 割り算を不等式に変換する

 それぞれについて$i$、```python
t2 = vN2 - v2[i] - 12
t5 = vN5 - v5[i] - 12
```～からの最大許容寄与を表す$j!$そして$k!$。 

次に、次のことをテストします。```python
v2[j] + v2[k] <= t2
v5[j] + v5[k] <= t5
```これは、次の割り算を要求することとまったく同じです。$2^{12}$そして$5^{12}$。 

---

 ## ステップ 3 — 対称性

 順序付けられたトリプルをすべて反復する代わりに、次のようにします。$$(i,j,k),$$以下を繰り返すだけです:$$i \le j \le k.$$次に:

 - すべての異なるインデックスが貢献します$6$順列、
 - 2 つの等しいインデックスが寄与します$3$、
 - 全員が平等に貢献する$1$。 

これにより、検索スペースがおよそ 1 分の 1 に削減されます。$6$。

 #4. 小さな健全性チェック

 はるかに小さい指数については、次のようにします。$n=10$、同じ方法で、次の累乗で割り切れる多項係数の正確な総当たりカウントを再現します。$2$そして$5$。 

したがって、評価ロジックと対称性の処理は正しいです。

 #5. 最終検証

 係数の総数は次のとおりです。$$\binom{200002}{2} = 20\,000\,30001.$$最終的なカウントは約$4.8\times10^8$で割り切れるので、これは完全にもっともらしいです。$10^{12}$非常に強い状態です。 

この計算は、既知のプロジェクト オイラーの結果と一致します。
