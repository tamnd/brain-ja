[プロジェクト オイラー問題 105](https://projecteuler.net/problem=105)

 ## 解決策

 **答え:**`73702`セットしましょう$A$どんどん並べ替えられる：$$a_1 < a_2 < \cdots < a_n$$それが **特別な合計セット** であるかどうかをテストする必要があります。これは次のことを意味します。 

1. 2 つの異なる空でないサブセットの合計が等しいことはありません。 
2. あるサブセットが別のサブセットよりも多くの要素を含む場合、その合計はより大きくなければなりません。 

入力ファイルには 100 個の候補セットが含まれており、それぞれの候補セットは$7$–$12$要素。 すべての有効な特別な合計セットを識別し、それらの合計セットの合計を合計する必要があります。 

---

 # 数学的分析

 ## プロパティ 2: 必要かつ十分なチェックを迅速に行う

 セットがソートされていると仮定します。 

最小の場合$k$要素は最大値を**超えません**$k-1$要素を使用すると、次のように形成できます。 

-$k$- 合計が小さい要素のサブセット、
 -$(k-1)$- 合計が大きい要素サブセット、

 条件(2)に違反しています。 

したがって、次のことが必要です。$$a_1 + a_2 + \cdots + a_k > a_n + a_{n-1} + \cdots + a_{n-k+2}$$あらゆる人にとって$k = 2,3,\dots,\lfloor n/2 \rfloor +1$。 

これで十分である理由は次のとおりです。 

- 可能な限り小さい$k$-サブセットが最初です$k$要素、
 - 可能な限り最大の$(k-1)$-サブセットは最後です$k-1$要素。 

したがって、最小の大きなサブセットでも最大の小さなサブセットに勝つ場合は、条件 (2) が常に成り立ちます。 

---

 ## プロパティ 1: サブセット合計の一意性

 以下を確保する必要があります。$$S(B) \ne S(C)$$空ではないすべての個別のサブセットに対して$B,C$。 

セットが小さいため、総当たりアプローチが機能します ($n \le 12$）。 

最大でも次のものがあります。$$2^{12}=4096$$サブセット。 

各サブセットについて:

 - その合計を計算します。 
- セットで保管します。 
- 合計がすでに出現している場合、プロパティ (1) は失敗します。 

これは計算的には簡単です。

 # Pythonの実装```python
from itertools import combinations
import urllib.request

URL = "https://projecteuler.net/resources/documents/0105_sets.txt"

# Download the file
data = urllib.request.urlopen(URL).read().decode()

sets_list = [
    list(map(int, line.split(",")))
    for line in data.strip().splitlines()
]

def satisfies_rule_2(nums):
    """
    Check:
    if |B| > |C| then S(B) > S(C)

    For a sorted list, it is sufficient to verify:
    sum(k smallest) > sum(k-1 largest)
    """
    nums = sorted(nums)
    n = len(nums)

    for k in range(2, n // 2 + 2):
        if sum(nums[:k]) <= sum(nums[-(k - 1):]):
            return False

    return True

def satisfies_rule_1(nums):
    """
    Check that all subset sums are unique.
    """
    n = len(nums)
    seen = set()

    # Enumerate all non-empty subsets
    for mask in range(1, 1 << n):
        subset_sum = 0

        for i in range(n):
            if mask & (1 << i):
                subset_sum += nums[i]

        if subset_sum in seen:
            return False

        seen.add(subset_sum)

    return True

def is_special_sum_set(nums):
    return satisfies_rule_2(nums) and satisfies_rule_1(nums)

answer = 0

for s in sets_list:
    if is_special_sum_set(s):
        answer += sum(s)

print(answer)
```---
