[プロジェクト オイラー問題 488](https://projecteuler.net/problem=488)

 ## 解決策

 **答え:**`216737278`させて$$(a,b,c),\qquad 0<a<b<c$$修正された Nim ゲームの位置であり、2 つの等しい山を作成する動きが禁止されます。 

計算しなければなりません$$F(N)=\sum (a+b+c)$$すべての負けポジション (P ポジション) に対して、$0<a<b<c<N$、そして最後に最後のものを出力します$9$の桁$F(10^{18})$。 

---

 # 数学的分析

 ## 1. 負けているポジションの特徴

 重要な観察は、単純な変更の後、ゲームが通常の Nim になるということです。 

定義する$$x=a+1,\qquad y=b+1,\qquad z=c+1.$$次に、「2 つのヒープを等しくすることはできない」というルールは、終端位置が 1 つの座標が等しい終端位置であるという事実に変換されます。$1$そして他は以下と等しい$2,3$ずらした形で。 

小さな状態を実験して（そしてスプラーグ・グランディ漸化式を使用して帰納的に証明すると）、正確な基準が得られます。$$(a,b,c)\text{ is losing} \iff (a+1)\oplus(b+1)\oplus(c+1)=0,$$どこ$\oplus$はビット単位の XOR を示します。 

したがって、設定すると$$x=a+1,\ y=b+1,\ z=c+1,$$この場合、負けているポジションはまさに、次の条件を満たす明確なプラスのトリプルです。$$x\oplus y\oplus z=0.$$なぜなら$z=x\oplus y$、 一度$x,y$選ばれ、$z$決まっている。 

---

 ## 2. 合計を変換する

 必要です$$0<a<b<c<N.$$シフト後:$$2\le x<y<z\le N.$$合計される数量は、$$a+b+c=(x-1)+(y-1)+(z-1)=x+y+z-3.$$したがって、タスクは合計に帰着します$x+y+z-3$すべての順序付けされていない個別のトリプルにわたって$$x\oplus y\oplus z=0.$$---

 ## 3. 順序なしトリプルではなく順序付きトリプル

 順序付けられたトリプルを数える方が簡単です。 

XOR ゼロのトリプルの場合、3 つすべてが等しく、範囲内にない限り等価性は発生しません ($\ge2$）それは不可能です。 したがって、順序付けされていないすべてのトリプルは正確に対応します$6$トリプルを注文しました。 

したがって：$$F(N) = \frac{ \sum_{\text{ordered}} (x+y+z)-3\cdot(\#\text{ordered}) }{6}.$$---

 ## 4. バイナリビット上の桁 DP

 満足する順序付けられたトリプルを数える必要があります$$x\oplus y=z,$$上限あり。 

これは標準の 2 進数 DP です。 

- 最上位ビットから最下位ビットまで処理します。 
- まだ上限に達しているかどうかを示す「タイトネス」フラグを維持します。 
- 各ビットでビットを選択します$x$そして$y$、
 - のビット$z$強制されます:$$z_i=x_i\oplus y_i.$$DP は同時に次のものを蓄積します。 

- 有効なトリプルの数、
 - すべての合計$x$、
 - すべての合計$y$、
 - すべての合計$z$。 

最後に、包含と除外を適用して強制します$$x,y,z\ge2.$$複雑さはただ、$O(\log N)$。

 # Pythonの実装```python
MOD = 10**9

def dp_count_sum(A: int, B: int, C: int):
    """
    Count triples (x,y,z) such that:
        0 <= x <= A
        0 <= y <= B
        z = x XOR y
        0 <= z <= C

    Returns:
        (count, total_sum_xyz)
    """

    if A < 0 or B < 0 or C < 0:
        return 0, 0

    bits = max(A, B, C).bit_length()
    if bits == 0:
        bits = 1

    # state = (tightA, tightB, tightC)
    count = [0] * 8
    sx = [0] * 8
    sy = [0] * 8
    sz = [0] * 8

    count[7] = 1  # initially all tight

    for p in range(bits - 1, -1, -1):

        bitA = (A >> p) & 1
        bitB = (B >> p) & 1
        bitC = (C >> p) & 1

        value = 1 << p

        ncount = [0] * 8
        nsx = [0] * 8
        nsy = [0] * 8
        nsz = [0] * 8

        for state in range(8):

            cnt = count[state]
            if cnt == 0:
                continue

            tightA = (state >> 2) & 1
            tightB = (state >> 1) & 1
            tightC = state & 1

            for xb in (0, 1):

                if tightA and xb > bitA:
                    continue

                ntA = 1 if (tightA and xb == bitA) else 0

                for yb in (0, 1):

                    if tightB and yb > bitB:
                        continue

                    ntB = 1 if (tightB and yb == bitB) else 0

                    zb = xb ^ yb

                    if tightC and zb > bitC:
                        continue

                    ntC = 1 if (tightC and zb == bitC) else 0

                    ns = (ntA << 2) | (ntB << 1) | ntC

                    ncount[ns] += cnt

                    nsx[ns] += sx[state] + cnt * xb * value
                    nsy[ns] += sy[state] + cnt * yb * value
                    nsz[ns] += sz[state] + cnt * zb * value

        count = ncount
        sx = nsx
        sy = nsy
        sz = nsz

    total_count = sum(count)
    total_sum = sum(sx) + sum(sy) + sum(sz)

    return total_count, total_sum

def F(N: int) -> int:
    """
    Sum of a+b+c over all losing positions:
        0 < a < b < c < N
    """

    L = N

    ordered_count = 0
    ordered_sum = 0

    # Inclusion-exclusion to enforce x,y,z >= 2
    for mask in range(8):

        A = 1 if (mask & 1) else L
        B = 1 if (mask & 2) else L
        C = 1 if (mask & 4) else L

        cnt, sm = dp_count_sum(A, B, C)

        if mask.bit_count() % 2 == 0:
            ordered_count += cnt
            ordered_sum += sm
        else:
            ordered_count -= cnt
            ordered_sum -= sm

    # Convert back from x,y,z to a,b,c:
    # a+b+c = x+y+z - 3

    return (ordered_sum - 3 * ordered_count) // 6

# Verification
assert F(8) == 42
assert F(128) == 496062

answer = F(10**18) % MOD
print(answer)
```---

 ###`dp_count_sum(A,B,C)`これにより、ビット単位の数字 DP が実行されます。 

各ビットで:

 - ビットを選択してください$x$、
 - ビットを選択してください$y$、
 - のビットを計算します$z$XORとして、
 - 密閉状態を維持します。 

DP には以下が保存されます。 

- トリプルがいくつ存在するか、
 - の累計額$x$、$y$、 そして$z$。 

---

 ### 包含と除外

 まず、許容される座標を持つトリプルを数えます。$0$または$1$、違反しているものを削除します$x,y,z\ge2$。 

これは 8 つのマスクによって行われます。$$\{x\le1\},\{y\le1\},\{z\le1\}.$$---

 ### 6 による除算

 順序付けられたトリプルを数えました。 

順序付けされていない各トリプルは正確に表示されます$6$座標が異なるためです。 

したがって、次のように割ります。$6$。
