[プロジェクト オイラー問題 463](https://projecteuler.net/problem=463)

 ## 解決策

 **答え:**`808981553`再帰的に定義された関数が与えられています$$\begin{aligned} f(1)&=1,\\ f(3)&=3,\\ f(2n)&=f(n),\\ f(4n+1)&=2f(2n+1)-f(n),\\ f(4n+3)&=3f(2n+1)-2f(n), \end{aligned}$$そして$$S(n)=\sum_{i=1}^n f(i).$$計算しなければなりません$$S(3^{37}) \pmod{10^9}.$$---

 #1. 数学的分析

 ## ステップ 1: の構造を理解する$f(n)$再帰により引数がおおよそ次の係数で削減されます。$2$または$4$したがって、メモ化された再帰は次の場合でも効率的になります。$3^{37}$。 

させて$$a_n=f(2n+1)$$(奇数のインデックス付きの値)。 

定義関係から:$$\begin{aligned} a_{2n} &=f(4n+1) =2f(2n+1)-f(n) =2a_n-f(n), \\[1ex] a_{2n+1} &=f(4n+3) =3f(2n+1)-2f(n) =3a_n-2f(n). \end{aligned}$$これらの恒等式により、次の繰り返しを導き出すことができます。$S(n)$。 

---

 ## ステップ 2: 繰り返しの導出$S(n)$剰余クラスのモジュロで数値を分割します$4$。 

代数的操作後 (上記の関係と恒等式を使用)$f(2n)=f(n)$)、次の結果が得られます。$$\boxed{ S(4n) = 6S(2n)-8S(n)+3f(n)-1 }$$

$$\boxed{ S(4n+1) = 6S(2n)-8S(n)+2f(n)+2f(2n+1)-1 }$$

$$\boxed{ S(4n+2) = 6S(2n)-8S(n)+2f(n)+3f(2n+1)-1 }$$

$$\boxed{ S(4n+3) = 6S(2n)-8S(n)+6f(2n+1)-1 }$$これらの式により、問題のサイズが次のように削減されます。$n$おおよそに$n/2$、対数的な複雑さを与えます。 

---

 ## ステップ 3: 複雑さ

 のために$N=3^{37}$、$$3^{37}\approx 4.5\times 10^{17},$$しかし、すべての再帰呼び出しでは引数が次のように除算されます。$2$または$4$, そのため、メモ化により計算が非常に高速になります。 

最後だけ必要です$9$数字なので、すべての算術をモジュロで実行できます$$10^9.$$---

 #2. Pythonの実装```python
from functools import lru_cache

MOD = 10**9

# -------------------------------------------------------
# f(n)
# -------------------------------------------------------

@lru_cache(None)
def f(n):
    if n == 1:
        return 1
    if n == 3:
        return 3

    # even case
    if n % 2 == 0:
        return f(n // 2)

    # n = 4k + 1
    if n % 4 == 1:
        k = (n - 1) // 4
        return 2 * f(2 * k + 1) - f(k)

    # n = 4k + 3
    k = (n - 3) // 4
    return 3 * f(2 * k + 1) - 2 * f(k)

# -------------------------------------------------------
# Small exact values for S(n)
# -------------------------------------------------------

small = [0]
s = 0
for i in range(1, 20):
    s += f(i)
    small.append(s)

# -------------------------------------------------------
# S(n)
# -------------------------------------------------------

@lru_cache(None)
def S(n):
    if n < 20:
        return small[n]

    q, r = divmod(n, 4)

    if r == 0:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 3 * f(q)
            - 1
        )

    elif r == 1:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 2 * f(2 * q + 1)
            - 1
        )

    elif r == 2:
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 2 * f(q)
            + 3 * f(2 * q + 1)
            - 1
        )

    else:  # r == 3
        ans = (
            6 * S(2 * q)
            - 8 * S(q)
            + 6 * f(2 * q + 1)
            - 1
        )

    return ans

# -------------------------------------------------------
# Required value
# -------------------------------------------------------

N = 3**37

print(S(N) % MOD)
```---

 #3. コードのチュートリアル

 ## 関数`f(n)`再帰的定義は直接実装されます。 

- もし$n$偶数です:$$f(2n)=f(n)$$- もし$n=4k+1$:$$f(4k+1)=2f(2k+1)-f(k)$$- もし$n=4k+3$:$$f(4k+3)=3f(2k+1)-2f(k)$$メモ化 (`@lru_cache`) すべての値が 1 回計算されるようにします。 

- -

＃＃ 関数`S(n)`各剰余モジュロに対して導出された反復を使用します$4$。 

例:

 もし$n=4q+2$、```python
6 * S(2*q)
- 8 * S(q)
+ 2 * f(q)
+ 3 * f(2*q + 1)
- 1
```これにより、問題ははるかに小さな引数に縮小されます。

 プログラムは以下を再現します。$$S(8)=22$$そして$$S(100)=3604.$$したがって、再帰システムは問題ステートメントと一致しています。

 #4. 最終検証

 再帰の深さは$O(\log n)$、だから評価する$S(3^{37})$メモ化では計算的には自明です。 

計算されたモジュロ値$10^9$は：$$808981553.$$したがって最後は$9$数字は次のとおりです。
