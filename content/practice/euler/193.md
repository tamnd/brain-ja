[プロジェクト オイラー問題 193](https://projecteuler.net/problem=193)

 ## 解決策

 **答え:**`684465067343069`させて$$N = 2^{50}.$$正の整数を数えたい$n < N$それは**平方フリー**であり、素平方除算がないことを意味します$n$。 

自由平方数を数える古典的な方法では、メビウス関数と包含排他を使用します。 

---

 #1. 数学的分析

 数が次で割り切れる場合、その数値は**非平方ではありません**$p^2$いくつかのプライムのために$p$。 

したがって、素二乗の割り切れる制約をすべて回避して整数を数えたいと考えます。 

鍵となるアイデンティティは次のとおりです。$$Q(x)=\sum_{d=1}^{\lfloor \sqrt{x}\rfloor}\mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor,$$どこ：

-$Q(x)$= 自由平方整数の数$\le x$、
 -$\mu(d)$はメビウス関数です。 

この問題では **以下** の数字が求められますので、$2^{50}$、必要です$$Q(2^{50}-1).$$---

 ## ステップ 1 — 包含と除外

 定義:$$A_p = \{n : p^2 \mid n\}.$$どの整数にも含まれていない整数のカウントが必要です$A_p$。 

包含と除外により、次のようになります。$$Q(x) = x -\sum_p \left\lfloor \frac{x}{p^2}\right\rfloor +\sum_{p<q}\left\lfloor \frac{x}{p^2q^2}\right\rfloor -\cdots$$すべてのスクエアフリー製品が、$$d=p_1p_2\cdots p_k$$貢献する$$(-1)^k\left\lfloor \frac{x}{d^2}\right\rfloor.$$その符号パターンはまさにメビウス関数です。$$\mu(d)= \begin{cases} 1 & d=1\\ (-1)^k & d \text{ is product of } k \text{ distinct primes}\\ 0 & d \text{ divisible by a square} \end{cases}$$したがって：$$Q(x)=\sum_{d\le \sqrt{x}} \mu(d)\left\lfloor \frac{x}{d^2}\right\rfloor.$$---

 ## ステップ 2 — 適用先$x=2^{50}-1$次のように計算します。$$\sum_{d=1}^{\lfloor\sqrt{2^{50}-1}\rfloor} \mu(d)\left\lfloor \frac{2^{50}-1}{d^2}\right\rfloor.$$以来$$\sqrt{2^{50}} = 2^{25}=33\,554\,432,$$合計に必要なのは$d \le 33{,}554{,}431$。 

これは、メビウス関数を計算するふるいを使用して簡単に実現できます。 

---

 #2. Pythonの実装```python
from math import isqrt

# We want squarefree numbers below 2^50
N = 2**50 - 1

# Maximum d needed in the Möbius summation
limit = isqrt(N)

# Linear sieve for Möbius function
mu = [0] * (limit + 1)
mu[1] = 1

primes = []
is_composite = [False] * (limit + 1)

for i in range(2, limit + 1):

    if not is_composite[i]:
        primes.append(i)
        mu[i] = -1

    for p in primes:
        if i * p > limit:
            break

        is_composite[i * p] = True

        # p divides i -> square factor appears
        if i % p == 0:
            mu[i * p] = 0
            break
        else:
            mu[i * p] = -mu[i]

# Count squarefree numbers
answer = 0

for d in range(1, limit + 1):
    answer += mu[d] * (N // (d * d))

print(answer)
```---

 #3. コードのチュートリアル

 ## 初期設定```python
N = 2**50 - 1
```以下では厳密に自由平方整数を数えます$2^{50}$。

 ## 合計の上限```python
limit = isqrt(N)
```なぜなら$d^2 \le N$、 のみ$d \le \sqrt{N}$案件。 

---

 ## メビウスの篩

 私たちは計算します$\mu(d)$みんなのために$d \le \sqrt N$。 

### プライム検出```python
if not is_composite[i]:
    primes.append(i)
    mu[i] = -1
```素数にはメビウス値がある$-1$。 

---

 ### 倍数

 もし$p \mid i$、 それから$i p$平方係数が含まれています$p^2$、 それで：```python
mu[i * p] = 0
```さもないと：```python
mu[i * p] = -mu[i]
```異なる素数を 1 つ追加すると符号が反転するためです。 

---

 ## 最終合計```python
answer += mu[d] * (N // (d * d))
```これは直接評価します$$\sum_d \mu(d)\left\lfloor\frac{N}{d^2}\right\rfloor.$$---

 #4. 小さな健全性チェック

 のために$x=12$:

 平方自由数は次のとおりです。$$1,2,3,5,6,7,10,11$$がある$8$。 

式を使用すると、次のようになります。$$\begin{aligned} Q(12) &= \left\lfloor\frac{12}{1^2}\right\rfloor -\left\lfloor\frac{12}{2^2}\right\rfloor -\left\lfloor\frac{12}{3^2}\right\rfloor -\left\lfloor\frac{12}{5^2}\right\rfloor +\cdots \\ &=12-3-1=8. \end{aligned}$$正しい。
