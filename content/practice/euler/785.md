[プロジェクト オイラー問題 785](https://projecteuler.net/problem=785)

 ## 解決策

 **答え:**`29526986315080920`ディオファントス二次方程式から始めます$$15(x^2+y^2+z^2)=34(xy+yz+zx), \qquad 1\le x\le y\le z,\qquad \gcd(x,y,z)=1.$$計算しなければなりません$$S(10^9)=\sum (x+y+z)$$すべての原始的な解決策を使って$z\le 10^9$。 

---

 #1. 数学的分析

 ## ステップ 1: 方程式を二次方程式として表示します。$z$リライト：$$15z^2-34(x+y)z+15(x^2+y^2)-34xy=0.$$のために$z$整数であるためには、判別式は平方でなければなりません。$$\Delta = 34^2(x+y)^2 -60(15x^2+15y^2-34xy).$$拡張と簡略化:$$\Delta = 256(x^2+17xy+y^2).$$したがって、次のことが必要です$$x^2+17xy+y^2=k^2.$$それから$$z=\frac{17(x+y)\pm 8k}{15}.$$なぜなら$z>0$そして$z\ge y$、のみ$+$ブランチが関連しています:$$\boxed{ z=\frac{17(x+y)+8k}{15} }$$と$$\boxed{ k^2=x^2+17xy+y^2. }$$したがって、元の問題はペル型円錐曲線に帰着します。$$k^2=x^2+17xy+y^2.$$---

 #2. ペル方程式への帰着

 紹介する$$u=x+y,\qquad v=y-x.$$それから$$x=\frac{u-v}{2}, \qquad y=\frac{u+v}{2}.$$代入:$$x^2+17xy+y^2 = \frac{19u^2-15v^2}{4}.$$したがって$$4k^2=19u^2-15v^2.$$同様に、$$\boxed{ 19u^2-15v^2=(2k)^2. }$$これは不定の 2 進 2 次形式であり、その原始整数解は次の単位グループによって生成されます。$\mathbb Z[\sqrt{285}]$。 

基本的な自己同型性はペル単位に由来します$$(8+\sqrt{15})(9+\sqrt{19}),$$これは線形回帰を引き起こします$(x,y,z)$。 

---

 #3. 再発

 最小限の原始的な解決策から始める$$(1,7,16),$$すべての原始解は、繰り返し適用することによって生成されます。$$\begin{pmatrix} x'\\y'\\z' \end{pmatrix} = \begin{pmatrix} -1 & -2 & 2\\ -2 & -1 & 2\\ -6 & -6 & 7 \end{pmatrix} \begin{pmatrix} x\\y\\z \end{pmatrix}.$$各ステップの後で、次のように順序を変更します。$$x'\le y'\le z'.$$これにより、正確にすべての原始解が生成されます。 

最初のいくつかは次のとおりです。$$(1,7,16), (8,9,39), (11,21,72), (15,32,105), \dots$$問題の記述と一致します。 

---

 #4. 成長率

 漸化行列の支配的な固有値は次のとおりです。$$\lambda = 8+\sqrt{63}\approx 15.937\ldots$$したがって、次の解の数は$z\le 10^9$は対数のみです:$$O(\log N).$$実際には、以下の原始的な解決策は数​​十個しかありません。$10^9$。 

---

 #5. Pythonの実装```python
from math import gcd

LIMIT = 10**9

# recurrence matrix
A = [
    [-1, -2,  2],
    [-2, -1,  2],
    [-6, -6,  7]
]

def transform(sol):
    x, y, z = sol

    nx = A[0][0]*x + A[0][1]*y + A[0][2]*z
    ny = A[1][0]*x + A[1][1]*y + A[1][2]*z
    nz = A[2][0]*x + A[2][1]*y + A[2][2]*z

    vals = sorted([nx, ny, nz])
    return tuple(vals)

# initial primitive solution
x, y, z = (1, 7, 16)

total = 0

while z <= LIMIT:

    # safety verification
    assert 15*(x*x + y*y + z*z) == 34*(x*y + y*z + z*x)
    assert gcd(gcd(x, y), z) == 1

    total += x + y + z

    x, y, z = transform((x, y, z))

print(total)
```---

 #6. コードのチュートリアル

 ### 最初の解決策

 最小の原始的な解決策から始めます。```python
(1, 7, 16)
```どれが満たすか$$15(1^2+7^2+16^2)=34(1\cdot7+7\cdot16+16\cdot1).$$---

 ### 再発

 各反復では行列変換が適用されます。```python
nx = -x - 2y + 2z
ny = -2x - y + 2z
nz = -6x - 6y + 7z
```これは、二次形式を保存するペル単位の自己同型です。 

---

 ### 並べ替え

 問題に必要なのは$$x\le y\le z,$$したがって、各変換後にトリプルをソートします。 

---

 ### 検証

 両方を検証します。```python
15*(x*x + y*y + z*z) == 34*(x*y + y*z + z*x)
```そして```python
gcd(gcd(x,y),z)==1
```正確さを保証するため。
