[プロジェクト オイラー問題 356](https://projecteuler.net/problem=356)

 ## 解決策

 **答え:**`28010159`の根を張らせてください$$g_n(x)=x^3-2^n x^2+n$$なれ$a_n,b_n,c_n$、 どこ$a_n$最大の実ルートです。 

私たちは求めています$$\sum_{n=1}^{30}\left\lfloor a_n^{987654321}\right\rfloor$$モジュロ$10^8$。 

## 1. 数学的分析

 ### ステップ 1: 下限値を電力和に関連付ける

 ビエテの公式によれば、$$a_n+b_n+c_n = 2^n,$$

$$a_nb_n+a_nc_n+b_nc_n=0,$$

$$a_nb_nc_n=-n.$$のために$n\ge 2$、多項式には 1 つの大きな正の根があります。$a_n$、1 つの小さな正の根$b_n\in(0,1)$、および 1 つの負の根$c_n\in(-1,0)$。 のために$n=1$、根は$$\phi,\quad 1,\quad -\frac1\phi.$$したがって、どのような場合でも次のようになります。$$0<b_n\le 1,\qquad -1<c_n<0,$$そして指数から$$m=987654321$$奇妙です、$$0<b_n^m+c_n^m<1.$$整数累乗和を定義する$$S_k = a_n^k+b_n^k+c_n^k.$$それから$$a_n^m=S_m-(b_n^m+c_n^m),$$と$0<b_n^m+c_n^m<1$。 したがって：$$\boxed{\lfloor a_n^m\rfloor = S_m-1.}$$したがって、必要なのは$S_m$。 

---

 ### ステップ 2: 再発を導出する$S_k$あらゆる根$r$満足する$$r^3=2^n r^2-n.$$乗算$r^{k-3}$、$$r^k = 2^n r^{k-1} - n r^{k-3}.$$3 つのルートをすべて合計すると、次のようになります。$$\boxed{ S_k = 2^n S_{k-1} - n S_{k-3} } \qquad (k\ge 3).$$初期値:$$S_0=3,$$

$$S_1=a_n+b_n+c_n=2^n,$$

$$S_2=(a_n+b_n+c_n)^2 -2(a_nb_n+a_nc_n+b_nc_n) =2^{2n}.$$したがって、次のようになります。$$S_0=3,\qquad S_1=2^n,\qquad S_2=2^{2n}.$$**最後の 8 桁** だけが必要なので、漸化剰余を計算します。$$10^8.$$行列のべき乗を使用します。$$\begin{pmatrix} S_k\\ S_{k-1}\\ S_{k-2} \end{pmatrix} = \begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix} \begin{pmatrix} S_{k-1}\\ S_{k-2}\\ S_{k-3} \end{pmatrix}.$$これを累乗すると$3\times3$行列のべき乗$m-2$与える$S_m$で$O(\log m)$。

 ## 2. Python の実装```python
MOD = 10**8
M = 987654321

def mat_mul(A, B):
    """Multiply two 3x3 matrices modulo MOD."""
    return [
        [
            (
                A[i][0] * B[0][j]
                + A[i][1] * B[1][j]
                + A[i][2] * B[2][j]
            ) % MOD
            for j in range(3)
        ]
        for i in range(3)
    ]

def mat_pow(A, exponent):
    """Fast matrix exponentiation."""
    result = [
        [1, 0, 0],
        [0, 1, 0],
        [0, 0, 1]
    ]

    while exponent:
        if exponent & 1:
            result = mat_mul(result, A)

        A = mat_mul(A, A)
        exponent >>= 1

    return result

answer = 0

for n in range(1, 31):

    two_n = pow(2, n, MOD)

    # Transition matrix for:
    # S_k = 2^n * S_{k-1} - n * S_{k-3}
    transition = [
        [two_n, 0, (-n) % MOD],
        [1, 0, 0],
        [0, 1, 0]
    ]

    # Initial vector [S_2, S_1, S_0]
    initial = [
        pow(2, 2 * n, MOD),
        two_n,
        3
    ]

    # Compute S_M
    power_matrix = mat_pow(transition, M - 2)

    S_M = (
        power_matrix[0][0] * initial[0]
        + power_matrix[0][1] * initial[1]
        + power_matrix[0][2] * initial[2]
    ) % MOD

    # floor(a_n^M) = S_M - 1
    answer = (answer + S_M - 1) % MOD

print(answer)
```---

 ## 3. コードのチュートリアル

 -`mat_mul`2を掛けます$3\times3$行列のモジュロ$10^8$。 
-`mat_pow`2 進累乗を使用して行列累乗を計算します。$O(\log M)$。 
- それぞれについて$n=1,\dots,30$:

 - 漸化式マトリックスを構築する$$\begin{pmatrix} 2^n & 0 & -n\\ 1&0&0\\ 0&1&0 \end{pmatrix}.$$- 初期値を使用します。$$(S_2,S_1,S_0)=(2^{2n},2^n,3).$$- コンピューティング$S_M$。 
- 追加$S_M-1$、 なぜなら$$\lfloor a_n^M\rfloor=S_M-1.$$### 小さな例のチェック

 のために$n=2$:$$a_2 = 3.86619826\ldots$$繰り返しにより整数値が得られます$S_k$、そして確かに$$\lfloor a_2^{11}\rfloor = S_{11}-1,$$直接数値計算のマッチング。

 ## 4. 最終確認

 - 必要なのは最後の 8 桁だけなので、剰余$10^8$算術は有効です。 
- 補正項は常に正確です$-1$他の 2 つの根は厳密に 2 つの間の数値に寄与するため、$0$そして$1$。 
- 行列のべき乗は巨大な指数を作成します$987654321$計算的には簡単です。
