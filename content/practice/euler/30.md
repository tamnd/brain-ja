[プロジェクト オイラー問題 30](https://projecteuler.net/problem=30)

 ## 解決策

 **答え:**`443839`**桁の 5 乗の合計**として記述できるすべての整数を求めます。 

### 1. 数学的分析

 まず上限を決定します。 

のために$n$- 桁数、その桁の 5 乗の最大和は次のとおりです。$$n \cdot 9^5$$以来：$$9^5 = 59049$$いつチェックするか$n$-桁の数値はそのような合計と等しくなりません:

 -$6 \cdot 9^5 = 354294$- 7 桁以上の数字$1{,}000{,}000$しかし：$$7 \cdot 9^5 = 413343 < 1{,}000{,}000$$したがって、7 桁の数字は条件を満たすことができません。 したがって、次の範囲まで検索するだけで済みます。$$354294$$除く$1$、合計とはみなされないため。 

### 2. クリーンな Python コード```python
def digit_fifth_power_sum():
    limit = 6 * (9 ** 5)  # 354294
    total = 0

    for n in range(2, limit + 1):
        if n == sum(int(d) ** 5 for d in str(n)):
            total += n

    return total

print(digit_fifth_power_sum())
```### 3. メンタルトレース/正当性チェック

 この特性を満たす数値は次のとおりです。 

- 4150
 - 4151
 - 54748
 - 92727
 - 93084
 - 194979

 一例を確認してください。$$4150 = 4^5 + 1^5 + 5^5 + 0^5$$

$$= 1024 + 1 + 3125 + 0 = 4150$$それらを合計すると、次のようになります。$$4150 + 4151 + 54748 + 92727 + 93084 + 194979 = 443839$$**答え: 443839**
