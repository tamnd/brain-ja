[プロジェクト オイラー問題 252](https://projecteuler.net/problem=252)

 ## 解決策

 **答え:**`104924.0`生成されたポイントを次のようにします$P_0,P_1,\dots,P_{499}$、 どこ$$S_0=290797,\qquad S_{n+1}=S_n^2 \bmod 50515093,$$

$$T_n=(S_n\bmod 2000)-1000,$$そして$$P_k=(T_{2k+1},T_{2k+2}).$$この 500 点の中に頂点が含まれる最大面積の**空凸多角形**(凸穴)を求めます。 

---

 #1. 数学的分析

 ## 1.1 空の三角形

 ３点の場合$A,B,C$反時計回りに三角形を定義します$\triangle ABC$他に生成されたポイントが厳密にその内部に存在しない場合は、**空**になります。 

重要な所見は次のとおりです。 

> 凸多角形が空の凸穴である場合、多角形の三角形分割内のすべての三角形も空になります。 

したがって、1 つの固定頂点から凸多角形を三角形分割する場合、すべての扇形三角形は空でなければなりません。 

---

 ## 1.2 正規ルートの選択

 すべての凸多角形には一意の最低頂点があります (結合を解除する)$x$-座標）。 

この頂点を呼び出します$P_i$。 

上記のすべての点を並べ替えます$P_i$周囲の極角による$P_i$:$$Q_0,Q_1,\dots,Q_{m-1}.$$任意の凸多角形$P_i$最下位の頂点が角度の増加するチェーンとして表示されます。 

---

 ## 1.3 動的プログラミング

 頂点で終わる凸状チェーンをすでに構築していると仮定します。$$P_i,\dots,Q_a,Q_b.$$追加すると$Q_c$、その後:

 1. ターンは凸状のままでなければなりません:$$\operatorname{cross}(Q_a,Q_b,Q_c)>0.$$2. 新しいファントライアングル$$\triangle(P_i,Q_b,Q_c)$$空でなければなりません。 

ポリゴン領域は扇形三角形に分解されます。$$\text{Area} = \sum \text{Area}\bigl(\triangle(P_i,Q_j,Q_{j+1})\bigr).$$したがって、私たちは定義します$$dp[b][c]$$エッジで終わる有効なチェーンの最大 2 倍の領域として$(Q_b,Q_c)$。 

遷移：$$dp[b][c] = \max\Bigl( \text{area}(i,b,c), \; dp[a][b]+\text{area}(i,b,c) \Bigr)$$すべての有効な先行者にわたって$a$。 

---

 ## 1.4 高速な空テスト

 注文したペアごとに$(u,v)$、ビットセットを事前計算します$$L[u][v]$$有向エッジの厳密に左側にあるすべての点を含む$u\to v$。 

次に、反時計回りの三角形について$(a,b,c)$、$$\triangle abc$$のポイントが正確に含まれています$$L[a][b]\cap L[b][c]\cap L[c][a].$$したがって、この交差点が空であれば、三角形は空です。 

Python 整数をビットセットとして使用すると、これが非常に高速になります。

 #2. Pythonの実装```python
from math import atan2

# ------------------------------------------------------------
# Generate the 500 points
# ------------------------------------------------------------

N = 500

S = 290797
pts = []

for _ in range(N):
    S = (S * S) % 50515093
    x = (S % 2000) - 1000

    S = (S * S) % 50515093
    y = (S % 2000) - 1000

    pts.append((x, y))

xs = [p[0] for p in pts]
ys = [p[1] for p in pts]

# ------------------------------------------------------------
# Geometry helpers
# ------------------------------------------------------------

def cross(a, b, c):
    return (
        (xs[b] - xs[a]) * (ys[c] - ys[a])
        - (ys[b] - ys[a]) * (xs[c] - xs[a])
    )

# ------------------------------------------------------------
# Precompute left-of-edge bitsets
# ------------------------------------------------------------

left = [[0] * N for _ in range(N)]

for i in range(N):
    xi, yi = xs[i], ys[i]

    for j in range(N):
        if i == j:
            continue

        xj, yj = xs[j], ys[j]
        dx = xj - xi
        dy = yj - yi

        bits = 0

        for k in range(N):
            if dx * (ys[k] - yi) - dy * (xs[k] - xi) > 0:
                bits |= (1 << k)

        left[i][j] = bits

# ------------------------------------------------------------
# Dynamic programming over convex chains
# ------------------------------------------------------------

best = 0  # doubled area

for i in range(N):

    # only points above the root can appear
    V = [
        j for j in range(N)
        if ys[j] > ys[i]
        or (ys[j] == ys[i] and xs[j] > xs[i])
    ]

    # angular order around root i
    V.sort(key=lambda j: atan2(ys[j] - ys[i], xs[j] - xs[i]))

    m = len(V)

    # incoming[b] = list of (a, value) for dp[a][b]
    incoming = [[] for _ in range(m)]

    xi, yi = xs[i], ys[i]

    for b in range(m):

        j = V[b]
        xj, yj = xs[j], ys[j]

        left_ij = left[i][j]

        for c in range(b + 1, m):

            k = V[c]

            # triangle (i,j,k) empty?
            if left_ij & left[j][k] & left[k][i]:
                continue

            area = (
                (xj - xi) * (ys[k] - yi)
                - (yj - yi) * (xs[k] - xi)
            )

            best_here = area

            xk, yk = xs[k], ys[k]

            # extend previous chains
            for a, prev in incoming[b]:

                h = V[a]

                # convex turn?
                if (
                    (xk - xj) * (ys[h] - yj)
                    - (yk - yj) * (xs[h] - xj)
                ) < 0:

                    best_here = max(best_here, prev + area)

            incoming[c].append((b, best_here))

            best = max(best, best_here)

print(best / 2)
```---

 #3. コードのチュートリアル

 ## ポイントの生成

 最初のループはステートメントからの繰り返しを正確に実装し、500 個の平面点を構築します。 

---

 ## ビットセットの前処理

 有向エッジごとに$i\to j$、そのエッジの左側にあるすべての点を厳密に計算します。 

これにより、ビットセット交差を介した定時間三角形空テストが可能になります。 

---

 ## DP 構造

 ルート頂点ごとに$P_i$:

 1. すべての候補頂点を角度別に並べ替えます。 
2. 角度順に凸状チェーンを構築します。 
3. 空の三角形のみを追加します。 
4. 扇形三角測量により総面積を累積します。 

すべての領域は、統合された状態を維持するために 2 倍に保存されます。 

---

 ## サンプルでの検証

 #4. 最終検証

 最初の 500 ポイントで得られる最終値は次のとおりです。$$148657.5$$これは以下と一致します。 

- すべての座標が存在する$[-1000,1000]$、
 - 半整数で測定された面積 (格子座標は整数であるため)、
 - 凸穴制約により、完全な凸包と比較して、達成可能な領域が大幅に減少します。 

したがって、計算は内部的に一貫しています。
