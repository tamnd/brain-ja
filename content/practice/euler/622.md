[プロジェクト オイラー問題 622](https://projecteuler.net/problem=622)

 ## 解決策

 **答え:**`3010983666182123972`デッキサイズをこうしよう$n$(偶数)、インデックス位置から$0$に$n-1$、 どこ$0$はトップカードです。 

説明されているシャッフルは **完全なアウト シャッフル** です (上部と下部のカードは固定されたままです)。 

## 1. 数学的分析

 ### ステップ 1: 順列を説明する

 デッキを 2 つに分割します。 

- 左手: ポジション$0,1,\dots,\frac n2-1$- 右手: ポジション$\frac n2,\dots,n-1$インターリーブにより次のことが得られます。$$0,\frac n2,1,\frac n2+1,2,\frac n2+2,\dots$$アウトシャッフルに関する標準的な事実は次のとおりです。 

- 一番下のカードは固定されたままです。 
- 1 つおきの位置は次のように変換されます。$$i \mapsto 2i \pmod{n-1}$$のために$0 \le i < n-1$。 

したがって、その後$k$シャッフル、$$i \mapsto 2^k i \pmod{n-1}.$$デッキは正確に元の構成に戻ります。$$2^k \equiv 1 \pmod{n-1}.$$したがって、次のようになります。$$s(n)=\operatorname{ord}_{n-1}(2),$$の乗算順序$2$モジュロ$n-1$。 

これは次の例と一致します。$$n=52 \implies n-1=51.$$以来$$2^8 \equiv 1 \pmod{51},$$これより小さい指数は機能しません。$$s(52)=8.$$---

 ### ステップ 2: 問題を変換する

 私たちが望んでいるのは:$$s(n)=60.$$させて$$m=n-1.$$それから：$$\operatorname{ord}_m(2)=60.$$乗算順序の定義により、次のようになります。$$m \mid (2^{60}-1),$$しかし$m$分割してはなりません**$2^d-1$任意の適切な約数に対して$d\mid 60$。 

したがって、アルゴリズムは次のようになります。 

1. コンピューティング$$M=2^{60}-1.$$1. すべての約数を列挙する$m$の$M$。 
2. それらを保管してください$$\operatorname{ord}_m(2)=60.$$1.合計$$n=m+1.$$---

 ## 2. Python の実装```python
from sympy import divisors, n_order

def solve(target_order=60):
    # All valid m = n - 1 must divide 2^target_order - 1
    M = 2**target_order - 1

    total = 0

    # Check every divisor m of M
    for m in divisors(M):
        if m <= 1:
            continue

        # Multiplicative order of 2 modulo m
        if n_order(2, m) == target_order:
            total += (m + 1)

    return total

# Verify the example
example = solve(8)
print("s(n)=8 sum:", example)   # should be 412

# Final answer
answer = solve(60)
print(answer)
```---
