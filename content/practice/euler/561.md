[プロジェクト オイラー問題 561](https://projecteuler.net/problem=561)

 ## 解決策

 **答え:**`452480999988235494`させて$$n=\prod_{j=1}^m p_j^{\,r_j}.$$のすべての約数$n$ベクトルに対応する$$(e_1,\dots,e_m), \qquad 0\le e_j\le r_j.$$2 つの約数の場合$a,b$、条件$a\mid b$と同等です$$e_j(a)\le e_j(b)\quad \text{for all }j.$$私たちに聞かれるのは、$$S(n)=\#\{(a,b): a\ne b,\ a\mid b,\ a,b\mid n\}.$$プロジェクト オイラー 561 の場合、$$n=(p_m)^k=\prod_{j=1}^m p_j^k,$$したがって、すべての指数は次のようになります$k$。 

---

 # ステップ 1: 閉じた式$S((p_m)^k)$1 つの素数座標に対して、ペアの数$(x,y)$と$$0\le x\le y\le k$$は$$\frac{(k+1)(k+2)}2.$$座標は独立しているため、次の約数のペアの総数は次のようになります。$a\mid b$は$$\left(\frac{(k+1)(k+2)}2\right)^m.$$これには、$a=b$そのうちのいくつかのケース$(k+1)^m$。 したがって、$$\boxed{ S((p_m)^k)= \left(\frac{(k+1)(k+2)}2\right)^m-(k+1)^m }$$または同等の$$\boxed{ S((p_m)^k) =(k+1)^m\left(\left(\frac{k+2}{2}\right)^m-1\right). }$$インライン数式の視覚化:$S\left((p_m)^k\right)=\left(\frac{(k+1)(k+2)}{2}\right)^m-(k+1)^m$必要です$$E(m,k)=v_2\!\left(S((p_m)^k)\right),$$どこ$v_2(x)$は 2 を割った指数です$x$。 

ここ$$m=904961,$$それは奇妙だ。 

---

 # ステップ 2: 決定する$E(m,k)$パリティケースに分割します。 

## ケース A:$k=2r+1$(奇数)

 それから$$k+1=2(r+1),$$それで$$S=(r+1)^m\bigl((2r+3)^m-2^m\bigr).$$以来$(2r+3)^m$奇妙であり、$2^m$均等です、$$(2r+3)^m-2^m$$奇数です。 

したがって$$E(m,k)=m\,v_2(r+1).$$なぜなら$$r+1=\frac{k+1}{2},$$私たちは得ます$$\boxed{ E(m,k)=m\left(v_2(k+1)-1\right) \qquad (k\text{ odd}). }$$---

 ## ケース B:$k=2r$(偶数)

 それから$$S=(2r+1)^m\bigl((r+1)^m-1\bigr).$$最初の要素は奇数なので、$$E(m,k)=v_2((r+1)^m-1).$$以来$m$奇数です:

 - もし$r$それは奇妙です、それでは$r+1$は偶数なので、$(r+1)^m-1$奇数です:$$E=0.$$- もし$r$偶数であれば、$r+1$は奇数であり、LTE は次のようになります。$$v_2((r+1)^m-1)=v_2(r)+v_2(m)=v_2(r),$$なぜなら$m$奇数です。 

したがって：$$\boxed{ E(m,k)= \begin{cases} v_2(k)-1, & 4\mid k,\\[4pt] 0, & k\equiv2\pmod4. \end{cases} }$$---

 # ステップ 3: 合計$Q(n)$必要です$$Q(N)=\sum_{k=1}^N E(904961,k), \qquad N=10^{12}.$$奇数と偶数の寄与を分けます。 

- -

＃＃ 奇数$k$書く$$k=2j-1.$$それから$$v_2(k+1)-1=v_2(2j)-1=v_2(j).$$したがって、奇妙な貢献度は$$904961\sum_{j\le N/2} v_2(j).$$- -

＃＃ 平$k$4 の倍数のみが寄与します。 書く$$k=4j.$$それから$$v_2(k)-1=v_2(4j)-1=v_2(j)+1.$$したがって、均等寄与率は次のようになります。$$\sum_{j\le N/4}(v_2(j)+1).$$したがって$$\boxed{ Q(N)=904961\,A(N/2)+A(N/4)+N/4 }$$どこ$$A(n)=\sum_{j\le n} v_2(j).$$しかし$$A(n)=v_2(n!)=n-s_2(n),$$と$s_2(n)$2進数の合計。 

それで$$Q(N)=904961\,(N/2-s_2(N/2)) +(N/4-s_2(N/4)) +N/4.$$---

 # ステップ 4: で評価する$N=10^{12}$必要なものは次のとおりです。$$N/2=500000000000, \qquad N/4=250000000000.$$2 進数の合計:$$s_2(500000000000)=13, \qquad s_2(250000000000)=13.$$したがって$$A(500000000000)=499999999987,$$

$$A(250000000000)=249999999987.$$ここで次を計算します。$$Q(10^{12}) = 904961\cdot 499999999987 +249999999987 +250000000000.$$これは等しい$$\boxed{452480999988235494}.$$---

 # Pythonの実装```python
def v2_sum(n):
    # Sum_{k<=n} v2(k) = n - popcount(n)
    return n - bin(n).count("1")

def Q(N):
    m = 904961
    return (
        m * v2_sum(N // 2)
        + v2_sum(N // 4)
        + N // 4
    )

print(Q(8))          # 2714886
print(Q(10**12))     # 452480999988235494
```---

 # コードのチュートリアル`v2_sum(n)`古典的なアイデンティティを使用します$$\sum_{k=1}^n v_2(k)=v_2(n!)=n-s_2(n).$$それから関数`Q(N)`導出された閉じた式を直接評価します。$$Q(N)=904961\,A(N/2)+A(N/4)+N/4.$$サンプルチェック:```python
Q(8)
```返品$$2714886,$$問題文と一致します。
