[プロジェクト オイラー問題 946](https://projecteuler.net/problem=946)

 ## 解決策

 **答え:**`585787007`させて$$\alpha=[2;\underbrace{1,\dots,1}_{2},2,\underbrace{1,\dots,1}_{3},2, \underbrace{1,\dots,1}_{5},2,\ldots]$$ここで、ブロックの長さは$1$'s are the consecutive primes.

 私たちは定義します$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$タスクは、最初の値の合計を計算することです。$10^8$の連分数係数$\beta$。 

メビウス写像で連分数を変換する標準的な方法$$x\mapsto \frac{ax+b}{cx+d}$$マトリックスを使うことです$$\begin{pmatrix}a&b\\ c&d\end{pmatrix}.$$受信する連分数桁ごとに$t$、行列は次のように更新されます。$$(a,b,c,d)\mapsto (at+b,\ a,\ ct+d,\ c).$$いつでも$$\left\lfloor \frac a c \right\rfloor = \left\lfloor \frac b d \right\rfloor,$$その共通の値は、変換された数値の次の連分数係数です。 

ここで、初期行列は次のようになります。$$\begin{pmatrix}2&3\\3&2\end{pmatrix},$$なぜなら$$\beta=\frac{2\alpha+3}{3\alpha+2}.$$このトランスデューサを連続部分にわたって実行すると、$\alpha$の係数を効率的に生成します。$\beta$。 最初の10は確かに$$[0;1,5,6,16,9,1,10,16,11],$$合計は誰の$75$、ステートメントと一致します。 

最適化された実装 (一定サイズの整数状態、大きな整数は必要ありません) は最初の値を計算します。$10^8$係数は数秒以内に得られます。 

コア ロジックの Python バージョン:```python
from sympy import primerange

N = 10**8

a, b, c, d = 2, 3, 3, 2
count = 0
total = 0

def process(t):
    global a, b, c, d, count, total

    a, b, c, d = a*t + b, a, c*t + d, c

    while c and d and a // c == b // d:
        q = a // c
        total += q
        count += 1

        if count == N:
            return True

        a, b, c, d = c, d, a - q*c, b - q*d

    return False

# initial term of alpha
process(2)

for p in primerange(2, 10**9):
    for _ in range(p):
        if process(1):
            break
    else:
        if process(2):
            break
        continue
    break

print(total)
```これにより、次の結果が得られます。
