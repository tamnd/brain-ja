[プロジェクト オイラー問題 849](https://projecteuler.net/problem=849)

 ## 解決策

 **答え:**`936203459`最終的なスコアを次のようにします$$s_1 \le s_2 \le \cdots \le s_n .$$各チームのペアは 2 回プレーします。 この2試合を通して、このペアはまさに貢献している$4$合計ポイントは次のいずれかとして配分されます。$$(4,0),(3,1),(2,2),(1,3),(0,4).$$したがって、トーナメントはすべての順序付けされていないペアに割り当てることと同じです。$\{i,j\}$整数$x_{ij},x_{ji}\ge 0$と$$x_{ij}+x_{ji}=4.$$チームの合計スコア$i$は$$s_i=\sum_{j\ne i} x_{ij}.$$---

 #1. 数学的分析

 ## 一般化されたランダウ定理

 通常のトーナメントでは、ランダウの定理がスコアシーケンスを特徴づけます。 

ここでも、「ペアごとに 4 点」を使用して、まったく同じ証明が機能します。 

減少しない整数列$$s_1\le s_2\le \cdots \le s_n$$実現可能であれば$$\sum_{i=1}^k s_i \ge 4\binom{k}{2}=2k(k-1) \qquad (1\le k\le n),$$平等に$k=n$:$$\sum_{i=1}^n s_i = 4\binom{n}{2}=2n(n-1).$$なぜ？ 

- のサブセット内$k$チーム、内部ゲームはすでに貢献しています$4\binom{k}{2}$ポイント。 
- 外部ゲームはマイナス以外の金額に貢献します。 
- したがって、すべてのプレフィックスは上記の不等式を満たさなければなりません。 

逆に、一般化されたランダウの定理は、これらの条件が十分であると言っています。 

それで$F(n)$を満たす、減少しない整数シーケンスの数に等しい$$\boxed{ \begin{aligned} &s_1\le s_2\le \cdots \le s_n,\\ &\sum_{i=1}^k s_i \ge 2k(k-1)\quad (1\le k\le n),\\ &\sum_{i=1}^n s_i = 2n(n-1). \end{aligned} }$$---

 ## DP 配合

 左から右にシーケンスを構築します。 

すでに最初のものを選択していると仮定します$i$値とその合計は$c$。 

次の値$x=s_{i+1}$以下を満たす必要があります:

 ### 1. 非減少条件$$x \ge s_i.$$### 2. ランダウの下限

 選択した後$x$、$$c+x \ge 2(i+1)i.$$したがって$$x \ge 2(i+1)i - c.$$### 3. 残りの条件の実現可能性

 もし$r$残りのメンバーに分配するポイントが残っています$m=n-i$条件、それでは$$x \le \left\lfloor \frac{r}{m} \right\rfloor$$残りの期間はすべて少なくとも$x$。 

これにより、メモ化された DP が得られます。 

状態は次のとおりです。$$(i,\text{prev},\text{rem})$$どこ

-$i$= すでに固定されている用語の数、
 -`prev`= 前回のスコア、
 -`rem`= 残りの合計スコアはまだ残っています。 

現在のプレフィックスの合計は自動的に決定されます。$$c = 2n(n-1)-\text{rem}.$$---

 #2. Pythonの実装```python
from functools import lru_cache

MOD = 10**9 + 7

def F(n):
    TOTAL = 2 * n * (n - 1)

    @lru_cache(None)
    def dp(i, prev, rem):
        """
        i    = number of scores already chosen
        prev = previous score (scores are nondecreasing)
        rem  = remaining total score still to distribute
        """

        # all scores chosen
        if i == n:
            return 1 if rem == 0 else 0

        # current prefix sum already fixed
        prefix_sum = TOTAL - rem

        # Landau lower bound
        lower = max(
            prev,
            2 * (i + 1) * i - prefix_sum
        )

        # all remaining entries are >= x
        upper = rem // (n - i)

        ans = 0

        for x in range(lower, upper + 1):
            ans += dp(i + 1, x, rem - x)

        return ans % MOD

    return dp(0, 0, TOTAL)

print(F(2))   # 3
print(F(7))   # 32923
print(F(100))
```---

 #3. コードのチュートリアル

 ## 初期化```python
TOTAL = 2 * n * (n - 1)
```すべてのペアが貢献するため、トーナメントの合計ポイントは固定されています$4$ポイント。

 ## DP 状態```python
dp(i, prev, rem)
```意味:

 - まず`i`すでに選ばれたスコア、
 - シーケンスは減少しないままでなければなりません。 
-`rem`ポイントが残っています。 

---

 ## プレフィックスの合計```python
prefix_sum = TOTAL - rem
```明示的に保存する必要はありません。

 ## 下限```python
lower = max(prev,
            2 * (i + 1) * i - prefix_sum)
```これにより、次の両方が強制されます。 

- 減少しない順序、
 - 一般化されたランダウ不等式。

 ## 上限```python
upper = rem // (n - i)
```すべての将来のスコアは少なくとも現在のスコアであるためです。
