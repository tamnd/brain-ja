[プロジェクト オイラー問題 878](https://projecteuler.net/problem=878)

 ## 解決策

 **答え:**`23707109`させて$$Q(a,b)=(a\otimes a)\oplus(2\otimes a\otimes b)\oplus(b\otimes b).$$XOR 積は、まさに次の多項式乗算です。$\mathbb F_2$：

もし$$a=\sum a_i2^i,\qquad b=\sum b_i2^i,$$多項式でそれらを識別する$$A(x)=\sum a_ix^i,\qquad B(x)=\sum b_ix^i.$$XOR 積は、次の乗算に対応します。$\mathbb F_2[x]$、 と$x$整数で表される$2$。 

したがって、$$Q(a,b)\leftrightarrow A^2+xAB+B^2.$$次に変換を定義します$$T(a,b)=(b,\ a\oplus (2b)).$$多項式形式では次のようになります。$$(A,B)\mapsto (B,\ A+xB).$$での直接計算$\mathbb F_2[x]$与える$$B^2+xB(A+xB)+(A+xB)^2 = A^2+xAB+B^2,$$特徴的すぎるから$2$、$$x^2B^2+x^2B^2=0.$$それで$Q(a,b)$以下では不変です$T$。 

さらに、すべての非ゼロ解は、繰り返し適用することによって生成されるちょうど 1 つの無限軌道に属します。$T$、各軌道には、満足のいく固有の **プリミティブ** 代表があります。$$b\oplus (2a) > a.$$とのプリミティブペアの場合$Q(a,b)\le 10^6<2^{20}$、程度の考慮事項が意味するもの$b<2^{11}=2048$。 

したがって、プリミティブペアを列挙するだけで済みます。$0\le a\le b<2048$。 

各プリミティブ ペアに対して、繰り返し適用します。$T$それまで$b>10^{17}$、すべての軌道要素を数えます。 

次の Python コードはまさにそれを行います。```python
def clmul(a, b):
    """Carryless (XOR) multiplication."""
    r = 0
    while b:
        if b & 1:
            r ^= a
        a <<= 1
        b >>= 1
    return r

def Q(a, b):
    return clmul(a, a) ^ (clmul(a, b) << 1) ^ clmul(b, b)

def primitive(a, b):
    return (a, b) == (0, 0) or ((b ^ (2 * a)) > a)

N = 10**17
M = 1_000_000

ans = 1   # (0,0) gives k=0

for a in range(2048):
    for b in range(max(a, 1), 2048):

        if not primitive(a, b):
            continue

        if Q(a, b) > M:
            continue

        x, y = a, b

        while y <= N:
            ans += 1
            x, y = y, x ^ (2 * y)

print(ans)
```サンプルの確認:```python
G(1000,100)=398
```これはステートメントと一致します。 

完全な計算を実行すると、次のようになります。$$G(10^{17},1{,}000{,}000)=23707109.$$**答え: 23707109**
