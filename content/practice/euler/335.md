[プロジェクト オイラー問題 335](https://projecteuler.net/problem=335)

 ## 解決策

 **答え:**`5032316`させて$$n = 2^k+1$$そして定義します$M(n)$の初期構成に戻るために必要な移動の数として$n$ボウルには最初は 1 個の豆が入っています。 

重要な課題は、その構造を理解することです。$M(2^k+1)$、効率的に合計すると、$k=10^{18}$。 

---

 ## 1. 数学的分析

 ### ステップ 1: 経験的構造

 小規模なプロセスをシミュレーションすると、$k$:$$\begin{aligned} M(2)&=2\\ M(3)&=5\\ M(5)&=15\\ M(9)&=53\\ M(17)&=207\\ M(33)&=845 \end{aligned}$$問題文は次のようになります。$$M(5)=15,\qquad M(100)=10920$$次に値を考えてみましょう$$M(2^k+1)-2^{k+1}$$小さいもの用$k$:$$0,1,7,37,175,781,3367,\dots$$この配列は一致します$$4^k-3^k$$正確に、閉じた形式を与える$$M(2^k+1)=4^k-3^k+2^{k+1}.$$私たちは以下を検証します:

 -$k=2$:$16-9+8=15$-$k=3$:$64-27+16=53$-$k=4$:$256-81+32=207$すべて一致します。 

したがって：$$M(2^k+1)=4^k-3^k+2^{k+1}.$$このアイデンティティは重要な洞察です。 

---

 ### ステップ 2: 合計する$k=0$に$10^{18}$私たちが欲しいのは$$S=\sum_{k=0}^{10^{18}} M(2^k+1).$$次の式を代入します。$$S = \sum_{k=0}^{N} (4^k-3^k+2^{k+1}), \qquad N=10^{18}.$$幾何和に分割する：$$S = \sum_{k=0}^{N}4^k - \sum_{k=0}^{N}3^k + 2\sum_{k=0}^{N}2^k.$$使用する$$\sum_{k=0}^{N}r^k=\frac{r^{N+1}-1}{r-1},$$私たちは得ます$$S = \frac{4^{N+1}-1}{3} - \frac{3^{N+1}-1}{2} + 2(2^{N+1}-1).$$このモジュロだけが必要です$$7^9 = 40353607.$$2と3は互いに素なので、$7^9$、逆モジュールが存在します。 

---

 ## 2. Python の実装```python
MOD = 7**9
N = 10**18

# Modular inverses
inv2 = pow(2, -1, MOD)
inv3 = pow(3, -1, MOD)

# Geometric sums modulo MOD
sum_4 = (pow(4, N + 1, MOD) - 1) * inv3
sum_3 = (pow(3, N + 1, MOD) - 1) * inv2
sum_2 = 2 * (pow(2, N + 1, MOD) - 1)

answer = (sum_4 - sum_3 + sum_2) % MOD

print(answer)
```---

 ## 3. コードのチュートリアル

 ### 係数```python

```この問題は結果のモジュロを求めます$7^9$。

 ### 高速モジュラーべき乗演算```python
pow(base, exponent, MOD)
```Python は、二乗を繰り返して膨大な累乗を効率的に計算します。 

例えば：```python
pow(4, 10**18 + 1, MOD)
```対数的な時間がかかります。 

---

 ### モジュール分割

 剰余算術では 2 と 3 で除算する必要があります。 

通常の除算の代わりに、逆数を掛けます。```python
inv2 = pow(2, -1, MOD)
inv3 = pow(3, -1, MOD)
```なぜなら$$a/b \pmod m = a\cdot b^{-1}\pmod m.$$---

 ### 小規模な検証

 のために$k=2$:$$M(5)=4^2-3^2+2^3 =16-9+8 =15,$$問題文と一致します。 

のために$x=100$、直接シミュレーションにより、$$M(100)=10920,$$問題文と一致しています。

 ## 4. 最終確認

 この式は幾何学的増加によって支配されていますが、必要なのは剰余モジュロだけです$7^9$したがって、高速べき乗剰余演算が適切です。 

計算すると次のようになります。$$S \equiv 5032316 \pmod{7^9}.$$**答え: 5032316**
