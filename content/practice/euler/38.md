[プロジェクト オイラー問題 38](https://projecteuler.net/problem=38)

 ## 解決策

 **答え:**`932718654`を連結して形成される最大の 9 桁のパンデジタル番号を求めます。$$x \times 1,\; x \times 2,\; \dots,\; x \times n$$ある整数に対して$x$そしていくつか$n>1$。 

各桁を使用する場合、数値は **1 ～ 9 パンデジタル **$1,2,\dots,9$まさに一度。 

---

 # 数学的分析

 しましょう$$P(x,n)=\text{concat}(x,2x,3x,\dots,nx).$$可能な限り最大のものを望んでいます$P(x,n)$それは:

 1. ちょうど 9 桁です。 
2. 数字が含まれています$1$–$9$ちょうど一度だけ、
 3.用途$n>1$。 

---

 ## ステップ 1: サイズを制限する$x$仮定する$x$もっている$d$数字。 

少なくとも 2 つの数値を連結するので ($n>1$)、全長は 9 でなければなりません。 

### もし$d=5$それから：

-$x\times1$すでに5桁になっていますが、
 -$x\times2$少なくとも5桁の数字があり、

 したがって、連結には少なくとも 10 桁が含まれます。 

不可能。 

- -

＃＃＃ もし$d=4$次に連結します$x$そして$2x$次のいずれかを与えます:

 -$4+4=8$数字、または
 -$4+5=9$数字。 

正確に 9 桁を取得するには、次のものが必要です。$$\text{len}(x)=4,\qquad \text{len}(2x)=5.$$したがって$x\ge 5000$。 

また、最大のパンデジタル番号が必要なので、連結が次で始まるため、4 桁のプレフィックスが有利です。$x$自体。 

したがって、最適解は次の 4 桁の値の間で得られる可能性が非常に高くなります。$n=2$。 

---

 ## ステップ 2: 検索戦略

 整数をテストします$x$そして次のように形成します:$$s = \text{str}(x) + \text{str}(2x) + \cdots$$連結された文字列の長さが少なくとも 9 になるまで。 

次に、次のことを確認します。 

- 長さはちょうど 9、
 - 数字は正確です$\{1,2,\dots,9\}$。 

簡単なパンデジタル テストは次のとおりです。```python
set(s) == set("123456789")
```そして`len(s) == 9`。 

---

 ## ステップ 3: 最大値に関する理由

 連結された数字はで始まるので、$x$、結果の最大化は、先頭の桁を最大化することを意味します。 

4桁の候補のうち、9876から下方向に検索します。 

既知の有力候補:$$9327 \times (1,2)$$与える$$9327\;18654 = 932718654.$$使用される数字:$$1,2,3,4,5,6,7,8,9$$まさに一度。 

これがパンデジタルです。 

次に、より大きな有効な候補が存在しないことを確認します。 

---

 # Pythonの実装```python
def is_pandigital_1_to_9(s):
    """
    Return True if s contains each digit 1-9 exactly once.
    """
    return len(s) == 9 and set(s) == set("123456789")

largest = 0

# Try possible base integers
for x in range(1, 10000):

    concatenated = ""
    n = 1

    # Keep appending x*n until length reaches 9
    while len(concatenated) < 9:
        concatenated += str(x * n)
        n += 1

    # Check if we formed a valid pandigital number
    if is_pandigital_1_to_9(concatenated):
        largest = max(largest, int(concatenated))

print(largest)
```---
