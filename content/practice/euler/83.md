[プロジェクト オイラー問題 83](https://projecteuler.net/problem=83)

 ## 解決策

 **答え:**`425185`行列を重み付きグラフとして扱います。 

- 各セルは頂点です。 
- 各セルから**上下左右**に移動できます。 
- セルを入力すると、そのセルの値が合計パス コストに追加されます。 

左上隅から右下隅までの最小コストのパスが必要です。 

すべての重みが正であるため、これは **ダイクストラの最短経路アルゴリズム**の古典的なアプリケーションです。 

---

 # 数学的分析

 マトリックスを次のようにします$A$サイズの$n \times n$。 

定義する：$$d(i,j)$$セルに到達するために必要な最小パス合計になります。$(i,j)$。 

問題 81 とは異なり、**4 方向**に移動できるため、次のような単純な動的計画法の反復はありません。$$d(i,j)=A_{i,j}+\min(d(i-1,j),d(i,j-1)).$$なぜ？ 上と左への移動を許可するとサイクルが作成されるためです。 

そこで、代わりに行列をグラフとしてモデル化します。 

---

 ## グラフの定式化

 それぞれの細胞$(i,j)$ノードです。 

エッジは直交する隣接セル間に存在します。$$(i,j)\leftrightarrow(i+1,j),\quad (i,j)\leftrightarrow(i-1,j),\quad (i,j)\leftrightarrow(i,j+1),\quad (i,j)\leftrightarrow(i,j-1)$$それらの座標が行列内にある場合。 

隣接セルに移動するコストは、その隣接セルの価値に等しくなります。 

開始セルが$(0,0)$の場合、初期距離は次のようになります。$$d(0,0)=A_{0,0}.$$すべてのエッジの重みは正であるため、ダイクストラのアルゴリズムは最適な最短パスを保証します。 

---

 # ダイクストラのアルゴリズム

 保守:

 - 現在の最良の距離によって順序付けされた優先キュー、
 - 無限に初期化された距離テーブル。 

各ステップで:

 1. 暫定距離が最小となるノードを抽出します。 
2. 隣人全員をリラックスさせます。$$\text{newdist} = d(u) + A(v)$$3. 新しい距離が小さい場合は、距離を更新してヒープにプッシュします。 

宛先ノードがヒープから削除されると、最適な答えが得られます。 

複雑さは$$O(V\log V + E\log V).$$のために$80\times80$マトリックス：$$V = 6400,\qquad E \approx 4V,$$これは非常に管理しやすいものです。 

---

 # Pythonの実装```python
import heapq

# Read matrix from file
with open("0083_matrix.txt") as f:
    matrix = [list(map(int, line.strip().split(",")))
              for line in f]

n = len(matrix)

# Distance table
INF = float('inf')
dist = [[INF] * n for _ in range(n)]

# Starting point
dist[0][0] = matrix[0][0]

# Priority queue: (distance, row, col)
pq = [(matrix[0][0], 0, 0)]

# Possible movements
dirs = [(1, 0), (-1, 0), (0, 1), (0, -1)]

while pq:
    d, r, c = heapq.heappop(pq)

    # Ignore outdated entries
    if d != dist[r][c]:
        continue

    # Reached destination
    if (r, c) == (n - 1, n - 1):
        print(d)
        break

    # Relax neighbors
    for dr, dc in dirs:
        nr, nc = r + dr, c + dc

        if 0 <= nr < n and 0 <= nc < n:
            nd = d + matrix[nr][nc]

            if nd < dist[nr][nc]:
                dist[nr][nc] = nd
                heapq.heappush(pq, (nd, nr, nc))
```---

 # コードのチュートリアル

 ## マトリックスの読み取り```python
matrix = [list(map(int, line.strip().split(",")))
          for line in f]
```ファイルの各行には、カンマで区切られた整数が含まれます。 

---

 ## 距離の初期化```python
dist = [[INF] * n for _ in range(n)]
dist[0][0] = matrix[0][0]
```最初は、開始ノードを除くすべてのノードに到達できません。 

---

 ## 優先キュー```python
pq = [(matrix[0][0], 0, 0)]
```ヒープには以下が格納されます。$$(\text{current distance}, \text{row}, \text{column})$$したがって、距離が最も小さいノードが最初に処理されます。 

---

 ## メインのダイクストラ ループ```python
d, r, c = heapq.heappop(pq)
```暫定的な距離が最小のノードを選択します。 

---

 ## 古いヒープ エントリを無視する```python
if d != dist[r][c]:
    continue
```より良い道がすでに発見されている可能性があります。 

---

 ## 隣人のリラクゼーション```python
nd = d + matrix[nr][nc]
```隣接セルに移動すると、その隣接セルの値が追加されます。 

このパスにより既知の最適距離が改善される場合:```python
if nd < dist[nr][nc]:
    dist[nr][nc] = nd
```更新してヒープにプッシュします。
