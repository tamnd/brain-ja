[プロジェクト オイラー問題 109](https://projecteuler.net/problem=109)

 ## 解決策

 **答え:**`38182`合計スコアが厳密に以下である個別のチェックアウトの組み合わせをカウントする必要があります。$100$、ルールの下では：

 - 最後のダーツは**ダブルでなければなりません**。 
- 最初の 2 つのダーツ (存在する場合) は順序付けされていません。 
- ミスは無視されるため、先頭のミスだけが異なるシーケンスは同じになります。 
- シングル$S1$–$S20$、ダブルス$D1$–$D20$、高音$T1$–$T20$、プラス$S25$そして$D25$は有効なダーツ結果です。 

問題は次のことを示しています$42336$全体の合計チェックアウト数。 スコアのあるものだけが必要です$<100$。 

---

 # 数学的分析

 可能なダーツスコアを形式化してみましょう。 

## 1. 可能なダーツ値

 1 本のダーツで得点できる場合:

 - シングル:$1,2,\dots,20$- ダブルス:$2,4,\dots,40$- 高音域:$3,6,\dots,60$- アウターブル：$25$- ダブルブル：$50$ただし、ダーツの種類が異なることが重要です。 例えば：

-$S2$そして$D1$両方のスコア$2$、しかしスローは異なります。 
-$S6,T2,D3$ダーツの結果はすべて異なります。 

すべての非最終ダーツ タイプのセットを定義します。$$\mathcal D = \{S1\ldots S20,\ D1\ldots D20,\ T1\ldots T20,\ S25,\ D25\}$$これには以下が含まれます:$$20+20+20+1+1 = 62$$独特のダーツ結果。 

フィニッシュダーツはダブルでなければなりません:$$\mathcal F = \{D1\ldots D20,\ D25\}$$持っている$21$可能性。 

---

 ## 2. 順序規則

 チェックアウトでは以下を使用できます。 

- ダーツ1本：フィニッシュダブルのみ
 - ダーツ 2 本: 通常のダーツ 1 本 + フィニッシュ ダブル
 - ダーツ3本: 通常ダーツ2本+フィニッシュダブル

 重要なルール:

 > 最初の 2 つのダーツには順序がありません。 

したがって：

-$S1,T1,D1$等しい$T1,S1,D1$- しかし$D1,D2$とは異なります$D2,D1$, 仕上がりのダブルが違うからです。 

したがって、フィニッシュダブルごとに次のようにカウントします。 

- サイズの順序付けされていないすべてのマルチセット$0,1,2$から選ばれた$\mathcal D$、
 - 合計とフィニッシュダブルが以下である場合$100$。 

---

 ## 3. 列挙戦略

 最もクリーンなアプローチは、総当たりの列挙です。 

各ダーツのタイプを次のように表します。$$(\text{name},\text{score})$$例：

-$(S20,20)$-$(D7,14)$-$(T19,57)$フィニッシュダブルごとに$f$:

 - 1ダーツチェックアウトをカウントします$[f]$- ダーツ2本チェックアウトごとにカウント$[a,f]$- すべての順序付けされていないペアをカウントします$(a,b)$と$a \le b$重複を避けるために辞書順に並べます。 

いつでも：$$\text{score}(a)+\text{score}(b)+\text{score}(f) < 100$$私たちはそれを数えます。 

これは問題ステートメントを直接実装します。 

---

 # Pythonの実装```python
from itertools import combinations_with_replacement

# ------------------------------------------------------------
# Build all possible dart results
# ------------------------------------------------------------

# Non-final dart options
darts = []

# Singles, doubles, trebles for 1..20
for n in range(1, 21):
    darts.append(("S" + str(n), n))
    darts.append(("D" + str(n), 2 * n))
    darts.append(("T" + str(n), 3 * n))

# Bulls
darts.append(("S25", 25))
darts.append(("D25", 50))

# Final dart must be a double
finishes = []

for n in range(1, 21):
    finishes.append(("D" + str(n), 2 * n))

finishes.append(("D25", 50))

# ------------------------------------------------------------
# Count distinct checkouts with total score < 100
# ------------------------------------------------------------

count = 0

for finish_name, finish_score in finishes:

    # --------------------------------------------------------
    # 1-dart checkout
    # --------------------------------------------------------
    if finish_score < 100:
        count += 1

    # --------------------------------------------------------
    # 2-dart checkout
    # --------------------------------------------------------
    for name1, score1 in darts:
        if score1 + finish_score < 100:
            count += 1

    # --------------------------------------------------------
    # 3-dart checkout
    # First two darts are unordered, so use combinations
    # with replacement.
    # --------------------------------------------------------
    for (name1, score1), (name2, score2) in combinations_with_replacement(darts, 2):

        total = score1 + score2 + finish_score

        if total < 100:
            count += 1

print(count)
```---

 ## 3 ダーツのチェックアウトを数える

 重要な行:```python
combinations_with_replacement(darts, 2)
```順序のないペアを生成します。 

したがって：

-$(S1,T1)$一度登場すると、
 - 二度ではありません。 

ただし、同等のダーツは許可されます。 

-$(S1,S1)$-$(D1,D1)$これは問題ステートメントで必要です。 

次に、次のことをテストします。```python
total = score1 + score2 + finish_score
```以下の場合はそれを数えます$100$。
