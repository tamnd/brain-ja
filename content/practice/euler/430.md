[プロジェクト オイラー問題 430](https://projecteuler.net/problem=430)

 ## 解決策

 **答え:**`5000624921.38`させて$X_i$ディスクのインジケーター確率変数になります。$i$後は白いです$M$曲がる。 

それから$$E(N,M)=\sum_{i=1}^N \mathbb E[X_i].$$したがって、必要なのは単一のディスクが白になる確率だけです。$M$ランダムな反転。 

---

 #1. ディスクが存在する確率$i$一手でひっくり返される

 移動では順序付けられた整数が選択されます$A,B\in\{1,\dots,N\}$均一に。 

ディスク$i$反転されている場合$i$間にあります$A$そして$B$、つまり$$(A\le i\le B)\quad\text{or}\quad(B\le i\le A).$$両方のエンドポイントが厳密に残っている場合にのみ、反転されません**$i$、またはその両方が厳密に正しい$i$。 

反転しない順序付きペアの数$i$:$$(i-1)^2 + (N-i)^2.$$したがって、$$p_i =1-\frac{(i-1)^2+(N-i)^2}{N^2}.$$簡略化した後、$$p_i=\frac{2i(N-i+1)-1}{N^2}.$$---

 # 2. 白/黒のパリティ

 フリップするたびに色が切り替わります。 

確率でディスクが裏返った場合$p_i$各ターン独立して、その後$M$ターン:$$P(\text{white}) = \frac{1+(1-2p_i)^M}{2}.$$定義する$$q_i = 1-2p_i.$$それから$$E(N,M) = \sum_{i=1}^N \frac{1+q_i^M}{2} = \frac N2+\frac12\sum_{i=1}^N q_i^M.$$の公式を使用すると、$p_i$、$$q_i = 1-\frac{4i(N-i+1)-2}{N^2}.$$---

 #3. 数値戦略$N=10^{10}, M=4000$直接加算終了$10^{10}$条件は不可能です。 

しかし、ほとんどの人にとって$i$、$$|q_i|<1$$そして$q_i^{4000}$天文学的に小さいです。 

両端付近のディスクのみが顕著に寄与します。 

対称性があるため、$$q_i=q_{N+1-i}.$$したがって、項が無視できるようになるまで、1 つのエッジ付近のみを合計します。 

---

 #4. Pythonの実装```python
from math import log, exp

N = 10**10
M = 4000

def q(i):
    return 1 - (4 * i * (N - i + 1) - 2) / (N * N)

# Sum only where contributions matter
# (beyond this, terms are effectively zero)
LIMIT = 50_000_000

s = 0.0

for i in range(1, LIMIT + 1):
    term = exp(M * log(q(i)))
    s += 2.0 * term   # symmetry

# Expected value
E = N / 2.0 + s / 2.0

print(round(E, 2))
```---

 #5. コードのチュートリアル

 ###`q(i)`計算します$$q_i = 1-2p_i.$$### メインループ

 計算します$$2\sum_{i=1}^{LIMIT} q_i^M,$$左右のエッジ間の対称性を使用します。 

### 切り捨てが機能する理由

 中程度の場合$i$、$$q_i^M \approx e^{-4Mi/N}.$$と$M=4000$そして$N=10^{10}$、用語は指数関数的に減衰し、数千万を超えると数値的に意味がなくなります。 

---

 #6. 小さな例での検証

 のために$N=3, M=1$:$$E(3,1)=\frac{10}{9},$$問題文と一致します。 

のために$N=3, M=2$:$$E(3,2)=\frac53,$$も正しいです。 

のために$N=10, M=4$:$$E(10,4)\approx 5.157,$$再びステートメントと一致します。 

---

 #7. 最終的な計算

 計算を実行すると、$$E(10^{10},4000)\approx 5000624921.38.$$したがって、小数点第 2 位に四捨五入されます。 

**答え: 5000624921.38**
