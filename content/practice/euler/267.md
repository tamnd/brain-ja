[プロジェクト オイラー問題 267](https://projecteuler.net/problem=267)

 ## 解決策

 **答え:**`0.999992836187`させて$H$1000 回の公平なコイントスの表の数、および$T=1000-H$尾の数。 

常に一定の割合でベットする場合$f$現在の資産の割合:

 - 頭の上では富が何倍にもなります$1+f$、
 - 尾を引くと富が倍増します$1-f$。 

したがって、1000 回投げた後、$$W(H,f)=(1+f)^H(1-f)^{1000-H}.$$選びたい$f$その確率を最大化するために$$W(H,f)\ge 10^9.$$重要なのは、それぞれの実現値について、$H$を決定できます。$f$それは富を最大化します。 

---

 # ステップ 1 — 最適化する$f$固定用$H$対数を取る：$$L(f)=H\log(1+f)+(1000-H)\log(1-f).$$差別化:$$L'(f)=\frac{H}{1+f}-\frac{1000-H}{1-f}.$$ゼロに設定します。$$\frac{H}{1+f}=\frac{1000-H}{1-f}.$$相互乗算:$$H(1-f)=(1000-H)(1+f).$$拡大する：$$H-Hf=1000-H+(1000-H)f.$$用語を収集します:$$2H-1000=1000f.$$したがって$$f^*=\frac{2H-1000}{1000}=\frac{H}{500}-1.$$以来$0\le f\le1$、$$f^*=\max\!\left(0,\frac{H-500}{500}\right).$$したがって:

 - もし$H\le500$、最適な$f=0$、富を与える$1$、
- もし$H>500$、最適な$$f=\frac{H-500}{500}.$$---

 # ステップ 2 — 最適な資産を計算する

 のために$H>500$、$$1+f = 1+\frac{H-500}{500}=\frac{H}{500},$$そして$$1-f = 1-\frac{H-500}{500}=\frac{1000-H}{500}.$$それで$$W_{\max}(H) = \left(\frac{H}{500}\right)^H \left(\frac{1000-H}{500}\right)^{1000-H}.$$必要です$$W_{\max}(H)\ge10^9.$$ログの取得:$$H\log\!\left(\frac{H}{500}\right) + (1000-H)\log\!\left(\frac{1000-H}{500}\right) \ge 9\log 10.$$最小のものを探します$H$これを満足させます。 

数値的に評価する:

 -$H=431$：無理だから$H<500$、
 -$H=616$: まだ下にあります$10^9$、
 -$H=617$: を超える$10^9$。 

したがって、次の場合にイベントが発生します$$H\ge617.$$したがって$$P = \sum_{H=617}^{1000} \binom{1000}{H}2^{-1000}.$$---

 # ステップ 3 — Python の実装```python
from math import comb

# Compute the probability:
# P = sum_{H=617}^{1000} C(1000,H) / 2^1000

n = 1000
threshold = 617

numerator = sum(comb(n, h) for h in range(threshold, n + 1))
denominator = 2 ** n

P = numerator / denominator

print("{:.12f}".format(P))
```---
