[プロジェクト オイラー問題 196](https://projecteuler.net/problem=196)

 ## 解決策

 **答え:**`322303240771079935`行のエントリを$n$なれ$$T(n,k)=\frac{n(n-1)}2+k,\qquad 1\le k\le n.$$だから漕ぐ$n$連続した整数が含まれます$$\frac{n(n-1)}2+1,\dots,\frac{n(n+1)}2.$$計算しなければなりません$$S(5678027)+S(7208785),$$どこ$S(n)$行内の素数の合計です$n$少なくとも 1 つの_プライム トリプレット_に属します。 

---

 # 数学的分析

 ## 1. 隣接構造

 位置の数値の場合$(n,k)$、隣接するものはすべて有効な位置です。$$(n+\delta_n,\;k+\delta_k),$$と$$\delta_n,\delta_k\in\{-1,0,1\},$$除く$(0,0)$。 

したがって、内部要素には最大で次のものがあります。$8$隣人たち。 

---

 ＃＃２ 素数三つ組に属するとはどういう意味でしょうか？ 

素数トリプレットは、そのうちの 1 つが他の 2 つと隣接する 3 つの素数のセットです。 

素数の**素数**を定義する$p$隣接する素数の数になります。 

次に:

 - 素数に次数がある場合$\ge 2$、それ自体が素数トリプレットの中心です。 
- 素数に次数がある場合$1$、その一意の素数隣接要素に次数がある場合は、トリプレットに属することができます。$\ge 2$。 

したがって:

 > 素数$p$ある素数の三つ組に属する
 >
 >
 >
 >
 > -$p$少なくとも 2 つの主要な隣接要素がある、または
 > - 隣接する素数の 1 つに、少なくとも 2 つの隣接する素数があります。 

これにより、問題は純粋にローカルな計算に帰着します。 

---

 ## 3. 地域性

 行内に素数があるかどうかを判断するには$n$トリプレットに属しているため、行からの情報のみが必要です$$n-2,\ n-1,\ n,\ n+1,\ n+2.$$確かに:

 - 隣の列$n$並んで横たわる$n-1,n,n+1$;
 - これらの素数の近傍次数を知るには、もう 1 つの層が必要です。 

したがって、次の場合でも計算は実行可能です。$n\approx 7\times10^6$。 

---

 ## 4. 素数の生成

 関係する数字は約$$\frac{n^2}{2}\approx 2.6\times10^{13},$$範囲全体を通常のふるい分けするには大きすぎます。 

しかし、ほんの約$5n$連続した整数が必要なため、**セグメント化されたふるい**が理想的です。

 # Pythonの実装```python
from math import isqrt

def row_start(n):
    return n * (n - 1) // 2 + 1

def value(n, k):
    return row_start(n) + k - 1

def neighbours(n, k):
    """
    Generate all neighbouring coordinates of (n,k).
    """
    out = []

    for dn in (-1, 0, 1):
        rn = n + dn
        if rn < 1:
            continue

        for dk in (-1, 0, 1):
            if dn == 0 and dk == 0:
                continue

            kk = k + dk

            if 1 <= kk <= rn:
                out.append((rn, kk))

    return out

def segmented_sieve(lo, hi):
    """
    Return a boolean array is_prime[x - lo]
    for all x in [lo, hi].
    """

    size = hi - lo + 1
    is_prime = [True] * size

    if lo <= 1 <= hi:
        is_prime[1 - lo] = False

    limit = isqrt(hi)

    # ordinary sieve up to sqrt(hi)
    base = [True] * (limit + 1)
    base[0] = base[1] = False

    for p in range(2, isqrt(limit) + 1):
        if base[p]:
            for m in range(p * p, limit + 1, p):
                base[m] = False

    primes = [i for i, v in enumerate(base) if v]

    # segmented marking
    for p in primes:
        start = max(p * p, ((lo + p - 1) // p) * p)

        for m in range(start, hi + 1, p):
            is_prime[m - lo] = False

    return is_prime

def S(n):
    """
    Sum of primes in row n that belong to some prime triplet.
    """

    # enough rows to determine all local structures
    lo = row_start(n - 2)
    hi = row_start(n + 3) - 1

    is_prime_segment = segmented_sieve(lo, hi)

    def is_prime(x):
        return is_prime_segment[x - lo]

    # prime neighbour counts
    degree = {}

    for r in range(n - 1, n + 2):
        for k in range(1, r + 1):

            x = value(r, k)

            if not is_prime(x):
                continue

            cnt = 0

            for rr, kk in neighbours(r, k):
                y = value(rr, kk)

                if is_prime(y):
                    cnt += 1

            degree[(r, k)] = cnt

    total = 0

    for k in range(1, n + 1):

        x = value(n, k)

        if not is_prime(x):
            continue

        ok = False

        # case 1: x itself is centre of a triplet
        if degree.get((n, k), 0) >= 2:
            ok = True

        # case 2: some neighbour is centre
        else:
            for rr, kk in neighbours(n, k):

                y = value(rr, kk)

                if is_prime(y) and degree.get((rr, kk), 0) >= 2:
                    ok = True
                    break

        if ok:
            total += x

    return total

answer = S(5678027) + S(7208785)

print(answer)

```---

 次のいずれかの場合、素数はトリプレットに属します。```python

```または、隣接する素数の 1 つが少なくとも次数を持っています$2$。
