[プロジェクト オイラー問題 60](https://projecteuler.net/problem=60)

 ## 解決策

 **答え:**`26033`**任意の 2 つの異なる素数**について、**5 つの素数の最小和集合**を求めます。$p,q$セット内では両方の連結$$pq \quad \text{and} \quad qp$$プライムです。 

たとえば、セット$\{3,7,109,673\}$サイズに合わせて機能します$4$、合計付き$792$。 

サイズを解決します$5$場合。 

---

 # 数学的分析

 ## 1. 算術としての連結

 もし$a$もっている$d$10 進数、連結$p$に続く$a$与える$$p \| a = p \cdot 10^d + a$$例：$$7 \| 109 = 7 \cdot 10^3 + 109 = 7109$$したがって、すべてのペアについて$(p,q)$、次のことをテストする必要があります。$$p \cdot 10^{\text{digits}(q)} + q$$そして$$q \cdot 10^{\text{digits}(p)} + p$$初数性のために。 

---

 ## 2. グラフの解釈

 この問題はグラフの問題として見ると非常に簡単になります。 

- 各素数は頂点です。 
- 素数を接続する$p,q$両方の連結が素数の場合、エッジを持ちます。 

合計が最小の **サイズ 5** のクリーク (完全に接続された 5 つの頂点のセット) を求めます。 

これにより、検索スペースが大幅に減少します。 

---

 ## 3. 重要な所見

 ### (a) 2と5を除く

 偶数桁で終わる連結は偶数です。 

したがって、セットに次のものが含まれる場合、$2$、その後、一部の連結は次のように終了します。$2$、それを複合化します。 

同様に、次で終わる連結も$5$で割り切れます$5$。 

したがって：$$2,5 \text{ cannot appear in the set}$$---

 ### (b) 効率的な素数性テスト

 連結はかなり大きくなるため、素数性テストを高速に行う必要があります。 

プロジェクト オイラー スケールの場合、試行分割は最大$\sqrt n$事前に計算された素数リストを使用するだけで十分です。 

---

 ## 4. 検索戦略

 次のように進めます。 

1. 素数を生成します。 
2. 互換性関係を構築します。$$compatible(p,q) \iff pq \text{ and } qp \text{ are prime}$$3. ネストされた交差点を使用します (クリーク検索)。 

- 選択します$a$- 選ぶ$b$と互換性があります$a$- 選ぶ$c$両方に対応
 -など

 交差点が急速に縮小するため、検索が可能になります。

 # Pythonの実装```python
from math import isqrt

# ------------------------------------------------------------
# Basic primality test
# ------------------------------------------------------------

def is_prime(n):
    """Return True if n is prime."""
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2

    limit = isqrt(n)
    d = 3
    while d <= limit:
        if n % d == 0:
            return False
        d += 2

    return True

# ------------------------------------------------------------
# Concatenation helper
# ------------------------------------------------------------

def concat(a, b):
    """Concatenate integers a and b."""
    return int(str(a) + str(b))

# ------------------------------------------------------------
# Compatibility test
# ------------------------------------------------------------

def compatible(a, b):
    """
    Two primes are compatible if both concatenations
    are prime.
    """
    return is_prime(concat(a, b)) and is_prime(concat(b, a))

# ------------------------------------------------------------
# Generate primes
# ------------------------------------------------------------

def generate_primes(limit):
    """Simple sieve of Eratosthenes."""
    sieve = [True] * limit
    sieve[0] = sieve[1] = False

    for i in range(2, isqrt(limit) + 1):
        if sieve[i]:
            step = i
            start = i * i
            sieve[start:limit:step] = [False] * len(range(start, limit, step))

    return [p for p in range(limit) if sieve[p]]

# ------------------------------------------------------------
# Main search
# ------------------------------------------------------------

primes = [p for p in generate_primes(10000) if p not in (2, 5)]

# Build compatibility graph
edges = {}

for i, p in enumerate(primes):
    edges[p] = set()

    for q in primes[:i]:
        if compatible(p, q):
            edges[p].add(q)
            edges[q].add(p)

best_sum = float('inf')
best_set = None

# Clique search of size 5
for a in primes:

    for b in edges[a]:

        ab = edges[a] & edges[b]

        for c in ab:

            abc = ab & edges[c]

            for d in abc:

                abcd = abc & edges[d]

                for e in abcd:

                    s = a + b + c + d + e

                    if s < best_sum:
                        best_sum = s
                        best_set = [a, b, c, d, e]

print(best_set)
print(best_sum)
```---

 # 例の検証

 問題の例:$$\{3,7,109,673\}$$私たちは以下を検証します:

 -$7 \| 109 = 7109$プライムです
 -$109 \| 7 = 1097$プライムです

 すべてのペアについても同様です。 

それらの合計:$$3+7+109+673=792$$ステートメントと一致します。

 このアルゴリズムは、最小の 5 素数クリークを見つけます。$$\{13, 5197, 5701, 6733, 8389\}$$合計を確認する:$$13 + 5197 + 5701 + 6733 + 8389 = 26033$$これは既知のプロジェクト オイラーの結果であり、ペアごとの連結条件をすべて満たしています。
