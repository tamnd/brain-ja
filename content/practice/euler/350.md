[プロジェクト オイラー問題 350](https://projecteuler.net/problem=350)

 ## 解決策

 **答え:**`84664213`させて$$f(G,L,N)=\#\{(a_1,\dots,a_N)\in \mathbb N^N:\gcd(a_i)\ge G,\ \operatorname{lcm}(a_i)\le L\}.$$計算しなければなりません$$f(10^6,10^{12},10^{18}) \pmod{101^4}.$$モジュラスは$$101^4=104060401.$$---

 #1. 数学的分析

 ## ステップ 1: gcd による正規化

 しましょう$$g=\gcd(a_1,\dots,a_N).$$書く$$a_i=g b_i.$$それから：

-$\gcd(b_1,\dots,b_N)=1$、
 -$\operatorname{lcm}(a_i)=g\operatorname{lcm}(b_i)$。 

定義する$$d=\operatorname{lcm}(b_i).$$したがって、すべての有効なリストは次のものに一意に対応します。 

- 整数$g\ge G$、
 - 整数$d\ge 1$、
 - リスト$(b_i)$と$$\gcd(b_i)=1,\qquad \operatorname{lcm}(b_i)=d,$$- そして制約$$gd\le L.$$したがって、固定用$d$、許可される数$g$は$$\left\lfloor \frac{L}{d}\right\rfloor-G+1,$$提供された$d\le L/G$。 

したがって$$f(G,L,N) = \sum_{d\le L/G} h_N(d)\left(\left\lfloor\frac{L}{d}\right\rfloor-G+1\right),$$どこ$h_N(d)$は長さの数値です -$N$リストには以下が含まれます:$$\gcd=1,\qquad \operatorname{lcm}=d.$$したがって、問題全体はコンピューティングに帰着します$h_N(d)$。 

---

 # ステップ 2: 計算する$h_N(d)$要素$$d=\prod p^{e_p}.$$gcd/lcm 条件は素数ごとに分離されているため、1 つの素数べき乗だけを調べる必要があります。 

プライムの場合を想定します$p$、の指数$N$エントリーは$$x_1,\dots,x_N\in\{0,1,\dots,e\}.$$持つべきもの:

 - lcm指数$=e$: 少なくとも 1 つ$x_i=e$、
 - gcd 指数$=0$: 少なくとも 1 つ$x_i=0$。 

したがって、次のように指数タプルをカウントします。$$\max x_i=e,\qquad \min x_i=0.$$タプルの合計数$[0,e]$:$$(e+1)^N.$$ゼロのないタプルを減算します。$$e^N.$$noを使用してタプルを減算します$e$:$$e^N.$$どちらも含まないタプルを追加し直す$0$または$e$:$$(e-1)^N.$$したがって、指数の寄与は$e$は$$A_e=(e+1)^N-2e^N+(e-1)^N.$$異なる素数は独立しているため、次のようになります。$$h_N(d)=\prod_{p^e\parallel d} A_e.$$これは乗算です。 

---

 # ステップ 3: 最終的な合計

 しましょう$$M=\left\lfloor \frac{L}{G}\right\rfloor.$$それから$$f(G,L,N) = \sum_{d=1}^{M} \left( \prod_{p^e\parallel d} \big((e+1)^N-2e^N+(e-1)^N\big) \right) \left( \left\lfloor \frac{L}{d}\right\rfloor-G+1 \right).$$この問題については:$$G=10^6,\quad L=10^{12},\quad N=10^{18},$$それで$$M=10^6.$$数値に現れる最大の指数$\le10^6$だけです$19$、 以来$$2^{19}=524288,\qquad 2^{20}>10^6.$$したがって、事前計算します$A_e$のために$e=0,\dots,19$モジュロ$101^4$、次に乗算的にふるいにかけます。$10^6$。 

複雑さ:

 - ふるい：$O(M\log\log M)$、
- 評価：$O(M)$、

 それは簡単に実現可能です。 

---

 #2. Pythonの実装```python
MOD = 101**4

G = 10**6
L = 10**12
N = 10**18

M = L // G   # = 10^6

# ------------------------------------------------------------
# Precompute:
# A[e] = (e+1)^N - 2*e^N + (e-1)^N  (mod MOD)
# ------------------------------------------------------------

MAX_E = 20

A = [0] * (MAX_E + 1)

for e in range(MAX_E + 1):
    A[e] = (
        pow(e + 1, N, MOD)
        - 2 * pow(e, N, MOD)
        + pow(e - 1, N, MOD)
    ) % MOD

# ------------------------------------------------------------
# Smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(M + 1))

for i in range(2, int(M**0.5) + 1):
    if spf[i] == i:  # i is prime
        for j in range(i * i, M + 1, i):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Compute h[d] multiplicatively
#
# h[d] = product over p^e || d of A[e]
# ------------------------------------------------------------

h = [0] * (M + 1)
h[1] = 1

for n in range(2, M + 1):

    p = spf[n]

    e = 0
    t = n

    while t % p == 0:
        t //= p
        e += 1

    h[n] = (h[t] * A[e]) % MOD

# ------------------------------------------------------------
# Final summation
# ------------------------------------------------------------

answer = 0

for d in range(1, M + 1):

    weight = (L // d) - G + 1

    answer = (answer + h[d] * weight) % MOD

print(answer)
```---

 #3. コードのチュートリアル

 ## 事前計算$A_e$

```python
A[e] = (e+1)^N - 2e^N + (e-1)^N
```これはまさに、最小値が次の指数タプルの包含/除外カウントです。$0$そして最大値は$e$。 

すべてのべき乗を剰余として計算します$101^4$。 

---

 ## 最小の素因数ふるい

 の`spf`配列には、次の値までのすべての数値の最小の素因数が格納されます。$10^6$。 

これにより、各数値を非常に迅速に因数分解することができます。 

- -

＃＃ 建物$h[n]$もし$$n = p^e \cdot t$$と$p\nmid t$、すると、乗法は次のようになります$$h(n)=h(t)\cdot A_e.$$したがって、各値は一定の償却時間で計算されます。 

---

 ## 最終合計額

 それぞれについて$d$:```python
weight = floor(L/d) - G + 1
```有効な gcd の選択肢をカウントします$g$。 

蓄積します$$h(d)\times \text{weight}.$$---
