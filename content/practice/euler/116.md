 ## 解決策

 **答え:**`20492570929`させて$F_m(n)$一定の長さの行をタイル状に並べる方法の数を示します$n$使用:

 - 灰色の長さの正方形$1$、そして
 - 固定長の色付きの長方形のタイル$m$、

 with the condition that **at least one coloured tile is used**.

 この問題については:

 - 赤いタイルには長さがあります$2$、
 - 緑のタイルには長さがあります$3$、
 - 青いタイルには長さがあります$4$、

 そして色を混ぜることはできないので、最終的な答えは次のようになります。$$F_2(50)+F_3(50)+F_4(50).$$---

 # ステップ 1 — 反復を導出する

 タイルの長さを固定する$m$。 

最初にすべてのタイリング (すべてグレーの配置を含む) を数えてから、減算します。$1$最後に。 

させて$$T_m(n)$$長さの行のタイリングの合計数になります。$n$使用:

 - 灰色の長さの正方形$1$、
 - 長さの色付きタイル$m$。 

左端の位置から漸化式を導出します。 

---

 ## ケース分析

 最初のタイルについて考えてみましょう。 

### ケース 1: 最初のタイルは灰色です

 次に、1 単位を消費して、長さの行を残します。$n-1$:$$T_m(n-1).$$### ケース 2: 最初のタイルに色が付いている

 色付きのタイルが配置されています$m$単位、長さの行を残す$n-m$:$$T_m(n-m).$$これらが唯一の可能性ですので、$n \ge m$、$$T_m(n)=T_m(n-1)+T_m(n-m).$$小型用$n<m$、色付きのタイルが適合しないため、唯一の配置はすべてグレーになります。$$T_m(n)=1 \qquad (0\le n<m).$$また、$$T_m(0)=1.$$最後に、この問題には **少なくとも 1 つの色付きタイル**が必要であるため、すべて灰色の配置を減算します。$$F_m(n)=T_m(n)-1.$$したがって、必要な答えは次のとおりです$$(T_2(50)-1)+(T_3(50)-1)+(T_4(50)-1).$$---

 # ステップ 2 — 例の確認$n=5$## 赤いタイル ($m=2$)

 使用する$$T_2(n)=T_2(n-1)+T_2(n-2),$$と$$T_2(0)=1,\quad T_2(1)=1,$$得られるもの:$$\begin{aligned} T_2(2)&=2\\ T_2(3)&=3\\ T_2(4)&=5\\ T_2(5)&=8 \end{aligned}$$したがって$$F_2(5)=8-1=7,$$ステートメントと一致します。 

---

 ## 緑のタイル ($m=3$)$$\begin{aligned} T_3(0)&=1\\ T_3(1)&=1\\ T_3(2)&=1\\ T_3(3)&=2\\ T_3(4)&=3\\ T_3(5)&=4 \end{aligned}$$したがって、$$F_3(5)=4-1=3.$$正しい。 

---

 ## 青いタイル ($m=4$)$$\begin{aligned} T_4(0)&=1\\ T_4(1)&=1\\ T_4(2)&=1\\ T_4(3)&=1\\ T_4(4)&=2\\ T_4(5)&=3 \end{aligned}$$それで$$F_4(5)=3-1=2.$$合計：$$7+3+2=12,$$まさに与えられたとおりです。

 # ステップ 3 — Python の実装```python
def count_ways(n, m):
    """
    Count tilings of a row of length n using:
      - grey tiles of length 1
      - coloured tiles of fixed length m

    At least one coloured tile must be used.
    """

    # dp[i] = total tilings of length i, including all-grey
    dp = [0] * (n + 1)

    # Base case
    dp[0] = 1

    for i in range(1, n + 1):

        # Put a grey tile first
        dp[i] += dp[i - 1]

        # Put a coloured tile first (if it fits)
        if i >= m:
            dp[i] += dp[i - m]

    # Exclude the all-grey arrangement
    return dp[n] - 1

answer = (
    count_ways(50, 2) +
    count_ways(50, 3) +
    count_ways(50, 4)
)

print(answer)
```---
