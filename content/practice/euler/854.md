[プロジェクト オイラー問題 854](https://projecteuler.net/problem=854)

 ## 解決策

 **答え:**`29894398`させて$\pi(n)$ピサーノ周期モジュロを示します$n$、定義します$$M(p)=\max\{n:\pi(n)=p\},$$と$M(p)=1$そうでない場合$n$存在します。 

計算しなければなりません$$P(10^6)=\prod_{p=1}^{10^6} M(p)\pmod{1234567891}.$$---

 #1. 数学的分析

 ピサーノ時代に関する重要な事実は次のとおりです。 

## A. ピサーノ周期とフィボナッチの可分性

 古典的なアイデンティティは次のとおりです。$$\pi(n)=\text{ord}_n \begin{pmatrix} 1&1\\1&0 \end{pmatrix}.$$もう 1 つの重要な結果は次のとおりです。$$N(p):=\max\{n:\pi(n)\mid p\} = \gcd(F_p,F_{p+1}-1),$$どこ$F_k$はフィボナッチ数列です。 

偶数周期の場合、これは大幅に単純化されます。 

---

 ## B. クローズドフォーム$N(2m)$フィボナッチ/ルーカス恒等式の使用:$$\gcd(F_{2m},F_{2m+1}-1)= \begin{cases} F_m, & m \text{ even},\\ L_m, & m \text{ odd}, \end{cases}$$どこ$L_m$ルーカスシーケンスは次のとおりです。$$L_0=2,\quad L_1=1,\quad L_n=L_{n-1}+L_{n-2}.$$したがって、$$N(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$さらに重要な事実は、これらの数値が実際に正確に周期に達するということです。$2m$、 それで：$$M(2m)=N(2m).$$---

 ## C. 奇数の期間

 あらゆる人にとって$n>2$、ピサーノ期間は偶数です。 

発生する唯一の奇妙なピサーノ周期は次のとおりです。$$\pi(2)=3.$$したがって：$$M(3)=2,$$そしてあらゆる奇数に対して$p>3$、$$M(p)=1.$$したがって、積全体は偶数周期のみに減少します。 

---

 #2. 最終的な式

 のために$p=2m$と$m\ge3$、$$M(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$したがって$$P(10^6) = 2 \prod_{m=3}^{500000} \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd} \end{cases} \pmod{1234567891}.$$これは、モジュロを反復的に計算するのが簡単になりました。$1234567891$。 

---

 #3. Pythonの実装```python
MOD = 1234567891
TARGET = 1_000_000

def solve():
    # M(3) = 2
    result = 2

    max_m = TARGET // 2

    # Fibonacci:
    # F0 = 0, F1 = 1
    f_prev, f_cur = 0, 1

    # Lucas:
    # L0 = 2, L1 = 1
    l_prev, l_cur = 2 % MOD, 1 % MOD

    for m in range(2, max_m + 1):

        # advance Fibonacci
        f_prev, f_cur = f_cur, (f_prev + f_cur) % MOD

        # advance Lucas
        l_prev, l_cur = l_cur, (l_prev + l_cur) % MOD

        if m < 3:
            continue

        if m % 2 == 0:
            # M(2m) = F_m
            result = (result * f_cur) % MOD
        else:
            # M(2m) = L_m
            result = (result * l_cur) % MOD

    return result

print(solve())
```---

 #4. コードのチュートリアル

 ### 初期化```python
result = 2
```以下のことを説明します:$$M(3)=2.$$---

 ### フィボナッチ反復```python
f_prev, f_cur = 0, 1
```連続したフィボナッチ数を格納します。 

各ステップで:```python
f_prev, f_cur = f_cur, (f_prev + f_cur) % MOD
```次のフィボナッチ数モジュロへの更新$MOD$。 

---

 ### ルーカスの反復

 同様に:```python
l_prev, l_cur = 2, 1
```ルーカスの番号を追跡します。 

---

 ### 乗算ステップ

 それぞれについて$m\ge3$：

- もし$m$は偶数なので、乗算します$F_m$、
 - それ以外の場合は乗算します$L_m$。 

これは正確に以下を実装します:$$M(2m)= \begin{cases} F_m,&m\text{ even},\\ L_m,&m\text{ odd}. \end{cases}$$---

 #5. サンプルの検証

 問題には次のように書かれています。$$P(10)=264.$$重要な値は次のとおりです。$$M(3)=2,\quad M(6)=4,\quad M(8)=3,\quad M(10)=11.$$したがって、$$P(10)=2\cdot4\cdot3\cdot11=264,$$それは完全に一致します。 

また：$$M(18)=L_9=76,$$まさに与えられたとおりです。 

---

 #6. 最終的な計算

 プログラムを実行すると、次の結果が得られます。$$P(1\,000\,000)\bmod 1\,234\,567\,891 = 29894398.$$**答え: 29894398**
