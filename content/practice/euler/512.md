 ## 解決策

 **答え:**`50660591862310323`させて$$f(n)=\left(\sum_{i=1}^{n}\varphi(n^i)\right)\bmod(n+1)$$そして$$g(n)=\sum_{i=1}^{n} f(i).$$必要です$g(5\times 10^8)$。 

## 1. 数学的分析

 ### ステップ 1: 簡素化する$f(n)$クライアントのアイデンティティを思い出してください。$$\varphi(n^k)=n^{k-1}\varphi(n)$$任意の整数に対して$k\ge1$。 

したがって$$\sum_{i=1}^{n}\varphi(n^i) = \varphi(n)\sum_{i=0}^{n-1} n^i.$$モジュロだけを気にします$n+1$。 以来$$n\equiv -1 \pmod{n+1},$$私たちは得ます$$n^i \equiv (-1)^i \pmod{n+1}.$$したがって、$$\sum_{i=0}^{n-1}n^i \equiv \sum_{i=0}^{n-1}(-1)^i \pmod{n+1}.$$ここでパリティを区別します。 

- もし$n$**偶数**、交互の合計には同じ数が含まれます$+1$そして$-1$、 それで：$$\sum_{i=0}^{n-1}(-1)^i=0.$$したがって$$f(n)=0.$$- もし$n$**奇数**、交互の合計は以下に等しい$1$、 それで：$$f(n)\equiv \varphi(n)\pmod{n+1}.$$以来$n>1$、$$0<\varphi(n)<n+1,$$残りは単純に$$f(n)=\varphi(n).$$また$f(1)=1=\varphi(1)$。 

したがって：$$f(n)= \begin{cases} \varphi(n), & n\text{ odd},\\[4pt] 0, & n\text{ even}. \end{cases}$$それで$$g(N)=\sum_{\substack{n\le N\\ n\text{ odd}}}\varphi(n).$$---

 ### ステップ 2: 合計式に変換する

 メビウス反転公式を使用します。$$\varphi(n) = n\sum_{d\mid n}\frac{\mu(d)}{d}.$$以来$n$が奇数である場合、すべての約数は奇数です:$$g(N) = \sum_{\substack{n\le N\\ n\text{ odd}}} n \sum_{d\mid n}\frac{\mu(d)}{d}.$$書く$n=dm$:$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \sum_{\substack{m\le N/d\\ m\text{ odd}}} m.$$までの奇数の整数の合計$M$:$$1+3+\cdots+(2k-1)=k^2,$$どこ$$k=\left\lfloor \frac{M+1}{2}\right\rfloor.$$したがって、$$g(N) = \sum_{\substack{d\le N\\ d\text{ odd}}} \mu(d) \left( \left\lfloor \frac{\lfloor N/d\rfloor+1}{2} \right\rfloor \right)^2.$$これは次のように計算できます。$O(\sqrt N)$除数のグループ化とメモ化された合計メビウス関数を使用します。

 ## 2. Python の実装```python
from functools import lru_cache

def compute_g(N):
    # Sieve limit for fast Möbius prefix values
    LIMIT = int(N ** (2 / 3)) + 10

    # Linear sieve for Möbius function
    mu = [0] * (LIMIT + 1)
    mu[1] = 1
    primes = []
    is_composite = [False] * (LIMIT + 1)

    for i in range(2, LIMIT + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            is_composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix sum of Möbius
    mobius_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mobius_prefix[i] = mobius_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def mertens(n):
        """M(n) = sum_{k<=n} mu(k)"""
        if n <= LIMIT:
            return mobius_prefix[n]

        result = 1
        left = 2

        while left <= n:
            q = n // left
            right = n // q

            result -= (right - left + 1) * mertens(q)
            left = right + 1

        return result

    @lru_cache(None)
    def odd_mertens(n):
        """Sum of mu(k) over odd k <= n"""
        total = 0

        while n > 0:
            total += mertens(n)
            n //= 2

        return total

    answer = 0
    left = 1

    while left <= N:
        q = N // left
        right = N // q

        # Number of odd integers <= q
        k = (q + 1) // 2

        mobius_sum = odd_mertens(right) - odd_mertens(left - 1)
        answer += k * k * mobius_sum

        left = right + 1

    return answer

# Verification
print(compute_g(100))  # 2007

# Final result
print(compute_g(5 * 10**8))

 ## 3. コードのチュートリアル

 ### メビウスのふるい

 私たちは計算します$\mu(n)$くらいまで$N^{2/3}$直線ふるいを使用します。 

これにより、以下への高速アクセスが可能になります。$$M(n)=\sum_{k\le n}\mu(k)$$小さい方用$n$。 

###`mertens(n)`古典的な分割統治の繰り返しを使用します。$$M(n) = 1 - \sum_{l=2}^{n} (r-l+1)M\!\left(\left\lfloor \frac{n}{l}\right\rfloor\right)$$等商範囲をグループ化します。 

###`odd_mertens(n)`必要なのは奇数だけです$d$。 観察する：$$M(n)=O(n)-O(n/2),$$どこ$O(n)$は奇数のみのメビウス和です。 

それで：$$O(n)=M(n)+O(n/2).$$これは次のようになります。$$O(n)=M(n)+M(n/2)+M(n/4)+\cdots.$$### 最終合計

 間隔をグループ化します。$$\left\lfloor \frac{N}{d}\right\rfloor$$一定であるため、複雑さが大まかに軽減されます$O(\sqrt N)$。 

### 検証

 コードは指定されたチェックを再現します。$$g(100)=2007.$$したがって、導出は一貫しています。
