[プロジェクト オイラー問題 879](https://projecteuler.net/problem=879)

 ## 解決策

 **答え:**`4350069824940`格子点を格子点とする$(x,y)$と$0 \le x,y < n$。 

パスワードは、スキップされた中間点を画面が解釈した後の_タッチされたスポットの実際のシーケンス_です。 

重要な点は次のとおりです。 

- からの移動の場合$A$に$B$未使用の中間スポットを通過すると、それらのスポットは自動的にシーケンスに挿入されます。 
- したがって、_最終的に解釈されたパスワード_では、スポットの連続するすべてのペアが互いに「見える」必要があります。セグメント上のそれらの間には、厳密に未使用の格子点があってはなりません。 

したがって、解釈されたシーケンスを直接カウントする必要があります。 

---

 #1. 数学的分析

 現在ポイントにいると仮定します$P$、すでに使用されたポイントのセットは次のようになります。$S$。 

未使用のポイントの隣に移動する可能性があります$Q$**すべての格子点が厳密に間にある場合に限ります**$P$そして$Q$すでに入っています$S$。 

---

 ## セグメント上の中間格子点

 しましょう$$P=(x_1,y_1), \qquad Q=(x_2,y_2)$$そして定義します$$dx=x_2-x_1,\qquad dy=y_2-y_1.$$直線に沿った等しいサブセグメントの数は次のとおりです。$$g=\gcd(|dx|,|dy|).$$- もし$g=1$、中間の格子点はありません。 
- もし$g>1$、中間格子点は次のようになります。$$P + k\left(\frac{dx}{g},\frac{dy}{g}\right), \qquad k=1,2,\dots,g-1.$$これらはまさに、そこからジャンプする前にすでに使用しなければならないポイントです。$P$に$Q$。 

---

 #2. 動的プログラミング

 DFS + メモ化を使用します。 

州：$$(\text{mask},\text{last})$$どこ

-`mask`= 使用ポイントのビットマスク、
 -`last`= 現在のエンドポイント。 

定義する：$$f(\text{mask},\text{last})$$= すぐに停止するオプションを含む、有効な継続の数。 

遷移:

 未使用ポイントごとに$q$、

 - 間のすべての中間点の場合`last`そして`q`すでに使用されており、
 - その後、次のように拡張する可能性があります$$f(\text{mask}\cup\{q\},q).$$したがって$$f(mask,last) = 1 + \sum_{\text{valid } q} f(mask\cup\{q\},q).$$の`1`現在のシーケンスで停止するカウント。 

最後に、すべての開始点から開始して、長さ 1 のパスワードを減算します。

 #3. Pythonの実装```python
from functools import lru_cache
from math import gcd

def count_passwords(n):
    # Enumerate grid points
    points = [(x, y) for x in range(n) for y in range(n)]
    index = {p: i for i, p in enumerate(points)}

    N = n * n

    # between[a][b] = bitmask of lattice points strictly
    # between point a and point b
    between = [[0] * N for _ in range(N)]

    for a, (x1, y1) in enumerate(points):
        for b, (x2, y2) in enumerate(points):

            if a == b:
                continue

            dx = x2 - x1
            dy = y2 - y1

            g = gcd(abs(dx), abs(dy))

            # If g > 1, there are intermediate lattice points
            if g > 1:
                step_x = dx // g
                step_y = dy // g

                mask = 0

                for k in range(1, g):
                    p = (x1 + k * step_x,
                         y1 + k * step_y)
                    mask |= 1 << index[p]

                between[a][b] = mask

    FULL = (1 << N) - 1

    @lru_cache(None)
    def dfs(mask, last):
        """
        Number of valid continuations from this state,
        including the option to stop immediately.
        """
        total = 1

        unused = FULL ^ mask

        while unused:
            bit = unused & -unused
            q = bit.bit_length() - 1

            # Valid iff all intermediate points are already used
            if between[last][q] & ~mask == 0:
                total += dfs(mask | bit, q)

            unused ^= bit

        return total

    ans = 0

    # Start from every initial point
    for s in range(N):
        ans += dfs(1 << s, s) - 1   # remove length-1 password

    return ans

# Verification against the problem statement
print(count_passwords(3))   # 389488

# Required answer
print(count_passwords(4))
