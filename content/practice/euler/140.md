[プロジェクト オイラー問題 140](https://projecteuler.net/problem=140)

 ## 解決策

 **答え:**`5673835352990`させて$$A_G(x)=\sum_{k\ge1} G_k x^k,$$どこ$$G_k=G_{k-1}+G_{k-2},\qquad G_1=1,\;G_2=4.$$すべての正の整数を求めます$n$そのような$$A_G(x)=n$$ある意味合理的な$x$。 これらの整数は「黄金の塊」です。 

---

 # ステップ 1 — 生成関数を見つける

 なぜなら$G_k$フィボナッチ型漸化式を満たす場合、その母関数は有理的です。 

書く$$A(x)=x+4x^2+5x^3+9x^4+\cdots.$$繰り返しを使用する$G_k=G_{k-1}+G_{k-2}$、$$A(x)-x-4x^2 =\sum_{k\ge3}(G_{k-1}+G_{k-2})x^k.$$合計を分割します。$$=\sum_{k\ge3}G_{k-1}x^k+\sum_{k\ge3}G_{k-2}x^k.$$要素：$$=x\sum_{k\ge3}G_{k-1}x^{k-1} +x^2\sum_{k\ge3}G_{k-2}x^{k-2}.$$生成関数を認識します。$$=x(A(x)-x)+x^2A(x).$$したがって、$$A(x)-x-4x^2=xA(x)-x^2+x^2A(x).$$再配置:$$A(x)(1-x-x^2)=x+3x^2.$$したがって$$A(x)=\frac{x+3x^2}{1-x-x^2}.$$---

 # ステップ 2 — ゴールデン ナゲット条件を課す

 仮定してください$$A(x)=n$$と$n\in\mathbb N$。 

それから$$n=\frac{x+3x^2}{1-x-x^2}.$$相互乗算:$$n(1-x-x^2)=x+3x^2.$$拡大する：$$n-nx-nx^2=x+3x^2.$$すべてを脇に寄せてください:$$(n+3)x^2+(n+1)x-n=0.$$のために$x$合理的であるためには、判別式は完全二乗でなければなりません。$$(n+1)^2+4n(n+3).$$計算:$$= n^2+2n+1+4n^2+12n =5n^2+14n+1.$$したがって、次の整数解が必要です。$$m^2=5n^2+14n+1.$$正方形を完成させてください$n$:$$5n^2+14n+1 =5\left(n+\frac75\right)^2-\frac{44}{5}.$$乗算する$5$:$$5m^2=(5n+7)^2-44.$$したがって、$$(5n+7)^2-5m^2=44.$$させて$$u=5n+7.$$次に、ペル型方程式を取得します。$$u^2-5m^2=44.$$すべての前向きな解決策は金塊をもたらします$$n=\frac{u-7}{5}.$$---

 # ステップ 3 — ソリューションを生成する

 ポジティブナゲットシーケンスが始まります$$2,5,21,42,152,296,\dots$$そして実際、問題は次のように述べています$20$-これ$211345365$。 

解は、ペル方程式によって引き起こされる線形漸化式を満たします。 ナゲットの便利な繰り返しの 1 つは次のとおりです。$$a_k = 7a_{k-2}-a_{k-4}+7,$$しかし、計算的には、Pell 解を反復するだけが最も簡単です。 

すべての正のナゲットを昇順に生成する標準的な繰り返しは次のとおりです。$$\begin{aligned} u' &= 9u+20m,\\ m' &= 4u+9m. \end{aligned}$$基本的なポジティブな解決策から始めると、ナゲットが得られます。 

---

 # ステップ 4 — Python の実装```python
from math import isqrt

# We solve:
#   u^2 - 5m^2 = 44
# and golden nuggets are:
#   n = (u - 7) // 5
#
# Pell transformation:
#   u' = 9u + 20m
#   m' = 4u + 9m

# Fundamental positive solutions producing nuggets
seeds = [
    (17, 7),
    (32, 14),
    (112, 50),
    (217, 97),
    (767, 343),
    (1487, 665),
]

nuggets = set()

for u, m in seeds:
    # Generate enough terms from each branch
    for _ in range(10):
        n = (u - 7) // 5

        # Verify integrality and Pell equation
        if (u - 7) % 5 == 0 and u*u - 5*m*m == 44:
            if n > 0:
                nuggets.add(n)

        # Pell recurrence
        u, m = 9*u + 20*m, 4*u + 9*m

# Take first 30 nuggets
nuggets = sorted(nuggets)

answer = sum(nuggets[:30])

print(nuggets[:30])
print(answer)
```---
