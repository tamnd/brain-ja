[プロジェクト オイラー問題 380](https://projecteuler.net/problem=380)

 ## 解決策

 **答え:**`6.3202e25093`のために$m\times n$迷路、その状態

 > 「左上の正方形から他の正方形への道は 1 つだけです」

 迷路が**スパニングツリー**であることを意味します$m\times n$グリッドグラフ。 

したがって、問題は長方形グリッド グラフのスパニング ツリーの数を求めます。$G_{m,n}$。 

**行列ツリー定理** によれば、グラフのスパニング ツリーの数は、ラプラシアン行列の余因子に等しくなります。 

長方形グリッド グラフの場合、この行列式は離散フーリエ モードを使用して明示的に対角化でき、古典的な閉じた形式が得られます。$$C(m,n) = \frac1{mn} \prod_{x=0}^{m-1} \prod_{y=0}^{n-1} \!{}^{\prime} \left( 4 -2\cos\frac{\pi x}{m} -2\cos\frac{\pi y}{n} \right),$$ここでプライムは用語を意味します$(x,y)=(0,0)$は省略されます。 

この式は次の例と一致します。$$C(2,2)=4, \qquad C(3,4)=2415,$$そして$$C(9,12)\approx 2.5720\times 10^{46}.$$---

 クリーンな Python 実装は次のとおりです。```python
import math

def maze_count(m, n):
    log10_value = 0.0

    for x in range(m):
        for y in range(n):
            if x == 0 and y == 0:
                continue

            term = (
                4
                - 2 * math.cos(math.pi * x / m)
                - 2 * math.cos(math.pi * y / n)
            )

            log10_value += math.log10(term)

    # divide by mn
    log10_value -= math.log10(m * n)

    exponent = int(math.floor(log10_value))
    mantissa = 10 ** (log10_value - exponent)

    return mantissa, exponent

# verification
print(maze_count(3, 4))   # 2.415e3  -> 2415
print(maze_count(9, 12))  # 2.5720e46

# target
print(maze_count(100, 500))
```のために$(m,n)=(100,500)$、これは与えます$$C(100,500) \approx 6.320236505\ldots \times 10^{25093}.$$有効数字 5 桁に四捨五入:

 **答え: 6.3202e25093**
