[プロジェクト オイラー問題 220](https://projecteuler.net/problem=220)

 ## 解決策

 **答え:**`139776963904`させて

-$A_n$シンボルの展開を示します`a`後$n$書き換えます、
 -$B_n$シンボルの展開を示します`b`後$n$書き換えます。 

書き換えルールは、$$a \to aRbFR,\qquad b \to LFaLb$$そして完全なドラゴンは$$D_n = F A_n$$なぜなら$D_0 = Fa$。 

重要な観察は次のとおりです。 

- 前進回数は世代ごとに 2 倍になります。 
- ただし、文字列の合計の長さは指数関数的に増加します。 
- したがって、生成することはできません$D_{50}$明示的に。 

代わりに、以下を再帰的に計算します。 

1. 各ブロックの変位ベクトル、
 2.実行後の方向変更、
 3. 内部の前進ステップ数。 

次に、可能な限り再帰ブロック全体を「スキップ」します。 

---

 # 数学的分析

 道順を使用します$$0=\text{up},\quad 1=\text{right},\quad 2=\text{down},\quad 3=\text{left}.$$方向への前進$d$は：$$(0,1),(1,0),(0,-1),(-1,0).$$再帰ブロックごとに次のものを保存します。$$(\Delta x,\Delta y,\Delta d,\text{steps})$$意味:

 - 正味変位、
 - ネットローテーション、
 - の数`F`説明書。 

---

 ## 再帰的な構造

 のために$n\ge1$、$$A_n = A_{n-1} \; R \; B_{n-1} \; F \; R$$

$$B_n = L \; F \; A_{n-1} \; L \; B_{n-1}$$シンボル`a,b`彼ら自身はレベルでは何もしません$0$、 それで$$A_0=B_0=\varepsilon$$変位もステップもゼロです。 

---

 ## 前進ステップ数

 しましょう$f_n$の数になります`F`のコマンド$A_n$。 

再帰から:$$f_n=f_{n-1}+f_{n-1}+1$$と$f_0=0$。 

したがって$$f_n = 2^n-1.$$したがって$D_{50}$含まれています$$1+(2^{50}-1)=2^{50}$$前進ステップ、より快適に大きい$10^{12}$。 

---

 # 効率的な再帰的スキップ

 最初のものが必要だとします$k$中に入る$A_n$。 

各サブブロックについて:

 - サブブロック全体に以下が含まれる場合$\le k$ステップでは、事前に計算された変位を使用して即座にスキップします。 
- それ以外の場合は、そのブロックに再帰的に入ります。 

これは複雑さを与えるだけです$O(n)$。 

---

 # Pythonの実装```python
from functools import lru_cache

# Rotate a vector clockwise by 90 degrees d times
def rotate(v, d):
    x, y = v
    for _ in range(d % 4):
        x, y = y, -x
    return x, y

# ------------------------------------------------------------
# Precompute properties of A_n and B_n
#
# Returns:
#   (dx, dy, dir_change, steps)
# ------------------------------------------------------------

@lru_cache(None)
def props(symbol, n):

    # Base case: a and b do nothing at level 0
    if n == 0:
        return (0, 0, 0, 0)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    x = y = 0
    d = 0
    steps = 0

    for t in seq:

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Rotate displacement into current orientation
            rdx, rdy = rotate((dx, dy), d)

            x += rdx
            y += rdy

            d = (d + dd) % 4
            steps += ss

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]
            steps += 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, steps)

# ------------------------------------------------------------
# Walk the first k forward steps inside symbol_n
# ------------------------------------------------------------

def walk(symbol, n, k, pos=(0, 0), direction=0):

    x, y = pos
    d = direction

    if n == 0 or k == 0:
        return (x, y, d, k)

    if symbol == 'a':
        seq = ['a', 'R', 'b', 'F', 'R']
    else:
        seq = ['L', 'F', 'a', 'L', 'b']

    for t in seq:

        if k == 0:
            break

        if t in 'ab':

            dx, dy, dd, ss = props(t, n - 1)

            # Skip whole block if possible
            if ss <= k:

                rdx, rdy = rotate((dx, dy), d)

                x += rdx
                y += rdy

                d = (d + dd) % 4
                k -= ss

            else:
                x, y, d, k = walk(t, n - 1, k, (x, y), d)

        elif t == 'F':

            move = [(0, 1), (1, 0), (0, -1), (-1, 0)][d]

            x += move[0]
            y += move[1]

            k -= 1

        elif t == 'L':
            d = (d - 1) % 4

        elif t == 'R':
            d = (d + 1) % 4

    return (x, y, d, k)

# ------------------------------------------------------------
# Full dragon D_n = F + A_n
# ------------------------------------------------------------

def solve(n, steps):

    # Initial instruction F
    x, y = (0, 1)
    steps -= 1

    if steps > 0:
        x, y, d, rem = walk('a', n, steps, (x, y), 0)

    return x, y

# ------------------------------------------------------------
# Verification against the example
# ------------------------------------------------------------

print(solve(10, 500))      # should be (18, 16)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------

print(solve(50, 10**12))
```---

 - 前進ステップ数。 

これらの値はメモ化されているため、各状態は 1 回計算されます。
