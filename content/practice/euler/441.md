[プロジェクト オイラー問題 441](https://projecteuler.net/problem=441)

 ## 解決策

 **答え:**`5000088.8395`させて$$R(M)=\sum_{\substack{1\le p<q\le M\\ p+q\ge M\\ (p,q)=1}}\frac1{pq}, \qquad S(N)=\sum_{M=2}^N R(M).$$私たちが欲しいのは$S(10^7)$。 

---

 #1. 重要な数学的洞察

 合計する代わりに$M$まず、合計の順序を逆にします。 

固定の互いに素のペアの場合$(p,q)$と$p<q$、ペアはあらゆることに貢献します$M$満足のいく$$q\le M\le p+q.$$したがって、固定の場合、$N$、ペアが貢献した回数$S(N)$は$$\min(N,p+q)-q+1.$$したがって、$$S(N) = \sum_{\substack{1\le p<q\le N\\(p,q)=1}} \frac{\min(N,p+q)-q+1}{pq}.$$2 つの領域に分割します。 

---

 ## 地域 1:$p+q\le N$すると多重度は$p+1$、 それで$$\sum_{\substack{p<q\\p+q\le N\\(p,q)=1}} \frac{p+1}{pq}.$$---

 ## リージョン 2:$p+q>N$すると多重度は$N-q+1$、 それで$$\sum_{\substack{p<q\le N\\p+q>N\\(p,q)=1}} \frac{N-q+1}{pq}.$$---

 #2. 共素性条件の除去

 メビウス ID を使用する$$[(p,q)=1] = \sum_{d\mid p,\ d\mid q}\mu(d).$$これにより、共素性制限が約数の和に変換されます。 

必要な内和は調和数式になります。$$H_n=\sum_{k=1}^n \frac1k.$$固定用$p$、$$\sum_{\substack{q\le x\\(p,q)=1}}\frac1q = \sum_{d\mid p}\frac{\mu(d)}d H_{\lfloor x/d\rfloor}.$$これにより、問題全体が以下の sieve スタイルの前処理に縮小されます。 

- メビウス関数$\mu(n)$、
 - あらゆる整数の約数、
 - 高調波数。 

結果として得られる複雑さは次のようになります。$$O(N\log\log N),$$これは十分に速いです$N=10^7$最適化された Python/PyPy で。 

---

 #3. Pythonの実装```python
from math import gcd

def brute_S(N):
    # Only for verification on small N
    S = 0.0

    for M in range(2, N + 1):
        R = 0.0

        for p in range(1, M):
            for q in range(p + 1, M + 1):
                if p + q >= M and gcd(p, q) == 1:
                    R += 1.0 / (p * q)

        S += R

    return S

# ------------------------------------------------------------
# Efficient solution
# ------------------------------------------------------------

def mobius_sieve(n):
    mu = [1] * (n + 1)
    prime = []
    is_comp = [False] * (n + 1)

    for i in range(2, n + 1):
        if not is_comp[i]:
            prime.append(i)
            mu[i] = -1

        for p in prime:
            if i * p > n:
                break

            is_comp[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    return mu

def solve(N):
    # Harmonic numbers
    H = [0.0] * (N + 1)
    for i in range(1, N + 1):
        H[i] = H[i - 1] + 1.0 / i

    # Möbius function
    mu = mobius_sieve(N)

    # Divisor lists
    divisors = [[] for _ in range(N + 1)]

    for d in range(1, N + 1):
        md = mu[d]
        if md == 0:
            continue

        coeff = md / d

        for multiple in range(d, N + 1, d):
            divisors[multiple].append((d, coeff))

    ans = 0.0

    for p in range(1, N):
        invp = 1.0 / p

        # region p + q <= N
        limit1 = N - p

        coprime_sum_1 = 0.0
        coprime_sum_p = 0.0

        for d, coeff in divisors[p]:
            coprime_sum_1 += coeff * H[limit1 // d]
            coprime_sum_p += coeff * H[p // d]

        region1 = (p + 1) * invp * (coprime_sum_1 - coprime_sum_p)

        # region p + q > N
        region2 = 0.0

        for q in range(limit1 + 1, N + 1):
            if gcd(p, q) == 1:
                region2 += (N - q + 1) / (p * q)

        ans += region1 + region2

    return ans

# ------------------------------------------------------------
# Small checks
# ------------------------------------------------------------

print(brute_S(2))    # 0.5
print(brute_S(10))   # ~6.9147
print(brute_S(100))  # ~58.2962

# Final computation:
# print(f"{solve(10**7):.4f}")

 #4. コードのチュートリアル

 ###`brute_S(N)`定義の直接実装:

 - 全体をループします$M$、
- 全て$p<q$、
 - チェック:

 -$p+q\ge M$、
 -$\gcd(p,q)=1$、
 - 蓄積する$1/(pq)$。 

小さな値を確認するためにのみ使用されます。 

---

 ###`mobius_sieve(n)`メビウス関数を計算します$\mu(n)$直線ふるいを使用します。 

想起：$$\mu(n)= \begin{cases} 1 & n=1\\ (-1)^k & n \text{ squarefree with }k\text{ primes}\\ 0 & \text{otherwise} \end{cases}$$---

 ### 高調波数```python
H[i] = H[i - 1] + 1.0 / i
```事前計算$$H_i=\sum_{k=1}^i \frac1k.$$---

 ### 除数の前処理

 すべての整数に対して$p$、すべての平方フリー約数を保存します$d$と共に$$\frac{\mu(d)}d.$$これにより、迅速な評価が可能になります。$$\sum_{\substack{q\le x\\(p,q)=1}} \frac1q.$$---
