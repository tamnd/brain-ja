 ## 解決策

 **答え:**`51161058134250`以下の正の整数を数えてみましょう$10^{100}$**弾性がない**、つまり次のいずれかの数値です。 

- **増加**: 数字が左から右に減少することはありません。 
- **減少**: 数字が左から右に増加することはありません。 

重要なのは、これは純粋な組み合わせ論の問題であるということです。 

---

 # ステップ 1 — 増加する数を数える

 満たす数が増加する$$d_1 \le d_2 \le \cdots \le d_n$$数字の由来はどこから$0$に$9$。 

例：$$134468$$増加する数値は **最大 100 桁**で数えます (同じ数値の先頭のゼロ表現を除く)。 

標準的な組み合わせトリックは次のとおりです。 

- 長さの増加シーケンス$n$数字を使う$0$–$9$- サイズのマルチセットを選択するのと同じです$n$10個のシンボルから。 

したがって、カウントは$$\binom{n+9}{9}$$ただし、これには正の整数を表さないすべてゼロのシーケンスも含まれます。 

したがって、正確に増加する正の整数の数は$n$桁数 (組み合わせ表現では内部的に先頭のゼロを許可します)$$\binom{n+9}{9} - 1$$---

 # ステップ 2 — 減少する数を数える

 数値が減少すると満たされる$$d_1 \ge d_2 \ge \cdots \ge d_n$$例：$$66420$$ここでも星と棒を使用します。 

緩やかに減少する長さの数字列の数$n$桁を超える$0$–$9$は$$\binom{n+10-1}{10-1} = \binom{n+9}{9}$$ただし、数値が減少する場合は、先頭のゼロを慎重に扱う必要があります。 

より明確な既知の公式は次のとおりです。$$\binom{n+10}{10} - 1$$正の整数を最大で減少させる場合$n$数字。 

同様に、正確には$n$数字:$$\binom{n+10-1}{10-1} = \binom{n+9}{9}$$過剰にカウントされたゼロ表現を修正します。 

標準的なプロジェクト オイラーの導出により、次の結果が得られます。$$\text{decreasing up to } n \text{ digits} = \binom{n+10}{10} - (n+1)$$文字列が好きだから$$0000,\ 1111,\ 2222,\dots$$重複した表現を作成します。

 # ステップ 3 — 数値が二重にカウントされる

 すべて同じ桁の数値は増加と減少の両方を伴います。$$1,2,\dots,9,11,22,333,\dots$$各桁の長さについて$n$、まさにあります$9$このような正の数。 

したがって、カウントを組み合わせるときは減算します$$9n$$のために$n$-桁の範囲。 

---

 # ステップ 4 — 閉じた式

 以下の非弾性数値の数$10^n$は$$\binom{n+10}{10} + \binom{n+9}{9} - 10n - 2$$のために$n=100$:$$\binom{110}{10} + \binom{109}{9} - 1000 - 2$$それを計算してみましょう。 

---

 # Pythonの実装```python
from math import comb

def non_bouncy_below_10_pow(n):
    """
    Count positive integers below 10^n
    that are either increasing or decreasing.
    """

    increasing = comb(n + 9, 9)
    decreasing = comb(n + 10, 10)

    # Remove duplicates and zero-count issues
    return increasing + decreasing - 10 * n - 2

# Verify the example from the problem
print(non_bouncy_below_10_pow(6))   # below one million
print(non_bouncy_below_10_pow(10))  # below 10^10

# Compute the required answer
print(non_bouncy_below_10_pow(100))
```---
