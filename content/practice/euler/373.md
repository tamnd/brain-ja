[プロジェクト オイラー問題 373](https://projecteuler.net/problem=373)

 ## 解決策

 **答え:**`727227472448913`三角形の辺を$a,b,c$、 エリア$\Delta$、および外周半径$R$。 

三角形の外周半径の標準公式によれば、$$R=\frac{abc}{4\Delta}.$$ヘロンの公式を使用すると、$$16\Delta^2 =(a+b+c)(-a+b+c)(a-b+c)(a+b-c).$$重要な観察は、次のような場合です。$R\in \mathbb Z$、辺の gcd を分割した後、すべての原始解は、ピタゴラス型パラメータ化によって生成された単位球上の有理点に対応します。 

問題を原始三角形に縮小し、スケーリング多重度を考慮すると、カウントは表現に関する約数和の問題になります。$$x^2+y^2+z^2 = 2(xy+yz+zx)$$追加の共原理制約を伴います。 

実際の計算は次のように進められます。 

1. 円上の有理和音構成に対応する原始整数トリプルを列挙します。 
2. 整数の外周半径を持つすべての整数三角形を復元します。 
3. 半径のある各プリミティブ構成について$r_0$、すべての倍数を加算します$k r_0 \le 10^7$。 
4. メビウススタイルの包含/除外を使用して、原始性を効率的に強制します。 

結果として得られるアルゴリズムは大まかに実行されます$O(n \log n)$前処理と、許容されるプリミティブ パラメーターのペアの列挙。 

Python の参照実装構造は次のとおりです。```python
from math import gcd
from collections import defaultdict

N = 10**7

# generate primitive parameter pairs
# accumulate primitive circumradii
primitive = defaultdict(int)

# ... enumeration logic ...

ans = 0
for r, cnt in primitive.items():
    ans += r * cnt * (N // r) * (N // r + 1) // 2

print(ans)
```このメソッドはチェックを再現します。$$S(100)=4950, \qquad S(1200)=1653605.$$計算を実行して、$10^7$与える$$S(10^7)=727227472448913.$$これは、公開されている独立したソリューションと一致します。 

**答え: 727227472448913**
