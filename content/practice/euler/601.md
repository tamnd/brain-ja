 ## 解決策

 **答え:**`1617243`させて$$\operatorname{streak}(n)=k$$それは次のことを意味します:

 - あらゆる人にとって$1\le j\le k$、$$n+j-1 \text{ is divisible by } j,$$- しかし$$n+k \text{ is NOT divisible by } k+1.$$同様に:$$\begin{aligned} n+1 &\equiv 0 \pmod 2\\ n+2 &\equiv 0 \pmod 3\\ &\vdots\\ n+(k-1) &\equiv 0 \pmod k \end{aligned}$$それぞれの合同式は、$$n \equiv 1 \pmod j.$$だからみんなにとって$2\le j\le k$、$$n\equiv 1 \pmod j.$$したがって：$$n\equiv 1 \pmod{\operatorname{lcm}(1,2,\dots,k)}.$$定義する$$L_k=\operatorname{lcm}(1,2,\dots,k).$$それから：

-$\operatorname{streak}(n)\ge k$もし$$n\equiv 1 \pmod{L_k}.$$**まさに**のストリークを持つには$k$、さらにステップでの失敗も必要とします$k+1$、つまり$$n\not\equiv 1 \pmod{L_{k+1}}.$$したがって、$$P(k,N) = \left\lfloor \frac{N-1}{L_k}\right\rfloor - \left\lfloor \frac{N-1}{L_{k+1}}\right\rfloor.$$---

 例を確認してください$P(3,14)$:$$L_3=\operatorname{lcm}(1,2,3)=6,\qquad L_4=12.$$それで$$P(3,14) = \left\lfloor\frac{13}{6}\right\rfloor - \left\lfloor\frac{13}{12}\right\rfloor = 2-1=1.$$正しい。 

---

 今すぐ計算してください$$\sum_{i=1}^{31} P(i,4^i).$$# Pythonの実装```python
from math import gcd

def lcm(a, b):
    return a * b // gcd(a, b)

total = 0
L = 1  # L_i = lcm(1..i)

for i in range(1, 32):
    # Compute L_i
    L = lcm(L, i)

    # Compute L_{i+1}
    L_next = lcm(L, i + 1)

    N = 4 ** i

    # P(i, N)
    p = (N - 1) // L - (N - 1) // L_next

    total += p

print(total)
```---
