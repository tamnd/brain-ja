[プロジェクト オイラー問題 885](https://projecteuler.net/problem=885)

 ## 解決策

 **答え:**`827850196`数値のゼロ以外の桁を$d$なれ$$1^{c_1}2^{c_2}\cdots 9^{c_9},$$どこ$c_i\ge 0$、そしてさせてください$$k=c_1+\cdots+c_9$$ゼロ以外の桁数になります。 

それから$$f(d)=\underbrace{11\ldots1}_{c_1} \underbrace{22\ldots2}_{c_2} \cdots \underbrace{99\ldots9}_{c_9},$$つまり、すべてのゼロが削除されて、数字が徐々にソートされます。 

計算しなければなりません$$S(18)=\sum_{\substack{d\ge1\\ \text{at most 18 digits}}} f(d) \pmod{1123455689}.$$---

 #1. 数学的分析

 ## ステップ 1 — ゼロ以外の数字を修正する

 非ゼロ数字のマルチセットが固定されていると仮定します。$$(c_1,c_2,\dots,c_9).$$次に、の値は$f(d)$固定されています。 

残された唯一の自由は次のとおりです。 

- ゼロはいくつありますか、
 - すべての数字がどのように配置されるか。 

数字に次の内容を含めます$c_0$ゼロなので、全長は$$n=k+c_0.$$正の整数のみを考慮するため、先頭の数字をゼロにすることはできません。 

---

 ## ステップ 2 — 有効な数値を数える

 マルチセットの順列の合計数は次のとおりです。$$\frac{n!}{c_0!c_1!\cdots c_9!}.$$このうち、最初の桁がゼロ以外の分数は、$$\frac{k}{n},$$なぜならまさに$k$の$n$位置にゼロ以外の数字が含まれています。 

したがって、有効な数は$n$-桁の整数は$$\frac{k}{n}\cdot \frac{n!}{c_0!c_1!\cdots c_9!} = \frac{k(n-1)!}{c_0!c_1!\cdots c_9!}.$$ここで書き換えます:$$\frac{k(n-1)!}{c_0!} = \frac{k!}{1}\binom{n-1}{c_0}.$$確かに、$$k\frac{(k+c_0-1)!}{c_0!} = k!\binom{k+c_0-1}{c_0}.$$したがって、カウントは次のようになります$$\frac{k!}{c_1!\cdots c_9!} \binom{k+c_0-1}{c_0}.$$---

 ## ステップ 3 — 考えられるすべてのゼロカウントを合計する

 固定非ゼロカウントの場合$(c_1,\dots,c_9)$、ゼロカウントは次のようになります。$$0\le c_0\le 18-k.$$したがって、多重度の合計は次のようになります。$$\frac{k!}{c_1!\cdots c_9!} \sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0}.$$ホッケースティックのアイデンティティを利用して、$$\sum_{t=0}^{m}\binom{k+t-1}{t} = \binom{k+m}{m}.$$と$m=18-k$、$$\sum_{c_0=0}^{18-k} \binom{k+c_0-1}{c_0} = \binom{18}{k}.$$したがって、すべてのマルチセットが貢献します$$f \cdot \frac{k!}{c_1!\cdots c_9!} \binom{18}{k}.$$したがって、$$S(18) = \sum_{k=1}^{18} \binom{18}{k} \sum_{c_1+\cdots+c_9=k} f(c_1,\dots,c_9) \frac{k!}{c_1!\cdots c_9!}.$$これは現在有限であり、小さいものです。 

合計の9タプルの数$k\le18$は$$\binom{18+9}{9}\approx 4.7\times10^4,$$それは小さいです。

 #2. Pythonの実装```python
from math import factorial, comb

MOD = 1123455689
N = 18

# Precompute factorials
fact = [factorial(i) for i in range(N + 1)]

answer = 0

def dfs(digit, remaining, counts):
    """
    Recursively generate all count vectors:
        c1 + c2 + ... + c9 <= N
    """
    global answer

    if digit == 10:
        k = sum(counts)

        # Ignore the empty multiset
        if k == 0:
            return

        # Build f(d):
        # digits sorted increasingly with repetitions
        s = []
        for d, c in enumerate(counts, start=1):
            s.extend(str(d) * c)

        f_value = int("".join(s))

        # multinomial factor = k! / (c1! c2! ... c9!)
        mult = fact[k]
        for c in counts:
            mult //= fact[c]

        # Contribution
        contribution = f_value * mult * comb(N, k)

        answer += contribution
        return

    # Choose count for current digit
    for c in range(remaining + 1):
        dfs(digit + 1, remaining - c, counts + [c])

dfs(1, N, [])

print(answer % MOD)
```---
