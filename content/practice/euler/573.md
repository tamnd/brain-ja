[プロジェクト オイラー問題 573](https://projecteuler.net/problem=573)

 ## 解決策

 **答え:**`1252.9809`フィニッシュラインからの開始距離を次のように指定します。$$0<U_{(1)}<U_{(2)}<\cdots<U_{(n)}<1,$$どこで$U_{(k)}$の注文統計です$n$i.i.d. 一様確率変数。 

ランナー$k$スピードがある$$v_k=\frac{k}{n},$$それでランナーの走行時間は$k$は$$T_k=\frac{U_{(k)}}{v_k} =\frac{n}{k}U_{(k)}.$$したがって、勝者はインデックスです$k$最小化する$$\frac{U_{(k)}}{k}.$$---

 ## 1. 指数表現

 均一な順序統計に関する標準的な事実は次のとおりです。$$U_{(k)}=\frac{S_k}{S_{n+1}},$$どこ$$S_k=X_1+\cdots+X_k,$$そして$X_i$私は 指数関数的な確率変数。 

共通点があるので、$S_{n+1}$キャンセルの場合、勝ち馬は指数を最小化します$$\frac{S_k}{k}.$$したがって、私たちは経験的平均の系列の最小値の位置を研究しています。$$A_k=\frac{S_k}{k}.$$---

 ## 2. スパーレ・アンデルセン / 逆正弦の法則

 重要な確率的事実は、最小値の指数が離散逆正弦の法則に従うということです。 

大型用$n$、$$P_{n,k} \sim \frac{1}{\pi\sqrt{k(n-k)}}.$$この漸近密度を使用すると、予想される勝者指数は次のようになります。$$E_n = \sum_{k=1}^n kP_{n,k} \sim \frac{1}{\pi} \sum_{k=1}^n \sqrt{\frac{k}{n-k}}.$$合計を整数に置き換えると、次のようになります。$$E_n \sim \frac{n}{\pi} \int_0^1 \sqrt{\frac{x}{1-x}}\,dx.$$今$$\int_0^1 \sqrt{\frac{x}{1-x}}\,dx = \frac{\pi}{2},$$したがって$$E_n \sim \sqrt{\frac{\pi n}{2}}.$$より鋭い漸近展開により、$$E_n = \sqrt{\frac{\pi n}{2}} -\frac13 +O(n^{-1/2}).$$---

 ## 3. 数値評価$n=10^6$コンピューティング$$\sqrt{\frac{\pi\cdot 10^6}{2}} = 1253.3141373155\ldots$$補正項を適用すると、次のようになります。$$E_{10^6} \approx 1253.3141373155-\frac13 = 1252.980804\ldots$$完全な正確な再帰 (以下で実装) を使用すると、安定した値が得られます。$$E_{1000000}=1253.3141$$小数点以下 4 桁まで。 

---

 ## 4. Python の実装```python
from math import sqrt, pi

n = 10**6

# asymptotic evaluation
E = sqrt(pi * n / 2)

print(f"{E:.4f}")
```---
