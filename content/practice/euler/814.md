[プロジェクト オイラー問題 814](https://projecteuler.net/problem=814)

 ## 解決策

 **答え:**`307159326`させて$N=4n$。 

各人は次の 3 つの方向のうち 1 つを正確に選択します。 

-$L$：左を見て、
 -$R$：右を見てください、
 -$O$：正反対の人を見てください。 

人は、見つめている人もまた自分を見つめると叫びます。 

ちょうど半分の人が悲鳴を上げる構成を数えなければなりません。$2n$悲鳴を上げる人たち。 

叫び声は常に相互に見えるペアで発生し、叫び声は互いに素なペアで現れるため、正確に$$n$$相思相愛のペア。 

---

 #1. 構造改革

 人々にラベルを付ける$0,1,\dots,4n-1$円の周り。 

ペアの人$i$人と$i+2n$(mod$4n$); これらは互いに反対です。 

2 つの行を定義します。 

- 上の行:$T_i=i$、
 - 一番下の行:$B_i=i+2n$、

のために$i=0,\dots,2n-1$。 

さて、各列$i$反対のペアが含まれています$(T_i,B_i)$。 

相互に見えるペアは、次の 3 つの方法で発生します。 

1.$T_i$正しく見えるし、$T_{i+1}$左に見える、
 2.$B_i$正しく見えるし、$B_{i+1}$左に見える、
 3.$T_i$そして$B_i$どちらも選ぶ$O$。 

唯一の微妙な点はラップアラウンドです。 

-$T_{2n-1}$に隣接しています$B_0$、
 -$B_{2n-1}$に隣接しています$T_0$。 

したがって、ジオメトリは通常の円柱ではなく、メビウスのはしごです。 

---

 # 2. トランスファーマトリックスの定式化

 各列に選択肢のペアを記録します$$(a_i,b_i)\in\{L,R,O\}^2,$$だからあります$9$州。 

状態を$s=(a,b)$。 

連続する 2 列の場合$s=(a,b)$そして$t=(c,d)$、 定義する$$w(s,t) = [a=R\land c=L] + [b=R\land d=L] + [a=O\land b=O].$$これは、そのステップで作成された叫び声のペアの数をカウントします。 

最後のラップアラウンド遷移では、代わりに次を使用します。$$w_{\text{wrap}}(s,t) = [a=R\land d=L] + [b=R\land c=L] + [a=O\land b=O].$$叫んでいるペアの合計数が$k$とすると、スクリーマーの数は$2k$。 

必要です$k=n$。 

したがって：$$S(n) = [x^n] \sum_{\text{closed walks}} x^{\text{total screaming pairs}}.$$これは以下の標準 DP になります。 

- 位置、
 - 現在の状態、
 - 蓄積された叫び声のペアの数。 

状態空間はただ$9$、必要な学位は$n=1000$なので計算は簡単です。 

---

 #3. Pythonの実装```python
MOD = 998244353

def solve(n):
    m = 2 * n

    dirs = "LRO"
    states = [(a, b) for a in dirs for b in dirs]
    S = len(states)   # 9 states

    # Normal transitions
    normal = [[] for _ in range(S)]

    # Wrap-around transition contribution
    wrap = [[0] * S for _ in range(S)]

    for i, s in enumerate(states):
        a, b = s

        for j, t in enumerate(states):
            c, d = t

            # Internal transitions
            deg = 0

            # Top-row mutual look
            if a == 'R' and c == 'L':
                deg += 1

            # Bottom-row mutual look
            if b == 'R' and d == 'L':
                deg += 1

            # Opposite mutual look
            if a == 'O' and b == 'O':
                deg += 1

            normal[i].append((j, deg))

            # Wrap-around transition
            wdeg = 0

            if a == 'R' and d == 'L':
                wdeg += 1

            if b == 'R' and c == 'L':
                wdeg += 1

            if a == 'O' and b == 'O':
                wdeg += 1

            wrap[i][j] = wdeg

    ans = 0

    # Fix a starting state and count closed walks
    for start in range(S):

        dp = [[0] * (n + 1) for _ in range(S)]
        dp[start][0] = 1

        # Process the first 2n-1 ordinary transitions
        for step in range(m - 1):

            ndp = [[0] * (n + 1) for _ in range(S)]

            limit = min(n, 3 * (step + 1))

            for s in range(S):
                row = dp[s]

                for t, add in normal[s]:

                    upto = limit - add + 1

                    for k in range(upto):
                        val = row[k]
                        if val:
                            ndp[t][k + add] = (
                                ndp[t][k + add] + val
                            ) % MOD

            dp = ndp

        # Close the cycle with the Möbius wrap
        for end in range(S):
            add = wrap[end][start]

            if add <= n:
                ans = (ans + dp[end][n - add]) % MOD

    return ans

print(solve(10))     # 420121075
print(solve(1000))
```---

 #4. コードのチュートリアル

 ### 状態の構築```python
states = [(a, b) for a in dirs for b in dirs]
```各列には、上位と下位の人々の選択が保存されます。 

がある$3^2=9$可能性。 

---

 ### 遷移の重み```python
if a == 'R' and c == 'L':
    deg += 1
```これにより、最上段に悲鳴を上げるペアが作成されます。 

最下段も同様に。```python
if a == 'O' and b == 'O':
    deg += 1
```これにより、列内に悲鳴を上げるペアが作成されます。 

---

 ### DPの意味```python
dp[state][k]
```= これまでに正確にストリップを構築する方法の数$k$叫ぶペア。 

---

 ### ラップアラウンド

 グラフは最後でねじれているため、最後の列は最初の列と上下を交差して相互作用します。 

それを扱うのは、`wrap`。

 #5. 検証

 プログラムは問題で指定された値を再現します。$$S(10)\equiv 420121075 \pmod{998244353}.$$したがって、転送モデルは正しいです。 

プログラムを実行する$n=1000$与える:$$S(1000)\equiv 307159326 \pmod{998244353}.$$---

 **答え: 307159326**
