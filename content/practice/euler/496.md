 ## 1. 数学的分析

 ### ステップ 1: エクスプレス$DI$幾何学的に

 以来$A,I,D$同一線上にあり、$D$外接円上にある場合は、点の力を使用します。$I$。 

外接円に対する内心の力は次のようになります。$$IA\cdot ID = 2Rr,$$どこ$R$は外周半径であり、$r$イン半径です。 

また、$$IA = \frac{r}{\sin(A/2)}.$$したがって、$$ID = \frac{2Rr}{IA} = 2R\sin(A/2).$$条件$AC = DI$になる$$b = 2R\sin(A/2).$$しかし、正弦の法則から、$$b = 2R\sin B.$$したがって$$\sin B = \sin(A/2).$$三角形の角が入っているので、$(0,\pi)$、唯一有効な可能性は$$B = \frac A2.$$したがって、条件は次と同等です。$$A = 2B.$$---

 ### ステップ 2: 角度条件をディオファントス方程式に変換する

 正弦の法則により、$$\frac{a}{\sin A} = \frac{b}{\sin B}.$$以来$A=2B$、$$a = b\frac{\sin(2B)}{\sin B} = 2b\cos B.$$したがって$$\cos B = \frac{a}{2b}.$$今$$c = b\frac{\sin(3B)}{\sin B} = b(4\cos^2B-1).$$代わりの$\cos B = a/(2b)$:$$c = b\left(\frac{a^2}{b^2}-1\right) = \frac{a^2-b^2}{b}.$$並べ替えると、重要な方程式が得られます。$$a^2 = b(b+c).$$これが正確な特徴です。 

---

 ### ステップ 3: パラメータ化

 しましょう$$g = \gcd(b,b+c).$$書く$$b = g u,\qquad b+c = gv,$$と$\gcd(u,v)=1$。 

それから$$a^2 = g^2 uv.$$以来$u$そして$v$は互いに素で、その積は平方です。両方とも平方でなければなりません。$$u=m^2,\qquad v=n^2,$$と$\gcd(m,n)=1$。 

したがって、あらゆる解決策は、$$\boxed{ a = gmn,\quad b = gm^2,\quad c = g(n^2-m^2) }$$と$$m<n<2m, \qquad \gcd(m,n)=1.$$(不等式$n<2m$三角不等式/角度の正から来ています。)

 例:

 -$m=2,n=3,g=1$与える$$(a,b,c)=(6,4,5),$$例と一致します。 

---

 ### ステップ 4: 合計の公式

 固定共素の場合$(m,n)$、$$a = gmn.$$すべての倍数$$gmn \le L$$許可されています。 

させて$$K=\left\lfloor \frac{L}{mn}\right\rfloor.$$このプリミティブ ペアの貢献:$$\sum_{g=1}^{K} gmn = mn\cdot \frac{K(K+1)}2.$$したがって$$F(L) = \sum_{\substack{m<n<2m\\ \gcd(m,n)=1}} mn\cdot \frac{K(K+1)}2, \quad K=\left\lfloor\frac{L}{mn}\right\rfloor.$$効率的に評価するには$L=10^9$、すべてを繰り返すことを避けます$n$直接、メビウス反転を使用して範囲内の互いに素な整数を合計します。$$\sum_{\substack{x\le n\le y\\(n,m)=1}} n.$$これにより、実行時間が数秒に短縮されます。

 ## 2. Python の実装```python
from math import isqrt

def F(L):
    M = isqrt(L)

    # Möbius function up to sqrt(L)
    mu = [0] * (M + 1)
    mu[1] = 1
    primes = []
    composite = [False] * (M + 1)

    for i in range(2, M + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > M:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break

            mu[v] = -mu[i]

    # divisors with nonzero Möbius values
    divisors = [[] for _ in range(M + 1)]

    for d in range(1, M + 1):
        if mu[d] == 0:
            continue

        coeff = mu[d] * d

        for m in range(d, M + 1, d):
            divisors[m].append((d, coeff))

    def triangular(k):
        return k * (k + 1) // 2

    total = 0

    for m in range(1, M + 1):

        limit = min(2 * m - 1, L // m)
        if limit <= m:
            continue

        divs = divisors[m]

        # Sum of integers <= N coprime to m
        def coprime_sum(N):
            s = 0
            for d, coeff in divs:
                t = N // d
                s += coeff * (t * (t + 1) // 2)
            return s

        n = m + 1

        # Group intervals where floor(L/(m*n)) is constant
        while n <= limit:
            k = L // (m * n)
            r = min(limit, L // (m * k))

            sum_n = coprime_sum(r) - coprime_sum(n - 1)

            total += m * triangular(k) * sum_n

            n = r + 1

    return total

print(F(15))      # 45
print(F(10**9))
```---
