[プロジェクト オイラー問題 319](https://projecteuler.net/problem=319)

 ## 解決策

 **答え:**`268457129`させて$$x_1,x_2,\dots,x_n$$満足する

-$x_1=2$、
 -$x_{i-1}<x_i$、
 - そして全員にとって$i,j$、$$x_i^j<(x_j+1)^i.$$私たちは求めています$t(n)$、そのようなシーケンスの数、$n=10^{10}$、モジュロ$10^9$。 

## 1. 数学的分析

 重要な観察点は、次の条件です。$$x_i^j < (x_j+1)^i$$次のように書き換えることができます$$x_i^{1/i} < (x_j+1)^{1/j}.$$したがって、すべての間隔$$I_i=\left(x_i^{1/i},\,(x_i+1)^{1/i}\right)$$空でない交差点が必要です。 

したがって実数が存在する$\lambda\in(2,3)$あらゆる人にとって$i$、$$x_i < \lambda^i < x_i+1.$$したがって$$x_i=\lfloor \lambda^i\rfloor.$$したがって、すべての有効なシーケンスは、ある間隔に一意に対応します。$\lambda\in(2,3)$、シーケンスは次の場合にのみ変更されます。$\lambda$境界を越える$$\lambda = k^{1/i}, \qquad 2^i \le k < 3^i.$$したがって：$$t(n) = \#\left\{ k^{1/i} : 1\le i\le n,\, 2^i\le k<3^i \right\}.$$（知らせ$\lambda=2$それ自体は経由で含まれます$k=2^i$。）

 ---

 ### 正規カウント

 **最小分母**を定義する$d$境界値の$r$次のような最小の正の整数として$r^d\in\mathbb Z$。 

させて$g(d)$最小分母が正確に一致する境界点の数になります。$d$。 

それから$$t(n)=\sum_{d\le n} g(d).$$固定用$d$、どの候補者も次のようになります$$r = m^{1/d}, \qquad 2^d\le m<3^d.$$その分母は最小ではありません。$m$です$e$ある約数の - 乗$e\mid d$、$e>1$。 

メビウス反転により:$$g(d) = \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right),$$どこ$\mu$はメビウス関数です。 

したがって$$t(n) = \sum_{d\le n} \sum_{e\mid d} \mu(e) \left(3^{d/e}-2^{d/e}\right).$$合計を交換します$d=ek$:$$t(n) = \sum_{e\le n} \mu(e) \sum_{k\le n/e} (3^k-2^k).$$定義する$$F(m) = \sum_{k=1}^{m}(3^k-2^k).$$幾何学和を使用すると、次のようになります。$$F(m) = \frac{3^{m+1}-3}{2} - (2^{m+1}-2).$$それで：$$t(n) = \sum_{e\le n} \mu(e)\, F\!\left(\left\lfloor \frac ne \right\rfloor\right).$$これは約で計算できます$O(\sqrt n)$総和メビウス関数 (メルテンス関数) を使用した個別のフロア値。

 ## 2. Python の実装```python
from functools import lru_cache

MOD = 10**9
MOD2 = 2 * MOD

def solve(n):
    # Precompute Möbius up to a cutoff
    LIMIT = 2_000_000

    mu = [0] * (LIMIT + 1)
    mu[1] = 1

    primes = []
    composite = [False] * (LIMIT + 1)

    # Linear sieve for Möbius
    for i in range(2, LIMIT + 1):
        if not composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            v = i * p
            if v > LIMIT:
                break

            composite[v] = True

            if i % p == 0:
                mu[v] = 0
                break
            else:
                mu[v] = -mu[i]

    # Prefix Mertens values
    mertens_prefix = [0] * (LIMIT + 1)
    for i in range(1, LIMIT + 1):
        mertens_prefix[i] = mertens_prefix[i - 1] + mu[i]

    @lru_cache(None)
    def M(x):
        """Summatory Möbius function."""
        if x <= LIMIT:
            return mertens_prefix[x]

        result = 1
        l = 2

        while l <= x:
            q = x // l
            r = x // q
            result -= (r - l + 1) * M(q)
            l = r + 1

        return result

    def F(m):
        """Sum_{k=1..m} (3^k - 2^k) modulo 1e9."""
        s3 = ((pow(3, m + 1, MOD2) - 3) % MOD2) // 2
        s2 = (pow(2, m + 1, MOD) - 2) % MOD
        return (s3 - s2) % MOD

    ans = 0
    l = 1

    # Group equal floor(n / i)
    while l <= n:
        q = n // l
        r = n // q

        coeff = M(r) - M(l - 1)
        ans = (ans + coeff * F(q)) % MOD

        l = r + 1

    return ans

print(solve(10**10))
```---

 ## 3. コードのチュートリアル

 1. **線形ふるい** はメビウス値を計算します$\mu(n)$。 
2. **プレフィックス合計** でメルテンス関数を構築します$$M(x)=\sum_{k\le x}\mu(k).$$1.`M(x)`大型用$x$標準の分割統治アイデンティティを使用します。$$M(x) = 1-\sum_{l=2}^{x} (r-l+1)M\!\left(\left\lfloor \frac{x}{l}\right\rfloor\right),$$等しい商をグループ化します。 

1.`F(m)`計算する$$\sum_{k=1}^{m}(3^k-2^k)$$幾何和モジュロを介して$10^9$。 

1. メイン ループ グループは次の値に等しい$$\left\lfloor \frac{n}{i}\right\rfloor$$近くを達成する$O(\sqrt n)$複雑。
