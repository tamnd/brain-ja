 ## 解決策

 **答え:**`4075`二項係数がいくつあるかを数えなければなりません$$\binom{n}{r}$$と$1 \le n \le 100$より大きい$1{,}000{,}000$。 

---

 # 数学的分析

 二項係数は$$\binom{n}{r}=\frac{n!}{r!(n-r)!}.$$階乗を使用した直接計算も可能ですが、より重要な構造観察があります。 

## 1. 二項係数の対称性

 私たちにはアイデンティティがある$$\binom{n}{r}=\binom{n}{n-r}.$$したがって、値は対称です$r=n/2$。 

例えば、$$\binom{23}{10}=\binom{23}{13}.$$この対称性は作業を軽減するのに役立ちます。 

---

 ## 2. 成長行動

 固定用$n$、シーケンス$$\binom{n}{0}, \binom{n}{1}, \dots, \binom{n}{n}$$中央まで増加し、その後対称的に減少します。 

したがって、係数が 100 万を超えると、中央に近いすべての係数も 100 万を超えます。 

したがって、それぞれについて$n$:

 1. 最初のものを見つける$r$そのような$$\binom{n}{r} > 1{,}000{,}000.$$1. 次に、からのすべての値$r$を通して$n-r$100万を超える。 

したがって、その行によって寄与されるカウントは次のようになります。$$(n-r) - r + 1 = n - 2r + 1.$$---

 ## 3. 効率的な繰り返し

 階乗の代わりに、次を使用して係数を繰り返し計算します。$$\binom{n}{r} = \binom{n}{r-1}\cdot\frac{n-r+1}{r}.$$これにより、膨大な階乗計算が回避されます。 

から始める$$\binom{n}{0}=1.$$その後、次の係数を繰り返し生成します。 

---

 # Pythonの実装```python
# Count binomial coefficients greater than one million

LIMIT = 1_000_000
count = 0

# Loop through all n from 1 to 100
for n in range(1, 101):

    # Start with C(n,0) = 1
    c = 1

    # Compute coefficients iteratively
    for r in range(1, n + 1):

        # Recurrence relation:
        # C(n,r) = C(n,r-1) * (n-r+1) / r
        c = c * (n - r + 1) // r

        # Once we exceed the limit,
        # all coefficients up to C(n,n-r) also exceed it
        if c > LIMIT:
            count += (n - 2 * r + 1)
            break

print(count)
```---

 # 小規模な例の検証

 問題には次のように書かれています。$$\binom{23}{10} = 1144066 > 1{,}000{,}000.$$確かに、$n=23$、最初の超過係数は次の時点で発生します。$r=10$。 

対称性により:$$\binom{23}{10}, \binom{23}{11}, \binom{23}{12}, \binom{23}{13}$$どれも100万を超えています。 

カウント：$$23 - 2(10) + 1 = 4,$$それは一致します。
