[プロジェクト オイラー問題 545](https://projecteuler.net/problem=545)

 ## 解決策

 **答え:**`921107572`させて$$S_k(n)=\sum_{i=1}^n i^k$$ファウルハーバー多項式になります。 の係数に興味があります。$n$、その分母は$D(k)$。 

### 1. ベルヌーイ数接続

 ファールハーバーの公式は、$$\sum_{i=1}^n i^k = \frac{1}{k+1} \sum_{j=0}^{k} (-1)^j \binom{k+1}{j} B_j n^{k+1-j},$$どこ$B_j$はベルヌーイ数です。 

の係数$n$という用語から来ています$j=k$、 それで：$$a_1 = B_k.$$したがって、次のようになります。$$D(k)=\text{denominator}(B_k).$$例えば、$$B_4=-\frac{1}{30},$$それで$D(4)=30$、問題文と一致します。 

---

 ### 2. フォン・シュタウト・クラウゼンの定理を適用する

 定理は次のように述べています。$$\operatorname{den}(B_k) = \prod_{p-1\mid k} p \qquad (k \text{ even}),$$積が素数を超える場合$p$そのような$p-1\mid k$。 

私たちが望んでいるのは:$$D(k)=20010.$$要素：$$20010 = 2\cdot 3\cdot 5\cdot 23\cdot 29.$$したがって、**のみ**の素数は$p$と$p-1\mid k$でなければなりません$$p\in\{2,3,5,23,29\}.$$同様に、$$1,2,4,22,28 \mid k,$$でも**他にはありません**$p-1$分割するかもしれない$k$。 

最小公倍数は$$\mathrm{lcm}(1,2,4,22,28)=308.$$したがって、すべての有効な$k$形を持っています$$k=308t.$$条件は次のようになります。 

あらゆる約数について$d\mid 308$、$$dt+1$$複合素数でなければなりません (それ以外の場合は新しい素数)$q=dt+1$満足するだろう$q-1\mid k$、分母に不要な係数を追加します)。 

これにより、再帰的な乗算テストが行われます。 

-$t=1$有効です ($k=308$、与える$F(1)=308$）。 
- 数字$t$次の場合に有効です。 

1.すべて$dt+1$のために$d\mid 308$複合的であり、
 2. 毎$t/p$(素数の場合$p\mid t$）は有効です。 

これにより次のことが再現されます。$$F(10)=96404,$$ステートメントと一致します。

 ### 3. Python の実装```python
import sympy as sp

DIVS = sp.divisors(308)

def find_F(target):
    N = 200000

    while True:
        # Smallest prime factor sieve
        spf = list(range(N + 1))
        for i in range(2, int(N**0.5) + 1):
            if spf[i] == i:
                for j in range(i * i, N + 1, i):
                    if spf[j] == j:
                        spf[j] = i

        good = [False] * (N + 1)
        good[1] = True

        count = 1  # t = 1 corresponds to F(1)=308

        for t in range(2, N + 1):

            # Local primality condition:
            # d*t + 1 must be composite for all d | 308
            local_ok = True
            for d in DIVS:
                if sp.isprime(d * t + 1):
                    local_ok = False
                    break

            if not local_ok:
                continue

            # Recursive divisor condition
            n = t
            ok = True
            used = set()

            while n > 1:
                p = spf[n]
                if p not in used:
                    used.add(p)
                    if not good[t // p]:
                        ok = False
                        break
                n //= p

            if ok:
                good[t] = True
                count += 1

                if count == target:
                    return 308 * t

        N *= 2

print(find_F(10))      # 96404
print(find_F(100000))  # final answer
```---

 ### 4. コードのチュートリアル

 -`DIVS = divisors(308)`すべての約数を計算します$308$。 
- 数字を検索します$t$そのような$k=308t$。 
- それぞれについて$t$、すべてかどうかをテストします$dt+1$複合です。 
- すべてをチェックすることで、再帰的な除数プロパティも適用します。$t/p$、 どこ$p$～の素約数を超える$t$。 
- 有効とみなします$t$まで昇順に並んでいます$100000$- 番目のもの。 

検証：

-$F(1)=308$✔
 -$F(10)=96404$✔
