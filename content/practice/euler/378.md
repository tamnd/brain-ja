[プロジェクト オイラー問題 378](https://projecteuler.net/problem=378)

 ## 解決策

 **答え:**`147534623725724718`させて$$T(n)=\frac{n(n+1)}2$$そしてさせてください$dT(n)$は約数の数を示します$T(n)$。 

私たちが欲しいのは$$Tr(N)=\#\{(i,j,k):1\le i<j<k\le N,\ dT(i)>dT(j)>dT(k)\}$$のために$N=60\,000\,000$。 

---

 #1. 数学的分析

 ## ステップ 1: の式$dT(n)$連続する整数は互いに素であるため、$$\gcd(n,n+1)=1.$$したがって、次のようになります。 

- もし$n$均等です、$$T(n)=\frac n2 (n+1),$$そして$\frac n2$と互いに素である$n+1$;

 - もし$n$奇妙です、$$T(n)=n\cdot \frac{n+1}{2},$$そして$n$と互いに素である$\frac{n+1}{2}$。 

divisor-count 関数以来$\tau(n)$互いに素な引数で乗算されます。$$dT(n)= \begin{cases} \tau(n/2)\tau(n+1), & n\text{ even},\\[4pt] \tau(n)\tau((n+1)/2), & n\text{ odd}. \end{cases}$$したがって、問題全体は、除数カウントを効率的に生成することに帰着します。 

---

 ## ステップ 2: 減少するトリプルを数える

 定義する$$a_n=dT(n).$$トリプルを数えなければなりません$$i<j<k,\qquad a_i>a_j>a_k.$$修理$j$。 次に:

 - しましょう$L_j$の数になります$i<j$と$a_i>a_j$、
- させて$R_j$の数になります$k>j$と$a_k<a_j$。 

次に、中間のインデックスを持つすべての有効なトリプル$j$正確に 1 回だけ貢献するため、$$Tr(N)=\sum_{j=1}^N L_jR_j.$$したがって、必要なのは次のものだけです。 

1. シーケンス$a_n$、
 2. 高速なプレフィックス/サフィックス頻度クエリ。 

これは古典的なフェンウィック ツリー (バイナリ インデックス ツリー) の問題です。 

---

 ## ステップ 3: 除数の数を計算する

 最小の素因数をふるいにかけます$N+1$。 

SPF テーブルからすべての約数を計算します$\tau(n)$線形時間で。 

それから：$$a_n= \begin{cases} \tau(n/2)\tau(n+1), & n\equiv0\pmod2,\\ \tau(n)\tau((n+1)/2), & n\equiv1\pmod2. \end{cases}$$の値$a_n$は比較的小さいため、それらを調整圧縮してフェンウィック ツリーを使用します。 

複雑さ:

 - 除数ふるい:$O(N)$、
 - フェンウィックがパス:$O(N\log M)$、

どこ$M$個別の除数カウントの数です。 

これは、最適化された Python / PyPy または C++ では十分に高速です。 

---

 #2. Pythonの実装```python
from array import array

N = 60_000_000

# ---------------------------------------------------------
# Smallest prime factor sieve
# ---------------------------------------------------------

spf = array('I', [0]) * (N + 2)
primes = []

for i in range(2, N + 2):
    if spf[i] == 0:
        spf[i] = i
        primes.append(i)

    for p in primes:
        v = p * i
        if v > N + 1 or p > spf[i]:
            break
        spf[v] = p

# ---------------------------------------------------------
# divisor-count function tau(n)
# ---------------------------------------------------------

tau = array('I', [0]) * (N + 2)
tau[1] = 1

exp = array('I', [0]) * (N + 2)
core = array('I', [0]) * (N + 2)

for n in range(2, N + 2):
    p = spf[n]
    m = n // p

    if spf[m] == p:
        exp[n] = exp[m] + 1
        core[n] = core[m]
    else:
        exp[n] = 1
        core[n] = m

    tau[n] = tau[core[n]] * (exp[n] + 1)

# ---------------------------------------------------------
# Build dT(n)
# ---------------------------------------------------------

A = array('I', [0]) * (N + 1)

for n in range(1, N + 1):
    if n & 1:
        A[n] = tau[n] * tau[(n + 1) // 2]
    else:
        A[n] = tau[n // 2] * tau[n + 1]

# ---------------------------------------------------------
# Coordinate compression
# ---------------------------------------------------------

vals = sorted(set(A[1:]))
rank = {v: i + 1 for i, v in enumerate(vals)}
M = len(vals)

# ---------------------------------------------------------
# Fenwick tree
# ---------------------------------------------------------

class BIT:
    def __init__(self, n):
        self.n = n
        self.bit = array('Q', [0]) * (n + 1)

    def add(self, idx, val):
        while idx <= self.n:
            self.bit[idx] += val
            idx += idx & -idx

    def sum(self, idx):
        s = 0
        while idx > 0:
            s += self.bit[idx]
            idx -= idx & -idx
        return s

# ---------------------------------------------------------
# Left counts
# ---------------------------------------------------------

L = array('Q', [0]) * (N + 1)

bit = BIT(M)

for j in range(1, N + 1):
    r = rank[A[j]]
    total = j - 1
    not_greater = bit.sum(r)
    L[j] = total - not_greater
    bit.add(r, 1)

# ---------------------------------------------------------
# Right counts and final answer
# ---------------------------------------------------------

bit = BIT(M)

ans = 0

for j in range(N, 0, -1):
    r = rank[A[j]]
    R = bit.sum(r - 1)
    ans += L[j] * R
    bit.add(r, 1)

print(ans % (10**18))
```---

 #3. コードのチュートリアル

 ## SPFふるい

 最初のブロックは最小素因数テーブルを構築します。 

例：

-$spf[12]=2$、
 -$spf[35]=5$。 

これにより、すべての整数を高速に因数分解できます。 

---

 ## 除数カウントテーブル

 繰り返しを使用する$$\tau(p^e m)=\tau(m)(e+1),$$すべての約数を線形時間で計算します。 

例：$$28=2^2\cdot7$$それで$$\tau(28)=(2+1)(1+1)=6.$$したがって$dT(7)=6$、ステートメントと一致します。 

---

 ## 構築中$dT(n)$私たちが使用するのは$$dT(n)= \begin{cases} \tau(n/2)\tau(n+1), & n\text{ even},\\ \tau(n)\tau((n+1)/2), & n\text{ odd}. \end{cases}$$これにより、巨大な三角数自体を構築することがなくなります。 

---

 ## フェンウィックの木の数え方

 ポジションごとに$j$:

 - 最初のパスでは、以前の値がどれだけ大きいかを計算します。 
- 2 番目のパスでは、後の値がどれだけ小さいかを計算します。 

それから$$Tr(N)=\sum_j L_jR_j.$$---
