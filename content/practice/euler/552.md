[プロジェクト オイラー問題 552](https://projecteuler.net/problem=552)

 ## 解決策

 **答え:**`326227335`させて$$A_n \equiv i \pmod{p_i}\qquad (1\le i\le n),$$どこ$p_i$です$i$-番目の素数、および$A_n$は_最小の正_解です。 

計算しなければなりません$$S(300000)=\sum_{\substack{p\le 300000\\ p\mid A_n\text{ for some }n}} p.$$---

 #1. 数学的分析

 ## 1.1 構築$A_n$定義する$$P_n=\prod_{i=1}^n p_i .$$すでに知っていると仮定してください$A_n$。 

次に、最初のすべての解決策$n$合同は$$A_n+kP_n.$$入手するには$A_{n+1}$、必要です$$A_n+kP_n \equiv n+1 \pmod{p_{n+1}}.$$以来$P_n$と互いに素である$p_{n+1}$、独自の解決策があります。$$k \equiv (n+1-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$最小の非負値を選択する$k$与える$A_{n+1}$。 

したがって：$$A_{n+1}=A_n+t_nP_n,$$どこ$$t_n=((n+1)-A_n)\,P_n^{-1}\pmod{p_{n+1}}.$$---

 # 1.2 可分性に関する重要な観察

 素数を修正する$q=p_k$。 

あらゆる人にとって$n\ge k$、$$A_n \equiv k \pmod{p_k},$$定義系にはすでに合同モジュロが含まれているため、$p_k$。 

したがって:

 - もし$p_k\mid A_n$、そうすると必然的に$n<k$。 

したがって、各素数について$p_k$、残基を追跡するだけで済みます。$$A_1,A_2,\dots,A_{k-1}\pmod{p_k}.$$---

 # 1.3 残基を効率的に更新する

 巨大な整数は必要ありません$A_n$彼ら自身。 

将来の素数ごとに$p_k$、 維持する：

-$r_k = A_n \bmod p_k$、
 -$c_k = P_n \bmod p_k$。 

最初に:$$A_1=1,\qquad P_1=2.$$したがって、すべての人にとって$k>1$:$$r_k=1,\qquad c_k=2.$$ここで、次から移動するとします。$A_n$に$A_{n+1}$。 

すでに計算しています:$$A_{n+1}=A_n+t_nP_n.$$したがって、将来の素数を法的に計算します$p_k$、$$r_k \leftarrow r_k+t_n c_k \pmod{p_k},$$

$$c_k \leftarrow c_k\,p_{n+1}\pmod{p_k}.$$いつでも$r_k=0$、いくつかを分割する素数を見つけました$A_n$。 

---

 #1.4 複雑さ

 あります$$\pi(300000)=25997$$までの素数$300000$。 

このアルゴリズムは、三角形の一連の更新を実行します。$$\sum_{i=1}^{m} (m-i)=O(m^2),$$それは約です$3.4\times 10^8$モジュラーアップデート。 

ベクトル化された NumPy 操作を使用すると、実際には高速に実行されます。 

---

 #2. Pythonの実装```python
import numpy as np
from math import isqrt

LIMIT = 300000

# ------------------------------------------------------------
# Sieve of Eratosthenes
# ------------------------------------------------------------
is_prime = bytearray(b"\x01") * (LIMIT + 1)
is_prime[0:2] = b"\x00\x00"

for p in range(2, isqrt(LIMIT) + 1):
    if is_prime[p]:
        is_prime[p * p : LIMIT + 1 : p] = (
            b"\x00" * (((LIMIT - p * p) // p) + 1)
        )

primes_list = [i for i, v in enumerate(is_prime) if v]
primes = np.array(primes_list, dtype=np.int64)

m = len(primes)

# ------------------------------------------------------------
# r[k] = current A_n mod p_k
# c[k] = current P_n mod p_k
# ------------------------------------------------------------
r = np.ones(m, dtype=np.int64)

c = np.empty(m, dtype=np.int64)
c[0] = 0
c[1:] = 2

# hit[k] becomes True if p_k divides some A_n
hit = np.zeros(m, dtype=bool)

# ------------------------------------------------------------
# Main recurrence
# ------------------------------------------------------------
for n in range(1, m - 1):

    q = int(primes[n])  # p_(n+1)

    # t_n = ((n+1) - A_n) * P_n^{-1} mod p_(n+1)
    t = ((n + 1) - int(r[n])) * pow(int(c[n]), -1, q) % q

    # Update all future residues simultaneously
    sl = slice(n + 1, m)

    r[sl] = (r[sl] + t * c[sl]) % primes[sl]
    c[sl] = (c[sl] * q) % primes[sl]

    # Any zero residue means divisibility
    hit |= (r == 0)

# ------------------------------------------------------------
# Final answer
# ------------------------------------------------------------
answer = int(primes[hit].sum())

print(answer)
```---

 #4. 例の検証

 のために$n\le 50$、プログラムは正確に次のものを見つけます:$$5,\ 23,\ 41$$いくつかを分割する素数として$A_n$。 

したがって$$S(50)=5+23+41=69,$$ステートメントと一致します。
