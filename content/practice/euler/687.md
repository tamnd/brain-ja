[プロジェクト オイラー問題 687](https://projecteuler.net/problem=687)

 ## 解決策

 **答え:**`0.3285320869`させて$X$は、均一にシャッフルされたデッキ内の完全なランクの数になります。 

私たちは、$52!$**異なる**カードの順列。 

そのランクの 2 枚のカードが隣接していない場合、そのランクは「完璧」です。 

---

 #1. 数学的分析

 各ランクには、$4$カード。 

定義する：$$A_r = \{\text{rank } r \text{ is perfect}\}.$$必要です$$\Pr(X \text{ is prime}).$$可能な素数値は次のとおりです。$$2,3,5,7,11,13.$$---

 ## ステップ 1: 固定されたランクのセットが完璧である確率

 次の固定セットがあるとします。$t$ランクはすべて完璧でなければなりません。 

これらの条件を満たす順列を包含-除外によって数えます。 

---

 ### 1 つのランクの包含と除外

 カードでランクを1つ上げる$$a_1,a_2,a_3,a_4.$$強制的に隣接させるには、隣接するカードをブロックにマージします。 

まさに$j$隣接関係が強制されます ($j=0,1,2,3$)、4 枚のカードは次のようになります。$$4-j$$ブロック。 

これらの隣接関係を選択する方法は次のとおりです。$$\binom{3}{j}.$$マージ後のオブジェクトの総数は次のようになります。$$52-j.$$したがって、貢献度は$$(-1)^j \binom{3}{j}\frac{(52-j)!}{(4-j)!}.$$- -

＃＃＃ のために$t$指定されたランク

 ランク付けしましょう$i$貢献する$j_i\in\{0,1,2,3\}$。 

次に:

 - 合計マージ:$$s=j_1+\cdots+j_t,$$- オブジェクトの合計:$$52-s,$$- 制約された各ランクは係数に寄与します$$(-1)^{j_i}\binom{3}{j_i}\frac1{(4-j_i)!}.$$残り$13-t$ランクが貢献する$(4!)^{-(13-t)}$。 

したがって、有利な置換の数は次のようになります。$$N_t = \sum_{j_1,\dots,j_t} (52-s)! \prod_{i=1}^t \left( (-1)^{j_i} \binom{3}{j_i} \frac1{(4-j_i)!} \right) \frac1{(4!)^{13-t}}.$$ランクパターンの置換の総数は次のとおりです。$$\frac{52!}{(4!)^{13}}.$$したがって$$p_t = \Pr(\text{a fixed set of }t\text{ ranks are perfect}) = \frac{N_t}{52!/(4!)^{13}}.$$---

 ## ステップ 2: ディストリビューションを回復する$X$対称性により、$$\binom{13}{t}p_t = \mathbb E\!\left[\binom Xt\right].$$したがって、$$\binom{13}{t}p_t = \sum_{k=t}^{13}\binom{k}{t}\Pr(X=k).$$これは二項変換です。 それを反転すると、$$\Pr(X=k) = \sum_{t=k}^{13} (-1)^{t-k} \binom{t}{k} \binom{13}{t} p_t.$$次に素数を合計します$k$。 

---

 #2. Pythonの実装```python
from math import factorial, comb
from collections import defaultdict

# Total number of rank-pattern permutations
TOTAL = factorial(52) / (factorial(4) ** 13)

# p[t] = probability that a fixed set of t ranks are perfect
p = []

for t in range(14):

    # DP over total number of merges s
    dp = {0: 1.0}

    for _ in range(t):
        ndp = defaultdict(float)

        for s, val in dp.items():
            for j in range(4):
                ndp[s + j] += (
                    val
                    * ((-1) ** j)
                    * comb(3, j)
                    / factorial(4 - j)
                )

        dp = ndp

    favorable = 0.0

    for s, coeff in dp.items():
        favorable += (
            factorial(52 - s)
            * coeff
            / (factorial(4) ** (13 - t))
        )

    p.append(favorable / TOTAL)

# Recover exact distribution of X
P = [0.0] * 14

for k in range(14):
    total = 0.0

    for t in range(k, 14):
        total += (
            ((-1) ** (t - k))
            * comb(t, k)
            * comb(13, t)
            * p[t]
        )

    P[k] = total

# Prime values
primes = [2, 3, 5, 7, 11, 13]

answer = sum(P[k] for k in primes)

print(f"{answer:.10f}")
```---

制約付きランクごとに次のようになります。```python

```強制に相当する$j$隣接関係。 

要因```python

```はまさに包含と除外の寄与です。 

全部処理したら$t$ランク、各州`s`貢献する```python

```マージされた構成には$52-s$オブジェクト。

 ### ディストリビューションの回復

 反転公式を使用します$$\Pr(X=k) = \sum_{t=k}^{13} (-1)^{t-k} \binom{t}{k} \binom{13}{t} p_t.$$これにより、すべての可能な値に対する正確な確率が生成されます。$X$。 

最後に素数の場合を合計します。
