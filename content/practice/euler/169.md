[プロジェクト オイラー問題 169](https://projecteuler.net/problem=169)

 ## 解決策

 **答え:**`178653872807`の表現の数を計算する必要があります。$$10^{25}$$べき乗の合計として$2$、各電力は最大 2 回使用できます。 

定義する$$f(n)=\#\left\{n=\sum_{k\ge0} a_k2^k \;\middle|\; a_k\in\{0,1,2\}\right\}.$$私たちは求められています$f(10^{25})$。 

---

 # 数学的分析

 問題は基本的に **バイナリ キャリー**に関するものです。 

仮定する$$n=\sum_{k\ge0} b_k2^k$$の通常のバイナリ展開です$n$、 どこ$b_k\in\{0,1\}$。 

数字列の数を求めます$$a_k\in\{0,1,2\}$$そのような$$\sum a_k2^k=n.$$重要な観察は、隣接するビット間の唯一の相互作用はキャリーによるものであるということです。 

---

 ## キャリーベースの動的プログラミング

 最下位から最上位までビットを処理します。 

ビット位置で$k$:

 - ターゲットビットは$b_k\in\{0,1\}$、
 - 係数を選択します$a_k\in\{0,1,2\}$、
 - キャリーもお受けできる場合がございます$c_k$前のビットから。 

必要です$$a_k + c_k \equiv b_k \pmod 2.$$次のキャリーは、$$c_{k+1}=\frac{a_k+c_k-b_k}{2}.$$なぜなら$a_k\le2$キャリーは小さいままなので、状態空間は非常に小さいです。 

したがって、計算できます$f(n)$数字のDP付き。 

- -

＃＃ 例：$f(10)$バイナリ：$$10 = 1010_2.$$キャリー再帰を実行すると、ちょうど 5 つの表現が得られます。$$\begin{aligned} 10 &= 8+2\\ &=8+1+1\\ &=4+4+2\\ &=4+4+1+1\\ &=4+2+2+1+1. \end{aligned}$$それで$f(10)=5$、ステートメントと一致します。

 # Pythonの実装```python
from functools import lru_cache

def f(n):
    # Binary digits of n
    bits = list(map(int, bin(n)[2:]))

    @lru_cache(None)
    def dp(pos, carry):
        """
        pos   : current bit position (from least significant upward)
        carry : incoming carry at this bit

        Returns the number of valid completions.
        """

        # All bits processed
        if pos == len(bits):
            return 1 if carry == 0 else 0

        # Current target bit of n
        bit = bits[-1 - pos]

        total = 0

        # Choose coefficient a_k in {0,1,2}
        for digit in (0, 1, 2):

            s = digit + carry

            # Parity must match the target bit
            if s % 2 == bit:

                # Compute next carry
                next_carry = (s - bit) // 2

                total += dp(pos + 1, next_carry)

        return total

    return dp(0, 0)

# Problem value
print(f(10**25))
```---
