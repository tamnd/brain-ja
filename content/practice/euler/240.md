[プロジェクト オイラー問題 240](https://projecteuler.net/problem=240)

 ## 解決策

 **答え:**`7448717393364181966`させてください$20$サイコロの出目は昇順ではない順序で並べ替えられます。$$x_1 \ge x_2 \ge \cdots \ge x_{20},$$それぞれどこで$x_i \in \{1,\dots,12\}$。 

問題の条件は、$$x_1+x_2+\cdots+x_{10}=70.$$重要な観察は、サイコロの順序が重要なのは最後だけであるということです。 

それぞれの額面の**多重度**によって数えることははるかに簡単です。 

---

 #1. 数学的分析

 次のように仮定します。$$c_v = \text{number of dice showing value } v$$のために$v=1,\dots,12$。 

それから：$$c_1+c_2+\cdots+c_{12}=20.$$任意の固定多重度ベクトルの場合$(c_1,\dots,c_{12})$、注文されたロールの数は$$\frac{20!}{c_1!c_2!\cdots c_{12}!}.$$したがって、問題は次のようになります。 

> どの多重度ベクトルが、最大 10 個のサイコロの和になる特性を持っていますか$70$?

 ---

 ## 各値の上位 10 位への寄与度を決定する

 値を高いものから低いものへと処理します。 

価値を考慮するとします$v$。 

させて$$H_v = c_{v+1}+c_{v+2}+\cdots+c_{12}$$より厳密に大きいサイコロの数であること$v$。 

それから、その中で、$c_v$等しいサイコロ$v$、 その通り$$t_v = \min(c_v,\; 10-H_v)$$トップ 10 に属している (ただし、$H_v<10$; それ以外の場合は何もしません）。 

したがって、上位 10 位の合計条件は次のようになります。$$\sum_{v=1}^{12} v\, t_v = 70.$$したがって、次を満たす多重度ベクトルをすべて列挙するだけです。 

- サイコロの合計 =$20$、
 - 誘導された上位 10 位の合計 =$70$、

 そして蓄積する$$\frac{20!}{\prod_v c_v!}.$$---

 #2. Pythonの実装```python
from math import factorial

def count_ways(num_dice, sides, top_count, target_sum):
    fact = [factorial(i) for i in range(num_dice + 1)]

    answer = 0

    def search(v, remaining_dice, top_used, top_sum, counts):
        """
        v               current face value being assigned
        remaining_dice  dice still unassigned
        top_used        how many of the top dice are already determined
        top_sum         current sum of the top dice
        counts          list of multiplicities chosen so far
        """
        nonlocal answer

        # Finished assigning all face values
        if v == 0:
            if (
                remaining_dice == 0
                and top_used == top_count
                and top_sum == target_sum
            ):
                ways = fact[num_dice]
                for c in counts:
                    ways //= fact[c]
                answer += ways
            return

        # Try all possible counts for face value v
        for c in range(remaining_dice + 1):

            # How many of these c dice appear in the top group?
            take = min(c, max(0, top_count - top_used))

            new_sum = top_sum + v * take

            # Prune impossible branches
            if new_sum > target_sum:
                break

            counts.append(c)

            search(
                v - 1,
                remaining_dice - c,
                top_used + take,
                new_sum,
                counts,
            )

            counts.pop()

    search(sides, num_dice, 0, 0, [])

    return answer

# Check the small example from the statement
print(count_ways(5, 6, 3, 15))

# Solve the actual problem
print(count_ways(20, 12, 10, 70))
```---
