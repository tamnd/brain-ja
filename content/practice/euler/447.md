[プロジェクト オイラー問題 447](https://projecteuler.net/problem=447)

 ## 解決策

 **答え:**`530553372`### ステップ 1 — 収縮の特徴を明らかにする$f(f(x)) = a(ax+b)+b = a^2x + ab + b$。 

条件$f(f(x)) \equiv f(x) \pmod{n}$みんなのために$x$必要：$$n \mid a(a-1) \quad \text{and} \quad n \mid ab.$$**条件 1** —$a$べき等である必要があります$\mathbb{Z}/n\mathbb{Z}$:$a^2 \equiv a$。 

なぜなら$\gcd(a,a-1)=1$、各素数パワーに対して$p^k \| n$私たちは必要です$p^k \mid a$または$p^k \mid (a-1)$。 CRT によって、べき等$\mathbb{Z}/n\mathbb{Z}$は、それぞれの素数べき成分に対して独立して選択することによって得られる要素です。$p_i^{k_i}$、 かどうか$a \equiv 0$または$a \equiv 1 \pmod{p_i^{k_i}}$。 がある$2^{\omega(n)}$冪等(冪等を含む)$0$)、したがって$2^{\omega(n)}-1$ゼロ以外のべき等$0 < a < n$。 

**条件 2** — 有効な場合$a$、カウント$b$。$n \mid ab$もし$b \equiv 0 \pmod{n/\gcd(a,n)}$。 まさにあります$\gcd(a,n)$そのような$b$で$[0,n)$。 

冪等の場合$a$サブセットから構築$S$主電源コンポーネント ($a \equiv 0$):$$\gcd(a,n) = \prod_{p^k \in S} p^k.$$### ステップ 2 — R(n) の閉じた形式$$R(n) = \sum_{\substack{S \subsetneq \{p_1^{k_1},\ldots,p_m^{k_m}\}}} \prod_{p^k \in S} p^k = \prod_{i=1}^{m}(1 + p_i^{k_i}) - \prod_{i=1}^{m} p_i^{k_i} = \sigma^*(n) - n$$どこ$\sigma^*(n) = \prod_{p^k \| n}(1+p^k)$**ユニタリ除数の和** (乗法関数) です。 

検証：$n=6=2\cdot3$、$\sigma^*(6)=(1+2)(1+3)=12$、$R(6)=6$。 直接カウント:$a\in\{1,3,4\}$、$b$-カウント$1,3,2$合計して$6$。 ✓

 ### ステップ 3 — F(N) を減らす$$F(N) = \sum_{n=2}^{N}(\sigma^*(n) - n) = G(N) - \frac{N(N+1)}{2}$$どこ$G(N) = \sum_{n=1}^{N}\sigma^*(n)$。 

### ステップ 4 — メビウス反転による G(N) の計算

 単一の約数$d$の$n$満足する$d \mid n$そして$\gcd(d, n/d)=1$。 それで：$$G(N) = \sum_{d=1}^{N} d \cdot \#\{n \le N : d \| n\} = \sum_{d=1}^{N} d \cdot \#\{m \le N/d : \gcd(m,d)=1\}.$$メビウス反転を適用して書き込み$d = ek$:$$G(N) = \sum_{e=1}^{\lfloor\sqrt{N}\rfloor} \mu(e)\cdot e \cdot S\!\left(\left\lfloor\frac{N}{e^2}\right\rfloor\right)$$どこ$S(M) = \sum_{k=1}^{M} k\left\lfloor\frac{M}{k}\right\rfloor = \sum_{m=1}^{M}\sigma(m)$。 

### ステップ 5 — O(√M) で S(M) を計算する

 グループ$k$の等しい値によって$q = \lfloor M/k\rfloor$。 各グループは連続した範囲です$[k_0, k_1)$と$k_1 = \lfloor M/q\rfloor + 1$、貢献$q \cdot (k_0+k_1-1)(k_1-k_0)/2$。 while ループが実行される$O(\sqrt{M})$繰り返し。 

### Python の実装```python
from math import isqrt

MOD = 10**9 + 7

def solve(N):
    sqN = isqrt(N)

    # Linear sieve: Mobius function up to sqrt(N)
    mu = [0] * (sqN + 1)
    mu[1] = 1
    primes = []
    is_comp = bytearray(sqN + 1)
    for i in range(2, sqN + 1):
        if not is_comp[i]:
            primes.append(i)
            mu[i] = -1
        for p in primes:
            ip = i * p
            if ip > sqN:
                break
            is_comp[ip] = 1
            if i % p == 0:
                mu[ip] = 0
                break
            mu[ip] = -mu[i]

    def S(M):
        total = 0
        k = 1
        while k <= M:
            q = M // k
            nk = M // q + 1
            cnt = nk - k
            s = (k + nk - 1) * cnt // 2 % MOD
            total = (total + q * s) % MOD
            k = nk
        return total

    G = 0
    for e in range(1, sqN + 1):
        if mu[e] == 0:
            continue
        M = N // (e * e)
        if M == 0:
            break
        G = (G + mu[e] * e % MOD * S(M)) % MOD

    tri = N % MOD * ((N + 1) % MOD) % MOD * pow(2, MOD - 2, MOD) % MOD
    return (G - tri) % MOD

assert solve(10**7) == 638042271
print(solve(10**14))  # → 530553372
```**複雑：**$O(\sqrt{N}\log N)$— ふるい$O(\sqrt{N})$; メインループ$\sum_{e \le \sqrt{N}} O(\sqrt{N/e^2}) = O(\sqrt{N}\log\sqrt{N})$。
