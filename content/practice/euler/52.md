[プロジェクト オイラー問題 52](https://projecteuler.net/problem=52)

 ## 解決策

 **答え:**`142857`最小の正の整数を探します$x$そのような$$2x,\;3x,\;4x,\;5x,\;6x$$すべてにまったく同じ数字が含まれています$x$、単に並べ替えただけです。 

この特性を持つ数値は、_permuted multiple_ と呼ばれることもあります。 

---

 # 数学的分析

 重要な条件は次のとおりです。$$\text{digits}(x)=\text{digits}(2x)=\cdots=\text{digits}(6x)$$ここで、「数字」は 10 進数の複数セットを意味します。 

2 つの数値に同じ数字が含まれているかどうかをテストする自然な方法は次のとおりです。 

- 文字列に変換します。 
- 数字を並べ替えます。 
- ソートされた文字列を比較します。 

例えば：$$125874 \to "125874" \to "124578"$$

$$251748 \to "251748" \to "124578"$$それで一致します。 

---

 ## 重要な観察: 同じ桁数

 もし$x$もっている$d$数字、その後$6x$も持っている必要があります$d$数字。 

仮定する$x$もっている$d$数字。 それから$$10^{d-1} \le x < 10^d$$のために$6x$も持つ$d$数字:$$6x < 10^d$$それで$$x < \frac{10^d}{6}$$これにより、探索範囲が大幅に狭まります。 

たとえば、6 桁の数字の場合:$$100000 \le x < \frac{1000000}{6} \approx 166666$$したがって、チェックする必要があるのは短い間隔だけです。 

---

 ## アルゴリズム

 正の整数ごとに$x$:

 1. その桁の正規表現を計算します。$$s(x)=\text{sorted digits of }x$$2. かどうかを確認します。$$s(x)=s(2x)=s(3x)=s(4x)=s(5x)=s(6x)$$3. 最初のそのようなもの$x$が答えです。 

この総当たり検索は、解決がかなり早い段階で行われるため、効率的です。 

---

 # Pythonの実装```python
def signature(n):
    """
    Return a canonical representation of the digits of n.
    Numbers with the same digits will have the same signature.
    """
    return ''.join(sorted(str(n)))

x = 1

while True:
    # Compute the digit signature of x
    sig = signature(x)

    # Check whether 2x through 6x have identical digit signatures
    if all(signature(k * x) == sig for k in range(2, 7)):
        print(x)
        break

    x += 1
```---
