[プロジェクト オイラー問題 605](https://projecteuler.net/problem=605)

 ## 解決策

 **答え:**`59992576`させて$T$ゲームが終了するラウンドになります。 

プレイヤーは、自分が参加するラウンドを 2 回連続で勝利すると勝ちとなります。 エンコードラウンド$r$少しずつ：

 -$b_r = 0$: ラウンドの**最初**のプレイヤー$r$勝ち、
 -$b_r = 1$: **2番目**のプレイヤーが勝ちます。 

ラウンド用$$(i,i+1),\ (i+1,i+2),$$プレーヤー$i+1$結果が次の場合は両方に勝ちます$$(1,0).$$したがって、**パターンが最初に出現した時点でゲームは終了します$10$** 無限フェアコインシーケンス内$(b_r)$。 

### ステップ 1: 最初の配布$10$最初のものを仮定します$10$ラウンドで終了する$r$。 次に:

 - それより早く$10$に登場する$b_1,\dots,b_{r-1}$、
 -$b_{r-1}=1,\ b_r=0$。 

バイナリ文字列の回避$10$次の形式でなければなりません$$0^a1^b$$(モノトーン: 1 回$1$すぐに表示されます$0$表示される場合があります）。 

最初で終わるには$10$ラウンド中$r$、 最初$r-1$ビットは必ず$$0^a1^{r-1-a},$$で終わる$1$、そしてまさにあります$r-1$～の選択肢$a$。 

したがって、$$\Pr(T=r)=\frac{r-1}{2^r}.$$### ステップ 2: どのプレイヤーが勝ちますか?

 プレーヤー$k$最初に勝ったとき$10$ラウンドで終了$$r \equiv k \pmod n.$$以来$k=10^4+7>1$、有効なラウンドは次のとおりです。$$r = k + mn,\qquad m\ge0.$$したがって$$P_n(k) = \sum_{m\ge0} \frac{k+mn-1}{2^{k+mn}}.$$させて$$A=2^n-1.$$等比級数を使うと、$$P_n(k) = 2^{-k} \left( \frac{k-1}{1-2^{-n}} + \frac{n\,2^{-n}}{(1-2^{-n})^2} \right).$$以来$$1-2^{-n}=\frac{A}{2^n},$$これを単純化すると、$$P_n(k) = \frac{2^{\,n-k}\big((k-1)A+n\big)}{A^2}.$$のために$k>1$、次の理由により、端数はすでに削減されています。 

-$A=2^n-1$奇妙です、
 -$\gcd((k-1)A+n,A)=\gcd(n,A)=1$。 

したがって$$M_n(k) = 2^{\,n-k} \big((k-1)A+n\big) A^2.$$最後だけ必要です$8$数字、つまりモジュロ$10^8$。 

Python コード:```python
MOD = 10**8

n = 10**8 + 7
k = 10**4 + 7

# A = 2^n - 1 (mod 10^8)
A = (pow(2, n, MOD) - 1) % MOD

# B = (k - 1)A + n (mod 10^8)
B = ((k - 1) * A + n) % MOD

# M_n(k) mod 10^8
answer = (
    pow(2, n - k, MOD)
    * B
    * A
    * A
) % MOD

print(answer)
```これは次のように評価されます。$$59992576.$$簡単な検証:

 - のために$n=6,k=2$、式は次のようになります$$P_6(2)=\frac{368}{1323},$$問題文と一致します。 

したがって、最後に必要な$8$数字は次のとおりです。 

**答え: 59992576**
