[プロジェクト オイラー問題 142](https://projecteuler.net/problem=142)

 ## 解決策

 **答え:**`1006193`整数を求めます$x>y>z>0$6 つの量すべてが$$x+y,\quad x-y,\quad x+z,\quad x-z,\quad y+z,\quad y-z$$は完全な正方形です。 

と表しましょう$$\begin{aligned} x+y &= a^2,\\ x-y &= b^2, \end{aligned} \qquad a>b>0.$$それから$$x=\frac{a^2+b^2}{2},\qquad y=\frac{a^2-b^2}{2}.$$同様に、次のように書きます$$x+z=c^2,\qquad x-z=d^2,$$となることによって$$x=\frac{c^2+d^2}{2},\qquad z=\frac{c^2-d^2}{2}.$$2 つの式を同等にすると、$x$、$$a^2+b^2=c^2+d^2.$$最後に、次のことも必要です$$y+z,\quad y-z$$正方形になること。 

---

 # ステップ 1: 条件を再定式化する

 から$$y=\frac{a^2-b^2}{2},\qquad z=\frac{c^2-d^2}{2},$$私たちは得ます$$\begin{aligned} y+z &= \frac{a^2-b^2+c^2-d^2}{2},\\ y-z &= \frac{a^2-b^2-c^2+d^2}{2}. \end{aligned}$$使用する$$a^2+b^2=c^2+d^2,$$簡略化します:$$\begin{aligned} y+z &= a^2-d^2,\\ y-z &= c^2-a^2. \end{aligned}$$したがって、問題は次のようになります。 

正方形を見つける$a^2,b^2,c^2,d^2$そのような$$a^2+b^2=c^2+d^2$$そしてさらに$$a^2-d^2,\qquad c^2-a^2$$は完全な正方形です。 

---

 # ステップ 2: 主要な観察

 必要な量はすべて二乗の差です。 

したがって、平方差のある平方の 3 倍を検索します。 

させて$$\begin{aligned} a^2-d^2 &= e^2,\\ c^2-a^2 &= f^2. \end{aligned}$$それから$$a^2=e^2+d^2,\qquad c^2=a^2+f^2.$$これは、ピタゴラス型の関係が生成されることを強く示唆しています。 

直接的な総当たり攻撃$x,y,z$絶望的ですが、正方形のペアを反復処理するのは十分に高速です。 

---

 # ステップ 3: 効率的な計算戦略

 私たちは以下を使用します:$$x=\frac{a^2+b^2}{2}, \qquad y=\frac{a^2-b^2}{2}, \qquad z=\frac{c^2-d^2}{2}.$$アルゴリズム:

 1. 平方を事前計算します。 
2. ペアを列挙する$(a,d)$そのような$a^2-d^2$は正方形です。 
3. ペアを列挙する$(c,a)$そのような$c^2-a^2$は正方形です。 
4. かどうかを確認します。$$a^2+b^2=c^2+d^2$$与える$b^2$完全な正方形。 

5. 構築する$x,y,z$。 

6. 最低限のものを守る$x+y+z$。 

これは非常に高速に実行されます。 

---

 # Pythonの実装```python
from math import isqrt

# ------------------------------------------------------------
# Helper function
# ------------------------------------------------------------

def is_square(n):
    """Return True iff n is a perfect square."""
    if n < 0:
        return False
    r = isqrt(n)
    return r * r == n

# ------------------------------------------------------------
# Search
# ------------------------------------------------------------

LIMIT = 2000

# Precompute squares
sq = [i * i for i in range(LIMIT + 1)]

best = None

# We use:
#
# x + y = a^2
# x - y = b^2
# x + z = c^2
# x - z = d^2
#
# Then:
#
# x = (a^2 + b^2)/2
# y = (a^2 - b^2)/2
# z = (c^2 - d^2)/2
#
# Additional conditions:
#
# y + z = a^2 - d^2 must be square
# y - z = c^2 - a^2 must be square
#

for a in range(1, LIMIT + 1):

    a2 = sq[a]

    for c in range(a + 1, LIMIT + 1):

        c2 = sq[c]

        # y - z must be square
        if not is_square(c2 - a2):
            continue

        for d in range(1, a):

            d2 = sq[d]

            # y + z must be square
            if not is_square(a2 - d2):
                continue

            # From:
            # a^2 + b^2 = c^2 + d^2
            b2 = c2 + d2 - a2

            if not is_square(b2):
                continue

            b = isqrt(b2)

            # Construct x,y,z
            x = (a2 + b2) // 2
            y = (a2 - b2) // 2
            z = (c2 - d2) // 2

            if not (x > y > z > 0):
                continue

            s = x + y + z

            if best is None or s < best:
                best = s
                print("Found:", x, y, z, "sum =", s)

print("Answer =", best)
```---
