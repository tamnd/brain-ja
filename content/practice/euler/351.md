 ## 解決策

 **答え:**`11762187201804552`果樹園の中心を原点とします。 別の格子点が中心から同じ光線上にあり、より近い場合、格子点は**非表示**になります。 

重要な所見は次のとおりです。 

> 点は、**その方向ベクトルがプリミティブである (その座標が互いに素である) 場合に限り、中心から見えます。 

この幾何学を、オイラーの合計関数を含む数論的な計数問題に変換します。 

---

 ## 1. 数学的分析

 ### ステップ 1: 六方格子をモデル化する

 六角形の秩序ある果樹園$n$正六角形の辺内のすべての格子点で構成されます$n$。 

六角形の対称性のため、6 つのうちの 1 つの点を数えれば十分です。$60^\circ$セクターを分割して 6 を掛けます。 

1つのセクター内で格子点を整数座標で表現できる$$(a,b), \qquad a,b\ge 0,\qquad a+b\le n.$$センター$(0,0)$は除外されます。 

ポイント$(a,b)$中心からは見える$$\gcd(a,b)=1.$$なぜ？ なぜなら、もし$d=\gcd(a,b)>1$、 それから$$(a,b)=d\left(\frac a d,\frac b d\right),$$したがって、近い格子点ほど$(a/d,b/d)$それをブロックします。 

したがって、隠れた点は **非プリミティブ ベクトル**に正確に対応します。 

---

 ### ステップ 2: 1 つのセクター内の可視ポイントを数える

 修正$k=a+b$、 どこ$$1 \le k \le n.$$プリミティブペアの数が必要です$(a,b)$と$$a+b=k.$$以来$b=k-a$、$$\gcd(a,b)=\gcd(a,k).$$したがって、可視性は、$a$と互いに素である$k$。 

そのような数$a\in\{1,\dots,k-1\}$まさに$$\varphi(k),$$どこ$\varphi$はオイラーのトーティエント関数です。 

したがって、次のようになります。 

- 1 つのセクター内の可視ポイント:$$\sum_{k=1}^{n} \varphi(k).$$6 を掛けると、目に見える非中心点の合計が得られます。$$6\sum_{k=1}^{n}\varphi(k).$$---

 ### ステップ 3: すべてのポイントを数える

 1 つのセクター内で、中心以外の格子点の総数は次のようになります。$$1+2+\cdots+n = \frac{n(n+1)}{2}.$$6 つのセクターすべてにわたって:$$6\cdot \frac{n(n+1)}{2}.$$そこで隠れたポイントは、$$H(n) = 6\left( \frac{n(n+1)}{2} - \sum_{k=1}^{n}\varphi(k) \right).$$したがって、問題は総和の計算に帰着します。$$\Phi(n)=\sum_{k=1}^{n}\varphi(k)$$のために$n=10^8$。 

---

 ### ステップ 4: 合計関数の効率的な計算

 直接ふるいにかけます$10^8$は高すぎます。 

古典的な分割統治アイデンティティを使用します。$$\Phi(n) = \frac{n(n+1)}{2} - \sum_{i=2}^{n}\Phi\!\left(\left\lfloor\frac{n}{i}\right\rfloor\right).$$下限値は範囲内で繰り返されるため、等しい商をグループ化します。 

もし$$q=\left\lfloor \frac{n}{l}\right\rfloor,$$それからすべてのインデックス$$l \le i \le r=\left\lfloor \frac{n}{q}\right\rfloor$$同じ商を共有します。 

これにより、複雑さが大まかに軽減されます$$O(n^{2/3})$$メモ化で。 

---

 ## 2. Python の実装```python
from functools import lru_cache

def hidden_points(n):
    @lru_cache(None)
    def totient_sum(x):
        # S(x) = sum_{k<=x} phi(k)
        if x == 1:
            return 1

        # Start with 1 + 2 + ... + x
        result = x * (x + 1) // 2

        l = 2
        while l <= x:
            q = x // l
            r = x // q

            # Subtract grouped contributions
            result -= (r - l + 1) * totient_sum(q)

            l = r + 1

        return result

    visible_sector = totient_sum(n)
    total_sector = n * (n + 1) // 2

    return 6 * (total_sector - visible_sector)

# Verification against examples
print(hidden_points(5))      # 30
print(hidden_points(10))     # 138
print(hidden_points(1000))   # 1177848

# Final answer
print(hidden_points(100000000))
```---

 ## 3. コードのチュートリアル

 ###`totient_sum(x)`計算します$$\Phi(x)=\sum_{k\le x}\varphi(k).$$ID の使用:$$\Phi(x) = \frac{x(x+1)}{2} - \sum_{i=2}^{x} \Phi\!\left(\left\lfloor \frac{x}{i}\right\rfloor\right).$$ループは商の値をグループ化します。```python
q = x // l
r = x // q
```すべてのインデックス`[l, r]`同じ商を持つ`q`なので、以下を減算します。```python
(r - l + 1) * totient_sum(q)
```メモ化により再計算が妨げられます。 

---

 ### Final computation

 私たちは以下を使用します:$$H(n) = 6\left( \frac{n(n+1)}{2} - \Phi(n) \right).$$---
