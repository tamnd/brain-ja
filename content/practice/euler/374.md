[プロジェクト オイラー問題 374](https://projecteuler.net/problem=374)

 ## 解決策

 **答え:**`334420941`させて$$F(n)=f(n)\cdot m(n)$$どこ$f(n)$のパーティションから取得できる最大の積です。$n$異なる正の整数に変換し、$m(n)$は、そのような最適なパーティション内のパーツの数です。 

重要な観察は、最適なパーティションが常に「ほぼ連続している」ということです。 

もし$$T_k=\frac{k(k+1)}2$$そして$$n=T_k+r,\qquad 0\le r\le k,$$次に:

 - のために$r=0$:$$n=1+2+\cdots+k$$最適なパーティションは、$$2+3+\cdots+(k-1)+(k+1)$$(交換により製品が増加します)$1$そして$k$と$k+1$）。 

したがって$$f(n)=\frac{(k+1)!}{2},\qquad m(n)=k-1.$$それで$$F(n)=\frac{(k-1)(k+1)!}{2}.$$- のために$1\le r\le k$:

 から開始$1,2,\dots,k$、 取り除く$k-r$、と追加します$k+1$。 

したがって、$$f(n)=\frac{(k+1)!}{k-r}, \qquad m(n)=k,$$専用ケース付き$r=k$与える$f(n)=(k+1)!$。 

これにより、次のように計算できる合計が得られます。$O(\sqrt N)$。

 ## Python コード```
import math
from array import array

MOD = 982451653
N = 10**14

# Largest k with T_k <= N
kmax = (math.isqrt(1 + 8 * N) - 1) // 2
r = N - kmax * (kmax + 1) // 2

# Modular inverses up to kmax
inv = array('I', [0]) * (kmax + 1)
inv[1] = 1

for i in range(2, kmax + 1):
    inv[i] = (MOD - (MOD // i) * inv[MOD % i] % MOD) % MOD

inv2 = (MOD + 1) // 2

ans = 0

# H = sum_{j=1}^{k-1} 1/j mod MOD
H = 0

# A = (k+1)! mod MOD
A = 2  # for k = 1

# Complete blocks
for k in range(1, kmax):

    # contribution for n = T_k
    # plus contributions for T_k + 1 ... T_k + k
    block = A * (((k - 1) * inv2 + k * (1 + H)) % MOD)

    ans = (ans + block) % MOD

    H = (H + inv[k]) % MOD
    A = (A * (k + 2)) % MOD

# Final partial block
k = kmax

# n = T_k
ans = (ans + A * ((k - 1) * inv2)) % MOD

# n = T_k + 1 ... T_k + r
for j in range(k - r, k):
    ans = (ans + k * A * inv[j]) % MOD

ans %= MOD

print(ans)
```---

 ## ウォークスルー

 ### 1. 三角形分解

 すべての整数$n$次のように一意に書くことができます$$n=T_k+r,\qquad 0\le r\le k.$$これにより、最適なパーティション構造が決定されます。 

---

 ### 2. モジュラーインバース

 多くの値が必要です$1/j \pmod{MOD}$。 

繰り返しを使用する$$\text{inv}[i] = MOD-\left\lfloor \frac{MOD}{i}\right\rfloor \cdot \text{inv}[MOD\bmod i] \pmod{MOD},$$すべての逆数は線形時間で計算されます。 

---

 ### 3. 階乗

 変数$$A=(k+1)! \pmod{MOD}$$反復ごとに段階的に更新されます。 

---

 ### 4. 高調波和

 保守します$$H=\sum_{j=1}^{k-1}\frac1j \pmod{MOD}.$$これにより、各ブロックの寄与を計算できるようになります。$O(1)$。
