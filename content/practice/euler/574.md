[プロジェクト オイラー問題 574](https://projecteuler.net/problem=574)

 ## 解決策

 **答え:**`5780447552057000454`させて$$P(q)=\prod_{r<q,\ r\text{ prime}} r$$(より小さい素数に対する初等数$q$）。 

私たちは最低限のものを求めます$A$素数の場合$p$、$$p=A+B \quad \text{or} \quad p=A-B,$$と：

-$\gcd(A,B)=1$、
 - すべての素数$r<q$分割する$AB$、
 -$p<q^2$。 

なぜなら$\gcd(A,B)=1$、すべての素数$r<q$**ちょうど 1** を分割します$A,B$。 したがって、そのような素数ごとに$r$、$$A \equiv 0 \pmod r \quad\text{or}\quad A \equiv p \pmod r,$$和の場合と差の場合の両方で、$B\equiv p-A$または$A-p$、同じ合同条件を法として与える$r$。 

だから固定のために$q$、$A$合同式によって決定されます。$$A \equiv \varepsilon_r \pmod r, \qquad \varepsilon_r\in\{0,p\}.$$中国の剰余定理により、各代入により固有の剰余クラスのモジュロが得られます。$P(q)$。 

各 CRT 残基について$x$、有効な候補は次のとおりです。 

- **合計ケース**$p=A+B$:$A\in[\lceil p/2\rceil,p)$、$A\equiv x\pmod{P(q)}$、
 - **異なるケース**$p=A-B$:$A>p$、$A\equiv x\pmod{P(q)}$。 

CRT ソリューションをプライムごとに再帰的に構築し、実現可能な最小のソリューションを維持します。$A$。 

次の Python は計算します$V(p)$その後$$S(3800)=\sum_{p<3800}V(p).$$

```python
from math import gcd, isqrt

def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False

    for i in range(2, isqrt(n) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False

    return [i for i in range(n + 1) if is_prime[i]

primes = sieve(100)

# primes less than q
primes_below_q = {
    q: [r for r in primes if r < q]
    for q in primes
}

def V(p):
    best = float('inf')

    for q in primes:
        if q * q <= p:
            continue

        ps = primes_below_q[q]

        def dfs(i, x, modulus):
            nonlocal best

            # pruning
            if x >= best:
                return

            # finished CRT construction
            if i == len(ps):

                # ----- sum case: p = A + B -----
                low = (p + 1) // 2
                A = x

                if A < low:
                    A += ((low - A + modulus - 1) // modulus) * modulus

                if A < p and gcd(A, p) == 1:
                    best = min(best, A)

                # ----- difference case: p = A - B -----
                A = x

                if A <= p:
                    A += ((p + 1 - A + modulus - 1) // modulus) * modulus

                if gcd(A, p) == 1:
                    best = min(best, A)

                return

            r = ps[i]
            inv = pow(modulus % r, -1, r)
            target = p % r

            # A ≡ 0 (mod r)
            k = ((-x) % r) * inv % r
            dfs(i + 1, x + modulus * k, modulus * r)

            # A ≡ p (mod r)
            k = ((target - x) % r) * inv % r
            dfs(i + 1, x + modulus * k, modulus * r)

        dfs(0, 0, 1)

    return best

def S(n):
    return sum(V(p) for p in sieve(n - 1))

print(S(10))    # 10
print(S(200))   # 7177
print(S(3800))
```検証：

-$S(10)=10$✔️
 -$S(200)=7177$✔️
 -$V(37)=22$✔️
 -$V(151)=165$✔️
