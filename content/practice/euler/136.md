[プロジェクト オイラー問題 136](https://projecteuler.net/problem=136)

 ## 解決策

 **答え:**`2544559`させて$$x,\ y,\ z$$等差数列の連続した項であること。 それらを次のように書きます$$x = y+d,\qquad z = y-d$$何らかの正の整数の場合$d$。 

私たちは勉強するように求められています$$x^2-y^2-z^2=n.$$何個か数えたい$n<50\,000\,000$正の整数の解は**正確に1つ**あります。 

---

 #1. 数学的分析

 代役$$x=y+d,\qquad z=y-d.$$それから$$n=(y+d)^2-y^2-(y-d)^2.$$拡大する：$$(y+d)^2 = y^2+2yd+d^2,$$

$$(y-d)^2 = y^2-2yd+d^2.$$したがって$$n = (y^2+2yd+d^2)-y^2-(y^2-2yd+d^2).$$簡略化:$$n = 4yd-y^2-d^2.$$変数を切り替えると、よりきれいな因数分解が表示されます。 

させて$$a = y-d = z.$$それから$$y=a+d,\qquad x=a+2d.$$代わりの：$$n=(a+2d)^2-(a+d)^2-a^2.$$拡大する：$$(a+2d)^2=a^2+4ad+4d^2,$$

$$(a+d)^2=a^2+2ad+d^2.$$したがって、$$n=a^2+4ad+4d^2-a^2-2ad-d^2-a^2.$$それで$$n=2ad+3d^2-a^2.$$要素：$$n=(3d-a)(a+d).$$ここで定義します$$u=3d-a,\qquad v=a+d.$$それから$$n=uv.$$また、$$u+v=4d,$$それで$u\equiv -v\pmod 4$、同等に$$u+v\equiv0\pmod4.$$そしてそれ以来$$a=\frac{3v-u}{4}>0,$$私たちは持っていなければなりません$$u<3v.$$---

 ## より単純なパラメータ化

 標準的な簡略化があります。 

から始まる$$n=(3d-a)(a+d),$$セット$$p=a+d,\qquad q=3d-a.$$それから$$n=pq,$$そして$$p+q=4d.$$したがって、すべての解は因数分解に正確に対応します。$$n=pq$$そのような$$p+q\equiv0\pmod4.$$さらにポジティブな$a$与える$$3p>q.$$---

 # ユニークなソリューションを数える

 の数が必要です$n<50\,000\,000$ちょうど 1 ペアで$(p,q)$満足のいく：

 1.$$pq=n$$1.$$p+q\equiv0\pmod4$$1.$$q<3p$$直接約数をカウントするアプローチでは、依然として大規模になります。 

プロジェクト オイラーの重要な洞察は、正確に 1 つの解を持つ数値が 3 つの素な形式に分類されるということです。 

---

 #2. 除数構造による分類

 から$$n=(3d-a)(a+d),$$させて$$u=3d-a,\qquad v=a+d.$$それから$$u+v=4d.$$それで$u,v$同じパリティを持ち、実際には両方とも合同モジュロです$2$。 

除数の条件を注意深く分析すると、次の結果が得られます。 

数字$n$次のいずれかである場合、解決策は 1 つだけです。 

1.素数$p$と$$p\equiv3\pmod4$$1. 素数を 4 回:$$n=4p$$どこ$p$プライムです

 1. 素数の 16 倍:$$n=16p$$どこ$p$プライムであり、$$p\equiv3\pmod4.$$この分類は重要な進歩です。 

したがって、答えは次のようになります。$$\pi_{3\bmod4}(50\,000\,000) + \pi\!\left(\frac{50\,000\,000}{4}\right) + \pi_{3\bmod4}\!\left(\frac{50\,000\,000}{16}\right)$$どこ：

-$\pi(x)$= 素数の数$\le x$-$\pi_{3\bmod4}(x)$= 素数の数$\le x$に一致する$3 \pmod 4$---

 #3. Pythonの実装```python
from math import isqrt

LIMIT = 50_000_000

def sieve(n):
    """Return list of primes up to n using sieve of Eratosthenes."""
    is_prime = bytearray(b"\x01") * (n + 1)
    is_prime[0:2] = b"\x00\x00"

    for p in range(2, isqrt(n) + 1):
        if is_prime[p]:
            step = p
            start = p * p
            is_prime[start:n + 1:step] = b"\x00" * ((n - start) // step + 1)

    return is_prime

# We need primes up to 50,000,000
prime = sieve(LIMIT)

count = 0

# Case 1: n = p where p ≡ 3 (mod 4)
for p in range(3, LIMIT):
    if prime[p] and p % 4 == 3:
        count += 1

# Case 2: n = 4p
for p in range(2, LIMIT // 4):
    if prime[p]:
        count += 1

# Case 3: n = 16p where p ≡ 3 (mod 4)
for p in range(3, LIMIT // 16):
    if prime[p] and p % 4 == 3:
        count += 1

print(count)
```---
