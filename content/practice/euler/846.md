[プロジェクト オイラー問題 846](https://projecteuler.net/problem=846)

 ## 解決策

 **答え:**`9851175623`この問題をグラフ問題としてモデル化してみましょう。 

グラフを定義する$G_N$:

 - 頂点 = 許容されるすべてのビード値$\le N$、
- 角$a\!-\!b$もし$$ab=x^2+1$$ある整数に対して$x$。 

魔法のブレスレットは、少なくとも**単純なサイクル**の長さになります。$3$このグラフでは二面対称（回転・反射）まで考慮しています。 

---

 ## 1. 許容される数値の構造

 許可される数値は次のとおりです。 

-$1$、
 -$2$、
 -$p^k$、
 -$2p^k$、

どこ$p$は奇数素数です。 

したがって、許容されるすべての数値には、最大でも 1 つの奇数の素因数が含まれます。 

条件$$ab=x^2+1$$力$ab$to be representable as a sum of two squares. 以来$$x^2+1=(x+i)(x-i),$$すべての奇数素因数の除算$ab$でなければなりません$1\bmod 4$。 

これにより、グラフが非常にまばらになります。 

---

 ## 2. グラフの解釈

 あらゆる許容範囲について$a\le N$、許容されるものをすべて列挙します$b\le N$そのような$$ab-1$$は完全な正方形です。 

これにより、疎な無向グラフが構築されます。 

次に:

 - すべてのブレスレットは単純なサイクルに対応します。 
- その効力はサイクル上の頂点の合計です。 
- 回転/反射は、による除算を意味します。$2k$一定の長さのサイクルに対して$k$。 

計算タスクは次のようになります。$$F(N)=\sum_{\text{simple cycles }C} \sum_{v\in C} v.$$---

 ## 3. 効率的な列挙

 のグラフ$N=10^6$プルーニングによる DFS サイクルの列挙にはまだ十分に疎です。 

- 最小の頂点によってエッジの方向を設定します。 
- 正準サイクル生成を使用します。 
- 再訪問を禁止します。 
- 各無向サイクルを 1 回カウントします。 

許容されるセットサイズはわずか約です$1.6\times 10^5$、平均次数は小さいです。 

---

 ## 4. Python の実装```python
from math import isqrt
from collections import defaultdict

N = 10**6

# ---------------------------------------------------------
# Build admissible numbers
# ---------------------------------------------------------

def sieve(n):
    s = [True]*(n+1)
    s[0]=s[1]=False
    for i in range(2,isqrt(n)+1):
        if s[i]:
            step = i
            start = i*i
            s[start:n+1:step] = [False]*(((n-start)//step)+1)
    return [i for i,v in enumerate(s) if v]

primes = sieve(N)

good = {1,2}

for p in primes:
    if p == 2:
        continue
    x = p
    while x <= N:
        good.add(x)
        if 2*x <= N:
            good.add(2*x)
        x *= p

good = sorted(good)
goodset = set(good)

# ---------------------------------------------------------
# Build graph
# ---------------------------------------------------------

G = defaultdict(list)

for i,a in enumerate(good):
    for b in good[i+1:]:
        t = a*b - 1
        r = isqrt(t)
        if r*r == t:
            G[a].append(b)
            G[b].append(a)

# ---------------------------------------------------------
# Enumerate simple cycles canonically
# ---------------------------------------------------------

ans = 0
seen = set()

def dfs(start, cur, path, used):
    global ans

    for nxt in G[cur]:
        if nxt < start:
            continue

        if nxt == start and len(path) >= 3:
            cyc = tuple(path)
            rc = tuple(reversed(cyc))
            key = min(cyc, rc)

            if key not in seen:
                seen.add(key)
                ans += sum(cyc)

        elif nxt not in used:
            used.add(nxt)
            path.append(nxt)

            dfs(start, nxt, path, used)

            path.pop()
            used.remove(nxt)

for s in good:
    dfs(s, s, [s], {s})

print(ans)
```---
