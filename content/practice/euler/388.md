[プロジェクト オイラー問題 388](https://projecteuler.net/problem=388)

 ## 解決策

 **答え:**`831907372805129931`格子点を$P=(a,b,c)$と$0\le a,b,c\le N$、すべてがゼロではありません。 

一方が他方の正の整数倍である場合、2 つの点は原点を通る同じ直線を決定します。 

したがって、それぞれの個別の行は **プリミティブ** トリプルに一意に対応します。$$\gcd(a,b,c)=1.$$それで$D(N)$立方体内のプリミティブ格子点の正確な数です$[0,N]^3\setminus\{(0,0,0)\}$。 

---

 #1. 数学的分析

 定義する$$F(N)=\#\{(a,b,c):0\le a,b,c\le N,\ \gcd(a,b,c)=1\}.$$それから$D(N)=F(N)-1$、 なぜなら$(0,0,0)$は許可されていません。 

ここで、メビウス反転を使用してプリミティブ トリプルを数えます。 

---

 ## 割り切れるトリプルを数える$d$させて$$T_d(N)=\#\{(a,b,c): d\mid a,\ d\mid b,\ d\mid c\}.$$の倍数$d$で$[0,N]$は$$0,d,2d,\dots,\left\lfloor \frac Nd\right\rfloor d,$$だからあります$\lfloor N/d\rfloor+1$コーディネートごとに選択肢があります。 したがって、$$T_d(N)=\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3.$$メビウス反転により、$$F(N)=\sum_{d=1}^{N}\mu(d)\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3,$$どこ$\mu$はメビウス関数です。 

しかし、起源はあらゆるものに貢献します。$T_d$、したがって、その純寄与は$$\sum_{d=1}^{N}\mu(d)=M(N),$$どこ$M(N)$はメルテンス関数です。 

原点はカウントされるべきではないため、その寄与を差し引きます。$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right].$$この式は正確です。 

---

 ## 複雑さの軽減

 直接$O(N)$合計は不可能です$N=10^{10}$。 

重要な観察は次のとおりです$$\left\lfloor \frac Nd\right\rfloor$$ほんの約だけかかります$2\sqrt N$明確な価値観。 

商が等しいグループインデックス:$$q=\left\lfloor \frac Nd\right\rfloor.$$もし$q$修正されたらすべて$$d\in [L,R],\qquad R=\left\lfloor \frac Nq\right\rfloor$$同じ商を共有します。 

したがって$$\sum_{d=L}^{R}\mu(d) = M(R)-M(L-1).$$そこで計算します$$D(N)= \sum_{\text{blocks}} \bigl(M(R)-M(L-1)\bigr)\bigl((q+1)^3-1\bigr).$$残りのタスクは評価です$M(x)$素早く。 

---

 ## メルテンス関数の高速計算

 古典的な再帰を使用する$$M(n)=1-\sum_{l=2}^{n}(r-l+1)M\!\left(\left\lfloor\frac nl\right\rfloor\right),$$ここで、等しい商がグループ化されます。 

メモ化すると、これが大まかに実行されます$O(n^{2/3})$、これは十分に高速です$10^{10}$。 

---

 #2. Pythonの実装```python
from functools import lru_cache

# ------------------------------------------------------------
# Linear sieve for Möbius values up to LIMIT
# ------------------------------------------------------------

def mobius_prefix(limit):
    mu = [0] * (limit + 1)
    mu[1] = 1

    primes = []
    is_composite = [False] * (limit + 1)

    for i in range(2, limit + 1):
        if not is_composite[i]:
            primes.append(i)
            mu[i] = -1

        for p in primes:
            if i * p > limit:
                break

            is_composite[i * p] = True

            if i % p == 0:
                mu[i * p] = 0
                break
            else:
                mu[i * p] = -mu[i]

    # Prefix sums: M(n) = sum_{k<=n} mu(k)
    M = [0] * (limit + 1)

    for i in range(1, limit + 1):
        M[i] = M[i - 1] + mu[i]

    return M

LIMIT = 2_000_000
M_small = mobius_prefix(LIMIT)

# ------------------------------------------------------------
# Fast recursive Mertens function
# ------------------------------------------------------------

@lru_cache(None)
def M(n):
    if n <= LIMIT:
        return M_small[n]

    result = 1
    l = 2

    while l <= n:
        q = n // l
        r = n // q

        result -= (r - l + 1) * M(q)

        l = r + 1

    return result

# ------------------------------------------------------------
# Compute D(N)
# ------------------------------------------------------------

def D(N):
    ans = 0
    l = 1

    while l <= N:
        q = N // l
        r = N // q

        mobius_sum = M(r) - M(l - 1)

        ans += mobius_sum * ((q + 1) ** 3 - 1)

        l = r + 1

    return ans

# ------------------------------------------------------------
# Verification
# ------------------------------------------------------------

print(D(100))       # 850957
print(D(1_000_000)) # 831909254469114121

# Final computation
value = D(10**10)

s = str(value)

print(value)
print(s[:9] + s[-9:])
```---

メモ化により、それぞれの個別の引数が 1 回計算されるようになります。

 ###`D(N)`評価する$$D(N)=\sum_{d=1}^{N}\mu(d)\left[\left(\left\lfloor \frac Nd\right\rfloor+1\right)^3-1\right]$$等しい商をグループ化することによって。
