[プロジェクト オイラー問題 349](https://projecteuler.net/problem=349)

 ## 解決策

 **答え:**`115384615384614952`この問題の鍵は、アリの動きが最初は混沌としているように見えますが、**ラングトンアリは最終的には完全に繰り返される「高速道路」パターン**に入るということです。 これが起こると、黒い四角の数が直線的に増加し、数千のシミュレートされたステップから最後までジャンプできるようになります。$10^{18}$。 

## 1. 数学的分析

 しましょう$B(n)$後の黒い四角の数になります$n$動きます。 

アリは次のように従う。 

- **白**の場合: 黒に反転し、右に曲がり、移動します。 
- **黒**の場合: 白に切り替え、左に曲がり、移動します。 

グリッドは完全に白から始まります。 

### ステップ 1: 創発構造を観察する

 の直接シミュレーション$10^{18}$ステップは不可能です。 

しかし、ラングトンアリは奥深い現象で有名です。 

> 混沌とした過渡期の後、最終的には繰り返しの「高速道路」を構築します。 

経験的に（そしてシミュレーションによって検証可能に）、アリは **9977 回移動**した後、周期的な体制に入ります。 

この体制では:

 - **104手**ごとに、
 - 設定は翻訳まで繰り返されます。 
- そして、黒い四角の数はちょうど **12** ずつ増加します。 

したがって、十分に大きい場合$n$、$$B(n+104)=B(n)+12.$$これにより線形回帰が得られます。 

### ステップ 2: 移行点を決定する

 最初の数千手をシミュレーションすると、次のようになります。$$B(9977)=715.$$その後、$$B(n+104)=B(n)+12.$$今書いてください$$10^{18}-9977 = 104q + r.$$計算:$$q = \left\lfloor \frac{10^{18}-9977}{104}\right\rfloor, \qquad r=(10^{18}-9977)\bmod 104.$$それから$$B(10^{18}) = 715 + 12q + \bigl(B(9977+r)-715\bigr).$$残り$r$最初のシミュレートされたサイクルから保存された値によって処理されます。 

これを実行すると、次の結果が得られます。$$B(10^{18}) = 115384615384614952.$$---

 ## 2. Python の実装```python
def solve():
    N = 10**18

    # Directions: up, right, down, left
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]

    black = set()

    x = y = 0
    direction = 0  # start facing up

    black_counts = []

    # Simulate enough steps to reach stable highway behavior
    LIMIT = 20000

    for step in range(1, LIMIT + 1):

        if (x, y) in black:
            # Black square: flip to white, turn left
            black.remove((x, y))
            direction = (direction - 1) % 4
        else:
            # White square: flip to black, turn right
            black.add((x, y))
            direction = (direction + 1) % 4

        # Move forward
        dx, dy = directions[direction]
        x += dx
        y += dy

        black_counts.append(len(black))

    # Highway begins after 9977 moves
    START = 9977
    PERIOD = 104
    GAIN = 12

    base = black_counts[START - 1]

    q, r = divmod(N - START, PERIOD)

    answer = base + q * GAIN

    if r:
        answer += black_counts[START + r - 1] - base

    return answer

print(solve())
```---

 ## 3. コードのチュートリアル

 ### シミュレーション

 黒い四角形を で表します。`set`。 

- 現在の正方形が黒の場合:

 - セットから削除（白に変わります）、
 - 左に回転します。 
- それ以外の場合:

 - セットに追加（黒に変わります）、
 - 右に回転します。 

そして、新たな方向へ一歩前進します。 

私たちは以下を記録します:```python
black_counts.append(len(black))
```それで`black_counts[n-1]`店$B(n)$。 

### 周期性の検出

 検査により：

 - 移動 **9977 以降**、
 - **104 ステップ**ごとに、
 - 黒の数は **12** 増加します。 

したがって：```python
START = 9977
PERIOD = 104
GAIN = 12
```膨大な数の移動を次のように分割します。```python
q, r = divmod(N - START, PERIOD)
```意味：

-`q`高速道路を完全にサイクリングし、
 -`r`残った動き。 

各サイクルは +12 個の黒い正方形に貢献します。

 ## 4. 最終確認

 健全性チェック:$$\frac{12}{104}=\frac{3}{26}\approx 0.11538$$だから、$10^{18}$大まかに予想されるステップ$$0.11538 \times 10^{18} \approx 1.1538\times10^{17},$$これは計算結果の大きさと一致します。$$115384615384614952.$$この数は、既知のラングトンアリの安定した線形成長とも一致しています。 

**答え: 115384615384614952**
