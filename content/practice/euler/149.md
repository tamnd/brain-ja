 ## 解決策

 **答え:**`52852124`私たちに与えられているのは、$2000 \times 2000$ラグ フィボナッチ ジェネレーター (LFG) によって生成された疑似乱数整数で満たされたグリッドであり、4 つの方向のいずれかで隣接するエントリの最大合計を見つける必要があります。 

- 水平、
 - 垂直、
 - 主対角線、
 - 対角線。 

重要な課題は効率です。すべての可能なサブアレイをすべての方向に総当たりで実行すると、時間がかかりすぎます。

 # 数学的分析

 ## 1. シーケンスの生成

 シーケンス$s_k$は次のように定義されます。 

のために$1 \le k \le 55$、$$s_k = (100003 - 200003k + 300007k^3) \bmod 1000000 - 500000$$のために$56 \le k \le 4{,}000{,}000$、$$s_k = (s_{k-24} + s_{k-55} + 1000000)\bmod 1000000 - 500000$$これらの値は間隔内にあります$$[-500000, 499999]$$の$4{,}000{,}000$用語は行ごとに書き込まれます。$2000 \times 2000$マトリックス。 

---

 #2. 最大部分配列の問題

 1D 配列があるとします。$$[a_1,a_2,\dots,a_n]$$連続したブロックの最大合計が必要です。 

これはまさに古典的な **最大部分配列問題** であり、**Kadane のアルゴリズム**によって線形時間で最適に解決されます。 

---

 ## Kadaneのアルゴリズム

 定義:

 -$best$= これまでに確認された最高額、
 -$current$= 現在の位置で終了する最良の合計。 

それぞれの値について$x$:$$current = \max(x, current+x)$$

$$best = \max(best, current)$$これは、すべての最適なサブ配列が位置で終わるため機能します。$i$次のいずれか:

 - 新たに開始します$i$、または
 - で終わる最適なサブ配列を拡張します。$i-1$。 

時間計算量:$$O(n)$$---

 # 3. Applying Kadane in 2D directions

 We must run Kadane on every:

 - 行、
 - コラム、
 - 斜め、
 - 対角線。 

Each line has length at most 2000.

 検査される要素の合計は、グリッド エントリの合計数に比例します。$$O(2000^2)$$それは完全に実現可能です。

 # Pythonの実装```python
def generate_sequence():
    n = 4_000_000
    s = [0] * n

    # First 55 terms
    for k in range(1, 56):
        val = (100003 - 200003 * k + 300007 * k**3) % 1_000_000
        s[k - 1] = val - 500000

    # Remaining terms
    for k in range(55, n):
        val = (s[k - 24] + s[k - 55] + 1_000_000) % 1_000_000
        s[k] = val - 500000

    return s

def kadane(arr):
    best = arr[0]
    current = arr[0]

    for x in arr[1:]:
        current = max(x, current + x)
        best = max(best, current)

    return best

def solve():
    SIZE = 2000

    # Generate sequence
    seq = generate_sequence()

    # Build grid
    grid = [seq[i * SIZE:(i + 1) * SIZE] for i in range(SIZE)]

    ans = -10**18

    # -------------------------------------------------
    # Horizontal
    # -------------------------------------------------
    for row in grid:
        ans = max(ans, kadane(row))

    # -------------------------------------------------
    # Vertical
    # -------------------------------------------------
    for c in range(SIZE):
        col = [grid[r][c] for r in range(SIZE)]
        ans = max(ans, kadane(col))

    # -------------------------------------------------
    # Main diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # Start from left column (excluding top-left)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, 0

        while r < SIZE and c < SIZE:
            diag.append(grid[r][c])
            r += 1
            c += 1

        ans = max(ans, kadane(diag))

    # -------------------------------------------------
    # Anti-diagonals
    # -------------------------------------------------
    # Start from top row
    for start_col in range(SIZE):
        diag = []
        r, c = 0, start_col

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    # Start from right column (excluding top-right)
    for start_row in range(1, SIZE):
        diag = []
        r, c = start_row, SIZE - 1

        while r < SIZE and c >= 0:
            diag.append(grid[r][c])
            r += 1
            c -= 1

        ans = max(ans, kadane(diag))

    return ans

print(solve())
