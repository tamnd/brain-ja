[プロジェクト オイラー問題 10](https://projecteuler.net/problem=10)

 ## 解決策

 これを効率的に解くには、以下のすべての素数の合計が必要です。$2{,}000{,}000$。 

すべての数値に対して直接素数性テストを行うと、時間がかかりすぎます。 標準的なアプローチは、各素数の倍数を合成としてマークする **エラトステネスの篩** です。 

アイデア:

 1. ブール配列を作成する`is_prime`から`0`に`1,999,999`。 
2. 最初はすべての数値を想定します$\ge 2$プライムです。 
3. 各素数について$p$, の倍数をすべてマークします。$p$から始まる$p^2$非プライムとして。 
4. 残りの素数インデックスをすべて合計します。 

複雑さはおよそ$O(n \log \log n)$, これは 200 万でも十分な速度です。 

Python コード:```python
limit = 2_000_000

is_prime = [True] * limit
is_prime[0] = is_prime[1] = False

p = 2
while p * p < limit:
    if is_prime[p]:
        for multiple in range(p * p, limit, p):
            is_prime[multiple] = False
    p += 1

total = sum(i for i, prime in enumerate(is_prime) if prime)

print(total)
```小さな例での正確性のトレース:

 以下の素数$10$は：$$2,3,5,7$$それらの合計は次のとおりです。$$2+3+5+7=17$$これはステートメントと一致します。
