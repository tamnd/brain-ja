[プロジェクト オイラー問題 429](https://projecteuler.net/problem=429)

 ## 解決策

 **答え:**`98792821`させて$$n! = \prod_{p \le n} p^{e_p}$$どこ$$e_p = \sum_{k\ge1}\left\lfloor \frac{n}{p^k}\right\rfloor$$ルジャンドルの公式によると。 

**単約数**$d$の$n!$満たさなければなりません$$\gcd(d,n!/d)=1.$$の素因数分解以来、$n!$素数ごとに一意です$p^{e_p}$、単一の約数は **因数全体** を受け取ります$p^{e_p}$または**どれも**。 指数の一部のみを取得すると、gcd は自明ではなくなります。 

したがって、すべての単位約数は次の形式になります。$$d=\prod_{p\le n} p^{\varepsilon_p e_p}, \qquad \varepsilon_p\in\{0,1\}.$$二乗和が必要です。$$S(n!) = \sum_{d \text{ unitary}} d^2.$$選択肢は素数間で独立しているため、これは乗算的に因数分解されます。$$S(n!) = \prod_{p\le n} \left(1+p^{2e_p}\right).$$だから、$n=100\,000\,000$、$$S(100000000!) = \prod_{p\le 100000000} \left(1+p^{2e_p}\right) \pmod{1000000009}.$$次のように計算します。 

1. すべての素数を生成する$p\le 10^8$ふるいを通して。 
2. 各素数について、計算します。$e_p$ルジャンドルの公式を使用します。 
3. 掛ける$$(1+p^{2e_p}) \bmod 1000000009$$実行中の製品に組み込まれます。 

Python の実装:```python
from math import isqrt

MOD = 1_000_000_009
N = 100_000_000

# Sieve of Eratosthenes
is_prime = bytearray(b'\x01') * (N + 1)
is_prime[0:2] = b'\x00\x00'

for i in range(2, isqrt(N) + 1):
    if is_prime[i]:
        is_prime[i * i : N + 1 : i] = (
            b'\x00' * (((N - i * i) // i) + 1)
        )

primes = [p for p in range(2, N + 1) if is_prime[p]]

result = 1

for p in primes:
    # Legendre exponent of p in N!
    e = 0
    m = N
    while m:
        m //= p
        e += m

    result = (result * (1 + pow(p, 2 * e, MOD))) % MOD

print(result)
```小さなチェック:

 のために$4!=24=2^3\cdot 3$、$$S(4!) = (1+2^{6})(1+3^2) = (1+64)(1+9) = 65\cdot 10 = 650,$$例と一致します。
