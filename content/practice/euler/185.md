[プロジェクト オイラー問題 185](https://projecteuler.net/problem=185)

 ## 解決策

 **答え:**`4640261571849533`知られざる16桁の秘密を明かそう$$x_0x_1x_2\dots x_{15}$$それぞれの推測により、次の形式の制約が与えられます。 

>「その通りです」$k$ポジションは合ってるよ。」

 これは **制約満足問題** です。 

行ごとに$g$、$$\sum_{i=0}^{15} [x_i = g_i] = k$$どこ$[P]$命題の場合は 1$P$は true、それ以外の場合は 0。 

重要な点は、制約が非常に厳しいということです。 

- 22 の方程式、
 - 16 桁のみ、
 - 各ポジションには 10 個の可能性しかありません。 

ブルートフォース検索$10^{16}$候補を絞り込むことは不可能ですが、慎重に選択されたバックトラッキング検索は非常に小規模です。 

---

 # 数学的分析

 各推測を次のようにエンコードします。$$(g^{(j)}, c^{(j)})$$どこ：

-$g^{(j)}$16 桁の文字列です。 
-$c^{(j)}$必要な完全一致の数です。 

部分的に構築されたシークレットについては、すでにいくつかの位置を割り当てていると仮定します。 

あらゆる手がかりについて$j$、 定義する：

-$m_j$: すでに強制された現在の一致数、
 -$r_j$: 残りのポジションはまだ割り当てられていません。 

その場合、実現可能性が必要となるのは、$$m_j \le c_j \le m_j + r_j$$なぜなら:

 - 必要な試合数を超えることはできません。 
- たとえ残りのポジションがすべて一致したとしても、まだ到達できなければなりません$c_j$。 

これにより、強力な枝刈りルールが得られます。 

---

 ## 「0 正解」行からの強い制約

 私たちは次のように言われます。$$2321386104303845 ; 0 \text{ correct}$$したがって、シークレットは、**すべて**の位置でこの行と異なります。 

それですぐに：$$x_i \ne (\text{digit in that row at position } i)$$16 ポジションすべてに対応します。 

これだけで、位置ごとに 1 桁が削除されます。 

---

 # 効率的な検索戦略

 位置ごとに再帰的に数字を割り当てます。 

各ステップで:

 1. 候補の数字を試してください。 
2. すべての手がかりの一致数を更新します。 
3. 手がかりが不可能になった場合は直ちに拒否します。$$m_j > c_j$$または$$m_j + r_j < c_j$$制約が非常に厳しいため、ツリーは急速に崩壊し、独自の解決策が得られます。

 # Pythonの実装```python
from collections import defaultdict

# (guess, number_of_correct_positions)
clues = [
    ("5616185650518293", 2),
    ("3847439647293047", 1),
    ("5855462940810587", 3),
    ("9742855507068353", 3),
    ("4296849643607543", 3),
    ("3174248439465858", 1),
    ("4513559094146117", 2),
    ("7890971548908067", 3),
    ("8157356344118483", 1),
    ("2615250744386899", 2),
    ("8690095851526254", 3),
    ("6375711915077050", 1),
    ("6913859173121360", 1),
    ("6442889055042768", 2),
    ("2321386104303845", 0),
    ("2326509471271448", 2),
    ("5251583379644322", 2),
    ("1748270476758276", 3),
    ("4895722652190306", 1),
    ("3041631117224635", 3),
    ("1841236454324589", 3),
    ("2659862637316867", 2),
]

N = 16

# Precompute allowed digits for each position
allowed = [set("0123456789") for _ in range(N)]

# Apply the 0-correct constraint immediately
for guess, score in clues:
    if score == 0:
        for i, d in enumerate(guess):
            allowed[i].discard(d)

solution = None

def search(pos, current, matches):
    global solution

    if solution is not None:
        return

    # Finished all positions
    if pos == N:
        if all(matches[i] == clues[i][1] for i in range(len(clues))):
            solution = "".join(current)
        return

    for digit in allowed[pos]:

        new_matches = matches[:]

        # Update match counts
        for i, (guess, score) in enumerate(clues):
            if guess[pos] == digit:
                new_matches[i] += 1

        # Feasibility check
        feasible = True
        remaining = N - pos - 1

        for i, (guess, score) in enumerate(clues):
            m = new_matches[i]

            # Too many matches already
            if m > score:
                feasible = False
                break

            # Even matching everything left can't reach score
            if m + remaining < score:
                feasible = False
                break

        if feasible:
            current.append(digit)
            search(pos + 1, current, new_matches)
            current.pop()

search(0, [], [0] * len(clues))

print(solution)
```---

 # コードのチュートリアル

 ## 1. 手がかりを保存する```python
clues = [

```各タプルには以下が含まれます。 

- 推測されたシーケンス、

---

 ## 2. 使用できる数字```python
allowed = [set("0123456789") for _ in range(N)]
```最初は、すべての位置に任意の数字を含めることができます。 

次に、一致が 0 件ある手がかりを処理します。```python
if score == 0:
    for i, d in enumerate(guess):
        allowed[i].discard(d)
```したがって、これらの数字はその位置では禁止されています。 

---

 ## 3. 再帰的検索```python
search(pos, current, matches)
```パラメータ:

 -`pos`= 現在の桁位置、
 -`current`= 部分的な秘密、
 -`matches[i]`= 現在の手がかりの一致$i$。 

---

 ## 4. 制約の更新

 数字を試すとき:```python
if guess[pos] == digit:
    new_matches[i] += 1
```---

 ## 5. 剪定

 それぞれの手がかりについて:```python
if m > score:
```すでに試合が多すぎます。 

そして```python
if m + remaining < score:
```残りのポジションがすべて一致したとしても、規定の合計に達することはできませんでした。 

これら 2 つの不等式により、検索ツリーのほぼ全体が刈り取られます。
