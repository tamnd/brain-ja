[プロジェクト オイラー問題 320](https://projecteuler.net/problem=320)

 ## 解決策

 **答え:**`278157919195482643`させて$$K = 1234567890.$$私たちは最小のものを望んでいます$n$そのような$$(i!)^K \mid n!.$$すべての素数について$p\le i$、 定義する$v_p(m!)$の指数として$p$で$m!$。 

ルジャンドルの公式によれば、$$v_p(m!)=\sum_{t\ge1}\left\lfloor \frac{m}{p^t}\right\rfloor.$$したがって$n$満たさなければなりません$$v_p(n!) \ge K\,v_p(i!) \qquad\text{for every prime }p\le i.$$それで$$N(i)=\max_{p\le i} F_p\!\bigl(K\,v_p(i!)\bigr),$$どこ$F_p(a)$最低です$n$そのような$v_p(n!)\ge a$。 

---

 # 重要な数学的洞察

 もう一度ルジャンドルを使うと、$$v_p(n!)=\frac{n-s_p(n)}{p-1},$$どこ$s_p(n)$は底の合計です -$p$の桁$n$。 

したがって、$F_p(a)$最小です$n$満足のいく$$n-s_p(n)\ge (p-1)a.$$以来$s_p(n)$に比べて小さいです$n$、私たちは得ます$$F_p(a)=(p-1)a+O(\log a).$$今$$(p-1)v_p(i!) = i-s_p(i),$$それで$$F_p\!\bigl(Kv_p(i!)\bigr) = K(i-s_p(i,p))+O(\log i).$$したがって、支配的な素数はまさに桁の合計を最小化する素数です。$s_p(i,p)$。 

計算は次のように効率的に行うことができます。 

1. 最小の素因数をふるいにかけます$10^6$、
 2. すべての指数を維持する$v_p(i!)$段階的に、
 3. 新しいものを分割する素数のみを更新します。$i$、
 4. コンピューティング$F_p(a)$ルジャンドルの公式の二分探索によって。 

全体的な複雑さは、最適化された Python / PyPy で簡単に十分に速くなります。

 # Pythonの実装```python
from collections import defaultdict
from math import log

K = 1234567890
MOD = 10**18
U = 10**6

# ------------------------------------------------------------
# smallest prime factor sieve
# ------------------------------------------------------------

spf = list(range(U + 1))

for i in range(2, int(U**0.5) + 1):
    if spf[i] == i:
        step = i
        start = i * i
        for j in range(start, U + 1, step):
            if spf[j] == j:
                spf[j] = i

# ------------------------------------------------------------
# Legendre valuation
# ------------------------------------------------------------

def vp_fact(n, p):
    s = 0
    while n:
        n //= p
        s += n
    return s

# ------------------------------------------------------------
# inverse Legendre:
# least n with vp_fact(n,p) >= target
# ------------------------------------------------------------

def inverse_legendre(p, target):
    lo = 0
    hi = (p - 1) * target + 1000

    while lo < hi:
        mid = (lo + hi) // 2
        if vp_fact(mid, p) >= target:
            hi = mid
        else:
            lo = mid + 1

    return lo

# ------------------------------------------------------------
# main accumulation
# ------------------------------------------------------------

exp_p = defaultdict(int)
need_p = defaultdict(int)

current_max = 0
answer = 0

for i in range(2, U + 1):

    x = i
    factors = defaultdict(int)

    while x > 1:
        p = spf[x]
        factors[p] += 1
        x //= p

    # update prime exponents in i!
    for p, e in factors.items():
        exp_p[p] += e

        target = K * exp_p[p]
        val = inverse_legendre(p, target)

        need_p[p] = val

        if val > current_max:
            current_max = val

    if i >= 10:
        # recompute if necessary
        if current_max not in need_p.values():
            current_max = max(need_p.values())

        answer = (answer + current_max) % MOD

print(answer)
```---
