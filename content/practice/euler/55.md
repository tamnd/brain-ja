[プロジェクト オイラー問題 55](https://projecteuler.net/problem=55)

 ## 解決策

 **答え:**`249`**ライクレル数** (この問題の目的上) は、「逆算」プロセスを 50 回繰り返しても回文にならない数です。 

整数が何個あるかを数えなければなりません$1 \le n < 10000$は、この定義に基づくライクレル数です。 

---

 # 数学的分析

 正の整数の場合$n$:

 1. 10 進数を反転します。$$r(n)$$2. フォーム:$$n_1 = n + r(n)$$3. もし$n_1$回文です、やめてください。 
4. それ以外の場合は繰り返します。 

分類する$n$50 回の反復以内に回文が出現しなかった場合は、ライクレル数として返されます。 

---

 ## 例 1:$47$

$$47 + 74 = 121$$以来$121$回文です、$47$ライクレルではありません**。 

---

 ## 例 2:$349$

$$349 + 943 = 1292$$

$$1292 + 2921 = 4213$$

$$4213 + 3124 = 7337$$3 回の反復の後、回文が得られます。$7337$、 それで$349$リクレルではありません。 

---

 # 主な所見

 ## 1. 回文の検出

 数値の 10 進数表現がその逆数と等しい場合、その数値は回文です。 

例えば：

-$121 \rightarrow$回文
 -$7337 \rightarrow$回文
 -$123 \rightarrow$回文ではありません

 アルゴリズム的に:```python
s == s[::-1]
```---

 ## 2. 逆加算演算

 もし$$n = 1234$$それから$$r(n)=4321$$そして$$1234+4321=5555$$---

 ## 3. 反復制限

 この問題には明確に次のように書かれています。 

- 以下のすべての数字$10000$次のいずれか:

 - 50 回未満の反復で回文になる、または
 - この問題では Lychrel が考えられます。 

したがって、最大 50 回の反復のみをテストする必要があります。 

---

 # アルゴリズム

 それぞれの番号について$n$から$1$に$9999$:

 1.セット$x=n$2. 最大 50 回繰り返します。 

- 計算します:$$x \leftarrow x + r(x)$$- もし$x$は回文です:

 -$n$リクレルではありません
 - 停止
 3. 50 回繰り返しても回文が表示されない場合:

 - カウント$n$リクレルとして

 ---

 # Pythonの実装```python
def reverse_number(n):
    """Return the integer obtained by reversing decimal digits of n."""
    return int(str(n)[::-1])

def is_palindrome(n):
    """Check whether n is a palindrome."""
    s = str(n)
    return s == s[::-1]

def is_lychrel(n, limit=50):
    """
    Return True if n is considered a Lychrel number.
    
    We repeatedly apply reverse-and-add up to 'limit' times.
    If a palindrome appears, return False.
    Otherwise return True.
    """
    x = n

    for _ in range(limit):
        x = x + reverse_number(x)

        if is_palindrome(x):
            return False

    return True

# Count Lychrel numbers below 10000
count = 0

for n in range(1, 10000):
    if is_lychrel(n):
        count += 1

print(count)
```---
