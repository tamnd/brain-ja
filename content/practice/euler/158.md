[プロジェクト オイラー問題 158](https://projecteuler.net/problem=158)

 ## 解決策

 **答え:**`409511334375`一定の長さの文字列をカウントしたい$n$**正確に 1 つ**の位置が存在するように、アルファベットの異なる文字から作られています。$i$と$$s_i < s_{i+1}.$$つまり、まさに1回の「上昇」です。 

---

 # ステップ 1: 問題を再定式化する

 どれかを選択してください$n$からの異なる文字$26$-文字のアルファベット。 

文字が選択されると、その実際の値は重要ではなくなり、相対的な順序だけが重要になります。 

したがって、選択した文字を並べ替えた後、ラベルを付け直すことができます$$1,2,\dots,n.$$ここで問題は次のようになります。 

> の順列は何回ありますか$1,\dots,n$上り坂が 1 つだけありますか?

 これは古典的なオイラー数の問題です。 

オイラー数$$A(n,k)$$の順列を数えます$n$正確に一致する要素$k$上昇。 

必要です$$A(n,1).$$標準の ID では次のことが得られます。$$A(n,1)=2^n-n-1.$$したがって、$$p(n)=\binom{26}{n}(2^n-n-1).$$課題はこれを最大化することです$1\le n\le 26$。 

---

 # ステップ 2: サンプルの式を確認する$n=3$問題文では、答えは次のようにする必要があると述べています$10400$。 

次のように計算します。$$A(3,1)=2^3-3-1=4.$$確かに、その中には、$3!=6$順列:

 - 123 → 2 上昇
 - 132 → 1 上昇
 - 213 → 1 上昇
 - 231 → 1 上昇
 - 312 → 1 上昇
 - 321 → 0 上昇

 ちょうど 4 つの順列が 1 つの上昇を持ちます。 

次に 3 文字を選択します。$$\binom{26}{3}=2600.$$したがって、$$p(3)=2600 \times 4 = 10400,$$ステートメントと一致します。 

---

 # ステップ 3: Python の実装```python
from math import comb

# Eulerian number A(n,1) = 2^n - n - 1
# counts permutations of n elements with exactly 1 ascent

best = 0

for n in range(1, 27):

    # number of permutations with exactly one ascent
    eulerian_1 = 2**n - n - 1

    # choose which n letters are used
    p = comb(26, n) * eulerian_1

    if p > best:
        best = p

print(best)
```---
