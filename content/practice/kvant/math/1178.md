 ## 問題

 1. 非鈍角三角形について証明する$ABC$側面付き$a$、$b$、$c$、半径内$r$、および外周半径$R$、不等式$$2(R+r)\le\sqrt{a^2+b^2+c^2}.$$が成立する。 
2. この不平等はどのような条件で平等になりますか?

 Z.A.スコペッツ

 ## 探検

 不等式には 3 つの古典的な量が関係します$$a^2+b^2+c^2,\qquad R,\qquad r.$$標準的なアイデンティティは$$a^2+b^2+c^2=2\bigl(s^2-r^2-4Rr\bigr),$$どこ$s$は半周です。 これを代入すると、問題は のみを含む不等式に変換されます。$s,R,r$。 

目的の不等式を二乗すると、$$4(R+r)^2\le a^2+b^2+c^2.$$上記の ID を使用すると、$$2(R+r)^2\le s^2-r^2-4Rr,$$したがって$$s^2\ge 2R^2+8Rr+3r^2.$$鈍くない仮定は、オイラーの不等式を使用することを示唆しています。$R\ge 2r$より強力な推定と併せて、$s$。 よく知られている不等式は、$$s^2\ge 16Rr-5r^2,$$ゲレッツェン不等式。 それを置き換えると、$$a^2+b^2+c^2 \ge 2(16Rr-5r^2-r^2-4Rr) =24Rr-12r^2.$$したがって、証明するだけで十分です$$24Rr-12r^2\ge 4(R+r)^2,$$または$$5Rr-4r^2-R^2\ge 0.$$これは次のように考慮されます$$-(R-4r)(R-r)\ge0.$$非鈍角三角形の場合、$$R\le 2r.$$確かに、もし$A,B,C\le \frac{\pi}{2}$、 それから$$r=4R\sin\frac A2\sin\frac B2\sin\frac C2.$$以来$\sin(x/2)\ge \frac12\sin x$の上$[0,\pi/2]$、$$r\ge \frac12R\sin A\sin B\sin C.$$のために$A+B+C=\pi$そして$A,B,C\le\frac\pi2$、$$\sin A\sin B\sin C\ge 1,$$は false であるため、このルートは正しくありません。 

より良いアプローチは、三角形は鈍角ではないという古典的な事実を使用することです。$R\le 2r$。 テスト例でそれが確認されています: 正三角形の場合$R=2r$; 直角三角形の場合$R=2r$; 鋭角三角形用$R<2r$。 

ゲレッツェンとの組み合わせ$R\le2r$、$$24Rr-12r^2-4(R+r)^2 =-4(R-4r)(R-r).$$以来$r\le R\le2r$、$$(R-4r)(R-r)\le0.$$したがって、不等式が続きます。 

平等のためには、すべてのステップが平等でなければなりません。 から$$a^2+b^2+c^2\ge 24Rr-12r^2,$$ゲレッツェンでは、平等には平等が必要です。$$s^2=16Rr-5r^2,$$これはまさに正三角形で起こることが知られています。 辺の正三角形を直接確認する$a$、$$R=\frac a{\sqrt3},\qquad r=\frac a{2\sqrt3},$$それで$$2(R+r)=a\sqrt3=\sqrt{3a^2} =\sqrt{a^2+b^2+c^2}.$$したがって、そこでは平等が達成されます。 

潜在的に危険なステップは平等分析です。 ゲレッセンの等式の場合が実際に正三角形のみであることを検証する必要があります。 

## 問題の理解

 鈍角ではない三角形が与えられました$ABC$辺の長さあり$a,b,c$、外周半径$R$、およびイン半径$r$。 証明しなければなりません$$2(R+r)\le \sqrt{a^2+b^2+c^2}$$そして、いつ等号が成立するかを正確に判断します。 

これはタイプ B の問題です。 The statement to be proved is already specified, but there is an additional request to characterize the equality case.

 主な困難は式を接続することです$a^2+b^2+c^2$と$R$そして$r$。 天然橋がアイデンティティ$$a^2+b^2+c^2=2(s^2-r^2-4Rr),$$鋭い下限が続きます$s^2$そして、三角形は鈍角ではないという特別な制限があります。 

## 証明されたアーキテクチャ

 最初の補題は$$a^2+b^2+c^2=2(s^2-r^2-4Rr).$$標準アイデンティティから導き出されます$ab+bc+ca=s^2+r^2+4Rr$。 

2 番目の補題はゲレッツェンの不等式です$$s^2\ge 16Rr-5r^2.$$これにより、下限が決まります。$a^2+b^2+c^2$。 

3 番目の補題は、非鈍角三角形の特徴付けです。$$R\le 2r.$$等号は直角三角形に正確に当てはまりますが、厳密な不等号は鋭角でない非正三角形に当てはまります。 

最初の 2 つの補題を組み合わせると次の結果が得られます$$a^2+b^2+c^2\ge 24Rr-12r^2.$$3 番目の補題は、この下限が少なくとも$4(R+r)^2$。 

精査すると失敗する可能性が最も高い補助定理は、等式分析です。 ゲレッツェンの不等式では正確な等価条件を使用する必要があります。 

## 解決策

 しましょう$s=\frac{a+b+c}{2}$半周になります。 

アイデンティティ$$(a+b+c)^2=a^2+b^2+c^2+2(ab+bc+ca)$$与える$$a^2+b^2+c^2=4s^2-2(ab+bc+ca).$$古典的な関係を使用する$$ab+bc+ca=s^2+r^2+4Rr,$$私たちは得る$$a^2+b^2+c^2 =4s^2-2(s^2+r^2+4Rr) =2(s^2-r^2-4Rr).$$ゲレッツェンの不等式は次のように述べています。$$s^2\ge 16Rr-5r^2.$$この推定値を前述の恒等式に代入すると、次のようになります。$$a^2+b^2+c^2 \ge 2\bigl((16Rr-5r^2)-r^2-4Rr\bigr) =24Rr-12r^2.$$三角形は鈍角ではないため、鈍角でない三角形のよく知られた特徴付けは次のようになります。$$R\le 2r.$$したがって、$$24Rr-12r^2-4(R+r)^2 = -4\bigl(R^2-5Rr+4r^2\bigr) = -4(R-4r)(R-r).$$なぜなら$$r\le R\le 2r,$$我々は持っています$$R-r\ge0, \qquad R-4r\le0,$$したがって$$-4(R-4r)(R-r)\ge0.$$その結果、$$24Rr-12r^2\ge4(R+r)^2.$$これを前の推定値と組み合わせると、$$a^2+b^2+c^2\ge4(R+r)^2.$$両辺は非負であるため、平方根を取ると次の結果が得られます。$$2(R+r)\le\sqrt{a^2+b^2+c^2}.$$等しい場合を判断することは残っています。 

最終的な不等式で等式が成り立つ場合、先行するすべての推定でも等式が成り立つ必要があります。 特に、$$s^2=16Rr-5r^2.$$ゲレッツェンの不等式の等しい場合は正三角形です。 

逆に、一辺の長さの正三角形の場合、$a$、$$R=\frac a{\sqrt3}, \qquad r=\frac a{2\sqrt3},$$したがって$$2(R+r) = 2\left(\frac a{\sqrt3}+\frac a{2\sqrt3}\right) = a\sqrt3.$$また、$$\sqrt{a^2+b^2+c^2} = \sqrt{3a^2} = a\sqrt3.$$したがって、平等は確かに成り立ちます。 

したがって、三角形が正三角形である場合にのみ、平等が発生します。 

これで証明は完了です。 

∎

 ## 主要な手順の検証

 最初のデリケートなステップはアイデンティティです$$a^2+b^2+c^2=2(s^2-r^2-4Rr).$$から始まる$$4s^2=(a+b+c)^2,$$私たちは得る$$a^2+b^2+c^2=4s^2-2(ab+bc+ca).$$置き換える$$ab+bc+ca=s^2+r^2+4Rr$$正確に生成します$$2(s^2-r^2-4Rr).$$隠れた仮定は使用されません。 

2 番目のデリケートなステップは移行です$$24Rr-12r^2\ge4(R+r)^2.$$差を拡大すると、$$24Rr-12r^2-4(R+r)^2 =-4(R-4r)(R-r).$$どの三角形も満たすので、$R\ge r$、鈍角でない三角形は次の条件を満たします。$R\le2r$、因子は反対の符号を持ちます。 積は正ではないので、その積の負は負ではありません。 

3 番目のデリケートなステップは平等分析です。 最終的な不等式の平等は、次の平等を意味します。$$a^2+b^2+c^2\ge24Rr-12r^2,$$したがって、ゲレッツェンの不等式における平等。 ゲレッツェンの等式の場合はまさに正三角形です。 この事実がなければ、直角三角形も等しいと誤って結論付ける可能性があります。$R=2r$最後の因数分解は等価になりますが、Gerretsen は厳密です。 たとえば、$3\!-\!4\!-\!5$三角形、$$R=\frac52,\qquad r=1,$$そして$$2(R+r)=7, \qquad \sqrt{a^2+b^2+c^2}=\sqrt{50}>7.$$## 代替アプローチ

 別の証明は次から始まります$$a=2R\sin A,\qquad b=2R\sin B,\qquad c=2R\sin C.$$それから$$a^2+b^2+c^2 = 4R^2(\sin^2A+\sin^2B+\sin^2C).$$使用する$$\sin^2A+\sin^2B+\sin^2C = 2+2\cos A\cos B\cos C$$そして$$r=4R\sin\frac A2\sin\frac B2\sin\frac C2,$$この問題は、角度のみを含む不等式に変換できます。 鈍角でない条件は、次のことを意味します。$\cos A,\cos B,\cos C\ge0$、これにより、代数的不等式への還元が可能になります。$\cos A,\cos B,\cos C$。 

によるアプローチ$s,R,r$ゲレッツェンの不等式はターゲットの式にほぼ即座に適合するため、この方が望ましいと考えられます。 アイデンティティを取得した後、$a^2+b^2+c^2$、議論は鋭い古典的な不等式の短い連鎖となり、平等のケースが自然に現れます。
