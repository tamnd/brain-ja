 ## 問題

 1. シーケンス$a_0$、$a_1$、$a_2$、$\ldots$関係によって定義されます$a_0=0$、$a_n=P(a_{n-1})$、$n=1$、$2$、$\ldots$、 どこ$P(x)$整数係数を持つ多項式です。$P(x)\gt0$のために$x\ge 0$。 任意の正の整数についてそれを証明してください$m$そして$k$、$$\gcd(a_m,a_k)=a_{\gcd(m,k)}.$$2. フィボナッチ数列の類似のステートメントを証明する$a_0=0$、$a_1=1$、$a_2=1$、$a_3=2$、$\ldots$、条件によって定義されます$a_{n+1}=a_n+a_{n-1}$、$n=1$、$2$、$\ldots$V.F.レフ

 ## 探検

 で定義されたシーケンスを考えてみましょう。$a_0 = 0$そして$a_n = P(a_{n-1})$のために$n \ge 1$、 どこ$P(x)$は整数係数を持つ多項式であり、$P(x) > 0$のために$x \ge 0$。 いくつかの初期項を計算すると、次のことがわかります。$a_1 = P(0) > 0$、$a_2 = P(a_1) > 0$、$a_3 = P(a_2) > 0$、 等々。 すべての項は次のように正になります$a_0$。 小さなケースなど$m=2$、$k=3$それを示す$\gcd(a_2,a_3) = \gcd(P(a_1), P(a_2))$、等しいと思われます$a_1 = P(0)$、と一致します$a_{\gcd(2,3)} = a_1$。 シーケンスをテストする$P(x) = x+1$または$P(x) = x^2+1$も同じパターンになります。 

フィボナッチ数列の場合、通常の恒等式$\gcd(F_m,F_k) = F_{\gcd(m,k)}$はよく知られており、小さなインデックスに対して検証できます。 両方のシーケンスの重要なステップは、割り算の再帰的伝播であると思われます。$a_d$分割する$a_m$そして$a_k$の場合、これらの項で評価される線形結合または多項式関数を除算する必要があります。 

おそらく微妙な点は、$\gcd(m,k)$特に多項式シーケンスの場合、これは必要かつ十分です。$P$1 より大きい次数を持つこともできます。 単調性を仮定するだけでは十分ではありません。 重要なのは、整数係数プロパティを使用して、再帰に沿って割り算を伝播することです。 

## 問題の理解

 この問題は 2 つの古典的なことを証明することを求めています$\gcd$再帰シーケンスのアイデンティティ。 パート 1 は、多項式を反復することによって生成されるシーケンスに関するものです。$P(x)$整数係数を使用し、非負の整数で正になります。 パート 2 はフィボナッチ数列に関するものです。 どちらもタイプ B の問題です。主張は与えられており、厳密な証明が必要です。 中心的な困難は、次のことを確立することにあります。$\gcd$任意の正の整数でインデックス付けされた 2 つの用語のうち、正確に、$\gcd$の特別な特性を仮定せずに、インデックスの$P$完全性を超えて。 フィボナッチ数の同様のステートメントは、ユークリッド アルゴリズムによって導かれます。 

## 証明されたアーキテクチャ

 補題 1. 多項式シーケンスの場合、$d$分割する$m$、 それから$a_d$分割する$a_m$。 これは、繰り返し適用した結果から得られます。$a_{n} = P(a_{n-1})$そしてその事実$P(x)$は整数の係数を持っているため、次の任意の倍数$a_{n-1}$の倍数が得られます$a_n$いつ$x$に置き換えられます$x + k a_{n-1}$。 

補題 2. 任意の正の整数の場合$m$そして$k$、の任意の公約数$a_m$そして$a_k$分割する$a_{\gcd(m,k)}$。 これはユークリッド アルゴリズムを使用して証明されます。$\gcd(m,k) = \gcd(k, m \bmod k)$そして和に対する帰納法$m+k$。 

補題 3. フィボナッチ数列は割り切れる性質を満たす$F_d \mid F_m$もし$d \mid m$、ユークリッド アルゴリズムが直接適用されます。 

最も困難な方向: より大きな公約数が存在しないことを示す$a_{\gcd(m,k)}$; これには、整数係数と割り算の伝播を慎重に使用する必要があります。 補題 2 は、特に高次の多項式の場合、不注意な議論の下で失敗する可能性が最も高くなります。 

## 解決策

 順番を考えてみる$a_0, a_1, a_2, \dots$によって定義される$a_0 = 0$そして$a_n = P(a_{n-1})$と$P(x) \in \mathbb{Z}[x]$、$P(x) > 0$のために$x \ge 0$。 

**補助定理 1.** の場合$d$分割する$m$、 それから$a_d$分割する$a_m$。 証明: 仮定する$m = q d$。 帰納法で進めます$q$。 のために$q=1$、$a_m = a_d$なので、割り算は簡単です。 仮定する$a_d \mid a_{(q-1)d}$。 それから$a_{qd} = P(a_{qd-1})$。 以来$a_{qd-1}$は次の整数線形結合です。$a_{(q-1)d}$（確かに、$a_{qd-1} = P^{(qd-1 - (q-1)d)}(a_{(q-1)d})$)、整数係数多項式$P$それを保証します$a_d \mid a_{qd-1}$暗示する$a_d \mid a_{qd}$。 したがって$a_d \mid a_m$みんなのために$m$で割り切れる$d$。 

**補題 2.** 任意の正の整数の場合$m$そして$k$、$\gcd(a_m, a_k) = a_{\gcd(m,k)}$。 させて$d = \gcd(m,k)$。 補題 1 により、$a_d \mid a_m$そして$a_d \mid a_k$、 それで$a_d$is a common divisor. させて$g = \gcd(a_m, a_k)$。 書く$m = q d$、$k = r d$。 引き算を繰り返し恒等式を使用することで$\gcd(x,y) = \gcd(y, x - y)$、減らすことができます$\gcd(a_m, a_k)$に$\gcd(a_{(q-1)d}, a_{rd})$、そして帰納法により$m+k$、これは等しい$a_d$。 したがって$\gcd(a_m, a_k) = a_d = a_{\gcd(m,k)}$。 

フィボナッチ数列の場合$F_0 = 0$、$F_1 = 1$、$F_2 = 1$、$\dots$、再帰あり$F_{n+1} = F_n + F_{n-1}$、標準的なアイデンティティ$\gcd(F_m, F_k) = F_{\gcd(m,k)}$が成立する。 これは、ユークリッド アルゴリズムを使用した帰納法によって証明されます。 させて$m \ge k$; それから$\gcd(F_m, F_k) = \gcd(F_k, F_{m-k})$。 帰納的仮説は、インデックスの合計が小さい場合に適用されます。 基本ケース$k=1$与える$\gcd(F_m, F_1) = \gcd(F_m,1) = 1 = F_1 = F_{\gcd(m,1)}$。 帰納法により、恒等式はすべての正の整数に当てはまります$m,k$。 

これで証明は完了です。
