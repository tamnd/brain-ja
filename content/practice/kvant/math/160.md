 ## 問題

 総当たりのホッケー トーナメントが終了すると、どのグループのチームでも、そのグループ内のチームとの試合で奇数のポイントを獲得したチーム (おそらく同じグループの) が見つかる可能性があることが判明しました。 トーナメントに偶数のチームが参加していたことを証明してください。 (負け — 0 ポイント、引き分け — 1 ポイント、勝ち — 2 ポイント。)

 G.A.カスパロフ

 全学学生数学オリンピック（1972年、10年生）

 ## 探検

## 問題の理解

 この問題は、ポイントに関する強力な同等特性を満たす総当りトーナメントには偶数のチームが必要であることを証明することを求めています。 問題はタイプ B です。問題は、ローカルなプロパティ (サブセットに対して奇数のポイントを持つチームの存在) とグローバルな構造的不変条件 (チームの総数) を結び付けることにあります。 直観的には、この要件は、対称行列の条件に似ています。$\mathbb{F}_2$ここで、サブセットの行または列のエントリの合計をゼロにすることはできません。奇数サイズの行列ではこれは不可能です。 予想される結論は、$n$指定されたパリティ条件を一貫して満たせるのは偶数次の構造だけであるため、偶数である必要があります。 

## 証明されたアーキテクチャ

 補助定理 1: トーナメントのポイント テーブルは対称行列として表現できる$P$対角にゼロがあり、エントリは 0、1、2、和は 2 を法として計算されます。スケッチは単純です。2 を法として、2 は 0 になり、1 は 1 のまま、0 は 0 のままなので、パリティだけが問題になります。 

補題 2: ベクトル空間を定義する$\mathbb{F}_2$チームに対応するベースを持つ。 各行のモジュロ 2 は、他のチームに対するポイントの同等性を表すベクトルです。 補題は、存在条件がベクトルの合計がゼロになる空でないサブセットがないことを意味するということです。 これは、サブセットの合計がゼロの場合、どのチームもそれに対して奇数のポイントを獲得しないためです。 

補題 3: 対称ゼロ対角行列$\mathbb{F}_2$奇数サイズのスパンには、空でないサブセット全体で合計が 0 になる非ゼロ ベクトルが常に含まれます。 スケッチ: で$\mathbb{F}_2$、対角がゼロの対称行列のすべての行の合計は、次の場合にゼロになります。$n$奇数です。 これは重要なステップです。 

補題 4: したがって、次の場合$n$奇数である場合、奇数のポイントを獲得しているチームがないチームのサブセットが存在し、条件に違反します。 これに続いて、すべての行を 2 を法として明示的に合計します。 

主な議論: 補助定理 3 と 4 を組み合わせると次のようになります。$n$奇数にすることはできないので、$n$は均等です。 最も難しいステップは補題 3 です。これは、対称ゼロ対角行列の構造を使用します。$\mathbb{F}_2$。 

## 解決策

 トーナメントの構成を次のようにします$n$ラベルが付いたチーム$1,2,\dots,n$。 を構築します$n \times n$マトリックス$P$エントリーあり$p_{ij}$、 どこ$p_{ii}=0$そしてのために$i \neq j$、$p_{ij}$はチームのポイント数です$i$チームに対して得点した$j$。 この行列のモジュロ 2 を考えて、次のように表します。$Q$、 それで$q_{ij} = p_{ij} \bmod 2$、値を取り込みます${0,1}$。 

任意のサブセットに対して$S \subseteq {1,2,\dots,n}$、 させて$s_i(S) = \sum_{j \in S} q_{ij}$チームのポイントの合計が同等であること$i$のチームに対して得点した$S$。 問題の仮定は、すべてのサブセットについて、$S$、いくつか存在します$i$(おそらく$S$)そのような$s_i(S) = 1$。 同様に、空でないサブセットはありません$S$満足する$s_i(S) = 0$みんなのために$i$。 

仮定する$n$奇数です。 ベクトルを考えてみる$\mathbf{1} = (1,1,\dots,1)$長さの$n$。 すべての行の合計$Q$は 2 を法とするゼロベクトルです。$Q$対角線がゼロの対称です:$$\sum_{i=1}^n q_{ij} = \sum_{i \neq j} q_{ij} = \sum_{i \neq j} q_{ji} = \sum_{i \neq j} q_{ij}.$$したがって、各列について、対角以外のすべてのエントリの合計は偶数であるため、すべての行を合計すると 2 を法としてゼロになります。すべてのチームのセットを次のように表します。$S = {1,2,\dots,n}$。 それから$s_i(S) = \sum_{j=1}^n q_{ij} = \sum_{j \neq i} q_{ij}$なぜなら$q_{ii} = 0$。 全体をまとめると$i$、 我々は持っています$$\sum_{i=1}^n s_i(S) = \sum_{i=1}^n \sum_{j \neq i} q_{ij} = \sum_{1 \le i \neq j \le n} q_{ij} = 2 \sum_{1 \le i < j \le n} q_{ij} \equiv 0 \pmod 2.$$以来$n$は奇数、奇数の合計$s_i(S)$モジュロ 2 はゼロです。これは、少なくとも 1 つが存在することを意味します。$s_i(S)$ゼロでなければなりません。 これは、すべてのサブセットに対して、奇数のポイント合計を持つチームが存在するという特性と矛盾します。 したがって$n$奇数であることはできません。 

したがって、$n$は均等です。 これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、すべての行を 2 を法として合計して矛盾を生成することです。$n$奇数です。 再導出すると、すべての非対角エントリの合計を次のように表します。$T = \sum_{1 \le i < j \le n} q_{ij}$。 それから$$\sum_{i=1}^n s_i(S) = 2T \equiv 0 \pmod 2.$$奇数の場合$n$、この合計$n$項モジュロ 2 はゼロに等しい。 すべての場合$s_i(S)$が 1 の場合、合計は次のようになります$n \equiv 1 \pmod 2$、矛盾です。 これは議論を裏付けるものである。 テスト$n=3$可能な構成のモジュロ 2 を明示的に使用すると、証明と一致して、一部のサブセットが奇数特性を満たさないことがわかります。 

もう 1 つの微妙な手順は、行列の法 2 が対角ゼロで対称であることを検証することです。 施工により、$q_{ij} = p_{ij} \bmod 2$そして$p_{ij} + p_{ji} \in {0,2}$, 勝利すると一方のチームに2ポイントが与えられ、もう一方のチームには0ポイントが与えられるため、引き分けは両方に1ポイントを与えます。 したがって、$q_{ij} + q_{ji} \equiv p_{ij} + p_{ji} \equiv 0 \pmod 2$、 それで$Q$これにより、必要な行列のプロパティがすべて確認されます。
