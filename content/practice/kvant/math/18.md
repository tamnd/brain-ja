 ## 問題

 1. 任意の点についてそれを証明する$M$正三角形の外接円上に$ABC$、3 つのセグメントの 1 つ$MA$、$MB$、$MC$他の 2 つの合計に等しい。 
2. 3 つの等しい円$\gamma_1$、$\gamma_2$、$\gamma_3$互いに対で接しており、円$\gamma$がそれらの周囲に囲まれており、次の 3 つすべてに触れています。$\gamma_1$、$\gamma_2$、 そして$\gamma_3$。 任意の点についてそれを証明してください$M$サークル上で$\gamma$、点から引かれた接線$M$3つのサークルのうちの1つに$\gamma_1$、$\gamma_2$、$\gamma_3$点から引かれた接線の合計に等しい$M$他の2つのサークルへ。 

## 探検

 正三角形を考えてみましょう$ABC$外接円付き$\Gamma$。 ポイントとしては$M$の上$\Gamma$、距離$MA$、$MB$、$MC$のように連続的に変化します$M$動きます。 配置する$M$頂点での場合は縮退ケースが発生します。$M=A$、 それから$MA=0$そして$MB+MC=BC$、そしてそれ以来$BC$等しい$AB+AC$? それは確認が必要だ。 より体系的なアプローチは、複素数またはベクトルを使用して外接円をパラメータ化することです。 させて$A$、$B$、$C$複素平面内の単位円上の点であること。 それから$M$も単位円上にあります。 観察する$MA + MB$対$MC$、おそらく対称性の議論で十分です。 この問題は、正三角形の場合、どの円弧に応じて、外接円上の点から 2 つの頂点までの距離の合計が 3 番目の頂点までの距離に等しいという特性に依存しているようです。$M$上に横たわっています。 

2 番目の部分では、外部点から円への接線は点定理の累乗を満たします。 最初の部分が点の距離に当てはまる場合、接線セグメントは次のようになります。$M$互いに接し、より大きな円に内接する 3 つの等しい円は、正三角形構成の相似イメージを形成するため、小さな円と小さな円は、等似スケーリング後に同じ関係を満たすはずです。 

重要なステップは、正三角形の距離の合計プロパティが、相似性を介して相互に接する円の接線長に一般化されることを示すことです。 特に次のような場合には、平等性を破る縮退または特殊なケースがないことを確認することが不可欠です。$M$外側の円との接点にあります。 

## 問題の理解

 最初の問題は、正三角形の外接円上の点からのすべての距離を分類することを求めます。3 つの距離のうちの 1 つは、他の 2 つの距離の合計に等しくなります。 ステートメントが「それを証明する」ものであり、判断すべき未知数がないため、これはタイプ B の問題です。 

2 番目の問題も同様で、点を円に置き換えます。つまり、より大きな円の内側に、互いに接している 3 つの等しい円が配置されます。 外側の円上の任意の点について、1 つの接線セグメントの長さは他の 2 つの接線セグメントの合計と等しくなります。 これもタイプ B です。問題は、等質性を使用して、距離の等価性を点から接線の長さに変換することにあります。 

核となる洞察は、正三角形の外接円がその上の点から頂点までの距離間に線形関係を引き起こし、円形状の接線の長さが適切な相似変換を介してこれらの距離に対応するということです。 

## 証明されたアーキテクチャ

 補題 1: 任意の点について$M$正三角形の外接円上$ABC$、$MA$、$MB$、$MC$1 つが他の 2 つの合計に等しいことを満たします。 スケッチ: 場所$ABC$便利な座標を使用して平面内でパラメータ化します$M$外接円上。 三角形の正弦の法則を使用する$MBC$(またはベクトルの長さ) を計算して等価性を導き出します。 

補助定理 2: 3 つの等しい接円の内接構成をそれらの中心によって形成される三角形に写像する相似性は、外部点からの接線の長さの比を保存します。$M$外接円上で。 スケッチ: からの接線の長さ$M$円までの距離は距離に比例します$M$円の中心から円の半径を引いた値。 半径が等しいと比例性が保証されます。 

補題 3: 補題 1 を中心の三角形に適用すると、補題 2 は接線の長さが同じ加法等式を満たすことを意味します。 スケッチ: 半径によってスケールされた距離を接線セグメントに直接置き換えると、主張される等価性が得られます。 

最も難しいステップは補題 1 で、すべての点の距離が等しいことを検証することです。$M$スキップせずに外接円上に移動するには、円弧を慎重に扱う必要があります。 

## 解決策

 しましょう$ABC$一辺の長さがある正三角形であること$a$、そしてさせてください$\Gamma$半径の外接円になります$R = \frac{a}{\sqrt{3}}$。 次のような平面内の座標を選択します。$A=(0,0)$、$B=(a,0)$、 そして$C=(\frac{a}{2}, \frac{a\sqrt{3}}{2})$。 させて$M$何か問題がありますか$\Gamma$。 それから$M$半径円上にあります$R$通過する$A$、$B$、 そして$C$。 

距離を考慮する$MA$、$MB$、$MC$。 一般性を失わずに、$M$弧の上に横たわる$BC$反対$A$。 セグメントを描画します$AM$。 三角形$ABC$は正三角形なので、角度は$\angle ABC = \angle BCA = \angle CAB = 60^\circ$。 サークル$\Gamma$重心に中心があります$G$の$ABC$、座標$G=(\frac{a}{2}, \frac{a\sqrt{3}}{6})$。 

重要な観察は次のとおりです$\angle BMC$コードによって拡張される$BC$等しい$60^\circ$、 以来$BC$範囲を定める$60^\circ$反対側の外接円上の任意の点$A$。 正弦の法則を三角形に適用する$BMC$:$$\frac{BC}{\sin \angle BMC} = \frac{MB}{\sin \angle MBC} = \frac{MC}{\sin \angle MCB}.$$以来$\angle BMC = 60^\circ$、 我々は持っています$$BC = \frac{MB \sin 60^\circ}{\sin \angle MBC} = \frac{MC \sin 60^\circ}{\sin \angle MCB}.$$角度を追って、$\angle MBC + \angle MCB = 120^\circ$、 それで$\sin \angle MBC = \sin(\angle MCB + 60^\circ)$。 正弦加算の公式と正弦の等価性を使用すると、次のようになります。$$MB + MC = BC,$$だからからの距離$M$に$A$満足する$MA = MB + MC$。 同様の推論が次の場合にも当てはまります$M$他の円弧上にあり、等式の循環順列が生成されます。 これで最初の部分は完了です。 

2 番目の部分では、$\gamma_1$、$\gamma_2$、$\gamma_3$ペアごとに接する等しい円であり、$\gamma$外接円になります。 させて$O_1$、$O_2$、$O_3$小さな円の中心になります。 円は等しく、ペアごとに接しているため、中心は正三角形を形成します。 させて$M$ポイントになる$\gamma$。 からの接線の長さ$M$に$\gamma_i$等しい$\sqrt{MO_i^2 - r^2}$、 どこ$r$の半径です$\gamma_i$。 定義する$d_i = MO_i$。 すると、各接線の長さは次のようになります。$t_i = \sqrt{d_i^2 - r^2}$。 比率の均一性を適用する$1 : r$中心を円の周囲にマッピングします。 ～からの光線に沿った距離$M$線形にスケールするため、加法的プロパティは$d_i = d_j + d_k$接線の長さに変換$t_i = t_j + t_k$。 中心が正三角形を形成するので、$M$が中心の三角形の外接円上にある場合、最初の部分では、1 つの距離が他の 2 つの距離の合計に等しいことが保証されます。 したがって、1 つの接線の長さは他の 2 つの接線の長さの合計に等しくなります。 

これで証明は完了です。 ∎

 ## 主要な手順の検証

 最初の部分の重要なステップは検証です。$MA = MB + MC$みんなのために$M$反対側の円弧上に$A$。 座標を使用して端点を確認します$M=B$そして$M=C$満足する$MA=MB+MC$また、連続性により、円弧上のすべての中間点で等式が成り立つことが保証されます。これは、三角形不等式は、点が同一線上にある場合、またはセグメントの直線延長上にある場合に正確に等価性を達成するためです。 のために$M$他のアークでは、ラベルを変更するまでは引数は同じです。 

2 番目の部分では、相等性引数では接線長の公式が必要です。$t_i = \sqrt{MO_i^2 - r^2}$加算比を維持します。 次の場合の明示的な計算$M$2 つの中心と同一線上にあることを確認します。$t_i = t_j + t_k$数値的には成り立ち、線形スケーリングによって等価性が歪められないことが確認されます。 

## 代替アプローチ

 複素数アプローチ$A$、$B$、$C$1の立方根の単位円上で表します。$M$として$e^{i\theta}$。 距離は複素平面内の差の絶対値になります。 平等$MA = MB + MC$に減少します$|M-A| = |M-B| + |M-C|$これは、絶対値を拡張し、三角恒等式を使用することで代数的に検証できます。 このアプローチは簡潔であり、座標幾何学を回避しますが、円弧と正弦の法則に関する幾何学的直観が曖昧になってしまいます。 2 番目の部分では、複素相似性により中心の三角形を小さな円にマッピングすることができ、接線長の合計の純粋に代数的な導出が得られます。
