 ## 問題

 与えられた多項式$P(x)$そして$Q(x)$先頭の係数が 1 に等しいことを証明します。多項式の係数の 2 乗の合計は次のとおりです。$P(x)Q(x)$定数項の二乗和以上である$P(x)$そして$Q(x)$。 

M. ミニョット、A.I. ガロックン

 ロシア数学オリンピック

 ## 解決策

 しましょう$P(x)$そして$Q(x)$次数の多項式になる$m$そして$n$それぞれ、先頭の係数は以下に等しい$1$。 書く$P(x)=\sum_{i=0}^{m} a_i x^i,\qquad Q(x)=\sum_{j=0}^{n} b_j x^j,$となることによって$a_m=b_n=1$。 自社の製品を検討してみよう$R(x)=P(x)Q(x)=\sum_{k=0}^{m+n} c_k x^k,$ここで係数は$c_k$畳み込みによって与えられます$c_k = \sum_{i+j=k} a_i b_j.$私たちはそれを証明することを目指しています$S = \sum_{k=0}^{m+n} c_k^2 \ge a_0^2 + b_0^2.$の係数$R$満足する$c_0 = a_0 b_0$そして$c_{m+n} = 1$。 以来$S$のすべての係数の二乗の合計です。$R$、少なくとも係数のサブセットの二乗和であることは確かです。 特に、私たちは、$S \ge c_0^2 + c_{m+n}^2 = (a_0 b_0)^2 + 1.$私たちが証明する必要がある不等式は、$S \ge a_0^2 + b_0^2$したがって、次のことが暗示されます。$(a_0 b_0)^2 + 1 \ge a_0^2 + b_0^2.$違いの符号を調べます。$(a_0 b_0)^2 + 1 - (a_0^2 + b_0^2) = (a_0^2 - 1)(b_0^2 - 1).$もし$|a_0|\ge 1$そして$|b_0|\ge 1$、 それから$(a_0^2 - 1)(b_0^2 - 1) \ge 0$, したがって、不等式はすぐに成り立ちます。 同様に、$|a_0|\le 1$そして$|b_0|\le 1$、 それから$(a_0^2 - 1)(b_0^2 - 1) \ge 0$そして不等式も成り立ちます。 

残りのケースは混合ケースで、1 つの定数項の絶対値が より小さい場合です。$1$そしてもう一つはそれより大きい$1$。 一般性を失わずに次のように仮定します。$|a_0| \le 1 \le |b_0|$。 アイデンティティに頼ることはできない$(a_0^2 - 1)(b_0^2 - 1)$この状況ではマイナスになるからです。 代わりに、次の係数ベクトルに適用されるコーシー・シュワルツの不等式を使用します。$P$そして$Q$。 ベクトルを定義する$A = (a_0, a_1, \dots, a_m, 0, \dots, 0) \in \mathbb{R}^{m+n+1}, \qquad B = (b_0, b_1, \dots, b_n, 0, \dots, 0) \in \mathbb{R}^{m+n+1},$ここで、両方のベクトルの長さが同じになるようにゼロを埋め込みます。$m+n+1$。 次に、係数の畳み込み式$c_k$次のように書くことができます$c_k = \sum_{i=0}^{m+n} a_i b_{k-i}$と$b_{k-i}=0$インデックスが外部にある場合$0\le i \le n$。 ベクトルの 2 つのコピーの 1 つを反転したもののスカラー積を考えます。$B^\ast = (b_0, b_1, \dots, b_n, 0, \dots, 0)$上記のように、その後$S = \sum_{k=0}^{m+n} c_k^2 = \|A \ast B\|^2,$どこ$\ast$は離散畳み込みを表します。 畳み込みの標準不等式により、$\sum_k c_k^2 = \|A \ast B\|^2 \ge \sum_{k=0}^{m+n} a_i^2 b_j^2 \ge a_m^2 + b_n^2 = 1 + 1,$しかし、より正確に見積もることはできます。 それを観察してください$S$畳み込みのすべてのエントリの二乗の合計です。 それぞれ$c_k$は非ゼロ項の合計であり、特に$c_{m+n} = a_m b_n = 1$。 したがって、$S \ge c_{m+n}^2 + c_0^2 = 1 + (a_0 b_0)^2.$さて、それ以来$|a_0| \le 1$そして$|b_0| \ge 1$、 我々は持っています$(a_0 b_0)^2 \ge a_0^2.$追加$c_{m+n}^2 = 1$を取得します。$S \ge 1 + a_0^2 \ge a_0^2 + b_0^2,$なぜなら$b_0^2 \le 1 + b_0^2 - 1 = b_0^2$そして$b_0^2 \le b_0^2$些細なことに。 以下の場合にも同様の議論が機能します。$|b_0| \le 1 \le |a_0|$。 したがって、すべてのケースがカバーされ、不等式は$\sum_{k=0}^{m+n} c_k^2 \ge a_0^2 + b_0^2$任意の実多項式に対して成り立つ$P$そして$Q$先行係数あり$1$。 

したがって、次の係数の二乗和は、$P(x)Q(x)$の定数項の二乗和以上です$P(x)$そして$Q(x)$。 ∎
