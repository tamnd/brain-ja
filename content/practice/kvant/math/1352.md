 ## 問題$n$数字 ($n\gt1$) それぞれがこれらの数値の合計を で割った値より小さい場合、close と呼ばれます。$n-1$。 させて$a$、$b$、$c$、$\ldots$なれ$n$数字を閉じて、$S$それらの合計になります。 それを証明してください

 1. それらはすべて陽性です。 
2.いつも$a+b\gt c$;
 3.いつも$a+b\ge\dfrac S{n-1}$。 

R・シュライファー

 市大会

 ## 探検

 「近い」数値の定義を考えてみましょう。 のために$n$数字$a_1, a_2, \dots, a_n$、それぞれを満たす$a_i < \frac{a_1 + a_2 + \dots + a_n}{n-1} = \frac{S}{n-1}.$のために$n = 2$、不等式は次のように減少します。$a < b/(2-1) = b$そして$b < a$、それは不可能です。 したがって、この場合$n = 2$は除外されます。 のために$n = 3$、数字を次のようにします$a, b, c$。 不平等はこうなる$a < \frac{b+c}{2}$、$b < \frac{a+c}{2}$、$c < \frac{a+b}{2}$。 小さな数値例は、すべての数値が正であり、次の条件を満たすことを示しています。$a+b > c$。 たとえば、$a=1, b=2, c=2$、計算します$S = 5$、 それから$S/(n-1) = 5/2 = 2.5$、そして確かに$1<2.5$、$2<2.5$、$2<2.5$。 さらに、$a+b = 3 > c = 2$、$a+b = 3 > S/(n-1) = 2.5$。 これによりパターンが確認されます。 主な課題は、恣意的なものの肯定性と不等式を厳密に証明することです。$n$、特に不平等を確保する$a+b \ge S/(n-1)$任意の数値のペアに当てはまります。 

不等式は厳密ですが、単に次の合計に相対的なものであるため、間違いを隠す可能性が最も高い手順は、陽性を証明することです。$n-1$数字。 

## 問題の理解

 についての 3 つのステートメントを証明するように求められます。$n>1$数字$a_1, \dots, a_n$「近い」と呼ばれるもので、不等式によって定義されます。$a_i < S/(n-1)$それぞれに$i$、 どこ$S = a_1+\dots+a_n$。 この問題はタイプ B であり、証明するステートメントが明示的に与えられているため、純粋な証明です。 主な困難は、それぞれの依存関係を処理することです。$a_i$すべての数値の合計を計算し、厳密な不等式を確保すると、正の値と合計の不等式が得られます。 

## 証明されたアーキテクチャ

 補題 1: 近い数はすべて正です。 スケッチ: 1 つの数値が非正であると仮定します。 不等式を合計すると矛盾が生じます。 

補題 2: 任意の 3 つの数値について$a, b, c$の間で$n$数字、$a+b>c$。 スケッチ: 近さの定義を適用する$c$そして並べ替えます。 

補題 3: 任意の 2 つの数値について$a, b$、$a+b \ge S/(n-1)$。 スケッチ: を除く他のすべての数値の不等式の合計$a$そして$b$縛る$S$に関しては$a+b$。 

最も難しい方向は補題 1 です。なぜなら、否定性の素朴な仮定は表面的に 1 つの不等式を満たしてしまう可能性があるからです。 補助定理 3 は、次の要素が含まれるため、最もデリケートです。$n$変数と等価性は自明ではありません。 

## 解決策

 しましょう$a_1, a_2, \dots, a_n$近い数字であることと、$S = a_1 + a_2 + \dots + a_n$。 

**補題 1.** すべて$a_i > 0$。 

仮定する$a_1 \le 0$。 次に、近さの定義は次のようになります。$a_1 < S/(n-1)$。 もし$a_1 \le 0$、 それから$S = a_1 + a_2 + \dots + a_n \le a_2 + \dots + a_n$。 したがって$\frac{S}{n-1} \le \frac{a_2 + \dots + a_n}{n-1}.$一方で、それぞれについて、$i = 2, \dots, n$、$a_i < S/(n-1) \le (a_2+\dots+a_n)/(n-1)$。 これらを合計すると$n-1$不平等がもたらすもの$a_2 + \dots + a_n < \frac{n-1}{n-1} (a_2 + \dots + a_n) = a_2 + \dots + a_n,$それは不可能です。 したがって$a_1 > 0$。 対称性により、すべて$a_i > 0$。 

**補助定理 2.** 任意の場合$a, b, c$、$a+b>c$。 

考慮する$c$数字の一つとして。 親密さによって、$c < S/(n-1)$。 それから$c < \frac{a+b + \sum_{\text{others}}}{n-1} = \frac{a+b + (S - a - b - c)}{n-1} = \frac{S - c}{n-1}.$両辺を乗算すると、$n-1$与える$(n-1)c < S - c = (a+b) + \sum_{\text{others}}$。 他の数値の合計 (補助定理 1 によりすべて正) を減算すると、次の結果が得られます。$a+b > c$。 

**補助定理 3.** あらゆる場合$a, b$、$a+b \ge S/(n-1)$。 

を除くすべての数値の不等式を合計します。$a$そして$b$:$\sum_{i\ne a,b} a_i < \sum_{i\ne a,b} \frac{S}{n-1} = (n-2) \frac{S}{n-1}.$を除くすべての数値の合計$a$そして$b$は$S - a - b$。 したがって$S - a - b < (n-2) S/(n-1)$。 並べ替えると$a+b > S - (n-2) S/(n-1) = S/(n-1)$。 

各補題は証明されます。 それらを組み立てると、必要な結論が得られます。 これで証明は完了です。 

∎

 ## 主要な手順の検証

 補題 1 では、重要なステップは合計です。$a_2 + \dots + a_n < (a_2 + \dots + a_n)$、それは不可能です。 次のような小さな数値を使用したテスト$a_1 = 0$、$a_2 = a_3 = 1$矛盾が発生していることを正確に確認します。 

補題 3 では、再配置は$S - a - b < (n-2) S/(n-1) \implies a+b > S/(n-1)$成立するので$(n-1)(a+b) > S$は同等です。 小さな数値チェック、例:$n=3$、$a=1$、$b=2$、$c=2$、$S=5$、不等式を検証します。 

補助定理 2 は、他の数値の合計を明示的に減算することによって検証され、各項の正の値によって不等式が反転しないことが保証されます。 

## 代替アプローチ

 誘導を試みることができる$n$。 のために$n=3$、不等式は標準の三角形不等式に帰着します。 ステートメントが次のように成り立つと仮定すると、$n-1$数字を追加すると、$n$番目の数値を調べて、合計の不等式が伝播することを確認します。 これはより面倒であり、すべての合計を注意深く追跡する必要がありますが、合計を使用する直接的なアプローチは$S$そして不等式を並べ替えると、すべての主張が即座に確立されます。 もう 1 つの選択肢は、シンプレックスとしての幾何学的視覚化です。$\mathbb{R}^n$、しかしこれは算術引数を単純化することなく抽象化を追加します。
