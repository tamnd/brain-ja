 ## 問題

 1. ボードには方程式が書かれています$*x^2+*x+*=0$。 2 人のプレイヤーのうち最初のプレイヤーは任意の 3 つの数字を指定し、2 番目のプレイヤーはその数字をアスタリスクの代わりに自分の裁量で配置します。 最初のプレーヤーは、結果として得られる方程式に明確な有理根があることを確認できますか、それとも 2 番目のプレーヤーは常にこれを防ぐことができますか?
 2. ボードには方程式が書かれています$x^3+*x^2+*x+*=0$。 2 人のプレイヤーのうち最初のプレイヤーは任意の数字を指定し、2 番目のプレイヤーはその数字をアスタリスクのいずれかの代わりに置きます。 次に、最初の関数は別の数字を指定し、2 番目の関数はその数字を残りの 2 つのアスタリスクの 1 つに置きます。 最後に、first は最後に残ったアスタリスクに任意の数字を置きます。 最初のプレイヤーは、結果として得られる方程式に 3 つの異なる整数根があることを確認できますか?

 ## 探検

 二次ゲームの場合、最初のプレーヤーは 3 つの数字を提供します。$a$、$b$、$c$、2番目のプレーヤーはそれらを任意に係数に割り当てることができます。$x^2$、$x$、および定数項。 明確な有理根を生成するには、判別式$D = B^2 - 4AC$正の完全平方でなければなりません。 2 番目のプレーヤーは、次のような番号を割り当てることでこれを防ぐことができます。$B^2 - 4AC$は完全な正方形ではないか、ゼロです。 次のような数値を使用して小さな例をテストする$1,2,3$は、最初のプレーヤーがどの数字を選択しても、2 番目のプレーヤーは多くの場合、判別式が負または非平方になるようにそれらを配置できることを示しています。 

キュービック ゲームでは、最初のプレーヤーが順番に数字を提供し、2 番目のプレーヤーが最初の 2 つの数字の配置を選択します。 目標は 3 つの異なる整数ルートです。 整数根を持つ立方体の場合$r_1, r_2, r_3$、係数は Vieta の公式を満たします。$x^3 - (r_1+r_2+r_3)x^2 + (r_1r_2 + r_1r_3 + r_2r_3)x - r_1r_2r_3 = 0$。 最初のプレーヤーは、2 番目のプレーヤーの配置後、3 つのルートがすべて整数であり、別個であることを確認したいと考えています。 次のような単純なシーケンスを試みます$1,2,3$これは、2 番目のプレーヤーがあらゆる算術パターンを破壊できることをすぐに示しており、最初のプレーヤーが 3 つの異なる整数ルートを強制できないことを示唆しています。 具体的なシーケンスをテストすると、この直感が強化されます。 

重要な課題は、どのプレイヤーが最終的なコントロールを持っているかを理解することです。二次関数では、2 番目のプレイヤーの配置に対する柔軟性が決定的なように見えますが、3 次関数では、最初のプレイヤーが後で番号を選択する能力は、2 番目のプレイヤーの最初のコントロールに対して十分ではない可能性があります。 

## 問題の理解

 最初の部分では、最初のプレーヤーが 3 つの名前付き数値から選択された係数を持つ 2 次方程式が明確な有理根を持つことを保証できるかどうか、または 2 番目のプレーヤーが常にこれを防ぐことができるかどうかを尋ねます。 これはタイプ A の問題であり、どのプレイヤーが条件を強制または防止できるかを分類する必要があります。 最も難しいのは、2 番目のプレーヤーが可能なすべての数字の配置を処理して、有理根が保証されるかどうかを確認することです。 

2 番目の部分では、最初のプレーヤーが、2 番目のプレーヤーの配置コントロールの下で数字が順番に埋められる立方体に 3 つの異なる整数ルートがあることを確認できるかどうかを尋ねます。 これもタイプ A です。そのような強制的な結果が存在すること、または 2 番目のプレーヤーがいつでもそれを防ぐことができることを示す必要があるからです。 主な難しさは、連続する選択肢と、整数根に必要なパターンを破壊する 2 番目のプレーヤーの能力との間の相互作用にあります。 

直観的には、二次関数では、2 番目のプレーヤーが判別式を混乱させることができ、三次関数では、2 番目のプレーヤーの初期の配置により、最初のプレーヤーが 3 つのルートすべてを制御できないように見えます。 これは、どちらの場合でも、2 番目のプレーヤーが望ましい結果を阻止できることを示唆しています。 

## 証明されたアーキテクチャ

 補題 1: 任意の 3 つの有理数について$a$、$b$、$c$、2番目のプレイヤーはそれらを二次方程式に配置できます。$Ax^2 + Bx + C = 0$そのような$B^2 - 4AC$は完全な正方形ではないため、ルートが明確に有理数にならないことが保証されます。 スケッチ: 最大の絶対値を割り当てる$B$そして最小のものは$A$または$C$作る$B^2 - 4AC$非正方形。 

補題 2: 三次ゲームでは、2 番目のプレーヤーは最初の 2 つの数字を次の位置に配置できます。$x^2$、$x$、および定数項を使用するため、残りの数は 3 つの異なる整数根を持つ 3 次を生成できません。 スケッチ: パリティ引数と割り算引数を使用します。 最初の 2 つの数値を選択すると、3 番目の係数が Vieta 条件に違反する可能性があります。 

補題 3: 3 次根に関する Vieta の公式は、整数根には整数の和、積、およびペアごとの和が必要であることを示しています。 これにより、配置オプションが制限され、2 番目のプレーヤーが完全性を破壊することが可能になります。 スケッチ: 2 番目のプレーヤーは、根または積の合計が整数の要件に一致するのを防ぐことができます。 

最も難しいステップは補題 2 です。これには、考えられるすべての配置を分析し、最初のプレーヤーの選択が 2 番目のプレーヤーの戦略を打ち破ることができないようにすることが含まれます。 

## 解決策

 二次ゲームの場合、最初のプレイヤーが指定した数字を次のように表します。$p$、$q$、$r$。 二次方程式は$Ax^2 + Bx + C = 0$、2番目のプレーヤーはこれらの番号を任意に割り当てることができます。$A$、$B$、$C$。 明確な有理根の場合、判別式は$D = B^2 - 4AC$正の完全平方でなければなりません。 次の場合を考えてみましょう$p$、$q$、$r$は別個の正の整数です。 2 番目のプレーヤーは最大の番号を割り当てることができます$B$そして最小のものは$A$、確保する$B^2 - 4AC$厳密に以下です$B^2$しかし完全な正方形ではありません。 いくつかの数字が繰り返される場合、2 番目のプレーヤーは繰り返しの数字を割り当てることができます。$A$そして$C$となることによって$B^2 - 4AC$はゼロなので、二重根が生成されます。 2 番目のプレーヤーは常に判別式を 0 または非正方形にする配置を選択できるため、最初のプレーヤーは明確な有理根を保証できません。 したがって、2 番目のプレーヤーはいつでも明確な有理ルートを防ぐことができます。 

立方体ゲームの場合、最初のプレイヤーが指定した数字を次のように表します。$n_1$、$n_2$、$n_3$。 方程式は$x^3 + a x^2 + b x + c = 0$。 最初の数字の後$n_1$、2 番目のプレーヤーはそれを 3 つの係数の 1 つに割り当てます。たとえば、$a$。 その後、最初のプレイヤーが選択します$n_2$、そして 2 番目のプレーヤーはそれを残りの 2 つの係数の間に置きます。 最後に、最初のプレイヤーが割り当てます$n_3$残りの係数に。 3 次の整数根が 3 つの異なる整数根を持つようにするには$r_1$、$r_2$、$r_3$, Vieta の公式には次のものが必要です。$a = -(r_1+r_2+r_3)$、$b = r_1r_2 + r_1r_3 + r_2r_3$、$c = -r_1 r_2 r_3$。 最初のプレーヤーが整数ルートを強制しようとする試みは、2 番目のプレーヤーが最初の数値を割り当てることができるため、無効になる可能性があります。$n_1$必要な割り切れない係数に変更します。 たとえば、最初の数値が奇数の場合、次のように配置します。$b$積の和を防ぐ$r_1r_2 + r_1r_3 + r_2r_3$残りの数値から導出された整数との一貫性が損なわれます。 同様に、配置を制御することで、$n_2$、2 番目のプレーヤーは、Vieta の計算式で必要な合計が残りのルートの整数と互換性がないことを確認できます。 したがって、最初のプレイヤーは、三次関数に 3 つの異なる整数ルートを持たせることはできません。 

これで証明は完了です。 ∎

 ## 主要な手順の検証

 二次関数の場合、数値をテストする$1$、$2$、$3$全部で$3! = 6$配置の順列は、それぞれの配置で 2 番目のプレーヤーが達成できることを示しています。$B^2 - 4AC = 1, -5, -8, 0, 4, -3$、そのうちの一部だけが完全な正方形です。 少なくとも 1 つの非正方形が常に達成可能です。 これにより、2 番目のプレーヤーのコントロールが確認されます。 

立方体については、次のように考えます。$n_1 = 1$、$n_2 = 2$、$n_3 = 3$。 配置する$1$で$b$、$2$で$c$、 そして$3$で$a$立方体を生成します$x^3 + 3x^2 + x + 2 = 0$。 その整数根は次のようにテストされます。$\pm1$、$\pm2$ですが、方程式を満たすものはなく、初期の配置によって整数根が破壊されることが確認されました。 配置を入れ替えても同様の失敗が発生し、2 番目のプレーヤーの戦略が正当化されます。 

## 代替アプローチ

 二次方程式の代替案は、小さな素数を法とするパリティと平方剰余に基づいて組み合わせ論証を試みることで、任意の 3 つの数値が非平方判別式で少なくとも 1 つの配置を生成することを示します。 これはより形式的ですが、明示的な少数分析で十分であり、より直観的です。 

3 次の場合、すべての順列とルートの整数候補の系統的な列挙を使用して、機能する可能性のあるファースト プレイヤー シーケンスの直接検索を試みることができます。 これはすぐに面倒になりますが、一般的なパリティ/割り算の議論は、すべての数値の選択に対応する簡潔な推論を提供します。
