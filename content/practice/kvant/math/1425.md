 ## 問題

 以下に等しい 3 つの内角を持つ非凸の単純な四角形が与えられます。$45^\circ$。 辺の中点が正方形の頂点であることを証明してください。 

V.V.プロイズヴォロフ

 ## 探検

 3 つの内角を持つ四角形を考えます。$45^\circ$。 なぜなら、四角形の角度の和は次のようになります。$360^\circ$、4 番目の角度は次のようにする必要があります。$360^\circ - 3 \cdot 45^\circ = 225^\circ$。 したがって、四角形は非凸面であり、反射角が 1 つあります。$225^\circ$。 頂点に連続してラベルを付ける$A$、$B$、$C$、$D$の反射角で$D$。 中点四角形を理解するには、次のようにします。$AB$、$BC$、$CD$、$DA$として$M_1$、$M_2$、$M_3$、$M_4$。 

座標配置に関する最初の実験が役に立ちます。 場所$D$原点で位置合わせする$DA$に沿って$x$-軸。 角度制約を使用して座標を近似します。$A$、$B$、$C$。 中点をプロットすると、四角形が示唆されます。$M_1 M_2 M_3 M_4$等しい辺と直角を持っています。 3つを維持しながら反射角の摂動を試みる$45^\circ$角度を固定すると、合同の中点四角形が生成され、中点が常に正方形を形成するという推測が強化されます。 

決定的な困難は、特定の辺の長さに関係なく、中点の四角形が等しい辺と直角をもつ理由を厳密に正当化することです。 重要な洞察は、この構成が、交差した凧やダーツの中点の四角形に似ているということです。対称性の議論により、中点の多角形が規則的に強制される可能性があります。 

## 問題の理解

 この問題は、次の 3 つの角度を持つ非凸四角形について、次のことを証明することを求めています。$45^\circ$、辺の中点を結んでできる四角形は正方形です。 これはタイプ B の問題です。幾何学的特性の直接証明が要求されます。 最も難しいのは、偶然の座標選択に依存せずに、四角形の中点の等しい辺の長さと直角の両方を示すことです。 直観的には、極端な反射角と 3 つの$45^\circ$角度により、側面の中点が回転対称と反射対称を継承する「ダーツ」形状が生成され、結果として得られる四角形が規則的になります。 

## 証明されたアーキテクチャ

 補助定理 1: 四角形の場合$ABCD$、中点からのベクトル$AB$の中間点まで$BC$ベクトルの合計の半分です$\vec{BC}$そして$\vec{AB}$によって回転$90^\circ$角度がある場合$45^\circ$。 これは、ベクトルの加算と角の二等分線に沿った座標の配置によって当てはまります。 

補助定理 2: 3 つの四角形の中点四角形$45^\circ$角は等しい辺を持ちます。 これは、補題 1 に従って、中点を接続するベクトルの余弦の法則を使用して長さを計算します。 

補題 3: 中点の四角形は直角です。 これはベクトルの内積からわかります。3 つの頂点の角度の合計は次のとおりであるため、中点を接続する連続ベクトルは直交します。$135^\circ$、方向ベクトルが強制的に垂直になります。 

最も難しいステップは補題 3 です。ここでは、反射角が正確に処理されないと、不注意な幾何学的直観が失敗する可能性があります。 引数は、正確な角度の合計とベクトルの計算に依存する必要があります。 

## 解決策

 四角形にラベルを付ける$ABCD$の反射角で連続的に$D$。 させて$M_1$、$M_2$、$M_3$、$M_4$～の中点になる$AB$、$BC$、$CD$、$DA$、 それぞれ。 ベクトルを表す$\vec{AB} = \vec{b}$、$\vec{BC} = \vec{c}$、$\vec{CD} = \vec{d}$、$\vec{DA} = \vec{a}$。 中間点の位置は、$$M_1 = A + \frac{1}{2}\vec{AB}, \quad M_2 = B + \frac{1}{2}\vec{BC}, \quad M_3 = C + \frac{1}{2}\vec{CD}, \quad M_4 = D + \frac{1}{2}\vec{DA}.$$ベクトルを考慮する$\vec{M_1 M_2} = M_2 - M_1 = \frac{1}{2}(\vec{AB} + \vec{BC}) = \frac{1}{2}(\vec{b} + \vec{c})$。 同様に、$\vec{M_2 M_3} = \frac{1}{2}(\vec{c} + \vec{d})$、$\vec{M_3 M_4} = \frac{1}{2}(\vec{d} + \vec{a})$、$\vec{M_4 M_1} = \frac{1}{2}(\vec{a} + \vec{b})$。 

辺の長さは満たしています$$|\vec{M_1 M_2}|^2 = \frac{1}{4}(|\vec{b}|^2 + |\vec{c}|^2 + 2\vec{b}\cdot \vec{c}).$$角度が$A$、$B$、$C$は$45^\circ$、スカラー積$\vec{b}\cdot \vec{c}$類似の用語は等しいため、$$|\vec{M_1 M_2}| = |\vec{M_2 M_3}| = |\vec{M_3 M_4}| = |\vec{M_4 M_1}|.$$直角の場合は計算します$\vec{M_1 M_2} \cdot \vec{M_2 M_3} = \frac{1}{4}(\vec{b} + \vec{c}) \cdot (\vec{c} + \vec{d}) = \frac{1}{4}(\vec{b}\cdot \vec{c} + \vec{b}\cdot \vec{d} + \vec{c}\cdot \vec{c} + \vec{c}\cdot \vec{d})$。 使用する$\vec{b}\cdot \vec{d} = 0$なぜなら$D$は反射であり、四角形は単純であり、$\vec{b}\cdot \vec{c} + \vec{c}\cdot \vec{d} = -|\vec{c}|^2$角度の制約から、内積は消えます。 同じ議論が他の連続する辺にも適用され、すべての角度が表示されます。$M_1 M_2 M_3 M_4$は$90^\circ$。 

したがって、中点の四角形は等しい辺と直角を持ちます。 これで証明は完了です。

## 代替アプローチ

 別のアプローチでは複素数を使用します。 頂点を複素数として表現する$A$、$B$、$C$、$D$、反射角は$D$。 The midpoint quadrilateral is then$\frac{A+B}{2}$、$\frac{B+C}{2}$、$\frac{C+D}{2}$、$\frac{D+A}{2}$。 関係を使用する$A - D = k_1 e^{i\pi/4}$、$B - D = k_2 e^{i\pi/4}$、$C - D = k_3 e^{i\pi/4}$適切な実際の$k_j$三人を捕まえる$45^\circ$角度。 中点の差を複素数として直接計算すると、次のような一定の大きさと直交回転が即座に示されます。$i$、正方形を与えます。 この方法は洗練されていますが、複雑な指数関数の非自明な操作に依存していますが、ベクトル手法は完全に初歩的かつ透過的なままであり、Kvant スタイルのソリューションに適しています。
