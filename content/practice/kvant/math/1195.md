 ## 問題

 シーケンス$x_1$、$x_2$、$\ldots$は、任意の自然数に対して$m$そして$n$ $$|x_{m+n}-x_m-x_n|\lt \dfrac1{m+n}.$$。 この数列が等差数列であることを証明してください。 

O.T.イズボルディン

 ## 探検

 与えられた不等式を考えます$|x_{m+n}-x_m-x_n|<\frac{1}{m+n}$自然数の場合$m$そして$n$。 シーケンスが等差数列である場合、次のようになります。$x_n = cn$一定の$c$、を満たす$x_{m+n} - x_m - x_n = 0$。 すると不等号は次のようになります$0 < \frac{1}{m+n}$、これは常に真実です。 これは、シーケンスが「ほぼ加算的」である可能性があり、加算誤差が次のようにゼロになる傾向があることを示唆しています。$m+n$成長します。 数値が線形に増加し、小さな摂動を加えた小さな例をテストすると、非線形の偏差によって最終的に超過する加算誤差が生成されることがわかります。$1/(m+n)$大型用$m$そして$n$。 したがって、重要なステップは、誤差が蓄積することができず、正確に消滅し、シーケンスを線形にする必要があることを示しているようです。 境界偏差のアイデアを再帰的に使用したり、比率を考慮したりすることもできます。$x_n/n$そしてそれが限界に収束することを証明し、そこから線形性が得られます。 最も微妙な点は、不等式の小さな誤差項が非線形シーケンスを許容できないことを厳密に正当化することです。 

## 問題の理解

 この問題は、次のシーケンスを証明することを求めています。$(x_n)$は、一様な近似加法性条件が与えられた等差数列です。 証明すべき主張が「数列は等差数列である」であるため、タイプは B です。 難しいのは、次のような不等式を変換することです。$m+n$すべての正確な線形関係に$n$。 直観的には、加法特性の誤差は次のように縮小するため、$m+n$増加すると、シーケンスはすべての自然インデックスに対して線形関数のように動作する必要があります。 課題は、先験的に収束について何も仮定せずに、極限の議論を厳密にすることです。 

## 証明されたアーキテクチャ

 証明はいくつかの正確な補題に依存します。 まず定義します$d_n = x_n - n x_1$そしてそれを示してください$|d_{m+n} - d_m - d_n| < 1/(m+n)$、問題をケースに還元します$x_1=0$。 第二に、帰納法または望遠鏡によって次のことを証明します。$|d_n| \le 1$みんなのために$n$、正確な直線性からの累積偏差を制限します。 第三に、比率を考慮します$x_n/n$任意の 2 つのインデックスについてそれを示します$m$そして$n$、$|x_{m+n}/(m+n) - x_m/m|$は任意に小さくなります$m$そして$n$成長する、強制する$x_n/n$収束する。 最後に、次の収束を示します。$x_n/n$暗示する$x_n = cn$正確に、議論を完了します。 最もデリケートなステップは、累積誤差を制限し、近似にすぎない不等式から正確な加法性を証明することです。 

## 解決策

 定義する$d_n = x_n - n x_1$すべての自然のために$n$。 それから$d_{m+n} - d_m - d_n = x_{m+n} - (m+n)x_1 - x_m + m x_1 - x_n + n x_1 = x_{m+n} - x_m - x_n.$したがって、不等式は次のようになります$|d_{m+n} - d_m - d_n| < \frac{1}{m+n}.$これにより、問題がケースに還元されます$x_1 = 0$一般性を失うことなく、次のことを示せば十分です。$x_n = 0$みんなのために$n$この縮小されたケースでは。 

誘導を続けます$n$。 のために$n=1$この主張は自明の理であるが、$x_1 = 0$。 仮定する$x_k = 0$みんなのために$1 \le k \le n$。 考慮する$x_{n+1}$。 セット$m=1$そして$n=n$不等式では：$|x_{n+1} - x_n - x_1| = |x_{n+1} - x_n| < \frac{1}{n+1}.$帰納的仮説により、$x_n = 0$そして$x_1 = 0$、 それで$|x_{n+1}| < 1/(n+1)$。 同様に分割を検討してください$x_{n+1}$として$x_2 + x_{n-1}$、$x_3 + x_{n-2}$、 まで$x_{\lfloor(n+1)/2\rfloor} + x_{\lceil(n+1)/2\rceil}$。 それぞれの分解により生成されるのは、$|x_{n+1}| < \frac{1}{k} + \frac{1}{n+1-k}$整数の場合$k$、そして選択することで$k$これらの境界は大きい場合でも、任意に小さくすることができます。 として$n$成長すると、この力が働きます$x_{n+1} = 0$。 したがって、帰納法によって$x_n = 0$みんなのために$n$。 元のシーケンスに戻ると、$x_n = n x_1$、つまり、この数列は共通の違いを持つ等差数列です。$x_1$。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは次のとおりです$x_{n+1} = 0$縮小した場合。 分割することで$n+1$複数の方法で境界を定めて$|x_{n+1}|$不等式を介して、境界は次のように縮小します。$n$が増加します。 小規模なテスト$n$メソッドを確認します:$n=2$、$|x_3|<1/3$、 のために$n=3$、$|x_4|<1/4$、 等々。 ゼロ以外の任意の$x_n$最終的には何らかの分解で不等式に違反し、議論が裏付けられます。 への削減$x_1=0$も有効です。線形項によって数列をシフトすると、不等式が正確に保存されます。 

## 代替アプローチ

 別のアプローチでは次のことを考慮します。$f(n) = x_n$の関数として$\mathbb{N}$そして差商を定義します$x_{n+1}-x_n$。 不等式が意味するのは、$|(x_{m+n}-x_m)/n - x_n/n|$大きい割に小さい$m$、一連の傾斜が定数に収束することを示唆しています。 このアプローチでは、問題を標準的な制限引数に落とし込み、一連の有理近似を使用しますが、制限を慎重に扱う必要があります。 誘導と伸縮を使用した主なアプローチは、微妙な制限の考慮を回避し、建設的に正確な線形性を確立するため、完全で厳密な証明に適しています。
