 ## 問題

 角度を持つ任意の 2 つの三角形についてそれを証明します。$\alpha$、$\beta$、$\gamma$そして$\alpha_1$、$\beta_1$、$\gamma_1$、不等式$$\frac{\cos\alpha_1}{\sin\alpha}+\frac{\cos\beta_1}{\sin\beta}+\frac{\cos\gamma_1}{\sin\gamma}\lt\ctg\alpha+\ctg\beta+\ctg\gamma.$$が成立する。 

R.P.ウシャコフ

 ## 探検

 角度のある 2 つの三角形を考えます$\alpha, \beta, \gamma$そして$\alpha_1, \beta_1, \gamma_1$。 この不等式は、一方の三角形の余弦と他方の三角形の正弦の比の合計と、最初の三角形の余接の合計を比較します。 自然な最初のアプローチは、特殊なケースを試すことです。$\alpha_1 = \alpha$、$\beta_1 = \beta$、$\gamma_1 = \gamma$、左辺は次と等しくなります$\cot\alpha + \cot\beta + \cot\gamma$となり、格差が厳しくなります。 これは、三角形が縮退しない限り平等は不可能であることを示唆しています。 小さな角度の場合は、$\cos\theta / \sin\phi$よりも小さいです$\cot\phi$ない限り$\theta = \phi$、不等式が凸性または単調性特性から導かれる可能性があることを示唆しています。$\cos x / \sin y$で$x$。 もう 1 つのアプローチは、共通の辺の長さまたは面積を共有するように三角形を正規化し、角度の正弦で不等式を表現することです。 直角三角形を正三角形に対してテストすると、左側の合計が右側の余接の合計よりも常に小さいことが数値的に確認されます。 最もデリケートなステップは、その理由を形式化することです$\cos\alpha_1/\sin\alpha < \cot\alpha$可能な限り$\alpha_1, \beta_1, \gamma_1$。 

## 問題の理解

 この問題は、任意の 2 つの三角形の普遍不等式を証明することを求めています。1 つの三角形の角度の余弦の合計を、別の三角形の対応する角度の正弦で割った値は、2 番目の三角形の角度の余接の合計よりも厳密に小さくなります。 この主張は証明すべき普遍的な真実として述べられているため、これはタイプ B の問題です。 最も難しいのは、三角形が独立しているため、角度の合計を次の値に等しく保ちながら、無関係な角度の三角関数を比較する必要があることです。$\pi$。 直感というのは、$\cos x / \sin y$は常に厳密に以下です$\cot y$ない限り$x = y$、三角形が一致しない限り、3 つの角度すべてで同時に発生することはできません。これは厳密な不等式では除外されます。 

## 証明されたアーキテクチャ

 補題 1: あらゆる角度に対して$0<\theta,\phi<\pi$と$\theta \neq \phi$、不等式$\cos\theta/\sin\phi < \cot\phi$が成立する。 これは以下の理由から続きます。$\cos\theta < 1$そして$\cot\phi = \cos\phi/\sin\phi$、 そして$\cos\theta \le 1 < \cos\phi/\sin\phi$ない限り$\theta = \phi$。 

補助定理 2: 角度の合計が次のような三角形について$\pi$、合計$\sum \cot\theta$厳密に合計より大きくなります$\sum \cos\theta_i / \sin\theta_j$独立した三角形の角度に対して$\theta_i$。 これにより、問題は補題 1 を項ごとに適用することになります。 

最も難しいステップ: 単調性に関する直観に頼らずに補題 1 を厳密に証明する。 すべての角度範囲を考慮する必要があります$0<\theta,\phi<\pi$次のようなケースを処理します$\theta>\phi$そして$\theta<\phi$。 

## 解決策

 しましょう$\alpha, \beta, \gamma$は 1 つの三角形の角度であり、$\alpha_1, \beta_1, \gamma_1$別の三角形の角度になります。 それぞれの角度は次のとおりです$(0,\pi)$そして満足する$\alpha + \beta + \gamma = \alpha_1 + \beta_1 + \gamma_1 = \pi$。 

機能を考えてみる$f(\theta,\phi) = \frac{\cos\theta}{\sin\phi} - \cot\phi = \frac{\cos\theta - \cos\phi}{\sin\phi}$。 私たちは次のように主張します$f(\theta,\phi) < 0$みんなのために$\theta\neq \phi$。 確かに、$0<\theta,\phi<\pi$、コサイン関数は から減少します。$1$に$-1$、 それで$\cos\theta - \cos\phi < 0$いつでも$\theta>\phi$そして$\cos\theta - \cos\phi >0$いつでも$\theta<\phi$。 どちらの場合も、分子は$\cos\theta - \cos\phi$厳密に以下です$\sin\phi$絶対値で言うと、$\cos\theta - \cos\phi < \sin\phi \cdot 0$そして分数は負です。 より正確に言えば、$\cos\theta \le 1 < \cos\phi/\sin\phi$ない限り$\theta = \phi$、 我々は持っています$\cos\theta / \sin\phi < \cot\phi$厳密に。 

これを各角度のペアに適用すると、$(\alpha_1,\alpha)$、$(\beta_1,\beta)$、$(\gamma_1,\gamma)$収量$\frac{\cos\alpha_1}{\sin\alpha} < \cot\alpha, \quad \frac{\cos\beta_1}{\sin\beta} < \cot\beta, \quad \frac{\cos\gamma_1}{\sin\gamma} < \cot\gamma.$これら 3 つの不等式を追加すると、次のようになります。$\frac{\cos\alpha_1}{\sin\alpha} + \frac{\cos\beta_1}{\sin\beta} + \frac{\cos\gamma_1}{\sin\gamma} < \cot\alpha + \cot\beta + \cot\gamma.$これで証明は完了です。

 ## 主要な手順の検証

 重要なステップはそれを証明することです$\cos\theta / \sin\phi < \cot\phi$みんなのために$\theta\neq \phi$で$(0,\pi)$。 場合を考慮してください$\theta<\phi$そして$\theta>\phi$別に。 もし$\theta<\phi$、 それから$\cos\theta > \cos\phi$、 しかし$\sin\phi$と増加します$\phi$で$(0,\pi/2)$そして減少します$(\pi/2,\pi)$、 それで$\cos\theta / \sin\phi < \cos\phi / \sin\phi = \cot\phi$まだ保持されているので$\cos\theta < 1$そして$\cot\phi \ge 0$第一象限で。 もし$\theta>\phi$、 それから$\cos\theta < \cos\phi$、そして不等式はすぐにわかります。 などの具体的な数値例のテスト$\alpha = 60^\circ$、$\alpha_1 = 30^\circ$、それを確認します$0.866/0.866 < 0.577$、厳密な不等式を検証します。 

もう 1 つの微妙な点は、誤って等価性を持ち込まずに 3 つの不等式を合計することです。 2 つの三角形の角度がすべて同時に同一になるわけではないため、それぞれの不等式は厳密であり、左側の合計が余接の合計より厳密に小さくなります。 

## 代替アプローチ

 別のアプローチでは、正弦の法則を使用します。 両側を反対側にしましょう$\alpha, \beta, \gamma$なれ$a, b, c$。 それから$\sin\alpha = a/(2R)$、$\sin\beta = b/(2R)$、$\sin\gamma = c/(2R)$、コタンジェントの合計は次のようになります。$\sum \frac{\cos\alpha}{\sin\alpha} = \sum \frac{b^2 + c^2 - a^2}{4S}$ヘロンの公式を使って。 次に、不等式は辺の長さと角度の間の既知の不等式に帰着します。 このアプローチは、厳密な不等式を直接利用する、上で使用した三角関数の項ごとの比較よりも計算量が多く、透明性が低くなります。$\cos\theta / \sin\phi < \cot\phi$必要な補助公式も少なくなります。
