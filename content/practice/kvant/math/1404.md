 ## 問題

 3 つの数字$x$、$y$、$z$条件を満たす$x+y+z=0$、$xyz=2$。 の最大値を求めます$\dfrac{x^2}{y}+\dfrac{y^2}{z}+\dfrac{z^2}{x}$。 

S.ドイチェフ、R.コザレフ

 ## 探検

 表現力を最大限に高めることが求められます$S = \frac{x^2}{y} + \frac{y^2}{z} + \frac{z^2}{x}$制約の下で$x+y+z=0$そして$xyz=2$。 最初のステップは、対称性を考慮することです。 この制約は、根を持つ立方体に対するビエテの公式に似た関係を示唆しています。$x$、$y$、$z$。 最初の制約を次のように書き換えます$z = -x-y$式を 2 つの変数に記述することができます。$S = \frac{x^2}{y} + \frac{y^2}{-(x+y)} + \frac{(-x-y)^2}{x}.$簡素化すると、$S = \frac{x^2}{y} - \frac{y^2}{x+y} + \frac{(x+y)^2}{x} = \frac{x^2}{y} + \frac{(x+y)^2}{x} - \frac{y^2}{x+y}.$小さな整数のテストは不可能に思えます。$xyz = 2$は整数立方体ではないため、合理的な例の方が有望です。 対称パターンを試みることができます: おそらく$x = y \neq z$または$x = -y$、などの設定$x=y$与える$z=-2x$そして$x^2 y = x^2 x = x^3$;$xyz= x^2(-2x) = -2x^3=2$、与える$x^3=-1$、 それで$x=-1$、$y=-1$、$z=2$。 農産物の代替$S = \frac{(-1)^2}{-1} + \frac{(-1)^2}{2} + \frac{2^2}{-1} = -1 + \frac{1}{2} - 4 = -\frac{9}{2}.$これは否定的です。 多分$x = -y$与える$z=0$、不可能なので$xyz=0\neq 2$。 もう 1 つの自然な推測は、2 つの等しい正の数と 1 つの負の数を試してみることです。$x=y=a$、$z=-2a$; 私たちは得ます$xyz=-2a^3$、次の場合は 2 に等しくなります。$a=-1$、上記の通り。 もう一方の対称性$x=z$与える$y=-2x$、 それから$xyz=-2x^3=2$、上記と同じ。 したがって、最大値は正である可能性が高く、3 つの数値がすべて異なる場合に極値が発生することを示唆しています。 

ラグランジュ乗数アプローチを試みることもできます。 考慮する$S$の関数として$x$、$y$、$z$制約付き$x+y+z=0$そして$xyz=2$。 これにより、3 つの変数における 3 つの有理方程式の系が得られます。 より対称的なアイデアは、置換を試みることです。$z=-x-y$そして定義します$S$に関しては$x$そして$y$のみ：$S(x,y) = \frac{x^2}{y} + \frac{y^2}{-x-y} + \frac{(x+y)^2}{x}.$これはまだ合理的ですが、次のように単純化できます。$S(x,y) = \frac{x^3 - y^3 + (x+y)^3}{xy(x+y)} = \frac{x^3 + 3x^2y + 3xy^2 + y^3 - y^3 + (x+y)^3?}{xy(x+y)},$これには注意深い代数が必要です。 次のような対称パターンのテスト$x=2$、$y=-1$、$z=-1$与える$xyz=2$そして$x+y+z=0$。 それから$S = 4/(-1) + 1/(-1) + 1/2 = -4 -1 + 1/2 = -9/2$以前のように。 

試しています$x=1$、$y=-2$、$z=1$、$xyz= -2\neq 2$;$x=2$、$y=1$、$z=-3$、$xyz=-6\neq 2$。 もっと有望なパターンは、$x=y$、$z$負の分数。 それから$x^2 z = 2 \implies z = 2/x^2$、$x+y+z = 2x + 2/x^2=0 \implies x^3 = -1$、前の例を挙げます。 

したがって、前の負の解は、数値が繰り返される唯一の解です。 おそらく最大値は、数値が個別であり、作成するのに非常に小さい場合に発生します。$S$大きい。 たとえば、$x>0$、$y>0$、$z<0$、 それから$\frac{z^2}{x} >0$、$\frac{y^2}{z}<0$、$\frac{x^2}{y}>0$。 それから$S$プラスになる可能性があり、おそらく大きくなる可能性があります。 

最大値の有力な候補は次のような場合です。$y=z$、$x$ネガティブ。 させて$y=z=t>0$、$x= -2t$、 それから$xyz = -2 t^3 = 2$、$t^3 = -1$、$t=-1$、$x=2$。 それから$S = x^2 / y + y^2 / z + z^2 / x = 4/(-1) +1/1 +1/2 = -4 +1 +0.5=-2.5$、まだマイナスです。 

有理分数のテスト、$x= -1$、$y=2$、$z=-1$、合計$0$、 製品$2$、$S = 1/2 + 4/(-1) +1/(-1) = 0.5 -4 -1=-4.5$。 まだネガティブです。 おそらく最大値は正であり、1 つの数値がゼロに近づくと発生します。 させて$x\to 0^+$、$y\to +\infty$、$z\to -y$、$xyz \to -0 \cdot y \cdot (-y) =0$したがって、最大値は有限であり、2 つの数値が等しい場合に発生する可能性があります。
