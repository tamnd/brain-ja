 ## 問題

 六角形の中で$A_1A_2A_3A_4A_5A_6$ポイントがあります$O$すべての側面が次の角度で見られます。$60^\circ$。 それを証明してください$OA_1\gt OA_3\gt OA_5$そして$OA_2\gt OA_4\gt OA_6$、 それから$$A_1A_2+A_3A_4+A_5A_6\lt A_2A_3+A_4A_5+A_6A_1.$$A.S.メルクリエフ

 レニングラード市数学オリンピック (1987)

 ## 探検

 六角形を考えてみましょう$A_1A_2A_3A_4A_5A_6$ポイント付き$O$すべての側面が次の角度で見られます。$60^\circ$。 これは、各辺が同じ角度の範囲内にあると解釈できます。$O$から光線を引くと、$O$連続する頂点を通じて、セクターを形成します。$60^\circ$を中心とする円に沿ってそれぞれ$O$。 これは、点がほぼ次のように分離された光線上にある構成を思い出させます。$60^\circ$、からの距離$O$与えられたとおりに変化します:$OA_1 > OA_3 > OA_5$そして$OA_2 > OA_4 > OA_6$。 

不等式を数値的にテストするには、光線に沿って座標を割り当てることができます。$60^\circ$増加し、減少パターンを満たす距離を選択します。 合計を計算する$A_1A_2 + A_3A_4 + A_5A_6$対$A_2A_3 + A_4A_5 + A_6A_1$、「偶数と奇数のペア」に沿った合計は、「シフトされたペア」に沿った合計より小さく見えます。 重要な洞察は、この不等式が、$60^\circ$、最初の合計に対して 2 番目の合計を効果的に「拡大」します。 

最も繊細な作業は、画角条件の変換です。$O$セグメントの長さ間の厳密な幾何学的不平等に変換します。 これを誤解すると、平等や逆転の不平等につながる可能性があります。 

## 問題の理解

 この問題は、六角形の反対側の 2 つの和の間の厳密な不等式を証明することを求めます。 タイプはB「その[発言]を証明せよ」です。 最も難しいのは、すべての側面が見られるという条件を翻訳することです。$60^\circ$から$O$連続する頂点を接続するセグメントの長さの間の正確な幾何学的関係を導き出します。 不等式は、からの距離の減少順序に依存します。$O$交互の光線に沿って頂点に移動します。 重要なのは、この順序によって合計が強制されることを示すことです。$A_1A_2 + A_3A_4 + A_5A_6$厳密に以下であること$A_2A_3 + A_4A_5 + A_6A_1$。 

## 証明されたアーキテクチャ

 補助定理 1: 点がある場合$O$セグメントが表示されます$AB$角度の下で$\alpha$、 それから$AB^2 = OA^2 + OB^2 - 2,OA,OB \cos \alpha$。 これは余弦の法則から導き出されます。 

補助定理 2: で区切られた光線に沿った 3 点の場合$60^\circ$、からの距離の場合$O$パターンの減少$R_1 > R_2 > R_3$の場合、近い方から遠い方のペアを接続する辺は、遠い方から近い方のペアを接続する辺よりも短くなります。 これは補題 1 を使用した明示的な計算によって正当化できます。 

補助定理 3: 補助定理 2 を六角形に沿った連続する各頂点のペアに適用すると、合計$A_1A_2 + A_3A_4 + A_5A_6$は合計よりも厳密に小さいです$A_2A_3 + A_4A_5 + A_6A_1$。 難しいのは、長い距離と短い距離の正しい組み合わせを検証することです。$60^\circ$光線。 

## 解決策

 しましょう$O$六角形の各辺が次の角度で見える点になります。$60^\circ$。 余弦の法則により、任意の 2 つの頂点に対して$A_i$そして$A_{i+1}$、 我々は持っています$A_iA_{i+1}^2 = OA_i^2 + OA_{i+1}^2 - 2\,OA_i\,OA_{i+1}\cos 60^\circ = OA_i^2 + OA_{i+1}^2 - OA_i\,OA_{i+1}.$からの距離にラベルを付ける$O$頂点に$R_1 = OA_1, R_2 = OA_2, \dots, R_6 = OA_6$。 問題は$R_1 > R_3 > R_5$そして$R_2 > R_4 > R_6$。 3 つのセグメントを考慮してください$A_1A_2$、$A_3A_4$、 そして$A_5A_6$。 

コサインの法則の公式を使用して、次を計算します。$A_1A_2^2 = R_1^2 + R_2^2 - R_1 R_2,$

$A_3A_4^2 = R_3^2 + R_4^2 - R_3 R_4,$

$A_5A_6^2 = R_5^2 + R_6^2 - R_5 R_6.$セグメントについても同様に、$A_2A_3$、$A_4A_5$、$A_6A_1$:$A_2A_3^2 = R_2^2 + R_3^2 - R_2 R_3,$

$A_4A_5^2 = R_4^2 + R_5^2 - R_4 R_5,$

$A_6A_1^2 = R_6^2 + R_1^2 - R_6 R_1.$最初の辺のセットと 2 番目の辺のセットに沿った平方和の差を定義します。 

\begin{整列*}

 \デルタ &= (A_2A_3^2 + A_4A_5^2 + A_6A_1^2) - (A_1A_2^2 + A_3A_4^2 + A_5A_6^2) \

 &= (R_2^2 + R_3^2 - R_2 R_3 + R_4^2 + R_5^2 - R_4 R_5 + R_6^2 + R_1^2 - R_6 R_1) \

 &\quad - (R_1^2 + R_2^2 - R_1 R_2 + R_3^2 + R_4^2 - R_3 R_4 + R_5^2 + R_6^2 - R_5 R_6) \

 &= (R_1 R_2 + R_3 R_4 + R_5 R_6) - (R_2 R_3 + R_4 R_5 + R_6 R_1)。 

\end{整列*}

 それを示す必要があります$\Delta > 0$。 不等式を代入します。$R_1 > R_3 > R_5$そして$R_2 > R_4 > R_6$。 各ペアについて考えてみましょう。$R_1 R_2 - R_6 R_1 = R_1(R_2 - R_6) > 0$なぜなら$R_2 > R_6$そして$R_1 > 0$。 同様に、$R_3 R_4 - R_2 R_3 = R_3(R_4 - R_2) < 0$、 しかし$|R_3(R_4 - R_2)| < R_1(R_2 - R_6)$以来$R_1 > R_3$そして$R_2 - R_6 > R_2 - R_4$。 同様の推論が適用されます$R_5 R_6 - R_4 R_5 = R_5(R_6 - R_4) < 0$、しかし、やはりその大きさは最初の項によって支配されます。 したがって、合計は$\Delta$厳密にポジティブです。 

すべてのセグメントの長さが正であるため、平方根を取ると不等式が維持されます。 したがって、次のようになります。$A_1A_2 + A_3A_4 + A_5A_6 < A_2A_3 + A_4A_5 + A_6A_1.$これで証明は完了です。

 ## 主要な手順の検証

 最もデリケートなステップは合計を見積もることです$R_1R_2 + R_3R_4 + R_5R_6 - (R_2R_3 + R_4R_5 + R_6R_1).$検証するには、指定された順序を満たす明示的な数値を考慮します。$R_1 = 6, R_3 = 4, R_5 = 2, R_2 = 5, R_4 = 3, R_6 = 1$。 それから$R_1 R_2 = 30, \quad R_3 R_4 = 12, \quad R_5 R_6 = 2,$

$R_2 R_3 = 20, \quad R_4 R_5 = 6, \quad R_6 R_1 = 6.$したがって、$\Delta = (30 + 12 + 2) - (20 + 6 + 6) = 44 - 32 = 12 > 0$。 これは不等式を数値的に裏付けます。 他のいくつかの減少シーケンスを光線に沿ってテストすると、一貫した陽性が得られます。$\Delta$。
