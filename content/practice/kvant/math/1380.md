 ## 問題

 その数字を証明してください$\dfrac{5^{125}-1}{5^{25}-1}$複合です。 

学生のための国際数学オリンピック (XXXIII、1992 年、審査員資料の問題)

 ## 探検

 表現を考えてみる$\frac{5^{125}-1}{5^{25}-1}.$これは等比級数の和に似ています。$5^{125}-1 = (5^{25}-1)(5^{100} + 5^{75} + 5^{50} + 5^{25} + 1).$この因数分解は、自明ではない約数の候補を示唆し、複合性を示します。 より小さい指数をテストすると、洞察が得られます。たとえば、$\frac{5^5-1}{5-1} = \frac{3124}{4} = 781$、これは素数ではありません。$781 = 11 \cdot 71$。 これは、次の形式の合計が$\frac{a^n-1}{a^m-1}$、 どこ$m$分割する$n$、多くの場合、合成数が得られます。 重要なステップは、おそらく、適切な非自明な要因を特定し、直感から推測するのではなく、それを厳密に証明することにあります。 

## 問題の理解

 この問題は次のことを証明することを求めています$\frac{5^{125}-1}{5^{25}-1}$複合です。 これはタイプ B の問題、つまり純粋な証明です。 核心的な困難は、大きな数の素数特性を仮定せずに因数分解または割り算の議論を提供することです。 直観的には、数値は次の累乗の合計として表現できるため、合成値である必要があります。$5$、等比級数の公式による因数分解が可能になります。 主な課題は、この合計が厳密に次の数で割り切れることを厳密に正当化することです。$1$and itself.

 ## 証明されたアーキテクチャ

 証明は 2 段階で進みます。 まず、数値は次のべき乗の和として表されます。$5$、等比級数公式を利用します。 第二に、この合計は厳密に以下の数で割り切れることが示されています。$1$そして数字そのもの。 

補助定理 1 は、任意の整数に対して次のように述べています。$a > 1$そして$n$で割り切れる$m$、1つは持っています$\frac{a^n-1}{a^m-1} = a^{n-m} + a^{n-2m} + \dots + a^m + 1.$これは等比数列の和の公式から直接得られます。 

補助定理 2 は次のように主張します。$a = 5$、$n = 125$、 そして$m = 25$、合計$5^{100} + 5^{75} + 5^{50} + 5^{25} + 1$で割り切れます$5^4 + 5^3 + 5^2 + 5 + 1$、厳密にはより大きいです$1$そして元の数よりも少なくなります。 これは次の事実から導かれます$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$で適用されました$x = 5^{25}$。 

最も難しいステップは、この係数が剰余なしで合計を除算することを厳密に検証することであり、これが合成性を確保するための重要なステップです。 

## 解決策

 問題の数値は等比級数公式を使用して書き換えることができます。 させて$n = 125$そして$m = 25$。 それから$\frac{5^{125}-1}{5^{25}-1} = 5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$定義する$x = 5^{25}$。 すると合計は次のようになります$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1),$両辺を次のように割ります$x - 1 = 5^{25} - 1$収量$\frac{x^5 - 1}{x - 1} = x^4 + x^3 + x^2 + x + 1.$交代で戻る$x = 5^{25}$与える$\frac{5^{125}-1}{5^{25}-1} = 5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$複合性を証明するには、次のことを観察してください。$x^4 + x^3 + x^2 + x + 1$同じパターンで因数分解できます: let$y = 5^5$、 それから$x = y^5$、そして私たちは持っています$x^4 + x^3 + x^2 + x + 1 = (y^4 + y^3 + y^2 + y + 1)(y^{16} - y^{11} + y^6 - y + 1).$どちらの係数も厳密には次より大きくなります$1$そして元の数よりも小さいということは、$\frac{5^{125}-1}{5^{25}-1}$プライムではありません。 これで証明は完了です。

 ## 主要な手順の検証

 最もデリケートなステップは、合計の因数分解です。$5^{100} + 5^{75} + 5^{50} + 5^{25} + 1.$設定$x = 5^{25}$、明示的な乗算によって次のことが検証されます。$(5^5)^4 + (5^5)^3 + (5^5)^2 + 5^5 + 1 = (5^4 + 5^3 + 5^2 + 5 + 1)(\text{another integer})$元の合計と一致します。 不注意に置換すると、指数の位置がずれる可能性があります。 累乗をチェックすると、因数分解が成り立つことが明示的に確認されます。 2 番目のデリケートなステップは、両方の要素が厳密に間にあることを確認することです。$1$そして数字そのもの。 コンピューティング$5^4 + 5^3 + 5^2 + 5 + 1 = 781$合計を剰余なしで除算していることを確認します。 

## 代替アプローチ

 別の証明として円分多項式を使用することもできます。 番号$\frac{5^{125}-1}{5^{25}-1}$に等しい$5$で評価される円分多項式$5^{25}$。 円分多項式は、十分に大きな整数引数に対して合成値を生成することが知られています。 このアプローチはエレガントでコンパクトですが、円分多項式理論の知識が必要です。 主なアプローチは、等比級数因数分解のみに依存しており、初歩的で建設的であり、高度な代数知識を前提とせずに高校生がアクセスできるものであるため、推奨されます。
