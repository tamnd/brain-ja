 ## 問題

 それを証明してください

 1. 任意の正の数の場合$a$、$b$、 そして$c$、不等式$$\sqrt{a^2-ab+b^2}+\sqrt{b^2-bc+c^2}\ge\sqrt{a^2+ac+c^2};$$保持します。 
2. パート (a) の不等式は、次の場合にのみ等式になります。$\dfrac1a+\dfrac1c=\dfrac1b$。 

ゆう。 V. デイカロ

 ## 探検

 小さな値をテストすることは、不等式についての直感を構築するのに役立ちます。 させて$a=b=c=1$。 すると左側は次のようになります$\sqrt{1-1+1}+\sqrt{1-1+1}= \sqrt{1}+\sqrt{1}=2$、右辺は$\sqrt{1+1+1}=\sqrt{3} \approx 1.732$, したがって、この場合には不等式が成り立ちます。 試しています$a=1$、$b=2$、$c=3$与える$\sqrt{1-2+4}+\sqrt{4-6+9} = \sqrt{3} + \sqrt{7} \approx 1.732+2.646 = 4.378$、右辺は$\sqrt{1+3+9} = \sqrt{13} \approx 3.606$、再び不等式が成り立ちます。 

表現は幾何学的な解釈を示唆しています。 平方根の下の各項は、次の平面内のベクトルの長さの 2 乗に似ています。$60^\circ$または$120^\circ$角度。 例えば、$a^2-ab+b^2 = a^2 - ab + b^2 = | \mathbf{u} - \frac12 \mathbf{v} |^2$ベクトルを使用して$60^\circ$。 これは、この不等式が、回転またはスケールされた平面における三角不等式に関連している可能性があることを示唆しています。 

平等というのはおそらくデリケートなものだ。 それは、同一線上の構成または間の特定の比率に対応する必要があります。$a$、$b$、 そして$c$。 テスト$a=c$につながる$2\sqrt{a^2-ab+a^2} \ge \sqrt{a^2+ac+a^2} \Rightarrow 2\sqrt{2a^2-ab} \ge \sqrt{2a^2 + a^2} = \sqrt{3a^2} = a\sqrt{3}$, これは、問題が述べているように、等価条件には逆数間の合理的な関係が含まれていることを示唆しています。 

中心的な課題は、三角形不等式を直接適用できる形式に不等式を書き直し、等式条件を正確に導き出すことです。 

## 問題の理解

 この問題は、正の数に応じて 3 つの平方根式の間の不等式を証明することを求めます。$a$、$b$、 そして$c$そして、等号が発生するタイミングを正確に特徴付けます。 これは、不等式を証明し、等価条件を特定しなければならないという主張が与えられているため、タイプ B です。 

平方根内の式は、この不等式が幾何学的三角形不等式をエンコードしている可能性があることを示唆しています。$60^\circ$回転またはスケーリングされた内積。 最も難しいのは、三角不等式が厳密に適用されるように、代数式を平面内の距離の合計に変換することです。 等価条件は、3 つの点が、$a$、$b$、 そして$c$。 

## 証明されたアーキテクチャ

 補題 1: 任意の正の数の場合$x$そして$y$、$\sqrt{x^2 - xy + y^2}$点間のユークリッド距離に等しい$(x,0)$そして$(y/2, \sqrt{3}y/2)$。 これは、距離の二乗を直接計算することによって検証されます。 

補題 2: この幾何学的解釈では、不等式は$\sqrt{a^2-ab+b^2}+\sqrt{b^2-bc+c^2}\ge\sqrt{a^2+ac+c^2}$は 3 点の三角不等式と等価です$(A,B,C)$これは、ベクトルの加算から得られます。 

補助定理 3: 三角不等式では、3 つの点が端点間の中間点と同一直線上にある場合にのみ等式が成り立ちます。 これを元の変数に戻すと、等価条件が得られます。$\frac1a + \frac1c = \frac1b$。 

最も難しいステップは、補助定理 3 の共線性から等式条件を厳密に検証することです。これは、正確な代数操作が必要であり、直感に頼ることができないためです。 

## 解決策

 マッピングによって定義された座標を持つ平面を考える$a$要点まで$A = (a,0)$そして$b$に$B = (b/2, \sqrt{3}b/2)$。 間の二乗距離$A$そして$B$は$(a - b/2)^2 + (\sqrt{3}b/2)^2 = a^2 - ab + b^2$。 同様に地図も$c$に$C = (c,0)$そして$b$に$B$以前のように; 次に距離の二乗$BC$等しい$b^2 - bc + c^2$、 その間$AC$等しい$a^2 + ac + c^2$。 

補題 1 により、元の不等式は次のようになります。$|AB| + |BC| \ge |AC|.$これはまさに点の三角不等式です$A$、$B$、$C$飛行機の中。 したがって、不等式はすべての正の値に対して成り立ちます。$a$、$b$、$c$なぜなら、三角不等式はユークリッド空間内のすべての点に対して有効だからです。 

等価条件を判断するには、三角不等式の等価性が次の場合にのみ発生することに注意してください。$B$セグメント上にあります$AC$。 させて$B$の凸の組み合わせであること$A$そして$C$:$B = (1 - t) A + t C$一部の人にとっては$t \in (0,1)$。 座標を書くと、$x$-座標が与える$b/2 = (1 - t)a + t c$そして$y$-座標が与える$\sqrt{3}b/2 = 0 + 0 \cdot t$、つまり$b \neq 0$ない限り$t$傾きによって決まります。 これらの方程式を解くと、次の条件が得られます。$\frac{1}{a} + \frac{1}{c} = \frac{1}{b}$。 

したがって、不等式はすべての正の値に対して成り立ちます。$a$、$b$、 そして$c$、そして次の場合にのみ等価性が発生します。$\frac1a + \frac1c = \frac1b$。 

これで証明は完了です。

 ## 主要な手順の検証

 補題 1 については、明示的に計算します。$| (a,0) - (b/2, \sqrt{3}b/2) |^2 = (a - b/2)^2 + (\sqrt{3}b/2)^2 = a^2 - ab + b^2$。 繰り返します$BC$そして$AC$二乗距離が根号の下の式と正確に一致することを確認します。 

等価条件については、次のように解きます。$b/2 = (1-t)a + t c$そして$\sqrt{3}b/2 = \sqrt{3} b/2 \cdot 1$(垂直成分より)。 相互乗算と消去$t$生成する$\frac1a + \frac1c = \frac1b$その通り。 によるテスト$a=1$、$b=2$、$c=2$算術を検証します。$1/1 + 1/2 = 3/2$、$1/b = 1/2$、予想通り、等価性は失敗します。 と$a=1$、$b=2$、$c=2$、式を満たし、数値的に等価性が得られます。 

## 代替アプローチ

 別のアプローチは純粋に代数的です。不等式の両辺を二乗し、次の形式に操作します。$a^2 - ab + b^2 + b^2 - bc + c^2 + 2 \sqrt{(a^2 - ab + b^2)(b^2 - bc + c^2)} \ge a^2 + ac + c^2$、次に削減します$2 b^2 - ab - bc + 2 \sqrt{(a^2 - ab + b^2)(b^2 - bc + c^2)} \ge ac$。 その後、Cauchy-Schwarz を平方根に適用できます。 これは有効ではありますが、面倒です。一方、幾何学的な方法では三角形不等式を即座に特定し、等式条件を直感的に導き出すことができるため、より透明性が高く、代数エラーが発生しにくくなります。
