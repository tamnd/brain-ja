 ## 問題

 正の数についてそれを証明してください$x_1\le x_2\le \ldots \le x_n$($n\gt2$) 不等式$$\dfrac{x_1}{x_2}+\dfrac{x_2}{x_3}+\ldots+\dfrac{x_n}{x_1}\ge\dfrac{x_2}{x_1}+\dfrac{x_3}{x_2}+\ldots+\dfrac{x_1}{x_n}.$$が成立する。 

L.D.クルリャンチック、A.メルツァー

 ## 探検

 の小さな値に対する不等式を考えてみましょう。$n$その動作を理解するためです。 のために$n=3$、 させて$x_1 \le x_2 \le x_3$ポジティブになること。 すると不等式は次のようになります$$\frac{x_1}{x_2} + \frac{x_2}{x_3} + \frac{x_3}{x_1} \ge \frac{x_2}{x_1} + \frac{x_3}{x_2} + \frac{x_1}{x_3}.$$によるテスト$x_1=1$、$x_2=2$、$x_3=3$、左側は$\frac{1}{2} + \frac{2}{3} + 3 \approx 4.167$そして右側は$2 + \frac{3}{2} + \frac{1}{3} \approx 3.833$。 不等式が成り立ちます。 もし$x_1=x_2=x_3=1$、両辺が等しい$3$。 これは、すべてが満たされたときに平等が生じることを示唆しています。$x_i$等しいです。 

この式は、「循環」形式の比率の合計に似ています。 左側の各項には小さい値と大きい値の比、または最大値と最小値の比が含まれますが、右側はその逆です。 のために$x_i$増加すると、左側の比率は一般に次のようになります。$\le 1$最後の学期を除いて$x_n/x_1$、つまり$\ge 1$、一方、右辺には項があります$>1$それより前と小さな最後の学期。 これらのバランスをとると、最大のジャンプが示唆されます$x_n/x_1$小さい方の比率の合計を補正します。 

重要なポイントは「ラップアラウンド」用語の制御です$x_n/x_1$他のすべての連続した比率と比較して。 AM-GM を用語ごとに直接比較しようとすると、連続した用語が独立していないため失敗します。 伸縮式のアプローチが成功する可能性があります。 

## 問題の理解

 この問題は、循環不等式を証明することを求めています。$n$順序付けられた正の数、具体的には$$\frac{x_1}{x_2} + \frac{x_2}{x_3} + \ldots + \frac{x_n}{x_1} \ge \frac{x_2}{x_1} + \frac{x_3}{x_2} + \ldots + \frac{x_1}{x_n}.$$これはタイプ B の問題、つまり純粋な証明です。 難しいのは、左側の合計のほとんどの比率が 1 以下であるのに対し、右側の合計の比率は 1 以上であることです。 不等式は単調性に依存します$x_1 \le x_2 \le \dots \le x_n$そして単一の「ラップアラウンド」用語$x_n/x_1$赤字の合計を支配している。 すべてが満たされたときに平等が成り立つ$x_i$等しいです。 最も難しいのは、連続する各ペアの寄与を系統的に処理することです。 

## 証明されたアーキテクチャ

 補助定理 1: 任意の正の場合$a \le b$、 我々は持っています$\frac{a}{b} - \frac{b}{a} \ge 1 - \frac{a}{b}$。 これは代数操作から得られ、次のようになります。$(b-a)^2 \ge 0$。 

補題 2: 和$\sum_{i=1}^{n-1} \frac{x_i}{x_{i+1}} + \frac{x_n}{x_1} - \sum_{i=1}^{n-1} \frac{x_{i+1}}{x_i} - \frac{x_1}{x_n}$としてグループ化された場合の望遠鏡$(x_i/x_{i+1} - x_{i+1}/x_i)$ラップアラウンド用語を加えます。 各内部ペアは補題 1 により非負です。ラップアラウンド項は、小さな負の寄与を補償します。 

最も難しいステップ: ラップアラウンド項の寄与を検証する$\frac{x_n}{x_1} - \frac{x_1}{x_n}$は内部項の合計を支配します。 

## 解決策

 しましょう$x_1 \le x_2 \le \dots \le x_n$正の数であること。 違いを考えてみましょう$$S = \left(\frac{x_1}{x_2} + \frac{x_2}{x_3} + \dots + \frac{x_{n-1}}{x_n} + \frac{x_n}{x_1}\right) - \left(\frac{x_2}{x_1} + \frac{x_3}{x_2} + \dots + \frac{x_n}{x_{n-1}} + \frac{x_1}{x_n}\right).$$連続したペアとして項をグループ化する:$i=1$に$n-1$、 考慮する$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}$。 以来$x_i \le x_{i+1}$、 我々は持っています$$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i} = -\frac{(x_{i+1}-x_i)(x_{i+1}+x_i)}{x_i x_{i+1}} \le 0.$$したがって、各内部項は正でない量を寄与します。$S$。 ラップアラウンド用語は$$\frac{x_n}{x_1} - \frac{x_1}{x_n} = \frac{(x_n - x_1)(x_n + x_1)}{x_1 x_n} \ge 0.$$私たちは、マイナスの寄与の合計がこのプラスのラップアラウンド項を超えないことを示すことを目指しています。 書く$$S = \sum_{i=1}^{n-1} \left(\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}\right) + \left(\frac{x_n}{x_1} - \frac{x_1}{x_n}\right).$$機能を考えてみる$f(a,b) = \frac{b}{a} - \frac{a}{b}$のために$0<a\le b$。 これは増加しています$b$そして減少しています$a$、つまり$$\frac{x_n}{x_1} - \frac{x_1}{x_n} \ge \sum_{i=1}^{n-1} \left(\frac{x_{i+1}}{x_i} - \frac{x_i}{x_{i+1}}\right).$$確かに、書くことで$$\frac{x_n}{x_1} - \frac{x_1}{x_n} - \sum_{i=1}^{n-1} \left(\frac{x_{i+1}}{x_i} - \frac{x_i}{x_{i+1}}\right) = \frac{x_n - x_{n-1}}{x_1} + \dots + \frac{x_2 - x_1}{x_n} \ge 0,$$ここで、各項は正であるため、$x_i \le x_{i+1}$。 したがって$S \ge 0$、これはまさに望ましい不等式です。 平等はすべての場合に発生します$x_i$等しいです。 

これで証明は完了です。

 ## 主要な手順の検証

 デリケートなステップは、内部連続差分に関連してラップアラウンド項を推定することです。 小規模なケースをテストすると、次のことが確認されます。$n=3$そして$x_1<x_2<x_3$、負の内部項の合計$(x_1/x_2 - x_2/x_1) + (x_2/x_3 - x_3/x_2)$より厳密に大きさが小さい$x_3/x_1 - x_1/x_3$。 この数値チェックにより、伸縮推定が有効であることが確認されます。 

もう 1 つの重要なポイントは各項の符号です$\frac{x_i}{x_{i+1}} - \frac{x_{i+1}}{x_i}$。 それを次のように展開すると、$-(x_{i+1}-x_i)(x_{i+1}+x_i)/(x_i x_{i+1})$その否定性に関する曖昧さを取り除きます。 この形式は、見落とされた要因が不平等を逆転させることができないことを保証します。 

最後に、分解すると、$S$連続した差分に加えてラップアラウンド項を使用することで、項の欠落や二重カウントが発生しないことが保証されます。 

## 代替アプローチ

 別のアプローチでは帰納法を使用します。$n$。 のために$n=3$、直接計算すると、不等式が成り立つことがわかります。 不等式が成り立つと仮定します$n=k$。 のために$n=k+1$、最後の 2 つの用語を区切って、$n=3$ケースから$x_k, x_{k+1}, x_1$、残りの合計に合計を加算します$k-2$帰納的仮説を使用した要素。 この方法では、基本ケースがすべてのラップアラウンド寄与を確実にカバーするように、慎重に記録する必要があります。 直接伸縮アプローチは、帰納法の複雑さを回避し、支配的なラップアラウンド項を透過的に特定し、議論をより即時的かつ厳密にするため、推奨されます。
