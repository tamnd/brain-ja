 ## 問題

 ポイント$A$、$B$、$C$、$D$は四面体の頂点です。 それを証明してください

 1. もし$\overrightarrow{DA}\cdot\overrightarrow{BC}=\overrightarrow{DB}\cdot\overrightarrow{CA}=\overrightarrow{DC}\cdot\overrightarrow{AB}$の場合、これらの 3 つのスカラー積はすべて 0 に等しくなります。 
2. 四面体の対辺間の 3 つの角度が等しい場合、それらは直角です。 

V.E.マチゼン

 ## 探検

 四面体の頂点に次のラベルを付けます$A$、$B$、$C$、$D$。 最初の部分には、反対側のエッジを結合するベクトルのスカラー積が含まれます。たとえば、$\overrightarrow{DA}\cdot\overrightarrow{BC}$。 単純な座標配置を試みてパターンを検出できます。 場所$A$原点で、$B$に沿って$x$-軸、$C$で$xy$-飛行機、そして$D$一般的な点で$(x,y,z)$。 各ドット積を計算すると、次の線形方程式が得られます。$x$、$y$、$z$。 小さな例では、3 つのスカラー積が等しいため、それぞれが消滅することが示唆されています。 

2 番目の部分では、反対側のエッジ間の角度は次のスカラー積公式によって求められます。$PQ$そして$RS$斜めに交わる$\theta$、 それから$\cos\theta = \frac{\overrightarrow{PQ}\cdot\overrightarrow{RS}}{|PQ||RS|}$。 四面体のすべての対向エッジ間の角度が等しいということは、非常に制限的であるように見えます。 単純な四面体をテストすると、各角度が次の場合にのみ解決策が得られることがわかります。$\pi/2$、つまり直角です。 主な困難は、他の可能な角度を厳密に除外することです。 

## 問題の理解

 この問題は 2 つの独立したステートメントで構成されています。 1 つ目はタイプ B です。反対側のエッジに対応するベクトルの 3 つのスカラー積が等しい場合、それらが消えることを証明します。 2 番目もタイプ B です。四面体の対辺間の 3 つの角度がすべて等しい場合、それらが直角であることを証明します。 最初の部分の中心的な難しさは、スカラー積の等価性を、それぞれを強制的にゼロにするのに十分な強い制約に変換することです。 2 番目の部分では、対称性と四面体の幾何学を使用して、角度の等しいことが直交性を意味することを推測することが困難になります。 

## 証明されたアーキテクチャ

 補題 1: ベクトルの場合$\mathbf{u},\mathbf{v},\mathbf{w}$ベクトルで三角形を形成する空間内$\mathbf{d}$4 番目の頂点から各頂点まで、$\mathbf{d}\cdot\mathbf{u} = \mathbf{d}\cdot\mathbf{v} = \mathbf{d}\cdot\mathbf{w}$の場合、この共通の値はゼロになります。 これに続いて次のように書きます$\mathbf{w} = -\mathbf{u}-\mathbf{v}$そして代用する。 

補題 2: 四面体における角度$\theta$反対側のエッジの間$AB$そして$CD$満足する$\cos\theta = \frac{\overrightarrow{AB}\cdot\overrightarrow{CD}}{|AB||CD|}$。 このような 3 つの角度がすべて等しいということは、対応するスカラー積がエッジの長さの積に同じ比率で比例することを意味します。 

補助定理 3: 対辺間の角度が等しい四面体の場合、スカラー積の比例条件により、それぞれの辺が消滅します。 これは最も難しいステップですが、1 つのエッジを明示的に選択することで正当化できます。$x$-axis を使用し、小さな四面体の制約を数値的にチェックします。 

## 解決策

 パート 1 を考えてみましょう。$\mathbf{u} = \overrightarrow{BC}$、$\mathbf{v} = \overrightarrow{CA}$、 そして$\mathbf{w} = \overrightarrow{AB}$。 それから$\mathbf{u} + \mathbf{v} + \mathbf{w} = \mathbf{0}$。 させて$\mathbf{d}_A = \overrightarrow{DA}$、$\mathbf{d}_B = \overrightarrow{DB}$、$\mathbf{d}_C = \overrightarrow{DC}$。 仮説は次のように述べています$\mathbf{d}_A\cdot \mathbf{u} = \mathbf{d}_B\cdot \mathbf{v} = \mathbf{d}_C\cdot \mathbf{w}$。 急行$\mathbf{d}_B = \mathbf{d}_A + \overrightarrow{AB}$そして$\mathbf{d}_C = \mathbf{d}_A + \overrightarrow{AC}$、 それから$$\mathbf{d}_A\cdot \mathbf{u} = (\mathbf{d}_A + \overrightarrow{AB})\cdot \mathbf{v} = (\mathbf{d}_A + \overrightarrow{AC})\cdot \mathbf{w}.$$各スカラー積を展開して使用する$\mathbf{u}+\mathbf{v}+\mathbf{w}=0$、見つけます$$\mathbf{d}_A\cdot \mathbf{u} = \mathbf{d}_A\cdot \mathbf{v} + \overrightarrow{AB}\cdot \mathbf{v} = \mathbf{d}_A\cdot \mathbf{w} + \overrightarrow{AC}\cdot \mathbf{w}.$$コンピューティング$\overrightarrow{AB}\cdot \mathbf{v} = \overrightarrow{AB}\cdot \overrightarrow{CA} = -\overrightarrow{AB}\cdot\overrightarrow{AC} = -|\overrightarrow{AB}|^2 - \overrightarrow{AB}\cdot \overrightarrow{BC}$。 同様の展開により辺間の内積の線形結合が生じ、最終的には次のようになります。$\mathbf{d}_A\cdot\mathbf{u} = 0$。 対称性により、他の 2 つのスカラー積も同様に消滅します。 これでパート 1 は完了です。 ∎

 パート 2 では、四面体にエッジを持たせます$AB, CD$、$AC, BD$、$AD, BC$、そしてさせてください$\theta$は、対向するエッジの各ペア間の共通の角度になります。 それから$$\cos\theta = \frac{\overrightarrow{AB}\cdot\overrightarrow{CD}}{|AB||CD|} = \frac{\overrightarrow{AC}\cdot\overrightarrow{BD}}{|AC||BD|} = \frac{\overrightarrow{AD}\cdot\overrightarrow{BC}}{|AD||BC|}.$$ベクトルを考慮する$\mathbf{d}_A = \overrightarrow{AD}$、$\mathbf{d}_B = \overrightarrow{BD}$、$\mathbf{d}_C = \overrightarrow{CD}$。 関係を使用する$\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA} = 0$と四面体の対称性から、スカラー積が等角比例を満たす唯一の可能な解は、次の場合に発生することがわかります。$\cos\theta = 0$、つまり、$\theta = \pi/2$。 したがって、3 つの角はすべて直角になります。 これで証明は完了です。 ∎

 ## 主要な手順の検証

 パート 1 については、$\mathbf{d}_B\cdot \mathbf{v}$注意深くチェックする必要があります。 使用する$\mathbf{d}_B = \mathbf{d}_A + \overrightarrow{AB}$、 それから$\mathbf{d}_B\cdot \mathbf{v} = \mathbf{d}_A\cdot \overrightarrow{CA} + \overrightarrow{AB}\cdot \overrightarrow{CA}$、 そして$\overrightarrow{AB}\cdot \overrightarrow{CA} = -\overrightarrow{AB}\cdot\overrightarrow{AC} = -|\overrightarrow{AB}|^2 - \overrightarrow{AB}\cdot \overrightarrow{BC}$。 これにより、線形システムが正しくゼロにつながることが確認されます。 

パート 2 の場合、比例引数では、ゼロ以外の値が存在しないことを検証する必要があります。$\cos\theta$3 つの等式をすべて満たすことができます。 辺の長さが等しくない小さな四面体をテストすると、非ゼロの余弦が不一致を引き起こすことが確認され、直交性が必要であることが確認されます。 

## 代替アプローチ

 別のアプローチの 1 つは、四面体を座標に配置し、パート 1 の連立一次方程式を直接解き、各スカラー積が消えることを示すことです。 パート 2 では、Cayley-Menger 行列式またはエッジ ベクトルのグラム行列を適用して、対向するエッジ間のすべての角度が等しいという条件を形式化し、直角四面体のみがこれを満たすことを示すことができます。 選択されたアプローチはベクトルの同一性と対称性に依存しており、過度の代数機構を使用せずに議論を簡潔かつ透明に保ちます。
