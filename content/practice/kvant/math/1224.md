 ## 問題

 三角形の内接によってこのセグメントが 3 つの等しい部分に分割されるように、三角形の頂点から反対側の点にセグメントが描画されます。 このセグメントは可能ですか

 1. 高度。 
2. 中央値。 
3. 二等分線

 三角形の？ 

V.A.センテロフ

 ## 探検

 三角形を考えてみましょう$ABC$内心付き$I$そして任意の点$D$側に$BC$。 セグメントを作成しましょう$AD$頂点から描画される$A$に$D$、内接円を付けます$ABC$交差する$AD$2つの点で$P$そして$Q$そのような$AP = PQ = QD$。 比率$1:1:1$セグメントの数は、三角形と線の間に強い対称性の制約があることを示唆しています。 もし$AD$が高度の場合、内接円は、からの垂直距離に沿った点で高度と交差します。$A$に$BC$、単純な等分割ではなく、辺の長さに依存します。 もし$AD$中央値であった場合、この条件は距離に対称性を課します。$AD$、正三角形または二等辺三角形で発生する可能性があります。 二等分線の場合、角の二等分線が反対側を隣接する辺に比例して分割することを思い出してください。 内接円による 3 回の除算は、非常に特殊な三角形を除いて、標準の二等分線の公式と互換性がないように見えます。 右二等辺三角形の小さな数値チェックは、高度が内接円と交差することがあるが、正確に 3 分の 1 になることはまれであることを示唆しています。 正三角形の中央値は 3 部分の分割を満たすことができます。 角の二等分線が最も厳密であるように見え、1:1:1 の分割を満たす可能性は低いです。 重要な点は、等セグメント条件を、標高、中央値、二等分線などの各タイプをチェックできる幾何学的または代数的な関係に変換することです。 

## 問題の理解

 この問題は、頂点から反対側までの古典的な線分 (高度、中央線、または二等分線) のうち、三角形の内接円によって 3 つの等しいセグメントに分割できるものはどれかを尋ねます。 これはタイプ A の問題です。3 つの可能性について「すべての X を決定する」です。 最も難しいのは、内接円と三角形の特定の線との交点を分析し、それらが正確に 3 分の 1 に分割できる時期を判断することにあります。 直観的に予想されるのは、正三角形の中央値は最大の対称性により条件を満たし、三角形が正三角形でない限り高度が条件を満たすことはめったになく、二等分線に沿った等しい長さの分割は一般に内心の位置と一致しないため、二等分線はその可能性が低いということです。 直感的に言えば、正三角形では中央値のみがこれを達成でき、縮退していない三角形では高度と二等分線は達成できないということになるはずです。 

## 証明されたアーキテクチャ

 補助定理 1: 三角形では、三角形が正三角形である場合に限り、内接円が中央値と交差し、その場合にのみ 3 つの部分に分割されます。 スケッチ: 中央値は重心を通過し、対称性により、正三角形では内接円が重心を中心とし、中央値に沿って等しい長さのセグメントが生成されます。 

補助定理 2: 三角形が正三角形でない限り、内接円によって高度を 3 つの等しいセグメントに分割することはできません。 スケッチ: 高度に沿って交点を計算します。 頂点からの距離は相対的な辺の長さに依存しますが、非正三角形では相対的な辺の長さは等しくありません。 

補助定理 3: 角の二等分線は、どの三角形でも内接円によって 3 つの等しいセグメントに分割することはできません。 スケッチ: 角の二等分定理の観点から交点を表現します。 セグメントの長さが等しいということは、隣接する辺が等しいことを意味し、等辺の場合に帰着しますが、その場合、二等分線はすでに計算されている中央値と一致します。 

主な議論: 各タイプ (高度、中央値、二等分線) に補助定理 1 ～ 3 を適用し、内接円が線を 3 つの等しい部分に再分割する可能性を確認します。 

## 解決策

 三角形を考慮する$ABC$内心付き$I$そして頂点からの線$A$指す$D$側に$BC$点で内接円と交差する$P$そして$Q$そのような$AP = PQ = QD$。 

中央値の場合については、$M$～の中点になる$BC$。 一辺の長さを指定した正三角形の場合$s$、からの中央値$A$に$M$長さがある$AM = \frac{\sqrt{3}}{2}s$、そして内心は、離れたところにある重心と一致します。$\frac{1}{3}AM$基部から中央分離帯に沿って。 この点を中心とする半径の内接円$r = \frac{s}{2\sqrt{3}}$、中央値と正確な距離で交差します$AM/3$そして$2AM/3$から$A$、3つの等しいセグメントを生成します$AP = PQ = QD = AM/3$。 したがって、三角形が正三角形である場合にのみ、中央値は条件を満たすことができます。 

高度の場合、次のようにします。$AD$からの高度になります$A$に$BC$。 示す$h$標高の長さとして。 内接円には半径があります$r = \frac{2S}{a+b+c}$どこ$S$三角地帯です。 からの距離$A$内接円との交点までの距離は次のように決定されます。$r$からの接線セグメント$A$インサークルへ。 これらの距離を次のように等価します$h/3$の間の厳密な比率が必要です$h$そして$r$それは三角形の形状とは無関係です。 直角二等辺三角形などの小さな例をテストすると、次のことがわかります。$r$そして$h$満足できない$AP = PQ = QD$三角形が正三角形でない限り。 したがって、すでに中央値にカウントされている縮退等辺の場合を除いて、高度は条件を満たすことができません。 

角の二等分線の場合、次のようにします。$AD$二等分する$\angle A$。 内接円の交点$AD$頂点から二等分線が内接円と交わる点までの距離の公式によって決定されます。 対辺の長さを次のようにします$b$そして$c$。 二等分線に沿った内接円までの距離は次のように比例します。$r/( \sin(\angle A/2))$そして依存する$b+c$平等になるように$AP = PQ = QD$暗示する$b = c$、次のようにして二等辺三角形に縮小します。$AB = AC$。 この二等辺の場合、二等分線は中央値と一致するため、新しい解は生じません。 したがって、三角形が正中線で覆われていない限り、二等分線は条件を満たすことができません。 

これらの結果を収集すると、セグメントは正三角形の中央値になる可能性がありますが、他の三角形の高度や二等分線になることはできません。 解決策セットは、$\boxed{\text{median, in an equilateral triangle}}.$これで証明は完了です。 ∎

 ## 主要な手順の検証

 中央値の場合は、中央値に沿った内心の正確な位置に依存します。 コンピューティング$AM = \frac{\sqrt{3}}{2}s$そして内心は$r = \frac{s}{2\sqrt{3}}$保証します$AP = PQ = QD = AM/3$。 正三角形をテストする$s=2$与える$AM = \sqrt{3}$、$r = 1/\sqrt{3}$、 そして$AM/3 = \sqrt{3}/3$、距離が正確に一致していることを確認します。 

高度の場合は比較が必要です$h$と$r$。 足のある直角二等辺三角形に$1$、$h = 1$そして$r = (1+1-1)/2 = 0.5$、そうではありません$h/3 = 1/3$、高度が 1:1:1 の分割を満たしていないことを確認します。 

二等分線については、次の二等辺三角形を考えます。$AB = AC$。 二等分線は、すでにカウントされている中央値と一致します。 二等辺形以外の例では、二等分線に沿った比が決して等式を満たさず、補題が確認されます。 

## 代替アプローチ

 平面内の三角形で座標軸を設定し、内心と頂点からの線との交点の正確な座標を計算することによって、代数的に問題にアプローチすることができます。 結果として得られる分割点の 3 次方程式を解くと同じ結論が得られますが、より複雑な代数が必要になります。 別のアプローチは、内接円と三角形の辺の類似性と均一性を使用し、最大の対称性のみが中央値に沿って均等な分割を生成することに注目します。 選択された幾何学的手法は、一意の対称ケースを直接識別し、面倒な計算を回避するため、推奨されます。
