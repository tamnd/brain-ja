 ## 問題

 単調増加する整数列$\{a_n\}$任意の互いに素な数のペアに対して、$p$そして$q$、平等$a_{pq}=a_p a_q$保持します。 さらに、次のことが知られています$a_1=1$、$a_2=2$。 

1. それを証明してください$a_3=3$。 
2. それを証明してください$a_n=n$任意の自然数に対して$n$。 

(公約数がない 2 つの数は互いに素と呼ばれます。)

 V.A.センテロフ

 ## 探検

 シーケンス${a_n}$は単調で整数値です。 乗算の性質$a_{pq} = a_p a_q$素数のため$p$そして$q$標準アイデンティティとの関連性を示唆しています$n \mapsto n$, 自然数は同じ乗法特性を満たすためです。 小さな数値をテストすると、$a_1=1$そして$a_2=2$与える$a_2 = 2$、$a_4 = a_2^2 = 4$、$a_6 = a_2 a_3$、これはすぐに次のことを示します。$a_3$重要です。 もし$a_3$3より大きかった、$a_6$6 を超えると、単調性に矛盾します。 もし$a_3 < 3$、 それから$a_3 = 2$、しかしその後$a_6 = a_2 a_3 = 4$、6 未満ですが、やはり単調性と矛盾します。$a_5$の間になければなりません$a_4 = 4$そして$a_6 = 4$、それは不可能です。 これは示唆します$a_3=3$。 より大きな数に拡張すると、素因数分解と乗算の性質を帰納的に使用することを試みることができます。 主な課題は、整数の選択が以下以外に存在しないことを厳密に正当化することです。$a_n = n$単調性と乗法性の両方と互換性があります。 

## 問題の理解

 この問題は正確な順序を決定することを求めています${a_n}$2 つの制約を満たす: 単調性と互いに素なインデックスに対する乗法性。$a_1=1$そして$a_2=2$。 これは、指定された条件を満たすすべてのシーケンス (この場合は 1 つのシーケンス) の分類を要求するため、タイプ A の問題です。 中心となる困難は、単調性と組み合わされた乗法特性により、数列が恒等関数と強制的に一致することを示すことです。$\mathbb{N}$。 直観的には、素数での偏差は乗法特性を介して合成数に伝播し、単調性に違反します。 

## 証明されたアーキテクチャ

 補題 1:$a_3=3$。 次に、整数の可能性をテストします。$a_3$そして検査中$a_6 = a_2 a_3$単調性制約に関して。 

補題 2:$a_p = p$すべての素数に対して$p$。 補題 1 と単調性を使用すると、素数があれば次のことがわかります。$p$～とは異なる値が割り当てられました$p$の倍数でシーケンス内に矛盾が発生します。$p$。 

補題 3:$a_n = n$すべての自然数に対して$n$。 素因数分解の使用$n = \prod p_i^{\alpha_i}$と乗法性を表現します。$a_n$として$\prod a_{p_i}^{\alpha_i}$。 補助定理 2 を適用すると、これは次のように評価されます。$n$。 

最も難しいステップは補題 2 です。これは、単調性が逸脱を許さないことを保証するために、すべての素数とその倍数を慎重に処理する必要があるためです。 

## 解決策

 まず最初に決定します$a_3$。 順番が増えてきたので、$a_3 > a_2 = 2$。 仮定する$a_3 \ge 4$。 それから$a_6 = a_2 a_3 \ge 2 \cdot 4 = 8$、 しかし$a_6 \le 6$単調性のため（以来$a_4 = a_2^2 = 4$そして$a_5 \ge a_4 = 4$、$a_6 \le a_5$6) を超えることはできず、矛盾が生じます。 もし$a_3 = 2$、 それから$a_3 = a_2$、厳密な単調性に違反します。 したがって$a_3=3$。 

次に、それを示します$a_p = p$すべての素数に対して$p$。 させて$p$3 より大きい任意の素数です。矛盾があると仮定します。$a_p \ne p$。 以来$a_p$より大きい整数です$a_{p-1} \ge p-1$、可能性は 2 つだけです。$a_p \ge p+1$または$a_p \le p-1$。 もし$a_p \ge p+1$、 考慮する$a_{2p} = a_2 a_p = 2 a_p \ge 2(p+1) = 2p+2$ただし、単調性には次のことが必要です。$a_{2p} \le 2p$、矛盾です。 もし$a_p \le p-1$、 それから$a_{3p} = a_3 a_p = 3 a_p \le 3(p-1) = 3p-3$ただし、単調性には次のことが必要です。$a_{3p} \ge 3p$、また矛盾です。 したがって$a_p = p$すべての素数に対して$p$。 

最後に、任意の自然数に対して、$n$、その素因数分解を書きます$n = \prod_{i=1}^k p_i^{\alpha_i}$。 互いに素な因数に対する乗法特性を繰り返し適用することにより、次の結果が得られます。$a_n = \prod_{i=1}^k a_{p_i}^{\alpha_i} = \prod_{i=1}^k p_i^{\alpha_i} = n.$これにより、次のことが確認されます$a_n = n$あらゆる自然数に対して$n$。$\boxed{a_n = n \text{ for all } n \in \mathbb{N}}$## 主要な手順の検証

 決定するための重要なステップ$a_3$両方の可能性をチェックする必要がある$a_3=2$そして$a_3 \ge 4$そしてその結果を観察する$a_6 = a_2 a_3$。 再計算中$a_6$と$a_3=2$与える$a_6 = 2 \cdot 2 = 4$、これは意味します$a_5 \le 4$、単調性に矛盾します。$a_4 = 4$、確認中$a_3$2. テストはできません$a_3 \ge 4$収量$a_6 \ge 8$、に比べて単調性に矛盾します。$a_4=4$そして$a_5 \ge a_4$、確認中$a_3=3$が唯一の可能性です。 

主要なステップとして、次のことを考慮してください。$p=5$。 もし$a_5=6$、 それから$a_{10} = a_2 a_5 = 12$、 しかし$10 < 12$、単調さと矛盾します。 もし$a_5=4$、 それから$a_{15} = a_3 a_5 = 12$、 しかし$a_{15} \ge 15$、また矛盾です。 同様の推論がすべての大きな素数に適用され、補題が検証されます。 

## 代替アプローチ

 別のアプローチでは、完全帰納法を使用します。$n$。 仮定する$a_k = k$みんなのために$k < n$。 もし$n$素数です、考慮してください$a_n = a_n a_1 = a_n$、および隣接する項からの単調性制約が適用されます。$a_n = n$。 もし$n$複合です、書きます$n = pq$共素と$p,q < n$、乗法は次のようになります。$a_n = a_p a_q = pq = n$。 この帰納法はより機械的ですが、プライムステップでは依然として注意深い単調性分析が必要であるため、透明性が低くなります。 主なアプローチは、同一性を強制する際の素数の重要な役割を明確にします。$a_n=n$直接。
