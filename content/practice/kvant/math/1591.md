 ## 問題

 三角形で$ABC$、角の二等分線$BL$そして$AK$描かれています。 判明したのは、$KL$は三角形の角の二等分線です$AKC$。 角度を見つける$BAC$。

## 問題の理解

 これはタイプ A の問題です。次のすべての可能な値を決定します。$\angle BAC$。 

三角形で$ABC$、2 つの標準角の二等分線が点を定義します$K$の上$BC$そして$L$の上$AC$。 追加の条件として、$KL$は三角形の角の二等分線です$AKC$頂点で$K$。 

タスクは、この幾何学的同時実行条件を辺比の代数的制約に変換することです。これにより、次の一意の値が強制されます。$\angle BAC$。 導出では、構成の必要性と存在の両方を証明する必要があります。 

## 証明されたアーキテクチャ

 まず、表現します$AL/LC$三角形の角の二等分定理を使用する$ABC$、与える$AL/LC = AB/BC$。 

次に、次の条件を表現します。$KL$二等分する$\angle AKC$三角形で$AKC$、降伏$AL/LC = AK/KC$。 

次に計算します$AK$そして$KC$に関しては$a,b,c$角の二等分定理を使用して、$A$三角形で$ABC$、取得$KC = \frac{ab}{b+c}$そして$AK = \frac{2bc\cos(\frac{A}{2})}{b+c}$。 

2 つの式を同等にすると、$AL/LC$で三角方程式を生成します。$A$一人で。 完全性を保証するために、次の三角形が存在することも検証する必要があります。$\angle A = 120^\circ$実際にはすべての二等分線条件を満たします。 

## 解決策

 しましょう$AB=c$、$BC=a$、$CA=b$、そしてさせてください$\angle BAC = A$。 

以来$BL$は内角の二等分線です$\angle B$三角形で$ABC$、角の二等分定理は次のようになります。$\frac{AL}{LC} = \frac{AB}{BC} = \frac{c}{a}.$次に三角形を考えてみましょう$AKC$。 条件には次のように記載されています$KL$は内角の二等分線です$\angle AKC$したがって、三角形の角の二等分定理より$AKC$、$\frac{AL}{LC} = \frac{AK}{KC}.$2 つの等式を組み合わせると、$\frac{AL}{LC}$収量$\frac{AK}{KC} = \frac{c}{a}.$今計算します$AK$そして$KC$。 

以来$AK$は内角の二等分線です$\angle A$三角形で$ABC$、角の二等分定理は次のようになります。$\frac{BK}{KC} = \frac{AB}{AC} = \frac{c}{b},$それで$KC = \frac{ab}{b+c}.$角の二等分線の標準長さの公式は、$A$与える$AK = \frac{2bc\cos\left(\frac{A}{2}\right)}{b+c}.$したがって、$\frac{AK}{KC} = \frac{\frac{2bc\cos\left(\frac{A}{2}\right)}{b+c}}{\frac{ab}{b+c}} = \frac{2c\cos\left(\frac{A}{2}\right)}{a}.$これを同等とすると、$\frac{c}{a}$収量$\frac{2c\cos\left(\frac{A}{2}\right)}{a} = \frac{c}{a}.$以来$a>0$そして$c>0$を取得するためにキャンセルします$2\cos\left(\frac{A}{2}\right) = 1,$それで$\cos\left(\frac{A}{2}\right) = \frac{1}{2}.$したがって、$\frac{A}{2} = 60^\circ,$それは与える$A = 120^\circ.$存在を確認するには、次の三角形があることを確認します。$\angle A = 120^\circ$すべての二等分関係を満たすことができます。 余弦の法則により、$a^2 = b^2 + c^2 - 2bc\cos A = b^2 + c^2 + bc,$それで$a = \sqrt{b^2 + bc + c^2}.$二等分線の長さは次の条件を満たします。$KC = \frac{ab}{b+c} = \frac{b \sqrt{b^2 + bc + c^2}}{b+c}, \qquad AK = \frac{2bc\cos(60^\circ)}{b+c} = \frac{bc}{b+c}.$それから$\frac{AK}{KC} = \frac{bc/(b+c)}{b\sqrt{b^2 + bc + c^2}/(b+c)} = \frac{c}{\sqrt{b^2 + bc + c^2}} = \frac{c}{a},$前の比率と一致します。 同様に、$\frac{AL}{LC} = \frac{c}{a}$以前と同じように、$KL$確かに二分する$\angle AKC$。 これにより、構成が存在し、すべての条件を満たしていることが確認されます。 

したがって、与えられた構成を満たす固有の角度は次のようになります。$\boxed{120^\circ}.$## 主要な手順の検証

 識別$\frac{AL}{LC} = \frac{AK}{KC}$三角形における角の二等分定理の適用から直接得られます。$AKC$に$KL$、 以来$L$上に横たわる$AC$そして$K$二等角の頂点です。

## 代替アプローチ

 三重線形座標または重心座標を使用して問題にアプローチすることもできます。$KL$は角の二等分線であり、次の座標間の線形関係に変換されます。$K$そして$L$、辺比の同次方程式が導かれ、次の三角関数の制約に帰着します。$\angle A$。 

別のアプローチでは、有向角と Ceva タイプの関係を 2 回適用し、1 回ずつ適用します。$ABC$そして一度入ったら$AKC$、明示的な長さの式を持たないセグメント比率を排除します。 三角二等分長法は、条件をただちに 1 つの方程式に還元するため、より短くなります。$\angle A$そして存在の直接の検証を可能にします。
