 ## 問題

 すべてのセットについてそれを証明してください$x_1$、$x_2$、$\ldots$、$x_n$、$0\lt x_1\le x_2\le\ldots\le x_n$、式$$x_2^{k}(x_1-x_3)+x_3^{k}(x_2-x_4)+\ldots+x_1^{k}(x_n-x_2)$$非負である場合$k\gt 1$そして非正の場合$0\lt k\lt 1$。 

L.D.クルリャンチク

 ## 問題の種類のチェック

 これは線形順序制約を伴う巡回符号の問題です。$0 < x_1 \le x_2 \le \cdots \le x_n$。 式は隣接する循環相互作用では非対称であるため、正しいアプローチでは、線形順序がラップアラウンド インデックスときれいに相互作用すると仮定することなく、各循環項を直接制御する必要があります。 

主要な構造的特徴は、各項がサイクル内の連続する 2 つの要素のみを含むため、証明はサイクル全体に均一に適用される単一の隣接する相互作用の符号分析に帰着できることです。 

## ステップ 1: 循環再定式化

 与えられた式は$$S = x_2^{k}(x_1-x_3)+x_3^{k}(x_2-x_4)+\cdots+x_1^{k}(x_n-x_2),$$循環的に解釈されるインデックスを使用します。 

書き込み$x_{n+j}=x_j$、これは次のようになります$$S=\sum_{i=1}^n x_{i+1}^k(x_i-x_{i+2}).$$この再定式化は純粋に表記上のものであり、追加の仮定は導入しません。 

## ステップ 2: 反対称分解

 和を展開すると、$$S=\sum_{i=1}^n x_{i+1}^k x_i-\sum_{i=1}^n x_{i+1}^k x_{i+2}.$$2 番目の合計では、次のように置き換えます。$j=i+1$収量$$\sum_{i=1}^n x_{i+1}^k x_{i+2}=\sum_{j=1}^n x_j^k x_{j+1}.$$したがって$$S=\sum_{i=1}^n \left(x_i x_{i+1}^k - x_{i+1} x_i^k\right).$$このアイデンティティは正確であり、プロパティの順序付けには依存しません。 

## ステップ 3: 各循環項の因数分解

 各加数は満たされます$$x_i x_{i+1}^k - x_{i+1} x_i^k = x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}).$$したがって$$S=\sum_{i=1}^n x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}).$$差の外側のすべての係数は正です。$x_i>0$。 

## ステップ 4: 単一変数の単調性ステートメントへの帰着

 修正$i$そして機能を考える$f(t)=t^{k-1}$の上$(0,\infty)$。 のために$x_i \ne x_{i+1}$に適用される平均値定理$f$エンドポイントとの間隔で$x_i$そして$x_{i+1}$数字を与える$\xi_i$間$x_i$そして$x_{i+1}$そのような$$x_{i+1}^{k-1}-x_i^{k-1} = (k-1)\xi_i^{k-2}(x_{i+1}-x_i).$$これを各項に代入すると、次のようになります。$$x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1}) = (k-1)\,x_i x_{i+1}\,\xi_i^{k-2}(x_{i+1}-x_i).$$以来$x_i>0$、$x_{i+1}>0$、 そして$\xi_i>0$、要因$x_i x_{i+1}\xi_i^{k-2}$すべての人にとって厳密にポジティブです$k>0$。 

したがって、各項の符号は完全に次のように決定されます。$(k-1)(x_{i+1}-x_i)$。 

数列は非減少なので、$x_{i+1}-x_i \ge 0$あらゆる人にとって$i$。 

したがって、各項は満たされます$$\operatorname{sign}\bigl(x_i x_{i+1}(x_{i+1}^{k-1}-x_i^{k-1})\bigr)=\operatorname{sign}(k-1).$$## ステップ 5: 全体的な合計と符号の決定

 和を定義するすべての項$S$同じ符号を持ち、次の符号に等しい$k-1$。 反対の符号間でキャンセルが発生しないため、加算ではこの符号が保持されます。 

のために$k>1$、 我々は持っています$k-1>0$したがって、すべての項が負でない限り、少なくとも 1 つは正になります。$x_i$は等しく、これは合計の非負性と互換性があります。 したがって、$S \ge 0$。 

のために$0<k<1$、 我々は持っています$k-1<0$したがって、すべての項は非正であり、次のようになります。$S \le 0$。 

## 最終結論

 表現は満たす$$S \ge 0 \quad \text{for } k>1,$$そして$$S \le 0 \quad \text{for } 0<k<1.$$循環構造は、隣接する 2 つの変数の寄与の合計に還元され、各寄与の符号は因子によってのみ決定されます。$k-1$電力差の平均値定理表現を介して。
