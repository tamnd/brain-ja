## 問題の理解

 この問題は、$m\times n$テーブルでは、各行と各列の両方が等差数列を形成します。4 隅のエントリの合計は次のとおりです。$s$。 これは、値、特にすべてのテーブル エントリの合計を決定する必要があるため、タイプ C の問題です。 最も難しいのは、行と列の等差数列によって課される制約を同時に考慮し、すべてのエントリの合計の式が純粋に次の観点から表現できるようにすることです。$m$、$n$、行および列に沿った個々の違いに依存せずに、角の合計を計算します。 直感的には、各エントリは左上隅と行と列の差の倍数の線形結合として記述できるため、すべてのエントリの合計は次のように考慮されます。$mn$四隅の平均の倍。

 補助定理 1 は次のように述べています。$m\times n$各行と列で等差数列を形成するエントリを含むテーブルは、次のように表すことができます。$a_{ij} = a + (j-1)d + (i-1)e$いくつかの数字については$a$、$d$、$e$。 左上隅と行と列の違いを指定すると、各エントリが一意に決定されるため、これは当てはまります。 補助定理 2 は、すべてのエントリの合計が次の合計によって計算できることを主張します。$i$そして$j$式の中で$a_{ij} = a + (j-1)d + (i-1)e$。 これは、次のように線形に依存する合計に減ります。$a$、$d$、 そして$e$。 補助定理 3 は、4 つの角の合計は次と等しいと主張します。$s = a + a + (n-1)d + a + (m-1)e + a + (m-1)e + (n-1)d = 4a + 2(m-1)e + 2(n-1)d$、間の線形関係が得られます。$a$、$d$、$e$、 そして$s$。 重要なステップは、合計を次のように表現することです。$s$、$m$、 そして$n$一人で、排除する$a$、$d$、 そして$e$。 

## 解決策

 のエントリにラベルを付けます。$m\times n$テーブルによる$a_{ij}$と$1\le i\le m$そして$1\le j\le n$。 各行と各列は等差数列であるため、次のようになります。$a_{11} = a$左上のエントリとして、$d$行に沿った共通の違いとして、$e$列に沿った共通の違いとして。 その後、すべてのエントリは次のように書くことができます$a_{ij} = a + (j-1)d + (i-1)e.$すべてのエントリの合計は、$\sum_{i=1}^{m}\sum_{j=1}^{n} a_{ij} = \sum_{i=1}^{m}\sum_{j=1}^{n} \left(a + (j-1)d + (i-1)e\right) = \sum_{i=1}^{m}\sum_{j=1}^{n} a + \sum_{i=1}^{m}\sum_{j=1}^{n} (j-1)d + \sum_{i=1}^{m}\sum_{j=1}^{n} (i-1)e.$各項を計算します。 最初の項は$mn a$。 第二期は$\sum_{i=1}^{m}\sum_{j=1}^{n} (j-1)d = \sum_{i=1}^{m} d\sum_{j=1}^{n} (j-1) = m d \frac{n(n-1)}{2}.$同様に、第 3 項は、$\sum_{i=1}^{m}\sum_{j=1}^{n} (i-1)e = \sum_{j=1}^{n} e\sum_{i=1}^{m} (i-1) = n e \frac{m(m-1)}{2}.$したがって、合計は次のようになります$S = mn a + m d \frac{n(n-1)}{2} + n e \frac{m(m-1)}{2} = mn a + \frac{mn(n-1)}{2} d + \frac{mn(m-1)}{2} e.$要素$mn$入手する$S = mn\left(a + \frac{n-1}{2} d + \frac{m-1}{2} e\right).$次に四隅は、$a_{11} = a$、$a_{1n} = a + (n-1)d$、$a_{m1} = a + (m-1)e$、$a_{mn} = a + (n-1)d + (m-1)e$。 それらの合計は$s = a + (a + (n-1)d) + (a + (m-1)e) + (a + (n-1)d + (m-1)e) = 4a + 2(n-1)d + 2(m-1)e.$両辺を次で割ります$4$入手する$\frac{s}{4} = a + \frac{n-1}{2} d + \frac{m-1}{2} e.$先ほどの計算式と比較すると、$S$、私たちは見つけます$S = mn \cdot \frac{s}{4}.$したがって、表内のすべての数値の合計は次のようになります。$\boxed{\frac{mn s}{4}}.$これで証明は完了です。 

## 主要な手順の検証

 計算を検証するには、次の点を考慮してください。$2\times 3$テーブル付き$a = 1$、$d = 2$、$e = 3$。 次に、テーブルのエントリは次のようになります。$\begin{matrix} 1 & 3 & 5 \\ 4 & 6 & 8 \end{matrix}.$角の合計は$1 + 5 + 4 + 8 = 18$。 すべてのエントリの合計は、$1 + 3 + 5 + 4 + 6 + 8 = 27$と一致します$mn s /4 = 2\cdot 3\cdot 18 /4 = 27$。 をチェックする$3\times 3$テーブル付き$a=0$、$d=1$、$e=2$、コーナーは$0,2,4,6$合計付き$12$、合計は$0+1+2+2+3+4+4+5+6=27$、また一致します$mn s/4 = 3\cdot 3\cdot 12/4 = 27$。 これらの独立した計算により、因数分解と代数が正しいこと、および一般的な導出で省略された項がないことが確認されます。
