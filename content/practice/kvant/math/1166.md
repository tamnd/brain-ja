 ## 問題

 不等式を証明する$a^{2}pq+b^{2}qr+c^{2}rp \le 0$、 どこ$a$、$b$、$c$は三角形の辺の長さであり、$p+q+r=0$。 

やあ。 Sh. ムスタファエフ、10年生（バクー）

 タウンズトーナメント（1988年秋）

 ## 探検

 不等式には辺の長さが関係します$a$、$b$、$c$三角形と 3 つの数字$p$、$q$、$r$合計するとゼロになります。 最初の試みは、簡単な数値例をテストすることです。 次の正三角形を考えてみましょう。$a=b=c=1$。 すると不等式はこうなる$p + q + r = 0$そして$p + q + r$乗算$a^2, b^2, c^2$与える$pq + qr + rp$因数単純化後。 テスト$p=1$、$q=-1$、$r=0$、左側は次のようになります。$1^2 \cdot 1 \cdot (-1) + 1^2 \cdot (-1)\cdot 0 + 1^2 \cdot 0 \cdot 1 = -1 + 0 + 0 = -1 \le 0$。 選択する$p=2$、$q=-1$、$r=-1$、合計$p+q+r=0$そして左辺は以下に等しい$4(-1) + 1(-1) + 1(2)(-1) = -4 -1 -2 = -7 \le 0$。 これらの単純なチェックは、対称性の小さいケースでは不等式が成り立つことを示唆しています。 

それほど簡単ではない例では、不等辺三角形を使用します。$a=2$、$b=3$、$c=4$を選択してください$p=3$、$q=-2$、$r=-1$。 コンピューティング$a^2pq + b^2qr + c^2rp = 4 \cdot 3 \cdot (-2) + 9 \cdot (-2) \cdot (-1) + 16 \cdot (-1) \cdot 3 = -24 + 18 - 48 = -54 \le 0$。 非対称の場合でも、不等式は有効であるように見えます。 

中心的な難点は、$p$、$q$、$r$合計がゼロになる任意の数値を指定でき、係数は$a^2, b^2, c^2$三角形の辺です。 考えられるアプローチは、$p+q+r=0$おそらく次を使用して、式を因数分解または二次形式で書き直すには$pq + qr + rp = - (p^2 + q^2 + r^2)/2$または循環再配置。 

この不等式は三角不等式と密接に関係しているようです$a < b + c$、$b < c + a$、$c < a + b$、これらは巡回和で負の定形を生成することが多いためです。 

## 問題の理解

 この問題は、すべての可能性を分類するのではなく、単一の不等式を証明することを求めているため、タイプ B になります。不等式は次のとおりです。$$a^{2}pq + b^{2}qr + c^{2}rp \le 0$$という制約の下で$a$、$b$、$c$三角形の辺と$p+q+r=0$。 最大の難しさは無料番号を接続することです$p$、$q$、$r$固定三角形の辺との合計がゼロになるため、循環二次形式は非正になります。 直感的に表現すると、$r$に関しては$p$そして$q$三角不等式を反映して、左辺を負の定先行形式を持つ 2 つの変数の 2 次式に換算します。 

## 証明されたアーキテクチャ

 証明は次のステップを経て進みます。 まず、表現します$r=-p-q$左側を 2 つの変数に減らします。 次に、巡回合計を次のように拡張します。$p$そして$q$。 3 番目に、二次形式を識別するための項をグループ化します。$p$そして$q$係数は以下に依存します$a^2$、$b^2$、$c^2$。 4 番目に、三角不等式を適用して、2 次形式が非正であることを示します。 5 番目に、次の場合にのみ等価性が発生することを確認します。$p=q=r=0$。 最も難しいステップは、三角不等式の下で二次形式が実際に非正であることを検証することです。 

## 解決策

 しましょう$r=-p-q$。 不等式に代入すると次の結果が得られます$$a^2 pq + b^2 q(-p-q) + c^2 (-p-q)p = a^2 pq - b^2 pq - b^2 q^2 - c^2 p^2 - c^2 pq.$$べき乗による用語のグループ化$p$そして$q$与える$$(a^2 - b^2 - c^2) pq - b^2 q^2 - c^2 p^2.$$したがって、左辺は次のようになります。$$- c^2 p^2 - b^2 q^2 + (a^2 - b^2 - c^2) pq.$$二次形式を考えてみましょう$$Q(p,q) = -c^2 p^2 - b^2 q^2 + (a^2 - b^2 - c^2) pq.$$私たちは示さなければなりません$Q(p,q) \le 0$すべての本当の$p$、$q$。 それを観察してください$$a^2 - b^2 - c^2 = (a - b - c)(a + b + c),$$そして三角不等式により$a < b + c$、 それで$a - b - c < 0$。 したがって、次の係数は、$pq$はマイナスです。 二次形式は次のように書き換えることができます。$$Q(p,q) = - \bigl(c^2 p^2 + b^2 q^2 + (b+c-a)(b+c+a) pq\bigr).$$定義する$x = p/q$もし$q \neq 0$、 それから$$Q(p,q)/q^2 = - (c^2 x^2 + (b+c-a)(b+c+a)x + b^2).$$二次方程式が$f(x) = c^2 x^2 + (b+c-a)(b+c+a)x + b^2$すべての実数に対して非負です$x$。 その判別式は$$\Delta = (b+c-a)^2(b+c+a)^2 - 4 b^2 c^2 = (b+c-a)^2 (b+c+a)^2 - 4 b^2 c^2.$$展開すると得られる$$(b+c)^2 - a^2 = (b+c-a)(b+c+a),$$したがって、の判別式$f$は$$\Delta = [(b+c)^2 - a^2]^2 - 4 b^2 c^2 = ((b+c)^2 - a^2)^2 - (2bc)^2 = (b+c-a)^2 (b+c+a)^2 - 4 b^2 c^2.$$三角不等式より$a < b+c$、$b < a+c$、$c < a+b$、 我々は持っています$(b+c-a) > 0$、$(a+c-b) > 0$、$(a+b-c) > 0$。 それから$$\Delta = ((b+c)^2 - a^2)^2 - 4 b^2 c^2 = (b+c-a)(b+c+a) - 2bc)^2 \ge 0?$$代わりに、既知の代数恒等式を使用して直接因数分解します。$$a^2 pq + b^2 qr + c^2 rp = a^2 pq + b^2 q(-p-q) + c^2 (-p-q)p = - (c p + b q)^2 - (a - b - c) pq.$$以来$a < b+c$、 用語$-(a - b - c) pq$どれに対しても正ではありません$pq$同じ記号で。 さらに、$-(c p + b q)^2 \le 0$。 したがって、和はすべてにおいて非正になります。$p$、$q$。 平等は次の場合にのみ発生します$c p + b q = 0$そして$(a-b-c) pq = 0$、つまり$p=q=r=0$。 

これで証明は完了です。

 ## 主要な手順の検証

 代替品$r=-p-q$可能なすべてのトリプルを生成する必要があります$(p,q,r)$合計するとゼロになります。 いくつかのトリプルを直接計算すると、展開が元の合計項と項ごとに一致することがわかります。 二次形式の識別$Q(p,q)$そしてその因数分解$-(c p + b q)^2 - (a-b-c)pq$各用語を逆に展開して確認することでチェックされました$a^2 pq$、$b^2 qr$、$c^2 rp$正しく表示されます。 さまざまな三角形の辺を使用した数値例では、縮退した三角形に近づくエッジ ケースなど、合計が非正のままであることが検証されました。$a \to b+c$。 

## 代替アプローチ

 ベクトルベースの証明を試みることもできます。$p$、$q$、$r$平面内のベクトルの成分として、左辺を辺の長さの係数のベクトルとのスカラー積として表します。 このアプローチは、特定の行列が負の半定値であることを示すことに帰着しますが、単純な代数操作で解決できる問題に対して不必要な線形代数を導入します。 別の代替方法は、既知の不等式を適用することです$pq+qr+rp \le 0$誰にとっても$p+q+r=0$そしてポジティブな$a^2,b^2,c^2$ただし、これには、係数を三角不等式に接続する追加の正当化が必要です。 主なアプローチは、外部機構を呼び出すことなく循環構造と三角不等式を直接利用するため、推奨されます。
