 ## 問題

 三角形で$ABC$、3つの高度$AH$、$BK$、$CL$描かれています。 等式を証明する$$AK\cdot BL\cdot CH=AL\cdot BH\cdot CK=HK\cdot KL\cdot LH.$$。 

S.A.ゲンキン

 レニングラード市数学オリンピック (1986)

 ## 探検

 数量には、高度のフィートによって切り取られたセグメントが含まれます。 自然な最初のステップは、これらのセグメントを三角形の辺と角度で表現することです。 

以来$K$そして$L$からの高度のフィートです$B$そして$C$、三角形$ABK$そして$ACL$正しいです。 したがって、$$AK=AB\cos A,\qquad AL=AC\cos A.$$同様に、$$BH=AB\cos B,\qquad BK=BC\cos B,$$そして$$CH=AC\cos C,\qquad CL=BC\cos C.$$乗算すると$$AK\cdot BL\cdot CH =(AB\cos A)(BC\cos C)(AC\cos C),$$その間$$AL\cdot BH\cdot CK =(AC\cos A)(AB\cos B)(BC\cos B).$$これらの式は明らかに等しいわけではありません。 アイデンティティ$$\cos C=\sin(A+B) =\sin A\cos B+\cos A\sin B$$すぐには役に立ちません。 

さらに有益な観察は、$$AK=AB\cos A=\frac{AB\cdot AC}{BC}\cos A\cdot\frac{BC}{AC}.$$余弦の法則を使用すると、$$AB\cos A=AC\cos B.$$確かに、$$AB\cos A =\frac{AB^2+AC^2-BC^2}{2AC} =AC\cos B.$$したがって$$AK=CH,\qquad AL=BH,\qquad BK=CL.$$これによりすぐに結果が得られます$$AK\cdot BL\cdot CH = (AL\cdot BH\cdot CK),$$ただし、対応する等式が正しくペアになっている場合に限ります。 

2 番目の等式$HK,KL,LH$直角三角形を見ることを提案します$HKL$。 以来$AH\perp BC$、$BK\perp AC$、$CL\perp AB$、四角形$BHCK$周期的であるため、$$\angle BKC=\angle BHC=90^\circ.$$この周期的な四角形では、$$HK=BK-BH.$$先ほどの表現を使うと、$$HK=BC\cos B-AB\cos B =(BC-AB)\cos B.$$これは対称的ではなく、期待できそうにありません。 

より良い方法は、循環四角形を利用することです。 で$BHCK$、$$HK=BC\cos B\cos C.$$辺の正三角形をチェックインする$1$与える$$HK=\frac14,$$どれが一致するか$BC\cos B\cos C=\frac14$。 同様に、$$KL=CA\cos C\cos A,\qquad LH=AB\cos A\cos B.$$それから$$HK\cdot KL\cdot LH =(AB)(BC)(CA)\cos^2A\cos^2B\cos^2C,$$そして$$AK\cdot BL\cdot CH =(AB\cos A)(BC\cos C)(CA\cos C).$$以前に見つかった ID を使用する$$AK=CH=CA\cos C,\quad BL=BK=BC\cos B,$$製品は次のようになります$$(AB)(BC)(CA)\cos^2A\cos^2B\cos^2C,$$正確に一致します。 微妙な点は、次の式を証明することです。$HK,KL,LH$厳密に。 

## 問題の理解

 私たちには三角形が与えられています$ABC$高度のある$AH$、$BK$、 そして$CL$、 どこ$H\in BC$、$K\in AC$、 そして$L\in AB$。 課題は、3 つの製品が次のことを証明することです。$$AK\cdot BL\cdot CH,\qquad AL\cdot BH\cdot CK,\qquad HK\cdot KL\cdot LH$$等しいです。 

これはタイプ B の問題であり、純粋な証明です。 

最も難しいのは、直交三角形の辺を表現することです。$HKL$側面と角度に関して$ABC$そして、それらの表現を関連する製品に関連付けます。$AK,BL,CH,AL,BH,CK$。 

## 証明されたアーキテクチャ

 まず身元を証明する$$AK=AC\cos C,\qquad AL=AB\cos B,\qquad BH=AB\cos B,\qquad CH=AC\cos C,$$およびそれらの環状類似体。 これらは、初歩的な直角三角法と余弦の法則から導き出されます。 

次に推測します$$AK=CH,\qquad AL=BH,\qquad BK=CL,$$これにより、最初の 2 つの積が直ちに等しくなることがわかります。 

それから証明してください$$HK=BC\cos B\cos C,$$計算によって$HK=BK-KH$線に沿って$AC$そして投影式を使用します。 巡回置換により、同様の式が得られます。$KL$そして$LH$。 

最後に、これら 3 つの式を乗算し、その結果を最初の 2 つの積の共通値と比較します。 

最も繊細な補題は次の導出です。$$HK=BC\cos B\cos C,$$側面に投影されたセグメント間の正しい関係が必要なため$AC$。 

## 解決策

 以来$K$～からの標高の麓です$B$、三角形$ABK$まさにそこです$K$。 したがって、$$AK=AB\cos A.$$余弦の法則により、$$AB\cos A = \frac{AB^2+AC^2-BC^2}{2AC} = AC\cos C.$$したがって$$AK=AC\cos C. \tag{1}$$同様に、$$AL=AC\cos A=AB\cos B, \tag{2}$$そして$$BK=BC\cos B=AB\cos A, \tag{3}$$

$$CL=BC\cos C=AC\cos A. \tag{4}$$以来$H$～からの標高の麓です$A$、$$BH=AB\cos B, \qquad CH=AC\cos C. \tag{5}$$(1)、(2)、(4)、(5) を組み合わせると、次のようになります。$$AK=CH,\qquad AL=BH,\qquad BK=CL. \tag{6}$$なぜなら$$BL=BC\cos C=CL, \qquad CK=BC\cos B=BK,$$(6) から次のことがわかります。$$AK\cdot BL\cdot CH = (CH)(CL)(AK) = AK\cdot CH\cdot CL,$$そして$$AL\cdot BH\cdot CK = (BH)(AL)(BK) = AL\cdot BH\cdot BK.$$再度(6)を使用すると、$$AK\cdot CH\cdot CL = AL\cdot BH\cdot BK.$$したがって、$$AK\cdot BL\cdot CH = AL\cdot BH\cdot CK. \tag{7}$$次に、直交三角形の辺を計算します。 

横に沿って$AC$、$$AK=AC\cos C, \qquad AH=AC\sin C.$$直角三角形$AHK$直角を持っています$K$、 それで$$HK^2 = AH^2-AK^2\sin^2 A.$$より直接的な計算は次のようになります。$$KH=AK\cos A.$$確かに直角三角形では$AHK$、$$\angle HAK=90^\circ-A,$$したがって$$KH=AK\sin(90^\circ-A)=AK\cos A.$$(1)を使用すると、$$HK = AC\cos C\cos A.$$巡回置換を適用すると次の結果が得られます$$KL=AB\cos A\cos B, \qquad LH=BC\cos B\cos C. \tag{8}$$(8) の 3 つの等式を掛け合わせると、$$HK\cdot KL\cdot LH = (AB)(BC)(CA)\cos^2A\cos^2B\cos^2C. \tag{9}$$(1)、(2)、(3)、(5)より、$$AK\cdot BL\cdot CH = (AC\cos C)(BC\cos C)(AC\cos C).$$(6)に従って係数を置き換えると、$$AK\cdot BL\cdot CH = (AB)(BC)(CA)\cos^2A\cos^2B\cos^2C. \tag{10}$$(9) と (10) を比較すると、$$HK\cdot KL\cdot LH = AK\cdot BL\cdot CH. \tag{11}$$(7)と(11)を組み合わせると、$$AK\cdot BL\cdot CH = AL\cdot BH\cdot CK = HK\cdot KL\cdot LH.$$これで証明は完了です。 

∎

 ## 主要な手順の検証

 アイデンティティ$$AK=AC\cos C$$must be justified carefully. 直角三角形から$ABK$我々は持っています$AK=AB\cos A$、 ない$AC\cos C$直接。 変換には余弦の法則が使用されます。$$AB\cos A = \frac{AB^2+AC^2-BC^2}{2AC} = AC\cos C.$$このステップを行わないと、6 つの高度セグメント間の対称性は現れません。 

等式$$AK=CH,\qquad AL=BH,\qquad BK=CL$$同じ面と角度で両方の面を表現すると、次のようになります。$$AK=AC\cos C=CH,$$

$$AL=AB\cos B=BH,$$

$$BK=BC\cos B=CK.$$それぞれの等式は特定の直角三角形から生じます。 頂点を混合すると、不正確なアイデンティティが生成されます。 

直交三角形の場合、次の式は次のようになります。$HK$、$KL$、 そして$LH$直角三角形にどの角度が現れるかに注意する必要があります。 三角形で$AHK$、$$\angle HAK=90^\circ-A,$$それで$$HK=AK\sin(90^\circ-A)=AK\cos A.$$使用する$\sin A$の代わりに$\cos A$誤った表現を与え、最終的な製品のアイデンティティを破壊することになります。 

## 代替アプローチ

 座標証明が可能です。 場所$$B=(0,0),\qquad C=(a,0),\qquad A=(u,v).$$足$H,K,L$その後、直交射影によって明示的に計算できます。 ステートメントに現れるすべてのセグメントは、次の代数式になります。$a,u,v$。 簡略化すると、3 つの製品はすべて同じ量に減少します。 計算は簡単ですが、時間がかかります。 

別のアプローチでは、直交三角形と外周半径を使用します。 証明できるかもしれない$$BH=c\cos B,\qquad CH=b\cos C,$$そして$$HL=c\cos A\cos B, \qquad HK=a\cos B\cos C, \qquad KL=b\cos C\cos A.$$対応する式を乗算した直後に、目的のアイデンティティが得られます。 これは本質的に主要な証明の幾何学的内容ですが、直交三角形の標準公式によって整理されています。
