 ## 問題

 三角形の辺に$ABC$、正方形$ABMN$、$BCKL$、$ACPQ$外側に構築されています。 セグメントについて$NQ$そして$PK$、正方形$NQZT$そして$PKXY$構築されています。 正方形の面積の差を求めます$NQZT$そして$PKXY$、正方形の面積の差を考慮すると、$ABMN$そして$BCKL$知られています。 

A. ゲルコ

 モスクワ 第 59 回数学オリンピック、1996 年、都市大会 (1996 年春)

 ## 探検

 三角形を考えてみましょう$ABC$外側が正方形の場合$ABMN$、$BCKL$、 そして$ACPQ$その側面に構築されています。 セグメントについて$NQ$そして$PK$、正方形$NQZT$そして$PKXY$構築されています。 この問題は、既知の第一世代の正方形の面積の差を基準にして、第二世代の正方形の面積の差を要求します。$ABMN$そして$BCKL$。 複素平面内の点を表すと、便利なフレームワークが提供されます。$90^\circ$の乗算に相当します$i$。 頂点の複素座標を次のように表します。$A$、$B$、 そして$C$。 次のようにセグメント上に外側の正方形を構築します: セグメント上に正方形を構築する場合$UV$、からのベクトル$U$隣接する正方形の頂点にない$UV$は$i(V-U)$反時計回りの回転の場合。 で示す$M$、$N$、$K$、$L$、$P$、$Q$第一世代の正方形の頂点が三角形の辺の反対側になるように、$M = B + i(B-A), \quad N = A + i(B-A), \quad K = C + i(C-B), \quad L = B + i(C-B), \quad P = C + i(C-A), \quad Q = A + i(C-A).$第 2 世代の正方形は、$NQ$そして$PK$。 これらのセグメントに沿ったベクトルは次のとおりです。$\overrightarrow{NQ} = Q - N = A + i(C-A) - (A + i(B-A)) = i(C-B),$

$\overrightarrow{PK} = K - P = C + i(C-B) - (C + i(C-A)) = i(A-B).$タスクは 2 乗の長さを計算することになります。$|NQ|^2$そして$|PK|^2$それらを元の三角形の辺に関連付け、その後、対応する正方形の領域に関連付けます。 

## 問題の理解

 建設利回り$|NQ| = |C-B|$そして$|PK| = |B-A|$ベクトルの差が単純化されると、 第 2 世代の正方形の面積は、これらの長さの正方形に等しいのに対し、第 1 世代の正方形の面積は、その上に構築される三角形の辺の 2 乗に等しいです。 明示的に、$[ABMN] = |AB|^2$そして$[BCKL] = |BC|^2$。 したがって、第 2 世代の正方形面積の差を計算するには、次の 2 乗の大きさを慎重に評価する必要があります。$\overrightarrow{NQ}$そして$\overrightarrow{PK}$。 

直接ベクトル計算では、「既知のアイデンティティ」に関する仮定が回避され、方向と回転が明示的に考慮されます。 表現する$NQ$として$i(C-B)$与える$|NQ|^2 = |C-B|^2 = |BC|^2$、そして表現する$PK$として$i(A-B)$与える$|PK|^2 = |A-B|^2 = |AB|^2$。 したがって、第 2 世代の正方形の面積の差は次のようになります。$[NQZT] - [PKXY] = |NQ|^2 - |PK|^2 = |BC|^2 - |AB|^2 = -(|AB|^2 - |BC|^2).$この負の符号は、第 2 世代の正方形のラベルに基づく減算の順序を反映しています。 問題の規則に合わせて減算を調整すると、次のようになります。$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$最終的な式は、第一世代の正方形の面積の差のみに依存し、すべてのベクトルが一貫して$90^\circ$複雑な平面内で。 

## 証明されたアーキテクチャ

 この問題は、正方形の頂点間のベクトルの差を計算し、二乗の大きさを評価することに帰着します。 させて$\overrightarrow{AB} = B-A$、$\overrightarrow{BC} = C-B$、 そして$\overrightarrow{AC} = C-A$。 外側の正方形は辺に垂直なベクトルを生成します: セグメントの場合$UV$、からの垂直ベクトル$U$は$i(V-U)$。 建設中$NQ$そして$PK$第一世代の正方形の頂点の違いが生み出すものとして$\overrightarrow{NQ} = Q - N = (A + i(C-A)) - (A + i(B-A)) = i(C-B),$

$\overrightarrow{PK} = K - P = (C + i(C-B)) - (C + i(C-A)) = i(A-B).$平方の長さは次のとおりです。$|NQ|^2 = |i(C-B)|^2 = |C-B|^2 = |BC|^2, \quad |PK|^2 = |i(A-B)|^2 = |A-B|^2 = |AB|^2.$したがって、第 2 世代の正方形の面積の差は次のようになります。$[NQZT] - [PKXY] = |NQ|^2 - |PK|^2 = |BC|^2 - |AB|^2.$この違いを次の観点から表現するという問題の要件を満たすには、$[ABMN] - [BCKL]$、と人は書きます。$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$すべてのステップは直接ベクトル計算によって正当化され、証明されていないアイデンティティには依存しません。 第一世代の正方形の外側の方向はベクトルの方向に影響しますが、二乗の大きさには影響しないため、最終的な面積の差は方向とは無関係です。 三角形の形状についての仮定は必要ありません。 

## 解決策

 三角形を作成する$ABC$そして外側の正方形$ABMN$、$BCKL$、 そして$ACPQ$。 セグメント上に第 2 世代の正方形を定義する$NQ$そして$PK$。 複素座標の割り当て$A$、$B$、$C$そして、第一世代の正方形の頂点を次のように構築します。$M = B + i(B-A)$、$N = A + i(B-A)$、$K = C + i(C-B)$、$L = B + i(C-B)$、$P = C + i(C-A)$、$Q = A + i(C-A)$。 第一世代の正方形の頂点を接続するセグメントに沿ってベクトルを計算します。$\overrightarrow{NQ} = Q - N = i(C-B), \quad \overrightarrow{PK} = K - P = i(A-B).$第 2 世代の正方形の面積は、次のベクトルの 2 乗の長さです。$[NQZT] = |NQ|^2 = |BC|^2, \quad [PKXY] = |PK|^2 = |AB|^2.$第 2 世代の正方形の面積の差を、第 1 世代の正方形の面積で表すと、次のようになります。$[PKXY] - [NQZT] = |AB|^2 - |BC|^2 = [ABMN] - [BCKL].$この等式はどの三角形にも当てはまります$ABC$外側の正方形が一貫して構築されており、計算はベクトルの減算と二乗の大きさの評価によって明示的に正当化されます。 第一世代の正方形の向きの符号は結果に影響を与えず、三角形についての仮定は必要ありません。
