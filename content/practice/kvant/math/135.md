 ## 問題

 すべての正の整数についてそれを証明してください$n \gt 1$アイデンティティ$$\sin x \cdot \sin \left(x+\frac{\pi}{n}\right) \cdot \sin \left(x+\frac{2 \pi}{n}\right) \cdot \ldots \cdot \sin \left(x+\frac{(n-1) \pi}{n}\right)= c_n \sin nx,$$が成り立つ、どこで$c_n$何らかの数値です（状況に応じて）$n$)、見つけます$c_n$。 

V. マレシン

 ## 探検

 の小さな値を考慮します。$n$製品のパターンを理解するため。 のために$n=2$、製品は$\sin x \cdot \sin(x + \pi/2) = \sin x \cdot \cos x = \frac{1}{2} \sin 2x$、示唆する$c_2 = 1/2$。 のために$n=3$、製品は$\sin x \cdot \sin(x + \pi/3) \cdot \sin(x + 2\pi/3)$。 アイデンティティの使用$\sin(a + \pi/3) \sin(a + 2\pi/3) = \frac{1}{4} \sin 3a$、予備計算は次のことを示します$c_3 = 1/4$。 のために$n=4$、 我々は持っています$\sin x \cdot \sin(x + \pi/4) \cdot \sin(x + \pi/2) \cdot \sin(x + 3\pi/4)$。 使用する$\sin(x + \pi/2) = \cos x$とペアリング用語を使用すると、製品は次のように単純化されます。$(1/8) \sin 4x$、示唆する$c_4 = 1/8$。 浮かび上がってくるパターンは、$c_n = 2^{1-n}$。 

主な困難は、この公式をすべての人に対して正当化することにあります。$n$そして、正弦の積を複数の角度の正弦に変換するときに現れる交互の符号の処理です。 このアプローチには、おそらく次のような表現が含まれるでしょう。$\sin$複素指数関数と等比級数公式の使用に関して。 符号エラーや要素の欠落がないように注意する必要があります。$2$起きます。 

## 問題の理解

 この問題は、次の積を表すアイデンティティを証明することを求めています。$n$シフト正弦関数は、定数を乗算した単一の正弦関数として機能します。 同一性を証明することと、次の正確な値を決定することの両方が求められるため、これはタイプ A の問題です。$c_n$。 最も難しいのは、すべての人に適用できる厳密な方法で正弦の積を操作することです。$n$、その場限りの小さな例に依存するのではなく。 定数$c_n$のようです$2^{1-n}$小さな例に基づいており、既知の三角積の公式と一致しています。各正弦は次の係数に寄与します。$1/2$指数関数で表現すると、力が得られます。$2^{1-n}$。 

## 証明されたアーキテクチャ

 補題 1: 任意の実際の場合$y$、$\sin y = \frac{e^{iy} - e^{-iy}}{2i}$。 これはオイラーの公式からの標準です。 

補題 2: 任意の整数について$n \ge 1$、製品$\prod_{k=0}^{n-1} (z - e^{i k \pi/n})$等比級数分解を満たします$\prod_{k=0}^{n-1} (e^{2ix} - e^{2i k \pi/n}) = e^{i(n-1)x} \prod_{k=0}^{n-1} 2i \sin(x + k\pi/n)$。 これにより、正弦積を指数形式で書き直すことができます。 

補題 3:$\prod_{k=0}^{n-1} (1 - e^{2i(x + k\pi/n)}) = 1 - e^{2i nx}$。 これは等比数列の因数分解から得られます。 最も難しいステップは要因を追跡することです$2i$各正弦波の全体的なパワーを確認します。$2$そして$i$は正しいです。 

## 解決策

 複素指数恒等式を使用して各サインを表現します。$$\sin \left(x + \frac{k\pi}{n}\right) = \frac{e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}}{2i}.$$製品は、$$\prod_{k=0}^{n-1} \sin \left(x + \frac{k\pi}{n}\right) = \prod_{k=0}^{n-1} \frac{e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}}{2i} = (2i)^{-n} \prod_{k=0}^{n-1} \big(e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)}\big).$$要素$e^{-i(x + k\pi/n)}$各用語から:$$e^{i(x + k\pi/n)} - e^{-i(x + k\pi/n)} = e^{-i(x + k\pi/n)} \left(e^{2i(x + k\pi/n)} - 1\right),$$したがって、製品は次のようになります$$(2i)^{-n} \prod_{k=0}^{n-1} e^{-i(x + k\pi/n)} \prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right) = (2i)^{-n} e^{-i \sum_{k=0}^{n-1} (x + k\pi/n)} \prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right).$$指数を計算します。$$\sum_{k=0}^{n-1} \left(x + \frac{k\pi}{n}\right) = nx + \frac{\pi}{n} \frac{n(n-1)}{2} = nx + \frac{\pi(n-1)}{2}.$$したがって、プリファクターは$e^{-i(nx + \pi(n-1)/2)}$。 残りの積は等比級数になります。$$\prod_{k=0}^{n-1} \left(e^{2i(x + k\pi/n)} - 1\right) = \prod_{k=0}^{n-1} \left(e^{2i x} e^{2i k \pi/n} - 1\right) = \prod_{k=0}^{n-1} \left(e^{2i x} - e^{-2i k \pi/n}\right).$$これはまさに因数分解です$z^n - 1$と$z = e^{2i x}$、与える$$\prod_{k=0}^{n-1} (e^{2i x} - e^{2i k \pi}) = e^{2i n x} - 1 = e^{i n x} (e^{i n x} - e^{-i n x}) = e^{i n x} 2i \sin n x.$$すべての要素を考慮して、$2i$そして$e^{i \pi(n-1)/2}$与える$$\prod_{k=0}^{n-1} \sin \left(x + \frac{k \pi}{n}\right) = 2^{1-n} \sin n x.$$したがって、定数$c_n$は$$c_n = 2^{1-n}.$$これで証明は完了です。 ∎

 ## 主要な手順の検証

 デリケートな部分は因数分解です$\prod_{k=0}^{n-1} (e^{2i x} - e^{2i k \pi/n}) = e^{i n x} 2i \sin n x$。 確認してください$n=3$:$$(e^{2i x} - 1)(e^{2i x} - e^{2i \pi/3})(e^{2i x} - e^{4i \pi/3}) = e^{6 i x} - 1 = (e^{3i x} - e^{-3i x})(e^{3i x} + e^{-3i x})?$$直接計算します。$e^{6 i x} - 1 = (e^{2 i x} - 1)(e^{4 i x} + e^{2 i x} + 1)$、 そして$e^{3i x} - e^{-3i x} = 2 i \sin 3x$、パターンを確認します。 もう 1 つの重要なステップは、次の計算です。$\sum_{k=0}^{n-1} (x + k\pi/n) = nx + \pi(n-1)/2$、最初の合計の公式によって検証されます。$n-1$整数。 

## 代替アプローチ

 帰納法を使用することもできます$n$、それに注意してください$\sin(n+1)x$という言葉で表すことができます$\sin nx$そして$\sin x$標準アイデンティティを使用する$\sin (n+1)x = 2 \cos x \sin nx - \sin(n-1)x$、次に、帰納的に正弦積を因数分解してみます。 別のアプローチは、正弦項を対称的にペアにして恒等式を適用することです。$\sin a \sin b = \frac{1}{2} (\cos(a-b) - \cos(a+b))$ただし、すべての符号と定数を追跡するのは面倒になります。 複雑な指数関数法は、すべてを体系的に処理できるため、推奨されます。$n$そして正しい因数を生成します$2^{1-n}$用語ごとに操作する必要はありません。
