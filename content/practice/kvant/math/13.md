 ## 問題

 最大のものと最小のものの差がある場合、$n$実数$a_1$、$a_2$、$\ldots$、$a_n$に等しい$d$、およびすべての絶対値の合計$\dfrac{n(n-1)}{2}$これらの数値のペアごとの差$$\sum_{i \lt j} |a_i - a_j|$$に等しい$s$、 それから$$(n-1)d \le s \le \frac{n^2}{4}d.$$## 探検

 最初の小さな値を考えてみましょう$n$ペアごとの差の和の構造を理解する。 のために$n=2$、数字付き$a_1$そして$a_2$、絶対差の合計は次のようになります。$|a_1 - a_2| = d$と一致します$(n-1)d = 1\cdot d$そして$\frac{n^2}{4}d = 1\cdot d$, したがって、両方の境界はタイトです。 のために$n=3$、 させて$a_1 \le a_2 \le a_3$と$a_3 - a_1 = d$。 差の合計は$|a_2 - a_1| + |a_3 - a_1| + |a_3 - a_2| = (a_2 - a_1) + (a_3 - a_1) + (a_3 - a_2) = 2(a_3 - a_1) = 2d$。 これは一致します$(n-1)d = 2d$、下限を与えます。 上限$\frac{n^2}{4}d = \frac{9}{4}d$ある程度の柔軟性があり、数値を異なる方法で分散することで合計を増やすことができることを示唆しています。 テスト番号$0$、$d/2$、$d$合計を与える$d/2 + d + d/2 = 2d$、やはり前と同じです。 テスト$0$、$0$、$d$与える$0 + d + d = 2d$、まだ範囲内です。 これは、数値が極端に集中している場合に合計が最小になることを示しています。 数値が均等に分散されている場合、離れた数値間の差が増加するため、合計は最大化される可能性があります。 最大の合計は、数値の半分が次の場合に発生するはずです。$0$そして半分で$d$、与える$n_0 n_d$違いのペア$d$、 どこ$n_0 + n_d = n$、 そして$n_0 n_d$最大化されるのは$n_0 = n_d = n/2$、降伏$s = n^2 d /4$。 重要なステップは、他の構成がこの上限を超えることができない理由を正当化することです。 

## 問題の理解

 問題は合計を制限することを求めています$s$すべてのペアごとの絶対差の$n$実数の広がり (最大値から最小値を引いた値) を仮定すると、$d$。 の極値を決定しているため、これはタイプ C の問題です。$s$。 下限$(n-1)d$1 つを除くすべての数値がどちらかの極端な数値と一致したときにこの値に達するため、それぞれの数値の差は最小限になります。 上限$n^2 d /4$数値が両極端の間で均等に分割され、ペアごとの差が最大化されたときにこの値に達します。 中心となる困難は、他の数値分布ではこれらの範囲外の合計を生成できないことを厳密に証明することです。 

## 証明されたアーキテクチャ

 補題 1: について$n$実数$a_1 \le \dots \le a_n$と$a_n - a_1 = d$、合計$s$満足する$s \ge (n-1)d$。 スケッチ: 含まれる差異の合計$a_1$そして$a_n$少なくとも$(n-1)d$それぞれの極端な現象が現れるため、$n-1$プラスの差があるペア。 

補題 2: 同じ数値の場合、$s \le \frac{n^2}{4} d$。 スケッチ: 数値を 2 つのクラスターに分割します。$a_1$そして1回目$a_n$、クラスター全体のペアの数を最大化します。 合計は$n_1 n_2 d \le n^2 d /4$、 と$n_1 + n_2 = n$。 核心は、これを超えることができる中間点の配置がないことを示しています。 

補助定理 3: 各境界の極値構成は、極値でのクラスタリングによって特徴付けられます。 スケッチ: 下限では、1 つを除くすべての数値が 1 つの極値で一致します。 上限の場合、数値は両端で均等に分割されます。 

最も難しい方向は補題 2 です。これは、数値を内部に分散することで、極値に分割するよりも大きな合計が生成されないようにするものです。 

## 解決策

 しましょう$a_1 \le a_2 \le \dots \le a_n$と示します$d = a_n - a_1$。 すべてのペアごとの絶対差の合計は次のとおりです。$$s = \sum_{1 \le i < j \le n} (a_j - a_i).$$これを書き直すと、それぞれ$a_k$すべての差分に正の係数で現れる$a_j$のために$j>k$すべての負の係数$a_i$のために$i<k$:$$s = \sum_{k=1}^n [(k-1) a_k - (n-k) a_k] = \sum_{k=1}^n (2k - n -1) a_k.$$下限については、次のことを観察してください。$a_1$そして$a_n$貢献する$(a_n - a_1)$それらのいずれかを含む各ペアに。 がある$n-1$を含むペア$a_n$そして$a_1$、 それで$s \ge (n-1)d$。 すべての中間数値が次のいずれかに一致すると、等価性が達成されます。$a_1$または$a_n$、追加の違いは最小限に抑えられます。 

上限については、$n_1$の数字$a_1$そして$n_2$の数字$a_n$、 と$n_1 + n_2 = n$。 この場合、クラスター間のすべての差は等しくなります$d$、合計を与える$s = n_1 n_2 d$。 製品$n_1 n_2$のために最大化されます$n_1 = n_2 = n/2$(または奇数の場合はできるだけ近い)$n$)、降伏$s \le n^2 d /4$。 任意の中間体$a_k$厳密に間$a_1$そして$a_n$寄与する差が以下$d$少なくとも 1 つの極端な値があるため、増加することはできません$s$超えて$n^2 d /4$。 

これらの引数を組み合わせると、目的の不等式が得られます。$$(n-1)d \le s \le \frac{n^2}{4} d.$$これで証明は完了です。

 ## 主要な手順の検証

 下限を決定するための重要なステップは、極値を含むペアを数えることです。 のために$n=4$数字付き$0, 0, 0, d$、差の合計は$d + d + d + d + d + d = 3d = (n-1)d$、バウンドを確認します。 上限については、テストします$n=4$数値を次のように分割します$0,0, d,d$、差の合計は$0+0+d+d+d+d = 4d = n^2 d /4$、最大構成を確認します。 任意の室内番号を導入$x$と$0 < x < d$いくつかの差を以下に減らす$d$、厳密に以下の合計を生成します$4d$、制限を超える構成がないことを確認します。 

## 代替アプローチ

 別のアプローチは、順序差分の二次形式として合計をモデル化することです。$b_i = a_{i+1} - a_i$、 と$b_1 + \dots + b_{n-1} = d$、 そして$s$リニアイン$b_i$係数付き$(n-i)i$。 最大化$s$配布を減らす$d$の間で$b_i$制約を設けて、すべてを集中させる$d$中央の差は最適ではなく、極値分布は次の場合に発生します。$b_1 = d$、$b_2 = \dots = b_{n-1} = 0$、または最後が対称です。 この方法は体系的に不等分割を一般化しますが、主なアプローチはより直観的で透明性があり、中間の差分の組み合わせ簿記を回避します。
