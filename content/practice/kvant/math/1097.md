 ## 問題

 二等辺三角形の頂点の座標は整数です。 底の二乗が偶数であることを証明してください。 

V.V.プロイズヴォロフ

 ## 探検

 頂点が整数の座標を持つ二等辺三角形の小さな例を考えてみましょう。 最も単純な三角形は、軸に沿った直角三角形です。 たとえば、ポイントとしては、$(0,0)$、$(2,0)$、$(1,1)$底辺と二等辺三角形を形成する$(0,0)-(2,0)$長さの$2$、 そして$2^2 = 4$は均等です。 別の例は$(0,0)$、$(4,0)$、$(2,3)$; 底の二乗は$16$、また偶数です。 基数の 2 乗が奇数である反例を見つけようとすると、小さな整数では失敗し、パリティ制約が働いていることを示唆します。 

座標のパリティを調べると、ベースエンドポイントが両方とも偶数であるか、両方とも奇数であるかどうかに注意してください。$x$そして$y$、二乗距離は偶数です。 一方が偶数で、一方が奇数の場合、座標の差の 2 乗は奇数になります。 主な困難は、整数の頂点を持つ二等辺三角形の場合、座標のパリティによって奇数の底の平方を生成できないことを示すことです。 

もう一つの角度はベクトル解析です。 させて$\mathbf{AB}$を基底ベクトルとし、$\mathbf{AC}$そして$\mathbf{BC}$等しい辺。 二乗距離には、整数の二乗和が含まれます。 問題は、2 つの二乗距離が等しい場合、残りの二乗距離は偶数でなければならないことを示すことに帰着します。 課題は、この平等の議論を厳密に形式化することです。 

## 問題の理解

 この問題は、すべての頂点が整数の座標を持つ二等辺三角形において、底辺の長さの 2 乗が偶数の整数であることを証明することを求めます。 この記述は普遍的であり、証明が必要であるため、これはタイプ B の問題です。 最も難しいのは、三角形が整数の座標を持つ場合の二乗距離のパリティを制御することです。 小さな例とパリティの考察からの洞察は、底の 2 乗の長さは必然的に次で割り切れることを示唆しています。$2$。 

## 証明されたアーキテクチャ

 補助定理 1: 整数座標を持つ二等辺三角形では、底辺の中点の座標が両方とも整数か、両方とも半整数になります。 スケッチ: 中点の公式$(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$これを直接示しています。 

補助定理 2: ベースの反対側の頂点は、ベースの端点から等距離になければなりません。 スケッチ: 二等辺三角形の定義により、基底端点までの二乗距離は等しくなります。 これらの距離を整数の二乗和として展開します。 

補助定理 3: 線分が 2 つの整数座標点を接続し、両方の端点から等距離にある点が垂直二等分上にある場合、線分の 2 乗の長さは偶数です。 スケッチ: 座標を代数的に表現します。 パリティ引数は、座標の差の二乗和が偶数でなければならないことを示します。 

パリティの処理を不用意に行うと誤った結論につながる可能性があるため、最も難しいステップは補題 3 です。 主な引数は、最初の 2 つの補題を組み合わせてパリティ制約を適用します。 

## 解決策

 しましょう$A=(x_1,y_1)$、$B=(x_2,y_2)$、 そして$C=(x_3,y_3)$整数座標の二等辺三角形の頂点になります。 仮定する$AB$がベースです。 それから$AC=BC$、つまり$$(x_3-x_1)^2 + (y_3-y_1)^2 = (x_3-x_2)^2 + (y_3-y_2)^2.$$両辺を展開すると、$$x_3^2 - 2x_3 x_1 + x_1^2 + y_3^2 - 2y_3 y_1 + y_1^2 = x_3^2 - 2x_3 x_2 + x_2^2 + y_3^2 - 2y_3 y_2 + y_2^2.$$引き算$x_3^2 + y_3^2$両側から、私たちは得ます$$-2 x_3 x_1 + x_1^2 - 2 y_3 y_1 + y_1^2 = -2 x_3 x_2 + x_2^2 - 2 y_3 y_2 + y_2^2.$$書き直すと、$$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1) = x_2^2 - x_1^2 + y_2^2 - y_1^2.$$両側を因数分解します。$$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1) = (x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1).$$両辺を次で割ります$1$(因子 2 はまだありません)。 ここで、左辺が次の式で割り切れることに注目してください。$2$、 以来$2 x_3 (x_2 - x_1) + 2 y_3 (y_2 - y_1)$明らかに均等です。 したがって、右辺も偶数でなければなりません。$$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1) \equiv 0 \pmod{2}.$$今、$(x_2 - x_1)^2 + (y_2 - y_1)^2 = (x_2 - x_1)(x_2 - x_1) + (y_2 - y_1)(y_2 - y_1)$は合同モジュロです$2$任意の整数の場合、上記の合計に$a,b$、$a^2 \equiv a \cdot a \equiv a \cdot a \pmod{2}$。 より正確には、次の点に注意してください。$(x_2 - x_1)^2 + (y_2 - y_1)^2 = (x_2 - x_1)(x_2 - x_1) + (y_2 - y_1)(y_2 - y_1)$、整数の合同モジュロです$2$に$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1)$なぜなら$(x_2 - x_1)(x_2 + x_1) - (x_2 - x_1)^2 = (x_2 - x_1)(x_1 + x_2 - x_2 + x_1) = 2(x_2 - x_1)x_1$で割り切れます$2$、同様に、$y$学期。 

したがって、底辺の二乗の長さは、$AB$、$$AB^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2,$$は均等です。 これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、パリティの合同性を検証することです。$$(x_2 - x_1)(x_2 + x_1) + (y_2 - y_1)(y_2 + y_1) \equiv (x_2 - x_1)^2 + (y_2 - y_1)^2 \pmod{2}.$$独立して再導出:$(x_2 - x_1)(x_2 + x_1) - (x_2 - x_1)^2 = (x_2 - x_1)(2 x_1)$で割り切れます。$2$。 同様に、$y$。 したがって、左辺が偶数であるということは、$AB^2$は均等です。 具体的な例を使ったテスト、$(0,0),(1,0),(0,1)$二等辺三角形を形成できません。$(0,0),(2,0),(1,1)$収量$AB^2 = 4$、これは均等であり、一貫性が確認されます。 

## 代替アプローチ

 底の中点を使用するベクトル アプローチにより、議論が簡素化されます。 させて$M$～の中点になる$AB$; 次に3番目の頂点$C$～に垂直な線上にあります$AB$を通して$M$。 以来$M$両方の整数または両方の半整数を含む座標、からの距離の 2 乗$A$に$B$で割り切れる必要があります$2$整数座標を維持するには$C$。 このアプローチはジオメトリを強調しますが、同じパリティ引数に帰着します。 代数展開は、座標の位置合わせに関する仮定なしにすべての整数の可能性を明示的に処理するため、厳密さを求める場合に推奨されます。
