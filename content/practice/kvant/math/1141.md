 ## 問題

 台形は円に外接します。 少なくとも 1 つの対角線が底辺と以下の角度を形成していることを証明してください。$45^\circ$。 

N.M.セドラキアン

 ## 探検

 台形を考えてみましょう$ABCD$と$AB$そして$CD$ベースとして、$AB \parallel CD$、そしてその中に内接する円。 台形には外接があるので、対辺の和は等しくなります。$AB + CD = AD + BC$。 対角線を示す$AC$そして$BD$、それらが底面と形成する角度に焦点を当てます。$AB$そして$CD$。 

自然なアプローチは、「最も極端な」台形、たとえば等脚台形を調べることです。$AD = BC$。 この場合、対称性は、対角線が等しい角度で底辺と交わることを示唆しており、おそらく次の角度を超えません。$45^\circ$少なくとも 1 つの対角線に対して。 

非等脚台形の場合、辺の長さは次の条件を満たします。$AB + CD = AD + BC$、これにより、台形がどの程度歪むことができるかが制限されます。 主張を検証するには、対角線の傾きを考慮してください。 底面は水平にしてください。 対角線が底面に対してなす角度は、相対的な高さと水平方向の変位によって決まります。 数値チェック$AB = 8$、$CD = 4$、$AD = 5$、$BC = 7$、 身長$h = 3$より小さい鋭角を形成する 1 つの対角線を示します。$45^\circ$と$AB$。 両方の対角線の角度を超えるようにしようとすると、$45^\circ$失敗し、主張が厳しいことを示唆しています。 

重要な点は、辺の長さを少なくとも 1 つの対角線の傾きに関連付けることと、外接条件を使用して角度を制限することであると思われます。 

## 問題の理解

 円に外接する台形に関する記述、つまり少なくとも 1 つの対角線が底辺と以下の角度を形成することを証明するように求められています。$45^\circ$。 問題はタイプ B です。最も難しいのは辺の長さの条件を接続することです。$AB + CD = AD + BC$対角線の斜面まで徹底的に磨きます。 洞察としては、外接条件により少なくとも 1 つの対角線が十分に「平ら」になることが強制され、最大でも$45^\circ$。 

## 証明されたアーキテクチャ

 補題 1: 底辺のある台形の場合$AB \parallel CD$、条件$AB + CD = AD + BC$円が内接するには必要かつ十分です。 これは、接線四辺形の標準的な特徴付けに従っています。 

補題 2: 台形の向きを次のように調整します。$AB$そして$CD$水平である。 高さを次のように表す$h$そして塩基間の水平方向のシフトは次のとおりです。$x$。 次に、対角線の傾き$AC$そして$BD$は$m_1 = h/(x + CD)$そして$m_2 = h/(AB - x)$、 それぞれ。 これは座標ジオメトリに基づいて配置されます。$D$原点と$C$で$(CD, 0)$。 

補題 3: もし$AB + CD = AD + BC$、その後、どちらか$x + CD \ge h$または$AB - x \ge h$したがって、少なくとも 1 つの勾配は次のようになります。$\le 1$、角度を与える$\le 45^\circ$。 これが重要なステップです。 これは、幾何学的条件を水平方向の変位と高さの間の不平等に帰着させます。 

最も難しいステップは補題 3 で、両方の対角線が 2 を超える角度を形成しないように台形構成を確保することです。$45^\circ$。 

## 解決策

 しましょう$ABCD$台形になる$AB \parallel CD$そして円が刻まれています。 外接四角形の性質により、$AB + CD = AD + BC$。 座標平面内で台形の向きを指定します。$D = (0, 0)$そして$C = (CD, 0)$。 上のベースを次のようにします$AB$、 と$A = (x, h)$そして$B = (x + AB, h)$、 となることによって$h$は高さであり、$x$に対する上底の水平方向のシフトです。$D$。 

対角線$AC$傾斜がある$m_1 = \frac{h - 0}{x - CD} = \frac{h}{x - CD} \quad\text{(in absolute value)},$そして対角線$BD$傾斜がある$m_2 = \frac{h - 0}{x + AB - 0} = \frac{h}{x + AB}.$角度$\theta_1$そして$\theta_2$これらの対角線は底辺とともに形成されます$CD$満足する$\tan \theta_1 = |m_1|$、$\tan \theta_2 = |m_2|$。 少なくとも 1 つの角度を確保するには$\le 45^\circ$、必要です$|m_1| \le 1$または$|m_2| \le 1$、同等に$x - CD \ge h$または$x + AB \ge h$。 

制限された条件により、$AD + BC = AB + CD$。 座標を使用して、$AD = \sqrt{x^2 + h^2}$そして$BC = \sqrt{(x + AB - CD)^2 + h^2}$。 それから$AD + BC = AB + CD$暗示する$\sqrt{x^2 + h^2} + \sqrt{(x + AB - CD)^2 + h^2} = AB + CD.$矛盾のために、両方の対角線の角度が次の値を超えると仮定します。$45^\circ$、 それで$x - CD < h$そして$x + AB < h$。 それから$AD + BC > \sqrt{CD^2 + h^2} + \sqrt{AB^2 + h^2} \ge AB + CD,$なぜなら$\sqrt{CD^2 + h^2} > CD$そして$\sqrt{AB^2 + h^2} > AB$。 これは限定条件に矛盾します。 したがって、少なくとも 1 つの対角線が角度を形成します。$\le 45^\circ$ベース付き。 

これで証明は完了です。

 ## 主要な手順の検証

 補題 3 は微妙でした。 それを検証するには、次のように考えてください。$AB = 8$、$CD = 4$、$h = 3$。 配置する$D$で$(0,0)$そして$C$で$(4,0)$、トップベース$AB$満たさなければなりません$AD + BC = AB + CD = 12$。 試しています$x = 1$、 それから$AD = \sqrt{1 + 9} = \sqrt{10} \approx 3.16$、$BC = \sqrt{(1 + 8 - 4)^2 + 9} = \sqrt{5^2 + 9} = \sqrt{34} \approx 5.83$、 合計$\approx 8.99 < 12$、小さすぎます。 増加中$x$に$2$、$AD \approx \sqrt{4 + 9} = \sqrt{13} \approx 3.61$、$BC \approx \sqrt{6^2 + 9} = \sqrt{45} \approx 6.71$、 合計$\approx 10.32 < 12$。 のみ$x$合計は十分に大きいか$12$、少なくとも 1 つの勾配を強制します$\le 1$、補題を数値的に確認します。 

## 代替アプローチ

 純粋に三角法のアプローチでは、次の公式が使用されます。$\tan \theta = \frac{\text{height}}{\text{horizontal projection}}$各対角線について、水平投影の合計が台形の辺で囲まれていることを示します。 これは上記と同じ不等式になります。 別のアプローチでは、内接円の接点を使用して対角線の合計と底辺の合計を比較する幾何学的不等式を使用します。 メインの座標ベースのアプローチは、傾きを明示的に構築し、問題を単一の単純な不等式に落とし込み、議論を完全に厳密にし、数値的に検証しやすくするため、推奨されます。
