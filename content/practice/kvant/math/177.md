 ## 問題

 方程式のすべての解を求める$$\sqrt[\scriptstyle n~]{x^n-a^n}+\sqrt[\scriptstyle n~]{2a^n-x^n}=a,$$、 どこ$a$は与えられた実数であり、$n$は 1 より大きい自然数です。 

T.テミロフ

 ## 探検

 方程式を考えてみましょう$$\sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n} = a,$$と$a \in \mathbb{R}$そして$n > 1$自然数。 この構造は、周囲の対称性を示唆しています。$x = a$、 以来$x^n - a^n$そして$2a^n - x^n$合計して$a^n$。 小さなテストから始める$n$パターンを検出します。 のために$n = 2$、方程式は次のようになります$\sqrt{x^2 - a^2} + \sqrt{2a^2 - x^2} = a$、これは次の場合にのみ意味があります。$x^2 - a^2 \ge 0$そして$2a^2 - x^2 \ge 0$、暗示$x \in [a, a\sqrt{2}]$。 コンピューティング$\sqrt{x^2 - a^2} + \sqrt{2a^2 - x^2}$の関数として$x$この間隔にわたって。 で$x = a$、合計は次と等しい$\sqrt{0} + \sqrt{a^2} = a$。 で$x = a\sqrt{2}$、合計は次と等しい$\sqrt{a^2} + \sqrt{0} = a$。 この導関数は単調性を示唆しています。 したがって、この方程式では、次の場合にちょうど 2 つの解が認められる可能性があります。$n = 2$。 のために$n > 2$、 テスト$x = a$。 それから$\sqrt[n]{a^n - a^n} + \sqrt[n]{2a^n - a^n} = 0 + \sqrt[n]{a^n} = a$、方程式を満たします。 境界線$x = 2^{1/n} a$与える$\sqrt[n]{(2^{1/n}a)^n - a^n} + \sqrt[n]{2a^n - (2^{1/n}a)^n} = \sqrt[n]{(2 - 1)a^n} + \sqrt[n]{2a^n - 2a^n} = a + 0 = a$、これは有効です。 陰性の解は次のように置き換えることでテストできます。$x = -a$; それから$\sqrt[n]{(-a)^n - a^n} + \sqrt[n]{2a^n - (-a)^n} = \sqrt[n]{(-1)^n a^n - a^n} + \sqrt[n]{2a^n - (-1)^n a^n}$。 偶数の場合$n$、最初の項は$\sqrt[n]{a^n - a^n} = 0$、2つ目は$\sqrt[n]{2a^n - a^n} = a$、解決策が得られます$x = -a$。 奇数の場合$n$、最初の項は$\sqrt[n]{-a^n - a^n} = \sqrt[n]{-2 a^n} = -2^{1/n} a$、第二期$\sqrt[n]{2a^n - (-a)^n} = \sqrt[n]{2a^n + a^n} = 3^{1/n} a$、つまり合計は$(-2^{1/n} + 3^{1/n}) a$に等しい可能性があります$a$場合のみ$2^{1/n} + 1 = 3^{1/n}$、これは誤りです。 したがって、負の解は偶数の場合にのみ存在します。$n$。 この予備分析は潜在的な解決策を示しています$x = a$、$x = 2^{1/n}a$、そしておそらく$x = -a$いつ$n$は均等です。 

重要な点は、他にはないことを正当化することです。$x$という方程式を満たすことができます。 機能があるので、$f(x) = \sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n}$に増加しています$[a, 2^{1/n}a]$対称である場合、これらの候補点の外側にある他の解は単調性または領域制限に違反する必要があります。 主な微妙な点は次のとおりです$n$奇数と偶数を区別し、解が存在しないことを確認します。$(−\infty, a)$または$(2^{1/n} a, \infty)$。 

## 問題の理解

 この問題はすべての実数を決定することを要求します$x$の合計を満たす$n$パラメーターを使用した - 乗根方程式$a \in \mathbb{R}$そして$n \in \mathbb{N}$、$n > 1$。 これは、完全な解決策セットを特定し、他の解決策が存在しないことを証明する必要があるため、タイプ A の問題です。 最も難しいのは、2 つの値の合計を分析することです。$n$-th 根。制限された区間でのみ定義され、非線形性やパリティによって予期せぬ解が生じないようにします。$n$。 予備的な調査により、解決策は次のとおりであることがわかりました。$x = a$、$x = 2^{1/n} a$、 そして$x = -a$もし$n$ドメイン制限と対称性に基づいて、偶数です。 

## 証明されたアーキテクチャ

 補助定理 1 は次のように述べています。$x^n - a^n \ge 0$そして$2a^n - x^n \ge 0$実際に必要なものです$n$-th ルートが存在することを意味します$x \in [a, 2^{1/n} a]$のために$a \ge 0$; 同様に、$x \in [2^{1/n} a, a]$もし$a \le 0$。 補助定理 2 は、関数が次のように主張します。$f(x) = \sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n}$厳密に増加しています$[a, 2^{1/n} a]$のために$n$偶数と$n$奇妙ですが、おそらく次の場合を除いて$x = a$または$x = 2^{1/n}a$これにより、この間隔内で最大 2 つの解が保証されます。 補助定理 3 は候補点をチェックする$x = a$、$x = 2^{1/n} a$、 そして$x = -a$（もし$n$は偶数）、それぞれが方程式を満たすことを示します。 最も困難な方向性は、特に次のような場合、他の解決策が存在しないことを証明することです。$n$微分分析には注意が必要なので、奇妙です。 精査すると失敗する可能性が最も高い補題は補題 2 であり、特に一般的な区間にわたって厳密な単調性を保証します。$n$。 

## 解決策

 しましょう$f(x) = \sqrt[n]{x^n - a^n} + \sqrt[n]{2a^n - x^n}$。 の$n$-th root は、偶数の基数が非負である場合にのみ、実数に対して定義されます。$n$、奇数の場合$n$すべての実数に対して定義されます。 考慮する$n$平。 それから$x^n - a^n \ge 0$そして$2a^n - x^n \ge 0$は必要な条件であり、$x \in [a, 2^{1/n} a]$もし$a > 0$そして$x \in [2^{1/n} a, a]$もし$a < 0$。 のために$x \in [a, 2^{1/n} a]$、 定義する$u = x^n - a^n$そして$v = 2a^n - x^n$。 それから$u, v \ge 0$そして$u + v = a^n$。 機能$g(u) = \sqrt[n]{u} + \sqrt[n]{a^n - u}$厳密に増加しています$u \in [0, a^n/2]$そして減少しています$u \in [a^n/2, a^n]$、したがって最大値は次の時点で発生します。$u = a^n/2$、与える$x^n = 3a^n/2$、境界点の間にありません。 境界点のテスト、$u = 0$収量$x = a$、与える$f(a) = 0 + \sqrt[n]{a^n} = a$、 そして$v = 0$与える$x^n = 2a^n$、 または$x = 2^{1/n} a$、与える$f(2^{1/n} a) = \sqrt[n]{a^n} + 0 = a$。 否定的な候補者$x = -a$有効です$n$偶数：それでは$(-a)^n - a^n = 0$均等に$n$、 そして$2a^n - (-a)^n = 2a^n - a^n = a^n$、 それで$f(-a) = 0 + a = a$。 

考慮する$n$奇数。 それから$x^n - a^n$ネガティブなこともあるかもしれませんが、$\sqrt[n]{x^n - a^n}$と定義されています。 もし$x > 2^{1/n} a$、 それから$2a^n - x^n < 0$、 それで$\sqrt[n]{2a^n - x^n} = -((x^n - 2a^n)^{1/n}) < 0$したがって、合計は厳密に以下になります。$\sqrt[n]{x^n - a^n}$を超える$a$でのみ$x = 2^{1/n} a$。 同様に、$x < a$、 それから$x^n - a^n < 0$、マイナスの寄与を与えます。 したがって、候補者はただ$x = a$そして$x = 2^{1/n} a$。 置き換える$x = a$を取得します。
