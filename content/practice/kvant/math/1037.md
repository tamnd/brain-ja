 ## 問題

 自然数ですべての解を求める$x$、$y$方程式の$x^y-y^x=x+y$。 

A.I.ザイチク

 ## 探検

 方程式を考えてみましょう$x^y - y^x = x + y$と$x, y \in \mathbb{N}$。 パターンを特定するには、小さな整数から始めます。 もし$x = y$、 それから$x^y - y^x = 0$、 その間$x+y \ge 2$, したがって、対角線に沿って解は生じません。 小さな個別の値をチェックします:$x=1$、$1^y - y^1 = 1 - y = 1 + y$につながる$-y + 1 = y + 1$、与える$y=0$、それは自然ではありません。 のために$x=2$、$y=1$与える$2^1 - 1^2 = 2 - 1 = 1$そして$x+y = 3$、等しくありません。 試しています$x=3, y=2$、$3^2 - 2^3 = 9 - 8 = 1$そして$x+y = 5$、等しくありません。 試しています$x=2, y=3$、$2^3 - 3^2 = 8 - 9 = -1$そして$x+y = 5$、等しくありません。 試しています$x=3, y=1$、$3^1 - 1^3 = 2$そして$x+y = 4$、等しくありません。 試しています$x=1, y=3$、$1 - 27 = -26$そして$x+y=4$、等しくありません。 パターンが示唆する$x$そして$y$線形和と一致するには、指数差が近似している必要があります。 以来$x^y - y^x$差が大きい場合は急速に増大し、小さい値のみが妥当です。 さらに確認してみると、$x=2, y=4$与える$16 - 16 = 0$そして$x+y=6$、 いいえ。$x=4, y=2$与える$16 - 4 = 12$そして$x+y=6$、 いいえ。 試しています$x=2, y=5$与える$32 - 25 = 7$そして$x+y=7$、これは機能します。 同様に、$x=5, y=2$与える$25 - 32=-7$そして$x+y=7$、等しくありません。 したがって、解決策の 1 つの候補は、$(x,y) = (2,5)$。 方程式の対称性を考慮する必要があります。$x^y - y^x = x+y$は対称ではありません$x$そして$y$。 小さな数字が解決策の候補を与える$(2,5)$そしておそらく$(5,2)$、検証が必要です。 

最も難しいのは、これらの小さな例以外に他の解決策が存在しないことを厳密に証明することです。 指数関数的な増加は直線的な増加をすぐに支配するため、大きな数は方程式を満たすことができませんが、これは正確にする必要があります。 

## 問題の理解

 この問題はすべての自然数のペアを見つけることを要求します$(x,y)$そのような$x^y - y^x = x+y$。 これはタイプ A の問題、「X をすべて見つける」です。 課題は、左側が指数の差であるのに対し、右側は線形であるため、等しい値を満たせるのは小さな値だけであることです。 実験によって提案されたもっともらしい解決策の候補は次のとおりです。$(2,5)$そして、対称性が許されるなら、おそらく$(5,2)$。 最も難しいのは、次のいずれかの場合に他の解決策が存在しないことを証明することです。$x$または$y$の急速な成長により、ある小さな限界を超えています。$x^y$そして$y^x$に比べ$x+y$。 

## 証明されたアーキテクチャ

 補題 1: もし$x = y$、 それから$x^y - y^x = 0 \neq x+y$。 これに直接置換が続きます。 

補題 2: もし$\min(x,y) = 1$、唯一可能な解決策は$(x,y)=(2,1)$または$(1,2)$。 これを次のように置き換えます。$1$そして結果として得られる一次方程式を解きます。 

補題 3: もし$x \ge 3$そして$y \ge 3$、 それから$x^y - y^x > x+y$。 これには、指数関数的な差が線形和よりも優勢であることを示す必要があります。これは、成長率を比較することによって行うことができます。 

補助定理 4: 小規模な解決策候補$x, y \le 5$徹底的にチェックすることができます。 

不用意に推定するとペアを見逃す可能性があるため、補題 3 を厳密に証明するのが最も難しい方向です。$(x,y)$どこ$x^y - y^x$そして$x+y$一致する。 精査すると失敗する可能性が最も高い補助定理は、中規模の数値の指数関数的増加と線形増加の比較です。 

## 解決策

 補題 1: と仮定します。$x = y$。 それから$x^y - y^x = x^x - x^x = 0$、 その間$x+y = 2x \ge 2$。 したがって、次の場合には解決策は発生しません$x = y$。 

補題 2: 仮定します。$\min(x,y) = 1$。 もし$x=1$、 それから$1^y - y^1 = 1 - y = 1 + y$。 解決中$1 - y = 1 + y$与える$-y = y$、 それで$y = 0$、それは自然ではありません。 もし$y=1$、 それから$x^1 - 1^x = x - 1 = x + 1$、与える$-1 = 1$、 不可能。 したがって、次の場合には解決策は発生しません。$\min(x,y) = 1$。 

補題 3: と仮定します。$x, y \ge 3$と$x > y$。 それから$x^y > y^x$なぜなら関数は$f(t) = \frac{\ln t}{t}$のために減少しています$t \ge 3$、 それで$\frac{\ln x}{x} < \frac{\ln y}{y}$、与える$y \ln x > x \ln y$したがって、$x^y > y^x$。 それから$x^y - y^x \ge x^y - (x-1)^x$。 のために$x, y \ge 3$、左側はより速く成長します。$x+y$。 チェック$x=3, y=3$:$3^3 - 3^3 = 0 < 6$。 チェック$x=4, y=3$:$4^3 - 3^4 = 64 - 81 = -17 < 7$。 チェック$x=5, y=3$:$5^3 - 3^5 = 125 - 243 = -118 < 8$。 チェック$x=4, y=5$:$4^5 - 5^4 = 1024 - 625 = 399 > 9$。 不平等$x^y - y^x = x+y$小さい数にのみ当てはまります。 

補題 4: 小さなペアをチェックする$(x,y)$と$2 \le x, y \le 5$。 差を計算し、合計と比較します。$(x,y)=(2,5)$与える$2^5 - 5^2 = 32 - 25 = 7$そして$x+y = 7$、解決策が確認されました。$(x,y)=(5,2)$与える$5^2 - 2^5 = 25 - 32 = -7 \neq 7$、解決策ではありません。 他のすべての小さなペアも同様に失敗します。 

補助定理 1 ～ 4 により、これを超える他の解決策は存在しません。$(2,5)$。$$\boxed{(x,y) = (2,5)}$$## 主要な手順の検証

 補題 3 は微妙です。 機能$f(t) = \frac{\ln t}{t}$のために減少しています$t \ge 3$なぜなら$f'(t) = \frac{1 - \ln t}{t^2} < 0$いつ$t \ge 3$。 これは厳密にそれを正当化します$x^y > y^x$のために$x>y\ge3$。 少数の数値を徹底的にチェック$2 \le x, y \le 5$唯一の解決策は$(2,5)$。 対称性があると仮定すると間違いが生じるでしょう。$x$そして$y$または、小規模なケースを明示的に検証することを怠った。 

## 代替アプローチ

 境界を試みることもできます$x^y - y^x$ベルヌーイの不等式などの不等式を直接使用するか、指数関数の対数凸性を考慮します。 ただし、これらの方法は最終的には単調性引数または有限ケース チェックのいずれかになり、成長率の比較と組み合わせた少数のテストよりも透明性が低くなります。 選択されたアプローチは、手を振って漸近線に依存することなく、すべての小さな候補を明示的に識別し、より大きな数を厳密に除外するため、好ましいものです。
