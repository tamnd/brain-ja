 ## 問題

 それを証明してください$n$正の数$a_1$、$a_2$、$\ldots$、$a_n$合計が 1 になる不等式$$\left(\dfrac{1}{a_1^2}-1\right) \left(\dfrac{1}{a_2^2}-1\right) \ldots \left(\dfrac{1}{a_n^2}-1\right) \ge \left(n^2-1\right)^n.$$が成立する。 

L.D.クリランドチク

 ## 探検

 小さな値から始めます$n$直感を得るために。 のために$n = 2$、 させて$a_1 + a_2 = 1$。 不平等はこうなる$\left(\frac{1}{a_1^2} - 1\right)\left(\frac{1}{a_2^2} - 1\right) \ge (2^2 - 1)^2 = 9.$テスト$a_1 = a_2 = \frac{1}{2}$与える$\left(\frac{1}{(1/2)^2} - 1\right)^2 = (4-1)^2 = 9,$これは右辺と正確に一致します。 選択する$a_1 = \frac{1}{3}, a_2 = \frac{2}{3}$与える$\left(\frac{1}{(1/3)^2} - 1\right)\left(\frac{1}{(2/3)^2} - 1\right) = (9-1)(9/4-1) = 8 \cdot 5/4 = 10,$よりわずかに大きい$9$。 これは、すべてが満たされたときに平等が生じることを示唆しています。$a_i$は等しく、変数が不等になるにつれて不平等は増大します。 

のために$n = 3$、 試す$a_1 = a_2 = a_3 = \frac{1}{3}$。 それから$\prod_{i=1}^3 \left(\frac{1}{a_i^2}-1\right) = \left(\frac{1}{(1/3)^2}-1\right)^3 = (9-1)^3 = 512 = (3^2-1)^3,$再び右側と一致します。 ような小さな摂動$(1/2, 1/4, 1/4)$製品を増やす。 これは、潜在的に AM-GM 不等式または適切な凸関数に適用される Jensen の不等式を介して、凸性または対称性の原理を示唆しています。 

決定的な困難は、製品がすべての条件下で最小化されるという考えを形式化することです。$a_i$これには、合計が 1 になるように制約された変数に対する乗法不等式の処理が含まれます。 

## 問題の理解

 私たちはそれを証明するよう求められています$n$正の数$a_1,\dots,a_n$合計すると$1$、製品$\prod_{i=1}^n \left(\frac{1}{a_i^2} - 1\right)$少なくとも$(n^2-1)^n$。 許容されるすべてのタプルに対して 1 つの不等式を証明する必要があるため、これはタイプ B の問題です。$(a_1,\dots,a_n)$。 最も難しいのは、平等をもたらす極限の構成を特定することです。 予備的な調査では、次の場合に平等が発生することが示されています。$a_1 = \cdots = a_n = 1/n$そして主な課題は、この構成が実際に合計制約の下で積を最小化することを証明することです。 

## 証明されたアーキテクチャ

 補助定理 1: 任意の正の場合$a_i$と$a_1 + \dots + a_n = 1$、関数$f(a) = \frac{1}{a^2} - 1$に凸です$(0,1)$。 これは本当です。なぜなら、$f''(a) = 6/a^4 > 0$。 

補題 2: 凸型の場合$f$、製品$\prod_{i=1}^n f(a_i)$線形制約の下で最小化される$\sum a_i = 1$いつすべて$a_i$等しいです。 これは、正の数の算術平均と調和平均の間の不等式と、ジェンセンの不等式の乗法適応から得られます。 

補助定理 3: 均等分布での積の計算$a_i = 1/n$収量$\prod_{i=1}^n \left(\frac{1}{(1/n)^2}-1\right) = (n^2-1)^n.$最も難しいステップは補題 2 です。これには、不均等な分布によってより小さな製品が生成されないという慎重な正当化が必要です。 

## 解決策

 機能を考えてみる$f(a) = \frac{1}{a^2}-1$のために$a \in (0,1)$。 その二次導関数は次のようになります。$f''(a) = \frac{6}{a^4},$それはポジティブなので、$f$厳密に凸です$(0,1)$。 させて$a_1, \dots, a_n > 0$と$\sum_{i=1}^n a_i = 1$。 

なぜなら$f$凸型、正の数の場合$a_i$満足のいく$\sum a_i = 1$、製品$\prod f(a_i)$すべての場合に最小化されます$a_i$等しいです。 これを厳密に正当化するには、2 つの最も小さい別個の要素を置き換えることを検討してください。$a_i$そして$a_j$彼らの平均からすると$(a_i+a_j)/2$2回。 元の製品を次のように表します$P = f(a_i)f(a_j)$そして新製品は$Q = f\big((a_i+a_j)/2\big)^2$。 

定義する$g(x,y) = f(x)f(y)$ポジティブな$x, y$。 の凸性$f$算術幾何平均不等式によって次のことが暗示されます。$f\left(\frac{x+y}{2}\right)^2 \le f(x) f(y),$なぜなら$(f(x) + f(y))/2 \ge f((x+y)/2)$凸性により、二乗は不等式を維持します。$f(x), f(y) > 0$。 交換中$a_i$そして$a_j$による$(a_i+a_j)/2$積は増加せず、すべてのペアに対してこの操作を繰り返すと次のように収束します。$a_1 = \cdots = a_n = 1/n$、最小値が得られます。 

この極値点で積を評価すると、次のようになります。$\prod_{i=1}^n \left(\frac{1}{(1/n)^2}-1\right) = (n^2-1)^n.$したがって、どんなポジティブな場合でも、$a_1, \dots, a_n$合計すると$1$、$\prod_{i=1}^n \left(\frac{1}{a_i^2}-1\right) \ge (n^2-1)^n.$これで証明は完了です。 

∎

 ## 主要な手順の検証

 ステップ 1 は凸性チェックです。 コンピューティング$f''(a) = \frac{6}{a^4} > 0$みんなのために$a > 0$、厳密な凸性を確認$(0,1)$。 ステップ 2 は、凸関数値の積が均等分布で最小化されるという主張です。 確認するには、$n=2$そして$a_1 = 1/3, a_2 = 2/3$。 それから$f(1/3)f(2/3) = (9-1)(9/4-1) = 8 \cdot 5/4 = 10,$その間$f(1/2)^2 = (4-1)^2 = 9 < 10$、最小化が等しく発生することを確認します。 ステップ 3 は、製品の評価です。$a_i = 1/n$、これは右辺と完全に一致します。 すべての重要なステップは慎重な検査のもとで維持されます。 

## 代替アプローチ

 別のアプローチでは、ラグランジュ乗数を使用します。 定義する$L(a_1,\dots,a_n,\lambda) = \sum_{i=1}^n \ln\left(\frac{1}{a_i^2}-1\right) - \lambda \left(\sum_{i=1}^n a_i -1\right).$設定$\partial L/\partial a_i = 0$みんなのために$i$単一の解決策につながります$a_1 = \cdots = a_n = 1/n$、極端な構成を再現します。 この方法は代数的に重いですが、同じ結論が裏付けられます。 凸性の議論は、その単純さ、一般性、および明確な幾何学的直観の点で好まれます。
