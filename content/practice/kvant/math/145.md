 ## 探検

この観察を形式化するには、シーケンスが次の倍数の小数部の観点から記述できることに注意してください。$\sqrt{2}$。 させて$S_n = a_1 + \dots + a_n$、エラーを定義します$E_n = S_n - n\sqrt{2}$。 それから$|E_n|$各ステップで最小化され、増分は$a_{n+1}$かどうかによって決まります。$E_n$未満です$1/2$以上$1/2$絶対値で言うと。 小規模な数値実験は、シーケンスが繰り返しパターンに落ち着かないことを示唆しており、不合理性が示唆されています。$\sqrt{2}$重要です。 

おそらく重要なステップは、整数の有限ブロックが無限に繰り返せないことを示すことにあります。そのためには、次のことを証明する必要があります。$a_1, \dots, a_p$繰り返し、そして$p\sqrt{2}$はある整数の整数倍となり、次の非合理性と矛盾します。$\sqrt{2}$。 

## 問題の理解

 この問題では、支払いの順序が次のとおりであることを証明する必要があります。$a_n \in {1,2}$、累積合計を最も近くに保つために選択されます。$n\sqrt{2}$、定期的にすることはできません。 これは、ステートメントが与えられ、それを証明する必要があるため、タイプ B の問題です。 最も難しいのは、の定義を結び付けることです。$a_n$近似という意味では$n\sqrt{2}$繰り返しブロックは不可能です。 直観的に、シーケンスがピリオドで周期的であれば、$p$の場合、ある期間の平均支払額は次の値に等しくなければなりません。$\sqrt{2}$、それは不可能です。$\sqrt{2}$不合理です。 これは、周期性が起こり得ないことを示唆しています。 

## 証明されたアーキテクチャ

 補題 1: すべての人にとって$n$、$a_n$どちらかに等しい$1$または$2$そして満足する$|S_n - n\sqrt{2}| \le 1/2$、 どこ$S_n = a_1 + \dots + a_n$。 これは選択規則から直接導き出されます。$a_n$最も近い$n\sqrt{2} - S_{n-1}$。 

補助定理 2: 整数のシーケンスの場合$a_1, \dots, a_p$定期的に繰り返されて生成される$a_n$みんなのために$n$、その後の平均$a_1, \dots, a_p$等しい$\sqrt{2}$。 これが成り立つのは、合計額が目標値に近づくためには、各期間の平均が期ごとの望ましい平均成長率と一致する必要があるためです。$n\sqrt{2}$。 

補助定理 3: 整数の有限シーケンスの平均は等しくありません$\sqrt{2}$、 として$\sqrt{2}$不合理です。 これは無理数の定義からすぐに分かります。 

最も難しいステップは、周期性によって 1 つの期間の平均が等しくなることを厳密に正当化することです。$\sqrt{2}$、シーケンスは近似しているため、$n\sqrt{2}$誤差が最小限に抑えられるという意味で、小さな変動は正確な周期性と一致しません。 

## 解決策

 しましょう$S_n = a_1 + a_2 + \dots + a_n$は数列の累積和を示します。 施工により、$a_n$そのように選ばれる$|S_n - n\sqrt{2}|$最小化され、$a_n \in {1,2}$。 したがって、すべての人にとって、$n$、エラー$E_n = S_n - n\sqrt{2}$満足する$|E_n| \le 1/2$。 

矛盾するため、次のシーケンスがあったとします。$(a_n)$周期的で周期的です$p$、 それで$a_{n+p} = a_n$みんなのために$n$。 この場合、累積和は次の条件を満たします。$S_{n+p} = S_n + S_p$、 どこ$S_p = a_1 + \dots + a_p$。 一方、目標金額は以下の条件を満たしている。$(n+p)\sqrt{2} = n\sqrt{2} + p\sqrt{2}$。 1 ピリオド後の誤差は次のとおりです。$$E_{n+p} = S_{n+p} - (n+p)\sqrt{2} = S_n + S_p - n\sqrt{2} - p\sqrt{2} = E_n + (S_p - p\sqrt{2}).$$最小エラー ルールにより次のことが保証されるため、$|E_{n+p}| \le 1/2$そして$|E_n| \le 1/2$、増分$S_p - p\sqrt{2}$満たさなければなりません$|S_p - p\sqrt{2}| \le 1$、より正確には、$S_p - p\sqrt{2} = 0$そうしないと、誤差が期間ごとに直線的に増加するためです。 したがって$$\frac{S_p}{p} = \sqrt{2}.$$しかし、$S_p$は整数であり、$p$は正の整数なので、$S_p/p$合理的である一方、$\sqrt{2}$不合理です。 これは矛盾です。 したがってそのような期間はありません$p$存在し、そのシーケンス$(a_n)$は非周期的です。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、周期性が意味することを主張することです。$(S_p/p) = \sqrt{2}$。 検証するには、次の累積和を考慮してください。$k$期間は$S_{kp} = kS_p$。 以降の目標金額$k$期間は$kp\sqrt{2}$。 エラーが最小限に抑えられる条件には、次のものが必要です。$|S_{kp} - kp\sqrt{2}| \le 1/2$、大規模な場合$k$場合にのみ可能です$S_p - p\sqrt{2} = 0$。 ゼロ以外の小さな差があると、$|k(S_p - p\sqrt{2})| > 1/2$十分な大きさの$k$、最小エラー規則に違反します。 小さな期間を数値的にテストすると、小さな整数の不一致でも累積することが確認され、議論が検証されます。
