 ## 問題

 合計しましょう$1+\dfrac12+\dfrac13+\ldots+\dfrac1n$で表される$h_n$。 証明する(各自然数について)$n$) 不等式$$\dfrac1{h_1^2}+\dfrac1{2h_2^2}+\dfrac1{3h_3^2}+\ldots+\dfrac1{nh_n^2}\lt 2.$$。 

L.D.クランドチック

 ## 探検

 しましょう$$S_n=\sum_{k=1}^{n}\frac1{k h_k^2}.$$証明する不等式は、$S_n<2$あらゆる人にとって$n$。 

まずいくつかの項を計算します。$$h_1=1,\qquad h_2=\frac32,\qquad h_3=\frac{11}{6}.$$したがって、$$S_1=1,$$

$$S_2=1+\frac1{2(3/2)^2}=1+\frac29=\frac{11}{9},$$

$$S_3=\frac{11}{9}+\frac1{3(11/6)^2} =\frac{11}{9}+\frac{12}{121}\approx1.322.$$合計はゆっくりと増加するため、伸縮式の推定値が妥当です。 

以来$$h_k-h_{k-1}=\frac1k,$$加数は次のように書き換えることができます$$\frac1{k h_k^2} =\frac{h_k-h_{k-1}}{h_k^2}.$$自然な比較は、$$\frac{h_k-h_{k-1}}{h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k},$$右側が望遠鏡だからです。 チェック中：$$\frac1{h_{k-1}}-\frac1{h_k} = \frac{h_k-h_{k-1}}{h_{k-1}h_k}.$$したがって、必要なのは$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k},$$それは本当です$h_k\ge h_{k-1}$。 

合計すると与えられます$$S_n \le \sum_{k=1}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right),$$しかし$h_0$は定義されていません。 最初の項は分離する必要があります。 

のために$k\ge2$、$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$それから$$S_n = 1+\sum_{k=2}^{n}\frac1{k h_k^2} \le 1+\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = 1+\left(1-\frac1{h_n}\right) = 2-\frac1{h_n}.$$以来$h_n>1$あらゆる人にとって$n\ge2$、これは次の結果をもたらします$S_n<2$。 のために$n=1$、$S_1=1<2$。 

潜在的にデリケートな唯一のステップは、伸縮差との比較です。 

## 問題の理解

 すべての自然数についてそれを証明しなければなりません$n$、$$\sum_{k=1}^{n}\frac1{k h_k^2}<2,$$どこ$$h_k=1+\frac12+\cdots+\frac1k$$です$k$-次高調波番号。 

これはタイプ B の問題であり、純粋な証明です。 

最も難しいのは、因子に関連する伸縮量を認識することです。$1/k=h_k-h_{k-1}$。 被加数を調和数の逆数の伸縮差と比較すると、不等式が続きます。 

## 証明されたアーキテクチャ

 最初の主張は、すべての$k\ge2$、$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$これは以下から導き出されます$h_k-h_{k-1}=1/k$そして不平等$h_{k-1}\le h_k$。 

2 番目の主張は、これらの不等式を合計すると、$k=2$に$n$伸縮シリーズを生産し、$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = 1-\frac1{h_n}.$$標準的な伸縮キャンセルです。 

最後のステップでは、元の合計の最初の項を分離し、前の推定値を適用して、次の値を取得します。$$S_n\le 2-\frac1{h_n}<2.$$精査すると失敗する可能性が最も高い補題は、最初の比較不等式です。これは、自明でない推定全体が含まれているためです。 

## 解決策

 定義する$$S_n=\sum_{k=1}^{n}\frac1{k h_k^2}.$$あらゆる人にとって$k\ge2$、$$h_k-h_{k-1}=\frac1k.$$したがって、$$\frac1{k h_k^2} = \frac{h_k-h_{k-1}}{h_k^2}.$$以来$h_{k-1}\le h_k$、 我々は持っています$$h_{k-1}h_k\le h_k^2,$$したがって$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k}.$$正の量を掛ける$h_k-h_{k-1}$与える$$\frac{h_k-h_{k-1}}{h_k^2} \le \frac{h_k-h_{k-1}}{h_{k-1}h_k}.$$使用する$h_k-h_{k-1}=1/k$、$$\frac1{k h_k^2} \le \frac{h_k-h_{k-1}}{h_{k-1}h_k} = \frac1{h_{k-1}}-\frac1{h_k}.$$この不等式を合計すると、$k=2,3,\ldots,n$を取得します。$$\sum_{k=2}^{n}\frac1{k h_k^2} \le \sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right).$$右側の望遠鏡:$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = \frac1{h_1}-\frac1{h_n} = 1-\frac1{h_n}.$$その結果、$$S_n = \frac1{h_1^2} + \sum_{k=2}^{n}\frac1{k h_k^2} \le 1+\left(1-\frac1{h_n}\right) = 2-\frac1{h_n}.$$もし$n=1$、 それから$S_1=1<2$。 

もし$n\ge2$、 それから$h_n>1$、 それで$$2-\frac1{h_n}<2.$$したがって、すべての場合において$$\sum_{k=1}^{n}\frac1{k h_k^2}<2.$$これで証明は完了です。 

∎

 ## 主要な手順の検証

 重要な推定値は次のとおりです。$$\frac1{k h_k^2} \le \frac1{h_{k-1}}-\frac1{h_k}.$$右側から始めて、$$\frac1{h_{k-1}}-\frac1{h_k} = \frac{h_k-h_{k-1}}{h_{k-1}h_k} = \frac1{k\,h_{k-1}h_k}.$$したがって、推定値は次と同等です。$$\frac1{h_k^2} \le \frac1{h_{k-1}h_k},$$それはまさに次の結果です$h_{k-1}\le h_k$。 隠れた仮定は使用されません。 

伸縮ステップは$$\sum_{k=2}^{n} \left(\frac1{h_{k-1}}-\frac1{h_k}\right) = \left(\frac1{h_1}-\frac1{h_2}\right) +\left(\frac1{h_2}-\frac1{h_3}\right) +\cdots +\left(\frac1{h_{n-1}}-\frac1{h_n}\right).$$中間学期ごとにキャンセルされ、退学します$$\frac1{h_1}-\frac1{h_n}.$$よくある間違いは、合計を次の時点で開始することです。$k=1$、これにより不定量が導入されます。$h_0$。 最初の項を分離すると、この問題は完全に回避されます。 

最後の厳密な不等式では、次のことを確認する必要があります。$$2-\frac1{h_n}<2.$$のために$n\ge2$、$$h_n=1+\frac12+\cdots+\frac1n>1,$$それで$1/h_n>0$。 のために$n=1$、元の合計は以下に等しい$1$。 したがって、次のすべての値は、$n$カバーされています。 

## 代替アプローチ

 加数を次のように書き換えることもできます。$$\frac1{k h_k^2} = \frac{h_k-h_{k-1}}{h_k^2}$$そしてそれを積分と比較します$$\int_{h_{k-1}}^{h_k}\frac{dx}{x^2}.$$以来$x\le h_k$間隔中ずっと$[h_{k-1},h_k]$、$$\int_{h_{k-1}}^{h_k}\frac{dx}{x^2} \ge \frac{h_k-h_{k-1}}{h_k^2} = \frac1{k h_k^2}.$$まとめ$k\ge2$与える$$\sum_{k=2}^{n}\frac1{k h_k^2} \le \int_{1}^{h_n}\frac{dx}{x^2} = 1-\frac1{h_n},$$そして同じ結論が続きます。 

テレスコープ証明は、完全に初等代数の範囲内に留まり、差が加数を支配する量を直接示すため、好ましい。
