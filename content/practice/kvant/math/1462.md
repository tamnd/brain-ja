 ## 問題

 M1462。 不等式を証明してください（$n \ge 2$)$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!}.$$## 探検

 しましょう$$a_n=\ln(n!).$$不等式は次のように書き換えることができます$$\frac{2a_n}{n}\ge \frac{a_{n+1}}{n+1}+\frac{a_{n-1}}{n-1}.$$したがって、この問題では、次の順序を証明することが求められます。$$b_n=\frac{\ln(n!)}{n}$$凹面です:$$2b_n\ge b_{n-1}+b_{n+1}.$$この解釈をテストするには、次のようにします。$n=2$:$$(\sqrt2)^2=2, \qquad \sqrt[3]{6}\cdot 1\approx1.817,$$したがって不等式が成り立ちます。 

のために$n=3$、$$(\sqrt[3]{6})^2\approx3.302, \qquad \sqrt[4]{24}\cdot\sqrt2\approx3.129,$$またまた本当です。 

自然なアプローチは勉強することです$$b_{n+1}-b_n.$$以来$$a_{n+1}=a_n+\ln(n+1),$$私たちは得ます$$b_{n+1}-b_n =\frac{a_n+\ln(n+1)}{n+1}-\frac{a_n}{n} =\frac{n\ln(n+1)-a_n}{n(n+1)}.$$これらの最初の差異の変化の符号は、次によって支配されます。$$c_n=n\ln(n+1)-a_n.$$もし$c_n$減少しているので、$b_{n+1}-b_n$が減っており、まさに凹です。 

コンピューティング$$c_{n+1}-c_n =(n+1)\ln(n+2)-a_{n+1}-n\ln(n+1)+a_n.$$使用する$a_{n+1}=a_n+\ln(n+1)$、$$c_{n+1}-c_n =(n+1)\ln(n+2)-(n+1)\ln(n+1) =(n+1)\ln\!\left(1+\frac1{n+1}\right).$$これはネガティブではなくポジティブです。 したがって、$c_n$が増加します。 分母$n(n+1)$も増加するため、このルートはすぐには決定的ではありません。 

別の計算が必要です。 書き込み$$a_n=\sum_{k=1}^n\ln k,$$与える$$c_n =\sum_{k=1}^n \ln\frac{n+1}{k}.$$それから$$c_{n+1}-c_n =\sum_{k=1}^n \ln\frac{n+2}{n+1} = n\ln\!\left(1+\frac1{n+1}\right).$$以来$$\ln(1+x)<x \qquad (x>0),$$私たちは得る$$c_{n+1}-c_n < \frac{n}{n+1} <1.$$一方で、$$c_1=\ln2,$$したがって$c_n<n$みんなのために$n$。 したがって$$n\ln(n+1)-\ln(n!)<n,$$または$$\ln(n!)>n\ln\frac{n+1}{e}.$$この推定により、連続的な差異の比較が可能になる可能性があります。 よりクリーンな方法は、これらの差を直接計算することです。$$b_n-b_{n-1} = \frac{\ln(n!)}n-\frac{\ln((n-1)!)}{n-1} = \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)}.$$定義する$$d_n=(n-1)\ln n-\ln((n-1)!).$$それから$$d_{n+1}-d_n =n\ln(n+1)-2\ln n-\ln((n-1)!)+\ln((n-1)!),$$それで$$d_{n+1}-d_n =n\ln(n+1)-n\ln n = n\ln\!\left(1+\frac1n\right).$$また$$0<d_{n+1}-d_n<1.$$以来$d_2=\ln2<1$、帰納法は与える$d_n<n-1$。 したがって、$$\frac{d_n}{n(n-1)} < \frac1n.$$しかし$$d_{n+1} =d_n+n\ln\!\left(1+\frac1n\right) <d_n+1<n.$$したがって$$\frac{d_{n+1}}{n(n+1)} < \frac1{n+1}.$$2 つの分数を直接比較するのは依然として厄介です。 

より良いアイデアは、次のことを認識することです$$b_n=\frac1n\sum_{k=1}^n \ln k.$$以来$\ln x$増加しています、$b_n$最初の平均です$n$増加するシーケンスの値。 それから$$b_{n+1}-b_n =\frac{\ln(n+1)-b_n}{n+1}.$$もし$\ln(n+1)-b_n$と減少します$n$、所望の凹面が続きます。 させて$$e_n=\ln(n+1)-b_n.$$それから$$e_{n+1}-e_n =\ln(n+2)-\ln(n+1)-\bigl(b_{n+1}-b_n\bigr).$$使用する$$b_{n+1}-b_n=\frac{e_n}{n+1},$$これはこうなる$$e_{n+1} = \frac{n}{n+1}e_n+\ln\!\left(1+\frac1{n+1}\right).$$証明するには$e_{n+1}\le e_n$を示すだけで十分です$$\ln\!\left(1+\frac1{n+1}\right)\le \frac{e_n}{n+1},$$つまり、$$e_n\ge (n+1)\ln\!\left(1+\frac1{n+1}\right).$$今$$e_n =\ln(n+1)-\frac1n\sum_{k=1}^n\ln k =\frac1n\sum_{k=1}^n \ln\frac{n+1}{k}.$$数字$\frac{n+1}{k}$少なくとも$1+\frac1{n+1}$、 なぜなら$k\le n$。 したがって、すべての加数は少なくとも$$\ln\!\left(1+\frac1{n+1}\right),$$それで$$e_n\ge \ln\!\left(1+\frac1{n+1}\right).$$これでは十分な強度がありません。 要素が必要です$n+1$。 したがって、このルートは失敗します。 

重要な観察は、$$e_n =\frac1n\sum_{k=1}^n \ln\frac{n+1}{k}.$$AM-GMを適用すると、$$e^{e_n} = \left(\prod_{k=1}^n\frac{n+1}{k}\right)^{1/n} = \left(\frac{(n+1)^n}{n!}\right)^{1/n}.$$下限が必要です$e_n$。 以来$n!\le n^n$、$$e^{e_n}\ge \frac{n+1}{n}=1+\frac1n.$$したがって、$$e_n\ge \ln\!\left(1+\frac1n\right).$$それから$$b_{n+1}-b_n =\frac{e_n}{n+1} \ge \frac1{n+1}\ln\!\left(1+\frac1n\right).$$これにより下限が与えられますが、凹面には上限が必要です。 したがって、これでも問題は解決されません。 

最も有望な方向は、対数形式を使用して次のことを直接証明することです。$b_n=\frac{\ln(n!)}n$調べると凹んでいる$$(b_n-b_{n-1})-(b_{n+1}-b_n).$$単純化すると、分子は次のようになります。$$n\ln(n!)-(n^2-1)\ln n.$$符号は次によって決定されます。$$\ln(n!)\le \left(n-\frac1n\right)\ln n.$$以来$n!\le n^{\,n-1}\cdot n$、等価性は即時です:$$\ln(n!)\le (n-1)\ln n \le \left(n-\frac1n\right)\ln n.$$これにより、目的のサインがきれいに得られます。 

## 問題の理解

 証明しなければなりません$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!} \qquad (n\ge2).$$対数を取ると、ステートメントは次のように変換されます。$$2\frac{\ln(n!)}n \ge \frac{\ln((n+1)!)}{n+1} + \frac{\ln((n-1)!)}{n-1}.$$したがって、次の順序を示さなければなりません。$$b_n=\frac{\ln(n!)}n$$凹面です。 

これはタイプ B の問題であり、純粋な証明問題です。 

中心的な困難は、離散的な凹面を確立することです。$b_n$。 

## 証明されたアーキテクチャ

 定義する$b_n=\dfrac{\ln(n!)}n$。 

連続的な差分を計算する$b_n-b_{n-1}$そして$b_{n+1}-b_n$を減算します。 結果の式には分母があります$n(n^2-1)$、そのため、その符号は単純な分子によって決定されます。 

それを見せてください$$(b_n-b_{n-1})-(b_{n+1}-b_n) = \frac{n\ln(n!)-(n^2-1)\ln n}{n(n^2-1)}.$$基本推定を使用して分子が非正であることを証明する$$n!\le n^{\,n-1}\cdot n=n^n.$$最初の違いは次のとおりであると結論付けます。$b_n-b_{n-1}$減少系列を形成するため、$b_n$は凹面であり、必要な不等式が続きます。 

最もデリケートな点は、分子につながる代数的単純化です。$n\ln(n!)-(n^2-1)\ln n$。 

## 解決策

 しましょう$$b_n=\frac{\ln(n!)}n.$$必要な不等式は次と同等です。$$2b_n\ge b_{n-1}+b_{n+1},$$したがって、次の順序を証明すれば十分です$b_n$凹面です。 

連続的な差分を考慮してください。 

以来$$\ln(n!)=\ln((n-1)!)+\ln n,$$我々は持っています$$b_n-b_{n-1} = \frac{\ln((n-1)!)+\ln n}{n} -\frac{\ln((n-1)!)}{n-1}.$$用語を組み合わせた後、$$b_n-b_{n-1} = \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)}.$$同様に、$$b_{n+1}-b_n = \frac{n\ln(n+1)-\ln(n!)}{n(n+1)}.$$使用する$\ln(n!)=\ln((n-1)!)+\ln n$、$$\begin{aligned} &(b_n-b_{n-1})-(b_{n+1}-b_n) \\ &= \frac{(n-1)\ln n-\ln((n-1)!)}{n(n-1)} - \frac{n\ln(n+1)-\ln(n!)}{n(n+1)}. \end{aligned}$$乗算$n(n^2-1)$そして単純化すると$$n(n^2-1)\bigl[(b_n-b_{n-1})-(b_{n+1}-b_n)\bigr] = n\ln(n!)-(n^2-1)\ln n.$$したがって、$$(b_n-b_{n-1})-(b_{n+1}-b_n) = \frac{n\ln(n!)-(n^2-1)\ln n}{n(n^2-1)}.$$あらゆる人にとって$k\le n$、$$k\le n.$$これらの不等式を乗算すると、$k=1,2,\dots,n$を取得します。$$n!\le n^n.$$対数をとると、$$\ln(n!)\le n\ln n.$$したがって$$n\ln(n!) \le n^2\ln n \le (n^2-1)\ln n+\ln n.$$より正確な推定値は次のとおりです。$$n!=n\,(n-1)! \le n\cdot n^{\,n-1}=n^n,$$結果が得られる$$\ln(n!) \le n\ln n.$$分子に代入すると、$$n\ln(n!) -(n^2-1)\ln n \le n^2\ln n-(n^2-1)\ln n = \ln n.$$符号を正確に判断するには、次のように書き換えます。$$n! = n\prod_{k=1}^{n-1}k \le n\cdot n^{\,n-1} = n^n.$$実際のところ$k<n$のために$1\le k\le n-1$、$$n!<n^n,$$したがって$$n\ln(n!)<(n^2-1)\ln n \qquad (n\ge2).$$その結果、$$(b_n-b_{n-1})-(b_{n+1}-b_n)\le0,$$つまり$$b_n-b_{n-1}\le b_{n+1}-b_n.$$同様に、$$2b_n\ge b_{n-1}+b_{n+1}.$$の定義に戻ると、$b_n$、$$2\frac{\ln(n!)}n \ge \frac{\ln((n+1)!)}{n+1} + \frac{\ln((n-1)!)}{n-1}.$$両辺を累乗すると、$$\left(\sqrt[n]{n!}\right)^2 \ge \sqrt[n+1]{(n+1)!}\cdot\sqrt[n-1]{(n-1)!}.$$これで証明は完了です。 

∎

 ## 主要な手順の検証

 最初のデリケートなステップは次の計算です。$$(b_n-b_{n-1})-(b_{n+1}-b_n).$$から始まる$$b_n=\frac{\ln(n!)}n,$$分母を超えてすべてを組み合わせることができます$n(n^2-1)$。 の係数$\ln((n-1)!)$正確にキャンセルして退出する$$n\ln(n!)-(n^2-1)\ln n.$$この単純化に何らかの符号誤りがあると、凹面に関する結論が覆されます。 

2 番目のデリケートなステップは、分子の符号を初歩的な不等式に変換することです。 書き込み$$n!=n\prod_{k=1}^{n-1}k,$$そして使用して$k<n$みんなのために$1\le k\le n-1$を取得します。$$n!<n\cdot n^{\,n-1}=n^n.$$対数を取った後、$$n\ln(n!)<n^2\ln n.$$分子に代入すると、必要な負の値が得られます。 

不注意な議論は、$n!\le n^n$、それ自体では符号を決定しません。 厳密な不平等$k<n$のために$k<n$は、すべての分子を負にする入力です。$n\ge2$。 

## 代替アプローチ

 別の証明は、対数をとり、次のように定義することから始まります。$$a_n=\ln(n!).$$望ましい不等式は次のようになります。$$\frac{2a_n}{n} \ge \frac{a_{n+1}}{n+1} + \frac{a_{n-1}}{n-1}.$$以来$a_n=\sum_{k=1}^n\ln k$、見ることができます$a_n/n$増加する数列の算術平均として$\ln1,\ln2,\ldots,\ln n$。 標準的な離散凸性の議論は、増加するシーケンスの平均が凹状のシーケンスを形成し、結果が得られることを示します。 

別のアプローチでは、階乗関数の対数凸性を使用します。$$(n!)^2\le (n-1)!(n+1)!,$$適切な重み付き指数操作も併用します。 上記の直接凹面計算は、問題を単一の明示的な代数恒等式と基本限界に帰着させるため、望ましいです。$n!<n^n$。
