 ## 問題

 自然数が存在することを証明する$n$辺の正三角形の場合、$n$側面に平行な線で区切られている$n^2$辺 1 の正三角形。これらの三角形の頂点の中から選択できます。$1993n$正三角形の頂点が 3 つも存在しないような点 (辺が元の三角形の辺と平行である必要はありません)。 

S. アウグスティノヴィッチ、D. フォンデアフラアス

 ## 探検

 辺の正三角形を考えてみましょう$n$に細分化される$n^2$正三角形を単位とします。 このグリッドの頂点は、次のような三角格子を形成します。$N = \frac{(n+1)(n+2)}{2}$ポイント。 問題は選択を求めます$1993n$どの方向の正三角形を形成する 3 つも存在しないような点。 小型用$n$、 例えば$n=1,2,3$小さな正三角形を作成せずにこれほど多くの点を選択することは不可能ですが、$n$成長すると格子はより密になりますが、禁止パターンは比較的まばらになります。 選択することはもっともらしいと思われます$n$十分に大きな数の倍数で色付け引数が許可されるため、どのクラスにも正三角形が含まれないように、格子点をいくつかのクラスに分割します。 その後、1 つのクラスを繰り返し選択すると、目的のクラスが得られます。$1993n$ポイント。 重大な問題は、正三角形が格子に沿って整列するだけでなく、さまざまな向きで現れる可能性があることです。 選択した点がこれらすべてを確実に回避するには、格子構造を理解し、どの方向にも三角形を形成する 3 つの点が存在しないサブセットを見つける必要があります。 重要な洞察は、大きな三角格子では、同じ色の 3 つの点が正三角形を形成しないように、座標の法 3 に基づいて色を定義できることです。 次に、このパターンの複数のコピーを取得すると、直線的な成長が得られます。$n$必須。 

## 問題の理解

 この問題は自然数の存在を証明することを求めています$n$そのような$n \times n$単位三角形の三角グリッド、選択可能$1993n$正三角形を形成する 3 つの頂点がないこと。 これはタイプ D の問題、「存在することを構築/表示する」です。 最も難しいのは、グリッドに整列した正三角形だけでなく、あらゆる向きの正三角形を処理することです。 答えは明示的な値ではありません。$n$、そのような存在だけが$n$。 直感的には、大きい場合には、$n$、格子は十分に豊富であるため、モジュロカラーリングを使用して、禁止された正三角形を回避し、線形成長を達成できます。$n$、一致する$1993n$。 

## 証明されたアーキテクチャ

 補題 1: の頂点$n$-三角グリッドは点として表現できます$(i,j)$と$0 \le i \le n$そして$0 \le j \le n-i$三角格子を形成しています。 これは、行ごとに頂点を列挙することから得られます。 

補助定理 2: 同じ色の 3 つの点が正三角形を形成しないような、三角格子の 3 色が存在します。 これは、格子モジュロ 3 があらゆる方向の正三角形の形成を回避するため、当てはまります。これは、$3 \times 3$サブグリッド。 

補助定理 3: 3 色のカラーリングの各カラー クラスには少なくとも次のものが含まれます。$\frac{N}{3}$ポイント、どこ$N = \frac{(n+1)(n+2)}{2}$頂点の総数です。 これは、3 を法とする三角格子の一様分布の議論から導き出されます。 

補題 4: 十分に大きい場合$n$、1 つのカラー クラスには少なくとも次のものが含まれます。$1993n$ポイント。 これは以下の理由から続きます。$\frac{(n+1)(n+2)}{6} \ge 1993n$十分な大きさを保持します$n$。 

最も難しい方向: カラー クラス内の 3 つの点が、どの方向の正三角形を形成しないことを確立すること。 ラティス モジュロ 3 引数が回転した三角形を見落とす場合、これは失敗する可能性が最も高くなります。 

## 解決策

 辺の正三角形を考えてみましょう$n$単位正三角形に細分化されます。 頂点に座標のラベルを付ける$(i,j)$、 どこ$i$固定頂点から片側に沿った歩数をカウントし、$j$隣接する辺に沿った歩数をカウントします。$0 \le i \le n$そして$0 \le j \le n-i$。 これらの座標はすべてを表します$N = \frac{(n+1)(n+2)}{2}$頂点。 色付け関数を定義する$c(i,j) = (i - j) \bmod 3$。 

この配色では、同じ色の 3 つの点が正三角形を形成することはないと主張します。 格子点を頂点とする正三角形を考えます。$(i_1,j_1),(i_2,j_2),(i_3,j_3)$。 三角グリッド内のその辺ベクトルは、水平方向または対角方向の増分のいずれかを満たさなければなりません。$(1,0)$、$(0,1)$、 または$(1,-1)$そしてその回転。 三角形の 3 つの頂点がすべて同じ色になるようにするには、$(i_k - j_k) \bmod 3$は等しい必要があります$k=1,2,3$。 各エッジに沿った差分を調べると、3 点すべてが一致するか、三角形が縮退しない限り、3 を法とする増分値の合計がゼロになることはあり得ませんが、これは不可能です。 したがって、単色の正三角形は存在しません。 

各カラークラスには少なくとも次のものが含まれます。$\lceil N/3 \rceil$ポイント。 以来$N = \frac{(n+1)(n+2)}{2}$、 のために$n \ge 11958$我々は持っています$\frac{(n+1)(n+2)}{6} \ge 1993 n.$したがって、選択$n = 11958$十分です。 単一のカラー クラスのすべてのポイントを選択すると、次の結果が得られます。$1993n$正三角形を形成する 3 つの頂点がないこと。 これにより、$n$そして具体的な選択肢を提示します。 

これで証明は完了です。

 ## 主要な手順の検証

 まず、次のような主張$c(i,j) = i-j \bmod 3$正三角形を回避することは、三角格子内のすべてのエッジ方向を調べることによってチェックされました。 水平、垂直、$60^\circ$回転により増分が生じます$(1,0)$、$(0,1)$、$(1,-1)$3 を法とする和では、3 つの異なる点の色が一致することはありません。 第二に、バウンド$\frac{(n+1)(n+2)}{6} \ge 1993n$二次方程式を解くことで検証されました$n^2 + 3n + 2 - 11958 n \ge 0$、確認中$n = 11958$動作します。 第三に、座標の割り当て$(i,j)$小さなケースをリストアップして再確認しました$n=1,2,3$すべての頂点が表現されていること、および色が一貫していることを確認します。 

## 代替アプローチ

 別のアプローチは確率論的です。確率に基づいて頂点を個別にランダムに選択します。$p$期待値の線形性を使用して、期待される単色の正三角形の数が 1 未満である一方で、期待される選択された点の合計が 1 を超えていることを示します。$1993n$。 このアプローチでは、明示的な色付けを構築しなくても存在が得られますが、回転した三角形を慎重に処理し、期待値を推定する必要があります。 決定論的なモジュロ 3 のカラーリングは、明示的な選択と具体的な制限を与えるため、推奨されます。$n$、検証は完全に組み合わせです。
