 ## 問題

 中心のある円の上に$O$、ポイント$A$そして$B$が位置しています。 ポイント$P$円弧の小さい方の上にあります$AB$、ポイント$Q$そして$R$点対称である$P$ラインに関しては$OA$そして$OB$それぞれ、そして$P'$セグメントの交点です$AR$そして$BQ$。 その点を証明してください$P$そして$P'$線に対して対称である$AB$。

## 問題の理解

 中心を通る線に反射がある円の幾何学的対称性を証明するように求められます。 ポイント$Q$そして$R$の反映として定義されます$P$線を越えて$OB$そして$OA$、 そして$P'$の交差点です$AR$そして$BQ$。 問題の種類はタイプBの「[ステートメント]を証明せよ」です。 最も難しいのは、これら 2 つのセグメントの交差点が、直線上の反射を介して構築されていることを示すことです。$O$、まさにそれを反映しています。$P$和音の上で$AB$。 重要な洞察は、反射と交差が線対称性と中心性を尊重しているということです。$O$乱雑な座標の代わりに線対称引数を使用できるようになります。 

## 証明されたアーキテクチャ

 補助定理 1: 円の中心を通る線の上での点の反射は、円を保存する線形変換と同等です。 これは、中心を通る線が直径を定義し、その線を横切る反射が直径に沿った中心対称であるため、当てはまります。 

補助定理 2: 線$AR$そして$BQ$点で交差する$P'$誰の反省$AB$と一致する$P$。 これは次のことを意味します。$OA$そして$OB$線間の角度を維持する$O$、および反射点から までの線の交点$A$そして$B$～の反映と一致する$P$横切って$AB$。 

最も難しいステップは補題 2 です。ここでは、座標またはベクトル ジオメトリを注意深く適用して、交差部分が例外なく望ましい対称性を実際に生成することを確認する必要があります。 

## 解決策

 円を座標平面に配置します。$O$原点で。 させて$A=(1,0)$そして$B=(-1,0)$となることによって$AB$に沿ってあります$x$-軸。 仮定する$P$座標があります$P=(\cos \theta, \sin \theta)$と$0<\theta<\pi$より小さい円弧上にあることを確認するため$AB$。 の反省$P$オーバーライン$OA$($x$-軸貫通$A$) はラインを反射することによって得られます。$x=1$。 垂直線上の反射式$x=a$与える$R = (2a - x_P, y_P) = (2 - \cos \theta, \sin \theta)$。 同様に、$P$オーバーライン$OB$(行$x=-1$) を与えます$Q = (-2 - \cos \theta, \sin \theta)$。 

ライン$AR$通り抜ける$A=(1,0)$そして$R=(2-\cos \theta, \sin \theta)$。 その傾きは$m_{AR} = \frac{\sin \theta - 0}{(2 - \cos \theta) - 1} = \frac{\sin \theta}{1 - \cos \theta +1} = \frac{\sin \theta}{1 - \cos \theta + 1}.$慎重に計算してください:$(2-\cos \theta) - 1 = 1 - \cos \theta$。 したがって$m_{AR} = \frac{\sin \theta}{1 - \cos \theta}$。 直線方程式は$y = \frac{\sin \theta}{1 - \cos \theta} (x - 1)$。 

ライン$BQ$通り抜ける$B=(-1,0)$そして$Q=(-2 - \cos \theta, \sin \theta)$。 その傾きは$m_{BQ} = \frac{\sin \theta - 0}{(-2 - \cos \theta) - (-1)} = \frac{\sin \theta}{-1 - \cos \theta} = -\frac{\sin \theta}{1 + \cos \theta}$。 その方程式は$y = -\frac{\sin \theta}{1 + \cos \theta} (x + 1)$。 

交差点$P'=(x',y')$満足する$\frac{\sin \theta}{1 - \cos \theta} (x' - 1) = -\frac{\sin \theta}{1 + \cos \theta} (x' + 1).$両辺を次で割ります$\sin \theta \neq 0$:$\frac{x' - 1}{1 - \cos \theta} = -\frac{x' + 1}{1 + \cos \theta}.$相互乗算:$(x' - 1)(1 + \cos \theta) = -(x' + 1)(1 - \cos \theta).$拡大する：$x' (1 + \cos \theta) - (1 + \cos \theta) = -x'(1 - \cos \theta) - (1 - \cos \theta).$全部持ってきて$x'$一方には項、もう一方には定数:$x'(1 + \cos \theta + 1 - \cos \theta) = (1 + \cos \theta - 1 + \cos \theta) = 2\cos \theta.$したがって$2 x' = 2 \cos \theta \implies x' = \cos \theta = x_P$。 

今$y' = \frac{\sin \theta}{1 - \cos \theta} (x' - 1) = \frac{\sin \theta}{1 - \cos \theta} (\cos \theta - 1) = -\sin \theta = -y_P$。 

したがって$P' = (x_P, -y_P)$、まさにそれを反映しています。$P$向こう側$x$-軸、線と一致$AB$。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、次の交差方程式を解くことです。$x'$。 不注意に拡張するとサインインを見逃す可能性があります$-(x' + 1)(1 - \cos \theta)$、不正確な結果につながります$x'$価値。 最初から再計算して確認する$x'(1 + \cos \theta + 1 - \cos \theta) = 2 x'$そして解決策$x' = \cos \theta$。 傾きの計算$AR$そして$BQ$明示的に座標を代入し、分子と分母の違いをチェックすることで検証されました。 最後に、$y'$計算は独立して再計算され、$y' = -y_P$。 

## 代替アプローチ

 純粋に合成的なアプローチでは、中心を通る線での反射が角度を維持するという事実を利用します。$O$そしてその円をそれ自体にマッピングします。 四角形を作ることで$ARPB$そして$BQPA$、交差点は次のように主張できます。$P'$～の反省に基づいていなければならない$P$以上$AB$周期的なプロパティと角度の追跡を使用します。 座標を使用する主なアプローチは、角度追跡における微妙なエラーを回避し、明示的な検証を保証するため、推奨されます。$x'$そして$y'$曖昧さなく。
