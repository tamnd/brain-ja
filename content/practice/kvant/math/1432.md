 ## 問題

 任意の正の数列についてそれを証明してください$a_n$、数値の平方根の整数部分$$b_n=(a_1+a_2+\ldots+a_n)\left(\dfrac{1}{a_1}+\dfrac{1}{a_2}+\ldots+\dfrac{1}{a_n}\right)$$はすべて異なります。 

L.D.クリランドチク

 ## 探検

 一連の正の数を考えてみましょう$a_1, a_2, \dots$。 定義する$b_n = (a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right).$小さなケースを計算してその動作を理解します。 のために$n=1$、$b_1 = a_1 \cdot \frac{1}{a_1} = 1$。 のために$n=2$、 もし$a_1 = 1$、$a_2 = 1$、 それから$b_2 = (1+1)(1 + 1) = 4$。 もし$a_1 = 1$、$a_2 = 2$、 それから$b_2 = (1+2)(1 + 1/2) = 3 \cdot 1.5 = 4.5$、整数部分$4$。 のために$n=3$、 選ぶ$a_1 = a_2 = a_3 = 1$、 それから$b_3 = 3 \cdot 3 = 9$。 選択する$a_1 = 1$、$a_2 = 2$、$a_3 = 3$、 我々は持っています$b_3 = 6 \cdot (1 + 1/2 + 1/3) = 6 \cdot \frac{11}{6} = 11$、整数部分$11$。 

整数部分が大きくなり、区別して表示されます。 数量$b_n$は離散コーシー-シュワルツ不等式に似ています。$(a_1 + \dots + a_n)(1/a_1 + \dots + 1/a_n) \ge n^2$、すべての場合にのみ等しい$a_i$等しいです。 これは示唆します$b_n$大きくなり、前の整数に戻ることはできません。 

主な困難は、2 つの数が存在しないことを証明することです。$b_m$そして$b_n$同じ整数部分を共有する$m \neq n$、ポジティブの選択に関係なく、$a_i$。 

## 問題の理解

 この問題では、任意の正の数列についてそれを示すことが求められます。$a_n$、整数部分$\lfloor \sqrt{b_n} \rfloor$シーケンスの$b_n = (a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right)$はすべて異なります。 これはタイプ B の問題です。分類や最適化を行わずにステートメントを証明するように求められます。 

最も難しいのは、シーケンスが先行するシーケンスと比較して十分に速く成長し、平方根の整数部分が増加し、整数が繰り返されないことを示すことです。 重要な洞察は不平等です$b_{n+1} > b_n$, しかし、整数部分が決して一致しないことを保証するには、より強い不等式も証明する必要があります。 コーシー-シュワルツの不等式は下限を提供します$b_n \ge n^2$、整数部分を分離するのに役立つ場合があります。 

## 証明されたアーキテクチャ

 補題 1: 任意の正の数列について$a_1, \dots, a_n$、$b_n \ge n^2,$すべてが平等である場合に限り、$a_i$等しいです。 これは、コーシー-シュワルツの不等式が適用されることから導き出されます。$(\sqrt{a_1}, \dots, \sqrt{a_n})$そして$(1/\sqrt{a_1}, \dots, 1/\sqrt{a_n})$。 

補題 2: 任意の正の数について$a_{n+1}$、$b_{n+1} > b_n.$これは、増分を考慮すると次のようになります。$(a_1 + \dots + a_n + a_{n+1})(1/a_1 + \dots + 1/a_n + 1/a_{n+1}) - (a_1 + \dots + a_n)(1/a_1 + \dots + 1/a_n)$そして、そのポジティブさを利用して、$a_{n+1}$そして凸状の構造。 

補題 3: もし$b_{n+1} > b_n$、 それから$\lfloor \sqrt{b_{n+1}} \rfloor \ge \lfloor \sqrt{b_n} \rfloor$。 これは、フロア関数の単調性から自明です。 

補題 4 (主要な補題): 増分$b_{n+1} - b_n < 2\sqrt{b_n} + 1$不可能です。 同様に、平方根の整数部分も一定に保つことはできません。連続する正方形の間の距離は少なくとも$2\lfloor \sqrt{b_n} \rfloor + 1$これにより、整数部分が明確に区別されます。 これには、成長を注意深く分析する必要があります。$b_n$。 

最も難しいステップは補助定理 4 です。これは、任意の正のシーケンスの整数部分の繰り返しを防ぐのに十分な増加であることを示す必要があるためです。 

## 解決策

 まず補題 1 を確立します。コーシー＝シュワルツによると、$(a_1 + \dots + a_n)\left(\frac{1}{a_1} + \dots + \frac{1}{a_n}\right) \ge \left(\sqrt{a_1 \cdot \frac{1}{a_1}} + \dots + \sqrt{a_n \cdot \frac{1}{a_n}}\right)^2 = n^2,$等しい場合のみ$\sqrt{a_i} / (1/\sqrt{a_i})$すべての人にとって一定です$i$、つまり、$a_1 = \dots = a_n$。 したがって$b_n \ge n^2$。 

補題 2 を証明するには、次のように書きます。$$b_{n+1} - b_n = (a_1 + \dots + a_n + a_{n+1})\left(\sum_{i=1}^{n} \frac{1}{a_i} + \frac{1}{a_{n+1}}\right) - (a_1 + \dots + a_n)\sum_{i=1}^{n} \frac{1}{a_i}.$$展開すると、$$b_{n+1} - b_n = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + (a_1 + \dots + a_n)\frac{1}{a_{n+1}} + a_{n+1}\frac{1}{a_{n+1}} = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + \frac{a_1 + \dots + a_n}{a_{n+1}} + 1.$$以来$a_i > 0$、各項は正であるため、$b_{n+1} - b_n > 0$、補題 2 を証明します。 

補助定理 3 は、床関数の単調性と次の事実から導かれます。$b_{n+1} > b_n$暗示する$\sqrt{b_{n+1}} > \sqrt{b_n}$したがって、$\lfloor \sqrt{b_{n+1}} \rfloor \ge \lfloor \sqrt{b_n} \rfloor$。 

補題 4 を証明するには、矛盾により次のように仮定します。$\lfloor \sqrt{b_{n+1}} \rfloor = \lfloor \sqrt{b_n} \rfloor = k$ある整数に対して$k$。 それから$k^2 \le b_n < (k+1)^2$そして$k^2 \le b_{n+1} < (k+1)^2$、つまり$b_{n+1} - b_n < (k+1)^2 - k^2 = 2k + 1$。 

ただし、前回の展開から、$$b_{n+1} - b_n = a_{n+1}\sum_{i=1}^{n} \frac{1}{a_i} + \frac{a_1 + \dots + a_n}{a_{n+1}} + 1 \ge 2 \sqrt{(a_1 + \dots + a_n)\sum_{i=1}^{n} \frac{1}{a_i}} + 1 = 2 \sqrt{b_n} + 1,$$2 つの正の数に適用される算術幾何平均不等式による$a_{n+1}\sum_{i=1}^{n} 1/a_i$そして$(a_1 + \dots + a_n)/a_{n+1}$。 以来$b_n \ge n^2 \ge 1$、ということになります。$2\sqrt{b_n} + 1 > 2k + 1$、矛盾です。 したがって、整数部分を増やす必要があります。 

その結果、整数部分は$\lfloor \sqrt{b_n} \rfloor$厳密に増加します$n$したがって、区別されます。 

これで証明は完了です。
