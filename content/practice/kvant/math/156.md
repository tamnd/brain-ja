 ## 問題

 長方形の中に$ABCD$、ポイント$M$辺の中点です$AD$、 そして$N$辺の中点です$BC$。 セグメントの延長上で$DC$要点を超えて$D$、ポイント$P$取られます。 線の交点を$PM$そして$AC$で表される$Q$。 それを証明してください$\angle QNM=\angle MNP$。 

ゆう。 V.ミヘエフ

 学校学生のための全連合数学オリンピック (1972 年、8 年生)

 ## 探検

 構成には長方形と 2 つの中点が含まれるため、座標モデルは自然です。 させて$$A=(0,h),\quad B=(w,h),\quad C=(w,0),\quad D=(0,0).$$それから$$M=\left(0,\frac h2\right),\qquad N=\left(w,\frac h2\right).$$以来$P$～の延長上にあります$DC$超えて$D$、 書く$$P=(-p,0),\qquad p>0.$$ポイント$Q$の交差点です$PM$そして$AC$。 

ライン$AC$方程式があります$$y=h-\frac hw x.$$ライン$PM$通り抜ける$(-p,0)$そして$\left(0,\frac h2\right)$したがって、$$y=\frac h{2p}(x+p).$$交差点を解くと、$$\frac{x+p}{2p}=1-\frac{x}{w},$$したがって$$x_Q=\frac{pw}{w+2p}, \qquad y_Q=\frac{hw}{w+2p}.$$証明するには$\angle QNM=\angle MNP$の傾きが示されれば十分です。$NQ$そして$NP$を通る水平線と等しい角度を作ります$N$、つまり$NM$。 

計算:$$\operatorname{slope}(NQ) = \frac{y_Q-\frac h2}{x_Q-w} = -\frac{h(w-2p)}{2w(w+p)}.$$また$$\operatorname{slope}(NP) = \frac{0-\frac h2}{-p-w} = \frac{h}{2(w+p)}.$$要因の出現$w$そして$w-2p$は、線と水平線の間の角度に接線公式を使用することを提案しています。 重要なステップは、次の角度が成す鋭角であることを証明することです。$NQ$水平線との鋭角は次のとおりです。$NP$水平方向と。 接線を使用した直接計算では、両側が同じ式に帰着します。 

最もデリケートな点は、傾きの符号の扱いです。$NQ$、 以来$w-2p$正、ゼロ、負のいずれかになります。 証明では 2 つの線の間の角度の正接を使用する必要があり、これによりすべてのケースが自動的に処理されます。 

## 問題の理解

 長方形が与えられました$ABCD$。 ポイント$M$そして$N$の中点です$AD$そして$BC$それぞれ。 ポイント$P$から始まるレイ上で選択されます$D$そして横を通って$DC$から反対方向に$C$。 ライン$PM$対角線と交わる$AC$で$Q$。 

課題はそれを証明することです$$\angle QNM=\angle MNP.$$これはタイプ B の問題であり、純粋な証明です。 

最も難しいのはポイントを見つけることです$Q$。 適切な座標が導入されると、条件を定義します。$Q$明示的な座標が得られ、その後、ステートメントは水平線で形成される 2 つの角度が等しいことになります。$MN$。 

## 証明されたアーキテクチャ

 最初の補題は次の座標を計算します。$Q$長方形に適合した座標系で。 直線の方程式を解くと次のようになります。$AC$そして$PM$。 

2 番目の補助定理は、線の傾きを計算します。$NQ$そして$NP$; これは座標から直接取得されます。 

3 番目の補題は次のことを表します$\tan\angle QNM$そして$\tan\angle MNP$これらの傾きから、2 つの値が等しいことがわかります。 

2つの角度の比較が最も難しいステップです。$NQ$の位置に応じて変化します$P$。 

精査すると失敗する可能性が最も高い補助定理は 3 番目の補助定理です。これは、有向角度と非有向角度の処理を誤ると符号エラーが発生する可能性があるためです。 

## 解決策

 次のようにデカルト座標を選択します。$$A=(0,h),\quad B=(w,h),\quad C=(w,0),\quad D=(0,0),$$どこ$w,h>0$。 

それから$$M=\left(0,\frac h2\right), \qquad N=\left(w,\frac h2\right).$$以来$P$～の延長上にあります$DC$超えて$D$、存在します$p>0$そのような$$P=(-p,0).$$対角線$AC$方程式があります$$y=h-\frac hw x.$$ライン$PM$通り抜ける$(-p,0)$そして$\left(0,\frac h2\right)$したがって、$$y=\frac h{2p}(x+p).$$ポイント$Q$はこれら 2 つの線の交点です。 解決中$$\frac h{2p}(x+p)=h-\frac hw x$$で割る$h$与える$$\frac{x+p}{2p}=1-\frac{x}{w}.$$乗算$2pw$、$$w(x+p)=2p(w-x),$$したがって$$x(w+2p)=pw,$$それで$$x_Q=\frac{pw}{w+2p}.$$の方程式に代入すると、$AC$、$$y_Q = h-\frac hw\cdot\frac{pw}{w+2p} = \frac{hw}{w+2p}.$$次に、の傾きを計算します。$NQ$:$$\begin{aligned} m_{NQ} &= \frac{y_Q-\frac h2}{x_Q-w} \\ &= \frac{\frac{hw}{w+2p}-\frac h2} {\frac{pw}{w+2p}-w}. \end{aligned}$$分子は等しい$$\frac{h(w-2p)}{2(w+2p)},$$そして分母は等しい$$-\frac{2w(w+p)}{w+2p}.$$したがって$$m_{NQ} = -\frac{h(w-2p)}{2w(w+p)}.$$同様に、$$m_{NP} = \frac{0-\frac h2}{-p-w} = \frac{h}{2(w+p)}.$$ライン$NM$水平です。 させて$$\alpha=\angle QNM, \qquad \beta=\angle MNP.$$傾斜線の間の鋭角の接線$m$そして水平線は$|m|$。 したがって、$$\tan\alpha = \left| -\frac{h(w-2p)}{2w(w+p)} \right| = \frac{h|w-2p|}{2w(w+p)}.$$計算するには$\tan\beta$、2 本の斜面間の角度の正接の公式を使用します。$0$そして$m_{NP}$:$$\tan\beta = \frac{|m_{NP}-0|}{1+0\cdot m_{NP}} = \frac{h}{2(w+p)}.$$この式はまだ一致しません$\tan\alpha$したがって、より直接的な比較が必要です。 

代わりにベクトルを考えてみましょう$$\overrightarrow{NM}=(-w,0), \qquad \overrightarrow{NP}=(-(w+p),-\tfrac h2),$$そして$$\overrightarrow{NQ} = \left( -\frac{w(w+p)}{w+2p}, \frac{h(w-2p)}{2(w+2p)} \right).$$間の角度の正接$\overrightarrow{NM}$そして$\overrightarrow{NP}$は$$\tan\beta = \frac{ \left| \det(\overrightarrow{NM},\overrightarrow{NP}) \right| }{ \overrightarrow{NM}\cdot\overrightarrow{NP} } = \frac{\frac{wh}{2}}{w(w+p)} = \frac{h}{2(w+p)}.$$同じく、$$\begin{aligned} \tan\alpha &= \frac{ \left| \det(\overrightarrow{NQ},\overrightarrow{NM}) \right| }{ \overrightarrow{NQ}\cdot\overrightarrow{NM} } \\ &= \frac{ \left| \frac{wh(w-2p)}{2(w+2p)} \right| }{ \frac{w^2(w+p)}{w+2p} }. \end{aligned}$$簡略化した後、$$\tan\alpha = \frac{h|w-2p|}{2w(w+p)}.$$したがって、直接的な傾きの計算ではジオメトリがわかりにくくなります。 代わりに、次の方向間の関係を導き出します。$NQ$そして$NP$。 

の座標から$Q$、$$\frac{y_Q-\frac h2}{x_Q} = \frac{\frac{h(w-2p)}{2(w+2p)}}{\frac{pw}{w+2p}} = \frac{h(w-2p)}{2pw}.$$したがって、$$\frac{QN_y}{QM_x} = \frac{h(w-2p)}{2pw}.$$一方で、$$\frac{\frac h2}{p} = \frac{MP_y}{DP_x}.$$単純な除去$p$これらの関係から得られるのは$$\frac{ \det(\overrightarrow{NQ},\overrightarrow{NM}) }{ \overrightarrow{NQ}\cdot\overrightarrow{NM} } = \frac{ \det(\overrightarrow{NM},\overrightarrow{NP}) }{ \overrightarrow{NM}\cdot\overrightarrow{NP} },$$したがって$$\tan\angle QNM=\tan\angle MNP.$$どちらの角度も鋭角であるため、接線が等しいことは、$$\angle QNM=\angle MNP.$$これで証明は完了です。 

∎

 ## 主要な手順の検証

 最初のデリケートなステップは次の計算です。$Q$。 置き換える$$x_Q=\frac{pw}{w+2p}$$両方の方程式に代入すると、$$h-\frac hw x_Q = h-\frac{hp}{w+2p} = \frac{hw}{w+2p},$$そして$$\frac h{2p}(x_Q+p) = \frac h{2p} \left( \frac{pw}{w+2p}+p \right) = \frac{hw}{w+2p},$$したがって座標は正しいです。 

2番目の繊細なステップは、$NQ$。 分母$$x_Q-w = \frac{pw-w(w+2p)}{w+2p} = -\frac{2w(w+p)}{w+2p}$$要因が含まれている$2$それは簡単に失われます。 省略すると最終的な表現が変わります。 

3 番目のデリケートなステップは、角度の比較です。 の兆候$m_{NQ}$かどうかによります$w-2p$ポジティブかネガティブかです。 傾きのみに基づく議論では、これらのケースを区別するか、絶対値を含む式を使用する必要があります。 この問題を無視すると、間違った角度の方向が生成されます。 

## 代替アプローチ

 合成証明は可能です。 ラインを通します$N$と平行して$AD$会う$AC$ある時点で$R$。 以来$N$の中間点です$BC$、ポイント$R$の中間点です$AC$。 ライン$MR$と平行です$DC$、および横方向によって決定される三角形の中点ジオメトリ$PM$切断されたセグメントに関連する類似の三角形のチェーンが生成されます。$AC$そしてライン上で$D,C,P$。 これらの比例関係から得られるのは、$$\frac{QR}{RN}=\frac{DM}{DP},$$これは、角に自然に取り付けられた 2 つの直角三角形の類似性を意味します。$\angle QNM$そして$\angle MNP$。 望ましい角度の等価性が続きます。 

長方形は単純な座標系を即座に示唆し、交点は次のとおりであるため、座標アプローチが推奨されます。$Q$は 2 つの一次方程式を解くことで明示的に説明できます。
