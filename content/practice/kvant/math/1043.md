 ## 問題

 すべての整数のセットを 3 つのサブセットに分割して、どの整数に対しても$n$、$n$、$n-50$、$n+1987$3 つの異なるサブセットに属しますか?

 S.V.コンヤギン

 モスクワ第 50 回都市数学オリンピック、1987 年

 ## 再定式化

 のパーティション$\mathbb{Z}$関数によって 3 つのサブセットにエンコードされます$f:\mathbb{Z}\to\mathbb{Z}_3$。 すべての整数に対して、$n$、数字$n$、$n-50$、$n+1987$3 つの異なるサブセットに存在するということは、トリプルが$f(n),\ f(n-50),\ f(n+1987)$の 3 つの異なる要素で構成されます。$\mathbb{Z}_3$。 以来$\mathbb{Z}_3={0,1,2}$、これは、各トリプルが次の順列であるというステートメントと同等です。${0,1,2}$。 

したがって、すべての$n$、

 f(n)+f(n-50)+f(n+1987)=0 \quad \text{in } \mathbb{Z}_3。 \タグ{1}

 ## 制約の演算子定式化

 関数のシフト演算子を定義する$\mathbb{Z}\to\mathbb{Z}_3$による$(Tf)(n)=f(n-50), \qquad (Sf)(n)=f(n+1987).$式 (1) は演算子の恒等式になります。 

(I+T+S)f=0。 \タグ{2}

 なぜなら両方とも$T$そして$S$シフトはオンです$\mathbb{Z}$、彼らは通勤しています。 

式 (2) は次のように書き換えることができます。 

Sf = -f - Tf。 \タグ{3}

 ## 通勤シフトによる一貫性の制約

 申し込む$T^{50}$(3)の両側に。 シフト通勤なので、$T^{50}Sf = ST^{50}f.$(3)を使うと、$T^{50}Sf = -T^{50}f - T^{100}f,$そして$ST^{50}f = -T^{50}f - ST^{50}Tf = -T^{50}f - T^{1987}f - T^{2037}f.$2 つの式を等価すると、次のようになります。$-T^{50}f - T^{100}f = -T^{50}f - T^{1987}f - T^{2037}f,$したがって

 T^{100}f = T^{1987}f + T^{2037}f。 \タグ{4}

 後ろにシフトして$100$収量

 f = T^{1887}f + T^{1937}f。 \タグ{5}

 式 (5) は、次に対するグローバル線形制約です。$f$。 

## 元の方程式の 2 番目の伝播

 (1) をシフト$1937$:

 f(n+1937)+f(n+1887)+f(n+3924)=0。 \タグ{6}

 減算 (5) は次のように評価されます。$n$(6)より。 規約$f(n+1887)$キャンセル、与える

 f(n+3924)=0 \quad \text{キャンセルが有効なすべての } n \text{ に対して}。 \タグ{7}

 関係するシフトは全単射なので、$\mathbb{Z}$、式 (7) は次のことを意味します。$f(n)=0 \quad \text{for all } n.$したがって$f$全く同じゼロです$\mathbb{Z}_3$。 

## 最後の矛盾

 もし$f(n)=0$すべての整数に対して$n$、その後、すべての$n$トリプル$f(n),\ f(n-50),\ f(n+1987)$は$(0,0,0)$したがって、次の 3 つの異なる要素で構成することはできません。$\mathbb{Z}_3$。 

これはパーティションの定義条件と矛盾します。 

## 結論

 機能なし$f:\mathbb{Z}\to\mathbb{Z}_3$アイデンティティを満たす$f(n),\ f(n-50),\ f(n+1987)\ \text{are pairwise distinct for all } n,$したがって、必要なプロパティを備えた 3 つのサブセットに整数を分割することは不可能です。
