 ## 問題

 数値が成り立つ必要十分条件を求めます。$a$、$b$、$\alpha$、$\beta$長方形を得るには満たさなければなりません$a\times b$いくつかの長方形に分割される$\alpha\times\beta$。 

たとえば、長方形は次のようにできますか?$50\times 60$次の寸法の長方形に分割されます。 

1.$20\times 15$;
 2.$5\times 8$;
 3.$6{,}25\times 15$;
 4.$(2-\sqrt{2})\times (2+\sqrt{2})$。 

A.T. コロトフ

 ## 探検

 辺が整数の小さな長方形を考えてみましょう。 サイズが長方形の場合$a\times b$一定のサイズの長方形でタイル状に並べられます$\alpha\times \beta$、その後両方$a$そして$b$の整数倍に対応する必要があります$\alpha$または$\beta$彼らの側面に沿って。 たとえば、$4\times 6$長方形は次のように分割できます$2\times 3$長方形なので、$4/2=2$そして$6/3=2$は整数です。 ただし、向きを交換する必要がある場合があります。$4\times 6$に分割することもできます$3\times 2$異なるレイアウトの長方形。 分数次元では微妙な点が生じます。 のために$6.25\times 15$長方形の場合でも、タイルの数は各次元に沿って整数に乗算する必要があります。 不合理な長さを含む長方形の場合、次のようになります。$(2-\sqrt{2})\times (2+\sqrt{2})$、辺の合理的な線形結合が重要になります。 最も難しいのは、すべてのタイルを重なりやギャップなく対応しながら、分割性の制約と方向の選択を区別することです。 

## 問題の理解

 この問題は必要十分条件を求めています。$a$、$b$、$\alpha$、 そして$\beta$サイズの長方形になるように$a\times b$有限数のサイズの長方形で正確にカバーできる$\alpha\times \beta$、回転している可能性があります。 これはタイプ A の問題、つまり分類です。 課題は 2 つあります。1 つは、合計面積が小さい方形の面積の整数倍と一致することと、方形の辺が整数倍と互換性があることを確認することです。$\alpha$そして$\beta$ある方向性で。 直感的に必要な条件は、総面積が$ab$で割り切れます$\alpha\beta$、そしてそれはどちらかです$\alpha$分割する$a$そして$\beta$分割する$b$、 または$\alpha$分割する$b$そして$\beta$分割する$a$。 

## 証明されたアーキテクチャ

 補助定理 1: 長方形の場合$a\times b$に分割されています$\alpha\times \beta$長方形、その後$ab$の整数倍です$\alpha\beta$タイルの面積の合計が大きな長方形の面積に等しいためです。 

補題 2: いずれか$\alpha$分割する$a$そして$\beta$分割する$b$、 または$\alpha$分割する$b$そして$\beta$分割する$a$これは、各行と列がその長さに沿って整数のタイルを収容する必要があるためです。 これは最も難しいステップであり、特にギャップや部分的なタイリングがないことを確認します。 

補助定理 3: で割り切れる次元に沿ってタイルを整列できるため、これら 2 つの条件は十分です。$\alpha$そしてそれらを次の次元に沿って積み上げます。$\beta$、長方形を完全に覆います。 

最も難しい方向: 一般的な (おそらく非整数の) ケースでの十分性を証明すること。 無理な長さが関係する場合、失敗する可能性が最も高い補題は補題 2 です。 

## 解決策

 あるサイズの長方形を考えてみましょう$a\times b$とサイズの長方形$\alpha\times \beta$。 させて$N$使用されるタイルの数を示します。 総面積条件に必要なものは、$$N \alpha \beta = ab.$$したがって$ab / (\alpha \beta)$正の整数でなければなりません。 これは補題 1 を証明します。 

次に、タイルが側面に沿ってどのようにフィットするかを調べます。 長さの側面に沿って$a$、 どちらか$\alpha$または$\beta$分けなければなりません$a$そうしないと、タイルで埋めることができない長さが残ります。 同じく、横に並んで$b$、タイルの残りの寸法を分割する必要があります。$b$。 したがって、どちらか$\alpha \mid a$そして$\beta \mid b$、 または$\alpha \mid b$そして$\beta \mid a$、これは補題 2 を証明します。 

逆に仮定すると、$ab/(\alpha\beta)$は整数であり、次のいずれかです$\alpha \mid a$、$\beta \mid b$、 または$\alpha \mid b$、$\beta \mid a$。 したがって、各次元に沿ったタイルの数も整数になります。 たとえば、次の場合$\alpha \mid a$そして$\beta \mid b$、 セット$m = a/\alpha$そして$n = b/\beta$。 場所$m$長さに沿ったタイル$a$そして$n$長さに沿ったタイル$b$、 形にする$mn = ab/(\alpha \beta)$タイルの合計。 これにより、隙間や重なりがなく、長方形が完全に覆われます。 代替の向きが選択された場合、同じ議論が適用されます。$\alpha$そして$\beta$交換した。 これは補題 3 を証明します。 

例: 長方形$50\times 60$次のように分割できます。 

1.$20\times 15$タイル:$50/20 = 2.5$、$60/15 = 4$。 タイルを回転する必要があります。$50/15 \approx 3.333$、$60/20 = 3$。 どちらも整数のカウントを与えないため、タイリングは不可能です。 
2.$5\times 8$タイル:$50/5=10$、$60/8=7.5$、回転:$50/8=6.25$、$60/5=12$。 どちらも非整数を与えるので、不可能です。 
3.$6.25\times 15$タイル:$50/6.25=8$、$60/15=4$。 どちらも整数であるため、タイリングが可能です。 
4.$(2-\sqrt{2})\times(2+\sqrt{2})$:$50/(2-\sqrt{2})$そして$60/(2+\sqrt{2})$は合理的ではないため、タイリングはできません。 

したがって、必要十分条件はまさに次のとおりです。$ab/(\alpha\beta)$は整数であり、次のいずれかです$\alpha$分割する$a$そして$\beta$分割する$b$、 または$\alpha$分割する$b$そして$\beta$分割する$a$。$$\boxed{\text{A rectangle } a\times b \text{ can be partitioned into rectangles } \alpha\times \beta \text{ if and only if } \frac{ab}{\alpha \beta} \in \mathbb{Z} \text{ and } (\alpha \mid a \text{ and } \beta \mid b) \text{ or } (\alpha \mid b \text{ and } \beta \mid a).}$$## 主要な手順の検証

 最もデリケートなステップは補題 2 です。非整数次元の場合は、視覚的な位置合わせに頼るのではなく、割り切れる可能性を注意深くチェックする必要があります。 たとえば、$50\times 60$長方形と$5\times 8$タイルはほぼぴったり合っているように見えますが、商は小数です$50/8 = 6.25$タイリング表示が失敗します。 不合理なタイルの場合、$(2-\sqrt{2})\times (2+\sqrt{2})$、乗算の結果$4$、しかしどちらでもない$(50/(2-\sqrt{2}))$または$(60/(2+\sqrt{2}))$は合理的であり、不可能であることを裏付けています。 十分性ステップは、タイリング グリッドを明示的に構築し、計算することによって検証されます。$m$そして$n$合計面積と一致するようにします。 

## 代替アプローチ

 タイリングを整数解としてエンコードすることで、線形代数的アプローチを試みることもできます。$m \alpha + n \beta = a$そして$p \alpha + q \beta = b$、しかし、これは最終的には上で導かれた可分性条件に帰着します。 もう 1 つのアプローチは、幅のストリップを繰り返し減算する幾何学的帰納法です。$\alpha$または$\beta$そして剰余を埋めますが、これも同じ整数商のプロパティに依存します。 面積プラス割り算法は、反復引数なしで必要条件と十分条件の両方を直接取得できるため、優れています。
