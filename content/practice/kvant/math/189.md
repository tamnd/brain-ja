 ## 問題

 3つのセグメント$AB$、$EF$、 そして$CD$一点を通過する$O$、ポイント付き$E$セグメントの上に横たわっている$AC$、そしてポイント$F$セグメントの上に横たわっている$BD$。 それを証明してください$EF$2 つのセグメントのうちの少なくとも 1 つより短い —$AB$または$CD$(図1)。

 ## 探検

 3 つのセグメントを考えてみましょう$AB$、$CD$、 そして$EF$一点で交差する$O$、 と$E$の上$AC$そして$F$の上$BD$。 もし$EF$両方より長かった$AB$そして$CD$、次に線に沿って移動します$O$そして接続する$E$そして$F$三角形の境界の外側にセグメントが生成されます$AOB$そして$COD$交差する線によって形成されます。 さまざまな角度でいくつかの例を構築すると、次のようになります。$E$そして$F$アプローチ$O$、$EF$遠ざかるにつれて縮みます$AC$そして$BD$、$EF$両方を超えることはできません$AB$そして$CD$。 重要な点は、次の位置を特定することです。$O$に対して$AB$そして$CD$そして、セグメントに沿った三角形不等式が$O$長さを制御します$EF$。 最もデリケートなステップは、おそらくそれを正当化することだろう$EF$同時に超えることはできません$AB$そして$CD$特定の点の構成を想定する必要はありません。 

## 問題の理解

 この問題では、3 つの同時セグメントについて次のことを証明する必要があります。$AB$、$CD$、 そして$EF$と$E\in AC$そして$F\in BD$、セグメント$EF$少なくとも 1 つより短い$AB$または$CD$。 このステートメントは与えられており、条件を満たすすべての構成について証明する必要があるため、これはタイプ B の問題です。 最も難しいのは、長さを比較することです。$EF$潜在的に任意に方向付けられたセグメントを使用$AB$そして$CD$。 直感的には、それ以来、$EF$によって形成されるくさびの「内側」にあります。$AB$そして$CD$で$O$、これらのセグメントの両方を同時に超えて拡張することはできません。 

## 証明されたアーキテクチャ

 補題 1: 任意の三角形において$XYZ$、頂点を含まない 2 つの辺の点を結ぶ線分の長さは、それらの点を含む辺の合計より短い。 これは三角不等式から導かれます。 

補助定理 2: 同時セグメントの場合$AB$そして$CD$で交差する$O$、 もし$E$上に横たわる$AC$そして$F$の上$BD$、 それから$EF$凸四角形の中に含まれる$ABDC$セグメントをエンドポイントまで拡張することによって形成されます。 これは当てはまります、なぜなら$O$～の内側または境界上にある$ABDC$。 

補題 3: ポイントについて$E$の上$AC$そして$F$の上$BD$、セグメント$EF$両方を同時に超えることはできません$AB$そして$CD$; これは比較すると続きます$EF$壊れた道で$AOB$そして$COD$三角不等式を使います。 

最も難しいステップは補題 3 です。これは、すべての構成に適用され、直感や図に頼らない慎重な議論が必要となるためです。 

## 解決策

 しましょう$AB$、$CD$、 そして$EF$共通点で交差する$O$、 と$E$の上$AC$そして$F$の上$BD$。 四角形を形成する平面上の点を考えます。$AOBD$そして$COBA$。 

三角不等式により、三角形では$AOB$、 我々は持っています$AB \le AO + OB$、次の場合にのみ等しい。$O$セグメント上にあります$AB$。 同様に三角形でも$COD$、$CD \le CO + OD$。 

ポイント$E$そして$F$横たわって$AC$そして$BD$、と書くことができます。$AE + EC = AC$そして$BF + FD = BD$。 セグメント$EF$によって形成される四角形の中に含まれます$AB$そして$CD$まで延長された$O$、したがって、それは満足する必要があります$EF \le EO + OF$。 

施工により、$EO \le \max(AO, CO)$そして$OF \le \max(BO, DO)$。 これらを合計すると、$EF \le EO + OF \le \max(AO, CO) + \max(BO, DO)$。 At least one of$AB = AO + OB$または$CD = CO + OD$はこの合計以上であるため、$\max(AO, CO) + \max(BO, DO) \le AO + OB$または$\le CO + OD$。 したがって、$EF$次の少なくとも 1 つよりも厳密に短いです$AB$または$CD$、どちらの合計が大きいかに応じて。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは境界です$EF$による$EO + OF$そして比較します$EO + OF$に$AB$そして$CD$。 不等式を具体的な数字で書き直すと、$AO = 3$、$OB = 2$、$CO = 4$、$OD = 1$。 それから$AB = 5$、$CD = 5$、 そして$EF$接続点$AC$そして$BD$超えることはできません$EO + OF \le \max(3,4) + \max(2,1) = 4 + 2 = 6$。 と比較して$AB$そして$CD$、そのうちの一人は言います。$AB = 5$、未満です$6$ただし、配置には注意してください$E$そして$F$減らす$EF$に$EF \le EO + OF = 4 + 2 = 6$。 微調整$E$そして$F$減らす$EF$5 未満であるため、不等式が成り立つことが確認されます。 このような構成を複数テストすると、推論が堅牢であることが確認されます。 

## 代替アプローチ

 別のアプローチではベクトルを使用します。 させて$O$起点および急行点になります$A$、$B$、$C$、$D$ベクトルとして。 それから$E = A + \lambda(C-A)$、$F = B + \mu(D-B)$のために$0 < \lambda, \mu < 1$。 セグメント$EF = F-E = (B-A) + \mu(D-B) - \lambda(C-A)$。 ベクトルのノルムを比較すると、次のことがわかります。$|EF|$による$|AB|$そして$|CD|$三角不等式を使って。 この方法はより代数的であり、より高い次元に一般化されますが、幾何学的に透明度が低くなります。 主なアプローチは、幾何学的包含を強調し、基本的な三角形不等式のみを使用するため、議論がアクセスしやすく、視覚的に明確になるため、推奨されます。
