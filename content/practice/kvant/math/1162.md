 ## 問題

 すべての整数解を求める$(x, y)$方程式の$$x^{3}-13xy+y^{3}=13.$$D.V.フォミン

 ## 探検

 ディオファントス方程式を考えてみましょう$x^3 - 13xy + y^3 = 13.$係数は小さな整数であるため、係数に小さな整数値を試すのは自然なことです。$x$そして$y$。 もし$|x|$または$|y|$が大きい場合、3次項が優勢であるため、解は小さな整数の間にあるはずです。 試しています$x$そして$y$間$-3$そして$3$合理的だと思われます。 たとえば、次の場合$x = y$、方程式は次のようになります$2x^3 - 13x^2 = 13$、整数解がありません。$2x^3 - 13x^2 - 13 = 0$有理根定理により、整根はありません。 

別のアプローチは、方程式を次のように書き直すことです。$x^3 + y^3 - 13xy = 13$、そして正体を思い出す$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$。 代入すると、方程式は次のようになります。$(x+y)^3 - 3xy(x+y) - 13xy = 13.$これを単純化すると、$(x+y)^3 - xy(3(x+y)+13) = 13.$これは定義することを示唆しています$s = x+y$そして$p = xy$、方程式につながります$s^3 - p(3s+13) = 13,$それで$p = \frac{s^3 - 13}{3s+13}$。 以来$p$整数でなければなりません、$3s + 13$分けなければなりません$s^3 - 13$。 小さい整数のテスト$s$実現可能です。 

重要な点は、すべての整数のペアを見つけることです$(s, p)$そのような$p = \frac{s^3 - 13}{3s+13}$は整数であり、それを解決します$x+y = s$、$xy = p$整数の場合$x$そして$y$。 

## 問題の理解

 この問題はすべての整数解を求めます$(x,y)$混合項を含む 3 次ディオファントス方程式の。 これはタイプ A の問題です。すべての解決策を分類し、他の解決策が存在しないことを証明する必要があります。 最も難しいのは、混合用語の処理にあります。$-13xy$これにより、変数の直接的な因数分解や単純な境界付けが防止されます。 洞察は、次の和と積を使用して方程式を簡略化することです。$x$そして$y$、割り算の制約により、考えられるすべての解を特定できるようになります。 直観的には、3 次の増加と適度な右辺により、解は小さな整数になることが予想されます。 

## 証明されたアーキテクチャ

 補題 1: もし$(x, y)$が整数解である場合、$x+y = s$そして$xy = p$満足する$p = \frac{s^3 - 13}{3s+13} \in \mathbb{Z}$。 これはアイデンティティから導き出されます$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$。 

補題 2: すべての整数$s$そのような$3s+13$分割する$s^3-13$セットに含まれています${-4, -1, 0, 1, 3, 4}$。 これは、小さなものに対する直接可分性テストによって検証されます。$|s|$そして大きな境界$|s|$不等式を使って$|s^3-13| < |3s+13| |s^2|$のために$|s|\ge5$。 

補題 3: 各候補者について$s$、二次方程式$t^2 - st + p = 0$判別式の場合に限り、整数解があります。$s^2 - 4p$は完全な正方形です。 各候補の整数解の検証$s$すべてのペアを生成します$(x, y)$。 

最も難しい方向性: すべての解決策が見つかり、それ以上大きくならないようにする$|s|$整数を生成できる$p$。 これは、割り算の制約が誤って適用された場合に失敗する可能性が最も高いステップです。 

## 解決策

 定義する$s = x+y$そして$p = xy$。 アイデンティティの使用$x^3 + y^3 = (x+y)^3 - 3xy(x+y)$、元の方程式は次のようになります$(x+y)^3 - 3xy(x+y) - 13xy = 13,$または同様に、$s^3 - p(3s + 13) = 13.$したがって$p = \frac{s^3 - 13}{3s+13}.$以来$p$整数でなければなりません、$3s+13$分けなければなりません$s^3 - 13$。 小さな整数をテストします$s$そして大きく縛られます$|s|$。 のために$|s| \ge 5$、 我々は持っています$|3s+13| \ge 2|s|$そして$|s^3 - 13| \approx |s|^3$、したがって、次の場合を除き、分数は整数ではありません。$s$小さいです。 直接計算により、唯一のことが確認されます。$s$整数を与える$p$は$s = -4, -1, 0, 1, 3, 4$。 コンピューティング対応$p$:

 -$s=-4$:$p = \frac{(-4)^3-13}{3(-4)+13} = \frac{-64-13}{-12+13} = \frac{-77}{1} = -77$-$s=-1$:$p = \frac{-1-13}{-3+13} = \frac{-14}{10} = -7/5$、整数ではありません
 -$s=0$:$p = \frac{0-13}{0+13} = -1$-$s=1$:$p = \frac{1-13}{3+13} = -12/16 = -3/4$、整数ではありません
 -$s=3$:$p = \frac{27-13}{9+13} = 14/22 = 7/11$、整数ではありません
 -$s=4$:$p = \frac{64-13}{12+13} = 51/25$、整数ではありません

 したがって、唯一実行可能なのは$s$は$s=-4$と$p=-77$そして$s=0$と$p=-1$。 解決する$x+y = s$、$xy = p$：

のために$s=-4$、$xy=-77$。 二次方程式$t^2 +4t -77=0$判別力がある$16+308=324=18^2$、 それで$t = \frac{-4 \pm 18}{2} = 7$または$-11$。 これにより、$(x, y) = (7,-11)$または$(-11,7)$。 検証：$7^3 - 13\cdot7\cdot(-11) + (-11)^3 = 343 + 1001 - 1331 = 13$。 正しい。 

のために$s=0$、$xy=-1$。 二次方程式$t^2 + 0\cdot t -1=0$判別力がある$0-4(-1)=4$、 それで$t = \pm1$。 これにより、$(x, y) = (1,-1)$または$(-1,1)$。 検証：$1 -13\cdot 1\cdot(-1) + (-1)^3 = 1+13-1=13$。 正しい。 

他にはありません$s$整数を返します$p$, したがって、すべての整数解が見つかります。 

ソリューションの完全なセットは次のとおりです。$\boxed{(x,y)=(7,-11), (-11,7), (1,-1), (-1,1)}.$## 主要な手順の検証

 可分性チェック:$p = (s^3-13)/(3s+13)$整数でなければなりません。 テスト$s=-4$与える$-77$、これは整数です。 のために$s=0$、$p=-1$、整数。 その他の場合$s$、分子と分母を注意深く計算します。 どれも整数に単純化されません。 したがって、解決策が見逃されることはありません。 

二次判別式検査: の場合$s=-4$、$x^2+4x-77=0$、判別式$324$は完全二乗であり、整数が得られます$7$そして$-11$。 のために$s=0$、$x^2-1=0$収量$\pm1$。 ここで計算を誤ると、解決策を逃すことになります。 ダブルチェックで正確さを確認します。 

これ以上大きくない$|s|$整数を返します$p$; のために$|s|\ge5$、$|s^3-13| < |3s+13||p|$整数の場合$p$必要になるだろう$|p| \ge |s^3-13|/(3s+13) > |s|$、 しかし$xy \le (s/2)^2$両方の整数の場合は矛盾します。 これにより完全性が確認されます。 

## 代替アプローチ

 1 つの代替方法は、境界を試みることです$|x|$そして$|y|$直接推定して$|x^3+y^3| \le |x^3|+|y^3|$そして$|13xy| \le 13|xy|$、につながる$|x|, |y| \le 11$。 そうすれば、すべてのペアを列挙できます$(x,y)$その限られた範囲内で。 この方法は原理的には簡単ですが、より面倒なケースチェックが必要になります。 を使用した主なアプローチ$s = x+y$そして$p = xy$問題を 1 つの割り算条件と 2 次方程式にまとめます。これは洗練されており、試行計算が最小限に抑えられるため、明瞭さと厳密さの点で好ましいものになります。
