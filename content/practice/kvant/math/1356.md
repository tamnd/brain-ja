 ## 問題

 それを証明してください$abc=4Rrr_c$、 どこ$a$、$b$、$c$は三角形の辺であり、$R$、$r$、$r_c$が外接円、内接円、および外接円の 1 つの半径である場合、三角形は直角になります。 (○は側面に接しています$c$および他の 2 つの側面の延長部分。)

 B. トゥレシバエフ、11 年生

 ## 探検

 辺のある三角形が与えられます$a$、$b$、$c$そしてその関係$abc = 4R r r_c,$どこ$R$外周半径です、$r$は半径であり、$r_c$エクスラジウスの反対側です$c$。 目標は、この条件が三角形が直角であることを意味することを証明することです。 標準的な公式は、これらの半径を三角形の半周長で表します。$s = \frac{a+b+c}{2}$とエリア$\Delta$として$R = \frac{abc}{4\Delta}, \qquad r = \frac{\Delta}{s}, \qquad r_c = \frac{\Delta}{s-c}.$これらを指定された関係に代入すると、のみを含む恒等式が生成されます。$s$、$\Delta$、辺の長さ。 ヘロンの公式を使用する$\Delta = \sqrt{s(s-a)(s-b)(s-c)}$これにより、純粋に辺間の関係を単純化できるようになります。$a$、$b$、$c$、強制的に示すことができます$c^2 = a^2 + b^2$。 

## 問題の理解

 問題は、辺の長さと半径の特定の積が直角三角形の特徴を表すことを示すことです。 自然なアプローチは、既知の公式を使用して半径を削除し、指定された条件を辺間の代数方程式に還元することです。 中心的なステップは、結果として得られる恒等式を正しく操作し、それがピタゴラスの定理と同等であることを実証することです。 

## 証明されたアーキテクチャ

 証明は、標準公式を次のように置き換えることによって進められます。$R$、$r$、 そして$r_c$与えられた条件に代入して、以下を含む方程式を取得します。$\Delta$そして$s$。 次に、ヘロンの公式を適用して置き換えます。$\Delta$側面と半周に関する式を使用します。 これにより、立体的なアイデンティティが生成されます。$s$を体系的に単純化して次のことを明らかにできます。$c^2 = a^2 + b^2$。 鍵となるのはステップ接続における慎重な代数です$(s-a)(s-b)$そして$s(s-c)$ピタゴラス条件に達します。 

## 解決策

 しましょう$\Delta$は三角形の面積を示し、$s = \frac{a+b+c}{2}$半周。 外周半径、半径内半径、半径外半径の反対側の標準公式$c$は$R = \frac{abc}{4\Delta}, \qquad r = \frac{\Delta}{s}, \qquad r_c = \frac{\Delta}{s-c}.$これらを与えられた条件に代入すると、次のようになります。$4R r r_c = 4 \cdot \frac{abc}{4\Delta} \cdot \frac{\Delta}{s} \cdot \frac{\Delta}{s-c} = \frac{abc \, \Delta}{s(s-c)}.$これを同等とすると、$abc$与える$abc = \frac{abc \, \Delta}{s(s-c)} \implies \Delta = s(s-c),$ここで除算$abc$三角形は非縮退であるため、正当化されます。$abc > 0$。 

ヘロンの公式を適用すると、$\Delta = \sqrt{s(s-a)(s-b)(s-c)}.$これを同等とすると、$\Delta = s(s-c)$与える$\sqrt{s(s-a)(s-b)(s-c)} = s(s-c) \implies (s-a)(s-b) = s(s-c).$各項を辺で表すと$a$、$b$、$c$:$s = \frac{a+b+c}{2}, \quad s-a = \frac{b+c-a}{2}, \quad s-b = \frac{a+c-b}{2}, \quad s-c = \frac{a+b-c}{2}.$これらを代入すると、$(s-a)(s-b) = s(s-c)$与える$\frac{b+c-a}{2} \cdot \frac{a+c-b}{2} = \frac{a+b+c}{2} \cdot \frac{a+b-c}{2}.$両辺に 4 を掛けると、等価な方程式が生成されます。$(b+c-a)(a+c-b) = (a+b+c)(a+b-c).$両辺を注意深く展開すると、左側は次のようになります。$$\begin{aligned} (b+c-a)(a+c-b) &= (b)(a) + (b)(c-b) + (c-a)(a+c-b) \\ &= ab + bc - b^2 + ac + c^2 - bc - a^2 - ac + ab \\ &= 2ab - a^2 - b^2 + c^2 \\ &= c^2 - (a-b)^2 + 2ab. \end{aligned}$$より体系的に拡張する$(b+c-a)(a+c-b)$:$$(b+c-a)(a+c-b) = b a + b c - b^2 + c a + c^2 - c b - a^2 - a c + a b = 2ab - a^2 - b^2 + c^2,$$これを単純化すると$c^2 - (a-b)^2 + 2ab = a^2 + b^2 + 2ab - (a^2 + b^2 - c^2) = 2ab + c^2 - a^2 - b^2.$右辺は次のように展開されます。$(a+b+c)(a+b-c) = (a+b)^2 - c^2 = a^2 + 2ab + b^2 - c^2.$2 つの展開を等価すると、次のようになります。$2ab + c^2 - a^2 - b^2 = a^2 + 2ab + b^2 - c^2 \implies 2c^2 = 2(a^2 + b^2) \implies c^2 = a^2 + b^2.$したがって、三角形はピタゴラスの定理を満たします。 ピタゴラスの定理の逆により、反対側の角度$c$は直角であり、三角形は直角です。$\boxed{\text{The triangle is right-angled.}}$## 主要な手順の検証

 標準式の置き換え$R$、$r$、 そして$r_c$有効です。 の導出$\Delta = s(s-c)$与えられた条件から直接導き出されます。 Heron の公式を適用して置換する$\Delta$は正当化され、から導かれる代数は$(s-a)(s-b) = s(s-c)$に$c^2 = a^2 + b^2$漏れなく計画的に実施されます。 各ステップは、標準的な三角形の恒等式と非縮退の仮定のみに依存し、議論を完全なものにします。 

## 代替アプローチ

 直接表現することもできる$r$そして$r_c$に関しては$a$、$b$、$c$そして$R$半周を呼び出すことなく。 使用する$r = \frac{2\Delta}{a+b+c}$そして$r_c = \frac{2\Delta}{-a-b+c+2c}$最終的に条件を 2 次式に還元します。$c^2$、同じ結論につながります$c^2 = a^2 + b^2$。 半周とヘロンの公式によるアプローチは、計算を単一の恒等式と自然な因数分解に減らすため、より洗練されています。
