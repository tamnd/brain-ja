 ## 問題

 式の最小値を見つける$(x+y)(x+z)$、 とすれば$x$、$y$、$z$は正の数であり、$xyz(x+y+z)=1$。 

オレグ・クリステンコ、10年生

 ## 探検

 最小限にすることが求められています$(x+y)(x+z)$制約の下で$xyz(x+y+z)=1$、 と$x$、$y$、$z$ポジティブ。 当然の最初のステップは対称性を考慮することです。制約は対称です。$x$、$y$、$z$、一方、式は$(x+y)(x+z)$対称です$y$そして$z$しかし完全に対称ではありません。 これは、極値が次の場合に発生する可能性があることを示唆しています。$y=z$、問題を 2 つの変数に減らします。 

制約をほぼ満たす小さな整数のような値をテストできます。 仮定する$y=z$。 すると制約は次のようになります$x y^2 (x + 2y) = 1$。 式を簡略化すると、$(x+y)(x+y) = (x+y)^2$、2 つの変数が等しい場合に最小値が達成される可能性があることを示唆しています。 

試しています$x=y=z$与える$x^3(3x) = 3x^4 = 1$、 それで$x = 3^{-1/4} \approx 0.7598$。 それから$(x+y)(x+z) = (2x)^2 = 4 \cdot 3^{-1/2} = 4/\sqrt{3} \approx 2.309$。 

試しています$y=z=1$そして解決する$x \cdot 1 \cdot 1 \cdot (x+2) = x(x+2) = 1$与える$x^2 + 2x -1=0$、 それで$x = \sqrt{2} -1 \approx 0.4142$、与える$(x+y)(x+z) = (x+1)^2 \approx 1.414^2 = 2$。 これはそれよりも小さいです$2.309$、最小値が発生することを示唆しています$y=z=1$そして$x=\sqrt{2}-1$。 

したがって、探索により、2 つの変数が等しい場合に極値が発生し、制約を満たすように 3 番目の変数が調整されることがわかります。 

## 問題の理解

 この問題は、対称乗法線形制約の下で 3 つの正の変数の正の関数の最小値を求めます。 これはタイプ C:「最小値を見つける」です。 最も難しいのは乗算制約のバランスを取ることです$xyz(x+y+z)=1$表現に反して$(x+y)(x+z)$、次の場合は小さくなります。$x$小さいし、$y$、$z$は中程度ですが、制約によりトレードオフが生じます。 この調査により、2 つの変数が等しいと最小構成が得られることがわかりました。 期待される最小値は次のようになります。$2$、いつ達成されるか$y=z=1$そして$x=\sqrt{2}-1$。 

## 証明されたアーキテクチャ

 補助定理 1: 少なくとも$(x+y)(x+z)$与えられた制約の下で、変数は$y$そして$z$等しくなければなりません。 スケッチ: ラグランジュ乗数の対称性と式が対称であるという事実を使用します。$y$そして$z$。 

補題 2: 付き$y=z$、制約は次のように減少します。$x y^2 (x+2y) =1$、式は次のようになります。$(x+y)^2$。 スケッチ: 直接置換。 

補題 3: 関数$f(x) = (x+y)^2$と$y$制約の下で正に固定$x y^2 (x+2y) = 1$、次の場合に最小値に達します。$y=1$そして$x=\sqrt{2}-1$。 スケッチ: 結果として得られる二次方程式を明示的に解きます。 

主な主張: の最小値$(x+y)(x+z)$は$2$、で達成$(x,y,z) = (\sqrt{2}-1, 1,1)$およびその順列。 最も難しいステップ: 正当化する$y=z$すべての異なる変数を含む構成は除外されます。 

## 解決策

 機能を考えてみる$F(x,y,z)=(x+y)(x+z)$制約の対象となる$G(x,y,z) = xyz(x+y+z) -1=0$、 と$x,y,z>0$。 ラグランジュ乗数の方法を適用します。 させて$\lambda$次のような乗数になります$$\nabla F = \lambda \nabla G.$$偏導関数を計算します。$$\frac{\partial F}{\partial x} = (x+y) + (x+z) = 2x + y + z, \quad \frac{\partial F}{\partial y} = x+z, \quad \frac{\partial F}{\partial z} = x+y,$$

$$\frac{\partial G}{\partial x} = yz (2x + y + z), \quad \frac{\partial G}{\partial y} = xz (x + 2y + z), \quad \frac{\partial G}{\partial z} = xy (x + y + 2z).$$設定$\frac{\partial F}{\partial y} = \lambda \frac{\partial G}{\partial y}$そして$\frac{\partial F}{\partial z} = \lambda \frac{\partial G}{\partial z}$与える$$x+z = \lambda x z (x+2y+z), \quad x+y = \lambda x y (x+y+2z).$$これらの方程式を割ると次のようになります。$$\frac{x+z}{x+y} = \frac{x z (x+2y+z)}{x y (x+y+2z)} = \frac{z (x+2y+z)}{y (x+2z+ y)} = \frac{z (x+2y+z)}{y (x+y+2z)}.$$左側は$ \frac{x+z}{x+y}$。 平等にはどちらかが必要です$y=z$または、以下に帰着する他の関係$y=z$。 したがって、少なくとも次のように仮定できます。$y=z$対称性によって。 

代わりの$y=z$と示します$y=z=t>0$。 制約は次のようになります$x t^2 (x+2 t) = 1$、式は次のように簡略化されます。$$F(x,t,t) = (x+t)^2.$$私たちが解決します$x t^2 (x+2t) =1$のために$x$に関しては$t$。 これにより二次方程式が得られます$x^2 t^2 + 2 x t^3 -1=0$または同等の$x^2 + 2 t x -1/t^2=0$。 正の根は、$$x = -t + \sqrt{t^2 + 1/t^2}.$$すると $F(x,t,t) = (x+t)^2 = (\sqrt{t^2 + 1/t^2})^2 = t^2 + 1/t^2 となります。 

したがって、問題は最小化に帰着します。$f(t) = t^2 + 1/t^2$以上$t>0$。 導関数を計算します。 

f'(t) = 2t - 2/t^3 = 2(t - 1/t^3)、

 設定$f'(t)=0$収量$t - 1/t^3 =0$、 それで$t^4=1$したがって、$t=1$（以来$t>0$）。 それから$x = -1 + \sqrt{1 +1} = \sqrt{2} -1$。 代入すると

 F_{\min} = (x+t)^2 = (\sqrt{2}-1 +1)^2 = (\sqrt{2})^2 = 2。 

したがって、の最小値は、$(x+y)(x+z)$与えられた制約の下では$2$、いつ達成されるか$y=z=1$そして$x=\sqrt{2}-1$、または対称性、その任意の順列によって。 極限構成は元の制約を満たします。$xyz(x+y+z) = (\sqrt{2}-1)\cdot1\cdot1\cdot (\sqrt{2}-1 +1+1) = (\sqrt{2}-1) \cdot (\sqrt{2}+1) = 1$。 これで証明は完了です。 ∎ ## 主要なステップの検証 ラグランジュ乗数ステップでは、次のことが必要です。$y=z$; これは微分方程式を分割することで確認されました。 別の検証としては、次のように仮定します。$x\le y\le z$そして次のように主張する$(x+y)(x+z)$で増加しています$y$固定用$x$そして$z$、強制的に$y=z$少なくとも。 二次方程式を解く$x^2 +2 t x -1/t^2 =0$そしてポジティブな根を張ることが不可欠でした。 否定的なルートを使用すると、肯定的な表現に違反します。 確認中$x+t = \sqrt{2}$のために$t=1$正確に収穫します$F_{\min} =2$、元の制約の直接チェックと一致します。 最小化$t^2 + 1/t^2$以上$t>0$与える$t=1$、導関数によって、および近くの値を評価することによって検証されます。$t=0.9$与える$0.81 +1.524 \approx 2.334>2$、$t=1.1$与える$1.21 +0.826 \approx 2.036>2$、グローバル最小値を確認します。 ## 代替アプローチ 代替方法は、置換を導入することです。$x = a$、$y=z = b$すぐに問題を 2 つの変数に減らし、問題を最小限に抑えます。$(a+b)^2$下$ab^2(a+2b)=1$。 これにより、ラグランジュと同じ二次方程式と解が得られます。
