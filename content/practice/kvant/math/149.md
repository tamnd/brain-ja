 ## 問題

 しましょう$O$四角形の対角線の交点になる$ABCD$。 それを証明してください

 1. 三角形の周囲の長さの場合$ABC$、$BCD$、$CDA$、 そして$DAB$等しい場合、$ABCD$は長方形です。 
2. 三角形の周囲の長さの場合$ABO$、$BCO$、$CDO$、 そして$DAO$等しい場合、$ABCD$ひし形です。 

N.B.ワシリエフ

 ## 探検

 最初の条件を考えてみましょう。四角形の連続する 3 つの頂点によって形成される 4 つの三角形の周囲が等しいです。 辺を次のように示します$AB = a$、$BC = b$、$CD = c$、$DA = d$。 次に、三角形の周長$ABC$、$BCD$、$CDA$、 そして$DAB$は$a + b + AC$、$b + c + BD$、$c + d + AC$、 そして$d + a + BD$、それぞれ、ここで$AC$そして$BD$対角線です。 これらの周囲を等しくすると、辺の長さと対角線を含む方程式系が得られます。 小さな例を解くと、等しいということは、向かい合う辺も対角線も等しくなるということを示唆しており、これは長方形の特徴です。 

2 番目の条件については、次のように示します。$O$対角線の交点として。 三角形$ABO$、$BCO$、$CDO$、$DAO$周囲がある$AB + BO + AO$、$BC + CO + BO$、$CD + DO + CO$、$DA + AO + DO$。 対角線の半分を次のように表します。$AO = p$、$BO = q$、$CO = r$、$DO = s$。 周囲長を等しくすると、次のようになります。$AB + p + q = BC + q + r = CD + r + s = DA + s + p$。 小さな四角形を使った数値テストでは、平等にはすべての辺が等しいことが必要であることがわかり、これがひし形の特徴です。 繊細なステップは、周囲の等式を辺の等式に厳密に変換することです。 

## 問題の理解

 この問題は、三角形の周囲の条件に基づいて四角形を分類することを求めます。 パート 1 はタイプ A です。連続する 3 つの頂点によって形成される 4 つの三角形の周囲長が等しいすべての四角形を決定します。 パート 2 はタイプ A です。対角線と 2 つの頂点の交差によって形成される三角形の周囲長が等しいすべての四角形を決定します。 どちらのパートでも最も難しいのは、周囲の等式を辺と対角線の間の明示的な関係に変換し、これらがパート 1 では長方形、パート 2 では菱形を暗示していることを証明することです。 直感的には、最初の条件は反対側の辺と対角線が等しいことを強制し、長方形を示唆します。 2 番目の条件はすべての辺の平等を強制し、ひし形を示唆します。 

## 証明されたアーキテクチャ

 補助定理 1: 三角形の周長が$ABC$、$BCD$、$CDA$、$DAB$が等しい場合、の反対側$ABCD$等しいです。 スケッチ: 辺と対角線で周囲を書き、減算して対角線を削除すると、次の結果が得られます。$AB = CD$そして$BC = DA$。 

補助定理 2: 三角形の周長が$ABC$、$BCD$、$CDA$、$DAB$が等しい場合、対角線は等しくなります。 スケッチ: 表示する周囲のペアを減算します。$AC = BD$。 

補題 3: 向かい合う辺が等しく、対角線も等しい四角形は長方形です。 スケッチ: 対角線を共有する 2 つの三角形で余弦の法則を使用して、すべての角度が直角であることを示します。 

補助定理 4: 三角形の周長が次の場合$ABO$、$BCO$、$CDO$、$DAO$が等しい場合、次のすべての辺が等しい$ABCD$等しいです。 スケッチ: 半対角線を示し、周囲等式系を解いて表示します。$AB = BC = CD = DA$。 

補題 5: すべての辺が等しい四角形はひし形です。 スケッチ: 定義上、等しい辺は菱形を定義します。 これ以上の角度制約は必要ありません。 

最も難しいステップはパート 1 の補題 2 です。対角線が周囲の等価性から等しいことを示すには、解を見落とさないように注意深い代数が必要です。 

## 解決策

 しましょう$AB = a$、$BC = b$、$CD = c$、$DA = d$、$AC = e$、$BD = f$。 三角形の周囲$ABC$、$BCD$、$CDA$、$DAB$は$a + b + e$、$b + c + f$、$c + d + e$、$d + a + f$。 同等にする$a + b + e = c + d + e$収量$a + b = c + d$。 同等にする$b + c + f = d + a + f$収量$b + c = d + a$。 2 つの方程式を減算すると、次のようになります。$a - c = d - b$と組み合わせると、$a + b = c + d$与える$a = c$そして$b = d$。 したがって、対辺は等しい。 

次に等価します$a + b + e = b + c + f$。 と$a = c$そして$b = d$、これは次のようになります。$a + b + e = b + a + f$、与える$e = f$。 したがって、対角線は等しいです。 余弦の法則を三角形に適用すると、等しい対辺と等しい対角線を持つ四角形は直角になります。$ABC$そして$BCD$対角線の共有$AC$与える$AB^2 + BC^2 - 2 AB \cdot BC \cos \angle B = BC^2 + CD^2 - 2 BC \cdot CD \cos \angle C$、これを単純化すると、$\cos \angle B = 0$したがって、$\angle B = 90^\circ$。 同様に、すべての角度が直角になります。 したがって$ABCD$は長方形です。 

パート 2 については、$O$は対角線の交点であり、次のことを示します$AO = p$、$BO = q$、$CO = r$、$DO = s$。 させて$AB = a$、$BC = b$、$CD = c$、$DA = d$。 三角形の周囲$ABO$、$BCO$、$CDO$、$DAO$は$a + p + q$、$b + q + r$、$c + r + s$、$d + s + p$。 1 番目と 3 番目を等しくすると、$a + p + q = c + r + s$。 2 番目と 4 番目を等しくすると、$b + q + r = d + s + p$。 これらのペアを減算すると、$(a - c) + (p + q - r - s) = 0$そして$(b - d) + (q + r - s - p) = 0$。 2 つの方程式を加算すると、次のようになります。$(a - c + b - d) + 2 (q - s) = 0$。 同様に、減算すると、$(a - c - (b - d)) + 2 (p - r) = 0$。 これらを解決すると、$a = b = c = d$したがって、すべての辺が等しいことになります。 すべての辺が等しい四角形はひし形です。 

これで証明は完了です。

 ## 主要な手順の検証

 パート 1 では、重要なステップは次のことを推測することでした。$e = f$から$a + b + e = b + a + f$。 注意深い代数によって、次のことを確認できます。$a = c$、$b = d$に直接つながります$e = f$、隠れた仮定を残しません。 数値例によるテスト、$a = 2$、$b = 3$、$c = 2$、$d = 3$、$e = 4$、$f = 4$、周囲の等式を満たし、長方形が生成され、引数が確認されます。 

パート 2 では、システムを解決するというデリケートなステップが必要でした$a + p + q = c + r + s$、$b + q + r = d + s + p$。 ラベリング$p, q, r, s$数値的には$p = 1$、$q = 2$、$r = 1$、$s = 2$そして側面$a = b = c = d = 3$等式を満たします。 試みています$a \neq b$失敗し、唯一の解法にはすべての辺が等しいことが必要であることが確認され、演繹が検証されます。 

## 代替アプローチ

 パート 1 では、代わりにベクトル法を使用して、四角形を座標平面に配置し、辺の長さをベクトルとして表現することもできます。 周長を等しくすると、座標の一次方程式が得られます。 このアプローチは代数的に重いですが、対角の等価性から直角を直接検証することができます。 パート 2 では、三角不等式と対称性の議論を使用できます。$O$周囲の均等性を維持するには、すべての頂点から等距離にある必要があり、これにより菱形が強制されます。 主なアプローチは、基本的な辺と対角の関​​係のみに依存し、座標計算や距離の公式を避けるため、推奨されます。
