 ## 問題

 負でない数の最大のもの$a_1$、$a_2$、$\ldots$、$a_n$は$a$。 

1. 不等式を証明する$$\frac{a_1^2+a_2^2+\ldots+a_n^2}n\le\left(\frac{a_1+a_2+\ldots+a_n}{n}\right)^2+\frac{a^2}4$$2. 平等はいつ達成されるのでしょうか?

 L.G.カニン

 ## 探検

 の小さな値を考慮します。$n$不等式を理解するために。 のために$n=2$、数字を次のようにします$a_1$そして$a_2$と$a_2 \ge a_1 \ge 0$そして$a_2 = a$。 不平等はこうなる$\frac{a_1^2 + a_2^2}{2} \le \left(\frac{a_1 + a_2}{2}\right)^2 + \frac{a^2}{4}.$右辺を展開すると、$\left(\frac{a_1 + a_2}{2}\right)^2 + \frac{a_2^2}{4} = \frac{a_1^2 + 2a_1 a_2 + a_2^2}{4} + \frac{a_2^2}{4} = \frac{a_1^2 + 2a_1 a_2 + 2 a_2^2}{4}.$左側は$\frac{a_1^2 + a_2^2}{2} = \frac{2a_1^2 + 2a_2^2}{4}$。 右から左を引くと、$\frac{a_1^2 + 2 a_1 a_2 + 2 a_2^2 - 2 a_1^2 - 2 a_2^2}{4} = \frac{-a_1^2 + 2 a_1 a_2}{4} = \frac{a_1(2a_2 - a_1)}{4} \ge 0,$以来$0 \le a_1 \le a_2$。 これは、不平等がもっともらしいことを示唆しています。 

テスト$n=3$と$0,0,a$与える$\frac{a^2}{3} \le \frac{a^2}{9} + \frac{a^2}{4} = \frac{13 a^2}{36} \approx 0.361 a^2$、 その間$\frac{a^2}{3} \approx 0.333 a^2$、これも成り立ちます。 

平等が生じるのは、$n=2$もし$a_1 = 0$または$a_1 = a_2$。 のために$n>2$、パターンによっては、すべての数字が$0$おそらく 1 つまたは 2 つが以下に等しい場合を除き、$a$。 

重要な点は、不等式一般をどのように定式化するかである。$n$。 として書くと$\frac{1}{n} \sum_{i=1}^n a_i^2 - \left(\frac{\sum a_i}{n}\right)^2 \le \frac{a^2}{4}$左側は次のとおりであるため、分散のような式を使用することを提案します。$\frac{1}{n} \sum a_i^2 - \bar a^2 = \frac{1}{n} \sum (a_i - \bar a)^2$つまり、平均二乗偏差です。 最大値$\sum (a_i - \bar a)^2$下$0 \le a_i \le a$数値が可能な限り離れている場合に発生します。$0$、 いくつかの$a$、最大 2 つの異なる値を持ちます。 これが核となる洞察です。 

## 問題の理解

 この問題は、非負の数の不等式を証明することを求めています$a_1, \dots, a_n$その最大値は$a$。 不等式は、二乗の平均を、平均にプラスしたものの二乗で制限します。$a^2/4$。 単一のステートメントを証明する必要があるため、これはタイプ B です。 中心的な難しさは、数値の分散を制御し、限界を示すことにあります。$\frac{a^2}{4}$で十分です。 等しい場合には、分散限界を飽和させる極値の配置を特定する必要があります。 

## 証明されたアーキテクチャ

 補題 1: 任意の実数について$x_1, \dots, x_n$、アイデンティティ$\frac{1}{n} \sum x_i^2 - \left(\frac{\sum x_i}{n}\right)^2 = \frac{1}{2 n^2} \sum_{i,j} (x_i - x_j)^2$が成り立ち、差はペアごとの差の二乗の平均として表されます。 これは直接展開すると当てはまります。 

補題 2: 内の数の間で$[0,a]$、合計$\sum_{i,j} (a_i - a_j)^2$それぞれの場合に最大化されます$a_i$どちらかに等しい$0$または$a$なぜなら、二次関数は区間の端点で極値に達するからです。 

補題 3: 数値について$0 \le a_i \le a$取るだけ$0$または$a$、合計$\sum_{i,j} (a_i - a_j)^2$は$2 k (n-k) a^2$、 どこ$k$の数です$a_i$に等しい$a$。 これは、異なるペアを数えることによって組み合わせ的に計算されます。 最大値は次の時点で発生します。$k = \lfloor n/2 \rfloor$または$k = \lceil n/2 \rceil$、せいぜい与えます$n^2 a^2 / 2$。 

主な議論: 補助定理 1 ～ 3 を組み合わせて表示する$\frac{1}{n} \sum a_i^2 - (\bar a)^2 \le a^2/4$を追加します。$\bar a^2$両側に当てはめて不等式を求めます。 等価性は、補題 3 で特定される極値配置でのみ発生します。$k = n/2$もし$n$偶数か$k = (n \pm 1)/2$もし$n$奇数。 

## 解決策

 数字の場合$a_1, \dots, a_n$、 させて$\bar a = \frac{1}{n} \sum_{i=1}^n a_i$。 それから$\frac{1}{n} \sum_{i=1}^n a_i^2 - \bar a^2 = \frac{1}{2 n^2} \sum_{i,j=1}^n (a_i - a_j)^2$拡張すると:$\sum_{i,j} (a_i - a_j)^2 = \sum_{i,j} (a_i^2 - 2 a_i a_j + a_j^2) = 2 n \sum a_i^2 - 2 (\sum a_i)^2$。 両辺をで割ると$2 n^2$アイデンティティを与えます。 

差の二乗和は、それぞれの場合に最大になります。$a_i$どちらかです$0$または$a$、なぜなら$x \in [0,a]$、関数$(x - y)^2$は各変数で凸であり、コンパクトな区間にわたる凸関数は終点で最大になります。 で示す$k$の数$a_i$に等しい$a$。 次にペアの数$(i,j)$と$a_i \neq a_j$は$2 k (n-k)$、そしてそのような各ペアは貢献します$a^2$合計に。 したがって$\sum_{i,j} (a_i - a_j)^2 = 2 k (n-k) a^2.$最大値$k(n-k)$整数の場合$k \in [0,n]$で発生します$k = \lfloor n/2 \rfloor$または$k = \lceil n/2 \rceil$、与える$k(n-k) \le n^2 /4$。 したがって、$\frac{1}{2 n^2} \sum_{i,j} (a_i - a_j)^2 = \frac{1}{2 n^2} \cdot 2 k(n-k) a^2 = \frac{k(n-k)}{n^2} a^2 \le \frac{a^2}{4}.$追加$\bar a^2$両側に譲る$\frac{1}{n} \sum_{i=1}^n a_i^2 = \bar a^2 + \left(\frac{1}{n} \sum a_i^2 - \bar a^2\right) \le \bar a^2 + \frac{a^2}{4}.$平等はまさに次の場合に発生します$k = n/2$均等に$n$、 または$k = (n \pm 1)/2$奇数の場合$n$、すべての数値は次のいずれかに等しい$0$または$a$。 これで証明は完了です。

 ## 主要な手順の検証

 最初の繊細なステップはアイデンティティです$\frac{1}{n} \sum a_i^2 - \bar a^2 = \frac{1}{2 n^2} \sum_{i,j} (a_i - a_j)^2.$右側を展開すると次のようになります。$\sum_{i,j} (a_i - a_j)^2 = \sum_i \sum_j a_i^2 - 2 \sum_i \sum_j a_i a_j + \sum_i \sum_j a_j^2 = 2 n \sum a_i^2 - 2 (\sum a_i)^2$。 で割る$2 n^2$正確に与える$\frac{1}{n} \sum a_i^2 - \bar a^2$、正しさを確認します。 

2 番目の繊細なステップは、最大化です$k(n-k)$以上$k \in [0,n]$。 機能$k(n-k) = n k - k^2$頂点が下に凹んだ二次関数です。
