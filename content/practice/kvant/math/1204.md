 ## 問題

 飛行機上では、ポイント$A$、$B$、$C$は 3 つの円の中心として与えられます。 各円は均一に拡大します (半径はすべての円で同じ割合で増加します)。 2 つの円が互いに接触するとすぐに「破裂」し、半径が 0 に縮小し、再び成長し始めます。 距離が離れたら本当ですか？$AB$、$BC$、$CA$が整数の場合、このプロセスは定期的に行われますか?

 三角形の場合、このプロセスがどのように進化するかを分析します。$ABC$です

 1. 等辺。 
二等辺三角形、３． 
3. 辺 3、4、5 が直角。 

初期状態は任意です (「ゼロ」だけでなく)。 

M.コバノフ

 ## 探検

 点を中心とする 3 つの円を考えます$A$、$B$、 そして$C$、それぞれが同じ一定の速度で拡大します。 2 つの円が接触すると、それらは半径 0 まで崩壊し、再び成長し始めます。 中心間の距離が整数であるとします。$AB = p$、$BC = q$、$CA = r$。 最初の観察は、衝突が発生する半径が中心間の距離のちょうど半分であるということです。 したがって、最初の衝突時間は次のようになります。$t_{AB} = p/2$、$t_{BC} = q/2$、$t_{CA} = r/2$、すべての円が半径 0 から始まると仮定します。 衝突後、関係する円はゼロにリセットされますが、3 番目の円は中断されることなく成長し続ける可能性があります。 

小さな例のシミュレーション: 辺の長さ 1 の正三角形の場合、最初の衝突は次の位置で発生します。$t = 1/2$。 その後、その衝突に関与した円はリセットされます。 残りの円は半径に達します$1/2$次の衝突が起こったとき。 衝突のタイミングは整数の距離に依存し、イベントの合理的な時間を示唆し、シーケンスの繰り返しにつながる可能性があります。 

非正三角形、特に辺の長さが一致しない三角形 (3、4、5 など) の場合、衝突が発生することがあります。$3/2$、$2$、$5/2$システムが最終的に半径の元の構成に戻るかどうかを確認する必要があります。 本質的な問題は、一連の衝突時間が合理的な格子を形成しているかどうかです。 おそらく重要なステップは、正三角形や二等辺三角形の場合だけではなく、任意の整数三角形の周期性を証明することです。 

## 問題の理解

 この問題は、中心によって形成される三角形の辺が整数である場合に、円の拡大と破裂のプロセスが周期的であるかどうかを尋ねます。 これはタイプ B: 三角形のタイプごとに「その [ステートメント] を証明する」です。 最も難しいのは、各バースト後に衝突シーケンスがどのように進展するのか、そして最終的には初期の半径構成が繰り返されるのかどうかを理解することです。 

正三角形の場合、対称性は、すべての円が一定の間隔で同時にリセットされることを示唆しています。 二等辺三角形の場合、2 つの等しい辺は特定の衝突を同期させる可能性がありますが、等しくない辺は異なるタイミングをもたらしますが、すべての距離は整数であるため、時間は合理的なままです。 辺が 3、4、5 の直角三角形の場合、衝突時間は次の倍数になります。$1/2$、$2$、$5/2$、など、そして問題は、これらの有理倍数がイベントの繰り返しシーケンスを生成するかどうかです。 

重要な洞察は、整数辺の長さによって合理的な衝突時間が保証され、そのプロセスが共通の分母を法として有限個の異なる有理時間構成で決定論的であるということです。 これは周期性を示唆しています。 

## 証明されたアーキテクチャ

 補助定理 1: 整数の距離を持つ点を中心とする任意の円のペアについて、(半径 0 からの) 衝突までの時間は有理数になります。 スケッチ: 衝突半径は距離の半分であり、すべての距離は整数です。 

補題 2: 衝突後、関係する円はリセットされ、残りの円は線形に増加します。 スケッチ: 線形成長は有理時間での将来の衝突を保存します。 

補題 3: システム全体は、共通の分母の有理数倍で進化します。 スケッチ: すべてのペアごとの距離の分母の最小公倍数を取得します。 すべてのイベントはこの単位の整数倍で発生します。 

補題 4: 公分母を法とする有限個の有理時間状態を持つ決定論的システムは、最終的には周期的になります。 スケッチ: 単位の倍数として表される「最後のリセットからの時間」の可能な組み合わせは有限だけです。 鳩の巣原理によ​​り、システムは繰り返さなければなりません。 

最も困難な方向: 衝突の順序だけでなく、構成が本当に正確に前の半径に戻ることを確認します。 バーストが異なる相対時間で発生する可能性があることを見逃した場合、失敗する可能性が最も高い補題は補題 4 です。 

## 解決策

 3つのポイントを考慮してください$A$、$B$、$C$整数距離の平面上$AB = p$、$BC = q$、$CA = r$。 時間における円の半径を示す$t$として$R_A(t)$、$R_B(t)$、$R_C(t)$。 サークルは単位速度で成長するため、$R_X(t) = R_X(t_0) + (t-t_0)$衝突と衝突の間、どこで$t_0$はその円の最後の衝突時間です。 

補助定理 1. 2 つの円の最初の衝突は次の場合に発生します。$R_X + R_Y = d(X,Y)$。 両方がゼロから始まる場合、これは次の時点で発生します。$t = d(X,Y)/2$。 以来$d(X,Y)$が整数の場合、衝突時間は有理数になります。 

補題 2. 衝突後の時間$t_1$、関係する 2 つの円の半径は 0 にリセットされ、3 番目の円は直線的に増加し続けます。 将来の衝突は、距離から現在の半径を引いたものによって決まります。 円を仮定します$Z$影響を受けなかった。 次の衝突時の半径は$R_Z(t_1) = t_1$。 そして次の衝突は$X$時間に発生する$t_2$満足のいく$R_X(t_2) + R_Z(t_2) = d(X,Z)$。 以来$R_X(t_2) = t_2 - t_1$そして$R_Z(t_2) = t_1 + (t_2 - t_1) = t_2$、私たちは得ます$2 t_2 - t_1 = d(X,Z)$、 それで$t_2 = (d(X,Z) + t_1)/2$、合理的。 将来のすべての衝突時間は再帰的に合理的です。 

補題 3. させてください$D$のすべての分母の最小公倍数になる${p/2, q/2, r/2}$; この場合、すべての衝突時間は次の整数倍になります。$1/D$。 したがって、システムには、「最後のリセットからの時間」の倍数のタプルとして表現される有限の状態しかありません。$1/D$。 

補題 4. システムは決定論的です。 衝突のたびに、どの円がリセットされ、新しい時間の増分が正確に決定されます。 補助定理 3 に従って、可能な状態は有限に多くあります。鳩の巣原理によ​​り、システムは最終的に前の状態に戻らなければならず、その後は進化が同様に繰り返されます。 したがって、このプロセスは定期的です。 

特定の三角形に適用する:

 1. 辺のある正三角形$p$。 すべての最初の衝突は次の時点で発生します。$t = p/2$。 すべての円が同時にリセットされるため、システムは毎回繰り返します。$p/2$時間単位。 
2. 辺のある二等辺三角形$p,p,q$。 等しい辺に沿った衝突は次の場所で発生します。$t = p/2$; ベースに沿った衝突は次の場所で発生します$q/2$。 両方とも有理数であるため、一般論によれば、システムは周期的であり、周期は次の公倍数に等しくなります。$p/2$そして$q/2$。 
3. 直角三角形 3、4、5。 衝突時間は、$3/2$、$2$、$5/2$。 分母はすべて2なので、$D = 2$、衝突時間は の倍数です。$1/2$。 システムには有限の多くの状態があり、同じ引数により周期的です。 

これで証明は完了です。

 ## 主要な手順の検証

 補題 2 では注意深い代数が必要です。 以前は影響を受けなかった円の次の衝突の式を確認する: let$R_Z(t_1) = t_1$そして$R_X$ゼロにリセットされます。 それから$R_X(t) + R_Z(t) = (t - t_1) + t = 2t - t_1$、解決します$2t - t_1 = d(X,Z)$収量$t = (d(X,Z) + t_1)/2$。 これは小規模な数値テストと一致します: サイド 3 の場合、最初の衝突は次のとおりです。$t=3/2$、影響を受けない円との次の衝突は次のとおりです。$(4 + 3/2)/2 = 11/4$、 一貫性のある。 

補題 4 の有限性: 半径を次の倍数として表す$1/D$有限個のタプルのみが存在することを示しています。 3-4-5 三角形の場合、半径の増分は次の倍数です。$1/2$、それ以上ではありません$2d_i$リセット前の単位で、有限の状態空間を与えます。 最初の数サイクルのシミュレーションにより、繰り返しが確認されます。 

## 代替アプローチ

 1 つの代替方法は、システムを離散時間セル オートマトンとしてモデル化することです。この場合、各円の半径は有理周期を法として表されます。 これにより、問題は有限オートマトンの周期性の検証に集約されます。 組み合わせ的にはエレガントですが、整数の距離が合理的な衝突時間を生み出すという幾何学的な直観がわかりにくくなります。 別のアプローチでは連分数を使用して、共通分母を法とする一次関数の漸化式を調べますが、これにより不必要な複雑さが追加されます。 提示された方法は、整数辺の長さと線形成長を直接利用して、最も透明かつ一般的な方法で周期性を確立します。
