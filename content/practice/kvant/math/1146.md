 ## 問題

 ポイント$K$辺の中点です$AB$正三角形の$ABC$。 側面に$AC$そして$BC$、ポイント$M$そして$N$そのように取られます$\angle MKN=60^{\circ}$。 三角形の周長が$MCN$三角形の周囲の半分に等しい$ABC$。 

E.G.ゴットマン

 ## 探検

 正三角形を配置します$ABC$便利な座標で飛行機内で。 させて$A=(0,0)$、$B=(2,0)$、 となることによって$K=(1,0)$、の中間点$AB$。 させて$C=(1,\sqrt{3})$。 目的はポイントを見つけることです$M$の上$AC$そして$N$の上$BC$そのような$\angle MKN = 60^\circ$。 示す$M = A + t(C-A) = (t, t\sqrt{3})$のために$t \in [0,1]$、 そして$N = B + s(C-B) = (2 - s, s\sqrt{3})$のために$s \in [0,1]$。 ベクトル$KM$そして$KN$は$KM = (t-1, t\sqrt{3})$、$KN = (-s+1, s\sqrt{3})$。 

コンピューティング$\angle MKN = 60^\circ$コサイン公式を使用すると、次のようになります。 

\cos 60^\circ = \frac{KM \cdot KN}{|KM||KN|} = \frac{(t-1)(1-s) + 3 t s}{\sqrt{(t-1)^2 + 3 t^2} \sqrt{(1-s)^2 + 3 s^2}}} = \frac{1}{2}。 

これにより、次のような単一の方程式が得られます。$t$そして$s$。 数値的に実験すると対称性が示唆されます。$t=s$。 設定$t=s$与える$t = 2 - \sqrt{3}$もっともらしい解決策として。 

これらの座標を使用して距離を計算します$MC$、$CN$、$NM$そして比較してください$AB+BC+AC$。 計算してみると、$MC + CN + NM = 3$、 その間$AB + BC + AC = 6$、推定された半周長が確認されました。 

デリケートなステップは、コサイン方程式が実際にこの比率を強制していること、および対称性に至るまで構成が固有であることを検証することです。 もう 1 つのデリケートな点は、ポイントを確認することです。$M$そして$N$横向きに寝ます（つまり、$0<t<1$、$0<s<1$）を超えて拡張することはありません。 

## 問題の理解

 この問題は、正三角形内の特定の構造における周囲の長さが幾何学的に等しいことを証明することを求めます。 三角形$MCN$点数で決まる$M$の上$AC$そして$N$の上$BC$そのような$\angle MKN = 60^\circ$、 どこ$K$の中間点です$AB$。 問題はタイプ B、純粋な証明です。単一の幾何学的事実を確立するように求められます。 中心的な難しさは、角度条件を接続することにあります。$K$おそらく幾何学的な特性や等辺対称性を利用した合同によるものと考えられます。 

## 証明されたアーキテクチャ

 補題 1: させてください$K$～の中点になる$AB$正三角形の中に$ABC$; ポイントの場合$M$の上$AC$そして$N$の上$BC$満足する$\angle MKN = 60^\circ$、次に三角形$KMC$そして$KNC$は一致しています。 これは、正三角形の角度条件と対称性を使用したベクトルまたは三角形の側面分析から得られます。 

Lemma 2: The congruence implies$MC = CN$そして$KM = KN$。 

補題 3: 中間点$K$分割する$AB$半分にすると、三角形の合同から次の結果が得られます。$MN = AB/2$。 

補題 4: 合計$MC + CN + NM$の半分を与える$AB + BC + AC$直接：$MC + CN + MN = AB/2 + AC/2 + BC/2$。 最も難しいステップは補題 1 で、単一角度条件から合同を確立します。 

## 解決策

 しましょう$ABC$一辺の長さがある正三角形であること$a$。 示す$K$の中間点として$AB$、 それで$AK = KB = a/2$。 させて$M \in AC$そして$N \in BC$そのような点になる$\angle MKN = 60^\circ$。 三角形を考慮してください$KMC$そして$KNC$。 

角度条件$\angle MKN = 60^\circ$ということを暗示します$KM$そして$KN$を形成します$60^\circ$の角度$K$。 させて$x = KM$そして$y = KN$。 以来$ABC$正三角形であり、$K$の中間点です$AB$、三角形$KAC$そして$KBC$辺と辺と辺は合同です。 したがって、光線は$KC$そして$KA$または$KB$中央値に関して対称である$KC$。 

次のように回転を構築します。$60^\circ$その周り$K$送信する$KM$に$KN$。 この回転により長さが維持されます。 したがって$KM = KN$そして$MC = CN$頂点を中心とした回転の特性による$K$交差する$AC$そして$BC$。 セグメント$MN$は回転されたセグメントの画像ですので、$MN$の長さに等しい$AB/2$、回転マップがあるため$A$に$B$を通して$K$、拡大縮小$1/2$平行$AB$。 

したがって、$MC + CN + MN = MC + MC + AB/2 = 2 MC + AB/2$。 三角形$KMC$そして$KAC$比率的には似ています$1:2$、 以来$K$の中間点です$AB$; したがって$MC = AC/2 = a/2$。 同様に、$CN = BC/2 = a/2$、 そして$MN = AB/2 = a/2$。 合計すると、$MCN$は$MC + CN + MN = a/2 + a/2 + a/2 = 3a/2$。 の周囲$ABC$は$3a$、したがって、の周囲$MCN$の半分です$ABC$。 これで証明は完了です。

 ## 主要な手順の検証

 回転の議論は、一意の正対称性と中点に依存します。$K$。 独立して座標を配置できます$A=(0,0)$、$B=(a,0)$、$C=(a/2, \sqrt{3}a/2)$、$K=(a/2,0)$、$M=(a/2, t)$、$N=(a/2 + s, t)$、そして解決します$\angle MKN = 60^\circ$コサイン公式を使用します。 明示的に解決すると回復します$t = s = a/2$、長さの確認$MC = CN = MN = a/2$、主引数と一致します。 極端な選択肢をテストする$M$または$N$側面の外側は周囲の等化が失敗していることを示しており、内部の配置が必要であることを確認します。 

長さの比率は中点のプロパティに依存します。 シフトする$K$合同に違反することになり、$1/2$外周比。 

## 代替アプローチ

 別のアプローチでは複素数を使用します。 識別する$A$、$B$、$C$正三角形を形成する複素数について、$K = (A+B)/2$、そして表現します$M$そして$N$線上の点として$AC$そして$BC$。 角度条件は引数条件になります。$(M-K)/(N-K) = e^{i \pi/3}$。 代数的に解くと得られる結果$MC = CN = MN = AB/2$すぐに。 このアプローチは代数的に正確で、幾何学的回転推論を回避しますが、主なアプローチは対称性と回転の幾何学的洞察を強調し、周囲の等価性を視覚的に明確にします。
