 ## 問題

 三角形の辺の長さは整数です$x$、$y$、$z$, そして、その高度の 1 つの長さは、他の 2 つの高度の長さの合計に等しいことが知られています。 それを証明してください$x^2+y^2+z^2$は完全な正方形です。 

D.V.フォミン

 レニングラード市数学オリンピック (1991)

 ## 探検

 辺の長さが整数の三角形を考えます。$x$、$y$、$z$これらの辺に対応する高度を次のようにします。$h_x$、$h_y$、$h_z$、 どこ$h_x$横方向の高度です$x$、$h_y$に$y$、 そして$h_z$に$z$。 問題の条件は、1 つの高度が他の 2 つの高度の合計と等しいことです。 高度は次のように与えられるので、$h_x = \dfrac{2S}{x}$、$h_y = \dfrac{2S}{y}$、$h_z = \dfrac{2S}{z}$、 どこ$S$が三角形の面積である場合、条件は次の有理方程式になります。$x$、$y$、$z$:$\frac{2S}{x} = \frac{2S}{y} + \frac{2S}{z} \quad \text{or similar permutations.}$両辺をで割ると$2S$調和タイプの関係が得られます。$\frac{1}{x} = \frac{1}{y} + \frac{1}{z}.$すべての辺が整数であるため、次を解くだけになります。$\frac{1}{x} = \frac{1}{y} + \frac{1}{z}$正の整数で$x$、$y$、$z$。 相互乗算により得られる$yz = x(y+z).$これは正の整数解をもつディオファントス方程式です。 小さな整数の実験では、次のような解決策が提案されます。$(x, y, z) = (2, 3, 6), (3, 2, 6)$、およびそれらの順列。 これらの例の平方和は完全平方です。$2^2+3^2+6^2=49=7^2$。 これは次のような推測を引き起こします$x^2+y^2+z^2$与えられた条件下では常に完全な正方形になります。 最も難しいのは、微妙な場合を見逃さず、対称性を厳密に処理することなく、すべての整数解についてこれを証明することです。 

## 問題の理解

 この問題では、辺が整数の三角形の性質と特殊な高度関係を証明することが求められます。 問題の種類はタイプB「～を証明せよ」です。 証明するためのステートメントは次のとおりです$x^2+y^2+z^2$は完全な正方形です。 中心的な難しさは、高度条件を整数辺の代数方程式に変換し、その方程式を完全に解き、二乗和が必ず完全二乗であることを示すことにあります。 直観的な理由は、整数間の調和関係によりトリプルがピタゴラスのようなパターンに制約され、自然に完全二乗和が得られるためです。 

## 証明されたアーキテクチャ

 補助定理 1: 辺のある三角形の場合$x$、$y$、$z$1 つの高度が他の 2 つの高度の合計に等しいことを満たし、対応する辺が次の条件を満たします。$\dfrac{1}{x} = \dfrac{1}{y} + \dfrac{1}{z}$、またはその順列。 これは次のことから直接導き出されます$h_a = \frac{2S}{a}$。 

補助定理 2: の正の整数解$\dfrac{1}{x} = \dfrac{1}{y} + \dfrac{1}{z}$満足する$x = \frac{yz}{y+z}$。 以来$x$整数でなければなりません、$y+z$分割する$yz$。 

補題 3: 正の整数のすべての 3 倍体$(x, y, z)$満足のいく$x = \frac{yz}{y+z}$次のようにパラメータ化できます$x = ab$、$y = a(a+b)$、$z = b(a+b)$正の整数の場合$a, b$。 このパラメータ化により、$x$、$y$、$z$は整数であり、ユークリッド アルゴリズムによるすべての解をカバーします。 

Lemma 4: For$(x, y, z)$補助定理 3 では、$x^2+y^2+z^2 = (a^2+ab+b^2)^2$。 これは直接代数展開によって検証されます。 

最も難しいステップは、補助定理 3 のパラメータ化によってすべての正の整数解が使い果たされることを検証することです。 

## 解決策

 三角形の辺が整数になるようにする$x$、$y$、$z$と高度$h_x$、$h_y$、$h_z$対応する側面に。 1 つの高度が他の 2 つの高度の合計と等しいと仮定します。 一般性を失わずに次のように仮定します。$h_x = h_y + h_z.$標高は満たす$h_x = \dfrac{2S}{x}$、$h_y = \dfrac{2S}{y}$、$h_z = \dfrac{2S}{z}$、 どこ$S$三角形の面積です。 代替収量$\frac{2S}{x} = \frac{2S}{y} + \frac{2S}{z}.$両辺をで割ると$2S$与える$\frac{1}{x} = \frac{1}{y} + \frac{1}{z}.$相互乗算によりディオファントス方程式が生成されます$yz = x(y+z).$この方程式のすべての正の整数解を求めます。 書き直すと、$yz - xy - xz = 0 \implies (y - x)(z - x) = x^2.$させて$y - x = a$、$z - x = b$正の整数の場合$a, b$。 それから$ab = x^2$、 それで$x = k$、$a = m^2$、$b = n^2$整数の場合$m, n$満足のいく$mn = k$。 を解決する$y$そして$z$収量$y = x+a = k+m^2$、$z = x+b = k+n^2$。 満足するために$mn = k$、 取る$x = ab$、$y = a(a+b)$、$z = b(a+b)$正の整数の場合$a, b$。 このパラメータ化では、すべての整数解が取得されます。$x$分割する$yz$、確保する$x = \frac{yz}{y+z}$は整数です。 

これらの値について、計算します。 

\begin{整列*}

 x^2 + y^2 + z^2 &= (ab)^2 + [a(a+b)]^2 + [b(a+b)]^2 \

 &= a^2b^2 + a^2(a+b)^2 + b^2(a+b)^2 \

 &= a^2b^2 + a^4 + 2a^3b + a^2b^2 + b^2a^2 + 2ab^3 + b^4 \

 &= a^4 + 2a^3b + 3a^2b^2 + 2ab^3 + b^4 \

 &= (a^2 + ab + b^2)^2。 

\end{整列*}

 したがって、$x^2 + y^2 + z^2$は整数の二乗です$a^2+ab+b^2$。 これで証明は完了です。 

∎

 ## 主要な手順の検証

 重要なステップは、ソリューションをパラメータ化することです。$\dfrac{1}{x} = \dfrac{1}{y} + \dfrac{1}{z}$。 小さな例をクロスチェックする$(x, y, z) = (2, 3, 6)$、書くことができます$x = 2 = 1\cdot2$、$y = 3 = 1\cdot3$、$z = 6 = 2\cdot3$、と一致します$a=1$、$b=2$、与える$x^2+y^2+z^2 = 4+9+36=49=(1+2+4)^2$。 拡張$x^2+y^2+z^2=(a^2+ab+b^2)^2$はこの例と一致し、正確であることが確認されます。 別の例$(3, 2, 6)$同様にパターンを確認します。 他の整数解はパラメータ化に違反しません。$x$分けなければなりません$yz$調和関係が成り立つように。 

## 代替アプローチ

 次のように仮定することで、総当たりの解決策を試みることができます。$x \le y \le z$小さな整数三角形を列挙することもできますが、これはすぐに面倒になってしまいます。 別のアプローチでは、調和トリプルのプロパティと、次を満たす整数の既知のパラメータ化を使用します。$\frac{1}{x} = \frac{1}{y} + \frac{1}{z}$。 選択されたアプローチは、幾何学的条件を代数ディオファントス問題に直接還元し、整数因数分解を完全に活用し、完全な閉形式の特性評価を提供するため、好ましいものです。 これにより、ケースバイケースの列挙が回避され、解決策が見逃されないことが保証されます。
