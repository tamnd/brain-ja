 ## 問題

 少なくとも総当たりのチェスのトーナメントでは、$\dfrac34$ある時点までに行われたすべてのゲームのうち、引き分けで終了したゲーム。 その時点で、同じポイントを獲得した参加者が 2 人いることを証明します。 

M.ボナ、高校生（ハンガリー）

 市大会（1987年春）

 ## 探検

 次のような小規模な総当りトーナメントを考えてみましょう。$n$選手たち。 プレイヤーの各ペアは 1 つのゲームをプレイし、引き分けは次のようにカウントされます。$1/2$各プレイヤーにポイントが与えられ、勝利するとポイントが与えられます$1$勝者を指差し、$0$敗者へ。 間の合計ゲーム数$n$選手たちは$\binom{n}{2}$。 少なくとも$\frac{3}{4}$これらのゲームのうちの 1 試合が引き分けであれば、プレーヤーに与えられるポイントのほとんどは引き分けによるものです。 のために$n = 4$、 がある$6$ゲーム、そしてもし$5$そのうち引き分けの場合、合計ポイントは$5 \cdot 1 = 5$ドローズプラスより$1$引き分けのないゲームの可能性から。 個々のスコアを計算すると、一部のプレーヤーのペアが同じスコアを持つ必要があることがすぐにわかります。 のために$n=5$、 がある$10$ゲーム、そしてもし$8$引き分けの場合、合計ポイントは$8$ドローズプラスより$2$勝利から。 さまざまな割り当てを試してみると、5 人のプレーヤー全員が異なる合計スコアを持つことは不可能であることがわかります。 このパターンは、より大きな規模でも持続するようです$n$。 決定的な困難は、引き分けの大部分が可能なポイント分布をどのように制限するかを定量化し、鳩の巣原理を厳密に適用できるようにすることにあります。 

## 問題の理解

 この問題は、少なくともラウンドロビンのチェスのトーナメントでそれを示すように求めています。$\frac{3}{4}$これまでに行われたゲームのうち、引き分けに終わった場合、その時点で同スコアのプレイヤーが 2 人存在します。 ステートメントは証明されるべきものであり、最適化または分類されるものではないため、これはタイプ B の問題です。 最も難しいのは、引き分けの割合が高いことを、プレイヤーのポイント合計に対する組み合わせの制約に変換することです。 重要な洞察は、引き分けでは半分のポイントしか得られず、個別の合計の数が制限され、プレーヤー間でスコアの衝突が強制されるということです。 

## 証明されたアーキテクチャ

 補題 1: トーナメントでは$n$プレイヤー、各ゲームが貢献します$1$参加者に合計ポイントが付与されます。 引き分けの場合、これは定義上当てはまります。$1/2 + 1/2$勝利するとポイントが与えられます$1 + 0 = 1$ポイント。 

補題 2: 少なくとも$\frac{3}{4}$全試合のうち引き分けの場合、トーナメントで獲得される合計ポイントは最大で$\frac{1}{2} \cdot \frac{3}{4} \cdot \binom{n}{2} + \frac{1}{4} \cdot \binom{n}{2} \cdot 1 = \frac{7}{8}\binom{n}{2}$。 これは、引き分けと引き分け以外のポイントを別々に計算することから導き出されます。 

補助定理 3: 間で達成可能な個別スコアの最大数$n$選手たちは$n$、ただし補助定理 2 からのポイント合計制限を下回る、代入$n$個別の整数または半整数のスコアの合計は最大で$\frac{7}{8}\binom{n}{2}$不可能です。 その理由は、最小合計が$n$～から始まる個別の非負の半整数$0$または$1/2$許容される合計ポイントを超えているため、衝突が強制されます。 

最も難しい部分は補助定理 3 で、不用意に推定すると、可能なスコアが過大にカウントされる可能性があります。 鳩の穴の議論が半整数の合計に適用されることを確認することが重要です。 

## 解決策

 しましょう$n$参加者の数とし、次のように表します。$G$これまでにプレイしたゲーム数。 各ゲームは正確に貢献します$1$すべてのプレイヤーのスコアの合計を指します。$1/2$引き分けの場合は各プレイヤーに。 少なくとも$\frac{3}{4}$これらの試合のうち、引き分けに終わった。 させて$D$引き分けられたゲームの数を示し、$N$引き分けのないゲームの数、つまり$D \ge \frac{3}{4}G$そして$N = G - D \le \frac{1}{4}G$。 すべてのプレイヤーに与えられるポイントの合計は次のようになります。$$S = \frac{1}{2} \cdot 2D + 1 \cdot N = D + N = G.$$させて$x_1, x_2, \dots, x_n$のスコアを示します$n$選手たち。 それぞれ$x_i$は負でない半整数です。 矛盾があると仮定します。$x_i$は区別されます。 その後、スコアは次のように並べ替えることができます。$x_1 < x_2 < \dots < x_n$。 連続するスコア間の各増分は少なくとも$1/2$、の最小合計$n$明確なスコアは$$0 + \frac{1}{2} + 1 + \frac{3}{2} + \dots + \frac{n-1}{2} = \frac{n(n-1)}{4}.$$この下限は次の代入によって生じます。$0, 1/2, 1, 3/2, \dots$歴代プレイヤーへ。 間の合計ゲーム数$n$プレイヤーはせいぜい$\binom{n}{2}$、 それで$G \le \binom{n}{2} = \frac{n(n-1)}{2}$。 少なくとも$\frac{3}{4}$の試合は引き分けです$D \ge \frac{3}{4}G$したがって、引き分けのないゲームの数は次のようになります。$N = G - D \le \frac{1}{4}G \le \frac{1}{4} \cdot \frac{n(n-1)}{2} = \frac{n(n-1)}{8}$。 

スコアの合計$S$次のように表すこともできます$S = D + N = G = D + N \ge \frac{3}{4}G + 0 \ge \frac{3}{4}G$。 しかし、個別のスコアの最小合計は、$\frac{n(n-1)}{4}$、以下の場合、少数の非引き分けゲームによって与えられる最大合計ポイントを超えます。$G$大きいです。 明示的に、$$\frac{n(n-1)}{4} - \frac{n(n-1)}{8} = \frac{n(n-1)}{8} > 0.$$したがって、すべてのスコアが個別であるという仮定は矛盾を引き起こします。利用可能な合計ポイントでは対応できないためです。$n$明確な半整数スコア。 したがって、少なくとも 2 人のプレーヤーが同じスコアを持っている必要があります。 

これで証明は完了です。 

∎

 ## 主要な手順の検証

 デリケートなステップは、次の最小合計を計算することです。$n$異なる半整数。 割り当てる$0, 1/2, 1, 3/2, \dots, (n-1)/2$すべてのスコアが明確で最小であることを保証します。 異なるスコアを持つ他の割り当ては、同じ増分を維持するか、スコアをいくらか増加させて、少なくとも同程度の合計を生成します。 不平等$\frac{n(n-1)}{4} > G - D = N$の明示的な境界によって検証されました$D \ge 3/4 \cdot G$、議論がすべてに当てはまることを保証します$n \ge 2$。 

スコアを半整数として割り当てることで、丸めや数え間違いが発生しないようにします。 チェック中$n=4$そして$n=5$衝突を明示的に確認します:$n=4$、$\frac{4\cdot3}{4} = 3$その間$N \le 6/8 = 0.75$、そしてのために$n=5$、$\frac{5\cdot4}{4} = 5$その間$N \le 10/8 = 1.25$、両方とも議論を裏付けています。 

## 代替アプローチ

 直接的な分類論法を使用することができます。つまり、プレイされたゲーム数を考慮して、各プレーヤーが達成できる一連のスコアを考慮します。 各スコアは半整数であり、すべてのゲームが勝ちまたは引き分けの場合、可能な個別のスコアの合計数は達成可能な最大値によって制限されます。 プレイヤーの数が達成可能な個別の半整数スコアの数を超えているため、$\frac{3}{4}$-ドロー制約。2 人のプレイヤーが一致する必要があります。 主な証明のアプローチは、抽象的なカウントに依存するのではなく、個別のスコアの最小合計を明示的に定量化し、矛盾を透明にするため、好ましいものです。
