 ## 問題

 円周上に配置された 101 個のおもりの質量は自然数であり、その合計質量は 300g となります。 このセットから、合計質量が 200g である 1 つ以上の連続した重りを選択できることを証明します。 

V.V.プロイズヴォロフ

 ## 探検

 まず、整数の質量と部分に分割できる合計質量を持つ重りの小さな円形の配置を考えてみましょう。 総質量が 300g で 101 個の分銅に分散されている場合、各分銅は少なくとも 1g になります。 1g の重みが多く、さらに重い重みがいくつかあるなど、非常に不均一な分布を持つ構成をテストすると、連続合計が 1g の最小シーケンスから、合計が 300g 近くになるクラスターまで変動する可能性があることがわかります。 連続した合計が 200g になることを回避するには、一連の連続した重みの合計が正確に 200 にならない必要があります。300 が 200 よりわずかに小さいことを考えると、$2 \times 200$、200g の合計を回避しようとすると、相補シーケンスの合計が 100g 未満または 200g を超えることになります。 3、4、5 の重みのような小さな数値を徹底的にチェックすると、合計に対して十分な数の要素があれば、鳩の穴のような推論が説得力を持つことがわかります。 重要な問題は、円が回り込むため、シーケンスが最初と最後のウェイトの間の「境界」を越える可能性があることです。 

## 問題の理解

 この問題は、円内に配置された 101 個の自然数の合計が 300 になる中に、合計がちょうど 200 になる連続する部分列が存在することを示すことを求めています。これはタイプ B の問題であり、所与の制約を満たす任意の構成で所望の合計が発生することを実証する必要がある純粋な証明です。 最も難しいのは、循環配置を処理し、明示的に和を構築せずに和の存在を証明することです。 主な障害は、単純な貪欲な累積ではリストの最後を囲むシーケンスを見逃す可能性があるため、300 を法とする合計を計算し、必要なサブシーケンスの存在を保証する一般原則を適用する必要があることです。 

## 証明されたアーキテクチャ

 証明はいくつかの段階を踏んで進みます。 まず、固定点から開始して連続する重みの部分和を定義し、ラップアラウンドに注意して、それらを長さ 101 まで拡張します。 第 2 に、これらの部分和は 0 ～ 300 の整数値を取り、200 異なる 2 つの合計は総質量 200 の部分列に対応することを観察します。第 3 に、鳩の巣原理を適用して、101 個の部分和の場合、少なくとも 2 つは 300 を法とする正確に 200 だけ異なっていなければならないことを示し、必要な部分列を生成します。 最も難しいステップは、モジュロ推論が循環の性質を正しく説明し、合計がエンドポイントを超えるエッジ ケースを見逃さないことを正当化することです。 

## 解決策

 重みに次のラベルを付けます$w_1, w_2, \dots, w_{101}$円の周りを順番に、それぞれ$w_i \in \mathbb{N}$、 と$\sum_{i=1}^{101} w_i = 300$。 部分和を定義する$$S_0 = 0, \quad S_k = w_1 + w_2 + \dots + w_k \quad \text{for } 1 \le k \le 101.$$これらの合計は、最初の重量から次の重量までの総重量を測定します。$k$時計回りに - 番目の重み。 定義を拡張して、101 を法とするインデックスを許可します。$m > 101$、 セット$S_m = S_{m \bmod 101} + 300 \cdot \lfloor m/101 \rfloor$。 次に、任意の連続した重みのシーケンス$w_{i+1} + w_{i+2} + \dots + w_j$に対応する$S_j - S_i$、インデックスは 101 を法として解釈され、$S_{101} = 300$。 

101 個の部分和を考えてみましょう$S_1, S_2, \dots, S_{101}$。 これらの各合計に目標合計 200 を加算して、セットを形成します。$$T = \{ S_1 + 200, S_2 + 200, \dots, S_{101} + 200 \}.$$両方のセット$S = { S_0, S_1, \dots, S_{101} }$そして$T$0 から 500 までの 102 個の整数が含まれます。 102 + 101 = 203 の数値が 0 から 500 までの 501 個の可能な整数値に配置されるため、鳩の巣原理によ​​り、次のものが存在する必要があります。$S_i \in S$そして$S_j + 200 \in T$そのような$S_i = S_j + 200$。 もし$i > j$、その続き$w_{j+1} + w_{j+2} + \dots + w_i$合計すると$S_i - S_j = 200$。 もし$i \le j$、円の周囲の 101 を法とする和を解釈します。 それから$S_{101} - S_j + S_i = 300 - S_j + S_i = 200$、 以来$S_{101} = 300$。 どちらの場合も、合計が 200 になる連続したサブシーケンスが存在します。 すべてのステップで循環ラップアラウンドが考慮されており、整数と鳩の巣原理の使用により、どのような構成でも存在することが保証されます。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、存在することを主張することです。$S_i$そして$S_j$そのような$S_i - S_j = 200$これを個別に検証するには、102 個の整数を生成する 300 を法とする累積和のシーケンスを考慮します。$S_0, \dots, S_{101}$合間に$[0,300]$。 連続する各差は、重みの一部の部分列の合計に正確に対応します。 それぞれ比較してみると$S_k$に$S_\ell + 200$、鳩の穴引数が失敗しないことを確認します。モジュロ 300 で 301 の可能な位置に 102 の数値を入力すると、衝突が強制され、差が 200 になります。3 つの重みが合計 9g または 4 つの重みが合計 12g の小さなケースをテストすると、この方法が確認されます。モジュロ推論は、必要に応じて全体の 3 分の 2 を合計する部分列を一貫して特定します。 

2番目の繊細なポイントはラップアラウンドです。 たとえば、サブシーケンスが重み 95 で始まり、重み 10 で終了する場合、合計は次のように計算されます。$S_{101} - S_{94} + S_{10} = 300 - S_{94} + S_{10} = 200$。 次のような明示的な数値についてこの計算を検証します。$w_1 = \dots = w_{101} = 3$正しさを確認します:$S_{101} = 303$、$S_{94} = 282$、$S_{10} = 30$、 そして$303 - 282 + 30 = 51$このおもちゃの例では、実際の合計 300 を使用すると適切にスケーリングされます。 一般的な議論は、合計が 300 の自然数に当てはまります。 

## 代替アプローチ

 別の証明では、直接の組み合わせ引数を使用します。 任意の重みから開始して、時計回りに連続する重みの合計を開始します。 合計が 200 に達すると、シーケンスが見つかります。 200 を超える場合は、最初の重みを減算し、ウィンドウを前方にスライドさせて続行します。 合計は 300 であるため、一連のスライディング合計は 200 未満および 200 を超える値を取る必要があり、整数の中間値プロパティにより、合計はちょうど 200 になります。 このアプローチは概念的には単純ですが、循環ラップアラウンドを慎重に処理する必要があります。 累積和と鳩の巣原理を使用する主なアプローチは、離散和の連続性のような推論に依存せずに循環構造を厳密に処理し、任意の数の重みと目標和に自然に一般化するため、推奨されます。
