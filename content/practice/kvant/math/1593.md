## 畳み込みによる構造解釈

 メジャーを定義する$\mu_n = \sum_{m \in \mathbb{Z}} f_n(m) \, \delta_m,$どこ$\delta_m$は次のディラック測度です$m$。 したがって、再帰は畳み込みと等価です$\mu_n = \mu_{n-1} * (\delta_{-2^n} + \delta_0 + \delta_{2^n}).$反復収量$\mu_n = \bigast_{k=0}^n (\delta_{-2^k} + \delta_0 + \delta_{2^k}).$各因子はゼロ付近の反射に関して対称であるため、$\mu_n$対称的であり、$f_n(m) = f_n(-m)$みんなのために$m$。

## マキシマイザーの識別

 誘導を続けます$n$。 のために$n = 0$、可能な合計の順序は次のとおりです。$-1, 0, 1$、 そして$f_0(0) = 1$に等しい$f_0(-1)$そして$f_0(1)$, so the statement holds trivially. 一部の人にとっては$n-1$、$f_{n-1}(m)$単峰性かつ対称的であり、次の時点で最大値に達します。$m = 0$。 

考慮する$f_n(m)$と$m \ge 0$。 再発により$f_n(m) = f_{n-1}(m) + f_{n-1}(m - 2^n) + f_{n-1}(m + 2^n).$以来$m \ge 0$、$m + 2^n > 0$そして$m - 2^n \le m$等しい場合のみ$m = 2^n$。 帰納法仮説により、$f_{n-1}(k)$は増加していない$k \ge 0$、 それで$f_{n-1}(m - 2^n) \le f_{n-1}(0)$そして$f_{n-1}(m) \le f_{n-1}(0)$。 さらに、$f_{n-1}(m + 2^n) \le f_{n-1}(0)$。 したがって、$f_n(m) \le f_{n-1}(0) + f_{n-1}(0) + f_{n-1}(0) = 3 f_{n-1}(0) = f_n(0).$平等は次の場合にのみ発生します。$m = 0$。 したがって、$f_n(m)$で最大値に達します$m = 0$。 これで誘導は完了です。
