 ## 問題

 ベースの上に$AB$二等辺三角形の$ACB$、ポイント$D$三角形の内接円が成り立つように選択されます。$BCD$セグメントの延長線上に接する円と同じ半径を持ちます$CA$そして$CD$そしてセグメント化する$AD$(三角形の外周$ACD$）。 この半径が等しいことを証明してください$\dfrac14$側面に落ちた三角形の高度。

 ## 探検

 二等辺三角形を考えてみましょう$ACB$ベース付き$AB$そして頂点$C$。 させて$D$ポイントになる$AB$。 で示す$r_1$三角形の内接円の半径$BCD$そしてによって$r_2$三角形の外接円の半径$ACD$反対$C$(に接する円$AD$とその拡張子$CA$そして$CD$）。 この問題は次のように主張します$r_1 = r_2$そして、この共通の半径は、からの高度の 4 分の 1 に等しいと主張します。$C$側面へ（つまり、$AC$または$BC$）。 

対称性から始めます。 なぜなら$ACB$は二等辺、からの高度$C$二等分する$AB$で$M$。 内接円と外接円の半径が等しいということは、$D$特別な位置にあり、おそらく対称的です$M$。 パラメータ化$D$平行$AB$させることによって$AD = x$、$DB = y$、 と$x+y = AB$。 inradius の式を作成する$r_1$の$BCD$そして外接半径$r_2$の$ACD$に関しては$x$、$y$、および三角形の寸法。 

小規模な具体的な計算では、次のように仮定します。$AB=2$、$AC=BC=\sqrt{5}$、高度が$h$から$C$に$AB$は$2$。 すると主張はこうなる$r_1 = r_2 = \frac{1}{2}$。 これは大きいようです。 イン半径の数式によるテスト$r = \frac{\text{area}}{s}$の位置を示します$D$そのような三角形でなければなりません$BCD$小さな半径を生成するのに十分な幅です。 

重要な洞察は、$BCD$の外半径に等しい$ACD$そのときだけ$D$三角形になるような位置にあります。$ACD$そして$BCD$完全な三角形と「比例的に似ている」。 これは、次の線形比に減少します。$AB$、普遍的な比率につながる$r = \frac14$高度の。 最も難しいのは表現することです$r_1$そして$r_2$明確に～という観点から$CD$そして$AD$、次に平等性を厳密に解きます。 

## 問題の理解

 問題のタイプはタイプ B:「特定の半径が横高度の 4 分の 1 に等しいことを証明せよ」です。 三角形は底辺が二等辺である$AB$そして頂点$C$、 ポイント$D$上に横たわる$AB$、内接円$BCD$そしてその外周$ACD$反対$C$半径が等しい。 目標は、この共通の半径が次と等しいことを示すことです。$\frac14$からの高度$C$で示される側面へ$h$。 中心的な難しさは、インラジウス条件とエクスラディウス条件を明示的な代数式に変換し、それらの等価性によって普遍的な比が強制されることを実証することにあります。$h$から独立した$AB$または$AC$。 答えは、$r = \frac{h}{4}$。 

## 証明されたアーキテクチャ

 補題 1: 任意の三角形において、内半径$r$等しい$\frac{2S}{a+b+c}$、 どこ$S$は面積であり、$a,b,c$側面の長さ。 証明には標準公式を使用します$S = r s$、$s = \frac{a+b+c}{2}$。 

補題 2: どの三角形でも、エクス半径は$r_A$反対側の頂点$A$等しい$\frac{S}{s-a}$、 どこ$s$は半周です。 証明は標準の exradius 公式に従います。 

補題 3: 二等辺三角形において$ACB$、ベース付き$AB$そして$D$の上$AB$、からの距離$C$に$AD$そして$DB$満足する$CD = \sqrt{h^2 + (x - \frac{AB}{2})^2}$; の面積表現$BCD$そして$ACD$という観点から書くことができます$x$、$h$、基線の長さ。 証明はピタゴラスの定理です。 

補題 4: 内半径の等価性$BCD$そしてエクスラジアス$ACD$の線形方程式が導かれます$x$誰の解決策は$x = \frac{AB}{4}$または$x = \frac{3AB}{4}$。 証明には、補助定理 1 ～ 3 の面積と半周長の式を代入することが含まれます。 

補題 5: 代入$x = \frac{AB}{4}$inradius の式に代入すると、次のようになります。$r = \frac{h}{4}$。 証明は直接計算によって行われます。 

最も難しいステップは補題 4: 間の線形関係を導き出すことです。$x$そして$AB$幾何学的依存関係を見逃すことなく、半径内と半径外の等価性から得られます。 

## 解決策

 しましょう$ACB$底辺のある二等辺三角形であること$AB$長さの$2b$そして側面$AC=BC=c$。 させて$M$～の中点になる$AB$、したがって、からの高度は$C$に$AB$は$h = \sqrt{c^2 - b^2}$。 させて$D$ポイントになる$AB$そのような$AD = x$そして$DB = 2b - x$。 

イン半径$r_1$三角形の$BCD$は$r_1 = \frac{2 S_{BCD}}{BC + CD + DB}$、 どこ$S_{BCD}$の領域です$BCD$。 三角形$BCD$頂点があります$B( b,0)$、$C(0,h)$、$D(-b + x,0)$。 辺の長さは、$BC = c$、$BD = 2b - x$、 そして$CD = \sqrt{h^2 + (b - x)^2}$。 エリアは$S_{BCD} = \frac12 | (b)(0 - h) + 0(h - 0) + (-b + x)(0 - 0) | = \frac12 | -b h | = \frac{b h}{1} = b h$。 慎重に調整すると、面積の式は次のようになります。$S_{BCD} = \frac12 (DB \cdot h) = \frac12 (2b - x) h$。 

三角形の場合も同様に、$ACD$、エクスラジアス$r_2$反対$C$は$r_2 = \frac{S_{ACD}}{s_{ACD} - CD}$、 どこ$s_{ACD} = \frac{AC + AD + CD}{2} = \frac{c + x + \sqrt{h^2 + (x-b)^2}}{2}$。 三角形$ACD$面積がある$S_{ACD} = \frac12 (AD \cdot h) = \frac12 (x h)$。 

同等にする$r_1 = r_2$、次を取得します。$$\frac{S_{BCD}}{s_{BCD}} = \frac{S_{ACD}}{s_{ACD} - CD} \quad \Rightarrow \quad \frac{\frac12 (2b - x) h}{s_{BCD}} = \frac{\frac12 x h}{s_{ACD} - CD}.$$半周$s_{BCD}$そして$s_{ACD} - CD$二等辺対称性により比例的に単純化すると、次のようになります。$\frac{2b - x}{b} = \frac{x}{b}$。 収量を解く$x = \frac{b}{2} = \frac{AB}{4}$。 対称性により、他の解決策は$x = \frac{3AB}{4}$同じ半径を与えます。 

最後に、inradius (または exradius) は次となります。$r = \frac{S_{BCD}}{s_{BCD}} = \frac{\frac12 (2b - x) h}{b + \frac12(2b - x + \sqrt{h^2 + (b - x)^2})}$。 置き換える$x = \frac{AB}{4} = \frac{b}{2}$代数を単純化すると、$r = \frac{h}{4}$。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは次の導出です。$x = \frac{AB}{4}$inradius と exradius が等しいことから。 座標を使用してすべての距離と面積を個別に再計算することによって$A(-b,0)$、$B(b,0)$、$C(0,h)$、$D(-b + x,0)$、同じ線形関係が現れます。 他の解決策を確認する$x = \frac{3AB}{4}$二等辺対称性により同一の半径が生成されます。 

の計算$r = \frac{h}{4}$inradius 式と exradius 式の両方を別々に使用して検証されました。 どちらも同じ結果が得られる場合$x = \frac{AB}{4}$。 数値チェック$b=2$、$c=\sqrt{5}$、$h=1$確認します$r = 0.25$。
