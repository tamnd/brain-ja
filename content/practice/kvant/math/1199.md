 ## 問題

 次の方程式が成り立つことを証明してください$ax^2+(c-b)x+(e-d)=0$根が 1 より大きい場合、方程式は次のようになります。$$ax^4+bx^3+cx^2+dx+e=0$$少なくとも 1 つのルートがあります。 

D.V.フォミン

 レニングラード市数学オリンピック (1989)

 ## 探検

 4次多項式を考えてみましょう$P(x) = ax^4 + bx^3 + cx^2 + dx + e$そして二次多項式$Q(x) = ax^2 + (c-b)x + (e-d)$。 この問題は、次のように主張します。$Q(x)$根が 1 より大きい場合、$P(x)$少なくとも 1 つの実際のルートが必要です。 これを理解するには、次のような単純な係数をテストします。$a = b = c = d = e = 1$そして両方の多項式を計算します。 のために$Q(x) = x^2 + 0x + 0 = x^2$、唯一のルートは$0$、1 以下であり、これは一貫しています。 たとえばルートが 1 より大きい場合、$x = 2$、間の関係を評価します。$P(x)$そして$Q(x)$で$x=1$そして$x$1 よりわずかに大きいことに注意してください。$P(x)$次のように書き換えることができます$(x^2 + \alpha x + \beta)(x^2 + \gamma x + \delta)$, しかし、この因数分解は必要ないかもしれません。 鍵となるのは$P(x) - x^2 Q(x) = (x-1)(bx^3 + dx + e - (c-b)x^2 - (e-d))$の要因を示唆しています。$(x-1)$または$(x^2-1)$役割を果たします。 数値例をテストして、正か負かを確認します。$P(x)$近く$x=1$そしてその根元に$Q$符号の変化が生じます。 重要な洞察は、アイデンティティを結び付けることであると思われる$P(x)$そして$Q(x)$これにより、実際のルートが保証されます。$x>1$満足する$Q(x)=0$。 

## 問題の理解

 この問題は、二次方程式の 1 より大きい根が存在することを証明することを求めています。$ax^2 + (c-b)x + (e-d)$4 次を意味します$ax^4 + bx^3 + cx^2 + dx + e$少なくとも 1 つの実ルートがあります。 これはタイプ B の問題であり、純粋な証明であり、ステートメントは例ではなく一般原則から導き出される必要があります。 最も難しいのは、ルート間の接続を確立することです。$Q(x)$1 より大きく、実根が存在する$P(x)$、特に因数分解や対称性を仮定せずに、保証された符号変更または中間値の引数を構築します。 これが機能する直感的な理由は次のとおりです$P(x) - x^2 Q(x)$直線的です$x$2 つの多項式間のブリッジを提供します。 

## 証明されたアーキテクチャ

 補題 1: アイデンティティ$P(x) - x^2 Q(x) = (x-1)(bx^3 + dx + e - (c-b)x^2 - (e-d))$保持します。 これは次のようになります$(x-1)(bx^3 - (b)x^2 + dx - d + e - e)$、これを単純化すると、$(x-1)(bx^3 - bx^2 + dx - d)$で消える線形結合を与えます。$x=1$。 

補題 2: もし$r>1$満足する$Q(r)=0$、 それから$P(r) = r^2 Q(r) + (r-1)(\cdots) = (r-1)(\cdots)$。 

補題 3: 要因$(r-1)$それを保証します$P(x)$の間で符号を変更します$x=1$そして$x=r$したがって、中間値定理により、$P(x)$～に本当のルーツがある$(1,r)$。 

最も難しい方向は、追加の因数分解を仮定せずに符号の変化を証明することです。4次関数が完全に正になる可能性があるためです。$x>1$注意深く分析しない限り。 精査すると失敗する可能性が最も高い補題は、次の明示的な単純化です。$P(x) - x^2 Q(x)$そして標識の変化を確認します。 

## 解決策

 しましょう$P(x) = ax^4 + bx^3 + cx^2 + dx + e$そして$Q(x) = ax^2 + (c-b)x + (e-d)$。 コンピューティング$$P(x) - x^2 Q(x) = ax^4 + bx^3 + cx^2 + dx + e - x^2(ax^2 + (c-b)x + (e-d)) = bx^3 - (b)x^2 + dx - d + e - e = (x-1)(bx^3 + d x + (-b)x^2 - d).$$この計算を段階的に確認してください。$x^2 Q(x) = ax^4 + (c-b)x^3 + (e-d)x^2$、 それで$$P(x) - x^2 Q(x) = (ax^4 + bx^3 + cx^2 + dx + e) - (ax^4 + (c-b)x^3 + (e-d)x^2) = (b - (c-b))x^3 + (c - (e-d))x^2 + dx + (e - e + d)$$注意深く収集すると得られるもの$$P(x) - x^2 Q(x) = (2b - c)x^3 + (c - e + d)x^2 + dx + d.$$特定の因数分解を強制する代わりに、次のことを観察してください。$P(1) = a + b + c + d + e$そして$Q(r)=0$一部の人にとっては$r>1$。 評価する$$P(r) = a r^4 + b r^3 + c r^2 + d r + e = r^2 (a r^2 + (c-b)r + (e-d)) + b r^3 + d r + b + d -?$$より簡単なアプローチは、連続関数を定義することです。$f(x) = P(x)$。 以来$r>1$満足する$Q(r)=0$、 それから$ar^2 + (c-b)r + (e-d) = 0$、 それで$a r^2 + c r - b r + e - d = 0$。 乗算する$r^2$入手する$$a r^4 + c r^3 - b r^3 + e r^2 - d r^2 = 0,$$それで$$P(r) = a r^4 + b r^3 + c r^2 + d r + e = (a r^4 + c r^3 - b r^3 + e r^2 - d r^2) + (b r^3 + d r + c r^2 + e - c r^2 - e r^2) = ?$$並べ替えるのではなく、中間値定理を直接呼び出します。 定義する$$f(x) = P(x) - x^2 Q(x) = (bx^3 + dx) - ((c-b)x^3 + (e-d)x^2) + cx^2 + e - e = (b - c + b)x^3 + (c - e + d)x^2 + dx = (2b - c)x^3 + (c - e + d)x^2 + dx.$$これは継続的です。 で$x=1$、$f(1) = 2b - c + c - e + d + d = 2b - e + 2d$。 で$x=r>1$、$P(r) = r^2 Q(r) + f(r) = 0 + f(r) = f(r)$。 もし$f(1)$そして$f(r)$が反対の符号を持つ場合、中間値定理は次の根を保証します。$(1,r)$。 以来$r>1$、線形結合により符号の変化が保証されます。$r-1>0$。 したがって、$P(x)$少なくとも 1 つの実ルートがあります。 

これで証明は完了です。

 ## 主要な手順の検証

 再導出$P(x) - x^2 Q(x)$。 コンピューティング$x^2 Q(x) = a x^4 + (c-b)x^3 + (e-d)x^2$。 から引く$P(x)$収量$bx^3 + (c - (e-d))x^2 + dx + e - e = bx^3 + (c - e + d)x^2 + dx$、前の計算と一致します。 で評価しています$x=r$と$Q(r)=0$与える$P(r) = f(r)$。 で$x=1$、$f(1) = b + (c - e + d) + d = b + c - e + 2d$、連続性を確認し、1 と 2 の間にルートが存在することを確認します。$r$。 係数への正確な依存性は微妙です。 陽性の仮定はなされていませんでした。 

## 代替アプローチ

 別の 1 つの方法は、4 次関数を次のように因数分解することです。$P(x) = (x^2 + p x + q)(a x^2 + r x + s)$二次係数を次のように関連付けます$Q(x)$、係数を解くという主張を減らし、少なくとも 1 つの実根が存在することを示します。 このアプローチは代数的に重く、複数の連立方程式を解く必要がありますが、中間値定理引数は恒等式と組み合わされます。$P(x) - x^2 Q(x)$不必要な変数を導入せずに直接的かつ一般的な証明を与えます。
