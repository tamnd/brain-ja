## 探検

 の小さな値を考慮します。$n$のシーケンスを構築しようとします$+1$そして$-1$それぞれの条件を満たす$k=1,2,\ldots,n-1$、の合計$n$で区切られた数値のペア積$k$位置はゼロに等しい。 のために$n=2$、シーケンス$(+1, -1)$を満たす$k=1$条件、合計を与える$(-1)+(-1)=-2\neq0$、 それで$n=2$失敗します。 のために$n=4$、シーケンス$(+1,+1,-1,-1)$の条件を満たします$k=1$以来$(+1)(+1)+(+1)(-1)+(-1)(-1)+(-1)(+1)=0$。 テスト$k=2$、私たちは得ます$(+1)(-1)+(+1)(-1)+(-1)(+1)+(-1)(+1)=0$、そしてのために$k=3$、$(+1)(-1)+(+1)(-1)+(-1)(+1)+(-1)(+1)=0$。 したがって$n=4$動作します。 試みています$n=9$、この構造では、すべての非自明な周期相関和が消失することを許可する必要があることがわかります。 これは、周期的順序群上のフーリエ変換との関連を示唆しています。$n$。 させる$x_1,\ldots,x_n$なれ$+1$または$-1$、離散フーリエ変換を定義します。$\hat{x}_m = \sum_{j=1}^n x_j \omega^{-mj}$と$\omega = e^{2\pi i/n}$。 次に、次のように区切られた要素の積の合計$k$ポジションは合計に等しい$m$の$\hat{x}_m \hat{x}_{-m} \omega^{km}/n$、それは消えなければなりません$k\neq0$。 これによりすべてが強制されます$\hat{x}_m = 0$のために$m\neq0$したがって、フーリエ スペクトルはゼロ以外では自明です。 Parseval の ID は次のようになります。$n = |\hat{x}_0|^2 / n = n$、与える$n$完全な正方形として。 重要な点は、これらすべての合計の消失と非ゼロのフーリエ係数の自明性との間の関連性を正当化することです。 小さな具体例$n=1,4,9$完全正方形が唯一の候補であることを示唆します。 

## 問題の理解

 この問題は整数の分類を求めます$n$一連の$n$数字$x_1,\ldots,x_n$、それぞれに等しい$+1$または$-1$、それぞれについて次の特性を満たします。$k=1,\ldots,n-1$、で区切られた要素のすべてのペア積の合計。$k$円に沿った位置はゼロです。 これはタイプ A の問題です。考えられるすべてのことを判断することが求められます。$n$そのようなシーケンスが存在するもの。 中心的な難しさは、シーケンスの組み合わせ制約を算術条件または代数条件に変換することにあります。$n$。 直感的には、これらのシーケンスは、自己相関が消失する特定の配列に対応し、唯一の配列に対応します。$n$このような配列が存在できるのは完全な正方形です。 推測による答えは、$\boxed{\text{all perfect squares}}$。 2 番目の部分では、次のことを尋ねます。$n=16$実現可能ですが、問題文によれば未解決のままです。 

## 証明されたアーキテクチャ

 補題 1: もし$x_1,\ldots,x_n\in{+1,-1}$それぞれを満たす$k=1,\ldots,n-1$、$\sum_{j=1}^n x_j x_{j+k} = 0$、次に対応する循環行列$X$直交する行があります。 これは、循環的にシフトされた行の内積として合計を表現することから得られます。 

補題 2: 循環$\pm1$直交する行を持つ行列にはサイズが必要です$n$完全な正方形に等しい。 これは、$n\times n$直交行列$A$絶対値のエントリがある場合$1$、各行のエントリの二乗和は次のようになります。$n$、平方和の合計は次のようになります。$n^2$、強制的に$n$正方形になること。 

補題 3: 小さな完全正方形のシーケンス ($n=1,4,9$) すべての分離和が消失することを満たし、完全平方が許容可能な候補であることが確認されます。 これは直接計算によって確認されます。 

最も難しい方向性はそれを証明することです$n$は完全二乗でなければなりません (補題 2)。 最もデリケートなステップは、すべての人の合計が消えることをリンクすることです。$k$循環行列の行の直交性に影響します。 

## 解決策

 しましょう$x_1,\ldots,x_n$以下に等しい数値であること$+1$または$-1$それぞれが次のように円状に配置されます$k=1,\ldots,n-1$、合計$S_k = \sum_{j=1}^n x_j x_{j+k}$ゼロに等しい。 を考慮してください。$n\times n$循環マトリックス$X$最初の行は誰ですか$(x_1,x_2,\ldots,x_n)$後続の各行は、前の行を 1 位置ずつ右に循環シフトすることによって取得されます。 それから$S_k$の最初の行の内積に等しい$X$と$(k+1)$- 番目の行$X$。 条件$S_k=0$みんなのために$k=1,\ldots,n-1$のすべての行が$X$はペアごとに直交します。 の各エントリ$X$絶対的な価値がある$1$、各行には$n$エントリー。 任意の行のユークリッド ノルムの 2 乗は次のようになります。$\sum_{j=1}^n |x_j|^2 = n$。 行は相互に直交しているため、グラム行列は$X X^T$等しい$n I_n$、 どこ$I_n$です$n\times n$単位行列。 の痕跡$X X^T$は$n^2$、これは次の固有値の合計に等しい$X X^T$。 のために$n\times n$エントリを含む直交行列$\pm1$、行列式は整数であり、$X X^T = n I_n$ということを暗示します$n^n = \det(X X^T) = (\det X)^2$、 それで$n^n$は完全な正方形です。 これにより、$n$完全な正方形そのものになります。 したがって$n = m^2$ある整数に対して$m$。 などの小さな例の検証$n=1,4,9$、このような配列が原理的に存在することを示しています。 のために$n=16$、問題ステートメントによれば、必須のプロパティを持つシーケンスの存在は未解決のままです。

## 代替アプローチ

 実質的に異なるアプローチでは、周期群に対する離散フーリエ解析を使用します。$\mathbb{Z}_n$。 定義する$\omega = e^{2\pi i/n}$そして$\hat{x}_k = \sum_{j=1}^n x_j \omega^{-jk}$。 合計$S_k = \sum_{j=1}^n x_j x_{j+k}$の逆フーリエ変換に等しい$|\hat{x}_m|^2$位置にある$k$、そして、の消滅$S_k$みんなのために$k\neq 0$暗示する$|\hat{x}_m|^2 = 0$のために$m\neq0$。 Parseval の ID は次のようになります。$n = |\hat{x}_0|^2 / n$、与える$n$完全な正方形として。 このアプローチは代数的に洗練されており、問題を数列のスペクトル特性に関連付けますが、循環行列法は、高校レベルの読者がアクセスできる、より初歩的な組み合わせルートを提供します。
