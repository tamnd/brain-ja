 ## 問題

 多項式であることを証明する$p(x)$整数係数を使用し、次の 3 つの異なる整数値に対して値 1 をとります。$x$、整数の根を持つことはできません。 

## 探検

 多項式を考えてみましょう$p(x)$値を取る整数係数を使用$1$3 つの異なる整数で、たとえば$a$、$b$、 そして$c$。 示す$p(a) = p(b) = p(c) = 1$。 自然なアプローチは、シフトされた多項式を調べることです。$q(x) = p(x) - 1$、その後消滅します$x = a, b, c$。 したがって、$q(x)$には 3 つの異なる整数根があるため、次で割り切れます。$(x-a)(x-b)(x-c)$整数係数を使用します。 仮定する$p(x)$整数のルートもあります$r$。 それから$q(r) = p(r)-1 = -1$。 これにより、$(r-a)(r-b)(r-c) = -1$整数で。 次のステップは、3 つの整数の積が以下に等しいかどうかを分析することです。$-1$のいずれかにならずに$a$、$b$、 または$c$。 小さい整数の例をテストする場合、$(r-a)(r-b)(r-c) = -1$の場合、要素のうち 2 つは次のとおりである必要があります。$\pm 1$そして3番目$\mp 1$。 以来$a$、$b$、$c$は別個であり、順列はありません$\pm 1$違いは同時に区別できます。 したがって、方程式には整数解がありません。 重要な問題は、整数解が存在しないことを証明することです。$r$自明な少数の場合を仮定することなく存在することができます。 整数に対する慎重な組み合わせ引数が必要です。 

## 問題の理解

 この問題は、多項式が次のことを証明することを求めています。$p(x)$整数係数を使用し、値を受け取ります$1$3 つの異なる整数の場合、それ自体はどの整数でも消えることはありません。 これは、普遍的な記述の証明を求めるため、タイプ B の問題です。 核心的な困難は次のことを示しています。$p(r) = 0$たとえ起こり得ないとしても、$p(a) = p(b) = p(c) = 1$これには、整数の割り算と、異なる整数が異なる 3 つの整数の積を正確に分析する必要があります。 洞察としては、$1$整数係数を持つ 3 つの異なる線形因数で割り切れる多項式を与え、整数根はそれらの積を強制的に等しくします。$-1$、それは不可能です。 

## 証明されたアーキテクチャ

 補題 1: もし$p(x)$整数係数がある場合は、任意の整数に対して$r$、$a$、$b$、$c$、数量$(r-a)(r-b)(r-c)$分割する$p(r)-p(a)$整数で。 スケッチ: 次の事実を利用します。$p(x) - p(a)$で割り切れます$x-a$整数商を使用して再帰的に適用します。 

補題 2: 個別の整数の場合$a$、$b$、$c$、整数は存在しません$r$そのような$(r-a)(r-b)(r-c) = \pm 1$。 スケッチ: 差の絶対値を考慮します。 3 つの異なる整数は、その積が次のような 3 つのペアごとの差を持つことはできません。$\pm 1$。 

主なクレーム: 整数なし$r$満足する$p(r) = 0$。 スケッチ: しましょう$q(x) = p(x)-1$そして補題 1 と 2 を使ってそれを示します$q(r) = -1$には整数解がありません。 

最も難しいステップは補題 2 です。これは、整数に関する慎重な組み合わせ推論が必要であり、不注意な議論により次のような小さな例を見逃す可能性があるためです。$0$、$1$、$-1$。 

## 解決策

 しましょう$a$、$b$、$c$次のような 3 つの異なる整数になります。$p(a) = p(b) = p(c) = 1$。 多項式を定義する$q(x) = p(x) - 1.$それから$q(x)$整数係数を持ち、次の条件を満たします$q(a) = q(b) = q(c) = 0.$したがって、$q(x)$は、次の根に対応する線形因子の積で割り切れます。$q(x) = (x-a)(x-b)(x-c) \cdot s(x),$どこ$s(x)$は整数係数を持つ多項式です。 

矛盾するため、次のように仮定します。$p(x)$整数のルートがあります$r$。 それから$p(r) = 0$、 それで$q(r) = p(r)-1 = -1$。 因数分解に代入すると、$(r-a)(r-b)(r-c) \cdot s(r) = -1.$以来$r$、$a$、$b$、$c$整数です、$s(r)$も整数です。 したがって$(r-a)(r-b)(r-c)$の約数でなければなりません$-1$整数で。 唯一の整数の約数は、$-1$は$1$そして$-1$。 したがって、$(r-a)(r-b)(r-c) = \pm 1.$3 つの異なる整数を考えてみましょう$r-a$、$r-b$、$r-c$。 彼らの製品が$1$の場合、数値は次の順列でなければなりません。$(1, 1, 1)$、$(-1, -1, 1)$、または同様の組み合わせを与える$1$。 すべての可能性では、少なくとも 2 つの差異が等しい必要がありますが、$a$、$b$、$c$は異なるので、$r-a$、$r-b$、$r-c$は区別されます。 同様に、自社の製品が$-1$の場合でも、絶対値には整数の乗算を満たすために少なくとも 1 回の繰り返しが含まれている必要があります。 したがって、整数はありません$r$そのように存在します$(r-a)(r-b)(r-c) = \pm 1$。 

この矛盾は、整数が存在しないことを示しています$r$満足できる$p(r) = 0$。 

これで証明は完了です。

 ## 主要な手順の検証

 補助定理 2 では、3 つの異なる整数を次のように乗算することはできないという主張は、$\pm 1$小さな整数のすべての可能性を列挙することによって検証されました。絶対値は次のとおりである必要があります。$1$、そのうちの 3 つの数字を与える${-1, 1}$ただし、3 つの異なる整数がすべてこのセットに含まれることはできません。 この引数は、絶対値が より大きい整数であるため、より大きな整数にも当てはまります。$1$製品が超過する可能性があります$1$絶対値で言うと。 もう一つのデリケートなステップは因数分解です$q(x) = (x-a)(x-b)(x-c)s(x)$整数係数を使用します。 これは正当化されるため、$q(x)$は 3 つの異なる整数で消滅し、整数係数を持っているため、商は$s(x)$整数上の多項式の除算アルゴリズムによる整数係数も持ちます。 

## 代替アプローチ

 別のアプローチは、整数を法とする多項式を考慮することです。 たとえば、モジュロを削減すると、$p$プライムのために$p$合同を分析できるようになります:$p(r) = 0$、 それから$p(r) \equiv 0 \pmod{r-a}$、$r-b$、$r-c$、モジュラー演算に矛盾を強制します。 この方法は見た目は短いですが、素数を法とする割り算のプロパティに精通している必要があります。 主なアプローチは、初歩的な整数算術と基本的な因数定理のみに依存しており、高校生でも十分にアクセスできるため、推奨されます。
