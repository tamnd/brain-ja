 ## 問題

 2 つの正の数の積がそれらの合計より大きい場合、それらの合計は 4 より大きいことを証明します。 

N.B.ワシリエフ

 トーナメント・オブ・タウンズ (1990 年秋)

 ## 探検

 2 つの正の数を考えてみましょう$x$そして$y$そのような$xy > x + y$。 小さな整数のペアを試してみると、以下の数値では不等式が成り立たないことがわかります。$2$。 例えば、$x = y = 1$与える$xy = 1$そして$x + y = 2$、 それで$1 \not> 2$。$x = y = 2$与える$xy = 4$そして$x + y = 4$、 それで$4 \not> 4$。$x = y = 3$与える$xy = 9$そして$x + y = 6$、 それで$9 > 6$、これは機能します。 これは、次のことを示唆しています。$xy > x + y$、その後両方$x$そして$y$厳密には次より大きいです$2$。 次のようなわずかに非対称なケースのテスト$x = 1.5$そして$y = 3$、収量$xy = 4.5$そして$x + y = 4.5$これは等しいので、厳密にはまだ大きいわけではありません。 この探査は、臨界境界が近いことを示しています$2$、合計は次を超える必要があります$4$。 

核となる洞察は、不平等であるということです。$xy > x + y$と同等です$(x - 1)(y - 1) > 1$、これは問題をより単純な形に変換します。$x + y$透明になる。 最もデリケートなステップは、それを正当化することです$(x - 1)(y - 1) > 1$確かに暗示します$x + y > 4$すべてのポジティブのために$x$そして$y$。 

## 問題の理解

 私たちは普遍的な命題を証明するように求められています: 2 つの正の数の積がその合計を超える場合、それらの合計は を超えます$4$。 これはタイプ B の問題です。 困難は不平等を変えることにある$xy > x + y$合計を直接推論できる形式に変換する$x + y$。 重要な観察は、$x + y$両側から追加$1$下限を与える因数分解を行います。$x + y$。 この問題は一見初歩的ですが、不等式を正確に操作し、肯定的なものを注意深く扱う必要があります。 

## 証明されたアーキテクチャ

 Lemma 1: For any positive numbers$x$そして$y$、不等式$xy > x + y$と同等です$(x - 1)(y - 1) > 1$。 This follows by expanding$(x - 1)(y - 1)$そして用語を並べ替えます。 

補題 2: もし$x - 1 > 0$そして$y - 1 > 0$、 そして$(x - 1)(y - 1) > 1$、 それから$x + y = (x - 1) + (y - 1) + 2 > 4$。 これは、AM-GM に適用されるものに続きます。$(x - 1)$そして$(y - 1)$、ただし、合計が積の平方根の 2 倍を超えるため、直接検証することもできます。$2$。 

最も難しいステップは、両方を確実に行うことです。$x - 1$そして$y - 1$ポジティブです、つまり、$x > 1$そして$y > 1$、これは最初の不等式から正当化される必要があります$xy > x + y$。 これには、1 つの変数が次のような場合を考慮する必要があります。$\le 1$そしてこれらを示すことは不可能です。 

## 解決策

 しましょう$x$そして$y$満足のいく正の数であること$xy > x + y$。 まず、次のいずれかの可能性を考えてください。$x \le 1$または$y \le 1$。 一般性を失わずに次のように仮定します。$x \le 1$。 それから$xy \le y$、 以来$x \le 1$、 そして$x + y \ge y + 0 = y$。 したがって$xy \le y \le x + y$、矛盾しています$xy > x + y$。 この矛盾は、両方が$x$そして$y$厳密に次より大きくなければなりません$1$、 それで$x - 1 > 0$そして$y - 1 > 0$。 

不等式を次のように書き換えます$xy - x - y > 0$そして追加します$1$両側に取得する$(x - 1)(y - 1) = xy - x - y + 1 > 1.$以来$x - 1 > 0$そして$y - 1 > 0$、それらの合計を考慮できます。$x + y = (x - 1) + (y - 1) + 2.$不平等$(x - 1)(y - 1) > 1$ということを暗示します$(x - 1) + (y - 1) > 2$なぜなら、任意の 2 つの正の数に対して$a$そして$b$、 もし$ab > 1$、 それから$a + b > 2$に適用される AM-GM 不等式から導かれます。$a$そして$b$:$\frac{a + b}{2} \ge \sqrt{ab} > 1 \implies a + b > 2.$置き換える$a = x - 1$そして$b = y - 1$を取得します。$(x - 1) + (y - 1) > 2 \implies x + y = (x - 1) + (y - 1) + 2 > 4.$これで証明は完了です。 

∎

 ## 主要な手順の検証

 最初の繊細なステップが表示されます$x > 1$そして$y > 1$。 テスト$x = 1$または$y = 1$平等をもたらす$xy = x + y$なので反例は生じません。 もし$x < 1$そして$y > 1$、 それから$xy < y < x + y$、不可能であることを確認します。 テスト$x, y \in (0,1)$与える$xy < x + y$、も無理です。 したがって、次の控除は、$x, y > 1$は厳しいです。 

2 番目のデリケートなステップは、AM-GM を適用することです。$(x - 1)$そして$(y - 1)$。 仮定する$(x - 1)(y - 1) = 1 + \epsilon$と$\epsilon > 0$。 それから$\sqrt{(x - 1)(y - 1)} = \sqrt{1 + \epsilon} > 1$、 それで$(x - 1) + (y - 1) \ge 2\sqrt{(x - 1)(y - 1)} > 2$、確認中$x + y > 4$。 次のような数値例の直接置換$x = 2.5$、$y = 2$、与える$xy = 5 > 4.5 = x + y$そして$x + y = 4.5 > 4$、不等式と一致します。 

## 代替アプローチ

 別のアプローチの 1 つは、修正することです。$x + y = s$そして治療します$xy$として$p$。 すると、不等式が$p > s$次のように書き換えることができます$p - s > 0$、そして使用して$p \le \frac{s^2}{4}$AM-GM により、次のようになります。$s^2/4 - s > 0 \implies s(s - 4) > 0$、これは直接与えます$s > 4$以来$s > 0$。 このアプローチは代数的にコンパクトですが、2 つの正の数と固定和の最大積を呼び出す必要があります。 メインのアプローチは、追加のパラメーターを導入せずに初歩的な不等式のみを使用し、コンテスト形式の解決策に適した明確な段階的な推論を提供するため、推奨されます。
