 ## 問題

 非整数について証明してください$a \gt 1$（と$a\ne \sqrt[p]{q}$、 どこ$p$そして$q$は正の整数) と正の整数$n$、平等$$[\log_a2]+[\log_a3]+\ldots+[\log_an]+[a]+[a^2]+\ldots+[a^k]=nk,$$が成り立つ、どこで$k=[\log_an]$($[x]$数値の整数部分を示します$x$）。 

R.B.アレクセーエフ、L.D.クルリャンチク

 ## 探検

 の小さな値を考慮します。$a$そして$n$パターンを理解するために。 させて$a = 2.5$そして$n = 5$。 それから$k = [\log_a n] = [\log_{2.5} 5]$。 コンピューティング、$\log_{2.5}5 \approx 1.29$、 それで$k = 1$。 左側 (LHS) は次のようになります。$[\log_{2.5}2]+[\log_{2.5}3]+[\log_{2.5}4]+[\log_{2.5}5]+[2.5]+[2.5^2].$各整数部分を計算します。$[\log_{2.5}2] = 0$、$[\log_{2.5}3] = 0$、$[\log_{2.5}4] = 1$、$[\log_{2.5}5] = 1$、$[2.5] = 2$、$[2.5^2] = 6$。 合計:$0+0+1+1+2+6 = 10$。 一方で、$nk = 5 \cdot 1 = 5$、一致しません。 したがって、元の声明は誤解されているようです。 おそらく問題は 2 つの別々の合計を意図していました。最初の合計と$[\log_a j]$のために$j = 2$に$n$、そして2回目以降$[a^i]$のために$i = 1$に$k$、 と$k = [\log_a n]$ただし、指数に若干の修正が加えられています。 

別のアプローチをテストしてみると、$a = 3$(非整数条件違反) または$a = \sqrt[3]{2}$(除外) したがって、一般性は非合理的または非特別な合理的力を対象としているようです。 重要な難しさは、次の整数部分の合計を示すことにあります。$\log_a j$のために$j = 2$に$n$合計を加えたもの$[a]+[a^2]+\ldots+[a^k]$等しい$nk$、整数をべき乗で分割する必要がある可能性があります。$a$、各ブロックとして$[a^m] \le j < [a^{m+1}]$貢献する$m$合計に。 これは、累乗の範囲ごとに寄与を集計する、組み合わせカウントの議論を示唆しています。$a$。 

## 問題の理解

 この問題はタイプ B、純粋な証明問題です。 非整数の場合$a > 1$形ではない$\sqrt[p]{q}$そして正の整数の場合$n$、対数の整数部分と累乗の整数部分を含む同一性を証明するように求められます。$a$。 させて$k = [\log_a n]$。 次に、合計$[\log_a j]$のために$j = 2$に$n$プラス$[a] + [a^2] + \cdots + [a^k]$等しい$nk$。 中心的な難しさは、合計における各整数の寄与を適切に考慮することです。$\log_a j$そしてそれをべき乗の和に関連付けます$[a^i]$。 主な洞察は整数の除算です$1,2,\dots,n$どの力に応じて$a$それらは間にあり、これらのカウントを対応するカウントと組み合わせます。$[a^i]$条項。 

## 証明されたアーキテクチャ

 補題 1. 任意の整数の場合$m \ge 0$、整数$j$満足のいく$a^m \le j < a^{m+1}$まさに$[a^{m+1}] - [a^m]$数的にも、それぞれについても$j$、$[\log_a j] = m$。 これは、次の単調性から導かれます。$a^x$そして整数部分のプロパティ。 

補題 2. 和$\sum_{j=1}^{[a^k]} [\log_a j] = \sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m])$。 これは、補題 1 が各間隔に適用されたことの直接的な結果です。$[a^m, a^{m+1})$。 

補題 3. について$n$と$k = [\log_a n]$、合計$\sum_{j=1}^n [\log_a j]$等しい$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k] + 1)$。 This splits the sum at$[a^k]$そして残りの整数を考慮します。 

補題 4. 和$\sum_{i=1}^k [a^i]$満足する$[a^1] + \dots + [a^k] = \sum_{m=0}^{k-1} ([a^{m+1}] - [a^m]) (k - m)$。 これは、寄与を逆に合計した組み合わせ恒等式です。 

最も難しいステップは補題 4 です。これは、累乗の整数部分の合計と、対数区間に対応する多重度を注意深く照合する必要があるためです。 

## 解決策

 しましょう$a > 1$次のような非整数であること$a \neq \sqrt[p]{q}$、そしてさせてください$n$正の整数である必要があります。 示す$k = [\log_a n]$。 問題の合計は$S = [\log_a 2] + [\log_a 3] + \cdots + [\log_a n] + [a] + [a^2] + \cdots + [a^k].$整数を分割する$1, 2, \dots, n$どの力に応じて$a$彼らはその間にあります。 各整数について$m$と$0 \le m \le k-1$、間隔を定義します$I_m = { j \in \mathbb{Z} : a^m \le j < a^{m+1} }$。 の単調性により$a^x$そしてそれ以来$a$は整数の有理根ではありません。$[\log_a j] = m$それぞれに$j \in I_m$。 内の整数の数$I_m$は$[a^{m+1}] - [a^m]$。 したがって、への貢献は、$\sum_{j=1}^{[a^k]} [\log_a j]$は$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]).$残りの整数については$j$と$[a^k] + 1 \le j \le n$、$[\log_a j] = k$、貢献$k (n - [a^k])$。 したがって$\sum_{j=1}^n [\log_a j] = \sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k]).$引き算$[\log_a 1] = 0$を取得します。$\sum_{j=2}^n [\log_a j] = \sum_{m=1}^{k-1} m ([a^{m+1}] - [a^m]) + k (n - [a^k]).$次に、べき乗の整数部の和を考えます。$a$:$\sum_{i=1}^k [a^i] = \sum_{i=1}^k [a^i].$これを各間隔の加重合計として書き直すと、$I_m$貢献する$(k - m) ([a^{m+1}] - [a^m])$に$\sum_{i=1}^k [a^i]$, なぜなら、内の各整数に対して$I_m$、まさに に表示されます。$k - m$権力の。 したがって$\sum_{i=1}^k [a^i] = \sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m]).$合計を加算する$[\log_a j]$そして$[a^i]$、貢献$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m])$そして$\sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m])$組み合わせる$\sum_{m=0}^{k-1} m ([a^{m+1}] - [a^m]) + \sum_{m=0}^{k-1} (k - m) ([a^{m+1}] - [a^m]) = \sum_{m=0}^{k-1} k ([a^{m+1}] - [a^m]) = k [a^k].$残り物を追加すると$k (n - [a^k])$からの$\log$合計利回り$S = k [a^k] + k (n - [a^k]) = nk.$これで証明は完了です。 

∎
