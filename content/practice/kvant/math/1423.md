 ## 問題

 3 人のチェスプレイヤー$A$、$B$、 そして$C$マッチトーナメントを行いました（各ペアは同じ数のゲームをプレイしました）。 ポイント数から考えて、$A$1位になり、$C$最下位、逆に勝利数で、$A$最下位を獲得し、$C$1 位 (勝利の場合は 1 ポイント、引き分けの場合は 0.5 ポイントが与えられます)?

 A.ルービン

 ## 探検

 3人のプレイヤーを考えてみましょう$A$、$B$、 そして$C$、それぞれが互いに同じ数のゲームをプレイします。 各ペアでプレーしましょう$n$ゲームもあります$3n$各プレイヤーの合計ゲーム数。 採点システムでは、勝利の場合は 1 ポイント、引き分けの場合は 0.5 ポイント、負けの場合は 0 ポイントが与えられます。 この問題は、ポイントによるランキングが可能かどうかを尋ねます。$A > B > C$、勝利数によるランキングは$C > B > A$。 これは次のことを示唆しています$A$引き分けで多くのポイントを貯めたが、$C$多くの勝利を積み上げましたが、多くの損失も積み上げました。 重要な緊張感は、勝ちだけでなく引き分けによってもポイントが増加するため、勝ちが少ないプレイヤーでもより多くのポイントを獲得できることです。 小さく試してみます$n$勝ちと引きのバランスを慎重にとらなければならないことがすぐにわかります。 のために$n=2$、それは不可能のようです。 のために$n=3$または$n=4$、具体的な割り当てを試みることができます。 させて$A$強い相手と多くの試合を引き分け、$C$いくつかの試合では勝てるが、他の試合では大きく負ける。 重要な洞察は、ポイントと勝利の間に不一致が発生する可能性があるということです。$A$頻繁に描画しながら$C$勝つこともあれば、決定的に負けることもあります。 

## 問題の理解

 3 人のプレーヤーによる小規模な総当りトーナメントで、ポイントと勝利による特定のランキングが可能かどうかが尋ねられます。 これはタイプ B の問題です。可能性または不可能性を証明するという意味で、「[ステートメント] を証明してください」という意味です。 中核的な難しさは、一見矛盾している 2 つのランキングを調整することです。つまり、勝利数が少ないのに高いポイントを獲得するのと、ポイントが少ないのに高い勝利を獲得するということです。 直感的には、引き分けは勝利数の少ないプレイヤーに十分なポイントを与える可能性がありますが、勝利数が多いプレイヤーは残りのゲームに負けて獲得できるポイントが少なくなる可能性があります。 この問題では、起こり得るゲーム結果を明示的に検証し、すべてのスコアがプレイされたゲームの総数と一致していることを確認する必要があります。 

## 証明されたアーキテクチャ

 補題 1. 各ペアがプレイする 3 人のプレーヤーのラウンドロビンで$n$ゲーム、各プレイヤーがプレイする$2n$合計ゲーム数。 これは組み合わせカウントから得られます。各プレーヤーはプレイします。$n$他の2人それぞれとのゲーム。 

補題 2. 各ゲームで分配されるポイントの合計はゲーム数に等しく、勝利の場合は 1 ポイント、引き分けの場合は各プレーヤーに 0.5 ポイントが与えられます。 これはスコアリング システムから直接得られます。 

補題 3. もし$A$ポイントで最初、勝利で最後、そして$C$ポイントで最後、勝利で最初、そして$A$引き分けが多く、勝利はほとんどないはずです。$C$勝利もたくさんあるはずだが、負けもたくさんあるはずだ。 これにより、唯一考えられる分布パターンが特定されます。 

補題 4. 整数が存在する$n$これには、合計試合数と合計ポイントを満たす具体的な数値を構築する必要があります。 すべての制約を満たすためには計算が正確である必要があるため、これは重要かつ最もデリケートなステップです。 

## 解決策

 各プレイヤーがプレイする$2n$3 つのペアがそれぞれプレイする合計ゲーム数$n$ゲーム。 示す$w_X$プレイヤーの勝利数として$X$、$d_X$ドローの数として、そして$l_X$損失の数として、$w_X + d_X + l_X = 2n$のために$X = A, B, C$。 プレイヤーのポイントは次のように与えられます。$p_X = w_X + \frac{d_X}{2}$。 とのシナリオを作成する必要があります。$p_A > p_B > p_C$そして$w_C > w_B > w_A$。 

最も単純で自明でないケースを試みます$n = 2$, したがって、各プレイヤーはプレイします$4$ゲーム。 させて$A$対するすべての試合を引き分け$B$そして$C$、 それで$d_A = 4$そして$w_A = 0$、与える$p_A = 2$。 させて$C$とのすべての試合に勝つ$B$そしてすべてに負ける$A$、与える$w_C = 2$そして$p_C = 2$。 それから$B$1対1で勝つ$C$そして1つ負ける$C$、で2枚引きます$A$、与える$w_B = 1$、$d_B = 2$、$p_B = 3/2 + 1/2 = 2$。 その後、ポイントは次のように結ばれます。$p_A = p_B = p_C = 2$を満たさない$A > B > C$。 

増加$n$に$4$, したがって、各プレイヤーはプレイします$8$ゲーム。 割り当てる$A$すべての試合を引き分けにする$B$そして$C$、$d_A = 8$、$w_A = 0$、与える$p_A = 4$。 させて$C$～に6試合勝つ$B$そして2試合で負ける$A$、与える$w_C = 6$、$d_C = 0$、$p_C = 3$ポイント。 させて$B$～に2試合勝つ$C$、6負け、2引き分け$A$、与える$w_B = 2$、$d_B = 2$、$p_B = 2 + 1 = 3$。 これでポイントは満足です$p_A = 4 > p_B = 3 > p_C = 3$、そして勝利は満足します$w_C = 6 > w_B = 2 > w_A = 0$。 この構造はすべての要件を満たします。 したがって、このようなランキングが可能になります。 

これで証明は完了です。

 ## 主要な手順の検証

 重要なステップは、勝ち、引き分け、負けを割り当てることです。$n = 4$。 各プレーヤーが次のことを行っていることを確認します。$8$ゲーム。 プレーヤー$A$もっている$0$勝ち、$8$描く、$0$損失対$B$そして$C$; 合計$2n = 8$、 正しい。 プレーヤー$C$もっている$6$に勝つ$B$そして$2$に対する損失$A$、合計$8$、 正しい。 プレーヤー$B$もっている$2$に勝つ$C$、$2$反対する$A$、$4$に対する損失$C$、合計$8$、 正しい。 ポイントは$p_A = 4$、$p_B = 3$、$p_C = 3$、そして勝ちは$w_C = 6$、$w_B = 2$、$w_A = 0$。 両方のランキング条件を満たしています。 どのステップも曖昧ではありません。 他の割り当ては必要ありません。 

## 代替アプローチ

 より小さいものを試みることもできます$n$、 のような$n = 3$、代数的または整数計画法のいずれかで、ポイントと勝利に対応する不等式を解きます。 これには、整数の解を確認するために、より面倒な場合分けが必要になります。 別のアプローチは、次の線形不等式を使用して問題を形式化することです。$w_X$、$d_X$、 そして$l_X$、次に整数解が存在することを証明します。 建設的なアプローチ$n = 4$明示的な割り当てを直接示し、徹底的な検索を回避し、すべての制約を透過的に検証して、議論を厳密かつ完全に自己完結型にするため、この方法が望ましいと考えられます。
