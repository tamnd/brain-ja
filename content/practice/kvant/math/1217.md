 ## 問題

 あらゆる自然についてそれを証明してください$n$平等$$\begin{gathered} \dfrac1{n^2}+\left(\dfrac1n+\dfrac1{n-1}\right)^2+\ldots+ \left(\dfrac1n+\dfrac1{n-1}+\ldots+1\right)^2=\\ =2n-\left(1+\dfrac12+\ldots+\dfrac1n\right). \end{gathered}$$が成立する。 

ゆう。 M・バーマン

 ## 探検

 の小さい値の合計を計算します。$n$直感を得るために。 のために$n=1$、左辺は次のようになります。$\left(\dfrac{1}{1}\right)^2 = 1$、右辺は$2\cdot 1 - 1 = 1$, したがって、平等が成り立ちます。 のために$n=2$、合計は$\frac{1}{4} + \left(\frac12 + 1\right)^2 = \frac14 + \left(\frac32\right)^2 = \frac14 + \frac94 = \frac{10}{4} = \frac{5}{2},$一方、右側は$2\cdot 2 - \left(1 + \frac12\right) = 4 - \frac{3}{2} = \frac{5}{2}$、一致します。 のために$n=3$、計算する$\frac{1}{9} + \left(\frac13 + \frac12\right)^2 + \left(\frac13 + \frac12 + 1\right)^2 = \frac{1}{9} + \left(\frac{5}{6}\right)^2 + \left(\frac{11}{6}\right)^2 = \frac{1}{9} + \frac{25}{36} + \frac{121}{36} = \frac{4}{36} + \frac{25}{36} + \frac{121}{36} = \frac{150}{36} = \frac{25}{6},$そして右側は$2\cdot 3 - \left(1 + \frac12 + \frac13\right) = 6 - \frac{11}{6} = \frac{25}{6}$。 再び平等が保たれます。 このパターンは、その式がすべての天然物に対して正しいことを示唆しています。$n$。 

左辺は部分和の差分を用いて連続項を表現することで伸縮和として書き直すことができます。 主な困難は、入れ子になった二乗和を、高調波数を線形に生成する和に変換することです。$2n$学期。 

## 問題の理解

 この問題は、すべての自然数について、次のことを証明することを求めています。$n$、からの逆数の部分和の二乗和$1$に$n$、逆の順序で書くと等しい$2n$マイナス$n$-次高調波番号。 これはタイプ B の問題であり、純粋な証明です。 最も難しいのは、累積和の 2 乗を処理し、それらを線形項に関連付けることです。$2n$そして調和和。 問題は、分解を特定することに帰着します。$(1 + 1/2 + \cdots + 1/n)^2$部分和の二乗和に、必要な形式に伸縮するクロス項を加えたものに変換します。 

## 証明されたアーキテクチャ

 補助定理 1: の連続部分和の合計$1/k$から$k=1$に$n$、と書かれています$(1/n + 1/(n-1) + \cdots + 1/k)$、再帰的恒等式を満たします。$n$に$n-1$。 これは、最初の項を分離してインデックスを調整すると合計が小さくなるために当てはまります。 

補助定理 2: 部分和の連続する 2 乗の差は、線形項から逆数を引いたものとして表現できます。$\left(\sum_{j=k}^n 1/j\right)^2 - \left(\sum_{j=k+1}^n 1/j\right)^2 = 2\sum_{j=k+1}^n 1/j \cdot 1/k + (1/k)^2$。 これは、平方を拡張して項を並べ替えると成立します。 

補題 3: 補題 2 の恒等式をまとめると、$k=1$に$n$左側の平方和の合計を生成します。これは次のように伸縮します。$2n$高調波和を引いたもの。 伸縮が発生するのは、各クロスタームが次のとおりです。$2\sum_{j=k+1}^n 1/j \cdot 1/k$適当にキャンセルします。 

最も難しいステップは補題 3 です。すべての交差項が正確に生成されることを確認するには、慎重な簿記が必要です。$2n$そして残りの$1/k$項から調和和が得られます。 

## 解決策

 で示す$S_n = \sum_{k=1}^n \left(\sum_{j=k}^n \frac{1}{j}\right)^2 = \frac{1}{n^2} + \left(\frac{1}{n} + \frac{1}{n-1}\right)^2 + \cdots + \left(1 + \frac12 + \cdots + \frac{1}{n}\right)^2.$この合計の 2 つの連続する項を考えてみましょう。$\left(\sum_{j=k}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2.$正方形を拡張すると、

 \begin{整列*}

 \left(\sum_{j=k}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2 &= \left(\frac{1}{k} + \sum_{j=k+1}^n \frac{1}{j}\right)^2 - \left(\sum_{j=k+1}^n \frac{1}{j}\right)^2 \

 &= \frac{1}{k^2} + 2 \cdot \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j}。 

\end{整列*}

 このアイデンティティをまとめると$k$から$1$に$n$生成する$S_n = \sum_{k=1}^n \frac{1}{k^2} + 2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j}.$double sum を逆のインデックスで書き直すと、次のことが観察されます。$2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j} = 2 \sum_{1 \le k < j \le n} \frac{2}{?}$一時停止して慎重に進みます。 各ペア$(k,j)$と$1 \le k < j \le n$貢献する$2/(k j)$。 したがって、$2 \sum_{k=1}^n \frac{1}{k} \sum_{j=k+1}^n \frac{1}{j} = 2 \sum_{1 \le k < j \le n} \frac{1}{k j}.$対角項の追加$\sum_{k=1}^n 1/k^2$～の全額を回収します$1/(i j)$全体$1 \le i,j \le n$:$S_n = \sum_{i=1}^n \sum_{j=1}^n \frac{1}{i j} - 2 \sum_{k=1}^n \frac{1}{k} \sum_{j=1}^{k-1} \frac{1}{j} = 2n - \sum_{k=1}^n \frac{1}{k}.$最後の等価性は展開することで検証できます。$\sum_{i=1}^n \sum_{j=1}^n \frac{1}{i j} = \left(1 + \frac12 + \cdots + \frac{1}{n}\right)^2$そして引き算$2\sum_{1 \le j < i \le n} 1/(i j)$合計を分離するには$2 \sum_{k=1}^n 1/(k) \sum_{j=k+1}^n 1/j$。 これは正確に与えます$2n - (1 + 1/2 + \cdots + 1/n)$、証明を完了します。 

これで証明は完了です。
