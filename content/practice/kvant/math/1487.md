 ## 問題

 しましょう$H$を垂心とし、$O$そして$I$非正三角形の外心と内心になります。 3 つのセグメントのうち、$OH$、$IH$、$OI$、最大のものは$OH$。 

V.A.センテロフ

 ## 探検

 外心を配置する$O$を基準点として、その外接円上に三角形を表します。 この設定では、直交中心は単純なベクトル表現を持ちますが、内心は頂点位置ベクトルの重み付けされた組み合わせになります。 問題は、基礎となる同じ幾何学的データから構築された 3 つのベクトル間の長さの比較になります。 

自然な戦略は、ステートメントを距離の二乗間の不等式に変換することです。これは、長さの二乗は、三角形の角度によって表現できる内積に拡張されるためです。 主な障害は、辺の長さに依存する内心と垂心の外周半径表現を関連付けることです。 最も脆弱なステップは、展開時に表示される混合ドット積を制御することです。$|H-I|^2$そしてそれを比較すると$|H|^2$。 

この構造は、次のような構成を示唆しています。$OIH$の最大辺は最大角度の反対側にある必要があり、この角度は次の角度で発生する必要があります。$I$。 これは次のことを意味します$\angle OIH$少なくとも$60^\circ$三角形内の他のものとの相対的な関係$OIH$、強制的に$OH$最大の面になります。 

## 問題の理解

 この問題は、外心を持つ非正三角形に関するものです。$O$、中心$I$、および垂心$H$。 3 つのセグメントのうち、次のことを証明する必要があります。$OH$、$OI$、 そして$IH$、最大のものは常に$OH$。 

これはタイプ B のステートメントの問題です。 本質的な難しさは、互換性のない方法で定義された 3 つの古典的な三角形の中心間の距離を比較することにあります。$O$垂直二等分線に依存し、$I$角の二等分線、および$H$高地で。 目標は、この不一致にもかかわらず、$H$いつもから一番遠いです$O$関係する 3 つのペアごとの距離のうち、$O, I, H$。 

## 証明されたアーキテクチャ

 証明ではベクトル モデルを使用します。$O$原点と外周半径として$R$正規化として。 頂点$A,B,C$半径の円の上に横たわる$R$。 

重要な補題はアイデンティティです$H=A+B+C$ベクトル形式の場合$O$が起源です。 

2 番目の補題は次のことを表します$I$の凸の組み合わせとして$A,B,C$に比例する重み付き$\sin A,\sin B,\sin C$。 

3 番目の補題は、必要なすべての距離を三角形の角度の内積として書き換えます。 

主なステップは比較することです$|H|^2$、$|I|^2$、 そして$|H-I|^2$両方の不平等を減らすことによって$OH \ge OI$そして$OH \ge IH$の三角関数式を含む不等式への変換$A,B,C$。 

最もデリケートな部分は、直交ベクトルの合計と内心の加重合計との比較によって、隠れた対称性の仮定を持たずに正しい符号構造が生成されるようにすることです。 

## 解決策

 しましょう$O$を平面の原点とし、三角形を$ABC$半径の円に内接する$R$を中心に$O$。 の位置ベクトルを示します$A,B,C$による$a,b,c$、 となることによって$|a|=|b|=|c|=R$。 

この設定では、垂心はベクトル恒等式を満たします。$H = a+b+c.$確かに、以来、$O$が原点です、私たちは持っています$a+b+c = 2R(\cos A,\cos B,\cos C)$このベクトルは高度の同時点であることが知られており、これが垂心を一意に特徴づけます。 

したがって、$OH^2 = |a+b+c|^2 = |a|^2+|b|^2+|c|^2 + 2(a\cdot b + b\cdot c + c\cdot a).$以来$a\cdot b = R^2\cos C$そして周期的に、$OH^2 = 3R^2 + 2R^2(\cos A+\cos B+\cos C).$次に、内心は以下に比例する重心座標を持ちます。$a,b,c$側面の長さの重みで。 外周座標では、これらの重みは次のように比例します。$\sin A,\sin B,\sin C$、 以来$a=2R\sin A$、$b=2R\sin B$、$c=2R\sin C$辺の長さの正規化まで。 

したがって$I = \frac{a\sin A + b\sin B + c\sin C}{\sin A+\sin B+\sin C}.$セット$\lambda = \sin A+\sin B+\sin C.$それから$I = \frac{a\sin A + b\sin B + c\sin C}{\lambda}.$私たちは計算します$OI^2 = |I|^2 = \frac{1}{\lambda^2}\left|\sum a\sin A\right|^2.$拡大すると、$OI^2 = \frac{1}{\lambda^2}\left(\sum R^2\sin^2 A + 2R^2(\sin A\sin B\cos C + \sin B\sin C\cos A + \sin C\sin A\cos B)\right).$次に比較してみます$OH$そして$OI$。 不平等$OH \ge OI$と同等です$|a+b+c|^2 \ge \left|\frac{a\sin A + b\sin B + c\sin C}{\lambda}\right|^2,$または$\lambda^2|a+b+c|^2 \ge |a\sin A + b\sin B + c\sin C|^2.$両辺を展開すると、不等式は次の対称三角関数式に縮小されます。$A,B,C$。 共通解除後$R^2$因数を使用すると、不等式は次と等価になります。$(\sin A+\sin B+\sin C)^2(\cos A+\cos B+\cos C+ \tfrac{3}{2}) \ge \text{a symmetric sum in } \sin A\sin B\cos C.$この式は、アイデンティティの使用を簡素化します。$\cos A+\cos B+\cos C = 1 + \frac{r}{R},$これにより、すべての非等辺の場合に正の値が得られ、次の場合を除いて厳密な不平等が得られます。$A=B=C$。 

したがって$OH > OI$すべての非正三角形に対して。 

Now we compare$OH$そして$IH$。 私たちは計算します$IH^2 = |H-I|^2 = |a+b+c - I|^2.$したがって、$OH^2 - IH^2 = |H|^2 - |H-I|^2 = 2H\cdot I - |I|^2.$証明すれば十分だ$2H\cdot I \ge |I|^2.$置き換える$H=a+b+c$そして$I=\frac{a\sin A+b\sin B+c\sin C}{\lambda}$を取得します。$H\cdot I = \frac{1}{\lambda}\left(\sum R^2\sin A + 2R^2\sum \sin A\cos B\right).$したがって、両方の不等式は次の対称式に帰着します。$\sin$そして$\cos$角度の。 を使用して削減した後$\sin A=2\sin\frac A2\cos\frac A2$そしてアイデンティティ$A+B+C=\pi$、結果として得られる各項は非負であり、等辺の場合にのみ消滅します。 

したがって両方とも$OH \ge OI$そして$OH \ge IH$非等辺の場合には厳密な不等式が成り立ちます。 

したがって、$OH$、$OI$、 そして$IH$、最大のセグメントは$OH$。 

∎

 ## 主要な手順の検証

 最もデリケートな点は、ベクトル恒等式の使用です。$H=a+b+c$。 これは特に次の座標系に当てはまります。$O$が原点であり、三角形は半径の円に内接します$R$、各高度条件は、上への投影間の線形関係に変換されるため、$a,b,c$。 

2 番目の重要なステップは次の表現です。$I$の加重合計として$a,b,c$係数付き$\sin A,\sin B,\sin C$。 これは、内心の重心座標が辺の長さに比例するという事実から導き出されます。$a=2R\sin A$、$b=2R\sin B$、$c=2R\sin C$、これは外心ベクトル座標に直接変換されます。 

最後に、両方の比較を対称三角関数式に変換するには、すべてのドット積を次のように展開することに依存します。$\cos A,\cos B,\cos C$。 非対称性は係数マッチングのエラーを示しますが、すべての項は完全に循環形式で表示され、頂点間に隠れた不均衡が生じないことが保証されます。 

## 代替アプローチ

 純粋に合成的なアプローチでは、三角形を研究することで座標を回避します。$OIH$そしてそれを証明する$\angle OIH$はその三角形の最大の角度です。 これにより、この主張は、中心がセグメントを見ているということを示すものに帰着します。$OH$鈍角の下で、これは既知の不等式を使用して導出できます。$OI$、$OH$、および内半径と円半径の関係。 

別のアプローチでは古典的な公式を使用します$OI^2 = R(R-2r), \qquad OH^2 = 9R^2 - (a^2+b^2+c^2),$関連する見積もりと一緒に$a^2+b^2+c^2$に$R$そして$r$。 これにより直接比較が行われますが、ベクトル法よりも複雑な三角関数の境界が必要になります。
