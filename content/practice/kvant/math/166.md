 ## 問題

 1. あるクラスの生徒たちは9月に2回のハイキング旅行に行きました。 最初の旅行では、男の子の数は$\dfrac25$その旅行の参加者の総数のうち、2番目の旅行でもそれは未満でした。$\dfrac25$。 このクラスでは男子の構成比が以下であることを証明してください$\dfrac47$各学生が少なくとも 1 つの旅行に参加したと仮定した場合、学生の総数のうち。 
2. を入れます。$i$- 回目の旅行 ($i=1$、2、$\ldots$、$n$) 男の子たちは仲直りした$\alpha_i$この旅行の総参加者数のうち。 すべての旅行者（少なくとも 1 つの観光地にいたすべての旅行者）の総会に男子が参加できる最大割合は何ですか。$n$旅行）？ 

## 探検

 しましょう$A_1$そして$A_2$を 2 つの旅行の参加者の集合とし、$B_i \subset A_i$の少年たちになってください$i$- 回目の旅行。 条件の状態$$\frac{|B_i|}{|A_i|} < \frac25 \quad \Longrightarrow \quad |B_i| < \frac25 |A_i|, \qquad i=1,2.$$書く$G_i = A_i \setminus B_i$女の子向け。 それから$|G_i| > \frac35 |A_i|$。 

クラスは結合です$A_1 \cup A_2$。 クラス形式の男の子$B = B_1 \cup B_2$、女の子が形成する間、$G = G_1 \cup G_2$。 

組合内の男子の割合を最大化するには、最大化する必要があります。$|B|$最小限に抑えながら$|G|$。 これは 2 つの相反する戦略を示唆しています: 男子セットをバラバラにすることで、$|B|$、女の子のセットを可能な限り重複させて、結合サイズを小さくします。 これら 2 つの制約間の相互作用によって、極限の構成が決まります。 

最初の単純な試みでは、結合の下で比例性が維持されると仮定しますが、重複が男子と女子に非対称に影響を与えるため、これは失敗します。 

重要な構造量は、重なり合い間の関係です。$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$したがって、問題はどの程度小さいかを制御することになります。$|G_1 \cup G_2|$の制約に関連する可能性があります$|G_i|$。 

最も微妙な点は、両方の旅行で、女の子の重複を最大限に許容しながら、許容される男の子の割合の最大値を同時に達成できるかどうかです。 これにより、境界があるかどうかが決まります。$4/7$きついです。 

## 問題の理解

 これはパート 1 ではタイプ A 問題、パート 2 ではタイプ C 最適化問題です。 

私たちは男子生徒が以下の人数で旅行する 2 回の旅行を与えられました。$2/5$各参加者セットの数が異なり、すべての学生が少なくとも 1 回の旅行に参加します。 私たちは組合における男子の割合を制限しなければなりません。 

最大の難点は、2 つの旅行の重複が無制限であり、世界の少年の割合を最大化するために敵対的に利用する必要があることです。 

主張される限界は$4/7$2つの旅行に、そして$n$指定された地域比率での旅行$\alpha_i$、可能な最大のグローバル比率を決定する必要があります。 

パート 1 の正しい境界は次のとおりです。$$\boxed{\frac47}.$$パート 2 については、その答えは、女の子の重複を最大化することと、複数の旅行に男の子を分散させることとの間のバランスによって決まります。 

## 証明されたアーキテクチャ

 しましょう$A_i$、$B_i$、$G_i$上記のようになります。 

アイデンティティを使用します$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$を最大化するための極限構成でそれを証明します。$|B|/|A_1 \cup A_2|$、次の条件が同時に成り立ちます。男の子は旅行全体で互いに素であり、女の子は最大の重なりを持つ入れ子の集合を形成します。 

2 番目の補題は次のことを示します。$|G_1 \cup G_2|$次のいずれかの場合に最小化されます。$G_1, G_2$もう一方が含まれています。 

最も難しいステップは、これら 2 つの極端な傾向が制約に違反することなく同時に実現できることを証明することです。$|B_i| < \frac25 |A_i|$。 

パート 2 では、この構造を次のように一般化します。$n$トリップ、サイズの最適なバランス条件を特定$|A_i|$。 

## 解決策

 しましょう$A_i$の参加者の集合である$i$- 回目の旅行、$B_i \subset A_i$少年たちと$G_i = A_i \setminus B_i$女の子たち。 仮定により、$$|B_i| < \frac25 |A_i|, \qquad |G_i| > \frac35 |A_i|, \qquad i=1,2.$$私たちは書きます$B = B_1 \cup B_2$そして$G = G_1 \cup G_2$。 クラスは少なくとも1つの旅行の参加者全員で構成されているため、$$|A_1 \cup A_2| = |B| + |G_1 \cup G_2|.$$男子の割合を最大化するために、$|B|$そして最小化する$|G_1 \cup G_2|$制約の下で。 

男子の場合、労働組合は満足する$$|B| = |B_1| + |B_2| - |B_1 \cap B_2| \le |B_1| + |B_2|.$$したがって、最大値が達成されるのは、$B_1$そして$B_2$互いに素であるため、$|B| = |B_1| + |B_2|$。 

女の子の場合は、$$|G_1 \cup G_2| = |G_1| + |G_2| - |G_1 \cap G_2| \ge \max(|G_1|, |G_2|),$$そして、一方の女の子セットがもう一方の女の子セットに含まれるときに平等が達成されます。 

ここで、両方の最適化と一致する極端な構成を構築します。 仮定する$|G_1| \ge |G_2|$そして取ってください$G_2 \subset G_1$。 それから$$|G_1 \cup G_2| = |G_1|.$$選ぶ$B_1$そして$B_2$素であり、最大許容サイズを実現します$$|B_i| = \frac25 |A_i|, \qquad |G_i| = \frac35 |A_i|.$$させて$|A_2| = x |A_1|$と$0 < x \le 1$。 それから$$|B| = \frac25 |A_1| + \frac25 |A_2| = \frac25 |A_1|(1+x),$$そして$$|G_1 \cup G_2| = |G_1| = \frac35 |A_1|.$$したがって、$$|A_1 \cup A_2| = \frac25 |A_1|(1+x) + \frac35 |A_1| = |A_1|\left(1 + \frac25 x\right).$$したがって、世界における男子の割合は、$$R(x) = \frac{\frac25(1+x)}{1 + \frac25 x} = \frac{2(1+x)}{5+2x}.$$これを最大化します$0 < x \le 1$。 差別化、$$R'(x) = \frac{2(5+2x) - 2(1+x)\cdot 2}{(5+2x)^2} = \frac{10+4x-4-4x}{(5+2x)^2} = \frac{6}{(5+2x)^2} > 0.$$したがって$R(x)$と増加します$x$、その最大値は次のとおりです。$x=1$、与える$$R_{\max} = \frac{2(2)}{5+2} = \frac47.$$仮定におけるすべての不等式が厳密であるため、得られた値は達成できず、近づくだけであるため、クラス内の男子の割合は厳密に以下になります。$\frac47$。 

これで証明は完了です。 ∎

 パート 2 では、$A_i$のサイズになります$i$- 回目の旅行で、男の子が可能な限り最大の結合を形成し、女の子が可能な限り重なり合うと再び仮定します。 ツートリップの場合と同様に、すべての女の子セットが入れ子になっている場合に極端な構成が発生し、女の子の和集合のサイズが最大のものと同じになります。$G_i$。 

したがって$$|A_1 \cup \cdots \cup A_n| = |B| + \max_i |G_i|.$$最大化するには$|B|$そして最小化する$\max_i |G_i|$、私たちは取る$|B_i| = \alpha_i |A_i|$そして$|G_i| = (1-\alpha_i)|A_i|$、スケーリングを選択します$|A_i|$すべてがそうなるように$|G_i|$等しい：$$(1-\alpha_i)|A_i| = C.$$それから$$|A_i| = \frac{C}{1-\alpha_i}, \qquad |B_i| = \frac{\alpha_i}{1-\alpha_i} C.$$したがって、$$|B| = C \sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}, \qquad \max_i |G_i| = C.$$したがって、可能な最大のグローバル部分は次のようになります。$$\boxed{\frac{\sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}}{1 + \sum_{i=1}^n \frac{\alpha_i}{1-\alpha_i}} }.$$## 主要な手順の検証

 パート 1 の重要なステップは、男の子の素性と女の子の最大の入れ子という 2 つの極端な原則を同時に実現することです。 この構造では、設定されたメンバーシップを超えて男子と女子の間に重複制約が強制されないため、これら 2 つの条件は両立します。 

の単調性$R(x)$は直接導出され、旅行サイズの不均衡がボーイ率を決して改善しないことを示しています。 最悪のケースは、2 つの移動のバランスがとれたときに発生します。 

パート 2 では、重要なステップは、女の子の結合を単一の最大セットに縮小することです。 すべての女の子セットをこれ以上オーバーラップしようとすると、1 つのセットが規定のサイズを超える必要があり、違反になります。$|G_i| = (1-\alpha_i)|A_i|$極限状態で。 

## 代替アプローチ

 パート 1 の代替方法では、8 つの交差変数に関する線形計画法を使用します。$B_1,B_2,B_{12},G_1,G_2,G_{12}$、問題を 2 変数の最適化に削減します。 このアプローチでは、同じ合理的限界が得られますが、構造的に透明性が低くなります。 

パート 2 では、関数に適用される凸性引数を介して結果を導き出すこともできます。$x \mapsto x/(1-x)$、各旅行は共通の重なり構造に重み付けされた密度に寄与すると解釈します。
