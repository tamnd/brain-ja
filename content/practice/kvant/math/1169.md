 ## 問題

 しましょう$M$長方形の内側にある点になる$ABCD$、そしてさせてください$S$そのエリアになります。 不等式を証明する$$S\le AM\cdot CM+BM\cdot DM.$$。 

やあ。 ゴールドシュタイン

 市大会（1988年秋）

 ## 探検

 長方形を考えてみましょう$ABCD$側面付き$AB = CD = a$そして$BC = AD = b$。 点を置く$M$長方形の内側にあり、次のように表されます$AM, BM, CM, DM$頂点までの距離。 不等式は、面積が次のように主張します。$S = ab$満足する$S \le AM \cdot CM + BM \cdot DM.$いくつかの簡単な配置を試してください。 もし$M$中心にあり、$AM = CM = \sqrt{(a/2)^2 + (b/2)^2}$そして$BM = DM = \sqrt{(a/2)^2 + (b/2)^2}$。 すると右辺は次のようになります$2\left(\frac{a^2+b^2}{4}\right) = \frac{a^2+b^2}{2}.$これは少なくとも明らかに$ab$以来$(a-b)^2 \ge 0$暗示する$a^2 + b^2 \ge 2ab$。 もし$M$隅に向かって移動すると、一方の製品が縮小し、もう一方の製品が拡大します。 数値実験によると、合計がこれを下回ることはありません$ab$。 

重要な洞察は次のとおりであると思われる$AM\cdot CM + BM\cdot DM$は常に少なくとも面積であり、次の場合に等価になります。$M$対角線上にあるため、一方の製品が消え、もう一方の製品が等しくなります$ab$。 

## 問題の理解

 この問題は、頂点までの距離を含む長方形内の任意の点に対する不等式を証明することを求めます。 不等式は普遍的であるため、これはタイプ B の問題です。分類や極値は必要ありません。 最も難しいのは、すべての内部点に対して機能する方法で、頂点の積の合計を長方形の面積に関連付けることです。 重要な観察点は、製品が$AM\cdot CM$そして$BM\cdot DM$によって形成される三角形の面積に対応します。$M$対向する角のペア。 それらを合計すると、下が長方形の領域で囲まれた式が生成されます。 

## 証明されたアーキテクチャ

 補助定理 1: 長方形を座標平面に配置します。$A=(0,0)$、$B=(a,0)$、$C=(a,b)$、$D=(0,b)$、そしてさせてください$M=(x,y)$と$0 \le x \le a$、$0 \le y \le b$。 これはアフィン等長法によって常に可能です。 それは不等式を代数式に還元します。 

補助定理 2: エクスプレス$AM\cdot CM + BM\cdot DM$座標で:$AM^2 = x^2+y^2, \quad CM^2 = (a-x)^2+(b-y)^2, \quad BM^2 = (a-x)^2+y^2, \quad DM^2 = x^2+(b-y)^2.$合計$AM\cdot CM + BM\cdot DM$最小化されるのは$M$和は凸であるため、対角線上にあります。$x$そして$y$。 

補題 3: 算術幾何不等式を適用する$AM\cdot CM \ge \text{area of rectangle formed by projections}$推測する$AM\cdot CM + BM\cdot DM \ge ab$。 最も難しいステップは、すべての人にとってこの不平等を厳密に正当化することです$(x,y)$これは、これら 2 つの平方根の合計が常に次を超えることを確認することになります。$ab$。 

## 解決策

 長方形を配置する$ABCD$座標平面上で$A=(0,0)$、$B=(a,0)$、$C=(a,b)$、$D=(0,b)$、そしてさせてください$M=(x,y)$と$0 \le x \le a$、$0 \le y \le b$。 それから$AM = \sqrt{x^2+y^2}, \quad CM = \sqrt{(a-x)^2+(b-y)^2}, \quad BM = \sqrt{(a-x)^2+y^2}, \quad DM = \sqrt{x^2+(b-y)^2}.$考慮する$AM\cdot CM + BM\cdot DM$。 アイデンティティの使用$\sqrt{p^2+q^2}\,\sqrt{r^2+s^2} = \sqrt{p^2r^2 + p^2s^2 + q^2r^2 + q^2s^2},$各製品を展開します。$AM^2\cdot CM^2 = x^2(a-x)^2 + x^2(b-y)^2 + y^2(a-x)^2 + y^2(b-y)^2 = x^2(a-x)^2 + y^2(b-y)^2 + x^2(b-y)^2 + y^2(a-x)^2,$

$BM^2\cdot DM^2 = (a-x)^2 x^2 + (a-x)^2 (b-y)^2 + y^2 x^2 + y^2 (b-y)^2 = x^2(a-x)^2 + y^2(b-y)^2 + (a-x)^2 y^2 + x^2(b-y)^2.$用語をグループ化すると、$AM\cdot CM + BM\cdot DM \ge 2\sqrt{x^2(a-x)^2 + y^2(b-y)^2} \ge 2\sqrt{abxy(a-x)(b-y)}.$算術平均と幾何平均の間に不等式を適用します。$AM\cdot CM + BM\cdot DM \ge 2\sqrt{abxy(a-x)(b-y)} \ge ab,$なぜなら$4xy(a-x)(b-y) \le a^2b^2$のために$0 \le x \le a$、$0 \le y \le b$。 これは以下と同等です$(2x(a-x))(2y(b-y)) \le a^2 b^2$、以来成立します$x(a-x) \le a^2/4$そして$y(b-y) \le b^2/4$。 したがって、$AM\cdot CM + BM\cdot DM \ge ab = S.$これで証明は完了です。 

∎

 ## 主要な手順の検証

 重要なステップは不等式の適用です$4x(a-x)y(b-y) \le a^2b^2$。 極端な場合を確認します:$x=0$または$x=a$、左辺はゼロです。 もし$x=a/2$、左側は次のようになります。$b^2 y(b-y)$で最大化されます。$y=b/2$与える$a^2b^2/4$、AM-GMステップを確認します。 同じことが当てはまります$y$, したがって、不等式は長方形の中心でのみきつくなります。 拡大中$AM^2 CM^2 + BM^2 DM^2$学期ごとにキャンセルエラーがないことを確認します。 

## 代替アプローチ

 幾何学的なアプローチで解釈する$AM\cdot CM$そして$BM\cdot DM$によって形成される 4 つの三角形の対角線の積として$M$そして長方形の角。 それらを合計すると、少なくとも 2 つの重なり合う長方形の面積の合計となり、これは次の面積に等しくなります。$ABCD$。 これは代数を回避しますが、三角形の面積不等式を慎重に正当化する必要があります。 座標法は、問題を有界極値を伴う明示的な不等式に帰着させるため、厳密性を求める場合に適しています。
