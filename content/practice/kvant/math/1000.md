## 解決策

 円弧を含む円をみましょう$AB$中心がある$O$と半径$1$。 以来$K$円弧の中点です$AB$、次のように座標を選択する場合があります。$$K=(1,0),$$そして$$A=(\cos\alpha,\sin\alpha), \qquad B=(\cos\alpha,-\sin\alpha),$$一部の人にとっては$0<\alpha<\pi$。 

させて$$M=(\cos\theta,\sin\theta), \qquad -\alpha<\theta<\alpha.$$条件$AM>MB$暗示する$\theta<0$ただし、この事実は計算には必要ありません。 

以来$H$セグメント上にあります$AM$、数が存在します$t$そのような$$H=A+t(M-A).$$したがって、$$AH=t\,AM, \qquad HM=(1-t)AM.$$という条件が$KH$に垂直です$AM$は$$(K-H)\cdot(M-A)=0.$$置き換える$H=A+t(M-A)$与える$$(K-A)\cdot(M-A)-t\,|M-A|^2=0,$$したがって$$t=\frac{(K-A)\cdot(M-A)}{|M-A|^2}.$$まず分母を計算します。$$|M-A|^2 = (\cos\theta-\cos\alpha)^2+(\sin\theta-\sin\alpha)^2.$$使用する$$(\cos u-\cos v)^2+(\sin u-\sin v)^2 = 2-2\cos(u-v),$$私たちは得る$$|M-A|^2 = 2-2\cos(\theta-\alpha) = 4\sin^2\frac{\alpha-\theta}{2}.$$次、$$(K-A)\cdot(M-A) = (1-\cos\alpha)(\cos\theta-\cos\alpha) -\sin\alpha(\sin\alpha-\sin\theta).$$拡張後は、$$(K-A)\cdot(M-A) = \cos\theta-\cos\alpha-\cos\alpha\cos\theta+\cos^2\alpha -\sin^2\alpha+\sin\alpha\sin\theta.$$以来$\cos^2\alpha-\sin^2\alpha=\cos2\alpha$そして$$\cos\alpha\cos\theta-\sin\alpha\sin\theta = \cos(\alpha+\theta),$$これはこうなる$$(K-A)\cdot(M-A) = \cos\theta-\cos\alpha+\cos2\alpha-\cos(\alpha+\theta).$$申請中$$\cos x-\cos y = -2\sin\frac{x+y}{2}\sin\frac{x-y}{2},$$2 つの違いから得られる結果$$(K-A)\cdot(M-A) = 2\sin\frac{\alpha+\theta}{2}\sin\frac{\alpha-\theta}{2} - 2\sin\frac{3\alpha+\theta}{2}\sin\frac{\alpha-\theta}{2}.$$ファクタリング、$$(K-A)\cdot(M-A) = 2\sin\frac{\alpha-\theta}{2} \left( \sin\frac{\alpha+\theta}{2} - \sin\frac{3\alpha+\theta}{2} \right).$$使用する$$\sin u-\sin v = 2\cos\frac{u+v}{2}\sin\frac{u-v}{2},$$私たちは得ます$$(K-A)\cdot(M-A) = 4\sin\frac{\alpha-\theta}{2} \cos\frac{2\alpha+\theta}{2} \sin\frac{\alpha}{2}.$$以来$$\cos\frac{2\alpha+\theta}{2} = \cos\left(\alpha+\frac{\theta}{2}\right),$$そして$$2\sin\frac{\alpha}{2} \cos\left(\alpha+\frac{\theta}{2}\right) = \cos\frac{\alpha+\theta}{2}-\cos\frac{3\alpha+\theta}{2},$$式は次のように簡略化されます$$(K-A)\cdot(M-A) = 2\sin^2\frac{\alpha-\theta}{2} \frac{\cos\frac{\alpha+\theta}{2}}      {\cos\frac{\alpha-\theta}{2}}.$$したがって、$$t = \frac{\cos\frac{\alpha+\theta}{2}}        {2\cos\frac{\alpha-\theta}{2}}.$$したがって$$2t-1 = \frac{\cos\frac{\alpha+\theta}{2}       -\cos\frac{\alpha-\theta}{2}}        {\cos\frac{\alpha-\theta}{2}}.$$使用する$$\cos u-\cos v = -2\sin\frac{u+v}{2}\sin\frac{u-v}{2},$$私たちは得る$$2t-1 = \frac{\sin\frac{\alpha+\theta}{2}}      {\sin\frac{\alpha-\theta}{2}}.$$弦の長さは満たしています$$AM = 2\sin\frac{\alpha-\theta}{2}, \qquad MB = 2\sin\frac{\alpha+\theta}{2}.$$その結果、$$(2t-1)AM = \frac{\sin\frac{\alpha+\theta}{2}}      {\sin\frac{\alpha-\theta}{2}} \cdot 2\sin\frac{\alpha-\theta}{2} = 2\sin\frac{\alpha+\theta}{2} = MB.$$以来$AH=tAM$そして$HM=(1-t)AM$、$$AH-(HM) = (2t-1)AM = MB.$$したがって$$AH=HM+MB.$$これで証明は完了です。

 ## 主要な手順の検証

 最初のデリケートなステップは、幾何学的条件をパラメータに変換することです。$t$。 以来$$H=A+t(M-A),$$からのベクトル$H$に$K$は$$K-A-t(M-A).$$直交性$AM$の内積を意味します$M-A$消えます。 結果として得られる一次方程式を解くと、$t$与える$$t=\frac{(K-A)\cdot(M-A)}{|M-A|^2}.$$直角度を超える幾何学的仮定は使用されません。 

2番目のデリケートなステップは関係です$$(2t-1)AM=MB.$$から始まる$$t=\frac{\cos\frac{\alpha+\theta}{2}}          {2\cos\frac{\alpha-\theta}{2}},$$直接計算する$$2t-1 = \frac{\cos\frac{\alpha+\theta}{2}       -\cos\frac{\alpha-\theta}{2}}      {\cos\frac{\alpha-\theta}{2}} = \frac{\sin\frac{\alpha+\theta}{2}}      {\sin\frac{\alpha-\theta}{2}}.$$乗算$$AM=2\sin\frac{\alpha-\theta}{2}$$正確に与える$$MB=2\sin\frac{\alpha+\theta}{2}.$$コサイン差の恒等式に符号誤りがあると結論が覆されるため、このステップは慎重にチェックする必要があります。 

3 番目の微妙な点は、弦長の計算式です。 角度分離のある単位円上の点の場合$\delta$、$$\text{chord}=2\sin\frac{\delta}{2}.$$ここでの別れは、$\alpha-\theta$そして$\alpha+\theta$、次の式が得られます。$AM$そして$MB$。 

## 代替アプローチ

 合成解は、次の接線を導入することによって取得できます。$A$そして$M$そして、弦、投影、等しい円弧の間の古典的な関係を使用します。 中間点$K$弧の$AB$にはいくつかの同等の特徴があります。それは、の内部二等分線上にあります。$\angle AOB$、および行$KA$そして$KB$対応する弦と等しい角度を作ります。 これらの角度関係を利用し、慎重に選択した三角形に正弦則を適用することにより、以下と同等の比例関係を導き出すことができます。$$AH-HM=MB.$$別のアプローチでは、ラインに沿ったアフィン座標を使用します。$AM$。 の投影を計算します。$K$に$AM$ベクトル幾何学を通じて結果を範囲の中心角で直接表現します。 これは本質的に幾何学的なままですが、明示的なデカルト座標を避けます。 投影パラメータが次のとおりであるため、上記の座標方法が推奨されます。$t$は単一の直交方程式から自然に現れ、残りは標準の三角恒等式に帰着します。
