 ## 問題

 多項式は存在しますか$P(x)$負の係数を持ちますが、そのべき乗のすべての係数は$P^n(x)$、$n\gt1$陽性ですか？ 

O. クリジャノフスキー

 モスクワ数学オリンピック (LVII、1994)

 ## 探検

 次のような負の係数を持つ多項式を考えてみましょう。$P(x) = -x + 2$または$P(x) = x^2 - x + 1$。 低電力を計算すると、負の係数が伝播することがすぐにわかります。$P(x) = -x + 2$、正方形は$P^2(x) = (-x + 2)^2 = x^2 - 4x + 4$、まだ負の係数を持っています。 次のような、より大きな正の項を追加して補正しようとします。$P(x) = x^2 + 3x - 1$、正方形は$P^2(x) = x^4 + 6x^3 + 7x^2 - 6x + 1$、負の係数が保持されます。 テスト$P(x) = -1 + x + x^2$与える$P^2(x) = 1 - 2x + 3x^2 + 2x^3 + x^4$、再び否定的な用語が持続します。 

小さな次数の例は、次の単一の負の係数が存在することを示唆しています。$P(x)$少なくとも 1 つの負の係数が生じます$P^2(x)$。 直観的には、乗算によって負の寄与が項全体に分散され、最初の負の値は他の項の正の係数によって完全に吸収できないということです。 これは、この問題が不可能である可能性があることを示唆しており、一般論として、少なくとも 1 つの負の係数を持つ多項式では、一部のべき乗が常に負の係数を保持することが示されなければなりません。 

決定的な困難は、任意の次数と任意の係数の組み合わせについてこれを証明することです。特に、負の係数が正の係数と比較して大きさが小さい場合にそうです。 不注意に合計すると、完全に正のべき乗を生成するキャンセルを見落とす可能性があるため、各ステップでは、どの項がべき乗の各係数に寄与するかを注意深く追跡する必要があります。 

## 問題の理解

 問題は多項式が存在するかどうかを尋ねます$P(x)$すべての整数に対して次のような負の係数を少なくとも 1 つ持つ$n > 1$、のすべての係数$P^n(x)$はポジティブです。 これはタイプ D の問題です。「存在するものを構築 / 表示する」、または存在しない場合は不可能であることを証明します。 中心的な問題は、負の寄与が乗算され、累乗の拡大で結合され、負の係数が残る可能性があることです。 調査の結果、負の係数があるため、そのような多項式は存在しないことが強く示唆されています。$P(x)$必然的に、より高いべき乗で負の係数が生成されます。 直観的には、乗算によってマイナスの影響が広がり、係数を微調整しないと他のプラスの項で完全に打ち消すことはできませんが、これはすべての人にとって不可能であるように見えます。$n>1$。 

## 証明されたアーキテクチャ

 補題 1: もし$P(x)$負の係数を持つ場合、負の係数を持つ最低次項は、正の累乗後の次数寄与が厳密に正になります。 スケッチ: 各単項式の最低次数における負の項の寄与を追跡します。$P^n(x)$。 

補題 2: 負の係数を持つ多項式は、あるべき乗で負の係数を生成します。$P^n(x)$、$n > 1$。 スケッチ: 負の係数が現れる最小次数と最大次数を考慮します。 展開における他の項との畳み込みは、最終的には常に負の係数を生成します。 

主な主張: 多項式がない$P(x)$次のような負の係数で存在します。$P^n(x)$すべての係数がすべて正である$n > 1$。 スケッチ: 補題 2 を適用します。 の否定的な用語$P$すべての力で消えることはできません。 

最も難しいステップ: 負の係数を示す補題 2 は、必然的にある程度の累乗に耐えます。 

## 解決策

 矛盾のために多項式が存在すると仮定します。$P(x)$少なくとも 1 つの負の係数があり、それがすべての$n>1$、$P^n(x)$は正の係数のみを持ちます。 書く$P(x) = a_0 + a_1 x + \dots + a_m x^m$整数付き$m \ge 0$、そしてさせてください$k$次のような最小のインデックスになります$a_k < 0$。 それから$a_0, \dots, a_{k-1} \ge 0$、 そして$a_k < 0$。 

考慮する$P^2(x) = P(x) \cdot P(x)$。 の係数$x^k$で$P^2(x)$は$$\sum_{i=0}^k a_i a_{k-i}.$$すべての条件$i < k$持っている$a_i \ge 0$そして$a_{k-i} \ge 0$ない限り$k-i = k$にのみ発生します。$i=0$与える$a_0 a_k \le 0$。 用語$i = k$貢献する$a_k a_0 < 0$、および条件$0 < i < k$は非負です。 したがって、合計は次のようになります$a_0 a_k + (\text{nonnegative terms}) \le a_0 a_k < 0$。 したがって、次の係数は、$x^k$で$P^2(x)$は負であり、のすべての係数が次のとおりであるという仮定に反します。$P^2(x)$ポジティブです。 

この議論はどのような場合にも等しく当てはまります$n > 1$: 負の係数を持つ最低次項$P(x)$に伝播します$P^n(x)$、負の係数が生成されます。 したがって、負の係数を持つ多項式は、すべてのべき乗においてすべて正の係数を持つことはできません。$n > 1$。 

これで証明は完了です。

 ## 主要な手順の検証

 デリケートなステップは、次の係数を特定することです。$x^k$で$P^2(x)$。 明示的に計算する: let$P(x) = a_0 + \dots + a_m x^m$と$k$そのような最小限の$a_k < 0$。 それから$x^k$で$P^2(x)$から来ています$a_i a_{k-i}$、$i = 0, \dots, k$。 以来$a_0, \dots, a_{k-1} \ge 0$、 のみ$a_0 a_k$そして$a_k a_0$は否定的です。 他のすべての寄与は負ではありません。 これらを加算するとマイナスの和になります。 小さな例をテストする。例:$P(x) = 2 - x + x^2$、与える$P^2(x) = 4 - 4x + 5x^2 - 2x^3 + x^4$、ここで、$x$係数は負であり、推論が裏付けられます。 

## 代替アプローチ

 別の方法は、係数を累乗展開の積に対応するインデックスの複数セットの合計として見る、母関数アプローチを検討することです。 の負の係数$P(x)$は、それを含むすべてのマルチセットに負の項を生成し、一部の負の係数が確実に残るようにします。 直接の最小次数引数は、明確さと技術的オーバーヘッドを最小限に抑えるために推奨され、組み合わせの爆発を避け、証明を完全に初歩的にします。
