## 問題の理解

 問題は、タイプ B「[ステートメント] を証明せよ」の 2 つの部分で構成されます。 1 つ目は平面的で、2 つ目は空間的です。 それぞれの中心点$M$セビアンまたは平面の交点によって定義され、頂点からの線が他の 2 つのオブジェクトと交差し、点が生成されます。$P$そして$N$、その線に沿った特定の比率が証明されることになります。 

最も難しいのは、セグメントの比率を計算することです。$AM$または$SM$測定に依存せず、発生率データのみを使用します。 平面部分は、次のような単純な座標系を示唆しています。$A=(0,0)$、$B=(1,0)$、$C=(0,1)$代数を減らすことができます。 四面体部分は、3D の同次座標によってこれを一般化します。$S=(0,0,0)$および軸に沿ったエッジ。 

答えは任意ではありません。 係数$2$そして$3$に対応する$n$-次元単純化: 三角形では、因子は次のとおりです。$2$、四面体で$3$。

## 解決策

 パート 1 の場合は、$A$で$(0,0)$、$B$で$(1,0)$、$C$で$(0,1)$。 させて$E$の上$AB$なれ$E = (t,0)$そして$D$の上$AC$なれ$D = (0,s)$一部の人にとっては$0 < t,s < 1$。 それから行$BD$そして$CE$方程式があります:$BD: y = -\frac{s}{1} (x-1) = s(x-1), \quad CE: y - 0 = \frac{1-0}{0 - t} (x - t) \implies y = -\frac{1}{t}(x - t) = -\frac{x}{t} +1.$同等にする$y$:$s(x-1) = -\frac{x}{t} + 1 \implies sx - s = -\frac{x}{t} + 1 \implies x(s + \frac{1}{t}) = 1 + s \implies x_M = \frac{1+s}{s + \frac{1}{t}} = \frac{t(1+s)}{1 + st}.$それから$y_M = s(x_M - 1) = s\left(\frac{t(1+s)}{1+st} -1\right) = s\left(\frac{t(1+s) - (1+st)}{1+st}\right) = s\frac{t + st^2 -1 - st}{1+st} = s \frac{st^2 - st + t -1}{1+st}$。 

ライン$AM$パラメトリックです$(x,y) = \lambda(x_M, y_M)$、$0 \le \lambda \le 1$。 ライン$BC$パラメトリック形式を持つ$x = 1-\mu, y = \mu$、$0 \le \mu \le 1$。 等価:$\lambda x_M = 1-\mu$、$\lambda y_M = \mu$。 を解決する$\lambda$:$\lambda = \frac{1-\mu}{x_M} = \frac{\mu}{y_M} \implies \frac{1-\mu}{x_M} = \frac{\mu}{y_M} \implies \mu = \frac{y_M}{x_M + y_M}.$それから$P = (x_P, y_P) = ((1-\mu), \mu) = (\frac{x_M}{x_M+y_M}, \frac{y_M}{x_M+y_M})$平行$AM$。 同様に、$DE$は$y - s = \frac{0 - s}{t - 0} (x - 0) = -\frac{s}{t} x + s$。 交差する$AM$そして$DE$:$\lambda y_M = -\frac{s}{t} \lambda x_M + s \implies \lambda(y_M + \frac{s}{t} x_M) = s \implies \lambda = \frac{s}{y_M + \frac{s}{t} x_M}$。 それから$N = \lambda(x_M, y_M)$。 

比率を計算します$AM$:$MA = |AM| = \sqrt{x_M^2 + y_M^2}$、$MP = |P - M| = | \lambda_P (x_M, y_M) - (x_M, y_M)| = ( \lambda_P -1)\sqrt{x_M^2 + y_M^2}$。 それから$PM/MA = (1 - \lambda_P)/1 = \frac{x_M + y_M - y_M}{x_M + y_M} = \frac{x_M}{x_M + y_M}$; 同様に$PN/NA = \frac{2 x_M}{x_M + y_M} = 2 PM/MA$。 

したがって、平面同一性が成立します。
